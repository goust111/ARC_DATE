实现内容是 `D2/0 + D3/0` 的组合：solver 现在只接受并处理水平线段，参考线段仍取中位行，但输出只把所有线段的左端对齐到参考线段左端，长度各自保留；generator 采用 output-first，固定生成“输入右端对齐、输出左端对齐”的样例，并强制至少一条比参考短、至少一条比参考长，避免退化回原题。

验证结果：
- 题目要求的稳定性测试：`50/50` 成功，约 `1ms/call`
- 非退化检查（100 个样本）：
  - `same_as_base = 0`
  - `multi_len_outputs = 100`
  - `left_aligned_outputs = 100`
  - `right_staggered_outputs = 100`

这说明生成样本稳定触发了“水平线段 + 仅头端对齐”的融合行为，而不是原始“双端对齐并统一长度”的行为。
