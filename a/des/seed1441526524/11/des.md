<new_puzzle>
description：根据每个封闭区域内部"种子"像素的颜色，选择该区域边框上与种子同色的缺口方向，将区域内容沿该方向平移出框外，同时用背景色填充原区域。

Input structure：
- 背景为黑色（black）。
- 网格中有若干个由同一种非背景色（如 grey）绘制的矩形边框，每个边框恰好在四条边的中段各有一个单像素缺口，四个缺口分别用四种不同的非背景、非边框色填充（例如北缺口为 red，东缺口为 blue，南缺口为 green，西缺口为 yellow），每道题中四个方向与四种颜色的对应关系在所有边框间保持一致。
- 每个边框内部的中心位置放置一个单像素"种子"，种子颜色恰好等于该边框四个缺口颜色之一。
- 边框内部除种子外，还包含若干由各种颜色绘制的小图案（载荷），载荷不接触边框壁。

Rule：
- 对于每个矩形边框，读取其内部种子像素的颜色。
- 找到该边框上与种子同色的缺口——该缺口所在的方向即为"出射方向"。
- 将该边框内部所有非背景像素（包括种子和载荷）整体沿出射方向平移，平移距离等于边框在该方向上的内部长度，使得内容完全移出边框，出现在边框外侧紧邻缺口的位置。
- 原边框内部全部填充为背景色，但边框本身（含四个缺口像素）保持不变。

Key insight：
缺口颜色构成一个方向编码表（北/东/南/西各对应一种颜色），种子颜色是查表键——解题者需要先从多个样例中归纳出颜色-方向映射关系，再用种子颜色查表确定平移方向。两层推理缺一不可：第一层是发现缺口色与方向的对应规则，第二层是将内容沿正确方向"射出"边框。
</new_puzzle>

<new_puzzle>
description：将散落的单色碎片拼回各自所属的"母版轮廓"内，拼入位置由碎片形状与轮廓内缺失区域的形状匹配决定，拼入后碎片改用母版的颜色。

Input structure：
- 背景为黑色（black）。
- 网格中有若干个较大的单色连通区域（母版），每个母版颜色各不相同（如 red、blue、green）。每个母版内部有一个或多个"洞"（被背景色填充的连通区域），洞的形状各不相同。
- 网格的空白区域散落着若干小的单色碎片，碎片的颜色均为同一种中性色（如 grey）。每个碎片的形状恰好与某个母版内某个洞的形状完全相同（无需旋转或翻转）。
- 碎片数量等于所有母版中洞的总数，且一一对应。

Rule：
- 对每个灰色碎片，在所有母版的洞中寻找形状完全匹配的洞（碎片与洞的像素形状逐格对齐比较，不做旋转或翻转）。
- 将碎片移入匹配的洞中，使碎片完全填充该洞，并将碎片颜色改为所属母版的颜色。
- 碎片原来所在的位置变为背景色。
- 母版本体及其边界像素保持不变。

Key insight：
解题者需要先将每个碎片的几何形状与各母版内洞的几何形状逐一比对以找到唯一匹配，再根据匹配将碎片"嵌入"对应母版并继承其颜色。这要求同时进行形状识别和颜色重映射两层操作——碎片本身的灰色不提供归属线索，唯有形状匹配才能确定归属。
</new_puzzle>

<new_puzzle>
description：网格中的彩色线段是"折叠指令"——沿每条线段将其一侧的图案翻折到另一侧，多条折叠按从短到长的顺序依次执行，翻折的像素叠加在已有内容之上。

Input structure：
- 背景为黑色（black）。
- 网格中有一块由多种颜色构成的矩形图案区域（画布），画布内像素颜色各异，构成一幅可辨识的图案。
- 画布内部有若干条完整横跨画布或纵跨画布的直线段（折痕线），每条折痕线由单一颜色绘制，各折痕线颜色互不相同且与画布图案中的其他颜色不重复。折痕线只会是水平线或垂直线，且每条线恰好将画布在其方向上分成两部分（不一定等分）。

Rule：
- 按折痕线长度从短到长排序（若长度相同则先处理水平线）。
- 依次处理每条折痕线：将该折痕线较小一侧（像素数较少一侧）的所有非背景像素沿折痕线做镜像翻折到较大一侧。翻折后的像素覆写目标位置的原有像素。
- 翻折完成后，擦除折痕线本身（变为背景色），并删除较小一侧的所有像素（变为背景色），输出仅保留较大一侧的内容（尺寸缩小到较大一侧）。
- 多条折痕线的处理是嵌套的：第一次折叠后画布缩小，第二条折痕线在缩小后的画布上操作，以此类推。

Key insight：
折痕线的处理顺序至关重要——长度排序决定了折叠的先后，而每次折叠都会改变画布的尺寸和内容，从而影响后续折叠的效果。解题者必须先识别出折痕线（贯穿画布的单色直线）、推断执行顺序（短到长）、确定折叠方向（小侧折向大侧），三层推理环环相扣。
</new_puzzle>

<new_puzzle>
description：每个前景对象根据其"影子"的朝向和长度，沿影子方向复制自身若干次，形成一串等间距的副本序列。

Input structure：
- 背景为黑色（black）。
- 网格中有若干个小型多色连通对象（精灵），每个精灵由 2-6 个非背景像素组成，内部可包含多种颜色。
- 每个精灵恰好有一个方向上紧邻一条由 grey 像素组成的直线段（称为"影子"），影子从精灵边缘开始向外延伸，方向为上、下、左、右之一。影子不会接触其他任何非背景对象。
- 不同精灵的影子长度可以不同（1 到 5 个像素不等）。

Rule：
- 对每个精灵，识别其 grey 影子的方向和长度 L。
- 擦除影子（变为背景色）。
- 沿影子方向，以间距等于精灵自身在该方向上的尺寸为步长，连续放置 L 个精灵副本。第一个副本紧接精灵原始位置之后（影子所在方向），后续副本依次排列。
- 每个副本保持精灵的原始形状和颜色，不做旋转或翻转。
- 原始精灵保持不变。

Key insight：
grey 影子同时编码了两条信息：方向（影子朝哪延伸）和重复次数（影子有几个像素长）。解题者需要发现影子不只是装饰，而是一个"生成指令"——方向决定复制朝向，长度决定复制数量。擦除影子后用精灵副本替代，构成从指令到执行的推理跳跃。
</new_puzzle>

<new_puzzle>
description：在网格的分层嵌套矩形框架中，每一层框架的颜色决定其内部内容的变换方式，变换从最外层向最内层依次累积执行。

Input structure：
- 背景为黑色（black）。
- 网格中有一个嵌套的矩形框架结构：最外层是一个单像素宽的矩形框，框内是背景色间隔，然后是下一层矩形框，如此嵌套 2-4 层。每层框的颜色不同。
- 最内层框的内部包含一个由若干非背景色像素组成的小图案（载荷）。
- 框架颜色来自一个固定的变换映射表，该映射表在所有样例中保持一致：
  - red 表示"水平翻转"
  - blue 表示"垂直翻转"
  - green 表示"顺时针旋转 90 度"
  - yellow 表示"保持不变"

Rule：
- 从最外层框架开始，向内逐层读取框架颜色。
- 将每层框架颜色对应的变换依次应用于最内层的载荷图案——先应用最外层的变换，再应用次外层的变换，以此类推直到最内层框架。
- 输出仅包含经过所有变换后的载荷图案（裁剪掉所有框架和间隔，只输出变换后的载荷本身）。

Key insight：
框架不仅是装饰结构，每一层的颜色都是一个变换指令。解题者需要三层推理：第一层是发现嵌套框架的层次结构并识别每层颜色；第二层是建立颜色-变换的映射表（需从多个样例中归纳）；第三层是确定变换的执行顺序是从外到内依次累积。任何一层推理错误都会导致输出方向错误。
</new_puzzle>

<new_puzzle>
description：网格中散布的单色标记像素形成若干"星座"，每个星座内标记像素的相对位置编码了一种连线图案；将每个星座的标记点用其专属颜色的直线段两两相连，连线方式由星座内标记像素的空间排列唯一确定。

Input structure：
- 背景为黑色（black）。
- 网格中有若干组同色单像素标记（如 red 标记组、blue 标记组、green 标记组），每组 3-5 个像素，组内颜色相同、组间颜色不同。
- 同一组的标记像素彼此不相邻（至少间隔 2 格），形成一个稀疏的"星座"。
- 网格中另有一个由 grey 像素绘制的小型"图例区域"，图例区域包含一个示意图：若干 grey 点通过 grey 线段相连，展示了一种连线拓扑（例如三角形连接、链式连接、星形连接等）。图例中的点数等于每组标记的像素数。

Rule：
- 读取图例区域中 grey 点之间的连线拓扑——哪些点对之间有线段相连。图例中点的排列按从左到右、从上到下排序，得到 1 号点、2 号点、3 号点……
- 对每组同色标记像素，同样按从左到右、从上到下排序，得到该组的 1 号点、2 号点、3 号点……
- 按照图例的连线拓扑，在该组的对应编号点对之间画直线段（使用 Bresenham 直线或逐像素连接最短路径），线段颜色与该组标记颜色相同。
- 标记点本身保留，图例区域保持不变。

Key insight：
图例不是装饰，而是一个拓扑模板——它定义了"哪些点应该相连"。解题者需要先识别图例中的连接关系，再将同一拓扑应用到每个颜色组的标记点上。关键在于发现图例中点的排序方式（从左到右、从上到下）与标记组中点的排序方式一致，从而建立对应关系。
</new_puzzle>

<new_puzzle>
description：根据网格边缘的彩色刻度标记，在网格内部对应的行列交叉点处绘制标记色的像素，形成一张散点投影图。

Input structure：
- 背景为黑色（black）。
- 网格的最上方一行（第 0 行）和最左方一列（第 0 列）是"刻度轴"，其余区域是"画布"。
- 上方刻度轴上间隔分布着若干彩色像素（非背景色），每个像素占据一个单元格，颜色各异或有重复。
- 左侧刻度轴上同样间隔分布着若干彩色像素。
- 刻度轴的角点（第 0 行第 0 列）始终为背景色。

Rule：
- 对于上方刻度轴中的每个彩色像素（位于第 0 行第 c 列，颜色为 X），以及左侧刻度轴中的每个彩色像素（位于第 r 行第 0 列，颜色为 Y）：
  - 当且仅当 X == Y（颜色相同）时，在画布的第 r 行第 c 列绘制该颜色的像素。
- 刻度轴本身保持不变。
- 画布上不符合条件的位置保持背景色。

Key insight：
上方和左侧的彩色标记构成两个"坐标投影"——只有当某行的标记色与某列的标记色一致时，交叉点才被点亮。解题者需要发现这不是简单地填充所有交叉点，而是一个基于颜色匹配的筛选条件。规则本身简洁，但隐蔽性在于颜色匹配这一关键过滤条件不容易从单个样例中看出——需要对比多个样例才能排除"填充所有交叉点"等错误假设。
</new_puzzle>

<new_puzzle>
description：网格中多个相同形状但不同颜色的对象分别经历了不同的"损坏"（部分像素被擦除）；利用所有副本互补修复，将完整形状以每个副本自己的颜色重新绘制。

Input structure：
- 背景为黑色（black）。
- 网格中有 N 个（N ≥ 3）相互分离的前景对象，每个对象由单一颜色绘制，各对象颜色互不相同。
- 这 N 个对象原本形状完全相同（相同的像素模式），但每个对象都被随机擦除了一部分像素（擦除位置各不相同），导致每个对象看起来都是残缺的。
- 任意两个对象的"残缺区域"不完全重叠——即通过所有副本的并集可以还原完整形状。
- 所有对象的包围盒尺寸相同，且对象在各自包围盒内的相对位置一致。

Rule：
- 将所有 N 个对象的包围盒对齐（以各自包围盒的左上角为基准）。
- 在对齐后的坐标系中，对每个局部坐标取所有副本的并集：如果某坐标在任一副本中存在非背景像素，则该坐标属于完整形状。
- 对每个原始对象，在其原始位置用其自身颜色绘制完整形状（补回所有缺失像素）。
- 不改变任何对象的位置。

Key insight：
这是参考题 1（冗余拼块修复）的变异——但不是在同一格点阵列中找共识多数，而是跨越空间分布的异色对象之间做形状并集。解题者需要先发现"这些不同颜色的残缺对象其实是同一形状的不同损坏版本"，然后通过对齐包围盒、取并集来恢复完整形状，最后分别用各自颜色补全。
</new_puzzle>
