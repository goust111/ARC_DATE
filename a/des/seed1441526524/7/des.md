<new_puzzle>
description：根据每个封闭区域内部"种子像素"的颜色，从区域边界的缺口处向外生长出与种子同色的射线，射线长度等于该区域内种子像素的数量。

Input structure：
- 背景色（bg）为网格中最常见的颜色。
- 网格中散布着若干由同一种边框颜色（如 grey）围成的封闭矩形区域，每个区域的边框上恰好有一个单像素宽的缺口。
- 每个矩形区域内部散布着若干同色的"种子像素"，不同区域的种子颜色互不相同（例如一个区域内是 red 种子，另一个是 blue 种子）。
- 区域内部除种子像素外其余为 bg。

Rule：
- 对每个封闭矩形区域，首先定位其边框上的唯一缺口位置，确定缺口朝向（上、下、左、右——即缺口像素相对于区域内部的方向取反，得到向外的方向）。
- 数出该区域内部种子像素的个数 N。
- 从缺口位置出发，沿缺口朝外的方向，用种子像素的颜色绘制一条长度为 N 的直线射线（每个像素占一格）。
- 区域本身（边框和内部）保持不变。

Key insight：缺口的位置和朝向决定射线的生长方向，种子像素的数量（而非颜色种类或区域面积）决定射线的长度；解题者需要同时识别三个要素——缺口方位、种子计数、种子颜色——才能确定输出。
</new_puzzle>

<new_puzzle>
description：将网格中散落的同色碎片拼合回各自所属的矩形模板的缺失区域，依据碎片轮廓与模板缺口的形状匹配来确定归属和放置位置。

Input structure：
- 背景色（bg）为最常见颜色。
- 网格上有若干不同颜色的矩形"模板"，每个模板是一个实心矩形但被挖去了一个连通的不规则缺口区域（缺口处显示为 bg）。
- 网格的其他位置散落着若干单色碎片（4-连通的小型不规则形状），每个碎片的颜色与某个模板的颜色相同。
- 每个模板恰好对应一个碎片，且碎片的形状恰好等于该模板缺口的形状（可能需要平移，但不需要旋转或翻转）。

Rule：
- 对每个模板，找到其内部 bg 缺口区域的形状。
- 在网格中找到与该模板同色且形状与缺口完全匹配的碎片。
- 将该碎片平移到模板缺口的位置，填补缺口，使模板恢复为完整的实心矩形。
- 碎片原来所在的位置清除为 bg。

Key insight：颜色匹配缩小了碎片-模板的配对范围，但最终确认归属需要验证碎片形状与模板缺口形状的完全一致；解题者必须同时进行颜色配对和形状匹配两层推理。
</new_puzzle>

description：网格被分为多个条带区域，每个条带内包含一个"印章"图案和一组散落的颜色标记点；根据标记点相对于印章的方位，将印章沿该方位复制并粘贴到标记点所在位置，同时用标记点的颜色替换印章副本中的前景色。

Input structure：
- 背景色（bg）为最常见颜色。
- 网格被水平方向的单像素宽分隔线（sep 颜色）均匀分成若干高度相同的水平条带。
- 每个条带内有一个多色或单色的小型连通图案（"印章"），以及一个或多个散落的单像素标记点，标记点颜色各不相同且与印章中使用的颜色均不同。
- 每个条带内印章只有一个，但标记点可能有多个。

- 对每个条带，先识别出印章（像素数最多的连通前景对象）。

- 印章副本中所有非 bg 像素的颜色全部替换为该标记点的颜色。
- 保留原始印章不变；标记点本身被副本覆盖。

Key insight：标记点既是颜色源又是位置锚点；其相对于印章的方位决定了副本的平移方向，而其颜色决定了副本的重新着色——解题者需要分两步理解标记点的双重角色。

- 背景色（bg）为最常见颜色。
- 网格中央有若干层同心嵌套的矩形框架，每层框架由不同颜色的单像素宽边框组成（例如最外层是 blue 框、第二层是 red 框、第三层是 green 框）。
- 最内层框架的内部包含一个由某种颜色绘制的小型非对称图案（例如 L 形、T 形等明显有方向性的形状）。
- 框架层数在 1 到 4 之间。

Rule：
- 数出从最外层到最内层的框架层数 K（不包含最内层图案本身）。
- 将最内层图案绕其包围盒中心顺时针旋转 K×90 度。
- 所有框架边框保持不变，仅替换最内层图案为旋转后的版本。
- 输出网格尺寸与输入相同。

Key insight：框架的颜色是视觉干扰项——真正决定旋转角度的是框架的嵌套层数而非颜色；解题者需要先数出层数，再推断出"每层贡献 90 度旋转"的规律。
</new_puzzle>

Input structure：
- 背景色（bg）为最常见颜色。
- 网格边缘上有若干不同颜色的单像素起点标记，每个起点旁边紧邻一个同色像素表示初始行进方向（即起点对由两个同色像素组成，位于网格边缘，连线方向即行进方向）。
- 网格内部散布着若干 maroon 色的转向块（单像素），路径遇到转向块时做 90 度转弯（选择唯一可行的垂直方向继续前进，类似参考题 10 的走廊机制）。
- 不同路径可能在网格中交叉。

Rule：
- 每条路径从起点出发，沿初始方向逐格前进，遇到 maroon 转向块时做 90 度转弯（选择不回头且不出界的唯一垂直方向），遇到网格边界时终止。
- 路径的优先级由起点在网格边缘上按顺时针排列的顺序决定（从左上角开始顺时针）。优先级高的路径先绘制。
- 当一条路径试图经过已被更高优先级路径占据的格子时，该路径在该格子前一格终止，终止格标记为 yellow。
- 路径绘制使用其起点颜色，覆盖 bg 格子。

Key insight：解题者需要先从起点的边缘位置推断出顺时针优先级排序，再模拟各路径的行进过程并在交叉冲突处应用优先级规则——两层推理分别对应"发现排序规则"和"发现阻断机制"。
</new_puzzle>

<new_puzzle>
description：网格中的每个彩色对象根据其所在象限执行不同的变换操作——左上象限的对象水平翻转，右上象限的对象垂直翻转，左下象限的对象顺时针旋转 90 度，右下象限的对象逆时针旋转 90 度——然后所有对象向网格中心的十字线靠拢直到接触十字线。

Input structure：
- 背景色（bg）为最常见颜色。
- 网格正中央有一条单像素宽的水平线和一条单像素宽的垂直线组成十字分隔线（用 grey 色绘制），将网格均匀分为四个象限。
- 每个象限内有且仅有一个由单一前景色绘制的小型非对称连通对象（4-连通），四个对象颜色互不相同。
- 对象尺寸不超过 5x5，且不接触十字线或网格边缘。

Rule：
- 识别每个对象所在的象限。
- 对左上象限的对象执行水平翻转（左右镜像）；对右上象限的对象执行垂直翻转（上下镜像）；对左下象限的对象顺时针旋转 90 度；对右下象限的对象逆时针旋转 90 度。
- 变换完成后，将每个对象沿两个轴方向同时平移，使其包围盒尽量靠近十字线（紧贴十字线但不覆盖十字线本身）。具体地：水平方向上，对象包围盒靠近垂直十字线的一侧紧贴垂直线；垂直方向上，对象包围盒靠近水平十字线的一侧紧贴水平线。
- 清除对象原始位置，输出网格尺寸不变。

Key insight：象限身份同时决定了两件事——变换类型和移动目标角——解题者需要先建立"象限→变换"的映射表，再理解所有对象统一向中心汇聚的平移规则；十字线既是象限分界也是移动终止线，承担双重功能。
</new_puzzle>

<new_puzzle>
description：网格中每个带颜色边框的房间内有一个小型图案和若干"门"（边框缺口）；将图案通过每扇门复制到相邻房间中，副本的朝向由门所在的墙面决定。

Input structure：
- 背景色（bg）为最常见颜色。
- 网格中有若干矩形"房间"，由单像素宽的彩色边框围成。不同房间的边框颜色可以不同。
- 某些房间共享一面墙（边框颜色以较小房间的边框色为准），共享墙上有单像素宽的缺口作为"门"。
- 恰好有一个房间被标记为"源房间"——其内部包含一个用特殊颜色（与所有边框色均不同）绘制的小型非对称图案。其他房间内部均为 bg。
- 源房间可能有多扇门通向不同的相邻房间。

Rule：
- 找到源房间及其内部图案。
- 对源房间的每扇门，确定门在哪面墙上（上、下、左、右）。
- 将图案复制到门所通向的相邻房间内。副本的放置规则：
  - 门在上墙：图案保持原样，放置在相邻房间内部的底部居中位置。
  - 门在下墙：图案上下翻转，放置在相邻房间内部的顶部居中位置。
  - 门在左墙：图案逆时针旋转 90 度，放置在相邻房间内部的右侧居中位置。
  - 门在右墙：图案顺时针旋转 90 度，放置在相邻房间内部的左侧居中位置。
- 副本颜色与原图案颜色相同。源房间内的原始图案保持不变。

Key insight：门的墙面位置同时编码了两个信息——副本的目标房间和副本的旋转角度；解题者需要发现"门的方位→旋转规则"的映射关系，而不是简单地原样复制。
</new_puzzle>

<new_puzzle>
description：网格中散布着若干大小不同的同色实心矩形，以及一个由另一种颜色绘制的"选择框"；选择框内部完全包含的矩形保持不变，与选择框边界相交的矩形被裁剪到选择框内部，完全在选择框外部的矩形被删除；最终输出裁剪为选择框大小的网格，并且被裁剪的矩形用第三种颜色重新着色以标记其被截断状态。

Input structure：
- 背景色（bg）为最常见颜色。
- 网格上有若干大小和位置各异的同色（如 blue）实心矩形，互不重叠。
- 一个由另一种颜色（如 red）绘制的单像素宽矩形边框作为"选择框"，选择框不与任何 blue 矩形的边框重合。
- 选择框可能跨越部分 blue 矩形。

Rule：
- 以选择框内部区域（不含 red 边框）裁剪输出网格。
- 完全在选择框内部的 blue 矩形在输出中保持 blue 不变。
- 与选择框边界相交（部分在内部、部分在外部）的 blue 矩形，只保留其在选择框内部的部分，并将该部分重新着色为 green 以标记截断。
- 完全在选择框外部的 blue 矩形被删除（不出现在输出中）。
- 输出网格尺寸等于选择框内部区域的尺寸。

Key insight：解题者需要先理解"选择框定义裁剪窗口"的概念，再发现被截断矩形变色这一隐蔽规则——仅观察完整保留的矩形无法发现变色规则，必须关注跨越边界的矩形才能归纳出完整变换逻辑。
</new_puzzle>
