- `description`：根据每个封闭区域内部"种子"像素的颜色，用该颜色沿区域边界内壁涂一圈衬里，再将种子本身擦除。

- `Input structure`：
  - 背景为 Black。
  - 一种墙壁颜色（如 Grey）绘制了若干互不相交的封闭矩形框（框线宽1像素，框之间不共享边）。
  - 每个矩形框的内部（被墙壁包围的 Black 区域）恰好包含一个非 Black、非 Grey 的单像素"种子"，颜色各不相同（如 Red、Blue、Green 等）。
  - 种子的位置在框内随机。

- `Rule`：
  - 第一层：识别每个封闭矩形框，定位其内部区域（墙壁之内的所有 Black 像素加上种子像素构成的矩形区域）。
  - 第二层：对每个框，找到内部唯一的种子像素及其颜色 C。将种子像素恢复为 Black（擦除种子）。然后将该框内部区域紧贴墙壁的最内一圈像素（即内部矩形的边缘一圈）全部涂为颜色 C。若框的内部区域只有1像素宽或1像素高，则整个内部都涂为 C。
  - 墙壁本身保持不变，框外的 Black 背景也保持不变。

- `Key insight`：种子像素不标记位置，而是标记颜色——它的空间位置无关紧要，唯一的作用是为它所在的封闭区域指定衬里颜色。解题者需要先识别封闭区域的归属关系（哪颗种子属于哪个框），再理解"种子消失、边界染色"这一非直觉的反转操作。
</new_puzzle>

<new_puzzle>
- `description`：在网格中找到由同色像素组成的"桥"（连接两个不同色区域的窄通道），根据桥两端区域的颜色对桥本身进行条纹着色。

- `Input structure`：
  - 背景为 Black。
  - 网格中有若干大块的单色区域（4-连通，面积≥4），颜色各不相同（如 Red、Blue、Green、Yellow 等）。
  - 某些成对的区域之间由 Grey 像素组成的窄通道（宽度恰好1像素，长度≥2像素）相连，通道严格沿水平或垂直方向延伸。
  - 每条通道的两端各紧邻一个彩色区域（通道端点的4-邻居中有且仅有一个彩色区域像素）。
  - 不存在两条通道连接同一对区域的情况。

- `Rule`：
  - 第一层：识别所有 Grey 通道，并确定每条通道两端分别连接的彩色区域及其颜色（设为 C1 和 C2）。确定通道的方向（水平或垂直）和起止端。
  - 第二层：将通道像素从靠近 C1 区域的一端开始，交替涂为 C1 和 C2，即第1个像素涂 C1，第2个像素涂 C2，第3个像素涂 C1，以此类推。
  - 彩色区域本身和 Black 背景保持不变。

- `Key insight`：Grey 通道是纯结构性连接件，其最终颜色完全由它连接的两端区域决定。解题者需先从视觉上识别出"桥"的拓扑角色（连接两个不同区域），再发现条纹的交替规则来自两端颜色的有序排列。
</new_puzzle>

<new_puzzle>
- `description`：每个前景对象根据自身包含的孔洞数量，向外发射相应数量的正交射线；射线方向由孔洞在对象内的相对位置决定。

- `Input structure`：
  - 背景为 Black。
  - 网格中有若干 8-连通的单色前景对象（颜色各不相同），它们之间互不接触。
  - 每个对象可能包含零个或多个"孔洞"——即完全被该对象像素包围的 Black 连通区域（4-连通判定孔洞）。
  - 每个孔洞面积很小（1~4像素），在对象内部的位置肉眼可分辨地偏向对象的上、下、左、右四个象限之一。

- `Rule`：
  - 第一层：对每个对象，计算其包含的孔洞数量 N，并确定每个孔洞相对于对象 bbox 中心偏向哪个方向（上/下/左/右，取偏移量最大的轴向）。
  - 第二层：从对象 bbox 的对应边的中点出发，向该方向发射一条射线（宽1像素），颜色与对象相同。射线延伸至网格边缘或碰到另一个对象（不覆盖其他对象）时停止。若同一个方向有多个孔洞，仍只发射一条射线。
  - 没有孔洞的对象不发射任何射线。
  - 对象本身的像素（包括孔洞）保持不变。

- `Key insight`：孔洞同时编码了两种信息——数量决定射线总数，位置决定射线方向。解题者必须先发现孔洞的"计数"作用（为何有的对象有射线有的没有），再发现孔洞的"指向"作用（为何射线朝特定方向），两层归纳缺一不可。
</new_puzzle>

- `description`：将散落在网格中的彩色碎片按形状配对拼合成完整矩形，然后将每对拼合后的矩形缩放到由碎片面积之和决定的统一尺寸，并按颜色排序排列在输出网格中。

- `Input structure`：
  - 背景为 Black。
  - 网格中有偶数个 4-连通的单色前景对象（碎片）。碎片的颜色可能重复，但每两个碎片恰好能互补拼合成一个无孔矩形（一个碎片是矩形减去另一个碎片的形状）。
  - 互补的两个碎片颜色不同。每个碎片的 bbox 尺寸相同（即它们来自同一个矩形）。
  - 碎片在网格中的位置和朝向随机，但不重叠、不接触。

- `Rule`：
  - 第一层（配对）：找到所有碎片，按 bbox 尺寸分组。同一组内，两个碎片的像素图案互为补集（即一个碎片的 Black 位置恰好是另一个碎片的有色位置，反之亦然，在对齐 bbox 左上角后）。可能需要对其中一个碎片进行水平翻转才能匹配。将匹配的两个碎片配对。
  - 第二层（合成与排列）：对每一对碎片，将它们叠合成一个完整矩形。矩形中每个像素取来自有色碎片的颜色（两碎片不重叠，因此每个位置只有一种颜色）。将所有拼合后的矩形按其中面积较大的碎片颜色排序（按颜色名的字典序：Azure < Blue < Green < Grey < Magenta < Maroon < Orange < Red < Yellow），从左到右排列在输出网格中，矩形之间间隔1列 Black。输出网格高度等于最高矩形的高度，宽度为所有矩形宽度之和加上间隔列数。

- `Key insight`：碎片之间的"互补"关系是视觉上可察觉的——两个碎片的有色部分恰好在同一矩形框架内互不重叠地填满所有位置。解题者需要先发现形状互补的配对规则，再发现拼合后按颜色排列的排序规则，两层推理各自独立且缺一不可。
</new_puzzle>

- `description`：网格中的每条彩色线段充当"折叠轴"，将轴一侧的图案沿轴翻折到另一侧，翻折方向由轴端点的标记颜色决定。

- `Input structure`：
  - 背景为 Black。
  - 网格中有若干条直线段（水平或垂直，宽1像素，长度≥3），每条线段的主体用同一种颜色绘制（如 Grey），但其两个端点之一被涂成了另一种颜色（标记色，如 Red 或 Blue）。不同线段的标记色可能不同。
  - 线段的一侧（相对于线段方向的左/上侧或右/下侧）存在由某种前景色绘制的小图案（4-连通，面积2~8像素），另一侧为空（全 Black）。图案不接触线段。

- `Rule`：
  - 第一层：确定翻折方向。标记端点指示了"源侧"——图案所在的一侧就是标记端点所在的那一侧（对于水平线段，标记端点在左端则源侧为上方，标记端点在右端则源侧为下方；对于垂直线段，标记端点在上端则源侧为左方，标记端点在下端则源侧为右方）。
  - 第二层：将源侧的图案沿线段做镜像翻折到目标侧。翻折后的图案颜色变为标记端点的颜色。原始图案保留不变（即输出中线段两侧都有图案）。
  - 线段本身保持不变。若翻折后的图案超出网格边界，则裁剪掉越界部分。

- `Key insight`：线段端点的标记色同时编码了两个信息——翻折的方向（哪一侧是源）以及翻折后图案的新颜色。解题者需要先破解端点位置与翻折方向的映射关系，再发现颜色继承规则，两层发现互相独立。
</new_puzzle>

<new_puzzle>
- `description`：网格被分为若干分区，每个分区内有一个"时钟"图案；根据分区边界上共享边的相邻分区的时钟指针方向，旋转每个时钟的指针。

- `Input structure`：
  - 背景为 Black。
  - Azure 色的十字线将网格等分为 N×M 个矩形分区（十字线横贯整个网格宽度/高度，宽1像素）。
  - 每个分区内部包含一个"时钟"：以分区中心像素为圆心（Grey 色），向上、下、左、右四个正交方向中的恰好一个方向延伸出一条长2像素的"指针"（与中心同色 Grey）。指针方向在各分区中不同。

- `Rule`：
  - 第一层：对每个分区，统计其4-邻接的相邻分区（上/下/左/右共享一条分隔线边的分区）中，有多少个分区的时钟指针方向**指向本分区**（即邻居的指针朝向本分区的方向——例如左邻居的指针朝右，则算"指向本分区"）。设这个计数为 K（0 ≤ K ≤ 4）。
  - 第二层：将本分区的时钟指针顺时针旋转 K×90°。K=0 则不动，K=1 则转90°，K=2 则转180°，K=3 则转270°。旋转仅改变指针像素的位置，中心像素不动。
  - 分隔线和背景保持不变。

- `Key insight`：每个时钟的输出状态不由自身决定，而由邻居对它的"关注度"决定——有多少邻居的指针指向它，它就旋转多少步。解题者必须先发现"指向"这一跨分区的空间关系，再发现旋转量等于指向计数的数值对应规则。
</new_puzzle>

<new_puzzle>
- `description`：前景对象的外轮廓形状决定它内部填充的纹理类型，而对象的颜色决定纹理的颜色。

- `Input structure`：
  - 背景为 Black。
  - 网格中有若干互不接触的 4-连通单色前景对象，每个对象是实心的（无孔洞），面积≥9像素。
  - 对象的外轮廓（bbox 边界上的形状特征）可归为三类：（a）轮廓是完美矩形（bbox 内全填满）；（b）轮廓有且仅有一个凹口（bbox 边缘上缺少一个连续的矩形缺口）；（c）轮廓有两个或以上凹口。
  - 每个对象的颜色从 Red、Blue、Green、Yellow 中选取，可能重复。

- `Rule`：
  - 第一层（分类）：根据凹口数量将对象分为三类：
    - 0 个凹口（完美矩形）→ 纹理类型"棋盘格"。
    - 1 个凹口 → 纹理类型"水平条纹"。
    - 2 个及以上凹口 → 纹理类型"垂直条纹"。
  - 第二层（填充）：将对象内部按纹理类型重新着色：
    - 棋盘格：以对象 bbox 左上角为起点，行+列之和为偶数的位置保持对象颜色，奇数位置变为 Black。
    - 水平条纹：bbox 内从上往下，奇数行（第1、3、5…行）保持对象颜色，偶数行变为 Black。
    - 垂直条纹：bbox 内从左往右，奇数列（第1、3、5…列）保持对象颜色，偶数列变为 Black。
  - 只对对象实际占据的像素应用纹理，不扩展到 bbox 外。对象外的 Black 背景不变。

- `Key insight`：对象的几何轮廓特征（凹口数量）是一个隐含的分类标签，决定了完全不同的填充模式。解题者需要先从样例中归纳出"轮廓形状→纹理类型"的映射关系，再理解每种纹理的具体像素规则——前者是非显然的归纳，后者是视觉模式识别。
</new_puzzle>

<new_puzzle>
- `description`：在由墙壁围成的迷宫中，从每个彩色源点同时进行"洪水填充"式扩散，扩散速度由源点所在封闭房间的面积决定；当两种颜色的洪水相遇时，在交界处画出分界墙。

- `Input structure`：
  - 背景为 Black（表示通道/可通行区域）。
  - Grey 像素组成迷宫墙壁，将网格分割成若干连通的 Black 区域（房间+走廊）。
  - 恰好有2~4个彩色像素（颜色各不相同，如 Red、Blue、Green）分布在不同的封闭房间内，每个房间最多一个彩色像素。彩色像素所在的封闭房间大小（Black 像素数量）各不相同。

- `Rule`：
  - 第一层（确定扩散优先级）：计算每个彩色源点所在封闭房间的面积（Black 像素数，含源点自身）。面积越小，扩散优先级越高（小房间先填满后溢出到走廊）。
  - 第二层（模拟扩散）：按优先级从高到低依次处理每个源点。每个源点的颜色通过 4-连通扩散填满所有可达的 Black 像素，直到遇到 Grey 墙壁或已被其他颜色占据的像素为止。扩散后该颜色的区域成为后续源点的障碍。
  - 第三层（画分界线）：对于每个已着色像素，若其 4-邻居中存在不同颜色的已着色像素，则将这两个像素之间的位置关系标记出来——具体地，将较低优先级（后扩散）一方的该像素改为 Maroon，形成分界线。
  - 墙壁保持 Grey 不变。

- `Key insight`：扩散的先后顺序不是随机的，而是由源点所在房间的大小（一个需要视觉估算的量）决定的——小房间的颜色"更急迫"，先占领走廊。解题者需要先发现面积→优先级的排序规则，再理解顺序扩散的填充机制，最后发现分界线的标记规则。三层推理层层递进。
</new_puzzle>
