- `description`：根据框架内种子像素的位置模式，从多个候选模板中选出匹配模板，并用种子颜色将模板按比例填入框架内部。
- `Input structure`：背景为 orange。网格上方有若干小型彩色模板掩码（每个模板由不同颜色绘制，形状各异，尺寸为 3x3 至 5x5）。下方有一个较大的 grey 矩形框架，框架内部尺寸是某个模板 bbox 的整数倍。框架内部散落着少量 red 种子像素，这些种子像素的位置恰好对应某个模板被整数倍放大后的部分像素位置。
- `Rule`：
  - 遍历上方每个模板，将其按整数比例（框架内部尺寸 / 模板 bbox 尺寸）放大为块状掩码。
  - 找到唯一一个模板，使得放大后的掩码覆盖了框架内所有已有 red 种子像素的位置。
  - 将框架内部清空为 orange 背景，然后用 red 颜色绘制该匹配模板放大后的完整掩码。
  - 保留框架本身和所有上方模板不变。
- `Key insight`：种子像素不是随机散布的装饰，它们是某个上方模板的局部放大采样；解题者需要先识别比例关系，再通过种子位置反向匹配唯一模板，最后补全整个放大掩码。

- `description`：将每个前景对象的轮廓缺口方向与颜色图例匹配，用图例指定的填充色填满该对象内部的封闭孔洞。
- `Input structure`：背景为 black。网格边缘有一个两列颜色图例：左列是四种不同方向标记色（分别代表上、右、下、左），右列是对应的填充色。网格中散布若干 grey 的 4 连通前景对象，每个对象是一个近似矩形但在上、下、左、右某一侧有一个明显的单像素宽缺口（开口），对象内部有一个或多个被 grey 像素包围的背景色孔洞。
- `Rule`：
  - 对每个 grey 对象，找到其 bbox 边界上唯一的缺口方向（上/下/左/右）。
  - 在图例中，缺口方向与左列颜色的行位置对应：第一行对应上方缺口，第二行对应右方缺口，第三行对应下方缺口，第四行对应左方缺口。
  - 用该行右列的填充色填充该对象内部所有封闭的背景色孔洞。
  - 保留 grey 对象像素、图例和背景不变。
- `Key insight`：缺口方向是一个需要归纳的隐含属性，它不直接给出颜色映射，而是通过图例的行序间接编码；解题者必须先发现缺口方向与图例行的对应规则，再用右列颜色填孔。
</new_puzzle>

- `description`：根据每个封闭区域内标记像素的数量，从共享的颜色调色板条中选取对应位置的颜色，重新着色该区域的边界框架。
- `Input structure`：背景为 black。网格底部有一条水平调色板条，由 N 个不同颜色的单像素组成（从左到右排列）。网格中有若干个由 grey 像素构成的一像素厚矩形框架，框架内部为背景色，但每个框架内部散落着若干 azure 标记像素（数量从 1 到 N 不等，且各框架内标记数互不相同）。
- `Rule`：
  - 数每个 grey 框架内部的 azure 标记像素数量 k。
  - 将该框架的所有 grey 像素重新着色为调色板条中从左数第 k 个颜色。
  - 擦除框架内部的 azure 标记像素为背景色。
  - 保留调色板条和背景不变。
- `Key insight`：标记像素的数量不是面积或形状属性，而是一个离散计数值，它作为调色板的索引键；框架的原始颜色（grey）是占位符，最终颜色完全由内部标记数决定。
</new_puzzle>

<new_puzzle>
- `description`：在分隔线两侧的面板中，通过颜色对称性识别互补对，将上面板的前景掩码形状与下面板的前景掩码形状叠加合并到输出中。
- `Input structure`：背景为 orange。一条 green 的满宽分隔行将网格分为上下两个等高区域。每个区域内有若干单色前景对象。上区域的对象颜色集合与下区域的对象颜色集合完全相同，但每种颜色在上下区域中的形状不同。
- `Rule`：
  - 对每种前景颜色 C，在上区域找到 C 的对象掩码 M_top，在下区域找到 C 的对象掩码 M_bottom。
  - 创建与单个区域等大的背景画布。
  - 对每种颜色 C，将 M_top 和 M_bottom 的像素位置取并集（使用各自在所属区域内的相对坐标），用颜色 C 绘制到输出画布上。
  - 后处理的颜色覆盖先处理的颜色；处理顺序为按颜色在上区域中面积从大到小。
- `Key insight`：分隔线两侧不是独立的场景，而是同一对象的两个互补视图；相同颜色跨面板的形状合并才是真正的变换目标，而非简单的面板选择或复制。
</new_puzzle>

<new_puzzle>
- `description`：识别嵌套框架的层级关系，将最内层框架的颜色沿层级向外传播，同时将每层框架的原始颜色记录为该层内角的单像素标记。
- `Input structure`：背景为 black。网格中有 3 到 5 层嵌套的一像素厚矩形框架，每层框架颜色互不相同（例如从外到内依次为 red、blue、green、yellow）。最内层框架内部为背景色。
- `Rule`：
  - 从最内层框架开始，记其颜色为 C_inner。
  - 将最内层框架的四个内角像素保留为该层原始颜色，其余框架像素重新着色为背景色。
  - 将次内层框架的所有像素重新着色为 C_inner，但在次内层的四个内角像素保留次内层的原始颜色。
  - 以此类推向外传播：每层框架的主体被重新着色为其内部下一层的原始颜色，但四个内角保留该层自身的原始颜色。
  - 最外层框架被着色为第二层的原始颜色，四个内角保留最外层自身颜色。
- `Key insight`：变换不是简单的颜色替换或排序，而是沿嵌套层级进行颜色冒泡传播；每层的内角标记像素记录了该层被覆盖前的原始身份，形成一个颜色层级证据链。
</new_puzzle>

<new_puzzle>
- `description`：将网格中散落的同色像素对通过直线段连接，连接方向由像素对之间的唯一共享行或列决定，然后根据线段交叉的层叠顺序确定最终可见颜色。
- `Input structure`：背景为 orange。网格中散布着若干颜色的前景像素，每种颜色恰好出现两个像素。同色的两个像素要么共享同一行，要么共享同一列（不会在对角线上）。不同颜色的像素对可能产生交叉。
- `Rule`：
  - 对每种颜色，在其两个像素之间（含端点）沿共享的行或列绘制一条单像素宽的直线段。
  - 先绘制水平线段（即共享行的颜色对），再绘制垂直线段（即共享列的颜色对）。
  - 在同类方向内，按线段长度从长到短的顺序绘制（长的先画，短的后画覆盖）。
  - 交叉处后绘制的线段覆盖先绘制的线段。
- `Key insight`：每种颜色的两个像素看似独立的散点，实际是待连接线段的端点；解题者需要先归纳出同色配对连线的规则，再发现层叠顺序的双重排序机制（方向优先加长度次之），才能确定交叉处的最终颜色。
</new_puzzle>
