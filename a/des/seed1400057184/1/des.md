# 第一步：分析与思考

## 参考题基础操作盘点

从20道参考题中可以提炼出以下基础操作类型：

1. **层叠/遮挡重建**（#1）：从可见片段反推完整图层的叠放顺序。
2. **颜色层独立变换**（#2）：按颜色拆层，每层独立旋转/变换后合并。
3. **方向编码与投射**（#3, #5, #9）：形状的不对称性编码方向，沿方向执行操作。
4. **计数转视觉编码**（#4）：将散落对象的数量统计转化为视觉表示。
5. **路径模拟/粒子运动**（#5, #9）：按规则在网格上移动实体，逐步着色或消耗标记。
6. **洪泛填充与遮挡**（#6）：流体式传播，带障碍物阻挡。
7. **角色互换/对偶**（#7）：两类对象的位置角色互换。
8. **类比推理**（#8）：从一对示例推断变换规则，应用到新对象。
9. **形状分类导致差异行为**（#16, #19）：根据几何属性分类，不同类别执行不同操作。
10. **图例/映射表**（#13, #17）：网格内嵌入映射关系表，指导变换。
11. **粗粒度抽象**（#20）：将精细网格压缩为粗粒度表示。
12. **空间移动/对齐**（#15, #18）：按条件将对象移动到边界或指定位置。
13. **跨区域传递**（#10）：不同区域之间的资源/属性迁移。
14. **缺陷检测与标记**（#12, #19）：识别异常点并做标记。
15. **裁剪/定位**（#14）：通过特殊标记确定感兴趣区域并裁剪。

## 非显而易见的串联方式与信息编码思考

- **"缺陷即指令"**：缺失的像素（如环上的缺口、边框上的断裂点）不仅是缺陷标志，更可以编码方向、数量甚至目标颜色。参考题 #14 用缺失的交叉点做定位，但缺陷还可以直接驱动运动方向。
- **"形状的语义值"**：一个图形的形状可能代表一个抽象概念（如数字、字母），而这个概念的"值"（而非形状的几何属性如面积、周长）才是变换的依据。这在参考题中完全没有出现。
- **"空间位置到排序的映射"**：对象在网格中的绝对坐标不仅是位置信息，还可以隐含优先级或执行顺序——比如行号决定"先后"、列号决定"层级"。
- **"坐标的数学属性作为分类信号"**：像素坐标的奇偶性、模运算结果等可以成为分类依据，将同一网格的像素分入不同组别进行不同处理。
- **"投票/多数派机制"**：多个分散的小对象通过某种"投票"机制共同决定一个大结构的属性——这是从局部到全局的信息汇聚。
- **"盖章/投影"**：外部对象按空间关系被"投影"或"盖章"到一个中心结构上，位置和朝向由相对空间关系决定。
- **"维度折叠"**：一个高维（大尺寸）网格通过某种对称操作折叠为低维（小尺寸）网格，折叠规则隐含在结构中。

- `description`：网格中散布着由同一颜色像素组成的嵌套矩形环，每层环上有一个单像素缺口；根据缺口所在的边（上/下/左/右），将该层环向缺口方向平移一个像素，最内层环保持不动作为锚点。

  - 背景色为 black。
  - 网格中央有一组同心嵌套的矩形环（2到5层），每层环颜色不同（可用 red、blue、green、yellow、orange）。

  - 网格尺寸足够大，确保最外层环平移后仍在网格内。
- `Rule`：
  - 最内层环保持原位不动，作为锚点。
  - 从内向外逐层处理每一层环：确定该层环缺口所在的边——若缺口在上边，该层整体向上平移 1 像素；缺口在下边则向下平移 1；缺口在左边则向左平移 1；缺口在右边则向右平移 1。
  - 平移为刚体平移，环的形状（包含缺口）完全保持不变。
  - 各层环平移独立进行；若平移后外层环像素与内层环像素位置重合，外层环像素覆盖内层像素（外层绘制在上层）。
  - 输出网格尺寸与输入相同，背景为 black。
- `Key insight`：解题者需要发现每层环上那个不起眼的单像素缺口不仅仅是"破损"——它编码了该层环的移动方向。缺口在哪条边上，环就向哪个方向移动。最内层不动是隐含的锚定规则。这种"缺陷即方向指令"的机制需要仔细对比输入输出中环的微小位置偏移才能归纳出来。
</new_puzzle>

<new_puzzle>

  - 背景色为 black。
  - 网格中有若干条贯穿整个网格的直线（水平或垂直），颜色为 grey，宽度 1 像素。这些灰线将网格分割为若干个矩形区域。灰线可以构成不规则网格（行间距和列间距不必相等）。
  - 每个矩形区域内恰好有一个非 black、非 grey 的彩色像素，称为"投票像素"。投票像素颜色可以是 red、blue、green、yellow 中的某种。
  - 投票像素在区域内的位置任意。
- `Rule`：
  - 对每条 grey 水平线：收集该线正上方所有区域的投票像素颜色和正下方所有区域的投票像素颜色，将它们合在一起统计出现次数最多的颜色（多数派）。将这条水平线的所有像素染成该多数派颜色。若存在两种颜色票数并列最高，则该线保持 grey 不变。
  - 对每条 grey 垂直线：同理收集左侧和右侧所有区域的投票像素，找多数派颜色并将该垂直线染色。并列则保持 grey。
  - 水平线和垂直线的交叉像素：若该交叉点所在的水平线和垂直线最终颜色不同，则交叉点取水平线的颜色（水平优先）。若其中一条保持 grey 而另一条被染色，则取被染色的颜色。
  - 投票像素本身和 black 背景保持不变。
- `Key insight`：解题者需要意识到灰线不是静态装饰，而是"待着色的边界"。着色的依据来自线两侧所有区域中散落像素的颜色"投票"——这是一种空间统计汇聚机制。容易误判为像素位置或距离相关的规则，但实际上只有颜色的计数决定结果。
</new_puzzle>

<new_puzzle>
- `description`：网格中散布着若干条由彩色像素组成的折线路径（带转角的连续像素链），每条路径被"拉直"为一条水平线段放置在输出网格中，线段长度等于原路径像素总数，放置行号等于路径起点的行号。
- `Input structure`：
  - 背景色为 black。
  - 网格中有若干条互不相交的折线路径。每条路径由同一种颜色的像素组成（不同路径颜色不同，可用 blue、red、green、orange、magenta 等）。
  - 每条路径是 4-连通像素链，仅沿水平或垂直方向延伸（由交替的水平段和垂直段组成），无分叉，恰好有两个端点（度为 1 的像素）。
  - 路径像素总数不超过 20。
  - 每条路径的"起点"定义为两个端点中行号较小的那个；若行号相同则取列号较小的端点。
- `Rule`：
  - 输出网格与输入同尺寸，背景为 black。
  - 对每条路径：统计其像素总数 L。确定起点行号 R。
  - 在输出的第 R 行，从第 0 列开始，连续绘制 L 个该路径颜色的像素，形成一条水平线段。
  - 若多条路径的起点行号相同（极少情况），则按路径长度从长到短依次排列在同一行，从第 0 列开始拼接（长路径在前，短路径紧跟其后，中间无间隔）。
  - 其余位置保持 black。
- `Key insight`：核心变换是"折线展开为等长直线"——路径总长度守恒但空间形态完全改变。解题者必须注意到每条输出线段的长度等于对应颜色折线路径的像素数（而非路径的首尾直线距离），并且放置行号来自起点坐标。"长度守恒"和"起点行号映射"是两个需要同时发现的规则要素。
</new_puzzle>

<new_puzzle>
- `description`：网格中有若干彩色区域，每个区域的形状是一个标准七段数码管风格的数字（1-9）；输出将每个数字区域替换为该数字"值"个数的像素点，沿水平方向排列在原区域重心位置。
- `Input structure`：
  - 背景色为 black。
  - 网格上有若干互不相连的单色连通区域（4-连通），每个区域颜色不同（可用 red、blue、green、yellow、orange、magenta、azure）。
  - 每个区域的形状是 3 列 5 行包围盒内的标准七段数码管数字（1-9）。数字绘制方式：包围盒内每一行最多 3 个像素。数字 "1" 为右列 5 个像素；"2" 为顶行3个 + 第2行右1个 + 中行3个 + 第4行左1个 + 底行3个；"3" 为顶行3个 + 第2行右1个 + 中行3个 + 第4行右1个 + 底行3个；其余数字类似七段管编码方式。
  - 数字不旋转不翻转。区域之间至少间隔 2 个像素。
- `Rule`：
  - 输出网格与输入同尺寸，背景为 black。
  - 对每个数字区域：识别其形状所代表的数字值 N（1到9）。
  - 计算该区域所有像素的行坐标平均值（向下取整）得到 R，列坐标平均值（向下取整）得到 C。
  - 在输出的第 R 行，以 C 为中心水平放置 N 个该区域颜色的像素：像素从列 C - floor((N-1)/2) 到列 C - floor((N-1)/2) + N - 1。
  - 若像素超出网格边界则裁剪，仅保留网格内部分。
  - 原始数字区域不保留在输出中。
- `Key insight`：解题者需要先"认读"出每个彩色区域是一个数字字符，然后理解该数字的"语义值"（而非像素数量或几何尺寸）决定了输出中该颜色的点数。极易走入歧途去数像素、算面积或分析形状对称性——但正确路径是直接把形状当作数字来"阅读"。这是一种罕见的"视觉语义"驱动变换。
</new_puzzle>

  - 网格中央有一个较大的实心 grey 矩形（"画布"），尺寸约 10x10 到 18x18。
  - 画布外散布若干个小的彩色图案，每个图案由多种非 black、非 grey 颜色的像素组成，占据 2x2 到 4x4 的包围盒。图案之间形状各异。
  - 每个图案与画布不接触，间距 1 到 3 个像素。
  - 每个图案唯一地离画布的某一侧（上、下、左、右）最近——即该图案包围盒到画布对应边的最短距离严格小于到其他三条边的距离。
- `Rule`：
  - 对每个画布外的小图案：
    (1) 确定它离画布哪一侧最近（上侧、下侧、左侧、右侧）。
    (2) 计算图案中心沿画布该侧边的投影坐标：若离上/下侧最近，投影到该边上得到列坐标；若离左/右侧最近，投影到该边上得到行坐标。
    (3) 将图案盖章到画布内部：图案紧贴该侧边的内壁放置，其中心对齐投影坐标。
    (4) 盖章旋转规则——图案从上侧进入不旋转；从右侧进入逆时针旋转 90 度；从下侧进入旋转 180 度；从左侧进入顺时针旋转 90 度。旋转后图案的"顶部"始终朝向画布内部。
  - 盖章后图案的像素覆盖画布上对应位置的 grey 像素。
  - 画布外原始图案的位置变为 black（清除）。
  - 各图案的盖章位置保证不会互相重叠。
- `Key insight`：解题者需要同时发现两层映射关系：(1) 图案离画布哪一侧最近决定了它进入画布的方向和旋转角度；(2) 图案沿该边的投影位置决定了盖章的精确坐标。整体效果像是从四个方向将印章按压到画布上。关键难点在于旋转规则——必须对比多个样例中不同方向图案的旋转方式才能归纳出一致的朝向逻辑。
</new_puzzle>

<new_puzzle>
- `description`：网格中有若干对同色的 L 形标记，每对标记的两个直角顶点确定一个矩形区域的对角；该矩形用一种由标记颜色和图例共同决定的填充色填充，但 L 形标记的两臂方向还决定了填充的纹理方向（水平条纹或垂直条纹）。
- `Input structure`：
  - 背景色为 black。
  - 网格右下角有一个小型图例区域（约 4 行 2 列），每行左列为一种标记颜色，右列为该颜色对应的填充颜色。例如：red 对应 orange、blue 对应 azure、green 对应 yellow。
  - 网格中散布着若干 L 形标记。每个 L 形由 3 个像素组成：一个直角顶点像素和从该顶点出发的两条各长 1 像素的臂（共 3 像素，呈直角形状）。
  - 同一颜色恰好有两个 L 形标记，构成一对。
  - 每个 L 形的直角顶点是该标记的"定位点"。一对同色标记的两个定位点确定一个轴对齐矩形的对角线两端（一个在左上方向，一个在右下方向，或一个在右上、一个在左下）。
- `Rule`：
  - 对每对同色 L 形标记：
    (1) 找到两个定位点（直角顶点），确定它们作为对角线的矩形区域。
    (2) 从图例中查找该颜色对应的填充色。
    (3) 判断该对标记中两个 L 形的臂的朝向——若两个 L 形的臂都在水平和垂直方向展开且水平臂更长（即 L 的横臂水平），则矩形内用填充色画水平条纹（每隔一行填充一行）；若两个 L 形的纵臂更突出（L 的竖臂垂直方向更长），则矩形内用填充色画垂直条纹（每隔一列填充一列）。由于每个 L 形只有 3 像素，两臂等长，因此方向判定依据为：两个 L 形的开口方向一致时看开口朝向——若开口水平朝向（朝左或朝右），填充垂直条纹；若开口垂直朝向（朝上或朝下），填充水平条纹。
    (4) 条纹从矩形的第一行/列开始，间隔一行/列绘制。
  - 图例区域和 L 形标记本身保持不变。
  - 后处理的填充区域若与先处理的重叠，后处理覆盖先处理（处理顺序按图例自上而下）。
- `Key insight`：解题者不仅要发现 L 形标记配对定义矩形区域（类似参考题 #13），更要发现 L 形的朝向编码了填充纹理的方向——这是一个额外的信息维度。开口方向与条纹方向的垂直关系是非直觉的，需要多个样例交叉验证才能发现。
</new_puzzle>

<new_puzzle>
- `description`：网格中有一个由彩色像素组成的连通图形；将该图形视为一个"模具"，对其执行"膨胀"操作（向外扩展一层像素），但膨胀的颜色不是原图形的颜色，而是由膨胀方向决定的：向上膨胀用一种颜色，向下用另一种，向左和向右各用一种。方向-颜色映射关系由网格角落的一个小指示器定义。
- `Input structure`：
  - 背景色为 black。
  - 网格中有一个由单一颜色（如 blue）组成的连通图形（4-连通），形状不规则，可以是 L 形、T 形、Z 形等。
  - 网格左上角有一个 3x3 的方向-颜色指示器：中心像素与原图形同色（如 blue），上方像素、下方像素、左方像素、右方像素各为一种不同颜色（如上 red、下 green、左 yellow、右 orange），四个对角像素为 black。
  - 原图形与指示器之间有足够间距，不相邻。
- `Rule`：
  - 对原图形的每个像素，检查其上、下、左、右四个邻居：
    - 若上方邻居为 black 且不属于原图形，则该位置在输出中被染成指示器中"上方"对应的颜色。
    - 若下方邻居为 black 且不属于原图形，则染成"下方"对应颜色。
    - 左方、右方类似。
  - 若一个 black 像素同时是原图形某像素的上方邻居和另一个原图形像素的左方邻居（即处于凹角外侧），则该位置使用先遇到的方向的颜色（优先级：上 > 右 > 下 > 左）。
  - 原图形本身的像素保持原色不变。
  - 指示器保持不变。
  - 只膨胀一层（仅扩展原图形的直接邻居）。
- `Key insight`：解题者需要发现输出中原图形周围新增了一圈彩色像素——这是一种"方向性膨胀"。关键在于膨胀颜色不是统一的，而是取决于"从原图形的哪个方向扩展出来"。角落的 3x3 指示器是解码方向-颜色映射的钥匙——中心色匹配原图形，四个正交方向的颜色对应膨胀方向。这一机制在仅看原图形和输出时并不明显，必须将指示器和膨胀结果关联起来才能破解。
</new_puzzle>
