# 第一步：分析与思考

## 参考题基础操作梳理

参考题中涉及的基础操作可以归纳为以下几类：

1. **空间选择与提取**：根据某种属性（颜色对的行列乘积、结构封闭性、间距最小值）从网格中定位目标区域。
2. **几何变换**：缩放、反射、旋转、平移——由锚点大小或象限位置编码变换参数。
3. **冗余与共识**：多份副本之间取多数投票恢复原型，差异部分标记。
4. **物理模拟**：重力、滑动、碰撞等物理直觉驱动的像素运动。
5. **循环与序列**：尺寸循环、时间序列外推、有序递进中的标记迁移。
6. **拓扑与连通性**：孔洞检测、路径连通性、结构封闭性判断。
7. **方向编码**：小对象的朝向、位置、形状编码全局操作指令。
8. **间接寻址**：颜色作为查找键，一个对象的属性指向另一个对象。

## 非显而易见的串联可能性

- **拓扑特征作为计算输入**：一个连通分量的孔洞数量、凹角数量、或周长与面积的关系可以编码一个离散数值，该数值再驱动后续的空间操作（如平移距离、重复次数）。这些特征在视觉上可通过仔细观察辨认。
- **对象之间的空间关系编码变换指令**：不是对象自身的属性，而是对象之间的相对距离、角度、排列关系等编码出变换参数。信息来自"关系"而非"实体"。
- **前景与背景的角色互换**：背景区域的形状本身携带信息（负空间），而前景只是划定负空间的边界。解题者的注意力通常聚焦在前景上，因此负空间作为信息载体具有天然的隐蔽性。
- **颜色的非分类用途**：颜色不表示类别，而表示层叠顺序、距离、或某种优先级，决定遮挡关系或操作先后。
- **对称性的破缺点**：一个几乎对称的结构中，不对称的那几个像素携带关键信息，决定输出。解题者必须先识别出"几乎对称"，再定位"破缺"。
- **跨对象的排序与比较**：单个对象的属性（面积、周长、高度等）本身无意义，只有在所有对象间排序后的相对名次才驱动变换。

## 创新方向

我将避免对参考题做简单的维度替换，而是追求全新的认知路径——即解题者从样例中归纳规则时需要经历的思维过程与任何参考题都不同。核心设计原则：

1. **负空间读取**：关键信息不在前景对象上，而在前景对象围合出的背景缝隙的形状中。
2. **视线投射与遮挡**：从某个标记出发的"视线"被最近的障碍截断，截断距离或被截断对象的属性决定输出。
3. **跨对象排名驱动变换**：变换参数不来自对象自身，而来自其在全局排名中的位次。
4. **计数到结构的转化**：内部标记的数量转化为边界上的结构变化（缺口、突起），信息从内部"转移"到外部。
5. **独立速度外推**：多个运动体各自有不同的运动参数，需要分别识别并外推。

  - 在网格的右下角区域，有一组"图例"：若干小型示意图（3×3或4×4的小方格内）展示了每种缝隙形状（用 grey 绘制），每个示意图右侧紧邻一个单像素色点标注对应的填充颜色。图例区域与主区域之间有明显间隔。

  - 将每个缝隙区域的形状与图例中的形状样本进行匹配（匹配时允许90度旋转和镜像翻转）。
  - 用图例中该形状对应的颜色填充整个缝隙区域。
  - 图例区域本身在输出中保持不变。

- `Key insight`：解题者的注意力自然会集中在彩色矩形上，但真正的信息载体是矩形之间的"负空间"——黑色缝隙的形状。需要识别出缝隙是一种可分类的几何形状，然后通过图例建立形状到颜色的映射。前景对象是"背景"，背景缝隙才是"前景"。

- `description`：根据每个封闭框内部标记点的数量，在该框的边界上按固定方向顺序打开相应数量的缺口。

- `Input structure`：
  - 背景色为 black。
  - 网格中有若干用 blue 绘制的封闭矩形框（框线宽度为1像素，框内为 black），框与框之间不重叠、不相邻，每个框的宽度和高度均不小于5像素。

- `Rule`：
  - 对每个封闭矩形框，计算其内部 red 标记点的数量 N。
  - 在该矩形框的边界上打开 N 个缺口（将1个框线像素替换为 black）。缺口按以下顺序轮流分配在四条边上：第1个缺口在上边的水平中点位置，第2个在右边的垂直中点位置，第3个在下边的水平中点位置，第4个在左边的垂直中点位置。
  - 中点位置的计算：对于长度为 L 的边（不含两端角点），中点位于第 floor(L/2) 个位置（从该边起始端数起，0-based）。
  - 移除框内部的所有 red 标记点（替换为 black）。
  - 输出网格尺寸与输入相同。

- `Key insight`：输入中可见的 red 标记点在输出中消失，取而代之的是框边界上出现的缺口。解题者需要将消失的点数量与出现的缺口数量建立对应关系，发现信息从框内部"转移"到了框边界上。缺口的分配顺序（上→右→下→左的固定轮次）需要从多个样例的对比中归纳。
</new_puzzle>

  - 输出网格尺寸与输入相同。

</new_puzzle>

- `description`：每个底座方块通过其边缘突出的单像素指针确定"视线"方向，捕获该方向上最近的彩色目标的颜色并填入底座中心。

- `Input structure`：
  - 背景色为 black。
  - 网格中有若干"底座"：每个底座是一个 3×3 的 grey 实心方块。
  - 每个底座的四条边中恰好有一条边的中心像素外侧（紧邻底座外部）有一个 maroon 单像素"指针"。指针的位置决定了方向：指针在底座上方表示指向上，在右方表示指向右，在下方表示指向下，在左方表示指向左。
  - 网格中还散布着若干"目标"：每个目标是一个 1×1 的彩色像素（使用 red、blue、green、yellow、orange 等颜色，每个目标颜色各不相同），目标不与任何底座或指针相邻。
  - 底座之间互不相邻，且底座和目标之间有足够间距。

- `Rule`：
  - 对每个底座，根据其 maroon 指针的位置确定"视线"方向（上/下/左/右）。
  - 从指针像素出发，沿视线方向逐像素扫描，找到该方向上第一个遇到的彩色目标像素（忽略 black 和 grey 像素）。
  - 将该目标像素的颜色填入底座的中心像素（替换原来的 grey）。底座其余8个 grey 像素不变。
  - 指针（maroon 像素）在输出中保持不变。
  - 如果某个方向上扫描到网格边界仍未遇到目标像素，则底座中心保持 grey 不变。

- `Key insight`：3×3 灰色方块在视觉上很显眼，但其边缘那个不起眼的 maroon 单像素突起容易被忽略。解题者需要发现指针的存在，理解指针方向的含义，然后推断出"视线投射捕获最近目标颜色"的机制。核心认知挑战在于：首先注意到指针的存在，然后将指针方向、扫描过程、颜色传递三者联系起来。
</new_puzzle>

- `description`：在包含多行同色像素轨迹的网格中，识别每种颜色各自的水平运动速度，将所有轨迹外推到底部空白行。

- `Input structure`：
  - 背景色为 black。
  - 网格有 R 行（R ≥ 6），其中前 R-2 行每行包含若干单像素色点，最后2行全为 black（空白行）。
  - 每种颜色（如 red、blue、green、yellow）在前 R-2 行中每行恰好出现一次（一个像素），其列位置逐行发生固定的水平偏移。例如 red 在第1行第3列、第2行第5列、第3行第7列……表示 red 的水平速度为每行右移2列。
  - 不同颜色的速度不同，速度可以为正（向右）、负（向左）或零（不动），且速度的绝对值不超过3。
  - 同一行中不同颜色的像素不会重叠。

- `Rule`：
  - 对每种颜色，从其在已有行中的列位置序列中计算相邻行之间的列偏移量（该偏移量在所有相邻行之间相同，即为常数速度）。
  - 将每种颜色的色点按照其速度，外推到最后2个空白行中对应的列位置，并绘制该颜色的单像素。
  - 如果外推位置超出网格列范围（<0 或 ≥ 网格宽度），则该颜色在该行不绘制。
  - 已有行中的像素保持不变。

- `Key insight`：这道题模拟了多个以不同速度水平运动的粒子。解题者需要识别出每种颜色各自有独立且恒定的"速度"（列偏移常量），并发现底部空行是需要填写的"下两帧"预测。核心难点在于发现速度可以是负数（向左移动），且不同颜色速度不同，必须分别独立计算。
</new_puzzle>

- `description`：将每个前景分量按面积在全局的排名作为扩展层数，为其绘制同色的外围边框。

- `Input structure`：
  - 背景色为 black。
  - 网格中有若干互不接触的单色前景分量（每个分量颜色各不相同），形状为凸多边形或简单矩形，面积各不相同。
  - 分量之间留有足够的间距（至少6个 black 像素），确保扩展后不会超出网格边界。
  - 前景分量数量为3到5个。

- `Rule`：
  - 将所有前景分量按面积从小到大排序，排名从1开始（面积最小的排名为1）。
  - 对排名为 K 的分量，在其周围绘制 K 层同色边框。每层边框定义为：将当前区域（原始分量加上已有边框）的每个像素的8-邻域中属于 black 的像素全部着色为该分量的颜色，重复此过程 K 次。
  - 扩展不得超出网格边界；超出部分忽略。
  - 如果两个分量扩展后的区域发生重叠（仅在极端情况下），重叠像素归属于扩展层数更多的（即排名更高的）分量。

- `Key insight`：解题者需要在多个样例中注意到：扩展的边框厚度不是固定值，也不是由颜色或位置决定的，而是由该分量的面积在所有分量中的相对排名决定的。这要求跨对象比较（对面积进行全局排序），而非仅分析单个对象的属性。面积最小的分量反而边框最薄，面积最大的边框最厚——这种"排名驱动"的变换是核心的隐蔽规则。
</new_puzzle>

- `description`：在近似对称的图案中找到对称性被破坏的像素，将这些像素的颜色替换为其对称位置的颜色以恢复完美对称。

- `Input structure`：
  - 背景色为 black。
  - 网格中有一个大型的彩色图案，占据网格的中央区域。该图案使用3-5种非黑色颜色绘制。
  - 该图案关于某一条对称轴近似对称（对称轴为水平线或垂直线，穿过图案的中心）。对称轴的方向在不同的样例中可能不同。
  - "近似对称"意味着：图案中绝大多数像素与其关于对称轴的镜像位置具有相同颜色，但有少数几个像素（2-5个）的颜色与其镜像位置不同。
  - 被破坏对称性的像素在对称轴的两侧都可能出现。

- `Rule`：
  - 确定图案的对称轴（水平或垂直），对称轴位于图案包围矩形的中心行或中心列。
  - 找到所有"不对称像素对"：即位置 P 和其镜像位置 P' 的颜色不同。
  - 对于每一对不对称像素，确定哪一侧是"正确"的：正确的一侧是该像素与其上下（或左右，取决于对称轴方向）相邻像素颜色一致的那一侧（即融入局部环境的一侧）。
  - 将"错误"一侧的像素颜色替换为"正确"一侧的像素颜色，从而恢复完美对称。

- `Key insight`：解题者首先需要识别出图案具有近似对称性（但不是完美对称），然后定位破缺点。关键的深层洞见是如何判断对称对中哪一侧是"原版"、哪一侧是"损坏版"——判据是局部一致性：与周围像素颜色协调的一侧是正确的，孤立的异色像素是错误的。这融合了对称性分析和局部一致性推理两层逻辑。
</new_puzzle>

- `description`：将散落在网格中的同色像素对用"管道"连接，管道转弯处颜色变为该对颜色对应的"转角色"。

- `Input structure`：
  - 背景色为 black。
  - 网格中散布着若干彩色单像素点，每种颜色恰好出现2个（即形成若干颜色配对）。可用颜色如 red、blue、green、yellow 等，共3-5对。
  - 同色像素对之间在水平和垂直方向上都不共线（即连接它们必须至少转弯一次）。
  - 不同颜色的像素对之间有足够间距。
  - 网格底部有一行"转角色对照表"：每种在主区域出现的颜色旁边紧邻一个不同颜色的单像素，表示该颜色的管道在转弯处应使用的颜色。例如 red 旁边是 orange，表示 red 管道的转弯处用 orange。

- `Rule`：
  - 对每对同色像素点（A 和 B），用 L 形路径连接：从 A 出发先沿水平方向移动到 B 的列位置，再沿垂直方向移动到 B 的行位置（先水平后垂直）。
  - L 形路径上的直线段部分（水平段和垂直段）使用该配对的原始颜色绘制。
  - L 形路径的转弯处（恰好1个像素，即水平段与垂直段相交的角点）使用转角色对照表中对应的颜色绘制。
  - 两个端点像素（A 和 B）保持原始颜色不变。
  - 转角色对照表在输出中保持不变。

- `Key insight`：解题者需要同时发现三层规则：(1) 同色像素成对、需要用 L 形路径连接；(2) 连接方向固定为先水平后垂直；(3) 转弯处使用的不是同一颜色而是对照表中的另一种颜色。第三层规则是最难发现的，因为转弯处的异色像素容易被视为噪声而非规律。
</new_puzzle>
