# 第一步：分析与思考

## 参考题中涉及的基础操作梳理

从20道参考题中可以提取以下基础操作类别：

1. **路径/连接**：在网格中寻路、连接同色组件（如参考1的L型路径连接，参考15的图论最短路径）。
2. **压缩/收缩**：将散落的像素向锚点聚拢（参考2的射线压缩）。
3. **区域划分与填充**：用边界将空间分区，按规则分配内容（参考3的flood-fill内外区域选择）。
4. **几何补全**：补画缺失的几何元素（参考4的对角线连接，参考16的L变三角形）。
5. **图层叠加/合并**：将多个对象视为同一模板的不同图层进行合并（参考5的矩形marker合并）。
6. **编码/解码控制信息**：网格中的特殊元素编码变换参数（参考7的红色标记编码滚动量，参考14的标记指示裁切方向）。
7. **序列/颜色重排**：在固定几何结构上重排颜色序列（参考9的路径颜色反转，参考13的环形颜色旋转）。
8. **模式替换/切换**：识别模式原型并进行交换（参考11的sprite原型互换）。
9. **计数与统计**：统计对象数量并以视觉方式记录（参考18的计数填点）。
10. **归一化与复制**：标准化对象尺寸并复制放置（参考19的5x5归一化并双重印章）。

## 非显而易见的串联方式思考

- **拓扑属性作为隐藏指令**：一个对象的拓扑特征（如孔洞数量、连通域数量、凸凹性）可以不直觉地编码某个变换的参数。例如一个形状有2个孔就意味着执行2次某种操作——这种信息隐藏在几何结构里，肉眼可见但需要思考才能关联。

- **视觉对称性缺陷作为信息载体**：一个"看起来对称"的图案中故意打破对称性的那几个像素，不是噪声而是指令。缺陷的位置和颜色编码了变换类型。

- **负空间（背景形状）承载意义**：前景物体围成的背景区域的形状本身是有意义的——输出不是变换前景，而是提取并操作负空间。

- **多步间接因果链**：A物体的某个属性决定了B物体的变换方式，而B物体变换后的结果又决定了C物体的最终状态。信息在不同对象之间隐式传递。

- **时序编码在空间中**：网格的空间排列实际上编码了一个时间序列或状态机的多步演化过程——输出是"下一帧"。

- **自指规则**：规则本身被编码在网格的某个区域中，需要先"读取"规则再"执行"规则。

<new_puzzle>
- `description`：根据每个封闭前景区域内部被困住的背景"气泡"数量，对该区域进行对应次数的 90 度顺时针旋转。
- `Input structure`：网格背景为 black。若干互不相邻的彩色前景封闭区域（每个区域是单色的 4-连通连通域，其外轮廓完全封闭，不触碰网格边缘）散布在网格上。每个封闭区域的内部可能包含 0、1、2 或 3 个由背景色构成的"气泡"（即被前景完全包围的 black 连通域，每个气泡为 1 个像素大小）。不同区域可以有不同颜色，但每个区域自身单色。
- `Rule`：
  1. 对网格中的每个前景 4-连通连通域，计算其内部被完全包围的 black 像素连通域（气泡）的数量 n（0 ≤ n ≤ 3）。
  2. 计算该连通域的最小外接矩形（bounding box）。
  3. 将该 bounding box 内的所有内容（包括前景像素和内部 black 像素）以 bounding box 中心为旋转中心，顺时针旋转 n × 90 度。旋转后写回原位置。bounding box 外的网格保持不变。
  4. 若 n = 0，该区域不做任何变换。
- `Key insight`：解题者必须意识到每个封闭形状内部的"洞"的数量不是装饰，而是编码了旋转次数的指令。关键难点在于将"孔洞计数"这一拓扑属性与"旋转角度"这一几何变换建立联系。
</new_puzzle>

<new_puzzle>
- `description`：在网格中找到"几乎完美对称"的图案，将其中破坏对称性的像素移动到使图案真正对称的位置。
- `Input structure`：网格背景为 black。网格中有若干由同一种非背景色（如 blue）组成的 4-连通前景图案。每个图案都"接近"具有某种对称性（水平镜像、垂直镜像、或 180 度旋转对称），但恰好有 1-2 个像素偏离了完美对称的位置。此外，网格中有一个用另一种颜色（如 red）绘制的小型对称轴指示符：一条长度为 1 的 red 水平线段表示水平镜像，一条长度为 1 的 red 垂直线段表示垂直镜像，一个单独的 red 像素点表示 180 度旋转对称。red 指示符不与任何 blue 图案相邻。
- `Rule`：
  1. 读取 red 指示符的形态，确定本题要求的对称类型（水平/垂直/旋转180度）。
  2. 对每个 blue 前景 4-连通连通域，计算其 bounding box 的中心线或中心点作为对称轴/对称中心。
  3. 找到该连通域中不满足指定对称性的像素（即该像素存在，但其对称位置为空；或对称位置有像素但该位置为空）。
  4. 将"多余"的像素（有像素但对称位没有的）擦除，将"缺失"的位置（对称位有像素但此处没有的）补上 blue 像素。最终每个图案都变成完美对称。
  5. Red 指示符在输出中保持不变。
- `Key insight`：核心挑战在于：(1) 认识到那个微小的 red 标记不是装饰而是指定了对称类型的密钥；(2) 图案的"缺陷"不是噪声，而是需要被修复的偏差。解题者需要同时发现"什么类型的对称"和"如何修复"这两层信息。
</new_puzzle>

<new_puzzle>
- `description`：将前景色物体之间的背景空隙形状提取出来，作为独立的新物体绘制到网格的空白区域。
- `Input structure`：网格背景为 black，尺寸不超过 20×20。网格被一条 grey 水平分割线分为上下两个面板（分割线占 1 行，横贯整个网格宽度）。上面板包含若干紧密排列（但不重叠、不接触）的同色矩形前景块（如 green 矩形），它们之间被窄缝隙隔开（缝隙宽度为 1 个像素）。这些缝隙形成由 black 像素构成的十字交叉图案或 T 形、L 形路径。下面板初始全为 black（空白）。
- `Rule`：
  1. 识别上面板中前景矩形之间由 black 背景构成的缝隙区域。
  2. 将每段连续的水平或垂直缝隙线段视为独立对象，记录其长度、方向和相对位置关系。
  3. 在下面板中，用 orange 像素重新绘制这些缝隙的形状——保持缝隙之间的拓扑关系和相对位置不变，但将整个缝隙图案平移到下面板的中央位置（水平和垂直居中）。
  4. 上面板保持不变。
- `Key insight`：解题者需要进行"图-底反转"——将注意力从显眼的彩色矩形前景转移到它们之间看似无意义的黑色背景缝隙上。真正的输出内容隐藏在负空间中。发现"缝隙即目标对象"是解题的核心认知跳跃。
</new_puzzle>

<new_puzzle>
- `description`：每个彩色箭头指向的方向和长度编码了"发射"操作——从箭头尖端沿指向方向发射一条等长的新射线，射线颜色取决于箭头经过的特殊染色区域。
- `Input structure`：网格背景为 black，尺寸不超过 25×25。网格上有若干用不同非背景色绘制的箭头形状。每个箭头由一条直线段（箭杆）和一个 V 形箭头尖（箭头）组成：箭杆为 1 像素宽的水平或垂直直线（长度 ≥ 2），箭头为箭杆末端向两侧各伸出 1 像素形成的 V 形（共 2 个像素），整个箭头与箭杆同色。箭头指向方向即 V 形张开的方向（上、下、左、右之一）。此外，网格上散布着若干 1×1 的 yellow 标记像素，它们不与任何箭头相邻。
- `Rule`：
  1. 对每个箭头，确定其指向方向 D 和箭杆长度 L（不含箭头尖的 2 像素）。
  2. 从箭头尖端像素出发，沿方向 D 绘制一条长度为 L 的射线。
  3. 射线的颜色规则：若该射线路径上会经过任何 yellow 标记像素，则射线颜色变为 red；否则射线颜色为 green。
  4. 射线绘制时覆盖背景像素；若射线碰到非背景、非 yellow 的像素则停止（不覆盖该像素）。
  5. 原始箭头和 yellow 标记在输出中保持不变（yellow 标记若被射线经过则被射线颜色覆盖）。
- `Key insight`：解题的难点在于理解箭头不仅指示方向，箭杆长度还编码了射程距离。更隐蔽的是，射线颜色并非由箭头自身决定，而是由射线路径上是否存在远处的 yellow 标记来决定——需要"先模拟射线轨迹，再判断颜色"的两步推理。
</new_puzzle>

<new_puzzle>
- `description`：网格中的每个小型"种子"图案会根据其相邻颜色带的宽度，在该方向上生长出对应层数的同心扩展框架。
- `Input structure`：网格背景为 black，尺寸不超过 25×25。网格中散布着若干彼此远离的小型"种子"图案——每个种子是一个 1×1 的彩色像素（非 black、非 grey）。部分种子的上、下、左、右四个方向上紧邻着长度不等的 grey 像素条带（每条 grey 条带为从种子出发沿某基本方向延伸的连续 grey 像素段，长度 1-3）。不同方向的 grey 条带长度可以不同，某些方向可以没有 grey 条带（长度为 0）。
- `Rule`：
  1. 对每个种子像素，读取其上、下、左、右四个方向的 grey 条带长度，分别记为 U、D、L、R。
  2. 擦除所有 grey 条带像素（变为 black）。
  3. 以种子像素为中心，向上扩展 U 行、向下扩展 D 行、向左扩展 L 列、向右扩展 R 列，形成一个矩形区域。
  4. 将该矩形区域的外边框（仅最外一圈）像素全部涂为种子的颜色。种子像素本身保持不变。矩形内部（除种子外）保持 black。
  5. 若某方向长度为 0，则该方向不扩展（即矩形该侧边框紧贴种子）。
- `Key insight`：grey 条带看似是种子的装饰或附属物，实际上是四个方向独立的"生长指令"，编码了最终矩形框架在每个方向上的扩展距离。核心认知跳跃是发现 grey 的长度不是输出的一部分，而是被消耗掉的控制参数——输出中 grey 完全消失，取而代之的是按其编码的尺寸生成的彩色框架。
</new_puzzle>

<new_puzzle>
- `description`：网格中的多个同色连通域按面积从小到大排序后，依次"吞噬"下一个更大的连通域，最终只剩最小的那个，但它获得了所有被吞噬对象的合并形状。
- `Input structure`：网格背景为 black，尺寸不超过 20×20。网格上有 3-5 个同色（如 blue）的 4-连通连通域，彼此不接触不重叠，面积互不相同。每个连通域的形状不规则但 bounding box 不超过 6×6。
- `Rule`：
  1. 将所有同色连通域按面积从小到大排序，编号为 S1、S2、...、Sn（S1 最小）。
  2. 从最小的 S1 开始：将 S2 的形状（以 S2 bounding box 左上角为锚点的相对坐标集合）平移，使 S2 的 bounding box 左上角与 S1 的 bounding box 左上角对齐，将平移后的 S2 形状叠加到 S1 位置（合并像素集合，即取并集）。
  3. 擦除 S2 原位置的所有像素。
  4. 然后对 S3 重复同样的操作：将 S3 的形状平移对齐到 S1（已合并 S2 后）的 bounding box 左上角，叠加并擦除 S3 原位置。
  5. 依此类推直到所有连通域都被合并到 S1 的位置。
  6. 最终输出只在 S1 的位置有一个合并了所有形状的大连通域，其他位置全部清空。
- `Key insight`：解题者需要识别出"面积排序"是操作的隐含顺序，且"最小者为接收者"这一反直觉的逻辑——不是大吞小，而是小聚大。关键难度在于理解多个形状如何通过 bounding box 左上角对齐逐步叠加成一个复合体。
</new_puzzle>

<new_puzzle>
- `description`：网格被划分为若干矩形房间，每个房间的"门"（墙壁上的缺口）方位决定了房间内部内容的旋转角度。
- `Input structure`：网格背景为 black，尺寸不超过 25×25。网格被 grey 像素组成的正交线段分割为若干个互不重叠的矩形"房间"（grey 线段构成墙壁，墙壁厚度 1 像素）。每个房间的四面墙壁中恰好有一面有一个 1 像素宽的缺口（"门"），门所在的位置用 black 像素表示（即墙壁上该像素缺失为 black）。每个房间内部包含一个由某种非 black、非 grey 颜色绘制的小型图案（不对称，使旋转结果可区分）。
- `Rule`：
  1. 对每个房间，确定其"门"位于哪面墙壁（上、下、左、右）。
  2. 定义"门朝上"为 0 度（不旋转）。门朝右 = 顺时针 90 度，门朝下 = 180 度，门朝左 = 逆时针 90 度（等价于顺时针 270 度）。
  3. 将该房间内部的图案以房间内部区域的中心为旋转中心，顺时针旋转上述角度。
  4. 旋转后的图案写回房间内部。墙壁和门保持不变。
- `Key insight`：墙壁上的缺口（门）看似只是房间的出入口，实际上编码了房间内容的旋转指令。解题者必须将"门的方位"与"旋转角度"关联起来——这需要对比多个房间中图案的朝向差异与门的位置差异，才能归纳出规则。
</new_puzzle>
