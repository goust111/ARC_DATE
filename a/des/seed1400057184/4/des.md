# 第一步：分析与思考

## 参考题中涉及的基础操作梳理

参考题涵盖了丰富的空间变换操作：路径规划与障碍规避、模板复制与偏移放置、奇异项提取、像素重排与几何重构、对齐与标准化、颜色编码信息传递、滑动与投射、排序与嵌套、分形自相似映射、地形剖面标注、遮罩修复等。

## 非显而易见的串联方式思考

1. **对象的"隐性身份"由上下文决定**：同一像素既可以是装饰，也可以是控制信号——关键在于它与其他元素的空间关系。例如，一个像素是否位于某条线的延长线上、是否落在某个周期节拍上，决定了它扮演的角色。这启发我思考：对象的功能不是固有的，而是由它在网格中与其他对象的关系动态赋予的。

2. **计数信息可以编码在意想不到的维度中**：蓝色像素数量编码危险半径（参考1）、灰色格子数量限制移动步数（参考18）。这让我思考：数量信息还可以编码在连通区域的面积、形状的对称性阶数、颜色的种类数等更隐蔽的维度中。

3. **局部模式作为全局结构的蓝图**：分形自相似（参考15）展示了"小格子的内部图案就是大格子的排列蓝图"。推广来看，任何局部结构都可能在描述一种全局行为——一个小图形的轮廓可能编码了一条路径，一组点的排列可能编码了一个变换矩阵。

4. **负空间（孔洞、空隙）作为主动信号源**：参考8中滑动后的封闭空洞成为射线的发射口。这暗示：有意义的信息不一定在"有颜色"的地方，而可能藏在"没有颜色"的空隙中——空隙的形状、大小、位置都可以是操作指令。

5. **变换规则的"多阶段揭示"**：有些题需要先完成一个预处理（如滑动、对齐、修复），然后才能看到真正的规则所作用的结构。这种"先还原再操作"的范式可以拓展为更深层的嵌套：操作A的结果揭示了隐藏的结构B，B中编码了操作C的参数。

6. **拓扑属性作为分类依据**：连通性、包围关系、孔洞数量等拓扑特征是人眼可以直觉感知但不容易形式化的属性，非常适合作为ARC谜题的核心判据。

<new_puzzle>
- `description`：根据每个封闭区域内部被"困住"的游离像素的颜色，对该封闭区域的边框重新上色。

- `Input structure`：
  - 背景色为 black。
  - 网格中有若干由同一种颜色（如 grey）绘制的封闭环形边框（一像素宽、不规则形状但保证四连通封闭）。
  - 每个封闭环内部有若干背景色像素和恰好一个非背景、非边框颜色的游离像素（如 red、blue、green 等，每个环内颜色不同）。
  - 封闭环外部也可能散落一些与某些环内相同颜色的游离像素，作为干扰。

- `Rule`：
  - 识别所有由 grey 像素构成的四连通封闭环。
  - 对于每个封闭环，找到其内部（被环完全包围的区域）唯一的非背景、非 grey 的游离像素，读取其颜色。
  - 将该封闭环的所有 grey 边框像素替换为该游离像素的颜色。
  - 环内的游离像素本身保持不变。
  - 环外的所有游离像素全部擦除为背景色。

- `Key insight`：封闭环"内部"与"外部"的区分是核心——只有被拓扑封闭的区域内部的单个彩色像素才是合法的颜色指令，外部同色像素是干扰项。解题者需要理解四连通封闭性判定，并意识到环的重新着色由其"囚徒"的颜色决定。
</new_puzzle>

<new_puzzle>
- `description`：将网格中散落的彩色像素组成的"星座"簇，根据其像素数量决定光环层数，向外扩展曼哈顿距离光环。

- `Input structure`：
  - 背景色为 black。
  - 网格中散布着若干组彩色像素簇（四连通分量），每组使用不同颜色（如 red、blue、green、yellow、magenta 等）。
  - 每个像素簇包含 1 到 5 个像素不等，形状各异。
  - 像素簇之间间距足够大（至少相隔 6 个背景像素），确保扩展环不会重叠。

- `Rule`：
  - 统计每个像素簇的像素数量 n。
  - 像素数量 n 即为该簇需要添加的"光环层数"：为该簇向外做 n 层曼哈顿距离扩展（即第 k 层光环覆盖所有与簇中任意像素的曼哈顿距离恰好为 k 的背景像素，k = 1, 2, ..., n）。
  - 光环颜色统一为 grey。
  - 原始彩色像素保持不变，光环只绘制在背景色像素上。

- `Key insight`：解题者需要发现一个看似反直觉的规律——像素数量越多的簇，光环反而越厚。核心洞见是"像素数量 = 光环层数"这个简单但隐蔽的数量对应关系，需要仔细对比不同大小的簇及其光环厚度才能发现。
</new_puzzle>

<new_puzzle>
- `description`：网格中的彩色路径在经过"门"标记时颜色发生互换变换，需要根据已可见的颜色变化推断门的映射规则，补全路径上的灰色缺失区间。

- `Input structure`：
  - 背景色为 black。
  - 网格中有 2-3 条从一个网格边缘延伸到另一个边缘的单像素宽路径（可以是水平、垂直方向，允许直角拐弯），路径不相交。
  - 路径上的像素有颜色（如 red、blue、green 等），但路径在某些位置有一段连续的 grey 像素区间（长度 3-8 像素），表示"颜色未知区间"。
  - 网格中有若干"门"：由两个相邻的 maroon 像素组成，恰好横跨在某条路径上（即门的两个 maroon 像素分别位于路径像素的正上正下或正左正右的相邻位置，夹住路径）。
  - 每条路径可能经过 0 到 2 个门。每个门只被一条路径穿过。

- `Rule`：
  - 每个门定义一个颜色互换映射：观察该门两侧（沿路径方向）紧邻的路径像素颜色，一侧颜色为 A，另一侧颜色为 B（A 和 B 不同）。通过此门时，颜色 A 变为 B，颜色 B 变为 A。
  - 对于路径上的 grey 未知区间，根据该区间的入口侧已知颜色以及其间是否经过门来推导每个 grey 像素应有的颜色：
    - 如果未知区间内没有门，则整段用入口侧颜色填充。
    - 如果未知区间内有一个门，则门之前的 grey 像素用入口侧颜色填充，门之后的 grey 像素用映射后颜色填充。
  - 门的映射规则需要从同一个门所在的、颜色完全可见的路径段来推断。即至少有一条路径在经过该门时两侧颜色都可见，解题者据此学习该门的映射。

- `Key insight`：门是颜色变换器，但门的变换规则不是直接标注的——需要从门两侧已经可见的路径颜色来推断。解题者必须先观察那些颜色完全可见的路径段来理解每个门的映射效果，然后将同样的映射应用到含有 grey 未知区间的路径上。信息传递是间接的：一条路径上可见的颜色变化"教会"你门的规则，另一条路径的缺失颜色需要你"应用"这个规则。
</new_puzzle>

<new_puzzle>
- `description`：将网格中每个正方形区域内部的"指针"标记解读为时钟方向，据此对该正方形执行相应角度的旋转。

- `Input structure`：
  - 背景色为 black。
  - 网格中有若干个不重叠的正方形彩色区域（大小为 5x5），每个区域由单一填充色构成（如 red、blue、green 等，颜色互不相同）。
  - 每个正方形区域的正中心像素（第3行第3列）为 grey，代表时钟中心。
  - 从中心向外延伸恰好 2 个像素（包含中心共3个像素）形成一条 maroon 色直线段，方向为上、下、左、右四个正方向之一。这条线段即为"指针"。

- `Rule`：
  - 指针朝上（即 maroon 线段从中心向上延伸2格）：区域不旋转（0度）。
  - 指针朝右（从中心向右延伸2格）：整个 5x5 区域顺时针旋转 90 度。
  - 指针朝下（从中心向下延伸2格）：整个 5x5 区域旋转 180 度。
  - 指针朝左（从中心向左延伸2格）：整个 5x5 区域顺时针旋转 270 度。
  - 旋转以正方形的中心像素为轴心，在原位完成（正方形的中心位置不移动）。旋转后，填充色像素、grey 中心、maroon 指针均一起旋转。
  - 区域之外的所有像素不变。

- `Key insight`：解题者需要注意到每个方块中心都有一个灰点和一条 maroon 短线（指针），并将其理解为时钟方向的编码。难点在于从样例中推断出"指针方向→旋转角度"的映射关系，关键是发现"朝上 = 不变"这个基准。由于旋转包括指针自身，输出中指针方向会改变（全部变为朝上），这可作为验证手段。
</new_puzzle>

<new_puzzle>
- `description`：网格中散落的彩色碎片是同一幅图被切割后的拼图块，需要根据边缘锯齿的凹凸吻合关系将它们无缝拼入中央的矩形框中。

- `Input structure`：
  - 背景色为 azure。
  - 网格中有 4 个不重叠的彩色碎片，每个碎片由同一种颜色的四连通像素组成（如 red、green、blue、yellow 各一块）。
  - 每个碎片的形状不规则，但都有一条或两条平直边缘（连续的直线边界）和一些锯齿形凹凸边缘。
  - 网格中央有一个 grey 单像素宽矩形轮廓框，框的内部面积恰好等于四个碎片面积之和。

- `Rule`：
  - 四个碎片需要被平移（不旋转、不翻转）到 grey 矩形框内部，完全无缝填满框的内部区域，碎片之间无重叠、无间隙。
  - 拼合方式唯一：每个碎片的锯齿凸出部分恰好嵌入相邻碎片的锯齿凹陷部分。
  - 碎片的平直边缘必须对齐框的内边界。
  - 输出中：grey 矩形框保持不变，四个碎片移入框内各自正确的位置，碎片在框外的原始位置被擦除为背景色。

- `Key insight`：这是一个纯空间吻合的拼图问题。解题者需要观察每个碎片的边缘轮廓，找到凹凸互补的配对关系来确定拼合方式。关键线索是碎片的平直边必须对齐框的边界，而锯齿边必须与另一碎片的互补锯齿边相邻。由于不允许旋转和翻转，配对关系是唯一确定的。
</new_puzzle>

<new_puzzle>
- `description`：将网格中的多个三视图投影面板（正视图和侧视图）反推合成为俯视图，输出到指定面板中。

- `Input structure`：
  - 背景色为 black。网格被两条垂直的 grey 分隔线等分为三个等宽面板（左、中、右）。
  - 左面板包含若干水平彩色线段——代表正视图（前视），每条线段的行位置代表高度层，线段的列跨度代表该层在左右方向上的宽度范围。
  - 中面板包含若干水平彩色线段——代表侧视图（右视），每条线段的行位置代表高度层，线段的列跨度代表该层在前后方向上的深度范围。
  - 同一高度层的线段在左面板和中面板中位于同一行且颜色相同。
  - 右面板初始全为背景色——这是需要填入俯视图的输出区域。

- `Rule`：
  - 对于每个高度层（同行同色的左面板线段和中面板线段配对）：
    - 左面板线段的列范围（相对于左面板左边界的偏移）决定俯视图中该层覆盖的列范围。
    - 中面板线段的列范围（相对于中面板左边界的偏移）决定俯视图中该层覆盖的行范围。
    - 该层在俯视图中占据的区域是上述行范围与列范围的笛卡尔积矩形。
  - 俯视图中每个像素取所有覆盖它的层中最高层（行号最小的层）的颜色。
  - 将结果绘制在右面板中。左面板和中面板内容保持不变。

- `Key insight`：三个面板分别是同一三维积木堆的三个视图。解题者需要意识到左面板和中面板是两个正交方向的投影，它们通过行位置（高度）关联，交叉定义了每一层在俯视图中的矩形区域。遮挡关系由高度（行号越小=越高）决定，最上层颜色胜出。
</new_puzzle>

<new_puzzle>
- `description`：网格中多个形状各自拥有一个"影子方向"标记，需要按标记方向为每个形状投射彩色影子，影子长度由形状的面积决定。

- `Input structure`：
  - 背景色为 black。
  - 网格中有若干个不同颜色的四连通形状（如 red、blue、green 等），每个形状的面积在 3-8 像素之间。
  - 每个形状的外围（紧邻形状的某一侧）有一个 maroon 单像素标记点，标记该形状的投影方向：标记在形状的右侧表示影子向右投射，在下侧表示向下投射，在左侧表示向左投射，在上侧表示向上投射。
  - 形状之间间距足够大，确保影子不会相互覆盖。

- `Rule`：
  - 对于每个形状，读取其面积 n 和 maroon 标记所指示的投影方向 d。
  - 沿方向 d，将该形状的轮廓逐像素平移 1 到 n 格，每次平移生成一个"影子层"。所有影子层统一用 grey 绘制。
  - 影子只绘制在背景色上，不覆盖原始形状。
  - maroon 标记点在输出中被擦除为背景色。

- `Key insight`：解题者需要发现两个隐蔽的对应关系：（1）maroon 标记相对于形状的位置编码了投影方向——标记不是箭头，而是通过空间位置隐式指示方向；（2）影子的长度（平移层数）等于形状自身的面积像素数，这个"面积=影长"的映射需要仔细计数对比才能发现。
</new_puzzle>
