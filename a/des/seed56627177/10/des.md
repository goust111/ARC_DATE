<description>
根据封闭区域内标记像素的颜色，从色带图例中查找对应的填充图案，再将该图案平铺填入该区域。

Input structure
- 背景为 Black。
- 网格顶部有一行或两行水平色带图例：每段色带由一个单像素颜色标签紧跟一段重复图案组成（图案由两到三种颜色按固定周期排列），相邻色带之间用 Black 间隔。
- 网格下方有若干由 Grey 线条围成的封闭矩形区域，每个区域内部全部为 Black，但其中恰好有一个像素被涂成了某个与色带标签相同的颜色，该像素位于区域内任意位置。

Rule
- 对每个封闭的 Grey 矩形区域，找到区域内唯一的非 Black 像素，读取其颜色。
- 在色带图例中找到以该颜色作为标签的那段图案。
- 将该段图案按其原始周期，从区域左上角开始逐行逐列平铺，填满整个区域内部（覆盖掉原来的标记像素）。
- Grey 边框和色带图例保持不变。

Key insight
- 解题需要两层推理：第一层是识别色带图例的结构——标签像素与紧随其后的重复图案之间的对应关系；第二层是将标记像素视为索引键，在图例中查表后将图案平铺到对应区域。标记像素本身不保留在输出中。
</description>
</new_puzzle>

<description>
将散落的彩色碎片按形状互补关系配对拼合，再将每对拼合体按面积从小到大排列到输出网格中。

Input structure
- 背景为 Black。
- 网格中散布着若干个由不同颜色构成的小型 4-连通碎片（每个碎片为单色）。
- 碎片总数为偶数，每两个碎片恰好能拼合成同一尺寸的实心矩形（即一个碎片的形状是另一个碎片在该矩形内的补集）。
- 同一对互补碎片的颜色不同。

Rule
- 识别所有碎片，按形状互补关系两两配对：两个碎片叠加后恰好组成一个无空隙的实心矩形。配对方式唯一（每个碎片只有一个互补伙伴）。
- 对每一对碎片，将它们拼合成完整矩形，保留各自的原始颜色。
- 将所有拼合后的矩形按面积从小到大、从左到右排列在输出网格中，矩形之间用一列 Black 间隔，所有矩形顶部对齐到第一行。

Key insight
- 核心推理在于发现碎片之间的形状互补关系——两个形状看似无关，但叠加后恰好填满同一个矩形。解题者需要先在脑中"试拼"来发现配对，然后才能完成排列输出。碎片颜色仅用于区分拼合后的两部分，不参与配对逻辑。
</description>
</new_puzzle>

<description>
用边框上的箭头标记指定的行或列作为"镜轴"，将网格中每个彩色对象沿该轴翻转到轴的另一侧，翻转后颜色由箭头颜色决定。

Input structure
- 背景为 Black。
- 网格边框的某一侧（上、下、左或右）有若干个由两个像素组成的箭头标记：一个像素位于边框行/列上，另一个像素紧邻它向网格内部方向偏移一格，两个像素颜色相同。箭头所指的行或列即为"镜轴"。
- 网格内部有若干个由 Grey 构成的 4-连通对象，全部位于镜轴的同一侧。
- 每个箭头颜色各不相同（非 Black、非 Grey）。

Rule
- 确定镜轴：箭头从边框指向内部的那一行或那一列即为镜轴。
- 对网格中每个 Grey 对象，找到距离它最近的箭头（按对象中心到箭头所在行/列位置的距离，取最近者）。
- 将该 Grey 对象沿镜轴做镜像翻转到轴的另一侧，翻转后的像素涂成对应箭头的颜色。
- 原始 Grey 对象保持不变，箭头标记保持不变。

Key insight
- 第一层推理是从箭头的朝向和位置推断出镜轴的存在与位置；第二层推理是发现每个对象由最近的箭头"认领"，而箭头颜色决定了翻转副本的颜色。Grey 对象不动，翻转副本以新颜色出现在轴的对侧。
</description>
</new_puzzle>

<new_puzzle>
<description>
根据各层嵌套框架的缺口方向，逐层向内传递并累积路径颜色，最终用路径终点的累积颜色填充最内层区域。

Input structure
- 背景为 Black。
- 网格中有若干层同心嵌套的矩形框架，每层框架由不同颜色绘制（如最外层 Blue、次外层 Red、再内层 Green 等），每层框架厚度为一个像素。
- 每层框架的四条边中恰好有一条边存在一个宽度为一格的缺口（即该边上有一个像素缺失为 Black）。
- 最内层框架围起的区域全部为 Black。
- 网格的外边界（最外层框架之外）的某一侧边缘上有一个单独的 Yellow 起始标记像素。

Rule
- 从 Yellow 起始标记出发，确定进入最外层框架的方向——起始标记必定位于最外层框架缺口所在边的外侧。
- 从最外层缺口进入后，在当前层与下一层之间的环形走廊中，沿着能到达下一层缺口的方向行进（走廊宽度为一格，路径唯一）。
- 每穿过一层框架的缺口，记录该层框架的颜色。
- 到达最内层区域后，收集从外到内穿过的所有框架颜色。将最内层区域逐行填充：第一行用最先穿过的框架颜色，第二行用第二个穿过的颜色，依此类推；若行数多于颜色数则从头循环。
- 所有框架本身保持不变，起始标记保持不变。

Key insight
- 解题者需要三层推理：第一层是识别嵌套框架结构与每层的缺口位置；第二层是从外部标记出发追踪穿越路径的顺序，确定颜色序列；第三层是将收集到的颜色序列按层序映射为最内层区域的逐行填充。缺口方向决定路径，路径决定颜色顺序，颜色顺序决定填充结果。
</description>
</new_puzzle>

<new_puzzle>
<description>
识别网格中由隔板分割的多个条带，在每个条带内根据"种子"像素的位置和颜色生长出对称图案，生长范围由相邻条带中对象的高度决定。

Input structure
- 背景为 Black。
- 若干条竖直的 Grey 隔板将网格分割成等宽的垂直条带（每个条带宽度相同，至少三列）。
- 奇数编号的条带（第 1、3、5...条带，从左起计数）各包含一个单色 4-连通对象，颜色各不相同，对象形状不规则但完全在条带内。
- 偶数编号的条带（第 2、4...条带）每个条带中央列上有一个单独的彩色"种子"像素，种子颜色与左右相邻奇数条带中某一个对象的颜色相同。

Rule
- 对每个偶数条带，读取其种子像素的颜色和行位置。
- 找到与种子同色的对象（位于相邻的奇数条带中），计算该对象的高度（最大行减最小行加一）。
- 以种子像素为中心，在该偶数条带内，向上和向下各延伸"对象高度 / 2"（向下取整）个像素，形成一条竖直线段，颜色与种子相同。
- 再将该竖直线段沿条带中心列做左右镜像，填充条带内对应的列（即在中心列左右各一列也画上相同高度的竖线），形成对称的竖直矩形色块。
- Grey 隔板和奇数条带中的原始对象保持不变。

Key insight
- 第一层推理是识别条带的奇偶分区以及种子像素的角色——种子不是随机噪点，而是生长指令；第二层推理是发现种子颜色与相邻条带对象的匹配关系，从而将对象的高度属性"远程传递"为生长范围。条带结构将空间划分为"数据区"和"输出区"，种子像素是两者之间的桥梁。
</description>
</new_puzzle>

<new_puzzle>
<description>
将网格中的多个小图案视为拼图碎片的"正面"，利用背面的颜色编码确定它们在隐含大画布上的摆放顺序，最终将所有碎片无缝拼接输出。

Input structure
- 背景为 Black。
- 网格中有若干个相同尺寸的矩形小区域，彼此不重叠不相邻，各区域之间由 Black 间隔。
- 每个矩形区域分为上下两部分（各占一半高度）：上半部分是由多种颜色绘制的图案（"正面"），下半部分是纯色填充（"背面标签"），每个区域的背面标签颜色各不相同。
- 在网格的最底行有一条由这些背面标签颜色组成的色序条：从左到右排列若干个单像素，每个像素的颜色对应某个矩形区域的背面标签颜色，色序条中颜色不重复。

Rule
- 读取最底行色序条中的颜色顺序，从左到右记为 C1, C2, C3, ...。
- 对每个颜色 Ci，找到背面标签为 Ci 的矩形区域，提取其正面图案。
- 将所有正面图案按照色序条的顺序从左到右水平拼接，组成输出网格（输出高度等于单个正面图案的高度，宽度等于所有正面图案宽度之和）。
- 不输出背面标签部分和色序条。

Key insight
- 第一层推理是发现每个矩形区域的上下分区含义——上半是内容，下半是标识；第二层推理是识别底部色序条的作用——它不是装饰，而是规定了碎片的拼接顺序。解题者需要将"标签-内容"对应关系与"排序指令"两个独立机制结合起来，才能得到正确输出。
</description>
</new_puzzle>

<new_puzzle>
<description>
将网格中被围栏包围的各色像素群按围栏开口方向"倒出"，沿开口方向滑出围栏后堆积在网格边界处，堆积顺序由像素距开口的远近决定。

Input structure
- 背景为 Black。
- 网格中有若干个由 Maroon 像素构成的 U 形围栏（即三面封闭、一面开口的矩形框架），每个围栏的开口朝向上、下、左或右中的某一方向。
- 每个围栏内部包含若干个不同颜色的单像素（颜色互不相同，且不为 Black 或 Maroon），这些像素散落在围栏内部的不同位置。

Rule
- 对每个围栏，确定其开口方向。
- 将围栏内部所有彩色像素沿开口方向"推出"：每个像素沿开口方向直线移动，直到到达网格边界后停下。
- 若多个像素投射到同一条直线（垂直于开口方向的同一行或同一列），它们在边界处堆叠，堆叠顺序保持它们在围栏内部沿开口方向的原始前后顺序（离开口近的先到达边界，排在最外侧）。
- 围栏本身（Maroon 框架）保持不变，围栏内部清空为 Black。

Key insight
- 第一层推理是从 U 形围栏的形状判断开口方向——需要识别三面封闭的结构并找到缺失的那一面；第二层推理是理解"倒出"机制——像素不是简单平移，而是沿开口方向射出并在边界堆积，且堆积时保持原始距离排序。围栏的朝向是每组像素运动方向的独立指令。
</description>
</new_puzzle>
