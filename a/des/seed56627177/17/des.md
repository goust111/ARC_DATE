- `description`：根据封闭围栏内部的颜色种类数选择对应的染色模板，将围栏外壁涂上模板指定的颜色。
- `Input structure`：背景为黑色。网格中有若干由同一颜色（如 grey）构成的封闭矩形围栏（一像素宽的空心矩形框），每个围栏内部散布着若干种不同颜色的像素点（不含背景色和围栏色）。网格的某个边缘（如最右侧列或最底行）排列着若干小型染色模板：每个模板是一个 1x2 的色块对，左侧格子用 1 到 N 个同色像素堆叠表示一个计数值，右侧格子是一个纯色像素表示对应的染色颜色。
- `Rule`：
  1. 识别边缘处的染色模板，建立"计数值 - 颜色"的映射表：模板左侧堆叠的像素个数即为计数值，右侧的颜色即为映射目标色。

  3. 用该颜色种类数在映射表中查找对应颜色，将该围栏的所有围栏像素重新着色为查到的颜色。
  4. 围栏内部像素和背景保持不变。
- `Key insight`：围栏本身的颜色不携带信息，其最终颜色由内部颜色的多样性决定；解题者需要先发现边缘模板是一个"数量到颜色"的查找表，再发现围栏内部的关键属性是颜色种类数而非像素总数。

- `Input structure`：背景为黑色。网格中散布着若干个不规则形状的单色连通区域（4-连通），每种形状恰好出现两次，且这两次的颜色不同。同形状的两个区域不会相邻，可能在网格中的任意位置。没有两个不同形状完全相同（可能需要旋转或翻转才能匹配）。
- `Rule`：
  1. 将所有前景连通区域按形状配对：两个区域形状相同（允许旋转和翻转）则配为一对。设某对中区域 A 颜色为 cA、区域 B 颜色为 cB。
  2. 对区域 A：保留其原始位置和轮廓，但将其中每个像素按棋盘格模式交替填充 cA 和 cB——区域边界框内左上角第一个属于该区域的像素用 cA，其后按行优先交替。
  3. 对区域 B 执行相同操作，第一个像素用 cB，交替填充 cB 和 cA。
  4. 背景保持不变。
- `Key insight`：解题者首先需要发现形状配对关系（可能涉及旋转/翻转匹配），然后发现配对后的两个区域互换颜色并以棋盘格方式交织，而非简单的颜色互换。两层推理缺一不可：第一层是几何形状的跨位置匹配，第二层是配对颜色的棋盘格交织规则。
</new_puzzle>

- `description`：沿箭头指向将源色块"投影"到目标框架内，投影长度由源色块的面积决定，在框架内壁反弹后继续延伸。
- `Input structure`：背景为黑色。网格中有一个由 grey 像素构成的较大空心矩形框架（一像素宽边框，内部为背景色）。框架外部有若干小型单色矩形色块（源色块），每个源色块紧贴框架的某一条边外侧。每个源色块旁边（远离框架的一侧）有一个由同色像素组成的箭头形状，箭头尖端指向框架方向（即指向源色块与框架接触的那一侧）。箭头的画法：一个 3 像素长的直线段加上尖端两侧各一个像素构成的"V"形箭头头部。
- `Rule`：
  1. 确定每个源色块的面积（像素数），记为 N。
  2. 从源色块与框架接触的位置开始，向框架内部沿垂直于接触边的方向延伸一条与源色块同色的射线。
  3. 射线长度为 N 个像素。如果射线在 N 步之内碰到框架对面的内壁，则在内壁处按镜面反射改变方向（水平碰壁变垂直，垂直碰壁变水平），继续延伸剩余的像素数。
  4. 若多次反弹仍未用完 N 步，继续反弹直到画完 N 个像素。
  5. 源色块和箭头在输出中保持不变，框架保持不变。
- `Key insight`：解题者需要三层推理：第一层是识别箭头方向确定投影起始方向，第二层是发现源色块的面积决定射线长度，第三层是发现射线在框架内壁的镜面反弹行为。面积与长度的跨维度映射以及反弹机制共同构成了非平凡的多层结构。
</new_puzzle>

- `description`：根据每个房间内地板砖的铺设方向，选择该房间对应门的位置并打开（擦除门段），其余门保持关闭。
- `Input structure`：背景为黑色。网格由 grey 颜色的单像素宽墙壁分隔成若干矩形"房间"。每个房间的四面墙壁中，恰好有两面墙的中间位置各有一个两像素宽的缺口（用与墙壁不同的特殊颜色如 maroon 填充），代表两扇"门"。每个房间内部铺有由某种前景色构成的条纹图案，条纹要么是水平方向（水平线段），要么是垂直方向（垂直线段），条纹之间间隔一个像素的背景色。
- `Rule`：
  1. 识别每个房间内条纹的方向：水平或垂直。
  2. 如果条纹是水平方向，则该房间应打开位于左墙或右墙上的门（即与条纹垂直的墙面上的门被打开）。
  3. 如果条纹是垂直方向，则打开位于上墙或下墙上的门。
  4. "打开门"的操作：将门的 maroon 像素替换为背景色（黑色），形成真正的通道缺口。
  5. "关闭门"保持不变：maroon 像素保留在原位。
  6. 条纹图案和墙壁其余部分不变。
- `Key insight`：解题者首先需要发现房间内的条纹方向与门的开闭之间存在对应关系，然后推断出具体规则：条纹方向决定了哪个轴上的门被打开——打开的门位于条纹延伸方向的尽头（垂直条纹开上下门，水平条纹开左右门）。门的存在是显然的，但条纹方向作为选择键是需要归纳的非平凡洞见。
</new_puzzle>

- `description`：将嵌套环形结构由外向内逐层剥离，按剥离顺序水平排列为独立的实心矩形色块，矩形的高度固定为一行，宽度由该环层的像素总数决定，形成水平柱状图。
- `Input structure`：背景为黑色。网格中央有一个由多层不同颜色的同心矩形环嵌套而成的结构。最外层是一个完整的矩形环（空心矩形框），每层环厚度为一个像素，内部是下一层颜色的环，最内层可以是实心矩形。每层颜色各不相同。层数在 2 到 5 之间。
- `Rule`：
  1. 从最外层开始，逐层识别每个同心环的颜色。
  2. 计算每层环实际包含的像素数量，记为 P。
  3. 输出网格的高度等于嵌套结构的层数，宽度等于最大 P 值。
  4. 从输出网格的第一行（顶行）开始，每一行对应一层环（从最外层到最内层）：该行从最左侧起连续填充 P 个该层颜色的像素，其余位置为背景色。
  5. 即输出是一个水平柱状图，每根柱子高一行，长度等于该层的像素数，颜色等于该层的颜色，从外到内自上而下排列。
- `Key insight`：解题者需要两层推理：第一层是识别同心嵌套环的层级结构并确定由外向内的剥离顺序，第二层是发现每层环被"展开"为一维的像素计数条，形成柱状图表示。嵌套空间结构到一维统计图的映射是核心难点。
</new_puzzle>

- `description`：在网格中找到"种子"像素与"土壤"区域的配对关系，让种子在土壤中按特定生长模式扩展，生长方向由种子相对于土壤的进入侧决定。
- `Input structure`：背景为黑色。网格中有若干个由同一颜色（如 green）构成的不同大小的实心矩形区域，称为"土壤"。每块土壤的某一条边外侧恰好紧贴着一个单独的彩色像素（颜色各异，与土壤颜色不同），称为"种子"。种子像素与土壤之间 4-连通相邻。
- `Rule`：
  1. 确定每颗种子紧贴土壤的哪一侧（上、下、左、右）。
  2. 从种子进入土壤的位置开始，在土壤内部沿进入方向画一条与种子同色的直线，直到碰到土壤的对面边界（含边界像素）。
  3. 以这条直线为"茎"，在茎的两侧每隔一个像素向左右（若茎为垂直）或上下（若茎为水平）方向各延伸一个像素，用种子颜色填充，形成交替的"枝叶"图案。具体来说：茎上第一个像素（紧邻种子进入点的土壤像素）向茎的左侧延伸一个像素，第二个像素不延伸，第三个像素向茎的右侧延伸一个像素，第四个不延伸，如此交替。
  4. 枝叶像素仅在土壤范围内绘制；超出土壤边界的枝叶不画。
  5. 种子像素本身在输出中保留，土壤中未被种子颜色覆盖的区域保持土壤原色。
- `Key insight`：解题者需要先发现种子与土壤的配对关系和进入方向，然后发现种子在土壤内部的生长不是简单的直线填充，而是带有交替枝叶的树形图案。进入侧决定茎的方向，交替规则决定枝叶的排布，两层规则共同定义了最终图案。
</new_puzzle>

- `description`：将网格中的多个小图案按照隐含的拼图边缘锁扣关系拼合成一幅完整的大图，锁扣的凸凹互补决定拼接方式。
- `Input structure`：背景为黑色。网格中散布着若干个大小相近的矩形彩色图案块（每个块内含多种颜色的像素图案）。每个图案块的边缘不是完美的矩形：某些边上有一个单像素的凸起（向外多出一个像素），而与之对应的另一个图案块的相邻边上有一个单像素的凹陷（向内缺少一个像素）。凸起像素颜色与所在图案块的边缘颜色一致，凹陷位置为背景色。每个图案块恰好在上、下、左、右四个方向中的若干方向有凸起或凹陷。
- `Rule`：
  1. 识别每个图案块边缘的凸起和凹陷的位置（相对于该块的哪一侧、在该侧的哪个偏移量）。
  2. 两个图案块可以拼合，当且仅当一个块某侧的凸起与另一个块对应侧的凹陷在位置上互补（凸起恰好填入凹陷）。
  3. 按照凸凹互补关系，将所有图案块平移到正确位置拼合在一起，凸起像素填入邻块的凹陷位置。
  4. 输出网格大小恰好容纳拼合后的完整图案，无多余背景边距。
- `Key insight`：解题者需要先发现图案块边缘不规则的凸起和凹陷不是噪声而是拼接线索，然后通过凸凹互补的空间匹配确定拼接方案。这类似拼图的锁扣机制——核心推理在于识别边缘形状编码了邻接关系，并通过匹配完成全局拼合。
</new_puzzle>
