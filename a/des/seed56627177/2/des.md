<description>
根据边框缺口方向将内部图案投射到外部，再用投射路径上遇到的染色标记像素重新着色投射出的副本。

Input structure
- 背景为 black。
- 网格中有若干独立的矩形边框（由单一颜色绘制的一像素宽空心矩形），每个边框的某一条边上恰好有一个连续缺口（缺口宽度等于内部图案在该方向上的跨度）。
- 每个边框内部包含一个由另一种颜色绘制的小型连通图案（非矩形、非对称的任意形状）。
- 在边框外部、沿缺口朝外的方向上，散布着若干单像素的染色标记点（颜色各异，与边框色和图案色均不同）。

Rule
- 对每个边框，找到其缺口所在的边及缺口的位置。
- 将内部图案沿缺口朝外的基本方向（上/下/左/右）平移，直到图案完全离开边框并紧贴边框外侧。
- 投射出的副本保留原始形状，但颜色需要更改：检查副本每个像素所在的行（若投射方向为左或右）或列（若投射方向为上或下）上是否存在染色标记点；若存在，该像素重新着色为该标记点的颜色；若不存在，则着色为边框自身的颜色。
- 原始边框和内部图案保持不变，染色标记点也保留。

Key insight
- 第一层推理：缺口方向决定投射方向，缺口宽度与图案宽度的匹配验证了这一点。第二层推理：投射出的副本不是简单复制，而是逐像素地从对应行或列上的标记点继承颜色，标记点实质上是一个逐行/逐列的调色板。
</description>

<description>
将网格中散落的碎片拼入唯一的矩形框架内，拼入位置由碎片自身的颜色通过框架边缘的色带索引决定。

Input structure
- 背景为 azure。
- 网格中有一个较大的空心矩形框架，由 grey 像素绘制，框架内部为背景色。
- 框架的上边缘外侧紧贴一行色带（宽度与框架内部宽度相同），色带由若干段不同颜色组成，每段覆盖若干连续列；框架的左边缘外侧紧贴一列色带（高度与框架内部高度相同），色带由若干段不同颜色组成，每段覆盖若干连续行。
- 网格其余位置散布着若干小型连通图案（碎片），每个碎片由单一颜色绘制。每个碎片的颜色在上边缘色带和左边缘色带中各恰好出现一次。

Rule
- 对每个碎片，在上边缘色带中找到与其颜色相同的那一段，记录其覆盖的列范围；在左边缘色带中找到与其颜色相同的那一段，记录其覆盖的行范围。
- 这两个范围的交叉区域定义了该碎片在框架内部的目标矩形区域。
- 将碎片平移到该目标区域内，碎片的左上角对齐目标区域的左上角。碎片的外接矩形不会超出目标区域。
- 清除碎片原始位置的像素（恢复为背景色），将碎片绘制在框架内部的新位置。框架、色带和背景保持不变。

Key insight
- 第一层推理：碎片颜色并非装饰，而是索引键——必须发现颜色与边缘色带的对应关系。第二层推理：上色带给出列坐标、左色带给出行坐标，两者交叉定位碎片的放置槽位，构成一个二维查表过程。
</description>

<description>
根据种子像素的邻域密度选择生长模式，将每个种子扩展为特定形状的区域，生长方向由相邻边界线段决定。

Input structure
- 背景为 black。
- 网格中有若干条由 grey 像素绘制的直线段（水平或垂直），它们将网格大致划分为若干区域但不完全封闭。
- 在这些线段附近散布着单个彩色像素（种子），每个种子颜色各异。每个种子恰好与一条或两条 grey 线段相邻（四方向邻接）。

Rule
- 对每个种子像素，数它四方向上相邻的 grey 像素数量（即它接触了几条线段的几个像素），记为 k。
- 若 k = 1：种子沿远离该 grey 邻居的方向生长为一条长度为 3 的直线（包含种子自身共 3 个像素）。
- 若 k = 2 且两个 grey 邻居在同一条线上（即种子夹在一条线段的两个像素之间的延长线上）：种子沿垂直于该线段的两个方向各生长 1 个像素，形成长度为 3 的十字臂。
- 若 k = 2 且两个 grey 邻居分属不同方向（即种子位于两条线段的交角处）：种子沿远离两条线段的对角方向生长为一个 2x2 的实心方块（种子占据靠近角落的那个像素位置）。
- 生长的像素使用种子自身的颜色。生长像素不会覆盖 grey 线段或其他种子。

Key insight
- 第一层推理：必须识别种子与 grey 线段的邻接关系及数量，这决定了生长模式的类别。第二层推理：生长的方向不是任意的，而是由邻接的线段方位决定——远离线段或垂直于线段，需要理解"排斥性生长"的空间逻辑。
</description>

<new_puzzle>
<description>
在分隔线划分的多个子区域中，找到每个区域的多数色图案和少数色标记，用少数色标记的位置关系对多数色图案执行特定的对称变换后覆盖回去。

Input structure
- 背景为 black。
- 网格被 maroon 色的完整行和完整列分割为若干矩形子区域（类似九宫格或更多格）。
- 每个子区域内部有一个由某种颜色绘制的主图案（占据多个像素的连通形状），以及恰好两个由另一种颜色绘制的单像素标记点。
- 主图案关于子区域中心不具有完全对称性。两个标记点总是关于子区域中心呈中心对称分布。

Rule
- 对每个子区域，识别主图案和两个标记点。
- 两个标记点连线穿过子区域中心，确定一条对称轴：若连线为水平方向，则对称轴为水平轴；若连线为垂直方向，则对称轴为垂直轴；若连线为对角方向（45度或135度），则对称轴为对应的对角线。
- 将主图案沿该对称轴做镜像翻转。
- 用翻转后的图案替换原来的主图案（标记点保留不变，背景不变）。

Key insight
- 第一层推理：标记点总是成对出现且关于中心对称，这暗示它们编码的是方向信息而非位置信息。第二层推理：标记点连线的方向决定了镜像轴——这是一种用离散点对编码连续对称操作的隐蔽方式，解题者需要跨越"点→线→轴"的抽象映射。
</description>

<description>
将网格中的路径线段按照交叉点处的层叠顺序进行分层着色，层级由交叉点处的覆盖关系链推断。

Input structure
- 背景为 black。
- 网格中有若干条由 green 像素绘制的水平或垂直线段，它们相互交叉形成若干交叉点。
- 每个交叉点处恰好有两条线段交叉（一条水平、一条垂直）。在交叉点的某个相邻位置（上下左右之一）有一个单像素的 red 标记，该标记靠近的那条线段被视为"在上层"的线段。
- 所有线段初始均为 green 色。

Rule
- 根据所有交叉点处的 red 标记，建立线段之间的层叠关系：在每个交叉点，red 标记靠近的线段在该交叉点处位于另一条线段之上。
- 从这些两两关系中推导出所有线段的全局层级排序（最底层、中间层、最顶层等）。题目保证该排序是唯一的全序。
- 将最底层的线段着色为 blue，次底层着色为 yellow，再上一层着色为 orange，最顶层着色为 red。若线段总数少于四条，则从 blue 开始按顺序使用对应数量的颜色。
- 交叉点处的像素着色为上层线段的颜色。移除所有 red 标记点（恢复为背景色）。

Key insight
- 第一层推理：red 标记点不是装饰，而是编码了每个交叉点处哪条线段在上方——需要理解标记的空间邻接关系与"上下层"的映射。第二层推理：每个交叉点只给出局部的两两比较，解题者必须将所有局部关系串联成全局排序，这是一个从局部约束推断全局结构的非平凡归纳过程。第三层推理：层级排序映射到特定的颜色序列，构成最终的着色方案。
</description>

<new_puzzle>
<description>
将棋盘格状网格中每个单元格的内部小图案，按照该单元格在棋盘中的奇偶位置执行不同的旋转变换，再根据相邻单元格的边界接触颜色决定是否额外翻转。

Input structure
- 网格被 grey 色的等间距完整行和完整列分割为规则的 NxN 棋盘状单元格阵列（N 至少为 3）。
- 每个单元格内部包含一个由某种非 grey、非背景颜色绘制的小图案（占据单元格内部若干像素的连通形状），图案不对称（无旋转或镜像不变性）。
- 背景为 black。
- 所有单元格内的图案形状相同但颜色可能不同。

Rule
- 将单元格按棋盘坐标 (row, col) 编号（从 0 开始）。
- 若 row + col 为偶数，将该单元格内的图案顺时针旋转 90 度。
- 若 row + col 为奇数，将该单元格内的图案顺时针旋转 270 度（即逆时针 90 度）。
- 旋转后，检查该单元格的上边缘和左边缘：若上方相邻单元格存在且其图案颜色与当前单元格的图案颜色相同，则将当前单元格的图案额外做一次左右镜像翻转；若左方相邻单元格存在且其图案颜色与当前单元格的图案颜色相同（且尚未因上方邻居触发翻转），则将当前单元格的图案额外做一次上下镜像翻转。若上方和左方邻居颜色都相同，则只执行左右镜像翻转。
- 第一行的单元格没有上方邻居，第一列的单元格没有左方邻居，对应的翻转条件自然不满足。

Key insight
- 第一层推理：棋盘奇偶位置决定基础旋转方向——需要从多个单元格的变换结果中归纳出奇偶规律。第二层推理：颜色相同的相邻单元格会触发额外翻转——这是一条容易被旋转规律掩盖的条件规则，只有在观察到某些单元格"不符合"纯旋转预期时才能被发现。
</description>
</new_puzzle>

<new_puzzle>
<description>
将网格中的环形轨道上的彩色珠子按照轨道内部指示器的颜色进行循环移位，移位步数等于指示器颜色在轨道上出现的珠子数量。

Input structure
- 背景为 black。
- 网格中有若干个独立的闭合环形轨道，每个轨道由一圈连续的彩色像素组成（轨道像素两两四方向相邻，形成一个恰好一像素宽的封闭环路，无分叉）。
- 轨道上的像素由若干种不同颜色组成，相同颜色的像素形成连续的弧段（称为"珠子"）。
- 每个环形轨道围成的内部区域中恰好有一个单像素的指示器，颜色为轨道上出现的某种珠子颜色。

Rule
- 对每个环形轨道，读取其内部指示器的颜色 C。
- 数出轨道上颜色为 C 的像素总数，记为 S。
- 将轨道上所有像素沿轨道的顺时针方向循环移位 S 步（每个像素的颜色沿顺时针方向传递 S 个位置）。
- 顺时针方向的定义：从轨道最上方的最左像素出发，优先向右行进，始终保持内部区域在右手侧。
- 指示器像素保持不变。

Key insight
- 第一层推理：指示器的颜色不是标记"哪个珠子要动"，而是编码"移多少步"——步数等于该颜色在轨道上的像素数量，需要从多个样例中归纳出计数-移位的对应关系。第二层推理：移位是沿轨道的循环移位而非空间平移，需要理解环形拓扑上的旋转操作。
</description>
</new_puzzle>
