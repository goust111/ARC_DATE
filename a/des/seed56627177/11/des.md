<description>
根据封闭区域内部的彩色种子像素数量，选择对应面积的模板形状，将模板形状以种子颜色绘制在该区域的重心位置。

Input structure:
- 背景为 black。
- 一种前景色（如 grey）绘制了若干互不相连的封闭矩形轮廓（空心框），每个框的内部尺寸各不相同。
- 每个框内部散落着若干彩色种子像素（颜色非 black、非 grey），同一个框内所有种子像素颜色相同，但不同框的种子颜色可能不同。
- 在网格的一个角落区域（如右下角），有一组用 maroon 色绘制的小型实心形状样本（模板库），每个模板形状的像素面积各不相同，模板之间用 black 背景分隔，每个模板是一个 4-连通的实心块。

Rule:
- 对每个 grey 封闭框，数出其内部种子像素的个数 N。
- 在模板库中找到像素面积恰好等于 N 的那个模板形状。
- 将该模板形状以种子像素的颜色（替换 maroon）绘制在框内部的视觉中心位置（内部区域的行范围和列范围各自取中间值作为锚点，模板的 bounding box 中心对齐到该锚点）。
- 清除框内原有的种子像素，仅保留新绘制的模板形状。
- grey 框轮廓和模板库区域保持不变。

Key insight:
种子像素本身不构成任何有意义的空间图案——它们的唯一作用是通过数量来索引模板库中对应面积的形状；解题者需要先发现"数量＝面积"的映射关系，再识别模板库的用途，最后完成颜色替换与居中放置。
</description>

<description>
将网格中散落的单色碎片拼回它们原本所属的矩形框内部，依据碎片行轮廓与框内缺口行轮廓的逐行匹配来确定归属和垂直对齐。

Input structure:
- 背景为 black。
- 若干不同颜色的矩形空心框（单像素厚边框）分布在网格中，每个框的内部有一些行被部分填充了与框同色的像素，形成不完整的水平条纹图案，其余行完全为 black（缺口行）。
- 在框的外部，散落着若干小的 4-连通碎片对象，每个碎片的颜色与某个框的颜色相同。每个碎片恰好是一个竖直方向的窄条（宽度为 1 到 3 列），高度等于其所属框内缺口行的数量。

Rule:
- 对每个框，找出其内部所有完全为 black 的缺口行，记录缺口行的数量 G。
- 在框外部找到颜色相同且高度恰好等于 G 的碎片。
- 将碎片水平平移到框内部，使碎片的每一行逐一填入框的每一个缺口行（按从上到下的顺序一一对应）。碎片的列位置通过以下方式确定：碎片的左边缘与框内已有条纹中最靠右的像素列紧邻（右侧相邻）。
- 填入后，碎片像素与框使用相同颜色。清除框外部原碎片位置的像素。

Key insight:
碎片的高度不是随意的——它精确等于目标框内缺口行的数量，这是匹配碎片与框的关键；碎片的每一行像素对应填入一个缺口行，形成逐行插值而非整体平移，解题者需要发现"高度＝缺口数"的对应关系以及逐行展开的填充方式。
</description>

沿每个彩色箭头指示的方向，将箭头尾部相连的色块推入网格边缘的凹槽中，色块到达凹槽后按凹槽形状重新排列。

Input structure:
- 背景为 black。
- 网格的四条边缘各有若干向内凹陷的凹槽（凹槽是边缘上缺少 grey 边框像素而露出的 black 矩形缺口）。整个网格被一圈单像素厚的 grey 边框包围，凹槽就是边框上的开口。
- 网格内部散布着若干彩色对象，每个对象由两部分组成：一个实心矩形色块（如 red、blue 等）和一个与色块同色的箭头。箭头由一条直线段（水平或垂直，长度至少 2 像素）和末端的一个三角形箭头头部组成（箭头头部是在直线末端的垂直方向各扩展 1 像素形成的 3 像素宽楔形，共 1 行/列）。箭头的尾端（非三角形端）与色块的一条边相邻。
- 每个凹槽的面积（宽 x 深）恰好等于恰好一个色块的面积，但凹槽的宽高比可能与色块不同。

Rule:
- 确定每个箭头指向的方向（上、下、左、右）。
- 沿箭头方向，将色块从当前位置平移，直到色块的前缘到达对应边缘的凹槽开口处。
- 如果凹槽的形状（宽 x 深）与色块的形状不同，将色块的像素重新排列以填满凹槽（按从上到下、从左到右的扫描顺序将色块像素逐个填入凹槽的 black 单元格中）。
- 清除箭头像素和色块原始位置的像素。grey 边框保持不变。

Key insight:
箭头不仅指示运动方向，还隐含了目标边缘的选择；面积相等但形状可能不同的色块与凹槽之间的匹配需要解题者发现"面积守恒、形状重排"的规则，而非简单的刚体平移。
</description>

<description>
在由分隔线划分的网格中，每个子区域包含一个主色图案和若干异色标记点；根据标记点相对于图案的方位组合，从全局方位-颜色映射表中查找对应颜色，用该颜色重绘整个图案。

Input structure:
- 背景为 black。
- 单像素厚的 grey 水平线和垂直线将网格划分为若干矩形子区域（类似表格）。
- 其中一个特殊子区域是"图例区"：它包含一个 3x3 的小型方位映射表。该表的中心像素为 grey，上、下、左、右四个正交邻居各为一种不同颜色（如上=red、下=blue、左=green、右=yellow），四个对角邻居为 black。这构成了方位到颜色的映射。
- 其余每个子区域包含：一个由某种前景色绘制的小型图案（形状各异，如 L 形、T 形、十字形等），以及 1 到 2 个 maroon 标记像素。标记像素位于图案 bounding box 之外，处于图案的某个方位（正上方、正下方、正左方、正右方）。

Rule:
- 从图例区读取方位-颜色映射：上→C1，下→C2，左→C3，右→C4。
- 对每个非图例子区域，确定其 maroon 标记点相对于图案 bounding box 中心的方位（上/下/左/右，取标记点与 bounding box 中心的主方向）。
- 如果只有一个标记点，直接查映射得到颜色。
- 如果有两个标记点且方位不同，取两个方位在图例中对应颜色的"混合"规则：在图例 3x3 表中，两个方位之间的对角位置如果为 black，则混合色为 orange；实际上简化为：两个标记都查表得到颜色，取在图例中顺时针方向排在前面的那个颜色。
- 用最终确定的颜色替换该子区域中图案的所有像素（替换原图案色），移除 maroon 标记像素。

Key insight:
解题者必须先识别出图例区并理解其编码的方位-颜色映射，然后对每个子区域判断标记相对于图案的方位，最后通过查表完成重着色——这是一个"发现编码表→解读方位→查表着色"的三层推理链。
</description>
</new_puzzle>

<description>
将网格中每个多色条纹矩形沿其内部条纹方向"展开"为一维色带，再按色带长度从短到长依次堆叠到输出网格的底部。

Input structure:
- 背景为 black。
- 网格中散布着若干互不重叠的实心矩形，每个矩形内部由平行的单像素宽彩色条纹组成（条纹方向为水平或垂直）。每个矩形的条纹颜色序列各不相同，且同一矩形内可包含多种颜色。矩形的另一个维度（垂直于条纹方向）上每行/列的颜色相同，即条纹在该方向上重复。
- 每个矩形的条纹方向可通过观察得出：沿条纹方向上颜色变化，垂直于条纹方向上颜色不变。

Rule:
- 对每个矩形，识别其条纹方向。
- 沿条纹方向读取颜色序列（从左到右或从上到下），得到一个一维色带，色带长度等于矩形在条纹方向上的像素数。
- 将所有矩形的色带按长度从短到长排序。
- 输出网格的宽度等于最长色带的长度，高度等于色带总数。
- 从输出网格的最底行开始，将最短的色带水平放置（左对齐），然后依次向上堆叠更长的色带，每个色带占一行。未被色带覆盖的单元格保持 black。

Key insight:
每个矩形看起来是二维的彩色块，但其信息实质是一维的条纹序列——解题者需要发现条纹方向的判定方法（沿哪个轴颜色变化），将二维矩形"压缩"为一维色带，再发现输出中色带按长度排序堆叠的规律。这是"维度压缩→排序→重排列"的三步推理。
</description>

<description>
在网格中找到每对同色标记像素，将它们视为一条隐含折线的两个端点，沿先水平后垂直的 L 形路径着色；当两条不同颜色对的路径交叉时，交叉点使用统一的交叉指示色。

Input structure:
- 背景为 black。
- 网格中有若干成对出现的彩色标记像素。每种非 black 颜色恰好出现两个像素，构成一对端点。不同颜色对之间互不相同（如一对 red、一对 blue、一对 green 等）。
- 端点之间的连线是轴对齐的折线（先水平再垂直的 L 形路径）：从左侧端点出发先水平移动到与右侧端点同列，再垂直移动到右侧端点。如果两个端点在同一行或同一列，则连线为直线段。

Rule:
- 对每对同色端点，确定左侧端点（列号较小者）和右侧端点。
- 绘制 L 形路径：从左侧端点沿水平方向画到右侧端点所在列，再从该列沿垂直方向画到右侧端点。路径上的所有 black 像素用该对的颜色填充。
- 如果某个像素同时位于两条不同颜色的路径上（交叉点），该像素填充为 yellow（作为固定的交叉指示色）。
- 端点像素本身保持原色不变。

Key insight:
解题者首先需要发现同色像素成对出现的规律，然后推断出连线方式是"先水平后垂直"的 L 形路径而非直线，最后发现交叉点使用统一的特殊颜色——路径生成规则的不对称性（先水平后垂直，而非先垂直后水平）是核心隐蔽点，必须从多个样例中归纳。
</description>

<new_puzzle>
<description>
在包含多个嵌套矩形框的网格中，根据每层框的开口方向依次传递一个彩色标记，标记最终停在最内层框中，其在最内层的放置位置由所有经过的开口方向序列决定。

Input structure:
- 背景为 black。
- 网格中有若干层同心嵌套的单像素厚矩形框，每层框使用不同颜色（如最外层 grey、次外层 blue、再内层 red 等）。
- 每个框恰好有一个单像素宽的开口（缺口），位于框的上、下、左或右边的中间位置。不同层框的开口方向各不相同。
- 在最外层框的外部，紧邻开口位置处有一个 maroon 标记像素。

Rule:
- 标记从最外层框的开口进入，进入后放置在开口正对的框内侧第一个 black 像素位置。
- 然后观察下一层（更内层）框的开口方向：标记从当前位置沿该开口方向移动，穿过该层框的开口，到达该层框内侧的第一个 black 像素。
- 重复此过程直到标记进入最内层框。
- 输出中，仅在标记的最终位置绘制 maroon 像素，清除标记的起始位置，所有框保持不变。

Key insight:
每层框的开口方向构成一个隐含的方向指令序列；解题者需要发现嵌套层级关系和"开口即通道"的传递机制，然后逐层追踪标记的路径——难点在于每一层的移动方向不由标记当前位置决定，而由下一层框的开口位置决定，形成"读取下一层开口→移动→进入→再读取"的多层递进推理。
</description>
</new_puzzle>
