根据框架颜色从色带中选取填充色，再按框架内种子像素的位置决定填充方向，生成半填充矩形。

Input structure：
- 背景为 black。网格顶部有一行水平色带，由若干不同颜色的连续色段组成，每段宽度不等，色段之间无间隔。
- 网格其余区域散布若干空心矩形框架，每个框架由单一颜色绘制（框架颜色一定出现在顶部色带中）。
- 每个框架内部恰好有一个 grey 种子像素，位于框架内部的上半部分或下半部分。

Rule：
- 对于每个框架，在顶部色带中找到与框架颜色相同的色段，读取该色段在色带中的左邻色段的颜色作为填充色（若框架颜色是色带最左色段，则取最右色段的颜色作为填充色，形成循环）。
- 若 grey 种子像素位于框架内部空间的上半部分，则用填充色填满框架内部的下半部分（从框架内底边向上填充至中线）。
- 若 grey 种子像素位于框架内部空间的下半部分，则用填充色填满框架内部的上半部分（从框架内顶边向下填充至中线）。
- 若框架内部高度为奇数，中间行不填充。填充完成后移除所有 grey 种子像素。

Key insight：
- 需要两层推理：第一层是通过框架颜色在色带中查表获取填充色（色带充当颜色映射图例，且映射关系是"取左邻"而非直接对应）；第二层是种子像素的位置决定填充发生在对侧——种子标记的是空白侧而非填充侧。
</description>

<description>
将分散的彩色碎片按形状互补关系配对拼合，拼合后的颜色由碎片面积大小决定。

Input structure：
- 背景为 azure。网格中散布若干 4-连通的不规则彩色碎片对象，每个碎片的颜色各不相同。
- 这些碎片可以两两配对：同一对中的两个碎片形状互补，即将其中一个碎片旋转 180 度后与另一个碎片拼合，恰好构成一个无空洞的实心矩形。
- 每个碎片恰属于一对，不存在落单碎片。

Rule：
- 识别所有互补配对：对每个碎片，找到另一个碎片使得将后者旋转 180 度后可与前者无重叠、无缝隙地拼成一个实心矩形。
- 对每一对碎片，比较二者的像素面积。面积较大的碎片保留自身颜色，面积较小的碎片改为面积较大碎片的颜色。
- 将较小碎片旋转 180 度后平移至较大碎片旁边，拼合成完整矩形。拼合位置为较大碎片的包围盒扩展区域，使二者紧密贴合。
- 若两碎片面积相等，则两者都保留位于网格中行号较小（更靠上）的那个碎片的颜色，较下方的碎片移动到较上方碎片处拼合。

Key insight：
- 第一层推理是发现碎片之间的形状互补关系——需要在心中旋转 180 度并检查是否能拼成矩形；第二层推理是发现面积比较决定颜色归属的规则，这不是简单的保留或替换，而是"大吃小"的竞争逻辑。
</description>

<description>
根据封闭区域内标记像素的颜色从网格边缘对应方向向内发射射线，射线在碰到障碍时停止并改变障碍物颜色。

Input structure：
- 背景为 black。网格中有若干由 grey 像素构成的封闭多边形轮廓（4-连通闭合环）。
- 每个封闭区域内部恰好有一个彩色标记像素（非 grey、非 black），颜色为 red、blue、green 或 yellow 之一。
- red 代表"从右边缘向左"，blue 代表"从上边缘向下"，green 代表"从左边缘向右"，yellow 代表"从下边缘向上"。
- 封闭区域外部可能有一些零散的 orange 像素作为障碍物。

Rule：
- 对每个封闭区域，读取其内部标记像素的颜色以确定射线方向。
- 从标记像素所在行（若方向为水平）或所在列（若方向为垂直）的对应网格边缘出发，沿指定方向发射一条标记颜色的射线。
- 射线覆盖沿途所有 black 背景像素，将其变为标记颜色。
- 射线碰到 grey 轮廓像素或 orange 障碍像素时停止（不覆盖该像素）。
- 射线停止后，将其碰到的那个阻挡像素（grey 或 orange）的颜色改为 maroon。
- 封闭区域内部的标记像素保留不变。

Key insight：
- 第一层推理是建立颜色与方向的映射关系（需要从多个样例中归纳出四种颜色分别对应哪个方向）；第二层是理解射线从网格边缘（而非从标记像素本身）发射，标记像素仅用于确定行/列和方向；第三层是发现射线终止时会将阻挡物染为 maroon，这是一个容易被忽略的输出细节。
</description>

<description>
在分隔线划分的多个子区域中，根据每个区域内对象的朝向关系，决定将哪些对象的颜色替换为其镜像区域中对应对象的颜色。

Input structure：
- 背景为 black。网格被一条水平 maroon 分隔线和一条垂直 maroon 分隔线切分为四个象限。
- 每个象限内恰好有若干个由单色像素组成的 L 形三格对象（L-triomino），每个 L 形占据一个 2x2 区域中的三个格子，缺失一个角。
- 四个象限中的 L 形对象在位置上关于分隔线交叉点呈镜像对称排列（即左上象限的每个 L 形在其他三个象限都有一个镜像位置上的对应 L 形）。
- 但每组四个对应 L 形的缺失角朝向可能不同，颜色也可能不同。

Rule：
- 对每组四个对称位置上的 L 形对象，检查它们的缺失角朝向。
- 找出每组中缺失角朝向与该组其余三个 L 形不同的那一个"异类"L 形（保证每组恰好有一个异类）。
- 将该异类 L 形的颜色替换为同组中与它关于垂直分隔线对称的那个 L 形的颜色。
- 异类 L 形的形状（朝向）保持不变，仅改变颜色。
- 非异类 L 形保持不变。

Key insight：
- 第一层推理是识别四象限镜像对称结构并建立对象的配对/配组关系；第二层推理是发现"缺失角朝向"作为判定异类的标准——需要比较同组四个 L 形的朝向而非颜色来确定谁是异类；第三层是确定颜色替换的来源——不是随机选一个同组对象，而是特指水平镜像（垂直轴对称）位置的对象。
</description>

<description>
将网格中的连通管道路径提取出来，根据路径经过的转弯次数在路径终点生成对应长度的刻度标记。

Input structure：
- 背景为 black。网格中有若干条互不相连的 4-连通单色路径（管道），每条路径宽度为 1 像素，颜色各不相同。
- 每条路径恰好有两个端点（度数为 1 的像素）。其中一个端点紧贴网格边缘（位于第 0 行、最后一行、第 0 列或最后一列），称为"入口端"；另一个端点在网格内部，称为"出口端"。
- 路径可包含直线段和直角转弯，但不包含分支。
- 网格中还有一些零散的 grey 像素不与任何路径相连，作为干扰。

Rule：
- 对每条路径，沿路径从入口端到出口端行走，统计路径中方向发生 90 度变化的次数（即转弯次数 T）。
- 在出口端的位置，沿路径最后一段的延伸方向，用 red 像素画一条长度为 T 的直线段（从出口端的下一个格子开始，不覆盖出口端本身）。
- 若延伸方向超出网格边界，射线在边界处截断。
- 原始路径和 grey 干扰像素保持不变。

Key insight：
- 第一层推理是识别管道路径结构并区分入口端和出口端（一端靠边缘、一端在内部）；第二层推理是发现 red 标记的长度编码了路径的转弯次数——这需要解题者对每条路径手动追踪并计数转弯，然后验证转弯数与输出中 red 线段长度的对应关系。
</description>

<description>
从嵌套框架的层级结构中提取深度信息，用深度值决定框架内部的棋盘格填充密度。

Input structure：
- 背景为 black。网格中有若干嵌套的空心矩形框架，框架由不同颜色绘制。
- 框架可以嵌套：一个框架完全包含在另一个框架内部。最外层框架不被任何其他框架包含，嵌套深度为 1；被一层框架包含的深度为 2，以此类推。
- 每个框架的内部区域在输入中为 black（空白）。
- 框架之间不重叠、不接触，每层嵌套之间至少间隔 1 像素。

Rule：
- 计算每个框架的嵌套深度 D（最外层为 1，往内依次递增）。
- 在每个框架的内部空白区域（不含框架本身的像素），用该框架自身的颜色绘制棋盘格图案：从框架内部左上角开始，每隔 D-1 个像素放置一个该颜色的像素（即步长为 D）。具体而言，对于框架内部坐标 (r, c)（相对于内部左上角），当 r 和 c 都能被 D 整除时，放置一个像素。
- 深度为 1 的最外层框架步长为 1，即内部完全填满自身颜色。
- 若某个内部像素位置属于更内层框架的区域（包括更内层框架的边框），则不绘制外层框架的棋盘点——内层框架区域优先。

Key insight：
- 第一层推理是识别嵌套层级关系并为每个框架确定深度值；第二层推理是发现填充密度与嵌套深度之间的反比关系——深度越深的框架，棋盘格点越稀疏（步长越大），这需要解题者观察不同层级框架内部填充点的间距规律并归纳出"步长等于深度"的量化关系。
</description>

<description>
根据种子颜色在颜色环上的顺序，沿螺旋路径向外生成渐变色带，色带的旋转方向由种子的位置决定。

Input structure：
- 背景为 black。网格中央附近有一个由 3 到 5 个不同颜色像素排成的短直线段（水平或垂直），称为"种子序列"。
- 种子序列中的颜色均取自固定颜色环：red -> orange -> yellow -> green -> azure -> blue -> magenta -> red（循环）。
- 种子序列中相邻像素的颜色在颜色环上相邻。
- 网格其余区域为 black 背景。

Rule：
- 读取种子序列的排列方向和颜色顺序，判断颜色在颜色环上是顺时针推进还是逆时针推进。
- 从种子序列的末尾像素开始，沿矩形螺旋路径向外延伸。螺旋旋转方向与颜色环推进方向一致（颜色环顺时针则螺旋顺时针展开）。
- 螺旋路径上每个新像素的颜色为前一个像素在颜色环上的下一个颜色（按已确定的顺/逆时针方向）。
- 螺旋持续展开直到触及网格边缘，超出边界的像素不绘制。
- 种子序列本身保留不变。

Key insight：
- 第一层推理是从种子序列中识别出颜色环上的行进方向（顺时针或逆时针），这要求解题者心中建立颜色环模型并判断序列的遍历方向；第二层推理是理解螺旋展开的旋转方向与颜色环方向绑定，且每步颜色都沿颜色环递进——需要同时追踪空间路径和颜色序列两条线索。
</description>
</new_puzzle>
