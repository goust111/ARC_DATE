- `Input structure`：
  - Azure 背景上放置若干互不重叠的 3×3 区域。
  - 每个 3×3 区域中恰好有一个角落像素为背景色（缺角），其余 8 个像素为同一种非背景色，形成 L 形。
  - 网格四个角落区域各有一个 2×2 的黑色方块作为"目标槽"。

- `Rule`：
  - 第一步：识别每个 L 形的缺角位置（左上、右上、左下、右下），缺角位置指示该 L 形应被发送到网格的哪个角落——缺角在左上则发送到左上角目标槽，以此类推。

  - 第三步：原始 L 形从其原位置被擦除为背景色。

- `Key insight`：缺角的位置同时编码了两个信息——目标角落和旋转方向；解题者需要先发现缺角与角落的对应映射关系，再理解 L 形如何被简化投影到 2×2 槽中。
</new_puzzle>

- `description`：识别网格中由同色像素围成的嵌套封闭区域，将区域内部按"嵌套深度"交替填色——奇数层填 Red，偶数层填 Blue。

- `Input structure`：
  - Grey 背景上有若干由 Green 像素绘制的一像素宽嵌套封闭矩形轮廓。
  - 矩形可以多层嵌套（如一个矩形内部包含另一个矩形，后者内部又包含更小的矩形），嵌套深度为 1 到 4 层不等。
  - 矩形之间不交叉，同一层级的矩形之间互不接触。
  - 所有矩形轮廓之间及内部初始均为 Grey 背景。

- `Rule`：
  - 第一步：确定每个 Grey 背景连通区域被 Green 轮廓包围的层数（最外层为第 0 层，即完全不被任何轮廓包围的区域）。
  - 第二步：第 0 层（最外层背景）保持 Grey 不变。
  - 第三步：第 1 层（被恰好一层轮廓包围的区域）填充为 Red。
  - 第四步：第 2 层填充为 Blue，第 3 层填充为 Red，第 4 层填充为 Blue……奇数层 Red、偶数层 Blue 交替。
  - 第五步：Green 轮廓像素本身保持不变。

- `Key insight`：解题者需要识别嵌套轮廓的"拓扑深度"——不是几何距离而是被包围的层数——然后应用交替着色规则。关键在于区分"视觉上处于内部"和"被几层轮廓包围"是不同的概念，且所有轮廓都是严格封闭的，因此深度由包围层数唯一确定。
</new_puzzle>

- `Input structure`：
  - 黑色背景上分布若干彩色小型多联骨牌形状（3-5 个像素组成的 4-连通块），每个颜色各不相同，称为"钥匙"。

  - 钥匙的数量与锁孔的数量相同，每把钥匙恰好匹配一个锁孔。

- `Rule`：
  - 第一步：对每把彩色钥匙，尝试 0°、90°、180°、270° 四种旋转，检查哪个锁孔（Grey 框边缘的凹陷缺口）与旋转后的钥匙形状完全吻合。

  - 第四步：Grey 框本身及其他所有像素保持不变。

- `Key insight`：解题者需要完成两层推理：首先通过形状互补（而非颜色或位置）来建立钥匙与锁孔的配对关系，这需要考虑旋转变换；然后执行"插入"操作——填充缺口而非叠放钥匙。难点在于锁孔的凹陷形状不是直接画出来的，而是通过 Grey 框边缘的缺失像素隐式呈现的，解题者必须从"负空间"中识别出目标形状。

- `Input structure`：
  - Azure 背景上有若干由彩色像素绘制的封闭矩形轮廓，每个轮廓恰好由两种颜色交替构成——水平边（上边和下边）为一种颜色，垂直边（左边和右边）为另一种颜色，四个角像素的颜色与其所在水平边的颜色一致。

- `Rule`：
  - 第一步：对每个封闭矩形轮廓，识别其水平边和垂直边分别使用的两种颜色，构成一个颜色对（顺序无关）。
  - 第二步：在色表中找到与该颜色对匹配的 2×2 方块（左列和右列颜色与轮廓的两种边颜色对应），读取其右侧的指示色。
  - 第三步：用指示色作为填充色，将该矩形轮廓内部所有 Azure 像素替换为指示色。
  - 第四步：轮廓本身和色表保持不变。

- `Key insight`：解题者面临三层推理：首先需要观察到矩形轮廓的水平边与垂直边使用不同颜色这一结构特征；然后发现角落色表中的颜色对与轮廓颜色对之间的对应关系；最后理解指示色才是填充色的来源。轮廓颜色本身不直接决定填充色，必须经过色表查找这个间接环节。
</new_puzzle>

- `description`：沿每个彩色线段的延长线方向寻找同色配对线段，在两条配对线段之间的中点位置绘制一条与原线段垂直的同色连接桥，桥的长度等于配对线段之间的间隔距离。

- `Input structure`：
  - 黑色背景上散布若干条短直线段（长度 2-4 像素），每条线段沿水平或垂直方向，颜色各异。
  - 同色线段恰好成对出现，且每对同色线段严格共线（在同一行或同一列上），方向相同，中间隔有黑色间隔。
  - 不同颜色的线段对之间互不共线。

- `Rule`：
  - 第一步：识别每对同色共线线段。
  - 第二步：计算每对线段之间的黑色间隔像素数 N。
  - 第三步：找到间隔的正中间位置（若 N 为偶数，取靠近第一条线段一侧的中间位置）。
  - 第四步：在该中间位置绘制一条垂直于原线段方向的"桥"，桥的颜色与配对线段相同，桥的长度为 N 个像素，以中间位置为中心向两侧等长延伸（若 N 为奇数，两侧各 (N-1)/2 像素加中心共 N 像素）。
  - 第五步：原始线段保持不变。

- `Key insight`：解题者需要先通过颜色和共线性发现线段配对关系，再观察到连接桥的方向是垂直于原线段方向的（而非沿线段方向填充间隔），最后归纳出桥的长度等于间隔距离这一非显然的映射规则——间隔距离被"旋转 90°"变成了桥的长度。
</new_puzzle>

- `description`：将散落的彩色碎片按颜色归组，每组碎片拼合后恰好填满对应颜色边框的内部空腔。

- `Input structure`：
  - 黑色背景上有若干由不同颜色绘制的一像素宽矩形边框（如 Red 边框、Blue 边框、Green 边框等），每个边框内部有一个不规则形状的空腔（由黑色像素构成），空腔形状各不相同。
  - 矩形边框之外的区域散落着若干小型彩色碎片（每个碎片为 1-4 像素的 4-连通块）。每个碎片的颜色与某个边框的颜色相同。
  - 同一颜色的所有碎片合在一起，其形状恰好能无缝拼合成对应边框内部空腔的形状（不需要旋转或翻转，只需平移）。

- `Rule`：
  - 第一步：按颜色将碎片分组，并找到同色的矩形边框。
  - 第二步：将每组碎片平移到对应边框的内部空腔中——碎片之间的相对位置保持不变，整组碎片作为一个整体平移，使其恰好填满空腔。
  - 第三步：碎片填入空腔后，其原始位置被擦除为黑色。
  - 第四步：边框及其他像素保持不变。

- `Key insight`：解题者需要完成两层推理：第一层是通过颜色匹配建立碎片组与边框的对应关系；第二层是意识到同色碎片之间的相对空间布局已经预先编码了它们在空腔中的排列方式——碎片不需要重排，只需整体平移即可完美嵌入，而这个"相对位置不变"的约束是从样例中需要归纳出的隐藏规则。
</new_puzzle>
