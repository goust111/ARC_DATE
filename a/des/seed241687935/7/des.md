- `description`：根据彩色锚点之间的连线穿过封闭区域的情况，用连线颜色填充被穿过的区域。

- `Input structure`：
  - 背景为 black。
  - 网格中散布若干个由单一颜色像素围成的封闭矩形区域（每个区域使用不同颜色，如 blue、green、red 等），区域内部为 black。
  - 网格边缘或空白区域中有若干对同色的锚点像素（每种锚点颜色恰好出现两个，颜色与区域边框颜色不同，如 yellow、magenta 等）。
  - 每对同色锚点在同一行或同一列上。

- `Rule`：
  - 第一步：对每对同色锚点，沿它们所在的行或列画一条直线段连接两个锚点（线段颜色与锚点颜色相同）。
  - 第二步：检查每条连线是否穿过某个封闭矩形区域的内部（即连线经过该矩形边框并进入内部区域）。
  - 第三步：对于被某条连线穿过的封闭矩形区域，将该区域内部所有 black 像素填充为该连线的颜色。如果一个区域被多条连线穿过，则填充最先（从左到右、从上到下扫描锚点对顺序）穿过它的连线颜色。
  - 未被任何连线穿过的区域内部保持 black。连线本身保留在输出中，矩形边框保持不变。

- `Key insight`：锚点对定义了隐含的直线路径，解题者需要先推断连线的存在，再判断哪些封闭区域被这些连线穿透，最后用连线颜色填充被穿透的区域内部。核心难点在于"穿过"这一空间关系需要从样例中归纳，而非简单的包含或邻接。

- `description`：将网格中散落的彩色碎片按形状互补关系配对拼合，然后按拼合后矩形的面积从大到小排列输出。

- `Input structure`：
  - 背景为 black。
  - 网格中散布偶数个彩色碎片（4-connected 连通分量），每个碎片为单一颜色。
  - 碎片两两配对：每对碎片的形状互补——即将两块碎片无旋转无翻转地平移拼在一起，恰好填满一个无缝隙的矩形。
  - 同一对中的两个碎片颜色不同。

- `Rule`：
  - 第一步：识别所有碎片，并找到形状互补的配对关系。具体判定方式：对于每个碎片 A，将其紧凑包围盒中 A 未占据的像素集合作为 A 的"互补形状"；若另一碎片 B 的紧凑形状与 A 的互补形状完全一致（不旋转不翻转），则 A 和 B 互补配对，拼合后形成一个矩形。
  - 第二步：对每一对互补碎片，将它们拼合为完整矩形，矩形中每个像素保留其原始碎片的颜色。
  - 第三步：将所有拼合后的矩形按面积（像素总数）从大到小排列，从输出网格左上角开始水平排列，矩形之间留一列 black 间隔，所有矩形的顶边对齐输出网格的顶边。输出网格高度等于最高矩形的高度，宽度等于所有矩形宽度之和加上间隔列数。

- `Key insight`：解题者需要先发现"互补拼合"这一配对机制——碎片不是按颜色或位置配对，而是按形状的负空间匹配；然后需要发现输出的排列顺序由拼合后矩形的面积决定。两步推理缺一不可。
</new_puzzle>

- `Input structure`：
  - 背景为 azure。
  - 网格中有若干个由 grey 像素围成的封闭矩形围栏（一像素厚的边框），每个围栏内部恰好有一个彩色种子像素（颜色各不相同，如 red、blue、green 等），其余内部为 azure。

- `Rule`：
  - 第一步：对每个 grey 围栏，找到其内部的种子像素颜色 c。
  - 第二步：在围栏外的模板库中找到颜色为 c 的模板，提取其紧凑包围盒内的图案形状（即哪些位置有颜色 c 的像素）。
  - 第三步：计算围栏内部可用空间（不含边框）的尺寸，确定一个整数缩放因子 k，使得模板按 k 倍放大后恰好填满围栏内部（每个模板像素变为 k*k 的块）。
  - 第四步：将缩放后的模板图案以颜色 c 填入围栏内部，azure 区域保持 azure。围栏边框本身保持 grey 不变。种子像素所在位置按缩放后模板图案决定是 c 还是 azure。模板库中的原始模板在输出中被清除为 azure。

- `Key insight`：解题者需要三层推理：首先发现种子颜色与模板颜色的对应关系；其次发现围栏尺寸与模板尺寸之间存在整数倍缩放关系；最后理解模板需要按该倍率放大后填入围栏内部。种子像素既是颜色索引又暗示了填充操作的存在。

- `Input structure`：
  - 背景为 black。
  - 网格中有若干个彩色对象，每个对象为单一颜色的 4-connected 连通分量，颜色各不相同。
  - 每个对象可能包含 0 到 3 个内部孔洞（孔洞指被该对象像素完全包围的 black 连通区域）。
  - 网格中有一个由 maroon 像素绘制的箭头标记。箭头由一条长度为 3 的直线段（水平或垂直）加上一端的三角形箭尖组成：若箭头朝右，则为三个水平像素加上右端上下各一个像素形成">"形；朝左则为三个水平像素加上左端上下各一个像素形成"<"形；朝下则为三个垂直像素加上下端左右各一个像素形成"v"形；朝上则为三个垂直像素加上上端左右各一个像素形成"^"形。

- `Rule`：
  - 第一步：识别箭头方向 d（上/下/左/右）。
  - 第二步：对每个彩色对象（不含箭头），数出其内部孔洞数量 n。
  - 第三步：若 n = 0，该对象保持原位不变，不产生副本。若 n >= 1，沿方向 d 在该对象旁边依次放置 n 个该对象的完整副本（包括孔洞）。第一个副本紧邻原对象在方向 d 上的边缘（间隔一行或一列 black），第二个副本紧邻第一个副本（同样间隔一行或一列），以此类推。副本颜色与原对象相同。
  - 箭头在输出中被清除为 black。所有对象的副本不会互相重叠（题目保证有足够空间）。

- `Key insight`：解题者需要发现两个独立的隐含规则：一是箭头标记决定全局复制方向（一个非平凡的符号解读），二是每个对象的孔洞数量决定复制次数（一个需要仔细观察的计数属性）。两层推理相互独立又必须同时正确才能得到输出。
</new_puzzle>

- `description`：将重叠的彩色十字形按遮挡关系排出前后顺序，然后按该顺序从外到内绘制同心十字环。

- `Input structure`：
  - 背景为 black。
  - 网格中有若干个不同颜色的十字形对象互相重叠。每个十字形由一个中心像素向上下左右各延伸相同长度的臂组成（即"+"形），每个十字臂宽为一像素。
  - 不同十字形的臂长可能不同。
  - 在重叠区域，某个十字形的颜色覆盖了另一个十字形的颜色，形成遮挡关系。每种颜色仍有足够可见像素来推断其完整的十字形范围（中心位置和臂长）。

- `Rule`：
  - 第一步：通过每种颜色可见像素的分布，还原每个十字形的完整形状（中心位置和臂长）。具体方法：对于每种颜色，找到其所有可见像素；十字中心是该颜色像素在水平和垂直方向交叉的那个像素；臂长为从中心到该颜色最远可见像素的距离。
  - 第二步：在重叠位置，可见颜色遮挡了隐藏颜色，建立有向遮挡图：若 A 的十字范围与 B 的十字范围重叠且重叠处显示 A 的颜色，则 A 遮挡 B（A 在 B 前面）。
  - 第三步：对遮挡图进行拓扑排序，得到从最前面到最后面的颜色顺序（假设有 n 种颜色）。
  - 第四步：输出一个边长为 2n-1 的正方形网格，绘制同心十字环。中心像素位于网格正中。最后面（最底层）的颜色画最外层十字（臂长为 n-1），下一层画臂长为 n-2 的十字居中叠加，依此类推，最前面的颜色画最内层即中心单像素。后画的覆盖先画的。

- `Key insight`：输入中的十字形位置和大小是干扰项，真正需要提取的信息是遮挡关系所隐含的前后顺序。解题者必须先理解如何从重叠像素中重建完整十字并推导遮挡方向，然后发现输出结构是一个与输入布局完全无关的同心十字环——层级由遮挡深度决定。
</new_puzzle>

- `description`：根据彩色路径穿越分隔线的顺序，对路径经过的子区域进行着色。

- `Input structure`：
  - 背景为 black。
  - 网格中有一条由 grey 像素构成的完整水平分隔线，将网格分为上下两个区域。
  - 上方区域和下方区域各自被若干条 grey 竖直线段进一步划分为若干个矩形子区域（竖直线段从分隔线延伸到网格边缘）。所有子区域内部为 black。
  - 一条由多种颜色组成的路径（4-connected，宽度为一像素）从网格左边缘某处开始，蜿蜒穿过各个子区域，穿越 grey 分隔线和竖直线段（穿越处 grey 像素被路径颜色覆盖），最终到达网格右边缘。路径在每个子区域内的部分使用同一种颜色，进入下一个子区域时颜色改变。

- `Rule`：
  - 第一步：沿路径从左边缘起点到右边缘终点逐像素追踪，记录路径依次穿过的每个子区域及其在该区域中的颜色。
  - 第二步：对于路径经过的每个子区域，将该子区域中所有 black 背景像素填充为路径在该区域中的颜色。
  - 第三步：路径本身的像素保留原色不变，grey 分隔线和竖直线段中未被路径覆盖的部分保持 grey。
  - 路径未经过的子区域保持 black 不变。

- `Key insight`：解题者需要首先发现路径的颜色在穿越区域边界时会改变（即颜色与区域绑定而非与路径段绑定），然后理解每个区域的填充色由穿过它的路径段颜色决定。难点在于路径可能多次穿越同一条分隔线（上下来回），解题者需要追踪完整路径才能确定每个区域对应的颜色。
</new_puzzle>

- `description`：将散落的单色碎片旋转拼入中央模具的凹槽中，拼入后碎片颜色由凹槽边缘的标记色决定。

- `Input structure`：
  - 背景为 black。
  - 网格中央有一个由 grey 像素构成的大型实心矩形"模具"，模具的边缘被挖去若干个不规则的凹槽（凹槽是模具边缘向内凹陷的连通 black 区域）。每个凹槽在模具边缘的入口处有一个彩色标记像素（颜色各不相同，如 red、blue、green、yellow 等），该标记像素位于凹槽相邻的 grey 像素位置上（即将该 grey 像素替换为标记颜色）。
  - 网格四周散布若干个单色碎片（每个碎片为 orange 色的 4-connected 连通分量）。碎片数量等于凹槽数量。

- `Rule`：
  - 第一步：对每个凹槽，提取其形状（凹槽内 black 区域的紧凑包围盒内的像素图案）。
  - 第二步：对每个 orange 碎片，尝试 0 度、90 度、180 度、270 度四种旋转，找到唯一一个凹槽使得碎片旋转后的形状与凹槽形状完全吻合。
  - 第三步：将碎片旋转到正确角度后平移填入对应凹槽中。填入后碎片的颜色不再是 orange，而是变为该凹槽入口处标记像素的颜色。
  - 第四步：输出中模具保持 grey，凹槽被填满后显示对应标记颜色，标记像素恢复为 grey（因为凹槽已填满，标记不再需要）。散落碎片的原始位置变为 black。

- `Key insight`：解题者需要完成三层推理：首先识别凹槽与碎片之间的形状匹配关系（需考虑旋转）；其次发现标记像素的颜色决定了碎片填入后的重着色；最后理解标记像素本身在输出中被还原为模具颜色。碎片的原始颜色（统一的 orange）是干扰项，真正的输出颜色由凹槽标记决定。
</new_puzzle>
