<new_puzzle>
描述：根据封闭围栏内部"种子"像素的颜色，在围栏的缺口方向生长出与种子数量等长的彩色枝条，枝条颜色由围栏外的调色板色块决定。

Input structure:
- bg = 最常见颜色（如 black）。
- 网格中散布若干由同一颜色（如 green）绘制的小型封闭矩形围栏（宽度为 1 像素的矩形环），每个围栏的某一侧有一个 1 像素宽的缺口（缺口位置可在上、下、左、右任一侧）。
- 每个围栏内部包含若干散落的"种子"像素，这些种子的颜色各异但同一围栏内所有种子同色。
- 网格边缘区域有一排调色板色块：每个色块由两行组成，上行是一个颜色 A 的像素，下行紧贴一个颜色 B 的像素，表示"种子颜色 A → 枝条颜色 B"的映射关系。

Rule:
- 对每个围栏，找到其唯一缺口所在的方向。
- 数出围栏内部种子像素的个数 N（N ≤ 8）。
- 在调色板中查找与种子颜色匹配的条目，获取对应的枝条颜色。
- 从缺口位置开始，沿缺口朝外的方向绘制一条长度为 N 的直线，颜色为查找到的枝条颜色。
- 围栏、种子和调色板保持不变。

Key insight: 解题需要两层独立归纳——第一层是发现调色板的颜色映射关系（上下配对），第二层是发现枝条长度由围栏内种子数量决定而非围栏大小或其他属性决定。两层规则都不显然，需要跨样例对比才能确认。
</new_puzzle>

<new_puzzle>
描述：将网格中散落的单色碎片拼入颜色匹配的框架槽位中，拼入时需要根据框架槽位边缘的方向标记对碎片进行旋转。

Input structure:
- bg = 最常见颜色（如 black）。
- 网格中有若干大型矩形"框架"，每个框架由某种颜色（如 blue）的像素绘制成中空的矩形边框，内部为 bg，框架内部恰好有一个与框架内腔尺寸完全相同的矩形区域为空（即槽位）。
- 每个框架的某一条外侧边上附着一个 1 像素的标记点，标记点颜色为 red。标记点的位置指示方向：位于框架顶边外侧表示"上"、底边外侧表示"下"、左边外侧表示"左"、右边外侧表示"右"。
- 网格中另有若干小型单色碎片（形状不规则，连通），每个碎片的颜色与某个框架的边框颜色相同。碎片的包围盒尺寸与对应框架的内腔尺寸之一匹配（可能需要旋转 0°、90°、180° 或 270°）。
- 每个碎片也有一个 red 标记点附着在碎片的某一侧外缘。

Rule:
- 通过颜色将每个碎片与对应框架配对。
- 旋转碎片，使得碎片上 red 标记点相对于碎片的方位与框架上 red 标记点相对于框架的方位一致（例如框架标记在顶边，则碎片标记也旋转到顶边）。
- 将旋转后的碎片平移至框架的内腔中，使碎片的包围盒与内腔对齐。
- 擦除碎片原始位置的所有像素（含其 red 标记点），框架上的 red 标记点也擦除。

Key insight: 颜色匹配只是第一步；关键的第二层推理是发现 red 标记点在碎片和框架上的相对位置编码了旋转角度——解题者需要归纳出"标记点朝向必须对齐"这一非显然规则。
</new_puzzle>

<new_puzzle>
描述：将网格中由彩色线段构成的"电路"按信号源的颜色进行染色，信号在交叉节点处根据节点内部小标记的朝向选择转弯方向继续传播。

Input structure:
- bg = 最常见颜色（如 black）。
- 网格中有若干条由 grey 像素绘制的水平和垂直直线段（宽度 1 像素），它们相互交叉形成网络。线段之间通过共享像素相连。
- 在两条线段交叉的位置（即某个 grey 像素同时属于一条水平线和一条垂直线），该交叉像素被替换为一个 2×2 的小方块。小方块的 4 个像素中，3 个为 grey，1 个为 orange。orange 像素在 2×2 方块中的位置指示转弯方向：左上表示"从水平转向上方/从垂直转向左方"，右上表示"从水平转向上方/从垂直转向右方"，左下表示"从水平转向下方/从垂直转向左方"，右下表示"从水平转向下方/从垂直转向右方"。
- 线段网络的某些末端（即线段不再延伸的端点处）有一个非 grey、非 orange 的彩色像素，作为"信号源"。每条线路最多有一个信号源。

Rule:
- 从每个信号源出发，沿其所在线段方向传播，将沿途的 grey 像素重新染为信号源的颜色。
- 当信号到达一个 2×2 交叉节点时，根据 orange 像素的位置决定信号转弯后沿哪个方向的线段继续传播（信号从节点的一个方向进入，orange 标记决定它从哪个垂直/水平方向离开）。交叉节点的 grey 像素也染为信号颜色，orange 像素保持不变。
- 信号传播直到到达线段末端（非信号源端）或遇到已被其他信号染色的像素时停止。
- 没有信号到达的 grey 像素保持 grey 不变。

Key insight: 解题包含三层推理——首先需要识别出 grey 线段网络的拓扑结构；其次需要发现 2×2 交叉节点中 orange 像素位置编码了转弯规则；最后需要理解信号从源头沿线段传播并在节点处按规则转向。仅凭一个样例难以区分 orange 标记的精确含义，需要多样例对比。
</new_puzzle>

<new_puzzle>
描述：根据网格中"窗户"图案上被遮挡的格子位置，从候选补丁库中选取正确的补丁填入，选择依据是补丁边缘轮廓与窗户缺损边缘的互补吻合。

Input structure:
- bg = 最常见颜色（如 black）。
- 网格左侧有一个大型"窗户"：由某种颜色（如 blue）绘制的规则方格图案，类似棋盘格或网格线。窗户中有一个矩形区域被 bg 覆盖（即被"打破"），形成一个洞。洞的边缘处，窗户图案被截断，留下不规则的锯齿状边缘轮廓。
- 网格右侧有若干候选"补丁"，每个补丁是一个与洞尺寸相同的矩形区域，由不同颜色绘制。每个补丁内部也有图案，其边缘处的图案形状各不相同。
- 候选补丁之间用 grey 分隔线隔开。

Rule:
- 检查窗户洞的四条边缘，提取窗户图案在边缘处被截断后留下的锯齿轮廓。
- 对每个候选补丁，检查其四条边缘的图案轮廓。
- 选择边缘轮廓与窗户洞的截断轮廓完全互补（即拼在一起恰好恢复完整图案）的补丁。
- 将选中的补丁填入洞中，补丁颜色变为窗户颜色（blue）。
- 未选中的补丁和分隔线从输出中擦除。

Key insight: 核心推理不是简单的形状匹配，而是需要理解"互补"的概念——补丁边缘的凸起必须对应窗户边缘的凹陷，就像拼图一样。解题者需要先识别窗户的规则图案结构，然后推断出截断处应有的完整样貌，再找到与之互补的补丁。这比直接的形状匹配多了一层"图案还原"的推理。
</new_puzzle>

<new_puzzle>
描述：在包含多个相互嵌套的彩色矩形环的网格中，根据环的嵌套层级和环上缺口的位置，向缺口方向的相邻外层环"传递"颜色标记，最终最外层环的标记颜色决定整个嵌套结构的填充色。

Input structure:
- bg = 最常见颜色（如 black）。
- 网格中有若干组同心矩形环结构。每组由 2 到 4 个不同颜色的矩形环从内到外嵌套而成，环之间间隔 1 像素的 bg 间距。
- 每个矩形环在其四条边之一上有一个 1 像素的缺口。
- 最内层环的内部包含一个单独的彩色像素（"核心色"），颜色与任何环的颜色都不同。

Rule:
- 从最内层环开始，找到该环的缺口方向。
- 在缺口方向上，将核心色标记"传递"到紧邻的外层环上：在外层环与内层环缺口对齐的那一侧，将外层环的 1 个像素染为核心色。
- 然后找到这个外层环自身的缺口方向，继续向更外层传递同样的标记。
- 重复直到最外层环也被标记。
- 最终，将最外层环的缺口所在的整条边（该边的所有像素）全部染为核心色。
- 其他所有环和像素保持不变。

Key insight: 解题需要三层推理——第一层是识别出同心矩形环的嵌套层级关系；第二层是发现每个环的缺口方向决定了标记传递到外层环的哪个位置；第三层是发现最终变换只作用于最外层环的缺口边，而传递过程本身不在输出中体现（中间层的标记在输出中不出现），解题者需要理解这是一个逐层向外传递方向信息的链式过程。
</new_puzzle>
