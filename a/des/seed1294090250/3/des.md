<description>
根据种子色块在框架内壁上的附着位置，选择对应的外部印章图案，将其旋转到正确朝向后盖印到框架内部。

Input structure:
- bg = 最常见颜色（black）。网格中散布着若干用同一颜色（blue）绘制的空心矩形框架，每个框架的内部为背景色。
- 每个框架的某一条内壁（上/下/左/右）上恰好有一个单像素的"种子色块"，颜色各不相同（如 red、green、yellow 等）。种子色块紧贴内壁，位于该壁的中点位置。
- 框架外部散布着若干小型多色图案（印章），每个印章由一种非背景、非框架色的颜色绘制，形状各异（L 形、T 形、十字形等），且每个印章的底边中点处有一个单像素标记，颜色与某个框架内的种子色块颜色相同。

Rule:
- 通过颜色匹配将每个印章与对应的框架配对：印章底边标记色 = 框架内种子色块色。
- 确定种子色块附着在框架的哪一面内壁（上/下/左/右）。
- 将印章旋转，使其原始底边朝向该内壁的反方向（即印章从该壁向框架内部"生长"）。例如种子在上壁，则印章底边朝上、图案向下展开。
- 将旋转后的印章以种子色块为锚点（印章底边中点对齐种子位置）盖印到框架内部，使用印章自身的颜色绘制。
- 种子色块在输出中被印章覆盖；框架边框保持不变。

Key insight:
种子色块同时承担两个角色——其颜色是配对钥匙，其在内壁上的位置决定了印章的旋转朝向。解题者必须先完成颜色配对，再根据附着壁面推断旋转方向，两步推理缺一不可。
</description>

<description>
在网格中找到被墙壁分隔的若干封闭区域，根据每个区域内散落的彩色像素的颜色种类数，从一组参考色带中选取对应长度的色带，将其铺设为该区域的边界内衬。

Input structure:
- bg = black。网格中有 grey 色的单像素宽墙壁网络，将网格分割成若干不规则的封闭区域。
- 每个封闭区域内散落着若干单像素的彩色点（颜色不一，可能包含 red、green、blue、yellow、orange 等）。
- 网格的一侧边缘外（如最底部几行）排列着若干水平色带，每条色带由不同颜色的像素从左到右排成一行，长度各不相同（例如长度为 2、3、4、5 的色带各一条）。色带之间用背景色分隔。

Rule:
- 对每个封闭区域，计算其内部散落的彩色像素共包含多少种不同颜色（不含背景色和墙壁色），得到数值 N。
- 在底部参考色带中，找到长度恰好为 N 的那条色带。
- 将该色带的颜色序列沿区域的内边界（紧贴墙壁内侧的一圈像素）循环铺设：从区域内最左上角的内边界像素开始，沿顺时针方向依次填入色带颜色，色带用完后从头循环，直到内边界铺满。
- 区域内部原有的散落彩色像素在输出中被清除（变为背景色）。
- 墙壁、色带参考区域保持不变。

Key insight:
颜色种类数是匹配键而非颜色本身——解题者必须先意识到要"数种类"而非"数数量"或"看具体颜色"，然后再理解色带是按长度匹配的查找表，最后还需推断出顺时针循环铺设的规则。三层推理逐层递进。
</description>

<description>
将网格中分散的碎片拼回一个被"爆炸拆散"的原始图案：每个碎片沿其特有的径向方向反向平移回中心，重叠区域用碎片自身颜色覆盖背景但不覆盖其他碎片。

Input structure:
- bg = black。网格中央有一个小型的彩色"核心残骸"图案（由多种颜色组成的紧凑块），周围散布着若干单色碎片（每个碎片是一个小型连通区域，颜色各异）。
- 每个碎片与核心残骸之间存在一条由同色单像素点组成的稀疏"轨迹线"（每隔两个背景像素出现一个同色像素），指示该碎片的飞散方向。
- 轨迹线严格沿八方向之一（上、下、左、右、四个对角）延伸。

Rule:
- 对每个碎片，沿其轨迹线的反方向（朝向核心）平移，平移距离等于碎片外边缘到核心残骸外边缘之间的轨迹点数量（含两端）乘以 3（因为轨迹点间距为 3）。
- 平移后碎片应恰好贴合到核心残骸上，与残骸组合形成完整图案。
- 轨迹线像素在输出中被清除。
- 核心残骸保持原位不动。
- 碎片间不会重叠（每个碎片填补核心残骸的不同缺失部分）。

Key insight:
稀疏轨迹线同时编码了两个信息：方向（线的朝向）和距离（点的数量决定平移步数）。解题者需要先识别出间隔出现的同色点是"轨迹"而非随机噪声，再理解点数与平移量的换算关系，最后验证所有碎片拼合后恰好复原完整图案。
</description>

<description>
网格中有若干对形状相同但颜色不同的图形，每对图形之间通过一条单色路径相连；根据路径经过的转弯次数，对目标图形内部进行对应次数的同心收缩填充。

Input structure:
- bg = black。网格中散布着若干成对出现的小型填充图形（如 3×3 或 4×4 的矩形、十字形等）。
- 每对图形形状完全相同，但颜色不同：一个是"源"（颜色为 red、blue、green 等鲜艳色），另一个是"目标"（统一为 grey 色）。
- 每对源与目标之间由一条 maroon 色的单像素宽路径相连，路径沿正交方向行进，遇墙或边界时转弯。路径不分叉、不交叉。

Rule:
- 将每个 grey 目标图形与通过路径相连的源图形配对。
- 计算连接路径的转弯次数 T（直线段之间的 90° 转角数）。
- 对目标图形进行 T 层同心收缩着色：最外层像素染成源图形的颜色，次外层染成背景色，再次外层染成源的颜色……交替进行，共处理 T 层。若图形太小不足 T 层，则有多少层染多少层。
- 路径在输出中保留不变。
- 源图形保持原样不变。

Key insight:
路径的转弯次数是隐含的控制参数——解题者必须首先注意到路径不仅仅是连接线，其几何复杂度（弯折数）直接控制了目标图形的填充深度。配对通过路径连通性确定，填充规则通过跨样例比较转弯数与同心层数的对应关系归纳得出。
</description>

<description>
网格中有一个大型迷宫和若干彩色入口标记；从每个入口沿迷宫通道行走，在每个岔路口选择向右转的分支，最终到达死胡同；用入口颜色填充从入口到死胡同的完整路径。

Input structure:
- bg = black。网格中由 grey 像素构成一个单像素宽通道的正交迷宫网络（通道为 grey，墙壁为 black）。
- 迷宫的外边界上有若干入口位置，每个入口处的 grey 通道像素被替换为一个独特的彩色像素（如 red、blue、green、yellow 等），标记该入口的颜色。
- 迷宫内部通道全部为 grey，包含若干岔路口（三通或四通）和死胡同。

Rule:
- 从每个彩色入口像素出发，沿 grey 通道向迷宫内部行进。
- 初始行进方向为从入口指向迷宫内部（垂直于入口所在的边界边）。
- 在每个岔路口，采用"右手法则"：优先选择相对于当前行进方向的右转通道；若右转不可行则直行；若直行也不可行则左转。不走回头路（不选择来时的方向）。
- 行走直到到达死胡同（除来路外无其他通道可走）。
- 将从入口到死胡同的整条路径（包括入口像素和死胡同像素）全部染成该入口的颜色。
- 不同入口的路径不会重叠（迷宫设计保证了这一点）。
- 未被任何路径经过的 grey 通道保持 grey 不变。

Key insight:
岔路口的选择规则（右手法则）是需要从样例中归纳的核心机制——解题者必须追踪每条示例路径在岔路口的转向选择，排除"最短路""随机选择""左手法则"等替代假设，最终锁定"始终右转优先"这一确定性规则。方向感的维持（需要记住当前朝向才能判断"右"是哪边）增添了空间推理的挑战。
</description>

<description>
网格被若干水平色带分割成行区域，每个行区域内散布着不同形状的小图形；将每个行区域内的图形按照该区域色带所指定的变换方式进行几何操作，变换类型由色带的颜色编码图案结合图例区决定。

Input structure:
- bg = black。网格由若干条水平色带（高度为 1 的整行像素）分隔成若干水平行区域。
- 每条色带由两种颜色交替组成，形成条纹图案。色带的两种颜色组合各不相同。
- 网格最上方有一个"图例区"，其中包含四个小方块，每个方块内部绘有一个简单的不对称 L 形标记（由 3 个像素组成：两个像素组成水平段，一个像素在水平段左端向上延伸），旁边紧贴一条与某种色带颜色组合相同的短色条（长度为 3，由两种颜色交替排列）。四个图例方块中的 L 形标记分别朝向四个不同方向（原始朝向、水平翻转、垂直翻转、顺时针旋转 90°），直观展示了该色条对应的变换效果。
- 每个行区域内散布着若干小型非对称图形（由单一颜色绘制），形状各异。

Rule:
- 读取图例区，建立色带颜色组合到几何变换的映射：观察每个图例方块中 L 形标记相对于标准朝向（水平段在下、竖直段在左上）的变化，推断对应的变换类型（水平翻转、垂直翻转、顺时针旋转 90°、或保持不变）。
- 对每个行区域，找到其上方紧邻的色带，识别该色带的两种颜色组合。

- 对该行区域内的每个图形，在其原位（以图形包围盒中心为锚点）执行对应的几何变换。
- 图例区和色带在输出中保持不变。

Key insight:
色带不是装饰而是指令编码——其颜色组合指向图例中的某种变换。解题者需要先破译图例区中 L 形标记的含义（将标记朝向变化映射为具体几何变换），再将色带作为查找键去匹配图例，最后对区域内所有图形统一执行变换。图例的视觉化设计使得变换类型可以被"看"出来而非被计算出来。

<description>
在网格中识别由边框颜色编码的嵌套容器层级，将最内层物体的颜色沿层级向外逐层传播，每经过一层容器就进行一次颜色选择（取容器边框色与传入色在可用颜色列表中排位靠前的那个）。

Input structure:
- bg = black。网格中有若干矩形空心边框彼此嵌套，形成 2-4 层的嵌套结构。
- 每个边框由单一颜色绘制（如 red、blue、green、yellow 等），宽度为 1 像素。
- 最内层的边框内部放置一个单色填充小方块（2×2 或 3×3），称为"核心物体"。
- 不同的嵌套组之间互不重叠，可能有多组并列存在于网格中。

Rule:
- 识别每组嵌套结构中从外到内的边框层级顺序。
- 从核心物体的颜色开始，向外逐层传播：
  - 核心物体颜色为 C₀。
  - 经过第一层（最内层）边框时，比较该边框颜色 F₁ 与 C₀ 在颜色列表（Blue、Red、Green、Yellow、Grey、Magenta、Orange、Azure、Maroon，按此固定顺序）中的位置，取排位靠前的那个，得到 C₁。
  - 经过第二层边框时，比较 F₂ 与 C₁，取排位靠前的，得到 C₂。依此类推。
- 将每层边框与其内层边框之间的空白区域填充为该层计算得到的传播颜色。
- 边框本身和核心物体保持原色不变。

Key insight:
嵌套层级决定了颜色传播的路径，而"取排位靠前者"这一选择规则需要解题者通过比较多组样例中不同颜色组合的结果来归纳发现——它既不是简单的"继承内层色"也不是"使用边框色"，而是一个需要跨样例推理的选择函数。嵌套深度的变化进一步增加了验证难度。
</description>
</new_puzzle>
