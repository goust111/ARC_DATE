- `description`：根据封闭区域内部"种子"像素的颜色，在区域边框缺口处向外生长出与种子同色的枝条；枝条长度等于该区域内种子像素的数量。

- `Input structure`：
  - bg = 最常见颜色。网格上分布着若干由 grey 像素构成的封闭矩形区域（1像素宽边框）。
  - 每个矩形边框上恰好有一个缺口（缺口为1像素宽，即边框上有一个位置是 bg 而非 grey）。
  - 每个矩形内部散布着若干同色的非bg非grey像素（"种子"），不同矩形内的种子颜色各不相同。
  - 矩形外部（bg区域）没有其他非bg非grey像素。

- `Rule`：
  - 对每个封闭矩形区域：
    1. 识别区域内种子像素的颜色 C 和数量 N（N 在 1-8 之间）。
    2. 找到边框上唯一缺口的位置，并确定缺口朝向的方向（缺口在上边框则方向为上，在下边框则方向为下，在左边框则方向为左，在右边框则方向为右）。
    3. 从缺口位置出发，沿缺口朝向的方向，向外连续绘制 N 个颜色为 C 的像素（即长度为 N 的直线枝条）。如果枝条碰到网格边界则截止。
  - 矩形边框和内部种子像素保持不变。

- `Key insight`：缺口方向决定枝条的生长方向，种子数量决定枝条长度，种子颜色决定枝条颜色——三个独立属性分别编码了变换的三个维度，解题者需要同时归纳出这三重对应关系。
</new_puzzle>

- `description`：将网格中散落的彩色L形碎片按颜色配对，每对碎片拼合成一个完整矩形；拼合后的矩形放置在由同色标记点指定的锚点位置。

- `Input structure`：
  - bg = 最常见颜色。网格上散落着若干 L 形碎片（每个碎片由3到5个同色像素组成，形状为L形或其旋转变体）。
  - 每种非bg颜色恰好出现两个 L 形碎片，它们可以互补拼合成一个无缝的实心矩形。
  - 网格最底行上分布着若干单像素标记点，每个标记点的颜色与某对碎片的颜色相同，标记点的位置表示该颜色对应的拼合矩形左下角应放置的列坐标。

- `Rule`：
  - 对每种颜色 C：
    1. 找到颜色为 C 的两个 L 形碎片。
    2. 确定一种旋转/翻转方式，使两个碎片可以互补拼合成一个无间隙的实心矩形（矩形内所有像素都为 C）。
    3. 找到最底行中颜色为 C 的标记点，将拼合后的矩形放置于该标记点指定的列位置，矩形底边紧贴标记点所在行的上方一行。
  - 清除所有原始碎片位置的像素和最底行标记点，只保留拼合后的矩形。

- `Key insight`：解题者首先需要识别同色碎片之间的互补关系（两个L形拼成矩形的旋转方式），然后需要发现底行标记点作为放置锚点的编码规则——两层归纳缺一不可。

- `Input structure`：

  - 右侧为主区域：包含若干组"同心嵌套方框"。每组方框由2到4个颜色不同的正方形边框严格同心嵌套而成（最外层最大，向内逐层缩小，边框宽度均为1像素，相邻层之间无间隙）。不同组之间不重叠。
  - 左侧为图例区：从上到下排列着若干颜色方块（每个方块为 2x2 实心色块），颜色方块之间间隔1行bg。这些颜色方块的排列顺序定义了颜色的优先级（最上方的颜色优先级最高，依次递减）。

- `Rule`：
  - 对右侧每组同心嵌套方框：
    1. 识别该组方框包含的所有层的颜色。
    2. 查阅左侧图例，找出这些颜色中优先级最高的那个颜色 C。
    3. 在输出中，仅保留该组方框中颜色为 C 的那一层边框（绘制在其原始位置），其余层全部擦除为bg。
  - 左侧图例区和分隔线在输出中移除，输出仅包含右侧主区域。

- `Key insight`：解题者需要先从左侧图例的垂直排列顺序中归纳出颜色优先级规则，再将此规则应用于右侧每组嵌套方框的层选择——图例不是简单的颜色标注，而是一个排序键。
</new_puzzle>

- `description`：网格中的彩色"信号源"像素沿灰色导线传播信号，在导线交叉节点处根据角落图例进行颜色混合，最终为所有导线和节点染色。

- `Input structure`：
  - bg = 最常见颜色。网格上由 grey 像素绘制了一个正交导线网络：若干条水平线和若干条垂直线，线宽均为1像素。水平线和垂直线交叉处形成节点（节点也是 grey 像素）。
  - 在某些导线的末端（即导线延伸到的最边缘位置的紧邻外侧1像素处），有一个非bg、非grey的彩色像素，称为"信号源"。不同信号源颜色可以不同。
  - 网格左上角有一个颜色混合图例区：由若干 3x1 的水平色条组成，每个色条的格式为 [颜色A, 颜色B, 颜色C]，表示颜色A和颜色B混合后产生颜色C。色条之间间隔1行bg。

- `Rule`：
  - 每个信号源沿其相邻导线传播自身颜色，将导线上的 grey 像素染为该信号源的颜色，传播沿导线直到遇到节点为止。
  - 在节点处：如果只有一个方向传来信号颜色 A，则节点染为 A，并继续沿节点连接的其他方向导线传播颜色 A。
  - 如果节点处有两个方向同时传来不同颜色的信号（分别为颜色A和颜色B），则查阅混合图例找到对应条目（包含A和B的那一条），节点染为混合色 C，且从节点出发沿其余方向的导线传播混合色 C。
  - 传播按导线段长度（像素数）同步推进：所有信号源同时出发，每步向前一个像素。先到达节点的信号先占据节点并继续传播；两个信号同步到达同一节点时触发混合。
  - 输出时移除角落的混合图例，仅输出染色后的导线网络（含bg区域）。

- `Key insight`：解题者需要三层推理——首先识别导线网络的拓扑结构和信号源位置，其次理解信号沿导线传播并在节点汇合的机制，最后发现角落图例编码了双色混合规则。同步传播意味着节点颜色取决于两端导线段长度的隐式比较（短的先到）。
</new_puzzle>

- `description`：网格中散布着若干彩色形状和同色的小方块"印章模板"；用模板图案周期性覆写填充大形状，但填充的对齐角由形状内部唯一红色锚点像素的位置决定。

- `Input structure`：
  - bg = 最常见颜色。网格上有若干较大的单色实心连通形状（不规则形状，面积约8-20像素），每个形状内部恰好有一个 red 像素（"锚点"）替代了原本的形状颜色。
  - 网格上另有若干 3x3 的小正方形方块（"印章模板"），每个小方块使用两种颜色构成二色棋盘或条纹图案：其中一种颜色与某个大形状的颜色相同（记为 C），另一种为 bg。每种非bg非red颜色恰好对应一个大形状和一个小方块。

- `Rule`：
  - 对每种颜色 C（非bg、非red）：
    1. 找到颜色为 C 的大形状和颜色为 C 的 3x3 小方块模板。
    2. 确定大形状内 red 锚点在形状边界框中的相对位置：计算锚点离边界框四个角的距离（上下左右像素差之和），选取最近的角作为对齐角（左上、右上、左下、右下之一）。
    3. 将 3x3 模板对齐到大形状边界框的该角，然后以 3x3 为周期在整个边界框区域内平铺。
    4. 对边界框内每个像素位置：如果该位置属于大形状且平铺图案中该位置为颜色 C，则输出 C；如果该位置属于大形状但平铺图案中该位置为 bg，则输出 bg；如果该位置不属于大形状，则输出 bg。
  - 移除所有 red 锚点像素（对应位置按平铺规则决定颜色）和原始 3x3 小方块模板。

- `Key insight`：解题者需要归纳两层非显然规则——第一层是小方块模板与大形状之间通过共享颜色建立配对关系，第二层是形状内部 red 锚点的位置决定了模板平铺的对齐角，使得相同模板在不同锚点位置下产生不同相位的填充图案。

- `description`：根据网格边缘的彩色箭头指令，将网格内部对应行或列的像素进行循环移位；箭头颜色指定目标行/列，箭头方向指定移位方向，箭头主体长度指定移位步数。

- `Input structure`：
  - bg = 最常见颜色。网格由两部分组成：2像素宽的外圈边框区域和内部图案区域。
  - 内部图案区域包含由多种颜色像素组成的图案（每种颜色仅出现在唯一一行或唯一一列上）。
  - 外圈边框区域中分布着若干"箭头"标记。每个箭头由同色像素组成，结构为：沿边框方向排列的一段连续像素（"主体"，长度1到4），加上在主体一端、朝向网格内部方向凸出的一个单像素（"尖端"）。箭头位于上/下边的操作列，位于左/右边的操作行。

- `Rule`：
  - 对每个箭头标记：
    1. 箭头颜色为 C，在内部图案区域中找到包含颜色 C 像素的那一行或那一列作为目标。
    2. 箭头尖端的朝向决定移位方向：上边箭头尖端朝下则目标列向下循环移位；下边箭头尖端朝上则目标列向上循环移位；左边箭头尖端朝右则目标行向右循环移位；右边箭头尖端朝左则目标行向左循环移位。
    3. 箭头主体的像素数量（不含尖端）即为循环移位步数 S。
    4. 将目标行或列的所有内部像素（含bg像素）循环移位 S 步。
  - 多个箭头按顺时针顺序依次执行：先上边从左到右，再右边从上到下，再下边从右到左，再左边从下到上。
  - 输出时移除外圈边框区域，仅输出变换后的内部图案。

- `Key insight`：箭头同时编码三重信息——颜色绑定目标行/列、尖端方向绑定移位方向、主体长度绑定移位步数。更深层的挑战在于多箭头按序执行时具有顺序依赖性：前一个移位操作改变了内部像素排布，影响后续操作的结果，解题者必须识别正确的执行顺序才能复现输出。
</new_puzzle>

<new_puzzle>
- `description`：网格被灰色墙壁分割成若干房间，每个房间有一个彩色"钥匙"像素和墙上同色"门锁"标记；用钥匙颜色填充从钥匙到门的路径并打开门，房间连通后可能产生新的钥匙-门配对，触发级联开锁。

- `Input structure`：
  - bg = 最常见颜色。网格由 grey 像素构成的墙壁（1像素宽）分割成若干矩形房间。
  - 某些墙壁上有1像素宽的缺口（该位置为bg而非grey）。每个缺口的一侧紧邻墙壁上有一个非bg非grey的彩色像素，称为"门锁"。门锁颜色各异。
  - 每个房间内部有且仅有一个非bg非grey的单像素"钥匙"。钥匙的颜色恰好与该房间某面墙壁上的一个门锁颜色相同。
  - 初始时缺口被视为锁住状态（不可通行）。

- `Rule`：
  - 反复执行以下步骤直到没有新操作可做：
    1. 在每个当前连通区域中，寻找钥匙颜色与该区域墙壁上某门锁颜色匹配的配对（钥匙颜色 C = 门锁颜色 C）。
    2. 对每个匹配：从钥匙位置到门锁旁缺口位置绘制一条颜色为 C 的直线路径（钥匙与缺口一定在同一行或同一列上，路径沿该行或列的bg像素绘制，包含钥匙位置和缺口位置）。
    3. 将门锁像素移除（变为bg），缺口保持为bg，此门打开。
    4. 门打开后，缺口两侧的房间合并为一个连通区域。在新的连通区域中重新检查是否存在新的钥匙-门锁颜色匹配。
  - 级联直到不再有新匹配。每把钥匙只对应一扇门，不会出现歧义。

- `Key insight`：解题者需要理解三层递进机制——颜色匹配确定钥匙与门锁的对应关系、路径填充和开门改变了房间的连通性、连通性变化可能暴露出此前不可达的新钥匙-门锁配对从而触发级联。仅看单个房间无法预测最终结果，必须模拟整个级联过程。
</new_puzzle>
