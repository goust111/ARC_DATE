<new_puzzle>
根据框架内部碎片的朝向选择镜像轴，再用框架外部色块的颜色对镜像结果进行重着色。

Input structure:
- 背景色为黑色（black）。网格中散布若干矩形空心框架，每个框架由单一颜色绘制（如蓝色 blue、绿色 green 等），框架线宽为 1 像素。
- 每个框架内部有一个不规则的小型碎片图案（由灰色 grey 像素组成），碎片图案不对称，且恰好只沿一个轴（水平或垂直）具有"几乎对称"的特征——即碎片的一侧比另一侧多出 1-2 个像素。
- 每个框架外部紧贴框架某一条边的外侧，有一个单色小方块（2x2 或 1x1），颜色各不相同（如红色 red、橙色 orange、洋红色 magenta 等），称为"染色标记"。

Rule:
- 第一步：观察每个框架内部的灰色碎片，判断它更接近沿哪个轴对称——如果碎片沿垂直中轴翻转后与原图重叠像素更多，则镜像轴为垂直轴；如果沿水平中轴翻转后重叠更多，则镜像轴为水平轴。（在样例中，碎片总是只有一个轴的重叠明显优于另一个，不存在平局。）
- 第二步：将碎片沿选定轴做镜像翻转，翻转后的图案覆盖原碎片位置（即用翻转版本替换原碎片）。翻转后多出的像素被保留，缺失的像素被填充，使碎片变为沿该轴完全对称的图案。
- 第三步：将翻转后碎片的颜色从灰色替换为对应框架外部"染色标记"的颜色。框架本身和染色标记在输出中保持不变。

Key insight:
碎片形状本身暗示了应该使用哪个镜像轴——解题者需要通过视觉对比"沿哪个轴翻转后更像原来的自己"来推断轴向，而不是被直接告知；然后第二步的颜色替换需要从框架外部的色块读取，形成两层独立归纳。
</new_puzzle>

<new_puzzle>
按照"种子像素"的颜色查找匹配的形状模板，将模板以种子为锚点生长出来，生长方向由种子相对于网格中心线的位置决定。

Input structure:
- 背景色为黑色（black）。网格被一条贯穿全宽的水平灰色（grey）分隔线分为上下两个区域。
- 上方区域是"模板库"：包含若干小型连通图案（每个图案由单一非黑非灰颜色绘制，如红色 red、蓝色 blue、绿色 green 等），每个图案都有一个明确的"根像素"——即该图案中唯一一个与图案其他像素仅有单边相连（度为 1）的末端像素。各图案之间不相邻，颜色互不相同。
- 下方区域是"画布"：在黑色背景上散布若干孤立的单像素点，颜色与上方某个模板的颜色相同，称为"种子像素"。每种颜色的种子像素恰好出现一次。

Rule:
- 第一步：为每个种子像素找到上方颜色相同的模板图案。
- 第二步：确定生长方向——将下方画布沿垂直中轴分为左半和右半。若种子位于左半区域，则模板以"根像素朝左"的方式放置（即模板水平翻转，使根在左侧）；若种子位于右半区域，则模板以"根像素朝右"的方式放置（不翻转或翻转使根在右侧）。若种子恰好在中轴上，则模板不翻转直接使用。
- 第三步：将模板图案的根像素对齐到种子像素的位置，把整个模板绘制到画布上。模板保持原色。上方模板库区域和分隔线在输出中被移除，输出仅包含下方画布区域（尺寸不变）。

Key insight:
颜色匹配确定"用哪个模板"，而种子在画布中的左右位置决定模板的水平朝向——解题者需要先发现颜色对应关系，再发现位置控制翻转这一隐含规则，两层推理缺一不可。
</new_puzzle>

<new_puzzle>
将网格中的"管道"连通图案按其内部流动标记的方向进行接力传色，最终每段管道的颜色由上游源头决定。

Input structure:
- 背景色为黑色（black）。网格中有若干由灰色（grey）像素组成的直线段（水平或垂直，宽度为 1 像素，长度 3-8 像素），称为"管道段"。
- 管道段之间通过端点直接相邻（4-连通）来首尾相连，形成若干条不分叉的链状路径。每条链的一个端点管道段内部有一个特殊的彩色像素（如红色 red、蓝色 blue 等），位于该管道段的某一端——这个彩色像素称为"源头标记"，其颜色是该链的"源色"。
- 每个管道段的中间位置有一个箭头标记：箭头由 3 个橙色（orange）像素组成，排列成">"、"<"、"^"或"v"形状（即一个中心像素加两个斜对角像素组成箭头尖）。箭头嵌在管道段内部，指示该段内的"流动方向"。

Rule:
- 第一步：识别每条管道链的起点——起点是包含源头彩色标记的那个管道段。
- 第二步：验证流向一致性——从源头出发，沿管道链依次检查每个管道段内部的箭头方向。箭头必须指向"从源头到末端"的方向（即从链的起点向终点）。如果某段管道的箭头方向与链的整体流向一致，该段管道被染为源色；如果箭头方向相反（逆流），该段管道保持灰色不变。
- 第三步：移除所有箭头标记（橙色像素变为该管道段最终的颜色——源色或灰色）。源头彩色标记像素保留。

Key insight:
解题者首先要识别管道链的拓扑连接和源头位置，然后理解箭头表示流向——只有"顺流"的管道段才被上色。这要求解题者进行两层推理：先确定链路结构和流向定义，再判断每段箭头与全局流向的一致性。
</new_puzzle>

<new_puzzle>
根据封闭区域内"投票像素"的多数颜色决定该区域的填充色，再根据区域的面积大小排序决定嵌套层级，重新绘制为同心方框。

Input structure:
- 背景色为黑色（black）。网格中有若干个由灰色（grey）线条围成的不规则封闭区域（区域之间互不重叠，不嵌套，线宽 1 像素）。
- 每个封闭区域内部散布着若干彩色像素点（每个区域内可能有 2-3 种颜色，如红色 red、蓝色 blue、绿色 green 等），这些像素称为"投票像素"。每个区域内各颜色的像素数量不同，不存在平局。

Rule:
- 第一步（投票决色）：对每个封闭区域，统计其内部各颜色投票像素的数量，数量最多的颜色即为该区域的"代表色"。
- 第二步（面积排序）：计算每个封闭区域的面积（内部黑色空像素 + 投票像素的总数，不含灰色边界），按面积从大到小排序。
- 第三步（同心方框重绘）：输出网格尺寸重新计算。面积最大的区域的代表色画为最外层方框；面积次大的区域的代表色画为第二层方框；以此类推，面积最小的区域的代表色画为最中心的实心方块。方框之间紧密嵌套，每层方框宽度为 1 像素。输出中不再包含灰色边界和投票像素，只有同心方框。输出网格为正方形，边长 = 2 * 区域数量 - 1。

Key insight:
解题者需要完成三层独立推理——第一层是从散乱投票像素中归纳出"多数决"的选色规则；第二层是发现区域面积决定嵌套顺序；第三层是理解输出格式从不规则区域变为规整的同心方框。每一层都不能从单纯的视觉直觉中一眼看出，必须通过多个样例交叉验证。
</new_puzzle>

<new_puzzle>
将散落的拼图块按缺口方向和榫头方向互锁拼合，拼合后整体旋转至缺口朝向网格外侧的方向。

Input structure:
- 背景色为黑色（black）。网格中散布若干个 5x5 的彩色方块（每个方块为单一颜色，各不相同，如红色 red、蓝色 blue、绿色 green、黄色 yellow 等）。
- 每个 5x5 方块的四条边之一上有一个 1x1 的缺口（即该边中央的像素缺失，显示为黑色），称为"凹槽"；另一条边（与凹槽所在边不相邻的那条对边）的中央向外凸出一个 1x1 的像素，称为"榫头"。其余两条边平整。
- 缺口和榫头总是位于对边——即如果凹槽在左边，榫头就在右边，反之亦然；如果凹槽在上边，榫头就在下边，反之亦然。

Rule:
- 第一步（配对拼合）：找到榫头方向指向另一块凹槽方向的配对。具体地，如果方块 A 的榫头朝右，方块 B 的凹槽朝左，则 A 的榫头可以插入 B 的凹槽——将 B 放置在 A 的右侧，A 的凸出像素恰好填入 B 的凹口。所有方块恰好形成一条不分叉的链（每块最多一个榫头被连接、一个凹槽被连接）。
- 第二步（整链拼装）：按链的顺序将所有方块无间隙地排列在一起（榫头填入凹槽，方块之间紧密贴合，榫头像素与凹槽像素重合为榫头方块的颜色）。
- 第三步（旋转定向）：观察拼装后的长条形整体，链的首块（只有榫头被连接、凹槽空闲的那块）的凹槽方向决定输出朝向：凹槽朝上则整体不旋转（长条水平排列，首块凹槽在顶部）；凹槽朝左则整体顺时针旋转 90 度；凹槽朝下则旋转 180 度；凹槽朝右则逆时针旋转 90 度。最终输出为旋转后的拼合结果，背景裁切到最小外接矩形。

Key insight:
解题者先要通过凹槽和榫头的方向匹配发现配对规则（第一层推理），再通过链式组装确定排列顺序（第二层推理），最后发现首块凹槽方向控制整体旋转（第三层推理）——三层规则逐步揭示，仅看单个样例难以同时归纳出全部。
</new_puzzle>

<new_puzzle>
利用网格边缘的色带序列作为"编织指令"，在中央画布上对经线和纬线交替染色，交叉点的颜色由上层线决定。

Input structure:
- 背景色为黑色（black）。网格的最左列和最上行分别是两条"色带"——最左列从上到下由若干种颜色的连续段组成（每段 2-4 像素高），最上行从左到右由若干种颜色的连续段组成（每段 2-4 像素宽）。最左列和最上行的交叉格（左上角像素）为灰色（grey），不属于任何色带。
- 网格其余区域（去掉最左列和最上行后的矩形）为中央画布，初始全为黑色。
- 在中央画布的某些位置有孤立的橙色（orange）像素，称为"上下标记"——它们标记该位置的纬线（水平线）在视觉上位于经线（垂直线）"上方"。

Rule:
- 第一步（画经线）：最上行色带的每个颜色段对应画布中一组垂直列。色带段中第 i 个像素对应画布的第 i 列。将画布中对应列的所有像素填充为该色带段的颜色。
- 第二步（画纬线）：最左列色带的每个颜色段对应画布中一组水平行。色带段中第 j 个像素对应画布的第 j 行。将画布中对应行的所有像素填充为该色带段的颜色——覆盖掉之前经线的颜色。
- 第三步（编织交叉）：默认情况下纬线在经线上方（第二步覆盖第一步）。但在有"上下标记"（橙色像素）的位置，经线应当在纬线上方——即该位置恢复为第一步中经线的颜色。最终移除所有橙色标记，显示编织结果。

Key insight:
解题者需要先发现边缘色带是如何映射到画布行列的（第一层），再理解经纬线的默认上下叠压关系（第二层），最后发现橙色标记反转局部叠压顺序实现"编织"效果（第三层）。三条规则叠加后才能正确复原输出。
</new_puzzle>

<new_puzzle>
根据每个对象"影子"的投射方向推断全局光源位置，再为缺少影子的对象补画正确方向和长度的影子。

Input structure:
- 背景色为黄色（yellow）。网格上有若干小型连通对象（每个由 2-5 个像素组成），颜色各异（如红色 red、蓝色 blue、绿色 green 等），称为"实体"。
- 部分实体旁边有一组灰色（grey）像素，形状和实体完全相同但沿某个方向平移了固定距离——这组灰色像素称为"影子"。影子始终位于实体的同一侧（所有有影子的实体，其影子相对实体的偏移方向相同），偏移距离为 1 或 2 个像素。
- 有些实体没有影子（旁边没有灰色像素）。

Rule:
- 第一步（推断光源方向）：观察所有已有影子的实体，确定影子相对实体的统一偏移方向（如"向右下偏移 1 格"意味着影子中每个像素的坐标 = 实体对应像素坐标 + (1,1)）。所有影子的偏移向量相同。
- 第二步（推断偏移距离）：通过已有影子确认偏移距离（1 或 2）。
- 第三步（补画影子）：为每个缺少影子的实体，按照相同的偏移方向和距离绘制灰色影子。影子像素绘制在实体像素之下（即如果影子位置已被其他实体占据，则该影子像素不绘制）。已有影子的实体保持不变。

Key insight:
解题者必须先从多个"有影子"的实体中归纳出全局一致的偏移向量（方向+距离），然后将同一向量应用于"无影子"的实体——关键在于偏移方向不是直接标注的，需要从多个样例中通过影子与实体的空间关系推断。
</new_puzzle>
