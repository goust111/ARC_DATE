- `description`：根据框架内部的彩色种子像素确定填充图案，再利用框架缺口方向将图案向外投射到网格边缘。
- `Input structure`：背景为最常见颜色。网格中散布若干由同一前景色绘制的一像素厚矩形框架（3x3 至 7x7 不等）。每个框架恰好有一个缺口（缺少一侧边的一段连续像素）。框架内部放置了一个由另一种颜色构成的小图案（1~4 像素的连通块），该图案位于框架内部的相对位置各不相同。
- `Rule`：
  1. 对每个框架，识别其缺口所在的边（上、下、左、右）。
  2. 将框架内部的彩色图案视为一个"印章"，以框架中心为原点记录图案的相对坐标。
  3. 从缺口向外，沿缺口方向每隔一个框架宽度的距离，重复粘贴该印章图案，直到到达网格边界。每次粘贴时，印章的颜色保持不变，位置沿缺口方向平移。
  4. 框架本身和内部原始图案保持不变。
- `Key insight`：框架缺口决定投射方向，而框架内部的小图案既是填充内容也是周期性重复的模板——解题者需要同时识别"方向由缺口给出"和"内容由内部种子给出"这两层独立信息。
</new_puzzle>

- `description`：将散落的彩色碎片按颜色配对后，在每对碎片之间的连接路径上用该颜色绘制直角折线，折线方向由碎片的相对形状朝向决定。
- `Input structure`：背景为最常见颜色。网格中有若干由不同颜色构成的小型连通块（每块 2~5 像素）。每种非背景颜色恰好出现两次（即两个独立的同色连通块）。每个连通块的形状是非对称的 L 形或 T 形，具有一个可辨认的"开口方向"（即形状凹陷所朝的方向：上、下、左、右）。
- `Rule`：
  1. 将同色的两个连通块配对。
  2. 对每对连通块，确定各自的开口方向。第一个块的开口方向决定折线从该块出发的初始方向，第二个块的开口方向决定折线到达该块的最终方向。
  3. 从第一个块的边缘中心出发，先沿第一个块的开口方向直行，再转一个直角弯，沿第二个块的开口方向直行到达第二个块的边缘中心，形成一条恰好有一个直角拐弯的折线。
  4. 折线用该颜色绘制，宽度为一像素。折线不覆盖原始连通块的像素。若折线路径经过其他颜色的已有像素，则跳过该像素不覆盖。
- `Key insight`：配对是第一层推理（按颜色匹配），折线方向是第二层推理（由每个碎片自身形状的开口朝向决定出发方向和到达方向），两层信息共同唯一确定路径。
</new_puzzle>

- `description`：在网格中找到被边框围住的多个房间，根据房间边框上"锁"标记的颜色去匹配对应的"钥匙房间"，然后将钥匙房间的内容复制到锁房间中。
- `Input structure`：背景为最常见颜色。一种前景色（如 grey）构成若干一像素厚的封闭矩形边框，将网格划分为若干矩形房间。每个房间内部要么完全为空（纯背景色），要么包含一个由某种颜色构成的小型图案（2~6 像素）。部分空房间的边框上恰好有一个不同颜色的单像素标记（"锁"），该标记颜色与某个其他房间内图案的颜色相同。包含图案的房间称为"钥匙房间"，边框上有标记的空房间称为"锁房间"。
- `Rule`：
  1. 对每个锁房间，找到其边框上的彩色标记像素，记录该标记的颜色 C。
  2. 在所有钥匙房间中，找到内部图案颜色为 C 的那个房间。
  3. 将该钥匙房间内部的图案（保持形状和颜色）复制到锁房间内部，对齐方式为居中放置。
  4. 钥匙房间的原始内容保持不变。边框和标记像素保持不变。
- `Key insight`：解题者需要先建立"锁标记颜色 → 钥匙房间内容颜色"的匹配关系（第一层），再执行图案的跨房间复制与居中对齐（第二层）。边框上的单像素标记容易被忽略，增加了机制的隐蔽性。
</new_puzzle>

- `description`：将网格中的多个同构图形按照各自内嵌标记的层级进行嵌套堆叠，生成一个从大到小逐层缩小的同心嵌套图。
- `Input structure`：背景为最常见颜色。网格中有若干个不同颜色的相同形状的矩形环（空心矩形，一像素厚边框），它们分散在网格各处，互不重叠，大小各不相同。每个矩形环的内部中心位置有一个由另一种颜色构成的单像素标记点。标记点的颜色恰好等于另一个矩形环的边框颜色，形成一条链式指向关系（A 内标记颜色 = B 的边框颜色，B 内标记颜色 = C 的边框颜色……）。链的末端矩形环内部标记颜色不对应任何其他环（或者标记颜色与自身边框颜色相同）。
- `Rule`：
  1. 通过标记颜色的链式指向，确定矩形环从外到内的嵌套顺序：链头（没有被任何其他环的标记指向的环）为最外层，链尾为最内层。
  2. 输出网格以最外层矩形环为基础，将第二层矩形环居中放入第一层内部，第三层居中放入第二层内部，依此类推。每层环保持其原始边框颜色，环的大小按原始大小保持不变（保证内层环能放入外层环内部）。
  3. 最内层环的内部标记点保留在最终输出的中心位置。其余标记点移除。
  4. 输出网格裁剪为恰好包含最外层矩形环的最小尺寸。
- `Key insight`：解题者需要先通过"内部标记颜色 = 另一个环的边框颜色"的链式关系推断出嵌套顺序（第一层推理），再按该顺序执行同心嵌套的几何构建（第二层推理）。分散的环和链式指向使得嵌套顺序并不直观。
</new_puzzle>

- `description`：识别网格中由栅栏分隔的区域，统计每个区域内不同颜色种子的数量，然后用数量最多的种子颜色从区域底部向上填充，填充行数等于该颜色种子的个数。
- `Input structure`：背景为最常见颜色。一种前景色（如 blue）构成水平和垂直的一像素厚直线，将网格划分为若干矩形区域（类似棋盘格式的栅栏结构）。每个矩形区域内部散布着若干单像素的彩色"种子"点，颜色各异（可能有 red、green、yellow 等多种颜色混在同一区域内）。每个区域内各颜色的种子数量互不相同，保证最多色唯一。
- `Rule`：
  1. 对每个被栅栏围出的矩形区域，统计其中每种种子颜色的像素数量。
  2. 找到数量最多的种子颜色（保证每个区域内有唯一最多色）。
  3. 清除该区域内所有种子像素。
  4. 用该最多色从区域底行开始向上填充，填充的行数等于该最多色种子的原始数量。填充宽度为整个区域的宽度。
  5. 栅栏线保持不变。
- `Key insight`：解题者需要先完成"区域内颜色计数 → 选出主导色"的统计推理（第一层），再将计数值转化为几何高度完成柱状填充（第二层）。种子的随机散布位置是干扰项，真正重要的是数量和颜色的对应关系。
</new_puzzle>

- `description`：根据网格边缘的箭头标记确定扫描方向，将扫描路径上遇到的第一个彩色像素的颜色"喷涂"到该路径后续所有空白像素上，直到遇到另一个不同颜色的像素为止。
- `Input structure`：背景为最常见颜色。网格的某一条边（上、下、左或右）上有若干由同一颜色（如 maroon）绘制的箭头标记，每个箭头占据边缘的一行或一列。箭头形状为三像素组成的指向符号：若箭头朝右，则为同一行相邻三列上的像素排列成 ">" 形（第一列中间一像素、第二列上下各一像素）；朝下则为类似的 "v" 形旋转；其余方向类推。箭头指向网格内部。网格内部散布着若干不同颜色的单像素点。
- `Rule`：
  1. 对每个箭头，沿箭头指向的方向扫描该行或该列。
  2. 遇到的第一个非背景像素的颜色成为"喷涂色"。
  3. 从该像素的下一个位置继续沿同方向前进，将所有背景像素替换为喷涂色。
  4. 当遇到另一个非背景像素（颜色不同于喷涂色）或到达网格边界时，喷涂停止。遇到的终止像素本身保持不变。
  5. 所有原始彩色像素保持不变。箭头标记在输出中被擦除为背景色。
- `Key insight`：箭头的位置和朝向确定了扫描的起始行/列和方向（第一层），而扫描路径上像素的排列顺序决定了喷涂的颜色和范围（第二层）。箭头被擦除这一细节增加了规则的隐蔽性。
</new_puzzle>

- `description`：将网格中的彩色路径段按端点处的颜色编码标记建立首尾拼接顺序，然后将所有段拼成一条连续路径输出。
- `Input structure`：背景为最常见颜色。网格中有若干条由不同颜色绘制的直线段（水平或垂直，长度 3~8 像素），各段分散放置互不重叠。每条线段的两个端点各有一个相邻的单像素标记（紧贴端点且不在线段延长线上），标记的颜色与该端点应连接的另一条线段的主体颜色相同。链的起始段有一个端点的标记颜色与自身主体颜色相同（表示链头），链的末尾段类似（表示链尾）。
- `Rule`：
  1. 对每条线段，检查其两个端点旁的标记颜色。标记颜色指示该端点应与哪条线段连接。
  2. 按照标记颜色的链式指引，将所有线段首尾拼接成一条连续路径。拼接时，将后续线段平移并在必要时旋转90度，使被连接的端点紧密相邻，且线段沿连接方向延伸。

- `Key insight`：解题者需要先通过端点标记颜色建立线段之间的连接图谱（第一层推理），再确定拼接的几何方向和最终排布（第二层推理）。标记颜色作为"指针"指向目标线段的机制是核心隐蔽点。
</new_puzzle>

- `description`：识别网格中多个部分残缺的旋转对称图案，利用各图案已有的三个象限通过旋转对称性补全缺失的第四个象限。
- `Input structure`：背景为最常见颜色。网格中有若干个大小相同的正方形区域（边长为偶数，如 4x4 或 6x6），彼此不重叠，由至少两行或两列背景色分隔。每个正方形区域被其中心划分为四个象限（左上、右上、左下、右下）。每个区域中恰好有三个象限包含由该区域特有颜色绘制的图案像素，第四个象限为空（纯背景色）。若将任一非空象限顺时针旋转 90 度，其图案与相邻象限的图案一致——即完整的四象限图案具有 90 度旋转对称性。不同区域缺失的象限位置不同。
- `Rule`：
  1. 识别每个正方形区域中缺失的是哪个象限（即全为背景色的象限）。
  2. 取缺失象限的顺时针相邻象限的图案，将其逆时针旋转 90 度，即得到缺失象限应有的图案。
  3. 用旋转后的图案填充缺失象限，填充颜色与该区域已有图案颜色相同。
  4. 所有原有像素保持不变。
- `Key insight`：解题者需要先发现所有区域的图案都服从 90 度旋转对称性这一隐含规律（第一层），再针对每个区域判断缺失位置并正确选择旋转方向来补全（第二层）。不同区域缺失不同象限迫使解题者确认旋转对称假设而非简单镜像复制。
</new_puzzle>
