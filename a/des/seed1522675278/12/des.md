<description>
根据边框缺口方向找到对应的内部色块，将色块的形状作为印章盖在同色边框的外侧。

Input structure:
- 背景为黑色（black）。
- 网格中有若干个不同颜色的矩形边框（仅由边框线构成，内部为背景色），每个边框在某一侧有一个连续缺口（缺口宽度 ≥ 2 像素）。
- 在每个边框的内部，有一个由另一种颜色构成的小型实心色块（sprite），该色块的颜色与网格中某个其他边框的颜色相同。

Rule:
- 对每个矩形边框，找到其内部的色块，该色块的颜色指向另一个边框（颜色匹配）。
- 找到目标边框的缺口所在的那一侧（上、下、左、右）。
- 将色块平移到目标边框缺口的外侧，紧贴缺口边缘居中放置，色块颜色保持不变。
- 原来边框内部的色块被擦除（变为背景色），边框本身保持不变。

Key insight:
- 色块的颜色不是用来装饰自身所在边框的，而是一个指针，指向另一个同色边框；色块的形状则是要盖在目标边框缺口外侧的印章。解题者需要建立"颜色→目标边框→缺口方向→放置位置"的多步推理链。
</description>

<description>
将散落的单色碎片按照隐含的层叠顺序重建，并用每个碎片的完整面积决定其在输出色带中的排列位置。

Input structure:
- 背景为 grey。
- 网格中有若干个不同颜色的不规则单色碎片（8-连通），碎片之间存在部分重叠。
- 在重叠区域，上层碎片的颜色覆盖了下层碎片的颜色。

Rule:
- 第一步：通过观察重叠区域，推断碎片之间的遮挡关系。如果颜色 A 的像素出现在颜色 B 碎片的连通区域预期位置上，说明 A 在 B 之上。据此建立从顶层到底层的完整层叠顺序。
- 第二步：对每个碎片，根据层叠顺序还原其完整形状（包括被遮挡部分），具体方法为：对于被上层碎片覆盖的像素位置，如果该位置与当前碎片的可见部分 8-连通相邻且处于当前碎片可见轮廓的凸包范围内，则视为被遮挡像素，将其计入该碎片的完整面积。
- 第三步：输出为单行色带（1 行 × N 列，N = 碎片数量），按完整面积从小到大排列，每格填入对应碎片的颜色。若面积相同，按碎片最上方像素的行号从小到大排列。

Key insight:
- 解题者不仅需要从可见像素中推断层叠顺序（遮挡推理），还需要"反向补全"被遮挡的碎片以获得真实面积，最终用面积排序生成一个与空间布局无关的抽象色带输出。层叠推理和面积排序是两层独立的非平凡归纳。
</description>
</new_puzzle>

<description>
在由分隔线划分的棋盘格中，每个格子包含一个 L 形图案或为空；根据相邻格子中 L 形图案的朝向是否"对视"，决定它们之间边界线的颜色。

Input structure:
- 背景为 black。
- 网格被 blue 色的单像素宽分隔线划分为 M×N 的等大方格阵列。
- 每个方格内部要么为空（全黑），要么包含一个由 red 像素组成的 L 形图案（占据 3 个像素，形成直角）。L 形有四种朝向：左上、右上、左下、右下，由直角顶点的位置决定。例如"右下"朝向表示直角顶点在右下角，两条臂分别向上和向左延伸各 1 像素。

Rule:
- 对于水平相邻的两个非空方格，检查左侧方格的 L 形直角顶点是否在其方格的右侧（即朝向为右上或右下），同时右侧方格的 L 形直角顶点是否在其方格的左侧（即朝向为左上或左下）。如果两者都满足（即"面对面"），将这两个方格之间的竖直分隔线段从 blue 改为 green。
- 对于垂直相邻的两个非空方格，检查上方方格的 L 形直角顶点是否在其方格的下侧（即朝向为左下或右下），同时下方方格的 L 形直角顶点是否在其方格的上侧（即朝向为左上或右上）。如果两者都满足，将这两个方格之间的水平分隔线段从 blue 改为 green。
- 其余情况（不面对面、有一方为空）分隔线保持 blue。
- 方格内部的 L 形图案保持不变。

Key insight:
- 分隔线颜色不取决于格子是否被占据，而取决于相邻两个 L 形图案的朝向是否形成"对视"关系。解题者需要先识别每个 L 形的朝向语义，再判断相邻对之间的方向对称关系，这是一个从局部图案属性到全局边界着色的两层推理。
</description>
</new_puzzle>

<description>
将网格中的灰色折线路径按照沿途遇到的"染色站"逐段重新上色，路径的遍历方向由端点处的起点标记决定。

Input structure:
- 背景为 black。
- 网格中有若干条由 grey 像素组成的单像素宽 4-连通折线路径，路径之间互不接触。每条路径有且仅有两个端点（仅有一个路径邻居的像素）。
- 每条路径的一个端点与一个非 grey、非 black 的彩色单像素标记 4-连通相邻（标记不在路径上），称为"起点标记"，其颜色即为路径的初始绘制颜色。
- 网格中另有若干非 grey、非 black 的彩色单像素点散布在路径旁边（与路径上某个像素 4-连通相邻，但自身不在路径上），称为"染色站"。

Rule:
- 对每条路径，从拥有起点标记的端点开始，沿路径逐像素遍历。
- 当前绘制颜色初始为起点标记的颜色，将路径起始端点像素染为该颜色。
- 沿路径依次前进，每个路径像素染为当前绘制颜色。
- 当路径上某个像素与一个染色站 4-连通相邻时，从该像素的下一个像素开始，绘制颜色切换为该染色站的颜色。
- 染色站和起点标记像素本身在输出中保持不变。

Key insight:
- 路径本身是无差别的灰色线条，最终的分段颜色由遍历过程中依次"拾取"的染色站决定。解题者需要先确定每条路径的遍历方向（由起点标记唯一确定），再沿路径追踪每个染色站的切换位置和影响范围。起点标记决定方向和初始颜色，染色站决定后续分段颜色，两层信息共同控制输出。
</description>

<description>
将样本区域中带外框的图案对象剥去外框后，嵌入模板区域中尺寸匹配的矩形空洞内。

Input structure:
- 背景为 black。
- 网格被一条 grey 色的完整竖线分为左右两个区域。
- 左侧为"模板区域"：包含一个由 blue 像素构成的大型连通形状，该形状内部有若干个不同大小的矩形空洞（全黑区域），空洞之间大小互不相同。
- 右侧为"样本区域"：包含若干个小型矩形对象，每个对象由单像素宽的 red 外框包裹，内部填充着由两种颜色交替组成的独特图案（如水平条纹、竖直条纹、棋盘格等）。不同样本对象的外框尺寸互不相同。

Rule:
- 第一步：测量模板中每个矩形空洞的宽 W 和高 H。
- 第二步：对每个样本对象，其外框尺寸为 W×H，去掉单像素宽的 red 外框后，内部图案尺寸为 (W-2)×(H-2)。
- 第三步：将样本对象的外框尺寸与模板空洞尺寸进行匹配（外框尺寸 = 空洞尺寸）。
- 第四步：将匹配的样本对象的内部图案（不含外框）填入模板对应空洞的中央，空洞四周保留 1 像素的黑色间距。
- 输出仅包含模板区域（从网格左边界到 grey 分隔线之前），空洞被图案填充，其余蓝色像素和黑色背景不变。

Key insight:
- 匹配并非用样本内部图案的尺寸直接对比空洞尺寸，而是用样本对象含外框的整体尺寸去匹配。外框是"包装"，内部图案才是"内容"，放入空洞时外框被丢弃，留下 1 像素的黑色边距。解题者需要先发现外框与空洞的尺寸对应关系，再理解剥离外框后居中放置的嵌套规则。
</description>

<description>
在包含多个封闭房间的迷宫中，每个房间有一把彩色钥匙，钥匙颜色指向同色的门，门另一侧的房间被填充为钥匙的颜色。

Input structure:
- 背景为 black。
- 网格中有由 grey 像素构成的单像素宽墙壁，围成若干个封闭的矩形房间（房间内部为 black）。
- 每个房间内部恰好有一个单像素的彩色"钥匙"（每把钥匙颜色各不相同，可能为 red、green、blue、yellow、magenta 等）。
- 相邻房间之间的共享墙壁上恰好有一个像素被替换为某种非 grey、非 black 的颜色，形成一扇"门"。门的颜色与某个房间内的钥匙颜色相同。每种颜色在整个网格中恰好出现两次：一次作为钥匙，一次作为门。

Rule:
- 对每个房间，找到其中的钥匙颜色 C。
- 在整个网格中找到颜色同为 C 的那扇门（位于某面墙壁上的单个彩色像素）。
- 该门连接两个相邻房间。确定门所在墙壁另一侧的那个房间。
- 将该目标房间的所有内部黑色背景像素填充为颜色 C。
- 钥匙像素保留，墙壁像素保留，门像素保留。

Key insight:
- 钥匙不是用来作用于自己所在房间的，而是通过颜色匹配远程指定了另一个房间的填充色。解题者需要建立"钥匙颜色 → 同色门 → 门另一侧房间 → 填充"的间接推理链。每个房间既是某把钥匙的来源，又可能是另一把钥匙的作用目标，形成交叉映射。
</description>

<description>
网格中的每个彩色方块根据其内部缺失像素的位置向对应方向滑动，滑动距离等于方块中缺失像素的数量。

Input structure:
- 背景为 black。
- 网格中有若干个 3×3 的实心彩色方块（颜色各不相同，可能为 red、blue、green、yellow 等），方块之间互不接触。
- 每个 3×3 方块中有 1 到 3 个像素被擦除为背景色（black），形成缺失位置。所有缺失像素集中在方块的某一侧边缘（上边缘、下边缘、左边缘或右边缘的一行或一列中）。

Rule:
- 对每个方块，观察其缺失像素所在的边缘方向：缺失在上边缘则方块向上滑动，缺失在下边缘则向下滑动，缺失在左边缘则向左滑动，缺失在右边缘则向右滑动。
- 滑动距离等于该方块中被擦除的像素数量（1、2 或 3）。
- 擦除原位置的方块像素，在新位置绘制完整的 3×3 方块（包括补全之前缺失的像素）。
- 如果滑动后方块会超出网格边界，则方块停在边界处（紧贴边缘）。

Key insight:
- 缺失像素同时编码了两个信息：缺口所在的边缘决定滑动方向，缺口的数量决定滑动距离。而且输出中方块是完整的——缺口在滑动后被"修复"。解题者需要发现缺口的双重语义（方向+距离），并注意输出方块是完整的 3×3 而非保留缺口。
</description>
</new_puzzle>
