<new_puzzle>
description：根据封闭框架内部碎片图案的对称性缺陷，从外部候选补丁中选取正确的补丁并旋转填入，使框架内部恢复指定对称性。

Input structure：
- 背景色为 black。网格分为左右两个区域，由一列 grey 分隔线隔开。
- 左侧区域包含一个较大的单色矩形框架（例如 blue），框架内部有一个图案，该图案接近某种对称性（水平镜像、垂直镜像或 90° 旋转对称），但其中一个矩形子区域被替换为背景色（即存在一个矩形空洞）。
- 右侧区域包含若干个与空洞尺寸相同的小色块补丁，每个补丁由不同颜色的单像素边框包裹，内部填有由框架颜色和背景色组成的图案。

Rule：
- 第一步：判断框架内部图案所接近的对称性类型——将空洞区域忽略后，检查剩余像素是否满足水平镜像、垂直镜像或 90° 旋转对称中的某一种（恰好满足一种）。
- 第二步：根据该对称性，计算出空洞位置在对称变换下应当包含的像素图案（即"期望补丁"）。
- 第三步：在右侧候选补丁中，找到与期望补丁在某个旋转（0°、90°、180°、270°）下完全匹配的那一个。
- 第四步：输出仅为左侧区域（不含分隔线和右侧），将匹配的补丁以正确旋转角度填入空洞位置。

Key insight：解题者必须先从不完整的图案中识别出它"想要成为"哪种对称性，再反推空洞应有的内容；候选补丁中只有一个在某个旋转下能恢复该对称性，其余都是干扰项。
</new_puzzle>

<new_puzzle>
description：将散落的彩色线段按颜色配对，然后沿两条线段的延长方向找到交点，在交点处绘制该颜色的十字标记。

Input structure：
- 背景色为 black。网格中散布着若干条水平或垂直的短线段（长度 2–5 像素），每种非背景颜色恰好出现两条线段。
- 同色的两条线段一条是水平方向，另一条是垂直方向。
- 线段之间互不接触，且同色两条线段的延长线恰好有唯一交点（交点在网格范围内且位于背景色像素上）。

Rule：
- 对每种颜色，找到该颜色的两条线段（一条水平、一条垂直）。
- 将水平线段所在的行与垂直线段所在的列求交，得到一个交点坐标。
- 在该交点处绘制一个由该颜色构成的十字标记：中心像素加上上下左右各延伸 1 像素，共 5 个像素。
- 原始线段保持不变。

Key insight：同色线段总是一横一竖地成对出现；解题者需要意识到交点不是线段端点的连接，而是将每条线段视为所在行/列的指示器，两条指示器的交叉定位了标记位置。
</new_puzzle>

<new_puzzle>
description：根据封闭区域内"种子"像素的颜色，选择对应颜色的印章模板，将模板图案铺满该封闭区域。

Input structure：
- 背景色为 black。网格上半部分是"模板区"，包含若干个由不同颜色绘制的小型图案模板（每个模板是一个 3×3 的图案，以某种非背景色绘制在背景上，模板之间至少间隔 1 像素）。
- 网格下半部分是"画布区"，包含若干个由 grey 像素构成的封闭单像素厚的矩形边框。每个矩形边框内部（背景色区域）恰好包含一个单像素的彩色"种子"，种子颜色与某个模板的颜色一致。
- 每个矩形边框的内部宽高都是 3 的整数倍。

Rule：
- 对每个 grey 矩形边框，读取其内部种子像素的颜色 C。
- 在模板区中找到颜色为 C 的 3×3 模板。
- 将该模板以 3×3 为单元平铺（tile）填满矩形边框的整个内部区域，模板从内部左上角开始对齐铺设。
- 移除种子像素（被铺设的模板图案覆盖）。
- 模板区在输出中保持不变。

Key insight：种子像素的作用不是标记位置而是索引模板——它的颜色是查找键，而铺设方式是固定的左上角对齐平铺；解题者需要先建立"颜色→模板"的映射关系，再理解平铺填充机制。
</new_puzzle>

<new_puzzle>
description：将网格中每个多色连通区域拆分为单色子区域，按面积从大到小分层"剥离"，每层向外偏移固定距离重新排列为同心框架。

Input structure：
- 背景色为 black。网格中包含若干个空间上分离的多色连通区域（每个区域由 2–4 种非背景色组成，各色子区域互相正交相邻，合在一起构成一个连通的整体）。
- 每个连通区域内各颜色子区域的面积互不相同。

Rule：
- 对每个多色连通区域，按颜色将其拆分为若干单色子区域。
- 按面积从大到小排序这些子区域：面积最大的颜色作为最外层，面积最小的颜色作为最内层。
- 输出中，每个连通区域被替换为同心矩形框架结构：最内层颜色填充为一个实心矩形，其尺寸为 1×1（单个像素）；次内层颜色包裹在外面形成 1 像素厚的边框（使整体变为 3×3）；再次外层颜色再包裹 1 像素厚边框（变为 5×5）；依此类推。
- 同心框架的中心位置与原始连通区域的视觉中心（bounding box 中心）对齐。

Key insight：解题者需要先发现拆分依据是颜色而非空间位置，再发现排列顺序由面积决定——面积越小越靠内；最终的同心框架结构编码了原始区域内各颜色的面积排名信息。
</new_puzzle>

<new_puzzle>
description：根据彩色路标的指示，将网格边缘的多条射线引导穿过迷宫，射线在路标处变色并转向，最终射线的颜色轨迹揭示了正确路径。

Input structure：
- 背景色为 black。网格边缘的某些像素是彩色"入口"像素（每个入口颜色不同）。
- 网格内部散布着若干 2×1 或 1×2 的"路标"小块，每个路标由两个不同颜色的像素组成，两个像素正交相邻。路标的两个像素分别称为"接收色"和"发射色"。
- 路标的朝向（水平或垂直）以及两个像素的排列顺序决定了转向规则。

Rule：
- 从每个边缘入口像素出发，沿垂直于网格边缘的方向向内发射一条射线，射线颜色与入口像素颜色相同。
- 射线沿直线前进，在背景像素上绘制当前颜色。
- 当射线碰到一个路标的"接收色"像素（即路标中与射线当前颜色相同的像素）时：射线在此处转弯 90°，转向从接收色像素指向同一路标内另一个像素（发射色像素）的方向；同时射线颜色变为该发射色。
- 如果射线碰到的路标中没有与射线当前颜色匹配的像素，射线直接穿过不受影响。
- 射线到达网格边缘时停止。
- 路标本身在输出中保持不变。

Key insight：路标是颜色敏感的——只有当射线的当前颜色与路标的其中一个像素匹配时才触发转向，否则射线会无视该路标；解题者需要追踪射线在每次转向后的颜色变化，才能判断后续哪些路标会被激活。这形成了一条"颜色链"式的推理路径。
</new_puzzle>

<new_puzzle>
description：网格中散落的单色形状是"钥匙"，带锁孔的彩色框架是"锁"；将每把钥匙旋转后插入形状匹配的锁孔，然后锁的框架颜色向外扩散一层。

Input structure：
- 背景色为 black。网格中有若干个不同颜色的单像素厚矩形框架（"锁"），每个框架内部有一个由背景色构成的连通空洞（"锁孔"），空洞形状不规则但面积为 2–5 像素。
- 网格中还有若干个由单一颜色绘制的小型连通形状（"钥匙"），每个钥匙的面积为 2–5 像素，颜色与所有框架颜色均不同。钥匙与框架空间上不接触。
- 每把钥匙恰好与某一个锁孔在 0°/90°/180°/270° 旋转下形状匹配（面积相同且像素轮廓吻合）。

Rule：
- 将每把钥匙与形状匹配的锁孔配对（允许旋转匹配）。
- 在输出中，将钥匙从原始位置移除。
- 将钥匙以正确的旋转角度填入对应锁孔内，钥匙保持自身颜色。
- 对每个已"解锁"的框架，将其框架颜色向外扩展 1 像素（即框架外侧所有正交相邻的背景像素变为框架颜色），形成加粗的框架效果。

Key insight：解题分三层——首先通过形状匹配（含旋转）建立钥匙与锁的配对关系，然后执行填入操作，最后触发框架的向外扩展效果；"解锁导致扩展"这一因果关系是需要从样例中额外归纳的隐蔽规则。
</new_puzzle>

<new_puzzle>
description：网格中的彩色矩形碎片是"拼图块"，将它们按边缘凸凹互补关系拼合，然后在拼合接缝处绘制边界线。

Input structure：
- 背景色为 black。网格中散布着若干个矩形彩色区域（"碎片"），每个碎片内部完全填充为单一颜色，碎片之间互不接触（至少间隔 2 像素）。
- 每个碎片的某些边缘上带有 1 像素宽的凸起（突出碎片矩形边界 1 像素的小齿），凸起颜色与碎片颜色相同。
- 同样，某些边缘上有 1 像素深的凹槽（从碎片矩形边界向内凹陷 1 像素的缺口，显示为背景色）。
- 碎片之间的凸起和凹槽可以互补咬合：一个碎片边缘的凸起位置恰好对应另一个碎片边缘的凹槽位置。

Rule：
- 通过凸起/凹槽的互补匹配，确定哪些碎片的哪条边应该拼合在一起。
- 在输出中，将所有碎片移动到正确位置使匹配的边紧密贴合（凸起填入凹槽），形成一个更大的组合图形。
- 拼合后，两个相邻碎片之间的接缝线（即原来的边界）用 grey 绘制：接缝线为 1 像素宽，位于两个碎片之间。
- 输出网格大小恰好为拼合后整体图形的 bounding box。

Key insight：凸起和凹槽不仅仅是装饰——它们是拼图的锁定机制，每条边的凸凹模式是唯一的，确保配对无歧义；解题者需要先识别这种机械互锁关系，再推断拼合后的空间布局。
</new_puzzle>

<new_puzzle>
description：网格中的每个对象自带"阴影方向指示器"，根据指示器的位置为对象投射对应方向的彩色阴影，阴影被其他对象阻挡时截断。

Input structure：
- 背景色为 black。网格中有若干个由非背景色填充的小型矩形对象（面积 2×2 到 4×4），每个对象颜色不同。
- 每个对象的某一侧外部紧贴着一个 grey 单像素点（"方向指示器"），该像素与对象正交相邻。方向指示器可以出现在对象的上、下、左、右任一侧。

Rule：
- 方向指示器表示阴影投射方向：指示器位于对象上方，则阴影向上投射；位于下方则向下；位于左侧则向左；位于右侧则向右。
- 从对象朝指示器方向的整条边出发，沿指示器方向逐像素延伸阴影。阴影颜色与对象颜色相同，但使用该颜色的"暗色版"：blue 的阴影色为 azure、red 的阴影色为 maroon、green 的阴影色为 yellow（即每种颜色有固定的阴影色映射，需从样例中归纳）。
- 阴影像素逐行/列延伸，直到碰到网格边缘或另一个对象（非背景、非阴影的像素）时停止。
- 方向指示器（grey 像素）在输出中被移除。
- 对象本身保持不变。

Key insight：解题者需要同时归纳两个独立规则——方向指示器与投射方向的空间对应关系，以及原色到阴影色的固定映射表；两者缺一不可才能正确生成输出。
</new_puzzle>
