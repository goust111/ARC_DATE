- `description`：根据边框上缺口的位置和颜色，从外部找到对应颜色的精灵，将其沿缺口方向推入边框内部，精灵在边框内壁反弹后最终固定。
- `Input structure`：
  - 背景为黑色（black）。
  - 网格中有一个大的单色矩形边框（如 blue），边框每条边上恰好有一个缺口（连续若干像素被替换为另一种颜色，该颜色即为缺口颜色）。
  - 边框外部散落着若干单色小精灵（4-连通，形状各异），每个精灵的颜色与某个缺口的颜色一致。
  - 边框内部初始为纯黑色背景。
- `Rule`：
  - 对每个缺口，找到与该缺口颜色相同的外部精灵。
  - 将该精灵沿缺口所在边的法线方向（指向边框内部）平移，精灵的前缘从缺口位置进入边框内部。
  - 精灵进入后沿该方向直线移动，直到其任意像素碰到边框内壁（即边框颜色的像素），此时精灵停止。
  - 精灵在原位置被擦除；停止后的精灵以其原色绘制在新位置。
  - 若多个精灵最终位置重叠，后进入的精灵覆盖先进入的（按缺口在边框上顺时针顺序处理）。
- `Key insight`：缺口颜色是精灵与入口的配对键，缺口所在的边决定了精灵的滑入方向，而边框内壁充当阻挡面决定精灵停靠位置。解题者需先识别缺口颜色与外部精灵的对应关系，再推断滑入方向与停靠逻辑。

- `description`：将散布在网格中的多个单色对象按各自包围的孔洞数量分组，然后用组内对象的颜色填充一个隐含的分层同心方框模板。
- `Input structure`：
  - 背景为黑色（black）。
  - 网格中散布着若干个单色 4-连通对象，每个对象形状各异，颜色不同。
  - 某些对象内部有被对象像素完全包围的黑色孔洞（4-连通封闭区域），孔洞数量从 0 到 N 不等。
  - 网格的一个角落有一个小的同心方框模板示意：由若干层嵌套的单像素宽方框组成，从外到内层数恰好等于对象中出现的不同孔洞数量的种类数，每层颜色为灰色（grey）。
- `Rule`：
  - 数出每个对象内部的封闭孔洞数量（0、1、2……）。
  - 按孔洞数量从少到多排序，得到颜色序列。
  - 在输出中，以模板示意的尺寸和位置为准，将同心方框模板的最外层涂为孔洞数量最少的那组对象的颜色，次外层涂为孔洞数量次少的那组颜色，依此类推，最内层涂为孔洞数量最多的那组颜色。
  - 如果同一孔洞数量对应多个对象（颜色不同），取面积（像素数）较大的对象的颜色。
  - 输出网格仅保留着色后的同心方框，其余区域为黑色。
- `Key insight`：对象本身的形状和位置都是干扰信息，真正的排序键是每个对象内部的封闭孔洞数量。解题者需先发现"孔洞计数→层级映射"这一非显然关系，再利用角落模板确定输出结构。
</new_puzzle>

- `description`：在由灰色墙壁分隔的房间网格中，每个房间包含一个彩色钥匙，墙壁上的彩色门与钥匙配对；从唯一无门可配的起点房间出发，逐房间画出穿越路径。
- `Input structure`：
  - 背景为黑色（black）。
  - 网格由灰色（grey）单像素宽墙壁分隔成若干矩形房间。
  - 每个房间内恰好有一个彩色单像素（钥匙），颜色各不相同。
  - 某些墙壁上有单像素缺口，缺口被涂成某种非灰色、非黑色的颜色（门）。每扇门的颜色与某个房间内的钥匙颜色相同。
  - 恰好有一个房间的钥匙颜色不与任何门匹配——该房间是路径的起点。
- `Rule`：
  - 从起点房间开始。在当前房间的墙壁上找到与当前房间钥匙颜色匹配的门（同一房间的墙上恰有一扇这样的门）。
  - 将钥匙像素擦除，从钥匙位置沿正交方向向门画一条该钥匙颜色的线段，穿过门进入相邻房间，直到碰到相邻房间的对面墙壁停止。
  - 进入新房间后，新房间原有的钥匙被擦除，该钥匙的颜色成为新的活跃颜色。在新房间墙壁上找到与新活跃颜色匹配的门，从线段末端沿正交方向画出新颜色的线段穿过该门，继续进入下一房间。
  - 当某个房间的墙壁上没有与当前活跃颜色匹配的门时（终点房间），该房间的钥匙保留不动，路径结束。
  - 所有被路径经过的门缺口像素被替换为经过时的线段颜色；未被路径经过的门保持原色不变。
- `Key insight`：解题者需先通过"哪个钥匙颜色没有对应的门"来识别起点，然后理解钥匙→门→穿越→下一房间的链式传递机制。每个房间既是一个环节的终点也是下一个环节的起点，形成三层推理：识别起点、理解穿越机制、追踪完整路径。
</new_puzzle>

- `description`：网格中的彩色箭头指向相邻的灰色矩形区域，箭头颜色决定区域的填充色，箭头朝向决定填充是按行还是按列进行交替条纹填充。
- `Input structure`：
  - 背景为黑色（black）。
  - 网格被灰色（grey）线条分割成若干矩形区域，每个区域内部初始全为黑色。
  - 在某些灰色分隔线的外侧（紧邻分隔线），有单像素宽的彩色箭头标记。箭头由三个像素组成：一个头部像素和两个尾部像素，排列成 T 形——T 形的竖笔（单独的那个像素）指示箭头方向。例如，若竖笔在右侧、两个尾部在左侧纵向排列，则箭头指向右方。
  - 每个箭头颜色各不相同，且箭头指向的方向恰好有一个相邻的灰色边界矩形区域。
- `Rule`：
  - 每个箭头控制它所指向的相邻矩形区域。
  - 如果箭头水平指向（左或右），则该区域按列填充：从箭头侧的边开始，第一列全部填充为箭头颜色，第二列跳过（保持黑色），第三列再填充，依此交替，直到区域的另一侧。
  - 如果箭头垂直指向（上或下），则该区域按行填充：从箭头侧的边开始，第一行全部填充为箭头颜色，第二行跳过，第三行再填充，依此交替。
  - 没有箭头指向的区域保持黑色不变。
  - 灰色分隔线本身保持不变。
- `Key insight`：解题者需要完成两层推理：首先识别 T 形标记的朝向以确定箭头方向（从而确定控制哪个区域以及填充是按行还是按列），然后理解交替填充的间隔模式。箭头的形状编码了方向信息，而方向同时决定了目标区域和填充轴。
</new_puzzle>

- `description`：根据网格顶部的颜色编码条筛选、旋转并重新排列散布在网格中的对象，编码条每段的颜色决定保留哪些对象，每段的长度编码该对象的旋转角度。
- `Input structure`：
  - 背景为黑色（black）。
  - 网格顶部第一行有一行颜色编码条，由若干段不同颜色的连续像素组成（段与段之间无间隔），每段长度为 1 到 4 个像素。
  - 网格其余区域散布着若干单色 4-连通对象，每个对象的颜色与编码条中的某一段颜色相同。
  - 可能存在颜色不在编码条中出现的对象（干扰项）。
- `Rule`：
  - 仅保留颜色出现在顶部编码条中的对象，丢弃所有颜色不在编码条中的对象。
  - 编码条中每段颜色的像素数决定该颜色对象的旋转角度：1 个像素 = 不旋转，2 个像素 = 顺时针旋转 90 度，3 个像素 = 顺时针旋转 180 度，4 个像素 = 顺时针旋转 270 度。
  - 将筛选并旋转后的对象按编码条中颜色从左到右的顺序，从左到右水平排列在输出网格中，相邻对象之间间隔一列黑色背景。
  - 所有对象底部对齐。
  - 输出网格的高度为所有旋转后对象中最高者的高度，宽度为所有对象宽度之和加上间隔列数。
- `Key insight`：编码条承担双重角色——它既是对象的颜色筛选器（决定哪些对象保留），又通过每段的长度隐式编码了旋转量。解题者需要先发现段长度与旋转角度的对应关系，再应用筛选-旋转-排列的三步流水线。
</new_puzzle>

- `description`：将网格中每个对称对象沿其对称轴"展开"为两个并排的半图案，展开方向由对象内部嵌入的单色标记像素决定。
- `Input structure`：
  - 背景为黑色（black）。
  - 网格中有若干单色 4-连通对象，每个对象关于某条轴（水平或垂直）具有镜像对称性。
  - 每个对称对象内部恰好嵌入一个不同颜色的单像素标记，该标记位于对称轴的某一侧（不在轴上）。
- `Rule`：
  - 对每个对称对象，找到其镜像对称轴（水平或垂直）。
  - 标记像素所在的那一侧为"保留侧"，另一侧为"擦除侧"。
  - 擦除侧的像素被清除为黑色背景。
  - 将保留侧的半个对象（含对称轴上的像素）复制一份，镜像翻转后放置在擦除侧的原始位置。
  - 同时将保留侧的原始半对象沿远离对称轴的方向平移，平移距离等于擦除侧半对象的宽度（若对称轴为垂直轴）或高度（若对称轴为水平轴）。

- `Key insight`：解题者需先识别每个对象的对称性和对称轴，然后通过标记像素的位置判断展开方向。对称轴的检测和标记的侧向定位构成两层独立的推理步骤，展开操作本身则是第三层空间变换理解。

<new_puzzle>
- `description`：网格中散布着若干彩色对象和同色的单像素锚点；每个对象需要与同色锚点配对，配对后对象被缩放至其像素数等于对象与锚点之间相隔的空行/列数，并放置在锚点位置。
- `Input structure`：
  - 背景为黑色（black）。
  - 网格中有若干单色 4-连通对象（至少 2 个像素），形状各异，颜色互不相同。
  - 每种对象颜色在网格中还有一个同色的孤立单像素（锚点），锚点不与对象相邻。
  - 每个对象与其同色锚点之间，沿水平或垂直方向上恰好对齐（即对象 bbox 的某条边与锚点在同一行或同一列上）。
- `Rule`：
  - 将每个对象与其同色锚点配对。
  - 计算对象 bbox 最近边缘与锚点之间的空格数（沿对齐方向，不含对象自身像素和锚点像素，只计中间的黑色像素数）。该数值记为 S。
  - 将对象的形状按比例缩放，使缩放后的对象总像素数等于 S。缩放方式：保持对象的整体轮廓形状，取对象 bbox 内像素占比最高的 S 个像素（按从左上到右下逐行扫描顺序选取）。
  - 将缩放后的对象放置在以锚点为中心的位置。
  - 原始对象和锚点像素被擦除。
- `Key insight`：解题者需先发现对象与同色锚点的配对关系，再发现"间距=目标像素数"这个非显然的数值映射，最后理解缩放和放置的具体方式。间距作为可视觉估算的小数值（通常不超过 8-10），在视觉上是可直觉感受的。
</new_puzzle>
