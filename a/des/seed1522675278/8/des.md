<new_puzzle>
根据框架颜色在镶嵌区域内播种对应颜色的缩小副本。

Input structure:
- 背景为黑色。
- 网格中有若干个由不同颜色边框围成的矩形框架（边框宽度为1像素），每个框架内部全部填充灰色。
- 每个框架内部的灰色区域中恰好有一个小型的非灰色、非边框色的彩色"种子"像素团（由1到3个同色像素组成的4连通块）。

Rule:
- 对每个框架，识别其边框颜色和内部种子的形状。
- 将种子的颜色替换为该框架的边框颜色，得到"模板图案"。
- 在该框架内部的灰色区域中，将模板图案以不重叠的方式从左上角开始逐行逐列平铺（像贴瓷砖一样），直到填满整个内部区域；超出边界的部分裁剪掉。
- 未被模板覆盖的剩余灰色像素保持灰色不变。

Key insight:
种子像素提供平铺的形状单元，而框架边框提供平铺所用的颜色；解题者需要先识别"种子形状"与"边框颜色"之间的映射关系，再理解平铺机制。
</new_puzzle>

<new_puzzle>
将散落的彩色碎片按颜色归入对应颜色围栏内，并在围栏中按碎片面积从小到大自下而上堆叠。

Input structure:
- 背景为黑色。
- 网格中有若干个由不同颜色构成的U形围栏（底部和两侧封闭、顶部开口的容器形状），每个围栏颜色各不相同。
- 网格中散布着若干个与围栏同色系的小型4连通色块（碎片），每个碎片的颜色恰好与某一个围栏的颜色相同。
- 碎片位于围栏外部的任意位置。

Rule:
- 将每个碎片归入与其颜色相同的围栏中。
- 对归入同一围栏的所有碎片，按面积（像素数）从小到大排序。
- 在围栏内部从底部开始向上堆叠：面积最小的碎片放在最底层，保持碎片原始形状不变，每个碎片水平居中放置（若围栏宽度大于碎片宽度，则左右留白尽量相等，奇数差时靠左）。
- 碎片之间紧密堆叠，不留空行。围栏和围栏外的碎片原始位置清除为背景色。

Key insight:
解题者需要先通过颜色匹配确定每个碎片属于哪个围栏（第一层推理），然后发现碎片在围栏内部是按面积排序堆叠的（第二层推理），两步归纳缺一不可。
</new_puzzle>

<new_puzzle>
根据箭头方向投射颜色射线，射线在撞到其他射线时混合产生第三种颜色。

Input structure:
- 背景为黑色。
- 网格中散布若干个彩色箭头。每个箭头由3个像素组成：一个箭头头部像素和两个箭尾像素构成直角形状，箭尾两像素相邻排成一行或一列，箭头头部像素在箭尾中点的延长线方向偏移一格，使整体呈现一个指向上、下、左或右的箭头。例如，向右的箭头：箭尾在(r-1,c)和(r+1,c)，箭头头部在(r,c+1)——即一个">"形。
- 每个箭头整体为同一种颜色，网格中恰好出现两种箭头颜色（例如红色和蓝色）。

Rule:
- 每个箭头从其头部像素开始，沿箭头指向的方向发射一条单像素宽的射线（用箭头自身颜色），射线延伸直到碰到网格边界或另一个箭头的实体像素为止。
- 当两条不同颜色的射线在同一像素位置交叉时，该像素变为第三种预设颜色（例如红色射线和蓝色射线交叉产生绿色）。交叉颜色在所有样例中保持一致。
- 箭头本身的像素保持不变。

Key insight:
解题者需要先识别箭头的朝向（从三像素的空间排列推断方向），然后理解射线的投射和终止规则，最后发现交叉点的颜色混合规则——三层视觉推理逐步叠加。
</new_puzzle>

在环形轨道上，根据轨道内部标记像素的数量将轨道上的移动块沿轨道顺时针旋转相应步数。

Input structure:
- 背景为黑色。
- 网格中有若干个由灰色像素构成的独立闭合环形轨道（宽度为1像素的矩形环）。
- 每个环形轨道上恰好有一个像素被替换为非灰色的彩色像素（称为"移动块"），其余轨道像素保持灰色。
- 每个环形轨道所围成的内部区域中散布着若干个红色标记像素（数量为1到6之间）。

Rule:
- 对每个环形轨道，数出其内部区域中红色标记像素的数量 N。
- 将该轨道上的彩色移动块沿轨道顺时针方向移动 N 步（每步移动到轨道上相邻的下一个像素位置）。
- 移动块离开的原始位置恢复为灰色。
- 红色标记像素和轨道的灰色部分保持不变。

Key insight:
解题者需要先识别出环形轨道的结构及其上的移动块（第一层），然后发现轨道内部的红色像素数量决定了移动步数（第二层），还需要正确判断顺时针方向沿环形路径行进的规则（第三层）。
</new_puzzle>

<new_puzzle>
将每个多色拼图块拆分为单色层，按颜色在调色板行中的出现顺序纵向展开排列。

Input structure:
- 背景为黑色。
- 网格顶部有一行"调色板行"：若干个不同颜色的像素从左到右排成一行，每个颜色占一个像素，颜色之间用黑色间隔一格。
- 调色板行下方隔若干行，有一个或多个由多种颜色混合构成的矩形拼图块（每个拼图块的边界框大小相同，且各块之间用黑色背景分隔）。
- 每个拼图块内部使用的颜色都是调色板行中颜色的子集。

Rule:
- 对每个拼图块，将其按颜色拆分为若干"单色层"：每一层与原拼图块尺寸相同，仅保留该颜色的像素，其余位置填充黑色。
- 按调色板行中颜色从左到右的出现顺序，将各单色层从上到下依次纵向排列（相邻层之间间隔一行黑色），替代原拼图块的位置。
- 调色板行本身在输出中被清除为黑色。
- 若拼图块中未使用调色板中的某种颜色，则跳过该层，不生成空白层。

Key insight:
解题者需要先发现调色板行定义了颜色的排序规则（第一层推理），然后理解每个拼图块被按颜色分解为独立层（第二层推理），最后发现各层的纵向排列顺序由调色板决定而非由像素数量或空间位置决定（第三层推理）。
</new_puzzle>

<new_puzzle>
通过镜像轴方向和对象缺口位置的配对，选择性地对对象执行翻转或保持不变。

Input structure:
- 背景为黑色。
- 网格中有若干个相同大小的彩色矩形对象（宽和高均为奇数），每个对象的某一条边的正中央有一个1像素的缺口（即该边中点像素为黑色背景色）。缺口可能出现在上、下、左、右四条边之一。
- 网格的正中央有一条由maroon像素构成的完整直线，要么是水平的（横贯整个网格宽度），要么是垂直的（纵贯整个网格高度），作为全局镜像轴。

Rule:
- 若某对象的缺口朝向镜像轴方向（例如轴是水平线且缺口在对象下边而轴在对象下方，或缺口在对象上边而轴在对象上方），则将该对象沿镜像轴翻转到轴的另一侧对称位置。
- 若对象的缺口朝向远离镜像轴的方向，则对象保持在原位不动。
- 翻转后的对象保留其颜色和缺口。被翻转对象的原始位置清除为黑色。
- 镜像轴本身保持不变。

Key insight:
解题者需要先识别全局镜像轴的方向（第一层），然后注意到每个对象缺口的朝向决定了该对象的行为——缺口面向轴则翻转、背离轴则不动（第二层推理），缺口不仅是装饰而是编码了对象与轴之间关系的指令信号。
</new_puzzle>

<new_puzzle>
识别网格中颜色相同的配对对象，用两者形状的差异像素连接它们。

Input structure:
- 背景为灰色。
- 网格中有若干个小型4连通色块，每种非背景颜色恰好出现两个色块（即成对出现）。
- 同色的两个色块形状相似但不完全相同：其中一个比另一个多出1到2个像素（称为"突出像素"）。
- 同色配对的两个色块在同一行或同一列上。

Rule:
- 对每对同色色块，找出两者之间的形状差异：将较大色块与较小色块对齐比较（以各自边界框左上角对齐），识别出较大色块中多出的"突出像素"。
- 从每个突出像素出发，沿着两个色块的连线方向（即同行则水平、同列则垂直）画一条连接线，延伸到另一个色块的边界框对应位置。
- 连接线使用该对色块的颜色。
- 原始色块保持不变。

Key insight:
解题者需要先通过颜色配对找到对应关系（第一层），再通过形状比较发现"突出像素"的位置（第二层），最后理解突出像素决定了连接线的具体行/列位置（第三层）——配对、比较、连接三步推理环环相扣。
</new_puzzle>
