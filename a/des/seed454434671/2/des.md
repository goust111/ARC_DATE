<description>
根据封闭区域内部"窗户"标记的朝向，选择对应角落的印章模板盖印到该区域中心。

Input structure:
- bg = black。网格中有若干个由 grey 像素围成的大型封闭矩形区域（内部空间约 7×7 到 10×10），矩形内部为 bg。
- 每个封闭矩形的某一侧内壁上贴有一个 2×1 的 azure 色"窗户"标记（两个相邻的 azure 像素紧贴矩形内壁，与该侧内壁平行）。窗户可能出现在上壁、下壁、左壁或右壁的内侧。
- 网格的四个角落区域（不与任何封闭矩形重叠）各放置一个小型彩色印章图案（3×3 到 4×4 的连通非 bg 图案，每个印章形状和颜色各不相同）。四个角落的印章与四个方向的对应关系为：左上角 = 上方向，右上角 = 右方向，左下角 = 左方向，右下角 = 下方向。

Rule:
- 第一层（方向识别）：对于每个封闭矩形，找到其内壁上的 azure 窗户标记，判断窗户贴在哪一侧壁（上/下/左/右）。
- 第二层（印章匹配与盖印）：窗户所在侧壁决定了使用哪个角落的印章。将对应角落的印章图案复制到该封闭矩形的内部中心位置（居中放置；若矩形内部空间与印章尺寸的奇偶性不同，则偏向左上一个像素）。
- 窗户标记在盖印后仍然保留，不被覆盖。角落的印章原件保留。灰色边框保留。bg 区域不变。

Key insight: 窗户的位置并非指示盖印的目标坐标，而是作为方向编码来索引四个角落中的印章模板——需要发现"角落位置与方向之间的映射关系"这一隐含规则。
</description>

<description>
将网格中贯穿的灰色线条用彩色形状"切割染色"：线条在形状内部的部分染为形状颜色，线条在形状外部的部分被擦除。

Input structure:
- bg = black。网格中有若干条贯穿整个网格的水平或竖直的 grey 线条（宽度 1 像素，从网格一侧边缘延伸到对侧边缘）。
- 网格中还有若干个不重叠的实心彩色形状（4-连通连通区域），颜色从 red、blue、green、yellow、magenta 中选取，形状大小约 3×3 到 6×6 不等。这些形状可能与 grey 线条在空间上交叉。

Rule:
- 对于每条 grey 线条，检查它与哪些彩色形状的区域有重叠（即线条像素与形状像素位于同一格）。
- 线条与形状重叠的部分：该像素着色为该形状的颜色（形状颜色覆盖 grey）。
- 线条在所有形状区域之外的部分：全部擦除为 bg。
- 如果一条线条未穿过任何形状，则整条线条擦除。
- 彩色形状本身保持不变——形状内部原本不在线条上的像素仍然显示形状颜色。

Key insight: 灰色线条不是输出的主体，而是被形状区域"筛选"的对象——形状像模具一样只保留线条与自身重叠的部分并赋予形状颜色。这种"模具切割"的隐喻需要从多个样例中归纳。
</description>

<description>
在画布内根据稀疏锚点反推周期平铺的偏移量，用外部提供的 tile 模板填满整个画布。

Input structure:
- bg = black。网格中有一个由 blue 像素围成的矩形边框（宽度 1 像素），内部为"画布"区域，画布初始大部分为 bg。
- 画布内散布着少量（3-6 个）相同颜色的锚点像素（如 red），这些锚点的位置呈周期性分布：它们是某个小型 tile（尺寸 2×2 或 3×3）按固定行列周期在画布上平铺时，tile 中非 bg 像素恰好落在画布范围内的可见位置。
- 边框外部的网格某处（与边框不相邻）放置着一个与锚点同色的完整 tile 样本——一个小的连通图案，展示 tile 的完整形状和尺寸。

Rule:
- 第一层（识别 tile）：在边框外找到与锚点颜色相同的完整 tile 样本，确定 tile 的形状和尺寸（宽 W、高 H）。
- 第二层（推断平铺偏移）：观察画布内锚点像素的位置，推断平铺的起始偏移量（dr, dc），满足 0 ≤ dr < H 且 0 ≤ dc < W。所有锚点必须落在以画布左上角为参考、偏移 (dr, dc) 开始、以 (H, W) 为周期的平铺网格中 tile 的非 bg 像素位置上。偏移量由锚点位置唯一确定。
- 第三层（填充画布）：以确定的偏移和周期，将 tile 图案在整个画布内完整平铺。画布内原有的 bg 像素被 tile 的非 bg 像素覆盖。边框本身和边框外的所有内容（包括 tile 样本）保持不变。

Key insight: 锚点像素看似随机散布，实则是周期平铺的采样残留——需要先在外部识别 tile 模板，再反推平铺的相位偏移，最后才能完成填充。三层推理环环相扣。
</description>

<description>
根据容器内彩色液面的高度差异，将液面较低的容器"注水"到与同色液面最高的容器齐平，注水颜色由容器底部的标记决定。

Input structure:
- bg = black。网格底部有一排由 grey 像素构成的若干个开口朝上的矩形"容器"（U 形结构：两侧竖直壁 + 底部水平壁），容器宽度 3-5 像素，高度 6-10 像素，容器之间有 1-2 列 bg 间隔。
- 每个容器底部正中有一个 1 像素的颜色标记（从 red、blue、green、yellow 中选取），表示该容器的类别。
- 部分容器内部从底部向上填充了与底部标记同色的"液体"像素（连续的矩形色块，宽度等于容器内部宽度），液面高度各不相同。部分容器可能完全为空（只有底部标记）。

Rule:
- 第一层（按颜色分组）：将所有容器按底部标记颜色分组。
- 第二层（找最高液面）：在每个颜色组中，找到液面最高的容器（液体像素从底部标记上方起算的行数最多的那个）。
- 第三层（注水补齐）：将同组中所有其他容器的液面补齐到该最高液面的高度——从现有液面顶部向上继续填充同色像素，直到液面行数与组内最高者相同。如果容器已经是最高液面，则不变。
- 灰色容器壁、底部标记、bg 区域均不变。

Key insight: 解题者必须先发现底部标记的颜色定义了分组，再发现同组内取最高液面作为目标，最后对组内其他容器进行补齐——需要跨容器比较而非对每个容器独立操作。
</description>

<description>
在迷宫网格中找到每个彩色标记能看到的同色标记数量，然后将标记周围与该数量相等的空白格填充为该颜色。

Input structure:
- bg = black。网格中有由 grey 像素构成的 1 像素宽的墙壁，形成不规则的迷宫结构（但没有完全封闭的房间，迷宫是连通的）。
- 迷宫的通道（bg 像素形成的路径）中散布着若干彩色标记像素，颜色从 red、blue、green、yellow 中选取。每种颜色出现 2-4 个标记。

Rule:
- 第一层（视线判定）：对于每个彩色标记，沿上下左右四个方向做视线检测——视线沿直线延伸，遇到 grey 墙壁或网格边缘则停止。如果视线在停止前经过了同色的另一个标记像素，则这两个标记"互相可见"。
- 第二层（计数与填充）：对于每个彩色标记，数出它能看到的同色标记数量 K（0 ≤ K ≤ 3）。然后从该标记出发，沿四个方向（按上、右、下、左的优先级顺序）检查相邻的 bg 像素，将前 K 个可用的相邻 bg 格填充为该标记的颜色。"可用"指该格为 bg 且不是墙壁。如果某方向相邻格不可用，则跳过该方向继续下一个方向。
- 标记本身保持不变，grey 墙壁不变。

Key insight: "能看到多少同色标记"这一信息需要通过直线视线检测获得，而这个数量又决定了填充多少相邻格——视线检测和计数驱动填充是两层嵌套的推理。
</description>

<description>
将分散的彩色碎片按形状互补性配对拼合为完整矩形，再根据碎片所在网格半区的位置决定拼合矩形的放置区域。

Input structure:
- bg = black。网格被一条水平的 grey 分隔线（宽度 1 像素，贯穿网格全宽）分为上下两个半区。
- 上半区和下半区各散布着若干单色碎片（4-连通连通区域）。碎片颜色从 red、blue、green、yellow、orange 中选取。
- 每个碎片的形状是某个矩形的一部分。恰好有一个上半区碎片和一个下半区碎片能配对：它们颜色相同，最小外接矩形（bounding box）尺寸相同，且一个碎片在 bounding box 中占据的像素恰好是另一个碎片在同尺寸 bounding box 中未占据的像素（几何互补）。

Rule:
- 第一层（跨半区配对）：对于每种颜色，找到上半区和下半区中 bounding box 尺寸相同的同色碎片对，验证它们形状互补（拼合后恰好填满一个完整矩形）。
- 第二层（拼合放置）：将配对成功的两个碎片拼合为一个完整的实心矩形。该矩形放置在下半区中原来下半区碎片的 bounding box 位置，颜色为该碎片对的颜色。
- 上半区中已配对的碎片被擦除（变为 bg），下半区中原碎片被替换为拼合后的完整矩形。未配对的碎片原样保留。grey 分隔线保留。

Key insight: 碎片配对需要跨越分隔线在两个半区之间寻找几何互补关系，而不是在同一区域内匹配——分隔线既是视觉分界也是配对规则的隐含约束。
</description>

<description>
将网格中的箭头形状沿其指向方向推进，直到箭头尖端触碰到与箭头同色的目标色块，然后箭头"嵌入"目标色块并将色块中被箭头覆盖的部分挖空。

Input structure:
- bg = black。网格中有若干个彩色箭头形状和若干个同色的目标色块。
- 每个箭头由 5 个像素组成：一个 1×3 的竖直杆（或 3×1 的水平杆）加上杆一端的两个斜对角像素形成尖端，构成明确的指向方向（上/下/左/右）。箭头颜色从 red、blue、green、yellow 中选取。
- 目标色块是大型实心矩形（至少 4×4），与对应箭头颜色相同。每种颜色恰好有一个箭头和一个目标色块，它们之间沿箭头指向方向有一段 bg 间隔。

Rule:
- 第一层（识别箭头方向）：根据箭头的尖端像素相对于杆的位置，确定箭头指向的方向。例如尖端在杆的上方则指向上。
- 第二层（推进箭头）：将箭头沿其指向方向平移，直到箭头尖端的下一步会进入同色目标色块的区域（箭头尖端像素与色块相邻）。
- 第三层（嵌入挖空）：箭头再前进一步，使箭头像素与色块重叠。重叠处的色块像素被擦除为 bg（形成箭头形状的孔洞），箭头本身也被擦除。箭头原来的位置变为 bg。
- 不同颜色的箭头和色块独立处理，互不影响。

Key insight: 箭头的最终效果不是"画上去"而是"挖掉"——它在色块上留下自身形状的负空间。需要先识别箭头方向、再模拟推进、最后理解嵌入挖空的逆直觉操作。
</description>
</new_puzzle>
