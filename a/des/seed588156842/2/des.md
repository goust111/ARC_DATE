description: 根据彩色种子像素在封闭区域内生长出与相邻区域互补的填充图案。

Input structure:
- 背景色为 black。网格中有若干由 grey 线段围成的封闭矩形区域，区域之间共享边界墙壁。
- 每个区域内部恰好有一个彩色种子像素（颜色各不相同，可能为 red、blue、green、yellow、orange 等）。
- 部分区域的边界墙壁上开有一个单像素宽的缺口（即墙壁上有一个 black 像素），该缺口连通相邻的另一个区域。

Rule:
- 第一步：确定每个区域的"图案类型"。观察种子像素在区域内的位置——若种子在区域的角落（距两面墙各一格），则该区域的图案类型为"棋盘格"（种子色与 black 交替）；若种子在区域某条边的中点位置，则图案类型为"横条纹"（种子色与 black 交替的水平条纹）；若种子不在角落也不在边中点（即在区域内部偏心位置），则图案类型为"竖条纹"。
- 第二步：确定每个区域的实际填充颜色。若一个区域通过缺口与相邻区域连通，则该区域不使用自己种子的颜色，而是使用通过缺口连通的那个相邻区域的种子颜色来绘制图案。若区域没有缺口（完全封闭），则使用自身种子颜色。
- 第三步：用确定的颜色和图案类型填充每个区域的全部内部空间（种子像素本身被覆盖）。缺口保持为 black，墙壁保持为 grey。

Key insight: 种子的位置编码了图案类型（角落/边中/内部 → 棋盘/横条/竖条），而墙壁缺口决定了颜色的跨区域借用——解题者需要同时发现位置-图案映射和缺口-颜色传递两层规则。
</new_puzzle>

description: 将散落的彩色碎片按形状匹配拼入模板轮廓，并根据碎片的来源方向决定其在模板内的着色层级。

Input structure:
- 背景色为 black。网格中央有一个由 grey 像素绘制的大型不规则轮廓（封闭的单像素宽边框），内部全为 black，构成一个"模板空腔"。
- 模板轮廓的上、下、左、右四个方向各散布着若干彩色小碎片（每个碎片是一个连通的单色形状，颜色可能为 red、blue、green、orange、magenta 等）。碎片的形状各不相同。
- 模板空腔的内部可被精确地分割为若干与碎片形状完全匹配的子区域（允许碎片做 90° 旋转），恰好无缝拼满。

Rule:
- 第一步：将每个碎片（允许旋转 0°/90°/180°/270°）拼入模板空腔中唯一匹配的位置，使所有碎片恰好填满整个空腔。
- 第二步：确定每个碎片拼入后的颜色。碎片不保留其原始颜色，而是根据碎片相对于模板的来源方向着色：从模板上方来的碎片着 red；从下方来的着 blue；从左方来的着 green；从右方来的着 yellow。来源方向的判定依据是碎片中心到模板中心的主方向（水平偏移大于垂直偏移时取左/右，反之取上/下）。
- 输出仅包含填满后的模板区域（grey 边框 + 着色后的内部），模板外的碎片全部移除。

Key insight: 解题者需要先完成空间拼图（形状匹配+旋转），再发现碎片的原始位置方向决定了填充颜色——拼图层和着色层是两个独立的推理步骤。
</new_puzzle>

description: 在网格中识别隐含的传送门配对，将每个彩色信号沿导线传输并在传送门出口处改变方向继续前进。

Input structure:
- 背景色为 black。网格中有若干由 grey 像素构成的单像素宽直线段（水平或垂直），这些是"导线"。
- 导线的端点处有彩色像素（red、blue、green、orange 等），这些是"信号源"，每种颜色恰好出现一次。
- 网格中散布着若干成对的相同颜色小方块（2×2），颜色为 maroon 或 azure 等非信号色。每种颜色的 2×2 方块恰好出现两个，构成一对"传送门"。
- 每个传送门方块紧贴某条导线的中段（与导线某个像素相邻）。

Rule:
- 每个信号源沿其所在导线的方向传播（将导线上的 grey 像素替换为信号源的颜色），直到遇到一个传送门方块。
- 信号到达传送门后，"跳转"到与之配对的同色传送门的位置，从配对传送门所贴合的导线上继续传播。
- 传播方向的确定：信号从传送门进入的方向（水平/垂直）在出口处旋转 90°。即若信号沿水平导线到达传送门 A，则在配对传送门 B 处沿垂直导线继续；反之亦然。
- 信号继续传播直到导线末端或再次遇到传送门（可多次跳转）。
- 传送门方块本身保持原色不变；信号最终覆盖所经过的全部导线像素。

Key insight: 解题者首先需要发现 2×2 同色方块是成对的传送门（配对规则），然后理解信号在跳转时会旋转 90° 改变传播轴向——传送门配对是第一层推理，方向旋转是第二层推理。
</new_puzzle>

description: 根据彩色标记像素的排列顺序对网格中的图形对象进行分层裁剪与叠放。

Input structure:
- 背景色为 black。网格中有若干彩色矩形图形（实心填充，颜色各不相同，如 red、blue、green、yellow、orange），这些矩形在空间上互不重叠。
- 网格的最底行（或最右列）有一排单像素的彩色标记，颜色与上述矩形一一对应，标记从左到右（或从上到下）排成一行。
- 每个矩形内部恰好有一个 grey 像素，位于矩形的某个位置。

Rule:
- 第一步：读取底行标记的颜色顺序，这定义了矩形的叠放优先级——左边的标记对应的矩形放在最底层，右边的放在最顶层。
- 第二步：确定叠放的锚点。每个矩形内部的 grey 像素是该矩形的"锚点"。在输出中，所有矩形的锚点必须对齐到同一个网格位置（即输出网格的中心）。
- 第三步：按照叠放优先级从底到顶依次绘制矩形（锚点对齐到输出中心），后绘制的矩形覆盖先绘制的。超出输出网格边界的部分被裁剪。
- 输出网格的尺寸等于最大矩形的尺寸。底行标记和 grey 锚点像素不出现在输出中（被矩形颜色覆盖）。

Key insight: 解题者需要发现三个独立规则：底行标记编码叠放顺序、grey 像素是对齐锚点、输出是锚点对齐后的分层叠放结果。标记顺序和锚点位置共同决定了最终图案中各颜色区域的可见范围。
</new_puzzle>

<new_puzzle>
description: 在镜像对称的网格中找出不对称的"污点"像素，利用污点的颜色和位置生成修复图案。

Input structure:
- 背景色为 black。网格整体呈现近似的左右镜像对称结构，由多种颜色（red、blue、green、yellow、orange 等）构成复杂图案。
- 对称轴是网格的垂直中线。
- 网格中有少量像素破坏了完美对称——这些"污点"像素的颜色与其镜像位置的像素颜色不同。污点像素的颜色不是 black，其镜像位置的像素也不是 black（即两侧都有颜色，但颜色不匹配）。
- 网格底部有一个单行的"颜色映射条"：若干对相邻的彩色像素，每对中左边的颜色映射到右边的颜色（对之间用 black 像素分隔）。

Rule:
- 第一步：找到所有破坏左右镜像对称的像素对。对于每一对不匹配的像素 (左, 右)，"正确颜色"是在该行中出现次数更多的那个颜色（即多数侧为正确侧），"污点颜色"是少数侧的颜色。
- 第二步：将每个污点像素的颜色通过底部颜色映射条进行转换——在映射条中查找污点颜色，替换为其映射目标颜色。
- 第三步：在污点像素的位置绘制一个 3×3 的十字形（中心 + 上下左右四个像素），颜色为映射后的颜色。十字形超出网格的部分裁剪。同时将污点像素的镜像位置也绘制相同的十字形。
- 底部映射条在输出中被移除（替换为 black）。

Key insight: 解题者需要先通过对称性检测定位污点（第一层），再发现底部映射条提供颜色转换规则（第二层），最后理解修复方式是在两侧对称地绘制转换后颜色的十字形（第三层）。三层推理缺一不可。
</new_puzzle>
