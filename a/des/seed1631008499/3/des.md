<description>
根据彩色"钥匙"条的颜色序列解锁对应"锁"框架，并用钥匙颜色序列填充锁内的空腔。

Input structure:
- bg = Black。网格中散布着若干由 Grey 线段围成的空心矩形框（"锁"），每个锁框的一侧边框上有一个 1 像素宽的缺口。
- 网格中另有若干水平或竖直的短彩色条（"钥匙"），每根钥匙由 2-4 个不同颜色的像素排成一排构成，形成一个颜色序列。
- 每把钥匙恰好有一个像素的颜色与某个锁框缺口旁边框像素的颜色相同（该颜色在钥匙中仅出现一次），以此匹配钥匙与锁。

Rule:
- 第一步：通过钥匙中包含的唯一匹配色将每把钥匙与对应的锁配对。匹配色是指钥匙上某个像素的颜色与锁框缺口两侧相邻边框像素的颜色一致（该锁框的边框中恰好有一个像素被替换为该特殊颜色）。
- 第二步：确定钥匙的颜色序列方向——从匹配色像素出发，沿钥匙延伸方向读取剩余颜色，形成有序颜色列表。
- 第三步：将锁框内部的空腔按行（从上到下）逐行填充：第一行填钥匙序列的第一个颜色，第二行填第二个颜色，依此类推。若行数多于钥匙颜色数，则循环使用颜色序列。
- 钥匙条在输出中被移除（还原为 bg）。

Key insight: 解题需要两层非平凡推理——首先通过边框上的特殊颜色像素将钥匙与锁匹配，然后理解钥匙的读取方向（从匹配色出发）决定了锁内部的逐行填色顺序。
</description>
</new_puzzle>

<description>
将散落在网格中的彩色碎片按形状互补性拼合，拼合后的完整矩形用两块碎片中面积较小者的颜色重新着色。

Input structure:
- bg = Black。网格中散布着若干彩色连通区域（碎片），每个碎片的颜色各不相同。
- 每个碎片的外接矩形（bounding box）大小相同（例如都是 4×4）。
- 碎片两两配对：同一对中的两个碎片在其外接矩形内互为补集——即一个碎片填充的像素恰好是另一个碎片在同尺寸矩形中留空的像素，合在一起恰好拼成一个完整的实心矩形。

Rule:
- 第一步：识别所有碎片的外接矩形，确认它们尺寸一致。对每个碎片，提取其在外接矩形内的形状掩码（哪些位置被填充）。
- 第二步：将形状掩码互补的两个碎片配对——即碎片 A 的填充位置并上碎片 B 的填充位置恰好覆盖整个矩形，且无重叠。
- 第三步：对每一对碎片，比较两者的像素数量（面积），将面积较小的碎片的颜色作为该对的目标颜色。
- 第四步：在输出中，将配对的两个碎片合并到面积较大碎片的原始位置，形成一个完整的实心矩形，整个矩形使用目标颜色（面积较小者的颜色）着色。面积较小碎片的原始位置清除为 bg。

Key insight: 解题者需先发现碎片之间的形状互补关系（而非颜色关系），再推理出合并后颜色取决于面积比较这一隐含规则。两层推理缺一不可：互补配对决定了"谁和谁合并"，面积比较决定了"用什么颜色"和"合并到哪里"。
</description>
</new_puzzle>

<new_puzzle>
<description>
在由彩色边框划分的子区域中，根据区域内"种子"像素的数量决定该区域的填充图案类型（实心、横条纹或棋盘格），图案颜色由种子颜色决定。

Input structure:
- bg = Black。网格被 Grey 颜色的水平线和竖直线划分为若干矩形子区域（类似网格表格）。
- 每个子区域的内部（不含 Grey 边界）要么为纯 bg（空区域），要么包含 1 至 3 个散落的彩色像素（种子）。所有种子在同一区域内颜色相同。
- 空区域在输出中保持不变。

Rule:
- 对每个非空子区域，数出其中种子像素的个数 N，并记录种子颜色 C。
- N = 1：将该区域内部全部填充为颜色 C（实心填充）。
- N = 2：将该区域内部填充为水平条纹图案——从区域内部第一行开始，奇数行（第 1、3、5…行）填充颜色 C，偶数行保持 bg。
- N = 3：将该区域内部填充为棋盘格图案——内部左上角位置为颜色 C，然后颜色 C 与 bg 交替排列形成棋盘。
- 种子像素本身在填充后被图案覆盖（即种子只是触发器，不保留原始位置）。

Key insight: 解题者需要同时归纳两个独立维度的规则——种子数量到图案类型的映射（1→实心、2→条纹、3→棋盘），以及种子颜色到填充色的传递。数量-图案的对应关系是核心隐蔽机制，因为三种图案的视觉差异很大，不易立即联想到与种子计数的关联。
</description>
</new_puzzle>

<description>
沿着彩色"导轨"传递形状印章：路径中每个转弯方向决定印章的旋转，最终在导轨终点处盖印旋转后的形状。

Input structure:
- bg = Black。网格中包含以下元素：
- 一个由 Maroon 颜色绘制的小型非对称形状（3×3 至 4×4 的不规则图案），作为"印章"原型，位于网格的某个位置。
- 若干条由不同颜色像素排成的直线段（"导轨"），每条导轨为水平或竖直方向，长度不一。导轨之间通过端点相邻（4-连通）首尾衔接，形成一条从印章出发的折线路径。
- 路径的最远端（远离印章的末端）旁有一个由 Grey 绘制的空心矩形框，框的大小恰好能容纳印章。

Rule:
- 第一步：从印章位置出发，沿着与印章相邻的导轨开始追踪路径。路径由多段不同颜色的导轨首尾相接构成。
- 第二步：确定每段导轨之间的转弯方向——若路径在某段末端向右转（顺时针 90°），则印章顺时针旋转 90°；若向左转（逆时针 90°），则印章逆时针旋转 90°；若直行进入下一段（不转弯），则不旋转。
- 第三步：将所有旋转依次叠加后，得到印章的最终朝向。
- 第四步：在 Grey 框内绘制经过最终旋转后的印章形状，颜色使用路径最后一段导轨的颜色。印章原型和导轨在输出中保持不变。

Key insight: 解题者需要三层推理——首先识别导轨的衔接顺序形成路径，然后理解每个转弯方向对应一次旋转操作，最后将多次旋转累积应用到印章上。路径的转弯方向隐含在导轨的空间排列中，而非显式标注。
</description>

<new_puzzle>
<description>
将网格中的彩色"信号塔"沿其箭头指向发射射线，射线在遇到"镜面"时反射改变方向，最终射线覆盖的路径用信号塔的颜色绘制；两条不同颜色的射线交叉处变为第三种指定颜色。

Input structure:
- bg = Black。网格中包含以下元素：
- 若干"信号塔"：每个信号塔由一个 2×2 的彩色实心方块和一个从方块某一侧边中点向外延伸 1 像素的同色突起组成，突起的方向即为信号发射方向（上/下/左/右）。不同信号塔颜色不同。
- 若干"镜面"：由 Grey 颜色绘制的 45° 对角线段（长度为 2-4 像素），分为两种朝向——从左上到右下（"\"型）和从左下到右上（"/"型）。
- 网格右下角有一个 1×1 的特殊颜色像素（"混合色指示器"），该颜色不同于任何信号塔或镜面的颜色。

Rule:
- 第一步：从每个信号塔的突起方向发射一条射线，射线沿该方向逐像素前进，将路径上的 bg 像素染为信号塔的颜色。
- 第二步：当射线碰到镜面时发生反射——"/"型镜面将水平运动变为竖直（向右→向上，向左→向下，向上→向右，向下→向左），"\"型镜面将水平运动变为竖直（向右→向下，向左→向上，向上→向左，向下→向右）。射线反射后继续前进。
- 第三步：射线在碰到网格边界或信号塔实体（2×2 方块部分）时终止。
- 第四步：若两条不同颜色的射线经过同一个像素，该像素的颜色替换为右下角混合色指示器的颜色。
- 信号塔、镜面和混合色指示器在输出中保持不变。

Key insight: 解题者需要先识别信号塔的发射方向（通过突起的位置推断），然后模拟射线的反射路径（理解两种镜面朝向的反射规则），最后发现射线交叉点的颜色混合规则。三层机制环环相扣：方向识别→反射模拟→交叉混色。
</description>
</new_puzzle>
