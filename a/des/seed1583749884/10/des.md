<new_puzzle>
- `description`：在一组散布的标记像素中，根据每个标记所在的网格象限确定其移动方向，将标记移至该象限的角落处堆叠。

- `Input structure`：
  - 背景为 Azure。
  - 网格被逻辑上分为四个等大象限（无可见分隔线）。
  - 网格中散布着若干彩色单像素标记（使用 Red、Blue、Green、Yellow 等颜色），分布在各象限中。

- `Rule`：
  - 左上象限的标记移动到网格左上角，从角落开始逐行填充（先填第 0 行从左到右，再填第 1 行）。
  - 右上象限的标记移动到右上角，从角落开始逐行填充。
  - 左下象限的标记移动到左下角，从角落开始向上逐行填充。
  - 右下象限的标记移动到右下角，从角落开始向上逐行填充。
  - 标记按其原始位置的行优先顺序排列。保持标记原色。
  - 清除标记原始位置为背景色。

- `Key insight`：象限归属决定了标记的目标角落；标记的原始位置仅影响排列顺序——这是一种隐式的空间分组加重排机制。
</new_puzzle>

<new_puzzle>
- `description`：在每行中找到唯一的"异类"颜色像素（与该行多数颜色不同），然后将该异类像素向下移动到与其所在列上最近的同色像素相邻。

- `Input structure`：
  - 网格由多种颜色构成，无明确背景色。
  - 每行有一个占多数的颜色和恰好一个不同颜色的"异类"像素。
  - 异类像素的颜色可能在不同行中不同。

- `Rule`：
  - 对每行，找到唯一的异类像素（颜色与该行其余像素不同的那个）。
  - 在异类像素所在的列中，向下搜索第一个与异类同色的像素。
  - 将异类像素从原位置移除（替换为该行的多数色），放置在目标同色像素正上方的空位（如果该位置已有像素则用异类色覆盖）。

- `Key insight`：每行的"行内少数派"向下寻找列内同色像素——行维度用于检测异类，列维度用于重定位，两个正交的规则交织在一起。
</new_puzzle>

<new_puzzle>
- `description`：将网格中相邻的同色像素对连接为条带，连接方向由像素对的相对位置决定，然后在条带两端绘制箭头标记。

- `Input structure`：
  - 背景为 Black。
  - 网格中散布着若干彩色单像素点（使用 Red、Blue、Green 等颜色），每种颜色恰好出现两个像素。
  - 同色的两个像素在水平或垂直方向上对齐。

- `Rule`：
  - 对每对同色像素，用该颜色填充两者之间的所有背景像素，形成一条直线条带。
  - 在条带的两端各绘制一个垂直于条带方向的一像素延伸（使用 Yellow），形成"T"形箭头端。
  - 保持非配对区域的像素不变。

- `Key insight`：同色像素对定义了条带的端点；条带方向自动由对齐方向决定，而箭头的朝向总是垂直于条带——两者共同构成了完整的视觉连接图案。
</new_puzzle>

<new_puzzle>
- `description`：根据每个封闭多边形内部包含的标记数量，选择将多边形的边框线加粗（标记多）或变细（标记少）。

- `Input structure`：
  - 背景为 Black。
  - 网格中有若干个由不同颜色一像素厚线段围成的封闭矩形轮廓（如 Red 框、Blue 框、Green 框）。
  - 每个框内部散布着 0-4 个 Yellow 标记像素。

- `Rule`：
  - 对每个彩色框，数出其内部的 Yellow 标记数量 N。
  - 如果 N >= 3：在框外侧再绘制一圈同色边框（使边框总厚度变为 2 像素）。
  - 如果 N == 1 或 2：保持边框不变。
  - 如果 N == 0：将边框擦除为背景色（框消失）。
  - 清除所有 Yellow 标记像素为背景色。

- `Key insight`：标记数量不是填充色的选择键，而是控制框本身存在与否及粗细的"元指令"；0 标记导致框消失这一极端情况是规则的隐蔽部分。
</new_puzzle>

<new_puzzle>
- `description`：在一个由重复模块组成的网格中，找到被修改过的模块，将修改过的像素位置在其他所有模块中高亮标记。

- `Input structure`：
  - 背景为 Black。
  - 网格由 Grey 分隔线分为 NxM 个等大的矩形模块。
  - 所有模块的内容应该完全相同（同一个多色图案的副本），但恰好一个模块中有若干像素被修改（颜色与其他模块对应位置不同）。

- `Rule`：
  - 通过模块间的多数投票，确定正确的模块图案。
  - 找到唯一与正确图案不同的模块。
  - 确定该模块中被修改的像素位置（局部坐标）。
  - 在所有其他模块（正确模块）中，将这些对应位置的像素重着色为 Magenta。
  - 被修改的模块保持不变（保留修改后的错误内容）。

- `Key insight`：错误模块本身不被修正，而是其错误位置被"广播"到所有正确模块中作为标记——这是一种逆向的错误传播机制。
</new_puzzle>
