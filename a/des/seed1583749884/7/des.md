<new_puzzle>
- `description`：将分隔面板中的同色精灵按其内部孔洞数量排序，然后按排序顺序重新排列到输出画布的指定位置。

- `Input structure`：
  - 背景为 Black。
  - Grey 色的完整行将网格分为上下两个面板。
  - 上面板包含 3-5 个等大的单色矩形精灵（各使用不同颜色），排成一行，间隔一像素。每个精灵内部可能包含 0-3 个背景色孔洞。
  - 下面板为空白（全背景色）。

- `Rule`：
  - 对上面板的每个精灵，计算其内部 4-连通背景孔洞的数量。
  - 按孔洞数量从少到多排序精灵。孔洞数量相同则保持原始从左到右顺序。
  - 在下面板中，按排序后的顺序从左到右排列精灵，保持间隔一像素、顶部对齐。
  - 清除上面板的精灵为背景色。保持 Grey 分隔行不变。

- `Key insight`：孔洞数量是排序键，而非精灵的颜色或原始位置；解题者需要先发现孔洞计数规律，再理解重排列机制。
</new_puzzle>

<new_puzzle>
- `description`：每个前景对象作为"印章"，其像素数量决定了印章在输出中被重复盖印的次数，排成一行。

- `Input structure`：
  - 背景为 Azure。
  - 网格中有 2-4 个 4-连通单色前景对象（使用不同颜色），每个对象面积为 2-5 像素。
  - 对象之间不接触，且彼此分隔。

- `Rule`：
  - 创建一个新的背景色画布。
  - 对每个对象，裁剪其 bbox 作为一个印章模板。
  - 按对象在原始网格中从左到右的顺序处理。
  - 对每个印章，将其连续盖印 N 次（N = 该对象的像素数量），从左到右排列，印章之间紧密相邻无间隔。
  - 不同对象的印章组之间间隔两列背景色。
  - 所有印章底部对齐。

- `Key insight`：对象面积同时充当两个角色——它既定义了印章的形状，也定义了重复次数；解题者需要发现这种"自引用"关系。
</new_puzzle>

<new_puzzle>
- `description`：在网格中找到与隐含的周期性图案不一致的"错误"像素，将错误像素标记为特殊颜色。

- `Input structure`：
  - 网格由一个小的 2x2 或 3x3 彩色 tile 周期性平铺而成，覆盖整个网格。
  - 平铺中有少数像素（1-5 个）被人为修改为其他颜色，破坏了周期性。
  - 修改后的颜色也是网格中已使用的颜色之一（即不能通过"网格中未使用的颜色"来识别错误）。

- `Rule`：
  - 推断出最小重复 tile 的尺寸和内容（通过多数投票：对每个 tile 位置取最常见的颜色）。
  - 找到与推断 tile 不一致的像素位置。
  - 将这些不一致的像素重着色为 Magenta（该颜色在原始输入中不存在）。
  - 保持其他所有像素不变。

- `Key insight`：错误像素无法通过颜色识别（它们使用的是合法颜色），只能通过位置在周期 tile 中的不一致来检测；推断 tile 本身就是一层非平凡的推理。
</new_puzzle>

<new_puzzle>
- `description`：将多个面板中的精灵按照其"朝向"（由精灵形状的不对称性决定）分组，每组精灵的朝向相同的排成一列输出。

- `Input structure`：
  - 背景为 Black。
  - 网格中散布着若干个相同大小（3x3 bbox）的单色精灵，每个精灵的形状在其 3x3 bbox 内是不对称的，具有明确的视觉"朝向"（如一个 L 形的开口朝上/下/左/右）。
  - 精灵使用不同的颜色。

- `Rule`：
  - 对每个精灵，确定其朝向：将精灵的归一化形状与四个旋转版本比较，朝向由其归一化后所属的旋转类别决定（上、右、下、左）。
  - 将所有同朝向的精灵分为一组。
  - 创建输出画布，每组占一列，组内精灵从上到下排列，保持原色，间隔一像素。
  - 列的顺序为：朝上、朝右、朝下、朝左（从左到右），列之间间隔两像素。
  - 如果某个朝向没有精灵，则跳过该列。

- `Key insight`：精灵的颜色和位置都是干扰项，唯一的分组键是形状的旋转朝向；解题者需要先抽象出朝向概念，再发现列排列的固定顺序。
</new_puzzle>

<new_puzzle>
- `description`：在包含"发送器"和"接收器"的网格中，每个发送器通过其颜色匹配的接收器，将自身的形状以镜像方式投影到接收器的另一侧。

- `Input structure`：
  - 背景为 Black。
  - 网格中间有一条完整的 Grey 垂直分隔线。
  - 分隔线左侧有若干 4-连通单色"发送器"对象，右侧有若干单像素"接收器"标记。
  - 每个发送器的颜色与恰好一个接收器标记的颜色匹配。

- `Rule`：
  - 对每个发送器-接收器颜色对：
    - 裁剪发送器的 bbox 形状。
    - 将形状水平镜像翻转。
    - 将翻转后的形状以接收器标记为锚点（对齐到发送器中标记对应位置），绘制在分隔线右侧。
  - 清除所有接收器标记像素。发送器和分隔线保持不变。

- `Key insight`：接收器标记既是颜色匹配键，也是空间定位锚点；发送器的形状经过镜像后"穿越"分隔线出现在右侧——颜色配对和镜像投影是两层独立的推理。
</new_puzzle>
