<new_puzzle>
- `description`：将每个彩色对象按其边界接触的网格边缘数量分类，然后用不同颜色标记每个类别：接触 0 条边的保持原色，接触 1 条边的变为 Green，接触 2 条边的变为 Yellow。

- `Input structure`：
  - 背景为 Black。
  - 网格中有若干个 4-连通单色前景对象（全部使用 Grey 颜色），形状和大小各异。
  - 部分对象的 bbox 接触网格的一条或两条边缘，部分对象完全位于网格内部（不接触任何边缘）。

- `Rule`：
  - 对每个 Grey 对象，计算其 bbox 接触的网格边缘数量（上/下/左/右，0-2 条）。
  - 接触 0 条边缘的对象保持 Grey 不变。
  - 接触恰好 1 条边缘的对象重着色为 Green。
  - 接触 2 条边缘（即位于角落区域）的对象重着色为 Yellow。
  - 背景保持不变。

- `Key insight`：所有对象初始颜色相同，无法通过颜色区分；分类标准是对象与网格边界的空间关系（接触边数），而非对象的内在属性。
</new_puzzle>

<new_puzzle>
- `description`：在包含多个颜色层的输入中，识别哪些颜色层是另一颜色层的水平平移副本，然后将所有副本合并到原始位置。

- `Input structure`：
  - 背景为 Black。
  - 网格中有 3-4 种前景颜色，每种颜色的像素构成一个形状。
  - 其中一种颜色是"原始"形状，其他 1-2 种颜色的形状是原始形状的水平平移副本（形状掩码完全相同，只是列坐标偏移了）。
  - 另外 1 种颜色的形状与原始形状无关，是干扰物。

- `Rule`：
  - 找到形状掩码在归一化后完全相同的颜色组（即互为平移副本的颜色）。
  - 将所有副本颜色的像素移动到原始颜色的列位置上（即消除水平平移），全部改为原始颜色。
  - 移除副本的原始位置像素。
  - 与原始形状无关的干扰色保持不变。

- `Key insight`：解题者需要先通过形状比较发现哪些颜色是同一形状的平移副本，再理解"合并到原始位置"的操作——颜色不是固有属性，而是平移的标记。
</new_puzzle>

<new_puzzle>
- `description`：在一个由"路径色"像素构成的迷宫中，将每个死胡同末端标记为 Red，将路径分叉点标记为 Blue，其余路径保持不变。

- `Input structure`：
  - 背景为 Black。
  - 网格中由 Grey 像素构成一个一像素宽的正交路径网络（迷宫），路径像素之间 4-连通。
  - 路径上有死胡同（只有一个 4-邻居为路径的像素）和分叉点（有三个或四个 4-邻居为路径的像素）。

- `Rule`：
  - 对每个 Grey 路径像素，计算其 4-邻居中属于路径的像素数量。
  - 数量为 1（死胡同末端）：重着色为 Red。
  - 数量为 3 或 4（分叉点）：重着色为 Blue。
  - 数量为 2（普通通道）：保持 Grey。
  - 背景保持不变。

- `Key insight`：重着色标准完全由局部 4-邻居连通度决定；虽然规则本身简单，但解题者需要从视觉模式中归纳出"邻居计数"这个非显然的分类标准。
</new_puzzle>

<new_puzzle>
- `description`：将输入中的前景像素按颜色分组，每组像素的凸包矩形互相交叉，输出中仅保留交叉区域内的像素，其余像素清除。

- `Input structure`：
  - 背景为 Black。
  - 网格中散布着两种颜色的前景像素（如 Red 和 Blue），每种颜色有多个散点或小对象。
  - 两种颜色的 bbox 存在重叠区域。

- `Rule`：
  - 计算 Red 像素集合的 bbox 和 Blue 像素集合的 bbox。
  - 计算两个 bbox 的交集矩形区域。
  - 在输出中，仅保留位于交集区域内的前景像素（无论颜色），清除交集区域外的所有前景像素为背景色。
  - 背景保持不变。

- `Key insight`：两种颜色的 bbox 交集定义了一个"共存区域"；只有该区域内的像素被保留——颜色本身不决定去留，空间关系才是关键。
</new_puzzle>

<new_puzzle>
- `description`：在由标记像素定义的行和列的交叉点处，绘制由行标记颜色和列标记颜色混合决定的十字图案。

- `Input structure`：
  - 背景为 Black。
  - 网格最上行（第 0 行）有若干彩色标记像素（如 Red、Blue、Green），标记了特定列。
  - 网格最左列（第 0 列）有若干彩色标记像素（如 Yellow、Orange、Maroon），标记了特定行。
  - 左上角像素 (0,0) 为背景色。

- `Rule`：
  - 对每个（行标记、列标记）配对，确定交叉点坐标。
  - 在每个交叉点处绘制一个 3x3 的十字图案（中心 + 上下左右各一像素）。
  - 十字的水平臂（左右像素）使用行标记的颜色。
  - 十字的垂直臂（上下像素）使用列标记的颜色。
  - 十字中心使用行标记颜色。
  - 保持边缘标记像素不变。

- `Key insight`：行和列标记各自贡献十字的不同部分颜色；解题者需要同时理解坐标交叉机制和颜色分配规则。
</new_puzzle>
