- `description`：将每个前景对象的像素按照其在对象内的局部坐标，映射到一个全局颜色查找表中获取新颜色，从而重绘整个对象。

- `Input structure`：
  - 背景为 Black。
  - 网格左上角有一个小的 NxN 彩色方阵作为颜色查找表，每个单元格为不同颜色（使用 Red、Blue、Green、Yellow、Grey 等）。
  - 网格其他区域散布着若干个大小恰好为 NxN 的 4-连通单色矩形前景对象，每个对象使用同一种 Grey 颜色。

- `Rule`：
  - 对每个 Grey 矩形对象，将其 NxN 内的每个像素按局部坐标 (r,c) 查找颜色表中 (r,c) 位置的颜色。
  - 用查找到的颜色替换该像素的 Grey 色。
  - 保留颜色查找表本身不变。

- `Key insight`：Grey 对象看似相同，但它们的重着色结果由位置无关的全局查找表决定；查找表的空间结构映射到每个对象的内部坐标，这是一种自掩码（self-mask）机制的变体。

<new_puzzle>
- `description`：根据每个封闭区域的开口方向，将该区域内部的散布标记像素沿开口方向"倾倒"出去，在区域外部排成一列。

- `Input structure`：
  - 背景为 Azure。
  - 网格中有若干个由 Maroon 像素构成的 U 形或 C 形半封闭容器（一像素厚边框，三面封闭、一面开口）。
  - 每个容器内部散布着若干个不同颜色的单像素标记（如 Red、Green、Yellow）。

- `Rule`：
  - 对每个容器，确定其开口方向（上、下、左、右）。
  - 将容器内部的所有标记像素从开口处"倾倒"出去：沿开口方向逐个排列在容器外部的第一列/行背景像素上。
  - 标记的排列顺序为：距离开口最近的标记排在最外面（即先倒出），距离最远的排在最里面（最后倒出）。
  - 清除容器内部的标记像素为背景色。容器本体保持不变。

- `Key insight`：开口方向决定倾倒方向，标记像素到开口的距离决定排列顺序；容器的形状本身提供了全部的空间指令。
</new_puzzle>

<new_puzzle>
- `description`：检测每个前景对象的对称类型（水平对称、垂直对称、旋转对称或无对称），按对称类型将对象移动到网格的指定区域。

- `Input structure`：
  - 背景为 Black。
  - 网格被 Grey 色的十字线（一条完整水平线和一条完整垂直线）分为四个象限。
  - 网格中散布着若干个多色 4-连通前景对象，每个对象的形状属于以下四种对称类型之一：仅水平反射对称、仅垂直反射对称、180 度旋转对称（但非反射对称）、无对称性。

- `Rule`：
  - 水平反射对称的对象移动到左上象限。
  - 垂直反射对称的对象移动到右上象限。
  - 180 度旋转对称的对象移动到左下象限。
  - 无对称性的对象移动到右下象限。
  - 在目标象限中，对象保持原色和形状，紧贴象限角落放置。多个同类对象按原始行优先顺序依次排列，间隔一像素。
  - 清除原始位置的对象。保持十字分隔线不变。

- `Key insight`：对称类型是分类标签而非变换操作；十字线不是对称轴，而是输出区域的分隔符；解题者需要对每个对象独立分析对称性。
</new_puzzle>

<new_puzzle>
- `description`：在一组形状相似的对象中，找出与"模板"对象形状完全匹配的那些，并将它们连接到模板对象上。

- `Input structure`：
  - 背景为 Black。
  - 网格中有一个用 Red 颜色绘制的"模板"对象（一个小型 4-连通形状，3-5 像素），位于网格中央。
  - 网格中散布若干个相同大小的 4-连通对象，部分对象的归一化形状（允许旋转和翻转）与模板匹配，部分不匹配。匹配对象使用 Blue 颜色，不匹配对象使用 Green 颜色。

- `Rule`：
  - 保留 Red 模板对象和所有 Blue 对象不变。
  - 将所有 Green 对象擦除为背景色。
  - 对每个 Blue 对象，从该对象到 Red 模板之间画一条 Yellow 的直线连接（水平或垂直，取较短路径），连接两者最近的边界像素。

- `Key insight`：颜色已经编码了匹配结果（Blue = 匹配，Green = 不匹配），但解题者仍需归纳出这一编码规则并发现连接线的绘制逻辑。
</new_puzzle>

<new_puzzle>
- `description`：将网格中每个连通区域的边界像素保留，内部像素替换为该区域所包含的孔洞数量对应的颜色。

- `Input structure`：
  - 背景为 Black。
  - 网格中有若干个 4-连通单色前景对象，每个对象为不同颜色且形状各异。
  - 部分对象内部包含背景色孔洞（4-连通的被完全包围的背景区域），孔洞数量从 0 到 3 不等。
  - 网格边缘有一个简单的颜色图例：四个纵向排列的色块，从上到下分别代表孔洞数量 0、1、2、3 对应的填充颜色。

- `Rule`：
  - 对每个前景对象，保留其边界像素（至少有一个 4-邻居为背景或其他颜色的像素）的原色不变。
  - 计算该对象内部的 4-连通背景孔洞数量 H。
  - 从图例中查找 H 对应的颜色，将该对象所有非边界像素（内部像素）替换为该颜色。
  - 孔洞本身保持为背景色。

- `Key insight`：拓扑特征（孔洞数量）作为查找键索引颜色图例，这需要解题者同时理解"孔洞计数"和"图例映射"两层逻辑。
</new_puzzle>
