- `Input structure`：
  - 背景为黑色（black）。
  - 网格中有若干由单一颜色（如 blue、red、green 等）绘制的一像素宽封闭矩形框，每个框内部为黑色背景，并包含恰好一个不同颜色的标记像素（marker）。
  - 网格的一侧（例如底部）有一排色彩图例区域：每个图例由一个两像素宽的竖条组成，左列为纯色（与某个标记像素颜色相同），右列为一个 2×2 或 3×3 的小型二色填充图案（pattern），图案使用该图例所属矩形框的边框颜色和黑色交替绘制。

- `Rule`：
  - 对每个封闭矩形框，找到框内标记像素的颜色。
  - 在图例区中查找左列颜色与该标记像素颜色匹配的图例条目，获取其右列的填充图案。
  - 将该填充图案以平铺（tile）方式重复填满矩形框的整个内部区域（覆盖原标记像素），图案中的非黑色像素使用矩形框的边框颜色绘制。

- `Key insight`：标记像素的颜色不是填充色，而是图例的索引键；真正的填充图案来自图例的右列，且图案的颜色要替换为该矩形框自身的边框颜色，形成"查表→取图案→变色平铺"的三层推理链。

- `description`：将散落的彩色碎片滑入模板形状中对应的凹槽，凹槽的匹配依据不是尺寸而是碎片轮廓与凹槽轮廓的互补拼合。

- `Input structure`：
  - 背景为黑色（black）。
  - 网格中央有一个由 grey 像素构成的大型不规则形状（模板），模板边缘有若干凹陷的缺口（凹槽），每个凹槽的边缘用一种独特的颜色（如 red、blue、green 等）标记一个单像素的"锚点"。
  - 模板外部散落着若干小型彩色碎片（connected component），每个碎片由某种非黑非灰颜色构成，碎片的某一侧边缘也有一个与某凹槽锚点颜色相同的单像素标记。

- `Rule`：
  - 将每个碎片与具有相同锚点颜色的凹槽配对。
  - 将碎片平移，使碎片上的锚点像素与凹槽的锚点像素重合。
  - 碎片填入凹槽后，碎片像素覆盖凹槽中的黑色区域，与模板的 grey 像素无缝拼合，形成完整的外轮廓。
  - 碎片原始位置清除为黑色背景；锚点像素在输出中保留其颜色。

- `Key insight`：颜色锚点同时承担两个角色——既是碎片与凹槽的配对键，又是精确对齐的定位锚；解题者需先通过颜色匹配建立配对关系，再通过锚点重合确定平移向量，最后验证碎片轮廓确实与凹槽互补。
</new_puzzle>

- `description`：每个彩色精灵（sprite）沿其内部箭头指示的方向移动，移动距离等于该精灵所在封闭围栏内同色小圆点的数量。

- `Input structure`：
  - 背景为黑色（black）。
  - 网格中有若干由 grey 像素围成的矩形围栏（一像素宽的灰色边框），每个围栏内部为黑色背景。
  - 每个围栏内部包含：(1) 恰好一个由某颜色（如 red、blue、green、orange 等）绘制的 3×3 精灵，精灵内部有一个由同色像素组成的"箭头"图案——箭头由中心像素加上一个方向的相邻像素构成（如中心 + 上方像素 = 向上箭头，中心 + 右方像素 = 向右箭头，共四个基本方向）；(2) 若干个与精灵同色的孤立单像素圆点散布在围栏内的黑色区域中。

- `Rule`：
  - 对每个围栏，识别其中精灵的箭头方向（中心像素指向哪个相邻像素即为方向）。
  - 数出围栏内与精灵同色的孤立单像素圆点的个数 N（不包含精灵自身的像素）。
  - 将精灵沿箭头方向平移 N 个像素。
  - 圆点在输出中被清除为黑色；围栏边框保持不变；精灵以新位置绘制，原位置清除为黑色。
  - 精灵不会移出围栏边界（题目保证 N 值不会导致越界）。

- `Key insight`：精灵自身的形状编码了运动方向，而围栏内的同色散点编码了运动距离——解题者需要分别解读"方向信号"和"距离信号"这两个独立的编码层，然后组合执行移动。
</new_puzzle>

- `description`：根据每行彩色像素的堆叠顺序确定遮挡关系，然后在输出中按该遮挡优先级将重叠区域分配给优先级更高的颜色。

- `Input structure`：
  - 背景为黑色（black）。
  - 网格左侧有一个"优先级塔"：一列纵向排列的单色像素，从上到下每个像素颜色不同（如从上到下依次为 red、blue、green、yellow），上方颜色优先级高于下方。
  - 网格右侧的主区域中有若干单色矩形，它们可能相互重叠。每个矩形的颜色对应优先级塔中的某一种颜色。在输入中，所有矩形都完整绘制（后绘制的矩形覆盖了先绘制的，导致部分矩形被遮挡）。

- `Rule`：
  - 从优先级塔中读取颜色的优先级顺序（最上方 = 最高优先级）。
  - 在输出中，重新绘制所有矩形，但重叠区域的像素颜色由优先级最高的矩形决定，而非由输入中的绘制顺序决定。
  - 每个矩形的完整尺寸和位置需要从输入中推断：被遮挡矩形的可见部分暗示了其完整的矩形范围（因为所有形状都是轴对齐的矩形）。
  - 优先级塔本身在输出中保持不变。

- `Key insight`：输入中的遮挡关系（绘制顺序）与优先级塔指定的优先级可能矛盾——解题者必须先从优先级塔读取正确的层序，再推断被遮挡矩形的完整范围，最后按新的优先级重新合成画面。这是"读取规则→推断隐藏信息→重新渲染"的三层推理。

<new_puzzle>
- `description`：识别每个房间中镜子的朝向，将光源发出的射线沿镜面反射，射线最终击中的墙壁像素被染成光源的颜色。

- `Input structure`：
  - 背景为黑色（black）。
  - 网格中有若干由 grey 像素围成的矩形"房间"（一像素宽灰色墙壁，内部为黑色）。
  - 每个房间的某一面墙壁上恰好有一个彩色像素（如 red、blue、green 等），该像素即为"光源"，它替换了墙壁上该位置的灰色像素。光源所在的墙壁边决定了光线的初始方向：上墙壁 → 光线向下，下墙壁 → 光线向上，左墙壁 → 光线向右，右墙壁 → 光线向左。
  - 每个房间内部恰好有一个由两个 yellow 像素组成的"镜子"：两个 yellow 像素对角相邻（即组成一个 45° 的对角线段）。镜子有两种朝向：左上-右下对角线（`\` 形）或左下-右上对角线（`/` 形）。

- `Rule`：
  - 从光源像素出发，沿初始方向发射一条射线（逐像素延伸）。
  - 射线在房间内部的黑色区域中直线传播，沿路将经过的黑色像素染成光源颜色。
  - 当射线到达镜子（yellow 像素）时发生 90° 反射：`\` 形镜子将水平运动变为同向垂直运动（右→下，左→上）、将垂直运动变为同向水平运动（下→右，上→左）；`/` 形镜子将水平运动变为反向垂直运动（右→上，左→下）、将垂直运动变为反向水平运动（下→左，上→右）。镜子像素本身保持 yellow 不变。
  - 射线反射后继续传播直到碰到灰色墙壁，将击中的那个墙壁像素也染成光源颜色，然后射线停止。
  - 其他未被射线经过的像素保持不变。

- `Key insight`：解题者需要完成三步非平凡推理：(1) 从光源在墙壁上的位置推断光线初始方向；(2) 从两个 yellow 像素的相对位置识别镜子朝向（`\` 或 `/`）；(3) 根据镜子朝向正确执行反射规则，确定射线的最终路径和终点。每一步都需要空间推理而非简单的模式匹配。
</new_puzzle>

- `description`：将网格中每个彩色环形图案按其缺口方向"展开"成一条直线段，线段的长度等于环的周长像素数。

- `Input structure`：
  - 背景为黑色（black）。
  - 网格中散布着若干由不同颜色绘制的环形图案。每个环是一个正方形框（3×3、4×4 或 5×5 的一像素宽边框），且恰好有一个缺口——即边框上恰好缺少一个像素的位置，该位置为黑色背景。
  - 每个环的颜色各不相同（如 red、blue、green、orange 等）。

- `Rule`：
  - 对每个环，确定缺口的位置及其所在边（上、下、左、右）。
  - 缺口所在边决定展开方向：上边缺口 → 向上展开，下边缺口 → 向下展开，左边缺口 → 向左展开，右边缺口 → 向右展开。
  - 从缺口位置出发，沿展开方向绘制一条直线段，线段长度等于该环上实际存在的有色像素总数（即环的周长减去缺口的 1 个像素）。
  - 原来的环形图案在输出中被清除为黑色，仅保留展开后的直线段。
  - 线段使用该环原来的颜色绘制。

- `Key insight`：缺口同时编码了两个信息——展开的起点位置和展开方向；而环的尺寸（从而周长像素数）决定了线段的长度。解题者需要将"形状特征"（缺口方向）和"数量特征"（周长）分别解读并组合应用。
</new_puzzle>

- `description`：在分隔线两侧的对应行中找出不匹配的像素对，用不匹配像素的颜色在中间指示区绘制标记。

- `Input structure`：
  - 背景为黑色（black）。
  - 网格由三个纵向区域组成，由两条一像素宽的 grey 竖线分隔：左区、中间指示区、右区。
  - 左区和右区宽度相同，各包含若干行彩色像素图案（每行独立，可能使用 red、blue、green、yellow、orange 等颜色）。
  - 中间指示区初始全部为黑色背景。
  - 左区和右区的每一行几乎相同，但每行恰好有一个像素位置的颜色不同（即左区该位置为颜色 A，右区对应位置为颜色 B，A ≠ B）。

- `Rule`：
  - 逐行比较左区和右区的对应像素。
  - 找到每行中唯一不匹配的像素位置。
  - 在中间指示区的对应行中，绘制两个像素：左侧像素使用左区中不匹配位置的颜色，右侧像素使用右区中不匹配位置的颜色。
  - 如果中间指示区宽度大于 2，则这两个像素居中放置，其余位置保持黑色。
  - 左区、右区和灰色分隔线保持不变。

- `Key insight`：解题者需要在视觉上逐行"找不同"，然后理解中间区域的编码方式——它不是简单地标记差异位置，而是提取差异双方的颜色信息并并排展示，形成一个差异摘要。这需要先完成视觉比对，再理解输出的编码格式。
</new_puzzle>
