<new_puzzle>
- `description`：根据每个封闭区域内标记像素的颜色，从对应颜色的边缘模板中提取形状，将模板旋转至标记所在的象限方向后印入该区域。

- `Input structure`：
  - 背景为黑色（Black），占据网格大部分面积。
  - 灰色（Grey）像素构成若干条直线段，将网格划分为多个封闭的矩形区域。
  - 在网格的边缘（紧贴网格最外圈），有若干个由不同颜色绘制的小型 3x3 形状（如 L 形、T 形等），每种颜色恰好出现一个这样的边缘形状，称为"模板"。
  - 每个被灰色线段封闭的矩形区域内部恰好有一个单像素标记，标记的颜色与某个边缘模板的颜色相同。
  - 标记像素位于其所在区域的四个象限之一（左上、右上、左下、右下），可通过标记相对于区域中心的位置判断。

- `Rule`：
  - 保留灰色分隔线不变。
  - 对每个封闭矩形区域：
    1. 读取区域内标记像素的颜色，找到边缘处同色的 3x3 模板。
    2. 判断标记像素位于区域的哪个象限（左上、右上、左下、右下）。
    3. 将模板旋转到对应象限的朝向：左上为原始方向（0度），右上顺时针旋转90度，右下旋转180度，左下旋转270度。
    4. 将旋转后的模板以标记像素为锚点（模板的角落像素对齐标记位置）绘入区域，覆盖背景像素。
  - 绘制完毕后擦除标记像素（恢复为背景色）。

- `Key insight`：解题需要两层独立归纳——第一层是发现标记颜色与边缘模板的对应关系（颜色匹配），第二层是发现标记在区域内的象限位置决定了模板的旋转角度。两层规则都无法仅靠单个样例推断。
</new_puzzle>

<new_puzzle>
- `description`：将网格中散落的彩色碎片按颜色分组，每组碎片沿其"领航碎片"的凹陷缺口方向平移合并为一个完整对象。

- `Input structure`：
  - 背景为黑色（Black）。
  - 网格中有若干彩色像素团，每种非背景颜色恰好出现两到三个互不相连的 4-连通碎片。
  - 同色碎片若拼合在一起，恰好组成一个紧凑的矩形或 L 形等简单形状（无孔洞）。
  - 每种颜色的碎片中，恰好有一个碎片在其外轮廓的某个方向上存在单像素凹陷缺口（即该碎片的边界有一个像素向内凹入一格），该碎片称为"领航碎片"，缺口所在方向即为平移方向。

- `Rule`：
  - 对每种颜色：
    1. 找到该颜色的领航碎片（拥有单像素凹陷缺口的碎片）。
    2. 确定缺口朝向（上、下、左、右），该方向即为其他同色碎片的平移方向。
    3. 将该颜色的所有非领航碎片沿缺口朝向平移，直到它们与领航碎片（或已合并的同色碎片）4-连通相邻为止。
    4. 合并后填补缺口：领航碎片的凹陷像素也被填充为该颜色。
  - 不同颜色的碎片独立处理，合并后的对象不会重叠。

- `Key insight`：核心推理分两层：首先需要识别出哪个碎片是"领航碎片"（通过其独特的凹陷缺口），然后需要发现缺口方向编码了其余碎片的移动方向。仅观察最终合并结果无法区分这两步——必须比较输入中碎片的形态差异才能归纳出规则。
</new_puzzle>

<new_puzzle>
- `description`：网格中的灰色折线路径穿过散布的彩色"染色门"，路径各段根据穿越门的先后顺序被重新着色为对应门的颜色。

- `Input structure`：
  - 背景为黑色（Black）。
  - 网格中有若干条由灰色（Grey）像素绘制的折线路径，每条路径从网格的某个边缘像素出发，由一系列水平或垂直的直线段通过直角转弯连接而成，路径不分叉、不交叉、不闭合。
  - 在网格中散布着若干"染色门"：每个染色门是一个由两个同色非灰色像素组成的竖直或水平对，间距恰好为 2（中间空一格），门的两个像素分布在路径经过的像素的两侧（路径从门中间穿过）。
  - 每条路径可能穿过零个或多个染色门。

- `Rule`：
  - 对每条灰色折线路径：
    1. 从路径的边缘起点出发，沿路径方向依次记录路径穿过的每个染色门的颜色，得到颜色序列 [C1, C2, ...]。
    2. 路径起点到第一个门之间的段保持灰色不变。
    3. 穿过第 k 个门之后、到第 k+1 个门之前的路径段（或到路径终点），重新着色为第 k 个门的颜色 Ck。
  - 染色门本身保持不变。
  - 未被任何路径穿过的门也保持不变。

- `Key insight`：解题者需要先识别出路径与染色门两类结构（它们由颜色和形态区分），再发现"门对路径的染色效果"是按穿越顺序逐段生效的——每段的颜色不取决于该段自身的属性，而取决于路径在此之前穿过的最后一扇门的颜色。这种"经过即改变后续状态"的序列机制需要从多个样例中对比归纳。
</new_puzzle>

- `description`：网格被灰色竖线分为左右两半；左侧包含有缺口的彩色框架和内部角标，右侧包含同色小形状；将右侧形状按角标颜色指定的角度旋转后嵌入左侧框架的缺口处。

- `Input structure`：
  - 背景为黑色（Black）。
  - 网格正中央有一条竖直的灰色（Grey）分隔线，将网格分为左右两半。
  - 左半部分包含若干个由单一颜色绘制的矩形框架（中空的矩形边框，边框宽度为一像素），每个框架的边缘有一处连续缺口（缺失若干像素）。每个框架的内部（中空区域的某个角落）有一个单像素角标，角标颜色为 Red、Green、Blue 或 Yellow 之一。
  - 右半部分包含若干个小型实心形状，每个形状的颜色与左侧某个框架的颜色相同。每个小形状的像素数恰好等于其对应框架缺口处缺失的像素数。

- `Rule`：
  - 对每个左侧框架：
    1. 通过颜色匹配找到右侧对应的小形状。
    2. 读取框架内部角标的颜色，确定旋转角度：Red = 0度，Green = 90度顺时针，Blue = 180度，Yellow = 270度顺时针。
    3. 将右侧小形状按该角度旋转。
    4. 将旋转后的形状填入框架缺口处，使框架恢复完整的矩形边框。
  - 擦除右侧所有小形状（恢复为背景色）。
  - 擦除框架内部的角标像素（恢复为背景色）。
  - 灰色分隔线保持不变。

- `Key insight`：解题包含三层推理：第一层是通过颜色匹配建立左右对应关系；第二层是发现框架内角标颜色编码了旋转角度（而非装饰）；第三层是验证旋转后的形状恰好与缺口互补。三层规则需要同时成立才能解释所有样例，仅发现其中一两层不足以得出完整规则。
</new_puzzle>

- `description`：网格中有彩色单像素"信号塔"和灰色空心方框"接收器"；信号塔向四方发射同色射线，射线遇障碍物停止；接收器根据被触碰的射线数量决定中心像素的填充颜色。

- `Input structure`：
  - 背景为黑色（Black）。
  - 网格中散布着两类对象：
    - "信号塔"：每个信号塔是一个 1x1 的单像素，颜色各异（可出现多个不同颜色的信号塔）。
    - "接收器"：每个接收器是一个由灰色（Grey）像素绘制的 3x3 空心方框（即 3x3 正方形边框，边框一像素宽，中心像素为背景色黑色）。
  - 信号塔和接收器不重叠，且分布在网格的不同位置。

- `Rule`：
  - 对每个信号塔：
    1. 从信号塔位置向上、下、左、右四个方向发射射线。
    2. 射线沿途将背景像素染为信号塔的颜色。
    3. 射线在碰到任何非背景像素（包括接收器的灰色边框、其他信号塔、或另一条射线已染色的像素）时停止，不覆盖该像素。
  - 对每个接收器：
    1. 统计有多少条不同的射线触碰到了该接收器的灰色边框（即射线终点像素与边框像素在四方向上相邻）。
    2. 若恰好有 1 条射线触碰，将接收器中心像素填充为该射线的颜色。
    3. 若有 2 条或更多射线触碰，将接收器中心像素填充为 Maroon。
    4. 若没有射线触碰，接收器中心保持背景色不变。
  - 信号塔像素本身保持不变。

- `Key insight`：解题需要两层推理：第一层是发现信号塔向四方广播射线的传播机制（包括射线被阻挡的规则）；第二层是发现接收器的中心填充颜色取决于触碰射线的数量——单条射线传递颜色，多条射线则触发特殊颜色标记。射线的相互阻挡使得传播结果非平凡，必须通过多个样例才能确认阻挡优先级和计数规则。
</new_puzzle>

<new_puzzle>
- `description`：网格中有若干对"种子"和"土壤区域"；种子的形状决定生长图案的类型，土壤区域在生长方向上的边长决定生长的延伸长度，生长方向由种子相对于土壤的位置决定。

- `Input structure`：
  - 背景为黑色（Black）。
  - 网格中有若干个矩形的"土壤区域"，每个土壤区域由同一种颜色的实心矩形表示（如 Green、Blue 等），不同土壤区域颜色可以不同。
  - 每个土壤区域的某一条边的外侧紧邻一个小型的"种子"对象（2-4 个像素组成的小形状），种子颜色与其相邻土壤区域颜色相同。
  - 种子的形状为以下三种之一：水平两像素横条、竖直两像素竖条、2x2 正方形。

- `Rule`：
  - 对每对种子和土壤区域：
    1. 确定种子位于土壤的哪一侧（上、下、左、右），该方向即为生长方向（从种子向远离土壤的方向延伸）。
    2. 根据种子形状确定生长图案：
       - 水平横条种子：生长图案为单像素宽的直线，沿生长方向延伸。
       - 竖直竖条种子：生长图案为每前进一行（或列）交替偏移一格的锯齿线，沿生长方向延伸。
       - 2x2 正方形种子：生长图案为逐步扩展的三角形（每前进一行/列宽度增加一个像素），沿生长方向延伸。
    3. 生长的延伸长度（像素行/列数）等于土壤区域在生长方向上的边长。
    4. 以种子颜色绘制生长图案，从种子位置开始沿生长方向向外绘制，覆盖背景像素。
  - 种子和土壤区域本身保持不变。

- `Key insight`：解题者需要同时归纳三条独立规则：种子位置编码方向、种子形状编码图案类型、土壤尺寸编码延伸长度。这三条规则在每个样例中同时生效，解题者必须控制变量——对比相同形状但不同位置的种子来分离方向规则，对比相同位置但不同形状的种子来分离图案规则，对比相同形状和位置但不同土壤大小的案例来分离长度规则。
</new_puzzle>

<new_puzzle>
- `description`：网格中有彩色墙壁围成的房间，每个房间墙壁上有一扇门（单像素缺口）；从门向外射线扫描找到钥匙像素，只有颜色与墙壁匹配的钥匙才能"打开"房间，将房间内部填充为该颜色。

- `Input structure`：
  - 背景为黑色（Black）。
  - 网格中有若干个由彩色像素围成的封闭矩形"房间"，每个房间的墙壁由同一种颜色绘制（一像素宽的矩形边框），不同房间可以不同颜色。
  - 每个房间的墙壁上恰好有一处单像素宽的缺口，称为"门"。门的缺口位于墙壁的某条边上（上边、下边、左边或右边）。
  - 在所有房间的外部（背景区域），散布着若干个单像素的"钥匙"，每个钥匙有自己的颜色。
  - 钥匙的数量多于房间数量（存在干扰项钥匙）。

- `Rule`：
  - 对每个房间：
    1. 找到该房间墙壁上的门（缺口位置）。
    2. 从门的位置沿门朝外的方向（垂直于该段墙壁、指向房间外部）做射线扫描，找到射线上遇到的第一个钥匙像素。
    3. 检查该钥匙的颜色是否与房间墙壁颜色相同：
       - 若相同（"钥匙匹配"）：将房间内部所有背景像素填充为该钥匙颜色，并擦除该钥匙（恢复为背景色）。
       - 若不同（"钥匙不匹配"）：房间保持不变，钥匙也保持不变。
  - 所有未被使用的钥匙保持原位不变。
  - 墙壁像素保持不变，门的缺口也保持为背景色。

- `Key insight`：解题分两层：第一层是发现门的朝向决定了射线扫描方向，从而在空间上将特定钥匙与特定房间关联起来；第二层是发现颜色匹配条件——不是所有被射线扫到的钥匙都会生效，只有颜色与墙壁相同的钥匙才能"打开"房间。干扰项钥匙的存在使得解题者必须同时发现空间关联和颜色匹配两条规则。
</new_puzzle>
