<new_puzzle>
根据框架内部的色带方向，将框架外的散落色块旋转后嵌入对应框架中。

Input structure
- 背景为主色调（如 black）。
- 网格中有若干个由同一颜色绘制的矩形框架（空心矩形，边宽1像素），每个框架的内部底边或侧边上附有一条短色带（2-3像素长，颜色与框架不同）。
- 框架外散落着若干个小型多色图案块（每个图案块由2-3种颜色组成，尺寸恰好能放入框架内部）。
- 每个图案块恰好有一条边上带有一条与某个框架内色带颜色相同的短色带。

Rule
- 第一步（配对）：将每个散落图案块与框架配对——图案块边缘色带的颜色必须与框架内部色带的颜色一致。
- 第二步（旋转与嵌入）：将图案块旋转（0°、90°、180°或270°），使得图案块上的色带与框架内部的色带在空间位置上对齐（即色带朝向相同的边、且列或行位置重合），然后将图案块放入框架内部，色带像素重叠。
- 框架和背景保持不变；原来图案块的位置清除为背景色。

Key insight
- 颜色匹配决定哪个图案属于哪个框架，但色带的方位（在框架的哪条边上）还决定了图案块必须旋转到什么角度才能正确嵌入，需要两步独立推理。
</new_puzzle>

将网格中每个封闭区域按其包含的标记像素数量排序，然后用排序后的名次对应的调色板颜色重新填充区域。

Input structure
- 背景为 black。
- 网格中有一组由 grey 线条绘制的封闭区域（类似于不规则地图分区），每个区域内部填充背景色。
- 每个封闭区域内散布着若干个 red 标记像素（数量从1到多个不等，每个区域内的数量互不相同）。
- 网格底部有一行调色板色条：从左到右依次排列若干种不同颜色的单像素，数量与封闭区域数量相同。

Rule
- 统计每个封闭区域内 red 标记像素的数量。
- 将所有区域按标记数量从少到多排序，得到排名 1、2、3……
- 调色板色条从左到右对应排名 1、2、3……
- 将每个区域内的所有 red 标记像素替换为该区域对应排名的调色板颜色，同时用同一颜色填充该区域的全部内部背景像素。
- grey 边界线和调色板色条保持不变。

Key insight
- 解题者需要先发现区域内标记数量决定排序，再发现底部色条是按排名索引的调色板——两步归纳缺一不可，仅观察颜色变化无法直接猜出规则。
</new_puzzle>

<new_puzzle>
识别网格中的"印章"与"画布"，将印章图案按画布边框上缺口的位置和数量进行重复印刷。

Input structure
- 背景为 black。
- 网格中有一个较大的矩形"画布"：由某种颜色（如 blue）绘制的单像素宽空心矩形框，内部全为背景色。画布边框上有若干个缺口（即边框上有几个像素被替换为背景色）。
- 网格中另有一个较小的多色图案块，称为"印章"，其外接矩形完全在画布外部。印章是一个紧凑的多色像素组合。
- 画布的每条边上的缺口数量可以是0或正整数，且每个缺口恰好1像素宽。

Rule
- 第一步（确定印刷轴）：仅在有缺口的边上进行印刷。对画布的上、下、左、右四条边分别检查缺口。
- 第二步（印刷位置）：对于每条有缺口的边，将印章图案沿该边的法线方向放入画布内部，印章的中心列（若缺口在上/下边）或中心行（若缺口在左/右边）对齐到缺口所在的列或行。印章紧贴该边内侧放置。
- 若同一条边有多个缺口，则印章在每个缺口位置各印刷一次。
- 多次印刷可能重叠，后印覆盖先印（按从左到右、从上到下的缺口顺序）。
- 印章原始位置保留不变，画布边框（含缺口）保持不变。

Key insight
- 缺口既编码了印刷的方向（哪条边），又编码了印刷的精确位置（哪一列/行），解题者必须同时发现这两层信息才能重建输出。边框上没有缺口的边不产生任何印刷，这是区分干扰的关键。
</new_puzzle>

<new_puzzle>
根据每个对象内部孔洞的形状，在网格边缘的"形状图例"中查找匹配项，然后用图例旁标注的颜色重绘该对象的外壳。

Input structure
- 背景为 black。
- 网格中央散布着若干个单色填充的较大对象（每个对象由同一种颜色填充，形状不规则但4-连通），每个对象内部恰好有一个由背景色构成的孔洞（孔洞形状各异，如L形、T形、十字形等，孔洞像素数不超过6）。
- 网格的最左列或最右列紧贴边缘处排列着若干个"形状图例"条目。每个条目由两部分组成：一个用 grey 像素绘制的小形状（与某个孔洞形状完全相同），以及紧邻该形状右侧（或下方）的一个单像素颜色标记。
- 图例条目之间用至少2行背景色间隔。

Rule
- 对每个中央对象，提取其内部孔洞的形状（相对坐标的像素集合）。
- 在边缘图例中找到与该孔洞形状全等的条目（允许平移对齐，不旋转不翻转）。
- 读取该图例条目旁的颜色标记。
- 将该对象的所有填充像素（不包括孔洞）重新着色为图例标记的颜色。
- 图例本身、孔洞和背景保持不变。

Key insight
- 对象的外部形状是干扰项——真正决定输出颜色的是隐藏在对象内部的孔洞形状。解题者必须先发现孔洞的存在，再发现孔洞与边缘图例的形状匹配关系，最后才能确定重绘颜色。这构成三层递进推理：发现孔洞→匹配图例→应用颜色。
</new_puzzle>

<new_puzzle>
将散落的拼图碎片按边缘齿形互锁关系拼入中央框架的空槽中。

Input structure
- 背景为 black。
- 网格中央有一个由 grey 像素构成的大型矩形区域，其中挖出了若干个不规则形状的空槽（空槽为背景色）。每个空槽的边缘呈锯齿形（凹凸交替的齿形轮廓）。
- 网格四周散落着若干个彩色碎片（每个碎片为单一非 grey、非背景的颜色），每个碎片的形状恰好能填入某一个空槽。碎片的边缘轮廓与对应空槽的轮廓互补（凸对凹、凹对凸），形成齿形互锁。
- 每个碎片可能需要旋转90°的整数倍才能与空槽匹配。碎片数量与空槽数量相同。

Rule
- 对每个空槽，在散落碎片中找到形状完全互补的那一个（碎片的像素集合经过适当旋转后与空槽的像素集合全等）。
- 将匹配的碎片旋转到正确角度后，平移放入空槽中，碎片颜色填充空槽位置。
- 碎片原始位置清除为背景色。
- grey 框架保持不变。

Key insight
- 碎片与空槽的匹配不能仅靠面积（多个碎片可能面积相同），必须通过边缘齿形轮廓的互补性来判断唯一配对。旋转增加了匹配的搜索空间，但齿形的不对称性保证了每个碎片只有唯一正确的旋转角度和唯一对应的空槽。
</new_puzzle>

<new_puzzle>
根据种子像素的颜色在对应的"生长模板"中查找生长图案，然后以种子为中心将模板图案生长出来，生长层数由种子周围相邻标记像素的数量决定。

Input structure
- 背景为 black。
- 网格顶部有若干个"生长模板"：每个模板是一个小的方形图案（3x3或5x5），中心像素为某种颜色 C，周围像素描述了颜色 C 的一层生长形状（哪些相邻位置会被填充，以及填充的颜色）。模板之间用至少2列背景色分隔。
- 网格下半部分散布着若干个"种子像素"（单个彩色像素），每个种子的颜色与某个模板的中心颜色一致。
- 每个种子像素的4-邻域中有若干个 maroon 标记像素（0到3个），标记像素仅用于计数，不参与生长。

Rule
- 对每个种子像素，根据其颜色找到对应的生长模板。
- 统计该种子4-邻域中 maroon 标记像素的数量 N。
- 以种子为中心，将模板的生长图案重复施加 N 层：第1层将模板中非背景像素的相对位置围绕种子绘制一次；第2层在第1层基础上，对第1层新增的每个像素再以同样的模板相对位置扩展一层，依此类推。
- 生长过程中，已有颜色的像素不被覆盖（先到先得）。超出网格边界的像素丢弃。
- maroon 标记像素在输出中被清除为背景色。模板区域保持不变。

Key insight
- 解题者需要发现三层规则：（1）种子颜色对应哪个模板（颜色查找），（2）模板定义了生长的空间形状（图案匹配），（3）邻域 maroon 像素数量控制生长迭代次数（计数决定规模）。三层信息来源互不重叠，必须逐一识别。
</new_puzzle>

<new_puzzle>
将网格中每对同色线段的交叉区域提取出来，按交叉区域面积从大到小排列在输出网格中。

Input structure
- 背景为 black。
- 网格中有若干条彩色矩形条带（每条条带宽1-2像素，长度不等），分为水平和垂直两组。
- 每种颜色恰好有两条条带：一条水平、一条垂直，它们在网格中某处交叉（有重叠像素区域）。
- 不同颜色的条带对之间不交叉。
- 交叉区域是一个小矩形（宽度 = 两条带宽度之积的像素区域）。

Rule
- 对每种颜色，找到其水平条带和垂直条带的交叉区域（重叠的矩形像素块）。
- 从交叉区域向外，沿水平和垂直两个方向各保留条带延伸出交叉区域的部分，形成一个十字形图案。将该十字形图案裁剪到其最小外接矩形。
- 将所有颜色的十字形图案按外接矩形面积从大到小排序。
- 输出网格中，将这些十字形图案从上到下依次堆叠排列，每两个图案之间留1行背景色间隔，所有图案左对齐。
- 输出网格的宽度等于最大图案的宽度，高度等于所有图案高度之和加上间隔行数。

Key insight
- 解题者需要先识别同色配对（颜色是配对线索），再理解交叉区域定义了十字形的中心，最后发现排序依据是十字形外接矩形面积而非条带长度或交叉面积本身。三步推理环环相扣。
</new_puzzle>
