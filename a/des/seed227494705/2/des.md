description：根据封闭区域内部的孔洞数量，在色板中查找对应颜色，用该颜色重绘整个封闭区域的边界。

Input structure：
- 背景为 Black。
- 网格右侧或底部有一个纵向或横向的色板条：色板由若干连续的彩色方块组成，从上到下（或从左到右）分别代表数值 0、1、2、3……，每个方块用不同颜色填充（例如第 0 格为 Red，第 1 格为 Blue，第 2 格为 Green，第 3 格为 Yellow 等）。
- 网格主区域包含若干个由 Grey 像素绘制的单像素宽封闭多边形（矩形、L形或不规则闭合轮廓）。
- 每个封闭多边形内部可能包含零个或多个由 Grey 像素绘制的独立小方块（1x1 或 2x2），这些小方块就是"孔洞标记"。

Rule：
- 对每个 Grey 封闭多边形，数出其内部包含的独立小方块数量 N（N 范围为 0 到色板长度-1）。
- 在色板中找到第 N 个位置对应的颜色 C。
- 将该封闭多边形的所有边界像素从 Grey 重绘为颜色 C。
- 内部的小方块标记保留为 Grey 不变。
- 色板本身在输出中保持不变。

Key insight：
- 第一层推理需要识别色板是一个有序的颜色查找表；第二层推理需要发现封闭区域内部的孤立小方块数量是查找表的索引键——孔洞数量与颜色之间的映射关系并非显然，需要跨多个样例比对才能归纳出来。
</new_puzzle>

description：将网格中散落的彩色碎片按颜色归组，每组碎片拼合后恰好填满对应颜色边框内的空腔。

Input structure：
- 背景为 Black。
- 网格中有若干个不同颜色的单像素宽矩形边框（例如 Red 边框、Blue 边框、Green 边框），每个边框内部为 Black 且包含一个不规则形状的 Grey 填充区域，Grey 区域中有若干个 Black 空洞像素（空腔）。
- 网格的其他区域散布着与边框颜色相同的彩色小碎片对象（4-连通的小型连通域），每种边框颜色对应若干个同色碎片。
- 每种颜色的所有碎片面积之和恰好等于对应颜色边框内 Grey 区域中 Black 空洞的总面积。

Rule：
- 对每种边框颜色，收集网格中所有同色碎片的形状。
- 将这些碎片按面积从大到小排列，依次填入对应颜色边框内 Grey 区域的 Black 空洞中：每个碎片从空洞区域的最上行最左列开始，逐行扫描找到第一个能放下的位置（碎片保持原始朝向不旋转），用该边框颜色填充对应像素。
- 清除网格中原始散落碎片的位置（恢复为 Black）。
- 边框本身和 Grey 填充区域保持不变。

Key insight：
- 第一层推理需要发现碎片颜色与边框颜色的对应关系——颜色匹配是分组依据；第二层推理需要发现碎片并非随意放置而是按面积降序逐个填入空腔，填充规则是行优先扫描的贪心放置，这一拼装规则需要从多个样例中归纳。
</new_puzzle>

description：根据每个对象与网格四条边的接触模式，在对象内部绘制对应方向的箭头符号，箭头方向受角落标记的全局翻转规则控制。

Input structure：
- 背景为 Black。
- 网格中有若干个不同颜色的实心矩形对象（至少 5x5 大小），彼此不重叠、不接触。
- 每个矩形恰好有一条边紧贴网格的某条外边界（上/下/左/右），其余三条边与网格边界之间有间隔。
- 网格的四个角落各有一个单像素的 Magenta 标记或没有标记。角落标记的存在/缺失编码了一个翻转规则。

Rule：
- 首先确定翻转模式：检查网格四角是否有 Magenta 标记。若左上和右下有标记（主对角线模式），则箭头方向需要沿主对角线翻转（上变左、下变右、左变上、右变下）；若右上和左下有标记（副对角线模式），则沿副对角线翻转（上变右、下变左、左变下、右变上）；若四角都无标记，则不翻转。
- 对每个矩形，找出它紧贴网格边界的那条边所指的方向 D（例如紧贴上边界则方向为"上"）。
- 将方向 D 经过翻转模式变换得到最终方向 D'。
- 在矩形的中心区域用 Grey 绘制一个指向 D' 的箭头符号。箭头绘制方式：以矩形中心像素为箭杆末端，沿 D' 方向绘制长度为 2 的箭杆（2 个像素），在箭杆末端（箭头尖端）的两侧各画 1 个像素作为箭翼，形成一个 ">" 形状（根据方向旋转）。

Key insight：
- 第一层推理需要发现矩形贴边方向决定了箭头的基础朝向——这并不明显因为箭头方向和贴边方向经过了变换；第二层推理需要发现角落标记编码了一种全局的方向映射规则（对角线翻转），这两层信息结合才能解释每个箭头的最终朝向。
</new_puzzle>

<new_puzzle>
description：沿着彩色路径行走，在每个拐弯处用路径前一段的颜色填充拐角内侧的矩形区域。

Input structure：
- 背景为 Black。
- 网格中有一条单像素宽的连续折线路径，路径由多段直线组成，每段直线使用不同颜色（例如第一段 Red、第二段 Blue、第三段 Green 等），段与段之间在拐弯处共享一个像素。
- 路径只做 90 度拐弯（水平转垂直或垂直转水平），不存在对角线段。
- 路径不自交叉，且与网格边界有至少 1 像素的间距。

Rule：
- 从路径的一个端点出发，沿路径行走。路径的端点是只有一个路径邻居的像素。选择行坐标较小的端点（若相同则选列坐标较小的）作为起点。
- 在每个拐弯处（方向改变的像素），确定拐弯的内侧方向——即拐弯形成的"凹角"方向。
- 以拐弯像素为角点，在内侧方向绘制一个填充矩形：矩形的两条边分别沿拐弯前的行进方向和拐弯后的行进方向延伸。沿拐弯前方向的边长等于拐弯前那一段路径的像素长度，沿拐弯后方向的边长等于拐弯后那一段路径的像素长度。
- 该矩形使用拐弯前那一段路径的颜色填充。
- 矩形不覆盖路径本身的像素——路径像素保持原色优先。
- 若多个矩形区域重叠，后绘制的（沿路径方向后遇到的拐弯）覆盖先绘制的。

Key insight：
- 解题者需要先识别路径的分段着色结构来确定行走方向和段落划分；然后需要发现每个拐弯的内侧区域被填充，且填充尺寸由相邻两段的长度决定、颜色由前一段决定——这一"拐角内侧矩形"的生成规则是核心非显然发现。
</new_puzzle>

description：识别网格中的"种子图案"和"生长模板"，将种子图案按模板指定的方向和层数向外扩展生长。

Input structure：
- 背景为 Black。
- 网格中包含一个由 Grey 像素绘制的小型封闭矩形框（3x3 到 5x5），框内有一个由某种颜色（如 Red）绘制的小图案，这就是"种子图案"。
- 网格的另一个区域有一个"生长模板"：一个与种子矩形框等大的 Grey 框，框内四个方向（上、下、左、右）的边缘像素中，某些位置被标记为不同颜色。每种标记颜色出现在且仅出现在一个方向的边缘上（例如 Blue 标记在上边缘，Green 标记在右边缘）。每种标记颜色的像素数量表示该方向的生长层数。
- 种子图案和生长模板不重叠。

Rule：
- 读取生长模板：对四个方向分别计算标记像素的数量，得到各方向的生长层数（例如上方向 2 层、右方向 1 层、下方向 0 层、左方向 3 层）。
- 以种子图案为起始，向每个有标记的方向逐层复制生长：每"生长一层"意味着将种子图案的边缘行或列沿该方向平移复制一次。例如向上生长 2 层，则将种子图案的顶行向上复制 2 次（第 1 层在顶行上方 1 格、第 2 层在上方 2 格）。
- 生长出的新像素使用对应方向在模板中的标记颜色，而非种子图案原色。
- 种子图案保持原色不变；Grey 框在输出中被移除（恢复为 Black）；生长模板也被移除。
- 输出仅保留生长后的完整图案。

Key insight：
- 第一层推理需要将 Grey 框中的小图案识别为种子、另一个 Grey 框识别为控制模板——两者外观相似但功能完全不同；第二层推理需要发现模板边缘标记像素的数量编码了生长层数、标记所在的方向编码了生长方向、标记颜色编码了生长部分的着色——三重信息编码在同一组标记像素中，需要跨样例归纳。
</new_puzzle>

description：在被分隔线划分的网格区域之间，找到形状配对关系，然后将每对中较小区域的图案复制填入较大区域的标记位置。

Input structure：
- 背景为 Black。
- 网格被一条或多条 Grey 直线（水平或垂直，贯穿整个网格宽度或高度）分割成若干矩形子区域。
- 每个子区域内包含一个由某种前景色绘制的图案。这些图案两两配对：同一对中的两个图案颜色相同但大小不同（一个占据较大面积，一个占据较小面积）。
- 每对中，较大图案所在的子区域还包含一块与较小图案的外接矩形等大的 Azure 矩形标记，标明了粘贴位置。

Key insight：
- 第一层推理需要发现 Grey 分隔线将网格划分为独立区域，同色图案之间是配对关系；第二层推理需要识别 Azure 矩形不是装饰而是位置标记，指定了小图案粘贴的确切位置——配对关系和粘贴位置两个规则需要分别从样例中归纳。
</new_puzzle>

<new_puzzle>
description：根据围栏内部填色对象的层叠遮挡顺序，在围栏外部按该顺序从内到外排列同色边框环。

Input structure：
- 背景为 Black。
- 网格中央有一个较大的 Grey 单像素宽矩形围栏。
- 围栏内部有若干个不同颜色的实心矩形对象（3 到 5 个），这些矩形彼此部分重叠，形成明确的前后层叠关系（前面的对象遮挡后面的对象）。每个矩形颜色唯一。
- 围栏外部为空（全 Black）。

Rule：
- 确定围栏内部各彩色矩形的层叠顺序：被遮挡的对象在"后面"（层级低），遮挡其他对象的在"前面"（层级高）。层级判断方式：如果一个矩形有边缘被另一个矩形截断（即矩形的可见边界不完整），则它在被截断方向上位于遮挡者后面。
- 以围栏为中心，在围栏外部绘制同心矩形环。最内层环（紧贴围栏外侧）使用层叠顺序中最前面（层级最高）的矩形颜色，向外每一层环依次使用层级递减的颜色。
- 每个环宽度为 1 像素。
- Grey 围栏保持不变；围栏内部的内容保持不变。

Key insight：
- 第一层推理需要从部分遮挡的矩形中推断出完整的层叠深度排序——这需要分析哪些边缘被截断来确定遮挡关系；第二层推理需要发现这个排序被"翻译"为围栏外部同心环的颜色顺序，最前面的对象对应最内圈——内部的深度信息被编码到外部的空间距离中。
</new_puzzle>
