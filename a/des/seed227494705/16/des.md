- `Input structure`：背景为主色（如 black）。网格中有一种颜色（如 blue）绘制的若干互不相交的封闭矩形框。每个矩形框内部恰好有一个单独的彩色标记像素（颜色各不相同，如 red、green、yellow 等）。网格的某个角落（如左上角）有一个图例区域：图例由若干行组成，每行左侧一个颜色像素作为"键"，右侧紧邻一个 2×2 或 3×3 的小图案作为"值"，图案由两种颜色的像素交替排列构成（如棋盘格、条纹、L 形等）。图例的每个键颜色与某个矩形框内的标记像素颜色一一对应。

- `Rule`：
  1. 识别图例区域中的每对"键颜色 → 图案"映射。
  2. 对于每个封闭矩形框，读取其内部标记像素的颜色，在图例中找到对应的图案。

  4. 标记像素本身被图案覆盖，不保留。
  5. 图例区域在输出中保持不变。

- `Key insight`：标记像素不是用来填充的颜色本身，而是指向图例的索引键；解题者需要先建立"颜色→图案"的映射表，再将图案作为纹理平铺进对应区域，这构成两层独立的归纳推理。

- `Input structure`：背景为主色（如 black）。网格中散布着若干个由三个同色像素组成的 L 形箭头标记，每个箭头由一个长度为 2 的直线段和一个垂直拐角像素组成，拐角像素指示射线方向（拐角处为箭头尾部，直线段末端远离拐角的一端为箭头头部）。箭头颜色各不相同（如 red、blue、green、yellow 等）。网格边缘没有其他前景对象。

- `Rule`：
  1. 确定每个 L 形箭头的朝向：从拐角像素沿直线段方向看，箭头头部的朝向即为射线发射方向。

  4. 原始箭头标记保留在输出中。

- `Key insight`：解题者首先需要从 L 形的不对称结构中推断射线方向（拐角编码了方向信息），然后需要发现射线碰撞时产生的颜色混合规则（任意两色相遇都变 grey），这两步归纳缺一不可。

- `description`：将网格中的多个相同形状但不同颜色的拼图块，按照它们的颜色在隐含色序条上的顺序，依次旋转对应角度后拼合到目标框架内。

- `Input structure`：背景为主色（如 black）。网格分为左右两个区域。右侧有一个由 grey 像素绘制的矩形空心框架，框架内部全为背景色。左侧散布着若干个形状完全相同的小对象（如 T 形或 Z 形），每个对象颜色不同（如 red、blue、green、orange）。左侧还有一个单列的"色序条"，从上到下排列着若干颜色像素，颜色与小对象一一对应，定义了拼合的先后顺序。

- `Rule`：
  1. 读取色序条从上到下的颜色顺序，确定小对象的放置次序。
  2. 色序条中第 1 个颜色对应的对象不旋转（0°），第 2 个顺时针旋转 90°，第 3 个顺时针旋转 180°，第 4 个顺时针旋转 270°，以此类推（每个后续对象比前一个多转 90°）。
  3. 按顺序将旋转后的对象从目标框架内部的左上角开始，逐行紧密排列放入框架中（类似从左到右、从上到下的阅读顺序），对象之间无间隔。
  4. 框架本身和色序条在输出中保持不变。左侧原始对象位置清除为背景色。

- `Key insight`：解题者需要同时发现两个非显然规则：色序条定义了放置顺序，而放置顺序隐含地编码了旋转角度（第 N 个对象旋转 (N-1)×90°）。颜色本身不决定旋转量，位置序号才决定旋转量。
</new_puzzle>

- `description`：每个彩色种子像素生长出与其所在封闭房间面积等高的向上柱状条，柱状条的颜色由房间出口方向对应的染色规则决定。

- `Input structure`：背景为主色（如 black）。网格中有 blue 像素构成的墙壁，将网格内部分隔成若干个互不连通的矩形"房间"（每个房间是一个由墙壁完全围合的矩形背景区域，但恰好有一面墙上缺少一个像素宽的"出口"）。每个房间内部底行有一个单独的彩色种子像素（颜色各不相同）。网格顶部有一行颜色图例：图例由四个颜色像素组成，从左到右分别对应"出口在上、出口在右、出口在下、出口在左"四个方向。

- `Rule`：
  1. 对每个房间，数出其内部背景像素的数量（即房间面积，不含墙壁和种子像素本身）。
  2. 确定该房间出口所在的方向（上、右、下、左）。
  3. 从顶部图例中，根据出口方向读取对应的颜色。
  4. 从种子像素位置向上绘制一条垂直柱状条，柱状条高度等于房间面积的像素数，颜色为步骤 3 查到的图例颜色。柱状条可穿过墙壁和网格边界外的空间（若超出网格则截断）。
  5. 种子像素本身被柱状条的底部像素覆盖。房间、墙壁和图例其余部分不变。

- `Key insight`：解题者需要完成三层推理：（1）识别出每个房间的"出口"缺口并判断其方向；（2）发现顶部图例的四个颜色按固定方向顺序编码了出口方向到柱状条颜色的映射；（3）发现柱状条高度等于房间面积而非房间某一维的长度。三层信息来源各不相同，缺一不可。
</new_puzzle>

- `description`：将散落的彩色碎片按照形状匹配嵌入对应的灰色模板孔洞中，并根据碎片原始位置相对于模板的方向对碎片进行镜像翻转。

- `Input structure`：背景为主色（如 black）。网格中央有一个较大的 grey 填充矩形区域，其中挖去了若干个不规则形状的孔洞（孔洞处为背景色）。每个孔洞的形状都是独一无二的。在 grey 矩形的上方、下方、左方、右方散布着若干个彩色小对象，每个小对象的形状恰好与某个孔洞完全匹配（未经变换时形状相同）。每个彩色对象颜色各不相同。

- `Rule`：
  1. 将每个彩色碎片与灰色模板中形状匹配的孔洞配对。
  2. 确定该碎片相对于灰色模板中心的方位：若碎片在模板上方，则将碎片沿水平轴上下翻转；若在下方，也沿水平轴翻转；若在左方，沿垂直轴左右翻转；若在右方，也沿垂直轴翻转。
  3. 将翻转后的碎片填入对应孔洞的位置，保持碎片自身颜色。
  4. 清除碎片的原始位置（恢复为背景色）。灰色区域其余部分不变。

- `Key insight`：碎片与孔洞的形状匹配是第一层推理，但仅靠形状匹配无法直接放入——碎片需要先经过镜像翻转才能正确嵌入孔洞。翻转轴由碎片相对于模板的空间方位决定（上下方位→水平翻转，左右方位→垂直翻转），这是第二层需要从样例中归纳的隐蔽规则。

- `description`：根据每条路径上"门"的开闭状态，选择从起点到终点的唯一通路，并用路径颜色标记该通路。

- `Input structure`：背景为主色（如 black）。网格中有 blue 像素构成的迷宫墙壁，形成若干条从左侧边缘通向右侧边缘的水平通道（通道宽度为 1 像素）。每条通道在中途被若干个单像素的"门"阻隔——门像素的颜色为 red 或 green。网格左侧边缘有一个 yellow 起点标记像素位于某条通道入口处，右侧边缘有一个 yellow 终点标记像素位于某条通道出口处。不同通道之间在某些位置有垂直的 1 像素宽连接段（也是背景色），允许从一条通道切换到相邻通道。

- `Rule`：
  1. green 门视为"开启"状态，可以通过；red 门视为"关闭"状态，不可通过。
  2. 从起点开始，沿通道向右移动；遇到 red 门时必须通过垂直连接段切换到相邻通道继续前进。遇到 green 门时直接穿过。
  3. 找到从起点到终点的唯一路径（保证存在且唯一）。
  4. 将该路径经过的所有背景像素涂为 orange，经过的 green 门保持 green 不变。
  5. 起点和终点标记保持 yellow，墙壁和 red 门保持不变。

- `Key insight`：解题者需要首先理解 red/green 门的通行语义（颜色编码开闭状态），然后发现垂直连接段是绕过关闭门的"换道"机制，最终通过逻辑推理找出唯一通路。门的颜色语义和换道机制构成两层独立的归纳。
</new_puzzle>

- `description`：将网格中的"源图形"通过"传送门对"复制到远端位置，并根据传送门边框的缺口方向旋转副本的朝向。

- `Input structure`：背景为主色（如 black）。网格中有若干对 maroon 色的小矩形空心框，每对框的内部各有一个相同颜色的单像素标记（如一对都含 red 标记，另一对都含 green 标记），以此标识配对关系。每个框恰好在一条边上有一个 1 像素宽的缺口。某些传送门框的附近（紧邻缺口外侧）有一个由多种颜色组成的小型前景图形（"源图形"），而配对的另一个框附近没有图形。

- `Rule`：
  1. 通过内部标记颜色将传送门框配对。
  2. 对于有源图形的一侧，确定该框缺口的朝向（上/下/左/右），以及配对框缺口的朝向。
  3. 计算从源框缺口方向到目标框缺口方向需要顺时针旋转的角度（0°/90°/180°/270°）。
  4. 将源图形按该角度顺时针旋转，然后放置在目标框缺口外侧，图形紧贴缺口。
  5. 源图形的原始副本保留不动。所有传送门框保持不变。

- `Key insight`：解题者需要先通过内部标记颜色完成传送门配对（第一层），再发现缺口方向的差异编码了旋转角度（第二层）。缺口不仅指示图形的放置位置，还隐含地决定了图形的旋转变换。
</new_puzzle>
