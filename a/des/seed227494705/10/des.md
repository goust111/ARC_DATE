<new_puzzle>
description：根据框架内部的彩色种子像素，向外生长出与种子颜色对应的枝干图案，枝干的生长方向由种子在框架中的象限位置决定。

Input structure：
- 背景为 Black。网格中有若干个大小相同的正方形空心框架，框架颜色为 Grey。
- 每个框架的内部恰好有一个彩色种子像素（非 Black、非 Grey），位于框架内部 2x2 区域的四个位置之一（左上、右上、左下、右下）。
- 框架外部为空白背景，有足够空间容纳生长图案。

Rule：
- 保持所有框架不变。
- 对每个框架，根据种子像素在框架内部 2x2 区域中的位置确定生长方向：左上→向左上方生长，右上→向右上方生长，左下→向左下方生长，右下→向右下方生长。
- 生长图案为：从框架对应角的外侧开始，沿对角线方向画出一条与种子同色的像素线，长度等于框架的边长（不含边框本身的内部宽度）。同时，在对角线的每一步，向该对角线的两个分量方向（水平和垂直）各延伸一个像素，形成类似树枝的 Y 形分叉。
- 如果生长超出网格边界，则在边界处截断。

Key insight：种子在框架内的微小位置差异决定了整个生长方向，而框架尺寸控制了枝干长度——解题者需要同时发现"位置→方向"的映射规则和"框架尺寸→枝干长度"的数值关系。
</new_puzzle>

<new_puzzle>
description：将散落在画布上的彩色碎片按颜色匹配拼入对应颜色轮廓的缺口中，拼入前需要将碎片旋转到与缺口形状吻合的朝向。

Input structure：
- 背景为 Black。网格中有若干个不同颜色的空心轮廓形状（由单色像素组成的闭合边框，内部为 Black），每个轮廓的边框上恰好有一个矩形缺口（连续缺失的边框像素）。
- 网格中还散落着若干个与轮廓颜色相同的小型实心碎片（3-5 个像素组成的连通块）。每个碎片的颜色与恰好一个轮廓匹配。
- 每个碎片的形状恰好可以在四种旋转（0度、90度、180度、270度）中的一种下精确填入对应轮廓的缺口。

Rule：
- 对每个彩色轮廓，找到与其颜色相同的碎片。
- 将碎片旋转到能精确填入该轮廓缺口的朝向（缺口形状与碎片的某个旋转态完全吻合）。
- 将旋转后的碎片放置到缺口位置，使轮廓变为完整的闭合边框。
- 碎片原始位置变为 Black 背景。

Key insight：解题者需要先识别每个轮廓的缺口形状，再在心中旋转碎片进行形状匹配——颜色提供配对线索，但真正的推理在于空间旋转匹配，且不同轮廓的缺口朝向各异，无法用统一旋转角度解决所有碎片。
</new_puzzle>

<new_puzzle>
description：在分隔条划分的多个面板中，每个面板包含一个彩色图案和若干标记点；根据标记点的数量从全局调色板中选色，用选出的颜色替换该面板内图案的原始颜色。

Input structure：
- 背景为 Black。网格被 Grey 色的完整竖线分隔为若干个等宽的垂直面板。
- 网格最左侧有一列特殊的调色板区域：从上到下依次排列着不同颜色的单个像素，从第 1 行到第 N 行分别为第 1 到第 N 种颜色（例如第 1 行 Red，第 2 行 Blue，第 3 行 Green……）。
- 每个面板内有一个由某种前景色构成的连通图案（形状各不相同），以及若干个散落的 Maroon 标记像素（不与图案相邻，孤立分布）。

Rule：
- 数出每个面板中 Maroon 标记像素的个数 K。
- 在调色板中找到第 K 个颜色（从上往下第 K 行的颜色）。
- 将该面板中图案的所有像素替换为这个调色板颜色。
- 移除所有 Maroon 标记像素（变为 Black）。
- 调色板区域和 Grey 分隔线保持不变。

Key insight：标记点的数量不是直接属性值，而是调色板的索引——解题者需要先发现"数标记"和"查调色板"这两步独立操作之间的链接关系，再应用到每个面板。单独看任一面板都无法确定规则，必须跨面板比较才能归纳出计数→索引→重着色的完整管道。
</new_puzzle>

<new_puzzle>
description：将网格中由箭头形状指示的源区域内容，沿箭头指向传送到目标框架内部，传送过程中内容需按箭头方向进行镜像翻转。

Input structure：
- 背景为 Black。网格中有若干个 Grey 色的空心矩形框架（大小可能不同但内部面积相同）。
- 每个框架的某一侧外部紧邻一个由 Red 像素组成的箭头。箭头由一条 3 像素长的直线杆和一个 V 形箭尖构成（箭尖朝向上、下、左、右四个方向之一），箭尖指向远离框架的方向。
- 沿箭头指向的方向，在箭头远端存在一个与框架内部面积相同的矩形区域，该区域内填有多色图案（源图案）。

Rule：
- 对每个框架，沿其关联箭头的反方向（即从箭尖向框架方向）找到源图案。
- 将源图案沿箭头杆所在轴进行镜像翻转：若箭头水平指向，则左右镜像；若箭头垂直指向，则上下镜像。
- 将翻转后的图案填入框架内部。
- 移除所有 Red 箭头像素，源图案保持不变。

Key insight：箭头同时编码了两层信息——方向指示源图案的位置（沿箭头方向寻找），而箭头的朝向轴决定了镜像翻转的方式。解题者容易只注意到"方向→位置"的关系，而忽略第二层"方向→翻转轴"的隐含规则。
</new_puzzle>

<new_puzzle>
description：在一个包含多个嵌套环形结构的网格中，每层环的颜色由该环所围住的内部独立对象数量决定，数量通过全局颜色序列映射为颜色。

Input structure：
- 背景为 Black。网格中心区域有若干层同心的矩形环（环之间有一个像素的间隔，间隔为 Black）。所有环的初始颜色均为 Grey。
- 在最内层环的内部空间中，散布着若干个小型彩色对象（每个对象是 2-4 个像素的连通块，颜色各异）。
- 网格的一个角落（例如左上角）有一行水平排列的颜色序列像素，从左到右依次为不同颜色（例如 Blue、Red、Green、Yellow、Orange……），作为编号 1, 2, 3, 4, 5… 的颜色图例。

Rule：
- 从最内层环开始，向外逐层处理每一层环。
- 对于最内层环：数出其内部包含的独立彩色对象个数 N，在颜色图例中找到第 N 个颜色，将该环重着色。
- 对于第二层环：数出其内部（即该环与更内层之间的环形区域中，加上内层包围的所有内容）包含的所有独立彩色对象的总数 M，用颜色图例第 M 个颜色重着色。
- 依此类推，每层环的颜色由从该环向内看能看到的所有独立对象总数决定。
- 颜色图例和内部彩色对象保持不变。

Key insight：外层环的颜色取决于其内部所有层的对象累计总数，而非仅该层自身区域内的对象数——这意味着外层环的颜色编号始终大于或等于内层环的颜色编号，形成一个单调递增序列。解题者需要发现"累计计数"而非"逐层独立计数"的规则。
</new_puzzle>

<new_puzzle>
description：根据网格中每个封闭区域的出口数量，选择性地保留或擦除区域内的内容，并用出口数量对应的颜色标记每个出口位置。

Input structure：
- 背景为 Black。网格中有一个由 Grey 像素构成的不规则迷宫状墙壁结构，将空间划分为若干个封闭或半封闭的区域（连通的 Black 空间）。
- 每个区域内部包含一些彩色像素构成的小图案。
- 某些区域的边界墙壁上有缺口（1 像素宽的 Black 间断），这些缺口就是"出口"，连通相邻区域或通往网格边缘。
- 网格底部有一行颜色图例：从左到右的像素颜色分别对应出口数 0, 1, 2, 3...

Rule：
- 对每个封闭区域，数出其边界墙壁上的出口（缺口）数量 E。
- 如果 E 为偶数，保留该区域内的所有彩色图案不变。
- 如果 E 为奇数，将该区域内的所有彩色图案擦除为 Black。
- 无论保留还是擦除，在每个出口位置（墙壁缺口处）放置一个像素，颜色为图例中第 E 个位置对应的颜色。
- 墙壁结构和颜色图例保持不变。

Key insight：解题者需要发现两层独立规则：第一层是"出口数量的奇偶性决定区域内容的保留与擦除"，第二层是"出口数量作为索引从图例中选色标记出口"。这两层规则作用于不同的输出位置（区域内部 vs 出口处），需要分别归纳。
</new_puzzle>

<new_puzzle>
description：将网格中的多个形状按照它们与同色锚点像素的相对位置关系，重新排列到一个公共目标框架内的对应位置。

Input structure：
- 背景为 Black。网格分为左右两个区域，由一条 Maroon 竖线分隔。
- 左侧区域包含一个较大的 Grey 空心矩形目标框架，框架内部为空（Black）。框架内部的边缘上有若干个不同颜色的单像素锚点（每种颜色恰好出现一次），每个锚点位于框架内壁的不同位置。
- 右侧区域散布着若干个小型彩色形状（每个形状为 3-6 像素的连通块），每个形状的颜色与左侧某个锚点颜色相同。每个形状旁边紧邻一个同色的孤立单像素标记点。

Rule：
- 对右侧每个彩色形状，找到其同色标记点，计算形状的几何中心相对于标记点的偏移向量（行偏移、列偏移）。
- 在左侧框架中找到同色锚点。
- 将该偏移向量应用到锚点位置，将形状放置到框架内部对应的位置。
- 形状如果超出框架内部范围，则在框架边界处截断。
- 右侧区域清空为 Black，Maroon 分隔线移除，仅输出左侧区域（含框架和放入的形状）。

Key insight：标记点不是形状的一部分，而是"定位参照物"——形状与标记点的空间关系被"传送"到锚点处复现。解题者需要发现标记点和锚点之间的对应关系（通过颜色），以及偏移向量的传递机制。
</new_puzzle>
