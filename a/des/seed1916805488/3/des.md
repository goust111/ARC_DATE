<description>
根据嵌套框架的层级深度选择对应图例颜色，再按框架朝向将内部填充物旋转后重绘。

Input structure:
- 背景为黑色。网格中散布着若干由灰色（Grey）像素构成的嵌套矩形框架，框架可以一层套一层（最多3-4层）。每个最内层框架的中心区域包含一个由单一非背景色绘制的小型图案（如L形、T形等，占3-5个像素）。
- 网格的一条边缘（如顶部）排列着一行颜色图例：从左到右依次为不同颜色的单个像素点（如红色、蓝色、绿色、橙色），它们的左右顺序对应嵌套深度1、2、3、4。
- 每个最外层框架的某一侧边有一个单像素缺口（上、下、左或右侧各一个像素缺失）。

Rule:
- 第一步：对每组嵌套框架，从外向内数框架层数（最外层算第1层），得到最内层图案所处的嵌套深度 D。
- 第二步：根据深度 D 在颜色图例中查找对应颜色（图例从左到右第 D 个颜色）。
- 第三步：确定最外层框架缺口所在的方位（上、下、左、右）。将最内层图案以框架中心为基准，朝缺口方向旋转90°的整数倍（缺口在上=不旋转，缺口在右=顺时针90°，缺口在下=180°，缺口在左=逆时针90°）。
- 第四步：用第二步查到的颜色重新绘制旋转后的图案，替换原图案。框架和图例保持不变。

Key insight: 解题需要两层独立推理——先通过嵌套层数与图例位置的对应关系确定颜色，再通过框架缺口方位确定旋转角度；两者缺一不可且互不提示。
</description>

<description>
将散落的彩色碎片按形状互补性配对拼合成矩形，再按矩形面积从小到大堆叠排列到输出网格。

Input structure:
- 背景为黑色。网格中散布着偶数个彩色连通区域（4连通），每个区域由单一颜色构成，颜色各不相同。
- 这些区域可以两两配对：每对中的两个形状恰好能拼合成一个无缝无重叠的实心矩形（一个是矩形的"正形"，另一个是"补形"）。
- 配对的两个碎片颜色不同，但它们的包围盒尺寸相同。

Rule:
- 第一步：识别所有碎片的包围盒尺寸。将包围盒尺寸相同的碎片两两配对——对于每对碎片，将其中一个碎片在包围盒内取反（填充像素变空、空变填充），若与另一个碎片的形状完全吻合，则确认配对。
- 第二步：对每对碎片，将两者叠合到同一个包围盒中，各自保持原色，形成一个双色实心矩形。
- 第三步：计算每个拼合矩形的面积（宽×高），按面积从小到大排序。
- 第四步：在输出网格中，将排序后的矩形从左到右依次排列，相邻矩形之间留1列黑色间隔，顶部对齐（行0开始）。输出网格高度为最大矩形的高度，宽度为所有矩形宽度之和加上间隔列数。

Key insight: 核心推理在于发现碎片之间的"互补配对"关系——两个看似无关的异色碎片在同尺寸包围盒内恰好互为正负形，拼合后构成完整矩形；配对依据不是颜色而是几何互补性。
</description>

<description>
沿彩色路径行走，在每个转弯处根据转弯方向（左转或右转）从路径两侧生长出不同颜色的枝条。

Input structure:
- 背景为黑色。网格中有一条由灰色（Grey）像素构成的单像素宽折线路径，路径从网格的一条边缘出发，经过若干次直角转弯，终止于网格内部。
- 路径的起点像素被标记为红色（Red）。
- 网格的某个角落有一个2×1的颜色图例：上方一个像素为蓝色（Blue），下方一个像素为绿色（Green）。

Rule:
- 第一步：从红色起点出发，沿灰色路径行进，记录每个转弯点及其转弯方向（相对于行进方向的左转或右转）。
- 第二步：在每个转弯点处，向路径外侧（转弯的反方向一侧）生长一条枝条。枝条颜色由转弯方向决定：右转时枝条颜色为图例上方的颜色（蓝色），左转时为图例下方的颜色（绿色）。
- 第三步：枝条的长度等于从当前转弯点到下一个转弯点之间的路径段长度（像素数）。枝条从转弯点出发，沿垂直于转弯后行进方向的外侧方向延伸，每个像素绘制对应颜色。
- 第四步：枝条若遇到网格边缘则截断。原灰色路径和红色起点保持不变。

Key insight: 需要同时推断两层规则——转弯方向决定枝条颜色（左/右与图例上/下的映射），而相邻转弯点间距决定枝条长度；仅观察颜色或长度中的一个无法完整归纳规则。
</description>

<description>
用散落的单色"钥匙"形状去匹配框架内的"锁孔"轮廓，匹配成功后将框架内部填充为钥匙的颜色，并根据钥匙需要旋转的次数决定填充的条纹方向。

Input structure:
- 背景为黑色。网格中有若干个由橙色（Orange）像素围成的矩形空心框架（1像素宽边框，内部为黑色背景）。每个框架的内部底边紧贴着一个由背景色和边框色共同构成的小型镂空图案——即框架底部边框上有几个像素被移除，形成一个"锁孔"形状（类似于参差不齐的缺口轮廓，宽2-4像素，高1-2像素）。
- 网格中另有若干个独立的小型单色连通区域（非橙色、非背景色），每个区域颜色不同（如红色、蓝色、绿色等），形状为2-4像素宽、1-2像素高的小图案——即"钥匙"。
- 钥匙的数量与框架数量相同。

Rule:
- 第一步：提取每个框架底部锁孔的形状（缺口的二值轮廓）。
- 第二步：对每把钥匙，尝试0°、90°、180°、270°四种旋转，找到与某个锁孔形状完全匹配的旋转角度。每把钥匙恰好匹配一个锁孔。
- 第三步：记录匹配所需的旋转次数 R（0、1、2、3次顺时针90°旋转）。
- 第四步：将匹配框架的内部（不含边框）填充为该钥匙的颜色，填充方式为条纹图案：R=0 时整体填充（纯色）；R=1 时竖条纹（奇数列填色、偶数列保持黑色）；R=2 时横条纹（奇数行填色、偶数行保持黑色）；R=3 时棋盘格（行列之和为奇数的格子填色）。
- 钥匙本身在输出中被移除（变为背景色）。

Key insight: 解题需要三层推理——形状匹配（钥匙旋转后与锁孔吻合）确定配对关系，钥匙颜色确定填充色，而旋转次数这个"隐性参数"还编码了填充图案的类型；最后一层最为隐蔽，因为旋转次数在匹配完成后看似已无用途。
</description>

<description>
在网格中识别由围墙围成的多个房间，根据房间内种子像素的颜色和数量向外"广播"信号，信号穿过围墙上的门洞传播到相邻房间并改变传播颜色。

Input structure:
- 背景为黑色。网格中有由灰色（Grey）像素构成的单像素宽直线墙壁，这些墙壁将网格分割成若干矩形房间。
- 每面墙壁上恰好有一个单像素宽的缺口（门洞），门洞处为背景色（黑色）。
- 部分房间内部包含1-3个彩色像素点（种子），每个房间内的种子颜色相同，但不同房间的种子颜色不同。其余房间为空（纯黑色内部）。

Rule:
- 第一步：识别所有含种子的房间（源房间）及其种子颜色 C 和种子数量 N。
- 第二步：从每个源房间出发，信号通过门洞向相邻房间传播。信号穿过第1道门洞后进入的房间被填充为颜色 C。
- 第三步：若种子数量 N > 1，信号继续传播：穿过第2道门洞时，填充颜色切换为"颜色序列"中 C 的下一个颜色（颜色序列固定为：红→蓝→绿→黄→红，循环）。每多穿过一道门洞，颜色在序列中再前进一步。信号最多传播 N 个房间（穿过 N 道门洞）。
- 第四步：填充方式为将目标房间内部所有背景像素替换为对应颜色。若同一房间被多个源的信号到达，先到的（传播距离更短的，即穿过更少门洞的）优先；距离相同则保持黑色不填充。
- 灰色墙壁和门洞保持不变。源房间内的种子像素保留。

Key insight: 种子数量不仅控制传播范围（最多穿几道门），还隐含地决定了远处房间的颜色（通过固定颜色序列的偏移）；解题者需要同时发现"数量=传播距离"和"门洞数=颜色偏移"两条独立规则，并理解颜色循环序列的存在。
</description>

<description>
将网格中的箭头形指示物所指方向上的目标对象"吸入"箭头内部，吸入后目标对象按箭头体内分隔线的位置被切割并重新着色。

Input structure:
- 背景为黑色。网格中有若干个由灰色（Grey）像素绘制的箭头形状。每个箭头由一个矩形"箭身"（宽3像素、长5-8像素）和一个三角形"箭头尖"（底边与箭身等宽，高2像素）组成，箭头朝上、下、左或右四个方向之一。
- 箭身内部有1-2条单像素宽的彩色横线或竖线（垂直于箭头方向），这些线将箭身内部分割成2-3个区段，每条分隔线颜色不同。
- 在每个箭头尖指向的方向上，隔1-2个像素的距离处有一个单色矩形目标对象（非灰色、非背景色），宽度与箭身内部宽度相同（1像素），高度/长度等于箭身内部总长度。

Rule:
- 第一步：确定每个箭头的朝向及其指向方向上的目标对象。
- 第二步：将目标对象沿箭头方向平移，移入箭身内部（目标对象的前端与箭头尖底部对齐）。移动后原位置恢复为背景色。
- 第三步：目标对象进入箭身后，被箭身内的彩色分隔线切割为若干段。每一段被重新着色为其紧邻的、更靠近箭头尖方向的那条分隔线的颜色。最靠近箭头尖的那段（前方没有分隔线）保持原色不变。
- 第四步：分隔线本身保留在原位，不被覆盖。箭头的灰色轮廓保持不变。

Key insight: 解题者需要先理解箭头方向决定目标的选取和移动方向（第一层），然后发现箭身内部的彩色线不是装饰而是切割标记（第二层），最后归纳出"每段取靠近箭头尖方向的最近分隔线颜色"这一着色规则（第三层）——三层结构依次隐蔽递进。
</description>

<description>
根据散落色块在网格中的相对空间聚类关系确定分组，再将每组色块的形状叠合为模板，用该模板在对应区域进行镂空雕刻。

Input structure:
- 背景为Azure（浅蓝色）。网格中有若干个大型单色实心矩形块（每个颜色不同，如红色、绿色、黄色等），这些矩形块之间不重叠且彼此间隔较远。
- 网格中还散布着若干小型标记物（每个由2-5个像素组成的连通区域），每个标记物为单一颜色。这些标记物的颜色不与任何大型矩形块的颜色相同——标记物只使用灰色（Grey）和黑色（Black）两种颜色。
- 每个标记物在空间上明显更靠近某一个大型矩形块（属于该矩形块的"势力范围"）。每个大型矩形块周围有2-4个标记物。

Rule:
- 第一步：将每个标记物分配给离它最近的大型矩形块（按标记物中心到矩形块边缘的视觉距离判断，不存在歧义情况）。
- 第二步：对于分配到同一矩形块的所有标记物，提取它们的形状。将同组内所有灰色标记物的形状进行布尔"或"运算（叠合），得到一个合并模板 A；将所有黑色标记物的形状同样叠合得到模板 B。
- 第三步：将模板 A 居中对齐到对应的大型矩形块上，将模板覆盖的像素从矩形块中移除（变为背景色），形成镂空效果。
- 第四步：将模板 B 居中对齐到同一矩形块上，将模板覆盖的像素颜色替换为黑色（在矩形块表面绘制黑色图案）。
- 若模板 A 和 B 有重叠像素，A 的镂空优先（该像素变为背景色）。标记物本身在输出中被移除。

Key insight: 解题者首先需要发现标记物与矩形块的空间归属关系（第一层），然后发现灰色和黑色标记物的功能不同——灰色代表"挖除"、黑色代表"印刷"（第二层），最后要理解同色标记物的形状需叠合而非单独使用（第三层）。
</description>
</new_puzzle>
