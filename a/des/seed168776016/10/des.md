- `description`：根据封闭区域内部陷阱像素的颜色，选择对应颜色的外部碎片填入该区域的空缺位置。
- `Input structure`：
  - 背景为黑色。
  - 网格中有若干由同一种非背景色（如 grey）绘制的封闭矩形框（空心），每个框内部大部分为背景色，但包含一个或少量"陷阱像素"——颜色各不相同（如 red、blue、green 等）。
  - 网格中散布着若干小型单色连通碎片（sprite），每个碎片的颜色与某个框内陷阱像素的颜色相同。
  - 每个封闭框内部的背景区域恰好有一块与对应颜色碎片形状完全吻合的空缺（即碎片可无旋转无翻转地精确嵌入）。
- `Rule`：
  - 对每个封闭框，读取其内部陷阱像素的颜色 C。
  - 在框外找到颜色为 C 的碎片。
  - 将该碎片平移到框内部，使其精确填入框内背景区域的空缺位置（碎片形状与空缺形状一致，无需旋转或翻转）。
  - 清除碎片原始位置，保留框和陷阱像素不变。
- `Key insight`：陷阱像素不是噪声，而是颜色索引——它指定了应当从外部取用哪个碎片来填补框内的空缺。解题者需先建立"内部颜色→外部碎片"的映射，再识别空缺的几何形状来确认嵌入位置。
</new_puzzle>

- `description`：在网格中找到被标记行列交叉定位的目标像素，将每个目标像素扩展为由其所在象限决定的方向性 L 形印章。
- `Input structure`：
  - 背景为黑色。
  - 网格的某一行和某一列分别被涂满同一种标记色（如 azure），形成一个十字准星，交叉点为一个特殊颜色（如 yellow）。
  - 网格中散布着若干前景色像素（如 red、green、blue），每个像素颜色各异或相同。
  - 这些前景色像素均不位于标记行或标记列上。
- `Rule`：
  - 十字准星的交叉点将网格分为四个象限：左上、右上、左下、右下。
  - 对每个前景色像素，根据它所在的象限，绘制一个 3 像素的 L 形印章（包含该像素本身加上两个相邻像素），L 形的两个臂朝向该象限的"内侧"——即朝向交叉点的方向：
    - 左上象限的像素：L 形向右和向下延伸（即该像素 + 右邻 + 下邻）。
    - 右上象限的像素：L 形向左和向下延伸（即该像素 + 左邻 + 下邻）。
    - 左下象限的像素：L 形向右和向上延伸（即该像素 + 右邻 + 上邻）。
    - 右下象限的像素：L 形向左和向上延伸（即该像素 + 左邻 + 上邻）。
  - L 形印章使用该前景像素自身的颜色。保留十字准星和交叉点不变。
- `Key insight`：十字准星不仅是视觉装饰，它将网格划分为四个象限，每个象限决定了一种不同的印章方向。解题者需要先识别出准星的分区作用，再归纳出象限与 L 形朝向之间的对应关系。
</new_puzzle>

- `description`：将网格中的彩色种子像素沿其所在通道（由墙壁围成的走廊）扩散填充，填充长度由同色计数器区域中的像素数量决定。
- `Input structure`：
  - 背景为黑色。
  - 网格中有若干由 grey 像素构成的水平或垂直墙壁段，这些墙壁将网格分割成若干条直线通道（走廊），每条通道宽度为 1 格。
  - 每条通道中恰好有一个彩色"种子"像素（如 red、blue、green 等），位于通道的某个位置。
  - 网格的一个角落区域（如右下角）被 grey 边框围成若干小格子，每个小格子内填有若干同色像素，颜色与某个种子颜色相同，像素数量为 1 到 5 不等。这个角落区域是"计数器面板"。
- `Rule`：
  - 对每个种子像素，在计数器面板中找到与其同色的格子，数出该格子中的像素数量 N。
  - 从种子像素出发，沿通道方向（通道只有一个可延伸方向，或两个方向中种子靠近通道一端则向另一端延伸；若种子在通道中间，则向两端各延伸 N 格）填充 N 个同色像素。
  - 若种子位于通道的一个端点（紧邻墙壁），则向通道的另一端延伸 N 格。
  - 填充不可穿过墙壁或越出网格边界（若空间不足则填满为止）。
  - 保留墙壁、计数器面板和种子像素不变。
- `Key insight`：解题者需要发现两层规则——首先在计数器面板中建立"颜色→数量"的映射，然后将该数量应用为通道中的填充长度。计数器面板的存在和作用是第一层需要归纳的非显然规律，通道方向的选择是第二层推理。
</new_puzzle>

- `description`：识别网格中多个形状对象，根据每个对象边框上的缺口方向将对象内部的图案"倒出"到缺口外侧。
- `Input structure`：
  - 背景为黑色。
  - 网格中有若干矩形空心框，每个框用不同的颜色绘制（如 red、blue、green 等）。
  - 每个框的四条边中恰好有一条边上存在一个 1 像素宽的缺口（该边上有一个像素被替换为背景色）。
  - 每个框内部包含一个由另一种颜色绘制的小型图案（连通的像素块），该图案不触碰框的边缘。
- `Rule`：
  - 对每个矩形框，找到其边框上的缺口位置，确定缺口所在的边（上、下、左、右）。
  - 将框内部的图案整体沿缺口方向平移，直到图案完全离开框的范围，紧贴框的外侧。具体地：图案沿缺口方向移动的距离等于从图案在该方向上最近的边缘到框的该侧边框的距离再加上 1（即图案刚好完全在框外，紧邻框壁）。
  - 清除框内部原图案位置的像素。
  - 保留框本身（包括缺口）不变。
- `Key insight`：缺口不是损坏，而是方向指示器——它告诉解题者图案应该被"倒"向哪个方向。解题者需要先发现缺口与移动方向的对应关系，再计算出正确的平移距离使图案恰好移出框外。
</new_puzzle>

- `description`：根据参考色带中颜色的排列顺序，对网格中散落对象按面积排序后重新着色。
- `Input structure`：
  - 背景为黑色。
  - 网格的最上方一行（或最左一列）是一条"参考色带"：由若干种不同颜色依次排列组成的连续色块序列（如从左到右依次为 red、blue、green、yellow），每种颜色恰好占 1 个像素。
  - 网格其余区域散布着若干个单色连通对象（4-连通），每个对象用 grey 绘制，形状和面积各不相同。
- `Rule`：
  - 统计所有 grey 对象的面积（像素数量），按面积从小到大排序。
  - 将参考色带中的颜色按从左到右（或从上到下）的顺序依次分配给排序后的对象：面积最小的对象获得色带最左边的颜色，面积第二小的获得第二个颜色，依此类推。
  - 将每个对象的所有像素重新涂为分配到的颜色。
  - 若对象数量与色带长度不一致则不会出现——题目保证二者相等。
  - 保留色带本身不变。
- `Key insight`：参考色带不是装饰边框，而是一个有序的颜色分配表。解题者需要先发现对象按面积排序这一隐含规律，再将色带中的顺序映射到排序结果上——两步推理缺一不可。
</new_puzzle>

- `description`：将网格中每个带有箭头标记的色块沿箭头方向复制，复制次数由色块内部孔洞的数量决定。
- `Input structure`：
  - 背景为黑色。
  - 网格中有若干个彩色矩形填充块（如 red、blue、green），每个块的尺寸为 3×3 到 5×5 不等。
  - 部分块的内部含有 0 到 3 个"孔洞"——即内部被替换为背景色的像素。
  - 每个块的某一侧外部紧邻一个由同色绘制的箭头标记：箭头由 3 个像素组成，形成一个指向上、下、左或右的尖角形状。具体绘制方式为——若箭头指向右，则在块右侧外部的中间行放置一个像素，其上方一格和下方一格各放置一个像素偏左一列（即形成">"形状）；其他方向以此类推旋转。
- `Rule`：
  - 对每个色块，数出其内部孔洞的数量 N。
  - 沿箭头指向的方向，在块的外侧依次放置 N 个该色块的完整副本（不含孔洞，副本为实心填充），相邻副本之间间隔 1 行或 1 列的背景色。
  - 若 N=0，则不产生任何副本。
  - 清除原始箭头标记。保留原始色块（含孔洞）不变。
- `Key insight`：孔洞数量编码了复制次数，箭头编码了复制方向。解题者需要同时发现两个独立的编码机制并将它们组合：孔洞→次数，箭头→方向。副本是实心的这一细节增加了额外的辨识难度。
</new_puzzle>

<new_puzzle>
- `description`：在由彩色边框构成的嵌套矩形中，根据嵌套层数的奇偶性决定内部填充色，并将最内层矩形的颜色广播到所有同奇偶层。
- `Input structure`：
  - 背景为黑色。
  - 网格中有一组严格嵌套的空心矩形框（每个框由单一颜色绘制，框的颜色各不相同），从外到内依次编号为第 1 层、第 2 层、……、第 K 层（K ≥ 3）。
  - 所有矩形共享同一中心点。相邻两层矩形之间的间距（即走廊宽度）均为 1 格背景色。
  - 最内层（第 K 层）矩形内部为背景色。
- `Rule`：
  - 找到最内层矩形的边框颜色 C_inner。
  - 对每个走廊区域（第 i 层与第 i+1 层之间的环形带），若走廊编号（从外到内编号为 1, 2, ...）与最内层的层号 K 具有相同的奇偶性，则将该走廊填充为 C_inner。
  - 具有不同奇偶性的走廊保持为背景色。
  - 最内层矩形的内部也按照 K 的奇偶性处理：若 K 为奇数，则填充 C_inner；若 K 为偶数，则保持背景色。
  - 所有矩形边框保持原色不变。
- `Key insight`：解题者需要三步推理——首先识别嵌套结构并确定层数，其次发现最内层颜色是填充色的来源，最后归纳出奇偶交替的填充规律。最内层颜色的"广播"作用是最不直观的一步。
</new_puzzle>

<new_puzzle>
- `description`：将网格中的"信号源"像素沿连接线传播到"接收器"形状中，接收器根据连接线的转弯次数选择不同的内部填充模式。
- `Input structure`：
  - 背景为黑色。
  - 网格中有若干个空心矩形"接收器"，每个接收器由 grey 像素绘制，内部为背景色。
  - 网格中有若干个单独的彩色像素"信号源"（如 red、blue 等），每个信号源通过一条由 grey 像素构成的单像素宽折线路径连接到恰好一个接收器。
  - 每条连接线从信号源出发，经过若干次 90° 转弯后到达接收器的边框。连接线与接收器边框在某一点相接。
- `Rule`：
  - 对每个接收器，沿连接线追溯到其信号源，记录信号源的颜色 C 和连接线的转弯次数 T。
  - 根据 T 的值选择填充模式：
    - T = 0（直线连接）：用颜色 C 完全填充接收器内部。
    - T = 1（一次转弯）：用颜色 C 填充接收器内部的上半部分（按行数平分，奇数行时上半多一行）。
    - T = 2（两次转弯）：用颜色 C 仅填充接收器内部的四个角像素。
    - T ≥ 3：用颜色 C 仅填充接收器内部的中心像素（若内部为偶数尺寸则填充中心四格）。
  - 保留接收器边框、连接线和信号源不变。
- `Key insight`：连接线不仅传递颜色信息，其几何复杂度（转弯次数）还编码了填充模式。解题者需要同时追踪两个信息通道——颜色沿线传播是显然的，但转弯次数决定填充方式是需要从多个样例中归纳的隐蔽规律。
</new_puzzle>
