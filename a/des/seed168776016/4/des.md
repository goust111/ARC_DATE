- `description`：根据封闭框架内部小色块的颜色，从网格边缘对应方向向框架发射同色射线，射线穿过框架壁上的缺口后填充框架内部空腔。
- `Input structure`：
  - 背景为主色（如 black）。
  - 网格中有若干由单一颜色（如 grey）绘制的空心矩形框架，每个框架的四条边上恰好有一个单像素缺口。
  - 每个框架内部中心区域放置一个小的单色像素块（颜色各不相同，如 red、blue、green 等），该像素块不接触框架壁。
  - 框架外部无其他前景对象。
- `Rule`：
  - 对每个框架，找到其内部的彩色像素块，记录其颜色 C。
  - 找到该框架四条边上的唯一缺口，确定缺口所在的方向（上、下、左、右）。
  - 从网格对应边缘出发，沿缺口方向的反方向（即从边缘朝框架方向），用颜色 C 绘制一条宽度为1的射线，直到射线到达框架外壁为止。
  - 同时，射线穿过缺口进入框架内部，用颜色 C 填满框架内部从缺口延伸到对面内壁的整条直线。
  - 框架本身、内部原始像素块保持不变。
- `Key insight`：内部色块的颜色决定射线颜色，而缺口位置决定射线来源方向——解题者需要同时发现"颜色来自内部"和"方向来自缺口"这两层独立编码，缺一不可。
</new_puzzle>

- `description`：将散落的单色碎片识别为同一模板图案的旋转副本，根据每个碎片的旋转状态确定其朝向，然后在碎片指向的方向上复制一份该碎片的镜像翻转版本。
- `Input structure`：
  - 背景为主色（如 black）。
  - 网格中散布着若干由不同颜色绘制的小型前景对象（每个对象为4-6个像素的4-连通区域）。
  - 所有前景对象实际上是同一个不对称L形模板的旋转版本（0°、90°、180°、270°四种朝向之一）。
  - L形模板定义：在3x3的格子中，占据左上、左下、右下三个像素（形成一个朝右上方开口的L形）。其余旋转版本是该模板绕中心旋转得到的。
  - 每个对象之间有足够间距，不会重叠。
- `Rule`：
  - 对每个前景对象，识别其为L形模板的哪个旋转版本，从而确定其"开口方向"（即L形缺失角所指的方向）。
  - 在该对象的开口方向上，间隔1个像素的位置，放置该对象沿开口方向轴的镜像翻转副本，使用相同颜色。
  - 原始对象保持不变。
  - 如果镜像副本会超出网格边界，则不放置该副本。
- `Key insight`：解题者首先需要发现所有对象都是同一模板的旋转变体（需要心理旋转来验证），然后需要发现开口方向决定了副本的放置方向，最后还要发现副本是镜像而非简单平移——这三层认知构成了递进的推理链。
</new_puzzle>

- `description`：在由彩色边界划分的区域网格中，每个区域内部有一个标记点，根据标记点在区域内的相对位置（偏左/偏右/偏上/偏下）决定该区域向哪个相邻区域"传递"自己的颜色，最终每个区域被重新染成传递链上游区域的边界颜色。
- `Input structure`：
  - 背景为主色（如 black）。
  - 网格被若干条水平和垂直的彩色直线分割成矩形区域（类似格子窗），每条分割线有自己的颜色（如 red、blue、green 等），不同分割线颜色可能不同。
  - 每个矩形区域内部恰好有一个 grey 像素作为标记点，标记点不在区域的正中心，而是明显偏向区域的某一侧（上、下、左或右）。
  - 区域内部除标记点外全为背景色。
- `Rule`：
  - 对每个区域，判断 grey 标记点偏向哪一侧（将区域分成上下左右四个象限，标记点落在哪个象限即为偏向方向）。

  - 用接收到的颜色填充整个区域内部（覆盖背景色和 grey 标记点），但保持所有边界线不变。
- `Key insight`：标记点的偏移方向是一个视觉上微妙但确定的信号——解题者需要先发现"标记点不在中心"这个事实，再发现偏移方向与选择哪条边界线之间的对应关系，而非简单地按照距离最近的边界来决定。
</new_puzzle>

- `description`：识别网格中由不同颜色绘制的"管道"路径，在每条管道的两个端点之间，根据管道经过的转弯次数，在输出中用对应数量的点标记在一个独立的计数面板上。
- `Input structure`：
  - 背景为主色（如 black）。
  - 网格分为左右两个区域，由一条垂直的 grey 分隔线隔开。
  - 左侧区域包含若干条不同颜色的"管道"：每条管道是一条宽度为1像素的连续路径（4-连通），只沿水平或垂直方向延伸，在需要改变方向时产生90度转弯。每条管道颜色唯一，路径两端为自由端点（即只有一个4-连通邻居的像素）。
  - 右侧区域初始为空（全为背景色），高度与左侧相同，宽度足够容纳计数结果。
- `Rule`：
  - 对左侧每条彩色管道，数出其路径中90度转弯的次数（直线段之间的方向变化点）。
  - 在右侧区域中，为每条管道分配一行（按管道在左侧区域中从上到下首次出现的顺序排列）。
  - 在该行中，从左到右用该管道的颜色绘制与转弯次数相等数量的像素点，像素点之间间隔1个背景色像素。
  - 左侧区域和分隔线保持不变。
- `Key insight`：解题者需要两步非显然推理：第一步是发现右侧的点数与左侧管道的某个属性对应（而非长度、端点位置等其他候选属性）；第二步是确认该属性恰好是"转弯次数"而非"线段数"或"总长度"——这两个相近的候选量需要通过多个样例才能区分。
</new_puzzle>

- `Input structure`：
  - 背景为主色（如 black）。
  - 网格中有若干个由 grey 像素绘制的实心矩形"框架"（空心矩形，内部为背景色）。
  - 每个框架的某一条边上有一段连续的彩色像素覆盖在 grey 边框之上，形成一个"锁"标记（例如框架顶边中间3个像素被染成 red）。
  - 在框架外部的网格空间中，散布着与锁颜色相同的小型"钥匙"对象：每个钥匙是一个由该颜色绘制的小型连通图案（如T形、L形等），每种颜色的钥匙恰好只有一个。
  - 每个框架内部隐藏着一个用某种颜色绘制的小图案，但该图案被框架内部的一个与锁同色的实心矩形色块完全遮盖（色块覆盖了图案所在的区域）。
- `Rule`：
  - 将每个框架的锁颜色与对应颜色的钥匙配对。
  - 钥匙的形状决定了移除遮盖色块的方式：将钥匙图案（保持方向不变）对齐到框架内部遮盖色块的左上角，钥匙图案覆盖的像素位置上的遮盖色块被移除（变为背景色），从而露出下方的隐藏图案。
  - 钥匙图案未覆盖的遮盖色块像素保持不变（仍然遮挡部分隐藏图案）。
  - 框架外部的钥匙对象从网格中擦除（变为背景色）。
  - 框架本身、锁标记、未被钥匙解锁的部分保持不变。
- `Key insight`：解题者需要发现三层结构：首先通过颜色匹配建立锁-钥匙配对关系；然后理解钥匙的形状是一个"蒙版"而非装饰；最后发现钥匙蒙版对齐到遮盖块左上角来决定哪些像素被揭示——形状匹配与空间对齐的结合构成了核心难点。
</new_puzzle>

- `Input structure`：
  - 背景为主色（如 black）。
  - 网格顶部有一行"图例区"：由若干个小方块组成，每个小方块内部有一个独特的小型镂空图案（孔洞形状），小方块的边框颜色各不相同（如 red、blue、green 等）。图例小方块之间用背景色间隔。

<new_puzzle>
- `description`：在包含多个嵌套矩形框的网格中，根据每层框的颜色在一个色环序列中的位置关系，决定该层框内部的内容是保留还是擦除。
- `Input structure`：
  - 背景为主色（如 black）。
  - 网格左上角有一个小型"色环图例"：由若干彩色像素排成一行，定义了一个颜色的循环顺序（例如 red → blue → green → yellow → red ...）。
  - 网格主区域中有一个由多层同心空心矩形框嵌套而成的结构，从外到内每层框使用不同颜色，颜色均来自色环图例。
  - 最内层框的内部有一个由某种颜色绘制的小型图案。
- `Rule`：
  - 读取色环图例，确定颜色的循环顺序。
  - 从最外层框开始，检查每层框的颜色是否按照色环顺序递进（即下一层是否是色环中的下一个颜色）。
  - 如果某层框的颜色与前一层在色环中相邻（顺序正确），则该层框保留。
  - 如果某层框的颜色与前一层在色环中不相邻（顺序中断），则擦除该层框及其所有内部内容（变为背景色）。
  - 色环图例在输出中被移除（变为背景色）。
- `Key insight`：解题者首先需要发现左上角的色带是一个定义顺序的图例而非装饰；然后需要理解嵌套框的颜色序列必须与色环顺序一致；最后关键在于"一旦断链则擦除该层及以内所有内容"的级联效应——这不是逐层独立判断，而是一个链式验证过程。
</new_puzzle>

<new_puzzle>
- `description`：将网格中每个由围墙封闭的房间内的彩色种子像素进行"生长"，生长方向由房间墙壁上的门洞位置决定，种子沿门洞的反方向填满房间。
- `Input structure`：
  - 背景为主色（如 black）。
  - 网格中有若干个由 grey 像素围成的封闭矩形"房间"，房间内部为背景色。
  - 每个房间的墙壁上恰好有一个单像素宽的缺口（"门洞"），门洞位置在四面墙的某一面上。
  - 每个房间内部恰好有一个非背景色、非 grey 的彩色种子像素，种子像素紧贴房间的某一面内壁。
- `Rule`：
  - 对每个房间，确定门洞所在的方向（上、下、左、右）。
  - 从种子像素开始，用种子的颜色向门洞的对面方向（即远离门洞的方向）填充房间内部：具体地，填充从种子像素所在行/列开始，向门洞反方向扩展，直到碰到对面的墙壁为止，形成一个矩形色块。填充宽度等于房间内部的完整宽度（若门洞在上或下面）或完整高度（若门洞在左或右面）。
  - 门洞本身保持为背景色（不被填充）。
  - 房间墙壁和门洞不变，房间外部不变。
- `Key insight`：直觉上种子可能会"朝门洞方向生长"，但实际规则恰恰相反——生长方向背离门洞。解题者需要通过多个样例才能排除"朝门洞生长"这个强干扰假设，发现真正的反方向规则。同时，填充范围不是简单的射线，而是占满房间宽度/高度的矩形色块，这也需要从样例中归纳。
</new_puzzle>
