- `description`：将每个封闭区域内部散落像素的颜色频率编码为该区域围墙的边框厚度变化。
- `Input structure`：背景为 black。网格中有若干由 grey 像素围成的矩形封闭区域（围墙厚度初始为 1 像素）。每个区域内部散布着若干不同颜色的单像素标记（2-4 种颜色，每种出现 1-3 次）。不同区域内部的颜色集合可能不同。
- `Rule`：
  - 对每个封闭区域，统计内部每种标记颜色的像素数量。
  - 找到出现次数最多的颜色（唯一最多），记为 C，其出现次数为 N。
  - 清除区域内部所有标记像素为背景色。
  - 将该区域的围墙从 1 像素厚扩展为 N 像素厚（向内扩展，用 C 颜色绘制新增的内层围墙像素，原始 grey 外层保持不变）。
  - 扩展后围墙内部剩余的空间保持为背景色。
- `Key insight`：内部散点不是要保留的内容——它们的颜色频率被"编译"成围墙的视觉属性（厚度和内层颜色）。解题者需要发现"最多色→内层颜色"和"出现次数→厚度"两个编码规则。
</new_puzzle>

- `description`：根据网格中多个同构精灵之间的唯一差异像素位置，将这些差异像素的颜色提取出来组成一个压缩输出。
- `Input structure`：背景为 black。网格中有若干相同尺寸和形状的矩形区域（通过固定间距排列，互不重叠）。每个区域内有一个多色精灵图案，这些精灵在大部分像素上颜色相同，但每个精灵恰好有一个像素与其他所有精灵在该位置的颜色不同——即每个精灵都有一个"特异像素"。
- `Rule`：
  - 对每个精灵内部坐标位置，比较所有精灵在该位置的颜色。
  - 找到每个精灵中的特异像素（该位置的颜色与多数精灵不同的那个像素）。
  - 输出一个 1 行 N 列的网格（N = 精灵数量），按精灵从左到右的排列顺序，每列填入对应精灵特异像素的颜色。
- `Key insight`：精灵之间的冗余信息提供了"正常基线"——特异像素是通过与其他精灵对比发现的异常值。解题者需要发现"跨精灵对比→提取差异"的推理模式。
</new_puzzle>

<new_puzzle>
- `description`：将每个精灵按其边界上的彩色标记段数量分组，然后将同组精灵合并为一个叠加图案。
- `Input structure`：背景为 azure。网格中有若干分离的 4 连通前景精灵（面积 5-15 像素），每个精灵主要由一种颜色绘制，但其边界像素中有 0-3 个被替换为不同的标记颜色（每个标记恰好一个像素，分布在精灵的外边界上）。
- `Rule`：
  - 对每个精灵，数其边界上的彩色标记像素数量 N（0-3）。
  - 将标记数量相同的精灵分为一组。
  - 对每组精灵，将所有精灵的形状以 bounding box 中心对齐后叠加（取像素级并集），叠加时使用每个精灵的主体颜色。若重叠位置颜色冲突，保留后叠加的精灵颜色（按精灵在输入中从左到右的顺序）。
  - 输出一个新网格，将各组的叠加图案从左到右排列，按标记数量从少到多排序，组之间间隔一列背景色。
- `Key insight`：标记数量是分组键——解题者需要先发现"数边界标记"的分组规则，然后理解同组精灵通过中心对齐进行叠加合并。
</new_puzzle>

- `description`：根据输入中每个矩形对象的颜色在颜色图例中的位置，将对象按图例顺序重新排列为嵌套的同心矩形。
- `Input structure`：背景为 black。网格中散布着若干不同颜色的分离实心矩形对象（面积各不相同）。网格的底部有一行颜色图例：从左到右列出若干颜色像素，每个颜色恰好对应网格中一个矩形对象的颜色。
- `Rule`：
  - 从图例中读取颜色的从左到右顺序。
  - 将所有矩形对象按图例顺序排列。图例中最左的颜色对应的矩形放在最外层。
  - 输出一个新网格，将矩形按图例顺序绘制为同心矩形（最外层矩形保持原始尺寸，每个内层矩形居中放置在上一层内部，保持原始尺寸）。
  - 若内层矩形大于外层可用空间，则裁剪为可用空间大小。
  - 图例行从输出中移除。
- `Key insight`：图例的颜色顺序不是排序键而是嵌套层级——最左=最外，最右=最内。解题者需要发现图例编码的是"由外到内的嵌套顺序"而非简单的排列顺序。
</new_puzzle>

<new_puzzle>
- `description`：将每个面板中所有同色对象的 bounding box 合并为一个矩形，然后根据合并矩形是否为正方形决定该颜色在输出中的表示方式。
- `Input structure`：背景为 black。网格由全高 grey 分隔列分成若干面板。每个面板中有若干不同颜色的 4 连通前景像素组（每种颜色可能由多个分离的小对象组成，散布在面板内）。
- `Rule`：
  - 对每个面板中的每种颜色，将该颜色所有像素的位置合并，计算合并后的 bounding box。
  - 若合并 bounding box 是正方形（宽=高），则将该 bounding box 完全填充为该颜色。
  - 若合并 bounding box 不是正方形，则仅保留原始像素不变（不扩展）。
  - 面板中不属于任何正方形 bounding box 扩展区域的背景像素保持不变。
  - 扩展在同一面板内完成，分隔列保持不变。
- `Key insight`：正方形的 bounding box 触发扩展填充，而非正方形的则保持散布——解题者需要发现"bounding box 的宽高比"是决定变换方式的关键属性。
</new_puzzle>
