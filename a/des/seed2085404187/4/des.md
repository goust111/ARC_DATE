<new_puzzle>
根据色块内部孔洞的形状，在配对色块之间的连线上绘制对应的缩放图案。

Input structure:
- bg = black。网格中散布若干成对的同色矩形色块（每种非背景色恰好出现两个矩形）。
- 每个矩形色块内部挖有若干背景色孔洞，孔洞组成一个小型图案（例如 L 形、T 形、十字形等），图案完全包含在矩形内部。
- 同色的两个矩形严格位于同一行带或同一列带上（即它们的行范围或列范围有重叠），两者之间隔有一段背景色空隙。

Rule:
- 对每对同色矩形，提取两个矩形内部的孔洞图案。两个孔洞图案形状相同但大小可能不同。
- 取较小矩形中的孔洞图案作为"印章"形状。
- 取较大矩形中的孔洞像素数量 N 作为缩放因子：将印章形状中每个像素放大为 N×N 的方块。
- 用该矩形对的颜色，在两个矩形之间的空隙区域的正中央位置绘制放大后的图案。放大图案的中心与空隙区域的中心对齐。
- 两个原始矩形保持不变（包括其中的孔洞）。

Key insight: 孔洞既编码了要绘制的形状，又通过数量编码了缩放因子——解题者需要分别从两个配对色块中提取不同的信息（形状 vs 数量），而非简单复制。
</new_puzzle>

<new_puzzle>
根据边框上的彩色标记确定裁剪窗口，然后按窗口内对象的层叠顺序重新排列为分离的切片。

Input structure:
- bg = black。网格中央有一个较大的矩形区域，内部包含若干不同颜色的矩形对象，这些对象可以互相重叠（后绘制的覆盖先绘制的）。
- 网格的上边框和左边框各有若干单像素彩色标记。上边框的标记确定列坐标，左边框的标记确定行坐标。
- 每个标记颜色在上边框和左边框各出现恰好一次，形成一对(行, 列)坐标。
- 在中央区域的右下角有一个小的 grey 方块（例如 2x2），其尺寸 S 定义裁剪窗口大小为 S x S。

Rule:
- 对每种标记颜色，根据其在上边框和左边框的位置确定裁剪窗口的左上角坐标（左边框行号, 上边框列号），裁剪出中央区域中的一个 S x S 窗口。
- 在每个裁剪窗口内，分析重叠对象的层叠关系：被部分遮挡的对象在下层，完全可见的在上层。
- 输出网格将所有窗口水平排列（间隔一列 grey 分隔线），窗口内从左到右按标记颜色在上边框中从左到右的出现顺序排列。
- 在每个窗口切片内部，将重叠的像素拆解：最上层对象保持原位，被遮挡的下层对象的被覆盖部分用该对象自身的颜色恢复（即去除遮挡，还原完整形状），然后将各层从上到下依次垂直堆叠在该窗口切片中，层与层之间用一行 grey 像素分隔。

Key insight: 解题者需要先通过边框标记与方块尺寸推断出裁剪坐标系统（第一层推理），然后在每个裁剪窗口内识别出部分遮挡关系并将重叠对象还原拆分为独立层（第二层推理）。
</new_puzzle>

<new_puzzle>
用散落的彩色碎片拼合还原被遮罩擦除的区域，碎片的放置位置由其边缘轮廓与遮罩边界的吻合度决定。

Input structure:
- bg = black。网格中有一个大型多色图案（由多种颜色像素组成的复杂形状），其中一块连通的矩形区域被 grey 像素完全覆盖（遮罩区域），表示该部分图案被擦除。
- 网格的边缘区域（远离大型图案的位置）散布若干小型彩色碎片。每个碎片是一个连通的多色像素块，碎片之间互不接触。
- 恰好有一个碎片的形状和颜色能完美填入遮罩区域——即碎片的外形与遮罩区域的形状完全一致，且碎片边缘处的颜色与遮罩区域边界相邻的大型图案像素颜色一致。
- 其余碎片是干扰项：它们的形状可能与遮罩区域相同，但边缘颜色不匹配；或者边缘颜色看似匹配，但形状不同。

Rule:
- 识别 grey 遮罩区域的矩形范围。
- 检查大型图案中与遮罩区域四周直接相邻的像素颜色，形成一个"边界颜色签名"。
- 对每个散落碎片，检查其外形是否与遮罩区域形状一致，并且碎片边缘像素与边界颜色签名是否匹配。
- 将唯一匹配的碎片平移到遮罩区域的位置，替换掉所有 grey 像素。
- 其余碎片从网格中移除（变为背景色）。

Key insight: 形状匹配是必要条件但不充分——解题者必须同时验证碎片边缘颜色与周围图案的连续性，这要求对"上下文一致性"的推理，而非仅凭几何形状。
</new_puzzle>

<new_puzzle>
将网格中的多色环形结构按嵌套层级拆解，每层环的颜色决定其在输出拼贴中的排列位置和朝向。

Input structure:
- bg = black。网格中包含若干独立的"靶标"结构，每个靶标由多层同心矩形环嵌套构成（类似靶心），从外到内每层环颜色不同。
- 每个靶标的最外层环上恰好有一个单像素缺口（缺口为背景色），缺口位于上、下、左、右四条边之一。
- 网格底部有一行"调色板行"：由若干颜色像素组成的水平序列（每个像素颜色不同，之间无间隔），排列顺序从左到右。

Rule:
- 对每个靶标，从外到内逐层剥离矩形环，记录每层环的颜色及其在调色板行中的位置索引（从左数第几个）。
- 最外层环的缺口方向决定该靶标的"基准朝向"。
- 输出网格为单行或多行排列的拆解结果：每个靶标拆解为从外到内的各层环，各层环单独绘制为独立的矩形环（保持原始尺寸），按调色板行中的颜色顺序从左到右排列，环与环之间间隔一列背景色。
- 每个独立绘制的环都要旋转，使得原始最外层缺口统一朝上。若原始缺口在右侧，则整个靶标的所有层环逆时针旋转 90 度；若在下方，旋转 180 度；若在左侧，顺时针旋转 90 度；若已在上方则不旋转。
- 若有多个靶标，各靶标的拆解结果上下排列，靶标之间间隔一行背景色。靶标的上下排列顺序与其最外层颜色在调色板行中的位置索引一致（索引小的在上）。

Key insight: 解题者需要完成三层推理：（1）识别同心环结构并逐层剥离，（2）通过缺口方向确定旋转变换使朝向归一化，（3）利用调色板行的颜色顺序同时控制水平排列次序和垂直靶标次序——调色板既是排序键又是结构解码器。
</new_puzzle>

<new_puzzle>
根据种子像素的颜色在对应颜色的框架内生长分支结构，树的分支方向由框架边缘缺口决定，分支末端形态由角落图例定义。

Input structure:
- bg = black。网格中有若干不同颜色的矩形空心框架（框架壁厚一像素），框架之间不重叠、不接触。
- 每个框架的内部为背景色（空心），框架某些边上有单像素宽的缺口（缺口为背景色）。每个框架至少有 1 个缺口，最多 4 个缺口（上下左右各最多一个）。
- 每个框架内部的正中央有一个与框架同色的单像素"种子"。
- 网格角落（例如左上角的 3x3 区域）有一个示例图例：一个微型框架内展示了从种子出发的生长规则样例——种子向每个缺口方向生长出一条单像素宽的直线，直线延伸到框架内壁停止，末端形成 T 形分叉。

Rule:
- 对每个框架，找到其边缘上所有缺口的方向（上、下、左、右）。
- 从种子像素出发，向每个缺口方向绘制一条与框架同色的直线，直线从种子延伸直到碰到该方向的框架内壁（不包括缺口本身的壁，而是框架内部空间的边界）。
- 每条直线的末端（到达框架内壁前一个像素），向该直线的两个垂直方向各延伸一个像素（形成 T 形末端），延伸像素不超出框架内部范围。
- 缺口本身保持为背景色不变（缺口不被填充）。

Key insight: 解题者需要从角落的图例中归纳出生长规则（第一层推理：种子向缺口方向延伸并在末端形成 T 形分支），然后将该规则应用于每个不同的框架，根据各框架独特的缺口组合生成对应的内部图案（第二层推理：缺口位置决定分支方向的组合）。
</new_puzzle>

<new_puzzle>
将网格中被切割线分隔的区块按照区块内标记像素指定的目标位置重新拼装，同时根据切割线颜色决定拼装时的旋转角度。

Input structure:
- bg = black。网格被若干水平和垂直的彩色单像素宽切割线分割为矩形区块（形成 2x2 的四个区块）。
- 切割线使用两种颜色：red 线和 blue 线。所有水平线颜色相同，所有垂直线颜色相同（例如水平线全为 red，垂直线全为 blue，或反过来）。
- 每个矩形区块内部包含一些彩色图案（非背景色、非切割线颜色的像素），以及恰好一个 grey 单像素标记。
- grey 标记在区块内部的相对位置（左上、右上、左下、右下四个象限之一）编码了该区块在输出中的目标位置象限。
- 区块的总数恰好等于 4（即网格被一条水平线和一条垂直线分为 2x2 的四个区块）。

Rule:
- 将四个区块按各自 grey 标记指示的象限重新排列到输出的 2x2 布局中（左上标记对应输出左上，右上标记对应输出右上，以此类推）。
- 移除所有 grey 标记像素（替换为背景色）。
- 如果分隔该区块的垂直切割线是 red 色，则该区块在放入目标位置前顺时针旋转 90 度。
- 如果分隔该区块的垂直切割线是 blue 色，则不旋转。
- 对于水平切割线：如果水平切割线是 red 色，则位于该线下方的区块上下翻转；如果是 blue 色，则不翻转。
- 旋转和翻转可以叠加：若一个区块同时受到 red 垂直线和 red 水平线的影响，则先旋转 90 度再上下翻转。
- 输出网格中区块之间无切割线，直接拼接。

Key insight: 解题者首先需要发现 grey 标记的相对位置编码了重排目标（第一层），然后需要发现切割线颜色与几何变换的对应关系——垂直 red 线触发旋转、水平 red 线触发翻转（第二层），最后理解变换可叠加（第三层）。
</new_puzzle>

<new_puzzle>
在网格中根据"染色规则模板"对各连通区域执行条件染色，模板本身需要通过比较多个样例中的公共结构来提取。

Input structure:
- bg = black。网格分为左右两个面板，由一列 grey 像素分隔。
- 左面板包含一个"规则模板区"：一个由 maroon 像素围成的矩形框，框内有若干小型彩色形状。每个小型形状由两种颜色组成——外轮廓色和内填充色。外轮廓色表示"条件色"（匹配目标区域的当前颜色），内填充色表示"目标色"（要变换成的颜色）。
- 右面板包含若干大型彩色连通区域（4-连通），每个区域是单色的。部分区域内部包含一个小的背景色方孔（正方形孔洞），部分区域没有方孔。

Rule:
- 从左面板的规则模板中提取所有颜色映射规则：每个小形状的外轮廓色 C1 映射到内填充色 C2，表示"颜色 C1 应被替换为 C2"。
- 对右面板中的每个连通区域：如果该区域内部包含方孔，则应用颜色映射——将该区域的颜色 C1 替换为规则模板中 C1 对应的 C2。
- 如果区域内部没有方孔，则保持原色不变。
- 输出仅包含右面板（去除左面板和 grey 分隔列），尺寸缩小为右面板大小。

Key insight: 解题者需要先从左面板的嵌套形状中解读出"轮廓色→填充色"的颜色映射表（第一层推理），然后发现方孔是触发颜色替换的开关——只有包含方孔的区域才被重新染色（第二层推理）。
</new_puzzle>
