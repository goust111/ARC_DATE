<description>
根据围栏内部种子像素的颜色，从颜色图例中查找对应的填充图案，将该图案平铺填入围栏区域。

Input structure:
- 背景色 bg 为网格中最常见的颜色。网格上散布若干由同一颜色构成的封闭围栏（单像素宽的矩形环），每个围栏内部（bg 区域）恰好包含一个非 bg 的单像素"种子"。
- 网格的一条边缘（例如底部两行）是颜色图例区：图例区被 grey 竖线分隔为若干小格，每个小格左上角有一个与某个种子颜色相同的单像素色块，其余部分绘有一个小型二色图案（由该种子颜色和 bg 组成的 2x2 或 3x3 重复单元）。

Rule:
- 对每个围栏，读取其内部种子像素的颜色 C。
- 在图例区中找到左上角色块颜色为 C 的那个小格，提取其中的重复单元图案 P。
- 将图案 P 以平铺方式填满围栏内部的所有 bg 像素（种子像素本身也被覆盖），平铺的起始对齐点为围栏内部区域的左上角。
- 围栏边框、图例区以及围栏外部的 bg 区域保持不变。

Key insight: 种子像素仅起"索引"作用——它的颜色指向图例中的某个平铺图案；解题者必须先建立种子颜色与图例小格的对应关系，再识别图例中的重复单元并正确平铺。
</description>
</new_puzzle>

<new_puzzle>
<description>
将散落的彩色碎片按照中央拼图板上的轮廓槽位放入，再根据槽位深度决定碎片的最终着色。

Input structure:
- 背景色 bg 为网格中最常见的颜色。网格中央有一个大型 maroon 色的"拼图板"，板上挖有若干形状各异的 bg 色凹槽（连通区域）。每个凹槽的边缘恰好有一个非 bg、非 maroon 的单像素"标签"色块，颜色各不相同。
- 拼图板外围散布着若干彩色碎片（连通的非 bg 像素块），每块碎片都是纯色，颜色与某个凹槽标签一致。
- 每个凹槽内部还嵌有零个或多个 grey 像素点，这些 grey 点的数量称为该凹槽的"深度值"。

Rule:
- 通过颜色匹配将每个碎片与对应标签颜色的凹槽配对。
- 碎片的形状在旋转 0/90/180/270 度后恰好能填满对应凹槽的 bg 区域（不含 grey 像素点的位置），将碎片平移到凹槽中。
- 碎片放入后，检查凹槽的深度值 D（grey 像素数量）：若 D 为奇数，碎片颜色变为 orange；若 D 为偶数（包括 0），碎片保持原色。
- Grey 像素点在输出中被碎片原色或变换色覆盖（它们只是计数标记）。

Key insight: 第一层推理是形状旋转匹配（碎片与凹槽），第二层推理是发现 grey 像素点数量的奇偶性决定了碎片是否变色——这需要跨多个样例对比才能归纳出来。
</description>
</new_puzzle>

<description>
在网格中找到由边框颜色编码的"传送门对"，将每个传送门入口侧的对象通过传送门搬运到出口侧的镜像位置。

Input structure:
- 背景色 bg 为网格中最常见的颜色。网格上有若干由单一颜色构成的竖直或水平细线段（长度大于等于 3），每种颜色恰好出现两条，构成"传送门对"。
- 每条传送门线段的一侧（称为"活跃侧"）紧邻一个或多个由其他颜色组成的小型图案（sprite），另一侧为空白 bg。两条同色传送门的活跃侧朝向相反。
- 每条传送门线段在其某一端有一个 yellow 像素标记，指示该传送门的"锚点"对齐端。

Rule:
- 将同色的两条传送门配对。对于每一对传送门 A 和 B：
  - 收集传送门 A 活跃侧的所有 sprite 像素，以 A 的 yellow 锚点为参考原点，计算每个像素相对于锚点的行列偏移。
  - 将这些像素以相同的偏移放置到传送门 B 的 yellow 锚点处，但沿传送门的垂直轴做镜像翻转（因为活跃侧朝向相反）。
  - 同理将 B 侧的 sprite 传送到 A 侧。
- 传送后，原位置的 sprite 被清除为 bg；传送门线段本身保留。

Key insight: 解题者需要先发现同色线段成对、再发现 yellow 锚点决定了对齐方式、最后发现传送是沿传送门轴镜像的——三层推理缺一不可。
</description>
</new_puzzle>

<new_puzzle>
<description>
根据网格中散落的"投影源"形状，沿指定方向投射阴影，阴影在遇到"反射墙"时改变方向继续延伸，最终形成折线阴影。

Input structure:
- 背景色 bg 为网格中最常见的颜色。网格中散布若干小型彩色形状（投影源），每个形状为 1 至 4 个像素的连通块，颜色各不相同。
- 每个投影源旁边紧邻一个 red 像素，位于投影源的上方、下方、左方或右方，指示该投影源的初始投射方向（从投影源朝 red 像素的相反方向投射）。
- 网格上还有若干条 grey 线段（水平或竖直），充当"反射墙"。

Rule:
- 对每个投影源，确定其初始投射方向 D（red 像素相对于投影源的反方向）。
- 从投影源的每个像素出发，沿方向 D 逐格绘制该投影源颜色的阴影像素。
- 当阴影射线碰到 grey 反射墙时，改变方向：碰到水平 grey 墙时上下翻转方向分量，碰到竖直 grey 墙时左右翻转方向分量。
- 阴影射线在碰到网格边界或另一个投影源实体时停止。
- 若多条阴影重叠，后绘制的覆盖先绘制的（绘制顺序按投影源在网格中从上到下、从左到右排列）。
- Red 像素和 grey 反射墙在输出中保留。

Key insight: 第一层推理是发现 red 像素方位决定投射方向（且方向是反方向，而非 red 像素所在方向）。第二层推理是发现 grey 墙会反射阴影使其拐弯继续延伸，形成折线路径。
</description>
</new_puzzle>

<description>
将网格中的多个"信号塔"根据其天线朝向向外广播，广播色带的宽度和颜色由塔身编码决定。

Input structure:
- 背景色 bg 为网格中最常见的颜色。网格中散布若干"信号塔"结构，每个信号塔由以下部分组成：
  - 一个竖直的单列"塔身"，由若干非 bg 色像素堆叠而成（至少 2 个像素），塔身中可能出现多种颜色，从上到下排列。
  - 塔身顶端或底端紧邻一个 azure 像素（"天线"），天线在塔身上方表示向上广播，在下方表示向下广播。
- 不同信号塔的塔身颜色序列和长度可各不相同。

Rule:
- 对每个信号塔，读取其天线位置确定广播方向（上或下）。
- 读取塔身的颜色序列（从远离天线端到天线端的顺序排列），得到颜色列表 [C1, C2, ..., Cn]，其中 n 为塔身像素数。
- 从天线位置出发，沿广播方向依次绘制 n 条水平色带：第 i 条色带的颜色为 Ci，宽度（水平像素数）等于 i 乘以 2 减 1（即 1, 3, 5, 7, ...），色带以塔身所在列为中心左右对称。
- 色带不覆盖已有的信号塔实体像素和其他塔的色带（先处理行号更小的塔）。
- 色带遇到网格边界时裁剪。

Key insight: 解题者需要从样例中发现三个非显然规律——天线位置决定广播方向、塔身颜色序列被反转映射为色带颜色顺序、色带宽度按奇数递增且与颜色在序列中的位置对应。
</description>
</new_puzzle>

<new_puzzle>
<description>
将封闭区域中的彩色像素沿区域边界的"出口缺口"方向推出，推出后的像素沿外部通道滑行直到被另一个区域捕获。

Input structure:
- 背景色 bg 为网格中最常见的颜色。网格中有若干由 maroon 色像素围成的封闭矩形区域，每个区域的边框上恰好有一个缺口（缺口为 1 像素宽的 bg 空隙）。
- 每个区域内部有若干彩色像素（非 bg、非 maroon），散布在 bg 底色上。
- 区域之间由 bg 通道相连（通道宽度为 1 像素）。某些区域内部没有彩色像素但有缺口，这些是"接收区域"。

Rule:
- 对每个包含彩色像素的区域，确定其缺口位置（上、下、左、右哪条边上）。
- 将区域内所有彩色像素视为一个整体刚性块，沿缺口方向平移，直到整个刚性块完全离开原区域。
- 离开后，刚性块继续沿同方向在 bg 通道中滑行。当刚性块的前缘碰到另一个 maroon 区域的缺口时，刚性块穿过缺口进入该接收区域，并在内部继续滑行直到碰到对面的 maroon 墙壁停止。
- 原区域内被清空为 bg。接收区域的缺口方向必须与来源区域的缺口方向在同一轴线上（但朝向相反）。

Key insight: 解题者首先要发现缺口位置决定了推出方向，然后要发现像素作为刚性整体移动（而非逐个移动），最后要发现接收区域是通过通道轴线对齐的缺口来匹配的。
</description>
</new_puzzle>

<new_puzzle>
<description>
在网格中根据"样本窗口"学习局部替换规则，然后在主区域中找到所有匹配的局部模式并执行相同的替换。

Input structure:
- 背景色 bg 为网格中最常见的颜色。网格被一条 green 色的分隔线（水平或竖直）分为两个区域：较小的"样本窗口"和较大的"主区域"。
- 样本窗口内有一个"替换前"子图案和一个"替换后"子图案，两者大小相同，水平排列，中间由一列 yellow 像素分隔。"替换前"图案包含若干非 bg 色像素排列成的小形状；"替换后"图案是同样位置的像素被修改后的结果（部分像素改变了颜色、部分保持不变）。
- 主区域中散布着多个与"替换前"图案在形状和颜色上完全相同的实例，可能处于不同的旋转状态（0/90/180/270 度）。

Rule:
- 从样本窗口中提取"替换前"图案和"替换后"图案，通过逐像素比较建立替换映射（哪些位置的颜色发生了变化、变成了什么颜色）。
- 在主区域中搜索所有与"替换前"图案匹配的实例（在四种旋转下均需检查）。
- 对每个找到的实例，将对应的替换映射（旋转到匹配的朝向后）应用到该实例上，修改相应像素的颜色。
- 未匹配的区域保持不变。

Key insight: 第一层推理是识别样本窗口中的"前后"对应关系；第二层推理是发现主区域中的实例可能经过旋转，需要将替换规则也相应旋转后才能正确应用。
</description>
</new_puzzle>
