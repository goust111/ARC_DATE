<description>
将散落的彩色碎片按形状匹配填入同心矩形框架的缺口中，填充颜色由碎片原色与框架环层级的奇偶性共同决定。

Input structure:
- 背景色（bg）为black。网格中有一个由多层同心矩形环组成的大型框架结构，每层环由不同颜色绘制，环之间留有一像素宽的black间隔。某些环存在缺口（连续的black段替代了该环颜色）。
- 框架外部散落着若干小型彩色碎片（连通分量），每个碎片的形状恰好与某个环上的某个缺口形状完全匹配（允许旋转和翻转）。
- 框架外部还有一个小型"排序图例"：一列纵向排列的单像素色块，从上到下排列了框架中所有环的颜色，顺序与环从外到内的顺序一致。

Rule:
- 首先通过排序图例确认环从外到内的颜色顺序，建立层级编号（从外到内依次为1、2、3……）。
- 对每个散落碎片，通过其形状（允许旋转和翻转）匹配到框架中唯一形状吻合的缺口位置。
- 碎片填入缺口时，默认将碎片重新着色为该缺口所在环的颜色。
- 但存在一个例外：如果碎片原始颜色恰好出现在排序图例中，且该颜色对应的环层级编号为奇数，则碎片填入后保留自身原始颜色而非环颜色。
- 所有碎片填充完毕后，移除框架外部的所有碎片和排序图例，只保留修补后的框架结构。

Key insight:
碎片与缺口的匹配依赖形状而非颜色，但最终填充颜色需要结合排序图例中的层级奇偶性来判断——解题者必须先建立环的层级映射，再根据奇偶规则决定是否保留碎片原色。
</description>

<description>
将多个残缺瓷砖的信息交叉拼合，恢复出每个瓷砖中被遮罩色破坏的像素。

Input structure:
- 网格由规则的 NxN 小格子（tile）紧密排列铺成，每个tile内部是一个相同尺寸的小图案（使用多种颜色）。
- 所有tile本应共享完全相同的内部图案，但部分tile中的某些像素被一种特殊的"遮罩色"（maroon）替换了。
- 没有任何一个tile是完全未被遮挡的——每个tile都至少缺失了一部分像素。
- 但对于图案中的每一个像素位置，至少存在一个tile在该位置未被遮挡。

Rule:
- 识别网格的tile划分方式（所有tile尺寸相同，紧密排列，tile之间无间隔）。
- 对于每个tile内部的每个像素位置，在所有tile中找到该位置未被maroon覆盖的那些tile，读取该位置的真实颜色（所有未遮挡tile在该位置颜色一致）。
- 用收集到的完整图案替换每个tile中的maroon像素，使所有tile恢复为相同的完整图案。
- 输出网格尺寸与输入相同。

Key insight:
没有任何单个tile能提供完整图案，解题者必须意识到所有tile是同一图案的不同"残缺视图"，需要跨tile交叉引用同一像素位置来重建完整图案——这是一种分布式信息恢复而非简单的对称性补全。
</description>

<description>
根据封闭区域内种子像素的计数，从梯度条中查表获取对应颜色，填充整个区域。

Input structure:
- 背景色（bg）为black。网格中有由grey线段构成的不规则网格状结构，将空间划分为若干封闭区域（每个区域由grey边界完全围合）。
- 每个封闭区域内散布着若干"种子像素"，所有种子像素为同一颜色（blue）。不同区域内的种子像素数量不同（范围1到5）。
- 网格的左上角有一个1行5列的"梯度条"，紧贴网格顶部和左侧边缘，由5种不同颜色从左到右排列（例如：red, orange, yellow, green, azure），第1格代表数量1，第5格代表数量5。梯度条本身不被grey边界包围，独立存在于角落。

Rule:
- 识别grey边界划分出的所有封闭区域。
- 数出每个封闭区域内blue种子像素的个数 K（K 在 1-5 之间）。
- 从梯度条中取第 K 个颜色（从左数第 K 格），用该颜色填充整个封闭区域内所有black像素。
- 将该区域内的blue种子像素全部变为black。
- grey边界和梯度条本身保持不变。

Key insight:
解题者需要完成两层推理：第一层是识别梯度条作为"数量到颜色"的映射表（而非装饰），第二层是在每个不规则区域内准确计数种子像素并查表填色——梯度条的存在使得颜色选择不是任意的而是确定性的。
</description>

<description>
将空间上嵌套包含的多个矩形提取出来，按嵌套树的前序遍历展开为水平序列，并用垂直偏移编码嵌套深度。

Input structure:
- 背景色（bg）为black。网格中有若干不同颜色的实心矩形，它们存在空间嵌套关系：较小的矩形完全位于较大矩形的内部，形成多层嵌套（最多4层）。
- 每个矩形的颜色唯一，不存在两个同色矩形。
- 最外层矩形可能有多个（即存在多棵嵌套树）。在输入中，不同的嵌套树在水平方向上不重叠。

Rule:
- 解析所有矩形的包含关系，构建嵌套树。一个矩形A直接包含另一个矩形B，当且仅当B的边界框完全在A内部，且不存在第三个矩形C使得B在C内部且C在A内部。
- 对嵌套树进行前序遍历：先父后子，同一父节点下的子节点按其在输入中的左上角列坐标从小到大排列。多棵树之间按根节点的左上角列坐标从小到大排列。
- 输出网格高度与输入相同。按遍历顺序从左到右放置每个矩形，矩形之间留1列black间隔。
- 每个矩形的垂直位置由其嵌套深度决定：深度0（最外层）顶部对齐第0行，深度1顶部对齐第2行，深度D顶部对齐第2D行。
- 放置时只绘制矩形本身（实心填充其颜色），不绘制其内部曾经包含的子矩形（即每个矩形在输出中是纯色填充）。

Key insight:
输入中的空间嵌套关系（谁在谁里面）是隐含的树结构，解题者需要先从视觉重叠中提取出这棵树，然后理解输出是这棵树的前序遍历展开——空间包含关系被转换为线性排列顺序加垂直深度编码。
</description>

<description>
根据网格边缘发射器发出的光线在内部镜面方块上的反射路径，为光线经过的空白格着色，交叉处混合为特殊颜色。

Input structure:
- 背景色（bg）为black。网格边缘（最外一圈像素）上有若干单像素的"发射器"，每个发射器颜色不同（如red、blue、green等）。发射器所在的边决定了光线初始方向：顶边发射器向下发射，底边向上，左边向右，右边向左。
- 网格内部散布着若干2x2的grey方块，作为"镜面"。每个镜面方块的四个像素中恰好有一个像素为yellow，其余三个为grey。yellow像素在2x2方块内的位置编码了镜面的朝向：左上或右下位置表示"\"方向镜面，右上或左下位置表示"/"方向镜面。
- 网格内部还可能有若干maroon单像素作为"吸收器"。

Rule:
- 从每个发射器出发，沿初始方向逐格前进，光线经过的每个black格被染为该发射器的颜色。
- 当光线的下一步将进入镜面方块的任意一格时，根据镜面朝向反射：对"\"镜面，向下变向右、向右变向下、向上变向左、向左变向上；对"/"镜面，向下变向左、向左变向下、向上变向右、向右变向上。光线不进入镜面方块，从接触面沿反射方向继续前进。
- 光线遇到maroon吸收器则终止；到达网格边界也终止。
- 如果两条不同颜色的光线经过同一格，该格颜色变为yellow。
- 镜面方块、吸收器和发射器本身在输出中保持不变。

Key insight:
解题者需要完成三层推理：第一层是理解发射器位置与初始光线方向的对应关系；第二层是从2x2镜面中yellow像素的位置解码出镜面朝向并正确计算反射方向；第三层是处理多条光线交叉时的颜色混合规则。镜面朝向的编码方式是本题最隐蔽的机制。
</description>

<description>
通过颜色标记将外部碎片与模板内空槽配对，再通过旋转使碎片形状与空槽吻合后填入。

Input structure:
- 背景色（bg）为black。网格中央有一个大型grey实心矩形（模板），模板内部挖出了若干L形空槽（black区域），每个空槽由3个相连像素组成L形，不同空槽的L形朝向可能不同。
- 模板的四条外边缘上各有若干单像素彩色标记，紧贴模板外侧。每种标记颜色在整个边缘上恰好出现一次。每个标记在正交方向上紧邻模板内部的某个空槽（标记与空槽之间仅隔一个grey像素，即模板边缘）。
- 模板外部散布着若干彩色L形碎片，每个碎片由3个同色像素组成L形连通分量，碎片颜色各不相同，且每种碎片颜色与某个边缘标记颜色一一对应。

Rule:
- 通过颜色匹配将碎片与边缘标记配对：碎片颜色等于标记颜色。
- 每个标记指向其正交方向上紧邻的那个空槽（即从标记出发穿过模板边缘后遇到的第一个空槽），碎片应填入该空槽。
- 碎片可能需要旋转（0度、90度、180度、270度）才能与空槽形状吻合。找到唯一匹配的旋转角度后，将碎片像素放入空槽对应位置。
- 填入后碎片保持其原始颜色。
- 移除模板外的所有碎片，边缘标记保留。

Key insight:
解题者需要先建立"颜色配对 -> 标记定位 -> 空槽识别"的对应链条，再通过旋转匹配确定碎片摆放方式——配对关系和几何匹配是两个独立的推理步骤，缺一不可。
</description>

<description>
识别被十字线分割的四个象限中哪个象限的周期图案被破坏，然后利用幸存像素推断底层图案并修复被篡改的像素。

Input structure:
- 网格被azure色的十字线（一条水平线和一条垂直线贯穿整个网格）分为四个象限。
- 每个象限内填充着一种2x2的重复瓷砖图案（四个象限使用四种不同的2x2图案，每种图案由两种颜色交替组成，按2x2周期平铺）。
- 其中恰好一个象限内的图案存在若干像素被"篡改"——该象限内有若干像素的颜色被替换为maroon，而maroon不出现在任何象限的正常2x2图案中。

Rule:
- 识别四个象限中哪一个包含maroon像素——该象限即为"异常象限"。
- 根据异常象限中未被篡改的像素（非maroon像素）推断该象限的2x2重复图案：检查这些像素在2x2周期中的行列奇偶位置，归纳出该象限的完整2x2瓷砖。
- 将异常象限中所有maroon像素替换为该位置在2x2重复图案中应有的颜色。
- 其余三个象限和azure十字线保持不变。输出网格尺寸与输入相同。

Key insight:
解题者必须先通过maroon颜色的唯一性定位异常象限（第一层），然后从该象限的"幸存"像素中逆向推导出底层的2x2周期图案（第二层）——关键在于理解maroon不属于任何正常图案，它是破坏标记而非图案元素。
</description>
</new_puzzle>
