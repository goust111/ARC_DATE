<description>
根据封闭区域内部"种子"色块的形状朝向，选择匹配的边框颜色图例，再用图例指定的填充色涂满该区域的空白部分。

Input structure:
- 背景色（bg）为 black。网格中散布着若干由 grey 线条围成的封闭矩形区域，每个区域内部包含一个由单一非背景、非 grey 颜色构成的小型"种子"形状（如 L 形、T 形、线段等），种子形状的朝向各不相同（上下左右四种旋转之一）。
- 网格底部有一行水平排列的"图例单元格"：每个图例单元格是一个小矩形，左半部分绘有一个固定朝向（朝上）的种子形状模板（颜色与某个封闭区域内的种子颜色相同），右半部分填充了一种"填充色"（与种子颜色不同）。

Rule:
- 第一层推理——朝向匹配：对每个封闭区域，识别其内部种子形状的颜色，在图例中找到相同颜色的模板。图例模板统一朝上；解题者需判断区域内种子相对于模板旋转了几个 90°（0°/90°/180°/270°）。
- 第二层推理——填充色分配：旋转量决定填充色的来源。网格右上角有一个 2×2 的"旋转-颜色"查找表：四个格子分别标注 0°/90°/180°/270° 对应的"修饰色"（用四种不同颜色表示，格子按顺时针从左上角 = 0° 排列）。将修饰色与图例中该种子对应的填充色组合使用：先用填充色填满区域空白，再用修饰色在填充区域的四角各画一个单像素标记。
- 种子形状本身保留不变，grey 边框保留不变。

Key insight:
解题者必须先通过旋转比对确定每个种子的朝向偏移量，再利用偏移量从查找表获取修饰色——两步推理缺一不可，仅靠颜色或形状无法直接得出答案。
</description>

<description>
将网格中散落的彩色碎片按"拼接规则"组装成完整矩形，其中每块碎片的缺口方向指示了它在矩形中的位置。

Input structure:
- 背景色（bg）为 black。网格中散布着若干彩色碎片，每块碎片是一个近似矩形但有一条边带有凹槽缺口的形状（缺口为背景色侵入碎片的一个矩形凹陷）。
- 每块碎片使用同一种颜色，但不同碎片颜色不同。
- 网格右侧有一个由 grey 线条画出的空心目标矩形框架，尺寸恰好等于所有碎片无缝拼合后的大小。目标框架内部有若干 grey 的内部分割线，将框架分成与碎片数量相同的子区域。

Rule:
- 第一层推理——缺口配对：每块碎片恰好有一个凹槽缺口，而另一块碎片在对应位置恰好有一个凸起突出（即该碎片在那个方向上比矩形多出一小块）。凹槽与凸起的尺寸完全吻合，形成唯一的配对关系。解题者需要识别哪些碎片互为邻居。
- 第二层推理——空间排布：根据配对关系和碎片的缺口朝向（上/下/左/右），确定每块碎片在目标矩形中的相对位置。缺口朝右的碎片，其右侧邻居就是拥有匹配凸起的碎片。将所有碎片平移到目标框架中对应的子区域内，碎片颜色保留不变。
- 碎片之间的拼接处（凹凸交界）在输出中用碎片各自的颜色填充（凸起部分覆盖凹陷部分），grey 框架线保留。

Key insight:
碎片的形状不仅是装饰——凹凸缺口编码了邻接关系和方向信息。解题者必须先通过缺口形状配对找到邻居，再根据缺口方向推断空间布局，两步推理串联才能完成拼图。
</description>

<new_puzzle>
<description>
利用网格中"传送门"像素对的颜色对应关系，将路径从一个区域跳转到另一个区域继续延伸，最终生成跨区域的连续折线。

Input structure:
- 背景色（bg）为 black。网格被 grey 的水平线和垂直线分割成若干矩形子区域（类似九宫格但数量不固定）。
- 每个子区域内有一条由某种颜色画出的单像素宽折线段（水平或垂直线段的组合），折线的一端或两端终止于子区域边界处的一个特殊"传送门"像素。传送门像素的颜色与折线颜色不同，且成对出现：整个网格中每种传送门颜色恰好出现两次，分别位于不同子区域的边界上。
- 部分子区域内的折线两端都有传送门（即该区域是"中转站"），部分只有一端有传送门（即该区域是起点或终点）。

Rule:
- 第一层推理——传送配对：找到所有传送门像素，按颜色配对。同色的两个传送门构成一对，表示路径从一个传送门跳到另一个传送门继续延伸。
- 第二层推理——路径方向推断：每条折线段到达传送门时有一个行进方向（水平或垂直）。路径跳转到配对传送门后，必须从该传送门出发沿与原方向垂直的方向继续行进，直到接上该子区域内已有的折线段。
- 第三层推理——全局连通：将所有子区域的折线通过传送门串联起来，输出时将所有折线统一重绘为同一种颜色（该颜色为网格中折线使用的最常见颜色）。传送门像素在输出中被替换为折线颜色。grey 分割线保留不变。

Key insight:
传送门颜色是跨区域配对的唯一线索，而跳转后方向必须旋转 90° 这一隐含规则需要从多个样例中归纳。解题者必须先完成颜色配对，再推断方向约束，最后串联出全局路径。
</description>
</new_puzzle>

<new_puzzle>
<description>
根据封闭形状的"骨架对称性类型"在颜色图例中查找匹配，然后将形状内部按图例指定的纹理图案填充。

Input structure:
- 背景色（bg）为 azure。网格中散布着若干由 black 像素围成的封闭形状（形状各异，可能是矩形、十字形、L 形等），每个形状内部为空（azure 背景色）。
- 网格左侧有一列纵向排列的"图例条目"，每个条目包含两部分：左边是一个小型示意形状轮廓（black 边框），右边是一个与示意形状大小相同的彩色纹理样本（例如棋盘格、条纹、对角线等，使用 red、green、blue 等颜色）。
- 图例中的示意形状各具不同的对称性类型：有的具有四重旋转对称（如正方形），有的具有仅水平对称（如宽矩形），有的具有仅垂直对称（如高矩形），有的无对称性（如不规则 L 形）。

Rule:
- 第一层推理——对称性分类：对网格中每个封闭形状，判断其对称性类型：四重旋转对称、仅水平镜像对称、仅垂直镜像对称、水平+垂直镜像对称（但非旋转对称）、或无对称性。同样地，对图例中每个示意形状也做对称性分类。
- 第二层推理——匹配与填充：将网格中的封闭形状与图例中具有相同对称性类型的示意形状配对。然后将图例中对应的纹理图案以平铺方式填充到封闭形状内部。纹理从形状内部左上角开始平铺，超出形状边界的部分裁剪掉。
- black 轮廓线保留，图例区域在输出中保留不变。

Key insight:
形状的几何外观千差万别，但对称性类型的种类有限——解题者必须忽略大小和具体几何细节，只关注对称性这个抽象拓扑属性来完成匹配。这与参考题中按孔洞数匹配类似，但维度从拓扑（孔洞计数）转移到了几何对称性分类。
</description>

<new_puzzle>
<description>
识别网格中由不同颜色绘制的重叠"透明层"，根据层的叠放顺序推断被遮挡的部分，然后将所有层分离并排输出。

Input structure:
- 背景色（bg）为 black。网格中有若干矩形色块相互重叠地绘制在画布上，每个矩形使用一种独特的颜色（如 red、blue、green、yellow 等）。重叠区域显示的是最上层矩形的颜色（即后绘制的遮挡先绘制的）。
- 网格底部有一行单像素高的"顺序提示条"：从左到右排列着若干不同颜色的单像素点，颜色与上方矩形的颜色一一对应。提示条中像素从左到右的排列顺序代表绘制顺序（最左 = 最先绘制 = 最底层，最右 = 最后绘制 = 最顶层）。

Rule:
- 第一层推理——层序解读：从顺序提示条中读取绘制顺序。最右边颜色对应的矩形在最顶层，其可见区域就是它的完整形状。
- 第二层推理——遮挡还原：从最顶层开始逐层处理。最顶层矩形完全可见，可直接确定其完整边界。移除最顶层后，次顶层矩形的可见部分加上被顶层遮挡的部分构成其完整矩形——由于所有形状都是轴对齐矩形，只需根据可见部分的行列范围推断完整边界即可。逐层向下重复此过程。
- 第三层推理——分离输出：将还原出的每个完整矩形分别绘制在独立的小画布上（大小恰好包住该矩形），按照从底层到顶层的顺序从左到右水平排列在输出网格中，相邻画布之间用一列 grey 像素分隔。每个小画布的背景为 black，矩形使用其原始颜色。顺序提示条在输出中不出现。

Key insight:
核心难点在于遮挡还原——解题者必须理解"可见区域只是矩形的一部分"，并利用矩形这一几何约束（所有边轴对齐）从残缺的可见碎片中推断完整形状。提示条提供了层序这一关键信息，没有它就无法确定哪个颜色在上、哪个在下。三层推理环环相扣：读取层序 → 逐层还原完整矩形 → 分离排列输出。
</description>
</new_puzzle>
