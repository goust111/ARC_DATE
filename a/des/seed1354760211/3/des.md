## 第一步：分析与思考

### 参考题中涉及的基础操作

从20道参考题中，我提炼出以下核心操作类别：

1. **空间平移/滑动**：将对象沿某方向移动到指定位置（题1、5、9、13、15）
2. **反射/镜像**：跨轴线翻转对象（题15、16）
3. **旋转**：对象绕中心旋转（题4、9）
4. **射线/填充/扩展**：从标记点发射射线或填充区域（题2、7、10）
5. **模板复制/印章**：将一个对象作为模板重复放置（题3、8、18、20）
6. **面板选取/组合**：从多个分区中选取部分合并（题6）
7. **清理/修复**：移除噪声或补全缺失部分（题11、12）
8. **拓扑/连接**：在锚点间绘制连接线段（题19）
9. **配对/索引**：通过颜色或位置将对象配对（题1、8、17）
10. **尺寸/面积驱动**：根据对象大小决定变换行为（题14）

### 非显而易见的串联方式

- **面积编码选择**：对象的像素数量不仅是一个属性，还可以作为索引来选择变换的参数（如颜色、方向、目标位置）。
- **拓扑属性作为隐含指令**：一个对象的连通性（如孔洞数量、分支数）可以编码另一个对象应执行的操作次数或类型。
- **负空间（背景空白）作为信息载体**：对象围合的空白区域的形状本身就是一个隐含模板，可用于填充或指导其他变换。
- **相对位置编码操作类型**：两个对象之间的空间关系（上下左右、对角、距离）可以隐式地指定应对其中一个对象执行何种变换。
- **颜色频率作为排序/优先级**：某种颜色在网格中出现的次数可以决定对象的处理顺序或层叠优先级。
- **边界接触作为触发条件**：对象是否接触网格边界、是否接触另一个对象的边，可以决定该对象是否参与变换。
- **形状对称性缺陷定位关键信息**：一个近乎对称的形状中，打破对称的那个像素就是关键标记。

### 寻找新的因果关系

- 一个对象的**轮廓形状**可以被"展开"成一条直线，其长度编码一个数值。
- 多个对象的**颜色序列**（按某种空间排序读取）可以编码一个"指令表"。
- 一个对象内部的**孔洞形状**可以恰好是另一个对象的正形（阳模/阴模关系）。
- 对象的**凸包**与其实际形状的差异（凹区域）可以指示需要填充的位置。

## 第二步：全新 ARC 谜题

<new_puzzle>
<description>
将每个封闭边框内部未被填充的空白图案提取出来，用边框颜色重绘到右侧画布上，按边框围合面积从小到大垂直排列。

Input structure
- 背景为 black。网格被一列 maroon 像素分为左右两半。
- 左半部分包含若干互不重叠的单色矩形边框（一像素厚），每个边框颜色各不相同，可能为 red、blue、green、yellow、orange 等。
- 每个边框内部区域被 grey 像素部分填充；其中未被 grey 覆盖而保持 black 的像素构成"空白图案"。
- 右半部分完全为 black。

Rule
- 对于左侧每个矩形边框，定位其内部区域（不含边框本身），找出所有保持 black 的像素位置——即被 grey 像素衬托出的"空白图案"。
- 将该空白图案以边框颜色绘制到右侧画布上。图案保持其在内部区域中的相对位置不变。
- 多个图案按来源边框的围合面积（边框内部的行数乘以列数）从小到大、从上到下排列在右侧画布中，每个图案的最上行紧贴前一个图案的最下行下方第二行（间隔一行 black）。第一个图案的最上行与网格顶部对齐。
- 每个图案在右侧画布中水平居中。

Key insight
- 核心洞见是"负空间提取"：解题者容易被 grey 填充区域吸引，但真正需要关注的是 grey 中"缺失"的 black 像素所形成的图案。边框颜色赋予图案着色，围合面积决定排列顺序。需要对比多个样例才能确认排序依据是围合面积而非边框颜色或位置。
</description>
</new_puzzle>

<new_puzzle>
<description>
识别网格中由 grey 像素绘制的箭头形状，沿箭头指向发射射线找到目标彩色像素，然后用目标的颜色回填整个箭头。

Input structure
- 背景为 black。网格中散布若干由 grey 像素绘制的小型箭头。
- 每个箭头由 5 个 grey 像素组成：3 像素的直线箭身和 2 像素的 V 形箭头尖端。朝右箭头的具体像素为箭身 (r,c), (r,c+1), (r,c+2)，尖端 (r-1,c+3), (r+1,c+3)；其余三个方向（上、下、左）是该形状旋转 90、180、270 度的结果。
- 网格中另有若干孤立的单像素彩色标记（非 grey、非 black），每个标记恰好位于某个箭头尖端沿指向方向延伸的直线上（同行或同列）。每个箭头的射线方向上恰好有一个这样的彩色标记。

Rule
- 对于每个 grey 箭头，从其尖端的中点（两个尖端像素的中间位置在箭身延长线上的下一个像素）沿指向方向搜索，找到第一个非 black 彩色像素。
- 将该箭头全部 5 个 grey 像素替换为找到的彩色像素的颜色。
- 彩色标记像素保持不变。其余 black 背景不变。

Key insight
- 解题者首先要识别四种旋转方向的箭头形状，理解 V 形尖端指示了射线方向。真正隐蔽的推理在于颜色传递的方向是"反直觉的"——不是箭头将颜色射出去，而是箭头从目标那里"吸收"颜色。解题者需要对比输入输出中 grey 像素消失而箭头区域变为彩色这一现象来归纳规则。
</description>
</new_puzzle>

<new_puzzle>
<description>
利用每个色块内部打破对称性的那个像素的位置来确定该色块应当平移的方向和距离。

Input structure
- 背景为 black。网格中有若干互不重叠的单色 4-连通区域（色块），每个色块形状是关于其 bounding box 中心近似对称的（水平对称或垂直对称或两者兼有）。
- 每个色块中恰好有一个像素被替换为与色块不同的颜色（"瑕疵像素"）。瑕疵像素的颜色所有色块统一使用 maroon。
- 瑕疵像素的位置打破了色块原有的对称性。若将瑕疵像素恢复为色块颜色，色块将是完美对称的。
- 所有色块的 bounding box 尺寸相同（例如都是 5x5）。

Rule
- 对于每个色块，找到其瑕疵像素（maroon）。
- 计算瑕疵像素相对于色块 bounding box 中心的偏移向量 (dr, dc)。
- 将整个色块（瑕疵像素恢复为色块颜色后）沿 (dr, dc) 方向平移，平移距离等于 |dr| + |dc|（曼哈顿距离）个像素。
- 清除色块原位置，将恢复后的完美对称色块绘制到新位置。
- 若平移后色块超出网格边界，则色块被裁剪（只保留网格内的部分）。

Key insight
- 解题者需要先发现每个色块中唯一的 maroon 像素是刻意放置的"瑕疵"而非随机噪声。然后需要理解瑕疵的位置不仅标记了对称性的破坏点，更编码了平移指令：偏移方向就是平移方向，偏移的曼哈顿距离就是平移步数。输出中瑕疵消失、色块变为完美对称这一线索是归纳规则的关键切入点。
</description>
</new_puzzle>

<new_puzzle>
<description>
网格被分为多个矩形房间，每个房间边框上有缺口形成"门"；找到正对的门对并在门之间绘制通道，通道颜色取两个房间中面积较小者的地砖颜色。

Input structure
- 背景为 black。网格中有若干矩形"房间"，每个房间由 grey 像素的一像素厚矩形边框围成。
- 每个房间内部完全填充某种非 grey、非 black 的单一颜色（"地砖色"），不同房间地砖色可能不同。
- 某些房间的边框上有恰好一个像素的缺口（该位置为 black），即"门"。每个房间至多有两扇门，分别在不同的边上。
- 部分门沿垂直于其所在边的方向直线延伸可以到达另一个房间的门（中间全是 black 背景），形成"对门"。

Rule
- 找到所有对门配对：两扇门在同一行或同一列，且之间只有 black 像素。
- 在每对对门之间的 black 像素上绘制一像素宽的直线通道。
- 通道颜色为两个房间中内部面积（边框内像素总数）较小者的地砖色。若面积相同，取行号更小的房间的地砖色；若行号也相同，取列号更小的房间的地砖色。
- 所有房间边框、内部颜色、门的缺口均保持不变。

Key insight
- 解题者需要先识别"门"是边框上的 black 缺口（与背景同色，容易被忽视），再发现对门之间需要连通。通道颜色的确定规则最为隐蔽：需要对比多个通道的颜色来排除"总是用左边/上边房间颜色"或"混合颜色"等假设，最终发现是取面积更小的房间颜色。面积比较需要解题者估算或计数各房间大小。
</description>
</new_puzzle>

<new_puzzle>
<description>
将网格中散布的小型图案按其内部孔洞的数量分组，然后为每组所有图案统一着色，孔洞数越多的组着色越"暖"。

Input structure
- 背景为 black。网格中散布若干 4-连通的 grey 单色小型图案（每个图案占据约 8 到 20 个像素），图案之间互不接触。
- 每个图案的形状不同，但可以按"孔洞数"分类：有些图案是实心的（0 个孔洞），有些包围了 1 个 black 孔洞（如环形），有些包围了 2 个孔洞，等等。这里"孔洞"定义为被该图案 4-连通完全包围的 black 连通区域（不包括与背景相连的外部 black）。
- 网格底部有一行宽的"色板带"，由若干种颜色从左到右排列：例如 blue、green、yellow、orange、red，每种颜色占据连续若干个像素（形成色条），颜色按从冷到暖排列。色板中颜色的数量恰好等于图案孔洞数的种类数。

Rule
- 统计每个 grey 图案内部 4-连通 black 孔洞的数量。
- 将所有图案按孔洞数排序：0 个孔洞为第一组，1 个孔洞为第二组，依此类推。
- 色板带中从左到右的颜色分别分配给第一组、第二组、第三组……
- 将每个图案的 grey 像素替换为其所在组对应的颜色。
- 移除底部色板带（输出网格高度减少一行）。

Key insight
- 解题者看到输出中原本统一的 grey 图案被着上了不同颜色，需要找出着色依据。形状、大小、位置等表面特征都不是决定因素，真正的分类标准是拓扑属性——孔洞数量。这要求解题者具备"内部空洞"的概念，并能区分图案内部被完全包围的 black 区域与连通到外部背景的 black 区域。色板带提供了颜色映射的线索，但其从左到右的顺序与孔洞数从少到多的对应关系需要从样例中归纳。
</description>
</new_puzzle>

<new_puzzle>
<description>
在包含多个同形但不同色的图案的网格中，找出每个图案相对于"标准形态"缺失的那些像素，然后将所有图案的缺失像素合并绘制成一个新图案。

Input structure
- 背景为 black。网格左侧有若干个形状几乎相同但颜色各异的小图案（每个图案一种独特颜色，如 red、blue、green、yellow 等），它们的 bounding box 大小完全相同，排列在同一列上，垂直方向等间距排列。
- 每个图案都是某个"标准形态"的子集——即从标准形态中随机移除了 1 到 3 个像素后的结果。没有任何一个图案是完整的标准形态。
- 网格右侧有一个与图案同等大小的空白区域（全 black），用于放置输出图案。

Rule
- 将所有左侧图案的 bounding box 对齐（它们已经是相同大小）。
- 对于 bounding box 中的每个位置，如果所有图案在该位置都有像素（无论颜色），则该位置属于标准形态的"共有部分"。
- 如果某些图案在该位置有像素而另一些没有，则该位置属于标准形态但在缺失它的图案中是"缺失像素"。
- 如果没有任何图案在该位置有像素，则该位置不属于标准形态。
- 在右侧空白区域绘制标准形态的完整图案，使用 grey 颜色。但是，对于标准形态中每个位置，如果恰好只有一个图案在该位置缺失了像素，则该位置用那个缺失图案的颜色绘制（而非 grey）。如果有多个图案都缺失了同一位置，则该位置仍用 grey 绘制。

Key insight
- 解题者需要先意识到所有左侧图案是同一个"标准形态"的不完整版本，再通过叠加比较找出哪些位置在某些图案中缺失。最隐蔽的是输出的着色规则：大部分标准形态用 grey（所有图案的"公约数"），但独特缺失的位置用缺失者的颜色标记出来——这既重建了完整形态，又标注了每个图案独特的"缺陷"。解题者需要逐位置对比所有图案才能归纳出这一规则。
</description>
</new_puzzle>
