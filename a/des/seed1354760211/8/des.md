## 第一步：分析与思考

### 参考题中涉及的基础操作归纳

通读 20 道参考题，可以提炼出以下基础操作类别：

1. **计数与统计**（#1 histogram）——统计对象数量并以柱状图形式输出。
2. **射线投射 / 方向延伸**（#2 ray-cast, #8 push-to-edge）——沿某方向传播直到碰到边界或障碍。
3. **模板 / 形状匹配与实例化**（#3 glyph template, #10 shape legend, #18 stencil recolor）——用已知模板替换标记。
4. **镜像 / 反射对称**（#4 mirror across separator, #19 reflection symmetry）——利用对称轴恢复被遮挡的信息。
5. **空间平移与滑动**（#5 slide-to-edge, #6 move-and-shear, #8 push, #13 diagonal shift, #14 color-coded displacement）——按规则移动对象。
6. **裁剪与分区**（#7 stagger regions, #11 crop by markers, #12 compress quadrants, #20 crop board）——识别区域边界并提取/重组。
7. **形状属性编码信息**（#5 notch→direction, #17 tab/notch pairing）——形状的几何特征编码了操作指令。
8. **颜色编码指令**（#14 color→displacement, #16 color ordering→side, #20 cue count→rotation）——颜色本身携带操作参数。
9. **路径跟踪**（#4 trail following, #15 rope around obstacle）——沿连通路径传递信息或重绘形状。
10. **计数转换为几何量**（#1 count→bar height, #9 gray count→stripe count, #20 pixel count→rotation angle）——数值信息转化为空间维度。

### 非显而易见的串联方式思考

- **形状属性可以编码"谁先谁后"的排序信息**：比如对象的面积、周长、凸凹性可以决定它们的叠放次序或处理优先级，这在参考题中尚未出现。
- **拓扑连通性作为分类依据**：对象内部是否有"洞"（环形 vs 实心）可以决定不同的变换路径。
- **局部邻域特征决定全局行为**：某个像素的局部邻域模式（如 L 形、T 形）可以编码该像素应该执行何种全局变换。
- **对象之间的相对空间关系编码操作**：两个对象之间的距离、相对方位（上下左右）、是否对齐等关系可以决定第三个对象的变换方式。
- **遮挡/重叠顺序反推**：部分遮挡的对象，其可见形状隐含了完整形状和叠放顺序的信息。
- **边界接触模式**：对象与网格边界的接触方式（哪条边、接触长度）可以编码操作参数。
- **颜色频率的排序作为密码**：不同颜色的像素数量大小关系可以编码排列或映射规则。
- **一个操作的几何产物隐式编码另一个操作的参数**：例如射线投射产生的线段长度可以成为后续旋转的角度参数，或平铺的重复次数。
- **对象的"朝向"由不对称缺口推断**：非对称形状有隐式的"面向"方向，可以用来决定它的行为方向，类似于参考题 #5 的 notch 但更加隐蔽。
- **多对象最近邻关系构成隐式图结构**：对象之间的最近邻配对可以定义连接线的画法或颜色的传递方式。

### 创新方向

我将构思核心推理路径互不相同的谜题，侧重以下认知挑战：
1. 拓扑属性（有洞 vs 无洞）作为分类信号——解题者需要从颜色变化反推拓扑分类标准。
2. 三像素消歧——每种颜色的第三个像素打破几何对称性，决定连接路径方向。
3. 局部像素度数→颜色映射——骨架拓扑的局部分析。
4. 种子图案平铺——各区域独立的自包含变换。
5. 对象面积编码缩放倍数——面积作为数值参数而非几何形状。
6. 接触长度与厚度的比值决定保留量——两个几何量的关系编码数值参数。
7. 箭头形状编码方向 + 路径遮挡关系编码颜色——两层独立信息叠加。
8. 质心偏移编码移动方向 + 凸角数编码颜色——形状自身属性多维度编码。

<new_puzzle>
<description>
根据每个封闭前景对象是否包含内部空洞（环形），对其进行分类并重新着色：有洞的对象着色为红色，无洞的实心对象着色为蓝色。

Input structure
- 背景色为黑色。
- 网格中散布着若干个由同一前景色（绿色）绘制的分离的 4-连通对象。
- 每个对象要么是实心块（内部无背景像素被完全包围），要么是环形（内部围出了至少一个全由背景色构成的封闭空洞区域）。
- 对象大小和形状各异，但均为单色绿色。

Rule
- 对每个绿色 4-连通对象，检测其是否围出了至少一个完全被该对象像素包围的背景空洞区域（空洞定义：一组黑色像素的 4-连通分量不与网格边界相连）。
- 若该对象包含至少一个空洞：将该对象的所有像素重着色为红色。
- 若该对象不包含任何空洞（实心）：将该对象的所有像素重着色为蓝色。
- 背景保持黑色不变。空洞内部的黑色像素也保持不变。

Key insight
- 分类信号不是对象的大小、位置或外部轮廓形状，而是其拓扑属性——是否围出了被完全封闭的内部空洞。解题者需要注意"环形"和"实心"的区分，而非形状相似性。
</description>
</new_puzzle>

<new_puzzle>
<description>
网格中散布着成对的同色像素；每对同色像素之间用 L 形折线连接，折线的拐弯方向由该颜色的唯一第三个同色"指示像素"与端点对的空间关系决定。

Input structure
- 背景色为黑色。
- 网格中有若干种非黑颜色，每种颜色恰好出现 3 个像素。
- 对于每种颜色的 3 个像素，其中两个像素位于同一行或同一列（称为"端点对"），第三个像素（称为"指示像素"）位于其他位置，既不与端点对同行也不与端点对同列。
- 端点对的两个像素不直接相邻，它们之间存在空的背景区域。

Rule
- 对每种颜色，找到位于同一行或同一列的两个端点像素，第三个像素即为指示像素。
- 端点对之间需要用一条 L 形折线连接（由一段水平线和一段垂直线组成，在拐角处相交）。用该颜色填充折线路径上端点之间的所有背景像素（含拐角像素）。
- L 形折线有两种可能的拐弯方式。当端点对在同一行时，垂直段可向上或向下延伸到另一端点的行再水平连接；当端点对在同一列时，水平段可向左或向右延伸。
- 选择拐弯方向的规则：指示像素相对于端点对所在直线的哪一侧，折线就向哪一侧拐弯。具体来说，若端点对在同一行（同一行号 r），指示像素的行号小于 r 则折线的垂直段向上延伸，行号大于 r 则向下延伸；若端点对在同一列（同一列号 c），指示像素的列号小于 c 则折线的水平段向左延伸，列号大于 c 则向右延伸。
- 折线的垂直/水平延伸长度等于端点对之间的间距（即折线连接两个端点，不多不少）。
- 所有颜色独立处理，指示像素保留在原位不变。

Key insight
- 每种颜色的三个像素各有不同角色：两个是连接端点，一个是方向指示器。解题者必须先将三像素分为"端点对"和"指示像素"两组（依据是否共行/共列），然后理解指示像素的位置如何消歧 L 形路径的拐弯方向。这种"第三像素打破对称"的信息编码方式是核心难点。
</description>
</new_puzzle>

<new_puzzle>
<description>
在一像素宽的单色骨架网络中，根据每个像素的局部连通度（4-邻域中同色邻居数量）将其着色为不同颜色。

Input structure
- 背景色为黑色。
- 网格中有一个由单一颜色（蓝色）绘制的一像素宽的连通路径网络（骨架）。骨架形成若干条水平和垂直线段的连接结构。
- 骨架像素严格为一像素宽度（即骨架上不存在 2×2 的同色方块）。
- 骨架中存在多个交叉点（4-邻域同色邻居数 ≥ 3 的像素）、端点（4-邻域同色邻居数 = 1 的像素）和普通路径点（4-邻域同色邻居数 = 2 的像素）。

Rule
- 遍历骨架上所有蓝色像素，计算每个像素的度（4-邻域中蓝色邻居的数量）。
- 度 = 1（端点）：将该像素重着色为红色。
- 度 = 2（普通路径点）：保持蓝色不变。
- 度 = 3（T 形交叉）：将该像素重着色为绿色。
- 度 = 4（十字交叉）：将该像素重着色为黄色。
- 背景保持黑色不变。

Key insight
- 变换规则完全由每个像素的局部 4-连通度决定，不涉及全局形状或对象级推理。解题者需要发现颜色变化只发生在骨架的特殊节点处（端点和交叉点），并归纳出颜色与邻域同色邻居数量之间的严格映射关系。
</description>
</new_puzzle>

<new_puzzle>
<description>
网格由框架线分割为若干矩形单元格，每个单元格左上角有一个小型种子图案；将种子图案沿水平和垂直方向重复平铺以填满整个单元格。

Input structure
- 网格由灰色像素构成的一像素宽的水平线和垂直线划分为若干个矩形单元格区域。灰色线贯穿整个网格的宽度或高度。
- 每个单元格区域的背景为黑色。
- 每个单元格内部的左上角放置着一个小型矩形种子图案，由非黑、非灰颜色的像素构成。种子图案的右边和下边紧邻黑色背景像素（或单元格边界）。
- 种子图案的宽度整除该单元格区域的内部宽度，种子图案的高度整除该单元格区域的内部高度。
- 不同单元格内的种子图案可以有不同的尺寸、形状和颜色。

Rule
- 对每个单元格区域，识别其左上角的种子图案：从该区域的左上角像素开始，种子图案是包含所有非黑像素的最小矩形（向右和向下扩展直到遇到全黑的行或列）。
- 将该种子图案作为瓦片，沿水平方向和垂直方向周期性重复复制，直到完全覆盖该单元格区域内的所有像素。
- 灰色框架线在输出中保持不变。

Key insight
- 每个区域的变换完全由其自身内部的种子图案自包含决定，不同区域可以有不同的种子和不同的重复次数。解题者需要意识到变换是"区域内局部平铺"而非全局模式复制，并且需要从左上角找到正确的种子边界。
</description>
</new_puzzle>

<new_puzzle>
<description>
网格中有若干个同色的 L 形对象散布在背景上；每个 L 形的"缺失象限"位置决定了它应该被填充为完整矩形，而填充色由该 L 形两条臂的长度比较结果决定。

Input structure
- 背景色为黑色。
- 网格中有若干个由灰色绘制的 L 形对象，彼此分离（4-连通分量）。
- 每个 L 形由两条垂直交叉的矩形臂构成，形成一个直角。两条臂共享一个角点像素，分别沿水平和垂直方向延伸。每条臂的宽度为一个像素。
- 每个 L 形的直角朝向四个可能方向之一（左上、右上、左下、右下），对应"缺失象限"的位置。
- 两条臂的长度（像素数）可能不同。

Rule
- 对每个灰色 L 形对象，确定其两条臂及其直角方向（即缺失象限在左上、右上、左下还是右下）。
- 将该 L 形补全为完整矩形：矩形的宽等于水平臂长度，高等于垂直臂长度，直角角点为矩形的一个角。用填充色填入缺失象限区域的所有黑色像素。
- 填充色的确定规则：比较水平臂长度 H 和垂直臂长度 V。若 H > V，填充色为红色；若 V > H，填充色为蓝色；若 H = V，填充色为绿色。
- 原始灰色像素保持灰色不变。
- 所有 L 形对象独立处理。

Key insight
- L 形的直角朝向决定了填充区域的位置（哪个象限被补全），而两条臂的长度对比决定了填充颜色。解题者需要同时分析两个独立的几何属性：朝向（位置信息）和臂长比较（颜色信息），这两个属性都编码在同一个对象的形状中，但作用于输出的不同方面。
</description>
</new_puzzle>

<description>
网格中每个彩色对象旁边都有一个由同色像素构成的小型"指针线段"；指针线段的方向指示该对象应被投影到网格边界的方向，而指针线段的长度决定投影后对象被截断保留的厚度。

Input structure
- 背景色为黑色。
- 网格中有若干个由不同颜色绘制的实心矩形对象（每个对象一种颜色，颜色各不相同）。
- 每个矩形对象的外侧恰好有一个由同色像素构成的一像素宽的直线段（水平或垂直），与该对象不直接 4-连通但位于同一行/列范围内，且与对象之间间隔至少一个黑色像素。
- 直线段是水平的或垂直的，其方向指向上、下、左、右四个基本方向之一（定义为从对象中心朝向直线段的方向）。

Rule
- 对每个矩形对象，找到其同色的指针线段。
- 确定投影方向：从对象中心指向指针线段中心的基本方向（上、下、左、右）。
- 擦除原始对象和指针线段（全部变为黑色）。
- 将对象沿投影方向平移，直到对象的前沿碰到网格边界。
- 到达边界后，对象只保留从边界开始的前 K 行/列（K = 指针线段的像素长度），其余部分擦除。
- 保留部分保持原色不变。

Key insight
- 指针线段同时编码了两个信息：方向（指针相对于对象的方位决定投影方向）和数值参数（指针长度决定保留厚度）。解题者需要发现这两层信息都隐藏在同一个辅助元素中，而对象本身的位置和形状对输出位置没有直接影响——最终位置完全由边界和方向决定。
</description>
</new_puzzle>

<new_puzzle>
<description>
将网格中每个多色矩形区域内的颜色层按照它们的面积从大到小重新堆叠——面积最大的颜色层置于底部（填充整个矩形），面积最小的叠在最上方（保留原始形状和位置）。

Input structure
- 背景色为黑色。
- 网格中有若干个互不重叠的矩形区域，每个区域由该区域内所有非黑像素的最小外接矩形确定。
- 每个矩形区域内有 2 到 4 种不同的非黑颜色，每种颜色占据区域内一组连续的像素（各颜色层不互相重叠，但共同填满矩形区域内的所有像素位置）。
- 每种颜色层的形状为一个连续的 4-连通区域。

Rule
- 对每个矩形区域，统计其中每种颜色的像素数量。
- 按面积从大到小排序所有颜色层。
- 重建输出：先将整个矩形区域用面积最大的颜色填满，然后在其上叠放面积第二大的颜色层（保持其原始形状和在区域内的相对位置），以此类推，最后叠放面积最小的颜色层。
- 由于从大到小叠放，面积小的颜色层覆盖在面积大的上方，所有面积小的层的原始像素位置在输出中可见，而面积大的层在被覆盖的位置显示不出来但在其他位置填满了整个矩形。
- 黑色背景和矩形区域外的像素保持不变。

Key insight
- 输入中各颜色层已经平铺无重叠地填满矩形，但输出中它们像按面积排序的透明层一样堆叠。解题者需要发现"面积排序决定叠放优先级"这一规则——最大层作为底色扩展到整个矩形，而小层保持原样浮在上方。这改变了大面积颜色的分布，但不改变小面积颜色的任何像素。
</description>
</new_puzzle>
