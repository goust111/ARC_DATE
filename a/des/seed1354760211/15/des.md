## 第一步：分析与思考

### 参考题中涉及的基础操作归类

**空间变换类：**
- 剪切/倾斜（参考2：行偏移形成平行四边形）
- 镜像/反射（参考6：跨分隔线镜像；参考12：水平翻转粗粒化网格）
- 平移（参考19：由路径端点编码位移向量）
- 循环位移（参考18：由标记行编码滚动量）
- 重力/下落（参考7：精灵按宽度规则下落）

**模式识别与匹配类：**
- 裁剪窗口匹配全图（参考1：从局部窗口恢复完整20x20母图）
- 形状识别（参考3：检测十字形；参考11：按孔洞数分类）
- 拼图组装（参考13：红色连接器配对；参考15：拼合+图例重着色）

**信息编码类：**
- 位置编码数值（参考9：粉色像素的相对位置选择3x3区域中的目标格；参考18：红色标记行号=滚动量）
- 内部图案编码全局结构（参考8：少数单元格内部图案是全局分布的蓝图——分形自相似）
- 路径端点编码向量（参考19：灰色路径两端的彩色像素定义净位移）
- 调色板行编码颜色序列（参考17：顶行调色板中的间隙=楔形中心）

**结构推断类：**
- 冗余副本恢复原型（参考4：多块一致投票恢复被损坏的那块）
- 粗粒化/降采样（参考12：从带噪声的晶格块提取粗网格）
- 嵌套层级/包含树（参考10：按包含关系整理嵌套图形）

**条件分支类：**
- 按对象属性分流处理（参考7：单列精灵穿越分隔线，宽精灵停在分隔线上方）
- 方向性条件重排（参考20：按边界标记的朝向重排蓝/粉序列）

### 非显而易见的串联方式

1. **拓扑属性驱动空间变换**：孔洞数不仅可以用来选颜色（参考11），还可以编码旋转角度、位移量或缩放因子——即形状的拓扑特征直接控制几何变换参数。

2. **对象间关系图编码全局操作**：多个对象之间的空间关系（如相对位置、距离序列）可以编码一个排列/置换，然后该置换作用于对象自身或其他元素。

3. **局部对称性缺陷作为信息载体**：一个几乎对称的图案中，打破对称的那个像素携带关键信息（如方向、选择），类似于参考9中粉色像素的角色，但推广到对称性分析。

4. **颜色频率编码操作序列**：某种颜色出现的次数决定变换的迭代次数或步骤参数，将计数与空间操作串联。

5. **连通域的形态决定变换类型**：不是简单的"有几个孔"，而是连通域的具体形状（L形、T形、直线等）决定对该对象施加哪种变换（旋转、翻转、平移方向等）。

6. **遮挡/覆盖关系反编码深度排序**：输出中对象的前后层叠顺序由某个与视觉深度无关的属性（如面积、颜色值排序）决定，而解题者需要从部分遮挡结果反推排序规则。

7. **路径拓扑（而非几何）传递变换**：两个对象通过一条弯曲路径连接，路径的转弯次数（而非路径长度或端点位移）编码旋转角度。

- 解题者需要发现决定填充方式的隐藏属性是框架边长的奇偶性，而非颜色、位置或大小本身。奇数框架完全填满，偶数框架出现棋盘格——这个分支条件并不直观，需要仔细比较不同框架的尺寸和输出结果才能归纳出来。

<description>
在网格中，每个彩色精灵拥有一个唯一的"尖端"像素（度为1的末端），该尖端相对于精灵质心的方位决定精灵的滑动方向；精灵沿该方向滑动直到碰壁或碰到已停止的精灵。

Input structure:
- 背景为黑色（black）。
- 网格中散布着若干由单一非黑颜色组成的4-连通精灵，每个精灵恰好有一个"尖端"——即精灵中唯一一个只有一个同色4-连通邻居的像素。精灵的其余部分较宽或有分支，使得尖端在视觉上像一个突出的指针。
- 每个精灵的颜色各不相同。
- 精灵之间不相邻。

Rule:
- 对每个精灵，找到其唯一的尖端像素 t（只有一个同色4-邻居的像素）。
- 计算精灵所有像素坐标的算术平均作为质心 m（行和列分别取平均，四舍五入到最近整数）。
- 滑动方向为从 m 指向 t 的向量，量化为四个正交方向（上/下/左/右）中与该向量夹角最小的那个。若向量恰好沿对角线（与两个正交方向等角），则选择行方向（上或下）。
- 按照精灵到其滑动方向前方网格边界距离从大到小的顺序依次处理（距离最远的先滑动）。
- 每个精灵沿确定方向整体平移，直到精灵的某个像素紧贴网格边界或紧邻已停止精灵的像素为止。
- 精灵的原位置清空为黑色。

Key insight:
- 每个精灵的运动方向完全隐含在其自身几何形状中——尖端相对于质心的方位就是运动方向。解题者需要识别"尖端"这一拓扑特征（度为1的像素）并理解它是方向指示器。处理顺序保证了最远的精灵先停靠在墙壁上，后续精灵依次堆叠，产出唯一确定的结果。
</description>
</new_puzzle>

<description>
网格被一条单像素宽的彩色路径分为若干区域；路径上散布着若干"染色门"像素，每扇门为路径后续段落指定新颜色，将原本灰色的路径分段重着色。

- 一条由灰色（grey）像素构成的连续4-连通路径贯穿网格，没有分支（每个路径像素恰好有两个灰色或门颜色的4-邻居，除了两个端点各只有一个）。

Rule:
- 确定遍历起点：选择路径两个端点中离最近一扇门距离（沿路径计算）更短的那个端点为起点。若等距则选行号更小的端点；若行号也相同则选列号更小的端点。

- 门像素自身保持原色不变。

Key insight:
- 门像素是路径上的"分段着色指令"：每扇门开启一段新颜色区间，一直持续到下一扇门。解题者需要理解路径具有线性顺序，且门充当了颜色切换开关。难度在于确定遍历方向——需要沿路径分别计算两端点到最近门的距离来消歧，而不是简单地看端点的坐标大小。

<new_puzzle>
<description>
网格中有若干形状各异的单色精灵和一个多色的"旋转指令块"。指令块是一个 2x2 方块，四个像素颜色分别对应网格中的四个精灵；指令块中每种颜色相对于中心的象限位置指定了该颜色精灵应旋转到的目标象限。

Input structure:
- 背景为黑色（black）。
- 网格中有恰好四个互不相邻的单色4-连通精灵，颜色各不相同（四种不同的非黑颜色，如红色 red、蓝色 blue、绿色 green、黄色 yellow）。
- 网格中还有一个 2x2 的方块，位于网格的中心附近（不与任何精灵重叠），其四个像素分别使用上述四种颜色，每种颜色恰好出现一次。这个方块是"旋转指令块"。
- 网格可以被十字线（通过网格中心的水平线和垂直线）划分为四个象限：左上、右上、左下、右下。每个精灵初始时位于某个象限内部（不跨越中心线）。

Rule:
- 读取旋转指令块中每种颜色的位置：左上格、右上格、左下格、右下格分别对应目标象限"左上、右上、左下、右下"。
- 对每个精灵（颜色为 c），找到 c 在指令块中的位置对应的目标象限 Q_target。
- 找到精灵当前所在的源象限 Q_source。
- 将精灵从 Q_source 平移到 Q_target：精灵相对于 Q_source 中心的偏移向量保持不变，但映射到 Q_target 的对应位置（即精灵在目标象限中占据与源象限中镜像对称的位置——行偏移关于水平中心线翻转、列偏移关于垂直中心线翻转，取决于象限跨越方向）。
- 具体计算：若网格中心为 (cr, cc)，精灵像素 (r, c) 在源象限中，则目标位置为 (cr + (cr - r) * vr_sign, cc + (cc - c) * vc_sign)，其中 vr_sign 和 vc_sign 由源象限到目标象限的关系决定（同行方向则 vr_sign = -1 即保持，跨行则 vr_sign = +1 即翻转；列方向同理）。
- 更直观地说：若精灵需要从左上移到右下，则精灵关于网格中心做点对称；若从左上到右上，则关于垂直中心线做镜像；若从左上到左下，则关于水平中心线做镜像；若停留在原象限，则不动。
- 移除指令块（其位置变为黑色）。

Key insight:
- 2x2 指令块是一个"颜色-象限分配表"：它的四个格子分别告诉每种颜色的精灵应该去往哪个象限。解题者需要将指令块的布局解读为象限指令，并理解精灵的移动是通过关于中心线的对称变换实现的。核心困难在于发现指令块的存在和意义——它看起来只是一个小方块，但实际上控制了所有精灵的重新分配。
</description>
</new_puzzle>

- 背景为黑色（black）。

- 将所有矩形按面积从小到大排序。
- 在输出中，清除所有原始矩形。

- 矩形之间无间隙，紧密排列。
- 蓝色轴线在输出中保持不变。
- 若矩形超出网格边界则截断。

Key insight:
- 蓝色轴线同时编码了两个信息：所在边缘决定堆叠方向，中点位置决定对齐轴。解题者需要发现矩形被按面积排序后沿特定方向重新排列——排序依据（面积）和排列规则（方向+对齐）都隐含在轴线的位置属性中。表面上看到的是散落的矩形和一条短线段，实际上短线段是一个多功能的控制器。

<description>
网格中包含若干彩色"源图案"和与之颜色匹配的"目标轮廓"。每个目标轮廓是一个空心形状；将对应颜色的源图案缩放（最近邻插值）以恰好填满目标轮廓的内部区域。

Input structure:
- 背景为黑色（black）。
- 网格中有若干成对的对象，每对包含：
  - 一个"源图案"：由灰色（grey）像素和该对的标识颜色像素共同构成的小型矩形图案（占据一个紧凑的矩形区域），其中标识颜色像素构成图案的前景，灰色像素构成图案的背景。
  - 一个"目标轮廓"：由该对的标识颜色绘制的单像素宽空心矩形框架，内部全为黑色。
- 标识颜色在不同对之间各不相同（如红色 red、蓝色 blue、绿色 green 等）。
- 源图案和目标轮廓可能在网格中任意位置，不相邻。

Rule:
- 对每一对（通过匹配标识颜色配对）：
  - 提取源图案中的二值前景（标识颜色 = 前景，灰色 = 背景），得到一个小矩形二值图。
  - 测量目标轮廓的内部空腔尺寸（高度 h_t、宽度 w_t）。
  - 将源图案的二值图通过最近邻插值缩放到 h_t x w_t 大小：对于输出位置 (i, j)，采样源图案位置 (floor(i * h_s / h_t), floor(j * w_s / w_t))，其中 h_s、w_s 为源图案尺寸。
  - 将缩放后的图案填入目标轮廓内部：前景像素用标识颜色，背景像素保持黑色。
- 源图案在输出中被清除为黑色。
- 目标轮廓的框架像素保持不变。

Key insight:
- 源图案和目标轮廓通过颜色配对；源图案是"缩略图"，目标轮廓的内部空间是"画布"。解题者需要发现小图案与大空心框架之间的颜色对应关系，并理解变换是将小图案放大填入大框架内部——一种视觉上的"投影放大"操作。难点在于意识到灰色在源图案中扮演"背景"角色，以及识别最近邻缩放的映射方式。
</description>
