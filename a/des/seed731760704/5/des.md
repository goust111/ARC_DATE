<description>
根据封闭区域内部的彩色种子像素确定该区域的"所属颜色"，再利用区域边界上的缺口方向，将该颜色沿缺口方向向外喷射射线，射线宽度等于缺口的像素宽度。

Input structure:
- 背景为 black。灰色 (grey) 像素构成若干封闭的不规则多边形轮廓，每个轮廓的边界上恰好有一个连续缺口（缺口处无灰色像素）。
- 每个封闭区域内部散布着若干同色的非黑非灰像素（如 red、blue、green 等），这些像素的颜色各区域互不相同，作为"种子"标识该区域的所属颜色。
- 缺口总是位于轮廓的正上、正下、正左或正右的某一段边上，且缺口为连续的一段缺失。

Rule:
- 第一步（归纳区域颜色）：对每个灰色封闭轮廓，找到其内部所有非黑非灰像素的颜色，该颜色即为此区域的"喷射颜色"。
- 第二步（确定喷射方向与宽度）：找到轮廓边界上的缺口位置；缺口所在的方向（上/下/左/右）即喷射方向；缺口跨越的像素数即射线的宽度。
- 第三步（绘制射线）：从缺口位置出发，沿缺口方向向外绘制一条宽度等于缺口宽度的直线射线，颜色为该区域的喷射颜色，射线一直延伸到网格边界为止。射线不覆盖灰色像素或其他已有的非黑像素。
- 灰色轮廓和内部种子像素保持不变。

Key insight: 解题者需要先完成"种子颜色→区域归属"的匹配，再独立发现"缺口方向决定喷射方向、缺口宽度决定射线宽度"这一几何编码规则——两步推理缺一不可，且第二步的宽度编码不易从单个样例中确认。
</description>

<description>
在网格中找到若干彩色"钥匙"形状和若干灰色"锁"形状，通过旋转/翻转将钥匙与锁进行形状匹配，然后用钥匙的颜色填充锁的内部孔洞。

Input structure:
- 背景为 black。网格中散布着若干由灰色 (grey) 像素构成的小型连通形状（称为"锁"），每个锁的内部包含一个或多个由黑色像素构成的孔洞（即被灰色完全包围的黑色区域）。
- 网格中还散布着若干彩色（非黑非灰）的小型连通形状（称为"钥匙"），每把钥匙是纯色的（如 red、blue、orange 等），不同钥匙颜色各不相同。
- 每把钥匙的外轮廓形状恰好与某一把锁的外轮廓形状在某个旋转（0°/90°/180°/270°）或翻转下完全匹配。钥匙本身没有孔洞（内部全部填满颜色）。

Rule:
- 第一步（形状匹配）：对每把彩色钥匙，尝试所有 8 种旋转/翻转变换，找到与之外轮廓完全匹配的灰色锁。每把钥匙恰好匹配一把锁，一一对应。
- 第二步（填充孔洞）：对每个已匹配的锁，将其内部的所有黑色孔洞像素填充为对应钥匙的颜色。
- 钥匙本身从网格中移除（替换为黑色背景）。灰色锁的轮廓保持不变。

Key insight: 钥匙是锁的"无孔版本"——解题者必须先意识到钥匙与锁之间是"填满孔洞后的同形关系"，再通过旋转/翻转找到正确配对；最终操作是用钥匙颜色填充锁的孔洞，而非简单的叠放。
</description>

<description>
网格中有若干条彩色路径和若干个标记方块；每个标记方块的颜色和大小编码了一条"剪切指令"——将与方块同色的路径在方块所在位置剪断，并将被剪断的较短段按方块边长的距离沿路径方向平移。

Input structure:
- 背景为 black。若干条由不同颜色（如 red、blue、green、orange 等）构成的单像素宽正交折线路径（仅沿水平和垂直方向延伸，可以有直角拐弯），各路径颜色不同。
- 网格中还散布着若干由 maroon 像素构成的实心正方形方块（边长为 2 至 4 不等），每个方块紧贴（8-邻接）在某条彩色路径的某一段上。每个方块旁边（4-邻接方向上）恰好有一个与某条路径同色的单像素标记点，该标记点指示这个方块作用于哪条路径。

Rule:
- 第一步（指令解读）：对每个 maroon 方块，找到其 4-邻接方向上的彩色标记点，该标记点的颜色即为目标路径颜色。方块的边长 N 即为平移距离。
- 第二步（定位剪切点）：在目标颜色路径上，找到距离 maroon 方块最近的路径像素，该像素即为剪切点。
- 第三步（剪切与平移）：在剪切点处将路径断开为两段。较短的那一段沿路径在剪切点处的延伸方向（远离较长段的方向）平移 N 个像素。平移后的路径段用原色绘制；原位置处留下的空隙用黑色填充。
- 若两段等长，则移动方块标记点一侧的那段。
- maroon 方块和彩色标记点在输出中被移除（变为黑色）。

Key insight: 解题者需要分三层推理——先通过标记点颜色确定方块对应哪条路径（颜色匹配层），再理解方块边长编码平移距离（尺寸编码层），最后理解剪切位置和平移方向的确定方式（空间操作层）。
</description>

<description>
在网格中，若干彩色边框矩形内各有一个二值图案；底部图例行中的颜色方块编码了变换类型。规则是根据边框颜色查图例确定变换（翻转或旋转），对图案执行变换后填入右侧对应的空边框中。

Input structure:
- 背景为 black。网格中央有一条垂直的 grey 分隔线将网格分为左右两半。
- 左半部分包含若干彩色边框矩形（边框颜色各不相同，如 red、blue、green、yellow），每个矩形内部是一个由 black 和 orange 像素构成的二值图案。
- 右半部分包含同样数量的空边框矩形（内部全为 black），每个空边框的颜色与左侧某个边框颜色相同，形成一一配对。右侧边框的尺寸恰好容纳变换后的图案。
- 网格底部有一个"图例行"：依次排列若干 2×2 的彩色小方块，每种颜色代表一种变换操作。

Rule:
- 第一步（解码图例）：通过观察训练样例，归纳出每种边框颜色对应的变换类型。变换类型包括：水平翻转、垂直翻转、顺时针旋转 90°、逆时针旋转 90°。每种边框颜色始终对应同一种变换（跨样例一致）。
- 第二步（配对）：根据边框颜色将左侧图案与右侧空框一一匹配。
- 第三步（变换与填充）：对每个左侧图案执行其边框颜色指定的变换操作，将变换结果填入右侧对应的空边框中。若右侧边框更大，图案居中放置，多余空间保持 black。

Key insight: 最深层的推理在于"颜色-变换映射"需要跨多个训练样例才能确认——单个样例中一种颜色可能对应多种变换解释，只有通过多样例交叉验证才能锁定每种颜色的唯一变换含义。底部图例行的颜色出现顺序暗示了变换类型的对应关系，但这一对应本身需要从样例中归纳。
</description>

<new_puzzle>
<description>
在网格中，若干个由不同颜色填充的"容器"（矩形框）通过单像素宽的"管道"相连；每条管道上有一个彩色"阀门"像素。当阀门颜色与管道两端中恰好一个容器的填充色匹配时管道激活，两个容器的填充色发生交换。

Input structure:
- 背景为 black。若干个由 grey 像素构成的矩形空心框（容器），每个容器内部被统一填充为一种非黑非灰的颜色（如 red、blue、green、yellow 等），不同容器的填充色可能相同也可能不同。
- 容器之间通过 grey 像素构成的单像素宽正交折线管道相连。每条管道连接恰好两个容器（管道的两端分别接触两个不同容器的灰色边框）。
- 每条管道的中间某处有一个非灰非黑的彩色像素替代了原本的灰色管道像素，该像素即为"阀门"。

Rule:
- 第一步（识别结构）：找出所有容器、管道及管道上的阀门。确定每条管道连接的两个容器。
- 第二步（判断激活）：对每条管道，检查其阀门颜色是否与管道两端中恰好一个容器的填充色相同。若匹配则该管道"激活"；若阀门颜色与两端容器都不匹配、或与两端都匹配，则该管道不激活。
- 第三步（执行交换）：对所有激活的管道，同时交换其两端容器的填充色。即：若管道连接容器 A（红色填充）和容器 B（蓝色填充），且阀门为红色（匹配容器 A），则交换后容器 A 变为蓝色填充，容器 B 变为红色填充。
- 所有交换同时发生（不串联）。阀门像素、管道和容器边框保持不变。

Key insight: 解题者需要首先发现管道-阀门-容器的拓扑连接结构，然后独立归纳出"阀门颜色匹配恰好一端才激活"的非对称激活条件（这排除了"两端都匹配"的情况，增加了隐蔽性），最后理解交换是同时执行而非顺序传播。三层推理中，激活条件的精确规则最难从少量样例中确认。
</description>
</new_puzzle>
