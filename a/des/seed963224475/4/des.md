<description>
根据色带密码解锁框架内的隐藏图案，再将图案按框架缺口方向投射到外部。

Input structure:
- 背景为black。网格中散布若干不同颜色的空心矩形框架（边框宽度为1个像素），每个框架在某一侧边框上有一个1像素宽的缺口（缺口处为black）。
- 每个框架内部包含一个由grey像素组成的小图案（连通区域），该图案被部分像素遮盖——框架内部还散布着若干"干扰像素"，颜色与框架边框相同。
- 网格的一个边缘区域（例如最底部两行）是一条"色带密码"：由若干颜色方块组成的水平序列，每个方块为2x2大小，方块之间用black隔开。色带中出现的颜色与框架边框颜色一一对应。

Rule:
- 第一步（解码色带）：色带中颜色方块从左到右的排列顺序为1, 2, 3, ...。该序号决定每个框架内grey图案需要被旋转的次数（每次顺时针旋转90度）。例如色带中排第2位的颜色对应的框架，其内部图案需顺时针旋转180度。
- 第二步（清理与提取）：移除每个框架内部所有与框架边框同色的干扰像素，只保留grey图案。对该grey图案执行上一步确定的旋转。
- 第三步（投射）：将旋转后的图案沿框架缺口方向（上、下、左、右）向外平移投射，投射距离为图案在投射方向上的尺寸（即图案刚好"滑出"框架到达外部紧邻位置）。投射出的图案颜色改为对应框架的边框颜色。框架本身及其内部保持不变（干扰像素已被移除）。

Key insight:
解题者需要先从色带中读取颜色顺序来确定旋转量，再根据框架缺口方向确定投射方向——两步推理缺一不可且互不相关，必须独立归纳。色带的顺序编码旋转次数这一机制是隐蔽的，因为色带看似仅是颜色图例。
</description>
</new_puzzle>

<new_puzzle>
<description>
用种子像素的颜色在迷宫通道中"灌溉"，通道交叉处按优先级规则决定颜色归属，最终统计每种颜色占领的死胡同数量并在图例区显示。

Input structure:
- 背景为black。网格中有一个由grey像素构成的正交迷宫通道网络（通道宽度为1像素），通道之间由black墙壁分隔。
- 迷宫的若干死胡同末端各放置一个彩色"种子像素"（颜色各异，如red、blue、green、orange等），每种颜色恰好出现一次。
- 网格右侧有一列纵向排列的小空心方框（3x3，边框为grey），数量与种子颜色数量相同，从上到下排列，框内为black。

Rule:
- 第一步（灌溉扩散）：所有种子像素同时开始沿grey通道向外扩散（类似洪水填充），每一步扩散一格。种子像素将经过的grey通道格子染成自己的颜色。
- 第二步（交叉冲突解决）：当两种颜色在同一时间步到达同一个通道格子时，该格子归属于拥有更多已染色邻居（4-连通）的那个颜色。若邻居数相同，则该格子保持grey不被染色（成为"边界"）。
- 第三步（计数与图例填充）：扩散结束后，统计每种颜色占领了多少个死胡同（死胡同定义为仅有一个通道邻居的通道格子）。注意每种颜色的起始死胡同也计入自身。按占领死胡同数量从多到少的顺序，将颜色依次填入右侧图例方框中（从上到下），每个方框内部的1x1中心格子染上对应颜色。

Key insight:
表面上这道题看起来是简单的洪水填充，但关键隐蔽机制在于：冲突解决不是看"谁先到"（因为同时到达），而是看当前已染色邻居数——这要求解题者理解扩散的全局拓扑结构。最终的排序输出进一步增加了推理层次，因为需要先完成灌溉再统计死胡同归属。
</description>

<description>
识别每个彩色区域的"骨架方向"，然后沿垂直于骨架的方向为区域添加对称的条纹阴影。

Input structure:
- 背景为azure。网格中散布若干单色连通区域（4-连通），每个区域颜色不同（如red、green、yellow、maroon等），形状为不规则但大致呈细长条状（宽度2-3像素，长度5-8像素）。
- 每个区域旁边紧邻放置一个单独的grey像素，称为"阴影标记"。阴影标记位于区域的某一侧（上、下、左、右之一），与区域有且仅有一个像素相邻。
- 网格某个角落有一个2x2的"示范方块"：左上和右下为black，左下和右上为该方块所属颜色——这是条纹图案的模板（对角交替）。

Rule:
- 第一步（判定骨架方向）：对每个细长区域，判断其主要延伸方向（水平或垂直）。判定方法为：区域的外接矩形中，较长的边对应骨架方向。若外接矩形为正方形，则骨架方向为水平。
- 第二步（确定阴影方向与深度）：阴影标记相对于区域的方位（上/下/左/右）决定阴影投射方向。阴影的"深度"（即条纹延伸的格数）等于区域在骨架方向上的像素长度除以2（向下取整），最少为1。
- 第三步（绘制条纹阴影）：从区域的每个边缘像素出发，沿阴影方向依次绘制深度个像素。这些像素按照与起始边缘的距离交替使用两种颜色：奇数距离（1, 3, 5...）用区域本身的颜色，偶数距离（2, 4, 6...）用grey。若阴影像素与其他区域或其阴影重叠，后绘制的覆盖先绘制的。绘制顺序按区域面积从小到大。

Key insight:
骨架方向影响阴影深度，而阴影标记的位置决定阴影方向——这两个要素看似无关却共同决定输出。解题者容易将阴影标记误解为指示骨架方向，实际上二者是独立的维度。条纹的交替模式来自角落的示范方块，需要解题者将一个远离区域的全局模板与局部操作关联起来。
</description>

<description>
将散落的拼图碎片按照边缘锯齿的凹凸互补关系拼合到目标框架内，并根据碎片重叠区域的颜色混合规则确定最终颜色。

Input structure:
- 背景为black。网格分为左右两个区域，由一条竖直的grey分隔线隔开。
- 左侧区域包含一个由grey像素构成的矩形空框架（内部为black），框架内壁上有若干突出的1像素"凸齿"（向内突出，颜色为grey）和凹陷的1像素"凹槽"（边框缺失一格）。
- 右侧区域散布着2-4个小的彩色矩形碎片（每个碎片为单一颜色，如red、blue、green、orange）。每个碎片的边缘也有凸齿和凹槽，凸齿颜色与碎片主体相同。碎片的尺寸小于框架内部空间。

Rule:
- 第一步（边缘匹配）：每个碎片必须被放入框架内部。碎片的某一条边必须紧贴框架内壁，且碎片边缘的凸齿必须恰好嵌入框架内壁的凹槽中，框架内壁的凸齿必须恰好嵌入碎片边缘的凹槽中（凹凸互补）。每个碎片只有一种合法的位置和朝向（可能需要旋转90度的倍数）。
- 第二步（放置碎片）：将匹配成功的碎片放入框架对应位置。碎片像素覆盖框架内部的black区域。碎片的凸齿像素填入框架凹槽中（替换black为碎片颜色），框架的凸齿像素保持grey不变。
- 第三步（重叠处理）：若两个碎片放置后存在重叠像素，重叠区域的颜色变为maroon（表示"混合"）。非重叠部分保持各自碎片颜色。

Key insight:
解题者需要像拼实体拼图一样进行空间凹凸匹配——这不是简单的位置对齐，而是需要检查每个碎片的锯齿轮廓与框架内壁锯齿是否互补。旋转碎片增加了搜索空间，而重叠变色规则增加了第三层推理。
</description>

<description>
根据"信号塔"的高度和颜色，在网格上生成扇形广播区域；信号被墙壁阻挡后在墙壁另一侧产生"阴影盲区"，最终未被任何信号覆盖的区域标记为特殊颜色。

Input structure:
- 背景为black。网格底部有一条水平的grey基准线，贯穿整个网格宽度。
- 基准线上方竖立着若干"信号塔"：每座塔是一列从基准线向上延伸的同色像素柱（颜色各异，如red、blue、green、orange），高度从2到6不等。
- 网格中散布若干单独的maroon像素作为"墙壁"，不与任何信号塔相邻。

Rule:
- 第一步（确定广播范围）：每座信号塔以其顶部像素为中心，向左上和右上两个对角方向发射信号射线。左侧射线沿左上方45度延伸，右侧射线沿右上方45度延伸。两条射线之间（包含射线本身）的所有格子构成该塔的"广播扇区"。射线延伸长度等于塔的高度（像素数）。扇区内所有black格子被染成该塔的颜色。
- 第二步（墙壁遮挡）：若射线路径上遇到maroon墙壁像素，射线在该点停止。墙壁正后方（沿射线方向继续延伸的区域）形成"阴影"——该阴影区域内如果之前被染色，则恢复为black。阴影区域的宽度为1列，长度为射线剩余的未走完距离。
- 第三步（盲区标记）：所有步骤完成后，基准线上方仍为black的格子（不包括maroon墙壁本身）被标记为yellow，表示"信号盲区"。

Key insight:
塔的高度同时决定了射线长度和扇区宽度，这一双重作用使得高塔的覆盖面积呈非线性增长——解题者需要领悟高度与面积的几何关系而非简单线性对应。墙壁的遮挡效果需要沿射线方向追踪，这要求解题者理解遮挡是方向性的而非全向的。最终的盲区标记将前两步的结果整合为一个可视化判断。
</description>

<new_puzzle>
<description>
通过"传送门"配对将对象从一个封闭房间搬运到另一个房间，对象在传送过程中根据目标房间的形状约束被裁剪或填充。

Input structure:
- 背景为black。网格中有若干由blue像素围成的封闭矩形"房间"（内部为black），房间之间不重叠不相邻。
- 每个房间的边框上恰好有两个非blue的彩色像素——这是"传送门"。传送门总是成对出现在不同房间上：两个相同颜色的传送门像素构成一对（如两个red传送门连接两个房间，两个green传送门连接另外两个房间），每对颜色只出现两次。
- 部分房间内部包含由grey像素组成的小图案（连通区域），部分房间内部为空（纯black）。每对传送门恰好连接一个有图案的房间和一个空房间。

Rule:
- 第一步（配对传送门）：找出所有同色传送门对，确定每对连接的两个房间（一个含图案，一个为空）。
- 第二步（确定传送朝向）：图案从有图案的房间通过传送门传送到空房间。传送门在源房间边框上的位置（上/下/左/右边框）决定图案的"出射方向"，传送门在目标房间边框上的位置决定图案的"入射方向"。图案需要旋转使得出射方向旋转到入射方向的对面（例如从源房间右边框出射，从目标房间左边框入射，则图案不旋转；若从右边框出射、上边框入射，图案顺时针旋转90度）。
- 第三步（裁剪与放置）：旋转后的图案以目标房间传送门像素在房间内壁的相邻格子为锚点放置。如果图案超出目标房间内部边界，超出部分被裁剪掉。传送后的图案颜色从grey变为传送门的颜色。

Key insight:
解题者必须先通过颜色匹配找到传送门对，再通过传送门在各自房间边框上的相对位置推断旋转量——这种"出射-入射方位差决定旋转"的机制是核心隐蔽洞见。裁剪规则使得目标房间的大小成为影响输出的隐含约束，不同样例中房间大小的变化会帮助解题者发现这一规则。
</description>

<new_puzzle>
<description>
在双层网格中执行"编织"操作：根据交叉点的标记颜色决定哪条带在上、哪条带在下，最终用遮挡关系决定每个交叉像素的可见颜色。

Input structure:
- 背景为black。网格中有若干水平条带和若干竖直条带，每条带宽度为1像素，各条带颜色互不相同（使用red、blue、green、orange、yellow、maroon等颜色）。
- 水平条带和竖直条带在网格中形成若干交叉点。每个交叉点处恰好有一个小标记：该标记位于交叉点的右下方对角邻居位置（即交叉点坐标为(r,c)，标记在(r+1,c+1)处），标记颜色为azure或magenta之一。
- 条带的非交叉部分正常显示为条带自身颜色。

Rule:
- 第一步（读取编织指令）：每个交叉点右下角的标记决定交叉处的上下关系。azure标记表示"水平在上"（交叉点显示水平条带颜色），magenta标记表示"竖直在上"（交叉点显示竖直条带颜色）。
- 第二步（验证编织合法性）：沿每条水平条带从左到右依次检查其各个交叉点：该条带的上下状态必须严格交替（上-下-上-下...或下-上-下-上...），如同真实编织。如果输入中的标记已经满足交替规律，则直接使用；如果某个标记打破了交替规律，则翻转该标记（azure变magenta或反之）以恢复交替。
- 第三步（渲染交叉点）：根据最终确定的上下关系，每个交叉点像素显示"在上"的那条带的颜色。移除所有右下角的标记像素（标记位置恢复为black）。

Key insight:
标记颜色看似直接决定了遮挡关系，但实际上存在"编织合法性修正"这一隐蔽层——解题者必须先注意到真实编织的交替约束，才能理解为什么某些交叉点的输出颜色与标记指示不一致。标记中故意设置的少量"错误"迫使解题者发现交替规律而非简单查表。
</description>
</new_puzzle>
