<description>
根据框架内部的彩色锚点匹配外部图案模板，将模板旋转对齐后填入框架，再依据锚点颜色对模板进行重新着色。

Input structure:
- bg = 最常见颜色（黑色）。
- 网格中散布若干用 grey 绘制的空心矩形框架（边框宽度为1像素），每个框架内部恰好有两个不同颜色的单像素锚点，分别位于框架内部的不同角落位置（如左上与右下、左下与右上等）。
- 网格中另有若干独立的小型图案模板（由两种颜色绘制的连通区域，尺寸恰好等于某个框架的内部空间大小）。每个模板中也恰好包含两个特殊像素，其颜色与某个框架内部的两个锚点颜色一一对应。

Rule:
- 第一步（匹配）：通过锚点颜色对将每个模板与对应的框架配对——模板中的两个特殊像素颜色必须与框架内两个锚点颜色完全一致（不计顺序）。
- 第二步（对齐旋转）：将模板旋转（0°/90°/180°/270°），使得模板中两个特殊像素的相对位置与框架内两个锚点的相对位置完全吻合。
- 第三步（重新着色）：将旋转后的模板放入框架内部。模板中原本用第一种绘制色画的像素全部改为框架内第一个锚点的颜色，第二种绘制色画的像素全部改为第二个锚点的颜色。两个特殊像素保持锚点颜色不变。
- 输出时框架、填充后的内部以及背景均保留，原始位置的独立模板被清除（变为 bg）。

Key insight: 锚点同时承担三重功能——配对键、旋转参照、以及着色映射源，解题者必须先识别颜色配对，再推断旋转方向，最后理解颜色替换规则，构成三层递进推理。
</description>

<description>
将网格中的多条彩色"传送带"上的货物块按传送带方向滑动，货物在交叉路口根据优先级规则换乘到另一条传送带。

Input structure:
- bg = 黑色。
- 网格中有若干条用不同颜色绘制的单像素宽直线段（水平或垂直），代表"传送带"。每条传送带的一端有一个同色的 2x1 或 1x2 的加粗端头，表示传送方向（从无端头端指向有端头端）。
- 传送带之间存在交叉点（两条不同颜色的传送带共享的像素位置），交叉点处的颜色为其中一条传送带的颜色。
- 传送带上散布着若干用 yellow 绘制的 1x1 货物块。

Rule:
- 每个货物块沿其所在传送带的方向滑动，直到遇到以下三种情况之一停止：(a) 到达传送带端头（货物停在端头前一格）；(b) 被另一个已停止的货物阻挡（停在该货物前一格）；(c) 到达交叉路口。
- 在交叉路口：货物离开当前传送带，转入交叉的另一条传送带，沿新传送带的方向继续滑动。交叉点像素的颜色指示"优先传送带"——如果货物已经在优先传送带上，则不换乘，直接通过交叉点继续前行。
- 所有货物同时开始移动；处理顺序为：离各自传送带端头最近的货物优先处理（先到先停）。
- 输出网格中传送带和端头保持不变，货物块出现在最终停止位置，原始位置变为传送带颜色。

Key insight: 交叉点颜色不仅是视觉装饰，而是决定货物是否换乘的优先级信号；解题者需要先理解传送带方向（端头位置），再理解交叉点的换乘规则，两层规则叠加决定最终位置。
</description>

<description>
在网格中识别由边框颜色编码的"容器-筛子"配对关系，将容器内的彩色像素通过筛子的孔洞模式过滤后投射到输出区域。

Input structure:
- bg = 黑色。
- 网格中有若干个用纯色绘制的空心矩形"容器"（边框宽1像素），内部填有由多种颜色组成的图案。
- 网格中另有若干个相同尺寸的空心矩形"筛子"，边框颜色与某个容器的边框颜色相同（形成配对）。筛子内部大部分为 bg，但在某些位置有 grey 像素，形成"孔洞图案"。
- 网格底部有一排与容器/筛子内部等宽等高的空白区域（全为 bg），用 azure 细线分隔，数量等于配对数。

Rule:
- 第一步（配对）：通过边框颜色将每个容器与对应的筛子配对。
- 第二步（过滤）：将筛子叠加在配对的容器上（对齐内部区域）。容器内部中，只有与筛子 grey 孔洞位置重合的像素被保留，其余位置变为 bg。
- 第三步（投射）：将过滤结果写入底部对应的空白区域中，按配对顺序从左到右排列。
- 容器和筛子在输出中被清除（变为 bg），仅保留底部的过滤结果。

Key insight: 边框颜色是隐含的配对键而非装饰；筛子的 grey 像素充当空间掩码而非填充物——解题者必须先发现配对机制，再理解"孔洞=保留、空白=丢弃"的反直觉过滤逻辑。
</description>

<description>
根据种子像素的扩散规则在分区网格中生长色块，色块的生长形状由该分区边界上缺口的位置和数量共同决定。

Input structure:
- bg = 黑色。
- 网格被 green 单像素线条分割为若干大小相等的矩形分区（如同棋盘格状的网格线）。
- 每个分区内部恰好有一个彩色种子像素（非 bg、非 green），位于分区内部的某个位置。
- 每个分区的 green 边界上有若干处缺口（边界线被擦除1像素宽），缺口位于四条边上的不同位置。

Rule:
- 第一步（确定生长方向）：每个分区的缺口指示该分区内色块的生长方向。如果缺口在分区的上边界，则色块从种子位置向上扩展；缺口在右边界则向右扩展，以此类推。一个分区可以有多个缺口，色块同时向所有缺口对应的方向扩展。
- 第二步（确定生长长度）：从种子像素出发，沿每个生长方向填充种子颜色的像素，一直延伸到该方向的分区边界为止（即填满种子到边界之间的所有 bg 像素）。
- 第三步（缺口连通）：生长到达缺口位置时，色块穿过缺口进入相邻分区，但只延伸1个像素到相邻分区内（覆盖缺口对面的那个像素）。
- 种子像素本身保留，green 边界线（含缺口）保持不变。

Key insight: 缺口不只是装饰性的边界破损，而是编码了生长方向的指令信号；解题者需要先将缺口位置与生长方向建立对应关系，再理解生长范围的两层规则（区内填满 + 跨区仅延伸1格），形成"方向编码→区内扩展→跨区渗透"的三层推理链。
</description>
</new_puzzle>

<description>
在包含多个嵌套环的同心结构中，根据环的层级关系和颜色标记规则，将内层环的图案"展开"复制到外层环的对应边上。

Input structure:
- bg = 黑色。
- 网格中有若干组同心矩形环结构。每组由2至3层嵌套的不同颜色空心矩形环组成（边框宽1像素），环与环之间间隔1像素的 bg 间隙。
- 最内层环的内部填充了一个由某种颜色绘制的小型图案（连通的非 bg 像素组成的形状）。
- 每层环的四条边中，恰好有一条边上嵌有一个 red 单像素标记（替换该边上某个像素）。

Rule:
- 第一步（识别展开方向）：每层环上 red 标记所在的边指示"展开方向"——内层环的图案将被复制到该边的外侧方向。
- 第二步（逐层展开）：从最内层开始向外处理。取最内层环内部的图案，将其沿最内层环 red 标记所在边的法线方向平移，放置到最内层环与次外层环之间的间隙中（图案的参考点对齐到 red 标记的位置）。
- 第三步（颜色继承）：被复制的图案不保留原色，而是改为它被放入的那一层间隙的外层环的颜色。
- 第四步（递归）：将刚放好的图案视为新的"内部图案"，继续按次外层环的 red 标记方向展开到下一层间隙，颜色改为更外层环的颜色。重复直到所有层处理完毕。
- 原始最内层图案保留不变，所有环结构保持不变，red 标记也保留。

Key insight: red 标记编码展开方向，每一层可能指向不同方向，形成折叠路径；颜色继承规则使得同一个图案在不同层呈现不同颜色——解题者必须理解"方向由标记决定、颜色由目标层决定"这一双重映射，并掌握从内到外的递归展开顺序。
</description>

<description>
将散落的单色碎片拼入目标轮廓中，拼入位置由碎片边缘的彩色接口像素与轮廓内壁的同色接口像素对齐决定。

Input structure:
- bg = 黑色。
- 网格中有一个用 grey 绘制的大型封闭轮廓（边框宽1像素），内部大部分为 bg，但在内壁的某些位置嵌有彩色单像素标记（每个标记颜色各不相同，如 red、blue、orange 等）。
- 网格中另有若干个用 grey 绘制的小型单色碎片（连通的 grey 像素块），每个碎片的边缘恰好有一个彩色单像素标记，颜色与轮廓内壁某个标记颜色相同。
- 每个碎片的形状恰好能嵌入轮廓内部的某个 bg 区域（碎片的 grey 像素与轮廓的 grey 边框不重叠）。

Rule:
- 第一步（颜色配对）：将每个碎片通过其彩色标记与轮廓内壁的同色标记配对。
- 第二步（对齐放置）：平移碎片（不旋转、不翻转），使碎片上的彩色标记像素恰好与轮廓内壁上的同色标记像素在四邻域方向上相邻（碎片标记紧贴轮廓标记的外侧）。此对齐方式唯一确定碎片位置。
- 第三步（写入）：将碎片的 grey 像素写入轮廓内部对应位置。碎片上的彩色标记像素也写入。轮廓内壁上的彩色标记保留。
- 输出中原始碎片位置被清除为 bg，轮廓和拼入的碎片构成完整图形。

Key insight: 彩色接口像素同时编码了三种信息——配对身份（哪个碎片对应哪个位置）、对齐锚点（碎片放在哪里）、以及朝向约束（标记必须紧邻而非重叠）。解题者需要先发现颜色配对关系，再推断"相邻而非重叠"的精确对齐规则。
</description>

<new_puzzle>
<description>
在网格中根据"钥匙-锁"色环匹配关系解锁门扉，门扉打开后走廊连通，并将钥匙的主色传播到新连通的走廊段中。

Input structure:
- bg = 黑色。
- 网格中有若干条用 grey 绘制的单像素宽走廊（水平或垂直直线段），走廊之间被"门扉"阻断。门扉是走廊上的一个 2 像素宽的彩色线段（颜色非 grey、非 bg），将走廊截断为不连通的两段。
- 在网格的边缘区域散布着若干"钥匙"：每把钥匙是一个 3x3 的小方块，中心为 bg，外圈8个像素中有若干个彩色像素形成独特的颜色环图案。
- 每个门扉的两侧（沿走廊方向紧邻门扉的两个像素）各有一个彩色像素，这两个像素加上门扉本身的颜色构成该门的"锁色环"（共三种颜色）。

Rule:
- 第一步（识别锁色环）：对每个门扉，收集门扉自身的颜色以及紧邻两侧的颜色像素，组成一个三色集合（无序）。
- 第二步（匹配钥匙）：在所有钥匙中找到色环中恰好包含相同三种颜色的那把钥匙。每把钥匙恰好匹配一个门扉。
- 第三步（解锁）：被匹配的门扉被"打开"——门扉的2个像素变为 grey（与走廊融为一体），门扉两侧的彩色像素也变为 grey。这使得被截断的走廊段重新连通。
- 第四步（颜色传播）：每把使用过的钥匙中，外圈8个像素里出现次数最多的颜色作为"激活色"。所有通过该钥匙解锁而新连通的走廊段被重新着色为该激活色。
- 未被匹配的门扉保持不变；钥匙在输出中被清除为 bg。

Key insight: 门扉的"锁"不仅仅是门本身的颜色，而是由门及其两侧邻居共同构成的三色集合；钥匙的3x3环形图案编码了同样的三色集合但以不同的空间排列呈现——解题者需要跨越空间表征差异识别颜色集合的等价性，然后理解解锁后的连通性变化和颜色传播规则。
</description>
</new_puzzle>
