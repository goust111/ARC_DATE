<description>
根据边框颜色匹配内外图案对，再按外部箭头指示的方向将外部图案"印章式"盖入对应边框内部的空白区域。

Input structure:
- bg = 最常见颜色。
- 若干彩色矩形边框（每个边框颜色不同），内部填充 bg，形成空白区域。
- 每个边框外部的网格中存在一个与该边框同色的小型图案（由若干像素组成的连通形状）。
- 每个外部图案旁有一个由同色像素组成的箭头标记（三像素 L 形：一个中心像素加两个相邻像素，其中一个位于中心的正上/正下/正左/正右方向，另一个位于中心像素沿该方向的下一格，形成指向该方向的箭头）。箭头方向为上、下、左、右之一。

Rule:
- 第一步：通过颜色匹配，将每个外部图案与其同色边框配对。
- 第二步：读取该图案旁箭头的朝向，确定印入方向。
- 第三步：将外部图案平移到边框内部，使其紧贴箭头所指方向的对面那条边框内壁。例如箭头指向右，则图案贴靠边框内部的左侧内壁；箭头指向下，则图案贴靠边框内部的顶部内壁。图案在垂直于印入方向的轴上居中放置。图案印入后颜色保持不变。

Key insight: 边框颜色是配对的钥匙，箭头方向决定图案在边框内的停靠位置——箭头指向哪边，图案就从那边"推入"并贴靠对面的墙壁。
</description>

<description>
在网格中识别由墙壁分隔的多个房间，根据每个房间内散落标记像素的颜色种类数选择对应的填充纹理模板，再用该模板平铺填充整个房间。

Input structure:
- bg = 最常见颜色。
- 一种墙壁颜色（如 grey）将网格划分为若干封闭矩形房间。
- 网格的一个角落区域（与主网格被墙壁隔开）包含若干纹理模板：每个模板是一个小型矩形图案（例如 2x2 或 3x3），模板之间用墙壁颜色分隔，模板从左到右编号为 1、2、3……
- 每个房间内部散布着少量非 bg、非墙壁颜色的标记像素（颜色各异）。

Rule:
- 第一步：数出每个房间内标记像素包含多少种不同颜色，得到数字 N。
- 第二步：从角落的模板区中选取第 N 个模板（从 1 开始计数）。
- 第三步：用该模板从房间左上角开始平铺填充整个房间内部（覆盖原有标记像素和 bg），平铺时模板按行列周期重复。墙壁保持不变。

Key insight: 标记像素本身的位置和具体颜色不影响结果，只有颜色的种类数才是选择模板的索引；模板区的排列顺序就是索引顺序。
</description>

<description>
在散布有彩色种子像素的网格中，每颗种子向四个正方向生长出与其颜色相同的线段，线段长度由该种子所在象限决定；当两条不同颜色的生长线段相交时，交点变为指定的第三种颜色。

Input structure:
- bg = 最常见颜色。
- 网格中央有一条水平分割线和一条垂直分割线（均为同一种颜色，如 grey），将网格分为四个象限。
- 四个象限的四个角落（即网格的四个角）各有一个小色块标记，色块由 maroon 像素构成，形状为水平或垂直短线段，其像素数量即为该象限的"生长长度" L（通常为 1-4）。
- 各象限内散布着若干非 bg、非 grey、非 maroon 的彩色种子像素。

Rule:
- 第一步：识别四个象限，读取每个象限角落 maroon 色块的像素数量，该数即为该象限的生长长度 L。
- 第二步：每颗种子像素向上、下、左、右四个方向各延伸 L 格（不越过分割线和网格边界），延伸像素颜色与种子相同。
- 第三步：若两条不同颜色的线段在同一格重叠，该格变为 yellow。若同色线段重叠则保持该颜色不变。

Key insight: 解题者必须先发现象限角落 maroon 色块的像素数量编码了该象限的生长长度，再发现不同色交叉点的变色规则——两层独立的归纳缺一不可。
</description>

<new_puzzle>
<description>
将网格中的多组"源-管道-容器"结构识别出来，源的颜色决定填充色，管道中的拐弯次数决定容器内填充的层数，填充从容器底部向上逐层叠加。

Input structure:
- bg = 最常见颜色。
- 若干组独立结构，每组包含三部分：
  - 源：一个纯色小方块（如 2x2），颜色各异（如 red、blue、green 等）。
  - 管道：从源出发的一条单像素宽的 grey 路径（仅沿水平或垂直方向延伸），路径可以有若干直角拐弯。
  - 容器：管道末端连接一个由 grey 像素构成的矩形空心框，内部为 bg。
- 每组结构互不接触。

Rule:
- 第一步：追踪每条 grey 管道，从源端到容器端，数出管道的直角拐弯次数 K。
- 第二步：在对应容器内部，从底部向上填充 K 层像素行，填充颜色为该组源方块的颜色。若 K 超过容器内部高度，则填满整个容器内部。
- 第三步：管道和源保持不变，容器边框保持不变。

Key insight: 管道不仅是连接线索（用于配对源与容器），其弯折次数还编码了填充量——解题者必须同时发现配对关系和计数规则。
</description>
</new_puzzle>

<new_puzzle>
<description>
根据环形围栏内缺口的朝向对围栏内的形状进行镜像翻转，翻转轴由缺口方向决定；围栏外的同色指示条决定翻转后形状的重新着色。

Input structure:
- bg = 最常见颜色。
- 若干个由单一颜色像素构成的环形围栏（近似正方形环，边长约 5-7），每个围栏在某一条边上有一个单像素宽的缺口。不同围栏颜色不同。
- 每个围栏内部包含一个由另一种颜色绘制的小型非对称形状（该颜色所有围栏内统一，如 orange）。
- 网格边缘（上、下、左、右四条边）上贴着若干短彩色线段（长度 2-4 像素），每条线段的颜色与某个围栏的颜色相同，且每个围栏颜色恰好对应一条边缘线段。

Rule:
- 第一步：确定每个围栏缺口所在的边（上、下、左、右）。缺口在上或下时，翻转轴为水平轴（上下翻转）；缺口在左或右时，翻转轴为垂直轴（左右翻转）。
- 第二步：将围栏内部的形状沿该轴在围栏内部进行镜像翻转（以围栏内部区域中心为翻转参考点）。
- 第三步：找到与该围栏同色的边缘线段，读取该线段所贴靠的网格边（上/下/左/右）。根据训练样例归纳出每个方位对应的着色颜色（例如上边 → red，下边 → blue，左边 → green，右边 → magenta，具体映射从训练样例中归纳），将翻转后的形状重新涂为该方位对应的颜色。

Key insight: 解题包含三层独立推理：缺口位置决定翻转轴方向是第一层；围栏颜色与边缘线段配对是第二层；边缘线段所在的网格边决定着色是第三层。三层规则需要同时归纳才能还原输出。
</description>
</new_puzzle>

<new_puzzle>
<description>
在包含多个大小不一的同色方块的网格中，以最大方块为"母版"，将其他小方块视为"印记"，根据小方块在母版上的相对投影位置，在母版内部对应区域挖去与小方块等大的孔洞；同时，每个小方块内部填入母版对应位置原有的像素图案。

Input structure:
- bg = 最常见颜色。
- 一个最大的彩色实心正方形方块（如 red，边长 6-10），视为母版。
- 若干较小的同色（与母版颜色相同）实心正方形方块，散布在网格各处。每个小方块的边长严格小于母版。
- 母版内部可能已经包含若干不同颜色的装饰像素（形成某种图案）。

Rule:
- 第一步：识别母版（最大的该颜色方块）和所有同色小方块。
- 第二步：对每个小方块，计算它的中心相对于母版中心的偏移向量（行偏移, 列偏移）。
- 第三步：在母版内部，以母版中心加上该偏移向量为中心，挖去一个与该小方块等大的矩形区域（将这些像素变为 bg）。
- 第四步：在小方块的位置上，将小方块内的像素替换为母版中被挖去区域原本的像素图案（包括装饰像素和母版底色）。
- 效果如同小方块与母版中对应位置进行了"内容交换"。

Key insight: 小方块的空间位置不是随意的——它与母版之间的偏移向量恰好指示了母版内需要交换的区域位置，形成了一种"远程像素交换"机制。
</description>

<new_puzzle>
<description>
在网格中找到散布的彩色像素对，每对同色像素之间用该颜色画直线连接；连线经过的每个已有异色像素会"激活"并向垂直于连线的方向复制扩展，扩展长度等于该异色像素到连线较近端点的格数。

Input structure:
- bg = 最常见颜色。
- 若干对同色像素，每对恰好共享同一行或同一列（即可通过水平或垂直直线连接）。不同对颜色不同。
- 在某些对的连线路径上，存在少量不同颜色的单独像素（这些像素不属于任何同色对）。

Rule:
- 第一步：识别所有同色像素对（每种非 bg 颜色恰好出现两个像素的为"连接色"）。对于每对，在它们之间画一条该颜色的水平或垂直直线（包含两端点之间的所有格子）。
- 第二步：检查每条连线路径上是否存在异色像素。若连线为水平线且经过一个异色像素 P，则 P 向上和向下各延伸，延伸长度等于 P 到这条连线较近端点的距离（格数，即 P 与较近端点之间的像素间隔数）。延伸像素颜色与 P 相同。若连线为垂直线，则 P 向左和向右延伸，规则相同。
- 第三步：连线绘制时覆盖路径上的 bg 像素和异色像素（异色像素原始位置被连线颜色覆盖），但异色像素产生的垂直延伸副本保留。

Key insight: 连线本身的规则是显然的（同色配对连线），但异色像素的"激活扩展"规则需要从样例中归纳——扩展方向垂直于连线，扩展长度由位置编码，这构成第二层推理。
</description>
</new_puzzle>
