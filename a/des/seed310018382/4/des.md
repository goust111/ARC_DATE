<new_puzzle>
description: 根据封闭区域内部散落标记像素的颜色，从色带图例中查找对应填充色，再按区域面积从大到小的顺序将各区域重新排列为紧凑的水平条带。

Input structure:
- bg = black。网格上方有一条水平色带图例，由若干相邻的 1x2 色块组成，每个色块左侧像素为"标记色"，右侧像素为"填充色"，色块之间用 grey 像素分隔。
- 网格中下部有若干用 grey 线段围成的封闭矩形区域（边框为 grey，内部为 bg）。每个矩形区域内部散落着 1-3 个同色的单像素标记点，标记点的颜色各区域各不相同，且每种标记色都能在图例中找到对应条目。
- 各封闭矩形大小不等（宽高各异），且彼此不重叠。

Rule:
- 第一层推理：对每个封闭矩形区域，识别其内部标记点的颜色，然后在色带图例中找到该标记色对应的填充色。
- 第二层推理：用查得的填充色完全填满该矩形区域的内部（覆盖标记点与 bg），边框保持 grey 不变。
- 第三层推理：将所有已填充的矩形区域按面积（内部像素数）从大到小排序，然后从输出网格左上角开始，逐个水平紧邻排列（矩形之间共享 grey 边框线）。若水平放不下则换行，行间也共享 grey 边框线。输出网格大小恰好容纳所有排列后的矩形。
- 图例行不出现在输出中。

Key insight: 标记像素不是装饰而是查表键——必须先通过图例将标记色转换为填充色，再按面积排序重排，三步推理缺一不可。
</new_puzzle>

<new_puzzle>
description: 将网格中的彩色"种子"像素沿其所在框架的缺口方向生长为与框架同形的缩小副本，生长长度由同色种子的数量决定。

Input structure:
- bg = black。网格中有若干不同颜色的矩形空心框架（边框宽 1 像素），每个框架在四条边之一上恰好有一个 1 像素宽的缺口（缺口位置各框架不同，可能在上/下/左/右边的中点处）。
- 每个框架内部散落着若干同色的单像素"种子"，种子颜色与框架颜色不同，且同一框架内所有种子颜色相同；不同框架内的种子颜色各不相同。
- 框架外部没有任何非 bg 像素。

Rule:
- 第一层推理：对每个框架，定位其缺口所在边及缺口位置，确定"生长方向"为从缺口向框架外部延伸的方向。
- 第二层推理：数出该框架内部种子像素的数量 N。
- 第三层推理：以缺口为起点，沿生长方向在框架外部绘制该框架形状的等比缩小副本——副本的长边长度等于 N，短边按原框架宽高比四舍五入取整（至少为 1）。副本使用种子的颜色绘制，同样是空心框架。副本的位置使其靠近缺口一侧的边与缺口对齐。
- 原框架及其内部种子保持不变。

Key insight: 缺口既编码了生长方向，种子数量又编码了副本尺寸——解题者必须同时识别方向信号和计数信号，并将二者结合才能确定输出。
</new_puzzle>

<new_puzzle>
description: 在棋盘状分区网格中，根据每个分区内"指针"三角形的朝向，从相邻分区"借入"颜色来重绘自身边框。

Input structure:
- bg = black。网格被 grey 线均匀分割为 NxM 个大小相同的正方形分区（例如每个分区 5x5，分区之间共享 grey 分隔线）。
- 每个分区内部包含：(a) 一个由某颜色绘制的 3 像素等腰直角三角形"指针"，其直角顶点位于分区中心，斜边朝向上/下/左/右四个方向之一（即三角形的尖端指向某个相邻分区）；(b) 分区的四条内边框各用不同颜色绘制（上、下、左、右各一种颜色，颜色紧贴 grey 分隔线内侧一圈）。
- 三角形指针的颜色与该分区所有边框颜色不同。

Rule:
- 第一层推理：识别每个分区内三角形指针的朝向——三角形尖端（斜边中点）所指的方向即为"借入方向"。
- 第二层推理：沿借入方向找到相邻分区。取相邻分区中与借入方向相对的那条边框的颜色（例如指针向右，则取右邻分区的左边框颜色）。
- 第三层推理：用借入的颜色替换当前分区指针所指方向那条边框的颜色。同时擦除三角形指针（改为 bg）。边界处若指针指向网格外部，则该分区的对应边框改为 bg。
- 其余边框保持原色不变。

Key insight: 三角形的几何朝向是一个间接引用——它不指示"做什么"，而是指示"从哪里取信息"；解题者需要先解码方向，再跨分区查色，最后执行替换，三步推理形成链式依赖。
</new_puzzle>

<new_puzzle>
description: 将散落的彩色像素"信号源"沿管道网络传播，在管道交叉点按叠加规则混色，最终给每段管道末端的容器染上正确的混合色。

Input structure:
- bg = black。网格中有若干由 grey 像素绘制的单像素宽直线管道（水平或垂直），管道之间可在交叉点以十字形交叉（交叉点为 grey）。
- 管道的某些末端（dead-end，即只有一个 grey 邻居的端点）紧邻一个 3x3 的空心 grey 小方框（"容器"），容器内部为 bg。
- 管道的另一些末端紧邻一个单像素的彩色点（"信号源"），信号源颜色各不相同，取自 {red, blue, yellow} 三种基色。
- 每条管道段（两个端点/交叉点之间的直线部分）不超过 15 像素长。

Rule:
- 第一层推理：识别管道网络的拓扑——哪些管道段在哪些交叉点连接，哪些末端有信号源，哪些末端有容器。
- 第二层推理：每个信号源向其所连管道注入自己的颜色。颜色沿管道传播，在交叉点处继续向所有分支扩散。
- 第三层推理：如果一个容器能从管道网络中接收到多个不同信号源的颜色，则进行混色：red + blue = magenta，red + yellow = orange，blue + yellow = green，三色全到 = grey。若只收到一种颜色则直接使用该颜色。
- 输出：所有管道和信号源保持不变；每个容器的内部（1x1）填上其接收到的混合颜色。

Key insight: 管道网络的分支拓扑决定了哪些信号源能到达哪些容器——解题者必须追踪每条路径的连通性，再在终点执行直觉性的颜色混合，两层推理相互独立但缺一不可。
</new_puzzle>

<new_puzzle>
description: 将网格中由不同颜色线段围成的"房间"内部的家具图案，按照房间之间"门"的连通关系进行传递——每个房间将自己的图案复制到所有与之直接相连的邻居房间，多个来源重叠时取后传入者覆盖先传入者。

Input structure:
- bg = black。网格由不同颜色的单像素宽线段分隔成若干矩形"房间"。每两个相邻房间之间的共享墙段上可能有一个 1 像素的缺口（"门"），也可能没有。
- 每个房间内部要么包含一个由 maroon 像素绘制的小型图案（如 L 形、十字形、T 形等，占据 3-5 个像素），要么为空（纯 bg）。包含图案的房间称为"源房间"，空房间称为"目标房间"。
- 图案总是位于源房间内部的中心位置。
- 网格中有 2-4 个源房间和 2-4 个目标房间。

Rule:
- 第一层推理：识别房间之间的连通关系——两个房间通过门相连当且仅当它们共享的墙段上存在缺口。构建房间连通图。
- 第二层推理：对于每个目标房间，找到所有通过门与之直接相连的源房间。如果只有一个相连的源房间，则将该源房间的 maroon 图案复制到目标房间中心。如果有多个相连的源房间，则按源房间到目标房间的门的位置从上到下、从左到右的顺序，依次复制图案——后复制的覆盖先复制的（像素级覆盖）。
- 第三层推理：复制到目标房间后，图案的颜色从 maroon 改为目标房间墙壁的颜色。源房间内的原始图案保持 maroon 不变。
- 没有门连接的目标房间保持为空。

Key insight: 门的位置不仅决定了连通性，还在多源重叠时决定了覆盖顺序——解题者必须先建立空间连通图，再理解覆盖优先级规则，最后执行颜色转换，三层推理环环相扣。
</new_puzzle>

<new_puzzle>
description: 识别网格中由不同颜色线段围成的多边形区域，根据每个区域边框上"门"（缺口）的数量选择对应的填充图案（来自图案库），再按门的位置旋转图案后填入。

Input structure:
- bg = black。网格下方有一行"图案库"：从左到右排列若干个用 grey 边框隔开的小方格（如 3x3 或 4x4），每个方格内部包含一个由某颜色绘制的独特小图案（如 L 形、T 形、十字形等），方格上方标注一个数字对应的像素点数（用该数量的 maroon 像素从左到右排列在方格顶边上方）。
- 网格上方主区域有若干个由彩色线段（非 bg、非 grey）围成的封闭矩形区域，每个区域的边框是一种统一颜色。每个矩形边框上有 1-4 个单像素缺口（"门"），门的位置在边框的不同边上。
- 不同矩形区域的边框颜色不同，面积也不同。

Rule:
- 第一层推理：数出每个矩形区域边框上门（缺口）的数量 D。
- 第二层推理：在图案库中找到标注数量为 D 的图案方格——D 个 maroon 点对应的那个图案。
- 第三层推理：确定门在矩形边框上的主要分布方位——如果门集中在上边或门最多在上边，则图案不旋转；门最多在右边则顺时针旋转 90 度；下边旋转 180 度；左边旋转 270 度。若多边持平则取顺时针方向最先遇到的边（从上边开始）。
- 将旋转后的图案以矩形区域中心为对齐点，用矩形边框的颜色绘制在区域内部（覆盖 bg）。图案按需平铺以覆盖整个内部区域。
- 图案库在输出中被移除。

Key insight: 门的数量是查表键，门的空间分布是旋转键——两个独立的信息通道编码在同一组缺口上，解题者必须分别提取数量和方位两种信号才能正确填充。
</new_puzzle>

<new_puzzle>
description: 将网格中散布的"碎片"按颜色分组后拼回各自的目标轮廓，拼接顺序由碎片内部隐藏的优先级标记决定——标记像素距碎片边缘的步数编码了该碎片的放置层级。

Input structure:
- bg = black。网格右侧有若干个用 grey 虚线框标出的目标轮廓区域，每个轮廓内部为 bg，轮廓形状各异（非矩形的不规则多连通形状），每个轮廓区域的左上角有一个单像素的颜色标签。
- 网格左侧散布着多个小型彩色连通块（"碎片"），每个碎片由两种颜色组成：主体色（占大部分像素）和标记色（恰好 1 个像素，嵌在主体内部某处）。不同碎片的主体色可能相同，但标记色始终为 maroon。
- 同一主体色的碎片组合在一起恰好能完美填满某个目标轮廓（颜色标签与主体色一致）。

Rule:
- 第一层推理：按主体色将碎片分组，并通过颜色标签找到每组对应的目标轮廓。
- 第二层推理：对于每组碎片，确定放置顺序——观察每个碎片中 maroon 标记像素的位置：标记在碎片最外缘（与 bg 相邻）的碎片最先放置，标记越靠近碎片内部中心的越后放置。具体排序依据为标记像素到碎片边界的最短正交步数，步数越小优先级越高。
- 第三层推理：按优先级从高到低依次将碎片放入目标轮廓中。每个碎片可旋转 0/90/180/270 度，需要找到唯一能放入剩余空间的位置和角度。放置后碎片的 maroon 标记像素改为主体色。
- 输出仅保留右侧已填充的目标轮廓区域（灰色虚线框改为实线），左侧碎片区域清空为 bg。

Key insight: 碎片拼合本身就有挑战性，但放置顺序至关重要——标记像素的位置不是随机的，它编码了拼装优先级。早放的碎片会约束晚放碎片的可用空间，只有正确的顺序才能让所有碎片完美嵌入。
</new_puzzle>
