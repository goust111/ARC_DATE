<new_puzzle>
- `description`：根据封闭区域内部"种子"像素的数量，从边框缺口处向外发射等长射线。

- `Input structure`：
  - bg = 背景色（black）。网格中分布着若干由同一颜色（如 blue）绘制的矩形封闭边框（边框宽度为 1 像素）。
  - 每个矩形边框上恰好有一个 1 像素宽的缺口（即该边框色被擦除了一个像素，露出背景色）。
  - 每个矩形内部散布着若干非背景色的像素点（"种子"），种子颜色各异，但每个矩形内所有种子共享同一种颜色，且该颜色与边框颜色不同。
  - 不同矩形的种子颜色可以相同也可以不同。

- `Rule`：
  - 对每个矩形边框：
    1. 定位其缺口位置，确定缺口所在的方向（上 / 下 / 左 / 右）。缺口在顶边则方向朝上，在底边则朝下，在左边则朝左，在右边则朝右。
    2. 统计该矩形内部种子像素的数量 N。
    3. 从缺口位置出发，沿缺口方向向外绘制一条长度为 N 的直线，颜色与种子相同。若线条超出网格边界，则截断。
  - 矩形边框、种子像素和背景均保持原样不变，仅新增射线。

- `Key insight`：缺口方向决定射线朝向，内部种子数量决定射线长度——解题者需要同时关注边框上的结构缺陷（缺口）和内部内容的计数，两者缺一不可。
</new_puzzle>

<new_puzzle>
- `description`：在网格中找到多个形状相同但颜色不同的连通图案，利用网格边缘的"颜色排序条"确定排列顺序，然后将所有图案按该顺序紧密拼接输出。

- `Input structure`：
  - bg = 背景色（black）。网格中散布着若干形状完全相同的连通图案（sprite），每个 sprite 使用不同的单一颜色绘制（如 red、green、yellow、blue 等）。
  - 网格的最底行有一条"排序条"：由若干不同颜色的单像素点组成，从左到右排列。排序条中出现的颜色恰好与所有 sprite 的颜色一一对应。
  - sprite 在输入网格中的位置是随机的，互不重叠。

- `Rule`：
  - 识别排序条中颜色的排列顺序（从左到右读取）。
  - 将所有 sprite 按排序条给出的颜色顺序，从左到右依次紧密放置（sprite 之间无间隔，但保持原始形状）。
  - 输出网格的高度等于单个 sprite 的高度，宽度等于所有 sprite 水平拼接后的总宽度。
  - 每个 sprite 保持其原始颜色不变。

- `Key insight`：所有 sprite 形状相同这一事实容易被忽略（因为颜色不同会让人以为它们是不同对象）；排序条不是装饰而是隐含的排列指令——解题者必须先意识到排序条的功能角色，再按其指定顺序重组 sprite。
</new_puzzle>

<new_puzzle>
- `description`：网格中有若干"信号塔"（小十字形图案）和"接收器"（单像素标记），信号塔沿四个正方向广播射线，射线在碰到另一座信号塔时被"转发"为该塔的颜色继续传播；接收器最终被染成到达它的射线颜色。

- `Input structure`：
  - bg = 背景色（black）。
  - "信号塔"：若干 3x3 的十字形图案（中心像素 + 上下左右各 1 像素），每座塔使用不同的非背景色（如 red、blue、green 等）。十字形中心即为塔的坐标。
  - "接收器"：若干 grey 单像素点，散布在网格各处。
  - 信号塔之间、信号塔与接收器之间的空间均为背景色。

- `Rule`：
  - 每座信号塔从其中心沿上、下、左、右四个方向发射射线，射线颜色与该塔的颜色相同。
  - 射线逐像素延伸，遇到以下情况：
    a. 到达网格边界——射线终止。
    b. 碰到另一座信号塔的十字形像素——射线终止于该像素前一格，但触发被碰塔从其中心沿同一传播方向继续发射一条新射线（颜色变为被碰塔的颜色）。即射线被"中继转发"。
    c. 碰到接收器——接收器被染成该射线的颜色，射线继续穿过该接收器向前传播。
  - 如果一个接收器被多条不同颜色的射线到达，则取最后被覆盖的颜色（即：按塔在网格中从上到下、从左到右的顺序依次处理每座塔的射线，后处理的覆盖先处理的）。
  - 输出网格中：信号塔保持原样，射线路径上的背景像素被染成相应射线颜色，接收器被染成最终颜色。

- `Key insight`：解题的关键不仅在于理解射线传播，更在于发现"中继转发"机制——射线碰到另一座塔时不会简单消失，而是以新颜色沿同方向继续传播。这导致一个接收器的最终颜色可能取决于一条经过多次中继的射线链，解题者需要追踪完整的传播路径。
</new_puzzle>

<new_puzzle>
- `description`：网格中有若干矩形色块和一个灰色"模板框"，模板框内用彩色单像素标记指定位置；将与标记同色的矩形色块缩小后填入对应单元格，矩形内部孔洞数量决定缩略图的旋转次数。

- `Input structure`：
  - bg = 背景色（black）。
  - 网格中有若干不同颜色的矩形色块（如 red 矩形、blue 矩形、green 矩形等），每个矩形内部可能有 0 至 3 个背景色的 1x1 孔洞（即矩形内部被挖去的单像素点）。
  - 一个灰色（grey）边框的矩形"模板框"，边框宽度为 1 像素，内部被均匀划分为若干等大的方形单元格（由 grey 分隔线划分，形成类似网格表格的结构）。
  - 模板框内的某些单元格中有一个与某矩形色块同色的单像素标记（位于单元格中心）。其余单元格为空（背景色）。

- `Rule`：
  - 对模板框中每个带标记的单元格：
    1. 找到网格中与标记同色的矩形色块。
    2. 将该矩形色块等比缩小，使其恰好填满模板框的一个单元格大小（忽略孔洞，缩略图为实心）。
    3. 统计原始矩形色块内部的孔洞数量 K（0、1、2 或 3）。
    4. 将缩略图顺时针旋转 K x 90 度。
    5. 将旋转后的缩略图绘制到该单元格中，替换掉原来的标记像素。
  - 模板框外的所有矩形色块在输出中被擦除（变为背景色）。模板框的灰色边框保持不变。

- `Key insight`：解题者需要发现两层独立规则——颜色匹配决定"放什么"，孔洞计数决定"怎么转"。孔洞是矩形内部微小的视觉特征，容易被忽视；而旋转效果只有在非正方形矩形缩略图上才能观察到差异，增加了归纳难度。
</new_puzzle>

<new_puzzle>
- `description`：网格被贯穿的彩色水平线和竖直线划分成矩形区域，每个区域内有小型图案；根据该区域四条边界线的颜色"同异"组合决定图案需要执行的翻转或旋转变换。

- `Input structure`：
  - bg = 背景色（black）。
  - 网格被若干条贯穿整个网格的水平线和竖直线划分成矩形区域。这些线条使用两种颜色之一绘制：red 或 blue。
  - 每个矩形区域内部有一个小型非对称图案（由某种非背景、非 red、非 blue 的颜色绘制，如 yellow 或 green），图案不接触区域边界线。
  - 图案在每个区域中的相对位置（相对于区域左上角的偏移）可能不同。

- `Rule`：
  - 对每个矩形区域，检查其四条边界线（上、下、左、右）的颜色：
    - 上边界线和下边界线颜色相同，且左边界线和右边界线颜色相同 → 图案保持不变。
    - 上边界线和下边界线颜色不同，且左边界线和右边界线颜色相同 → 图案进行垂直翻转（上下翻转）。
    - 上边界线和下边界线颜色相同，且左边界线和右边界线颜色不同 → 图案进行水平翻转（左右翻转）。
    - 上边界线和下边界线颜色不同，且左边界线和右边界线颜色不同 → 图案旋转 180 度。
  - 对于处在网格最外边缘的区域，缺失的边界线视为与对面边界线颜色相同（即不产生翻转效果）。
  - 输出网格尺寸和分隔线保持不变，每个区域内的图案被替换为变换后的版本，图案相对于区域中心进行对称变换。

- `Key insight`：分隔线的颜色看起来只是装饰，但实际上它们编码了变换指令。解题者需要发现"同色 vs 异色"这一二元判断分别控制水平和垂直两个轴的翻转——这是一个将颜色对称性映射到几何对称性的隐蔽对应关系。两条轴的判断相互独立，组合出四种变换结果。
</new_puzzle>

<new_puzzle>
- `description`：网格中有一个灰色的树状分支图案和若干彩色"探针"像素；每个探针从图案末端沿分支路径向内染色，直到遇到分叉点为止。

- `Input structure`：
  - bg = 背景色（black）。
  - 一个大型连通前景图案，由 grey 像素绘制，形状为树状分支结构（无环路），分支宽度为 1 像素。图案中存在若干分叉点（一个 grey 像素有 3 个或 4 个正交方向的 grey 邻居）。
  - 若干彩色单像素"探针"（如 red、blue、green、yellow 等），每个探针位于前景图案某个末端（叶节点，即只有 1 个正交前景邻居的 grey 像素）的正交相邻位置（与叶节点上下左右相邻，但自身位于背景区域）。
  - 每个叶节点最多有一个探针与之相邻。

- `Rule`：
  - 对每个探针：
    1. 找到与其正交相邻的前景叶节点。
    2. 从该叶节点出发，沿前景图案的分支路径向内行走（每步移动到唯一的下一个 grey 正交邻居），将沿途的 grey 像素全部重新着色为探针的颜色。
    3. 当到达一个分叉点（有 3 个或以上正交前景邻居的像素）时停止，该分叉点像素本身不被染色，保持 grey。
  - 没有探针对应的叶节点分支保持 grey 不变。
  - 探针像素本身在输出中被擦除（变为背景色）。

- `Key insight`：解题者需要理解前景图案是一棵"树"，探针从叶节点向内染色到最近的分叉点。关键洞见在于分叉点充当了"防火墙"——不同探针的颜色在分叉点处停止，永远不会互相覆盖。看似是简单的射线发射，实际上是沿着拓扑分支结构的路径追踪，分叉点的识别（通过正交邻居数量）是解题的核心观察。
</new_puzzle>

<new_puzzle>
- `description`：网格中有若干配对的同色 L 形拐角标记围出源区域，以及同色角点标记围出目标区域；源区域内的图案被复制到目标区域，L 形拐角的朝向决定复制时的翻转或旋转方式。

- `Input structure`：
  - bg = 背景色（black）。
  - 网格中有若干对 L 形拐角标记（每个 L 形由 3 个像素组成：一个拐角像素加两个分别向水平和垂直方向各延伸 1 像素的臂）。每对 L 形使用相同颜色，且恰好有两个，分别位于某个矩形区域的对角位置（如左上角和右下角，或右上角和左下角），从而框定一个矩形区域。
  - 每对 L 形框定的矩形区域内部包含一个由某种其他颜色绘制的小型图案。
  - 网格中另有若干空的矩形区域，这些区域仅由四角处的单像素标记（与某对 L 形同色）标定，内部为空（背景色）。这些单像素标记形成矩形的四个角，标定的区域大小与对应 L 形框定的源区域相同。

- `Rule`：
  - 对每种颜色，找到该颜色的一对 L 形（源）和四个角点标记（目标）。
  - 观察源区域中两个 L 形的朝向：
    - 如果两个 L 形的开口朝向内部（即拐角在外侧，臂伸向矩形中心方向），则图案原样复制到目标区域。
    - 如果两个 L 形的开口方向一致朝左或朝右，则图案水平翻转后复制到目标区域。
    - 如果两个 L 形的开口方向一致朝上或朝下，则图案垂直翻转后复制到目标区域。
    - 如果两个 L 形的开口朝向外部（即拐角在内侧，臂背离矩形中心），则图案旋转 180 度后复制到目标区域。
  - 输出网格中，源区域和 L 形标记保持不变，目标区域被填入变换后的图案，角点标记保留。

- `Key insight`：L 形拐角的朝向不是随意的装饰——它们编码了图案的变换方式。解题者需要先发现 L 形配对机制（通过颜色匹配源和目标），再发现 L 形开口方向与几何变换之间的对应关系。这是一个"配对查找 + 方向解码"的双层推理结构。
</new_puzzle>
