description: 根据嵌套框架的层级颜色序列，将散落碎片按颜色归入对应层级的缺口，并按缺口所在边的方向旋转碎片后填入。

Input structure:
- 背景色（black）填充整个网格。
- 网格中央有一组同心矩形框架（由外到内层数为 3-4 层），每层框架使用不同颜色（如 red、blue、green、yellow），每层框架厚度为 1 像素。
- 每层框架上恰好有一个矩形缺口（连续缺失的像素段），缺口位于框架的某一边（上、下、左、右）。
- 框架外的网格区域散落着若干小型彩色碎片（由 2-5 个像素组成的连通块），每个碎片的颜色与某一层框架颜色相同。
- 每层框架的缺口大小恰好能容纳与之同色的碎片的某个旋转形态（0°、90°、180°、270°）。
- 每层框架的缺口所在边决定了碎片的旋转方式：缺口在上边 → 不旋转（0°），缺口在右边 → 顺时针 90°，缺口在下边 → 180°，缺口在左边 → 逆时针 90°。

Rule:
- 第一步：识别每层框架的颜色以及该层缺口所在的边。
- 第二步：在散落碎片中找到与该层框架同色的碎片。
- 第三步：根据缺口所在的边确定旋转角度（上 → 0°、右 → 顺时针 90°、下 → 180°、左 → 逆时针 90°），对碎片进行旋转。
- 第四步：将旋转后的碎片放置到缺口位置，使其恰好填补缺口。碎片的左上角与缺口区域的左上角对齐。
- 散落碎片原来的位置变为背景色。

Key insight: 缺口所在的边隐式编码了碎片的旋转角度——解题者需要先发现"边 → 旋转"的映射规则，再根据颜色匹配碎片到对应层级，两步推理缺一不可。
</new_puzzle>

description: 沿彩色路径网络传播信号，在交叉点根据路径颜色优先级选择转向方向，最终将信号源的颜色涂满所经路径。

Input structure:
- 背景色为 black。
- 网格中有由若干不同颜色（如 red、blue、green、yellow）绘制的单像素宽路径段，这些路径段在某些像素处交叉形成十字路口或 T 形路口。
- 网格的一个角落有一个 2x2 的"优先级图例"区域，用 grey 边框围起来。图例内部从上到下排列了 2-3 个不同颜色的像素，它们的排列顺序代表路径颜色的优先级（最上面的优先级最高）。
- 路径网络中有若干"信号源"：一个用 orange 标记的 1x1 像素，位于某条路径的端点上。
- 路径网络中有若干"终点"：一个用 maroon 标记的 1x1 像素，位于某条路径的端点上。

Rule:
- 从每个信号源（orange 像素）出发，沿其所在路径向前传播。
- 当信号到达一个交叉路口（路径像素有多于两个路径邻居）时，检查所有可继续前进的路径分支的颜色（不包括来时的方向）。
- 根据优先级图例，选择优先级最高的颜色对应的分支继续前进。
- 信号沿途经过的所有路径像素都被重绘为 orange。
- 当信号到达 maroon 终点时停止，将该终点像素也变为 orange。
- 未被信号经过的路径像素保持原色不变。
- 图例区域在输出中保留不变。

Key insight: 优先级图例中颜色的排列顺序决定了信号在每个路口的转向选择——解题者必须先从图例中归纳出颜色优先级，再将其应用于路径网络的每个交叉决策点。
</new_puzzle>

description: 将网格中的封闭区域按照其内部标记像素的数量排序，然后将排序后的区域颜色按照另一组参考色带的顺序重新映射。

Input structure:
- 背景色为 black。
- 网格主体区域包含若干由 grey 线条围成的不规则封闭区域（每个区域面积约 8-30 像素）。每个封闭区域内部填充了某种非 black、非 grey 的颜色（如 red、blue、green、yellow 等），且每个区域的填充色各不相同。
- 每个封闭区域内部散布着 0-4 个 azure 标记像素（小点），这些标记像素位于该区域填充色之上。
- 网格底部有一行"参考色带"：从左到右依次排列若干个不同颜色的 1x1 像素块（颜色与封闭区域的填充色不同），用 grey 像素分隔。色带中颜色的数量等于封闭区域的数量。

Rule:
- 第一步：对每个封闭区域，数出其内部 azure 标记像素的数量。
- 第二步：将所有封闭区域按标记数量从少到多排序（标记数量相同时，按区域在网格中从左到右、从上到下的位置排序）。
- 第三步：读取底部参考色带从左到右的颜色序列。
- 第四步：将排序后第 i 个封闭区域的填充色替换为参考色带中第 i 个颜色。
- azure 标记像素从输出中移除（变为新的填充色）。
- grey 边界线和参考色带在输出中保留不变。

Key insight: azure 标记的数量是隐藏的排序键，而参考色带提供了排序后的颜色映射目标——解题者需要发现"数标记 → 排序 → 按色带重映射"的三步推理链。
</new_puzzle>

<new_puzzle>
description: 根据种子图案的对称性缺陷方向，在网格中沿缺陷方向生长出镜像修复后的完整图案副本。

Input structure:
- 背景色为 black。
- 网格中有一个约 5x5 到 7x7 的彩色"种子图案"（由多种非 black 颜色组成的连通块），该图案几乎具有某种对称性（水平镜像或垂直镜像），但恰好有 1-3 个像素偏离了完美对称——这些偏离的像素使用了一种在图案中独特的"缺陷色"（如 maroon），而该位置若对称完美则应为另一种颜色。
- 所有缺陷色像素都位于对称轴的同一侧，这一侧即为"生长方向"。
- 网格中还有若干 grey 的单像素"锚点"，散布在种子图案的外围，每个锚点与种子图案之间有一定距离。

Rule:
- 第一步：识别种子图案接近的对称类型（水平镜像或垂直镜像），找到使图案最接近完美对称的轴。
- 第二步：找到所有缺陷色像素，确定它们相对于对称轴的偏移方向。所有缺陷像素位于对称轴的同一侧，这个方向就是"生长方向"。
- 第三步：生成种子图案的"修复版"——将每个缺陷色像素替换为其关于对称轴的镜像位置上对应的颜色，使图案变为完美对称。
- 第四步：对每个 grey 锚点，在锚点位置放置修复版图案的一个副本（锚点对应副本的中心像素），副本沿生长方向做一次镜像翻转。
- 第五步：原始种子图案中的缺陷色像素也被替换为修复后的正确颜色。Grey 锚点被副本图案覆盖。

Key insight: 缺陷像素不是噪声而是方向编码器——它们打破对称的方向决定了副本的翻转方式，解题者必须先还原"本应完美"的对称性，才能理解缺陷的编码含义。
</new_puzzle>

<new_puzzle>
description: 在分区网格中，根据每个分区内"指针"对象指向的相邻分区，将被指分区的填充图案复制到指针所在分区，同时按指针颜色对图案重新着色。

Input structure:
- 背景色为 black。
- 网格被 grey 线条均匀分割为 3x3 或 4x4 的矩形分区（每个分区大小相同，约 5x5 到 7x7 像素）。
- 部分分区内部有一个小型"填充图案"——由 2-6 个非 black、非 grey 像素组成的小图形（如 L 形、T 形、十字形等），每个图案使用单一颜色，不同分区的图案颜色和形状各不相同。
- 其他分区内部包含一个"指针"对象：一个由 3 个像素组成的直角箭头形状。箭头的画法为：2 个像素排成一行或一列作为箭杆，第 3 个像素在箭杆末端沿垂直于箭杆的方向偏移 1 像素形成箭头尖端。箭头指向的方向由箭杆到尖端的朝向决定（上、下、左、右四个方向之一）。指针使用某种特定颜色（如 red、blue 等）。
- 每个指针恰好指向一个相邻分区（上/下/左/右直接相邻），且被指向的分区一定包含填充图案。
- 至少有一个分区是完全空的（只有 black 背景），既没有图案也没有指针。

Rule:
- 第一步：识别每个分区的内容类型——空白、填充图案、或指针。
- 第二步：对每个包含指针的分区，根据箭头的 3 像素形状判断指向方向，找到该方向上相邻分区中的填充图案。
- 第三步：将被指向分区的填充图案复制到指针所在分区中（保持图案在分区内的相对位置不变），但将图案的颜色替换为指针的颜色。
- 第四步：指针本身从输出中移除（变为 black）。
- 包含原始填充图案的分区保持不变。空白分区保持不变。Grey 分割线保持不变。

Key insight: 指针的朝向决定"从哪个邻居借图案"，指针的颜色决定"借来的图案用什么颜色重绘"——解题者需要同时解读方向信息和颜色信息两个独立维度，并理解它们分别控制不同的变换要素。
</new_puzzle>
