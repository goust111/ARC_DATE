<new_puzzle>
根据前景对象的轮廓封闭性选择变换方式：封闭轮廓内部填充其图例对应色，开放轮廓沿缺口方向投射出与轮廓像素数等长的色带。

Input structure
- 背景为 black 的网格上散布着若干由单一颜色像素构成的一像素宽轮廓对象。
- 每个轮廓对象要么是完全封闭的（如矩形环、L 形环等无缺口闭合回路，内部区域不与外部背景连通），要么是开放的（恰好有一个单像素宽的缺口打断了闭合）。
- 每个轮廓使用不同的前景色（如 red、green、blue、orange 等），颜色互不重复。
- 网格右上角有一个由 grey 像素构成的"色彩图例"：一个 2 列 × N 行的小表格，每行左列是一种前景色的单像素，右列是该前景色对应的"填充色"单像素。N 等于封闭轮廓的数量。

Rule
- 对每个轮廓对象，判断其是否封闭（4-连通遍历轮廓像素能形成闭合回路，且内部被轮廓完全包围的背景区域不与网格外部背景连通）。
- 若轮廓封闭：在其包围的内部区域全部填充该轮廓颜色在色彩图例中对应的填充色，轮廓本身保持不变。
- 若轮廓开放：找到缺口位置（轮廓上唯一断开的那个像素宽间隙），确定从轮廓内侧朝缺口看去的方向（上、下、左、右），从缺口处沿该方向画一条色带，色带宽度为 1 像素，长度等于该轮廓对象的总像素数，颜色为轮廓自身的颜色。色带遇到网格边界则截断。
- 色彩图例在输出中被清除（全部变为背景色 black）。

Key insight
解题者必须先发现封闭与开放轮廓的分类标准（闭合 vs 有缺口），然后对两类对象分别归纳出完全不同的变换规则——封闭轮廓需要查图例获取填充色，而开放轮廓需要从缺口方向和轮廓像素计数推导出射线。分类判断与两套独立规则构成多层推理。
</new_puzzle>

<new_puzzle>
将网格中的彩色"种子"像素按分隔线上箭头标记编码的全局方向生长为 L 形枝条，枝条在碰到分隔线或边界时截断。

Input structure
- 背景为 black 的网格被一条水平的 grey 线和一条垂直的 grey 线分成四个象限。
- 两条分隔线的交叉点是网格的视觉中心。
- 每条分隔线上恰好有一个非 grey 的 maroon 像素作为"箭头标记"，位于交叉点的某一侧。水平线上的 maroon 标记指示水平方向（标记在交叉点左侧表示"向左"，右侧表示"向右"）；垂直线上的 maroon 标记指示垂直方向（标记在交叉点上方表示"向上"，下方表示"向下"）。两个方向组合成一个全局朝向（如"向左 + 向上" = 左上）。
- 四个象限中各散布着 1-3 个孤立的彩色前景像素（"种子"），颜色各不相同且不包含 grey 或 maroon。

Rule
- 根据两个 maroon 标记相对于交叉点的位置确定一个全局朝向（四种之一：左上、右上、左下、右下）。
- 每个种子像素生长为一个 L 形枝条：先从种子位置沿全局朝向的水平分量方向（左或右）连续延伸 2 格，再从该端点沿全局朝向的垂直分量方向（上或下）连续延伸 2 格，全部使用种子自身的颜色绘制。
- 若延伸过程中某一格会落在分隔线上或超出网格边界，枝条在该格之前截断（不覆盖分隔线）。
- 分隔线（含 maroon 标记）在输出中保持不变，种子原位置保留为枝条的起点。

Key insight
解题者首先需要从分隔线上两个 maroon 标记相对于交叉点的位置解码出全局生长方向，然后将该方向拆解为水平和垂直两个分量来驱动每个种子的 L 形生长路径。方向编码隐藏在分隔线结构中，与生长规则构成两个独立的推理层。
</new_puzzle>

<new_puzzle>
利用小型"模具"对象内部的孔洞图案在配对的大型同色矩形上冲压镂空，再将冲下的碎片收集到指定区域。

Input structure
- 背景为 black 的网格中有若干大型实心彩色矩形和若干小型同色"模具"对象。
- 每个模具是一个小矩形块，其内部包含若干背景色 black 像素形成的孔洞图案，模具其余部分为某种前景色。每个模具的颜色与恰好一个大型矩形的颜色相同，形成唯一的颜色配对。
- 每个模具位于其配对大型矩形的外部，且与该大型矩形在水平或垂直方向上对齐（模具的某些行与大型矩形的某些行处于同一行号，或某些列处于同一列号）。
- 网格左下角有一个由 azure 像素构成的单像素宽矩形边框，围成一个空白的"碎片收集区"。

Rule
- 对每个颜色配对，将模具的孔洞图案（模具 bbox 内部为 black 的像素的相对位置）投影到配对大型矩形上：投影在对齐方向上与模具保持相同的行号或列号，在非对齐方向上从大型矩形靠近模具一侧的边缘开始，与模具在该方向上的内部偏移一一对应。
- 在大型矩形上将投影命中的像素清除为背景色（完成镂空）。
- 将被清除的像素（保留其颜色和相对形状）作为碎片，放入碎片收集区内部。碎片在收集区中按照其对应大型矩形在网格中从上到下的顺序依次从收集区顶部向下排列，碎片之间间隔一行。
- 模具对象在输出中被清除为背景色。收集区 azure 边框保持不变。

Key insight
解题者需要三步推理：(1) 通过颜色匹配将模具与大型矩形配对；(2) 理解模具的孔洞（black 像素）才是"冲压模板"——模具的实体部分是干扰项，真正起作用的是其中的空洞；(3) 发现被冲掉的碎片要按空间顺序收集到指定区域。孔洞即模板的反直觉是核心隐蔽性所在。
</new_puzzle>

<new_puzzle>
根据每个矩形对象内部"指针像素"的位置推断指向方向，沿指向追踪出对象间的有向链，链的起点颜色覆盖终点对象的颜色。

Input structure
- 背景为 grey 的网格上有若干互不接触的实心矩形对象，每个矩形使用不同的前景色（如 red、blue、green、yellow、orange 等）。
- 每个矩形对象内部恰好有一个 black 像素作为"指针像素"。指针像素位于矩形四条边之一的内侧中点（例如，若矩形宽 5 高 3，指针在右边中点即第 2 行最右列），该边指示对象的"指向方向"（指针贴右边则指向右方，贴上边则指向上方，以此类推）。
- 从每个对象沿其指向方向看去，在该直线方向上存在另一个矩形对象（中间隔着背景像素）。
- 对象间的指向关系构成若干条不分叉的有向链（无环路），每条链有唯一起点（无入边的对象）和唯一终点（指向方向上无更多对象的对象）。

Rule
- 对每个矩形，根据 black 指针像素贴近矩形哪条边来确定其指向方向。
- 沿指向方向找到下一个矩形对象，建立有向链。
- 找到每条链的起点对象（没有被链中其他对象指向的那个）。
- 将链终点对象的颜色替换为链起点对象的颜色。链中间的对象颜色保持不变。
- 所有 black 指针像素在输出中被替换为其所在矩形当前的颜色（即指针消失，融入矩形）。

Key insight
解题者需要依次完成三层推理：(1) 从 black 像素在矩形内部的偏心位置推断每个对象的指向方向；(2) 沿方向追踪建立对象间的有向链拓扑；(3) 理解颜色传播规则是"起点颜色覆盖终点"而非逐级传递。指针位置编码方向这一步是核心隐蔽性所在。
</new_puzzle>

<new_puzzle>
将散落的碎片通过形状匹配（含旋转）拼入拼图底板的缺口中，拼入后碎片颜色替换为缺口边框提示色，同时边框提示色像素恢复为其外侧邻居的原始颜色。

Input structure
- 背景为 black 的网格分为上下两个区域，由一条水平的 grey 分隔线隔开。
- 上方区域包含一个大型"拼图底板"：一个矩形区域由若干不同颜色的相邻色块紧密拼成，但其中有 2-4 个不规则形状的缺口（缺口处为背景色 black）。每个缺口的所有相邻像素（缺口在底板内部一侧的 4-连通邻居）被统一替换为一种独特的"边框提示色"（如 maroon、azure、orange 等），不同缺口的提示色各不相同。
- 下方区域散布着 2-4 个彩色碎片对象，每个碎片是一个不规则形状的 4-连通区域，使用某种前景色（与所有提示色不同）。碎片数量与缺口数量相同。

Rule
- 对每个碎片，通过形状匹配找到其对应的缺口：碎片经过 0°、90°、180° 或 270° 旋转后，其形状与某个缺口的形状完全吻合（像素数相同且相对位置一致）。不需要翻转，每个碎片恰好匹配一个缺口。
- 将碎片旋转到正确角度后填入缺口位置。填入后碎片像素的颜色不保留原色，而是全部替换为该缺口的边框提示色。
- 同时，缺口周围那些边框提示色像素在输出中被恢复为其原始颜色。恢复方法：每个提示色像素取其 4-连通邻居中不属于缺口、不属于提示色的那个邻居的颜色（即该像素背向缺口一侧的底板色块颜色）。
- 下方区域的碎片在输出中被清除为背景色。分隔线保持不变。

Key insight
解题者需要依次完成三层推理：(1) 通过含旋转的形状匹配将碎片与缺口配对——碎片颜色与缺口无关，只有形状吻合才是配对依据；(2) 发现填入的碎片不保留原色而是采用缺口边框提示色进行染色，理解提示色作为"目标色"的角色；(3) 发现边框提示色本身也需要被还原为原始底板颜色，还原线索来自其外侧邻居——这揭示了提示色只是临时标记层。三层规则层层递进，单一样例难以完全归纳。
</new_puzzle>
