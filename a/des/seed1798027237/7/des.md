根据内部孔洞的形状在网格边界上"盖章"对应的轮廓印记。

Input structure
- 背景为黑色的方形网格。
- 网格中散布若干单色填充矩形，每个矩形内部被挖去一个连通的孔洞（孔洞颜色为背景色黑色）。
- 每个矩形恰好位于网格的某一条边附近（上、下、左、右），即矩形的一条边紧贴或最接近该边界。

Rule
- 保留所有原始矩形及其孔洞不变。
- 对每个矩形，提取其内部孔洞的形状（相对于孔洞自身的包围盒）。
- 将孔洞形状作为印记，以矩形自身的颜色，"盖"在矩形所靠近的那条网格边界上：印记紧贴边界，水平居中（若靠近上/下边界）或垂直居中（若靠近左/右边界）对齐于矩形中心所在的行或列。
- 印记的朝向需要翻转：若矩形靠近上边界，则孔洞形状上下翻转后盖在顶部边缘；若靠近右边界，则左右翻转后盖在右侧边缘；以此类推，使得印记像是孔洞向边界方向"投射"出去的镜像。

Key insight
- 孔洞不是缺损而是编码：它的形状决定了边界印记的图案，它所在矩形靠近哪条边决定了印记出现在哪个方向，而翻转规则模拟了"从矩形向外投影"的镜像关系。解题需要先识别孔洞形状，再确定投影方向和翻转方式，构成两层独立推理。
</new_puzzle>

<new_puzzle>
将网格中分散的彩色线段按颜色配对，然后沿配对线段围成的矩形区域填充第三种颜色，填充颜色由两条线段的交叉朝向决定。

Input structure
- 背景为黑色的矩形网格。
- 网格中有若干条水平或垂直的单色线段（长度至少为 3 像素），每种颜色恰好出现两条线段。
- 同色的两条线段一定一条水平一条垂直，且它们的延长线会形成一个交点。
- 网格中还存在一个由 grey 像素组成的 2x2 色块作为"调色板"，其四个像素分别为四种不同颜色，分布在四个象限位置（左上、右上、左下、右下各一个颜色）。

Rule
- 对每对同色线段，找到它们延长线的虚拟交点。
- 以两条线段的端点（远离交点一侧的端点）和虚拟交点为对角，确定一个轴对齐矩形区域。
- 判断虚拟交点相对于两条线段实际像素的方位（交点在线段对的左上、右上、左下还是右下），该方位对应调色板 2x2 色块中同一象限位置的颜色。
- 用该颜色填充矩形区域的内部（不含边框），原有线段像素保持不变。

Key insight
- 第一层推理：识别同色线段配对并构造虚拟交点来定义填充矩形。第二层推理：交点相对于线段对的方位需要映射到调色板的对应象限才能确定填充色——调色板是方位-颜色的编码表，而非装饰。
</new_puzzle>

<new_puzzle>
将散落在网格中的小型"箭头"精灵按其指向方向依次堆叠到网格中央的十字准线上。

Input structure
- 背景为黑色的奇数边长正方形网格。
- 网格正中央有一个由 grey 像素组成的十字准线：一条完整的水平中线和一条完整的垂直中线（交叉处也是 grey）。
- 网格中散布若干彩色"箭头"精灵，每个箭头由 5 个同色像素组成：一个 1x3 或 3x1 的柄加上柄一端的垂直方向两侧各伸出 1 像素构成箭头尖端。箭头的朝向由尖端相对于柄的方向决定（上、下、左、右四种朝向之一）。
- 同一颜色可能有多个箭头，不同颜色的箭头数量不同。

Rule
- 统计每种朝向（上、下、左、右）的箭头总数 N。
- 从十字准线的中心交叉点出发，沿该朝向的准线臂方向，将距中心最近的 N 个 grey 像素替换为 red。
- 清除所有原始箭头精灵（恢复为黑色背景），十字准线其余部分保持 grey 不变。

Key insight
- 箭头的颜色是干扰项——真正重要的是箭头的朝向。解题者需要先忽略颜色差异，按朝向分组计数，再将计数转化为十字准线上从中心向外延伸的 red 标记长度。第一层推理在于发现颜色无关、朝向才是分类依据；第二层在于发现计数与准线臂上的染色长度之间的对应关系。
</new_puzzle>

<new_puzzle>
根据框架内部的"种子"像素位置，在框架上对应的边上打开缺口，然后从缺口向外生长出与种子颜色相同的射线。

Input structure
- 背景为黑色的矩形网格。
- 网格中有若干个由 grey 像素绘制的空心矩形框架（边框宽度 1 像素），框架之间不重叠、不接触。
- 每个框架内部（被 grey 边框包围的区域）恰好有一个非黑非灰的彩色"种子"像素。
- 种子像素不在框架的正中心，而是偏向框架内部的某一侧。

Rule
- 对每个框架，找到种子像素到框架四条边的距离（以像素为单位），选择种子最靠近的那条边。
- 在该边上，将与种子同列（若最近边为上/下边）或同行（若最近边为左/右边）的那个 grey 边框像素替换为黑色，形成一个 1 像素宽的缺口。
- 从缺口位置出发，沿垂直于该边向外的方向，绘制一条种子颜色的射线，一直延伸到网格边界或碰到其他 grey 框架像素为止（不覆盖 grey 像素）。
- 种子像素本身从框架内部清除（恢复为黑色），框架其余部分保持 grey 不变。

Key insight
- 第一层推理：种子像素的偏移位置决定了哪条边被打开——这不是任意选择，而是"最近边"规则。第二层推理：缺口的精确位置由种子的行/列坐标投影到边上决定，射线从缺口向外延伸的方向与种子"试图逃离"框架的方向一致。种子既编码了出口方向又编码了出口位置，但需要两步独立推理才能解码。
</new_puzzle>

<new_puzzle>
将网格中的多个小图案按照"嵌套信封"规则逐层包裹，包裹顺序由图案面积从小到大决定，每层包裹使用被包裹图案的颜色。

Input structure
- 背景为黑色的正方形网格。
- 网格中散布若干个不重叠的单色填充矩形，每个矩形颜色各不相同，大小也各不相同（面积互不相等）。
- 矩形的数量在 3 到 5 个之间。

Rule
- 将所有矩形按面积从小到大排序。
- 取面积最小的矩形作为最内层"核心"，保持其颜色和形状不变，将其放置在输出网格的正中央。
- 从第二小的矩形开始，依次为当前已构建的图形添加一圈 1 像素宽的边框，边框颜色为该矩形的颜色。
- 重复此过程：第三小的矩形颜色成为第二圈边框，第四小的成为第三圈边框，以此类推。
- 输出网格的尺寸恰好容纳最终的嵌套结构（核心宽度 + 2 乘以边框层数，核心高度 + 2 乘以边框层数）。
- 原始矩形的位置和大小（除最小矩形的形状外）在输出中不被保留——只有颜色和排序关系被使用。

Key insight
- 第一层推理：需要发现输入中矩形的空间位置是无关信息，真正的排序依据是面积大小。第二层推理：面积排序不是用于空间排列，而是用于确定嵌套包裹的层级顺序——小的在内、大的在外，但"大"只贡献颜色而非形状，形状完全由嵌套边框的几何规则决定。第三层推理：最小矩形的实际形状被保留为核心，这打破了"所有矩形只贡献颜色"的假设，需要解题者注意到核心的非正方形形状在输出中被忠实保留。
</new_puzzle>
