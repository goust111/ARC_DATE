<description>
根据封闭区域内的颜色种类数选择对应的边框样式，再用区域内的主色填充边框缺口。

Input structure
- 背景为 black。网格中散布若干由 grey 边框围成的矩形封闭区域，每个区域的边框上恰好有一个单像素缺口。
- 每个封闭区域内部包含 1 到 3 种不同的非背景、非边框颜色的像素块（小色块随机分布在区域内部）。
- 区域外部是纯 black 背景，无其他元素。

Rule
- 对每个封闭区域，统计其内部包含多少种不同颜色（不计 black 和 grey）。
- 颜色种类数决定边框的变换方式：
  - 1 种颜色：边框保持 grey 不变，仅用该颜色填充缺口像素。
  - 2 种颜色：整条边框重新着色为区域内面积较大的那种颜色，缺口用面积较小的颜色填充。
  - 3 种颜色：整条边框重新着色为面积最大的颜色，缺口用面积最小的颜色填充，同时区域内部面积居中的颜色像素全部清除为 black。
- 区域内部原有的色块（除被清除的部分外）保持不变。

Key insight
- 解题者需要先独立发现"内部颜色种类数"与"边框变换模式"之间的映射关系，再在每种模式内部识别面积排序决定的着色规则——两层规律都需要从样例中归纳，而非直觉可见。
</description>
</new_puzzle>

<description>
将网格中的彩色路径按交叉点拆分为独立线段，然后根据线段长度对线段重新着色。

Input structure
- 背景为 black。网格中有若干条由不同颜色绘制的单像素宽直线段（水平或垂直），它们会在某些像素处交叉。
- 交叉点处的像素颜色为 red，标记两条线段的相交位置。
- 每条线段由一种非 red、非 black 的纯色绘制（如 blue、green、yellow 等），且在交叉点处被 red 像素打断。

Rule
- 将每个 red 交叉点像素视为分隔符，把所有线段在交叉点处切断，得到一组独立的子线段。每条子线段是从一个端点（线段原始端点或 red 交叉点的邻接像素）到另一个端点的连续同色水平或垂直像素序列。
- 统计所有子线段的像素长度，对所有子线段按长度从短到长排序。
- 建立长度排名与颜色的映射：找出输入中所有出现过的非 black、非 red 颜色，按其在输入中首次出现的位置（从左到右、从上到下扫描）排序，得到颜色序列 C1, C2, C3, ...
- 将长度排名第 k 的子线段（若有并列则保持原色不变）重新着色为 Ck。
- red 交叉点像素保持 red 不变。

Key insight
- 交叉点不仅是视觉标记，更是将连续线段拆分为可度量单元的分隔符；解题者需要先完成"拆分"再完成"按长度重排颜色"，两步推理缺一不可。
</description>
</new_puzzle>

<new_puzzle>
<description>
在分格棋盘中，每个格子的输出图案由其行模板和列模板的逻辑交运算决定，运算类型由格子角落的标记色指定。

Input structure
- 背景为 black。网格被 grey 线条等分为 N 行 M 列的格子阵列（每个格子内部为相同大小的正方形区域，如 5x5）。
- 最左列的 N 个格子各包含一个由单一颜色绘制的二值图案（像素要么为该颜色要么为 black），作为该行的"行模板"。
- 最上行的 M 个格子各包含一个由另一种单一颜色绘制的二值图案，作为该列的"列模板"。
- 左上角格子（第 0 行第 0 列）为空白，不参与运算。
- 在内部每个待填充格子（行 >= 1 且列 >= 1）的右下角像素处有一个标记色像素：
  - green 表示"与"运算（AND）。
  - orange 表示"或"运算（OR）。
  - magenta 表示"异或"运算（XOR）。

Rule
- 对于内部每个格子 (i, j)（i >= 1, j >= 1）：
  - 取第 i 行的行模板和第 j 列的列模板，将两者视为同尺寸的二值掩码（有色=1，black=0）。
  - 读取该格子右下角的标记色，确定逻辑运算类型。
  - 对两个掩码逐像素执行对应的逻辑运算，得到输出掩码。
  - 输出掩码中值为 1 的像素着色为行模板的颜色，值为 0 的像素保持 black。
- 行模板列和列模板行原样保留，grey 分隔线保留，标记色像素被输出图案覆盖。

Key insight
- 解题者必须先识别出边缘行列是模板、角落像素是运算符的编码结构，再理解三种标记色分别对应三种不同的逻辑合并方式——模板读取和运算符解码构成两层独立的归纳任务。
</description>
</new_puzzle>

<new_puzzle>
<description>
将散布的彩色碎片按形状互补性配对拼合，再将拼合后的完整矩形按面积从小到大嵌套堆叠输出。

Input structure
- 背景为 azure。网格中散布若干彩色碎片，每个碎片是一个 4-连通的同色区域。
- 碎片总数为偶数，每两个碎片形状互补——即它们可以无旋转、无翻转地拼合成一个完整的实心矩形（一个碎片占据矩形内某些像素，另一个碎片恰好占据剩余像素）。
- 互补的两个碎片颜色不同。同一对碎片拼合成的矩形尺寸在所有配对中唯一（没有两对拼出相同大小的矩形）。

Rule
- 找出所有互补配对：对每个碎片计算其 bounding box，在 bounding box 中标记碎片占据的像素和空缺的像素；若某另一碎片的形状恰好与该空缺匹配（形状相同、大小相同），则两者配对。
- 对每一对，将两个碎片叠合：在拼合后的矩形中，两个碎片各保持自己的颜色。
- 将所有拼合后的矩形按面积从小到大排序，以嵌套方式居中放置在输出网格上：最大的矩形在最底层，最小的在最顶层，每个矩形的中心对齐到输出网格中心，后放置的矩形覆盖先放置的矩形。
- 输出网格大小等于最大拼合矩形的大小，未被覆盖的区域保持 azure。

Key insight
- 解题者需要先通过形状互补性（而非颜色或位置邻近性）发现配对关系，再理解嵌套堆叠的面积排序规则——配对逻辑和堆叠逻辑是两个需要分别归纳的独立推理层。
</description>
</new_puzzle>

<new_puzzle>
<description>
沿着每个箭头指示的方向，将箭头尾部区域的图案"推印"到箭头前方的空白区域，推印距离由箭头杆的长度决定。

Input structure
- 背景为 black。网格中包含若干个由非背景色绘制的矩形图案区域（每个区域内部可以有多种颜色的像素构成花纹）。
- 每个图案区域的某一侧外部紧邻一个由 red 像素绘制的箭头。箭头由一条直线杆和一个三角箭头组成：杆为沿上/下/左/右某方向的单像素宽直线段（长度 >= 1），箭头为杆末端的 3 像素 V 形尖端（例如向右的箭头：杆为水平线段，末端右侧有一个像素，其上下各一个像素构成 V 形）。
- 箭头杆的起始端紧贴图案区域的边缘，箭头尖端指向远离图案的方向。

Rule
- 对每个箭头，确定其指向方向 D 和杆长度 L（不含箭头尖端的像素数）。
- 确定箭头所依附的图案区域 P。
- 将图案区域 P 的全部内容沿方向 D 平移 (L + 图案在 D 方向的宽度) 个像素的距离，在新位置绘制一份 P 的副本。
- 原图案 P 保持不变。箭头的 red 像素在输出中被清除为 black。
- 若多个推印副本发生重叠，后处理的（箭头杆更长的）副本覆盖先处理的。

Key insight
- 箭头的朝向编码推印方向，杆的长度编码推印距离（即图案副本与原图案之间的间隔），解题者需要同时解码方向和距离两个参数；而箭头自身在输出中消失，暗示它是纯指令符号而非输出内容的一部分。
</description>
</new_puzzle>

<description>
根据封闭围栏内"种子"像素的颜色查找外部对应的生长模板，再以种子位置为锚点将模板生长到围栏内部的空白区域。

Input structure
- 背景为 black。网格中有一个由 grey 像素围成的大型封闭矩形围栏（围栏为单像素宽的完整矩形边框）。
- 围栏内部大部分为 black，但散布着若干单独的彩色像素（"种子"），每个种子颜色不同。
- 围栏外部散布着若干小型彩色图案（"生长模板"），每个模板是一个连通的多像素形状，由单一颜色绘制。每个模板的颜色与围栏内某个种子的颜色一一对应。
- 每个模板形状中恰好有一个像素被标记为 maroon（与模板其余像素颜色不同），该 maroon 像素标识模板的"锚点"。

Rule
- 对围栏内的每个种子像素，找到围栏外部与其同色的生长模板。
- 将模板的 maroon 锚点对齐到种子像素的位置，把模板的其余像素（保持模板颜色）绘制到围栏内部对应的位置上。
- 若模板的某些像素对齐后落在围栏边框上或围栏外部，则这些像素被裁剪掉（不绘制）。
- 种子像素本身被模板锚点覆盖后变为该模板的颜色（即保持种子原色）。
- 围栏外部的模板和 maroon 锚点在输出中保持不变。围栏的 grey 边框保持不变。

Key insight
- 解题者需要先通过颜色匹配建立种子与外部模板的对应关系，再识别 maroon 像素是锚点定位符而非普通内容像素——颜色匹配和锚点对齐构成两层需要分别归纳的推理结构。
</description>
</new_puzzle>

<new_puzzle>
<description>
将网格中多层嵌套的彩色环拆解，根据环的嵌套深度决定输出位置，形成从左到右按深度排列的环序列。

Input structure
- 背景为 black。网格中央有若干层同心的单像素宽矩形环（每层环为不同颜色），最外层环最大，逐层向内缩小，每层环与相邻层之间间隔恰好 1 像素的 black 间隙。
- 环的层数为 2 到 5 层不等。每层环的颜色各不相同，且环是完整的矩形框（无缺口）。
- 最内层环内部可能包含一个单色实心矩形填充，也可能为空（纯 black）。

Rule
- 识别所有矩形环，按嵌套深度从外到内编号（最外层深度为 1，次外层为 2，以此类推；若最内层是实心填充而非环，则视为最大深度层）。
- 输出网格的高度等于最外层环的高度，宽度等于所有环的宽度之和加上环之间的 1 像素 black 间隔。
- 从左到右依次放置每层环/填充，按深度从浅到深排列：深度 1 的环在最左边，深度最大的在最右边。每层之间用 1 列 black 像素分隔。
- 每层环在垂直方向上居中对齐（若环高度小于输出高度，上下用 black 填充使其居中）。

Key insight
- 嵌套的同心环在视觉上是一个整体结构，解题者需要先将其"剥离"为独立层，再理解深度到水平位置的映射规则——从嵌套空间结构到线性排列的维度转换是核心推理难点。
</description>
</new_puzzle>
