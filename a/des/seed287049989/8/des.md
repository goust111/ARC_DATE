<new_puzzle>
description: 根据框架边框上的缺口位置，将框架内部的彩色碎片向缺口反方向滑动堆叠，再用框架自身的颜色重新着色堆叠后的碎片。

Input structure:
- 背景为 black。网格中散布若干大小不同的矩形空心框架，每个框架由单一颜色绘制（如 red、blue、green 等），框架线宽为 1 像素。
- 每个框架的四条边中恰好有一条边存在一个连续缺口（缺口宽度 >= 2 像素，缺口处为 black 背景色）。
- 框架内部散布若干小型单色连通碎片（每个碎片 2-4 像素），碎片颜色与框架颜色不同，且同一个框架内部的碎片可能有多种颜色。

Rule:
- 对每个框架，首先确定缺口所在的边（上、下、左、右）。
- 将框架内部所有碎片沿缺口的反方向滑动（即远离缺口方向），直到碎片触碰框架的对侧内壁或已堆叠的碎片为止（类似重力效果，碎片保持自身形状不变）。滑动顺序为：距离对侧内壁最近的碎片先滑动。
- 滑动完成后，将所有堆叠碎片的颜色统一替换为框架自身的颜色。
- 框架线条保持不变，缺口保持不变。

Key insight: 缺口不是碎片的出口，而是"重力方向"的反向指示器——碎片向远离缺口的方向堆叠；第二层推理在于碎片最终颜色由所属框架决定，而非碎片原有颜色，解题者需要从多个样例中发现这一着色替换规则。
</new_puzzle>

<new_puzzle>
description: 在由分隔线划分出的多个区域中，根据每个区域内种子像素的颜色进行有限步洪水扩散，扩散步数由该区域轮廓的边段数量决定。

Input structure:
- 背景为 black。网格中有一组 maroon 色的直线段（水平或垂直，宽 1 像素）作为分隔线，将网格分割成若干多边形区域（每个区域由若干矩形块拼合而成，整体轮廓可为 L 形、T 形、矩形等）。
- 每个区域内恰好有一个非 black、非 maroon 的单像素"种子"（颜色各不相同，可为 red、blue、green、yellow、orange 等）。
- 所有区域的种子颜色互不重复。

Rule:
- 对每个区域，沿着该区域的内部轮廓行走，数出轮廓由多少段水平或垂直线段组成（每当轮廓转弯 90 度，就开始新的一段；一个简单矩形区域有 4 段，一个 L 形区域有 6 段或 8 段，以此类推）。
- 从种子像素开始，进行四方向洪水扩散，扩散步数 = 轮廓边段数 / 2（整数除法向下取整）。即：第 1 步扩散填充种子的四邻域中属于该区域的 black 像素，第 2 步填充第 1 步新填色像素的四邻域中属于该区域的 black 像素，依此类推，总共扩散步数不超过计算值，且不超过区域边界。
- 扩散覆盖的 black 像素被替换为种子颜色，种子本身保留。
- 分隔线（maroon）保持不变。未被扩散覆盖的区域内像素保持 black。

Key insight: 第一层推理需要识别分隔线将网格切分成的区域及其形状；第二层推理需要发现扩散步数与区域轮廓复杂度之间的隐含对应——轮廓边段越多的区域（形状越复杂）允许更多步扩散，而简单矩形（4 段）只扩散 2 步。解题者需要主动去数轮廓边段数才能理解扩散范围的差异。
</new_puzzle>

<new_puzzle>
description: 在棋盘格布局中，根据方块内部微小标记点的位置判断弹出方向，沿该方向逐格推移整行或整列方块，最后用邻居多数颜色填充空缺。

Input structure:
- 背景为 black。网格被划分为规整的 N×N 棋盘格（N 为 4 或 5），每个格子为 3×3 像素的单色方块，方块之间以 1 像素宽的 grey 分隔线隔开。
- 棋盘中恰好有两个方块内部带有一个 1 像素的 black 标记点，标记点位于方块 3×3 区域的上边缘中央（第 0 行第 1 列）、下边缘中央（第 2 行第 1 列）、左边缘中央（第 1 行第 0 列）或右边缘中央（第 1 行第 2 列）位置之一。
- 其余方块为各种非 black、非 grey 的纯色填充，无标记。

Rule:
- 对每个带标记的方块，标记点所在的边缘指示该方块的"弹出方向"（上边缘标记 → 向上弹出，右边缘标记 → 向右弹出，以此类推）。
- 弹出操作：将该方块所在行（水平弹出时）或所在列（垂直弹出时）上、从该方块到弹出方向边缘的所有方块，整体沿弹出方向平移一个格子。最外侧的方块被推出棋盘消失，被标记方块原位变为空位（black 填充 3×3）。
- 两个带标记方块按从上到下、从左到右的顺序依次处理（先处理第一个弹出，再处理第二个）。
- 所有弹出完成后，对每个空位格子：查看其在棋盘格中上下左右四个相邻格子（不含对角，且必须在棋盘范围内）的颜色，取出现次数最多的颜色填入该空位。若有并列，选择在相邻格子中位置靠上的那个格子的颜色；若仍并列，选靠左的。

Key insight: 第一层推理需要从方块内极小的 1 像素标记点位置推断弹出方向，标记很不显眼，增加了观察难度；第二层推理需要理解弹出引起的同行或同列连锁平移（非单一方块移动）；第三层推理需要发现空位的填充规则来自相邻方块的多数颜色投票。
</new_puzzle>

<new_puzzle>
description: 将网格中散落的彩色 L 形拼块旋转后嵌入灰色模板的缺口中，拼入后拼块颜色由缺口旁的隐藏色标决定。

Input structure:
- 背景为 black。网格中央偏左有一个较大的 grey 色连通区域作为"模板"，模板整体近似矩形但边缘有若干 L 形缺口（每个缺口恰好占据 3 个像素，形成直角 L 形，即 2×2 区域去掉一个角的形状）。
- 网格右侧或边缘散落若干彩色 L 形拼块（每块恰好 3 像素，形状与缺口相同），每块颜色各不相同（如 red、blue、green、yellow 等）。
- 拼块数量等于模板缺口数量。
- 每个缺口的外侧紧邻位置（与缺口共享一条边但不属于模板的像素处）有一个单像素的彩色"色标"，色标颜色与所有拼块颜色均不相同。

Rule:
- 每个 L 形拼块需要经过 0 度、90 度、180 度或 270 度旋转后，恰好嵌入模板的某个缺口中（旋转后形状与缺口完全吻合）。由于 L 形在四种旋转下产生四种不同朝向，每个拼块与缺口之间的匹配是唯一的。
- 将拼块平移并旋转到对应缺口位置，补全模板边缘。
- 嵌入后，拼块的颜色不保留原色，而是替换为该缺口旁色标的颜色。
- 原始拼块位置清除为 black，色标像素在输出中移除（变为 black）。
- 模板的 grey 像素保持不变。

Key insight: 第一层推理需要通过 L 形的旋转匹配找到每个拼块与缺口的一一对应关系；第二层推理需要发现拼块最终颜色不由自身决定，而由缺口旁不起眼的单像素色标决定——色标是隐含的重着色指令，很容易被误认为是背景噪声。
</new_puzzle>

<new_puzzle>
description: 网格中多条不同颜色的折线在交叉点处显示为特殊颜色，输出时每条折线根据其经过的交叉点数量查色带重新着色。

Input structure:
- 背景为 black。网格上有若干条不同颜色的折线（每条折线由连续的水平和垂直线段组成，线宽 1 像素，每条折线使用一种独特颜色，如 blue、red、green、orange 等）。
- 当两条折线在同一像素位置交叉时，该像素显示为 yellow（作为交叉标记色，yellow 不作为任何折线本身的颜色使用）。
- 网格最底行有一条"色带"——从左到右依次排列若干种颜色的单像素色块，相邻色块之间以 1 像素 black 间隔。色带中的颜色可能与折线原色不同。色带从左到右的位置编号为 1、2、3……

Rule:
- 对每条折线，先还原其完整路径：折线的连通段加上路径上的 yellow 交叉点构成该折线的完整轨迹。识别方法为：每个 yellow 像素恰好被两条折线共享，沿着折线颜色的连通段可追踪到 yellow 像素两侧属于同一折线的两个端口。
- 数出每条折线经过的 yellow 交叉点个数 K。
- 在底部色带中找到从左起第 K 个色块的颜色。
- 将该折线上所有非 yellow 像素替换为色带中查找到的颜色。
- yellow 交叉点像素保持不变。
- 色带在输出中保留不变。

Key insight: 第一层推理需要通过 yellow 交叉点还原出各条折线的归属关系——交叉处被统一染为 yellow，解题者必须追踪连通性来判断哪些线段属于同一条折线；第二层推理需要发现"交叉点计数 → 色带位置查表"的映射规则，即折线的新颜色由它穿越的交叉点数量在色带中索引得到。
</new_puzzle>

<new_puzzle>
description: 在多层同心矩形环中，从每层环的缺口向内发射射线，射线遇到无缺口的内环时借助该内环的缺口转向，最终标记环心命中位置。

Input structure:
- 背景为 black。网格中央有一组同心矩形环（3 层），从外到内每层环由不同颜色绘制（如最外层 blue、中层 red、最内层 green），每层环线宽 1 像素。
- 环心区域为一个 3×3 的 grey 填充方块。
- 每层环的四条边上恰好有一个 1 像素宽的缺口（该位置为 black 而非环的颜色）。缺口位于该边的中点附近。不同层环的缺口不在同一条直线上。

Rule:
- 从最外层环开始处理，依次处理每一层。对于当前层的缺口，从缺口处沿该边的法线方向向环心发射射线（例如上边缺口 → 射线向下，左边缺口 → 射线向右）。
- 射线向内行进时，如果遇到下一层环的像素：检查射线当前行进路径上该内环是否有缺口——若有缺口（即射线路径经过该内环的缺口位置），射线直接穿过继续前进；若没有缺口（射线被内环壁阻挡），则射线发生转向：找到该内环自身缺口的位置，射线改为朝该缺口方向水平或垂直行进，到达缺口后穿过，继续向环心方向行进。
- 射线最终到达 grey 环心区域时，将命中的那个像素标记为发射该射线的那层环的颜色。
- 每层环独立发射一条射线，因此环心最终可能有多个不同颜色的标记像素。
- 环结构和缺口在输出中保持不变。

Key insight: 每层环的缺口既是本层射线的发射口，又可能成为外层射线被阻挡后的转向目标——解题者需要逐层追踪射线路径，理解"阻挡 → 寻找同层缺口 → 转向"的反射机制。环心最终的彩色标记位置编码了射线经过多次转向后的最终落点，需要空间追踪推理才能预测。
</new_puzzle>

<new_puzzle>
description: 网格由若干彩色水平条纹组成，每个条纹内嵌有不同数量的小孔；根据小孔数量在独立的颜色图例中匹配目标颜色，然后用目标颜色重绘该条纹。

Input structure:
- 网格分为左右两个区域，以一列 grey 像素作为分隔。
- 左侧区域：包含若干水平条纹，每个条纹高 1 像素、宽度等于左侧区域宽度，每个条纹使用不同颜色（如 red、blue、green、orange 等），条纹之间以 1 行 black 间隔。每个条纹内部有若干像素被挖为 black（形成"小孔"），每个条纹的小孔数量不同（范围在 1-5 之间）。
- 右侧区域：包含一个"颜色图例"。图例由若干行组成，每行有一个彩色像素紧跟若干个 black 像素后紧跟若干个与该彩色像素同色的圆点（即小色块），格式为：[颜色像素] [间隔 black] [N 个同色像素]，其中 N 为 1-5 之间的不同值，每行的 N 各不相同。图例的颜色与左侧条纹颜色完全不同。

Rule:
- 对左侧每个条纹，数出该条纹中 black 小孔的数量 K。
- 在右侧图例中，找到点数恰好为 K 的那一行，读取该行的颜色 C。
- 将左侧该条纹的所有像素（包括小孔）统一替换为颜色 C，即用图例颜色 C 完整填充该条纹（小孔被填平）。
- 右侧图例和 grey 分隔线保持不变。

Key insight: 第一层推理需要发现左侧条纹中的小孔不是随机缺陷而是编码了一个数量信息；第二层推理需要发现右侧图例中点的数量与左侧孔的数量之间的匹配关系，并据此进行跨区域的颜色映射——条纹的原始颜色完全被丢弃，目标颜色完全由孔数在图例中查找决定。
</new_puzzle>
