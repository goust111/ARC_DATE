<new_puzzle>
用每个封闭区域内部散落的彩色种子像素的颜色，重新填充该区域的边框，同时根据种子像素的数量决定边框的绘制层数。

Input structure：
- 网格以一种主色为背景。
- 前景中有若干个由同一种边框色（如 blue）绘制的封闭矩形边框，边框厚度为一个像素。
- 每个矩形边框内部散布着若干个彩色单像素点（种子），每个矩形内部的种子全部同色，但不同矩形内的种子颜色各不相同。
- 种子像素的颜色与边框色不同，也与背景色不同。

Rule：
- 对每个封闭矩形边框，收集其内部所有种子像素。
- 统计种子像素数量 N。
- 将该矩形的边框色替换为种子的颜色，并向内再绘制 N-1 层同色边框环（即总共 N 层边框环）。若矩形内部空间不足以容纳 N 层，则填满为止。
- 清除所有种子像素（内部恢复为背景色，已被边框环覆盖的位置除外）。

Key insight：
种子像素承担双重角色——它们的颜色决定了边框的输出色，它们的数量决定了边框向内扩展的层数。解题者需要同时归纳出颜色映射和计数驱动几何变化这两层规律。
</new_puzzle>

<new_puzzle>
将网格中分散的同色碎片按照"拼图模板"的形状归位，模板由另一种颜色的镂空区域定义，匹配依据是碎片集合的总面积与模板镂空区域的面积一致。

Input structure：
- 网格以一种主色为背景。
- 存在若干个大型纯色实心矩形块（模板块），每个模板块内部被挖去了一个不规则的连通区域（镂空），镂空处显示为背景色。
- 不同模板块的颜色各不相同。
- 在模板块之外的背景区域中，散落着若干组小型 4-连通色块（碎片），每组碎片颜色相同，但与所有模板块颜色不同。
- 每组碎片的像素总数恰好等于某个模板块的镂空区域像素数，且碎片能无重叠、无间隙地拼合填满该镂空。

Rule：
- 对每个模板块，提取其镂空区域的形状（相对坐标集合）。
- 对每组同色碎片，统计其像素总数，与各模板镂空面积匹配，找到唯一面积相等的配对。
- 将匹配的碎片组平移至对应模板的镂空区域内，找到唯一的拼合方式使碎片恰好填满镂空。
- 碎片从原位置擦除（恢复背景），在镂空区域内用碎片颜色绘制。
- 碎片组与模板镂空之间是一一对应关系。

Key insight：
碎片到模板的匹配不是通过颜色对应，而是通过面积相等来确定；找到匹配后，还需要推理出碎片在镂空内的唯一拼合位置。解题者必须先完成面积匹配的归纳，再完成空间拼合的推理。
</new_puzzle>

<new_puzzle>
根据箭头指示的方向将色带"推入"相邻的空框中，色带在框内折叠堆积，堆积顺序由色带离框的远近决定。

Input structure：
- 网格以一种主色为背景。
- 存在若干个由 grey 像素绘制的空心矩形框（内部为背景色），框的厚度为一个像素。
- 每个框的某一侧外部紧邻着一组平行的彩色水平或垂直色带（单像素宽的直线段），色带颜色各不相同。
- 在色带与框之间（紧贴框壁外侧）有一个由 red 像素绘制的箭头形状，箭头指向框的内部。箭头由三个像素构成：一个尖端像素最靠近框壁，另外两个像素在尖端的反方向一格处沿垂直轴对称排列。

Rule：
- 对每个框，识别其外侧的箭头和色带组。
- 箭头的尖端方向指示色带被推入框内的方向。
- 色带按照距离框壁由近到远的顺序，依次"推入"框中：最近的色带先进入，沿箭头方向填充框内第一行/列；第二近的填充第二行/列，依此类推。
- 每条色带在框内保持其原始长度；若色带长度超过框在垂直于推入方向上的内部宽度，则截断至框内宽度；若色带长度不足，则靠框内对应维度的起始侧对齐。
- 色带推入后，其原始位置和箭头均被擦除（恢复为背景）。

Key insight：
箭头不仅决定了推入的方向，还隐含地定义了色带的排序轴——色带沿箭头反方向到框壁的距离决定了它们在框内的堆叠层次。解题者需要先从箭头推断方向，再从空间距离推断排列顺序。
</new_puzzle>

<new_puzzle>
根据小图案在各子区域中的旋转状态，选择对应的颜色映射方案，对该子区域内的标记像素重新着色。

Input structure：
- 网格以一种主色为背景，被均匀分割为若干个大小相等的正方形子区域（如 6x6），子区域之间由单像素宽的 grey 分隔线隔开。
- 网格的左上角子区域是"图例区"：其中包含一个由 red 像素绘制的小型 L 形图案（两条臂分别朝两个正交方向，各长两个像素，共享一个拐角像素），L 形的每条臂的末端像素外侧紧邻一个独特颜色的单像素（如朝上的臂末端上方为 green，朝右的臂末端右方为 blue）。
- 其余每个子区域中都有一个与图例中形状相同但可能经过 0/90/180/270 度旋转的 red L 形图案，以及若干个 maroon 色的单像素标记散布在子区域的背景位置上。

Rule：
- 在图例子区域中，建立 L 形每条臂的朝向到其末端相邻颜色的映射。L 形有两条臂，产生两组方向-颜色对应。
- 对每个非图例子区域，判断其 L 形图案相对于图例 L 形的旋转角度（0/90/180/270 度）。
- 确定旋转后 L 形较长臂（若两臂等长则取顺时针方向第一条臂）在当前子区域中的实际朝向，回溯该朝向在图例中原始对应的颜色，作为该子区域的"活跃颜色"。
- 将该子区域中所有 maroon 标记像素替换为活跃颜色。
- L 形图案、分隔线和图例区保持不变。

Key insight：
图例中 L 形臂的方向与颜色的对应关系是一张查找表，但其他子区域中 L 形被旋转了，解题者必须先判断旋转角度，再通过逆旋转回溯到图例的原始方向映射，才能确定正确的着色方案。旋转状态编码了颜色选择，这是核心的隐蔽机制。
</new_puzzle>

<new_puzzle>
将网格中每条彩色折线路径按其经过的"染色线"依次分段变色，每段的颜色由路径行进方向上最近一次穿过的染色线决定。

Input structure：
- 网格以一种主色为背景。
- 存在若干条由不同颜色绘制的单像素宽折线路径（路径仅做水平和垂直转弯），每条路径的两个端点位于网格边缘。
- 网格中有若干条特殊的完整行或完整列，由单一非背景色像素填满（"染色线"），这些染色线的颜色各不相同，且与所有路径的初始颜色不同。
- 路径与染色线在交叉处重叠时，交叉点显示路径颜色（路径层在前）。

Rule：
- 对每条路径，确定其起点：若路径有端点在网格左边缘则从左端点开始；否则从上边缘端点开始。
- 沿路径从起点向终点行走。路径初始保持其原色。
- 当路径穿过一条染色线时，从该交叉点的下一个像素开始，路径颜色变为该染色线的颜色。交叉点本身保持路径在变色前的颜色。
- 若路径随后穿过另一条染色线，则从新交叉点的下一个像素开始，路径颜色再次更新为新染色线的颜色。
- 依此类推，路径被分割为若干段，第一段保持原色，后续每段取前方最近染色线的颜色。
- 染色线本身在输出中保持不变。

Key insight：
染色线不是背景装饰——它们是改变路径颜色的"关卡"。解题者需要先识别哪些完整行/列是染色线（与路径区分），然后沿每条路径追踪其与染色线的交叉顺序，才能确定每段的输出颜色。路径有转弯，因此交叉顺序取决于沿路径的行走距离而非简单的行列坐标。
</new_puzzle>

<new_puzzle>
利用网格边缘的色条作为"周期尺"，对内部每个同色对象沿其最长轴方向生成与色条段长度对应的周期性条纹填充。

Input structure：
- 网格以一种主色为背景。
- 网格的顶部第一行是一条色条序列：由若干段不同颜色的连续像素拼接而成，每段长度不同（长度范围 1 到 5），段与段之间无间隔。色条从第一列开始，可能不占满整行（剩余为背景色）。
- 网格内部（第二行起）有若干个不同颜色的实心 4-连通对象，每个对象的颜色恰好与顶部色条中某一段的颜色相同。
- 各对象的颜色互不相同，与色条段一一对应。

Rule：
- 对每个内部对象，在顶部色条中找到与其颜色相同的那一段，记录该段的像素长度 L。
- 确定该对象包围盒的最长边方向（宽 >= 高则为水平，否则为垂直）。
- 沿最长边方向，对对象内的像素按行（水平时）或按列（垂直时）编号，从 0 开始。
- 编号除以 L 后，偶数组（第 0、2、4... 组）保持原色，奇数组（第 1、3、5... 组）变为 grey。每组包含连续 L 个像素。
- 顶部色条行在输出中保持不变。

Key insight：
顶部色条的段长度不是装饰性分隔——每段的长度编码了对应颜色对象的条纹周期。解题者必须先测量色条中各段的长度，再将长度映射为填充频率，而非简单地按颜色对应替换。颜色仅用于匹配对象与色条段，真正的变换参数藏在段的几何长度中。
</new_puzzle>

<new_puzzle>
在网格中找到被 U 形"信封"包裹的矩形"信件"，根据信封开口方向将信件弹出并平移至网格边缘对齐。

Input structure：
- 网格以一种主色为背景。
- 存在若干个由不同颜色绘制的 U 形对象（"信封"），每个 U 形由一个矩形边框去掉一条完整的边构成，边框厚度为一个像素。缺失的边定义了开口方向（上、下、左或右）。
- 每个 U 形的凹槽内部恰好有一个由另一种颜色绘制的小型实心矩形（"信件"），信件与 U 形边框之间至少有一个像素的背景间隔，信件完全在 U 形包围盒内部。
- 网格中可能有其他孤立的单像素点作为干扰项，其颜色与所有信封和信件颜色均不同。

Rule：
- 对每个 U 形信封，确定其开口方向（缺失边框的那一侧）。
- 将信封内的信件对象沿开口方向平移，直到信件的前进边缘与网格边界齐平（即信件紧贴该方向的网格边缘）。
- 信件在新位置用其原色绘制；信件原位置恢复为背景色。
- U 形信封自身保持原位不变。
- 干扰像素保持不变。

Key insight：
U 形的结构缺口同时编码了两个信息：哪个矩形是它的"信件"（在凹槽内部的那个），以及信件应该沿哪个方向弹出（开口方向）。解题者需要先通过 U 形的形态分析推断开口方向，再识别配对的内部矩形，最后执行方向性平移。
</new_puzzle>

<new_puzzle>
网格中散布着若干"印章"和"印泥"对象，每个印章在其正下方的空白区域盖印，盖印图案是印章形状的垂直镜像，盖印颜色由印章内部嵌入的印泥色点决定。

Input structure：
- 网格以一种主色为背景。
- 存在若干个由 blue 像素绘制的不规则 4-连通对象（"印章"），每个印章内部恰好嵌入一个非 blue、非背景色的单像素（"印泥色点"），各印章的印泥色点颜色可能不同。
- 每个印章下方（从印章包围盒底边向下）有足够的背景空间容纳其垂直镜像。
- 印章之间在水平方向上的包围盒不重叠。

Rule：
- 对每个印章，提取其完整形状（包括印泥色点所在位置）。
- 将印章形状沿水平轴做垂直镜像翻转。
- 将翻转后的形状放置在印章包围盒正下方紧邻的位置（翻转图案的顶行紧贴印章包围盒底行的下一行，水平位置对齐）。
- 盖印图案中，原本为 blue 的像素改用该印章的印泥色点颜色绘制；原本为印泥色点的位置也用印泥颜色绘制（即整个盖印图案统一使用印泥颜色）。
- 原始印章保持不变（包括其中的印泥色点）。

Key insight：
印章的几何形状决定了盖印的图案轮廓（垂直镜像），而嵌入的印泥色点决定了盖印的颜色。解题者需要分别识别这两个独立的信息来源——形状来自整个印章轮廓，颜色来自内部异色点——并将它们组合应用。
</new_puzzle>
