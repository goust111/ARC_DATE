<new_puzzle>
<description>
根据封闭区域内部"种子"像素的颜色，在区域的边框上找到同色缺口标记，然后从缺口向外生长出与区域内部面积等长的射线。

Input structure
- 背景为主色（如 black）。
- 网格中有若干由同一边框颜色（如 grey）绘制的封闭矩形边框，每个边框的某一条边上恰好有一个单像素宽的缺口（缺口处为背景色）。
- 每个矩形内部恰好有一个非背景、非边框颜色的"种子"像素（颜色各不相同，如 red、blue、green 等）。
- 在每个矩形的边框上，恰好有一个像素被染成了与该矩形内部种子像素相同的颜色——该像素位于缺口所在的那条边上，紧邻缺口。

Rule
- 对每个矩形，首先找到其内部种子像素的颜色 C。
- 在边框上找到颜色为 C 的像素，确定缺口的位置和朝外的方向（上、下、左、右）。
- 数出该矩形边框所围内部面积（内部行数 × 内部列数）的像素数量 N。
- 从缺口处沿朝外方向绘制一条长度为 N 的射线，颜色为 C。射线的每个像素占一格，若碰到网格边界则截断。
- 输出中保留所有矩形边框（包括缺口）和种子像素不变，仅新增射线。

Key insight
种子颜色同时承担两个角色：它标记了缺口的位置（通过边框上的同色像素定位缺口方向），又决定了射线的颜色；而射线长度由封闭区域的内部面积决定，需要解题者分别推断"方向来源"和"长度来源"这两层独立规律。
</description>
</new_puzzle>

<new_puzzle>
<description>
在网格中找到由路径颜色连通的配对端点，沿路径传播端点颜色使其在路径中点处交汇，交汇格填入第三种"混合"颜色——该混合颜色由网格角落的色表定义。

Input structure
- 背景为主色（如 black）。
- 网格的左上角有一个小型色表区域（3 行 3 列）：每行前两格为两个不同颜色的像素——表示一对"输入色"，第三格为"混合结果色"。例如第一行为 red、blue、magenta，表示 red 和 blue 混合得 magenta。色表区域与网格其余部分之间用一行或一列背景色隔开。
- 网格其余区域散布着若干条由同一路径颜色（如 grey）构成的一像素宽的直线或折线路径。
- 每条路径的两个端点处各有一个非背景、非路径颜色的彩色像素（两端颜色不同）。

Rule
- 对每条路径，找到两端的颜色 A 和 B。
- 从端点 A 沿路径向内逐格染色 A，同时从端点 B 沿路径向内逐格染色 B。两侧各染至路径长度的一半。
- 当路径上 grey 像素总数为奇数时，中间恰好剩余一格；当为偶数时，两侧各染一半，无中间格。
- 对奇数长度路径的中间格，查色表找到 (A, B) 或 (B, A) 对应的混合色 M，将该格染为 M。
- 路径两端的原始彩色端点像素保留不变。色表区域在输出中保持不变。

Key insight
解题者需要先发现路径被两端颜色从两头向中间"对称填充"的规律（第一层推理），再发现中间交汇格的颜色并非来自端点之一，而是由角落色表定义的"混合"映射决定（第二层推理）。色表是解码交汇色的关键，但它藏在角落且形式紧凑，容易被忽略。
</description>
</new_puzzle>

<new_puzzle>
<description>
每个前景对象根据自身包含的"孔洞"数量，在网格底部的颜色图例中查找对应颜色，然后用该颜色重绘对象的外轮廓，对象内部恢复为背景色。

Input structure
- 背景为主色（如 black）。
- 网格上半部分有若干个由同一颜色（如 grey）绘制的不规则封闭形状（8-连通），每个形状内部可能包含 0、1、2 或 3 个背景色"孔洞"（4-连通的背景色封闭区域，即完全被形状像素包围的背景色连通块）。
- 网格最底部一行是颜色图例：从左到右依次排列 4 个不同颜色的单像素点（如 red、blue、green、yellow），相邻两点之间用一个背景色像素间隔，代表孔洞数 0、1、2、3 对应的输出颜色。

Rule
- 对上半部分每个 grey 形状，数出其内部 4-连通背景色封闭孔洞的数量 K（0 至 3）。
- 在底部图例中，取从左到右第 K+1 个颜色像素的颜色 C。
- 找出该形状的外轮廓：即所有至少有一个 4-邻居为外部背景色（属于形状外围的背景色，非孔洞内的背景色）的形状像素。
- 将外轮廓像素染为颜色 C，形状内部所有非轮廓的 grey 像素全部恢复为背景色，孔洞保持为背景色。
- 底部图例行在输出中被移除（输出网格高度减少一行）。

Key insight
解题者首先需要发现"孔洞数量"是区分各对象的关键属性（第一层：属性识别），然后发现底部色条是按位置编码的数量-颜色映射表（第二层：图例解码），最后发现输出并非简单重染整个对象，而是只保留外轮廓并清空内部（第三层：变换方式）。三层规律需要逐步归纳。
</description>

<new_puzzle>
<description>
网格中有若干"箭头"形状和若干色带；箭头"射向"同色色带，命中后箭头消失，色带沿箭头来路方向扩展与箭头主干等长的距离。

Input structure
- 背景为主色（如 black）。
- 网格中有若干水平或垂直的单色带状区域（宽一格、长度不等），每个色带使用不同颜色（如 red、blue、green 等）。
- 网格中有若干"箭头"形状。箭头的绘制方式为：一条直线段（长 2~4 格）为箭头主干，主干的一端（尾端）带一个垂直于主干方向的 3 像素横杠（横杠中心与主干尾端重合），形成 T 形。T 形横杠所在端为尾部，另一端（无横杠的端点）为尖端，尖端指向射出方向。
- 每个箭头的颜色与某一条色带的颜色相同，且箭头的尖端朝向该色带方向，与色带在同一行或同一列上对齐。
- 箭头与其目标色带之间只有背景色。

Rule
- 对每个箭头，确定其指向方向（尖端方向）。
- 箭头在输出中被完全擦除（所有像素变为背景色）。
- 目标色带在箭头来路方向（即箭头尖端朝向色带的那一侧）扩展，扩展长度等于箭头主干的长度（仅计主干直线段的格数，不含横杠）。扩展部分颜色与色带相同。
- 如果多个箭头指向同一色带的同一侧，扩展长度取这些箭头主干长度之和。
- 色带其余部分保持不变。

Key insight
解题者需要首先识别 T 形结构是箭头并推断指向规则——横杠在尾部、无横杠端为尖端（第一层推理）；然后发现箭头颜色匹配目标色带颜色，箭头消失后色带反向扩展的因果关系（第二层推理）；扩展长度等于箭头主干长度这一量化关系需要从多个样例中对比归纳（第三层推理）。
</description>

<description>
网格被中间灰色分隔线分为左右两个面板；左面板中每个彩色形状是某个对称图案的"折叠片段"，右面板中有对应颜色的种子像素标记展开中心；根据片段的边缘特征推断折叠类型，在种子位置展开为完整对称图案。

Input structure
- 背景为主色（如 black）。
- 网格正中有一列 grey 分隔线将网格分为等宽的左面板和右面板。
- 左面板包含若干个小型彩色形状（各不相同颜色，如 red、blue、green），每个形状占据不超过 4x4 的区域。这些形状是某个完整对称图案的一个"折叠片段"。
- 折叠类型判断依据：观察形状包围盒内的像素分布——
  - 若形状像素同时填满了包围盒的最右列和最底行（即右下角像素存在），则该形状是完整图案的左上四分之一，需沿右边缘和下边缘双轴镜像展开为 4 倍大小。
  - 若形状像素填满了包围盒的最右列但最底行未全部填满，则该形状是完整图案的左半部分，需沿右边缘单轴左右镜像展开。
  - 若形状像素填满了包围盒的最底行但最右列未全部填满，则该形状是完整图案的上半部分，需沿下边缘单轴上下镜像展开。
- 右面板中，每种出现在左面板的颜色恰好有一个单独的种子像素，标记展开后完整图案的中心位置。

Rule
- 对左面板中的每个彩色形状 S（颜色 C），按上述规则判断折叠类型。
- 根据折叠类型执行镜像展开，得到完整图案。双轴展开时：先将 S 沿右边缘向右镜像得到上半部分，再将整个上半部分沿下边缘向下镜像得到完整图案。单轴展开时，仅沿对应边缘镜像一次。
- 在右面板中找到颜色 C 的种子像素位置 P，以 P 为完整图案的几何中心，绘制完整图案。
- 输出仅包含右面板（裁去左面板和分隔线），宽度为原始右面板宽度。

Key insight
解题者需要先发现左面板的形状不是完整图案而是需要展开的片段（第一层推理），再通过观察形状包围盒边缘的填充情况区分"四分之一折叠"和"二分之一折叠"及其轴向（第二层推理），最后将展开结果正确放置到右面板种子位置（第三层推理）。折叠类型的判断隐藏在边缘像素的微妙差异中。
</description>

<description>
网格中有若干"容器"矩形和散落的同色像素；容器吸收同色散落像素，根据这些像素相对于容器的空间方位（由四角色标定义）在容器内部分区域填色。

Input structure
- 背景为主色（如 black）。
- 网格四个角落各有一个固定的单像素"方位色标"：左上角为 green，右上角为 yellow，左下角为 orange，右下角为 magenta。
- 网格中有 2~3 个空心矩形"容器"，各使用不同的边框颜色（如 red、blue）。容器内部全部为背景色，内部空间不小于 2x2。
- 容器外部散布着若干单独的彩色像素，每个像素的颜色与某一个容器边框颜色相同。

Rule
- 对每个容器 R（边框颜色 C），收集网格中所有颜色为 C 的散落像素（不含边框自身像素）。
- 对每个散落像素 P，判断 P 相对于容器 R 中心的方位象限：P 在 R 中心的左上方则归类为 green，右上方为 yellow，左下方为 orange，右下方为 magenta。若 P 恰好在中心行上则按上方算，恰好在中心列上则按左方算。
- 统计每个方位象限的像素数量。按固定方位顺序 green、yellow、orange、magenta，在容器内部从左上角第一格开始，逐格从左到右、从上到下依次填入：先填 green 对应数量的 green 格，再填 yellow 对应数量的 yellow 格，依此类推。若容器内部空间不足则截断。
- 容器边框保持不变，散落像素在输出中被擦除（变为背景色），四角方位色标保持不变。

Key insight
解题者首先需要发现散落像素按颜色"归属"于同色边框的容器（第一层推理），然后发现角落四像素不是普通对象而是"方位图例"——散落像素的空间方位通过角落色标转换为填充颜色（第二层推理），最后发现容器内部按固定方位序、逐行扫描的方式排列填色（第三层推理）。角落色标既是方位编码器又极易被误认为无关装饰。
</description>

<description>
网格中多个小图案放置在闭合环形传送带的站点上；图案沿传送带方向循环移位一步，经过路径上的旋转标记时额外顺时针旋转 90 度。

Input structure
- 背景为主色（如 black）。
- 网格中有一条由 grey 像素构成的单像素宽的闭合环形路径（传送带），路径沿水平和垂直方向折线延伸，首尾相连形成封闭环。
- 路径外侧间隔分布着若干"站点"——每个站点是路径旁紧邻的一个 2x2 空位（三面被路径像素包围，一面朝向路径外侧为开口）。站点内部为背景色或放置有图案。
- 每个站点空位中放置着一个 2x2 的小图案，使用同一种非背景、非 grey 的颜色（如 blue），但 2x2 中被填充的格子组合各不相同（例如可能是左上+右下两格，或左上+左下+右上三格等）。
- 路径上某些位置有特殊标记像素：该像素颜色为 maroon（区别于 grey 路径色），位于相邻两站点之间的路径段上。每两个相邻站点之间至多有一个 maroon 标记。

Rule
- 所有图案沿传送带路径的顺时针方向（从训练样例中可归纳出固定方向）同时移动到下一个站点。环形末尾站点的图案移入第一个站点（循环）。
- 当某个图案从当前站点移往下一站点、且两站点之间的路径段上存在 maroon 标记像素时，该图案在放入目标站点前先顺时针旋转 90 度。
- 没有 maroon 标记的路径段上，图案原样移入下一站点，不旋转。
- 传送带路径（含 maroon 标记）在输出中保持原样不变。

Key insight
解题者先要识别闭合 grey 路径是"传送带"、路径旁的 2x2 空位是"站点"（第一层推理），再发现图案沿路径方向循环移位一步（第二层推理），最后注意到路径上的 maroon 像素是旋转指令——经过它的图案会被旋转 90 度（第三层推理）。maroon 标记嵌在灰色路径中，视觉上不突出，需要仔细对比移位前后图案的朝向变化才能发现旋转规律。
</description>
</new_puzzle>
