<new_puzzle>
根据网格边缘的颜色锚点确定每个内部封闭区域的填充颜色，再用区域内的标记像素指示需要在填充后擦除的行或列条纹。

Input structure
- 背景为主色（black）。
- 网格中有若干由 grey 像素围成的封闭矩形区域（墙壁厚度为 1 像素），各区域互不重叠。
- 每个封闭区域的外壁上恰好有一个非 grey、非背景色的单像素锚点，紧贴该区域外壁的某一侧边。
- 每个封闭区域内部可能有零或多个 maroon 单像素标记，分布在不同的行或列上。

Rule
- 第一层：对每个封闭区域，找到紧贴其外壁的颜色锚点，将该区域内部所有背景像素填充为锚点的颜色。
- 第二层：填充完成后，检查每个区域内部的 maroon 标记像素。若 maroon 标记位于区域内部的第 r 行，则擦除该区域内第 r 行的所有填充像素（恢复为背景色）；若 maroon 标记位于区域内部的第 c 列，则擦除该区域内第 c 列的所有填充像素。判定方式：若 maroon 标记所在行在该区域内的跨度大于所在列的跨度，则视为列标记（擦除该列）；反之视为行标记（擦除该行）。
- maroon 标记像素本身也被擦除。grey 墙壁保持不变。

Key insight
- 锚点颜色决定"填什么"，maroon 标记的位置与区域形状的交互决定"擦什么方向"——解题者需要先发现锚点-区域配对规则，再发现 maroon 标记的行列消除机制及其方向判定逻辑。
</new_puzzle>

<new_puzzle>
将散布在网格中的多色碎片拼回各自的模板轮廓内，拼入位置由碎片颜色与模板边框上的色带标记匹配决定。

Input structure
- 背景为主色（black）。
- 网格中有若干个由 grey 像素绘制的矩形轮廓框（仅边框，内部为背景色），每个框的四条边中恰好有一条边被替换为某种非 grey 的颜色（如 red、blue、green 等），称为"色带边"。
- 网格其他区域散布着若干个小型 4-连通单色碎片（形状各异），每个碎片的颜色恰好与某个框的色带边颜色相同。
- 每个碎片的形状恰好能嵌入其匹配框的内部空间。

Rule
- 第一层：通过颜色匹配，将每个碎片与拥有相同颜色色带边的矩形框配对。
- 第二层：碎片放入框内时，放置位置由色带边所在方向决定——碎片需紧贴色带边的对侧内壁。具体来说：色带边在框的顶边，则碎片贴框的内部底边；色带边在框的右边，则碎片贴框的内部左边；依此类推。碎片在贴靠方向上紧贴内壁，在垂直于贴靠方向的维度上居中放置（若无法精确居中则偏左或偏上）。
- 碎片被放入框内后使用碎片原本的颜色绘制；原始碎片位置清除为背景色。

Key insight
- 颜色匹配是第一层推理（碎片归属哪个框），色带边位置到放置朝向的映射是第二层推理（碎片放在框内的哪个方位）——色带边不仅是匹配标签，还编码了空间放置指令。
</new_puzzle>

<new_puzzle>
根据每个彩色区域内部嵌入的"箭头"标记方向，将该区域的形状沿箭头方向投影复制到网格边界，投影副本使用箭头颜色绘制。

Input structure
- 背景为主色（black）。
- 网格中有若干个单色 4-连通区域（每个区域使用不同颜色，如 red、blue、green 等）。
- 每个区域内部恰好嵌有一个由 yellow 像素构成的三像素"箭头"标记：箭头由一个中心像素和一个与中心相邻的像素组成一条两像素线段，加上从中心像素沿垂直于线段方向延伸的一个像素构成箭头尖端。箭头尖端指向的方向即为投影方向（上、下、左、右之一）。

Rule
- 第一层：识别每个彩色区域内的 yellow 箭头，确定箭头尖端所指的方向（上 / 下 / 左 / 右）。
- 第二层：将该彩色区域的完整形状（不含 yellow 箭头像素）沿箭头方向平移，每次平移距离等于该区域在投影方向上的跨度（即包围盒在该方向的长度），不断重复直到副本超出网格边界为止。
- 所有投影副本用 yellow 颜色绘制。原始区域保持不变（包括其内部的 yellow 箭头）。若投影副本与其他原始区域重叠，则投影副本覆盖在上层。

Key insight
- 箭头的朝向需要从三个 yellow 像素的空间排列中推断（而非简单的线段方向），这要求解题者理解箭头的几何编码方式；投影间距等于区域自身在该方向的跨度，形成无缝重复铺排效果。
</new_puzzle>

<new_puzzle>
在由彩色线段构成的网络中，找到每对同色端点之间的唯一通路，然后用该颜色填充通路，最后根据每条通路穿过的交叉点数量对通路颜色进行深浅替换。

Input structure
- 背景为主色（black）。
- 网格中有一个由 grey 像素构成的正交线段网络（所有线段为水平或垂直，宽度为 1 像素），线段在交叉处相交。
- 网络的若干末端（度为 1 的端点）各有一个彩色像素替代 grey，这些彩色端点成对出现——每种颜色恰好出现两次。
- 网络中存在若干交叉点（度 ≥ 3 的 grey 像素节点）。

Rule
- 第一层：对每对同色端点，沿 grey 网络找到连接它们的唯一简单路径（网络结构保证唯一性——网络是一棵树）。
- 第二层：将该路径上的所有 grey 像素重绘为该对端点的颜色。
- 第三层：统计每条已着色通路经过的交叉点数量（度 ≥ 3 的节点数）。若通路经过的交叉点数量为奇数，则将该通路的颜色替换为 maroon；若为偶数（包括 0），则保持原色不变。
- 两个彩色端点本身保留原色不变。未被任何通路覆盖的 grey 像素保持 grey。

Key insight
- 第一层需要发现端点配对规则（同色配对）；第二层需要沿树结构追踪路径；第三层的奇偶判定是隐蔽的——解题者需要注意到某些通路变色而另一些没有，进而发现与交叉点数量奇偶性的关联。
</new_puzzle>

<new_puzzle>
将网格中散落的单色矩形按面积从小到大嵌套堆叠到指定锚点位置，堆叠时每层矩形的对齐角由锚点所在的网格象限决定。

Input structure
- 背景为主色（black）。
- 网格中散布着若干个不同颜色的实心矩形（4-连通，无重叠），每个矩形颜色唯一。
- 网格中恰好有一个由 yellow 像素标记的单像素锚点，不与任何矩形重叠。

Rule
- 第一层：将所有矩形按面积从小到大排序。
- 第二层：确定锚点所在的网格象限（以网格中心为分界——左上、右上、左下、右下）。象限决定堆叠时每个矩形的对齐角：左上象限 → 所有矩形以其左上角对齐到锚点；右上象限 → 以右上角对齐；左下象限 → 以左下角对齐；右下象限 → 以右下角对齐。
- 第三层：按面积从大到小的顺序，依次将矩形绘制到以锚点为对齐角的位置（大的先画，小的后画覆盖在上面），形成嵌套的同心矩形堆叠。清除所有矩形的原始位置。
- 若堆叠后矩形超出网格边界，则裁剪掉超出部分。锚点像素本身在最终输出中被最小矩形覆盖或保持 yellow。

Key insight
- 面积排序决定绘制顺序（大底小顶），而锚点的象限位置决定对齐方式——解题者需要同时发现两个独立的规律：一个控制"叠放次序"，另一个控制"朝哪个方向展开"，两者结合才能复现输出。
</new_puzzle>

<new_puzzle>
识别网格中由边框颜色编码的"容器"与"印章"配对关系，将印章图案旋转后盖入对应容器内部，旋转角度由容器缺口的位置决定。

Input structure
- 背景为主色（black）。
- 网格中有若干个矩形"容器"：每个容器由某种颜色（如 red、blue、green 等）的像素绘制三面边框，第四面留有一个完整的缺口（即该侧整条边缺失）。容器内部为背景色。
- 网格中另有若干个小型实心图案"印章"，每个印章被一圈单像素厚的边框包围，边框颜色与某个容器的边框颜色相同。印章内部的图案由 orange 像素构成（形状各异），其余为背景色。

Rule
- 第一层：通过边框颜色匹配，将每个印章与对应的容器配对。
- 第二层：确定容器缺口所在方向（上、下、左、右）。将缺口方向视为容器的"开口朝向"。
- 第三层：将印章内部的 orange 图案旋转，使得图案的"顶部"（即印章边框内图案原始朝上的方向）旋转到面朝容器缺口的方向。具体地：缺口朝上则不旋转（0 度）；缺口朝右则顺时针旋转 90 度；缺口朝下则旋转 180 度；缺口朝左则逆时针旋转 90 度。
- 将旋转后的图案放入容器内部中心位置，用 orange 绘制。印章原始位置（含边框）清除为背景色。容器边框保持不变。

Key insight
- 颜色匹配是配对线索，缺口朝向是旋转指令——解题者需先发现边框颜色的配对关系，再发现缺口方向与旋转角度的对应规律，两层推理缺一不可。
</new_puzzle>

<new_puzzle>
根据网格顶部的颜色序列条和左侧的形状模板列，在交叉位置生成对应颜色的形状副本，但仅在交叉格被"激活标记"点亮时才绘制。

Input structure
- 背景为主色（black）。
- 网格顶部有一行彩色单像素序列（从左到右排列，每个像素颜色不同，如 red、blue、green 等），占据第 0 行的若干连续列，起始列记为 c0。
- 网格左侧有一列小型形状模板（纵向排列），每个模板是一个由 grey 像素绘制的小图案（如 L 形、T 形、十字形等，包围盒不超过 3x3），模板之间间隔 1 行背景色。模板起始行记为 r0。
- 在顶部序列和左侧模板形成的"交叉矩阵"区域中（即每个模板行与每个序列列的交汇处），某些交汇格内有一个 yellow 单像素"激活标记"。

Rule
- 第一层：将顶部颜色序列的第 j 个颜色与左侧的第 i 个形状模板建立交叉索引关系。
- 第二层：对于每个存在 yellow 激活标记的交叉位置 (i, j)，在该交叉格区域内绘制第 i 个形状模板的副本，使用第 j 个颜色序列的颜色。
- 第三层：未被激活的交叉格保持背景色。激活标记（yellow 像素）在绘制形状后被覆盖。顶部颜色序列和左侧形状模板在输出中保留不变。

Key insight
- 这是一个二维查找表的解码问题：行索引选形状，列索引选颜色，激活标记选位置——解题者需要同时识别出行/列的索引语义和激活标记的开关作用，三者协同才能还原输出。
</new_puzzle>
