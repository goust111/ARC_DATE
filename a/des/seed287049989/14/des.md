<new_puzzle>
根据封闭区域内部孔洞的形状，从网格边缘的颜色图例中匹配对应模板，再用图例颜色填充该区域的外轮廓。

Input structure
- 背景为 Black。网格中散布着若干由 Grey 像素构成的封闭区域（即 Grey 像素围成的闭合环，内部为 Black 背景，环内可能存在不规则的小孔洞——孔洞是环内部被 Grey 像素隔开的独立连通 Black 区域）。
- 网格最右侧两列是颜色图例区：每个图例条目由一个小型 Black 孔洞模板（用 Grey 边框框住）和紧邻其下方的一个单色色块（如 Red、Blue、Green、Yellow 等）组成，图例条目之间用 Black 行分隔。
- 每个封闭区域内部恰好有一个孔洞，其形状（像素的相对位置模式）与某个图例条目中的孔洞模板完全一致（可能经过平移但不旋转不翻转）。

Rule
- 对每个 Grey 封闭区域，提取其内部孔洞的形状，在图例中找到形状匹配的模板条目，读取该条目对应的颜色。
- 将该封闭区域的所有 Grey 像素重新着色为匹配到的图例颜色，孔洞和区域外部保持 Black 不变。
- 图例区域本身在输出中保持不变。

Key insight
- 解题需要两层独立推理：第一层是发现区域内部孔洞的形状是查找键，第二层是理解图例区的编码方式——孔洞模板与颜色配对，从而建立"形状到颜色"的映射关系。孔洞形状不大（3-5 个像素），人眼可直接比对。
</new_puzzle>

<new_puzzle>
将网格中每个彩色框架内的图案按照框架颜色所指示的旋转角度旋转后输出到原位，旋转角度由框架颜色在网格顶部色条中的出现位置决定。

Input structure
- 背景为 Black。网格顶部第一行是一条"色条"：从左到右依次排列 1 到 4 个不同颜色的单像素，它们之间用 Black 像素分隔。这些颜色分别对应 0 度、90 度顺时针、180 度、270 度顺时针旋转（按从左到右的顺序）。
- 网格其余部分包含若干互不重叠的正方形框架，每个框架由单像素厚的彩色边框围成，边框颜色是色条中出现的某种颜色。框架内部包含由其他颜色（不同于边框颜色和 Black）组成的非对称小图案，图案四周可能有 Black 填充。

Rule
- 读取顶部色条，按从左到右的位置顺序为每种颜色分配旋转角度：第 1 个颜色对应 0 度，第 2 个对应 90 度顺时针，第 3 个对应 180 度，第 4 个对应 270 度顺时针。
- 对每个正方形框架，根据其边框颜色查找对应的旋转角度，将框架内部的图案（不含边框本身）绕其中心旋转该角度。
- 边框像素、色条和背景保持不变。

Key insight
- 第一层推理：发现顶部色条不是装饰，而是旋转角度的编码图例，位置序号决定角度。第二层推理：框架边框颜色是查找键，内部图案需要按匹配到的角度做就地旋转。由于图案是非对称的，解题者必须同时正确解读色条含义和旋转方向才能还原输出。
</new_puzzle>

<new_puzzle>
在网格中找到被遮挡的完整周期性条纹图案，利用未遮挡区域推断条纹方向和周期，然后仅对长轴与条纹方向平行的矩形遮挡物执行条纹恢复操作。

Input structure
- 网格被一个双色水平或垂直交替条纹图案覆盖（例如 Blue 和 Green 交替，每条宽度为 2-3 像素）。
- 若干单色实心矩形遮挡物覆盖在条纹上方，遮挡物颜色为条纹中未使用的颜色（如 Red、Yellow、Orange 等），每个遮挡物是非正方形的矩形。
- 每个矩形遮挡物要么是"宽矩形"（宽大于高），要么是"高矩形"（高大于宽）。

Rule
- 首先从未被遮挡的区域推断底层条纹图案的方向（水平条纹或垂直条纹）和周期。
- 对于每个遮挡物矩形：如果条纹是水平方向且该矩形是宽矩形（长轴平行于条纹方向），则将遮挡物移除并恢复其下方的条纹图案；如果条纹是垂直方向且该矩形是高矩形（长轴平行于条纹方向），同样恢复条纹。
- 长轴垂直于条纹方向的矩形保持原样不变（不恢复条纹）。

Key insight
- 第一层推理：识别底层存在周期性条纹并从可见区域重建完整图案。第二层推理：发现并非所有遮挡物都被移除，而是只有长轴方向与条纹方向一致的矩形才被"透视"还原，解题者需要跨样例归纳出这个基于形状朝向的筛选条件。
</new_puzzle>

<new_puzzle>
将散落的彩色碎片拼回到灰色模板的对应槽位中，槽位匹配依据是碎片形状与槽位形状一致，碎片颜色决定填充后槽位边框的重着色。

Input structure
- 背景为 Black。网格中央偏上有一个较大的 Grey 区域，其中包含若干"槽位"——即 Grey 区域内部被挖去的 Black 连通区域，每个槽位形状不同（如 L 形、T 形、Z 形等，面积 3-6 像素）。
- 网格下方散布若干彩色碎片（如 Red、Blue、Green、Yellow），每个碎片是一个单色 4-连通对象，形状恰好与 Grey 区域中某个槽位完全吻合（经过平移，不旋转不翻转）。碎片数量与槽位数量相同，形成一一对应。
- 每个槽位的 Grey 边框定义为：与该槽位的 Black 像素 4-邻接的所有 Grey 像素。

Rule
- 对每个彩色碎片，在 Grey 区域的槽位中找到形状完全匹配的那个槽位（形状比较基于像素相对位置，仅平移对齐）。
- 将碎片的颜色填入对应槽位（替换槽位中的 Black 像素为碎片颜色）。
- 同时将该槽位的 Grey 边框像素也重着色为碎片颜色。
- 碎片原始位置变为 Black 背景。其余 Grey 像素（不属于任何槽位边框的部分）保持 Grey 不变。

Key insight
- 第一层推理：识别碎片与槽位之间的形状匹配关系——需要将分散的碎片逐一与模板槽位进行视觉比对。第二层推理：发现输出不仅仅是填槽，还要将匹配颜色扩展到槽位的 Grey 边框上，这个"边框重着色"规则需要从样例中额外归纳。两层规则叠加使得仅看一个样例难以确定完整变换。
</new_puzzle>

<new_puzzle>
利用网格中的"种子像素"沿其所在封闭房间的内壁生长出与种子颜色相同的边框线，生长方向由种子紧邻的墙壁决定，生长长度等于房间内同色种子的总数。

Input structure
- 背景为 Black。网格中有若干由 Grey 像素构成的单像素厚直线墙壁，这些墙壁将网格分割成若干矩形"房间"（房间内部为 Black）。
- 部分房间内部散布着 1-4 个彩色"种子像素"（如 Red、Blue、Green 等），同一房间内所有种子颜色相同。不同房间的种子颜色可以不同，也可以相同。
- 每个种子像素紧邻房间的某一面墙壁（即种子的上、下、左、右恰好有一个方向与 Grey 墙壁像素 4-邻接），且每个种子只紧邻一面墙。

Rule
- 对每个房间，统计其内部种子像素的数量 N。
- 对该房间内的每个种子像素，确定它紧邻的是哪面墙（上墙、下墙、左墙、右墙），然后从种子位置出发，沿该墙壁方向（即平行于墙壁的方向）绘制一条长度为 N 个像素的线段（含种子自身），颜色与种子相同。线段紧贴墙壁（保持在与墙壁相邻的那一行或列上）。
- 延伸方向：线段从种子位置开始，优先向行号或列号增大的方向延伸；如果该方向碰到墙壁则剩余长度向另一方向补齐。如果两个方向总长度都不够则在墙壁处截断。
- 墙壁本身和空房间保持不变。

Key insight
- 第一层推理：发现种子数量决定了绘制线段的长度——同一房间内种子越多，每个种子生长出的线段越长，需要跨房间对比才能归纳出"数量等于长度"的映射。第二层推理：种子紧邻墙壁的方位决定线段的绘制方向（平行于该墙壁），这需要观察种子与墙壁的空间关系。两层规则互相独立又必须同时正确才能复原输出。
</new_puzzle>

<new_puzzle>
将网格中每个多色对象拆分为单色层，按照层颜色在调色板行中的顺序进行空间偏移后重新叠合输出。

Input structure
- 背景为 Black。网格最底部一行是"调色板行"：从左到右排列着若干不同颜色的单像素点（如 Red、Blue、Green、Yellow），像素之间用 Black 分隔，它们的左右排列顺序定义了颜色的"偏移等级"——最左颜色等级为 0，向右依次为 1、2、3。
- 网格其余区域包含若干互不重叠的多色对象，每个对象由 2-4 种颜色的像素组成（所有颜色都出现在调色板行中），对象整体是 4-连通的。

Rule
- 将每个多色对象按颜色拆分为多个单色层（每层是该颜色在对象中的所有像素）。
- 对每个单色层，根据其颜色在调色板行中的等级 k，将该层的所有像素整体向右平移 k 个像素。
- 如果平移后不同层的像素重叠在同一位置，保留等级更高（调色板中更靠右）的颜色。
- 调色板行在输出中保持不变。平移后超出网格右边界的像素被裁剪。

Key insight
- 第一层推理：发现调色板行不是装饰而是偏移量的编码——颜色在调色板中的位置序号决定了该颜色层的水平平移量，需要对比多个样例中不同颜色的移动距离才能归纳出规律。第二层推理：理解多色对象的拆分-偏移-重叠机制，特别是重叠时高等级颜色覆盖低等级颜色的优先级规则，这需要从有重叠发生的样例中归纳。
</new_puzzle>

<new_puzzle>
识别网格中成对的同色标记点，将每对标记点之间的矩形区域填充为该颜色，但填充时需要保留区域内已有的 Grey 对象作为镂空，且重叠矩形按面积从大到小分层绘制。

Input structure
- 背景为 Black。网格中散布着若干成对的彩色标记像素——每种非 Black、非 Grey 颜色恰好出现两个像素点，形成一对。不同颜色对之间不共享像素。
- 网格中还存在若干由 Grey 像素构成的小型 4-连通对象（面积 2-6 像素），这些 Grey 对象可能位于某些标记对定义的矩形区域内部。

Rule
- 对每对同色标记像素，以两个标记点为对角顶点确定一个轴对齐矩形区域（矩形的行范围从两点行坐标的较小值到较大值，列范围从两点列坐标的较小值到较大值）。
- 按矩形面积从大到小的顺序依次绘制：将矩形区域内的所有 Black 像素填充为标记颜色。
- 矩形区域内已有的 Grey 对象像素保持 Grey 不变（形成镂空效果）。
- 由于按面积从大到小绘制，较小的矩形会覆盖较大矩形的重叠部分，使小矩形显示在上层。
- 标记像素本身被矩形填充覆盖（融入填充色中）。

Key insight
- 第一层推理：发现同色像素对定义矩形区域并触发填充——需要识别"成对标记到矩形"的映射机制。第二层推理：归纳出 Grey 对象作为镂空被保留的规则，这从单个样例中不易确定是"所有非 Black 色保留"还是"仅 Grey 保留"。第三层推理：当矩形重叠时，需要推断出按面积排序的绘制优先级，这要求从包含重叠情况的样例中仔细对比才能发现。
</new_puzzle>
