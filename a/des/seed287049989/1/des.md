  - 网格最左列或最右列紧贴边缘放置一列纵向颜色图例：图例由若干行组成，第 k 行（从 1 开始计数）的像素为某种独特颜色，表示"岛屿数量 = k 时应使用的填充色"。

  - 将该封闭环内部所有背景像素填充为颜色 C，保留岛屿像素和边框像素不变。
  - 图例本身保持不变。

- `Key insight`：岛屿不是装饰而是计数器——每个封闭区域内的岛屿数量是查表键，边缘图例的行序号将计数映射为填充颜色。解题者需要先发现"数岛屿"这一非显然步骤，再发现图例的行号对应关系。

- `description`：将散落的彩色碎片按形状匹配拼入唯一带有同形缺口的灰色模板中，拼入时碎片颜色覆盖缺口，同时模板外的碎片原位置被其镜像副本替代。

- `Input structure`：
  - 背景为主色（如 black）。
  - 一个大型灰色（grey）连通区域作为模板，模板内部有若干处背景色缺口，每处缺口形状各不相同。
  - 模板外散布着若干彩色小型连通对象（碎片），每个碎片的形状恰好与模板内某一处缺口的形状相同（可能需要旋转 0/90/180/270 度才能匹配）。

- `Rule`：
  - 对每个彩色碎片，在模板的缺口中找到与其形状一致的缺口（允许 90 度整数倍旋转匹配）。
  - 将碎片以匹配的旋转角度嵌入缺口位置，缺口像素变为碎片的颜色。
  - 在碎片原来的位置，放置该碎片沿其中心进行水平镜像翻转后的灰色副本（颜色变为 grey）。
  - 模板其余部分和背景保持不变。

- `Key insight`：第一层推理是经典的形状匹配拼图——碎片旋转后嵌入缺口；第二层推理是碎片原位留下的"幽灵"是其镜像而非原形，解题者需要观察样例才能发现原位置的残影经过了镜像翻转且变为灰色。
</new_puzzle>

- `description`：网格中的每个彩色箭头沿其指向方向发射一条射线，射线长度等于箭头自身像素数量；当两条射线在同一像素交叉时，该交叉点变为第三种指定颜色。

- `Input structure`：
  - 背景为主色（如 black）。
  - 网格中散布若干由非背景色像素构成的小型箭头形状。每个箭头由一条短直线段（箭身，2-4 像素长，水平或垂直排列）和一个指向某个正交方向（上/下/左/右）的单像素尖端组成。尖端位于箭身延长线上且在箭身的一端，具体绘制方式为：箭身是一段连续的同色像素，尖端像素紧接箭身的某一端，与箭身共线。尖端所在的那一端即为箭头指向。箭头整体为同一颜色。
  - 网格中还有一个独立的双色标记像素对（两个不同颜色的像素水平相邻），它是交叉色指示器：右侧像素的颜色即为射线交叉点应使用的颜色。

- `Rule`：
  - 计算每个箭头的总像素数 N（箭身 + 尖端）。
  - 从尖端出发，沿箭头指向方向绘制一条长度为 N 个像素的射线（不含尖端自身），颜色与箭头相同。射线遇到网格边界则截断。
  - 若两条不同箭头的射线覆盖了同一像素，该像素改为交叉色指示器所标定的交叉颜色。
  - 箭头本体保持不变，交叉色指示器保持不变。

- `Key insight`：箭头的像素数量同时编码了射线长度——这是第一层非显然推理；射线交叉时的变色规则由独立标记指定而非固定颜色——这是第二层推理。解题者必须先归纳"像素数 = 射程"的对应关系，再发现交叉变色的规则来源。
</new_puzzle>

- `Input structure`：
  - 背景为主色（如 black）。

  - 网格的四个角落各有一个单像素颜色种子：左上角像素为颜色 A，右上角为颜色 B，左下角为颜色 C，右下角为颜色 D，四色互不相同且与背景色、边框色不同。

  - 对每个矩形框，判断其内部标记像素位于框内部空间的哪个象限（以框内部空间的中心行和中心列为分界）：左上、右上、左下、或右下。

  - 用选取的颜色填充框内部所有背景像素（标记像素被覆盖消失）。
  - 将矩形边框的颜色替换为该框内标记像素原来的颜色。

- `Key insight`：解题有三层结构——第一层需要发现网格四角像素是颜色图例而非装饰；第二层需要归纳标记像素的相对位置（象限）与四角图例之间的映射关系；第三层需要发现边框会"吸收"标记的颜色，发生颜色互换。单独看任何一步都不算复杂，但三步级联让规则变得隐蔽。
</new_puzzle>

<new_puzzle>
- `description`：每个彩色连通对象根据其内部是否含有孔洞来决定变换方式：有孔洞的对象向内收缩一层边界像素，无孔洞的对象向外膨胀一层像素；膨胀时若两个对象的膨胀区域重叠，重叠像素变为 maroon。

- `Input structure`：
  - 背景为主色（如 black）。
  - 网格中散布若干个单色 4-连通前景对象（每个对象颜色可以不同），部分对象内部包含一个或多个背景色孔洞（即被对象像素完全 4-连通包围的背景区域），其余对象没有孔洞。对象之间不相邻（至少间隔一个背景像素）。

- `Rule`：
  - 对每个前景对象，判断其是否包含孔洞（对象包围范围内是否存在被完全包围的背景像素连通区域）。
  - 无孔洞的对象：向外膨胀一层——将对象的每个 4-连通相邻背景像素也变为该对象的颜色。
  - 有孔洞的对象：向内收缩一层——移除对象中所有与背景或孔洞 4-连通相邻的对象像素（即侵蚀掉对象的最外一圈），被移除的像素变为背景色。收缩后孔洞会扩大或对象可能变薄。
  - 若两个不同对象的膨胀结果覆盖了同一个像素，该像素颜色变为 maroon。
  - 原始对象像素（未被收缩移除的部分）保持原色不变。

- `Key insight`：对象的"有孔 vs 无孔"属性是一个视觉上可判断但非显然的二元开关，它决定了完全相反的变换方向（收缩 vs 膨胀）。解题者需要先发现这个分类标准，再归纳两类对象各自的变换规则，最后理解膨胀冲突的处理方式。
</new_puzzle>

- `description`：网格被分隔线划分为若干小格，每个小格中的彩色图案需要按照同行最左格中图案的旋转姿态进行统一旋转对齐，使所有同行图案朝向一致。

- `Input structure`：
  - 网格由单色分隔行和分隔列（如 grey）均匀划分为 R 行 C 列的等大矩形小格（C >= 3）。
  - 每个小格内有一个由单一前景色绘制的非对称小图案（如 L 形、T 形等不具有四重旋转对称性的形状），该图案在不同小格中可能以 0/90/180/270 度的不同旋转出现。
  - 同一行的所有小格中，图案的基础形状相同（只是旋转角度可能不同）；不同行之间图案形状可以不同。
  - 每行最左侧的小格是"参考格"，其图案姿态即为该行的标准朝向。

- `Rule`：
  - 对每一行，以最左侧小格中的图案旋转姿态作为该行的标准姿态。
  - 对该行其余每个小格，将其中的图案旋转到与参考格图案完全一致的姿态。旋转以图案在小格内的中心为旋转中心，旋转后图案仍然居于小格内相同的相对位置。
  - 分隔线和背景保持不变。图案颜色保持不变。

- `Key insight`：表面上看每格的图案似乎随机旋转，但参考格隐含了"标准朝向"的定义。解题者需要先发现同一行的图案其实是同一形状的不同旋转版本，再发现最左格充当旋转基准的角色，最后将所有图案统一旋转到基准姿态。

<new_puzzle>
- `description`：将网格中每个彩色"种子"像素沿其所在的灰色路径扩散，扩散距离等于该种子在路径上的排列序号；路径交汇处的颜色由序号较小的种子决定。

- `Input structure`：
  - 背景为主色（如 black）。
  - 网格上有若干条由灰色（grey）像素构成的单像素宽路径（可以有直角转弯，路径像素之间 4-连通相邻），路径之间不交叉不共享像素。
  - 每条路径上间隔放置着若干个彩色种子像素（颜色非背景非灰色），这些种子像素替代了该位置原本的灰色像素，位于路径之上。同一条路径上的种子颜色可以相同也可以不同。
  - 每条路径有两个端点（只有一个 4-连通灰色或种子邻居的像素）。

- `Rule`：
  - 对每条路径，确定其起点端：两个端点中，行号更小的为起点；若行号相同，则列号更小的为起点。
  - 从起点端沿路径依次遇到种子像素，第一个种子编号为 1，第二个为 2，以此类推。
  - 每个编号为 k 的种子，沿路径向两个方向各扩散 k 步（每步为路径上相邻的一个灰色像素），将这些灰色像素变为该种子的颜色。扩散遇到路径末端则截断，遇到另一个种子像素则在该种子前停止（不覆盖其他种子）。
  - 若某个灰色像素同时处于两个种子的扩散范围内，则保留编号较小的种子的颜色。
  - 种子像素本身保留原色不变。未被任何扩散覆盖的灰色像素仍为灰色。

- `Key insight`：第一层推理是识别灰色路径和种子像素的结构关系；第二层是发现种子的"排列序号"决定扩散半径——序号越大扩散越远，而序号取决于路径方向的确定规则（靠近左上角的端点为起点）；第三层是扩散冲突时小编号优先的规则。路径方向和序号的确定本身就需要从样例中归纳。
</new_puzzle>

<new_puzzle>
- `description`：网格中散落的彩色像素对通过"隐形连线"配对，每对像素之间的矩形区域用两者颜色中按色表顺序靠后的颜色填充，但仅填充该矩形的边框（不填内部）。

- `Input structure`：
  - 背景为主色（如 black）。
  - 网格中散布偶数个前景色单像素点，颜色种类有限（如 red、blue、green 等）。
  - 每种颜色恰好出现偶数次（通常为 2 次），同色像素构成一个配对。
  - 不同配对的像素颜色不同。

- `Rule`：
  - 将同色的两个像素配对。
  - 对每一对像素，以两像素为对角顶点确定一个最小轴对齐矩形。
  - 仅绘制该矩形的边框（即矩形最外一圈像素），颜色为该对像素的颜色。矩形内部保持背景色不变。
  - 若两个不同配对的矩形边框在某个像素重叠，该像素使用在以下固定色序中排列靠后的颜色：red < blue < green < yellow < grey < magenta < orange < azure < maroon。
  - 原始配对像素位于矩形角上，自然被边框覆盖。

- `Key insight`：第一层推理是发现同色像素配对和矩形边框的绘制规则；第二层是发现重叠处的颜色不是简单覆盖而是按固定优先级选取——这个优先级顺序需要从多个样例中的重叠情况归纳得出。配对本身是显然的（同色即配对），但矩形只画边框而非填充、以及重叠优先级是需要观察才能发现的规则。
</new_puzzle>
