<description>
根据封闭区域内部的标记像素颜色，从网格边缘的颜色图例中查找对应的填充纹理，将该纹理平铺到封闭区域内部。

Input structure:
- 背景为 black。
- 网格中有若干由 grey 像素构成的一像素宽封闭轮廓，形成不同大小的矩形封闭区域。
- 每个封闭区域内部恰好有一个单独的标记像素，颜色各不相同（如 red、blue、green 等）。
- 网格最上方两行是颜色图例区：每个图例条目由左侧一个 2x1 的颜色标识块和右侧紧邻的一个 2x2 纹理样本组成，条目之间用一列 black 分隔。颜色标识块的颜色与封闭区域中的标记像素颜色一一对应；纹理样本由两种颜色构成的 2x2 图案。

Rule:
- 保留所有 grey 轮廓不变。
- 对每个封闭区域，找到其内部标记像素的颜色，在图例区中查找颜色标识块与之匹配的条目。
- 取该条目的 2x2 纹理样本，以封闭区域内部左上角为起点进行周期性平铺，填满整个封闭区域内部（覆盖原来的标记像素和 black 背景）。
- 图例区本身在输出中保持不变。

Key insight:
标记像素不是装饰，而是索引键——它将封闭区域与图例中的纹理样本关联起来；解题者需要先建立"标记颜色→图例条目→2x2 纹理"的映射关系，再执行空间上的平铺填充。
</description>

<description>
将网格中散落的彩色碎片按形状匹配拼回到灰色模板的对应缺口中，每个碎片需要旋转到正确朝向才能嵌入。

Input structure:
- 背景为 black。
- 网格中央有一个较大的 grey 连通区域作为"模板"，模板内部有若干形状各异的 black 缺口（每个缺口是一个 4-连通的 black 区域，完全被 grey 包围）。
- 模板外部散布着若干彩色碎片对象（每个碎片是一种独特的非 black、非 grey 颜色），每个碎片的形状恰好与模板中某一个缺口在 90 度旋转下匹配（即碎片经过 0°、90°、180° 或 270° 旋转后与某个缺口的形状完全吻合）。
- 碎片数量与缺口数量相同，且一一对应。

Rule:
- 保留 grey 模板不变。
- 对每个缺口，找到形状匹配的彩色碎片（在四种旋转中的某一种下形状完全一致）。

- 移除模板外部原来碎片所在位置的像素（恢复为 black 背景）。

Key insight:
碎片和缺口之间不是简单的平移关系——解题者必须对每个碎片尝试旋转匹配才能确定它属于哪个缺口以及需要怎样旋转，这构成了两层推理：先通过旋转形状匹配建立碎片-缺口配对，再执行空间嵌入。

Input structure:
- 背景为 black。
- 网格上半部分有若干彩色的 4-连通前景对象，颜色互不相同（如 red、blue、green）。每个对象是一个含有零个或多个封闭孔洞（被对象颜色完全包围的 black 区域）的连通块。
- 网格最底部一行是调色板行：从左到右排列若干不同颜色的单像素，颜色之间用 black 间隔。调色板中的颜色种类数不少于任何对象的孔洞数。

Rule:
- 保留所有原始对象不变。
- 对每个对象，数出其内部封闭孔洞的个数 N。
- 在该对象的紧邻下方（从对象 bounding box 底边的下一行开始），绘制 N 行水平条纹，每行的宽度等于对象 bounding box 的宽度。

- 若 N = 0，不绘制任何条纹。
- 调色板行本身在输出中保持不变。

Key insight:
孔洞数量是隐含的结构信息——解题者需要先识别每个对象中被完全包围的 black 区域数目，再将这个计数映射为条纹层数；同时条纹颜色并非来自对象自身，而是来自底部调色板的顺序索引，形成"计数→查表→绘制"的三层推理链。
</description>

<description>
沿着每个箭头指示的方向，将箭头尾部对齐的同色矩形滑动到箭头头部所指的边界线上，箭头本身在输出中消失。

Input structure:
- 背景为 black。
- 网格中有若干条完整的 grey 水平线或垂直线，将网格划分为多个矩形区间。
- 在某些区间内，存在一个彩色矩形对象（至少 2x2）和一个同色的箭头形标记。箭头由一条 3 像素的直线段加一个 1 像素的尖端构成，整体呈十字方向之一（上、下、左、右）。箭头的尾端（直线段的非尖端一端）与矩形对象的某一边紧邻。
- 箭头的尖端指向该区间内的某一条 grey 边界线方向。

Rule:
- 移除所有箭头标记（恢复为 black）。
- 对每个彩色矩形，沿箭头尖端指示的方向平移，直到矩形的前进边紧贴该方向上最近的 grey 边界线（矩形与 grey 线相邻但不重叠）。
- 原来矩形的位置恢复为 black。
- 所有 grey 线保持不变。

Key insight:
箭头不仅编码了移动方向，还隐含地指定了目标边界——矩形总是滑向箭头所指方向上的最近 grey 线。解题者需要先从箭头形状中解读方向信息，再确定滑动的终止条件是"贴靠最近 grey 线"，而非简单地移动固定距离。
</description>

将网格中每对颜色相同的标记点用直线段连接，线段交叉处的颜色由统一的混合色标记。

Input structure:
- 背景为 black。
- 网格中散布着若干彩色标记像素，每种颜色恰好出现两次，形成若干对。
- 所有标记点的位置保证：同色的两个标记点要么在同一行，要么在同一列，要么形成一个精确的 45 度对角线关系（行差绝对值等于列差绝对值）。
- 不同颜色对的连线可能在网格内交叉。

Rule:
- 对每对同色标记点，沿两点之间的直线路径（水平、垂直或 45 度对角线）绘制连线，颜色与标记点相同。标记点本身保留。
- 当两条不同颜色的连线经过同一个像素时，该像素使用一个固定的混合色 yellow 来标记交叉点。
- 若某个像素被三条或更多连线经过，仍然使用 yellow。
- 不与任何其他线交叉的线段保持原色。

Key insight:
解题者需要两层推理：第一层是识别同色配对并确定连线路径（水平、垂直还是对角线），第二层是发现交叉点的混合规则——交叉处不是简单地被后画的线覆盖，而是统一变为一种特殊颜色，这一规则需要从多个样例中的交叉实例中归纳得出。

<description>
根据每个彩色矩形边缘上唯一缺口的位置确定射线方向，射线长度等于矩形边缘像素总数减一。

Input structure:
- 背景为 black。
- 网格中有若干个互不接触的彩色实心矩形区域，每个矩形恰好有一个像素宽的缺口（即矩形边缘上有一个像素被替换为 black）。
- 不同矩形颜色各不相同。

Rule:
- 保留所有原始矩形不变。
- 对每个矩形，找到其边缘上的唯一缺口位置，确定缺口朝向外部的方向（缺口在上边则向上，在下边则向下，在左边则向左，在右边则向右）。
- 从缺口位置沿该方向向外绘制一条直线射线，射线颜色与矩形相同。
- 射线长度（像素数）等于该矩形边缘上非缺口的彩色像素总数（即矩形周长减 1）。
- 射线遇到网格边界则截断。

Key insight:
缺口同时编码了两个信息：射线的发射方向和发射起点。而射线的长度并非固定值，而是取决于矩形自身边缘的像素计数——解题者需要先发现缺口决定方向的规则，再发现长度与周长的关联，两层规律缺一不可。
</description>

<description>
将散落在网格四个象限中的小图案块按照其所在象限对应的旋转角度旋转后，拼贴到中央框架的对应象限位置。

Input structure:
- 背景为 black。
- 网格正中央有一个由 grey 像素构成的十字线（一条水平线和一条垂直线交叉于网格中心），将网格分为四个象限：左上、右上、左下、右下。
- 十字线交叉处有一个空的矩形区域（由 grey 边框围成），作为目标拼贴框架，内部为 black。
- 每个象限中恰好有一个小的彩色图案块（不同颜色），大小恰好等于目标框架内部面积的四分之一（即框架内部可以被四个这样的块无缝拼成）。

Rule:
- 左上象限的图案块不旋转，放入目标框架内部的左上四分之一区域。
- 右上象限的图案块顺时针旋转 90 度，放入框架内部的右上四分之一区域。
- 右下象限的图案块旋转 180 度，放入框架内部的右下四分之一区域。
- 左下象限的图案块顺时针旋转 270 度（即逆时针 90 度），放入框架内部的左下四分之一区域。
- 移除原来象限中图案块的像素（恢复为 black）。
- grey 十字线和框架边框保持不变。

Key insight:
象限位置隐含地编码了旋转角度——解题者需要发现"左上=0°、右上=90°、右下=180°、左下=270°"的顺时针旋转规律，而非仅仅将图案块平移到框架内。这个旋转-象限映射关系是从样例中需要归纳的核心规律。

<description>
将网格中每个前景对象根据其所接触的网格边缘方向，在 bounding box 内进行对应的镜像翻转。

Input structure:
- 背景为 blue。
- 网格中有若干个互不接触的单色 4-连通前景对象（颜色各异，均非 blue），每个对象都恰好接触网格的某一条边缘（上、下、左或右边缘），即对象中至少有一个像素位于该边缘行或列上。
- 每个对象只接触一条边缘，不会同时接触两条。

Rule:
- 对于接触上边缘或下边缘的对象：在其 bounding box 内进行左右镜像翻转（以 bounding box 的垂直中轴为镜像轴）。
- 对于接触左边缘或右边缘的对象：在其 bounding box 内进行上下镜像翻转（以 bounding box 的水平中轴为镜像轴）。
- 翻转后的对象放回原来 bounding box 的位置。
- 背景保持不变。

Key insight:
对象的镜像方式不是统一的——解题者需要发现接触水平边缘（上/下）的对象做垂直中轴翻转（左右翻），而接触垂直边缘（左/右）的对象做水平中轴翻转（上下翻）。镜像轴与接触边缘之间的正交关系是需要从样例中归纳的隐蔽规则。
</description>
</new_puzzle>
