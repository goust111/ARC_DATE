<description>
根据嵌套框架的层数对内部图案进行递归缩放与颜色继承。

Input structure:
- 背景为网格中最常见的颜色。网格中有若干互不重叠的嵌套矩形框架结构，每个结构由多层不同颜色的矩形边框从外到内层层嵌套。
- 最内层的矩形区域包含一个由某种前景色绘制的小型非对称图案（模板），模板占据最内层区域的一部分像素。
- 每层边框使用不同的颜色，相邻层之间隔一行/一列背景色。

Rule:
- 对每个嵌套框架结构，数出其边框层数 N（不含最内层图案区域）。
- 将最内层的小型图案作为种子模板，从内向外逐层填充：第 k 层（k=1 为紧邻最内层的那层边框内侧空隙区域）用第 k 层边框的颜色绘制模板的放大版本，放大倍数为 k+1。
- 放大的模板以该层区域的左上角对齐放置；超出该层区域范围的部分裁剪掉。
- 原有的边框线条保持不变。

Key insight:
边框的层数同时编码了缩放倍数，而每层边框的颜色决定了该层放大图案使用的绘制颜色——解题者需要发现"层数即倍率"这一递归缩放规则，并理解颜色从对应的边框层继承而来。
</description>

<description>
将散落的彩色碎片按颜色配对拼合为完整矩形，再根据矩形面积从小到大依次堆叠到画布上。

Input structure:
- 背景为网格中最常见的颜色。网格上散落着若干单色连通区域（碎片），每种颜色恰好出现两个碎片。
- 同色的两个碎片可以无重叠地拼合为一个完整的实心矩形（可能需要对其中一个碎片做平移，但不需要旋转或翻转）。
- 网格的某个角落有一个小型的单色标记像素（使用一种独特的标记颜色），标记画布输出的锚点位置。

Rule:
- 对每种颜色，找到该颜色的两个碎片，将它们平移拼合成一个完整的实心矩形。拼合方式唯一：两个碎片的凸凹轮廓互补。
- 计算每个拼合后矩形的面积（像素总数）。
- 构建输出画布：以标记像素所在角落为起始角，按面积从小到大的顺序，将矩形从该角落开始依次水平排列放置，矩形之间用一列背景色分隔。矩形的顶边与画布顶边对齐。
- 输出网格大小恰好容纳所有排列后的矩形加分隔列。

Key insight:
解题者首先需要识别出同色碎片的互补拼合关系（这不是简单的形状匹配，而是要发现两个不规则碎片恰好填满一个矩形），然后还需发现排列顺序由拼合后矩形的面积决定——两步推理缺一不可。
</description>

<new_puzzle>
<description>
利用网格中的"路标箭头"逐步传递并旋转图案，每经过一个路标箭头就将图案旋转该箭头指示的方向。

Input structure:
- 背景为网格中最常见的颜色。网格中有一个由某种前景色绘制的小型图案（源图案），位于网格的一侧。
- 网格中散布着若干"路标箭头"，每个箭头由三个像素组成一个 T 形结构：一个中心像素与沿某个正交方向延伸出的两个同色像素组成 T 形的横杠，中心像素在 T 形横杠对面方向有一个同色像素作为"茎"。T 形的"茎"方向即箭头指向（上、下、左、右）。每个箭头使用独特的颜色。
- 源图案旁有一个与某路标箭头同色的单像素标记，指示传递链的第一站。

Rule:
- 从源图案出发，首先找到与标记像素同色的路标箭头，将源图案复制到该箭头中心位置（图案中心对齐箭头中心）。
- 到达该箭头后，将图案按箭头指向顺时针旋转 90 度（若箭头指右则旋转 90 度，指下则 180 度，指左则 270 度，指上则不旋转）。
- 旋转后的图案沿箭头指向方向进行射线投射，找到射线上遇到的下一个路标箭头，将旋转后的图案传递到该箭头中心位置，再按新箭头的指向再次旋转。
- 重复此过程直到射线方向上没有更多路标箭头为止。
- 输出网格保留所有路标箭头，并在每个被经过的箭头位置叠加对应旋转状态的图案副本。源图案原始位置保留。

Key insight:
解题者必须先理解 T 形像素结构编码了方向信息，然后发现传递链的顺序由颜色标记启动、由射线投射决定下一站，最后还需认识到每一站的旋转量取决于当前箭头的朝向——三层推理环环相扣。
</description>
</new_puzzle>

<description>
将网格中的多面"镜子"墙段与光源组合，追踪光线的反射路径，并用光源颜色填充光线经过的所有像素。

Input structure:
- 背景为网格中最常见的颜色（例如 black）。网格中有若干条由 grey 像素组成的水平或垂直线段，作为"镜面墙段"。
- 网格边缘（第一行、最后一行、第一列或最后一列）上有若干单个彩色像素作为"光源"，每个光源颜色不同。光源所在的边缘位置决定了初始光线的发射方向：顶边光源向下发射，底边向上，左边向右，右边向左。
- 每条镜面墙段的一个端点旁有一个 maroon 色的单像素标记，位于墙段端点的对角位置（左上、右上、左下或右下），指示该端点处光线的偏转方向。

Rule:
- 从每个光源沿其初始方向发射光线（逐像素前进）。
- 光线遇到镜面墙段时，根据该墙段端点处 maroon 标记的位置，将光线偏转 90 度继续前进。
- 光线遇到网格边界或另一光源时停止。
- 将光线经过的所有背景像素染成该光源的颜色。若两条光线交叉，交叉点使用后到达该点的光线颜色（按光源从左到右、从上到下的扫描顺序决定先后）。
- 镜面墙段和 maroon 标记保持不变。

Key insight:
解题者需要先识别光源位置与发射方向的边缘编码规则，再理解 maroon 标记相对于墙段端点的空间位置编码了反射偏转方向，最后追踪多条光线的完整反射路径——每一层都需要独立的模式归纳。
</description>

<description>
根据分区面板中图案的对称性类型选择对应的颜色映射，将图案重新着色后输出。

Input structure:
- 网格被单像素宽的 grey 分隔线分成若干等大的正方形面板，排列为若干行若干列。
- 每个面板内部有一个由某种前景色在背景色上绘制的图案。图案具有不同的对称性：有些仅具有水平轴对称、有些仅具有垂直轴对称、有些同时具有水平和垂直轴对称（即 180 度旋转对称）、有些不具有任何对称性。
- 网格的最后一行面板是"图例行"：每个面板内部是纯色填充（无图案），从左到右共四个面板分别对应四种颜色，代表"双轴对称"、"仅水平对称"、"仅垂直对称"和"无对称"的输出颜色。

Rule:
- 读取图例行中四个面板从左到右的颜色分别为 C_both（双轴对称）、C_h（仅水平对称）、C_v（仅垂直对称）、C_none（无对称）。
- 对图例行以外的每个面板，分析其内部图案的对称性类型：同时具有水平和垂直轴对称归为"双轴对称"；仅关于水平中轴对称归为"仅水平对称"；仅关于垂直中轴对称归为"仅垂直对称"；两者都不具备归为"无对称"。
- 将该面板内的前景色像素全部重新着色为对应对称性类型的颜色，背景像素保持不变。
- 输出仅包含图例行以外的面板区域（含分隔线），图例行被裁掉。

Key insight:
解题者需要先发现最后一行面板是纯色图例而非普通图案面板，然后推断出图例从左到右的四种颜色分别对应四种对称性类型的分类规则，再对每个图案做对称性判定——对称性类型的视觉判断和图例映射关系的归纳构成两层独立的推理。
</description>

<description>
在由障碍物分隔的多个房间之间，根据房间内种子像素的数量选取调色板颜色并生成对应圈数的螺旋填充图案。

Input structure:
- 背景为网格中最常见的颜色（例如 black）。网格中有若干由 blue 像素组成的连通墙壁，将网格划分为多个封闭的矩形"房间"。
- 每个房间内部散布着若干个 red 单像素"种子点"。种子点的数量在 1 到 5 之间。
- 网格的某个角落有一个小型色带（由 2 到 5 个不同颜色的像素排成一行），作为"调色板"。

Rule:
- 对每个房间，数出其内部 red 种子点的个数 N。
- 从调色板中取第 N 个颜色（调色板从左到右第 1、2、3...个像素）。
- 从房间的左上角开始，用该颜色绘制一个顺时针螺旋线条，螺旋的臂宽为 1 像素，螺旋圈数为 N 圈。螺旋线不覆盖原有的 red 种子点位置（种子点保留为 red）。
- 若螺旋超出房间边界则在房间边界处截断。
- 墙壁和调色板保持不变。

Key insight:
解题者需要先发现种子点数量与螺旋圈数的对应关系，再发现种子点数量同时作为调色板索引来决定螺旋的颜色——同一个可视属性（种子数量）同时控制两个不同的输出特征，这种双重编码是核心隐蔽机制。
</description>

<description>
将网格中的多个相同尺寸但不同颜色的重叠矩形按遮挡关系还原层序，然后根据深度调色板重新着色。

Input structure:
- 背景为网格中最常见的颜色。网格上有若干个尺寸完全相同的实心矩形色块，互相部分重叠，每个矩形使用不同的颜色。
- 由于重叠，部分矩形被遮挡，只能看到未被覆盖的像素区域。
- 网格的一侧边缘有一个垂直排列的颜色条（由若干个不同颜色的单像素从上到下排列），作为"深度调色板"。调色板的第一个颜色（最上方）对应最顶层，最后一个颜色（最下方）对应最底层。

Rule:
- 通过分析可见像素区域推断每个矩形的完整位置（所有矩形尺寸相同，可从完全可见的矩形获得尺寸信息）。
- 根据遮挡关系确定从顶到底的层叠顺序：若矩形 A 的预期区域中出现了矩形 B 的颜色像素，则 B 在 A 之上。
- 将每个矩形重新着色为深度调色板中对应层深度位置的颜色：最顶层矩形用调色板第 1 个颜色，第二层用第 2 个颜色，依此类推。
- 按原始层叠顺序重新绘制所有矩形（保持遮挡关系不变），但使用新的深度颜色。调色板本身从输出中移除。

Key insight:
解题者必须先从部分可见的像素中推断出所有矩形的完整位置，再通过遮挡像素分析出层叠顺序，最后发现边缘的颜色条是按深度重新着色的映射表——三个推理步骤依次递进，每一步的输出都是下一步的输入。
</description>

<description>
利用网格中散布的同色"锚点对"确定复制目标位置，并根据 L 形标记解读全局旋转角度，将主图案旋转后复制到各目标位置。

Input structure:
- 背景为网格中最常见的颜色。网格中有一个由某种前景色绘制的主图案区域（一个小型非对称连通图形）。
- 网格中有若干"锚点对"：每对由两个相同颜色的单像素组成，不同对使用不同的颜色。每对中的一个像素位于主图案的包围盒内部，另一个像素位于主图案外部的空白区域。
- 主图案外部还有一个由 grey 像素绘制的 L 形标记（三个像素组成直角形状），L 形的开口方向编码了旋转角度：开口朝右上方表示顺时针旋转 90 度，开口朝右下方表示 180 度，开口朝左下方表示 270 度，开口朝左上方表示 0 度（不旋转）。

Rule:
- 读取 L 形标记的开口方向，确定全局旋转角度 θ。
- 对每个锚点对，以主图案内部的锚点像素作为参考点，计算主图案中每个前景像素相对于该参考点的偏移量。
- 将这些偏移量旋转 θ 度后，以该锚点对的外部像素为新参考点，绘制旋转后的图案副本。
- 若多个副本重叠，后绘制的覆盖先绘制的（按锚点对颜色在网格中首次出现的行号从小到大排序决定绘制先后）。
- 主图案、所有锚点像素和 L 形标记保留在原位不变。

Key insight:
解题者需要先将散布的同色像素对配对并识别出"内部点=参考原点，外部点=放置目标"的角色分配规则，再从 L 形标记的几何朝向中解读出全局旋转角度——锚点配对与方向解码是两个相互独立的推理层，二者结合才能确定最终的变换。
</description>
</new_puzzle>
