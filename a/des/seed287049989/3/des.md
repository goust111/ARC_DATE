<new_puzzle>
description
根据封闭区域内部散落标记像素的颜色，选取对应颜色的边界段作为"门"打开（擦除），然后将区域内所有非标记前景对象沿门的朝向平移出去，直到离开网格。

Input structure
- 背景为主色。网格中有若干由单一"墙色"围成的封闭矩形区域，每个区域的四条边可能由不同颜色的线段拼接而成（每条边整体为一种非背景、非墙色的前景色，不同边颜色不同）。
- 每个封闭区域内部有一个或多个小型前景对象（形状各异，颜色与边界段颜色无关），以及恰好一个孤立的单像素标记点。
- 标记点的颜色与该区域某一条边界段的颜色相同。

Rule
- 对每个封闭区域，找到其内部标记像素的颜色，定位与该颜色匹配的边界段。
- 将该边界段擦除为背景色（即"打开门"）。
- 将区域内所有非标记前景对象沿门所在边的法线外方向（上边→向上，下边→向下，左边→向左，右边→向右）逐像素平移，直到对象完全离开网格边界。
- 标记像素本身也被擦除，墙的其余部分保持不变。

Key insight
标记像素不是装饰，而是一把"钥匙"——它的颜色指定了哪段墙被打开，门的位置又隐含地决定了内部对象的弹射方向。解题者需要先完成颜色匹配（钥匙→门），再推断方向（门的朝向→平移方向），这是两层独立的非平凡推理。
</new_puzzle>

<new_puzzle>
description
将网格中散落的单色碎片按形状互补配对拼合成完整矩形，再按矩形面积从小到大纵向堆叠输出。

Input structure
- 背景为主色。网格上散布着若干个单色 4-连通前景对象，每个对象的颜色各不相同。
- 这些对象可以两两配对：同一对中的两个对象形状互补——将其中一个对象水平翻转后，与另一个对象拼合恰好填满一个无空隙的实心矩形。
- 对象总数为偶数，保证配对唯一（每对拼出的矩形尺寸不同）。

Rule
- 识别所有前景对象，计算每个对象的最小包围矩形(bbox)。
- 对于 bbox 尺寸相同的两个对象，将其中一个水平翻转后与另一个叠加，验证它们恰好互补填满该 bbox（一个对象的前景像素恰好是另一个翻转后对象的背景像素）。
- 拼合时，面积较小的对象的颜色填充整个矩形（即整个矩形统一用该对中像素数较少的那个对象的颜色）。
- 将所有拼成的矩形按面积从小到大排列，从输出网格顶部开始纵向依次排列，矩形之间无间隔，左对齐。输出网格宽度等于最宽矩形的宽度，高度等于所有矩形高度之和。

Key insight
解题者首先需要发现碎片之间的互补配对关系（翻转后拼合为矩形），然后需要发现输出颜色的选取规则（取像素数较少者的颜色），最后还需发现排列规则（按面积排序堆叠）。三层推理环环相扣：配对→选色→排序。
</new_puzzle>

<new_puzzle>
description
在网格中找到"模板区域"和若干"印章区域"，将模板中各颜色层的叠放顺序反转后，重新绘制到每个印章区域中。

Input structure
- 背景为主色。网格被灰色的十字分割线划分为若干等大的矩形子区域。
- 恰好有一个子区域是"模板区域"：其中包含多个不同颜色的矩形色块，这些色块存在部分重叠，重叠处只显示最上层的颜色。模板区域的四个角上各有一个红色单像素标记。
- 其余子区域为"印章区域"，初始时全为背景色。

Rule
- 识别带有四角红色标记的子区域为模板。
- 从模板中还原每个彩色矩形的完整范围：被遮挡的部分可以通过可见边缘和矩形假设推断出来（每个色块都是完整的轴对齐矩形）。
- 确定各矩形的叠放顺序：在重叠像素处可见的颜色位于上层，被遮挡的颜色位于下层。
- 将叠放顺序完全反转（原来最底层的变为最顶层，原来最顶层的变为最底层），然后按反转后的顺序重新绘制所有矩形到每个印章区域中（矩形的位置和尺寸相对于子区域不变）。
- 模板区域本身保持不变。

Key insight
解题者需要先从被遮挡的画面"逆向工程"出每个矩形的完整形状和层叠顺序，然后执行层序反转重绘。关键难点在于：遮挡信息是唯一能揭示层叠顺序的线索，而反转后的输出看起来与输入的模板截然不同，因为不同的矩形暴露了出来。
</new_puzzle>

<new_puzzle>
description
每个前景对象根据其内部孔洞的数量，向外生长对应层数的同色轮廓环；孔洞本身用对象颜色填实。

Input structure
- 背景为主色（black）。网格中有若干彼此不相邻的单色 4-连通前景对象。
- 部分对象内部包含一个或多个由背景色构成的封闭孔洞（4-连通背景区域，不与网格边界相连）。
- 部分对象没有孔洞。
- 对象之间的间距足够大，使得生长后的轮廓环不会重叠。

Rule
- 对每个前景对象：
  1. 计算其内部封闭孔洞的数量 N（没有孔洞则 N=0）。
  2. 用该对象的颜色填实所有孔洞。
  3. 以填实后的对象为基础，向外扩展 N 层像素环（每一层是当前形状的 4-邻域外扩一圈），所有新增像素使用该对象的原始颜色。
- 没有孔洞的对象（N=0）仅填实（无变化），不生长任何轮廓环。

Key insight
孔洞数量承担了双重角色：它既是需要被消除的结构（填实），又是决定向外生长层数的计数器。解题者必须先发现"孔洞数=生长层数"这个非显然的映射关系，然后才能正确预测输出。仅仅看到"对象变大了"不足以归纳规则——必须关联到孔洞计数。
</new_puzzle>

<new_puzzle>
description
将网格中的彩色路径按其经过的"检查站"顺序截断并重排颜色，使每段路径的颜色反映它在检查站序列中的位次。

Input structure
- 背景为主色。网格中有一条由单一前景色（如 blue）绘制的连续单像素宽路径（4-连通，无分支，两个端点各只有一个 4-邻居属于路径）。
- 路径上散布着若干"检查站"像素，每个检查站是一个与路径 4-相邻的孤立单像素，颜色各不相同（非背景、非路径色）。
- 检查站不在路径上，而是紧贴路径旁边。

Rule
- 从路径的一个端点出发，沿路径行走到另一个端点。
- 按行走过程中依次遇到（4-相邻经过）的检查站顺序，记录检查站颜色序列：C1, C2, C3, ...
- 将路径分为对应的段：从起点到第一个检查站旁的路径像素为第一段，涂为 C1 的颜色；从第一个检查站到第二个检查站之间的路径像素为第二段，涂为 C2 的颜色；依此类推，最后一个检查站之后到终点的路径像素涂为最后一个检查站的颜色。
- 路径的起点端点定义为：行号更小的端点；若行号相同，则列号更小的端点。
- 检查站像素本身保持不变。

Key insight
解题者需要完成三层推理：（1）识别出路径是一条无分支的连续线，与旁边的孤立彩色像素（检查站）是不同角色；（2）发现路径的行走方向决定了检查站的遇到顺序；（3）发现检查站颜色被"投射"到路径段上。路径本身的形状不变，只有颜色被重新分配，这使得规则不易一眼看出。
</new_puzzle>

<new_puzzle>
description
将网格中每个"容器"对象内的彩色填充物按照容器开口方向"倒出"，使填充物沿开口方向滑落到网格边缘并堆积。

Input structure
- 背景为主色。网格中有若干由灰色像素构成的 U 形"容器"对象（即三面封闭、一面开口的矩形凹槽），每个容器有且仅有一个开口方向（上、下、左、右之一）。
- 每个容器内部（凹陷区域）填充了一种非背景、非灰色的纯色色块，色块完全充满凹槽内部空间。
- 不同容器内的填充色各不相同。
- 容器之间互不重叠，且每个容器开口方向朝向的路径上无其他对象阻挡直至网格边缘。

Rule
- 对每个容器，识别其开口方向（灰色像素围成 U 形，唯一没有灰色封闭的那一侧即为开口方向）。
- 将容器内部的彩色填充物从容器中移除（原位置变为背景色）。
- 将填充物保持其形状不变，沿开口方向平移，直到填充物的前缘碰到网格边界，此时停止。
- 灰色容器本身保持原位不动。

Key insight
容器的开口方向是隐含的——解题者必须通过观察灰色像素围成的 U 形形状，判断哪一侧缺少封闭边界，从而推断出"倒出"方向。每个容器的开口可能朝不同方向，因此不存在全局统一的运动方向。关键推理在于：容器的几何缺口决定了运动方向，而非任何外部标记。
</new_puzzle>

<new_puzzle>
description
根据网格边缘的色带编码，在网格内部对应的行或列上绘制穿透线，穿透线交叉处取两条线颜色中在边缘上距离角落更近的那条线的颜色。

Input structure
- 背景为主色。网格的四条边缘（最外一圈像素）上分布着若干彩色像素段，其余边缘像素为背景色。
- 上边缘和下边缘上的彩色段标记了需要绘制竖直穿透线的列范围和颜色。
- 左边缘和右边缘上的彩色段标记了需要绘制水平穿透线的行范围和颜色。
- 每个彩色段是连续的同色像素（长度至少为 1），不同段的颜色各不相同。
- 上边缘的段和下边缘的段在列位置上一一对应（同一竖直线在上下边缘都有标记，颜色相同）。
- 左边缘的段和右边缘的段在行位置上一一对应（同一水平线在左右边缘都有标记，颜色相同）。

Rule
- 对于上/下边缘的每个彩色段，在该段覆盖的每一列上从第 1 行到倒数第 2 行绘制该颜色的竖直线（不覆盖边缘行本身）。
- 对于左/右边缘的每个彩色段，在该段覆盖的每一行上从第 1 列到倒数第 2 列绘制该颜色的水平线（不覆盖边缘列本身）。
- 当竖直线和水平线交叉时，交叉像素的颜色取两者中边缘段的最近端点距离最近网格角落更近的那条线的颜色。即：对每条线，计算其边缘段两端中离最近角落更近的那个端点到角落的步数；步数更小的线颜色优先。若步数相同，竖直线优先。

Key insight
边缘色带同时编码了线的位置和颜色，这一层是直观可见的。但交叉处的颜色优先级规则隐藏在边缘段与角落的空间关系中——解题者需要观察多个交叉点的颜色，才能归纳出"离角落更近的线优先"这个非显然的规则。这构成了两层推理：边缘→线条绘制，以及角落距离→交叉优先级。
</new_puzzle>

<new_puzzle>
description
将网格中的多个同尺寸异色对象视为"投票者"，对每个像素位置进行多数投票生成共识形状，再用每个对象与共识的偏差数决定其在输出中的排列顺序。

Input structure
- 背景为主色。网格中有若干个相同 bbox 尺寸的前景对象，它们分散排列互不重叠，每个对象使用不同的单一颜色。
- 这些对象的形状高度相似但不完全相同：每个对象在相同的 bbox 内，大部分像素位置一致（即该位置要么所有对象都有前景像素，要么所有对象都是背景），但各有少量位置与其他对象不同。
- 对象数量为奇数（如 3 或 5），保证多数投票不会平局。

Rule
- 将所有对象的 bbox 对齐叠放，对每个像素位置进行多数投票：若超过半数的对象在该位置有前景像素，则该位置为"共识前景"，否则为"共识背景"。
- 用 green 绘制共识形状，放置在输出网格的最左侧。
- 计算每个原始对象与共识形状不同的像素数量（即"偏差数"）。
- 将原始对象按偏差数从小到大从左到右依次排列在共识形状右侧，每个对象保持原始颜色，对象之间间隔一列背景色。
- 输出网格高度等于对象的 bbox 高度，宽度根据排列内容自适应。

Key insight
解题者需要先发现所有对象形状几乎相同但各有微小差异，然后推断出"多数投票"产生共识形状的机制，最后还需发现输出中对象的排列顺序由偏差数决定。这三层推理——识别相似性、归纳投票规则、发现排序依据——层层递进，每一层都需要主动归纳。
</new_puzzle>
