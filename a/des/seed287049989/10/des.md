<new_puzzle>
根据封闭区域内部的颜色种类数，从对应颜色图例中选色重绘该区域的边框。

Input structure
- 背景为黑色。网格中有若干由灰色像素围成的封闭矩形区域，每个区域内部散布着一种或多种非灰色、非黑色的彩色像素点。
- 网格的底部或右侧有一行/列颜色图例：图例由从左到右（或从上到下）排列的单色色块组成，每个色块占一个像素，颜色各不相同，位置索引从 1 开始。

Rule
- 对每个灰色封闭矩形区域，数出其内部出现了多少种不同的非黑色颜色（记为 N）。
- 在颜色图例中找到第 N 个位置对应的颜色 C。
- 将该矩形的灰色边框全部重绘为颜色 C，内部像素保持不变。
- 颜色图例本身在输出中被移除（对应行/列变为黑色）。

Key insight
- 解题需要两步非显然的归纳：第一步发现封闭区域内颜色种类数是关键属性；第二步发现底部色条是索引图例，而非装饰或直接的颜色映射。
</new_puzzle>

<new_puzzle>
将网格中各彩色"种子"沿其所在象限的对角方向发射射线，射线在碰到其他射线的尾迹时反弹为正交方向继续延伸。

Input structure
- 背景为黑色，网格尺寸为偶数行×偶数列。
- 网格正中心有一个由绿色像素组成的十字分隔线（一行加一列），将网格分为四个象限。
- 每个象限中散布一到两个单像素的彩色种子（颜色各不相同，且不为绿色或黑色）。

Rule
- 每个种子根据其所在象限确定初始发射方向：左上象限向左上对角发射，右上象限向右上对角发射，左下象限向左下对角发射，右下象限向右下对角发射。
- 射线以种子自身的颜色逐像素绘制，遇到网格边缘则停止。
- 若射线的下一个像素已被另一条射线占据（非黑色、非绿色），则该射线转向 90 度（对角线变为水平或垂直方向中能继续延伸的那个方向），然后继续绘制直到再次碰壁或到达边缘。若两个正交方向都被阻挡则停止。
- 种子按从上到下、从左到右的顺序依次处理。

Key insight
- 象限位置决定初始方向是隐含的空间规则，而射线碰撞后的正交反弹使得处理顺序影响最终图案——解题者需要同时归纳方向规则和交互规则。
</new_puzzle>

<new_puzzle>
用框架内部小标记的相对位置作为平铺偏移量，将框架内的图案在整个网格中重复平铺。

Input structure
- 背景为黑色。网格中有一个由红色像素围成的矩形框架（一像素宽边框）。
- 框架内部包含一个由多种颜色组成的小型图案（不含红色和黑色），以及恰好一个蓝色标记像素。
- 蓝色标记像素位于框架内部，但不属于图案本身。

Rule
- 提取框架内部的矩形区域（不含红色边框）作为"瓦片"。
- 蓝色标记像素在瓦片内的相对坐标 (dr, dc) 定义了平铺的行偏移和列偏移。
- 从框架的原始位置开始，沿行方向每隔 dc 列、沿列方向每隔 dr 行放置一个瓦片副本，覆盖整个网格（超出网格部分裁剪）。
- 在输出中，蓝色标记像素的位置用黑色替代（标记本身不参与平铺图案），红色边框也被移除。

Key insight
- 蓝色标记不是图案的一部分而是编码信息：它的局部坐标同时定义了两个方向的平铺步长——这是一个"元数据嵌入在数据中"的隐蔽编码。
</new_puzzle>

<new_puzzle>
识别网格中每个"缺损环"的缺口方位，在缺口对面的环外侧生长出与缺口弧长等长的同色直线段。

Input structure
- 背景为黑色。网格中散布若干由单一颜色像素组成的近似矩形环（空心矩形，一像素宽边框），每个环有且仅有一段连续缺口（即环的四条边中某一条边上缺少若干连续像素）。
- 各环的颜色互不相同，环之间不重叠。

Rule
- 对每个环，找到其缺口所在的边（上、下、左或右）以及缺口的长度（缺失像素数，记为 L）。
- 在缺口的正对面那条边的外侧，绘制一条与该边平行的同色直线段，长度为 L 个像素。
- 该直线段的中心与缺口的中心在垂直于边的方向上对齐。直线段紧贴环外侧（与环边框相距一个像素）。
- 原始环的缺口保持不变（不补全）。

Key insight
- 解题者需要先识别缺口的位置和方位，再理解"对面"这一空间反转关系，最后发现缺口长度被用作外部线段的长度——一个可视属性在空间反转后被复用为几何度量。
</new_puzzle>

<new_puzzle>
根据彩色箭头的指向和箭身长度，将箭头尖端对应行/列内的目标色块沿箭头方向平移箭身长度的距离。

Input structure
- 背景为黑色。网格中有若干由灰色像素组成的矩形色块，大小和位置各异。
- 网格边缘附近有若干彩色箭头。每个箭头由"箭身"和"箭头尖端"组成：箭身是沿水平或垂直方向排列的同色像素直线（至少 2 像素长）；箭头尖端是箭身末端额外的一个像素，偏移到箭身延伸方向的下一格（即箭头指向箭身延伸的方向）。箭头颜色各不相同，且不为灰色或黑色。
- 每个箭头的尖端所在行或列上恰好有一个灰色色块（箭头水平则对应该行，箭头垂直则对应该列）。

Rule
- 对每个箭头，确定其指向方向（上、下、左或右）和箭身长度（箭身像素数，不含尖端，记为 L）。
- 找到箭头尖端所在行或列上的灰色色块。
- 将该灰色色块沿箭头指向方向平移 L 个像素。平移后色块用箭头的颜色重绘（不再是灰色）。
- 色块原始位置变为黑色。箭头本身在输出中被移除。

Key insight
- 箭头同时编码三种信息：方向（指向）、距离（箭身长度）和目标选择（尖端对齐的行或列）。解题者还需发现灰色色块被重绘为箭头颜色——箭头不仅控制运动，还传递颜色属性。
</new_puzzle>

<new_puzzle>
将散落的彩色碎片按颜色匹配到模板的同色锚点上，以锚点为基准将碎片拼入模板的空白区域。

Input structure
- 背景为黑色。网格左侧有一个较大的灰色矩形模板（实心），模板内部散布若干单像素的彩色锚点（颜色各不相同，不为灰色或黑色）。
- 网格右侧散布若干小型彩色碎片，每个碎片是由多个像素组成的连通形状，碎片中恰好有一个像素的颜色与模板中某个锚点颜色相同，其余像素为灰色。
- 碎片数量与锚点数量相等，颜色一一对应。

Rule
- 对每个碎片，找到其中颜色与某锚点匹配的那个像素，将其作为碎片的"定位点"。
- 将碎片平移，使定位点与模板中对应颜色的锚点重合。
- 碎片中灰色像素覆盖模板上的对应位置（如果该位置原本是灰色则变为黑色——即在模板上"挖洞"）。
- 输出仅包含模板区域（裁剪到模板的边界框），碎片原始位置变为黑色。彩色锚点/定位点像素在输出中保留其颜色。

Key insight
- 颜色匹配确定了碎片与锚点的配对关系，碎片内的彩色像素充当对齐基准点——这是一种"注册标记"机制。碎片的灰色部分在拼合后执行的是"减法"操作（挖除模板），而非直觉上的"加法"填充。
</new_puzzle>

<new_puzzle>
网格中的彩色线段两两配对形成"门"，将穿过门的灰色路径在出门后重新着色为门的颜色。

Input structure
- 背景为黑色。网格中有一条由灰色像素组成的连续曲折路径（一像素宽，四连通），从网格的一条边进入、从另一条边离开。
- 路径沿途穿过若干"门"。每扇门由两个相同颜色的短线段（2-3 像素长）组成，分别位于路径的两侧且与路径垂直，形成门框状结构。
- 不同的门使用不同的颜色（不为灰色或黑色），门的数量为 2 到 4 个。

Rule
- 沿路径从入口到出口的方向依次遍历。路径初始为灰色。
- 每当路径穿过一扇门，此后路径上的像素被重绘为该门的颜色，直到路径穿过下一扇门。
- 若路径在最后一扇门之后还有剩余段，则该段保持最后一扇门的颜色。
- 门的入口之前的路径段保持灰色。门本身的彩色线段在输出中保持不变。

Key insight
- 解题者需要先从路径的连通性推断行进方向（从一边到另一边），再沿行进方向识别门的穿越顺序——门的颜色不是标记路径的起始段，而是标记路径穿过该门之后的区段。行进方向的确定是隐含的第一层推理。
</new_puzzle>

<new_puzzle>
根据每个封闭房间内墙壁上彩色标记的数量，在房间内部从下往上堆叠相应高度的同色填充层。

Input structure
- 背景为黑色。灰色像素组成若干相连的"墙壁"，将网格分隔成多个封闭的矩形"房间"（每个房间是一个黑色的矩形连通区域，四面被灰色墙壁包围）。
- 每个房间的墙壁上（紧邻房间内部的灰色像素中）嵌有若干彩色标记像素。同一个房间的所有标记颜色相同，不同房间的标记颜色不同。

Rule
- 对每个房间，数出其墙壁上彩色标记的数量（记为 N）。
- 在该房间的内部，从底部向上填充 N 行该标记颜色的像素（填满房间的整个宽度）。
- 若 N 大于或等于房间的内部高度，则整个房间内部被填满。
- 灰色墙壁和彩色标记在输出中保持不变。

Key insight
- 标记的颜色确定了填充色，而标记的数量被转化为填充的高度——同一种视觉元素同时编码了"是什么颜色"和"填多高"两个独立属性。解题者容易注意到颜色对应关系，但需要进一步归纳出"计数→高度"的量化映射。
</new_puzzle>
