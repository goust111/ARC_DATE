<description>
根据封闭区域内种子像素的颜色，从色带图例中查找对应的填充纹理，再按区域朝向旋转纹理后铺满区域。

Input structure:
- 背景为黑色。网格中有若干由灰色线条围成的封闭矩形区域，每个区域内部恰好包含一个彩色种子像素。
- 网格右侧边缘有一列纵向排列的小矩形色带图例，每个图例由两部分组成：左侧一列为单色键（与种子像素颜色对应），右侧为一个 3×3 的双色纹理方块（由键色和另一种颜色组成的图案）。
- 每个封闭区域的灰色边框上恰好有一个缺口（宽度为 1 个像素），缺口可能位于上、下、左、右任意一侧。

Rule:
- 对每个封闭区域，找到其内部种子像素的颜色，在右侧图例中查找键色匹配的纹理。
- 根据区域边框缺口的位置确定旋转角度：缺口在上方 → 纹理不旋转（0°）；缺口在右方 → 顺时针旋转 90°；缺口在下方 → 旋转 180°；缺口在左方 → 顺时针旋转 270°。
- 将旋转后的 3×3 纹理以平铺方式填满整个区域内部（不含灰色边框），多余部分截断。种子像素被纹理覆盖。
- 灰色边框、缺口和图例保持不变。

Key insight: 种子颜色决定"用什么纹理"，缺口方向决定"纹理怎么旋转"——解题者需要同时发现颜色匹配和方向编码两层独立规则。
</description>

<description>
将散落的彩色碎片按形状互补关系配对拼合，拼合后的复合体按面积从小到大排列输出。

Input structure:
- 背景为黑色。网格中散布着若干彩色小形状（每个形状为单色连通区域，4-连通，面积 2–6 像素）。
- 形状总数为偶数，恰好可以两两配对。
- 每对互补形状拼合后恰好填满一个完整矩形（无重叠、无空隙）。同一对中的两个形状颜色不同。

Rule:
- 找到所有能拼合成完整矩形的形状配对（每个形状只属于一对）。配对的判定方式：将一个形状进行上下左右平移（不旋转、不翻转），使其与另一个形状相邻且合并后的外接矩形内无空隙。
- 对每一对，将两个形状合并绘制为一个完整矩形，保留各自原色。
- 输出网格宽度等于所有矩形宽度之和加上间距（矩形之间留 1 列黑色间隔），高度等于最大矩形的高度。
- 矩形按总面积从小到大、从左到右排列。面积相同则按矩形中出现的颜色编号较小者优先（颜色顺序：Blue < Red < Green < Yellow < Grey < Magenta < Orange < Azure < Maroon）。

Key insight: 解题者需先通过形状互补关系完成配对（而非颜色匹配），再按合并后面积排序——配对逻辑和排序逻辑构成两层独立推理。
</description>

沿彩色路径传播信号，在路径交叉口根据优先级规则选择前进方向，最终将到达的终端区域染色。

Input structure:
- 背景为黑色。网格中有一张由灰色像素构成的正交路径网络（路径宽度 1 像素），路径上存在若干交叉口（灰色像素的正交邻居中有 3 个或 4 个也是灰色）。
- 路径的若干末端（只有 1 个灰色正交邻居的灰色像素）各连接着一个小的单色矩形区域（终端），每个终端颜色不同。
- 网格的一条边（如顶部边缘）上有一个红色起始标记像素，紧邻路径网络的某个入口。
- 每个交叉口旁边（8-邻域中）恰好有一个彩色方向标记像素（非灰色、非黑色），其相对于交叉口的位置编码了优先前进方向：标记在交叉口的上方表示优先向上，在右方表示优先向右，以此类推。

Rule:
- 信号从红色起始标记进入路径网络，沿灰色像素前进。
- 在直道上（仅有前后两个灰色邻居），信号继续直行。
- 到达交叉口时，读取该交叉口旁的方向标记：信号优先转向标记所指方向。如果该方向不可通行（无灰色路径），则选择顺时针方向的下一个可通行方向。
- 信号沿路径行进直到到达某个终端。
- 输出中，信号到达的终端区域被染为红色，其余终端保持原色，路径网络和标记不变。

Key insight: 交叉口旁标记像素的相对位置编码了转向优先级——解题者需要先识别"位置即方向"的编码方式，再模拟信号沿路径的传播和转向决策。
</description>

<description>
在网格中找到被"钥匙"形状匹配的"锁"形状，将锁内隐藏区域的颜色复制到对应钥匙的位置。

Input structure:
- 背景为黑色。网格中有若干"锁"和"钥匙"对象。
- 每把"锁"是一个较大的单色矩形区域（如蓝色），其内部挖去了一个不规则形状的孔洞（孔洞为黑色），孔洞内部藏有一个由另一种颜色填充的小图案（秘密图案）。
- 每把"钥匙"是一个与某个锁的孔洞形状完全相同的单色填充形状（形状匹配允许旋转 0°/90°/180°/270°，但不允许翻转），钥匙的颜色与对应锁的外框颜色相同。
- 锁和钥匙在网格中的位置互不重叠。

Rule:
- 对每把钥匙，找到孔洞形状与之匹配的锁（考虑旋转）。确定钥匙需要旋转多少度才能与锁的孔洞对齐。
- 将锁内秘密图案提取出来，按与钥匙相同的旋转角度旋转。
- 在输出中，钥匙的位置被替换为旋转后的秘密图案（背景像素保持黑色），锁保持不变。

Key insight: 钥匙的外形轮廓编码了它属于哪把锁（形状匹配），而旋转关系同时决定了秘密图案的朝向——解题者需先完成形状匹配配对，再推断旋转变换如何作用于隐藏图案。
</description>

根据围栏颜色从图例读取生长步数，让围栏内的种子图案向外扩展相应层数，不同围栏的生长产物在重叠处混色。

Input structure:
- 背景为黑色。网格中有若干彩色矩形围栏（每个围栏为单色空心矩形边框，颜色各不相同），围栏内部各有一个小的单色种子图案（种子颜色与围栏颜色不同）。
- 网格底部有一行图例：由若干 1×2 的小色块对组成，每对左侧像素颜色对应某个围栏颜色，右侧像素为 Red、Green 或 Yellow 之一，分别编码生长步数 1、2、3。

Rule:
- 对每个围栏，在图例中找到与其颜色匹配的条目，读取对应的生长步数 N。
- 移除围栏边框。将种子图案保留，然后向外扩展 N 层：每一层是上一层所有像素的 4-邻域中尚未被占据的黑色像素，新层填充为种子的颜色。
- 如果两个不同种子的生长区域在同一像素重叠，该像素填充为灰色。
- 围栏边框像素在输出中变为黑色（被移除），图例保持不变。

Key insight: 图例中的颜色对应关系和"颜色即步数"的编码需要同时被发现——围栏颜色查图例获得步数，步数控制形态扩展，重叠产生混色，形成三层推理链。
</description>

<description>
利用彩色标尺线段的长度确定对应颜色对象的缩放倍率，将对象按倍率缩放后放置到输出画布的指定锚点。

Input structure:
- 背景为黑色。网格被一条灰色水平分割线分为上下两部分。
- 上半部分包含若干小的彩色对象（每个为单色 4-连通区域，面积 3–6 像素），以及与每个对象颜色相同的水平线段（标尺），标尺与对象不相连。每根标尺长度为 2 或 3 像素。
- 下半部分是一个较大的黑色画布，画布中散布着若干单像素的彩色锚点标记，每个锚点的颜色与上方某个对象相同。

Rule:
- 对每个对象，找到同颜色的标尺，标尺长度即为缩放倍率 K（2 或 3）。
- 将对象按倍率 K 放大：对象中的每个像素扩展为 K×K 的方块，整体形状等比放大。
- 在下半部分画布中找到同颜色的锚点标记，将放大后的对象放置于画布上，使放大对象的左上角与锚点位置对齐。
- 锚点标记被放大后的对象覆盖。上半部分（含原始对象和标尺）在输出中保持不变。

Key insight: 标尺不是装饰而是编码缩放倍率的度量工具——解题者需要先发现标尺长度与放大倍率的对应关系，再理解锚点决定放置位置，两层规则缺一不可。
</description>

<description>
根据容器开口方向收集沿该方向飞来的彩色子弹像素，将子弹按到达顺序堆叠在容器内部。

Input structure:
- 背景为黑色。网格中有若干由灰色像素构成的 U 形容器（每个容器由三面灰色墙壁围成，开口朝上、下、左或右之一），容器内部初始为黑色，内部空间为 1 像素宽、3–5 像素深。
- 在每个容器开口方向的远处，有若干彩色单像素散布在与容器开口对齐的行或列上（即子弹位于容器开口正前方的直线延长线上）。同一容器前方可能有多颗不同颜色的子弹。

Rule:
- 每颗子弹沿容器开口的反方向飞行（即朝容器方向移动），直到进入容器内部。
- 子弹按距离容器远近排序：离容器最近的子弹最先到达，堆在容器底部（离开口最远的位置）；后到的子弹依次堆叠在前一颗上方（朝开口方向）。
- 如果子弹数量超过容器深度，多余的子弹停留在容器开口外侧、紧贴容器边缘依次排列。
- 子弹原始位置在输出中变为黑色。容器灰色墙壁保持不变。

Key insight: 容器的 U 形开口方向决定了子弹的飞行轴和堆叠方向——解题者需识别开口朝向（隐含在灰色墙壁的缺失侧），再理解"近者先到、从底部堆叠"的填充顺序。
</description>
</new_puzzle>
