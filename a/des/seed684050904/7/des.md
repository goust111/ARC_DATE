## 第一步：分析与思考

### 参考题目中涉及的基础操作梳理

1. **空间映射与缩放**（参考1）：小精灵作为微缩线图映射到框架内部，涉及坐标映射和线段填充。
2. **信号传播与形态变换**（参考2）：沿线网传递令牌，并在传播过程中进行形态循环变换（实心→X→菱形）。
3. **递归生长**（参考3）：从种子行向下交替生长，仅在"活跃-背景-活跃"三元组中繁殖。
4. **邻域标签传递**（参考4）：标记像素通过邻接关系为中性区域染色。
5. **运动外推**（参考5）：从帧序列中推断运动规律并预测下一帧。
6. **形状频率分类**（参考6）：按旋转不变的形状频率将对象排序到网格顶部或底部。
7. **射线反射**（参考7）：对角线射线遇到红色镜面反射，非红色障碍物被穿透覆盖。
8. **递归分形铺设**（参考8）：种子掩码的分形自相似展开。
9. **距离场着色**（参考9）：以标记点为中心，用循环调色板按曼哈顿距离填充。
10. **模板印章+颜色图例**（参考10）：通过图例重新着色精灵并印到框架内。
11. **像素级自掩码展开**（参考11）：每个像素扩展为整个网格的同色掩码。
12. **奇异元素提取**（参考12）：每行格子中找出唯一不同的单元格。
13. **对称臂补全/清除**（参考13）：根据已有方向臂推断旋转补全，完成后清除。
14. **双轨道旋转**（参考14）：3x3环的角和边中心按相反方向旋转。
15. **边缘相对图案迁移**（参考15）：将标记图案按边缘相对距离迁移到素色矩形。
16. **切换射线**（参考16）：顶行控制像素向下发射切换射线，同色翻转异色覆盖。
17. **面板间掩码交换**（参考17）：两个面板交换图案掩码并用对方底色重新着色。
18. **剪切变换**（参考18）：逐行偏移实现平行四边形剪切。
19. **走廊路径追踪**（参考19）：沿走廊延伸，遇阻转弯直到离开网格。
20. **交叉条编织**（参考20）：根据标记位置确定编织矩形的列跨度和颜色切换。

### 非显而易见的串联方式

- **编码方式的非直觉性**：信息可以编码在对象的数量、间距、相对位置、连通性、甚至缺失中。例如，对象之间的间距编码了变换参数；某区域的空白本身就是指令。
- **操作链的意外组合**：一个操作的几何结果可以成为另一个操作的拓扑条件。例如，距离场的等值线可以成为反射路径的镜面；形状频率可以决定填充颜色。
- **条件触发机制**：某个局部特征决定全局变换的模式选择，而非参数选择。例如，对象的朝向不仅决定移动方向，还决定整个变换的类型。
- **隐式坐标系**：对象本身定义了非标准坐标系（如极坐标、沿路径的弧长坐标），变换在该坐标系下才是简单的。
- **缺失即信息**：某些谜题的关键在于发现"什么不在那里"——缺口、空白、唯一缺失的颜色或唯一不存在的对称性，反而是触发变换的核心信号。
- **自参照结构**：对象的某个属性（如面积、周长、颜色数量）反过来控制对该对象施加的变换参数，形成自参照循环。

## 第二步：全新 ARC 谜题描述

<new_puzzle>
description:
识别网格中由灰色线条围成的若干封闭区域，根据每个区域内部缺失的颜色（相比于全局颜色集合）来决定该区域的填充色。

Input structure:
- 背景为 black。
- 网格中有由 grey 像素绘制的一像素宽线条网络，将网格分割为若干互不连通的封闭区域。封闭区域外部（与网格边界相通的部分）保持 black 不变。
- 全局恰好使用了 4 种非 black、非 grey 的前景色（例如 red、blue、green、yellow），每个封闭区域内部散布着其中恰好 3 种颜色的像素点（每种颜色至少出现 1 个像素），缺少第 4 种中的某一种。
- 不同封闭区域缺失的颜色可能不同。

Rule:
- 确定全局 4 种前景色集合。
- 对每个封闭区域，找出该区域内部缺失的那一种前景色（4 种中唯一未出现的颜色）。
- 将该封闭区域内所有 black 背景像素填充为缺失的那种颜色。
- 区域内原有的 3 种颜色像素保持不变。
- grey 线条保持不变。
- 封闭区域外部的 black 背景保持不变。

Key insight:
解题者需要先识别全局颜色集合，然后逆向思考——每个区域"拥有什么"不重要，"缺少什么"才是答案。这是一种基于缺失信息的推理，需要跨区域对比才能发现规律。
</new_puzzle>

<new_puzzle>
description:
网格中的每个彩色对象根据自身像素面积决定旋转角度：面积为 1 时不旋转，面积为 2 时顺时针旋转 90 度，面积为 3 时旋转 180 度，面积为 4 时逆时针旋转 90 度（即面积 mod 4 决定旋转档位）。旋转以对象的包围盒中心为锚点。

Input structure:
- 背景为 black。
- 网格中散布着若干小型单色连通对象（4-连通），每个对象不超过 5x5 像素。
- 每个对象使用不同的颜色（red、blue、green、yellow、orange、magenta 等）。
- 对象之间间距足够大，旋转后的包围盒不会与其他对象重叠。

Rule:
- 对每个对象，计算其非背景像素的数量 n。
- 计算旋转档位 r = n mod 4：r=0 不旋转，r=1 顺时针旋转 90 度，r=2 旋转 180 度，r=3 逆时针旋转 90 度。
- 旋转以对象包围盒的中心为锚点（若包围盒的宽或高为偶数，中心取左上偏移）进行。
- 旋转后的对象绘制在以原包围盒中心为新包围盒中心的位置上。原位置的对象像素先清除为 black，再绘制旋转后的结果。
- 若旋转后部分像素超出网格边界，截断到边界处。

Key insight:
对象的面积同时扮演了两个角色：它既是对象的固有属性，也是变换指令的编码。解题者需要发现不同对象发生了不同的旋转，然后推断出面积与旋转角度之间的 mod 4 对应关系。由于面积差异不大（多数在 1-8 之间），旋转结果是周期性的，增加了归纳难度。
</new_puzzle>

<new_puzzle>
description:
在网格中，每个"信号源"像素沿四个正方向发出射线，射线遇到"棱镜"对象时发生颜色转换并继续传播，最终形成彩色射线网络。

Input structure:
- 背景为 black。
- 网格中有若干孤立的单像素"信号源"，颜色为 red。
- 网格中还有若干由 2x1 或 1x2 的小矩形构成的"棱镜"对象，每个棱镜由两种不同颜色的像素组成（左/上像素一种颜色，右/下像素另一种颜色）。棱镜的两种颜色都不是 black 或 red。
- 棱镜按方向分为水平棱镜（2x1，左右排列）和垂直棱镜（1x2，上下排列）。

Rule:
- 每个 red 信号源同时向上、下、左、右四个方向发射 red 射线，逐像素延伸。
- 射线碰到网格边界则停止。
- 射线碰到棱镜的入射面时：射线不覆盖棱镜像素；射线颜色转换为棱镜出射面的颜色（入射面是射线方向上先碰到的那个像素，出射面是另一个像素），然后射线以新颜色从棱镜出射面的另一侧继续沿相同方向传播。
- 射线碰到另一条已有射线的像素时，若颜色相同则继续延伸（合并），若颜色不同则停止。
- 信号源本身保持 red。

Key insight:
解题者需要理解棱镜的方向性——同一个棱镜从不同方向被射线击中会产生不同的颜色转换效果，因为"入射面"和"出射面"互换了。棱镜不是简单的颜色替换器，而是方向相关的颜色转换器。此外，多个信号源的射线可能通过棱镜链形成复杂的颜色传播网络。
</new_puzzle>

<new_puzzle>
description:
网格中的彩色条带充当"尺子"，每条尺子的长度指定了与其垂直方向上另一个对象应被复制的次数；复制品沿尺子方向等间距排列。

Input structure:
- 背景为 black。
- 网格中有若干"尺子"：每条尺子是一条水平或垂直的单色直线段（厚度为1像素，长度至少为2），颜色可以是 blue、green、yellow 等。
- 每条尺子的一端（首像素或末像素）的正交方向（水平尺子的正上方或正下方，垂直尺子的正左方或正右方）紧邻着一个小型彩色"种子"对象（与尺子颜色不同，由另一种颜色构成的连通图案，不超过 3x3）。种子对象与尺子端点之间恰好间隔 1 个 black 像素。
- 每条尺子与其种子之间颜色不同，且不同尺子-种子对之间互不干扰。

Rule:
- 对每条尺子，测量其长度 L（像素数）。
- 找到与该尺子关联的种子对象。
- 沿尺子的方向（从种子所在端向另一端），以种子在尺子正交方向上的位置为基准，每隔尺子长度 / (L-1) ... 不，规则更简单：沿尺子方向，从种子对齐的位置开始，在尺子的每一个像素位置处各放置一份种子的副本。即种子被复制 L 次，每份副本的正交位置与原始种子相同，沿尺子方向依次偏移 1 像素对齐到尺子的每个像素位置。
- 副本使用种子的原始颜色。
- 原始尺子被保留。
- 原始种子被保留。

Key insight:
尺子看起来只是简单的线段装饰，但其长度精确地控制了种子的复制次数。解题者需要建立"长度 = 复制数"的对应关系，并发现副本排列的方向由尺子的朝向决定、排列的间距由尺子像素位置决定。这是一种"元数据编码在几何属性中"的模式。
</new_puzzle>

<new_puzzle>
description:
网格分为上下两个面板：上面板包含若干彩色图案作为"词汇表"，下面板包含由这些图案的重叠组合构成的复合图像。输出仅保留复合图像中恰好被奇数个词汇图案覆盖的像素。

Input structure:
- 背景为 black。
- 一条水平的 grey 分割线将网格分为上下两部分。
- 上面板（"词汇表"）包含若干互不重叠的小型彩色图案（每个图案为单一颜色的连通区域，颜色各不相同，如 red、blue、green、yellow 等），每个图案不超过 5x5 像素。
- 下面板包含一个复合图像区域，大小固定。复合图像中的彩色像素来自上面板词汇图案的叠加：每个词汇图案在下面板中被平移到某个位置，多个图案可能重叠。
- 在重叠处，像素颜色为 grey（特殊标记色，表示此处有多层覆盖）。非重叠处保留原图案颜色。

- 输出网格仅包含下面板部分（去掉上面板和分割线），大小等于下面板。
- 在输出中，保留下面板中所有非 grey 的彩色像素（即只被一个图案覆盖的位置），颜色不变。
- 将下面板中所有 grey 像素（重叠位置）替换为 black（即擦除重叠区域）。
- 其余 black 背景保持不变。

Key insight:
解题者最初可能试图逐个识别和分离叠加的图案，但真正的规则远比"解构叠加"简单：只需区分 grey（重叠）和非 grey（唯一覆盖）像素。grey 不是需要还原的谜题，而是需要擦除的标记。词汇表面板是干扰项——它帮助人类理解场景，但规则本身不需要引用它。
</new_puzzle>

<new_puzzle>
description:
网格中有若干形状相同但颜色不同的对象，以及一条由箭头状标记构成的"颜色转换链"。按照链的顺序，将每个对象的颜色替换为链中该颜色的下一个颜色。

Input structure:
- 背景为 black。
- 网格底部有一行"颜色链"标记：由若干 2x1 的水平色块紧密排列构成，每个色块是纯色的，相邻色块颜色不同。链从左到右排列，例如 red-red | blue-blue | green-green | yellow-yellow，表示颜色转换顺序为 red → blue → green → yellow → red（首尾循环）。
- 网格上方散布着若干单色连通对象（4-连通），形状各异，每个对象的颜色恰好是颜色链中出现的某种颜色。
- 多个对象可以共享同一颜色。

Rule:
- 读取底部颜色链，确定颜色的循环顺序：链中第 i 个色块的颜色 c_i 应被替换为第 (i+1) 个色块的颜色 c_{i+1}；最后一个色块的颜色映射回第一个色块的颜色。
- 对网格上方每个彩色对象，将其所有像素颜色替换为链中的下一个颜色。
- 颜色链标记本身保持不变。
- 背景保持不变。

Key insight:
解题者需要发现底部排列的色块不是装饰，而是一条"颜色转换指令链"。链的阅读顺序（从左到右）定义了循环映射关系。关键难点在于：(1) 识别底部色块构成一个有序链；(2) 理解链定义的是循环替换关系而非简单配对；(3) 将链中的映射应用到上方所有匹配颜色的对象上。
</new_puzzle>

<new_puzzle>
description:
网格中有一个大型"容器"轮廓和若干外部"碎片"对象。每个碎片在容器内壁上有一个颜色匹配的锚点标记，碎片应以锚点为定位基准"嵌入"容器内壁，嵌入方向为从锚点指向容器内部。

Input structure:
- 背景为 black。
- 网格中有一个由 grey 像素绘制的大型封闭矩形轮廓（一像素宽），构成"容器"。容器内部为 black 背景。
- 容器轮廓的内壁上（紧贴轮廓内侧的像素位置）有若干单像素的彩色"锚点"标记，每种颜色只出现一次。锚点颜色包括 red、blue、green、yellow 等。
- 容器外部散布着若干小型彩色连通对象（"碎片"），每个碎片为单一颜色，且颜色与某个锚点颜色一一对应。每个碎片不超过 4x4 像素。

Rule:
- 对每个碎片，找到颜色匹配的锚点。
- 确定锚点所在的容器边（上边、下边、左边、右边）。
- 将碎片旋转使其"朝向"容器内部：碎片在外部时有一个默认朝向（不旋转），嵌入时需要根据锚点所在边进行旋转——上边锚点旋转 180 度，下边不旋转，左边顺时针旋转 90 度，右边逆时针旋转 90 度。（约定碎片原始朝向为"向上"，旋转使其开口/延伸方向指向容器内部。）
- 将旋转后的碎片放置在容器内部，使碎片的顶部中心像素与锚点在容器内侧的相邻位置对齐。
- 碎片使用原始颜色绘制。
- 清除碎片在容器外部的原始位置（置为 black）。
- 锚点标记被碎片覆盖或保留为碎片颜色（若碎片覆盖了锚点位置）。
- grey 容器轮廓保持不变。

Key insight:
解题者需要同时解决三个子问题：(1) 通过颜色匹配建立碎片-锚点配对；(2) 根据锚点在容器哪条边上来决定碎片的旋转角度；(3) 理解碎片被"吸附"到容器内壁的定位规则。锚点位置不仅编码了"放哪里"，还隐含了"怎么转"——这是容器边缘方向与旋转角度之间的隐式对应。
</new_puzzle>
