## 第一步：基础操作分析与非显而易见的串联方式

### 参考题中涉及的基础操作梳理

1. **颜色重映射/编码**：通过数量→颜色的固定映射（参考1）、扫描序→循环着色（参考20）、方位→颜色（参考16）。
2. **区域分割与二部着色**：墙壁分割区域后交替上色（参考2）。
3. **空间位移/平移**：由路径端点编码的净位移向量（参考3）、向下重力落体（参考15）、推向边缘（参考19）。
4. **周期/时序外推**：多帧序列中推断下一帧的动态颜色位置（参考14）。
5. **模板填充/图例应用**：固定位置色表覆盖缺失位置（参考5）、图例色块映射拼图片（参考12）。
6. **形态学操作**：膨胀取交集产生通道（参考11）、稀疏→稠密化（参考8）。
7. **镜像/反射**：沿轴线镜像最小色群（参考18）。
8. **物体分类与差异化处理**：按面积区分静止/运动（参考15）、按种群大小决定颜色分配（参考16）。
9. **切割与滑移**：控制射线切割精灵并将碎片推向角落（参考17）。
10. **嵌套构建**：条纹高度→方形嵌套框架（参考9）。

### 非显而易见的串联思路

- **拓扑属性作为隐式选择器**：不是直接看颜色或大小，而是通过对象的连通性、包围关系、孔洞数量来决定操作方式。例如，有孔的对象执行一种变换，无孔的执行另一种。
- **边界接触模式编码操作指令**：对象接触网格边缘的方式（哪条边、接触多少格）可以编码平移方向和距离——与参考3中路径端点编码位移不同，这里是接触模式本身即指令。
- **对象间的相对拓扑关系决定输出结构**：不是单独处理每个对象，而是根据对象之间的"包含"、"相邻"、"对齐"等空间关系来决定如何合并或拆分。
- **计数结果反馈为几何属性**：某区域内对象的数量决定输出中某形状的尺寸或重复次数——数量→尺寸的反馈回路。
- **颜色出现顺序（非空间位置）作为隐藏排列键**：在网格中按某种扫描顺序首次出现的颜色序列决定了输出中元素的排列。

<description>
根据每个封闭区域内部包含的孤立标记点数量，用对应数量级的颜色填充该区域。

Input structure
- 背景为 black。
- 一种前景色（如 blue）形成若干闭合的一像素宽矩形边框，边框之间互不重叠、不相邻。
- 每个矩形边框的内部区域（不含边框本身）中散布着若干 red 的孤立单像素标记点（互不相邻）。
- 部分矩形内部可能没有标记点。

Rule
- 保持所有 blue 边框和 black 背景不变。
- 统计每个矩形边框内部 red 标记点的数量 n。
- 根据 n 的值将该矩形内部所有非边框像素（包括原有的 red 标记点位置和 black 空位）统一重新着色：
  n=0 → 内部保持 black；n=1 → green；n=2 → yellow；n=3 → orange；n=4 → magenta；n>=5 → maroon。
- red 标记点在输出中被覆盖为对应的填充色，不再保留。

Key insight
- 标记点本身不重要作为空间位置——它们的数量才是关键，数量通过固定映射决定了整个封闭区域的填充色。解题者需要先意识到"计数"是核心操作，而非标记点的位置模式。
</description>
</new_puzzle>

<new_puzzle>
<description>
将网格中的每个彩色对象沿其最长内部对称轴折叠，保留折叠后重叠的像素并移除不重叠的像素。

Input structure
- 背景为 black。
- 网格中有若干个由同一种非背景色（如 green）构成的 4-连通对象，彼此不相邻。
- 每个对象近似对称但有少量缺陷像素——即沿某条对称轴折叠后，大部分像素重合，少部分仅出现在一侧。
- 每个对象恰好存在一条最优对称轴（水平、垂直、或45度对角线），使得重合像素数量最多。

Rule
- 对每个对象，找到使折叠后重合像素最多的轴（水平、垂直、主对角线、反对角线四选一）。
- 沿该轴将对象折叠：将轴一侧的像素镜像映射到另一侧。
- 输出中仅保留折叠后两侧都有像素的位置（即交集），将其着色为 red。
- 仅在一侧存在的缺陷像素在输出中变为 black（消失）。
- 折叠方向统一：水平轴向上折叠、垂直轴向左折叠、对角线轴向左上折叠。输出对象的位置为折叠目标侧的位置。

Key insight
- 解题者需要发现每个对象都"几乎对称"，核心操作是找到最佳对称轴，然后通过折叠的交集运算去除不对称的杂质像素。颜色变化（green→red）提示发生了变换而非简单保留。
</description>
</new_puzzle>

<new_puzzle>
<description>
每个小型彩色精灵（sprite）充当"印章"，在其对应的同色大矩形区域内按精灵自身形状进行周期性平铺填充。

Input structure
- 背景为 black。
- 网格中有若干个不同颜色的大矩形区域（实心填充），每个矩形是一种独特的非背景色，如 blue、red、green 等。矩形之间互不接触。
- 在大矩形之外，每种颜色还各有一个由同色像素构成的小型自由形状精灵（面积远小于其对应矩形）。小精灵的包围盒不超过 5x5。
- 每个小精灵通过颜色唯一对应一个大矩形。

Rule
- 对每种颜色，取其小精灵的形状作为平铺模板（以精灵的包围盒为平铺单元）。
- 将大矩形的内部区域用该平铺模板周期性铺满：从矩形左上角开始，将精灵包围盒逐行逐列无间隔排列。
- 精灵包围盒内有像素的位置保持该颜色，无像素的位置变为 black。
- 若矩形边界处平铺单元被截断，则仅显示落在矩形内的部分。
- 小精灵本身在输出中被清除为 black。

Key insight
- 关键发现是颜色匹配：每个小精灵与同色大矩形配对。精灵不是"放入"矩形，而是作为平铺纹理的母版反复印刷，将实心矩形变为镂空图案。
</description>
</new_puzzle>

<new_puzzle>
<description>
根据每个对象与网格四条边缘的最近距离排序，然后按排序结果将对象重新排列到网格对角线上。

Input structure
- 背景为 black。
- 网格中有 3 到 6 个不同颜色的小型对象（每个对象为 1x1 到 3x3 的紧凑形状），分散放置在网格各处。
- 每个对象颜色各不相同。
- 网格为正方形（边长在 10 到 20 之间）。

Rule
- 计算每个对象的包围盒中心到网格四条边缘的最小距离（曼哈顿距离），取四个距离中的最小值作为该对象的"边缘距离"。
- 将所有对象按"边缘距离"从小到大排序（距离相同时按对象颜色在调色板中的顺序：blue < red < green < yellow < grey < magenta < orange < azure < maroon）。
- 清空网格为 black。
- 将排序后的对象依次放置在主对角线上：第一个对象的包围盒左上角放在 (0,0)，第二个紧接在第一个之后的对角线位置（行列各偏移前一个对象的包围盒大小+1 格间距），依此类推。
- 对象形状保持不变，只是位置改变。

Key insight
- 解题者需要发现输出中对象排列在对角线上的顺序不是按颜色或大小，而是按"离边缘多近"排序。越靠近网格边缘的对象越先出现在对角线起始端。这种空间属性作为排序键是不直觉的。
</description>
</new_puzzle>

<description>
将网格中"桥接"两个同色区域的中间色条替换为被桥接颜色，同时将桥接色条原本连接的两个同色区域合并。

Input structure
- 背景为 black。
- 网格中有若干个大的单色 4-连通区域，使用 2-3 种不同的前景色（如 blue、red、green）。
- 某些不同颜色的区域之间存在一条由第三种颜色构成的窄色条（宽度为 1 像素，长度 2-5 像素），该色条的两端分别 4-连通地接触两个颜色相同的区域。
- 也存在一些色条连接两个不同颜色的区域，或只有一端接触某区域。

Rule
- 找出所有"桥接色条"：一条由非背景色 C 构成的 1 像素宽直线段（水平或垂直），其两端恰好各 4-连通接触一个颜色相同（设为颜色 A）且 A ≠ C 的区域。
- 将此类桥接色条的颜色从 C 改为 A，使两个被桥接的 A 色区域通过色条连为一体。
- 不满足"两端接触同色区域"条件的色条保持原样不变。
- 背景和所有大区域像素保持不变。

Key insight
- 解题者必须发现关键条件不是色条本身的颜色或形状，而是色条两端接触的区域是否"同色"。只有当色条充当两个同色区域之间的桥梁时，它才被重新着色以完成合并。连接异色区域的色条被忽略——这迫使解题者检查每条色条的两端邻接关系而非仅看色条自身属性。
</description>
</new_puzzle>

<description>
将每个对象内部的连通"空腔"形状提取出来，按空腔面积从大到小排列在网格底部。

Input structure
- 背景为 black。
- 网格中有 2-4 个由不同颜色构成的大型 4-连通对象，每个对象内部包含一个或多个由 black 像素构成的封闭空腔（即被对象颜色完全包围的 black 连通区域，不与网格外部的 black 背景相连）。
- 每个空腔形状各异，面积在 2-8 像素之间。
- 对象之间互不接触，位于网格上半部分。

Rule
- 识别所有对象内部的封闭空腔（不与外部背景连通的 black 区域）。
- 提取每个空腔的形状（以其包围盒内的相对坐标表示）。
- 将每个空腔用其所属对象的颜色着色（原本是 black 的空腔像素变为该对象的颜色）。
- 清空网格为 black。
- 将所有提取的空腔形状按面积从大到小、从左到右排列在网格最底部一行对齐（每个空腔包围盒的底边与网格底边对齐），相邻空腔之间间隔 1 列。
- 若两个空腔面积相同，则按其所属对象颜色在调色板中的顺序排列（blue < red < green < yellow < grey < magenta < orange < azure < maroon）。

Key insight
- 解题者需要经历一个认知反转：输出中显示的形状不是输入中可见的对象本身，而是对象内部"看不见的"空洞形状。对象的颜色被转移给了空腔，而对象本身完全消失。这种"负空间提取"是核心洞见。
</description>
</new_puzzle>

<new_puzzle>
<description>
每个彩色线段按其长度决定旋转角度，然后绕自身中心旋转后重新绘制。

Input structure
- 背景为 black。
- 网格中有若干条由不同颜色构成的直线段（水平或垂直），每条线段颜色唯一，长度在 2-4 像素之间。
- 线段之间互不接触，且距离网格边缘足够远以容纳旋转后的结果。
- 网格尺寸为 15x15 到 25x25。

Rule
- 对每条线段，计算其长度 L。
- 根据长度决定顺时针旋转角度：L=2 → 旋转 90°；L=3 → 旋转 180°；L=4 → 旋转 270°。
- 旋转以线段的几何中心为轴心：对偶数长度线段，中心在两个中间像素之间；对奇数长度线段，中心在正中间像素上。
- 水平线段旋转 90° 或 270° 后变为垂直线段，反之亦然。旋转 180° 的线段保持方向不变但像素顺序翻转（视觉上对于纯色线段等效于不动，但其中心位置可能微调——实际上 180° 旋转后位置完全不变）。
- 将旋转后的线段绘制在输出网格中，原位置清除为 black。

Key insight
- 解题者需要将线段长度这一几何属性与旋转角度这一变换参数关联起来。长度为 2 的短线段旋转 90° 最容易观察（水平变垂直），而长度为 3 的线段旋转 180° 看似不变但实际上规则一致。关键是发现"长度编码旋转量"的映射关系。
</description>
</new_puzzle>

<new_puzzle>
<description>
在两个颜色不同的对象之间画一条最短路径，路径颜色由两个对象颜色的"混合规则"决定。

Input structure
- 背景为 black。
- 网格中恰好有两个不同颜色的单色 4-连通对象（如一个 blue 对象和一个 yellow 对象），形状不规则，面积在 3-10 像素之间。
- 两个对象不相邻，之间有 black 间隔。
- 网格中还有若干 grey 像素构成的障碍物块，路径不能穿过障碍物。

Rule
- 找到两个对象之间的 4-连通最短路径（仅经过 black 像素，不穿过 grey 障碍物和任何对象像素）。路径连接两个对象边界上距离最近的一对像素。
- 路径颜色由两个对象的颜色通过以下固定混合规则决定：
  blue + yellow → green；blue + red → magenta；red + yellow → orange；blue + green → azure；red + green → maroon。
- 将最短路径的所有 black 像素重新着色为混合色。
- 若最短路径不唯一，选择字典序最小的路径（优先向上 > 向左 > 向下 > 向右）。
- 所有其他像素保持不变。

Key insight
- 解题者先看到两个对象之间出现了一条新颜色的线，需要发现该颜色既不是对象 A 也不是对象 B 的颜色，而是两者的"混合"。核心认知路径是：先识别路径是最短连接，再发现颜色来自一个颜色配对表。
</description>
</new_puzzle>
