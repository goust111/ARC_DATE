## 第一步：分析与思考

### 参考题目中的基础操作归纳

通过对 20 道参考题的深入分析，可以提取出以下基础操作类别：

1. **空间变换类**：平移（题4、14）、旋转/翻转（题18的颜色循环）、缩放/归一化（题6）
2. **层叠与遮挡推理**：从部分可见推断完整对象及其前后关系（题1）
3. **模板匹配与配对**：形状匹配（题19）、颜色匹配（题20）、查表（题16）
4. **属性编码**：颜色编码运动方向（题14）、Chebyshev 距离编码调色盘（题8）、对称性编码颜色（题11）
5. **聚合/统计**：计数生成直方图（题17）、面积排序生成嵌套环（题13）
6. **空间打包/布局**：行压缩（题5）、嵌套排列（题10）、紧凑排列（题20）
7. **投影/扩展**：条纹模式全画布投影（题12）
8. **标记驱动的定向操作**：标记像素指定目标（题7）、角标指示方向（题4）、门控走廊（题2）
9. **对称性修复**：利用对称轴补全缺失（题15）
10. **模版冲压/雕刻**：印章叠加（题6、9）、镂空雕刻（题20）

### 非显而易见的串联方式思考

- **拓扑属性→分类→差异化变换**：对象的拓扑特征（如孔洞数、连通分量数、欧拉数）是人眼可见但容易被忽视的属性。可以将拓扑属性作为分类键，驱动不同类别对象接受不同变换——这与题11用对称性分类类似，但从几何对称切换到拓扑结构，认知路径完全不同。

- **方向编码于形状缺口**：一个微小图案（如 L 形缺角）可以编码方向信息。与题4中"角标指示平移方向"不同，此处方向信息不是驱动运动而是驱动"接收/选择"——相当于定向天线，只有特定方向来的信号才被捕获。

- **路径行走产生序数→排序键**：沿对象轮廓行走（如顺时针遍历矩形边框），行走过程中某个特征的出现位置产生一个序数。这个序数是一个隐蔽的排序键，因为它不能通过静态观察直接获得，必须"走一遍"才能计算。

- **配对+路径+叠加混合**：散布的同色像素对暗示配对关系；配对后连线产生路径；路径交叉处产生混合色——三步因果链，每一步都需要独立发现。

- **距离递增作为参数**：路径上的位置（距起点的步数）不仅定义"在哪填"，还递增地定义"填多宽"，形成扇形扩散效果。这与简单的均匀粗化路径不同。

- **采样探针从邻域色带读取信息**：一个标记像素本身不携带颜色信息，而是像探针一样从最近的"色源"（行带或列带）读取颜色。这种"间接颜色获取"机制在参考题中未出现。

- **计数器→操作次数**：区域内的散布点数量不是要移动或保留的对象，而是一个"控制变量"，决定对该区域施加某种操作的重复次数（如收缩填充层数）。

- **象限→变换类型映射**：对象在全局坐标系中的位置（象限）不决定去哪，而是决定"怎么变"（用哪种翻转轴）。位置编码变换类型而非变换目标。

<description>
根据每个封闭区域内部独立"孤岛"像素的数量，用对应数量的同心收缩层填充该区域。

Input structure:
- 背景为黑色（black）。
- 网格中有若干用同一种颜色（如 blue）绘制的闭合环形轮廓，每个轮廓围成一个封闭区域。闭合轮廓的宽度恒为一个像素，形状不规则但保证 4-连通闭合。不同轮廓互不接触，也不嵌套（即没有轮廓在另一个轮廓内部）。
- 每个封闭区域内部散布着若干孤立的红色（red）像素，这些红色像素彼此不 4-连通，且不与蓝色轮廓 4-连通。
- 不同封闭区域内的红色像素数量不同（范围为 1 到 5）。

Rule:
- 对每个封闭区域，计数其内部红色孤岛像素的数量 N。
- 移除所有红色像素（变为黑色背景）。
- 从该封闭区域的内部边界开始（即紧邻蓝色轮廓内侧的黑色像素），向内逐层收缩（每层为当前未填充区域的 4-连通外边界像素），依次用绿色（green）、黄色（yellow）、橙色（orange）、品红色（magenta）、灰色（grey）的固定顺序填充恰好 N 层。第 1 层用绿色，第 2 层用黄色，以此类推。
- 若区域内部空间不足 N 层，则在耗尽可填充空间后停止。
- 蓝色轮廓本身保持不变。轮廓外部的黑色背景保持不变。

Key insight:
- 红色孤岛像素不是装饰也不是要移动的对象；它们的数量是一个计数器，编码了该区域应被多少层同心收缩环填充。解题者必须先意识到"数红点"，再将数量映射为由外而内的填充层数。红点的空间位置无关紧要，仅其数量有意义。
</description>

<description>
将网格中每个彩色对象沿特定轴做镜像翻转，翻转轴的选择由对象质心相对于网格中心的象限决定。

Input structure:
- 背景为黑色（black）。
- 网格大小为 21×21（奇数边长，网格中心为第 10 行第 10 列，从 0 起计数）。
- 网格中有 4 个互不接触的单色 4-连通对象，分别使用 red、green、blue、yellow 四种颜色，每种颜色恰好一个对象。
- 每个对象的像素数量在 5-12 之间，形状不规则且不具有任何对称性。
- 四个对象分别位于网格的四个象限中（以网格中心为分界，每个象限恰好一个对象，对象的所有像素都严格在该象限内部，不跨越中心行或中心列）。

Rule:
- 对每个对象，根据其所在象限决定翻转方式：
  - 左上象限的对象：沿其自身 bounding box 的水平中线做上下翻转（垂直镜像）。
  - 右上象限的对象：沿其自身 bounding box 的垂直中线做左右翻转（水平镜像）。
  - 左下象限的对象：沿其自身 bounding box 的主对角线（左上→右下方向）做转置翻转。
  - 右下象限的对象：沿其自身 bounding box 的副对角线（右上→左下方向）做反转置翻转。
- 翻转在对象自身 bounding box 内原地进行：bounding box 的左上角位置不变，翻转后的像素仍然落在相同大小的 bounding box 内（对角线翻转时 bounding box 的行列尺寸可能互换，但左上角坐标不变）。
- 翻转后颜色不变。

Key insight:
- 对象的全局位置（在哪个象限）编码了一个隐含的变换类型选择。解题者需要从样例中发现：并非所有对象做相同的翻转，也不是颜色决定翻转方式——是位置决定的。四个象限对应四种不同的镜像轴，这要求解题者逐象限对比输入输出才能拆解出规则。
</description>
</new_puzzle>

<new_puzzle>
<description>
识别网格中由分隔线分出的若干面板，在每个面板内找到唯一的"种子路径"，然后沿路径方向逐步生长出宽度递增的带状填充。

Input structure:
- 背景为黑色（black）。
- 网格被灰色（grey）的单像素宽水平分隔线分为若干等高的矩形面板（如 3 到 4 个面板纵向排列）。每个面板高度至少 8 行，宽度等于整个网格的宽度（约 15-20 列）。
- 每个面板内有一条用蓝色（blue）像素绘制的简单路径（无分支、无环，由 4-连通像素组成）。路径从面板的左边缘某一行开始（起点在最左列），水平向右延伸，可能有上下弯折但整体从左往右推进，终点在面板内部而非右边缘。路径长度至少 4 个像素。
- 路径的起点（最左端）处有一个红色（red）像素标记代替蓝色，指示"生长从这里开始"。

Rule:
- 对每个面板，从红色标记开始沿蓝色路径依次行进（红色为第 0 步，之后每个蓝色像素步数递增）。
- 路径上第 k 步的像素（k=0,1,2,...）向路径行进方向的垂直方向两侧各扩展 k 个像素。也就是说：起点处（k=0）不扩展（宽度 1），第 1 步扩展 1 格（宽度 3），第 2 步扩展 2 格（宽度 5），以此类推。
- 对于水平行走的路径段，垂直方向是上下；对于垂直行走的路径段，垂直方向是左右。
- 扩展使用绿色（green）。原始蓝色路径像素保持蓝色。红色标记在输出中变为蓝色。
- 扩展若超出面板边界（碰到灰色分隔线或网格边缘），则截断。
- 灰色分隔线和未被填充的黑色背景保持不变。

Key insight:
- 路径不仅定义了填充的骨架位置，还通过"距起点的步数"递增地定义每个骨架点处的扩展宽度，形成从窄到宽的锥形/扇形扩散。解题者需要发现这个"距离=宽度"的递增规则，而非均匀的固定宽度填充。红色标记是方向锚点，指出从哪端计数。
</description>
</new_puzzle>

根据矩形边框上"品红缺口"沿顺时针遍历的位置偏移量，对矩形进行排序并紧凑排列输出。

Input structure:
- 背景为黑色（black）。
- 网格中散布着 3 到 5 个互不接触的矩形框。每个矩形框由单像素宽的彩色边框构成（每个矩形使用不同的边框颜色，选自 red、blue、green、yellow、orange），内部为黑色。
- 矩形尺寸各异（边长范围 4-8 像素），且每个矩形的边框上恰好有一段连续的品红色（magenta）像素替换了原边框颜色，形成"品红缺口"。缺口长度为 2-4 像素，位于矩形某一条边上。
- 矩形在网格中的空间位置是随机的。

Rule:
- 对每个矩形，从其左上角像素开始，沿顺时针方向遍历整个边框像素序列（上边从左到右→右边从上到下→下边从右到左→左边从下到上）。记录品红缺口第一个像素在此序列中的位置索引 P（从 0 开始计数）。
- 按 P 值从小到大对所有矩形排序。
- 输出网格中，将排序后的矩形从左到右紧凑排列：第一个矩形的左上角在 (0,0)，相邻矩形之间有 1 列黑色间隔，所有矩形顶部对齐（上边缘在第 0 行）。输出网格的高度为最大矩形的高度，宽度为所有矩形宽度之和加上间隔列数。
- 矩形的边框（包括品红缺口部分）和黑色内部保持不变地复制到输出中。

Key insight:
- 排序键不是矩形的大小、颜色、位置或面积——这些都是干扰因素。真正的排序键是品红缺口在顺时针遍历序列中的起始位置索引。解题者必须构思出"沿边框顺时针走一圈"的操作，才能理解为什么某些矩形排在前面（缺口在上边靠左=索引小）而某些排在后面（缺口在左边靠上=索引大，因为是遍历的最后一条边）。

<description>
将每对同色像素用 L 形路径连接，路径交叉处按固定混色规则生成新颜色。

Input structure:
- 背景为黑色（black）。
- 网格大小约 12×12 到 18×18。
- 网格中散布 6 个非背景像素，恰好使用三种颜色：red、blue、yellow，每种颜色恰好出现 2 次。
- 每对同色像素既不同行也不同列。
- 6 个像素之间互不相邻。

Rule:
- 对每对同色像素 A(r1,c1) 和 B(r2,c2)（约定 A 是两者中行号较小的那个），绘制一条 L 形路径连接它们：从 A 出发先垂直移动到 B 的行（经过 r1 到 r2 之间的所有行，列不变为 c1），再水平移动到 B 的列（行不变为 r2，经过 c1 到 c2 之间的所有列）。路径上所有中间像素（不含 A 和 B 自身）着为该对的颜色。
- 若两条不同颜色的路径像素重叠在同一格子上，使用以下混色规则：
  - red + blue → magenta
  - red + yellow → orange
  - blue + yellow → green
  - red + blue + yellow（三色重叠）→ grey
- 源像素（原始 6 个点）保持其原色不变，不参与混色。
- 路径连线不覆盖源像素。

Key insight:
- 解题者需要依次发现三个独立的子规则：（1）每种颜色恰好两个像素构成配对；（2）连线方式是"先竖后横"的 L 形（而非先横后竖或其他路径），这需要从样例中对比归纳；（3）交叉点颜色不是某个路径的颜色覆盖另一个，而是两色混合生成第三种颜色。三重因果链使规则难以一次性发现。
</description>

<description>
网格中的 L 形"接收器"图案根据其缺角朝向有选择性地接收来自对角方向的信号塔广播，被激活的接收器变色。

Input structure:
- 背景为黑色（black）。
- 网格大小约 15×15 到 20×20。
- 网格中有若干橙色（orange）单像素，称为"信号塔"（2-4 个）。
- 网格中有若干"接收器"，每个接收器由三个蓝色（blue）像素组成 L 形，恰好占据 2×2 区域中的三个格子（留一个角为黑色背景）。缺角的位置定义接收器的"开口方向"：
  - 缺左上角 → 开口朝左上
  - 缺右上角 → 开口朝右上
  - 缺左下角 → 开口朝左下
  - 缺右下角 → 开口朝右下
- 接收器有 4-8 个，信号塔和接收器之间互不 4-连通。

Rule:
- 判断激活条件：对每个接收器，检查是否存在某个信号塔恰好位于该接收器开口方向的 45° 对角线上。具体地：
  - 若接收器开口朝左上，检查是否有信号塔在接收器缺角位置的左上对角线延长线上（即信号塔的行号 < 缺角行号且列号 < 缺角列号，且行差 = 列差）。
  - 若接收器开口朝右上，检查是否有信号塔在缺角位置的右上对角线上（行号 < 缺角行号且列号 > 缺角列号，且行差 = 列差）。
  - 若接收器开口朝左下，检查是否有信号塔在缺角位置的左下对角线上（行号 > 缺角行号且列号 < 缺角列号，且行差 = 列差）。
  - 若接收器开口朝右下，检查是否有信号塔在缺角位置的右下对角线上（行号 > 缺角行号且列号 > 缺角列号，且行差 = 列差）。
- 被激活的接收器：其三个蓝色像素全部变为绿色（green）。
- 未被激活的接收器保持蓝色不变。
- 信号塔（橙色像素）在输出中保持不变。背景保持黑色。

Key insight:
- 解题者需要同时推断两个非显然的机制：（1）L 形缺角不是随机残缺而是编码了方向信息——缺角方向就是"天线指向"；（2）激活条件是信号塔恰好在缺角方向的对角线上。仅观察形状变化（蓝→绿）不够，必须将空间方位关系（塔相对于接收器的对角线位置）与形状特征（缺角位置）联系起来。
</description>

<description>
根据每个同色前景对象的拓扑"孔洞数量"对其重新着色，并按孔洞数量排序后紧凑输出。

Input structure:
- 背景为黑色（black）。
- 网格中有 4 到 6 个互不接触的 4-连通前景对象，所有对象使用相同颜色红色（red）。
- 每个对象的 bounding box 不超过 7×7。
- 对象形状各异：有些是实心形状（无封闭孔洞），有些包含 1 个或 2 个甚至 3 个封闭孔洞。"封闭孔洞"定义为被红色像素完全 4-连通包围的黑色连通区域（不与网格边界相连的黑色 4-连通分量）。

Rule:
- 对每个红色对象，计数其封闭孔洞数量 H。
- 按 H 值对对象重新着色（红色像素变为新颜色，孔洞内部保持黑色不变）：
  - H=0 → blue
  - H=1 → green
  - H=2 → yellow
  - H=3 → orange
- 输出网格将重新着色后的对象按 H 值从小到大从左到右排列。H 值相同的对象按其在输入网格中的位置排序（先按行从上到下，再按列从左到右）。
- 每个对象以其 bounding box 裁剪后放置，对象间间隔 1 列黑色。所有对象底部对齐。输出网格高度为最大 bounding box 高度，宽度为所有 bounding box 宽度之和加间隔数。

Key insight:
- 输入中所有对象颜色相同（红色），但输出中颜色各异——颜色的分化依据不是对象的面积、位置或轮廓形状等几何属性，而是拓扑属性"孔洞数"。解题者需要"看穿"形状的外观差异，关注哪些对象内部有被完全包围的黑色区域。这类似人类识别手写数字时的直觉（"0"有 1 个孔，"8"有 2 个孔），但在 ARC 网格中需要更仔细地判断黑色区域是否真正被完全封闭。
</description>

<description>
灰色采样点从最近的行色带和列色带分别读取颜色，在采样点处绘制双色十字形。

Input structure:
- 背景为黑色（black）。
- 网格大小约 18×18 到 24×24。
- 网格中有 2-4 条完整的水平色带：每条色带是某一整行的所有像素被填充为同一颜色（颜色选自 red、blue、green、yellow，不同色带可使用相同或不同颜色）。
- 网格中有 2-4 条完整的垂直色带：每条色带是某一整列的所有像素被填充为同一颜色（颜色选自同上）。
- 水平色带和垂直色带不交叉——即没有任何一行既是水平色带又有垂直色带经过（水平色带所在行上不会有垂直色带的列）。注意：实际实现中，水平色带和垂直色带在交叉格可以共存，水平色带的颜色显示在该格上。
- 在非色带区域中，散布着 3-6 个灰色（grey）单像素作为采样点。每个采样点不在任何色带上。

Rule:
- 对每个灰色采样点 S 位于 (r, c)：
  - 找到距离 S 最近的水平色带（即找所有水平色带行号中与 r 距离最小的行），取该色带的颜色为 C_h。若两条水平色带距离相同则取上方那条。
  - 找到距离 S 最近的垂直色带（即找所有垂直色带列号中与 c 距离最小的列），取该色带的颜色为 C_v。若两条垂直色带距离相同则取左侧那条。
- 以 S 为中心绘制臂长为 2 的十字形（共 9 个像素：中心 1 个 + 上下左右各 2 个）：
  - 水平臂（S 左 1 格、左 2 格、右 1 格、右 2 格）使用颜色 C_h。
  - 垂直臂（S 上 1 格、上 2 格、下 1 格、下 2 格）使用颜色 C_v。
  - 中心像素使用 C_v。
- 十字形超出网格边界的部分截断不绘制。
- 若十字形某个像素落在已有色带上，则该像素保持色带原色不变（色带优先于十字形）。
- 灰色采样点自身被十字中心颜色覆盖。
- 所有色带在输出中保持不变。

Key insight:
- 采样点本身不携带颜色信息——它是一个"读取探针"，从空间上最近的行色带和列色带上分别采样颜色，然后将两种颜色分配给十字形的不同方向臂。解题者需要发现：（1）十字形的水平臂和垂直臂颜色不同，分别来自不同方向上的"色源"；（2）"色源"是距离最近的色带而非任意色带。这个间接的颜色获取机制是核心难点。
