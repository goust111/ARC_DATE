## 第一步：分析与思考

### 参考题中的基础操作提取

从20道参考题中，可以提取出以下基础操作类别：

1. **区域识别与填充**（题1、3）：洪泛填充、连通分量分析、封闭区域检测
2. **方向编码与移动**（题2、5、10、15、20）：框架颜色编码方向、标记物指示移动目标
3. **模板复制与变换**（题4、7、16、17、18）：裁剪模板、旋转/反射/平铺、对称推断
4. **属性解耦与重组**（题8）：独立属性（颜色、高度）的循环旋转
5. **排序与摘要**（题9、12、19）：按空间位置排序、按数量排序、层级排序
6. **替换与映射**（题6、13）：查找替换表、缺陷修补
7. **几何变形**（题14、15）：金字塔堆叠、剪切变形

### 非显而易见的串联思路

- **拓扑属性作为隐式编码**：一个区域的"孔洞数量"或"连通分量数"可以编码某种离散量，这个量又驱动另一个完全不同维度的操作（如颜色选择或重复次数）。这在题4中已有体现（组件计数→重复次数），但可以推广到更隐蔽的形式：例如形状的凹角数量编码旋转角度，或边界的弯折次数编码填充颜色。
- **路径属性作为变换参数**：题10中路径的脊柱由标记位置决定，但路径本身的几何属性（如长度、转弯次数）并未被利用为变换参数。可以设计"路径的拓扑属性决定终端状态"的谜题。
- **遮挡的逆向推理**：题7和题19都涉及遮挡，但遮挡的"模式"本身可以作为信息源——哪些部分被挡住、挡住的形状是什么，这些都可以编码操作指令。
- **对称破缺作为极端信号**：题7利用对称性恢复缺失信息。反过来，可以让对称破缺的具体位置和方式编码操作类型——破缺不是需要修复的缺陷，而是需要读取的指令。
- **颜色频次与空间操作的跨域映射**：统计信息（如颜色出现次数）通常用于排序或筛选，但可以映射到完全不同的空间操作上，如频次决定移动距离、旋转角度或缩放比例。
- **邻接关系作为图结构编码**：将对象之间的邻接/包含/相交关系视为一个隐式图，图的某种属性（如度数、连通性）驱动输出变换。

<new_puzzle>
<description>
根据每个封闭房间唯一"门洞"的朝向，为房间内部填充对应的方向色。

Input structure:
- 背景色为 black。网格中由 grey 像素绘制的单像素宽直线段（水平或垂直）相互交叉，与网格的四条外边界共同围成若干封闭的矩形房间。
- 每个房间的 grey 墙壁上恰好有一个缺口（即某条 grey 线段上缺失一个像素的位置），缺口宽度为1个像素。缺口处为 black。
- 网格的四条外边界本身视为完整的墙壁，永远没有缺口。

Rule:
- 识别每个由 grey 墙壁和网格边界围成的4-连通 black 区域（即房间）。
- 找到每个房间边界上唯一的缺口位置，判断缺口相对于房间的方位：缺口在房间的上侧墙壁上则朝上，在下侧墙壁上则朝下，在左侧墙壁上则朝左，在右侧墙壁上则朝右。
- 朝上填充 red，朝下填充 blue，朝左填充 green，朝右填充 yellow。
- grey 墙壁像素保持不变，缺口处的 black 像素也保持不变。

Key insight:
密集的网格线让所有房间外观极为相似，真正的差异隐藏在每个房间墙壁上那一个微小的缺口中。解题者必须逐房间精确定位缺口并判断其方向，才能确定填充色。
</description>

<new_puzzle>
<description>
每个彩色形状上有一个微小的单像素"尖刺"指示平移方向，将形状整体沿尖刺方向滑动至网格边界或碰到障碍。

Input structure:
- 背景色为 black。网格中有若干互不相邻的小型4-连通形状，每个形状由单一前景色填充（颜色各不相同，如 red、blue、green、orange 等）。
- 每个形状的主体是一个紧凑的实心矩形（2×2 或 3×3），并且恰好有一个像素从矩形某条边的中央位置向外突出1格，形成一个"尖刺"。尖刺方向为上、下、左、右之一。
- 网格尺寸不超过 20×20，形状数量为2到5个。

Rule:
- 识别每个形状上尖刺相对于矩形主体的突出方向（上、下、左、右）。
- 将整个形状（包含尖刺）沿尖刺方向平移，直到形状在该方向上的最外侧像素恰好抵达网格边界（紧贴边缘），或者紧贴到另一个已定位的形状旁边（不重叠）。
- 清除形状原始位置的所有像素（恢复为 black）。
- 处理顺序：距其目标边界最近的形状先移动，依次处理。

Key insight:
每个形状上那个不起眼的单像素突出并非轮廓噪声，而是一个方向箭头，精确编码了该形状必须滑动的方向。解题者需要在视觉上辨别出每个形状的微小不对称，并将其解读为运动指令。
</description>
</new_puzzle>

<new_puzzle>
<description>
网格中散布的同色像素对之间的连线方向编码了一种旋转指令，对连线中点处的独立目标形状施加对应角度的旋转。

Input structure:
- 背景色为 black。网格中有一个由 grey 像素组成的小型4-连通形状（目标形状），位于网格中央区域。
- 网格四周散布着若干成对出现的彩色标记像素，每种颜色恰好出现2个像素。颜色种类为1到3种（如 red、blue、green）。
- 每对同色像素的两个像素之间没有其他前景像素阻隔。

Rule:
- 对于每对同色标记像素，计算从第一个像素到第二个像素的方向向量。"第一个"定义为行号更小的那个（行号相同则列号更小的在先）。
- 若方向向量指向右（列增大，行不变），对目标形状施加 0° 旋转（不变）。
- 若方向向量指向下（行增大，列不变），施加顺时针 90° 旋转。
- 若方向向量指向左（列减小，行不变），施加 180° 旋转。
- 若方向向量指向上（行减小，列不变），施加顺时针 270° 旋转。
- 若方向向量为对角线方向（如右下），则取其主方向分量中较长的那个维度对应的旋转。若两维分量等长，取顺时针方向较大的旋转。
- 多对标记的旋转累加：将所有旋转角度求和后对 360° 取模，得到最终旋转角度。
- 将目标 grey 形状绕其 bounding box 中心旋转最终角度，输出中仅包含旋转后的形状（背景为 black），网格裁剪为刚好容纳旋转后形状的 bounding box。

Key insight:
散布在网格边缘的同色像素对看似装饰，实则每对像素的连线方向编码了一个旋转角度。多对标记的角度叠加决定了中心形状的最终旋转。解题者需要同时理解方向-角度映射和累加机制。
</description>
</new_puzzle>

<new_puzzle>
<description>
两个相同大小的彩色图案上下排列，输出为逐像素比较后的"差异图"——相同位置保持不变，不同位置用特定颜色标出并指示哪个图案"赢"。

Input structure:
- 网格由上下两个等高的面板组成，中间由一行 grey 像素分隔。
- 上面板和下面板大小相同（宽度等于网格宽度，高度各占一半减去分隔行）。
- 每个面板的背景为 black，其上有若干彩色像素构成的图案，可能使用的颜色包括 red、blue、green、yellow、orange 等。

Rule:
- 逐像素对比上面板与下面板中对应位置的颜色。
- 输出网格与单个面板大小相同（去掉分隔行和另一个面板）。
- 若上下面板对应位置颜色相同，输出该位置为 black。
- 若上下面板对应位置颜色不同，且其中一个为 black（即只有一个面板在此位置有前景色），输出该前景色本身。
- 若上下面板对应位置颜色不同，且两者都不为 black（两个面板在此位置有不同的前景色），则输出 maroon。

Key insight:
这道题的核心不是寻找匹配，而是精确定位差异。"两个面板都有前景色但颜色不同"这一冲突条件用第三种颜色 maroon 标记，迫使解题者区分三种比较结果，而非简单的"相同/不同"二分。
</description>
</new_puzzle>

<new_puzzle>
<description>
根据每个孤立色块与网格中唯一参考线（彩色直线）的拓扑位置关系（在线的哪一侧），对色块进行颜色翻转。

Input structure:
- 背景色为 black。网格中有一条由 magenta 像素组成的单像素宽直线段，水平或垂直贯穿整个网格（从一条边界到对面边界），将网格分为两个半区。
- 两个半区中各散布着若干小型4-连通形状，每个形状由 red 或 blue 单色填充。
- 形状不与 magenta 线接触。

Rule:
- 确定 magenta 线的方向（水平或垂直）及其将网格分为的两个半区。
- 对于水平线：线上方为半区A，线下方为半区B。对于垂直线：线左侧为半区A，线右侧为半区B。
- 半区A中的所有形状保持原色不变。
- 半区B中的所有 red 形状变为 blue，所有 blue 形状变为 red（颜色互换）。
- magenta 线本身保持不变。

Key insight:
输入中两侧形状的颜色分布看起来随机混杂，但输出揭示了一个隐藏的对称性：magenta 线是一条"镜子"，一侧的颜色是真实的，另一侧的颜色是被翻转的。解题者必须发现哪一侧被翻转了，以及翻转规则是什么。
</description>
</new_puzzle>

<new_puzzle>
<description>
网格中有若干由不同颜色描边的闭合矩形框，每个框的周长决定其内部的填充色——从一个固定的颜色序列中按周长排名选取。

Input structure:
- 背景色为 black。网格中有3到6个互不重叠、互不接触的空心矩形框，每个框由不同颜色的单像素宽边框绘制（如 red、blue、green、yellow、orange 等）。
- 每个框的内部全部为 black（空心）。
- 矩形框大小各不相同，但边框颜色与框的大小之间没有固定对应关系。

Rule:
- 计算每个矩形框的周长（以像素数计：框的外边界像素总数）。
- 按周长从小到大排序所有矩形框。
- 使用一个固定的填充色序列：[azure, yellow, orange, maroon, magenta, green]，将排名第 k 的矩形框（k 从 1 开始）的内部填充为序列中的第 k 种颜色。
- 矩形框的边框颜色保持不变。
- 若两个框周长相同，则行坐标更小（更靠上）的框排名在前。

Key insight:
框的边框颜色是干扰信息——它不参与决定填充色。填充色完全由框的周长（即大小）排名决定。解题者必须忽略显眼的边框颜色，转而度量并比较各框的尺寸。
</description>
</new_puzzle>

<new_puzzle>
<description>
将一组重叠放置的透明彩色矩形"展平"——重叠区域的颜色通过预定义的优先级规则决定，并在输出中于每个矩形的特定角落标注其原始层级编号。

Input structure:
- 背景色为 black。网格中有2到4个部分重叠的实心矩形，每个矩形由不同的前景色填充（如 red、blue、green、yellow）。
- 在重叠区域中，只有最上层矩形的颜色可见（后绘制的遮住先绘制的）。
- 每个矩形至少有一部分区域是完全可见的（不被其他矩形遮挡）。

Rule:
- 通过观察哪些颜色覆盖了哪些颜色，推断矩形的前后层级顺序（最前面的图层编号为1，最后面的编号最大）。判断依据：如果颜色A在某处覆盖了颜色B（即A的矩形区域与B的矩形区域重叠处显示A），则A在B前面。
- 输出中，所有矩形的颜色和位置保持不变（重叠区域仍显示最前面矩形的颜色）。
- 但在每个矩形可见区域的左上角像素处，将该像素的颜色替换为 grey，并在该 grey 像素的右边一格放置一个 maroon 像素。若该位置已被其他矩形遮挡（左上角不可见），则沿该矩形上边界向右寻找第一个可见像素作为替代标注位置。
- 标注的排列方式编码层级编号：第1层（最前）的标注为1个 maroon 像素跟在 grey 后面；第2层为2个 maroon 像素跟在 grey 后面；第 n 层为 n 个 maroon 像素跟在 grey 后面。

Key insight:
输出几乎与输入相同，差异仅在每个矩形角落处出现的微小标注。解题者需要先推断重叠层级，然后理解标注的 maroon 像素数量直接编码了层级深度。
</description>
</new_puzzle>

<new_puzzle>
<description>
网格被分为左右两半：左半是一组带有缺失像素的形状模板，右半是一个颜色调色板行；用调色板中对应位序的颜色填补每个模板中的缺失像素。

Input structure:
- 网格被一列 grey 像素垂直分为左右两个面板。
- 左面板背景为 black，其中有若干个互不重叠的小型形状（每个形状由一种前景色填充，如 red、blue、green 等）。每个形状是一个近乎完整的简单几何体（如3×3方块、十字形、L形），但每个形状恰好缺失了1到3个像素（应有像素的位置显示为 black）。
- 右面板是一个单行或单列的颜色条，从上到下（或从左到右）包含若干不同颜色的像素，数量等于左面板中所有形状缺失像素的总数。

Rule:
- 对左面板中的每个形状，识别其缺失像素的位置（通过形状的几何规律或对称性推断出应有但缺失的像素位置）。
- 将所有缺失位置按照从上到下、从左到右的阅读顺序排列。
- 从右面板颜色条中按顺序取色，依次填入排列好的缺失位置中。
- 左面板中原有的形状像素保持不变，右面板和 grey 分隔列在输出中被移除（输出仅包含修补后的左面板）。

Key insight:
难点在于准确识别每个形状"缺了什么"——这需要理解每个形状本应是什么几何体。右面板的颜色条提供的不是"用什么颜色修补"的信息（因为修补色可能与形状本身颜色不同），而是一种刻意的跨形状颜色注入，使得填补后的形状变成多色的。
</description>
</new_puzzle>
