## 第一步：基础操作分析与非显而易见的串联方式

### 参考题中涉及的基础操作归类

1. **传播/射线类**：条纹传播（#1）、对角射线反射（#17）、对角光束发射与碰撞（#13）、粒子沿走廊运动（#6）
2. **对称/镜像类**：点反射复制（#3）、跨标记线反射（#9）、镜像标记对连接（#19）
3. **空间移动/位移类**：循环下移（#4）、裂缝分裂推移（#7）、重力下落与滑动（#11）
4. **连接/桥接类**：对角连线（#8）、控制序列桥接（#5）
5. **控制像素/元数据编码类**：控制列编码位移量（#4）、计数决定尺寸（#14）、粉色定位（#12）、图例排名重着色（#16）
6. **区域填充/重着色类**：腔体填充（#10）、面板内对象统一色（#20）、视线标记（#18）

### 非显而易见的串联思路

- **计数结果作为几何参数**：某区域的像素数不仅可以决定尺寸（#14），还可以决定旋转角度、平移步数、颜色选择的索引。
- **空间拓扑作为信息编码**：对象之间的相对位置关系（包围、邻接、共线）可以编码操作类型——比如一个标记在对象的哪一侧决定了变换方向。
- **形状差异作为操作指令**：两个"几乎相同"的图案之间的差异像素本身可以编码变换规则。
- **路径追踪的终点决定属性**：射线、路径或传播的终止位置的属性可以反馈影响起点或路径上的着色。
- **嵌套层次的识别**：对象内部的子结构可以作为另一个操作的模板或掩码。

<new_puzzle>
- `description`：根据封闭区域内部"种子"像素的颜色，将该区域的边界墙体重新着色为种子颜色，同时擦除种子像素。

- `Input structure`：
  - bg = black。网格中有若干由 grey 像素构成的不规则但封闭的围墙（4-连通封闭环），围墙之间互不接触。
  - 每个封闭围墙内部恰好有一个非黑非灰的"种子"像素（颜色各不相同，如 red、blue、green 等）。
  - 围墙外部可能散落一些孤立的灰色像素作为干扰项（它们不构成封闭区域）。

- `Rule`：
  - 识别所有由 grey 像素构成的 4-连通封闭环（即环内区域通过 4-连通 flood-fill 无法到达网格边界的区域）。
  - 对每个封闭环，找到其内部唯一的种子像素，记录其颜色 C。
  - 将该封闭环的所有 grey 墙体像素重新着色为 C。
  - 将种子像素本身设为 black（背景色）。
  - 不构成封闭区域的孤立灰色像素保持不变。

- `Key insight`：核心难点在于区分"构成封闭围墙的灰色像素"与"孤立的灰色干扰像素"——只有真正围成封闭区域的灰色像素才会被重着色，而判断封闭性需要对内部区域做 flood-fill 测试。种子像素的作用是"染色后消失"，信息从内部传递到边界。
</new_puzzle>

<new_puzzle>
- `description`：将网格中每个彩色"箭头"形状沿其指向方向平移，平移距离等于该箭头尾部的长度（像素数）。

- `Input structure`：
  - bg = black。网格中散布若干单色箭头形状，每个箭头由一个三角头部和一条直线尾部组成，颜色各异（如 red、blue、orange 等）。
  - 箭头头部：一个 3 像素的直角三角形（占据 2×2 区域中的 3 格，缺少的角指示方向反面），指向上/下/左/右之一。
  - 箭头尾部：从头部底边中心沿指向方向的反方向延伸的一条直线段，长度为 1 到 5 个像素不等。
  - 箭头之间不重叠，且平移后不会超出网格边界或彼此碰撞。

- `Rule`：
  - 对每个箭头，计算其尾部直线段的像素数 L。
  - 将整个箭头（头部 + 尾部）沿头部指向的方向平移 L 个像素。
  - 原位置清为背景色 black。

- `Key insight`：解题者需要先识别每个箭头的指向方向（由三角头部缺角位置决定），再意识到尾部长度不仅是箭头的组成部分，更编码了平移的距离。尾部越长的箭头移动越远——箭头"自身携带了自己的运动指令"。
</new_puzzle>

<new_puzzle>
- `description`：在网格中找到配对的同色"钥匙"与"锁"，用钥匙的缺口形状补全锁的缺口，并将锁的颜色改为钥匙的颜色。

- `Input structure`：
  - bg = black。网格中有若干矩形块，每个矩形块在一条边上有一个凹陷缺口（缺口是从边缘向内凹入的一个矩形区域，宽度和深度各为 1-3 像素）。
  - 矩形块分为两类：
    - "钥匙"：以某种前景色（如 red、green、blue 等）绘制的矩形，缺口处填充为 grey。
    - "锁"：以 grey 绘制的矩形，缺口处为 black（空缺）。
  - 每个钥匙恰好与一个锁配对：配对条件是钥匙的 grey 缺口区域与锁的 black 缺口区域形状（宽度×深度）完全相同，且缺口位于矩形的同一侧（上/下/左/右）。
  - 每种前景色最多出现一次（即每种颜色对应一个钥匙和一个锁）。

- `Rule`：
  - 对每对配对的钥匙和锁：
    - 将锁的 black 缺口区域填充为钥匙的前景色。
    - 将锁的整个 grey 矩形体也重新着色为钥匙的前景色。
    - 钥匙保持不变。
  - 未配对的锁或钥匙（如果有）保持不变。

- `Key insight`：解题者需要先理解"缺口形状匹配"是配对机制——不是通过颜色直接匹配（锁本身都是灰色），而是通过缺口的几何形状（大小和朝向）来建立钥匙与锁的对应关系。然后钥匙的颜色"解锁"了锁，赋予它身份。
</new_puzzle>

<new_puzzle>
- `description`：将网格中每个多色条形图案的各色段按长度排序重组，排序方向由条形一端的标记像素指定。

- `Input structure`：
  - bg = black。网格中有若干水平或垂直的条形图案，互不接触。
  - 每个条形由多个连续的单色段拼接而成（例如 3 个 red + 2 个 blue + 5 个 green），段数在 2 到 5 之间。
  - 每个条形的一端（起始端或末尾端）紧邻一个 maroon 标记像素。maroon 像素位于条形延长线上、紧贴条形端部。
  - 条形中不包含 maroon 色。

- `Rule`：
  - 对每个条形，识别其中各色段及其长度。
  - 确定 maroon 标记在条形的哪一端（左端/右端 或 上端/下端）。
  - 将各色段按长度从短到长排序，最短段放在 maroon 标记所在的那一端，最长段放在远离标记的那一端。长度相同的段保持原始相对顺序。
  - 每个色段重排后仍保持其原始长度和颜色，仅位置改变。
  - maroon 标记像素保持不动。

- `Key insight`：解题者面对的条形看似随机排列的彩色段，需要发现"段长度"是排序依据，而 maroon 标记指示了排序的锚定方向（升序从标记端开始）。关键在于识别出 maroon 不是条形的一部分而是元数据，以及排序的维度是"段长度"而非颜色值或出现顺序。
</new_puzzle>

<new_puzzle>
- `description`：网格中散布着若干同色像素对，每对之间的曼哈顿距离编码了一个颜色索引；在每对连线的中点处绘制一个该索引对应颜色的像素。

- `Input structure`：
  - bg = black。网格中有若干 azure 像素，总数为偶数。
  - 这些 azure 像素构成若干配对：每对 azure 像素关于某条水平线或垂直线对称（即共享同一行或同一列，且到对称轴等距），使得配对方式唯一。
  - 每对 azure 像素之间的曼哈顿距离 d 在 2 到 8 之间（保证中点落在整数坐标上）。
  - 颜色映射表固定：d=2 → red, d=3 → green, d=4 → yellow, d=5 → blue, d=6 → magenta, d=7 → orange, d=8 → grey。

- `Rule`：
  - 对每对配对的 azure 像素，计算它们之间的中点坐标（因距离为偶数或奇数但对称性保证中点为整数坐标）。
  - 计算它们的曼哈顿距离 d。
  - 在中点处放置颜色映射表中 d 对应的颜色像素。
  - 保留所有原始 azure 像素不变。

- `Key insight`：所有输入像素看起来都是同一种颜色（azure），解题者必须发现配对规则（对称性），然后注意到输出中出现的新颜色与配对距离之间存在系统性映射。难点在于：(1) 从视觉上识别出哪些像素是配对的——对称性是配对的依据；(2) 距离→颜色的映射需要从多个样例中逐一验证归纳。
</new_puzzle>

<new_puzzle>
- `description`：在一个包含多层嵌套矩形框的网格中，根据嵌套深度的奇偶性决定每层框的保留或擦除。

- `Input structure`：
  - bg = black。网格中有若干由 green 像素绘制的空心矩形框（每个框是 1 像素宽的矩形环）。
  - 这些矩形框呈严格嵌套关系：每个框要么完全包含在另一个框内部，要么完全在另一个框外部，不存在部分重叠。
  - 嵌套深度定义为：最外层框深度为 1，被最外层包含的下一层为 2，以此类推。
  - 每组嵌套的框之间间隔至少 1 个像素。网格中可能有多组独立的嵌套结构。

- `Rule`：
  - 计算每个矩形框的嵌套深度。
  - 保留所有奇数深度（1, 3, 5, ...）的框，将它们的颜色从 green 改为 red。
  - 擦除所有偶数深度（2, 4, 6, ...）的框（设为 black 背景色）。
  - 背景和框内部的空区域保持不变。

- `Key insight`：所有框在输入中看起来完全相同（都是 green 空心矩形），解题者必须发现嵌套层级的概念，并且注意到输出中每隔一层框被删除。关键认知路径是：首先看到某些框消失了，然后尝试寻找消失框的共同特征，最终发现"嵌套深度的奇偶性"是选择标准。
</new_puzzle>

<new_puzzle>
- `description`：网格被若干颜色不同的直线分割成区域，每个区域被填充为包围它的所有分割线颜色的"混合色"——即这些颜色在调色板中出现顺序的中位数对应的颜色。

- `Input structure`：
  - bg = black。网格中有若干条贯穿整个网格的水平线和垂直线（从一边到另一边），每条线为 1 像素宽，颜色为 red、blue、green、yellow、orange 之一。
  - 这些线将网格分割成若干矩形区域，每个区域当前为 black 背景。
  - 线与线之间的交叉点处，交叉像素的颜色为后绘制的线的颜色（但这不影响规则，因为规则只关注区域的边界线）。
  - 颜色排序约定固定：red=1, orange=2, yellow=3, green=4, blue=5。

- `Rule`：
  - 对每个被分割出的矩形区域，找到构成其四条边界的线的颜色集合（一个区域的边界可能包含 2 到 4 种不同颜色的线，也可能某些边界是网格边缘则不计入）。
  - 将边界线颜色按照固定排序（red < orange < yellow < green < blue）排列，取中位数（偶数个取较小的中间值）对应的颜色。
  - 用该中位数颜色填充整个矩形区域的内部（不覆盖边界线本身）。

- `Key insight`：解题者看到的是一个被彩色线条分割的网格，输出中每个空白区域被填上了某种颜色。关键在于发现填充色不是随机的，而与围绕该区域的边界线颜色有关——具体是取这些边界颜色在固定调色板序列中的中位数。需要解题者建立"颜色有序"的认知框架。
</new_puzzle>

<new_puzzle>
- `description`：网格中有若干对同色 L 形标记互相"对视"，在它们之间的矩形区域内填充该颜色。

- `Input structure`：
  - bg = black。网格中有若干 L 形标记，每个 L 形由 3 个像素组成：一个拐角像素加上从拐角沿两个垂直方向各延伸 1 像素（形成直角）。
  - 每种前景色（如 red、blue、green 等）恰好出现两个 L 形标记。
  - 同色的两个 L 形标记构成一对"对视"关系：它们的开口方向相对（即一个开口朝右下则另一个开口朝左上），使得两个 L 形可以被视为某个矩形的对角括号。
  - 不同颜色的 L 形对之间不重叠。

- `Rule`：
  - 对每对同色 L 形标记，找到它们的拐角像素坐标 (r1,c1) 和 (r2,c2)。
  - 用该颜色填充以这两个拐角为对角的矩形区域内的所有像素（包括 L 形标记自身已有的像素）。
  - 不同颜色的矩形之间如有重叠，后处理的颜色覆盖先处理的（但题目保证不重叠）。

- `Key insight`：L 形标记看起来像是散落的小形状，解题者需要发现同色 L 形总是成对出现且方向互补——它们实际上是矩形的两个对角"括号"。核心认知跳跃是从"3 像素的小标记"到"矩形的两个角标"，然后填充由角标定义的矩形。
</new_puzzle>
