<description>
根据彩色种子像素的颜色在分隔线图例中查找对应的填充图案，再将该图案平铺到种子所在的封闭区域中。

Input structure:
- bg = 最常见颜色（black）。网格被灰色（grey）线条划分为若干封闭矩形区域。
- 网格底部有一行水平图例区：图例区由若干小方块组成，每个小方块左侧是一个单像素的颜色标记（如 red、blue、green 等），右侧紧跟一个 2×2 或 3×3 的小图案（由两种颜色交替组成，如棋盘格、条纹、对角线等）。
- 在灰色线条划分的封闭区域内部，某些区域包含一个单像素的彩色"种子"像素，颜色与图例中某个标记颜色一致。

Rule:
- 首先识别底部图例区，提取每个颜色标记与其对应的小图案的映射关系。
- 对于每个包含种子像素的封闭区域，根据种子颜色在图例中查找对应的填充图案。
- 将该图案以平铺（tile）方式填满整个封闭区域（不含灰色边界线本身），平铺的对齐基准为区域的左上角。
- 种子像素本身被图案覆盖，不保留。
- 没有种子像素的区域保持 bg 不变。

Key insight: 需要两层推理——第一层是从图例中建立"颜色→图案"的映射字典，第二层是识别种子所在区域的边界并用对应图案平铺填充；仅看到种子和区域不够，必须先解读图例才能确定填充内容。
</description>

<new_puzzle>
<description>
将散落的彩色碎片按颜色归组，每组碎片拼合成完整矩形后，按矩形面积从大到小垂直堆叠输出。

Input structure:
- bg = 最常见颜色（black）。网格中散布着若干彩色连通分量（碎片），每个碎片是不规则形状。
- 同一颜色的碎片有 2-4 块，它们的形状互补——拼合在一起恰好组成一个无缝的实心矩形。
- 不同颜色的碎片组形成的矩形尺寸各不相同。

Rule:
- 按颜色将碎片分组。对每组同色碎片，找到唯一的平移排列方式使它们无重叠地拼合成一个完整的实心矩形（碎片不旋转、不翻转，仅平移）。
- 计算每个拼合矩形的面积（宽×高）。
- 输出网格宽度等于最宽矩形的宽度，高度为所有矩形高度之和加上矩形间的 1 行 bg 间隔。
- 按面积从大到小、从上到下排列各矩形，每个矩形左对齐放置，矩形之间用 1 行 bg 分隔。

Key insight: 解题者必须先完成空间拼图——发现同色碎片可以互补拼成矩形，然后再按面积排序输出；拼合步骤本身就需要对碎片形状进行非显然的空间推理。
</description>
</new_puzzle>

<description>
沿箭头方向推送对象，对象在遇到边界或障碍时停止，并在经过的路径上按照对象自身的条纹图案留下周期性轨迹。

Input structure:
- bg = 最常见颜色（black）。网格中有若干小矩形对象（宽或高为 2-4 像素），每个对象内部包含两种交替颜色的水平或垂直条纹（如 red-blue-red 交替）。
- 每个对象的一侧（上、下、左或右）紧邻一个由 maroon 像素组成的箭头形标记：箭头为 3 像素的">"、"<"、"^"或"v"形状（例如向右箭头为：一列 3 像素高的 maroon 竖线，右侧中间位置有 1 个 maroon 像素突出）。箭头方向表示推送方向。
- 网格中可能存在灰色（grey）实心矩形作为静止障碍物。

Rule:
- 每个对象沿箭头指示方向滑动，直到对象的前沿碰到网格边界或灰色障碍物时停止。
- 对象在滑动过程中，其经过的每一列（水平移动时）或每一行（垂直移动时）都留下对象条纹图案的一个"切片"。具体地：对象的条纹沿移动轴方向是周期性的，轨迹上第 k 个切片的颜色等于对象在移动轴方向上第 (k mod 条纹周期) 个切片的颜色。
- 箭头标记本身在输出中移除。
- 对象最终停在终点位置，轨迹填充从起点到终点之间的空白区域。

Key insight: 解题者需要分两层推理——第一层是识别箭头方向确定运动轴和终点，第二层是发现轨迹不是简单的单色拖尾，而是对象内部条纹图案的周期性延伸，必须从对象本身的条纹中提取重复单元。
</description>

<new_puzzle>
<description>
在网格中找到每个彩色"窗口框"内的图案，将其旋转到与框上缺口方向对应的朝向后，投射到框外缺口对面的空白画布区域。

Input structure:
- bg = 最常见颜色（black）。网格中有若干矩形空心框，每个框由单一颜色绘制（如 red、blue、green 等），框的四条边中恰好有一条边存在一个连续缺口（缺口宽度为 2-4 像素，位于该边的中央位置）。
- 每个框内部包含一个由另一种颜色组成的小图案（非对称形状，占据框内部分区域）。
- 框的缺口对面的外侧（与缺口方向相反的方向），有一块与框内部等大的空白 bg 区域（画布），画布四周无其他对象遮挡。

Rule:
- 确定每个框的缺口位于哪条边（上、下、左、右）。
- 缺口所在边定义了"出口方向"。根据出口方向对框内图案进行旋转：缺口在上边→不旋转（0°），缺口在右边→顺时针旋转 90°，缺口在下边→旋转 180°，缺口在左边→顺时针旋转 270°。
- 将旋转后的图案绘制到缺口对面外侧的画布区域中，图案在画布中的相对位置与其在框内的相对位置镜像对称（沿缺口边的法线方向翻转）。
- 输出中框和框内原始图案保持不变，画布区域被填入旋转并翻转后的图案。

Key insight: 三层推理结构——第一层是识别缺口位置确定方向，第二层是根据方向选择旋转角度，第三层是将图案沿法线方向镜像投射到外部画布；缺口方向同时编码了旋转量和投射方向，这一双重语义需要从多个样例中归纳。
</description>
</new_puzzle>

<new_puzzle>
<description>
根据连接线的拓扑将散布的色块分组，每组内按色块面积排序后重新排列为从内到外的嵌套同心框。

Input structure:
- bg = 最常见颜色（black）。网格中散布着若干不同颜色的实心矩形色块（每个色块为单一颜色的小矩形，大小各异）。
- 色块之间由单像素宽的 grey 线段相连（水平或垂直直线，可以有直角拐弯），每条线段连接恰好两个色块（线段端点接触色块边缘）。
- 通过这些线段，色块形成若干互不相连的组（每组 2-4 个色块通过线段链式相连）。
- 网格中还有与每组对应的 orange 单像素标记点，每组恰好一个，位于该组色块附近但不与任何色块或线段接触。

Rule:
- 通过 grey 连接线识别色块分组：沿线段可达的色块属于同一组。
- 在每组内，按色块面积从小到大排序。面积最小的色块颜色作为最内层实心正方形（边长等于该色块的短边长度），面积次小的颜色作为包裹它的第一层框（框厚度为 1 像素），依次向外包裹，每层框厚度均为 1 像素。
- 将生成的嵌套同心框结构绘制在对应的 orange 标记点位置（标记点作为同心框结构的中心点）。
- 输出中移除所有原始色块、grey 连接线和 orange 标记点，仅保留生成的同心框结构。

Key insight: 需要三步非显然推理——第一步是通过连接线的拓扑关系将色块分组（不能仅靠空间邻近性），第二步是在组内按面积排序确定嵌套层次，第三步是将排序结果转化为以标记点为中心的同心框输出；连接线既不出现在输出中也不影响几何形状，仅作为分组依据。
</description>

<description>
识别网格中的"印章"模板和"指令条"，根据指令条中颜色块的排列顺序，对印章模板进行逐步变色复制，生成一行渐变序列。

Input structure:
- bg = 最常见颜色（black）。网格上半部分包含一个由单一颜色（如 blue）绘制的小型非对称图案作为"印章模板"（大小约 3×3 到 5×5）。
- 网格下半部分有一条水平的"指令条"：由若干相邻的单像素色块组成的一行，每个像素颜色不同（如 red、green、yellow、maroon 等），共 N 个像素（N 为 3-6）。
- 指令条的第一个像素颜色与印章模板的颜色相同。

Rule:
- 输出网格的高度与印章模板相同，宽度为 N 个印章模板宽度加上 (N-1) 个 1 像素间隔。
- 从左到右放置 N 个印章模板的副本，每个副本之间用 1 列 bg 分隔。
- 第 i 个副本（从 1 开始计数）的颜色为指令条中第 i 个像素的颜色。即印章模板的所有非 bg 像素被替换为指令条中对应位置的颜色。
- 输出中不包含指令条本身。

Key insight: 两层推理——第一层是识别出指令条中的第一个颜色与模板颜色一致从而建立"指令条控制模板颜色"的关联，第二层是理解指令条的长度决定了副本数量、每个位置的颜色决定了对应副本的重新着色；指令条既编码了数量信息又编码了颜色映射序列。
</description>
</new_puzzle>

<new_puzzle>
<description>
检测每个封闭形状内部的"裂缝"方向，沿裂缝将形状一分为二，然后将两半分别沿裂缝法线方向向外平移，露出裂缝间隙并用指定颜色填充。

Input structure:
- bg = 最常见颜色（black）。网格中有若干由单一颜色填充的大型封闭形状（不规则但连通的实心区域，每个约 6×6 到 10×10 像素）。
- 每个形状内部有一条贯穿的"裂缝线"——由 bg 颜色组成的连续单像素宽直线（水平或垂直），将形状在视觉上分为两半，但裂缝两端不超出形状边界。
- 每个形状外部紧邻其边缘有一个 2×1 的小色块标记（颜色与形状颜色不同），标记的长轴方向与裂缝方向垂直。

Rule:
- 识别每个形状内部的裂缝线及其方向（水平或垂直）。
- 沿裂缝将形状分为两个半块。
- 将两个半块分别沿裂缝的法线方向（即与裂缝垂直的方向）各向外平移 1 像素，使裂缝间隙从 1 像素扩大为 3 像素。
- 用形状旁边小色块标记的颜色填充扩大后的 3 像素宽间隙区域。
- 小色块标记在输出中移除。

Key insight: 两层非显然推理——第一层是发现形状内部的 bg 直线不是背景穿透而是"裂缝"指令（需要区分真正的内部裂缝与外部背景），第二层是理解外部小色块标记的朝向与裂缝垂直这一隐含关联，并将标记颜色用于填充裂缝间隙。
</description>
</new_puzzle>
