<description>
根据嵌套框架的层级深度对内部像素进行颜色重映射。

Input structure:
- bg = 背景色。网格中有若干由单一颜色构成的嵌套矩形框架（同心框），每层框架颜色相同。
- 最内层区域包含由多种非背景色组成的小型图案（种子图案）。
- 网格边缘有一个 1×N 或 N×1 的颜色条带作为深度-颜色映射图例，从外到内依次列出每层深度对应的替换颜色。

Rule:
- 计算每个嵌套框架从最外层到最内层的深度编号（最外层 = 1）。
- 将种子图案中的每个非背景像素按其所在的嵌套深度层查找图例，获取对应的替换颜色。
- 将种子图案按深度层数进行径向复制：每层框架的内壁上都粘贴一份经颜色重映射后的种子图案副本，图案朝向该层框架的中心对齐。
- 移除原始图例条带。

Key insight: 嵌套深度既决定了图案的复制位置，又通过图例决定了每份副本的颜色方案——框架本身是空间索引，图例是颜色查找表。
</description>

<description>
将网格中的二维条形码解码为颜色指令序列，对指定目标区域执行逐行/逐列染色。

- bg = 背景色。网格被分为两个区域：上方是"条形码区"，包含若干水平彩色条纹（每条纹高度为1像素，颜色和长度各异）；下方是"目标区"，包含一个灰色（5）填充的矩形。

- 输出仅包含染色后的目标区矩形（裁剪掉条形码区和分隔线）。

Key insight: 条纹长度是位置索引而非字面尺寸——一根5像素长的条纹意味着"第5行/列"而非"染5个像素"，这种语义转换是主要陷阱。

- 迷宫墙壁和非路径通道保持不变。
- 渐变条在输出中被移除。

Key insight: 渐变条的长度与路径长度无关——它是一个颜色采样源，需要通过比例映射而非一一对应来着色路径，这要求解题者理解线性插值的离散化。

Key insight: 五线谱是一个空间编码的高度量化系统——音符的垂直位置不是直接映射为输出高度，而是通过相对于最低线的偏移量来计算，线间位置产生半整数高度值。
