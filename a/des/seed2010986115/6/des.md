- `description`：根据封闭区域内部"种子"像素的颜色，从色带图例中查找对应的填充纹理，将该纹理平铺填入封闭区域。

- `Input structure`：
  - 背景为黑色（black）。
  - 网格上方有一条水平色带图例区，图例区由若干宽度相等的小方块组成，每个小方块上半部分是纯色标识色，下半部分是 2×2 或 3×3 的纹理图案（由两种颜色交替构成，例如棋盘格、条纹等）。
  - 网格下方的主区域中，若干由灰色（grey）像素围成的封闭矩形区域散布在黑色背景上。
  - 每个封闭区域内部恰好有一个非黑色、非灰色的"种子"像素，其颜色与图例区某个小方块的标识色一致。

- `Rule`：
  - 对每个封闭区域，读取其内部种子像素的颜色。
  - 在图例区中找到标识色与种子颜色匹配的小方块，提取其下半部分的纹理图案。
  - 用该纹理图案以左上角对齐的方式平铺填满整个封闭区域的内部（覆盖种子像素），灰色边框和外部黑色背景保持不变。

- `Key insight`：种子像素不是直接决定填充颜色，而是作为索引键在图例中查找一个二维纹理模板；解题者需要先建立"颜色→纹理"的映射关系，再执行空间填充。

- `description`：将散布的彩色像素按颜色分组，每组像素沿各自的"领航像素"指示的方向平移，直到同组像素拼合成一个紧凑的矩形。

- `Input structure`：
  - 背景为黑色（black）。
  - 网格中散布着若干种非黑色像素，每种颜色恰好出现若干个像素。
  - 对于每种颜色，恰好有一个像素位于网格的某条边上（上/下/左/右边缘），称为该颜色的"领航像素"。其余同色像素分散在网格内部。

- `Rule`：
  - 对每种颜色，确定其领航像素所在的边：上边缘表示"向上"，下边缘表示"向下"，左边缘表示"向左"，右边缘表示"向右"。
  - 将该颜色的所有像素（包括领航像素）沿指定方向逐步平移，每步一格，直到该颜色的所有像素恰好构成一个无间隙的实心矩形为止。
  - 平移过程中，不同颜色的像素互不阻挡，各自独立移动。
  - 最终输出中，每种颜色的像素形成一个紧凑矩形，矩形靠近领航像素所在的那条边。

- `Key insight`：解题者需要先识别每种颜色中哪个像素在边缘（确定方向），再推断该组像素平移后能拼成什么形状的矩形——方向选择和目标形状推断是两个独立的非平凡推理层。
</new_puzzle>

<new_puzzle>
- `description`：将网格中由不同颜色框架嵌套包裹的目标对象"剥壳"提取，并按嵌套层数对提取出的对象进行缩放后排列输出。

- `Input structure`：
  - 背景为黑色（black）。
  - 网格中有若干组"嵌套结构"：每组由一个小型彩色图案（目标对象，面积不超过 3×3）位于中心，外面被一层或多层不同颜色的单像素宽矩形框架同心包裹。
  - 不同组的嵌套结构彼此不重叠，框架颜色在同一组内各层不重复。
  - 各组的框架层数不同（1 层、2 层或 3 层）。

- `Rule`：
  - 对每组嵌套结构，剥去所有外层框架，提取最内层的目标对象。
  - 统计该组的框架层数 N。
  - 将目标对象放大为 N 倍（每个像素扩展为 N×N 的方块）。
  - 将所有放大后的目标对象按框架层数从少到多、从左到右排列在输出网格中，对象之间间隔 1 列黑色背景。
  - 输出网格的高度为最大放大对象的高度，较矮的对象顶部对齐。

- `Key insight`：框架层数同时决定两件事——哪些像素属于"壳"需要丢弃、以及提取出的核心需要放大多少倍。解题者需要先正确计数每组的嵌套深度，再将该数值转化为几何缩放因子，这两个推断步骤都需要主动归纳。
</new_puzzle>

- `description`：在网格中识别由"钥匙"形状与"锁孔"形状互补匹配的配对，将每把钥匙平移嵌入对应锁孔，并用钥匙的颜色覆盖填充匹配区域。

- `Input structure`：
  - 背景为黑色（black）。
  - 网格中有若干彩色的小型对象（3×3 至 5×5 范围内），每个对象为实心形状但内部可能有黑色孔洞，称为"钥匙"。每把钥匙颜色各不相同。
  - 网格中另有若干由灰色（grey）像素构成的较大矩形块（例如 5×5 至 8×8），每个灰色块内部有一个由黑色像素形成的"锁孔"凹槽。锁孔凹槽的形状恰好与某把钥匙的实心部分（忽略孔洞）互补匹配——即钥匙的实心像素恰好能填满锁孔的黑色像素，且钥匙的孔洞像素对应锁孔旁的灰色像素。
  - 每把钥匙恰好匹配一个锁孔，无需旋转或翻转。

- `Rule`：
  - 对每把钥匙，在所有灰色块中找到锁孔形状与之互补匹配的那个灰色块。
  - 匹配条件：钥匙形状（仅考虑实心像素，忽略内部孔洞）与锁孔凹槽（灰色块中的黑色区域）在形状和大小上完全一致。
  - 将锁孔凹槽中的黑色像素替换为钥匙的颜色（即用钥匙颜色填充锁孔）。
  - 原始钥匙对象从网格中擦除（变为黑色背景）。
  - 灰色块的灰色部分和其余背景保持不变。

- `Key insight`：解题者需要完成两层推理：第一层是理解钥匙的"有效形状"要忽略内部孔洞（仅看实心轮廓），第二层是在多个锁孔中进行形状匹配找到唯一配对。孔洞的存在是干扰项，迫使解题者区分"钥匙的完整边界"和"钥匙的实心部分"。
</new_puzzle>

<new_puzzle>
- `description`：根据网格边缘的彩色标记确定行列交叉规则，在每个交叉点生成由行色和列色共同决定的小图案。

- `Input structure`：
  - 背景为黑色（black）。
  - 网格被灰色（grey）线划分为均匀的 N×M 个单元格（例如 4×4 或 5×5），每个单元格大小为 3×3。
  - 网格最左列的每个单元格内有一个纯色像素（位于单元格中心），表示该行的"行色"。
  - 网格最上行的每个单元格内有一个纯色像素（位于单元格中心），表示该列的"列色"。
  - 左上角单元格为空（黑色），起分隔作用。
  - 部分内部单元格已填有 3×3 的小图案作为示例，其余内部单元格为空。

- `Rule`：
  - 每个内部单元格的图案由其行色和列色共同决定：
    - 若行色与列色相同，则该单元格填满该颜色（3×3 实心方块）。
    - 若行色与列色不同，则该单元格绘制一个十字图案——中心行 3 个像素为行色，中心列 3 个像素为列色，中心像素（重叠处）为行色，四角为黑色。
  - 将所有空的内部单元格按上述规则填充完整。
  - 已有的示例图案保持不变（它们与规则一致，用于帮助推断）。

- `Key insight`：解题者必须先从已填示例中归纳出"同色→实心、异色→十字叠加"的生成规则，再利用边缘标记的行色和列色将规则应用到所有空单元格。规则的发现依赖于对已有示例中颜色组成与边缘标记之间关系的交叉比对。
</new_puzzle>

<new_puzzle>
- `description`：识别网格中散布的箭头形状及其指向，每个箭头将其指向方向上最近的彩色对象推动到该方向的网格边界，竞争时距离最近的箭头生效。

- `Input structure`：
  - 背景为黑色（black）。
  - 网格中有若干彩色实心矩形对象（颜色各异，非黑非灰非红），大小不一，彼此不接触。
  - 网格中另有若干由红色（red）像素组成的箭头。每个箭头占据 3×3 的区域，形状明确表示方向：向右箭头的红色像素位于第 0 行第 2 列、第 1 行第 0 至第 2 列、第 2 行第 2 列（形成右指三角），向上/下/左箭头类似地通过三角形朝向表示。
  - 每个箭头沿其指向方向的延长线上恰好有一个彩色矩形对象。

- `Rule`：
  - 对每个箭头，确定其指向方向（上/下/左/右）。
  - 沿该方向找到第一个彩色矩形对象。
  - 将该矩形对象沿箭头方向平移，直到矩形的前边缘抵达网格边界。
  - 矩形离开的原始位置变为黑色背景。
  - 所有箭头从网格中擦除（变为黑色背景）。
  - 若多个箭头指向同一个对象，以距离该对象最近的箭头为准（其余箭头视为无效，仅擦除）。

- `Key insight`：箭头的朝向决定推动方向，但当多个箭头竞争同一对象时，解题者需要先判断哪个箭头"生效"——最近优先规则构成第二层推理，防止一眼看穿。
</new_puzzle>

<new_puzzle>
- `description`：利用网格中散布的"染色炸弹"的颜色和爆炸半径，对其曼哈顿邻域内的灰色像素进行染色，重叠区域由面积更小的炸弹优先着色。

- `Input structure`：
  - 背景为黑色（black）。
  - 网格中散布着灰色（grey）像素，形成若干不规则的连通区域。
  - 在灰色区域中嵌入了若干"染色炸弹"：每个炸弹是一个非黑非灰的彩色像素，周围紧邻（上下左右四方向）的同色像素数量表示其爆炸半径 R（即该彩色像素加上与之四连通的同色像素总数为 R）。

- `Rule`：
  - 对每个染色炸弹，计算其连通同色像素组的面积 R。
  - 以炸弹组的几何中心（视觉上的中间位置）为圆心，将距离圆心不超过 R 步（上下左右逐步扩散 R 轮）范围内的所有灰色像素染为炸弹的颜色。
  - 若某个灰色像素在多个炸弹的爆炸范围内，则被面积 R 最小的炸弹染色（小炸弹优先）。
  - 黑色背景像素不受影响，炸弹自身的彩色像素保持不变。

- `Key insight`：解题者需要先通过炸弹的连通区域大小推断爆炸半径（面积即半径），再理解重叠区域的优先级规则（小优先）——两层推理缺一不可。
</new_puzzle>
