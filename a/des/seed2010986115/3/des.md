<description>
根据封闭区域内部的标记像素颜色，从网格边缘的颜色图例中查找对应的填充图案，将该图案平铺填充到对应的封闭区域内。

Input structure:
- 背景为最常见颜色（black）。网格内有若干由 grey 像素构成的封闭矩形框架（一像素宽的边框）。
- 每个框架内部的背景上恰好有一个孤立的标记像素，颜色各不相同（如 red、blue、green 等）。
- 网格最下方一行的下方（或最右侧一列的右侧）排列着若干小型矩形色块作为图例区域，每个图例由两部分组成：左侧（或上方）一个单像素的索引色块，右侧（或下方）一个由两种颜色绘制的小型二值图案（如棋盘格、条纹、十字等），图案绘制在背景上。
- 图例的索引色与框架内部标记像素的颜色一一对应。

Rule:
- 对每个 grey 框架，读取其内部标记像素的颜色 C。
- 在图例区域中找到索引色为 C 的图例，获取其对应的小型图案。
- 将该图案以平铺方式填充到框架内部（不覆盖框架本身），从框架内部左上角开始按行按列重复图案。标记像素被图案覆盖（即标记像素消失）。
- 图例区域在输出中被移除，输出仅包含填充后的框架区域及背景。

Key insight:
标记像素不是装饰而是查找键——需要先建立"标记颜色→图例图案"的映射关系，再用图案替换框架内容。解题者必须同时发现两层结构：标记-图例的配对机制，以及图案的平铺填充方式。
</description>
</new_puzzle>

<new_puzzle>
<description>
将每个彩色对象沿其自身形状中缺口的方向投射，投射距离由同色对象的数量决定，投射轨迹用该对象的颜色绘制。

Input structure:
- 背景为 black。网格中散布着若干小型彩色对象（每个对象为 4-连通的同色像素块，大小 3-6 像素不等）。
- 同一颜色可能出现多个独立对象（2 到 4 个不等）。
- 每个对象的外轮廓（bounding box 边界上的像素分布）恰好在上、下、左、右四个方向之一存在一个凹口（即 bounding box 的某一侧边上有且仅有一个背景像素缺失位置，被对象像素两侧夹住）。

Rule:
- 对每个对象，检测其凹口所在的方向 D（上/下/左/右）。
- 统计整个网格中与该对象同色的独立对象总数 N。
- 从该对象的凹口位置出发，沿方向 D 延伸 N 个像素的射线（用该对象的颜色绘制）。
- 原对象保持不变，射线不覆盖已有的非背景像素（遇到非背景像素则提前停止）。

Key insight:
方向编码在对象自身的形态缺口中——这需要解题者观察对象轮廓而非位置；而射线长度由全局同色对象的计数决定，这要求解题者在局部形态分析之外再进行一次全局统计推理。两层信息来源不同（局部形状 vs 全局计数），构成真正的双层推理。
</description>
</new_puzzle>

<new_puzzle>
<description>
识别网格中由边框颜色隐式编码的"容器嵌套层级"，将每个容器内的自由像素重新着色为与其嵌套深度对应的颜色序列中的颜色。

Input structure:
- 背景为 black。网格中有若干嵌套的矩形边框（框线宽度为一像素），每个边框由不同颜色绘制（如 red、blue、green、yellow 等）。
- 边框可以嵌套：一个边框完全包含在另一个边框内部，形成多层嵌套结构（最多 3-4 层）。
- 在最内层边框内部（以及某些中间层的边框之间），散布着若干 grey 像素点（自由像素），它们不接触任何边框。
- 网格的某个角落（如左上角）放置一个小的颜色序列条：一列纵向排列的不同颜色像素（如从上到下为 orange、magenta、azure），共 3-4 个颜色，代表深度 1、2、3、4 的着色方案。

Rule:
- 计算每个 grey 自由像素所处的嵌套深度：该像素被多少层矩形边框包含，即为其深度值（不被任何边框包含则深度为 0）。
- 根据角落颜色序列条，深度 1 对应序列第 1 个颜色，深度 2 对应第 2 个颜色，依次类推。
- 将每个 grey 像素重新着色为其深度对应的颜色。深度为 0 的 grey 像素（若存在）保持 grey 不变。
- 所有边框和背景保持原样。

Key insight:
解题者需要三步推理：(1) 识别出矩形边框的嵌套包含关系并确定每个位置的嵌套深度；(2) 发现角落颜色条是深度到颜色的映射图例；(3) 将深度映射应用于所有自由像素。嵌套层级是空间结构推理，颜色条是符号映射推理，二者结合形成多层认知路径。
</description>
</new_puzzle>

<new_puzzle>
<description>
每个前景对象根据其所在行列与"标尺线"的交叉方式，被复制并拼接到输出网格中的指定区域，同时对象的朝向由标尺线的交叉模式决定。

Input structure:
- 背景为 black。网格被一条水平的 maroon 线和一条垂直的 maroon 线划分为四个象限（两条线各一像素宽，贯穿整个网格，构成十字分割）。
- 每个象限中恰好有一个小型彩色前景对象（4-连通，非对称形状，每个对象颜色不同）。
- 在十字交叉点的位置（maroon 线的交汇处）有一个单独的 yellow 像素覆盖在 maroon 之上。
- 输出网格的尺寸等于输入网格去除两条 maroon 线后的大小（行数减 1，列数减 1）。

Rule:
- 将四个象限无缝拼合（移除 maroon 十字线和 yellow 交叉点），形成输出网格。
- 每个对象在拼合时需要进行变换：根据其所在象限相对于交叉点的位置决定变换方式。左上象限的对象保持原样；右上象限的对象水平翻转；左下象限的对象垂直翻转；右下象限的对象旋转 180 度。
- 变换后的对象保留其在象限内的相对位置（相对于象限左上角的偏移量不变）。

Key insight:
表面上看似简单的"去除分割线并拼合"，实际上每个象限的对象都经历了与其象限位置绑定的几何变换。解题者需要先发现分割线的存在和拼合操作，再通过对比输入输出中每个对象的形状变化，归纳出"象限决定翻转/旋转"的隐含规则。第一层推理是空间重组，第二层推理是象限-变换的映射关系。
</description>
</new_puzzle>

<description>
将网格中散布的彩色"种子"像素根据相邻同色种子之间的连线方向，生长为特定形状的图案，图案的大小由两个配对种子之间的距离决定。

Input structure:
- 背景为 black。网格中散布着若干成对出现的同色孤立像素（种子），每种颜色恰好出现两个种子像素。不同颜色的种子对有 3-5 组。
- 每对同色种子要么在同一行（水平配对），要么在同一列（垂直配对），且两者之间没有其他非背景像素阻挡。
- 网格的一个边缘区域（如最上方两行）包含一个"形状字典"：一组小型示例图案，每个图案由 green 像素在 black 背景上绘制，图案之间用至少一列 black 间隔。形状字典中的图案按面积从小到大排列。

Rule:
- 计算每对同色种子之间的间距 G（不含种子本身的像素数）。
- 将间距 G 作为索引，在形状字典中选取第 G 个图案（从 1 开始计数）。
- 在两个种子的中点位置（若中点为半像素则取靠近左/上的整数位置），用该种子对的颜色绘制所选图案（替换 green 为种子颜色）。
- 两个原始种子像素在输出中被移除（变为背景色）。
- 形状字典在输出中被保留。

Key insight:
解题者需要完成三层独立推理：(1) 发现孤立像素是成对配对的（通过颜色匹配和行列对齐）；(2) 发现种子间距映射到形状字典的索引（间距编码了选择哪个图案）；(3) 发现图案绘制在种子对中点且使用种子颜色（位置和颜色的来源不同于形状的来源）。每一层都需要非平凡的归纳，而非直觉可得。
</description>
</new_puzzle>

<description>
根据每个封闭区域的"门"的位置和朝向，将区域内的所有彩色像素沿门的方向依次"倒出"到区域外部，形成有序的像素队列。

Input structure:
- 背景为 black。网格中有若干由 grey 像素围成的封闭矩形房间（边框一像素宽）。
- 每个房间的边框上恰好有一个缺口（一个像素宽的开口），称为"门"。门可以在房间的上、下、左、右任一侧。
- 每个房间内部有若干不同颜色的像素散布在背景上（每个像素颜色可能不同，像素之间不连通）。

Rule:
- 对每个房间，确定门所在的方向 D。
- 将房间内的所有彩色像素按照"距离门最近者优先"的顺序排列：沿方向 D 的反方向度量，距门近的像素排在前面；若距门的垂直距离相同，则按门所在边从左到右（或从上到下）的顺序排列。
- 从门的外侧第一个像素开始，沿方向 D 依次排列这些彩色像素，形成一条直线队列。每个像素紧邻前一个。
- 房间内部变为全背景色（清空），房间边框和门保持不变。

Key insight:
解题者需要先识别每个房间的"门"的位置（边框缺口），推断出"倒出"的方向，然后理解像素的排列顺序是由其在房间内相对于门的空间位置决定的。关键的隐蔽性在于排序规则：不是按颜色或出现顺序，而是按空间距离门的远近——这需要解题者通过多个样例比对才能发现排序依据是几何位置而非其他属性。
</description>
</new_puzzle>

<new_puzzle>
<description>
将网格中由"路径色"连接的节点对象按路径拓扑顺序排列，每个节点对象根据其在路径中的位置（奇数或偶数）执行不同的变换（保持原色或替换为统一色）。

Input structure:
- 背景为 black。网格中有若干小型矩形色块（节点对象），每个节点颜色各不相同（如 red、blue、green、yellow 等），大小为 2x2 或 3x3。
- 节点之间由单像素宽的 orange 路径线段连接（仅水平或垂直延伸），形成一条不分叉的链式路径。路径从一端的节点开始，依次串联所有节点。
- 链的两个端点节点各只有一条 orange 路径连出；中间节点各有两条 orange 路径连入/连出。
- 在网格的某个边缘位置有一个孤立的 magenta 像素，不与任何路径或节点相连。

Rule:
- 沿链从一端追踪到另一端，按访问顺序对节点编号 1、2、3……（从距离 magenta 标记像素更近的端点开始计数）。
- 编号为奇数的节点保持原色不变。
- 编号为偶数的节点将其所有像素替换为 azure 色。
- orange 路径线段在输出中全部移除（变为背景色）。
- magenta 标记像素在输出中也被移除。

Key insight:
解题者需要三层推理：(1) 识别 orange 线段是连接节点的路径而非装饰，理解链式拓扑；(2) 发现 magenta 像素决定了路径的起点方向（距离 magenta 更近的端点为起点）；(3) 发现奇偶位置决定变换方式（保持 vs 替换）。magenta 作为隐式的方向标记很容易被忽视，构成关键的隐蔽层。
</description>
</new_puzzle>
