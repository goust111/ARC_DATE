<description>
根据每个封闭围栏内部的色点颜色，从外部同色图案库中选取匹配图案，将其缩放填充到围栏内部。

Input structure:
- 背景为black。网格中散布着若干由grey像素构成的封闭矩形围栏（宽度为1像素的空心矩形框）。
- 每个围栏的内部恰好有一个单像素色点（颜色各异，如red、blue、green等）。
- 网格的边缘区域（不与任何围栏重叠）放置着若干小型彩色图案（由单一非black非grey颜色绘制的连通形状），每种颜色恰好出现一个图案。

Rule:
- 对每个grey围栏，读取其内部色点的颜色。
- 在边缘区域找到同颜色的小型图案，获取该图案的形状（归一化到其自身的包围盒）。
- 计算围栏内部空间的尺寸（围栏内壁之间的宽和高）。将该图案等比缩放（最近邻缩放），使其恰好填满围栏内部空间。
- 用缩放后的图案替换围栏内部的所有像素（包括覆盖掉原来的色点），图案颜色保持与色点颜色一致。
- 围栏本身（grey框）保持不变。边缘区域的原始小型图案在输出中被擦除为black。

Key insight:
色点不是装饰，而是索引键——它指定了从外部图案库中选取哪个模板；围栏的内部尺寸决定了模板的缩放倍数。解题者需要先建立"颜色→图案"的映射关系，再理解缩放填充的机制。
</description>

<description>
将网格中散落的同色碎片拼回各自颜色对应的目标轮廓框内，碎片的朝向由轮廓框缺口方向决定。

Input structure:
- 背景为black。网格被一条水平的maroon分隔线分为上下两个区域。
- 上方区域包含若干用不同颜色绘制的空心矩形轮廓框（仅边框，内部为black），每个轮廓框的某一侧边框恰好缺失一段（形成一个明显的缺口）。
- 下方区域散落着若干彩色碎片（4-连通的单色连通块），每个碎片的颜色与上方某个轮廓框的颜色相同。每种颜色在下方恰好有一个碎片，在上方恰好有一个轮廓框。

Rule:
- 将每个碎片与同颜色的轮廓框配对。
- 观察轮廓框缺口所在的方向（上、下、左、右）。碎片需要被旋转（0度、90度、180度、270度），使得碎片的"开口侧"（碎片包围盒中像素密度最低的一侧）朝向与轮廓框缺口相同的方向。
- 将旋转后的碎片平移放置到轮廓框的内部中心位置（碎片的包围盒中心对齐轮廓框内部空间的中心）。
- 下方区域的原始碎片被擦除为black。maroon分隔线保持不变。

Key insight:
颜色匹配只完成了第一层配对；第二层推理在于发现轮廓框的缺口方向编码了碎片需要旋转到的朝向——缺口不是残缺，而是朝向指令。
</description>

<new_puzzle>
<description>
每个彩色对象根据其所在象限内的箭头标记方向进行镜像翻转，然后按照对象面积从大到小的顺序依次绘制到中央画布上。

Input structure:
- 背景为black。网格被一条水平azure线和一条垂直azure线精确地分为四个象限。
- 每个象限内包含：恰好一个由单一非black非azure颜色构成的4-连通对象，以及恰好一个由yellow像素构成的箭头标记。
- 箭头标记由3个yellow像素组成：一个中心像素和两个与中心像素相邻的像素，三者构成一个指向上、下、左或右的箭头形状（例如指向右的箭头：中心像素左侧一个像素加上中心像素上方一个像素加上中心像素本身，形成直角折线指向右方）。具体地：指向右=中心+左+上三像素组成的直角折线开口朝右，指向左=中心+右+上三像素组成的直角折线开口朝左，指向上=中心+下+左三像素组成的直角折线开口朝上，指向下=中心+上+左三像素组成的直角折线开口朝下。

Rule:
- 对每个象限中的对象，根据该象限内箭头指向的方向进行翻转：箭头指左或指右则水平翻转，箭头指上或指下则垂直翻转。
- 输出为一个新的画布（大小等于单个象限的内部空间大小，不含azure分隔线），背景为black。
- 按对象面积从大到小的顺序，将翻转后的对象依次绘制到画布上（对象的包围盒中心对齐画布中心）。后绘制的对象覆盖先绘制的对象的重叠像素。

Key insight:
解题包含三层独立推理：（1）识别箭头方向并理解其编码的翻转轴（水平翻转还是垂直翻转）；（2）按面积排序决定绘制顺序；（3）多对象合成到单一画布时的覆盖逻辑。箭头的形状需要从样例中归纳出方向与翻转轴的对应关系。
</description>

<new_puzzle>
<description>
网格中的彩色路径段按"颜色接力"规则首尾相连，形成一条完整路径；每段路径的末端颜色指示下一段路径的颜色。

Input structure:
- 背景为black。网格中有若干条由不同颜色绘制的短路径段（每段为同一颜色的4-连通像素链，宽度为1像素，长度3到6像素，形状为直线或L形）。
- 每条路径段的两个端点像素中，恰好有一个端点被替换为另一种颜色的单像素标记（该标记颜色与该路径段本身颜色不同）。
- 所有路径段恰好可以按如下规则串成一条链：某段路径的标记颜色等于链中下一段路径的主体颜色。链的第一段路径的主体颜色不被任何其他路径段的标记颜色引用；链的最后一段路径的标记颜色不对应任何路径的主体颜色。

Rule:
- 识别链的起始路径段（即其主体颜色不被任何其他路径段的标记颜色引用的那一段）。
- 沿链的顺序依次连接路径段：将每段路径平移，使其非标记端点紧邻前一段路径的标记端点（标记端点和非标记端点在四方向上相邻）。
- 平移后的所有路径段的像素统一重新着色为blue。标记像素也统一着色为blue。
- 输出为包含这条完整拼接路径的最小包围盒（背景为black）。

Key insight:
每条路径段的异色标记端点不是噪声，而是链接指针——标记颜色指向下一段路径的主体颜色，形成一条隐式链表。解题者需要先识别这种"颜色引用"关系建立顺序，再执行空间上的首尾拼接。
</description>

<description>
在包含多个"房间"的网格中，每个房间内的种子像素按照房间墙壁的内轮廓形状向内生长，生长层数等于房间内种子像素的数量。

Input structure:
- 背景为black。网格中由grey像素构成若干封闭的不规则"房间"（grey像素形成宽度为1的连通墙壁，将网格分割成若干封闭区域）。
- 每个房间内部散布着若干同色的种子像素（每个房间内的种子像素颜色相同，但不同房间的种子颜色可以不同）。种子像素不与grey墙壁相邻。

Rule:
- 对每个房间，统计其内部种子像素的数量N。
- 从该房间的墙壁内表面开始，向内逐层生长（类似洋葱剥皮的逆过程）：第1层是所有与grey墙壁四方向相邻的black内部像素，第2层是所有与第1层四方向相邻且尚未着色的black内部像素，以此类推。
- 恰好生长N层，将这N层像素全部着色为该房间种子像素的颜色。
- 种子像素本身在输出中被擦除为black（仅保留生长出的层）。
- grey墙壁保持不变。超过N层的内部区域保持black。

Key insight:
种子像素的空间位置是无关的——只有种子的数量和颜色有意义。数量决定了墙壁内表面向内渲染的层数，颜色决定了渲染色。这需要解题者克服"种子位置有意义"的直觉偏见，发现真正的驱动变量是计数值。
</description>

<description>
网格中每个彩色条带的宽度编码了一个"采样步长"，用该步长从同行的数据带中等间距采样像素，组成输出图案。

Input structure:
- 背景为black。网格分为左右两个区域，由一列grey分隔线隔开。
- 左侧区域包含若干水平彩色条带（每条是一行连续的同色非black像素，颜色各异）。
- 右侧区域包含同样数量的水平条带，每条由交替颜色的像素组成（例如red与blue交替排列），形成一条"数据带"。每条数据带恰好与左侧的某条彩色条带处于同一行。

Rule:
- 将左侧每条彩色条带与同行的右侧数据带配对。
- 左侧条带的像素宽度（长度）为S，作为采样步长。
- 从右侧数据带的第一个像素开始，每隔S个像素取一个像素（即取第1个、第1+S个、第1+2S个像素，以此类推），采样到的像素保留，其余像素设为black。
- 输出仅包含右侧区域（不含grey分隔线和左侧区域），其中未被采样的像素变为black，被采样的像素保持原色。

Key insight:
左侧单色条带看似只是颜色标签，但其真正作用是通过宽度编码采样间隔。解题者需要将"条带长度"这一视觉属性与"等间距采样"这一操作建立映射——条带的颜色是干扰项，宽度才是功能量。
</description>

<description>
将网格中的多个形状按照各自包围盒内grey标记像素数量所指示的堆叠层级，投影合成到一个统一画布上。

Input structure:
- 背景为black。网格中有若干个空间上不重叠的单色4-连通形状，每个形状由一种主体颜色绘制。
- 每个形状的包围盒内（形状像素之外的black区域中）恰好有1到4个grey像素，这些grey像素被称为"层级标记"。
- 所有形状的包围盒大小完全相同。

Rule:
- 统计每个形状包围盒内grey像素的数量K（K的范围为1到4）。K代表该形状在最终合成中的绘制层级：K=1最先绘制（最底层），K=4最后绘制（最顶层）。
- 创建一个与单个包围盒等大的black输出画布。
- 将所有形状归一化到各自包围盒的局部坐标系后，按K值从小到大的顺序依次绘制到输出画布上。后绘制的形状覆盖先绘制的形状在相同位置的像素。

Key insight:
grey像素既不是形状的一部分，也不是位置标记——它们的数量构成了一个离散的"深度标签"，决定了多个同尺寸形状在合成叠加时的前后遮挡关系。解题者需要先发现grey像素数量的排序意义，再理解空间叠加的覆盖规则。
</description>
</new_puzzle>
