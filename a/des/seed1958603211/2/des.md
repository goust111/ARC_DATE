<description>
根据色带图例中条纹的排列顺序，对网格中散落的嵌套同心矩形环框架进行分层填色。

Input structure:
- 背景色（bg）填充大部分网格。
- 网格顶部有一个水平色带图例区域，由若干紧邻的彩色竖条纹组成（每种颜色占一列宽），条纹颜色各不相同，从左到右排列。
- 网格其余区域散布着若干个由同一颜色（非bg、非图例中出现的颜色）绘制的嵌套同心矩形环框架。每个框架由若干层同心矩形环组成，最外层环最大，向内逐层缩小，环与环之间间隔一个像素宽的bg间隙。每个框架的环层数不同。

Rule:
- 读取图例色带中从左到右的颜色序列。
- 对于每个嵌套环框架，从最外层环开始，依次将第 1 层环重新着色为色带序列的第 1 个颜色，第 2 层环着色为第 2 个颜色，以此类推。
- 如果框架的环层数少于色带颜色数，则只使用色带前几个颜色。如果环层数多于色带颜色数，则色带颜色循环使用。
- 环之间的 bg 间隙保持不变。

Key insight: 色带图例提供了一个有序的颜色映射序列，环的空间嵌套层级（从外到内）与色带的线性顺序（从左到右）形成对应关系；解题者需要先识别出"同心环层级"这一非显然的空间结构，再将其与图例的线性序列进行匹配。
</description>

<description>
将网格中被墙壁分隔的多个房间按照门的连通关系进行传染式染色，颜色由种子房间向外逐层传播并在每层发生颜色变异。

Input structure:
- 背景色（bg）为 black。墙壁颜色（grey）形成正交线段，将网格分割成若干封闭矩形房间。
- 每面墙上恰好有一个单像素的缺口作为"门"，连通相邻的两个房间。
- 恰好有一个房间内部填充了一种非bg非grey的种子颜色（如 red）；其余房间内部全部为 bg。
- 网格边缘有一个小的颜色变换图例：一列纵向排列的彩色像素，从上到下依次列出颜色 C1、C2、C3……

Rule:
- 种子房间为第 0 层。通过门与第 0 层房间直接相邻的房间为第 1 层，与第 1 层直接相邻且尚未被访问的房间为第 2 层，以此类推（类似广度优先的层级扩散）。
- 第 0 层房间保持种子颜色不变。
- 第 k 层（k>=1）的房间内部填充图例中第 k 个颜色（图例从上到下索引为 1, 2, 3…）。
- 如果层数超过图例长度，则停止填充，剩余更深层的房间保持 bg。
- 门（墙壁缺口）本身不着色，保持 bg。墙壁保持 grey 不变。

Key insight: 解题者需要完成两层非平凡推理——首先从墙壁缺口推断房间之间的连通拓扑结构（哪些房间通过门相邻），然后发现颜色按照距种子房间的"房间跳数"逐层变化，而图例提供了层级到颜色的映射。
</description>

根据标记像素所在对象的轮廓形状，从形状模板库中选取匹配模板，并将模板图案印入该对象内部。

Input structure:
- 背景色（bg）填充大部分网格。
- 网格左侧有一个模板库区域，由水平的 grey 分隔线划分为若干格子。每个格子包含两部分：左半部分是一个小的轮廓形状（用某种颜色绘制的空心边框，内部为 bg），右半部分是一个与该轮廓尺寸相同的填充图案（使用多种颜色绘制的实心图案）。
- 网格右侧散布着若干个较大的彩色实心对象（4-连通区域），每个对象的外轮廓形状恰好是模板库中某个轮廓形状的整数倍放大版本。
- 每个大对象内部恰好有一个单像素标记点（颜色与对象本身不同，也不是 bg），标记该对象需要被处理。

Rule:
- 对每个带标记的大对象，提取其外轮廓形状。
- 在模板库中找到轮廓形状与之匹配的条目（大对象的轮廓是模板轮廓的等比放大）。
- 将该条目右半部分的填充图案按相同的放大比例缩放，然后替换大对象的内部像素（覆盖标记点和原有颜色）。
- 大对象的外轮廓保持原色不变，仅内部被图案替换。
- 无标记的对象保持不变。

Key insight: 解题者需要三层推理——首先识别模板库的"轮廓-图案"配对结构，然后发现大对象的轮廓是某个模板轮廓的缩放版本从而建立匹配关系，最后将对应的填充图案按相同比例放大后植入对象内部。
</description>

<description>
根据箭头指向，将源区域的图案沿箭头方向投影到目标框架中，投影过程中图案需依据箭头颜色进行指定的几何变换。

Input structure:
- 背景色（bg）填充大部分网格。
- 网格中有若干个矩形空心框架（用 grey 绘制的单像素宽矩形边框，内部为 bg），以及若干个填有彩色图案的小矩形源区域（无边框，直接由彩色像素构成）。
- 每个源区域旁边紧贴着一个由 3 个同色像素组成的箭头，箭头形状为一字型指向某个正方向（上/下/左/右）：箭头由一个像素的头部和两个像素的尾部组成（例如，向右的箭头为竖排两像素尾部 + 右侧一像素头部，形成"▶"形状）。
- 箭头的颜色有两种可能：red 或 blue。
- 每个箭头指向的方向上，沿直线最终会遇到一个空心框架。

Rule:
- 沿箭头方向，将源区域的图案投影（平移复制）到箭头所指的空心框架内部。图案对齐方式：图案从框架靠近箭头来源的那一侧边缘开始放置。
- 如果箭头颜色为 red，则图案在投影前需要沿箭头方向的垂直轴进行镜像翻转。
- 如果箭头颜色为 blue，则图案在投影前需要旋转 180 度。
- 框架的 grey 边框保持不变。源区域和箭头在输出中被擦除（替换为 bg）。

Key insight: 解题者需要同时发现两个隐藏规则——箭头方向决定投影目标和对齐方式，箭头颜色编码了几何变换类型（red=镜像，blue=旋转）。两条规则必须同时正确归纳才能得到正确输出。
</description>

<description>
在网格中，每个对象根据其内部"种子色块"的数量决定膨胀层数，膨胀时每一层使用与该层距离对应的种子色块颜色。

Input structure:
- 背景色（bg）填充大部分网格。
- 网格中散布着若干个由同一颜色（如 grey）绘制的不规则形状对象（4-连通区域）。
- 每个 grey 对象内部嵌入了若干个单像素的彩色"种子色块"（颜色各不相同，非 bg 非 grey），不同对象内部的种子色块数量不同（范围在 1 到 4 之间）。

Rule:
- 对每个 grey 对象，数出其内部种子色块的数量 N。
- 将该对象向外膨胀 N 层（每层为原轮廓向外扩展 1 个像素的环带，仅覆盖 bg 像素，不覆盖其他对象）。
- 膨胀的第 1 层（最内圈，紧贴原轮廓）着色为对象内部最上方（行号最小）的种子色块的颜色；第 2 层着色为第二上方的种子色块的颜色；以此类推。
- 原始 grey 对象保持不变（包括其内部的种子色块像素也保持原色）。
- 如果膨胀区域与另一个对象的膨胀区域重叠，则先处理种子数量更多的对象（其膨胀优先覆盖）。

Key insight: 解题者需要发现三层嵌套规则——种子色块的数量决定膨胀层数，种子色块在对象内部的空间位置（上下排列顺序）决定各层的颜色分配，而多对象膨胀冲突时的优先级由种子数量这一同一属性二次利用来裁决。
</description>

<description>
将网格中散落的碎片拼入由分隔线划定的目标槽位中，拼入规则由碎片边缘的彩色接头与槽位边缘的彩色插口的颜色匹配决定。

Input structure:
- 背景色（bg）填充大部分网格。
- 网格被 maroon 颜色的完整行和完整列分割成若干个大小相同的矩形槽位（类似九宫格或更大的均匀划分）。
- 部分槽位内部为空（全 bg），部分槽位的边缘（紧贴 maroon 分隔线内侧）有单像素的彩色"插口"标记（如 red、blue、green 等），每个槽位每条边最多一个插口。
- 网格的一个角落区域（与槽位网格分开）放置着若干个形状各异的小碎片。每个碎片由一种统一的填充色构成，碎片的某些边缘像素被替换为彩色"接头"像素（颜色与插口颜色相同的那组颜色）。

Rule:
- 每个碎片恰好对应一个空槽位。匹配方式：碎片边缘的接头颜色必须与目标槽位对应边上的插口颜色一一对应（即碎片左边缘的接头对应槽位左边的插口，以此类推）。
- 碎片可能需要旋转（0度/90度/180度/270度）才能使接头与插口对齐。正确的旋转角度是使所有接头与对应插口颜色匹配的唯一旋转。
- 将碎片以正确旋转角度放入匹配的槽位中，碎片在槽位内居中放置。
- 已有内容的槽位保持不变。碎片原始位置被擦除为 bg。

Key insight: 解题者需要先发现"接头-插口"的颜色匹配机制来确定碎片与槽位的配对关系，然后发现旋转是通过让碎片各边的接头颜色与槽位各边的插口颜色对齐来唯一确定的——这两层规则共同约束了碎片的目标位置和朝向。
</description>

<description>
网格中的彩色路径段根据交叉点处的叠色规则合并颜色，最终将所有路径交叉点染为混合色。

Input structure:
- 背景色（bg）为 black。
- 网格中有若干条单像素宽的正交路径（水平或垂直直线段），每条路径由一种纯色绘制（如 red、blue、green、yellow 等，各路径颜色不同）。
- 部分路径在某些像素位置交叉（即同一位置属于一条水平路径和一条垂直路径）。在输入中，交叉点处显示的是其中一条路径的颜色（后绘制的覆盖了先绘制的）。
- 网格边缘有一个颜色混合图例：若干对小色块并排放置，每对由两个输入颜色和一个结果颜色组成（例如 red 和 blue 旁边放一个 magenta 色块，表示 red+blue=magenta）。

Rule:
- 识别所有路径交叉点：即同时被一条水平路径和一条垂直路径经过的像素位置（通过沿水平和垂直方向延伸来判断路径归属）。
- 对每个交叉点，确定交叉的两条路径的颜色。
- 查阅颜色混合图例，找到这两种颜色对应的混合结果色。
- 将交叉点像素重新着色为混合结果色。
- 非交叉点的路径像素和 bg 保持不变。

Key insight: 输入中的交叉点信息是被遮盖的（只能看到一种颜色），解题者需要先通过路径的线性延伸关系推断出哪些位置是真正的交叉点以及交叉的是哪两种颜色，然后利用图例中的混合规则确定输出颜色——路径归属推断和颜色混合查表构成两层独立的推理。
</description>
</new_puzzle>
