Input structure:

- 导轨的一个端点处紧贴着一个由 grey 像素构成的小型矩形图案块（2×2 或 3×3 的非对称图案）。

Rule:
- 对每条导轨，数出该导轨上 yellow 中继站的数量 N。
- 将该导轨端点处的 grey 图案块沿导轨方向平移 N 个格子的距离。
- 平移后的图案块用该导轨的颜色重绘（grey 变为导轨颜色）。
- 原始位置的图案块被擦除（变为 black）。导轨本身和中继站保持不变。

Key insight: 中继站数量编码了传送距离，导轨颜色决定了图案块的最终着色——解题者需要先发现"数中继站=移动步数"这一隐含映射，再发现"导轨颜色→块颜色"的重绘规则。

Key insight: 箭头的几何结构同时编码了三个信息——朝向（由 V 形尖端位置决定）、射线颜色（箭头自身颜色）和射线长度（主体像素数）。解题者必须先正确解析箭头结构才能执行射线绘制。

Input structure:
- 网格被 grey 分隔线（完整的行或列）划分为若干大小相同的矩形子区域（例如 2×2 或 3×2 的排列）。
- 每个子区域内包含一个由某种颜色构成的图案（图案可以有 black 背景部分），不同子区域的图案颜色各不相同。
- 在网格的右下角有一个与子区域同尺寸的小型参考面板，面板内用不同颜色的像素按从左到右、从上到下的阅读顺序排列成一列，每个像素的颜色对应一个子区域中图案的主色。

Rule:
- 从参考面板中读取图层叠放顺序：面板中按照从左到右、从上到下的阅读顺序排列的颜色，最先出现的颜色对应最底层，最后出现的颜色对应最顶层。
- 通过颜色匹配找到每个子区域对应的图层深度。
- 输出一个与子区域同尺寸的网格：按照从底到顶的顺序依次将每个子区域的图案叠放上去，非 black 像素遮挡下方图层。

Key insight: 解题者需要先在角落发现参考面板并理解其阅读顺序编码了图层深度，再通过颜色匹配确定每个子区域的叠放层级，最后执行多层合成——三步推理环环相扣。
</description>

<description>
根据封闭区域的边框颜色在顶行颜色序列中的先后关系决定区域之间的填充色传播方向，将有色区域的填充色单向传递给空白区域。

Input structure:
- 背景色为 black。网格中有若干互不重叠的矩形封闭区域，每个区域由一种颜色的边框围成（边框为 1 像素宽的完整矩形环）。
- 每个区域内部填充着另一种颜色（与边框色不同），或为 black（空区域）。
- 在网格的顶部一行有一条由若干颜色像素排成的水平序列（"颜色链"），例如从左到右依次为 red、blue、green、yellow，表示这些颜色构成一个有向链，排在前面的颜色指向排在后面的颜色。颜色链中每种颜色恰好出现一次，且恰好对应网格中所有出现过的边框颜色。

Rule:
- 颜色链定义了边框颜色之间的传播方向：如果颜色 A 在链中排在颜色 B 之前（A 在 B 左边），则边框色为 A 的区域可以向边框色为 B 的区域"传播"填充色。
- 传播规则：对于链中每一对相邻颜色 A→B，如果边框色为 A 的区域内部有非 black 填充，而边框色为 B 的区域内部为 black，则将 A 的内部填充色复制到 B 的内部。
- 如果 B 已有非 black 填充，则不发生传播（不覆盖）。传播沿链的方向依次进行（先处理链中靠前的对，再处理靠后的对），使得填充色可以沿链条级联传递。
- 边框和颜色链本身保持不变。

Key insight: 解题者需要先识别顶行的颜色序列是一个有向链，再根据链中的先后关系确定哪个区域的填充色"流向"哪个区域——颜色链既不是装饰也不是图例，而是一个编码传播方向的拓扑指令。级联传播意味着一个空区域可能通过中间区域间接获得填充色。
</description>
</new_puzzle>

<description>
将散落的彩色线段按长度分组，同组线段拼成封闭矩形框，框的填充色由该组线段围绕区域内的唯一单色种子像素决定。

Input structure:
- 背景色为 black。网格中散布着若干水平和垂直的彩色线段（每条线段为同一颜色的连续像素，长度 ≥ 2）。
- 线段颜色各异，但同一长度的线段恰好有四条（两条水平、两条垂直），它们可拼成一个矩形框。
- 每组四条同长线段所围成的大致区域内（取四条线段中心的平均位置作为区域中心）恰好有一个孤立的单色像素（颜色与该组线段颜色不同），称为"填充种子"。

Rule:
- 按长度对线段分组，每组恰好四条（两条水平、两条垂直）。
- 对每组，用这四条线段拼成一个矩形框：两条水平线段作为上下边，两条垂直线段作为左右边，矩形框居中放置于这四条线段中心的平均位置（四舍五入到最近整数格点）。
- 找到该组对应的填充种子像素，用其颜色填满矩形框内部（不含边框线段本身）。
- 线段本身构成矩形框的边，保留原色；填充种子像素被填充色覆盖。原始散落位置的线段被擦除。

Key insight: 解题者需要先发现"长度相同的线段属于同一组"这一分组规则，再理解"四条线段拼框"的几何构造方式，最后发现填充种子像素隐藏在线段围成的区域中——三层推理依次为分组、构造、着色。
</description>

<description>
在棋盘格图案中恢复被擦除区域的颜色，同时利用边缘色带中异色像素的数量决定恢复后图案的整体平移量。

Input structure:
- 网格大部分被两种颜色（如 red 和 blue）构成的棋盘格图案覆盖（相邻格子颜色交替），其中若干连通的矩形区域被擦除为 black（形成"破洞"）。
- 网格的左侧边缘有一条垂直的 green 色带（1 像素宽），色带中有若干像素被替换为 yellow。
- 网格的顶部边缘有一条水平的 green 色带（1 像素宽），色带中同样有若干像素被替换为 yellow。

Rule:
- 第一步（恢复）：根据棋盘格的奇偶交替规律，将所有 black 破洞区域中的每个像素恢复为正确的棋盘格颜色（与相邻已知格子的颜色交替）。
- 第二步（平移）：数出左侧色带中 yellow 像素的数量 dy，数出顶部色带中 yellow 像素的数量 dx。将恢复后的完整棋盘格图案向右平移 dx 格、向下平移 dy 格。
- 输出网格尺寸与输入相同（不含边缘色带），移出边界的部分裁剪，移入的空白部分填 black。边缘色带不出现在输出中。

Key insight: 棋盘格恢复是第一层视觉推理（利用奇偶交替规律填补破洞），色带中的异色像素计数编码平移量是第二层隐蔽推理——两层机制相互独立但必须依次完成。
</description>
</new_puzzle>
