<new_puzzle>
根据对象的轮廓形状在颜色图例中查找匹配，然后用图例内部的填充图案覆盖对象内部。

Input structure:
- 背景为黑色。网格中散布着若干灰色（Grey）填充的封闭形状（由灰色像素构成的4-连通区域），形状各异（如L形、T形、正方形、十字形等），每个形状的大小不超过6×6。
- 网格边缘附近有若干"图例块"：每个图例块由一圈彩色边框（如红色、蓝色、绿色等，各不相同）围成，边框内部填有由该边框颜色以外的多种颜色组成的小图案。
- 每个图例块的边框形状（即边框像素去掉内部填充后的轮廓）恰好与某个灰色形状的轮廓在旋转和翻转意义下同构。

Rule:
- 对每个灰色形状，计算其轮廓（即该形状的8-邻域边界像素集合的相对形状）。
- 在所有图例块中找到边框轮廓与该灰色形状轮廓在旋转/翻转下匹配的图例块。
- 确定将图例块的边框对齐到灰色形状所需的旋转/翻转变换。
- 将同样的变换应用到图例块内部的填充图案上，然后用变换后的图案替换灰色形状内部的灰色像素。灰色形状的轮廓像素变为图例块的边框颜色。
- 图例块本身在输出中被擦除（变为背景色）。

Key insight: 必须先通过轮廓形状匹配找到对应的图例，再推断出正确的旋转/翻转方向，最后才能将图案正确地"印"入形状内部——轮廓匹配和变换推断是两层独立的非平凡推理。
</new_puzzle>

沿彩色路径传播信号，信号在交叉点根据路径颜色的优先级选择分支方向，最终在路径末端生成对应长度的标记。

Input structure:
- 背景为黑色。网格中有若干条由不同颜色绘制的单像素宽路径（如红色、蓝色、绿色），路径沿正交方向延伸。
- 某些路径在交叉点处重叠（交叉像素同时属于两条路径，显示为其中一种颜色）。
- 网格的一条边（如左边缘）上有若干黄色（Yellow）"信号源"像素，每个信号源恰好与一条路径的端点相邻。
- 每条路径的另一端（远离信号源的末端）位于网格内部，末端像素旁边有一个空的矩形区域（全为背景色），大小为3行×N列（N待确定）。

Rule:
- 从每个黄色信号源出发，信号沿相邻的路径传播。信号沿路径的唯一方向前进（路径无分叉，宽度为1）。
- 当信号到达一个交叉点时，交叉点处有两条不同颜色的路径交汇。信号选择与当前所在路径颜色不同的那条路径继续前进（即"换色前进"）。
- 记录信号从起点到路径末端经过的交叉点数量K。
- 在路径末端旁的空矩形区域中，从左到右填入K个橙色（Orange）像素（填在矩形的中间行），形成一个长度为K的水平条。

Key insight: 信号在每个交叉点"换色"前进，解题者需要追踪信号的完整路径并理解交叉点处的换色规则，然后将经过的交叉点数量转化为末端标记的长度——路径追踪和计数转换是两层推理。
</new_puzzle>

将网格中的封闭区域按嵌套层级交替填色，然后根据最内层的颜色决定整个嵌套结构的旋转方向。

Input structure:
- 背景为黑色。网格中有若干由灰色（Grey）像素绘制的嵌套封闭矩形框（同心矩形）。每组嵌套结构由2到4层矩形框组成，框之间间隔至少1个像素的黑色间隙。
- 每组嵌套结构的最内层矩形框内部有一个单像素的彩色标记（红色或蓝色）。
- 每组嵌套结构整体不与其他组重叠，之间有足够的黑色间隙。

Rule:
- 对每组嵌套矩形结构，从最外层到最内层编号为第1层、第2层、……。
- 将奇数层（第1、3层）的矩形框像素重新着色为绿色（Green），偶数层（第2、4层）重新着色为黄色（Yellow）。
- 框与框之间的间隙区域（黑色环带）也按层级交替填色：第1层框与第2层框之间的间隙填为Azure，第2层框与第3层框之间的间隙填为Magenta，以此交替。
- 最后检查最内层的彩色标记：若为红色，将整组嵌套结构（包括所有框和间隙）顺时针旋转90°后放回原位；若为蓝色，保持不旋转。
- 旋转以该嵌套结构的外接矩形中心为旋转中心。

Key insight: 解题者需要先识别嵌套层级并理解交替填色规则（第一层推理），然后发现最内层标记颜色决定整体旋转方向（第二层推理），两层规则需要分别从样例中归纳。

识别网格中散落的碎片，将属于同一原始图案的碎片拼合复原，拼合依据是碎片边缘的锯齿接口互补匹配。

Input structure:
- 背景为黑色。网格中散布着若干彩色碎片（4-连通区域），每个碎片由同一种非黑颜色的像素组成。
- 碎片来自若干个被切割的原始矩形图案。每个原始图案被沿一条锯齿线（仅沿正交方向走的阶梯形折线）切成恰好两个碎片。
- 同一原始图案的两个碎片颜色相同；不同原始图案使用不同颜色。
- 每个碎片在网格中被平移到了随机位置（无旋转、无翻转），碎片之间互不重叠。

Rule:
- 找出所有颜色相同的碎片对（每种颜色恰好出现两个碎片）。
- 对每对碎片，检查它们的锯齿边缘（即碎片边界中非矩形外框的那一侧）：两个碎片的锯齿边缘互为镜像互补。
- 将两个碎片沿锯齿边缘拼合，使它们恰好组成一个完整的实心矩形。拼合方向由锯齿边缘的朝向决定（锯齿沿垂直方向则左右拼合，沿水平方向则上下拼合）。
- 输出网格中，每个拼合后的矩形放置在其两个碎片中靠左上方那个碎片的原始位置，另一个碎片从原位置擦除。

Key insight: 解题者需要先通过颜色配对找到碎片组合（第一层），再通过分析锯齿边缘的互补形状确定拼合方式和方向（第二层）——颜色配对是显然的，但锯齿互补匹配和拼合定位需要空间推理。
</new_puzzle>

<new_puzzle>
根据网格中"种子"像素的颜色和周围墙壁的形状，生长出与墙壁开口方向一致的彩色枝条，枝条在遇到其他枝条时融合变色。

Input structure:
- 背景为黑色。网格中有若干由灰色（Grey）像素构成的小型U形或L形墙壁（每个墙壁占据3到5个像素，形成半封闭结构）。
- 每个墙壁的开口内（凹陷处）有一个彩色"种子"像素（颜色各不相同，如红色、蓝色、绿色、黄色等）。
- 墙壁的开口朝向四个正交方向之一（上、下、左、右），由墙壁缺失的那一侧决定。

Rule:
- 从每个种子像素出发，沿墙壁开口方向生长一条单像素宽的枝条（即逐格向开口方向延伸），枝条颜色与种子颜色相同。
- 枝条持续生长，直到遇到网格边界或另一条枝条的像素。
- 当两条枝条相遇时（一条枝条的下一步将落在另一条枝条已占据的像素上），两条枝条都停止生长。相遇点的像素（已被先到达的枝条占据）变为Maroon色。同时，较短的那条枝条整体变为较长枝条的颜色。若两条等长，则都变为Orange色。
- 未与任何枝条相遇的枝条保持原色不变。
- 灰色墙壁和种子像素在输出中保持不变。

Key insight: 解题者首先需要从墙壁形状推断开口方向以确定枝条生长方向（第一层推理），然后理解枝条碰撞时的融合变色规则——相遇点标记为Maroon，短枝条被长枝条"吞并"变色（第二层推理），最后处理等长的特殊情况（第三层推理）。
</new_puzzle>

<new_puzzle>
在网格中找到被遮挡的重叠矩形，根据重叠关系确定绘制顺序，然后将每个矩形向其未被遮挡的方向平移分离。

Input structure:
- 背景为黑色。网格中央区域有若干彩色实心矩形相互重叠堆叠。每个矩形使用不同的颜色（如红色、蓝色、绿色、黄色等）。
- 重叠区域显示最上层矩形的颜色（即后绘制的遮挡先绘制的）。
- 在网格的四条边各有一个小型彩色标记像素（单像素），颜色与某个矩形对应，标明该矩形应被平移到的目标边。

Rule:
- 首先重建每个矩形的完整形状：被遮挡的矩形可以通过其可见的边缘片段推断出完整的矩形尺寸（至少有两条相邻边的部分可见）。
- 确定堆叠顺序：若矩形A的部分区域被矩形B覆盖，则B在A之上。
- 对每个矩形，找到网格边缘上与其颜色匹配的标记像素。将矩形沿垂直于该边的方向平移，直到矩形的对应边紧贴该网格边缘。
- 平移后的矩形按原始堆叠顺序重新绘制（底层先画，顶层后画），保持遮挡关系。
- 边缘标记像素在输出中被擦除。

Key insight: 解题者需要先从部分可见的边缘重建被遮挡矩形的完整形状（第一层推理），再通过边缘标记确定每个矩形的平移目标方向（第二层推理），最后保持正确的堆叠绘制顺序使遮挡关系一致（第三层推理）。
</new_puzzle>

<new_puzzle>
将网格中的彩色线段视为"指针"，每个指针指向的目标对象获得该指针的颜色作为边框，目标对象原有颜色决定指针末端生成的装饰符号。

Input structure:
- 背景为黑色。网格中有若干个小型实心正方形对象（3×3大小），每个正方形由单一颜色填充（如红色、绿色、蓝色等，各不相同）。
- 网格中另有若干条彩色直线段（水平或垂直，长度3到8像素，宽度1像素），每条线段的颜色与某个正方形对象的颜色不同。
- 每条线段的一端靠近网格边缘或空旷区域（"尾端"），另一端指向某个正方形对象且与该对象的某一面在同一行或同一列上（"指向端"），两者之间有黑色间隙。

Rule:
- 判断每条线段的指向：线段沿其延伸方向，从尾端向指向端看去，在指向方向上最近的正方形对象即为该线段的目标对象。
- 为目标对象添加一圈1像素宽的边框，边框颜色等于指向它的线段的颜色。若有多条线段指向同一对象，使用距离该对象最近的线段的颜色。
- 在每条线段的尾端（远离目标的那端）生成一个由目标对象原始填充颜色绘制的十字标记（"+"形，5个像素：中心+上下左右各1个像素）。
- 线段本身在输出中保持不变。

Key insight: 解题者先要判断每条线段的指向方向和对应的目标对象（第一层推理），再理解颜色的双向交换逻辑——线段颜色给目标当边框，目标颜色给线段尾端当装饰（第二层推理），形成一种间接的颜色映射关系。
</new_puzzle>
