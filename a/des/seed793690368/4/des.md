- `description`：根据封闭区域内"种子"像素的颜色，在区域边框上找到对应颜色的缺口，然后从种子位置向缺口方向生长出一条路径；路径的长度等于该封闭区域内背景像素的数量。
- `Input structure`：
  - 背景色 = 最常见颜色（black）。
  - 网格中有若干由单一颜色（如 green）绘制的封闭矩形边框，每个边框恰好有一个缺口（边框上缺失一个像素的位置），缺口像素被染成另一种颜色（如 red、blue 等），每个边框的缺口颜色各不相同。
  - 每个封闭矩形内部恰好有一个"种子"像素，种子的颜色与该矩形边框上缺口的颜色相同。种子不位于矩形正中心，而是偏向某一侧。
- `Rule`：
  - 对每个矩形，识别边框上的缺口颜色，找到内部与缺口同色的种子像素。
  - 统计该矩形内部背景像素的总数（不含种子本身），记为 N。
  - 从种子像素出发，沿种子指向缺口的轴向方向（水平或垂直），穿过缺口向矩形外部延伸，绘制一条长度为 N 个像素的直线，颜色与种子/缺口相同。
  - 种子像素保留，矩形边框保留，缺口处恢复为背景色。
- `Key insight`：缺口颜色是种子与出口的配对键；封闭区域内的空白面积（背景像素数）转化为射出路径的长度——需要先完成颜色配对，再完成面积到长度的映射，两步推理缺一不可。
</new_puzzle>

- `description`：在网格中，每个彩色"信号塔"向四个正方向发射射线，射线遇到"镜面"像素后反射 90° 继续传播；最终射线交汇的空白像素被染成特殊颜色。

  - 网格中有若干单像素的"信号塔"，每个塔有不同颜色（如 red、blue、green 等）。
  - 网格中还散布着若干 yellow 单像素作为"镜面"。
  - 镜面像素的放置位置保证：信号塔发出的射线会恰好经过某些镜面。
- `Rule`：
  - 每个信号塔同时向上、下、左、右四个方向发射射线（用信号塔自身颜色绘制），射线沿直线传播直到到达网格边界或碰到另一个信号塔。
  - 当射线经过一个 yellow 镜面像素时，射线在该像素处分裂为两条垂直于原方向的射线（即左转和右转），原方向的射线终止于镜面处。镜面像素本身保持 yellow 不变。

  - 如果同一颜色的射线交叉，该像素只显示该颜色。
  - 射线不能穿过信号塔或其他已被射线占据的像素（先到先得，但交叉点例外——交叉点始终变为 magenta）。
- `Key insight`：解题需要三层推理——首先识别信号塔和镜面的角色，其次理解镜面的 90° 分裂机制（而非简单反射），最后发现不同颜色射线的交叉规则（交叉 → magenta）。镜面造成的路径改变使得交汇位置无法一眼看出。

- `description`：网格中多个彩色环形框架按照"嵌套深度"决定输出时的填充颜色——最内层环填充自身颜色，外层环填充其所包含的最小子环的颜色。
- `Input structure`：
  - 背景色 = black。
  - 网格中有若干不同颜色的矩形环形框架（每个框架是一个单像素宽的矩形环，仅由边框像素构成，内部为背景色）。
  - 这些环形框架存在嵌套关系：某些小环完全位于大环的内部，形成多层嵌套结构（最多 3-4 层）。也有一些环彼此不嵌套，独立存在。
  - 每个环的颜色各不相同（如 red、blue、green、orange 等）。
- `Rule`：
  - 识别所有环形框架及它们的嵌套层级关系。
  - 对于不包含任何其他环的最内层环（叶子环）：用该环自身的颜色填充其内部区域（将内部背景像素全部染成环框颜色）。
  - 对于包含子环的环：用其直接子环中面积最小的那个子环的颜色来填充本环内部的背景区域（不覆盖子环本身及子环内部已填充的内容）。
  - 独立环（不嵌套于任何环内，也不包含任何环）：不做任何填充，保持原样。
- `Key insight`：解题者首先需要识别环之间的嵌套包含关系（第一层推理），然后发现填充颜色不是取自环本身而是取自其最小子环的颜色（第二层推理）。独立环不填充这一例外增加了规则的隐蔽性——必须区分"叶子环"、"父环"和"独立环"三种角色。
</new_puzzle>

<new_puzzle>
- `description`：网格中的彩色箭头指向目标对象，箭头的颜色决定对目标执行的变换类型；多个箭头可以指向同一目标，变换按从外到内的距离顺序依次叠加。
- `Input structure`：
  - 背景色 = black。
  - 网格中有若干小型灰色（grey）实心矩形色块（3×3 或 4×4），每个色块内部有一些像素被挖去形成不对称图案（如 L 形、T 形），以便在旋转和翻转后产生可区分的结果。
  - 网格中还有若干"箭头"标记。每个箭头由 3 个同色像素组成：一个"头部"像素和两个"尾部"像素。尾部两像素与头部像素相邻，排列方式表示方向——向右箭头为竖排两像素（尾部，上下排列）加右侧一像素（头部）；向左箭头为竖排两像素（尾部）加左侧一像素（头部）；向下箭头为横排两像素（尾部，左右排列）加下方一像素（头部）；向上箭头同理。
  - 每个箭头的颜色是 red、blue 或 green 之一。箭头的头部像素沿其指向方向延伸，在同一行或同一列上能对准某个灰色色块。
- `Rule`：
  - 每个箭头指向其头部方向上最近的灰色色块（沿箭头方向做射线检测，找到第一个碰到的灰色色块）。
  - 箭头颜色编码变换类型：red = 将目标色块水平翻转（左右镜像）；blue = 将目标色块顺时针旋转 90°；green = 将目标色块的最外一圈像素颜色改为 green，内部保持 grey。
  - 如果多个箭头指向同一个色块，按箭头到色块的距离从远到近的顺序依次施加变换（远的箭头的变换先执行，近的后执行）。
  - 变换完成后，所有箭头像素从网格中移除（变为背景色）。
- `Key insight`：三层推理结构——第一层：通过箭头的像素排列识别其指向方向并确定目标色块；第二层：发现箭头颜色与变换类型的对应关系；第三层：当多箭头指向同一目标时，发现施加顺序是按距离从远到近排列的（而非从近到远），这会影响旋转和翻转的叠加结果。
</new_puzzle>

- `description`：网格中每个彩色"窗户"框架内部被分割为若干小格，部分小格中有标记像素；根据同色窗户之间标记位置的"异或"关系，生成一个新的合并窗户。
- `Input structure`：
  - 背景色 = black。
  - 网格中有若干大小相同的矩形"窗户"框架，每个窗户由某种颜色的边框构成（单像素宽），内部被同色的十字线均匀分割为 2×2、2×3 或 3×3 的小格（所有窗户的分割方式相同）。
  - 每个窗户的部分小格中心位置有一个 red 标记像素，其余小格中心为背景色。
  - 窗户按边框颜色分组，每种颜色恰好有两个窗户。
  - 网格中还有一个与窗户同样大小和分割方式的空白窗户（边框为 grey，内部所有小格中心均为背景色），作为输出模板。
- `Rule`：
  - 对每对同色窗户，逐格比较它们的标记状态：若两个窗户在某格的标记状态不同（一个有标记、一个没有），则该格在输出中有标记；若相同（都有或都没有），则该格在输出中无标记。这就是逻辑异或操作。
  - 对所有颜色对执行上述异或操作后，将所有结果再做逐格"或"合并：任意一对的异或结果在某格为有标记，则最终输出该格有标记。
  - 将最终的标记结果填入 grey 空白窗户中（在对应小格中心放置 red 标记像素）。
  - 输出仅包含填充后的 grey 窗户区域。
- `Key insight`：解题者首先需要发现窗户按颜色配对（第一层），然后发现配对窗户之间的标记遵循异或逻辑（第二层——这需要对比多对窗户才能区分异或与其他逻辑运算），最后发现多对结果通过"或"运算合并到输出模板中（第三层）。
</new_puzzle>

<new_puzzle>
- `description`：网格中散布着若干彩色像素簇，每个簇的形状编码了一个"印章"图案；根据簇的颜色在色谱中的排列顺序，依次将印章叠印到一个固定位置的画布上，后印的覆盖先印的。
- `Input structure`：
  - 背景色 = black。
  - 网格被一条 grey 水平线分为上下两个区域。
  - 上方区域包含若干彩色像素簇（每个簇由同一种颜色的相连像素构成），每个簇的颜色各不相同，可能的颜色包括 red、orange、yellow、green、blue。每个簇的形状构成一个小型图案（占据约 3×3 到 5×5 的范围）。
  - 下方区域有一个由 grey 边框围成的空白矩形画布（内部为背景色），画布的大小与上方每个簇的外接矩形大小相同。
- `Rule`：
  - 将上方每个簇的图案提取出来（以其外接矩形为基准，保留像素的相对位置）。
  - 按照彩虹色谱顺序（red → orange → yellow → green → blue）确定叠印顺序，排在前面的颜色先印。
  - 将图案依次叠印到下方画布上：每个图案对齐画布左上角，图案中的非背景像素覆盖画布上对应位置的像素。后印的颜色覆盖先印的颜色。
  - 输出仅包含下方画布区域（含 grey 边框）。
- `Key insight`：第一层推理需要识别上方区域的各个簇并提取其图案形状；第二层需要发现叠印顺序并非按簇的空间位置排列，而是按颜色在彩虹色谱中的固有顺序排列——这意味着最后印上去的（blue）会显示在最上层，而最先印的（red）可能被部分覆盖。解题者必须从输出中被覆盖的痕迹反推出这个顺序规则。
</new_puzzle>
