- `description`：根据彩色锚点像素在网格边界上的位置，将散落的形状精灵投射到对应的行/列轨道上，再依据精灵内部孔洞的数量决定其最终停靠的深度。

- `Input structure`：
  - 背景色为 black。
  - 网格的四条边界上分布着若干单像素彩色锚点（颜色各不相同，可能出现在任意一条边上）。
  - 网格内部散布着若干小型单色形状精灵（每个精灵为 8-连通的单色区域，颜色与某个锚点匹配）。每个精灵内部可能包含 0 到 4 个由背景色构成的孔洞（4-连通的封闭背景区域）。
  - 每个锚点颜色在精灵中恰好出现一次，形成一一配对。

- `Rule`：
  - 第一步（轨道确定）：每个锚点定义一条从该锚点出发、垂直于其所在边界、向网格内部延伸的直线轨道。例如，锚点在顶边第 5 列，则轨道为第 5 列从上向下；锚点在左边第 3 行，则轨道为第 3 行从左向右。
  - 第二步（深度计算）：统计与该锚点颜色匹配的精灵内部的孔洞数量 H。精灵被放置在轨道上，其靠近锚点一侧的边缘距离锚点恰好 H 个像素（H=0 则紧贴锚点）。
  - 第三步（放置）：将精灵从原始位置擦除，沿轨道方向重新绘制到计算出的深度位置。精灵保持原始朝向不变。若精灵的 bounding box 宽度或高度与轨道方向不匹配（即精灵宽于单列轨道或高于单行轨道），则精灵以其中心线对齐到轨道上。
  - 输出网格尺寸与输入相同。

- `Key insight`：锚点的边界位置决定了运动的方向和轨道，而精灵内部孔洞数量——一个需要主动识别和计数的结构特征——决定了最终停靠的偏移距离。解题者需要同时发现"颜色配对 + 轨道方向"和"孔洞数 + 深度"两层独立规则。
</new_puzzle>

- `description`：将网格中由分隔线划分出的多个小图案区域视为"印章"，根据独立的颜色图例面板确定每个印章的旋转角度，再将旋转后的印章按图例中的排列顺序拼接成最终输出。

- `Input structure`：
  - 背景色为 black。
  - 网格被 grey 色的十字分隔线划分为若干矩形区域。
  - 其中一个较大的矩形区域是"排列图例"：内部是一个小型网格，每个格子填充了一种颜色，代表某个印章的身份色（每个印章有且仅有一种非背景、非 grey 的主色调）。排列图例中的格子按行列排布，定义了输出中印章的拼接顺序（从左到右、从上到下）。
  - 另一个较小的矩形区域是"旋转图例"：内部包含若干 L 形标记，每个 L 形由两段组成——一段水平（2 像素长）、一段垂直（2 像素长），共享一个拐角像素，总共 3 个像素。L 形的颜色与某个印章的主色调一致。L 形的开口方向编码旋转角度：开口朝右上=0度，开口朝右下=顺时针90度，开口朝左下=180度，开口朝左上=逆时针90度。
  - 剩余的矩形区域各自包含一个小型图案（印章），每个印章有一种主色调。

- `Rule`：
  - 第一步（身份识别）：通过主色调将每个印章与排列图例和旋转图例中的对应条目配对。
  - 第二步（旋转）：根据旋转图例中对应 L 形标记的开口方向，对印章图案施加相应角度的旋转。
  - 第三步（拼接）：按排列图例中格子的行列位置，将旋转后的印章紧密拼接（印章之间无间隔），生成输出网格。输出网格不包含分隔线和图例区域。

- `Key insight`：解题者需要分别破解三个子结构的含义——印章区域提供图案、旋转图例中 L 形的开口方向编码旋转角度、排列图例定义拼接布局。三层信息通过颜色配对关联，缺一不可。
</new_puzzle>

- `description`：在网格中识别由不同颜色围栏围成的封闭区域，根据围栏上缺口的位置和朝向将区域内部的填充色"倒出"到外部，形成从缺口延伸的彩色射线，射线长度等于区域内非背景像素的数量。

- `Input structure`：
  - 背景色为 azure。
  - 网格中有若干由单一非背景色像素构成的矩形围栏（围栏为 1 像素宽的矩形边框）。每个围栏的颜色各不相同。
  - 每个围栏恰好有一个缺口：围栏边框上有一个像素缺失，形成一个 1 像素宽的开口。
  - 每个围栏的内部（围栏包围的区域，不含围栏本身）填充了若干散落的彩色像素（颜色与围栏色不同，也不是背景色），其余为背景色。不同围栏内部的填充色可能相同也可能不同。

- `Rule`：
  - 第一步（识别缺口方向）：确定每个围栏缺口所在的边（上、下、左、右）。缺口方向即为该边朝外的法线方向（例如缺口在围栏的右边，则方向为向右）。
  - 第二步（计数）：统计该围栏内部所有非背景像素的总数 N（包括所有颜色的填充像素）。
  - 第三步（生成射线）：从缺口位置开始，沿缺口方向向外绘制一条长度为 N 的射线。射线的颜色为围栏内部面积最大的那种填充色（即出现次数最多的填充颜色）。若射线遇到网格边界则截断。
  - 第四步（清空内部）：围栏内部所有填充像素被擦除为背景色，围栏本身保持不变（缺口仍然存在）。

- `Key insight`：围栏的缺口位置给出方向，内部像素总数给出射线长度，内部最多的颜色给出射线颜色——三个属性分别来自围栏结构的不同层面。解题者需要发现"缺口 + 方向"和"像素计数 + 长度"以及"众数颜色 + 射线色"三条独立规则并将它们组合。
</new_puzzle>

<new_puzzle>
- `description`：网格中包含若干对颜色相同的"门框"和"钥匙"形状；将每把钥匙插入颜色匹配的门框中，但插入方向由门框边框上的特殊标记像素决定，且钥匙需要进行镜像翻转以适配门框的内部轮廓。

- `Input structure`：
  - 背景色为 black。
  - 网格中有若干矩形"门框"：每个门框是某种颜色 C 的空心矩形（1 像素宽的边框），内部为背景色。门框的某一条边（上、下、左或右）的正中央有一个 maroon 色的标记像素，嵌在边框中替换了原本的颜色 C 像素。
  - 网格中有若干"钥匙"形状：每把钥匙是由颜色 C 组成的小型不规则连通区域（4-连通），其 bounding box 严格小于对应门框的内部空间。每把钥匙的颜色与恰好一个门框匹配。
  - 门框和钥匙在网格中互不重叠，互不相邻。

- `Rule`：
  - 第一步（配对）：通过颜色将每把钥匙与其对应的门框配对。
  - 第二步（确定插入方向）：maroon 标记像素所在的边决定了钥匙从哪个方向插入门框。例如标记在门框的右边则钥匙从右侧插入（钥匙贴靠门框内部的右侧边缘）。
  - 第三步（镜像翻转）：钥匙沿垂直于插入方向的轴进行一次镜像翻转。具体来说：从右侧或左侧插入时，钥匙沿垂直轴（左右翻转）进行镜像；从上方或下方插入时，钥匙沿水平轴（上下翻转）进行镜像。
  - 第四步（放置）：将翻转后的钥匙放入门框内部，紧贴标记像素所在边的内侧，在该边方向上居中对齐。钥匙原始位置被擦除为背景色。maroon 标记像素恢复为门框颜色 C。

- `Key insight`：颜色配对是显而易见的第一步，但解题者还必须发现 maroon 标记的双重作用——它既指示插入方向，又隐含了镜像翻转的轴向。翻转规则并非任意，而是与插入方向存在固定的几何对应关系，需要从多个样例中归纳。
</new_puzzle>

<new_puzzle>
- `description`：网格中散布着若干彩色"种子"像素和灰色"墙壁"线段；每颗种子向四个基本方向生长出与自身颜色相同的枝条，枝条遇墙停止；当两颗不同种子的枝条在同一个像素相遇时，该像素变为第三种颜色（由两颗种子的颜色通过网格中一个独立的"调色板"区域查表决定）。

- `Input structure`：
  - 背景色为 black。
  - 网格右下角有一个由 grey 边框围起的小型"调色板"矩阵（例如 3x3 或 4x4）。调色板的行和列各对应一种颜色（行头和列头用对应颜色的单像素标注），矩阵内部每个格子填充一种颜色，表示该行颜色与该列颜色"混合"后的结果色。调色板是对称的（即行色 A 列色 B 的结果等于行色 B 列色 A 的结果）。
  - 网格其余区域散布着若干单像素的彩色"种子"（颜色出现在调色板的行/列头中）。
  - 网格中有若干 grey 色的直线段（水平或垂直，宽度 1 像素），充当墙壁。

- `Rule`：
  - 第一步（生长）：每颗种子同时向上、下、左、右四个方向发射直线枝条。枝条沿直线延伸，逐像素填充种子的颜色，直到遇到以下任一情况停止：(a) 遇到 grey 墙壁像素（墙壁本身不被覆盖），(b) 到达网格边界，(c) 到达调色板区域的 grey 边框。
  - 第二步（冲突解决）：若某个像素同时被两颗不同颜色的种子的枝条覆盖（即该像素在两颗种子的枝条路径上），则该像素不使用任何一颗种子的颜色，而是查阅调色板矩阵，找到这两种颜色交叉处的结果颜色来填充。若某像素被三颗及以上种子覆盖，则取任意两两组合中在调色板中出现的那个结果色（题目保证此情况下结果唯一）。
  - 第三步：种子像素本身保留原色不变。墙壁保持 grey 不变。调色板区域保持不变。

- `Key insight`：枝条的生长规则（遇墙停止）本身比较直观，但"交叉点变色"的规则需要解题者发现调色板的查表功能。解题者必须先理解调色板矩阵的行列结构代表颜色映射关系，再将其应用到枝条交汇处——这构成两层独立的推理：生长机制和混色查表机制。
</new_puzzle>

<new_puzzle>
- `description`：网格中包含若干由不同颜色绘制的闭合路径和路径内部的小型"货物"精灵；每条路径上有一个箭头标记指示环绕方向；货物沿路径移动，移动步数等于货物自身占据的像素数量。

- `Input structure`：
  - 背景色为 black。
  - 网格中有若干由单一非背景色像素构成的闭合环形路径（路径宽度为 1 像素，形成封闭的回路，可以是矩形环、L形环等不规则形状，但保证路径上每个像素恰好有两个同色 4-连通邻居形成唯一环路）。
  - 每条路径上恰好有一个像素被替换为 yellow 色，该 yellow 像素即为"箭头标记"。箭头标记的两个路径色邻居中，沿顺时针方向遍历路径时从箭头标记出发经过的下一个像素所在的方向，就是货物移动的正方向。
  - 每条路径的内部区域（被路径围起来的封闭区域）包含恰好一个小型"货物"精灵——由某种颜色（非路径色、非背景色、非 yellow）组成的 4-连通区域。

- `Rule`：
  - 第一步（路径解析）：识别每条闭合路径及其上的 yellow 箭头标记。沿路径从 yellow 标记的位置出发，按顺时针方向确定路径上像素的有序序列。
  - 第二步（计算步数）：统计路径内部货物精灵的像素数量 S。
  - 第三步（确定新位置）：货物精灵的"锚点"定义为其最上且最左的像素。找到锚点在路径上最近的路径像素作为起始位置，沿顺时针方向前进 S 步到达目标路径像素。
  - 第四步（移动货物）：将货物精灵整体平移，使其锚点移动到目标路径像素的内侧相邻位置（即从目标路径像素向路径围成区域内部方向偏移 1 像素的位置）。货物原始位置擦除为背景色。yellow 标记恢复为路径颜色。

- `Key insight`：解题者需要同时理解三个层面：闭合路径定义了离散的环形轨道，yellow 标记确定了遍历方向，而货物自身的面积决定了移动距离。货物的大小既是"负载"也是"燃料"，这一双重角色是本题的核心隐蔽性所在。
</new_puzzle>

- `description`：网格被划分为若干房间，每个房间内有一个多色图案和一面"镜子"线段；图案在镜子中产生反射像，但反射像的颜色根据房间边界上的色条进行重新映射。

- `Input structure`：
  - 背景色为 black。
  - 网格被 grey 色的直线（水平和垂直）划分为若干矩形"房间"。
  - 每个房间内部包含：
    - 一个由 2-4 种非背景色像素构成的小型图案（4-连通区域），位于房间的某一侧。
    - 一条 maroon 色的直线段（水平或垂直，1 像素宽），充当"镜子"，位于房间内部将房间分为两半——图案所在的一半和空白的一半。
  - 每个房间的一条 grey 边界上附着若干成对的彩色像素点：每对由两个相邻像素组成，一个位于边界线上（替换原本的 grey），另一个紧邻其内侧（位于房间内部紧贴边界的位置）。这对像素表示颜色映射关系：边界上的像素颜色 A 映射为内侧像素颜色 B。每个房间可能有 1-3 对这样的映射标记。

- `Rule`：
  - 第一步（反射）：将图案以 maroon 镜子线段为对称轴进行镜像反射，在镜子另一侧的空白区域生成反射像。
  - 第二步（颜色重映射）：读取该房间边界上的颜色映射对。对反射像中的每个像素，若其颜色出现在某个映射对的源色（边界上的那个）中，则将其替换为对应的目标色（内侧的那个）。未被映射覆盖的颜色保持不变。
  - 第三步：原始图案保持不变。maroon 镜子线段保持不变。颜色映射标记保持不变。

- `Key insight`：反射本身是直观的几何操作，但解题者需要额外发现边界上的成对像素构成了颜色映射表，并将该映射选择性地应用于反射像而非原像。两层规则——几何反射与颜色重映射——通过镜子和边界标记分别编码，需要独立归纳后组合。
</new_puzzle>
