<new_puzzle>
根据边框缺口方向和内部种子色块的颜色，在对应方向上用种子颜色生长出阶梯状填充图案。

Input structure：
- 背景为 black。
- 网格中有若干个由同一种颜色（如 grey）绘制的矩形闭合边框，每个边框恰好有一个单像素宽的缺口位于某条边的中央位置。
- 每个边框内部恰好有一个小的单色矩形色块（称为"种子"），种子颜色各不相同（如 red、blue、green），种子不与边框接触。
- 边框外部为纯背景色。

Rule：
- 对每个边框，首先确定缺口所在的边（上、下、左、右）。
- 从种子色块出发，向缺口所在边的方向逐行（或逐列）生长阶梯状填充：第一步填充种子正上/下/左/右方一行（或一列）像素，宽度等于种子宽度；第二步填充下一行，宽度在种子宽度基础上左右各扩展一个像素；以此类推，每一行比上一行左右各宽一像素，形成等腰梯形。
- 填充在碰到边框内壁时停止：如果某一行的扩展宽度超出了边框内壁范围，则该行被边框内壁裁剪（不超出边框）。
- 填充颜色使用种子色块的颜色。
- 边框、种子色块本身、缺口以及背景均保持不变。

Key insight：
- 缺口方向决定了生长方向，种子的位置和宽度决定了阶梯的起始形态；解题者需要同时识别"缺口→方向"和"种子→颜色+起点+初始宽度"两层对应关系，并理解阶梯扩展被边框裁剪的几何约束。
</new_puzzle>

<new_puzzle>
将散落的单色碎片按形状匹配嵌入到模板网格中对应形状的空洞里，并根据碎片在输入中所处的象限决定嵌入时的旋转角度。

Input structure：
- 背景为 black。
- 网格正中央有一个由 grey 像素构成的大型连通模板区域，模板内部包含若干个不规则形状的背景色空洞（孔洞）。
- 模板外部的四个象限中各散落着若干单色碎片（4-连通连通块），每个碎片颜色各异（如 red、blue、green、yellow 等），每个碎片的形状在旋转 0/90/180/270 度后恰好与模板中某个空洞吻合。

Rule：
- 碎片所处的象限决定其旋转量：左上象限的碎片旋转 0 度，右上象限旋转 90 度（顺时针），右下象限旋转 180 度，左下象限旋转 270 度（顺时针）。
- 对每个碎片，先按象限规则旋转，再与模板中的空洞逐一比对形状；形状匹配的空洞即为该碎片的目标位置。
- 输出时，模板保持不变，每个空洞被对应碎片的颜色填充；碎片从原位置移除（恢复为背景色）。

Key insight：
- 形状匹配本身是一层推理，但仅靠形状匹配无法唯一确定旋转方式；解题者必须发现象限与旋转角度的隐含映射规则，才能正确地将碎片嵌入空洞。这两层推理缺一不可。
</new_puzzle>

<new_puzzle>
根据每行的颜色图例条，对该行中的所有前景对象执行对应的几何变换（水平翻转、垂直翻转、或 90 度旋转），然后将变换后的对象就地替换。

Input structure：
- 背景为 black。
- 网格被若干条完整的水平 grey 分隔线分成若干横条区域（行区域）。
- 每个行区域的最左侧有一个 2 像素高、1 像素宽的竖直色条作为图例，色条由两个像素组成：上方像素颜色为 A，下方像素颜色为 B。
- 每个行区域的右侧部分包含若干个多色或单色的小型前景精灵（sprite），每个精灵的外接矩形不超过 5x5，精灵之间互不接触。

Rule：
- 图例色条编码了一种变换：若上下两个像素颜色相同，表示"不变换"；若上方为 red、下方为 blue，表示"水平翻转"；若上方为 blue、下方为 red，表示"垂直翻转"；若上方为 green、下方为 yellow，表示"顺时针旋转 90 度"。
- 对该行区域中的每个精灵，在其外接矩形内执行图例指定的几何变换，变换后的精灵放回原外接矩形的位置。
- 分隔线和图例色条在输出中保持不变。

Key insight：
- 解题者需要先从多个样例中归纳出色条颜色组合与几何变换类型之间的映射关系（这需要对比输入输出中精灵的朝向变化），然后将该映射应用于测试样例中的每个行区域。色条编码规则是隐蔽的，不同行区域可能使用不同变换，增加了归纳难度。
</new_puzzle>

<new_puzzle>
在网格中找到由标记像素定义的"源区域"和"目标区域"，将源区域的内容复制到目标区域，但复制时需要按照两个区域之间连线上的颜色编码进行逐层颜色替换。

Input structure：
- 背景为 black。
- 网格中有两个大小相同的矩形区域，各由一种不同颜色的单像素边框围成（如 red 边框和 blue 边框），内部包含由多种颜色组成的图案。
- 两个矩形之间由一条单像素宽的水平或垂直的"管道"连接，管道由交替排列的成对颜色像素组成，例如：green-yellow-green-yellow...，每一对相邻的两个不同颜色像素定义一条颜色替换规则（第一个颜色→第二个颜色）。
- 其中一个矩形内部图案更丰富（源），另一个矩形内部为纯背景色或仅有少量像素（目标）。

Rule：
- 识别源矩形（内部非背景像素更多的那个）和目标矩形。
- 读取管道中的颜色对序列，构建颜色替换映射表：管道从源矩形端到目标矩形端，每两个相邻像素为一对，前者为原色、后者为替换色。
- 将源矩形内部的图案复制到目标矩形内部，复制时将每个像素的颜色按映射表替换；若某颜色不在映射表中，则保持原色不变。
- 源矩形、管道和边框均保持不变。

Key insight：
- 第一层推理：识别源和目标（通过内容丰富度判断）以及管道的读取方向（从源端到目标端）。第二层推理：发现管道中交替颜色对构成的是颜色映射规则，而非装饰。第三层推理：将映射应用于源图案的逐像素复制。三层结构使得规则不容易从单个样例中一眼看穿。
</new_puzzle>

<new_puzzle>
将网格中每个封闭区域内的前景图案按照区域边框上特殊标记的位置进行"弹球反射式"的平移复制，直到填满整个封闭区域。

Input structure：
- 背景为 black。
- 网格中有若干个由 grey 像素构成的矩形封闭边框，边框线宽为 1 像素。
- 每个边框的内部左上角区域有一个小型多色前景图案（"种子图案"），其外接矩形的尺寸严格整除边框内部空间的宽度和高度。
- 每个边框的上边或左边恰好有一个像素被替换为 orange（"发射标记"），标记位于种子图案外接矩形的某条边的延长线上。

Rule：
- 发射标记决定平铺的初始方向：标记在上边表示种子图案先向右平铺，标记在左边表示种子图案先向下平铺。
- 从种子图案的位置开始，沿初始方向将种子图案逐格复制，每次平移一个种子外接矩形的宽度（或高度）。
- 当复制到达边框内壁时，平移方向旋转 90 度（类似弹球反射：水平变垂直，垂直变水平），继续向未填充区域复制。
- 每次"反射"时，种子图案本身也做一次对应的翻转：水平移动碰壁则水平翻转，垂直移动碰壁则垂直翻转。
- 重复直到边框内部所有种子大小的格位都被填满。

Key insight：
- 解题者首先要发现种子图案恰好整除内部空间（确定平铺单元），然后要从发射标记归纳出初始方向，最后要理解碰壁反射同时伴随图案翻转的规则。三层机制叠加在一起：平铺单元识别、方向编码、反射翻转，使得仅看一个样例很难完整归纳出规则。
</new_puzzle>
