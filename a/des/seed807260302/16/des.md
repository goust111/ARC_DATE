- `description`：根据每个封闭区域内部的色块数量，从色块颜色库中选取对应排位的颜色重新填充该区域的边框。
- `Input structure`：
  - 背景为 black。
  - 网格中有若干由 grey 像素围成的封闭矩形边框（边框宽度为1像素），边框内部区域包含数量不等的散落小色块（每个色块为1像素，颜色各异）。
  - 网格底部有一行水平排列的颜色样本条：从左到右依次排列若干不同颜色的单像素点，间隔1像素，作为颜色库。
- `Rule`：
  - 统计每个 grey 封闭矩形边框内部包含的色块像素数量 N。
  - 在底部颜色库中，从左到右第 N 个颜色即为该边框的目标颜色。
  - 将该矩形边框的所有 grey 像素替换为目标颜色；边框内部的色块像素全部清除为 black。
  - 底部颜色库本身保持不变。
- `Key insight`：封闭边框内部的色块不是要被保留的内容，而是用来计数的；计数结果作为索引查询底部颜色库，从而决定边框自身的重绘颜色。解题者需要先发现"内部色块数量"这一隐含属性，再发现底部色条是按序号查询的颜色映射表。
</new_puzzle>

- `description`：将散落的彩色像素沿其所在行或列的方向聚合到同色 L 形拐角的拐点处，再根据聚合后的像素数决定从拐点延伸的射线长度。
- `Input structure`：
  - 背景为 black。
  - 网格中有若干不同颜色的 L 形拐角结构，每个 L 形由两条互相垂直的单像素宽线段组成（一条水平、一条垂直），共享一个拐点像素。每条线段长度至少为2像素（含拐点）。
  - 与每个 L 形同色的若干孤立像素散落在网格中，这些孤立像素必定位于 L 形两条臂所在的行或列上（即与某条臂共行或共列）。
- `Rule`：
  - 对每个 L 形颜色，收集所有同色孤立像素，按照它们与 L 形拐点的行列关系归类：与水平臂同行的归入水平组，与垂直臂同列的归入垂直组。
  - 清除所有孤立像素和原始 L 形。
  - 从拐点出发，沿水平臂的原始延伸方向画一条射线，长度等于水平组的像素数量；沿垂直臂的原始延伸方向画一条射线，长度等于垂直组的像素数量。拐点本身始终保留。
  - 不同颜色的 L 形互不干扰。
- `Key insight`：孤立像素不是装饰，而是通过行列对齐关系分配给 L 形的两条臂的计数器；原始臂长无关紧要，输出臂长完全由收集到的同色孤立像素数量决定。解题者需要先识别行列对齐的归属规则，再发现计数驱动长度的机制。
</new_puzzle>

- `description`：将多个带缺口的矩形框按缺口朝向拼接成链式结构，缺口处用下一个框的颜色填充连接桥。
- `Input structure`：
  - 背景为 black。
  - 网格中散布若干不同颜色的空心矩形框（边框宽度为1像素），每个框的某一条边上有一个连续缺口（缺口宽度为2-3像素）。
  - 网格角落有一个小型排序提示区：一列从上到下排列的单像素色块，颜色与矩形框一一对应，表示链接顺序。
- `Rule`：
  - 按角落提示区从上到下的颜色顺序确定框的链接次序：第1个框为链首，第2个框链接到第1个框，依此类推。
  - 链接方式：将第 k+1 个框平移，使其缺口所在边与第 k 个框的缺口所在边相对（缺口对缺口），两个缺口在同一行或同一列上对齐，框之间留1像素间距。
  - 在两个对齐的缺口之间的间距处，用第 k+1 个框的颜色绘制连接桥（填满缺口宽度 x 1像素的间距）。
  - 输出网格裁剪为恰好包含整条链的最小边界框。
- `Key insight`：每个框的缺口不是损坏，而是连接端口；角落色序决定了拼接顺序，而缺口朝向决定了空间排列方向。解题者需要先从角落提示发现排列顺序，再理解缺口作为定向连接器的拼接规则，最后发现连接桥的颜色取自被链接框而非链接到的框。
</new_puzzle>

- `description`：识别网格中重叠放置的多个透明色层，根据层叠遮挡关系还原每层的完整原始形状，然后将各层按面积从小到大水平排列输出。
- `Input structure`：
  - 背景为 black。
  - 网格中有若干不同颜色的矩形区域发生了部分重叠。在重叠区域，后放置的颜色完全覆盖先放置的颜色，因此某些矩形仅有部分像素可见（呈现为 L 形、U 形或其他被遮挡后的残留形状）。
  - 每种前景颜色恰好对应一个矩形（非框，是实心矩形）。
  - 没有颜色被完全遮挡（每种颜色至少有1个像素可见）。
- `Rule`：
  - 对每种前景颜色，根据其可见像素推断出该颜色原始完整矩形的尺寸：可见像素的行范围即矩形的行跨度，列范围即矩形的列跨度。
  - 还原每个颜色的完整实心矩形。
  - 按矩形面积从小到大排序。
  - 在输出网格中，将这些还原的矩形从左到右水平排列，矩形之间间隔1列 black，所有矩形顶部对齐于第0行。
- `Key insight`：被遮挡的矩形虽然不完整，但其可见像素的行列范围已足够还原完整尺寸——这利用了矩形的轴对齐特性。解题者需要先认识到每种颜色对应一个被遮挡的完整矩形，再发现从残留像素的边界范围可以还原原始形状，最后按面积排列输出。
</new_puzzle>

<new_puzzle>
- `description`：网格中的每个彩色种子像素沿其所在象限对应的对角方向生长出与同象限内壁面距离等长的 L 形枝条，枝条颜色由种子与中心标记的相对位置决定。
- `Input structure`：
  - 背景为 black。
  - 网格正中央有一个 red 十字标记（1像素宽，横竖各占满整行整列），将网格分为四个象限（左上、右上、左下、右下）。
  - 每个象限内散布若干孤立的彩色种子像素（颜色不为 red 或 black），每个象限内的种子颜色相同但不同象限的种子颜色可能不同。
  - 网格边缘有 grey 边框（1像素宽）。
- `Rule`：
  - 每个种子像素根据所在象限确定生长方向：左上象限向左上生长，右上象限向右上生长，左下象限向左下生长，右下象限向右下生长。
  - 生长方式：从种子出发，先沿水平方向（朝象限外侧边框方向）画一条线段，长度等于种子到该方向 grey 边框的像素距离减1；再从该线段末端沿垂直方向（朝象限外侧边框方向）画一条线段，长度等于种子到该方向 grey 边框的像素距离减1。两段构成 L 形。
  - L 形枝条使用种子自身的颜色绘制。种子像素本身保留。
  - red 十字标记和 grey 边框保持不变。
  - 枝条不会越过 red 十字线或 grey 边框。
- `Key insight`：red 十字将空间划分为四个独立象限，每个象限的生长方向由其相对于中心的位置隐含决定；枝条的两段长度不是固定的，而是由种子到边框的距离动态决定。解题者需要先理解十字线的象限划分作用，再发现每个种子的 L 形生长方向和长度都取决于其在象限中的空间位置。
</new_puzzle>

<new_puzzle>
- `description`：在包含多个相同模板图案副本的网格中，找出每个副本相对于"标准版"的差异像素，将所有差异像素叠加到一个干净的模板上生成输出。
- `Input structure`：
  - 背景为 black。
  - 网格中以规则间距排列着若干个大小相同的矩形区域（如 2x3 或 3x4 的网格排列），每个区域包含一个近似相同的多色图案。
  - 这些图案副本大部分像素相同，但每个副本有少量像素（1-3个）与其他副本不同——即被"篡改"过。
  - 存在一个"多数一致"的标准图案：对于每个像素位置，多数副本在该位置的颜色即为标准颜色。
- `Rule`：
  - 通过多数投票确定每个像素位置的标准颜色，得到标准模板。
  - 对每个副本，找出与标准模板不同的像素位置及其篡改颜色。
  - 创建一个与模板大小相同的输出网格，以标准模板为底，将所有副本的所有差异像素叠加上去（差异像素的颜色覆盖标准颜色）。
  - 如果多个副本在同一位置都有差异，取最后一个副本（按从左到右、从上到下的阅读顺序）的差异颜色。
- `Key insight`：多个"几乎相同"的副本不是冗余，而是通过差异编码了隐藏信息；解题者需要先通过对比发现"多数一致即为标准"的投票机制，再收集每个副本偏离标准的"异常"像素，最后将这些异常合并到一个模板上。
</new_puzzle>

- `description`：将网格中每条彩色路径按照路径上遇到的关卡标记依次截断并变色，形成分段渐变的彩色路径。
- `Input structure`：
  - 背景为 black。
  - 网格中有若干条由 grey 像素构成的单像素宽连续路径（4-连通），路径不分叉，两端各有一个端点像素。
  - 每条路径的起点端（一端）标记为 blue 像素（替代该位置的 grey）。
  - 路径上间隔分布着若干 red 像素作为关卡标记（替代该位置的 grey）。
  - 网格边缘有一个颜色序列参考条：从左到右排列若干不同颜色的像素（不含 black、grey、blue、red），表示分段着色的颜色顺序。
- `Rule`：
  - 从每条路径的 blue 端点出发，沿路径行走。
  - 将 blue 端点到第一个 red 关卡之间的所有像素（含 blue 端点，不含 red 关卡）重新着色为颜色序列的第1个颜色。
  - 将第1个 red 关卡到第2个 red 关卡之间的像素（含第1个关卡，不含第2个关卡）着色为颜色序列的第2个颜色。
  - 依此类推，每经过一个关卡，使用颜色序列中的下一个颜色。
  - 最后一个 red 关卡到路径另一端之间的像素（含最后的关卡和端点）使用序列中的下一个颜色。
  - 颜色序列参考条在输出中保持不变。
- `Key insight`：grey 路径和 red 关卡在输出中完全消失，被分段颜色取代；解题者需要先识别 blue 为起点、red 为分割标记的角色分工，再发现边缘颜色条提供了分段着色的顺序映射，最后理解路径遍历方向决定了颜色分配。
</new_puzzle>
