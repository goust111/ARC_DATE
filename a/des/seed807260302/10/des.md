<new_puzzle>
将网格中散落的彩色碎片按颜色配对，每对碎片之间用桥梁连接，桥梁的颜色由碎片所在区域的边框颜色决定。

Input structure:
- 背景为最常见的颜色（black）。网格被若干单像素宽的彩色边框线分割为多个矩形区域，每个区域的边框颜色各不相同。
- 每个区域内部散布着一些小型单色碎片（4-连通，面积2-4像素）。每种碎片颜色在整个网格中恰好出现两次，分布在不同的区域中。
- 同一对碎片（相同颜色）一定位于在同一行或同一列上对齐的两个区域中。

Rule:
- 对于每对同色碎片，找到它们各自质心所在的行或列（取对齐的那个轴）。
- 沿该行或列在两个碎片之间画一条直线桥梁，桥梁起点和终点分别为两个碎片的最近边缘像素。
- 桥梁的颜色不是碎片本身的颜色，而是碎片所处区域的边框颜色：如果两个碎片分属不同边框颜色的区域，桥梁分为两段，每段使用各自区域的边框颜色，在两区域的边界处交接。
- 碎片本身保持不变，桥梁仅覆盖背景像素。

Key insight:
解题者需要先发现碎片的配对规则（同色配对），再发现桥梁颜色不来自碎片而来自区域边框——需要两步独立的归纳：配对机制和着色机制。
</new_puzzle>

<new_puzzle>
根据每个封闭房间内"门"的朝向，将房间内部的自由色块旋转相应角度后重新放置。

Input structure:
- 背景为 black。网格中有若干由 grey 像素围成的封闭矩形"房间"，房间大小各异（内部至少4x4）。
- 每个房间的 grey 边框上恰好有一个单像素缺口（"门"），门可以在上、下、左、右四个边中的任意一边。
- 每个房间内部有一个由单一非 grey、非 black 颜色构成的小型不对称色块（4-连通，面积3-5像素），色块不触碰房间边框。

Rule:
- 确定每个房间的门所在的边：上边=0度，右边=90度，下边=180度，左边=270度。
- 将房间内部的色块以其自身包围盒中心为锚点，顺时针旋转"门的角度"（上边不旋转，右边旋转90度，下边旋转180度，左边旋转270度）。
- 旋转后的色块放回房间内部的对应位置（旋转后包围盒中心保持在房间内部中心）。
- 房间边框、门缺口和背景保持不变。

Key insight:
门的位置不是装饰而是旋转指令——解题者必须先识别"门在哪一边"编码了旋转角度，再对每个房间内的不对称色块执行对应旋转。色块的不对称性使旋转效果可辨别。
</new_puzzle>

<new_puzzle>
将网格中的多个同心环形图案拆解，按环的层数重新排列为并排的实心矩形色条。

Input structure:
- 背景为 black。网格中有若干互不重叠的同心环形图案（正方形环），每个图案由2到4层不同颜色的嵌套方环组成，最内层可以是一个实心正方形。
- 每个同心环图案的各层颜色各不相同，但不同图案之间可能共享颜色。
- 同心环图案在网格中的位置和大小各异。

Rule:
- 对每个同心环图案，从最外层到最内层依次读取各层的颜色，得到一个颜色序列。
- 按图案在网格中的位置从左到右排序（以最外层左上角的列坐标为准）。
- 输出网格的高度等于所有图案中最大层数，宽度等于图案总数。
- 每个图案对应输出中的一列，从上到下依次填入该图案从外到内的颜色序列；如果某图案层数不足最大值，底部用背景色填充。

Key insight:
解题者需要先理解同心环的层级结构并正确剥离各层颜色，再发现输出是将空间嵌套结构"展平"为一维色条——从二维嵌套到一维序列的映射是核心认知跳跃。
</new_puzzle>

<new_puzzle>
在网格中，每个彩色种子沿其所在通道生长出与通道等宽的色带，生长方向由种子相对于通道中线的偏移决定，生长长度由同通道内另一颗种子的距离决定。

Input structure:
- 背景为 black。网格中有若干条平行的水平或垂直"通道"，通道由两条平行的 grey 线界定，通道宽度为2或3像素。
- 每条通道内恰好有两颗不同颜色的"种子"像素，每颗种子占1个像素。
- 种子在通道的横截方向上可能偏向一侧（靠近上侧/下侧 grey 墙或左侧/右侧 grey 墙）。

Rule:
- 对每条通道中的每颗种子，判断它在横截方向上偏向哪一侧的 grey 墙。偏向上/左墙的种子沿通道的负方向（向左/向上）生长；偏向下/右墙的种子沿正方向（向右/向下）生长。若种子在通道正中央（仅当通道宽度为奇数时可能），则不生长。
- 生长长度等于该种子到同通道内另一颗种子的距离（沿通道方向的像素差）。
- 生长产生的色带宽度等于通道宽度，颜色为种子颜色，从种子位置开始沿确定方向延伸。
- 色带不覆盖另一颗种子本身，也不超出通道边界。Grey 墙和背景保持不变。

Key insight:
解题者需要发现三层规则：（1）种子在通道横截面上的偏移编码了生长方向，（2）同通道内两颗种子的间距决定了生长长度，（3）色带宽度继承通道宽度。方向、长度、宽度分别由不同的空间关系决定。
</new_puzzle>

<new_puzzle>
将散落在网格中的彩色三角形箭头按其指向方向移动到网格边缘，沿边的精确落点由颜色匹配的边缘标记条决定。

Input structure:
- 背景为 black。网格的四条边上各有零或一段连续的彩色边缘标记条（宽1像素，长度不等，颜色各不相同，紧贴网格边缘）。
- 网格内部散布着若干由不同颜色构成的小型三角形箭头精灵（每个箭头由5个像素组成：3像素构成底边横排或竖排的一行，2像素构成在底边中央像素的前方叠起的尖端，整体形成指向上、下、左、右某个方向的箭头形状）。
- 每个箭头的颜色与某一条边缘标记条的颜色相同。

Rule:
- 对每个箭头，根据其尖端朝向确定移动方向（尖端朝上则向上移动，以此类推）。
- 将箭头从当前位置移除，沿指向方向平移，直到箭头的前端像素紧贴网格边界。
- 箭头沿边方向的最终位置由其颜色对应的边缘标记条决定：箭头的中轴线对齐到标记条的中心位置。
- 若箭头指向的边恰好没有标记条，则箭头指向的边上一定有与之同色的标记条（题目保证每个箭头都能找到匹配的标记条在其指向的边上）。
- 其余像素保持不变。

Key insight:
解题者需要分两步归纳：（1）箭头的几何形状编码了移动方向，（2）箭头的颜色与边缘标记条的匹配关系决定了它沿边的精确落点——方向和定位是两套独立的编码系统。
</new_puzzle>

<new_puzzle>
网格中的每个彩色区块根据其内部孔洞的数量，被复制到对应编号的"展示槽"中，展示槽由下半部分的分隔线划分。

Input structure:
- 背景为 black。网格被一条水平的 grey 分隔线分为上下两部分。
- 上半部分包含若干个互不重叠的单色封闭区块（4-连通），每个区块内部可能有0到3个背景色孔洞（孔洞为完全被区块像素包围的背景色连通区域）。区块颜色各不相同。
- 下半部分被竖直的 grey 分隔线均匀分为4列"展示槽"，从左到右编号为0、1、2、3。每个展示槽初始为空（全为背景色）。

Rule:
- 对上半部分的每个区块，数其内部孔洞的数量 N（0、1、2或3）。
- 将该区块（保持形状和颜色）复制到下半部分编号为 N 的展示槽中，放置在槽内顶部居中的位置。
- 若多个区块映射到同一个槽，按它们在上半部分从左到右的顺序从上到下依次堆叠。
- 上半部分保持不变。

Key insight:
孔洞数量是分类的隐含键——解题者必须先发现"数孔洞"这一非显然的属性提取步骤，再发现孔洞数与展示槽编号的对应关系，才能理解分拣规则。
</new_puzzle>

<new_puzzle>
将网格中由"骨架线"连接的节点对按骨架线的弯折方向，在节点上生成对称的彩色翼展图案。

Input structure:
- 背景为 black。网格中有若干个由 red 像素构成的小型实心正方形"节点"（大小为2x2）。
- 每对相邻节点之间由一条单像素宽的 grey "骨架线"连接，骨架线由一段水平线段和一段垂直线段组成（即一次直角弯折），从一个节点边缘出发到另一个节点边缘。
- 骨架线的弯折点（拐角处）有一个特殊的单色像素标记，颜色非 red、非 grey、非 black，每条骨架线的标记颜色可能不同。

Rule:
- 对每条骨架线，找到其弯折点和标记颜色。
- 确定弯折的方向类型：弯折形成的内角朝向四个对角方向之一（左上、右上、左下、右下）。
- 在骨架线连接的两个节点上，各生成一个"翼展"：以节点为中心，向弯折内角的反方向（即外侧）延伸一个 L 形的彩色图案，颜色为弯折标记的颜色，L 形的两臂各长2像素、宽1像素。
- 骨架线和弯折标记保持不变。

Key insight:
解题者需要先识别骨架线的拐角方向编码了翼展的生长朝向（内角的对面），再发现拐角处的彩色标记决定了翼展颜色——空间方向和颜色信息分别从骨架线的几何形状和标记点获取，是两个独立的推理步骤。
</new_puzzle>
