<new_puzzle>
根据框架内嵌套对象的层数选择对应颜色图例，再用该图例颜色重绘框架外的同形状对象。

Input structure：
- 背景为黑色。网格中散布着若干单色4-连通对象。
- 部分对象被同色矩形框架包围（框架为一像素宽的矩形环），框架内可能嵌套更小的框架，形成多层嵌套结构（最多三层）。
- 网格底部有一行颜色图例：从左到右依次排列若干 1x2 的色块，分别代表"嵌套深度1"、"嵌套深度2"、"嵌套深度3"所对应的输出颜色。

Rule：
- 对每个被框架包围的核心对象（最内层的非框架对象），计算它被嵌套了几层框架（1、2 或 3 层）。
- 在网格中找到与该核心对象形状完全相同（允许平移，不允许旋转或翻转）但不在任何框架内部的"自由对象"。
- 将该自由对象的颜色替换为底部图例中对应嵌套深度的颜色。
- 框架和核心对象本身保持不变，图例保持不变。

Key insight：
- 框架嵌套的层数不是装饰，而是一个查表索引；解题者需要先通过嵌套计数建立"形状→颜色"的映射，再将该映射应用到框架外的同形对象上。两步归纳缺一不可。
</new_puzzle>

<new_puzzle>
将散落的彩色碎片按颜色配对，每对碎片互为镜像拼合成完整矩形，再按矩形面积从小到大纵向堆叠输出。

Input structure：
- 背景为黑色。网格中散布着若干彩色4-连通对象，每种非背景色恰好出现两个对象。
- 同色的两个对象形状互补：将其中一个沿垂直轴镜像翻转后，与另一个恰好拼合成一个无缝实心矩形（无间隙、无重叠）。
- 各对象的像素数不超过 12。

Rule：
- 将同色对象配对。对每一对，将其中一个对象沿垂直轴镜像后与另一个拼合，形成实心矩形。拼合时，镜像对象紧贴原对象右侧，使二者左右合并。
- 计算每个拼合矩形的面积（宽 × 高）。
- 输出网格宽度等于最大矩形的宽度，高度等于所有矩形高度之和加上矩形间的 1 行黑色间隔。
- 按面积从小到大，将矩形从上到下堆叠放置，每个矩形左对齐，矩形之间用一行黑色分隔。

Key insight：
- 解题者首先需要发现同色碎片互为镜像互补这一隐蔽关系，然后需要发现输出的排列顺序取决于拼合后矩形的面积而非颜色或输入位置。两层独立归纳构成核心难度。
</new_puzzle>

<new_puzzle>
用网格边缘的箭头标记确定射线方向和起点，射线在遇到彩色障碍物时将障碍物的颜色"吸收"并改变自身颜色继续前进。

Input structure：
- 背景为黑色。网格边缘（上、下、左、右）上有若干由 green 像素构成的箭头标记，每个箭头由三个像素组成：一个轴像素和两个翼像素，形成指向网格内部的箭头形状。例如，左边缘的箭头为一列三行，中间像素在最右，上下像素各退一列，指向右方。
- 网格内部散布着若干单像素的彩色障碍物（非黑色、非 green）。

Rule：
- 每个边缘箭头从其轴像素位置沿箭头指向方向发射一条单像素宽的射线，初始颜色为 green。
- 射线逐格前进；当射线的下一格是彩色障碍物时，射线覆盖该障碍物的位置，并且从该位置起射线颜色变为该障碍物原来的颜色，继续沿同方向前进。
- 射线到达网格对边边缘时停止。
- 若两条射线交叉，交叉点的颜色为后绘制射线的颜色（按箭头在边缘上的顺序：上边从左到右、右边从上到下、下边从右到左、左边从下到上依次绘制）。

Key insight：
- 箭头形状编码了方向（而非简单的边缘位置），射线不仅是填充工具，还会在碰到障碍物时发生颜色突变——解题者必须同时发现方向编码规则和颜色吸收机制，两者结合才能正确预测输出。
</new_puzzle>

<new_puzzle>
在被围栏分隔的多个房间中，根据每个房间内种子像素的颜色和数量生成对应的十字形图案，图案的臂长等于种子数量。

Input structure：
- 背景为黑色。grey 像素构成一像素宽的直线围栏（水平或垂直），将网格分割成若干矩形房间。
- 每个房间内散布着一到四个同色的种子像素（颜色非黑色、非 grey），它们在房间内的具体位置不固定。
- 每个房间还有一个 red 单像素标记，标示图案的中心位置。

Rule：
- 对每个房间，数出该房间内种子像素的数量 N（1 到 4）。
- 以 red 标记位置为中心，向上、下、左、右四个方向各延伸 N 格，绘制种子颜色的十字形图案（包括中心点）。
- 十字形的臂在碰到围栏或网格边缘时被截断（不穿过围栏）。
- 移除原始种子像素和 red 标记（它们被十字图案覆盖或还原为背景色）。
- 围栏保持不变。

Key insight：
- 房间分割是识别独立操作区域的前提，种子数量编码了图案的尺寸而非位置，red 标记编码了图案的位置而非颜色——解题者需要分别发现三种元素各自的角色（分区、计数、定位），并将它们组合成最终变换。
</new_puzzle>

<new_puzzle>
识别网格中由虚线矩形框标记的"模板区域"和由实线矩形框标记的"目标区域"，将模板区域内的图案旋转后填入目标区域，旋转角度由目标框角落的彩色角标决定。

Input structure：
- 背景为黑色。网格中有若干矩形区域，每个矩形由一像素宽的边框围成。
- 边框分两种样式：虚线边框（边框像素每隔一格出现，即棋盘格式排列在矩形边界上）标记"模板区域"；实线边框（边框像素连续不断）标记"目标区域"。
- 虚线模板框和实线目标框使用相同的边框颜色（非黑色），颜色相同的一对虚线框和实线框构成配对。
- 每个实线目标框的四个角中，恰好有一个角的像素颜色为 yellow（其余三个角为边框颜色）。
- 虚线模板框内部包含由各种颜色绘制的图案；实线目标框内部为空（全黑）。

Rule：
- 将同色的虚线框与实线框配对。
- 提取虚线框内部的图案（不含边框本身）。
- 根据实线框 yellow 角标所在的角位置确定旋转角度：左上角 = 不旋转（0度）、右上角 = 顺时针旋转 90 度、右下角 = 旋转 180 度、左下角 = 顺时针旋转 270 度。
- 将旋转后的图案填入目标框内部（目标框内部尺寸与模板框内部尺寸一致）。
- 虚线框及其内容保留不变。

Key insight：
- 解题者需要先通过边框的虚实样式区分模板与目标（而非通过位置或大小），再通过边框颜色完成配对，最后通过角标位置确定旋转——三层独立的视觉编码依次解锁，每层都需要从样例中归纳出不同的规律。
</new_puzzle>

<new_puzzle>
将网格中的彩色连通区域视为"地图板块"，根据板块之间共享边界的长度建立连接关系，然后在输出中用小型邻接矩阵表示这些连接。

Input structure：
- 背景为黑色。网格中有若干大型单色 4-连通区域（板块），每个板块颜色不同。
- 板块之间可能直接相邻（共享至少一条边），也可能被黑色背景隔开。
- 网格右下角有一个小型正方形区域（由 grey 边框围成），内部为空白（全黑），其边长等于板块数量加一。

Rule：
- 按板块在网格中首次出现的位置（逐行扫描，先上后下，同行先左后右）为板块编号排序。
- 在右下角的灰色方框内绘制邻接矩阵：第一行和第一列为表头，按排序顺序填入各板块颜色（每格一个像素）。
- 对于矩阵中的每个非对角线格 (i, j)：若板块 i 与板块 j 共享边界（即存在相邻像素对），则该格填 green；否则保持黑色。
- 对角线格保持黑色。
- 输入中的板块和背景保持不变。

Key insight：
- 输入看似是一幅彩色地图，实际任务是提取拓扑邻接关系并编码为矩阵；解题者需要先发现右下角方框是输出区域，再理解行列表头是板块颜色的有序索引，最后发现填充规则是"是否共享边界"而非面积或距离。
</new_puzzle>

<new_puzzle>
根据封闭区域内"窗户"（小矩形孔洞）的排列方向选择对应的填充纹理，并用该纹理铺满整个封闭区域。

Input structure：
- 背景为黑色。网格中有若干由 blue 像素围成的封闭区域（blue 像素形成一像素宽的闭合边界），每个区域内部为黑色。
- 每个封闭区域的边界上开有一到两个"窗户"——即边界上连续缺失的像素段（长度为 2 格），形成小缺口。
- 网格的一个角落（如左上角）有两到三个纹理样本区：每个样本区由一个小矩形 blue 框围成，框内填充着不同的两色重复纹理（如水平条纹、垂直条纹、棋盘格）。每个纹理样本旁边紧邻一个方向标记——一条长度为 2 的短线段，方向为水平或垂直，颜色为 red。

Rule：
- 检查每个封闭区域的窗户方向：若窗户开在水平边界上（即缺口在上边或下边），则窗户方向为"水平"；若窗户开在垂直边界上（即缺口在左边或右边），则窗户方向为"垂直"。
- 若一个区域有两个窗户且方向不同，则窗户方向为"混合"。
- 在角落纹理样本中，找到方向标记与窗户方向匹配的纹理（水平标记对应水平窗户，垂直标记对应垂直窗户）。若窗户方向为"混合"，选择没有被其他方向使用的第三种纹理。
- 用匹配的纹理平铺填充对应封闭区域的内部（不覆盖边界），纹理的相位以区域内部左上角像素为起始对齐。
- 窗户缺口保持不变（不修复边界）。

Key insight：
- 窗户的位置不是随机破损，而是编码了该区域应使用哪种纹理的关键信息；解题者需要先从样本旁的方向标记建立"方向→纹理"的映射，再从封闭区域的边界缺口中读取方向，两步推理共同决定填充结果。
</new_puzzle>
