- `description`：根据围栏形状内的"种子"颜色在图例中查找生长模式，再按模式从种子位置向外扩展填充围栏内部。

- `Input structure`：
  - 背景色为 black。
  - 网格顶部有一行图例区，由 grey 分隔线与主区域隔开。图例区包含若干小方格，每个方格内左侧是一个颜色像素（种子色），右侧是一个 3x3 的二值模式（用 maroon 表示活跃像素，black 表示非活跃像素），表示该种子色对应的生长方向模板。生长方向模板是一个以中心像素为参照的 3x3 邻域掩码，maroon 位置表示从当前像素可以向该方向扩展一步。
  - 主区域中有若干封闭的围栏，每个围栏由 blue 像素构成不规则但封闭的环形边界（宽度为1像素）。
  - 每个围栏内部恰好有一个非 black 非 blue 的单像素"种子"，种子颜色与图例中某个条目匹配。

- `Rule`：
  - 对每个围栏内的种子像素，在图例中找到其颜色对应的 3x3 生长模式。
  - 从种子位置开始，反复执行扩展：对当前所有已填充种子色的像素，检查其 3x3 邻域中生长模式为 maroon 的方向，如果该方向的邻居是 black（围栏内部空白），则将其填充为种子色。
  - 重复扩展直到没有新像素可以填充为止（被围栏边界 blue 阻挡或已填满）。
  - 输出网格保留围栏边界和图例，种子色区域按上述规则扩展后填充。

- `Key insight`：图例中的 3x3 模式并非静态贴图，而是定义了一个各向异性的扩散规则——种子只能沿模式允许的方向生长，围栏形状决定了最终填充区域的形状，但生长模式决定了哪些角落能被到达、哪些不能。解题者需要先建立"颜色→方向模板"的映射，再模拟受限扩散过程。
</new_puzzle>

- `Input structure`：
  - 背景色为 black。
  - 网格中散布着偶数个彩色连通区域（4-连通），每个区域是单一颜色，形状不规则但保证每个区域的 bounding box 不超过 5x5。
  - 这些区域可以两两配对：同一对的两个区域形状互补——将其中一个区域的二值掩码与另一个区域的二值掩码（可能需要旋转 0/90/180/270 度之一）叠加后恰好构成一个实心矩形（无孔洞、无溢出）。
  - 每对中两个区域颜色不同；配对是唯一的（每个区域只有一个互补伙伴）。

- `Rule`：
  - 找到所有互补配对：对于每两个尚未配对的区域 A 和 B，检查 B 的形状（允许旋转）是否恰好填补 A 的 bounding box 内的空缺，使合并后形成完整矩形。
  - 对于每一对，合并时保留 A 的颜色作为矩形中 A 原本像素的颜色，B 的颜色填充 B 的像素位置。合并后的矩形同时包含两种颜色。
  - 输出网格尺寸与输入相同。将每对合并后的矩形放置在该对两个原始区域 bounding box 中心连线的中点位置（取整），矩形中心对齐该中点。
  - 若放置时矩形之间发生重叠，按配对中面积较大者优先（先放置），后放置者不覆盖已放置的像素。

- `Key insight`：核心推理有两层——第一层是发现"互补拼合成矩形"的配对规则（需要尝试旋转），第二层是发现合并后矩形的放置位置取决于原始两个碎片位置的中点。单看任一层都不足以完成题目。
</new_puzzle>

- `description`：识别网格中由分隔线划分的多个子区域，每个子区域内含一个"指令箭头"和若干目标像素；箭头的朝向和臂长编码了一种镜像变换，需要对子区域内的目标像素执行该变换。

- `Input structure`：
  - 背景色为 black。
  - 网格被 grey 的单像素宽横线和竖线划分为若干矩形子区域（类似表格的单元格），每个子区域大小在 5x5 到 10x10 之间。
  - 每个子区域内有：
    - 一个由 red 像素构成的"箭头"：箭头由一条直线段（箭头柄）和末端的一个 V 形尖端（箭头头）组成。箭头柄沿四个正方向之一延伸（上/下/左/右），柄的长度为 1 到 3 个像素。V 形尖端由 2 个像素构成，分别位于柄末端像素的两个垂直方向邻居位置。
    - 若干散落的非 red 非 grey 非 black 的彩色像素（目标像素），颜色可能不同。

- `Rule`：
  - 箭头朝向（箭头头所指的方向）定义了镜像轴的方向：箭头朝上或朝下表示镜像轴为水平线，箭头朝左或朝右表示镜像轴为垂直线。
  - 箭头柄的长度 L 定义了镜像轴的偏移：镜像轴位于子区域中心沿箭头指向方向偏移 L 个像素处。例如，箭头朝右且柄长为 2，则垂直镜像轴位于子区域中心向右偏移 2 个像素的那一列。
  - 对子区域内每个目标像素，按上述镜像轴做镜像翻转，将翻转后的像素绘制到对应位置（保持原色）。原始目标像素保留不变（即输出中同时存在原像素和镜像像素）。
  - 如果镜像位置落在 grey 分隔线上或子区域外，则不绘制该镜像像素。箭头本身在输出中被擦除（替换为 black）。

- `Key insight`：解题者需要两步非平凡推理：首先从箭头的形态中提取两个独立信息（朝向编码轴方向，柄长编码轴偏移），然后将这两个信息组合确定每个子区域内的具体镜像轴位置。箭头被擦除这一事实进一步增加了识别难度——解题者必须先注意到箭头的存在及其编码含义。

<new_puzzle>
- `description`：在包含多个"信号塔"和"接收器"的网格中，每座信号塔向四个方向发射彩色射线，射线在经过接收器时改变接收器的颜色，而接收器的原始颜色决定了射线是否穿透或被吸收。

- `Input structure`：
  - 背景色为 black。
  - 网格中有若干"信号塔"：每座信号塔是一个 3x3 的实心方块，颜色各不相同（可能为 blue、green、yellow、magenta 等），每座塔的颜色即为其发射的射线颜色。
  - 网格中还有若干"接收器"：每个接收器是单个像素，颜色为 orange 或 azure。接收器散布在信号塔之间的空白区域。
  - 信号塔和接收器不会重叠，且信号塔之间不会在同一行或同一列上直接对齐（即任意两座塔不共享同一行或同一列）。

- `Rule`：
  - 每座信号塔从其 3x3 方块的四条边的中心像素分别向上、下、左、右发射一条射线。射线沿该方向逐像素延伸，将沿途的 black 像素染为塔的颜色。
  - 当射线遇到 orange 接收器时：射线穿透该接收器继续前进，同时将接收器的颜色改为射线的颜色（塔色）。
  - 当射线遇到 azure 接收器时：射线被吸收并停止，接收器的颜色改为射线的颜色（塔色）。
  - 当射线遇到另一座信号塔（3x3 方块的任何像素）时，射线停止，信号塔不变。
  - 当射线遇到已被其他射线染色的非 black 像素时，射线停止（先到先得，不覆盖）。
  - 射线到达网格边界时停止。
  - 多座信号塔同时发射；处理顺序：按信号塔在网格中从上到下、从左到右的顺序依次处理每座塔的四条射线。

- `Key insight`：解题的关键在于发现接收器的两种颜色代表两种不同的射线交互行为（穿透 vs 吸收），而非仅仅是装饰性颜色差异。这构成第一层推理。第二层推理在于信号塔的处理顺序会影响射线能延伸多远——先处理的塔的射线会阻挡后处理的塔的射线路径，因此解题者还需要推断出处理顺序规则（从上到下、从左到右）。
</new_puzzle>

<new_puzzle>
- `description`：根据网格边缘的颜色标记推断出行列置换规则，对网格内部的图案执行行置换和列置换的复合变换。

- `Input structure`：
  - 背景色为 black。
  - 网格大小为 (N+1) x (N+1)，其中 N 在 4 到 8 之间。
  - 第 0 行（最顶行）的第 1 到第 N 列各有一个彩色像素，颜色互不相同，共 N 种颜色。这些像素称为"列标签"，表示每列的初始标识。
  - 第 0 列（最左列）的第 1 到第 N 行各有一个彩色像素，颜色与列标签使用相同的 N 种颜色但排列不同。这些像素称为"行标签"。
  - 内部区域（第 1 到第 N 行，第 1 到第 N 列）包含一个由多种颜色组成的图案（使用的颜色与边缘标签颜色无关，可能是 grey、maroon 等其他颜色），图案中也包含 black 背景像素。
  - 位于 (0, 0) 的角落像素为 black（空）。

- `Rule`：
  - 列标签定义了列的目标排列：第 0 行从左到右读取列标签颜色，得到一个颜色序列 C1, C2, ..., CN。
  - 行标签定义了行的目标排列：第 0 列从上到下读取行标签颜色，得到一个颜色序列 R1, R2, ..., RN。
  - 确定列置换：找到列标签序列中每种颜色在行标签序列中的位置。具体来说，列 j 的标签颜色为 Cj，找到 Cj 在行标签序列中出现的位置 k，则列 j 的内容应移动到列 k 的位置。
  - 确定行置换：找到行标签序列中每种颜色在列标签序列中的位置。具体来说，行 i 的标签颜色为 Ri，找到 Ri 在列标签序列中出现的位置 m，则行 i 的内容应移动到行 m 的位置。
  - 先执行列置换，再对结果执行行置换。
  - 输出仅包含变换后的 N x N 内部区域（不含标签行和标签列）。

- `Key insight`：解题者面临三层推理挑战。第一层是识别边缘彩色像素是"标签"而非图案的一部分。第二层是发现两组标签之间的颜色对应关系编码了一种置换映射——每种颜色在另一组标签中的位置定义了移动目标。第三层是确定置换的执行顺序（先列后行），因为两种顺序会产生不同结果，解题者需要从样例中推断正确顺序。
</new_puzzle>
