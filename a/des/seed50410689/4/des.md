<description>
根据封闭区域内的种子颜色，用对应颜色的纹理图案填充该区域。

Input structure:
- 背景为黑色。网格中有若干由灰色（Grey）像素构成的一像素宽的封闭围栏，围成不规则的封闭区域。
- 网格的某个角落（如左上角）有一个"纹理字典"区域，由一个小的灰色矩形框包围。字典内部被水平分为若干行，每行左侧第一个像素是一个彩色"键"像素（如 Red、Blue、Green 等不同颜色），其右侧紧跟一段由同色像素组成的小纹理图案（如水平条纹、棋盘格、对角线等），纹理图案宽度固定为 3 个像素、高度固定为 2 行。
- 在主网格的每个封闭区域内部，恰好有一个单独的彩色"种子"像素，其颜色与字典中某个键颜色相同。

Rule:
- 对每个封闭区域，找到其内部的种子像素颜色，在纹理字典中查找对应键的纹理图案。
- 用该纹理图案以平铺（tiling）方式填充整个封闭区域：以区域左上角的像素坐标为平铺起点，将 3×2 的纹理块反复平铺，覆盖区域内所有非灰色、非种子的黑色像素。超出区域边界的纹理部分被裁剪。
- 种子像素本身被纹理覆盖（不保留）。
- 灰色围栏和字典区域在输出中保持不变。

Key insight: 需要先识别纹理字典中每种颜色对应的图案模板，再将每个封闭区域内的种子颜色与字典匹配，最后用正确的图案平铺填充——字典查找与空间平铺是两个独立的推理层。
</description>

<description>
将散落的彩色碎片按颜色配对，然后沿两块碎片之间的连线方向将它们滑动合并为完整的矩形。

Input structure:
- 背景为黑色。网格上散布着若干彩色形状，每种非黑颜色恰好出现两个形状（碎片对）。
- 同色的两个碎片形状互补：将它们沿某个正交方向（上下或左右）拼合后，恰好构成一个无间隙的实心矩形。
- 每对碎片在拼合方向上严格对齐（即它们在垂直于拼合方向的坐标范围完全一致），但中间隔着若干行或列的黑色空隙。
- 不同颜色对之间不会在空间上互相干扰（拼合路径不交叉）。

Rule:
- 对每种颜色，找到该颜色的两个碎片。
- 确定拼合方向：两个碎片在水平或垂直方向上对齐，选择对齐的那个轴作为拼合轴。
- 沿拼合轴将两个碎片向彼此滑动，直到它们的边缘像素相邻（中间无空隙），合并成一个完整矩形。
- 其他颜色的碎片对同理处理。所有碎片对独立拼合，不影响彼此。

Key insight: 解题者需要先通过颜色配对识别哪两个形状属于同一组，再判断拼合方向（通过观察哪个轴上两者坐标范围一致），最后理解"滑动合并"的含义——碎片不是原地变化而是平移到相邻位置，形成完整矩形。
</description>

<description>
在管道网络中追踪信号流动，信号在交叉节点处根据节点颜色改变方向，最终在信号到达的终点处标记输出颜色。

Input structure:
- 背景为黑色。网格中有由灰色（Grey）像素构成的一像素宽的水平和垂直管道线段，形成正交网络。
- 管道线段的交叉点处有一个彩色像素（非黑非灰），称为"路由节点"，颜色为 Red、Blue 或 Green 之一。
- 网格边缘有若干管道端点（管道的一端触及网格边界），其中恰好有一个端点处标有一个 Orange 像素作为"信号源"。其余边界端点处为灰色（无标记）。

Rule:
- 信号从 Orange 信号源出发，沿管道方向（进入网格内部的方向）流动。
- 信号沿灰色管道直线前进，直到遇到一个彩色路由节点。
- 路由节点的颜色决定转向规则：Red 表示右转 90°，Blue 表示左转 90°，Green 表示直行不转弯。转向方向相对于信号的当前行进方向定义。
- 信号继续沿新方向前进，遇到下一个路由节点再次转向，如此反复。
- 当信号沿管道到达一个网格边缘端点（非信号源的端点）时停止。
- 输出中，信号经过的所有管道像素（包括路由节点）变为 Orange 色，信号最终到达的边缘端点也标为 Orange。未经过的管道和节点保持原色不变。

Key insight: 解题者需要发现三种颜色节点各自对应的转向规则（左转、右转、直行），这需要通过多个样例中信号的实际路径来归纳——单看一个节点无法确定规则，必须追踪完整路径后反推每种颜色的含义。
</description>

<description>
根据容器内部小图案的朝向，选择对应的外部模板，将模板缩放后覆盖到容器上方。

Input structure:
- 背景为黑色。网格下方有一排"模板展示区"，包含 4 个小的彩色图案模板，每个模板是一个不同的 3×3 非对称图形（如 L 形、T 形等），分别用 Red、Blue、Green、Yellow 四种颜色绘制。每个模板旁边（正下方一行）有一个 Maroon 像素标记该模板的"锚点方位"——Maroon 像素位于模板 3×3 范围的四角之一（左上、右上、左下、右下），表示该模板的朝向标识。
- 网格上方有若干个由灰色边框围成的正方形"容器"（内部边长为 3 的倍数，如 3×3、6×6、9×9）。每个容器内部的某一角恰好有一个单独的 Maroon 像素。

Rule:
- 对每个容器，观察其内部 Maroon 像素所在的角位（左上、右上、左下、右下）。
- 在模板展示区中，找到 Maroon 锚点方位与容器中 Maroon 方位相同的那个模板。
- 计算缩放倍数：容器内部边长 ÷ 3。
- 将匹配的模板按该倍数整数放大（每个像素变成 k×k 的方块），然后填入容器内部，替换原有内容（包括 Maroon 像素）。
- 灰色边框保持不变，模板展示区保持不变。

Key insight: 解题者需要发现两层规则——第一层是通过 Maroon 像素的角位来匹配模板（而非通过颜色或形状），第二层是根据容器大小确定缩放倍数。Maroon 像素同时充当"选择器"和"定位器"的双重角色是核心隐蔽点。
</description>

<description>
将网格中的彩色像素群按照"影子投射"规则向指定方向延伸，影子长度由同色围栏内封闭的空洞数量决定，影子颜色由围栏形状的开口方向决定。

Input structure:
- 背景为黑色。网格中有若干个由单一颜色像素构成的一像素宽的矩形围栏（空心矩形框），每个围栏颜色不同（如 Red、Blue、Green 等）。
- 每个围栏的某一条边上恰好有一个缺口（该边上缺少一个像素）。
- 每个围栏内部有若干个 Azure 像素散落在黑色背景上，这些 Azure 像素称为"空洞标记"。
- 在围栏外部、与缺口相邻的位置，有一个与围栏同色的单独像素，称为"投射起点"。

Rule:
- 对每个围栏，首先数出其内部 Azure 空洞标记的数量 N。
- 确定缺口所在的边（上、下、左、右），缺口方向即为"影子投射方向"：上边缺口则向上投射，下边缺口则向下投射，左边缺口则向左投射，右边缺口则向右投射。
- 从投射起点出发，沿投射方向绘制一条长度为 N 个像素的单像素宽射线，颜色与围栏颜色相同。
- 围栏内部的 Azure 空洞标记在输出中被移除（变为黑色）。
- 围栏本身（含缺口）和投射起点保持不变。

Key insight: 解题者需要发现三个独立的映射关系并将它们串联：（1）围栏内部 Azure 像素的数量决定射线长度，（2）围栏边上的缺口位置决定射线方向，（3）围栏外的同色像素是射线起点。这三条线索分散在不同的视觉元素中，必须全部正确关联才能得出变换规则。
</description>

<description>
根据网格中"镜面"的位置和角度反射彩色光线，光线在镜面间来回弹射，最终将光线轨迹上经过的背景像素染色。

Input structure:
- 背景为黑色。网格边缘的某一侧有若干个彩色像素（每种颜色最多一个），作为"光源"，光源颜色各不相同（如 Red、Blue、Green）。每个光源发射方向为垂直于其所在边界、指向网格内部的方向（即上边光源向下、左边光源向右，以此类推）。
- 网格内部散布着若干个由两个相邻 Grey 像素组成的"镜面"，每个镜面要么是水平排列（左右相邻）要么是垂直排列（上下相邻）。
- 水平镜面将垂直方向的光线反射为水平方向（左或右），垂直镜面将水平方向的光线反射为垂直方向（上或下）。

Rule:
- 每条光线从光源出发，沿初始方向直线前进，逐像素染上光源颜色。
- 当光线到达一个镜面时，光线被反射：水平镜面将上下运动变为左右运动，垂直镜面将左右运动变为上下运动。具体反射方向取决于光线击中镜面的哪一侧——光线从镜面的哪一侧到达，就向镜面延伸方向的"远离光线来源"的一端转向。即：光线打到水平镜面时，若从上方到达，则转向镜面两端中离光线入射列更远的那一端方向；从下方到达同理。垂直镜面类推。
- 光线继续前进直到遇到下一个镜面再次反射，或到达网格边缘停止。
- 镜面像素本身不被染色，保持 Grey。
- 若两条不同颜色的光线轨迹交叉于同一像素，该像素变为 Yellow。

Key insight: 解题者需要先理解两种镜面朝向各自的反射行为（水平镜面改变垂直分量，垂直镜面改变水平分量），再发现反射后的具体方向取决于光线击中镜面的相对位置，最后注意光线交叉的混色规则。多次反射形成的路径需要逐步追踪才能确认。
</description>

<description>
将散落的彩色方块按层级嵌套关系组装成同心矩形框结构，嵌套顺序由方块面积从大到小决定，嵌套位置由方块内部的定位标记决定。

Input structure:
- 背景为黑色。网格中散布着若干个不同颜色的实心矩形方块（每种颜色一个），大小各不相同。
- 每个方块内部恰好有一个单像素的 Maroon 标记点，位于方块内部的某个位置（不在边缘）。
- 网格的一个角落有一个小的黑色区域中放置了一个单独的 Maroon 像素，称为"锚点"。

Rule:
- 将所有彩色方块按面积从大到小排序。
- 最大的方块首先放置：将其 Maroon 标记点对齐到锚点位置，整个方块平移至该位置。
- 将该方块"掏空"为仅保留一像素宽的外框（空心矩形框），内部变为黑色。
- 第二大的方块同样将其 Maroon 标记点对齐到同一个锚点位置，放置后也掏空为外框。
- 依次对所有方块重复此操作。由于方块大小递减且 Maroon 点都对齐到同一锚点，最终形成以锚点为公共参考点的同心（但不一定居中对称的）嵌套矩形框。
- 输出中，各层框保持各自原有颜色。若不同层的框像素重叠，外层（更大的）被内层（更小的）覆盖。

Key insight: 解题者需要发现三个非显然的规律：（1）方块按面积排序决定嵌套的从外到内顺序；（2）每个方块内的 Maroon 标记点是定位锚，所有标记点对齐到同一全局锚点；（3）实心方块变为空心框后嵌套组装——原始方块的形状和颜色只是"材料"，最终产物的结构由面积排序和锚点对齐共同决定。
</description>
</new_puzzle>
