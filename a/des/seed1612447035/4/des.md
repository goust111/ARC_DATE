<new_puzzle>
根据嵌套框架的层级深度对内部填充色进行由外向内的级联替换。

Input structure:
- bg = 最常见颜色（black）。网格中有若干由不同颜色绘制的矩形框架，框架之间存在嵌套关系（一个框架完全包含在另一个框架内部）。
- 每个框架是单色的 1 像素宽空心矩形边框，框架内部可能包含更小的框架，也可能包含一个单色填充区域（叶子区域）。
- 网格的某个角落（例如左下角）有一个小型"调色板"区域：一列纵向排列的单色像素，从上到下分别对应嵌套深度 1、2、3……的替换颜色。

Rule:
- 首先识别所有矩形框架及其嵌套层级关系：最外层框架深度为 1，被其直接包围的框架深度为 2，以此类推。
- 读取调色板中从上到下的颜色序列 c1, c2, c3, ...。
- 对每个框架：将该框架的边框颜色替换为调色板中对应其深度的颜色（深度 d 的框架使用 cd）。
- 叶子区域（最内层无子框架的填充区域）的颜色替换为其所在深度对应的调色板颜色。
- 调色板本身在输出中被擦除（填充为 bg）。

Key insight: 解题者需要先识别框架的嵌套包含关系以确定深度，再将深度与调色板位置建立映射——两步推理缺一不可，且嵌套深度必须通过空间包含关系而非颜色来判断。
</new_puzzle>

<new_puzzle>
将散落的碎片拼入镂空模板，但每块碎片需先按模板边缘的箭头标记旋转到正确朝向。

Input structure:
- bg = 最常见颜色（black）。网格中有一个较大的单色矩形区域（模板色为 grey），模板内部被挖去若干不规则形状的孔洞（孔洞区域为 bg 色）。
- 模板边缘紧邻每个孔洞的外侧有一个由 2 像素组成的 L 形箭头标记（颜色与对应碎片颜色相同）。L 形由两个正交相邻的像素构成，其中一个像素紧贴孔洞边界（称为"指向臂"），另一个像素沿孔洞边界方向延伸（称为"沿边臂"）。指向臂从模板内部指向孔洞的方向即为"目标插入方向"。
- 网格其他区域散布着若干彩色碎片（每块碎片是一个由单一非 bg、非 grey 颜色组成的 4-连通区域）。每块碎片的颜色与恰好一个箭头标记的颜色相同。
- 每块碎片自身也有一个 L 形突起（比碎片主体多出的 2 像素拐角），该突起的朝向记录了碎片的"原始插入方向"。

Rule:
- 通过颜色将每块碎片与其对应的箭头标记配对。
- 比较碎片 L 形突起的朝向与箭头标记指向臂的朝向，计算从碎片原始朝向到目标朝向所需的 90 度顺时针旋转次数（0、1、2 或 3 次）。
- 将碎片旋转对应次数后，平移填入对应的孔洞中，使碎片形状与孔洞完全吻合。
- 输出为模板 + 所有已填入的碎片，散落位置的碎片和箭头标记均被擦除为 bg。

Key insight: 孔洞的归属通过颜色匹配解决，但正确的旋转角度必须通过比较碎片自身的 L 形突起方向与模板箭头标记的指向来确定——颜色匹配是第一层推理，方向对比编码旋转量是第二层推理。
</new_puzzle>

<new_puzzle>
根据种子像素的颜色从图案库中选取图案，再按种子所在象限确定图案的翻转方式，最终以种子为中心铺设图案。

Input structure:
- bg = 最常见颜色（black）。网格被一条水平线和一条垂直线（均为 grey 色，宽 1 像素）分割为四个象限。
- 网格的左上角紧贴网格边缘有一个"图案库"区域：包含 2-4 个小型矩形图案（每个图案的像素均为同一种颜色，绘制在 bg 上，图案之间用 1 列 bg 间隔）。每个图案的绘制颜色即为其"键颜色"，各图案键颜色互不相同。图案为非对称形状（翻转后与原始不同）。
- 四个象限中各散布着 0-3 个"种子像素"——每个种子是一个单独的非 bg、非 grey 像素，其颜色恰好等于图案库中某个图案的键颜色。

Rule:
- 对每个种子像素，在图案库中找到键颜色匹配的图案。
- 根据种子所在象限决定图案的翻转方式：左上象限 = 原始不翻转；右上象限 = 水平翻转（左右镜像）；左下象限 = 垂直翻转（上下镜像）；右下象限 = 水平 + 垂直翻转（等价于旋转 180 度）。
- 将翻转后的图案以种子像素为中心点铺设到网格上（图案包围盒的中心像素对齐种子位置）。
- 图案库区域在输出中保持不变；grey 分割线保持不变。若多个图案铺设后发生重叠，按种子从左到右、从上到下的扫描顺序处理，后铺设的图案覆盖先铺设的。

Key insight: 解题者需要独立发现三层规则：(1) 种子颜色与图案库颜色匹配确定选用哪个图案；(2) 种子所在象限编码翻转方式（四种象限对应四种翻转）；(3) 图案以种子为中心对齐铺设——其中象限-翻转映射关系最为隐蔽，需跨样例对比才能归纳。
</new_puzzle>

<new_puzzle>
沿彩色路径网络传播信号，信号在交叉节点处根据节点颜色改变传播方向，最终点亮到达的终点标记。

Input structure:
- bg = 最常见颜色（black）。网格中有由 grey 像素绘制的正交路径网络（宽 1 像素的水平和垂直线段），路径在某些位置交叉形成十字交叉点。
- 每个交叉点的中心像素被替换为一个非 grey、非 bg 的颜色（red、blue、green 或 yellow 之一），该颜色编码了信号到达该交叉点时的转向规则。
- 路径网络的某一个末端有一个"信号源"标记：一个 orange 像素紧邻该路径末端像素（orange 像素本身不在路径上，而是与路径末端正交相邻）。
- 路径网络的若干其他末端各有一个"终点"标记：一个 maroon 像素紧邻路径末端。

Rule:
- 信号从 orange 信号源出发，进入其相邻的 grey 路径末端像素，初始传播方向为从 orange 像素指向该路径像素的方向。
- 信号沿路径直线传播（将经过的 grey 像素着色为 azure），直到遇到交叉点。
- 在交叉点处根据中心像素颜色转向：red = 向右转 90 度；blue = 向左转 90 度；green = 直行不转向；yellow = 掉头 180 度。转向以信号当前行进方向为参考。
- 信号沿新方向继续传播直到下一个交叉点或路径末端。
- 信号最终到达某个路径末端，该末端旁的 maroon 终点标记被重新着色为 orange，表示被"点亮"。其余 maroon 终点标记保持不变。

Key insight: 解题者需要先通过跨样例追踪信号的完整路径来破译四种颜色与转向方向的对应关系（这是一个需要多样例交叉验证的归纳过程），然后才能在新测试中模拟信号传播以确定哪个终点被点亮——颜色-转向映射关系的破译是核心难点。
</new_puzzle>

<new_puzzle>
根据围栏内种子的数量决定围栏的膨胀层数，膨胀后新增边框的颜色由种子颜色的多数投票决定。

Input structure:
- bg = 最常见颜色（black）。网格中有若干互不接触的闭合"围栏"——每个围栏是一个由 grey 像素绘制的 1 像素宽闭合矩形边框。
- 每个围栏内部散布着若干"种子像素"（非 bg、非 grey 的单个彩色像素），种子可以是 red、blue、green 等颜色。同一围栏内可能有多种颜色的种子，但总有一种颜色的种子数量严格多于其他颜色。
- 围栏之间有足够的 bg 空间供膨胀扩展而不会重叠。

Rule:
- 对每个围栏，数出其内部种子像素的总数 N（N 不超过 5）。
- 将围栏向外膨胀 N 层：在围栏外部依次添加 N 圈同心矩形边框环，每一层环宽 1 像素，形状与原围栏同心等距扩大（第 k 层环的矩形比原围栏四边各向外扩展 k 像素）。
- 统计围栏内出现次数最多的种子颜色，用该颜色绘制所有新增的膨胀层边框。
- 原始 grey 围栏边框保留不变；围栏内部的种子像素保留不变。

Key insight: 解题者需要分别发现两条作用于同一组种子不同属性的独立规则再组合：(1) 种子总数控制膨胀层数——这是从计数到几何尺度的映射；(2) 种子中的多数颜色决定膨胀层的着色——这是投票机制。两条规则必须同时正确归纳才能重现输出。
</new_puzzle>

<new_puzzle>
将散布的形状碎片沿引力方向堆叠到地面，然后根据上下相邻碎片的水平接触面宽度决定是否触发颜色融合。

Input structure:
- bg = 最常见颜色（black）。网格底部有一条 1 像素宽的 grey 水平线作为"地面"。
- 网格中散布着若干不同颜色的连通碎片（每块碎片由单一非 bg、非 grey 颜色组成的 4-连通区域，面积 3-8 像素）。碎片之间互不接触，且都悬浮在地面上方。
- 每块碎片正下方的地面线上有一个与碎片同色的 1 像素标记，指示碎片下落后的水平对齐位置（碎片包围盒的水平中点列应对齐该标记所在列）。

Rule:
- 每块碎片保持形状不变，垂直向下平移直到其最底部像素紧贴地面线上方或紧贴已堆叠碎片的最顶部像素上方（取先接触者）。碎片水平位置对齐其地面标记。
- 碎片按从低到高的原始位置顺序依次下落（原始位置离地面最近的碎片先落）。
- 堆叠完成后执行颜色融合检查：对每对上下直接接触的碎片，计算它们的水平接触面宽度（即两块碎片在接触行中列坐标重叠的像素数）。若接触面宽度 >= 2 像素，则面积较小的碎片变为面积较大碎片的颜色。若面积相同则各自保持颜色不变。
- 地面标记在输出中被擦除为 grey（与地面线融合）。

Key insight: 解题者需要依次发现三层规则：(1) 地面标记的颜色匹配决定水平对齐位置；(2) 碎片按距地面远近顺序依次下落堆叠；(3) 接触面宽度阈值（>= 2）触发颜色融合且融合方向由面积大小决定——第三层最为隐蔽，因为它仅在堆叠结果确定后才生效。
</new_puzzle>

<new_puzzle>
从网格边缘的彩色入口发射射线，射线遇到镜面色块时反射，最终在不同颜色射线交汇的像素处生成混合色。

Input structure:
- bg = 最常见颜色（black）。网格四条边上分布着若干单色像素作为"入口"，每个入口颜色为 red、blue 或 yellow 之一。入口像素位于网格最外圈。
- 网格内部散布着若干 grey 色小型线段作为"镜面"。每个镜面是 1 像素宽、2-3 像素长的水平或垂直线段。
- 网格内部其余区域为 bg。

Rule:
- 每个边缘入口向网格内部发射一条射线，方向为垂直于该边缘向内（上边入口向下、下边入口向上、左边入口向右、右边入口向左）。
- 射线沿直线传播，将路径上的 bg 像素着色为入口颜色。
- 当射线遇到水平镜面时：若射线方向为垂直（上或下），则反射为水平方向；反射朝向取决于射线击中镜面的位置——击中镜面左半部分则向右反射，击中镜面右半部分则向左反射。当射线遇到垂直镜面时同理：水平射线反射为垂直方向，击中上半部分则向下，击中下半部分则向上。
- 射线反射后继续传播直到再次遇到镜面（可多次反射）或到达网格边缘。
- 当两条不同颜色的射线路径在同一像素交叉时，该像素着色为混合色：red + blue = magenta，red + yellow = orange，blue + yellow = green。若三色交叉则显示为 grey。同色射线交叉不改变颜色。

Key insight: 解题者需要独立归纳三层机制：(1) 边缘入口的射线发射方向规则；(2) 镜面反射的方向由击中位置决定（位置敏感反射）；(3) 不同颜色射线交汇处遵循颜色混合规则——其中镜面反射的位置敏感性和颜色混合规则各自需要独立的跨样例归纳。
</new_puzzle>
