<description>
根据封闭区域内种子像素的颜色，选择对应的外部模板精灵，将其旋转后填充到封闭区域中。

Input structure:
- bg = 最常见颜色（black）。
- 一种结构色（如 grey）绘制若干互不相连的封闭围墙，每个围墙内部恰好包含一个单像素种子，种子颜色各不相同。
- 每个围墙的外轮廓上恰好有一个缺口（一格宽），缺口位于围墙的上、下、左、右四侧之一。
- 网格的某个角落区域（用另一种结构色如 maroon 框出）中排列着若干小型模板精灵，每个精灵恰好用一种颜色绘制，颜色与某个种子颜色一一对应。每个模板精灵的尺寸不超过围墙内部空间。

Rule:
- 第一层：通过颜色匹配，为每个封闭围墙找到对应的模板精灵（种子颜色 = 精灵颜色）。
- 第二层：根据围墙缺口所在的方位确定旋转量——缺口在上侧表示不旋转（0°），缺口在右侧表示顺时针旋转 90°，缺口在下侧表示旋转 180°，缺口在左侧表示顺时针旋转 270°。
- 将旋转后的模板精灵放置到围墙内部，左上角对齐围墙内部区域的左上角，精灵使用种子的颜色绘制。
- 种子像素本身被精灵覆盖（如果精灵覆盖了该位置）或保留（如果精灵未覆盖该位置）。
- 输出中移除角落的模板展示区域（填充为 bg），围墙结构保持不变。

Key insight: 缺口方位不只是一个视觉特征，它编码了精灵的旋转指令；解题者需要先通过颜色匹配找到精灵，再通过缺口方位推断旋转角度，两步都需要非平凡的归纳。
</description>

<description>
沿彩色路径传播信号，信号在交叉点根据路径颜色的优先级选择分支方向，最终在路径末端生成与传播步数等长的标记条。

Input structure:
- bg = 最常见颜色（black）。
- 若干条由不同颜色绘制的单像素宽路径（4-连通），路径之间可以交叉（交叉点处两条路径共享同一个像素，该像素使用其中一条路径的颜色）。
- 每条路径有且仅有两个端点（只有一个4-邻居属于该路径的像素）。
- 网格边缘处有一个单独的 red 像素作为信号源，它与恰好一条路径的一个端点 4-相邻。
- 网格中还有一个小的矩形色块图例区（如 2xN），图例区的每一行包含两个像素：左侧是一种路径颜色，右侧是另一种路径颜色，表示"当信号沿左侧颜色路径到达交叉点时，优先转向右侧颜色路径继续传播"。

Rule:
- 信号从 red 像素出发，进入与之相邻的路径端点，沿该路径传播。
- 信号沿路径逐像素前进（不回头），每经过一个像素计为一步。
- 当信号到达一个交叉点时（该像素同时属于两条路径），查阅图例：如果当前路径颜色在图例某行的左侧出现，则信号转向该行右侧颜色对应的路径继续前进；如果图例中没有匹配项，则信号继续沿当前路径不转弯。
- 信号传播直到到达路径的一个死端（端点）为止。
- 在该死端位置，沿死端处路径的延伸方向（即信号到达的最后一步的方向）向外绘制一条与传播总步数等长的线段，颜色为死端所在路径的颜色。

Key insight: 图例定义了交叉点处的路径切换规则，解题者必须先破译图例的"当前色→转向色"映射关系，然后模拟信号在路径网络中的传播路径，最后将步数转化为输出线段的长度——三层推理环环相扣。
</description>

<new_puzzle>
<description>
识别网格中散落的成对形状，根据两个形状之间的相对位置关系，用连接线桥接它们，并在连接线的中点放置一个由两者颜色混合规则决定的标记像素。

Input structure:
- bg = 最常见颜色（black）。
- 网格中散布着若干小型单色连通块（4-连通），每个连通块是一个不超过 4 像素的小形状。
- 这些形状成对出现：同一对中的两个形状完全全等（形状相同，可含旋转或翻转），但颜色不同。
- 每对形状在水平方向或垂直方向上严格对齐（即两个形状的质心在同一行或同一列上）。
- 网格的某个边缘行或列上有一排颜色对标记：每两个相邻像素构成一个颜色对 (A, B)，中间用 bg 隔开，表示颜色 A 和颜色 B 配对后产生的结果颜色等于标记对右侧（或下方）紧邻的第三个像素颜色。即格式为：A-B-gap-C，其中 C 是 A 与 B 的混合结果色。

Rule:
- 第一层：通过形状全等性（允许旋转和翻转）将散落的连通块配对。同一形状只会出现两次。
- 第二层：对于每一对，在两个形状之间沿它们对齐的方向（水平或垂直）绘制一条连接线。连接线颜色取两者中在网格中位置靠上或靠左的那个形状的颜色。连接线连接两个形状最近边缘之间的空隙。
- 第三层：查阅边缘的颜色混合图例，找到该对的两种颜色对应的结果色 C。在连接线的中点像素处（若线段长度为偶数，则取靠近起点的那个中间位置），将该像素改为结果色 C。

Key insight: 解题者需要先通过形状匹配（而非颜色匹配）发现配对关系，再推断连接线的绘制规则，最后破译颜色图例来确定中点标记色——配对依据与标记依据使用了不同的属性维度，增加了机制的隐蔽性。
</description>
</new_puzzle>

<description>
将网格中的多层嵌套框架拆解为独立层，按嵌套深度从内到外依次水平排列输出，每层框架内部的填充图案由其相邻外层框架的颜色决定。

Input structure:
- bg = 最常见颜色（black）。
- 网格中央有一组同心嵌套的矩形空心框架（每个框架由单像素宽的线条绘制，框架之间间隔至少一个像素）。每个框架使用不同的颜色。
- 最内层框架内部有一个小型非 bg 图案（形状不规则，由某种颜色绘制）。
- 嵌套层数在 2 到 4 层之间。

Rule:
- 第一层：识别所有嵌套框架并确定它们的嵌套层级（最内层为第 1 层，向外依次递增）。
- 第二层：将每个框架及其内部内容提取为独立的子网格。最内层框架包含其内部的原始图案；其余每层框架的内部区域需要被填充——填充内容为最内层图案的副本，但颜色改为该框架紧邻的外层框架的颜色（最外层框架的内部图案使用 bg 中不存在的、网格中未使用过的颜色——实际上最外层没有更外层，所以其内部图案保持最内层图案的原始颜色）。
- 第三层：输出网格将这些提取出的子网格按从内层到外层的顺序从左到右水平排列，子网格之间用一列 bg 像素分隔。每个子网格仅包含该层框架线条及其内部填充。

Key insight: 拆解嵌套结构需要正确判断层级关系；每层的填充颜色不取决于自身而取决于相邻外层的颜色，这种"向外借色"的规则需要解题者观察多个样例后才能归纳出来，而非仅凭单个样例就能猜到。
</description>

<new_puzzle>
<description>
根据网格中"投影仪"方块在墙壁上的投影重叠情况，确定被遮挡区域的颜色叠加结果，并在墙壁上绘制最终的彩色投影图。

Input structure:
- bg = 最常见颜色（black）。
- 网格中有一条贯穿整个网格的水平或垂直直线作为"墙壁"，由 grey 像素绘制。
- 墙壁的一侧（称为"光源侧"）散布着若干小型矩形色块（不超过 3x3），每个色块使用不同的非 bg、非 grey 颜色，称为"投影仪"。
- 墙壁的另一侧为空（全 bg）。
- 每个投影仪与墙壁之间可能有也可能没有 bg 间隔。

Rule:
- 第一层：确定投影方向——所有投影仪位于墙壁的同一侧，投影方向为从投影仪垂直朝向墙壁的方向。
- 第二层：每个投影仪向墙壁做垂直投影——将投影仪的每一列（若墙壁为垂直线则为每一行）像素投影到墙壁上对应的位置。投影仪在墙壁上的投影区域即为与投影仪同行（或同列）的墙壁像素段。
- 第三层：在墙壁上绘制投影结果。若墙壁某像素只被一个投影仪投影覆盖，则该像素变为该投影仪的颜色。若被多个投影仪同时覆盖（投影重叠），则使用以下规则：距离墙壁最近的投影仪的颜色优先（覆盖其他颜色）。若距离相同，则保持 grey（墙壁原色）不变。
- 未被任何投影覆盖的墙壁像素保持 grey。
- 投影仪本身及其所在侧的内容在输出中保持不变。

Key insight: 解题者需要先理解"垂直投影到墙壁"的几何映射关系，再发现重叠区域的颜色由距离优先级决定——距离近的投影仪"遮挡"距离远的，这模拟了现实中近处物体优先投影的直觉，但需要从样例中归纳出距离优先规则而非简单的颜色覆盖顺序。
</description>
</new_puzzle>

<description>
将散落在网格中的碎片拼回到带有颜色提示槽的底座上，碎片的放置顺序由底座槽位中的层级标记决定，后放置的碎片覆盖先放置的碎片。

Input structure:
- bg = 最常见颜色（black）。
- 网格底部有一个由 grey 像素绘制的矩形底座（实心矩形，高度约 2-3 像素，宽度接近网格宽度）。
- 底座的顶面（最上面一行）嵌有若干彩色像素，称为"槽位标记"。每个槽位标记占一个像素，颜色各不相同。
- 网格上方散布着若干小型碎片（4-连通连通块），每个碎片由某种颜色绘制，碎片颜色与某个槽位标记颜色一一对应。
- 网格中还有一个小型"层级条"——一行相邻的彩色像素序列（与底座分离，通常在网格角落），其中包含所有槽位标记颜色，从左到右的排列顺序表示放置的先后顺序（左侧先放，右侧后放）。

Rule:
- 第一层：通过颜色匹配，将每个碎片与底座上的槽位标记配对。
- 第二层：将每个碎片向下平移，使碎片的最底行像素的水平中点对齐其对应槽位标记的列位置，碎片底边紧贴底座顶面上方（即碎片最下一行像素位于底座顶面的正上方一行）。
- 第三层：读取层级条中颜色的排列顺序，按从左到右的顺序依次放置碎片。先放置的碎片如果与后放置的碎片在空间上重叠，后放置的碎片覆盖先放置的碎片的像素。
- 输出中移除层级条（填充为 bg），底座和最终拼合的碎片均保留。

Key insight: 槽位标记决定水平定位，层级条决定绘制顺序（从而决定重叠时谁在前），解题者必须同时破译两个独立的编码机制——位置编码和层级编码——并正确组合它们才能得到唯一正确的输出。
</description>

<description>
在网格中找到由"门"连接的多个房间，根据房间内物品数量打开或关闭门，并将打开的门所连通的房间合并填充为统一颜色。

Input structure:
- bg = 最常见颜色（black）。
- 由 grey 像素绘制的墙壁将网格分割为若干矩形房间（每个房间是一个被 grey 墙壁完全包围的 bg 矩形区域）。
- 相邻房间之间的共享墙壁上可能有一个单像素宽的缺口，缺口像素为某种非 bg、非 grey 的颜色（如 yellow），这些彩色缺口称为"门"。
- 每个房间内部可能散布着若干单像素的彩色标记点（颜色与门的颜色不同，如 blue 或 red），称为"物品"。

Rule:
- 第一层：识别所有房间及其包含的物品数量。
- 第二层：判断每扇门是否"打开"——一扇门连接两个相邻房间，若这两个房间的物品数量相等，则门打开（将门的像素变为 bg，形成通道）；若数量不等，则门关闭（将门的像素变为 grey，与墙壁融为一体）。
- 第三层：找到所有通过打开的门彼此连通的房间组，将同一连通组内的所有房间（包括打开的门像素）填充为同一种颜色。填充颜色为该连通组中所有房间内物品颜色中出现次数最多的那种颜色。如果某个连通组没有物品，则保持 bg。
- 墙壁（grey）在输出中保持不变；关闭的门变为 grey；物品标记被填充色覆盖。

Key insight: 门的开关状态不是预设的，而是由两侧房间的物品数量对比决定的——解题者需要先数出每个房间的物品数量，再判断每扇门的状态，最后追踪连通性来确定填充范围和颜色。三层推理中，"数量相等则开门"这一规则是最隐蔽的核心洞见。
</description>
</new_puzzle>
