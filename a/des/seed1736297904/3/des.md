- `description`：根据封闭矩形框内部散落碎片的颜色，从顶部色板条中查找对应的填充色，将该封闭框内部整体填充为查找到的颜色。

- `Input structure`：
  - 背景为黑色（black）。
  - 网格顶部有一行色板条：由若干相邻的双像素对组成，每对的左像素是"碎片色"，右像素是"填充色"，双像素对之间用黑色间隔一格。
  - 网格中有若干用同一种边框色（如 grey）绘制的一像素厚的封闭矩形框。
  - 每个矩形框内部有少量散落的非黑色像素（碎片），同一个框内的碎片全部是同一种颜色。不同框内的碎片颜色可以不同。
  - 每个框内的碎片颜色一定在色板条的"碎片色"位置出现恰好一次。

- `Rule`：
  - 色板条保持不变。
  - 对每个封闭矩形框：
    1. 读取其内部碎片的颜色 C。
    2. 在色板条中找到左像素为 C 的那一对，取其右像素颜色 F。
    3. 将该矩形框内部所有黑色像素填充为 F（碎片像素也被 F 覆盖）。
  - 矩形边框本身颜色不变。

- `Key insight`：碎片的作用不是被保留，而是充当索引键——通过碎片颜色查色板获得填充色，再用填充色替换整个内部区域。解题者需要先发现色板的"键-值"配对结构，再发现框内碎片是查表的键。
</new_puzzle>

<new_puzzle>
- `description`：将网格中散落的彩色线段按方向分类，水平线段向左收拢堆叠，垂直线段向下收拢堆叠，堆叠顺序由线段长度决定。

- `Input structure`：
  - 背景为黑色（black）。
  - 网格左下角有一个由 green 像素标记的 L 形角标：一条从左边缘向右延伸的水平短线和一条从底边缘向上延伸的垂直短线，两者在左下角像素相交。L 形角标的水平臂长度和垂直臂长度可能不同。
  - 网格中散布着若干一像素宽的直线段（水平或垂直），每条线段颜色各异且均非黑色、非 green。线段之间互不接触。

- `Rule`：
  - L 形角标保持不变。
  - 将所有水平线段收集，按照线段长度从短到长排序（长度相同时按原始行号从小到大排序）。将排序后的水平线段从 L 形角标水平臂的上方一行开始，逐行向上依次放置，每条线段左端对齐到第 0 列。
  - 将所有垂直线段收集，按照线段长度从短到长排序（长度相同时按原始列号从小到大排序）。将排序后的垂直线段从 L 形角标垂直臂的右侧一列开始，逐列向右依次放置，每条线段底端对齐到最底行。
  - 线段保持原色和原长度。原始位置的线段被擦除为黑色。

- `Key insight`：L 形角标不仅是装饰——它的两条臂分别定义了水平线段的堆叠起始行和垂直线段的堆叠起始列，同时角标的方向暗示了水平线段左对齐、垂直线段底对齐的锚定规则。解题者需要同时识别方向分类、排序依据和锚定位置三层逻辑。
</new_puzzle>

<new_puzzle>
- `description`：每个彩色对象根据其所在象限被赋予不同的旋转角度，变换后的对象被搬运到网格中央的空白目标区域内对应象限位置。

- `Input structure`：
  - 网格为正方形，边长为偶数（如 20x20）。
  - 背景为黑色（black）。
  - 一条完整的 red 水平线穿过网格正中（将网格分为上下两半），一条完整的 red 垂直线穿过网格正中（将网格分为左右两半）。两条线交叉形成十字，将网格划分为四个象限。
  - 十字线的交叉点周围有一个由 red 像素围成的小正方形空白区域（如 6x6 的内部空间），内部全部为黑色，这是目标区域。
  - 四个象限中各有恰好一个小型单色非红非黑的 4-连通对象（形状不对称，便于观察旋转效果），四个对象颜色互不相同。每个对象的边界框不超过目标区域单象限大小。

- `Rule`：
  - 十字线和目标区域边框保持不变。
  - 左上象限的对象不旋转（0 度），将其搬入目标区域的左上四分之一，对象的边界框左上角对齐到目标区域左上角。
  - 右上象限的对象顺时针旋转 90 度后搬入目标区域的右上四分之一，边界框右上角对齐到目标区域右上角。
  - 右下象限的对象顺时针旋转 180 度后搬入目标区域的右下四分之一，边界框右下角对齐到目标区域右下角。
  - 左下象限的对象顺时针旋转 270 度后搬入目标区域的左下四分之一，边界框左下角对齐到目标区域左下角。
  - 原始位置的对象被擦除为黑色。

- `Key insight`：十字线不仅是分割标记，更隐含了一个"象限编号到旋转角度"的映射规则（按顺时针方向每个象限增加 90 度）。解题者需要从多个样例中归纳出象限位置与旋转量之间的对应关系，而非仅仅发现"对象被移动到中心"。
</new_puzzle>

<new_puzzle>
- `description`：网格中每个彩色种子像素沿其所在行带的箭头方向生长出矩形色块，色块的高度等于行带高度，宽度等于该行带内同色种子的数量。

- `Input structure`：
  - 背景为黑色（black）。
  - 网格左侧或右侧边缘有若干由 grey 像素绘制的水平箭头符号，每个箭头占据若干连续行。每个箭头的绘制方式为：一条水平的 grey 线段加上末端的一个三角箭头尖（由 grey 像素构成的 3 行高的三角形，尖端指向左或右）。箭头指向左表示向左生长，指向右表示向右生长。每个箭头所覆盖的行范围称为一个"行带"。不同箭头的行带互不重叠且覆盖不同数量的行（例如一个箭头覆盖 2 行，另一个覆盖 3 行，再一个覆盖 4 行）。
  - 在网格非箭头区域中，散布着若干单个彩色像素（种子），颜色各异且均非黑色、非 grey。每个种子像素必定落在某个箭头行带的范围内。同一行带内可能有多个种子，但它们的颜色一定相同。不同行带内的种子颜色可能不同。

- `Rule`：
  - 箭头本身保持不变。
  - 对每个行带：
    1. 统计该行带内种子像素的数量 N。
    2. 确定箭头方向（左或右）。
    3. 确定该行带覆盖的行数 H（即行带的高度）。
    4. 以每个种子像素为起点，沿箭头方向生长出一个 H 行高、N 列宽的实心矩形色块，颜色与种子相同。矩形的垂直范围恰好覆盖整个行带高度，水平起点为种子所在列，向箭头方向延伸 N 列（含种子所在列）。
    5. 如果生长超出网格边界，则在边界处截断。
  - 不同种子生长的矩形如果重叠，后绘制的覆盖先绘制的（绘制顺序：按箭头方向排列，靠近箭头源头侧的种子先绘制）。

- `Key insight`：解题者必须发现三层嵌套的逻辑：首先，箭头既标定了行带的范围（决定生长高度），又指定了生长方向；其次，同一行带内种子的数量决定了每个矩形的宽度（数量即宽度）；最后，种子的列位置决定了矩形的水平锚点。行带高度、种子计数和方向三者缺一不可。
</new_puzzle>

<new_puzzle>
- `description`：将环形轨道上的彩色标记沿轨道顺时针移动，移动步数等于轨道内部区域中同色像素的个数。

- `Input structure`：
  - 背景为黑色（black）。
  - 网格中有一个由 grey 像素组成的一像素厚的矩形环形轨道（即一个矩形框，四条边均为 grey，内部为黑色区域）。
  - 轨道上（即 grey 像素的位置上）有若干彩色标记像素，每个标记将其所在位置的 grey 替换为自身颜色。不同标记颜色互不相同，且标记彼此不相邻。
  - 矩形框内部的黑色区域中散布着若干彩色像素，这些像素的颜色都能在轨道标记中找到对应。同一种颜色在内部可出现 0 到多个像素。

- `Rule`：
  - 轨道的 grey 像素保持不变（除了标记移动后覆盖的位置）。
  - 内部区域的所有彩色像素被擦除为黑色。
  - 对每个轨道上的彩色标记：
    1. 统计该标记颜色在内部区域中出现的像素数量 K。
    2. 将该标记沿轨道顺时针移动 K 步。顺时针方向定义为：顶边从左到右、右边从上到下、底边从右到左、左边从下到上。每一步移动到轨道上的下一个相邻像素位置。
    3. 标记的原始位置恢复为 grey。标记的新位置像素变为该标记颜色。
  - 如果两个标记移动后落在同一位置，则后处理的标记覆盖先处理的（处理顺序为按原始位置的顺时针顺序，从顶边左上角起始）。

- `Key insight`：内部散落的彩色像素看似装饰或噪声，实际是每个轨道标记的"步数编码"——解题者需要发现内部像素的颜色与轨道标记一一对应，且数量直接转化为移动距离。两层推理缺一不可：第一层是建立颜色配对（轨道标记色 = 内部计数色），第二层是理解沿矩形轨道的顺时针行走规则。
</new_puzzle>

<new_puzzle>
- `description`：根据每个封闭房间的出口数量，从调色板中选取对应位置的颜色填充该房间。

- `Input structure`：
  - 背景为黑色（black）。
  - 网格中有由 blue 像素绘制的一像素厚的墙壁网络，将网格分割成若干封闭的矩形房间。墙壁沿水平和垂直方向延伸，形成类似迷宫的网格状结构。
  - 部分墙壁上存在缺口（一个像素宽的断开），作为房间的出口。每个房间可以有 1 到 5 个出口。
  - 网格最底部一行是一个调色板行：从左到右依次排列 5 个单像素颜色样本，分别对应出口数 1、2、3、4、5。颜色样本之间用黑色间隔一格。调色板中的 5 种颜色互不相同且均非黑色、非 blue。

- `Rule`：
  - 墙壁（blue 像素）保持不变。
  - 调色板行保持不变。
  - 对每个封闭房间：
    1. 数出该房间四面墙壁上的缺口（出口）总数 E（1 <= E <= 5）。
    2. 从调色板行中取第 E 个颜色样本的颜色。
    3. 将房间内部所有黑色像素填充为该颜色。
  - 如果某个房间的出口数量为 0（完全封闭无缺口），则不填充，保持黑色。

- `Key insight`：墙壁缺口通常被视为"通道"或"连接"，但在此题中缺口的数量才是关键——它作为索引值查找调色板。解题者需要建立"出口计数到调色板位置到填充色"这一非显然的映射链。难点在于：缺口既有空间含义（位置、连通性）又有数值含义（计数），而本题只使用数值含义。
</new_puzzle>

<new_puzzle>
- `description`：识别每对同色锚点之间的连线方向，用该颜色填充锚点之间的线段，然后根据角落优先级色板确定交叉点处的颜色。

- `Input structure`：
  - 网格为正方形，背景为黑色（black）。
  - 网格中有若干成对出现的同色单像素锚点。每种颜色恰好出现两个像素，颜色互不相同（例如 red 两个、green 两个、yellow 两个）。共有 2 到 4 对。
  - 每对锚点要么在同一行（水平对）、要么在同一列（垂直对），不出现斜对角的情况。
  - 在网格的一个角落（如右下角）有一个小的优先级色板：由若干单像素从上到下垂直排列，每个像素颜色对应某一对锚点的颜色。色板中颜色从上到下的顺序表示图层优先级，越靠上优先级越高（覆盖在上层）。

- `Rule`：
  - 优先级色板保持不变。
  - 对每对同色锚点：
    1. 如果是水平对（同一行），用该颜色填充两个锚点之间的整行像素（含锚点自身），填充高度为 1 像素。
    2. 如果是垂直对（同一列），用该颜色填充两个锚点之间的整列像素（含锚点自身），填充宽度为 1 像素。
  - 当水平线段与垂直线段交叉时（共享同一像素），根据优先级色板决定该像素颜色：优先级高的颜色覆盖优先级低的颜色。
  - 按优先级从低到高的顺序绘制线段（最高优先级最后绘制，因此在交叉点处可见）。

- `Key insight`：锚点配对和连线方向是第一层推理（同色配对、同行/同列判定）；交叉处的颜色不是简单的"后画覆盖前画"，而是由角落的优先级色板显式定义叠压顺序，这是第二层推理。解题者必须同时发现连线规则和色板的优先级编码功能。
</new_puzzle>
