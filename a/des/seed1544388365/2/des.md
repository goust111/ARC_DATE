- `description`：根据封闭区域内的"钥匙"颜色，在区域边框上找到同色"锁孔"缺口，并从缺口向外发射与区域面积等长的射线。

- `Input structure`：
  - 背景为 black。
  - 网格中散布若干由 grey 像素绘制的封闭矩形边框（边框宽度为 1 像素），每个矩形内部恰好包含一个单像素的彩色"钥匙"（颜色各不相同，可能为 red、blue、green、yellow、orange 等）。
  - 每个 grey 矩形边框上恰好有一个 1 像素宽的缺口（即边框某条边上缺少一个 grey 像素），该缺口处的像素为某种非 black、非 grey 的颜色，称为"锁孔色"。
  - 每个矩形的锁孔色与该矩形内部的钥匙色可能相同也可能不同；多个矩形之间的锁孔色可能相同。

- `Rule`：
  - 对每个封闭矩形，比较其内部钥匙颜色与其边框锁孔颜色：
    - 若钥匙色与锁孔色**相同**（"钥匙匹配锁孔"），则该矩形被"解锁"。
    - 若不同，则该矩形不做任何变换，保持原样。
  - 对每个被解锁的矩形：
    - 计算该矩形内部的面积（即边框内部空间的像素总数，不含边框本身），记为 N。
    - 从锁孔缺口位置出发，沿缺口朝外的方向（即远离矩形内部的方向），绘制一条长度为 N 的射线，射线颜色为钥匙色。射线遇到网格边界则截断。
  - 射线覆盖路径上已有的非 black 像素时，射线像素优先覆盖。
  - 未解锁的矩形及其内容保持不变。

- `Key insight`：解题需要两层独立推理——第一层是发现"钥匙色等于锁孔色"才触发变换的匹配条件；第二层是发现射线长度由矩形内部面积决定，而非由矩形尺寸或其他可见属性决定。两层规则都需要跨多个样例对比才能归纳出来。
</new_puzzle>

- `description`：将散落的彩色碎片按形状互补关系配对拼合，拼合后的矩形按面积从小到大堆叠在输出网格的左下角。

- `Input structure`：
  - 背景为 black。
  - 网格中散布偶数个（4-8 个）不规则的 4-连通单色对象，每个对象颜色各不相同。
  - 这些对象可以两两配对：每对对象的形状恰好互补——即将两者不重叠地拼在一起可以恰好填满一个实心矩形（无间隙、无溢出）。拼合方式唯一（其中一个对象需要平移到另一个的某个相邻位置，无需旋转或翻转）。
  - 不同对的矩形大小可能不同。

- `Rule`：
  - 第一步：识别配对关系——对所有对象尝试两两组合，找到形状互补（拼合为矩形）的唯一配对方案。
  - 第二步：对每一对，将两个碎片拼合为一个实心矩形。矩形中保留两个碎片各自的原始颜色（即矩形内部分像素为颜色 A，其余为颜色 B）。
  - 第三步：将所有拼合后的矩形按面积（像素总数）从小到大排序。面积最小的矩形放在输出网格的左下角（矩形的左下角与网格左下角对齐）；第二小的矩形紧接在第一个矩形的右侧（左下角对齐，与前一个矩形间隔 1 列 black 像素）；依此类推，从左到右排列。
  - 输出网格的高度为所有矩形中最高者的高度，宽度为所有矩形宽度之和加上间隔列。所有矩形底边对齐在网格最底行。

- `Key insight`：解题的核心难点在于发现碎片之间的"形状互补"配对关系——这不是基于颜色或位置的匹配，而是纯几何的互锁拼合。配对完成后，还需发现排列规则是按面积排序并底部对齐，这构成第二层推理。
</new_puzzle>

<new_puzzle>
- `description`：网格中的彩色路径网络在交叉点处按"上下层"关系交织；根据图例中的层级顺序，在每个交叉点处仅保留上层路径的颜色。

- `Input structure`：
  - 背景为 black。
  - 网格中有若干条 4-连通的彩色路径（每条路径为单一颜色，路径宽度为 1 像素），路径颜色互不相同（例如 red、blue、green、yellow 等）。
  - 路径之间存在交叉：在交叉点处，两条路径共享同一个像素位置。在输入中，交叉点像素显示为其中一条路径的颜色（即"上层"路径的颜色），另一条路径在此处视觉上断开。
  - 每条路径的两个端点（仅有一个 4-连通路径邻居的像素）位于网格的边缘（最外圈的行或列）。
  - 在网格的最上方一行（第 0 行）中，若干像素显示颜色，从左到右读取这些颜色构成一个"层级序列"：序列中越靠前的颜色层级越高（在交叉点处显示在上层）。这一行不属于路径网络，仅作为图例。

- `Rule`：
  - 读取第 0 行的颜色序列作为层级表（从左到右为从高到低）。
  - 在路径网络中，每个像素本来属于某条路径。对于非交叉像素（仅属于一条路径），颜色保持不变。
  - 对于交叉点像素（同时被两条路径经过），将其颜色设为层级更高的那条路径的颜色。
  - 判断一个像素是否为交叉点的方法：观察该像素的 4 邻域。若在某个方向轴（上下或左右）上，两侧各有一个属于另一颜色 D 的路径像素，说明颜色 D 的路径穿越此处，该像素是交叉点。
  - 交叉点处，比较两条路径在层级表中的位置，保留层级更高者的颜色。在输入中被"压在下面"的路径若在层级表中更高，则该像素颜色翻转为该路径的颜色。
  - 最终输出移除第 0 行图例，仅输出路径网络部分（网格高度减 1）。

- `Key insight`：第一层推理是发现路径在交叉点处存在"覆盖"关系，某些路径在交叉点被另一条路径的颜色遮盖而视觉断开。第二层推理是发现第 0 行的颜色序列并非装饰，而是决定交叉点处谁覆盖谁的层级优先级表——输入中的覆盖关系可能与层级表不一致，输出需要按层级表纠正。
</new_puzzle>

<new_puzzle>
- `description`：每个彩色对象根据颜色匹配找到自己的目标框架，然后按框架角标指示的锚定角进行整数倍缩放后放入框架内部。

- `Input structure`：
  - 背景为 black。
  - 网格被两条贯穿全网格的 grey 直线（一条水平、一条垂直）分为四个象限。grey 线宽度为 1 像素。
  - 四个象限中，恰好有两个象限各包含一个由 azure 像素绘制的矩形空心框架（边框宽度 1 像素）。每个框架在其四个角中的某一个角的外侧对角相邻位置（对角方向 1 像素处）有一个单像素的彩色角标，角标颜色各不相同且不为 black、grey 或 azure。
  - 另外两个象限各包含一个小型 4-连通单色对象（非 black、非 grey、非 azure），对象颜色与某个框架角标颜色相同。每个对象颜色恰好与某一个框架角标匹配。

- `Rule`：
  - 对每个彩色对象，找到角标颜色与该对象颜色相同的框架——此框架即为该对象的"目标模板"。
  - 计算缩放因子：设对象紧致包围盒大小为 h_obj x w_obj，框架内部区域大小为 h_frame x w_frame。缩放因子 s = min(h_frame / h_obj, w_frame / w_obj) 向下取整。
  - 将该对象的每个非 black 像素放大为 s x s 的像素块。
  - 角标所在的角决定对象在框架内部的对齐锚点：对象缩放后的包围盒的对应角与框架内部区域的该角对齐（例如角标在右下角，则缩放后对象的右下角与框架内部右下角对齐）。
  - 输出中，框架和 grey 分隔线保持不变；角标像素保留；原始对象从原位置移除（变为 black）。

- `Key insight`：解题需要三层推理。第一层：发现颜色匹配关系——对象颜色与框架角标颜色相同表示归属。第二层：发现角标位于框架哪个角决定了对象在框架内的锚定位置。第三层：发现对象被整数倍缩放后放入框架内部，缩放比例由框架与对象的尺寸比决定。
</new_puzzle>

<new_puzzle>
- `description`：在网格中，每个"种子"像素根据同一围栏内种子的总数向外生长相应层数的同心方环，多种子重叠区域按最近种子着色。

- `Input structure`：
  - 背景为 black。
  - 网格中有若干由 grey 像素构成的封闭围栏。每个围栏是一个 4-连通的闭合矩形环（宽度 1 像素），内部为 black 背景。不同围栏大小可能不同。
  - 每个围栏内部包含 1-4 个单像素的彩色种子（可能为 red、blue、green、yellow、orange 等），同一围栏内各种子颜色不同。不同围栏内的种子颜色可以重复。

- `Rule`：
  - 对每个围栏，数其内部种子的总数量，记为 K。
  - 对围栏内部的每个种子像素，以该种子为中心，向外生长 K 层同心正方形环。第 i 层（i 从 1 到 K）由所有与种子的棋盘距离（取行距差和列距差的较大值）恰好等于 i 的像素组成。
  - 每层环使用该种子自身的颜色绘制，但仅在围栏内部区域绘制——属于围栏 grey 像素或围栏外部的像素不受影响。
  - 若不同种子生长的环在某个像素处重叠，则该像素显示离它棋盘距离最小的种子的颜色。若距离相同，则显示在围栏内部位置更靠上（行号更小）的种子的颜色，若行号也相同则取列号更小者。
  - 种子像素自身保留其原始颜色。围栏本身（grey 像素）保持不变。围栏外部不受影响。

- `Key insight`：第一层推理是发现每个种子的生长层数并非固定常数，而是等于同一围栏内种子的总数——这需要跨样例对比不同围栏（含不同数量种子）的输出来归纳。第二层推理是发现重叠区域的颜色由棋盘距离最近的种子决定，这形成了类似 Voronoi 分区的效果，需要观察多种子围栏中的颜色分界线来发现。
</new_puzzle>
