- `description`：根据封闭区域内部的孔洞数量，从色带图例中选取对应颜色，对该区域进行重新填色。

- `Input structure`：
  - 背景为 black。
  - 网格中存在若干个由同一种非背景颜色（如 blue）绘制的闭合环形轮廓，每个轮廓内部被背景色填充，但部分轮廓内部还包含若干个由轮廓色绘制的小实心方块（1×1），这些小方块即为"孔洞标记"。不同轮廓内的孔洞标记数量各不相同（范围 0–4）。
  - 网格的某一侧（例如底部）有一条水平色带图例：由左到右排列着 5 个不同颜色的连续色块（例如 red、green、yellow、magenta、orange），每个色块宽度相同，分别对应孔洞数 0、1、2、3、4。

- `Rule`：
  - 识别所有由轮廓色绘制的 4-连通闭合环。
  - 统计每个闭合环内部的孔洞标记（轮廓色小方块）数量 n。
  - 从色带图例中取第 n+1 个颜色（从左数第 1 个对应 0 个孔洞）。
  - 将该闭合环的所有轮廓像素重新着色为图例对应的颜色，同时移除内部的孔洞标记（还原为背景色）。
  - 色带图例本身在输出中保持不变。

- `Key insight`：闭合环的颜色不由其形状或位置决定，而由其内部孔洞标记的数量索引到色带图例来确定；解题者需要先发现"数孔洞"这一隐含计数步骤，再发现色带是有序映射表。
</new_puzzle>

<new_puzzle>
- `description`：将散落的彩色碎片沿着灰色导轨滑动到导轨末端，碎片到达末端后按导轨方向堆叠，堆叠顺序由碎片在导轨上的初始距离决定。

- `Input structure`：
  - 背景为 black。
  - 网格中有若干条由 grey 像素绘制的直线导轨，每条导轨为水平或垂直的一像素宽连续线段，长度各异。
  - 每条导轨上散布着若干个不同颜色的单像素碎片（非 black、非 grey），这些碎片占据导轨上的某些位置。
  - 每条导轨的一端有一个 red 单像素终止标记，紧邻导轨末端外侧（不在导轨上），指示堆叠方向。

- `Rule`：
  - 对每条导轨，确定 red 终止标记所在的那一端为"堆叠端"。
  - 将导轨上的所有彩色碎片按其距堆叠端的远近排序（最远的排最前）。
  - 从堆叠端开始，将碎片紧密排列在导轨上：第一个碎片放在导轨最靠近堆叠端的格子，第二个紧邻其后，依此类推。
  - 碎片原来的位置恢复为 grey（导轨色）。
  - red 终止标记在输出中被移除（变为背景色）。
  - 导轨上未被碎片占据的其余格子保持 grey。

- `Key insight`：red 标记不是碎片而是方向指示器，决定了堆叠端；碎片的最终排列顺序并非按颜色而是按它们距堆叠端的原始距离（最远先放），这意味着碎片的相对顺序会被反转。
</new_puzzle>

<new_puzzle>
- `description`：识别网格中由边框颜色围成的多个房间，将每个房间内的"种子图案"按房间面积从小到大的排名进行旋转，然后将旋转后的图案写回房间中心。

- `Input structure`：
  - 背景为 black。
  - 一种颜色（如 blue）绘制了若干个互不重叠的矩形闭合边框（边框宽度为 1 像素），形成多个"房间"。每个房间的内部尺寸（不含边框）各不相同。
  - 每个房间内部中心区域包含一个由另一种颜色（各房间颜色可以不同）绘制的小型非对称图案（种子图案），该图案的外接矩形严格小于房间内部空间，且图案位于房间内部正中央。

- `Rule`：
  - 计算每个房间的内部面积（内部行数 × 内部列数）。
  - 将所有房间按内部面积从小到大排名，排名从 0 开始。
  - 对排名为 k 的房间，将其种子图案顺时针旋转 (k mod 4) × 90 度。即：排名 0 不旋转，排名 1 旋转 90°，排名 2 旋转 180°，排名 3 旋转 270°，排名 4 不旋转，以此类推。
  - 旋转后的图案重新居中放置在该房间内部，原图案位置的多余像素清除为背景色。
  - 边框保持不变。

- `Key insight`：解题者需要先发现房间面积决定了排序，再发现排名与旋转角度之间的周期映射关系（0→0°, 1→90°, 2→180°, 3→270°）；图案本身的形状和颜色是干扰项，真正的变量是房间的相对大小。
</new_puzzle>

<new_puzzle>
- `description`：根据每个彩色对象与最近的同色边界标记之间的对齐轴，选择该轴方向对对象做镜像翻转，然后用边界标记的配对颜色替换对象颜色。

- `Input structure`：
  - 背景为 black。
  - 网格的四条边上分布着成对的彩色单像素标记。每对标记由两个不同颜色组成，紧邻放置（水平相邻或垂直相邻），其中一个颜色为"选择色"，另一个为"替换色"。位于上/下边的标记对指示水平轴翻转，位于左/右边的标记对指示垂直轴翻转。
  - 网格内部散布着若干个不同颜色的 4-连通对象（每个对象为 2–6 个像素的小型非对称形状），每个对象的颜色恰好与某个边界标记对的"选择色"相同。

- `Rule`：
  - 对每个内部对象，找到与其颜色匹配的边界标记对。
  - 根据该标记对所在的边（上/下边 → 水平翻转，左/右边 → 垂直翻转），对该对象以其自身几何中心为轴做相应的镜像翻转。
  - 翻转后的对象保持在原位（中心不动），颜色替换为标记对中的"替换色"。
  - 清除原对象位置上因翻转而不再被占据的像素（变为背景色）。
  - 边界上的标记对在输出中保持不变。

- `Key insight`：边界标记对同时编码了两层信息——其位置（在哪条边上）决定翻转轴方向，其颜色配对决定颜色替换；解题者必须同时发现位置→翻转和颜色→重着色这两个独立的映射关系。
</new_puzzle>

<new_puzzle>
- `description`：将网格中的多个同色"信号塔"向外发射正交射线直到碰到边界或障碍，射线交叉点处生成新颜色，新颜色由交叉的两条射线所属信号塔的颜色通过固定的颜色混合表决定。

- `Input structure`：
  - 背景为 black。
  - 网格中散布着若干个单像素的"信号塔"，使用 2–3 种不同颜色（例如 red、blue、yellow），每种颜色有 1–3 个信号塔。
  - 网格中还有若干个 grey 像素作为"墙壁"障碍物，分布在不同位置。
  - 网格角落处有一个 3×3 的颜色混合表：表的第一行和第一列分别标注了信号塔可用的颜色（如 red、blue、yellow），表格内部的交叉格填有混合结果颜色（例如 red×blue → magenta，red×yellow → orange，blue×yellow → green）。

- `Rule`：
  - 每个信号塔向上、下、左、右四个方向发射射线，射线为该信号塔的颜色，从信号塔位置开始沿直线延伸，直到碰到网格边界或 grey 墙壁为止（不覆盖墙壁）。
  - 射线可以覆盖背景像素，但不覆盖其他信号塔。
  - 当两条不同颜色的射线经过同一个像素时，该像素不使用任一射线的颜色，而是查阅角落的颜色混合表，使用两种颜色对应的混合结果颜色。
  - 如果三条或以上射线交叉在同一像素，优先使用离该像素最近的两个信号塔所发射的射线进行混合。
  - 同色射线交叉时保持原色不变。
  - 颜色混合表在输出中保持不变；grey 墙壁保持不变；信号塔本身保持不变。

- `Key insight`：解题者需要三层推理——首先发现信号塔发射正交射线的规则，然后发现射线交叉处的颜色不是简单覆盖而是混合，最后发现角落的小网格是颜色混合的查找表而非装饰。
</new_puzzle>
