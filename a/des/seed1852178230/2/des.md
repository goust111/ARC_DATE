  - 标记点像素被图案覆盖，grey 轮廓像素保持不变。

- `Key insight`：解题者需要先发现底部色带是"标记颜色→填充图案"的查找表（第一层推理），然后理解图案是以水平周期平铺的方式填入封闭区域的（第二层推理）。标记点颜色本身不出现在输出中，仅作为索引键使用。

<new_puzzle>
- `description`：将网格中散落的彩色碎片按颜色分组拼合成完整矩形，再按矩形面积从大到小的堆叠顺序绘制到统一画布的中心。

- `Input structure`：
  - 背景为主色（如 black）。
  - 网格中散布着若干彩色 4-连通对象，每种非背景颜色恰好出现两个分离的对象。
  - 同一颜色的两个对象形状互补：将它们按相对位置拼合后恰好构成一个无孔的实心矩形。两个碎片的相对拼合方式由它们的凹凸轮廓唯一确定——其中一个碎片的凸出部分恰好填入另一个碎片的凹陷部分。
  - 每种颜色拼合后的矩形尺寸互不相同。

- `Rule`：
  - 对每种颜色，找到它的两个碎片对象。
  - 确定唯一的拼合方式：将两个碎片沿互补边界平移对齐，使它们合并为一个实心矩形（不旋转、不翻转，仅平移）。
  - 计算每个拼合矩形的面积（宽×高）。
  - 创建一个新的输出网格，大小等于最大矩形的尺寸。
  - 按面积从大到小的顺序，将每个矩形居中绘制到输出网格上（后绘制的覆盖先绘制的）。居中方式：矩形中心与输出网格中心对齐，若无法精确居中则偏左上。

- `Key insight`：第一层推理在于发现同色碎片是可以拼合的互补件，需要找到唯一的平移拼合方案。第二层推理在于发现拼合后的矩形按面积排序并居中堆叠——面积最小的矩形在最上层完全可见，较大的矩形仅露出边框部分，形成嵌套的彩色方框效果。
</new_puzzle>

<new_puzzle>
- `description`：利用网格边缘的箭头指示符确定每行或每列的扫描方向，将该方向上遇到的第一个彩色像素的颜色传播填满整行或整列直到碰到另一个彩色像素为止。

- `Input structure`：
  - 背景为主色（如 black）。
  - 网格的顶部边缘和左侧边缘各有一行/列指示符。顶部边缘的指示符控制对应列，左侧边缘的指示符控制对应行。
  - 指示符有两种颜色（如 red 和 blue）：red 表示正方向（从上到下或从左到右），blue 表示反方向（从下到上或从右到左）。
  - 网格内部（排除边缘指示符行列后的区域）散布着少量彩色像素（颜色不同于指示符颜色和背景色），其余为背景色。
  - 每行和每列的指示符独立作用。

- `Rule`：
  - 首先处理行方向的传播：对于内部区域的每一行，读取左侧边缘该行的指示符颜色，确定扫描方向。沿该方向扫描该行，遇到第一个非背景像素后，用该像素的颜色向前填充所有后续背景像素，直到遇到下一个非背景像素（不覆盖它）或到达行尾。对该行后续的每一段背景区域重复同样的规则：每遇到一个非背景像素，就用它的颜色继续向前填充。
  - 然后处理列方向的传播：对行传播完成后的网格，对每一列读取顶部边缘该列的指示符颜色确定扫描方向，执行相同的传播逻辑。列传播中新填入的颜色仅覆盖仍为背景色的像素，不覆盖行传播已填入的颜色。
  - 指示符行和列本身不出现在输出中，输出网格仅包含内部区域。

- `Key insight`：解题者首先需要发现边缘标记是方向指示符，红蓝两色分别编码正反方向（第一层推理）。然后需要理解颜色传播的"接力"机制——每个彩色像素只向前传播到下一个彩色像素为止（第二层推理）。最后需要理解行列传播是有序叠加的，行先列后，列传播只填补行传播留下的空白（第三层推理）。
</new_puzzle>

- `Input structure`：
  - 背景为主色（如 black）。
  - 网格中有若干由同一颜色（如 green）绘制的空心矩形框（一像素宽边框，内部为背景色）。
  - 每个矩形框的边框上有 1 到 3 个单像素缺口（边框像素被替换为背景色）。每个缺口位于矩形的某一条边的中点位置。
  - 网格的四个角落各放置一个小的样板图案（3×3），每个样板由不同颜色的像素组成，形成一个从中心向外的简单十字或 L 形图案。四个样板分别标记为 1 缺口、2 缺口、3 缺口的对应样板（其中一个角落为空，表示不使用）。角落样板的标记方式：样板内非背景像素的数量等于它对应的缺口数。

- `Rule`：
  - 统计每个矩形框边框上的缺口数量。
  - 在四个角落样板中，找到非背景像素数量等于该缺口数量的样板。
  - 对矩形框的每个缺口：确定缺口所在边（上、下、左、右），从缺口位置向矩形内部方向画一条射线（一像素宽），射线颜色取自所选样板中对应方向位置的像素颜色（样板中心为原点，上缺口取样板中心上方像素的颜色，右缺口取中心右方像素的颜色，依此类推）。射线从缺口位置开始向内延伸，直到碰到对面的边框为止。
  - 矩形边框本身保持不变（包括缺口保留为背景色）。

- `Key insight`：第一层推理是发现角落小图案是按"非背景像素计数"索引的样板库，缺口数量是查找键。第二层推理是理解样板中各方向像素的颜色决定了从对应方向缺口射入的射线颜色——样板的空间布局直接编码了颜色与方向的映射关系。
</new_puzzle>

- `description`：识别网格中被分隔线划分的子区域，在每个子区域内找到"种子对象"和"模具对象"，将种子对象的颜色按模具对象的形状进行裁剪，再将裁剪结果放置到模具对象的原始位置。

- `Input structure`：
  - 背景为主色（如 black）。
  - 一条或两条贯穿整个网格的直线（水平或垂直，颜色为 grey）将网格分为 2 到 4 个子区域。
  - 每个子区域内恰好包含两个不同颜色的 4-连通对象：
    - 一个"种子对象"：一个实心矩形，尺寸大于等于另一个对象的 bounding box。
    - 一个"模具对象"：一个任意形状的非矩形对象（形状不规则，可能有凹陷或分支）。
  - 每个子区域中种子对象和模具对象的颜色各不相同，但不同子区域之间可能复用颜色。

- `Rule`：
  - 在每个子区域中识别种子对象（实心矩形）和模具对象（非矩形形状）。
  - 将模具对象的形状像素映射到种子对象的 bounding box 内——以模具对象 bounding box 的左上角与种子对象 bounding box 的左上角对齐。
  - 在种子对象中，仅保留与模具形状重叠位置的像素（使用种子对象的颜色），其余种子像素清除为背景色。
  - 将裁剪后的结果（种子颜色、模具形状）放置到模具对象原来的位置（左上角对齐模具的 bounding box 左上角）。
  - 清除种子对象和原始模具对象，只保留裁剪结果。
  - 分隔线保持不变。

- `Key insight`：解题者需要先理解分隔线将网格划分为独立工作区（第一层推理），然后发现每个区域内矩形是"颜色源"而不规则形状是"形状模板"（第二层推理），最后理解变换是"用矩形的颜色填充不规则形状的轮廓并放回原位"——本质上是颜色与形状的交叉重组（第三层推理）。
</new_puzzle>

- `description`：将网格中的彩色路径段按"交汇节点处的转弯规则"重新着色，使得每条完整路径从起点到终点呈现颜色渐变序列。

- `Input structure`：
  - 背景为主色（如 black）。
  - 网格中有若干条由非背景色像素组成的一像素宽路径，路径沿水平或垂直方向延伸。
  - 路径在某些位置交汇形成 T 形或十字形节点。每个节点像素本身为一种特殊颜色（如 yellow）。
  - 网格边缘有一条颜色序列条（如位于最右列），从上到下排列了 N 种颜色，定义了颜色的排序顺序。
  - 每条路径的两个端点（路径末端，仅有一个邻居的像素）各自有独立的颜色，这两种颜色都出现在边缘颜色序列中。
  - 路径中间段（端点和节点之间的像素）在输入中全部为同一种中间色（如 grey）。

- `Rule`：
  - 找到边缘颜色序列条，读取颜色排列顺序。
  - 识别所有路径端点（仅有一个非背景邻居的路径像素）。每条完整路径连接两个端点，可能经过多个节点。
  - 对每条完整路径，在颜色序列中查找两个端点颜色的位置，获取从起始颜色到终止颜色之间的子序列（含两端）。
  - 将路径分为与子序列长度相等的段数：路径总像素数（含端点、节点、中间像素）均匀分配到子序列的每种颜色上（若不能整除，多余像素分配给最后一段）。
  - 沿路径从一个端点到另一个端点，依次用子序列中的颜色重新着色每一段。方向规则：颜色序列中位置较小（靠上）的端点颜色为起点。
  - 节点像素也被重新着色为其所在段的颜色。
  - 颜色序列条本身不出现在输出中。

- `Key insight`：第一层推理是发现边缘的颜色条定义了全局颜色排序。第二层推理是理解每条路径的两端颜色决定了该路径使用的颜色子序列。第三层推理是路径被均匀分段并依序着色——节点处的颜色由它在路径中的位置决定而非由节点自身属性决定。
</new_puzzle>

- `description`：将散落在网格中的单色方块视为三维堆叠的俯视图，根据重叠层数改变颜色深度，并按照阴影方向偏移投射阴影。

- `Input structure`：
  - 背景为主色（如 white）。
  - 网格中有若干相同尺寸的正方形（如 3×3），全部为同一种颜色（如 blue）。部分正方形可能在位置上相互重叠（共享部分像素坐标）。
  - 网格的某一个角落（如左上角的 1×1 单元格）有一个方向标记像素（如 red），其所在角落指示阴影投射方向：左上角表示阴影向左上偏移，右下角表示阴影向右下偏移，依此类推。

- `Rule`：
  - 读取角落方向标记确定阴影偏移方向（对角方向，行和列各偏移 1 像素）。
  - 将所有正方形看作堆叠层：对网格中每个像素位置，计算有多少个正方形覆盖了该位置（重叠计数）。
  - 使用预定义的颜色深度映射对覆盖区域着色：覆盖 1 次用 azure，覆盖 2 次用 blue，覆盖 3 次用 maroon（即覆盖越多颜色越深）。原始输入中所有方块都是同一颜色，但输出中根据重叠数分化为不同颜色。
  - 对整个着色后的前景区域，沿阴影方向偏移 1 像素绘制 grey 阴影：阴影仅绘制在前景区域之外的背景像素上。
  - 移除角落方向标记。

- `Key insight`：第一层推理是发现角落单像素是阴影方向指示符。第二层推理是识别出同色方块存在重叠，重叠区域在输出中颜色加深——解题者需要反向推断每个像素被多少个方块覆盖。第三层推理是理解阴影的生成方式：整体前景轮廓沿指示方向偏移一格投射灰色阴影。
</new_puzzle>
