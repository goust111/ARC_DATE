- `description`：根据框架内部的彩色种子像素确定每个框架的"开口方向"，然后将框架外部对应方向上的散落碎片吸入框架内部，按种子颜色重新着色后紧贴开口内壁排列。
- `Input structure`：黑色背景网格上分布着若干单色空心矩形框架（如蓝色、绿色），每个框架的四条边中恰好有一条边存在一个单像素宽的缺口。框架内部靠近缺口对面的内壁上有一个或多个彩色种子像素（颜色与框架色不同）。框架外部散落着若干由各种颜色构成的小型连通对象（面积 2-5 像素），这些碎片分布在网格各处。
- `Rule`：
  1. 对每个框架，找到其四边上唯一的缺口，缺口方向即为该框架的"吸入方向"（例如缺口在右边则吸入方向为从右向左）。
  2. 沿吸入方向向外延伸，收集该方向上与框架同行/同列范围内的所有外部碎片，按距离缺口从近到远排序。
  3. 统计框架内部种子像素的数量 N，取距离最近的 N 个碎片。
  4. 将这 N 个碎片从网格上擦除，然后在框架内部从缺口对面的内壁开始，沿缺口方向依次放置这些碎片的形状（保持原形状不旋转），但颜色全部替换为对应位置种子像素的颜色（第一个碎片用第一个种子的颜色，依此类推）。
- `Key insight`：缺口方向同时决定了"从哪里收集碎片"和"在内部从哪个方向开始排列"；种子像素不仅标记了数量，还为每个吸入的碎片指定了重着色方案——解题者需要先推断缺口-方向-收集的对应关系，再推断种子颜色与碎片的配对规则。
</new_puzzle>

- `description`：将网格中散布的同色像素对用直线段相连，线段在交叉处按层叠优先级决定显示哪种颜色。
- `Input structure`：灰色背景网格上散布着多种颜色的像素点，每种非背景颜色恰好出现两个像素。这些像素对之间可以用水平、垂直或 45 度对角线段相连（每对像素必定共享行、列或对角线）。网格右下角有一个小的颜色图例区域：若干颜色方块从上到下垂直排列，表示层叠优先级（最上方的颜色在最顶层）。
- `Rule`：
  1. 对每种颜色，找到它的两个像素，沿共享的行/列/对角线方向画一条包含两端点的直线段，用该颜色填充线段上的所有像素。
  2. 当多条线段经过同一个像素时，根据右下角图例的层叠顺序，只保留优先级最高（图例中位置最靠上）的颜色。
  3. 图例区域本身在输出中保持不变。
- `Key insight`：解题者首先需要识别出每种颜色的配对关系和连线方向（这一步通过观察两点的几何对齐关系完成），然后需要发现右下角图例区域并非装饰而是定义了交叉处的层叠覆盖规则——两层推理缺一不可。
</new_puzzle>

- `description`：用网格边缘的彩色标尺行/列对内部区域进行"染色体检"——根据标尺颜色序列，逐行或逐列扫描每个分区，在颜色序列首次中断处放置一个标记像素。
- `Input structure`：黑色背景网格被一条垂直的黄色分隔线和一条水平的黄色分隔线切割成四个矩形象限。网格最顶行（分隔线以上）从左到右排列着一组彩色像素序列（如 Red, Blue, Green, Red, Blue ...），形成"列标尺"；网格最左列（分隔线以左）从上到下排列着另一组彩色像素序列，形成"行标尺"。每个象限内部填充着由多种颜色组成的像素图案。
- `Rule`：
  1. 确定每个象限由哪条标尺控制：左上和右上象限由顶行列标尺控制，左下和右下象限由左列行标尺控制。
  2. 对列标尺控制的象限：逐列扫描——将该列内从上到下的像素颜色序列与列标尺从左到右的循环序列对齐。找到第一个不匹配的像素位置。
  3. 对行标尺控制的象限：逐行扫描——将该行内从左到右的像素颜色序列与行标尺从上到下的循环序列对齐。找到第一个不匹配的像素位置。
  4. 在每个首次不匹配的位置放置一个橙色标记像素。如果整行/整列完全匹配则不放置标记。其余所有像素保持不变。
- `Key insight`：解题者需要首先发现黄色分隔线将网格分为四个象限，再发现边缘色带不是装饰而是"期望序列"，最后理解标记像素标注的是"实际与期望首次偏离"的位置——三层结构依次为：空间分区识别、标尺-象限配对、循环匹配与偏离检测。
</new_puzzle>

- `description`：识别网格中被遮挡的重叠矩形的完整轮廓，然后仅保留被其他矩形遮挡的部分（交集区域），并用被遮挡矩形的颜色填充。
- `Input structure`：白色背景网格上有若干不同颜色的实心矩形，它们部分重叠。重叠区域显示的是"最上层"矩形的颜色（后绘制的覆盖先绘制的）。每个矩形至少有两条完整的边可见（未被遮挡），使得其完整的边界框可以被推断出来。网格底部有一行单像素颜色序列，从左到右表示矩形的绘制顺序（最左 = 最先绘制 = 最底层）。
- `Rule`：
  1. 根据底部颜色序列确定各矩形的层叠顺序。
  2. 利用每个矩形的可见边推断其完整的边界框（即使部分边被遮挡，通过可见的两条边可以确定四个角的坐标）。

  4. 对每个矩形，只绘制它与所有位于其上层的矩形的重叠区域（即该矩形被遮挡的部分），用该矩形自身的颜色填充。
  5. 如果一个矩形完全未被遮挡（最顶层），则它在输出中不出现。
  6. 底部的颜色序列行在输出中移除。
- `Key insight`：解题者需要逆向重建被遮挡的矩形轮廓（从可见边推断完整边界框），然后执行一个反直觉的操作——不是显示可见部分，而是只显示被隐藏的部分。底部序列提供了必要的层叠顺序信息，没有它就无法确定哪些区域属于遮挡关系。

<new_puzzle>
- `description`：将网格中的"管道网络"按流向规则传播源头颜色，在管道交叉口根据混合规则生成新颜色。
- `Input structure`：黑色背景网格上有一个由灰色像素构成的正交管道网络（单像素宽的水平和垂直线段相互连接）。管道的若干末端（度为 1 的端点）各有一个彩色像素作为"源头"，颜色为 Red、Blue 或 Yellow 三种之一。管道网络中存在若干 T 形或十字形交叉口（度为 3 或 4 的节点）。所有非端点、非交叉口的管道像素均为灰色。
- `Rule`：
  1. 从每个彩色源头开始，沿管道方向将颜色向内传播，将沿途的灰色像素替换为源头颜色。
  2. 颜色传播在遇到交叉口时暂停。当一个交叉口的所有入口方向都已被颜色到达后，进行颜色混合：
     - Red + Blue = Magenta
     - Red + Yellow = Orange
     - Blue + Yellow = Green
     - 三色相遇 = Maroon
     - 同色相遇 = 保持该颜色
  3. 混合后的新颜色继续沿交叉口的出口方向（即尚未被颜色到达的方向）传播。
  4. 如果某个交叉口只有一个未到达方向，则混合色沿该方向传播；如果有多个未到达方向，混合色同时沿所有未到达方向传播。
  5. 最终所有灰色管道像素都应被替换为某种颜色。
- `Key insight`：解题者首先需要识别管道网络的拓扑结构并找到末端源头，然后需要发现颜色在交叉口的"等待-混合-再传播"机制——关键的隐蔽性在于混合规则必须从多个样例中通过观察交叉口前后的颜色变化来归纳，而非直接给出。管道的连接方式决定了哪些颜色会在哪里相遇，使得空间结构与颜色逻辑紧密耦合。
</new_puzzle>

<new_puzzle>
- `description`：识别网格中的"印章"和"画布"，将印章按画布上箭头标记指示的方向和次数进行旋转后盖印到画布的指定位置。
- `Input structure`：Azure 背景网格上有若干用黑色边框围起来的小矩形区域（"印章"），每个印章内部有一个由某种颜色构成的小图案（3x3 至 5x5）。网格上还有一个较大的黑色边框矩形区域（"画布"），画布内部为 Azure 背景色，其中散布着若干标记：每个标记由一个与某印章图案颜色相同的单像素点和紧邻该点的一个由 Maroon 像素构成的 L 形箭头组成。L 形箭头由两个像素构成：一个与彩色点相邻，另一个与第一个 Maroon 像素成 90 度方向——整体指示一个旋转方向（顺时针或逆时针）。
- `Rule`：
  1. 找到所有印章和画布。通过颜色匹配将画布中的彩色标记点与对应的印章配对。
  2. 分析每个标记旁的 L 形箭头：从彩色点出发，先走到第一个 Maroon 像素，再拐到第二个 Maroon 像素，拐弯方向决定旋转方向（向右拐 = 顺时针 90 度，向左拐 = 逆时针 90 度）。
  3. 统计每种颜色在画布中出现的标记数量 N。将对应印章旋转 N 个 90 度（按箭头指示的方向累计旋转）。
  4. 将旋转后的印章图案以彩色标记点为中心盖印到画布上（覆盖 Azure 背景，不覆盖黑色边框和其他已盖印图案）。如果同色标记有多个，在每个标记位置都盖印同一个旋转结果。
  5. 擦除所有 Maroon 箭头像素和彩色标记点。输出仅包含画布区域（含边框），紧凑裁剪。
- `Key insight`：解题者需要依次发现三层结构：（1）颜色匹配确定印章-标记配对；（2）L 形箭头的几何朝向编码了旋转方向；（3）同色标记的数量决定了旋转次数——每一层都需要从样例中独立归纳，且只有三层规则同时正确才能得到正确输出。
</new_puzzle>

<new_puzzle>
- `description`：根据网格中封闭区域的"邻接图"结构，将区域重新着色，使得邻接数量相同的区域获得相同颜色，邻接数量不同的区域获得不同颜色，颜色分配顺序由区域面积决定。
- `Input structure`：黑色网格线将整个网格划分为若干不规则的封闭区域（类似彩色地图）。每个区域填充着某种非黑色颜色（输入中各区域颜色可能相同也可能不同，这些初始颜色是干扰项）。网格右侧有一列分隔开的色块从上到下排列，作为"调色板"，提供可用的输出颜色。
- `Rule`：
  1. 忽略各区域的输入颜色。识别黑色网格线划分出的所有封闭区域。
  2. 计算每个区域的"邻接度"——即与该区域共享黑色边界线段的其他区域数量（两个区域之间共享至少一个像素长度的黑色边界即视为邻接）。
  3. 将所有区域按邻接度分组。对各组按"该组中面积最大的区域的面积"从大到小排序。
  4. 依次将右侧调色板中从上到下的颜色分配给排序后的各组：第一组（含面积最大区域的组）用调色板第一个颜色，第二组用第二个颜色，依此类推。
  5. 用分配的颜色重新填充每个区域。黑色网格线和调色板保持不变。
- `Key insight`：输入中区域的原始颜色是纯干扰——解题者必须忽略它们，转而发现隐藏的邻接度等价关系。两层推理：第一层是发现"邻接度相同 = 同色"的分组规则，第二层是发现组间排序依据面积最大成员的面积来确定调色板映射顺序。
</new_puzzle>
