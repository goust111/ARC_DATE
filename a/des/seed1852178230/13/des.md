<description>
根据封闭区域内部标记像素的颜色，从色带图例中查找对应模板，将模板图案铺填到该封闭区域内部。

Input structure
- 背景为 black。网格上方有一条水平色带图例，由若干段不同颜色的连续色块组成（如 red 段、blue 段、green 段），每段色块宽度为 3-5 像素、高度为 1 像素。每段色块正下方紧邻一个相同宽度、高度为 2-3 行的小型二值图案（仅由 grey 像素和 black 像素构成）。色带各段之间用至少 1 列 black 分隔。
- 网格下半部分散布着若干用同一种边框颜色（如 blue）绘制的 1 像素宽封闭矩形边框，矩形内部全为 black，但恰好包含一个单像素标记，标记颜色与色带图例中某一段色块颜色相同。不同矩形内的标记颜色可以相同也可以不同。

Rule
- 对每个封闭矩形区域，读取其内部标记像素的颜色，在色带图例中找到同色段。
- 取该色段下方对应的小型二值图案作为瓦片模板。
- 以矩形区域内部（不含边框）的左上角为起点，将该瓦片模板按行列周期性平铺到矩形内部所有像素位置：模板中 grey 像素对应的位置填入标记颜色，模板中 black 像素对应的位置保持 black。
- 标记像素本身被瓦片覆盖（按照平铺结果决定其颜色），不再单独保留。矩形边框和色带图例保持不变。

Key insight
- 标记颜色不是用来直接填充区域的，而是一个索引键，指向色带图例中的二值瓦片模板；解题者需要先建立"颜色→模板"的映射，再执行周期性铺贴——这两步推理缺一不可。
</description>

<new_puzzle>
<description>
将网格中每个 C 形凹槽对象沿开口方向平移至开口被封闭，然后用对象自身颜色填满封闭后形成的内部空腔。

Input structure
- 背景为 black。网格中散布着若干单色 4-连通前景对象，每个对象都是一个"C 形"凹槽——即一个实心矩形去掉其某一侧边中央连续若干像素后形成的带有单侧开口的容器形状。开口宽度严格小于该侧边总长度（即开口两端各保留至少 1 像素的边角）。
- 每个对象的颜色各不相同（如 red、green、blue、yellow 等）。
- 对象之间有足够间隔，开口方向在上、下、左、右四种中各有分布。

Rule
- 对每个前景对象，确定其凹槽开口方向：比较对象的外接矩形与实际像素，缺失像素所在的那一侧即为开口方向。
- 将该对象整体沿开口方向逐格平移，直到开口侧的所有缺失像素行（或列）都紧邻网格边界或另一个已定位前景对象的实体像素为止。
- 平移完成后，对象的开口被边界或障碍封闭，用该对象自身颜色填充被封闭后形成的内部空腔（即原本凹槽内侧的 black 矩形区域）。
- 处理顺序：按平移距离从短到长依次处理；先到位的对象成为后续对象的障碍物。

Key insight
- 解题者需要先从形状中识别"开口方向"这一非显然属性（需要将实际形状与其外接矩形做差异对比），然后理解移动的终止条件是"封闭开口"而非简单碰壁——运动方向、终止条件和填充行为全部由同一个几何缺口特征决定。
</description>

<new_puzzle>
<description>
将散布在网格中的彩色线段按颜色配对，每对线段之间沿折线路径连接；折线的两段分别继承出发侧线段的颜色，拐角用特殊颜色标记。

Input structure
- 背景为 black。网格中有若干条短线段（长度 2-4 像素），每条线段为纯色且方向为水平或竖直。
- 颜色成对出现：每种前景颜色恰好有两条线段。
- 每条线段的一个端点被替换为 grey 像素，表示该端点为连接端。其余像素保持线段原色。
- 线段之间不重叠，且任意两个待连接的 grey 端点之间存在唯一的不穿越其他线段的 L 形折线路径。

Rule
- 对每种颜色，找到该颜色的两条线段（分别称为线段 A 和线段 B），定位各自的 grey 连接端点。
- 确定折线路径走法：从线段 A 的 grey 端出发，第一段沿线段 A 自身延伸方向（即从线段 A 的非 grey 端指向 grey 端的方向）继续直线前进；到达与线段 B 的 grey 端同行或同列的位置后，第二段转 90 度直线走到线段 B 的 grey 端。
- 折线第一段（从线段 A 的 grey 端到拐角，不含拐角）用线段 A 的颜色绘制；折线第二段（从拐角到线段 B 的 grey 端，不含拐角和 grey 端）用线段 B 的颜色绘制；拐角处的 1 个像素用 maroon 标记。
- 将所有线段上的 grey 端点恢复为其所属线段的原始颜色。

Key insight
- 解题者需要三层推理：(1) 通过 grey 标记识别每条线段的连接端并按颜色配对；(2) 折线走向由线段 A 自身延伸方向决定（不是随意选择先水平还是先竖直）；(3) 折线分段着色——每段继承出发侧线段的颜色，拐角独立标记为 maroon。
</description>

<new_puzzle>
<description>
网格被分割线划分为若干矩形房间，每个房间有一面特殊颜色的"镜墙"；将房间内的彩色像素关于镜墙做镜像反射，在对称位置绘制副本。

Input structure
- 背景为 black。网格由 grey 单像素宽的直线划分为若干不重叠的矩形房间（grey 线段构成完整网格状分割，房间大小不一但均为矩形）。
- 每个房间的四面墙（紧邻房间内部的 grey 线段）中，恰好有一面墙的 grey 像素被替换为 azure，称为"镜墙"。其余三面墙保持 grey。
- 每个房间内部包含 1-3 个彩色前景像素（颜色为非 black、非 grey、非 azure 的颜色），散布在房间内部的任意位置。

Rule
- 对每个房间，识别其 azure 镜墙的位置和方向（上墙、下墙、左墙或右墙）。
- 将房间内每个彩色像素关于镜墙所在直线做对称翻转：若镜墙在房间上侧（即房间顶部边界为 azure），则该像素到房间顶行的距离为 d 行，翻转后的像素位于从房间顶行向下 d 行的位置、列坐标不变；其余方向类推。实质上，像素坐标在垂直于镜墙的轴上关于镜墙位置取对称值，平行于镜墙的轴坐标不变。
- 在翻转目标位置绘制与原像素相同颜色的副本。原像素保留不动。
- 若翻转目标位置落在房间内部范围之外（即超出该房间的边界），则不绘制该副本。
- 所有 grey 分割线和 azure 镜墙保持不变。

Key insight
- 分割线颜色的局部变化（grey→azure）是隐蔽的方向编码，解题者必须注意到每个房间恰好有一面墙颜色不同，并归纳出这面墙充当镜面反射轴——关键在于"镜墙"概念需要从边界颜色差异中自主发现，而非显式给出。
</description>
</new_puzzle>

<new_puzzle>
<description>
根据种子对象的同心嵌套层数确定放大倍数，将最内层核心按该倍数放大后，用各层颜色从内到外重新包裹，在指定位置绘制放大版同心结构。

Input structure
- 背景为 black。网格中有若干独立的小型"种子对象"，彼此至少间隔 2 像素。
- 每个种子对象是一个正方形的同心嵌套结构：最外层是一圈颜色 A 的 1 像素宽正方形框，下一层是一圈颜色 B 的 1 像素宽正方形框……直到最内层是一个 1x1 的实心核心像素。每层颜色各不相同，层数在 2-4 层之间（含核心）。例如，一个 3 层种子对象外观为 5x5 正方形：最外圈为 red、中间圈为 blue、中心 1x1 为 yellow。
- 网格中另有若干 1x1 的 grey 标记像素，数量与种子对象相同，散布在网格的其他位置。

Rule
- 将种子对象按其左上角坐标从上到下、从左到右排序；将 grey 标记点按相同方式排序；按顺序一一配对。
- 对每个种子对象，统计其嵌套层数 n（包含核心层）。
- 放大倍数等于 n：取种子最内层核心的 1x1 像素，放大为 n x n 的实心色块。
- 从放大后的核心开始，向外逐层包裹 1 像素宽的正方形边框，颜色顺序与种子对象从内到外的层序一致（即倒数第二层颜色紧贴放大核心外侧，最外层颜色在最外面）。
- 将最终构建的放大同心结构以其对应 grey 标记点为中心绘制到网格上，覆盖该标记点。原始种子对象保留在原位不变。

Key insight
- 解题者需要两步非平凡推理：(1) 识别种子对象的同心嵌套层结构并数出层数，理解层数本身决定了核心的放大倍数（而非某个固定常数）；(2) 放大操作仅针对最内层核心，各层颜色按照原始从内到外的顺序重新构建——放大结果不是种子的整体等比缩放，而是核心的选择性放大加上颜色层序的忠实重现。
</description>

<description>
网格中散布的彩色碎片根据颜色找到对应的框架，旋转至唯一匹配的姿态后填入框架内部的空缺区域；框架内部的固定障碍色块决定了碎片必须避开的位置。

Input structure
- 背景为 black。网格中有若干大型单色矩形框架（每个框架颜色不同，如 red、blue、green），每个框架由 1 像素宽的彩色边框围成一个矩形区域，内部为 black。
- 每个框架内部散布着 1-2 个小型 grey 矩形障碍色块（宽高均 >= 1 像素），占据框架内部的部分位置。
- 网格中另有若干小型彩色碎片对象（4-连通，形状不规则），每个碎片的颜色与某个框架边框颜色相同，表示该碎片属于该框架。每种框架颜色恰好对应一个碎片。
- 每个碎片的像素数恰好等于其对应框架内部 black 像素的数量（即框架内部面积减去 grey 障碍色块面积）。

Rule
- 按颜色将碎片与框架配对。
- 对每个碎片，尝试 0 度、90 度、180 度、270 度旋转（绕碎片外接矩形中心旋转），找到唯一一种旋转方式，使碎片形状恰好覆盖框架内部所有非 grey 的 black 空位而不与 grey 障碍重叠。碎片在框架内部的放置位置由精确匹配唯一确定。
- 将旋转后的碎片以其自身颜色绘制到框架内部的对应空位上。
- 碎片原始位置的像素清除为 black。框架边框和 grey 障碍色块保持不变。

Key insight
- 解题者需要先通过颜色匹配确定碎片与框架的归属关系，然后理解 grey 色块是"已占位障碍"而非装饰——碎片不是简单地填满整个框架内部，而是必须精确嵌入 grey 障碍之间的剩余空间。旋转选择需要同时考虑框架内部形状和障碍位置的约束，形成一个带约束的空间拼合问题。
</description>
</new_puzzle>

<new_puzzle>
<description>
每个前景对象根据其内部孔洞的数量，在对象外围绘制相应层数的同色膨胀环带。

Input structure
- 背景为 black。网格中散布着若干单色 4-连通前景对象，彼此间隔足够大。
- 每个对象形状不规则，但都是"实心带孔"结构——即对象像素围成的区域内部可能包含 0-3 个由 black 背景构成的 4-连通封闭孔洞。
- 不同对象可能颜色相同或不同。

Rule
- 对每个前景对象，统计其内部封闭孔洞的数量 k（完全被该对象像素包围的 black 连通区域，不与网格边界相通的 black 区域即为孔洞）。
- 若 k = 0，对象保持原样不变。
- 若 k >= 1，在对象外围绘制 k 层膨胀环带：第 1 层环带由所有与对象外边界 4-相邻的 black 像素组成，填充为对象颜色；第 2 层环带由所有与第 1 层环带外边界 4-相邻的 black 像素组成，同样填充为对象颜色；以此类推直到绘制 k 层。
- 膨胀环带不填充对象内部的孔洞——孔洞保持 black 不变。膨胀仅向对象外部扩展。
- 如果膨胀过程中某些像素超出网格边界，则忽略这些像素。

Key insight
- 解题者需要两步独立推理：(1) 发现对象内部孔洞数量是控制变换的关键参数（孔洞需要通过判断 black 区域是否被完全包围来识别，而非简单地数 black 像素）；(2) 该数量决定的不是颜色或位移，而是向外膨胀的层数——孔洞越多，外围扩展越厚。内部孔洞本身保持不变，这构成了一个"内部特征决定外部行为"的反直觉映射。
</description>
</new_puzzle>
