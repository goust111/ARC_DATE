- `description`：根据边框形状内部的"种子色块"确定填充图案，再利用边框缺口方向将图案向外投射到网格边界。
- `Input structure`：
  - 背景色为 black。
  - 网格中有若干个由同一颜色（如 blue）绘制的闭合矩形边框（边宽 1 像素），每个边框恰好有一个缺口（连续缺失 1-3 个像素的开口）。
  - 每个边框内部有一个由另一种颜色（如 red、green、yellow 等，每个边框内部颜色不同）绘制的小型色块图案（2x2 或 3x3 的非背景像素组合，可含背景色空隙）。
  - 边框外部全为背景色。
- `Rule`：
  - 对每个矩形边框，首先识别其缺口所在的边（上、下、左、右）以及缺口在该边上的位置。
  - 从缺口位置出发，沿缺口朝外的方向（例如缺口在上边则向上），将边框内部的小型色块图案作为"瓷砖"周期性平铺，直到到达网格边界。投射带的宽度等于缺口的宽度，投射方向与缺口朝外方向一致。
  - 具体地：将色块图案在投射方向上重复排列，投射带的横向对齐以缺口中心与色块图案中心对齐为准。色块图案保持原始朝向不变。
  - 边框本身和内部的色块保留不变；投射的图案像素不覆盖已有的非背景像素。
- `Key insight`：边框缺口不仅指示投射方向，其宽度还约束了投射带的范围；内部色块不是装饰，而是需要被周期重复投射的"发射物模板"。解题者需要同时归纳出方向选择规则和图案平铺规则两层逻辑。
</new_puzzle>

- `description`：将散落的彩色碎片按颜色归组，每组碎片拼合成一个完整矩形后，按矩形面积从小到大堆叠到输出网格的固定锚点上。
- `Input structure`：
  - 背景色为 black。网格尺寸不超过 25x25。
  - 网格中散布着若干彩色碎片（每个碎片是一个 4-连通的非背景色像素区域）。
  - 颜色种类为 3-5 种（如 red、green、blue、yellow）。同一颜色的碎片有 2-4 块，它们的形状互不相同。
  - 网格右下角有一个 grey 像素作为锚点标记。
- `Rule`：
  - 对每种颜色，收集该颜色的所有碎片。这些碎片可以像拼图一样无重叠地拼合成一个完整的实心矩形（无需旋转或翻转，只需平移）。拼合方式唯一。
  - 计算每种颜色拼合后矩形的面积（宽 x 高）。
  - 以 grey 锚点像素为输出区域的右下角，将各颜色的矩形按面积从小到大、从上到下依次竖直堆叠。最小面积的矩形底边紧贴锚点所在行，每个矩形的右边与锚点所在列对齐，相邻矩形之间无间隔。
  - 输出仅包含堆叠后的矩形区域（紧凑裁剪），锚点像素被矩形覆盖后不再显示。
- `Key insight`：第一层推理是发现同色碎片能无缝拼成矩形（需要在脑中试拼）；第二层推理是发现拼合后的面积决定了堆叠顺序和最终布局。碎片的空间散布位置是干扰信息，与输出位置无关。
</new_puzzle>

- `description`：在网格中找到被 grey 通道连接的彩色房间对，根据房间内标记像素的数量差异决定颜色"流动"方向，将像素多的房间的颜色沿通道灌入像素少的房间。
- `Input structure`：
  - 背景色为 black。
  - 网格中有若干个由 blue 像素围成的封闭矩形区域（"房间"），每个房间内部填满背景色，并散布着若干该房间特有颜色的标记像素（如 red、green、yellow、orange 等，每个房间只有一种非背景色标记）。不同房间的标记颜色互不相同。
  - 部分房间之间通过 grey 像素形成的 1 像素宽直线通道相连（通道穿过两个房间之间的 blue 墙壁，连接两个房间的内部空间）。每条通道恰好连接两个房间。一个房间最多连接一条通道。
  - 有些房间没有通道连接（孤立房间）。
- `Rule`：
  - 对于每对通过通道连接的房间 A 和 B：
    - 数出 A 内部标记像素的数量 Na 和 B 内部标记像素的数量 Nb。
    - 标记像素较多的房间为"源房间"，较少的为"目标房间"（若相同则不变化）。
    - 将通道上的所有 grey 像素重新着色为源房间的标记颜色。
    - 将目标房间内的所有背景色像素（非标记、非墙壁的空位）填充为源房间的标记颜色。目标房间原有的标记像素保持不变。
  - 孤立房间（无通道连接的）保持不变。
  - blue 墙壁始终不变。
- `Key insight`：第一层推理需要发现 grey 通道定义了房间之间的配对关系；第二层推理需要发现房间内标记像素的数量对比决定了颜色的"流动"方向——从多到少。通道不仅是连接标志，还是颜色传输的可视化路径。
</new_puzzle>

- `description`：根据网格边缘的彩色刻度线确定行列坐标映射，在网格内部的交叉点处绘制与刻度颜色匹配规则对应的标记。
- `Input structure`：
  - 背景色为 black。网格尺寸约 15x15 至 25x25。
  - 网格的最左列和最上行作为"刻度轴"：最左列的某些行上有单个彩色像素（如 red、green、blue 等），最上行的某些列上也有单个彩色像素。这些刻度像素颜色各不相同，且左列和上行使用的颜色集合可能有重叠。
  - 网格内部（排除刻度轴后的区域）在部分位置已经绘制了 maroon 像素作为示例标记。
  - 左上角 (0,0) 位置为空（背景色）。
- `Rule`：
  - 对于网格内部的每个位置 (r, c)（r 为行，c 为列，均从 0 开始计数，排除刻度轴），检查最左列第 r 行是否有刻度像素、最上行第 c 列是否有刻度像素。
  - 如果该位置的行刻度和列刻度都存在且颜色相同，则在该位置放置一个与该刻度颜色相同的像素。
  - 如果该位置的行刻度和列刻度都存在但颜色不同，则在该位置放置一个 maroon 像素。
  - 如果行刻度或列刻度只有一个存在（另一个为空），则该位置保持背景色。
  - 如果两个都不存在，也保持背景色。
  - 输出网格大小与输入相同，刻度轴保留不变。
- `Key insight`：第一层推理需要发现边缘的彩色像素是行列坐标的刻度标记；第二层推理需要从已有的 maroon 示例中归纳出"同色交叉保持原色、异色交叉变 maroon"的双条件规则。刻度系统本身是稀疏的，只有部分行列有标记，增加了模式识别的难度。

<new_puzzle>
- `description`：识别输入网格中由不同颜色绘制的重叠矩形层，按遮挡关系还原每层矩形的完整形状，然后将所有层按从底到顶的顺序水平排列输出。
- `Input structure`：
  - 背景色为 black。网格尺寸约 12x12 至 20x20。
  - 网格中显示的是 3-5 个不同颜色的实心矩形叠放后的俯视图。每个矩形颜色唯一（如 red、blue、green、yellow、orange）。
  - 矩形之间存在部分重叠，上层矩形遮挡下层矩形，导致被遮挡的矩形只能看到未被覆盖的部分像素（形成 L 形、U 形或条状的可见区域）。
  - 最上层的矩形完全可见（是完整矩形），最下层的矩形可能只露出很小一部分。
- `Rule`：
  - 首先确定遮挡顺序（从顶到底）：完全可见为完整矩形的颜色在最顶层；被其他颜色打断的矩形在更底层。具体判断方法是：如果颜色 A 的可见区域的边界处紧邻颜色 B 的像素，且颜色 A 的可见区域不构成完整矩形，则 B 遮挡了 A，B 在 A 之上。
  - 对于每个被遮挡的矩形，还原其完整矩形边界：该矩形的完整范围是其可见像素的 bounding box（因为矩形是轴对齐的，被遮挡的部分可以通过 bounding box 推断）。
  - 输出时，将每个矩形（还原为完整实心矩形）按照从底层到顶层的顺序从左到右水平排列。相邻矩形之间用 1 列 grey 像素分隔。输出高度为所有矩形中最大的高度，较矮的矩形顶部对齐（即底部可能有背景色填充到统一高度）。
- `Key insight`：第一层推理需要从不规则的可见区域形状中识别出"矩形重叠遮挡"的空间模型，并推断遮挡层序；第二层推理需要发现每个矩形的完整尺寸可以通过其可见部分的 bounding box 恢复；第三层推理需要发现输出的排列顺序是从底层到顶层（与视觉上的显著性相反）。解题者必须在脑中"拆分"叠放的层次。
</new_puzzle>

- `description`：找出网格中每个封闭区域内的"种子"像素图案，将该图案按区域形状进行适应性平铺填充，同时用区域边界的颜色决定填充时的颜色替换。
- `Input structure`：
  - 背景色为 black。网格尺寸约 20x20 至 28x28。
  - 网格中有若干个由不同颜色绘制的 1 像素宽闭合边界（每个边界颜色唯一，如 red、blue、green 等），围成不规则但无锯齿的封闭区域（边界由水平和竖直线段组成，形成直角多边形）。
  - 每个封闭区域内部有一个小型"种子图案"：由 azure 像素绘制的 2x2 或 3x3 小图案（可以包含背景色空隙），位于区域内部的左上角（紧贴内壁）。
  - 区域内部其余位置为背景色。
- `Rule`：
  - 对每个封闭区域：
    - 提取其左上角的 azure 种子图案（取种子的 bounding box）。
    - 将种子图案作为瓷砖，从区域内部左上角开始，向右和向下周期性平铺，填满整个区域内部。超出区域边界的部分裁剪掉（只保留区域内部的像素）。
    - 平铺完成后，将所有 azure 像素替换为该区域边界的颜色。背景色空隙保持为背景色。
  - 边界像素本身保持不变。
  - 不同区域独立处理。
- `Key insight`：第一层推理需要识别出每个区域左上角的小图案是"种子"而非普通装饰；第二层推理需要发现种子按周期平铺填充整个不规则区域并在边界处裁剪；第三层推理需要发现填充颜色不是种子本身的 azure，而是由包围该区域的边界颜色决定的颜色替换。三层规则逐步揭示，仅看一个样例很难同时归纳出全部规则。
</new_puzzle>

<new_puzzle>
- `description`：将网格中的彩色箭头作为"搬运指令"，把箭头所指方向上遇到的第一个彩色对象搬运到箭头尾部对称位置，箭头自身颜色决定搬运后对象的重新着色。
- `Input structure`：
  - 背景色为 black。网格尺寸约 15x15 至 25x25。
  - 网格中散布着若干"箭头"和若干"货物对象"。
  - 箭头的绘制方式：每个箭头由 3 个像素组成，呈 L 形排列。L 形的长边（2 像素）为箭头杆，短边（1 像素）垂直于杆的末端伸出，形成箭头尖端。箭头指向的方向为从杆的起点朝杆的末端（即尖端所在端）的方向。箭头颜色为单一颜色（如 red、blue、green 等）。
  - 货物对象：由 maroon 像素组成的小型连通图形（3-6 像素，形状各异），散布在网格各处。
  - 箭头和货物对象之间不接触，且箭头沿指向方向延伸的直线上至少会遇到一个货物对象。
- `Rule`：
  - 对每个箭头：
    - 确定箭头的指向方向（上、下、左、右之一）和箭头杆起点的位置（即远离尖端的那一端）。
    - 从箭头尖端沿指向方向扫描，找到该方向上遇到的第一个货物对象。
    - 将该货物对象从原位置移除（变为背景色）。
    - 将货物对象搬运到箭头杆起点的对称位置：即以箭头杆起点为基准，货物对象相对于箭头尖端的偏移量取反后放置。换言之，货物出现在箭头的"背后"，与原货物到箭头尖端的距离相同。
    - 搬运后的货物对象颜色从 maroon 替换为该箭头的颜色。
  - 箭头像素在输出中保留不变。
  - 未被任何箭头指向的货物对象保持不变。
- `Key insight`：第一层推理需要识别 3 像素 L 形为箭头并确定其指向方向；第二层推理需要发现箭头的作用是"抓取"前方最近的货物并将其搬到身后对称位置；第三层推理需要发现箭头颜色决定了搬运后货物的重新着色。箭头既是方向指示器、又是距离参照点、又是颜色指令，一个对象承载三重语义。
</new_puzzle>
