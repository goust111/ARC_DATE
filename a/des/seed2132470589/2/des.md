<new_puzzle>
- `description`：根据每个封闭区域内部标记像素的颜色，在该区域的外边界上找到同色"出口"像素，然后将区域内容沿出口方向投影到区域外部。
- `Input structure`：背景为 black。网格中有若干由 grey 像素围成的封闭区域（形状不规则但均为 4-连通闭合边界）。每个封闭区域内部包含若干散布的彩色像素（每个区域仅使用一种非 grey、非 black 的颜色，如 red、blue、green 等）。每个封闭区域的 grey 边界上恰好有一个像素被替换为与区域内部彩色像素相同的颜色，这个像素即为"出口标记"。出口标记与区域内部之间在 4-连通意义上通过区域内部相连。
- `Rule`：
  1. 对每个封闭区域，识别其 grey 边界上的彩色出口标记像素及其颜色 C。
  2. 确定出口方向：从区域内部中心（所有内部彩色像素的几何重心，取最近整数格）指向出口标记的基本方向（上、下、左、右四选一，取主分量方向）。
  3. 将区域内所有颜色 C 的像素擦除。
  4. 从出口标记向外（远离区域内部的那一侧），沿出口方向绘制一列颜色 C 的像素，像素数量等于区域内被擦除的彩色像素数量。如果碰到网格边界则截断。
  5. 出口标记本身保留为颜色 C，grey 边界其余部分不变。
- `Key insight`：边界上的异色像素既标识了出口位置又编码了投射方向；内部像素数量决定了投射长度。解题者需要先识别"边界上的异色点"这一非显然特征，再推断投射机制。
</new_puzzle>

<new_puzzle>
- `description`：将网格中散布的同色像素对视为"传送门"，把每个独立形状通过其接触的传送门颜色传送到同色的另一个传送门位置，并在目的地按传送门相对朝向进行旋转重绘。
- `Input structure`：背景为 black。网格中有若干由不同颜色构成的小型 4-连通形状（每个形状为单色，如 orange、maroon、azure 等，形状各异，占 3-6 个像素）。另外有若干"传送门对"：每种传送门颜色（如 red、green、blue）恰好出现两个孤立单像素，分布在网格不同位置。每个形状恰好有一个像素与某个传送门单像素 4-相邻（即形状的某个像素紧挨着一个传送门像素）。
- `Rule`：
  1. 识别所有传送门对：同色的两个孤立单像素为一对，记为 P1 和 P2。
  2. 对每个形状，找到它 4-相邻的传送门像素 P1，以及 P1 的配对传送门 P2。
  3. 确定形状相对于 P1 的布局方向：形状从 P1 的哪个方向延伸（以形状与 P1 相邻的那个像素为锚点，记锚点相对 P1 的方向为 D1）。
  4. 确定 P2 的"开放方向"：P2 的四个邻居中，哪个方向没有其他非背景像素阻挡，记为 D2。如果多个方向开放，取与 D1 顺时针旋转最少次数能对齐的那个方向。
  5. 将形状从原位擦除，以 P2 为新锚点参考，将形状旋转（D1→D2 的旋转量），重绘在 P2 的 D2 方向侧。形状保持原色。
  6. 传送门像素本身保留不变。
- `Key insight`：解题者需要先发现"孤立同色像素对"是传送门，再理解形状与传送门的邻接关系编码了传送源，最后推断旋转规则来自两个传送门各自的空间朝向差异。这是一个三层推理：识别传送门→确定配对→推断旋转。
</new_puzzle>

<new_puzzle>
- `description`：网格被分割为若干矩形房间，每个房间墙壁上有一个彩色"窗户"像素；房间内的图案需要被重新着色为其窗户所朝向的相邻房间的窗户颜色。
- `Input structure`：背景为 black。网格由 grey 的单像素厚直线分割成若干矩形房间（类似棋盘格但房间大小不等）。每个房间内部有一个由某种颜色绘制的小图案（占 2-5 个像素，形状各异）。每个房间的 grey 墙壁上恰好有一个像素被替换为某种非 grey、非 black 的颜色（称为该房间的"窗户"），窗户颜色与该房间内部图案颜色不同。窗户总是位于该房间与某个相邻房间的共享墙段上。
- `Rule`：
  1. 识别每个房间的窗户像素及其颜色 W。
  2. 确定窗户所在墙壁连接的是哪个相邻房间 N。
  3. 找到相邻房间 N 自己的窗户颜色 W_N。
  4. 将当前房间内部图案的颜色全部替换为 W_N（相邻房间的窗户颜色）。
  5. 所有窗户像素和 grey 墙壁保持不变。
- `Key insight`：窗户像素有双重作用——它标记了"朝向哪个邻居"（位置编码方向），同时每个房间自己的窗户颜色又是被其他房间引用的"颜色源"。解题者需要先理解窗户是方向指针，再发现颜色传递的间接性：不是用自己的窗户颜色，而是用窗户指向的邻居的窗户颜色来重绘图案。
</new_puzzle>

<new_puzzle>
- `description`：在网格的格子系统中，每行格子里有一个"模板格"和若干"目标格"；需要找出模板格中图案与目标格中图案的差异像素，然后仅保留这些差异像素并用模板格的边框颜色重新着色输出。
- `Input structure`：背景为 black。网格被均匀的 grey 线条分割成 M×N 的等大方格阵列（类似参考题 16 的格子结构）。每个方格内部可以包含由某种颜色绘制的图案（像素集合），也可以为空。在每一行方格中：恰好有一个方格的边框被替换为某种非 grey 的颜色（如 red、blue、green），该方格为"模板格"；其余方格边框保持 grey，为"目标格"。同一行中所有非空方格内的图案使用相同颜色绘制，且模板格的图案是最"完整"的（像素最多），目标格的图案是模板格图案的子集（部分像素被擦除为 black）。
- `Rule`：
  1. 对每一行方格，识别模板格（边框颜色非 grey 的那个）及其边框颜色 C。
  2. 提取模板格内的完整图案 T。
  3. 对该行每个目标格，计算其图案与 T 的差异：即 T 中存在但目标格中缺失的像素位置集合 D。
  4. 输出网格保持同样的格子结构。模板格内容清空。每个目标格中，仅绘制差异像素集合 D，颜色使用该行模板格的边框颜色 C。
  5. 格子线条在输出中保留为 grey。
- `Key insight`：解题者首先需要发现"彩色边框"标记了模板格（非显然，因为边框颜色可能与内容颜色混淆），然后需要理解输出的是"缺失部分"而非"共有部分"——这是一个逆向思维。边框颜色在输入中仅作为标记，但在输出中被复用为差异像素的绘制颜色，形成了跨功能的语义转移。
</new_puzzle>

<new_puzzle>
- `description`：每个彩色形状内部的孔洞数量决定了它在输出中被复制的份数，复制品沿形状最长轴方向等距排列；同时形状的原始颜色被替换为由孔洞数量在一个隐含色序中索引得到的新颜色。
- `Input structure`：背景为 black。网格中有 3-5 个互不重叠的 4-连通彩色形状，每个形状为单色（使用 red、blue、green、orange、maroon 等颜色），大小约 4×4 到 7×7 像素范围。部分形状内部有 4-连通的 black 孔洞（被形状完全包围的 black 区域），孔洞数量从 0 到 3 不等。网格边缘有一行或一列由若干颜色按固定顺序排列的单像素色条（如左边缘从上到下依次为 yellow、azure、magenta、green），这是"色序图例"。
- `Rule`：
  1. 识别每个彩色形状及其内部孔洞数量 H。
  2. 在网格边缘找到色序图例（一列或一行紧贴边缘的连续彩色单像素），读取颜色序列，索引从 0 开始。
  3. 如果 H = 0，该形状在输出中消失（不绘制）。
  4. 如果 H ≥ 1，将形状复制 H 份。确定形状的最长轴方向（水平或垂直，由形状 bounding box 的长边决定）。沿该方向将 H 份副本等距排列（相邻副本之间间隔 1 个像素），起始位置为原形状位置。
  5. 每份副本的颜色替换为色序图例中第 H 个颜色（索引从 1 开始，即 H=1 取图例第 1 个颜色，H=2 取第 2 个，依此类推）。
  6. 副本中的孔洞保留为 black。色序图例在输出中保留不变。
- `Key insight`：解题者需要完成三层推理：(1) 发现孔洞数量是控制变量而非装饰；(2) 发现边缘色条是颜色查找表且孔洞数量是索引；(3) 理解复制方向由形状自身几何属性决定。孔洞数量同时控制"是否保留""复制几份"和"用什么颜色"三个输出属性，这种一对多的编码关系增加了机制隐蔽性。
</new_puzzle>
