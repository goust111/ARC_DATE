- `description`：根据每个封闭区域内部标记像素的颜色，在该区域的外轮廓上用对应颜色绘制定向箭头（朝向区域重心方向的射线）。
- `Input structure`：黑色背景上有若干由灰色像素构成的封闭矩形环（一像素宽的空心矩形框）。每个矩形环内部恰好有一个彩色标记像素（非黑非灰），位于环内某个位置。环与环之间互不接触。
- `Rule`：
  1. 对每个灰色矩形环，找到其内部的彩色标记像素。
  2. 判断标记像素相对于矩形环中心的方位（上/下/左/右四方向，取行差或列差绝对值较大的那个维度）。
  3. 在矩形环外轮廓与该方位相反的那条边的中点位置，向外延伸一条射线（长度等于矩形环该方向边长的一半），颜色为标记像素的颜色。射线末端添加一个垂直于射线方向的三像素横杠作为箭头头部。
  4. 灰色矩形环和内部标记像素保持不变。
- `Key insight`：标记像素的偏移方向编码了箭头应指向的反方向——箭头从标记的对侧边射出，仿佛标记在"推"矩形框，使箭头从对面弹出。解题者需同时归纳"方位取反"和"射线长度来源于边长"两层规律。

- `description`：将散落的彩色碎片按颜色配对后，用连接两碎片的最短直角路径填充第三种颜色，路径宽度由碎片面积差决定。
- `Input structure`：黑色背景上散布着若干彩色 4-连通对象。每种非背景颜色恰好出现两个对象（即颜色成对）。此外网格上还有一个单独的橙色单像素作为"宽度指示器"——它不参与配对。
- `Rule`：
  1. 将同色的两个对象配对。
  2. 对每一对，计算两个对象各自的像素面积，取较大面积减去较小面积的差值 d。
  3. 从较小对象的边界框中心到较大对象的边界框中心，绘制一条先水平后垂直的直角路径（曼哈顿 L 形），路径宽度为 d 像素（路径以中心线为轴向两侧扩展），颜色为橙色。
  4. 原有彩色对象保持不变；路径若经过已有像素则不覆盖。
- `Key insight`：颜色配对是第一层推理（从样例中发现同色对象总是两个）；面积差决定连接线宽度是第二层推理（需要数像素并观察宽度与差值的对应关系）。橙色单像素暗示了路径颜色但不参与配对。
</new_puzzle>

- `description`：根据种子图案在分隔线两侧的镜像缺失部分，用种子图案的互补色填充缺口，完成对称拼图。
- `Input structure`：网格被一条红色的完整水平或垂直分隔线分为两半。一侧包含一个由蓝色像素组成的完整"种子图案"（任意连通形状）；另一侧包含同一图案关于分隔线镜像后的部分副本——某些像素被删除留下黑色空位，另有若干绿色像素散布在该侧的非图案位置上。
- `Rule`：
  1. 识别分隔线和完整种子图案所在的一侧。
  2. 将种子图案关于分隔线做镜像反射，得到"期望镜像"。
  3. 在另一侧，比较期望镜像与实际存在的蓝色像素：凡是期望镜像中应有蓝色而实际为黑色的位置，填入绿色。
  4. 原本另一侧已有的蓝色像素保持蓝色不变；绿色散布像素被清除为黑色（它们是干扰项）。
  5. 种子侧和分隔线保持不变。
- `Key insight`：解题者需要先识别哪一侧是"完整模板"（通过连通性和完整性判断），再做镜像比对找出缺失位置。关键的第二层推理是发现绿色散布像素是干扰物而非答案的一部分——真正的填充位置由镜像差异决定，填充颜色恰好也是绿色，但位置完全不同于干扰像素。
</new_puzzle>

- `description`：将网格中每个彩色环的"开口方向"作为指令，按环从外到内的嵌套顺序依次执行方向指令，驱动一个光标从起点走出轨迹路径。
- `Input structure`：黑色背景上有若干同心嵌套的彩色矩形环（每个环用不同颜色，环宽一像素）。每个环恰好有一个一像素宽的缺口（开口）位于其四条边之一上。网格的一个角落有一个白色单像素标记作为光标起点。
- `Rule`：
  1. 按环的面积从大到小排序（最外层环面积最大）。
  2. 每个环的缺口所在边确定一个方向指令：缺口在上边→向上，缺口在下边→向下，缺口在左边→向左，缺口在右边→向右。
  3. 每个环的边长（较短边）确定该步的移动距离。
  4. 从白色起点出发，按从外到内的顺序依次执行方向指令：沿指定方向移动指定距离，在经过的所有像素上绘制该环的颜色。
  5. 光标最终停留位置绘制为白色。所有原始环结构被清除，只保留轨迹路径和终点。
- `Key insight`：解题者需要发现三层结构：（1）环的嵌套层级决定执行顺序；（2）每个环的开口位置编码移动方向；（3）环的尺寸编码移动步数。只有同时归纳这三层关系才能复现输出的彩色折线轨迹。
</new_puzzle>

- `description`：根据每行中特殊标记像素的数量选择该行应用哪种列重排模式，将网格的列按对应模式重新排列。
- `Input structure`：网格由多种颜色像素填充，没有明显背景色。网格最左列是一列交替出现的洋红色（magenta）像素和黑色像素组成的"控制列"。网格最上面两行是"模式定义行"：第一行定义模式 A（洋红标记数为 1 时使用），第二行定义模式 B（洋红标记数为 2 时使用）。模式定义行中，从左到右的颜色序列表示列的重排索引（例如第一行 [red, blue, green, red, blue, green...] 表示将列按 [1,2,3,1,2,3...] 的循环分组后组内不变）。
- `Rule`：
  1. 读取最左控制列：对于第 3 行及以下的每一行，数该行控制列及其右邻像素中洋红色像素的个数 n（n 为 1 或 2）。
  2. 若 n=1，该行的数据列（去掉控制列后的部分）按模式 A 重排：将所有列按模式 A 定义行中相同颜色分组，同组列保持相对顺序，组间按模式 A 中该颜色首次出现位置排列。
  3. 若 n=2，该行按模式 B 同理重排。
  4. 输出网格去掉控制列和模式定义行，只保留重排后的数据区域。
- `Key insight`：解题者首先要发现最上面两行不是普通数据而是"重排字典"；然后要发现控制列中洋红像素的数量（而非位置）选择使用哪个字典；最后要理解颜色序列如何编码列的分组重排规则。三层推理环环相扣，且前两层都需要跨样例归纳才能确认。
</new_puzzle>

- `description`：识别网格中由边框颜色编码的"容器"和由内部标记编码的"货物数量"，将每个容器缩放为其货物数量对应的标准尺寸并紧密排列。
- `Input structure`：灰色背景上有若干不同颜色的矩形空心边框（一像素宽），每个边框内部散布着若干小的 azure 色单像素标记（"货物"）。边框颜色各不相同且不为灰色或 azure。边框之间互不接触。
- `Rule`：
  1. 对每个矩形边框，数其内部 azure 标记像素的个数 k。
  2. 将该边框缩放为 k×k 大小的实心正方形（填充为该边框的颜色）。
  3. 将所有生成的正方形按 k 值从小到大排序；若 k 相同则按原始边框在网格中从左到右、从上到下的出现顺序。
  4. 输出网格为灰色背景，所有正方形从左上角开始逐行紧密排列（每行从左到右放置，一行放满则换下一行），正方形之间间隔一像素灰色。
- `Key insight`：第一层推理是发现 azure 标记的数量（而非边框自身尺寸）决定输出正方形的大小；第二层推理是发现排列顺序按数量递增而非按原始位置。边框在输入中的大小是干扰信息——大边框可能只有少量标记从而变成小正方形。
</new_puzzle>

<new_puzzle>
- `description`：将网格中的彩色"信号塔"按其高度确定广播半径，塔的广播区域重叠处取颜色混合规则的结果色。
- `Input structure`：黑色背景的方形网格底部有一行灰色像素作为"地面"。地面上方竖立着若干不同颜色的垂直柱体（宽一像素、高度不等），它们底部与地面相接。每根柱体的颜色唯一（不重复）。
- `Rule`：
  1. 每根柱体的高度 h 即为其"广播半径"。
  2. 以柱体顶端像素为圆心，在曼哈顿距离 ≤ h 的所有黑色背景像素上标记该柱体的颜色（形成菱形广播区域）。柱体本身和地面不被覆盖。
  3. 若某个背景像素被多根柱体的广播区域覆盖，则该像素着色为所有覆盖它的柱体中**最矮**那根的颜色（最矮柱体优先级最高）。
  4. 输出保留地面、所有柱体以及着色后的广播区域。
- `Key insight`：解题者首先需要发现柱体高度等于广播范围（通过观察菱形区域的大小）；第二层推理是发现重叠区域的着色规则——直觉上可能以为"强信号覆盖弱信号"（高塔优先），但实际规则恰好相反：矮塔优先。这种反直觉的优先级需要仔细比对样例中的重叠区域才能归纳出来。
</new_puzzle>
