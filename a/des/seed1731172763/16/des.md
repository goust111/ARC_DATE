- `description`：将输入中每个前景对象的"邻居数量"作为索引，在全局颜色表中查找对应的颜色，然后用该颜色重绘对象。
- `Input structure`：背景为 Black。网格中有若干不同颜色的 4-连通单色前景对象。网格底部有一行颜色表——从左到右依次排列的像素颜色，第 0 个位置对应邻居数 0，第 1 个位置对应邻居数 1，以此类推。颜色表上方有一行 Grey 分隔线。
- `Rule`：
  - 对每个前景对象（颜色表以外的），计算其"邻居数量"——与该对象 4-相邻的其他前景对象的数量（即有多少个不同的其他对象与它接触）。
  - 在颜色表中查找第 k 个位置的颜色（k = 邻居数量）。
  - 用查找到的颜色重绘该对象。
  - 移除颜色表和分隔线。
- `Key insight`：对象的原始颜色被完全丢弃——新颜色仅由"社交关系"（邻居数）决定。颜色表是一个按位置索引的查找表，邻居数是查表的键。
</new_puzzle>

<new_puzzle>
- `description`：将输入中由不同颜色构成的"同心环"图案的各层颜色向内旋转一圈——最外层颜色变为次外层，最内层颜色移到最外层。
- `Input structure`：背景为 Black。网格中心有一个由多种颜色构成的同心正方形环图案——最外层是一个矩形框，向内依次是更小的矩形框，直到中心像素。每层颜色不同，相邻层之间无间隔。
- `Rule`：
  - 识别所有同心环层，从外到内编号为 0, 1, 2, ..., N-1。
  - 将颜色循环旋转一步：
    - 第 0 层（最外层）取第 N-1 层（最内层）的原始颜色。
    - 第 1 层取第 0 层的原始颜色。
    - 第 2 层取第 1 层的原始颜色。
    - 以此类推。
  - 每层的几何形状保持不变，仅颜色改变。
- `Key insight`：颜色在同心环层之间循环移动——最内层颜色"跳跃"到最外层，其他颜色依次向内推进。这是环形空间中的颜色循环，而非简单的内外交换。
</new_puzzle>

<new_puzzle>
- `description`：将每个前景对象的形状"投影"到网格的四条边上，形成四条边框条纹——对象在某方向上的投影宽度决定该边上条纹的长度。
- `Input structure`：背景为 Azure。网格中有 1-3 个不同颜色的 4-连通单色前景对象，位于网格中心区域（不接触任何网格边缘）。
- `Rule`：
  - 清除所有原始前景对象。
  - 对每个原始对象：
    - 计算其在水平方向上的列跨度 W（包围盒宽度）和垂直方向上的行跨度 H（包围盒高度）。
    - 在网格的上边缘，绘制一条长度为 W 的同色水平条纹，水平居中于对象的列范围。
    - 在网格的下边缘，绘制同样的水平条纹。
    - 在网格的左边缘，绘制一条长度为 H 的同色垂直条纹，垂直居中于对象的行范围。
    - 在网格的右边缘，绘制同样的垂直条纹。
  - 多个对象的投影条纹可能重叠，后处理的对象覆盖先处理的。
- `Key insight`：对象从中心"消失"，但其空间属性被编码为四条边上的条纹——宽度信息投射到上下边缘，高度信息投射到左右边缘。对象的形状细节丢失，仅保留尺寸和位置的摘要。
</new_puzzle>

<new_puzzle>
- `description`：根据每个面板中的"箭头序列"依次对该面板的图案施加对应的变换（旋转或翻转），输出最终变换后的图案。
- `Input structure`：背景为 Black。网格由 Grey 分隔列分为若干等大面板。每个面板分为上下两区：上区是一个彩色图案，下区包含 1-3 个小的箭头标记（从左到右排列）。每个箭头由 3 个像素组成，形状为直角三角形（占据 2x2 区域中的 3 格），尖端指向上、右、下或左四个方向之一。
- `Rule`：
  - 对每个面板，从左到右读取下区的箭头序列。
  - 每个箭头代表一个变换操作：
    - 尖端朝上：顺时针旋转 90 度。
    - 尖端朝右：水平翻转（左右镜像）。
    - 尖端朝下：逆时针旋转 90 度。
    - 尖端朝左：垂直翻转（上下镜像）。
  - 按从左到右的顺序依次对上区图案施加这些变换。
  - 输出仅包含变换后的图案（移除箭头和分隔线）。
- `Key insight`：箭头不是指向目标的方向标记——它们是"操作码"序列，按顺序执行的多步变换。单个箭头的方向编码了一种特定的几何变换类型。
</new_puzzle>

<new_puzzle>
- `description`：将输入中每个前景色块"溶解"为该色块像素数量个单像素点，均匀散布在色块原始包围盒区域内，同时保持原始颜色。
- `Input structure`：背景为 Azure。网格中有若干不同颜色的实心矩形色块（不同大小），色块之间不重叠。
- `Rule`：
  - 对每个矩形色块：
    - 记录其像素数量 N、颜色 C 和包围盒。
    - 清空包围盒区域（改为背景色）。
    - 在包围盒区域内均匀放置 N 个颜色为 C 的单像素点：按从左到右、从上到下的扫描顺序，每隔固定间距放置一个点。间距计算为包围盒总像素数除以 N（向下取整），使得点尽可能均匀分布。
  - 背景区域保持不变。
- `Key insight`：实心色块被"解散"为同数量的散点——形状信息完全丢失，但像素总量、颜色和空间范围被保留。密度从原来的 100% 变为与面积成比例的稀疏分布。
</new_puzzle>
