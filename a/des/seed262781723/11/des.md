- `description`：根据信封对象的开口方向将内部信件颜色投递给沿途第一个邮箱，同时邮箱原色回流为信封边框的新颜色。

- `Input structure`：
  - 背景为黑色。
  - 网格中散布着若干个 3×3 的"信封"对象。每个信封由一种颜色的边框构成——完整边框共 8 个像素，但恰好有一侧中间像素缺失形成开口（缺口不在角上）。信封中心有一个与边框不同颜色的像素，称为"信件"。
  - 网格中另有若干孤立的彩色单像素，称为"邮箱"，邮箱与任何信封不相邻。

- `Rule`：
  - 第一步：识别每个信封边框上缺失像素的方向（上、下、左、右），即为该信封的开口方向。
  - 第二步：从信封中心沿开口方向发射一条直线射线，遇到的第一个邮箱像素即为目标邮箱。记录该邮箱的原始颜色。
  - 第三步：将目标邮箱的颜色替换为信封中心"信件"的颜色。
  - 第四步：将该信封的所有边框像素颜色替换为目标邮箱的原始颜色。信封中心像素保持不变。
  - 射线方向上没有邮箱的信封和未被任何射线命中的邮箱均保持原样。

- `Key insight`：开口方向编码了投递路径，而投递动作是双向颜色交换——信件颜色写入邮箱的同时，邮箱原色回流到信封边框。解题者需先识别缺口方向、再追踪射线、最后理解颜色双向置换这三层耦合机制。
</new_puzzle>

- `description`：将散落的碎片按其内部封闭孔洞的数量分类归入对应的容器框中，容器内碎片按面积从小到大自上而下堆叠。

- `Input structure`：
  - 背景为黑色，网格尺寸约 25×25 至 30×30。
  - 网格中有若干个由 grey 像素绘制的矩形空心框，称为"容器"。容器之间互不重叠，内部初始全为黑色。容器按从左到右的排列顺序分别对应孔洞数 0、1、2……（此映射需从样例归纳）。
  - 网格中散布若干个由各种非黑非 grey 颜色构成的 4-连通单色不规则形状对象，称为"碎片"。每个碎片内部可能包含 0 个、1 个或多个封闭孔洞——即被该碎片像素在 4-连通意义下完全包围的黑色背景连通区域。

- `Rule`：
  - 第一步：计算每个碎片内部封闭孔洞的数量（被碎片完全包围的 4-连通黑色区域个数）。
  - 第二步：将孔洞数相同的碎片归入对应的容器（从左到右第 k 个容器对应孔洞数 k-1）。
  - 第三步：取每个碎片的最小包围盒，保留原色，按面积（像素数）从小到大、自上而下依次放入容器内部。每个碎片的包围盒水平居中对齐容器内壁，相邻碎片之间无额外间隔行。
  - 第四步：清除容器外所有碎片的原始像素。

- `Key insight`：分类键不是颜色或形状，而是封闭孔洞数量——一个需要主动推理才能发现的视觉拓扑属性（第一层）；容器内按面积排序堆叠是第二层独立规则。两层规则各自都需要从样例中归纳。
</new_puzzle>

<new_puzzle>
- `description`：每个前景对象根据它接触的网格边界条数确定射线数量，接触哪条边就向内发射一条射线，射线长度等于该对象的像素面积。

- `Input structure`：
  - 背景为黑色，网格尺寸不超过 25×25。
  - 网格中有若干个 4-连通的单色前景对象，各对象颜色互不相同。
  - 部分对象的像素位于网格边界上（第 0 行、最后一行、第 0 列或最后一列），即接触了网格的上、下、左或右边缘。一个对象可能同时接触 0 到 4 条边缘。

- `Rule`：
  - 第一步：对于每个前景对象，判断它接触了网格的哪些边缘（上、下、左、右）。
  - 第二步：计算该对象的像素面积 N（N 通常不超过 8）。
  - 第三步：对于该对象接触的每一条边缘，找到该对象在该边缘上最靠中间的像素，从该像素出发向网格内部方向（上边缘→向下，下边缘→向上，左边缘→向右，右边缘→向左）绘制一条长度为 N 个像素的直线射线，颜色与对象相同。如果射线遇到其他非背景像素则在该像素前停止。
  - 不接触任何边缘的对象保持原样，不产生射线。

- `Key insight`：射线方向和数量由空间关系（接触哪些边界）决定，而射线长度由一个独立的数量属性（面积）决定。解题者需要分别归纳方向规则和长度规则，并理解两者耦合在同一变换中——这构成真正的双层推理。
</new_puzzle>

<new_puzzle>
- `description`：识别空心方框"表盘"上的彩色刻度标记和内部"指针"方向，按指针方向将刻度沿边框轨道做循环移位。

- `Input structure`：
  - 背景为黑色，网格尺寸约 22×22 至 28×28。
  - 网格中有若干个由 grey 像素构成的空心正方形环（边长为 5 或 7），称为"表盘"。每个表盘的边框上有若干个像素被替换为其他非黑非 grey 颜色，这些是"刻度标记"，其余边框像素仍为 grey。
  - 每个表盘的正中心有一个非黑非 grey 的彩色像素，称为"轴心"。轴心颜色不与该表盘的任何刻度颜色相同。
  - 从轴心出发，沿上、下、左、右四个方向中恰好一个方向，有一个紧邻轴心的 red 像素，称为"指针"。指针位于表盘内部空间中。

- `Rule`：
  - 第一步：识别每个表盘中指针相对于轴心的方向。指向上对应旋转 0 步（不旋转），指向右对应顺时针旋转 1 步，指向下对应 2 步，指向左对应 3 步。
  - 第二步：将表盘边框上的刻度标记沿边框轨道顺时针循环移位。边框轨道定义为从左上角出发沿上边→右边→下边→左边的顺时针像素序列。"1 步"表示沿轨道移动（边框周长÷4）个像素位置。
  - 第三步：移除指针（将 red 像素还原为黑色），轴心像素保持不变，grey 边框像素不变。
  - 各表盘独立处理。

- `Key insight`：解题者需从样例中归纳"指针方向→旋转步数"的映射关系（第一层），再理解刻度是沿离散边框轨道做 90° 整数倍的循环移位（第二层）。指针方向作为操作指令的编码方式是核心隐蔽机制——它看起来像装饰，实则控制变换参数。
</new_puzzle>

<new_puzzle>
- `description`：彩色种子像素沿 grey 通道网络扩散填充，当两条通道在交叉点相遇时，离交叉点更近的种子获得该像素的着色权。

- `Input structure`：
  - 背景为黑色，网格尺寸约 18×18 至 26×26。
  - 网格中由 grey 像素绘制了若干条水平和垂直的单像素宽直线通道。通道之间可能交叉形成十字路口（交叉处是一个同时属于水平和垂直通道的 grey 像素）。
  - 在部分通道的一端（最靠近网格边缘的那端），紧邻通道末端 grey 像素的外侧有一个彩色单像素（非黑、非 grey），称为"种子"。种子位于通道延长线上、通道之外。
  - 每条通道至多一端有种子，每个种子颜色互不相同。没有种子的通道初始只有 grey。

- `Rule`：
  - 第一步：每个种子从其所在端进入通道，将该通道上所有 grey 像素替换为种子的颜色，从种子端一直填充到通道另一端。
  - 第二步：对于交叉点像素（同时属于水平通道和垂直通道的位置），当两个种子各自沿自己的通道均试图填充该像素时，比较两个种子沿各自通道到该交叉点的步数（即种子到交叉点之间的通道像素数），步数更少（距离更近）的种子获得该交叉点的着色权。
  - 第三步：若某条通道无种子，则该通道所有 grey 像素保持 grey 不变；该通道上的交叉点仍可被另一条有种子的通道着色。
  - 种子像素本身保留在原位置不变。

- `Key insight`：基本的通道填充机制较易观察（第一层），但交叉点的颜色冲突解决规则是核心挑战（第二层）——解题者需要从多个样例中排除"后到覆盖""先到先得""按颜色优先级"等假设，才能归纳出"距离更近者优先"的规则。距离以数格子方式计量，属于直观可感的空间量。
</new_puzzle>

<new_puzzle>
- `description`：根据"模具"对象边框上彩色凹槽的位置和颜色，从匹配颜色的"原料条"上切出对应长度的片段，嵌入凹槽位置。

- `Input structure`：
  - 背景为黑色，网格尺寸约 20×20 至 28×28。
  - 网格中有一个较大的由 grey 像素构成的实心矩形对象，称为"模具"。模具的四条边上各有若干处连续缺口（grey 像素被移除为黑色），每处缺口的旁边（紧邻缺口外侧一行或一列）有一个与缺口等长的彩色线段标记，称为"凹槽标记"。凹槽标记的颜色各不相同。
  - 网格中另有若干条水平或垂直的彩色单色长条，称为"原料条"。每条原料条的颜色与恰好一个凹槽标记的颜色相同。原料条的长度大于或等于对应凹槽的长度。

- `Rule`：
  - 第一步：通过颜色匹配，将每个凹槽标记与对应的原料条配对。
  - 第二步：从原料条的一端截取与凹槽长度相等的片段（保持原色）。
  - 第三步：将截取的片段填入模具边框上的缺口位置，恢复模具的完整矩形轮廓。片段的方向与缺口方向一致（水平缺口用水平片段，垂直缺口用垂直片段）。
  - 第四步：原料条被截取后，剩余部分保留在原位；凹槽外侧的彩色标记像素被清除为黑色。
  - 若原料条长度恰好等于凹槽长度，则原料条完全消失。

- `Key insight`：解题者需要先发现模具边框上的缺口与外侧彩色标记的对应关系（第一层），再通过颜色匹配找到远处的原料条并理解截取长度由凹槽决定（第二层），最后将片段嵌入缺口完成修补（第三层）。凹槽标记既编码了需要修补的位置和长度，又通过颜色充当远程索引键。
</new_puzzle>

<new_puzzle>
- `description`：网格中的多个小图案各自被一个同色"画框"包围，画框的某条边上有一个异色标记像素；将每个图案沿标记所在边的法线方向翻转后，再按画框面积从大到小的顺序叠放到输出网格中央。

- `Input structure`：
  - 背景为黑色，网格尺寸约 24×24 至 30×30。
  - 网格中有若干个不重叠的矩形"画框"，每个画框由单一颜色的单像素宽空心矩形边框构成（不同画框颜色可以不同）。
  - 每个画框内部有一个由一种或多种非黑非框色颜色构成的小图案（4-连通对象或多个对象）。
  - 每个画框的边框上恰好有一个像素的颜色与该框其余边框像素不同（该异色像素为 yellow），称为"翻转标记"。翻转标记位于画框的上边、下边、左边或右边。

- `Rule`：
  - 第一步：识别每个画框及其内部图案，并找到翻转标记所在的边（上、下、左、右）。
  - 第二步：将画框内部图案沿标记所在边的法线方向做镜像翻转。具体地：标记在上边或下边，则图案做上下翻转；标记在左边或右边，则图案做左右翻转。翻转以画框内部空间的中心为对称轴。
  - 第三步：输出网格大小等于最大画框的内部尺寸。将所有翻转后的图案按画框面积（边框围成的总面积）从大到小的顺序依次居中叠放到输出网格上。后放的图案覆盖先放的图案（小框图案在最上层）。
  - 画框边框本身不出现在输出中。

- `Key insight`：翻转标记是一个微小的视觉异常，解题者需要先发现它的存在并理解它编码了翻转轴方向（第一层），然后发现输出是裁剪叠放而非原地变换、且叠放顺序由画框面积决定（第二层）。两层规则独立且都需要主动归纳。
</new_puzzle>
