- `description`：根据封闭区域内部孔洞的数量，在配色图例中查找对应颜色，然后用该颜色重绘整个封闭区域的轮廓。

- `Input structure`：
  - 背景为黑色（black）。
  - 网格中散布着若干由同一种颜色（如 grey）绘制的封闭矩形轮廓（单像素宽边框），每个矩形内部可能有零个、一个或多个小型背景色孔洞（即边框内部某些像素为黑色而非填充色）。
  - 网格的某一角落（如右下角）有一个竖向排列的配色图例：图例由若干小色块组成，每个色块占一行，从上到下分别代表"孔洞数量为 0、1、2、3……"所对应的颜色。图例色块的颜色各不相同（如 red、blue、green、yellow、orange 等）。
  - 矩形轮廓的内部除了孔洞外，其余像素用一种统一的填充色（如 azure）填满。

- `Rule`：
  - 对每个封闭矩形轮廓，计算其内部黑色孔洞的数量 N（N 通常在 0-4 的范围内）。
  - 在配色图例中，找到第 N+1 个色块对应的颜色 C。
  - 将该矩形的轮廓像素全部重绘为颜色 C，内部填充色和孔洞保持不变。
  - 图例本身在输出中保持不变。

- `Key insight`：孔洞数量不是装饰——它是通往图例的索引键。解题者需先发现"数孔洞"这一隐含属性，再发现图例是按孔洞数排列的颜色查找表，最后才能确定每个矩形轮廓应被染成什么颜色。

- `description`：将散落的彩色碎片按形状配对后，把每对碎片沿它们之间的中轴线对称合并为一个完整对象，并用两个碎片各自的颜色分别填充对应的半边。

- `Input structure`：
  - 背景为黑色（black）。
  - 网格中有偶数个互不重叠的小型前景对象，每个对象为单色（颜色各不相同，如 red、blue、green、orange、magenta、yellow 等）。
  - 这些对象两两配对：同一对中的两个对象具有完全相同的形状，但其中一个是另一个经过水平翻转或垂直翻转后的镜像。
  - 每对中的两个对象在网格上沿某条水平线或垂直线大致对称分布（它们到该中轴线的距离相等）。

- `Rule`：
  - 找到形状匹配的对象对（一个是另一个的镜像翻转）。
  - 对于每一对，确定两者之间的对称轴（水平或垂直方向的中线）。
  - 将两个对象沿对称轴合并：把两个碎片都移动到对称轴处拼合，使翻转后的形状恰好左右（或上下）对接。合并后的对象中，来自原左侧（或上方）碎片的像素保持该碎片的颜色，右侧（或下方）碎片的像素保持其颜色。
  - 清除原始位置上的碎片，只保留合并后的拼合对象。

- `Key insight`：解题者需要先通过形状匹配发现配对关系（两个碎片形状互为镜像），再推断出合并的位置在它们的对称中线处。颜色不是配对线索而是保留属性——形状才是关键匹配依据。

- `Input structure`：
  - 背景为黑色（black）。
  - 网格中央有一个较大的矩形区域，该区域内部全部为背景色（黑色），形成一个"空窗口"。
  - 窗口的四条边各由一种不同的纯色边框构成（每条边一种颜色，例如上边为 red、下边为 blue、左边为 green、右边为 yellow），边框宽度为一个像素。四个角落像素属于水平边框（上或下）。
  - 每条边框上有若干像素被替换为 maroon 色，形成"缺口标记"。缺口的位置沿该边分布不规则。

- `Rule`：
  - 对于每条边上的每个非缺口像素，从该像素位置向窗口内部垂直投射一条该边颜色的射线，射线延伸到窗口对面的边框为止，形成一条贯穿窗口的彩色条纹线。
  - 缺口（maroon）位置不投射射线，其对应的行或列在该方向上保持黑色。
  - 四个方向的射线同时投射。当水平射线和垂直射线在某个像素交叉时，垂直方向（来自上边或下边）的射线颜色优先显示。
  - 边框本身在输出中保持不变（包括缺口的 maroon 色）。

- `Key insight`：缺口标记决定了哪些行/列不被某个方向的颜色填充，从而在窗口内形成网格状的彩色图案。解题者需要先理解"边框颜色 = 投射方向"的映射关系，再发现缺口是"遮挡"机制，最后识别交叉处的优先级规则。
</new_puzzle>

- `description`：将网格中每个彩色"种子"像素沿其所在象限的对角方向生长为矩形色块，色块的宽和高分别等于该种子到最近水平分隔线和垂直分隔线的距离。

- `Input structure`：
  - 背景为黑色（black）。
  - 一条 grey 色的水平线和一条 grey 色的垂直线将网格分成四个象限（十字形分隔线，每条线宽一个像素）。
  - 每个象限内散布着若干单像素的彩色"种子"点（颜色可能为 red、blue、green、orange 等），种子点不接触分隔线。
  - 每个象限内的种子点颜色各不相同。

- `Rule`：
  - 对于每个种子像素，计算它到最近水平分隔线的行距 H 和到最近垂直分隔线的列距 W（均为正整数，不含分隔线本身）。
  - 以种子像素为起点，向该种子所在象限的角落方向（即远离十字中心的对角方向）生长一个 W 列 x H 行的矩形色块，颜色与种子相同。种子像素位于该矩形靠近十字中心的那个角。
  - 如果生长后的矩形超出网格边界，则在边界处截断。
  - 灰色分隔线在输出中保持不变。

- `Key insight`：种子的位置编码了两个信息——它到两条分隔线的距离分别决定了生成矩形的宽和高，而它所在的象限决定了矩形的生长方向。解题者需要发现距离与尺寸的对应关系，以及象限决定方向这两层规则。
</new_puzzle>

- `description`：识别网格中由不同颜色构成的嵌套矩形框架，按照从外到内的顺序提取各层颜色，然后在输出中将这些颜色按该顺序排列为从左到右的竖条纹。

- `Input structure`：
  - 背景为黑色（black）。
  - 网格中包含一个由多层同心矩形框架嵌套构成的结构。每层框架是单像素宽的矩形轮廓，使用不同的颜色（如最外层 red、第二层 blue、第三层 green、最内层 yellow 等）。各层框架之间间隔一个像素的黑色间隙。
  - 最内层框架的内部可能是黑色或包含一个单色填充的小矩形。
  - 嵌套层数在不同样例之间可能变化（通常 2-5 层）。

- `Rule`：
  - 识别所有矩形框架层，按照从最外层到最内层的顺序提取每层的颜色，得到一个有序颜色序列。如果最内层框架内部有填充色块，则该填充色作为序列的最后一个颜色。
  - 创建一个新的输出网格：高度等于嵌套结构中最外层框架的高度，宽度等于颜色序列的长度。
  - 从左到右，每列用序列中对应位置的颜色完全填充。

- `Key insight`：同心矩形的空间嵌套顺序被"展开"为一维的颜色条纹序列。解题者需要先识别出嵌套层级关系（而非简单地按颜色面积或位置排序），再理解输出是将这种嵌套深度线性化的结果。
</new_puzzle>

- `description`：网格中每个彩色对象充当"印章"，在其相邻的灰色画布区域上按特定朝向盖印自身形状，印章颜色由画布边缘的色带决定。

- `Input structure`：
  - 背景为黑色（black）。
  - 网格中有若干互不相连的灰色（grey）矩形区域，充当"画布"。
  - 每个画布的恰好一条外边缘紧邻着一条单像素宽的彩色色带（如 red、blue、green 等），色带颜色各画布不同。
  - 在网格的其他位置（不接触任何画布），散布着若干由 maroon 色构成的小型对象（形状各异，如 L 形、T 形等）。每个 maroon 对象恰好与某一个画布在该画布没有色带的某一侧相邻（间隔零像素或一像素）。

- `Rule`：
  - 对于每个画布，找到与之相邻的 maroon 对象。
  - 确定 maroon 对象相对于画布的方位（上、下、左、右）。
  - 将 maroon 对象的形状"盖印"到画布内部：以 maroon 对象靠近画布的那一排/列像素为基准，将形状投影到画布内，颜色使用该画布色带的颜色（而非 maroon）。印章在画布内的起始位置为与 maroon 对象对齐的边缘位置。
  - 如果印章形状超出画布范围则截断。输出中 maroon 对象被清除为背景色，色带和画布灰色底色保持不变。

- `Key insight`：解题者需要建立三重关联——maroon 对象提供形状，相邻方位决定投影方向，而色带提供最终颜色。三个属性分别来自三个不同的视觉元素，需要综合才能确定最终的盖印结果。
</new_puzzle>

- `description`：将网格中散落的同色像素团识别为"指令编码"，每个像素团的像素数量指定其同行的目标对象应旋转的 90 度倍数，旋转后的对象放回原位。

- `Input structure`：
  - 背景为黑色（black）。
  - 网格被一条灰色（grey）垂直分隔线分为左右两个区域。
  - 右侧区域包含若干互不重叠的彩色小型对象（每个对象为单色，形状不对称，如 L 形、阶梯形等），每个对象占据独立的若干行。
  - 左侧区域在与每个右侧对象相同的行范围内，放置了一小团 azure 色像素（4-连通团块）。每个 azure 团块的像素数量为 1、2 或 3。
  - 左侧不同行范围内的 azure 团块互不接触。

- `Rule`：
  - 将左右区域按行对齐配对：每个 azure 团块与同一行范围内的右侧彩色对象配对。
  - 读取每个 azure 团块的像素数量 N（N = 1、2 或 3）。
  - 将配对的彩色对象以其自身包围盒中心为轴，顺时针旋转 N x 90 度。
  - 旋转后的对象放回其原始包围盒的中心位置。左侧的 azure 团块在输出中被清除为背景色。灰色分隔线保持不变。

- `Key insight`：左侧的像素团不是装饰物，而是旋转指令的编码——像素数量 1/2/3 分别代表顺时针旋转 90/180/270 度。解题者需要先发现左右配对关系，再发现像素计数与旋转角度的对应规则。
</new_puzzle>
