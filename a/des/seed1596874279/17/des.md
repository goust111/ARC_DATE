<new_puzzle>
description：根据框架内部的孔洞数量，从网格边缘的色带图例中查找对应颜色，用该颜色填充框架围成的封闭区域（孔洞除外）。

Input structure：
- 背景为 Black。
- 网格的最左列或最上行有一条色带图例：色带由若干段不同颜色的连续像素组成，从上到下（或从左到右）依次编号 1、2、3……，每段长度为 1 像素。
- 网格其余区域分布着若干个由同一种前景色（如 Grey）绘制的一像素厚矩形框架（闭合矩形轮廓）。
- 每个框架内部可能有 0 至若干个单像素孔洞（即框架轮廓上缺失的像素，已被 Black 替代）。框架内部区域全为 Black。

Rule：
- 数出每个框架轮廓上的孔洞数量 H（缺失像素数）。
- 在色带图例中找到第 H 段颜色 C（从 1 开始计数；H=0 时不填充）。
- 将该框架包围的内部 Black 像素全部填充为颜色 C，但不修改框架轮廓本身。
- 孔洞处的轮廓像素保持 Black 不变。

Key insight：框架上的孔洞数量不是需要修复的缺损，而是一个索引值，用来从边缘色带图例中查找填充颜色；解题者需要先发现"数孔洞"这一非显然步骤，再发现色带的编号含义。
</new_puzzle>

<new_puzzle>
description：将散落的同色像素对视为"传送门"端点，把从每个端点出发的射线通过传送门接力延伸到另一端，最终在射线终点绘制标记。

Input structure：
- 背景为 Black。
- 网格中有若干颜色各异的像素对，每种非背景、非 Red 颜色恰好出现两个像素，它们构成一对"传送门"。
- 恰好有一个 Red 像素作为射线源，以及一个与 Red 像素同行或同列的 Grey 像素作为方向指示器（位于 Red 的正上/下/左/右方向）。

Rule：
- 射线从 Red 像素出发，沿 Red→Grey 方向的反方向直线行进（即背离 Grey 的方向）。
- 射线遇到的第一个非背景像素若是某传送门颜色 C 的一个端点 P1，射线"进入"传送门：从 C 的另一个端点 P2 出发，沿相同方向继续行进。
- 射线可以经过多个传送门，每次都从配对端点继续同方向行进。
- 射线最终到达网格边界时停止，在停止前最后一个 Black 像素处绘制一个 Maroon 像素。
- 射线经过的所有 Black 像素保持不变（不画轨迹），仅标记终点。

Key insight：解题者需要先识别出同色像素对是空间传送门而非普通障碍物，再理解射线"穿越"传送门后保持方向不变地从配对端点继续前进——这要求先归纳传送门配对规则，再追踪射线的接力路径。
</new_puzzle>

<new_puzzle>
description：根据每个封闭区域内部"种子十字"的臂长比例，选择性地向对应方向扩展该区域的外轮廓。

Input structure：
- 背景为 Black。
- 网格中有若干个由不同颜色绘制的一像素厚闭合矩形轮廓（各颜色不同，如 Blue、Green、Red 等）。
- 每个矩形内部中心处有一个由 Yellow 像素组成的十字形（加号形），十字的四条臂长度可能不同（范围 1-3 像素）。十字中心位于矩形内部的几何中心。

Rule：
- 检查每个矩形内部的 Yellow 十字的四条臂（上、下、左、右）。
- 某条臂的长度为 L 时，将矩形轮廓在该方向上向外平移扩展 L 个像素：即在该方向侧绘制 L 行（或列）新的同色轮廓像素，使矩形在该方向上增长 L 格。
- 扩展后重新闭合矩形轮廓（四角连接）。
- 移除所有 Yellow 十字像素（变为 Black）。
- 各矩形独立扩展；若扩展后轮廓重叠，后处理的矩形（按颜色在网格中首次出现的扫描顺序）覆盖先处理的。

Key insight：Yellow 十字不是装饰——它的四条臂分别编码了矩形在四个方向上的扩展量；解题者必须先发现臂长与扩展距离的对应关系，再理解十字是指令而非输出的一部分。
</new_puzzle>

<new_puzzle>
description：在一个被彩色路径网络分割的网格中，根据每块区域边界上路径颜色的"多数投票"结果来填充该区域。

Input structure：
- 背景为 Black。
- 网格中有多条一像素宽的直线路径（水平或垂直），颜色各异（如 Red、Blue、Green、Orange 等），它们相互交叉，将网格分割成若干个矩形区域。
- 每条路径从网格一边延伸到另一边（贯穿整个网格）。
- 路径交叉点处，上层路径颜色可见，下层路径颜色被遮挡。
- 网格的四个角各有一个单像素的 Yellow 标记。

Rule：
- 找到所有由路径围成的矩形封闭区域（内部全为 Black）。
- 对每个区域，统计其四条边界上接触的路径像素颜色（不含角点的交叉色）。
- 将该区域内部全部填充为出现次数最多的边界路径颜色；若出现平局，选择在该区域上边界出现的颜色。
- 路径本身像素和 Yellow 角标记保持不变。

Key insight：路径交叉形成的格子是分区工具而非输出重点；真正的推理在于"边界多数色决定填充色"这一投票机制——解题者需要先理解分区结构，再发现统计投票规则，最后注意到上边界优先的平局消解。
</new_puzzle>

<new_puzzle>
description：将散落的彩色像素视为"棋子"，根据它们在隐含棋盘格上的位置奇偶性决定移动方向，所有棋子同时滑动直到撞墙或撞到其他棋子。

Input structure：
- 背景为 Black。
- 网格尺寸为偶数 × 偶数。
- 网格中散布若干个不同颜色的单像素（颜色可重复），每个像素即一枚"棋子"。
- 没有其他前景结构。

Rule：
- 将网格视为隐含的棋盘格：行号+列号为偶数的格子属于"白格"，为奇数的属于"黑格"（行列号从 0 开始）。
- 白格上的棋子向右滑动；黑格上的棋子向下滑动。
- 所有棋子同时开始滑动，每一步所有棋子同时移动一格。
- 棋子遇到网格边界或下一格已被（静止或运动中的）其他棋子占据时停止。
- 一旦棋子停止便不再移动；已停止的棋子可以阻挡后续到达的棋子。
- 按步骤模拟直到所有棋子都停止，输出最终网格。

Key insight：网格上没有可见的棋盘格线，解题者必须通过观察不同位置像素的移动方向差异，归纳出隐含的奇偶棋盘格分区规则；移动方向完全由像素坐标的奇偶性决定，而非颜色或形状。
</new_puzzle>

<new_puzzle>
description：利用边缘色条作为"解密密钥"，对网格内部被加密过的彩色图案执行逐行颜色循环移位还原。

Input structure：
- 背景为 Black。
- 网格最上方一行是一条"密钥行"，由若干不同颜色像素组成，其余位置为 Black。密钥行中非 Black 像素从左到右定义了一个颜色序列 K。
- 网格其余行（从第二行起）包含一幅由多种颜色组成的图案，这些颜色全部属于密钥序列 K 中出现过的颜色集合。
- 图案中的 Black 像素代表背景，不参与解密。

Rule：
- 密钥行中的非 Black 像素按从左到右的顺序构成颜色环 K = [K₀, K₁, K₂, …, Kₘ₋₁]。
- 对于图案中第 r 行（从 0 开始编号，即密钥行下方第一行为 r=0）的每个非 Black 像素，若其当前颜色为 Kᵢ，则将其替换为 K[(i - r) mod m]，其中 m 是密钥序列长度。
- 密钥行本身在输出中被清除为全 Black。
- 所有原本为 Black 的像素保持不变。

Key insight：解题者需要先发现顶部色条是一个有序颜色环，再观察到图案中每一行的颜色都被"旋转"了与行号相关的偏移量——还原操作是反向旋转；这要求同时归纳出颜色环结构和行号驱动的移位规则。
</new_puzzle>

<new_puzzle>
description：在网格中找到由边框颜色编码的"源-目标"配对关系，将源框架内的图案按目标框架的尺寸进行拉伸或压缩后填入目标框架。

Input structure：
- 背景为 Black。
- 网格中有若干个一像素厚的矩形框架，每个框架用单一颜色绘制。
- 框架颜色成对出现：恰好有两个框架颜色相同，构成一组配对。
- 每对中，一个框架内部包含由其他颜色绘制的图案（"源框架"），另一个框架内部为空（全 Black，"目标框架"）。
- 源框架和目标框架尺寸可能不同。

Rule：
- 通过颜色匹配找到每对源-目标框架。
- 将源框架内部的图案按目标框架内部的尺寸进行最近邻缩放（整数倍放大或按行列独立缩放取最近邻采样）。
- 将缩放后的图案填入目标框架的内部区域。
- 源框架内部的图案保持不变。
- 所有框架轮廓保持不变。

Key insight：框架颜色不仅是装饰，还编码了配对关系——同色框架互为源和目标；解题者需要先发现颜色配对规则，再通过比较内部是否有图案来区分源和目标，最后理解图案需要按目标尺寸进行空间缩放。
</new_puzzle>

<new_puzzle>
description：每个彩色对象根据其内部被Grey线段穿过的方向进行镜像翻转，未被穿过的对象保持不变。

Input structure：
- 背景为 Black。
- 网格中有若干个由不同颜色绘制的小型实心对象（不规则形状，4-连通，面积 3-8 像素）。
- 若干条一像素宽的 Grey 直线段（水平或垂直）穿过网格，每条线段至少穿过一个彩色对象。
- 一条 Grey 线段可能穿过多个对象；一个对象最多被一条线段穿过。

Rule：
- 对每个被 Grey 水平线段穿过的彩色对象，以该线段所在行为对称轴，对该对象进行上下镜像翻转（对象的像素关于穿过它的 Grey 行做垂直翻转）。
- 对每个被 Grey 垂直线段穿过的彩色对象，以该线段所在列为对称轴，对该对象进行左右镜像翻转。
- 翻转后的对象覆盖原位置的像素（先清除原对象，再绘制翻转结果）。
- 未被任何 Grey 线段穿过的对象保持不变。
- 所有 Grey 线段像素在输出中被移除（变为 Black）。

Key insight：Grey 线段同时扮演两个角色：它标识了哪些对象需要变换，并且它自身的方向和位置定义了翻转的对称轴——解题者需要先理解线段方向决定翻转类型（水平线→上下翻，垂直线→左右翻），再发现线段在输出中消失。
</new_puzzle>
