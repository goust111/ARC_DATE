<new_puzzle>
根据嵌套环的层数对散落色块进行分组染色，再按组内面积排序拼接为水平色带。

Input structure：
- 背景为 black。网格中散布若干互不相邻的单色填充矩形（称为"色块"），颜色各异。
- 网格中还存在若干由同一颜色绘制的闭合矩形环（一像素宽的矩形框线）。这些环可以嵌套：一个小环可以被一个大环完全包含，大环又可以被更大的环包含，形成多级嵌套。
- 每个色块恰好被某一层嵌套深度的环包围（嵌套深度 = 该色块所在位置被多少个环包含）。

Rule：
- 统计每个色块所在位置的嵌套深度 d（即包围它的环的数量）。
- 将相同嵌套深度的色块归为一组。
- 在每组内部，按色块面积从大到小排序。
- 输出网格高度 = 最大组的成员数，宽度 = 所有组面积之和 + 组间一列 grey 分隔线。
- 从左到右按嵌套深度从小到大排列各组；每组内从左到右按面积从大到小排列，每个色块绘制为宽度等于其原始面积、高度为 1 的水平色带，颜色保持不变，各色带顶端对齐于输出网格的第 0 行，组间以一列 grey 像素分隔。

Key insight：
环的嵌套层数是分组的隐含依据——解题者需要先理解嵌套深度的概念，再发现组内的排序规则是面积，最后推断出色带化的输出编码方式。三层归纳缺一不可。
</new_puzzle>

<new_puzzle>
利用箭头形状指示的方向和箭头体内的色条序列，沿该方向依次在画布上铺设平行色带。

Input structure：
- 背景为 black 的大网格。
- 网格中有一个由 green 像素绘制的箭头轮廓（箭头形状：一个等腰三角形箭头 + 一个矩形尾巴，箭头指向上/下/左/右四个方向之一）。箭头内部被不同颜色的水平或垂直色条填充（色条方向与箭头指向垂直）。
- 箭头外部的画布区域为空白背景。

Rule：
- 识别箭头指向的方向 D。
- 提取箭头内部的色条序列（从箭尾到箭头方向依次读取每条色带的颜色）。
- 擦除箭头及其内部色条。
- 从箭头原始尖端位置开始，沿方向 D 向外依次铺设全宽（或全高）的平行色带，色带颜色按照提取的序列循环排列，直到铺满网格边界。每条色带宽度为 1 像素。

Key insight：
箭头同时编码了两层信息——其外形决定铺设方向，其内部的色条序列决定铺设的颜色周期。解题者需要先从箭头形状推断方向，再从箭头内部解码颜色模式，两步推理缺一不可。
</new_puzzle>

<new_puzzle>
根据封闭区域内标记像素的颜色查找同色图例条，用图例条的长度决定该区域的缩放因子，对区域内的图案进行整数倍放大。

Input structure：
- 背景为 black。
- 网格左侧有若干水平色条（图例），每条由单一颜色的连续像素组成，彼此间隔一行背景。每条图例的长度各不相同（2、3、4 等）。
- 网格右侧有若干由 grey 像素绘制的闭合矩形框（一像素宽边框）。每个框内部有一个小型多色图案，以及恰好一个单独的标记像素，其颜色与左侧某条图例颜色相同。

Rule：
- 对于每个 grey 框，找到框内标记像素的颜色 C。
- 在左侧图例中找到颜色为 C 的色条，取其长度 L。
- 将该框内的小型图案（不含标记像素和 grey 边框）以 L 倍整数缩放（每个像素变为 L×L 的同色方块）。
- 输出网格仅包含所有缩放后的图案，从上到下排列，图案之间以一行背景色分隔。

Key insight：
标记像素的颜色不是用来染色的——它是一个查找键，将封闭区域链接到图例条目，而图例条的长度才是真正的操作参数（缩放因子）。解题者必须先发现颜色匹配机制，再理解长度作为缩放因子的含义。
</new_puzzle>

<new_puzzle>
将碎片沿各自所在行/列的轨道滑动到与其颜色匹配的锚点框上，滑动过程中碎片穿越的路径被染上第三种颜色，碎片到达锚点后覆盖在锚点框之上。

Input structure：
- 背景为 black。
- 网格中有若干小型单色填充矩形（锚点框），每个锚点框颜色唯一，且在其正上方/正下方/正左方/正右方的某个位置（同一行或同一列上）有一个形状不同但颜色相同的碎片（也是单色填充连通体）。
- 每对同色的锚点框和碎片之间存在一条清晰的直线轨道（全部为背景色）。
- 网格中还有若干 red 像素散布于非轨道位置，作为干扰物。

Rule：
- 对每个碎片，找到与之颜色相同的锚点框。
- 碎片沿所在的行或列方向朝锚点框平移，直到碎片的边缘紧贴锚点框的边缘。
- 碎片滑动经过的路径像素（原来为背景色的位置）被染为 maroon。
- 碎片最终位置覆盖在锚点框上方（碎片像素优先显示）。
- Red 干扰像素保持不变。

Key insight：
解题者需要先通过颜色匹配识别每对碎片-锚点的配对关系，再推断出滑动方向是由两者的空间对齐关系（同行或同列）决定的，最后发现滑动路径留下的 maroon 轨迹是第三层视觉线索。配对、方向推断、轨迹生成三者构成完整的推理链。
</new_puzzle>

<new_puzzle>
将散落的单色块按照它们在隐含螺旋路径上的顺序收集，以收集顺序决定输出堆叠的层次。

Input structure：
- 背景为 black 的正方形网格（边长为奇数）。
- 网格中心有一个 grey 像素作为螺旋起点标记。
- 从中心开始，存在一条隐含的顺时针螺旋路径（先右、再下、再左、再上，每次转弯后步长递增），路径本身不可见。
- 沿该螺旋路径的某些位置上放置了不同颜色的单个像素（每种颜色恰好出现一次，共 3-6 种颜色）。

Rule：
- 从中心 grey 像素出发，沿顺时针螺旋顺序遍历网格。
- 按遍历时遇到各色像素的先后顺序，给每个颜色赋予排名 1、2、3……
- 输出为一个小型正方形网格：以排名最后的颜色填满整个方块，然后依排名倒序将每种颜色绘制为一个居中的更小正方形覆盖在上层，最内层（排名第 1）的颜色为 1×1 居中像素。相邻层的正方形边长差为 2（即 1×1、3×3、5×5……）。

Key insight：
螺旋遍历顺序是隐含的——网格上没有画出路径，解题者必须自行推断从中心出发的顺时针螺旋规则，并按照该顺序对颜色排序。排序结果再编码为嵌套同心正方形，两层推理各自独立且非显然。
</new_puzzle>

<new_puzzle>
识别每个封闭区域中"缺口"的朝向，以缺口朝向为键在颜色映射表中查找目标色，用目标色重新填充该区域。

Input structure：
- 背景为 black。
- 网格顶部有一行颜色映射图例：四个小方块从左到右分别为 red、blue、green、yellow，分别对应缺口朝向上、右、下、左（图例的排列顺序即编码了方向到颜色的映射）。
- 网格下方有若干由 grey 像素绘制的矩形框（一像素宽边框），每个框的某一条边上恰好有一个 1 像素宽的缺口（即该边上有一个像素被擦除为背景色）。
- 每个框内部填充有某种非 grey、非背景的统一颜色（但该颜色并非最终颜色）。

Rule：
- 对每个 grey 框，找到其缺口所在的边（上/右/下/左）。
- 在图例中查找该方向对应的颜色 C。
- 将框内部的所有填充像素重新染为颜色 C。
- Grey 边框和缺口保持不变。

Key insight：
图例条目的排列位置隐含了方向编码（从左到右 = 上/右/下/左），解题者必须先破解图例的方向映射规则，然后才能正确地为每个框选择重染颜色。框原本的填充色是干扰项，不参与规则。
</new_puzzle>

<new_puzzle>
对网格中由不同颜色框线围成的嵌套矩形区域执行逐层剥离，每剥一层就对内部图案施加一次由该层框线颜色编码的变换（旋转或翻转），最终输出最内层图案经过所有变换后的结果。

Input structure：
- 背景为 black。
- 网格中央有一个小型多色图案（核心图案），被多层不同颜色的矩形框线嵌套包围（每层框线为一像素宽，颜色各不相同）。
- 可能出现的框线颜色及其编码的变换：red = 顺时针旋转 90°，blue = 逆时针旋转 90°，green = 水平翻转，yellow = 垂直翻转。
- 框线从最外层到最内层依次排列，各层之间可以紧贴也可以有一像素间距。

Rule：
- 从最外层框线开始，向内逐层识别每层的颜色。
- 记录从外到内的颜色序列，得到变换序列 T1, T2, …, Tn。
- 提取最内层的核心图案。
- 依次对核心图案施加 T1, T2, …, Tn 变换（即外层先施加）。
- 输出变换后的核心图案（不含任何框线）。

Key insight：
每层框线的颜色不是装饰——它是一个变换指令，且变换的施加顺序由嵌套层次决定（外层先于内层）。解题者需要先理解颜色到变换的映射，再正确识别嵌套顺序，最后按序复合变换。三层认知步骤环环相扣。
</new_puzzle>

<new_puzzle>
在两组对象之间建立配对关系：一组是带方向标记的"发射器"，另一组是带有孔洞的"靶板"；发射器沿标记方向射出与其孔洞数等宽的射线，射线颜色由靶板内部填充色决定。

Input structure：
- 背景为 black。
- 网格中有若干 orange 填充的小型 L 形或 T 形对象（发射器），每个发射器的某一端有一个 azure 像素标记，指示射出方向（标记相对于发射器主体的位置决定方向：标记在上方则向上射出，在右方则向右射出，依此类推）。
- 网格中另有若干 grey 边框的矩形靶板，靶板内部填充某种颜色（每个靶板颜色可能不同），且靶板的面朝发射器一侧的边框上有若干等间距的 1 像素孔洞。
- 每个发射器与恰好一个靶板配对：发射器的像素总数等于对应靶板上的孔洞数。

Rule：
- 通过计数匹配（发射器像素数 = 靶板孔洞数）确定每对发射器-靶板的配对。
- 从发射器的 azure 标记位置出发，沿标记指示的方向射出平行射线束，射线数量等于靶板孔洞数，射线之间间距为 1 像素。
- 射线颜色为配对靶板的内部填充色。
- 射线从发射器出发延伸到网格边界，穿过靶板孔洞时不中断。
- 原有的发射器和靶板保持不变。

Key insight：
配对机制基于"发射器像素数 = 靶板孔洞数"的计数匹配，而非颜色或空间邻近。射线的方向来自发射器的标记位置，射线的颜色来自靶板的内部填充色——三个属性分别由三个不同的视觉线索决定，解题者必须逐一破解。
</new_puzzle>
