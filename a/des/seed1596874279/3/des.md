description：根据每个封闭区域内部"钥匙色"像素的数量，从色带图例中查找对应颜色，再用该颜色填充整个封闭区域。

Input structure：
- 背景为 black。
- 网格中有若干由 grey 像素围成的不规则封闭区域（围墙厚度为 1 像素，围墙完全闭合，无缺口）。
- 每个封闭区域内部散布着少量"钥匙色"像素（同一区域内钥匙色只有一种颜色，但不同区域可能颜色不同，也可能相同）。钥匙色像素的数量在 1 到 5 之间。
- 网格最上方有一条水平色带图例，由 5 个连续的单像素色块组成，从左到右编号 1-5，每个色块颜色各不相同（均非 black、grey 和钥匙色）。

Rule：
- 对每个封闭区域，数出其内部钥匙色像素的数量 N（1 ≤ N ≤ 5）。
- 在色带图例中取第 N 个位置的颜色 C。
- 将该封闭区域内部所有 black 像素和钥匙色像素全部替换为颜色 C（grey 围墙不变）。
- 色带图例行本身保持不变。

Key insight：钥匙色像素的数量是查表索引，色带图例是颜色查找表；解题者需要先发现"计数→查表"这一两层机制，而非简单的颜色匹配或替换。
</new_puzzle>

Input structure：
- 背景为 black。
- 一条 maroon 水平分隔线将网格分为上下两半。

- 每个碎片的外轮廓颜色在整个网格中恰好出现两次——上半部分一个、下半部分一个，形成配对关系。

Rule：
- 通过外轮廓颜色找到上下配对的碎片。

- 将所有拼合后的矩形按轮廓颜色在输入中从左到右的出现顺序，在输出网格中从左到右依次排列，矩形之间间隔 1 列 black，所有矩形顶边对齐在第 0 行。
- 输出网格大小恰好容纳所有矩形及间隔。

Key insight：外轮廓颜色既是配对线索又是输出的组成部分；碎片的互补关系需要解题者在空间上推断如何拼合——这不是简单的平移叠加，而是要发现两个不规则形状如何填满同一个矩形。

description：每个彩色对象沿其内部"缺口方向"滑动，滑动距离等于与该对象同色的孤立计数点的数目。

Input structure：
- 背景为 black。
- 网格中有若干个由单一非 black 颜色填充的矩形对象（至少 2×2），每个矩形在恰好一条边上有一个 1 像素深的缺口（即该边上缺少一个像素，形成凹陷）。不同矩形颜色各不相同。
- 在远离所有矩形的空白区域中，散布着一些孤立的单像素点，每个点的颜色与某个矩形的颜色相同。同色的孤立点数量在 1 到 4 之间。

Rule：
- 缺口的位置指示滑动方向：缺口在上边→向上滑动，缺口在下边→向下滑动，缺口在左边→向左滑动，缺口在右边→向右滑动。
- 滑动距离等于与该矩形同色的孤立计数点的数目（单位为像素）。
- 滑动后，矩形原来占据的位置清除为 black，矩形（含缺口形状）出现在新位置。
- 所有孤立计数点在输出中被清除为 black。
- 矩形滑动后不会越出网格边界，也不会与其他矩形重叠。

Key insight：解题者必须同时发现两个独立编码——缺口编码方向、同色孤立点编码距离——并将二者组合才能确定每个对象的完整运动。单独观察任何一个编码都无法得出完整规则。
</new_puzzle>

Input structure：
- 网格右侧有一个 K×K 的颜色图例矩阵（K 不超过 4），由 grey 边框围成，内部每个格子为一个独立颜色，图例矩阵的行和列分别用不同颜色标注在图例外侧：行标注在左侧（每行一个彩色像素），列标注在上方（每列一个彩色像素）。
- 网格左侧是主画布，背景为 black。主画布中有若干嵌套的矩形环，每个矩形环由 1 像素厚的彩色边框构成。最外层矩形的边框色是某种颜色 A，其内部可能包含更小的矩形，边框色为 B，B 内部可能再嵌套 C，以此类推。嵌套深度最多为 K 层。
- 每个矩形环的边框颜色一定出现在图例的列标注中。

- 对主画布中每个矩形环围成的区域（不包括边框本身），计算它的嵌套深度 D（最外层为 1，其内部为 2，以此类推）。

- 边框本身和图例区域保持不变。

Key insight：解题者需要发现三层结构——识别嵌套深度、将边框颜色映射到图例列、将深度映射到图例行——然后在二维图例中交叉查表得到填充色。任何单一维度都不足以确定答案。
</new_puzzle>

<new_puzzle>
description：每条彩色路径沿自身方向生长，生长长度由路径穿过的"计数门"中的像素数决定，遇到墙壁则折射转向。

Input structure：
- 背景为 black，网格中有若干 grey 色的水平和垂直墙壁段（各为连续的 grey 像素行或列段，厚度 1 像素）。
- 墙壁上某些位置有 1 像素宽的缺口（门），每个门内有一个非 black、非 grey 的彩色像素，称为"计数门"。同一面墙上可以有多个门。
- 网格边缘处有若干彩色"种子"像素（位于第 0 行、最后一行、第 0 列或最后一列），每个种子的颜色与某些计数门的颜色不同，种子颜色在整个网格中唯一。
- 每个种子像素旁边（朝网格内部方向）紧邻一个同色的像素，两个像素构成一个长度为 2 的线段，指示初始生长方向（水平或垂直）。

Rule：
- 从每个种子出发，沿其初始方向生长，每到达一面墙壁时：
  a. 找到该墙上最近的门。
  b. 路径穿过该门（门内的彩色像素保留），并在门的另一侧继续。
  c. 穿过门后，路径转向 90 度（水平变垂直或垂直变水平），转向方向为使路径朝向下一面最近墙壁的方向。
  d. 穿门后继续生长的长度等于刚穿过的门内彩色像素的数量（门内只有 1 个像素时生长 1 格，但如果门宽为 3 且内有 2 个彩色像素则生长 2 格）。
- 路径用种子颜色绘制。生长在到达指定长度、碰到网格边界或碰到另一条路径时停止。
- 所有墙壁和门保持不变。

Key insight：解题者需要依次发现种子的方向编码、墙壁与门的折射机制、以及门内像素数控制下一段长度的计数机制——三层规则环环相扣，缺一不可。
</new_puzzle>

<new_puzzle>
description：将散落的彩色碎片按颜色分组后，每组碎片按面积从大到小堆叠到该颜色对应的"停靠框"内，堆叠方向由停靠框的开口方向决定。

Input structure：
- 背景为 black。
- 网格中有若干个由 1 像素厚边框围成的三面封闭、一面开口的 U 形"停靠框"，每个停靠框的边框颜色不同。停靠框内部初始全为 black。开口方向可以是上、下、左、右之一。
- 网格的其他区域散布着若干个不规则形状的彩色碎片（4-连通），每个碎片的颜色与某个停靠框的边框颜色相同。同一颜色可能有多个碎片。碎片之间不接触，碎片也不接触任何停靠框。

Rule：
- 将同色碎片归为一组，每组对应一个同色停靠框。
- 在每组中，按碎片面积（像素数）从大到小排序。
- 将碎片依次放入停靠框内部：第一个碎片紧贴停靠框的封闭底部（即与开口相对的那一侧内壁），保持碎片形状不变但水平或垂直居中于框内；第二个碎片紧接在第一个碎片之后（向开口方向偏移，使其紧贴第一个碎片），以此类推。
- 碎片放入时，其包围盒的"宽度"（与堆叠方向垂直的维度）不超过停靠框内部宽度，碎片在该维度上居中对齐（若无法完全居中则偏左或偏上）。
- 原始散落位置的碎片被清除为 black。

Key insight：解题者需要发现三个独立规则——颜色配对确定归属、面积排序确定顺序、开口方向确定堆叠朝向——每一层都需要从样例中独立归纳。
</new_puzzle>

<new_puzzle>
description：网格中的每个"源图章"通过隐藏的"传送通道"将自己的图案复制到对应的"目标框"中，传送通道由两端口的颜色和朝向共同编码。

Input structure：
- 背景为 black。
- 网格中有若干个小型彩色图案（3×3 以内），每个图案四周被 1 像素宽的单色边框包围，构成"源图章"。不同源图章的边框颜色可能不同。
- 每个源图章的某一条边框外侧中央紧贴一个 red 像素，称为"出口端"，指示该图章向外连接的方向。
- 网格中另有若干个大小相同的空白框（内部全为 black，被 1 像素宽的单色边框包围），称为"目标框"。每个目标框也有一个 red 像素紧贴在某条边框外侧中央，称为"入口端"。
- 配对规则：源图章与目标框配对当且仅当二者的边框颜色相同，且出口端与入口端的朝向相反（如源的出口朝右，则目标的入口朝左）。每个源恰好有一个配对目标。

Rule：
- 将每个源图章内部的图案复制到其配对目标框的内部。
- 复制时，图案需要根据出口-入口的方向关系进行旋转：如果出口朝右、入口朝左（即水平传送），图案水平翻转；如果出口朝下、入口朝上（即垂直传送），图案垂直翻转；如果出口朝右、入口朝上（即 L 形传送），图案顺时针旋转 90 度；以此类推，旋转角度使图案的"出口侧"变为"入口侧"。
- 源图章本身（含边框和出口端 red 像素）保持不变。

Key insight：解题者需要先通过边框颜色发现配对关系，再通过 red 端口的位置发现方向编码，最后推断出方向差异决定图案变换方式——三层推理中，最隐蔽的是"方向差异→旋转/翻转规则"的映射。
</new_puzzle>
