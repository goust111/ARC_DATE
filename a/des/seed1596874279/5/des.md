description：根据封闭区域内部的孔洞数量，在颜色图例中查找对应颜色，用该颜色重绘封闭区域的边框。

Input structure：
- 背景为一种主色（如 black）。
- 网格上方有一行颜色图例条：从左到右排列若干个小色块，第 1 个色块代表"1 个孔洞"，第 2 个色块代表"2 个孔洞"，依此类推。每个图例色块为 1×1 像素，色块之间用背景色间隔 1 列。
- 网格下方散布着若干用 grey 绘制的一像素厚封闭矩形框。每个矩形框内部区域中存在若干个单像素的背景色孔洞（即矩形框内除孔洞外其余内部像素均为 grey 填充）。不同矩形框的孔洞数量不同，且孔洞数量恰好能在图例中找到对应。

Rule：
- 保持图例条不变。
- 对每个封闭矩形框，数出其内部的背景色孔洞数量 N。
- 在图例条中取第 N 个色块的颜色 C。
- 将该矩形框的所有边框像素从 grey 重绘为颜色 C，矩形框内部的填充像素也改为 C，孔洞仍保留为背景色。

Key insight：
孔洞数量不是装饰性特征，而是图例的索引键；解题者需要先建立"孔洞计数 → 图例位置"的映射，再用映射结果执行重新着色——两步都需要非平凡的归纳。
</new_puzzle>

<new_puzzle>
description：将散落的彩色碎片按颜色配对后，用两块碎片的形状交集区域生成输出图案，并按配对颜色的色相排序排列。

Input structure：
- 背景为一种主色（如 black）。
- 网格中散布着偶数个单色矩形碎片，每种非背景颜色恰好出现两次（两个碎片）。
- 同色的两个碎片尺寸可能不同，但其中一个的宽度和高度分别小于等于另一个的宽度和高度（即小碎片可以在左上对齐后完全落入大碎片范围内）。

Rule：
- 将同色的两个碎片配对。对每一对，将小碎片左上角对齐到大碎片左上角，取两者重叠区域（即小碎片的完整区域）作为输出图案块。
- 输出图案块的颜色保持原色不变。
- 将所有配对结果按碎片面积差（大碎片面积减小碎片面积）从小到大排列，从左到右水平排列在输出网格中，相邻图案块之间用 1 列背景色间隔，所有图案块底部对齐。
- 输出网格的高度取所有输出图案块的最大高度，宽度为所有图案块宽度之和加上间隔列数。

Key insight：
同色碎片的配对是第一层推理（颜色匹配）；取交集区域确定输出形状是第二层推理（几何对齐）；按面积差排序是第三层推理（排序键的发现）。解题者不能简单复制碎片，而是必须发现"小套大取交集"的几何操作。
</new_puzzle>

description：用网格边缘的彩色种子像素沿行或列方向生长色带，色带在遇到内部障碍物时反弹到垂直方向继续生长，最终形成 L 形路径。

Input structure：
- 背景为一种主色（如 black）。
- 网格的四条边上各有若干单像素的彩色种子，每个种子颜色唯一。
- 网格内部散布着若干 grey 的单像素障碍物。
- 每个种子位于网格边缘的某一行或某一列上。

Rule：
- 从每个种子出发，沿其所在边的法线方向（即向网格内部）逐像素生长一条色带，颜色与种子相同。
- 色带在遇到障碍物前一格停止水平/垂直生长。
- 停止后，色带从停止点向该种子所在边的边缘方向的垂直分量转弯：若种子在上/下边，转弯后水平生长，方向朝向种子在该行中更近的左右网格边缘；若种子在左/右边，转弯后垂直生长，方向朝向种子在该列中更近的上下网格边缘。
- 转弯后的色带继续生长至碰到网格边缘或另一条已有色带时停止。
- 障碍物像素保持 grey 不变。

Key insight：
种子的位置决定了初始生长方向（第一层），障碍物的位置决定了转弯点（第二层），转弯方向由种子相对于网格中心的位置隐式编码（第三层）。解题者需要同时理解三个层面的规则才能完整预测 L 形路径。
</new_puzzle>

description：在网格中找到被框架包围的"画布"区域，根据画布外部标注像素的行列位置在画布内绘制对应的十字交叉标记。

Input structure：
- 背景为一种主色（如 black）。
- 网格中有一个由 blue 像素绘制的一像素厚矩形框架，框架内部全部为背景色，构成"画布"区域。
- 框架外部、与框架相邻的位置上，散布着若干彩色单像素标注点。这些标注点只出现在框架的上边或左边的外侧紧邻行/列上。
- 上边外侧的标注点标示列坐标（相对于画布），左边外侧的标注点标示行坐标（相对于画布）。
- 同一对（行标注色、列标注色）中，若行标注和列标注颜色相同，则它们构成一个配对。

Rule：
- 保持框架和框架外部不变。
- 对每一对同色的行标注和列标注，在画布内部的对应行列交叉点上绘制一个十字形标记（中心 1 像素 + 上下左右各延伸 1 像素，共 5 像素），颜色与标注相同。

- 不同颜色的十字形互不重叠（输入保证不会冲突）。

Key insight：
解题者首先要识别框架并区分画布内外（空间分割），然后理解外部标注点是行列坐标的编码方式（坐标解码），最后通过颜色匹配将行坐标与列坐标配对来确定十字形位置（颜色配对定位）。三层推理缺一不可。
</new_puzzle>

<new_puzzle>
description：根据各连通前景对象的像素面积对它们进行分级，面积最大的对象保持原色，面积居中的对象重绘为其原色与背景色的"中间层"颜色，面积最小的对象被擦除为背景色。

Input structure：
- 背景为一种主色（如 black）。
- 网格中有若干个 4-连通的单色前景对象，每个对象为一种非背景颜色。同一颜色可能出现在多个不同对象中。
- 网格的右侧有一列"色阶图例"：从上到下排列 3 个像素，分别为 3 种不同颜色。第 1 个（最上方）代表"保留原色"，第 2 个代表"替换色"（中间层颜色），第 3 个代表"擦除为背景"。

Rule：
- 计算每个 4-连通前景对象的像素面积。
- 将所有对象按面积排序，分为三组：面积最大的一组（面积相同的对象归为同一组）、面积最小的一组、以及介于两者之间的中间组。
- 面积最大组的对象保留原色不变。
- 中间组的对象全部重绘为色阶图例中第 2 个颜色。
- 面积最小组的对象全部擦除为背景色。
- 色阶图例本身从输出中移除（替换为背景色）。

Key insight：
色阶图例不是简单的颜色映射表，而是一个"面积等级→处理方式"的三级指令；解题者需要先理解图例的三级含义（保留/替换/擦除），再通过对象面积分组来应用这三级指令。图例的位置和编码方式构成第一层推理，面积分组和分级应用构成第二层推理。
</new_puzzle>

description：将输入网格中散布的多个同色"路径片段"首尾相接拼成一条完整路径，然后将路径所围成的封闭区域用指定颜色填充。

Input structure：
- 背景为一种主色（如 black）。
- 网格中有若干段由同一种前景色（如 green）绘制的一像素宽折线片段，每段片段是连续的像素序列（水平或垂直方向的直线段组合）。
- 每段折线片段恰好有两个端点（度为 1 的像素），且每个端点与恰好一个其他片段的某个端点相邻（8-连通意义上间隔恰好 1 个背景像素）。
- 网格中有一个单独的彩色像素（非前景色、非背景色），位于路径片段围成的区域内部，代表填充色。

Rule：
- 将所有折线片段之间的 1 像素间隙用前景色连接，使所有片段拼合成一条封闭环路。
- 对封闭环路内部进行洪水填充，填充颜色为网格中那个单独彩色像素的颜色。
- 填充后，移除那个单独的彩色像素标记（若它被填充覆盖则自然被填充色取代）。
- 环路本身的前景色像素保持不变。

Key insight：
解题者首先需要识别出片段的端点配对关系并完成"拼图"（片段连接），然后识别出内部标记像素的角色是填充色指定器而非装饰（语义理解），最后执行封闭区域的洪水填充（空间操作）。片段拼接的拓扑推理和填充色的语义推理构成两层独立的归纳挑战。
</new_puzzle>

<new_puzzle>
description：网格被分为若干个由边框线分隔的小房间，每个房间内有一个彩色"灯泡"像素，灯泡的颜色决定该房间墙壁上"窗户"（缺口）的开关状态。

Input structure：
- 背景为一种主色（如 black）。
- 网格由 grey 线条划分成若干个矩形"房间"。grey 线条构成完整的网格状分隔线（类似九宫格或更多格子）。
- 每个房间的 grey 边框上有若干个 1 像素的背景色缺口（"窗户"），这些缺口在输入中已经存在。
- 每个房间内部恰好有一个单像素的彩色"灯泡"（非 grey、非背景色）。
- 网格顶部有一行图例：交替排列彩色像素和相邻的 1 像素标记（maroon 代表"关闭窗户"，azure 代表"保持窗户打开"）。

Rule：
- 读取图例：每种灯泡颜色对应一个操作——关闭（maroon 标记）或保持打开（azure 标记）。
- 对每个房间，查看其灯泡颜色在图例中的对应操作。
- 若操作为"关闭"：将该房间边框上所有背景色缺口用 grey 填补，使房间完全封闭。
- 若操作为"保持打开"：该房间的缺口保持不变。
- 灯泡像素本身保留不变，图例行从输出中移除。

Key insight：
解题者需要先解读图例的编码方式（颜色→操作的映射），然后将映射应用到每个房间的灯泡上以决定该房间的窗户状态。图例解码是第一层推理，灯泡颜色驱动房间状态变更是第二层推理。看似简单的开/关操作，难点在于发现图例的编码规则和灯泡的控制语义。
</new_puzzle>
