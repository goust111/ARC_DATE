- `description`：根据彩色种子像素的颜色在灰色管道网络中注入染料，染料沿管道流动直到遇到分叉口，在分叉口处按管道宽度比例分配颜色。

- `Input structure`：
  - 背景为 black。
  - 灰色（grey）像素构成若干条一像素宽的管道路径，管道在网格中形成树状分支网络（无环路）。每条管道是水平或垂直的直线段，在交叉点处以 T 形或十字形分叉。
  - 管道网络的若干叶端（死胡同末端）各放置一个彩色种子像素（如 red、blue、green 等），每个叶端最多一个种子，颜色互不相同。
  - 管道网络中有若干其他叶端没有种子像素，这些是"出口端"。

- `Rule`：
  - 每个种子像素向管道内部注入自己的颜色。颜色沿灰色管道像素逐格传播，将经过的灰色像素重新着色为种子颜色。
  - 当两种不同颜色的染料在某个管道像素处相遇（即从不同方向到达同一灰色像素的路径长度相等），该像素保持灰色不变，形成"分界线"，染料各自停止。
  - 当某种染料率先到达一个灰色像素（路径步数更少），该像素着为该染料颜色，另一种染料到达时发现已被占据则停止。
  - 路径长度按沿管道的像素步数计算（即沿管道走的格数）。
  - 没有种子的出口端按上述规则自然被最近的种子颜色覆盖。

- `Key insight`：解题者需要先识别管道网络的拓扑结构（树形分支），然后从每个种子同时出发沿管道计步，判断每段管道被哪种颜色"先到先得"地占据。关键在于理解染料是沿管道路径传播而非空间直线距离，分界线出现在等距交汇处。
</new_puzzle>

- `description`：将散落的彩色碎片按形状互补配对，然后把每对碎片拼合成一个完整矩形，拼合后的矩形放置在网格中由同色锚点标记指定的位置。

- `Input structure`：
  - 背景为 black。
  - 网格中散布着若干彩色小精灵（sprite），每个精灵由单一非背景色构成，形状不规则但面积较小（3-6 像素）。
  - 这些精灵可以两两配对：同色的两个精灵拼合后（其中一个需要平移但不旋转）恰好填满一个实心矩形。每种颜色恰好有两个精灵。
  - 网格边缘附近有若干单像素的 maroon 锚点，每个锚点旁边紧邻一个与某种精灵颜色相同的单像素色标。锚点的数量等于颜色对数。

- `Rule`：
  - 找到每种颜色的两个精灵，确定它们拼合成矩形的唯一平移方式：将其中一个精灵平移，使两者的并集形成一个无间隙、无重叠的实心矩形。
  - 通过锚点旁的色标确定该颜色对应的目标位置：以 maroon 锚点像素为拼合矩形的左上角。
  - 清除所有精灵原始位置的像素，在锚点指定位置绘制拼合后的完整矩形（保留原色）。
  - maroon 锚点和色标像素在输出中移除（变为背景色）。

- `Key insight`：解题者首先需要发现同色碎片之间的形状互补关系（两块拼成矩形），然后识别 maroon 锚点 + 色标的定位机制。两层推理缺一不可：仅靠颜色配对无法确定放置位置，仅靠锚点无法确定矩形的形状和大小。
</new_puzzle>

- `Input structure`：
  - 背景为 black。
  - 网格中有若干由单一前景色像素构成的矩形空心边框（"房间"），边框厚度为一像素。不同房间可能使用不同颜色。

  - 对每个房间，确定其窗户所在的边（上、下、左、右）。
  - 从窗户缺口向外延伸（沿窗户朝向的方向），找到该方向上视线内遇到的第一个灰色符号。

  - 原始灰色符号保留不变。窗户缺口在输出中被房间边框颜色填补（关闭窗户）。

- `Key insight`：解题的第一层是识别每个房间的缺口朝向（需要检查边框的四条边找到中断处），第二层是理解缺口方向即为"视线方向"从而确定要引入的符号，第三层是符号在房间内的放置规则（居中 + 变色 + 封闭缺口）。缺口既是方向指示器又是需要被修补的结构缺陷。

  - 网格中有若干大小不同的单色实心矩形区域（"色块"），颜色各不相同（如 red、blue、green、yellow 等），色块之间不重叠。
  - 每个色块内部嵌有一个由 black 像素构成的小图案（"印章"），即色块内部某些像素被挖空为背景色，形成一个可识别的连通形状。印章图案各不相同。
  - 网格中还有一个由 grey 像素构成的实心矩形区域（"画布"），大小足以容纳任何单个印章，画布内部初始全为灰色。

- `Rule`：
  - 对每个彩色色块，提取其内部的黑色印章图案（相对于色块左上角的相对坐标）。
  - 按色块面积从大到小排序。

  - 后盖印的印章覆盖先盖印的——即面积最小的色块的印章图案在最顶层。
  - 画布中未被任何印章覆盖的像素保持灰色。原始彩色色块区域在输出中全部清除为背景色。

- `Key insight`：解题者需要完成三层推理：（1）识别每个色块内的"负空间"印章图案并提取其形状；（2）发现色块面积决定了盖印顺序（大的先印、小的后印，因此小的在上层）；（3）理解多个印章在画布上的叠加覆盖机制。面积排序是隐蔽的——解题者需要通过对比多个训练样例中不同面积色块的印章在画布上的遮挡关系才能归纳出排序规则。

<new_puzzle>
- `description`：网格被若干水平色带分割为条状区域，每个区域内的散点对象需要沿色带指定的方向滑动到区域边界，方向由色带颜色在色带自身中的渐变朝向决定。

- `Input structure`：
  - 背景为 black。
  - 网格被若干条水平的双像素高彩色带（"色带"）分隔为若干水平条状区域。色带横贯网格全宽。
  - 每条色带使用两种颜色：色带的上行像素为一种颜色，下行像素为另一种颜色。左半段和右半段的上下颜色互换（即色带左半部分上行为 red 下行为 blue，右半部分上行为 blue 下行为 red）。颜色切换点在色带的水平中点处。
  - 每个条状区域（两条色带之间的空间）内散布着若干单像素的 grey 前景点。

- `Rule`：
  - 对每条色带，观察其左半段的上行颜色。这个颜色在色带的视觉渐变方向编码了该色带上方区域内对象的移动方向：如果上行颜色比下行颜色在以下色序中靠前，则方向为向左；否则为向右。色序为：red < blue < green < yellow < grey < magenta < orange < azure < maroon。
  - 每个条状区域使用其**下方**色带所编码的方向。最底部区域（下方无色带）使用其上方色带的**相反方向**。
  - 区域内所有 grey 点沿指定方向水平滑动，直到碰到网格边缘或另一个已停止的 grey 点为止（堆叠）。
  - 色带本身在输出中保持不变。

- `Key insight`：第一层推理是识别色带的结构——双行、左右颜色互换的对称模式；第二层是破解色带颜色与方向的编码关系——需要比较上下行颜色的某种序关系；第三层是确定每个区域应参照哪条色带（下方色带优先，最底区域取反）。色带既是区域分隔符又是方向指令编码器，双重角色增加了隐蔽性。
</new_puzzle>

<new_puzzle>
- `description`：将网格中每个 L 形三格标记解读为"折叠指令"，沿标记指示的折叠线将相邻的彩色矩形条翻折叠加，重叠处颜色混合为第三种颜色。

- `Input structure`：
  - 背景为 black。
  - 网格中有若干彩色矩形条（宽度为一像素的水平或垂直直线段），每条使用单一颜色（如 red、blue、green 等）。
  - 每条矩形条的某一端附近有一个由 maroon 像素构成的 L 形三像素标记。L 形标记由两个像素组成"臂"、一个像素为"肘"，整体占据一个 2×2 区域的三个格子。
  - L 形标记的开口方向（缺失像素的角）指示折叠方向：开口朝上表示该条向上折叠，开口朝下向下折，开口朝左向左折，开口朝右向右折。
  - L 形标记的肘部像素与矩形条的端点相邻。

- `Rule`：
  - 对每条矩形条，根据其 L 形标记的开口方向，确定折叠轴线：折叠轴为矩形条上离标记最近的端点处的垂直于折叠方向的线。
  - 将矩形条沿折叠轴翻折（镜像）：条的远端部分翻转到近端部分之上，形成双层重叠。
  - 重叠区域中，仅保留翻折后覆盖上来的像素（即远端部分翻折后的位置），颜色不变。未被翻折覆盖的近端部分也保留原色。
  - 如果翻折后的像素落在另一条不同颜色的矩形条上，该位置颜色变为 yellow（表示两色混合）。
  - 清除 maroon 标记像素和矩形条翻折前在原始位置超出折叠区域的部分。

- `Key insight`：解题者需要先读懂 L 形标记的"开口方向"语义（第一层），然后理解折叠的几何操作——端点为轴、远端翻转到近端上方（第二层），最后发现跨条重叠时的颜色混合规则（第三层）。L 形标记同时编码了方向和折叠轴位置，是一种紧凑的几何指令。
</new_puzzle>

- `description`：网格中散布着大小不同的同色实心方块和同数量的空心方框；根据面积匹配将每个实心方块缩小后嵌入对应空心方框的内部，嵌入位置由方框缺角决定。

- `Input structure`：
  - 背景为 black。
  - 网格中有 N 个由 blue 像素构成的实心正方形（大小各不相同，如 2×2、3×3、4×4 等）。
  - 同时有 N 个由 red 像素构成的空心正方形边框（边框厚度一像素，内部为背景色）。这些边框的边长也各不相同。
  - 每个红色边框恰好在四个角之一缺少一个像素（即该角位置为背景色而非红色）。不同边框的缺角位置可能不同（左上、右上、左下、右下）。
  - 每个红色边框的内部空间（去掉边框后的区域）恰好能容纳某个蓝色实心方块并在方块与边框之间留有空隙。具体配对方式为：内部空间边长 = 蓝色方块边长 + 2，上下左右各留一行/列空隙。

- `Rule`：
  - 按面积配对：每个蓝色方块与内部空间恰好能容纳它的红色边框配对（蓝色方块边长 = 红色边框内部边长 - 2）。
  - 将蓝色方块放入配对的红色边框内部。放置位置取决于缺角位置：蓝色方块被推向缺角的对角方向。即如果缺角在左上，蓝色方块贴靠边框内部的右下角；缺角在右上，蓝色方块贴靠左下角；以此类推。
  - 清除蓝色方块原始位置的像素。红色边框保持不变（包括缺角）。

- `Key insight`：第一层推理是发现实心方块和空心边框的面积/尺寸配对关系；第二层是识别边框缺角并理解缺角与方块放置位置之间的"对角排斥"规则——缺角像是一个推力来源，将方块推向对角。两层推理互相独立且都非显然。
</new_puzzle>
