<new_puzzle>
根据每个前景对象内部的"缺失行/列"方向，从对象的对应边界向外发射同色射线，射线长度等于对象内部孔洞的像素数量。

Input structure
- 背景为 black。网格中散落若干单色 4-连通前景对象，每个对象的包围盒呈矩形但内部有一条或多条行或列的像素被移除（形成水平或垂直的内部缺口）。
- 每个对象的内部缺口方向唯一确定（全是水平缺口或全是垂直缺口），且缺口数量不超过 5。
- 不同对象的颜色互不相同。

Rule
- 对每个前景对象：
  1. 检测其内部缺口方向——若缺口是水平的（某行像素缺失），则射线向上或向下发射；若缺口是垂直的（某列像素缺失），则射线向左或向右发射。
  2. 射线发射的方向由缺口在对象内部的偏置决定：缺口更靠近对象的上边界（或左边界），射线从对象的下边界（或右边界）向外发射，反之亦然。
  3. 射线的长度等于该对象内所有缺口像素的总数。
  4. 射线的宽度为 1 像素，水平位置（或垂直位置）与对象包围盒的中心列（或中心行）对齐。
  5. 射线颜色与对象颜色相同。
- 原有的所有前景对象保持不变。

Key insight
- 缺口的方向决定射线的发射轴，缺口在对象内的偏置决定发射朝向，缺口像素总数决定射线长度——三个独立属性分别编码射线的三个参数。
</new_puzzle>

<new_puzzle>
将散落在网格中的多个小型"钥匙"图案与大型"锁"框架上的凹槽进行形状匹配，匹配后用钥匙的颜色填充锁上对应凹槽内侧一圈的边框环。

Input structure
- 背景为 black。网格中央有一个大型 grey 矩形框架（"锁"），框架边缘上有若干向内凹陷的缺口（"凹槽"），每个凹槽形状各异，深度为 2-4 像素。
- 框架外部散落若干小型单色图案（"钥匙"），每个钥匙的外轮廓形状恰好与某个凹槽的形状互补（即钥匙能严丝合缝地插入凹槽）。
- 钥匙的颜色各不相同（red、blue、green、yellow 等），且每个钥匙唯一对应一个凹槽。

Rule
- 对每个凹槽：
  1. 提取凹槽的形状轮廓（允许旋转 0°/90°/180°/270° 进行匹配）。
  2. 在外部钥匙中找到形状互补的那一个（钥匙旋转后能填满凹槽）。
  3. 将凹槽内的像素用 grey 填满（即把凹槽补完，恢复矩形框架的完整性）。
  4. 在凹槽所在的那一段框架边缘的内侧，沿框架内壁绘制一条与凹槽等宽的色带，色带颜色取自匹配钥匙的颜色，色带长度等于凹槽深度。
- 外部的钥匙图案从网格中删除。

Key insight
- 解题需要两步非平凡推理：先通过形状互补匹配找到钥匙-凹槽配对关系，再理解颜色的转移方式——不是直接将钥匙贴入凹槽，而是将颜色"投射"到框架内壁上。
</new_puzzle>

<new_puzzle>
每个前景对象根据其自身的对称类型选择一种平铺方式，在其包围盒的四周进行特定模式的复制扩展。

Input structure
- 背景为 black。网格中有若干互不重叠的单色 4-连通前景对象，每个对象的包围盒不超过 6×6。
- 每个对象恰好属于以下三种对称类型之一：仅有水平对称轴、仅有垂直对称轴、同时有水平和垂直对称轴（即具有两轴对称）。
- 输出网格尺寸根据对象数量和包围盒大小确定。

Rule
- 输出由多个"瓦片块"拼成，每个前景对象生成一个瓦片块，瓦片块之间用 1 像素宽的 grey 分隔线隔开，按对象在输入中从左到右、从上到下的阅读顺序排列成一行。
- 每个瓦片块的生成规则取决于对象的对称类型：
  - 仅水平对称：将对象沿垂直方向复制一次（上下镜像拼接），瓦片块高度翻倍，宽度不变。
  - 仅垂直对称：将对象沿水平方向复制一次（左右镜像拼接），瓦片块宽度翻倍，高度不变。
  - 两轴对称：将对象向四个方向各镜像复制一次（2×2 排列），瓦片块宽高均翻倍。
- 瓦片块内的镜像副本保持与原对象相同的颜色。

Key insight
- 解题者必须先独立判断每个对象的对称类型（这需要对每个对象进行对称性检测），然后根据对称类型确定不同的镜像拼接方式——对称性分类本身是第一层推理，拼接规则是第二层推理。表面上看对称的对象反而获得更多的复制，这在直觉上不太容易察觉。
</new_puzzle>

<new_puzzle>
在一个包含多个彩色"信号塔"和 grey 墙壁的网格中，每座信号塔沿四个正方向发射射线直至碰壁，射线交叉处的颜色由两座信号塔的颜色混合规则决定。

Input structure
- 背景为 black。网格中有若干 grey 像素构成的不规则墙壁段（不形成封闭区域）。
- 网格中有 3-5 个单像素"信号塔"，每个信号塔的颜色从 {red, blue, yellow} 中取值。
- 信号塔之间不会出现在同一行或同一列上（保证射线不会正面对撞）。

Rule
- 每个信号塔从自身位置向上、下、左、右四个方向发射射线，射线在碰到 grey 墙壁像素或网格边缘时停止（不包含墙壁和信号塔本身的位置）。
- 射线颜色与信号塔颜色相同。
- 当两条不同颜色的射线交叉于同一像素时，该像素的颜色按以下混合规则确定：
  - red + blue → magenta
  - red + yellow → orange
  - blue + yellow → green
- 若三条不同颜色的射线交叉于同一点，该像素为 maroon。
- 同色射线交叉处保持该颜色不变。
- 信号塔自身的像素颜色保持不变；grey 墙壁保持不变。

Key insight
- 第一层推理是理解射线的传播规则（沿四方向到墙壁停止）；第二层推理是发现交叉点的颜色混合规则。解题者需要先在脑中"模拟"射线路径，再在交叉位置应用正确的颜色叠加——而墙壁的存在使得射线路径不可简单推断，必须逐条追踪。
</new_puzzle>

<new_puzzle>
将网格中的每个多色矩形"调色板"拆解为单色层，再按各层面积从大到小依次向网格右侧的空白区域堆叠绘制为底部对齐的柱状条。

Input structure
- 背景为 black。网格左半部分包含 2-4 个互不重叠的矩形区域（"调色板"），每个调色板内部由 2-4 种颜色的像素填充，各颜色形成不规则但 4-连通的区域。
- 网格右半部分为空白（全 black），由一条 1 像素宽的 azure 垂直线与左半部分分隔。
- 右半部分底部有一条 1 像素高的 grey 水平基线。

Rule
- 对于左半部分的每个调色板，统计其中每种颜色占据的像素数量。
- 在右半部分，为每个调色板生成一组底部对齐于 grey 基线的垂直柱状条：
  1. 同一个调色板的柱状条相邻排列，柱状条之间无间隔，每根柱状条宽度为 1 像素。
  2. 柱状条按颜色面积从大到小、从左到右排列。
  3. 每根柱状条的高度等于该颜色在调色板中的像素数量。
  4. 柱状条的颜色为对应的调色板颜色。
- 不同调色板的柱状条组之间用 1 列 black 间隔。
- 调色板组的排列顺序按调色板在左半部分中从上到下的位置排序。
- 左半部分（包括调色板和 azure 分隔线）保持不变。

Key insight
- 解题者需要三层推理：首先识别出左侧每个矩形调色板及其内部颜色分布，其次理解右侧柱状条是对颜色面积的"直方图"可视化，最后发现排序规则（按面积从大到小）和分组规则（按调色板的空间位置排序）。这不是简单的形状复制，而是从空间分布到统计图表的抽象转化。
</new_puzzle>

<new_puzzle>
网格中每个带色框的矩形内部包含一个小型"种子"图案，将种子图案按框的颜色所指示的旋转角度旋转后，用种子的颜色填充整个框的内部空间（平铺填充）。

Input structure
- 背景为 black。网格中有若干矩形色框（仅边框着色，内部为 black 加上一个小型种子图案）。
- 每个色框的边框颜色取自 {red, green, blue, yellow} 之一，边框宽度为 1 像素。
- 每个色框内部左上角有一个 2×2 或 3×3 的小型图案（"种子"），由 orange 像素在 black 背景上构成。种子图案不具有旋转对称性（即旋转 90° 后与原图不同）。
- 色框内部剩余空间为 black。

Rule
- 每种边框颜色对应一个旋转角度：red → 0°（不旋转）、green → 90° 顺时针、blue → 180°、yellow → 270° 顺时针。
- 对每个色框：
  1. 提取其内部左上角的种子图案。
  2. 按边框颜色对应的角度旋转种子图案。
  3. 用旋转后的种子图案平铺（tile）填满色框内部的全部空间。平铺从色框内部的左上角开始，若边缘空间不足以放下完整种子，则裁剪多余部分。
  4. 平铺像素保持 orange 颜色，black 位置保持 black。
- 色框边框保持不变。

Key insight
- 解题的第一层推理是发现边框颜色与旋转角度之间的映射关系（需要对比多个样例中同色框的种子变换）；第二层推理是理解旋转后的种子被用于平铺填充而非单次放置。颜色-旋转的编码表需要从样例中归纳，这是非平凡的。
</new_puzzle>

<new_puzzle>
在网格中，多个相同形状但不同颜色的"印章"散落于一个大型 grey 棋盘格背景上，根据每个印章落在棋盘格的浅色格还是深色格上，决定将其保留原色还是替换为互补色。

Input structure
- 网格由 grey 和 black 交替的 2×2 棋盘格图案铺满（即每个 2×2 块全为 grey 或全为 black，交替排列）。
- 棋盘格上放置了若干个形状完全相同的小型图案（"印章"），每个印章由单一前景色绘制（如 red、blue、green、yellow 等），占据 3-5 个像素。
- 每个印章完全落在一个棋盘格块内（不跨越块边界）。
- 网格右下角有一个 2×N 的"图例区"，背景为 azure，其中上行列出所有出现过的印章颜色，下行列出每种颜色的"互补色"配对（例如上行 red 下行 green，上行 blue 下行 yellow）。

Rule
- 对每个印章：
  1. 判断其所在的 2×2 棋盘格块的类型：grey 块（浅色）或 black 块（深色）。
  2. 若印章位于 grey 块上：保持印章颜色不变。
  3. 若印章位于 black 块上：将印章颜色替换为图例中对应的互补色。
- 棋盘格背景本身保持不变。
- 图例区保持不变。

Key insight
- 解题者需要首先发现棋盘格的 2×2 块结构（而非逐像素交替），然后理解浅/深位置对印章的不同处理方式，最后通过图例解码互补色映射。三个要素（棋盘结构识别、位置条件分支、颜色映射图例）构成了层层递进的推理链。
</new_puzzle>
