描述：根据封闭区域内部"种子"像素的颜色，从区域字典中查找对应的填充图案，将该图案平铺到封闭区域内部。

Input structure：
- 背景为黑色（black）。
- 网格中有若干由灰色（grey）像素围成的封闭矩形区域（一像素宽的灰色边框）。每个封闭区域内部大小不同，但都至少为 3×3。
- 每个封闭区域内部恰好有一个"种子"像素，颜色为非黑色、非灰色的前景色（如 red、blue、green 等），位于区域内部的任意位置，其余内部像素为黑色。
- 网格的一个角落（例如左上角）有一个"图案字典"区域：由若干小的灰色边框矩形排成一行，每个小矩形内部填有一种二色图案（用某种前景色与黑色交替），该图案的前景色即为该字典条目的"键"。

Rule：
- 首先识别图案字典：每个字典小矩形内部的前景色确定了该条目的键，内部的图案（前景色像素的排布）即为该键的"值"。
- 对于每个封闭区域，读取其内部种子像素的颜色，在字典中找到键颜色匹配的条目。
- 将字典条目中的图案以平铺方式填满该封闭区域的内部（从区域内部的左上角开始平铺，超出区域的部分裁剪），种子像素被图案覆盖。
- 灰色边框和字典区域保持不变。

Key insight：种子像素不是绘制指令，而是查表键——解题者必须先识别角落的图案字典结构，再通过颜色匹配将每个种子链接到正确的平铺图案。这是一个"解码字典→颜色键匹配→图案平铺"的三层推理管道。
</new_puzzle>

<new_puzzle>
描述：将散落在网格中的彩色碎片按形状配对拼合为完整矩形，再按矩形面积从小到大垂直堆叠到输出网格的底部。

Input structure：
- 背景为黑色（black）。
- 网格中散布着若干 4-连通的单色前景对象（碎片），每种颜色恰好出现两个不相邻的碎片。
- 每对同色碎片可以通过平移（不旋转、不翻转）拼合为一个无缝实心矩形。两个碎片的形状互补——即一个碎片的像素集合与另一个碎片平移后的像素集合的并集恰好构成一个矩形，且不重叠。

Rule：
- 对于每种前景色，找到该色的两个碎片。
- 确定唯一的平移向量，使两个碎片拼合成一个完整的实心矩形。记录该矩形的尺寸（宽×高）。
- 按矩形面积从小到大排序。
- 输出网格的宽度等于所有矩形中最大的宽度，高度等于所有矩形高度之和。
- 从输出网格的底行开始，面积最小的矩形放在最底部、左对齐；依次向上堆叠，每个矩形紧贴上一个矩形的顶部、左对齐。
- 每个矩形用其对应的颜色填充为实心。

Key insight：碎片本身的空间位置是干扰项——关键在于发现同色碎片互补拼合为矩形的关系，再用拼合后的面积排序来决定输出布局。"形状配对→虚拟拼合→面积排序→重新堆叠"构成多层推理。
</new_puzzle>

描述：每个彩色对象根据它所嵌入的"通道层"在输出中获得不同的边框样式，通道层由背景色带的嵌套深度决定。

Input structure：
- 网格由两种交替的背景色（如 azure 和 yellow）组成同心矩形环带，形成类似靶心的结构。最外层为 azure，向内交替 yellow、azure、yellow……
- 在各环带中散布着若干小型单色前景对象（如 red、green、blue 等），每个对象完全位于某一条环带内部，不跨越环带边界。

Rule：
- 确定每个前景对象所在环带的嵌套深度：最外层环带深度为 1，向内依次为 2、3、4……
- 深度为奇数的环带中的对象：在对象的外侧添加一圈一像素宽的 maroon 边框（8-连通方向扩展一像素，边框像素不覆盖已有前景色或其他边框）。
- 深度为偶数的环带中的对象：在对象的正上方和正下方各复制一份该对象的水平镜像副本，副本紧贴对象的顶/底边缘放置，用 grey 色绘制。
- 环带本身和不含对象的区域保持不变。

Key insight：解题的第一层是识别交替色同心环带并计算嵌套深度——这不是简单的"看颜色"，因为两种背景色交替出现，必须通过环带的几何嵌套关系推断深度。第二层是根据奇偶深度选择完全不同的变换操作。环带嵌套深度决定变换类型这一关联在表面上并不明显。
</new_puzzle>

<new_puzzle>
描述：沿着每个箭头标记指示的方向，将箭头所指向的源对象"推挤"穿过网格中的窄缝隙，使对象在通过缝隙后被压缩为缝隙允许的形状。

Input structure：
- 背景为黑色（black）。
- 网格中有若干由 grey 色像素组成的水平或垂直墙壁（一像素宽的直线段）。
- 每面墙壁上恰好有一个缺口（连续的一段灰色像素缺失），缺口宽度可能为 1 到 3 个像素。
- 墙壁的一侧有一个单色前景对象（4-连通，非灰色、非黑色），形状各异。
- 在该对象与墙壁之间有一个箭头标记：由 maroon 色像素绘制的一个像素的点加上一条指向墙壁方向的单像素尾巴（例如向右的箭头为一行上的 2-3 个 maroon 像素，最右端为箭头头部）。箭头的方向指向墙壁。

Rule：
- 箭头指示推挤方向（上/下/左/右之一）。
- 将箭头同侧的前景对象沿箭头方向投影到墙壁的缺口处。
- 投影规则：沿推挤方向逐列（或逐行）扫描对象，将对象在垂直于推挤方向上的像素"压缩"到缺口的宽度内——保留对象在推挤方向上的层数（即沿推挤方向的跨度不变），但在垂直方向上仅保留对象轮廓中与缺口对齐的那些像素。
- 压缩后的对象出现在墙壁的另一侧，紧贴缺口位置，颜色不变。
- 原对象位置清除为黑色，箭头标记清除为黑色，墙壁和缺口保持不变。

Key insight：箭头只是方向指示——真正的推理在于理解"推挤穿过缝隙"的几何含义：对象沿推挤方向的剖面被裁剪到缝隙宽度，但推挤方向上的层次结构被保留。解题者必须先识别墙壁-缺口-箭头-对象的四元组关系，再推断缝隙裁剪的几何规则。
</new_puzzle>

<new_puzzle>
描述：利用网格边缘的彩色刻度尺确定每个内部对象的"坐标地址"，再根据地址在独立的输出表格中填入对象的颜色。

Input structure：
- 背景为黑色（black）。
- 网格的顶边（第一行）有若干不同颜色的单像素标记，等间距排列，每个标记占一列——这是"列刻度尺"。
- 网格的左边（第一列）有若干不同颜色的单像素标记，等间距排列，每个标记占一行——这是"行刻度尺"。
- 网格内部（非首行首列的区域）散布着若干小型单色前景对象（4-连通，每个对象为 1-4 个像素），颜色各不相同。
- 网格右下角有一个由 grey 边框围成的小矩形空表格，行数等于行刻度尺标记数，列数等于列刻度尺标记数，内部为黑色。

Rule：
- 对于每个内部前景对象，确定其重心（所有像素行坐标的平均值和列坐标的平均值，取最近整数）。
- 找到行刻度尺中距离该重心行坐标最近的标记，以及列刻度尺中距离该重心列坐标最近的标记。这两个刻度标记确定了对象在输出表格中的"行地址"和"列地址"。
- 在右下角的输出表格中，将对应行列位置的像素填上该前景对象的颜色。
- 若多个对象映射到同一地址，则按对象面积从大到小，选取面积最大者的颜色。
- 输入网格中的前景对象、刻度尺标记保持不变。

Key insight：刻度尺标记不仅仅是装饰——它们定义了一套离散坐标系统，解题者必须发现"边缘标记=坐标轴刻度"这一隐含对应关系，再通过空间最近邻匹配将每个对象"编址"到输出表格中。这是"识别坐标系→空间编址→表格填充"的三层管道。
</new_puzzle>

<new_puzzle>
描述：检测每个封闭区域中的"感染源"像素，让感染沿特定路径扩散，扩散的步数由区域内另一种标记像素的数量决定。

Input structure：
- 背景为黑色（black）。
- 网格中有若干由 blue 色像素围成的封闭矩形区域（一像素宽的蓝色边框），各区域互不重叠。
- 每个封闭区域内部包含：
  - 恰好一个 red 像素——"感染源"。
  - 若干个 yellow 像素——"燃料标记"，散布在区域内部各处。
  - 其余内部像素为黑色。

Rule：
- 对于每个封闭区域，数出其内部 yellow 像素的数量 N。
- 从 red 像素出发，进行 N 步的 4-连通扩散（类似 BFS 的逐层扩展）：第 1 步将 red 像素的四个正交邻居（在区域内部且为黑色的）染成 orange；第 2 步将所有 orange 像素的未染色正交邻居染成 orange；依此类推，共扩散 N 步。
- 扩散不会越过蓝色边框，也不会覆盖 yellow 像素（yellow 像素充当障碍物，扩散绕过它们）。
- 扩散完成后，将所有 yellow 像素变为黑色（燃料耗尽消失）。
- 蓝色边框和原始 red 像素保持不变。

Key insight：yellow 像素同时扮演两个角色——它们的数量决定扩散的步数，但它们的位置又阻挡扩散路径。解题者必须同时理解"计数=距离"和"标记=障碍"这两层含义。单纯观察扩散范围无法推断规则，必须注意到 yellow 像素消失且其数量与扩散范围精确对应。
</new_puzzle>

<new_puzzle>
描述：每个前景对象在其"影子方向"上投射一个按照对象孔洞数量逐级变暗的阶梯影子。

Input structure：
- 背景为黑色（black）。
- 网格底部有一行 yellow 像素作为"地面线"。
- 地面线上方有若干单色前景对象（4-连通，颜色各异，如 red、green、blue 等），它们"站在"地面线上（底边与地面线相邻）。
- 每个对象内部可能有若干黑色"孔洞"（被对象像素完全包围的黑色 4-连通区域）。
- 网格的左边或右边（第一列或最后一列）有一个 orange 像素——"光源"。光源位于网格的最高行之一。

Rule：
- 光源在左侧时，影子向右侧投射；光源在右侧时，影子向左侧投射。
- 每个对象向远离光源的方向水平投射影子。影子的形状为对象的水平投影轮廓（即对象每一行的最左和最右列所确定的宽度），高度与对象相同。
- 影子的颜色层级由对象的孔洞数量 H 决定：影子共有 (H+1) 层。第 1 层紧贴对象，用 grey 色绘制，宽度等于对象本身的宽度；第 2 层紧贴第 1 层的外侧，用 maroon 色绘制，宽度相同；若 H≥2，第 3 层用 azure 色……颜色按 grey→maroon→azure 循环。
- 每层影子的水平宽度等于对象每行的水平跨度，高度等于对象高度。层与层之间紧密排列，无间隔。
- 影子不覆盖其他前景对象或地面线。若影子遇到其他对象则在该处截断。

Key insight：解题者需要发现两层非显然的规律：第一层是孔洞的数量决定影子的层数（而非影子颜色或方向），第二层是影子颜色按固定序列循环分配。光源位置只决定方向，真正的结构信息编码在对象自身的拓扑特征（孔洞数）中。
</new_puzzle>

<new_puzzle>
描述：网格中的"信号线"从发射器出发，遇到分色棱镜时按颜色分裂为多条子线，子线的终点颜色揭示正确的输出着色方案。

Input structure：
- 背景为黑色（black）。
- 网格边缘（上/下/左/右之一）有若干 maroon 色单像素"发射器"，每个发射器发出一条指向网格内部的直线射线（水平或垂直，由发射器所在边决定）。
- 网格内部有若干 grey 色的 1×3 或 3×1 矩形"棱镜"，方向与射线垂直。每个棱镜的三个像素分别被标记为三种不同的非黑色、非灰色前景色（如 red、blue、green），覆盖在灰色底色上（即每个棱镜像素显示为其标记色而非灰色）。
- 网格中还有若干由 grey 色边框围成的空白矩形"目标框"，每个框内部为黑色。

Rule：
- 每条 maroon 射线从边缘发射器出发，沿直线行进直到碰到棱镜。
- 射线击中棱镜的哪个像素，就以该像素的标记色继续行进（方向不变），同时从棱镜的另外两个像素各发出一条与原射线平行的同色射线（颜色分别为该像素自身的标记色），方向与原射线相同。
- 这样一条射线经过棱镜后分裂为三条带色射线，继续行进。
- 当带色射线进入某个目标框时，将该目标框内部填充为射线的颜色。
- 若多条不同颜色的射线进入同一目标框，混色规则为：red+blue=magenta，red+green=yellow，blue+green=azure。三色混合=grey。
- 射线遇到网格边缘或非棱镜的前景色障碍物时停止。

Key insight：解题者必须追踪射线的几何路径并理解棱镜的分裂机制——棱镜不只是改变颜色，而是将一条射线"分光"为三条，每条携带棱镜上不同位置的颜色。目标框的最终颜色取决于有多少条、什么颜色的射线汇入，需要空间路径追踪与颜色合成两层推理。
</new_puzzle>
