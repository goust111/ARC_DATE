<new_puzzle>
根据颜色连线网络中的交叉层级，决定哪条线在交叉点处"位于上方"并遮挡另一条线。

Input structure
- 背景为黑色。网格中有若干条彩色直线（水平或垂直），每条线由一种独特的非黑色颜色绘制。
- 每条线的两个端点处各有一个同色的 2x2 实心方块作为"端子"。
- 线与线之间可能存在交叉点（某条水平线与某条垂直线相交的像素）。
- 在输入中，所有交叉点处两条线的颜色混合表示为灰色（Grey）像素。
- 网格的最左列有一个从上到下排列的"层级图例"：若干彩色像素从上到下排列，每种颜色出现恰好一次，顺序表示该颜色线的层级——越靠上层级越高（位于上方）。

Rule
- 对于每个灰色交叉像素，确定在此交叉的两条线的颜色（通过该像素所在行和列各有哪条彩色线经过来判断）。
- 查阅左列图例中两种颜色的上下位置关系：图例中靠上的颜色层级更高。
- 将该灰色像素重新着色为层级更高的那条线的颜色（即上方的线遮挡下方的线）。
- 移除最左列的层级图例（将其像素恢复为黑色背景）。

Key insight
- 交叉点处的颜色不是由线本身的任何空间属性决定的，而需要查阅一个独立的层级排序图例；解题者必须先发现图例的作用（层级排序），再将其应用到每个交叉点的颜色决策中。
</new_puzzle>

<new_puzzle>
将散落的彩色碎片按颜色分组拼回各自的"画框"内，拼入位置由碎片形状与画框内缺口形状的吻合关系决定。

Input structure
- 背景为黑色。网格中有若干个大小相同的正方形"画框"，每个画框由独特颜色的单像素宽边框围成。
- 每个画框内部大部分区域已被与边框相同颜色的像素填满，但存在一个黑色"缺口"区域（形状不规则，像拼图缺失的一块）。
- 网格中另有若干散落的小型实心彩色碎片（4-连通单色形状），每个碎片的颜色与某个画框的边框颜色相同。
- 每个碎片的形状恰好与对应画框内的缺口形状完全吻合（可能需要旋转 0/90/180/270 度之一）。

Rule
- 根据颜色将每个碎片与对应的画框配对。
- 对碎片尝试四种旋转（0°、90°、180°、270°），找到能恰好填满对应画框内缺口的旋转方式。
- 将碎片平移并旋转后放入缺口位置，用碎片颜色填充缺口像素。
- 从碎片的原始位置移除碎片（恢复为黑色）。

Key insight
- 颜色匹配只完成了配对的第一层；第二层需要解题者在旋转空间中搜索碎片与缺口的形状吻合——这是一个视觉上的"拼图"问题，两层推理（颜色配对 + 旋转匹配）缺一不可。
</new_puzzle>

<new_puzzle>
根据每个封闭区域内部"种子"像素的数量，从一个共享的调色板条中选取对应位置的颜色来填充该区域。

Input structure
- 背景为黑色。网格由一种颜色（如蓝色 Blue）绘制的连通线条将空间分割为若干个封闭的黑色区域。
- 部分封闭区域内部散布着若干红色（Red）单像素"种子"点，数量从 1 到 N 不等，每个区域内的种子数量互不相同。
- 网格底部有一行水平排列的调色板条：从左到右依次排列 N 个不同颜色的单像素色块，中间用黑色间隔分开。调色板条的第 k 个色块（从左数第 k 个，k 从 1 开始）对应种子数量为 k 的区域。

Rule
- 计算每个封闭区域内红色种子像素的数量 k。
- 在底部调色板条中找到第 k 个色块的颜色。
- 用该颜色填充整个封闭区域（将区域内所有黑色像素和红色种子像素都重新着色）。
- 没有种子的区域保持黑色不变。
- 蓝色边界线和调色板条本身保持不变。

Key insight
- 解题者需要完成两层独立的归纳：第一层是发现种子数量是区分区域的索引键；第二层是发现底部调色板条是一个按位置编码的颜色查找表，索引恰好对应种子数量。两层缺一不可。
</new_puzzle>

<new_puzzle>
沿着每条彩色路径追踪方向，在路径的"拐弯处"向弯道外侧生长出长度等于该路径已经过拐弯次数的短棒。

Input structure
- 背景为黑色。网格中有若干条彩色折线路径，每条路径由独特颜色的像素绘制。
- 每条路径由一个起点（路径一端的像素，只有一个同色邻居）开始，沿水平或垂直方向延伸，途中若干次 90 度拐弯，直到终点（另一端只有一个同色邻居的像素）。
- 起点处有一个相邻的绿色（Green）单像素标记，指示该端为路径起始端。
- 各路径互不接触。

Rule
- 从起点开始沿路径行走，依次遇到每个拐弯点。
- 在第 k 个拐弯点（k 从 1 开始），确定弯道的外侧方向（路径从一个方向转向另一个方向时，外侧是转弯的凸侧，即与转弯后前进方向相反的那一侧对应的垂直方向）。
- 从拐弯点向外侧方向延伸一条长度为 k 个像素的短棒，颜色与路径相同。
- 若短棒延伸时遇到非黑色像素或超出网格边界，则截断到可用长度。
- 移除所有绿色起点标记（恢复为黑色）。

Key insight
- 解题者需要三层推理：(1) 通过绿色标记确定每条路径的行走方向；(2) 确定每个拐弯处的"外侧"方向（需要理解行走方向与转向方向的关系）；(3) 发现短棒长度按拐弯的序号递增而非固定——这使得同一条路径上的不同拐弯产生不同长度的短棒。
</new_puzzle>

<new_puzzle>
网格中有若干对称图案，每个图案恰好有一个像素被"污染"为错误颜色；找到并修复每个被污染的像素，修复依据是该图案自身的对称性。

Input structure
- 背景为黑色。网格中有若干个分离的彩色图案，每个图案由单一颜色绘制，占据一个连通区域。
- 每个图案在设计上具有某种对称性（可能是水平镜像、垂直镜像或 180 度旋转对称中的一种），但恰好有一个像素被改为了另一种非黑非原色的"污染色"（如橙色 Orange），破坏了对称性。
- 污染色在整个网格中只使用一种颜色（如全部为橙色），但每个图案中被污染的位置不同。

Rule
- 对每个图案，检测其最小外接矩形内的对称类型（通过比较去除污染像素后的图案来判定是水平、垂直还是旋转对称）。
- 根据确定的对称类型，计算污染像素在对称位置处应当存在的像素：
  - 如果对称位置已有正确颜色的像素，则将污染像素恢复为该图案的原始颜色。
  - 如果对称位置是黑色背景，则将污染像素移除（恢复为黑色），同时在对称位置添加一个该图案原始颜色的像素。
- 输出中所有污染色像素均被消除，每个图案恢复为完美对称。

Key insight
- 解题者不能简单地"删除异色像素"——污染像素可能本该是图案的一部分（只是颜色错了），也可能是被错误添加的（对称位置本该有像素却没有）。必须先判断每个图案的对称类型（第一层），再根据对称性推断污染像素的正确处理方式（第二层）。
</new_puzzle>

<new_puzzle>
在网格中找到所有"门"（边框上的缺口），然后从每扇门向内发射射线直到碰到障碍物，射线的颜色由门两侧边框段的颜色交替规则决定。

Input structure
- 背景为黑色。网格边缘由彩色像素构成一圈不完整的边框。
- 边框由若干段不同颜色的连续线段拼接而成，段与段之间颜色不同。
- 边框中有若干个单像素宽的黑色缺口（"门"），每扇门位于两段不同颜色边框段的交界处。
- 网格内部散布着若干灰色（Grey）实心矩形障碍物。
- 至少有一扇门的射线已经被绘制在输入中（作为规则示范）。

Rule
- 识别边框上的每个缺口（门）。
- 确定每扇门左右（或上下）相邻的两段边框的颜色，设为颜色 A 和颜色 B。
- 射线颜色规则从示范射线中归纳：射线的第奇数个像素用颜色 A，第偶数个像素用颜色 B（形成 A-B-A-B 的交替条纹，A 是门顺时针方向的第一段边框颜色）。
- 从门的位置沿垂直于边框的方向（即向网格内部）发射射线，射线延伸直到碰到灰色障碍物或网格对面的边框为止。
- 示范门的射线保持不变，其余未绘制射线的门需要补全。

Key insight
- 解题者需要先从已有的示范射线"逆向工程"出颜色交替规则和颜色与边框段的对应关系（第一层推理），再将该规则应用到其他门上确定射线颜色（第二层推理），最后确定射线的方向和终止条件（第三层推理）。
</new_puzzle>

<new_puzzle>
将网格中每个彩色"箭头"沿其指向方向推进，推进距离等于箭头自身所在行（或列）中同色像素的总数。

Input structure
- 背景为黑色。网格中有若干个由不同颜色绘制的箭头形状。
- 每个箭头由一个 3 像素高、2 像素宽的竖直矩形"尾部"加上一个 3 像素宽、1 像素高的水平横条"头部"组成，头部紧贴尾部的一端，形成 T 字形。T 字形的开口方向（头部相对于尾部的位置）表示箭头的指向：头部在上方表示向上，在下方表示向下，在左侧表示向左，在右侧表示向右。
- 每个箭头颜色唯一，且箭头不与其他箭头接触。

Rule
- 确定每个箭头的指向方向。
- 如果箭头指向水平方向（左或右），计算该箭头所在行中该箭头颜色像素的总数 d；如果箭头指向垂直方向（上或下），计算该箭头所在列中该箭头颜色像素的总数 d。注意：箭头可能跨越多行多列，取箭头尾部中心像素所在的行或列来计算。
- 将整个箭头沿其指向方向平移 d 个像素。
- 从箭头的原始位置移除箭头（恢复为黑色）。
- 若平移后箭头部分超出网格边界，则超出部分被裁剪。

Key insight
- 解题者需要先识别箭头的绘制规则和指向编码方式（第一层），再发现平移距离是由箭头自身像素在特定行或列中的计数决定的（第二层）——距离不是固定的，也不是由外部标记给出的，而是箭头的几何属性自我编码了自己的移动量。
</new_puzzle>

<new_puzzle>
根据网格中若干"钟表"图案的指针方向，选择性地保留或删除钟表周围对应象限中的装饰物。

Input structure
- 背景为黑色。网格中有若干个相同大小的"钟面"：每个钟面是一个由灰色（Grey）像素绘制的 5x5 空心正方形框。
- 每个钟面的中心像素（第 3 行第 3 列）为红色（Red），代表钟轴。
- 从红色钟轴出发，恰好有一条长度为 2 像素的黄色（Yellow）直线指向上、下、左、右四个方向之一，代表"指针"。
- 每个钟面的四个外侧（上方、下方、左方、右方）各放置一个由不同颜色绘制的小型装饰物（如 2x2 方块或 L 形小图案），四个方位各一个。装饰物与钟面之间间隔 1 个黑色像素。

Rule
- 确定每个钟面的指针方向。
- 保留指针所指方向的装饰物。
- 同时保留指针顺时针方向下一个方位的装饰物。
- 移除另外两个方位的装饰物（恢复为黑色）。
- 钟面本身（包括灰色边框、红色钟轴和黄色指针）保持不变。

Rule
- 确定每个钟面的指针方向。
- 保留指针所指方向的装饰物。
- 同时保留指针顺时针方向下一个方位的装饰物（即指针指向和其顺时针 90 度方向的两个装饰物保留）。
- 移除另外两个方位的装饰物（恢复为黑色）。
- 钟面本身（包括灰色边框、红色钟轴和黄色指针）保持不变。

Key insight
- 解题者需要先理解钟面的结构和指针编码（第一层），然后发现保留规则不是简单地"只保留指针方向"，而是保留指针方向及其顺时针下一个方向的两个装饰物（第二层）——这个"顺时针偏移"规则需要从多个样例中仔细对比才能归纳出来。
</new_puzzle>
