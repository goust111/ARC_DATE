- `description`：根据每个封闭房间内"窗户"（缺口）的朝向，将房间内的种子像素沿该方向推到墙壁上，模拟风从窗户吹入将物体吹向对面墙的效果。
- `Input structure`：背景为黑色。网格中散布若干由 grey 像素构成的矩形"房间"轮廓，每个房间的轮廓恰好有一个单像素宽的缺口（窗户），缺口位于房间的上、下、左或右某一侧边的中部。每个房间内部恰好有一个或多个彼此不相邻的彩色种子像素（颜色各异，非 grey、非黑色），种子像素不贴墙。
- `Rule`：
  1. 找到每个 grey 矩形房间轮廓上的唯一缺口，确定缺口所在的方向（上、下、左、右）。
  2. 想象风从缺口方向吹入房间：风的方向是从缺口朝向房间内部，即缺口在上侧则风向下吹，缺口在左侧则风向右吹，以此类推。
  3. 将房间内每个种子像素沿风向平移，直到它紧贴与缺口对面的那面内墙（即种子像素移动到该方向上最远的可用位置，紧邻对面墙壁内侧）。若同一列/行有多个种子，它们依次堆叠，先到的贴墙，后到的紧邻前一个。堆叠顺序按种子原始位置决定：距离对面墙更近的种子先放置。
  4. 房间轮廓（包括缺口）和背景保持不变。
- `Key insight`：每个房间的缺口位置决定了一个"风向"，所有房间内的种子像素都被这股风推向对面墙壁并堆叠——需要先识别缺口方向，再执行方向性平移。
</new_puzzle>

- `description`：将网格中每个彩色对象视为"印章"，根据它旁边的箭头标记确定盖章方向，在对象的该方向侧留下一个颜色变淡（替换为指定浅色）的"印痕"副本。
- `Input structure`：背景为黑色。网格中有若干小型彩色 4-连通对象（形状各异，每个对象为单一颜色，颜色可以是 red、blue、green、magenta 等）。每个对象的正上方、正下方、正左方或正右方紧邻一个 yellow 单像素标记（箭头标记），该标记与对象之间恰好间隔一个像素的空隙。每个对象恰好有一个 yellow 标记。
- `Rule`：
  1. 对每个彩色对象，找到其关联的 yellow 标记像素。标记相对于对象紧凑包围盒中心的方向即为"盖章方向"（上、下、左、右）。
  2. 在盖章方向的反方向上，以对象自身为起点，紧贴对象地复制一份该对象的完整形状作为"印痕"。具体做法：将对象的每个像素沿盖章方向的反方向平移 d 个像素，其中 d 等于对象在该轴方向上的跨度（即包围盒在该轴的尺寸）。
  3. 印痕的颜色统一替换为 grey。
  4. 原始对象和 yellow 标记保持不变；印痕若与其他对象或标记重叠，印痕画在最底层（不覆盖已有内容）。
- `Key insight`：yellow 标记指示盖章方向，但印痕出现在相反方向——如同印章按下时，章面朝下而印痕留在下方。需要先从标记位置推断方向，再向反方向复制并变色。
</new_puzzle>

- `description`：识别网格中由不同颜色绘制的多个相同模板形状的副本，找出其中被"污损"（有像素被篡改）的副本，并将污损像素修复为正确颜色。
- `Input structure`：背景为黑色。网格中有若干个形状完全相同（经过平移后可重合）的对象，每个对象用不同的单一前景色绘制（如一个 red 的 T 形、一个 blue 的 T 形、一个 green 的 T 形等）。其中大多数副本是完好的（所有像素颜色一致），但恰好有一个副本存在"污损"：该副本中有 1-2 个像素的颜色被替换成了另一个出现在其他副本中的颜色。
- `Rule`：
  1. 识别网格中所有具有相同形状（平移等价）的 4-连通前景对象，确定它们共用的模板形状。
  2. 对每个副本检查颜色一致性：完好副本的所有像素颜色相同；污损副本中存在少数像素颜色与该副本的主色不同。
  3. 将污损副本中颜色异常的像素修改为该副本的主色（即出现次数最多的颜色）。
  4. 输出修复后的完整网格，其余所有像素不变。
- `Key insight`：解题的核心是两步管道——先通过形状匹配发现所有副本共享同一模板，再通过颜色一致性检测找到并修复污损像素。模板形状需要从多个副本的共性中归纳，而非直接给出。
</new_puzzle>

<new_puzzle>
- `description`：网格被分为左右两个面板：左面板包含若干带颜色的"钥匙"形状，右面板包含若干 grey 的"锁"轮廓；将每把钥匙旋转后插入形状匹配的锁中，用钥匙的颜色填充该锁的内部。
- `Input structure`：背景为黑色。网格被一条单像素宽的 maroon 竖线分为左右两个面板。
  - 左面板：包含若干小型实心彩色对象（钥匙），每个对象是一个不规则的小形状（3-6 个像素），颜色各不相同（如 red、blue、green、orange 等）。
  - 右面板：包含若干由 grey 像素绘制的空心轮廓（锁），每个轮廓围出一个封闭区域。每个锁轮廓内部的封闭空腔形状恰好与某一把钥匙的形状在经过 0°、90°、180° 或 270° 旋转后完全吻合（形状像素数和排布一致）。钥匙与锁之间存在一一对应关系。
- `Rule`：
  1. 提取左面板中每个彩色实心对象的归一化形状（紧凑包围盒内的像素布局）。
  2. 提取右面板中每个 grey 轮廓内部空腔的归一化形状。
  3. 对每把钥匙，尝试 0°、90°、180°、270° 四种旋转，找到与之形状匹配的锁空腔。
  4. 用该钥匙的颜色填充匹配锁的内部空腔像素（grey 轮廓本身保持不变）。
  5. 左面板的钥匙对象在输出中被擦除（变为背景色）。maroon 分隔线保持不变。
- `Key insight`：需要先将钥匙形状与锁的内腔形状进行旋转匹配——这是一个空间推理的分组步骤；匹配成功后，钥匙的颜色决定锁内的填充色。难点在于需要同时处理形状的旋转等价和颜色的传递。
</new_puzzle>

<new_puzzle>
- `description`：网格中散布着若干彩色像素"火种"和 grey 像素"燃料带"；每个火种沿与其相连的燃料带蔓延，将燃料带染成火种的颜色，两个火种的火焰在燃料带上相遇时，交汇点变为第三种指定颜色。
- `Input structure`：背景为黑色。网格中存在若干条由 grey 像素构成的单像素宽路径（燃料带），这些路径沿水平或垂直方向延伸，可以在交叉点处相交形成网络。在某些燃料带的端点或中途位置上，恰好有一个像素被替换为非黑非 grey 的彩色像素（火种）。整个网格中恰好只有两种不同的火种颜色（例如 red 和 blue），每种颜色的火种可以有一个或多个。
- `Rule`：
  1. 从每个火种像素出发，沿着与之 4-连通相邻的 grey 燃料带像素进行洪水填充式蔓延，将经过的 grey 像素染成火种的颜色。蔓延同时从所有火种出发，每步扩展一个像素，速度相同。
  2. 当两股不同颜色的火焰（来自不同颜色的火种）试图同时到达同一个 grey 像素时，该像素不被任何一方染色，而是变为 yellow。
  3. 同色火种的火焰相遇时正常合并，像素染为该颜色。
  4. 所有火种像素保留原色不变；不与任何火种连通的 grey 像素保持 grey；背景保持黑色。
- `Key insight`：这是一个"同时扩散 + 碰撞检测"的两层机制——先理解火焰沿燃料带等速蔓延的扩散规则，再理解不同色火焰交汇处产生特殊标记色的碰撞规则。解题者需要从样例中同时发现扩散方向（沿连通路径）和碰撞变色（异色交汇变 yellow）两个独立规则。
</new_puzzle>
