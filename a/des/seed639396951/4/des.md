<description>
根据彩色边框矩形内部的"窗口"形状，从外部散落的调色板精灵中查找匹配轮廓，再用调色板精灵自身的颜色填充窗口。

Input structure:
- 背景色 = black。
- 网格上散布若干大的单色矩形边框（不同颜色），每个边框内部有一块背景色区域构成的"窗口"——即边框内壁上被挖去的一个小连通形状（形如 T 形、L 形、十字形等），窗口与边框外部不连通。
- 网格上另有若干小的彩色实心精灵（与边框颜色均不同），每个精灵恰好是某个窗口形状的精确副本（可能经过旋转或翻转）。

Rule:
- 对每个矩形边框，提取其内部窗口的形状（背景色连通区域的轮廓）。
- 在所有小精灵中找到与该窗口形状全等的那个（允许 0°/90°/180°/270° 旋转和水平翻转）。
- 将窗口区域的每个像素填充为匹配精灵的颜色。
- 小精灵从网格中删除；边框本身保持不变。

Key insight: 窗口是"负空间"形状，需要将边框内部的背景色空洞视为一个独立图形，再与外部正空间精灵做轮廓匹配——解题者必须完成"负→正"的认知翻转，然后还需处理旋转/翻转的等价匹配。
</description>
</new_puzzle>

<description>
将网格中的彩色路径按照路径交叉点处的颜色优先级规则进行"编织"——高优先级路径在交叉处保持原色，低优先级路径在交叉处被截断并用背景色填充。

Input structure:
- 背景色 = black。
- 网格上有若干条不同颜色的直线路径（水平或垂直），每条路径宽度为 1 像素。
- 这些路径会在某些位置交叉，交叉点当前显示为其中一种路径的颜色。
- 网格右侧或下方有一个小的"优先级图例"：一列竖排的彩色像素，从上到下排列，表示从高到低的优先级顺序。

Rule:
- 从优先级图例中读取颜色的优先级排序（最上方 = 最高优先级）。
- 对于每个路径交叉点，确定交叉的两条路径的颜色。
- 优先级更高的路径在交叉点处保留原色（视觉上"从上方穿过"）。
- 优先级更低的路径在交叉点处被背景色替换（视觉上"从下方穿过"，被遮挡）。
- 非交叉位置的路径像素保持不变。

Key insight: 图例并非颜色映射，而是"深度排序"——解题者需要意识到竖排颜色编码的是前后层次关系，再将这个层次应用到每个交叉点来决定哪条路径"可见"。
</description>
</new_puzzle>

<new_puzzle>
<description>
利用网格中箭头精灵指示的方向和框内种子图案的形状，沿箭头方向逐步"生长"种子图案，每步扩展一层轮廓像素，生长层数由箭头的长度决定。

Input structure:
- 背景色 = black。
- 网格上有若干个小矩形边框（grey 色，宽 1 像素），每个边框内部包含一个由某种颜色绘制的小型种子图案（如 2x2 方块、十字形、L 形等），种子图案不接触边框。
- 每个边框外侧恰好有一个箭头精灵：箭头由一条直线段（水平或垂直）加上末端的一个三角形箭头尖构成。箭头尖由 3 个像素组成，排列方式为：沿直线段方向的最前端 1 个像素加上垂直于直线段方向的两侧各 1 个像素。箭头颜色与对应边框内种子图案颜色相同。箭头尖指向远离边框的方向。箭头的直线段长度（不含箭头尖的 3 个像素）为 N 个像素。

Rule:
- 移除所有 grey 边框和箭头精灵。
- 对每个种子图案，沿箭头指向的方向执行 N 次"定向膨胀"：每次膨胀仅在箭头指向的那一侧（上/下/左/右）为图案当前轮廓添加一层新像素（颜色与种子相同）。具体来说，若箭头朝右，则每次膨胀将图案最右边每个像素的右邻居（若为背景色）设为种子颜色。
- 膨胀后的图案留在种子的原始位置，向箭头方向单侧扩展。
- 若两个图案膨胀后重叠，重叠像素保留先膨胀完成的图案颜色（即按种子图案从上到下、从左到右的顺序依次处理）。

Key insight: 解题者需要同时归纳两层规则——第一层是箭头长度编码生长步数，第二层是生长方向为单侧定向膨胀而非四面膨胀。箭头的颜色匹配机制将箭头与种子配对，而箭头朝向和长度分别编码了膨胀的方向和次数。
</description>
</new_puzzle>

<new_puzzle>
<description>
根据每个封闭房间内"门"的数量和位置，从颜色库中选色并按门的朝向规则为房间内部绘制条纹图案。

Input structure:
- 背景色 = black。
- 网格由 blue 像素绘制的墙壁分隔成若干封闭的矩形"房间"，每个房间内部为背景色。墙壁宽 1 像素。
- 每个房间的墙壁上有 1 到 3 个"门"——即墙壁中被移除的 1 像素宽缺口（显示为背景色）。门仅出现在房间的上、下、左、右四面墙壁上。
- 网格角落有一个颜色库：竖排的 3 个彩色像素（从上到下分别标号 1、2、3），每个像素颜色不同，且不为 blue 或 black。颜色库与墙壁之间用至少 2 像素的背景色隔开。

Rule:
- 对每个房间，数出其门的数量 D（1、2 或 3）。
- 从颜色库中取第 D 个颜色（从上到下第 D 个像素的颜色）。
- 观察该房间的门位于哪些墙壁上：若任意一扇门在左墙或右墙上，则绘制水平条纹；若所有门都在上墙或下墙上，则绘制垂直条纹。
- 条纹图案：从房间内部的第一行（或第一列）开始，交替填充"选定颜色"和"背景色"，每条纹宽 1 像素。即第 1 行（列）填选定颜色，第 2 行（列）保持背景色，第 3 行（列）填选定颜色，以此类推。
- 门的缺口像素保持为背景色不变。

Key insight: 门的数量决定颜色选取，门的方位决定条纹方向——解题者必须分别归纳这两条独立规则，而且"数量→颜色"和"方位→方向"两层映射混合在同一视觉线索（门）中，增加了分离难度。
</description>
</new_puzzle>

<description>
将网格中的多个嵌套环形框架按照从外到内的包含顺序拆解，每层框架以其包含深度对应的偏移量向指定方向平移后重新排列在输出中。

Input structure:
- 背景色 = black。
- 网格中央有一组同心嵌套的矩形框架（每个框架是 1 像素宽的矩形环），每个框架颜色不同，框架之间有 1 像素的背景色间隔。最外层框架最大，最内层最小，嵌套深度为 2 到 4 层。
- 网格的一个角落有一个方向指示器：一个 3x3 的小方块，中心为 grey 像素，某个 4-邻接方向（上/下/左/右之一）上有一个 red 像素，其余位置为背景色。red 像素指示平移方向。

Rule:
- 识别所有嵌套的矩形框架，按包含关系确定深度（最外层深度 = 1，次外层深度 = 2，依此类推）。
- 读取方向指示器中 red 像素相对于 grey 中心的方向 D。
- 将每个框架沿方向 D 平移 (深度 - 1) × 2 个像素。深度 1 的最外层框架不动，深度 2 的框架平移 2 像素，深度 3 的框架平移 4 像素，以此类推。
- 输出网格大小调整为恰好容纳所有平移后的框架（加 1 像素边距）。
- 若平移后框架像素重叠，深度更大（更内层）的框架覆盖深度更小的框架。

Key insight: 嵌套深度不仅是视觉层次，还被量化为平移距离的乘数——解题者先要识别包含层级，再发现深度与位移的线性关系，最后注意重叠时的深度优先覆盖规则。
</description>
</new_puzzle>

<description>
根据彩色标记点在封闭区域边界上的位置，从标记点向区域内部引垂线分割空间，再用图例指定的颜色填充分割后的子区域。

Input structure:
- 背景色 = black。
- 网格上有若干个由 grey 像素绘制的封闭矩形区域（边框宽 1 像素），每个矩形内部为背景色。
- 每个矩形的边框上有 2 到 3 个彩色标记点（非 grey、非背景色），这些标记点位于边框像素位置上（替换了该处的 grey 像素）。同一个矩形上所有标记点颜色相同。
- 网格边缘有一个颜色图例区：若干个小的 3x3 方块，每个方块的边框色为某种颜色 C，内部填充单个像素的颜色为 F。

Rule:
- 对每个矩形，找到其边框上的所有标记点。
- 标记点的颜色 C 用于在图例中查找对应的填充色 F（找到边框色 = C 的那个图例方块，取其内部颜色 F）。
- 从每个标记点向矩形内部引一条垂直于该标记点所在边的直线，延伸到对面的边框为止。例如：标记点在上边框 → 向下引竖线；标记点在左边框 → 向右引横线。这些分割线用 grey 颜色绘制。
- 分割线将矩形内部分成若干个矩形子区域，所有子区域用填充色 F 填充。
- 标记点本身保持其颜色 C。

Key insight: 标记点不仅是颜色匹配的线索（用于查找图例），还是空间分割的锚点——它们在边框上的位置决定了内部分割线的走向。解题者需要先通过颜色匹配找到填充色，再根据标记点位置推断分割几何。
</description>

<new_puzzle>
<description>
将散落的彩色碎片按形状匹配填入模板的空槽中，然后根据碎片填入后与模板边界接触的面积比例，对碎片执行不同的颜色变换。

Input structure:
- 背景色 = black。
- 网格上方有一个大的 maroon 色实心形状（"模板"），模板内部挖有若干个不规则的背景色空槽（空洞），每个空槽形状不同。
- 网格下方散布若干个彩色实心碎片精灵（每块颜色各不相同，均非 maroon 和 black），每个碎片的形状恰好与模板中某个空槽全等（仅需平移，无需旋转或翻转）。
- 碎片数量与空槽数量相同，一一对应。

Rule:
- 将每个碎片平移到与其形状匹配的空槽位置，填入模板。
- 填入后，计算每块碎片与 maroon 模板边界的接触边数（4-连通方向上，碎片像素与 maroon 像素相邻的边的总数）。
- 接触边数最多的碎片：颜色变为 yellow。
- 接触边数最少的碎片：颜色变为 blue。
- 其余碎片：保持原色不变。
- 模板的 maroon 像素保持不变。

Key insight: 解题者先要解决空间拼图问题（碎片匹配空槽），再发现填入后的"接触面积"决定了颜色变换规则——同一视觉属性（碎片与模板的邻接程度）同时编码了最大和最小两个极端的不同变换。
</description>
</new_puzzle>
