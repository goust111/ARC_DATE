<description>
根据嵌套框架的层数选择对应的颜色图例，再用图例颜色重新填充框架的间隙区域。

Input structure:
- bg = 最常见颜色（如 black）。网格右侧或底部有一列颜色图例方块，从上到下排列，每个方块是一种不同颜色，位置编号从 1 开始递增。
- 网格主区域中有若干组嵌套的同心矩形框架（hollow rectangles），每组框架由同一种颜色绘制，框架之间以 bg 间隔。每组框架的嵌套层数不同（1 层、2 层、3 层等）。
- 每个框架组之间互不重叠，各自独立放置在网格上。

Rule:
- 对每组嵌套框架，数出其嵌套层数 N（即同心矩形的个数）。
- 在颜色图例中找到编号为 N 的颜色条目（图例第 1 个方块对应 N=1，第 2 个对应 N=2，依此类推）。
- 将该组框架之间所有 bg 间隙区域（即相邻两层框架之间的空白带）填充为图例指定的颜色。框架本身的颜色保持不变。
- 图例方块本身在输出中保留原样。

Key insight: 嵌套层数是匹配图例的索引键——解题者需要先识别每组框架的同心层数，再将层数映射到图例位置来确定填充颜色，两步推理缺一不可。
</description>

将散落的彩色碎片按形状拼入灰色模板的缺口中，但拼入时需根据碎片与缺口之间的朝向关系进行旋转对齐。

Input structure:
- bg = black。网格中央有一个大型 grey 色模板对象，模板内部有若干不规则缺口（被 bg 填充的连通区域）。每个缺口的形状各不相同。
- 每个缺口的边缘恰好有一个 red 像素作为"锚点标记"，位于缺口边界的某一侧（上、下、左、右边缘之一）。
- 模板外部散落着若干单色碎片（每个碎片颜色各异，非 grey、非 red、非 black），每个碎片上也恰好有一个 red 像素锚点。
- 碎片的基础形状（忽略 red 锚点后）与某个缺口的形状在旋转 0°/90°/180°/270° 后匹配。

Rule:
- 对每个缺口，在外部碎片中找到形状匹配的碎片（允许旋转 0°/90°/180°/270°，不允许翻转）。

- 将旋转后的碎片填入缺口，碎片用自身颜色填充缺口区域，red 锚点在输出中保留为 red。
- 模板的 grey 区域保持不变。

Key insight: 形状匹配确定"哪个碎片填哪个缺口"，但正确的旋转角度由 red 锚点的相对位置决定——仅靠形状匹配会有多个旋转候选，锚点消除了歧义。

<description>
沿着彩色路径传播信号色，信号在路径交叉点处根据优先级规则选择分支方向。

Input structure:
- bg = black。网格中有若干条由不同颜色绘制的单像素宽路径（如 blue、green、orange 等），路径沿水平或垂直方向延伸，可以转弯，部分路径在某些像素位置交叉重叠。
- 交叉点处的像素为 grey，表示两条路径在此相交。
- 每条路径的一个端点处有一个 red 像素（信号源），另一个端点无特殊标记。
- 网格边缘或角落有一个小的颜色优先级图例：一列彩色方块从上到下排列，表示颜色优先级从高到低。

Rule:
- 从每个 red 信号源开始，沿其所在路径向另一端传播，将路径上所有像素重新着色为 red。
- 当信号到达一个 grey 交叉点时，信号进入与之交叉的另一条路径并继续传播。但一个交叉点只允许信号通过一次。
- 如果两个信号同时到达同一个交叉点（即两条路径的信号源到该交叉点的路径长度相同），则根据优先级图例决定哪个信号通过——优先级更高的路径颜色对应的信号获胜并继续传播，另一个信号在交叉点处停止。
- 所有被信号到达的像素变为 red；未被到达的路径像素保持原色；交叉点像素变为通过它的信号的 red 色或保持 grey（若无信号到达）。

Key insight: 解题者需要先追踪每条路径的拓扑结构来确定信号传播顺序，再利用颜色优先级图例解决交叉冲突——路径结构决定传播范围，优先级图例决定冲突胜负，两个推理层相互依赖。
</description>

根据封闭区域内部"种子"像素的颜色，选择对应的填充纹理模板来铺满该区域。

Input structure:
- bg = black。网格中有若干由 grey 线条围成的封闭区域（不规则多边形），区域内部为 bg。
- 每个封闭区域内部恰好有一个非 bg、非 grey 的单像素"种子"（如 red、blue、green 等），颜色各不相同。
- 网格的一侧（如最底部几行）有一排小的正方形纹理样本框，每个样本框由 grey 边框包围，内部是一个 2×2 或 3×3 的重复纹理图案。每个纹理样本框的左上角有一个与种子颜色对应的单像素颜色标签。

Rule:
- 对每个封闭区域，读取其内部种子像素的颜色。
- 在纹理样本区找到颜色标签与种子颜色匹配的纹理模板。
- 将该纹理以平铺（tiling）方式填满整个封闭区域，平铺的相位以种子像素所在位置为锚点（即种子像素处对应纹理图案的左上角像素）。
- 种子像素本身被纹理覆盖。grey 边界线保持不变。纹理样本区域在输出中保留原样。

Key insight: 种子颜色是查找纹理的键，而种子位置决定了纹理平铺的相位对齐——相同纹理在不同区域中因种子位置不同而呈现不同的平铺偏移，这要求解题者同时理解"颜色匹配"和"位置锚定"两层机制。

<description>
将网格中每个多色对象拆分为单色层，再按照隐含的深度顺序将各层重新堆叠到指定位置。

Input structure:
- bg = black。网格左半区有若干多色对象，每个对象是一个矩形区域，内部由 2-3 种颜色的像素混合构成（类似像素重叠后的合成结果）。
- 网格右半区有一列从上到下排列的单色小方块作为"深度图例"，每个方块颜色不同，排列顺序代表深度——最上面的方块表示最底层（最先绘制），最下面的方块表示最顶层（最后绘制）。
- 右半区还有与左半区每个对象对应的空白目标框（grey 边框，内部 bg），目标框的尺寸与对应的多色对象相同。

Rule:
- 对每个多色对象，将其拆分为若干单色层：每种颜色的像素构成一层，每层本身是一个连通的形状。
- 参考深度图例确定各层的绘制顺序（图例中靠上的颜色先画，靠下的后画）。
- 在对应的目标框中，按深度顺序依次绘制各层。后绘制的层会覆盖先绘制的层。
- 每一层在绘制时需要"补全"为其连通像素的最小外接矩形（bounding box），即将该颜色层扩展为完整矩形后再绘制。
- 最终目标框内呈现的是所有层按深度堆叠后的结果。

Key insight: 多色对象是多层矩形叠加后的"可见表面"——解题者需要逆向推理出每一层被遮挡的完整矩形形状，再依据深度图例的顺序正确重建。核心难点在于从遮挡后的合成结果反推出每层的完整形状，这是一个视觉反遮挡推理过程。
</description>

<description>
根据箭头指向将源区域的图案"投影"到目标墙面上，投影大小由箭头与墙面的距离决定。

Input structure:
- bg = black。网格中有若干条完整的水平或垂直 grey 线段作为"墙面"。
- 每面墙的一侧（与墙面垂直的方向上）有一个小型彩色图案（源图案），由单一非 bg 颜色绘制，尺寸为 2×2 或 3×3。
- 每个源图案旁边（远离墙面的一侧）紧贴一个由 red 像素构成的箭头，箭头形状为三角形尖端朝向墙面（例如：朝右的箭头用 3 个 red 像素排成 ">" 形，即上中下三行分别偏移 0、1、0 列的三像素构成指向右的尖角）。箭头表示投影方向。

Rule:
- 对每个源图案，沿箭头指向的方向，测量源图案到墙面的距离 D（以像素为单位，从图案最近边缘到墙面的空白格数）。
- 若 D ≤ 2，则在墙面上绘制与源图案相同大小的图案副本（1:1 投影）。
- 若 D 为 3 或 4，则将源图案放大为 2 倍（每个像素扩展为 2×2）后绘制在墙面上。
- 若 D ≥ 5，则将源图案放大为 3 倍后绘制在墙面上。
- 投影图案绘制在墙面的另一侧（穿过墙面），位置与源图案在垂直于墙面方向上居中对齐。投影图案紧贴墙面绘制。
- 墙面本身的 grey 像素保持不变。箭头和源图案在输出中保留。

Key insight: 箭头确定投影方向，但放大倍率由距离隐式编码——距离越远投影越大，这模拟了"光源越远、影子越大"的直觉。解题者需要先识别箭头方向确定投影侧，再度量距离确定缩放比例，最后正确放置放大后的图案。
</description>

<description>
对网格中的形状按面积排序，然后用排序后的位次决定每个形状内部填充哪种条纹方向。

Input structure:
- bg = 最常见颜色（如 azure）。网格中散布若干个不同大小的实心单色形状（颜色各异），每个形状为不规则但紧凑的连通区域。
- 网格角落有一个小型"方向图例"区域，包含三个用 grey 边框隔开的小格子，从左到右分别展示：水平条纹样本（交替一行颜色、一行 bg）、垂直条纹样本（交替一列颜色、一列 bg）、棋盘格样本（颜色和 bg 交替排列如棋盘）。三个样本分别对应排名第 1（最小）、第 2（中等）、第 3（最大）。若形状超过三个，则排名循环使用（第 4 个用水平条纹，第 5 个用垂直条纹，依此类推）。

Rule:
- 计算每个形状的面积（像素数量），按面积从小到大排序。面积相同时，位置更靠左上角（先比较行号，再比较列号）的排前面。
- 排名第 1 的形状（最小）内部替换为水平条纹纹理，排名第 2 的替换为垂直条纹，排名第 3 的替换为棋盘格，排名第 4 的回到水平条纹，以此循环。
- 条纹和棋盘格使用该形状原本的颜色与 bg 色交替绘制。条纹 / 棋盘格的相位从形状的 bounding box 左上角开始（左上角像素始终为形状原色）。
- 仅形状内部的像素被替换为纹理，形状外部不变。方向图例在输出中保留。

Key insight: 面积排序产生的位次决定纹理类型——解题者必须先通过视觉比较各形状大小并排序，再从图例中理解三种纹理的循环分配模式，两步推理共同决定每个形状的最终样式。
</description>
</new_puzzle>
