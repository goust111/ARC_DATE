<description>
根据彩色种子像素的颜色在封闭区域的边界墙上开门，然后从种子出发沿开门方向填充相邻区域。

Input structure:
- 背景为最常见的颜色（black）。
- 一种墙壁颜色（grey）构成若干封闭的矩形房间，房间之间共享墙壁段。
- 每个房间内部恰好有一个彩色种子像素（非背景、非墙壁色），颜色各不相同。
- 在网格的某个角落有一个颜色图例区域：若干 1×2 的小色块对，每对由一个种子颜色像素和一个方向指示颜色像素组成（red 表示向右开门，blue 表示向下开门，green 表示向左开门，yellow 表示向上开门）。

Rule:
- 首先读取图例，确定每种种子颜色对应的开门方向。
- 对每个房间，找到其种子像素，查图例得到开门方向。
- 在该房间边界的对应方向墙壁上，找到与种子像素同行（左/右方向）或同列（上/下方向）的那段墙壁像素，将其擦除为背景色（即"开门"）。
- 然后将种子颜色从开门处向外填充到相邻房间中所有背景像素（洪水填充），直到遇到墙壁或网格边界为止。
- 原房间内的种子像素保留，图例区域保持不变。

Key insight:
- 图例将颜色映射到方向，这是第一层需要归纳的规则；开门后的洪水填充是第二层——解题者必须先破解颜色-方向映射，才能理解为什么某些墙壁消失、某些区域被染色。
</description>

<description>
将散落的碎片拼回被遮挡的主图案中，拼接位置由碎片边缘轮廓与主图案缺口轮廓的吻合决定，拼入后碎片颜色需按旋转映射表重新着色。

Input structure:
- 背景为 black。
- 网格中央有一个大型多色图案（主图案），其中有若干矩形缺口区域被背景色填充（即"被挖走的洞"）。
- 主图案外散布着若干小型多色碎片，每个碎片的外形（非背景像素的轮廓）恰好与主图案中某个缺口的形状在某个旋转（0°/90°/180°/270°）下完全匹配。
- 网格边缘有一个 2×4 的颜色映射表：左列四个像素为四种输入颜色，右列四个像素为对应的输出颜色，从上到下分别对应旋转 0°、90°、180°、270°。

Rule:
- 对每个碎片，尝试四种旋转，找到与某个缺口形状完全匹配的旋转角度。
- 确定旋转角度后，查颜色映射表中该旋转角度对应的那一行，获取颜色替换对（输入色→输出色）。
- 将碎片旋转到正确角度后，把碎片中所有为该行"输入色"的像素替换为"输出色"，其余颜色保持不变。
- 将重新着色后的碎片放入对应缺口位置，碎片原位置擦除为背景色。

Key insight:
- 形状匹配确定旋转角度是第一层推理；旋转角度反向索引颜色映射表来决定重着色方案是第二层推理——碎片的最终颜色不仅取决于它本身的颜色，还取决于它需要旋转多少度才能拼入缺口。
</description>

Key insight:
- 导轨路径同时编码了两个信息：颜色首次出现的位置决定盖印坐标，首次出现的先后顺序决定盖印的叠加层次——解题者需要同时沿路径追踪顺序和坐标，才能还原最终的叠加图像。

<description>
在网格中找到多个"时钟"对象，根据每个时钟指针当前指向的方向，将指针旋转到下一个被占据的刻度位置。

Input structure:
- 背景为 black。
- 每个时钟是一个 5×5 的结构：中心一个像素为 grey（轴心），轴心的上、下、左、右各延伸 2 格形成十字形刻度盘（共 8 个刻度位置，均为 grey）。
- 在 8 个刻度位置中，有若干个被彩色像素替换（称为"占据的刻度"），其余保持 grey。这些彩色刻度的颜色各不相同。
- 从轴心向外延伸恰好 1 格处，有一个与某彩色刻度同色的像素作为"指针"——指针所在位置必定是十字刻度盘上的一个内圈位置（上/下/左/右距轴心 1 格处）。

Rule:
- 对每个时钟，找到指针像素（与某个彩色刻度同色且距轴心 1 格的像素）。
- 确定指针当前指向的方向（上/右/下/左之一）。
- 按顺时针顺序（上→右→下→左→上…），从当前方向的下一个方向开始，找到下一个有彩色像素（非 grey）的刻度方向。
- 将指针移动到新方向：在新方向距轴心 1 格处放置新刻度颜色的像素，原指针位置恢复为 grey。
- 如果新方向的内圈位置（距轴心 1 格）原本就是彩色刻度，则指针放在该位置并保留该颜色（指针与刻度重合）。

Key insight:
- 解题者需要识别指针（通过颜色匹配与位置区分），然后理解顺时针"跳到下一个被占据的刻度"的旋转规则——颜色匹配建立指针-刻度关联是第一层，顺时针跳跃到下一个非空刻度是第二层。
</description>

<description>
将网格中每个多色对象沿其唯一对称轴折叠，两半重叠时用"胜出规则"决定每个像素的最终颜色，胜出规则由网格边缘的优先级条编码。

Input structure:
- 背景为 black。
- 网格中有若干互不相邻的多色对象（4-连通分量），每个对象恰好有一条对称轴（水平或垂直），但对称轴两侧的像素颜色不完全相同。
- 网格最下方一行是一个"优先级条"：由若干不同颜色的像素从左到右排列（不含背景色），表示颜色优先级从高（左）到低（右）。

Rule:
- 对每个对象，找到其唯一的几何对称轴（即像素位置关于该轴对称，但颜色可以不同）。
- 将对象沿对称轴折叠：对称轴一侧保持不动，另一侧翻折覆盖上去。
- 对于折叠后重叠的每对像素，如果两者颜色相同则保留该颜色；如果不同，查优先级条，保留优先级更高（更靠左）的颜色。
- 折叠后对象的尺寸缩小为原来的一半（沿对称轴方向减半），输出网格尺寸缩小以紧密包含所有折叠后的对象（对象间相对位置保持不变）。
- 优先级条不出现在输出中。

Key insight:
- 找到对称轴需要忽略颜色只看形状，这是第一层推理；折叠后通过外部优先级条解决颜色冲突是第二层推理——对称轴的发现依赖几何直觉，而颜色冲突的解决依赖对优先级编码的归纳。
</description>

<description>
识别网格中被"信封"包裹的"信件"图案，根据信封开口方向将信件抽出并平移到信封外部。

Input structure:
- 背景为 black。
- 网格中有若干"信封"对象：每个信封是一个单色矩形框（只有边框，内部为背景色），但矩形的某一条边缺失（即开口）。
- 每个信封内部包含一个多色小图案（"信件"），信件不接触信封边框。
- 信封外部、远离开口的一侧有一个与信封同色的单像素"邮戳"标记。

Rule:
- 对每个信封，识别其矩形框缺失的那条边，确定开口方向（上/下/左/右）。

Key insight:
- 开口方向的判定（哪条边缺失）是视觉直觉层面的观察；邮戳的作用不是决定方向，而是作为干扰项让解题者区分"信封颜色的边框"和"邮戳标记"——真正的推理在于发现信件总是沿开口方向被"抽出"，且平移距离恰好让信件完全脱离信封。

<description>
在网格中找到若干"齿轮"对象，根据齿轮间的啮合关系传递旋转方向，最终用旋转后的齿轮图案替换原图案。

Input structure:
- 背景为 black。
- 每个齿轮是一个由单一颜色构成的十字形（中心 3×3 实心方块加上四个方向各突出 1 个像素的"齿"），总共 13 个像素。不同齿轮颜色不同。
- 齿轮的十字形不完全对称：四个齿中恰好有一个齿被替换为 maroon 色（"标记齿"），用于指示齿轮当前朝向。
- 某些齿轮的齿与相邻齿轮的齿之间恰好间隔 1 个背景像素（即"啮合"状态）。
- 恰好有一个齿轮的中心 3×3 方块中央像素为 yellow（"驱动齿轮"），其余齿轮中央为该齿轮自身颜色。

Rule:
- 找到驱动齿轮（中央为 yellow 的齿轮），它的旋转方向固定为顺时针 90°。
- 对于与驱动齿轮啮合的齿轮，其旋转方向为逆时针 90°（啮合齿轮旋转方向相反）。
- 旋转方向沿啮合链传递：每经过一次啮合，旋转方向翻转。
- 对每个齿轮，将其整个十字形图案（包括标记齿）绕自身中心旋转对应的 90° 方向。
- 不与任何齿轮啮合的孤立齿轮保持不动。

Key insight:
- 啮合关系的判定（齿间隔 1 像素）是第一层推理；旋转方向沿啮合链交替传递是第二层推理；标记齿的位置变化是验证旋转结果的视觉线索——解题者必须先建立啮合图，再沿链传播旋转方向，才能得到正确的输出。
</description>

<description>
网格中有若干条不同颜色的路径和一组"过滤门"，每条路径穿过过滤门后颜色发生变化，变化规则由门的颜色决定。

Input structure:
- 背景为 black。
- 若干条单像素宽的水平或垂直彩色路径穿过网格，路径颜色各不相同。
- 网格中有若干条垂直或水平的 azure 色细线横跨整个网格宽度或高度，作为"过滤门"。过滤门与路径垂直相交。
- 每个过滤门上、在非路径交叉的位置处，有一个小型 2×1 的颜色对标记（两个像素上下或左右排列），上/左像素为某颜色 A，下/右像素为某颜色 B，表示"颜色 A 经过此门变为颜色 B"。

Rule:
- 识别所有路径及其方向（水平或垂直）。
- 识别所有过滤门及门上的颜色对标记。
- 每条路径从起点（网格边缘）出发，每次穿过一个过滤门时：检查门上所有颜色对标记，如果路径当前颜色等于某标记的颜色 A，则路径在穿过门之后变为颜色 B。
- 如果路径当前颜色不匹配门上任何标记的颜色 A，则路径颜色不变。
- 路径穿过多个门时，颜色变换依次累积。
- 过滤门线条本身和颜色对标记在输出中保持不变。

Key insight:
- 解题者首先需要识别门上的颜色对标记作为"如果-则"转换规则（第一层推理），然后需要理解路径颜色的变换是依次累积的——前一个门的输出颜色成为后一个门的输入颜色（第二层推理），这使得最终颜色取决于路径穿过门的完整序列。
</description>
</new_puzzle>
