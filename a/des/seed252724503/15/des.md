- `description`：根据每个封闭区域内部散落的彩色种子像素的颜色，从配对图例中查找对应的填充纹理，将该纹理平铺填满整个封闭区域。

- `Input structure`：
  - 背景为主色（如 black）。
  - 网格中有若干由同一颜色（如 grey）线段围成的封闭区域，区域形状为矩形或 L 形等简单多边形。
  - 每个封闭区域内部恰好有一个彩色"种子"像素（颜色各不相同，如 red、blue、green 等），其余内部像素为背景色。
  - 网格的一侧（如最左列或最上方若干行）有一组图例条目：每个条目由一个 1x1 颜色色块和紧邻的一个 2x2 或 3x3 纹理小方块组成，色块颜色与某个种子颜色一一对应，纹理由两种颜色构成。

- `Rule`：
  - 识别每个封闭区域内部的种子像素颜色。
  - 在图例中找到与该种子颜色匹配的条目，提取其纹理方块。
  - 将该纹理以左上角对齐的方式平铺填充整个封闭区域的内部（覆盖种子像素和背景像素），纹理超出区域边界的部分裁剪掉。
  - 灰色边界线和图例区域保持不变。

- `Key insight`：种子像素不是被保留的内容，而是一个索引键——它指向图例中的纹理模板；解题者必须先建立"颜色→纹理"的映射关系，再对每个区域执行纹理填充，这是两层独立的推理。
</new_puzzle>

<new_puzzle>
- `description`：将网格中散落的同色碎片拼合还原为完整形状，然后按照每个完整形状内部包含的孔洞数量从少到多，在输出网格中从左到右排列完整形状。

- `Input structure`：
  - 背景为主色（如 black）。
  - 网格中有若干颜色不同的碎片对象（4-连通区域），每种颜色恰好出现两个碎片。
  - 同色的两个碎片可以无重叠地拼合成一个矩形或简单凸形状（类似拼图），拼合时一个碎片需要平移（不旋转）到另一个碎片旁，使两者的凹凸边缘互补吻合。
  - 拼合后的完整形状内部可能包含 0、1 或多个单像素孔洞（背景色像素被形状像素完全包围）。

- `Rule`：
  - 对每种颜色，找到其两个碎片，将其中一个平移拼合到另一个上，形成完整形状。拼合方式唯一——只有一种平移方向能使两个碎片的边缘完全互补。
  - 数出每个拼合后完整形状内部的孔洞数量。
  - 在输出网格中，将所有完整形状按孔洞数量从少到多（左到右）排列，形状之间间隔一列背景色，所有形状顶部对齐到第一行。

- `Key insight`：碎片的空间分布是干扰信息——真正的第一层推理是识别同色碎片的互补拼合关系；第二层推理是发现排列顺序由拼合后才可见的孔洞数量决定，而非由颜色、大小或原始位置决定。
</new_puzzle>

- `description`：每个彩色对象沿着与自身形状缺口方向相反的方向滑动，滑动距离等于该对象所在行（或列）上同色标记点的数量，标记点在滑动后消失。

- `Input structure`：
  - 背景为主色（如 orange）。
  - 网格中有若干个单色的 3x3 方块对象，每个方块恰好缺少一个边缘像素（即 3x3 区域中有 8 个像素着色、1 个像素为背景色），缺口位于上、下、左、右四个边的中间位置之一。
  - 在每个方块所在的同一行（若缺口在左或右）或同一列（若缺口在上或下），散布着若干个与该方块同色的孤立标记像素（1x1），标记像素不与方块相邻。

- `Rule`：
  - 确定每个方块的缺口方向（上、下、左、右）。
  - 滑动方向为缺口的对侧方向（缺口在左则向右滑，缺口在上则向下滑，以此类推）。
  - 数出与该方块同色的、位于同一行或同一列（取决于滑动轴）的标记像素数量 N。
  - 将方块沿滑动方向平移 N 个像素。
  - 清除所有标记像素（替换为背景色）。

- `Key insight`：解题需要三层推理——第一层是从缺口位置推断滑动方向（缺口是"推力入口"，物体向对侧移动）；第二层是发现滑动距离由同色同轴标记点的数量控制；第三层是标记点在输出中消失，证实它们是"燃料"而非装饰。
</new_puzzle>

- `description`：在由分隔线划分的多个子面板中，每个面板包含一个形状和一个箭头标记；将形状沿箭头方向投影到面板边界，然后用投影区域的互补形状（面板内去掉原形状投影后的剩余部分）替换原形状。

- `Input structure`：
  - 网格被单色分隔线（如 grey）划分为若干个大小相同的矩形子面板（如 6x6）。
  - 每个面板的背景为 black。
  - 每个面板内有一个由单一前景色构成的小型形状（如 3x2 的 L 形），以及一个由另一种颜色（如 red）构成的 1x1 箭头标记像素，箭头标记位于面板的某个边缘（上边缘、下边缘、左边缘或右边缘的中间位置）。

- `Rule`：
  - 箭头标记所在的边缘指示投影方向：标记在上边缘表示向上投影，在右边缘表示向右投影，以此类推。
  - 将形状沿投影方向压缩到面板的该侧边界：即统计形状在垂直于投影方向的每一行（或列）上占据的像素数，将这些像素紧贴边界重新排列。
  - 计算面板内沿投影轴方向的每一列（或行）的总高度（或宽度），减去形状占据的像素数，得到互补高度。
  - 输出中，原形状被替换为其互补形状：在投影方向的对侧，用原形状的颜色填充互补高度的像素。
  - 清除箭头标记像素。

- `Key insight`：箭头标记不是指示移动方向，而是指示投影轴——解题者需要理解"投影后取互补"这一非直觉操作；形状的每一列（或行）的像素数与面板对应维度之和为常数，这是规则的核心不变量。
</new_puzzle>

- `description`：网格中的多个同心框架按照框架厚度从外到内重新嵌套排列，最厚的框架成为最外层，最薄的成为最内层，每层框架的颜色保持不变。

- `Input structure`：
  - 背景为主色（如 black）。
  - 网格中央有若干层同心矩形框架（空心矩形环），每层颜色不同（如 red、blue、green、yellow）。
  - 每层框架的厚度（边框宽度）不同，可以是 1、2 或 3 个像素。
  - 在输入中，这些框架从外到内的排列顺序是随机的（即厚度不是单调递增或递减的）。

- `Rule`：
  - 识别每层框架的颜色和厚度（通过观察每层环的边宽度）。
  - 按厚度从大到小重新排列：最厚的框架放在最外层，最薄的放在最内层。
  - 重绘时，保持最外层框架的外边界位置不变，每层框架紧贴上一层框架的内边界绘制。
  - 最内层框架围成的中心区域填充背景色。

- `Key insight`：输入中框架的嵌套顺序与厚度无关，这是干扰——解题者必须先独立测量每层框架的厚度（需要将连续的同色像素行数与框架概念关联），然后发现输出的排列规则是"厚度降序嵌套"。颜色本身不决定顺序，厚度才是排序键。
</new_puzzle>

- `description`：将网格中每个彩色对象视为一枚"印章"，根据该对象旁边的小色块指示的目标颜色，在网格中所有该目标颜色的矩形区域上盖印该印章的形状。

- `Input structure`：
  - 背景为主色（如 black）。
  - 网格中有若干个小型彩色前景对象（形状各异，如 T 形、L 形等），每个对象由单一颜色构成。
  - 每个对象的正上方（或正下方）紧邻一个 1x1 的"指示色块"，颜色与对象本身不同。
  - 网格中另有若干个纯色填充的矩形区域，颜色与某些指示色块的颜色相同。

- `Rule`：
  - 对每个前景对象，读取其紧邻的指示色块的颜色 C。
  - 找到网格中所有颜色为 C 的矩形区域。
  - 将该对象的形状（保持原始朝向）以矩形区域的中心为对齐点，用对象自身的颜色盖印到每个匹配的矩形区域上。印章像素覆盖矩形像素，矩形中未被覆盖的部分保持颜色 C。
  - 原始对象和指示色块从原位置清除（替换为背景色）。

- `Key insight`：指示色块是"目标选择器"而非装饰——解题者需要先建立"印章形状 + 指示颜色 → 目标矩形"的三角映射关系，再执行居中盖印操作。两层推理缺一不可：仅观察印章或仅观察矩形都无法推断完整规则。
</new_puzzle>

  - 右面板中有若干个孤立的 2x1 彩色标记，颜色与左面板的路径颜色一一对应，标记位于右面板的边缘位置。

- `Rule`：
  - 将左面板每条路径的起点标记与右面板中同色的标记配对。

  - 从右面板的标记位置出发，沿标记朝向面板内部的方向，按照相同的转弯序列绘制镜像路径（左右翻转：原来的左转变右转，右转变左转），路径颜色与标记颜色相同。
  - 左面板保持不变。

- `Key insight`：解题者不能简单地复制或平移路径——必须提取路径的抽象"转弯指令序列"，然后在镜像坐标系中重新执行这些指令。关键推理在于识别左右镜像关系应用于转弯方向而非像素坐标。

<new_puzzle>
- `description`：网格中散落着若干对同色对象，每对中一个是"模具"（封闭轮廓），另一个是"原料"（实心块）；将原料裁剪成模具内腔的形状，然后放入模具中。

- `Input structure`：
  - 背景为主色（如 azure）。
  - 网格中有若干种前景色，每种颜色恰好出现两个 4-连通对象。
  - 每对同色对象中，一个是封闭的空心轮廓（环形，内部为背景色），另一个是面积大于或等于轮廓内腔面积的实心块。
  - 两个同色对象在网格中的位置不相邻。

- `Rule`：
  - 对每种颜色，识别哪个对象是空心轮廓（模具）、哪个是实心块（原料）。判断标准：包含背景色孔洞的是模具。
  - 提取模具内腔的形状（即被轮廓包围的背景色区域的形状）。
  - 将原料对象从原位置清除。
  - 用原料的颜色填充模具的内腔区域（即把内腔从背景色改为该前景色），使模具变为完全实心。

- `Key insight`：同色对象的角色不对称——解题者必须先区分"模具"与"原料"（通过孔洞的有无），然后理解变换的本质是"原料消失 + 模具被填满"，而非任何形式的移动或拼接。原料的具体形状是干扰信息，输出只取决于模具内腔的形状。
</new_puzzle>
