- `description`：根据彩色种子像素的颜色在对应颜色的框架内部生长出枝条，枝条方向由种子相对于原始框架中心的象限决定，长度由该方向上分配的种子数决定。

- `Input structure`：
  - 背景色 = 最常见颜色。网格中散布若干单色矩形框架（仅边框，内部为背景色），每个框架用不同颜色绘制（如 red、blue、green 等）。
  - 框架内部散布若干单像素"种子"，种子颜色与所在框架的边框颜色不同，但种子颜色一定是网格中某个其他框架的边框颜色。
  - 每个框架的中心可通过其边框的几何中点直观确定。

- `Rule`：
  - 第一层：将每颗种子按其颜色归属到对应颜色的框架——即种子颜色与目标框架边框颜色一致。这确定了每个框架要生长的枝条数量（= 被归属到该框架的种子总数）。
  - 第二层：在每个框架内部，从框架的几何中心点出发，向四个基本方向（上、下、左、右）生长枝条。枝条分配规则：种子位于其原始所在框架中心的哪个象限（左上→向上，右上→向右，左下→向左，右下→向下），就为目标框架在该方向分配一根枝条。
  - 每个方向上若分配了 N 根枝条，则从目标框架中心沿该方向画一条长度为 N 像素的线段，颜色使用目标框架的边框颜色。
  - 种子像素在输出中被移除；框架边框保留不变。

- `Key insight`：种子颜色决定目标框架（跨框架映射），种子在其原始框架中的象限位置编码了枝条在目标框架中的生长方向——解题者必须同时发现"颜色归属"和"象限→方向"两层隐含规则。
</new_puzzle>

- `description`：将散落的彩色碎片按颜色配对后凹凸互锁拼合成矩形，再将所有矩形按面积从大到小水平排列在输出网格中。

- `Input structure`：
  - 背景色 = 最常见颜色。网格中散布若干小型不规则形状的彩色碎片（连通分量）。
  - 碎片总是成对出现：每对碎片颜色相同，且恰好有两个同色碎片。
  - 每个碎片的边界有凹凸结构——一个碎片的凸出部分恰好能嵌入同色配对碎片的凹陷部分，两者拼合后形成一个紧凑的矩形。
  - 碎片在输入中的朝向可能需要旋转 0°/90°/180°/270° 才能完成互锁。

- `Rule`：
  - 第一层：按颜色找到配对碎片。对于每对同色碎片，尝试四种旋转，找到使两者凹凸互补、拼合为矩形的唯一旋转方案。拼合时一个碎片保持不动，另一个旋转后平移，使凸部填入凹部，合并为无缝矩形。
  - 第二层：将所有拼合后的矩形按面积（像素数）从大到小排序。在输出网格中，从左上角开始，按排序顺序水平依次排列各矩形，矩形之间间隔一列背景色，所有矩形顶部对齐在第一行。
  - 输出网格的高度 = 最大矩形的高度，宽度 = 所有矩形宽度之和 + 间隔列数。

- `Key insight`：解题者必须先发现同色碎片的凹凸互补关系（需要尝试旋转才能拼合，而非简单平移），再发现拼合结果按面积排序输出——配对拼合机制和排列顺序都需要从样例中独立归纳。
</new_puzzle>

- `description`：沿彩色路径传递信号，信号在 3x3 交叉节点处根据节点内部标记像素的位置选择转向，最终按到达顺序为路径终端重新着色。

- `Input structure`：
  - 背景色 = black。网格中有若干条单像素宽的彩色路径（由同一颜色的像素组成直线段），路径在某些位置交叉。
  - 每个交叉点是一个 3x3 的 grey 方块，方块内部的 3x3 区域中恰好有一个非 grey 像素作为"方向标记"，其位置编码转向规则。
  - 网格边缘有若干 green 像素作为"信号源"，每个信号源恰好位于一条路径的端点上。
  - 路径的另一端（非信号源端）以 maroon 像素标记为"终端"。

- `Rule`：
  - 每个信号从 green 信号源出发，沿路径颜色前进。
  - 当信号到达一个 3x3 grey 交叉节点时，查看节点内方向标记像素的相对位置：标记位于 3x3 区域中心的上方、下方、左方或右方的边格中，信号就从节点沿该方向的路径离开。若标记在四个角格之一，则信号按如下规则离开：左上角→向上离开，右上角→向右离开，右下角→向下离开，左下角→向左离开。
  - 信号沿新路径继续前进直到遇到下一个交叉节点或终端。
  - 所有信号同时出发，每步前进一格。当信号到达 maroon 终端时，将终端像素重新着色：第一个到达的终端变为 red，第二个变为 blue，第三个变为 yellow，依此类推。同时到达则按终端行号小者优先。
  - 输出中路径和交叉节点保持不变，仅终端颜色改变。

- `Key insight`：解题者需要先破解 3x3 节点内方向标记的位置→转向编码规则（角格映射非平凡），然后模拟多条信号的并行传播以确定到达顺序——转向解码和时序竞争构成两层独立的推理挑战。
</new_puzzle>

- `description`：识别被表格分隔线颜色隐式分组的单元格区域，在每个分组内部根据"投票"像素的多数颜色统一重绘所有非边框像素。

- `Input structure`：
  - 背景色 = 最常见颜色。网格被 grey 线条划分为若干矩形单元格（类似表格），每个单元格内部包含若干彩色像素散布在背景上。
  - 部分相邻单元格之间的 grey 分隔线被替换为某种彩色线段（如 red、blue、orange 等），彩色线段长度和位置与原 grey 分隔线相同。
  - 每个单元格内部的彩色像素可能有多种颜色。

- `Rule`：
  - 第一层（分组识别）：将 grey 线条视为隔断，彩色线条视为连通桥。若两个相邻单元格之间的分隔线是彩色的（非 grey），则这两个单元格属于同一分组。通过传递性，所有被彩色线段直接或间接相连的单元格构成一个分组。被 grey 线完全包围的单元格自成一组。
  - 第二层（投票重绘）：在每个分组中，统计分组内所有单元格中出现的非背景、非 grey 的彩色像素。找到出现次数最多的颜色（多数色）。将分组内所有单元格中的所有非背景像素统一替换为该多数色。
  - 连接线段的颜色本身不参与投票计数，也不被修改。Grey 线段和彩色连接线段在输出中保持不变。

- `Key insight`：表格的分隔线颜色不仅是装饰——它编码了单元格之间的分组关系（彩色=连通，grey=隔断）。解题者必须先发现这一隐含的分组规则，再发现每组内的多数投票重绘机制，两层推理相互独立且都非显然。
</new_puzzle>

- `description`：根据"模具"形状在色带上冲压出彩色裁片，再按模具内标记像素的颜色所指示的层叠优先级将裁片叠放到输出画布上。

- `Input structure`：
  - 背景色 = black。网格左半部分包含若干水平"色带"，每条色带占据若干行，内部填充某种颜色构成的水平条纹图案（如交替的两种颜色条纹），各色带之间用 grey 水平线分隔。
  - 网格右半部分散布若干"模具"——每个模具是一个由 grey 像素构成边框的矩形区域，内部轮廓为不规则形状的中空区域（背景色填充）。模具内部恰好有一个非背景、非 grey 的单像素标记。
  - 每个模具的内部高度（不含 grey 边框）恰好等于某条色带的高度。

- `Rule`：
  - 第一层（模具-色带配对）：每个模具通过其内部高度与色带配对——内部高度等于色带高度的那条色带就是该模具的源色带。
  - 第二层（冲压裁片）：将模具的内部中空形状作为遮罩，叠放在配对色带上（左对齐），从色带中"冲压"出对应形状的彩色裁片——裁片保留色带在对应位置的颜色图案。
  - 第三层（层叠放置）：模具内部标记像素的颜色决定层叠顺序。观察所有模具的标记颜色，在输入网格中这些标记颜色也恰好出现在左侧色带的条纹中——条纹中某颜色在色带中从上到下首次出现的行越靠上，对应的裁片越先放置（在底层）。所有裁片放置在输出画布的同一位置（左上角对齐），后放的裁片覆盖先放裁片的重叠部分。
  - 输出网格大小等于最大裁片的边界框大小，背景为 black。

- `Key insight`：解题者需要依次发现三层规则——高度匹配确定色带来源、模具形状冲压色带图案、标记颜色通过色带中的出现顺序编码层叠优先级。每一层都需要独立的归纳推理，且三层共同作用才能确定最终输出。
</new_puzzle>

- `description`：在网格中推断隐藏的对称轴，利用边缘锚点对建立跨轴颜色映射表，最终通过映射修复对称图案中的缺失区域。

- `Input structure`：
  - 背景色 = 最常见颜色。网格中有一个大型多色图案，该图案接近于关于某条轴（水平或垂直）的镜像对称，但其中一侧有若干像素缺失（显示为背景色）。
  - 对称轴本身不可见（没有显式画出），需要从图案的近似对称性推断其位置。
  - 在网格的边缘处，有若干"锚点对"——每对由紧邻的两个像素组成，排列方向与对称轴垂直。一个像素的颜色出现在对称轴一侧的图案中，另一个像素的颜色出现在另一侧。这些锚点对定义了跨轴的颜色映射关系。

- `Rule`：
  - 第一层（定位对称轴）：找到使图案最大程度满足镜像对称的那条唯一轴线（某一行或某一列的中线）。除了缺失像素和颜色映射差异外，图案关于该轴对称。
  - 第二层（建立颜色映射）：利用边缘的锚点对建立颜色映射关系。每个锚点对中，靠近对称轴左侧/上方的像素颜色 A 对应右侧/下方的像素颜色 B。映射可能不是恒等映射——即镜像两侧系统性地使用不同颜色。
  - 第三层（填补缺失）：对于缺失侧的每个背景色像素，找到其关于对称轴的镜像位置的像素颜色，通过颜色映射表转换后填入。非缺失的像素保持不变。
  - 锚点对本身在输出中保留不变。

- `Key insight`：这不是简单的镜像修复——解题者必须先从近似对称性中找到隐含的对称轴位置，再从边缘锚点中发现镜像两侧存在系统性的颜色替换关系，最后才能正确填补缺失区域。三层推理环环相扣。
</new_puzzle>

<new_puzzle>
- `description`：将网格中由墙壁分隔的封闭区域视为容器，根据容器共享墙壁上不同颜色"阀门"的单向/双向通行规则，模拟液体从初始容器级联扩散，填充所有可达容器。

- `Input structure`：
  - 背景色 = black（表示容器内的空腔）。网格中有 grey 像素构成的墙壁，将空间划分为若干封闭的矩形区域（容器）。
  - 其中一个容器内部完全填充了某种颜色（如 blue），代表初始液体源。
  - 容器之间的共享墙壁上，某些位置有一个像素宽的"阀门"——即墙壁上的一个非 grey、非背景色的像素，替代了该位置原本的 grey 墙壁像素。
  - 阀门有两种颜色：red 阀门表示"仅向下通过"（液体只能从上方容器向下流过该阀门进入下方容器），green 阀门表示"双向通过"（液体可以在阀门两侧容器之间自由流动）。
  - red 阀门只出现在水平墙壁上（容器的上下边界），green 阀门可出现在任意方向的墙壁上。

- `Rule`：
  - 液体从初始填充的容器开始扩散。
  - 对于当前含有液体的每个容器，检查其所有墙壁上的阀门：
    - green 阀门：液体流入阀门另一侧的相邻容器（无论方向）。
    - red 阀门：仅当阀门位于当前含液容器的底部墙壁上时，液体才通过该阀门向下流入下方容器。若含液容器在阀门下方，液体不能向上通过 red 阀门。
  - 持续扩散直到没有新容器被填充为止。
  - 输出中，所有被液体到达的容器内部填充为液体颜色（与初始容器相同），未到达的容器保持 black。所有阀门像素保持原始颜色不变，grey 墙壁保持不变。

- `Key insight`：解题者需要先识别出墙壁上的彩色像素是功能性"阀门"而非装饰，然后发现两种阀门颜色代表不同的流通规则（red 仅允许向下单向通过，green 允许双向通过），最后模拟液体经多个阀门的级联扩散路径。阀门颜色的方向性语义和级联传播构成两层核心推理。
</new_puzzle>
