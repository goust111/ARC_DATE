描述：根据封闭区域内"种子色块"的颜色，从区域边界的缺口处向外生长出与种子面积等长的彩色枝条，枝条方向由缺口朝向决定，颜色由种子决定。

Input structure:
- 背景色为 black。网格中散布若干由 grey 像素构成的封闭矩形围栏（边框厚度为 1 像素）。
- 每个围栏的某一条边上有一个连续缺口（缺口宽度 1-3 像素），缺口处边框像素被移除，露出 black 背景。
- 每个围栏内部恰好有一个由单一非 grey、非 black 颜色填充的小方块（1x1 至 2x2），称为"种子色块"。
- 围栏内部除种子色块外均为 black。

Rule:
- 对每个围栏，找到其边框上的缺口位置和朝向（上/下/左/右）。
- 从缺口的每个像素位置出发，沿缺口朝外的方向（即远离围栏内部的方向）画一条射线。射线长度等于该围栏内种子色块的像素总数（即种子面积）。
- 射线使用种子色块的颜色绘制，遇到非 black 像素时停止（不覆盖）。
- 围栏本身和种子色块保持不变。

Key insight：缺口的宽度决定了枝条的"根部宽度"（即并行射线的数量），种子色块的面积决定了枝条的长度，种子的颜色决定了枝条的颜色——三个属性分别来自三个不同的视觉线索。
</new_puzzle>

<new_puzzle>
描述：将散落的彩色碎片按颜色配对后叠合，碎片重叠区域变为第三种颜色（由网格角落的调色板指定），非重叠部分保留原色。

Input structure:
- 背景色为 black。网格中散布若干小型彩色精灵（sprite），每种非 black 颜色恰好出现两个精灵，形状可能不同。
- 网格的一个角落（例如左上角）有一个小型调色板区域：由一行或一列彩色像素对组成，每对包含两个相邻像素——左侧（或上方）像素的颜色表示"输入配对色"，右侧（或下方）像素表示"混合后输出色"。
- 同色的两个精灵在水平或垂直方向上对齐（共享至少一行或一列）。

Rule:
- 找出所有同色精灵对。对于每对同色精灵，将其中一个沿共享的行或列方向平移，直到两个精灵的边界框完全重合（较小的精灵对齐到较大精灵的中心）。
- 重叠位置（两个精灵都有像素的格子）用调色板中该颜色对应的混合输出色填充。
- 仅有一个精灵占据的像素保留原色。
- 平移后，原位置的精灵被擦除。最终输出中调色板区域也被擦除（变为 black）。

Key insight：解题需要两层推理——第一层是识别同色配对并确定平移方向（利用行列对齐关系），第二层是通过角落调色板查表确定重叠区域的新颜色，而非简单的颜色混合直觉。
</new_puzzle>

Input structure:
- 背景色为 black。网格分为左右两个区域，由一列 grey 像素分隔。
- 左侧区域包含若干小型彩色精灵（"钥匙"），每个钥匙由单一非 black 颜色绘制，形状不规则但连通。
- 右侧区域包含若干由 grey 像素围成的矩形框（"锁"），每个锁框的内部为 black，且锁框的某一条外边上有一个单像素的彩色标记（颜色与某把钥匙相同），该标记所在的边称为"插入边"。
- 每个锁框的内部尺寸恰好能容纳对应钥匙的边界框。

Rule:
- 通过颜色匹配将每把钥匙与一个锁配对。
- 确定锁的插入边（彩色标记所在的边）。

- 将翻转后的钥匙放入锁框内部，紧贴插入边一侧对齐。
- 钥匙使用其原始颜色绘制。左侧区域的原始钥匙被擦除。彩色标记保留。

Key insight：插入边不仅决定了钥匙在锁内的位置（贴近哪一侧），还决定了镜像翻转的轴向——解题者必须同时推断出"方向→翻转轴"和"颜色→配对"两层映射关系。
</new_puzzle>

描述：沿灰色管道网络传播颜色信号，在管道交叉口根据优先级规则决定胜出颜色，最终为每段管道着色。

Input structure:
- 背景色为 black。网格中有一个由 grey 像素构成的正交管道网络（管道宽度 1 像素）。
- 管道网络包含若干 T 形或十字形交叉口。
- 管道的若干末端（度为 1 的端点）各紧邻一个 2x2 的彩色方块（"信号源"），方块颜色各不相同。每个信号源恰好与一个管道端点 4-连通相邻。
- 网格的一个角落有一个小型"优先级图例"：由若干彩色像素从上到下（或从左到右）排列，表示颜色优先级从高到低。

Rule:
- 每个信号源的颜色沿其相邻管道端点向整个管道网络扩散，将经过的 grey 像素染成该颜色。
- 当两种颜色在同一段管道上相遇（从交叉口的不同分支进入同一分支时），查阅优先级图例：优先级高的颜色覆盖优先级低的颜色，继续沿该分支传播。
- 最终网络中每段管道恰好被一种颜色染色；信号源方块保持不变。优先级图例保持不变。

Key insight：解题的第一层是识别管道网络的拓扑结构和各信号源的扩散路径；第二层是发现角落图例编码了颜色优先级，从而在交叉口冲突时确定哪种颜色胜出——仅凭拓扑结构无法确定最终着色，必须结合优先级查表。

描述：网格中的多个图案区域各缺失一块拼图碎片，碎片散落在网格空白处；通过形状匹配将碎片归位后，用碎片内隐藏的单色像素数量决定整个区域的边框重绘颜色。

Input structure:
- 背景色为 black。网格中有若干由不同颜色绘制的矩形边框（厚度 1 像素），每个边框内部填充了与边框不同的另一种颜色形成实心区域。
- 每个矩形边框的某一段上有一个连续缺口（2-4 像素宽），缺口处边框像素被移除，露出内部填充色。
- 在网格其他位置（不与任何边框接触）散落着若干小型彩色碎片，每个碎片由与某个边框相同颜色的像素构成，碎片形状恰好能填补某个边框上的缺口。
- 每个碎片内部（被碎片像素包围的位置）可能嵌有 0-2 个 maroon 像素点。

Rule:
- 通过颜色和形状双重匹配，将每个碎片归入对应边框的缺口位置（碎片颜色 = 边框颜色，且碎片形状与缺口轮廓互补）。
- 将碎片放置到缺口处，修补边框使其完整闭合。
- 统计每个碎片中嵌入的 maroon 像素数量 N：
  - N = 0：该边框保持原色不变。
  - N = 1：该边框整体（包括刚填入的碎片）重绘为 azure。
  - N = 2：该边框整体重绘为 yellow。
- 碎片原始位置被擦除。maroon 像素不出现在最终输出中（被边框颜色或重绘颜色覆盖）。

Key insight：解题包含三个推理层——第一层是颜色匹配锁定碎片候选目标，第二层是形状互补确认碎片归位，第三层是碎片内隐藏的 maroon 像素计数驱动边框的全局重绘规则。前两层在视觉上较直观，但第三层需要解题者注意碎片内部不起眼的标记像素并归纳出计数→颜色的映射。
</new_puzzle>

<new_puzzle>
描述：根据围栏内填充色块的排列方向，将围栏外的附属精灵沿该方向复制排列，排列数量由围栏内色块数量决定。

Input structure:
- 背景色为 black。网格中有若干由 grey 像素构成的矩形围栏（边框厚度 1 像素）。
- 每个围栏内部有 2-4 个相同大小的单色方块，沿水平或垂直方向等距排列（方块之间间隔 1 像素 black），所有方块颜色相同但各围栏颜色不同。
- 每个围栏的外侧（紧贴围栏边框外部）附着一个小型精灵（由与围栏内色块不同的颜色绘制），精灵所附着的边决定了它的"锚定边"。

Rule:
- 对每个围栏，读取内部色块的排列方向（水平或垂直）和数量 N。
- 确定附属精灵的锚定边及其位置。
- 沿色块排列方向，从精灵当前位置开始，以精灵自身尺寸加 1 像素间距为步长，重复放置精灵共 N 次（包含原始精灵）。若原始精灵只有 1 个，则额外复制 N-1 个。
- 复制的精灵颜色改为围栏内色块的颜色，仅原始精灵保持其初始颜色。
- 围栏和围栏内部保持不变。

Key insight：解题者须先从围栏内部的色块排布中提取两个信息——方向和数量，再将这两个信息应用到围栏外的精灵复制操作中；同时还需注意复制品与原件的颜色差异规则（复制品采用围栏内色块的颜色），这构成了"内部编码→外部执行→颜色转换"的三层推理链。
</new_puzzle>

<new_puzzle>
描述：网格中每个彩色环形图案的缺口方向指示了一个"投射方向"，环的内部小图案沿该方向被投射到网格远处的接收框中，投射距离由环的层数决定。

Input structure:
- 背景色为 black。网格中有若干同心环形结构，每个由 1-3 层不同颜色的环嵌套而成（最外层环最大，每层厚度 1 像素，环为正方形空心框）。
- 每个环形结构的所有层在同一侧有一个对齐的 1 像素宽缺口（上/下/左/右之一），形成一个"开口方向"。
- 每个环形结构最内层的中心有一个 1x1 至 3x3 的小型彩色图案（"载荷"），颜色与各层环不同。
- 网格中还散布若干由 grey 像素绘制的空心小方框（"接收框"），内部为 black，每个接收框的内部尺寸恰好可容纳一个载荷。

Rule:
- 对每个环形结构，确定其缺口方向和环的层数 L。
- 从环形结构中心出发，沿缺口方向寻找第 L 个接收框（按与中心的距离排序，取第 L 近的那个；距离以"视觉上第几个"计，即沿该方向上遇到的第 L 个接收框）。
- 将载荷图案复制到该接收框内部（载荷颜色保持不变）。
- 环形结构本身保持不变；被填入载荷的接收框保留 grey 边框。

Key insight：需要三步推理——先从对齐的缺口识别投射方向，再数环的层数得到跳数 L，最后沿方向找到第 L 个接收框填入载荷。层数不是直接标记在环上的数字，而是需要解题者观察嵌套层级来确定。
</new_puzzle>
