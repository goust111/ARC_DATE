<description>
根据彩色锚点像素在封闭区域边框上的位置，选择对应的外部图案模板，将其旋转至锚点朝向后填入该区域内部。

Input structure:
- 背景为 black。网格中有若干由 grey 线段围成的封闭矩形区域（"房间"），每个房间的边框上恰好有一个非 grey、非 black 的彩色像素（"锚点"），锚点颜色各不相同。
- 网格的空白区域散布着若干小型图案块（"模板"），每个模板由单一非 black 颜色绘制，模板的颜色与某个房间锚点的颜色一一对应。
- 每个模板的形状为矩形，且恰好能放入对应房间的内部空间。模板内部包含该颜色像素和 black 像素构成的图案。

Rule:
- 对每个房间，找到边框上锚点的颜色 C，在外部找到颜色为 C 的模板。
- 锚点在边框上的位置决定旋转方式：锚点在上边框 → 模板不旋转（原始朝向为"顶部"）；锚点在右边框 → 模板顺时针旋转 90 度；锚点在下边框 → 旋转 180 度；锚点在左边框 → 逆时针旋转 90 度。
- 将旋转后的模板放入房间内部（grey 边框内的区域），模板中的彩色像素覆盖原有 black 背景，模板中 black 像素保持为 black。
- 输出网格与输入网格大小相同；外部模板从原位置被擦除（变为 black），房间边框和锚点保持不变。

Key insight: 锚点的颜色是"钥匙"用于匹配模板，而锚点在边框的哪一侧则是"旋钮"用于决定模板的旋转角度——解题者需要同时发现颜色匹配和位置编码旋转这两层规则。
</description>

<description>
在网格中识别由墙壁围成的多个连通走廊，根据走廊中散布的彩色标记像素确定走廊的"流向"，然后将走廊内所有标记像素沿流向推到尽头并按颜色分层堆叠。

Input structure:
- 背景为 black。grey 像素构成墙壁，墙壁将网格分隔为若干条宽度为 1 的走廊（水平或垂直方向的连通通道）。
- 每条走廊中散布着若干彩色像素（非 black、非 grey），颜色可能有多种。
- 每条走廊的两个端点之一紧邻一个 maroon 像素（位于墙壁上或走廊的尽头外侧），标记该端为"出口端"。

Rule:
- 确定每条走廊的方向（水平或垂直）以及出口端的位置（通过 maroon 标记判断）。
- 走廊中所有彩色像素沿**远离出口端**的方向滑动，在走廊的**非出口端**尽头堆叠。
- 堆叠顺序：按照像素原本离非出口端的距离从近到远排列（原本就靠近非出口端的像素在最里面）。
- 堆叠后，走廊中空出的位置变为 black。Maroon 标记保持不变，墙壁保持不变。

Key insight: 解题者需要先识别出 maroon 标记与走廊端点的关联来确定"出口端"，然后理解像素是反向（远离出口）推动的——maroon 标记的含义是"此端为出口，内容远离此端堆积"，这一反直觉的方向编码构成核心推理层。
</description>

<description>
将网格中多个彩色对象按照它们各自内部"缺口"的形状进行分组配对，然后让配对的两个对象互相交换颜色。

Input structure:
- 背景为 azure。网格中有偶数个矩形区域，每个区域由一种纯色填充（可用颜色包括 red、green、blue、yellow、magenta、orange），但区域内部各有一个由背景色 azure 构成的小型"缺口"（形状为不规则的连通区域，占据区域内的若干像素）。
- 每个矩形区域的外轮廓大小可以不同，但缺口的形状在所有区域中恰好两两相同（经过平移后完全匹配，不需要旋转或翻转）。
- 没有两个区域具有相同的颜色。

Rule:
- 提取每个矩形区域内部缺口的形状（相对于区域左上角的坐标集合）。
- 找到缺口形状完全相同的两个区域，将它们配对。
- 配对的两个区域互相交换填充颜色：区域 A 原为 red 且区域 B 原为 green，则 A 变为 green、B 变为 red。缺口仍保持为 azure。
- 区域的位置和大小不变，仅颜色交换。

Key insight: 表面上看，区域的颜色和大小各异，解题者必须忽略这些显眼的属性，转而关注每个区域内部"负空间"（缺口）的形状——缺口形状才是配对的依据，而配对关系又决定颜色的交换方向。
</description>

<description>
根据输入网格中"种子色块"与"染色轨道"的空间关系，让每个种子沿轨道扩散填色，轨道交叉处的颜色由多个种子的扩散距离远近决定覆盖优先级。

Input structure:
- 背景为 black。网格中有若干条由 grey 像素构成的直线轨道（水平线或垂直线），轨道可以交叉。
- 每条轨道上恰好有一个非 grey、非 black 的彩色像素（"种子"），颜色各不相同，种子占据轨道上的一个像素位置（替代了该位置的 grey）。
- 轨道的宽度为 1 像素。不同轨道可以在交叉点共享像素。

Rule:
- 每个种子沿自己所在轨道的两个方向同时扩散，将轨道上的 grey 像素替换为种子的颜色。扩散在轨道端点处停止。
- 当两个种子的扩散区域在交叉点相遇时：交叉点的颜色取离该交叉点更近的种子的颜色（按沿轨道的像素步数计算）。如果距离相等，则交叉点颜色取两个种子中在网格上行优先（行号小者优先，行号相同则列号小者优先）的那个。
- 种子自身像素保持其原始颜色不变。扩散完成后，所有 grey 像素都应被替换为某个种子颜色。

Key insight: 解题者需要分两层推理——第一层是发现种子沿轨道扩散的机制；第二层是发现交叉点处的颜色冲突通过"沿轨道距离比较"来解决，而非简单的空间覆盖，这要求解题者追踪每个种子沿轨道到达交叉点的路径长度。
</description>

<description>
在网格中找到多个由不同颜色边框围成的矩形区域，每个区域内部有一个小型"印章"图案和若干散点标记；根据散点标记相对于印章的方位，将印章复制到区域边框对应方位的外侧。

Input structure:
- 背景为 black。网格中有若干个由单色边框（宽度 1 像素）围成的矩形区域，边框颜色各不相同（如 red、blue、green 等）。
- 每个矩形区域内部包含：（a）一个由 yellow 像素构成的小型连通图案（"印章"），形状不规则但紧凑；（b）若干个 maroon 单像素散点（"方位标记"），分布在印章的不同方向上。
- 方位标记总是严格位于印章的正上方、正下方、正左方或正右方（即与印章在同一行或同一列上，中间可以有空隙）。

Rule:
- 对每个矩形区域，找出其内部印章的位置和所有方位标记的位置。
- 对每个方位标记，判断它相对于印章中心的方位（上、下、左、右）。
- 在矩形边框的对应方位外侧，紧贴边框放置一份印章的副本。具体地：方位标记在印章上方 → 在边框上边外侧放置印章副本（印章底边紧贴边框上边外侧一行）；方位标记在印章右方 → 在边框右边外侧放置印章副本（印章左边紧贴边框右边外侧一列）；以此类推。
- 印章副本使用该矩形边框的颜色绘制（而非 yellow）。
- 区域内部保持不变（印章和方位标记都保留）。如果一个区域有多个方位标记，则在多个方向上各放置一份副本。

Key insight: 解题者需要三层推理：（1）识别印章和方位标记的角色区分（都在区域内部，但功能不同）；（2）理解方位标记的方位编码含义（标记在哪个方向 → 在该方向的边框外放印章）；（3）发现副本颜色来源于边框颜色而非印章本身颜色。
</description>

<description>
网格中有若干对颜色相同的"门框"（由两条平行短线段组成），每对门框之间存在一条由背景色构成的隐含通道；从两端门框开口同时向通道内填充门框颜色，障碍物阻断填充的传播。

Input structure:
- 背景为 azure。网格中有若干对同色的"门框"结构。每个门框由两条平行的短线段组成（线段长 2-4 像素），两线段之间留有 1 像素宽的间隙作为"开口"。同色的两个门框开口相对（面对面），之间有一段水平或垂直的直线通道。
- 通道沿途可能有 grey 像素作为障碍物（占据通道中的单个像素位置）。
- 不同颜色的门框对之间的通道互不交叉。

Rule:
- 对每对同色门框，识别它们之间的通道（连接两个开口的直线路径）。
- 从两端门框的开口同时向通道内填充该颜色，填充在遇到障碍物（grey 像素）时停止。
- 障碍物本身不被覆盖，障碍物与对侧门框之间如果没有其他障碍物，则对侧的填充可以到达障碍物旁边。
- 如果通道中没有障碍物，则整条通道被完全填充。
- 门框本身保持不变，障碍物保持 grey。

Key insight: 解题者需要先通过颜色匹配找到门框配对关系，再通过门框的开口方向确定通道走向，最后理解双向填充与障碍物阻断的交互——障碍物将通道分成若干段，每段被离它更近的那一端门框的填充所覆盖，而障碍物自身形成"断点"。
</description>
</new_puzzle>

<description>
网格中有一个大型"棋盘"区域和外部的行列调色板；棋盘上被标记的格子根据其行列位置的奇偶性从不同调色板取色进行填充。

Input structure:
- 背景为 black。网格中央有一个 N*N 的棋盘状区域，由 grey 网格线分隔为若干等大的正方形格子（每个格子为 2x2 或 3x3 像素），所有格子初始为 black。
- 部分格子中包含一个 maroon 像素标记（位于格子中央）。
- 棋盘的正上方有一行水平排列的彩色方块（"列调色板"），每个方块宽度与棋盘的一列格子对齐，颜色各不相同。
- 棋盘的正左侧有一列垂直排列的彩色方块（"行调色板"），每个方块高度与棋盘的一行格子对齐，颜色各不相同。

Rule:
- 对棋盘中每个带有 maroon 标记的格子，找到其所在列对应的列调色板颜色 Cc 和所在行对应的行调色板颜色 Cr。
- 如果该标记格子的行号（从上到下，从 0 开始）与列号（从左到右，从 0 开始）之和为偶数，则用列调色板颜色 Cc 填充该格子；如果之和为奇数，则用行调色板颜色 Cr 填充该格子。
- 填充时覆盖格子内所有像素（包括 maroon 标记），格子变为纯色。
- 未标记的格子保持 black。调色板和 grey 网格线保持不变。

Key insight: 解题者首先需要建立调色板与棋盘行列的对应关系，然后发现着色规则并非简单地取行色或列色，而是根据行列坐标之和的奇偶性在两个调色板之间切换——这一奇偶交替规则需要从多个样例中对比才能归纳出来。
</description>
</new_puzzle>
