根据边框颜色配对嵌套矩形框，将内层框的填充色互换。

Input structure
- 背景为主色（如 black）。
- 网格中散布着若干"嵌套矩形对"，每对由一个外层矩形框和一个内层矩形框组成。
- 外层框为一像素宽的矩形边框，使用某种前景色（如 red、blue 等）；内层框也是一像素宽的矩形边框，使用另一种前景色，且完全位于外层框内部，与外层框之间至少间隔一个背景像素。
- 内层框围出的矩形区域被某种颜色填充（非背景色、非边框色）。
- 网格中恰好存在偶数个嵌套矩形对，且不同对的外层框颜色各不相同，但两两之间存在唯一配对关系：一对的外层框颜色等于另一对的内层框颜色，反之亦然。

Rule
- 找到外层框颜色互为对方内层框颜色的两个嵌套矩形对，将它们视为一组配对。
- 对于每组配对，交换两个内层框所围区域的填充颜色。
- 所有边框颜色、边框形状、位置以及背景均保持不变，仅内部填充色互换。

Key insight
- 配对线索隐藏在边框颜色的交叉引用中：外层框色指向对方的内层框色，解题者需要先建立边框颜色之间的双向映射关系，再据此交换填充色。
</new_puzzle>

<new_puzzle>
将散布的同色碎片按形状拼合回各自的矩形母体，并用碎片颜色标记母体上的缺口位置。

Input structure
- 背景为主色（如 black）。
- 网格中有若干不同颜色的"母体"：每个母体是一个近完整的矩形，但矩形内部有若干像素缺失（显示为背景色），形成不规则缺口。
- 网格中另有若干散落的小型 4-连通碎片，每个碎片使用与某个母体相同的颜色。
- 每个碎片的形状（平移归一化后）恰好与某个母体内部的某个缺口形状完全吻合；每个缺口恰好对应一个碎片。
- 碎片不与任何母体相邻（至少间隔一个背景像素）。

Rule
- 对每个母体，找出其矩形边界框内所有缺口（连通的背景区域）。
- 在同色碎片中，找到形状（平移归一化后）与该缺口完全匹配的碎片。
- 将缺口处的背景像素填充为该母体的颜色，使母体成为完整矩形。
- 删除原碎片位置的所有像素（恢复为背景色）。

Key insight
- 碎片不是直接放置到缺口位置的——它们的网格坐标无关紧要，只有形状匹配才能确定哪个碎片填哪个缺口。解题者必须先识别出母体的缺口轮廓，再在散落碎片中做形状配对。
</new_puzzle>

<new_puzzle>
根据种子行的颜色序列，逐层生长出螺旋向内收缩的彩色边框层。

Input structure
- 网格为正方形（边长为奇数，如 11x11 或 13x13），初始全部为背景色（如 black）。
- 网格最外圈的某一条完整边（如顶边）上排列着若干不同颜色的像素，从左到右形成一个颜色序列，其余最外圈像素为背景色。这条边称为"种子行"。
- 种子行上的颜色数量恰好等于从外到内可以画的完整矩形边框层数（即 floor(min(H,W)/2)）。

Rule
- 将种子行中从左到右的颜色序列记为 C1, C2, C3, ...
- 用 C1 绘制网格最外一圈的完整矩形边框（一像素宽）。
- 用 C2 绘制向内缩进一圈的完整矩形边框。
- 依此类推，每个颜色绘制下一个内缩的边框层，直到所有种子颜色用完。
- 若网格中心剩余一个像素未被覆盖，则用最后一个种子颜色填充。
- 种子行本身被最外层边框覆盖。

Key insight
- 种子行看似只是一行彩色标记，实际上它是一个有序的颜色图例，定义了从外到内每一层嵌套边框的颜色。解题者需要意识到种子行的颜色个数与可嵌套的层数严格对应，而颜色的左右顺序决定了由外到内的涂色顺序。
</new_puzzle>

<new_puzzle>
用"影子投射"规则将每个前景对象沿指示箭头方向展开为渐变色带，色带长度由对象面积决定。

Input structure
- 背景为主色（如 black）。
- 网格中有若干不同颜色的 4-连通前景对象，每个对象形状不规则但紧凑（面积不超过 8 像素）。
- 每个对象旁边恰好有一个同色的单像素"箭头头部"，与对象之间间隔恰好一个背景像素，且位于对象的正上方、正下方、正左方或正右方之一。箭头头部所在方向即为该对象的"投射方向"。
- 网格中另有一个由 grey 像素组成的色阶图例：一行或一列包含从左到右（或从上到下）排列的若干不同颜色像素，定义了色带的颜色渐变序列。

Rule
- 对每个前景对象，计算其像素面积 N。
- 从对象的每个像素出发，沿投射方向依次绘制 N 个像素，颜色依次取色阶图例中的第 1、第 2、...、第 N 种颜色。若 N 大于图例长度，则循环使用图例颜色。
- 原对象像素保持原色不变。
- 箭头头部像素在输出中被擦除为背景色。
- 若投射路径上遇到其他对象的原始像素，该路径在此截止。

Key insight
- 这道题有三层需要主动推理的结构：（1）识别箭头头部与对象的空间关系以确定投射方向；（2）理解对象面积决定投射长度；（3）从色阶图例中读取颜色序列并按序着色。三层信息分别来自不同的网格元素，必须整合后才能得出变换规则。
</new_puzzle>

<new_puzzle>
将网格中由隔板分出的每个子区域内的彩色图案，按隔板上缺口的位置"推送"到相邻区域，图案在穿越缺口时旋转 90 度。

Input structure
- 背景为主色（如 black）。
- 网格被若干条完整的单色直线（如 grey）分隔为矩形子区域。这些直线要么是完整的水平线，要么是完整的垂直线，形成网格状隔板。
- 每条隔板线上恰好有一个一像素宽的缺口（该位置为背景色而非隔板色）。
- 部分子区域内包含由某种前景色绘制的小型图案（4-连通，面积不超过 6 像素）；其余子区域为空（仅含背景色）。
- 每个非空子区域恰好与一个空子区域通过一个缺口相邻。

Rule
- 对每个包含图案的子区域，找到它与相邻空区域之间隔板上的缺口。
- 将图案从当前区域"推送"穿过缺口到相邻的空区域中。
- 推送时，图案以缺口位置为参考点进行 90 度顺时针旋转：若缺口在水平隔板上，图案从上方区域推到下方或从下方推到上方时顺时针旋转 90 度；若缺口在垂直隔板上，图案从左侧推到右侧或从右侧推到左侧时顺时针旋转 90 度。
- 旋转后的图案放置在空区域内，使图案中距缺口最近的像素紧邻缺口的另一侧。
- 原区域中图案被擦除为背景色。隔板和缺口保持不变。

Key insight
- 缺口不仅指示图案的传输方向，还隐含地触发了 90 度旋转变换。解题者需要先发现"图案穿越缺口"的传输机制，再归纳出旋转规则——这两层规则必须同时成立才能解释所有样例。
</new_puzzle>

<new_puzzle>
根据每个封闭区域内"种子像素"的数量，从预设调色板中选色填充该区域。

Input structure
- 背景为主色（如 white 或 azure）。
- 网格中有一个由单一前景色（如 black）绘制的连通线条网络，将网格分割为若干封闭区域（包括网格边界与线条共同围成的区域）。
- 部分封闭区域内散布有一个或多个"种子像素"，使用另一种统一的标记色（如 red）。不同区域内的种子像素数量各不相同（范围 1-5）。
- 网格某个边缘（如最底行）有一排调色板像素：从左到右依次排列 5 种不同颜色的单像素，用背景色分隔，分别对应数量 1、2、3、4、5。

Rule
- 对每个封闭区域，数出其中种子像素的数量 N。
- 在调色板中找到第 N 个颜色（从左到右第 N 个）。
- 用该颜色填充整个封闭区域（覆盖原有的背景色和种子像素，但不覆盖线条网络像素）。
- 不含种子像素的封闭区域保持原背景色不变。
- 调色板像素行在输出中保持不变。

Key insight
- 种子像素的作用不是标记颜色（它们全部同色），而是通过数量编码一个索引值。解题者必须先建立"种子数量→调色板位置"的映射关系，这需要同时观察多个区域的种子数与最终填充色才能归纳出规则。调色板的顺序是隐含的序数映射，而非直接的颜色对应。
</new_puzzle>

<new_puzzle>
将每个 L 形对象沿其缺失象限方向翻转出一个镜像副本，使两者拼合成完整矩形，副本使用该对象所在象限的角落标记色。

Input structure
- 背景为主色（如 black）。
- 网格被一条水平线和一条垂直线（均为 grey，各一像素宽，贯穿整个网格）分成四个象限。
- 每个象限的角落（靠近网格顶点的位置）有一个单独的彩色标记像素，四个象限的标记色各不相同。
- 若干 L 形对象（每个 L 形是一个 3x2 或 2x3 的矩形去掉一个角后剩余的 5 像素形状）散布在各象限内，每个 L 形使用某种前景色（非背景、非 grey、非角落标记色）。
- 每个 L 形恰好缺少一个角——该缺失角指向四个方向之一（左上、右上、左下、右下）。

Rule
- 对每个 L 形对象，确定其缺失角的方向。
- 将该 L 形沿缺失角方向进行翻转（若缺失角在右上，则沿垂直轴翻转并向右平移，使翻转副本补全缺失角），生成一个镜像副本，与原 L 形拼合成一个完整的矩形。
- 镜像副本的颜色不使用原 L 形的颜色，而是使用该 L 形所在象限的角落标记色。
- 原 L 形像素保持原色不变。grey 分隔线和角落标记像素保持不变。

Key insight
- 这道题包含两层非显然推理：（1）翻转方向由 L 形自身的缺失角方向决定，而非由象限位置决定；（2）副本颜色由所在象限的角落标记决定，而非由 L 形自身颜色决定。解题者必须分别归纳出形状变换规则和颜色赋值规则，两者的线索来源完全不同。
</new_puzzle>
