- `description`：根据每个封闭区域内部"种子"像素的颜色，从配色图例中查找对应的填充图案，将该图案平铺填入封闭区域。
- `Input structure`：背景为黑色。网格中有若干由单一颜色（如蓝色）绘制的封闭框（矩形或L形等不规则封闭轮廓），每个封闭框内部恰好有一个非背景、非框色的"种子"像素。网格的某个角落有一个图例区域，图例由若干小方块组成，每个小方块的左上角像素是一种颜色标识，其余像素构成一个 2×2 或 3×3 的小图案（使用两到三种颜色）。种子像素的颜色一定在图例的颜色标识中出现。
- `Rule`：
  1. 识别所有由框色构成的封闭轮廓，以及每个封闭区域内部的种子像素颜色。
  2. 在图例中找到与种子颜色匹配的小方块，提取该方块中除颜色标识外的图案部分。
  3. 将提取的图案以平铺方式填满对应封闭区域的内部（不覆盖框色轮廓），从封闭区域内部左上角开始对齐平铺，超出区域部分截断。
  4. 移除种子像素（被图案覆盖）。图例区域在输出中保留不变。
- `Key insight`：种子像素不是要被保留的对象，而是一个查表索引——它指向图例中的特定图案；解题者需要先建立"种子颜色→图例图案"的映射关系，再理解图案是以平铺方式填充封闭区域的。

- `description`：将网格中散落的彩色碎片按颜色配对，每对碎片沿各自朝向对方的方向滑动并拼合成完整对称图形，拼合后的图形再按面积从大到小依次堆叠在输出网格底部。
- `Input structure`：背景为黑色。网格中有偶数个单色的4-连通碎片对象，每种颜色恰好出现两个碎片。同色的两个碎片在某条水平线或垂直线上镜像对称，但各自只包含完整对称图形的一半（沿对称轴切开的两半）。不同颜色的碎片对之间不会在空间上重叠或干扰。
- `Rule`：
  1. 将同颜色的两个碎片配对。
  2. 对于每一对，找到它们共享的对称轴（水平或垂直），将两个碎片沿垂直于对称轴的方向平移直到它们在对称轴处紧密贴合，形成一个完整的对称图形。
  3. 计算每个拼合后图形的面积（像素数）。
  4. 在输出网格中，从底部开始，按面积从大到小依次向上堆叠这些拼合图形。每个图形水平居中放置，相邻图形之间无间隔，直接紧贴。
- `Key insight`：解题者需要完成两层推理——第一层是识别同色碎片是镜像半体并理解如何拼合它们，第二层是发现拼合后的图形按面积排序堆叠在底部，而不是放回原位。
</new_puzzle>

- `Input structure`：背景为黑色。网格被一条水平线和一条垂直线（均为灰色）分成四个象限。每个象限中有且仅有一个单色的4-连通前景对象（四个对象颜色各不相同）。网格中央灰色十字线的交叉处有一个与四个象限等大的空白画布区域（由灰色线围成的矩形内部，初始全为背景色）。
- `Rule`：
  1. 提取每个象限中的前景对象的形状（相对于其所在象限左上角的坐标）。
  2. 根据对象所在象限确定旋转角度：左上象限不旋转（0°），右上象限顺时针旋转90°，右下象限旋转180°，左下象限顺时针旋转270°。
  3. 将旋转后的对象形状以其原始颜色"盖印"到中央画布区域中——每个对象使用旋转后的形状，放置位置为该对象在其象限中的相对坐标映射到画布上。
  4. 如果多个对象在画布上的像素重叠，后盖印的覆盖先盖印的（按左上、右上、右下、左下的顺序依次盖印）。
  5. 输出仅为中央画布区域的内容（裁剪掉四个象限和灰色线）。
- `Key insight`：四个象限不是独立的输出区域，而是"印版"——每个对象的旋转角度由其象限位置隐式编码（解题者需要归纳出象限与旋转角度的对应关系），最终所有印版叠加在同一块中央画布上形成输出。
</new_puzzle>

- `description`：网格中散布着多个带有缺口的彩色矩形框，每个框内部有一个小型"钥匙"图案；将钥匙图案从框内移除，沿缺口方向射出，并在射线路径上按钥匙的像素数量为间距重复绘制钥匙图案，直到到达网格边缘。
- `Input structure`：背景为黑色。网格中有若干个彩色的空心矩形框（每个框由单一颜色绘制，框的四条边各一像素宽）。每个框的某一条边上恰好有一个连续缺口（缺口宽度等于框内钥匙图案在该方向上的尺寸）。每个框内部有一个由与框相同颜色绘制的小型连通图案（"钥匙"），钥匙的位置紧邻缺口所在边的内侧，且与缺口在该边方向上对齐。
- `Rule`：
  1. 识别每个矩形框及其缺口所在的边和缺口位置。
  2. 提取框内部的钥匙图案形状。
  3. 将钥匙从框内部移除（恢复为背景色）。
  4. 确定缺口的朝向（上、下、左、右），钥匙沿该方向射出。
  5. 从缺口外侧开始，沿射出方向每隔 K 个像素的距离（K = 钥匙图案的总像素数）绘制一个钥匙图案副本，保持钥匙的原始颜色和形状，直到下一个副本会超出网格边界为止。
  6. 矩形框本身（含缺口）保持不变。
- `Key insight`：解题者需要分三层推理——首先识别缺口方向决定了射出方向，其次理解钥匙图案被"发射"而非简单平移，最后发现重复间距不是固定常数而是由钥匙自身的像素数量决定的（面积→距离的跨域映射）。
</new_puzzle>

<new_puzzle>
- `description`：网格由多条彩色"传送带"构成，每条传送带上的物品根据传送带交叉点处的颜色优先级规则换乘到另一条传送带，最终物品停在传送带末端。
- `Input structure`：背景为黑色。网格中有若干条水平或垂直的单色线段（"传送带"），每条传送带颜色不同。传送带之间可能存在交叉点（两条传送带共享的一个像素，该像素显示为其中一条传送带的颜色）。每条传送带的一个端点处有一个橙色像素（"物品"），另一端为该传送带自身颜色的末端。网格的某个角落有一个小型颜色序列图例（由若干种颜色从上到下排成一列），表示传送带颜色的优先级（从高到低）。
- `Rule`：
  1. 每个物品（橙色像素）从其所在传送带的起点端出发，沿传送带方向移动。
  2. 当物品到达一个交叉点时，检查交叉点处显示的颜色：如果该颜色在图例中的优先级高于物品当前所在传送带的颜色，则物品转向到交叉的那条传送带上继续移动；否则物品忽略该交叉点，继续沿当前传送带移动。
  3. 物品一直移动到最终所在传送带的末端停下。
  4. 输出中，每个物品（橙色像素）出现在其最终停留位置，传送带和图例保持不变，物品的原始起点位置恢复为其所在传送带的颜色。
- `Key insight`：交叉点处显示的颜色不是装饰——它是换乘信号。解题者需要先从图例归纳出颜色优先级排序，再理解物品在交叉点根据优先级比较决定是否换乘，最后追踪每个物品经过可能的多次换乘后的最终位置。
</new_puzzle>

- `description`：网格中有若干个相同外接矩形尺寸但不同颜色的对象，每个对象内部挖有不同形状的孔洞；将所有对象的孔洞形状提取出来，找到孔洞形状与另一个对象实心部分互补的配对关系，然后用配对对象的颜色填充孔洞。
- `Input structure`：背景为黑色。网格中散布着若干个单色的4-连通前景对象，每个对象的外接矩形尺寸相同。每个对象内部有一个由背景色构成的4-连通孔洞。不同对象的孔洞形状各不相同，但每个对象的孔洞形状恰好与另一个对象去掉孔洞后的"实心部分"形状在旋转或翻转下完全一致（即孔洞可以精确地被另一个对象的实心部分填满）。这种配对关系是一一对应的。
- `Rule`：
  1. 提取每个对象的孔洞形状（背景色连通区域被对象完全包围的部分）。
  2. 提取每个对象的实心部分形状（对象像素在外接矩形内的分布）。
  3. 对于每个对象 A，找到另一个对象 B，使得 B 的实心部分形状在某种旋转或翻转下与 A 的孔洞形状完全匹配。
  4. 用 B 的颜色填充 A 的孔洞区域。
  5. 所有对象的位置和原始颜色保持不变，仅孔洞被填充。
- `Key insight`：解题者需要进行两层推理——首先发现每个对象的孔洞恰好是另一个对象实心部分的"阴模"（可能需要旋转/翻转），然后理解填充颜色来自配对对象而非孔洞所在对象本身，建立起"形状互补→颜色传递"的映射关系。
</new_puzzle>

- `description`：网格中有若干个彩色箭头指向不同方向，每个箭头的颜色在网格中还有一个同色的小型模板图案；将每个箭头替换为其同色模板图案沿箭头指向方向排列的序列，序列长度等于箭头的像素数。
- `Input structure`：背景为黑色。网格中有若干个由单一颜色绘制的箭头形状（箭头由一条直线段加一个三角形箭尖组成，箭尖指向上、下、左、右四个方向之一；箭头的绘制方式为：线段部分宽1像素，箭尖为3像素宽的等腰三角形末端）。每种箭头颜色在网格的边缘区域还有一个同色的小型矩形模板图案（2×2 或 3×3 大小），模板图案与箭头在空间上不相邻。
- `Rule`：
  1. 识别每个箭头的颜色、指向方向和总像素数 N。
  2. 找到与该箭头同色的模板图案。
  3. 移除箭头（恢复为背景色）。
  4. 从箭头原始位置的中心点开始，沿箭头指向方向依次排列 N 个模板图案副本，相邻副本紧密贴合无间隔。
  5. 模板图案保留不变，作为参照留在原位。
- `Key insight`：解题者需要三层推理——先识别箭头的指向确定排列方向，再通过颜色匹配找到对应的模板图案，最后发现序列的重复次数等于箭头本身的像素数（箭头不仅编码方向，其大小还编码了数量）。
</new_puzzle>
