- `description`：根据彩色钥匙的齿形解锁对应锁孔，将锁内封存的图案释放到锁的另一侧。
- `Input structure`：背景为黑色。网格中有若干"锁"结构和若干"钥匙"精灵。每把锁是一个由单色边框围成的矩形区域，矩形的一侧边框上有若干连续缺口（齿槽），矩形内部填充着一个多色图案。每把钥匙是一个与某把锁边框同色的小型条状物体，其一侧有凸起部分（齿），凸起的形状各不相同，钥匙散布在网格空白区域。
- `Rule`：
  1. 对每把钥匙，找到与其颜色相同的锁边框。
  2. 检查该锁缺口侧边框的缺口形状（缺口在边框上的相对位置和长度序列）是否与钥匙的齿形（凸起部分相对于钥匙主干的位置和长度序列）完全吻合。只有形状匹配时才算配对成功。
  3. 配对成功后，将锁内部的图案沿缺口所在方向平移到锁外侧，紧贴锁边框放置；锁内部清空为背景色。
  4. 删除已配对的钥匙。未配对的锁和钥匙保持不变。
- `Key insight`：颜色匹配只是第一层筛选；真正决定锁能否被打开的是钥匙齿形与锁缺口形状的几何吻合——解题者需要同时推断颜色配对规则和齿形匹配规则两层逻辑。
</new_puzzle>

- `description`：将散落的彩色碎片按颜色归入对应颜色边框的容器中，容器内碎片的排列顺序由碎片面积从大到小决定。
- `Input structure`：背景为黑色。网格中有若干由不同颜色单像素厚边框围成的空心矩形容器，容器内部为背景色。网格其他区域散布着若干不规则形状的单色碎片（4-连通区域），每个碎片的颜色与某个容器边框颜色相同。每种颜色可能有多个碎片，但只有一个容器。
- `Rule`：
  1. 对每种颜色，找到该颜色边框的容器和所有同色碎片。
  2. 将同色碎片按面积（像素数）从大到小排序。
  3. 在容器内部，从左上角开始，按排序顺序将碎片的归一化形状（平移到最小包围盒左上角对齐）逐个水平排列放入，相邻碎片之间间隔一列背景色；若当前行放不下则换到下一可用行的最左侧继续。
  4. 删除容器外的所有碎片。
- `Key insight`：碎片的颜色决定它归属哪个容器（第一层），但碎片在容器内的放置位置由面积排序决定（第二层）——解题者需先发现颜色归属规则，再发现面积排序的排列规则。
</new_puzzle>

- `description`：每个封闭区域内的种子像素数量决定从缺口射出的射线长度，射线方向由缺口方位决定，射线颜色由区域内种子的颜色投票决定。
- `Input structure`：背景为黑色。网格中有若干由灰色像素构成的封闭矩形边框（单像素厚）。每个矩形边框的某一侧恰好有一个由一个或多个连续背景像素构成的缺口。每个矩形内部散布着若干单像素点（种子），种子可能有多种颜色，颜色均不为灰色或背景色。
- `Rule`：
  1. 对每个灰色矩形边框，找到其缺口所在的方向（上、下、左、右）。
  2. 数出该矩形内部种子像素的总数 N。
  3. 统计矩形内每种种子颜色的出现次数，找到出现次数最多的颜色作为射线颜色（若有并列，取在该矩形内空间位置最靠近缺口的那个种子的颜色）。
  4. 从缺口的中心位置出发，沿缺口朝外的方向画一条长度为 N 个像素的射线，使用上一步确定的射线颜色。
  5. 矩形内部的种子像素全部清除为背景色，缺口保持不变。
- `Key insight`：解题者需要分三层推理：首先识别缺口位置以确定射线方向；然后数种子个数以确定射线长度；最后发现射线颜色由种子颜色的多数投票决定——三层规则需要从样例中分别归纳。
</new_puzzle>

- `description`：识别每个彩色框架中外侧箭头所指的方向，将框架内的内容物沿该方向整体推出缺口，堆叠在框架外壁处。
- `Input structure`：背景为黑色。网格中有若干由不同颜色像素构成的矩形框架（单像素厚边框，内部包含若干彩色像素作为内容物）。每个框架的边框有一侧缺少中间一段（形成一个缺口），而在与缺口相对的那一侧边框的外部紧贴着一个由同色像素构成的小三角形箭头，箭头尖端指向缺口方向。三角形箭头的绘制方式：以边框外侧某点为顶点，由 1 像素、3 像素、5 像素逐行排列构成一个实心等腰三角形（类似金字塔），尖端朝向缺口方向。框架内部散布的内容物像素颜色与框架边框颜色不同。
- `Rule`：
  1. 对每个框架，找到其外侧的三角形箭头，确定箭头指向的方向（即缺口所在的方向：上、下、左、右）。
  2. 将框架内所有内容物像素保持相对位置不变，沿箭头方向整体平移，穿过缺口，直到最前方的像素到达网格边界或碰到其他非背景像素时停下。
  3. 清除框架内部所有原始内容物像素为背景色。
  4. 删除箭头三角形，用背景色替代。框架边框（含缺口）保持不变。
- `Key insight`：缺口和箭头共同编码运动信息，但解题者需要意识到箭头方向才是推送方向的决定因素（第一层），然后理解内容物是整体保持相对位置穿过缺口平移（第二层），而非简单地填充缺口或在缺口处逐像素溢出。
</new_puzzle>

- `description`：将网格中的"印章"图案旋转到与"信封"缺角方位一致后，嵌入到信封的缺角位置。
- `Input structure`：背景为黑色。网格中有若干"信封"和若干"印章"。每个信封是一个较大的单色实心矩形，但其四个角之一被裁去了一个小矩形区域（缺角），缺角区域显示为背景色。每个印章是一个较小的矩形图案，外圈颜色与某个信封的颜色相同，内部包含一个不同颜色的小图形，整体形状和尺寸与对应信封缺角完全吻合。印章的某一角有一个单像素的 Red 标记点，表示印章当前的朝向角。
- `Rule`：
  1. 通过外圈颜色匹配，将每个印章与对应的信封配对。
  2. 确定信封缺角的方位（左上、右上、左下、右下）。
  3. 确定印章 Red 标记点所在的角（左上、右上、左下、右下）作为印章当前朝向。
  4. 将印章旋转（0 度、90 度、180 度 或 270 度），使印章 Red 标记点所在角旋转后对应信封缺角的方位。
  5. 将旋转后的印章放置到信封缺角的位置，精确填充缺失区域。旋转后标记点被信封颜色覆盖（因为它处于缺角的外角位置，该位置属于信封矩形的一部分）。
  6. 删除原始位置的印章。
- `Key insight`：颜色匹配确定配对关系（第一层），缺角方位确定目标朝向（第二层），Red 标记点确定印章当前朝向从而推算所需旋转角度（第三层）——三层信息需要逐步从样例中归纳。
</new_puzzle>

<new_puzzle>
- `description`：根据"调色板"条带中颜色的排列顺序，对网格中同心嵌套矩形环按从外到内的层级重新着色。
- `Input structure`：背景为黑色。网格分为两个区域：顶部有一行"调色板"条带，由若干不同颜色的像素从左到右依次排列（例如 Red、Blue、Green、Yellow），每种颜色占一个像素，各颜色之间无间隔。调色板下方隔一行背景色后，有一个由多层同心矩形环嵌套构成的图案，每层环为单像素厚，当前各层环的颜色是随意分配的（可能出现重复颜色，也可能与调色板颜色无关）。嵌套环的层数恰好等于调色板中颜色像素的个数。
- `Rule`：
  1. 读取调色板条带中颜色从左到右的排列顺序，记为颜色序列 C1、C2、C3、...、Cn。
  2. 识别下方嵌套环结构，从最外层到最内层依次编号为第 1 层、第 2 层、第 3 层、...、第 n 层。最外层环是嵌套图案最外圈的像素环，最内层可能是一个实心矩形或单像素。
  3. 将第 k 层环重新着色为调色板序列中的第 k 个颜色 Ck。
  4. 调色板条带本身保持不变。
- `Key insight`：解题者需要先发现调色板中颜色的有序排列是重着色的依据（第一层），然后正确识别嵌套环从外到内的层级顺序（第二层），最后建立调色板位置与环层级的一一对应关系（第三层）。环当前的颜色是干扰项，与最终输出完全无关。
</new_puzzle>

<new_puzzle>
- `description`：找到网格中每对同色标记点，用它们之间的连线作为"折叠轴"，将轴一侧的图案镜像翻折到另一侧并叠加。
- `Input structure`：背景为黑色。网格中有若干对同色标记像素，每种颜色恰好出现两个像素，它们位于同一行或同一列上。标记像素之间的连线构成一条水平或垂直的折叠轴。网格中还分布着若干非标记色的前景图案（4-连通的单色区域），位于折叠轴的一侧或两侧。
- `Rule`：
  1. 找到所有同色标记对，每对连线形成一条折叠轴（水平或垂直线段）。
  2. 对每条折叠轴，检查轴两侧的前景像素分布：像素数更多的一侧为"源侧"，更少的一侧为"目标侧"。
  3. 将源侧的所有前景像素沿折叠轴做镜像翻转，叠加到目标侧。若目标侧某位置已有前景像素，则保留原色不覆盖；若目标侧该位置为背景色，则填入镜像过来的颜色。
  4. 源侧前景像素保持不变。删除所有标记像素，替换为背景色。
- `Key insight`：解题者需要先发现同色像素对定义折叠轴（第一层），再判断哪一侧是源侧（通过像素数量多少）以确定折叠方向（第二层），最后理解叠加时已有像素不被覆盖的合并规则（第三层）。
</new_puzzle>
