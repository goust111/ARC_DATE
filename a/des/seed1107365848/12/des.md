- `description`：根据彩色种子像素在封闭围栏内"生长"出与围栏形状同构的缩小副本，生长层数由种子像素的数量决定。
- `Input structure`：背景为黑色。网格中有若干由同一颜色（如 green）绘制的单像素宽封闭围栏（4-连通闭合环），每个围栏内部散布着若干彩色种子像素（颜色各异，但都不是围栏颜色和背景色）。种子像素不与围栏相邻。
- `Rule`：
  1. 对每个封闭围栏，数出其内部种子像素的数量 N。
  2. 从围栏向内逐层收缩（每层向内偏移一个像素，类似剥洋葱），共收缩 N 层。每一层用该围栏内从左上到右下读取顺序排列的第 k 个种子像素的颜色来填充（第 1 层用第 1 个种子的颜色，第 2 层用第 2 个种子的颜色，依次类推）。
  3. 围栏本身保持不变。种子像素被其所在层的颜色覆盖。若收缩到无法再产生完整环时停止，即使 N 尚未用尽。
- `Key insight`：种子像素的数量控制生长深度，种子像素的读取顺序控制每层颜色；解题者需要先识别出"种子数量＝层数"的对应关系，再发现颜色的空间读取顺序规律。
</new_puzzle>

<new_puzzle>
- `description`：将网格中散落的彩色碎片按颜色配对，在每对碎片之间画出正交折线路径，折线的拐弯方向由碎片自身的形状朝向决定。
- `Input structure`：背景为黑色。网格中有若干小型彩色对象（每个对象由 2-4 个同色像素组成），每种颜色恰好出现两个对象。每个对象的像素排列构成一个指向某正交方向的"箭头"形状：例如两个水平相邻像素加上方一个像素构成向上的箭头。箭头方向为上、下、左、右之一。
- `Rule`：
  1. 将每种颜色的两个对象配对。
  2. 从对象 A 沿其箭头方向画出射线，再从对象 B 沿其箭头方向画出射线，两条射线会在某行或某列上有共同可达区域。
  3. 在两条射线的交汇处拐弯，形成一条精确的 L 形折线（先沿 A 的方向走，到交汇行/列后转向 B 的方向走，到达 B），折线颜色与配对颜色相同。
  4. 折线像素覆盖背景，但不覆盖任何已有对象像素。若两条折线交叉，后绘制的像素覆盖先绘制的（按颜色在调色板中的排列顺序，排列靠后的颜色后绘制）。
- `Key insight`：解题者需要同时识别两层非显然规律——首先从碎片像素排列中辨认出"箭头朝向"，然后理解两个配对箭头的朝向共同决定了折线的唯一拐弯位置。
</new_puzzle>

<new_puzzle>
- `description`：在网格的分隔框中，根据"钥匙"格子中小图案的旋转状态，对"锁"格子中的大图案施加相同旋转，并用钥匙的颜色重新着色。
- `Input structure`：背景为黑色。网格被 grey 色的单像素宽十字线分割为 2×3 共六个等大矩形单元格。每一行包含三个单元格：最左侧是"钥匙"单元格，包含一个由某颜色绘制的小型非对称 L 形图案（3×3 范围内的 3-4 个像素）；中间是"锁"单元格，包含一个用 red 绘制的较大非对称图案（5×5 范围内的 6-8 个像素），该图案在所有行中形状完全相同但可能处于不同旋转状态；最右侧是输出单元格，在输入中为空。每行的钥匙 L 形图案与一个"标准 L 形"之间存在 0°、90°、180° 或 270° 的旋转关系，且每行旋转角度不同。
- `Rule`：
  1. 识别所有行中钥匙单元格的 L 形图案，确定一个"标准朝向"（出现在某一行中的原始朝向），计算每行钥匙相对于标准朝向的旋转角度 θ。
  2. 对该行锁单元格中的 red 图案施加相同的旋转角度 θ。
  3. 将旋转后的图案用该行钥匙的颜色（非 red）绘制到该行的输出单元格中。
- `Key insight`：解题者需要先跨行比较钥匙图案以推断出旋转关系，再将同样的旋转逻辑迁移应用到完全不同形状的锁图案上——两步归纳缺一不可。
</new_puzzle>

<new_puzzle>
- `description`：沿着彩色路径行走，在每个拐弯处根据转弯方向在路径外侧放置标记像素，标记的颜色由该段路径上经过的直线步数决定。
- `Input structure`：背景为黑色。网格中有一条由 blue 像素组成的单像素宽正交折线路径（4-连通），路径不分叉、不成环，有明确的两个端点。路径由若干水平段和垂直段组成，段与段之间在拐弯处以 90° 相连。网格边缘有一个 red 像素标记路径的起点端。
- `Rule`：
  1. 从 red 标记的端点开始，沿路径行走。
  2. 在每个拐弯处，确定转弯方向（左转或右转）。若为右转，在拐弯像素的外侧（即弯道外角的对角位置）放置一个标记像素；若为左转，不放置标记。
  3. 标记像素的颜色由当前拐弯之前那一段直线的长度（像素数）决定：长度 1 → green，长度 2 → yellow，长度 3 → orange，长度 4 → maroon，长度 ≥5 → grey。
  4. 路径本身和起点标记保持不变。
- `Key insight`：解题者需要先发现只有右转才产生标记（而非所有拐弯），这需要建立起点→行走方向→左右转的空间推理；然后还需发现标记颜色与前段长度的映射关系，两层规律相互独立，必须分别归纳。
</new_puzzle>

<new_puzzle>
- `description`：将散落在网格中的彩色碎片"磁吸"到颜色匹配的边框段上，碎片到达边框后沿边框滑行到该段的中点位置并嵌入边框。
- `Input structure`：背景为黑色。网格四周有一圈单像素宽的边框，但边框并非统一颜色——它被分为若干段，每段由不同颜色绘制（如 red、green、blue、yellow 等），各段之间无间隔地首尾相连，覆盖整个矩形周长。四个角的像素颜色归属于其中一段（由相邻段颜色可判断）。网格内部散布着若干小型单色对象（每个 2-4 像素，4-连通），每个对象的颜色与边框某一段的颜色相同，且每种颜色在内部只出现一个对象、在边框上也只有一段。
- `Rule`：
  1. 对每个内部对象，找到边框上与其颜色相同的那一段。
  2. 计算该边框段的中点像素位置（若段长为偶数，取靠近段起始方向的那个中间像素）。
  3. 将对象沿垂直于该边框段的方向平移，直到对象的最外侧像素紧贴边框内侧（即与边框像素相邻）。
  4. 再沿边框段方向平移对象，使对象的中心（bounding box 中心）与边框段中点对齐。
  5. 对象像素覆盖到新位置；原位置恢复为背景色。边框本身不变。
- `Key insight`：解题者首先需要识别边框的分段着色结构并建立颜色匹配关系，然后需要发现碎片不仅是简单地移向最近边框、而是先垂直靠近再沿边框滑动到段中点——这个两阶段运动规律是核心难点。
</new_puzzle>

<new_puzzle>
- `description`：在由墙壁围成的房间中，根据房间内"染料源"像素的位置，将房间地板分区染色——每个地板像素归属于离它正交视线最先可见的那个染料源。
- `Input structure`：背景为黑色（代表地板）。网格中有 grey 色的单像素宽墙壁，将网格划分为若干封闭的矩形房间。每个房间内部有 2-3 个不同颜色的单像素"染料源"（颜色取自 red、blue、green、yellow、orange 等），染料源不与墙壁相邻。
- `Rule`：
  1. 对每个房间，独立处理其内部地板像素。
  2. 对每个黑色地板像素，从该像素向上、下、左、右四个方向分别发出射线，找到每个方向上在撞到墙壁之前最先遇到的染料源（如果该方向上没有染料源则忽略）。
  3. 在所有方向上最先被看见的染料源中，选取与当前像素正交距离最近的那个。若有多个距离相同的候选者，选取从上方或左方看到的那个（优先上方，其次左方）。
  4. 用选中的染料源颜色填充该地板像素。染料源像素自身保持原色，墙壁保持 grey。
- `Key insight`：解题者需要理解"可见性"的含义——不是简单的欧氏距离最近，而是正交视线直达且无墙壁遮挡的最近源；这将房间分割成看似沃罗诺伊图但实际受墙壁约束的不规则区域，需要逐方向追踪才能复现。
</new_puzzle>

<new_puzzle>
- `description`：网格中的每个彩色"印章"对象在其镜像位置留下一个颜色变换后的副本，镜像轴和变换后的颜色都由印章内部的特殊标记像素决定。
- `Input structure`：背景为黑色。网格中有若干互不重叠的小型对象（每个 bounding box 约 3×3 到 5×5），每个对象主体由某种颜色 C 绘制，内部恰好有一个像素是不同的"标记色" M（M ≠ C 且 M ≠ 黑色）。标记像素位于对象 bounding box 的某条边上（上边、下边、左边或右边的中间位置）。网格中央有一条贯穿整个网格的 grey 单像素宽直线（水平或垂直），作为全局对称轴。
- `Rule`：
  1. 每个对象关于 grey 对称轴做镜像反射，在镜像位置放置副本。
  2. 副本的形状与原对象镜像对称。
  3. 副本的主体颜色变为原对象中标记像素的颜色 M。
  4. 副本中对应的标记像素位置变为原对象的主体颜色 C（即主体色和标记色互换）。
  5. 原对象保持不变。若镜像位置与其他对象重叠，镜像副本的像素覆盖在上方。
- `Key insight`：解题者需要发现三层独立规律：（1）副本位置由全局 grey 轴决定的镜像产生；（2）副本颜色不是简单复制而是取自标记像素的颜色；（3）标记像素与主体颜色在副本中互换。仅从位置或颜色单独观察都无法完整推断规则。
</new_puzzle>
