- `description`：根据封闭区域内部的种子颜色选择对应的边框模板，将模板图案以平铺方式填入该封闭区域。

- `Input structure`：
  - 背景为黑色（black）。
  - 一种前景色（如 grey）绘制了若干互不相交的封闭矩形边框（一像素宽），每个边框围出一个矩形内部区域。
  - 每个封闭矩形的内部恰好有一个单像素"种子"，颜色各不相同（如 red、blue、green 等）。
  - 网格中另有若干独立的小型矩形色块（3×3 至 5×5），每个色块由统一的单一颜色绘制出一个二值图案（即该颜色像素 + 黑色像素构成的图案）。这些色块充当"模板"。每个模板的颜色恰好与某个封闭矩形内部的种子颜色一一对应。

- `Rule`：
  - 对每个封闭矩形边框，找到其内部的种子像素颜色。
  - 在网格中找到与该颜色匹配的模板色块。
  - 将模板图案以平铺（tile）方式重复填充到该封闭矩形的内部区域（左上角对齐，超出部分裁剪），填充时使用种子的颜色绘制模板中的非黑色像素，黑色像素保持黑色。
  - 种子像素本身被模板图案覆盖。模板色块和封闭边框保持不变。

- `Key insight`：种子颜色不是直接用来填充的纯色，而是检索模板的索引键；真正决定填充结果的是模板的二值空间图案。解题者需要先建立"种子颜色→模板"的映射，再理解平铺填充机制。
</new_puzzle>

<new_puzzle>
- `description`：将每个带缺口的彩色环按缺口朝向排列到对应的行或列通道中，并在通道末端标记环的层数。

- `Input structure`：
  - 背景为黑色（black）。
  - 网格边缘有若干条单像素宽的彩色直线段从边缘向内延伸（称为"通道"），每条通道颜色不同，水平通道从左边缘或右边缘出发，垂直通道从上边缘或下边缘出发。
  - 网格中央散布着若干 3×3 的彩色环对象（由一种非黑色颜色绘制的 3×3 方框，中心为黑色），每个环恰好有一个单像素缺口（即方框的上/下/左/右某一边中间像素缺失）。环的颜色各不相同。
  - 环可以是单层环（普通 3×3）或嵌套双层环（5×5 外环包含 3×3 内环，同色，中心黑色，缺口方向相同）。

- `Rule`：
  - 每个环的缺口朝向决定它属于哪个方向的通道：缺口朝左 → 从左边缘出发的水平通道；缺口朝右 → 从右边缘出发的水平通道；缺口朝上 → 从上边缘出发的垂直通道；缺口朝下 → 从下边缘出发的垂直通道。
  - 在同一方向的多条通道中，环的颜色与通道颜色匹配决定具体归属。
  - 将环从原位置移除，沿匹配通道的方向平移到通道起始端（紧贴网格边缘），环的形状和朝向保持不变。
  - 在通道的末端（远离边缘的一端），绘制一个长度等于环层数（单层环=1像素，双层环=2像素）的同色短线段，作为层数标记。

- `Key insight`：缺口朝向同时编码了两层信息——它既决定环的归属方向（上/下/左/右），又隐含了环在通道上的运动方向。层数标记则要求解题者区分单层环和嵌套环的视觉差异。
</new_puzzle>

- `description`：用箭头指向的颜色重新着色箭头对象本身，箭头指向的目标区域则被填充为箭头原来的颜色——即箭头与目标交换颜色。

- `Input structure`：
  - 背景为黑色（black）。
  - 网格中有若干彩色的"箭头"对象，每个箭头由一种颜色绘制，形状为一个 3 像素长的直线段（水平或垂直），加上在其一端的一个垂直方向上的两个像素形成箭头尖端（即整体呈"T"形的一半，共 5 个像素，明确指向某个方向）。例如一个朝右的箭头：在某行的三个连续像素构成水平杆，杆的右端上下各一个像素构成尖端。
  - 网格中还有若干单色的矩形填充区域（至少 2×2），每个区域的颜色各不相同。
  - 每个箭头恰好指向（箭头尖端方向上最近的）一个矩形区域，且箭头颜色与它所指向的矩形区域颜色不同。
  - 没有两个箭头指向同一个矩形区域。

- `Rule`：
  - 对每个箭头对象，沿箭头尖端方向找到最近的矩形区域，记录该矩形的颜色为 C_target，箭头自身颜色为 C_arrow。
  - 将箭头对象的所有像素重新着色为 C_target。
  - 将该矩形区域的所有像素重新着色为 C_arrow。
  - 即箭头和它指向的矩形交换颜色。
  - 不被任何箭头指向的矩形区域保持不变。

- `Key insight`：这不是简单的"箭头指示移动方向"的模式——箭头和目标之间发生的是颜色交换而非位置移动。解题者需要先通过箭头朝向确定配对关系，再发现交换机制，两步推理缺一不可。
</new_puzzle>

- `description`：根据分隔线将网格划分为若干面板，找出面板之间的形状包含关系，然后将大面板中与小面板形状匹配的子区域用小面板的颜色进行着色。

- `Input structure`：
  - 背景为黑色（black）。
  - 一种特定颜色（如 grey）的完整行和/或列将网格分割为若干矩形面板。
  - 每个面板内部包含一个由单一颜色绘制的 4-连通前景对象（形状各异），其余为黑色背景。
  - 面板中的对象大小不同：有的面板内对象较小（占据面板面积的少部分），有的较大（占据面板面积的大部分）。
  - 每个小对象的形状恰好是某个大对象形状的一个连续子区域（即小对象可以平移后完全嵌入大对象内部，且嵌入位置唯一）。

- `Rule`：
  - 将所有面板中的对象按像素数量分为"大对象"和"小对象"两组（大对象的像素数严格大于所有小对象）。
  - 对每个小对象，在所有大对象中找到唯一一个能让小对象形状完全嵌入的大对象（平移匹配，不旋转不翻转）。匹配位置唯一。
  - 在大对象所在面板中，将匹配区域（即小对象嵌入后覆盖的那些像素）的颜色改为小对象的颜色。大对象的其余像素保持原色。
  - 小对象所在面板保持不变。

- `Key insight`：分隔线面板结构是第一层需要识别的组织方式；形状的子区域嵌入匹配是第二层核心推理——解题者需要发现小形状是大形状的"拼图碎片"，而非独立无关的对象。唯一嵌入位置保证了确定性。
</new_puzzle>

- `description`：沿着灰色折线路径传播颜色，在每个转弯处根据拐角旁的标记像素切换为新颜色，将路径分段着色。

- `Input structure`：
  - 背景为黑色（black）。
  - 一种颜色（grey）绘制了一条单像素宽的连续折线路径（仅水平和垂直段，无分支），从网格的一个边缘像素（起点）延伸到另一个边缘像素（终点）。
  - 起点像素旁边（路径外侧、紧邻起点、不在路径上）有一个单像素标记，颜色为 C_start（如 red）。
  - 路径上每个转弯处（即路径从水平变为垂直或反之的拐角像素）的外侧拐角位置（即拐角像素的对角方向、路径不经过的那个象限中紧邻拐角的像素）有一个单像素标记，颜色各不相同。
  - 终点像素旁边没有标记。

- `Rule`：
  - 从起点开始，将路径像素的颜色从 grey 改为 C_start（起点标记的颜色）。
  - 沿路径行进，持续用当前颜色重绘路径像素，直到遇到一个转弯处。
  - 在转弯处（含该拐角像素本身），读取该拐角旁的标记颜色 C_turn，从转弯处（含）开始将后续路径像素改为 C_turn。
  - 继续行进，每遇到新的转弯就切换为新的标记颜色，直到路径终点。
  - 所有标记像素本身保持不变，位置不移动。

- `Key insight`：路径本身是灰色的均匀线条，解题者必须先识别出路径的几何走向和转弯位置，再发现转弯旁的彩色标记控制着后续路径段的颜色。这是"路径追踪"与"局部颜色指令读取"的双层结构——既要理解空间路径拓扑，又要发现颜色传播的切换规则。
</new_puzzle>

<new_puzzle>
- `description`：识别网格中的"印章"和"画布"对象，将印章按其边框上标记像素的位置指示的旋转角度旋转后，盖印到画布中每个标记点所在的位置。

- `Input structure`：
  - 背景为黑色（black）。
  - 网格中有两个由同一种边框颜色（如 blue）绘制的矩形边框（一像素宽），按大小分为两类：
    - "印章"：较小的正方形边框（如 5×5），内部包含一个由另一种颜色（如 red）绘制的非对称图案，以及恰好一个特殊标记像素（yellow），该标记像素位于边框四条边之一的中间位置。标记位于上边=0度不旋转，右边=顺时针90度，下边=180度，左边=顺时针270度。
    - "画布"：较大的正方形边框（边长至少是印章的三倍），内部以黑色为底，散布着若干与印章标记相同颜色（yellow）的单像素标记点。
  - 印章恰好一个，画布恰好一个。

- `Rule`：
  - 提取印章边框内部的图案（不含蓝色边框和 yellow 标记像素所在位置，标记位置视为黑色），记录标记像素在边框上的位置以确定旋转角度。
  - 将图案按标记指示的角度顺时针旋转。
  - 在画布内部，将旋转后的图案以每个 yellow 标记像素为中心进行盖印（图案的几何中心对齐标记点），图案像素覆盖画布内部的黑色像素；若图案像素超出画布边框则不绘制。
  - 若多个盖印区域重叠，后盖的图案覆盖先盖的。盖印顺序为画布内标记点从上到下、从左到右。
  - 盖印完成后，移除画布内所有 yellow 标记像素（恢复为黑色），印章对象整体保持不变。

- `Key insight`：解题者需要三层推理——第一层是区分印章与画布（通过大小）；第二层是从印章边框上标记的位置推断旋转角度（标记在上=不旋转，在右=转90度等）；第三层是理解画布中的标记点是盖印位置坐标。标记像素同时承担了旋转指令和位置指令的双重角色，但分布在不同的对象上。
</new_puzzle>

<new_puzzle>
- `description`：在网格中找到成对的同色 L 形对象，用配对之间的孤立标记像素的颜色填充每个 L 形的缺角区域，使其补全为完整矩形。

- `Input structure`：
  - 背景为黑色（black）。
  - 网格中有若干 L 形对象（即一个矩形去掉一个角上的矩形子区域后的形状），每个 L 形由单一前景色绘制。
  - 同色的 L 形恰好成对出现（即每种颜色的 L 形恰好有两个），且每对中两个 L 形的缺角区域大小相同（即缺角矩形的宽和高相同），但缺角位于不同的角（如一个缺左上角，另一个缺右下角）。
  - 网格中另有若干孤立的单像素标记，每个标记的颜色独特（与所有 L 形颜色不同且标记之间互不同色），且每个标记恰好位于某一对同色 L 形的两个边界框之间的空间中（即标记的位置在两个同色 L 形之间）。每对 L 形之间恰好有一个这样的标记。

- `Rule`：
  - 找到所有同色 L 形配对。
  - 对每一对同色 L 形，找到位于它们之间的标记像素，记录其颜色 C_fill。
  - 对这一对中的每个 L 形，用 C_fill 填充其缺角处的空缺矩形区域，使 L 形补全为完整矩形。
  - 标记像素本身从网格中移除（恢复为黑色背景）。
  - L 形对象的原有像素保持颜色不变。

- `Key insight`：解题者首先需要识别 L 形的同色配对关系（颜色相同即为一对），然后发现每对之间的孤立标记像素决定了填充颜色——标记不是装饰噪声而是颜色指令。两层推理：几何配对识别 + 标记颜色指派。
</new_puzzle>
