- `description`：根据封闭区域内部"种子"像素的颜色，在颜色图例中查找对应方向，仅当图例方向与边框缺口所在边一致时，才从缺口向外延伸一条种子颜色的射线。
- `Input structure`：背景为黑色。网格中有若干由单一前景色（如蓝色）绘制的封闭矩形边框，每个边框的某一条边上有一个单像素宽的缺口（缺口像素为背景色）。每个矩形内部恰好有一个"种子"像素，颜色为红色、绿色或黄色之一。在网格的某个固定位置有一个颜色图例区：图例由若干小色块组成，每个色块旁边紧邻一个方向标记（由两个同色像素组成的短线段，水平表示左或右，垂直表示上或下），标记颜色与色块颜色相同。
- `Rule`：
  1. 对每个封闭矩形，找到其边框上的缺口位置（上、下、左、右哪条边）。
  2. 查看矩形内部的种子像素颜色，在图例区中找到该颜色对应的方向标记，确定图例指示的方向。
  3. 如果图例指示的方向与缺口所在边一致（例如图例指示"上"且缺口在上边），则从缺口位置向外延伸一条种子颜色的射线，直到碰到网格边界或其他非背景像素为止。
  4. 如果图例方向与缺口边不一致，则该矩形保持不变，不绘制射线。
  5. 边框、种子像素和图例均保留不变。
- `Key insight`：解题者需要同时识别两个独立线索——缺口的物理位置和图例中的方向编码——并发现只有两者一致时才触发射线绘制，这构成了一个非显然的"与"条件过滤。仅观察缺口或仅观察图例都无法完整解释输出。
</new_puzzle>

<new_puzzle>
- `description`：将网格中散落的同色像素对识别为"传送门"，把与传送门接触的对象传送到配对传送门的对应位置，并根据传送门对的空间排列方向对对象进行镜像翻转。
- `Input structure`：背景为黑色。网格中有若干小型多色对象（每个对象由 2-5 个像素组成，形状不对称，便于识别翻转）。网格中还散布着若干成对的单像素标记，每对标记颜色相同且整个网格中该颜色恰好出现两次。每个对象恰好有一个像素与某个传送门标记四连通相邻。
- `Rule`：
  1. 找到所有成对的同色单像素标记（传送门对）。
  2. 对每个非背景对象，找到与其四连通相邻的传送门标记 A，再找到与 A 同色的配对标记 B。
  3. 计算对象接触点相对于 A 的偏移量，将对象以相同偏移放置到 B 的对应位置。
  4. 确定 A 到 B 的连线主方向（水平或垂直，取位移绝对值较大的分量）：若主方向为水平，则对传送后的对象做左右镜像；若主方向为垂直，则做上下镜像。
  5. 清除原始对象位置的像素（变为背景色），传送门标记保留不变。
- `Key insight`：解题者首先需要识别出成对出现的同色单像素是传送门，然后发现对象不仅被传送了位置，还根据传送门对的空间排列方向被镜像翻转——翻转轴由传送门对的相对位置隐式决定，而非显式标注。
</new_puzzle>

<new_puzzle>
- `description`：在包含多个同色框架的网格中，同组框架内部的图案各自存在不同位置的像素缺损；通过跨框架比较，用"多数投票"修复所有缺损，使同组图案完全一致。
- `Input structure`：背景为黑色。网格中有若干组矩形框架，每组由相同颜色的边框标识（例如三个红色边框的矩形、两个绿色边框的矩形）。同组框架的内部尺寸相同。每个框架内部包含一个由另一种颜色绘制的图案，同组框架的图案"本应"相同，但每个框架中有若干像素被错误地替换为背景色（即缺损）。不同框架的缺损位置各不相同，且同一位置在同组中最多只有一个框架存在缺损。
- `Rule`：
  1. 按边框颜色将矩形框架分组。
  2. 对同一组中的所有框架，逐像素比较其内部图案：对于每个内部坐标位置，取该组所有框架中该位置出现的非背景色作为正确颜色。
  3. 用正确颜色填补每个框架中的缺损位置，使同组所有框架的内部图案变得完全一致。
  4. 边框和背景保持不变。
- `Key insight`：解题者需要发现同色边框标识了"应该相同"的图案组，而修复策略是跨框架的互补参照——任何单个框架都不完整，但组内框架的缺损位置互不重叠，因此可以互为"答案"。核心推理在于识别边框颜色的分组功能以及跨实例修复的机制。
</new_puzzle>

<new_puzzle>
- `description`：识别网格中由灰色墙壁分隔的房间，根据每个房间地板上红色标记像素的数量对房间排序，然后按排序顺序从边缘颜色序列条中依次取色重新粉刷每个房间的地板。
- `Input structure`：背景为黑色。网格中有灰色像素构成的一像素宽墙壁网络，将网格划分为若干封闭的四连通区域（房间）。每个房间的地板最初为黑色（背景色），房间内散布着若干红色标记像素（每个标记为单个像素）。网格最上方一行包含一个颜色序列条：从左到右依次排列着不同颜色的单像素色块（颜色各不相同），色块之间间隔一个背景色像素，色块总数等于房间数量。
- `Rule`：
  1. 用四连通洪水填充找到灰色墙壁分隔出的所有房间。
  2. 数出每个房间内红色标记像素的数量 N。
  3. 按 N 从小到大对房间排序；若 N 相同，按房间中最靠上且最靠左的像素位置做字典序排序（先比较行号，再比较列号）。
  4. 从颜色序列条中按从左到右的顺序取色：排序第一的房间用序列条第一个颜色填充全部地板像素，第二个房间用第二个颜色，以此类推。
  5. 红色标记像素被新地板颜色覆盖；灰色墙壁保持不变；颜色序列条保持不变。
- `Key insight`：解题者需要先识别出红色标记的"计数"功能（而非装饰或位置信息），再发现计数结果决定了房间在颜色序列中的排位——这是两层独立的非显然归纳：标记数量决定排序键，边缘序列条提供调色板。两层线索缺一不可。
</new_puzzle>

- `description`：网格中的每个彩色对象内部的孔洞图案是一个"印章模板"，通过颜色匹配找到下方区域中的同色目标矩形，将孔洞图案作为印章盖印到目标上。
- `Input structure`：背景为黑色。网格分为上下两个区域，由一条灰色水平分隔线隔开。上方区域包含若干彩色对象（每个对象为一个实心矩形，内部挖去了若干像素形成孔洞，孔洞显示为背景色），不同对象颜色不同。下方区域包含若干实心填充的目标矩形（无孔洞），每个目标矩形的颜色与上方某个对象的颜色一一对应，但目标矩形的尺寸大于或等于上方对应对象的尺寸。
- `Rule`：
  1. 在上方区域中识别每个彩色对象及其内部孔洞的相对位置图案（以对象边界框左上角为原点记录每个孔洞的相对行列坐标）。
  2. 在下方区域中找到同色的目标矩形。
  3. 将孔洞图案以目标矩形的左上角为锚点叠加：对应位置的像素从目标颜色变为背景色（即"打孔"）。
  4. 如果孔洞图案超出目标矩形范围，超出部分忽略。
  5. 上方区域保持不变，灰色分隔线保持不变。
- `Key insight`：解题者需要意识到上方对象中的"缺陷"（孔洞）不是噪声或损坏，而是有意义的信息载体——它们编码了一个空间模板。核心推理在于将"孔洞"从"缺损"重新解读为"印章图案"，并通过颜色匹配确定印章与目标的对应关系。
</new_puzzle>

- `description`：识别网格中由路径连接的源-目标对象对，路径上的直角转弯次数编码了目标对象需要顺时针旋转的 90 度倍数。
- `Input structure`：背景为黑色。网格中有若干小型对象（每个对象占据 3x3 的区域，内部图案由多种颜色组成，形状不对称以便识别旋转）。每个对象被一圈单像素宽的边框包围：红色边框表示源对象，蓝色边框表示目标对象。灰色单像素宽路径在对象之间延伸，仅沿水平和垂直方向行进，每条路径恰好连接一个红色边框对象和一个蓝色边框对象。
- `Rule`：
  1. 追踪每条灰色路径，确定它连接的源对象（红色边框）和目标对象（蓝色边框）。
  2. 沿路径数出直角转弯的次数 T（即路径方向从水平变为垂直或从垂直变为水平的位置数）。
  3. 将目标对象的 3x3 内部图案（不含边框）顺时针旋转 (T mod 4) x 90 度。
  4. 源对象的内部图案保持不变；灰色路径保持不变；所有边框颜色保持不变。
- `Key insight`：解题者需要先通过边框颜色区分源和目标的角色，再发现路径的转弯次数（而非路径长度、走向或形状）才是决定旋转量的关键编码。路径的弯曲几何本身就是变换指令，这一点容易被忽视，因为路径通常被视为单纯的连接而非信息载体。
</new_puzzle>

<new_puzzle>
- `description`：在网格中找到由不同颜色构成的嵌套同心矩形环（"洋葱"结构），将每层环剥离后按从外到内的顺序水平排列为独立的矩形环。
- `Input structure`：背景为黑色。网格中有一个或多个"洋葱"结构，每个洋葱由若干层同心矩形边框嵌套而成，每层边框颜色不同，边框宽度均为一个像素，相邻层之间无间隙（内层紧贴外层内侧）。最内层可以是单像素实心填充或单层边框环。各洋葱之间互不接触。
- `Rule`：
  1. 识别每个洋葱结构：从最外层边框开始，逐层向内剥离每一层颜色不同的矩形环。
  2. 对每个洋葱，将剥离出的各层按从外到内的顺序从左到右排列在输出网格中。每一层保持其原始矩形环形状（仅保留该层边框像素，内部为背景色；最内层若为实心则保留实心）。
  3. 相邻层之间留一列背景色作为间隔。
  4. 如果有多个洋葱结构，按其在输入网格中最外层左上角的位置从上到下排列（先比较行号），不同洋葱之间留一行背景色间隔。
  5. 输出网格的尺寸恰好容纳所有排列后的层及间隔。
- `Key insight`：解题者首先需要识别"洋葱"的嵌套层次结构（通过颜色变化界定层边界），然后理解变换是空间上的"拆解并展开"——嵌套的径向深度结构被展平为从左到右的线性序列。这是一种从嵌套拓扑到并列拓扑的结构重映射。
</new_puzzle>
