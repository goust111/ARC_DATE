<new_puzzle>
根据形状轮廓的凹陷方向，将散落的碎片精确嵌入对应的凹槽中，碎片颜色覆盖凹槽区域。

Input structure
- 背景为主色调。网格中有若干大型单色实心形状，每个形状的边缘有一处凹陷（即从矩形轮廓向内缺失的一块区域，形成一个凹槽）。
- 网格中另有若干小型单色碎片（4-连通），每个碎片的形状恰好与某个大型形状的凹槽形状完全吻合（旋转0度）。
- 碎片颜色与其对应的大型形状颜色不同；每个大型形状恰好对应一个碎片，反之亦然。

Rule
- 对每个大型形状，找到其凹槽区域（即该形状的最小外接矩形与实际形状之间的差集，且该差集为单个4-连通区域）。
- 在所有碎片中找到形状与该凹槽完全相同的碎片（无需旋转或翻转，形状严格一致）。
- 将该碎片从原始位置移除（恢复为背景色），并将其放置到凹槽位置，用碎片自身的颜色填充凹槽区域。
- 大型形状本身的像素保持不变。

Key insight
- 匹配不依赖颜色对应，而依赖几何形状吻合：碎片的轮廓必须与凹槽的形状严格一致，这要求解题者同时识别"缺口的负空间形状"和"碎片的正空间形状"，并进行二维形状匹配。
</new_puzzle>

<new_puzzle>
根据封闭区域内种子像素的颜色，沿该区域的边界轮廓向外生长出对应颜色的等宽边框，边框宽度由种子像素的数量决定。

Input structure
- 背景为主色调（如 black）。网格中有若干个由同一颜色（如 grey）绘制的封闭矩形框（单像素宽的矩形边框）。
- 每个矩形框的内部（被框包围的区域）包含若干个同色的种子像素（非背景色、非框颜色），这些种子像素颜色相同，散布在框内部的背景区域中。
- 不同矩形框内的种子像素颜色可能不同。

Rule
- 对每个封闭矩形框，统计其内部种子像素的数量 N（N 的范围为 1 到 3）。
- 在该矩形框的外侧，生长出 N 层同心矩形边框，颜色为该框内部种子像素的颜色。
- 原始的 grey 框保留不变，内部种子像素也保留不变。
- 若两个框的外扩边框发生重叠，后绘制的（按框中心行坐标从上到下排序）覆盖先绘制的。

Key insight
- 解题需要两层独立推理：第一层是识别种子颜色决定外框颜色（颜色传递），第二层是发现种子数量决定外框的扩展层数（计数→几何量映射）。这两个信息来源不同（颜色属性 vs. 数量属性），必须同时归纳才能完整还原规则。
</new_puzzle>

<new_puzzle>
将网格中的彩色路径段按照路径交叉点处的"立交桥"规则重新着色，使得在每个交叉点处，水平方向的路径段始终从上方穿过垂直方向的路径段。

Input structure
- 背景为主色调（如 black）。网格中有若干条单像素宽的水平和垂直彩色路径段，每条路径段由一种非背景色构成（如 red、blue、green 等）。
- 路径段之间存在交叉：某些像素位置同时属于一条水平路径和一条垂直路径。在输入中，交叉像素的颜色可能为水平路径色或垂直路径色（不确定）。
- 每条路径段是一条直线（严格水平或严格垂直），长度至少为 3 个像素。

Rule
- 识别所有水平路径段和垂直路径段（通过各自的非交叉部分确定每条路径段的颜色和方向）。
- 在每个交叉点处，将该像素的颜色设置为经过该点的水平路径段的颜色（水平优先规则）。
- 非交叉像素保持原色不变。

Key insight
- 输入中交叉点的颜色是随机分配的（有时显示水平色，有时显示垂直色），解题者需要首先推断出每条路径的方向和颜色（通过观察连续的同色像素段来确定），然后发现交叉点统一采用水平路径颜色的规则。关键在于"方向判定先于颜色赋值"——必须先还原路径结构，才能应用覆盖规则。
</new_puzzle>

<new_puzzle>
将网格中每个多色精灵的各色块按照面积从大到小的顺序，重新排列为从左到右的水平条带，条带高度等于该精灵的原始高度，同时保留精灵之间的相对空间顺序。

Input structure
- 背景为主色调（如 black）。网格中有若干个互不接触的多色精灵（4-连通区域，每个精灵由 2 到 4 种非背景色组成）。
- 每个精灵内部，同一颜色的像素形成一个连续的色块区域。各色块在精灵内的排列方式不规则（可能交错、嵌套或相邻）。
- 精灵的外接矩形互不重叠。

Rule
- 对每个精灵，计算其外接矩形的高度 H。
- 统计该精灵中每种颜色的像素数量，按数量从大到小排序。
- 在输出中，将该精灵替换为一个高度为 H 的水平条带：按排序后的颜色顺序，从左到右依次填充，每种颜色占据的宽度为 ceil(该颜色像素数 / H)，整个条带的左上角与原精灵外接矩形的左上角对齐。
- 精灵外接矩形内多余区域（条带未覆盖的部分）清除为背景色。

Key insight
- 解题者必须先发现"各色块面积决定排列顺序"这一非显然的排序规则，再发现"像素总数按高度折叠为宽度"这一几何变换规则。这两步分别需要独立归纳：第一步从输出中色块的左右顺序与输入中色块面积的对应关系推断排序依据，第二步从条带的具体宽度反推折叠公式。
</new_puzzle>

<new_puzzle>
将网格中由围墙包围的迷宫房间内的入口标记沿迷宫通道传播，直到遇到第一个分岔口停止，并用标记颜色填充从入口到分岔口之间的整条通道。

Input structure
- 背景为主色调（如 black），代表迷宫的墙壁。一种前景色（如 grey）构成迷宫的通道（单像素宽的4-连通路径网络）。
- 通道网络中存在若干分岔口（即某个 grey 像素有 3 个或更多 grey 邻居的位置）。
- 在通道网络的某些末端（仅有 1 个 grey 邻居的像素），放置了彩色标记像素（如 red、blue、green），每个标记颜色不同。

Rule
- 从每个彩色标记像素出发，沿着通道向内传播（即沿着唯一的相邻 grey 像素前进）。
- 传播过程中，将经过的 grey 像素重新着色为该标记的颜色。
- 当传播到达一个分岔口像素（该像素的 grey/已着色邻居总数 ≥ 3）时停止，分岔口像素本身也被着色。
- 如果两个不同颜色的传播在到达分岔口之前在同一像素相遇，该像素保持 grey 不变，且两条传播都在此处停止。

Key insight
- 解题者需要同时理解两个层次的结构：第一层是识别迷宫的拓扑结构（区分末端、通道和分岔口），第二层是发现"传播在分岔口停止"的终止条件。单纯的"颜色沿路径填充"是一个常见的直觉，但分岔口作为停止信号是一个需要从样例中归纳的非显然规则——解题者必须观察到填充总是恰好在分岔口处截断，而非填满整个连通区域。
</new_puzzle>
