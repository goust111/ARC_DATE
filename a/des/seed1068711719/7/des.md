<description>
根据封闭边框内部散落标记的数量，从边框外侧对应方向的色条中读取颜色，用该颜色重绘整个边框的填充区域。

Input structure:
- 背景为黑色。
- 网格中有若干个由灰色像素绘制的一像素宽空心矩形边框，大小各异（最小 4×4，最大 8×8），互不重叠。
- 每个矩形边框的内部散落着若干个 maroon 像素（称为"标记"），数量在 1 到 4 之间。
- 网格的最右侧有一列垂直色条，由从上到下依次排列的 4 个等高色块组成（每块高度 2 像素，颜色分别为 blue、red、green、yellow），色块之间无间隔。

Rule:
- 对每个灰色矩形边框，数出其内部 maroon 标记的数量 N（1 ≤ N ≤ 4）。
- 从右侧垂直色条中取第 N 个色块的颜色。
- 将该矩形边框内部的所有像素（包括原 maroon 标记位置）填充为该颜色，灰色边框本身保持不变。
- 右侧色条在输出中保持不变。

Key insight:
- 边框内部的填充颜色不取决于边框的大小或位置，而取决于内部标记的计数；右侧色条需要被识别为一个有序的颜色查找表，标记数量是索引键。
</description>

<description>
网格中每个前景对象的轮廓向外生长，生长层数等于该对象内部被完全包围的背景孔洞数量；生长消耗孔洞，输出中对象变为实心。

Input structure:
- 背景为黑色。
- 网格中有 2 到 4 个互不接触的单色前景对象，每个对象是一个 4-连通区域，颜色各不相同（如 red、blue、green、yellow）。
- 部分对象内部包含被完全包围的黑色背景区域（"孔洞"），即被该对象像素四面封闭的黑色连通区域。每个对象的孔洞数量在 0 到 3 之间。
- 没有孔洞的对象为实心形状。

Rule:
- 对每个前景对象，计算其内部孔洞的数量 K。
- 将该对象的所有孔洞填充为该对象的颜色，使其变为实心。
- 然后将该实心化后的对象轮廓向外膨胀 K 层：每层膨胀是将所有与当前对象边缘正交相邻（上下左右四方向）的背景像素染为该对象颜色。
- 没有孔洞的对象（K=0）保持原样不变，既不填充也不膨胀。
- 如果不同对象的膨胀区域发生重叠，孔洞数更多的对象（膨胀层数更大的）优先占据该像素。

Key insight:
- 第一层推理：需要发现孔洞数量与膨胀层数之间的对应关系——孔洞多的对象扩展得更厚。第二层推理：孔洞本身在输出中消失了（被填充），扩展的"能量"来源于被消耗的孔洞，形成"内部孔洞转化为外部厚度"的机制，需要跨样例对比对象的变化才能归纳出来。
</description>

<description>
网格中散布着若干形状各异的前景精灵图，它们按形状全等关系两两配对；每对精灵图交换彼此的颜色，位置和形状保持不变。

Input structure:
- 背景为黑色。
- 网格中有偶数个前景精灵图（通常 4 到 6 个），每个精灵图由单一颜色构成的 4-连通小型形状（面积 3 到 8 像素）。
- 精灵图两两配对：每对中的两个精灵图具有完全相同的形状（平移后可完全重合），但颜色不同。不同配对的形状互不相同。
- 每种颜色在整个网格中恰好出现在两个精灵图上（它们分属不同的配对）。

Rule:
- 通过形状全等匹配识别配对关系：将每个精灵图的像素坐标平移至原点后比较，像素集合完全一致的两个精灵图构成一对。
- 对每一对精灵图，交换它们的颜色。例如精灵图 A 原为 red、精灵图 B 原为 blue 且形状相同，则输出中 A 变为 blue、B 变为 red。
- 精灵图的位置和形状保持不变，仅颜色互换。

Key insight:
- 配对依据不是颜色相同（实际上同对的颜色不同），也不是空间邻近，而是形状的全等关系。解题者需要先通过视觉比对发现"哪些形状是一样的"来建立配对（第一层推理），然后发现"配对之间交换颜色"的变换规则（第二层推理）。
</description>

<description>
每个带缺口的矩形边框沿缺口方向平移，平移距离等于其内部色块的像素面积，平移后缺口被封闭补全。

Input structure:
- 背景为黑色。
- 网格中有若干个由灰色像素绘制的空心矩形边框（一像素宽），每个边框在其四条边之一上有一个连续缺口（缺失 1 到 3 个像素的缺口）。
- 每个矩形边框内部恰好有一个小型实心色块（由 red、blue、green 等颜色构成的连续矩形区域），色块面积在 1 到 5 个像素之间。不同矩形内的色块颜色可以不同。
- 矩形边框之间互不重叠，也不紧贴网格边缘（留有足够的平移空间）。

Rule:
- 对每个矩形边框，确定缺口所在的边（上、下、左、右），该边的朝外方向即为平移方向。
- 计算该边框内部色块的像素面积 N。
- 将整个灰色矩形边框沿缺口朝向的方向平移 N 个像素。
- 平移后，将缺口处补全为灰色像素，使边框变为完整的封闭矩形。
- 内部色块保留在原位不动，不随边框平移。

Key insight:
- 第一层推理：缺口所在的方向决定平移方向——需要观察多个样例中不同缺口位置与平移方向的对应关系。第二层推理：平移距离由内部色块面积决定——而非色块颜色、色块位置或边框大小。缺口在输出中被封闭是辅助验证线索。
</description>

网格被竖直分隔线分为左右两半：左侧包含带有彩色标记的灰色模板形状，右侧为空白画布；输出时将模板形状复制到右侧并以标记颜色重新着色，摆放的垂直顺序由标记在各自模板内的相对垂直位置决定。

Input structure:
- 网格宽度为偶数，被一条竖直的 maroon 分隔线（占一列）均匀分为左右两半。
- 左半部分背景为黑色，其中有 2 到 4 个互不重叠的灰色 4-连通形状（面积在 4 到 10 像素之间），形状各异。
- 每个灰色形状内部恰好嵌有一个彩色标记像素（颜色各不相同，如 red、blue、green、yellow），该标记像素占据形状内不同的垂直相对位置（有的靠近形状顶部、有的在中部、有的在底部）。
- 右半部分为全黑空白画布。

Rule:
- 对每个灰色模板形状，将其所有灰色像素替换为该形状内标记像素的颜色（标记像素自身也保持该颜色）。
- 将着色后的形状复制到右半部分画布上，水平居中放置。
- 垂直排列顺序由标记像素在各自模板内的相对垂直位置决定：计算每个标记像素在其所属形状包围盒内从上到下的相对位置（0 表示最顶部，1 表示最底部）。相对位置越小（标记越靠近形状顶部）的形状在右侧画布中越靠上放置。形状之间垂直间隔一行黑色像素。
- 左半部分和 maroon 分隔线在输出中保持不变。

Key insight:
- 第一层推理：标记像素的颜色决定形状的重新着色——灰色是"待定"的占位符，而非输出颜色。第二层推理：形状在右侧画布的排列顺序不取决于它们在左侧的原始空间位置，而取决于标记像素在各自模板内部的相对垂直偏移——这一排序键是隐蔽的，需要跨样例比较才能归纳。
</description>

<description>
网格中有若干个不同颜色的 L 形物体和若干个单像素锚点；每个 L 形物体绕其自身拐角旋转，旋转方向由其配对锚点相对于拐角的象限决定，旋转次数等于 L 形物体两臂长度之差。

Input structure:
- 背景为黑色。
- 网格中有 2 到 4 个不同颜色的 L 形物体（如 red、blue、green），每个 L 形由两条正交的像素臂组成，共享一个拐角像素，两臂长度可能不同（含拐角，每臂长度 2 到 5 像素）。
- 每种 L 形物体的颜色在网格中另有一个孤立的同色单像素（即该颜色的"锚点"），锚点不与 L 形物体相邻。

Rule:
- 对每个 L 形物体，找到同色锚点。
- 以 L 形物体的拐角像素为旋转中心，确定旋转方向：如果锚点在拐角的顺时针方向象限（以 L 形两臂为参考轴，锚点落在两臂所夹的外侧区域的顺时针方向），则顺时针旋转 90 度；否则逆时针旋转 90 度。
- 旋转次数等于 L 形两臂长度之差的绝对值（若两臂等长则不旋转）。每次旋转 90 度。
- 旋转后的 L 形物体覆盖原位置（原位置清除为背景）。锚点在输出中保持不变。

Key insight:
- 第一层推理：同色配对建立 L 形物体与锚点的对应关系。第二层推理：旋转方向由锚点相对于拐角的空间位置决定——需要观察锚点在 L 形"开口侧"还是"封闭侧"来判断顺逆时针。第三层推理：旋转次数由两臂长度差决定——这是一个需要测量并比较的隐蔽属性。
</description>

<new_puzzle>
<description>
网格中有一个大型迷宫状的通道结构和若干起点标记；每个标记沿通道蔓延，蔓延在通道分叉处总是选择向标记原始朝向偏转最小的分支，直到通道终点或与其他蔓延相遇。

Input structure:
- 背景为黑色。
- 网格中有一个由灰色像素构成的连通通道网络，通道宽度恒为 1 像素，通道仅沿水平和垂直方向延伸，存在 T 形或十字形分叉。
- 通道的某些末端（死胡同）各放置一个彩色像素标记（如 red、blue、green），颜色各不相同，标记数量 2 到 4 个。
- 每个标记所在的死胡同有一个明确的初始方向（即从标记出发进入通道的唯一方向）。

Rule:
- 每个彩色标记从其死胡同出发，沿通道将灰色像素染为自身的颜色。
- 在直线段中，颜色持续蔓延。
- 在分叉处，颜色只选择一条分支继续：选择与当前前进方向夹角最小的分支（直行优先于转弯）。若有两条分支夹角相同（如左转和右转），则选择保持顺时针偏转更小的分支（即优先右转）。
- 蔓延在以下情况停止：到达另一个死胡同终点、遇到已被其他颜色染色的像素、或到达通道网络的另一个出口。
- 所有标记同时开始蔓延，但由于路径长度不同，不同颜色的蔓延可能在不同时间到达同一分叉——先到达的颜色占据该路径。

Key insight:
- 第一层推理：需要发现分叉处的选择规则是"最小偏转角"（直行优先）而非某种全局最短路径。第二层推理：多个标记同时蔓延，先到者优先占据通道，因此路径长度隐式决定了各颜色的领地范围。解题者需要模拟并发蔓延过程才能确定最终分布。
</description>
</new_puzzle>
