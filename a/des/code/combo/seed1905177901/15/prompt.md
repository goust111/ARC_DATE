Carve color-matched motifs into solid blocks and pack them into a compact grid.

Key insight: The motif acts as a stencil — it's not stamped onto the block but carved out of it as background holes.

<description>
Assemble the foreground objects by docking equal-colored boundary markers edge-to-edge.

Input structure
The grid has a dominant background color and several 4-connected multicolor foreground
objects.  One foreground color is the body color; the less frequent foreground colors are
boundary connector markers, and each marker color appears once as a free end or twice as a
matched docking pair.

Rule
Crop each foreground object to its bounding box and translate the objects so that the two
occurrences of every paired connector color touch on their exposed boundary sides.  Preserve
each object's orientation and colors, then return the tight crop around the assembled
foreground on the original background color.

Key insight
The colored marker pixels are ports: matching colors specify which objects must touch, and
the marker's side of its object determines the direction of the translation.
</description>

<description>
Turn a 4-cell-wide strip of 2x2 blocks into four nested corner-fill patterns.

Input structure
The input is an even-sized rectangle whose shorter dimension is four pixels.
It can be partitioned exactly into 2x2 blocks, giving one block for each layer
of the output quadrants.

Rule
Read the 2x2 blocks in reverse row-major order: bottom-right block first,
moving left, then moving upward. For each block, send its top-left,
top-right, bottom-left, and bottom-right pixels to the layer sequences of the
upper-left, upper-right, lower-left, and lower-right output quadrants.

Key insight
Each input 2x2 block supplies the four colors for one concentric layer, and
the layer order is the block order from bottom-right back to top-left.
</description>
</reference_puzzle>

<description>
Reverse the sequence of colors along the single 4-connected foreground path while keeping the path shape fixed.

Input structure:
- The background is the dominant color.
- All non-background pixels form one multicolor 4-connected one-pixel-wide path.
- The path has exactly two endpoints and no branches.

Rule:
- Walk the path from one endpoint to the other.
- Replace the colors on those same path cells by the original path colors in reverse order.
- Leave every background pixel unchanged.

Key insight:
- Nothing moves geometrically; only the color string written on the path is reversed between the endpoints.
</description>

<description>
Expand the sparse dot lattice into a 26x26 drawing with thick bars between adjacent matching dots.

Input structure
- The background is the dominant color.
- Foreground pixels lie on logical rows and columns separated by background spacer rows/columns.
- A logical row or column is present when it contains at least one foreground pixel.

Rule
- Expand every background spacer row/column to thickness 2.
- Expand the logical rows/columns equally so the full output is 26x26.
- Paint each foreground logical pixel as a solid rectangle of its color.
- Connect adjacent same-color logical pixels horizontally through the intervening spacer.
- Connect adjacent same-color logical pixels vertically only when neither endpoint is part of a horizontal same-color run.

Key insight
- The input is a sampled line drawing: horizontal same-color runs define the bars first, and only unclaimed same-color vertical neighbors are joined.
</description>
</reference_puzzle>

Fill each centered square ring with the color of the marker at that ring distance.

Input structure
The input is an odd square grid with a dominant background color and one

Rule
The output replaces the background with concentric square rings centered on
the middle cell; every cell at distance d from the center takes the color of

Key insight
The scattered markers are not objects to move; their Chebyshev distances
form a palette for the centered square rings.

Paint a recolored diagonal copy from each L triomino source object.

- The background is the dominant color.
- The only foreground objects are 4-connected red and grey L triominoes,

Rule:
- Grey L objects paint a yellow copy translated one diagonal step toward
  their missing 2x2 corner.

- Copies are clipped by the grid boundary; red-derived green copies are

Key insight:
- The missing corner of each 2x2 L object identifies its diagonal axis, and
  the source color determines which side of that axis receives the copy.

<description>
Move each gray marker along its green path until it reaches the cell next to a black-green-black gate, erasing the path behind it.

Input structure:
- The background is the dominant color.
- Foreground components are made from a path color, a paired gate-end color, and single marker pixels.
- A gate is a straight end-center-end motif whose center has the path color and whose two ends share the gate-end color.

Rule:
- In every 4-connected foreground component with exactly one marker and one gate, erase the marker and all path-color pixels except the gate center.
- Place the marker on the unique path-color pixel adjacent to the gate center but not between the two gate ends.
- Components without both a marker and a gate stay unchanged.

Key insight: The black-green-black motif marks the stopping gate; the gray marker consumes the connected green path until it rests on the path cell immediately beside that gate.
</description>
</reference_puzzle>

Delete connected components whose colors match a legend swatch.

<description>
Scale a minority cell's inner pattern up to the cell-grid level, completing a fractal overlay.

Input structure:
- Grid divided into NxN cells by separator lines of a single color.
- Most cells share an identical interior pattern (majority); a few have a distinct pattern (minority).

Rule:
- Extract the inner pixel pattern from the minority cell.
- Treat each pixel as a cell-sized stamp: active pixels → minority pattern, inactive → majority pattern.
- Position this scaled-up pattern on the cell grid so existing minority cells align with active pixels.
- Fill in all remaining active positions with the minority pattern.

Key insight: The minority cell's interior is a miniature blueprint of where minority cells should appear at the grid scale — fractal self-similarity.
</description>
</reference_puzzle>

<description>
Extend each top-row control pixel downward as a vertical toggle ray in its own color.

Input structure:
- The background is the dominant color.
- Non-background pixels on the top row are control pixels, each identifying
  one column and one ray color.
- Foreground regions below may intersect these control columns.

Rule:
- For every top-row control pixel, process the cells below it in the same
  column down to the bottom edge.
- A cell that already has the control color is erased to the background.
- Every other cell on that downward ray is painted with the control color.
- The top-row control pixels themselves remain unchanged.

Key insight:
The top row is a set of vertical ray launchers; each ray toggles only cells
matching its own color and overwrites all other colors along that column.
</description>

Repair noisy periodic patterns inside frame-delimited grid regions.

注意事项：
1. 任务不应依赖大量先验知识或复杂计算，而应依赖对模式、结构与空间关系的直觉推理。
2. 关于"计算"的边界：
   - **允许使用**（这些都是人类能心算的视觉量）：数像素 / 孔洞 / 对象 / 邻居（≤10 量级）、比大小、按某个可见属性排序、奇偶判断、取最大 / 最小、用一个计数值作为另一个等量几何量（如 N 个像素 → 长度 N 的射线、面积 N → 边长 N）、判断接触 / 相邻 / 包含、粗略中心位置（簇的视觉中点）、"距离"作为"几步"而不是公式等人类能够直观感受计算的内容。
   - **不建议使用**（这些是算法量而非视觉量，会迫使解题者依赖公式而非视觉直觉）：曼哈顿 / 欧氏 / Chebyshev 距离作为精确查表键、凸包面积、二进制位编码 / 位运算、模运算 / 余数、拓扑距离（BFS / 最短路 / 跳数）、精确几何质心坐标、凸角 / 凹角计数等复杂且不易被看出来的计算。
3. 问题必须能从少量示例中推断出来（通常为 3 对训练样例 + 1 个测试样例）。设计时从人类解题者的视觉角度思考：规则涉及的所有关键要素（对象、关系、属性）必须在网格上肉眼可见，不应依赖人眼无法直接观察到的隐含信息（例如颜色id是不可用的）或需要推算的隐藏属性。规则背后的逻辑本身可以有一定挑战性，但解题所需的所有线索必须能从网格中直接获取。
4. 生成的问题描述旨在促进后续用于创建题目网格的代码生成。因此，对输入 / 输出网格的描述以及规则总结必须极其详细；语言风格应易于理解；对于特定对象（如箭头），必须在描述中明确其绘制方式。
5. 描述谜题时避免使用 0 或 1 这类颜色编号；应使用颜色名称，例如 "red"。可用颜色如下：Black、Blue、Red、Green、Yellow、Grey、Magenta、Orange、Azure、Maroon。
6. 5 个新题的核心推理机制应明显不同——即从观察样例到归纳规则的认知路径不同，而不仅仅是场景、对象或颜色不同。
7. 题目难度应来自机制的隐蔽性而非步骤数。用参考题作为难度标尺——如果你生成的题一个样例就能猜到规则，说明机制太透明，需要加深隐蔽性。
8. 优先从参考题的机制出发进行重组或推演，而非从物理隐喻出发。物理隐喻容易导致大量题目归结为一种模式，例如"沿方向移动到阻挡处停止"。
9. 题目的难度优先来自规则的**结构层数**，而不是单一步骤的复杂度。关于"结构层数"的判定标准：**只有解题者需要主动推理才能完成的步骤才算一层**。肉眼一扫即可获得的信息（如"找到缺口在哪一侧"、"数出像素个数"、"识别哪个对象最大"）不构成独立的推理层——它们只是变换的前置输入，不增加认知难度。真正的多层结构是指每一层都需要解题者发现一个非显然的规律。以两层结构为例：
   - ✗ 伪两层："找到缺口方向"→"把东西推到对面" — 第一步肉眼可见，实际只有一层推理。
   - ✓ 真两层："通过孔洞数量匹配颜色图例"→"用匹配到的颜色重绘对象" — 两步都需要非平凡的归纳。

   如果你发现自己写出的题只是"对每个对象，根据它的某个属性做某变换"的单步规则，请引入一个需要主动推理的前置步骤。**用堆叠 tie-break 规则或复杂数学公式来"加难度"是劣解；用多一层需要归纳的结构嵌套来"加难度"才是好解**。
10. 在符合ARC题目和提示词要求的基础上，鼓励尝试创新规则为多层结构的题目，不局限于两层，可以创新三层或四层结构的题目，但不可为了多结构层数违背要求。

生成后对生成的题执行以下四项审查（审查内容不需要保存到文件）：
1. 原创性
  新题不可与上述参考题相同或类似，不可只是替换颜色、方向、对象类型等表层要素。判断标准：新题的核心推理路径应与任何一道参考题不同。
2. 确定性
  规则完全确定，同一输入只能产生唯一输出，每一步操作都有明确定义。
3. 可实现性
  所有必要细节都已给出——对象如何生成、如何识别、如何变换、边界情况如何处理，读完描述后可以直接写代码。
4. ARC 合规性
  网格尺寸合理（≤30×30），使用颜色不超过 10 种，规则复杂度适中，人类能从 3-5 个样例中发现规律。
