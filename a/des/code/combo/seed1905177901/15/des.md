<new_puzzle>
- `description`：在网格中，每个前景对象根据其内部"核心像素"（与四个方向的背景均不相邻的像素）的数量来决定自身应被缩放的倍率，缩放后的对象居中放置在原始位置。
- `Input structure`：背景为 Azure。网格中有若干不同颜色的 4-连通单色前景对象，形状各异，大小从 4 到 20 像素不等。对象之间有足够间距。
- `Rule`：
  - 对每个对象，统计其"核心像素"的数量 C——即该对象中四个正交方向上的邻居全部也是该对象像素的像素。
  - 如果 C = 0（所有像素都在边界上），将对象缩小为其 bbox 的 1/2（每 2x2 像素取一个，向下取整）。
  - 如果 C = 1，保持不变。
  - 如果 C >= 2，将对象放大 2 倍（每个像素扩展为 2x2）。
  - 缩放后的对象以原始 bbox 中心为中心放置。
  - 超出网格边界的部分裁剪。
- `Key insight`：核心像素数量是对象"厚度"的视觉度量——薄对象（无核心）缩小，厚对象（多核心）放大。解题者需要发现核心像素这一非平凡的结构指标。
</new_puzzle>

<new_puzzle>
- `description`：根据每个前景对象的边界形状（凸或凹），选择性地填充其凹陷区域，填充颜色由对象与最近网格角落的关系决定。
- `Input structure`：背景为 Black。网格中有若干不同颜色的 4-连通单色前景对象。部分对象边界有凹陷（bbox 中有被对象包围的背景区域），部分对象完全凸出（bbox 内无背景像素）。网格四个角落各有一个不同颜色的单像素标记。
- `Rule`：
  - 对每个前景对象，检查其是否有凹陷（bbox 内是否存在由对象边界围成的 4-连通背景区域）。
  - 如果没有凹陷（凸形对象），保持不变。
  - 如果有凹陷，找到对象 bbox 中心距离最近的网格角落，读取该角落标记的颜色。
  - 用该角落颜色填充对象的所有凹陷区域。
  - 保持角落标记不变。
- `Key insight`：凹凸性是"是否需要操作"的开关，而空间位置（最近角落）决定操作的具体颜色——形状拓扑和空间位置分别承担不同的决策角色。
</new_puzzle>

<new_puzzle>
- `description`：将网格中由分隔线围成的区域内的图案进行"棋盘化"处理——根据图案中每个像素的棋盘奇偶校验，决定是保留原色还是替换为特定的对照色。
- `Input structure`：背景为 Black。Grey 分隔线将网格分为若干矩形区域。每个区域内有一个多色前景图案。每个区域的右下角有一个单像素的"对照色"标记（与图案颜色不同）。
- `Rule`：
  - 对每个区域，读取右下角的对照色。
  - 对区域内的每个前景像素，根据其在区域内的局部坐标 (r, c) 判断棋盘奇偶性：如果 (r + c) 为偶数，保留原色；如果 (r + c) 为奇数，替换为对照色。
  - 背景像素保持不变。
  - 清除对照色标记。
- `Key insight`：棋盘化不是简单的全局操作——每个区域有独立的对照色，由角落标记指定。解题者需要发现"局部坐标决定奇偶"和"角落标记决定替换色"的双重规则。
</new_puzzle>

<new_puzzle>
- `description`：根据每个前景对象接触的网格边的数量，决定对该对象施加的变换方式，然后将变换后的对象按接触边数排序输出。
- `Input structure`：背景为 Azure。网格中有若干不同颜色的 4-连通单色前景对象。部分对象接触网格的一条边或多条边（对象的某些像素位于网格第一行/最后一行/第一列/最后一列）。部分对象完全在网格内部不接触任何边。
- `Rule`：
  - 对每个对象，统计它接触的网格边数 E（0 到 4）。
  - E = 0（不接触任何边）：清除该对象（视为干扰项）。
  - E = 1（接触一条边）：将对象水平镜像翻转。
  - E = 2（接触两条边）：将对象旋转 90 度顺时针。
  - E >= 3（接触三条或更多边）：保持不变。
  - 将所有保留的对象按 E 从小到大排序，在新画布上从左到右排列（裁剪到 bbox 大小），对象之间间隔一列背景。
- `Key insight`：接触边数同时编码了"变换方式"和"排列顺序"——解题者需要发现单一的空间属性（边接触数）驱动了两个独立的输出行为。
</new_puzzle>

<new_puzzle>
- `description`：将输入网格中前景对象的"轮廓"提取出来，根据轮廓上不同颜色段的长度比例，在输出中绘制对应比例的彩色条形图。
- `Input structure`：背景为 Black。网格中有一个由多种颜色构成的大型闭合前景形状。形状的边界轮廓由不同颜色的段组成——沿轮廓行走，颜色会周期性变化。形状内部填充 Grey。
- `Rule`：
  - 提取形状的外部轮廓像素（与背景相邻的前景像素）。
  - 从轮廓的左上角开始，顺时针遍历轮廓，记录每种颜色的连续段长度。
  - 创建输出：一个 1 行 × N 列的条形图（N = 轮廓总长度），从左到右按遍历顺序填入每段的颜色。
  - 每种颜色的段在条形图中占据与其轮廓长度相等的像素数。
- `Key insight`：二维的闭合轮廓被"展开"为一维的颜色条形图——解题者需要发现轮廓遍历的起点和方向规则，以及长度到宽度的直接映射。
</new_puzzle>
