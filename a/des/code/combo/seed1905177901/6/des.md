- `description`：根据每个前景对象所接触的边框侧颜色，将对象内部的背景孔洞填充为该侧颜色，同时将对象本身重染为其孔洞数量对应的图例颜色。
- `Input structure`：背景为 Black。网格有一个一像素厚的矩形边框，四条边各为不同颜色（上 Red、右 Blue、下 Green、左 Yellow，角像素为背景色）。边框内部有若干 Grey 的 4-连通前景对象，部分对象接触边框某一侧，部分对象不接触边框。每个对象内部可能有 0 到 3 个背景色孔洞。网格边框外侧有一行图例：从左到右依次为代表 0、1、2、3 个孔洞的颜色像素。
- `Rule`：
  - 对每个 Grey 对象，确定它接触的边框侧（若接触多侧，取接触像素最多的那侧）。
  - 用该侧边框的颜色填充对象内部的所有孔洞。
  - 统计对象的孔洞数量，在图例中查找对应颜色。
  - 将对象本身（原 Grey 像素）重染为图例颜色。
  - 不接触边框的对象保持 Grey 不变，其孔洞也不填充。
  - 清除图例行。
- `Key insight`：三层推理叠加——接触侧决定孔洞填充色，孔洞数量决定对象自身重染色，不接触边框的对象是干扰项。

- `Input structure`：背景为 Black。网格中有偶数个彩色 4-连通前景对象，它们两两配对。每对中两个对象形状互为镜像（水平或垂直镜像），且关于它们之间的某条水平或垂直中线对称放置。不同对的对称轴可能不同。
- `Rule`：
  - 找出所有对称对：两个对象互为镜像且关于它们中心连线的中垂线对称。
  - 对每一对，在对称轴位置放置合并后的对象（取两个对象的像素并集在轴线位置的投影）。
  - 合并对象的颜色取面积较大者的颜色（像素更多的一方）。若面积相等，取在网格中位置更靠上或更靠左的对象的颜色。
  - 清除原始两个对象。
- `Key insight`：对称对的识别需要同时匹配形状镜像和空间对称性——解题者不能仅通过颜色或形状单独判断配对关系，必须综合考虑几何对称条件。

- `description`：将散落的彩色标记像素收集到其所在行/列的"收集器"对象中，收集器根据收到的标记数量改变高度。
- `Input structure`：背景为 Azure。网格中有若干垂直方向的一像素宽彩色条（"收集器"），每条至少 3 像素高，底部对齐在同一行。在收集器上方的区域，散布着与收集器同色的单像素标记，每个标记在其所在列中恰好有一个同色的收集器。
- `Rule`：
  - 对每个收集器，统计同一列中在收集器上方的同色标记数量 N。
  - 将收集器的高度增加 N 个像素（向上生长）。
  - 清除所有同色标记像素。
  - 保持收集器的列位置和底部行不变。
- `Key insight`：同色标记被"吸收"到对应收集器中，转化为收集器的高度增长——颜色是配对键，计数是几何变换量。
</new_puzzle>

- `description`：在由分隔线形成的单元格矩阵中，将每个单元格的图案替换为该单元格行列交叉处图例所指定的图案，同时用行图例颜色重绘列图例形状。
- `Input structure`：背景为 Black。Grey 分隔线将网格划分为规则矩阵。第一行的单元格为"列图例"，每格内有一个不同形状的 Grey 小图案。第一列的单元格为"行图例"，每格内有一个不同颜色的实心 2x2 方块。其余单元格为目标区域，当前全为背景。
- `Rule`：
  - 对每个目标单元格，读取其对应列的列图例形状和对应行的行图例颜色。
  - 在目标单元格中绘制列图例的形状，使用行图例的颜色。
  - 保留分隔线和图例区域不变。
- `Key insight`：行图例和列图例分别提供颜色和形状两个独立维度——输出是两者的笛卡尔积，解题者需要分别识别"颜色来源"和"形状来源"。

- `description`：根据对象的边界周长与面积之比将前景对象分为"细长型"和"紧凑型"两类，分别用不同颜色标记，并将同类对象连线。
- `Input structure`：背景为 Black。网格中有若干不同颜色的 4-连通单色前景对象。每个对象要么是细长的条形（周长远大于面积的两倍），要么是紧凑的块状（周长接近面积的两倍的最小值）。
- `Rule`：
  - 对每个前景对象，判断其是否"细长"：如果对象 bbox 的长宽比 >= 3（较长边/较短边 >= 3），则为细长型；否则为紧凑型。
  - 细长型对象保持原色不变，紧凑型对象重染为 Maroon。
  - 在所有细长型对象的中心之间依次连线（按从左到右、从上到下的顺序），用 Red 绘制单像素宽连线。
  - 在所有紧凑型对象的中心之间依次连线，用 Blue 绘制单像素宽连线。
  - 连线为水平-垂直的 L 形折线（先水平后垂直）。
- `Key insight`：长宽比是分类标准，分类结果决定了两种不同的连线网络——解题者需要先发现形状分类规则，再理解分类如何驱动连线行为。
</new_puzzle>
