- `description`：根据每个矩形框架的缺口位置确定其"开口方向"，然后将开口朝向相同方向的框架合并为一个更大的框架，合并后的框架颜色取面积最大者的颜色。
- `Input structure`：背景为 Black。网格中有若干个不同颜色的一像素厚矩形框架。每个框架恰好有一条边存在一个连续的背景色缺口（缺口宽度为 1 到 3 像素），缺口所在的边决定了框架的"开口方向"（上、下、左或右）。框架之间不重叠。
- `Rule`：
  - 识别每个框架的开口方向。
  - 将所有开口方向相同的框架分为一组。
  - 每组中，计算所有框架的联合 bbox。
  - 用该组中面积（bbox 面积）最大的框架的颜色，绘制一个新的一像素厚矩形框架，其 bbox 等于联合 bbox，缺口位于与原方向相同的边上、宽度为组内所有缺口宽度之和。
  - 清除所有原始框架。
- `Key insight`：缺口方向是分组键而非装饰特征——解题者需要先发现缺口方向的分类作用，再理解面积优先的颜色选择和缺口宽度累加机制。
</new_puzzle>

- `description`：在棋盘格背景上，每个前景色块按其面积等量复制到该色块所在对角线的对称位置，复制品颜色取反（交换棋盘的两种底色）。
- `Input structure`：背景为交替的 Azure 和 Black 棋盘格图案。若干彩色前景色块（4-连通，每个色块为单一非背景色）散布在棋盘上。每个色块的面积不超过 6 个像素。
- `Rule`：
  - 对每个前景色块，找到其几何中心。
  - 将该色块关于网格中心进行点对称（180 度旋转），得到对称位置。
  - 在对称位置放置该色块的镜像副本。
  - 副本的颜色保持不变，但副本覆盖的棋盘格底色位置关系取反：原来覆盖 Azure 格的像素现在覆盖 Black 格，反之亦然。为此，副本整体偏移一个像素（向右或向下），选择使底色关系完全取反的唯一偏移方向。
  - 保留原始色块不变。
- `Key insight`：棋盘格不是无关背景——色块与其对称副本在棋盘上的奇偶校验相反，解题者必须识别出这种"棋盘相位翻转"机制。
</new_puzzle>

<new_puzzle>
- `description`：根据标记行中颜色对的排列顺序，将网格中对应颜色的对象两两连线，连线方向由颜色对在标记行中的相对位置编码。
- `Input structure`：背景为 Black。网格底部有一行标记行，由成对的彩色像素组成（每对相邻，对间有一个背景像素间隔）。网格上方散布着与标记行颜色对应的 4-连通单色前景对象，每种颜色恰好出现两个对象。
- `Rule`：
  - 读取标记行中的颜色对，从左到右依次处理。
  - 对于每个颜色对 (A, B)：找到网格中颜色 A 的两个对象中较小的一个和颜色 B 的两个对象中较小的一个，在它们的中心之间画一条 A 色的直线段。
  - 找到颜色 A 的两个对象中较大的一个和颜色 B 的较大的一个，在它们的中心之间画一条 B 色的直线段。
  - 连线为单像素宽的水平/垂直/对角线段（选择最短路径方向）。
  - 清除标记行。
- `Key insight`：标记行编码了颜色配对关系，而对象面积编码了配对内部的匹配——小配小、大配大，两层匹配机制叠加。
</new_puzzle>

- `description`：将网格中由颜色渐变序列构成的路径提取出来，根据路径的起始颜色查找图例中对应的变换方式，对路径形状施加该变换后输出。
- `Input structure`：背景为 Grey。网格中有若干条由连续像素构成的一像素宽路径，每条路径的颜色沿路径方向呈现固定的颜色循环（例如 Red→Blue→Green→Red→...）。不同路径可能使用不同的起始颜色但相同的循环序列。网格左上角有一个 3x3 的图例区域，包含三行：每行左侧一个颜色像素表示起始颜色，右侧两个像素表示变换类型（水平排列 = 水平翻转，垂直排列 = 垂直翻转，对角排列 = 90 度旋转）。
- `Rule`：
  - 找到每条路径的起始端点（路径中循环序列的第一个颜色所在端点）。
  - 读取起始颜色，在图例中查找对应的变换类型。
  - 将路径的几何形状（像素位置集合）施加该变换（关于路径 bbox 中心执行翻转或旋转）。
  - 保持变换后每个像素的颜色循环顺序不变（即重新沿变换后的路径方向涂色）。
  - 清除图例区域。
- `Key insight`：颜色循环的起始点标识了路径的"头部"，而头部颜色是查找变换方式的键——解题者需要先发现颜色循环的方向性，再通过图例推断变换规则。
</new_puzzle>

- `description`：将输入网格中的多层半透明彩色矩形叠加图案分解为独立的颜色层，按面积从大到小排列输出。
- `Input structure`：背景为 Black。网格中有若干个轴对齐的彩色矩形区域，它们相互重叠。在重叠区域，颜色混合为第三种颜色（例如 Red + Blue 区域显示为 Magenta，Red + Yellow 显示为 Orange，Blue + Yellow 显示为 Green）。每个原始矩形仅使用 Red、Blue 或 Yellow 三原色之一。
- `Rule`：
  - 从混合颜色中推断原始矩形层：Magenta = Red + Blue 重叠，Orange = Red + Yellow 重叠，Green = Blue + Yellow 重叠。
  - 还原每个原始矩形的完整 bbox 和颜色。
  - 按面积从大到小排列，在新画布上逐个绘制为实心矩形，底部对齐、从左到右排列，矩形之间间隔一列背景色。
- `Key insight`：混合颜色不是独立的前景对象，而是两个原色层重叠的证据——解题者需要从"加色混合"规则逆向推断出原始分层。
</new_puzzle>
