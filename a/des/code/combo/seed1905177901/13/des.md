- `description`：将网格中的每个前景"钥匙"对象与同色的"锁"框架配对，根据钥匙形状在锁框架的缺口处完成补全，补全后用钥匙的内部标记颜色填充锁框架的内部。
- `Input structure`：背景为 Black。网格中有若干彩色一像素厚的矩形框架（"锁"），每个框架的一条边有一个凹形缺口。另有若干与框架同色的小型实心对象（"钥匙"），每个钥匙的形状恰好能填补某个锁的缺口。每个钥匙内部有一个不同颜色的单像素标记。钥匙和锁的颜色一一对应。
- `Rule`：
  - 按颜色将钥匙与锁配对。
  - 将钥匙平移到锁的缺口位置，使其形状恰好填满缺口，完成框架的封闭。
  - 读取钥匙内部标记像素的颜色。
  - 用该标记颜色填充封闭后框架的全部内部区域。
  - 清除钥匙的原始位置。
- `Key insight`：三层推理叠加——颜色匹配找到配对，形状互补确定放置方式，内部标记决定填充颜色。每一层都需要非平凡的归纳。
</new_puzzle>

<new_puzzle>
- `description`：将网格中的前景对象按其"重力方向"（由对象形状不对称性决定）下落，不对称的"重"端向下，直到碰到障碍物或网格底部。
- `Input structure`：背景为 Azure。网格中有若干不同颜色的 4-连通前景对象。每个对象的形状在垂直方向上不对称——上半部分和下半部分的像素数量不同。网格底部有一行 Grey 像素作为地面。部分列上有 Grey 障碍物像素。
- `Rule`：
  - 对每个对象，比较其 bbox 上半部分和下半部分的像素数量。
  - 如果下半部分像素更多（"重心在下"），对象保持当前朝向向下移动。
  - 如果上半部分像素更多（"重心在上"），先将对象垂直翻转（使重端朝下），然后向下移动。
  - 向下移动直到对象底部接触 Grey 地面或障碍物。
  - 保持 Grey 像素不变。
- `Key insight`：对象的垂直不对称性编码了"翻转与否"——不是所有对象都简单下落，部分需要先翻转再下落。解题者需要发现"重端朝下"的隐含规则。
</new_puzzle>

<new_puzzle>
- `description`：根据分隔区域内前景图案与参考面板中模板的匹配关系，使用参考面板中模板的"互补"颜色重绘匹配区域。
- `Input structure`：背景为 Black。网格被 Grey 分隔行分为上下两部分。上半部分为参考面板，包含若干个 4x4 的双色图案模板（每个模板由两种颜色组成，排列成特定的二值图案）。下半部分包含若干个 4x4 的区域，每个区域使用参考面板中某个模板的其中一种颜色绘制了该模板的部分图案（另一种颜色的位置为背景色）。
- `Rule`：
  - 对下半部分的每个 4x4 区域，将其非背景像素的位置模式与上半部分的模板进行匹配。
  - 找到匹配的模板后，确定该区域使用的是模板的哪一种颜色。
  - 用模板的另一种颜色填充该区域中当前为背景色的位置（即模板中该颜色对应的位置）。
  - 保持参考面板和分隔行不变。
- `Key insight`：每个下方区域是其匹配模板的"半幅"——解题者需要发现下方的单色图案是模板双色图案的一半，然后用另一半（互补颜色和互补位置）补全。
</new_puzzle>

<new_puzzle>
- `description`：将网格中由两种颜色交替排列构成的条纹带"解码"为单色带，解码规则由条纹带的起始颜色和条纹方向共同决定。
- `Input structure`：背景为 Black。网格中有若干条纹带，每条带由两种颜色交替排列的像素组成（如 ABABAB...），条纹带可以是水平或垂直的，宽度为一像素。每条带的两种颜色不同，但不同条纹带可能共享颜色。
- `Rule`：
  - 对每条条纹带，确定其起始颜色（最左或最上的第一个像素颜色）和方向（水平或垂直）。
  - 如果起始颜色为"暖色"（Red、Orange、Yellow、Maroon），将整条带替换为起始颜色的纯色带。
  - 如果起始颜色为"冷色"（Blue、Green、Azure），将整条带替换为第二种颜色（非起始色）的纯色带。
  - 如果起始颜色为"中性色"（Grey、Magenta），保持交替条纹不变。
  - 保持条带的位置和方向不变。
- `Key insight`：条纹的起始颜色不仅分类了处理方式，还决定了最终保留哪种颜色——暖色保留自身，冷色让位给对方，中性色维持原状。解题者需要归纳出这种颜色类别与处理规则的映射。
</new_puzzle>

<new_puzzle>
- `description`：将输入中每个对象的"影子"投射到指定方向，影子长度由对象的像素数量决定，影子颜色由对象的形状类型（矩形 vs 非矩形）决定。
- `Input structure`：背景为 Azure。网格中有若干不同颜色的 4-连通前景对象。网格的某一条边（例如右边）上有一个 Maroon 单像素标记，指示影子投射的方向（标记在右边 → 影子向右投射）。
- `Rule`：
  - 确定影子方向（Maroon 标记所在边的方向）。
  - 对每个前景对象，统计其像素数量 N。
  - 从对象在投射方向上的最远边缘开始，沿投射方向绘制 N 像素长的影子区域。影子的宽度等于对象在垂直于投射方向上的跨度。
  - 影子颜色：如果对象是一个完美的实心矩形（bbox 内无背景像素），影子颜色为 Grey；如果对象不是完美矩形（有空洞或不规则形状），影子颜色为 Maroon。
  - 影子不覆盖其他前景对象，遇到阻挡时截断。
  - 保持所有原始对象和标记不变。
- `Key insight`：面积决定影子长度，形状类型决定影子颜色——解题者需要同时发现两个独立的属性到输出的映射规则。
</new_puzzle>
