- `description`：将网格中每个前景对象沿其"最长对角线"方向滑动，滑动距离由同色标记像素的数量决定，在路径上用该颜色绘制对角线轨迹。
- `Input structure`：背景为 Black。网格中有若干不同颜色的 4-连通前景对象。每个对象形状为矩形或近矩形。每种颜色在网格边缘有若干个同色的单像素标记（标记不与对象物理接触）。
- `Rule`：
  - 对每个对象，确定其 bbox 的主对角线方向（左上→右下 或 右上→左下，取 bbox 较长的对角线）。
  - 统计网格边缘同色标记像素的数量 N。
  - 将对象沿主对角线方向移动 N 个像素。
  - 在对象的原始位置到新位置之间的对角线路径上，用该对象的颜色绘制单像素宽的对角线轨迹。
  - 清除原始位置的对象像素（已由轨迹覆盖的除外）。
  - 清除所有边缘标记像素。
- `Key insight`：对象自身的长宽比决定了移动的对角线方向，外部标记的数量决定了移动距离——形状和计数两个线索共同确定输出。
</new_puzzle>

<new_puzzle>
- `description`：根据网格中"信号"像素到"天线"对象的视线方向，将信号颜色传播到天线的对应面上。
- `Input structure`：背景为 Azure。网格中有若干 3x3 的 Grey 实心方块（"天线"）。每个天线的四周散布着若干不同颜色的单像素"信号"，每个信号与其最近天线在同一行或同一列上（即在天线的正上方、正下方、正左方或正右方）。
- `Rule`：
  - 对每个天线，收集其四个正交方向上的信号像素。
  - 每个信号的方向决定天线的哪一面被"染色"：信号在天线上方 → 染天线的顶边一行为信号颜色；信号在下方 → 染底边一行；左方 → 染左边一列；右方 → 染右边一列。
  - 如果同一面有多个信号，使用距天线最近的信号的颜色。
  - 天线中心像素保持 Grey 不变。
  - 清除所有信号像素。
- `Key insight`：信号的方位编码了天线的着色面——不是信号颜色决定面，而是信号的空间位置决定面，信号颜色决定该面的颜色。
</new_puzzle>

<new_puzzle>
- `description`：将网格中分散的同色像素组合并为一个紧凑的矩形，矩形的放置位置由该颜色的像素质心决定，矩形边长由像素数的因数分解决定。
- `Input structure`：背景为 Black。网格中散布着若干颜色的前景单像素标记。每种颜色出现的次数恰好可以分解为两个整数的乘积（即是某个矩形的面积）。不同颜色的像素分布在网格的不同区域。
- `Rule`：
  - 对每种颜色，统计像素数量 N。
  - 找到 N 的最接近正方形的因数分解 (a, b)，使得 |a - b| 最小。
  - 计算所有同色像素的位置平均值（向下取整）作为矩形中心。
  - 在该中心位置绘制 a × b 的实心矩形（a 为高度、b 为宽度），颜色为该组颜色。
  - 清除所有原始分散像素。
  - 如果多个矩形重叠，后处理的（按颜色像素数量从少到多的顺序）在上层。
- `Key insight`：分散像素的集合被"凝聚"为紧凑矩形——像素数量决定矩形面积，位置分布决定放置位置。解题者需要发现"质心定位+因数分解定形状"的双重机制。
</new_puzzle>

<new_puzzle>
- `description`：在分隔线构成的单元格矩阵中，根据每行和每列的"主导颜色"交叉确定每个空白单元格应填入的颜色。
- `Input structure`：背景为 Black。Grey 分隔线将网格划分为规则的方形单元格矩阵（例如 5x5）。部分单元格内有一个实心的单色像素块（占满整个单元格），部分单元格为空（全背景色）。每行和每列中已填充的单元格颜色可能不同。
- `Rule`：
  - 对矩阵的每一行，确定该行中出现次数最多的颜色作为"行主导色"。
  - 对矩阵的每一列，确定该列中出现次数最多的颜色作为"列主导色"。
  - 对每个空白单元格，如果其行主导色和列主导色相同，则填入该颜色。
  - 如果行主导色和列主导色不同，则填入 Maroon（冲突标记色）。
  - 保持已有填充和分隔线不变。
- `Key insight`：空白单元格的颜色由其行列的"投票"共同决定——一致则采纳，冲突则标记。解题者需要发现行列两个独立维度的多数投票和一致性判断机制。
</new_puzzle>

<new_puzzle>
- `description`：将输入中由路径连接的彩色节点网络简化为邻接矩阵形式的输出网格。
- `Input structure`：背景为 Black。网格中有若干 2x2 的实心彩色方块（"节点"），颜色各不相同（最多 5 个节点）。节点之间由一像素宽的 Grey 路径连接（水平或垂直直线段，可能有直角转弯）。不是所有节点对都有路径连接。
- `Rule`：
  - 识别所有节点及其颜色，按从左到右、从上到下的顺序编号。
  - 确定哪些节点对之间有 Grey 路径连接（4-连通追踪路径）。
  - 创建一个 KxK 的输出网格（K = 节点数），每个单元格对应一对节点。
  - 如果节点 i 和节点 j 有路径连接，在 (i,j) 和 (j,i) 位置填入 Green。
  - 对角线位置 (i,i) 填入节点 i 的颜色。
  - 其余位置为背景色。
- `Key insight`：空间中的路径网络被压缩为抽象的邻接矩阵——解题者需要发现输出是网络的图论表示，对角线编码节点身份，非对角线编码连接关系。
</new_puzzle>
