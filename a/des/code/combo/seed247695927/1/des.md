- `description`：根据每个封闭区域内部标记像素的颜色，从颜色图例中查找对应的填充图案，然后将该图案平铺填充到该区域内。
- `Input structure`：
  - 背景为 black。
  - 一种前景色（如 grey）构成一像素宽的正交线段网络，将网格划分为若干封闭的矩形区域。
  - 网格右下角有一个小型颜色图例区：图例由若干 3x3 的小方块组成，每个方块的边框用一种颜色绘制、内部填充 2x2 的另一种颜色。边框颜色是"键"，内部颜色是"值"。
  - 每个封闭区域内恰好有一个非背景、非线段颜色的单像素标记，其颜色与图例中某个方块的边框颜色匹配。

- `Rule`：
  - 识别线段网络划分出的所有封闭矩形区域。
  - 读取右下角图例区中的每个 3x3 方块，建立边框颜色到内部颜色的映射表。
  - 对每个封闭区域，找到其内部的单像素标记，查表得到对应的填充颜色。
  - 用该填充颜色将区域内所有背景像素替换，保留线段网络和标记像素不变。
  - 图例区域本身在输出中保持不变。

- `Key insight`：标记像素不是直接的填充色——它是图例中的查找键；解题者需要先发现图例的键值映射关系，再用标记颜色间接确定每个区域的实际填充色。
</new_puzzle>

<new_puzzle>
- `description`：将网格中散布的同色像素对通过它们共线关系进行配对，并在每对中点处绘制一个以该配对间距为边长的实心正方形。
- `Input structure`：
  - 背景为 orange。
  - 若干非背景颜色各自恰好有两个像素，分布在网格的不同位置。
  - 每对同色像素要么在同一行、要么在同一列上对齐。
  - 所有颜色对的中点处目前是背景色。

- `Rule`：
  - 对每种非背景颜色，找到其恰好两个像素的位置。
  - 计算这两个像素之间沿行或列方向的间距 d（以格数计）。
  - 找到这两个像素的行列中点。
  - 以该中点为中心，绘制一个边长为 d 的实心正方形，颜色使用该像素对的颜色。若正方形超出网格则裁剪。
  - 原始的两个像素在输出中被擦除为背景色。

- `Key insight`：每对同色像素不是要被连接的端点，而是定义了一个隐含正方形的对称参考点；像素间距编码正方形的尺寸，中点编码正方形的位置。
</new_puzzle>

<new_puzzle>
- `description`：识别网格中每个"窗户"形状对象的缺口方向，然后按缺口方向将对应颜色的射线从窗户内部射出到网格边缘。
- `Input structure`：
  - 背景为 black。
  - 若干个 5x5 的"窗户"对象分布在网格中：每个窗户是一个一像素宽的矩形框，框的四条边各用一种颜色绘制（上、下、左、右边各自颜色不同），且其中恰好一条边有一个单像素的背景色缺口（即该边中间的一个像素被擦除为背景色）。
  - 每个窗户的内部（3x3 区域）全部为背景色。

- `Rule`：
  - 对每个窗户，找到其四条边中有缺口的那条边。
  - 确定缺口的朝向（上/下/左/右）。
  - 从缺口位置出发，沿缺口朝外的方向，用缺口所在边的颜色绘制一条一像素宽的射线，直到到达网格边界。
  - 射线经过的所有背景像素被涂上该颜色；如果射线遇到另一个窗户的边框像素，射线在该像素之前停止。
  - 所有窗户对象本身保持不变。

- `Key insight`：每个窗户有四种颜色标记四个方向，但只有缺口边的颜色会被"激活"为射线——解题者需要先发现缺口选择了哪条边的颜色，再理解射线从缺口向外发射的规则。
</new_puzzle>

<new_puzzle>
- `description`：根据分隔线将网格分为上下两个面板，上面板中每个对象的孔洞数量与下面板中颜色图例的孔洞数量匹配，匹配后用图例颜色重新着色该对象的边框。
- `Input structure`：
  - 背景为 azure。
  - 一条完整的水平 grey 分隔线将网格分为上下两个面板。
  - 上面板包含若干用 grey 颜色绘制的一像素宽空心矩形框对象，每个框内部可能包含零个或多个由 grey 像素进一步分隔出的背景区域（孔洞）。
  - 下面板包含若干小型彩色对象（非 grey、非背景色），每个彩色对象也是一个一像素宽空心框，内部同样有零个或多个孔洞。每种颜色只出现一次，且每种颜色的孔洞数量各不相同。

- `Rule`：
  - 统计下面板中每个彩色对象内部的 4-连通背景孔洞数量，建立孔洞数到颜色的映射。
  - 统计上面板中每个 grey 框对象内部的 4-连通背景孔洞数量。
  - 将上面板中每个 grey 框对象的边框重新着色为下面板中孔洞数量相同的彩色对象的颜色。
  - 框内部的背景像素和孔洞保持不变，下面板保持不变。

- `Key insight`：颜色匹配的关键不是形状或大小的视觉相似性，而是拓扑特征——孔洞数量。解题者需要分两层推理：先发现下面板是按孔洞数编码的颜色图例，再用孔洞计数完成上面板的颜色分配。
</new_puzzle>

<new_puzzle>
- `description`：在网格中找到所有 T 形标记，根据 T 形的朝向确定投影方向，然后将 T 形茎端指向的封闭区域用 T 形横杆的颜色填充，并在该区域对面边界画一条横杆色的标记线。
- `Input structure`：
  - 背景为 black。
  - 一种分隔色（如 blue）形成一像素宽的正交线段网络，将网格划分为若干矩形区域。
  - 在某些线段旁边，存在由三个像素组成的 T 形标记：一个两像素宽的横杆（用颜色 A 绘制）和一个单像素的茎（用颜色 B 绘制），茎从横杆的中心向一个方向伸出一格。
  - 横杆紧贴分隔线网络的某条线段，茎伸入横杆所在线段相邻的一个封闭区域。

- `Rule`：
  - 对每个 T 形标记，茎伸入的方向确定目标区域。
  - 用横杆颜色 A 填充该目标区域内的所有背景像素。
  - 在该区域与茎方向相对的那条边界线段上，用茎颜色 B 画一条长度等于横杆长度的标记线段，行或列位置与 T 形横杆在本侧边界的对称位置对应。
  - 保留分隔线网络和 T 形标记本身不变。

- `Key insight`：T 形标记同时编码了三个信息：茎的方向选择了目标区域，横杆的颜色决定了填充色，横杆的位置决定了对面边界标记线的位置。解题者需要发现 T 形朝向、区域选择、双色填充的三层结构。
</new_puzzle>

<new_puzzle>
- `description`：将散布在网格中的彩色像素按其所在的格子行带和列带分组，每个交叉区域取主导颜色，生成一个压缩网格后沿其长轴方向翻转。
- `Input structure`：
  - 背景为 green。
  - 若干条完整的水平和垂直 maroon 分隔线将网格划分为 R 行 C 列的矩形格子阵列。
  - 每个格子内散布着若干非背景、非分隔色的彩色像素。每个格子内有一个占主导地位的颜色（出现次数最多），但也可能夹杂少量其他颜色的噪声像素。

- `Rule`：
  - 用分隔线将网格划分为 R 行 C 列的格子阵列。
  - 对每个格子，统计其中非背景、非分隔色像素的颜色频率，取出现次数最多的颜色作为该格子的代表色。
  - 构建一个 R x C 的输出网格，每个单元格填充对应格子的代表色。
  - 如果 R > C，将输出网格上下翻转；如果 C > R，将输出网格左右翻转；如果 R == C，不翻转。

- `Key insight`：第一层推理是发现格子内的多数投票规则，第二层推理是发现压缩后的翻转方向取决于粗粒度网格的长短轴方向——这不是对原始网格的操作，而是对压缩结果的后处理。
</new_puzzle>
