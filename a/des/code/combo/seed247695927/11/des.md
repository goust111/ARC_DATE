<new_puzzle>
- `description`：将每个前景对象按其像素数作为垂直条高度绘制，然后按高度从矮到高重新分配到各槽位，每个槽位保留其原始颜色。
- `Input structure`：
  - 背景色；一条单色水平基线横跨整个网格宽度。
  - 若干不同颜色的单色垂直条从基线向上延伸。

- `Rule`：
  - 按高度从矮到高对条形轮廓排序。
  - 按从左到右的顺序对原始 x 位置（槽位）排序。
  - 将第 i 个最矮的轮廓放入第 i 个最左的槽位，重涂为该槽位的原始颜色。
  - 基线保持不变。

- `Key insight`：每个槽位保留其 x 位置和颜色身份；只有条形轮廓按高度顺序在槽位之间重新分配。
</new_puzzle>

- `description`：用十字形背景缺口面向的框架边颜色填充每个十字缺口。
- `Input structure`：
  - 一个一像素宽矩形框有四条不同颜色的边和中性角像素。
  - 框内有主导背景色和一种前景对象色。
  - 某些对象边界包含五像素十字形的背景缺口。

- `Rule`：
  - 找到每个其对面由前景对象像素支撑、开口面向某条框架边的背景十字。
  - 用面向的框架边颜色重绘该十字的五个像素。
  - 其他所有像素保持不变。

- `Key insight`：框架边颜色是开口缺口的方向标签。
</new_puzzle>

<new_puzzle>
- `description`：按形状是否重复（旋转/翻转不变）将对象分流到网格顶部或底部。
- `Input structure`：
  - 背景为主导色。
  - 若干多色连通分量（8-连通）散布在网格中。

- `Rule`：
  - 计算每个对象的规范形状（二值掩码，旋转和翻转不变）。
  - 形状出现在两个或更多分量中的对象→平移到顶部边缘（第 0 行）。
  - 形状唯一的对象→平移到底部边缘。
  - 水平位置（左列）保持不变；仅垂直平移改变。

- `Key insight`：排序标准是形状频率（旋转不变），不是面积——重复形状上移，唯一形状下移。
</new_puzzle>

<new_puzzle>
- `description`：将 4-连通前景路径上的颜色序列整体反转，保持路径形状固定不变。
- `Input structure`：
  - 背景为主导色。
  - 所有非背景像素形成一条多色 4-连通一像素宽路径。
  - 路径恰好有两个端点且无分支。

- `Rule`：
  - 从一个端点走到另一个端点。
  - 用原始路径颜色的反转顺序替换同一路径上的颜色。
  - 所有背景像素保持不变。

- `Key insight`：几何上没有任何移动；只有写在路径上的颜色字符串在两个端点之间被反转。
</new_puzzle>
