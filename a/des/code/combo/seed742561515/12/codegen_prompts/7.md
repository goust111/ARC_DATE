    - 第一个像素的颜色表示旋转量：Red = 不旋转，Blue = 顺时针 90 度，Green = 顺时针 180 度，Yellow = 顺时针 270 度。

  - 输出网格的宽度与输入相同，高度等于模板区域内部的高度。
  - 输出背景为 Black。
  - 对每组指令，取模板图案，先按旋转颜色指示的角度顺时针旋转，再根据翻转标记决定是否水平镜像。
  - 将变换后的图案放置在输出网格中，图案的左边缘对齐 Azure 像素所在的列，图案顶部对齐输出的第 0 行。

- `Key insight`：解题者需要三步归纳：第一步识别模板区域是被复制的源图案；第二步破解指令条中颜色编码的旋转/翻转含义（需要从多个样例中对比旋转颜色与输出图案朝向的对应关系）；第三步理解 Azure 像素的列位置即为放置坐标。
