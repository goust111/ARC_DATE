<new_puzzle>
description：根据每个封闭区域内部"指针"三角形的朝向，从区域边界的对应侧向外喷射同色射线，射线长度等于该封闭区域内非背景像素的总数。

Input structure：
- 背景为 black。
- 网格中散布着若干由 grey 像素围成的封闭矩形区域（边框宽度为 1 像素）。
- 每个矩形区域内部恰好包含一个由某种非 grey、非 black 颜色（如 red、blue、green 等）绘制的 3 像素直角三角形（L 形状，占据 2x2 方格的三个格子），以及零个或多个同色的额外标记像素。
- 三角形的缺角方向指示射线发射的方向（缺角朝上表示向上发射，缺角朝右表示向右发射，以此类推）。

Rule：
- 第一步：识别每个 grey 矩形边框内部的所有非 black 像素数量 N（包括三角形和额外标记像素）。
- 第二步：识别三角形的缺角方向 D（上/下/左/右）。
- 第三步：从矩形边框在方向 D 上的外侧中点位置开始，沿方向 D 画一条长度恰好为 N 个像素的射线，颜色与三角形相同。若射线超出网格边界，则在边界处截断。
- 矩形边框和内部内容保持不变。

Key insight：
- 三角形既是方向指示器又是计数的一部分——解题者需要先发现缺角方向决定射线方向，再发现区域内像素总数决定射线长度，两层规则分别需要独立归纳。
</new_puzzle>

<new_puzzle>
description：将散落的彩色碎片按颜色匹配到对应颜色边框的空容器中，碎片在容器内的放置位置由碎片相对于容器的来源方向决定——碎片从哪个方向来，就贴靠容器内部的对侧墙壁。

Input structure：
- 背景为 black。
- 网格中有若干矩形"容器"，每个容器是一个由某种颜色（如 red、blue、green）绘成的单像素宽空心矩形框，内部全为 black。
- 网格中还散布着若干小型 4-连通前景碎片（形状不规则，像素数 2-5），每个碎片的颜色与恰好一个容器的边框颜色相同。
- 每个容器颜色对应恰好一个碎片，每个碎片也恰好对应一个容器。
- 碎片不与任何容器接触或重叠，且碎片的包围盒小于对应容器的内部空间。

Rule：
- 第一步：将每个碎片与其同色容器配对。
- 第二步：确定碎片中心相对于其配对容器中心的主方向（上、下、左或右，取偏移量较大的轴，若等则取水平轴）。
- 第三步：将碎片移入容器内部，贴靠与来源方向相反的那一侧内壁。例如碎片在容器的左边（来源方向=左），则碎片被放入容器内部并紧贴容器右侧内壁；碎片在容器上方（来源方向=上），则碎片紧贴容器底部内壁。碎片在贴靠轴上紧贴内壁，在垂直于贴靠轴的方向上居中放置（若无法精确居中则偏向行号/列号较小的一侧）。
- 第四步：清除碎片的原始位置（恢复为 black）。

Key insight：
- 颜色匹配只是第一层；第二层需要发现碎片的空间方位决定了它在容器内的停靠侧，这种"方向反转"规则需要从多个样例的不同方位中归纳得出。
</new_puzzle>

<new_puzzle>
description：网格中的彩色种子像素沿灰色管道网络扩散，在管道交叉口处按交叉口的局部形状决定转向规则，最终为整条管道路径染上种子颜色。

Input structure：
- 背景为 black。
- grey 像素构成若干条宽度为 1 的管道路径，管道仅沿水平或垂直方向延伸，管道之间通过直角转弯或 T 形/十字交叉口相连，形成一个连通的管道网络。
- 网格中有若干彩色"种子"像素（如 red、blue、orange 等），每个种子像素恰好位于某条管道的一个端点（管道的死胡同末端，该位置仅有一个 grey 邻居方向）。
- 每条管道分支的另一端要么是另一个种子、要么是 T 形/十字交叉口。

Rule：
- 每个种子像素开始沿其唯一相邻的管道方向传播自身颜色，将沿途的 grey 像素替换为种子颜色。
- 当传播到达一个 L 形转角（恰好有 2 个 grey/已染色邻居形成直角）时，颜色继续沿转弯方向传播。
- 当传播到达一个 T 形交叉口（3 个方向有管道）时，颜色仅沿直行方向继续（不拐弯），若传播方向本身就是 T 形的"顶部"（即前方无管道），则传播在此停止。
- 当传播到达十字交叉口（4 个方向有管道）时，颜色沿所有三个非来源方向继续传播。
- 当两种颜色在同一像素相遇时，先到者占据该像素（若同时到达，则管道路径更短者优先；若路径长度也相同，取颜色名称字母序靠前者）。
- 传播结束后，种子像素本身保留原色。

Key insight：
- 管道染色看似简单扩散，但交叉口的局部拓扑形状（L/T/十字）决定了不同的转向策略——尤其是 T 形交叉口"只直行不拐弯"的规则是最隐蔽的一层，需要从多个样例中对比不同交叉口处的传播行为才能归纳出来。
</new_puzzle>

<new_puzzle>
description：网格中每个彩色对象的形状编码了一种"印章模板"，对象旁边的单像素标记指定印章的放大倍数，最终在输出中用放大后的印章替换原对象。

Input structure：
- 背景为 black。
- 网格中有若干个由不同颜色绘制的小型 4-连通对象（每个对象 2-6 个像素），对象之间互不接触。
- 每个对象旁边（与对象的包围盒相邻但不接触对象本体的位置）恰好有一个 yellow 单像素标记。
- yellow 标记与其最近对象的包围盒之间恰好间隔 K-2 个 black 像素（K >= 2），其中 K 即为放大倍数。即标记紧邻包围盒时间隔为 0 表示放大 2 倍，间隔 1 个像素表示放大 3 倍，以此类推。

Rule：
- 第一步：对每个对象，计算其 yellow 标记到对象包围盒最近边的间距 gap，得到放大倍数 K = gap + 2。
- 第二步：将对象视为一个最小包围盒内的位图模板，将模板中每个像素放大为 K x K 的方块，得到放大后的印章图案。
- 第三步：将放大后的印章以原对象包围盒的左上角为锚点绘制到输出网格上（保持对象颜色），覆盖该区域原有内容。
- 第四步：清除所有 yellow 标记像素。
- 若放大后的印章超出网格边界，则在边界处截断。

Key insight：
- 标记像素的作用不是指示方向或位置，而是通过其与对象的距离编码了一个数值参数（放大倍数）——解题者需要跨多个样例比较不同间距和放大结果之间的对应关系才能归纳出 K = gap + 2 的规则。
</new_puzzle>

<new_puzzle>
description：网格被分为上下两个面板：上面板包含若干形状各异的彩色模板对象，下面板包含同样数量的灰色"影子"对象；每个影子的形状是某个模板经过特定二面体变换（旋转/翻转）后的结果，输出时需要将影子替换为对应模板的颜色，同时在影子所在位置的四周边框画出一个单像素宽的框，框的颜色由变换类型决定。

Input structure：
- 背景为 black。
- 网格在中间有一条水平的 maroon 分隔线，将网格分为上下两个面板。
- 上面板包含 2-4 个不同颜色的 4-连通前景对象（形状各异，非对称，每个 4-8 像素），对象之间互不接触。
- 下面板包含相同数量的 grey 对象，每个 grey 对象的形状恰好是上面板某个对象经过一种二面体变换后的结果（原样、顺时针 90 度、180 度、270 度、水平翻转、垂直翻转、主对角线翻转、副对角线翻转，共 8 种之一）。
- 上面板的每个对象恰好与下面板的一个 grey 对象配对（一一对应）。

Rule：
- 第一步：通过形状匹配，将每个下面板 grey 对象与其对应的上面板彩色对象配对。
- 第二步：确定从上面板对象到下面板 grey 对象所施加的二面体变换类型。
- 第三步：将下面板每个 grey 对象的颜色替换为其配对的上面板对象的颜色。
- 第四步：根据变换类型，在该对象包围盒外扩一圈的位置绘制单像素宽的边框——框的颜色按以下规则确定：原样不变则为 red；旋转（90 度/180 度/270 度）则为 blue；翻转（水平/垂直）则为 green；对角线翻转（主/副）则为 orange。
- 上面板和分隔线保持不变。

Key insight：
- 第一层推理是形状匹配（需要心理旋转来识别哪个 grey 形状对应哪个模板）；第二层推理是发现边框颜色并非随机，而是编码了变换的类别（恒等/旋转/翻转/对角线翻转），需要从多个样例中比较变换类型与边框颜色的对应关系才能归纳。
</new_puzzle>
