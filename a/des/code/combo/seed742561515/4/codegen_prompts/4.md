description：网格中每个彩色对象的形状编码了一种"印章模板"，对象旁边的单像素标记指定印章的放大倍数，最终在输出中用放大后的印章替换原对象。

Input structure：
- 背景为 black。
- 网格中有若干个由不同颜色绘制的小型 4-连通对象（每个对象 2-6 个像素），对象之间互不接触。
- 每个对象旁边（与对象的包围盒相邻但不接触对象本体的位置）恰好有一个 yellow 单像素标记。
- yellow 标记与其最近对象的包围盒之间恰好间隔 K-2 个 black 像素（K >= 2），其中 K 即为放大倍数。即标记紧邻包围盒时间隔为 0 表示放大 2 倍，间隔 1 个像素表示放大 3 倍，以此类推。

Rule：
- 第一步：对每个对象，计算其 yellow 标记到对象包围盒最近边的间距 gap，得到放大倍数 K = gap + 2。
- 第二步：将对象视为一个最小包围盒内的位图模板，将模板中每个像素放大为 K x K 的方块，得到放大后的印章图案。
- 第三步：将放大后的印章以原对象包围盒的左上角为锚点绘制到输出网格上（保持对象颜色），覆盖该区域原有内容。
- 第四步：清除所有 yellow 标记像素。
- 若放大后的印章超出网格边界，则在边界处截断。

Key insight：
- 标记像素的作用不是指示方向或位置，而是通过其与对象的距离编码了一个数值参数（放大倍数）——解题者需要跨多个样例比较不同间距和放大结果之间的对应关系才能归纳出 K = gap + 2 的规则。
