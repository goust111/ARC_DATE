<new_puzzle>
根据框架颜色从调色板区域选取对应的填充图案，将每个框架内部填充为该图案。

Input structure
- 背景为主色（black）。网格分为两个区域：左侧是调色板区，右侧是工作区。
- 调色板区包含若干小矩形色块，每个色块由单一颜色的边框围成，内部填有某种由另一颜色构成的规则图案（如棋盘格、条纹、十字等），每个色块的边框颜色各不相同。
- 工作区包含若干大小不同的空心矩形框架，每个框架用单一颜色绘制（框架线宽为 1 像素），框架内部全部为背景色。框架的颜色与调色板中某个色块的边框颜色一致。

Rule
- 对于工作区中的每个空心框架，根据其边框颜色在调色板中找到匹配的色块。
- 将该色块内部的图案以平铺方式填充到框架内部区域（不包含边框本身），图案从框架内部左上角开始对齐，超出部分裁剪。
- 调色板区域在输出中保持不变，框架边框保持不变。

Key insight
- 边框颜色是索引键，将工作区框架与调色板色块配对；解题者需要同时识别"颜色匹配"和"图案平铺"两层规则——第一层确定使用哪个图案，第二层确定如何将小图案周期性地铺满大框架。
</new_puzzle>

<new_puzzle>
将散落的彩色碎片按形状互补性拼合，并用两块碎片颜色的混合规则决定拼合体的最终颜色。

Input structure
- 背景为主色（black）。网格中散布着若干 4-连通的彩色碎片（每个碎片为单一颜色）。
- 每个碎片的形状恰好能与另一个碎片拼合成一个完整的矩形（即两块碎片的边界箱尺寸相同，像素位置互补——一个碎片占据的格子恰好是另一个碎片在同尺寸边界箱内未占据的格子）。
- 互补碎片对的颜色各不相同。网格中还存在一个位于右下角的小型 2×N 颜色查找表：每行包含两个颜色像素，表示"当这两种颜色的碎片拼合时，结果矩形使用第三种颜色"——第三种颜色绘制在该行右侧紧邻的一个额外像素中。

Rule
- 识别所有互补碎片对：两个碎片的边界箱尺寸相同，且像素位置在边界箱坐标系中完全互补。
- 将每对碎片平移拼合到同一位置（以两者中位置靠左上的碎片为锚点）。
- 在颜色查找表中找到与这对碎片两种颜色匹配的行，将拼合后的完整矩形统一涂为该行指定的第三种颜色。
- 删除查找表本身，背景保持不变。

Key insight
- 第一层推理是空间互补性——需要发现哪些碎片在形状上恰好拼成矩形；第二层推理是颜色映射——拼合后的颜色既不是碎片 A 的颜色也不是碎片 B 的颜色，而是由查找表决定的第三种颜色。两层规则缺一不可。
</new_puzzle>

<new_puzzle>
沿每个箭头指向的方向推送相邻对象，推送距离等于箭头尾部所在封闭区域内标记像素的数量；被推送对象在原位留下与箭头同色的轨迹。

Input structure
- 背景为主色（grey）。网格中包含以下元素：
  - 若干由单一颜色绘制的封闭矩形区域（边框颜色各不相同，内部为背景色，部分内部格子被涂上与边框不同的标记色像素）。
  - 若干箭头形状：每个箭头由 3 个像素组成——2 个像素构成尾部直线段，1 个像素偏移构成箭头尖端，三者同色。箭头方向由尾部到尖端的偏移方向决定（上、下、左、右四方向之一）。箭头尾部的末端像素恰好位于某个封闭矩形的边框上（即箭头从矩形边框向外伸出）。
  - 箭头前方（沿箭头方向）存在一个独立的小型单色 4-连通对象（被推送目标），目标与箭头之间可能隔有若干背景像素。

Rule
- 对于每个箭头，数出其尾部所依附的封闭矩形内部的标记像素数量 N。
- 将箭头前方的目标对象沿箭头方向平移 N 格。
- 目标对象经过的路径格子（不含最终位置）涂上箭头的颜色，形成彩色轨迹。
- 箭头本身、封闭矩形及其内部标记像素保持不变。

Key insight
- 解题者首先需要理解箭头与矩形的从属关系（箭头从哪个矩形伸出），然后需要发现推送距离不是由箭头长度或目标大小决定，而是由矩形内部隐藏的标记像素计数决定——这是一个"远程参数传递"机制，视觉上不明显但可通过对比样例归纳。
</new_puzzle>

<new_puzzle>
将网格中每个连通区域内部的孔洞形状提取出来，按孔洞面积从小到大依次填入一组预设颜色序列，颜色序列由网格边缘的色带定义。

Input structure
- 背景为主色（black）。网格最左列为一条纵向色带，从上到下包含 K 个不同颜色的像素（每个颜色恰好 1 像素），它们定义了一个有序颜色序列。
- 网格其余部分包含若干由同一种前景色（如 blue）绘制的独立 4-连通区域。
- 每个区域内部可能包含一个或多个被前景色完全包围的背景色孔洞（4-连通的背景色连通分量，不与网格边界相连）。不同区域内的孔洞数量和面积各不相同。

Rule
- 对于每个前景色连通区域，找出其包围的所有孔洞，按孔洞面积（像素数量）从小到大排序。
- 将颜色序列中的第 1 个颜色填入面积最小的孔洞，第 2 个颜色填入面积次小的孔洞，依此类推。
- 如果某个区域的孔洞数量少于 K，则只使用序列前几个颜色；如果恰好等于 K，则全部使用。（所有区域的孔洞数量均不超过 K。）
- 左侧色带在输出中保持不变，前景色区域的像素保持不变。

Key insight
- 第一层推理是识别色带定义了一个有序颜色映射表；第二层推理是发现孔洞按面积排序后与颜色序列按位置对应——排序依据不是孔洞的空间位置而是其面积大小，这需要解题者通过对比多个样例中不同区域的孔洞着色来归纳。
</new_puzzle>

<new_puzzle>
根据种子像素的颜色在对应颜色的管道网络中进行洪水填充，当两种颜色的填充流在同一管道交叉口相遇时，交叉口像素变为第三种混合颜色。

Input structure
- 背景为主色（black）。网格中存在由 grey 像素构成的管道网络——一组宽度为 1 像素的水平和垂直通道，通道之间通过交叉点相连，形成不规则的网格状结构。
- 管道网络中散布着若干"种子像素"，每个种子像素为非背景、非 grey 的某种颜色（如 red、blue、green 等），且位于管道通道上（替换了该位置原本的 grey 像素）。
- 网格右上角有一个小型"混合表"：由若干行组成，每行 3 个像素，前两个像素表示两种输入颜色，第三个像素表示它们相遇时产生的混合颜色。

Rule
- 从每个种子像素出发，沿管道网络（grey 像素构成的 4-连通路径）进行洪水填充，将所有可达的 grey 像素涂为种子的颜色。
- 当同一个 grey 像素可被两个不同颜色的种子到达时（即该像素是两条填充流的交汇处），查阅混合表找到这两种颜色对应的混合颜色，将该像素涂为混合颜色。
- 如果某个 grey 像素只能被一种颜色到达，则直接涂为该颜色。
- 种子像素本身颜色不变，混合表保持不变，背景像素不变。管道网络设计保证不会出现三种及以上颜色在同一像素交汇的情况。

Key insight
- 第一层推理是发现管道中的灰色像素会被最近的种子颜色"灌满"；第二层推理是发现交叉口处两种颜色相遇不是简单的覆盖或保留，而是通过混合表映射为第三种颜色；第三层推理是理解混合表本身的对应关系需要从样例中归纳。三层结构使得解题者必须同时掌握空间传播规则和颜色合成规则。
</new_puzzle>

<new_puzzle>
将每个形状对象沿其内部箭头标记指示的方向翻转，然后根据对象边界箱接触网格边界的边数选择重新着色。

Input structure
- 背景为主色（black）。网格中包含若干互不重叠的 4-连通单色对象（每个对象颜色各不相同）。
- 每个对象内部恰好嵌入了一个由 maroon 像素构成的 3 像素 L 形箭头标记（占据对象内部 2×2 区域的三个格子，缺失的角指示翻转方向：缺失角在右上表示水平翻转，缺失角在左下表示垂直翻转，缺失角在左上表示沿主对角线翻转，缺失角在右下表示沿副对角线翻转）。
- 网格四个边缘各有一个单独的颜色像素（位于边缘中点位置），分别标记为：顶部边缘 = 颜色 A、右侧边缘 = 颜色 B、底部边缘 = 颜色 C、左侧边缘 = 颜色 D。

Rule
- 对于每个对象，根据其内部箭头标记指示的方向，将对象在其边界箱内执行相应翻转（水平 / 垂直 / 主对角线 / 副对角线），翻转后箭头标记一并变换。
- 翻转完成后，检查每个对象的边界箱接触了网格的哪些边界（上 / 右 / 下 / 左）。
- 将对象重新着色为它所接触的那些边界上标记颜色的组合规则：若只接触一条边界，涂为该边界的标记颜色；若接触两条边界，涂为两个标记颜色中在网格边缘像素从左上角顺时针扫描时先出现的那个颜色。
- 边缘标记像素和背景保持不变；箭头标记像素在翻转后被对象新颜色覆盖（即消失）。

Key insight
- 第一层推理是识别 L 形标记的缺失角方向与翻转类型的对应关系；第二层推理是发现翻转后对象的位置决定了它接触哪些网格边界，而边界接触情况又通过边缘标记像素映射到最终颜色——翻转既改变形状又间接决定了着色，两步推理环环相扣。
</new_puzzle>

<new_puzzle>
在分隔线两侧分别识别"模板"和"控制信号"，用控制信号选择模板的哪些行列被保留，然后将保留的子网格输出。

Input structure
- 网格被一条贯穿整个宽度的 red 水平线分为上下两部分。
- 上半部分是一个由多种颜色构成的矩形图案（模板），尺寸为 R 行 × C 列。
- 下半部分包含两组标记：
  - 一组"行选择标记"：位于下半部分最左列，由若干 green 像素组成，每个 green 像素所在的行号（相对于下半部分起始行的偏移）指示模板中对应行号的行应被保留。
  - 一组"列选择标记"：位于下半部分最上行（紧贴 red 分隔线下方），由若干 yellow 像素组成，每个 yellow 像素所在的列号指示模板中对应列号的列应被保留。

Rule
- 从模板中仅保留行选择标记和列选择标记同时指定的行和列的交集，提取出一个子网格。
- 输出网格的尺寸为（被选择的行数）×（被选择的列数），内容为模板中对应位置的像素。
- 被选择的行和列保持原有的相对顺序。

Key insight
- 第一层推理是发现 red 线是分隔符，上方是数据、下方是控制信号；第二层推理是理解两组不同颜色的标记分别控制行和列的筛选，输出是行列交集的子矩阵——这需要解题者同时追踪两个维度的选择逻辑，而不是简单的裁剪或遮罩。
</new_puzzle>
