<new_puzzle index="7">
在分隔线两侧分别识别"模板"和"控制信号"，用控制信号选择模板的哪些行列被保留，然后将保留的子网格输出。

Input structure
- 网格被一条贯穿整个宽度的 red 水平线分为上下两部分。
- 上半部分是一个由多种颜色构成的矩形图案（模板），尺寸为 R 行 × C 列。
- 下半部分包含两组标记：
  - 一组"行选择标记"：位于下半部分最左列，由若干 green 像素组成，每个 green 像素所在的行号（相对于下半部分起始行的偏移）指示模板中对应行号的行应被保留。
  - 一组"列选择标记"：位于下半部分最上行（紧贴 red 分隔线下方），由若干 yellow 像素组成，每个 yellow 像素所在的列号指示模板中对应列号的列应被保留。

Rule
- 从模板中仅保留行选择标记和列选择标记同时指定的行和列的交集，提取出一个子网格。
- 输出网格的尺寸为（被选择的行数）×（被选择的列数），内容为模板中对应位置的像素。
- 被选择的行和列保持原有的相对顺序。

Key insight
- 第一层推理是发现 red 线是分隔符，上方是数据、下方是控制信号；第二层推理是理解两组不同颜色的标记分别控制行和列的筛选，输出是行列交集的子矩阵——这需要解题者同时追踪两个维度的选择逻辑，而不是简单的裁剪或遮罩。
</new_puzzle>

## 实现要求

1. `main(grid)` 必须实现新题描述中的确定性转换规则，不能只识别 `generate_input()` 的固定模板。
2. `generate_input()` 必须随机生成多样样例，不能固定死。随机维度应覆盖：网格大小、对象数量、位置、颜色、方向、形状参数或关键分支。
3. 生成器必须保证输入满足 `main()` 的隐式假设：对象不重叠、不越界、特殊标记唯一或可区分、匹配关系无歧义、关键分支出现概率相同。
4. 禁止把 ARC 颜色 id 当作人类不可见的数值语义参与排序、大小比较或隐藏映射。颜色变化必须有可见结构线索。注意颜色亮度等也是不可见信息，若描述中出现违规的颜色id或者亮度，可自行使用少量的固定颜色替代，但注意生成时要在三个以内输入输出网格中对所有变换100%覆盖度。
5. 输出样例要视觉清晰：避免对象粘连、覆盖关系混乱、同一像素多重语义、过密导致规则不可读。
6. 若规则有多个分支，生成器不能长期固定成一个分支；应让分支在随机样例中合理出现。
7. 代码风格参考 `ARC_code`：使用 `numpy`，必要时使用本地 helper，但目标文件应能被 `SourceFileLoader` 直接加载。
8. 可以在目标目录放公共 helper 文件，但若只实现一道题，优先保持目标文件自包含，减少额外依赖。
