  - 每种前景色恰好出现一个源对象和一个箭头。
  - 箭头位于源对象的正上方、正下方、正左方或正右方（箭头 bounding box 的中心与源对象 bounding box 的中心在一个坐标轴上严格对齐，另一轴上箭头在源对象外侧）。

- `Rule`：
  - 第一步配对：通过颜色将每个箭头与其对应的源对象匹配。通过面积区分箭头（恰好5像素）和源对象（大于5像素）。
  - 第二步确定翻转轴：箭头尖端朝上或朝下时，对源对象执行上下翻转（沿水平轴镜像）；箭头尖端朝左或朝右时，对源对象执行左右翻转（沿垂直轴镜像）。

- `Key insight`：箭头同时编码了两个独立信息通道——其尖端朝向编码镜像类型（上下翻转还是左右翻转），其相对于源对象的空间方位编码镜像副本的放置方向。解题者需要先通过面积差异识别出5像素的箭头并与源对象区分开，再分别解读朝向和位置这两条独立的指令通道，缺一不可。
