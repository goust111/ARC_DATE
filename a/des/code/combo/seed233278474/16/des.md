<description>
根据封闭区域内部标记像素的颜色，从颜色图例行中查找对应的填充图案，再将该图案平铺填满整个封闭区域。

Input structure：
- 背景为最常见颜色。网格顶部有一行颜色图例：由若干 1×3 的色块组成，每个色块左端一个像素为"键色"，右侧两个像素构成一个 1×2 的二色图案（即"值图案"）。各色块之间用一个背景色像素分隔。
- 网格下方有若干用同一种非背景色绘制的封闭矩形框（单像素厚边框，内部为背景色）。
- 每个矩形框内部恰好有一个单像素标记，其颜色与图例中某个键色一致。

Rule：
- 保持图例行和所有矩形框边框不变。
- 对每个矩形框，读取其内部标记像素的颜色，在图例行中查找键色匹配的色块，取出对应的 1×2 值图案。
- 用该 1×2 图案在水平方向周期平铺，填满该矩形框的整个内部区域（含标记像素所在位置）。
- 垂直方向上每行都是相同的水平平铺。

Key insight：标记像素不是直接的填充色，而是索引图例的查找键；解题者必须先建立"键色→图案"的映射关系，再将图案作为纹理平铺，而非简单的单色填充。
</description>

<description>
将散落的彩色碎片按形状互补配对拼合成完整矩形，然后根据配对双方的颜色混合规则确定拼合矩形的最终颜色。

Input structure：
- 背景为黑色。网格中散布若干单色的不规则碎片（4-连通区域），每个碎片有唯一颜色。
- 所有碎片可以两两配对：每对碎片的形状互补——将其中一个碎片旋转 0°/90°/180°/270° 后，与另一个碎片拼合恰好形成一个无间隙的实心矩形。
- 网格底部有一行颜色混合图例：若干个 1×3 的色块，格式为"颜色A - 颜色B - 结果色"，其中中间像素为灰色分隔符。

Rule：
- 找出所有互补配对（通过尝试旋转使两碎片拼成矩形）。
- 对每一对，在图例中查找包含这两种颜色的条目（顺序无关），读取结果色。
- 输出网格中，将拼合后的完整矩形放置在两碎片中靠左上方那个碎片的原始位置，整个矩形用结果色填充。
- 未配对的碎片（若有）保持原样。

Key insight：解题需要两层独立推理——第一层是空间的：识别形状互补关系完成拼图配对；第二层是符号的：用配对双方的颜色查图例确定输出色，两层缺一不可。
</description>

<description>
识别网格中多个"信号塔"对象的朝向，沿其朝向发射射线直到碰到另一个对象，然后在射线路径上绘制与目标对象颜色相同的渐变条纹。

Input structure：
- 背景为最常见颜色。网格中有若干单色的 T 形对象（3 像素横杆 + 1 像素竖杆），每个 T 形颜色各不同。
- T 形的竖杆方向即为其"朝向"（竖杆指向的方向就是发射方向）。例如竖杆在横杆下方则朝向为向下。
- T 形对象之间有足够的背景间隔。

Rule：
- 对每个 T 形对象，从其竖杆末端沿朝向方向发射一条射线，射线在碰到另一个 T 形对象的任意像素或网格边界时停止。
- 如果射线碰到了另一个 T 形对象，则在射线经过的所有背景像素上，交替绘制发射方 T 形的颜色和目标方 T 形的颜色（从发射端开始，先画发射方颜色，再画目标方颜色，如此交替）。
- 如果射线碰到网格边界而未遇到任何对象，则不绘制任何内容。
- 所有 T 形对象本身保持不变。

Key insight：T 形的不对称结构隐含了方向信息——解题者需要先从 T 形的几何形状中推断出"朝向"这一隐含属性，然后才能确定射线方向和交替着色规则。朝向的识别是非平凡的第一层推理，射线碰撞后的双色交替是第二层。
</description>

<description>
在棋盘式的分区网格中，每个分区包含一个主色块和若干"投票像素"；统计投票像素的多数色来决定主色块是保留还是被擦除，然后将所有存活的主色块按面积从大到小重新排列到输出网格中。

Input structure：
- 网格被灰色单像素线分割成若干大小相等的矩形分区（类似表格）。
- 每个分区内部有一个较大的单色矩形色块（主色块，颜色各异）和若干散落的单像素点（投票像素），投票像素只使用绿色和红色两种颜色。
- 所有分区的灰色边框和背景（黑色）是固定元素。

Rule：
- 对每个分区，统计其中绿色投票像素和红色投票像素的数量。
- 如果绿色数量大于等于红色数量，该分区的主色块"存活"；否则主色块被"淘汰"（擦除为背景色）。
- 移除所有投票像素。
- 将所有存活的主色块提取出来，按面积从大到小排序。
- 在输出网格中，保持原有灰色分区框架不变，将排序后的主色块依次从左上到右下填入各分区（按行优先顺序），每个色块在新分区中居中放置，剩余空分区保持为背景色。

Key insight：解题包含三层推理——第一层：识别绿/红像素是"投票"而非装饰，理解多数决机制；第二层：意识到存活色块需要按面积重新排序而非保持原位；第三层：排序后的色块按行优先顺序重新填入原始分区框架。仅看到投票机制或仅看到排序都不够，必须将筛选、排序、重排三步串联。
</description>

<description>
将多个嵌套框架逐层剥离，根据每层框架的颜色在输出中绘制对应层数的同心环，环的尺寸由最内层框架内的标记数量决定。

Input structure：
- 背景为黑色。输入包含若干组嵌套的矩形框架，每组框架由外到内层层嵌套（每层一像素厚，颜色各不相同，层间有一像素的背景间隔）。
- 最内层的框架内部有若干单像素的橙色标记点，标记点的数量在 1 到 5 之间。
- 不同组的嵌套框架在网格中互不重叠，各自独立。

Rule：
- 对每组嵌套框架，记录从外到内的颜色序列 C1, C2, ..., Cn 和最内层的橙色标记数量 K。
- 清除该组所有框架和标记。
- 在该组原始中心位置，以 K 为最内层正方形环的半边长，绘制 n 层同心正方形环。最内层环使用颜色 Cn（即原始最内层框架色），向外依次为 Cn-1, ..., C1。每层环为一像素厚，相邻环之间无间隔紧密排列。
- 如果环超出网格边界则截断。

Key insight：解题需要两层独立推理。第一层：识别嵌套框架的层数和颜色顺序，理解层序在输出中被反转（原来的最内层变为输出的最内环，颜色顺序从内到外对应原始从内到外）。第二层：最内层的橙色标记数量不是装饰，而是控制输出环尺寸的参数——标记越多，最内环越大，从而整个同心环结构越大。颜色反转和尺寸编码必须同时被发现。
</description>

<description>
通过比较同一行中两个图案区域的差异像素位置，在第三个空白区域中按差异类型分类绘制投影。

Input structure：
- 背景为黑色。网格被两条竖直的灰色分隔线均匀分成三列区域：左区、中区、右区。
- 左区和中区各包含一个由多种颜色组成的图案，两个图案大小相同、位置对齐（行对齐），但有若干像素不同。
- 右区初始为空（全背景色）。
- 网格可能包含多行这样的三列结构，由水平灰色分隔线分隔。

Rule：
- 对每一行的左区和中区，逐像素比较。
- 两者颜色相同的位置在右区保持为背景色。
- 对于颜色不同的位置，按以下规则在右区对应位置绘制：如果左区该位置为背景色而中区不是，则绘制中区的颜色；如果中区该位置为背景色而左区不是，则绘制左区的颜色；如果两者都非背景但颜色不同，则绘制红色。

Key insight：右区不是简单的"找不同标记"，而是差异的语义分类投影——解题者必须归纳出三种差异情况（仅左有、仅右有、双方冲突）分别对应不同的输出规则，而非统一标记。相同像素反而不显示，这与直觉中"保留共同部分"的预期相反，增加了推理的隐蔽性。
</description>

<description>
将网格中每个"指针"对象所编码的方向与距离信息解码，找到其指向的目标像素，然后用目标像素的颜色回填指针对象的尾部。

Input structure：
- 背景为最常见颜色。网格中有若干"指针"对象和若干孤立的单色像素点（"目标点"）。
- 每个指针对象是一条由两种颜色组成的直线段（水平或垂直）：一端有一个红色箭头像素，其余像素为"尾部色"（各指针尾部色不同）。
- 红色像素位于线段的一端，标示指针的指向方向（从尾部到红色端的方向即为指向方向）。
- 指针线段的长度（包含红色像素在内的像素总数）编码了"距离"：从红色端沿指向方向前进该步数到达的位置即为目标点。

Rule：
- 对每个指针，确定其指向方向（从非红色尾部朝向红色端的方向）。
- 计算指针的总长度 L（所有像素数）。
- 从红色像素出发，沿指向方向前进 L 步，到达目标位置。该位置应恰好有一个目标点。
- 读取该目标点的颜色，将指针对象中所有非红色（尾部）像素重新着色为目标点的颜色。
- 红色箭头像素和目标点本身保持不变。

Key insight：指针对象同时编码了两种信息——方向（由红色端点的位置确定）和距离（由线段长度确定）。解题者必须先意识到红色像素标记的是"箭头"而非装饰，然后发现线段长度恰好等于到目标的距离，最后理解回填规则是用目标颜色替换尾部颜色。方向识别和距离解码是两个需要独立归纳的非显然规律。
</description>
</new_puzzle>
