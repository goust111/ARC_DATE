<description>
根据框架内部缺口的朝向，从外部精灵库中选取对应方向的精灵，再按精灵自身像素数量与框架空腔面积的匹配度决定配对关系。

Input structure：
- 背景为 Black。网格中有若干个由 Grey 像素构成的矩形框架（边框厚度为 1 像素）。
- 每个框架的四条边上恰好有一个单像素缺口（缺口位置可在上、下、左、右任意一边）。
- 框架外部散布着若干个由不同颜色构成的小型精灵（连通分量），每个精灵具有明确的朝向特征：精灵整体形状类似一个箭头，箭头尖端朝上、下、左或右。箭头的绘制方式为：一条 3 像素长的直线段加上尖端处向两侧各伸出 1 像素的翼，共 5 像素组成。
- 外部精灵的颜色各不相同，且每种朝向恰好有若干个精灵。

Rule：
- 对每个框架，确定其缺口所在的边（上、下、左、右），然后在外部精灵中找到箭头朝向与缺口方向相同的所有精灵。
- 在这些候选精灵中，选择像素数量（连通分量面积）与框架内部空腔面积最接近的那个精灵。
- 用该精灵的颜色填满框架的内部空腔（不包括边框本身），精灵本身从原位置擦除。
- 未被选中的外部精灵保持不变。

Key insight：
缺口方向是第一层筛选键，将精灵按朝向分组；面积匹配是第二层选择键，将同组精灵与具体框架配对。解题者需要先发现"缺口方向 = 箭头朝向"这一对应规则，再发现"面积最近匹配"这一分配规则。
</description>

<description>
将网格中散落的彩色同色像素对沿其连线的反方向各自延伸出与像素对间距等长的条带，形成以像素对为中心的对称色带结构。

Input structure：
- 背景为 Black。网格中散布着若干对同色像素，每对像素位于同一行或同一列上，且每种颜色恰好出现两个像素。
- 不同颜色的像素对可能在不同的行或列上，也可能共享行或列。
- 使用的颜色可包括 Red、Blue、Green、Yellow、Orange、Magenta 等。

Rule：
- 对每对同色像素，计算它们之间的间隔格数（不含两端自身），记为 D。
- 将两个同色像素之间的所有 Black 像素填充为该颜色（连同两端像素形成一条长度为 D+2 的色带核心）。
- 从每个端点像素出发，沿远离另一端点的方向再延伸 D 个像素，延伸部分也用该颜色填充。
- 如果延伸过程中遇到已经被其他颜色占据的像素，则在碰撞位置前一格停止（不覆盖对方）。处理顺序：间距 D 较小的颜色对优先处理。
- 延伸遇到网格边界时也停止。

Key insight：
每对像素的间距同时编码了两个信息：内部填充的长度和向外延伸的长度。解题者需要先识别"同色配对"关系，再发现"间距 = 延伸量"这一对称映射规则，最后还需推断出短距优先的碰撞处理顺序。
</description>
</new_puzzle>

<new_puzzle>
<description>
在网格中根据种子色块的形状向外扩展多层对称轮廓，每层轮廓的颜色由一个全局颜色环决定，该环的起点随种子自身颜色滑动。

Input structure：
- 背景为 Black。网格中有若干个小型彩色连通区域（种子），每个种子由单一颜色构成，形状各异（如 L 形、T 形、直线段等），大小在 2 到 5 像素之间。
- 每个种子周围已经绘制了 1 到 2 层"回声轮廓"——即沿种子边界向外逐层扩展 1 像素形成的环形区域，每层使用不同颜色。
- 存在一个全局颜色环序列（如 Red → Orange → Yellow → Green → Blue → Magenta → Red → ...），所有种子共享该环。种子自身的颜色为环中的起始位置，第 1 层轮廓为环中下一个颜色，第 2 层为再下一个，依此类推。
- 在训练样例中，部分种子只显示了 1 层轮廓，而另一些显示了 2 层轮廓。

Rule：
- 通过观察不同种子（颜色各异）的已有轮廓层颜色，交叉推断出全局颜色环的完整顺序。
- 对每个种子，保留已有的轮廓层不变，继续向外扩展缺失的轮廓层直到所有种子都补齐到 3 层。
- 第 N 层轮廓由所有与第 N-1 层轮廓 4-连通相邻且当前为 Black 的像素组成，使用环中对应位置的颜色。
- 如果两个种子的轮廓层在扩展过程中发生重叠，则重叠像素归属于层数较低（更靠近种子）的那一方。

Key insight：
颜色环不是固定的起点——它以每个种子自身颜色为起点在环上滑动。解题者必须从多个不同颜色种子的已有轮廓中交叉推断出这个共享色环的完整顺序，然后才能为每个种子预测正确颜色的后续轮廓层。这构成了"归纳色环序列"和"按序列补全轮廓"两层独立推理。
</description>

<new_puzzle>
<description>
将网格中由分隔线划分的若干子区域，按照各区域内部图案的旋转对称阶数进行分类，然后按阶数从高到低重新排列到输出网格的对应行中。

Input structure：
- 背景为 Black。网格被 Grey 的单像素水平线和垂直线分割成若干大小相同的正方形子区域（如 5×5）。
- 每个子区域内部包含一个由单一前景色绘制的小图案。不同子区域可使用不同的前景色。
- 每个图案具有不同的旋转对称性：有的图案旋转 90° 后与自身重合（4 阶旋转对称，例如加号形），有的仅旋转 180° 后重合（2 阶，例如 S 形），有的没有旋转对称性（1 阶，例如 L 形）。

Rule：
- 对每个子区域内的图案，判定其旋转对称阶数（1、2 或 4）。判定方法：将图案分别旋转 90°、180°、270°，看哪些旋转后与原图案完全重合。
- 输出网格与输入网格大小相同，Grey 分隔线位置不变。
- 将所有子区域按旋转对称阶数从高到低重新填入网格：4 阶的子区域依次填入第一行的槽位，2 阶的填入第二行，1 阶的填入第三行。同阶数内，按它们在输入中从左到右、从上到下的出现顺序排列。
- 每个子区域的图案内容和颜色保持不变，仅改变其所处的网格位置。
- 如果某一行的槽位数多于该阶数的图案数量，多余的槽位填充为纯 Black。

Key insight：
解题者需要对每个小图案进行心理旋转测试以判定其对称阶数——这不是简单的视觉属性（如颜色或大小），而是需要主动验证"旋转后是否重合"。分类完成后，还需要推断出"按阶数分行排列"的输出布局规则。两步推理相互独立且都需要非平凡的归纳。
</description>

<new_puzzle>
<description>
将网格中的管道网络按照阀门标记的开闭状态进行分段，然后从各颜色源出发沿管道进行洪水填充染色。

Input structure：
- 背景为 Black。网格中有一个由 Grey 像素构成的管道网络——Grey 像素形成若干条单像素宽的水平和垂直线段，线段在交叉处或端点处相连，构成一个连通的管道图。
- 管道网络中的某些像素被替换为特殊标记，分为两类：
  - **颜色源**：位于管道的末端（仅有一个相邻管道像素的端点），每个颜色源用唯一的非 Grey、非 Black 颜色标记（如 Red、Blue、Green 等）。每种颜色最多出现一个源。
  - **阀门**：位于管道线段的中间位置（恰好有两个相邻管道像素），用 Maroon 标记。阀门的开闭状态由其侧面（与管道方向垂直的方向）是否有一个 Yellow 像素决定：若阀门所在管道段为水平段，则检查阀门正上方或正下方是否有 Yellow 像素；若为垂直段，则检查阀门正左方或正右方。Yellow 像素存在表示阀门"关闭"，不存在表示阀门"开启"。
- 管道网络可能有分支（T 形或十字交叉）。

Rule：
- 从每个颜色源开始，沿管道网络进行洪水填充：将路径上经过的所有 Grey 像素染成该颜色源的颜色。
- 填充在以下情况停止：到达管道末端、遇到已被其他颜色占据的像素、或遇到"关闭"的阀门。
- "开启"的阀门允许颜色通过，阀门自身也被染成通过它的颜色。"关闭"的阀门阻断传播，阀门保持 Maroon 不变。
- 如果两个颜色源的填充路径在管道上相遇（某段管道到两个源的管道步数相等），则该段管道保持 Grey 不变。
- 所有 Yellow 指示器像素在输出中被擦除为 Black。

Key insight：
解题者需要完成三层推理：（1）识别管道网络的拓扑结构并区分颜色源（端点处的彩色像素）与阀门（中间的 Maroon 像素）；（2）通过阀门旁边垂直方向是否有 Yellow 像素推断阀门的开闭状态——这是最隐蔽的一层，因为 Yellow 像素不在管道上而是在管道外侧；（3）模拟从各颜色源出发的并行洪水填充过程，处理阀门阻断和等距竞争的边界情况。
</description>
</new_puzzle>
