<description>
将网格中散落的彩色同色像素对沿其连线的反方向各自延伸出与像素对间距等长的条带，形成以像素对为中心的对称色带结构。

Input structure：
- 背景为 Black。网格中散布着若干对同色像素，每对像素位于同一行或同一列上，且每种颜色恰好出现两个像素。
- 不同颜色的像素对可能在不同的行或列上，也可能共享行或列。
- 使用的颜色可包括 Red、Blue、Green、Yellow、Orange、Magenta 等。

Rule：
- 对每对同色像素，计算它们之间的间隔格数（不含两端自身），记为 D。
- 将两个同色像素之间的所有 Black 像素填充为该颜色（连同两端像素形成一条长度为 D+2 的色带核心）。
- 从每个端点像素出发，沿远离另一端点的方向再延伸 D 个像素，延伸部分也用该颜色填充。
- 如果延伸过程中遇到已经被其他颜色占据的像素，则在碰撞位置前一格停止（不覆盖对方）。处理顺序：间距 D 较小的颜色对优先处理。
- 延伸遇到网格边界时也停止。

Key insight：
每对像素的间距同时编码了两个信息：内部填充的长度和向外延伸的长度。解题者需要先识别"同色配对"关系，再发现"间距 = 延伸量"这一对称映射规则，最后还需推断出短距优先的碰撞处理顺序。
