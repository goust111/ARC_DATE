- `description`：根据边框缺口方向选取对应的内嵌模板层，将模板图案印刻到同色外壳对象的内部。
- `Input structure`：背景为黑色。网格中散布若干中空矩形外壳，每个外壳有不同的边框颜色。每个外壳的边框上恰好有一个单像素缺口，缺口位于上、下、左、右四侧之一。网格的四个角落各有一个小型实心图案（模板），分别对应上、下、左、右四个方位——左上角对应"上"，右上角对应"右"，右下角对应"下"，左下角对应"左"。每个模板用灰色绘制，尺寸不超过3x3。
- `Rule`：
  - 对每个中空矩形外壳，先判定其缺口所在的边（上/下/左/右）。

  - 将该模板居中放置在外壳的内部空腔中，模板像素的颜色替换为该外壳的边框颜色。
  - 四个角落的原始模板在输出中保持不变。
- `Key insight`：缺口方位不是移动方向，而是一个查表键——它选择四个角落中的哪一个模板被"盖章"到该外壳内部。解题者需要先建立"缺口方位→角落模板"的映射关系，再执行颜色替换的印刻操作。

- `description`：将散落的彩色碎片按颜色配对拼合，再根据拼合体的朝向决定其在输出网格中的排列轴。
- `Input structure`：背景为黑色。网格中有若干彩色小型连通块（碎片），每种非背景颜色恰好出现两个碎片。每对同色碎片的形状互补——将它们沿某个方向拼合后恰好形成一个完整的矩形。网格边缘有一条单像素宽的橙色标记线，位于上边或左边。
- `Rule`：
  - 找到所有同色碎片对。对每一对，尝试将两个碎片上下或左右拼合（不旋转、不翻转），找到能形成无间隙矩形的唯一拼合方式。
  - 若拼合后的矩形是横向的（宽>高），归入"横组"；若是纵向的（高>宽），归入"纵组"；若为正方形，归入"横组"。
  - 若橙色标记线在上边：先将横组的所有拼合矩形从左到右排列（按颜色在输入中首次出现的从左到右、从上到下扫描序），矩形间隔一列黑色；纵组排在横组下方，间隔一行黑色，同样从左到右排列。
  - 若橙色标记线在左边：先将纵组从上到下排列，横组排在纵组右侧。
  - 输出网格紧凑裁剪，无多余边距。
- `Key insight`：解题者需要完成两层非显然推理——第一层是发现同色碎片互补拼合成矩形，第二层是发现拼合矩形的长宽比决定了它被分配到哪个排列组，而橙色标记线决定了两组的排列主轴。
</new_puzzle>

- `description`：用栅格线将网格分成子区域，每个子区域内的散点图案充当"投票"来决定该区域的整体填充颜色。
- `Input structure`：背景为黑色。网格被若干条完整的灰色水平线和竖直线分割成矩形子区域（栅格）。每个子区域内散布着少量彩色像素点，可能包含多种颜色，也可能为空。网格的最下方一行（在最后一条灰色水平线之下）是一个颜色优先级图例：从左到右排列着若干不同颜色的单像素，表示优先级从高（左）到低（右）。
- `Rule`：
  - 对每个子区域，统计其中各非背景、非灰色颜色的像素数量。
  - 找出数量最多的颜色；如果有多个颜色数量并列，则参考最下方的优先级图例，选择优先级更高（更靠左）的颜色。
  - 将该子区域内所有非灰色像素清除，然后用胜出颜色完全填充整个子区域（灰色栅格线保持不变）。
  - 若某子区域内没有任何彩色像素，则保持为黑色背景不变。
  - 输出中移除最下方的优先级图例行。
- `Key insight`：散点不是要被保留的对象，而是对区域颜色的"投票"；优先级图例作为tie-break机制只在平局时才起作用，解题者必须先发现"多数决"规则，再发现图例的仲裁角色。
</new_puzzle>

- `description`：沿着每个箭头指示的方向复制目标图案，复制次数由箭头杆的长度编码，每份副本的颜色由途经的色带决定。
- `Input structure`：背景为黑色。网格中有若干小型实心图案（形状各异，每个用红色绘制，尺寸不超过4x4）。每个图案的某一侧紧邻一个由蓝色像素构成的箭头——箭头由一条直线杆和一个三角箭头尖组成，杆沿四个基本方向之一（上/下/左/右）延伸，箭头尖为杆末端的3像素宽三角形（例如向右的箭头尖为：杆末端右侧一列有3个蓝色像素，呈纵向排列，中间那个再向右延伸一个像素）。在箭头指向的方向上，与箭头杆平行地铺设着若干条横跨网格的单像素宽色带（非黑、非蓝、非红的颜色），色带之间间隔不等。
- `Rule`：
  - 对每个红色图案，找到其关联的蓝色箭头，确定箭头方向和杆长度（不含箭头尖的像素数）。杆长度 N 即为复制次数。
  - 沿箭头方向依次放置 N 份该图案的副本，每份副本紧接前一份（或紧接原图案），副本之间无间隔。
  - 每份副本的颜色由其中心像素所在位置处最近的色带颜色决定：取副本包围盒中心点，沿垂直于箭头方向找到最近的色带，副本整体着该色带的颜色。
  - 原始红色图案和蓝色箭头在输出中被清除（变为背景色），只保留新生成的彩色副本和色带。
- `Key insight`：箭头同时编码了两个独立信息——方向和数量（杆长度），而副本的颜色则来自第三个独立元素（色带），解题者需要分别识别这三个编码通道并正确组合。
</new_puzzle>

<new_puzzle>
- `description`：根据封闭区域的嵌套层级交替填色，再将最内层区域的形状作为印章盖到指定位置。
- `Input structure`：背景为黑色。网格中有一个由绿色像素绘制的大型封闭轮廓，该轮廓内部嵌套着一个由蓝色像素绘制的较小封闭轮廓，蓝色轮廓内部可能还嵌套一个由红色像素绘制的更小封闭轮廓（最多三层嵌套）。所有轮廓均为单像素宽的闭合曲线，互不接触。网格的某个角落有一个由黄色像素标记的小型十字标记（3x3，中心加四个正交邻居），标记不与任何轮廓重叠。
- `Rule`：
  - 识别所有嵌套轮廓，从最外层到最内层编号为第1层、第2层、第3层。
  - 对奇数层（第1层、第3层）轮廓围成的区域（不含轮廓线本身），用灰色填充其中属于背景的像素。偶数层（第2层）围成的区域中属于背景的像素用橙色填充。
  - 取最内层轮廓（若只有两层则取第2层，若有三层则取第3层）围成的区域形状（包含该层填充色的像素），将其裁剪为最小包围盒。
  - 将裁剪后的形状以黄色十字标记的中心为放置锚点（形状的左上角对齐到标记中心），用洋红色绘制到网格上，覆盖该位置原有内容。
  - 黄色十字标记在输出中被移除（变为背景或被洋红色覆盖）。
- `Key insight`：解题者需要完成三层推理——第一层是识别嵌套层级关系并建立奇偶交替填色规则，第二层是发现最内层区域的形状被提取为印章模板，第三层是发现黄色标记指定了印章的放置位置且印章使用了全新的颜色。
</new_puzzle>
