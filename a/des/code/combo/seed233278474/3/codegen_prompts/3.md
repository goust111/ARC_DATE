- `Input structure`：
  - 背景为 Black。
  - 网格被一条水平分隔线和一条垂直分隔线（均为 Grey 像素的完整行/列）分为四个矩形区域。
  - 四个区域中，每个区域有自己的纯色填充（四个区域颜色各不相同，且都不是 Grey 或 Black）。
  - 恰好有两个区域内各包含一个由 Maroon 像素绘制的箭头图案。箭头为 3×3 大小的标准图案：一个指向四个基本方向之一的箭头形状。具体绘制方式——以"向右箭头"为例：第 1 行第 3 列、第 2 行第 1-3 列、第 3 行第 3 列各有一个 Maroon 像素，形成指向右的箭头（其余三个方向依此旋转）。
  - 两个箭头所指的方向必定指向与其相邻的另一个区域（通过分隔线相邻）。

- `Rule`：
  - 按照从上到下、从左到右的顺序依次处理每个箭头。
  - 对当前箭头：读取箭头所在区域的填充色 C，以及箭头指向的相邻目标区域。
  - 将目标区域的所有填充像素重新着色为 C（即用箭头所在区域的颜色覆盖目标区域）。
  - 移除箭头图案（恢复为该区域的填充色 C）。
  - 第二个箭头处理时，使用的是经过第一步覆盖后的网格状态（级联效应）。
  - Grey 分隔线始终保持不变。

- `Key insight`：箭头不仅编码了推挤方向，还存在处理顺序带来的级联效应——第一个箭头的推挤结果会改变第二个箭头所在区域的有效颜色。解题者需要发现处理顺序（从上到下、从左到右），并理解级联覆盖的语义，才能正确推断最终输出。
