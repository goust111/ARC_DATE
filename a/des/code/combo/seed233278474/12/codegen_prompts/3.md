  - 矩形大小在 4x4 到 8x8 之间（含边框）。

- `Rule`：
  - 第一步（计数）：数出每个矩形内部种子像素的数量 N。
  - 第二步（确定方向）：缺口所在的边决定刺突的生长方向——缺口在上边 → 刺突向上；缺口在下边 → 向下；缺口在左边 → 向左；缺口在右边 → 向右。

  - 矩形边框和内部种子保持不变。

- `Key insight`：缺口不是"出口"而是"方向指示器"，种子不是"填充物"而是"长度编码器"——解题者需要发现缺口编码方向、种子数量编码长度这两个独立机制，并将它们组合。
