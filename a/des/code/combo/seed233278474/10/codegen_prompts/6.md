将每个对象按其内部孔洞的连通数分组，同组对象排列到输出网格的同一行中，行的排列顺序由孔洞数从少到多决定；同一行内对象的左右顺序由其原始位置的列坐标从左到右决定。

Input structure
- 背景为 Black 的网格中散布着若干 4-连通的单色对象（同一对象内所有像素颜色相同，不同对象颜色可能不同）。
- 每个对象内部可能包含 0 到 3 个"孔洞"——即被对象像素完全包围的 Black 连通区域（4-连通）。
- 对象之间互不接触。

Rule
- 对每个对象，计算其内部孔洞的数量（被该对象的像素完全 4-连通包围的 Black 区域的个数）。
- 将所有对象按孔洞数分组：孔洞数相同的对象归为一组。
- 输出网格的每一行对应一组，行从上到下按孔洞数递增排列（0 个孔洞在最上方）。
- 同一行内的对象按照它们在输入网格中包围盒左上角的列坐标从左到右排列，对象之间用一列 Black 背景分隔。每个对象以其紧凑包围盒形式绘制。
- 不同行之间用一行 Black 背景分隔。
- 输出网格的宽度为所有行中最宽者，较短的行右侧用 Black 填充；高度为所有行高度之和加行间分隔行数。

Key insight
颜色和形状都是干扰项——分组的唯一依据是孔洞数量这一拓扑属性，而非颜色或外形。解题者需要先发现孔洞计数作为分组键，再理解行排序和行内排序的双重规则。孔洞数量虽然需要"计数"，但由于数量极少（0-3），人眼可以直接识别。
