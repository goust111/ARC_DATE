- `description`：根据封闭区域边框上"锁孔"凹口的形状匹配，将含有彩色钥匙的区域颜色传递填充到配对的空区域中。
- `Input structure`：
  - 背景为最常见的颜色（如 Black）。
  - 网格中有若干由 Grey 像素围成的封闭矩形区域，区域之间互不重叠。
  - 每个封闭区域的 Grey 边框上有一个"锁孔"：边框上恰好缺失一段连续的 Grey 像素（形成一个凹口），凹口的形状（长度和所在边的位置）各不相同。
  - 部分封闭区域内部是空的（全为背景色），这些是"锁区域"。
  - 其余封闭区域内部包含一个由某种非背景、非 Grey 颜色填充的小形状（称为"钥匙"），钥匙的形状恰好是一段水平或垂直的像素条。钥匙区域的边框上也有一个凹口，其长度和相对位置与某个空区域的锁孔一致。
- `Rule`：
  - 识别所有封闭区域，将它们分为"钥匙区域"（内部有彩色像素条）和"锁区域"（内部为空）。
  - 对每个钥匙区域，读取其边框凹口的形状特征（凹口长度、凹口在边框哪一侧）。
  - 对每个锁区域，读取其边框凹口的形状特征。
  - 将凹口形状特征完全一致的钥匙区域与锁区域配对。
  - 将钥匙区域内部的彩色像素条的颜色填充到配对的锁区域内部（填满整个内部空间），同时保留钥匙区域原样不变。
- `Key insight`：解题者需要先发现边框凹口是一种"钥匙-锁"配对编码，再通过凹口形状匹配找到颜色传递关系——两步均需非平凡归纳：第一步识别凹口作为配对信号，第二步完成形状匹配与颜色迁移。
</new_puzzle>

<new_puzzle>
- `description`：将散落在网格中的彩色 L 形碎片通过几何互补性配对，再依据碎片内嵌的红色方向标记拼合成完整矩形并紧凑排列输出。
- `Input structure`：
  - 背景为 Black。
  - 网格中散落若干个大小不同的 L 形区域（每个 L 形由同一种非背景颜色填充，各 L 形颜色各不相同）。
  - 每个 L 形内部恰好有一个用 Red 像素画出的两像素方向标记：由一个"杆"像素和一个"头"像素组成，杆像素在 L 形的长臂上，头像素在杆像素的上/下/左/右正交相邻位置，头像素相对于杆像素的偏移方向即为该 L 形的拼合指向。
  - 恰好有偶数个 L 形，每两个 L 形可以互补拼合成一个完整的实心矩形（即两个 L 形的凹角位置互补）。
- `Rule`：
  - 找到所有 L 形对象，读取每个 L 形的 bounding box 尺寸和凹角位置（左上、右上、左下、右下四种之一）。
  - 两个 L 形能够配对的条件：它们的 bounding box 尺寸相同，且凹角位置对角互补（左上配右下，右上配左下）。
  - 配对后，按照各自 Red 箭头指向的方向将两个 L 形拼合：箭头指向对方，沿箭头方向平移使凹角互补填满，形成完整矩形。
  - 移除所有 Red 方向标记像素（恢复为该 L 形本身的颜色）。
  - 输出网格中，所有拼合后的矩形按原始位置的行优先顺序从上到下、从左到右依次排列，矩形之间有一列 Black 分隔。
- `Key insight`：解题者需要先通过 L 形的几何互补性找到配对关系（凹角对角互补），再通过内嵌的 Red 方向标记确定拼合方向——配对依据几何互补，拼合方向依据标记编码，两层推理缺一不可。
</new_puzzle>

<new_puzzle>
- `description`：利用网格边缘行和列上的蓝/绿色标记像素作为折叠指令，将中央图案沿指定轴线按指定方向逐步折叠叠加，输出最终的紧凑结果。
- `Input structure`：
  - 背景为 Black。
  - 网格中央区域（去除第 0 行和第 0 列后的部分）包含一个由多种非背景颜色绘制的图案。
  - 网格的第 0 行（最上方一行）包含若干标记像素，其余位置为背景色。每个标记像素位于某一列，颜色为 Blue 或 Green。
  - 网格的第 0 列（最左侧一列）同样包含若干标记像素，颜色为 Blue 或 Green。
  - 第 0 行中的标记表示一条垂直折叠线（位于该标记所在列处）；第 0 列中的标记表示一条水平折叠线（位于该标记所在行处）。
  - Blue 标记表示将折叠线右侧（垂直线）或下侧（水平线）的内容镜像翻转叠到左侧或上侧。
  - Green 标记表示将折叠线左侧（垂直线）或上侧（水平线）的内容镜像翻转叠到右侧或下侧。
- `Rule`：
  - 从第 0 行（从左到右）和第 0 列（从上到下）读取所有折叠指令，按照它们出现的顺序依次执行。第 0 行的指令先于第 0 列的指令执行。
  - 每次折叠：以指定行或列为轴线，将 Blue/Green 指定方向的一半镜像翻转叠到另一半。
  - 叠加规则：若翻转过来的像素为非背景色且目标位置也为非背景色，保留目标位置原色（底层优先）；若目标位置为背景色，填入翻转过来的颜色。
  - 折叠后丢弃轴线及被折走的一半，网格尺寸相应缩小。
  - 所有折叠完成后，裁去第 0 行和第 0 列的标记行/列，输出最终的紧凑网格。
- `Key insight`：解题者需要三层推理：第一层识别边缘标记是折叠指令而非装饰；第二层理解 Blue/Green 编码的折叠方向含义；第三层按正确顺序执行多次折叠并处理像素叠加冲突。标记行列本身不出现在输出中。
</new_puzzle>

<new_puzzle>
- `description`：根据种子像素在封闭房间中的偏心位置确定射线发射方向，射线长度等于房间在该方向的内部跨度，射线从种子出发穿透墙壁向外延伸。
- `Input structure`：
  - 背景为 Black。
  - 网格中有若干由 Grey 像素构成的一像素宽的正交线段，这些线段交叉连接形成若干封闭的矩形"房间"（房间内部为 Black）。
  - 部分房间内部恰好包含一个非背景、非 Grey 的彩色种子像素。每个有种子的房间只有一个种子。
  - 种子到房间四面内墙的距离（像素步数，不含墙壁本身）各不相同。
- `Rule`：
  - 对每个含种子的房间，计算种子像素到房间上、下、左、右四面内墙的距离。
  - 找到种子距离最近的那面墙所在的方向，射线的发射方向为该方向的反方向（即朝远离最近墙壁的方向发射）。
  - 射线的长度等于房间在射线发射方向上的完整内部跨度（即该方向上从一面内墙到对面内墙的像素数）。
  - 射线从种子像素出发，沿发射方向逐像素延伸，覆盖途经的所有像素（包括 Grey 墙壁和 Black 背景），射线颜色与种子颜色相同。
  - 射线不覆盖其他种子像素；其他无种子的房间和墙壁结构保持不变。
- `Key insight`：解题者需要先发现种子在房间中的偏心位置（距最近墙壁最短的方向）决定射线朝反方向发射（第一层归纳），再发现射线长度并非到墙壁的距离而是房间在该方向的完整内部宽度（第二层归纳）。种子颜色不编码方向，方向完全由空间位置关系决定。
</new_puzzle>

<new_puzzle>
- `description`：将输入网格中散布的矩形边框"邮票"按其边框缺口朝向分组，同组邮票按面积从大到小同心嵌套堆叠，各组结果按缺口方向的固定顺序排列输出。
- `Input structure`：
  - 背景为 Black。
  - 网格中散布若干个矩形"邮票"对象。每个邮票由一种非背景颜色的一像素宽边框围成，内部填充 Black。
  - 每个邮票的边框在某一侧（上、下、左或右）的正中央有一个恰好一像素宽的缺口（即该侧边框中间位置缺少一个像素，露出内部的 Black）。
  - 不同邮票的尺寸（宽高）各不相同，颜色可以相同也可以不同。
  - 邮票之间在输入中不重叠、不相邻。
- `Rule`：
  - 识别所有邮票对象，读取每个邮票边框的颜色、bounding box 尺寸、以及缺口所在的方向（上/下/左/右）。
  - 按缺口方向将邮票分为最多四组。
  - 在每组内，按邮票面积（宽 × 高）从大到小排序。
  - 对每组，以最大邮票为最外层，依次将较小邮票居中放置在上一层内部（较小邮票的中心与较大邮票的中心对齐），形成同心嵌套的矩形框结构。嵌套时每个邮票保留自身的边框颜色和缺口位置。
  - 输出网格中，各组嵌套结果作为独立块，按缺口方向的固定顺序排列：上、右、下、左，从左到右水平放置，组与组之间有两列 Black 分隔。若某个方向没有邮票则跳过该组。
- `Key insight`：解题者需要三层推理：第一层发现边框缺口是分组依据而非随机缺损；第二层发现同组内按面积排序并同心嵌套堆叠；第三层发现输出中各组按缺口方向的固定顺序（上→右→下→左顺时针）排列。缺口既是分类标签又在嵌套输出中持续可见，提供跨样例的视觉一致线索。
</new_puzzle>
