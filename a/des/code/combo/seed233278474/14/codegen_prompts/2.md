description：读取网格边缘的方向箭头标记，沿箭头指示的方向逐层剥离多色嵌套矩形框架，将剥离的层按原始尺寸重新排列到箭头所在边。

Input structure：
- 背景为 black。
- 网格中央有一组同心嵌套的矩形框架，从外到内每层使用不同颜色（如最外层 red、次外层 blue、再内层 green、最内层 yellow），每层框架宽度为 1 像素，层与层之间无间隔（紧密嵌套）。
- 网格的四条边（上、下、左、右）中恰好有一条边上放置了一个由 orange 像素构成的箭头标记。箭头为 3 像素的 V 形：若在上边则尖端朝下（一个顶点像素位于某列，其左下和右下各一个像素），若在下边则尖端朝上，若在左边则尖端朝右，若在右边则尖端朝左。箭头尖端始终指向网格内部方向。

Rule：
- 确定箭头所在的边，该边即为"堆叠目标边"。
- 将嵌套框架从外到内逐层拆解。拆解后，每层框架保持其原始矩形尺寸和颜色。
- 按从外到内的顺序，将各层框架依次紧贴堆叠目标边放置：最外层框架紧贴该边，次外层紧贴最外层内侧，依此类推。若堆叠目标边为上边，则各层从上往下排列；若为左边，则从左往右排列；其余类推。
- 各层框架在堆叠时，沿垂直于堆叠方向的轴居中对齐（与原始嵌套的中心对齐位置一致）。
- 箭头标记在输出中移除。

Key insight：解题者首先需要识别嵌套框架的层次结构及每层的颜色和尺寸，然后理解箭头标记指示的是框架"展开"后的堆叠方向。核心难点在于理解空间展开操作：嵌套的同心结构被拆成独立层后按原始尺寸沿指定方向重新排列，而非简单平移或缩放。

## 实现要求

1. `main(grid)` 必须实现新题描述中的确定性转换规则，不能只识别 `generate_input()` 的固定模板。
2. `generate_input()` 必须随机生成多样样例，不能固定死。随机维度应覆盖：网格大小、对象数量、位置、颜色、方向、形状参数或关键分支。
3. 生成器必须保证输入满足 `main()` 的隐式假设：对象不重叠、不越界、特殊标记唯一或可区分、匹配关系无歧义、关键分支出现概率相同。
4. 禁止把 ARC 颜色 id 当作人类不可见的数值语义参与排序、大小比较或隐藏映射。颜色变化必须有可见结构线索。注意颜色亮度等也是不可见信息，若描述中出现违规的颜色id或者亮度，可自行使用少量的固定颜色替代，但注意生成时要在三个以内输入输出网格中对所有变换100%覆盖度。

6. 若规则有多个分支，生成器不能长期固定成一个分支；应让分支在随机样例中合理出现。
7. 代码风格参考 `ARC_code`：使用 `numpy`，必要时使用本地 helper，但目标文件应能被 `SourceFileLoader` 直接加载。
