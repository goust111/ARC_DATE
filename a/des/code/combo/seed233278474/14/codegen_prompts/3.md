Input structure：
- 背景为 black。
- 网格中散布着若干单像素的彩色种子点，使用 2 至 4 种不同颜色（如 red、blue、green、yellow）。每种颜色的种子点数量在 2 到 5 之间。
- 每个种子点的上下左右四个方向中，恰好有一个方向是"最大开放方向"——即沿该方向到网格边界的距离最长，且该方向路径上全为 black 像素（无遮挡）。如果存在多个等长的无遮挡方向，则取最先遇到的（按上、右、下、左的优先顺序）。

Rule：
- 统计每种颜色的种子点总数 N。
- 对于每个种子点，确定其最大开放方向。
- 从该种子点出发，沿最大开放方向画一条长度为 N 的直线（种子本身算第 1 个像素，再向外延伸 N-1 个像素），颜色与种子相同。
- 如果枝条在到达长度 N 之前碰到网格边界，则在边界处截断。

Key insight：解题需要两步非显然推理——第一步需归纳出枝条长度等于同色种子的数量（这需要跨多个样例对比同色种子数与枝条长度的关系），第二步需理解每个种子的生长方向由其空间位置决定（选择最长的无遮挡方向）。两个规则维度（长度来源和方向来源）分别编码在不同的视觉特征中。
