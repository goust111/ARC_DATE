Input structure:

- 子区域内部（不含边缘行/列）初始全为黑色。

Rule:
- 对每个子区域，分别统计其上边、下边、左边、右边上的标记数量，记为 T、B、L、R。

- 四个角落矩形可能重叠，重叠部分仍为同色。Azure 分隔线保持不变。

Key insight:
- 解题需要三层推理：第一层识别分隔线将网格分成子区域；第二层发现每条边上的标记数独立控制一个维度的填充量；第三层理解四条边的标记数通过"行维度×列维度"的交叉组合方式决定四个角落矩形的尺寸，而非简单地把标记总数个像素随意摆放。

1. `main(grid)` 必须实现新题描述中的确定性转换规则，不能只识别 `generate_input()` 的固定模板。
