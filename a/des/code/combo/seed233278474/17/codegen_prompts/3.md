<new_puzzle index="3">
用网格中的"路标"箭头为每个彩色方块指定传送目的地，再将方块沿箭头链逐跳传递到终点位置。

Input structure
- 背景为主色（如 black）。
- 网格中有若干个 2x2 的实心彩色方块（颜色各不相同，如 red、blue、green 等）。
- 网格中还散布着若干由 orange 色绘制的"路标箭头"：每个箭头由 3 个像素组成，呈 L 形，其中 2 个像素构成箭杆（沿某个轴对齐），1 个像素在箭杆末端的垂直方向偏移一格构成箭头尖端，箭头方向由箭杆指向尖端的方向决定（上、下、左、右四种之一）。
- 每个彩色方块的 4 邻域（上下左右紧邻方块外侧一格）中恰好有一个路标箭头。

Rule
- 对每个彩色方块，找到与其相邻的路标箭头，读取箭头方向。
- 沿箭头方向平移方块，直到方块的边缘抵达另一个路标箭头所在的行或列（即方块移动到下一个路标箭头旁边停下）。
- 到达新位置后，读取这个新路标箭头的方向，继续沿新方向平移，重复上述过程。
- 当方块沿箭头方向移动但前方没有更多路标箭头时，方块移动到网格边缘停下。
- 所有方块同时按各自的箭头链独立移动（不互相阻挡）。路标箭头在输出中保留不变。

Key insight
解题者必须先识别出 L 形像素组合编码了方向信息，然后理解每个方块不是只移动一次，而是沿路标箭头构成的"接力链"逐段传递——核心难点在于追踪多跳传递路径并发现方块在每个路标处改变方向的机制。
</new_puzzle>
