- `description`：根据每个封闭区域内部标记像素的颜色种类数，选择对应的"图例条"颜色来填充该区域。

- `Input structure`：
  - 背景为黑色（black）。
  - 一种颜色（如 grey）绘制了若干条直线（水平或垂直），将网格划分成多个封闭矩形区域。
  - 某些区域内部散布着少量标记像素，标记像素可能使用多种不同颜色（如 red、blue、green 等），但每个标记像素仅占一格。
  - 网格的一侧边缘（例如最底行或最右列）排列着一组"图例条"：每个图例条是一小段连续的纯色像素，从左到右（或从上到下）排列，颜色各不相同。图例条按位置编号 1、2、3……

- `Rule`：
  - 对每个被灰线围成的封闭矩形区域，数出区域内部标记像素所包含的**不同颜色种类数** N。
  - 在图例条序列中找到编号为 N 的图例条，读取其颜色 C。
  - 将该封闭区域内所有黑色背景像素填充为颜色 C；原有的标记像素和灰色分割线保持不变。
  - 若区域内没有标记像素（N=0），则该区域保持黑色不变。

- `Key insight`：解题者需要先发现"区域内标记颜色的种类数"是一个关键量，再发现这个数值与图例条的位置对应关系，两步归纳缺一不可。标记像素的具体颜色本身不直接决定填充色，只有种类计数才起作用，这是主要的隐蔽性来源。
</new_puzzle>

<new_puzzle>
- `description`：将网格中散落的 L 形碎片拼合成完整矩形，拼合顺序由每个碎片内部嵌入的方向箭头指定。

- `Input structure`：
  - 背景为黑色（black）。
  - 网格中散布着若干个 L 形前景对象，每个 L 形由同一种颜色绘制，不同 L 形颜色不同。
  - 每个 L 形的内部（紧贴 L 拐角处）有一个由另一种颜色绘制的单像素"方向标记"。方向标记的位置相对于 L 形拐角的偏移方向指示了该 L 形在最终矩形中的朝向角落：标记在拐角的右上方表示该 L 形应放在矩形的左下角，标记在拐角的左上方表示放在右下角，标记在拐角的右下方表示放在左上角，标记在拐角的左下方表示放在右上角——即标记方向与放置角落关于拐角中心对称。
  - 所有 L 形的像素面积之和恰好等于一个矩形的面积，且恰好有四个 L 形。

- `Rule`：
  - 确定输出矩形的尺寸：总像素数 = 宽 × 高，选择最接近正方形的因数分解。
  - 读取每个 L 形内方向标记的相对位置，确定该 L 形应被放置到矩形的哪个角落。
  - 将每个 L 形（不含方向标记像素）平移到输出矩形对应角落，使 L 的拐角顶点与矩形角顶点对齐。四个 L 形恰好无重叠、无间隙地铺满整个矩形。
  - 输出网格仅包含拼合后的矩形，方向标记像素不出现在输出中。

- `Key insight`：解题者首先需要意识到四个 L 形可以拼成一个矩形，然后需要发现每个 L 形内部的标记像素位置编码了放置角落信息，且编码方式是"对角反转"而非直接映射。两层推理——拼合目标的识别和方向编码规则的破译——共同构成难度。
</new_puzzle>

<new_puzzle>
- `description`：每个彩色对象根据其所在"通道"中的同色信号灯状态决定是保留、擦除还是变色。

- `Input structure`：
  - 背景为黑色（black）。
  - 网格被若干条贯穿整行（水平）的 grey 线分割成水平通道（每条通道高度若干行）。
  - 每个通道内散布着一些彩色前景对象（4-连通、单色、形状各异）。
  - 在网格最左列（紧贴左边界），每个通道内恰好有一个 1×1 的"信号灯"像素，颜色为 red、green 或 yellow 之一。

- `Rule`：
  - 读取每个通道最左列的信号灯颜色。
  - 若信号灯为 green：该通道内所有前景对象保持原样不变。
  - 若信号灯为 red：该通道内所有前景对象被擦除（变为黑色背景）。
  - 若信号灯为 yellow：该通道内每个前景对象的颜色被替换为该通道中**面积最大的前景对象**的颜色（信号灯本身不算前景对象）。若面积最大的对象不唯一，取在通道中最靠左的那个的颜色。
  - 灰色分割线和信号灯像素在输出中保持不变。

- `Key insight`：解题者先要发现通道分割结构和最左列信号灯的存在，再归纳出三种信号灯颜色分别对应三种完全不同的操作——保留、擦除、统一变色。yellow 规则中的"面积最大对象的颜色"是第二层需要归纳的非显然规则，使该题具备真正的两层推理结构。
</new_puzzle>

<new_puzzle>
- `description`：将网格中的彩色线段视为"折叠指令"，沿每条线段折叠网格的一部分，使被折叠区域的像素叠加到另一侧。

- `Input structure`：
  - 背景为黑色（black）。
  - 网格中有一个由某种颜色（如 blue）绘制的大型图案（非矩形，有不规则边缘）。
  - 图案内部嵌有一到两条由 red 绘制的完整直线段（水平或垂直），每条线段从图案的一侧边缘延伸到另一侧边缘，将图案切分为两部分或多部分。
  - 每条 red 线段的**一个端点**处，紧邻线段外侧有一个 green 单像素标记，指示折叠方向——green 标记所在的一侧是"被折叠过去的一侧"。

- `Rule`：
  - 按照从外向内的顺序依次处理每条 red 折叠线（若只有一条则直接处理）。
  - 对于每条折叠线：确定 green 标记所在的一侧为"源侧"，另一侧为"目标侧"。
  - 将源侧的所有 blue 像素沿折叠线做镜像翻转，映射到目标侧对应位置。
  - 若目标侧对应位置已有 blue 像素，则该像素颜色变为 yellow（表示两层叠加）。若目标侧对应位置为黑色背景，则填入 blue。
  - 折叠完成后，擦除源侧区域（变为黑色）和 red 折叠线本身，保留 green 标记不变。

- `Key insight`：解题者需要先识别 red 线是折叠轴而非普通分割线，再通过 green 标记推断折叠方向，最后发现重叠区域的颜色变化规则（blue + blue = yellow）。折叠操作本身是空间推理，而叠加变色规则需要从样例中额外归纳，构成多层推理。
</new_puzzle>

<new_puzzle>
- `description`：根据每对同色锚点之间的相对位置关系，在连线路径上生成特定的重复图案带。

- `Input structure`：
  - 背景为黑色（black）。
  - 网格中散布着若干对同色单像素"锚点"，每种非黑色颜色恰好出现两个像素，构成一对。不同对使用不同颜色。
  - 网格的某个角落（如左上角）有一个小的矩形"字典区"，由 grey 边框围起。字典区内部每一行展示一种图案样本：左端是一个颜色像素 C，右侧紧跟着一小段（2-4 像素）由另一种颜色绘制的图案片段 P。

- `Rule`：
  - 对于每一对同色锚点，确定两点之间的连线方向：若两点在同一行则为水平连接，若在同一列则为垂直连接，否则先水平后垂直构成 L 形路径（从左侧锚点出发先水平再垂直）。
  - 在字典区中查找与该对锚点颜色匹配的行，读取其图案片段 P。
  - 沿连线路径，从一个锚点到另一个锚点，用图案片段 P 做周期性铺设：将 P 的像素序列沿路径方向反复平铺，直到到达另一个锚点。
  - 两个锚点像素本身保留其原色不变；路径上的图案覆盖背景像素但不覆盖已有的锚点。
  - 灰色字典区边框和字典内容在输出中保持不变。

- `Key insight`：解题者需要先发现锚点的配对规则（同色成对），再发现字典区的查找机制（颜色→图案映射），最后推断路径生成规则（方向优先级和周期铺设）。三层递进式推理——配对、查表、铺路——每一层都需要从样例中独立归纳，且字典查找机制不在主网格中直接呈现，增加了隐蔽性。
</new_puzzle>

<new_puzzle>
- `description`：根据每个封闭房间的出口数量，对房间内的对象执行不同次数的旋转变换。

- `Input structure`：
  - 背景为黑色（black）。
  - 一种颜色（如 blue）绘制了网格状的墙壁线条，将网格分割为若干个矩形"房间"。
  - 每个房间的墙壁上有若干个"出口"——即墙壁线条中被擦除（变为黑色）的单像素缺口，每个缺口恰好一格宽。
  - 每个房间内部恰好有一个由非黑、非墙壁颜色绘制的小型图案对象（3-6 像素，形状不对称，便于观察旋转效果）。

- `Rule`：
  - 对每个房间，数出其四面墙壁上出口的总数 N。
  - 将房间内的图案对象围绕其自身的视觉中心点（bbox 中心）顺时针旋转 N×90°。
  - 旋转 1 次 = 顺时针 90°，旋转 2 次 = 180°，旋转 3 次 = 逆时针 90°（即顺时针 270°），旋转 4 次 = 回到原位（等价于 0°）。
  - 旋转后的图案仍放置在该房间内部，中心位置不变。墙壁和出口保持不变。

- `Key insight`：解题者首先需要发现墙壁缺口（出口）的存在及其计数意义，然后需要从样例中归纳出"出口数→旋转次数"的对应关系，以及旋转方向为顺时针。出口数量作为旋转次数的映射是非显然的——解题者可能最初以为出口方向决定旋转方向，需要通过多个样例才能排除干扰、确认真正的规则。
</new_puzzle>

<new_puzzle>
- `description`：将散落在网格中的彩色碎片按照"影子投射"规则投影到一面共享的墙上，投影颜色由碎片的重叠层数决定。

- `Input structure`：
  - 背景为黑色（black）。
  - 网格的某一条边（如最右列）是一面由 grey 绘制的"投影墙"（一整列灰色像素）。
  - 网格中散布着若干个彩色前景对象，每个对象为单色的 4-连通区域，颜色各不相同。
  - 所有对象位于投影墙的同一侧（如墙在右侧，则所有对象在墙的左侧）。

- `Rule`：
  - 每个前景对象向投影墙方向（水平向右）做正交投影：对象占据的每一行，在投影墙上对应行的像素被"激活"。
  - 统计投影墙上每个像素被多少个不同对象激活（即有多少个对象在该行有像素存在）。
  - 激活次数为 0：墙上该像素保持 grey。
  - 激活次数为 1：墙上该像素变为激活它的那个唯一对象的颜色。
  - 激活次数为 2 或更多：墙上该像素变为 red（表示多重投影重叠）。
  - 原始前景对象在输出中被擦除（变为黑色背景），只保留投影墙及其上的投影结果。

- `Key insight`：解题者需要先发现灰色墙是投影目标面、前景对象按行做水平投影的机制，再从样例中归纳出投影重叠的混色规则——单层保留原色、多层统一变红。投影的"按行压缩"本质和重叠变色规则是两个独立的非显然发现，且"擦除原始对象"的输出模式进一步增加了逆推难度。
</new_puzzle>
