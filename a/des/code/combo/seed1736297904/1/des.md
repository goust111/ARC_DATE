- `description`：根据封闭区域内部"窗口"缺口的朝向从边界色带取色，再以区域面积为长度在内部绘制螺旋填充线。
- `Input structure`：背景为最常见颜色。网格中有若干由同一前景色绘制的封闭矩形区域（"房间"），每个房间的某一面墙上恰好有一个单像素宽的缺口（"窗口"）。网格的四条边界外侧各贴有一条单像素宽的色带（上、下、左、右各一条，颜色各不相同，例如上边 blue、下边 red、左边 green、右边 yellow）。每个房间内部全部为背景色。
- `Rule`：
  1. 对每个封闭矩形房间，找到其墙壁上唯一的单像素缺口，确定缺口朝向的方向（上/下/左/右）。
  2. 查看缺口朝向对应的那条网格边界色带的颜色——例如缺口朝上则取上边色带颜色。
  3. 统计该房间内部背景像素的数量 N。
  4. 从缺口位置出发，沿缺口朝向的反方向（即朝房间内部），在房间内部绘制一条长度为 N 的直线（使用该色带颜色）。如果直线碰到对面墙壁则沿顺时针方向转弯继续绘制，直到画满 N 个像素。
  5. 房间墙壁、色带和其余背景保持不变。
- `Key insight`：窗口的朝向决定了从哪条边界色带取色，而房间面积决定了填充线段的长度；解题者需要同时发现"方向→颜色映射"和"面积→长度"两层规则。
</new_puzzle>

- `description`：将散落的彩色精灵按形状匹配拼入模板框架的空槽中，再根据精灵与框架接触边的数量通过图例决定最终填充颜色。
- `Input structure`：背景为最常见颜色。网格中央有一个由单一颜色（如 grey）绘制的大型模板框架，框架内部包含若干不规则形状的背景色空槽（孔洞）。框架外部散落着若干小型单色精灵（sprite），每个精灵的形状恰好与框架内某个空槽的形状完全匹配（可能需要旋转 0/90/180/270 度，但不翻转）。网格的某个角落有一个小型颜色图例区域：图例由若干行组成，每行左侧是一组用 maroon 绘制的小点（1 个点、2 个点、3 个点、4 个点分别排成一行），右侧紧邻一个单像素的颜色块，表示"接触边数为该点数 → 用此颜色填充"。
- `Rule`：
  1. 对每个空槽，在框架外部找到形状匹配的精灵（通过 0/90/180/270 度旋转对齐）。
  2. 将精灵的形状放入对应空槽后，计算该精灵区域的像素与框架颜色像素在四连通方向上相邻的总对数（即接触边数）。
  3. 在角落图例中查找该接触边数对应的颜色。
  4. 用查找到的颜色填充该空槽（而非使用精灵原本的颜色）。
  5. 输出时移除框架外部的所有精灵和角落图例，只保留框架及其填充后的内容，裁剪到框架的包围盒。
- `Key insight`：精灵的原始颜色是干扰项——它仅用于在外部区分不同精灵；真正的填充颜色由精灵嵌入槽后与框架的接触边数通过图例间接决定，解题者需先完成形状匹配，再发现"接触量→图例查色"的第二层规则。
</new_puzzle>

- `description`：沿分隔线对两侧同色对象进行面积比较，胜出对象镜像复制到对面一侧，落败对象被擦除。
- `Input structure`：背景为最常见颜色。网格正中有一条贯穿全宽（水平）或全高（垂直）的单像素分隔线（使用独特颜色，如 maroon）。分隔线两侧各分布着若干单色四连通前景对象，颜色各异。两侧的对象在颜色上形成一一配对关系——即左侧（或上侧）某颜色的对象在右侧（或下侧）也有且仅有一个同颜色的对象，但两者的位置和大小不同。
- `Rule`：
  1. 对每一对同颜色的对象，比较它们的像素数量（面积）。
  2. 面积较大的对象"胜出"，面积较小的对象"落败"。
  3. 落败的对象被擦除为背景色。
  4. 将胜出对象沿分隔线做镜像反射，复制到对面一侧（落败对象原来所在的区域附近），镜像副本使用胜出对象的颜色。镜像的锚点为对象包围盒中心关于分隔线的对称位置。
  5. 如果镜像位置与其他已存在的胜出对象重叠，则重叠像素保留距离分隔线更近的对象的颜色。
  6. 分隔线本身保持不变，胜出对象的原始副本也保留。
- `Key insight`：解题者需要先发现两侧对象的颜色配对关系，再发现面积比较决定胜负方向，最后才是镜像操作——三层推理环环相扣，而表面看上去像是简单的对称题。
</new_puzzle>

- `description`：根据边缘箭头标记确定同色内部对象的滑动方向，滑动停止后相邻的对象按角落图例进行颜色混合。
- `Input structure`：背景为最常见颜色（如 black）。网格内部散布着若干小型单色矩形对象（每个占 2~4 个像素，颜色互不相同）。网格的四条边缘上分布着若干由 3 个像素组成的箭头标记：箭头由一个"尖端"像素和两个紧邻其后方对角线位置的"尾翼"像素组成（形成指向网格内部的"V"形），每个箭头使用一种颜色，该颜色与网格内部某个对象的颜色相同。每种对象颜色恰好对应一个边缘箭头。网格的一个角落（如左上角）有一个小型 2 列 N 行的颜色混合图例，每行左侧格和右侧格各一个颜色像素，表示"当这两种颜色的对象最终相邻时，两者都重绘为左侧格的颜色"。
- `Rule`：
  1. 对每个边缘箭头，找到网格内部与其同色的对象。箭头尖端朝向网格内部的方向（上/下/左/右）即该对象的滑动方向。
  2. 按照各对象距其滑动目标边界从近到远的顺序，依次滑动每个对象。每个对象沿指定方向滑动，直到碰到网格边界或另一个已停止的对象为止。
  3. 所有滑动完成后，检查所有四连通相邻的对象对。如果某对相邻对象的颜色组合（不分顺序）出现在角落图例中，则将这两个对象都重绘为图例中该行左侧格的颜色。
  4. 擦除所有边缘箭头标记和角落图例，只保留背景和滑动、混合后的对象。
- `Key insight`：箭头颜色匹配确定"谁动、往哪动"，滑动堆叠后的邻接关系触发第二层"颜色混合"规则——解题者必须先归纳运动规则，再发现角落图例的混合语义。
</new_puzzle>

- `description`：在由分隔线划分的单元格中，根据种子像素数量作为索引从侧边样本条中选取对应几何图案填入。
- `Input structure`：背景为最常见颜色（如 black）。网格被等间距的水平和垂直分隔线（单像素宽，使用 grey）划分为若干大小相同的矩形单元格（例如每个单元格为 5x5 的内部空间）。每个单元格内部散布着 0~4 个"种子"像素（均使用统一的标记颜色，如 red）。网格最右侧紧贴边缘有一列与单元格等高的样本图案条（共 4 个，用灰色细线彼此分隔），从上到下每个样本条内绘制着一种独特的小型几何图案（如第 1 个为对角线图案、第 2 个为十字图案、第 3 个为边框图案、第 4 个为实心方块图案），分别使用不同的非背景非标记颜色（如 blue、green、yellow、orange）。
- `Rule`：
  1. 识别灰色分隔线，将网格（不含最右侧样本列）划分为矩形单元格。
  2. 统计每个单元格内红色种子像素的数量 N。
  3. 如果 N = 0，该单元格保持全背景色不变。
  4. 如果 N 为 1~4，从右侧样本条中取第 N 个图案（从上到下第 N 个），将该图案绘制到当前单元格中（图案在单元格内居中对齐），使用该样本图案自身的颜色。
  5. 绘制图案后，擦除该单元格内原有的红色种子像素。
  6. 输出网格不包含右侧样本列，仅保留分隔线和填充后的单元格。
- `Key insight`：种子像素的数量不是填充色的直接编码，而是一个"索引"，指向右侧样本条中的某个几何图案——解题者需要先发现计数→索引的映射关系，再发现样本条的排列顺序即为索引顺序，两层归纳缺一不可。
</new_puzzle>

- `description`：根据封闭回路内困住的散点颜色种类数，通过边缘图例确定回路自身的重绘颜色，并擦除所有散点。
- `Input structure`：背景为最常见颜色（如 black）。网格中有若干由同一颜色（如 azure）绘制的单像素宽封闭回路（每个回路为一个完整的简单闭合曲线，八连通相连，互不相交且互不嵌套）。回路的内部和外部都散布着若干单像素的彩色点（可能使用 red、green、yellow、orange、magenta 等多种颜色）。网格左侧边缘有一个竖排的颜色图例：图例从上到下共若干行，第 K 行（K=1,2,3...）包含 K 个 maroon 小点和紧邻其右的一个单像素颜色块，表示"困住 K 种不同颜色 → 用该颜色块的颜色重绘回路"。
- `Rule`：
  1. 识别所有由 azure 绘制的封闭回路。
  2. 对每个回路，确定其内部区域（被回路像素完全包围的区域，用洪泛填充从回路外部标记不可达的背景区域来判定）。
  3. 统计该回路内部区域中散点的不同颜色种类数 N（注意是种类数，不是总像素数；不计入背景色和回路自身颜色）。
  4. 在左侧边缘图例中查找第 N 行对应的颜色块。
  5. 将该回路的所有像素重绘为图例指定的颜色。
  6. 擦除网格中所有散点（回路内外的散点均擦除为背景色），保留重绘后的回路和左侧图例。
- `Key insight`：回路外的散点是纯干扰项——只有被回路围住的散点参与计数；而计数的是颜色种类而非数量，这要求解题者先区分内外，再区分"种类"与"数量"，最后通过图例完成颜色映射，三步推理缺一不可。
</new_puzzle>

- `description`：将同色前景区域按拓扑嵌套深度分层着色，深度-颜色映射由网格角落的渐变色条指定。
- `Input structure`：背景为最常见颜色（如 black）。网格中有若干互不重叠的大型前景对象，每个对象初始均为同一颜色（如 grey）。这些对象内部包含背景色的孔洞，某些孔洞内部又包含前景色的"岛屿"，岛屿内可能还有更深层的孔洞——形成嵌套的同心环结构（最大嵌套深度不超过 4 层）。网格左上角有一个小型渐变色条（横向排列，从左到右为 3~5 个单像素颜色块，如第 1 格 blue、第 2 格 green、第 3 格 yellow、第 4 格 orange、第 5 格 red），色条下方无其他标注。
- `Rule`：
  1. 对每个前景对象及其内部的嵌套结构，从外向内计算拓扑嵌套深度：最外层前景区域深度为 0，该前景内的孔洞中若存在前景岛屿则该岛屿深度为 1，该岛屿内的孔洞中若存在前景则深度为 2，以此类推。
  2. 根据角落渐变色条，将深度 D 的前景区域重绘为色条中第 D+1 格的颜色（即深度 0 用第 1 格颜色、深度 1 用第 2 格颜色……）。
  3. 所有孔洞（背景色区域）保持背景色不变。
  4. 输出中移除左上角的渐变色条区域（将其擦除为背景色）。
- `Key insight`：所有前景对象初始颜色相同，解题者不能靠颜色区分层级——必须识别出嵌套的拓扑深度结构，并将角落色条理解为"深度→颜色"的有序映射表，这是一个纯空间拓扑推理与外部图例结合的双层问题。
</new_puzzle>
