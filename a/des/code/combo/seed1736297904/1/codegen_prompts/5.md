- `Input structure`：背景为最常见颜色（如 black）。网格被等间距的水平和垂直分隔线（单像素宽，使用 grey）划分为若干大小相同的矩形单元格（例如每个单元格为 5x5 的内部空间）。每个单元格内部散布着 0~4 个"种子"像素（均使用统一的标记颜色，如 red）。网格最右侧紧贴边缘有一列与单元格等高的样本图案条（共 4 个，用灰色细线彼此分隔），从上到下每个样本条内绘制着一种独特的小型几何图案（如第 1 个为对角线图案、第 2 个为十字图案、第 3 个为边框图案、第 4 个为实心方块图案），分别使用不同的非背景非标记颜色（如 blue、green、yellow、orange）。
- `Rule`：
  1. 识别灰色分隔线，将网格（不含最右侧样本列）划分为矩形单元格。
  2. 统计每个单元格内红色种子像素的数量 N。
  3. 如果 N = 0，该单元格保持全背景色不变。
  4. 如果 N 为 1~4，从右侧样本条中取第 N 个图案（从上到下第 N 个），将该图案绘制到当前单元格中（图案在单元格内居中对齐），使用该样本图案自身的颜色。

  6. 输出网格不包含右侧样本列，仅保留分隔线和填充后的单元格。
- `Key insight`：种子像素的数量不是填充色的直接编码，而是一个"索引"，指向右侧样本条中的某个几何图案——解题者需要先发现计数→索引的映射关系，再发现样本条的排列顺序即为索引顺序，两层归纳缺一不可。
