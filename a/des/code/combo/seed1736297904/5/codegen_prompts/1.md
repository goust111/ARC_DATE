- `Input structure`：
  - 背景色（black）填充整个网格。
  - 若干不重叠的矩形空心边框，每个边框由同一种颜色绘制（如 blue、green、red 等，各框颜色可不同）。

  - 种子不会位于边框的正中心，它总是偏向四个象限之一（左上、右上、左下、右下）。
- `Rule`：
  - 保留所有原有像素不变。
  - 对每个矩形边框，判断其内部种子相对于边框内部中心点所处的象限：左上、右上、左下、右下。
  - 根据象限在边框对应的角上制造一个缺口：将该角的角像素及其在边框上相邻的两个像素（沿两条边各一个，共 3 个像素）重新着色为种子的颜色。
  - 例如种子偏左上，则左上角的 3 个边框像素被改为种子颜色。
- `Key insight`：种子的空间位置不是用来填充或移动的，而是作为一个"指针"，通过它在边框内部的相对象限来选择边框的哪个角需要被标记。解题者需要先发现种子与角的对应关系（象限映射），再发现标记方式（角上 3 像素变色）。
