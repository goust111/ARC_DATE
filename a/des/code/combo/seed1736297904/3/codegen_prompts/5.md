- `Input structure`：
  - 背景为黑色（black）。
  - 网格中有一个由 grey 像素组成的一像素厚的矩形环形轨道（即一个矩形框，四条边均为 grey，内部为黑色区域）。
  - 轨道上（即 grey 像素的位置上）有若干彩色标记像素，每个标记将其所在位置的 grey 替换为自身颜色。不同标记颜色互不相同，且标记彼此不相邻。
  - 矩形框内部的黑色区域中散布着若干彩色像素，这些像素的颜色都能在轨道标记中找到对应。同一种颜色在内部可出现 0 到多个像素。

- `Rule`：
  - 轨道的 grey 像素保持不变（除了标记移动后覆盖的位置）。
  - 内部区域的所有彩色像素被擦除为黑色。
  - 对每个轨道上的彩色标记：
    1. 统计该标记颜色在内部区域中出现的像素数量 K。
    2. 将该标记沿轨道顺时针移动 K 步。顺时针方向定义为：顶边从左到右、右边从上到下、底边从右到左、左边从下到上。每一步移动到轨道上的下一个相邻像素位置。
    3. 标记的原始位置恢复为 grey。标记的新位置像素变为该标记颜色。
  - 如果两个标记移动后落在同一位置，则后处理的标记覆盖先处理的（处理顺序为按原始位置的顺时针顺序，从顶边左上角起始）。

- `Key insight`：内部散落的彩色像素看似装饰或噪声，实际是每个轨道标记的"步数编码"——解题者需要发现内部像素的颜色与轨道标记一一对应，且数量直接转化为移动距离。两层推理缺一不可：第一层是建立颜色配对（轨道标记色 = 内部计数色），第二层是理解沿矩形轨道的顺时针行走规则。
