- `Input structure`：
  - 背景为黑色（black）。
  - 网格左侧或右侧边缘有若干由 grey 像素绘制的水平箭头符号，每个箭头占据若干连续行。每个箭头的绘制方式为：一条水平的 grey 线段加上末端的一个三角箭头尖（由 grey 像素构成的 3 行高的三角形，尖端指向左或右）。箭头指向左表示向左生长，指向右表示向右生长。每个箭头所覆盖的行范围称为一个"行带"。不同箭头的行带互不重叠且覆盖不同数量的行（例如一个箭头覆盖 2 行，另一个覆盖 3 行，再一个覆盖 4 行）。
  - 在网格非箭头区域中，散布着若干单个彩色像素（种子），颜色各异且均非黑色、非 grey。每个种子像素必定落在某个箭头行带的范围内。同一行带内可能有多个种子，但它们的颜色一定相同。不同行带内的种子颜色可能不同。

- `Rule`：
  - 箭头本身保持不变。
  - 对每个行带：
    1. 统计该行带内种子像素的数量 N。
    2. 确定箭头方向（左或右）。
    3. 确定该行带覆盖的行数 H（即行带的高度）。
    4. 以每个种子像素为起点，沿箭头方向生长出一个 H 行高、N 列宽的实心矩形色块，颜色与种子相同。矩形的垂直范围恰好覆盖整个行带高度，水平起点为种子所在列，向箭头方向延伸 N 列（含种子所在列）。
    5. 如果生长超出网格边界，则在边界处截断。
  - 不同种子生长的矩形如果重叠，后绘制的覆盖先绘制的（绘制顺序：按箭头方向排列，靠近箭头源头侧的种子先绘制）。

- `Key insight`：解题者必须发现三层嵌套的逻辑：首先，箭头既标定了行带的范围（决定生长高度），又指定了生长方向；其次，同一行带内种子的数量决定了每个矩形的宽度（数量即宽度）；最后，种子的列位置决定了矩形的水平锚点。行带高度、种子计数和方向三者缺一不可。
