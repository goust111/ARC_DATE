- `Input structure`：背景为 Black。网格中央偏左有一个大型多色图案（由 3-5 种前景色组成的连通区域，面积约 8×8 至 12×12）。网格右侧或角落散落着 2-4 个小型 Grey 模板精灵（每个模板形状各异，面积 3-6 像素）。每个 Grey 模板的形状（在平移意义下）恰好在大图案的前景像素中出现一次。这些匹配区域互不重叠。
- `Rule`：
  1. 对每个 Grey 模板，在大图案中找到与之形状完全匹配的前景像素子集（仅允许平移，不旋转、不翻转）。
  2. 统计该匹配区域中各前景颜色的像素数量，找到出现最多的颜色 C_dom（若平局则选取在编码表 Blue < Red < Green < Yellow < Magenta < Orange < Azure < Maroon 中排序靠前的颜色）。
  3. 将该匹配区域的所有像素统一重绘为 C_dom。
  4. 将该 Grey 模板从网格中擦除（恢复为 Black）。
  5. 大图案中未被任何模板匹配的区域保持不变。
- `Key insight`：解题者需要完成两步非平凡推理：第一步是发现灰色小模板不是"印章"而是"搜索模板"——需要在大图案中找到形状匹配的区域（模式匹配）；第二步是发现匹配区域的变换规则——不是简单地涂成灰色或某固定色，而是根据区域内部的颜色统计（众数）来统一重绘。模板的作用是"定位 + 触发统一化"，而非"覆盖"。
