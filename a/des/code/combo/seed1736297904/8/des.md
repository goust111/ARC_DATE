- `Rule`：
  1. 对每个箭头，沿其尖端所指方向找到与之颜色相同的色带。

- `Key insight`：解题者首先需要识别箭头的朝向和颜色配对关系（箭头颜色 = 目标色带颜色），然后理解箭头并非"印"在色带上，而是"击穿"色带——箭头消失的同时在色带上留下精确的缺口。缺口的位置由箭头沿指向方向的投影位置决定，缺口宽度由箭头体的宽度决定。

- `Input structure`：背景为 Black。网格由一条水平 Maroon 分隔线分为上下两个面板。上面板包含一个紧凑的编码表：从左到右排列着 N 个不同颜色的单像素（N ≤ 8，位于同一行，像素之间无间隔），分别代表数字 1, 2, 3, ... N。上面板仅有这一行非背景像素。下面板包含若干互不重叠、互不接触的 Grey 实心矩形，每个矩形的行数和列数均在 1 到 N 之间。
- `Rule`：
  1. 读取上面板的编码表：第 k 个像素（从左数第 k 个）的颜色对应数字 k。
  2. 对下面板中的每个 Grey 矩形，测量其行数 R 和列数 C。
  3. 查表得到 R 对应的颜色 C_R 和 C 对应的颜色 C_C。
  4. 将该矩形的顶边和底边（各为完整的一行像素）全部绘制为 C_R。
  5. 将该矩形的左边和右边（各为完整的一列像素，但排除四个角点——角点保持 C_R）全部绘制为 C_C。

  8. 上面板和分隔线保持不变。
- `Key insight`：解题者需要发现三层嵌套结构：（1）上面板的像素序列是一个"数字→颜色"的映射表；（2）每个灰色矩形的几何尺寸（行数、列数）是查表的输入键；（3）查表结果分别应用于矩形的水平边和垂直边，而非整个矩形统一上色。将尺寸属性拆分为两个独立维度分别查表并分别作用于不同方向的边，是本题最隐蔽的机制。

- `description`：在包含若干彩色"种子对"的网格中，每对同色种子之间生长出 L 形折线连线；当两条不同颜色的连线交叉时，交叉点显示为由固定颜色合成规则决定的第三种"混合色"。
- `Input structure`：背景为 Black。网格中有若干对同色单像素标记（种子），每种颜色恰好出现两个像素。可能出现的种子颜色包括 Red、Blue、Yellow（不超过 3 对）。同色的两个种子要么共享同一行、要么共享同一列、要么需要恰好一次直角拐弯即可用行列折线连接（即一条水平线段 + 一条垂直线段，构成 L 形路径）。当需要拐弯时，拐弯方向选择使折线不经过任何其他种子像素的那个方向（保证唯一）。
- `Rule`：
  1. 对每对同色种子，沿唯一的 L 形折线路径（若共行或共列则为直线段）连接两个种子，将路径上所有 Black 像素绘制为该对种子的颜色。
  2. 若两条不同颜色的连线在某个像素处交叉，则该像素不绘制为任何一条连线的颜色，而是绘制为"混合色"：Red + Blue = Magenta，Red + Yellow = Orange，Blue + Yellow = Green。
  3. 种子像素本身保持原色不变。
  4. 连线的绘制结果与绘制顺序无关（因为交叉点的混合色由固定规则决定）。
- `Key insight`：第一层推理是发现同色像素对之间通过 L 形折线连接的规则，以及拐弯方向的消歧规则。第二层推理是发现交叉点并非简单地被后绘制的颜色覆盖，而是遵循一个需要从样例中归纳出的颜色合成表（类似加法混色）。解题者必须同时推断连线规则和混色规则，这两个规则互相独立但在输出中交织呈现。
</new_puzzle>

- `Rule`：
  1. 对每个 Grey 模板，在大图案中找到与之形状完全匹配的前景像素子集（仅允许平移，不旋转、不翻转）。

</new_puzzle>
