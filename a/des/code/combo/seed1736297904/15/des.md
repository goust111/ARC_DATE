- `description`：根据封闭区域内部"种子"像素的颜色，在区域边界的对应边上开口，并将种子像素沿开口方向延伸为射线直到网格边缘。
- `Input structure`：背景为最常见颜色。网格中有若干由同一颜色（如 Blue）绘制的封闭矩形边框（一像素厚的中空矩形）。每个矩形内部恰好有一个非背景、非边框颜色的"种子"像素。种子像素的颜色从以下四种之一取值：Red 表示上、Green 表示下、Yellow 表示左、Orange 表示右。种子像素位于矩形内部的任意位置（不在边框上）。
- `Rule`：
  1. 对每个封闭矩形，读取其内部种子像素的颜色，确定方向映射（Red→上、Green→下、Yellow→左、Orange→右）。
  2. 在该矩形边框的对应边上，找到与种子像素同行（左/右方向）或同列（上/下方向）的那个边框像素，将其擦除为背景色，形成一个一像素宽的"开口"。
  3. 从开口位置出发，沿开口方向向网格外侧绘制一条与边框同色的射线，直到到达网格边缘。
  4. 种子像素本身保留在原位不变。
- `Key insight`：种子的颜色不是用来重绘对象的，而是编码了一个方向指令；解题者需要先建立颜色→方向的映射，再理解开口位置由种子在矩形内的行列坐标决定——这两层信息共同决定了射线的起点和朝向。
</new_puzzle>

- `description`：将散布在网格中的同色像素簇按面积从小到大排序，然后依照排序结果重新分配颜色：最小簇获得原本最大簇的颜色，最大簇获得原本最小簇的颜色，以此类推镜像交换。
- `Input structure`：背景为最常见颜色。网格中有若干个互不接触的 4-连通前景像素簇，每个簇由单一颜色构成，不同簇的颜色各不相同。所有簇的面积（像素数）互不相等。
- `Rule`：
  1. 识别所有 4-连通前景簇，记录每个簇的颜色和面积。
  2. 按面积从小到大排序，得到序列 S1, S2, …, Sn。
  3. 将颜色进行镜像重分配：面积最小的簇 S1 重绘为原来面积最大簇 Sn 的颜色，S2 重绘为 Sn-1 的颜色，依此类推。若簇总数为奇数，正中间的簇颜色不变。
  4. 每个簇的形状和位置保持不变，仅颜色改变。
- `Key insight`：解题者需要先按面积排序（而非按位置或颜色），再发现颜色交换遵循的是面积排名的镜像对称关系——即排名第 k 小的簇与排名第 k 大的簇互换颜色。仅看单个样例可能误以为是相邻簇交换或按位置交换，需要多个样例才能锁定"面积排名镜像"这一隐蔽规则。
</new_puzzle>

- `description`：网格被分为上下两个面板；上面板中的彩色"钥匙"形状决定下面板中对应"锁孔"区域的填充方式——钥匙旋转后恰好嵌入锁孔，填充色取决于钥匙触碰的边框颜色。
- `Input structure`：背景为最常见颜色（如 Black）。网格被一条水平的 Grey 分隔线分为上下两个面板。上面板包含若干个小型彩色前景形状（"钥匙"），每个钥匙是一个不规则的 4-连通单色区域。下面板包含若干个由不同颜色绘制的一像素厚的矩形边框（"锁"），每个锁的内部全为背景色（"锁孔"）。每个锁的内部空腔形状恰好与上面板中某一个钥匙旋转 0°、90°、180° 或 270° 后的形状完全吻合（包括包围盒尺寸一致）。上面板的钥匙数量与下面板的锁数量一一对应。
- `Rule`：
  1. 对每个下面板的锁，提取其内部空腔的形状（背景区域的像素模式）。
  2. 在上面板中找到唯一一个钥匙，使得该钥匙经过某个 90° 倍数的旋转后形状与空腔完全匹配。
  3. 将该锁的内部空腔填充为锁边框的颜色（不是钥匙的颜色）。
  4. 上面板的所有钥匙被擦除为背景色；Grey 分隔线保留；下面板的锁边框保留。
- `Key insight`：解题包含两层非显然推理：第一层是发现钥匙与锁孔之间的旋转匹配关系（需要心理旋转来配对），第二层是发现填充色来自锁边框而非钥匙本身的颜色——后者在只看一个样例时容易被忽略，因为可能恰好钥匙色与边框色相同。
</new_puzzle>

<new_puzzle>
- `description`：网格中有若干对颜色相同的对象，每对对象之间需要画一条折线路径连接；路径的折弯方向由路径中途经过的单像素"路标"颜色决定（Red 路标表示右转，Blue 路标表示左转）。
- `Input structure`：背景为最常见颜色（如 Black）。网格中有若干对同色的小型实心矩形（每种非背景、非 Red、非 Blue 颜色恰好出现两个矩形）。此外还有一些散布的 Red 和 Blue 单像素"路标"。每对同色矩形之间的路标沿唯一可行的曼哈顿路径排列（沿水平或垂直方向行进、仅在路标处折弯）。
- `Rule`：
  1. 对每对同色矩形，确定连接它们的路径。路径从一个矩形最接近另一个矩形的边的中心像素出发，沿朝向另一个矩形的水平或垂直方向直线前进。
  2. 当路径前方遇到一个 Red 或 Blue 路标像素时，路径在路标所在位置折弯：Red 路标表示相对当前行进方向右转 90°，Blue 路标表示左转 90°。路径经过路标后继续沿新方向直行。
  3. 路径最终到达另一个矩形的边缘停止。路径用该对矩形的颜色绘制（一像素宽的线段）。
  4. 所有路标像素在输出中保留原色。原有的矩形对象也保留不变。
- `Key insight`：解题者需要两层推理：第一层是发现同色矩形需要配对并连接（配对规则），第二层是发现路径不是最短路径或任意路径，而是严格由路标颜色控制折弯方向的确定性路径——Red/Blue 不是装饰而是转向指令。
</new_puzzle>

<new_puzzle>
- `description`：在包含多个"画框"和一个"调色板行"的网格中，每个画框内的残缺图案需要根据调色板行中颜色的排列顺序进行逐层补全——调色板中从左到右的颜色顺序定义了画框内从外到内的嵌套填充层级。
- `Input structure`：背景为最常见颜色（如 Black）。网格顶部或底部有一行"调色板行"：该行在背景上排列着若干不同颜色的单像素点，从左到右各不重复，像素之间可以有背景间隔。网格其余区域包含若干个由 Grey 绘制的一像素厚矩形边框（"画框"）。每个画框的内部已经有一些前景像素，这些像素的颜色都出现在调色板行中，但覆盖不完整——有些像素缺失（仍为背景色）。每个画框内的前景像素颜色可能有多种，且在空间上呈现从外向内的嵌套矩形环状分布的线索（但有大量像素缺失）。
- `Rule`：
  1. 读取调色板行，从左到右记录颜色序列 C1, C2, C3, …, Ck。
  2. 对每个画框，其内部应填充为 k 层嵌套矩形环。最外层环（紧贴 Grey 边框内侧的一圈像素）填充颜色 C1，次外层环填充 C2，依此向内直到最内层填充 Ck。若画框内部尺寸不足以容纳所有 k 层，则从外层开始尽可能多地填充。
  3. 已有的前景像素作为线索——它们的位置和颜色与上述嵌套环规则一致（用于解题者验证自己的推断）。
  4. Grey 画框边框和调色板行在输出中保留不变。
- `Key insight`：解题者需要分两步推理：第一步是发现调色板行的颜色排列顺序对应嵌套深度（从外到内），而非简单的重绘或替换；第二步是意识到画框内部的残缺像素实际上暗示了同心矩形环的结构，需要将这一结构补全。调色板给出"哪种颜色在第几层"的映射，而画框内的现有像素给出结构验证。
</new_puzzle>

<new_puzzle>
- `description`：网格中每个前景对象的"影子"需要被绘制出来，影子的投射方向由对象自身形状中的不对称缺口决定，影子长度等于对象在垂直于投射方向上的厚度。
- `Input structure`：背景为最常见颜色。网格中有若干互不重叠的单色 4-连通前景对象，每个对象整体呈矩形但恰好有一个角上缺少一个像素（即矩形去掉一个角像素后的形状）。不同对象的颜色各不相同。对象之间有足够的背景空间。
- `Rule`：
  1. 对每个对象，找到其包围盒中唯一缺失的角像素位置，确定该角所在的方向（左上、右上、左下、右下）。
  2. 缺角所在的对角方向即为"光源方向"——影子向缺角的对角方向投射。例如：缺少左上角 → 光源在左上 → 影子向右下投射；缺少右下角 → 光源在右下 → 影子向左上投射。
  3. 影子为 Grey 色，形状是对象整体形状沿投射方向平移后的副本，平移距离等于对象包围盒在投射方向的对角分量中较小的那个维度的长度。具体地：如果对象包围盒为 W 列 × H 行，则影子偏移量为 (±min(W,H), ±min(W,H))，正负号由投射方向决定（右下为正正，左上为负负，右上为正负，左下为负正，第一个分量为列偏移，第二个为行偏移）。
  4. 影子绘制在对象之下（即影子像素不覆盖对象像素；若影子与对象重叠，重叠部分保留对象颜色）。缺角像素在输出中仍保持为背景色。
- `Key insight`：解题者需要首先识别出每个对象只缺一个角像素这一微妙特征，然后推断缺角方向如何映射到影子投射方向（对角反转关系），最后还要发现影子偏移量由对象自身尺寸的较短边决定——三层视觉线索层层递进。
</new_puzzle>

<new_puzzle>
- `description`：网格中散布的前景像素按颜色分组后，每组像素的凸包围盒内部需要被该颜色填充为实心矩形，但不同颜色组之间存在遮挡优先级——像素数越少的颜色绘制在越上层。
- `Input structure`：背景为最常见颜色。网格中有若干种前景颜色的单像素散布在各处，每种颜色至少出现两个像素。不同颜色的像素可能在空间上有交错分布。
- `Rule`：
  1. 对每种前景颜色，找到该颜色所有像素的最小轴对齐包围盒（即该颜色最上、最下、最左、最右像素所确定的矩形）。
  2. 统计每种颜色在输入中出现的像素数量。
  3. 按像素数量从多到少的顺序依次绘制各颜色的实心填充矩形（包围盒区域全部填充为该颜色）。像素数量多的颜色先画（在底层），像素数量少的后画（在上层覆盖先画的内容）。
  4. 若两种颜色像素数量相同，则包围盒面积较大的先画。
- `Key insight`：解题者需要两层推理：第一层是从散布的像素中推断出每种颜色对应一个包围盒实心矩形（像素是矩形的"采样点"），第二层是发现矩形之间的遮挡/绘制顺序由原始像素数量决定——少的在上、多的在下。单看一个样例时，遮挡顺序的规律不明显，需要对比多个样例中不同颜色像素数与最终可见面积的关系来归纳。
</new_puzzle>
