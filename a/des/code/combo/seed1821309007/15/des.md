- `description`：将网格中的完整色行和完整色列视为坐标轴，根据每个前景对象在两条轴上的投影位置确定其在输出矩阵中的行列坐标。
- `Input structure`：背景为 Black。网格中有一条完整的单色水平行（"X 轴"）和一条完整的单色垂直列（"Y 轴"），两者交叉形成坐标系。网格中散布若干不同颜色的小型 4-连通前景对象。每个对象恰好与 X 轴或 Y 轴上的某个标记像素在同行或同列上对齐。X 轴和 Y 轴上各有若干不同颜色的标记像素。
- `Rule`：
  - 对每个前景对象，找到与其同列的 X 轴标记像素（确定列坐标）和与其同行的 Y 轴标记像素（确定行坐标）。
  - 构建一个输出矩阵，行数等于 Y 轴标记数，列数等于 X 轴标记数。
  - 在输出矩阵的对应位置填入该前景对象的颜色。
  - 未被任何对象占据的矩阵位置填背景色。
- `Key insight`：坐标轴上的标记是地址索引——对象的颜色通过行列对齐关系被映射到压缩矩阵中。解题者需发现轴上标记与对象之间的对齐关系。
</new_puzzle>

<new_puzzle>
- `description`：将网格中每个前景对象的边界像素与内部像素分别重绘为两种不同颜色，边界色由对象的邻居数量决定，内部色由对象的孔洞数量决定。
- `Input structure`：背景为 Azure。网格中有若干不同大小的 Grey 色 4-连通前景对象。部分对象是实心的，部分对象内部有孔洞（被背景色包围的封闭区域）。
- `Rule`：
  - 对每个对象，将其像素分为"边界像素"（至少有一个 4-邻居是背景色的前景像素）和"内部像素"（所有 4-邻居都是前景色的像素）。
  - 数出该对象的 4-连通前景邻居对象数量 M（与该对象有 4-相邻关系的其他前景对象数）。
  - 数出该对象内部封闭孔洞数量 H。
  - 边界像素重绘颜色：M=0 用 Red，M=1 用 Green，M=2 用 Blue，M>=3 用 Yellow。
  - 内部像素重绘颜色：H=0 用 Maroon，H=1 用 Orange，H>=2 用 Magenta。
- `Key insight`：边界色和内部色由两个完全不同的属性决定——邻居关系和孔洞数量。解题者需分别归纳两个独立的映射规则。
</new_puzzle>

<new_puzzle>
- `description`：在含有"模板面板"和"数据面板"的网格中，将模板面板中的图案形状与数据面板中的颜色分布组合，生成最终的彩色图案。
- `Input structure`：背景为 Black。Grey 分隔列将网格分为左右两个面板。左面板（模板面板）包含一个由 Grey 像素绘制的图案形状。右面板（数据面板）包含若干水平色带（每行一种颜色，不同行颜色不同），色带覆盖面板的完整宽度。
- `Rule`：
  - 将模板面板的 Grey 图案作为掩码。
  - 将数据面板的色带作为逐行颜色源。
  - 输出与模板面板大小相同的网格：在模板有 Grey 像素的位置，填入该行在数据面板中对应行的色带颜色。
  - 在模板为背景色的位置，输出保持背景色。
  - 数据面板的行数必须等于模板面板的行数。
- `Key insight`：模板提供"在哪里画"，数据提供"用什么颜色画"——两种信息来自不同面板，必须组合才能生成输出。解题者需发现跨面板的行对行颜色映射关系。
</new_puzzle>

<new_puzzle>
- `description`：将网格中散落的同色像素对解读为"门"的两个门柱，在门柱之间画横梁，横梁高度由门柱之间区域内的标记像素数量决定。
- `Input structure`：背景为 Azure。网格中有若干颜色的像素对，每对由两个同色像素组成，位于同一行但不相邻（中间有若干背景像素的间隔）。在每对像素之间的间隔区域内，可能散布着若干 Grey 单像素标记。
- `Rule`：
  - 对每对同行同色像素（"门柱"），数出它们之间的 Grey 标记数量 N。
  - 在门柱所在行的上方 N 行处，画一条水平横梁连接两个门柱的列位置，颜色为门柱颜色。
  - 同时画两条垂直柱从横梁向下延伸到门柱行，颜色也为门柱颜色。
  - 擦除门柱之间的 Grey 标记。
  - 最终效果是每对门柱上方出现一个倒 U 形的"门框"，门框高度等于 N。
- `Key insight`：Grey 标记不是要移动或保留的对象——它们的数量编码了门框的高度。解题者需发现"标记计数 → 几何尺寸"的非直觉映射。
</new_puzzle>

<new_puzzle>
- `description`：根据网格中前景对象的旋转对称性阶数来决定在其周围画多少条等角分布的射线。
- `Input structure`：背景为 Black。网格中有若干不同颜色的 4-连通单色前景对象。每个对象具有某种旋转对称性（90 度旋转对称、180 度旋转对称、或无旋转对称性）。对象之间有足够间距。
- `Rule`：
  - 对每个对象，判断其旋转对称阶数：具有 90 度旋转对称（即旋转 90 度后与自身重合）的阶数为 4，具有 180 度旋转对称的阶数为 2，无旋转对称性的阶数为 1。
  - 从对象包围框中心向外画 N 条等角分布的射线（N = 对称阶数），射线延伸到网格边缘，颜色为对象颜色。
  - 阶数 4：画上/下/左/右四条射线。
  - 阶数 2：画左上到右下和右上到左下两条对角射线。
  - 阶数 1：画一条向右的水平射线。
  - 对象本身保持不变。
- `Key insight`：射线数量和方向由对称性阶数决定——解题者需先正确识别对象的旋转对称类型，然后才能推断射线模式。对称性判断本身是非平凡的视觉推理。
</new_puzzle>
