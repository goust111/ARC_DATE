<new_puzzle>
- `description`：将每个带有颜色标签的空心框内部用其标签颜色对应的外部模板图案填充，模板需根据标签位置确定旋转角度。
- `Input structure`：背景为 Black。网格中有若干不同颜色的一像素厚空心矩形框。每个框的某条外边上紧贴一个单像素彩色标签（标签颜色与框颜色不同）。网格中还有若干与标签同色的小型模板图案散布在远离框的区域。
- `Rule`：
  - 对每个框，读取其标签颜色，找到同色的外部模板图案。
  - 标签所在的边决定模板的旋转角度：标签在框的上边=0 度，右边=90 度顺时针，下边=180 度，左边=270 度顺时针。
  - 将模板旋转后居中填入框的内部空间，用模板颜色绘制；模板中的背景像素保持为背景色。
  - 如果模板尺寸小于框内部，居中放置；如果大于框内部，裁剪到框的内部尺寸。
  - 擦除标签像素和原始模板。
- `Key insight`：标签的颜色选择模板，标签的位置选择旋转角度——两个独立信息编码在同一个像素中，需要分别归纳。
</new_puzzle>

<new_puzzle>
- `description`：根据网格中每行前景像素的数量，将该行的前景像素重排为以行中心为中心的等间距分布。
- `Input structure`：背景为 Azure。每行包含 0-5 个单色前景像素（同一行内的像素颜色可能不同），分布在行的不同列位置。
- `Rule`：
  - 对每行，数出前景像素的数量 N。
  - 清空该行为背景色。
  - 将 N 个像素（保持原始颜色和从左到右的顺序）等间距重新放置，以行的中心列为中心对称分布。间距 = 行宽度 / (N+1)，取整后均匀分布。
  - N=0 的行保持不变。
- `Key insight`：像素的原始列位置被完全丢弃——只有数量和颜色顺序保留。输出的均匀分布模式在视觉上完全不同于输入的随机分布。
</new_puzzle>

<new_puzzle>
- `description`：在含有"发射器"和"靶标"的网格中，发射器沿其朝向射出颜色射线，射线遇到靶标后将靶标重绘为射线颜色，同时靶标的形状决定射线是否继续穿透或停止。
- `Input structure`：背景为 Black。网格中有若干由三个同色像素构成的 L 形"发射器"（占据 2x2 区域中的三个像素，缺失的角确定发射方向）。网格中还有若干不同颜色的小型靶标对象：实心矩形靶标和空心矩形框靶标。
- `Rule`：
  - 每个发射器从其 L 形缺失角的方向发射一条射线，射线颜色为发射器颜色。
  - 射线在背景上画一像素宽的直线段，直到遇到靶标或网格边缘。
  - 遇到实心靶标时：射线停止，靶标重绘为射线颜色。
  - 遇到空心框靶标时：射线穿透靶标继续前进，靶标的框边颜色重绘为射线颜色（内部背景不变）。
  - 射线不穿越其他发射器。
- `Key insight`：靶标的实心/空心状态决定射线是否穿透——这一规则需要从实心阻挡和空心穿透的对比中归纳，构成"方向解码 → 传播 → 形状决定穿透性"的推理链。
</new_puzzle>

<new_puzzle>
- `description`：将网格中排列成行的小型色块序列解读为"读取指令"，用该指令从一个大型参考图案中裁剪出指定区域作为输出。
- `Input structure`：背景为 Orange。网格左半部分是一个大型多色参考图案。右半部分有若干行由小型色块（2x2 的单色方块）排列的指令序列，各行之间用背景行间隔。每个色块的颜色来自参考图案中出现的颜色。
- `Rule`：
  - 每行指令序列中有两个色块：第一个色块的颜色指定"行范围"，第二个色块的颜色指定"列范围"。
  - "行范围"是参考图案中该颜色像素覆盖的行范围（最小行到最大行）。
  - "列范围"是参考图案中该颜色像素覆盖的列范围（最小列到最大列）。
  - 输出为参考图案在行范围和列范围交叉区域的裁剪。
  - 多行指令时，裁剪区域取所有指令指定区域的交集。
- `Key insight`：色块不是颜色指令而是范围指针——每种颜色在参考图案中的空间分布隐含定义了一个行列范围。两个色块的组合通过取交集进一步缩小裁剪区域。
</new_puzzle>

<new_puzzle>
- `description`：将网格中的完整行或列标记线解读为折叠轴，将一侧内容折叠到另一侧，重叠处取两层中非背景色的那个。
- `Input structure`：背景为 Black。网格中有一条完整的 Red 行或 Red 列（贯穿整个网格）。Red 线两侧各有不同的前景图案。两侧的图案在大部分位置互补——一侧有前景色的位置，另一侧通常是背景色，但有少数位置两侧都有前景色。
- `Rule`：
  - 将 Red 线识别为折叠轴。
  - 将较小的那一侧（像素数较少的半边）的内容沿折叠轴翻转到较大一侧上。
  - 对于每个位置，输出取两层中非背景色的像素；如果两层都有前景色，取折叠过来那一侧的颜色。
  - 输出网格大小等于较大那一侧的尺寸。
  - Red 折叠线不出现在输出中。
- `Key insight`：这不是简单的镜像——而是折叠叠加，像把纸对折后透过两层看到合成的图案。重叠冲突时折叠面优先的规则是需要归纳的关键。
</new_puzzle>
