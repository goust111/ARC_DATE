<new_puzzle>
- `description`：根据图例中色条的高度选择网格中对应高度的竖直条，将被选中的条重绘为图例色条的颜色，未选中的条擦除。
- `Input structure`：背景为 Black。网格左侧有一列竖排的小型色条图例（不同颜色的底部对齐竖直色条，各自高度不同，用背景列间隔）。网格右侧有若干底部对齐的单色竖直条（均为 Grey），高度各不同。
- `Rule`：
  - 读取图例中每个色条的颜色和高度。
  - 在右侧的 Grey 条中，找到与每个图例色条高度完全相同的 Grey 条。
  - 将匹配的 Grey 条重绘为对应图例色条的颜色。
  - 没有匹配图例的 Grey 条擦除为背景色。
  - 图例保持不变。
- `Key insight`：图例高度是匹配键而非排序指标——解题者需发现高度相等是配对条件，而非高度排序或颜色相关性。
</new_puzzle>

<new_puzzle>
- `description`：将网格中每个空心框对象的边框缺口位置和数量编码为框内部的填充图案——缺口侧画条纹，缺口数决定条纹数。
- `Input structure`：背景为 Azure。网格中有若干不同颜色的一像素厚空心矩形框。大部分框的边框完整，但部分框的某条边上有 1-3 个像素被擦除为背景色（缺口）。
- `Rule`：
  - 对每个有缺口的框，识别缺口所在的边（上/下/左/右）和缺口中被擦除的像素数 N。
  - 在框内部，沿缺口方向画 N 条一像素宽的条纹线，用框的颜色绘制：
    - 缺口在上/下边：画 N 条水平条纹，从缺口侧开始，等间距排列。
    - 缺口在左/右边：画 N 条垂直条纹，从缺口侧开始，等间距排列。
  - 完整框（无缺口）内部保持为背景色。
  - 原始缺口像素保持为背景色（不修复）。
- `Key insight`：缺口同时编码方向和数量两种信息——方向决定条纹朝向，像素数决定条纹数量。这两个规则需要从不同的框的比较中分别归纳。
</new_puzzle>

<new_puzzle>
- `description`：在由墙壁分隔的网格中，将每个房间内的彩色标记按照标记的空间排列顺序解码为该房间边框的涂色指令。
- `Input structure`：背景为 Black。Grey 墙壁将网格分为若干矩形房间。每个房间内有 1-4 个不同颜色的单像素标记，分布在房间的不同位置。
- `Rule`：
  - 对每个房间，读取其标记像素。
  - 按标记像素相对于房间中心的方位排序：上方标记 → 涂上边框，右方标记 → 涂右边框，下方标记 → 涂下边框，左方标记 → 涂左边框。
  - 将对应方位的边框从 Grey 重绘为该标记的颜色。
  - 没有标记指向的边框保持 Grey。
  - 房间内标记擦除为背景色。
- `Key insight`：标记的位置不是随意的——它相对于房间中心的方位是一个指向房间边框的方向指令，标记颜色是该边框的目标颜色。
</new_puzzle>

<new_puzzle>
- `description`：将网格中每个前景对象的形状解析为一个方向序列，然后沿该序列从对象位置出发画一条折线路径。
- `Input structure`：背景为 Orange。网格中有若干不同颜色的小型 4-连通前景对象（3-6 像素）。每个对象的形状可以被唯一地解读为一条从某个端点开始的 4-连通路径（对象是一条无分支的链状像素序列）。
- `Rule`：
  - 对每个对象，找到其路径的两个端点（只有一个 4-邻域前景像素的像素）。
  - 选择行坐标较小的端点作为起点（行相同则选列坐标较小的）。
  - 沿路径从起点到终点，记录每一步的方向（上/下/左/右）。
  - 从对象包围框的右下角开始，沿相同的方向序列画一条折线路径，每步画一个像素，使用对象的颜色。
  - 原始对象保持不变。
- `Key insight`：对象的形状是一个编码了方向序列的"指令条"——它不是要被移动的内容，而是要被解读的程序。输出的折线路径是对象形状的"执行结果"。
</new_puzzle>

<new_puzzle>
- `description`：在含有色块网格和选择标记的输入中，根据标记的行列位置从色块网格中提取指定的行和列，交叉组合输出。
- `Input structure`：背景为 Black。网格分为两个区域：上方是一个 NxM 的彩色像素矩阵（色块网格，无背景间隔，每个像素一种颜色）；下方有若干单像素标记，分为两类——Red 标记和 Blue 标记，各占一行排列。
- `Rule`：
  - Red 标记的列位置指定从色块网格中提取哪些列。
  - Blue 标记的列位置指定从色块网格中提取哪些行（标记的列位置对应色块网格的行索引）。
  - 输出是提取出的行与列的交叉子矩阵。
  - 行按照 Blue 标记从左到右的顺序排列，列按照 Red 标记从左到右的顺序排列。
- `Key insight`：两种颜色的标记分别是行选择器和列选择器——解题者需发现 Red 选列、Blue 选行的映射关系，以及列位置到行索引的间接编码。
</new_puzzle>
