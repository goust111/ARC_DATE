<new_puzzle>
- `description`：根据前景对象内部颜色块的排列方向来决定对对象执行哪种几何变换，同时将颜色块的数量转化为变换的参数。
- `Input structure`：背景为 Black。网格中有若干分离的多色 8-连通前景对象。每个对象由 2-4 个不同颜色的矩形色块紧密拼接而成。色块的排列方向要么是水平（从左到右排列），要么是垂直（从上到下排列）。
- `Rule`：
  - 对每个多色对象，判断其色块排列方向。
  - 水平排列的对象：将整个对象顺时针旋转 90 度 x N 度，其中 N 是色块的数量。
  - 垂直排列的对象：将整个对象沿水平方向翻转 N 次（奇数次翻转等于翻转一次，偶数次等于不翻转），其中 N 是色块的数量。
  - 变换后对象保持在其原始包围框中心位置。
  - 超出网格边界的部分裁剪。
- `Key insight`：排列方向选择变换类型，色块数量选择变换参数——两个属性同时编码在对象内部结构中，需要分别提取和独立归纳。
</new_puzzle>

<new_puzzle>
- `description`：在网格的四个象限中，每个象限包含的前景对象形状和象限本身的"地址"共同决定该对象应在输出网格中放置的位置。
- `Input structure`：背景为 Azure。一条完整 Grey 行和一条完整 Grey 列形成十字分隔线，将网格分为四个象限。每个象限内有一个单色 4-连通前景对象（四个对象颜色各不相同）。
- `Rule`：
  - 读取每个象限的"地址"：左上=(0,0)，右上=(0,1)，左下=(1,0)，右下=(1,1)。
  - 读取每个对象的包围框中心相对于其象限中心的偏移方向：偏向上=0，偏向下=1，偏向左=0，偏向右=1。
  - 将对象的偏移方向编码为一个二位地址 (行偏移, 列偏移)。
  - 将对象从其原始象限移到由偏移地址指定的象限中（保持在目标象限内的相同相对位置）。
  - 分隔线保持不变。
- `Key insight`：对象在原始象限内的偏移位置编码了它的目标象限——这是一种空间自引用机制。解题者需发现偏移方向不是对象的属性而是移动指令。
</new_puzzle>

<new_puzzle>
- `description`：从网格中的"完整样本"和"残缺样本"比较中推断出缺失规律，然后在"测试样本"中补全缺失部分。
- `Input structure`：背景为 Black。Grey 分隔行将网格分为三个水平面板。第一个面板包含一个完整的多色图案（"完整样本"）。第二个面板包含同一图案的残缺版本——部分像素被擦除为背景色（"残缺样本"）。第三个面板包含一个不同的完整图案（"测试样本"）。
- `Rule`：
  - 比较完整样本和残缺样本，确定被擦除的像素位置集合——即"缺失掩码"。
  - 将同一缺失掩码应用到测试样本上：在测试样本中与缺失掩码对应的位置，将像素替换为 Red 色。
  - 输出仅包含修改后的测试样本面板。
- `Key insight`：第一和第二面板是"示例对"，展示了一个空间掩码的效果。解题者需从两者的差异中提取掩码模式，然后将该模式迁移到第三面板——核心是"差异提取 → 模式迁移"。
</new_puzzle>

<new_puzzle>
- `description`：将网格中每个前景对象沿其自身形状的"主轴方向"平移，平移距离等于对象跨越的行数或列数。
- `Input structure`：背景为 Orange。网格中有若干不同颜色的 4-连通单色前景对象。每个对象的包围框是一个非正方形矩形（宽和高不等）。
- `Rule`：
  - 对每个对象，确定其包围框的长轴方向：宽大于高则主轴为水平方向，高大于宽则主轴为垂直方向。
  - 沿主轴方向平移对象：
    - 水平主轴：向右平移，距离等于对象包围框的宽度。
    - 垂直主轴：向下平移，距离等于对象包围框的高度。
  - 擦除对象原始位置的像素。
  - 平移后超出网格边界的部分裁剪。
- `Key insight`：主轴方向同时决定平移方向和平移距离——宽对象向右移动宽度那么多步，高对象向下移动高度那么多步。方向和距离不是独立参数。
</new_puzzle>

<new_puzzle>
- `description`：在含有彩色"信号源"和 Grey"导线"的网格中，信号沿导线传播并在导线分叉处分裂，最终将导线末端的标记重绘为信号颜色。
- `Input structure`：背景为 Black。网格中有若干单像素彩色"信号源"（不同颜色）。从每个信号源出发有 Grey 色的一像素宽导线（4-连通直线段），导线可能在某些位置分叉（T 形或十字形交叉）。导线末端（只有一个 Grey 4-邻居的 Grey 像素）是"接收端"。
- `Rule`：
  - 从每个信号源沿 4-连通的 Grey 导线传播信号。
  - 信号在分叉处分裂，沿所有分支继续传播。
  - 信号到达接收端时，将接收端像素重绘为信号源的颜色。
  - 导线上的中间像素保持 Grey。
  - 如果两个不同颜色的信号到达同一接收端，该端标记为 Maroon。
  - 信号源保持不变。
- `Key insight`：导线网络的拓扑结构决定了哪个信号源到达哪个接收端——分叉使一个信号能到达多个端点。冲突检测（双色合为 Maroon）是第二层规则。
</new_puzzle>
