<new_puzzle>
- `description`：将网格中由分隔线围成的每个区域内的前景图案与相邻区域的图案进行比较，保留两者的"交集"像素，删除"差集"像素。
- `Input structure`：背景为 Black。一条完整的 Grey 行或列将网格分为两个等大的区域。两个区域内各有一个由同一种前景色绘制的图案，两个图案形状相似但不完全相同（部分像素位置不同）。
- `Rule`：
  - 将两个区域的图案在各自区域内的局部坐标下对齐比较。
  - 两个图案都有前景像素的位置（交集）：保持前景色不变。
  - 只有一个图案有前景像素的位置（差集）：将该位置标记为 Red。
  - 两个图案都没有前景像素的位置：保持背景色。
  - 分隔线保持不变。
- `Key insight`：这是一个视觉"diff"操作——解题者需要发现分隔线两侧的图案是同一图案的两个版本，而输出高亮的是它们之间的差异，不是简单的叠加或合并。
</new_puzzle>

<new_puzzle>
- `description`：根据网格中每个封闭区域内标记像素的数量来选择该区域边框应使用的线型（实线/虚线/点线），同时用标记颜色重绘边框。
- `Input structure`：背景为 Azure。Grey 色完整行列形成若干封闭矩形区域（Grey 线条构成网格状分隔线）。每个区域内部散布着若干同色的单像素标记点，不同区域的标记颜色和数量各不相同。
- `Rule`：
  - 对每个区域，读取标记颜色 C 和标记数量 N。
  - 用颜色 C 重绘该区域的四条边框，线型由 N 决定：
    - N = 1：实线（边框上每个像素都画）。
    - N = 2：虚线（每隔一个像素画一个，即画一个跳一个）。
    - N = 3：点线（每隔两个像素画一个）。
    - N >= 4：保持 Grey 不重绘。
  - 区域内部标记点擦除为背景色。
  - 多个区域共享的边框段，使用后处理区域的颜色和线型（按区域从左上到右下的顺序处理）。
- `Key insight`：标记数量编码的不是大小或颜色而是线型样式——这个映射关系相当隐蔽，需要从多个区域的比较中才能发现。
</new_puzzle>

<new_puzzle>
- `description`：将网格中的多个同形异色对象进行颜色轮换——每个对象的颜色替换为下一个按空间顺序排列的同形对象的颜色，最后一个轮换到第一个。
- `Input structure`：背景为 Black。网格中有若干 4-连通前景对象，它们的形状可归为若干组（同组对象形状相同，不同组形状不同）。同组内的对象颜色各不相同，散布在网格不同位置。
- `Rule`：
  - 将所有前景对象按形状归一化（平移到左上角后比较，不考虑旋转）分组。
  - 在每组内，将对象按其包围框中心的行优先顺序排列。
  - 将组内颜色循环向前移一位：第一个对象获得第二个对象的颜色，第二个获得第三个的颜色，……最后一个获得第一个的颜色。
  - 对象形状和位置保持不变，只有颜色变化。
  - 形状独一无二的对象（该组只有一个成员）颜色不变。
- `Key insight`：颜色轮换的前提是形状分组——解题者需先发现不同位置的对象共享同一形状这个隐含关系，然后才能归纳出组内颜色循环的规则。
</new_puzzle>

<new_puzzle>
- `description`：在含有"源"和"池"的网格中，源从边缘射出颜色射线穿过背景，射线进入池后在池内扩散填充，扩散颜色由池边框颜色与射线颜色共同决定。
- `Input structure`：背景为 Orange。网格边缘上有若干单像素彩色"源"标记（各种颜色，紧贴网格边界）。网格内部有若干不同颜色的一像素厚空心矩形框（"池"），池内部为背景色。
- `Rule`：
  - 每个源标记沿其所在边缘的法线方向（向网格内部）射出一条射线。
  - 射线颜色为源的颜色，在背景上画一像素宽的直线，直到遇到池的边框或网格对边。
  - 射线遇到池的边框时停止。
  - 如果射线颜色与池边框颜色相同：池内部填充该颜色。
  - 如果射线颜色与池边框颜色不同：池内部不填充，射线在池边框处终止但不画在池边框上。
  - 每个池最多被一条射线填充（按射线到达的先后顺序，先到先得）。
- `Key insight`：射线和池之间存在颜色匹配的"钥匙-锁"关系——只有同色射线才能打开池的填充。解题者需同时理解射线传播规则和颜色匹配条件。
</new_puzzle>

<new_puzzle>
- `description`：将网格中的各前景对象视为字母表中的"字符"，根据它们在不同面板中的排列顺序推断替换规则，然后在测试面板中应用同一替换。
- `Input structure`：背景为 Black。Grey 分隔列将网格分为 3-4 个等宽面板。前 2-3 个面板各包含一组彩色前景对象（每组含 3-5 个对象），排列在面板内的不同位置。这些面板成对出现：一个"输入面板"和紧邻右边的"输出面板"构成一个示例对。最后一个面板是"测试输入面板"，其右侧为空白的"测试输出面板"。
- `Rule`：
  - 在每个示例对中，比较输入面板和输出面板中对象的变化：某些对象的颜色被替换了，某些保持不变。
  - 从所有示例对中归纳出一个一致的颜色替换规则（例如：Red → Blue，Green → Yellow）。
  - 在测试输入面板中应用同一替换规则，将结果绘制在测试输出面板中。
  - 对象的形状和位置保持不变。
- `Key insight`：这是"类比推理"的元结构——谜题本身是一个嵌套的 ARC 问题：外层是面板到面板的变换，内层是颜色替换规则的归纳。解题者需要在面板级别发现示例-测试的关系。
</new_puzzle>
