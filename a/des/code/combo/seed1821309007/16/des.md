- `description`：将网格中每个前景对象按其所在的"环形带"分组——对象到网格中心的距离层决定其分组，然后同组对象的颜色循环轮换一位。
- `Input structure`：背景为 Black。网格中散布若干不同颜色的小型 4-连通单色前景对象（每个 2-5 像素）。对象与网格中心的距离各不相同。
- `Rule`：
  - 将网格中心向外划分为若干距离层：第 0 层是中心 3x3 区域，第 1 层是围绕第 0 层的下一圈 2 像素宽的环形带，第 2 层是再外一圈，以此类推。
  - 将每个对象分配到其包围框中心所在的距离层。
  - 在每个距离层内，将该层的所有对象按顺时针角度排序。
  - 将排序后的颜色序列循环前移一位：第一个对象获得第二个对象的颜色，最后一个获得第一个的颜色。
  - 只有一个对象的层不变色。
  - 对象形状和位置不变，只有颜色轮换。
- `Key insight`：分组键不是行列坐标而是到中心的距离层——同一层内的颜色轮换需要先正确分层，再按角度排序后循环。
</new_puzzle>

<new_puzzle>
- `description`：从网格中的多个带标记的空心框中提取标记位置模式，用该模式在最大的空心框内部生成标记色填充。
- `Input structure`：背景为 Azure。网格中有若干不同颜色的一像素厚空心矩形框，大小各不相同。每个较小的框内部有一个单像素彩色标记，标记在框内部的相对位置各不相同（如偏左上、居中、偏右下等）。有一个最大的空心框内部为空（无标记）。
- `Rule`：
  - 对每个有标记的小框，记录标记在框内部的相对位置（以框内部左上角为原点的行比例和列比例）。
  - 将所有标记的相对位置映射到最大框的内部空间中。
  - 在最大框内部的对应相对位置处放置标记，颜色为对应小框的框色。
  - 小框保持不变。
- `Key insight`：小框中的标记位置是相对坐标——当映射到大框时需要按比例缩放。标记颜色不取决于标记本身而是其所在小框的边框颜色。
</new_puzzle>

<new_puzzle>
- `description`：在网格中找到所有形状相同但颜色不同的对象对，在每对之间画一条连线，连线颜色由两个对象颜色的"混合"规则决定。
- `Input structure`：背景为 Black。网格中有若干不同颜色的 4-连通单色前景对象。部分对象的形状相同（平移归一化后掩码一致），形成同形对。形状唯一的对象是干扰项。
- `Rule`：
  - 将所有对象按形状分组（平移归一化后比较，不考虑旋转翻转）。
  - 每组恰好有两个对象（同形对）或一个对象（干扰项）。
  - 对每个同形对，在两个对象的包围框中心之间画一条直线（水平、垂直或对角，取最短的轴对齐路径：先水平后垂直的折线）。
  - 连线颜色为 Maroon（固定色，表示"配对成功"）。
  - 干扰项对象擦除为背景色。
- `Key insight`：形状匹配是配对的关键——解题者需发现颜色不同但形状相同的对象是成对的，而形状独特的对象是要被删除的干扰项。
</new_puzzle>

<new_puzzle>
- `description`：将网格中的前景像素根据其在前景图案中的"连通角色"（端点/中继/分支/交叉）重绘为不同颜色。
- `Input structure`：背景为 Azure。网格中有单一前景色（Grey）形成一个 4-连通图案（可能有分支和交叉）。
- `Rule`：
  - 对每个 Grey 像素，数出其 4-邻域中 Grey 像素的数量 K。
  - K=1（端点）：重绘为 Red。
  - K=2（中继点，路径中间）：重绘为 Green。
  - K=3（T 形分支点）：重绘为 Blue。
  - K=4（十字交叉点）：重绘为 Yellow。
  - 背景像素不变。
- `Key insight`：每个像素的颜色完全由其局部 4-邻域的前景像素计数决定——这是一个局部规则，但解题者需要从全局模式的颜色变化中反向推断出这个局部计数规则。
</new_puzzle>

<new_puzzle>
- `description`：从含有"源图案"和"变换指令"的网格中，解读指令面板对源图案执行一系列空间变换，输出最终结果。
- `Input structure`：背景为 Black。Grey 分隔行将网格分为上下两部分。上方是一个多色"源图案"。下方是"指令面板"，包含 1-3 个横向排列的小型符号，每个符号是一个 3x3 的 Red 图案，形状表示一种变换操作。
- `Rule`：
  - 解读指令符号（从左到右依次执行）：
    - 水平线形（3 像素水平排列）=水平翻转。
    - 垂直线形（3 像素垂直排列）=垂直翻转。
    - L 形（2x2 区域缺一角）=顺时针旋转 90 度。
    - 十字形（中心+四个正交邻居）=颜色取反（每种前景色替换为其"互补色"，通过示例中的颜色对推断互补关系）。
  - 按从左到右的顺序依次对源图案执行指令。
  - 输出最终变换后的图案。
- `Key insight`：下方面板不是装饰——每个 3x3 符号编码一种变换操作。解题者需从符号形状到变换类型的映射中归纳编码规则，然后按序组合执行。
</new_puzzle>
