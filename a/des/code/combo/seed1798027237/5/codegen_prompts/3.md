利用小型"模具"对象内部的孔洞图案在配对的大型同色矩形上冲压镂空，再将冲下的碎片收集到指定区域。

Input structure
- 背景为 black 的网格中有若干大型实心彩色矩形和若干小型同色"模具"对象。
- 每个模具是一个小矩形块，其内部包含若干背景色 black 像素形成的孔洞图案，模具其余部分为某种前景色。每个模具的颜色与恰好一个大型矩形的颜色相同，形成唯一的颜色配对。
- 每个模具位于其配对大型矩形的外部，且与该大型矩形在水平或垂直方向上对齐（模具的某些行与大型矩形的某些行处于同一行号，或某些列处于同一列号）。
- 网格左下角有一个由 azure 像素构成的单像素宽矩形边框，围成一个空白的"碎片收集区"。

Rule
- 对每个颜色配对，将模具的孔洞图案（模具 bbox 内部为 black 的像素的相对位置）投影到配对大型矩形上：投影在对齐方向上与模具保持相同的行号或列号，在非对齐方向上从大型矩形靠近模具一侧的边缘开始，与模具在该方向上的内部偏移一一对应。
- 在大型矩形上将投影命中的像素清除为背景色（完成镂空）。
- 将被清除的像素（保留其颜色和相对形状）作为碎片，放入碎片收集区内部。碎片在收集区中按照其对应大型矩形在网格中从上到下的顺序依次从收集区顶部向下排列，碎片之间间隔一行。
- 模具对象在输出中被清除为背景色。收集区 azure 边框保持不变。

Key insight
解题者需要三步推理：(1) 通过颜色匹配将模具与大型矩形配对；(2) 理解模具的孔洞（black 像素）才是"冲压模板"——模具的实体部分是干扰项，真正起作用的是其中的空洞；(3) 发现被冲掉的碎片要按空间顺序收集到指定区域。孔洞即模板的反直觉是核心隐蔽性所在。
</new_puzzle>
