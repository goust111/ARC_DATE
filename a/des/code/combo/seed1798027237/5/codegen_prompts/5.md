将散落的碎片通过形状匹配（含旋转）拼入拼图底板的缺口中，拼入后碎片颜色替换为缺口边框提示色，同时边框提示色像素恢复为其外侧邻居的原始颜色。

Input structure
- 背景为 black 的网格分为上下两个区域，由一条水平的 grey 分隔线隔开。
- 上方区域包含一个大型"拼图底板"：一个矩形区域由若干不同颜色的相邻色块紧密拼成，但其中有 2-4 个不规则形状的缺口（缺口处为背景色 black）。每个缺口的所有相邻像素（缺口在底板内部一侧的 4-连通邻居）被统一替换为一种独特的"边框提示色"（如 maroon、azure、orange 等），不同缺口的提示色各不相同。
- 下方区域散布着 2-4 个彩色碎片对象，每个碎片是一个不规则形状的 4-连通区域，使用某种前景色（与所有提示色不同）。碎片数量与缺口数量相同。

Rule
- 对每个碎片，通过形状匹配找到其对应的缺口：碎片经过 0°、90°、180° 或 270° 旋转后，其形状与某个缺口的形状完全吻合（像素数相同且相对位置一致）。不需要翻转，每个碎片恰好匹配一个缺口。
- 将碎片旋转到正确角度后填入缺口位置。填入后碎片像素的颜色不保留原色，而是全部替换为该缺口的边框提示色。
- 同时，缺口周围那些边框提示色像素在输出中被恢复为其原始颜色。恢复方法：每个提示色像素取其 4-连通邻居中不属于缺口、不属于提示色的那个邻居的颜色（即该像素背向缺口一侧的底板色块颜色）。
- 下方区域的碎片在输出中被清除为背景色。分隔线保持不变。

Key insight
解题者需要依次完成三层推理：(1) 通过含旋转的形状匹配将碎片与缺口配对——碎片颜色与缺口无关，只有形状吻合才是配对依据；(2) 发现填入的碎片不保留原色而是采用缺口边框提示色进行染色，理解提示色作为"目标色"的角色；(3) 发现边框提示色本身也需要被还原为原始底板颜色，还原线索来自其外侧邻居——这揭示了提示色只是临时标记层。三层规则层层递进，单一样例难以完全归纳。
