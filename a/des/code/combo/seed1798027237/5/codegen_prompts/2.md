<new_puzzle index="2">
将网格中的彩色"种子"像素按分隔线上箭头标记编码的全局方向生长为 L 形枝条，枝条在碰到分隔线或边界时截断。

Input structure
- 背景为 black 的网格被一条水平的 grey 线和一条垂直的 grey 线分成四个象限。
- 两条分隔线的交叉点是网格的视觉中心。
- 每条分隔线上恰好有一个非 grey 的 maroon 像素作为"箭头标记"，位于交叉点的某一侧。水平线上的 maroon 标记指示水平方向（标记在交叉点左侧表示"向左"，右侧表示"向右"）；垂直线上的 maroon 标记指示垂直方向（标记在交叉点上方表示"向上"，下方表示"向下"）。两个方向组合成一个全局朝向（如"向左 + 向上" = 左上）。
- 四个象限中各散布着 1-3 个孤立的彩色前景像素（"种子"），颜色各不相同且不包含 grey 或 maroon。

Rule
- 根据两个 maroon 标记相对于交叉点的位置确定一个全局朝向（四种之一：左上、右上、左下、右下）。
- 每个种子像素生长为一个 L 形枝条：先从种子位置沿全局朝向的水平分量方向（左或右）连续延伸 2 格，再从该端点沿全局朝向的垂直分量方向（上或下）连续延伸 2 格，全部使用种子自身的颜色绘制。
- 若延伸过程中某一格会落在分隔线上或超出网格边界，枝条在该格之前截断（不覆盖分隔线）。
- 分隔线（含 maroon 标记）在输出中保持不变，种子原位置保留为枝条的起点。

Key insight
解题者首先需要从分隔线上两个 maroon 标记相对于交叉点的位置解码出全局生长方向，然后将该方向拆解为水平和垂直两个分量来驱动每个种子的 L 形生长路径。方向编码隐藏在分隔线结构中，与生长规则构成两个独立的推理层。
</new_puzzle>

1. `main(grid)` 必须实现新题描述中的确定性转换规则，不能只识别 `generate_input()` 的固定模板。

3. 生成器必须保证输入满足 `main()` 的隐式假设：对象不重叠、不越界、特殊标记唯一或可区分、匹配关系无歧义、关键分支出现概率相同。
4. 禁止把 ARC 颜色 id 当作人类不可见的数值语义参与排序、大小比较或隐藏映射。颜色变化必须有可见结构线索。注意颜色亮度等也是不可见信息，若描述中出现违规的颜色id或者亮度，可自行使用少量的固定颜色替代，但注意生成时要在三个以内输入输出网格中对所有变换100%覆盖度。

6. 若规则有多个分支，生成器不能长期固定成一个分支；应让分支在随机样例中合理出现。
7. 代码风格参考 `ARC_code`：使用 `numpy`，必要时使用本地 helper，但目标文件应能被 `SourceFileLoader` 直接加载。
