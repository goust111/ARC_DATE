根据内部孔洞的形状在网格边界上"盖章"对应的轮廓印记。

Input structure
- 背景为黑色的方形网格。
- 网格中散布若干单色填充矩形，每个矩形内部被挖去一个连通的孔洞（孔洞颜色为背景色黑色）。
- 每个矩形恰好位于网格的某一条边附近（上、下、左、右），即矩形的一条边紧贴或最接近该边界。

Rule
- 保留所有原始矩形及其孔洞不变。
- 对每个矩形，提取其内部孔洞的形状（相对于孔洞自身的包围盒）。
- 将孔洞形状作为印记，以矩形自身的颜色，"盖"在矩形所靠近的那条网格边界上：印记紧贴边界，水平居中（若靠近上/下边界）或垂直居中（若靠近左/右边界）对齐于矩形中心所在的行或列。
- 印记的朝向需要翻转：若矩形靠近上边界，则孔洞形状上下翻转后盖在顶部边缘；若靠近右边界，则左右翻转后盖在右侧边缘；以此类推，使得印记像是孔洞向边界方向"投射"出去的镜像。

Key insight
- 孔洞不是缺损而是编码：它的形状决定了边界印记的图案，它所在矩形靠近哪条边决定了印记出现在哪个方向，而翻转规则模拟了"从矩形向外投影"的镜像关系。解题需要先识别孔洞形状，再确定投影方向和翻转方式，构成两层独立推理。
</new_puzzle>

## 实现要求

1. `main(grid)` 必须实现新题描述中的确定性转换规则，不能只识别 `generate_input()` 的固定模板。
2. `generate_input()` 必须随机生成多样样例，不能固定死。随机维度应覆盖：网格大小、对象数量、位置、颜色、方向、形状参数或关键分支。
3. 生成器必须保证输入满足 `main()` 的隐式假设：对象不重叠、不越界、特殊标记唯一或可区分、匹配关系无歧义、关键分支出现概率相同。
4. 禁止把 ARC 颜色 id 当作人类不可见的数值语义参与排序、大小比较或隐藏映射。颜色变化必须有可见结构线索。注意颜色亮度等也是不可见信息，若描述中出现违规的颜色id或者亮度，可自行使用少量的固定颜色替代，但注意生成时要在三个以内输入输出网格中对所有变换100%覆盖度。

6. 若规则有多个分支，生成器不能长期固定成一个分支；应让分支在随机样例中合理出现。
7. 代码风格参考 `ARC_code`：使用 `numpy`，必要时使用本地 helper，但目标文件应能被 `SourceFileLoader` 直接加载。
