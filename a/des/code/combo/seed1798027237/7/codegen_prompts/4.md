根据框架内部的"种子"像素位置，在框架上对应的边上打开缺口，然后从缺口向外生长出与种子颜色相同的射线。

Input structure
- 背景为黑色的矩形网格。
- 网格中有若干个由 grey 像素绘制的空心矩形框架（边框宽度 1 像素），框架之间不重叠、不接触。
- 每个框架内部（被 grey 边框包围的区域）恰好有一个非黑非灰的彩色"种子"像素。
- 种子像素不在框架的正中心，而是偏向框架内部的某一侧。

Rule
- 对每个框架，找到种子像素到框架四条边的距离（以像素为单位），选择种子最靠近的那条边。
- 在该边上，将与种子同列（若最近边为上/下边）或同行（若最近边为左/右边）的那个 grey 边框像素替换为黑色，形成一个 1 像素宽的缺口。
- 从缺口位置出发，沿垂直于该边向外的方向，绘制一条种子颜色的射线，一直延伸到网格边界或碰到其他 grey 框架像素为止（不覆盖 grey 像素）。
- 种子像素本身从框架内部清除（恢复为黑色），框架其余部分保持 grey 不变。

Key insight
- 第一层推理：种子像素的偏移位置决定了哪条边被打开——这不是任意选择，而是"最近边"规则。第二层推理：缺口的精确位置由种子的行/列坐标投影到边上决定，射线从缺口向外延伸的方向与种子"试图逃离"框架的方向一致。种子既编码了出口方向又编码了出口位置，但需要两步独立推理才能解码。
</new_puzzle>
