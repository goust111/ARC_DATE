<new_puzzle index="2">
将网格中分散的彩色线段按颜色配对，然后沿配对线段围成的矩形区域填充第三种颜色，填充颜色由两条线段的交叉朝向决定。

Input structure
- 背景为黑色的矩形网格。
- 网格中有若干条水平或垂直的单色线段（长度至少为 3 像素），每种颜色恰好出现两条线段。
- 同色的两条线段一定一条水平一条垂直，且它们的延长线会形成一个交点。
- 网格中还存在一个由 grey 像素组成的 2x2 色块作为"调色板"，其四个像素分别为四种不同颜色，分布在四个象限位置（左上、右上、左下、右下各一个颜色）。

Rule
- 对每对同色线段，找到它们延长线的虚拟交点。
- 以两条线段的端点（远离交点一侧的端点）和虚拟交点为对角，确定一个轴对齐矩形区域。
- 判断虚拟交点相对于两条线段实际像素的方位（交点在线段对的左上、右上、左下还是右下），该方位对应调色板 2x2 色块中同一象限位置的颜色。
- 用该颜色填充矩形区域的内部（不含边框），原有线段像素保持不变。

Key insight
- 第一层推理：识别同色线段配对并构造虚拟交点来定义填充矩形。第二层推理：交点相对于线段对的方位需要映射到调色板的对应象限才能确定填充色——调色板是方位-颜色的编码表，而非装饰。
