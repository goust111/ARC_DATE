<description>
根据彩色种子像素在网格分区中的位置，用种子颜色沿分区边界生长出与种子所在象限对应方向的L形枝条，枝条长度由该分区内背景像素的行数决定。

Input structure:
- 背景为 Black。网格被若干条贯穿整行或整列的 Grey 直线分割成矩形分区。
- 每个分区内恰好有一个彩色种子像素（颜色各不相同，可能为 Red、Blue、Green、Yellow、Orange 等）。
- 种子像素位于分区内部某处，其余分区内像素均为 Black 背景。

Rule:
- 对每个分区，先判断种子像素位于该分区四个象限中的哪一个（以分区中心为基准，分为左上、右上、左下、右下）。
- 象限决定L形枝条的生长方向：左上象限→枝条向右再向下；右上象限→枝条向左再向下；左下象限→枝条向右再向上；右下象限→枝条向左再向上。即枝条始终朝对角方向展开。
- 枝条的每一段长度等于该分区内纯背景行的总数（不含种子所在行和 Grey 边界行）。
- 枝条从种子像素出发，先沿水平方向画出第一段，再从第一段末端沿垂直方向画出第二段，颜色与种子相同。
- Grey 分割线和种子像素本身保持不变。

Key insight:
种子在分区内的相对位置（象限）决定枝条的朝向，而分区内空行数编码了枝条长度——解题者必须同时归纳出方向规则和长度规则，两者缺一不可。
</description>
</new_puzzle>

<new_puzzle>
<description>
将散布在网格中的单色碎片按形状互补性配对，然后把每对碎片合并为一个填满的矩形，矩形的颜色由两片碎片的颜色混合规则决定。

Input structure:
- 背景为 Azure。网格中散布着若干个由单一颜色组成的 4-连通碎片对象，每个碎片的颜色可以是 Red、Blue、Yellow 中的一种。
- 每个碎片都可以视为从某个矩形中"挖去"一块后剩下的部分。碎片成对出现：一对中的两个碎片恰好互补——将它们叠合后可以拼成一个完整的矩形，两者无重叠也无间隙。
- 每对碎片的包围盒大小相同。不同对的包围盒大小可以不同。

Rule:
- 第一步（配对）：找出包围盒大小相同的碎片对，验证将一个碎片在其包围盒内取反后恰好等于另一个碎片的形状（即两者互补）。
- 第二步（混色）：Red + Blue → Magenta；Red + Yellow → Orange；Blue + Yellow → Green。同色配对时颜色不变。
- 第三步（绘制）：在两个碎片各自原始位置处，都替换为混合后颜色的完整矩形（大小等于包围盒）。即每个碎片位置都变成一个实心矩形。

Key insight:
解题者需要先发现碎片之间的形状互补关系来完成配对（这不是简单的颜色匹配），然后再发现颜色混合遵循减色混合规则——两层推理路径完全不同，第一层是空间几何推理，第二层是颜色组合推理。
</description>
</new_puzzle>

<new_puzzle>
<description>
网格中的彩色管道网络携带"信号色"从源头流向终端，信号在每个T形交叉处选择转弯方向由交叉处的指示标记决定，最终在终端处用信号色填充终端形状的内部。

Input structure:
- 背景为 Black。网格中有若干由 Grey 像素构成的一像素宽管道线段，这些线段水平或垂直延伸，在交叉处形成T形或L形连接，构成一个从源到终端的网络。
- 网络中有一个源头：一个 2x2 的实心彩色方块（颜色为 Red、Blue、Green、Yellow 或 Orange），位于某条管道的一端。
- 网络中有若干个终端：每个终端是一个中空的矩形框（由非 Grey、非背景色的单一颜色绘制，如 Maroon、Magenta 等），位于管道末端。
- 每个T形交叉处（即三个方向的管道汇合点）紧邻一个单像素指示标记，颜色与某个终端框的颜色相同，位于T形交叉的"直通"方向那一侧（即不转弯的出口侧）。

Rule:
- 信号从源头 2x2 方块出发，沿管道传播。信号色 = 源头方块的颜色。
- 在L形转弯处，信号自然跟随管道转弯。
- 在T形交叉处，信号不走指示标记所在的那个出口，而是转向另一个出口（即指示标记标记的是"禁止通行"方向）。
- 信号到达终端矩形框时，将该矩形框内部的 Black 背景像素全部填充为信号色。
- 管道、源头方块、指示标记和终端框的边框像素均保持不变。

Key insight:
解题者需要先理解T形交叉处的指示标记含义是"排除"而非"指向"（这是反直觉的核心洞见），然后沿管道追踪路径到达正确的终端，最后用源头色填充终端内部——三层推理依次为：标记语义的归纳、路径追踪、填充操作。
</description>
</new_puzzle>

<new_puzzle>
<description>
根据网格边缘色带的层叠顺序，对网格内部的多层同心矩形框重新上色，使内部框的颜色序列与边缘色带从外向内的顺序一致。

Input structure:
- 背景为 Black。网格内部有一组同心矩形框（每个框为一像素宽），由不同颜色绘制（如 Red、Blue、Green、Yellow、Orange 等），框与框之间有一像素的 Black 间隔。
- 网格的某一条外边缘（上、下、左或右）上绘有一条多段色带：色带由若干段不同颜色的连续像素组成，颜色段之间无间隔，每段长度至少 2 像素。色带中使用的颜色与同心框的颜色完全相同，但排列顺序不同。
- 色带的位置（在哪条边缘上）在不同样例中可能不同。

Rule:
- 第一步：找到边缘色带，读取色带中颜色段从外侧端点向内侧端点的顺序。"外侧端点"定义为距离色带所在边缘最近角落较近的那一端。
- 第二步：识别内部同心矩形框从最外层到最内层的嵌套顺序。
- 第三步：将同心框重新上色——最外层框使用色带第一个颜色，次外层框使用色带第二个颜色，依此类推。每个框的所有像素都替换为新颜色。
- 色带本身在输出中保持不变。Black 背景和间隔不变。

Key insight:
解题者必须先识别出边缘色带的存在并确定其读取方向（方向由色带相对于最近角落的位置决定，而非简单的从左到右），然后将色带颜色序列映射到同心框的几何层级——方向推断和层级映射构成两层独立的非平凡推理。
</description>
</new_puzzle>

<new_puzzle>
<description>
网格中的每个封闭区域内含有若干散点标记，根据区域边框上缺口的数量对散点进行聚类分组，再将每组散点连接成该组质心处的十字形图案。

Input structure:
- 背景为 Black。网格中有若干个由单一颜色（如 Red、Blue、Green 等，不同区域颜色不同）绘制的近似矩形封闭边框，每个边框一像素宽。
- 每个边框上有若干个一像素宽的缺口（即边框线断开一格的位置）。缺口数量为 1 到 4 之间。
- 每个封闭区域内部散布着若干个 Yellow 单像素标记点，位置随机但互不相邻。
- 区域外部的背景上没有 Yellow 标记。

Rule:
- 第一步：对每个封闭区域，数出其边框上的缺口数量 N。
- 第二步：将该区域内的 Yellow 标记点按从左到右、从上到下的阅读顺序排列，然后按每 N 个为一组进行分组（如果最后一组不足 N 个，则单独成组）。
- 第三步：对每一组标记点，计算该组所有点的视觉中心位置（行坐标取中位数、列坐标取中位数，向下取整），在该中心位置绘制一个十字形（上下左右各延伸一格，共 5 像素），颜色与该区域的边框颜色相同。
- 第四步：原来的 Yellow 标记点全部擦除为 Black 背景。边框（含缺口）保持不变。

Key insight:
缺口数量不是用来"打开"或"连通"什么，而是作为分组大小的编码参数——解题者需要先发现缺口数等于分组大小这个非显然的对应关系，然后再理解分组后如何聚合为十字图案的规则，两层推理路径截然不同。
</description>
</new_puzzle>
