根据封闭区域内部的颜色种类数，从色板图例中选取对应填充色，为每个封闭区域的外轮廓镶边。

Input structure:
- 背景为一种主色（如 Black）。
- 网格中散布若干由 Grey 像素围成的封闭区域（形状各异，均为完整闭合的一像素厚轮廓）。每个封闭区域内部包含若干不同颜色的像素点（如 Red、Blue、Green 等），数量和种类不等，但颜色种类数不超过 5。
- 网格的一条边缘（如底部一行）放置一个色板图例：图例由两行组成，上面一行依次排列 1、2、3、4、5 个连续同色小方块（分别代表"内部含 1 种颜色"、"含 2 种颜色"……），下面一行对应位置放置该数量所映射的边框填充色。每组之间用背景色隔开。

Rule:
- 保留所有 Grey 轮廓和内部彩色像素不变。
- 对每个封闭区域，数出其内部出现了多少种不同的非背景、非 Grey 颜色（即颜色种类数 K）。
- 在色板图例中找到上行方块数量等于 K 的那一列，读取下行对应的边框色 C。
- 将该封闭区域的 Grey 轮廓向外扩展一圈：在轮廓外侧所有与 Grey 正交相邻的背景像素处涂上颜色 C（若该像素已被另一个区域的镶边占据，则保持先到先得，不覆盖）。
- 色板图例本身在输出中保持不变。

Key insight:
解题需要两步非显然推理：第一步是发现封闭区域内部的颜色"种类数"（而非像素总数或面积）才是关键属性；第二步是将该种类数与边缘色板图例中上行方块的"连续长度"进行匹配，从而确定镶边颜色。仅观察轮廓形状或内部颜色本身都无法得出答案。
</new_puzzle>

<new_puzzle>
将每个彩色种子像素沿其所在象限的对角方向生长为矩形，矩形的宽高由同行和同列的另一颗种子的距离决定。

Input structure:
- 背景为 Black。
- 网格被一条水平 Grey 线和一条垂直 Grey 线分割为四个象限（两条线交叉形成十字，各一像素宽）。
- 每个象限内恰好有一个彩色种子像素（四个种子颜色互不相同，如 Red、Blue、Yellow、Green）。种子不在 Grey 线上。

Rule:
- 保留 Grey 十字线不变。
- 对每个种子像素 P（位于某象限），找到与 P 同行的另一个象限中的种子 Q（隔着垂直 Grey 线），以及与 P 同列的另一个象限中的种子 R（隔着水平 Grey 线）。
- 计算宽度 W = P 与 Q 之间的水平距离（不含 Grey 线像素和两端种子），高度 H = P 与 R 之间的垂直距离（同理不含 Grey 线像素和两端种子）。
- 以 P 为起点，向 P 所在象限的角落方向（即远离十字中心的对角方向）绘制一个 W×H 的实心矩形，颜色为 P 的颜色。矩形的一个角与 P 重合，矩形向象限角落方向延伸。
- 若矩形超出网格边界则截断到边界内。

Key insight:
每个种子的矩形尺寸并非由自身属性决定，而是由其他象限中与它共享行或列的种子的位置编码。解题者必须跨越 Grey 分割线建立行列配对关系，再将距离转换为几何尺寸，最后确定生长方向为远离中心的对角方向。
</new_puzzle>

<new_puzzle>
按照路径上箭头标记的转向指令，将从源点出发的射线折射传播，最终在路径经过的所有背景像素上涂色。

Input structure:
- 背景为 Black。
- 网格中有若干由 Grey 像素构成的箭头标记。每个箭头由一个 3×3 的图案表示：中心为 Grey，加上三个 Grey 像素构成箭头形状——箭头尾部占据中心到来源方向的一格，箭头头部占据中心到目标方向的两格（形成 "┘"、"┐"、"└"、"┌" 等 L 形转角），明确指示从哪个方向进入、向哪个方向离开。
- 网格边缘某处有一个彩色像素（如 Red）作为射线源点，它位于网格的某一条边上。
- 网格边缘另一处有一个不同颜色的像素（如 Blue）作为射线终点，也位于网格的某一条边上。

Rule:
- 从源点出发，沿垂直于源点所在边的方向向网格内部发射一条射线。
- 射线沿直线前进，在经过的每个背景像素上涂上源点的颜色。
- 当射线到达某个箭头标记的入口方向时，射线改变方向为该箭头指示的出口方向，继续前进。箭头本身的 Grey 像素保持不变。
- 射线继续传播直到到达终点像素或网格边界。
- 所有箭头标记和源点、终点像素保持不变，仅在射线路径经过的背景像素上涂色。

Key insight:
解题的核心在于识别 Grey 像素构成的 L 形图案实际上是方向转换器——箭头的形状编码了"入射方向→出射方向"的映射。解题者需要先理解箭头的朝向语义，然后沿路径依次应用每个转向指令来追踪完整路径。仅凭源点和终点的位置无法直接连线，必须逐个解读中间的转向标记。
</new_puzzle>

<new_puzzle>
识别每个彩色框架的缺口位置和缺口宽度，将框架内部的精灵图案从缺口方向"挤出"，在框架外复制该图案，复制次数等于缺口宽度。

Input structure:
- 背景为 Black。
- 网格中有若干矩形框架，每个框架由一种前景色（如 Red、Blue、Green 等）的一像素厚边框构成。每个框架的边框上恰好有一个缺口——某一侧边框的连续若干像素被移除（缺口宽度为 1 至 3 个像素）。
- 每个框架内部包含一个由另一种颜色构成的小型精灵图案（如 Yellow 的小十字、Magenta 的小 L 形等），精灵不接触框架边框。

Rule:
- 保留所有框架边框（含缺口）不变。
- 保留框架内部的精灵图案不变。
- 确定每个框架缺口所在的方向（上、下、左、右）以及缺口的宽度 G（缺口中缺失的像素数）。
- 从缺口方向向框架外部，以精灵图案的尺寸为步长，连续复制精灵图案 G 次。第一份副本紧贴框架外侧（与缺口对齐），后续副本依次向外排列，相邻副本之间无间隔。
- 复制的精灵使用与原精灵相同的颜色。若副本超出网格边界则截断。

Key insight:
解题包含两层推理：第一层是发现缺口的方向决定了精灵的"挤出"移动方向（而非精灵自身的形状或朝向）；第二层是发现缺口的宽度（缺失像素数）编码了复制的次数，而非移动的距离。这两个属性都来自框架边框而非精灵本身。
</new_puzzle>

<new_puzzle>
根据每个岛屿与海岸线上灯塔标记的可见性关系，用灯塔颜色的混合色填充岛屿。

Input structure:
- 背景为 Azure（代表"海洋"）。
- 网格中有若干由 Grey 像素构成的不规则实心区域作为"岛屿"，岛屿之间互不接触。
- 网格的四条边缘上分布着若干彩色像素作为"灯塔"（如 Red、Yellow、Green、Magenta），每个灯塔占据一个边缘像素。
- 网格中还有若干由 Maroon 像素构成的一像素宽的直线段作为"墙壁"（水平或垂直），墙壁不接触岛屿，但可能阻断灯塔与岛屿之间的视线。

Rule:
- 对每个灯塔，沿其所在边缘向网格内部的垂直方向发射一条视线射线（顶部边缘的灯塔向下发射，左侧边缘的灯塔向右发射，依此类推）。
- 射线在碰到 Maroon 墙壁时被阻断，无法穿过墙壁继续传播。
- 如果射线在被阻断前经过了某个岛屿（即射线穿过了该岛屿的至少一个 Grey 像素），则该岛屿"可见"该灯塔。
- 对每个岛屿，收集所有能看见它的灯塔的颜色集合。若集合中只有一种颜色，则用该颜色填充整个岛屿（替换 Grey）。若集合中恰好有两种颜色，则用交替条纹填充岛屿：沿岛屿包围框的较长轴方向，奇数行/列填第一种颜色（按灯塔在边缘上出现的顺序，先上后下先左后右，排序靠前者为第一种），偶数行/列填第二种颜色。若没有灯塔能看见该岛屿，则岛屿保持 Grey 不变。
- 灯塔、墙壁和海洋背景保持不变。

Key insight:
解题需要三层推理：第一层是理解灯塔从边缘向内发射视线射线的机制；第二层是发现 Maroon 墙壁作为遮挡物会阻断视线，从而改变哪些灯塔对哪些岛屿"可见"；第三层是根据可见灯塔的数量和颜色组合决定填充方式——单色直接填充，双色则交替条纹。岛屿的最终颜色完全由其可见性关系决定，而非空间距离。
</new_puzzle>
