将散落的彩色箭头沿其指向方向依次拼接成链，并用每个箭头的尾部颜色标记绘制连接路径。

Input structure：
- 背景为 black。
- 网格中有若干由同色像素构成的"箭头"对象，每个箭头由一个 3x1 或 1x3 的杆和一个 3 像素的 V 形箭尖组成（箭尖朝上/下/左/右之一），整体占据约 3x3 的区域。每个箭头有唯一的主体颜色。
- 每个箭头的杆的末端（远离箭尖的一端）有一个不同颜色的单像素"尾标"。
- 网格角落有一个 2x2 的 orange 方块作为"起点标记"。

Rule：
- 从起点标记出发，找到距离起点最近的箭头（按箭头中心到起点的视觉距离）。
- 沿该箭头的指向方向画一条该箭头尾标颜色的直线路径，从箭头箭尖出发延伸，直到碰到下一个箭头的杆部（路径不覆盖箭头本身的像素）。
- 到达的下一个箭头重复此过程：从该箭头箭尖出发，沿其指向方向画该箭头尾标颜色的路径，直到碰到再下一个箭头或网格边界。
- 所有箭头保留在原位，起点标记保留，仅在箭头之间的空白区域添加连接路径。
- 链中箭头的顺序由路径的物理延伸方向唯一确定（每个箭头的指向方向上恰好有一个下一个箭头）。

Key insight：
连接路径的颜色不由路径终点的箭头决定，而由路径起点箭头的尾标颜色决定——尾标是一个容易被忽略的单像素标记，它将颜色信息从一个箭头"发射"到下一段路径上，形成颜色-方向的双重编码链。
