- `description`：根据封闭区域内部"窗口"（背景色孔洞）的形状在色板中查找匹配色，再用该色填充区域外轮廓向外延伸一圈的光环。

- `Input structure`：
  - 网格以 black 为背景色。
  - 网格上方有一行色板条：由若干 3×3 的彩色小方块组成，每个小方块内部中央的一个或多个像素被挖去（显示为背景色），形成独特的孔洞图案；每个小方块使用不同颜色（如 red、blue、green、orange 等）。
  - 色板条下方的主区域中散布着若干大小不一的单色封闭区域（均为 grey），每个 grey 区域内部包含一个或多个背景色孔洞，这些孔洞的形状（平移归一化后）与色板条中某个小方块的孔洞图案完全一致。
  - 每个 grey 区域的孔洞图案恰好匹配色板中唯一一个小方块。

- `Rule`：
  - 保留色板条不变。
  - 对主区域中的每个 grey 封闭区域：
    1. 提取其内部背景色孔洞的形状，平移归一化后与色板条中每个小方块内部的孔洞图案进行匹配，找到对应的颜色 C。
    2. 找到该 grey 区域的外轮廓——即所有与该区域 4-邻接但不属于该区域的背景像素。
    3. 将这些外轮廓像素涂为颜色 C。
  - grey 区域本身保持不变，内部孔洞保持为背景色。

- `Key insight`：
  - 解题需要两层独立推理：第一层是发现色板中小方块的孔洞图案与主区域中封闭区域的内部孔洞存在形状对应关系（而非位置对应）；第二层是发现输出的着色位置不是区域本身，而是区域向外扩展一圈的光环轮廓。
</new_puzzle>

- `description`：将网格中每条彩色折线的拐点提取出来，按折线颜色在图例指定的目标行上从左到右排列为单像素点。

- `Input structure`：
  - 网格以 black 为背景色。
  - 网格最右侧有一列纵向图例：每隔两行出现一个彩色像素，该像素的行坐标即为该颜色折线拐点应被放置的目标行。
  - 主区域中有若干条不同颜色的折线（如 red、blue、green、magenta 等）。每条折线由水平段和垂直段交替连接组成，宽度为一个像素，折线之间不重叠。
  - 每条折线的颜色与图例中恰好一个像素的颜色相同。

- `Rule`：
  - 输出网格尺寸与输入相同，背景为 black，图例列保留不变。
  - 对每条折线：
    1. 识别其所有拐点（即折线从水平段变为垂直段或从垂直段变为水平段的转折像素）。
    2. 将拐点按其在折线中出现的顺序（从折线的一端到另一端）排序。
    3. 在图例中找到与该折线同色的像素所在的行 R。
    4. 从该行的第 1 列开始，依次放置与拐点数量相同的该颜色像素（每个像素占一列，连续排列）。
  - 折线本身在输出中被移除。

- `Key insight`：
  - 第一层推理是发现折线的拐点数量才是关键信息，而非折线的长度或位置；第二层推理是发现图例不仅指定颜色对应关系，还通过其行位置指定了输出行，即每条折线的拐点被"压缩"到图例指示的特定行上。
</new_puzzle>

<new_puzzle>
- `description`：在被分割线划分的多个子区域中，每个子区域内的彩色种子像素沿分割线的缺口方向"流动"到相邻子区域，最终将目标子区域填满种子的颜色。

- `Input structure`：
  - 网格以 black 为背景色。
  - 网格中有若干条 grey 直线（水平或垂直，一像素宽），将网格分割为若干矩形子区域。
  - 每条分割线上恰好有一个单像素缺口（该位置为背景色而非 grey）。
  - 部分子区域内包含一个单像素的彩色种子（颜色各不相同，如 red、blue、green、orange 等）。
  - 恰好有一个子区域为空（不含任何种子像素），它是最终的目标区域。

- `Rule`：
  - 从每个含种子的子区域出发，判断该子区域是否能通过分割线上的缺口到达目标空区域：从种子所在子区域开始，若该子区域与相邻子区域之间的分割线上存在缺口，则种子可以"流过"缺口进入相邻子区域，如此传递，直到到达目标空区域或无路可走。
  - 找到能够经过缺口链到达目标空区域的唯一种子。
  - 将目标空区域的所有背景像素填充为该种子的颜色。
  - 其余所有内容（分割线、缺口、其他种子）保持不变。

- `Key insight`：
  - 第一层推理是识别 grey 线上的缺口构成了子区域之间的"通道"；第二层推理是需要追踪从每个种子出发、经由缺口链能否连通到目标空区域，从而确定哪个种子的颜色应该填入目标区域——种子的颜色选择取决于拓扑连通性而非空间距离。
</new_puzzle>

<new_puzzle>
- `description`：根据每个彩色对象的轮廓凹陷方向，在凹陷所朝的网格边界上印出该对象颜色的标记条，标记条的长度等于凹陷的宽度。

- `Input structure`：
  - 网格以 black 为背景色。
  - 网格中散布着若干单色矩形对象（颜色各不相同，如 red、blue、green、yellow、magenta 等），每个矩形对象在某一侧边上有一个矩形凹陷（即该侧边上有若干连续像素被移除，露出背景色）。
  - 凹陷的深度均为 1 个像素，但宽度（沿边方向的跨度）因对象而异，范围在 1 到 4 像素之间。
  - 每个对象的凹陷恰好位于上、下、左、右四侧中的一侧，且不同对象的凹陷可以朝不同方向。

- `Rule`：
  - 保留所有原始对象不变。
  - 对每个对象：
    1. 识别其凹陷所在的方向（上、下、左、右）。
    2. 凹陷朝上 → 在网格最上一行绘制标记条；朝下 → 最下一行；朝左 → 最左一列；朝右 → 最右一列。
    3. 标记条使用该对象的颜色，长度等于凹陷的宽度（像素数）。
    4. 标记条在对应边界行/列上的位置：其中心与凹陷在垂直于凹陷方向的轴上的位置对齐。即：若凹陷朝上，标记条在顶行，其列范围与凹陷的列范围相同；若凹陷朝左，标记条在最左列，其行范围与凹陷的行范围相同。
  - 若多个标记条在边界上不重叠（题目保证不重叠）。

- `Key insight`：
  - 第一层推理是发现每个矩形的凹陷不仅指示方向，还编码了标记条的尺寸（凹陷宽度 = 标记条长度）；第二层推理是发现标记条的放置位置由凹陷方向决定（朝哪边凹就印到哪条边界上），而标记条沿边界的精确对齐位置则由凹陷自身的坐标投影决定。
</new_puzzle>

<new_puzzle>
- `description`：在网格中找到由框架颜色编码的旋转指令，将框架内的图案按指定次数旋转 90 度后放回原位。

- `Input structure`：
  - 网格以 black 为背景色。
  - 网格中有若干个独立的矩形框架，每个框架由一圈一像素宽的彩色边框围成（边框颜色各不相同）。
  - 每个框架内部包含一个由另一种颜色绘制的非对称图案（图案颜色与边框颜色不同，图案在旋转 0°/90°/180°/270° 下各不相同，以便区分旋转结果）。
  - 网格的某个角落（如左上角）有一个色板区域：色板由若干行组成，每行包含一个颜色像素后跟若干个 grey 小圆点（单像素），排列为 "颜色像素 + N 个 grey 点" 的形式。颜色像素的颜色与某个框架的边框颜色对应，N 的值为 1、2 或 3。

- `Rule`：
  - 移除色板区域（将其还原为背景色）。
  - 对每个框架：
    1. 在色板中找到与该框架边框颜色相同的行。
    2. 读取该行中 grey 点的数量 N。
    3. 将框架内部的图案顺时针旋转 N×90 度。
    4. 将旋转后的图案放回框架内部原来的位置。
  - 框架边框本身保持不变。

- `Key insight`：
  - 第一层推理是发现色板中每行的 grey 点数量编码了旋转次数，而非其他几何属性；第二层推理是发现色板行的颜色与框架边框颜色的对应关系——通过颜色匹配确定哪个框架应用哪个旋转量；第三层是正确执行顺时针旋转并将结果放回原始框架内（需要注意旋转中心为框架内部的中心）。
</new_puzzle>
