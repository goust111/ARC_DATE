<description>
根据框架内部的缺口形状匹配外部碎片，再按碎片自身的颜色标记点顺序决定框架内部同心环的着色方案。

Input structure:
- 背景为黑色。网格中有若干单色矩形空心框架（每个框架颜色不同，如蓝色、红色、绿色等）。
- 每个框架的边框上有一个连续缺口（缺口处边框像素被擦除为背景色），缺口形状各异（如 L 形、T 形、直线段等）。
- 框架外部散布着若干小型单色碎片，每个碎片的形状恰好与某个框架的某个缺口形状一致（可能需要旋转 0/90/180/270 度）。
- 每个碎片内部嵌有一到三个不同颜色的单像素标记点，这些标记点沿碎片的长轴方向排列，颜色各不相同。

Rule:
- 第一步：将每个碎片的形状与所有框架的缺口形状进行匹配（允许四种旋转），找到唯一对应关系。
- 第二步：将碎片旋转到与缺口朝向一致后，嵌入缺口位置，补全框架边框。嵌入后碎片颜色变为该框架的边框颜色。
- 第三步：读取碎片内标记点的颜色顺序（从碎片靠近框架外侧的一端到靠近框架内侧的一端），以此顺序对框架内部进行同心矩形环填充——最外环使用第一个标记色，次外环使用第二个标记色，依此类推；若标记色用尽则循环重复。

Key insight: 缺口形状匹配决定碎片归属于哪个框架，而碎片内嵌标记点的空间排列顺序（外到内）定义了框架内部同心环的着色方案——解题者需要先完成形状匹配，再理解标记点方向性编码着色规则，两步推理缺一不可。
</description>

<description>
将网格中的彩色箭头沿其指向方向发射至同色挡板处，箭头到达后将箭杆"折叠展开"为垂直于运动方向的矩形色块。

Input structure:
- 背景为黑色。网格中有若干箭头形对象和若干单像素宽的短线段（挡板）。
- 每个箭头由一种非背景色绘制，形状为一个三角形箭尖加一条直线箭杆：箭杆为沿某个正交方向（上、下、左、右）的连续像素线段（长度大于等于 2），箭尖为箭杆末端向运动方向突出的三像素尖端——箭杆最前端像素的前方一格处放置一个像素，该像素的左右（或上下，取决于方向）各一格各放置一个像素，三者共同构成 V 形尖端。
- 挡板为与箭头颜色相同的短线段（长度 2 到 4 像素），方向垂直于对应箭头的运动方向，位于箭头前方的路径上。
- 每个箭头与其同色挡板一一配对，路径上无其他障碍。

Rule:
- 对每个箭头，确定其指向方向（由箭尖朝向决定）。
- 将整个箭头对象沿指向方向平移，直到箭尖的最前端像素与同色挡板相邻（紧贴挡板前一格）时停止。
- 停止后，箭头发生"折叠展开"变换：箭杆的每个像素沿垂直于运动方向展开，展开长度等于箭杆原始长度，展开方向以箭杆原位置为中心向两侧对称扩展。箭尖像素保持不变。
- 擦除箭头和挡板的原始位置像素（被平移后的新位置覆盖的除外）。

Key insight: 箭头的指向决定运动方向，同色关系决定配对和停止位置，而"折叠展开"操作将一维的箭杆长度转化为二维的矩形宽度——解题者需要先识别箭头的运动-停止机制，再理解杆长到展开宽度的维度转换规则。
</description>

<new_puzzle>
<description>
在被灰色线划分的区域中，根据每个区域内"种子图案"的自身对称类型，选择不同的翻转铺满策略来填充该区域的四个角落。

Input structure:
- 背景为黑色。灰色单像素宽的水平线和垂直线将网格划分为若干矩形区域。
- 每个区域内有一个小型彩色图案（种子图案），由一种非背景非灰色的颜色绘制，占据区域的一个角落，大小不超过区域面积的四分之一。
- 种子图案本身可能具有以下对称性之一：（a）仅关于水平轴对称，（b）仅关于垂直轴对称，（c）关于两条轴都对称（即同时水平和垂直对称），（d）无任何轴对称性。

Rule:
- 对每个区域，识别种子图案所在的角落位置（左上、右上、左下、右下）以及种子图案的对称类型。
- 根据对称类型决定铺满方式：
  - 仅水平轴对称：将种子图案上下翻转后放置到同侧的上方或下方角落（即竖直方向的对面角落），形成上下两份图案。
  - 仅垂直轴对称：将种子图案左右翻转后放置到同行的另一侧角落（即水平方向的对面角落），形成左右两份图案。
  - 双轴对称：将种子图案分别翻转后填充到全部四个角落。
  - 无对称性：将种子图案旋转 180 度后放置到对角线方向的那个角落，只填充两个对角。
- 原始种子图案保持不变，灰色分隔线保持不变。

Key insight: 解题者不能简单地对所有区域执行统一的"复制到四角"操作——必须先判断每个种子图案自身的对称类型，再据此选择对应的铺满策略。对称类型的判别是第一层非显然推理，铺满方式的差异化选择是第二层推理。
</description>

<new_puzzle>
<description>
将网格中的多个彩色连通区域按照各区域内部"封闭孔洞数量"进行配对，再用配对伙伴的颜色互相重绘各自的外边界像素。

Input structure:
- 背景为黑色。网格中有偶数个互不接触的单色连通区域（4-连通），每个区域使用不同颜色。
- 每个区域是一个不规则的实心形状，内部可能包含零个、一个或多个由背景色构成的封闭孔洞（孔洞为被该区域像素完全包围的黑色连通块）。
- 孔洞数量在各区域之间恰好两两相同，形成唯一配对。例如：若有六个区域，其孔洞数分别为 0、2、1、1、0、2，则孔洞数为 0 的两个区域配对，孔洞数为 1 的两个配对，孔洞数为 2 的两个配对。

Rule:
- 第一步：计算每个彩色区域内部的封闭孔洞数量。
- 第二步：将孔洞数量相同的两个区域配对（每个数量恰好出现两次）。
- 第三步：对每对区域 A 和 B，提取各自的外边界像素（即与背景黑色像素四方向相邻的区域像素）。将 A 区域的外边界像素重绘为 B 的颜色，将 B 区域的外边界像素重绘为 A 的颜色。两个区域的内部非边界像素颜色保持不变。

Key insight: 孔洞计数是隐藏的配对键——解题者需要先注意到每个形状内部被包围的空洞数量，再发现数量相同的形状总是成对出现，最后理解配对后的边界颜色互换规则。三层推理环环相扣：识别孔洞、按孔洞数配对、边界互染。
</description>

<new_puzzle>
<description>
识别网格中重叠放置的多个彩色矩形的遮挡层级关系，推断每个矩形的完整形状，然后仅输出位于最底层的矩形。

Input structure:
- 背景为黑色。网格中可见若干不同颜色的矩形区域，部分区域之间存在重叠。
- 每个矩形为单一颜色的轴对齐实心矩形，但由于堆叠遮挡，某些矩形被其他矩形部分覆盖，只有未被遮挡的部分可见。
- 重叠处显示的是位于更上层（更靠前）矩形的颜色。
- 每种非背景颜色只出现一次（即每个矩形颜色唯一）。至少有三个矩形存在于网格中。

Rule:
- 第一步：识别所有矩形及其完整尺寸。对于被部分遮挡的矩形，需根据其可见的边缘像素推断完整的矩形范围——因为矩形是轴对齐的，可见部分中最小行、最大行、最小列、最大列即可确定完整矩形的四条边。
- 第二步：根据遮挡关系确定图层深度——若颜色 A 的可见区域覆盖了颜色 B 的完整矩形范围内的某些像素（即 B 在该处被 A 挡住了），则 A 在 B 之上。通过所有遮挡对关系，排列出从最上层到最底层的完整深度顺序。
- 第三步：输出仅包含最底层矩形的网格——在一个与输入同尺寸的黑色背景画布上，绘制最底层矩形的完整形状（使用其原始颜色），不绘制其他任何矩形。

Key insight: 解题者需要逆向推理被遮挡的矩形边界（从可见碎片恢复完整矩形），再从多对遮挡关系中推导出全局深度排序，最终只提取最深层的那个矩形——三步推理分别考验形状补全能力、遮挡关系推导能力和选择性输出能力。
</description>
</new_puzzle>
