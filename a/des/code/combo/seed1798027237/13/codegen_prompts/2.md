将网格中的彩色路径按交叉点拆分为独立线段，然后根据线段长度对线段重新着色。

Input structure
- 背景为 black。网格中有若干条由不同颜色绘制的单像素宽直线段（水平或垂直），它们会在某些像素处交叉。
- 交叉点处的像素颜色为 red，标记两条线段的相交位置。
- 每条线段由一种非 red、非 black 的纯色绘制（如 blue、green、yellow 等），且在交叉点处被 red 像素打断。

Rule
- 将每个 red 交叉点像素视为分隔符，把所有线段在交叉点处切断，得到一组独立的子线段。每条子线段是从一个端点（线段原始端点或 red 交叉点的邻接像素）到另一个端点的连续同色水平或垂直像素序列。
- 统计所有子线段的像素长度，对所有子线段按长度从短到长排序。
- 建立长度排名与颜色的映射：找出输入中所有出现过的非 black、非 red 颜色，按其在输入中首次出现的位置（从左到右、从上到下扫描）排序，得到颜色序列 C1, C2, C3, ...
- 将长度排名第 k 的子线段（若有并列则保持原色不变）重新着色为 Ck。
- red 交叉点像素保持 red 不变。

Key insight
- 交叉点不仅是视觉标记，更是将连续线段拆分为可度量单元的分隔符；解题者需要先完成"拆分"再完成"按长度重排颜色"，两步推理缺一不可。
