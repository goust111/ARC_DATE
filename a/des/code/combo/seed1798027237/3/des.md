<description>
根据边框缺口的朝向选择对应的图例染色方案，将封闭区域内的对象重新着色。

Input structure:
- 背景为黑色（Black）。
- 网格中散布着若干由同一种前景色（如 Grey）绘制的矩形边框（一像素宽的空心矩形），每个边框的某一条边上恰好有一个一像素宽的缺口。
- 每个矩形边框内部包含一个或多个由不同颜色组成的小型对象（连通分量），这些对象的颜色各不相同。
- 网格的四条外边界（上、下、左、右）各自紧贴着一个两像素高（或宽）的色条作为图例：上边界图例对应缺口朝上的边框，下边界对应缺口朝下，左边界对应缺口朝左，右边界对应缺口朝右。每个图例色条包含两种颜色交替排列，分别代表"保留色"和"替换色"。

Rule:
- 第一层推理：确定每个矩形边框缺口所在的方向（上、下、左、右）。
- 第二层推理：根据缺口方向，找到网格对应外边界上的图例色条，从中读取"保留色"和"替换色"的映射关系——图例色条中从左到右（或从上到下）每两个像素为一组，第一个像素是保留色，第二个像素是替换色。
- 第三层操作：对该边框内部的每个对象，若对象颜色等于图例中的"保留色"，则不变；若对象颜色等于图例中的"替换色"，则将其重新着色为同组的"保留色"。所有不在任何映射中出现的颜色保持不变。边框本身和背景不变。

Key insight:
缺口方向不是装饰性特征，而是选择四套染色规则之一的索引键；解题者必须先发现缺口→边界图例的对应关系，再从图例中解码颜色映射，最后才能应用重着色——三步推理环环相扣。
</description>

<description>
将网格中散落的彩色碎片视为拼图块，根据碎片内部孔洞数量的匹配关系将碎片两两配对，然后将填充块嵌入底板的孔洞中拼合成完整的矩形。

Input structure:
- 背景为黑色（Black）。
- 网格中散布着偶数个不规则形状的彩色连通分量（拼图碎片），每个碎片由单一颜色组成，颜色可以重复。
- 每个碎片内部可能包含零个或多个黑色孔洞（被碎片像素完全包围的黑色连通区域）。
- 碎片的颜色恰好成对出现（例如两个 Red 碎片、两个 Blue 碎片等）。

Rule:
- 第一层推理：计算每个碎片内部的孔洞数量。在同一颜色的两个碎片中，孔洞数量较多的碎片称为"底板"，孔洞数量较少的称为"填充块"。
- 第二层推理：将"填充块"平移（不旋转、不翻转），精确嵌入"底板"的孔洞区域中。填充块的形状恰好等于底板中某些孔洞的联合形状，嵌入后底板的所有孔洞被完全填满。
- 输出仅包含拼合完成后的各个矩形（每个配对拼合后恰好形成一个实心矩形），按照"底板"在输入中的原始位置放置，"填充块"从原位置消失。

Key insight:
颜色相同的两个碎片不是简单的重复，而是互补的拼合对；孔洞数量的多少决定了谁是底板、谁是嵌入块，而非依赖碎片面积或位置。
</description>

<description>
沿对象的对称轴将其一分为二，保留与邻近锚点颜色匹配的那一半，擦除另一半。

Input structure:
- 背景为黑色（Black）。
- 网格中有若干由多种颜色组成的对称对象：每个对象具有恰好一条对称轴（水平或垂直），对称轴两侧的形状完全镜像，但颜色不同——一侧为颜色 A，另一侧为颜色 B。对称轴上的像素可以是 A 或 B 中的任一颜色。
- 在每个对象附近（上下左右四个方向之一，距对象边界恰好一像素），有一个单独的"锚点"像素，颜色为 A 或 B 之一。

Rule:
- 第一层推理：找到每个对象的对称轴（水平或垂直），并识别对称轴两侧分别使用的两种颜色。
- 第二层推理：找到该对象附近的锚点像素，读取其颜色。
- 操作：保留对象中与锚点颜色相同的那一半（包括对称轴上该颜色的像素），将另一半擦除为背景色。锚点像素本身也从输出中擦除。

Key insight:
对象的对称性不是输出的目标形态，而是定义"切割线"的线索；锚点颜色决定保留哪一半，这要求解题者同时识别对称结构和锚点的选择功能——两个非显然步骤缺一不可。
</description>

<description>
根据封闭围栏内"种子"像素的颜色，从围栏缺口处向外生长出与围栏对应边等长的射线。

Input structure:
- 背景为黑色（Black）。
- 网格中有若干由 Grey 像素构成的封闭矩形围栏（一像素宽的空心矩形框），每个围栏的四条边上各有零个或一个单像素缺口（即该边某处缺少一个 Grey 像素）。
- 每个围栏内部恰好有一个非黑色、非 Grey 的"种子"单像素，颜色各不相同（如 Red、Blue、Green 等）。
- 种子像素位于围栏内部的某个位置，不一定在中心。

Rule:
- 第一层推理：识别每个围栏的所有缺口位置及缺口所在的边（上、下、左、右）。
- 第二层推理：确定缺口所在边的长度（即该边在围栏中的像素跨度，含两端角像素）。
- 第三层操作：从每个缺口出发，沿缺口朝外的方向（上边缺口向上、下边缺口向下、左边缺口向左、右边缺口向右）画一条射线，射线长度等于该边的长度，射线颜色等于围栏内种子像素的颜色。射线不覆盖已有的非背景像素；若射线遇到网格边界则截断。围栏和种子像素保持不变。

Key insight:
缺口不仅是射线的发射口，缺口所在边的几何长度还编码了射线的长度——解题者需要发现"边长→射线长"这一非显然的映射关系，同时种子颜色与围栏颜色的分离迫使解题者建立"内部种子决定外部射线颜色"的跨区域关联。
</description>

<description>
将网格中由分隔线划分的子区域视为"容器"，根据容器边框上彩色标记的颜色和数量，对容器内的对象执行对应类型和次数的空间变换。

Input structure:
- 背景为黑色（Black）。
- 一组 Maroon 色的完整横线和竖线将网格分割为若干矩形子区域（容器），类似棋盘格。
- 每个容器内部包含一个由单一前景色绘制的小型非对称对象（形状各异，便于观察变换效果）。
- 在每个容器的 Maroon 边框上，恰好有一到三个彩色标记像素（颜色为 Red、Blue 或 Green 之一，每个容器的标记颜色相同），这些标记替换了边框上对应位置的 Maroon 像素。

Rule:
- 第一层推理：确定每个容器边框上标记像素的颜色和数量。颜色决定变换类型：Red 表示顺时针旋转 90 度，Blue 表示沿垂直轴左右翻转，Green 表示沿水平轴上下翻转。
- 第二层推理：标记的数量决定该变换执行的次数（1 个标记 = 执行 1 次，2 个 = 执行 2 次，3 个 = 执行 3 次）。多次执行同一变换会产生不同效果（例如顺时针旋转 90 度执行 2 次等于旋转 180 度，左右翻转执行 2 次等于恢复原状）。
- 操作：对容器内的对象执行确定的变换，将变换后的对象放回容器中心位置。Maroon 分隔线和标记像素保持不变。

Key insight:
边框上的彩色标记同时编码了两个独立维度的信息——颜色编码变换类型，数量编码执行次数——解题者必须同时破解这两层编码才能正确推断变换结果，而对象的非对称性是验证推理正确性的关键线索。
</description>

<description>
将散落的路径片段按端点方向互相对准后首尾相接，形成一条从起点标记到终点标记的连续折线路径。

Input structure:
- 背景为黑色（Black）。
- 网格中有两个特殊的单像素标记：一个 Yellow 像素作为起点，一个 Orange 像素作为终点。
- 网格中散布着若干条短折线段（每条由 2 至 5 个像素组成的四连通路径片段），每条折线段使用不同的颜色（从 Red、Blue、Green、Azure、Magenta 等颜色中选取，每条颜色不同）。
- 每条折线段的两个端点（路径的首尾像素，即只有一个四连通邻居的像素）各自有一个延伸方向——即从倒数第二个像素指向端点像素的方向（上、下、左、右之一）。

Rule:
- 第一层推理：确定连接顺序。起点标记 Yellow 的某个四邻方向上恰好能对准某条折线段的某个端点的延伸方向（即该端点的延伸方向指向起点），这条就是第一段。第一段的另一个端点的延伸方向又指向下一段的某个端点，依此类推形成链式匹配，直到最后一段的末端端点指向终点标记 Orange。
- 第二层推理：将每条折线段平移到正确位置，使相邻两段的对准端点之间恰好相隔一个像素。
- 操作：在相邻片段之间的单像素间隙处填入 Grey 像素作为连接符。起点和终点标记保留在原位，各折线段保留原始颜色。

Key insight:
折线段的连接顺序不能仅靠空间位置判断，而必须通过端点的延伸方向互相"对准"来确定——类似拼接铁轨，每段轨道的出口方向必须与下一段的入口方向一致，构成方向匹配的链式推理。
</description>

<description>
识别网格中重叠放置的多层矩形框架，根据层序图例还原被遮挡部分，使每层框架完整显示。

Input structure:
- 背景为黑色（Black）。
- 网格中呈现的是若干个矩形框架层叠后的合成结果。每个框架是一个一像素宽的空心矩形边框，每层使用不同的颜色（如 Red、Blue、Green、Azure 等）。
- 框架之间存在部分重叠。在重叠区域，只显示最上层框架的颜色（完全遮挡下层）。
- 在网格的最底行有一行单像素的颜色序列作为"层序图例"，从左到右表示从最底层到最顶层的颜色顺序，图例像素之间以黑色间隔。

Rule:
- 第一层推理：从层序图例中读取各层颜色及其堆叠顺序（左侧为底层，右侧为顶层）。
- 第二层推理：从合成图像中分离各层。最顶层的框架可完整看到其全部像素；次顶层的框架被顶层部分遮挡，需要根据其可见部分（至少能看到部分边框线段）推断出完整矩形框架的四个角坐标；依此类推直到最底层。关键约束：每层都是一个完整的一像素宽矩形边框。
- 操作：输出网格移除最底行的层序图例，将所有被遮挡的框架像素补全——即每个框架层的完整矩形边框都显示出来。重叠区域仍显示层序最高（最顶层）的颜色。

Key insight:
输入看似是一幅平面图像，但实际编码了三维的层叠信息；层序图例是解码遮挡关系的钥匙，而"矩形边框"的结构约束使得即使只看到部分边框片段，也能唯一确定整个框架的位置和大小——解题者需要同时运用层序推理和几何补全两种能力。
</description>
</new_puzzle>
