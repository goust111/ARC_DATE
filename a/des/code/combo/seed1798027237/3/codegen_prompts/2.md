将网格中散落的彩色碎片视为拼图块，根据碎片内部孔洞数量的匹配关系将碎片两两配对，然后将填充块嵌入底板的孔洞中拼合成完整的矩形。

Input structure:
- 背景为黑色（Black）。
- 网格中散布着偶数个不规则形状的彩色连通分量（拼图碎片），每个碎片由单一颜色组成，颜色可以重复。
- 每个碎片内部可能包含零个或多个黑色孔洞（被碎片像素完全包围的黑色连通区域）。
- 碎片的颜色恰好成对出现（例如两个 Red 碎片、两个 Blue 碎片等）。

Rule:
- 第一层推理：计算每个碎片内部的孔洞数量。在同一颜色的两个碎片中，孔洞数量较多的碎片称为"底板"，孔洞数量较少的称为"填充块"。
- 第二层推理：将"填充块"平移（不旋转、不翻转），精确嵌入"底板"的孔洞区域中。填充块的形状恰好等于底板中某些孔洞的联合形状，嵌入后底板的所有孔洞被完全填满。
- 输出仅包含拼合完成后的各个矩形（每个配对拼合后恰好形成一个实心矩形），按照"底板"在输入中的原始位置放置，"填充块"从原位置消失。

Key insight:
颜色相同的两个碎片不是简单的重复，而是互补的拼合对；孔洞数量的多少决定了谁是底板、谁是嵌入块，而非依赖碎片面积或位置。

## 实现要求

1. `main(grid)` 必须实现新题描述中的确定性转换规则，不能只识别 `generate_input()` 的固定模板。
2. `generate_input()` 必须随机生成多样样例，不能固定死。随机维度应覆盖：网格大小、对象数量、位置、颜色、方向、形状参数或关键分支。
3. 生成器必须保证输入满足 `main()` 的隐式假设：对象不重叠、不越界、特殊标记唯一或可区分、匹配关系无歧义、关键分支出现概率相同。
4. 禁止把 ARC 颜色 id 当作人类不可见的数值语义参与排序、大小比较或隐藏映射。颜色变化必须有可见结构线索。注意颜色亮度等也是不可见信息，若描述中出现违规的颜色id或者亮度，可自行使用少量的固定颜色替代，但注意生成时要在三个以内输入输出网格中对所有变换100%覆盖度。

6. 若规则有多个分支，生成器不能长期固定成一个分支；应让分支在随机样例中合理出现。
7. 代码风格参考 `ARC_code`：使用 `numpy`，必要时使用本地 helper，但目标文件应能被 `SourceFileLoader` 直接加载。
