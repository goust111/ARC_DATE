Input structure:
- 背景为黑色（Black）。
- 一组 Maroon 色的完整横线和竖线将网格分割为若干矩形子区域（容器），类似棋盘格。
- 每个容器内部包含一个由单一前景色绘制的小型非对称对象（形状各异，便于观察变换效果）。
- 在每个容器的 Maroon 边框上，恰好有一到三个彩色标记像素（颜色为 Red、Blue 或 Green 之一，每个容器的标记颜色相同），这些标记替换了边框上对应位置的 Maroon 像素。

Rule:
- 第一层推理：确定每个容器边框上标记像素的颜色和数量。颜色决定变换类型：Red 表示顺时针旋转 90 度，Blue 表示沿垂直轴左右翻转，Green 表示沿水平轴上下翻转。
- 第二层推理：标记的数量决定该变换执行的次数（1 个标记 = 执行 1 次，2 个 = 执行 2 次，3 个 = 执行 3 次）。多次执行同一变换会产生不同效果（例如顺时针旋转 90 度执行 2 次等于旋转 180 度，左右翻转执行 2 次等于恢复原状）。
- 操作：对容器内的对象执行确定的变换，将变换后的对象放回容器中心位置。Maroon 分隔线和标记像素保持不变。

Key insight:
边框上的彩色标记同时编码了两个独立维度的信息——颜色编码变换类型，数量编码执行次数——解题者必须同时破解这两层编码才能正确推断变换结果，而对象的非对称性是验证推理正确性的关键线索。
