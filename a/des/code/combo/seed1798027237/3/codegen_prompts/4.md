根据封闭围栏内"种子"像素的颜色，从围栏缺口处向外生长出与围栏对应边等长的射线。

Input structure:
- 背景为黑色（Black）。
- 网格中有若干由 Grey 像素构成的封闭矩形围栏（一像素宽的空心矩形框），每个围栏的四条边上各有零个或一个单像素缺口（即该边某处缺少一个 Grey 像素）。
- 每个围栏内部恰好有一个非黑色、非 Grey 的"种子"单像素，颜色各不相同（如 Red、Blue、Green 等）。
- 种子像素位于围栏内部的某个位置，不一定在中心。

Rule:
- 第一层推理：识别每个围栏的所有缺口位置及缺口所在的边（上、下、左、右）。
- 第二层推理：确定缺口所在边的长度（即该边在围栏中的像素跨度，含两端角像素）。
- 第三层操作：从每个缺口出发，沿缺口朝外的方向（上边缺口向上、下边缺口向下、左边缺口向左、右边缺口向右）画一条射线，射线长度等于该边的长度，射线颜色等于围栏内种子像素的颜色。射线不覆盖已有的非背景像素；若射线遇到网格边界则截断。围栏和种子像素保持不变。

Key insight:
缺口不仅是射线的发射口，缺口所在边的几何长度还编码了射线的长度——解题者需要发现"边长→射线长"这一非显然的映射关系，同时种子颜色与围栏颜色的分离迫使解题者建立"内部种子决定外部射线颜色"的跨区域关联。
