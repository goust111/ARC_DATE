  - 在孔洞区域内从边界向内绘制 N 层同心矩形环，使用精灵颜色；剩余内部像素保持背景色。

- `Key insight`：精灵不仅通过形状匹配选择填充哪个孔洞，其像素数量还隐式编码了孔洞内同心环的层数——形状匹配与数量编码是两层独立的非显然推理。

  - 找到从底层到顶层的唯一全序。
  - 输出正方形网格边长为 2*颜色数-1，从外到内按底层到顶层顺序绘制嵌套方框环，顶层为中心像素。
- `Key insight`：输出不是输入场景的裁剪，而是将推断出的遮挡层级重新编码为全新的几何结构——嵌套环。

<new_puzzle>
- `description`：根据每个分区内两个标记像素的相对位置关系确定翻转类型，对区内图案执行对应的轴对称变换。
- `Input structure`：背景为主色。分隔色形成完整行和列，将网格划分为等大矩形区域。每个区域内有一个彩色小图案和恰好两个相同颜色的标记像素（标记色与图案色不同）。两标记可同行、同列或对角排列。
- `Rule`：
  - 两标记同行 → 区内图案左右翻转。
  - 两标记同列 → 区内图案上下翻转。
  - 两标记对角 → 区内图案旋转 180 度。
  - 变换后移除标记像素，保留分隔线。
- `Key insight`：标记像素的空间排列（同行/同列/对角）编码了对同区域图案的变换类型，而非标记颜色或位置本身。
</new_puzzle>

<new_puzzle>
- `description`：通过跨象限颜色比对确定每个象限缺失的颜色，再从其他象限中读取该颜色的位置模式来补全。
- `Input structure`：背景为主色。完整分隔行和分隔列将网格分为四个等大象限。每象限含一组彩色像素，颜色集合几乎相同，但各象限恰好缺少一种不同颜色，缺失位置留为背景色。
- `Rule`：
  - 统计四象限中出现过的完整颜色集合。
  - 对每个象限找出缺失的颜色。
  - 从拥有该颜色的其他象限读取其局部坐标位置，将本象限对应背景像素替换为该颜色。
  - 保持分隔线不变。
- `Key insight`：需要两步推理——先跨象限比对确定缺什么颜色，再跨象限读取该颜色的空间模式来确定补全位置。
</new_puzzle>

- `Key insight`：前景矩形是遮挡物而非保留对象；核心任务是从不完整样本重建底层瓦片，矩形颜色仅作为边框位置标记保留。
