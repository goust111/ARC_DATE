<new_puzzle>
根据嵌套框架的层数确定填充颜色，再按框架开口方向向外延伸色带。

Input structure:
- 背景为 black。网格中散布若干由彩色像素构成的矩形框架（边框宽度为 1 像素）。
- 每个框架恰好在一条边上有一个连续缺口（缺口宽度 >= 2 像素），缺口处边框像素被擦除为 black。
- 框架可以嵌套：较小的框架完全位于较大框架的内部。没有框架部分重叠，只有完全包含或完全不相交两种关系。
- 所有框架使用同一种前景色（如 grey），在输入中无法通过颜色区分层级。

Rule:
- 第一层（确定嵌套深度与对应颜色）：计算每个框架的嵌套深度——最外层深度为 1，被一层框架包含则深度为 2，以此类推。深度 1 对应 blue，深度 2 对应 red，深度 3 对应 green，深度 4 对应 yellow（题目中最大嵌套深度不超过 4）。将每个框架的边框像素重新着色为其对应的深度颜色。
- 第二层（根据缺口方向生成色带）：识别每个框架缺口所在的边（上 / 下 / 左 / 右）。从缺口的每个像素位置出发，沿缺口朝外的方向（上边缺口向上，下边缺口向下，左边缺口向左，右边缺口向右）逐格绘制该框架的深度颜色，直到到达网格边界或遇到任何非 black 像素为止。色带宽度等于缺口宽度，每条射线独立停止。

Key insight:
框架本身在输入中颜色相同，解题者必须先通过空间包含关系推断嵌套层级来确定颜色，然后再利用缺口方向生成向外的射线色带——两步推理缺一不可。
</new_puzzle>

<new_puzzle>
将散落的单色碎片拼回被遮挡区域，拼接顺序由碎片与遮挡区之间的唯一行列对齐关系决定。

Input structure:
- 背景为 black。网格中有一个大型的彩色周期纹理区域（由某个小 tile 按行列平铺而成），其中若干矩形子区域被统一涂成了 grey，形成"遮挡块"。
- 在纹理区域外部散落着若干小型单色矩形碎片（每个碎片颜色各不相同且与纹理中出现的颜色均不同），碎片数量与遮挡块数量相同。
- 每个碎片的尺寸恰好与某一个遮挡块相同（宽高完全匹配），且不同遮挡块的尺寸互不相同，因此碎片与遮挡块存在按尺寸的一一配对。

Rule:
- 第一层（尺寸配对）：将每个碎片按宽高与唯一匹配的遮挡块配对。
- 第二层（纹理恢复与标记）：利用纹理区域中未被遮挡的可见像素推断出完整的周期 tile。用该 tile 恢复每个遮挡块下方原本的纹理图案。然后在恢复后的区域外围（即原遮挡块的边界像素的外侧一圈，仍在网格范围内的 black 像素）涂上与之配对的碎片的颜色，形成一圈单像素宽的彩色边框。碎片本身从原位置擦除为 black。

Key insight:
解题者需要先通过尺寸匹配建立碎片与遮挡块的对应，再独立推断周期纹理来恢复被遮挡内容，最后用碎片颜色作为边框标记——碎片的作用不是填入遮挡区，而是为恢复区提供标识颜色。
</new_puzzle>

<new_puzzle>
根据封闭区域内种子像素的颜色组合查找色板字典，用查得的颜色填充该区域。

Input structure:
- 背景为 black。网格被若干条 maroon 色的单像素宽直线（水平或垂直贯穿整个网格）分割成多个矩形封闭区域。
- 网格的一个角落（如左上角）有一个特殊的"色板字典"区域，该区域也由 maroon 线分隔成若干小格。每个小格内恰好有两个不同颜色的像素（称为"键"）和一个第三种颜色填充整个小格剩余空间（称为"值色"）。键的两个颜色唯一标识一个值色。
- 其余的大封闭区域中，每个区域恰好包含两个不同颜色的单像素点（种子像素），其余均为 black。

Rule:
- 第一层（解读色板字典）：在字典区域中，为每个小格提取其两个键颜色（无序对）和对应的值色，建立映射表。
- 第二层（匹配与填充）：对于字典区域之外的每个封闭区域，读取其中两个种子像素的颜色，组成无序对，在映射表中查找对应的值色。将该区域内所有 black 像素填充为该值色，保留种子像素和 maroon 分隔线不变。

Key insight:
分隔线既定义了字典的格子也定义了待填充区域；种子像素的颜色组合不是简单的"哪个颜色"而是"哪两个颜色的配对"，必须在字典中做组合查表才能确定填充色。
</new_puzzle>

<new_puzzle>
将每个对象按其内部标记像素指定的旋转角度旋转后，放置到网格中与标记颜色对应的锚点位置。

Input structure:
- 背景为 azure。网格中散布若干多色的小型图案对象（每个对象是一个紧凑的 4-连通多色块，尺寸不超过 5x5）。
- 每个对象内部恰好有一个像素的颜色与对象其余像素的颜色都不同，该像素称为"标记像素"。标记像素在对象 bounding box 内的相对位置编码旋转信息：若标记在 bounding box 的上边中部区域则不旋转（0 度），在右边中部区域则顺时针旋转 90 度，在下边中部区域则旋转 180 度，在左边中部区域则逆时针旋转 90 度（即顺时针 270 度）。具体判断方式：将 bounding box 按对角线分成上、右、下、左四个三角形区域，标记像素落入哪个三角形就对应哪个方向。
- 网格边缘（第一行、最后一行、第一列、最后一列）上分布着若干单独的彩色锚点像素，每个锚点的颜色与恰好一个对象的标记像素颜色相同。

Rule:
- 第一层（旋转角度推断）：对每个对象，根据标记像素在 bounding box 中的相对位置（上/右/下/左三角区域）确定旋转角度。
- 第二层（颜色匹配与放置）：将标记像素颜色与网格边缘的锚点颜色匹配，确定目标位置。将对象按推断的角度旋转后，以锚点为基准（锚点对齐到旋转后对象的标记像素位置）放置到网格中。放置时覆盖背景像素，原位置的对象擦除为 azure。

Key insight:
标记像素承担双重角色——其颜色决定对象去往哪个锚点，其在对象内的空间位置决定旋转角度。解题者必须同时解读颜色匹配和空间位置编码两套信息。
</new_puzzle>

<new_puzzle>
根据路径沿途经过的彩色关卡门的颜色顺序，对路径终点处的目标对象进行逐步变色渲染。

Input structure:
- 背景为 black。网格中有若干用 grey 像素绘制的单像素宽连通路径（路径不分叉，呈蛇形或折线形），每条路径连接一个起点标记和一个终点对象。
- 起点标记：路径一端有一个 2x2 的 white 方块，标识路径起点。
- 终点对象：路径另一端连接一个由 grey 像素构成的小型填充形状（如矩形、L形等，面积 >= 4 像素）。
- 关卡门：路径途中，某些位置的 grey 路径像素被替换为彩色像素（非 black、非 grey、非 white），这些彩色像素称为"关卡门"。每条路径上可能有 1 到 3 个关卡门，每个关卡门占据路径上的一个像素。

Rule:
- 第一层（路径追踪与颜色序列提取）：从 white 起点方块出发，沿 grey 路径向终点对象行进。按经过的先后顺序记录沿途所有关卡门的颜色，得到一个有序颜色列表。
- 第二层（终点对象的分层着色）：将终点对象视为一个填充形状，从其外轮廓向内逐层剥离（类似洋葱层，每层是当前形状的最外圈像素）。第一层外壳涂上颜色列表的第一个颜色，第二层外壳涂上第二个颜色，依此类推。如果形状的层数多于颜色列表长度，则多余的内层保持 grey 不变；如果颜色列表多于层数，多余的颜色忽略。路径本身（包含关卡门像素）保持不变，white 起点保持不变。

Key insight:
关卡门的空间位置决定了颜色的出现顺序（必须沿路径追踪才能确定先后），而终点对象的几何形状决定了分层方式——路径上的时序信息被转化为终点对象上的空间分层信息，这一对应关系是解题的核心。
</new_puzzle>
