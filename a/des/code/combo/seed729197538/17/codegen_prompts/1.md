根据嵌套框架的层数确定填充颜色，再按框架开口方向向外延伸色带。

Input structure:
- 背景为 black。网格中散布若干由彩色像素构成的矩形框架（边框宽度为 1 像素）。
- 每个框架恰好在一条边上有一个连续缺口（缺口宽度 >= 2 像素），缺口处边框像素被擦除为 black。
- 框架可以嵌套：较小的框架完全位于较大框架的内部。没有框架部分重叠，只有完全包含或完全不相交两种关系。
- 所有框架使用同一种前景色（如 grey），在输入中无法通过颜色区分层级。

Rule:
- 第一层（确定嵌套深度与对应颜色）：计算每个框架的嵌套深度——最外层深度为 1，被一层框架包含则深度为 2，以此类推。深度 1 对应 blue，深度 2 对应 red，深度 3 对应 green，深度 4 对应 yellow（题目中最大嵌套深度不超过 4）。将每个框架的边框像素重新着色为其对应的深度颜色。
- 第二层（根据缺口方向生成色带）：识别每个框架缺口所在的边（上 / 下 / 左 / 右）。从缺口的每个像素位置出发，沿缺口朝外的方向（上边缺口向上，下边缺口向下，左边缺口向左，右边缺口向右）逐格绘制该框架的深度颜色，直到到达网格边界或遇到任何非 black 像素为止。色带宽度等于缺口宽度，每条射线独立停止。

Key insight:
框架本身在输入中颜色相同，解题者必须先通过空间包含关系推断嵌套层级来确定颜色，然后再利用缺口方向生成向外的射线色带——两步推理缺一不可。
