- `description`：将网格中的彩色"种子"像素沿其所在通道生长为线段，生长方向由种子与通道壁的相对位置决定，生长长度由同通道内的其他种子数量决定。

- `Input structure`：背景为 Black。网格中有若干条由 Grey 像素构成的水平或垂直"通道"（宽度为3像素、长度不等的矩形条带）。每条通道内部散布着若干单像素的彩色"种子"（Red、Blue、Green、Yellow 等），种子总是位于通道的中轴线上。通道之间互不连通，且不与网格边缘相接。

- `Rule`：
  1. 对每条通道，数出其内部种子的总数 N。
  2. 对每个种子，判断它离通道的哪一端更近（对于水平通道是左端或右端，对于垂直通道是上端或下端）。种子沿远离较近端的方向生长（即朝向较远端的方向）。若种子恰好位于通道正中央，则朝通道延伸方向的正方向（水平通道向右，垂直通道向下）生长。
  3. 种子从自身位置开始，沿确定的方向在中轴线上生长 N 个像素（不含种子自身），使用种子自身的颜色。若生长遇到通道尽头则在尽头停止。
  4. 通道的 Grey 壁、背景、以及种子原始像素均保持不变。

- `Key insight`：生长方向需要通过种子在通道中的偏心位置来推断（靠近哪端就背离哪端生长），而生长长度则编码在同一通道内种子的总数中——这两条规则分别需要独立归纳，且"数量决定长度"这一关联并不显然。
