- `Input structure`：背景为 Azure。网格左半部分是一个由 Grey 边框围成的大矩形"组装图纸"，图纸内部背景为 Azure，其中有若干个矩形空槽（由 Azure 背景构成）。每个空槽的某一个角上有一个单像素标记，标记颜色为 Red、Green、Yellow、Magenta 四种之一，分别代表 0度、90度顺时针、180度、270度顺时针旋转。网格右半部分散布着若干个彩色形状碎片（每个碎片使用独特的非标记色前景色，如 Blue、Orange、Maroon 等），碎片大小各异。

- `Rule`：
  1. 对每个组装图纸中的空槽，测量其矩形尺寸（宽 x 高）。
  2. 读取该空槽角上的颜色标记，确定旋转角度（Red=0度，Green=90度顺时针，Yellow=180度，Magenta=270度顺时针）。
  3. 在右侧碎片中，找到唯一一个碎片，使得将其按标记指定的角度旋转后，其边界框尺寸恰好等于空槽尺寸。
  4. 将该碎片旋转后放入空槽中，碎片颜色保持不变。标记像素被碎片覆盖（若碎片该角位置有像素）或保持标记色（若碎片该角位置为空）。
  5. 输出仅包含组装图纸区域（含 Grey 边框），右侧碎片区域被裁剪掉。

- `Key insight`：解题者需要先发现空槽角落的彩色标记不是装饰而是旋转指令的编码，然后理解匹配碎片时必须先将碎片旋转后再比较尺寸——这意味着一个看起来是"宽>高"的碎片可能对应一个"高>宽"的空槽（经90度旋转后匹配）。旋转编码的发现和旋转后匹配这两步推理缺一不可。
