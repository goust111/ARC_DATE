网格中有若干由不同颜色绘制的封闭围栏，每个围栏内部有一个小型"钥匙"图案；根据钥匙图案的朝向找到围栏上的对应出口边，然后将围栏内部的所有内容沿该方向平移到围栏外部。

Input structure
- 背景为黑色。
- 若干个由单一颜色绘制的 1 像素厚封闭矩形围栏，每个围栏颜色不同（如 red、blue、green）。
- 每个围栏的某一条边上有一个 2 像素宽的缺口（该边上连续 2 个像素被擦除为背景色）。
- 每个围栏内部有一个由 azure 色绘制的小型"L"形图案（3 个像素组成的直角形状）。L 形的开口方向朝向上、下、左、右四个方向之一。
- 每个围栏内部还可能有其他颜色的装饰像素（1-3 个像素的小色块）。

Rule
- 对每个围栏，观察其内部 L 形图案的开口方向。
- 找到围栏上缺口所在的边。如果 L 形的开口方向与缺口所在边的方向一致（例如 L 形开口朝右且缺口在右边），则该围栏为"激活"状态。
- 对于激活的围栏：将围栏内部的所有内容（L 形图案和装饰像素）沿 L 形开口方向平移出围栏，平移距离等于围栏在该方向上的内部宽度或高度，使得内容完整地出现在围栏外侧。围栏内部清空为背景色。围栏框架（包括缺口）保持不变。
- 对于未激活的围栏（L 形开口方向与缺口方向不一致）：整个围栏及其内容保持不变。

Key insight
- 解题者需要执行三层推理：(1) 识别 L 形图案的开口方向作为"指令"；(2) 判断该指令是否与围栏缺口匹配来决定是否激活；(3) 对激活的围栏执行方向性平移。缺口和 L 形都单独可见，但只有它们的一致性才触发变换——这种"条件匹配触发"机制增加了规则的隐蔽性。
