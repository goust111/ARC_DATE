Input structure

- 存在若干对单元格，它们内部的图案形状互补——即将一个图案旋转 180 度后与另一个图案拼合，恰好填满整个单元格内部区域（无重叠无空隙）。

Rule

- 无法配对的干扰图案保持原样不变。
- 分隔线保持不变。

Key insight
- 解题者需要在视觉上执行"心理旋转"来判断两个图案是否互补，这不是简单的形状匹配，而是需要想象 180 度旋转后的拼合。第二层推理在于：合并结果放在哪个单元格取决于位置排序规则，而非图案本身的属性。
