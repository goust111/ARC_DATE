Input structure
- 背景为黑色。
- 网格中有若干个矩形对象，每个矩形由 1 像素厚的彩色外框和内部的另一种颜色填充组成（例如外框 red、内部 blue）。不同矩形的外框颜色各不相同，但内部填充色可以重复。
- 这些矩形在空间上部分重叠。在输入中，重叠区域的颜色由某种遮挡顺序决定（某些矩形"在上面"覆盖了其他矩形）。
- 在网格的某个角落（如左上角）有一个小型"图例条"：一行或一列中排列着若干不同颜色的单像素点，这些颜色恰好是所有矩形外框使用的颜色。图例条中颜色的排列顺序定义了优先级（靠近角落的优先级最低，远离角落的优先级最高）。
- 图例条与矩形对象在空间上不重叠。

Rule
- 读取图例条中的颜色顺序，建立外框颜色的优先级排序。
- 识别输入中的所有矩形（通过非重叠部分的外框和内部填充推断每个矩形的完整位置和大小）。
- 将所有矩形按照图例条定义的优先级重新绘制——优先级最高的矩形最后绘制（在最上层），优先级最低的最先绘制（在最底层）。
- 图例条本身在输出中保持不变。

Key insight
- 输入中的遮挡顺序是"旧的"，解题者需要发现角落的图例条编码了"正确的"优先级顺序，并据此重新渲染所有矩形的重叠关系。关键难点在于：(1) 从部分被遮挡的输入中还原每个矩形的完整边界和大小；(2) 理解图例条的排列方向与优先级的对应关系；(3) 按新顺序重绘所有矩形。这是三层需要主动推理的结构。
