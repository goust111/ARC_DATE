根据框架内部的缺口位置确定投射方向，再将框架外的彩色精灵沿该方向滑入框架内部并填充到对侧内壁。

Input structure
- 背景为黑色。
- 网格中有若干单像素厚的彩色矩形框架（每个框架用一种颜色绘制，如 red、blue 等），每个框架的四条边中恰好有一条边存在一个连续缺口（即该边上有若干连续像素被擦除为背景色）。
- 每个框架的外侧（与缺口同侧方向）附近有一个由另一种颜色构成的小型精灵（形状不规则，3-6 像素的 4-连通区域）。
- 精灵的颜色与其对应框架颜色不同，但每个精灵恰好只与一个框架配对（通过空间邻近性：精灵与该框架缺口边的距离最近）。

Rule
- 对每个框架，找到其缺口所在的边（上、下、左、右）。
- 将与该框架配对的精灵沿缺口朝向的方向（即从缺口外侧向框架内部）平移，直到精灵的边界像素接触到框架的对侧内壁。
- 精灵保持原始形状和颜色不变，放置在对侧内壁贴靠的位置。
- 原位置的精灵像素擦除为背景色。
- 框架本身（包括缺口）保持不变。

Key insight
- 缺口不是损坏，而是"入口"——它同时编码了精灵的滑入方向和目标停靠位置（对侧内壁）。解题者需要先识别每个框架上缺口的朝向，然后理解精灵是穿过缺口滑到对面的。
