<description>
根据框架内部的缺口位置确定投射方向，再将框架外的彩色精灵沿该方向滑入框架内部并填充到对侧内壁。

Input structure
- 背景为黑色。
- 网格中有若干单像素厚的彩色矩形框架（每个框架用一种颜色绘制，如 red、blue 等），每个框架的四条边中恰好有一条边存在一个连续缺口（即该边上有若干连续像素被擦除为背景色）。
- 每个框架的外侧（与缺口同侧方向）附近有一个由另一种颜色构成的小型精灵（形状不规则，3-6 像素的 4-连通区域）。
- 精灵的颜色与其对应框架颜色不同，但每个精灵恰好只与一个框架配对（通过空间邻近性：精灵与该框架缺口边的距离最近）。

Rule
- 对每个框架，找到其缺口所在的边（上、下、左、右）。
- 将与该框架配对的精灵沿缺口朝向的方向（即从缺口外侧向框架内部）平移，直到精灵的边界像素接触到框架的对侧内壁。
- 精灵保持原始形状和颜色不变，放置在对侧内壁贴靠的位置。
- 原位置的精灵像素擦除为背景色。
- 框架本身（包括缺口）保持不变。

Key insight
- 缺口不是损坏，而是"入口"——它同时编码了精灵的滑入方向和目标停靠位置（对侧内壁）。解题者需要先识别每个框架上缺口的朝向，然后理解精灵是穿过缺口滑到对面的。
</description>

<new_puzzle>
<description>
将网格中散布的同色像素对视为"线段端点"，根据每对端点连线所穿过的彩色区域的颜色来决定该连线应当被绘制成什么颜色。

Input structure
- 背景为黑色。
- 网格中有若干矩形彩色区域（如 red、green、blue 的实心矩形块），它们互不重叠。
- 散布着若干对灰色像素（grey），每对灰色像素在同一行或同一列上对齐，且两个像素之间恰好穿过一个彩色矩形区域。
- 同一行或同一列上不会有超过两个灰色像素。
- 灰色像素本身不在任何彩色矩形区域内部。

Rule
- 找到所有共行或共列的灰色像素对。
- 对每一对灰色像素，沿它们之间的直线（水平或垂直）检查该线段穿过了哪一个彩色矩形区域。
- 将两个灰色像素之间的整条线段（包括穿过矩形区域的部分，但不包括灰色端点像素本身）绘制为该矩形区域的颜色。
- 灰色端点像素保持灰色不变。
- 彩色矩形区域保持不变（线段经过的部分已经是该颜色，视觉上无变化）。

Key insight
- 灰色像素对定义了"在哪里画线"，而线的颜色不是由灰色像素决定的，而是由线段路径上所穿过的彩色区域"染色"决定的。解题者需要先配对灰色像素，再追踪路径来确定颜色——这是一个两层推理：几何配对 + 颜色继承。
</description>

<new_puzzle>
<description>
在被分隔线划分的网格中，每个单元格包含一个小图案；找到图案之间的"拼合关系"，将可拼合为完整矩形的图案对合并到其中一个单元格中，另一个单元格清空。

Input structure
- 背景为黑色。
- 一种颜色（如 grey）的完整行和完整列将网格均匀分割成 N×M 个大小相同的矩形单元格。
- 每个单元格内部有一个由某种非背景、非分隔线颜色构成的图案。图案是一个不规则形状，占据单元格内部的部分像素。
- 存在若干对单元格，它们内部的图案形状互补——即将一个图案旋转 180 度后与另一个图案拼合，恰好填满整个单元格内部区域（无重叠无空隙）。
- 互补配对的两个图案颜色相同。
- 部分单元格内的图案不与任何其他图案互补（干扰项），这些图案的颜色与可配对图案不同。

Rule
- 在所有同色图案之间寻找互补对：将图案 A 旋转 180 度后叠加到图案 B 上，如果二者恰好填满单元格，则为一对。
- 对于每一对互补图案，将它们合并：在行号或列号较小的那个单元格中绘制完整的填充矩形（用该图案颜色填满整个单元格内部），将另一个单元格清空为背景色。
- 无法配对的干扰图案保持原样不变。
- 分隔线保持不变。

Key insight
- 解题者需要在视觉上执行"心理旋转"来判断两个图案是否互补，这不是简单的形状匹配，而是需要想象 180 度旋转后的拼合。第二层推理在于：合并结果放在哪个单元格取决于位置排序规则，而非图案本身的属性。
</description>

<new_puzzle>
<description>
网格中有若干条不同颜色的折线路径，每条路径上散布着若干"门"像素；统计每条路径穿过的门的数量，然后在路径的起点处沿垂直于路径起始方向生成对应长度的标记条。

Input structure
- 背景为黑色。
- 若干条不同颜色的 1 像素宽折线路径（每条路径由单一颜色构成，如 red、blue、green），路径由水平段和垂直段的直角转折连接而成，每条路径有两个端点（度为 1 的像素）。
- 路径上散布着若干 maroon 色的像素点，称为"门"。这些门像素覆盖在路径像素之上（即门的位置处路径颜色被替换为 maroon）。
- 每条路径的一个端点标记为 yellow（起点），另一个端点保持路径本色（终点）。起点像素为 yellow 色，不是路径颜色。

Rule
- 对每条路径，沿路径从 yellow 起点走到终点，统计路径上 maroon 门像素的数量 K。
- 从 yellow 起点位置出发，沿路径前进方向的垂直方向（即如果路径在起点处向右延伸，则标记条向上或向下生长；如果路径在起点处向下延伸，则标记条向左或右生长——取不与路径重叠的那一侧）绘制一条长度为 K 的标记条，颜色为该路径的颜色。
- 路径本身（包括门像素和起点）保持不变。

Key insight
- 解题者面临三层推理：(1) 识别出 maroon 像素是"门"而非路径的一部分——它们打断了路径颜色但在拓扑上属于路径；(2) 统计每条路径上的门数量；(3) 标记条的生长方向由起点处路径的朝向决定，标记条垂直于路径起始方向延伸。前两层需要归纳，第三层需要空间推理。
</description>

<new_puzzle>
<description>
网格中有若干个由外框和内部填充组成的嵌套矩形；根据角落处的颜色图例定义的优先级顺序，将输入中矩形的遮挡层次反转后重新绘制。

Input structure
- 背景为黑色。
- 网格中有若干个矩形对象，每个矩形由 1 像素厚的彩色外框和内部的另一种颜色填充组成（例如外框 red、内部 blue）。不同矩形的外框颜色各不相同，但内部填充色可以重复。
- 这些矩形在空间上部分重叠。在输入中，重叠区域的颜色由某种遮挡顺序决定（某些矩形"在上面"覆盖了其他矩形）。
- 在网格的某个角落（如左上角）有一个小型"图例条"：一行或一列中排列着若干不同颜色的单像素点，这些颜色恰好是所有矩形外框使用的颜色。图例条中颜色的排列顺序定义了优先级（靠近角落的优先级最低，远离角落的优先级最高）。
- 图例条与矩形对象在空间上不重叠。

Rule
- 读取图例条中的颜色顺序，建立外框颜色的优先级排序。
- 识别输入中的所有矩形（通过非重叠部分的外框和内部填充推断每个矩形的完整位置和大小）。
- 将所有矩形按照图例条定义的优先级重新绘制——优先级最高的矩形最后绘制（在最上层），优先级最低的最先绘制（在最底层）。
- 图例条本身在输出中保持不变。

Key insight
- 输入中的遮挡顺序是"旧的"，解题者需要发现角落的图例条编码了"正确的"优先级顺序，并据此重新渲染所有矩形的重叠关系。关键难点在于：(1) 从部分被遮挡的输入中还原每个矩形的完整边界和大小；(2) 理解图例条的排列方向与优先级的对应关系；(3) 按新顺序重绘所有矩形。这是三层需要主动推理的结构。
</description>

<new_puzzle>
<description>
网格中散布着若干彩色"种子"像素和若干灰色矩形"土壤"区域；每颗种子向对齐的土壤区域发射连接线，并在土壤内部的对齐行或列上染上种子的颜色。

Input structure
- 背景为黑色。
- 若干个灰色（grey）实心矩形区域，大小不等，散布在网格中，互不接触。
- 若干个单像素的彩色"种子"（颜色各异，如 red、blue、green、orange 等），每个种子与某个灰色矩形在同一行或同一列上对齐（即种子的行坐标落在矩形的行范围内，或种子的列坐标落在矩形的列范围内），且种子与该矩形之间没有其他对象阻挡。
- 每个种子恰好只与一个灰色矩形在行或列上对齐。

Rule
- 对每个种子像素，确定它与哪个灰色矩形对齐以及对齐方向（水平或垂直）。
- 如果种子与矩形在同一行范围内水平对齐（种子在矩形的左侧或右侧），则从种子位置向矩形方向水平延伸一条填充条：宽度为 1 像素，长度为种子到矩形最近边缘的像素距离（不包括种子像素本身，也不覆盖矩形），颜色为种子颜色。同时，在矩形内部与种子同行的位置，将该行的灰色像素全部重绘为种子颜色。
- 如果种子与矩形在同一列范围内垂直对齐（种子在矩形的上方或下方），则从种子位置向矩形方向垂直延伸一条填充条：宽度为 1 像素，长度为种子到矩形最近边缘的像素距离，颜色为种子颜色。同时，在矩形内部与种子同列的位置，将该列的灰色像素全部重绘为种子颜色。
- 种子像素本身保持其颜色不变。
- 没有被任何种子影响的灰色矩形像素保持灰色。

Key insight
- 种子不仅在矩形外部"生长"出一条连接线，还会"渗透"进矩形内部，在对齐的那一行或一列上留下自己的颜色印记。解题者需要推断两个独立的效果：外部的连接条和内部的染色条，它们共同由对齐方向决定。这是"方向决定效果形态"的双重表达——两层效果需要从样例中分别归纳。
</description>

<new_puzzle>
<description>
网格中有若干由不同颜色绘制的封闭围栏，每个围栏内部有一个小型"钥匙"图案；根据钥匙图案的朝向找到围栏上的对应出口边，然后将围栏内部的所有内容沿该方向平移到围栏外部。

Input structure
- 背景为黑色。
- 若干个由单一颜色绘制的 1 像素厚封闭矩形围栏，每个围栏颜色不同（如 red、blue、green）。
- 每个围栏的某一条边上有一个 2 像素宽的缺口（该边上连续 2 个像素被擦除为背景色）。
- 每个围栏内部有一个由 azure 色绘制的小型"L"形图案（3 个像素组成的直角形状）。L 形的开口方向朝向上、下、左、右四个方向之一。
- 每个围栏内部还可能有其他颜色的装饰像素（1-3 个像素的小色块）。

Rule
- 对每个围栏，观察其内部 L 形图案的开口方向。
- 找到围栏上缺口所在的边。如果 L 形的开口方向与缺口所在边的方向一致（例如 L 形开口朝右且缺口在右边），则该围栏为"激活"状态。
- 对于激活的围栏：将围栏内部的所有内容（L 形图案和装饰像素）沿 L 形开口方向平移出围栏，平移距离等于围栏在该方向上的内部宽度或高度，使得内容完整地出现在围栏外侧。围栏内部清空为背景色。围栏框架（包括缺口）保持不变。
- 对于未激活的围栏（L 形开口方向与缺口方向不一致）：整个围栏及其内容保持不变。

Key insight
- 解题者需要执行三层推理：(1) 识别 L 形图案的开口方向作为"指令"；(2) 判断该指令是否与围栏缺口匹配来决定是否激活；(3) 对激活的围栏执行方向性平移。缺口和 L 形都单独可见，但只有它们的一致性才触发变换——这种"条件匹配触发"机制增加了规则的隐蔽性。
</description>
</new_puzzle>
