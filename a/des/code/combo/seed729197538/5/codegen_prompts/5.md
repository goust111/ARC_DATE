网格中的每个彩色种子像素根据其所在区域的围墙形状生长出与围墙互补的填充图案。

Input structure
- 背景为 black。网格被 grey 像素构成的直线（水平和竖直）分割成若干个大小相同的矩形房间。
- 每个房间的四面墙（上、下、左、右边界上的 grey 像素段）可能存在缺口——即墙上某些位置的 grey 像素被移除，露出 black 背景。
- 部分房间内部恰好有一个非 black、非 grey 的彩色种子像素；其余房间为空（全 black 内部）。

Rule
- 对每个含种子像素的房间，检查其四面墙的缺口位置。
- 在房间内部（不含墙壁），生成一个填充图案：对于房间内部的每个像素位置，如果该位置"投影"到最近的墙壁上时命中缺口（即该像素所在行投影到左墙或右墙时对应位置是缺口，或所在列投影到上墙或下墙时对应位置是缺口），则将该像素填充为种子颜色。
- 更精确地说：对于房间内部坐标 (r, c)，若该行对应的左墙位置是缺口或右墙位置是缺口，则填充整行在房间内的该像素；若该列对应的上墙位置是缺口或下墙位置是缺口，则填充该像素。最终填充的像素是两个方向缺口投影的并集。
- 种子像素本身保留。空房间保持不变。

Key insight
解题者首先要发现房间墙壁的缺口是关键信息而非随机噪声，其次要发现填充规则是缺口位置向房间内部的"正交投影"——缺口所在的行或列会在房间内部产生一整条彩色线。墙壁的缺口模式与内部填充图案之间的互补映射关系是核心洞见。
