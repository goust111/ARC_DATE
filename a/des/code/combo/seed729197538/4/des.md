- `Input structure`：网格背景为黑色。灰色像素构成若干互不相交的封闭矩形边框（边框宽度为1像素）。每个封闭矩形的内部恰好有一个非黑非灰的标记像素。网格的某个角落区域存在一个"图案映射表"：由若干小方块组成，每个小方块左侧一列为单色色块（颜色与某个标记像素颜色相同），右侧为一个3x3的二色图案（用该颜色和黑色绘制）。
- `Rule`：
  1. 识别角落的图案映射表，建立"颜色→3x3图案"的对应关系。

- `Key insight`：标记像素不是要保留的对象，而是一个查表键；解题者需要先识别出角落的映射表结构，再将颜色与图案关联起来，最后用周期平铺完成填充——这是"查表"加"平铺"的两层推理。

- `Input structure`：网格背景为黑色。网格中散布着若干由不同颜色构成的小型不规则形状（碎片），每个碎片都是某个矩形的一部分。同时网格中有若干单像素的锚点标记，每个锚点的颜色与恰好两个碎片的颜色相同。每对同色碎片的形状互补：将它们无旋转地叠放后恰好拼成一个实心矩形。

- `Key insight`：解题者需要先发现碎片之间的形状互补关系（两块拼成一个完整矩形），然后识别锚点与碎片颜色的对应关系来确定放置位置——核心推理在于"互补配对"这一非显然的几何关系。

- `Input structure`：网格背景为黑色。网格中有若干由非黑色像素构成的箭头形对象。每个箭头由两部分组成：箭头头部（一个三角形尖端，由3个像素组成一个直角三角形，开口朝箭头反方向）和箭头尾部（一条从头部底边中心向反方向延伸的直线段）。箭头头部和尾部使用相同颜色。箭头可以指向上、下、左、右四个方向之一。每个箭头的尾端（远离头部的末端）紧邻一个不同颜色的单像素标记。
- `Rule`：
  1. 识别每个箭头的朝向（由三角形头部的开口方向确定指向）。
  2. 计算每个箭头对象的总像素数量 N（包括头部3像素和尾部线段像素）。
  3. 从箭头头部的尖端像素出发，沿箭头指向的方向绘制一条长度为 N 的直线段，颜色使用箭头尾端紧邻的那个标记像素的颜色。
  4. 箭头本身及标记像素保持不变。
- `Key insight`：箭头同时编码了两层信息——方向和数量。解题者首先需要理解箭头形状决定射线方向，然后需要发现箭头的像素总数决定射线长度，最后还要注意射线颜色来自尾端标记而非箭头自身颜色。
</new_puzzle>

- `description`：识别网格中被"围栏"环绕的种子像素，根据围栏的缺口方向让种子向外生长，生长形态由种子颜色在网格边缘的色条模板决定。
- `Input structure`：网格背景为黑色。网格中有若干由灰色像素构成的不完整矩形围栏（每个围栏是一个矩形环，但在某一条边的中央缺少若干像素形成一个缺口）。每个围栏内部有一个非黑非灰的单像素种子。网格的顶部边缘有一排色条模板：每个模板是一个小型的单色图形（宽度不超过5像素，高度不超过5像素），不同颜色的模板之间由黑色间隔分开。每个模板的颜色与某个种子的颜色对应。
- `Rule`：
  1. 对每个围栏，找到其缺口所在的边（上、下、左、右之一）。
  2. 读取围栏内种子的颜色，在顶部边缘找到同色的模板图形。
  3. 将模板图形放置在围栏缺口外侧：模板的参考边（与缺口方向对应的那条边）紧贴缺口，模板居中对齐于缺口位置。若缺口在左或右侧，模板需旋转90度使其"朝外"生长。
  4. 围栏、种子、其余模板均保持不变。
- `Key insight`：解题者需要发现三层对应关系——种子颜色链接到边缘模板、围栏缺口决定生长方向、模板需要根据缺口方向进行旋转——每一层都需要从样例中独立归纳。
</new_puzzle>

- `description`：将网格中的多个同构对象按照它们内部"钥匙孔"形状与边框上"钥匙"形状的匹配关系重新着色，未匹配的对象则被擦除。
- `Input structure`：网格背景为黑色。网格中央区域有若干大小相同的矩形对象，每个矩形用一种颜色绘制外框（宽1像素），内部为黑色，但每个矩形的某条边上有一个独特的凹陷缺口（"钥匙孔"），形状为向内凹入1-2像素的小凸形、L形或阶梯形。网格的四条边框（最外圈一行/列）上散布着若干小型凸起图形（"钥匙"），每个钥匙由某种非黑颜色绘制，从边框向内凸出，形状各异。
- `Rule`：
  1. 提取每个矩形对象的钥匙孔形状（缺口的轮廓）。
  2. 提取每个边框钥匙的凸起形状。
  3. 将钥匙孔与钥匙进行形状匹配（钥匙的凸出形状恰好与钥匙孔的凹入形状互补吻合，允许旋转匹配）。
  4. 匹配成功的矩形：将其外框颜色替换为对应钥匙的颜色。
  5. 匹配失败的矩形（无对应钥匙）：整个矩形被擦除为黑色。
  6. 边框上的钥匙保持不变。
- `Key insight`：解题者需要先识别矩形边框上的缺口并非残缺而是"钥匙孔"编码，再发现边框上的凸起是与之配对的"钥匙"，最后通过形状互补匹配（可能需要旋转）来决定重新着色——关键推理在于凹凸互补的空间匹配关系。
</new_puzzle>

- `description`：在网格中找到由不同颜色构成的"传送链"，沿链条方向依次将每个节点的内容传递给下一个节点，链尾内容回绕到链头。
- `Input structure`：网格背景为黑色。网格中有若干矩形区域（"容器"），每个容器由一种颜色的单像素边框围成，内部包含一个由另一种颜色绘制的小图案。不同容器的边框颜色各不相同。每个容器的边框颜色恰好与另一个容器内部图案的颜色相同，由此形成一条或多条闭合的颜色链。例如：容器A边框红色、内部图案蓝色；容器B边框蓝色、内部图案绿色；容器C边框绿色、内部图案红色——形成 A→B→C→A 的环。
- `Rule`：
  1. 通过"边框颜色 = 下一个容器内图案颜色"的关系，将所有容器串成一条或多条闭合环链。
  2. 沿环链方向，将每个容器内部的图案形状传递给链中的下一个容器：即下一个容器的内部图案被替换为当前容器内部图案的形状，但颜色改为下一个容器原有内部图案的颜色。
  3. 容器的边框、大小、位置均不变。
- `Key insight`：解题者需要先通过颜色交叉引用发现容器之间的链式连接关系，然后理解传递的是"形状"而非"颜色"——形状沿链传递而颜色保持本地不变，这需要两层独立的归纳。
</new_puzzle>

<new_puzzle>
- `description`：根据每个区域的"投票像素"多数颜色决定该区域的填充色，但投票前需先剔除与相邻区域重复出现的"间谍像素"。
- `Input structure`：网格背景为黑色。灰色线条将网格划分为若干矩形区域（类似九宫格或不规则网格）。每个区域内部散布着若干彩色像素（至少两种颜色），这些像素不相邻、不成形，看似随机分布。
- `Rule`：
  1. 识别灰色线条划分出的各个矩形区域。
  2. 对每个区域，检查其内部每种颜色的像素。如果某种颜色同时出现在当前区域和至少一个相邻区域（共享灰色边界的区域）中，则该颜色为"间谍色"，从当前区域的投票中剔除。
  3. 剔除间谍色后，统计剩余像素中数量最多的颜色（保证唯一）。
  4. 将该区域内所有非灰色像素替换为该多数颜色，完全填满区域（灰色边界保持不变）。
- `Key insight`：解题者容易直接用多数投票来填色，但会发现结果不对——需要先发现"间谍像素"的剔除规则（出现在相邻区域中的颜色不参与投票），这是一个反直觉的前置过滤步骤，构成真正的第二层推理。
</new_puzzle>
