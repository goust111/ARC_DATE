根据每个封闭区域内部的种子颜色，从区域的墙壁颜色图例中查找对应的填充纹理，将该纹理平铺填满整个封闭区域。

Input structure：
- 背景为 black。
- 网格中有若干由 grey 像素围成的封闭矩形区域，每个区域内部恰好有一个非背景、非 grey 的单像素种子点。
- 网格的某一侧边缘（例如最右侧几列）是一个图例区：图例区包含若干小矩形色块，每个色块的左上角像素颜色与某个种子颜色一致，色块其余部分是一个 3x3 的二色纹理模板（由该种子颜色和 black 组成的固定图案）。

Rule：
- 对每个封闭区域，找到其内部种子点的颜色。
- 在图例区中找到左上角颜色与该种子颜色匹配的纹理模板。
- 将该 3x3 纹理模板以平铺方式填满整个封闭区域的内部（不覆盖 grey 墙壁），种子点本身也被纹理覆盖。
- 图例区在输出中保持不变。

Key insight：
- 第一层推理：需要发现图例区的色块左上角像素是颜色索引，而非整个色块是单色；第二层推理：需要发现纹理是以 3x3 为单元在区域内周期性平铺，而不是缩放或居中放置。

<description>
将网格中散落的同色像素对视为"传送门"，把每个非传送门的前景对象通过其接触的传送门颜色转移到同色传送门的对称位置，并在转移后按目标传送门的局部朝向旋转对象。

Input structure：
- 背景为 black。
- 网格中有若干成对出现的单像素标记，每对共享同一颜色（如 red、blue、green 等），每种颜色恰好出现两个像素，构成一对传送门。
- 每个传送门像素恰好与一个由 grey 像素组成的 4-连通前景对象相邻（4-邻域接触）。
- 每个传送门像素位于其相邻对象的某一侧（上、下、左、右），这个方位定义了该传送门的"入口朝向"。

Rule：
- 对每个前景对象，找到与其 4-邻域接触的传送门像素的颜色，再找到同颜色的另一个传送门像素。
- 计算两个传送门像素的"入口朝向"之间的旋转差（例如：源传送门朝向为"右"即对象在传送门左侧，目标传送门朝向为"下"即目标对象应出现在传送门上方，则旋转差为顺时针 90 度）。
- 将该前景对象按此旋转差旋转后，放置到目标传送门像素的对应朝向一侧，使旋转后的对象与目标传送门像素相邻。
- 源位置的对象和传送门像素均被擦除（变为背景色）。

Key insight：
- 第一层推理：需要识别成对同色像素是传送门，对象通过传送门转移位置；第二层推理：需要发现传送门的朝向（即传送门相对于对象的方位）决定了对象在目标位置的旋转角度——这不是简单的平移，而是带旋转的映射。
</description>

<description>
在一个含有多层嵌套矩形框架的网格中，根据框架的嵌套深度（从外到内的层序号）奇偶性决定框架内部的填充方式：奇数层保留原内容，偶数层将内容水平镜像翻转。

Input structure：
- 背景为 black。
- 网格中有若干层由不同颜色绘制的单像素厚矩形框架，严格嵌套（每层框架完全包含在外层框架内部，不重叠不交叉）。
- 最内层框架的内部包含一个由多种颜色组成的不对称图案（"核心图案"）。
- 框架颜色互不相同，但框架颜色本身不编码任何信息，仅用于视觉区分层次。

Rule：
- 从最外层框架开始向内编号：最外层为第 1 层，次外层为第 2 层，依此类推。
- 最内层框架内部的核心图案作为初始内容。
- 从最内层向外逐层处理：若当前框架的层序号为偶数，则将该框架内部的全部内容（包括更内层的框架和图案）进行水平镜像翻转（左右翻转）；若为奇数，保持不变。
- 框架本身的像素位置不变，仅翻转框架围住的内部区域。
- 输出网格尺寸与输入相同。

Key insight：
- 第一层推理：需要发现嵌套框架的层序号决定了变换规则（奇偶交替），而不是框架颜色决定变换；第二层推理：需要理解翻转是累积的——偶数层的翻转会影响其内部所有内容，包括已经被内层规则处理过的部分，因此从内到外逐层应用翻转后，核心图案在某些层级会被翻转偶数次（恢复原样）或奇数次（最终镜像）。
</description>

<description>
网格中每个彩色对象充当一枚"印章"，其形状定义了印刷模板；将每枚印章沿其唯一伸出的"手柄"方向的反方向滑动到网格边缘，在滑动路径的终点用印章形状盖印，盖印颜色由印章经过的色带决定。

Input structure：
- 背景为 black。
- 网格中有若干由 grey 像素组成的小型 4-连通对象（"印章"），每个印章恰好有一个像素从主体向外伸出一格（形成一个单像素宽的"手柄"），手柄方向为上、下、左或右。
- 网格中另有若干条单像素宽的水平或垂直色带（非 grey、非背景的纯色线段），色带方向与某些印章的滑动路径垂直相交。

Rule：
- 对每个印章，识别其手柄方向——手柄指向的反方向即为滑动方向。
- 将印章沿滑动方向平移，直到印章的前沿（滑动方向上最远的像素行或列）抵达网格边缘。
- 在滑动路径中，检查印章是否穿越了某条色带：若穿越了，盖印使用该色带的颜色；若未穿越任何色带，盖印使用 grey（保持原色）。
- 原始位置的印章被擦除。盖印时，印章形状（含手柄）完整复制到终点位置。
- 色带本身在输出中保留不变。

Key insight：
- 第一层推理：需要识别手柄的突出方向，并推断出滑动方向是手柄的反方向（手柄像"尾巴"拖在后面）；第二层推理：需要发现印章的最终颜色不是固定的，而是由其滑动路径上是否穿越色带来决定——色带充当"染料池"，印章滑过时被"染色"。
</description>

<description>
在一个包含多个相似但略有差异的图案副本的网格中，找出每对副本之间的差异像素，并用差异像素的局部坐标作为平移向量，将一个隐藏在角落的小型"种子"图案沿该向量方向复制。

Input structure：
- 背景为 black。
- 网格中有一个由某种颜色（如 blue）绘制的"参考图案"，以及该图案的若干个副本，副本使用与参考图案相同的颜色。参考图案和每个副本尺寸、形状几乎完全相同，但每个副本恰好有一个像素位置与参考图案不同（要么多了一个像素，要么少了一个像素）。
- 网格的某个角落有一个由 red 像素组成的小型图案（"种子"），尺寸远小于参考图案。
- 参考图案位于网格的固定位置（如左上区域），可通过其完整性和位置识别。

Rule：
- 将每个副本与参考图案逐像素比较，找出差异像素在副本内部的局部坐标 (dr, dc)。
- 每个差异点的局部坐标 (dr, dc) 定义一个平移向量。
- 将 red 种子图案按每个平移向量分别复制一份：即在种子图案原始位置的基础上偏移 (dr, dc) 处绘制一份种子图案的副本（使用 green 颜色）。
- 参考图案、blue 副本和原始 red 种子在输出中保持不变。

Key insight：
- 第一层推理：需要识别哪个 blue 图案是"参考"（最完整或位于特定位置的那个），哪些是副本；第二层推理：需要发现每个副本与参考之间恰好一个像素的差异，并提取差异的局部坐标；第三层推理：需要理解这些局部坐标不是标记位置，而是作为平移向量施加到种子图案上，从而生成种子的多份偏移副本。
</description>

<description>
在一个由分隔线划分的网格面板中，每个面板包含一个不完整的环形轮廓和若干散落的颜色碎片；需要将环形闭合，并根据碎片位于环内还是环外的多数关系决定环的最终颜色。

Input structure：
- 背景为 black。
- 网格被 maroon 色的单像素分隔线分为若干等大的矩形面板。
- 每个面板中有一个由 grey 像素绘制的不完整环形轮廓（即一个闭合环缺少了一段弧），环的缺口恰好可以用直线段或 L 形转角补全。环形轮廓为单像素宽，整体呈矩形或近似矩形的封闭回路。
- 每个面板中还有 1-3 个散落的非背景、非 grey、非 maroon 的单像素颜色点。

Rule：
- 对每个面板，找到 grey 环形轮廓的两个断点（度数为 1 的端点）。
- 用最短的 4-连通路径连接两个断点以闭合环形（路径沿断点自然延伸方向行进，遇到需要转向时做 90 度转弯）。
- 闭合环形后，判断每个颜色碎片点位于闭合环的内部还是外部（通过 4-连通区域判断）。
- 统计位于环内部的颜色碎片数量：若内部碎片数量多于外部碎片数量，则整个闭合环（包括原有的 grey 部分和补全部分）重新着色为内部碎片中出现的颜色；若外部碎片数量多于或等于内部碎片数量，则环着色为外部碎片中出现的颜色。
- 若被选中一侧有多个不同颜色的碎片，使用距离环轮廓最近（像素步数最少）的那个碎片的颜色。
- 碎片点本身在输出中被擦除（变为背景色）。

Key insight：
- 第一层推理：需要发现灰色轮廓是不完整的环并找到正确的闭合方式；第二层推理：需要理解碎片与环的内外位置关系构成一个"投票"机制——多数侧的碎片决定环的最终颜色；第三层推理：当多数侧有多个颜色时，需要进一步使用距离作为 tie-break 来确定唯一颜色。
</description>

<description>
将网格中的每个箭头形状对象沿其指向方向发射，箭头飞行过程中若穿过彩色"棱镜"线段则发生分裂：一个副本继续原方向，另一个副本沿棱镜线段的法线方向偏折，分裂产物使用棱镜颜色绘制。

Input structure：
- 背景为 black。
- 网格中有若干由 grey 像素绘制的箭头形对象。每个箭头由一个 3x3 的箭头头部和一条 1 像素宽的尾巴线段组成。箭头头部是一个指向上、下、左或右的三角形（例如指向右的箭头头部：第 1 列 3 个像素、第 2 列中间 1 个像素、第 3 列中间 1 个像素，形成">"形状），尾巴从头部底边中点向指向方向的反方向延伸 1-2 格。
- 网格中有若干条由非 grey、非背景颜色绘制的单像素宽直线段（"棱镜"），方向为水平或垂直，且与箭头的飞行路径方向垂直。

Rule：
- 擦除每个箭头的原始位置。
- 每个箭头沿其指向方向飞行（整体平移），在飞行路径上每隔一格留下一个 grey 轨迹像素。
- 当箭头头部的前沿像素行/列到达某条棱镜线段时，发生分裂：
  - 原箭头继续沿原方向飞行并继续留下轨迹。
  - 产生一个相同形状的副本箭头，副本的指向旋转 90 度（朝向棱镜的法线方向，即若棱镜为水平线则副本向上或向下偏折——偏折方向取决于箭头从棱镜的哪一侧接近：箭头从上方接近水平棱镜则副本向下偏折，反之向上）。副本箭头从分裂点开始沿新方向飞行并留下轨迹。
- 副本箭头遇到新的棱镜时不再分裂（每个箭头只分裂一次）。
- 所有箭头（原始和副本）飞出网格边界后停止。最终仅保留轨迹像素。
- 棱镜线段在输出中保留不变。原方向的轨迹使用 grey 绘制，分裂副本的轨迹使用其触发棱镜的颜色绘制。

Key insight：
- 第一层推理：需要从箭头的三角形头部形状推断其飞行方向；第二层推理：需要发现棱镜线段导致箭头分裂而非反射——原箭头不改变方向，而是产生一个偏折的副本；第三层推理：需要发现分裂后的偏折轨迹使用棱镜颜色而非原始 grey，这意味着棱镜不仅改变方向还"染色"了分裂产物。
</description>
</new_puzzle>
