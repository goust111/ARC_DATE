将网格中散布的彩色像素对视为微型箭头，根据箭头朝向在尾部方向生长出射线，射线长度由箭头前方最近灰色障碍物的距离决定，不同颜色射线交叉处变为第三种颜色。

Input structure:
- 背景为 black 的网格。
- 网格中散布着若干由两个像素组成的彩色对（仅使用 red 和 blue 两种颜色）。每对中两个同色像素 4-邻接排列（水平或垂直），构成一个"微型箭头"：远离网格中心的那个像素为箭尾，靠近网格中心的那个像素为箭头。
- 网格中还存在若干由 grey 像素组成的独立小对象（每个为 1 到 3 个像素的连通块），分布在各处。

Rule:
- 对每个彩色微型箭头，确定其朝向（箭尾到箭头的方向，即朝向网格中心的方向）。
- 从箭头像素出发，沿箭头朝向方向在同一行或同一列上找到最近的 grey 对象，数出箭头像素到该 grey 对象最近边缘之间经过的背景像素数 N。
- 从箭尾像素出发，沿箭头的反方向延伸 N 个像素的射线，射线颜色与箭头颜色相同。射线遇到网格边界时截断。
- 若两条不同颜色的射线（一条 red、一条 blue）经过同一个像素，该像素变为 yellow。
- grey 对象、原始箭头像素保持不变。

Key insight:
箭头的方向决定射线的生长方向（反向），而射线的长度由箭头前方最近灰色对象的距离决定——解题者需要同时理解方向反转和距离借用两层机制，并在交叉处识别出颜色混合规则。
