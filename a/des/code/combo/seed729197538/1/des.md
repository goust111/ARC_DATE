<description>
根据前景对象内部孔洞的形状，在图例区找到匹配的模板，再用模板对应的边框颜色重绘该对象的轮廓。

Input structure:
- 网格分为上下两个区域，由一整行背景色（black）分隔。
- 上方为图例区：包含若干个小型闭合矩形框，每个矩形框用不同颜色绘制（如 red、blue、green、orange 等），框内部用背景色填充，但框内留有一个由 grey 像素绘制的微型形状（如 L 形、T 形、十字形等），每个框内的微型形状各不相同。
- 下方为主区域：包含若干个较大的单色（统一用 grey 绘制）闭合矩形对象，每个对象内部有一个由背景色构成的孔洞，孔洞的形状与图例区中某个微型形状完全相同（经过平移对齐后逐像素匹配）。

Rule:
- 对主区域中每个 grey 矩形对象，提取其内部孔洞的形状（即背景色区域相对于孔洞边界框左上角的像素布局）。
- 在图例区中找到内部微型形状与该孔洞形状完全相同的那个矩形框。
- 将主区域中该 grey 对象的所有 grey 像素重新着色为匹配到的图例矩形框的边框颜色。
- 图例区在输出中移除（不出现在输出网格中）。

Key insight:
解题者需要先识别出每个大矩形的"负空间"（孔洞形状），再到图例中找到对应的"正空间"模板来确定颜色——匹配发生在形状的正负反转之间，而非直接的颜色或位置对应。
</description>

<new_puzzle>
<description>
将网格中散布的彩色像素对视为微型箭头，根据箭头朝向在尾部方向生长出射线，射线长度由箭头前方最近灰色障碍物的距离决定，不同颜色射线交叉处变为第三种颜色。

Input structure:
- 背景为 black 的网格。
- 网格中散布着若干由两个像素组成的彩色对（仅使用 red 和 blue 两种颜色）。每对中两个同色像素 4-邻接排列（水平或垂直），构成一个"微型箭头"：远离网格中心的那个像素为箭尾，靠近网格中心的那个像素为箭头。
- 网格中还存在若干由 grey 像素组成的独立小对象（每个为 1 到 3 个像素的连通块），分布在各处。

Rule:
- 对每个彩色微型箭头，确定其朝向（箭尾到箭头的方向，即朝向网格中心的方向）。
- 从箭头像素出发，沿箭头朝向方向在同一行或同一列上找到最近的 grey 对象，数出箭头像素到该 grey 对象最近边缘之间经过的背景像素数 N。
- 从箭尾像素出发，沿箭头的反方向延伸 N 个像素的射线，射线颜色与箭头颜色相同。射线遇到网格边界时截断。
- 若两条不同颜色的射线（一条 red、一条 blue）经过同一个像素，该像素变为 yellow。
- grey 对象、原始箭头像素保持不变。

Key insight:
箭头的方向决定射线的生长方向（反向），而射线的长度由箭头前方最近灰色对象的距离决定——解题者需要同时理解方向反转和距离借用两层机制，并在交叉处识别出颜色混合规则。
</description>

<new_puzzle>
<description>
在网格中找到被单色边框包围的矩形区域，根据边框上缺口的位置和方向将区域内的图案"倒出"到区域外，倒出副本的颜色继承自边框。

Input structure:
- 背景为 black 的网格。
- 网格中有若干个由单一颜色绘制的矩形闭合边框（线宽为 1 像素），每个边框颜色各不相同（如 red、blue、green 等）。
- 每个矩形边框上恰好有一个缺口：边框某条边上有连续 1 至 3 个像素被擦除为背景色。
- 每个矩形边框内部包含一个由 grey 像素组成的小型图案（形状各异，如 L 形、方块、线段等）。
- 矩形边框之间不重叠，且边框外沿缺口方向有足够的空白空间。

Rule:
- 对每个矩形边框，定位其缺口所在的边（上、下、左、右）。
- 缺口所在的边决定图案的"倒出"方向：上边缺口则向上平移，下边缺口则向下平移，左边缺口则向左平移，右边缺口则向右平移。
- 将边框内部的 grey 图案沿该方向平移，平移距离等于边框在该方向上的内部高度或宽度（即让图案刚好完整地滑出边框，出现在边框外紧邻缺口的一侧）。
- 倒出后的图案副本颜色从 grey 变为所在边框的颜色。
- 原始边框和内部 grey 图案保持不变。

Key insight:
解题者需要先找到每个边框上微小的缺口来确定方向，再理解平移距离由边框自身的内部尺寸决定，最后发现倒出的副本颜色继承自边框而非原图案——三层信息（方向、距离、颜色）分别从边框的不同属性中提取。
</description>

<new_puzzle>
<description>
网格中有若干彩色印章对象，每个印章内有一个标记像素指示旋转角度；通过锚点旁的颜色标签建立配对关系后，将旋转后的印章盖印到对应锚点上。

Input structure:
- 背景为 black 的网格。
- 网格中有若干个由不同颜色绘制的小型连通对象（称为"印章"），每个印章由某种非黑非灰颜色的像素组成（如 red、blue、green、orange），形状各异但均可被一个不超过 5x5 的边界框包围。
- 每个印章内部恰好有一个像素被替换为 maroon 色，称为"旋转标记"。旋转标记位于印章边界框的四个象限之一（相对于边界框中心划分：左上、右上、右下、左下）。
- 网格中另有若干个 grey 单像素点，称为"锚点"。
- 每个 grey 锚点的某个 4-邻接位置上紧贴着一个彩色单像素"颜色标签"，其颜色与某个印章的颜色相同，用于指示该锚点对应哪个印章。每种颜色的印章和颜色标签均恰好各一个。

Rule:
- 对每个 grey 锚点，读取其 4-邻接位置上的颜色标签，确定对应的印章颜色。
- 找到该颜色的印章，提取其形状（将 maroon 标记视为该印章颜色的一部分来提取形状）。
- 根据 maroon 标记在印章边界框中的象限位置确定旋转角度：左上象限代表不旋转（0 度），右上象限代表顺时针旋转 90 度，右下象限代表顺时针旋转 180 度，左下象限代表顺时针旋转 270 度。
- 将旋转后的印章以锚点像素为中心盖印到网格上，印章像素覆盖背景色像素，全部使用印章的原始颜色绘制（maroon 标记也变为印章颜色）。
- 原始印章和颜色标签从输出中移除（恢复为背景色），仅保留锚点位置的盖印结果和 grey 锚点像素本身。

Key insight:
解题者需要先通过颜色标签建立锚点与印章的配对，再从印章内部 maroon 标记的象限位置推断旋转角度——配对机制和旋转编码是两层独立的非显然推理，且旋转标记的含义只有在比较多个样例的输入输出后才能归纳出来。
</description>

<description>
网格中有一条由前景色绘制的闭合环形路径和若干紧贴路径的彩色种子像素；沿路径顺时针行走，每经过一个种子就切换当前染色，将路径分段重绘为不同颜色。

Input structure:
- 背景为 black 的网格。
- 网格中有一条由 grey 像素组成的宽度为 1 的闭合环形路径（路径上每个 grey 像素恰好有两个 grey 的 4-邻接邻居），路径不自交。
- 路径围成的区域内外散布着若干单像素的彩色种子（使用 red、blue、green、orange 等颜色），每种颜色最多出现一次。
- 每个种子恰好与路径上的某一个 grey 像素 4-邻接（即种子紧贴路径）。

Rule:
- 找到路径上的起点：路径最上方的像素中最左边的那个。
- 从起点出发，沿路径顺时针行走（始终保持路径内部区域在行走者的右手侧）。
- 维护一个"当前活跃色"变量，初始为无。行走过程中，每当经过一个与某种子 4-邻接的路径像素时，将"当前活跃色"更新为该种子的颜色。
- 将行走经过的每个路径像素重绘为当前活跃色。若当前活跃色尚未被设置（起点到第一个种子之间），则该段路径保持 grey。
- 行走回到起点后结束。若最后一段的活跃色与起始段的 grey 相邻，grey 段不被覆盖。
- 种子像素本身在输出中保持不变。

Key insight:
解题者需要先识别闭合路径的拓扑结构和种子的邻接位置，再确定顺时针行走方向，最后理解"当前活跃色"沿路径传播并在遇到新种子时切换的状态机机制——路径的环形拓扑、行走方向、种子顺序三者共同决定最终的分段染色结果。
</description>

<new_puzzle>
<description>
网格中有若干个形状同构但大小不同的缩放对象，按面积从小到大逐层居中嵌套，最终输出紧凑裁剪的多层复合图形。

Input structure:
- 背景为 black 的网格。
- 网格中散布着若干个由不同颜色绘制的前景对象（每个对象单色，颜色各不相同，如 red、blue、green、orange、yellow 等）。
- 所有对象的形状完全相同（互为整数倍缩放关系）：它们都是同一种基本图案（如十字形、L 形、环形等）的不同缩放版本。例如若基本图案为 3x3 的十字形，则可能存在 3x3、5x5、7x7 等缩放版本，每个缩放版本的像素以对应倍率放大。
- 每个对象内部，属于图案的位置为该对象颜色，不属于图案的位置为背景色（即对象不是实心矩形，而是保持了图案的镂空结构）。

Rule:
- 按前景像素数量（面积）从小到大排列所有对象。
- 以最大对象为底层画布，将其放置在输出网格中。
- 将第二大的对象居中叠放在最大对象之上（两者边界框中心对齐），第二大对象的像素覆盖最大对象的像素。
- 继续将更小的对象依次居中叠放，每次都与当前复合图形的中心对齐，小对象像素覆盖下方像素。
- 最小的对象在最顶层。
- 输出为以最大对象的边界框为范围的紧凑裁剪结果，背景为 black。

Key insight:
解题者需要先发现所有对象虽颜色各异但形状同构（互为缩放），再按面积排序确定从外到内的嵌套顺序，最后理解居中对齐和逐层覆盖的叠加规则——识别跨颜色的同构缩放关系是核心的第一层推理，排序嵌套是第二层推理。
</description>
</new_puzzle>

<new_puzzle>
<description>
网格中有若干由不同颜色绘制的连通区域和一条贯穿网格的 grey 分界线；根据每个区域的多数像素落在分界线哪一侧，将该区域整体搬移到对侧的镜像位置，同时颜色变为该侧已有区域的颜色。

Input structure:
- 背景为 black 的网格。
- 网格中有一条由 grey 像素组成的完整直线（水平或垂直），将网格分为大小相等的两半（若网格为奇数宽/高，则 grey 线占据中间行/列）。
- 两侧各有若干个由不同颜色绘制的 4-连通前景区域。每个区域完全位于一侧（不跨越 grey 线）。
- 每一侧恰好有一个区域的形状与对侧某个区域的形状完全相同（经镜像翻转后逐像素匹配），但颜色不同。这两个互为镜像的区域称为"配对区域"。
- 每一侧还有一个"孤立区域"，在对侧没有形状匹配的配对。

Rule:
- 识别 grey 分界线的方向（水平或垂直）。
- 对每一侧的每个前景区域，尝试在对侧找到形状镜像匹配的区域（沿 grey 线做镜像翻转后形状相同）。
- 对于成功配对的区域：保持两个区域都不变，但将各自的颜色交换——即左侧配对区域变为右侧配对区域的原色，右侧配对区域变为左侧配对区域的原色。
- 对于孤立区域（无配对）：将其沿 grey 线镜像翻转到对侧，颜色保持不变。原始位置恢复为背景色。
- grey 分界线保持不变。

Key insight:
解题者需要先识别分界线，再通过形状的镜像匹配找到配对关系——配对区域交换颜色而孤立区域翻转位置，两种不同的变换规则取决于是否存在镜像配对，这一分支逻辑需要从多个样例中归纳得出。
</description>
</new_puzzle>
