每个彩色对象沿其"尾巴"所指方向的反方向滑动，在路径上留下灰色拖尾痕迹，碰到其他对象时触发链式传递运动。

Input structure:
- 背景为黑色。网格中有若干单色连通对象，每个对象的主体是一个紧凑的小块（2x2 或 3x3），主体的某一侧延伸出一条单像素宽、长度为1-3像素的"尾巴"，尾巴与主体同色。
- 尾巴的方向指示运动的反方向（即对象将朝远离尾巴的方向滑动）。
- 对象之间初始不接触，且每个对象的滑动路径上最多遇到一个其他对象。

Rule:
- 确定每个对象的运动方向：从尾巴指向主体的方向即为运动方向。
- 对象沿运动方向滑动，直到主体的前缘接触另一个对象或到达网格边界。
- 对象停在最终位置，其原始位置到最终位置之间的路径上，用灰色填充单像素宽的拖尾轨迹。
- 若对象撞上另一个静止对象，被撞对象接收运动并沿相同方向开始滑动（链式传递），同样留下灰色拖尾。
- 尾巴在运动后消失（被背景色覆盖）。

Key insight:
尾巴是方向编码器而非运动轨迹——它的朝向与运动方向相反；碰撞产生的链式传递要求解题者追踪多个对象的连锁运动序列，形成"方向解码 + 碰撞传递链"的双层推理。
