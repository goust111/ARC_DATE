<description>
根据封闭区域内部的颜色标记，选择对应的外部模板，将模板旋转至标记所指示的朝向后填入该区域。

Input structure：
- 背景为 Black。网格中散布若干大小不同的矩形封闭框，框的边界颜色统一为 Grey。
- 每个框的内部恰好有一个单像素颜色标记（如 Red、Blue、Green 等），位于框内四条边之一的中点位置。
- 框的外部散布若干小型彩色模板（3×3 或 4×4 的非对称图案），每个模板有一个主色，与某个框内标记颜色相同。每个模板在其正上方有一个与自身主色相同的单像素"方向锚点"，锚点与模板顶边中点对齐。

Rule：
- 将每个框内标记的颜色与外部模板的主色进行匹配，找到唯一对应的模板。
- 确定标记像素贴靠框内的哪条边（上、下、左、右），这指示了"入口方向"。
- 将模板旋转，使模板的锚点方向（默认朝上）对准框的入口方向（即标记所贴靠的那条边的朝内法线方向）。例如标记贴靠框的左边，则入口方向朝右，模板需顺时针旋转 90°。
- 将旋转后的模板居中放入框内部（去掉标记像素），模板像素覆盖框内背景像素。
- 框的边界和外部模板在输出中保留不变。

Key insight：
- 标记像素的位置同时编码了两层信息：颜色决定选哪个模板，位置决定模板以什么旋转角度填入框内。解题者必须先发现颜色匹配关系，再发现位置-旋转映射关系，两层规律缺一不可。
</description>

<description>
将网格中的多条折线路径按交叉点处的优先级规则进行上下分层重绘，模拟"编织"效果。

Input structure：
- 背景为 Black。网格上有若干条由不同颜色绘制的单像素宽折线路径（仅沿水平和垂直方向延伸，拐角处 90° 转弯）。
- 部分路径会在某些像素位置交叉重叠。在输入中，交叉点的颜色为其中一条路径的颜色（即一条路径"盖住"了另一条）。
- 每条路径的两个端点之一标有一个相邻的单像素 Yellow 标记，另一个端点无标记。

Rule：
- 识别每条路径的完整走向（包括被覆盖的交叉段）。路径可通过其颜色的连通性以及交叉点处的共线推断来恢复。
- 对所有交叉点，按以下编织规则重新决定哪条路径在"上方"：沿每条路径从有 Yellow 标记的端点出发，该路径遇到的第一个交叉点为"上方"（保留该路径颜色），第二个交叉点为"下方"（显示另一条路径颜色），第三个又为"上方"，依此交替。
- 当两条路径在同一交叉点都声称"上方"时，路径长度更短的那条优先在上方。
- 输出中所有非交叉像素保持不变，仅交叉点颜色可能改变。

Key insight：
- 解题者需要先恢复被遮盖的路径完整走向（第一层推理），然后发现从标记端点出发的奇偶交替编织规则（第二层推理），最后理解长度 tie-break（第三层在少数样例中触发）。Yellow 标记不是装饰而是编织起点的关键锚定。
</description>

<description>
将散落的碎片对象按照各自内部孔洞的形状拼接到中央模板的对应凹槽中，碎片需要翻转或旋转以匹配凹槽轮廓。

Input structure：
- 背景为 Azure。网格中央有一个大型 Grey 实心矩形模板，模板边缘被挖去若干个不规则凹槽（凹槽区域为背景色 Azure）。
- 模板外部散布若干彩色碎片对象（每个碎片颜色不同，如 Red、Green、Blue、Maroon 等）。每个碎片是一个实心连通区域，内部恰好有一个由背景色构成的孔洞（即碎片内部有一个封闭的 Azure 区域）。
- 凹槽的数量与碎片的数量相同。每个凹槽的形状恰好与某个碎片内部孔洞的形状全等（可能需要旋转 0°/90°/180°/270° 或水平翻转）。

Rule：
- 对每个碎片，提取其内部孔洞的形状。
- 将孔洞形状与模板上各凹槽进行匹配（允许旋转和翻转），找到唯一对应的凹槽。
- 用该碎片的颜色填充对应的凹槽区域（即凹槽中的 Azure 像素变为碎片颜色）。
- 输出仅包含模板矩形区域（裁剪到模板的边界框），碎片对象不出现在输出中。

Key insight：
- 匹配的关键不是碎片的外部轮廓而是其内部孔洞——碎片的"负空间"才是拼图的钥匙。解题者需要先识别出碎片内部孔洞（而非外轮廓）是匹配单元，再通过旋转/翻转找到凹槽对应关系，两层推理互相依赖。
</description>

<description>
根据种子像素沿路径传播生长方向，在每个分叉口选择由路径宽度决定的分支继续生长，最终到达的终端涂上种子颜色。

Input structure：
- 背景为 Black。网格中有一棵由 Grey 像素构成的树状路径网络：从一个根节点出发，路径不断分叉，每个分叉恰好分为两条子路径，最终到达若干叶子终端（终端为 Grey 像素的死胡同末端）。
- 路径宽度不一：有些路径段为单像素宽，有些为双像素宽（即两行或两列并行的 Grey 像素）。
- 根节点处恰好有一个非 Grey、非 Black 的彩色种子像素（如 Red），紧邻路径的起点。
- 每个叶子终端处也有一个单像素的 Maroon 标记，紧邻终端末端。

Rule：
- 从种子像素开始，沿 Grey 路径向下游传播。
- 每遇到一个分叉口，比较两条分支路径的宽度（单像素宽 vs 双像素宽）：始终选择较宽的分支继续传播。若两条分支宽度相同，则选择在分叉口处先遇到的那条（即从传播方向看偏左的一条）。
- 传播直到到达某个叶子终端。
- 输出中，将该终端旁的 Maroon 标记替换为种子的颜色（Red），其余所有像素保持不变。

Key insight：
- 解题者首先需要识别路径的树状分叉结构（非线性路径），然后发现分叉选择规则是由路径宽度（单/双像素）决定的——这要求注意路径的"粗细"这一容易忽视的视觉属性。宽度信息肉眼可见但不显眼，构成了机制的隐蔽性。
</description>

<description>
将输入网格中被彩色边框包围的子区域按照边框颜色在色谱图例中的排列顺序进行嵌套缩放重组，形成同心矩形环输出。

Input structure：
- 背景为 Black。网格中散布若干互不重叠的矩形区域，每个区域由一种独特颜色的单像素宽边框围成（边框颜色各不相同，如 Red、Blue、Green、Yellow、Orange 等），内部填充为 Black。
- 每个矩形的面积各不相同。
- 网格的某个角落有一个由所有边框颜色按特定顺序排列的单行或单列色带（如从左到右依次为 Red、Orange、Yellow、Green、Blue），作为排序图例。

Rule：
- 读取色带图例，确定颜色的排列顺序（从左到右或从上到下），该顺序定义了同心环的从外到内层次。
- 按此顺序，色带中第一个颜色对应最外层环，最后一个颜色对应最内层环。
- 构建输出：输出是一个同心矩形环结构。最外层环的周长等于色带第一个颜色对应的原始矩形的周长，环宽为 1 像素，颜色为该矩形的边框色。
- 每一层内环的周长等于其对应颜色原始矩形的周长，环宽为 1 像素，各层紧密嵌套（内层紧贴外层内壁）。
- 最内层环内部填充该层颜色（若剩余空间不足以形成环则整体填充）。
- 输出网格大小恰好容纳所有同心环。

Key insight：
- 解题者需要三步推理：（1）识别色带是排序图例而非装饰元素；（2）发现每个矩形的周长（而非面积或边长）决定了它在同心环中的尺寸；（3）理解从散布的独立矩形到紧密嵌套同心环的拓扑重组方式。周长作为尺寸映射的媒介是容易被忽略的关键。
</description>
</new_puzzle>

<new_puzzle>
<description>
在网格中找到每对同色标记之间的最短直角路径，路径颜色由该路径穿越的分区边界颜色决定。

Input structure：
- 背景为 Black。网格被若干条单像素宽的彩色直线（水平或垂直）分割成多个矩形分区，每条分割线颜色不同（如 Red、Blue、Green 等）。
- 在不同的分区内部散布着若干对同色标记像素（每种标记颜色恰好出现两次，标记颜色与分割线颜色均不相同，标记使用 Yellow、Maroon、Orange 等颜色）。
- 每对同色标记分布在不同的分区中。

Rule：
- 对每对同色标记，找到从一个标记到另一个标记的最短轴对齐路径（路径仅沿水平和垂直方向，可有一个直角拐弯）。
- 该路径必然穿越一条或多条分割线。收集路径按顺序穿越的所有分割线颜色。
- 路径上位于分割线之间（或标记到第一条分割线之间）的每一段，用它刚穿越的那条分割线的颜色来绘制。路径起点到第一条分割线之间的段用第一条穿越的分割线颜色绘制。
- 路径像素覆盖在背景上，不覆盖分割线本身和标记像素。
- 若某对标记之间存在多条等长最短路径，选择拐弯点行号更小的那条；若行号相同则选列号更小的。

Key insight：
- 解题者需要先理解分割线构成的分区结构，再发现路径的颜色并非由标记决定而是由"穿越了哪条分割线"动态决定——同一条路径的不同段可以有不同颜色。分割线同时扮演空间分隔和颜色赋予两种角色，这一双重功能是核心洞见。
</description>

<new_puzzle>
<description>
将每个封闭图形内部的纹理图案"投影"到该图形尖端所朝方向的外侧，投影位置由尖端顶点决定。

Input structure：
- 背景为 Black。网格中有若干个由 Grey 像素构成的凸多边形封闭轮廓（轮廓为单像素宽的 Grey 边界，内部填充为 Black 或纹理）。
- 每个封闭轮廓内部包含由某种非 Grey 颜色（如 Red、Blue、Green 等）绘制的稀疏纹理像素（不超过 5-6 个像素），纹理颜色每个图形各不相同。
- 每个封闭轮廓恰好有一条边比其他边短得多，形成一个明显的"尖端"，指示该图形的朝向（类似箭头的尖端方向）。尖端由轮廓上相邻两条边交汇于一个锐角顶点来定义。

Rule：
- 确定每个图形的朝向：从图形几何中心指向尖端顶点的方向（上、下、左、右四个轴对齐方向之一）。
- 提取图形内部的纹理像素相对于图形几何中心的坐标偏移。
- 从尖端顶点沿朝向方向向外，将纹理图案的像素模式复制一份，放置在图形外部。复制时保持纹理像素之间的相对位置不变，但将整个纹理块的锚点从几何中心平移到尖端顶点再沿朝向方向外移一个像素。
- 投影的纹理使用与内部纹理相同的颜色。超出网格边界的像素忽略。
- 原始图形（轮廓和内部纹理）在输出中保留不变。

Key insight：
- 解题者需要分两层推理：先通过轮廓的几何特征（锐角顶点）判断"朝向"，再发现内部纹理被当作一个整体图案沿该方向向外投射。纹理不是装饰而是待投影的内容，尖端不是装饰而是方向和出口的指示器。
</description>
</new_puzzle>
