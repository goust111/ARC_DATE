- `description`：根据封闭区域内部"种子"像素的颜色，从区域边界向内逐层收缩填充，每层使用种子颜色序列中的下一个颜色。

- `Input structure`：背景为 black。网格中有若干由同一颜色（如 grey）绘制的封闭矩形边框，每个边框内部放置了 1 到 4 个不同颜色的"种子"像素，种子像素散布在边框内部的 black 区域中。种子像素的颜色各不相同，且按照它们距离边框最近边的距离从小到大排列，构成一个有序颜色序列。

- `Rule`：
  1. 对每个封闭矩形边框，找到其内部的所有种子像素。
  2. 按每个种子像素到最近边框边的最小距离从小到大排序，得到颜色序列 c1, c2, c3, ...
  3. 将边框内部（不含边框本身）按层收缩填充：最外一圈（紧贴边框内侧）填充 c1，再向内一圈填充 c2，依此类推。
  4. 如果内部层数多于种子数量，剩余内层保持 black 不变。
  5. 种子像素本身被覆盖，不保留。

- `Key insight`：种子像素的作用不是标记位置，而是通过它们各自到边框的距离来编码填充层的颜色顺序——距离边框越近的种子决定越外层的填充色。
</new_puzzle>

<new_puzzle>
- `description`：将网格中散落的同色像素对视为"橡皮筋"的两个端点，沿最短的轴对齐路径连线，当两条线交叉时，后绘制的线在交叉点改用对方的颜色。

- `Input structure`：背景为 black。网格中有若干种非背景颜色，每种颜色恰好出现两个像素，分布在不同的行和列上。没有两对端点共享同一行或同一列。

- `Rule`：
  1. 对每种颜色，找到其两个像素端点 A 和 B。
  2. 按颜色对的两端点之间的曼哈顿包围盒面积（即 |行差| x |列差|）从小到大排序，确定绘制顺序。
  3. 连线方式：从 A 出发，先沿水平方向画到与 B 同列，再沿垂直方向画到 B（形成一个 L 形折线），折线使用该颜色对的颜色。
  4. 按排序顺序依次绘制每条折线。如果某条折线经过的像素已经被先前的折线占据，则该像素改为两种颜色中的后绘制的颜色（即当前颜色覆盖先前颜色）。
  5. 但在交叉点处（两条折线都经过的同一像素），该像素显示先绘制的那条线的颜色（先到先得）。

- `Key insight`：解题者需要同时推断两件事：连线的折线方向规则（先水平后垂直），以及绘制优先级（包围盒面积越小越先画）。交叉点的颜色保留先画的线，而非后画的线覆盖，这与直觉中"后画覆盖前画"相反，构成第二层需要归纳的规则。
</new_puzzle>

- `description`：在由分隔线划分的多个子区域中，每个区域包含一个"模板形状"和若干"碎片"；将碎片拼入模板的缺口中，拼合依据是碎片的轮廓与缺口轮廓的互补匹配。

- `Input structure`：背景为 black。网格被 grey 的十字分隔线（一条水平线和一条垂直线）划分为四个象限。每个象限中包含：
  - 一个由某种颜色（如 blue）绘制的大型矩形区域，其中有一个或多个矩形缺口（缺口区域为 black）。
  - 一个或多个小型碎片，由另一种颜色（如 red）绘制，形状与缺口完全互补（即碎片恰好能填满缺口）。碎片散落在同一象限的空白区域中。

- `Rule`：
  1. 在每个象限中，识别由 blue 色绘制的带缺口的大型模板。
  2. 识别同一象限中由 red 色绘制的碎片。
  3. 将每个碎片平移（不旋转、不翻转），使其恰好填入模板中与之形状匹配的缺口位置。
  4. 填入后，碎片颜色变为模板的颜色（blue），使模板成为完整的矩形。
  5. 碎片原来所在的位置变为 black 背景。

- `Key insight`：解题者首先需要识别出哪些是模板、哪些是碎片（通过尺寸和颜色区分），然后需要发现碎片不是按位置对应缺口，而是按形状互补性匹配——同一象限可能有多个缺口和多个碎片，必须通过轮廓吻合来配对。
</new_puzzle>

- `Input structure`：背景为 black。网格中散布着若干单像素的"信号塔"，每座塔有一种颜色，颜色取自 red、blue、yellow 三种原色。网格的一个角落（如左下角）有一个 3x3 的颜色混合图例：图例的行和列分别标注三种原色，交叉格显示两种原色混合后的结果色（red+blue=magenta，red+yellow=orange，blue+yellow=green，同色+同色=该色本身）。

- `Rule`：
  1. 每座信号塔向四个对角方向（左上、右上、左下、右下）发射射线。
  2. 射线沿对角线逐像素前进，遇到网格边界或另一座信号塔时停止（不覆盖终点的塔）。
  3. 如果射线在到达另一座塔之前碰到了网格边界，则该方向不绘制任何射线。
  4. 如果射线到达了另一座塔，则将射线路径上的所有 black 像素染成"混合色"——该混合色由发射塔颜色和接收塔颜色在图例中对应的交叉格颜色决定。
  5. 如果两条不同的射线经过同一个像素，该像素保留先绘制的射线的颜色（按塔从上到下、从左到右的顺序处理）。

- `Key insight`：解题者需要发现三层规则：(1) 射线方向是对角线而非水平/垂直；(2) 射线仅在成功连接到另一座塔时才绘制；(3) 射线颜色不是发射塔的颜色，而是需要查阅角落的混合图例来确定——图例本身的结构（行列交叉）也需要从样例中归纳。
</new_puzzle>

<new_puzzle>
- `description`：将网格中每个由边框围成的"房间"内的图案，按照房间边框上缺口的位置和朝向，翻转后"推出"到房间外的相邻空白区域。

- `Input structure`：背景为 black。网格中有若干个由 grey 边框围成的矩形"房间"，房间之间互不重叠但可能相邻。每个房间内部包含一个由某种颜色绘制的小型图案（形状不规则，但适合放入房间）。每个房间的边框上恰好有一个缺口（一个像素宽的 black 间断），缺口位于边框的上、下、左或右某一侧。

- `Rule`：
  1. 识别每个房间及其内部图案和边框缺口的位置。
  2. 将房间内部的图案沿缺口所在方向"推出"：图案从房间内移除（房间内部变为全 black），然后出现在房间外紧邻缺口的区域中。
  3. 推出时图案需要进行一次镜像翻转：如果缺口在左或右侧，图案沿垂直轴（左右）翻转后放置在缺口外侧；如果缺口在上或下侧，图案沿水平轴（上下）翻转后放置在缺口外侧。
  4. 推出后的图案紧贴缺口外侧放置，图案的边缘与缺口位置对齐。
  5. 房间的 grey 边框保持不变（包括缺口）。

- `Key insight`：解题者需要归纳出两个非显然的规则：第一，图案的移动方向由缺口位置决定（这相对容易观察）；第二，图案在推出过程中会发生镜像翻转，翻转轴垂直于推出方向——这个翻转操作不容易在第一个样例中就确定，需要多个样例才能区分"平移推出"和"翻转推出"。
</new_puzzle>

<new_puzzle>
- `description`：网格中多条不同颜色的路径从边界进入并在内部交汇；在每个交汇点处，两条路径交换各自的前进方向，使得每条路径的入口颜色最终到达另一条路径原本的出口。

- `Input structure`：背景为 black。网格中有若干条由不同颜色绘制的一像素宽路径，每条路径从网格的一条边进入，沿水平或垂直方向延伸。路径成对出现：每对中两条路径分别从不同的边进入，在网格内部的某个像素处相交（形成十字交叉）。交叉点处两条路径的像素重叠，该像素在输入中显示为 grey（表示这是一个交汇节点）。每条路径恰好经过一个交叉点。

- `Rule`：
  1. 识别所有 grey 像素作为交叉点。
  2. 对每个交叉点，找到经过它的两条路径（通过交叉点上下左右四个方向延伸的颜色段来确定）。
  3. 在交叉点处，两条路径交换前进方向：原来水平路径在交叉点后变为垂直继续延伸，原来垂直路径在交叉点后变为水平继续延伸。
  4. 交换后，每段路径保持原来入口段的颜色。因此交叉点之后的路径颜色会改变为另一条路径入口段的颜色。
  5. 交叉点本身的像素颜色变为其"输出侧"两段路径颜色中行号较小的那一段的颜色。

- `Key insight`：表面上看路径只是简单的直线，但交叉点处发生了"方向交换"——水平变垂直、垂直变水平，同时颜色跟随入口段而非跟随方向。解题者需要从多个样例中分辨出这不是颜色交换（因为颜色跟随入口段不变），而是方向交换，这种区别需要仔细对比输入输出才能发现。
</new_puzzle>

<new_puzzle>
- `description`：根据网格中"时钟指针"图案所指示的方向和臂长，从指针末端开始，在指定方向上绘制与臂长等长的彩色线段；指针的颜色决定线段颜色，而指针所附着的中心点颜色决定线段的绘制层级。

- `Input structure`：背景为 black。网格中有若干个"时钟"结构，每个时钟由以下部分组成：
  - 一个中心像素，颜色为 red、blue 或 green 中的一种，代表绘制优先级（red 最高，green 最低，blue 居中）。
  - 从中心像素出发的一条直线"指针"，指针沿八个方向之一（上、下、左、右、四个对角）延伸，长度为 1 到 4 个像素。指针颜色与中心像素不同，取自 yellow、orange、magenta、azure 等颜色。

- `Rule`：
  1. 识别每个时钟的中心像素和指针。
  2. 确定指针的方向和长度 L（不含中心像素）。
  3. 从指针末端（距中心最远的像素）开始，沿指针的同一方向继续延伸，绘制 L 个像素的线段，颜色与指针颜色相同。
  4. 如果延伸线段超出网格边界，则只绘制边界内的部分。
  5. 按中心像素的优先级处理所有时钟：red 中心的时钟最先绘制延伸线段，blue 其次，green 最后。高优先级的线段不会被低优先级覆盖；低优先级的线段在遇到已有非背景像素时跳过该位置。

- `Key insight`：解题者需要依次发现三层规则：(1) 指针末端是延伸的起点而非中心点；(2) 延伸长度等于指针本身的臂长（需要计数）；(3) 中心像素的颜色不影响线段颜色，而是编码了绘制优先级——这一点需要从线段重叠区域的颜色归纳得出。
</new_puzzle>
