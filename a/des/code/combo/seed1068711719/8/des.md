- `description`：根据每个封闭区域边框上缺口的方位，将区域内部的图案沿缺口方向整体平移出框，并在原位留下 maroon 色残影。

- `Input structure`：
  - 背景为 black。
  - 网格中有若干个由 grey 色绘制的单像素厚矩形闭合边框，每个边框恰好有一个单像素宽的缺口（该位置为 black，打断了边框环）。
  - 每个边框内部有一个由某种彩色像素（颜色各不相同，如 blue、orange、green 等）组成的连通图案，图案不接触边框。
  - 在边框外部、沿缺口朝外的方向上，有足够的空白背景空间容纳平移后的图案。

- `Rule`：
  - 第一层推理——缺口定向：找到每个边框上唯一的缺口像素位置。缺口所在的边（上、下、左、右）决定该边框内部图案的平移方向：缺口在右边则图案向右平移，缺口在上边则图案向上平移，以此类推。
  - 第二层推理——平移距离与残影：平移距离等于边框在平移方向上的内部跨度（即内容恰好完全移出边框，不再与边框内部区域重叠）。平移后的像素保持原色绘制在边框外部。原来图案所占的每个像素位置用 maroon 色填充，形成与原图案形状完全相同的残影。
  - 边框本身保持不变（包括缺口保持为 black）。

- `Key insight`：缺口不仅标记了方向，其所在边还隐含了平移的确切距离（框的内部跨度）；解题者需要同时归纳"缺口→方向"和"框宽→距离"两条规律，且残影机制要求理解"移出"与"留痕"的双重操作。
</new_puzzle>

- `description`：将网格中散落的同色像素簇按面积排序后首尾配对，每对簇互换颜色，位置和形状不变。

- `Input structure`：
  - 背景为 azure。
  - 网格上散布着偶数个互不相连的 4-连通像素簇（例如 4 个或 6 个），每个簇内部所有像素颜色相同，不同簇颜色互不相同。
  - 所有簇的像素数量（面积）互不相同，形状各异（L 形、线段、小方块等），位置互不重叠。

- `Rule`：
  - 第一层推理——排序与配对：将所有簇按像素数量从小到大排序，得到序列 S1, S2, …, Sn。将最小簇 S1 与最大簇 Sn 配对，次小簇 S2 与次大簇 Sn-1 配对，依次类推直到所有簇配对完毕。
  - 第二层推理——颜色互换：每一对中两个簇互换颜色。即 S1 的所有像素涂为 Sn 的原色，Sn 的所有像素涂为 S1 的原色；S2 与 Sn-1 同理。
  - 所有簇的位置和形状保持不变，仅颜色改变。背景不变。

- `Key insight`：解题者需要先发现簇的面积是排序键（而非位置、颜色等其他属性），再发现配对规则是首尾交叉（最小↔最大）而非相邻交换，两层归纳缺一不可。
</new_puzzle>

- `description`：网格被墙壁分割为线性排列的房间链，从标记起点出发依次穿越每个房间，按房间序号的奇偶性在房间内铺设不同方向的条纹，条纹颜色按固定序列循环。

- `Input structure`：
  - 背景为 black。
  - 网格由 red 色单像素厚墙壁分割成若干矩形房间。
  - 每个房间的墙壁上有一个或两个单像素缺口（门），门的连接关系使所有房间形成一条不分叉的线性链——从一端出发可经每扇门依次穿越所有房间恰好一次。
  - 链的一个端头房间（仅有一扇门的房间）内有一个 green 单像素标记，表示起点。

- `Rule`：
  - 第一层推理——链序还原：通过门的位置确定相邻房间关系，从 green 标记所在房间出发沿唯一路径遍历所有房间，得到有序序列 R1, R2, R3, …。
  - 第二层推理——条纹方向编码：序号为奇数的房间（R1, R3, R5, …）内部绘制水平条纹（第一行为彩色，第二行为 black，逐行交替）；序号为偶数的房间（R2, R4, R6, …）绘制垂直条纹（第一列为彩色，第二列为 black，逐列交替）。
  - 第三层推理——颜色循环：条纹的彩色按固定顺序循环分配：blue → yellow → magenta → orange → blue → …（即 R1 用 blue，R2 用 yellow，R3 用 magenta，R4 用 orange，R5 回到 blue）。
  - 条纹从房间内部左上角开始。墙壁和门保持 red 不变。green 标记保留在原位。

- `Key insight`：解题者必须先通过门的拓扑关系重建房间遍历顺序（空间推理），再发现奇偶序号决定条纹方向（结构归纳），最后发现颜色按四周期循环（模式识别），三层推理逐步叠加。
</new_puzzle>

- `description`：每个矩形对象内部有一条 grey 直线将其一分为二，沿该线折叠后，重叠位置保留在整个对象中出现次数更少的颜色。

- `Input structure`：
  - 背景为 black。
  - 网格中有若干互不接触的矩形区域，每个矩形由两种非背景颜色填充（例如一半主要为 blue，另一半主要为 orange）。
  - 每个矩形内部恰好有一条完整的 grey 水平线段或垂直线段贯穿矩形，将其分为面积可能不等的两半。
  - 两半各自以一种颜色为主色，但各有少量像素被对方颜色"入侵"（即 blue 半边零星散布着几个 orange 像素，反之亦然）。

- `Rule`：
  - 第一层推理——折叠轴与方向：grey 线段为折叠轴。若为水平线段则上下折叠，若为垂直线段则左右折叠。折叠方向：将较大的一半向较小的一半翻转（等大时将下半/右半向上半/左半翻转）。
  - 第二层推理——重叠冲突解决：折叠后两半像素逐格叠加。同色位置保持不变；异色位置选择在该对象整体中出现总次数较少的颜色。grey 折叠线在输出中消失。较大一半超出较小一半边界的多余行/列正常保留。
  - 每个对象的输出尺寸缩小为折叠后的尺寸，位置对齐原较小一半所在位置。

- `Key insight`：grey 线段是折叠轴而非分隔装饰；"入侵像素"是折叠后产生冲突的根源；解题者需要独立推断折叠方向（基于面积比较）和冲突解决规则（全局稀有度优先），两步推理均不可从单一样例直接看出。
</new_puzzle>

<new_puzzle>
- `description`：中央模板窗口内展示一个目标轮廓，四个方位的彩色对象各需经过与方位对应的几何变换后与模板对齐，多出的像素删除、缺失的像素用 maroon 补全。

- `Input structure`：
  - 背景为 black。
  - 网格中央有一个由 grey 单像素边框围成的矩形"模板窗口"，窗口内部绘有一个 green 色的不规则连通形状（模板轮廓），其余窗口内部为 black。
  - 模板窗口的上方、下方、左方、右方各有一个彩色对象（颜色互不相同，如 blue、red、yellow、orange），每个对象也是不规则连通形状，面积与模板形状接近但不完全相同。
  - 四个对象与模板窗口之间有明显间隔，不会互相接触。

- `Rule`：
  - 第一层推理——方位→变换映射：上方对象需水平翻转（沿水平轴上下翻转）后与模板对齐；下方对象保持原样对齐；左方对象需垂直翻转（沿垂直轴左右翻转）后对齐；右方对象需旋转 180 度后对齐。
  - 第二层推理——差异修补：将变换后的对象与模板轮廓逐像素比较（以各自包围盒的左上角对齐）。对象中有而模板中没有的像素删除（改为 black）；模板中有而对象中缺失的像素用 maroon 填充在对象中对应位置。最终每个对象的轮廓与经过对应变换的模板形状完全一致。
  - 对象在原位就地修改。模板窗口及 grey 边框在输出中保持不变。

- `Key insight`：解题者需要跨多个样例对比才能归纳出四种方位分别对应哪种几何变换（这一对应关系并不直观），然后还需独立发现变换后的对象与中央模板之间执行裁剪+补全操作——两层规律均需主动推理。
</new_puzzle>
