<description>
根据封闭区域内的颜色种类数选择对应的印章模板，将印章盖印到该区域的中心位置。

Input structure:
- 背景为黑色（Black）。
- 网格中散布若干由灰色（Grey）像素构成的封闭围栏，每个围栏围成一个矩形区域。围栏为一像素宽的完整矩形框。
- 每个围栏内部包含若干彩色像素点（颜色各异，从 Red、Blue、Green、Yellow、Orange 中选取），这些像素随机散布在围栏内部的黑色背景上。
- 网格的右下角有一组"印章图例"：由若干小的 3x3 图案组成，每个图案用 Maroon 绘制在黑色背景上，图案之间用一列黑色像素分隔。图例从左到右排列，分别编号为第 1、第 2、第 3……个印章模板。每个 3x3 图案的形状各不相同（例如十字、L形、对角线等）。

Rule:
- 对每个灰色围栏区域，数出其内部包含多少种不同的非黑、非灰颜色。设该数量为 N。
- 从印章图例中选取第 N 个印章模板（从左到右，第 1 个对应 N=1）。
- 将该 3x3 印章模板以 Maroon 色盖印到围栏内部区域的中心位置（若内部区域高度或宽度为偶数，则印章偏左上）。印章覆盖其下方的所有像素。
- 围栏内部原有的彩色散布像素全部清除为黑色（即只保留印章图案）。
- 灰色围栏本身保持不变，印章图例区域保持不变。

Key insight:
围栏内部的彩色像素不是装饰——它们的颜色种类数是查询印章图例的索引键；解题者需要先建立"颜色种类数→图例位置"的映射，再理解印章被放置于围栏中心。
</description>

<description>
将网格中分散的同色碎片拼合回各自的矩形原型，并按面积从小到大依次嵌套为同心矩形框。

Input structure:
- 背景为黑色（Black）。
- 网格中有若干组彩色碎片，每组碎片使用同一种颜色（如 Red、Blue、Green、Yellow 等），每种颜色恰好出现一组。
- 同一颜色的碎片是一个完整的一像素宽矩形框被切割成 2-4 块连通分量后散落在网格中的结果。每块碎片保持了原始矩形框上的形状（即碎片是矩形框边的一部分，保留了直角转弯等特征）。
- 每种颜色的所有碎片加在一起恰好组成一个完整的一像素宽矩形框（无重叠、无多余像素）。

Rule:
- 对每种颜色，将其所有碎片在平移意义下重新拼合为一个完整的一像素宽矩形框。拼合方式唯一。
- 计算每个矩形框的面积（框所围住的内部区域面积，即 (宽-2)x(高-2)）。
- 按面积从小到大排序。面积最小的矩形框放在输出网格的中心，下一个较大的矩形框同心地套在外面，依此类推。
- 相邻两层矩形框之间恰好间隔一个像素的黑色背景。
- 输出网格大小恰好容纳所有嵌套框，外围无多余空行或空列。

Key insight:
碎片的拼合是第一层推理——需要识别哪些散落碎片属于同一个矩形框，并推断出完整框的尺寸；嵌套排列是第二层推理——面积排序决定了由内到外的绘制顺序，且输出网格尺寸由最大框加上间距决定。
</description>

<description>
沿彩色导线传播信号，信号在每经过一个中继节点时改变传播方向（顺时针旋转90度），最终在导线末端绘制与起点颜色相同的标记。

Input structure:
- 背景为黑色（Black）。
- 网格中有若干条由灰色（Grey）像素构成的导线。每条导线是一像素宽的水平或垂直直线段，导线之间通过"中继节点"相连。中继节点是一个彩色像素（非黑、非灰），位于两条导线的交汇端点处，即一条导线的末端与另一条导线的起端共享这个彩色节点，且这两条导线方向不同（一条水平、一条垂直）。
- 每条导线链的一端是"信号源"：一个 2x2 的彩色方块，其颜色为该链的信号颜色（如 Red、Blue、Green 等）。2x2 方块的一个边与第一条灰色导线的端点相邻。
- 每条导线链的另一端是"终端"：最后一条灰色导线的自由末端（不与任何节点或信号源相邻）。
- 网格中有多条独立的导线链，它们互不相交。

Rule:
- 从每个 2x2 信号源出发，信号沿相邻的灰色导线传播。初始传播方向由信号源与第一段导线的相对位置决定（信号源在导线端点的哪一侧，信号就朝相反方向传播）。
- 信号沿导线传播时，将灰色导线像素重新着色为信号源的颜色。
- 当信号到达一个中继节点时，传播方向顺时针旋转 90 度，然后继续沿下一段导线传播。中继节点本身的颜色不改变。
- 当信号到达导线链的终端时，在终端位置绘制一个与信号源相同颜色的 2x2 方块（方块向远离导线的方向延伸）。
- 信号源的 2x2 方块在输出中保持不变。

Key insight:
中继节点的存在不仅仅是连接——它们强制信号每次转弯都是顺时针 90 度旋转，解题者必须从样例中归纳出"每个节点顺时针转向"这一隐含规则，而非简单地"沿导线走"。同时，终端标记的绘制方向取决于信号到达时的最终传播方向。
</description>

<description>
根据网格边缘的色带编码，在网格内部为每个交叉区域填充由行色带和列色带共同决定的混合颜色。

Input structure:
- 背景为黑色（Black）。
- 网格的最左列和最上行作为"色带编码区"。最左列（不含左上角格）的每个像素涂有一种颜色，代表该行的"行颜色"。最上行（不含左上角格）的每个像素涂有一种颜色，代表该列的"列颜色"。左上角格始终为黑色。
- 色带中使用的颜色来自 {Red, Blue, Green, Yellow, Orange, Azure} 的子集。
- 网格内部（即去掉最左列和最上行后的区域）中，部分单元格已经被填充了颜色，部分单元格为黑色（待填充）。
- 已填充的单元格遵循一个隐含的"颜色混合表"：每对（行颜色, 列颜色）对应一个确定的输出颜色。这张混合表在所有样例中保持一致，但不会直接给出，需要从已填充的单元格中归纳。

Rule:
- 从已填充的内部单元格中，归纳出完整的颜色混合表：对于位于第 r 行、第 c 列的已填充单元格，其颜色 = mix(行色带[r], 列色带[c])。
- 将所有黑色的内部单元格按照该混合表填充：查找其对应的行颜色和列颜色，查表得到混合结果。
- 色带编码区（最左列和最上行）保持不变。

Key insight:
解题者需要完成两层归纳：第一层是发现边缘色带是行/列的编码键；第二层是从已有的填充样本中逆向推断出隐含的混合函数（混合表），然后用该表补全所有空位。混合表不是简单的"取其中一个颜色"，而是一个需要从多个样本点中推断的任意映射。

<description>
识别网格中每个"窗户"图案的开口方向，将窗户内部的颜色沿开口方向向外投射为等长的彩色射线。

Input structure:
- 背景为黑色（Black）。
- 网格中有若干个"窗户"对象。每个窗户由一种颜色（如 Blue、Red、Green 等）的像素构成一个 3x3 的方框，但方框的四条边之一的中间像素缺失（即被替换为黑色），形成一个开口。因此每个窗户恰好有 7 个同色像素，开口在上、下、左、右四个方向之一。
- 每个窗户的内部中心像素（3x3 方框的正中心）涂有一种与窗框不同的颜色，称为"内容色"。
- 窗户之间互不接触（8-连通意义下不相邻）。

Rule:
- 对每个窗户，确定其开口方向（缺失像素所在的边指示的方向）。
- 从窗户的开口位置出发（即缺失像素的位置），沿开口方向发射一条射线。
- 射线的颜色为该窗户的内容色（中心像素的颜色）。
- 射线的长度等于网格中与该窗户使用相同窗框颜色的窗户总数（包括自身）。例如，若有 3 个蓝色窗框的窗户，则每个蓝色窗框窗户射出的射线长度均为 3。
- 射线逐像素绘制，如果射线超出网格边界则截断。射线不会覆盖已有的非黑色像素（遇到非黑色像素时提前停止）。
- 窗户本身（窗框和中心内容色）在输出中保持不变。

Key insight:
解题者面临三层推理：（1）识别 3x3 方框的缺口位置以确定开口方向——这需要在四个方向上检查哪个边的中间像素缺失；（2）理解射线颜色来自窗户内部而非窗框；（3）发现射线长度不是固定值，而是由"全局同色窗框计数"决定的——这要求解题者跨越多个窗户进行统计，将一个全局属性映射为局部几何量。
</description>

<description>
将散落的彩色种子像素沿其所在象限的对角线方向推入中央花盆区域，种子在花盆内按到达顺序自下而上堆叠生长为花茎。

Input structure:
- 背景为黑色（Black）。
- 网格正中央有一个由灰色（Grey）像素构成的矩形区域，称为"花盆"。花盆宽度为奇数（如 5 或 7），高度为网格高度的约一半，底边与网格底边对齐。
- 花盆将网格上半部分的左右两侧分为四个象限（左上、右上两个主要区域，花盆左右两侧）。
- 每个象限中散布着若干单个彩色像素（种子），颜色从 Red、Blue、Green、Yellow、Orange 中选取。每个象限内的种子颜色可以不同。
- 花盆的顶边中央有若干等距的黑色缺口（每个缺口宽 1 像素），这些缺口是"种植槽"。

Rule:
- 对花盆顶边上的每个种植槽（从左到右编号），确定其左侧象限和右侧象限各有多少颗种子。
- 左侧象限的种子和右侧象限的种子分别按照其到种植槽的距离从近到远排序（距离按行差+列差的直观格数衡量，即视觉上更近的优先）。
- 从每个种植槽向上生长一条"花茎"：将对应的种子颜色自下而上逐像素绘制在种植槽正上方的列中。左侧象限的种子排在下方，右侧象限的种子排在上方。
- 花茎的总高度等于对应两个象限中种子的总数。
- 种子原来所在的位置清除为黑色。花盆灰色区域保持不变。

Key insight:
解题者需要先理解花盆顶部的缺口是种植槽而非破损，再发现每个种植槽"管辖"其两侧象限的种子，最后归纳出种子按距离排序并分左右叠放的堆叠规则。种植槽的位置决定了哪些种子属于哪个槽，而种子的空间分布决定了花茎中颜色的排列顺序。
</description>

<description>
在网格中找到每对同色锚点，沿两锚点之间的路径铺设该颜色的"桥梁"，桥梁的宽度由锚点自身的尺寸决定。

Input structure:
- 背景为黑色（Black）。
- 网格中有若干个彩色"锚点"。每个锚点是一个由同一颜色填充的正方形块（尺寸为 1x1、2x2 或 3x3）。
- 每种颜色恰好出现两个锚点，且这两个锚点的尺寸相同。两个同色锚点要么在同一行（中心行相同），要么在同一列（中心列相同），即它们之间可以用一条水平或垂直的直线连接。
- 不同颜色的锚点对之间的连线不会交叉。

Rule:
- 对每对同色锚点，确定它们之间的连接方向（水平或垂直）。
- 沿连接方向，在两个锚点之间铺设一条"桥梁"：桥梁的颜色与锚点相同。
- 桥梁的宽度（垂直于连接方向的像素数）等于锚点正方形的边长。例如，两个 2x2 的红色锚点之间的桥梁宽 2 像素。
- 桥梁从一个锚点的边缘延伸到另一个锚点的边缘，填满两者之间的所有空隙。
- 如果桥梁路径上存在其他颜色的锚点像素，桥梁在该位置中断（不覆盖其他颜色），形成隧道效果：桥梁在障碍两侧保持，但不覆盖障碍像素。
- 锚点本身保持不变。

Key insight:
解题者的第一层推理是识别配对规则——同色、同尺寸、共线的两个方块构成一对；第二层是发现桥梁宽度不是固定的，而是由锚点尺寸决定的；第三层是理解桥梁遇到异色障碍时的中断行为，而非简单覆盖。
</description>
</new_puzzle>
