- `description`：根据彩色种子像素在封闭围栏内的位置，用种子颜色沿围栏内壁涂满该种子所在的"区段"，再将围栏外侧对应区段标记为种子数量对应长度的射线。
- `Input structure`：背景为 black。网格中有若干由 grey 像素构成的一像素宽封闭矩形围栏（不共享边）。每个围栏内部散布着若干彩色种子像素（颜色各异，每种颜色在同一围栏内仅出现一次）。围栏的每条边（上、下、左、右）在内壁一侧构成一个"区段"。围栏外部全为 black 背景。
- `Rule`：
  1. 对每个封闭围栏，将其内部空间按最近内壁边划分为四个区段（上、下、左、右）；若种子像素到两条边距离相等，则归属于水平边（上或下）优先。
  2. 找出每个区段内包含的所有种子像素；将该区段内所有 black 内部像素全部涂为该区段中种子像素的颜色（若区段内有且仅有一个种子颜色）。若某区段内无种子，则该区段保持 black。
  3. 统计每个区段内种子像素的个数 N。在围栏外壁对应边的中点位置，沿远离围栏的方向画一条长度为 N 的射线，颜色为该区段的种子颜色。
  4. 围栏本身（grey 像素）保持不变。
- `Key insight`：解题需要两层独立推理——第一层是发现种子按最近内壁归属到区段并决定区域填色；第二层是发现区段内种子数量转化为围栏外侧的射线长度，两层规则需要同时归纳才能复现输出。
</new_puzzle>

<new_puzzle>
- `description`：将网格中散落的彩色碎片按颜色配对，每对碎片合并为一个完整矩形，合并方向由隐藏在背景中的单色箭头指示。
- `Input structure`：背景为 orange。网格中存在若干对同色的不规则碎片对象（4-连通），每种前景色恰好出现两个分离的碎片。另有若干由 grey 像素绘制的单像素宽箭头形状（一个三像素长的箭杆加一个两像素的箭头尖端，形成指向上、下、左或右的箭头）。每个箭头在空间上位于某一对同色碎片之间。
- `Rule`：
  1. 对每种前景色，找到其两个碎片的包围盒，以及位于两碎片之间区域的 grey 箭头。
  2. 箭头指向的方向即为"推动方向"：将箭头所指一侧的碎片沿箭头反方向平移，直到两碎片的包围盒刚好相邻（间距为零）。
  3. 两碎片合并后的并集必须恰好构成一个实心矩形；这验证了配对和平移的正确性。
  4. 擦除所有 grey 箭头像素（变为 orange 背景），保留合并后的实心矩形。
- `Key insight`：箭头不是装饰而是操作指令——它既标识了哪两个碎片配对（空间邻近性），又指定了平移方向；解题者必须先识别箭头的朝向语义，再发现碎片互补为矩形的几何约束。
</new_puzzle>

<new_puzzle>
- `description`：网格中的彩色环形轨道上各有一个标记像素在"行驶"，输出是标记沿轨道前进若干步后的位置，步数由轨道内部包含的点阵数量决定。
- `Input structure`：背景为 black。网格中有若干由不同颜色绘制的一像素宽封闭环形轨道（每条轨道是一个由单一颜色构成的简单闭合回路，4-连通，无分支）。每条轨道上恰好有一个 red 标记像素覆盖了轨道的某个位置（该位置的原轨道颜色被 red 替换）。每条轨道的封闭内部区域（被轨道围起来的空间）中散布着若干 yellow 点像素。
- `Rule`：
  1. 对每条轨道，恢复被 red 标记覆盖位置的原轨道颜色，以识别完整轨道形状。
  2. 确定轨道的行进方向：顺时针（从轨道外部观察时，轨道内部始终在右手侧）。
  3. 统计该轨道封闭内部的 yellow 点数量 N。
  4. 将 red 标记沿顺时针方向在轨道上前进 N 步（每步移动到轨道上的下一个 4-连通相邻像素）。
  5. 在新位置放置 red 标记（覆盖该处轨道颜色），同时擦除该轨道内部所有 yellow 点（变为 black）。
  6. 不同轨道独立处理，互不影响。
- `Key insight`：解题包含三层推理——首先识别 red 像素是轨道上的可移动标记而非独立对象；其次发现轨道内部的 yellow 点数量编码了移动步数；最后需要确定统一的顺时针行进方向规则。三层信息必须同时正确归纳才能得到输出。
</new_puzzle>

<new_puzzle>
- `description`：利用网格边缘的颜色条带作为"折叠轴"的指示，将网格沿指定轴折叠后，用叠加规则合并像素颜色。
- `Input structure`：背景为 black。网格的四条边中，恰好有一条边被一整行（或一整列）的 magenta 像素覆盖，形成"折叠轴指示条"。网格的其余区域中分布着若干由不同颜色绘制的前景对象（4-连通单色区域）。折叠轴指示条将网格在该边的方向上分为两个可能不等的区域（指示条本身作为折叠轴）。
- `Rule`：
  1. 以 magenta 条带所在的行或列为折叠轴，将较小的一侧翻折到较大的一侧上（若两侧等大，则将条带远离网格中心的一侧翻折过来）。
  2. 输出网格的尺寸等于较大一侧的尺寸（不包含折叠轴本身）。
  3. 像素叠加规则：若翻折后某位置只有一侧有前景色，则保留该前景色；若两侧都有前景色，则保留原本在较大侧的颜色；若两侧都是背景色，则保持 black。
  4. 翻折时超出较大侧边界的像素被丢弃。
- `Key insight`：解题的核心在于首先识别 magenta 边缘条带的"折叠轴"语义（而非装饰边框），然后理解折叠的方向性（小侧折向大侧），最后掌握叠加时的优先级规则。折叠操作本身在视觉上并不直观，需要解题者从输入输出对中反向推断出空间翻转关系。
</new_puzzle>

<new_puzzle>
- `description`：每个彩色对象根据其自身包含的"缺口方位"确定投影方向，再根据与网格中唯一图例色块的颜色层级关系确定投影的颜色替换。
- `Input structure`：背景为 azure。网格左上角有一个由 grey 边框围成的小矩形图例区，内部包含 2-4 个不同颜色的单像素点，从上到下排列形成颜色优先级序列（最上方优先级最高）。网格其余区域中分布着若干一像素宽的矩形环（中空矩形框），每个环使用图例中出现的某种颜色。每个矩形环在其四条边之一上恰好有一个一像素宽的缺口（缺失一个像素）。
- `Rule`：
  1. 对每个矩形环，找到其缺口所在的边（上、下、左、右），缺口的对面方向即为"投影方向"。
  2. 将该矩形环内部的空心区域沿投影方向平移投射出去：从矩形环的投影方向外壁开始，向外绘制一个与内部空心区域等宽等高的实心矩形色块。
  3. 投射色块的颜色由图例决定：在图例的优先级序列中，找到该矩形环颜色的下一级颜色（即图例中紧接其后的颜色），用该下一级颜色绘制投射色块。若矩形环颜色是图例中最末位的颜色，则投射色块使用图例中最顶级的颜色（循环）。
  4. 原矩形环（含缺口）保持不变，图例区保持不变。投射色块若超出网格边界则截断。
- `Key insight`：本题需要三层推理——第一层从缺口位置推断投影方向（缺口对面）；第二层理解投影的几何形状（内部空腔的尺寸决定投射块大小）；第三层从图例的排列顺序中归纳出颜色循环替换规则。单独看任何一层都较简单，但三层叠加后解题者需要同时把握方向、几何和颜色映射三种关系。
</new_puzzle>
