根据框架内部缺失边的方位，从外部候选色块中选取朝向匹配的色块，将其颜色填入框架围合的封闭区域。

Input structure：
- 背景为黑色。
- 网格中散布若干由同一颜色（如 blue）绘制的矩形框架，每个框架恰好缺失一条边（即四边中有一边完全缺失，形成一个 U 形开口）。
- 框架内部区域全部为黑色背景。
- 在所有框架的外部，散布若干单色小方块（2x2），每个小方块的颜色各不相同。每个小方块恰好紧贴某一个框架的外侧，且紧贴的那一面正对该框架的缺失边所在方位。
- 也存在一些小方块紧贴在框架的完整边外侧，这些是干扰项。

Rule：
- 对每个框架，找到其缺失边的方位（上、下、左、右）。
- 在紧贴该框架外侧的所有小方块中，找到位于缺失边对面方位的那个小方块（即：若缺失边在上方，则选取紧贴框架下方外侧的小方块；若缺失边在左方，则选取紧贴框架右方外侧的小方块）。
- 用该小方块的颜色填充框架内部的全部黑色区域。
- 框架本身的颜色、所有小方块均保持不变。

Key insight：
- 缺失边的方位不是直接指向填充色源，而是需要取其对面方位——开口朝上的框架要去下方找色源。紧贴完整边的小方块是干扰项，解题者需要先判断缺失边方位，再做方向反转，才能确定正确的颜色来源。
</description>

<description>
将网格中每个封闭区域内的彩色种子图案，按照周期性平铺的方式填满整个封闭区域。

Input structure：
- 背景为黑色。
- 网格中有若干由 grey 颜色绘制的不规则封闭轮廓（轮廓线宽为 1 像素，完全封闭，内部无 grey 像素）。
- 每个封闭区域的左上角有一个小的矩形彩色种子图案（由非黑非灰的颜色组成，例如 red、green、yellow 等），种子图案占据封闭区域左上角的一个小矩形子区域。
- 封闭区域中种子图案以外的内部区域全部为黑色。

Rule：
- 对每个封闭区域，提取其左上角的种子图案（即从封闭区域内部左上角开始，向右向下扫描直到遇到全黑行或全黑列，得到种子矩形）。
- 将该种子图案作为周期性瓦片，向右和向下平铺，填满整个封闭区域的内部。平铺时超出封闭区域边界的部分裁剪掉。
- grey 轮廓线保持不变，黑色背景保持不变。

Key insight：
- 种子图案并非独立对象，而是嵌入在封闭区域内部的纹理模板。解题者需要先识别封闭区域边界，再从区域内部分离出种子，最后理解种子是被周期平铺而非缩放。不同封闭区域的种子大小和颜色各不相同，进一步确认平铺机制的独立性。
</description>

<description>
网格中的彩色路径段按颜色分组后，每组路径段首尾相连形成完整路径；路径的连接顺序由路径段的长度从长到短排列决定，连接处用 maroon 像素标记转折点。

Input structure：
- 背景为黑色。
- 网格中散布若干条水平或垂直的单色直线段（长度至少为 2 像素），每种非黑颜色恰好出现 2 到 4 条线段。
- 同色线段之间互不接触，且不同颜色的线段之间也互不接触。
- 每条线段的两个端点（即线段最外侧的两个像素）附近的空间足够放置连接路径。

Rule：
- 对每种颜色，将该颜色的所有线段按长度从长到短排序。
- 按排序顺序依次连接：第一条（最长）线段的右端点或下端点连接到第二条线段的左端点或上端点，使用与该颜色相同的 L 形单像素宽路径（先沿原方向延伸，再转弯到达目标端点）。
- 具体连接规则：从源线段的末端沿该线段方向延伸，直到与目标线段的起始端在同一行或同一列，然后转 90 度直行到达目标起始端。
- 在每个 L 形转弯处（即方向改变的那个像素），将该像素改为 maroon 颜色。
- 原始线段保持不变。

Key insight：
- 解题者需要两步非显然的归纳：第一步是发现同色线段的连接顺序取决于长度排序（而非空间邻近度）；第二步是发现连接路径固定为 L 形且转弯点被特殊标记。长度排序在视觉上不明显，需要解题者主动测量和比较。
</description>

<description>
网格被分为上下两半：上半部分包含若干彩色形状和一个颜色图例条；下半部分包含与上方形状完全相同的灰色轮廓。根据图例条将每个灰色轮廓重新着色，着色依据是该形状在上半部分中与图例条各色段的相对水平位置对齐关系。

Input structure：
- 网格由一条水平的 azure 分隔线分为上下两半。
- 上半部分的最顶行是一条颜色图例条：由若干段不同颜色的连续水平色块组成（例如从左到右依次为 red 段、green 段、yellow 段），每段占据若干连续列，各段之间无间隔。
- 图例条下方、分隔线上方的区域包含若干彩色形状（4-连通，颜色各异），每个形状恰好有一种非背景非 azure 的颜色。
- 下半部分包含与上方形状形状完全相同（像素级一致）的轮廓，但所有轮廓统一为 grey 颜色。下方轮廓的水平位置与上方对应形状相同，垂直位置则是上方形状关于分隔线的镜像。
- 背景为黑色。

Rule：
- 对下半部分的每个 grey 轮廓，找到上半部分中与其形状匹配的彩色形状。
- 计算该彩色形状的水平中心列（即其包围盒的水平中点列）。
- 查看图例条中该列所属的颜色段，获取该颜色。
- 将下半部分对应的 grey 轮廓全部重新着色为该图例颜色。
- 上半部分保持不变。

Key insight：
- 上方形状自身的颜色是干扰项——它与输出无关。真正决定下方轮廓颜色的是形状在水平方向上对应到图例条的哪个色段。解题者需要先忽略形状原色，再发现图例条的列映射关系，这构成了两层独立的推理。
</description>

<description>
网格中有若干对形状相同但大小不同的同色对象；将每对中较小的对象移入较大对象内部预留的空洞中，小对象原位置清除为背景。

Input structure：
- 背景为黑色。
- 网格中有若干单色 4-连通对象，颜色包括 red、blue、green 等，每种颜色恰好出现两个对象。
- 同色的两个对象形状相同（像素级几何相似），但大小不同：一个是另一个的整数倍缩放（例如 2 倍或 3 倍）。较大对象内部全部填充为该颜色（实心），较小对象同样为实心。
- 每个较大对象内部恰好有一个由背景色（黑色）构成的矩形空洞，空洞的大小恰好等于较小对象的包围盒大小。

Rule：
- 对每种颜色，识别该颜色的大对象和小对象（通过像素数量比较）。
- 将小对象从原位置移除（设为黑色背景）。
- 将小对象放置到大对象内部的黑色空洞中，使小对象的包围盒与空洞完全对齐。小对象的颜色保持不变，填入空洞后与大对象颜色相同，视觉上空洞被填满。
- 若小对象形状与空洞形状不完全匹配（小对象有凹凸而空洞是矩形），则小对象像素填入对应位置，空洞中未被小对象覆盖的像素保持黑色。

Key insight：
- 表面上看这是一个形状匹配和移动任务，但核心推理在于：同色配对不是通过空间邻近而是通过形状相似性；移动目标不是任意位置而是大对象内部预留的空洞。解题者需要先发现大小对象的同色配对关系，再发现大对象内部空洞的存在及其作为"插槽"的功能。
</description>

<description>
网格中包含若干由边框围成的房间和房间外的彩色钥匙；每个房间的边框上有一个单像素缺口标记，缺口的颜色指示该房间需要哪把钥匙；将匹配钥匙的颜色填入房间内部，同时缺口像素恢复为边框颜色以封闭房间。

Input structure：
- 背景为黑色。
- 网格中有若干矩形房间，每个房间由 grey 边框围成（边框宽 1 像素，完全封闭），但每个房间的边框上恰好有一个像素不是 grey，而是某种彩色（如 red、blue、green 等），该彩色像素即为缺口标记。
- 房间内部全部为黑色背景。
- 房间外部的背景中散布若干小的彩色对象（每个对象为 3 到 5 像素的 4-连通区域），这些是钥匙。每把钥匙有唯一颜色，钥匙颜色与某个房间缺口颜色一一对应。
- 钥匙的形状各不相同，但形状信息在此题中不参与规则。

Rule：
- 对每个房间，找到其边框上唯一的彩色（非 grey）像素，记录该颜色。
- 在房间外部找到相同颜色的钥匙对象。
- 将该房间内部所有黑色像素填充为钥匙的颜色。
- 将房间边框上的缺口像素（原来是彩色）改为 grey，使边框完整。
- 钥匙对象从原位置移除（设为黑色背景）。
- 没有对应房间的多余钥匙保持不变。

Key insight：
- 边框上的"瑕疵"像素不是损坏而是编码信息——它既标识了该房间需要的颜色，也暗示了"开锁-填充-关锁"的三步操作。解题者需要先发现边框上的单个异色像素是有意义的标记而非噪声，再将其与外部钥匙颜色进行配对，最后理解缺口在填充后会被修复。
</description>

<description>
网格中有一个中心多色图案和环绕四周的单像素箭头标记；每个箭头指向中心图案的一行或一列，该行或列中的像素按箭头所指方向循环移位，移位步数等于该箭头颜色在整个网格中出现的总次数。

Input structure：
- 背景为黑色。
- 网格中央有一个矩形多色图案（不含黑色，由 red、blue、green、yellow 等颜色组成）。
- 图案的上方、下方、左方、右方各有若干单像素箭头标记，箭头由一个像素表示，颜色非黑且非图案使用的颜色（例如 orange、magenta、azure、maroon）。
- 上方和下方的箭头位于图案某一列的正上方或正下方，表示作用于该列。左方和右方的箭头位于图案某一行的正左方或正右方，表示作用于该行。
- 上方箭头表示该列向上循环移位，下方表示向下，左方表示该行向左，右方表示向右。
- 同一种箭头颜色可能出现多次（作用于不同行或列）。

Rule：
- 统计每种箭头颜色在整个网格中出现的总次数，该次数即为该颜色所有箭头的移位步数。
- 对每个箭头，将其指向的那一行或那一列（仅限中心图案范围内的像素）按箭头方向循环移位，步数为该箭头颜色的总出现次数。
- 若同一行或同一列被多个箭头作用，按从外到内的顺序依次执行（先执行离图案更远的箭头）。
- 箭头标记本身在输出中移除（设为黑色），仅保留变换后的中心图案。

Key insight：
- 移位步数不是直接编码在箭头的位置或大小中，而是通过"同色箭头的全局计数"间接编码。解题者需要先发现箭头颜色与移位方向和目标行列的关系，再发现移位步数来自该颜色箭头的全局出现次数——这两步归纳构成独立的推理层。
</description>
</new_puzzle>
