- `Input structure`：
  - 背景色为 black。
  - 网格中有若干条直线段路径（水平或垂直），每条路径由单一颜色绘制，颜色各不相同，长度各不相同。路径段之间不直接相连，它们散布在网格各处。
  - 网格中还有若干个 2×2 的"路口方块"，每个路口方块由四个像素组成，排列方式为：左上和右下为同一颜色 A，右上和左下为同一颜色 B（对角线配色）。颜色 A 和 B 各对应一条路径段的颜色。
  - 路口方块的数量恰好等于路径段数量减一（即 N 条路径段对应 N-1 个路口方块，形成一条链）。

- `Rule`：
  - 第一步（建立连接链）：每个路口方块的两种对角颜色分别指向两条路径段，表示这两条路径段在最终输出中首尾相接。通过所有路口方块，可以将所有路径段串成一条唯一的链（起点和终点路径段各只出现在一个路口方块中，中间段各出现在两个路口方块中）。
  - 第二步（确定朝向）：在路口方块中，左上-右下对角线颜色对应的路径段提供"入方向"，右上-左下对角线颜色对应的路径段提供"出方向"。水平路径段在链中连接时保持水平，垂直路径段保持垂直。相邻两段必须形成直角转弯（水平接垂直，垂直接水平）。
  - 第三步（拼装输出）：从链的起点开始，将路径段依次首尾相连地绘制在输出网格上。起点路径段从输出网格的左上角 (0,0) 开始绘制。每条路径段保持原始颜色和长度，转弯处的像素为两条路径段共享的角点像素，该像素取后一条路径段的颜色。
  - 输出网格大小恰好包含整条重组路径的边界框。

- `Key insight`：路口方块的对角线配色模式不仅编码了哪两条路径段相连，还通过对角线方向编码了连接的先后顺序——解题者需要从分散的信号灯方块中读取拓扑链和方向信息，才能正确拼装路径。
