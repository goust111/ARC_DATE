<description>
根据封闭区域内标记像素的颜色，从色带图例中查找对应条纹宽度，再用该宽度将封闭区域填充为水平条纹。

Input structure:
- 背景为最常见颜色（如 black）。
- 网格中有若干由同一种边框颜色（如 grey）围成的封闭矩形区域，每个区域内部恰好包含一个非背景、非边框颜色的标记像素（颜色各不相同，如 red、blue、green 等）。
- 网格的一侧（如最底部几行）有一个色带图例区域，图例区域由与封闭区域相同的边框颜色围成。图例内部排列着若干水平色条，每种颜色占据不同的行数（即条纹宽度），颜色与封闭区域内的标记像素颜色一一对应。色条之间无间隔，紧密排列。

Rule:
- 对每个封闭矩形区域，读取其内部标记像素的颜色。
- 在色带图例中找到该颜色对应的色条，数出该色条占据的行数 W。
- 用该标记颜色以宽度 W 的水平条纹（从区域顶部开始，交替填充标记颜色和背景颜色，每段宽度为 W 行）填满整个封闭区域的内部。
- 色带图例区域本身在输出中保持不变。

Key insight:
第一层推理需要识别色带图例中每种颜色对应的条纹宽度（即该色条占据的行数）；第二层推理需要发现封闭区域的填充方式是用对应宽度的水平条纹交替铺满。图例的作用不是直接复制图案，而是编码了一个数值参数（宽度），该参数控制填充的密度。
</description>

<description>
将网格中散落的 L 形碎片按颜色配对拼合成完整矩形，再按矩形面积从小到大沿指定方向堆叠排列。

Input structure:
- 背景为最常见颜色（如 black）。
- 网格中散布着若干 L 形（即从一个矩形中切去一个角上的矩形所得的形状）前景对象，每种颜色恰好出现两个 L 形碎片。
- 网格边缘有一条单像素的方向指示线（如顶部一整行 maroon 像素），指示堆叠方向（顶部 → 向下堆叠，左侧 → 向右堆叠，以此类推）。

Rule:
- 将同色的两个 L 形碎片拼合：它们恰好能互补拼成一个完整的实心矩形（一个是另一个的缺角补块）。记录每对拼合后矩形的宽和高。
- 按矩形面积从小到大排序（面积相同则按矩形高度从小到大排序）。
- 从方向指示线的对侧边缘开始，按排序结果依次紧贴放置这些矩形。矩形之间无间隔，每个矩形左对齐（若水平堆叠则底对齐）。
- 输出网格的尺寸恰好容纳所有堆叠后的矩形，背景填充。

Key insight:
第一层推理需要发现同色的两个 L 形碎片可以互补拼成矩形，这要求解题者在空间上"旋转并拼合"两个不规则形状；第二层推理需要发现拼合后的矩形按面积排序并堆叠，输出尺寸由堆叠结果决定。碎片的原始位置和朝向是干扰信息，真正有意义的是它们拼合后的矩形尺寸。
</description>

<description>
将每个前景对象沿其内部"裂缝线"一分为二，然后根据裂缝线上标记点的颜色决定哪半部分保留、哪半部分被擦除。

Input structure:
- 背景为最常见颜色（如 black）。
- 网格中有若干大型单色前景对象（如 blue、green、red），每个对象内部恰好被一条由背景色构成的单像素宽直线（水平或垂直）贯穿，将对象分成两半——这条线称为"裂缝线"。
- 每条裂缝线上恰好有一个非背景、非对象颜色的标记像素（如 yellow、orange）。
- 网格角落有一个 2x2 的图例块：左上和右下各一个像素为背景色，另外两个像素分别为两种标记颜色。图例中标记颜色所在的位置（左下 vs 右上）编码了保留规则的方向。

Rule:
- 对每个被裂缝线分割的对象，确定裂缝线的方向（水平或垂直）以及标记像素在裂缝线上的位置。
- 查看图例：如果标记颜色在图例中位于左下角，则保留该标记颜色所在裂缝线以下（水平裂缝）或以左（垂直裂缝）的半部分；如果标记颜色在图例中位于右上角，则保留以上或以右的半部分。
- 被擦除的半部分变为背景色，裂缝线和标记像素也变为背景色，保留的半部分颜色不变。

Key insight:
第一层推理需要识别对象内部的背景色直线是"裂缝"而非普通间隙，并注意裂缝上的标记像素；第二层推理需要破解角落图例的编码——标记颜色在图例中的空间位置（左下 vs 右上）映射为保留方向（下/左 vs 上/右），这是一个非平凡的空间-语义映射。
</description>

<description>
在由路径网络连通的节点图中，根据每个节点的连通度（与之相连的路径条数）选择对应的填充图案来填充该节点区域。

Input structure:
- 背景为最常见颜色（如 black）。
- 网格中有若干由同一颜色（如 grey）绘制的空心正方形节点（大小相同，如 5x5），节点之间由单像素宽的同色（grey）直线路径连接（水平或垂直）。
- 每个节点内部（3x3 区域）初始为背景色。
- 网格的一角有一个图案字典区域：包含若干小方块（与节点内部大小相同，如 3x3），每个小方块展示一种独特的填充图案（用不同前景色绘制），这些图案方块从左到右排成一行，按顺序分别对应连通度 1、2、3、4。

Rule:
- 计算每个节点的连通度（即有多少条灰色路径从该节点的四条边向外延伸连接到其他节点）。
- 在图案字典中，第 k 个图案对应连通度 k。
- 将对应连通度的图案复制到该节点的内部 3x3 区域。
- 图案字典区域本身在输出中保持不变。

Key insight:
第一层推理需要理解图案字典中图案的排列顺序对应一个递增的数值（连通度），而不是对应颜色或位置；第二层推理需要为每个节点数出连接的路径条数并正确匹配图案。路径网络的拓扑结构是视觉上可以直接追踪的，但连通度与图案的对应关系需要从多个样例中归纳。
</description>

<description>
识别网格中每个对象的对称缺陷像素，将缺陷像素修复以恢复点对称，同时在边框上标记缺陷位置的行列投影。

Input structure:
- 背景为最常见颜色（如 black）。
- 网格中有若干互不接触的单色前景对象，每个对象几乎关于自身中心点呈 180 度旋转对称（点对称），但恰好有一个像素破坏了对称性——该像素要么多出来（在对称位置没有对应像素），要么缺失（对称位置应有像素却是背景色）。
- 每个对象的颜色各不相同。
- 网格边缘有一圈单像素宽的边框，颜色为 grey。

Rule:
- 对每个对象，找到其几何中心（最小包围矩形的中心），检测破坏 180 度旋转对称的那个缺陷像素的位置。
- 如果缺陷是"多出的像素"，则在输出中将该像素移除（变为背景色）并将其对称位置补上对象颜色，使对象恢复完美对称。
- 同时，在灰色边框上，缺陷像素所在行的左右边框像素和所在列的上下边框像素都被重新着色为该对象的颜色，形成一个指向缺陷位置的十字准星。
- 对象本身（修复后的对称版本）保留在原位。

Key insight:
第一层推理需要发现每个对象"几乎对称"并定位那个打破对称的像素——这要求解题者对每个对象做心理旋转比对；第二层推理需要理解边框上的彩色标记是缺陷位置的行列投影，形成十字准星指示系统。修复对称和投影标记是两个独立但耦合的输出变化。
</description>

<description>
根据种子像素在封闭房间内的反弹轨迹，用颜色序列逐段着色路径，每次碰壁时切换颜色并顺时针转弯。

Input structure:
- 背景为最常见颜色（如 black）。
- 网格中有若干由 grey 像素构成的封闭矩形房间（空心矩形），房间墙壁为单像素宽。
- 每个房间内部恰好有一个非背景、非灰色的种子像素，位于房间内壁的某一侧（紧贴某面墙），种子像素的颜色为路径的起始颜色。
- 种子像素紧贴的那面墙上，与种子像素相邻的墙壁像素被替换为另一种非灰色颜色——这个颜色指示种子像素的初始运动方向：该墙壁像素相对于种子像素的方位即为初始前进方向（如墙壁标记在种子上方，说明种子紧贴上墙，初始方向为向下）。
- 网格一角有一个颜色序列条：一行若干不同颜色的像素，从左到右定义颜色循环顺序。

Rule:
- 种子像素从初始位置沿初始方向直线移动，逐格绘制路径。
- 路径颜色从颜色序列条的第一个颜色开始；每次路径碰到墙壁（即下一步将进入灰色墙壁像素），路径像素在碰壁点停下，颜色切换为序列中的下一个颜色，方向做 90 度顺时针转弯，继续前进。
- 如果颜色序列用完，则循环回到序列开头。
- 如果转弯后前方仍为墙壁，则路径终止。
- 种子像素原始位置也被路径覆盖。

Key insight:
第一层推理需要从墙壁上的方向标记推断种子的初始运动方向（标记所在墙面的法线方向指向房间内部）；第二层推理需要理解碰壁时固定顺时针转弯并按颜色序列条切换颜色；第三层需要将颜色序列条识别为循环调色板。路径本身是确定性的弹球轨迹，但颜色变化的规律需要从样例中归纳。
</description>

<description>
将网格中的彩色"信号塔"像素沿其所在行和列广播信号线，信号线在交叉点处按颜色优先级规则决定显示哪种颜色。

Input structure:
- 背景为最常见颜色（如 black）。
- 网格中散布着若干单像素的"信号塔"，每个信号塔有不同颜色（如 red、blue、green、yellow 等，颜色可重复）。
- 网格的最右列自上而下排列着若干颜色样本（每个颜色占一个像素，之间用背景色隔开），定义颜色优先级：越靠上优先级越高。

Rule:
- 每个信号塔沿其所在行向左右、所在列向上下发射信号线，信号线用信号塔的颜色绘制，覆盖背景像素，直到碰到网格边缘。
- 信号线不会覆盖信号塔本身以及其他信号塔。
- 当两条不同颜色的信号线交叉于同一像素时，保留优先级更高的颜色（根据右列的颜色优先级排列）。
- 优先级列本身在输出中保持不变。

Key insight:
第一层推理需要理解每个信号塔发射十字形信号线的机制；第二层推理需要发现交叉点的颜色冲突不是简单覆盖或混合，而是由网格边缘的优先级图例决定的。优先级的编码方式（位置越高优先级越高）需要从多个样例中的交叉冲突结果反推得出。
</description>
</new_puzzle>
