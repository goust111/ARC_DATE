<description>
根据框架内部缺口的朝向，从外部候选色板中选取对应颜色，将框架内的空心区域填充为该颜色。

Input structure:
- 背景为主色（如 black）。网格中有若干个大小相同的矩形空心框架，每个框架由同一种颜色绘制，但每个框架的颜色各不相同。
- 每个框架的边框上恰好有一个单像素宽的缺口，缺口位于上、下、左、右四条边中的某一条。
- 网格的四条边缘（上边缘、下边缘、左边缘、右边缘）各放置一个由两行或两列像素组成的色板条。每个色板条包含若干颜色块，每个颜色块为一个像素。色板条的位置（上/下/左/右边缘）对应缺口的朝向（缺口朝上则使用上边缘色板）。
- 每个色板条中的颜色块数量等于缺口朝向该方向的框架数量。色板条中颜色块的排列顺序与对应框架沿垂直于缺口方向的坐标排序一致（例如缺口朝上的框架，按其水平中心坐标从左到右排序，对应上边缘色板从左到右的颜色块）。

Rule:
- 确定每个框架的缺口朝向（上、下、左、右）。
- 根据缺口朝向，找到网格对应边缘的色板条。
- 将该方向上的所有框架按垂直于缺口方向的坐标排序，与色板条中的颜色块一一对应。
- 用对应的颜色填充该框架内部的所有背景像素（缺口本身保持不变，框架边框保持不变）。

Key insight:
缺口朝向是一个两层索引的关键：第一层决定查哪个边缘色板，第二层通过空间排序确定色板中的哪个颜色块，两层索引缺一不可。
</description>

<description>
将散布在网格中的彩色碎片视为拼图块，根据它们边缘轮廓的互补性拼合成若干完整矩形，并将每个矩形平移至其锚点标记处。

Input structure:
- 背景为主色（如 black）。网格中散布着若干个由非背景色组成的不规则连通区域（碎片），每个碎片由单一颜色构成。
- 每对可拼合的碎片使用相同颜色，且整个网格中同一颜色恰好出现两个碎片。
- 网格中另有若干个由 grey 像素组成的小十字标记（一个中心像素加上下左右各一个像素），每个十字标记对应一对同色碎片。十字标记的颜色（grey）与任何碎片颜色都不同。
- 每对碎片拼合后恰好形成一个与十字标记大小无关的实心矩形。拼合方式为：将两个碎片的边界裁剪框对齐，一个碎片的前景像素恰好填充另一个碎片裁剪框内的背景像素。

Rule:
- 找到所有同色碎片对。对每一对，将两个碎片裁剪到各自的最小外接矩形。
- 将两个裁剪后的碎片叠加（前景像素互补、不重叠），形成一个完整的实心矩形，矩形颜色为该对碎片的颜色。
- 找到与该颜色对关联的 grey 十字标记。关联规则：十字标记按从上到下、从左到右的顺序排列，碎片对也按其第一个碎片（最上方且最左方的）从上到下、从左到右排列，两者一一对应。
- 将拼合后的矩形放置在十字标记的中心位置（矩形中心与十字中心对齐）。清除原始碎片和十字标记。

Key insight:
碎片的颜色配对是第一层推理；碎片边缘的互补拼合是第二层推理；十字标记与碎片对的空间排序对应关系是第三层推理。三层结构使得仅看单个样例很难确定完整规则。
</description>

<description>
在包含多个嵌套矩形环的网格中，根据每个环的层级深度决定其旋转方向，将环上的彩色标记像素沿环边界顺时针或逆时针移动固定步数。

Input structure:
- 背景为主色（如 black）。网格中心有若干层同心嵌套的单像素宽矩形环，每层环使用不同颜色，环与环之间间隔一个像素的背景色。
- 最外层环为第 1 层，向内依次为第 2、3、... 层。
- 每个环上有一个或多个标记像素，标记像素的颜色与该环颜色不同（也与背景色不同），标记像素位于环的边框路径上。

Rule:
- 识别所有嵌套矩形环及其层级（从外向内编号 1, 2, 3, ...）。
- 奇数层的标记像素沿环边界顺时针移动 2 步；偶数层的标记像素沿环边界逆时针移动 2 步。移动沿环的像素路径计算（沿环的上边从左到右、右边从上到下、下边从右到左、左边从下到上为顺时针方向）。
- 环本身的颜色和位置保持不变，仅标记像素的位置发生变化。标记像素移动后仍保持在同一个环的边框路径上。

Key insight:
识别嵌套层级并为奇偶层分配不同旋转方向是核心推理。解题者必须先从样例中发现层级与旋转方向的奇偶对应关系，再确定步数——两者都无法从单个样例中同时确认。
</description>

<description>
网格中的每个封闭区域内含有一个"种子图案"和一个"方向箭头"；将种子图案沿箭头方向平铺复制，直到填满整个封闭区域。

Input structure:
- 背景为主色（如 black）。网格中有若干由 grey 像素绘制的不规则但封闭的围墙区域（围墙为单像素宽的连通闭合曲线，内部为背景色）。
- 每个围墙内部包含两个元素：（a）一个由某种非背景、非 grey 颜色组成的小型连通图案（种子图案），位于围墙内部的某个位置；（b）一个由 red 像素组成的 L 形箭头标记，由两段垂直线段组成——较长的一段表示主方向（水平或垂直），较短的一段（长度为 1 像素）连接在较长段的一端并垂直于主方向，形成箭头尖端，箭头尖端所指方向即为平铺方向。
- 种子图案的外接矩形能整除围墙内部区域在平铺方向上的长度。

Rule:
- 对每个围墙区域，识别其内部的种子图案和箭头方向。
- 将种子图案的外接矩形作为瓦片单元。
- 从种子图案当前位置开始，沿箭头指向的方向反复复制瓦片单元，直到到达围墙边界。每次复制时，新瓦片紧接前一个瓦片放置（无间隔）。
- 移除 red 箭头标记（恢复为背景色）。围墙保持不变。

Key insight:
解题者需要先识别 L 形标记的方向编码方式（较短端指向平铺方向），再理解种子图案是瓦片单元而非装饰物。箭头解码和瓦片平铺是两个独立的非显然推理层。
</description>

<new_puzzle>
<description>
网格中有多个相同形状但不同颜色的物体，以及一个由线段连接的"颜色交换图"；根据交换图中的连接关系，将每个物体的颜色替换为图中与其相连的另一种颜色。

Input structure:
- 背景为主色（如 black）。网格分为两个区域，由一条完整的 grey 水平分隔线隔开。
- 上方区域包含若干个形状完全相同的小型连通物体（例如都是 T 形或 Z 形），每个物体由单一非背景色填充，不同物体颜色不同。同一颜色可能出现在多个物体上。
- 下方区域是"颜色交换图"：若干个 2x2 的实心色块散布在下方区域中，每个色块的颜色与上方某个物体的颜色相同。部分色块之间由单像素宽的 maroon 线段（水平或垂直）连接。每个色块最多连接一条线段，且线段总是连接恰好两个不同颜色的色块，形成一一配对关系。
- 未被线段连接的色块（如果有）对应的物体颜色保持不变。

Rule:
- 解析下方区域的颜色交换图：找到所有通过 maroon 线段连接的色块对，读取每对的两种颜色，建立双向颜色交换映射（A↔B 表示颜色 A 换为 B，颜色 B 换为 A）。
- 对上方区域的每个物体，查找其颜色在交换映射中的对应颜色，将整个物体重新填充为映射后的颜色。
- 若物体颜色未出现在任何交换对中，则保持不变。
- 下方区域（包括色块和连接线段）在输出中保持不变。

Key insight:
解题者必须先在下方区域中识别出"图"的结构——色块是节点、线段是边——然后将图的连接关系解读为颜色交换指令，最后将指令应用到上方的物体上。从视觉图结构中提取抽象映射关系是核心难点。
</description>
</new_puzzle>
