- `description`：根据框架内部图案的对称性缺陷方向，选择对应颜色图例，将框架边框重新着色。

- `Input structure`：
  - 背景为 black。
  - 网格左侧或顶部有一个颜色图例区：包含若干小色块，每个色块旁边有一个用 grey 像素画出的微型箭头（由三个像素组成：一个轴像素和两个翼像素构成指向上/下/左/右的箭头头部）。每个箭头指向一个基本方向（上、下、左、右），箭头旁的色块颜色各不相同。
  - 网格主区域有若干个用 maroon 像素画出的正方形空心框架（边长 5-7），框架内部填充了一个由某种前景色构成的近似四重对称图案。
  - 每个框架内部图案恰好在一个方向上有一处对称性缺陷：即将图案沿水平轴或垂直轴翻转后，只有一侧存在一个多出或缺少的像素，导致图案在该方向上不对称。

- `Rule`：
  - 对每个 maroon 框架，检查其内部图案的对称性。找到图案不对称的那个方向（上、下、左、右中的一个），即缺陷所在的方向。
  - 在颜色图例中找到箭头指向该方向的条目，取该条目的色块颜色。
  - 将该框架的 maroon 边框像素全部重新着色为该颜色。框架内部的图案保持不变。
  - 图例区域在输出中保持原样。

- `Key insight`：解题者需要先发现每个框架内的图案并非完美对称，然后判断不对称缺陷偏向的方向，再将该方向与图例中箭头方向匹配以确定框架应被重新着色的颜色。两步推理——识别对称缺陷方向和方向-颜色映射——缺一不可。
</new_puzzle>

- `description`：将散落的彩色碎片沿各自颜色的"传送带轨道"滑动到终点槽位，碎片叠加时按轨道优先级决定可见颜色。

- `Input structure`：
  - 背景为 grey。
  - 网格中有若干条由 azure 像素构成的单像素宽 L 形或直线轨道，每条轨道的一端标记有一个独特颜色的终点像素（如 red、green、blue 等），另一端为轨道起始端（无特殊标记）。
  - 轨道上散布着若干与该轨道终点颜色相同的单像素碎片，碎片位于轨道的 azure 像素的 4-邻接位置（碎片本身不在轨道上，而是紧贴轨道旁边）。
  - 不同轨道可能交叉，但终点像素颜色各不相同。

- `Rule`：
  - 对每条轨道，找到所有与该轨道 4-邻接的同色碎片。
  - 每个碎片沿其所贴邻的轨道方向（朝终点方向）滑动，直到到达终点像素的 4-邻接位置（即终点旁边的空位）。多个碎片到达同一终点时，依次堆叠在终点延伸方向上（先到的离终点最近）。
  - 碎片从原位置消失（恢复为背景色）。
  - 轨道的 azure 像素保持不变。
  - 如果两条轨道交叉处有碎片堆叠，按轨道终点像素在网格中从上到下、从左到右的顺序决定优先级，优先级高的颜色显示在该像素位置。

- `Key insight`：解题者必须先识别每条轨道的走向和终点，再将碎片与正确的轨道关联（通过颜色匹配），最后沿轨道方向移动碎片到终点附近。轨道的 L 形拐弯使滑动方向在途中改变，而交叉处的优先级规则需要从多个样例中归纳出排序标准。
</new_puzzle>

- `description`：根据封闭区域内标记像素的数量，从嵌套的同心框架中由内向外逐层剥离，保留对应层数的框架。

- `Input structure`：
  - 背景为 black。
  - 网格中有若干组嵌套的同心空心矩形框架，每组由 2 到 4 层框架组成，所有框架使用同一种颜色（如 blue），各层框架之间间隔一个像素的 black 间隙。
  - 每组嵌套框架的最内层区域（最内层框架围成的空间）包含若干个 red 标记像素，数量为 1 到 4 不等。
  - 网格中可能有多组嵌套框架，各组之间不相连。

- `Rule`：
  - 对每组嵌套框架，数出其最内层区域中 red 标记像素的数量 N。
  - 从最内层开始，保留最内侧的 N 层框架（连同它们之间的间隙），将外侧多余的框架层擦除为背景色。
  - red 标记像素本身在输出中也被擦除为背景色。
  - 例如：若有 4 层嵌套框架，内部有 2 个 red 像素，则保留最内侧 2 层框架，擦除外侧 2 层。

- `Key insight`：解题者需要先理解"同心嵌套框架"的层数结构，然后发现内部 red 像素的数量不是用于填充或着色，而是作为"保留多少层"的计数器。剥离方向是从内向外保留（而非从外向内），这与直觉相反，增加了隐蔽性。
</new_puzzle>

- `description`：将网格中的每个彩色形状投影到由同色锚点线段指定的镜面上，生成镜像副本，再根据形状内部孔洞的位置对副本进行局部擦除。

- `Input structure`：
  - 背景为 black。
  - 网格中有若干个由不同颜色构成的小型连通形状（3-8 个像素），每个形状内部可能包含 0 或 1 个 black 孔洞像素（即形状中间缺少一个像素）。
  - 每种前景色在网格中除了该形状外，还有一条由相同颜色构成的直线段（水平或垂直，长度 3-5 像素），作为该颜色的镜面线段。镜面线段与其对应形状不 4-连通。
  - 不同颜色的形状和镜面线段之间互不重叠。

- `Rule`：
  - 对每个彩色形状，找到同色的镜面线段。
  - 将形状相对于镜面线段做镜像反射，在镜像位置绘制该形状的副本（使用相同颜色）。
  - 如果原始形状内部有一个孔洞，确定孔洞在形状局部坐标中的位置；在镜像副本中，将对应位置的像素擦除为背景色（即副本也带有同位置的孔洞）。
  - 如果原始形状没有孔洞，则额外操作：将镜像副本的重心位置（副本所有像素坐标的平均值，四舍五入到最近整数）的那个像素擦除为背景色，人为制造一个孔洞。
  - 原始形状和镜面线段在输出中保持不变。

- `Key insight`：第一层推理是识别颜色配对关系（形状与同色线段配对）并执行镜像反射。第二层推理是发现孔洞的传递规则：有孔洞的形状保留孔洞位置，无孔洞的形状在副本中心生成新孔洞。解题者需要从样例中同时归纳出镜像机制和孔洞生成的条件分支。
</new_puzzle>

- `description`：利用网格边缘的彩色种子像素沿行列射线扫描，在射线交汇处生成混合色标记，最后用交汇标记围成的区域填充特定颜色。

- `Input structure`：
  - 背景为 yellow。
  - 网格的四条边缘（第一行、最后一行、第一列、最后一列）上散布着若干彩色种子像素，颜色包括 red、blue、green 等，且同一颜色恰好出现两次：一次在水平边缘（顶行或底行），一次在垂直边缘（左列或右列）。
  - 网格内部全部为背景色，没有其他前景元素。

- `Rule`：
  - 从每个水平边缘的种子像素出发，沿垂直方向（顶行种子向下、底行种子向上）发射一条射线，将射线经过的所有背景像素标记为该种子的颜色。
  - 从每个垂直边缘的种子像素出发，沿水平方向（左列种子向右、右列种子向左）发射一条射线，同样标记沿途的背景像素。
  - 当两条不同颜色的射线在某个像素交叉时，该像素着色为 orange（统一的交汇标记色），而非任一射线的颜色。
  - 当同一颜色的两条射线（来自水平边缘和垂直边缘的配对种子）交叉时，该交叉像素着色为 magenta。
  - 最后，找到所有 magenta 像素；如果恰好有四个 magenta 像素构成一个轴对齐矩形的四个角，则将该矩形内部（不含边界上的射线像素）全部填充为 azure。

- `Key insight`：解题者首先需要理解射线从边缘种子发射并在内部交叉的机制，然后区分异色交叉（orange）与同色交叉（magenta）的不同标记规则，最后发现 magenta 交叉点围成的矩形区域会被填充。三层规则——射线发射、交叉分类标记、矩形区域填充——需要从样例中逐步归纳。
</new_puzzle>

- `description`：根据连接两个形状的桥的宽度，决定将哪个形状的颜色覆盖到另一个形状上，桥本身按胜出颜色重新着色。

- `Input structure`：
  - 背景为 black。
  - 网格中有若干对彩色形状，每对形状由一条 grey 像素构成的矩形"桥"连接。桥为单方向延伸的矩形条（水平或垂直），宽度为 1 到 3 个像素。
  - 每对通过桥连接的两个形状颜色不同（如一个 red 一个 blue）。
  - 每个形状是一个 4-连通的实心矩形，面积在 4 到 12 像素之间。
  - 桥的两端分别 4-邻接于一对形状中的各一个。

- `Rule`：
  - 对每对通过桥连接的形状，比较两个形状的面积（像素数）。
  - 如果桥的宽度为奇数（1 或 3），面积较大的形状"胜出"；如果桥的宽度为偶数（2），面积较小的形状"胜出"。
  - 将败方形状的所有像素重新着色为胜方形状的颜色。
  - 将连接该对形状的 grey 桥也重新着色为胜方形状的颜色。
  - 胜方形状本身保持不变。

- `Key insight`：解题者首先需要识别桥连接的形状配对关系，然后发现桥的宽度（奇偶性）反转了面积比较的胜负规则。宽度为偶数时"以小胜大"违反直觉，这一隐蔽的条件分支需要从多个样例中对比归纳才能发现。
</new_puzzle>

<new_puzzle>
- `description`：在网格中识别被围栏包围的牧场区域，根据牧场内"饲料堆"的排列方向旋转牧场内容，再将旋转后溢出围栏的像素裁剪掉。

- `Input structure`：
  - 背景为 green。
  - 网格中有若干个由 maroon 像素构成的单像素宽封闭矩形围栏，围栏内部为背景色以及一些前景元素。
  - 每个围栏内部包含：(a) 一个由 blue 像素构成的小型不规则形状（"动物"），(b) 若干个 orange 单像素（"饲料堆"），排成一条近似直线（水平或垂直方向，偏差不超过 1 像素）。
  - 饲料堆排列成的直线方向为水平或垂直。每个围栏内饲料堆数量为 1 到 3 个。

- `Rule`：
  - 对每个围栏，判断其内部 orange 饲料堆的排列方向：水平排列或垂直排列。
  - 如果饲料堆水平排列：将围栏内部的所有内容（blue 形状和 orange 像素）以围栏内部区域的中心为旋转中心，顺时针旋转 90 度。
  - 如果饲料堆垂直排列：将围栏内部的所有内容逆时针旋转 90 度。
  - 旋转后，如果任何前景像素落在围栏边框上或围栏外部，将其裁剪（不绘制）。
  - 围栏本身（maroon 边框）在输出中保持不变。
  - 围栏外部的背景区域不受影响。

- `Key insight`：解题者需要先发现 orange 像素的排列方向决定了旋转方向（水平→顺时针，垂直→逆时针），这一映射关系并不直观。再结合围栏边界的裁剪效果，解题者必须在心理上模拟旋转后的结果。两层推理——方向编码识别和受约束的旋转变换——构成了题目的核心挑战。
</new_puzzle>
