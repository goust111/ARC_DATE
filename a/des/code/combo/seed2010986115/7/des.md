<new_puzzle>
description：根据封闭区域内部陷阱像素的颜色，在区域外壁上对应方向绘制等长的彩色尾巴。

Input structure
- 背景色（black）填充整个网格。
- 网格中有若干由同一种墙壁颜色（grey）围成的封闭矩形区域，每个区域内部为背景色，但包含一个或多个单像素"陷阱点"，每个陷阱点的颜色各不相同且与墙壁颜色不同。
- 每个陷阱点恰好紧邻（4-连通）该区域的某一面内壁（上、下、左、右），且与该面内壁之间没有其他非背景像素。

Rule
- 对每个封闭区域内的每个陷阱点，确定它贴近的那面内壁的方向（上/下/左/右）。
- 从该面外壁出发，沿同一方向向外延伸，绘制一条与封闭区域在该面的边长等长的线段（即"尾巴"），颜色为该陷阱点的颜色。"尾巴"的起点为陷阱点正对的那段外壁像素向外偏移一格的位置，沿垂直于该面的方向延伸，长度等于该面外壁的完整边长。
- 如果尾巴绘制方向上已有其他颜色像素，尾巴在碰到该像素前停止。
- 封闭区域及其墙壁保持不变，陷阱点保留。

Key insight
陷阱点并非装饰；它的位置编码了尾巴生长的方向（贴近哪面墙），它的颜色决定了尾巴的颜色，而所贴近墙面的边长决定了尾巴的粗细——需要同时推理方向选择和几何度量两层规则。
</new_puzzle>

<new_puzzle>
description：将分散在网格中的彩色碎片按形状配对后，用配对双方的颜色混合规则重新着色为统一颜色。

Input structure
- 背景色（black）占据网格大部分区域。
- 网格中散布着若干 4-连通的单色小对象（碎片），每种颜色最多出现两次。
- 每个碎片的像素数量不超过 6 个。
- 在网格的一个角落，有一个由分隔线划分的小"调色板"区域，其中每一行恰好包含两个不同颜色的单像素和一个结果颜色的单像素，三者在同一行从左到右排列，表示"颜色A + 颜色B → 颜色C"的映射关系。

Rule
- 将所有碎片按其归一化形状（忽略平移，但不忽略旋转和翻转）进行配对：形状完全一致的两个不同颜色碎片构成一对。
- 对每一对碎片，在调色板中查找包含这两种颜色的那一行，读取对应的结果颜色。
- 将该对中两个碎片的所有像素都重新着色为查找到的结果颜色，位置不变。
- 调色板区域在输出中被清除为背景色。
- 若某碎片没有形状配对（即该形状只出现一次），则保持原色不变。

Key insight
解题需要两层非平凡推理：第一层是通过形状匹配（非颜色匹配）找到配对关系，第二层是理解角落调色板是颜色混合查找表并正确应用映射——仅看颜色或仅看形状都无法单独得出答案。
</new_puzzle>

description：沿着路径网络传递标记颜色，每经过一个交叉节点时根据节点形状改变传递方向。

Input structure
- 背景色（black）填充网格。
- 网格中有由 grey 像素构成的直线路径段（水平或垂直，宽度为 1 像素），路径段在交叉处形成 T 形或十字形节点。
- 路径网络的若干末端（度为 1 的端点）各有一个彩色标记像素（颜色各不相同），紧邻路径末端外侧一格。
- 每个交叉节点处，节点本身的 grey 像素保持不变，但节点周围恰好有一个方向上的相邻背景格被标记为 blue，指示该节点的"转向偏好"——即信号到达该节点时应优先选择的出口方向。

Rule
- 从每个彩色标记出发，信号沿路径传播。
- 信号到达交叉节点时：如果 blue 标记所指的方向是一个可用出口（即该方向有路径段延伸出去且不是信号来的方向），则信号转向该方向继续传播；否则信号沿直线方向继续（不转弯）。
- 信号传播到路径末端时停止。
- 输出时，将路径上每一个 grey 像素替换为最后经过该像素的信号的颜色。若某路径段没有信号经过，保持 grey 不变。
- 彩色标记和 blue 转向标记在输出中被清除为背景色。

Key insight
路径着色不是简单的最近源扩散——需要先理解 blue 标记编码的转向规则来确定每条信号的实际行进路线，再根据路线对路径段进行着色。转向偏好是隐蔽的方向编码，构成推理的核心层。
</new_puzzle>

description：根据每个封闭房间内的"窗户"数量，从共享图例中选取对应阶数的填充图案铺满该房间。

Input structure
- 背景色（black）填充网格。
- 网格中有由 blue 像素构成的墙壁，将网格内部分割成若干互不相通的矩形"房间"（每个房间内部全为背景色）。
- 每个房间的墙壁上有零个或多个"窗户"——即墙壁上被替换为 yellow 的单像素缺口（窗户像素仍然是墙壁的一部分，不会导致房间连通）。
- 在网格底部或右侧，有一组水平排列的小型示例方块（用 grey 边框隔开），每个方块内部包含一种不同的填充图案（由 red、green、orange 等颜色组成的 2×2 或更大的重复纹理）。这些示例方块从左到右分别编号为 1、2、3……

Rule
- 数出每个房间墙壁上的窗户（yellow 像素）数量 N。
- 从底部/右侧的图案图例中，取出第 N 个图案（从 1 开始计数）。
- 用该图案以平铺方式填充整个房间的内部区域（图案从房间左上角开始铺设，超出房间范围的部分截断）。
- 没有窗户的房间（N=0）保持背景色不变。
- 墙壁、窗户和图例区域在输出中保持不变。

Key insight
解题者必须先发现窗户数量是索引键（第一层推理：数量→序号的映射关系），然后理解图例的排列顺序就是索引顺序（第二层推理：图例是有序查找表），最后正确执行平铺填充——窗户数量的视觉计数是简单的，但"数量即索引"的映射关系需要从多个样例中归纳。
</new_puzzle>

description：将网格中的箭头形状对象沿其指向方向投射，在碰到边界或障碍时留下一个与箭头互补的"印章"。

Input structure
- 背景色（black）填充网格。
- 网格中有若干由单一颜色构成的箭头形状对象。每个箭头由一个 3×3 的实心方块去掉一个角上的 2×2 区域构成，形成 L 形，其中较长边指示箭头的朝向方向（缺失角的对角方向即为箭头指向）。
- 网格中还有若干由 grey 像素构成的单像素宽的障碍线段（水平或垂直）。

Rule
- 对每个箭头对象，沿其指向方向（由缺角位置确定：左上角缺失则指向右下，右上角缺失则指向左下，左下角缺失则指向右上，右下角缺失则指向左上）逐像素平移整个箭头，直到箭头的任意像素即将越出网格边界或碰到 grey 障碍像素。
- 在箭头停止的位置，不绘制箭头本身，而是绘制箭头的"互补印章"：在箭头停止位置的 3×3 包围框内，将箭头原本缺失的那个 2×2 区域用 maroon 填充，其余位置保持背景色。
- 箭头的原始位置保留原始颜色不变。
- grey 障碍在输出中保持不变。

Key insight
解题者需要首先从 L 形的缺角方位推断出箭头的指向方向（第一层：形状编码方向），然后理解投射终点绘制的不是箭头自身而是其 3×3 包围框中的互补区域（第二层：正形变负形的反转逻辑）——方向推断和互补印章是两个独立的非显然规则。
</new_puzzle>

<new_puzzle>
description：根据种子像素在对象内部的相对位置，选择对应的旋转变体将对象复制到输出网格的指定槽位。

Input structure
- 背景色（black）填充网格。
- 网格左半部分包含若干互不重叠的单色 4-连通对象（"模板对象"），每个对象内部恰好有一个不同颜色的单像素"种子"。种子的颜色在所有对象中各不相同。
- 网格右半部分被 grey 单像素线分割成若干大小相等的矩形"槽位"，每个槽位内部为背景色，但在左上角恰好有一个单色像素标签，颜色与某个种子颜色相同。

Rule
- 通过颜色匹配将每个模板对象与一个槽位配对（种子颜色 = 槽位标签颜色）。
- 确定种子在模板对象最小包围矩形中的相对象限位置（左上、右上、左下、右下）。
- 根据种子的象限位置对模板对象进行旋转：左上 → 不旋转（0°），右上 → 顺时针 90°，右下 → 180°，左下 → 逆时针 90°。
- 将旋转后的模板对象（不含种子像素，仅保留对象自身颜色）绘制在配对槽位的中央位置（居中对齐）。
- 槽位标签像素在输出中被对象覆盖或保留为背景。左半部分的模板对象和种子在输出中被清除为背景色。

Key insight
解题者需要三层推理：第一层是通过颜色匹配建立对象-槽位的配对关系；第二层是发现种子在包围矩形中的象限位置编码了旋转角度（而非种子颜色或对象大小）；第三层是正确执行旋转并居中放置。种子的位置意义是最隐蔽的环节。
</new_puzzle>

<new_puzzle>
description：将散落的拼图碎片按边缘锯齿互锁规则拼合到框架的正确位置。

Input structure
- 背景色（black）填充网格。
- 网格中央有一个由 grey 像素构成的矩形"框架"，框架内部被分割为若干等大的矩形槽位，每个槽位内部为背景色。每个槽位的四条边上可能有 0-2 个单像素突起（凸出到相邻槽位或框架外）或单像素凹陷（从槽位边缘向内缩进一格）。凸起用 green 标记，凹陷用 red 标记。
- 框架外散布着若干与槽位等大的彩色矩形碎片（每个碎片为单一颜色，颜色各不相同）。每个碎片的四条边上同样有 green 凸起和 red 凹陷标记，位置和数量各不相同。

Rule
- 每个碎片恰好对应框架中的一个槽位。匹配规则为：碎片的每条边上的凸起（green）必须与槽位对应边上的凹陷（red）在相同的偏移位置一一对应，反之亦然（碎片凹陷对应槽位凸起）。
- 将每个碎片放入匹配的槽位中，碎片的颜色填充整个槽位内部。
- 输出中去除所有 green 和 red 标记，框架 grey 像素保留，每个槽位填充为对应碎片的颜色。

Key insight
解题者需要先理解凸起-凹陷的互锁配对机制（每条边的凸凹必须互补），然后在多个碎片和槽位之间进行全局匹配——难点不在于单条边的匹配，而在于同时满足四条边的约束来唯一确定每个碎片的位置。
</new_puzzle>
