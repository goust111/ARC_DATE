description：将分散在网格中的彩色碎片按形状配对后，用配对双方的颜色混合规则重新着色为统一颜色。

Input structure
- 背景色（black）占据网格大部分区域。
- 网格中散布着若干 4-连通的单色小对象（碎片），每种颜色最多出现两次。
- 每个碎片的像素数量不超过 6 个。
- 在网格的一个角落，有一个由分隔线划分的小"调色板"区域，其中每一行恰好包含两个不同颜色的单像素和一个结果颜色的单像素，三者在同一行从左到右排列，表示"颜色A + 颜色B → 颜色C"的映射关系。

Rule
- 将所有碎片按其归一化形状（忽略平移，但不忽略旋转和翻转）进行配对：形状完全一致的两个不同颜色碎片构成一对。
- 对每一对碎片，在调色板中查找包含这两种颜色的那一行，读取对应的结果颜色。
- 将该对中两个碎片的所有像素都重新着色为查找到的结果颜色，位置不变。
- 调色板区域在输出中被清除为背景色。
- 若某碎片没有形状配对（即该形状只出现一次），则保持原色不变。

Key insight
解题需要两层非平凡推理：第一层是通过形状匹配（非颜色匹配）找到配对关系，第二层是理解角落调色板是颜色混合查找表并正确应用映射——仅看颜色或仅看形状都无法单独得出答案。
</new_puzzle>
