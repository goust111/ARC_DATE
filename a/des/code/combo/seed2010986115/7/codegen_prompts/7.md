description：将散落的拼图碎片按边缘锯齿互锁规则拼合到框架的正确位置。

Input structure
- 背景色（black）填充网格。
- 网格中央有一个由 grey 像素构成的矩形"框架"，框架内部被分割为若干等大的矩形槽位，每个槽位内部为背景色。每个槽位的四条边上可能有 0-2 个单像素突起（凸出到相邻槽位或框架外）或单像素凹陷（从槽位边缘向内缩进一格）。凸起用 green 标记，凹陷用 red 标记。
- 框架外散布着若干与槽位等大的彩色矩形碎片（每个碎片为单一颜色，颜色各不相同）。每个碎片的四条边上同样有 green 凸起和 red 凹陷标记，位置和数量各不相同。

Rule
- 每个碎片恰好对应框架中的一个槽位。匹配规则为：碎片的每条边上的凸起（green）必须与槽位对应边上的凹陷（red）在相同的偏移位置一一对应，反之亦然（碎片凹陷对应槽位凸起）。
- 将每个碎片放入匹配的槽位中，碎片的颜色填充整个槽位内部。
- 输出中去除所有 green 和 red 标记，框架 grey 像素保留，每个槽位填充为对应碎片的颜色。

Key insight
解题者需要先理解凸起-凹陷的互锁配对机制（每条边的凸凹必须互补），然后在多个碎片和槽位之间进行全局匹配——难点不在于单条边的匹配，而在于同时满足四条边的约束来唯一确定每个碎片的位置。
