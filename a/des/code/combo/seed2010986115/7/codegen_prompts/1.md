description：根据封闭区域内部陷阱像素的颜色，在区域外壁上对应方向绘制等长的彩色尾巴。

Input structure
- 背景色（black）填充整个网格。
- 网格中有若干由同一种墙壁颜色（grey）围成的封闭矩形区域，每个区域内部为背景色，但包含一个或多个单像素"陷阱点"，每个陷阱点的颜色各不相同且与墙壁颜色不同。
- 每个陷阱点恰好紧邻（4-连通）该区域的某一面内壁（上、下、左、右），且与该面内壁之间没有其他非背景像素。

Rule
- 对每个封闭区域内的每个陷阱点，确定它贴近的那面内壁的方向（上/下/左/右）。
- 从该面外壁出发，沿同一方向向外延伸，绘制一条与封闭区域在该面的边长等长的线段（即"尾巴"），颜色为该陷阱点的颜色。"尾巴"的起点为陷阱点正对的那段外壁像素向外偏移一格的位置，沿垂直于该面的方向延伸，长度等于该面外壁的完整边长。
- 如果尾巴绘制方向上已有其他颜色像素，尾巴在碰到该像素前停止。
- 封闭区域及其墙壁保持不变，陷阱点保留。

Key insight
陷阱点并非装饰；它的位置编码了尾巴生长的方向（贴近哪面墙），它的颜色决定了尾巴的颜色，而所贴近墙面的边长决定了尾巴的粗细——需要同时推理方向选择和几何度量两层规则。

1. `main(grid)` 必须实现新题描述中的确定性转换规则，不能只识别 `generate_input()` 的固定模板。
