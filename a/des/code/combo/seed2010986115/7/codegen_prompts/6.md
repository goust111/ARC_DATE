Input structure
- 背景色（black）填充网格。
- 网格左半部分包含若干互不重叠的单色 4-连通对象（"模板对象"），每个对象内部恰好有一个不同颜色的单像素"种子"。种子的颜色在所有对象中各不相同。
- 网格右半部分被 grey 单像素线分割成若干大小相等的矩形"槽位"，每个槽位内部为背景色，但在左上角恰好有一个单色像素标签，颜色与某个种子颜色相同。

Rule
- 通过颜色匹配将每个模板对象与一个槽位配对（种子颜色 = 槽位标签颜色）。
- 确定种子在模板对象最小包围矩形中的相对象限位置（左上、右上、左下、右下）。

Key insight
解题者需要三层推理：第一层是通过颜色匹配建立对象-槽位的配对关系；第二层是发现种子在包围矩形中的象限位置编码了旋转角度（而非种子颜色或对象大小）；第三层是正确执行旋转并居中放置。种子的位置意义是最隐蔽的环节。
