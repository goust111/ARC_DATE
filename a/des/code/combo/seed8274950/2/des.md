- `description`：根据每个前景对象的边界缺口方向和缺口宽度，沿缺口方向发射等宽的彩色光带，光带颜色由对象内部的标记像素决定。
- `Input structure`：背景色填充网格。若干单色 4-连通前景对象分散在网格中，每个对象的边界框（bbox）的某一边上有一段连续的缺口（该边上若干连续像素为背景色，且缺口两侧有对象像素）。每个对象内部恰好有一个颜色不同于对象主色的单像素标记。
- `Rule`：
  - 对每个对象，找到其 bbox 上唯一的缺口，确定缺口方向和缺口宽度 W。
  - 从缺口位置沿缺口向外方向发射一条宽度为 W 的光带，光带延伸到网格边界或遇到其他前景像素时停止。
  - 光带的颜色为对象内部标记像素的颜色。
  - 保留所有原始对象不变。
- `Key insight`：缺口宽度不仅定义方向，还决定光带的截面宽度；内部标记像素是需要单独识别的颜色源——两个属性各自编码输出的不同维度。
</new_puzzle>

- `description`：在分隔线划分的面板阵列中，找到每行面板中的"异类"面板，将所有异类面板的内容叠加到一个输出画布上。
- `Input structure`：分隔色形成完整行和列，将网格划分为等大的矩形面板，排列成若干行若干列。每行面板中，除一个外其余面板的内部图案完全相同；那个不同的面板就是该行的"异类"面板。不同行的异类面板可能在不同列位置。
- `Rule`：
  - 对每行面板，比较该行内所有面板的像素内容，找到唯一与其他面板不同的异类面板。
  - 创建一个面板大小的输出画布，填充背景色。
  - 按行从上到下的顺序，将每行异类面板中的非背景像素叠加到输出画布上（后叠加的覆盖先叠加的）。
- `Key insight`：题目不是简单地找一个全局异类，而是每行独立找异类；输出是所有行异类的叠加——行独立的"找不同"加上叠加合成构成两层推理。
</new_puzzle>

- `description`：将每个前景对象按面积排名映射到网格边缘图例指定的颜色，用该颜色重新着色对象。
- `Input structure`：背景色填充网格。网格中有若干分离的单色 4-连通前景对象，面积各不相同。网格的左边缘有一列颜色图例：从上到下每个像素是一种不同的颜色，共 N 个（N 等于对象数量）。
- `Rule`：
  - 将所有前景对象按面积从小到大排序。
  - 图例从上到下的第 k 个颜色对应排名第 k 的对象。
  - 将每个对象重新着色为图例分配的颜色，保持位置和形状不变。
  - 擦除图例像素为背景色。
- `Key insight`：图例颜色的顺序是排名编码——按面积排名分配颜色，而非按位置或原始颜色匹配。
</new_puzzle>

<new_puzzle>
- `description`：根据两条交叉分隔线将网格分成四个象限，每个象限内的前景对象按该象限对应的固定旋转角度进行就地旋转。
- `Input structure`：背景色填充网格。一条水平线和一条垂直线（各自为不同非背景颜色）将网格分成四个象限。每个象限内有一个或多个分离的单色 4-连通前景对象。
- `Rule`：
  - 左上象限：对象不旋转。
  - 右上象限：每个对象绕其 bbox 中心顺时针旋转 90 度。
  - 右下象限：每个对象绕其 bbox 中心旋转 180 度。
  - 左下象限：每个对象绕其 bbox 中心逆时针旋转 90 度。
  - 旋转后对象保持在原始中心位置，超出象限的部分被裁剪。分隔线保持不变。
- `Key insight`：四个象限各对应一种旋转角度，该映射需要从样例归纳发现，不由显式标注给出。
</new_puzzle>

<new_puzzle>
- `description`：在包含多个重叠矩形框架的网格中，从遮挡关系推导层序，输出从底到顶的颜色序列。
- `Input structure`：背景色填充网格。若干不同颜色的一像素厚矩形框架相互重叠。重叠处上层颜色可见、下层被遮盖。每种框架颜色的可见像素仍能确定其矩形 bbox。
- `Rule`：
  - 对每种框架颜色，根据可见像素的 bbox 重建完整矩形框架。
  - 在重叠像素处，可见颜色位于上层，被遮盖颜色位于下层。
  - 从遮挡关系推导唯一的从底到顶层序。
  - 输出 1 列 N 行的网格，从上到下依次为从最底层到最顶层的框架颜色。
- `Key insight`：框架遮挡关系通过重叠处可见颜色推断——需要理解"层叠"概念并从交叉处提取偏序关系。
</new_puzzle>

<new_puzzle>
- `description`：识别散布标记之间的对齐关系，用对齐方向决定连线样式，连线颜色取路径上的局部环境色。
- `Input structure`：背景色填充网格。网格中散布若干单像素彩色标记。部分背景像素被染成"区域色"，形成小色块。两个标记位于同行或同列且中间无其他标记阻隔时构成配对。
- `Rule`：
  - 同行对齐的标记对：之间画水平实线，颜色为路径上最近的区域色；若无区域色则用 grey。
  - 同列对齐的标记对：之间画垂直虚线（每隔一个像素画一个），颜色规则同上。
  - 标记像素本身保持不变。
- `Key insight`：同行 vs 同列决定连线样式（实线 vs 虚线），连线颜色来自路径上的局部环境色而非标记本身——两个独立的非显然规则。
</new_puzzle>
