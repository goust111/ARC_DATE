<new_puzzle>
- `description`：在网格中找到每对同色对象之间的连线路径，路径颜色由两个对象的相对方位（水平/垂直/对角）决定。
- `Input structure`：背景色填充网格。网格中有若干分离的单色 4-连通前景对象，每种颜色恰好出现两次（形成配对）。不同配对的颜色不同。
- `Rule`：
  - 对每对同色对象，找到它们的 bbox 中心连线方向。
  - 若连线主要为水平方向（中心在同一行或近似同行），在两者之间画一条水平连线，颜色为 red。
  - 若连线主要为垂直方向，画垂直连线，颜色为 blue。
  - 若连线为对角方向（中心不在同行也不在同列），画 L 形连线（先水平后垂直），颜色为 green。
  - 连线仅在背景像素上绘制，保留所有原始对象。
- `Key insight`：同色配对是第一层（颜色匹配），连线颜色由方位关系决定而非由对象颜色决定是第二层——输出颜色与输入颜色完全无关。
</new_puzzle>

<new_puzzle>
- `description`：在包含"种子行"和"规则行"的网格中，按规则行定义的局部替换规则迭代扩展种子行，生成完整的输出图案。
- `Input structure`：背景色填充网格。网格的第一行是"种子行"，包含若干彩色像素。第二行和第三行组成"规则行"：第二行是输入模式（每两个相邻像素为一组），第三行是输出模式（对应位置的单个替换像素）。其余行为背景色。
- `Rule`：
  - 从规则行中读取局部替换规则：每对相邻输入像素（颜色对 A、B）映射到一个输出像素颜色 C。
  - 从种子行开始，每一行根据上一行生成下一行：上一行的第 k 和第 k+1 个像素组成输入对，查找规则得到输出像素，写入下一行的第 k 个位置。
  - 每行比上一行少一个像素（因为每次取相邻对）。
  - 重复直到只剩一个像素或行数到达网格底部。
- `Key insight`：规则行是一个"局部邻域替换表"，种子行通过反复应用该规则逐行收缩——这类似于一维元胞自动机，但规则是从样例中显式给出而非隐含的。
</new_puzzle>

<new_puzzle>
- `description`：将网格中的前景对象按面积分成"大"和"小"两类，大对象保留位置但被其 bbox 的十字线替换，小对象被移动到最近的大对象十字线交叉点上。
- `Input structure`：背景色填充网格。网格中有若干分离的单色 4-连通前景对象，面积差异显著（大对象面积至少是小对象的 4 倍以上）。
- `Rule`：
  - 找到面积阈值：将所有对象按面积排序，找到最大的面积间隙作为大/小的分界。
  - 对每个大对象，擦除其像素，改为在其 bbox 中心画一个十字形（水平线和垂直线各贯穿整个 bbox），颜色为该对象的原始颜色。
  - 对每个小对象，找到距其 bbox 中心最近的大对象十字线交叉点（即某个大对象 bbox 的中心），将小对象移动到该交叉点处（小对象的 bbox 中心对齐到交叉点）。
  - 小对象保持原色和形状。
- `Key insight`：大/小分类决定了完全不同的变换命运（替换为十字 vs 移动到十字中心），这种"角色分配"需要从面积差异中推断。
</new_puzzle>

<new_puzzle>
- `description`：在由两种交替颜色填充的棋盘格背景上，找到被"污染"的格子（颜色与棋盘规律不符的格子），将污染区域改为正确的棋盘色，并在该位置的边框画一个标记环。
- `Input structure`：网格由两种颜色交替填充形成标准棋盘格图案（如 black 和 orange 交替），但部分格子的颜色被改为了第三种颜色（污染色）。
- `Rule`：
  - 推断标准棋盘格的两种颜色和格子大小（通过未被污染的区域判断）。
  - 找到所有颜色不符合棋盘规律的像素（即不是该位置应有的两种棋盘色之一的像素）。
  - 将这些像素恢复为正确的棋盘颜色。
  - 在每个被污染区域的 bbox 外围一像素处，画一圈 red 色的矩形标记框。
- `Key insight`：先推断棋盘的周期和颜色是第一层推理（从可见的规律区域），识别并修复污染是第二层，添加标记框是第三层——但后两层在发现棋盘规律后是机械的。
</new_puzzle>

<new_puzzle>
- `description`：在网格中找到所有"完整对"——两个对象的形状互为 90 度旋转——将每对合并放置在它们中点处，重叠部分涂为第三种颜色。
- `Input structure`：背景色填充网格。网格中有若干分离的单色 4-连通前景对象，颜色各异。部分对象的形状恰好是另一个对象旋转 90 度后的结果（归一化到 bbox 后比较）。
- `Rule`：
  - 检查所有对象对，找到形状互为 90 度旋转关系的配对。
  - 对每个配对，计算两个对象 bbox 中心的中点。
  - 将两个对象平移到中点处对齐（两个对象的 bbox 中心都移到中点）。
  - 两个对象各自保留原色。重叠的像素涂为 maroon。
  - 没有配对的对象保持不变。
- `Key insight`：旋转等价性是配对依据（不是颜色或大小），重叠像素的特殊着色使得合并结果视觉上突出了两个形状的交集。
</new_puzzle>
