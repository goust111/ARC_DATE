<new_puzzle>
- `description`：根据每个封闭区域的边界缺口数量从颜色图例中选取填充色，再根据缺口的朝向决定填充的渐变方向。
- `Input structure`：背景色填充网格。一种墙壁色形成若干封闭的矩形区域（一像素厚的边框），每个区域的边框上有一个或多个单像素缺口（边框上的背景色像素）。网格边缘有一行颜色图例，第 k 个位置的颜色对应"缺口数为 k"的填充色。
- `Rule`：
  - 对每个封闭区域，统计边框上的缺口数量 N。
  - 从图例中查找第 N 个颜色 C。
  - 确定所有缺口中最常出现的朝向（上/下/左/右）。
  - 从该朝向的对面开始，用颜色 C 做渐变填充：最靠近对面边框的行/列完全填满 C，然后每向缺口方向前进一行/列，填充像素数减少一个。
- `Key insight`：缺口数量是颜色查找键（第一层），缺口朝向是渐变方向的决定因素（第二层）——两个来自同一视觉特征（缺口）的不同属性分别编码不同维度的输出。
</new_puzzle>

<new_puzzle>
- `description`：在由网格线划分的棋盘格中，找到所有包含"完整环形"图案的格子，将这些格子的位置编码到一个缩小版的输出网格中。
- `Input structure`：网格色形成等间距的完整行和列，将网格划分为等大的正方形格子。每个格子内有一种前景色组成的图案。图案类型包括：实心方块、环形（外圈有色内圈为背景色）、L形、十字形等。
- `Rule`：
  - 对每个格子，判断其内部图案是否为"环形"：即前景色像素组成的 4-连通对象内部包含至少一个不接触格子边缘的背景色封闭区域。
  - 创建一个缩小版的输出网格，行列数等于格子的行列数。
  - 包含环形图案的格子位置在输出中标记为 red；其他位置标记为背景色。
- `Key insight`：关键属性是"图案内部是否有封闭孔洞"——这是一个拓扑属性而非几何形状，环形和其他有孔形状都算，而实心或开放形状不算。
</new_puzzle>

<new_puzzle>
- `description`：将网格中散布的标记像素按颜色分组，每组标记的凸包矩形定义一个输出区域，区域内用该颜色按标记数量画同心环。
- `Input structure`：背景色填充网格。网格中有若干单像素彩色标记，每种颜色出现 2 到 5 次不等。同色标记散布在不同位置。
- `Rule`：
  - 对每种标记颜色，取其所有像素的 bbox（最小外接矩形）。
  - 统计该颜色的标记数量 N。
  - 在该 bbox 区域内，从外到内绘制 N 层同心矩形环，每层用该标记颜色绘制一像素厚的矩形环，环之间间隔一像素的背景色。
  - 不同颜色的同心环区域如果重叠，后处理的覆盖先处理的（按颜色出现次数从少到多的顺序处理）。
- `Key insight`：标记数量同时编码了同心环的层数——多一个标记就多一层环；而 bbox 由标记的空间分布决定——这是"计数驱动几何"的两层推理。
</new_puzzle>

<new_puzzle>
- `description`：在包含一个大型模板和若干小型碎片的网格中，将碎片按颜色匹配嵌入模板的对应色区域，碎片形状决定嵌入后的裁剪。
- `Input structure`：背景色填充网格。网格中有一个大型多色对象（模板），由若干不同颜色的相邻矩形色区组成。模板外散布着若干小型单色碎片精灵。每个碎片的颜色恰好匹配模板中某个色区的颜色。
- `Rule`：
  - 将每个碎片与模板中同色的色区配对。
  - 将碎片的 bbox 居中对齐到色区的中心。
  - 在色区范围内，将碎片形状对应的像素保留为该颜色，其余色区像素改为背景色（相当于用碎片形状"裁剪"色区）。
  - 没有对应碎片的色区保持原样。
  - 碎片从原位置擦除。
- `Key insight`：碎片颜色配对是第一层（颜色匹配），碎片作为"裁剪蒙版"而非"填充模板"是第二层——碎片覆盖的像素保留，未覆盖的被清除。
</new_puzzle>

<new_puzzle>
- `description`：将每个前景对象沿其最长轴展开为一维色带，色带长度等于对象面积，色带中的颜色由对象沿最长轴的投影决定。
- `Input structure`：背景色填充网格。网格中有若干分离的单色 4-连通前景对象，形状各异。每个对象的 bbox 不是正方形（高度和宽度不同）。
- `Rule`：
  - 对每个对象，确定其 bbox 的较长边方向（水平或垂直）。
  - 将对象沿较长边方向投影：对每个较长边上的坐标位置，统计该位置上有多少个对象像素。
  - 创建一条水平色带，长度等于对象的总像素数。
  - 色带按较长边方向的坐标从小到大排列，每个坐标位置重复该坐标上像素数那么多次。颜色为对象色。
  - 若对象像素数为奇数，色带中心像素改为 yellow。
  - 色带放置在对象原始 bbox 左上角的行上。
- `Key insight`：对象被"展开"为其沿主轴的投影直方图，奇偶性标记增加了一个需要单独归纳的规则。
</new_puzzle>
