- `description`：将网格中每个前景对象沿其"开口方向"推出网格，推出后留下的轨迹颜色由对象像素数量决定。
- `Input structure`：背景色填充网格。网格中有若干分离的单色 4-连通前景对象。每个对象的形状在 bbox 的某一条边上是"开放"的（该边上对象像素不连续，有背景色间隙），其余三条边上对象像素连续覆盖。
- `Rule`：
  - 对每个对象，找到 bbox 上不连续的那条边，确定为"开口方向"。
  - 将对象沿开口方向平移直到完全离开网格。
  - 对象经过的路径（从原始位置到网格边缘）涂上轨迹颜色。
  - 轨迹颜色规则：像素数 ≤ 4 的对象留 red 轨迹，5-8 的留 blue 轨迹，≥ 9 的留 green 轨迹。
  - 对象本身在输出中不出现（已推出网格）。
- `Key insight`：开口方向编码了推出方向（第一层），像素数量编码了轨迹颜色（第二层）——两个独立属性驱动不同维度的输出。
</new_puzzle>

<new_puzzle>
- `description`：在网格中找到所有"嵌套框架"结构（框架内还有框架），将最内层框架的颜色传播到最外层，最外层的颜色传播到最内层，中间层保持不变。
- `Input structure`：背景色填充网格。网格中有若干组嵌套的矩形框架：每组由 2-4 个不同颜色的一像素厚矩形框架嵌套而成，框架之间有一像素的背景色间隔。
- `Rule`：
  - 对每组嵌套框架，识别从外到内的层序。
  - 交换最外层和最内层的颜色：最外层框架改为最内层的原始颜色，最内层框架改为最外层的原始颜色。
  - 中间层（如果有）保持原色不变。
  - 框架之间的背景间隔和框架外的背景保持不变。
- `Key insight`：只有最外层和最内层发生颜色交换，中间层是"传输介质"但自身不变——这种"首尾交换"规则需要从多层嵌套的样例中归纳。
</new_puzzle>

<new_puzzle>
- `description`：将网格中分散的单像素标记根据它们在"参考图案"中的对应位置决定颜色，参考图案由最大的前景对象提供。
- `Input structure`：背景色填充网格。网格中有一个较大的多色前景对象（参考图案）和若干 grey 色单像素标记散布在网格中。每个标记的行列坐标在参考图案 bbox 的行列范围内对应一个位置。
- `Rule`：
  - 对每个 grey 标记，计算其在参考图案 bbox 中的相对位置（相对于参考图案 bbox 的左上角）。
  - 查看参考图案在该相对位置的颜色。
  - 将标记像素改为参考图案中对应位置的颜色。
  - 如果标记的位置落在参考图案 bbox 之外，标记保持 grey。
  - 参考图案本身保持不变。
- `Key insight`：标记是参考图案的"采样探针"——它们不是被移动到图案中，而是从图案的对应位置"读取"颜色。坐标对齐关系需要从样例推断。
</new_puzzle>

<new_puzzle>
- `description`：在网格中找到所有"桥接对"——两个颜色相同但被墙壁隔开的对象——在它们之间建造最短的穿墙桥梁，桥梁颜色为对象颜色。
- `Input structure`：背景色填充网格。一种墙壁色形成若干水平或垂直的直线段墙壁。墙壁两侧有若干单色 4-连通前景对象。同色对象恰好出现两个，分别位于某面墙壁的两侧。
- `Rule`：
  - 对每对同色对象，找到将它们分隔的那面墙壁。
  - 在墙壁上打开一个一像素宽的缺口，缺口位置选在两个对象 bbox 中心连线与墙壁的交点处（或最近的整数位置）。
  - 从一个对象到缺口、再从缺口到另一个对象，画一条水平或垂直的桥梁线（颜色为对象颜色），取最短路径。
  - 墙壁上的缺口像素改为对象颜色。
- `Key insight`：同色配对确定需要桥接的对象（第一层），桥梁位置由几何最短路径决定（第二层）——颜色匹配和空间路径是两个独立推理步骤。
</new_puzzle>

<new_puzzle>
- `description`：将网格中的前景像素按照它们所属的"视觉层"重新着色，视觉层由像素的 4-邻居中背景色的数量决定。
- `Input structure`：背景色填充网格。网格中有一个大型单色 4-连通前景对象，形状不规则，占据网格的大部分。
- `Rule`：
  - 对每个前景像素，计算其 4-邻居中背景色像素的数量 B。
  - B = 0（完全被前景包围）：改为 maroon。
  - B = 1（一个邻居是背景）：改为 blue。
  - B = 2（两个邻居是背景）：改为 green。
  - B = 3 或 4（大部分邻居是背景）：改为 yellow。
  - 背景像素保持不变。
- `Key insight`：颜色由像素的"暴露程度"（与背景的接触面积）决定——内部像素、边缘像素和角落像素各获得不同颜色，形成对象的"地形图"。
</new_puzzle>
