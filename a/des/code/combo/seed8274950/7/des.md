- `description`：将网格中的两组镜像对称的精灵通过它们共享的对称轴合并为一个完整图案，对称轴的位置由两组精灵的中点连线确定。
- `Input structure`：背景色填充网格。网格中有若干小型多色精灵，分为两组：每组内的精灵排列形成一个图案的一半，两组互为镜像。两组精灵之间有一段背景色间隔。
- `Rule`：
  - 找到两组精灵各自的 bbox 中心点，连线确定对称轴方向（水平或垂直）。
  - 对称轴位于两组 bbox 中心的中点处。
  - 将两组精灵的像素关于对称轴合并到输出画布上。
  - 在合并处重叠的像素，保留与对称轴较近的那一组的颜色。
  - 输出为合并后图案的紧凑裁剪。
- `Key insight`：对称轴不是给定的几何线——需要从两组精灵的空间关系中推断轴的位置和方向，这是核心推理步骤。
</new_puzzle>

<new_puzzle>
- `description`：在包含若干彩色"信号灯"的网格中，每盏灯的颜色序列决定其四个方向中哪些方向发射光线，光线互相阻挡。
- `Input structure`：背景色填充网格。网格中有若干 2x2 的"信号灯"对象，每个信号灯由四个像素组成，四个像素可能是不同颜色或背景色。信号灯的四个像素按位置分别对应四个方向：左上→向左、右上→向上、右下→向右、左下→向下。
- `Rule`：
  - 对每个信号灯，检查四个像素：若某个位置的像素为非背景色，则从该信号灯中心向对应方向发射一条光线。
  - 光线颜色为该位置像素的颜色。
  - 光线沿该方向延伸，在遇到其他信号灯、其他光线像素或网格边界时停止。
  - 按信号灯从左到右、从上到下的顺序依次处理。
  - 信号灯本身保持不变。
- `Key insight`：2x2 信号灯的四个像素位置编码了方向信息——左上控制左方向、右上控制上方向等。背景色像素表示该方向不发射。
</new_puzzle>

<new_puzzle>
- `description`：将网格中的前景对象按照它们之间的空间包含关系组织成树结构，然后将整棵树展平为一个从外到内的颜色序列。
- `Input structure`：背景色填充网格。网格中有若干不同颜色的 4-连通前景对象，部分对象被其他对象完全包围（即位于另一个对象的 bbox 内部，且被该对象的像素环绕）。
- `Rule`：
  - 建立包含关系树：如果对象 A 完全位于对象 B 内部（A 的所有像素都在 B 的 bbox 范围内，且 A 被 B 的像素与背景隔离），则 A 是 B 的子节点。
  - 从最外层（不被任何对象包含的对象）到最内层，按层级顺序排列颜色。
  - 输出一个 1 行的网格，宽度等于对象数量，从左到右依次为从最外层到最内层的对象颜色。
  - 同层级的对象按面积从大到小排列。
- `Key insight`：包含关系而非位置邻近关系决定输出顺序——需要从视觉上识别"谁嵌套在谁里面"的层级结构。
</new_puzzle>

<new_puzzle>
- `description`：在包含一个"模板栅格"和若干"填充块"的网格中，根据填充块的颜色将其分配到模板中对应颜色标签的空槽位。
- `Input structure`：背景色填充网格。网格中有一个由 grey 色格线形成的矩形栅格（如 3x3），栅格中部分格子是空的（背景色），部分格子内有一个单像素颜色标签。栅格外散布着若干与标签颜色相同的小型单色矩形填充块。每个填充块的尺寸恰好等于栅格中一个格子的内部尺寸。
- `Rule`：
  - 对每个标签颜色，找到栅格中带有该颜色标签的格子位置。
  - 找到栅格外同色的填充块。
  - 将填充块放入标签格子中（覆盖标签像素），用填充块的颜色完全填满该格子内部。
  - 没有标签的空格子保持为背景色。
  - 栅格线保持不变，原位置的填充块被擦除。
- `Key insight`：颜色标签是分配键而非填充内容——标签只指定哪个填充块该放在哪个格子里，填充块提供实际的填充。
</new_puzzle>

<new_puzzle>
- `description`：将网格中的彩色条纹图案沿每条条纹的方向"推挤"到最近的边缘，空出的区域由对面方向的条纹填补。
- `Input structure`：背景色填充网格。网格中有若干一像素宽的水平或垂直彩色条纹，横跨整个网格宽度或高度。条纹之间有背景色间隔。每条条纹的一个端点处有一个不同颜色的单像素标记。
- `Rule`：
  - 标记位于条纹左端或上端的条纹向左/向上推挤：条纹平移到最靠近标记端的网格边缘，中间空出的行/列填充为背景色。
  - 标记位于条纹右端或下端的条纹向右/向下推挤：类似处理。
  - 推挤后，如果两条条纹重叠（在同一行/列），水平条纹优先覆盖垂直条纹。
  - 标记像素在输出中被擦除为背景色。
- `Key insight`：标记的位置（条纹的哪一端）编码了推挤方向——这不是简单的"向标记移动"，而是"向标记所在端的边缘推挤"。
</new_puzzle>
