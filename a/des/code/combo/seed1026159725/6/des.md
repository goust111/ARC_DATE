<new_puzzle>
- `description`：在分隔线划分的面板中，每个面板包含一个对象和若干标记点；将标记点的数量转化为对象周围环绕的同心框层数。
- `Input structure`：背景为主色。分隔色的完整行和列将网格划分为若干等大面板。每个面板内有一个居中的小型彩色 4-连通对象，以及散布在面板内的若干个 red 单像素标记点。不同面板中标记点数量不同（1~3 个）。
- `Rule`：
  - 对每个面板，计算其中 red 标记点的数量 N。
  - 在对象周围绘制 N 层同心矩形边框（每层一像素厚），颜色与对象相同。
  - 第一层边框紧贴对象边界框外侧一像素，第二层再外一像素，以此类推。
  - 擦除面板内所有 red 标记点。
  - 分隔线和对象本身保持不变。
- `Key insight`：标记点不是对象的一部分——它们的数量编码了输出中同心边框的层数。解题者需要发现"标记点计数 → 边框层数"的转换关系。
</new_puzzle>

<new_puzzle>
- `description`：网格中的多个半透明色层通过颜色混合产生了合成色；根据合成色反推原始色层，输出每个色层的独立掩码。
- `Input structure`：背景为 black。网格中只使用三种基础前景色：red、blue、green。在某些区域，两种基础色重叠后显示为混合色：red+blue → magenta，red+green → yellow，blue+green → azure。三种基础色全部重叠显示为 grey。每种基础色各自形成一个简单的矩形区域。
- `Rule`：
  - 分析每个像素的颜色，反推该位置上存在哪些基础色层。
  - 输出三个水平排列的子面板（以一列 black 分隔），每个子面板大小与输入相同。
  - 第一个子面板显示 red 层的掩码（有 red 的位置为 red，其余为 black）。
  - 第二个子面板显示 blue 层的掩码。
  - 第三个子面板显示 green 层的掩码。
- `Key insight`：混合色不是独立颜色——它们是两种或三种基础色重叠的结果。解题者需要先理解颜色混合规则（如 magenta = red + blue），再对每个像素进行"解混合"操作。
</new_puzzle>

<new_puzzle>
- `description`：将散布的彩色精灵按照其形状的连通性特征（是否包含孔洞）分为实心组和空心组，然后分别排列到输出的两行中。
- `Input structure`：背景为主色。网格中散布着若干个不同颜色的单色 4-连通前景对象。有些对象是实心的（内部没有背景色孔洞），有些是空心的（内部包含至少一个被完全包围的背景色连通区域）。
- `Rule`：
  - 对每个前景对象，判断其内部是否包含被完全包围的背景色区域（孔洞）。
  - 空心对象（有孔洞）排列在输出网格的第一行，从左到右按面积从大到小排列。
  - 实心对象（无孔洞）排列在输出网格的第二行，从左到右按面积从小到大排列。
  - 对象间以一列背景色分隔，两行间以一行背景色分隔。
  - 每个对象保持其原始颜色和形状。
- `Key insight`：分类标准不是颜色或大小——而是拓扑属性（有无孔洞）。且两组内的排序方向相反（空心组降序、实心组升序），增加了额外的推理层。
</new_puzzle>

<new_puzzle>
- `description`：在包含控制色带和目标区域的网格中，控制色带的颜色序列决定了目标区域中行/列的重新排列顺序。
- `Input structure`：背景为主色。网格的左边缘有一列垂直的彩色像素（控制列），每个像素颜色不同。网格的其余部分是一个矩形"目标区域"，其中每一行有一个主色调，与控制列中某个像素颜色相同。行的数量等于控制列中像素的数量。
- `Rule`：
  - 读取控制列中从上到下的颜色序列。
  - 在目标区域中，找到每行的主色调（该行中最频繁的非背景颜色）。
  - 按控制列的颜色顺序重新排列目标区域的行：控制列第一个颜色对应的行排在最上面，第二个颜色对应的行排在第二行，依此类推。
  - 擦除控制列（输出不含控制列）。
- `Key insight`：控制列不是装饰——它是行排列的顺序指令。解题者需要先发现控制列颜色与目标行主色调的对应关系，再理解重排规则。
</new_puzzle>

<new_puzzle>
- `description`：根据每个封闭框架内部标记线段的方向和长度，在框架外部对应方向上绘制同长度的延伸线段。
- `Input structure`：背景为主色。网格中有若干个不同颜色的一像素厚矩形框架。每个框架内部有一条由 red 像素组成的短直线段（水平或垂直），线段的一端接触框架的内壁。框架内其余区域为背景色。
- `Rule`：
  - 对每个框架，找到内部的 red 线段。
  - 确定线段接触框架哪一面内壁（上/下/左/右）。
  - 从框架的该面外壁正对线段的位置出发，向外延伸一条长度与内部 red 线段相同的线段，颜色使用框架颜色。
  - 内部 red 线段在输出中被擦除为背景色。
  - 框架本身保持不变。
- `Key insight`：内部线段的方向和接触面决定了外部延伸的方位，内部线段的长度决定了外部延伸的长度——信息从框架内部被"投射"到框架外部。
</new_puzzle>
