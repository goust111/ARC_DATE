- `description`：将每个前景对象的像素重新排列为一个紧凑矩形，矩形的宽高由对象中不同颜色的数量和每种颜色的像素数决定。
- `Input structure`：背景为主色。网格中有若干个 4-连通前景对象，每个对象由 2~4 种不同颜色的像素组成（多色对象）。不同对象使用不同的颜色集合。
- `Rule`：
  - 对每个对象，统计其中不同颜色的数量 C 和总像素数 T。
  - 创建一个 C 行 × (T/C) 列的紧凑矩形（T 必须是 C 的整数倍）。
  - 矩形的每行用一种颜色填充，颜色顺序按该颜色在对象中像素数从多到少排列。
  - 将紧凑矩形放置在对象原始边界框的位置（左上角对齐）。
  - 擦除原对象超出紧凑矩形的区域。
- `Key insight`：输入对象的不规则形状被完全抛弃，取而代之的是由颜色统计信息决定的标准矩形。颜色数决定行数，每色像素数决定列数。
</new_puzzle>

- `description`：在含有"种子"对象和"生长规则"标记的网格中，每个种子根据其旁边标记的颜色进行特定方向的迭代复制生长。
- `Input structure`：背景为主色。网格中有若干个小型单色 4-连通"种子"对象。每个种子旁边（4-邻接）有一个不同颜色的单像素"生长标记"。标记的颜色决定生长方向：red → 向右，blue → 向下，green → 向左，yellow → 向上。
- `Rule`：
  - 对每个种子，读取其生长标记的颜色确定生长方向。
  - 沿生长方向，将种子的完整形状重复复制（平移一个种子边界框宽/高的距离），直到副本的任何像素超出网格边界或覆盖非背景像素。
  - 所有副本使用种子的原始颜色绘制。
  - 生长标记在输出中被擦除。
  - 原始种子保持不变。
- `Key insight`：标记颜色是方向编码器——每种颜色对应一个固定方向。种子的形状作为"印章"被沿方向周期性复制。
</new_puzzle>

- `description`：在含有两个面板的网格中，一个面板中对象的位置模式指定了另一个面板中对象应被保留还是删除。
- `Input structure`：背景为主色。一条分隔线将网格分为上下两个面板。上面板包含若干个不同颜色的小型 4-连通前景对象，散布在不同列中。下面板也包含若干不同颜色的前景对象。上面板中被对象占据的列集合是"活跃列"。
- `Rule`：
  - 找出上面板中包含前景像素的列集合（活跃列）。
  - 在下面板中，保留边界框中心列属于活跃列的对象。
  - 删除（擦除为背景）边界框中心列不属于活跃列的对象。
  - 上面板和分隔线保持不变。
- `Key insight`：上面板中对象的列位置充当"掩码"或"选择器"——它们决定了下面板中哪些列位置的对象存活。对象本身的颜色和形状都是干扰。
</new_puzzle>

- `description`：将网格中的线段图案根据其端点之间的方向关系进行旋转标准化——所有线段都旋转到"从左到右"的标准方向。
- `Input structure`：背景为主色。网格中有若干条不同颜色的一像素宽直线段。每条线段的方向可能是水平（左到右或右到左）、垂直（上到下或下到上）或 45 度对角线。每条线段的两个端点中，一端有一个 red 单像素标记（标识该端为"起点"）。
- `Rule`：
  - 对每条线段，确定从 red 起点到另一端的方向向量。
  - 旋转整条线段（包括起点标记），使其方向变为水平向右。
  - 旋转后的线段放置在原始线段中点位置。
  - 擦除原位置。
- `Key insight`：red 标记不仅标识起点——它与另一端的方向关系编码了需要旋转的角度。所有线段被标准化为同一方向，无论原始朝向如何。
</new_puzzle>

<new_puzzle>
- `description`：在含有压缩编码行的网格中，将每行的"颜色+长度"编码展开为实际的像素行，生成解压后的图案。
- `Input structure`：背景为主色。网格中有若干行"编码行"。每个编码行由若干个 2 像素宽的"编码单元"组成：每个编码单元的第一个像素为颜色指示，第二个像素的垂直高度（从底部到该像素的距离）编码了该颜色的重复次数。编码单元之间以一列背景色分隔。
- `Rule`：
  - 对每个编码行中的每个编码单元，读取颜色 C 和长度 N（编码像素在本编码行内的垂直偏移值）。
  - 将每个编码单元展开为 N 个连续的颜色 C 像素。
  - 将展开后的像素序列从左到右拼接成一个完整的输出行。
  - 所有编码行的展开结果依次从上到下排列，构成输出网格。
- `Key insight`：输入网格不是最终图案——它是一种游程编码的视觉化。解题者需要理解"高度=长度"的编码规则来解压图案。
</new_puzzle>
