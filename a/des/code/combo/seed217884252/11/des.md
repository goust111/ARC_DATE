- `description`：将交叉的彩色线段拆解为独立层，根据交叉处的可见颜色推导出从底到顶的层叠顺序，输出为按层叠顺序排列的颜色条。
- `Input structure`：背景为 black。网格中有若干条不同颜色的直线段（水平、垂直或 45 度对角线），每条线段只有一种颜色。线段之间存在交叉，交叉处只显示上层线段的颜色。
- `Rule`：
  - 从可见像素推断每条线段的完整范围（同色共线像素定义线段范围）。
  - 在交叉点处，可见颜色位于不可见颜色的上方。
  - 从这些遮挡关系中推导出唯一的从底到顶的颜色层叠顺序。
  - 创建一个 Nx1 的输出（N 为线段数），从上到下按从底层到顶层的顺序填入每条线段的颜色。
- `Key insight`：交叉处的可见/不可见关系形成了一个偏序关系图，解题者需要从这些局部遮挡约束中推出全局的线性排序。
</new_puzzle>

<new_puzzle>
- `description`：在每个灰色框架内部，根据框架上方和左方的控制条纹图案，用逐行逐列的颜色交叉规则填充内部。
- `Input structure`：背景为 black。网格中有一个大型 grey 矩形框架。框架上方有一行水平彩色条纹（与框架内部等宽），框架左方有一列垂直彩色条纹（与框架内部等高）。框架内部为背景色。
- `Rule`：
  - 对框架内部的每个像素 (r, c)，读取上方条纹在列 c 的颜色 C_col 和左方条纹在行 r 的颜色 C_row。
  - 如果 C_col 等于 C_row，该像素着色为该颜色。
  - 如果 C_col 不等于 C_row，该像素保持背景色。
  - 保留框架、上方条纹和左方条纹不变。
- `Key insight`：上方和左方的条纹是行列索引，内部填充是两个条纹的逐元素匹配结果；只有行列颜色一致时才着色，形成一种离散的色彩交集图案。
</new_puzzle>

<new_puzzle>
- `description`：将网格中每个前景对象替换为其轮廓的外接多边形的最长边所在方向的一条直线段。
- `Input structure`：背景为 orange。网格中有若干不同颜色的 4 连通前景对象，形状为不规则多边形。
- `Rule`：
  - 对每个前景对象，找到其 bbox 的宽度 W 和高度 H。
  - 如果 W >= H（即对象更宽），在该对象 bbox 的垂直中心行绘制一条长度为 W 的水平线段，颜色为对象颜色。
  - 如果 H > W（即对象更高），在该对象 bbox 的水平中心列绘制一条长度为 H 的垂直线段，颜色为对象颜色。
  - 擦除对象的原始像素（线段位置除外）。
- `Key insight`：对象被简化为其主轴方向上的一条线段；bbox 的宽高比决定了线段方向，bbox 的较长边决定了线段长度。
</new_puzzle>

<new_puzzle>
- `description`：根据每个面板中前景对象的镜像对称轴方向，将面板内对象沿该轴翻转后与原对象叠加。
- `Input structure`：背景为 black。grey 分隔线将网格划分为若干等大面板。每个面板内有一个单色 4 连通前景对象，该对象具有恰好一条镜像对称轴（水平或垂直）。
- `Rule`：
  - 对每个面板内的对象，找到其唯一的镜像对称轴方向。
  - 如果对称轴为水平方向，将对象沿垂直方向翻转后与原对象叠加（取并集）。
  - 如果对称轴为垂直方向，将对象沿水平方向翻转后与原对象叠加。
  - 叠加后的新像素使用 red 颜色绘制，与原对象像素重叠的部分保持原颜色。
- `Key insight`：对称轴的方向决定了翻转的轴向（与对称轴垂直），而不是沿对称轴翻转；解题者需要发现"沿垂直于对称轴的方向翻转"这一反直觉规则。
</new_puzzle>

<new_puzzle>
- `description`：将每个前景框架内部的散点图案按框架大小排序后合并，较大框架的图案作为较小框架图案的背景层。
- `Input structure`：背景为 orange。网格中有若干个不同颜色的一像素厚矩形框架，框架大小各不相同且互不嵌套。每个框架内部有若干该框架同色的散点像素，散点像素的相对位置在所有框架中使用相同的归一化坐标（即等比例缩放后位置相同）。
- `Rule`：
  - 按框架面积从大到小排序。
  - 创建一个与最大框架内部等大的背景画布。
  - 从最大框架开始，将每个框架内部的散点图案（归一化到最大框架尺寸）依次绘制在画布上，后绘制的覆盖先绘制的。
  - 输出为该合并后的画布。
- `Key insight`：不同大小的框架不是独立场景，而是同一图案在不同缩放级别下的视图；合并时大框架的低分辨率图案被小框架的高分辨率图案逐步覆盖。
</new_puzzle>
