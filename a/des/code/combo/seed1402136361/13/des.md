- `description`：将网格中每个前景对象的"骨架"（中轴线）提取出来并用特殊颜色标记，同时擦除骨架以外的对象像素。
- `Input structure`：背景为主色。网格中有若干分离的单色4-连通前景对象，全部使用同一种前景色。每个对象的宽度至少为3个像素，形状为长条形或分叉形。
- `Rule`：
  - 对每个前景对象，逐步从外向内剥离边界像素（即每次移除所有与背景4-邻接的前景像素），直到不能再剥离为止（再剥离会使对象完全消失或断开连通性）。
  - 剩余的像素即为骨架。将骨架像素着色为 red。
  - 将被剥离的像素全部擦除为背景色。
  - 背景不变。
- `Key insight`：骨架提取是一个逐层收缩的过程，最终剩余的是对象的"中轴线"——解题者需要识别出这种从外向内的剥离模式。
</new_puzzle>

<new_puzzle>
- `description`：将网格中分散的单色标记像素按其颜色分组，每组构成一个"星座"，在星座中相邻最近的像素对之间画同色连线。
- `Input structure`：背景为主色。网格中散布着多种颜色的单个前景像素，每种颜色出现2到5次。同色像素之间不相邻。
- `Rule`：
  - 对每种颜色，将该色的所有像素视为一个"星座"。
  - 从像素数最少的星座开始处理，到像素数最多的星座结束。
  - 对每个星座，构建最小生成树：依次连接最近的尚未连通的像素对（距离用行距与列距之和衡量）。
  - 对每条连接边，在两像素之间绘制一条L形路径（先水平后垂直），颜色为星座颜色。路径仅覆盖背景像素，不覆盖其他颜色。
  - 按处理顺序绘制，先画的星座的连线不会被后画的覆盖。
- `Key insight`：同色像素不是独立标记而是星座的节点——需要发现"最近连接"的规则，以及先处理小星座以避免覆盖的顺序规则。
</new_puzzle>

<new_puzzle>
- `description`：检测网格中每行和每列的前景像素分布对称性，在对称中心处绘制十字标记。
- `Input structure`：背景为主色。网格中散布着多种颜色的前景像素，形成若干行和列上的对称分布。部分行中的前景像素关于该行的水平中心左右对称，部分列中的前景像素关于该列的垂直中心上下对称。
- `Rule`：
  - 对每一行检查：该行中的非背景像素位置是否关于该行中点左右对称（即位置 c 有前景像素则位置 W-1-c 也有前景像素，且颜色相同；W 为网格宽度）。
  - 对每一列检查：该列中的非背景像素位置是否关于该列中点上下对称。
  - 如果某行是对称的，在该行的中心位置画一个 red 像素。
  - 如果某列是对称的，在该列的中心位置画一个 blue 像素。
  - 如果某位置同时是行对称中心和列对称中心，着色为 green。
  - 其他像素不变。
- `Key insight`：标记位置由行和列的独立对称性检测决定——三种标记颜色分别对应行对称、列对称和双重对称，需要从样例中归纳出对称性检测规则。
</new_puzzle>

- `description`：将网格中的嵌套矩形框架按层级拆开，从最内层到最外层依次水平排列为独立框架。
- `Input structure`：背景为主色。网格中心有若干同心嵌套的矩形框架（每个框架一像素粗，使用不同颜色），从外到内嵌套。最内层框架内部可能有或没有实心填充。
- `Rule`：
  - 识别所有嵌套的矩形框架层，从最内层到最外层排序。
  - 输出画布上从左到右依次绘制每个框架层：最内层在最左边，最外层在最右边。
  - 每个框架在输出中按其原始大小绘制为独立的矩形框架（不含内部的其他层），框架之间用一列背景色间隔。
  - 如果最内层有实心填充，将其作为第一个对象绘制。
- `Key insight`：嵌套结构需要逐层拆解——输出的排列顺序（内→外=左→右）与输入的空间包含关系相反，需要归纳出这种反转。
</new_puzzle>

<new_puzzle>
- `description`：将网格中每个前景对象沿其自身最长轴翻转，同时将对象颜色替换为其在网格中按面积排名对应的新颜色。
- `Input structure`：背景为主色。网格中有若干分离的单色4-连通前景对象，颜色各不相同。每个对象的边界框是非正方形的矩形（高度和宽度不等）。
- `Rule`：
  - 对每个前景对象，确定其边界框的长轴方向：如果宽度大于高度，长轴为水平方向，则对对象进行水平翻转（左右镜像）；如果高度大于宽度，长轴为垂直方向，则对对象进行垂直翻转（上下镜像）。翻转以对象边界框中心为轴。
  - 将所有对象按面积从大到小排序。按排名分配新颜色：第1名（最大）→ red，第2名 → blue，第3名 → green，第4名 → yellow，第5名 → magenta。
  - 在原位绘制翻转后的对象，使用分配的新颜色。
  - 背景不变。
- `Key insight`：长轴方向决定翻转轴，面积排名决定新颜色——两个独立的属性分别控制几何变换和颜色变换，需要同时发现。
</new_puzzle>
