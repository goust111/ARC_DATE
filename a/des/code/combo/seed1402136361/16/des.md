- `description`：将网格中嵌套的同心矩形框架拆解并水平排列，排列顺序由框架上标记像素的数量从少到多决定。
- `Input structure`：背景为主色。网格中心有若干同心嵌套的一像素粗矩形框架，每个框架使用不同颜色。每个框架的边上嵌有若干同色的额外标记像素（即框架边上的部分位置有双倍粗度的突出）。不同框架的标记像素数量不同。
- `Rule`：
  - 识别每个嵌套框架层及其颜色。
  - 统计每个框架上的标记像素数量（突出于正常一像素粗度的额外像素数）。
  - 按标记像素数量从少到多排序。
  - 在输出中从左到右依次绘制每个框架为独立的矩形框架（按原始大小），框架之间用一列背景色间隔。
  - 标记像素在输出中不保留，仅绘制干净的矩形框架。
- `Key insight`：框架边上的突出标记不是装饰而是排序键——标记数量决定了拆解后的排列顺序，且标记在输出中被"清理"掉。
</new_puzzle>

<new_puzzle>
- `description`：将网格中每个前景对象的边界像素按照其4-邻居中背景像素的数量进行分级着色。
- `Input structure`：背景为主色。网格中有若干分离的单色4-连通前景对象，全部使用同一种前景色（如 grey）。对象形状各异，有些复杂有些简单。
- `Rule`：
  - 对每个前景对象中的每个像素，计算其4-邻居中背景像素的数量（0到4之间）。
  - 根据背景邻居数量重着色：
    - 0个背景邻居（完全被前景包围的内部像素）：着色为 blue。
    - 1个背景邻居（边缘像素）：着色为 green。
    - 2个背景邻居（角落或窄处像素）：着色为 yellow。
    - 3个或4个背景邻居（突出或孤立像素）：着色为 red。
  - 背景不变。
- `Key insight`：输出颜色完全由每个像素的局部邻域结构决定——这是一种"热力图"可视化，将对象的边缘深度转化为颜色。
</new_puzzle>

<new_puzzle>
- `description`：根据面板中前景图案的旋转对称阶数选择变换方式：2阶对称的图案水平翻转，4阶对称的图案缩小为一半，无旋转对称的图案旋转90度。
- `Input structure`：背景为主色。网格被分隔线划分为若干等大的正方形面板。每个面板内有一个居中的单色前景图案。部分图案具有180度旋转对称性（2阶），部分具有90度旋转对称性（4阶），部分不具有旋转对称性。
- `Rule`：
  - 对每个面板中的图案判断其旋转对称性：
    - 如果图案旋转90度后与自身一致（4阶对称）：将图案缩小为左上四分之一区域的内容，居中放置在面板中。
    - 如果图案旋转180度后与自身一致但旋转90度后不一致（2阶对称）：将图案水平翻转。
    - 如果图案不具有旋转对称性（1阶）：将图案顺时针旋转90度。
  - 变换后的图案保持在面板中心。分隔线不变。
- `Key insight`：对称性阶数不是显式标注的，需要从图案形状推断——不同阶数触发完全不同的变换操作，形成一个基于属性的分派规则。
</new_puzzle>

<new_puzzle>
- `description`：将网格中每个前景对象的像素重新排列为一个紧凑的螺旋形图案，螺旋起点和方向由对象内部标记像素的位置决定。
- `Input structure`：背景为主色。网格中有若干分离的单色4-连通前景对象，每个对象内部恰好有一个异色标记像素。对象的像素数量恰好是某个正方形数（如4、9、16、25）。
- `Rule`：
  - 对每个前景对象，计算其像素总数 N（含标记），令 S = sqrt(N)。
  - 确定标记像素在对象边界框中的象限（左上/右上/左下/右下）作为螺旋起始角。
  - 在对象原边界框中心位置创建一个 S x S 的画布。
  - 从起始角开始，沿顺时针方向螺旋向内排列对象像素（按原对象中从左到右、从上到下的扫描顺序读取像素颜色）。标记像素在螺旋中保持其异色。
  - 擦除原始对象位置。
- `Key insight`：标记像素的象限位置选择了螺旋的起始角落，对象面积决定了正方形螺旋的大小——两层信息共同定义螺旋的具体形态。
</new_puzzle>

<new_puzzle>
- `description`：将网格中多个重叠的半透明彩色矩形层恢复为独立的非重叠矩形，通过重叠区域的颜色混合模式推断层叠顺序。
- `Input structure`：背景为主色。网格中可见若干彩色区域，部分区域的颜色是两种基础颜色的"混合色"（在ARC颜色空间中，混合色是一种预设的固定映射，如 red + blue 重叠区域显示为 magenta）。非重叠区域显示原始基础颜色。
- `Rule`：
  - 识别所有可见的基础颜色（仅出现在非重叠区域的颜色）和混合颜色（在重叠区域出现的颜色）。
  - 通过混合色推断两种基础色的重叠：每种混合色对应两种基础色的叠加（映射关系从样例中学习）。
  - 恢复每种基础颜色的完整矩形区域（包括被遮挡的部分）。
  - 输出中将每种基础色的完整矩形独立绘制，从左到右排列（按在原网格中的面积从大到小），之间用一列背景色间隔。
- `Key insight`：混合色区域不是新颜色而是两层叠加的证据——需要先学习颜色混合映射规则，再反向解码还原每层的完整范围。
</new_puzzle>
