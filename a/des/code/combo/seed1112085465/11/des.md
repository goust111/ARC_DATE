- `description`：将网格中每个"容器"内部的彩色像素按颜色分组后，根据每种颜色的像素数量决定该颜色在容器边框上的涂覆位置。
- `Input structure`：背景为 black。网格中有若干由 grey 像素构成的一像素厚正方形框架（"容器"），边长各异。每个容器内部散布着若干不同颜色的单像素标记（2-4 种颜色，每种 1-4 个像素）。
- `Rule`：
  - 对于每个容器，统计内部每种颜色的标记像素数量。
  - 按像素数量排序颜色（从多到少）。
  - 将容器的四边边框按顺时针顺序分为四段（上、右、下、左）。
  - 将数量最多的颜色涂在上边（覆盖 grey），数量第二的颜色涂在右边，第三涂在下边，第四涂在左边。如果只有 2-3 种颜色，则剩余边保持 grey。
  - 容器内部的标记像素被擦除为背景色。
- `Key insight`：内部标记的颜色频率决定了它们在边框上的分配位置——频率排名映射到空间上的顺时针方向，解题者需要同时发现频率排序和方向分配两层规则。
</new_puzzle>

<new_puzzle>
- `description`：根据"种子对"像素之间的相对位移向量，将种子对之间的矩形区域填充为由该位移向量决定的平行斜线条纹。
- `Input structure`：背景为 azure。网格中散布着若干彩色单像素标记，每种颜色恰好出现两次，形成"种子对"。每对种子的两个像素不在同一行也不在同一列。
- `Rule`：
  - 对于每对同色种子像素 P1 和 P2（P1 为更靠近左上角的那个），计算位移向量 (dr, dc) = (P2.row - P1.row, P2.col - P1.col)。
  - 确定 P1 和 P2 围成的轴对齐矩形区域。
  - 在该矩形内，从 P1 开始，沿方向 (sign(dr), sign(dc)) 每步走一个像素绘制对角线，到达矩形边界后平移一个步长重新开始，形成平行斜线条纹（条纹间距由 |dr| 和 |dc| 的最大公约数决定，但由于 ARC 中数量较小，间距通常为 1-3）。
  - 条纹使用种子对的颜色。
  - 种子像素保留在条纹中。
- `Key insight`：种子对的空间偏移不仅定义了填充区域，还编码了条纹的方向和间距——位移向量同时控制了"在哪里画"和"怎么画"。
</new_puzzle>

<new_puzzle>
- `description`：识别网格中每个对象的"骨架方向"（最长轴方向），然后将该对象沿骨架方向拉伸至网格边缘，同时用该对象颜色的"互补色"绘制拉伸轨迹。
- `Input structure`：背景为 black。网格中有若干不同颜色的 4-连通单色前景对象，形状为细长条或不规则形状。每个对象的 bbox 宽高比不为 1（即要么更宽要么更高）。网格中还有一个小型"图例"区域，由若干颜色对组成（每对为两个垂直相邻的像素），展示颜色到互补色的映射。
- `Rule`：
  - 对于每个对象，确定其骨架方向：如果 bbox 宽 > 高，则方向为水平；如果高 > 宽，则方向为垂直。
  - 将对象沿骨架方向平移到最近的网格边缘（保持垂直于骨架方向的坐标不变）。
  - 在平移路径上（从原位置到目标位置之间）用图例中该颜色的互补色填充所经过的背景像素。
  - 对象在目标位置用原色绘制。
  - 图例区域在输出中被擦除。
- `Key insight`：骨架方向决定移动方向，图例提供轨迹颜色——解题者需要发现三层信息：对象形状→方向、图例→轨迹颜色、移动→边缘对齐。
</new_puzzle>

<new_puzzle>
- `description`：在网格中找到所有"完全对称"的对象，将它们的对称轴用特定颜色绘制出来；非对称对象被擦除。
- `Input structure`：背景为 orange。网格中散布着若干由 grey 像素构成的 4-连通前景对象。某些对象具有水平反射对称、垂直反射对称或两者兼具。某些对象完全不对称。
- `Rule`：
  - 对于每个 grey 对象，检查其是否具有水平反射对称（上下对称）和/或垂直反射对称（左右对称）。
  - 如果对象具有水平对称：在对象的水平对称轴行上，将对象范围内的所有像素重着色为 blue（覆盖 grey）。
  - 如果对象具有垂直对称：在对象的垂直对称轴列上，将对象范围内的所有像素重着色为 red（覆盖 grey 和之前画的 blue）。
  - 如果对象同时具有两种对称，则两条轴都绘制（交叉处为 red，因为垂直轴后画）。
  - 完全不对称的对象擦除为背景色。
- `Key insight`：对称性不只是用于分类，而是直接在空间中显现——对称轴被物理绘制在对象上，非对称对象则完全消失。
</new_puzzle>

<new_puzzle>
- `description`：将网格中散布的"像素云"根据颜色分组，每组像素云的 bbox 作为一个"选区"，将选区内的所有像素（包括背景和其他颜色像素）提取后按颜色出现频率重新排列为底部对齐的柱状图。
- `Input structure`：背景为 azure。网格中散布着若干不同颜色的单像素标记（3-5 种颜色，每种 2-6 个像素）。不同颜色的像素位置随机分布，可能交织重叠在同一区域。
- `Rule`：
  - 将所有标记按颜色分组。
  - 对于每种颜色，计算其所有标记像素的 bbox。
  - 统计该 bbox 区域内包含的所有非背景像素总数 N（包括其他颜色的像素，不仅仅是当前颜色）。
  - 输出为一个柱状图：每种颜色对应一列，列高为 N，底部对齐，列间一个像素间隔。列的排列顺序为该颜色自身的像素数量从多到少。每列使用该颜色绘制。
- `Key insight`：颜色的 bbox 是一个"影响范围"，该范围内所有像素（不分颜色）都被计入——解题者需要发现计数的范围不是自身颜色像素，而是 bbox 内的所有前景像素。
</new_puzzle>
