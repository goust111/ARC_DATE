<new_puzzle>
- `description`：将网格中多个"信号灯"对象按其亮起颜色的数量排序，然后根据排名重新分配亮起颜色。
- `Input structure`：背景为 black。网格中有若干 3x1（或 1x3）的"信号灯"对象，每个信号灯由三个垂直（或水平）排列的格子组成。每个格子要么是 grey（熄灭），要么是某种彩色（亮起）。不同信号灯亮起的格子数量不同（0-3 个）。网格的一个边缘有一个由 3 种颜色组成的调色板条带，从左到右（或从上到下）排列。
- `Rule`：
  - 统计每个信号灯亮起（非 grey）的格子数量。
  - 按亮起数量从少到多排序。
  - 将排序后的第 k 个信号灯的所有亮起格子重着色为调色板条带中第 k 个颜色。
  - 熄灭的 grey 格子保持不变。信号灯位置不变。
- `Key insight`：信号灯的原始亮起颜色是干扰信息，真正重要的是亮起数量的排名——排名决定了从调色板中选取哪种颜色重新着色。
</new_puzzle>

<new_puzzle>
- `description`：在包含"模板"和"掩码"的双面板网格中，将模板像素按掩码的孔洞形状裁剪后旋转输出。
- `Input structure`：背景为 orange。一条全高的 grey 垂直分隔条将网格分为左右两个等大面板。左面板包含一个由多种颜色构成的矩形彩色图案（"模板"），图案填满面板大部分区域。右面板包含一个由 maroon 像素构成的封闭矩形框架，框架内部有一个由背景色形成的连通孔洞，孔洞形状不规则。
- `Rule`：
  - 将左面板模板与右面板框架对齐（两面板同样大小，坐标直接对应）。
  - 找到右面板中框架内部的背景色孔洞区域。
  - 从左面板模板中，仅保留与右面板孔洞位置对应的像素，其余位置变为背景色。这形成了"裁剪结果"。
  - 将裁剪结果紧凑裁剪（tight crop）后顺时针旋转 90 度输出。
- `Key insight`：右面板的孔洞是裁剪模板的"饼干切割器"——模板被孔洞形状裁剪后还要旋转，解题者需要发现裁剪和旋转两步操作。
</new_puzzle>

<new_puzzle>
- `description`：将网格中的"种子对"按颜色配对后，在每对种子之间的矩形区域内绘制交替的棋盘格图案，棋盘格使用该对种子的两种颜色。
- `Input structure`：背景为 black。网格中散布着若干单像素彩色标记。每种颜色恰好出现两次，形成若干"种子对"。每对种子的两个像素在水平和垂直方向上都有偏移（即不在同一行也不在同一列）。
- `Rule`：
  - 将同色标记配对。
  - 对于每对标记（颜色为 c），确定两个标记像素围成的轴对齐矩形区域。
  - 在该矩形区域内绘制棋盘格图案，使用颜色 c 和背景色交替（左上角像素使用 c）。
  - 不同对的矩形可能重叠；后处理的对（按颜色在网格中首次出现位置从上到下、从左到右排序，后出现的后处理）覆盖先处理的。
  - 原始标记像素保留在棋盘格中。
- `Key insight`：同色标记的两个位置定义了一个矩形区域，颜色对同时是棋盘格的构成色——解题者需要发现"同色配对→矩形→棋盘格"的三步推理链。
</new_puzzle>

<new_puzzle>
- `description`：从网格边缘的"发射器"像素出发，沿垂直于边缘的方向发射射线，射线颜色在经过每个"变色器"像素时切换为变色器的颜色。
- `Input structure`：背景为 azure。网格的四个边缘上散布着若干单像素"发射器"标记，每个标记使用不同的颜色（非 azure）。网格内部散布着若干单像素"变色器"标记，颜色与发射器不同。发射器和变色器不会位于同一行或同一列上有两个发射器的情况。
- `Rule`：
  - 每个发射器从其所在的边缘位置向网格内部发射一条射线（垂直于所在边缘方向）。
  - 射线初始颜色为发射器的颜色。
  - 射线沿直线前进，涂色所经过的背景像素。
  - 当射线经过一个变色器像素时，射线从该位置之后的颜色切换为变色器的颜色。变色器像素本身被射线颜色覆盖。
  - 射线到达对面边缘时停止。
  - 如果两条射线交叉，先发射的射线（按发射器在边缘上从左到右、从上到下的顺序排列）优先，交叉点使用先到射线的颜色。
- `Key insight`：变色器不是阻挡射线的墙壁，而是改变射线颜色的"染色站"——射线穿透变色器但颜色发生改变。
</new_puzzle>

<new_puzzle>
- `description`：将网格中每个对象的"凸缺陷"区域（对象凸包与对象本身的差集）填充为该对象所在区域的"对面框架色"。
- `Input structure`：背景为 black。网格中有一个大型矩形框架，四边使用不同颜色（上 red、右 blue、下 green、左 yellow），角落为背景色。框架内部散布着若干由 grey 像素构成的 4-连通前景对象，每个对象形状为凹多边形（即其 bbox 内存在属于 bbox 但不属于对象的背景像素——凸缺陷区域）。每个对象恰好有一个凹陷面朝向四个基数方向之一。
- `Rule`：
  - 对于每个 grey 对象，确定其凹陷面朝向的方向 d（即凸缺陷区域相对于对象主体所在的方向）。
  - 找到框架上与方向 d 相对的一边的颜色 c（例如凹陷朝上，则对面是下边，颜色为 green）。
  - 将该对象的凸缺陷区域（bbox 内的背景像素中与对象边界相邻的连通区域）填充为颜色 c。
  - 对象本身和框架保持不变。
- `Key insight`：凹陷方向决定了颜色来源——不是凹陷所朝方向的框架边，而是相反方向的框架边提供填充色。解题者需要先识别凹陷方向，再发现"对面取色"的规则。
</new_puzzle>
