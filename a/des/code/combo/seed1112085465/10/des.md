- `description`：将网格中的"标签精灵"与"目标容器"按照形状互补性配对，然后将标签精灵的颜色涂在目标容器的边框外缘。
- `Input structure`：背景为 black。网格中有若干由 grey 像素构成的封闭矩形框架（"容器"），每个容器的边框上有一个独特的缺口形状（由连续缺失的 grey 像素形成）。网格中还散布着若干小型单色彩色精灵（"标签"），每个标签的形状恰好与某个容器的缺口形状互补（即标签像素恰好可以填补缺口）。
- `Rule`：
  - 将每个标签精灵与其形状互补的容器缺口配对。
  - 将标签精灵的颜色涂在其配对容器的整个外缘（即容器 bbox 向外扩展一像素的环形区域中的所有背景像素）。

  - 容器框架（包括缺口）保持原样。
- `Key insight`：标签的形状不是用来填补缺口的，而是用来识别哪个容器——配对之后，标签颜色被应用在容器的外圈而非缺口处。

<new_puzzle>
- `description`：将网格中的双色对象按其两种颜色的面积比拆分为两个独立的子对象，然后将面积较大的子对象缩小为与较小子对象同样大小的 bbox。
- `Input structure`：背景为 orange。网格中有若干 4-连通的前景对象，每个对象恰好由两种颜色的像素组成（如 blue 和 red 像素交织在一起形成一个连通对象）。两种颜色在对象中的像素数量不同。
- `Rule`：
  - 对于每个双色对象，将其拆分为两个单色子掩码（同色像素组成的集合）。
  - 确定较大子掩码（像素数更多的颜色）和较小子掩码。
  - 保持较小子掩码的位置和形状不变。
  - 将较大子掩码缩放使其 bbox 大小等于较小子掩码的 bbox 大小，然后放置在原始对象 bbox 的正下方（紧贴原 bbox 的下边缘，水平居中对齐）。
  - 擦除较大子掩码的原始位置像素。
- `Key insight`：双色对象的两种颜色不是装饰性交织，而是需要分离的独立层——较大层通过缩放来匹配较小层的尺度。
</new_puzzle>

<new_puzzle>
- `description`：将网格中"指针对象"所指向方向的所有同色像素收集起来，以指针对象为中心绘制一个该颜色的实心正方形，边长等于收集到的像素数。
- `Input structure`：背景为 black。网格中有若干由 3 个像素构成的 L 形"指针对象"（占据 2x2 bbox 的三个格子），每个指针使用不同的颜色。指针的缺失角落指向某个基数方向（上/下/左/右）。在指针所指方向的延长线上（同行或同列），散布着若干与指针同色的单像素标记。
- `Rule`：
  - 对于每个指针对象，确定其指向方向 d（由 2x2 bbox 中缺失角落的位置决定：缺失在右上→指向上，缺失在右下→指向右，缺失在左下→指向下，缺失在左上→指向左）。
  - 沿方向 d 从指针出发，收集该方向上所有同色单像素标记，数量为 n。
  - 擦除指针和所有收集到的标记。
  - 以指针原始位置的中心为中心，绘制一个 n x n 的实心正方形，使用指针的颜色。
- `Key insight`：指针的形状编码了搜索方向，沿该方向的同色像素数编码了输出正方形的大小——方向和计数共同决定了变换结果。
</new_puzzle>

<new_puzzle>
- `description`：在由分隔线划分的面板阵列中，每个面板包含一个图案和一个方向标记；将每个面板的图案沿方向标记指示的方向"推出"到相邻面板中。
- `Input structure`：背景为 azure。全宽的 grey 水平分隔行和全高的 grey 垂直分隔列将网格分成 3x3 的等大矩形面板。每个面板包含一个由彩色像素构成的图案，以及一个靠近面板某一边的 red 单像素方向标记。方向标记靠近面板的上/下/左/右边，表示该面板的图案将被"推向"该方向的相邻面板。
- `Rule`：
  - 读取每个面板中 red 标记靠近的边缘方向 d。
  - 擦除当前面板的图案（保留 red 标记）。
  - 将图案平移到方向 d 的相邻面板中，保持图案在面板内的相对位置不变。
  - 如果多个图案被推到同一个面板中，后到的覆盖先到的（处理顺序：从左到右，从上到下）。
  - 分隔线保持不变。如果方向指向网格边缘外（没有相邻面板），图案消失。
- `Key insight`：方向标记不是移动对象本身的方向，而是将图案跨面板传递的指令——图案离开自己的面板进入邻居的面板。
</new_puzzle>

<new_puzzle>
- `description`：根据每个对象的"边界接触模式"（接触网格的哪些边缘）决定该对象在输出中的旋转角度，然后将所有对象旋转后紧凑排列输出。
- `Input structure`：背景为 black。网格中有若干不同颜色的 4-连通单色前景对象。某些对象的部分像素位于网格的边缘行或边缘列上（即"接触"网格边缘）。每个对象接触 0-2 个网格边缘。
- `Rule`：
  - 不接触任何边缘的对象：不旋转。
  - 仅接触上边缘的对象：旋转 180 度。
  - 仅接触右边缘的对象：逆时针旋转 90 度。
  - 仅接触下边缘的对象：不旋转。
  - 仅接触左边缘的对象：顺时针旋转 90 度。
  - 接触两个边缘的对象（角落接触）：旋转使接触的角落变为左下角。
  - 将所有旋转后的对象紧凑裁剪，按原来在网格中从上到下、从左到右的顺序水平排列输出，对象间一列背景色分隔，底部对齐。
- `Key insight`：边缘接触模式编码了旋转指令——对象与网格边界的相对位置决定了应如何旋转，而非对象的形状或颜色。
</new_puzzle>
