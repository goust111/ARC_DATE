- `description`：将网格中的"轨道环"上的彩色标记沿轨道移动若干步，步数等于环上标记的总数。
- `Input structure`：背景为 black。网格中有若干由 grey 像素构成的一像素宽封闭矩形环形轨道。每个轨道环上散布着若干彩色标记像素（替换了该位置的 grey 像素），每种标记颜色不同。轨道的角落像素也是 grey。
- `Rule`：
  - 对于每个轨道环，沿顺时针方向读取环上的所有像素序列。
  - 统计该环上彩色标记的总数 k。
  - 将所有彩色标记沿顺时针方向移动 k 步（每步移动到轨道上的下一个位置）。
  - 移动后空出的位置恢复为 grey。移动到的新位置替换原来的 grey。
  - 其他轨道像素保持 grey。
- `Key insight`：移动步数不是固定常数，而是由同一轨道上标记的总数动态决定——标记越多，每个标记移动得越远。
</new_puzzle>

- `description`：在包含"参考行"和"查询行"的网格中，根据参考行中颜色块的排列顺序对查询行中的颜色块进行重新排序。
- `Input structure`：背景为 black。网格由若干行组成。第 0 行是"参考行"，由若干不同颜色的连续色块组成（每个色块 1-3 像素宽），从左到右排列。下方的每一行是"查询行"，每行也包含若干连续色块，使用的颜色集合与参考行相同，但排列顺序不同。查询行之间有一行背景色分隔。
- `Rule`：
  - 读取参考行中颜色从左到右的顺序，建立颜色优先级（最左边的颜色优先级最高）。
  - 对于每个查询行，将其色块按参考行中的颜色优先级重新排序（优先级高的色块放在左边）。
  - 每个色块的宽度保持不变，仅改变色块之间的排列顺序。
  - 参考行在输出中保持不变。
- `Key insight`：参考行定义了一个颜色的"字典序"——所有查询行中的色块必须按照这个字典序重新排列，而不是按任何其他属性排序。
</new_puzzle>

- `description`：将网格中的"链式对象"根据链接顺序展开为一行，链接顺序由相邻对象之间的颜色传递关系确定。
- `Input structure`：背景为 azure。网格中有若干 4-连通前景对象，每个对象主要由一种"主色"构成，并且在其边界上有一个不同颜色的"连接点"像素。每个对象的连接点颜色恰好等于另一个对象的主色（形成链式引用关系）。恰好有一个对象没有被任何其他对象的连接点引用（链头），恰好有一个对象的连接点颜色不匹配任何对象的主色（链尾）。
- `Rule`：
  - 从链头开始，通过连接点颜色→下一个对象的主色依次跟踪整条链。
  - 将链上的对象按顺序从左到右紧凑排列在一行输出画布上，对象间一列背景色分隔。
  - 每个对象保持其形状和颜色不变（包括连接点像素）。
- `Key insight`：连接点颜色是"指针"，指向链中的下一个对象——解题者需要发现颜色引用关系并遍历整条链。
</new_puzzle>

<new_puzzle>
- `description`：在网格中检测每个前景对象的"凸性"，将凸对象缩小到其最小外接正方形，将凹对象扩大到其最小外接正方形。
- `Input structure`：背景为 black。网格中有若干由不同颜色构成的 4-连通单色前景对象。某些对象是凸的（bbox 内没有属于 bbox 但不属于对象的背景像素凹陷），某些对象是凹的（bbox 内存在凹陷背景像素）。
- `Rule`：
  - 对于每个对象，判断它是凸还是凹：如果对象的 bbox 内不存在背景色"凹陷"（即对象填满了其 bbox 的每一行中从最左前景像素到最右前景像素之间的所有格子），则为凸；否则为凹。
  - 凸对象：将其缩小为以 bbox 中心为中心的最小正方形（边长 = min(bbox宽, bbox高)），仅保留该正方形内的像素，正方形外的像素擦除。
  - 凹对象：将其 bbox 扩大为以中心为中心的最小正方形（边长 = max(bbox宽, bbox高)），用该对象颜色填充正方形与原 bbox 之间新增的区域。
  - 背景保持不变。
- `Key insight`：凸/凹的判断结果决定了相反的操作方向——凸的缩小、凹的扩大。解题者需要先识别凸凹属性，再应用对应的变换。
</new_puzzle>

<new_puzzle>
- `description`：根据网格中"颜色图例对"定义的颜色映射关系，对每个前景对象的边界像素和内部像素分别应用不同的映射规则。
- `Input structure`：背景为 azure。网格角落有一个由若干水平颜色对组成的小型"图例"区域（每对为两个水平相邻的像素，左色为"边界映射色"，右色为"内部映射色"）。网格中有若干由同一种前景色（grey）构成的 4-连通对象。
- `Rule`：
  - 找到 grey 在图例中的对应条目（grey 出现在某个颜色对的左或右位置）。
  - 读取图例条目：假设 grey 对应的条目为 (c_border, c_interior)。
  - 对于每个 grey 对象，将其边界像素（至少一个 4-邻居为背景色的像素）重着色为 c_border。
  - 将其内部像素（所有 4-邻居都是前景像素的像素）重着色为 c_interior。
  - 图例区域在输出中被擦除。
- `Key insight`：图例的两列不是简单的"旧色→新色"替换，而是分别指定了同一对象边界和内部的不同着色——空间位置（边界 vs 内部）决定了应用图例的哪一列。
</new_puzzle>
