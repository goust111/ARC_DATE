- `description`：在网格中检测每个前景对象的"凸性"，将凸对象缩小到其最小外接正方形，将凹对象扩大到其最小外接正方形。
- `Input structure`：背景为 black。网格中有若干由不同颜色构成的 4-连通单色前景对象。某些对象是凸的（bbox 内没有属于 bbox 但不属于对象的背景像素凹陷），某些对象是凹的（bbox 内存在凹陷背景像素）。
- `Rule`：
  - 对于每个对象，判断它是凸还是凹：如果对象的 bbox 内不存在背景色"凹陷"（即对象填满了其 bbox 的每一行中从最左前景像素到最右前景像素之间的所有格子），则为凸；否则为凹。
  - 凸对象：将其缩小为以 bbox 中心为中心的最小正方形（边长 = min(bbox宽, bbox高)），仅保留该正方形内的像素，正方形外的像素擦除。
  - 凹对象：将其 bbox 扩大为以中心为中心的最小正方形（边长 = max(bbox宽, bbox高)），用该对象颜色填充正方形与原 bbox 之间新增的区域。
  - 背景保持不变。
- `Key insight`：凸/凹的判断结果决定了相反的操作方向——凸的缩小、凹的扩大。解题者需要先识别凸凹属性，再应用对应的变换。

## 实现要求

1. `main(grid)` 必须实现新题描述中的确定性转换规则，不能只识别 `generate_input()` 的固定模板。
2. `generate_input()` 必须随机生成多样样例，不能固定死。随机维度应覆盖：网格大小、对象数量、位置、颜色、方向、形状参数或关键分支。
3. 生成器必须保证输入满足 `main()` 的隐式假设：对象不重叠、不越界、特殊标记唯一或可区分、匹配关系无歧义、关键分支出现概率相同。
4. 禁止把 ARC 颜色 id 、亮度、拼写等当作人类不可见的数值语义参与排序、大小比较或隐藏映射。颜色变化必须有可见结构线索。注意颜色亮度、拼写等也是不可见信息，若描述中出现违规的颜色id或者亮度，可自行使用少量的固定颜色替代，但注意生成时要在三个以内输入输出网格中对所有变换100%覆盖度。
