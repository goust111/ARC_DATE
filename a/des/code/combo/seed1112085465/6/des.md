<new_puzzle>
- `description`：从分隔线划分的面板阵列中，找出每列面板中"独一无二"的图案，将其提取并按列顺序水平拼接输出。
- `Input structure`：背景为 black。全宽的 maroon 水平分隔行和全高的 maroon 垂直分隔列将网格分成若干等大的矩形面板（如 4 行 3 列）。同一列的所有面板中，大多数面板包含相同的彩色图案，但恰好有一个面板的图案与该列其他面板不同。
- `Rule`：
  - 对于每列面板，逐像素比较所有面板，找出与其他面板不同的"独特面板"。
  - 将每列的独特面板提取出来。
  - 按原来的列顺序从左到右水平拼接所有独特面板，面板间用一列背景色分隔。
  - 输出高度等于单个面板高度，宽度为所有面板宽度加分隔列的总和。
- `Key insight`：每列中的冗余副本是用来衬托异常的背景——解题者需要逐列进行"找不同"，然后将结果横向拼接。
</new_puzzle>

<new_puzzle>
- `description`：将网格中每个"容器"对象内部的彩色像素按颜色分组后重新排列为底部对齐的分层色带，层的顺序由每种颜色的像素数量决定。
- `Input structure`：背景为 azure。网格中有若干由 grey 像素构成的封闭矩形框架（一像素厚），每个框架内部散布着若干不同颜色的前景像素（如 red、blue、green 等），分布无规律。
- `Rule`：
  - 对于每个框架，统计其内部每种颜色的像素数量。
  - 将框架内部清空为背景色。
  - 按颜色数量从多到少排序。
  - 从框架内部底行开始，逐行向上填充：数量最多的颜色填满最底部若干行（每行填满框架内部的完整宽度），然后次多的颜色填上面若干行，以此类推。每种颜色占据的行数等于其像素数除以框架内部宽度（向上取整）。
  - 框架本身保持不变。
- `Key insight`：散乱的内部像素不是按位置保留的，而是按颜色频率重新"沉淀"为分层色带——解题者需要发现频率排序和底部堆叠的双重规则。
</new_puzzle>

<new_puzzle>
- `description`：根据每个对象边界上"触碰标记"的数量决定对象的缩放倍数，然后将缩放后的对象放置在标记重心的位置。
- `Input structure`：背景为 black。网格中有若干由不同颜色构成的 4-连通单色前景对象。每个对象的边界外侧紧邻着若干 red 单像素标记（标记与对象像素 4-邻接）。不同对象的标记数量不同（1-4 个）。
- `Rule`：
  - 对于每个对象，数其边界外侧 4-邻接的 red 标记数量 n。
  - 将对象的归一化掩码缩放 n 倍（每个原始像素变为 nxn 的方块）。
  - 擦除原对象和其所有 red 标记。
  - 将缩放后的对象放置在所有 red 标记的位置重心处（取标记像素坐标的平均值，向下取整），使缩放后对象的 bbox 中心对齐到该重心。
  - 超出网格的部分被裁剪。
- `Key insight`：标记同时编码了缩放倍数（数量）和目标位置（重心）——同一组标记承担两个不同角色。
</new_puzzle>

<new_puzzle>
- `description`：将网格中散布的"箭头精灵"的指向方向汇总，在网格边缘对应的边上绘制汇总计数条。
- `Input structure`：背景为 orange。网格中散布着若干由 3 个像素构成的箭头精灵，每个箭头精灵占据一个 2x2 bbox 的三个格子（L 形），缺失的角落指示箭头方向（缺失右上角=指向右上，以此类推，但仅取基数方向：缺失的角落在上面两个位置之一时箭头指向上，在下面两个位置之一时指向下，在左边两个位置之一时指向左，在右边两个位置之一时指向右）。箭头颜色各不相同。
- `Rule`：
  - 对于每个箭头，根据其 2x2 bbox 中缺失角落的位置确定指向方向（上/下/左/右）。
  - 统计指向每个方向的箭头数量。
  - 在网格的对应边缘上绘制该数量长度的 maroon 条：指向上的箭头在上边缘从左开始画 maroon 条，指向下的在下边缘从左开始画，指向左的在左边缘从上开始画，指向右的在右边缘从上开始画。
  - 箭头精灵本身保持不变。
- `Key insight`：箭头精灵的形状方向性是投票信号，投票结果以边缘计数条的形式汇总——解题者需要先发现方向编码规则，再发现边缘汇总的统计机制。
</new_puzzle>

<new_puzzle>
- `description`：将网格中的对象按"包含关系"构建嵌套树，然后在输出中将树的每一层用不同的颜色重绘，颜色由层深度决定。
- `Input structure`：背景为 black。网格中有若干由同一颜色（grey）构成的 4-连通前景对象。某些对象完全位于另一个对象的 bbox 内部（即被"包含"），形成嵌套关系。嵌套可以多层（最多 4 层）。
- `Rule`：
  - 构建对象的包含树：如果对象 A 的 bbox 完全包含在对象 B 的 bbox 内部且 A 不被 B 和 A 之间的任何中间对象包含，则 A 是 B 的直接子节点。
  - 最外层（不被任何对象包含）的对象为树的根节点，深度为 0。
  - 按深度着色：深度 0 着色 blue，深度 1 着色 red，深度 2 着色 green，深度 3 着色 yellow。
  - 背景保持不变。
- `Key insight`：所有对象初始颜色相同，输出颜色完全由嵌套深度决定——解题者需要发现 bbox 包含关系所构成的层次结构，并归纳深度到颜色的固定映射。
</new_puzzle>
