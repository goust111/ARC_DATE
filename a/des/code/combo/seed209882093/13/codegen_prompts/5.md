- `Input structure`：
  - 网格尺寸至少为 6×6。
  - 网格最外圈一圈像素构成"边框"，其余为"内部"。
  - 内部区域包含由 2 至 4 种前景色构成的水平条纹图案——每条条纹为整行同色，多种颜色交替重复。
  - 边框的上边（从左到右，不含两个角像素）包含若干个散布的非灰色彩色标记像素，其余位置为灰色（grey）。
  - 边框的左边（从上到下，不含两个角像素）也包含同样数量的非灰色彩色标记像素，其余位置为灰色。
  - 上边标记和左边标记的颜色集合完全相同（都是同一组颜色），但排列顺序不同。
  - 边框的右边、下边和四个角像素全部为灰色。

- `Rule`：
  - 从上边框的彩色标记中，按从左到右的出现顺序提取颜色序列 A = [a1, a2, ..., ak]。
  - 从左边框的彩色标记中，按从上到下的出现顺序提取颜色序列 B = [b1, b2, ..., bk]。
  - 建立颜色置换映射：a1→b1, a2→b2, ..., ak→bk。
  - 将此映射应用到内部区域每个像素：若该像素颜色等于某个 ai，则替换为 bi；否则保持不变。
  - 边框所有像素保持不变。

- `Key insight`：
  - 第一层推理：需要识别出边框上边和左边的彩色标记不是装饰，而是编码了一个颜色映射关系——上边读出"原始颜色"序列，左边读出"目标颜色"序列。
  - 第二层推理：映射关系是纯粹的位置对应（上边第 k 个标记色→左边第 k 个标记色），不是按颜色名的任何内在规律。需要解题者通过对比多个样例中内部条纹颜色的变化来反推出边框标记的编码含义。
