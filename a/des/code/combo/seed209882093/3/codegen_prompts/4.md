- `Input structure`：
  - 背景为 black。
  - 网格中有一个较大的 grey 矩形实心区域作为"画布"。
  - 画布内部有若干 red 单像素标记点，散布在画布范围内不同位置。
  - 画布外部有一个小型图案（由多种非 black、非 grey、非 red 颜色组成的 4-连通区域），这是"印章"。印章的 bounding box 为矩形，内部包含背景色（black）像素和彩色像素构成的图案。
  - 印章旁边有一个 red 单像素作为印章的"锚点"，位于印章 bounding box 的某个角落外侧紧邻位置。

- `Rule`：
  - 将画布视为坐标系。对每个画布内的 red 标记点：
    - 判断该标记点位于画布中心的哪个象限（左上、右上、左下、右下）。画布中心取 bounding box 的几何中心，行列各取中值。
    - 左上象限：印章原样（不翻转）。右上象限：印章水平翻转（左右镜像）。左下象限：印章垂直翻转（上下镜像）。右下象限：印章水平+垂直翻转（旋转 180 度）。
    - 将对应翻转后的印章图案以 red 标记点对齐印章锚点的位置，粘贴到画布上。印章中的 black 像素不覆盖画布（即只粘贴印章中的彩色像素）。
  - 多个标记点的印刷按从上到下、从左到右的顺序执行，后印刷的覆盖先印刷的。
  - 粘贴完成后，所有 red 标记点像素被移除（恢复为 grey）。画布外部的印章和锚点保持不变。

- `Key insight`：解题者需要先识别印章-锚点的空间关系来确定对齐方式，再发现标记点的象限位置决定翻转模式——这不是简单的"在标记处复制印章"，而是象限驱动的对称变换。两层规则（位置对齐 + 象限翻转）需要从样例中分别归纳。
