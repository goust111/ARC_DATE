- `description`：根据封闭区域内部"种子"像素的颜色，从区域边界的对应颜色缺口处向外生长出与种子数量等长的射线。

- `Input structure`：
  - 背景为 black。
  - 网格中有若干用 grey 像素围成的封闭矩形区域（边框厚度为 1 像素）。每个矩形的四条边上各有恰好零个或一个缺口（缺口为边框上缺失的一个 grey 像素）。
  - 每个矩形内部散布着若干彩色"种子"像素（颜色可为 red、blue、green、yellow 等非 black、非 grey 颜色）。同一矩形内部所有种子像素颜色相同。
  - 每个矩形的缺口处，在边框外侧紧邻缺口的那个像素是一个与内部种子颜色相同的单像素标记，用于标示缺口归属方向。

- `Rule`：
  - 对每个封闭矩形区域，数出其内部种子像素的个数 N。
  - 找到该矩形边框上所有缺口。每个缺口确定一个朝外的方向（上边缺口朝上、下边缺口朝下、左边缺口朝左、右边缺口朝右）。
  - 从缺口位置出发，沿朝外方向绘制一条长度为 N 的射线，颜色与内部种子颜色相同。射线的第一个像素覆盖缺口外侧的那个标记像素位置，依次向外延伸共 N 个像素。
  - 矩形内部的种子像素和边框保持不变。

- `Key insight`：种子像素不是装饰——它们的数量编码了射线长度；缺口的边框方位编码了射线方向。解题者需要先识别"计数驱动长度"的映射，再理解"缺口方位驱动方向"的映射，两层规则叠加才能还原完整变换。
</new_puzzle>

- `description`：将网格中散落的同色像素对视为"传送门"，把每个独立形状通过传送门入口吸入、从出口按镜像方式弹出到对侧空间。

- `Input structure`：
  - 背景为 black。
  - 网格中有一条贯穿整个网格的 grey 水平分隔线（厚度 1 像素），将网格分为上半区和下半区。
  - 上半区和下半区各有若干小型彩色形状（由 4-连通的同色像素组成，颜色非 black、非 grey、非 maroon）。
  - 分隔线上有若干 maroon 像素对：每对由分隔线上方紧邻一行和下方紧邻一行的同一列上各一个 maroon 像素组成，构成一个"传送门"。每个传送门占据一列。
  - 每个形状的 bounding box 的水平范围恰好覆盖且仅覆盖一个传送门列。

- `Rule`：
  - 对每个形状，找到其 bounding box 水平范围内的传送门列。
  - 将该形状从原来所在的半区（上或下）移除。
  - 将形状水平镜像翻转（左右翻转），然后放置到分隔线的另一侧半区。放置时，形状的传送门列对齐不变，形状与分隔线的垂直距离保持与原来相同（即形状边缘到分隔线的行数不变，但方向从上变下或从下变上）。
  - 分隔线和 maroon 传送门像素保持不变。

- `Key insight`：解题者需要先识别 maroon 像素对作为"传送门"的功能性角色（而非装饰），再发现形状穿越传送门时发生了水平镜像翻转，最后确认距离守恒规则。传送门匹配和镜像变换是两个需要独立归纳的推理层。
</new_puzzle>

<new_puzzle>
- `description`：在网格中找到由边框颜色编码的"模板框"和散落的"碎片"像素群，将碎片按颜色匹配填入对应模板框内部，填充时碎片的相对布局需旋转至与模板框开口方向一致的朝向。

- `Input structure`：
  - 背景为 black。
  - 网格中有若干矩形空心边框（边框厚度 1 像素），每个边框由单一颜色绘制（如 red、blue、green 等）。每个边框的四条边中恰好有一条边完全缺失（即该边框呈 U 形，有一个开口方向：上、下、左或右）。边框内部全为 black。
  - 网格中另有若干由彩色像素组成的小型碎片图案（4-连通区域），每个碎片的颜色与某个边框颜色相同。碎片位于所有边框外部。
  - 每种颜色恰好对应一个边框和一个碎片。
  - 所有碎片在输入中均朝向同一个参考方向（例如所有碎片都可视为"开口朝上"的默认朝向）。

- `Rule`：
  - 将每个碎片与同色的边框配对。
  - 确定该边框的开口方向。确定所有碎片共同的默认朝向（通过观察样例归纳，例如默认朝上）。
  - 计算从默认朝向到边框开口方向所需的顺时针旋转次数（0度、90度、180度、270度）。
  - 将碎片旋转相应角度后，放置在边框内部的中心位置（碎片 bounding box 在边框内部空间中水平和垂直方向均居中；若无法精确居中则偏向开口方向的对侧）。
  - 边框本身保持不变。碎片原位置清除为 black。

- `Key insight`：解题者首先要发现边框开口方向的差异并将其与碎片旋转关联——开口方向不是装饰性差异，而是旋转指令。其次要归纳出所有碎片共享一个默认朝向，从而推出每个碎片需要旋转多少度。颜色匹配是第一层，旋转对齐是第二层需要独立归纳的规则。
</new_puzzle>

<new_puzzle>
- `description`：识别网格中由不同颜色标记的"源区域"和"印章区域"，将印章区域的图案按源区域内标记点的位置进行多次重复印刷，印刷时根据标记点在源区域内的象限决定印章的翻转方式。

- `Input structure`：
  - 背景为 black。
  - 网格中有一个较大的 grey 矩形实心区域作为"画布"。
  - 画布内部有若干 red 单像素标记点，散布在画布范围内不同位置。
  - 画布外部有一个小型图案（由多种非 black、非 grey、非 red 颜色组成的 4-连通区域），这是"印章"。印章的 bounding box 为矩形，内部包含背景色（black）像素和彩色像素构成的图案。
  - 印章旁边有一个 red 单像素作为印章的"锚点"，位于印章 bounding box 的某个角落外侧紧邻位置。

- `Rule`：
  - 将画布视为坐标系。对每个画布内的 red 标记点：
    - 判断该标记点位于画布中心的哪个象限（左上、右上、左下、右下）。画布中心取 bounding box 的几何中心，行列各取中值。
    - 左上象限：印章原样（不翻转）。右上象限：印章水平翻转（左右镜像）。左下象限：印章垂直翻转（上下镜像）。右下象限：印章水平+垂直翻转（旋转 180 度）。
    - 将对应翻转后的印章图案以 red 标记点对齐印章锚点的位置，粘贴到画布上。印章中的 black 像素不覆盖画布（即只粘贴印章中的彩色像素）。
  - 多个标记点的印刷按从上到下、从左到右的顺序执行，后印刷的覆盖先印刷的。
  - 粘贴完成后，所有 red 标记点像素被移除（恢复为 grey）。画布外部的印章和锚点保持不变。

- `Key insight`：解题者需要先识别印章-锚点的空间关系来确定对齐方式，再发现标记点的象限位置决定翻转模式——这不是简单的"在标记处复制印章"，而是象限驱动的对称变换。两层规则（位置对齐 + 象限翻转）需要从样例中分别归纳。
</new_puzzle>

- `description`：网格中多个同构形状各自缺失不同的局部，利用所有副本的并集重建完整形状，然后用完整形状替换每个残缺副本。

- `Input structure`：
  - 背景为 black。
  - 网格被 green 网格线分割为若干等大的矩形单元格（类似棋盘格局，green 线厚度 1 像素）。
  - 每个单元格内部包含一个用同一种颜色（如 blue）绘制的图案。所有单元格中的图案原本是同一形状的副本，但每个副本都被随机擦除了一部分像素（变为 black），使得没有任何单个副本是完整的。
  - 任意被擦除的像素位置，在至少一个其他副本中是完好的（即所有副本的并集构成完整形状）。

- `Rule`：
  - 将所有单元格中的图案在相同的局部坐标系下取并集，得到完整的原始形状。
  - 用完整形状替换每个单元格中的残缺图案。即每个单元格都绘制完整的形状副本。
  - green 网格线保持不变。

- `Key insight`：单独看每个单元格都是残缺的，解题者不能简单地找"最完整的那个"——必须意识到所有副本是同一形状的互补碎片，需要叠加所有副本才能还原完整形状。核心推理在于发现"跨单元格并集重建"这一非局部操作，而非对每个单元格独立处理。
</new_puzzle>

<new_puzzle>
- `description`：将网格中的彩色路径段按颜色亮度排序后首尾相接，拼成一条从起点标记出发的连续折线，每段路径在拐点处按下一段的行进方向延伸。

- `Input structure`：
  - 背景为 black。
  - 网格中有一个 yellow 单像素作为起点标记。
  - 网格中散布着若干条互不相连的直线段（水平或垂直，长度大于等于 2 像素），每条线段颜色各不相同，使用以下颜色的子集：blue、red、green、magenta、orange、maroon、grey。
  - 每条线段独立放置，不与其他线段或起点标记相邻。
  - 线段数量不超过 6 条。

- `Rule`：
  - 将所有线段按颜色亮度从深到浅排序。排序规则为固定顺序：maroon（最深）、blue、green、red、magenta、orange、grey（最浅）。
  - 从 yellow 起点标记开始，依次连接排序后的线段。第一条线段（最深色）的一端放在起点标记的正右方（起点标记右邻像素为该线段的第一个像素），方向为该线段原始的朝向（水平或垂直）。
  - 后续每条线段接在前一条线段的末端：在前一条线段的末尾像素沿其延伸方向再前进一格作为拐点，然后新线段从该拐点沿新线段自身的朝向（水平或垂直，必定与前一段垂直）延伸，延伸方向为"向下或向右"优先（即垂直段向下延伸、水平段向右延伸；若该方向会超出网格则反向）。
  - 拐点像素颜色为前一段和后一段中较浅的颜色。
  - 所有线段的原始位置清除为 black。起点标记 yellow 像素保留。

- `Key insight`：散落的线段看似无关，但它们的颜色隐含了拼接顺序（深到浅），每段的长度和朝向决定折线的几何形状。解题者需要先发现颜色排序规则（非字母序、非出现位置，而是视觉亮度序），再理解交替方向的拼接机制和拐点着色规则，三层推理逐步叠加。
</new_puzzle>

<new_puzzle>
- `description`：根据每个彩色区域中嵌入的方向箭头标记，将该区域沿箭头方向平移，平移距离等于区域内非箭头像素的行数（高度）。

- `Input structure`：
  - 背景为 azure。
  - 网格中有若干互不重叠的矩形实心彩色区域（颜色为 red、green、blue、yellow 等，非 azure、非 black）。
  - 每个矩形区域内部嵌入一个由 black 像素组成的箭头标记。箭头标记由一条长 3 像素的直线段和末端的一个 1 像素偏移构成方向指示：向右箭头为水平 3 像素线段，末端（右端）上方或下方偏移 1 像素形成箭头尖（具体地，右箭头形如：第一行第 3 列 1 个 black 像素，第二行第 1-3 列 3 个 black 像素，共 4 个 black 像素构成向右指的箭头）。向左、向上、向下的箭头以此类推，分别为对应方向的旋转版本。
  - 每个矩形区域恰好包含一个箭头，箭头完全在矩形内部。

- `Rule`：
  - 对每个矩形区域，识别其中 black 箭头的朝向（上、下、左、右）。
  - 计算该矩形区域的高度 H（行数，包含箭头所占行）。
  - 将整个矩形区域（包括其中的 black 箭头）沿箭头朝向平移 H 个像素。原位置恢复为 azure 背景。
  - 如果平移后超出网格边界，则区域被裁剪到网格范围内（超出部分消失）。
  - 多个区域的平移互不影响（先全部擦除原位置，再全部绘制新位置；若有重叠，行索引较小的区域在上层）。

- `Key insight`：箭头不仅编码平移方向，平移距离也隐藏在区域自身的几何属性（高度）中而非显式给出。解题者需要先破解箭头的方向编码方式，再发现"高度即距离"这一非显然的映射关系。
</new_puzzle>
