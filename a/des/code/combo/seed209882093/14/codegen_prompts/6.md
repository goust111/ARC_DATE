- `Input structure`：
  - 背景为 Black。
  - 网格中有若干个互不接触的彩色连通对象（4-连通），每个对象由单一非 Black 颜色组成，形状不规则但边界框不超过 5x5。
  - 每个对象的某一侧（上、下、左或右）紧邻一个由 Azure 像素组成的箭头标记。箭头由 3 个 Azure 像素构成：一个像素为箭头尖端，另外两个像素在尖端后方形成箭尾的 V 形（例如向右箭头为：左上和左下各一个 Azure 像素，右侧中间一个 Azure 像素）。箭头指向远离对象的方向。
  - 每个箭头尖端与对象边界框之间的间距（以像素为单位）即为"步数"，每步等于对象在箭头方向上的边界框尺寸。

- `Rule`：
  - 对每个对象，读取其箭头的指向方向 D 和尖端到对象边界框的距离 G（像素数）。
  - 沿方向 D，将对象平移 G 个"步长"（每步长度 = 对象边界框在 D 方向上的尺寸）。
  - 在目标位置放置对象的翻转副本：若 D 为左或右，则对图案执行水平翻转；若 D 为上或下，则对图案执行垂直翻转。
  - 原始对象保留在原位，箭头标记在输出中清除为 Black。

- `Key insight`：箭头不仅编码了移动方向，其与对象的间距还编码了移动步数（步长由对象自身尺寸定义），而移动方向同时隐含了翻转轴——解题者需要同时从箭头中解读三重信息（方向、距离、翻转方式），这三者耦合在同一个标记中是该题的核心隐蔽性来源。
