- `description`：网格中的彩色十字标记既指定了重涂颜色，又通过臂长定义了作用范围——影响范围内的非背景像素被统一染为十字臂的颜色，十字自身随后消失。

- `Input structure`：
  - 背景色为 Azure。
  - 网格中散布若干彩色像素块和小型对象（各种颜色，形状不一）。
  - 网格中有 2 至 4 个"十字标记"：每个十字标记由一个 Grey 中心像素和四条等长的臂组成（上下左右各延伸相同长度，臂长 2 至 4 像素），四条臂上的像素颜色相同但各十字可能不同（如一个十字臂为 Red，另一个臂为 Blue）。
  - 十字之间不重叠，十字的臂可能穿过背景或穿过已有的彩色像素。

- `Rule`：
  - 对每个十字标记独立操作（如果影响范围重叠，后处理的十字覆盖先处理的结果；处理顺序为从左到右、从上到下）：
  - 第一步——确定影响范围：十字的臂长为 L，则该十字的影响范围为以十字中心为中心的 (2L+1) x (2L+1) 正方形区域。
  - 第二步——重涂：十字臂的颜色为 C。对于影响范围内每一个非 Grey、非 Azure 的像素（即已有颜色的像素），将其颜色替换为 C。对于影响范围内的 Azure 背景像素，保持不变。
  - 第三步——移除十字：将所有十字标记的像素（Grey 中心和臂像素）全部擦除为 Azure 背景色。

- `Key insight`：十字标记是一种"作用力源"——它的臂长定义了作用范围的大小，臂的颜色定义了重涂颜色。解题者需要先理解十字的几何结构（Grey 中心 + 等长同色臂）来区分十字标记与普通对象（第一层推理），然后发现臂长与影响范围的对应关系（臂长 L 对应 (2L+1)x(2L+1) 正方形）以及颜色替换规则（第二层推理）。十字在完成使命后自我消除，进一步增加了从输出反推规则的难度。
</new_puzzle>
