- `description`：根据边框缺口的朝向选择内部图案的投影方向，再将投影条纹的长度编码为对应颜色的填充深度。

- `Input structure`：
  - 背景色为 Black。
  - 网格中散布若干中等大小（约 5x5 至 8x8）的矩形边框，每个边框由单一颜色绘制（如 Red、Blue、Green 等），且每个边框恰好有一条边存在一个连续缺口（即该边上有若干连续像素被擦除为 Black）。
  - 每个边框内部包含一个由另一种颜色绘制的小型不规则图案（占据若干像素，不触碰边框本身）。

- `Rule`：
  - 第一步——确定投影方向：观察每个边框的缺口位于哪条边（上、下、左、右）。缺口所在边的朝外方向即为该边框的"投影方向"。例如缺口在上边，则投影方向为向上。
  - 第二步——计算投影条纹：将内部图案沿投影方向做正交投影（即沿投影方向把图案压扁到一条线上）。对于投影方向为上或下的情况，将图案按列压扁，得到一个水平条纹序列；对于左或右，按行压扁，得到一个垂直条纹序列。条纹中每一段的长度等于该列（或行）中图案像素的个数。
  - 第三步——填充输出：清空边框内部，然后从缺口所在边的内侧开始，沿投影方向的反方向逐列（或逐行）绘制填充条。每一列（或行）的填充条长度等于第二步中对应位置的投影像素计数，颜色使用内部图案的颜色。填充条从缺口边内侧起画，向边框内部延伸。
  - 边框本身和缺口保持不变；背景其余部分不变。

- `Key insight`：缺口不仅指示了"出口"方向，还隐含地定义了内部图案的投影轴——解题者必须先从缺口位置推断投影方向，再将不规则图案转化为沿该方向的密度直方图，最后将直方图从缺口内侧"灌入"边框。两步推理缺一不可：缺口→投影轴是第一层归纳，图案→密度条是第二层归纳。
</new_puzzle>

- `description`：将散落的彩色碎片按照隐藏的模板网格对齐拼合，模板网格的结构需要从碎片的公共间距中反推。

- `Input structure`：
  - 背景色为 Black。
  - 网格中散布若干小型彩色图案碎片（每个碎片由 2 至 6 个同色像素组成，呈 4-连通），颜色各不相同（如 Red、Blue、Green、Yellow、Magenta 等）。
  - 这些碎片看似随意放置，但实际上它们的位置可以被一个不可见的等间距矩形网格（如 4x4 或 5x5 的单元格大小）完美对齐——即每个碎片的所有像素在对该隐藏网格取模后，落在同一个单元格内的相同相对位置。
  - 碎片之间不重叠，且每个碎片完全位于某一个隐藏网格单元格内。

- `Rule`：
  - 第一步——推断隐藏网格：观察所有碎片的位置坐标，找到一个周期（行周期 Pr、列周期 Pc），使得每个碎片的像素坐标对 (Pr, Pc) 取模后，碎片之间不冲突（无重叠）。这个周期就是隐藏网格的单元格大小。可以通过碎片之间的间距的公约数来发现。
  - 第二步——叠合碎片：将所有碎片投射到一个大小为 Pr x Pc 的输出网格中。每个碎片像素的输出位置为其坐标对 (Pr, Pc) 取模后的余数坐标。不同碎片的颜色填入对应位置，背景保持 Black。
  - 输出是一个 Pr x Pc 的小网格，包含所有碎片叠合后的彩色图案。

- `Key insight`：碎片的绝对位置看似随机，但它们共享一个隐藏的空间周期。解题者必须首先从碎片间的位置关系中发现这个周期（第一层推理），然后将所有碎片折叠到一个周期单元中拼合出完整图案（第二层推理）。关键线索是碎片之间的行距和列距都是某个固定值的整数倍。
</new_puzzle>

<new_puzzle>
- `description`：识别每个封闭区域内的"种子"颜色像素，用种子颜色沿区域边界的内壁涂抹，涂抹的圈数由种子像素的数量决定。

- `Input structure`：
  - 背景色为 Black。
  - 网格中有若干由 Grey 像素绘制的封闭区域轮廓（4-连通闭合环，厚度为 1 像素）。每个封闭区域的形状不同（可以是矩形、L 形、不规则多边形等），大小约 6x6 至 12x12。
  - 每个封闭区域内部有 1 至 3 个同色"种子"像素（颜色非 Black 且非 Grey），放置在区域内任意位置。不同区域的种子颜色互不相同。
  - 区域之间不接触，Grey 轮廓之间至少隔一个 Black 像素。

- `Rule`：
  - 对每个封闭区域独立操作：
  - 第一步——计数种子：数出该区域内种子像素的数量 N（1 至 3）。
  - 第二步——内壁涂抹：从 Grey 轮廓的内侧开始，将最靠近轮廓的第 1 层内部像素全部涂为种子颜色。如果 N >= 2，则继续将第 2 层（距离轮廓 2 步的内部像素）也涂为种子颜色。如果 N = 3，则第 3 层也涂。这里"第 k 层"定义为：区域内部所有与 Grey 轮廓的 4-连通最短路径恰好为 k 的像素。
  - 第三步——种子像素本身被涂抹覆盖（如果它们位于被涂抹的层内），或保持种子颜色（如果在更深层）。
  - Grey 轮廓本身不变，背景不变。

- `Key insight`：种子像素的作用是双重的——它们的颜色决定涂抹色，它们的数量决定涂抹的层数（深度）。解题者需要先发现"种子数量 = 涂抹圈数"这一数量-几何映射关系（第一层推理），然后理解"涂抹是从边界向内逐层扩展"的空间填充方式（第二层推理）。仅看颜色或仅看位置都不足以解题。
</new_puzzle>

<new_puzzle>
- `description`：在分隔线两侧的面板中，左侧面板的彩色路径编码了右侧面板中对象的变换指令序列，路径的转弯方向依次对应旋转操作。

- `Input structure`：
  - 背景色为 Black。
  - 一条 Grey 色的竖直分隔线将网格分为左右两个面板。
  - 右侧面板：包含若干小型彩色对象（每个对象由 3 至 5 个同色像素构成可辨识的非对称形状，如 L 形、T 形等），每个对象颜色不同，彼此不接触。
  - 左侧面板：包含与右侧对象一一对应的彩色路径。每条路径的颜色与右侧某个对象的颜色相同。每条路径是由同色像素组成的 4-连通单像素宽折线，从左侧面板的左边缘某处出发，向右延伸并可能有若干次直角转弯（仅水平和垂直方向），最终到达分隔线处。

- `Rule`：
  - 对每种颜色，找到左侧面板中该颜色的路径和右侧面板中该颜色的对象。
  - 沿路径从左边缘到分隔线的方向遍历，记录每次转弯的方向：如果路径从当前行进方向向左转（逆时针 90 度），记为"左转"；向右转（顺时针 90 度），记为"右转"。
  - 对右侧面板中对应的对象，按照路径转弯的顺序依次施加旋转操作：每遇到一个"左转"，将对象逆时针旋转 90 度；每遇到一个"右转"，将对象顺时针旋转 90 度。旋转以对象自身的中心为轴。
  - 将旋转后的对象绘制在其原位置（对象的中心像素不动）。左侧面板在输出中被清空为 Black，分隔线保留。

- `Key insight`：左侧面板的路径不是装饰——它的几何形态（具体是转弯序列）编码了对右侧对象的操作指令。解题者必须先发现路径颜色与对象颜色的配对关系（显而易见的前置步骤），然后发现路径转弯方向与旋转操作的对应关系（第一层核心推理），最后理解多次转弯意味着累积旋转（第二层推理——例如两次右转等于 180 度翻转）。
</new_puzzle>

<new_puzzle>
- `description`：每个彩色区域内部隐藏着一个"戳印方向"，由区域内唯一的异色标记像素相对于区域质心的方位决定；将区域的缩略形状作为戳印，沿该方向在区域外部重复盖印，直到触及网格边界。

- `Input structure`：
  - 背景色为 Black。
  - 网格中有若干互不接触的中型彩色区域（每个区域是一个 4-连通的同色块，颜色各不相同，约占 8 至 20 个像素，形状不规则）。
  - 每个区域内部恰好有一个像素被替换为另一种特殊标记颜色（Maroon），这个标记像素是区域的一部分（与区域其余像素 4-连通）。

- `Rule`：
  - 对每个彩色区域独立操作：
  - 第一步——确定戳印方向：找到该区域的视觉中心（所有区域像素坐标的平均值，四舍五入到最近整数）。观察 Maroon 标记像素相对于视觉中心的位置，确定一个基本方向——上、下、左、右、左上、右上、左下、右下（8 方向之一），取标记像素到视觉中心的位移向量最接近的基本方向。
  - 第二步——生成缩略戳印：将该区域的形状缩放到其最小外接矩形，并以 1:1 保留形状（即用区域的 tight-crop 作为戳印模板），颜色使用区域本身的颜色（Maroon 标记位置也恢复为区域颜色）。
  - 第三步——重复盖印：从区域的外接矩形边缘出发，沿第一步确定的方向，以戳印模板的尺寸为步长，反复将戳印粘贴到网格上，直到戳印的任何部分超出网格边界为止。每次粘贴之间无间隙，紧密排列。粘贴时只覆盖 Black 像素，不覆盖已有的其他颜色。
  - 原始区域保持不变（包括其中的 Maroon 标记）。

- `Key insight`：Maroon 标记像素看似是一个瑕疵或噪声，但它实际上编码了戳印的方向信息。解题者必须先发现标记像素相对于区域中心的方位决定了输出的扩展方向（第一层推理——方向编码），然后理解区域自身的形状被用作重复粘贴的模板（第二层推理——自我复制机制）。两个线索分别来自区域的内部结构和整体形状，需要综合判断。
</new_puzzle>

<new_puzzle>
- `description`：网格中的彩色十字标记既指定了重涂颜色，又通过臂长定义了作用范围——影响范围内的非背景像素被统一染为十字臂的颜色，十字自身随后消失。

- `Input structure`：
  - 背景色为 Azure。
  - 网格中散布若干彩色像素块和小型对象（各种颜色，形状不一）。
  - 网格中有 2 至 4 个"十字标记"：每个十字标记由一个 Grey 中心像素和四条等长的臂组成（上下左右各延伸相同长度，臂长 2 至 4 像素），四条臂上的像素颜色相同但各十字可能不同（如一个十字臂为 Red，另一个臂为 Blue）。
  - 十字之间不重叠，十字的臂可能穿过背景或穿过已有的彩色像素。

- `Rule`：
  - 对每个十字标记独立操作（如果影响范围重叠，后处理的十字覆盖先处理的结果；处理顺序为从左到右、从上到下）：
  - 第一步——确定影响范围：十字的臂长为 L，则该十字的影响范围为以十字中心为中心的 (2L+1) x (2L+1) 正方形区域。
  - 第二步——重涂：十字臂的颜色为 C。对于影响范围内每一个非 Grey、非 Azure 的像素（即已有颜色的像素），将其颜色替换为 C。对于影响范围内的 Azure 背景像素，保持不变。
  - 第三步——移除十字：将所有十字标记的像素（Grey 中心和臂像素）全部擦除为 Azure 背景色。

- `Key insight`：十字标记是一种"作用力源"——它的臂长定义了作用范围的大小，臂的颜色定义了重涂颜色。解题者需要先理解十字的几何结构（Grey 中心 + 等长同色臂）来区分十字标记与普通对象（第一层推理），然后发现臂长与影响范围的对应关系（臂长 L 对应 (2L+1)x(2L+1) 正方形）以及颜色替换规则（第二层推理）。十字在完成使命后自我消除，进一步增加了从输出反推规则的难度。
</new_puzzle>

<new_puzzle>
- `description`：网格被隐含的列奇偶性分成两组，每个彩色对象根据它所跨越的奇偶列的像素比例关系，决定是被保留、被镜像还是被删除。

- `Input structure`：
  - 背景色为 Black。
  - 网格宽度为偶数。网格中有若干互不接触的彩色 4-连通对象（每个对象为单一颜色，颜色各不相同）。
  - 没有显式的条纹标记——奇偶列的划分是隐含的（第 0、2、4... 列为偶数列，第 1、3、5... 列为奇数列）。

- `Rule`：
  - 对每个彩色对象，统计其像素分布：设对象中位于偶数列的像素数为 E，位于奇数列的像素数为 O。
  - 如果 E > O（对象主要占据偶数列）：对象保持原位不变。
  - 如果 O > E（对象主要占据奇数列）：将对象沿其自身的垂直中心轴做左右镜像翻转，翻转后放回其外接矩形的原位置。
  - 如果 E = O（对象均匀跨越奇偶列）：将对象删除（替换为 Black 背景）。
  - 输出网格尺寸不变。

- `Key insight`：网格上没有任何可见的条纹分隔线——奇偶列的存在必须从多个样例中对象的不同命运（保留、镜像、消失）反推得出。解题者需要先发现"列的奇偶性"这一隐藏的空间结构（第一层推理），然后发现对象像素在奇偶列上的多数归属决定了变换类型（第二层推理）。关键难点在于"奇偶列"本身是不可见的，必须通过对比输入输出才能归纳出来。
</new_puzzle>
