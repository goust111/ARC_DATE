- `description`：在网格中找到所有"门"结构（墙壁上的单像素缺口），将每扇门连接的两个房间中较小的房间用较大房间的地板颜色填充，然后用 red 像素封堵所有门。

- `Input structure`：
  - 背景为 black。
  - Azure 像素构成墙壁，形成若干封闭的矩形"房间"。
  - 每个房间内部填充着一种纯色"地板"（可能为 green、yellow、orange、maroon 等），不同房间的地板颜色各异。
  - 部分墙壁上有恰好 1 像素宽的缺口（即 azure 墙壁线段中间缺少一个像素），这就是"门"。每扇门恰好连接两个相邻房间。
  - 有些房间之间没有门（完全隔开），有些房间之间有一扇门。

- `Rule`：
  - 第一步：识别所有房间及其地板颜色，并计算每个房间的面积（地板像素总数）。
  - 第二步：对于每扇门，比较它连接的两个房间的面积。将面积较小的房间的所有地板像素重新染为面积较大房间的地板颜色。如果两个房间面积相同，则两个房间都保持不变。
  - 第三步：用 red 像素填入每扇门的缺口位置（即将原本缺失的 azure 像素位置设为 red），封堵所有门。
  - 第四步：所有墙壁（azure）保持不变，未通过门连接的房间保持原样。

- `Key insight`：解题者需要先识别"门"是墙壁上的单像素缺口而非随机空隙，然后理解颜色传播的方向性——面积大的房间"吞噬"面积小的房间。门的封堵用 red 标记则是最终确认规则的线索。这道题的两层推理在于：第一层是发现门的拓扑连接关系决定了哪些房间会交互；第二层是发现面积比较决定了颜色流向。
