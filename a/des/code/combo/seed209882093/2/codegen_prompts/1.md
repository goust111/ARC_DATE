- `Input structure`：
  - 背景为 black。
  - Grey 像素构成一张连通的网格状墙壁网络，将整个网格分割为若干封闭矩形区域。

  - 墙壁厚度为 1 像素，区域大小不等。

- `Rule`：
  - 第一步：识别所有由 grey 墙壁围成的封闭矩形区域，以及每个区域内部的种子像素颜色。
  - 第二步：对于每段墙壁（一条连续的 grey 像素直线段），判断它分隔了哪两个区域。如果墙壁只与一个区域相邻（即处于网格最外边界），则该墙壁保持 grey 不变。
  - 第三步：对于分隔两个区域的内部墙壁段，将该墙壁段上的所有像素重新染色。染色规则为：取两侧区域种子颜色中颜色编号较小的那个颜色（颜色编号顺序：blue < red < green < yellow < grey < magenta < orange < azure < maroon）。
  - 第四步：种子像素本身在输出中被擦除（变为 black），区域内部其余像素保持 black 不变。

- `Key insight`：解题者首先需要发现墙壁颜色并非简单复制某一侧种子颜色，而是由两侧种子颜色共同决定；其次需要归纳出"取编号较小者"这一混合规则——这要求解题者从多个样例中对比不同颜色对的墙壁结果来推断出隐含的颜色优先级顺序。
