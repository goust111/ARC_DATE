<new_puzzle>
- `description`：根据每个封闭区域内部"种子像素"的颜色，从区域外部找到同色模板条纹，将该条纹图案平铺填充到对应封闭区域中。
- `Input structure`：
  - 背景为黑色（black）。
  - 网格中存在若干由灰色（grey）像素构成的不规则封闭边框，每个边框围出一个空心区域。
  - 每个封闭区域内部恰好有一个单独的"种子像素"，颜色各不相同（如 red、blue、green 等）。
  - 在所有封闭边框的外部，散布着若干水平或垂直的短条纹（长度 2-4 像素），每种条纹由单一颜色构成，颜色与某个种子像素颜色对应。每种颜色的条纹恰好出现一根，其方向（水平或垂直）和长度各异。
- `Rule`：
  - 找到每个灰色封闭区域及其内部的种子像素颜色 C。
  - 在边框外部找到颜色为 C 的唯一条纹，记录其方向（水平/垂直）和长度 L。
  - 将该条纹作为平铺单元，沿条纹方向在封闭区域内部重复铺设：若条纹为水平方向，则逐行从左到右用长度 L 的色块重复填充区域内每一行的空位；若条纹为垂直方向，则逐列从上到下用长度 L 的色块重复填充区域内每一列的空位。超出区域边界的部分截断。
  - 种子像素被平铺覆盖，灰色边框和外部条纹保持不变。
- `Key insight`：种子像素不是装饰，而是颜色索引键；外部条纹不仅指定填充颜色，其方向和长度共同决定了平铺的轴向和周期。解题者需要先建立"种子→外部条纹"的颜色匹配，再从条纹的几何属性推断填充方式。
</new_puzzle>

- `description`：将网格中散落的同色像素对按照它们连线的方向进行"折叠投影"，在两点中点处生成一个缩微版的方向指示符号。
- `Input structure`：
  - 背景为黑色（black）。
  - 网格中散落着若干成对的单像素标记，每对标记颜色相同且每种颜色恰好出现两个像素。不同对的颜色互不相同。
  - 每对像素之间的连线严格为水平、垂直或 45 度对角线方向之一。
  - 网格中还有一个由 azure 色构成的 3x3 参考图例块，位于角落。图例块中，中心像素为 azure，八个方向中恰好有四个位置也是 azure，形成一个"十字"或"X"形状，标示了"水平/垂直"或"对角"两组方向的视觉样板。
- `Rule`：
  - 对于每一对同色像素，计算两者的中点位置（保证中点落在整数格点上）。
  - 判断两点连线方向：若为水平或垂直，则在中点处绘制一个 3x3 的"十字"形（中心 + 上下左右四格），颜色为该对像素的颜色；若为对角线方向，则在中点处绘制一个 3x3 的"X"形（中心 + 四个对角格），颜色为该对像素的颜色。
  - 擦除原始的两个标记像素。
  - 角落的 azure 参考图例保持不变。
- `Key insight`：角落的 azure 图例是解码密钥——它示范了两种方向类别分别对应的 3x3 图案（十字 vs X），解题者需要先从图例中归纳出"连线方向→图案形状"的映射规则，再对每对像素应用该规则。中点位置和方向判断都是视觉直觉可完成的。
</new_puzzle>

<new_puzzle>
- `description`：在被分隔线划分的多个子区域中，根据每个区域内"缺陷像素"的数量，从共享的颜色排序序列中选取对应位次的颜色，对该区域的所有前景像素重新着色。
- `Input structure`：
  - 背景为黑色（black）。
  - 网格被若干条完整的灰色（grey）水平线或垂直线分割成矩形子区域（类似棋盘格分区）。
  - 每个子区域内包含一个由 maroon 色构成的实心矩形块（大小不一），矩形块中混有少量（1-5 个）与背景相同的黑色"缺陷像素"（即矩形内部的空洞）。
  - 在网格的最底部一行（位于最后一条灰色分隔线之下）排列着一行彩色像素序列，从左到右依次为不同颜色（如 red、blue、green、yellow、orange），每种颜色占一格，形成一个有序的"颜色调色板"。
- `Rule`：
  - 对每个子区域，数出其 maroon 矩形块内部的缺陷像素（黑色空洞）数量 N。
  - 在底部颜色调色板中，取从左起第 N 个颜色（N=1 对应最左边的颜色）。
  - 将该子区域内所有 maroon 像素（包括缺陷位置，即填补空洞）替换为选中的颜色，形成一个完整的实心矩形。
  - 灰色分隔线和底部调色板行保持不变。
- `Key insight`：解题者需要完成两层非显然推理：第一层是发现每个矩形块内的"缺陷数量"是关键属性而非随机噪声；第二层是发现底部那行像素不是装饰而是一个位次索引的调色板，缺陷数量作为索引来选择重着色的颜色。单看颜色或单看缺陷都无法解题，必须将两者关联。
</new_puzzle>

<new_puzzle>
- `description`：每个前景对象按照自身形状中隐含的"箭头方向"滑动，直到其尖端与同色锚点相邻为止；滑动过程中对象穿越异色障碍但遇同色障碍停止。
- `Input structure`：
  - 背景为黑色（black）。
  - 网格中包含若干由不同颜色构成的小型前景对象（3-6 像素大小），每个对象形状不对称且可被解读为指向某个基本方向的"箭头"：对象的像素分布中，一端较宽（2-3 像素宽的"尾部"），另一端较窄并突出一个像素（"头部尖端"）；箭头方向即从尾部中心指向头部尖端的方向（上、下、左、右四个基本方向之一）。
  - 每种前景颜色恰好出现两次：一次作为可移动的箭头对象，一次作为固定的单像素"锚点"。锚点与其同色箭头不在同一行/列上（需要沿箭头方向滑动后才能相邻）。
  - 网格中还散布着一些其他颜色的单像素"障碍"。
- `Rule`：
  - 识别每个多像素对象的箭头方向：找到对象的"尾部"（最宽的截面）和"头部尖端"（最窄的突出端），方向从尾部指向头部。
  - 将整个箭头对象沿其箭头方向平移。在滑动路径上，对象可以无视并穿过不同颜色的障碍像素（障碍保持不动且不被覆盖——对象从上方"飞过"）。
  - 当箭头对象的头部尖端像素与同色锚点在滑动方向上相邻（即尖端的下一格就是锚点）时停止。
  - 擦除箭头对象原始位置的像素；在新位置绘制箭头对象。锚点和障碍像素保持不变。
- `Key insight`：解题者需要先从每个不规则小对象的形状中识别出隐含的方向信息（宽端为尾、窄端为头），这是第一层推理；然后发现同色锚点是滑动的终止条件且对象会穿越异色障碍，这是第二层推理。方向不是由外部标记给出的，而是编码在对象自身的几何形状中。
</new_puzzle>

<new_puzzle>
- `description`：将网格中若干"信号发射塔"沿其开口方向发射的射线，在经过"棱镜"对象时分裂成两条对角射线，分裂后的射线颜色由棱镜颜色决定。
- `Input structure`：
  - 背景为黑色（black）。
  - 网格中有若干"发射塔"：每个发射塔是一个 3x1 或 1x3 的单色条（如 red、blue 等），其中一端缺少一个像素形成 2 像素的短条，缺失端即为"开口方向"（开口朝上/下/左/右）。发射塔颜色各不相同。
  - 网格中散布着若干"棱镜"：每个棱镜是一个单独的彩色像素（颜色与所有发射塔颜色不同，例如 yellow、green 等）。
  - 网格边缘可能有若干灰色（grey）的"吸收墙"像素。
- `Rule`：
  - 每个发射塔从开口方向发射一条直线射线，射线颜色为发射塔的颜色，沿开口方向逐像素绘制。
  - 射线遇到网格边缘或灰色吸收墙时终止。
  - 射线遇到棱镜像素时：原射线终止于棱镜前一格（不覆盖棱镜）；从棱镜位置向两个与原射线方向成 45 度的对角方向各发射一条新射线，新射线颜色变为棱镜的颜色。例如，向右行进的射线遇到棱镜后，分裂为右上和右下两条对角射线。
  - 分裂后的对角射线继续传播，若再遇到另一个棱镜则再次分裂（方向进一步偏转 45 度，变为与原对角线垂直的基本方向），颜色变为新棱镜的颜色。
  - 所有射线在遇到边缘、吸收墙或已有非背景像素时终止。发射塔和棱镜像素本身保持不变。
- `Key insight`：解题者需要理解三层递进结构：第一层是从发射塔的形状（缺失像素的位置）推断射线的初始方向；第二层是发现棱镜将直线射线分裂为两条对角射线的规则；第三层是颜色继承——每段射线的颜色不由发射源决定，而由最近一次经过的棱镜决定，形成"颜色沿路径被改写"的传播链。
</new_puzzle>

<new_puzzle>
- `description`：在一个由彩色边框围成的封闭迷宫中，根据边框上缺口的颜色配对关系，用对应颜色的路径连接每对同色缺口，路径必须沿迷宫内部通道行走。
- `Input structure`：
  - 背景为黑色（black）。
  - 网格中央有一个由灰色（grey）像素围成的矩形边框，边框宽度为 1 像素。
  - 边框内部被灰色的内墙分割成若干连通的通道（通道宽度为 1 像素，类似简单迷宫结构）。
  - 边框的外围边上有若干"缺口"：缺口处灰色像素被替换为彩色像素（如 red、blue、green 等）。每种颜色恰好出现两个缺口，分布在边框的不同边上。
  - 边框外部（缺口之外）为黑色背景，无其他对象。
- `Rule`：
  - 识别边框上所有彩色缺口，按颜色配对。
  - 对于每一对同色缺口，从一个缺口进入迷宫内部，沿通道（黑色空格）行走，找到连接两个缺口的唯一无分支路径（迷宫保证每对缺口之间恰好存在唯一简单路径）。
  - 用该对缺口的颜色填充路径上经过的所有黑色通道像素。
  - 不同颜色的路径不会交叉（迷宫结构保证）。
  - 灰色墙壁和边框保持不变；缺口像素保持其颜色。
- `Key insight`：解题者需要先识别出边框上的彩色像素不是装饰而是"端口"，且同色端口需要配对连接——这是第一层推理。第二层是发现内部灰色结构构成迷宫墙壁，路径必须沿迷宫通道行走而非直线连接。由于迷宫保证唯一路径，解题者可以从任一端口出发沿通道走到底即可，无需复杂搜索。
</new_puzzle>

<new_puzzle>
- `description`：在网格中，每个前景色块根据其自身"对称性类型"进行不同的变换：完全对称的色块保持不动，仅水平对称的色块垂直翻转，仅垂直对称的色块水平翻转，完全不对称的色块旋转 180 度。
- `Input structure`：
  - 背景为黑色（black）。
  - 网格中散布着若干互不接触的小型前景对象（每个对象由 4-8 个同色像素通过四连通组成），每个对象颜色各不相同。
  - 对象的形状各异：有些关于水平轴对称，有些关于垂直轴对称，有些两个轴都对称，有些完全不对称。
  - 网格右下角有一个由四个小图标组成的 2x2 图例区域（每个图标是 3x3 大小），分别用 grey 色绘制，展示四种对称类型对应的变换效果示例：图例中每个 3x3 图标的上半部分是变换前的微型形状，下半部分是变换后的结果，用箭头像素（azure 色）分隔。
- `Rule`：
  - 分析每个前景对象的形状对称性（在其最小包围矩形内判断）：
    - 若对象关于水平轴和垂直轴都对称（双对称），则保持原位不变。
    - 若对象仅关于水平中轴对称（左右对称但上下不对称），则将对象在其包围矩形内进行上下翻转（垂直翻转），位置不变。
    - 若对象仅关于垂直中轴对称（上下对称但左右不对称），则将对象在其包围矩形内进行左右翻转（水平翻转），位置不变。
    - 若对象既无水平也无垂直对称性，则将对象在其包围矩形内旋转 180 度，位置不变。
  - 图例区域保持不变。
- `Key insight`：解题者需要完成两层归纳：第一层是从图例中识别出四种对称类型与四种变换操作的对应关系；第二层是对每个主区域中的对象独立判断其对称类型并施加对应变换。难点在于对称性的判断是隐含在形状中的属性，不能直接"看到"，需要解题者主动检验每个对象的几何结构。
</new_puzzle>
