根据每对标记像素之间路径上经过的障碍物数量，选择性地连接或不连接它们。

Input structure：
- 背景为 black。
- 网格中有若干 grey 的水平和垂直线段作为"墙壁"，将空间部分遮断。
- 散布着若干成对的同色标记像素（每种颜色恰好出现两个像素），颜色包括 red、blue、green、yellow 等。
- 每对同色标记像素要么在同一行，要么在同一列（保证共线）。

Rule：
- 对每对同色标记像素，沿它们共线方向（水平或垂直）数出两者之间穿过了多少条 grey 墙壁线段。
- 如果穿过的墙壁数为偶数（含 0），则在两个标记之间画一条该颜色的直线连接它们（线在墙壁位置也会覆盖绘制，即颜色覆盖 grey）。
- 如果穿过的墙壁数为奇数，则不连接——两个标记像素保持原样但不画线。
- 所有墙壁中未被覆盖的部分、背景和标记像素均保持不变。

Key insight：
- 表面上看像是"连接同色对"的简单任务，但实际存在一个隐蔽的筛选层——奇偶判断决定是否连线。解题者需要先注意到某些同色对被连接而另一些没有，然后发现中间墙壁数量的奇偶性是决定因素。
