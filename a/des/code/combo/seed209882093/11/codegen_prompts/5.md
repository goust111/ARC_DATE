按照"传播源"精灵体中各色像素的叠放层序，对网格中同色区域执行由内向外的逐层扩展。

Input structure：
- 背景为 black。
- 网格左侧或顶部有一个小型"传播源"精灵体（如 3×3 或 4×4），内部由多种颜色组成同心嵌套结构：最外圈一种颜色、次外圈另一种颜色……直到中心像素一种颜色（每层一种颜色，不超过 4 层）。
- 网格其余区域散布着若干种子像素，每个种子像素的颜色恰好等于传播源中心像素的颜色。

Rule：
- 读取传播源精灵体的同心层结构，从中心到外层记录颜色序列 C1（中心）、C2、C3、…、Cn（最外层）。
- 对网格中每个颜色为 C1 的种子像素，执行多轮 4-连通扩展：
  - 第 1 轮：种子像素本身保持颜色 C1。
  - 第 2 轮：所有与已染色区域 4-连通相邻且当前为 black 的像素染为 C2。
  - 第 3 轮：再向外扩展一层，染为 C3。
  - 依此类推，直到颜色序列用尽。
- 若多个种子的扩展区域发生碰撞（同一像素被多个种子尝试染色），则该像素保持先到的颜色（即离该像素更近的种子决定颜色）。距离相同时保持 black 不染色。
- 传播源精灵体本身在输出中保持不变。

Key insight：
- 传播源不是要被复制或平铺的模板，而是一个编码了"扩展顺序与颜色"的指令表——解题者需要先解读同心层结构得到颜色序列，再将其理解为逐层扩展的规则而非空间模板的复制，这构成"解码指令→应用扩展→处理碰撞"的多层推理。
</new_puzzle>
