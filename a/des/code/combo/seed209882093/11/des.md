根据封闭区域内部"岛屿"的数量，从颜色图例中选取对应颜色来填充该区域的背景。

Input structure：
- 背景为 black。
- 网格中有若干用同一颜色（如 grey）绘制的一像素宽的闭合环形边框，每个环形边框围出一块矩形封闭区域。
- 每个封闭区域内部散落着若干不相连的小型单色"岛屿"（4-连通的前景色块，每个岛屿面积 1-3 像素不等）。
- 网格的某个角落（如左上角）有一组颜色图例：由 1 到 N 个紧挨排列的小方块组成的水平条，每个条的颜色各不相同，条的长度（方块个数）从 1 递增到 N。例如长度 1 的条颜色为 red，长度 2 的条颜色为 blue，长度 3 的条颜色为 green，依此类推。

Rule：
- 对每个 grey 闭合边框围出的封闭区域，数出其内部独立岛屿（4-连通前景色块）的个数 K。
- 在颜色图例中找到长度恰好为 K 的那一条，读取其颜色 C。
- 将该封闭区域内所有 black 背景像素（不含岛屿像素和边框像素）替换为颜色 C。
- 图例本身、边框像素和岛屿像素保持不变。

Key insight：
- 岛屿的数量不是用来决定几何形状的，而是作为索引去查找颜色图例——解题者需要先发现"数岛屿"这一步，再发现图例条长度与岛屿数的映射关系，这构成两层独立的归纳推理。
</new_puzzle>

<new_puzzle>
将网格中散布的各色线段碎片拼回各自所属的完整矩形边框，并用碎片颜色为对应矩形内部染色。

Input structure：
- 背景为 black。
- 网格中有若干灰色（grey）的不完整矩形边框，每个边框恰好缺失一条边（上、下、左或右）。
- 网格中另有若干独立的单色水平或垂直线段（颜色各不相同，如 red、blue、green 等），这些线段的长度和朝向各自恰好等于某个矩形缺失边的长度和朝向。
- 每条线段散布在网格中任意位置，与其目标矩形不相邻。

Rule：
- 对每个不完整矩形，确定其缺失边的位置、长度和方向（水平或垂直）。
- 在所有独立线段中找到长度和方向均匹配的那条线段（保证匹配唯一）。
- 将该线段平移到缺失边的位置，补全矩形边框，线段颜色覆盖原本的缺口。
- 同时将该矩形内部所有 black 像素填充为该线段的颜色。
- 线段原来的位置恢复为 black 背景。

Key insight：
- 解题者首先需要从不完整的 grey 边框中推断出每个矩形缺少哪条边（位置、方向、长度），然后再将散落的彩色线段按几何属性（长度 + 方向）匹配到对应矩形——最后发现线段颜色不仅补边而且决定了内部填色，这构成"缺口诊断→匹配→填充"的多层推理链。
</new_puzzle>

根据每对标记像素之间路径上经过的障碍物数量，选择性地连接或不连接它们。

Input structure：
- 背景为 black。
- 网格中有若干 grey 的水平和垂直线段作为"墙壁"，将空间部分遮断。
- 散布着若干成对的同色标记像素（每种颜色恰好出现两个像素），颜色包括 red、blue、green、yellow 等。
- 每对同色标记像素要么在同一行，要么在同一列（保证共线）。

Rule：
- 对每对同色标记像素，沿它们共线方向（水平或垂直）数出两者之间穿过了多少条 grey 墙壁线段。
- 如果穿过的墙壁数为偶数（含 0），则在两个标记之间画一条该颜色的直线连接它们（线在墙壁位置也会覆盖绘制，即颜色覆盖 grey）。
- 如果穿过的墙壁数为奇数，则不连接——两个标记像素保持原样但不画线。
- 所有墙壁中未被覆盖的部分、背景和标记像素均保持不变。

Key insight：
- 表面上看像是"连接同色对"的简单任务，但实际存在一个隐蔽的筛选层——奇偶判断决定是否连线。解题者需要先注意到某些同色对被连接而另一些没有，然后发现中间墙壁数量的奇偶性是决定因素。
</new_puzzle>

<new_puzzle>
将输入中每个前景精灵体按其内部孔洞的形状裁剪后，嵌入到另一个拥有相同形状孔洞的精灵体中。

Input structure：
- 背景为 black。
- 网格中有若干互不重叠的单色前景精灵体（4-连通色块），每个精灵体内部可能有零个或一个"孔洞"（被精灵体完全包围的 black 连通区域）。
- 有孔洞的精灵体保证：每个孔洞的形状（二值掩码，不考虑旋转和翻转）恰好与另一个精灵体的外轮廓形状相同——即该另一精灵体能恰好嵌入此孔洞中（可能需要旋转或翻转）。
- 每个精灵体要么有一个孔洞（作为"容器"），要么没有孔洞且其整体形状匹配某个容器的孔洞（作为"嵌件"）。容器与嵌件保证一一配对。

Rule：
- 对每个有孔洞的"容器"精灵体，找到外轮廓形状（旋转/翻转后）与该孔洞形状一致的"嵌件"精灵体。
- 将嵌件以正确的旋转/翻转方式放入容器的孔洞中，嵌件保持自身颜色。
- 嵌件原来的位置恢复为 black 背景。
- 没有配对关系的像素保持不变。

Key insight：
- 解题者需要将每个精灵体的"负空间"（孔洞形状）与其他精灵体的"正空间"（外轮廓）进行形状匹配——这是一个图形-背景反转的认知跳跃。匹配后还需确定正确的旋转/翻转，构成"负空间识别→形状匹配→变换嵌入"的多层推理。
</new_puzzle>

<new_puzzle>
按照"传播源"精灵体中各色像素的叠放层序，对网格中同色区域执行由内向外的逐层扩展。

Input structure：
- 背景为 black。
- 网格左侧或顶部有一个小型"传播源"精灵体（如 3×3 或 4×4），内部由多种颜色组成同心嵌套结构：最外圈一种颜色、次外圈另一种颜色……直到中心像素一种颜色（每层一种颜色，不超过 4 层）。
- 网格其余区域散布着若干种子像素，每个种子像素的颜色恰好等于传播源中心像素的颜色。

Rule：
- 读取传播源精灵体的同心层结构，从中心到外层记录颜色序列 C1（中心）、C2、C3、…、Cn（最外层）。
- 对网格中每个颜色为 C1 的种子像素，执行多轮 4-连通扩展：
  - 第 1 轮：种子像素本身保持颜色 C1。
  - 第 2 轮：所有与已染色区域 4-连通相邻且当前为 black 的像素染为 C2。
  - 第 3 轮：再向外扩展一层，染为 C3。
  - 依此类推，直到颜色序列用尽。
- 若多个种子的扩展区域发生碰撞（同一像素被多个种子尝试染色），则该像素保持先到的颜色（即离该像素更近的种子决定颜色）。距离相同时保持 black 不染色。
- 传播源精灵体本身在输出中保持不变。

Key insight：
- 传播源不是要被复制或平铺的模板，而是一个编码了"扩展顺序与颜色"的指令表——解题者需要先解读同心层结构得到颜色序列，再将其理解为逐层扩展的规则而非空间模板的复制，这构成"解码指令→应用扩展→处理碰撞"的多层推理。
</new_puzzle>
