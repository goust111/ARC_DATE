- `description`：将每个精灵的外接矩形边框用精灵内部孔洞的数量对应的颜色重绘，同时保持精灵内部不变。
- `Input structure`：背景为 black。网格中有若干 4 连通的单色前景精灵，每个精灵可能包含一个或多个背景色孔洞（完全被精灵像素包围的 4 连通背景区域）。网格角落有一个小型颜色图例：图例由若干行组成，每行左列是一个数字形状的 grey 标记（1 个像素代表数字 1，两个垂直相邻像素代表数字 2，三个垂直像素代表数字 3），右列是一个颜色色块。
- `Rule`：
  - 对每个精灵，数其内部被完全包围的背景孔洞数量 N。
  - 在颜色图例中查找 N 对应的颜色 C（通过匹配图例左列的像素数量）。
  - 绘制精灵 bounding box 的一像素厚矩形边框，使用颜色 C。边框绘制在精灵外侧（bounding box 向外扩展一像素）。
  - 精灵本身的像素和内部孔洞保持不变。
  - 图例区域保持不变。
- `Key insight`：孔洞数量是隐藏的拓扑属性，需要解题者仔细检查每个精灵内部——然后通过图例将这个拓扑特征映射为边框颜色，形成"拓扑分析→图例查表→几何绘制"的三步链。
</new_puzzle>

- `description`：根据每条水平栅栏线上的彩色标记位置，在栅栏线之间的通道中绘制垂直的同色连线。
- `Input structure`：背景为 black。网格中有若干条全宽的 grey 水平栅栏线，将网格分割为若干水平通道。每条栅栏线上散布着若干非 grey 非背景色的单像素标记。相邻栅栏线上可能在相同列位置有相同颜色的标记。
- `Rule`：
  - 对每对上下相邻的栅栏线，检查它们是否在同一列上有相同颜色的标记。
  - 若上方栅栏线在列 c 有颜色 C 的标记，且下方栅栏线在同一列 c 也有颜色 C 的标记，则在它们之间的通道中绘制一条颜色 C 的垂直连线（从上方标记下方一像素到下方标记上方一像素）。
  - 若某列只有一条栅栏线上有标记（无配对），则不绘制任何连线。
  - 若两条不同颜色的连线在通道中交叉（不会出现，因为每列每对栅栏线间最多一条连线），不适用。
  - 栅栏线上的标记和栅栏线本身保持不变。
- `Key insight`：栅栏线上的标记像素不是独立的——它们是相邻栅栏之间垂直连接的端点。解题者需要发现"同列同色配对→画连线"的规则。
</new_puzzle>

- `description`：将每个封闭区域中的全部前景像素视为一个旋转指令集，根据像素数量旋转区域的围墙形状。
- `Input structure`：背景为 black。网格中有若干由不同颜色像素围成的矩形封闭区域（围墙一像素厚）。每个区域的围墙在某一条边上有一段 2-3 像素的彩色标记段（与围墙其余部分颜色不同）。区域内部有 0-3 个 red 像素散布。
- `Rule`：
  - 对每个封闭区域，数其内部 red 像素的数量 N。
  - 将整个区域（包括围墙和内部）以其中心为轴旋转 N × 90 度（顺时针）。N=0 不旋转，N=1 旋转 90 度，N=2 旋转 180 度，N=3 旋转 270 度。
  - 旋转后的区域放回其原始中心位置。
  - 旋转后清除内部所有 red 像素为背景色。
  - 区域外部的背景保持不变。
- `Key insight`：red 像素不是要保留的内容而是旋转控制信号——其数量编码了旋转角度。解题者需要发现"像素计数→旋转次数"的关系。
</new_puzzle>

- `description`：将输入中的镜像对称精灵对识别出来，然后将每对中的两个精灵合并为一个完整的对称图案。
- `Input structure`：背景为 azure。网格中有若干小型 4 连通单色精灵（面积 3-6 像素），使用不同颜色。精灵成对出现——每对中的两个精灵颜色相同，形状互为左右镜像（沿某条垂直线翻转后形状相同）。每对精灵在同一行高度上，左侧的是原始形状，右侧的是镜像形状。两者之间有一段背景间隔。
- `Rule`：
  - 识别所有同色精灵对（每种颜色恰好两个精灵）。
  - 验证每对精灵互为水平镜像。
  - 将右侧镜像精灵向左平移，使其与左侧精灵的 bounding box 在水平方向上紧邻（间隔 0 像素），两者的行范围对齐。
  - 合并后的图案保持两个精灵各自的颜色（相同）。
  - 清除右侧精灵的原始位置为背景色。
  - 无配对的精灵保持不变。
- `Key insight`：精灵的配对不靠位置接近而靠"同色+镜像形状"——解题者需要先识别镜像关系，再执行合并操作。
</new_puzzle>

<new_puzzle>
- `description`：将输入中每个"窗格"面板的内容根据窗格边框四角的标记颜色进行四象限独立变换。
- `Input structure`：背景为 black。网格中有若干一像素厚的 grey 矩形框架（"窗格"）。每个窗格的四个角落像素各自被替换为一种非 grey 非背景的标记色（四个角可能有相同或不同的颜色）。窗格内部有一个由某种前景色绘制的精灵图案。
- `Rule`：
  - 将每个窗格的内部按水平中线和垂直中线分成四个象限。
  - 每个象限对应窗格的一个角落标记。
  - 若角落标记为 red，则该象限内的精灵像素保持不变。
  - 若角落标记为 blue，则该象限内的精灵像素上下翻转（以象限中心为轴）。
  - 若角落标记为 green，则该象限内的精灵像素左右翻转。
  - 若角落标记为 yellow，则该象限内的精灵像素旋转 180 度。
  - 窗格框架（含角落标记）保持不变。
- `Key insight`：四个角落标记是独立的变换指令——每个只控制其对应象限的内容。解题者需要发现"角色→变换类型"的映射以及"按象限独立应用"的作用范围。
</new_puzzle>
