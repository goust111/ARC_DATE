- `description`：将输入中每对同色矩形通过其重叠的行范围或列范围确定连接轴，然后在连接轴上绘制第三种颜色的桥梁，桥梁宽度由两矩形重叠范围的长度决定。
- `Input structure`：背景为 black。网格中有若干不同颜色的实心矩形对象。某些颜色恰好出现两次（成对），这两个同色矩形在水平或垂直方向上有行范围或列范围的重叠。每对同色矩形之间有背景间隙。
- `Rule`：
  - 找到所有同色矩形对。
  - 对每对同色矩形，确定它们共享的行范围或列范围（重叠部分）。
  - 若行范围重叠（两矩形水平分离），在两矩形之间的水平间隙内绘制 grey 矩形桥梁，桥梁的垂直范围等于行重叠范围，水平范围覆盖整个间隙。
  - 若列范围重叠（两矩形垂直分离），在两矩形之间的垂直间隙内绘制 grey 矩形桥梁，桥梁的水平范围等于列重叠范围，垂直范围覆盖整个间隙。
  - 原始矩形保持不变。只出现一次的颜色的矩形不参与连接。
- `Key insight`：同色矩形对之间的"重叠范围"决定了桥梁的宽度——桥梁不是全宽连接而是精确匹配两者共享的投影区域。

- `description`：将网格中的每个精灵按其边界像素中四种方向类型（上/下/左/右边缘像素）的数量比例，决定精灵应该向哪个方向延伸生长。
- `Input structure`：背景为 azure。网格中有若干分离的 4 连通单色前景精灵（不规则形状，面积 5-15 像素）。每个精灵使用不同颜色。
- `Rule`：
  - 对每个精灵，找到其边界像素（与背景 4 相邻的前景像素）。
  - 将边界像素分类：上边界（上方是背景）、下边界（下方是背景）、左边界（左方是背景）、右边界（右方是背景）。一个像素可能属于多个类别。
  - 找到数量最多的边界类别（唯一最多），确定为生长方向。
  - 将该方向上所有边界像素各自向该方向延伸一个像素（即在每个该方向边界像素的外侧添加一个同色像素）。
  - 其他方向的边界不变。若延伸位置已有非背景像素，不覆盖。
- `Key insight`：精灵的形状决定了其"最暴露"的方向——最多边界像素的方向就是生长方向。解题者需要发现边界方向统计→生长方向的规则。
</new_puzzle>

<new_puzzle>
- `description`：根据输入中每个面板的前景图案与其相邻面板图案的相似度，决定是否将两面板合并为一个输出面板。
- `Input structure`：背景为 black。网格由全高 grey 分隔列分成若干面板。每个面板中有一个彩色前景图案（可能由多种颜色组成）。相邻面板的图案可能非常相似（仅有少量像素不同）或完全不同。
- `Rule`：
  - 对每对相邻面板，计算它们在对应位置上颜色相同的像素比例（匹配率）。
  - 若匹配率超过 80%（即超过 80% 的内部像素颜色相同），则将这两个面板合并：在输出中只保留一个面板，取两面板中在每个位置的多数颜色（若两面板颜色不同则取左面板的颜色）。
  - 若匹配率不超过 80%，则两面板在输出中各自保留，之间保持 grey 分隔列。
  - 连续多个面板若两两匹配率都超过 80%，则全部合并为一个。
- `Key insight`：分隔列不一定是永久边界——当相邻面板内容足够相似时它们会"融合"。解题者需要发现相似度阈值机制。
</new_puzzle>

- `description`：将输入中的散落标记像素根据它们在行列上形成的"十字交叉模式"合并，在每个交叉点绘制两条相交标记颜色的混合色。
- `Input structure`：背景为 black。网格中有若干非背景色的单像素标记。每种颜色的标记要么全部在同一行上（形成一个水平标记组），要么全部在同一列上（形成一个垂直标记组）。水平组和垂直组使用不同的颜色。
- `Rule`：
  - 识别水平标记组（同行同色标记）和垂直标记组（同列同色标记）。
  - 对每个水平组，将该行上所有标记之间的像素用该组颜色填充为一条完整的水平线段（连接最左和最右标记）。
  - 对每个垂直组，将该列上所有标记之间的像素用该组颜色填充为一条完整的垂直线段。
  - 在水平线段和垂直线段交叉的位置，用 grey 标记该交叉点（覆盖两条线段的颜色）。
  - 原始标记像素被保留在线段中。
- `Key insight`：散落的标记不是独立的点——同行的形成水平线，同列的形成垂直线。交叉点用第三种颜色高亮，形成一个"行列连线→交叉检测"的两步规则。
</new_puzzle>

<new_puzzle>
- `description`：将输入中每个对象的形状"投影"到网格的四条边上，然后根据投影覆盖的边缘像素数量对对象排序，按排序结果将对象从大到小嵌套放置。
- `Input structure`：背景为 black。网格中有若干分离的 4 连通单色前景精灵（不规则形状，面积各不相同），使用不同颜色。精灵之间无重叠。
- `Rule`：
  - 对每个精灵，计算其"投影范围"：将精灵的列范围投影到上下边缘（水平投影长度 = 列范围宽度），将精灵的行范围投影到左右边缘（垂直投影长度 = 行范围高度）。
  - 计算总投影范围 = 2 × 水平投影长度 + 2 × 垂直投影长度（即 bounding box 周长）。
  - 按总投影范围从大到小排序精灵。
  - 输出一个新网格，将排序后的精灵按从大到小的顺序嵌套放置为同心结构：最大的精灵放在最外层保持原始形状，第二大的精灵居中缩放放入第一个的 bounding box 内部……以此类推。
  - 实际操作：清空画布为背景色，按从大到小顺序将精灵绘制在画布中心，每个精灵的 bounding box 中心对齐到画布中心。
- `Key insight`：排序键不是面积而是 bounding box 的周长（投影范围）——一个狭长精灵可能面积小但投影范围大。解题者需要发现"周长排序→中心叠放"的规则。
</new_puzzle>
