<new_puzzle>
- `description`：根据精灵内部"指针像素"指向的相邻精灵，将指针颜色传递给被指向的精灵，完成一个颜色传播链。
- `Input structure`：背景为 black。网格中有若干 4 连通单色精灵对象（面积 4-9 像素），使用 grey 绘制。每个精灵内部恰好有一个非 grey 非背景的"指针像素"，该指针像素位于精灵的某条边上。指针像素的位置指向某个方向——即指针像素所在的精灵边（上/下/左/右边缘）决定了指向方向。在该方向上，最近的另一个精灵就是"被指向的精灵"。
- `Rule`：
  - 对每个精灵，找到其指针像素及其指向方向（指针在精灵上边缘则指向上方，以此类推）。
  - 沿指向方向找到最近的另一个精灵。
  - 将被指向精灵的所有 grey 像素重新着色为指针的颜色。
  - 若某个精灵既是指向者又是被指向者，则后处理的颜色覆盖先处理的。处理顺序为从左到右、从上到下扫描指向者。
  - 指针像素本身保留原色。未被任何指针指向的精灵保持 grey。
- `Key insight`：指针的位置在精灵边缘的哪一侧决定了方向，而指针的颜色决定了被指向精灵的新颜色——解题者需要发现"边缘位置→方向"和"指针色→目标色"两个映射。
</new_puzzle>

<new_puzzle>
- `description`：将分隔面板中每个面板里最大的对象"吞噬"面板内所有较小对象，最大对象的形状扩展为其自身与所有小对象 bounding box 的并集。
- `Input structure`：背景为 black。网格由全高 grey 分隔列分成若干面板。每个面板中有 2-4 个不同颜色的 4 连通实心矩形对象，面积各不相同。
- `Rule`：
  - 在每个面板中，找到面积最大的矩形对象。
  - 计算最大对象与所有较小对象 bounding box 的几何并集（即能包围所有对象的最小矩形）。
  - 将该并集矩形全部填充为最大对象的颜色。
  - 所有较小对象被覆盖/消失。
  - 分隔列保持不变。
- `Key insight`：最大对象不仅保留下来，还"吞噬"了同面板中所有小对象的空间——输出中每个面板只有一个矩形，其范围是所有原始对象的包围矩形。
</new_puzzle>

<new_puzzle>
- `description`：将网格中的多个同心矩形环按其颜色顺序"展开"为从上到下排列的水平色条，色条宽度等于对应环的周长。
- `Input structure`：背景为 black。网格中央有一组同心矩形环（嵌套的一像素厚矩形框），每层环使用不同颜色，从外到内颜色各异。环之间紧邻（无间隔），最内层可能是一个实心矩形或单个像素。
- `Rule`：
  - 从外到内识别每层同心环的颜色和周长（一像素厚矩形框的像素总数）。
  - 输出一个新网格：宽度等于最外层环的周长，高度等于环的层数。
  - 从上到下，每行对应从外到内的一层环：用该层颜色从左侧开始绘制像素，绘制数量等于该层的周长，其余位置为背景色。
- `Key insight`：同心环的二维嵌套结构被"展开"为一维的周长序列——解题者需要发现周长→色条宽度的编码方式，而非直觉上的"裁剪"或"放大"。
</new_puzzle>

<new_puzzle>
- `description`：将输入中每个精灵的颜色根据其与网格中心的相对象限位置进行循环替换。
- `Input structure`：背景为 azure。网格中有若干分离的 4 连通单色前景精灵，分布在网格的不同位置。所有精灵使用的颜色来自一个固定集合（如 red、blue、green、yellow）。网格中心未被任何精灵占据。
- `Rule`：
  - 以网格中心为原点，将每个精灵分类到四个象限之一（根据精灵 bounding box 中心的位置：左上、右上、右下、左下）。
  - 定义颜色循环：red → blue → green → yellow → red。
  - 左上象限的精灵颜色循环前进 0 步（不变）。
  - 右上象限的精灵颜色循环前进 1 步（red→blue，blue→green 等）。
  - 右下象限的精灵颜色循环前进 2 步。
  - 左下象限的精灵颜色循环前进 3 步。
  - 精灵的形状和位置保持不变。
- `Key insight`：象限位置决定了颜色循环的偏移量——解题者需要先发现颜色循环的存在，再发现象限与偏移量的对应关系。这不是简单的"位置决定颜色"，而是"位置决定颜色变换函数"。
</new_puzzle>

<new_puzzle>
- `description`：将每个前景对象根据其与最近的同色对象之间的间距，决定是否将两者之间的背景填充为第三种颜色。
- `Input structure`：背景为 black。网格中有若干不同颜色的 4 连通单色实心矩形对象。某些颜色恰好出现两次（两个同色矩形），某些颜色只出现一次。同色矩形对在同一行或同一列上对齐，之间有背景间隙。
- `Rule`：
  - 找到所有同色矩形对。
  - 对每对同色矩形，计算它们之间的间距（背景像素数）。
  - 若间距小于等于两个矩形中较小者的短边长度，则用 red 填充两矩形之间的整个矩形间隙区域。
  - 若间距大于较小者的短边长度，则不填充。
  - 只出现一次的颜色的矩形保持不变。
- `Key insight`：填充与否取决于间距与矩形尺寸的比较——"足够近"的定义不是固定阈值，而是由矩形自身尺寸动态决定的。
</new_puzzle>
