- `Input structure`：背景为 black。网格左侧有一个竖向图例区域，由 grey 分隔列与右侧场景隔开。图例中从上到下排列着若干行，每行包含一个小型轮廓模板（用 grey 像素绘制的 3x3 或 4x4 形状轮廓）和紧邻其右侧的一个 2x1 填充色色块。右侧场景中有若干不同颜色的 4 连通前景精灵，每个精灵都是一个带有内部背景孔洞的空心形状，其外轮廓（即精灵像素的 8 连通边界形状）在标准化后与某个图例模板相同。
- `Rule`：
  - 对每个场景精灵，提取其外轮廓的标准化形状（不考虑旋转/翻转，仅平移对齐）。
  - 在图例中找到轮廓形状匹配的模板条目。
  - 用该条目对应的填充色填充精灵内部所有背景色（black）的孔洞像素。
  - 精灵自身颜色、图例区域和分隔列保持不变，仅输出右侧场景部分。
- `Key insight`：匹配键不是精灵的颜色或大小，而是其轮廓的拓扑形状——解题者需要发现"轮廓形状→图例模板→填充色"的间接映射链，而精灵的颜色只是干扰信息。

- `description`：根据每个矩形框架内部标记像素的对称性类型，选择不同的方式将标记像素扩展填满框架内部。
- `Input structure`：背景为 orange。网格中有若干个由 blue 像素围成的一像素厚矩形框架，框架内部主要为背景色，但包含少量散布的彩色标记像素（非 blue、非 orange）。每个框架内的标记像素恰好满足以下三种对称性之一：仅关于水平中轴对称、仅关于垂直中轴对称、或关于两个轴都对称。
- `Rule`：
  - 对每个框架，检查其内部标记像素相对于框架内部中心的对称性类型。
  - 若标记仅有水平对称：将标记像素图案在框架内部沿垂直方向上下平铺（周期重复）直到填满所有背景像素。
  - 若标记仅有垂直对称：将标记像素图案在框架内部沿水平方向左右平铺直到填满。
  - 若标记有双轴对称：将标记像素图案同时沿水平和垂直方向四向平铺直到填满。
  - 框架边框和非框架区域保持不变。
- `Key insight`：标记像素的对称性类型不是一个肉眼即可识别的简单属性——它需要解题者将标记与框架中心线比较后才能判断，而对称性类型又决定了完全不同的平铺方向。
</new_puzzle>

- `description`：将分隔面板中每个面板的前景对象按连通性分类，然后用分类结果决定面板输出时的排列顺序和方向。
- `Input structure`：背景为 black。网格被若干全高的 maroon 分隔列分成 3-5 个等宽面板。每个面板内有若干 4 连通的单色前景对象。面板中的对象要么全部互不接触（分离型），要么全部通过共享边相连形成一个大连通体（连接型）。
- `Rule`：
  - 将所有面板分为"分离型"和"连接型"两类。
  - 输出网格的宽度与输入相同，高度等于一个面板的高度。
  - 先按从左到右的顺序排列所有"连接型"面板，再按从右到左的顺序排列所有"分离型"面板。
  - 连接型面板内容保持原样，分离型面板内容上下翻转后放入输出。
  - 输出面板之间用 maroon 分隔列隔开。
- `Key insight`：面板的排列顺序和变换方式同时由对象的连通性决定——解题者不仅要发现连通性分类，还要发现分类后的两种不同处理方式（顺序反转 + 垂直翻转）。
</new_puzzle>

<new_puzzle>
- `description`：将分层堆叠的矩形色片拆解后，根据每层色片的面积大小重新排列为从左到右递增的水平序列。
- `Input structure`：背景为 grey。网格中有若干不同颜色的矩形色片，部分互相重叠。每个色片是一个纯色实心矩形。在重叠处，后绘制（上层）的颜色覆盖先绘制（下层）的颜色。每个颜色的完整矩形可以通过其可见像素的 bounding box 推断。
- `Rule`：
  - 从可见像素推断每个颜色的完整矩形尺寸（宽 x 高）。
  - 通过重叠处的颜色覆盖关系推断层次顺序。
  - 计算每个矩形的面积。
  - 创建一个新的背景画布，将所有矩形按面积从小到大从左到右水平排列，底边对齐，相邻矩形之间间隔一个背景色列。
  - 每个矩形保持其原始颜色和尺寸，不旋转。
- `Key insight`：输入中的空间遮挡关系在输出中被完全抛弃——解题者需要先重建被遮挡的完整矩形，再按面积而非层次重新排序，形成"重建→度量→重排"的三步推理链。
</new_puzzle>

<new_puzzle>
- `description`：根据每对相邻精灵之间的间距，在间距最小的那对之间绘制连接桥梁，桥梁的宽度等于两个精灵重叠维度的较短者。
- `Input structure`：背景为 black。网格中有 3-5 个分离的 4 连通单色实心矩形对象，每个使用不同颜色。所有矩形要么在水平方向对齐（行范围有重叠），要么在垂直方向对齐（列范围有重叠），使得每对相邻矩形之间存在一个纯背景的间隙。
- `Rule`：
  - 对每对在同一轴方向上相邻的矩形，计算它们之间的间距（背景像素数）。
  - 找到间距最小的那一对（唯一最小）。
  - 在这对矩形之间的间隙中，用 red 填充一个矩形桥梁，桥梁沿间隙方向跨越全部间距，桥梁在垂直于间隙方向的宽度等于两个矩形在该方向重叠范围的长度。
  - 所有原始矩形和其余间隙保持不变。
- `Key insight`：桥梁只出现在最近的一对矩形之间——解题者需要发现"全局最小间距"的选择标准，而非"每对都连"或"特定颜色才连"的局部规则。
</new_puzzle>
