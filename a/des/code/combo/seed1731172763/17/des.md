- `description`：根据每个前景对象的形状在颜色图例中查找对应的颜色替代规则，同时将对象平移到图例指示的网格象限。
- `Input structure`：背景为 Black。网格的四个角落各有一个小的颜色图例区域——每个角落包含一个小形状掩码（由 Grey 像素绘制）和一个相邻的纯色像素（替代色）。网格中心区域散布着若干不同颜色的 4-连通单色前景对象。
- `Rule`：
  - 对每个前景对象，将其形状归一化为最小包围盒内的掩码。
  - 在四个角落的图例中查找形状匹配的掩码（允许旋转和翻转）。
  - 用匹配的图例的替代色重绘该对象。
  - 将对象平移到匹配图例所在的角落象限（对象的包围盒中心移到该象限的中心位置）。
  - 移除所有图例。
- `Key insight`：图例同时提供颜色映射和位置映射——形状匹配决定哪个角落图例生效，图例中的替代色决定新颜色，图例的位置（哪个角落）决定对象的目标位置。一个查找操作产生两个变换结果。
</new_puzzle>

<new_puzzle>
- `description`：将输入中的颜色分布"逆转"——将最常见的前景色变为最少见的前景色的位置，将最少见的变为最常见的位置，中间频率的颜色按频率排名交叉互换位置。
- `Input structure`：背景为 Black。网格中有 3-5 种不同的前景颜色，每种颜色占据不同数量的像素，形成不同的空间图案。各颜色的像素数量互不相同。
- `Rule`：
  - 按像素数量对所有前景颜色排序，从最多到最少编号为 1, 2, ..., K。
  - 执行颜色互换：第 1 名和第 K 名互换位置，第 2 名和第 K-1 名互换位置，以此类推。
  - "互换位置"意味着：原本颜色 A 占据的所有像素改为颜色 B，原本颜色 B 占据的所有像素改为颜色 A。
  - 若 K 为奇数，中间那种颜色保持不变。
- `Key insight`：颜色互换不是按颜色本身的某种属性——而是按频率排名的对称配对。最"多数"和最"少数"交换，次多和次少交换。频率排名是隐含的，需要通过数像素来确定。
</new_puzzle>

<new_puzzle>
- `description`：将每个封闭框架内部的图案替换为该框架外部最近邻框架的内部图案，同时保留原框架的颜色作为图案的新绘制色。
- `Input structure`：背景为 Azure。网格中有若干不同颜色的单像素厚矩形框架，框架大小相同但颜色各不相同。每个框架内部有一个用该框架颜色绘制的小图案（形状各异）。框架之间有一定间距。
- `Rule`：
  - 对每个框架 F，找到距离它最近的另一个框架 G（以框架包围盒中心之间的水平+垂直距离粗略计算，选最小的）。
  - 取 G 内部的图案掩码（归一化到框架内部坐标）。
  - 清空 F 的内部，用 F 的框架颜色重新绘制 G 的图案掩码。
  - 所有框架的替换同时进行（使用原始图案，而非被替换后的图案）。
- `Key insight`：每个框架"偷取"最近邻框架的图案形状，但用自己的颜色绘制。空间邻近关系决定形状来源，框架自身颜色决定绘制色——形状和颜色来自不同的信息源。
</new_puzzle>

<new_puzzle>
- `description`：将网格中的每个前景对象按其"重心偏移方向"重新着色——重心偏左的用冷色，偏右的用暖色，偏上的加深，偏下的变浅。
- `Input structure`：背景为 Black。网格中有若干不同颜色的 4-连通单色前景对象，每个对象的形状不对称。
- `Rule`：
  - 对每个对象，计算其视觉重心（所有像素行坐标和列坐标的平均值）和包围盒中心。
  - 比较重心和包围盒中心的相对位置：
    - 若重心列 < 包围盒中心列（偏左），则水平分量为"冷"。
    - 若重心列 >= 包围盒中心列（偏右），则水平分量为"暖"。
    - 若重心行 < 包围盒中心行（偏上），则垂直分量为"深"。
    - 若重心行 >= 包围盒中心行（偏下），则垂直分量为"浅"。
  - 组合颜色：冷+深 = Blue，冷+浅 = Green，暖+深 = Red，暖+浅 = Yellow。
  - 用组合颜色重绘对象。
- `Key insight`：输出颜色由对象形状的不对称性决定——重心偏离包围盒中心的方向编码为一个二维的颜色坐标。解题者需要发现"重心偏移"这个隐含的分类维度。
</new_puzzle>

<new_puzzle>
- `description`：将输入中的分隔面板按内部图案的"连通分量数"排列成一条递增序列，并在每个面板的底部绘制等量的计数点。
- `Input structure`：背景为 Black。网格由 Grey 分隔列分为若干等大面板。每个面板内有一个由某种颜色构成的图案，图案可能由 1-5 个分离的 4-连通分量组成。
- `Rule`：
  - 对每个面板，数出其内部图案的 4-连通分量数量 N。
  - 按 N 从小到大排序面板。N 相同时按原始从左到右的顺序保持稳定。
  - 在每个面板底部（面板内部最后一行）从左到右绘制 N 个 Red 计数点，每个点之间留一格间隔。
  - 输出排序后的面板序列，面板之间用 Grey 分隔列隔开。
- `Key insight`：排序依据不是图案的大小或颜色，而是图案被"打碎"成多少个独立部分。计数点是对这一隐含属性的显式可视化——解题者需要同时发现排序规则和计数标记规则。
</new_puzzle>
