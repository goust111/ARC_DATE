- `description`：将每个彩色对象沿其"最长轴"方向压缩为一条线段，保持线段的颜色和中心位置不变，线段长度等于对象在该轴方向上的跨度。
- `Input structure`：背景为 Azure。网格中有若干不同颜色的 4-连通单色前景对象，每个对象形状不规则但具有明显的长轴方向（水平跨度和垂直跨度不等）。
- `Rule`：
  - 对每个前景对象，比较其包围盒的宽度和高度。
  - 若宽度 >= 高度，最长轴为水平方向；否则为垂直方向。
  - 计算对象中心（包围盒中心行和中心列）。
  - 将对象替换为一条沿最长轴方向的单像素宽线段：线段以对象中心为中点，长度等于对象在最长轴方向的跨度，颜色与原对象相同。
  - 擦除原对象的所有其他像素。
- `Key insight`：复杂形状被简化为其主方向上的"投影"——形状的细节被丢弃，只保留方向、长度和颜色信息。宽扁对象变为水平线，瘦高对象变为垂直线。
</new_puzzle>

<new_puzzle>
- `description`：将网格中由分隔线划分的面板按"内容相似度"分组——内容相同的面板归为一组，然后每组用唯一的颜色重绘所有面板的边框。
- `Input structure`：背景为 Black。网格由 Grey 分隔行和分隔列均匀划分为若干等大面板（如 3x3 或 4x3）。每个面板内有一个由某种颜色构成的小图案。部分面板的图案完全相同（形状和颜色都一致），形成若干"相同面板组"。
- `Rule`：
  - 比较所有面板的内部图案，将内容完全相同的面板归为一组。
  - 为每组分配一种新颜色（按组大小从大到小排序：最大组用 Red，第二大组用 Blue，第三大组用 Green，以此类推）。
  - 在每个面板的边缘（面板内部的 1 像素边框位置）绘制该组颜色的边框。
  - 面板内部的原始图案保持不变。
  - Grey 分隔线保持不变。
- `Key insight`：边框颜色不是由面板内容的颜色决定的，而是由面板内容的"等价类"决定——相同图案的面板获得相同的边框色，不同图案的面板获得不同的边框色。
</new_puzzle>

<new_puzzle>
- `description`：将每个前景对象"展开"到其包围盒的四条边上——对象内部的每种颜色被投影到其像素所在行和列对应的包围盒边框位置。
- `Input structure`：背景为 Black。网格中有若干分离的多色 8-连通前景对象（每个对象由 2-3 种颜色组成，形状紧凑）。
- `Rule`：
  - 对每个前景对象，取其包围盒。
  - 清空包围盒内部（全部变为背景色）。
  - 对对象中的每个像素（颜色 C，位于包围盒内的相对行 r、相对列 c）：
    - 在包围盒的上边框的第 c 列位置绘制颜色 C。
    - 在包围盒的下边框的第 c 列位置绘制颜色 C。
    - 在包围盒的左边框的第 r 行位置绘制颜色 C。
    - 在包围盒的右边框的第 r 行位置绘制颜色 C。
  - 若同一边框位置被多个像素投影，使用后投影的颜色（按像素在包围盒内从左到右、从上到下的扫描顺序）。
- `Key insight`：对象被"解构"为四条边框上的颜色投影——每个内部像素向四条边投射其行和列信息。原始的二维形状被编码为边框上的一维颜色序列。
</new_puzzle>

<new_puzzle>
- `description`：找到输入中每对颜色相同的对象，在两个对象之间绘制一条"中间路径"——路径上每个像素的颜色取决于它更靠近哪个对象。
- `Input structure`：背景为 Azure。网格中有若干 4-连通单色前景对象。每种颜色恰好出现两次（即有两个同色对象），两个同色对象沿同一行或同一列排列，中间是背景色间隔。
- `Rule`：
  - 对每对同色对象，它们位于同一行或同一列上。
  - 在两个对象之间的背景区域绘制一条连接线。
  - 连接线中，前半段（靠近第一个对象的部分）用 Yellow 绘制，后半段（靠近第二个对象的部分）用 Orange 绘制。
  - 若间隔像素数为奇数，中间的那个像素用 Red 绘制。
  - 原始对象保持不变。
- `Key insight`：同色对象对定义了连接关系，但连接线的颜色不是该对象的颜色——而是由位置（距离哪端更近）决定的渐变式分段着色。奇数间隔的中心位置有特殊标记。
</new_puzzle>

<new_puzzle>
- `description`：将每个面板中图案的"缺失部分"（相对于最完整面板而言）用特定颜色填充，不同面板的缺失用不同颜色。
- `Input structure`：背景为 Black。网格由 Grey 分隔列分为若干等大面板。所有面板包含同一个基础图案的不同"残缺版本"——每个面板的图案是完整图案的一个子集（某些像素被删除为背景色）。恰好有一个面板的图案是最完整的（像素最多）。
- `Rule`：
  - 找到像素数最多的面板，将其图案作为"完整模板"。
  - 对每个其他面板，计算其相对于完整模板的"缺失像素"（完整模板中有但该面板中为背景色的位置）。
  - 按面板从左到右的顺序，用不同颜色填充缺失像素：第 1 个非完整面板的缺失用 Red，第 2 个用 Blue，第 3 个用 Green，以此类推。
  - 完整面板保持不变。
- `Key insight`：面板之间的关系是"子集"关系——每个面板是完整图案的一个残缺版本。解题者需要先找到最完整的面板作为参考，再用差异比较来确定每个面板缺了什么。
</new_puzzle>
