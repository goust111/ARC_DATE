- `description`：通过框架内部孔洞的形状匹配外部精灵，将精灵颜色填入孔洞，同时根据孔洞数量决定框架边框的绘制粗细。
- `Input structure`：背景为主色（如 Azure）。网格中有若干单色矩形框架对象，每个框架内部包含若干不规则形状的背景色孔洞。框架外部散布着若干小型单色精灵对象。每个框架的边框颜色各不相同。
- `Rule`：
  - 对于每个框架，找到其内部所有 4-连通的背景色孔洞区域。
  - 数出该框架内部孔洞的数量 N。
  - 对于每个孔洞，在外部精灵中找到形状完全匹配（允许旋转和翻转）的精灵。
  - 用匹配精灵的颜色填充对应的孔洞。
  - 将框架的边框加粗为 N 像素厚（原始边框为 1 像素厚，向内扩展）。
  - 输出裁剪到所有框架的紧凑包围盒。
- `Key insight`：孔洞数量不仅是匹配的前置信息，还直接控制框架边框的视觉厚度——这是一个双重角色：形状匹配决定填充颜色，而孔洞计数决定边框几何变换。

- `description`：根据每个封闭区域内标记像素的对称性类型，选择不同的填充图案来重绘区域内部。
- `Input structure`：背景为 Black。网格中有一个由 Grey 像素构成的单像素厚分隔线网络，将网格划分为若干封闭矩形区域。每个区域内部有少量彩色标记像素（如 Red、Blue、Green、Yellow），这些标记像素构成某种对称图案（水平对称、垂直对称、旋转对称或无对称）。
- `Rule`：
  - 保持 Grey 分隔线不变。
  - 对每个封闭区域，分析其内部标记像素的对称类型：
    - 若标记像素关于区域水平中轴对称，用标记颜色填满区域的上半部分，下半部分保持背景色。
    - 若标记像素关于区域垂直中轴对称，用标记颜色填满区域的左半部分，右半部分保持背景色。
    - 若标记像素关于区域中心呈 180 度旋转对称，用标记颜色绘制从左上到右下的对角线条纹。
    - 若标记像素无任何对称性，清除该区域内所有标记像素，使之变为纯背景色。
- `Key insight`：标记像素的空间排列不是要保留的图案——它们编码的是一种对称"指令"，决定该区域的填充方式。解题者必须先识别对称类型，再据此选择完全不同的填充规则。
</new_puzzle>

- `description`：将散落的彩色像素按其所在行列的交叉关系组装成一个紧凑的颜色矩阵，同时用行列交叉处缺失的颜色来填充矩阵中的空位。
- `Input structure`：背景为 Orange。网格中散布着若干不同颜色的单像素标记点。每种颜色恰好出现在某些行和某些列上。不同颜色占据的行集合和列集合可能部分重叠。
- `Rule`：
  - 收集所有非背景色像素。
  - 找出所有被至少一个标记像素占据的行，按从上到下排序，编号为输出行 0, 1, 2...
  - 找出所有被至少一个标记像素占据的列，按从左到右排序，编号为输出列 0, 1, 2...
  - 构建一个输出矩阵，大小为（活跃行数 x 活跃列数）。
  - 对于输出矩阵中的每个位置 (r, c)，如果原始网格中对应的实际行和实际列的交叉处有一个非背景色像素，则填入该颜色；否则填入 Maroon。
- `Key insight`：散落的标记像素定义了一个隐含的行列交叉表格——存在标记的位置保留原色，而"应该存在但缺失"的交叉位置用统一的补全色标记。解题者需要先发现行列压缩的逻辑，再发现缺失位置的填充规则。
</new_puzzle>

<new_puzzle>
- `description`：识别每个封闭容器内物体的朝向，将物体沿朝向方向推出容器并在容器开口处留下痕迹色。
- `Input structure`：背景为 Azure。网格中有若干由 Grey 像素构成的 U 形容器（三面封闭、一面开口的矩形框，边框单像素厚）。每个容器内部有一个由某种颜色构成的 L 形物体（三个像素组成的 L 形，占据 2x2 区域的三个格子）。L 形物体的缺失角指示朝向方向。
- `Rule`：
  - 对每个容器，找到其内部的 L 形物体。
  - L 形物体缺失的那个角所指的方向即为该物体的朝向。
  - 若朝向与容器开口方向一致：将物体沿朝向方向平移出容器，直到物体的边界框接触网格边缘。在容器开口处（物体离开的位置）绘制 Yellow 像素。
  - 若朝向与容器开口方向不一致：物体保持不动，但将物体颜色改为 Red。
  - 容器本身（Grey 像素）始终保持不变。
- `Key insight`：L 形物体的缺角方向和容器开口方向的匹配关系是关键的双重判定条件——只有两者一致时物体才会移动，否则物体被"锁定"并变色。这需要解题者同时分析两个独立的方向信息。
</new_puzzle>

- `description`：将网格中的多层嵌套框架拆解为按嵌套深度排列的独立框架行，并根据每层框架内标记像素的数量决定该框架在输出中的缩放比例。
- `Input structure`：背景为 Black。网格中有若干嵌套的单像素厚矩形框架，每个框架用不同颜色绘制。最外层框架最大，每层内层框架严格包含在外层框架内部。部分框架的边框上散布着少量与该框架同色的额外标记像素（位于框架外部但紧邻框架）。
- `Rule`：
  - 识别所有矩形框架及其嵌套关系，按从外到内排序。
  - 数出每个框架外部紧邻的同色标记像素数量 k。
  - 创建输出画布：宽度等于最外层框架的宽度。
  - 从上到下依次放置每个框架：绘制该颜色的单像素厚矩形边框，宽度与原始相同，高度为 k+1 行。
  - 框架之间留一行背景色间隔。
- `Key insight`：嵌套深度决定排列顺序，而同色标记像素的计数不是噪声而是一个几何参数——它控制着每层框架在输出中的高度。解题者需要先发现嵌套拆解规则，再发现计数与高度的映射关系。
</new_puzzle>

<new_puzzle>
- `description`：在分隔线划分的面板中，每个面板包含一个主色形状和若干异色标记点；将每个面板的形状旋转到标记像素多数所在的象限方向，并用标记中最多的颜色重绘旋转后的形状。
- `Input structure`：背景为 Black。网格由 Grey 分隔行和分隔列划分为若干等大的正方形面板。每个面板内有一个由 Blue 像素构成的不对称 4-连通形状，以及 1-3 个不同颜色的单像素标记点（如 Red、Green、Yellow）。标记点分布在形状的外部。
- `Rule`：
  - 对每个面板，找到其中的 Blue 形状和所有标记像素。
  - 以面板中心为原点，统计标记像素在四个象限（左上、右上、左下、右下）中的分布。
  - 找到包含最多标记像素的象限（若平局，选最上方的，再平局选最左方的）。
  - 将 Blue 形状旋转，使其视觉重心偏向该象限（左上不旋转，右上顺时针 90 度，右下 180 度，左下逆时针 90 度）。
  - 用标记像素中出现次数最多的那种颜色重绘旋转后的形状（替代原来的 Blue）。
  - 擦除所有标记像素。
- `Key insight`：标记像素同时编码两个信息：它们的空间位置决定旋转方向，而它们的颜色频率决定输出用色。这两个信息维度需要分别提取并独立应用，构成真正的双层推理。
</new_puzzle>
