- `description`：将散布的前景像素按照它们所在的隐含对角线分组，每组像素合并为一条从组内最近网格角落出发的对角线段，段长度等于组内像素数。
- `Input structure`：背景为 Black。网格中有若干孤立的彩色前景像素，每个像素颜色互不相同。这些像素恰好落在若干条 45 度对角线上（同一条反对角线 r+c=常数 或同一条主对角线 r-c=常数）。
- `Rule`：
  - 将所有前景像素按它们所在的对角线分组。同一对角线上的像素属于同一组。
  - 对每组，确定该对角线最近的网格角落。
  - 从该角落出发，沿对角线方向绘制一条长度等于组内像素数的连续对角线段。
  - 线段内的像素颜色按照原始像素沿对角线从角落方向由近到远的顺序排列。
  - 清除不在线段上的原始像素。
- `Key insight`：像素的分组依据不是颜色而是对角线位置（第一层推理），而线段的长度和起始角落都由组的属性决定——像素数决定长度，最近角落决定方向（第二层推理）。颜色只是被搬运到新位置的标签。
</new_puzzle>

- `description`：解码网格左侧的两列颜色替换图例，将图例中的替换规则按从上到下的顺序依次应用于右侧的多色图案，允许同一像素被多次替换。
- `Input structure`：背景为 Black。网格左侧有一个宽 2 列的垂直图例区域，每行包含一对颜色：左列为"源颜色"，右列为"目标颜色"，表示一条替换规则。图例区域与右侧的主画布之间有一列背景分隔。主画布上有由多种颜色构成的前景图案。
- `Rule`：
  - 读取图例区域的替换规则，从上到下排列。
  - 对主画布中的每个非背景像素，从上到下扫描替换规则。
  - 当像素当前颜色匹配某条规则的源颜色时，将其替换为目标颜色，然后继续扫描后续规则（允许被后续规则再次替换）。
  - 图例区域和分隔列在输出中移除，仅输出替换后的主画布。
- `Key insight`：替换规则的顺序至关重要——同一颜色可能被多次级联替换（如 Red→Blue, Blue→Green 会导致原始 Red 最终变成 Green）。解题者需要发现这一"链式替换"机制，而不是简单的一次性颜色映射。
</new_puzzle>

<new_puzzle>
- `description`：在网格中找到所有矩形边框对象，按边框内部孔洞的面积从大到小排序，然后将排序后的边框颜色依次写入一个与边框数量同高的单列输出网格。
- `Input structure`：背景为 Orange。网格中有若干不同颜色的一像素厚矩形边框（hollow rectangles），每个边框完全不重叠。每个边框的内部面积（孔洞面积）各不相同。边框内部除了背景色外可能还有一些小型干扰像素。
- `Rule`：
  - 识别所有一像素厚的矩形边框对象（每个边框是一个颜色的 4-连通组件，且其 bounding box 的外边界像素全部是该颜色）。
  - 计算每个边框的内部面积（bounding box 面积减去边框像素数）。
  - 忽略非矩形对象和干扰像素。
  - 按内部面积从大到小排序边框。
  - 输出一个 N×1 的单列网格（N 为边框数量），从上到下依次填入排序后的边框颜色。
- `Key insight`：关键在于正确识别"矩形边框"并将其与干扰对象区分开——只有 bounding box 边界完全被同色像素覆盖的对象才是有效边框。排序依据是内部空间面积而非外部总面积或像素数。
</new_puzzle>

<new_puzzle>
- `description`：将网格中的每个前景对象投射到它最近的网格边缘上，投射方向由对象内部的单像素方向标记决定，投射后的对象被压扁为一条沿边缘的单像素线段。
- `Input structure`：背景为 Grey。网格中有若干不同颜色的 4-连通前景对象。每个对象内部恰好嵌入一个不同颜色的单像素方向标记。标记相对于对象 bounding box 中心的位置编码了投射方向：标记在中心上方→向上投射，标记在中心下方→向下投射，标记在中心左侧→向左投射，标记在中心右侧→向右投射。
- `Rule`：
  - 对每个对象，根据内嵌标记的位置确定投射方向。
  - 清除原始对象和标记。
  - 将对象"压扁"为一条线段绘制在投射方向对应的网格边缘上：向上投射→对象投影到第 0 行；向下投射→投影到最后一行；向左→投影到第 0 列；向右→投影到最后一列。
  - 线段的长度等于对象在垂直于投射方向的轴上的跨度，线段的位置对应该跨度的列/行范围。线段颜色为对象的主体颜色。
- `Key insight`：方向标记的位置是相对于对象自身中心的，不是绝对网格位置（第一层推理）。投射结果是降维操作——2D 对象被压缩为 1D 线段（第二层推理）。
</new_puzzle>

<new_puzzle>
- `description`：在包含多个重叠层的网格中，重建每个颜色层的完整矩形，按照它们的遮挡关系从下到上排列为水平色带输出。
- `Input structure`：背景为 Black。网格中有 3-6 种前景颜色，每种颜色原本是一个完整的实心矩形，但矩形之间互相重叠，重叠处只显示最上层的颜色。每种颜色至少有部分像素可见。
- `Rule`：
  - 对每种颜色，从其可见像素推断完整的矩形 bounding box。
  - 在每个两种颜色矩形重叠的像素位置，可见颜色在上层，被遮挡颜色在下层。
  - 综合所有成对的遮挡关系，确定从底到顶的唯一层叠顺序。
  - 输出一个水平色带：每种颜色绘制为一行高、宽度等于其原始矩形面积的色条，从上到下按从底层到顶层的顺序排列。
- `Key insight`：遮挡关系的推断需要在所有颜色对之间综合分析（第一层推理），而输出格式将 2D 的层叠关系编码为 1D 的面积色带——面积信息来自推断的完整矩形而非可见像素数（第二层推理）。
</new_puzzle>
