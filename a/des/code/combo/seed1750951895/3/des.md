- `description`：将每个带有嵌入标记像素的 L 形精灵平移到与标记颜色相同的孤立控制像素位置，同时根据 L 形弯折方向对精灵进行 180 度旋转。
- `Input structure`：背景为 Orange。网格中有若干 4-连通的多色精灵，每个精灵由一种主体颜色的 L 形（3-5 像素）加上一个嵌入其中的不同颜色标记像素组成。网格中还有若干孤立的单像素控制点，每个控制点的颜色与恰好一个精灵的嵌入标记颜色相同。
- `Rule`：
  - 将每个精灵的标记颜色与同色的孤立控制像素配对。
  - 找到精灵 L 形的弯折顶点（即三个以上 4-邻居都是主体色的像素）。
  - 将精灵平移使弯折顶点落在对应控制像素的位置上。
  - 同时将精灵绕弯折顶点旋转 180 度。
  - 清除原始精灵位置和已消耗的控制像素。没有匹配控制像素的精灵保持不动。
- `Key insight`：标记颜色将精灵与目标位置配对（第一层推理），而 L 形弯折顶点既是平移锚点又是旋转中心——旋转方向固定为 180 度而非由其他信息编码（第二层推理，需要从样例中发现这一固定变换）。

- `description`：将网格中的控制条（单像素射线标记）解码为折叠指令，沿指定行或列将网格的一半折叠到另一半上，重叠处取非背景像素。
- `Input structure`：背景为 Black。网格中有两种前景颜色：一种形成散布的图案内容，另一种形成恰好一条完整的行或列（折叠线）以及与折叠线垂直的一个短箭头标记（由 2 个像素组成，从折叠线向一侧延伸）。
- `Rule`：
  - 找到由折叠线颜色构成的完整行或列——这是折叠轴。
  - 箭头标记从折叠轴向一侧延伸，指示"被折叠的一侧"。
  - 将箭头指向的那一侧沿折叠轴翻转，叠加到另一侧。翻转后的像素覆盖规则：非背景像素覆盖背景像素；两侧都是非背景像素时保留原有（未翻转的）一侧的颜色。
  - 输出仅包含未被折叠的那一侧（含叠加结果），裁剪掉折叠轴和被折叠的那一侧。
- `Key insight`：折叠轴的朝向（水平/垂直）从完整行/列直接可见，但被折叠的方向需要通过箭头标记推断（第一层推理）。折叠后的像素合并规则需要从样例中归纳——特别是重叠冲突的解决方式（第二层推理）。
</new_puzzle>

<new_puzzle>
- `description`：根据中心十字分隔线将网格分为四个象限，每个象限中有一个封闭区域；从四个区域中提取"缺失颜色"，将缺失颜色绘制为封闭区域中心的十字标记。
- `Input structure`：背景为 Grey。一行和一列由 Maroon 像素组成的完整分隔线将网格分为四个矩形象限。每个象限内有一个由某种前景颜色构成的封闭矩形框（一像素厚），框内部有 2-3 种不同颜色的像素。四个象限的矩形框内颜色集合几乎相同，但每个象限恰好缺少一种其他三个象限都有的颜色。
- `Rule`：
  - 收集每个象限的矩形框内部出现的所有非背景颜色（不含框本身的颜色）。
  - 取四个象限颜色集合的并集作为"完整集合"。
  - 对每个象限，找到完整集合中唯一缺失的颜色。
  - 在该象限矩形框的内部中心绘制一个 3×3 的十字标记（中心像素加四个正交邻居），颜色为缺失颜色。如果十字标记与已有非背景像素冲突，则仅绘制在背景像素上。
  - 保持所有其他像素不变。
- `Key insight`：四个象限互为参照——缺失颜色无法从单个象限中发现，必须跨象限比较才能确定（第一层推理）。缺失颜色的绘制位置和形状（中心十字）需要从样例中归纳（第二层推理）。
</new_puzzle>

<new_puzzle>
- `description`：在网格中找到所有对称轴不同的前景对象，将每个对象替换为其对称类型对应的标准化符号，符号颜色保持对象原色。
- `Input structure`：背景为 Azure。网格中有若干不同颜色的 4-连通单色前景对象。每个对象恰好属于以下对称类型之一：仅水平对称、仅垂直对称、仅旋转对称（180 度）、完全对称（同时水平和垂直对称）。
- `Rule`：
  - 对每个前景对象分析其反射对称性。
  - 仅水平对称的对象→替换为一条水平线段，长度等于对象 bounding box 的宽度，位于 bounding box 的垂直中心。
  - 仅垂直对称的对象→替换为一条垂直线段，长度等于对象 bounding box 的高度，位于 bounding box 的水平中心。
  - 仅 180 度旋转对称的对象→替换为一个位于 bounding box 中心的单像素点。
  - 完全对称的对象→替换为一个以 bounding box 中心为中心的 3×3 十字形（5 像素）。
  - 替换后的符号使用原对象的颜色，清除原对象的其他像素。
- `Key insight`：解题者需要对每个对象独立判断其对称类型（第一层推理），然后将对称类型映射到固定的几何符号（第二层推理）。对称类型不是由颜色或面积决定的，而是由形状的几何属性决定的。
</new_puzzle>

<new_puzzle>
- `description`：在一个由分隔线分成面板的网格中，每个面板的唯一多数颜色对象充当"印章"，印章被盖在由同色孤立像素标记的位置上，但盖印时需要根据标记像素相对于面板中心的象限进行旋转。
- `Input structure`：背景为 Black。Grey 分隔线将网格分为若干等大的矩形面板。每个面板中有一个由某种非背景非 Grey 颜色构成的连通印章对象（面积 > 3），以及 1-3 个同色孤立像素标记。印章对象总是位于面板的某个角落附近。
- `Rule`：
  - 在每个面板中，识别印章对象和同色孤立标记像素。
  - 对每个标记像素，确定它相对于面板中心位于哪个象限（左上/右上/左下/右下）。
  - 将印章对象平移并旋转后盖印到标记位置：印章的 bounding box 中心对齐到标记像素位置。旋转角度由标记所在象限决定：左上→0 度，右上→90 度顺时针，右下→180 度，左下→270 度顺时针。
  - 清除原始印章对象，保留盖印结果。分隔线不变。
- `Key insight`：标记像素不仅是位置锚点，其在面板内的象限位置还编码了旋转角度——解题者必须发现这一"位置→旋转"映射（核心推理层），而不是简单的平移复制。
</new_puzzle>
