<description>
根据每个封闭区域内部的标记像素颜色，从区域外部的色带图例中查找对应颜色，再用图例中该颜色右侧相邻的颜色重新填充该封闭区域。

Input structure:
- 背景为黑色。
- 网格底部有一条水平色带图例，由若干不同颜色的像素从左到右排列成一行，每种颜色恰好占一个像素，色带之间无间隔。
- 网格上方散布着若干由灰色像素围成的封闭矩形区域（灰色边框宽度为一个像素）。
- 每个封闭矩形区域内部恰好有一个单独的标记像素，其颜色与色带图例中的某种颜色一致；区域内其余像素为黑色背景。

Rule:
- 保留灰色边框和底部色带图例不变。
- 对每个封闭矩形区域，读取其内部标记像素的颜色，在底部色带图例中找到该颜色的位置。
- 取色带中该颜色右侧紧邻的下一个颜色（若标记颜色是色带最右端，则循环回到色带最左端的颜色）。
- 用查到的新颜色填满该封闭矩形区域的全部内部空间（覆盖原来的标记像素和黑色背景），灰色边框保持不变。

Key insight:
标记像素本身不是填充色——它是一个指向色带图例的"指针"，真正的填充色是图例中标记色的后继颜色，解题者需要先发现色带图例的顺序查找关系，再发现"右移一位"的偏移规则。
</description>

<description>
将网格中每个由单色像素围成的封闭房间内的散落碎片，按照房间边框上缺口的位置和方向，整体平移推出房间并填入相邻的走廊中，房间内部变为空白。

Input structure:
- 背景为黑色。
- 网格中有若干个矩形"房间"，每个房间由某种非黑色的单色像素绘制成一像素宽的矩形边框。
- 每个房间的边框上恰好有一个缺口（一个像素宽的断开处），缺口位于边框的上、下、左、右某一侧。
- 每个房间内部有若干散落的彩色碎片像素（颜色与边框颜色不同，也不是黑色），碎片构成某个不规则图案。
- 房间外部的走廊区域全部为黑色背景，走廊宽度足够容纳推出的碎片。

Rule:
- 对每个房间，找到其边框上的缺口位置，确定缺口所在的方向（上、下、左、右）。
- 将房间内部所有碎片像素作为一个整体，沿缺口方向平移，直到所有碎片像素完全离开房间内部区域（即碎片整体刚好移出边框外一个像素的位置）。具体而言：计算碎片整体在缺口方向上距离边框缺口侧边缘的最远像素距离d，然后将整个碎片图案沿缺口方向平移 d+1 个像素。
- 平移后的碎片绘制在走廊中（保持原有颜色和相对形状）。
- 房间边框保持不变（包括缺口），房间内部清空为黑色。

Key insight:
缺口不是破损——它是碎片的"出口"，指示了碎片应被推出的方向；解题者需要先识别每个房间边框上缺口的位置来确定推出方向，再理解碎片是作为一个刚性整体被平移推出（而非逐像素移动或旋转），最后计算出恰好使碎片完全移出房间的平移距离。
</description>

<description>
根据网格中彩色种子像素的颜色在色阶面板中的排列位置，让每个种子向四个正交方向生长出对应长度的十字形射线，射线被其他种子的射线或网格边界截断。

Input structure:
- 背景为黑色。
- 网格左侧有一列垂直排列的色阶面板：从上到下依次排列若干不同颜色的像素（每种颜色一个像素，无间隔），面板与主网格之间有一列黑色间隔。
- 主网格区域中散布着若干单像素的彩色种子，每个种子的颜色都出现在左侧色阶面板中。

Rule:
- 左侧色阶面板保持不变，仅用于查表。
- 对每个种子像素，读取其颜色在左侧色阶面板中从上到下的位置序号（最上方为1，其次为2，依此类推）。
- 该位置序号即为种子的"生长半径"：从种子位置出发，向上、下、左、右四个方向各延伸该数量的像素，用种子自身的颜色绘制射线。
- 射线不进入左侧面板区域，也不超出网格边界。
- 若两条射线发生重叠，生长半径较大的种子的颜色优先（覆盖半径较小的）。
- 种子像素本身保留其颜色。

Key insight:
色阶面板不仅定义了合法颜色集合，更隐含了一个"颜色到数值"的映射关系——颜色在面板中的垂直位置直接决定了该种子的十字射线长度。解题者需要先发现面板位置与射线长度的对应关系，再理解射线重叠时的优先级规则。
</description>

<description>
识别输入网格中由不同颜色组成的若干"门"结构，每扇门由两个相同颜色的门柱和门柱之间的通道组成；将每扇门的通道颜色替换为与门柱颜色对应的"锁芯色"，而锁芯色由网格角落的小型配对图例定义。

Input structure:
- 背景为黑色。
- 网格的左上角有一个小型配对图例区域（用灰色单像素边框围成的矩形）。图例内部每行恰好有两个像素：左侧像素为"门柱色"，右侧像素为对应的"锁芯色"。图例行数等于门的种类数。
- 主网格中散布着若干"门"结构。每扇门由两个相同颜色的门柱像素组成，门柱位于同一行或同一列，彼此间隔恰好两个像素。两个门柱之间的像素目前为背景色（黑色），构成"通道"。
- 不同的门具有不同的门柱颜色，且每种门柱颜色都在左上角图例中有对应条目。

Rule:
- 左上角图例区域（含灰色边框）保持不变。
- 对主网格中的每扇门，识别其门柱颜色。
- 在左上角图例中找到该门柱颜色所在行，读取同行右侧的锁芯色。
- 将该门的两个门柱之间的通道像素（原为黑色的那两个像素）填充为锁芯色。
- 门柱像素本身保持不变。

Key insight:
黑色通道像素看似普通背景，实际上是"未上色的锁芯"；解题者需要先发现左上角图例的"门柱色到锁芯色"映射关系，再识别主网格中成对的门柱结构，最后将映射应用到每扇门的通道上。图例是一个间接查找表，而非直接的颜色替换指令。
</description>

<description>
将网格中散布的多个小型图案块，根据每个图案块边缘伸出的单像素"连接臂"的方向和颜色，拼接成一个完整的大图案——连接臂颜色必须与目标邻居块的边缘颜色匹配。

Input structure:
- 背景为黑色。
- 网格中散布着若干个大小相同的正方形图案块（例如3x3或4x4），每个块内部有多种颜色构成的图案。
- 每个图案块的某些边缘外侧紧邻处有单个彩色像素作为"连接臂"，连接臂从块的边缘向外延伸一个像素。
- 连接臂的颜色与它应该连接的相邻块在该接触边上的边缘像素颜色一致。
- 每个块在上、下、左、右最多各有一个连接臂。

Rule:
- 找到没有左侧连接臂且没有上侧连接臂的块，作为拼接起点（即左上角块）。
- 从起点开始，通过匹配连接臂颜色找到每个块的右邻和下邻：某块右侧连接臂的颜色应与其右邻块左边缘对应行的像素颜色一致；某块下侧连接臂的颜色应与其下邻块上边缘对应列的像素颜色一致。
- 将所有块按照匹配关系无缝拼接（去掉连接臂本身），组成一个大的输出网格。
- 输出中只保留块的内部图案，连接臂不出现在输出中。

Key insight:
连接臂是隐藏的"拼图锁扣"——它们的颜色编码了相邻关系，解题者需要先理解连接臂是方向性配对线索（而非块自身图案的一部分），再通过颜色匹配推断出全局的拼接拓扑结构，最后将分散的块组装成完整图案。
</description>

<description>
在网格中找到由不同颜色构成的若干对"发射器-靶标"配对，每个发射器沿自身形状暗示的方向发射一条射线到达同色靶标，射线路径上经过的其他颜色像素被替换为发射器的颜色，但射线遇到同色靶标时终止。

Input structure:
- 背景为黑色。
- 网格中有若干对同色的像素组，每对由一个"发射器"和一个"靶标"组成。
- 发射器是一个由三个像素组成的箭头形状：一个像素作为箭头尖端，另外两个像素分别位于尖端沿某个正交方向后退一步再向两侧各偏一步的位置（形成V字尾翼）。箭头朝向即尖端相对于尾翼中点的方向。
- 靶标是一个同色的单独像素，位于发射器箭头朝向的延长线上。
- 不同颜色对之间的射线路径可能交叉。

Rule:
- 对每个发射器，确定其颜色和箭头朝向。
- 从箭头尖端沿朝向方向逐像素前进，将路径上的每个黑色背景像素绘制为发射器的颜色。
- 若路径上遇到非黑色像素（属于其他颜色对的结构），也将其覆盖为发射器的颜色。
- 当射线到达同色靶标像素时停止（靶标像素保留，不被覆盖）。
- 发射器本身的三个像素保持不变。
- 若多条射线经过同一个像素，最后处理的射线颜色覆盖先前的（处理顺序为：按发射器尖端像素的行号从小到大，行号相同则按列号从小到大）。

Key insight:
箭头形状不是装饰，而是编码了射线的发射方向——解题者必须从三像素构型中识别出"尖端"和"尾翼"的空间关系来推断朝向；同时需要发现同色单像素靶标是射线的终止条件，而非另一个发射器。两层推理缺一不可：方向推断和配对终止规则。
</description>
</new_puzzle>

<description>
网格中有若干个彩色矩形区域和一个灰色"印章"图案模板；对每个矩形区域，根据其内部已有的少量提示像素确定印章的放置位置，然后用矩形区域自身的颜色将印章图案印入该区域内部，提示像素恰好是印章图案的一部分。

Input structure:
- 背景为黑色。
- 网格中有一个由灰色像素组成的小型不规则图案，作为"印章模板"，位于网格的某个角落，与其他元素不接触。
- 网格中另有若干个不同颜色的实心矩形区域（每个矩形内部全部填充为同一种非黑、非灰的颜色）。
- 每个矩形区域内部有恰好两个像素被替换为黑色（形成黑色"提示点"）。这两个黑色提示点的相对位置与印章模板中某两个灰色像素的相对位置完全一致。

Rule:
- 灰色印章模板保持不变，仅用于参考。
- 对每个彩色矩形区域，找到其内部的两个黑色提示点。
- 将印章模板与提示点对齐：旋转和平移印章模板（允许0度、90度、180度、270度旋转），使模板中对应的两个灰色像素恰好落在两个黑色提示点上。
- 对齐后，将印章模板中所有灰色像素对应的位置（在矩形区域内）替换为黑色。
- 矩形区域内不属于印章图案的像素保留原来的颜色。

Key insight:
两个黑色提示点看似是矩形中的随机缺陷，实际上是印章模板的定位锚点——解题者需要先识别灰色印章模板的形状，再发现每个矩形中的两个黑点与模板中某对像素的几何对应关系（可能需要旋转），最后通过对齐将完整的印章图案"盖印"到矩形中。
</description>
</new_puzzle>
