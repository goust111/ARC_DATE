根据每个封闭区域内部标记像素的颜色，在区域的边框上找到同色缺口，然后从缺口向外延伸射线直到碰到另一个区域的边框或网格边缘。

Input structure：
- 背景为 black。
- 网格中有若干个由同一种颜色（如 blue）绘制的单像素宽封闭矩形边框，边框之间互不接触。
- 每个封闭矩形边框上恰好有一个缺口（即边框上缺少一个像素的位置），缺口处为背景色。
- 每个封闭矩形内部恰好有一个单独的标记像素，颜色各不相同（如 red、green、yellow 等），且不同于边框颜色和背景色。

Rule：
- 对每个封闭矩形，找到其边框上唯一的缺口位置，以及其内部标记像素的颜色。
- 从缺口位置出发，沿缺口所在边的法线方向（即朝向矩形外部的方向）向外逐像素绘制一条射线，颜色为该矩形内部标记像素的颜色。
- 射线延伸直到碰到另一个矩形的边框像素或到达网格边缘时停止（不覆盖已有的边框像素）。
- 保留所有原始边框像素和内部标记像素不变。

Key insight：
缺口的朝向决定射线方向，内部标记的颜色决定射线颜色——解题者必须同时识别两个独立信息源（缺口位置与内部颜色）并将它们关联起来，而非简单地从标记位置出发扩展。

1. `main(grid)` 必须实现新题描述中的确定性转换规则，不能只识别 `generate_input()` 的固定模板。

6. 若规则有多个分支，生成器不能长期固定成一个分支；应让分支在随机样例中合理出现。
