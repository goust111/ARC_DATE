Input structure：
- 背景为 black。
- 网格中散布着若干条 L 形路径片段（即由一段水平线和一段垂直线在拐角处相连组成的直角路径），每条 L 形路径由单一颜色绘制且宽度为 1 像素。
- 每条 L 形路径的拐角内侧（即直角的凹侧对角位置）有一个单独的像素，其颜色不同于该 L 形路径的颜色，称为"指示色块"。
- 有一个 maroon 单像素作为起点标记，它紧邻（4-邻接）某条 L 形路径的一个端点。
- 每条 L 形路径有两个端点（两条线段各自的末端），其中一个端点用于连接前一段路径，另一个端点可能紧邻下一段路径的端点。

Rule：
- 从 maroon 起点标记出发，找到与之相邻的第一条 L 形路径，这是路线的第一段。
- 查看当前 L 形路径拐角处的指示色块颜色，找到与该颜色相同的另一条 L 形路径。
- 在当前 L 形路径的另一个端点（非入口端）与目标 L 形路径的某个端点之间，它们必定在网格上相邻（4-邻接），将它们连接起来。
- 重复此过程：沿新路径走到拐角，读取指示色块颜色，找到下一段路径，直到某条路径的指示色块颜色在剩余路径中找不到匹配（即路线终点）。
- 输出网格保持与输入相同大小，背景为 black，仅绘制完整路线上的所有 L 形路径像素及它们之间的连接像素，起点标记保留为 maroon。未被选中的 L 形路径和所有指示色块均被移除。

Key insight：
拐角处的指示色块不是装饰而是"指针"——它的颜色指向下一段要连接的路径，解题者必须发现这种颜色链式引用机制，并区分哪些 L 形路径属于正确路线、哪些是干扰项。
