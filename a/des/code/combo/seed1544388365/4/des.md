<description>
根据每个封闭区域内部标记像素的颜色，在区域的边框上找到同色缺口，然后从缺口向外延伸射线直到碰到另一个区域的边框或网格边缘。

Input structure：
- 背景为 black。
- 网格中有若干个由同一种颜色（如 blue）绘制的单像素宽封闭矩形边框，边框之间互不接触。
- 每个封闭矩形边框上恰好有一个缺口（即边框上缺少一个像素的位置），缺口处为背景色。
- 每个封闭矩形内部恰好有一个单独的标记像素，颜色各不相同（如 red、green、yellow 等），且不同于边框颜色和背景色。

Rule：
- 对每个封闭矩形，找到其边框上唯一的缺口位置，以及其内部标记像素的颜色。
- 从缺口位置出发，沿缺口所在边的法线方向（即朝向矩形外部的方向）向外逐像素绘制一条射线，颜色为该矩形内部标记像素的颜色。
- 射线延伸直到碰到另一个矩形的边框像素或到达网格边缘时停止（不覆盖已有的边框像素）。
- 保留所有原始边框像素和内部标记像素不变。

Key insight：
缺口的朝向决定射线方向，内部标记的颜色决定射线颜色——解题者必须同时识别两个独立信息源（缺口位置与内部颜色）并将它们关联起来，而非简单地从标记位置出发扩展。
</description>
</new_puzzle>

<description>
将输入网格中被分隔线划分的若干个小格子视为"棋盘"，根据格子内部图案的旋转对称阶数决定该格子在输出中应被替换为哪种颜色，再将这个粗粒度着色方案作为模板，对每个格子内部填充对应颜色的标准化图案。

Input structure：
- 网格由 grey 分隔线划分为 N×M 个大小相同的正方形格子。
- 每个格子内部包含一个由前景色绘制在 black 背景上的小图案。
- 这些小图案各不相同，但每个图案都具有某种旋转对称性：有的图案旋转 90 度后不变（4 阶对称），有的旋转 180 度后不变但 90 度不行（2 阶对称），有的没有旋转对称性（1 阶对称）。
- 在网格的某个角落区域存在一个"图例区"，由三个独立的小色块组成，分别为三种不同颜色，按从上到下排列，分别对应 4 阶、2 阶、1 阶对称。

Rule：
- 首先识别图例区的三种颜色与三种对称阶数的对应关系（最上方颜色 = 4 阶，中间 = 2 阶，最下方 = 1 阶）。
- 对每个格子，分析其内部图案的旋转对称阶数。
- 输出网格与输入网格大小相同，保留 grey 分隔线不变。
- 将每个格子内部全部填充为该阶数对应的图例颜色（即用纯色块替换原来的图案）。

Key insight：
解题者需要先从图例区推断颜色与对称阶数的映射关系，再对每个格子的图案进行旋转对称性判断——两步都需要非平凡的归纳，图例不直接标注含义，而对称性需要心理旋转来验证。
</description>

<description>
在输入网格中找到多个同形但颜色不同的"印章"对象，根据每个印章底部附带的彩色条纹序列确定它们的堆叠顺序，然后将所有印章叠印到同一位置，按该顺序从下往上覆盖。

Input structure：
- 背景为 azure。
- 网格中分散着若干个形状完全相同但颜色各异的连通对象（"印章"），每个印章由单一前景色构成。
- 每个印章的正下方紧贴着一行彩色条纹（高度为 1 的水平像素序列），条纹的长度等于印章的宽度。
- 每个条纹由其他印章的颜色组成（不包含自身颜色），条纹中从左到右的颜色顺序编码了该印章相对于其他印章的"深度排名"。
- 输出网格的尺寸等于单个印章的外接矩形大小。

Rule：
- 识别所有印章及其各自的颜色和条纹。
- 每个印章的条纹代表"在我之下的印章，从最底层到紧挨我下方"的颜色序列。因此条纹最长的印章在最顶层，条纹为空（无条纹）的印章在最底层。
- 根据条纹长度从短到长排列印章，得到从底到顶的堆叠顺序。
- 创建一个与单个印章外接矩形同大的输出网格，背景为 azure。
- 按堆叠顺序依次将每个印章（以其原始形状和颜色）绘制到输出网格的相同位置，后绘制的覆盖先绘制的。

Key insight：
印章的空间位置是干扰信息，条纹长度而非印章位置才决定堆叠顺序——解题者需要先发现条纹编码深度的规律，再理解条纹长度与层级的对应关系，最后执行叠印操作。
</description>

<new_puzzle>
<description>
输入网格中有一组由不同颜色构成的 L 形路径片段和一个起点标记，需要根据每段路径拐角处的"指示色块"选择下一段路径的颜色来拼接完整路线，最终输出仅包含完整路线的网格。

Input structure：
- 背景为 black。
- 网格中散布着若干条 L 形路径片段（即由一段水平线和一段垂直线在拐角处相连组成的直角路径），每条 L 形路径由单一颜色绘制且宽度为 1 像素。
- 每条 L 形路径的拐角内侧（即直角的凹侧对角位置）有一个单独的像素，其颜色不同于该 L 形路径的颜色，称为"指示色块"。
- 有一个 maroon 单像素作为起点标记，它紧邻（4-邻接）某条 L 形路径的一个端点。
- 每条 L 形路径有两个端点（两条线段各自的末端），其中一个端点用于连接前一段路径，另一个端点可能紧邻下一段路径的端点。

Rule：
- 从 maroon 起点标记出发，找到与之相邻的第一条 L 形路径，这是路线的第一段。
- 查看当前 L 形路径拐角处的指示色块颜色，找到与该颜色相同的另一条 L 形路径。
- 在当前 L 形路径的另一个端点（非入口端）与目标 L 形路径的某个端点之间，它们必定在网格上相邻（4-邻接），将它们连接起来。
- 重复此过程：沿新路径走到拐角，读取指示色块颜色，找到下一段路径，直到某条路径的指示色块颜色在剩余路径中找不到匹配（即路线终点）。
- 输出网格保持与输入相同大小，背景为 black，仅绘制完整路线上的所有 L 形路径像素及它们之间的连接像素，起点标记保留为 maroon。未被选中的 L 形路径和所有指示色块均被移除。

Key insight：
拐角处的指示色块不是装饰而是"指针"——它的颜色指向下一段要连接的路径，解题者必须发现这种颜色链式引用机制，并区分哪些 L 形路径属于正确路线、哪些是干扰项。
</description>

<description>
输入网格中有一个大型图案被切割成若干矩形碎片并打散分布，每个碎片的边缘带有彩色"接缝标记"，需要通过匹配相邻碎片边缘上的接缝标记颜色序列来将碎片拼回原始图案。

Input structure：
- 背景为 black。
- 网格中散布着若干个矩形碎片，每个碎片内部包含由多种颜色绘制的图案。
- 每个碎片的四条边缘外侧紧贴着一行或一列彩色像素作为"接缝标记"。接缝标记的长度等于该边的长度，由若干种颜色组成特定序列。
- 如果两个碎片在原始图案中是相邻的，那么它们共享边缘上的接缝标记序列完全相同（如碎片 A 的右边缘接缝序列与碎片 B 的左边缘接缝序列逐像素一致）。
- 所有碎片的高度或宽度并非全部相同，但可拼合成一个无缝无重叠的矩形。

Rule：
- 提取每个碎片四条边的接缝标记序列。
- 通过匹配相邻边的接缝序列（右边缘匹配另一碎片的左边缘，下边缘匹配另一碎片的上边缘），确定碎片之间的邻接关系。
- 将碎片按照邻接关系拼合成完整矩形。
- 输出仅包含拼合后的内部图案，移除所有接缝标记。

Key insight：
接缝标记是拼图的"锁扣"——解题者不能靠碎片在输入中的空间位置来推断拼合顺序，而必须通过逐边比对接缝标记的颜色序列来发现唯一正确的拼合方式，类似于 DNA 序列比对的视觉版本。
</description>

<description>
将输入网格中的多组"容器—液体"对按照容器的孔洞位置进行液体倾倒模拟：液体从容器的孔洞流出，沿重力方向下落，在下方的平台或网格底部堆积成与液体面积相等的矩形水坑。

Input structure：
- 背景为 black。
- 网格中有若干个由 grey 像素绘制的 U 形"容器"，每个容器由三面封闭的墙壁组成，开口朝上。
- 每个容器的一侧墙壁上有恰好一个像素宽的"孔洞"（即墙壁上缺失一个像素的位置）。
- 每个容器内部填充有一种非 grey、非 black 的颜色像素，代表"液体"，液体完全填满容器内部从底部到某一高度的矩形区域。
- 容器之间在水平方向上不重叠；某些容器的下方可能存在由 grey 绘制的水平"平台"线段。

Rule：
- 对每个容器，找到其墙壁上孔洞的位置。
- 清空容器内部的所有液体像素（变为背景色）。
- 从孔洞位置开始，液体沿重力方向（向下）直线下落，直到遇到一个 grey 平台或到达网格底边。
- 在落点处，以孔洞的水平坐标为中心，绘制一个矩形"水坑"：水坑的面积（像素数）等于原容器中液体的像素数，水坑紧贴平台上表面或网格底边向上堆积，宽度等于原容器内部宽度，高度由面积除以宽度确定。
- 水坑的颜色与原液体颜色相同。
- 保留所有 grey 容器壁和平台像素不变。

Key insight：
解题者需要三层推理：第一层是识别孔洞位置（在哪一侧、在什么高度），第二层是追踪液体下落路径找到堆积位置，第三层是用原液体面积和容器内部宽度计算水坑的几何形状——孔洞位置决定水平坐标，液体面积决定水坑高度。
</description>

<description>
输入网格包含若干个彩色环形边框和一组散落的同色像素簇，需要根据每个环内部的"钥匙图案"与某个像素簇的形状匹配关系，将匹配的像素簇移动到对应环的内部并重新着色。

Input structure：
- 背景为 black。
- 网格中有若干个由不同颜色绘制的单像素宽矩形环形边框（如 red 环、blue 环、green 环等），每个环的内部区域大小相同。
- 每个环的内部包含一个由 grey 像素绘制的小图案，称为"钥匙图案"，该图案占据环内部区域的一部分像素位置。
- 在网格的其他位置散落着若干个由 orange 像素组成的连通像素簇，每个簇的形状各不相同。
- 每个 orange 像素簇恰好可以与某一个环内的 grey 钥匙图案拼合成一个完整的矩形（填满环内部），即像素簇的形状是钥匙图案的互补形状。

Rule：
- 对每个环，提取其内部的 grey 钥匙图案。
- 计算该钥匙图案在环内部区域中的互补形状（即内部区域中非 grey 的背景像素位置构成的形状）。
- 在所有 orange 像素簇中找到与该互补形状完全匹配的簇（可能需要旋转 0 度、90 度、180 度、270 度来匹配，但不需要翻转）。
- 将匹配的 orange 像素簇从原位置移除，并以该环边框的颜色绘制在环内部的互补位置上。
- 原 grey 钥匙图案保持不变。
- 最终每个环内部被 grey 图案和环框色图案完全填满。

Key insight：
解题者需要先理解"钥匙与锁"的互补关系——环内 grey 图案不是要匹配的目标而是要互补的模具，然后在散落的像素簇中寻找经旋转后能精确填入剩余空间的那一个，最终重新着色为环框颜色而非保持 orange。
</description>
</new_puzzle>
