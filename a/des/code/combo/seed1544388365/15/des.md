- `description`：根据每个封闭框架的嵌套层数查询颜色图例，用对应颜色填充最内层封闭区域。

- `Input structure`：
  - 背景为 black。
  - 网格中散布若干由同一颜色（如 grey）绘制的嵌套矩形框架组，每组由一层至三层同心矩形边框构成，各组之间不重叠。
  - 网格的一侧有一列纵向排列的单色小方块作为颜色图例，从上到下分别对应层数 1、2、3，每个方块是一个不同的非背景色（例如从上到下为 red、green、blue）。
  - 每个嵌套框架组的最内层区域（被最内圈边框包围的矩形内部）在输入中为 black 背景。

- `Rule`：
  - 对每个嵌套矩形框架组，数出其同心边框层数 N（1、2 或 3）。
  - 在颜色图例中，从上到下第 N 个方块即为该框架组对应的填充颜色。
  - 将该框架组最内层边框围成的矩形内部全部填充为对应颜色，边框本身保持不变。
  - 颜色图例在输出中被擦除为背景色。

- `Key insight`：嵌套深度不是装饰——它是一个索引键，用来查找图例中对应位置的颜色。解题者需要先意识到层数与图例位置的对应关系，再完成内部区域的填色。
</new_puzzle>

- `description`：将分散的单色碎片按颜色匹配并按形状互补关系拼回各自所属的破损模板框中。

- `Input structure`：
  - 背景为 black。
  - 网格中有若干个颜色各异的矩形边框（如 red 边框、blue 边框、green 边框），每个边框的内部包含一个由该边框颜色绘制的实心形状，但形状被挖去了一块——框内存在一个不规则的 black 缺口区域。
  - 网格中另有若干个与边框颜色相同的小型单色碎片散落在边框外部（不与任何边框接触）。每个碎片的形状恰好与某个同色边框内部的缺口形状完全匹配。
  - 每个边框只有一个缺口，每个缺口恰好对应一个同色碎片，无需旋转或翻转即可匹配（碎片平移即可嵌入）。

- `Rule`：
  - 对每个边框，找到与其颜色相同的外部碎片。
  - 将该碎片平移到框内缺口的位置（碎片的形状与缺口形状完全互补，碎片的相对像素布局直接填入缺口的 black 区域）。
  - 擦除碎片原始位置的像素（恢复为 black 背景）。
  - 最终每个边框内部变为完整的实心区域，边框本身不变。

- `Key insight`：颜色匹配只是第一步——关键在于识别碎片轮廓与框内缺口的空间互补关系，而非简单的位置邻近或大小对应。每个碎片的形状是唯一能契合其同色缺口的拼图块。
</new_puzzle>

- `description`：根据房间内方向标记推断图案的投射方向，仅当投射方向与墙壁缺口一致时才将图案弹射出房间。

- `Input structure`：
  - 背景为 black。
  - 网格中有若干由 grey 线段构成的封闭矩形房间（grey 像素形成一格宽的墙壁）。每个房间的四面墙中恰好有一面墙上存在一个一格宽的缺口（开口）。
  - 每个房间内部有若干非背景、非 grey 的彩色像素组成一个小图案（图案不接触墙壁）。
  - 每个房间内部还有恰好一个单独的"方向标记"像素，其颜色与房间内图案的颜色不同。该标记像素位于图案的上、下、左或右侧之一（与图案之间隔开至少一格）。
  - 方向标记像素相对于图案的方位（上/下/左/右）指示了投射方向。

- `Rule`：
  - 对每个房间，找到其内部的图案和方向标记像素。
  - 方向标记在图案的哪一侧（上/下/左/右），即为投射方向。
  - 找到房间墙壁上缺口所在的那一面墙。如果投射方向指向缺口所在墙壁，则将图案沿该方向平移出缺口，放置在房间外部（紧贴缺口外侧），图案在房间内的原始位置清除为 black。
  - 如果投射方向不指向缺口所在墙壁，则图案不移动，保持原样。
  - 方向标记像素在输出中总是被擦除（变为 black）。
  - 墙壁和缺口本身保持不变。

- `Key insight`：缺口的位置是一个陷阱——解题者可能以为图案总是从缺口出去。实际上，必须先从方向标记推断投射方向，只有方向与缺口一致时图案才会被投射出去。这形成了两层推理：第一层是从标记位置推断方向，第二层是将方向与缺口位置做条件匹配。
</new_puzzle>

- `description`：在由灰色路径连接的彩色节点网络中，根据路径上中继标记的空间归属关系对节点重新着色。

- `Input structure`：
  - 背景为 black。
  - 网格中有若干个 3x3 的实心彩色方块作为"节点"，每个节点颜色各不相同（如 red、blue、green、yellow 等）。
  - 节点之间由一格宽的 grey 直线路径（水平或垂直）相连。每条路径连接恰好两个节点，路径的两端分别紧贴两个节点的边缘。
  - 某些路径上有一个或多个单像素的彩色"中继标记"，标记的颜色是网络中其他节点（非该路径两端节点）的颜色。中继标记替换了路径上对应位置的 grey 像素。
  - 有些节点没有被任何中继标记引用（即没有任何路径上出现该节点颜色的标记），这些是"源节点"，保持原色不变。

- `Rule`：
  - 找出所有中继标记。每个中继标记位于某条路径上，该路径连接两个节点。
  - 对每条路径，中继标记按照从路径一端到另一端的顺序排列。距离某端节点最近的中继标记"归属"于该端节点。
  - 如果一个节点的所有相邻路径上，归属于该节点的最近中继标记颜色都相同，则将该节点的 3x3 方块重新着色为该中继标记颜色。
  - 如果一个节点没有任何相邻路径上有归属于它的中继标记，则保持原色不变。
  - 路径上的中继标记在输出中被还原为 grey（恢复为普通路径像素）。

- `Key insight`：解题者需要意识到中继标记的空间位置（在路径上离哪端更近）决定了它影响哪个端点，而非简单地影响路径两端。这是一种基于"距离归属"的方向性着色规则，而非对称传播。
</new_puzzle>

- `description`：将网格中散落的同色同长线段按颜色分组，每组的线段数量和线段长度分别编码输出矩形的两个维度，按长度排序填入预留槽位。

- `Input structure`：
  - 背景为 black。
  - 网格中有若干条水平或垂直的单色线段（一格宽、长度至少为 2 的连续同色像素段）。不同线段可能颜色相同也可能不同，但同一颜色的所有线段长度相同、方向相同。
  - 网格底部有一排由 grey 像素标出的"输出槽位"——若干个等距的小矩形 grey 边框，内部为 black，水平排列。槽位数量等于网格中不同颜色的数量。

- `Rule`：
  - 将所有线段按颜色分组。同一颜色的线段长度和方向一定相同。
  - 对每组，记线段长度为 L，该颜色的线段数量为 N。
  - 为该组构造一个实心矩形：若该组线段为水平方向，则矩形为 N 行 x L 列；若为垂直方向，则矩形为 L 行 x N 列。矩形颜色为该组的颜色。
  - 按线段长度从小到大排序各组，将矩形从左到右依次填入输出槽位中（居中放置在槽位内部）。
  - 输入中的原始线段在输出中被擦除，槽位 grey 边框保留，只在槽位内部添加填充矩形。

- `Key insight`：线段不是要移动或连接的对象——它们是"编码器"：颜色编码身份，长度编码矩形的一个维度，同色线段的数量编码另一个维度。解题者需要先发现"同色同长"的分组规律，再发现长度和数量分别映射到矩形的两个边长。
</new_puzzle>

- `description`：识别每个彩色图案的近似中心对称性，将"缺陷色"标记像素沿对称中心翻转到对称位置，并移除原始标记。

- `Input structure`：
  - 背景为 black。
  - 网格中有若干个互不重叠的彩色区域，每个区域由一种"主色"构成一个几乎关于自身中心点呈中心对称的图案。
  - 每个区域中恰好有少量像素（1 到 3 个）属于一种"缺陷色"（与主色不同），这些缺陷色像素破坏了原本的中心对称性。
  - 每个区域的缺陷色各不相同，但主色可以相同。

- `Rule`：
  - 对每个区域，找到其主色像素群的几何中心（所有主色像素坐标的平均值，取最近整数格）。
  - 找到缺陷色像素的位置。对每个缺陷色像素，计算它关于该几何中心的中心对称点位置。
  - 在对称点位置放置一个缺陷色像素（如果该位置当前是 black 背景）。
  - 将原始缺陷色像素恢复为主色（因为对称结构表明该位置原本应有主色像素）。
  - 主色图案的其余部分不变。

- `Key insight`：缺陷色像素不是噪声——它们是"指针"，标记了对称性需要被修补的位置。解题者需要先识别每个区域近似中心对称的事实，然后理解缺陷像素的作用是"从当前位置跳转到对称位置"，即像素沿对称中心翻转而非简单移除。
</new_puzzle>

<new_puzzle>
- `description`：利用 2x2 色环图例同时编码颜色循环和方向映射，从种子像素出发生成逐段加长的螺旋臂。

- `Input structure`：
  - 背景为 black。
  - 网格中有若干个孤立的彩色"种子"像素，每个种子颜色不同。
  - 网格角落有一个由四种颜色构成的 2x2 色块作为"色环图例"，四种颜色按顺时针排列（例如左上 red、右上 green、右下 blue、左下 yellow），定义一个颜色循环顺序：red → green → blue → yellow → red。
  - 色环图例的空间布局同时定义了方向映射：左上位置对应"向右"，右上位置对应"向下"，右下位置对应"向左"，左下位置对应"向上"（即从每个位置出发的顺时针行进方向）。
  - 每个种子像素的颜色一定是色环中的某种颜色。

- `Rule`：
  - 从每个种子像素开始生长。种子的颜色在色环中对应一个方向，沿该方向绘制 1 个像素（颜色与种子相同）。
  - 绘制完成后，颜色在色环中顺时针前进一步（例如 red → green），新颜色决定下一步的方向，沿新方向绘制 2 个像素（颜色为新颜色）。
  - 每次转向后，绘制长度加 1：第一段 1 像素，第二段 2 像素，第三段 3 像素，以此类推。颜色继续在色环中循环。
  - 如果生长路径遇到网格边界或已有非背景像素，则在该处截断停止（该种子不再继续生长）。
  - 色环图例在输出中保持不变。

- `Key insight`：色环图例同时编码了两个信息：颜色的循环顺序和每种颜色对应的生长方向。解题者需要将 2x2 图例的空间布局（顺时针）映射为方向序列，并发现每段长度递增的规律，两者结合才能还原螺旋臂的生成规则。
</new_puzzle>
