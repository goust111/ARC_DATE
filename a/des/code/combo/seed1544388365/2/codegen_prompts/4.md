- `Input structure`：
  - 背景为 black。
  - 网格被两条贯穿全网格的 grey 直线（一条水平、一条垂直）分为四个象限。grey 线宽度为 1 像素。
  - 四个象限中，恰好有两个象限各包含一个由 azure 像素绘制的矩形空心框架（边框宽度 1 像素）。每个框架在其四个角中的某一个角的外侧对角相邻位置（对角方向 1 像素处）有一个单像素的彩色角标，角标颜色各不相同且不为 black、grey 或 azure。
  - 另外两个象限各包含一个小型 4-连通单色对象（非 black、非 grey、非 azure），对象颜色与某个框架角标颜色相同。每个对象颜色恰好与某一个框架角标匹配。

- `Rule`：
  - 对每个彩色对象，找到角标颜色与该对象颜色相同的框架——此框架即为该对象的"目标模板"。
  - 计算缩放因子：设对象紧致包围盒大小为 h_obj x w_obj，框架内部区域大小为 h_frame x w_frame。缩放因子 s = min(h_frame / h_obj, w_frame / w_obj) 向下取整。
  - 将该对象的每个非 black 像素放大为 s x s 的像素块。
  - 角标所在的角决定对象在框架内部的对齐锚点：对象缩放后的包围盒的对应角与框架内部区域的该角对齐（例如角标在右下角，则缩放后对象的右下角与框架内部右下角对齐）。
  - 输出中，框架和 grey 分隔线保持不变；角标像素保留；原始对象从原位置移除（变为 black）。

- `Key insight`：解题需要三层推理。第一层：发现颜色匹配关系——对象颜色与框架角标颜色相同表示归属。第二层：发现角标位于框架哪个角决定了对象在框架内的锚定位置。第三层：发现对象被整数倍缩放后放入框架内部，缩放比例由框架与对象的尺寸比决定。
