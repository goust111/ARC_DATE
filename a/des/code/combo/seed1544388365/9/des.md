- `description`：根据每个封闭区域内部散落标记点的颜色，将该区域的边框重绘为标记点颜色，同时将标记点替换为边框原来的颜色。
- `Input structure`：背景为主色。网格中有若干由同一颜色（如 blue）绘制的单像素厚封闭矩形边框，彼此不重叠不接触。每个矩形内部散布着少量（1-4 个）同色的标记像素，标记颜色在不同矩形之间各不相同（如 red、green、yellow 等），但同一矩形内部的标记像素颜色一致。矩形内部除标记像素外均为背景色。
- `Rule`：
  1. 对每个封闭矩形边框，找到其内部所有标记像素的颜色 C。
  2. 将该矩形的整条边框从原色重绘为颜色 C。
  3. 将该矩形内部的所有标记像素重绘为边框的原始颜色。
  4. 矩形内部其余背景像素和网格其他区域不变。
- `Key insight`：边框颜色与内部标记颜色互换——标记点不是装饰而是"颜色指令"，它告诉你边框应该变成什么颜色，而标记自身则继承边框原来的颜色。解题者需要同时发现两个非显然规律：边框被重新着色，以及标记点也同步变换为边框旧色，而非简单消失或保持不变。
</new_puzzle>

<new_puzzle>
- `description`：将网格中散落的彩色线段碎片按颜色分组，每组碎片拼装成一个完整的矩形轮廓，并将拼装后的矩形平移到由同色锚点标记的位置。
- `Input structure`：背景为黑色。网格中有若干不同颜色的前景像素组，每种颜色恰好出现两类元素：（a）一组分散的直线段碎片（水平或垂直的连续像素段，长度 2-5），它们的形状恰好能无间隙地拼成一个单像素厚的矩形轮廓；（b）一个孤立的单像素锚点。同色碎片之间互不相邻，锚点也与碎片不相邻。不同颜色的元素互不接触。
- `Rule`：
  1. 按颜色将所有前景像素分组。
  2. 对每种颜色，识别其中的单像素锚点（4-连通邻居中无同色像素的那个）和剩余的线段碎片。
  3. 将该颜色的所有碎片像素数求和，确定它们唯一可拼成的矩形轮廓尺寸：周长 = 总像素数，矩形宽高满足 2(w+h)-4 = 总像素数 且 w ≤ h，取最接近正方形的解。
  4. 以锚点为矩形左上角，在输出中绘制该颜色的完整矩形轮廓。
  5. 清除所有原始碎片和锚点的原位置像素（设为背景色）。
- `Key insight`：碎片的总像素数编码了目标矩形的尺寸，而孤立锚点编码了放置位置。解题者必须先发现"数像素→推矩形大小"这一层，再发现"锚点=左上角"这一层，两步都需要主动归纳。
</new_puzzle>

<new_puzzle>
- `description`：每个彩色对象沿其内部缺口所指方向滑动，滑动距离等于同色对象在网格中出现的次数；若不同颜色对象在目标位置重叠，重叠像素变为指定的混合色。
- `Input structure`：背景为黑色。网格中有若干单色 4-连通对象，每个对象的形状为一个 3x3 的实心方块，方块内部挖去了一个边缘像素形成"缺口"。缺口的位置编码方向：缺口在顶行中央表示向上，在底行中央表示向下，在左列中央表示向左，在右列中央表示向右。网格中同一颜色可能出现 1-3 个这样的对象。颜色使用 red、blue、green、yellow 中的若干种。
- `Rule`：
  1. 对每个对象，通过缺口位置确定其移动方向。
  2. 统计该对象颜色在整个网格中出现的对象个数 N（不是像素数，是同色的独立对象数量）。
  3. 将该对象沿方向平移 N 格（每格 = 1 像素）。
  4. 清除对象原位置，在新位置绘制对象。
  5. 若两个不同颜色的对象在新位置存在像素重叠：red+blue 重叠像素变 magenta，red+green 变 yellow，blue+green 变 azure。同色对象不会重叠（题目保证）。
  6. 对象移动时不会越出网格边界（题目保证）。
- `Key insight`：解题需要三层推理：第一层是从缺口位置识别移动方向，第二层是发现移动距离等于同色对象的计数值而非其他属性，第三层是重叠区域的颜色混合规则。方向编码在形状中而非用额外标记，距离编码在全局统计中而非局部属性中，这两层隐蔽性使得规则不易一眼看穿。
</new_puzzle>

<new_puzzle>
- `description`：在被分隔线划分的网格瓦片中，每个瓦片内的前景图案按照该瓦片在阵列中的行列位置之和进行对应次数的 90 度顺时针旋转。
- `Input structure`：背景为黑色。网格被单像素厚的 grey 分隔线（完整横跨或纵跨）均匀划分为 m 行 n 列的等大矩形瓦片（例如 3x3 或 3x4 的瓦片阵列，每个瓦片约 4x4 到 6x6 像素）。所有瓦片内含有相同的前景图案（由一种非背景、非 grey 的颜色绘制，如 red），该图案是非对称的（即旋转 90/180/270 度后与原图案不同，例如一个 L 形）。输入中所有瓦片的图案朝向完全一致（均为原始朝向，即 0 度）。
- `Rule`：
  1. 将每个瓦片按其在阵列中的位置编号：第 r 行第 c 列的瓦片（0-indexed），计算旋转次数 k = (r + c) mod 4。
  2. 将该瓦片内的前景图案绕瓦片中心顺时针旋转 k × 90 度。
  3. 分隔线和背景保持不变。
- `Key insight`：所有瓦片初始图案相同，但输出中不同瓦片的图案朝向不同。解题者需要先注意到旋转角度随位置变化，再归纳出"行号+列号决定旋转次数"这一空间编码规则。表面上看起来像是随机旋转，但实际上是行列坐标之和对旋转角度的调制。由于图案非对称，旋转结果视觉上可区分，从而能够从样例中逆推出 (r+c) mod 4 的规律。
</new_puzzle>

<new_puzzle>
- `description`：识别网格中由不同颜色路径连接的端点对，将每条路径缩减为仅保留两端像素，然后在两端点定义的矩形区域中根据路径长度与矩形周长的比较关系绘制空心轮廓或实心填充矩形。
- `Input structure`：背景为黑色。网格中有若干条不同颜色的单像素宽路径（4-连通，无分支，可弯折），每条路径的两个端点（仅有一个 4-连通同色邻居的像素）各自紧邻一个 grey 的 2x2 实心方形锚块。不同颜色的路径互不接触，grey 锚块也互不接触。路径颜色使用 red、blue、green、orange、maroon 等，且每种颜色只出现一条路径。每条路径长度至少为 4 个像素。
- `Rule`：
  1. 对每条彩色路径，找到它的两个端点像素 A 和 B，并统计路径上的总像素数 L。
  2. 清除路径上除 A 和 B 之外的所有像素（设为背景色），仅保留两个端点。
  3. 以 A 和 B 的行列坐标为对角顶点，确定一个轴对齐矩形区域。
  4. 计算该矩形的周长像素数 P = 2×(矩形宽+矩形高) - 4。
  5. 若 L ≤ P，则仅绘制矩形的轮廓（单像素厚边框），颜色为路径色。
  6. 若 L > P，则绘制实心填充矩形，颜色为路径色。
  7. 端点 A、B 已被矩形覆盖，保持路径色；grey 锚块保持不变。
- `Key insight`：解题者需要三层推理。第一层：识别出路径被缩减为两个端点。第二层：发现两个端点定义了一个矩形区域。第三层：矩形是空心轮廓还是实心填充取决于路径原始长度与矩形周长的比较——路径越长说明原始"材料"越多，足够多的材料就能填满矩形而不仅仅是画出边框。这个长度-周长的比较判据需要从多个样例中对比归纳才能发现。
</new_puzzle>
