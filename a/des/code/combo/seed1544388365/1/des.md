- `description`：根据边框缺口方向确定对象的投影轴，再用投影长度从颜色图例中查找填充色，最终为每个对象的投影区域着色。

- `Input structure`：
  - 背景为主色（如 Black）。
  - 网格中散布若干个单色矩形对象，每个矩形恰好有一侧紧贴一个单像素厚的同色边框，且边框在某一侧有一个单像素宽的缺口。
  - 网格的某一条边（如最右列）放置一个竖向颜色图例条：图例由若干格子组成，从上到下第 k 格的颜色对应"投影长度为 k"时应使用的填充色。

- `Rule`：
  - 对每个矩形对象，找到其边框上的缺口位置。缺口所在的边决定投影方向：缺口在上边则向上投影，缺口在下边则向下投影，缺口在左边则向左投影，缺口在右边则向右投影。
  - 从矩形对象沿投影方向延伸，计算从矩形边缘到网格边界（或另一个对象）之间可用的空背景像素行/列数，记为投影长度 L。
  - 在颜色图例中查找第 L 格对应的颜色 C。
  - 用颜色 C 填充从矩形边缘到投影终点之间的矩形区域（宽度与矩形在投影垂直方向的尺寸一致）。
  - 原始矩形对象、边框和图例保持不变。

- `Key insight`：解题需要两层独立归纳——第一层是发现缺口方向编码了投影方向（而非简单的"朝某固定方向投射"），第二层是发现投影长度作为索引去查图例中的颜色，两者缺一不可。
</new_puzzle>

- `description`：将散落的彩色碎片按形状配对后合并为完整矩形，再按矩形面积从小到大排列到输出网格中。

- `Input structure`：
  - 背景为主色（如 Black）。
  - 网格中散布偶数个小型单色连通分量（4-连通），每个分量形状不规则。
  - 这些分量两两配对：每对中的两个碎片拼合后恰好构成一个无间隙的实心矩形。配对的两个碎片颜色不同。
  - 没有两对碎片拼出的矩形尺寸完全相同。

- `Rule`：
  - 遍历所有分量，找到形状互补（即拼合后形成实心矩形）的配对。互补判定方法：将两个碎片的像素集合取并集后，检查其是否恰好填满其联合边界框的每一个格子。
  - 对每一对碎片，确定拼合后的矩形尺寸（高 h、宽 w）。拼合时，较小颜色编号的碎片保持原始相对位置在左上方。
  - 按矩形面积（h × w）从小到大排序。
  - 在输出网格中，从左到右依次放置每个拼合后的矩形，矩形顶部对齐到第 0 行，相邻矩形之间留一列背景色间隔。
  - 输出网格高度为所有矩形中最大的 h，宽度为所有矩形宽度之和加上间隔列数，不足高度的部分用背景色填充。

- `Key insight`：核心难点在于发现碎片之间的"互补配对"关系——不是按颜色或位置配对，而是按形状的几何互补性配对。只有识别出这一结构性规律，才能正确拼合并排序。
</new_puzzle>

- `description`：在网格中找到被围栏围成的封闭区域，根据区域内"种子"像素的颜色和数量决定生长图案，向外扩散填充整个封闭区域。

- `Input structure`：
  - 背景为主色（如 Black）。
  - 一种前景色（如 Grey）构成单像素宽的正交线段网络，形成若干封闭的矩形区域（围栏）。围栏线段彼此首尾相连，完全封闭。
  - 每个封闭区域内部有 1 到 3 个"种子"像素，每个种子像素为非背景、非围栏的颜色。同一区域内的种子像素可能颜色相同也可能不同。
  - 围栏外部没有任何种子像素。

- `Rule`：
  - 识别 Grey 围栏形成的所有封闭矩形区域。
  - 对每个封闭区域：
    - 若区域内只有 1 个种子像素，用该种子颜色填满整个区域内部（围栏本身不变）。
    - 若区域内有 2 个同色种子像素，用该颜色绘制从两个种子之间连线方向的条纹图案：若两个种子在同一行则画水平条纹（奇数行填色、偶数行留背景，行号相对于区域内部左上角计算），若在同一列则画竖直条纹（奇数列填色、偶数列留背景）。
    - 若区域内有 2 个不同色种子像素，用棋盘格图案填充区域：区域内部左上角起，偶数格（行+列为偶数）用第一个种子颜色（按从左到右、从上到下先出现的），奇数格用第二个种子颜色。
  - 种子像素本身被填充图案覆盖（即种子只是触发信号，不保留）。

- `Key insight`：解题者需要先发现围栏划分区域的结构，然后归纳出种子数量和颜色异同如何选择三种不同的填充模式——单色填充、条纹和棋盘格。种子的空间排列（同行 vs 同列）进一步决定条纹方向，增加了第三层推理。
</new_puzzle>

- `description`：将网格中的"信号塔"沿其箭头方向发射射线，射线碰到"镜面"后反射，最终在"接收器"处停止，并用射线路径的颜色重绘接收器。

- `Input structure`：
  - 背景为主色（如 Black）。
  - 网格中有若干个"信号塔"：每个信号塔是一个 3×3 的实心方块，方块为某种颜色（如 Red、Blue 等）。在方块的某一侧正中间外侧紧邻一个同色像素，形成一个突出的"箭头"，指示发射方向（上、下、左、右四个方向之一）。
  - 网格中有若干个"镜面"：每个镜面是一个 1×1 的 Magenta 像素。
  - 网格中有若干个"接收器"：每个接收器是一个 1×3 或 3×1 的 Grey 条。
  - 信号塔、镜面、接收器互不重叠。

- `Rule`：
  - 从每个信号塔的箭头方向发射一条射线（单像素宽），射线颜色与信号塔相同。
  - 射线沿箭头方向直线前进，直到碰到镜面、接收器或网格边界。
  - 若射线碰到镜面（Magenta 像素），射线转向 90 度：若原来水平前进则改为竖直前进（具体向上还是向下取决于镜面相对于射线来向的位置——若镜面在射线行进路径的正前方，则从镜面处起向下转弯；若需要明确：水平射线碰到镜面后一律向下转，竖直射线碰到镜面后一律向右转）。镜面像素本身被射线颜色覆盖。
  - 若射线碰到接收器（Grey 条），射线停止，将接收器的所有 Grey 像素重绘为该射线的颜色。
  - 若射线碰到网格边界，射线停止，无其他效果。
  - 射线路径上的所有背景像素都被绘制为射线颜色。
  - 不同信号塔的射线互不干扰（即一条射线不会被另一条射线阻挡）。

- `Key insight`：解题者首先需要识别 3×3 方块加单像素突出构成的"箭头"结构以确定发射方向，然后理解镜面的固定反射规则（水平转竖直、竖直转水平），最后发现接收器被射线"染色"的机制。三层结构环环相扣。
</new_puzzle>

- `description`：识别网格中由边框颜色标记的嵌套层级，根据层级深度对每层内部施加不同的几何变换（保留、水平翻转或旋转180度），然后将变换后的内容写回原位。

- `Input structure`：
  - 背景为主色（如 Black）。
  - 网格中有若干个嵌套的矩形边框，每个边框为单像素宽，颜色各不相同。边框严格嵌套：最外层边框包含第二层边框，第二层包含第三层，以此类推，最深层内部是一个由非边框颜色像素组成的图案。
  - 嵌套层数在 2 到 4 层之间。
  - 每层边框的颜色在整个网格中只出现在该层边框上。

- `Rule`：
  - 识别所有嵌套的矩形边框，按从外到内的顺序确定层级深度（最外层深度为 1，次外层深度为 2，以此类推）。
  - 对最内层的图案区域（不含任何边框像素），根据其所处的嵌套深度 d 施加变换：
    - 若 d 为奇数（即被奇数层边框包裹）：将图案区域做水平翻转（左右镜像）。
    - 若 d 为偶数：将图案区域做 180 度旋转。
  - 所有边框像素保持不变，仅最内层图案区域发生变换。
  - 变换后的图案写回其原始位置。

- `Key insight`：解题者需要先识别出多层嵌套边框的层级结构（这本身需要归纳"嵌套"的概念），然后发现层级深度的奇偶性决定了不同的几何变换类型。关键的迷惑性在于水平翻转和 180 度旋转在某些对称图案上效果相似，解题者必须用非对称图案的样例才能区分这两种变换。
</new_puzzle>

<new_puzzle>
- `description`：将网格中分散的单色线段识别为"骨架"，根据骨架的走向和长度在其两侧对称地生成"羽毛"状分支，分支颜色由骨架端点处的标记像素决定。

- `Input structure`：
  - 背景为主色（如 Black）。
  - 网格中有若干条单色直线段（水平或竖直，长度 ≥ 3 像素），每条线段颜色为 Grey。这些是"骨架"。
  - 每条骨架的恰好一个端点的紧邻外侧（沿骨架延伸方向的下一个格子）有一个非背景、非 Grey 的彩色标记像素（如 Red、Blue 等）。另一个端点外侧为背景或网格边界。

- `Rule`：
  - 对每条 Grey 骨架线段：
    - 找到其带有彩色标记的端点，读取标记颜色 C。
    - 从标记端点开始，沿骨架方向逐像素编号（标记端为第 1 个像素，另一端为第 N 个像素）。
    - 对骨架上的每个像素，在其垂直于骨架方向的两侧各延伸一条长度等于该像素编号的短线段（用颜色 C 绘制）。即第 1 个骨架像素两侧各延伸 1 格，第 2 个各延伸 2 格，以此类推。
    - 延伸时若碰到网格边界则截断，不超出网格。
    - 标记像素本身在输出中被擦除（变为背景色）。骨架线段保持 Grey 不变。

- `Key insight`：解题者需要归纳三个非显然的规律：(1) 标记像素不是装饰而是颜色来源且标识了方向起点；(2) 分支长度随骨架位置线性递增（而非固定长度），形成羽毛/三角形轮廓；(3) 递增方向从标记端向无标记端增长。这三条规律共同决定了最终的对称生长图案。
</new_puzzle>

<new_puzzle>
- `description`：根据网格边缘的行列颜色标注，在每个标注行与标注列的交叉格子处绘制由两种标注颜色混合而成的双色图案。

- `Input structure`：
  - 背景为主色（如 Black）。
  - 网格的第 0 行（顶行）中，部分格子被涂上了非背景颜色，称为"列标注"。每个列标注占一个格子，标注了该列。不同列标注颜色可能相同或不同。
  - 网格的第 0 列（最左列）中，部分格子被涂上了非背景颜色，称为"行标注"。每个行标注占一个格子，标注了该行。
  - 第 (0,0) 格始终为背景色。
  - 网格内部（第 1 行起、第 1 列起的区域）初始全为背景色。

- `Rule`：
  - 对每个被标注的行 r（即第 0 列第 r 行有颜色 A）和每个被标注的列 c（即第 0 行第 c 列有颜色 B），在网格内部的格子 (r, c) 处绘制一个 2×2 的小图案（若空间不足则截断）：
    - 若 A 和 B 是同一种颜色：将 2×2 区域全部填充为该颜色。
    - 若 A 和 B 是不同颜色：将 2×2 区域填充为棋盘格——左上和右下填颜色 A，右上和左下填颜色 B。
  - 标注行和标注列本身（第 0 行和第 0 列）的颜色保持不变。
  - 若两个 2×2 图案有重叠区域，后绘制的（按行优先顺序）覆盖先绘制的。

- `Key insight`：解题者需要发现行列标注构成的"交叉矩阵"结构——每个内部图案的位置由行标注和列标注的交集决定，而图案样式（纯色 vs 棋盘格）由两个标注颜色是否相同决定。这是一种坐标查表机制，与直觉上的"对每个对象做变换"完全不同。
</new_puzzle>
