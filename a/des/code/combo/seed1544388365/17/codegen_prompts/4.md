<new_puzzle index="4">
根据封闭区域内"投票色块"的多数颜色决定该区域的边框颜色，再将少数色块沿边框中心点对称弹射到镜像位置。

Input structure
- 背景为主色。网格中有若干个由灰色（grey）像素围成的一像素宽封闭矩形边框，边框之间不重叠不相邻。
- 每个边框内部散布着若干单像素色块，这些色块只使用两种颜色（例如 red 和 green），每个边框内两种颜色的数量不相等。
- 边框外部的背景区域没有任何色块。

Rule
- 对每个封闭边框，统计内部两种颜色的色块数量，确定多数颜色和少数颜色。
- 将该边框的所有灰色像素重新着色为多数颜色。
- 对每个少数颜色的色块，计算它相对于边框内部矩形中心的位置，将其移动到关于中心的点对称位置。若对称位置已有色块（无论什么颜色），则少数色块不移动，保留在原位。
- 少数颜色色块本身保持原色不变。

Key insight
多数颜色决定了边框的新颜色（"投票"机制），而少数颜色色块被"反弹"到中心对称位置。解题者需要先发现颜色计数决定边框颜色的规则，再独立发现少数色块的点对称迁移规则——两个子规则作用于不同的视觉元素（边框 vs 内部色块），必须分别归纳。
</new_puzzle>
