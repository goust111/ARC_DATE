根据管道网络的连通性将源色块的颜色传播到各终端，再根据终端接收到的颜色混合结果选择输出色。

Input structure
- 背景为主色。网格中有一个由黑色（black）像素构成的一像素宽管道网络，管道沿水平和垂直方向延伸并在交叉点处分叉。
- 管道网络的若干末端（死胡同位置）各有一个彩色单像素"终端"标记，终端颜色均为灰色（grey）。
- 管道网络的另外若干末端各有一个非灰非黑非背景的彩色单像素"源色块"，每个源色块颜色可能不同（如 red、blue、green 等）。
- 管道网络中的某些交叉点处有一个 maroon 像素"阀门"，阀门阻断该交叉点处垂直方向的连通（水平方向仍可通过），即颜色只能沿水平方向穿过阀门所在交叉点。

Rule
- 从每个源色块出发，沿管道网络传播其颜色。在每个分叉处颜色向所有可达方向继续传播，但不可穿过阀门的垂直方向。
- 对每个灰色终端，收集所有能到达它的源色块的颜色集合。
- 如果只有一种颜色到达该终端，则将终端重新着色为该颜色。
- 如果有多种颜色到达该终端，则将终端重新着色为 yellow。
- 如果没有颜色到达该终端（被阀门完全阻断），则终端保持灰色不变。
- 管道网络和源色块本身保持不变。

Key insight
管道的拓扑连通决定了哪些源色块能到达哪些终端，而阀门的方向性阻断打破了交叉点的全连通假设。解题者需要先理解阀门仅阻断垂直方向这一隐含规则，再通过路径追踪确定每个终端的颜色来源，最后根据颜色数量（单一/混合/无）执行不同的着色规则。
</new_puzzle>
