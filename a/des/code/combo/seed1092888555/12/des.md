<new_puzzle>
- `description`：网格中有若干前景对象，每个对象的"邻居计数"（与之 4-相邻的其他对象数量）决定该对象在输出中被绘制为何种基本形状——正方形、十字形或菱形。
- `Input structure`：背景为 black。网格中有若干不同颜色的 4-连通单色前景对象（面积 3 到 8 像素），散布在各处。部分对象的边界框彼此 4-相邻（间距为 1 像素以内），形成局部邻接关系。
- `Rule`：
  - 对每个对象，数与之 4-相邻（边界框间距 <= 1）的其他前景对象数量 N。
  - 清除原始对象，在其边界框中心位置绘制：
    - N = 0（孤立）：一个 3x3 实心正方形，使用该对象颜色。
    - N = 1（一个邻居）：一个 5 像素十字形（中心 + 四个基数方向各一像素）。
    - N >= 2（多个邻居）：一个 5 像素菱形（中心 + 四个对角方向各一像素）。
- `Key insight`：输出形状不取决于原始对象的形状或颜色，而取决于其社交网络——邻居数量决定了完全不同的几何表达。
</new_puzzle>

<new_puzzle>
- `description`：在网格的分隔面板中，找到每个面板图案的唯一"旋转不动点"像素（在所有旋转下位置不变的像素），用特殊颜色标记该不动点。
- `Input structure`：背景为 grey。网格被 blue 分隔线分为若干等大奇数边长正方形面板。每个面板包含一个由彩色像素构成的图案，图案可能具有或不具有旋转对称性。
- `Rule`：
  - 对每个面板，将面板内容分别旋转 90、180、270 度。
  - 找到在所有旋转下颜色保持不变的像素位置（即旋转不动点）。
  - 若面板中心是不动点（对于奇数边长面板中心总是位置不动点，但颜色也必须不变）：将中心像素重绘为 red。
  - 若中心不是颜色不动点：不做任何标记。
  - 保持所有其他像素和分隔线不变。
- `Key insight`：只有当面板图案在中心位置具有完全的四重旋转颜色对称性时，中心才被标记——这需要在脑中旋转图案并检查中心像素是否在每次旋转后保持同色。
</new_puzzle>

<new_puzzle>
- `description`：网格中有一个大型图案和若干散落的"补丁"对象；将每个补丁按颜色匹配嵌入到大型图案中该颜色像素缺失的区域。
- `Input structure`：背景为 black。网格中有一个较大的多色 4-连通前景对象（"主图案"），其中某些位置的像素被替换为背景色形成"空洞"。网格其他位置有若干小型单色前景对象（"补丁"），每个补丁的形状恰好与主图案中某种颜色的空洞形状匹配。补丁的颜色可能与空洞周围的颜色不同。
- `Rule`：
  - 对主图案中的每个空洞区域（连通的背景像素被前景包围），确定空洞边界上最常见的前景颜色 C。
  - 在散落的补丁中，找到形状与该空洞匹配的补丁（归一化掩码在平移下相同）。
  - 将补丁的像素填入空洞位置，但重绘为颜色 C。
  - 擦除补丁的原始位置。
- `Key insight`：补丁的自身颜色是干扰——它不决定填充颜色；真正的填充颜色来自空洞周围的主图案像素，而补丁仅提供形状信息用于匹配。
</new_puzzle>

<new_puzzle>
- `description`：将网格中每个对象按其边界框面积除以像素面积的比率分类——比率为 1 的对象（实心矩形）保留，比率大于 1 的对象（有空隙）被其边界框的实心版本替代。
- `Input structure`：背景为 orange。网格中有若干不同颜色的 4-连通单色前景对象，部分对象是实心矩形（像素完全填满边界框），部分对象是非矩形或有内部空隙的不规则形状。
- `Rule`：
  - 对每个前景对象，计算其边界框面积（宽 x 高）和实际像素面积。
  - 若两者相等（实心矩形）：保持对象不变。
  - 若边界框面积大于像素面积：擦除原始对象，在相同位置绘制一个与边界框等大的实心矩形，颜色不变。
- `Key insight`：变换的条件不是形状名称，而是"填充率"——完全填满边界框的对象不变，不完全填满的对象被补全为矩形。解题者需要通过对比发现"不规则→矩形"的模式。
</new_puzzle>

<new_puzzle>
- `description`：在分隔面板网格中，每个面板包含一个彩色对象和一个标记像素；标记像素到面板边缘的距离编码了该对象应被缩放的倍数，缩放后的对象替换原始面板内容。
- `Input structure`：背景为 black。网格被 maroon 分隔线分为若干等大矩形面板。每个面板内有一个小型彩色前景对象（约 2x2 或 3x3）和一个 yellow 单像素标记。标记位于面板内部，距离面板上边缘 1 到 3 个像素。
- `Rule`：
  - 对每个面板，测量 yellow 标记到面板上边缘的距离 D（1 到 3）。
  - 将面板内的前景对象按 D 倍缩放（每个像素扩展为 DxD 的像素块）。
  - 清除面板原始内容，将缩放后的对象放置在面板内部居中位置。
  - 若缩放后对象超出面板内部，截断超出部分。
  - 擦除 yellow 标记。
- `Key insight`：标记像素的位置不是目标位置——它的垂直偏移量编码了一个缩放参数；解题者需要发现距离与缩放倍数之间的直接对应关系。
</new_puzzle>
