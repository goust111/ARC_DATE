<new_puzzle>
- `description`：网格中有若干对同色对象，每对中一个是"模型"（较大），一个是"钥匙"（较小）；钥匙的形状决定应从模型中删除哪些像素，输出仅保留模型被修剪后的结果。
- `Input structure`：背景为 black。网格中有若干颜色的前景对象，每种颜色恰好有两个 4-连通对象。每对中较大的对象为"模型"，较小的为"钥匙"。钥匙的形状是模型形状的一个子集（在平移对齐后）。
- `Rule`：
  - 对每对同色对象，按面积区分模型和钥匙。
  - 将钥匙的形状掩码归一化到其边界框。
  - 在模型中找到唯一的位置，使得钥匙掩码完全覆盖模型的某个子区域。
  - 擦除模型中被钥匙覆盖的像素（设为背景色）。
  - 擦除钥匙的原始位置。
  - 输出修剪后的模型。
- `Key insight`：钥匙不是要添加的部分——而是要从模型中"挖除"的部分；形状匹配确定挖除位置，面积大小确定谁是模型谁是钥匙。
</new_puzzle>

<new_puzzle>
- `description`：在分隔面板中，每个面板包含若干散落的单像素；将像素按颜色分组后，每组的像素数量决定该颜色在输出中的"条宽"，所有颜色条按像素数量从少到多从左到右排列。
- `Input structure`：背景为 grey。网格被 maroon 分隔线分为若干等大矩形面板。每个面板内有若干不同颜色的孤立单像素前景标记。
- `Rule`：
  - 对每个面板，按颜色统计像素数量。
  - 按数量从少到多排序颜色。
  - 输出一个与面板等高的小网格：从左到右，每种颜色占据一列，列内从底部向上填充该颜色，填充高度等于该颜色的像素数量，其余为背景。
  - 不同面板的输出并排排列，中间用一列分隔。
- `Key insight`：散落的像素位置无关紧要——只有每种颜色的计数有意义，它被转化为柱状图的柱高。解题者需要发现像素是计数器而非空间标记。
</new_puzzle>

<new_puzzle>
- `description`：网格中有一个大型参考图案和若干小型"窗口"框架；每个窗口框架的位置对应参考图案中的某个区域，输出将参考图案中该区域的内容裁剪到窗口框架中。
- `Input structure`：背景为 black。网格的上半部分有一个大型多色图案（"参考图案"，约 10x10 像素）。下半部分有若干由 green 像素构成的小型矩形框架（3x3 或 4x4），框架内部为背景色。每个框架旁有一个 red 标记像素，red 标记的位置与参考图案中某个像素位置在列方向上对齐。
- `Rule`：
  - 对每个窗口框架，通过其旁边 red 标记的列位置确定参考图案中的锚定列。
  - red 标记的行位置相对于框架中心的偏移确定参考图案中的锚定行。
  - 以锚定位置为中心，从参考图案中裁剪一个与窗口框架内部等大的区域。
  - 将裁剪内容填入窗口框架内部。
  - 擦除 red 标记。
- `Key insight`：red 标记是参考图案和窗口框架之间的坐标桥梁——它的空间位置编码了参考图案中的裁剪坐标。
</new_puzzle>

<new_puzzle>
- `description`：在网格中根据每对相邻区域的共享边界长度，选择性地擦除边界——共享边界长度为该区域较短边的区域对之间的边界被保留，其余边界被擦除。
- `Input structure`：背景为无（网格完全由彩色区域填满）。网格由若干不同颜色的矩形区域组成，区域之间直接相邻（共享一条完整的行段或列段边界）。每个区域为单色。
- `Rule`：
  - 对每对直接相邻的区域，计算它们共享边界的长度 L。
  - 若 L 等于其中一个区域在边界方向上的完整边长：保留该边界（不做改变）。
  - 若 L 小于两个区域在边界方向上的完整边长：将边界处两个区域的像素都重绘为两个区域颜色中较浅的那个（在视觉上"融合"边界）。
  - 保持非边界像素不变。
- `Key insight`：边界保留或擦除的判定基于边界长度是否等于相邻区域的完整边长——完整边界表示两个区域完全相邻，不完整边界表示它们只是部分相邻，需要融合处理。
</new_puzzle>

<new_puzzle>
- `description`：网格中有若干对称图案面板，每个面板中有一个"破坏标记"——将对称图案中被标记像素破坏的对称性修复回来，同时根据标记颜色确定修复后新增像素的颜色。
- `Input structure`：背景为 black。网格被 grey 分隔线分为若干等大正方形面板。每个面板包含一个近乎完全对称（水平或垂直对称）的彩色图案，但有 1 到 2 个像素被替换为不同的颜色（"破坏标记"），破坏了图案的对称性。
- `Rule`：
  - 对每个面板，确定图案的对称类型（水平对称还是垂直对称）——通过检查未被破坏的像素推断。
  - 找到被标记颜色替换的像素位置。
  - 将这些位置恢复为根据对称性应有的颜色。
  - 同时，在对称轴的另一侧找到与标记位置对称的像素，将其重绘为标记的颜色。
- `Key insight`：标记不仅指示"哪里被破坏了"——它的颜色还要传播到对称位置，形成一种"交换"效果：被破坏的位置恢复原色，而对称位置获得标记色。
</new_puzzle>
