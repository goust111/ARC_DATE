<new_puzzle>
- `description`：在网格中根据每个前景对象与最近网格角落的关系，将对象翻转到该角落的对角位置。
- `Input structure`：黑色背景上有若干不同颜色的 4-连通前景对象。每个对象的包围盒中心距离四个网格角落中的某一个最近。对象之间不重叠，且翻转后也不会重叠。
- `Rule`：
  - 对每个前景对象，计算其包围盒中心到四个网格角落的距离，找到最近的角落。
  - 将对象关于该角落所在的对角线进行轴对称翻转：左上/右下对角翻转（沿主对角线），右上/左下对角翻转（沿反对角线）。
  - 清除对象的原始位置为背景色。
  - 翻转后的对象放置在新位置，保持原色。
- `Key insight`：最近角落决定翻转轴——左上和右下角对应主对角线翻转，右上和左下角对应反对角线翻转。对象位置和翻转轴之间的对应关系是解题的关键。
</new_puzzle>

<new_puzzle>
- `description`：将网格中散布的同色像素对作为"桥墩"，在两个桥墩之间用第三种颜色绘制一像素宽的桥面，桥面方向由桥墩的对齐方式决定。
- `Input structure`：灰色背景上有若干彩色像素。每种非背景颜色恰好出现两次，形成一对。不同颜色的像素对之间不会在同一行或同一列上产生歧义。网格中还有一种颜色（如 red）从未成对出现，仅作为单个像素存在——这是"桥面颜色指示器"。
- `Rule`：
  - 对每种成对出现的颜色，找到其两个像素的位置。
  - 如果两个像素水平对齐（同行），在它们之间的所有背景像素位置绘制桥面颜色（red）的水平线段。
  - 如果两个像素垂直对齐（同列），绘制垂直线段。
  - 如果两个像素既不同行也不同列，绘制一条 L 形折线连接它们（先水平后垂直），使用桥面颜色。
  - 原始的成对像素保持原色不变。
  - 桥面颜色指示器像素在输出中被消除为背景色。
- `Key insight`：成对的同色像素是桥墩而非需要连接的端点——连接它们的桥面使用由指示器像素指定的第三种颜色。解题者需要发现颜色配对、连接规则和桥面颜色来源三层信息。
</new_puzzle>

<new_puzzle>
- `description`：根据每个分隔面板中前景图案的"稀疏度"（非背景像素占比）决定输出变换：稀疏图案放大，密集图案缩小。
- `Input structure`：网格由蓝色分隔线分为若干等大的方形面板。每个面板内有一个多色前景图案，占据面板内部的不同比例的像素。
- `Rule`：
  - 对每个面板，计算前景像素占面板总像素的比例 R。
  - 如果 R < 0.3（稀疏），将面板的前景图案放大2倍（每个像素变为2x2），裁剪到面板大小。
  - 如果 R > 0.7（密集），将前景图案缩小为1/2（每2x2区域取左上角像素），居中放置在面板内。
  - 如果 0.3 <= R <= 0.7（适中），保持不变。
  - 分隔线保持不变。
- `Key insight`：稀疏度不是一个需要精确计算的数值，而是一个视觉判断——解题者通过"看起来空旷"还是"看起来拥挤"就能判断应该放大还是缩小，但需要发现这个反直觉的规律（空旷的放大、拥挤的缩小）。
</new_puzzle>

<new_puzzle>
- `description`：将每个前景对象替换为它的"边界骨架"——仅保留对象边界上每条边中间的像素，清除其余所有像素。
- `Input structure`：黑色背景上有若干不同颜色的实心矩形前景对象。每个矩形的边长都是奇数（确保每条边有唯一的中间像素）。
- `Rule`：
  - 对每个矩形前景对象，识别其四条边。
  - 对每条边（上边、下边、左边、右边），仅保留该边的中间像素（即该边线段的正中央像素），其余边界像素清除为背景色。
  - 矩形的内部像素全部清除为背景色。
  - 保留的四个中间像素使用原始对象颜色。
- `Key insight`：实心矩形被"骨架化"为仅四个点——这四个点是边的中点而非角点。解题者需要发现保留的是边的中点而非直觉上更显眼的角点。
</new_puzzle>

<new_puzzle>
- `description`：根据每对嵌套框架之间的间距确定它们之间区域的填充颜色，间距越大颜色越靠后于颜色序列。
- `Input structure`：黑色背景上有若干同心矩形框架（一像素厚），颜色各不相同，从外到内嵌套。相邻框架之间的间距（框架边缘到边缘的像素数）可能不同。网格边缘有一个颜色图例条，从左到右排列若干颜色。
- `Rule`：
  - 对每对相邻的嵌套框架（从外到内的第k个和第k+1个），计算它们之间的间距 G（取四条边间距的最小值）。
  - 在颜色图例中，取索引为 G-1 的颜色。
  - 用该颜色填充这两个框架之间的所有背景像素。
  - 最内层框架内部的区域保持为背景色。
  - 框架像素本身保持原色不变。
- `Key insight`：间距值直接映射为颜色图例的索引——间距是一个视觉可数的量（几个像素宽），而图例提供颜色映射。解题者需要发现间距-索引的对应关系。
</new_puzzle>
