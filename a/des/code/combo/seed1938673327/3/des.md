- `description`：根据框架内前景对象的轮廓凹陷方向，从边缘图例中查找对应的填充颜色，再用该颜色填充对象的凹陷区域。
- `Input structure`：黑色背景上有若干不同颜色的 4-连通前景对象，每个对象是一个近似矩形但在某一条边上有一个单像素深的凹陷缺口。网格的左侧边缘有一列 4 行的颜色图例，每行包含一个方向指示符（一个 2 像素的箭头状 L 形：朝上、朝下、朝左或朝右）和一个颜色色块。
- `Rule`：
  - 对每个前景对象，识别其边界上的凹陷缺口所在的方向（上、下、左、右）。
  - 在图例中查找方向指示符匹配的行，读取该行的颜色色块。
  - 用该颜色填充凹陷缺口的像素（将背景色像素替换为图例颜色）。
  - 保留对象的其他像素和颜色不变。
- `Key insight`：凹陷的方向不是缺陷而是编码——图例中的 L 形方向指示符与对象凹陷方向的匹配关系决定填充颜色。解题者需要先发现凹陷方向编码，再归纳出图例的方向-颜色映射。
</new_puzzle>

- `description`：将每个彩色矩形对象沿其最近同色孤立像素的方向平移，平移距离等于该矩形的短边长度。
- `Input structure`：灰色背景上有若干不同颜色的实心矩形对象。对于每种颜色，除了一个矩形对象外，还存在恰好一个同色的孤立单像素，位于矩形对象的正上方、正下方、正左方或正右方（水平或垂直对齐）。
- `Rule`：
  - 对每个矩形对象，找到与其同色的孤立像素。
  - 确定孤立像素相对于矩形的方向（上、下、左、右）。
  - 将矩形沿该方向平移，平移距离等于矩形自身的短边长度。
  - 清除矩形的原始位置为背景色。
  - 孤立像素在输出中被消除（替换为背景色）。
- `Key insight`：同色孤立像素不是目的地标记，而是方向指示器——平移距离由矩形自身的几何属性（短边长度）决定，而非像素与矩形之间的距离。
</new_puzzle>

- `description`：通过比较相邻面板中前景对象的差异像素来推断变换规则，再将该规则应用到最后一个面板。
- `Input structure`：网格被蓝色分隔线分为三个等大的面板（从左到右排列）。前两个面板各包含一个多色前景对象，第三个面板包含一个与第一个面板相似但不完全相同的前景对象。第一面板与第二面板中的对象形状相同，但存在若干像素的颜色差异。
- `Rule`：
  - 比较第一面板和第二面板中对象的每个像素。
  - 对于所有差异像素，记录颜色变化映射（如 red->green, blue->yellow 等）。
  - 将此颜色映射规则应用到第三面板中的对象：凡是匹配映射源颜色的像素，替换为映射目标颜色。
  - 输出仅为变换后的第三面板内容。
- `Key insight`：前两个面板构成一个"变换示例对"，第三面板是测试输入——解题者需要从示例对中归纳出颜色替换规则并泛化应用，本质上是类比推理。
</new_puzzle>

- `description`：将网格中的对称分布的同色对象对连线，连线颜色由对象所在象限对决定。
- `Input structure`：黑色背景上有一个灰色十字将网格分为四个象限。每个象限中有若干不同颜色的小型前景对象。某些颜色在两个关于十字中心点对称的象限中各出现一次（如左上和右下，或右上和左下），形成对称对。
- `Rule`：
  - 找到所有关于中心点对称分布的同色对象对。
  - 对于位于左上-右下对角的对象对，用 red 绘制两对象中心之间的直线段。
  - 对于位于右上-左下对角的对象对，用 green 绘制两对象中心之间的直线段。
  - 连线仅绘制在背景色像素上，不覆盖十字线和现有对象。
  - 没有对称配对的孤立对象保持不变。
- `Key insight`：同色对象在不同象限的对称分布方式决定连线颜色——解题者需要先发现中心对称的配对规则，再归纳出对角方向与连线颜色的映射。
</new_puzzle>

<new_puzzle>
- `description`：根据框架内前景对象之间的包含关系构建层次结构，然后按层次深度重新着色每个对象。
- `Input structure`：橙色背景上有若干不同颜色的闭合矩形框架（一像素粗）。框架可能嵌套（一个框架完全在另一个框架内部）。最外层框架外的背景中有一个小型颜色图例条，图例条从左到右依次排列若干颜色。
- `Rule`：
  - 分析所有框架的包含关系：如果框架 A 的内部完全包含框架 B，则 B 是 A 的子节点。
  - 为每个框架计算其嵌套深度（最外层为深度 0，其子节点为深度 1，依此类推）。
  - 用图例条中第 d 个颜色（从左到右，0 索引）替换深度为 d 的框架的颜色。
  - 保留所有框架的形状和位置不变。
- `Key insight`：框架的原始颜色无关紧要，输出颜色完全由嵌套深度决定——解题者需要先构建包含层次树，再通过图例条的索引映射着色。
</new_puzzle>
