- `description`：根据每个前景对象内部"特殊像素"的颜色从颜色图例中查找对应的旋转角度，然后将整个对象旋转后重新放置。
- `Input structure`：黑色背景上有若干多色 4-连通前景对象。每个对象由一种主色构成大部分像素，内部嵌有恰好一个不同颜色的"特殊像素"。网格边缘有一个颜色图例条，包含四个颜色像素，从左到右分别对应旋转 0 度、90 度、180 度、270 度。
- `Rule`：
  - 对每个前景对象，找到其内部的特殊像素颜色。
  - 在图例中查找该颜色对应的旋转角度。
  - 将整个对象（包括特殊像素）关于其包围盒中心旋转该角度。
  - 旋转后的对象放置在原包围盒的位置。
  - 清除旋转前超出旋转后范围的像素为背景色。
  - 图例保持不变。
- `Key insight`：特殊像素的颜色不是装饰而是旋转指令的编码——它通过图例映射到具体的旋转角度。解题者需要先发现特殊像素的颜色-图例-角度的三级映射链。
</new_puzzle>

<new_puzzle>
- `description`：将网格中前景对象按其包围盒的"长轴方向"分为水平组和垂直组，然后交换两组的颜色。
- `Input structure`：黑色背景上有若干不同颜色的 4-连通前景对象。每个对象的包围盒是长方形（非正方形），因此有明确的长轴方向（水平或垂直）。
- `Rule`：
  - 将所有包围盒宽度大于高度的对象归入"水平组"。
  - 将所有包围盒高度大于宽度的对象归入"垂直组"。
  - 按面积从大到小排列水平组中的对象，同样排列垂直组中的对象。
  - 交换两组中对应位次（按面积排序后的位次）的颜色：水平组第k大的对象使用垂直组第k大对象的原始颜色，反之亦然。
  - 如果一组的对象数量多于另一组，多余的对象保持原色不变。
  - 对象的形状和位置保持不变。
- `Key insight`：颜色交换发生在两个由长轴方向定义的组之间，且交换是按面积排序后的位次对应——解题者需要先发现分组规则，再归纳出面积配对的交换逻辑。
</new_puzzle>

<new_puzzle>
- `description`：根据网格中每个前景对象接触的网格边缘数量，在对象上叠加不同的标记图案。
- `Input structure`：黑色背景上有若干不同颜色的 4-连通前景对象。有些对象完全在网格内部，有些接触一条网格边缘，有些接触两条边缘（位于角落）。
- `Rule`：
  - 对每个前景对象，计算它接触的网格边缘数量（0, 1, 或 2）。
  - 不接触任何边缘（0条）的对象：在其包围盒中心放置一个 yellow 像素。
  - 接触一条边缘（1条）的对象：沿其接触的边缘方向，在对象上叠加一条 yellow 的单像素线（从对象的一端到另一端）。
  - 接触两条边缘（2条，即在角落）的对象：用 yellow 填充对象包围盒的四个角像素。
  - 原始对象像素保持原色不变（yellow 标记叠加在其上方）。
- `Key insight`：边缘接触数量决定标记图案的类型（点、线、角）——三种图案视觉上差异明显，但解题者需要发现它们与边缘接触数量的对应关系。
</new_puzzle>

<new_puzzle>
- `description`：将网格中的每条彩色路径按其端点所在的框架区域着色，路径中间的交叉点使用两个端点颜色的混合规则。
- `Input structure`：黑色背景上有若干灰色矩形框架，每个框架内部填充一种独特的颜色。框架之间有若干白色的一像素宽路径连接不同框架（路径端点接触框架边缘）。某些路径可能在中间交叉。
- `Rule`：
  - 对每条路径，识别其两个端点所接触的框架。
  - 将路径的前半段（从端点A到中点）着色为框架A的内部颜色。
  - 将路径的后半段（从中点到端点B）着色为框架B的内部颜色。
  - 如果路径长度为奇数，中间像素使用框架A的颜色。
  - 路径交叉点的颜色由后绘制的路径决定（路径按端点框架面积从小到大的顺序依次绘制）。
  - 框架保持不变。
- `Key insight`：路径是框架之间的"渐变连接器"——每条路径的两半来自其两端框架的颜色。交叉点的绘制顺序由框架面积排序决定，增加了第二层推理。
</new_puzzle>

<new_puzzle>
- `description`：根据分隔网格中每个面板内前景图案的连通性（单连通或多连通），选择该面板在输出中的表示方式。
- `Input structure`：网格由灰色分隔线分为若干等大的方形面板。每个面板内有一个由同色前景像素构成的图案。有些图案是单个 4-连通组件，有些由多个分离的 4-连通组件构成。
- `Rule`：
  - 对每个面板，计算其前景图案的 4-连通组件数量 N。
  - 创建一个与面板网格同大小的输出面板网格。
  - 如果 N = 1（单连通），在对应的输出面板中，用该图案的颜色绘制一个填满面板的实心矩形。
  - 如果 N >= 2（多连通），在对应的输出面板中，用该图案的颜色绘制 N 个等间隔的水平条纹（条纹数等于组件数）。
  - 分隔线保持灰色。
- `Key insight`：前景图案的具体形状被丢弃——决定输出的仅是组件数量。单组件变实心矩形，多组件变条纹（条纹数等于组件数）。解题者需要发现连通性分析是关键的第一步。
</new_puzzle>
