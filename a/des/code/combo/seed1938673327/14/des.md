- `description`：根据每个前景对象所占行数和列数的奇偶性组合决定其重绘颜色，并将所有对象按面积排序后居中堆叠。
- `Input structure`：黑色背景上有若干不同颜色的 4-连通前景对象。每个对象的包围盒行数和列数可以是奇数或偶数。网格边缘有一个 2x2 的颜色图例：左上格为 red（奇行奇列），右上格为 blue（奇行偶列），左下格为 green（偶行奇列），右下格为 yellow（偶行偶列）。
- `Rule`：
  - 对每个前景对象，计算其包围盒的行数和列数。
  - 根据行数奇偶性和列数奇偶性的组合，从 2x2 图例中查找对应的颜色。
  - 用该颜色重绘对象的所有像素（保持形状不变）。
  - 按对象面积从大到小排序所有对象。
  - 将所有重绘后的对象居中叠放到一个新画布上（与输入等大），大面积在底层、小面积在顶层。
  - 图例区域在输出中不保留。
- `Key insight`：奇偶性组合（2x2矩阵）与图例的2x2布局形成自然映射——解题者需要先发现包围盒尺寸奇偶性的四种组合，再理解面积排序叠放的逻辑。
</new_puzzle>

- `description`：将每个彩色前景对象"投射"到由分隔线定义的镜像位置，投射时根据对象跨越分隔线的行/列数决定颜色变化。
- `Input structure`：黑色背景上有一条灰色的全宽水平分隔线或全高垂直分隔线。分隔线一侧（如上方）有若干不同颜色的 4-连通前景对象。
- `Rule`：
  - 将每个前景对象关于分隔线进行轴对称翻转，在分隔线另一侧绘制镜像副本。
  - 镜像副本的颜色不使用原对象颜色：如果原对象的包围盒跨越的行数等于列数（正方形包围盒），则镜像使用 orange；如果行数大于列数，使用 green；如果列数大于行数，使用 blue。
  - 原始对象保持原色不变。
  - 分隔线保持不变。
- `Key insight`：分隔线是镜像轴，但镜像的颜色不取决于原色而是取决于对象包围盒的宽高比——这个额外的编码层使得规则不能仅从"对称翻转"就完全推断出来。
</new_puzzle>

<new_puzzle>
- `description`：在每个封闭区域内，根据该区域边界的拐角数量选择填充颜色，然后用该颜色从区域中心向外绘制十字形图案。
- `Input structure`：黑色背景上有灰色墙壁像素将网格分隔为若干封闭区域。每个区域的形状为简单的直角多边形（由水平和垂直墙壁段围成）。区域内部为背景色。网格一角有一个小型颜色图例：3行，每行包含一个数字标签区域（用像素数表示数量，如3个像素表示"3"）和一个颜色色块。
- `Rule`：
  - 对每个封闭区域，计算其边界墙壁的拐角数量（墙壁方向发生90度转弯的位置数）。
  - 在图例中查找拐角数量对应的颜色。
  - 从该区域的视觉中心（包围盒中心）出发，向四个基本方向绘制十字形线条，直到碰到墙壁。
  - 十字形使用查找到的颜色。
  - 墙壁和图例保持不变。
- `Key insight`：拐角数量是区域复杂度的度量——简单的矩形区域（4个拐角）和复杂的L形区域（6个拐角）会得到不同的颜色。解题者需要先归纳出拐角计数规则，再理解十字形绘制逻辑。
</new_puzzle>

<new_puzzle>
- `description`：将网格中每个"指针"精灵沿其指向方向移动，移动距离等于指针的长度，到达位置后将指针颜色"印"到目标区域的前景对象上。
- `Input structure`：灰色背景上有若干 4-连通前景对象（各种形状和颜色）和若干"指针"精灵。每个指针是一个一像素宽的直线段（水平或垂直），一端有一个不同颜色的"箭头像素"。箭头像素所在端为指针的指向端。
- `Rule`：
  - 对每个指针，识别其指向方向（箭头像素相对于线段主体的方向）。
  - 计算指针线段的长度 L（包括箭头像素）。
  - 将指针沿指向方向平移 L 个像素。
  - 如果平移后的指针位置与某个前景对象重叠，将重叠的前景对象像素替换为指针主体的颜色（非箭头颜色）。
  - 清除指针的原始位置为背景色。
  - 指针在新位置不被绘制（指针消失，只留下颜色印记）。
- `Key insight`：指针的长度同时编码了移动距离——箭头像素提供方向信息但不决定目标颜色（目标颜色来自线段主体而非箭头）。解题者需要区分箭头颜色和主体颜色的不同作用。
</new_puzzle>

<new_puzzle>
- `description`：根据前景对象之间共享边界的长度决定连接方式：短共享边的对象对合并为一个对象，长共享边的对象对在共享边上绘制分隔线。
- `Input structure`：黑色背景上有若干不同颜色的 4-连通前景对象。部分对象之间存在共享边界（两个对象的像素在某些位置 4-邻接）。
- `Rule`：
  - 对每对 4-邻接的不同颜色对象，计算它们共享边界的长度（共享的邻接像素对数量）。
  - 如果共享边界长度 <= 2（短），将面积较小的对象重绘为面积较大对象的颜色（两对象合并为一种颜色）。
  - 如果共享边界长度 >= 3（长），在两对象的共享边界上绘制一条 yellow 分隔线（在两对象边界像素之间的背景位置或直接在边界像素上绘制）。
  - 没有共享边界的对象保持不变。
- `Key insight`：共享边界的长度决定了"合并"还是"分隔"——短接触暗示两个对象本应属于同一整体，长接触则需要明确标记边界。解题者需要发现这个反直觉的阈值规则。
</new_puzzle>
