- `description`：根据框架内部孔洞的形状从外部精灵库中匹配精灵嵌入，再用孔洞总数从颜色图例中查找统一重着色。

- `Input structure`：
  - 背景为主色（bg）。
  - 一个大型单色矩形框架占据网格中心，框架内部有若干不规则形状的bg孔洞（4-连通bg区域，不接触框架外部）。
  - 框架外部散布着若干小型单色精灵，每个精灵形状（忽略旋转/翻转）与框架内恰好一个孔洞匹配。
  - 网格边缘有一个小型颜色图例条：2-4个不同颜色的单像素竖排，从上到下对应"孔洞数=1"、"孔洞数=2"、"孔洞数=3"等。

- `Rule`：
  - 识别框架内所有孔洞，统计孔洞总数 N。
  - 对每个孔洞，在外部精灵中找到形状匹配的精灵（允许旋转0/90/180/270度和翻转）。
  - 将匹配的精灵以正确的变换嵌入孔洞位置。
  - 嵌入后，将所有精灵像素重着色为图例条中第 N 行对应的颜色。
  - 清除框架外部的精灵和图例条，输出仅包含框架及填充结果。

- `Key insight`：第一层推理是形状匹配——通过旋转/翻转将外部精灵与内部孔洞配对；第二层推理是孔洞计数查表——孔洞总数作为索引从颜色图例中选取统一重着色方案。精灵原始颜色是干扰项。

- `description`：将分散的同色路径片段通过行列对齐间隙连接成完整路径，然后沿路径方向将颜色序列逆序重写。

- `Input structure`：
  - 背景为主色。
  - 多条不同颜色的一像素宽4-连通路径片段分散在网格中。
  - 同色路径片段之间有bg间隙，但在同一行或同一列对齐，间隙不超过3像素。
  - 每条路径连接后是无分支链，恰有两个端点。
  - 路径上每个像素可能被替换为不同前景色，形成多色序列。

- `Rule`：
  - 对每种路径颜色，找到所有同色片段，填充行/列对齐的短间隙将它们连接。
  - 连接间隙用该路径基础颜色填充。
  - 连接后从一端到另一端遍历，读取像素颜色序列。
  - 将颜色序列逆序重写回相同路径位置，路径几何形状不变。

- `Key insight`：第一层需要识别哪些片段属于同一路径（行列对齐+间隙大小），第二层是沿路径做颜色序列反转。连接本身改变了网格，颜色反转作用于连接后的完整路径。
</new_puzzle>

- `description`：根据封闭区域内标记像素数量从边缘色板查找颜色，用该颜色绘制区域的外轮廓线。

- `Input structure`：
  - 背景为主色。
  - 一种前景色形成若干互不相连的封闭环形轮廓（一像素厚闭合边框），每个轮廓内部包含bg和零到若干个标记像素。
  - 标记像素使用统一的标记色（如grey），散布在各轮廓内部。
  - 网格左侧边缘有一列色板：从上到下每个像素代表"标记数=0的颜色"、"标记数=1的颜色"等。

- `Rule`：
  - 清除所有原始轮廓像素和标记像素。
  - 对每个原封闭轮廓，数其内部标记像素数量 k。
  - 在色板中查找第 k 行的颜色 C。
  - 计算外轮廓线：所有与原轮廓像素4-相邻的bg像素位置。
  - 用颜色 C 绘制外轮廓线。
  - 保留色板不变。

- `Key insight`：轮廓被擦除后由向外扩展一圈的新轮廓替代；新轮廓颜色由内部标记计数通过色板查找得到。需先发现"计数→查表"映射，再发现"内轮廓→外轮廓"几何变换。
</new_puzzle>

<new_puzzle>
- `description`：在分隔面板序列中通过多数投票找出每个面板的唯一异常像素，将异常位置收集到新画布上并按面板顺序着色。

- `Input structure`：
  - 网格由3-5个等宽面板组成，面板间用单像素分隔列隔开。
  - 每个面板在bg上有相同的基础图案（同一种前景色），但恰好有一个像素与基础图案不同。
  - 异常可能是前景像素变bg或bg像素变前景。

- `Rule`：
  - 通过多数投票确定每个局部坐标的"正确"颜色，识别基础图案。
  - 对每个面板找到其唯一偏离基础图案的像素位置（局部坐标）。
  - 创建与单面板等大的bg画布。
  - 按面板从左到右顺序，依次用red、blue、green、yellow、magenta在画布对应坐标绘制像素。
  - 若多个面板的异常在同一位置，后色覆盖前色。

- `Key insight`：第一层是跨面板比较发现基础图案；第二层是提取每个面板的偏差位置；第三层是面板序号映射为固定颜色。异常像素的"缺失"或"多余"不重要，只有位置重要。
</new_puzzle>

- `description`：识别由箭头体和箭头头部两种颜色组成的方向精灵，根据指向方向发射体色射线，射线宽度由头部像素数决定。

- `Input structure`：
  - 背景为主色。
  - 若干"箭头"精灵分散在网格中。每个箭头由两部分组成：箭头体（一种颜色，直线段，长2-4像素）和箭头头部（另一种颜色，紧贴体的一端的3像素V形：中间像素在体延长线上，两侧各偏一格）。
  - 箭头可指向上下左右四个方向。

- `Rule`：
  - 对每个箭头确定指向方向（从体到头方向）。
  - 从头部尖端沿指向方向绘制宽度为3的射线（中心列/行及两侧各一），延伸到网格边缘。
  - 射线使用箭头体的颜色。
  - 射线遇到其他箭头像素时停止该列/行的延伸。
  - 保留所有原始箭头像素。

- `Key insight`：体色决定射线颜色，头部形状决定方向，头部像素数决定射线宽度。需先识别箭头组成结构，再根据属性生成射线。箭头间射线互相阻挡增加空间推理复杂度。
</new_puzzle>

<new_puzzle>
- `description`：将网格中每个前景对象的边界缺口方向作为"出口"，从出口射出长度等于对象面积的彩色射线，射线颜色由缺口所在边决定。

- `Input structure`：
  - 背景为主色。
  - 若干单色矩形框架对象（一像素厚空心矩形），每个框架恰好有一个单像素宽的边界缺口。
  - 缺口可以在框架的上、下、左、右任一边。
  - 框架使用的颜色各不相同。

- `Rule`：
  - 对每个框架，找到其边界缺口的位置和方向（缺口所在边的外法线方向即为射线方向）。
  - 计算框架的总像素面积（框架边框的像素数 + 缺口位置本来应有的1个像素 = 完整矩形边框像素数）。
  - 从缺口位置向外发射一条射线，长度等于框架的完整边框像素数。
  - 射线颜色规则：缺口在上边→ red，下边→ blue，左边→ green，右边→ yellow。
  - 射线覆盖bg像素，遇到非bg像素或网格边缘时停止（可能短于预期长度）。
  - 保留所有框架像素不变。

- `Key insight`：缺口方向同时决定射线方向和射线颜色（边→颜色的固定映射需从样例归纳），而框架的像素面积决定射线长度。面积作为一个可视的几何量（数边框像素）被转化为线性长度。
</new_puzzle>
