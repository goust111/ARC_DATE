<new_puzzle>
- `description`：在包含重复图案的网格中，找到唯一被修改的图案实例，将修改的像素位置标记为特殊颜色并输出该图案实例。

- `Input structure`：
  - 网格由分隔行和分隔列划分为等大的矩形单元格。
  - 所有单元格包含同一个多色图案的副本，但恰好一个单元格的图案有1-3个像素与其他单元格不同（被修改）。
  - 修改可能是颜色变化或变为bg。

- `Rule`：
  - 通过多数投票确定每个局部坐标位置的正确颜色，得到共识图案。
  - 找到唯一与共识图案不同的单元格。
  - 输出该单元格的图案，但将所有与共识不同的像素位置替换为 red。
  - 与共识相同的像素保持原色。

- `Key insight`：多数投票提供了"正确答案"的参考，但输出的不是修正后的图案，而是"标记了错误位置"的原始损坏图案。red像素是错误标记而非修补颜色。
</new_puzzle>

<new_puzzle>
- `description`：将输入网格中的多层嵌套框架拆解为独立层，按层级顺序水平排列输出，每层只保留自身像素。

- `Input structure`：
  - 背景为主色。
  - 若干不同颜色的一像素厚矩形框架相互嵌套（最外层最大，最内层最小）。
  - 嵌套层数为3-5层。
  - 最内层可能是实心矩形而非框架。

- `Rule`：
  - 按包围盒面积从大到小识别各层框架。
  - 创建输出画布，宽度为所有层宽度之和加层间间隔，高度为最大层的高度。
  - 从左到右按从外到内的顺序放置每层：每层只包含自身的像素（框架线），内部为bg。
  - 层间间隔一列bg。
  - 每层在输出中垂直居中。

- `Key insight`：嵌套结构被"爆炸视图"式展开——每层独立显示，不再相互遮挡。拆解顺序是从外到内（从大到小），这需要正确识别嵌套层级。
</new_puzzle>

<new_puzzle>
- `description`：根据每个前景对象与网格中心的相对方位，用方位对应的颜色在对象的朝向中心一侧绘制一像素宽的彩色边框。

- `Input structure`：
  - 背景为主色。
  - 网格中心有一个小型标记像素（如grey单像素）。
  - 若干不同颜色的4-连通前景对象分散在中心标记周围。
  - 每个对象明确位于中心的某个基本方位（上、下、左、右，不在对角线上）。

- `Rule`：
  - 对每个前景对象，确定其相对于中心标记的方位。
  - 方位到边框颜色的映射：上方→ red，下方→ blue，左方→ green，右方→ yellow。
  - 在对象朝向中心一侧的外边缘绘制一像素宽的彩色边框（如对象在中心右方，则在对象的左边缘绘制yellow边框）。
  - 保留对象原色和中心标记。

- `Key insight`：边框不是绘制在"朝外"的一侧，而是"朝中心"的一侧。颜色不由对象自身决定，而由其方位决定。需要先发现方位→颜色的映射，再确定边框的放置侧。
</new_puzzle>

<new_puzzle>
- `description`：在含有"色卡"和若干矩形区域的网格中，每个矩形区域内最长连续行段的颜色作为查找键，在色卡中匹配后用色卡的配对色重新填充整个区域。

- `Input structure`：
  - 背景为主色。
  - 网格一侧有一列"色卡"：每两个相邻像素为一组，上像素为查找色，下像素为填充色。
  - 网格中有若干不同颜色的实心矩形区域。
  - 每个矩形区域内部主要由一种颜色填充，但可能有少量另一种颜色的像素夹杂其中。

- `Rule`：
  - 对每个矩形区域，找到其中最长的水平连续同色段，该段的颜色为"主色"。
  - 在色卡中查找主色，找到其配对的填充色。
  - 将整个矩形区域（包括夹杂的异色像素）重新填充为配对的填充色。
  - 保留色卡不变。

- `Key insight`：区域的"主色"不是简单的多数色，而是"最长水平连续段"的颜色——这在多数情况下与多数色一致，但在精心设计的例子中可能不同。色卡提供了颜色映射的间接查找。
</new_puzzle>

<new_puzzle>
- `description`：在网格中的对象对之间绘制连接线，连接线的样式（实线/虚线/点线）由两个对象之间的相似程度决定。

- `Input structure`：
  - 背景为主色。
  - 若干不同颜色的小型4-连通前景对象，成对出现（每种颜色恰好两个对象）。
  - 同色对象对之间通过行或列对齐，可以用直线连接。
  - 同色对象对的形状可能相同或不同。

- `Rule`：
  - 对每种颜色的对象对，比较两个对象的形状：
    - 如果形状完全相同（归一化掩码一致）：用该颜色画实线连接（所有中间像素填充）。
    - 如果形状旋转/翻转后相同：用该颜色画虚线连接（每隔一个像素填充）。
    - 如果形状完全不同：用该颜色画点线连接（每隔两个像素填充一个）。
  - 连接线沿两个对象之间的行或列绘制。
  - 保留所有原始对象。

- `Key insight`：连接线样式编码了形状相似度——完全相同、旋转等价、完全不同分别对应三种线型。需要先比较对象形状，再选择正确的线型。颜色只用于配对而非编码线型。
</new_puzzle>
