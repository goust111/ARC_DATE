<new_puzzle>
- `description`：在包含多个"源"和"目标"框架的网格中，通过框架内部孔洞数量匹配源与目标，然后将源的内部图案按目标框架的朝向旋转后填入目标。

- `Input structure`：
  - 背景为主色。
  - 若干不同颜色的一像素厚矩形框架分为两组：
    - "源"框架：内部包含一个多色小图案，框架完整（无缺口）。
    - "目标"框架：内部为bg，框架有1-4个单像素缺口。
  - 源框架的数量等于目标框架的数量。
  - 不同源框架内部的图案不同。

- `Rule`：
  - 对每个源框架，计算其内部图案中非bg像素的数量 P。
  - 对每个目标框架，计算其缺口数量 G。
  - 当 P = G 时，该源与该目标配对。
  - 确定目标框架的主缺口所在边（缺口最多的边），将源图案旋转使其"上方"对准目标的主缺口边。
  - 将旋转后的源图案填入目标框架内部。
  - 保留所有框架不变，清除源框架的原内部图案。

- `Key insight`：配对键是"源的像素数 = 目标的缺口数"——两个看似不相关的量实际编码了同一个值。旋转方向由目标缺口的分布决定而非固定。
</new_puzzle>

<new_puzzle>
- `description`：将网格中的"路标"精灵解读为方向指令，从起点按指令序列行走，在路径上绘制彩色轨迹。

- `Input structure`：
  - 背景为主色。
  - 一个red像素标记起点位置。
  - 若干"路标"精灵散布在网格中。每个路标是一个3x1或1x3的三像素条：中间像素为grey，两端像素颜色不同——其中一端为某种方向色（red=上，blue=下，green=左，yellow=右），另一端为序号色（决定该路标在序列中的位置）。
  - 序号通过颜色编码：orange=第1步，magenta=第2步，maroon=第3步，azure=第4步。

- `Rule`：
  - 按序号色排列路标的执行顺序。
  - 从起点开始，按每个路标的方向色指示的方向行走固定步数（步数 = 路标的方向色端到网格最近边缘的距离）。
  - 在行走路径上绘制路标的方向色。
  - 每步结束的位置成为下一步的起点。
  - 保留路标精灵不变。

- `Key insight`：路标同时编码了三个信息：执行顺序（序号色）、行走方向（方向色）和行走距离（方向色端的边缘距离）。需要从精灵结构中分离这三个信息维度。
</new_puzzle>

<new_puzzle>
- `description`：根据每个封闭区域的"开口方向"确定该区域的填充图案类型，开口朝上的填充水平条纹，开口朝右的填充垂直条纹，其余保持空白。

- `Input structure`：
  - 背景为主色。
  - 一种前景色形成若干互不连通的U形或C形框架（三面封闭、一面开口的矩形框架）。
  - 每个框架的内部为bg。
  - 开口可以朝上、下、左、右四个方向之一。

- `Rule`：
  - 对每个框架确定开口方向。
  - 根据开口方向选择填充图案：
    - 开口朝上：用框架颜色在内部绘制水平条纹（每隔一行填充一行）。
    - 开口朝下：用框架颜色在内部绘制竖直条纹（每隔一列填充一列）。
    - 开口朝左：内部全部填充框架颜色。
    - 开口朝右：内部保持bg不变。
  - 框架本身保持不变。

- `Key insight`：开口方向是四种不同填充模式的选择器，而非简单的方向信息。四种模式（水平条纹/垂直条纹/全填充/不填充）与四个方向的对应关系需要从样例中归纳。
</new_puzzle>

<new_puzzle>
- `description`：在网格中找到所有具有相同"骨架"的对象（忽略不同的"装饰"像素），将它们提取出来并按原始位置排列，用统一颜色显示骨架、不同颜色标记装饰。

- `Input structure`：
  - 背景为主色。
  - 若干4-连通前景对象，使用2-3种不同颜色。
  - 某些对象共享相同的形状"骨架"（去掉特定位置的像素后形状一致），但在不同位置有额外的"装饰"像素。
  - 不共享骨架的对象是干扰项。

- `Rule`：
  - 找到所有形状在去除最多2个像素后可以变为相同掩码的对象组（骨架匹配组）。
  - 选择包含对象最多的骨架匹配组。
  - 对该组中的每个对象，用 blue 绘制骨架像素（所有对象共有的像素位置），用 red 绘制装饰像素（该对象独有的像素位置）。
  - 在输出画布上按原始网格中的相对位置排列这些对象。
  - 忽略不属于最大组的对象。

- `Key insight`：骨架不是通过腐蚀或形态学运算得到的，而是通过跨对象比较发现的共同子结构。装饰像素是每个对象独有的差异部分。选择最大组是一层额外推理。
</new_puzzle>

<new_puzzle>
- `description`：将网格中的彩色像素按其在前景对象上的"深度"（到对象边界的距离）重新着色，距离越深颜色越深。

- `Input structure`：
  - 背景为主色。
  - 若干单色4-连通前景对象，每个对象面积至少为9个像素。
  - 所有对象使用同一种前景色。
  - 对象形状足够大以至于有明显的"内部"区域。

- `Rule`：
  - 对每个前景对象的每个像素，计算其到对象边界的最小4-连通步数（边界像素 = 有bg邻居的像素，深度=0）。
  - 按深度着色：深度0 → yellow，深度1 → orange，深度2 → red，深度3+ → maroon。
  - 背景不变。

- `Key insight`：每个像素的颜色完全由其在对象内部的深度决定，原始颜色被丢弃。这实际上是对象的距离变换可视化。深度概念需要从样例的同心色环结构中归纳。
</new_puzzle>
