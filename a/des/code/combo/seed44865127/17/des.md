<new_puzzle>
- `description`：在网格中找到由不同颜色层叠形成的"沉积层"结构，将最上层的颜色向下扩展填充到最近的同色层之间的间隙。

- `Input structure`：
  - 背景为主色。
  - 网格底部有多层水平色带堆叠，从下到上颜色各不相同。
  - 某些层有间断——同一层的色带被bg间隙分割成若干段。
  - 间隙的上方可能有其他颜色的层覆盖。

- `Rule`：
  - 从顶层开始向下处理每一层。
  - 对每层颜色的每个间隙，检查间隙上方是否有同色层（更靠近顶部）。
  - 如果上方存在同色像素，从上方像素向下垂直延伸填充间隙，直到遇到另一种颜色或网格底部。
  - 如果上方无同色像素，间隙保持不变。
  - 层间的覆盖关系保持（上层覆盖下层）。

- `Key insight`：颜色从上向下"渗透"填充同色层的间隙——这类似于液体沿通道向下流动到同色基底。需要先识别哪些间隙有上方同色源，再执行垂直填充。
</new_puzzle>

<new_puzzle>
- `description`：将网格中的前景对象按其"接触的分隔线段数"分组，同组对象合并为一个大对象放置在输出的对应行中。

- `Input structure`：
  - 背景为主色。
  - 一种分隔色形成若干不完整的水平和垂直线段（不贯穿整个网格宽/高）。
  - 若干不同颜色的4-连通前景对象分散在网格中。
  - 每个对象可能与0、1或2条分隔线段4-相邻接触。

- `Rule`：
  - 对每个前景对象统计其接触的分隔线段数量。
  - 按接触数量分组（0组、1组、2组）。
  - 对每组，将组内所有对象的形状水平拼接（按原始从左到右顺序，间隔一列bg）。
  - 在输出中从上到下排列三组：0组在顶行，1组在中间，2组在底行。
  - 每组保留对象原色和形状。

- `Key insight`：分隔线段不是分区边界而是"接触探针"——对象与分隔线段的接触数量决定了其分组归属。需要先发现接触计数作为分类标准，再按组重新排列。
</new_puzzle>

<new_puzzle>
- `description`：在含有"窗口"和"景观"的网格中，每个窗口框架的颜色决定它能"看到"景观中哪种颜色的对象，窗口内只显示匹配色的对象投影。

- `Input structure`：
  - 背景为主色。
  - 网格分为上下两半。
  - 上半部："景观"区域，包含若干不同颜色的前景对象散布在bg上。
  - 下半部：若干不同颜色的矩形"窗口"框架（一像素厚空心矩形），内部为bg。
  - 每个窗口框架的颜色与景观中某种对象颜色相同。

- `Rule`：
  - 对每个窗口，确定其框架颜色。
  - 在景观中找到所有同色对象。
  - 将这些对象垂直投影到窗口的列范围内（只保留与窗口列范围重叠的对象像素）。
  - 将投影后的对象绘制在窗口内部，行位置保持与景观中的相对位置一致（按比例缩放到窗口高度）。
  - 不匹配色的景观对象不出现在该窗口中。
  - 保留景观和窗口框架不变。

- `Key insight`：窗口颜色是"颜色过滤器"——每个窗口只"看到"同色的景观对象。不同窗口显示景观的不同颜色子集。需要先发现颜色匹配的过滤规则，再理解投影机制。
</new_puzzle>

<new_puzzle>
- `description`：将网格中每个前景对象替换为其"影子"——影子的形状是对象在某个光源方向上的投影轮廓，光源方向由网格角落的标记确定。

- `Input structure`：
  - 背景为主色。
  - 网格的一个角落有一个单像素yellow标记，表示"光源"位置。
  - 若干不同颜色的4-连通前景对象分散在网格中。
  - 对象形状为简单的凸形（无凹陷）。

- `Rule`：
  - 光源在角落，光线方向为从光源角落指向网格中心的对角方向。
  - 对每个前景对象：
    - 清除原始对象像素。
    - 从对象的每个像素沿光线方向延伸2个像素，绘制grey影子。
    - 影子像素不覆盖其他前景对象。
  - 保留光源标记。

- `Key insight`：光源角落决定了所有影子的统一方向（对角线方向），影子长度固定为2像素。需要先发现角落标记=光源，再确定影子方向和长度。不同角落产生不同方向的影子。
</new_puzzle>

<new_puzzle>
- `description`：在含有多个"称重盘"的网格中，根据每个盘内对象的总面积与盘大小的比值，选择盘倾斜的方向——面积比大于一半的盘向对象密集侧倾斜。

- `Input structure`：
  - 背景为主色。
  - 若干"称重盘"结构分散在网格中。每个称重盘由以下部分组成：
    - 一条水平grey"横梁"（长5-7像素）。
    - 横梁中点下方有一个垂直grey"支柱"（2-3像素高）。
    - 横梁的左端和右端各悬挂一个矩形"盘"（由grey框架围成，大小相同）。
  - 每个盘内部可能有若干彩色前景像素（代表重物），分布不对称。

- `Rule`：
  - 对每个称重盘结构，分别统计左盘和右盘内的前景像素数量。
  - 较重的一侧（像素更多）向下倾斜：
    - 将较重侧的盘向下移动一行。
    - 将较轻侧的盘向上移动一行。
    - 横梁相应倾斜（较重端低一行，较轻端高一行）。
  - 如果两侧等重，保持水平不变。
  - 保留所有像素颜色。

- `Key insight`：这是一个"视觉天平"——左右盘内像素数量的比较决定倾斜方向。需要先识别称重盘结构的各个组成部分，再统计比较左右重量，最后执行几何变换。
</new_puzzle>
