<new_puzzle>
- `description`：在网格中识别由不同颜色像素组成的"指令序列"，按指令顺序对一个"画笔"精灵执行移动和绘制操作，最终输出画笔轨迹。

- `Input structure`：
  - 背景为主色。
  - 网格左列有一个垂直"指令序列"：从上到下排列的彩色像素，每个像素的颜色编码一个方向（red=右移2格，blue=下移2格，green=左移2格，yellow=上移2格）。
  - 网格中有一个orange单像素标记为"画笔起点"。
  - 指令序列与画布区域之间有一列bg分隔。

- `Rule`：
  - 从起点开始，按指令序列从上到下依次执行移动。
  - 每次移动后，在新位置绘制一个orange像素。
  - 移动路径上经过的所有bg像素也绘制为grey轨迹色。
  - 如果移动会超出网格边界，停在边界上。
  - 输出保留指令序列和轨迹。

- `Key insight`：指令序列不是装饰而是程序代码——颜色编码方向，顺序编码执行次序。画笔的最终轨迹是程序执行的结果。需要先破译颜色→方向的映射，再模拟执行。
</new_puzzle>

<new_puzzle>
- `description`：在包含"模具"和"材料"的网格中，材料被模具的凸起部分"压印"——凸起对应的材料位置被压凹（变为bg），其余材料保持不变。

- `Input structure`：
  - 背景为主色。
  - 网格分为上下两半，中间有一行bg分隔。
  - 上半部："模具"，由一种前景色在bg上形成图案（凸起部分为前景，凹下为bg）。
  - 下半部："材料"，由另一种前景色完全填满（实心矩形）。
  - 模具和材料宽度相同。

- `Rule`：
  - 将模具的图案垂直翻转（上下镜像）。
  - 将翻转后的模具对齐到材料的上表面。
  - 模具的凸起位置对应的材料像素被"压凹"——变为bg。
  - 保留模具不变，输出修改后的材料区域。

- `Key insight`：模具需要先翻转再应用——这模拟了真实的压印过程（模具朝下压在材料上时图案是镜像的）。如果不翻转直接对应，结果会是错误的。
</new_puzzle>

<new_puzzle>
- `description`：在网格的棋盘格布局中，每个格子里的小图案决定了该格子在输出中应该用哪种宏观纹理填充，纹理类型由图案的对称性决定。

- `Input structure`：
  - 背景为主色。
  - 网格由分隔线划分为等大的正方形格子（如4x4格子）。
  - 每个格子内有一个小型多色图案。
  - 图案可能具有不同类型的对称性：四重对称（水平+垂直都对称）、仅水平对称、仅垂直对称、无对称。

- `Rule`：
  - 对每个格子判断其图案的对称类型。
  - 四重对称：格子填充为实心（用图案的主色全部填满）。
  - 仅水平对称：格子填充水平条纹（交替行用主色和bg）。
  - 仅垂直对称：格子填充垂直条纹（交替列用主色和bg）。
  - 无对称：格子填充为棋盘格（交替像素用主色和bg）。
  - 分隔线保持不变。

- `Key insight`：图案的具体内容不重要——只有其对称性类别决定输出纹理。四种对称类型对应四种视觉上截然不同的纹理，但映射关系需要从样例中归纳。
</new_puzzle>

<new_puzzle>
- `description`：根据每个前景对象的"伸展方向"（包围盒中较长的一维），将对象沿垂直于伸展方向的轴进行折叠——两半叠加，重叠部分变色。

- `Input structure`：
  - 背景为主色。
  - 若干单色4-连通前景对象，每个对象的包围盒为明确的非正方形矩形。
  - 对象可以是水平伸展的（宽>高）或垂直伸展的（高>宽）。
  - 每个对象的较长维度为偶数。

- `Rule`：
  - 对每个对象确定伸展方向。
  - 沿伸展方向的中线将对象折叠——将一半翻转叠加到另一半上。
  - 水平伸展的对象沿垂直中线左右折叠；垂直伸展的沿水平中线上下折叠。
  - 折叠后的像素位置：
    - 只有一半有像素→保持原色。
    - 两半都有像素（重叠）→变为 red。
    - 两半都无像素→保持bg。
  - 输出画布大小为折叠后的大小（较长维度减半）。

- `Key insight`：伸展方向决定折叠轴——这不是随意的选择而是由包围盒长宽比唯一确定的。重叠区域的颜色变化揭示了对象形状的内部对称性。
</new_puzzle>

<new_puzzle>
- `description`：在含有"源"面板和"目标"面板的网格中，将源面板的每一行/列颜色统计结果作为索引，从颜色图例中查找对应色填充目标面板的同行/列。

- `Input structure`：
  - 背景为主色。
  - 网格分为三个区域（由分隔列隔开）：左侧"源面板"、中间"颜色图例"、右侧"目标面板"。
  - 源面板包含一个多色图案。
  - 颜色图例是一列像素，从上到下对应"计数1的颜色"、"计数2的颜色"等。
  - 目标面板为空bg。

- `Rule`：
  - 对源面板的每一行，统计该行的非bg像素数量 k。
  - 在图例中查找第 k 行的颜色。
  - 用该颜色填充目标面板的同一行（整行填满）。
  - 源面板和图例保持不变。

- `Key insight`：源面板的每行像素计数转化为目标面板的行颜色——计数值通过图例间接映射为颜色。源面板的实际颜色和图案形状都不影响输出，只有每行的像素密度重要。
</new_puzzle>
