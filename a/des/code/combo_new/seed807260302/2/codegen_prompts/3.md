用网格边缘的箭头标记确定射线方向和起点，射线在遇到彩色障碍物时将障碍物的颜色"吸收"并改变自身颜色继续前进。

Input structure：
- 背景为黑色。网格边缘（上、下、左、右）上有若干由 green 像素构成的箭头标记，每个箭头由三个像素组成：一个轴像素和两个翼像素，形成指向网格内部的箭头形状。例如，左边缘的箭头为一列三行，中间像素在最右，上下像素各退一列，指向右方。
- 网格内部散布着若干单像素的彩色障碍物（非黑色、非 green）。

Rule：
- 每个边缘箭头从其轴像素位置沿箭头指向方向发射一条单像素宽的射线，初始颜色为 green。
- 射线逐格前进；当射线的下一格是彩色障碍物时，射线覆盖该障碍物的位置，并且从该位置起射线颜色变为该障碍物原来的颜色，继续沿同方向前进。
- 射线到达网格对边边缘时停止。
- 若两条射线交叉，交叉点的颜色为后绘制射线的颜色（按箭头在边缘上的顺序：上边从左到右、右边从上到下、下边从右到左、左边从下到上依次绘制）。

Key insight：
- 箭头形状编码了方向（而非简单的边缘位置），射线不仅是填充工具，还会在碰到障碍物时发生颜色突变——解题者必须同时发现方向编码规则和颜色吸收机制，两者结合才能正确预测输出。
