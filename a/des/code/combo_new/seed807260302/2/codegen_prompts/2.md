将散落的彩色碎片按颜色配对，每对碎片互为镜像拼合成完整矩形，再按矩形面积从小到大纵向堆叠输出。

Input structure：
- 背景为黑色。网格中散布着若干彩色4-连通对象，每种非背景色恰好出现两个对象。
- 同色的两个对象形状互补：将其中一个沿垂直轴镜像翻转后，与另一个恰好拼合成一个无缝实心矩形（无间隙、无重叠）。
- 各对象的像素数不超过 12。

Rule：
- 将同色对象配对。对每一对，将其中一个对象沿垂直轴镜像后与另一个拼合，形成实心矩形。拼合时，镜像对象紧贴原对象右侧，使二者左右合并。
- 计算每个拼合矩形的面积（宽 × 高）。
- 输出网格宽度等于最大矩形的宽度，高度等于所有矩形高度之和加上矩形间的 1 行黑色间隔。
- 按面积从小到大，将矩形从上到下堆叠放置，每个矩形左对齐，矩形之间用一行黑色分隔。

Key insight：
- 解题者首先需要发现同色碎片互为镜像互补这一隐蔽关系，然后需要发现输出的排列顺序取决于拼合后矩形的面积而非颜色或输入位置。两层独立归纳构成核心难度。

## 实现要求

1. `main(grid)` 必须实现新题描述中的确定性转换规则，不能只识别 `generate_input()` 的固定模板。
2. `generate_input()` 必须随机生成多样样例，不能固定死。随机维度应覆盖：网格大小、对象数量、位置、颜色、方向、形状参数或关键分支。
3. 生成器必须保证输入满足 `main()` 的隐式假设：对象不重叠、不越界、特殊标记唯一或可区分、匹配关系无歧义、关键分支出现概率相同。
4. 禁止把 ARC 颜色 id 、亮度、拼写等当作人类不可见的数值语义参与排序、大小比较或隐藏映射。颜色变化必须有可见结构线索。注意颜色亮度、拼写等也是不可见信息，若描述中出现违规的颜色id或者亮度，可自行使用少量的固定颜色替代，但注意生成时要在三个以内输入输出网格中对所有变换100%覆盖度。
