根据每个封闭房间内"门"的朝向，将房间内部的自由色块旋转相应角度后重新放置。

Input structure:
- 背景为 black。网格中有若干由 grey 像素围成的封闭矩形"房间"，房间大小各异（内部至少4x4）。
- 每个房间的 grey 边框上恰好有一个单像素缺口（"门"），门可以在上、下、左、右四个边中的任意一边。
- 每个房间内部有一个由单一非 grey、非 black 颜色构成的小型不对称色块（4-连通，面积3-5像素），色块不触碰房间边框。

Rule:
- 确定每个房间的门所在的边：上边=0度，右边=90度，下边=180度，左边=270度。
- 将房间内部的色块以其自身包围盒中心为锚点，顺时针旋转"门的角度"（上边不旋转，右边旋转90度，下边旋转180度，左边旋转270度）。
- 旋转后的色块放回房间内部的对应位置（旋转后包围盒中心保持在房间内部中心）。
- 房间边框、门缺口和背景保持不变。

Key insight:
门的位置不是装饰而是旋转指令——解题者必须先识别"门在哪一边"编码了旋转角度，再对每个房间内的不对称色块执行对应旋转。色块的不对称性使旋转效果可辨别。

Reflect the solid rectangular source objects across the full separator line and color the gap with the separator color.

Input structure:
- A dominant background contains one full-width or full-height one-pixel
  separator line in a non-background color.
- One other foreground color forms solid rectangular objects, all strictly on the same side of that separator.
- Remaining non-background pixels are scattered distractors.

Rule:
- Keep the input grid shape and unchanged pixels outside each affected corridor.
- Mirror each source object across the separator line.
- For every source object, recolor the rectangular strip between the
  original object and its reflection to the separator color, then paint the
  reflected object in the source color.

Key insight:
- The full straight line is a mirror axis; the real objects are identified
  structurally as the only solid rectangles confined to one side, while
  scattered pixels are noise that may be overwritten inside the corridor.

## 实现要求

1. `main(grid)` 必须实现新题描述中的确定性转换规则，不能只识别 `generate_input()` 的固定模板。
2. `generate_input()` 必须随机生成多样样例，不能固定死。随机维度应覆盖：网格大小、对象数量、位置、颜色、方向、形状参数或关键分支。
3. 生成器必须保证输入满足 `main()` 的隐式假设：对象不重叠、不越界、特殊标记唯一或可区分、匹配关系无歧义、关键分支出现概率相同。
4. 禁止把 ARC 颜色 id 、亮度、拼写等当作人类不可见的数值语义参与排序、大小比较或隐藏映射。颜色变化必须有可见结构线索。注意颜色亮度、拼写等也是不可见信息，若描述中出现违规的颜色id或者亮度，可自行使用少量的固定颜色替代，但注意生成时要在三个以内输入输出网格中对所有变换100%覆盖度。
5. 输出样例要视觉清晰：避免对象粘连、覆盖关系混乱、同一像素多重语义、过密导致规则不可读。
6. 若规则有多个分支，生成器不能长期固定成一个分支；应让分支在随机样例中合理出现，即每个分支出现的概率平均，所谓的分支是在描述中提到的分支，即规则语义中的不同情况。
7. 代码风格参考 `ARC_code`：使用 `numpy`，必要时使用本地 helper，但目标文件应能被 `SourceFileLoader` 直接加载。
8. 可以在目标目录放公共 helper 文件，但若只实现一道题，优先保持目标文件自包含，减少额外依赖。
9. `main(grid)` 必须带一段 docstring，按 `ARC_code` 参考题的格式分四部分书写：首行用一句话概述转换目标；随后 `Input structure:` 描述输入网格中的对象/背景/标记/边界/组件；`Rule:` 给出从输入到输出的确定性变换规则；`Key insight:` 点明解题核心洞见。该 docstring 供下游相似度/索引流程（按 `main` 的 docstring 抽取机制标签）使用，缺失会导致此题无法被收录为参考题。
