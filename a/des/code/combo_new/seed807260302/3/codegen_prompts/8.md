- `description`：根据每个彩色对象所接触的边界墙颜色，从网格角落的颜色-形状图例中查找对应的小型印章图案，然后将该印章盖印在对象的质心位置。

- `Input structure`：
  - 背景为 black，网格大小约 18x18 到 25x25。
  - 网格中央区域有若干独立的 4-连通单色对象（如 red 的矩形、blue 的 L 形等），每个对象至少 4 个像素。
  - 这些对象被若干一像素厚的彩色直线墙分隔开来。墙的颜色各不相同（如 green、yellow、magenta），每面墙是水平或垂直的直线段。每个对象恰好与一面墙的某一侧 4-邻接接触。
  - 网格的四个角落各放置一个"图例条目"。每个图例条目由一个 1x1 的颜色标记像素和一个紧邻其旁的 3x3 小型图案组成。颜色标记的颜色与某面墙的颜色相同，3x3 图案是需要盖印的"印章"。

- `Rule`：
  - 第一步：对每个中央区域的对象，找到它 4-邻接接触的那面墙的颜色 C。
  - 第二步：在四个角落的图例中，找到颜色标记为 C 的图例条目，获取其 3x3 印章图案。
  - 第三步：找到该对象所有像素的视觉中心位置（所有像素行坐标的中间值取整、列坐标的中间值取整）。
  - 第四步：将 3x3 印章图案以该中心位置为图案中心，叠印在对象上方。印章的非 black 像素覆盖原有内容，印章的 black 像素不改变下层内容（即 black 为透明）。
  - 第五步：墙和图例在输出中保持不变。

- `Key insight`：解题者需要发现对象与印章的关联不是通过对象自身的颜色，而是通过对象所接触的墙的颜色间接建立的。这种"邻接关系 → 颜色查找 → 图案印刷"的三步链条是核心推理路径。第一层：发现对象-墙的接触关系决定查找键；第二层：用墙颜色在角落图例中检索印章；第三层：确定印章的放置位置为对象的视觉中心。
</new_puzzle>
