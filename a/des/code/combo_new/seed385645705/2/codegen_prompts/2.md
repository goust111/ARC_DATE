Input structure
- 背景为 black。网格中散布着若干彩色前景对象，每个对象是单色的四连通区域。
- 这些对象可以两两配对：同一对中两个对象的形状互补——即把它们的边界框对齐后，一个对象的前景像素恰好填满另一个对象在同尺寸矩形中的空缺（二者合并恰好构成一个实心矩形），但配对的两个对象颜色不同。
- 每对中两个对象的边界框尺寸相同。网格中对象总数为偶数，恰好能完全配对。

Rule
- 对每一对互补对象，比较二者的前景像素数量，将像素较少的那个对象重新着色为像素较多的那个对象的颜色。
- 将每对中的两个对象沿最短轴向方向平移，使它们的边界框完全重合，从而拼合成一个纯色实心矩形。
- 如果平移路径上有其他对象，则沿另一轴向平移；拼合后的矩形放置在较大碎片（像素更多者）的原始位置。

Key insight
解题者首先需要发现"形状互补"这一配对关系（而非颜色匹配或位置邻近），然后需要发现面积大小决定了颜色继承方向和最终位置——两层规律都需要从样例中独立归纳。
