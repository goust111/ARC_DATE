网格中的连通前景区域各自包含一条隐藏的直线分界，将每个区域沿分界线切分为两个纯色半区后，交换两半的颜色。

Input structure
- 背景为 black。网格中有若干互不接触的彩色前景区域，每个区域恰好使用两种颜色（形成双色连通对象）。
- 每个双色对象内部存在一条沿水平或垂直方向的直线（脊线），使得该直线一侧的所有像素为颜色 A，另一侧的所有像素为颜色 B。脊线本身不是一个可见的分界——两种颜色在脊线处直接相邻。
- 不同对象的双色组合各不相同。

Rule
- 对每个双色对象，找到将其分为纯色 A 区域和纯色 B 区域的那条直线（水平或垂直）。
- 交换两半的颜色：原来颜色 A 的像素改为颜色 B，原来颜色 B 的像素改为颜色 A。
- 所有对象都执行相同的颜色交换操作。背景保持不变。

Key insight
表面上看每个对象只是"颜色互换"，但解题者需要先识别出每个对象内部的直线分界结构——这在某些不规则形状中并不显然，因为对象的外轮廓可能是锯齿形或 L 形的。真正的难点在于确认"沿直线切分后两半各自纯色"这一结构性前提，而非简单的全局颜色替换（因为不同对象使用不同的颜色对，全局替换无法同时满足所有对象）。

1. `main(grid)` 必须实现新题描述中的确定性转换规则，不能只识别 `generate_input()` 的固定模板。
2. `generate_input()` 必须随机生成多样样例，不能固定死。随机维度应覆盖：网格大小、对象数量、位置、颜色、方向、形状参数或关键分支。
3. 生成器必须保证输入满足 `main()` 的隐式假设：对象不重叠、不越界、特殊标记唯一或可区分、匹配关系无歧义、关键分支出现概率相同。
4. 禁止把 ARC 颜色 id 、亮度、拼写等当作人类不可见的数值语义参与排序、大小比较或隐藏映射。颜色变化必须有可见结构线索。注意颜色亮度、拼写等也是不可见信息，若描述中出现违规的颜色id或者亮度，可自行使用少量的固定颜色替代，但注意生成时要在三个以内输入输出网格中对所有变换100%覆盖度。
