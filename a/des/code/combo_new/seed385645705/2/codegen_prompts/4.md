在一个包含多个封闭区域的网格中，根据每个区域边界上"门"（缺口）的数量，用对应数量的同心收缩层填充该区域的内部。

Input structure
- 背景为 black。网格中有一个由 blue 像素绘制的连通边界结构，将网格划分为若干封闭区域（类似房间）。
- 每个封闭区域的边界上有 1 到 4 个"门"——即边界线上宽度恰好为 1 像素的缺口（black 像素打断了 blue 边界）。
- 每个封闭区域内部初始全为 black。
- 网格外围有一个颜色图例：4 个小色块从左到右排列，分别为 red、green、yellow、orange，对应数字 1、2、3、4。

Rule
- 对每个封闭区域，数出其边界上的门（缺口）数量 n（n 从 1 到 4）。
- 从颜色图例中查找 n 对应的颜色 c。
- 从该区域的边界向内逐层收缩：第 1 层（紧贴边界内侧的像素）填充颜色 c，第 2 层继续向内收缩填充 c，直到填满 n 层为止。若区域太小不足 n 层，则填满所有可用层。
- 收缩层之内若仍有空间，保持 black 不变。边界结构保持 blue 不变。

Key insight
解题者需要完成三层推理：（1）识别边界上的缺口即为"门"；（2）发现门的数量通过图例映射到填充颜色；（3）发现门的数量同时还决定了填充的层数——同一个计数值同时控制颜色和几何深度，这种双重绑定是机制的核心隐蔽性所在。
