将网格中多色对象拆分为单色层，按面积从大到小排序后重新排列为由内到外的同心轮廓环。

Input structure：
- 网格背景为黑色。
- 网格中央有一个紧凑的多色对象，由 2 至 4 种不同的前景颜色组成。对象整体 4-连通。
- 对象中每种颜色的像素各自构成一个 4-连通区域，各色层的像素面积互不相同。

Rule：
- 确定多色对象的几何中心位置（取对象边界框的中心像素）。
- 将对象拆分为若干单色层，按每层的像素面积从大到小排序。
- 清除原始对象，从中心开始重建：面积最大的颜色填充为中心的一个实心小矩形，该矩形的边长等于该层像素面积的平方根向下取整（面积较小时可以为 1×面积 的横条）。若面积为完全平方数则绘制正方形，否则绘制面积相同的最接近正方形的矩形（宽 ≥ 高，宽 × 高 = 面积）。
- 面积第二大的颜色绘制为紧贴第一层外部的一圈宽度为 1 像素的轮廓环，仅填充与内层正交相邻且当前为背景的像素。
- 面积第三大的颜色绘制为紧贴第二层外部的一圈轮廓环，以此类推。
- 输出为以中心为核心、各色层由内到外排列的同心嵌套结构。

Key insight：
- 第一层推理：发现原始对象的空间布局被完全抛弃，颜色被重新组织为同心结构。第二层推理：发现颜色在同心结构中从内到外的排列顺序由其原始面积从大到小决定——面积最大的颜色占据核心，面积最小的颜色位于最外圈。
