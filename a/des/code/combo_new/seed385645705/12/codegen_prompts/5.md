  - 三个面板中的对象形状各异，但每个面板内三个对象的面积（像素数）互不相同。

- `Rule`：
  - 在每个面板内，将三个对象按面积从小到大排列，排名为 1（最小）、2（中等）、3（最大）。
  - 从左面板取排名第 1（最小）的对象，从中面板取排名第 2（中等）的对象，从右面板取排名第 3（最大）的对象。
  - 在一个新的单面板大小的黑色画布上，将这三个被选中的对象按其在各自面板内的原始相对位置放置。
  - 如果放置位置有重叠，后放的对象（右面板的对象最后放置）覆盖先放的。

- `Key insight`：面板序号（1、2、3）与面积排名（从小到大 1、2、3）形成对应关系——左面板选最小、中面板选中等、右面板选最大。解题者不仅需要发现跨面板选择的机制，还需要归纳出选择依据是面积排名与面板位置的匹配，而非简单的空间位置选择。

3. 生成器必须保证输入满足 `main()` 的隐式假设：对象不重叠、不越界、特殊标记唯一或可区分、匹配关系无歧义、关键分支出现概率相同。
4. 禁止把 ARC 颜色 id 、亮度、拼写等当作人类不可见的数值语义参与排序、大小比较或隐藏映射。颜色变化必须有可见结构线索。注意颜色亮度、拼写等也是不可见信息，若描述中出现违规的颜色id或者亮度，可自行使用少量的固定颜色替代，但注意生成时要在三个以内输入输出网格中对所有变换100%覆盖度。
