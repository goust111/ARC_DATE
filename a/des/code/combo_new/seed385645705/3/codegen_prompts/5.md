  - 网格正中央有一条由 yellow 像素绘制的单像素宽直线（垂直线或水平线），将网格分为左右两半或上下两半。该线即为镜像轴。
  - 镜像轴两侧各有若干彩色对象（4-连通实心块），它们关于镜像轴近似对称：大部分像素关于轴有镜像对应，但少量像素存在差异（一侧有而另一侧缺失，或颜色不一致）。
  - 镜像轴一侧的非背景像素总数严格多于另一侧。像素更多的一侧为"基准侧"，另一侧为"残缺侧"。

- `Rule`：
  - 第一步：通过比较两侧非背景像素总数，确定基准侧和残缺侧。
  - 第二步：将基准侧的所有像素镜像投射到残缺侧。对于残缺侧原本为背景但基准侧对应位置有前景的像素，用基准侧的颜色填入（修补缺失）。
  - 第三步：对于残缺侧原本存在前景像素但基准侧对应位置为背景的位置，将该像素重染为 maroon（标记为"错误位置"）。对于残缺侧原有颜色与基准侧不同的位置，同样将残缺侧该像素重染为 maroon。
  - 镜像轴本身（yellow 线）保持不变。基准侧保持不变。

- `Key insight`：解题者需要先发现 yellow 线是对称轴，再通过像素计数判断哪侧是基准侧（这需要主动比较而非直接可见），最后理解修补与错误标记是同时进行的两个操作——仅修补是不够的，差异像素的 maroon 标记是规则的隐藏第二层。

1. `main(grid)` 必须实现新题描述中的确定性转换规则，不能只识别 `generate_input()` 的固定模板。

3. 生成器必须保证输入满足 `main()` 的隐式假设：对象不重叠、不越界、特殊标记唯一或可区分、匹配关系无歧义、关键分支出现概率相同。
4. 禁止把 ARC 颜色 id 、亮度、拼写等当作人类不可见的数值语义参与排序、大小比较或隐藏映射。颜色变化必须有可见结构线索。注意颜色亮度、拼写等也是不可见信息，若描述中出现违规的颜色id或者亮度，可自行使用少量的固定颜色替代，但注意生成时要在三个以内输入输出网格中对所有变换100%覆盖度。
