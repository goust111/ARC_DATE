- `description`：每个彩色矩形根据其可见邻居数量，从标记点出发向外生长出对应数量的触角线段。

- `Input structure`：
  - 背景为 black。
  - 网格中有若干互不重叠的单色实心矩形区域（颜色各异，如 red、blue、green、orange 等），矩形之间至少间隔 2 个像素。
  - 每个矩形的某一条边（上、下、左或右）上恰好有一个 azure 像素标记，该标记替换了该边上的一个原色像素。azure 标记所在的边称为该矩形的"生长边"。

- `Rule`：
  - 第一步：对每个矩形，计算它的"可见邻居"数量 N。可见邻居定义为：从该矩形的某条边沿垂直于该边的方向直线看去，能直接看到另一个矩形的边（两者之间无第三个矩形阻挡），且两个矩形在平行于视线方向的坐标轴上有行或列重叠。
  - 第二步：从该矩形的 azure 标记位置出发，沿生长边的外法线方向绘制 N 条平行线段。每条线段长度为 3 个像素，颜色与矩形原色相同。若 N 条线段需要沿生长边分布，则以 azure 标记为中心，向两侧对称排列，相邻线段间隔 1 个像素。若生长边长度不足以容纳所有线段，则从 azure 标记开始向边的两端交替放置。
  - 第三步：azure 标记像素恢复为矩形原色。

- `Key insight`：解题者需要先推断"可见邻接"这一非平凡的空间关系（不是简单的 4-邻接或距离最近，而是"沿轴向视线可达且有行列重叠"），再将邻居计数转化为触角数量的几何输出，两层推理相互独立且都需要从样例中归纳。
