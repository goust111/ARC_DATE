将网格中的每个 U 形容器旋转到开口朝上，再根据容器内部标记点的数量从顶部刻度条中选色填充容器内部。

Input structure
- 背景为最常见颜色。
- 网格中有若干由同一颜色（如 grey）绘制的 U 形容器对象，每个容器是一个三面封闭、一面开口的矩形槽（宽 3 至 5 像素，深 3 至 5 像素），开口方向可以朝上、下、左或右。
- 每个容器内部散落着若干单像素的 maroon 标记点（数量 1 到 4 不等）。
- 网格顶部有一个水平颜色刻度条：从左到右排列 4 个不同颜色的色块，分别对应标记数量 1、2、3、4。

Rule
- 对每个容器，首先确定其开口方向，然后将整个容器（含内部标记点）旋转，使开口统一朝上。
- 计算该容器内部 maroon 标记点的数量 N。
- 从顶部刻度条中取第 N 个颜色（从左数第 N 个色块）。
- 用该颜色填充容器旋转后的全部内部空白区域（覆盖标记点和原有背景区域），容器的 grey 边框保持不变。
- 刻度条保持不变。

Key insight
解题需要三层推理：第一层识别容器的开口方向并确定旋转量，第二层计数容器内部标记点，第三层通过计数结果查阅刻度条选取填充色。每一层都需要独立归纳——方向识别不能替代计数，计数不能替代查表。
