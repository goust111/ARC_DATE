沿每条 grey 路径从信号源端点传播颜色，路径交叉点处按照网格边缘的图层顺序图例决定最终颜色。

Input structure
- 背景为 black。
- 网格中有若干条由 grey 像素组成的一像素宽路径（4-连通），路径之间可以有交叉（即某些 grey 像素同时属于两条路径的交汇处）。
- 每条路径的一个端点被涂成了独特的非 grey、非 black 颜色（如 red、blue、green 等），该端点即为该路径的"信号源"。
- 在网格的左侧边缘，有一列由小色块从上到下排列的图层顺序图例，排列了所有出现的信号源颜色，从上到下表示优先级从高到低。

Rule
- 从每条路径的信号源端点开始，沿着 grey 路径像素传播信号源颜色，将路径上的所有 grey 像素替换为该信号源颜色。
- 当两条路径在交叉像素处相遇时，该像素的最终颜色由图层顺序图例决定：优先级更高（在图例中位置更靠上）的颜色覆盖优先级更低的颜色。
- 信号源端点像素本身保持原色不变。
- 不属于任何路径的背景像素保持 black。

Key insight
单独的路径着色很直观，但交叉点的颜色冲突需要参考图层图例来裁决。解题者必须先追踪每条路径的归属（哪个信号源能到达哪些像素），再在冲突像素处查阅优先级图例——路径追踪和优先级查表构成两层独立推理。
</new_puzzle>
