网格中的彩色种子像素在各自所属的封闭区域内生长扩散，生长层数由种子所在区域的其他种子数量决定，多个种子的生长区域重叠时保留后生长的颜色。

Input structure:
- 背景为黑色。
- 网格中有若干个由灰色像素构成的不规则封闭区域（每个区域是一个 4-连通的灰色连通分量），各区域之间互不接触，被黑色背景分隔。
- 每个灰色区域内部散布着若干个彩色单像素"种子"，每个种子颜色可能相同或不同，种子位置处的像素为彩色（非灰色、非黑色）。每个区域内至少有一个种子，且不同区域内的种子数量可能不同。

Rule:
- 第一步（计算生长层数）：对于每个灰色区域，数出其内部种子的数量 N。该区域内每个种子将向外扩散 N 层（即 N 次 4-邻域膨胀）。
- 第二步（逐层生长）：每个种子从自身位置开始，逐层向 4-邻域扩散。每一层扩散时，只能覆盖同一灰色区域内的灰色像素（不能越过区域边界进入黑色背景，也不能覆盖其他区域）。扩散最多进行 N 层后停止，即使仍有可达的灰色像素也不再继续。
- 第三步（重叠处理）：所有种子同时逐层生长。当同一层中两个不同种子要覆盖同一个灰色像素时，该像素保持灰色不变（双方抵消）。若某像素在第 k 层被唯一一个种子覆盖，则该像素变为该种子的颜色。
- 区域内未被任何种子扩散到的灰色像素保持灰色。黑色背景保持不变。种子自身像素保持原色。

Key insight:
解题者需要发现三层嵌套规则：首先识别出灰色区域是独立的生长容器；然后发现每个区域内种子的生长层数等于该区域内种子的总数（这是核心隐蔽规则——种子越多的区域反而每个种子扩散得越远）；最后发现同层冲突时的抵消规则而非简单覆盖。数种子数量是肉眼可做的小规模计数，但将"种子数量"与"生长层数"联系起来需要跨样例比较才能归纳。
