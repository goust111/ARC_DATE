信号塔向四方发射同色射线直到被阻挡，射线交汇处的接收器取经过它的所有射线中最稀有的颜色。

Input structure:
- 背景为黑色。
- 网格中散布着若干个由不同颜色构成的 3x3 实心正方形"信号塔"（每座塔为单一颜色，不同塔颜色可能相同也可能不同），塔与塔之间互不相邻。
- 网格中还有若干个灰色单像素点作为"接收器"，接收器不与任何信号塔相邻。
- 所有信号塔和接收器均不紧贴网格边缘（与边缘至少有一个像素的间距）。

Rule:
- 第一步（发射射线）：每座信号塔从其四条边的中心像素（即上边中点、下边中点、左边中点、右边中点）各向外发射一条同色射线。射线沿直线（上/下/左/右）逐像素延伸，遇到另一座信号塔的任意像素或网格边缘时停止（射线不覆盖塔像素本身，也不超出网格）。射线会经过接收器所在位置但不在此停止。
- 第二步（收集射线）：对每个接收器，收集所有经过它所在像素的射线，记录每条射线的颜色。同一颜色可能有多条射线经过（来自不同的塔）。
- 第三步（确定接收器颜色）：统计经过该接收器的各颜色的射线条数。将接收器的灰色替换为射线条数最少的那种颜色。若存在多种颜色射线条数并列最少，则在这些并列颜色中，选取射线源信号塔距该接收器最近的那种颜色（此处距离指塔边缘到接收器之间沿射线方向的像素间隔数）。
- 射线绘制在输出中（覆盖原本的黑色背景像素），信号塔保持不变。

Key insight:
第一层推理是发现信号塔四向发射同色射线的机制（通过输出中出现的彩色直线可以观察到），第二层是发现接收器颜色取的是经过它的所有射线中出现次数最少的颜色——这个"少数派获胜"规则与直觉中"多数决定"相反，构成核心隐蔽性。平局打破规则（取更近的源塔）则是第三层微妙的推理。

1. `main(grid)` 必须实现新题描述中的确定性转换规则，不能只识别 `generate_input()` 的固定模板。

3. 生成器必须保证输入满足 `main()` 的隐式假设：对象不重叠、不越界、特殊标记唯一或可区分、匹配关系无歧义、关键分支出现概率相同。
4. 禁止把 ARC 颜色 id 、亮度、拼写等当作人类不可见的数值语义参与排序、大小比较或隐藏映射。颜色变化必须有可见结构线索。注意颜色亮度、拼写等也是不可见信息，若描述中出现违规的颜色id或者亮度，可自行使用少量的固定颜色替代，但注意生成时要在三个以内输入输出网格中对所有变换100%覆盖度。

7. 代码风格参考 `ARC_code`：使用 `numpy`，必要时使用本地 helper，但目标文件应能被 `SourceFileLoader` 直接加载。
8. 可以在目标目录放公共 helper 文件，但若只实现一道题，优先保持目标文件自包含，减少额外依赖。
9. `main(grid)` 必须带一段 docstring，按 `ARC_code` 参考题的格式分四部分书写：首行用一句话概述转换目标；随后 `Input structure:` 描述输入网格中的对象/背景/标记/边界/组件；`Rule:` 给出从输入到输出的确定性变换规则；`Key insight:` 点明解题核心洞见。该 docstring 供下游相似度/索引流程（按 `main` 的 docstring 抽取机制标签）使用，缺失会导致此题无法被收录为参考题。
