将散落的彩色碎片按形状匹配填入带缺口的框架中，并根据框架边框颜色对碎片重新着色。

Input structure:
- 背景为黑色。网格中包含若干个由同一种颜色（如 grey）绘制的矩形框架，每个框架的边框完整但内部有一个不规则缺口（缺口区域为背景色）。
- 网格中还散布着若干个由不同颜色绘制的小型不规则形状碎片，每个碎片的形状恰好与某个框架内部的缺口形状完全吻合（平移后重合，无需旋转）。
- 每个框架的四条边中恰好有一条边的颜色与其余三条不同，该特殊边的颜色即为"目标色"。

Rule:
- 对每个框架，在所有散落碎片中找到形状与其内部缺口完全匹配的那一块。
- 将该碎片平移到框架缺口位置，填入缺口。
- 填入后，将碎片的颜色替换为该框架特殊边的颜色（目标色）。
- 框架本身保持不变，未被匹配的碎片不会出现在输出中。

Key insight:
- 第一层推理：通过形状匹配将碎片与框架配对；第二层推理：框架四边中颜色不同的那一条边决定了碎片填入后的最终颜色，而非碎片原本的颜色。
