- `Input structure`：
  - 背景为最常见颜色（如 black）。
  - 网格中散布着若干互不相邻的单色连通对象（四连通），每个对象由某种非背景色构成。
  - 每个对象内部有若干像素被替换为另一种统一的特殊颜色（如 yellow），这些像素称为"染色体像素"。染色体像素在对象内部排成一条水平线段或一条垂直线段（不会同时有水平和垂直方向的染色体像素）。
  - 每个对象中染色体像素的数量为 1 到 4 之间。

- `Rule`：
  - 对每个对象，数出其内部的染色体像素数量 n，并确定这些染色体像素的排列方向（水平或垂直）。
  - 将对象（含染色体像素位置）复制 n 次，副本沿染色体的排列方向依次排列：若染色体为水平方向，则 n 个副本从左到右水平排列，相邻副本之间间隔一列背景色；若染色体为垂直方向，则 n 个副本从上到下垂直排列，相邻副本之间间隔一行背景色。
  - 第一个副本的位置与原始对象的位置相同。
  - 所有副本中的染色体像素被还原为对象本体颜色（即输出中不再有染色体颜色）。
  - 原始对象位置的像素被第一个副本覆盖（位置重合）。

- `Key insight`：染色体像素同时编码了两个独立信息——数量决定复制次数，排列方向决定副本的排列方向。解题者需要先发现对象内部的特殊颜色像素并非噪声而是控制指令，再分别解读其数量和空间排列两个维度的含义。

## 实现要求

1. `main(grid)` 必须实现新题描述中的确定性转换规则，不能只识别 `generate_input()` 的固定模板。
2. `generate_input()` 必须随机生成多样样例，不能固定死。随机维度应覆盖：网格大小、对象数量、位置、颜色、方向、形状参数或关键分支。
3. 生成器必须保证输入满足 `main()` 的隐式假设：对象不重叠、不越界、特殊标记唯一或可区分、匹配关系无歧义、关键分支出现概率相同。
4. 禁止把 ARC 颜色 id 、亮度、拼写等当作人类不可见的数值语义参与排序、大小比较或隐藏映射。颜色变化必须有可见结构线索。注意颜色亮度、拼写等也是不可见信息，若描述中出现违规的颜色id或者亮度，可自行使用少量的固定颜色替代，但注意生成时要在三个以内输入输出网格中对所有变换100%覆盖度。
5. 输出样例要视觉清晰：避免对象粘连、覆盖关系混乱、同一像素多重语义、过密导致规则不可读。
6. 若规则有多个分支，生成器不能长期固定成一个分支；应让分支在随机样例中合理出现，即每个分支出现的概率平均，所谓的分支是在描述中提到的分支，即规则语义中的不同情况。
