根据箭头指向选择源图案的某一行或某一列，将其复制到箭头所在的空白条中并沿箭头方向对齐。

Input structure：
- 背景为 black。网格中有一个矩形"源图案"区域，由多种颜色填充，形成一个小型彩色图案（例如 5×5 的图案块）。
- 网格中另有若干 grey 条带（一像素宽的水平或垂直直线段），每根条带的一端有一个彩色箭头标记。箭头由 3 个同色像素组成尖头形状：一个顶点像素加两个对角像素（形成 "V" 形），箭头的尖端指向条带的延伸方向。
- 箭头的颜色是源图案中出现的某种颜色。
- 水平条带的长度等于源图案的宽度；垂直条带的长度等于源图案的高度。

Rule：
- 对每根 grey 条带及其箭头标记：
  - 若条带为水平方向：在源图案中找到箭头颜色出现次数最多的那一行，将该行的像素序列复制到条带上，替换 grey 像素。
  - 若条带为垂直方向：在源图案中找到箭头颜色出现次数最多的那一列，将该列的像素序列复制到条带上，替换 grey 像素。
  - 复制时保持像素的相对顺序（水平条带保持左到右，垂直条带保持上到下）。
- 箭头标记在输出中被清除为 black。
- 源图案本身保持不变。

Key insight：
- 箭头颜色不是用于给条带上色的，而是作为索引键在源图案中选择特定的行或列。解题者需要先发现箭头颜色与源图案的行/列选择之间的关系（最多出现次数），再将选中的行列内容复制到条带上。颜色的角色从"外观属性"变为"查找键"是核心认知跳跃。
