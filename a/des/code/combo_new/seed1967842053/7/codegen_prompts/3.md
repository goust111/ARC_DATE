用连通管道网络中的阀门颜色对管道分段染色，阀门自身变为背景色。

Input structure
- 背景色网格上有一个由 grey 像素构成的单像素宽正交管道网络（类似迷宫走廊），管道上有若干 T 形或十字形交叉节点。
- 管道上散布着若干"阀门"：每个阀门是一个跨越管道的 1x1 彩色像素（非 grey、非背景色），将管道在该处切断为两段。阀门的颜色各不相同。
- 管道网络的某些末端（死胡同）带有一个与某阀门同色的 1x1 标记像素，位于管道末端外侧紧邻的背景格上。

Rule
- 每个阀门将管道局部切成两半；对于每个阀门，从该阀门位置出发沿管道向两侧做洪水填充（不穿越其他阀门），得到阀门两侧各自的管道连通段。
- 检查每段管道的所有死胡同末端：如果某段管道的某个末端外侧带有与该阀门同色的标记像素，则该段管道被染成该阀门的颜色。
- 阀门像素本身变为背景色（阀门被"打开"消失）。
- 末端标记像素保持不变。
- 如果某段管道不属于任何阀门的标记段，则保持 grey 不变。

Key insight
阀门同时承担两个角色——切割管道的分界点和染色的候选色源——但染色方向由末端标记决定，而非简单地"两侧都染"。解题者需要先理解阀门的切割功能，再通过末端标记匹配判断每段管道应该继承哪个阀门的颜色。
