- `Input structure`：
  - 背景色（black）占据大部分网格。
  - 一种前景色（grey）构成一像素宽的墙壁线段，这些墙壁将网格划分为若干封闭的背景区域。
  - 部分封闭区域内恰好包含一个彩色种子像素（非背景色、非墙壁色），每个种子颜色互不相同。
  - 其余封闭区域内没有种子像素（空区域）。

- `Rule`：
  - 背景像素和种子像素保持不变。
  - 对于每一段灰色墙壁线段（4-连通的一像素宽直线段，水平或垂直），检查其两侧相邻的封闭区域。
  - 如果墙壁线段的两侧区域中恰好只有一侧包含种子像素，则将该墙壁线段重新着色为该种子的颜色。
  - 如果墙壁线段的两侧区域都包含种子像素（颜色不同），则墙壁保持原色（grey）不变。
  - 如果墙壁线段的两侧区域都不包含种子像素，则墙壁也保持原色不变。

- `Key insight`：墙壁的颜色不是由距离决定的，而是由"争夺"关系决定的——只有当墙壁一侧有颜色、另一侧为空时，颜色才能"渗透"到墙壁上；两种颜色同时争夺的墙壁保持中立。解题者需要先识别封闭区域及其种子归属，再判断每段墙壁的两侧归属情况。

1. `main(grid)` 必须实现新题描述中的确定性转换规则，不能只识别 `generate_input()` 的固定模板。
2. `generate_input()` 必须随机生成多样样例，不能固定死。随机维度应覆盖：网格大小、对象数量、位置、颜色、方向、形状参数或关键分支。
3. 生成器必须保证输入满足 `main()` 的隐式假设：对象不重叠、不越界、特殊标记唯一或可区分、匹配关系无歧义、关键分支出现概率相同。
4. 禁止把 ARC 颜色 id 、亮度、拼写等当作人类不可见的数值语义参与排序、大小比较或隐藏映射。颜色变化必须有可见结构线索。注意颜色亮度、拼写等也是不可见信息，若描述中出现违规的颜色id或者亮度，可自行使用少量的固定颜色替代，但注意生成时要在三个以内输入输出网格中对所有变换100%覆盖度。
