- `Input structure`：
  - 背景为灰色（grey）。
  - 网格中有若干矩形容器，每个容器由一种颜色的单像素宽边框围成，内部填充着由黑色（black）和 azure 像素组成的二值图案。不同容器的边框颜色各不相同。
  - 每个容器附近有一个同色的 L 形箭头指示物：由一条水平臂和相连的一条垂直短杠（1 像素）组成，短杠位于水平臂的一端。短杠在臂的上方表示方向"向上"，在下方表示"向下"，在左端表示"向左"，在右端表示"向右"。水平臂的像素数量即为臂长。
  - 箭头的颜色与且仅与一个容器的边框颜色匹配。

- `Rule`：
  - 对每个容器，找到与其边框同色的箭头。
  - 读取箭头指示的方向 D 和臂长 L。
  - 将容器内部的图案沿方向 D 循环滚动 L 步：图案像素沿 D 方向平移 L 格，超出容器内部边界的部分从对面重新进入。
  - 箭头指示物在输出中保留不变，容器边框不变。

- `Key insight`：
  - 箭头同时编码了三种信息：颜色决定作用对象、短杠位置决定滚动方向、臂长决定滚动步数。解题者需要先破译箭头的三重编码机制，再将其应用于对应容器的图案变换——箭头解码和图案滚动构成两层推理。
