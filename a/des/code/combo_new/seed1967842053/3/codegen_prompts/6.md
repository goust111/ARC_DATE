- `Input structure`：
  - 背景为黑色（black）。
  - 网格左侧有一个"优先级塔"：由若干不同颜色的单行色块从上到下堆叠而成，形成一个垂直的颜色序列（最上面的颜色优先级最高，依次递减）。
  - 网格右侧有若干水平的多色条纹带，每条条纹带占据一行，由左到右排列着若干长度不等的连续色段。每条条纹带中恰好有一个色段的颜色出现在优先级塔中（称为"主键色段"），其余色段颜色不在塔中出现。
  - 各条纹带之间用一行黑色背景分隔。

- `Rule`：
  - 找到每条条纹带中的主键色段及其颜色。
  - 根据优先级塔中该颜色的位置（从上到下的排名），对所有条纹带重新排列：优先级最高的颜色对应的条纹带排在最上面。
  - 在重新排列的同时，检查每条条纹带的主键色段长度：若长度为奇数则保持条纹带原始的左右顺序，若长度为偶数则将整条条纹带左右镜像翻转。
  - 输出中条纹带之间仍保留一行黑色分隔。

- `Key insight`：
  - 优先级塔提供了行间排序的依据，但解题者还需要发现第二层规则：主键色段的长度奇偶性控制着条纹带内部是否镜像翻转。排序层和镜像层各自需要独立归纳，且镜像条件隐藏在色段长度中而非颜色本身中，增加了隐蔽性。

1. `main(grid)` 必须实现新题描述中的确定性转换规则，不能只识别 `generate_input()` 的固定模板。
2. `generate_input()` 必须随机生成多样样例，不能固定死。随机维度应覆盖：网格大小、对象数量、位置、颜色、方向、形状参数或关键分支。
3. 生成器必须保证输入满足 `main()` 的隐式假设：对象不重叠、不越界、特殊标记唯一或可区分、匹配关系无歧义、关键分支出现概率相同。
4. 禁止把 ARC 颜色 id 、亮度、拼写等当作人类不可见的数值语义参与排序、大小比较或隐藏映射。颜色变化必须有可见结构线索。注意颜色亮度、拼写等也是不可见信息，若描述中出现违规的颜色id或者亮度，可自行使用少量的固定颜色替代，但注意生成时要在三个以内输入输出网格中对所有变换100%覆盖度。
