- `Input structure`：
  - 背景为黑色（black）。
  - 网格上半部分是图例区：包含若干水平排列的小方块，每个小方块由特定颜色的实心正方形组成，正方形内挖有 0、1、2 或 3 个单像素的黑色孔洞。每个小方块展示了"该颜色对应孔洞数为 K"的映射关系（颜色各不相同）。
  - 网格下半部分散布着若干用橙色（orange）像素绘制的 4-连通封闭图形，每个图形的内部（被橙色完全包围的黑色区域）包含 0 至 3 个不等的单像素孔洞。

- `Rule`：
  - 统计下半部分每个橙色图形内部的孔洞数量 K。
  - 从图例区查找孔洞数为 K 对应的连线颜色 C。
  - 将所有孔洞数相同的图形用颜色 C 的折线首尾相连：连线连接每对同组图形中心点之间最近的边界像素对，走先水平后垂直的 L 形折线。

- `Key insight`：
  - 图例区的小方块既是颜色样本又是孔洞计数的视觉编码——解题者需要先"数图例中的孔洞来解码映射表"，再"数下方图形中的孔洞来分类对象"，最后用映射表给出的颜色来绘制连线。核心难点在于发现图例中的孔洞数量本身就是分类键。
