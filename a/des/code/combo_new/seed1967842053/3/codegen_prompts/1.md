- `description`：根据彩色种子像素在封闭围栏内"生长"出同心矩形环，生长层数由围栏外部同色标记像素的数量决定。

- `Input structure`：
  - 背景为黑色（black）。
  - 网格中有若干用不同颜色绘制的一像素宽封闭矩形围栏（hollow rectangular frames），每个围栏颜色各不相同。
  - 每个围栏的正内部（interior）恰好有一个与围栏颜色不同的单像素"种子"，种子颜色在整个网格中唯一对应该围栏。
  - 在围栏外部、远离所有围栏的区域，散落着若干与各种子颜色相同的独立标记像素。

- `Rule`：
  - 对每个围栏，找到其内部的种子像素颜色 C，然后统计网格中围栏外部颜色为 C 的标记像素总数 N。
  - 以种子像素为中心，用种子颜色 C 向外逐层绘制同心矩形环，共绘制 N 层。每层环比上一层在四个方向各扩展一个像素。
  - 若生长的环碰到围栏边界，则在该边界处停止（被围栏像素裁剪，不覆盖围栏本身）。
  - 围栏外部的标记像素在输出中被擦除为背景色。

- `Key insight`：
  - 围栏外部散落的标记像素不是装饰，而是"燃料计数器"——其数量决定种子向外扩展的层数。解题者需要先建立"种子颜色与围栏"的配对关系，再将外部同色像素的计数转化为几何生长的步数，形成两层独立的推理。
