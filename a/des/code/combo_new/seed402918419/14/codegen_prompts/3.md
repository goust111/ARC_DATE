- `Input structure`：背景为黑色。每行包含零到多个散落的 green 像素（信号像素）和至多一个由三个相邻像素组成的箭头标记。箭头标记由 red 像素绘制：水平三像素成一排表示向右（红红红），或者竖直排列中间一个红像素与其左右各一个红像素构成"T"字——T 的横杠指向的方向即箭头方向（横杠在红竖线的右侧表示向右，在左侧表示向左）。具体地：箭头形态为一个 red 像素及其同行右侧紧邻的两个 red 像素（指向右）或左侧紧邻的两个 red 像素（指向左）。没有箭头的行保持不变。
- `Rule`：
  1. 对每行，数出该行中 green 信号像素的数量 N。
  2. 识别该行箭头标记的方向 D（向左或向右）。

- `Key insight`：信号像素的"数量"决定生长条的长度，箭头标记决定生长方向和起点——两层信息来源不同但共同决定输出。解题者必须同时归纳出计数规则和方向规则。

1. `main(grid)` 必须实现新题描述中的确定性转换规则，不能只识别 `generate_input()` 的固定模板。

4. 禁止把 ARC 颜色 id 、亮度、拼写等当作人类不可见的数值语义参与排序、大小比较或隐藏映射。颜色变化必须有可见结构线索。注意颜色亮度、拼写等也是不可见信息，若描述中出现违规的颜色id或者亮度，可自行使用少量的固定颜色替代，但注意生成时要在三个以内输入输出网格中对所有变换100%覆盖度。
