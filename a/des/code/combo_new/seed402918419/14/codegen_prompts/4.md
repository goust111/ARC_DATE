- `Input structure`：背景为黑色。Azure 色的完整行和完整列将网格划分为若干等大的矩形区域。每个区域内有一个由某种颜色绘制的环形图案（闭合的单像素宽矩形环或 L 形环等），但其中一些区域的环缺失了一条边或一个角。每个缺失环的区域内还有一个孤立的单像素提示点，其颜色与某个其他区域中完整环的颜色相同。
- `Rule`：
  1. 识别所有区域，将区域分为"完整环区域"（环没有缺口）和"缺失环区域"（环有缺口且含提示像素）。
  2. 对每个缺失环区域，找到提示像素的颜色 C。
  3. 在完整环区域中找到颜色为 C 的那个环，该环的形状就是目标形状。
  4. 将缺失环区域的环补全为与目标环完全相同的形状，补全部分使用提示像素的颜色 C 绘制。
  5. 提示像素本身从输出中移除。分隔线保持不变。
- `Key insight`：提示像素的颜色是跨区域的索引——它指向另一个区域中的完整环作为"模板"。解题者需先通过颜色匹配建立区域间的对应关系，再利用完整模板推断缺失部分的位置和形状。
