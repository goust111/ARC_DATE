在嵌套的同心矩形框中，按照从外到内的层级关系依次传递颜色，每层框的颜色由其直接外层框和一个全局"色环"顺序决定。

Input structure:
- 背景为黑色。
- 网格中有若干组同心矩形框（每组由多个矩形环嵌套而成，矩形环之间有黑色间隔）。
- 每组同心框中，最外层的矩形框有明确的颜色（如红色、蓝色等），内层的矩形框全部为灰色。
- 在网格的某个角落（如左上角），有一个小的水平色条序列作为"色环图例"，由若干不同颜色像素排成一行，定义了颜色的循环顺序。

Rule:
- 读取色环图例中的颜色顺序（如：红、蓝、绿、黄，则颜色按此顺序循环）。
- 对于每组同心框，最外层框的颜色已知。在色环中找到该颜色的位置，然后按色环顺序依次为每一层内部灰色框赋色（第二层取色环中下一个颜色，第三层再取下一个，循环使用）。
- 将每层灰色框重新着色为对应的色环颜色。
- 色环图例本身在输出中保持不变。

Key insight:
解题者需要三层推理：首先识别角落的色条是颜色循环的图例而非装饰；其次发现同心框的层级嵌套关系（从外到内的顺序）；最后将外层框的已知颜色作为色环的起始索引，推导出内层各框应有的颜色。色环的循环特性使得不同起始颜色的框组产生不同的内层配色方案。

## 实现要求

1. `main(grid)` 必须实现新题描述中的确定性转换规则，不能只识别 `generate_input()` 的固定模板。
2. `generate_input()` 必须随机生成多样样例，不能固定死。随机维度应覆盖：网格大小、对象数量、位置、颜色、方向、形状参数或关键分支。
3. 生成器必须保证输入满足 `main()` 的隐式假设：对象不重叠、不越界、特殊标记唯一或可区分、匹配关系无歧义、关键分支出现概率相同。
4. 禁止把 ARC 颜色 id 、亮度、拼写等当作人类不可见的数值语义参与排序、大小比较或隐藏映射。颜色变化必须有可见结构线索。注意颜色亮度、拼写等也是不可见信息，若描述中出现违规的颜色id或者亮度，可自行使用少量的固定颜色替代，但注意生成时要在三个以内输入输出网格中对所有变换100%覆盖度。
