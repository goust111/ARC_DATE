用"信号塔"像素向四个正交方向广播颜色射线，射线遇到"滤色墙"时变色继续传播。

Input structure:
- 背景为黑色。
- 网格中有若干孤立的彩色单像素点，称为"信号塔"。
- 网格中还有若干由两个不同颜色像素组成的正交相邻对（水平或垂直排列的两像素），称为"滤色墙"。滤色墙中靠近信号塔方向的像素颜色称为"输入色"，另一个像素颜色称为"输出色"。

Rule:
- 每个信号塔向上、下、左、右四个方向发射射线，射线颜色初始为信号塔本身的颜色。
- 射线沿直线传播，将沿途的黑色背景像素染为当前射线颜色。
- 当射线碰到滤色墙时：如果射线当前颜色与滤色墙的"输入色"匹配，则射线穿过滤色墙，从另一侧以"输出色"继续传播；如果颜色不匹配，射线在滤色墙前停止。
- 当射线碰到另一个信号塔或网格边界时停止。
- 两条射线交叉时，后到的射线覆盖先到的（按信号塔从上到下、从左到右的顺序处理）。

Key insight:
滤色墙的两像素排列方向和顺序编码了颜色转换的方向性（哪一侧是输入、哪一侧是输出），解题者必须同时推断出射线传播规则和滤色墙的方向性变色机制，形成两层独立的推理。

1. `main(grid)` 必须实现新题描述中的确定性转换规则，不能只识别 `generate_input()` 的固定模板。

3. 生成器必须保证输入满足 `main()` 的隐式假设：对象不重叠、不越界、特殊标记唯一或可区分、匹配关系无歧义、关键分支出现概率相同。
