  2. 提取每个候选拼图块的形状——将其连通彩色像素的相对坐标集合归一化。

  5. 候选拼图块区域从输出中擦除（被背景色覆盖）。大矩形的边框和 Grey 内部填充保持不变。
- `Key insight`：解题的核心在于两步匹配——首先需要将"负空间"（空洞轮廓）转化为"正空间"（形状），然后在候选库中寻找几何一致的匹配。空洞是拼图块的模具，候选块是拼图块本身，匹配后颜色从候选块传递到空洞，实现跨区域的信息传递。隐蔽性在于解题者需要主动意识到"空洞的形状"就是要寻找的对象。

4. 禁止把 ARC 颜色 id 、亮度、拼写等当作人类不可见的数值语义参与排序、大小比较或隐藏映射。颜色变化必须有可见结构线索。注意颜色亮度、拼写等也是不可见信息，若描述中出现违规的颜色id或者亮度，可自行使用少量的固定颜色替代，但注意生成时要在三个以内输入输出网格中对所有变换100%覆盖度。
