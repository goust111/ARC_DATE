- `Input structure`：
  - 背景为 black。
  - 网格中有若干彩色实心小方块（2x2），每个方块颜色各不相同，称为"源色块"。
  - 网格中有若干由 grey 围成的空心小方框（内部为 black，内部尺寸也是 2x2），称为"目标框"。
  - 每个源色块旁边（上下左右四方向之一）紧邻一个由 maroon 像素构成的箭头形状（3 像素的 L 形：一个 1x3 或 3x1 的杆加上垂直于杆末端的 1 像素翼构成，翼所在端为尾部，无翼的另一端为箭头指向的方向）。
  - 在源色块沿箭头方向的路径上，可能存在 0 个或多个"中继站"——中继站是一个 1x1 的彩色像素，颜色与源色块和目标框颜色均不同。
  - 路径末端有一个目标框。

- `Rule`：
  - 对每个源色块，沿其箭头指向的方向直线前进，依次经过中继站直到到达目标框。
  - 源色块经过每个中继站时，色块颜色变为该中继站的颜色（中继站本身在输出中消失，变为 black）。
  - 最终色块以经过所有中继站后的最终颜色填入目标框内部的 2x2 区域。
  - 原始源色块从原位置消失（变为 black）。箭头也消失。
  - 若路径上无中继站，色块以原色填入目标框。

- `Key insight`：箭头确定传送方向和路径配对（哪个源对应哪个目标），而路径上的中继站数量和颜色决定最终着色——解题者必须先解读箭头的方向语义建立路径，再沿路径追踪颜色的链式变换，这两步推理相互独立且都非显然。
