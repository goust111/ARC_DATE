- `description`：在网格中找到被"路径"连接的对象对，根据路径上经过的中继站数量来决定目标对象的最终颜色。

- `Input structure`：
  - 背景色为黑色。
  - 网格中有若干由不同颜色绘制的小型实心矩形对象（3x2或2x3大小）。
  - 网格中有若干灰色的单像素点作为"中继站"。
  - 每两个对象之间恰好有一条由黄色像素组成的一像素宽的正交折线路径（只走水平或垂直方向）连接它们。
  - 每条路径上可能经过0、1或多个灰色中继站（路径像素与中继站像素4-连通相邻）。
  - 每个对象恰好参与一条路径（即对象两两配对）。

- `Rule`：
  - 找出每对被路径连接的对象。
  - 数出连接路径上经过的灰色中继站数量N。
  - 若N为偶数（包括0）：两个对象都保持原色不变。
  - 若N为奇数：两个对象交换颜色（A的颜色变为B的原始颜色，B的颜色变为A的原始颜色）。
  - 路径本身和中继站在输出中保持不变。

- `Key insight`：
  - 路径的连接关系决定了配对，但颜色是否交换取决于路径上中继站数量的奇偶性——解题者既需要追踪路径找到配对关系，又需要判断中继站奇偶来决定操作类型，两层信息缺一不可。

1. `main(grid)` 必须实现新题描述中的确定性转换规则，不能只识别 `generate_input()` 的固定模板。

3. 生成器必须保证输入满足 `main()` 的隐式假设：对象不重叠、不越界、特殊标记唯一或可区分、匹配关系无歧义、关键分支出现概率相同。
4. 禁止把 ARC 颜色 id 、亮度、拼写等当作人类不可见的数值语义参与排序、大小比较或隐藏映射。颜色变化必须有可见结构线索。注意颜色亮度、拼写等也是不可见信息，若描述中出现违规的颜色id或者亮度，可自行使用少量的固定颜色替代，但注意生成时要在三个以内输入输出网格中对所有变换100%覆盖度。
