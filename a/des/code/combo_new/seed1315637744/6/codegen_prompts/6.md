Input structure

- 迷宫中有一个起点标记（白色单像素）和一个终点标记（白色 2×2 方块）。
- 通道中散布着若干"门"——横跨通道的单像素宽彩色线段（例如红色、蓝色、绿色），每扇门完全阻断通道。
- 在起点附近的通道中放置着若干"钥匙"——小型彩色对象（3-5 像素的连通块），每把钥匙的颜色与某扇门的颜色相同。
- 从起点到终点只有一条可行路径（不考虑门的阻挡）。

Rule
- 沿从起点到终点的唯一路径前进。
- 遇到一扇门时，该门被同色钥匙"打开"：门的像素被清除为背景色。
- 钥匙按路径上遇到的顺序依次使用：路径上第一把遇到的钥匙打开路径上第一扇遇到的门（颜色必须匹配，题目保证匹配）。
- 每把钥匙在使用后（打开门后），其形状（像素图案）被"印"在门原来的位置：以门的中心像素为锚点，将钥匙的形状图案居中绘制，颜色改为灰色。
- 起点标记和终点标记在输出中保持不变；未使用的钥匙保持原位。

Key insight
- 表面上这是一个路径寻找题，但真正的推理在于：钥匙不仅仅是"开门"的功能对象，它的几何形状会被转印到门的位置——解题者需要发现"形状转移"这一隐藏机制，而不仅仅是颜色匹配的消除。
