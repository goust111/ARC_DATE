将网格中的彩色像素视为"棋子"，按照它们所在区域的隐含棋盘格奇偶性，将奇格棋子的颜色映射到偶格棋子上。

Input structure
- 网格背景由两种颜色交替排列形成棋盘格图案（如黑色和灰色交替）。
- 棋盘格上散布着若干彩色像素（非黑非灰），每个彩色像素恰好占据一个格子。
- 彩色像素总是成对出现：每种非背景颜色恰好出现两次，一次在"奇格"（黑色背景格）上，一次在"偶格"（灰色背景格）上。

Rule
- 对每一对同色像素，保留位于偶格（灰色背景格）上的那个像素不变。
- 将位于奇格（黑色背景格）上的像素移除（恢复为黑色背景）。
- 然后，对每个保留的偶格像素，在其正上方/下方/左方/右方最近的同为偶格的空位处（即距离最近的灰色背景偶格），绘制一个同色像素副本。
- 棋盘格背景本身保持不变。

Key insight
- 第一层推理是识别出背景的棋盘格结构并理解奇偶格的区分——这决定了哪些像素被保留、哪些被删除；第二层推理是保留像素的"复制扩展"规则遵循偶格跳跃而非简单相邻，解题者需要发现扩展目标也受棋盘格奇偶约束。
