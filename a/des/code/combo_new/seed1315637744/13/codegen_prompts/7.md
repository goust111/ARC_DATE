- `Input structure`：
  - 背景为主色（如 black）。
  - 网格被一条垂直的 grey 分隔线分为左右两半。
  - 左半部分是"模板区"：包含一个由非背景色像素绘成的小型图案（不超过 5×5），图案不对称，使用单一前景色（如 blue）。图案周围有足够的背景色空间。
  - 右半部分是"指令区"：包含一个 3×3 的 grey 像素网格框。框内 9 个格位中，恰好有一个格位放置了一个与模板图案相同颜色的像素（如 blue），其余格位为背景色。

- `Rule`：
  - 3×3 指令框的中心格位代表"不变换"。
  - blue 像素相对于中心的位置决定变换类型：
    - 正上方 → 原样不变（0°旋转）
    - 正右方 → 顺时针旋转 90°
    - 正下方 → 旋转 180°
    - 正左方 → 逆时针旋转 90°（即顺时针 270°）
    - 右上角 → 沿主对角线翻转
    - 左上角 → 水平翻转
    - 左下角 → 沿副对角线翻转
    - 右下角 → 垂直翻转
    - 中心 → 原样不变
  - 将变换后的模板图案绘制在输出网格中（输出尺寸等于变换后图案的最小外接矩形）。

- `Key insight`：
  - 第一层推理：理解右侧 3×3 框是一个"罗盘式"指令编码器，框内像素的位置代表八种空间变换之一。第二层推理：将抽象的位置编码与具体的几何变换（旋转、翻转）对应起来，并正确应用于左侧不对称的模板图案。指令编码本身是空间隐喻——像素在右边意味着"向右旋转"。
</new_puzzle>
