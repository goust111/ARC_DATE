- `Input structure`：
  - 背景为 black。
  - 网格中央区域可见一个复合图形，由三种颜色组成：颜色 A、颜色 B、颜色 C。
  - 该复合图形实际上是两个形状完全相同的一像素宽矩形边框的重叠结果：边框 1 为颜色 A，边框 2 为颜色 B，两者重叠的像素显示为颜色 C。
  - 在网格的上方有一行"方向提示"：一个颜色 A 的 1x1 像素后面紧跟一个由颜色 A 的 3 像素水平或垂直线段构成的箭头（末端有一个像素偏移表示方向——向左、向右、向上或向下）；同行另一侧有颜色 B 的类似箭头，方向与颜色 A 的箭头恰好相反。

- `Rule`：
  - 第一步：识别重叠结构——颜色 C 的像素是两个边框共享的位置，由此推断两个边框各自的完整形状（A 的完整边框 = A 像素 + C 像素的位置；B 的完整边框 = B 像素 + C 像素的位置）。
  - 第二步：计算颜色 C 的像素总数 N。
  - 第三步：将边框 1 的所有像素（全部着色为 A）沿方向提示中颜色 A 箭头指示的方向平移 N 个像素；将边框 2 的所有像素（全部着色为 B）沿颜色 B 箭头指示的方向平移 N 个像素。
  - 第四步：在输出网格中绘制两个分离后的完整边框，背景保持 black。方向提示行保持不变。

- `Key insight`：颜色 C 具有双重含义——它既标识了重叠位置（用于还原各边框的完整形状），又通过其像素计数决定了分离距离。解题者需要三层推理：识别重叠合成机制、理解方向提示、发现计数决定位移量。
