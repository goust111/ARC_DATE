- `Input structure`：
  - 背景为 black。
  - 网格中有若干个互不接触的前景图形，每个图形由单一颜色绘制。
  - 每个图形"几乎"具有某种对称性（左右对称、上下对称或 180 度旋转对称），但恰好有一个像素被替换为另一种颜色，破坏了对称性。
  - 被替换的那个像素的颜色与该图形的主体颜色不同，且在整个网格中每个图形的"破缺像素"颜色各不相同。

- `Rule`：
  - 对每个图形，通过观察大部分像素满足的对称关系来检测其对称类型。
  - 找到破坏对称性的那个异色像素。
  - 找到该破缺像素在对称变换下的对应位置：如果对应位置是背景色，则在该位置补上图形主体颜色的像素；如果对应位置已有主体颜色像素，则将破缺像素本身改回主体颜色。
  - 修复完成后，收集每个图形中破缺像素在修复前的颜色，按图形 bounding box 左边界从左到右排序。
  - 输出为单行网格（高度 1），依次排列这些破缺颜色像素，像素间无间隔。

- `Key insight`：每个图形的对称类型不同且未被显式标注，解题者需要先为每个图形独立判断它"想要"哪种对称，然后找到唯一的异色破缺点；最终输出并非修复后的网格，而是提取破缺颜色的序列——这一"信息提取而非图形修复"的输出模式增加了额外的推理层。

## 实现要求

1. `main(grid)` 必须实现新题描述中的确定性转换规则，不能只识别 `generate_input()` 的固定模板。
2. `generate_input()` 必须随机生成多样样例，不能固定死。随机维度应覆盖：网格大小、对象数量、位置、颜色、方向、形状参数或关键分支。
3. 生成器必须保证输入满足 `main()` 的隐式假设：对象不重叠、不越界、特殊标记唯一或可区分、匹配关系无歧义、关键分支出现概率相同。
4. 禁止把 ARC 颜色 id 、亮度、拼写等当作人类不可见的数值语义参与排序、大小比较或隐藏映射。颜色变化必须有可见结构线索。注意颜色亮度、拼写等也是不可见信息，若描述中出现违规的颜色id或者亮度，可自行使用少量的固定颜色替代，但注意生成时要在三个以内输入输出网格中对所有变换100%覆盖度。

6. 若规则有多个分支，生成器不能长期固定成一个分支；应让分支在随机样例中合理出现，即每个分支出现的概率平均，所谓的分支是在描述中提到的分支，即规则语义中的不同情况。
