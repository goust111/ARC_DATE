Input structure
- 背景为黑色。网格上半部分包含若干个由 grey 绘制的一像素厚封闭轮廓（称为"模具"），每个模具围出一个不规则形状的空腔。

Rule
- 将第 k 条条带（从上到下第 k 条）与第 k 个模具（从左到右第 k 个）配对。
- 对每个模具，逐行扫描其内部空腔：对于空腔的每一行，用配对条带的颜色填充该行中属于空腔的像素。

- 原来的条带区域清除为黑色背景。模具轮廓保持不变。

Key insight
解题者需要首先建立条带与模具之间的排序配对规则（纵向顺序对横向顺序），这不是基于颜色或形状的匹配，而是基于空间位置的序数对应——这种"跨维度序数映射"是核心隐蔽机制；第二步才是直观的填充操作。
