在被分隔线划分的四个区域中，每个区域内的彩色对象沿该区域独立的重力方向滑动到边界，重力方向由区域角落的小条形标记编码。

Input structure:
- 背景为 black。网格被一条水平的 grey 分隔线和一条垂直的 grey 分隔线（均贯穿全网格）划分为四个矩形区域（左上、右上、左下、右下）。
- 每个区域的靠近网格外角的角落处有一个由 maroon 色绘制的 2x1 或 1x2 的小条形标记：水平条 (1x2) 位于区域顶部表示重力向上，位于区域底部表示重力向下；垂直条 (2x1) 位于区域左侧表示重力向左，位于区域右侧表示重力向右。每个区域恰好有一个条形标记，四个区域的重力方向两两不同。
- 每个区域内散布着若干彩色的小对象（每个对象为单一颜色的 4-连通区域，颜色不是 black、grey 或 maroon），对象不跨越分隔线。

Rule:
- 对每个区域，读取其角落条形标记以确定该区域的重力方向。
- 将该区域内每个彩色对象沿重力方向整体平移，直到对象的某个像素紧邻区域边界（分隔线或网格边缘）或紧邻另一个已停止的对象为止，对象形状保持不变。
- 移动顺序：沿重力方向最靠前（最接近目标边界）的对象先移动。
- 条形标记自身在输出中被擦除为背景色。
- 分隔线保持不变。

Key insight:
解题的第一层推理是发现四个区域各有独立的重力方向，第二层是识别角落小条形标记的位置和朝向编码了重力方向——条形标记靠近哪个边就代表物体被吸向那个边。两层推理缺一不可：仅观察对象运动可能看出方向，但标记的编码方式需要归纳才能应用于测试。
