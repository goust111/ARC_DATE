在分格棋盘中，每个格子的最终颜色由其所在行的"行模板"和所在列的"列模板"的颜色经优先级图例裁决后共同决定。

Input structure:
- 网格被 grey 色线条均匀分割为 R 行 C 列的格子阵列（每个格子内部为 3x3 的方块）。
- 最左列的格子作为"行模板"：每个格子内部填充了一种颜色（非 black、非 grey），不同行的颜色可能相同或不同。
- 最上行的格子作为"列模板"：每个格子内部填充了一种颜色，不同列的颜色可能相同或不同。
- 左上角的格子（行模板与列模板的交叉处）为空（背景色）。
- 网格右下角区域有一个由 maroon 边框围起的小型"优先级图例"：图例内部将出现的所有颜色纵向排列为单像素列，从上到下表示优先级从高到低。
- 阵列中其余格子（非模板行/列）的内容在输入中为空（背景色），需要在输出中填充。

Rule:
- 对于阵列中第 i 行第 j 列的非模板格子，读取第 i 行行模板的颜色 A 和第 j 列列模板的颜色 B。
- 若 A 等于 B，则该格子填充颜色 A。
- 若 A 不等于 B，则查看优先级图例，优先级更高（在图例中位置更靠上）的颜色胜出，格子填充胜出的颜色。
- 模板行/列本身在输出中保持不变。优先级图例在输出中保持不变。

Key insight:
第一层推理是发现行模板和列模板的交叉决定了每个格子的颜色（类似乘法表结构）；第二层是当行列颜色冲突时，需要发现角落的优先级图例提供了裁决规则——图例中的纵向排列顺序编码了颜色优先级。仅从输出的颜色分布无法直接反推规则，必须同时参考模板和图例。
</new_puzzle>
