将网格中的彩色"信号源"沿其发射方向传播，信号穿过"透镜条"时颜色发生由边缘映射表决定的替换。

Input structure:
- 背景为 black。网格中有若干单像素的"信号源"，每个信号源由一种颜色（如 red、blue、green 等）绘制，且紧邻信号源的上下左右四个方向中恰好有一个方向存在一个 maroon 单像素"方向指示器"，指示器与信号源相邻。
- 网格中还有若干条贯穿整行或整列的"透镜条"，每条透镜条由某种颜色（非 black、非 maroon）的连续像素绘制，宽度为 1 像素。透镜条颜色可能与某些信号源颜色相同，也可能不同。
- 网格边缘有一个 2 行 N 列的小型"颜色映射表"：第一行是若干不同颜色的像素（输入色），第二行是对应位置的另一种颜色（输出色），表示信号穿过该颜色透镜时的颜色变换关系。每种透镜颜色在映射表第一行中出现一次。

Rule:
- 对每个信号源，发射方向为信号源指向远离 maroon 指示器的方向（即指示器在信号源左侧，则信号向右发射）。
- 从信号源出发，沿发射方向逐像素绘制信号线（颜色与当前信号颜色相同），直到碰到网格边缘。
- 当信号线穿过一条透镜条时：查找颜色映射表，找到透镜条颜色所在列，读取第二行的输出色；从透镜条之后开始，信号线的颜色变为该输出色。若之后再穿过另一条透镜条，再次查表变色。
- maroon 指示器在输出中被擦除为背景色。信号线覆盖透镜条像素时，透镜条像素被信号线当前颜色覆盖。

Key insight:
三层推理：(1) 从 maroon 指示器的位置推断信号发射方向（反向逻辑）；(2) 识别边缘的映射表将透镜颜色映射为变换后的颜色；(3) 信号线在穿过不同透镜时会发生多次颜色变换，最终颜色取决于透镜的穿越顺序。方向推断、映射表解读和多次变色三者缺一不可。
