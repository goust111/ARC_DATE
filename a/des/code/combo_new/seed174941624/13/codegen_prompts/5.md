将输入网格中的多个互相遮挡的彩色矩形分离还原，然后按面积从小到大依次水平排列输出。

Input structure:
- 背景为 black。网格中有若干不同颜色的矩形色块，它们在网格上部分重叠，形成类似"窗口叠放"的效果。每个矩形为实心单色，当两个矩形重叠时，"上层"矩形的像素覆盖"下层"矩形的像素。
- 所有矩形颜色互不相同，矩形数量为 2 到 5 个。
- 被遮挡的矩形可能只露出 L 形、U 形或分散的边缘条，但其完整轮廓可以从可见部分推断出来（每个矩形的四条边中至少有两条完整可见的边，从而可以确定完整宽高）。

Rule:
- 首先还原每个矩形的完整尺寸：对于每种颜色，找到该颜色所有可见像素的最小外接矩形，即为该矩形的原始大小。
- 计算每个矩形的面积（宽 x 高）。
- 输出一个新网格：将所有还原后的完整矩形按面积从小到大从左到右水平排列，相邻矩形之间间隔 1 列背景色。输出网格的高度等于最大矩形的高度，每个矩形顶部对齐。

Key insight:
第一层推理是发现输入中的颜色区域实际上是互相遮挡的完整矩形，需要从部分可见的轮廓推断每个矩形的原始尺寸；第二层是发现输出按面积排序并水平排列——排序依据不是颜色或位置，而是还原后的面积。遮挡关系的识别和面积排序的发现构成两层独立的归纳任务。
