Input structure:
- 背景为 black。网格中由 grey 色线条构成若干封闭矩形房间（类似网格状布局，但房间大小不一），房间之间共享墙壁，所有墙壁宽度为 1 像素。
- 每个房间内部可能为空（全部背景色），也可能包含若干同色的非背景、非 grey 像素（散布在房间内部的任意位置），每个含像素的房间只使用一种颜色。

Rule:
- 对每个房间，数其内部彩色像素的个数。

- 原本为空的房间（0 个像素）保持不变。

Key insight:
解题者需要发现两个非显然规律：(1) 房间的命运取决于内部像素数量的奇偶性——奇数扩张、偶数清空；(2) 扩张时不仅填充内部，还会"感染"边框颜色。由于房间大小不一且像素散布位置随机，仅靠视觉面积判断容易误判，必须精确数像素个数。

3. 生成器必须保证输入满足 `main()` 的隐式假设：对象不重叠、不越界、特殊标记唯一或可区分、匹配关系无歧义、关键分支出现概率相同。
