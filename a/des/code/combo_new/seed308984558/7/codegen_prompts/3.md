- `Input structure`：
  - 背景色为 black。
  - 网格最左列是一条垂直的彩色刻度尺：从上到下依次排列着若干不同颜色的单像素色块，每两个色块之间用一个 grey 像素分隔。从上到下的非 grey 像素依次对应索引 1、2、3……
  - 网格其余区域包含若干互不相邻的 4-连通前景对象，每个对象由 red 像素构成，形状各异。
  - 每个 red 对象的高度（其最小包围矩形的行数）各不相同，且高度值不超过刻度尺中非 grey 像素的总数。

- `Rule`：
  - 测量每个 red 对象的高度 H（包围矩形的行数）。
  - 在左侧刻度尺中，从上往下数第 H 个非 grey 像素，读取其颜色。
  - 将该对象所有像素重绘为该颜色。位置和形状不变。
  - 刻度尺本身保持不变。

- `Key insight`：左侧刻度尺不是装饰边框，而是一个"高度→颜色"的查找表。解题者需要先意识到对象高度是关键属性，再发现刻度尺的索引方式（第 H 个非分隔像素），两步归纳合在一起才能确定重绘颜色。
