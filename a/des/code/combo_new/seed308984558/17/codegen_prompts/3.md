- `Input structure`：
  - 背景为黑色（black）。
  - 网格中有若干由不同颜色构成的小型 4-连通对象（"印章"），每个对象占据约 3×3 到 5×5 的区域。每个印章形状不对称，具有一个明确的视觉方向——即形状在某个正交方向上存在一个尖角或突出的单像素突起（类似箭头尖端），该突起方向即为印章的"方向"。具体判定方式：找到该对象外轮廓上唯一一个只有 1 个正交邻居属于该对象的像素，该像素相对于对象质心的方向即为印章方向。
  - 每种颜色除了一个印章对象外，还有零个或多个同色的孤立单像素标记点散布在网格各处。
  - 不同颜色的印章和标记点之间不会空间重叠。

- `Rule`：
  - 对每个印章对象：
    1. 确定其方向 D（上/下/左/右），方法如上述。
    2. 数出网格中与该印章同色的孤立单像素标记点的数量 N。
    3. 沿方向 D，以印章自身的宽度或高度（取决于 D 的方向：水平方向取宽度，垂直方向取高度）为步长，连续复制印章 N 次。即第 k 次副本的位置是原始印章沿 D 平移 k 个步长。
    4. 每个副本与原始印章形状和颜色相同。
  - 复制完成后，擦除所有孤立标记点（变为背景色）。原始印章保留。
  - 若多个副本位置超出网格边界，则不绘制该副本。

- `Key insight`：解题者需要同时发现三个规则：（1）形状的不对称突起编码了方向，（2）同色孤立点的数量编码了复制次数，（3）步长由形状自身的尺寸决定。方向从形状几何中推导、次数从散布的标记点计数获得——两个信息来源完全不同，构成双层推理。
