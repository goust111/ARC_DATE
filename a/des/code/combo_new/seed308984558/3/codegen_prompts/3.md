- `description`：网格中的彩色"种子"像素沿着灰色轨道扩展生长，生长方向由轨道的走向决定，生长长度由种子所在轨道段上的孔洞数量决定。

- `Input structure`：
  - 网格背景为主色（如 black）。
  - 灰色（grey）像素构成若干条互不相连的直线轨道（水平或垂直），每条轨道是一段连续的 grey 像素，但其中可能有若干个背景色的"孔洞"（即轨道像素序列中被背景色中断的位置）。
  - 每条轨道的一个端点处（紧邻轨道末端的外侧一格）有一个彩色种子像素（非 grey、非背景色），颜色各异。

- `Rule`：
  - 对每条轨道，数出该轨道中孔洞的数量 H（即轨道方向上被背景色中断的间隙数，连续的背景像素块算一个孔洞）。
  - 从种子像素出发，沿轨道方向（即从种子朝向轨道延伸的方向），用种子的颜色覆盖轨道上的前 H 个 grey 像素（跳过孔洞，只计 grey 像素）。
  - 如果 H 为零（轨道无孔洞），则不做任何绘制。
  - 种子像素本身保留，轨道中未被覆盖的 grey 像素和孔洞保持不变。

- `Key insight`：孔洞不是障碍物而是计数器——轨道自身的孔洞数量反过来控制种子颜色向轨道中扩展的距离。解题者需要先发现"数孔洞"这一非显然的量化步骤，再理解"孔洞数 = 着色长度"的映射关系。
