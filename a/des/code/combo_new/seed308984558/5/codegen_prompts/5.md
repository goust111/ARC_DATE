- `Rule`：
  1. 找到 red 矩形边框，提取其内部区域（不含边框本身）。
  2. 找到边框上的切割标记（非 red 的像素）。若标记在水平边上，则它们定义垂直切割线；若在垂直边上，则定义水平切割线。切割线将内部区域分成若干条带。
  3. 找到边框外部的排列指令序列。序列中每个像素的颜色对应一个切割标记或边框端点的颜色。从左到右（或从上到下）读取序列中的颜色顺序。
  4. 将条带按照排列指令中的颜色顺序重新排列：指令序列中第 i 个颜色对应的条带放在输出的第 i 个位置。输出仅包含重排后的内部区域，不含边框。
- `Key insight`：边框上的特殊颜色像素不是装饰而是切割指示（第一层推理），边框外部看似无关的颜色序列实际上编码了条带的重排顺序（第二层推理）。解题者需要将"切割"和"重排"两个独立的编码系统联合解读才能得到输出。
