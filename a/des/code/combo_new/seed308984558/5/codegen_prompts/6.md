- `Input structure`：背景为黑色。网格中有若干由 grey 像素围成的封闭矩形区域（grey 作为围墙，单像素宽）。每个封闭区域内部包含：(a) 一些由各种颜色组成的图案像素；(b) 恰好一个由 red 像素组成的箭头形状。箭头形状为一个 3x3 的标准箭头图案——由一个 1x3 或 3x1 的杆加上一个三角形箭头尖端组成，箭头指向上、下、左、右四个方向之一。具体来说，向右的箭头形状为：第 0 行第 2 列、第 1 行第 0-2 列、第 2 行第 2 列各有一个 red 像素（共 5 个像素，形成一个指向右的箭头）。其他方向的箭头以此类推，通过旋转获得。
- `Rule`：
  1. 识别每个 grey 围墙界定的封闭矩形区域。
  2. 在每个区域内找到 red 箭头，判断其指向方向。
  3. 移除 red 箭头像素（变为背景色）。
  4. 将区域内所有剩余的非背景像素视为一个整体，沿箭头指向的方向推挤：每个非背景像素尽可能向箭头方向移动，直到碰到围墙或另一个已停止的像素。像素之间的相对行列顺序在垂直于推挤方向的轴上保持不变。推挤后空出的位置填充背景色。
  5. 围墙本身保持不变。
- `Key insight`：区域内的 red 箭头不是需要保留的图案内容，而是一个"操作指令"，指示该区域内所有其他内容的推挤方向。解题者首先需要识别箭头是指令而非内容（第一层），然后理解推挤规则是像素级的重力模拟而非整体平移（第二层）——即像素会紧密堆叠而非保持原有间距。
