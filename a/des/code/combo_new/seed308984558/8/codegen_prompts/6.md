- `description`：根据每个对象上附着的箭头颜色在色板中查找目标位置，再按箭头方向将对象平移到该目标位置。
- `Input structure`：背景为black。网格分为左右两部分，中间用一列grey像素分隔。左侧为"色板区"：一列彩色像素从上到下排列，每个像素颜色不同，它们的行位置编码了目标行号。右侧为"操作区"：包含若干小的实心彩色矩形对象（如2x3、3x2等），每个对象的某一侧（上/下/左/右）紧邻一个单像素的箭头标记（箭头标记颜色与色板中某个颜色相同，但与对象自身颜色不同）。箭头标记所在的方位指示平移方向（标记在对象上方表示向上移动，在下方表示向下移动，在左侧表示向左移动，在右侧表示向右移动）。
- `Rule`：
  1. 读取左侧色板，记录每种颜色对应的行号。
  2. 对右侧每个对象，找到其附着的箭头标记及其颜色C和方位D。
  3. 在色板中查找颜色C对应的行号R。
  4. 将对象沿方向D平移，直到对象在该方向上的前缘到达行号R（若D为上或下）或对象保持在原列位置不变（若D为左或右则移动至对象的前缘列号等于色板像素的列号，但由于色板在固定列，实际上左右移动是移至紧邻grey分隔线）。具体而言：方向为上时，对象向上移动直到其顶边位于行R；方向为下时，对象向下移动直到其底边位于行R；方向为左时，对象向左移动直到其左边紧邻grey分隔列；方向为右时，对象向右移动直到其右边抵达网格右边缘。
  5. 输出中移除所有箭头标记像素，保留grey分隔列和色板。
- `Key insight`：两层推理——（1）箭头标记的颜色不是装饰而是索引键，用于在色板中查找目标位置；（2）箭头的方位指示移动方向，结合色板查到的行号确定移动终点。解题者必须同时理解颜色索引和方向编码两套机制才能正确预测输出。
