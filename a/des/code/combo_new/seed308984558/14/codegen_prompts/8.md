- `Input structure`：网格是一个无背景的全填充矩形，由交替的彩色像素构成类似棋盘或条纹的周期图案。整个网格遵循一个二维周期模式：每 P 列和每 Q 行颜色重复（P 和 Q 为 2 或 3）。网格中有少量像素（不超过总数的 10%）的颜色偏离了该周期模式，这些是"违规像素"。
- `Rule`：
  1. 推断网格的二维周期模式：确定水平周期 P 和垂直周期 Q，以及周期单元内每个位置 (r mod Q, c mod P) 应有的颜色。周期颜色由该位置上出现最频繁的颜色决定（多数投票）。
  2. 将所有不符合推断周期模式的像素替换为该位置应有的正确颜色。
  3. 输出为修复后的完美周期图案网格，尺寸不变。
- `Key insight`：网格表面看起来是随机的彩色马赛克，但实际暗藏一个二维周期重复模式——解题者需要先发现这个隐藏的周期结构（这需要观察多个样例来确认周期长度），然后识别出偏离模式的"噪声"像素并予以纠正。推理难度在于周期长度本身需要归纳发现，而非直接可见。

3. 生成器必须保证输入满足 `main()` 的隐式假设：对象不重叠、不越界、特殊标记唯一或可区分、匹配关系无歧义、关键分支出现概率相同。
4. 禁止把 ARC 颜色 id 、亮度、拼写等当作人类不可见的数值语义参与排序、大小比较或隐藏映射。颜色变化必须有可见结构线索。注意颜色亮度、拼写等也是不可见信息，若描述中出现违规的颜色id或者亮度，可自行使用少量的固定颜色替代，但注意生成时要在三个以内输入输出网格中对所有变换100%覆盖度。
