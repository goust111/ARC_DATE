- `Input structure`：背景为 black。网格被 grey 的完整行和完整列分隔为若干大小相同的矩形面板（如 3x3 或 4x4 的面板网格布局）。每个面板有一个独特的非 black、非 grey 的纯色填充作为底色。每个面板中央有一个由 black 像素绘制的 3 像素箭头形状，箭头指向上、下、左、右四个方向之一。指向右的箭头为：左侧一个像素位于中心，右侧上下各一个像素构成">"形；指向上的箭头为：底部一个像素位于中心，顶部左右各一个像素构成"^"形；其余方向类推。

- `Rule`：
  - 读取每个面板的底色和箭头朝向。
  - 从每个面板出发，沿箭头所指方向找到相邻面板（跨过分隔线的下一个面板）。
  - 每个面板的输出底色 = 指向它的那个面板的原始底色。即：如果面板 A 的箭头指向面板 B，则面板 B 的新底色变为面板 A 的原始底色。
  - 如果没有任何面板指向某个面板，该面板的底色变为 black。
  - 如果多个面板同时指向同一面板，取行号较小的源面板的底色；行号也相同时取列号较小的。
  - 箭头本身保持不变（仍为 black），分隔线保持 grey 不变。

- `Key insight`：解题者首先需要识别箭头的朝向并建立面板间的指向关系图，这是第一层推理；然后需要理解颜色传递的方向是"被指向者接收指向者的颜色"而非"指向者把自己的颜色推送出去"——两者在存在汇聚和空指向时结果截然不同，这是第二层推理。
