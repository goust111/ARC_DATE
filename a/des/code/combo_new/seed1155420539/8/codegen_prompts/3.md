- `Input structure`：
  - 背景为主色调（如 black）。
  - 网格中有若干条由同一种中性色（如 grey）绘制的单像素宽路径，路径之间可能在某些像素处交叉（即某个 grey 像素的4-邻域中有3个或4个 grey 邻居）。
  - 每条路径有两个端点（4-邻域中恰好只有1个 grey 邻居的像素）。其中一个端点被涂成一种非背景、非 grey 的起始颜色（如 red、blue、green 等），另一个端点保持 grey。
  - 网格的某个角落有一个颜色序列图例：一行排列的 3-4 个不同颜色像素，表示颜色环形轮换顺序（如 red、blue、green 从左到右排列，代表 red→blue→green→red→... 的循环）。

- `Rule`：
  - 第一层：识别角落的颜色序列图例，建立环形轮换映射（序列中每个颜色映射到下一个颜色，最后一个映射回第一个）。
  - 第二层：从每条路径的彩色端点出发，沿 grey 路径逐像素向另一端传播。在到达交叉点之前的所有经过像素都涂成当前传播颜色。
  - 第三层：每当传播到达一个交叉点（4-邻域中有≥3个路径邻居的位置），当前颜色按图例的环形序列轮换到下一个颜色，交叉点本身涂成轮换后的新颜色，然后以新颜色继续传播。
  - 传播直到路径的另一端点。图例本身在输出中保持不变。

- `Key insight`：
  路径的走向是肉眼可见的，但解题者需要同时发现两个非显然规则：(1) 颜色不是沿路径均匀填充，而是在交叉点处发生轮换；(2) 轮换的顺序由角落的颜色图例决定，而非按某种默认顺序。仅观察路径颜色分段现象不足以解题，必须结合图例才能确定正确的轮换方向。
