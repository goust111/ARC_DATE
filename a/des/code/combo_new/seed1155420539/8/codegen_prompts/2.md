- `Input structure`：
  - 背景为主色调（如 black）。
  - 网格中有偶数个彩色连通区域（4-连通），每个区域是单色的不规则形状。
  - 这些区域恰好可以两两配对：同一对中的两个区域形状互补——即把它们的二值掩模放在相同尺寸的包围盒中时，一个区域的前景像素恰好填满另一个区域在该包围盒中的背景像素位置，两者合在一起形成一个无间隙的实心矩形。
  - 同一对的两个区域颜色不同，且包围盒尺寸相同。

- `Rule`：
  - 第一层：识别所有连通区域及其包围盒尺寸。包围盒尺寸相同的两个区域互为候选配对。在候选对中，验证其中一个区域的前景掩模与另一个区域在同尺寸包围盒内的背景掩模完全吻合（即前者填满后者的空隙），确认配对。
  - 第二层：对每一对，将两个区域合并为一个双色实心矩形：在配对包围盒中，各区域保留自己的原始颜色。
  - 第三层：按合并后矩形的面积（像素总数）从小到大排列，从输出网格的顶部开始逐个放置，每个矩形之间留一行背景色间隔，水平左对齐。输出网格宽度取所有矩形中最宽者，高度取所有矩形及间隔行的总高度。

- `Key insight`：
  配对的关键不是颜色匹配而是形状互补——一个碎片的轮廓恰好是另一个碎片在同尺寸矩形中的"负空间"。面积排序是第二层需要归纳的规则，因为样例中配对的呈现位置是打乱的。

## 实现要求

1. `main(grid)` 必须实现新题描述中的确定性转换规则，不能只识别 `generate_input()` 的固定模板。
2. `generate_input()` 必须随机生成多样样例，不能固定死。随机维度应覆盖：网格大小、对象数量、位置、颜色、方向、形状参数或关键分支。
3. 生成器必须保证输入满足 `main()` 的隐式假设：对象不重叠、不越界、特殊标记唯一或可区分、匹配关系无歧义、关键分支出现概率相同。
4. 禁止把 ARC 颜色 id 、亮度、拼写等当作人类不可见的数值语义参与排序、大小比较或隐藏映射。颜色变化必须有可见结构线索。注意颜色亮度、拼写等也是不可见信息，若描述中出现违规的颜色id或者亮度，可自行使用少量的固定颜色替代，但注意生成时要在三个以内输入输出网格中对所有变换100%覆盖度。
