<new_puzzle index="3">
- `description`：每个彩色区域根据其相邻边界上接触的不同颜色数量，生成对应数量的同心收缩层来重绘自身。

- `Input structure`：
  - 背景为 Black。
  - 网格被分割成若干个大型不规则 4-连通单色区域（使用 Red、Blue、Green、Yellow、Orange 等颜色），区域之间直接相邻（共享边），没有间隔，整个网格被这些区域完全覆盖（无 Black 背景）。
  - 每个区域至少有 2 个不同颜色的相邻区域。

- `Rule`：
  - 对每个区域，计算其边界上接触的不同颜色邻居的数量 N（即该区域有多少种不同颜色的相邻区域）。
  - 从该区域的外边界开始，向内做 N 层"洋葱皮剥离"：第 1 层（最外圈，即与其他区域相邻的像素）保持原色；第 2 层（剥去第 1 层后暴露的新边界像素）变为 Grey；第 3 层再变回原色；第 4 层再变 Grey……交替进行，共 N 层。
  - 剥离 N 层后仍剩余的内部核心像素全部变为 Black。
  - 若区域面积不足以支持 N 层剥离（即在剥完 N 层之前区域已耗尽），则有多少层画多少层，无剩余核心。

- `Key insight`：解题者需要先发现"邻居颜色数"决定了层数这一隐蔽关联，再理解交替着色的同心剥离机制——邻居数是通过观察边界接触关系得出的视觉量，而非需要公式计算的值。

1. `main(grid)` 必须实现新题描述中的确定性转换规则，不能只识别 `generate_input()` 的固定模板。

3. 生成器必须保证输入满足 `main()` 的隐式假设：对象不重叠、不越界、特殊标记唯一或可区分、匹配关系无歧义、关键分支出现概率相同。
4. 禁止把 ARC 颜色 id 、亮度、拼写等当作人类不可见的数值语义参与排序、大小比较或隐藏映射。颜色变化必须有可见结构线索。注意颜色亮度、拼写等也是不可见信息，若描述中出现违规的颜色id或者亮度，可自行使用少量的固定颜色替代，但注意生成时要在三个以内输入输出网格中对所有变换100%覆盖度。
