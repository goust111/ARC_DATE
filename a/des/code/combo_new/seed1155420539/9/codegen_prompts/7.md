将网格中的多条折线按交叉点处的颜色混合规则重新着色，交叉点颜色由参与交叉的两条折线颜色在色环上的中间色决定。

Input structure：
- 背景为Black。
- 网格中有若干条单像素宽的折线（每条折线由水平和垂直线段交替连接而成），每条折线一种颜色，使用的颜色来自以下有序色环：Red → Orange → Yellow → Green → Azure → Blue → Magenta → Red（循环）。
- 折线之间可能在某些像素位置交叉。交叉点处两条折线共享同一个像素格。
- 网格边缘有一圈1像素宽的Grey边框。

Rule：
- 找到所有交叉点（即同时属于两条折线路径的像素）。
- 对每个交叉点，确定经过该点的两条折线的颜色，在色环上找到两者之间较短弧的中间色（如Red和Yellow之间的中间色为Orange；Green和Blue之间的中间色为Azure）。
- 将交叉点像素涂为该中间色。
- 非交叉点的折线像素保持原色不变。Grey边框保持不变。

Key insight：
- 第一层推理：需要追踪每条折线的完整路径以识别交叉点，而非简单地寻找某种颜色的像素；第二层推理：交叉点的颜色不是两条线中任何一条的颜色，而是通过一个隐含的色环关系计算出的中间色——解题者必须从多个交叉点的颜色样例中归纳出色环顺序及中间色规则。
