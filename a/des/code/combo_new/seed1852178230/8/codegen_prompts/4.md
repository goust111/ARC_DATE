- `Input structure`：网格背景为黑色。网格中有若干个单像素的彩色"信号塔"（颜色各异，如红、蓝、绿、黄等），以及若干段由灰色像素组成的连续水平或垂直线段（长度 3-8 像素），称为"接收墙"。信号塔和接收墙不相邻、不接触。每段接收墙是一个独立的 4-连通灰色线段。
- `Rule`：
  1. 从每个信号塔向上、下、左、右四个方向发射射线（沿行或列延伸）。
  2. 射线遇到的第一个非黑色像素若属于某段灰色接收墙，则该墙"接收"到了这座塔的颜色。若射线先遇到其他信号塔或到达网格边界，则该方向无效。射线路径本身不绘制任何内容。
  3. 统计每段接收墙收到的不同颜色集合，按颜色在网格中从左到右、从上到下首次出现的顺序排列这些颜色。
  4. 将该墙段重绘：若墙段为水平线段且收到 N 种颜色，则将墙段向下扩展为 N 行高的矩形（宽度不变），每行填充一种收到的颜色（按上述排序从上到下）。若墙段为垂直线段，则向右扩展为 N 列宽的矩形（高度不变），每列一种颜色（从左到右）。原始灰色像素被覆盖。
  5. 信号塔本身保持不变。
- `Key insight`：解题包含两层非显然推理：第一层是发现信号塔通过正方向射线"命中"接收墙的机制（需要追踪视线遮挡关系，遇到其他塔会被阻挡）；第二层是发现墙段的重绘方式取决于收到的颜色数量——数量决定了扩展的厚度，颜色集合决定了色带内容。解题者不能仅看最终输出中的色带，还需要反向推断哪些塔能"看到"哪段墙。
