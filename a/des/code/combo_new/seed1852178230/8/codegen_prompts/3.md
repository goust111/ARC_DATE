- `Input structure`：网格背景为黑色。网格中有若干个由不同颜色像素绘制的大型封闭环形边界，每个环形边界围出一个独立区域。每个区域内部包含：(a) 一个由非边界、非背景的第三种颜色绘制的小型连通图案（3-6 像素，形状不对称，包围盒不超过 3x3），称为"印章源"；(b) 若干个与印章源同色的孤立单像素，称为"锚点"，分布在印章源的不同方向上。每个区域内印章源只有一个。
- `Rule`：
  1. 识别每个封闭环形边界围成的区域。
  2. 在每个区域内，找到由多个像素组成的连通图案作为印章源，找到所有孤立单像素作为锚点。
  3. 确定印章源的中心（包围盒的中心）。
  4. 对每个锚点，判断它相对于印章源中心的方向象限：若锚点在印章源的右侧（且非上非下），则水平镜像翻转图案；若在下方（且非左非右），则垂直镜像翻转；若在右下方，则同时水平和垂直翻转（即旋转 180 度）；若在左上方（与印章源同象限方向），则不翻转。
  5. 将翻转后的印章图案以锚点为中心绘制，覆盖锚点像素。印章源本身保持不变。绘制不得超出区域边界。
- `Key insight`：解题的核心隐蔽性在于锚点与印章源的相对位置不仅决定了"在哪里画"，还决定了"怎么画"——方向象限编码了镜像翻转方式。解题者需要先识别出印章源与锚点的角色区分（连通图案 vs 孤立像素），然后再发现方向-翻转的对应关系。

1. `main(grid)` 必须实现新题描述中的确定性转换规则，不能只识别 `generate_input()` 的固定模板。
2. `generate_input()` 必须随机生成多样样例，不能固定死。随机维度应覆盖：网格大小、对象数量、位置、颜色、方向、形状参数或关键分支。
3. 生成器必须保证输入满足 `main()` 的隐式假设：对象不重叠、不越界、特殊标记唯一或可区分、匹配关系无歧义、关键分支出现概率相同。
4. 禁止把 ARC 颜色 id 、亮度、拼写等当作人类不可见的数值语义参与排序、大小比较或隐藏映射。颜色变化必须有可见结构线索。注意颜色亮度、拼写等也是不可见信息，若描述中出现违规的颜色id或者亮度，可自行使用少量的固定颜色替代，但注意生成时要在三个以内输入输出网格中对所有变换100%覆盖度。
