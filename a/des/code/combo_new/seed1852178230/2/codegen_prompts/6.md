  - 路径在某些位置交汇形成 T 形或十字形节点。每个节点像素本身为一种特殊颜色（如 yellow）。
  - 网格边缘有一条颜色序列条（如位于最右列），从上到下排列了 N 种颜色，定义了颜色的排序顺序。
  - 每条路径的两个端点（路径末端，仅有一个邻居的像素）各自有独立的颜色，这两种颜色都出现在边缘颜色序列中。
  - 路径中间段（端点和节点之间的像素）在输入中全部为同一种中间色（如 grey）。

- `Rule`：
  - 找到边缘颜色序列条，读取颜色排列顺序。
  - 识别所有路径端点（仅有一个非背景邻居的路径像素）。每条完整路径连接两个端点，可能经过多个节点。
  - 对每条完整路径，在颜色序列中查找两个端点颜色的位置，获取从起始颜色到终止颜色之间的子序列（含两端）。
  - 将路径分为与子序列长度相等的段数：路径总像素数（含端点、节点、中间像素）均匀分配到子序列的每种颜色上（若不能整除，多余像素分配给最后一段）。
  - 沿路径从一个端点到另一个端点，依次用子序列中的颜色重新着色每一段。方向规则：颜色序列中位置较小（靠上）的端点颜色为起点。
  - 节点像素也被重新着色为其所在段的颜色。
  - 颜色序列条本身不出现在输出中。

- `Key insight`：第一层推理是发现边缘的颜色条定义了全局颜色排序。第二层推理是理解每条路径的两端颜色决定了该路径使用的颜色子序列。第三层推理是路径被均匀分段并依序着色——节点处的颜色由它在路径中的位置决定而非由节点自身属性决定。
