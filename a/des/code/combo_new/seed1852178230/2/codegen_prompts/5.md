- `Input structure`：
  - 背景为主色（如 black）。
  - 一条或两条贯穿整个网格的直线（水平或垂直，颜色为 grey）将网格分为 2 到 4 个子区域。
  - 每个子区域内恰好包含两个不同颜色的 4-连通对象：
    - 一个"种子对象"：一个实心矩形，尺寸大于等于另一个对象的 bounding box。
    - 一个"模具对象"：一个任意形状的非矩形对象（形状不规则，可能有凹陷或分支）。
  - 每个子区域中种子对象和模具对象的颜色各不相同，但不同子区域之间可能复用颜色。

- `Rule`：
  - 在每个子区域中识别种子对象（实心矩形）和模具对象（非矩形形状）。
  - 将模具对象的形状像素映射到种子对象的 bounding box 内——以模具对象 bounding box 的左上角与种子对象 bounding box 的左上角对齐。
  - 在种子对象中，仅保留与模具形状重叠位置的像素（使用种子对象的颜色），其余种子像素清除为背景色。
  - 将裁剪后的结果（种子颜色、模具形状）放置到模具对象原来的位置（左上角对齐模具的 bounding box 左上角）。
  - 清除种子对象和原始模具对象，只保留裁剪结果。
  - 分隔线保持不变。

- `Key insight`：解题者需要先理解分隔线将网格划分为独立工作区（第一层推理），然后发现每个区域内矩形是"颜色源"而不规则形状是"形状模板"（第二层推理），最后理解变换是"用矩形的颜色填充不规则形状的轮廓并放回原位"——本质上是颜色与形状的交叉重组（第三层推理）。
