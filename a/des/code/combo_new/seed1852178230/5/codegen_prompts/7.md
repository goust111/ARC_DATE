- `description`：根据网格中封闭区域的"邻接图"结构，将区域重新着色，使得邻接数量相同的区域获得相同颜色，邻接数量不同的区域获得不同颜色，颜色分配顺序由区域面积决定。
- `Input structure`：黑色网格线将整个网格划分为若干不规则的封闭区域（类似彩色地图）。每个区域填充着某种非黑色颜色（输入中各区域颜色可能相同也可能不同，这些初始颜色是干扰项）。网格右侧有一列分隔开的色块从上到下排列，作为"调色板"，提供可用的输出颜色。
- `Rule`：
  1. 忽略各区域的输入颜色。识别黑色网格线划分出的所有封闭区域。
  2. 计算每个区域的"邻接度"——即与该区域共享黑色边界线段的其他区域数量（两个区域之间共享至少一个像素长度的黑色边界即视为邻接）。
  3. 将所有区域按邻接度分组。对各组按"该组中面积最大的区域的面积"从大到小排序。
  4. 依次将右侧调色板中从上到下的颜色分配给排序后的各组：第一组（含面积最大区域的组）用调色板第一个颜色，第二组用第二个颜色，依此类推。
  5. 用分配的颜色重新填充每个区域。黑色网格线和调色板保持不变。
- `Key insight`：输入中区域的原始颜色是纯干扰——解题者必须忽略它们，转而发现隐藏的邻接度等价关系。两层推理：第一层是发现"邻接度相同 = 同色"的分组规则，第二层是发现组间排序依据面积最大成员的面积来确定调色板映射顺序。
</new_puzzle>
