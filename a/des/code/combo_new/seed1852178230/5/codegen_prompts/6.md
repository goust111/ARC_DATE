- `Rule`：
  1. 找到所有印章和画布。通过颜色匹配将画布中的彩色标记点与对应的印章配对。
  2. 分析每个标记旁的 L 形箭头：从彩色点出发，先走到第一个 Maroon 像素，再拐到第二个 Maroon 像素，拐弯方向决定旋转方向（向右拐 = 顺时针 90 度，向左拐 = 逆时针 90 度）。
  3. 统计每种颜色在画布中出现的标记数量 N。将对应印章旋转 N 个 90 度（按箭头指示的方向累计旋转）。
  4. 将旋转后的印章图案以彩色标记点为中心盖印到画布上（覆盖 Azure 背景，不覆盖黑色边框和其他已盖印图案）。如果同色标记有多个，在每个标记位置都盖印同一个旋转结果。
  5. 擦除所有 Maroon 箭头像素和彩色标记点。输出仅包含画布区域（含边框），紧凑裁剪。
- `Key insight`：解题者需要依次发现三层结构：（1）颜色匹配确定印章-标记配对；（2）L 形箭头的几何朝向编码了旋转方向；（3）同色标记的数量决定了旋转次数——每一层都需要从样例中独立归纳，且只有三层规则同时正确才能得到正确输出。
