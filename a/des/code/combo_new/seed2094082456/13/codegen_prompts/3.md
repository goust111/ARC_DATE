- `Input structure`：
  - 背景为 black。
  - 网格中散布着若干由 grey 构成的 4-连通矩形前景对象（大小不一，形状为矩形但可能带有单像素缺角或凸起以体现不同对称性）。

  - 每个 grey 对象恰好关联一个最近的 red 方向标记。

- `Rule`：
  - 第一步（确定运动方向）：对每个 grey 对象，找到离它最近的 red 方向标记（距离按像素格数计，取对象边界到标记的最短正交距离）。对象向远离该标记的方向（即标记在对象上方则对象向下）滑动，直到对象的边界触碰网格边缘或另一个已停止的对象为止。滑动按行优先顺序处理（最上方的对象先移动）。red 标记在滑动完成后从网格中移除。
  - 第二步（根据对称性着色）：滑动完毕后，检查每个对象的形状对称性。具有水平反射对称的对象重绘为 blue；具有垂直反射对称的对象重绘为 green；同时具有水平和垂直反射对称的对象重绘为 yellow；无任何反射对称的对象重绘为 magenta。

- `Key insight`：第一层推理需要发现 red 标记不是目标而是"排斥源"——对象朝远离标记的方向移动；第二层推理需要发现最终颜色并非由移动方向或原始位置决定，而是由对象自身形状的对称性类别决定。这两条规则互相独立，必须同时归纳才能正确预测输出。
