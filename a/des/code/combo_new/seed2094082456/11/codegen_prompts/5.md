- `Input structure`：
  - 背景为主色调（如 black）。
  - 网格中有若干个同心嵌套的矩形框架（仅由边框像素构成，内部为背景色或更小的框架）。每个框架使用不同的颜色，如从外到内依次为 red、blue、green 等。
  - 在最内层框架的内部，有若干孤立的单像素标记，每个标记颜色不同。这些标记像素从上到下排列。

- `Rule`：
  - 将所有嵌套框架按从外到内的层级排序，得到层级列表 L（L[0] 为最外层，L[N-1] 为最内层）。
  - 将最内层的孤立像素标记从上到下排序，得到颜色列表 C。
  - 执行颜色反转映射：第 i 层框架（从外到内计数，i=0 为最外层）重新着色为颜色列表 C[i]。
  - 如果框架层数多于标记颜色数，多余的内层框架保持原色不变。
  - 孤立像素标记在输出中被移除。

- `Key insight`：
  - 第一层推理需要识别框架的嵌套层级关系（哪个包含哪个）；第二层推理需要发现最内层的孤立像素是颜色指令序列，且映射方向是反转的——像素序列中的第一个颜色分配给最外层框架，而非最内层。这种"由内定外"的反直觉映射是核心难点。

4. 禁止把 ARC 颜色 id 、亮度、拼写等当作人类不可见的数值语义参与排序、大小比较或隐藏映射。颜色变化必须有可见结构线索。注意颜色亮度、拼写等也是不可见信息，若描述中出现违规的颜色id或者亮度，可自行使用少量的固定颜色替代，但注意生成时要在三个以内输入输出网格中对所有变换100%覆盖度。
