- `description`：根据每个封闭区域内标记像素的颜色，用该颜色重新绘制区域的边界线段。
- `Input structure`：背景色网格上有一个由灰色线段构成的不规则网络，这些线段将网格分割成若干封闭区域（每个区域是一个由灰色边界围成的 4-连通背景色区域）。部分封闭区域内包含恰好一个非灰色、非背景色的单像素标记点，标记点颜色各不相同。部分区域没有标记点。
- `Rule`：
  - 第一步：识别灰色线段网络划分出的所有封闭区域。
  - 第二步：对于每个包含标记点的区域，找到该区域的所有边界灰色像素（即与该区域的背景像素 4-邻接的灰色像素）。
  - 第三步：如果一个灰色边界像素仅与一个含标记区域相邻，则将其重新着色为该标记的颜色。如果一个灰色边界像素同时与两个含标记区域相邻，则保持灰色不变（共享墙壁保留原色）。
  - 第四步：不含标记的区域的专属边界（不与任何含标记区域共享的灰色像素）也保持灰色不变。标记点本身在输出中被清除为背景色。
- `Key insight`：关键不在于"找到标记点"这一步，而在于理解边界像素的归属规则——共享墙壁不被染色，只有专属于单个标记区域的边界才变色。解题者需要从样例中归纳出这条共享墙壁例外规则。

1. `main(grid)` 必须实现新题描述中的确定性转换规则，不能只识别 `generate_input()` 的固定模板。

3. 生成器必须保证输入满足 `main()` 的隐式假设：对象不重叠、不越界、特殊标记唯一或可区分、匹配关系无歧义、关键分支出现概率相同。
4. 禁止把 ARC 颜色 id 、亮度、拼写等当作人类不可见的数值语义参与排序、大小比较或隐藏映射。颜色变化必须有可见结构线索。注意颜色亮度、拼写等也是不可见信息，若描述中出现违规的颜色id或者亮度，可自行使用少量的固定颜色替代，但注意生成时要在三个以内输入输出网格中对所有变换100%覆盖度。
