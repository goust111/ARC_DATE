- `description`：网格中的彩色路径段连接着起点标记和终点标记，将每条路径上的颜色序列"压缩"——相邻重复色合并为一个像素——然后将压缩后的序列重新铺在从起点到终点的直线段上。

- `Input structure`：
  - 背景为主色（如 black）。
  - 网格中有若干条由非背景像素构成的路径，每条路径是一个 4-连通的像素序列，沿途可能拐弯。
  - 每条路径的两个端点之一标有一个 green 像素（起点），另一端标有一个 red 像素（终点）。green 和 red 不参与颜色序列。
  - 路径主体（不含端点标记）由多种颜色的像素组成，沿路径形成一个有序颜色序列。
  - 每条路径的起点和终点要么在同一行，要么在同一列（即直线方向对齐）。

- `Rule`：
  - 对每条路径，沿 4-连通方向从 green 端点出发，记录路径上每个像素的颜色序列（不含 green 和 red 端点自身）。
  - 对该序列执行游程压缩：将连续相同颜色的段压缩为单个像素。例如 [blue, blue, blue, yellow, yellow, orange] 压缩为 [blue, yellow, orange]。
  - 清除原路径的所有像素（包括端点标记）。
  - 从 green 端点位置出发，沿起点到终点的直线方向（水平或垂直），依次绘制压缩后的颜色序列，每个颜色占一个像素。
  - 压缩后的序列末尾紧接一个 red 像素作为新终点。
  - 原 green 端点位置绘制 green 像素。

- `Key insight`：路径的弯折走向是干扰信息——实际输出是起终点之间的直线。路径上的颜色重复编码了"展开长度"但在输出中被压缩。解题者需要发现两个规则：（1）弯曲路径变直线；（2）颜色序列经过游程压缩。单独发现任一条都不足以完全解释输出。
</new_puzzle>
