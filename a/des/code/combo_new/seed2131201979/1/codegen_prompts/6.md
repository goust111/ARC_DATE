网格中每个彩色形状的"影子"被投射到一面灰色"镜墙"上，影子的投射方向由形状内部的单像素箭头标记决定，影子长度由形状的面积决定。

Input structure：
- 背景为黑色。
- 网格中有一条贯穿整个网格的灰色直线（水平或垂直），宽度为 1 像素，充当"镜墙"。
- 镜墙两侧分布着若干彩色实心形状（4-连通，每个形状为单一非灰非黑颜色）。
- 每个形状内部恰好有一个与形状颜色不同的单像素标记（箭头标记），该标记的颜色为 Maroon。Maroon 标记在形状内部的相对位置编码了投射方向：标记位于形状最左列 → 向左投射；最右列 → 向右投射；最上行 → 向上投射；最下行 → 向下投射。

Rule：
- 计算每个形状的面积（像素数，不含 Maroon 标记）。
- 根据 Maroon 标记的位置确定投射方向。
- 从形状朝投射方向看，在镜墙表面上找到形状在该方向上的正交投影区域（即形状在镜墙上的"影子范围"——形状沿投射方向投影到镜墙上覆盖的那些灰色像素）。
- 从该投影区域出发，沿投射方向的反方向（即远离形状的一侧）延伸，长度等于形状面积的像素数，用形状的颜色绘制实心矩形条带。条带的宽度等于投影区域的宽度。
- 原始形状和 Maroon 标记保持不变。
- 镜墙上被投影覆盖的灰色像素保持灰色。

Key insight：Maroon 标记的相对位置是方向编码（第一层推理），形状面积转化为影子长度（第二层推理），而镜墙既是投影面又是反射分界线——影子出现在形状的对侧。

1. `main(grid)` 必须实现新题描述中的确定性转换规则，不能只识别 `generate_input()` 的固定模板。

3. 生成器必须保证输入满足 `main()` 的隐式假设：对象不重叠、不越界、特殊标记唯一或可区分、匹配关系无歧义、关键分支出现概率相同。
4. 禁止把 ARC 颜色 id 、亮度、拼写等当作人类不可见的数值语义参与排序、大小比较或隐藏映射。颜色变化必须有可见结构线索。注意颜色亮度、拼写等也是不可见信息，若描述中出现违规的颜色id或者亮度，可自行使用少量的固定颜色替代，但注意生成时要在三个以内输入输出网格中对所有变换100%覆盖度。
