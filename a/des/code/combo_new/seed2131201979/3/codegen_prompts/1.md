- `Input structure`：背景为黑色的矩形网格，内部被灰色单像素线条分隔为若干不规则的单色填充区域（每个区域为一种非黑非灰的颜色）。网格最外围有一圈灰色边框，边框上有若干单像素缺口，每个缺口处标有一个彩色像素（颜色与内部区域颜色不同，使用 Azure、Maroon 等标记色）。
- `Rule`：
  1. 每个边框缺口的彩色像素沿缺口朝向（上缺口向下、左缺口向右等）发射一条单像素宽的射线，射线初始颜色为缺口标记色。
  2. 射线在黑色背景上行进时保持标记色不变。
  3. 当射线进入一个彩色填充区域时，射线不穿过该区域，而是沿区域边界的灰色分隔线转向（遇到灰色线时选择顺时针方向的第一个可行方向继续前进）。
  4. 射线离开该区域边界后，其颜色变为该区域的填充色，继续在黑色背景上行进，直到遇到下一个区域或到达网格边缘停止。
  5. 所有原有的区域填充色、灰色线条和边框保持不变，仅在黑色背景像素上绘制射线轨迹。
- `Key insight`：射线并非简单的直线投射——灰色分隔线构成的区域边界既是折射面又是转向导轨，而射线颜色在穿越每个区域后被"染色"为该区域的颜色，形成一条颜色渐变的折线轨迹。解题者需要同时推理出转向规则（顺时针贴边）和变色规则（继承区域色）。
