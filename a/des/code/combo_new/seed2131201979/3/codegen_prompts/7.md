- `Input structure`：背景为黑色。网格中有若干个单色实心矩形色块（每个颜色不同），每个色块内部恰好有一个由背景色构成的连通孔洞，孔洞形状为 L 形、T 形、I 形或方形之一。网格中另有若干孤立的单像素锚点，每个锚点颜色与某个色块颜色相同。每种孔洞形状对应一种旋转角度：L 形 = 顺时针 90 度，T 形 = 180 度，I 形 = 顺时针 270 度，方形 = 不旋转。
- `Rule`：
  1. 识别每个色块内部孔洞的形状类别（L / T / I / 方形）。
  2. 根据孔洞形状确定旋转角度：L 形 → 90°CW，T 形 → 180°，I 形 → 270°CW，方形 → 0°。
  3. 将色块按对应角度旋转。
  4. 将旋转后的色块移动至同色锚点位置，锚点作为旋转后色块包围盒的左上角。
  5. 原色块位置清除为背景色，锚点被色块覆盖。
- `Key insight`：孔洞形状同时承担了两个看似无关的功能——它既是色块的视觉特征，又隐蔽地编码了旋转指令。解题者需要先发现孔洞形状与旋转角度之间的映射关系（通过对比输入输出中色块的朝向变化来归纳），再发现锚点颜色与色块的配对及锚定规则。这两层推理相互独立，必须分别归纳。
