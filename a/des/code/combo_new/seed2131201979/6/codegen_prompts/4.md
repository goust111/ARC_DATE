Input structure：
- 背景为 black。
- 网格被 1 像素宽的 grey 十字分隔线（一条水平线和一条垂直线贯穿全格）切成四个矩形区域。
- 每个区域内包含：（a）若干同色像素组成的一个小图案（邮票），（b）恰好 1 个不同于邮票颜色的单像素锚点。
- 锚点的颜色与另一个区域中的邮票颜色相同（形成跨区域颜色配对）。每个区域的邮票颜色各不相同。

Rule：
- 第一步：通过颜色匹配建立配对——区域 A 的锚点颜色 = 区域 B 的邮票颜色，意味着区域 B 的邮票将被印到区域 A 中。
- 第二步：确定区域 B 中锚点位于邮票外接矩形的哪个象限（左上、右上、左下、右下）。这决定邮票的旋转：左上 = 不旋转，右上 = 顺时针 90°，右下 = 180°，左下 = 逆时针 90°。
- 第三步：将旋转后的邮票绘制到区域 A 中，以区域 A 的锚点位置为邮票外接矩形的中心。邮票颜色保持区域 B 中的原色。
- 第四步：输出网格保留 grey 分隔线，各区域仅显示印入的邮票（原区域的邮票和锚点均清除）。

Key insight：
- 跨区域颜色配对是第一层推理，锚点象限编码旋转角度是第二层推理，两者结合才能确定最终输出——单独看任何一个区域都无法推断完整规则。

3. 生成器必须保证输入满足 `main()` 的隐式假设：对象不重叠、不越界、特殊标记唯一或可区分、匹配关系无歧义、关键分支出现概率相同。
4. 禁止把 ARC 颜色 id 、亮度、拼写等当作人类不可见的数值语义参与排序、大小比较或隐藏映射。颜色变化必须有可见结构线索。注意颜色亮度、拼写等也是不可见信息，若描述中出现违规的颜色id或者亮度，可自行使用少量的固定颜色替代，但注意生成时要在三个以内输入输出网格中对所有变换100%覆盖度。
