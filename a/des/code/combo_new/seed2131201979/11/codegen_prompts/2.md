- `Input structure`：
  - 背景色为 black。网格中散布着偶数个彩色 4-连通对象，每个对象由单一颜色构成。
  - 这些对象可以两两配对：配对的两个对象形状互补，即将其中一个对象平移（不旋转、不翻转）后与另一个对象无重叠地拼合，恰好构成一个实心矩形。
  - 每对互补对象的颜色各不相同；拼合后形成的矩形大小也各不相同。

- `Rule`：
  - 第一步：找出所有互补配对——对于每两个对象，检查是否存在一种平移使得二者无重叠地恰好填满某个矩形。每个对象恰好属于一个配对。
  - 第二步：对每个配对，将两个碎片拼合成完整矩形。拼合后，每个像素保持其原始碎片的颜色。
  - 第三步：将所有拼合后的矩形按面积从小到大、从左到右排列在输出网格中，矩形之间留一列 black 间隔，所有矩形顶边对齐输出网格顶行。

- `Key insight`：解题者不仅需要发现碎片之间的形状互补关系（哪两个碎片能拼成矩形），还需要发现输出的排列规则是按拼合后面积排序——配对逻辑和排序逻辑构成两层独立推理。

## 实现要求

1. `main(grid)` 必须实现新题描述中的确定性转换规则，不能只识别 `generate_input()` 的固定模板。
2. `generate_input()` 必须随机生成多样样例，不能固定死。随机维度应覆盖：网格大小、对象数量、位置、颜色、方向、形状参数或关键分支。
3. 生成器必须保证输入满足 `main()` 的隐式假设：对象不重叠、不越界、特殊标记唯一或可区分、匹配关系无歧义、关键分支出现概率相同。
4. 禁止把 ARC 颜色 id 、亮度、拼写等当作人类不可见的数值语义参与排序、大小比较或隐藏映射。颜色变化必须有可见结构线索。注意颜色亮度、拼写等也是不可见信息，若描述中出现违规的颜色id或者亮度，可自行使用少量的固定颜色替代，但注意生成时要在三个以内输入输出网格中对所有变换100%覆盖度。
