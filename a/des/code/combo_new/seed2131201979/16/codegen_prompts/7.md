- `description`：网格被分成若干矩形区域，每个区域内有一个"指针"箭头和一个"目标"色块；将每个区域内的色块搬移到指针所指向的相邻区域中，放置在该相邻区域的镜像对称位置。

- `Input structure`：
  - 背景为主色（如 black）。
  - 网格被 maroon 色的水平线和垂直线均匀分割成 N×M 个大小相等的矩形区域（类似九宫格或更大的网格）。
  - 每个矩形区域内包含两个元素：
    1. 一个由 3 个像素组成的 L 形"指针"箭头（由 red 像素构成），指向上/下/左/右之一（L 的短边指示方向）。
    2. 一个小型彩色色块（2×2 或 3×1 等小形状，颜色各不相同，非 red 非 maroon 非背景色），位于区域内的某个位置。
  - 所有区域的指针都指向一个有效的相邻区域（不会指向网格外部）。

- `Rule`：
  - 第一步：识别每个区域中指针的朝向，确定其指向的相邻区域。
  - 第二步：计算色块在当前区域内的相对位置（相对于区域左上角的偏移量）。
  - 第三步：将色块从当前区域移除，放置到指针所指的相邻区域中。放置时，色块的位置要做一次关于指针方向轴的镜像翻转——若指针向右，则色块在目标区域中的列坐标做左右镜像（相对于区域中心）；若指针向下，则行坐标做上下镜像；以此类推。
  - 第四步：如果目标区域已有来自其他区域的色块被搬入，后到的色块叠加在上方（覆盖）。指针本身在输出中移除（变为背景色）。分割线保持不变。

- `Key insight`：指针给出了色块的传送方向，但色块到达目标区域后的放置位置不是简单复制——而是沿传送方向轴做了镜像翻转。解题者需要先发现"指针 = 传送方向"（第一层），再发现"到达后做方向轴镜像"（第二层），两步缺一都无法完全还原输出。
</new_puzzle>
