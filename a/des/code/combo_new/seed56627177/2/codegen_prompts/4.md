Input structure
- 背景为 black。
- 网格被 maroon 色的完整行和完整列分割为若干矩形子区域（类似九宫格或更多格）。

- 主图案关于子区域中心不具有完全对称性。两个标记点总是关于子区域中心呈中心对称分布。

Rule
- 对每个子区域，识别主图案和两个标记点。
- 两个标记点连线穿过子区域中心，确定一条对称轴：若连线为水平方向，则对称轴为水平轴；若连线为垂直方向，则对称轴为垂直轴；若连线为对角方向（45度或135度），则对称轴为对应的对角线。
- 将主图案沿该对称轴做镜像翻转。
- 用翻转后的图案替换原来的主图案（标记点保留不变，背景不变）。

Key insight
- 第一层推理：标记点总是成对出现且关于中心对称，这暗示它们编码的是方向信息而非位置信息。第二层推理：标记点连线的方向决定了镜像轴——这是一种用离散点对编码连续对称操作的隐蔽方式，解题者需要跨越"点→线→轴"的抽象映射。

## 实现要求

1. `main(grid)` 必须实现新题描述中的确定性转换规则，不能只识别 `generate_input()` 的固定模板。
2. `generate_input()` 必须随机生成多样样例，不能固定死。随机维度应覆盖：网格大小、对象数量、位置、颜色、方向、形状参数或关键分支。
3. 生成器必须保证输入满足 `main()` 的隐式假设：对象不重叠、不越界、特殊标记唯一或可区分、匹配关系无歧义、关键分支出现概率相同。
4. 禁止把 ARC 颜色 id 、亮度、拼写等当作人类不可见的数值语义参与排序、大小比较或隐藏映射。颜色变化必须有可见结构线索。注意颜色亮度、拼写等也是不可见信息，若描述中出现违规的颜色id或者亮度，可自行使用少量的固定颜色替代，但注意生成时要在三个以内输入输出网格中对所有变换100%覆盖度。
