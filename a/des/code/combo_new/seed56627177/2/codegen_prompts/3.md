根据种子像素的邻域密度选择生长模式，将每个种子扩展为特定形状的区域，生长方向由相邻边界线段决定。

Input structure
- 背景为 black。
- 网格中有若干条由 grey 像素绘制的直线段（水平或垂直），它们将网格大致划分为若干区域但不完全封闭。
- 在这些线段附近散布着单个彩色像素（种子），每个种子颜色各异。每个种子恰好与一条或两条 grey 线段相邻（四方向邻接）。

Rule
- 对每个种子像素，数它四方向上相邻的 grey 像素数量（即它接触了几条线段的几个像素），记为 k。
- 若 k = 1：种子沿远离该 grey 邻居的方向生长为一条长度为 3 的直线（包含种子自身共 3 个像素）。
- 若 k = 2 且两个 grey 邻居在同一条线上（即种子夹在一条线段的两个像素之间的延长线上）：种子沿垂直于该线段的两个方向各生长 1 个像素，形成长度为 3 的十字臂。
- 若 k = 2 且两个 grey 邻居分属不同方向（即种子位于两条线段的交角处）：种子沿远离两条线段的对角方向生长为一个 2x2 的实心方块（种子占据靠近角落的那个像素位置）。
- 生长的像素使用种子自身的颜色。生长像素不会覆盖 grey 线段或其他种子。

Key insight
- 第一层推理：必须识别种子与 grey 线段的邻接关系及数量，这决定了生长模式的类别。第二层推理：生长的方向不是任意的，而是由邻接的线段方位决定——远离线段或垂直于线段，需要理解"排斥性生长"的空间逻辑。

1. `main(grid)` 必须实现新题描述中的确定性转换规则，不能只识别 `generate_input()` 的固定模板。
