将网格中的路径线段按照交叉点处的层叠顺序进行分层着色，层级由交叉点处的覆盖关系链推断。

Input structure
- 背景为 black。
- 网格中有若干条由 green 像素绘制的水平或垂直线段，它们相互交叉形成若干交叉点。
- 每个交叉点处恰好有两条线段交叉（一条水平、一条垂直）。在交叉点的某个相邻位置（上下左右之一）有一个单像素的 red 标记，该标记靠近的那条线段被视为"在上层"的线段。
- 所有线段初始均为 green 色。

Rule
- 根据所有交叉点处的 red 标记，建立线段之间的层叠关系：在每个交叉点，red 标记靠近的线段在该交叉点处位于另一条线段之上。
- 从这些两两关系中推导出所有线段的全局层级排序（最底层、中间层、最顶层等）。题目保证该排序是唯一的全序。
- 将最底层的线段着色为 blue，次底层着色为 yellow，再上一层着色为 orange，最顶层着色为 red。若线段总数少于四条，则从 blue 开始按顺序使用对应数量的颜色。
- 交叉点处的像素着色为上层线段的颜色。移除所有 red 标记点（恢复为背景色）。

Key insight
- 第一层推理：red 标记点不是装饰，而是编码了每个交叉点处哪条线段在上方——需要理解标记的空间邻接关系与"上下层"的映射。第二层推理：每个交叉点只给出局部的两两比较，解题者必须将所有局部关系串联成全局排序，这是一个从局部约束推断全局结构的非平凡归纳过程。第三层推理：层级排序映射到特定的颜色序列，构成最终的着色方案。
