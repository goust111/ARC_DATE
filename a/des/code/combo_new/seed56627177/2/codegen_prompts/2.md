Input structure
- 背景为 azure。
- 网格中有一个较大的空心矩形框架，由 grey 像素绘制，框架内部为背景色。
- 框架的上边缘外侧紧贴一行色带（宽度与框架内部宽度相同），色带由若干段不同颜色组成，每段覆盖若干连续列；框架的左边缘外侧紧贴一列色带（高度与框架内部高度相同），色带由若干段不同颜色组成，每段覆盖若干连续行。
- 网格其余位置散布着若干小型连通图案（碎片），每个碎片由单一颜色绘制。每个碎片的颜色在上边缘色带和左边缘色带中各恰好出现一次。

Rule
- 对每个碎片，在上边缘色带中找到与其颜色相同的那一段，记录其覆盖的列范围；在左边缘色带中找到与其颜色相同的那一段，记录其覆盖的行范围。
- 这两个范围的交叉区域定义了该碎片在框架内部的目标矩形区域。
- 将碎片平移到该目标区域内，碎片的左上角对齐目标区域的左上角。碎片的外接矩形不会超出目标区域。
- 清除碎片原始位置的像素（恢复为背景色），将碎片绘制在框架内部的新位置。框架、色带和背景保持不变。

Key insight
- 第一层推理：碎片颜色并非装饰，而是索引键——必须发现颜色与边缘色带的对应关系。第二层推理：上色带给出列坐标、左色带给出行坐标，两者交叉定位碎片的放置槽位，构成一个二维查表过程。
