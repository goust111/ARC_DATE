- `Input structure`：
  - 背景为黑色（black）。
  - 网格中散布若干单像素的彩色锚点（如 red、blue、green 等），每个颜色恰好出现两个。
  - 同色的两个锚点之间由灰色（grey）像素组成的直线段或折线段相连，形成"围栏"。
  - 多条围栏可能共享灰色像素段，整体围栏网络将网格划分为若干封闭区域。
  - 每个封闭区域的边界恰好由两条不同颜色对的围栏段构成（即该区域被两对锚点的围栏共同围住）。
  - 网格的某个角落有一个小型颜色配对图例——一个 N×3 的小表格，每行前两格各放一种锚点颜色，第三格放结果颜色，表示这两种锚点颜色的围栏共同围住的区域应填充的颜色。

- `Rule`：
  - 第一步：识别每个被围栏完全封闭的区域（不含围栏像素本身）。
  - 第二步：确定围住该区域的两条围栏分别属于哪两对锚点颜色，例如 red 对和 blue 对。
  - 第三步：查找角落图例中与该两色组合匹配的行，取其结果颜色。
  - 第四步：用该结果颜色填充整个封闭区域的背景像素。围栏像素、锚点像素和图例像素保持不变。

- `Key insight`：解题者需要先理解灰色围栏将空间分区，再识别每个区域由哪两对颜色的围栏界定，最后通过角落的颜色配对图例查表得到填充色——三层推理缺一不可。
