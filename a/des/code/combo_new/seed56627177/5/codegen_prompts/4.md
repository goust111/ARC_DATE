根据封闭区域内种子像素的颜色对区域染色，再将染色区域的面积转换为该区域边框上等距排列的标记点。

Input structure
- 背景为黑色。
- 网格中有若干由 grey 像素绘制的封闭多边形轮廓（边框宽 1 像素，各多边形互不接触，形状为简单的轴对齐矩形或 L 形）。
- 每个封闭区域内部恰好有一个非黑非灰的"种子"像素（颜色各不同，如 red、blue、green、yellow 等）。
- 每个封闭区域的内部面积（黑色像素数，不含种子和边框）各不相同且均不超过 10。

Rule
- 第一步：对每个封闭区域，将其内部所有黑色像素染为种子像素的颜色（种子本身保持不变）。
- 第二步：数出每个区域被染色的像素数量（即内部面积减去种子占的 1 格）。
- 第三步：在该区域的 grey 边框上，从边框的左上角像素开始，沿边框顺时针方向，每隔一个边框像素放置一个种子颜色的标记点（即将该 grey 像素改为种子颜色），总共放置的标记点数量等于第二步数出的染色像素数量。若标记点数量超过边框像素数的一半则环绕继续放置。

Key insight
解题者首先需要发现种子颜色扩散填充区域的简单规则，但仅此不够——第二层规则是将内部面积"投影"到边框上成为等距标记点。面积与边框标记的对应关系是核心隐蔽机制：同一个数值既是填充面积又是边框标记的数量，这种跨域映射需要从多个样例中归纳。
