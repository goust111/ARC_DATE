- `description`：将每对通过"桥"连接的对象合并，合并方式由桥的颜色决定：一种桥色执行形状叠加（并集），另一种桥色执行形状相减（差集）。

- `Input structure`：
  - 背景为 black。
  - 网格中有若干个由不同颜色构成的单色矩形实心对象（每个对象内部全部为同一种颜色，如 blue、green、yellow 等），对象之间不直接接触。
  - 某些对象之间通过一像素宽的水平或垂直直线段相连，这些连线称为"桥"。桥的颜色只有两种：red 或 orange。
  - 每个桥恰好连接两个不同的对象（桥的两个端点分别 4-邻接两个不同对象的边缘像素）。
  - 每个对象最多被一座桥连接。被桥连接的两个对象大小相同（bounding box 尺寸一致）。

- `Rule`：
  - 对每对被桥连接的对象 A 和 B：
    - 将 A 和 B 的形状归一化到相同的 bounding box 坐标系中（左上角对齐）。
    - 如果桥为 red：输出形状为 A 和 B 的像素并集，颜色使用 A 的颜色，放置在 A 的原始位置。同时擦除 B 和桥。
    - 如果桥为 orange：输出形状为 A 减去 B 的像素（在 A 中存在但在 B 对应位置不存在的像素保留，A 中与 B 重合的像素擦除为 black），颜色使用 A 的颜色，放置在 A 的原始位置。同时擦除 B 和桥。
    - 其中 A 是桥连接的两个对象中距离网格左上角更近的那个（按行优先：先比较顶行，顶行相同则比较左列）。
  - 未被桥连接的对象保持不变。

- `Key insight`：解题者需要先识别桥的连接关系并理解桥是操作指令而非装饰（第一层），然后发现两种桥色对应两种不同的集合运算——并集与差集（第二层），还需要确定运算的方向性（哪个是 A 哪个是 B 影响差集结果，第三层）。

1. `main(grid)` 必须实现新题描述中的确定性转换规则，不能只识别 `generate_input()` 的固定模板。

4. 禁止把 ARC 颜色 id 、亮度、拼写等当作人类不可见的数值语义参与排序、大小比较或隐藏映射。颜色变化必须有可见结构线索。注意颜色亮度、拼写等也是不可见信息，若描述中出现违规的颜色id或者亮度，可自行使用少量的固定颜色替代，但注意生成时要在三个以内输入输出网格中对所有变换100%覆盖度。
