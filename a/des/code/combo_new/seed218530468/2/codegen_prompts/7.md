Input structure:
- 背景为黑色（black）。
- 网格中有若干个"信号塔"：每个信号塔是一个 2x2 的同色方块，颜色各不相同（如 red、blue、green 等）。
- 网格中有若干个"接收器"：每个接收器是一个 1x1 的灰色（grey）像素。
- 网格中还有若干个 1x1 的"混合色样本"像素，每个样本恰好位于两个不同颜色信号塔之间的同一行或同一列上，且样本的颜色既非两个信号塔的颜色，也非灰色或黑色。每对信号塔颜色组合最多对应一个混合色样本。

Rule:
- 第一层：识别所有信号塔（2x2 同色方块）和它们的颜色。识别所有灰色接收器。
- 第二层：每个信号塔从其四条边的中心位置（2x2 方块的每条边中间两个像素各自）向外发射水平或垂直射线。射线在碰到信号塔、网格边缘或非黑非灰像素时停止。记录每条射线经过的灰色接收器。
- 第三层：对于只被一个信号塔射线覆盖的接收器，将其染为该信号塔的颜色。对于被两个不同信号塔射线同时覆盖的接收器，找到网格中这两种颜色对应的混合色样本，将接收器染为该样本的颜色。未被任何射线覆盖的接收器保持灰色。
- 信号塔、混合色样本像素和背景保持不变。

Key insight:
解题者需要先理解射线传播机制，再发现混合色样本充当了"双色叠加查找表"——网格本身就编码了颜色混合规则，而非依赖外部知识。三层推理分别对应信号源识别、射线传播、颜色叠加查表。

1. `main(grid)` 必须实现新题描述中的确定性转换规则，不能只识别 `generate_input()` 的固定模板。
2. `generate_input()` 必须随机生成多样样例，不能固定死。随机维度应覆盖：网格大小、对象数量、位置、颜色、方向、形状参数或关键分支。
3. 生成器必须保证输入满足 `main()` 的隐式假设：对象不重叠、不越界、特殊标记唯一或可区分、匹配关系无歧义、关键分支出现概率相同。
4. 禁止把 ARC 颜色 id 、亮度、拼写等当作人类不可见的数值语义参与排序、大小比较或隐藏映射。颜色变化必须有可见结构线索。注意颜色亮度、拼写等也是不可见信息，若描述中出现违规的颜色id或者亮度，可自行使用少量的固定颜色替代，但注意生成时要在三个以内输入输出网格中对所有变换100%覆盖度。
