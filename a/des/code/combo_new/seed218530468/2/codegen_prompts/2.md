在由彩色条纹分隔的多个区域中，根据每个区域内小图案的朝向，将该区域的内容旋转到统一朝向后拼合成一幅完整图像。

Input structure:
- 背景为黑色（black）。
- 网格被若干条单像素宽的红色（red）水平线和红色垂直线分割为大小相同的矩形格子（类似九宫格或更大的网格布局）。
- 每个格子内有一个用多种颜色绘制的小图案（sprite），每个小图案内部恰好有一个箭头标记：箭头由三个同色像素组成，一个像素为箭头尖端，另外两个像素从尖端向同一方向的两侧各偏一格形成箭尾（即"V"字形，开口方向即箭头指向的反方向；箭头指向即尖端相对于两个箭尾像素的方向）。
- 箭头标记的颜色为绿色（green），与图案的其他颜色不同。

Rule:
- 第一层：识别每个格子中绿色箭头的指向（上/下/左/右）。所有格子中有且仅有一个格子的箭头指向上方，该格子的内容无需旋转，作为基准朝向。
- 第二层：对其他每个格子，计算其箭头指向与"上方"之间需要顺时针旋转多少个 90 度才能对齐到上方。将该格子的全部内容（包括箭头）做相应旋转。
- 第三层：旋转完成后，移除所有格子中的绿色箭头像素（恢复为黑色背景），然后将所有格子按照它们在原始网格中的行列位置拼合（去掉红色分隔线），输出最终图像。

Key insight:
红色网格线仅用于分隔，绿色箭头仅用于编码旋转量——两者都不会出现在输出中；解题者必须先识别箭头朝向以推断旋转角度，再拼合才能还原被打散并旋转过的完整图像。
