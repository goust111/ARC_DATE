- `Input structure`：
  - 背景色为 black。
  - 网格中央有一个由 grey 像素绘制的空心矩形框架（一像素宽边框，内部为背景色）。
  - 框架外部散布若干个小型彩色碎片（每个碎片是一个 2-4 像素的连通体，使用独特的非背景、非 grey 颜色）。
  - 每个碎片恰好有一个像素与框架边框的外侧正交相邻（即该像素与框架某条边上的某个 grey 像素在上下或左右方向上直接相邻），该像素称为碎片的"锚点"。锚点所在的框架边决定了投射方向：锚点贴在框架上边外侧 → 向下投射；贴在左边外侧 → 向右投射；贴在下边外侧 → 向上投射；贴在右边外侧 → 向左投射。

- `Rule`：
  - 第一步（确定投射方向）：根据碎片锚点与框架的哪条边相邻，确定碎片向框架内部的投射方向。
  - 第二步（计算投射距离）：测量碎片在投射方向上跨越的像素行数（或列数），该值即为投射距离 D。
  - 第三步（投射绘制）：将碎片整体沿投射方向平移，跳过框架边框本身，使碎片锚点进入框架内部后再继续移动 D-1 个像素（总共使锚点位于框架内壁起算第 D 个位置）。在最终位置用碎片颜色绘制碎片的完整形状。
  - 输出中框架外部的原始碎片被擦除为背景色，grey 框架保留。

- `Key insight`：投射方向可从碎片与边框的邻接关系直接看出，但投射距离的编码是核心难点——碎片沿投射方向的"厚度"同时充当了位移量，使得碎片形状既是要绘制的图案，也是距离指令。
</new_puzzle>
