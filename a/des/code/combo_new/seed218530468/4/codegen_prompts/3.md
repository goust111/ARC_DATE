description: 网格中若干彩色条带沿不同方向排列，每个条带内部有一个"空洞"像素；根据空洞在条带中的相对位置，决定该条带向哪个方向平移以及平移多远。

Input structure:
- 背景为 black。
- 网格中有若干互不重叠的彩色条带，每个条带为单一颜色的水平或垂直连续线段，长度为 4-8 像素。
- 每个条带中恰好有一个像素为 black（形成空洞），条带的其余像素为该条带的颜色。
- 条带之间保持至少 2 像素的间隔。

Rule:
- 对每个水平条带：空洞将条带分为左段和右段。若左段比右段长，条带向右平移，距离等于左段长度；若右段比左段长，条带向左平移，距离等于右段长度。平移时空洞被填充为条带颜色（条带变完整）。
- 对每个垂直条带：空洞将条带分为上段和下段。若上段比下段长，条带向下平移，距离等于上段长度；若下段比上段长，条带向上平移，距离等于下段长度。平移时空洞同样被填充。
- 即条带总是朝较短段的方向平移，平移距离等于较长段的像素数。
- 条带从原位置擦除（变为 black），在新位置绘制完整的（无空洞的）条带。

Key insight:
空洞不是缺陷而是编码指令的信息载体：它的不对称位置同时编码了平移方向（朝短段侧）和平移距离（长段的长度）。解题者需要发现"空洞偏向哪边"与"条带移向哪边"之间的反向关系——条带远离空洞偏向的一侧，这个反直觉规则是核心隐蔽点。
</new_puzzle>
