- `Input structure`：背景为 Black。网格中有若干小型单色实心矩形对象（每个对象 2×2 或 3×3，颜色为 Grey）。对象之间有单像素宽的彩色连接线（颜色取自 Red、Blue、Green、Orange），每条线水平或垂直地连接恰好两个对象（线从一个对象的边缘像素出发，沿直线到达另一个对象的边缘像素）。同色的连接线将对象串联成组（若 A 和 B 有 Red 线相连，B 和 C 有 Red 线相连，则 A、B、C 属于同一个 Red 组）。
- `Rule`：
  - 首先根据连接线颜色将所有对象分组。擦除所有连接线。
  - 数出每组中对象的数量 N：
    - 若 N = 2：将该组中两个对象用该组连接线的颜色画一条直线连接（与输入线相同路径），并将两个对象本身的颜色从 Grey 改为该组连接线的颜色。
    - 若 N = 3：将该组中三个对象的颜色改为连接线颜色，并在三个对象的外接矩形边界上画一个该颜色的单像素厚空心矩形框。
    - 若 N = 4 或更多：将该组所有对象的颜色改为连接线颜色，并将这些对象的外接矩形内部全部填充为该连接线颜色。
  - 不属于任何组的孤立对象（无连接线）保持 Grey 不变。
- `Key insight`：解题者首先需要通过线的颜色发现分组规则（这并非直观的——线连接的是 Grey 对象而非同色对象）；然后需要发现组内成员数量决定了变换类型，而变换类型是一个离散的阶梯函数（2→连线，3→框，4+→填充）。颜色在此题中同时承担了"分组标签"和"输出着色"的双重角色。
