- `Input structure`：
  - 背景为 black。
  - 网格中有若干个彩色对象，每个对象为单一颜色的 4-connected 连通分量，颜色各不相同。
  - 每个对象可能包含 0 到 3 个内部孔洞（孔洞指被该对象像素完全包围的 black 连通区域）。
  - 网格中有一个由 maroon 像素绘制的箭头标记。箭头由一条长度为 3 的直线段（水平或垂直）加上一端的三角形箭尖组成：若箭头朝右，则为三个水平像素加上右端上下各一个像素形成">"形；朝左则为三个水平像素加上左端上下各一个像素形成"<"形；朝下则为三个垂直像素加上下端左右各一个像素形成"v"形；朝上则为三个垂直像素加上上端左右各一个像素形成"^"形。

- `Rule`：
  - 第一步：识别箭头方向 d（上/下/左/右）。
  - 第二步：对每个彩色对象（不含箭头），数出其内部孔洞数量 n。
  - 第三步：若 n = 0，该对象保持原位不变，不产生副本。若 n >= 1，沿方向 d 在该对象旁边依次放置 n 个该对象的完整副本（包括孔洞）。第一个副本紧邻原对象在方向 d 上的边缘（间隔一行或一列 black），第二个副本紧邻第一个副本（同样间隔一行或一列），以此类推。副本颜色与原对象相同。
  - 箭头在输出中被清除为 black。所有对象的副本不会互相重叠（题目保证有足够空间）。

- `Key insight`：解题者需要发现两个独立的隐含规则：一是箭头标记决定全局复制方向（一个非平凡的符号解读），二是每个对象的孔洞数量决定复制次数（一个需要仔细观察的计数属性）。两层推理相互独立又必须同时正确才能得到输出。
