- `Input structure`：
  - 背景为黑色（black）。
  - 网格被红色（red）单像素线均匀分割为 N×N 的正方形分区（例如每个分区为 5×5 或 7×7 像素）。
  - 每个分区内包含一个由非背景、非红色的单一颜色绘制的小图案，图案仅占据分区的左上角子区域（如左上角的 2×3 或 3×3 子区域内）。
  - 不同分区内的小图案具有不同的对称性质：有的图案关于水平中线对称，有的关于垂直中线对称，有的关于主对角线对称，有的无对称性。

- `Rule`：
  - 第一步：检测每个分区左上角子区域中小图案的对称性类型。
  - 第二步：根据对称性类型决定如何将图案扩展到整个分区——
    - 若图案关于水平中线对称：将图案向右镜像翻转，填充分区的右半部分。
    - 若图案关于垂直中线对称：将图案向下镜像翻转，填充分区的下半部分。
    - 若图案关于主对角线对称（左上到右下）：将图案沿主对角线翻转，填充分区的右下三角区域。
    - 若图案无对称性：将图案分别水平翻转、垂直翻转、中心旋转180度，分别填充分区的右上、左下、右下三个象限，构成四象限平铺。
  - 第三步：红色分隔线和背景保持不变。

- `Key insight`：每个分区的变换方式不是统一的，而是由其内部图案自身的对称性质"自我声明"的——解题者必须逐个检查图案的对称特征，才能确定正确的扩展策略。表面上看起来所有分区做了相似的"展开"操作，但背后的选择逻辑取决于图案自身的几何属性。
