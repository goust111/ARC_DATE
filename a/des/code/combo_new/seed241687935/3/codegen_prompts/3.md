  - 箭头标记本身从网格中擦除（恢复为背景色）。

- `Key insight`：箭头同时编码了三条信息——方向（指定作用面板和绘制起始侧）、颜色（指定新颜色）、长度（指定保留区域的大小）。解题者需要发现长度不是"画多少"而是"保留多少"，这是一个反直觉的映射。
