从嵌套框架的层级结构中提取深度信息，用深度值决定框架内部的棋盘格填充密度。

Input structure：
- 背景为 black。网格中有若干嵌套的空心矩形框架，框架由不同颜色绘制。
- 框架可以嵌套：一个框架完全包含在另一个框架内部。最外层框架不被任何其他框架包含，嵌套深度为 1；被一层框架包含的深度为 2，以此类推。
- 每个框架的内部区域在输入中为 black（空白）。
- 框架之间不重叠、不接触，每层嵌套之间至少间隔 1 像素。

Rule：
- 计算每个框架的嵌套深度 D（最外层为 1，往内依次递增）。
- 在每个框架的内部空白区域（不含框架本身的像素），用该框架自身的颜色绘制棋盘格图案：从框架内部左上角开始，每隔 D-1 个像素放置一个该颜色的像素（即步长为 D）。具体而言，对于框架内部坐标 (r, c)（相对于内部左上角），当 r 和 c 都能被 D 整除时，放置一个像素。
- 深度为 1 的最外层框架步长为 1，即内部完全填满自身颜色。
- 若某个内部像素位置属于更内层框架的区域（包括更内层框架的边框），则不绘制外层框架的棋盘点——内层框架区域优先。

Key insight：
- 第一层推理是识别嵌套层级关系并为每个框架确定深度值；第二层推理是发现填充密度与嵌套深度之间的反比关系——深度越深的框架，棋盘格点越稀疏（步长越大），这需要解题者观察不同层级框架内部填充点的间距规律并归纳出"步长等于深度"的量化关系。
