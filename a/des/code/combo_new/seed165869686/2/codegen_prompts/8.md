- `Input structure`：
  - 背景为 Black。
  - 网格中有一行或一列由交替的两种颜色（如 Orange 和 Azure）组成的像素条纹，这条条纹贯穿整个网格的某一行或某一列，作为"镜面线"。
  - 镜面线两侧各有若干个单色前景对象（4-连通），对象不接触镜面线，且对象颜色与镜面线的两种颜色均不同。

- `Rule`：
  - 将镜面线识别为反射轴（条纹的交替模式使其区别于普通前景对象）。
  - 对每个前景对象，计算其关于镜面线的镜像位置，在镜像位置绘制该对象的副本。
  - 若某个副本的像素与另一个已有对象（原始对象或其他副本）的像素重叠，则重叠位置的像素颜色变为镜面线条纹中的第一种颜色（Orange）；若无重叠，副本保持原对象的颜色。
  - 原始对象保留不变。镜面线保留不变。

- `Key insight`：条纹行/列不是普通对象，而是一面镜子——这是第一层推理。反射后的重叠检测决定副本颜色——这是第二层推理。解题者容易忽略条纹的特殊身份，也容易遗漏重叠导致的变色规则。

1. `main(grid)` 必须实现新题描述中的确定性转换规则，不能只识别 `generate_input()` 的固定模板。

3. 生成器必须保证输入满足 `main()` 的隐式假设：对象不重叠、不越界、特殊标记唯一或可区分、匹配关系无歧义、关键分支出现概率相同。
4. 禁止把 ARC 颜色 id 、亮度、拼写等当作人类不可见的数值语义参与排序、大小比较或隐藏映射。颜色变化必须有可见结构线索。注意颜色亮度、拼写等也是不可见信息，若描述中出现违规的颜色id或者亮度，可自行使用少量的固定颜色替代，但注意生成时要在三个以内输入输出网格中对所有变换100%覆盖度。
