- `Input structure`：网格背景为 black。网格中有若干个一像素粗的彩色矩形边框（每个边框颜色不同，如 red 框、blue 框、green 框），边框彼此不重叠。每个边框内部为 black 背景。在所有边框之外的背景区域中，散布着若干单像素的种子点，每个种子点的颜色恰好匹配某一个边框的颜色。此外，在背景区域中还有若干小型单色对象（2-4 像素的连通块），颜色为 orange 或 magenta 等与边框颜色不同的颜色。
- `Rule`：
  1. 每个种子像素与同色边框配对。
  2. 从种子像素出发，沿四个对角线方向（左上、右上、左下、右下）中能最终命中其配对边框的那个方向，画一条对角线射线，直到射线碰到边框的边界像素为止。射线用种子的颜色绘制。
  3. 如果射线的路径在延伸过程中经过（穿越）了某个小型单色对象的像素位置，则射线从该对象位置开始到边框为止的那一段，改用该对象的颜色绘制（种子到对象之间的段保持种子颜色）。若路径上有多个对象，每段颜色依次更新为最近经过的对象颜色。
  4. 被射线穿过的小型对象本身从网格上擦除。
- `Key insight`：种子与边框的配对是通过颜色匹配完成的（第一层推理），而射线方向必须通过对角线几何对齐来确定（第二层推理），路径上的颜色对象作为"染色过滤器"改变射线后半段的颜色（第三层推理）。三层规则逐步叠加，增加了归纳难度。
