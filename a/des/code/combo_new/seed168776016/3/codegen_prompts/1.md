- `Input structure`：背景为黑色。网格中散布着若干由不同颜色绘制的封闭矩形边框（边框宽度为1像素），每个边框内部为黑色背景且恰好含有一个不同颜色的单像素标记点，该标记点位于边框内部的某一条边（上/下/左/右）的中间位置附近。网格的一个角落有一个调色板区域：调色板由若干横向排列的条目组成，每个条目左侧一列像素为某种边框颜色，右侧紧接一个 3x3 的双色纹理图案，条目之间用一行黑色像素分隔。
- `Rule`：
  1. 读取角落的调色板区域，建立"边框颜色 → 3x3 纹理"的映射表。
  2. 对每个封闭矩形边框，通过边框像素颜色在调色板中找到对应的 3x3 纹理。
  3. 确定边框内部标记点所在的边：标记点在上边内侧表示0度、在右边内侧表示顺时针90度、在下边内侧表示180度、在左边内侧表示顺时针270度。
  4. 将查到的原始纹理按上述角度顺时针旋转，然后以平铺方式填满边框内部区域（从内部左上角开始铺，多余部分裁剪），同时移除标记点像素（恢复黑色后被纹理覆盖）。
  5. 边框本身保持不变，调色板区域保持不变。
- `Key insight`：解题需要两层独立归纳——第一层是发现调色板以边框颜色为键映射到纹理图案，第二层是发现标记像素的方位编码了纹理的旋转角度。两层规则互相独立，必须分别从样例中识别和验证。
