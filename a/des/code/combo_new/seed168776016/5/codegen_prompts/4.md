- `Input structure`：背景为 Black。网格上散布着若干个不同大小的单色实心矩形（不含 Black），矩形之间互不重叠、互不接触。这些矩形的宽度和高度各不相同，且恰好可以按面积从小到大排成严格递增序列。每个矩形的颜色互不相同。

  2. 以最小矩形（面积最小者）的中心位置为锚点。

  4. 叠放时大矩形先绘制、小矩形后绘制（即小矩形覆盖大矩形的中心部分），形成同心嵌套的彩色矩形环。
  5. 输出网格裁剪为恰好包围最大矩形的最小边界框。
- `Key insight`：解题者需要完成两层推理——第一层是识别出所有矩形需要按面积排序后嵌套组装（而非保持原位），第二层是发现锚点不是网格中心也不是最大矩形的中心，而是最小矩形的原始位置决定了整个组装结构在输出中的定位。最终输出被裁剪到最大矩形的边界。
