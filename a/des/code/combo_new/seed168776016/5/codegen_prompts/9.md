- `Rule`：
  1. 对每个 L 形，计算其缺角区域（外接矩形减去 L 形本身）的形状。
  2. 在所有 L 形中找到缺角区域形状相同的唯一配对（两个 L 形的缺角大小相同）。
  3. 将每个 L 形补全为完整矩形，补全区域使用其配对 L 形的颜色填充。
  4. 所有 L 形保持原位不动，仅补全缺角部分。
- `Key insight`：解题者需要完成三层推理——第一层是识别每个对象都是 L 形并确定其缺角区域的形状；第二层是发现 L 形之间通过缺角面积相等进行配对；第三层是补全时使用的颜色不是自身颜色而是配对者的颜色，形成了一种"颜色交换式补全"。
