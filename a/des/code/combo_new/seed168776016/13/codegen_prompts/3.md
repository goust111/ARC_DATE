- `description`：用网格边缘的颜色箭头指示的方向对每行或每列的非背景像素进行循环移位，移位量由同行或同列对侧边框上的标记像素数量决定。

- `Input structure`：
  - 背景色为 black，网格内部有一个由多种颜色组成的图案。
  - 网格的最外一圈像素（第 0 行、最后一行、第 0 列、最后一列）构成"控制边框"，控制边框中大部分像素为 grey。
  - 控制边框上某些位置有彩色箭头标记：箭头由 3 个同色像素组成，呈 L 形排列，L 形的朝向指示方向（向右：一个像素在左，两个像素在右侧上下排列；向下：一个像素在上，两个像素在下方左右排列；向左和向上类推）。
  - 箭头出现在某一行的左端或右端边框上，表示该行需要水平移位；箭头出现在某一列的上端或下端边框上，表示该列需要垂直移位。
  - 在同一行或同一列的控制边框另一端，可能有若干 azure 单像素标记。

- `Rule`：
  - 对于每个箭头，确定它控制的行或列，以及移位方向（由 L 形朝向决定）。
  - 统计该行或列的控制边框对侧（即箭头不在的那一端）上 azure 标记像素的数量 K。
  - 将该行或列内部（不含边框）的所有非背景像素沿箭头方向循环移位 K 步（像素移出一端后从另一端回来）。背景像素不参与移位，只有非背景像素的位置发生变化。
  - 没有箭头的行/列保持不变。控制边框本身从输出中移除，输出网格仅包含内部区域。

- `Key insight`：箭头的 L 形朝向编码了移位方向，而移位量并非来自箭头本身，而是来自同一行/列对侧边框上的 azure 标记数量。解题者需要分别识别"方向来源"和"步数来源"位于边框的两端这一空间分离关系。
