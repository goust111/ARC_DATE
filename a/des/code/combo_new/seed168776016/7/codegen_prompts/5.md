- `Input structure`：
  - 背景色为 black。
  - 网格中有一个较大的矩形"画布"，由 grey 色单像素边框围成，内部为背景色（black），画布尺寸至少 10x10。
  - 画布内部散布着若干单像素的彩色标记点（如 red、blue、green 等），每种颜色最多出现一次。
  - 画布外部散布着若干小型图章对象（每个图章是一个紧凑的多色连通区域），每个图章恰好有一个单像素宽的边框颜色包围着内部图案。图章的边框颜色与画布内某个标记点颜色一一对应。图章的原始朝向统一（如都朝上）。

- `Rule`：
  - 画布中心将画布内部分为四个象限：左上、右上、左下、右下。
  - 标记点在左上象限 → 图章不旋转（0度）；右上象限 → 顺时针旋转 90度；右下象限 → 旋转 180度；左下象限 → 顺时针旋转 270度。
  - 将每个图章按对应旋转量旋转后，以标记点位置为图章的中心像素，放置到画布上。
  - 图章覆盖画布内的背景像素；若多个图章重叠，后处理的图章（按标记点从上到下、从左到右的顺序）覆盖先前的。
  - 输出为画布区域（含 grey 边框），画布外的图章和背景被裁掉。

- `Key insight`：标记点颜色与图章边框颜色的匹配决定了"哪个图章放在哪里"（颜色查找层），而标记点在画布中的象限位置决定了图章放置时的旋转角度（空间-旋转映射层）——解题者需要分别发现这两层规律。
