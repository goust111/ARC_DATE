  - 网格中有若干个由同一种边框色（如 blue）绘制的封闭矩形框，框的四条边各为一像素宽。
  - 每个矩形框的某一条边上恰好有一个单像素缺口（缺口处该像素为背景色），不同框的缺口可能在不同边上。
  - 每个矩形框的边框上还恰好有一个像素被染成了一种非边框、非背景的颜色（如 red、green 等），该颜色像素所在的边称为"标记边"。

- `Rule`：
  - 对每个矩形框，先找到框边上标记像素的颜色 C，以及缺口所在的边（上/下/左/右）。
  - 标记像素的颜色 C 告诉解题者该框的"活跃颜色"。
  - 从种子像素出发，沿缺口所在边的方向（若缺口在上边则向上、在右边则向右，以此类推）画一条颜色为 C 的直线，直到碰到框的边框像素为止（不覆盖边框本身）。
  - 缺口像素本身也被填充为 C（即缺口被"封住"）。
  - 射线画完后，将原来框边上的标记像素恢复为边框色。

- `Key insight`：种子颜色与边框标记颜色的匹配确定了每个框的活跃色，而缺口的位置暗示了射线的方向——解题者需要同时发现颜色匹配关系和缺口-方向映射这两层规律。
