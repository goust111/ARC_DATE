- `Input structure`：
  - 背景为 Black。
  - 网格中有若干由 Grey 像素围成的封闭矩形区域（Grey 像素构成一像素厚的完整矩形边框）。
  - 每个封闭区域内部恰好有一个由单一非 Black、非 Grey 颜色组成的小色块（1~3 个像素的 4-连通块），称为"种子"。种子位于区域内部的某个角落或某条边附近（不在正中心）。
  - 网格中在所有 Grey 矩形区域之外，散布着若干独立的小型形状模板（4-连通块），每个模板恰好使用一种颜色，且该颜色与某个种子颜色一一对应。模板的像素数量不超过 6。

- `Rule`：
  - 对于每个 Grey 矩形区域，找到其内部的种子色块，记录种子的颜色 C。
  - 在矩形区域外部找到颜色为 C 的模板形状，提取该模板的边界框。
  - 判断种子色块相对于矩形区域内部中心的方位：种子在左上角则铺贴方向为从左上角开始向右下；种子在右上角则从右上角开始向左下；种子在左下角则从左下角开始向右上；种子在右下角则从右下角开始向左上。
  - 从确定的角落开始，将模板形状作为瓦片（tile）周期性重复铺贴，填满矩形区域内部所有 Black 像素（种子像素也被覆盖），颜色使用模板原色 C。超出区域内部边界的部分裁剪掉。
  - Grey 边框和区域外部保持不变。

- `Key insight`：种子的颜色决定铺贴的形状（通过匹配外部模板），种子的位置决定铺贴的对齐起点方向——这是两层独立的推理：先做颜色匹配找形状，再做空间推理定方向。

1. `main(grid)` 必须实现新题描述中的确定性转换规则，不能只识别 `generate_input()` 的固定模板。

3. 生成器必须保证输入满足 `main()` 的隐式假设：对象不重叠、不越界、特殊标记唯一或可区分、匹配关系无歧义、关键分支出现概率相同。
4. 禁止把 ARC 颜色 id 、亮度、拼写等当作人类不可见的数值语义参与排序、大小比较或隐藏映射。颜色变化必须有可见结构线索。注意颜色亮度、拼写等也是不可见信息，若描述中出现违规的颜色id或者亮度，可自行使用少量的固定颜色替代，但注意生成时要在三个以内输入输出网格中对所有变换100%覆盖度。
