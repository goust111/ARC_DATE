- `Input structure`：背景色为黑色。网格中有若干用蓝色绘制的 4-连通对象（形状各异，不重叠），以及散布在背景中的若干红色单像素标记点。红色标记点的数量与蓝色对象的数量相同。
- `Rule`：
  1. 将每个蓝色对象与一个红色标记点配对：每个蓝色对象的边界框中心（取整到最近像素）与最近的尚未配对的红色标记点配对。
  2. 将每个蓝色对象平移，使其边界框中心移动到其配对的红色标记点位置。
  3. 平移后，多个蓝色对象可能发生重叠。输出网格中：没有覆盖的位置保持黑色；被恰好一个对象覆盖的位置着蓝色；被两个对象重叠覆盖的位置着绿色；被三个或更多对象重叠覆盖的位置着黄色。
  4. 红色标记点在输出中被擦除。
- `Key insight`：红色标记点不是装饰或边界，而是每个碎片的目标锚点——通过"中心-最近点"的配对逻辑将碎片聚合。第二层规则是重叠计数到颜色的映射：1→蓝、2→绿、3+→黄，这需要从多个样例中归纳出来。

3. 生成器必须保证输入满足 `main()` 的隐式假设：对象不重叠、不越界、特殊标记唯一或可区分、匹配关系无歧义、关键分支出现概率相同。
4. 禁止把 ARC 颜色 id 、亮度、拼写等当作人类不可见的数值语义参与排序、大小比较或隐藏映射。颜色变化必须有可见结构线索。注意颜色亮度、拼写等也是不可见信息，若描述中出现违规的颜色id或者亮度，可自行使用少量的固定颜色替代，但注意生成时要在三个以内输入输出网格中对所有变换100%覆盖度。
