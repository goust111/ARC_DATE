根据每个彩色区域内部嵌入的"箭头"标记方向，将该区域的形状沿箭头方向投影复制到网格边界，投影副本使用箭头颜色绘制。

Input structure
- 背景为主色（black）。
- 网格中有若干个单色 4-连通区域（每个区域使用不同颜色，如 red、blue、green 等）。
- 每个区域内部恰好嵌有一个由 yellow 像素构成的三像素"箭头"标记：箭头由一个中心像素和一个与中心相邻的像素组成一条两像素线段，加上从中心像素沿垂直于线段方向延伸的一个像素构成箭头尖端。箭头尖端指向的方向即为投影方向（上、下、左、右之一）。

Rule
- 第一层：识别每个彩色区域内的 yellow 箭头，确定箭头尖端所指的方向（上 / 下 / 左 / 右）。
- 第二层：将该彩色区域的完整形状（不含 yellow 箭头像素）沿箭头方向平移，每次平移距离等于该区域在投影方向上的跨度（即包围盒在该方向的长度），不断重复直到副本超出网格边界为止。
- 所有投影副本用 yellow 颜色绘制。原始区域保持不变（包括其内部的 yellow 箭头）。若投影副本与其他原始区域重叠，则投影副本覆盖在上层。

Key insight
- 箭头的朝向需要从三个 yellow 像素的空间排列中推断（而非简单的线段方向），这要求解题者理解箭头的几何编码方式；投影间距等于区域自身在该方向的跨度，形成无缝重复铺排效果。
