Input structure:
- 背景为 black。网格被划分为规整的 N×N 棋盘格（N 为 4 或 5），每个格子为 3×3 像素的单色方块，方块之间以 1 像素宽的 grey 分隔线隔开。
- 棋盘中恰好有两个方块内部带有一个 1 像素的 black 标记点，标记点位于方块 3×3 区域的上边缘中央（第 0 行第 1 列）、下边缘中央（第 2 行第 1 列）、左边缘中央（第 1 行第 0 列）或右边缘中央（第 1 行第 2 列）位置之一。
- 其余方块为各种非 black、非 grey 的纯色填充，无标记。

Rule:
- 对每个带标记的方块，标记点所在的边缘指示该方块的"弹出方向"（上边缘标记 → 向上弹出，右边缘标记 → 向右弹出，以此类推）。
- 弹出操作：将该方块所在行（水平弹出时）或所在列（垂直弹出时）上、从该方块到弹出方向边缘的所有方块，整体沿弹出方向平移一个格子。最外侧的方块被推出棋盘消失，被标记方块原位变为空位（black 填充 3×3）。
- 两个带标记方块按从上到下、从左到右的顺序依次处理（先处理第一个弹出，再处理第二个）。
- 所有弹出完成后，对每个空位格子：查看其在棋盘格中上下左右四个相邻格子（不含对角，且必须在棋盘范围内）的颜色，取出现次数最多的颜色填入该空位。若有并列，选择在相邻格子中位置靠上的那个格子的颜色；若仍并列，选靠左的。

Key insight: 第一层推理需要从方块内极小的 1 像素标记点位置推断弹出方向，标记很不显眼，增加了观察难度；第二层推理需要理解弹出引起的同行或同列连锁平移（非单一方块移动）；第三层推理需要发现空位的填充规则来自相邻方块的多数颜色投票。
