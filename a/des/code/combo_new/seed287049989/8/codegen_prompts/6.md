Input structure:
- 背景为 black。网格中央有一组同心矩形环（3 层），从外到内每层环由不同颜色绘制（如最外层 blue、中层 red、最内层 green），每层环线宽 1 像素。
- 环心区域为一个 3×3 的 grey 填充方块。
- 每层环的四条边上恰好有一个 1 像素宽的缺口（该位置为 black 而非环的颜色）。缺口位于该边的中点附近。不同层环的缺口不在同一条直线上。

Rule:
- 从最外层环开始处理，依次处理每一层。对于当前层的缺口，从缺口处沿该边的法线方向向环心发射射线（例如上边缺口 → 射线向下，左边缺口 → 射线向右）。
- 射线向内行进时，如果遇到下一层环的像素：检查射线当前行进路径上该内环是否有缺口——若有缺口（即射线路径经过该内环的缺口位置），射线直接穿过继续前进；若没有缺口（射线被内环壁阻挡），则射线发生转向：找到该内环自身缺口的位置，射线改为朝该缺口方向水平或垂直行进，到达缺口后穿过，继续向环心方向行进。
- 射线最终到达 grey 环心区域时，将命中的那个像素标记为发射该射线的那层环的颜色。
- 每层环独立发射一条射线，因此环心最终可能有多个不同颜色的标记像素。
- 环结构和缺口在输出中保持不变。

Key insight: 每层环的缺口既是本层射线的发射口，又可能成为外层射线被阻挡后的转向目标——解题者需要逐层追踪射线路径，理解"阻挡 → 寻找同层缺口 → 转向"的反射机制。环心最终的彩色标记位置编码了射线经过多次转向后的最终落点，需要空间追踪推理才能预测。
