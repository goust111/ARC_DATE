- `Input structure`：

  - 网格中散布若干由非背景色像素构成的小型箭头形状。每个箭头由一条短直线段（箭身，2-4 像素长，水平或垂直排列）和一个指向某个正交方向（上/下/左/右）的单像素尖端组成。尖端位于箭身延长线上且在箭身的一端，具体绘制方式为：箭身是一段连续的同色像素，尖端像素紧接箭身的某一端，与箭身共线。尖端所在的那一端即为箭头指向。箭头整体为同一颜色。
  - 网格中还有一个独立的双色标记像素对（两个不同颜色的像素水平相邻），它是交叉色指示器：右侧像素的颜色即为射线交叉点应使用的颜色。

- `Rule`：
  - 计算每个箭头的总像素数 N（箭身 + 尖端）。
  - 从尖端出发，沿箭头指向方向绘制一条长度为 N 个像素的射线（不含尖端自身），颜色与箭头相同。射线遇到网格边界则截断。
  - 若两条不同箭头的射线覆盖了同一像素，该像素改为交叉色指示器所标定的交叉颜色。
  - 箭头本体保持不变，交叉色指示器保持不变。

- `Key insight`：箭头的像素数量同时编码了射线长度——这是第一层非显然推理；射线交叉时的变色规则由独立标记指定而非固定颜色——这是第二层推理。解题者必须先归纳"像素数 = 射程"的对应关系，再发现交叉变色的规则来源。
