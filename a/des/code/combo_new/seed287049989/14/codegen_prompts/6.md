将网格中每个多色对象拆分为单色层，按照层颜色在调色板行中的顺序进行空间偏移后重新叠合输出。

Input structure
- 背景为 Black。网格最底部一行是"调色板行"：从左到右排列着若干不同颜色的单像素点（如 Red、Blue、Green、Yellow），像素之间用 Black 分隔，它们的左右排列顺序定义了颜色的"偏移等级"——最左颜色等级为 0，向右依次为 1、2、3。
- 网格其余区域包含若干互不重叠的多色对象，每个对象由 2-4 种颜色的像素组成（所有颜色都出现在调色板行中），对象整体是 4-连通的。

Rule
- 将每个多色对象按颜色拆分为多个单色层（每层是该颜色在对象中的所有像素）。
- 对每个单色层，根据其颜色在调色板行中的等级 k，将该层的所有像素整体向右平移 k 个像素。
- 如果平移后不同层的像素重叠在同一位置，保留等级更高（调色板中更靠右）的颜色。
- 调色板行在输出中保持不变。平移后超出网格右边界的像素被裁剪。

Key insight
- 第一层推理：发现调色板行不是装饰而是偏移量的编码——颜色在调色板中的位置序号决定了该颜色层的水平平移量，需要对比多个样例中不同颜色的移动距离才能归纳出规律。第二层推理：理解多色对象的拆分-偏移-重叠机制，特别是重叠时高等级颜色覆盖低等级颜色的优先级规则，这需要从有重叠发生的样例中归纳。
