Input structure
- 背景为 Black。网格顶部第一行是一条"色条"：从左到右依次排列 1 到 4 个不同颜色的单像素，它们之间用 Black 像素分隔。这些颜色分别对应 0 度、90 度顺时针、180 度、270 度顺时针旋转（按从左到右的顺序）。

Rule
- 读取顶部色条，按从左到右的位置顺序为每种颜色分配旋转角度：第 1 个颜色对应 0 度，第 2 个对应 90 度顺时针，第 3 个对应 180 度，第 4 个对应 270 度顺时针。

- 边框像素、色条和背景保持不变。

Key insight
- 第一层推理：发现顶部色条不是装饰，而是旋转角度的编码图例，位置序号决定角度。第二层推理：框架边框颜色是查找键，内部图案需要按匹配到的角度做就地旋转。由于图案是非对称的，解题者必须同时正确解读色条含义和旋转方向才能还原输出。
