在网格中找到被遮挡的完整周期性条纹图案，利用未遮挡区域推断条纹方向和周期，然后仅对长轴与条纹方向平行的矩形遮挡物执行条纹恢复操作。

Input structure
- 网格被一个双色水平或垂直交替条纹图案覆盖（例如 Blue 和 Green 交替，每条宽度为 2-3 像素）。

- 每个矩形遮挡物要么是"宽矩形"（宽大于高），要么是"高矩形"（高大于宽）。

Rule
- 首先从未被遮挡的区域推断底层条纹图案的方向（水平条纹或垂直条纹）和周期。
- 对于每个遮挡物矩形：如果条纹是水平方向且该矩形是宽矩形（长轴平行于条纹方向），则将遮挡物移除并恢复其下方的条纹图案；如果条纹是垂直方向且该矩形是高矩形（长轴平行于条纹方向），同样恢复条纹。
- 长轴垂直于条纹方向的矩形保持原样不变（不恢复条纹）。

Key insight
- 第一层推理：识别底层存在周期性条纹并从可见区域重建完整图案。第二层推理：发现并非所有遮挡物都被移除，而是只有长轴方向与条纹方向一致的矩形才被"透视"还原，解题者需要跨样例归纳出这个基于形状朝向的筛选条件。
