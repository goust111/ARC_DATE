识别网格中成对的同色标记点，将每对标记点之间的矩形区域填充为该颜色，但填充时需要保留区域内已有的 Grey 对象作为镂空，且重叠矩形按面积从大到小分层绘制。

Input structure
- 背景为 Black。网格中散布着若干成对的彩色标记像素——每种非 Black、非 Grey 颜色恰好出现两个像素点，形成一对。不同颜色对之间不共享像素。
- 网格中还存在若干由 Grey 像素构成的小型 4-连通对象（面积 2-6 像素），这些 Grey 对象可能位于某些标记对定义的矩形区域内部。

Rule
- 对每对同色标记像素，以两个标记点为对角顶点确定一个轴对齐矩形区域（矩形的行范围从两点行坐标的较小值到较大值，列范围从两点列坐标的较小值到较大值）。
- 按矩形面积从大到小的顺序依次绘制：将矩形区域内的所有 Black 像素填充为标记颜色。
- 矩形区域内已有的 Grey 对象像素保持 Grey 不变（形成镂空效果）。
- 由于按面积从大到小绘制，较小的矩形会覆盖较大矩形的重叠部分，使小矩形显示在上层。
- 标记像素本身被矩形填充覆盖（融入填充色中）。

Key insight
- 第一层推理：发现同色像素对定义矩形区域并触发填充——需要识别"成对标记到矩形"的映射机制。第二层推理：归纳出 Grey 对象作为镂空被保留的规则，这从单个样例中不易确定是"所有非 Black 色保留"还是"仅 Grey 保留"。第三层推理：当矩形重叠时，需要推断出按面积排序的绘制优先级，这要求从包含重叠情况的样例中仔细对比才能发现。
</new_puzzle>
