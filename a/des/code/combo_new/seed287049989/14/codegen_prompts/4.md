将散落的彩色碎片拼回到灰色模板的对应槽位中，槽位匹配依据是碎片形状与槽位形状一致，碎片颜色决定填充后槽位边框的重着色。

Input structure
- 背景为 Black。网格中央偏上有一个较大的 Grey 区域，其中包含若干"槽位"——即 Grey 区域内部被挖去的 Black 连通区域，每个槽位形状不同（如 L 形、T 形、Z 形等，面积 3-6 像素）。
- 网格下方散布若干彩色碎片（如 Red、Blue、Green、Yellow），每个碎片是一个单色 4-连通对象，形状恰好与 Grey 区域中某个槽位完全吻合（经过平移，不旋转不翻转）。碎片数量与槽位数量相同，形成一一对应。
- 每个槽位的 Grey 边框定义为：与该槽位的 Black 像素 4-邻接的所有 Grey 像素。

Rule
- 对每个彩色碎片，在 Grey 区域的槽位中找到形状完全匹配的那个槽位（形状比较基于像素相对位置，仅平移对齐）。
- 将碎片的颜色填入对应槽位（替换槽位中的 Black 像素为碎片颜色）。
- 同时将该槽位的 Grey 边框像素也重着色为碎片颜色。
- 碎片原始位置变为 Black 背景。其余 Grey 像素（不属于任何槽位边框的部分）保持 Grey 不变。

Key insight
- 第一层推理：识别碎片与槽位之间的形状匹配关系——需要将分散的碎片逐一与模板槽位进行视觉比对。第二层推理：发现输出不仅仅是填槽，还要将匹配颜色扩展到槽位的 Grey 边框上，这个"边框重着色"规则需要从样例中额外归纳。两层规则叠加使得仅看一个样例难以确定完整变换。
