Input structure
- 背景为黑色，网格尺寸为偶数行×偶数列。
- 网格正中心有一个由绿色像素组成的十字分隔线（一行加一列），将网格分为四个象限。

Rule
- 每个种子根据其所在象限确定初始发射方向：左上象限向左上对角发射，右上象限向右上对角发射，左下象限向左下对角发射，右下象限向右下对角发射。
- 射线以种子自身的颜色逐像素绘制，遇到网格边缘则停止。
- 若射线的下一个像素已被另一条射线占据（非黑色、非绿色），则该射线转向 90 度（对角线变为水平或垂直方向中能继续延伸的那个方向），然后继续绘制直到再次碰壁或到达边缘。若两个正交方向都被阻挡则停止。
- 种子按从上到下、从左到右的顺序依次处理。

Key insight
- 象限位置决定初始方向是隐含的空间规则，而射线碰撞后的正交反弹使得处理顺序影响最终图案——解题者需要同时归纳方向规则和交互规则。
