  - 左列上散布着若干彩色单像素标记，每个标记位于不同的行，颜色可能重复（如 red 出现在第 3 行和第 7 行）。

  - 在刻度轴上出现的颜色集合中，每种颜色在左列至少出现一次，在上行也至少出现一次。

- `Rule`：
  - 对每种出现在刻度轴上的颜色 C：
    - 数出颜色 C 在左列中出现的次数 Nr，以及在上行中出现的次数 Nc。
    - 方块边长 S = Nr + Nc。
    - 收集颜色 C 在左列中所有标记的行坐标集合 R，以及在上行中所有标记的列坐标集合 Col。
    - 对 R 和 Col 的每一个 (r, c) 组合，在画布上以 (r, c) 为左上角绘制一个 S x S 的实心方块，颜色为 C。若方块超出画布范围则截断。
  - 绘制顺序：按方块边长 S 从大到小绘制。S 相同时按颜色在左列中首次出现的行号从大到小绘制。后绘制的方块覆盖先绘制的方块。（即小方块绘制在大方块之上，最终可见。）
