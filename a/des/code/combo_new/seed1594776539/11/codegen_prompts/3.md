- `Input structure`：
  - 背景为 Black。
  - 网格中有若干互不重叠的矩形彩色区域（每个区域为一种纯色填充，颜色各不相同，如 Red、Blue、Green、Orange 等），每个区域大小约为 4×4 到 7×7。
  - 每个区域内部包含若干 Black 像素形成的孔洞。其中恰好有一个孔洞的形状是箭头：箭头由 3 个 Black 像素组成，形如"▲"（朝上）、"▼"（朝下）、"◄"（朝左）或"►"（朝右）。具体绘制方式：朝上箭头为上方 1 像素 + 下方相邻 2 像素横排；朝右箭头为右方 1 像素 + 左方相邻 2 像素纵排；其他方向类推。

- `Rule`：
  - 对每个彩色区域：
    - 识别其内部的箭头孔洞，确定箭头朝向（上、下、左、右）。
    - 数出该区域内除箭头以外的单像素孔洞数量 N。
    - 将整个区域（包括所有内部孔洞）沿箭头方向平移 N 个像素。
    - 原位置变为 Black 背景。
  - 如果 N=0（没有额外孔洞），区域不移动。
  - 平移后各区域不会重叠，也不会超出网格边界（输入保证这一点）。

- `Key insight`：解题者需要完成两层独立的非显然推理：第一层是在每个区域的多个孔洞中识别出哪一个是箭头（确定方向），第二层是发现平移距离不是固定值，而是由剩余孔洞的数量决定的——孔洞同时扮演了"方向指示"和"距离编码"两种截然不同的角色。
