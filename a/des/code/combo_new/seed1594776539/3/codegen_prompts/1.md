- `Input structure`：
  - 背景为黑色（black）。
  - 网格中有若干由 grey 像素围成的一像素厚的封闭矩形区域（房间），房间内部填充背景色，且恰好包含一个非背景、非 grey 的单像素"种子"（颜色可能为 red、blue、green 等）。
  - 在每个房间的 grey 边框的上、下、左、右四条边中，恰好有一条边的正中央像素被替换为与房间内种子相同的颜色，称为"锚点"。
  - 网格中远离各房间的区域散布着若干彩色单像素"目标标记"，每个目标标记的颜色恰好与某个房间的种子颜色相同，且每种颜色的目标标记只有一个。

- `Rule`：
  - 对每个封闭矩形房间，找到其 grey 边框上唯一的彩色锚点，锚点所在的边决定了方向：锚点在上边则方向向上，锚点在下边则方向向下，锚点在左边则方向向左，锚点在右边则方向向右。
  - 从房间当前位置出发，沿该方向搜索，找到与种子同色的目标标记像素。
  - 将整个房间（包括 grey 边框和内部种子）平移，使得房间锚点所在边的中点与目标标记像素对齐。
  - 原位置的房间被擦除为背景色；目标标记像素被房间覆盖。
  - 若平移后房间部分超出网格边界，则超出部分被裁剪。

- `Key insight`：解题者必须先发现边框上的"异色像素"是方向指示器（而非缺陷），再发现网格中同色散落像素是目的地锚点——两步归纳缺一不可：第一步从边框异色推断运动方向，第二步从同色远端标记推断停止位置。
