  - 管道的若干个末端（死端，即只有一个 grey 邻居的 grey 像素）处各有一个彩色像素（如 red、blue、green）紧邻，这些是"入口标记"，每种颜色最多出现一次。
  - 管道在某些位置形成十字交叉（一个 grey 像素在上下左右四个方向都有 grey 邻居）。每个十字交叉的中心像素为以下两种标记之一：
    - orange 像素：表示"直通"——流体从任意方向进入后继续沿原方向直行穿过。
    - azure 像素：表示"右转"——流体进入后向其前进方向的右侧转 90°。
  - 非交叉处的 L 形管道拐弯（恰好两个 grey 邻居且成 90° 角）处流体自然沿管道转弯。

- `Rule`：
  - 从每个入口标记出发，沿管道方向推进（入口标记的唯一相邻 grey 像素确定初始方向）。
  - 将沿途所有 grey 管道像素重新着色为该入口标记的颜色。
  - 遇到 L 形拐弯时自然转向（只有一个可行方向）。
  - 遇到十字交叉时：若中心为 orange 则直行穿过，若中心为 azure 则向前进方向的右侧转 90°。交叉中心像素本身也被着色为入口颜色。
  - 当管道到达另一个已着色管道段或到达死端时停止。
  - 所有入口标记像素保持原色不变。

- `Key insight`：解题者需要三层归纳：第一层是识别管道网络结构和入口标记作为颜色源；第二层是发现十字交叉处的 orange/azure 标记控制了流向（而非简单地在交叉处分叉或选择任意方向）；第三层是确定 azure 的具体语义是"右转"而非其他转向规则——这需要在多个样例中追踪流体路径才能验证。
