- `Input structure`：网格背景为 black。网格中存在若干横跨整个网格的"色带"——每条色带是宽度为 1 像素的完整行或完整列，每条色带有唯一颜色（如 red、blue、green 等，色带之间颜色互不相同）。网格中还存在若干"箭头"，每个箭头由 grey 像素构成。箭头的结构为：一段长度 ≥ 2 的水平或垂直直线段（箭头杆身），杆身一端连接一个三像素的尖端，指示方向。具体来说：向右箭头的尖端是杆身最右端像素的右上方一格、正右方一格、右下方一格共 3 个 grey 像素；向左箭头的尖端是杆身最左端像素的左上方、正左方、左下方 3 个 grey 像素；向上箭头的尖端是杆身最上端像素的左上方、正上方、右上方 3 个 grey 像素；向下箭头类似。杆身与色带交叉处，色带像素被 grey 覆盖。
- `Rule`：
  1. 对每个箭头，根据尖端形状确定其朝向（上/下/左/右）。
  2. 检查箭头杆身所经过的行或列，找出被杆身穿过的色带（水平箭头穿过垂直色带，垂直箭头穿过水平色带），按从杆尾到尖端的顺序记录这些色带的颜色，得到颜色序列 C1, C2, ..., Cn。
  3. 从箭头尖端最前方的下一个像素开始，沿箭头朝向逐像素绘制射线直到网格边缘。射线第 1 个像素用 C1，第 2 个用 C2，...，第 n 个用 Cn，第 n+1 个重新用 C1，依此循环。
  4. 若箭头杆身未穿过任何色带，则该箭头不产生射线。箭头自身（grey 像素）和色带均保持不变。
- `Key insight`：解题者需要三层推理——识别箭头朝向（形状解析）、发现杆身与色带的空间交叉决定射线颜色（"装载"机制）、理解射线按装载顺序循环着色。色带既是独立的视觉结构，又是箭头的"颜色来源"，这种双重身份需要跨区域推理才能发现。
