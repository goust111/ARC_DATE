- `Input structure`：
  - 背景为 black，网格大小约 15x15。
  - 网格中包含同一个不规则形状（模板）的 2-4 个副本，每个副本使用不同的颜色（如 red、green、blue、yellow）。
  - 每个副本是原始模板经过 0 度、90 度、180 度、270 度之一的旋转后放置在网格中的。副本之间可能部分重叠；在重叠区域，后放置的颜色覆盖先前的颜色（即只能看到最上层的颜色）。
  - 网格的某个角落（如左上角的 2x2 区域内）有一个单独的彩色像素，称为"指示像素"。指示像素的颜色与某个副本的颜色相同。

- `Rule`：
  - 第一步（副本分离）：识别出每个颜色对应的副本。由于重叠导致部分像素被遮盖，解题者需要利用未被遮盖的部分以及旋转关系推断每个副本的完整形状。所有副本都是同一模板的旋转版本，这一约束帮助恢复被遮盖的像素。
  - 第二步（模板还原）：找到所有副本共享的原始模板形状——将任意一个副本旋转到 0 度朝向即可得到该模板。0 度朝向的定义是：模板的最小外接矩形中，宽度大于等于高度（若宽高相等则取模板重心偏向左上的朝向）。
  - 第三步（指示输出）：指示像素的颜色指定了输出应使用的颜色。输出网格裁剪为模板的最小外接矩形大小，用指示像素的颜色绘制模板，背景为 black。

- `Key insight`：多个重叠的彩色区域看似混乱，但解题者需要洞察它们实际上是同一形状的旋转副本。指示像素不是选择"输出哪个副本"，而是指定输出颜色——输出的是还原后的标准朝向模板，而非任何一个副本的原样。
