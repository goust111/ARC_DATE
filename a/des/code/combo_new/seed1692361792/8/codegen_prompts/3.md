- `Input structure`：
  - 背景为 black。
  - 网格中有若干个由不同颜色像素构成的闭合围栏。每个围栏是一个单色的、宽度为 1 像素的封闭环（矩形轮廓或不规则闭合曲线，但始终形成一个 4-连通的封闭区域）。
  - 每个围栏内部包含若干个小的彩色像素点，这些点可能有 1 到 3 种不同的颜色（均不同于围栏颜色和背景色）。
  - 围栏之间在空间上互不接触，保持足够间距。

- `Rule`：
  - 第一步（计数）：对每个围栏，数出其内部区域中出现的不同颜色种类数 N（N 为 1、2 或 3）。
  - 第二步（生长外环）：以围栏的外轮廓为起点，向外生长 N 层同色环。具体做法：将围栏颜色向外扩展 N 像素的厚度——即围栏外侧所有与围栏曼哈顿距离 1 的 black 像素涂为围栏颜色，这算第 1 层；再对新边界重复，共扩展 N 层。
  - 围栏内部的彩色像素点在输出中被清除为 black（它们仅作为计数线索）。
  - 如果两个围栏的外扩区域即将重叠，各自在重叠前一格停止（保留一像素 black 间隔）。

- `Key insight`：围栏内部的彩色点不是要被保留或变换的对象——它们是"编码器"，其颜色种类数决定了围栏外部装饰的厚度。解题者需要跨越"内部信息决定外部形态"这一非直觉的因果方向。
