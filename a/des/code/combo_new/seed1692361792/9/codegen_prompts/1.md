- `description`：根据每个封闭区域内部的标记像素颜色，从色板行中选取对应颜色对该区域的边框进行重新上色，目标边框由色板段长度与边框周长的匹配决定。

- `Input structure`：
  - 背景为黑色（black）。
  - 网格最底部一行是"色板行"：由若干段不同颜色的连续水平色块组成，每段色块长度不同，颜色互不相同，段与段之间用黑色像素分隔。
  - 网格上方区域包含若干个用灰色（grey）像素绘制的封闭矩形边框（宽度为 1 像素），矩形之间互不重叠、互不接触。
  - 每个灰色矩形内部恰好有一个非黑色、非灰色的单像素标记点，标记颜色与色板行中某一段色块的颜色相同。
  - 色板行中每段色块的长度（像素数）各不相同，且恰好等于某个灰色矩形边框的周长像素数（周长 = 矩形边框上所有灰色像素的总数）。

- `Rule`：
  1. 对每个灰色矩形，读取其内部标记像素的颜色 C。
  2. 在色板行中找到颜色为 C 的那一段色块，读取其长度 L。
  3. 在所有灰色矩形中，找到边框周长像素数恰好等于 L 的那个矩形 T（T 与当前矩形可以是同一个，也可以不同）。
  4. 将矩形 T 的灰色边框像素全部重新上色为 C。
  5. 擦除所有标记像素（恢复为黑色背景）。色板行保持不变。

- `Key insight`：标记颜色不是直接重绘自身矩形的边框，而是通过色板行建立"颜色→长度→周长匹配"的间接映射，将颜色传递到周长匹配的另一个矩形上。解题者需要先发现颜色-色板-长度的对应关系，再发现长度与目标矩形周长的匹配关系，这构成两层非显然的推理。
</new_puzzle>
