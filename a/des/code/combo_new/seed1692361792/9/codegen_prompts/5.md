- `Input structure`：
  - 背景为黑色（black）。
  - 网格中有若干个 4-连通的彩色对象（每个对象为单一非黑非灰颜色，各对象颜色互不相同）。每个对象是一个 U 形或 C 形——即一个大致矩形的区域，但其四条边中恰好有一条边完全缺失，形成明确的"开口"。开口总是朝向上、下、左、右四个基本方向之一。例如，一个右侧缺边的矩形就是向右开口的 C 形。
  - 网格的四条边界（第一行、最后一行、第一列、最后一列）上散布着若干个单像素的彩色锚点，每个锚点的颜色与网格内某个对象的颜色相同。每种颜色在边界上恰好出现一个锚点。

- `Rule`：
  1. 对每个对象，通过分析其形状确定开口方向：找到对象的矩形包围盒，包围盒的四条边中像素覆盖率最低（或完全缺失）的那条边所在的方向即为开口方向。
  2. 找到与该对象同色的边界锚点。
  3. 数出该锚点沿其所在边界到最近的网格角落的像素距离 D（即锚点与最近角落之间的格子数，不含锚点自身所在的格子）。
  4. 将对象整体沿其开口方向平移 D 个像素。
  5. 对象原来占据但平移后不再占据的那些像素位置填充为灰色（grey），形成"残影"。
  6. 平移后的对象保持原来的颜色不变。边界上的锚点在输出中被擦除为黑色。

- `Key insight`：解题者首先要从对象的不规则形状中识别"开口方向"，这决定了滑动的方向——方向来自形状特征而非任何标记；然后要发现滑动距离不是来自对象自身属性，而是来自同色边界锚点到角落的距离——距离来自远程的空间位置关系。两层推理分别是："形状缺口→运动方向"和"同色锚点的边界位置→运动距离"。
