  - 网格中有由 grey 像素构成的连通墙壁结构，墙壁围成若干个封闭腔室（每个腔室是一个由 grey 墙壁完全包围的 4-连通 black 区域）。

- `Rule`：
  - 对每个腔室，从种子像素出发做逐层 4-连通扩展：种子本身为第 0 层；与第 0 层 4-邻接的腔室内 black 格子为第 1 层；与第 1 层 4-邻接且尚未标记的腔室内 black 格子为第 2 层；以此类推，直到腔室内所有格子都被赋予层号。
  - 着色规则：第 0 层（种子自身）为种子颜色；奇数层（1, 3, 5, ...）用种子颜色填充；偶数层（2, 4, 6, ...）保持 black 不变。
  - 最终效果：每个腔室内部呈现以种子为中心、种子颜色与 black 交替出现的同心环状条纹，因为种子位置偏心，条纹环的形状也不对称。
  - grey 墙壁保持不变。
- `Key insight`：解题者需要发现两层独立规律——第一层：填充的中心不是腔室的几何中心，而是其内部唯一的彩色像素（种子）；第二层：填充不是简单的单色洪水填充，而是按距种子的步数奇偶交替着色，产生条纹效果。种子的偏心位置是排除"以几何中心为中心"这一错误假设的关键线索。

## 实现要求

1. `main(grid)` 必须实现新题描述中的确定性转换规则，不能只识别 `generate_input()` 的固定模板。
2. `generate_input()` 必须随机生成多样样例，不能固定死。随机维度应覆盖：网格大小、对象数量、位置、颜色、方向、形状参数或关键分支。
3. 生成器必须保证输入满足 `main()` 的隐式假设：对象不重叠、不越界、特殊标记唯一或可区分、匹配关系无歧义、关键分支出现概率相同。
4. 禁止把 ARC 颜色 id 、亮度、拼写等当作人类不可见的数值语义参与排序、大小比较或隐藏映射。颜色变化必须有可见结构线索。注意颜色亮度、拼写等也是不可见信息，若描述中出现违规的颜色id或者亮度，可自行使用少量的固定颜色替代，但注意生成时要在三个以内输入输出网格中对所有变换100%覆盖度。
