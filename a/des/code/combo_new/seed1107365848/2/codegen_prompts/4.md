- `Input structure`：
  - 背景为 black。
  - 网格中有偶数个彩色 4-连通形状，每个形状为单色且颜色唯一。
  - 这些形状可以两两配对：每对中的两个形状互为镜像关系。对于水平并排的一对，它们互为水平翻转（左右镜像）；对于垂直并排的一对，它们互为垂直翻转（上下镜像）。
  - 同一对中的两个形状颜色不同。
  - 每对镜像形状要么左右并排（中间隔着 black 背景），要么上下并排。

- `Rule`：
  - 第一步——配对：遍历所有形状，将互为镜像翻转的两个形状配为一对。水平并排的对通过水平翻转匹配，垂直并排的对通过垂直翻转匹配。
  - 第二步——确定统一颜色：每对形状取两者中面积（像素数）较大者的颜色作为该对的统一颜色；若面积相同，取行号较小的形状的颜色。
  - 第三步——重绘与连接：将每对中两个形状都涂为统一颜色。然后在两个形状之间绘制一条由该统一颜色组成的单像素宽直线段：对于水平并排的对，画水平线段连接左形状最右列像素的垂直中点与右形状最左列像素的垂直中点；对于垂直并排的对，画垂直线段连接上形状最下行像素的水平中点与下形状最上行像素的水平中点。中点取整数坐标（向下取整）。

- `Key insight`：解题者需要先发现配对依据是几何形状的镜像对称而非颜色（第一层推理——颜色差异是干扰项），再发现统一颜色选取规则是面积较大者（第二层推理——需要对比同一对中两个形状的大小），最后发现连接线位置是最近边中点连线（第三层推理）。

## 实现要求

1. `main(grid)` 必须实现新题描述中的确定性转换规则，不能只识别 `generate_input()` 的固定模板。

3. 生成器必须保证输入满足 `main()` 的隐式假设：对象不重叠、不越界、特殊标记唯一或可区分、匹配关系无歧义、关键分支出现概率相同。
4. 禁止把 ARC 颜色 id 、亮度、拼写等当作人类不可见的数值语义参与排序、大小比较或隐藏映射。颜色变化必须有可见结构线索。注意颜色亮度、拼写等也是不可见信息，若描述中出现违规的颜色id或者亮度，可自行使用少量的固定颜色替代，但注意生成时要在三个以内输入输出网格中对所有变换100%覆盖度。
