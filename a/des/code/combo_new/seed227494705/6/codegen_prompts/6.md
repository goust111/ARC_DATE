根据种子像素的颜色在对应的"生长模板"中查找生长图案，然后以种子为中心将模板图案生长出来，生长层数由种子周围相邻标记像素的数量决定。

Input structure
- 背景为 black。
- 网格顶部有若干个"生长模板"：每个模板是一个小的方形图案（3x3或5x5），中心像素为某种颜色 C，周围像素描述了颜色 C 的一层生长形状（哪些相邻位置会被填充，以及填充的颜色）。模板之间用至少2列背景色分隔。
- 网格下半部分散布着若干个"种子像素"（单个彩色像素），每个种子的颜色与某个模板的中心颜色一致。
- 每个种子像素的4-邻域中有若干个 maroon 标记像素（0到3个），标记像素仅用于计数，不参与生长。

Rule
- 对每个种子像素，根据其颜色找到对应的生长模板。
- 统计该种子4-邻域中 maroon 标记像素的数量 N。
- 以种子为中心，将模板的生长图案重复施加 N 层：第1层将模板中非背景像素的相对位置围绕种子绘制一次；第2层在第1层基础上，对第1层新增的每个像素再以同样的模板相对位置扩展一层，依此类推。
- 生长过程中，已有颜色的像素不被覆盖（先到先得）。超出网格边界的像素丢弃。
- maroon 标记像素在输出中被清除为背景色。模板区域保持不变。

Key insight
- 解题者需要发现三层规则：（1）种子颜色对应哪个模板（颜色查找），（2）模板定义了生长的空间形状（图案匹配），（3）邻域 maroon 像素数量控制生长迭代次数（计数决定规模）。三层信息来源互不重叠，必须逐一识别。

7. 代码风格参考 `ARC_code`：使用 `numpy`，必要时使用本地 helper，但目标文件应能被 `SourceFileLoader` 直接加载。
