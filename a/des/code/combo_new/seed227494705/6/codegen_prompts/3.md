识别网格中的"印章"与"画布"，将印章图案按画布边框上缺口的位置和数量进行重复印刷。

Input structure
- 背景为 black。
- 网格中有一个较大的矩形"画布"：由某种颜色（如 blue）绘制的单像素宽空心矩形框，内部全为背景色。画布边框上有若干个缺口（即边框上有几个像素被替换为背景色）。
- 网格中另有一个较小的多色图案块，称为"印章"，其外接矩形完全在画布外部。印章是一个紧凑的多色像素组合。
- 画布的每条边上的缺口数量可以是0或正整数，且每个缺口恰好1像素宽。

Rule
- 第一步（确定印刷轴）：仅在有缺口的边上进行印刷。对画布的上、下、左、右四条边分别检查缺口。
- 第二步（印刷位置）：对于每条有缺口的边，将印章图案沿该边的法线方向放入画布内部，印章的中心列（若缺口在上/下边）或中心行（若缺口在左/右边）对齐到缺口所在的列或行。印章紧贴该边内侧放置。
- 若同一条边有多个缺口，则印章在每个缺口位置各印刷一次。
- 多次印刷可能重叠，后印覆盖先印（按从左到右、从上到下的缺口顺序）。
- 印章原始位置保留不变，画布边框（含缺口）保持不变。

Key insight
- 缺口既编码了印刷的方向（哪条边），又编码了印刷的精确位置（哪一列/行），解题者必须同时发现这两层信息才能重建输出。边框上没有缺口的边不产生任何印刷，这是区分干扰的关键。

## 实现要求

1. `main(grid)` 必须实现新题描述中的确定性转换规则，不能只识别 `generate_input()` 的固定模板。
2. `generate_input()` 必须随机生成多样样例，不能固定死。随机维度应覆盖：网格大小、对象数量、位置、颜色、方向、形状参数或关键分支。
3. 生成器必须保证输入满足 `main()` 的隐式假设：对象不重叠、不越界、特殊标记唯一或可区分、匹配关系无歧义、关键分支出现概率相同。
4. 禁止把 ARC 颜色 id 、亮度、拼写等当作人类不可见的数值语义参与排序、大小比较或隐藏映射。颜色变化必须有可见结构线索。注意颜色亮度、拼写等也是不可见信息，若描述中出现违规的颜色id或者亮度，可自行使用少量的固定颜色替代，但注意生成时要在三个以内输入输出网格中对所有变换100%覆盖度。

6. 若规则有多个分支，生成器不能长期固定成一个分支；应让分支在随机样例中合理出现，即每个分支出现的概率平均，所谓的分支是在描述中提到的分支，即规则语义中的不同情况。
7. 代码风格参考 `ARC_code`：使用 `numpy`，必要时使用本地 helper，但目标文件应能被 `SourceFileLoader` 直接加载。
