- `Input structure`：
  - 背景为 black。
  - 网格中有若干个互不接触的单色实心矩形对象，每个对象使用不同的颜色。
  - 每个矩形对象内部挖去了一个小矩形孔洞（孔洞为 black），孔洞的位置不一定居中。
  - 各对象孔洞的宽度和高度各不相同（如 1×2、2×3、3×1 等）。

- `Rule`：
  - 第一层推理：测量每个对象内部孔洞的宽度 W 和高度 H。孔洞的尺寸 (W, H) 即为该对象在输出中应被缩放到的目标尺寸——输出中该对象变为一个 W×H 的实心矩形（无孔洞），颜色保持不变。
  - 第二层推理：将所有缩放后的矩形按面积（W×H）从大到小排序，依次居中放置在输出网格上。输出网格的尺寸取所有缩放后矩形中最大的宽度和最大的高度。每个矩形都居中对齐（若无法精确居中则偏左偏上）。面积大的先放（在底层），面积小的后放（在顶层），后放的覆盖先放的。
  - 输出网格的背景为 black。

- `Key insight`：孔洞不是"缺损"而是"尺寸说明书"——每个对象通过自身内部的空缺形状来声明自己在输出中应变成多大。解题者需先发现"孔洞尺寸 = 目标尺寸"的编码关系，再推断居中堆叠的渲染顺序。

1. `main(grid)` 必须实现新题描述中的确定性转换规则，不能只识别 `generate_input()` 的固定模板。

3. 生成器必须保证输入满足 `main()` 的隐式假设：对象不重叠、不越界、特殊标记唯一或可区分、匹配关系无歧义、关键分支出现概率相同。
4. 禁止把 ARC 颜色 id 、亮度、拼写等当作人类不可见的数值语义参与排序、大小比较或隐藏映射。颜色变化必须有可见结构线索。注意颜色亮度、拼写等也是不可见信息，若描述中出现违规的颜色id或者亮度，可自行使用少量的固定颜色替代，但注意生成时要在三个以内输入输出网格中对所有变换100%覆盖度。
