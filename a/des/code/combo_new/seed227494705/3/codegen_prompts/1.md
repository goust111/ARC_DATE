- `Input structure`：

  - 网格左侧或顶部有一列纵向排列的颜色图例方块，从上到下依次表示数量 1、2、3……每个图例方块为单一颜色的 2x2 实心块。

  - 封闭框的轮廓色在所有框之间相同，但孔洞数量各不相同。
- `Rule`：
  - 统计每个封闭矩形框内部（不含边框本身）的背景色孔洞像素数量 N。
  - 在颜色图例中，第 N 个位置（从 1 开始）对应一种填充颜色。
  - 将该封闭框内部所有背景色像素（包括孔洞和非孔洞的内部背景）替换为图例指定的填充颜色，保留框的轮廓色不变。
  - 孔洞数量为 0 的封闭框不填充任何颜色，保持内部为背景色。
  - 图例本身在输出中保持不变。
- `Key insight`：孔洞不是需要修复的缺陷，而是一种编码——孔洞数量是查找图例的索引键，图例顺序隐含了数量到颜色的映射关系。解题者需要先发现"数孔洞"这一非显然操作，再发现图例的序数对应关系。
