- `Input structure`：
  - 背景为黑色（black）。
  - 网格中包含若干互不接触的彩色连通区域（每个区域为单一颜色，如 red、blue、green、yellow 等），每个区域形状为不规则但大致呈块状的连通体。
  - 部分区域内部含有"洞"——即完全被该区域四连通包围的单个黑色像素。每个区域的洞数量在 0 到 4 之间。
  - 不同区域的颜色各不相同。各区域之间至少间隔两个像素。

- `Rule`：
  - 对每个彩色区域，数出其内部包含的洞（被完全包围的黑色单像素）的数量 N。
  - 以该区域的边界为起点，向外做 N 层四连通膨胀（每层膨胀将所有与当前区域四连通相邻的黑色像素着色为该区域颜色）。N=0 的区域不膨胀。
  - 膨胀按层同步进行：所有区域先同时完成第 1 层膨胀，再同时完成第 2 层，依此类推。
  - 当某一层膨胀时，如果两个不同区域的膨胀前沿争夺同一个黑色像素，该像素着色为两个区域中洞数较多者的颜色。若洞数相同，着色为原始面积（膨胀前像素总数）较大者的颜色。
  - 区域内部的洞在整个过程中保持为黑色不变（不被填充）。

- `Key insight`：解题者需要先识别出"洞"这一内部拓扑特征并将其与膨胀层数关联（洞数=膨胀层数），然后理解同步膨胀时的碰撞优先级规则（洞数优先，面积次之）。这两层推理相互独立但都需要从样例中归纳：第一层是"为什么有些区域膨胀多而有些少"，第二层是"碰撞边界上的颜色由谁决定"。
