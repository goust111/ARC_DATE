- `Rule`：
  - 第一步（形状配对）：将所有图案按形状（允许旋转和翻转）分组配对，每组恰好两个图案。
  - 第二步（绘制 L 形路径）：对每一对配对的图案 A（颜色 cA）和 B（颜色 cB），以各自的几何中心像素为锚点，绘制一条从 A 锚点到 B 锚点的 L 形折线路径（先水平后垂直）。路径的前半段（水平段）使用颜色 cA，后半段（垂直段）使用颜色 cB。折线路径宽度为一像素。
  - 原始图案保持不变，路径像素叠加到背景上。

- `Key insight`：解题者首先必须识别出形状等价关系（需要心理旋转和翻转），然后才能理解路径的颜色分配规则——水平段用起点图案色、垂直段用终点图案色。两层推理缺一不可：配对错误则路径颜色也会错误。

1. `main(grid)` 必须实现新题描述中的确定性转换规则，不能只识别 `generate_input()` 的固定模板。

3. 生成器必须保证输入满足 `main()` 的隐式假设：对象不重叠、不越界、特殊标记唯一或可区分、匹配关系无歧义、关键分支出现概率相同。
4. 禁止把 ARC 颜色 id 、亮度、拼写等当作人类不可见的数值语义参与排序、大小比较或隐藏映射。颜色变化必须有可见结构线索。注意颜色亮度、拼写等也是不可见信息，若描述中出现违规的颜色id或者亮度，可自行使用少量的固定颜色替代，但注意生成时要在三个以内输入输出网格中对所有变换100%覆盖度。
