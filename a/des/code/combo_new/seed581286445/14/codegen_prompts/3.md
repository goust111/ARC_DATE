- `description`：用网格边缘的"色带顺序"作为调色板，按对象到边缘的层数为每个对象重新上色。

- `Input structure`：
  - 背景为黑色（black）。
  - 网格的最外一圈像素（第 0 行、最后一行、第 0 列、最后一列）由若干种颜色的连续色带组成，从左上角顺时针排列，每段色带长度不等但至少 2 个像素，颜色互不相同。按顺时针读取这些色带得到一个有序颜色序列（如 red, blue, green, yellow）。
  - 网格内部（去掉最外圈后）包含若干个互不接触的 4-连通单色前景对象，对象颜色为 grey。
  - 这些灰色对象分布在不同的"深度层"：有的紧贴最外圈边框（与边框的最小正交距离为 1），有的更靠内部。

- `Rule`：
  - 顺时针读取最外圈的色带，得到有序颜色序列 C1, C2, C3, ..., Ck。
  - 对每个灰色对象，计算其所有像素到网格边缘的最小正交距离（即该像素所在行列到四边的最小值），取对象内所有像素中该值的最小值作为对象的"深度" d（d 大于等于 1）。
  - 将深度 d 的对象重新上色为序列的第 d 个颜色（从 1 开始索引）。若 d 超过序列长度 k，则循环使用序列。
  - 最外圈色带在输出中保持不变。

- `Key insight`：边缘色带不是装饰边框，而是一个有序调色板——解题者需要发现顺时针读取色带顺序这一非显然的编码方式（第一层推理），然后需要发现对象的"深度"（到边缘的最小距离）作为调色板索引（第二层推理）。两层信息的来源不同（边缘 vs 内部），增加了归纳难度。
