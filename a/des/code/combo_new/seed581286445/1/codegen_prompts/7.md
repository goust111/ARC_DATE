Input structure：
- 背景为 black。
- 网格中有一个矩形区域被完全填满（无背景色），由水平条纹组成。条纹使用两种不同颜色交替出现，例如奇数行为颜色 A 的条纹，偶数行为颜色 B 的条纹（或反之）。
- 每条条纹是一行像素，其中大部分像素为该条纹的主色（A 或 B），但有若干像素被替换为一种"标记色"（如 red），形成该条纹内的图案。
- 关键观察：同色条纹（如所有 A 色条纹）中的标记色像素如果按条纹顺序上下堆叠，会形成某个图形，但该图形在不同条纹间存在固定的水平偏移——即每隔一条 A 色条纹，标记图案向右偏移固定像素数 dA。B 色条纹同理，有自己的偏移量 dB。
- 矩形区域外四角之一有一个 2×1 的小色块，上方像素颜色为 A、下方为 B，指示输出中 A 图层在上、B 图层在下的叠放顺序。

Rule：
- 将所有 A 色条纹提取出来，按原始行顺序排列，并将每条条纹反向平移以消除偏移（即将第 k 条 A 色条纹向左移动 k×dA 像素，循环移位），得到 A 图层的对齐图案。
- 同样处理所有 B 色条纹，得到 B 图层的对齐图案。
- A 图层和 B 图层各自形成一个矩形图案（高度 = 该色条纹数，宽度 = 条纹长度）。
- 按色块指示的顺序，将两个图层上下拼接（A 在上 B 在下）输出。输出中仅显示标记色像素的位置（用原标记色绘制），其余位置为背景色。

Key insight：交错排列的条纹隐藏了两个独立的信息图层，每层内部还有递进的水平偏移使图案难以直接辨认——解题者需先发现"奇偶分层"，再归纳每层的"等差偏移"规律并反向校正，最后按指示顺序合成输出。
