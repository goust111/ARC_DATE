- `Input structure`：
  - 网格宽度为 N+3，其中右侧 3 列为"信号灯区"，左侧 N 列为"条纹区"。两区之间无分隔。
  - 信号灯区的每一行包含 3 个像素，每个像素为 Maroon（灭）或 Yellow（亮），形成一个三位亮灭模式。
  - 条纹区的每一行包含若干不同颜色的像素（非 Black、非 Maroon、非 Yellow），构成一个彩色序列。
  - 网格中有一行完全为 Black 的分隔行，将网格分成上下两个面板：上面板是"图例区"，下面板是"操作区"。
  - 图例区中，每一行展示一种信号灯模式以及该模式下条纹区已经过变换的结果——同一行条纹区的颜色顺序即为变换后输出。图例区覆盖了操作区中出现的所有信号灯模式，每种模式恰好出现一次。
  - 操作区中，条纹区的内容是待变换的原始序列，各行的信号灯模式可以与图例区中的某行相同。

- `Rule`：
  - 对操作区中的每一行，读取其右侧 3 个像素的亮灭组合（信号灯模式）。
  - 在图例区中找到信号灯模式相同的行。观察图例行条纹区各位置的颜色排列相对于一个标准升序参考（可从图例区所有行的对比中推断）发生了怎样的列位置置换。
  - 将同样的列位置置换应用到操作区该行的条纹像素上，得到输出行。
  - 信号灯区在输出中保持不变。

- `Key insight`：
  信号灯模式本身不直接编码变换方式（不是简单的二进制编码）——它是一个查表索引，解题者必须先从图例区归纳出"模式→排列置换"的映射表，再应用到操作区。两步推理缺一不可。
