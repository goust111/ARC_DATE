- `Input structure`：
  - 背景为 black。
  - 网格最左列（第 0 列）包含若干个不同颜色的单像素"种子"，其余位置为背景色。种子之间不相邻。
  - 网格中其他位置散布着若干个彩色单像素"距离标记"，每个距离标记的颜色与某个种子相同，且与该种子位于同一行。每个种子在同一行中恰好有一个对应的距离标记。

- `Rule`：
  - 对最左列的每个种子像素（颜色 C，位于第 r 行第 0 列），在第 r 行中找到同色的距离标记（位于第 r 行第 d 列）。
  - 从种子位置向右绘制一条长度为 d 的水平枝干（即从第 0 列到第 d-1 列的第 r 行全部填充为颜色 C）。距离标记本身（第 d 列）不包含在枝干中，在输出中被移除。
  - 在枝干的末端像素（第 r 行第 d-1 列）处，向上和向下各绘制一条长度为 d 的垂直分支（即从第 r-1 行到第 r-d 行，以及从第 r+1 行到第 r+d 行，均在第 d-1 列上填充为颜色 C）。如果分支超出网格边界，则在边界处截断。
  - 不同颜色的 T 形树结构之间不会重叠（题目保证）。

- `Key insight`：解题者需要先发现"距离标记"的作用——它不是输出的一部分，而是编码了生长长度的控制信号（第一层推理：标记的列位置就是长度参数）；然后理解同一个长度参数同时控制水平枝干和垂直分支的长度，形成对称的 T 形结构（第二层推理：一个参数复用于两个维度）。
