利用边缘图例条中颜色的排列顺序作为优先级，对十字形对象重叠区域中被抹去的像素进行裁决填充。

Input structure：
- 背景为最常见颜色。
- 网格的最左列是一个"优先级图例条"：由若干种不同颜色自上而下排列，每种颜色恰好占一个像素，其余位置为背景色。图例条中颜色的排列顺序定义优先级：越靠上的颜色优先级越高。
- 网格其余区域包含若干个单色的十字形对象。每个十字由一个中心像素加上上下左右各延伸相同长度的臂构成（臂长 1-3 像素），十字的颜色均出现在图例条中。
- 不同十字形对象可能在臂部发生空间重叠。重叠区域在输入中显示为背景色（即冲突导致的空白）。

Rule：
- 第一步（十字还原）：根据每个十字的中心和臂长推断出其完整覆盖范围（中心同行同列、臂长范围内的所有像素）。
- 第二步（冲突识别）：找到所有显示为背景色但被两个或以上十字覆盖范围同时包含的像素。
- 第三步（优先级裁决）：对每个冲突像素，根据图例条中的顺序选择优先级最高的那个十字颜色进行填充。
- 非冲突区域的背景像素保持不变，十字形对象原有的已着色像素保持不变。图例条保持不变。

Key insight：
输入中的"空白"并非真正的空白，而是多个十字形重叠后故意留下的冲突标记。图例条的排列顺序是隐含的"图层优先级"，解题者需要先从十字的中心和臂推断出每个空白像素的重叠归属，再用图例条打破平局。这是一个"推断隐藏冲突→查表裁决"的两层结构。
