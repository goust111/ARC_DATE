<new_puzzle index="8">
根据每个封闭区域内"指针"像素所指方向，从该区域的边界沿指针方向向外搜索，找到最近的同色区域，然后将两个区域都重新着色为指针的颜色。

Input structure：
- 背景为最常见颜色。
- 网格中有若干个由不同颜色构成的封闭四连通单色区域（色块），形状不规则但各自四连通，区域之间被背景色隔开（至少一像素间距）。
- 每个色块内部恰好有一个不同于色块颜色和背景色的单像素"指针"。指针像素在色块中的位置偏向色块的某一侧（上/下/左/右），即指针像素到色块包围盒某一条边的距离最小，该最近边的方向就是指针所指方向。若到两条边距离相同，优先选择水平方向（左或右）。
- 每种色块颜色在网格中恰好出现两次（即有两个同色色块形成一对）。

Rule：
- 第一步（指针方向判定）：对每个色块，找到其内部指针像素距离色块包围盒最近的那条边，该边的朝外法线方向即为指针方向。
- 第二步（配对验证）：从色块沿指针方向向外搜索（沿指针像素所在的行或列延伸），检查该方向上是否存在与当前色块同色的配对色块。若存在，则这两个色块构成一个配对。
- 第三步（重着色）：将配对的两个色块（包括其所有像素）全部重新着色为指针的颜色。两个配对色块中指针颜色应相同。指针像素本身也变为指针颜色（即指针像素与色块融为一体）。
- 不满足配对条件的色块保持不变。背景保持不变。

Key insight：
解题者需要先通过指针在色块中的偏心位置推断"方向"，再沿该方向搜索发现同色配对机制，最后理解指针颜色是重着色的目标色。三层信息（方向→配对→着色）分别嵌入在指针的位置、色块的颜色和指针的颜色中。
</new_puzzle>

## 实现要求

1. `main(grid)` 必须实现新题描述中的确定性转换规则，不能只识别 `generate_input()` 的固定模板。
2. `generate_input()` 必须随机生成多样样例，不能固定死。随机维度应覆盖：网格大小、对象数量、位置、颜色、方向、形状参数或关键分支。
3. 生成器必须保证输入满足 `main()` 的隐式假设：对象不重叠、不越界、特殊标记唯一或可区分、匹配关系无歧义、关键分支出现概率相同。
4. 禁止把 ARC 颜色 id 、亮度、拼写等当作人类不可见的数值语义参与排序、大小比较或隐藏映射。颜色变化必须有可见结构线索。注意颜色亮度、拼写等也是不可见信息，若描述中出现违规的颜色id或者亮度，可自行使用少量的固定颜色替代，但注意生成时要在三个以内输入输出网格中对所有变换100%覆盖度。

6. 若规则有多个分支，生成器不能长期固定成一个分支；应让分支在随机样例中合理出现，即每个分支出现的概率平均，所谓的分支是在描述中提到的分支，即规则语义中的不同情况。
