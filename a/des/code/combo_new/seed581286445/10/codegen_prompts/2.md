将散落的彩色像素"收集"到同色锚点方块上，收集方向由锚点方块缺失的角决定，形成对角射线。

Input structure:
- 背景为主色（如 black）。
- 网格中有若干不同颜色的 2×2 方块，但每个方块恰好缺少一个角上的像素（该像素保持为背景色），形成一个 L 形三像素结构。每种颜色只出现一个这样的锚点。
- 同一颜色的若干单像素点散布在网格各处（远离锚点）。

Rule:
- 对每个锚点，识别其缺失角的方向（左上、右上、左下、右下）。缺失角的方向定义一个对角方向向量（例如缺失左上角意味着向量指向左上方）。
- 统计该颜色散落单像素的数量 N。
- 从锚点缺失角位置开始，沿缺失角对角方向依次放置 N 个该颜色像素：第一个放在缺失角位置（补全 2×2 方块），第二个放在沿对角方向再远一格的位置，依此类推，形成一条长度为 N 的对角线。
- 散落像素的原始位置被清除为背景色。锚点的原始三个像素保持不变。

Key insight:
- 2×2 方块缺失角的位置同时编码了两个信息：对角线的延伸方向和起始位置。解题者需要先识别"L 形即缺角方块"的模式，然后推断缺角方向与像素排列方向的对应关系，最后理解散落像素的数量决定了对角线的长度。

## 实现要求

1. `main(grid)` 必须实现新题描述中的确定性转换规则，不能只识别 `generate_input()` 的固定模板。
2. `generate_input()` 必须随机生成多样样例，不能固定死。随机维度应覆盖：网格大小、对象数量、位置、颜色、方向、形状参数或关键分支。
3. 生成器必须保证输入满足 `main()` 的隐式假设：对象不重叠、不越界、特殊标记唯一或可区分、匹配关系无歧义、关键分支出现概率相同。
4. 禁止把 ARC 颜色 id 、亮度、拼写等当作人类不可见的数值语义参与排序、大小比较或隐藏映射。颜色变化必须有可见结构线索。注意颜色亮度、拼写等也是不可见信息，若描述中出现违规的颜色id或者亮度，可自行使用少量的固定颜色替代，但注意生成时要在三个以内输入输出网格中对所有变换100%覆盖度。

6. 若规则有多个分支，生成器不能长期固定成一个分支；应让分支在随机样例中合理出现，即每个分支出现的概率平均，所谓的分支是在描述中提到的分支，即规则语义中的不同情况。
