将左侧模板中标记像素的相对位置"印"到右侧同色碎片上，模板本身被清除。

Input structure:
- 背景为主色（如 black）。
- 网格左半区有若干小的矩形"模板"，彼此不重叠。每个模板由单一颜色填充，但其中有若干像素被替换为一种独特的标记色（每个模板使用不同的标记色）。模板整体仍为矩形轮廓。
- 网格右半区散布着若干与模板尺寸完全相同的纯色矩形碎片（无标记、完全由单色填满）。每个碎片的主色与某个模板的主色相同。
- 每个模板恰好与右侧一个碎片通过主色一一对应，且碎片的尺寸与对应模板完全相同。

Rule:
- 将每个右侧碎片与左侧同色模板配对。
- 在碎片上，将模板中标记色像素所处的相对位置（以模板左上角为原点的局部坐标）对应的像素替换为该模板的标记色。
- 碎片其余像素保持其主色不变，碎片位置不变。
- 左侧模板区域在输出中全部清除为背景色。

Key insight:
- 核心推理分两层：第一层需要通过颜色匹配建立碎片与模板的对应关系；第二层需要将模板中标记色的局部坐标映射到碎片上——模板不是要被"修复"，而是作为一种空间印章模式施加于碎片。
