Input structure：
- 背景为 Black。网格中每一行独立包含一段连续的彩色像素序列（长度和颜色各行不同），其余位置为背景色。

Rule：
- 对每一行，找到其彩色序列的中心，识别唯一的对称缺陷像素及其所在侧（左半或右半）。
