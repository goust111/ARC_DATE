Input structure：
- 背景为 Black。网格底部有一行"调色板条"：一排连续像素，从左到右各不相同的颜色（如 Red、Orange、Yellow、Green、Blue），它们定义了一个颜色序列。
- 网格其余区域有若干小型 4-连通单色填充对象（"印章"），每个印章的颜色是调色板条中的某个颜色。
- 每个印章旁边（4-邻域中某个方向上间隔 1 像素）有一个与印章同色的单像素"箭头点"，箭头点相对于印章整体重心的方向（上/下/左/右）指示投影方向。

Rule：
- 找到调色板条，记录其颜色序列 C0, C1, C2, …, Cn。
- 对每个印章，确定其颜色在调色板条中的位置 i，以及箭头点指示的方向 D。
- 从印章位置开始，沿方向 D 每隔（印章在 D 方向上的跨度 + 1）个像素绘制印章的副本，第一个副本颜色为 C(i+1)，第二个为 C(i+2)，依此类推，直到颜色序列用尽或副本超出网格边界。
- 原始印章和箭头点保留，调色板条保留。

Key insight：
调色板条既编码了颜色变换顺序又限定了副本数量；箭头点看似装饰实则编码方向——解题者需要先发现调色板条的作用（确定颜色迭代规则），再识别箭头点与方向的关系，两步归纳缺一不可。
