在网格中找到由不同颜色段拼成的环形路径，根据环上每段的长度决定其在输出中的径向膨胀厚度，将细环变为粗细不均的宽环。

Input structure：
- 背景为 Black。网格中有一个由多种颜色段首尾相连组成的单像素宽闭合环路（环路沿 4-连通路径行进，每段是一种颜色的连续像素序列，相邻段颜色不同）。
- 环路围成一个封闭的内部区域（内部全为背景色）。
- 环路外部也全为背景色。

Rule：
- 识别闭合环路，将其分解为若干连续同色段。
- 对每一段，数出该段包含的像素数 L。
- 在输出中，将该段的每个像素向环路内侧法线方向扩展 L 个像素（含原始像素本身），即该段的径向厚度变为 L 像素，颜色不变。
- 扩展后的像素若与其他段的扩展区域重叠，则保留先绘制的段的颜色（按环路顺序，从环路上 Red 段开始顺时针依次绘制，先绘制的段不被后续段覆盖）。
- 环路外侧不扩展。

Key insight：
解题者需先发现环由多色段拼成并正确分段（第一层），再发现每段长度等于其膨胀厚度（第二层），还需理解膨胀方向始终朝向环的内侧而非外侧（第三层）。段长度与几何厚度的对应关系是核心的非显然洞见。
