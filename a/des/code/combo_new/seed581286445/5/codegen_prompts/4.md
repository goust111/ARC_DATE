网格中的彩色"门"对象控制着相邻通道的通断：打开的门让通道中的信号色通过，关闭的门则阻断信号并在阻断处标记警示色。

Input structure
- 背景色为 Black。
- 网格被 Grey 色的水平或垂直单像素厚墙壁分隔成若干矩形通道（通道宽度为 1 行或 1 列）。
- 每面墙壁上恰好有一个非 Grey、非背景的单像素"门"，门的颜色为 Green 或 Maroon。
- 每条通道的一端（靠近网格边缘的一端）有一个 Azure 色单像素"信号源"。

Rule
- 信号从每个 Azure 信号源出发，沿通道方向传播，将通道中的背景像素染为 Azure。
- 当信号到达一面墙壁时，检查墙壁上的门颜色：
  - 若门为 Green（开门），信号穿过墙壁继续在下一条通道中传播。
  - 若门为 Maroon（关门），信号被阻断；将门的 Maroon 像素改为 Red，信号不再向前传播。
- 信号持续传播直到遇到 Maroon 门、网格边界、或通道尽头。
- 所有未被信号到达的通道像素保持为背景色。Grey 墙壁和 Green 门保持不变。

Key insight
解题者需要先理解门的颜色编码（Green = 通行，Maroon = 阻断），再追踪信号的级联传播路径——关键在于发现门色决定通断、信号可跨越多面墙壁级联传播、以及阻断时门色变化这三条规则的叠加，而非简单的单步填充。
