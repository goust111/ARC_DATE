- `Input structure`：
  - 背景为黑色（black）。
  - 一条 grey 色的水平线和一条 grey 色的垂直线将网格分成四个象限（十字形分隔线，每条线宽一个像素）。
  - 每个象限内散布着若干单像素的彩色"种子"点（颜色可能为 red、blue、green、orange 等），种子点不接触分隔线。
  - 每个象限内的种子点颜色各不相同。

- `Rule`：
  - 对于每个种子像素，计算它到最近水平分隔线的行距 H 和到最近垂直分隔线的列距 W（均为正整数，不含分隔线本身）。
  - 以种子像素为起点，向该种子所在象限的角落方向（即远离十字中心的对角方向）生长一个 W 列 x H 行的矩形色块，颜色与种子相同。种子像素位于该矩形靠近十字中心的那个角。
  - 如果生长后的矩形超出网格边界，则在边界处截断。
  - 灰色分隔线在输出中保持不变。

- `Key insight`：种子的位置编码了两个信息——它到两条分隔线的距离分别决定了生成矩形的宽和高，而它所在的象限决定了矩形的生长方向。解题者需要发现距离与尺寸的对应关系，以及象限决定方向这两层规则。

## 实现要求

1. `main(grid)` 必须实现新题描述中的确定性转换规则，不能只识别 `generate_input()` 的固定模板。
2. `generate_input()` 必须随机生成多样样例，不能固定死。随机维度应覆盖：网格大小、对象数量、位置、颜色、方向、形状参数或关键分支。
3. 生成器必须保证输入满足 `main()` 的隐式假设：对象不重叠、不越界、特殊标记唯一或可区分、匹配关系无歧义、关键分支出现概率相同。
4. 禁止把 ARC 颜色 id 、亮度、拼写等当作人类不可见的数值语义参与排序、大小比较或隐藏映射。颜色变化必须有可见结构线索。注意颜色亮度、拼写等也是不可见信息，若描述中出现违规的颜色id或者亮度，可自行使用少量的固定颜色替代，但注意生成时要在三个以内输入输出网格中对所有变换100%覆盖度。
