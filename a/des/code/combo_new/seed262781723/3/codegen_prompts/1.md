- `Input structure`：网格背景为 Black。网格中包含若干由 Grey 像素围成的封闭矩形区域（一像素宽的完整边框），每个矩形的某一侧边框上有一个恰好一像素宽的缺口。每个封闭区域内部有一个由单一颜色构成的小型实心矩形色块（2x2 或 3x3）。网格的一个角落有一个"色环图例"：四个不同颜色的单像素点分别位于一个十字形的上、下、左、右四个位置，分别对应上、下、左、右四个方向。
- `Rule`：
  1. 首先读取角落的色环图例，建立颜色→方向的映射（例如 Red 在十字上方→Red 对应"向上"）。
  2. 对每个 Grey 封闭区域，识别其内部色块的颜色，在色环图例中查找该颜色对应的方向。
  3. 忽略灰色边框上的缺口位置，将色块沿图例指定的方向平移，直到色块完全离开灰色边框区域，紧贴在灰色边框的外侧。色块保持原始尺寸和形状。
  4. 灰色边框保持不变（缺口仍然存在），色块在原来区域内部的位置变为 Black 背景。
- `Key insight`：缺口是干扰项——色块的移动方向不由缺口决定，而由图例中颜色对应的方向决定。解题者必须先破解色环图例的方向编码，再将该映射应用于每个区域，这构成两层独立的推理。
