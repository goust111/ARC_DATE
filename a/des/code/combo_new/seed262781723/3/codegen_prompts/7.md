- `Input structure`：网格背景为 Black，整体为正方形。网格的中心行和中心列由 Grey 像素绘制的十字线标出，将网格分为四个象限（左上、右上、左下、右下）。若干单像素的彩色种子散布在四个象限中（不在灰色十字线上）。同一颜色可能出现多个种子，分布在不同象限中。

  1. 对每种颜色，数出该颜色在整个网格中的种子总数 K。
  2. 每个种子根据其所在象限确定 L 形枝干的生长方向：左上象限的种子向左和向上生长；右上象限的种子向右和向上生长；左下象限的种子向左和向下生长；右下象限的种子向右和向下生长。

  4. Grey 十字线保持不变。如果枝干像素超出网格边界则截断。
- `Key insight`：枝干的方向由空间位置（象限）决定，而枝干的长度由全局统计量（同色种子总数）决定。解题者必须同时发现这两条独立规则并将它们组合，才能正确预测输出。
