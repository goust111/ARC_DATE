- `Input structure`：背景为黑色。网格中散布着若干个小型彩色物体（各不相同的2x2或3x3实心方块）和若干个"路标"。每个路标由一个灰色的3x1或1x3像素条组成，条的一端有一个与条垂直的单像素突出（整体形成T形或箭头形），突出的方向指示该路标的"指向"（上、下、左或右四个方向之一）。每个彩色物体最初紧邻某个路标放置（与路标相邻但不重叠）。
- `Rule`：
  1. 找到每个彩色物体当前紧邻的路标。
  2. 读取该路标的指向方向。
  3. 沿该方向将物体平移，直到物体紧邻该方向上遇到的下一个路标为止（物体停在下一个路标旁边，不重叠）。
  4. 如果该方向上没有更多路标，物体平移到网格边缘处停止。
  5. 到达新路标后，不再继续移动（每个物体只执行一步路标跳转）。
  6. 路标本身位置不变，物体原始位置清除为背景色。
- `Key insight`：路标的T形突出方向编码了移动指令，但解题者需要发现物体只执行"一跳"——从当前路标到下一个路标——而不是沿路标链连续移动。物体的移动距离完全由路标的空间分布决定，而非固定步数。
</new_puzzle>

3. 生成器必须保证输入满足 `main()` 的隐式假设：对象不重叠、不越界、特殊标记唯一或可区分、匹配关系无歧义、关键分支出现概率相同。
4. 禁止把 ARC 颜色 id 、亮度、拼写等当作人类不可见的数值语义参与排序、大小比较或隐藏映射。颜色变化必须有可见结构线索。注意颜色亮度、拼写等也是不可见信息，若描述中出现违规的颜色id或者亮度，可自行使用少量的固定颜色替代，但注意生成时要在三个以内输入输出网格中对所有变换100%覆盖度。
