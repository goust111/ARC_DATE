Input structure
- 背景为黑色。网格中有若干种非背景颜色的像素，每种颜色恰好出现两个像素点（即成对出现）。
- 同色像素对要么在同一行（水平对齐），要么在同一列（垂直对齐），不会出现对角线对齐的情况。
- 不同颜色的像素对分别沿水平或垂直方向对齐，使得某些连线之间会产生交叉点。
- 网格边缘有一个"混色图例"：一个小矩形区域，其中若干行各包含两个颜色像素和一个结果色像素，表示"当这两种颜色的线交叉时，交叉点应填充该结果色"。图例格式为每行三个像素：第一个和第三个为两种输入色，中间为结果色。

Rule
- 对每对同色像素，在它们之间画一条与行或列对齐的直线（包含两个端点之间的所有像素），颜色与该对像素相同。
- 当两条不同颜色的直线在某个像素位置交叉时，查找混色图例中包含这两种颜色的那一行，将交叉点像素填充为图例中给出的结果色。
- 如果某个像素只被一条线覆盖，则填充为该线的颜色。
- 混色图例区域在输出中被清除为背景色。

Key insight
解题者首先要发现同色像素对之间需要连线（第一层），然后注意到交叉点的颜色不是简单覆盖而是遵循特定的混合规则（第二层），最后要识别出边缘图例提供了混色查找表（第三层）。三层推理环环相扣。
