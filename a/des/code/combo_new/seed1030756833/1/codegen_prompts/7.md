Input structure
- 背景为黑色。网格中可见若干种非背景颜色的像素，这些像素实际上来自若干个不同颜色的实心矩形的叠放。
- 这些矩形具有不同的尺寸，中心点大致重合，较小的矩形叠在较大的矩形上方，遮挡了下方矩形的中心部分。
- 因此每个较大矩形只有未被遮挡的边缘"框"部分可见，最小的矩形完全可见。
- 每种颜色只对应一个矩形。

Rule
- 通过可见的边缘区域推断每个矩形的完整尺寸：对每种颜色，其可见像素形成一个框形区域（或对于最顶层，一个完整矩形），该框的外边界即为该矩形的实际边界。
- 确定所有矩形的完整尺寸后，按面积从小到大排序。
- 在输出网格中，将这些矩形重新绘制为同心嵌套结构：最大的矩形在最外层，最小的在最内层，所有矩形共享同一个中心点。相邻层之间间隔一个像素的背景色形成"间隙环"。
- 输出网格的尺寸恰好容纳最外层矩形加上所有间隙。

Key insight
第一层推理是从遮挡碎片还原每个矩形的完整尺寸（逆向遮挡推理），第二层是发现输出将这些矩形重新组织为等间距同心框架——输入编码的是自由叠放，输出编码的是规则嵌套，两者的几何组织原则完全不同。
