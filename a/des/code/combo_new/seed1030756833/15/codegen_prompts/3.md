Input structure
- 网格由一个小尺寸（如 3×3 或 4×4）的多色平铺单元周期性铺满。

- 每个遮挡物内部恰好有一个由背景色组成的孔洞（连通区域），孔洞的形状为以下四种之一：朝上的 L 形、朝右的 L 形、朝下的 L 形、朝左的 L 形。这四种 L 形分别对应 0 度、90 度、180 度、270 度旋转。

Rule
- 首先利用所有未被遮挡物覆盖的像素，推断出底层的周期性平铺单元。

- 然后读取该遮挡物内部孔洞的 L 形朝向，将恢复出的图案块围绕其中心旋转对应角度（朝上=0 度，朝右=90 度，朝下=180 度，朝左=270 度），再填入遮挡物区域。

Key insight
遮挡物不仅标记了需要修复的区域，其内部孔洞的形状还编码了一条隐藏指令——恢复的图案需要额外旋转。解题者需要先完成周期图案重建，再识别孔洞形状与旋转角度的对应关系，形成两层独立的归纳任务。
