- `Input structure`：背景为 Black。网格中散布若干由单一颜色绘制的一像素厚矩形框架（如 Red 框、Blue 框等），每个框架的某一条边上恰好有一个单像素缺口。每个框架内部恰好有一个与框架颜色不同的彩色种子像素（如框架为 Red，种子为 Green）。
- `Rule`：
  1. 对每个框架，找到其边上的缺口所在方位（上、下、左、右）。
  2. 从种子像素出发，沿缺口的**反方向**逐行（或逐列）生长：在框架内部，从种子所在行/列开始，向缺口反方向逐步填充整行/整列，直到碰到框架边界为止，填充颜色为种子颜色。
  3. 计算每个框架内被填充的像素总数（即生长后的面积）。
  4. 在与最大框架等大的输出画布上，按面积从小到大的顺序依次放置各框架（含其内部填充），小面积在下、大面积在上，各框架左上角对齐画布左上角。重叠处上层覆盖下层。
- `Key insight`：缺口方位决定生长方向的反转是第一层推理；生长面积决定堆叠顺序是第二层推理——两层规则都需要从样例中独立归纳。
