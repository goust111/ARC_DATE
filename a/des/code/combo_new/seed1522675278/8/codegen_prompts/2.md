将散落的彩色碎片按颜色归入对应颜色围栏内，并在围栏中按碎片面积从小到大自下而上堆叠。

Input structure:
- 背景为黑色。
- 网格中有若干个由不同颜色构成的U形围栏（底部和两侧封闭、顶部开口的容器形状），每个围栏颜色各不相同。
- 网格中散布着若干个与围栏同色系的小型4连通色块（碎片），每个碎片的颜色恰好与某一个围栏的颜色相同。
- 碎片位于围栏外部的任意位置。

Rule:
- 将每个碎片归入与其颜色相同的围栏中。
- 对归入同一围栏的所有碎片，按面积（像素数）从小到大排序。
- 在围栏内部从底部开始向上堆叠：面积最小的碎片放在最底层，保持碎片原始形状不变，每个碎片水平居中放置（若围栏宽度大于碎片宽度，则左右留白尽量相等，奇数差时靠左）。
- 碎片之间紧密堆叠，不留空行。围栏和围栏外的碎片原始位置清除为背景色。

Key insight:
解题者需要先通过颜色匹配确定每个碎片属于哪个围栏（第一层推理），然后发现碎片在围栏内部是按面积排序堆叠的（第二层推理），两步归纳缺一不可。
