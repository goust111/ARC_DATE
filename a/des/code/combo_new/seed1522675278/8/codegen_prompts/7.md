识别网格中颜色相同的配对对象，用两者形状的差异像素连接它们。

Input structure:
- 背景为灰色。
- 网格中有若干个小型4连通色块，每种非背景颜色恰好出现两个色块（即成对出现）。
- 同色的两个色块形状相似但不完全相同：其中一个比另一个多出1到2个像素（称为"突出像素"）。
- 同色配对的两个色块在同一行或同一列上。

Rule:
- 对每对同色色块，找出两者之间的形状差异：将较大色块与较小色块对齐比较（以各自边界框左上角对齐），识别出较大色块中多出的"突出像素"。
- 从每个突出像素出发，沿着两个色块的连线方向（即同行则水平、同列则垂直）画一条连接线，延伸到另一个色块的边界框对应位置。
- 连接线使用该对色块的颜色。
- 原始色块保持不变。

Key insight:
解题者需要先通过颜色配对找到对应关系（第一层），再通过形状比较发现"突出像素"的位置（第二层），最后理解突出像素决定了连接线的具体行/列位置（第三层）——配对、比较、连接三步推理环环相扣。
