将每个多色拼图块拆分为单色层，按颜色在调色板行中的出现顺序纵向展开排列。

Input structure:
- 背景为黑色。
- 网格顶部有一行"调色板行"：若干个不同颜色的像素从左到右排成一行，每个颜色占一个像素，颜色之间用黑色间隔一格。
- 调色板行下方隔若干行，有一个或多个由多种颜色混合构成的矩形拼图块（每个拼图块的边界框大小相同，且各块之间用黑色背景分隔）。
- 每个拼图块内部使用的颜色都是调色板行中颜色的子集。

Rule:
- 对每个拼图块，将其按颜色拆分为若干"单色层"：每一层与原拼图块尺寸相同，仅保留该颜色的像素，其余位置填充黑色。
- 按调色板行中颜色从左到右的出现顺序，将各单色层从上到下依次纵向排列（相邻层之间间隔一行黑色），替代原拼图块的位置。
- 调色板行本身在输出中被清除为黑色。
- 若拼图块中未使用调色板中的某种颜色，则跳过该层，不生成空白层。

Key insight:
解题者需要先发现调色板行定义了颜色的排序规则（第一层推理），然后理解每个拼图块被按颜色分解为独立层（第二层推理），最后发现各层的纵向排列顺序由调色板决定而非由像素数量或空间位置决定（第三层推理）。
