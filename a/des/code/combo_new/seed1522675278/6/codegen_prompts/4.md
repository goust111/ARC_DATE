- `Input structure`：背景为最常见颜色。网格中有若干个不同颜色的相同形状的矩形环（空心矩形，一像素厚边框），它们分散在网格各处，互不重叠，大小各不相同。每个矩形环的内部中心位置有一个由另一种颜色构成的单像素标记点。标记点的颜色恰好等于另一个矩形环的边框颜色，形成一条链式指向关系（A 内标记颜色 = B 的边框颜色，B 内标记颜色 = C 的边框颜色……）。链的末端矩形环内部标记颜色不对应任何其他环（或者标记颜色与自身边框颜色相同）。
- `Rule`：
  1. 通过标记颜色的链式指向，确定矩形环从外到内的嵌套顺序：链头（没有被任何其他环的标记指向的环）为最外层，链尾为最内层。
  2. 输出网格以最外层矩形环为基础，将第二层矩形环居中放入第一层内部，第三层居中放入第二层内部，依此类推。每层环保持其原始边框颜色，环的大小按原始大小保持不变（保证内层环能放入外层环内部）。
  3. 最内层环的内部标记点保留在最终输出的中心位置。其余标记点移除。
  4. 输出网格裁剪为恰好包含最外层矩形环的最小尺寸。
- `Key insight`：解题者需要先通过"内部标记颜色 = 另一个环的边框颜色"的链式关系推断出嵌套顺序（第一层推理），再按该顺序执行同心嵌套的几何构建（第二层推理）。分散的环和链式指向使得嵌套顺序并不直观。
