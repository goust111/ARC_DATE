Input structure:
- 背景为 black。
- 网格被一条 grey 色的完整竖线分为左右两个区域。
- 左侧为"模板区域"：包含一个由 blue 像素构成的大型连通形状，该形状内部有若干个不同大小的矩形空洞（全黑区域），空洞之间大小互不相同。
- 右侧为"样本区域"：包含若干个小型矩形对象，每个对象由单像素宽的 red 外框包裹，内部填充着由两种颜色交替组成的独特图案（如水平条纹、竖直条纹、棋盘格等）。不同样本对象的外框尺寸互不相同。

Rule:
- 第一步：测量模板中每个矩形空洞的宽 W 和高 H。
- 第二步：对每个样本对象，其外框尺寸为 W×H，去掉单像素宽的 red 外框后，内部图案尺寸为 (W-2)×(H-2)。
- 第三步：将样本对象的外框尺寸与模板空洞尺寸进行匹配（外框尺寸 = 空洞尺寸）。
- 第四步：将匹配的样本对象的内部图案（不含外框）填入模板对应空洞的中央，空洞四周保留 1 像素的黑色间距。
- 输出仅包含模板区域（从网格左边界到 grey 分隔线之前），空洞被图案填充，其余蓝色像素和黑色背景不变。

Key insight:
- 匹配并非用样本内部图案的尺寸直接对比空洞尺寸，而是用样本对象含外框的整体尺寸去匹配。外框是"包装"，内部图案才是"内容"，放入空洞时外框被丢弃，留下 1 像素的黑色边距。解题者需要先发现外框与空洞的尺寸对应关系，再理解剥离外框后居中放置的嵌套规则。
