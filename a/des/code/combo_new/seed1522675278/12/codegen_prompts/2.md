将散落的单色碎片按照隐含的层叠顺序重建，并用每个碎片的完整面积决定其在输出色带中的排列位置。

Input structure:
- 背景为 grey。
- 网格中有若干个不同颜色的不规则单色碎片（8-连通），碎片之间存在部分重叠。
- 在重叠区域，上层碎片的颜色覆盖了下层碎片的颜色。

Rule:
- 第一步：通过观察重叠区域，推断碎片之间的遮挡关系。如果颜色 A 的像素出现在颜色 B 碎片的连通区域预期位置上，说明 A 在 B 之上。据此建立从顶层到底层的完整层叠顺序。
- 第二步：对每个碎片，根据层叠顺序还原其完整形状（包括被遮挡部分），具体方法为：对于被上层碎片覆盖的像素位置，如果该位置与当前碎片的可见部分 8-连通相邻且处于当前碎片可见轮廓的凸包范围内，则视为被遮挡像素，将其计入该碎片的完整面积。
- 第三步：输出为单行色带（1 行 × N 列，N = 碎片数量），按完整面积从小到大排列，每格填入对应碎片的颜色。若面积相同，按碎片最上方像素的行号从小到大排列。

Key insight:
- 解题者不仅需要从可见像素中推断层叠顺序（遮挡推理），还需要"反向补全"被遮挡的碎片以获得真实面积，最终用面积排序生成一个与空间布局无关的抽象色带输出。层叠推理和面积排序是两层独立的非平凡归纳。
