  - 背景色为黑色。
  - 网格中有一个多色连通图案（"源图案"），占据一个矩形区域，由至少三种颜色组成。源图案的四个角像素（左上、右上、左下、右下）各自具有不同的颜色。
  - 网格其余位置散布着若干孤立的单像素标记点，每个标记点的颜色恰好与源图案四个角像素中的某一个颜色相同。

- `Rule`：
  - 对每个标记点，根据其颜色判断它对应源图案的哪个角：
    - 标记颜色 = 源图案左上角颜色 → 将源图案原样复制，使源图案的左上角对齐到标记点位置。
    - 标记颜色 = 源图案右上角颜色 → 将源图案水平翻转后复制，使翻转后图案的右上角（即原图案的左上角）对齐到标记点位置。
    - 标记颜色 = 源图案左下角颜色 → 将源图案垂直翻转后复制，使翻转后图案的左下角对齐到标记点位置。
    - 标记颜色 = 源图案右下角颜色 → 将源图案旋转180度后复制，使旋转后图案的右下角对齐到标记点位置。
  - 复制时，标记点本身被图案覆盖；若复制的图案超出网格边界，则截断不绘制。
  - 源图案本身在输出中保留不变。

- `Key insight`：解题者需要三层推理。第一层：识别出哪个是源图案、哪些是锚点标记。第二层：发现标记颜色与源图案的四个角颜色存在对应关系。第三层：归纳出颜色匹配到的角位置同时编码了两个信息——放置时的对齐锚点和图案的翻转/旋转方式。角颜色的差异在视觉上是可见的，但需要解题者主动将标记颜色与源图案角落进行比对。
