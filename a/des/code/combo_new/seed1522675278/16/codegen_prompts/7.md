- `Input structure`：

  - 网格中有若干单色 4-连通对象（至少 2 个像素），形状各异，颜色互不相同。
  - 每种对象颜色在网格中还有一个同色的孤立单像素（锚点），锚点不与对象相邻。
  - 每个对象与其同色锚点之间，沿水平或垂直方向上恰好对齐（即对象 bbox 的某条边与锚点在同一行或同一列上）。
- `Rule`：
  - 将每个对象与其同色锚点配对。
  - 计算对象 bbox 最近边缘与锚点之间的空格数（沿对齐方向，不含对象自身像素和锚点像素，只计中间的黑色像素数）。该数值记为 S。
  - 将对象的形状按比例缩放，使缩放后的对象总像素数等于 S。缩放方式：保持对象的整体轮廓形状，取对象 bbox 内像素占比最高的 S 个像素（按从左上到右下逐行扫描顺序选取）。
  - 将缩放后的对象放置在以锚点为中心的位置。
  - 原始对象和锚点像素被擦除。
- `Key insight`：解题者需先发现对象与同色锚点的配对关系，再发现"间距=目标像素数"这个非显然的数值映射，最后理解缩放和放置的具体方式。间距作为可视觉估算的小数值（通常不超过 8-10），在视觉上是可直觉感受的。
