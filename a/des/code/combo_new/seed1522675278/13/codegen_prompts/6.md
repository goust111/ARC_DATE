将网格中的每个对象沿其"尾巴"方向滑动，直到尾巴尖端接触到同色边框线段，然后将对象与边框线段之间的间隙用 azure 色填充轨迹。

Input structure：
- 背景为黑色。
- 网格的四条边上各有一段或多段单色线段（不一定覆盖整条边），这些边框线段颜色各异。
- 网格内部有若干个前景对象，每个对象由一个主体块（紧凑的矩形或近矩形区域）加上一条从主体某侧伸出的单像素宽"尾巴"组成（尾巴沿基数方向延伸2-4个像素）。
- 每个对象的主体颜色与网格四边上某一段边框线段的颜色相同。

Rule：
- 对每个对象，识别其尾巴伸出的方向（尾巴从主体延伸出去的基数方向）。
- 找到网格四边上与该对象同色的边框线段。
- 将整个对象（主体+尾巴）沿尾巴方向平移，直到尾巴的尖端像素与同色边框线段相邻（紧贴边框线段，中间无间隔）。
- 对象移动后，在原始位置和新位置之间、沿移动路径上，用 azure 色填充对象主体扫过的矩形轨迹区域（不含对象最终位置本身）。
- 若多个对象的轨迹重叠，后移动的对象（按原始位置从上到下、从左到右的顺序）的轨迹覆盖先前的。

Key insight：
- 解题者需要三层推理：第一层是识别对象的"尾巴"结构来确定移动方向（尾巴指向目标而非远离目标）；第二层是通过颜色匹配找到目标边框线段确定终点；第三层是理解轨迹填充规则。尾巴既编码了方向又暗示了目标，这种双重编码增加了机制的隐蔽性。
