将散落的单色碎片拼回到网格中央的灰色剪影区域内，每个碎片的放置位置由剪影内部的同色锚点像素确定。

Input structure：
- 背景为黑色。
- 网格中央有一个由灰色像素组成的大型不规则剪影区域（4连通）。
- 剪影内部散布着若干个不同颜色的单个锚点像素（每种非灰色、非背景颜色恰好在剪影内出现一次）。
- 剪影外部散布着与锚点颜色一一对应的小型单色碎片对象（4连通，每个碎片恰好包含一个与其同色的特殊标记像素，该像素在碎片中被替换为灰色）。

Rule：
- 对每个碎片，找到其中唯一的灰色像素——这是碎片的锚定点。
- 在剪影内部找到与该碎片颜色相同的锚点像素。
- 将碎片平移，使碎片中的灰色锚定点与剪影内部的同色锚点像素位置重合。
- 将碎片（包括其灰色锚定点）覆盖写入输出网格。碎片的非灰色像素覆盖剪影的灰色像素；碎片的灰色锚定点保持灰色。
- 所有碎片放置完毕后，剪影中未被碎片覆盖的灰色像素保持灰色不变。
- 输出网格大小与输入相同，剪影外部保持黑色背景。

Key insight：
- 碎片中的灰色像素不是碎片形状的一部分，而是对齐锚——解题者必须先发现碎片内部"异色像素"的作用是定位键，再将其与剪影内部的同色锚点匹配，这是两步非显然的归纳过程。

1. `main(grid)` 必须实现新题描述中的确定性转换规则，不能只识别 `generate_input()` 的固定模板。

4. 禁止把 ARC 颜色 id 、亮度、拼写等当作人类不可见的数值语义参与排序、大小比较或隐藏映射。颜色变化必须有可见结构线索。注意颜色亮度、拼写等也是不可见信息，若描述中出现违规的颜色id或者亮度，可自行使用少量的固定颜色替代，但注意生成时要在三个以内输入输出网格中对所有变换100%覆盖度。
