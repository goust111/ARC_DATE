- `Input structure`：背景为黑色。网格中有若干个由绿色像素围成的封闭矩形区域（一像素厚的边框，内部填充黑色背景）。每个矩形区域内部有若干个"窗户"——即 1x1 的 azure 色像素，它们紧贴矩形内壁的某一侧（上、下、左或右内壁，距边框恰好一格）。同一个矩形内所有窗户都贴在同一侧内壁上。
- `Rule`：
  - 第一步——读取方向：观察每个矩形内窗户紧贴的是哪一侧内壁。窗户贴在上内壁表示方向为"上"，贴在下内壁表示"下"，左内壁表示"左"，右内壁表示"右"。

  - 矩形本身和窗户在输出中保持不变。
- `Key insight`：窗户贴壁的方向不是装饰而是矢量指令，窗户数量不是标签而是生长参数——解题者需要同时归纳方向编码规则和数量-长度映射两层机制。
