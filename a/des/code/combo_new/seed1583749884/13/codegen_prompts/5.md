- `Input structure`：
  - 背景为 Black。
  - 网格中有若干个 8-连通前景对象，每个对象可能包含 1-3 种不同的非背景颜色。
  - 对象之间不接触。

- `Rule`：
  - 对每个对象，计算其内部包含的不同颜色数量 C。
  - C = 1（单色对象）：保持不变。
  - C = 2（双色对象）：找到两种颜色的像素区域的交界线（即颜色边界），将整个对象仅保留交界线上的像素（使用两种颜色中面积较大的颜色），擦除其余像素。
  - C >= 3（三色及以上对象）：仅保留面积最大的颜色的像素，擦除其他颜色的像素为背景。

- `Key insight`：颜色多样性是分类标准，每个类别对应不同的简化操作——这是一种基于内在属性的条件分支规则。
