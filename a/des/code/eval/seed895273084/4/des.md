<new_puzzle>
根据框架内部图案的对称性缺陷方向，选择对应颜色图例，重新填充框架内部。

Input structure:
- bg = 黑色背景。网格中散布若干大小相同的正方形框架（边框由同一种颜色绘制，如 grey），每个框架内部包含一个由另一种颜色绘制的小图案（sprite）。
- 每个框架内的小图案本身接近四折对称，但恰好在上、下、左、右四个方向之一缺少一小块像素，形成一个对称性缺口。
- 网格边缘有一个 4xN 的颜色图例区域，包含四行，每行左侧是一个方向指示符（用单像素箭头表示：上=一个像素在上方、下=一个像素在下方、左=一个像素在左方、右=一个像素在右方），右侧紧跟一个颜色色块（如 red、blue、green、yellow 各一个）。

Rule:
- 对每个框架，检测其内部图案的对称性缺口朝向哪个方向（上/下/左/右）。
- 在颜色图例中找到与该方向对应的颜色。
- 将框架内部的图案像素全部重新着色为该对应颜色，框架边框颜色不变。

Key insight: 解题的第一层推理是发现每个图案都"几乎对称"但有一个方向上的缺陷；第二层推理是将缺陷方向与边缘图例中的方向-颜色映射表对应起来，从而确定重着色的颜色。
</new_puzzle>

<new_puzzle>
将散落的彩色碎片按形状互补配对，拼合成完整矩形后按面积从小到大排列输出。

Input structure:
- bg = 黑色背景。网格上散布若干不规则形状的彩色碎片，每个碎片是一个 4-连通的单色区域。
- 碎片总数为偶数。每两个碎片恰好能拼成一个实心矩形（一个碎片的形状是另一个碎片在同尺寸矩形内的补集）。互补配对的两个碎片颜色不同。
- 网格中没有其他标记或边界。

Rule:
- 找到每个碎片的最小外接矩形（bounding box）。
- 将外接矩形尺寸相同的碎片两两配对：对于同尺寸的两个碎片 A 和 B，将 A 的形状在其外接矩形内取补集，若补集与 B 的形状（经过平移对齐后）完全吻合，则 A 和 B 互为配对。
- 将每对碎片合并：在同一个外接矩形中，A 保留原色，B 也保留原色，两者拼合形成一个双色实心矩形。
- 将所有拼合后的矩形按面积从小到大、从左到右排列在输出网格中，矩形之间间隔一列黑色背景。

Key insight: 解题者需要先发现碎片之间存在"形状互补"关系——两块碎片的形状加在一起恰好填满一个矩形；然后需要发现输出的排列顺序由拼合后矩形的面积决定。形状配对需要空间想象力，而非简单的颜色或位置匹配。
</new_puzzle>

<new_puzzle>
根据封闭区域内种子像素的数量，从区域边界向内逐层剥离着色，层数等于种子数。

Input structure:
- bg = 黑色背景。网格中有若干由 grey 颜色绘制的封闭多边形轮廓（轮廓宽度为 1 像素，形状为简单的矩形或 L 形等正交多边形）。
- 每个封闭区域内部散布若干单像素的种子点，种子点颜色统一为 red。
- 封闭区域的内部（除种子点外）全部为黑色背景。

Rule:
- 对每个封闭区域，数出其内部 red 种子像素的数量 N（N 不超过 5）。
- 从该区域的 grey 轮廓开始，向内逐层"剥皮"着色：第 1 层（紧贴轮廓内侧的一圈像素）着色为 blue，第 2 层着色为 green，第 3 层着色为 yellow，第 4 层着色为 magenta，第 5 层着色为 orange。总共着色 N 层。
- 层的定义：第 k 层是所有与第 k-1 层（第 0 层为 grey 轮廓本身）4-邻接且尚未着色的内部像素。
- 着色完成后，种子像素被移除（变为黑色），灰色轮廓保留不变。

Key insight: 第一层推理是发现种子数量控制着色层数；第二层推理是理解"层"的含义——每一层是从边界向内的等距收缩环，颜色按固定序列分配。种子本身不参与最终输出，仅作为计数器。
</new_puzzle>

<new_puzzle>
识别网格中每个"迷宫房间"的出口方向，将房间内的箭头图案旋转至指向该出口，然后沿出口方向将箭头平移到房间外墙上。

Input structure:
- bg = 黑色背景。网格被 blue 颜色的线条分割成若干矩形"房间"（类似迷宫布局，线条宽度为 1 像素）。
- 每个房间的四面墙中恰好有一面墙上有一个 1 像素宽的缺口（即该墙的某一段 blue 像素被移除，露出黑色背景），这是房间的"出口"。
- 每个房间内部包含一个由 red 像素绘制的小箭头图案（3x3 大小）。箭头初始朝向可能是上、下、左、右中的任意方向。箭头的绘制方式：中心像素 + 指向方向的一个像素 + 垂直于指向方向的两侧各一个像素（形成 T 字形的箭头头部）+ 指向方向反方向的一个像素（箭尾）。

Rule:
- 对每个房间，找到其墙壁上的缺口位置，确定出口方向（缺口在上墙则出口朝上，在下墙则出口朝下，以此类推）。
- 将房间内的 red 箭头旋转（0度、90度、180度、270度），使箭头指向出口方向。
- 将旋转后的箭头从房间内部平移，使箭头的头部像素恰好位于缺口处（箭头从房间内"射出"到缺口位置）。
- 清除箭头原始位置的像素（变为黑色背景）。

Key insight: 第一层推理是发现每个房间有且仅有一个缺口，缺口所在的墙面决定了出口方向；第二层推理是理解箭头需要被旋转至指向出口方向并平移到缺口处——箭头的初始朝向是干扰项，真正决定最终朝向的是房间结构。
</new_puzzle>

<new_puzzle>
按照"信号塔"的高度顺序接力传播射线，每座塔向下一座塔发射水平射线，射线颜色由发射塔的塔顶色块决定，遇到中间障碍塔时射线需绕行。

Input structure:
- bg = 黑色背景。网格中分布若干"信号塔"：每座塔由一根竖直的 grey 柱体和柱体顶端的一个单色色块组成。柱体从网格底部向上延伸，高度各不相同（以像素行数表示，范围 2-10）。塔顶色块为 1x1 像素，颜色各不相同（如 red、blue、green、yellow、orange 等）。
- 各塔之间在水平方向上有间隔，不会重叠。
- 网格底部有一行 maroon 像素作为"地面线"。

Rule:
- 按塔的高度从高到低排序（最高的塔排第一）。
- 从最高的塔开始，向第二高的塔发射一条水平射线：射线从最高塔的塔顶位置水平出发（朝向第二高塔的方向），到达第二高塔所在列时停止。射线颜色为最高塔的塔顶色块颜色。
- 然后从第二高的塔的塔顶向第三高的塔发射水平射线，颜色为第二高塔的塔顶颜色。
- 依此类推，直到最矮的塔接收到射线。
- 若射线的水平路径被其他塔的柱体阻挡（即射线行高度低于中间某座塔的塔顶），则射线需要在被阻挡处向上绕行：射线先垂直向上到达阻挡塔顶上方一格，再水平继续前进，到达目标塔所在列后垂直向下回到原始行高。绕行部分的颜色与射线颜色相同。

Key insight: 第一层推理是发现塔的高度决定了信号传递的顺序——从高到低依次接力；第二层推理是理解射线的颜色由发射塔（而非接收塔）的塔顶颜色决定；第三层推理是发现当中间有更高的障碍塔时，射线必须绕行而非穿透，绕行路径形成"门"字形的折线。
</new_puzzle>

<new_puzzle>
将网格中的彩色环形轨道上的"火车"（连续色段）沿轨道滚动，滚动距离由轨道内部标记点的数量决定。

Input structure:
- bg = 黑色背景。网格中有若干由 grey 像素绘制的闭合环形轨道。每条轨道是一个正交的闭合回路（由水平段和垂直段组成，宽度为 1 像素，类似矩形环或 L 形环）。
- 每条轨道上有一段连续的非 grey 像素覆盖在轨道上，形成一列"火车"——火车的颜色各不相同（如 red、blue、green 等），火车占据轨道上连续的若干格。轨道的其余部分保持 grey。
- 每条轨道所围成的内部区域中，散布着若干 yellow 标记像素（1x1 大小）。

Rule:
- 对每条轨道，数出其内部区域中 yellow 标记像素的数量 N。
- 将该轨道上的火车沿轨道顺时针方向滚动 N 步（每步移动一个像素位置）。火车离开的格子恢复为 grey，火车到达的格子变为火车颜色。
- 顺时针方向的定义：沿轨道外侧朝右看时的前进方向；具体地，对于矩形环，上边向右、右边向下、下边向左、左边向上。
- yellow 标记像素在输出中保持不变。

Key insight: 第一层推理是发现轨道内部的黄色标记点数量控制火车的移动距离；第二层推理是理解"沿轨道滚动"意味着火车要沿着环形路径前进，在轨道拐角处改变方向，而非直线平移。火车的长度不变，只是位置沿轨道推进。
</new_puzzle>

<new_puzzle>
在棋盘格背景上，根据同色区块配对，在两者之间绘制桥梁，桥梁的线条样式由区块的内部纹理编码决定。

Input structure:
- bg = 由 black 和 grey 交替排列的棋盘格背景（每格 1x1 像素）。
- 网格上散布若干小型矩形色块（3x3 或 4x4），每个色块有一个边框颜色和一个内部纹理。边框颜色有多种（如 red、blue、green），每种边框颜色恰好出现两个色块。
- 每个色块的内部纹理是以下三种之一：全实心填充、水平条纹（交替填色行和空行）、垂直条纹（交替填色列和空列）。同色配对的两个色块内部纹理相同。

Rule:
- 将每种边框颜色的两个色块配对。
- 对每对色块，在两者之间绘制连接桥梁。桥梁的路径是 L 形折线：先沿水平方向从一个色块的中心行延伸到另一个色块所在列，再沿垂直方向到达另一个色块的中心行。
- 桥梁的线条宽度为 1 像素，颜色与色块的边框颜色相同。
- 桥梁的线条样式由色块内部纹理决定：全实心纹理对应桥梁为连续实线；水平条纹纹理对应桥梁为虚线（每隔一个像素画一个像素）；垂直条纹纹理对应桥梁为双线（在桥梁线条两侧各偏移一像素处再画一条平行线）。

Key insight: 第一层推理是通过边框颜色匹配找到配对；第二层推理是发现色块内部的纹理并非装饰，而是编码了桥梁的线条样式——实心、虚线、双线三种样式与三种纹理一一对应。
</new_puzzle>
