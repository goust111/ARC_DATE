- `description`：根据封闭区域内部"种子"图案的朝向，选择对应的染色模板，将该区域的背景像素填充为模板图案。

- `Input structure`：
  - 背景色（bg）为最常见颜色。网格中有若干由同一颜色（边框色）绘制的封闭矩形区域，区域大小不一但内部尺寸均为偶数×偶数。
  - 每个封闭区域内部有一个由两个相邻像素组成的"种子"标记（非边框色、非背景色），两个像素颜色相同但与其他区域的种子颜色可能不同。种子的朝向有四种：水平排列（左右）或垂直排列（上下）。
  - 网格的某个角落（如左上角）有一个独立的参考面板，面板内包含两个小方块模板（如 3×3），分别标记为"H 模板"和"V 模板"：其中一个模板旁边有一个水平种子示例，另一个旁边有一个垂直种子示例。两个模板使用 Red 和 Green 两种颜色绘制不同的几何图案（如条纹 vs 棋盘格）。

- `Rule`：
  - 首先识别参考面板中的两个模板及其对应的种子朝向：水平种子对应 H 模板，垂直种子对应 V 模板。
  - 对网格中每个封闭矩形区域，判断其内部种子的朝向（水平或垂直）。
  - 将对应的模板以平铺方式填充该区域内部所有背景像素（模板从区域左上角开始平铺），但保留种子像素不覆盖。模板中的颜色替换为该区域种子的实际颜色。
  - 参考面板在输出中保持不变。

- `Key insight`：种子的空间朝向（水平 vs 垂直）是选择填充模板的索引键，而种子的颜色决定填充时使用的实际着色——需要同时从面板学习"朝向→模板"的映射关系，并从种子提取颜色信息。
</new_puzzle>

<new_puzzle>
- `description`：将散落的彩色碎片按照它们与"磁铁条"的颜色匹配关系吸附到磁铁条上，吸附侧由碎片上的缺口方向决定。

- `Input structure`：
  - 背景色（bg）为 Black。网格中有若干水平或垂直的单色长条（"磁铁条"），每根磁铁条颜色不同（如 Red、Blue、Green 等），长度至少为 4 像素，宽度为 1 像素。
  - 网格中另有若干 3×3 的小方块碎片，每个碎片的主体由某种颜色填满 3×3 区域，但恰好缺少一条边上的中间像素（即 3×3 中去掉上/下/左/右边中央的一个像素），形成一个 8 像素的"缺口方块"。碎片的颜色与某根磁铁条颜色相同。
  - 每根磁铁条恰好有 1-2 个同色碎片与之对应。

- `Rule`：
  - 对每个碎片，找到与其颜色相同的磁铁条——这是它的目标磁铁条。
  - 碎片的缺口方向（上/下/左/右）指示碎片应该从哪一侧贴靠磁铁条。例如缺口朝右，表示碎片的右侧是"吸附面"，碎片应从右侧贴到磁铁条的左边。
  - 碎片沿缺口方向平移（不旋转），直到缺口边紧贴磁铁条。碎片贴靠后，缺口处的像素被磁铁条的像素填补（视觉上碎片变成完整 3×3）。
  - 若同一磁铁条有两个碎片，它们分别贴靠在磁铁条的不同位置（沿磁铁条方向依次排列，先上/先左的碎片优先占据靠近磁铁条端点的位置）。
  - 碎片原始位置变为背景色。

- `Key insight`：缺口不是缺陷而是"方向指示器"——缺口朝向编码了碎片应贴靠磁铁条的方位；颜色匹配建立碎片与磁铁条的归属关系，缺口方向决定贴靠的空间关系。
</new_puzzle>

<new_puzzle>
- `description`：在网格中识别由墙壁围成的"管道网络"，根据入口处注入的颜色信号沿管道传播，在交叉口按照通道宽度优先规则分流。

- `Input structure`：
  - 背景色（bg）为 Black。Grey 像素构成管道的墙壁，墙壁之间留出宽度为 1 到 3 像素的通道（即管道内部）。管道在某些位置形成 T 形或十字形交叉口。
  - 管道的若干末端（死端）开口处紧邻网格边缘，这些开口处各有一个彩色像素（如 Red、Blue、Orange 等）作为"注入信号"。每个开口的信号颜色不同。
  - 管道内部（墙壁之间的通道）初始全部为背景色。

- `Rule`：
  - 从每个注入信号像素开始，沿其所在管道通道向内部扩散，将通道内的背景像素染为该信号颜色。
  - 当信号到达 T 形或十字形交叉口时，信号只进入交叉口中**通道最宽**的那条分支（通道宽度 = 垂直于通道方向的连续背景像素数）。若有多条分支宽度相同，则信号同时进入所有同宽的最宽分支。
  - 信号传播直到遇到管道死端、已被其他颜色占据的像素或网格边缘。
  - 若两种信号同时到达某段管道（理论上不会出现，因宽度优先规则保证分流确定），则保留先到达的信号（距注入点管道路径更短的信号）。

- `Key insight`：交叉口处的"通道宽度"是肉眼可直接度量的视觉属性（数墙壁之间的像素列数），它充当信号的路由规则——解题者需要先理解信号沿管道流动的基本机制，再发现宽度优先的分流策略，构成两层推理结构。
</new_puzzle>

- `description`：将网格中的彩色"印章"对象按照其内部空洞的形状，盖印到网格中对应形状的灰色"底座"上，印章颜色覆盖底座。

- `Input structure`：
  - 背景色（bg）为 Black。网格中有若干 Grey 色的小型连通区域（"底座"），每个底座形状各异（如 L 形、T 形、直线段等），大小在 3-6 像素之间。
  - 网格中另有若干彩色连通区域（"印章"），每个印章是一个较大的矩形色块（如 5×5 或 6×6），内部挖去了一个与某个底座形状完全相同的空洞（空洞为背景色）。印章颜色各不相同（如 Red、Blue、Green、Orange 等）。
  - 底座数量与印章数量相同，且每个印章内部的空洞形状恰好与一个底座的形状一一对应（形状匹配时可能需要考虑平移对齐，但不需要旋转或翻转）。

- `Rule`：
  - 对每个印章，提取其内部空洞的形状（相对于空洞左上角的像素坐标集合）。
  - 在所有底座中找到形状完全匹配的那个底座（像素相对位置集合相同）。
  - 将该底座的所有 Grey 像素替换为印章的颜色。
  - 印章本身在输出中保持不变（包括其空洞）。

- `Key insight`：匹配的线索藏在印章的"负空间"里——空洞是底座的精确倒模。解题者必须先意识到印章的空洞形状才是关键信息（而非印章的外轮廓），再将负空间与底座的正形状进行匹配，这构成了"发现线索藏在哪里"和"执行形状匹配"两层推理。
</new_puzzle>

<new_puzzle>
- `description`：根据网格边缘"刻度尺"上彩色标记的位置，在网格内部对应的行列交叉点处绘制该颜色的十字星图案，十字星的臂长由刻度尺上相邻同色标记之间的间距决定。

- `Input structure`：
  - 背景色（bg）为 Black。网格的顶部边缘行和左侧边缘列充当"刻度尺"，其余部分为空白画布。
  - 顶部刻度尺（第 0 行）上分布着若干彩色像素，每种颜色恰好出现两次，两个同色像素之间间隔若干背景像素。
  - 左侧刻度尺（第 0 列）上同样分布着若干彩色像素，每种颜色也恰好出现两次。
  - 顶部和左侧的颜色集合相同（例如都使用 Red、Blue、Green 这三种颜色）。

- `Rule`：
  - 对每种颜色 C，在顶部刻度尺上找到两个 C 色像素的列坐标，计算它们的中点列 col_C；在左侧刻度尺上找到两个 C 色像素的行坐标，计算它们的中点行 row_C。(row_C, col_C) 即为颜色 C 的十字星中心。
  - 十字星的臂长 = 顶部刻度尺上两个 C 色像素之间的间距（即两个像素之间背景像素的数量）。左侧刻度尺上同色两像素的间距与顶部相同（作为冗余验证）。
  - 在画布上以 (row_C, col_C) 为中心，向上、下、左、右四个方向各延伸臂长个像素，绘制颜色 C 的十字星（即一条垂直线段和一条水平线段的交叉）。若臂超出画布边界则截断。
  - 不同颜色的十字星可能重叠；后绘制的颜色覆盖先绘制的（绘制顺序为臂长从小到大，即小十字星在上层）。

- `Key insight`：刻度尺上同色标记对的"间距"同时编码了两个独立信息——中点决定十字星的位置，间距本身决定十字星的大小。解题者需要先发现同色配对关系，再分别推理出中点定位规则和间距定尺寸规则，最后理解绘制顺序的覆盖逻辑，构成三层递进推理。
</new_puzzle>

- `description`：网格中散布的彩色"信封"对象各自包裹着一个小图案；将每个信封拆开后，根据信封上"邮戳"标记的颜色，把内部图案投递到网格中对应颜色围栏内的空白区域。

- `Input structure`：
  - 背景色（bg）为 Black。网格中有若干由不同颜色绘制的矩形空心围栏（如 Red 围栏、Blue 围栏等），围栏内部为背景色，围栏大小各不相同。
  - 网格中另有若干"信封"：每个信封是一个 Maroon 色的实心矩形，内部包裹着一个小型多色图案（图案被 Maroon 色完全包围，图案与 Maroon 边框之间恰好间隔 1 像素的背景色作为"内衬"）。
  - 每个信封的外表面（Maroon 矩形边框上）恰好有一个像素被替换为另一种颜色，该像素称为"邮戳"，邮戳颜色与某个围栏颜色相同。
  - 信封数量与围栏数量相同，每个信封的邮戳颜色恰好匹配一个围栏。

- `Rule`：
  - 对每个信封，提取其内部的小图案（去掉 Maroon 边框和背景色内衬后的彩色像素）。
  - 读取信封上邮戳的颜色，找到网格中对应颜色的围栏。
  - 将提取的图案放置到围栏内部的中央位置（水平和垂直都居中；若无法精确居中则偏左上）。
  - 在输出中，信封从原位置消失（变为背景色），围栏保持不变，图案出现在围栏内部。

- `Key insight`：解题者需要三步推理——首先识别 Maroon 矩形为"信封"并理解内部图案的提取方式（跳过内衬层），然后发现边框上的异色像素是"邮戳"而非噪声，最后建立邮戳颜色到围栏颜色的投递映射。信封的嵌套结构（边框→内衬→图案）增加了图案提取的隐蔽性。
</new_puzzle>

<new_puzzle>
- `description`：网格中的彩色路径段在"镜面"墙壁上反射后继续延伸，反射时颜色按照墙壁上标注的颜色映射表发生转换。

- `Input structure`：
  - 背景色（bg）为 Black。网格中有若干 Grey 色的直线墙壁（水平或垂直，宽度 1 像素）。
  - 每面墙壁的某一端有一个 2×1 或 1×2 的"映射标签"：由两个不同颜色像素上下（或左右）排列组成，表示"颜色 A → 颜色 B"的转换关系（上/左像素为 A，下/右像素为 B）。
  - 网格边缘处有若干彩色像素作为"光源"，每个光源发出一条沿水平或垂直方向的射线（方向为从边缘指向网格内部）。

- `Rule`：
  - 每条射线从光源出发，沿其方向在背景上绘制该颜色的像素。
  - 当射线碰到 Grey 墙壁时发生反射：射线碰到垂直于其行进方向的墙壁时，转弯 90°，转弯方向取决于射线碰到墙壁的位置相对于墙壁中点的哪一侧：靠近墙壁上端/左端则向上/向左转，靠近下端/右端则向下/向右转。
  - 反射的同时，射线颜色按照该墙壁映射标签的规则转换：若射线当前颜色为标签中的 A，则变为 B；若为 B 则变为 A；若不在标签中则颜色不变。
  - 射线继续前进直到碰到下一面墙壁（再次反射并可能再次变色）、碰到网格边缘或碰到已着色像素则停止。

- `Key insight`：解题者需要先理解射线遇到墙壁时的转弯规则（碰撞点相对于墙壁中点的位置决定转向），再发现墙壁端部的双色标签不是装饰而是颜色转换指令，两层规则叠加使得最终路径的颜色序列难以一眼看穿。
</new_puzzle>
