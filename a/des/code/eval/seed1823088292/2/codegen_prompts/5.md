- `Input structure`：
  - 背景色（bg）为 Black。网格的顶部边缘行和左侧边缘列充当"刻度尺"，其余部分为空白画布。
  - 顶部刻度尺（第 0 行）上分布着若干彩色像素，每种颜色恰好出现两次，两个同色像素之间间隔若干背景像素。
  - 左侧刻度尺（第 0 列）上同样分布着若干彩色像素，每种颜色也恰好出现两次。
  - 顶部和左侧的颜色集合相同（例如都使用 Red、Blue、Green 这三种颜色）。

- `Rule`：
  - 对每种颜色 C，在顶部刻度尺上找到两个 C 色像素的列坐标，计算它们的中点列 col_C；在左侧刻度尺上找到两个 C 色像素的行坐标，计算它们的中点行 row_C。(row_C, col_C) 即为颜色 C 的十字星中心。
  - 十字星的臂长 = 顶部刻度尺上两个 C 色像素之间的间距（即两个像素之间背景像素的数量）。左侧刻度尺上同色两像素的间距与顶部相同（作为冗余验证）。
  - 在画布上以 (row_C, col_C) 为中心，向上、下、左、右四个方向各延伸臂长个像素，绘制颜色 C 的十字星（即一条垂直线段和一条水平线段的交叉）。若臂超出画布边界则截断。
  - 不同颜色的十字星可能重叠；后绘制的颜色覆盖先绘制的（绘制顺序为臂长从小到大，即小十字星在上层）。

- `Key insight`：刻度尺上同色标记对的"间距"同时编码了两个独立信息——中点决定十字星的位置，间距本身决定十字星的大小。解题者需要先发现同色配对关系，再分别推理出中点定位规则和间距定尺寸规则，最后理解绘制顺序的覆盖逻辑，构成三层递进推理。

## 实现要求

1. `main(grid)` 必须实现新题描述中的确定性转换规则，不能只识别 `generate_input()` 的固定模板。
