- `description`：根据颜色框架内嵌套小图案的朝向，选取对应的调色板行，将框架内部重新着色。

- `Input structure`：
  - 背景色为 black。
  - 网格中散布若干大小相同的矩形空心框架，每个框架由单一颜色绘制（如 red、blue、green 等），框架线宽为 1 像素。
  - 每个框架内部（被框架围住的区域）有一个用 grey 绘制的小型方向指示图案：一个 3x3 的 L 形，L 的朝向为四种之一（左上、右上、左下、右下），即 L 形的拐角分别位于 3x3 区域的四个角之一，L 的两条臂各占 2 像素。
  - 网格的某一条边（如底边）紧贴着一个调色板区域：一个 4 行 x N 列的色块表，每行对应一个方向（从上到下依次对应：左上、右上、左下、右下），每行有 N 个色块，N 等于框架内部去掉 L 图案后剩余空白区域的像素数。调色板行的颜色各不相同。

- `Rule`：
  - 首先识别每个框架内部 L 形图案的朝向（左上、右上、左下、右下）。
  - 根据朝向在调色板中选取对应的行（第 1 行=左上，第 2 行=右上，第 3 行=左下，第 4 行=右下）。
  - 将框架内部的所有非 grey 像素（即背景空白像素），按照从左到右、从上到下的顺序，依次用选中行中的色块逐一填充。
  - L 形图案本身保留为 grey 不变，框架颜色不变。
  - 调色板区域在输出中被移除（替换为背景色）。

- `Key insight`：L 形图案不仅是装饰，其拐角位置编码了一个四选一的查表索引；解题者需要先识别 L 的朝向与调色板行的对应关系，再用选中行的色序逐像素填充内部空白。两步推理缺一不可——仅看到"L 在里面"或"调色板在边上"都不足以独立推断规则。
</new_puzzle>

- `description`：将网格中分散的碎片拼回由边框颜色指定的目标容器内，拼入位置由碎片自身携带的角标色点决定。

- `Input structure`：
  - 背景色为 black。
  - 网格中有若干矩形"容器"，每个容器由特定颜色的单像素边框围成（如 red 边框、blue 边框），容器内部完全为背景色，内部尺寸各不相同。
  - 网格中还散布着若干小型多色图案（碎片），每个碎片是一个紧凑的像素块（不超过 5x5），其主体使用一种颜色绘制，但碎片的四个角中恰好有一个角像素被涂成了某个容器边框的颜色（角标色点）。
  - 每个容器的内部尺寸恰好等于所有属于它的碎片拼合后的最小矩形——碎片按角标色点的位置（左上角、右上角、左下角、右下角）分别放入容器的对应象限。

- `Rule`：
  - 通过碎片角标色点的颜色判断该碎片属于哪个容器（颜色匹配容器边框色）。
  - 角标色点所在的角位（左上 / 右上 / 左下 / 右下）指示碎片在容器内部的放置象限：角标在碎片左上角 → 放入容器左上象限，以此类推。
  - 将碎片放入对应象限时，角标色点的角紧贴容器的对应内角。碎片不旋转、不翻转。
  - 放置后，角标色点本身被替换为碎片主体颜色（即角标消失）。
  - 原始碎片所在位置清除为背景色。

- `Key insight`：解题者需要完成两层归纳——第一层是发现角标色点的颜色与容器边框颜色的匹配关系（决定碎片去向），第二层是发现角标在碎片中的角位决定了碎片在容器中的放置象限。两层信息都编码在同一个角标像素上，但分别编码了不同维度的信息。
</new_puzzle>

<new_puzzle>
- `description`：根据种子像素的颜色在网格的分区中生长出特定形状的图案，生长的层数由同一分区内另一种标记像素的数量决定。

- `Input structure`：
  - 背景色为 black。
  - 网格被 grey 色的十字线（完整的行和列）分割成若干大小相等的矩形分区。
  - 每个分区中央（或接近中央）有一个"种子像素"，颜色为 red、blue 或 green 三者之一。
  - 每个分区中还散布着若干 yellow 色的单像素标记点（数量从 1 到 4 不等）。
  - 不同颜色的种子对应不同的生长形状：red → 菱形（以种子为中心，第 k 层是所有与种子行距加列距之和等于 k 的像素），blue → 正方形框（第 k 层是以种子为中心边长为 2k+1 的正方形轮廓），green → 十字形（仅沿上下左右四个方向延伸，第 k 层是四个方向各距种子 k 步的像素）。

- `Rule`：
  - 对每个分区，数出其中 yellow 标记点的数量 N（N 范围 1-4）。
  - 以种子像素为中心，按种子颜色决定的形状，向外生长 N 层，每层都用种子颜色绘制。
  - 生长不超出分区边界；如果某一层的部分像素落在分区外，则只绘制分区内的部分。
  - yellow 标记点在输出中被移除（变为背景色）。
  - grey 分割线保持不变。

- `Key insight`：解题者需要同时归纳两条独立规则并将它们交叉应用——种子颜色决定生长的几何形状（三种颜色三种形状，需要对比多个样例才能确认映射关系），而同分区内 yellow 点的数量决定生长的层数。单独发现任何一条规则都不够，必须两条同时正确才能重现输出。
</new_puzzle>

<new_puzzle>
- `description`：识别网格中多个传送门对，将穿过传送门的射线在出口处以镜像方向延续，射线颜色在每次传送后改变为出口传送门的颜色。

- `Input structure`：
  - 背景色为 black。
  - 网格中有若干成对出现的同色小方块（2x2），每种颜色恰好出现两个方块，构成一对"传送门"。颜色可能包括 red、blue、green、orange 等，共 2-4 对。
  - 每对传送门的两个方块分别位于网格的不同位置。
  - 网格某一条边上有一个 maroon 色的单像素"发射器"，以及紧邻发射器内侧的一个 yellow 色箭头标记（由 3 个像素组成的 L 形或直线形），指示射线的初始发射方向（上、下、左、右四个基本方向之一）。

- `Rule`：
  - 从发射器出发，沿 yellow 箭头指示的方向发射一条 maroon 色射线（逐像素延伸）。
  - 射线沿途如果碰到某个传送门方块的边缘像素，射线立即从该传送门的配对方块的对应边缘位置射出。射出方向为入射方向的延续（保持不变），但射线从配对方块的对侧边缘开始继续。
  - 射线从传送门出口射出后，颜色变为该出口传送门方块的颜色。
  - 射线继续延伸，可以再次进入其他传送门（或同一对的另一个），规则相同。
  - 射线到达网格边界时停止。
  - 传送门方块本身保留原色不变，射线覆盖的背景像素被着色。

- `Key insight`：解题者需要逐层拆解三个嵌套机制——第一层：识别同色方块对构成传送门（颜色配对）；第二层：理解射线遇到传送门时的空间映射关系（从一个方块进入，从配对方块的对侧射出，方向不变）；第三层：射线颜色在每次传送后继承出口门的颜色，因此最终路径呈现分段变色的特征。仅靠单个样例很难区分这三层规则，需要多个样例中不同的门排列和射线路径来逐一验证。
</new_puzzle>

<new_puzzle>
- `description`：将散落的单色矩形按面积从大到小依次嵌套堆叠为同心矩形结构，每层缩进一圈，颜色按面积排名映射。

- `Input structure`：
  - 背景色为 black。
  - 网格中散布着若干个不同颜色的实心矩形（每个矩形为单一颜色，如 red、blue、green、yellow、orange 等），颜色各不相同。
  - 这些矩形大小各异（面积互不相同），都是轴对齐的矩形。
  - 所有矩形均不重叠，彼此间有背景色间隔。

- `Rule`：
  - 按面积从大到小对所有矩形排序。
  - 最大矩形保持其位置和大小不变，作为最外层容器。
  - 第二大矩形的颜色成为嵌套的第二层：在最大矩形内部绘制一个上下左右各缩进 1 像素的同心矩形，颜色为第二大矩形的颜色。
  - 第三大矩形的颜色成为第三层：在第二层内部再缩进 1 像素绘制，以此类推。
  - 每一层都是实心填充（覆盖内部所有像素），后绘制的层覆盖先绘制的层，因此最终效果为同心矩形环。
  - 不参与嵌套的原始矩形位置被清除为背景色（即除最大矩形外，其余矩形从原位消失）。
  - 如果矩形数量多到内层缩进后宽或高不足 1 像素，则忽略剩余矩形。

- `Key insight`：解题者首先需要发现输出中的同心矩形嵌套结构并非凭空出现，而是由输入中散落的独立矩形"折叠"而成。第一层推理是发现面积排序决定嵌套层级——面积最大者为外壳，依次向内。第二层推理是发现每层的颜色并非按空间位置分配，而是严格按面积排名映射：排名第 k 的矩形颜色出现在从外往内第 k 层。两层规则交织后才能正确重建输出。
</new_puzzle>

<new_puzzle>
- `description`：沿封闭轮廓线传播染色波，波的传播距离由信号源的连续像素长度编码，不同颜色的波相遇时混合为第三种颜色。

- `Input structure`：
  - 背景色为 black。
  - 网格中有若干 grey 色的不规则封闭轮廓线（单像素宽，4-连通闭合），形成类似岛屿边界的闭合曲线。
  - 轮廓线上的某些位置的 grey 像素被替换为彩色"信号源"像素。每个信号源由一段连续的同色像素组成（占据轮廓线上连续的 1-5 个像素位置），颜色为 red 或 blue。
  - 每条轮廓线上可能有 1-3 个信号源，颜色可能相同或不同。

- `Rule`：
  - 对每个信号源，数出它占据的连续像素数量 L。
  - 信号源沿轮廓线向两侧各传播 L 个像素，将沿途的 grey 像素染为信号源的颜色。传播方向沿轮廓线的 4-连通路径行进。
  - 如果两个不同颜色的信号源（一个 red、一个 blue）的传播范围在轮廓线上重叠，重叠区域的像素被染为 magenta（代表 red 与 blue 的混合）。
  - 如果两个同色信号源的传播范围重叠，重叠区域保持该颜色不变。
  - 信号源自身的像素颜色保持不变。
  - 未被任何波触及的轮廓像素保持 grey。
  - 轮廓线内部和外部的背景区域不受影响。

- `Key insight`：解题者需要先发现信号源长度编码了传播距离（第一层推理：连续像素数 = 沿轮廓传播的步数），再沿着轮廓线追踪传播路径并判断覆盖范围（第二层推理：传播沿轮廓曲线而非直线扩散），最后识别颜色混合规则（第三层推理：red + blue = magenta）。信号源长度的编码方式较为隐蔽，因为看起来只是轮廓上一段稍长的彩色标记，不容易第一眼就联想到"长度=传播距离"。
</new_puzzle>
