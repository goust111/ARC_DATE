- 以封闭区域左上角为起点，将该纹理单元周期性地平铺到整个封闭区域内部（仅覆盖 black 像素，不覆盖标记点本身，标记点保留原色）。
- grey 边界和调色板区域保持不变。

Key insight：标记点颜色是查找调色板的索引键，而调色板中的纹理单元需要被识别并周期性铺展——解题者需要先建立颜色到纹理的映射关系，再理解纹理的平铺机制。

Key insight：箭头同时编码了源图案的身份（紧邻哪个图案）和传输方向（指向哪个目标框），而路径上的 orange 点数量编码了旋转角度——解题者需要先理解箭头的双重角色，再发现 orange 点计数与旋转的关系。

Input structure：
- 背景色为 black。
- 网格中央有一个嵌套的矩形结构：最外层是一个大矩形边框（由某种颜色如 blue 的单像素线绘制），其内部包含一个较小的矩形边框（另一种颜色如 green），再内部可能还有更小的矩形边框（如 red），最内层包含一个小的非对称彩色图案（种子图案，使用 maroon 绘制）。
- 网格的顶部一行放置着一个"颜色序列图例"：从左到右排列着若干单像素色块，每个色块的颜色对应一种变换操作。图例中颜色的排列顺序从左到右分别对应：水平翻转、垂直翻转、顺时针旋转 90°、逆时针旋转 90°。图例恰好包含 4 个像素，颜色各不相同。

- 从嵌套矩形的最外层边框开始，记录从外到内每层边框的颜色序列。
- 对每层边框的颜色，在颜色序列图例中查找其位置（第几个），该位置对应一种变换操作。
- 从最外层开始，依次对种子图案施加每层对应的变换操作（即先施加最外层对应的变换，再施加次外层的变换，以此类推）。
- 输出为仅包含最终变换后种子图案的紧凑裁剪网格（去掉所有边框和背景）。

Key insight：解题者需要发现三层独立的结构——嵌套边框的颜色序列定义了操作顺序，颜色图例定义了颜色到操作的映射，而种子图案是被操作的对象。三者缺一不可，且图例的位置编码需要通过对比多个样例才能确认。
</new_puzzle>

description：将网格中散落的彩色碎片按颜色分组，每组碎片拼合成一个完整矩形，然后按矩形面积从小到大的顺序将它们依次堆叠到输出网格的指定锚点位置，大的在下小的在上。

Input structure：
- 背景色为 black。
- 网格中散布着若干彩色像素块（碎片），每种颜色有 2 到 4 个不相邻的碎片。同一颜色的所有碎片恰好可以无重叠、无间隙地拼合成一个完整的实心矩形（碎片形状互补）。不同颜色拼成的矩形大小各不相同。
- 网格的某个角落（例如左下角）有一个由 grey 像素标记的单像素锚点。

Rule：
- 对每种颜色，找到该颜色的所有碎片。
- 将同色碎片在脑中平移拼合（不旋转、不翻转），得到一个完整的实心矩形。拼合方式唯一：碎片之间的相对行列偏移量使得合并后恰好形成矩形。具体来说，碎片的相对位置由它们各自最小外接矩形之间的关系暗示——将所有同色碎片的坐标集合视为一个整体时，其最小外接矩形恰好就是拼合后的矩形。
- 按矩形面积从大到小排序。
- 以锚点为所有矩形的左下角对齐点，先放最大的矩形，再依次放较小的矩形，后放的矩形覆盖先放的矩形（即小的在上层）。
- 输出网格仅包含堆叠后的矩形区域（紧凑裁剪），不保留原始碎片的位置信息。

Key insight：解题者首先需要发现同色碎片可以拼合成矩形这一非显然关系（碎片在网格中位置分散，不暗示拼合），然后需要发现堆叠顺序由面积决定且小的覆盖大的——两层推理缺一不可。
</new_puzzle>

<new_puzzle>
description：在一个包含多个"发射器-反射镜-接收器"光路系统的网格中，追踪每条光路的完整路径，根据光路经过的反射次数对接收器进行着色。

Input structure：
- 背景色为 black。
- 网格中存在若干彩色单像素点作为"发射器"，分布在网格边缘。每个发射器的颜色各不相同（例如 red、blue、green、yellow 等）。发射器发射方向为从边缘朝向网格内部的正交方向（位于左边缘的发射器向右发射，位于顶边缘的发射器向下发射，以此类推）。
- 网格内部散布着若干 grey 像素构成的短线段（长度 2-3 像素），作为"反射镜"。反射镜分为两种朝向：水平放置（横向排列的 grey 像素）和垂直放置（纵向排列的 grey 像素）。水平反射镜将垂直方向的光线反射为水平方向（向左或向右，取远离反射镜中心的一侧），垂直反射镜将水平方向的光线反射为垂直方向（向上或向下，取远离反射镜中心的一侧）。
- 网格中存在若干 azure 单像素点作为"接收器"，分布在网格内部。
- 每条光路从发射器出发，沿直线行进，遇到反射镜时改变方向，最终到达一个接收器（每条光路恰好到达一个接收器，每个接收器恰好被一条光路到达）。

Rule：
- 从每个发射器出发，沿其发射方向追踪光路。光线沿直线行进直到碰到反射镜或接收器。
- 碰到反射镜时，光线改变方向：水平镜将垂直光线转为水平方向，垂直镜将水平光线转为垂直方向。具体转向方向为：光线到达反射镜的哪一端就从该端沿新方向射出（即光线击中反射镜的位置决定转向方向——若击中反射镜左半部分则向左转弯，击中右半部分则向右转弯；对垂直镜同理取上下）。
- 统计每条光路经过的反射次数 N。
- 根据 N 的值对接收器着色：N=0（直达）→ 接收器变为发射器颜色；N=1 → 接收器变为 green；N=2 → 接收器变为 yellow；N=3 → 接收器变为 orange。着色规则通过观察样例中不同反射次数的光路及其接收器颜色来归纳。
- 光路本身不在输出中绘制，仅改变接收器颜色。发射器和反射镜保持不变。

Key insight：解题者需要先理解反射镜的方向转换规则以追踪每条光路（第一层推理），然后发现接收器的最终颜色不是简单地继承发射器颜色，而是由反射次数通过一个需要从样例中归纳的映射表来决定（第二层推理）。反射次数较少（0-3），人类可以通过视觉追踪直接数出。
</new_puzzle>

description：识别网格中多个"模板-印章"配对关系，根据模板内部的挖空图案在印章对应位置进行挖空，然后将所有印章的挖空碎片收集起来按特定规则拼装成输出图案。

Input structure：
- 背景色为 black。
- 网格中存在若干成对出现的彩色矩形实心块。每对包含一个"模板"和一个"印章"，二者大小完全相同。

- 印章是一个完整的实心矩形（无挖空），使用某种非 grey 的彩色绘制（例如 red、blue、green 等），每个印章颜色不同。
- 每个模板的正下方（间隔一行 black）恰好有一个与其大小相同的印章。模板在上，印章在下。
- 网格的右侧有一个由 maroon 单像素边框围成的空白矩形"输出区域"，其内部为 black。

- 将所有碎片按印章颜色对应的模板在网格中从左到右的排列顺序，依次叠加到输出区域中。叠加时，每个碎片与输出区域左上角对齐。后叠加的碎片中非 black 像素覆盖先前的内容。
- 输出为填充后的输出区域（包含 maroon 边框）。

Key insight：解题者需要发现模板与印章的上下配对关系（第一层），理解模板的镂空图案是印章的"选择掩码"而非直接使用模板本身（第二层），最后发现多个碎片按空间顺序叠加到输出区域的组合规则（第三层）。
</new_puzzle>

<new_puzzle>
description：根据网格中"样本行/列"展示的局部填色规律，将该规律推广到整个网格的所有行/列，完成全局填色。

Input structure：
- 背景色为 black。
- 网格被 grey 线条划分为规则的小格子（例如每个小格子 1x1，由 grey 网格线分隔），形成一个 M×N 的格子阵列。
- 大部分格子为 black（空）。
- 网格的某一行（"样本行"）中，部分格子被填上了彩色像素（使用 2-3 种颜色），形成一个看似随意的颜色序列。
- 网格的某一列（"样本列"）中，部分格子也被填上了彩色像素，形成另一个颜色序列。
- 样本行和样本列的交叉格子颜色一致（即该格子在行序列和列序列中颜色相同）。
- 网格中还散布着少量其他已着色格子作为验证线索。

Rule：
- 样本行定义了每一列的"列颜色"：样本行中第 j 列格子的颜色即为第 j 列的列颜色（若为 black 则该列无列颜色）。
- 样本列定义了每一行的"行颜色"：样本列中第 i 行格子的颜色即为第 i 行的行颜色（若为 black 则该行无行颜色）。
- 对网格中每个空格子 (i, j)：若第 i 行有行颜色且第 j 列有列颜色，则该格子填入行颜色与列颜色中、在样本行/列中出现位置更靠近交叉点的那个颜色；若仅有行颜色或仅有列颜色，则填入该颜色；若两者都没有，则保持 black。
- 更简洁地说：当行列颜色冲突时，行颜色优先（通过观察样例中已有的验证线索可归纳出此优先级规则）。
- 已有的着色格子保持不变。

Key insight：解题者需要先识别出哪一行是样本行、哪一列是样本列（通过找到着色最密集的行和列），然后理解行列颜色的"外积"填充逻辑（第一层推理），最后通过散布的验证线索发现颜色冲突时的优先级规则（第二层推理）。
</new_puzzle>
