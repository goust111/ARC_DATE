Input structure：
- 背景色为 black。
- 网格中存在若干彩色单像素点作为"发射器"，分布在网格边缘。每个发射器的颜色各不相同（例如 red、blue、green、yellow 等）。发射器发射方向为从边缘朝向网格内部的正交方向（位于左边缘的发射器向右发射，位于顶边缘的发射器向下发射，以此类推）。
- 网格内部散布着若干 grey 像素构成的短线段（长度 2-3 像素），作为"反射镜"。反射镜分为两种朝向：水平放置（横向排列的 grey 像素）和垂直放置（纵向排列的 grey 像素）。水平反射镜将垂直方向的光线反射为水平方向（向左或向右，取远离反射镜中心的一侧），垂直反射镜将水平方向的光线反射为垂直方向（向上或向下，取远离反射镜中心的一侧）。
- 网格中存在若干 azure 单像素点作为"接收器"，分布在网格内部。
- 每条光路从发射器出发，沿直线行进，遇到反射镜时改变方向，最终到达一个接收器（每条光路恰好到达一个接收器，每个接收器恰好被一条光路到达）。

Rule：
- 从每个发射器出发，沿其发射方向追踪光路。光线沿直线行进直到碰到反射镜或接收器。
- 碰到反射镜时，光线改变方向：水平镜将垂直光线转为水平方向，垂直镜将水平光线转为垂直方向。具体转向方向为：光线到达反射镜的哪一端就从该端沿新方向射出（即光线击中反射镜的位置决定转向方向——若击中反射镜左半部分则向左转弯，击中右半部分则向右转弯；对垂直镜同理取上下）。
- 统计每条光路经过的反射次数 N。
- 根据 N 的值对接收器着色：N=0（直达）→ 接收器变为发射器颜色；N=1 → 接收器变为 green；N=2 → 接收器变为 yellow；N=3 → 接收器变为 orange。着色规则通过观察样例中不同反射次数的光路及其接收器颜色来归纳。
- 光路本身不在输出中绘制，仅改变接收器颜色。发射器和反射镜保持不变。

Key insight：解题者需要先理解反射镜的方向转换规则以追踪每条光路（第一层推理），然后发现接收器的最终颜色不是简单地继承发射器颜色，而是由反射次数通过一个需要从样例中归纳的映射表来决定（第二层推理）。反射次数较少（0-3），人类可以通过视觉追踪直接数出。
