- `Input structure`：
  - 背景色为 black。
  - 若干条 1 像素宽的水平或垂直直线段（管道），每条管道使用不同颜色（如 red、blue、green、yellow、orange 等），在网格上相互交叉。
  - 交叉点处只显示一种颜色（即"上层"管道的颜色），被遮挡的管道颜色在交叉处不可见。
  - 网格左上角有一个小的"优先级提示框"（由 grey 边框围成的 N×1 竖列），框内从上到下排列若干颜色像素，但只列出了部分管道颜色（不是全部）。

- `Rule`：
  - 第一层推理——推断完整优先级：提示框中从上到下排列的颜色表示已知的优先级片段（上方 = 更高优先级 = 显示在上层）。未出现在提示框中的管道颜色，其优先级需从交叉点的实际遮挡关系中推断——在某个交叉点处，若颜色 A 可见而颜色 B 的线段在此中断，则 A 优先级高于 B。将所有管道颜色排成完整的优先级序列。
  - 第二层推理——分层擦除：按优先级从低到高处理。优先级最低的管道完全保留；优先级次低的管道在与更低优先级管道的交叉处被擦除（该交叉点变为更低优先级管道的颜色）；依此类推，每条管道仅在与比它优先级更低的管道交叉时被擦除。
  - 最终输出：所有交叉点处显示的颜色变为优先级最低（原本被遮挡）的管道颜色，即原来的遮挡关系完全反转。

- `Key insight`：提示框只给出部分排序，必须结合交叉点遮挡证据推断完整优先级；输出是将遮挡层序完全翻转，而非简单地移除某一层。

1. `main(grid)` 必须实现新题描述中的确定性转换规则，不能只识别 `generate_input()` 的固定模板。
