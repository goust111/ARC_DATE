  - 网格中散布着偶数个彩色碎片（4-连通区域），每种颜色恰好出现两个碎片。

  - 网格底部有一行 grey 像素组成的"位置条"，位置条上间隔均匀地标有若干 azure 点，azure 点的数量等于颜色对的数量。

- `Rule`：
  - 第一层推理——配对与合并：找到每对同色碎片，判断它们的镜像对称轴方向（水平或垂直）。将两个碎片沿对称轴拼合（即将一个碎片翻转后与另一个碎片的边缘对齐，使重叠的边界像素完全吻合），得到一个完整的合并图形。
  - 第二层推理——孔洞计数排序：统计每个合并图形内部封闭的 black 区域（孔洞）数量。按孔洞数从少到多排序。

- `Key insight`：碎片的颜色相同是配对线索，但必须找到正确的镜像轴才能完成合并；合并后的拓扑属性（孔洞数）决定输出排列，而非碎片的原始空间位置。
