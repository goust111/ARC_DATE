- `Input structure`：
  - 背景色为 black。
  - 网格被 grey 的十字分隔线均匀分割为 2×2 共四个象限区域，每个象限大小为 M×M（M ≥ 5）。
  - 左上象限包含一个由某颜色绘制的"原始图案"（一个非对称的小型精灵，占据象限内部的部分区域）。
  - 其余三个象限（右上、左下、右下）各自包含一个"时钟标记"：一个 3×3 的方框（由 maroon 绘制），方框中心为一个像素，从中心向上/右/下/左四个方向之一延伸出一个 maroon 像素作为"指针"。指针朝上表示 0°，朝右表示 90°，朝下表示 180°，朝左表示 270°。
  - 每个时钟标记旁边（与指针方向相反的一侧、紧贴方框外壁）有一个单像素色标，颜色与左上象限中原始图案的颜色不同——这是该象限输出图案应使用的颜色。

- `Rule`：
  - 第一层推理——读取旋转角度：解读每个象限中时钟标记的指针方向，得到旋转角度（0°/90°/180°/270°，均为顺时针）。
  - 第二层推理——旋转与重绘色：将左上象限的原始图案按对应角度顺时针旋转，并将图案颜色替换为该象限色标像素的颜色。

- `Key insight`：时钟指针编码旋转角度，色标编码输出颜色，两者必须同时解读才能正确生成每个象限的输出；图案的放置位置需要理解"先平移到对应象限、再以象限中心为轴旋转"的两步定位过程。

## 实现要求

1. `main(grid)` 必须实现新题描述中的确定性转换规则，不能只识别 `generate_input()` 的固定模板。
2. `generate_input()` 必须随机生成多样样例，不能固定死。随机维度应覆盖：网格大小、对象数量、位置、颜色、方向、形状参数或关键分支。
3. 生成器必须保证输入满足 `main()` 的隐式假设：对象不重叠、不越界、特殊标记唯一或可区分、匹配关系无歧义、关键分支出现概率相同。
4. 禁止把 ARC 颜色 id 、亮度、拼写等当作人类不可见的数值语义参与排序、大小比较或隐藏映射。颜色变化必须有可见结构线索。注意颜色亮度、拼写等也是不可见信息，若描述中出现违规的颜色id或者亮度，可自行使用少量的固定颜色替代，但注意生成时要在三个以内输入输出网格中对所有变换100%覆盖度。
