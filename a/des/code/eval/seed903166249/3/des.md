<description>
根据嵌套框架的层数选择调色板行，再用该行颜色重新填充框架各层。

Input structure:
- 背景为黑色（black）。网格分为左右两个区域，由一列灰色（grey）分隔线隔开。
- 左侧区域包含若干嵌套的矩形框架（同心矩形），每个嵌套组由不同颜色的1像素宽矩形环层层嵌套而成（最外层最大，最内层最小，内部填黑色背景）。各嵌套组的层数可能不同（2层、3层或4层）。每层的颜色在输入中是任意的。
- 右侧区域包含一个调色板表格：若干行，每行由不同数量的连续彩色像素组成（例如某行2个像素、某行3个像素、某行4个像素），各行之间用一行黑色背景分隔。每行的像素数量各不相同，且恰好覆盖了左侧所有嵌套组出现的层数值。

Rule:
- 对于左侧每个嵌套矩形组，数出它的嵌套层数 N。
- 在右侧调色板中找到像素数等于 N 的那一行。
- 用该行的颜色从外到内依次重新涂色：调色板行最左边的颜色涂最外层框架环，第二个颜色涂第二层，以此类推。
- 右侧调色板区域和灰色分隔线在输出中保持不变。

Key insight: 嵌套层数不是直接写出来的数字，而需要解题者识别同心矩形结构并计数层数，再用层数作为索引去匹配调色板行的长度，最后调色板内颜色的顺序决定了重涂的从外到内的映射。

将散落的彩色碎片拼入带缺口的灰色模板中，碎片需旋转至唯一匹配的朝向后嵌入，拼入后碎片颜色由缺口边缘的标记色决定。

Input structure:
- 背景为黑色（black）。
- 网格中有一个较大的灰色（grey）矩形模板，模板边缘上有若干缺口（凹陷区域，形状各异，均为由若干连续背景像素构成的小洞）。每个缺口的紧邻外侧（模板边缘上与缺口相邻的像素）被涂成一种非灰色的标记色（如 red、blue、green 等），每个缺口的标记色不同。
- 网格的其余空白区域散落着若干彩色碎片，每个碎片由同一种颜色的连通像素组成。碎片数量与缺口数量相同。每个碎片的形状恰好与某个缺口的形状在某个 90° 旋转下吻合（0°、90°、180°、270° 中恰好有唯一一个旋转使碎片形状与缺口形状完全匹配）。

Rule:
- 对每个缺口，在散落碎片中找到形状匹配的碎片（尝试四个 90° 旋转，恰好有唯一一个碎片在唯一一个旋转角度下与该缺口形状吻合）。
- 将碎片旋转到匹配角度后放入缺口位置。
- 放入后，碎片的颜色变为该缺口边缘标记色。
- 原碎片位置变为黑色背景。散落碎片全部消失，模板上所有缺口被填满。

Key insight: 需要两层非平凡推理——第一层是通过形状旋转匹配确定碎片与缺口的配对及旋转角度，第二层是发现填入后的颜色并非碎片原色而是由缺口周围的标记色决定。
</description>

<description>
沿彩色路径传播信号，信号在交叉路口按路口中心像素的颜色选择转弯方向，最终点亮终点灯泡。

Input structure:
- 背景为黑色（black）。
- 网格中有若干条由单色像素构成的正交路径（水平或垂直线段），颜色为灰色（grey）。路径在某些位置交叉，形成十字路口；每个十字路口的中心像素被涂成一种非灰色、非黑色的方向色（如 red、blue、green、yellow 中的一种）。
- 网格的一条边缘上有一个橙色（orange）像素作为信号起点，它与某条灰色路径的端点相邻。
- 网格中散布着若干 2x2 的纯色方块作为"灯泡"，每个灯泡颜色不同且均为非灰色、非黑色、非橙色的颜色。灯泡紧邻某条灰色路径的末端。

Rule:
- 信号从橙色起点出发，沿灰色路径传播（路径上的灰色像素在输出中变为橙色）。
- 当信号到达一个十字路口时，读取路口中心像素的方向色：
  - red = 右转（相对于信号当前行进方向顺时针 90°）。
  - blue = 左转（逆时针 90°）。
  - green = 直行。
  - yellow = 掉头（180°）。
- 信号沿新方向继续传播，路径像素变为橙色。方向色像素本身也变为橙色。
- 当信号到达路径末端且末端相邻一个灯泡时，该灯泡的 2x2 像素全部变为橙色（"点亮"）。
- 未被信号经过的路径和灯泡保持原色不变。

Key insight: 解题者需要先理解路口中心颜色编码了转弯指令（这需要从多个样例中归纳出颜色-方向映射），然后模拟信号沿路径传播并在每个路口按指令转弯，才能确定哪些路径被点亮、哪个灯泡被激活。
</description>

<description>
将网格中的彩色"种子"像素按其所在区域的围栏形状向外生长，生长层数由同色种子的数量决定，不同种子的生长区域重叠时高优先级色覆盖低优先级色。

Input structure:
- 背景为黑色（black）。
- 网格中有若干个由灰色（grey）像素构成的封闭围栏（1像素宽的闭合矩形环），每个围栏内部的黑色区域中恰好有一个或多个同色的"种子"像素（非灰色、非黑色），同一围栏内所有种子颜色相同。不同围栏的种子颜色可能相同也可能不同。
- 网格一角有一个由不同颜色像素排成的单行或单列"优先级表"：从一端到另一端，颜色的优先级依次递减（最靠边缘角落的颜色优先级最高）。优先级表中的颜色恰好覆盖了所有出现过的种子颜色。

Rule:
- 对每个围栏区域，统计其内部种子像素的数量 N。
- 以围栏（含围栏本身）为初始边界，向围栏外部做 N 层正交扩展（类似"膨胀"操作）：第一层是围栏外上下左右紧邻的所有像素，第二层是第一层外上下左右紧邻的所有像素，以此类推。所有扩展层像素涂成该围栏的种子颜色。
- 灰色围栏本身也变为种子颜色。围栏内部（种子和黑色背景）保持不变。
- 当两个不同颜色的扩展区域重叠时，参照优先级表，优先级高的颜色覆盖优先级低的颜色。
- 优先级表本身在输出中保持不变。

Key insight: 三层推理——首先识别围栏内种子数量决定扩展层数（数量-距离映射），然后执行空间膨胀操作确定扩展范围，最后在重叠区域利用角落的优先级表解决颜色冲突。
</description>

- 网格中有若干条彩色线段（水平或垂直，长度不少于2像素，宽度1像素）。线段总是成对出现：同一对中的两条线段平行、等长、颜色不同，且它们之间的矩形区域内没有其他线段。不同对之间的矩形区域不重叠。

Rule:
- 识别所有线段对：两条平行、等长的线段构成一对，它们定义了一个矩形区域（以两条线段为对边）。
- 在该矩形区域内（不包括线段本身）填充棋盘格图案。棋盘格的两种颜色分别是该对线段的两种颜色。

Key insight: 解题者需要先发现线段的配对逻辑（平行、等长、颜色不同），然后推断出矩形区域的棋盘格填充规则，还要注意棋盘格的起始相位取决于哪条线段在空间上更靠近左上方——这决定了用哪个颜色开始交替。

<description>
将散落的彩色像素沿所在行或列滑动至灰色轨道上，滑动方向由像素相对于轨道的位置决定，像素在轨道上的落点处触发垂直于轨道方向的彩色射线。

Input structure:
- 背景为黑色（black）。
- 网格中有若干条灰色（grey）直线轨道（水平或垂直，贯穿网格的大部分宽度或高度，宽度1像素）。
- 在轨道的两侧（非轨道上），散落着若干孤立的彩色像素（非灰色、非黑色），每个彩色像素与某条轨道在同一行（若轨道为水平）或同一列（若轨道为垂直）。每个彩色像素与其最近轨道之间没有其他彩色像素或轨道阻挡。

Rule:
- 每个彩色像素沿其所在行/列向最近的灰色轨道滑动，直到到达轨道上的格子。像素原位置变为黑色。
- 像素到达轨道后，从该落点沿垂直于轨道的两个方向（即如果轨道水平则向上和向下，如果轨道垂直则向左和向右）发射该像素颜色的射线。
- 射线沿垂直方向延伸，涂色每个经过的黑色背景像素，直到碰到网格边界或碰到非黑色像素（不覆盖该像素）时停止。
- 灰色轨道上落点处的像素变为该彩色像素的颜色。
- 若两条射线在同一格子相遇，距离各自轨道落点更近的射线优先保留其颜色；距离相同时，行号更小的落点发射的射线优先。

Key insight: 解题者首先要识别"像素向轨道滑动"的运动规则和方向判断（靠近哪条轨道就滑向哪条），然后发现落点会触发垂直射线，最后还需推理射线碰撞时的优先级规则——三层机制层层递进。
</description>
</new_puzzle>
