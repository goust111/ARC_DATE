将网格中的彩色"种子"像素按其所在区域的围栏形状向外生长，生长层数由同色种子的数量决定，不同种子的生长区域重叠时高优先级色覆盖低优先级色。

Input structure:
- 背景为黑色（black）。
- 网格中有若干个由灰色（grey）像素构成的封闭围栏（1像素宽的闭合矩形环），每个围栏内部的黑色区域中恰好有一个或多个同色的"种子"像素（非灰色、非黑色），同一围栏内所有种子颜色相同。不同围栏的种子颜色可能相同也可能不同。
- 网格一角有一个由不同颜色像素排成的单行或单列"优先级表"：从一端到另一端，颜色的优先级依次递减（最靠边缘角落的颜色优先级最高）。优先级表中的颜色恰好覆盖了所有出现过的种子颜色。

Rule:
- 对每个围栏区域，统计其内部种子像素的数量 N。
- 以围栏（含围栏本身）为初始边界，向围栏外部做 N 层正交扩展（类似"膨胀"操作）：第一层是围栏外上下左右紧邻的所有像素，第二层是第一层外上下左右紧邻的所有像素，以此类推。所有扩展层像素涂成该围栏的种子颜色。
- 灰色围栏本身也变为种子颜色。围栏内部（种子和黑色背景）保持不变。
- 当两个不同颜色的扩展区域重叠时，参照优先级表，优先级高的颜色覆盖优先级低的颜色。
- 优先级表本身在输出中保持不变。

Key insight: 三层推理——首先识别围栏内种子数量决定扩展层数（数量-距离映射），然后执行空间膨胀操作确定扩展范围，最后在重叠区域利用角落的优先级表解决颜色冲突。
