Input structure:
- 背景为黑色（black）。
- 网格中有若干条灰色（grey）直线轨道（水平或垂直，贯穿网格的大部分宽度或高度，宽度1像素）。
- 在轨道的两侧（非轨道上），散落着若干孤立的彩色像素（非灰色、非黑色），每个彩色像素与某条轨道在同一行（若轨道为水平）或同一列（若轨道为垂直）。每个彩色像素与其最近轨道之间没有其他彩色像素或轨道阻挡。

Rule:
- 每个彩色像素沿其所在行/列向最近的灰色轨道滑动，直到到达轨道上的格子。像素原位置变为黑色。
- 像素到达轨道后，从该落点沿垂直于轨道的两个方向（即如果轨道水平则向上和向下，如果轨道垂直则向左和向右）发射该像素颜色的射线。
- 射线沿垂直方向延伸，涂色每个经过的黑色背景像素，直到碰到网格边界或碰到非黑色像素（不覆盖该像素）时停止。
- 灰色轨道上落点处的像素变为该彩色像素的颜色。
- 若两条射线在同一格子相遇，距离各自轨道落点更近的射线优先保留其颜色；距离相同时，行号更小的落点发射的射线优先。

Key insight: 解题者首先要识别"像素向轨道滑动"的运动规则和方向判断（靠近哪条轨道就滑向哪条），然后发现落点会触发垂直射线，最后还需推理射线碰撞时的优先级规则——三层机制层层递进。
