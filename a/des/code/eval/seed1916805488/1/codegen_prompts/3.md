- `Rule`：
  - 第一层——确定路径方向：从路径的两个端点中找到"起点"——起点定义为距离网格边缘更近的那个端点（若相同则取更靠上方、再取更靠左方的端点）。从起点沿路径走向另一端点。

- `Key insight`：解题者需要先理解路径的方向性（哪端是起点），再识别滤色器作为分界点的角色——两段路径颜色不同是因为滤色器"改变"了经过它之后的颜色。仅看颜色变化容易误以为是两条独立路径，必须发现滤色器是颜色切换的因果机制。

4. 禁止把 ARC 颜色 id 、亮度、拼写等当作人类不可见的数值语义参与排序、大小比较或隐藏映射。颜色变化必须有可见结构线索。注意颜色亮度、拼写等也是不可见信息，若描述中出现违规的颜色id或者亮度，可自行使用少量的固定颜色替代，但注意生成时要在三个以内输入输出网格中对所有变换100%覆盖度。
