- `Input structure`：

  - 每个子区域内填充一个单色的小型不规则连通图案（碎片），四个碎片恰好可以无缝拼接成一个完整的矩形图案（碎片之间没有间隙也没有重叠）。
  - 在所有框架中，四个碎片的形状组合是相同的（即拼接方式一致），但颜色各不相同。
  - 恰好有一个框架的某一个子区域被 maroon 色的实心方块完全覆盖（遮挡），看不到该碎片的颜色。
  - 在框架外部的网格边缘处，有一行由若干颜色像素组成的"调色板行"，每个像素代表一种在所有框架碎片中出现过的颜色，按从左到右排列。

- `Rule`：
  - 第一层推理——颜色唯一性规则：观察所有未被遮挡的框架，发现每个框架内的四个碎片颜色互不相同，且每个框架使用的四种颜色恰好是调色板行中四种颜色的某个排列。
  - 第二层推理——位置-颜色映射：在所有完整框架中，观察同一位置（如"左上"）出现过哪些颜色，发现每种颜色在同一位置最多出现一次。利用排除法，被遮挡位置只有一种颜色满足"在该框架中未使用"且"在该位置上未被其他框架占用"的双重约束。
  - 输出网格与输入相同，唯一的变化是将 maroon 遮挡方块替换为推断出的正确颜色碎片（形状与其他框架中该位置的碎片相同，颜色为推断出的颜色）。

- `Key insight`：解题需要同时运用"框架内颜色不重复"和"同一位置跨框架颜色不重复"两条约束进行交叉排除——单独使用任何一条约束都不足以唯一确定答案，必须两条联合才能锁定被遮挡碎片的颜色。

4. 禁止把 ARC 颜色 id 、亮度、拼写等当作人类不可见的数值语义参与排序、大小比较或隐藏映射。颜色变化必须有可见结构线索。注意颜色亮度、拼写等也是不可见信息，若描述中出现违规的颜色id或者亮度，可自行使用少量的固定颜色替代，但注意生成时要在三个以内输入输出网格中对所有变换100%覆盖度。
