  - 网格的一个角落有一个调色板区域：由 4 行组成，每行包含一个数字指示图案（用 Azure 像素拼成的 1、2、3、4 的简单像素字形，每个字形宽 3 高 5）和紧邻其右侧的一个 3x3 彩色方块（颜色各不相同，例如 Blue、Green、Yellow、Magenta）。
- `Rule`：
  - 数出每个封闭形状内部 Red 锚点的数量 N（1 至 4）。
  - 在调色板中找到数字 N 对应的颜色 C。
  - 以该封闭形状的 Grey 边界为基础，向外扩展 N 层像素（即在边界外侧逐层包裹 N 圈），所有扩展层的像素都涂为颜色 C。扩展时使用 4-连通邻接：第 1 层 = 所有与 Grey 边界 4-连通相邻的 bg 像素，第 2 层 = 所有与第 1 层 4-连通相邻的 bg 像素（不含已涂色的），依此类推。

  - 原始 Grey 边界保留，内部 Red 锚点保留，调色板区域保留。
- `Key insight`：第一层推理需要发现锚点数量与调色板数字的对应关系从而确定颜色；第二层推理需要发现锚点数量同时还决定了向外扩展的层数——即同一个计数值既选色又定量，这种双重映射是解题的核心洞见。
