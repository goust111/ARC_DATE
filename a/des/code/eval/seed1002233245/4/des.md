根据框架颜色在嵌套容器间传递并翻转内容图案。

Input structure:
- 背景为黑色。网格中散布着若干"容器"，每个容器由一个单色矩形边框包围一块内部区域构成。
- 每个容器的内部区域包含一个由另一种颜色绘制的小型图案（非对称形状，如 L 形、T 形等），以及恰好一个"信号像素"——颜色与该容器边框颜色不同、也与内部图案颜色不同的孤立单像素。
- 部分容器彼此"配对"：容器 A 的边框颜色等于容器 B 内部信号像素的颜色，同时容器 B 的边框颜色等于容器 A 内部信号像素的颜色。未配对的容器保持不变。

Rule:
- 第一步（配对识别）：扫描所有容器，通过边框颜色与信号像素颜色的交叉匹配找到配对关系（每个容器最多配对一个）。
- 第二步（内容交换与翻转）：对于每一对配对容器 A 和 B，将 A 的内部图案复制到 B 的内部区域，将 B 的内部图案复制到 A 的内部区域。复制时执行翻转操作：若信号像素位于容器内部区域的左半侧或右半侧，则水平翻转图案；若信号像素位于上半侧或下半侧，则垂直翻转图案。图案颜色保持不变。
- 第三步（清除信号）：所有信号像素被替换为黑色背景。

Key insight:
信号像素承担双重角色——其颜色决定配对目标，其在容器内的空间位置决定翻转轴向。解题者必须先通过颜色交叉匹配发现配对关系，再通过信号像素的位置推断翻转方式，两步推理缺一不可。

<new_puzzle>
根据管道网络的拓扑将散落色块排入正确的收集槽。

Input structure:
- 背景为黑色。网格中有若干用灰色像素绘制的一像素宽的正交管道（仅水平或垂直线段，转角处为直角）。
- 管道的一端连接着一个"收集槽"——由 maroon 色绘制的小型矩形空腔（3 至 5 格宽，内部为黑色）。
- 管道的另一端（开口端）附近散落着一个或多个单色小方块（2x2 或 3x3），每个方块颜色各异。
- 管道可能在中途分叉（T 形或十字形交叉），每个分叉处恰好有一个"阀门像素"——一个非灰色、非黑色的彩色像素嵌在管道交叉点上。

Rule:
- 第一步（路径选择）：从每个散落色块出发，沿灰色管道向收集槽方向追踪。在每个分叉点，阀门像素的颜色决定路径选择——色块沿着阀门像素颜色与自身颜色相同的那条分支继续前进；若没有匹配的分支，则选择直行方向。
- 第二步（排列入槽）：到达收集槽后，色块按照到达的先后顺序（即经过的管道总长度从短到长）从收集槽的左端（或上端，取决于槽的朝向）开始依次紧密排列。色块被缩放为 1x1 像素放入槽中，保留原色。
- 第三步（清除）：原始位置的散落色块被擦除为黑色；管道和阀门保持不变。

Key insight:
阀门颜色构成一套路由规则——解题者需要先理解颜色匹配决定分叉方向，再根据路径长度推断排列顺序。路由机制和排序机制是两层独立的非平凡推理。
</new_puzzle>

将碎片化的形状拼合到模板框架中，通过缺口方向确定旋转角度。

Input structure:
- 背景为黑色。网格被一条蓝色水平分隔线分为上下两个区域。
- 上方区域包含若干个"模板框架"——每个框架是一个由绿色像素绘制的封闭矩形轮廓，内部为黑色，但轮廓上恰好有一个单像素缺口（缺口位于上、下、左、右四条边之一）。每个框架内部的黑色区域有特定形状——框架内部可能有若干绿色像素形成隔板，使得内部连通黑色空腔呈现不规则形状（如 L 形、T 形）。
- 下方区域包含若干个由不同颜色绘制的实心碎片（连通区域），每个碎片的形状恰好与某一个框架的内部空腔形状在某个旋转下吻合。

Rule:
- 第一步（形状匹配）：将每个碎片的形状（忽略颜色）与每个框架的内部空腔形状进行比较，找到旋转 0°、90°、180°、270° 中能完美吻合的配对。每个碎片恰好匹配一个框架。
- 第二步（旋转确定）：框架轮廓上的缺口位置决定碎片需要旋转的角度——缺口在上边表示不旋转（0°），缺口在右边表示顺时针旋转 90°，缺口在下边表示旋转 180°，缺口在左边表示顺时针旋转 270°。
- 第三步（嵌入）：将碎片按确定的旋转角度旋转后，填入对应框架的空腔中，碎片保持原色。下方区域的碎片原位置被清除为黑色。

Key insight:
解题者需要先通过形状匹配确定碎片与框架的对应关系，但仅凭形状匹配存在旋转歧义（可能多个旋转角度都能吻合）。缺口方向提供了消歧信息，编码了唯一正确的旋转角度。两层推理——形状配对和缺口解码——共同决定最终结果。
</new_puzzle>

<new_puzzle>
用种子图案的连通结构选择染色规则，对区域进行条纹或棋盘填充。

Input structure:
- 背景为黑色。网格被 orange 色的单像素宽正交线段划分为若干矩形区域（类似窗格）。
- 每个矩形区域内部有一个由两种颜色构成的小型"种子图案"（占据 2x2 到 3x3 的范围），其余区域内部为黑色。
- 种子图案中的两种颜色分别称为"主色"和"副色"。主色是种子图案中像素数较多的颜色，副色是像素数较少的颜色。

Rule:
- 第一步（结构判定）：观察种子图案中副色像素与主色像素的空间关系。若副色像素与主色像素在四连通方向上相邻（即副色像素至少有一个四连通邻居是主色），则该区域执行"条纹填充"。若副色像素与主色像素仅在对角方向上相邻（即副色像素没有四连通主色邻居，只有八连通主色邻居），则该区域执行"棋盘填充"。
- 第二步（条纹填充）：用主色和副色交替填充整个区域。条纹方向由副色像素相对于主色像素的方位决定——副色在主色的上方或下方则为水平条纹（逐行交替），副色在主色的左方或右方则为垂直条纹（逐列交替）。条纹从区域左上角开始，第一行/列为主色。
- 第三步（棋盘填充）：用主色和副色在整个区域内形成棋盘格图案。区域左上角为主色，相邻格子为副色，依此交替。
- 种子图案所在的像素也被覆盖为对应的填充结果。orange 色分隔线保持不变。

Key insight:
种子图案不仅提供颜色信息，其内部的连通关系（四连通 vs. 仅对角连通）编码了填充模式的类型，而副色的相对方位进一步编码了条纹的方向。解题者必须同时从种子图案中读取三层信息：颜色、连通类型、空间方位。
</new_puzzle>

<new_puzzle>
通过影子方向和遮挡关系推断对象的堆叠顺序，在输出中重建无遮挡的分离视图。

Input structure:
- 背景为 azure。网格中有若干个部分重叠的单色矩形对象，每个对象颜色不同。
- 由于堆叠遮挡，部分矩形只露出 L 形、U 形或条状的可见区域。
- 每个矩形在其右侧和下侧投射一个灰色"影子"——影子是该矩形完整轮廓向右偏移一格、向下偏移一格后，仅绘制与矩形本身不重叠的部分，用灰色填充。影子也可能被更上层的矩形遮挡而仅部分可见。

Rule:
- 第一步（完整形状恢复）：利用每个矩形的可见边缘和对应影子的可见部分，还原每个矩形的完整宽度和高度。影子的可见边缘暗示了矩形被遮挡侧的真实延伸范围。
- 第二步（堆叠顺序推断）：根据遮挡关系确定从底到顶的堆叠顺序。若矩形 A 的区域被矩形 B 部分覆盖（即 A 在 B 下方），则 A 的堆叠层级低于 B。
- 第三步（分离输出）：输出网格的尺寸与输入相同。将所有矩形按照从底到顶的顺序，从左到右排列在输出网格中，每个矩形恢复为完整尺寸，矩形之间留一列 azure 间隔，不再有任何重叠。矩形保持原色，不绘制影子。

Key insight:
影子提供了被遮挡部分的几何线索——解题者需要从灰色影子的形状反推出完整矩形的尺寸，再通过遮挡的方向性判定堆叠层级。影子解码和遮挡排序是两层独立的视觉推理。
</new_puzzle>

<new_puzzle>
根据箭头指令链对目标区域执行级联颜色替换。

Input structure:
- 背景为黑色。网格左侧有一个由灰色边框围成的矩形"画布区域"，内部填有若干种颜色形成的马赛克图案（每个像素是一种纯色）。
- 网格右侧排列着若干个"箭头指令"，从上到下依次排列，构成一个有序序列。每个箭头指令由三部分组成：一个 1x3 的水平彩色条（表示源色，三个像素颜色相同）、紧接其右侧的一个由三个同色像素组成的箭头符号（形状为：中间一行一个像素，上下各偏右一个像素，形成向右的尖角，颜色与源色条相同）、以及箭头尖端正右方一格处的一个单像素（表示目标色，颜色与源色不同）。

Rule:
- 按从上到下的顺序依次执行每条箭头指令。
- 每条指令的含义是：在画布区域中，将所有当前为"源色"（彩色条的颜色）的像素替换为"目标色"（箭头尖端右方单像素的颜色）。
- 指令是级联的——前一条指令的替换结果会影响后续指令的执行。例如，若指令 1 将红色替换为蓝色，指令 2 将蓝色替换为绿色，则原来的红色像素最终变为绿色。
- 执行完所有指令后，输出仅包含画布区域的内部内容（去掉灰色边框），右侧指令区域被裁剪掉。

Key insight:
指令的执行顺序至关重要——级联效应意味着解题者不能独立地看待每条指令，而必须追踪颜色在整个指令链中的传递路径。解题者需先理解箭头符号的编码方式（源色条 → 箭头 → 目标色），再正确模拟级联替换的过程，两层推理相互交织。
</new_puzzle>

<new_puzzle>
根据边框形状的对称性类型决定内部图案的复制方式，生成对称完备的输出。

Input structure:
- 背景为黑色。网格中有若干个彩色边框围成的矩形区域，每个区域的边框颜色不同。
- 每个矩形区域的内部只有一个象限（左上、右上、左下或右下之一）包含由另一种颜色绘制的图案，其余三个象限为黑色。
- 每个矩形的边框形状具有某种不完整的对称标记：边框的四条边中，部分边的中点处有一个与边框同色的向内突出像素（"凸起标记"）。凸起标记可能出现在上边、下边、左边、右边的中点位置。

Rule:
- 第一步（对称类型判定）：根据凸起标记的位置判定需要生成的对称类型。若上下两条边都有凸起标记，则要求水平轴对称（上下镜像）。若左右两条边都有凸起标记，则要求垂直轴对称（左右镜像）。若四条边都有凸起标记，则要求双轴对称（同时上下和左右镜像）。若仅一条边有凸起标记，则该边指向的方向为图案平移复制的方向（如上边凸起则向上复制一份）。
- 第二步（图案复制）：将已有图案按判定的对称类型镜像复制到矩形内部对应的空白象限。若为水平轴对称，将图案上下翻转后填入对侧象限。若为垂直轴对称，将图案左右翻转后填入对侧象限。若为双轴对称，则三个空白象限都被填入相应的镜像图案。
- 边框和凸起标记保持不变。

Key insight:
凸起标记不是装饰而是对称性指令——其分布模式编码了需要执行的镜像操作类型。解题者需要先发现凸起标记与对称类型之间的映射关系，再据此正确执行图案复制，构成两层推理。
</new_puzzle>
