- `Input structure`：
  - 背景色（bg）填充大部分网格。
  - 一个由 Maroon 像素构成的大型矩形空框架（内部为 bg），框架内壁的四条边上各有一个不同颜色的单像素标记（例如上边 Red、右边 Blue、下边 Green、左边 Yellow），称为"边锚点"。
  - 框架外散落若干个不规则形状的碎片（每个碎片由一种主色构成），每个碎片恰好有两个像素的颜色与框架边锚点颜色相同，这两个彩色像素分别位于碎片的不同边缘位置，称为"碎片锚点"。
  - 每个碎片的面积恰好能填充框架内部的一块子区域，所有碎片无重叠地拼满框架内部。

- `Rule`：
  - 第一层推理——匹配旋转：每个碎片有两个彩色锚点像素，它们的颜色对应框架上两条边的锚点。碎片需要旋转（0°/90°/180°/270°），使得碎片上颜色为 X 的锚点朝向框架上颜色为 X 的锚点所在的那条边。两个锚点颜色同时满足方向约束，唯一确定旋转角度。
  - 第二层推理——平移拼装：旋转后的碎片平移进入框架内部，所有碎片无间隙、无重叠地拼满框架内部空间。碎片间的相邻边界自然对齐。
  - 输出仅包含框架及其内部被碎片填满后的结果；碎片的原始位置用 bg 填充。框架的 Maroon 边框和边锚点保留。

- `Key insight`：碎片上的两个异色锚点像素与框架四边锚点的颜色配对关系唯一确定了碎片的旋转角度——解题者必须先发现这个颜色-方向映射，然后才能正确拼装。
