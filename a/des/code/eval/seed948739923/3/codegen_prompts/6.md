- `Input structure`：
  - bg = 最常见颜色（如 black）。
  - 网格中有若干个相同大小的正方形区域，每个由 grey 边框围成（"表盘"），内部包含一个彩色小图案。
  - 每个表盘的外侧恰好有一个单像素突起（"指针"），位于上、下、左、右四边之一，指针颜色为 orange。
  - 部分表盘之间有 azure 单像素宽的直线段相连（"连线"），连线连接两个表盘最近的边的中点。
  - 恰好有一个表盘的指针颜色为 red 而非 orange，标记为"起始时钟"。

- `Rule`：
  - 第一步：对起始时钟（red 指针），根据指针方向确定旋转量——指针在上 = 不旋转，指针在右 = 顺时针旋转 90°，指针在下 = 旋转 180°，指针在左 = 逆时针旋转 90°。将该时钟内部图案做对应旋转。
  - 第二步：沿连线传播——起始时钟通过连线连接到的下一个时钟，继承起始时钟的旋转量，再叠加自身指针指示的旋转量（两次旋转累加），对内部图案执行累加后的总旋转。
  - 第三步：继续沿连线级联，每个新到达的时钟累加之前所有时钟的旋转量再加自身指针的旋转量。
  - 未被连线连接到起始时钟的孤立时钟，仅按自身指针旋转。
  - 输出中表盘边框、指针、连线均保持原样，仅内部图案发生旋转。

- `Key insight`：指针方向编码旋转量，连线定义传播路径，旋转沿路径累加——解题者先需建立指针方向与旋转角度的映射，再发现沿连线路径旋转量是累积叠加而非独立应用的，形成"方向解码、路径追踪、累积旋转"的三层结构。
