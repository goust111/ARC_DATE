- `Input structure`：
  - bg = 最常见颜色（如 black）。
  - 网格中散布若干灰色（grey）封闭轮廓，每个轮廓内部恰好有一条单像素宽的水平或垂直色带（非灰色、非背景色），色带颜色各不相同。

- `Rule`：
  - 第一步：将每个彩色色块按外接矩形尺寸与灰色容器匹配（尺寸唯一对应）。
  - 第二步：查看匹配到的灰色容器内部色带的方向（水平或垂直）。
  - 第三步：在输出中，将该彩色色块保留在原位，但用其颜色对色块的外接矩形区域按色带方向画等间距条纹（间距 = 1 像素背景色间隔），条纹仅在色块的原始非背景像素所在行（水平方向时）或列（垂直方向时）绘制。
  - 灰色容器及其色带在输出中保持不变。

- `Key insight`：色块的外接矩形尺寸是查找配对容器的钥匙；容器内色带的朝向才是决定条纹方向的真正编码——两层匹配缺一不可。

- `Input structure`：
  - bg = 最常见颜色（如 black）。
  - 网格中央有一个大型多色图案，其中若干矩形区域被统一的遮挡色（如 maroon）覆盖，形成"缺口"。
  - 网格边缘散落若干与缺口同尺寸的彩色碎片。
  - 每个缺口的四条边各有一像素宽的边框；边框像素的颜色沿顺时针方向形成一个从浅到深（在可用颜色列表中的顺序：red、orange、yellow、green、blue）的渐变序列，序列起始边（最浅色所在边）指示该缺口的"上方"朝向。
  - 每个碎片外围也有相同编码的单像素边框。

- `Rule`：
  - 将每个碎片与缺口按内部尺寸（去掉边框后的尺寸）配对。
  - 比较碎片边框的渐变起始边与缺口边框的渐变起始边，计算需要旋转的 90° 倍数（0°、90°、180°、270°），使两者起始边对齐。
  - 将碎片旋转后（仅旋转内部内容，不含边框）填入缺口位置，替换遮挡色像素。
  - 输出中碎片原始位置变为背景色，散落碎片的边框也一并移除。

- `Key insight`：边框颜色渐变序列定义了隐含的方向标记——解题者必须先识别渐变顺序以确定旋转量，再按尺寸配对完成拼图，形成"朝向解码、尺寸匹配、旋转放置"的三层推理。

- `description`：让信号沿彩色导线网络传播，在每个节点处根据节点形状决定信号的转向与分裂。

- `Input structure`：
  - bg = 最常见颜色（如 black）。
  - 网格中有若干单像素宽的直线段（导线），颜色统一为 azure，沿水平或垂直方向延伸。
  - 导线交叉或转弯处有 2x2 或 3 像素 L 形的小色块作为"节点"，节点颜色各异（如 red、green、yellow 等），但每种颜色在整个网格中最多出现一次。
  - 网格边缘恰好有一个 orange 像素作为信号源，它紧邻某条导线的端点。
  - 每个节点的形状编码转向规则：若节点为 2x2 正方形，信号到达后向所有连接的导线方向传播（分裂）；若节点为 L 形（2x2 缺一个角的 3 像素），信号仅向缺角对侧的方向转弯。

- `Rule`：
  - 信号从 orange 源点出发，沿导线传播，将经过的导线像素从 azure 重新着色为 orange。
  - 信号到达节点时：
    - 2x2 正方形节点：信号分裂到该节点连接的所有导线（除来路方向外），节点本身变为 orange。
    - L 形节点（2x2 去掉一个角的 3 像素）：信号从缺角对角线方向转弯——即从入口方向旋转 90°，转向缺角的对侧方向，节点本身变为 orange。若转弯方向没有连接导线，信号终止。
  - 信号持续传播直到到达导线末端（无更多节点可达）或网格边界。
  - 未被信号到达的导线和节点保持原色不变。

- `Key insight`：节点形状（完整正方形 vs. L 形）决定信号是分裂还是转弯，而 L 形的缺角位置编码了具体转弯方向——解题者需先破解节点形状与传播行为的映射关系，再模拟信号在网络中的级联传播路径。
</new_puzzle>

- `Input structure`：
  - bg = 最常见颜色（如 black）。

  - 每个围栏内部恰好有一个 yellow 单像素标记，位于图案旁边。yellow 标记与缺口的相对位置（同侧或对侧）编码投影模式：同侧 = 正常投影，对侧 = 镜像投影。

- `Rule`：
  - 对每个围栏，确定缺口方向作为投影方向。
  - 判断 yellow 标记与缺口是否在围栏的同一边：若同侧，图案沿投影方向原样平移复制；若对侧，图案沿投影方向做垂直于投影方向的镜像翻转后再平移复制。
  - 投影的图案从缺口处开始绘制，沿投影方向逐像素延伸，直到碰到网格边界或另一个围栏的外壁。
  - 当两个不同围栏的投影在同一像素重叠时，该像素变为 red（无论原来两个投影各自是什么颜色）。
  - 围栏本身和围栏内部图案保持不变；缺口保持为背景色。

- `Key insight`：缺口位置编码方向，yellow 标记与缺口的同侧/对侧关系编码镜像与否——解题者需先建立"标记-缺口相对位置到投影模式"的映射，再追踪投影路径和碰撞叠加规则，形成"方向解码、镜像判断、碰撞混色"的三层推理链。

- `description`：在网格中识别多个"时钟"结构，根据指针方向旋转时钟内部的图案，再根据时钟之间的连线传递旋转信息实现级联变换。

- `Input structure`：
  - bg = 最常见颜色（如 black）。
  - 网格中有若干个相同大小的正方形区域，每个由 grey 边框围成（"表盘"），内部包含一个彩色小图案。
  - 每个表盘的外侧恰好有一个单像素突起（"指针"），位于上、下、左、右四边之一，指针颜色为 orange。
  - 部分表盘之间有 azure 单像素宽的直线段相连（"连线"），连线连接两个表盘最近的边的中点。
  - 恰好有一个表盘的指针颜色为 red 而非 orange，标记为"起始时钟"。

- `Rule`：
  - 第一步：对起始时钟（red 指针），根据指针方向确定旋转量——指针在上 = 不旋转，指针在右 = 顺时针旋转 90°，指针在下 = 旋转 180°，指针在左 = 逆时针旋转 90°。将该时钟内部图案做对应旋转。
  - 第二步：沿连线传播——起始时钟通过连线连接到的下一个时钟，继承起始时钟的旋转量，再叠加自身指针指示的旋转量（两次旋转累加），对内部图案执行累加后的总旋转。
  - 第三步：继续沿连线级联，每个新到达的时钟累加之前所有时钟的旋转量再加自身指针的旋转量。
  - 未被连线连接到起始时钟的孤立时钟，仅按自身指针旋转。
  - 输出中表盘边框、指针、连线均保持原样，仅内部图案发生旋转。

- `Key insight`：指针方向编码旋转量，连线定义传播路径，旋转沿路径累加——解题者先需建立指针方向与旋转角度的映射，再发现沿连线路径旋转量是累积叠加而非独立应用的，形成"方向解码、路径追踪、累积旋转"的三层结构。
</new_puzzle>

- `description`：将散落的彩色线段按颜色分组后首尾相接形成封闭直角多边形，再用该颜色填充多边形内部区域。

- `Input structure`：
  - bg = 最常见颜色（如 black）。
  - 网格中散布若干短线段（每段 2-5 像素长，水平或垂直），每条线段有一种非背景颜色。
  - 同一颜色的线段恰好有 3 到 5 条，它们在空间上并不相连，但其端点之间存在唯一的配对方式，使得这些线段加上连接线段端点的直线能形成一个封闭多边形（所有转角均为 90°，即只有水平和垂直线段交替出现）。
  - 不同颜色的线段组形成不同的多边形，多边形之间不重叠。

- `Rule`：
  - 对每种颜色，找到所有同色线段。
  - 将这些线段的端点两两配对（每个端点恰好与另一个端点配对），在配对端点之间画同色直线连接（仅水平或垂直），使所有线段和连接线共同形成一个封闭的直角多边形。
  - 用该颜色填充多边形内部的所有背景像素。
  - 不同颜色的多边形独立处理，最终所有多边形的边框和填充同时呈现在输出中。

- `Key insight`：散落的线段是多边形边的可见片段，解题者需要发现同色线段构成封闭直角多边形的骨架——关键在于识别端点的唯一配对方式（只有一种连接方案能形成合法的直角封闭形状），然后补全缺失边并填充内部。
</new_puzzle>
