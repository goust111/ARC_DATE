- `Input structure`：
  - 背景色（bg）为 azure。
  - 网格的上边缘和左边缘各有一排单像素高（或宽）的"投影尺"，由交替的 grey 和 bg 像素组成，形成刻度。
  - 网格内部有若干不重叠的小型彩色对象（4-连通，每个对象为单一非 bg、非 grey 颜色），对象形状各异但均可被其最小包围盒框定，且包围盒为正方形。
  - 每个对象恰好有三面与 bg 相邻，一面紧贴另一个对象或网格边缘的投影尺（即该面无自由邻接）。

- `Rule`：
  - 第一层推理——读取阴影长度：将每个对象向上边缘投影尺和左边缘投影尺做正交投影。对象在投影尺上的投影覆盖了若干刻度格，其中被 grey 像素标记的刻度格数量即为该对象的"阴影长度" L。对象使用上边缘投影尺还是左边缘投影尺，取决于对象的拉伸方向：拉伸方向为水平时用上边缘尺，垂直时用左边缘尺。
  - 第二层推理——方向与拉伸：对象三面自由邻接中，找到唯一一面对面完全没有其他对象的方向（即沿该方向到网格边缘之间全为 bg），该方向为拉伸方向。从对象边缘沿拉伸方向延伸 L 个像素的矩形区域，用对象的原始形状进行周期性平铺（如果 L 不足以完成一个完整周期则截断），平铺颜色与对象相同。
  - 输出网格尺寸不变，原对象保留。

- `Key insight`：投影尺上的刻度标记数量编码了拉伸距离，但需要先确定拉伸方向才能知道该读哪把尺；拉伸方向由对象周围的空旷程度决定，而非由尺的位置决定。

1. `main(grid)` 必须实现新题描述中的确定性转换规则，不能只识别 `generate_input()` 的固定模板。

3. 生成器必须保证输入满足 `main()` 的隐式假设：对象不重叠、不越界、特殊标记唯一或可区分、匹配关系无歧义、关键分支出现概率相同。
4. 禁止把 ARC 颜色 id 、亮度、拼写等当作人类不可见的数值语义参与排序、大小比较或隐藏映射。颜色变化必须有可见结构线索。注意颜色亮度、拼写等也是不可见信息，若描述中出现违规的颜色id或者亮度，可自行使用少量的固定颜色替代，但注意生成时要在三个以内输入输出网格中对所有变换100%覆盖度。

6. 若规则有多个分支，生成器不能长期固定成一个分支；应让分支在随机样例中合理出现，即每个分支出现的概率平均，所谓的分支是在描述中提到的分支，即规则语义中的不同情况。
