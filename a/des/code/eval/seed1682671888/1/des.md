- `description`：根据封闭花盆内种子像素的数量，从花盆缺口向外生长出固定转弯规则的 L 形藤蔓。

- `Input structure`：
  - 背景色（bg）为最常见颜色（black）。
  - 若干由 green 像素围成的封闭矩形"花盆"，每个花盆的边框上恰好有一个缺口（一个像素宽的间断）。
  - 每个花盆内部散布着若干 red 种子像素（1×1 单像素点），数量在 1 到 6 之间。
  - 花盆外部全为背景色。

- `Rule`：
  - 对每个花盆，找到其边框上的唯一缺口位置，确定缺口朝外的方向（上、下、左、右之一）。
  - 从缺口位置开始，沿缺口朝外方向绘制一条 red 像素线段，线段长度等于该花盆内种子像素的数量。
  - 线段绘制完毕后，在末端像素处转弯：转弯方向为顺时针旋转 90°（例如向上生长的藤蔓在末端转向右），继续绘制同样长度的第二段 red 线段。
  - 如果藤蔓线段在延伸过程中遇到网格边界，则在边界处截断停止，不再继续转弯。
  - 花盆本身（green 边框和内部种子）保持不变。

- `Key insight`：解题需要同时发现两个非显然规律——种子数量决定每段藤蔓的长度，缺口方向决定生长起始方向，且藤蔓在末端固定执行顺时针转弯形成 L 形路径。仅观察缺口或仅计数种子都无法独立推出完整规则。
</new_puzzle>

- `description`：将网格中散落的成对彩色碎片用 L 形直角连线相连，连线拐角处标记特殊颜色。

- `Input structure`：
  - 背景色（bg）为最常见颜色（black）。
  - 网格中散布着若干彩色连通分量（碎片），每种非背景颜色恰好出现两个独立的连通分量（即成对出现），每个碎片由 2 到 5 个像素组成。
  - 碎片之间无重叠，彼此不相邻。

- `Rule`：
  - 对每种颜色，找到该颜色的两个碎片。
  - 计算两个碎片各自的视觉中心（碎片所有像素的行坐标取平均并四舍五入，列坐标取平均并四舍五入）。
  - 从碎片 A 的中心到碎片 B 的中心绘制一条 L 形直角连线（先水平后垂直），使用该碎片的颜色。碎片 A 是同色两个碎片中位置更靠上（行坐标更小）的那个；若行坐标相同则取列坐标更小的。连线仅覆盖背景色像素，不覆盖已有碎片。
  - 在 L 形连线的拐角处（水平段与垂直段交汇的那个像素），将该像素改为 yellow。
  - 如果两个碎片中心恰好在同一行或同一列（即连线为直线无拐角），则不绘制 yellow 标记，直接用原色画直线连接。
  - 所有原始碎片保持不变。

- `Key insight`：解题者需要先识别颜色配对关系（每种颜色恰好两个碎片），再发现连线规则是"先水平后垂直"的固定 L 形路径（而非最短路径或其他形状），最后发现拐角处的特殊标记色。三层规则缺一不可。
</new_puzzle>

- `Input structure`：
  - 背景色（bg）为 black。
  - blue 像素构成墙壁，将网格分割成若干矩形房间（每个房间内部至少 3×3）。
  - 相邻房间共享的墙壁上恰好有一个 1 像素宽的缺口（门洞）。
  - 每个房间内部包含：
    - 恰好一个由 3 个同色像素组成的 L 形箭头（占据 2×2 包围框中的三个格子，缺少一个角）。箭头颜色为 red、green、orange 或 magenta 之一。箭头缺失角的对角方向即为箭头的朝向。
    - 零到三个 grey 单像素方块，散布在房间内部的背景上。

- `Rule`：
  - 对每个房间，箭头指向该房间中门洞所在的那面墙壁方向（上、下、左、右之一）。
  - 将该房间内的所有 grey 方块沿箭头方向移动，穿过门洞进入相邻房间。
  - grey 方块在相邻房间中沿同方向继续滑动，直到碰到墙壁或其他已停止的方块时紧贴停止，彼此紧密堆叠。距离门洞更近的 grey 方块先移动、先停靠（即按到门洞的距离从近到远依次处理）。
  - 箭头本身保持原位不动，原房间中 grey 方块的原始位置恢复为背景色。
  - 所有房间的推送同时执行（各房间推入的方块不会被其他房间的箭头二次推送）。

- `Key insight`：解题的第一层推理是发现箭头指向与门洞位置的对应关系（箭头永远指向本房间的门洞），第二层是发现 grey 方块穿过门洞后在相邻房间中沿同方向滑动到墙壁处堆叠的行为。箭头颜色本身是干扰项，不参与变换规则。
</new_puzzle>

<new_puzzle>
- `description`：网格中有多个相同外轮廓但内部孔洞数不同的物体，以及一条水平调色板条；根据孔洞数量作为索引，从调色板中查找颜色对物体重新着色。

- `Input structure`：
  - 背景色（bg）为 black。
  - 网格底部有一行水平的"调色板"条，紧贴底边绘制，由若干不同颜色的连续像素段组成（例如连续 3 个 red 像素、连续 3 个 blue 像素、连续 3 个 green 像素……），每段长度相同（2 或 3 像素），段与段之间无间隔，共 N 段（N 为 3 到 5）。
  - 网格其余区域散布着若干外轮廓形状完全相同的物体（例如都是 5×5 的十字形或 6×6 的 U 形），但每个物体当前的填充颜色各异且互不相同。
  - 每个物体内部有零到 N-1 个"孔洞"（被物体像素在四方向上完全包围的、保持背景色的像素或像素组）。不同物体的孔洞数量不同。

- `Rule`：
  - 读取调色板条中颜色从左到右的顺序，建立索引：第 0 种颜色、第 1 种颜色、……第 N-1 种颜色。
  - 对每个物体，计数其内部孔洞的数量 H（一个孔洞是一个被物体像素四方向封闭的背景色连通区域，无论大小均计为一个孔洞）。
  - 将该物体的所有像素重新着色为调色板中第 H 个颜色（索引从 0 开始）。
  - 调色板条本身保持不变。物体的位置、形状和孔洞均不变，仅颜色改变。

- `Key insight`：解题的第一层推理是识别底部调色板条的结构并提取颜色顺序（调色板容易被误认为装饰性边框）；第二层是发现物体内部孔洞数量与着色之间的映射关系——孔洞数量直接作为调色板的索引。物体原始颜色是干扰信息，完全不参与规则。
</new_puzzle>

- `description`：网格中有一个大矩形框架，框架内壁上有彩色锚点；框架外散布着与锚点同色的小图案，将小图案按锚点位置和方向旋转后复制印入框架内部。

- `Input structure`：
  - 背景色（bg）为 black。
  - 一个由 grey 像素构成的大矩形空心框架（边框宽度 1 像素，内部填满背景色），尺寸至少 10×10。
  - 框架的内壁（紧贴边框内侧的那一圈位置）上有若干彩色锚点像素（非 grey、非 black），每个锚点颜色互不相同，且每个锚点位于框架四条内边（上内边、下内边、左内边、右内边）中的某一条上。
  - 框架外部散布着若干小的矩形图案（3×3 大小），每个图案由一种与某锚点相同颜色的像素构成边框（1 像素宽），图案内部（1×1 中心像素）为 maroon 或背景色，形成简单花纹。每种锚点颜色恰好对应一个小图案。

- `Rule`：
  - 通过颜色匹配，将每个小图案与框架内壁上的同色锚点配对。
  - 确定每个锚点所在的内边（上、下、左、右）。
  - 将配对的小图案旋转，使图案的上边朝向框架中心方向（即：锚点在上内边→图案旋转 180°使其上边朝下；锚点在下内边→图案不旋转，上边朝上即朝向中心；锚点在左内边→图案顺时针旋转 90°使其上边朝右即朝向中心；锚点在右内边→图案逆时针旋转 90°使其上边朝左即朝向中心）。
  - 将旋转后的 3×3 图案放置在框架内部：图案靠近锚点的那条边紧贴锚点所在的内壁，图案在沿内壁方向上以锚点为中心居中对齐（锚点对准图案该边的中间像素）。
  - 图案以复制方式放入，原始位置保持不变。框架和锚点也保持不变。

- `Key insight`：解题者首先需要通过颜色匹配建立图案与锚点的对应关系，然后需要发现旋转规则——锚点在框架哪条内边上决定了图案旋转多少度（核心原则是图案"顶部朝向框架中心"），最后需要确定放置位置是以锚点为中心沿内壁对齐。旋转方向规则是最隐蔽的一层。
</new_puzzle>

<new_puzzle>
- `description`：网格中有若干闭合环路，环路内部有标记点；将每个环路展开为一行水平线段，长度等于环路像素数，标记点映射到展开后的对应位置。

- `Input structure`：
  - 背景色（bg）为 black。
  - 网格中有若干闭合环路，每个环路由单一颜色的像素组成（宽度恰好 1 像素），形成封闭回路（矩形、L 形或其他简单多边形轮廓）。每个环路使用不同颜色（如 red、blue、green 等），环路之间不重叠、不相邻。
  - 每个环路围住的内部区域中有零到三个 maroon 标记像素（1×1），各自位于不同位置。

- `Rule`：
  - 输出网格宽度等于所有环路中最大周长（环路像素总数），高度等于环路数量。每行对应一个环路，按环路在输入中的位置从上到下排列（以每个环路最上方最左方像素的行坐标为主排序键，列坐标为次排序键）。
  - 对每个环路，找到其最上方且最左方的像素作为起点，沿顺时针方向逐像素遍历整个环路，得到周长 P（即环路总像素数）。
  - 在输出的对应行中，从第 0 列起连续绘制 P 个该环路颜色的像素。
  - 对于环路内部的每个 maroon 标记像素：在环路上找到与该标记像素四方向相邻距离最近的环路像素，设该像素是顺时针遍历中的第 k 个（从 0 计数），则在输出行的第 k 列将颜色替换为 maroon。
  - 输出行中第 P 列及之后的位置保持背景色。

- `Key insight`：解题需要三层推理——首先识别闭合环路并理解"展开"概念（环路像素总数即为展开后的线段长度），其次发现遍历方向为顺时针且起点固定为最上最左像素，最后发现内部标记点通过"最近环路像素"在顺时针序列中的位次映射到展开线段上的位置。环路的几何形状仅决定周长和遍历顺序，展开后形状信息被丢弃。
</new_puzzle>
