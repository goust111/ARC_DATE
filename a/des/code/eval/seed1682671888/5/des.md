<new_puzzle>
根据封闭区域内部的颜色碎片推断该区域所属的"模板形状"，再用模板形状替换原区域轮廓。

Input structure:
- bg = 背景色（Black）。网格中有若干用同一种边框色（如 Blue）绘制的不规则封闭轮廓，每个轮廓围出一块区域。
- 网格右下角有一个"模板图例区"，用 Grey 线框隔开。图例区内纵向排列着若干小型标准形状（如 3×3 十字、3×3 L 形、3×3 T 形等），每个标准形状用独特的颜色绘制。每个标准形状旁边紧邻一个由 1-3 个不同颜色像素组成的"签名"（signature）——这些像素的颜色组合与排列方式是唯一的。
- 每个主网格封闭轮廓的内部散落着若干与某个签名完全相同的颜色像素（颜色种类与相对位置模式一致），但可能被平移到了区域内的任意位置。

Rule:
- 第一步：对每个封闭轮廓，收集其内部所有非背景、非边框色的像素，提取它们的颜色集合与相对位置模式（平移无关），与图例区中各签名进行匹配，找到对应的模板形状。
- 第二步：计算该封闭轮廓的外接矩形中心，以此中心为锚点，将匹配到的模板形状放大到与该轮廓外接矩形等宽等高（每个模板像素扩展为 k×k 的块，k = 外接矩形边长 ÷ 模板边长，向下取整），用边框色绘制放大后的模板形状，替换掉原来的不规则轮廓。
- 第三步：清除轮廓内部的签名像素，内部回归背景色。

Key insight: 内部散落的彩色碎片不是装饰，而是一组"颜色签名"，用于在图例中查找该区域应当呈现的标准形状；解题者需要先识别签名匹配机制，再理解轮廓被模板形状替换的缩放规则。
</new_puzzle>

<new_puzzle>
利用网格中"门"的朝向筛选哪些房间相互连通，再用连通房间共有的标记色统一填充。

Input structure:
- bg = 背景色（Black）。网格被 Grey 线条分割成若干矩形房间（类似迷宫的房间布局，Grey 线宽为 1 像素）。
- 每面 Grey 墙壁上可能有一个 1 像素宽的缺口（即该位置的 Grey 被替换为背景色），这些缺口就是"门"。
- 每个房间内部有 1-2 个孤立的彩色像素（非背景、非 Grey），这些是该房间的"标记色"。

Rule:
- 第一步（识别门的有效性）：一个门是"可通行"的，当且仅当门缺口两侧的两个房间各自至少拥有一个相同颜色的标记像素。如果两侧房间没有共享任何标记色，则该门视为"锁死"，等同于实墙。
- 第二步（确定连通分量）：通过所有可通行的门将房间连成若干连通分量。
- 第三步（填充）：对于每个连通分量，找到该分量中所有房间共同拥有的标记色（取交集）。用该共同颜色填充连通分量内所有房间的全部背景像素。若交集包含多种颜色，选取在该连通分量的房间中出现次数最多的颜色。原有的标记像素和 Grey 墙壁保留不变。

Key insight: 门的存在不等于连通——只有当相邻房间共享标记色时门才开放；解题者需要先理解"颜色匹配开门"的机制，再推导连通分量，最后确定填充色是所有连通房间的公共标记色。这是一个三层推理结构：判断门的有效性→建立连通关系→选取公共色填充。
</new_puzzle>

<new_puzzle>
根据箭头指向在网格中建立"投影链"，每个对象将自身形状沿箭头方向投影到下一个对象表面，并按投影顺序叠加着色。

Input structure:
- bg = 背景色（Black）。网格中散布着若干由单一颜色填充的小型矩形色块（宽高均 ≤ 5），每个色块颜色各不相同。
- 每个色块的某一侧边（上、下、左或右）外紧邻一个由 Red 像素组成的三像素箭头。箭头形状为：沿色块边缘外侧一格放置一个 Red 中心像素，然后在该中心像素的垂直于指向方向的两侧各放置一个 Red 像素，构成一个指向外侧的"V"形尖端。箭头尖端朝外的方向即为该色块的投影方向。

Rule:
- 第一步（建立投影链）：从每个色块出发，沿其箭头方向做直线延伸，找到射线上碰到的第一个其他色块——该色块即为投影目标。如果射线方向上没有其他色块，则该色块是链的末端。由此所有色块形成若干条单向链。
- 第二步（执行投影）：沿链从起点到末端依次处理。当色块 A 投影到色块 B 时，将 A 的矩形形状以 A 的颜色"印"在 B 所在的位置上：投影的锚点为 B 沿投影方向的迎面边的中心像素，A 的形状以该锚点为中心对齐绘制。投影的像素覆盖在 B 之上。
- 第三步：处理完所有投影后，移除所有 Red 箭头像素，将箭头位置恢复为背景色。原色块保持原位不动。

Key insight: 箭头不仅指示方向，还隐含了投影链的拓扑顺序——解题者需要先通过箭头方向和射线命中关系重建整条链的先后顺序，再理解"形状印到目标表面"的对齐规则；多层叠加时后投影覆盖先投影的结果。
</new_puzzle>

<new_puzzle>
网格中的彩色路径段各自记录了一个"笔画指令"，需要按路径段的长度排序后依次执行，在空白画布区域绘制出组合图案。

Input structure:
- bg = 背景色（Black）。网格被一条垂直的 Grey 分隔线（1 像素宽，贯穿网格全高）分为左右两半。
- 左半部分（指令区）：包含若干条由不同颜色绘制的连续路径段。每条路径段是由同一颜色像素组成的一笔 4-连通线段（可水平或垂直折弯），起点和终点各有一个该颜色的 2×2 方块标记，中间是 1 像素宽的路径。
- 右半部分（画布区）：完全为背景色的空白区域。画布区的中心位置有一个用 Maroon 像素标记的单点，作为绘制原点。

Rule:
- 第一步（解析指令）：对左侧每条路径段，识别其起点和终点的 2×2 方块。起点为两个方块中位于更靠左上位置（先比较行号，再比较列号）的那个。从起点到终点，沿路径逐像素行走，记录行走的方向序列（如"右 3 步、下 2 步、右 1 步"）。
- 第二步（排序）：统计每条路径段的总像素数（包含起点和终点的 2×2 方块以及中间路径），按像素数从少到多排序。
- 第三步（绘制）：在右侧画布上，以 Maroon 原点为第一条路径的起始位置，按排序后的顺序依次执行每条路径段的方向序列。每一步用该路径段的颜色绘制 1 像素。第一条路径段从原点开始绘制；绘制完毕后笔尖停留在终点；第二条路径段从上一条的终点位置继续绘制，以此类推。
- Maroon 原点像素在绘制完成后保留。

Key insight: 路径段的执行顺序不是它们在网格中的空间位置顺序，而是按像素总长排序决定的；解题者需要先测量每条路径段的长度来确定排序，再将每段的方向序列理解为相对位移指令，最后在画布上串联执行——三层推理环环相扣。
</new_puzzle>

<new_puzzle>
在网格中找到被纯色"遮罩块"部分遮挡的周期性拼贴图案，利用未遮挡区域推断完整的拼贴单元，然后移除遮罩并恢复被遮挡的内容。

Input structure:
- bg = 背景色（Black）。网格的大部分区域被一个周期性拼贴图案覆盖——该图案由一个小型矩形"瓦片"（例如 4×4 或 5×3）在水平和垂直方向无缝重复铺满整个网格。瓦片内使用 2-3 种非背景色（如 Blue、Green、Yellow）绘制某种几何纹样（如条纹、棋盘变体、十字花纹等）。
- 网格上叠放着 1-2 个纯色矩形"遮罩块"（颜色统一为 Magenta），遮罩块完全覆盖了其下方的拼贴图案内容。遮罩块的边缘与像素格对齐，但不一定与瓦片边界对齐。
- 遮罩块不会大到覆盖所有拼贴周期——保证至少有一个完整的瓦片周期在遮罩外可见。

Rule:
- 第一步：从未被遮罩覆盖的区域中，识别拼贴图案的最小重复周期。具体方法为：找到最小的矩形尺寸 (w, h)，使得所有可见（非 Magenta）像素都满足 pixel(r, c) = pixel(r + h, c) = pixel(r, c + w)，即在水平和垂直方向上具有周期 w 和 h。
- 第二步：从可见区域中提取一个完整的 w×h 瓦片内容。
- 第三步：对每个 Magenta 遮罩像素，根据其坐标 (r, c) 计算对应的瓦片内位置 (r mod h, c mod w)，用瓦片中该位置的颜色替换 Magenta，恢复被遮挡的拼贴图案。最终输出完整的无遮罩拼贴网格。

Key insight: 遮罩块是故意打断周期性的干扰物——解题者需要先从残缺的可见区域逆向推出拼贴的最小周期单元和相位，再利用周期性重建被遮挡的内容；关键难点在于瓦片边界与遮罩边界不对齐时，需要正确推断瓦片的起始偏移。
</new_puzzle>

<new_puzzle>
检测每个封闭形状内部的"缺陷标记"数量，根据数量从底部颜色图例中查找对应颜色，重新填充整个形状内部。

Input structure:
- bg = 背景色（Black）。网格底部有一行颜色图例：从左到右依次排列若干个 2×1 的竖向彩色条（每个条由 2 个同色像素上下叠放），条与条之间用 1 列背景色间隔。这些颜色各不相同（例如依次为 Blue、Red、Green、Yellow、Orange），按位置编号 1、2、3、4、5。
- 网格上方主区域有若干用 Grey 像素绘制的封闭形状轮廓（形状可以是矩形、L 形或 T 形等简单多边形，轮廓线宽 1 像素）。
- 每个封闭形状内部大部分像素为背景色，但散布着若干个 Maroon 像素作为"缺陷标记"，位置随机。

Rule:
- 对每个 Grey 轮廓封闭形状，数出其内部 Maroon 缺陷标记的数量 n（n 的取值范围为 1 到 5）。
- 在底部颜色图例中，从左往右取第 n 个颜色。
- 用该颜色填充该形状内部的所有像素（覆盖掉背景色和 Maroon 缺陷标记），Grey 轮廓保持不变。

Key insight: Maroon 像素不是需要保留的内容物，而是一种"计数信号"——它们的数量充当了查询颜色图例的索引；解题者必须先意识到缺陷数量与图例位置的对应关系，才能确定每个形状的填充颜色。
</new_puzzle>

<new_puzzle>
根据对象的"影子长度"确定图层叠放顺序，再按此顺序将对象堆叠到锚点位置。

Input structure:
- bg = 背景色（Black）。网格中散布着若干个小型彩色形状（每个形状由单一颜色的连通像素组成，大小 3×3 至 5×5），每个形状颜色各不相同。
- 每个形状的正右方紧邻一条由 Grey 像素组成的水平线段，从形状右边缘向右延伸若干格后终止。这条灰线即该形状的"影子"，不同形状的影子长度各不相同。
- 网格右下角有一个由 Maroon 像素标记的小十字（5 像素，上下左右各延伸 1 格），作为堆叠锚点。

Rule:
- 第一步：测量每个形状的影子长度（Grey 线段的像素数）。
- 第二步：按影子长度从长到短排序——影子最长的形状放在最底层，影子最短的放在最顶层。
- 第三步：将所有形状平移到锚点位置进行堆叠。每个形状的中心像素对齐到 Maroon 十字的中心。按照从底层到顶层的顺序依次绘制，上层覆盖下层。
- 第四步：移除原始位置的形状和影子（恢复为背景色），保留 Maroon 十字标记。

Key insight: 影子长度编码了深度信息——长影子意味着对象离"光源"更远、处于更深的图层；解题者需要先发现影子长度与叠放顺序的反向关系，再理解所有形状汇聚到锚点的堆叠机制。
</new_puzzle>
