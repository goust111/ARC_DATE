在网格中找到被纯色"遮罩块"部分遮挡的周期性拼贴图案，利用未遮挡区域推断完整的拼贴单元，然后移除遮罩并恢复被遮挡的内容。

Input structure:
- bg = 背景色（Black）。网格的大部分区域被一个周期性拼贴图案覆盖——该图案由一个小型矩形"瓦片"（例如 4×4 或 5×3）在水平和垂直方向无缝重复铺满整个网格。瓦片内使用 2-3 种非背景色（如 Blue、Green、Yellow）绘制某种几何纹样（如条纹、棋盘变体、十字花纹等）。
- 网格上叠放着 1-2 个纯色矩形"遮罩块"（颜色统一为 Magenta），遮罩块完全覆盖了其下方的拼贴图案内容。遮罩块的边缘与像素格对齐，但不一定与瓦片边界对齐。
- 遮罩块不会大到覆盖所有拼贴周期——保证至少有一个完整的瓦片周期在遮罩外可见。

Rule:
- 第一步：从未被遮罩覆盖的区域中，识别拼贴图案的最小重复周期。具体方法为：找到最小的矩形尺寸 (w, h)，使得所有可见（非 Magenta）像素都满足 pixel(r, c) = pixel(r + h, c) = pixel(r, c + w)，即在水平和垂直方向上具有周期 w 和 h。
- 第二步：从可见区域中提取一个完整的 w×h 瓦片内容。
- 第三步：对每个 Magenta 遮罩像素，根据其坐标 (r, c) 计算对应的瓦片内位置 (r mod h, c mod w)，用瓦片中该位置的颜色替换 Magenta，恢复被遮挡的拼贴图案。最终输出完整的无遮罩拼贴网格。

Key insight: 遮罩块是故意打断周期性的干扰物——解题者需要先从残缺的可见区域逆向推出拼贴的最小周期单元和相位，再利用周期性重建被遮挡的内容；关键难点在于瓦片边界与遮罩边界不对齐时，需要正确推断瓦片的起始偏移。
</new_puzzle>
