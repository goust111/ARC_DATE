- `Input structure`：
  - bg = 最常见颜色（如 black）。
  - 网格中有一个较大的矩形空心"画布框"，由 grey 像素围成，框内填充 bg。画布框的四条边上各有若干彩色标记像素（非 grey、非 bg），每个标记像素替换了该边上某个 grey 像素的位置。每条边上最多有一个标记像素。
  - 网格其他位置散布着若干小型彩色"印章"图案，每个印章是一个连通的非 bg 像素块（形状不规则，3-8 个像素），每个印章整体为单一颜色，不同印章颜色不同。

- `Rule`：
  - 第一层推理——颜色配对：每个画布框边缘上的标记像素颜色与网格中某个同色印章配对。
  - 第二层推理——确定盖印位置与方向：标记像素在画布框边上的位置决定印章在画布内的放置坐标。具体规则为：标记像素沿其所在边的方向（左到右或上到下）的相对位置，映射为印章在画布内部沿同一轴的对应位置。标记所在的边决定印章从哪个方向"贴入"画布——标记在顶边，印章从顶部向下放置（印章的最上行紧贴画布框顶部内侧）；标记在底边，印章从底部向上放置（印章的最下行紧贴画布框底部内侧）；标记在左边，印章从左侧向右放置（印章最左列紧贴画布框左侧内侧）；标记在右边，印章从右侧向左放置（印章最右列紧贴画布框右侧内侧）。
  - 第三层推理——旋转对齐：印章在放入画布前需要旋转，使其"底边"（印章原始形状中像素最多的那一行或列）朝向画布框的对应边。如果印章像素最多的是某一行，则该行被视为印章的底边；如果是某一列，则该列被视为底边。旋转印章（0/90/180/270 度）使底边与标记所在的画布框边平行且紧贴。
  - 输出为画布框及其内部盖印结果，画布框外的所有内容（包括原始印章）被清除为 bg。

- `Key insight`：标记像素同时编码了三重信息——颜色确定配对的印章，位置确定画布内的坐标偏移，所在边确定贴入方向。而印章自身的形状属性（最密集的行或列）又隐含地决定了旋转角度。解题者需要逐层解码这些信息才能正确放置每个印章。

4. 禁止把 ARC 颜色 id 、亮度、拼写等当作人类不可见的数值语义参与排序、大小比较或隐藏映射。颜色变化必须有可见结构线索。注意颜色亮度、拼写等也是不可见信息，若描述中出现违规的颜色id或者亮度，可自行使用少量的固定颜色替代，但注意生成时要在三个以内输入输出网格中对所有变换100%覆盖度。
