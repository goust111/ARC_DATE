- `description`：根据封闭区域内的色块数量，从色环图例中选取对应颜色，为每个封闭区域的边界重新上色。

- `Input structure`：
  - 背景为 black。
  - 网格中有若干由 grey 像素构成的不规则闭合边界，每个边界围出一个封闭区域。
  - 每个封闭区域内部散落着若干单像素的彩色小点（颜色各异，但小点本身的颜色不影响规则）。
  - 网格的一个角落有一个色环图例：一列纵向排列的彩色方块，从上到下依次编号为 1、2、3……，每个方块是一种不同的颜色（如 red、blue、green、yellow、orange 等）。

- `Rule`：
  - 对每个 grey 闭合边界，数出其内部封闭区域中彩色小点的数量 N。
  - 在色环图例中找到第 N 个颜色（从上往下，第 1 个对应图例最上方的方块）。
  - 将该闭合边界的所有 grey 像素重新着色为图例中第 N 个颜色。
  - 封闭区域内部的彩色小点在输出中被移除（变为 black 背景）。
  - 色环图例本身在输出中保留不变。

- `Key insight`：彩色小点的具体颜色是干扰项——真正重要的是每个区域内小点的数量，该数量用来索引色环图例以确定边界的最终颜色。解题需要两层推理：第一层是发现"数量→图例索引"的映射关系，第二层是意识到小点颜色本身无意义、仅数量有效。
</new_puzzle>

- `description`：将网格中的多个形状按照各自缺口的朝向投射到对应方向的收集墙上，在墙面上拼合成连续图案。

- `Input structure`：
  - 背景为 black。
  - 网格四条边各有一面彩色"收集墙"——由单行（或单列）连续像素构成，每面墙颜色不同（如上墙 red、下墙 blue、左墙 green、右墙 yellow），墙紧贴网格边缘。
  - 网格中央散布若干小型矩形色块（3×3 或 4×4），每个色块在恰好一条边上有一个单像素宽的缺口（即该边上缺少一个像素）。每个色块的颜色与四面墙之一匹配。
  - 每个色块内部有一个由另一种颜色绘制的小图案（如 L 形、T 形等），该图案占据色块内部的部分像素。

- `Rule`：
  - 每个色块的缺口朝向决定其投射方向：缺口朝上则向上投射，缺口朝右则向右投射，以此类推。
  - 将色块内部的小图案沿投射方向平移，直到图案的前沿像素紧贴对应方向的收集墙。
  - 图案到达墙面后，按原始相对位置"印"在墙内侧（占据墙相邻的行或列）。
  - 色块本身的外壳颜色必须与目标墙颜色一致——这是验证方向的冗余线索。
  - 原始位置的色块和内部图案在输出中被清除（变为 black）。

- `Key insight`：解题者需要同时发现两条独立线索并验证其一致性——缺口朝向决定方向，色块外壳颜色与墙颜色的匹配则确认目标墙。核心推理在于识别"缺口方向"这一非显然特征作为投射规则的关键，而颜色匹配提供了验证但非唯一决定因素。
</new_puzzle>

- `description`：利用网格中分散的"路径片段"重建完整路径，再根据路径经过的色带区域依次改变路径颜色。

- `Input structure`：
  - 背景为 black。
  - 网格被若干条水平的彩色色带分割成水平区域。每条色带为一行宽的连续彩色像素横贯整个网格宽度，色带颜色各不相同（如 red、blue、green、orange 等），色带之间是 black 背景区域。
  - 在 black 背景区域中，散布着若干由 grey 像素构成的短线段片段（水平或垂直，长度 2-5 像素）。这些片段是一条连续折线路径的碎片，但片段之间存在间断。
  - 有且仅有一个 maroon 像素标记路径起点，一个 azure 像素标记路径终点。

- `Rule`：
  - 将所有 grey 片段通过最短的轴对齐直线连接起来，形成一条从 maroon 起点到 azure 终点的唯一连续折线路径。连接时，在两个片段端点之间的缺口处补上 grey 像素（只允许水平或垂直延伸，且每个缺口只有唯一合理的连接方式）。
  - 路径重建完成后，检查路径从起点到终点依次穿越了哪些色带（路径像素与色带在同一行即视为"穿越"）。
  - 路径上的像素按区间重新着色：从起点到第一条色带之间的路径段着色为第一条色带的颜色；两条相邻色带之间的路径段着色为路径行进方向上刚穿越的那条色带的颜色；最后一条色带到终点之间的路径段着色为最后穿越的色带颜色。
  - 色带本身保持不变。起点和终点标记像素保持原色。

- `Key insight`：解题包含三层推理——第一层是从散碎片段中重建唯一路径（利用端点对齐和距离的唯一性），第二层是识别色带作为"颜色闸门"的角色，第三层是理解路径颜色的分段染色规则取决于路径穿越色带的顺序。
</new_puzzle>

- `description`：根据框架内图案的旋转对称阶数选择对应的填充纹理，将纹理铺入框架外围的空白区域。

- `Input structure`：
  - 背景为 black。
  - 网格中有若干个由 grey 像素绘制的正方形框架（如 7×7、9×9），框架之间不重叠，彼此间隔。
  - 每个框架内部有一个由某种颜色绘制的小图案。这些图案具有不同阶数的旋转对称性：有的图案具有 1 阶对称（无旋转对称，即只有 360° 旋转才与自身重合），有的是 2 阶（180° 对称），有的是 4 阶（90° 对称）。
  - 网格边缘有一排并列的纹理样本区：3 个小矩形区域，每个区域内部有一种不同的重复纹理（如条纹、棋盘格、交叉线等），每个纹理区域的左上角分别标有一个数字形状的标记——用 maroon 像素拼成 "1"、"2"、"4" 的字样，代表旋转对称阶数。

- `Rule`：
  - 判断每个框架内图案的旋转对称阶数 K（K 为 1、2 或 4）。
  - 在纹理样本区找到标记为 K 的纹理。
  - 在该框架的外围（框架外侧一圈，宽度为 1 像素的环形区域）铺上对应的纹理。纹理的铺设从框架左上角外侧开始，按纹理样本的图案周期性重复。
  - 框架本身和内部图案保持不变。

- `Key insight`：核心难点在于识别每个框架内图案的旋转对称阶数——解题者必须心理旋转图案来判断其对称性等级，然后用该等级去索引纹理库。这不是简单的颜色或大小匹配，而是需要对几何对称性进行视觉推理。
</new_puzzle>

<new_puzzle>
- `description`：在网格中用连通区域的拓扑嵌套关系构建树形层级，再根据层级深度分配颜色，最后将最深层物体复制到根层的对应位置。

- `Input structure`：
  - 背景为 black。
  - 网格中有若干由不同颜色绘制的闭合矩形环（即矩形框，内部为 black 或包含更小的矩形环）。矩形环可以嵌套——一个大矩形环内部可以包含一个或多个较小的矩形环，小矩形环内部又可以包含更小的，形成多层嵌套。
  - 网格左侧有一列垂直排列的彩色色块作为"深度图例"，从上到下分别表示深度 0（最外层）、深度 1、深度 2……每个色块颜色不同（如 red、green、blue、yellow 等）。

- `Rule`：
  - 确定每个矩形环的嵌套深度：不被任何其他矩形环包含的环深度为 0，被一层环包含的深度为 1，被两层包含的深度为 2，以此类推。
  - 根据深度图例，将每个矩形环重新着色为其深度对应的图例颜色（深度 0 对应图例第 1 个颜色，深度 1 对应第 2 个，以此类推）。
  - 找到所有达到最大深度的矩形环（即最内层的环），将它们的形状复制到网格中深度为 0 的矩形环内部的对应相对位置——相对位置的计算方式为：最内层环相对于其直接父环的偏移量，递归映射到最外层环的坐标系中。
  - 复制的形状使用最大深度对应的图例颜色。

- `Key insight`：解题需要三层推理：第一层是从视觉上识别矩形环的嵌套包含关系并确定层级深度；第二层是利用深度图例进行重新着色（发现"深度→颜色"的映射关系）；第三层是理解最内层物体向最外层"投影"的相对位置映射规则——这需要解题者追踪跨越多层嵌套的坐标对应关系。
</new_puzzle>
