<new_puzzle>
description: 根据框架内部的彩色种子像素的颜色，在框架的缺口方向上生长出树状分支结构，分支的层数由种子像素的数量决定。

Input structure:
- 背景色（bg）为黑色（Black），占据网格大部分区域。
- 网格中散布若干用灰色（Grey）像素绘制的矩形空心框架（边框宽1像素），每个框架的某一条边上有一个1像素宽的缺口。
- 每个框架内部放置1到3个不同颜色的种子像素（非黑色、非灰色），种子像素彼此不相邻。

Rule:
- 第一层推理：确定每个框架缺口所在的方向（上/下/左/右），这是树的生长方向。
- 第二层推理：框架内种子像素的数量 N 决定树的分支深度。从缺口中心向外延伸一条主干线（长度3像素），主干颜色为框架内第一个种子像素的颜色（按从上到下、从左到右扫描顺序）。
- 主干末端向生长方向的两个垂直侧各分出一条分支（长度2像素），分支颜色为第二个种子像素的颜色（若存在）。若 N=1，则只有主干无分支。
- 若 N=3，每条二级分支末端再各分出两条更短的三级分支（长度1像素），颜色为第三个种子像素的颜色。
- 所有生长线段遇到非背景像素或网格边缘时截断。

Key insight: 框架缺口定方向，种子数量定深度，种子扫描顺序定颜色层级——三个独立线索共同决定最终的树状输出结构。
</new_puzzle>

<new_puzzle>
description: 将散落的彩色碎片滑入由墙壁围成的房间中，碎片进入的门由碎片颜色与门框标记颜色的匹配决定，碎片在房间内的放置位置由房间内已有地标像素锚定。

Input structure:
- 背景色（bg）为黑色（Black）。
- 蓝色（Blue）像素构成若干封闭或半封闭的矩形房间墙壁，每个房间有1到2个缺口（门），每个门的两侧各有一个单独的彩色标记像素（非蓝色、非黑色），标记门的颜色身份。
- 每个房间内部有一个绿色（Green）地标像素，标记碎片放置的锚点位置。
- 房间外部散布若干小型矩形彩色碎片（宽高均不超过3像素），每个碎片为单一颜色。

Rule:
- 第一层推理（匹配）：每个碎片的颜色与某个门的标记颜色相同，该碎片属于那个门所在的房间。若房间有两个门且标记颜色不同，则每个门各吸引对应颜色的碎片。
- 第二层推理（定位）：碎片通过匹配的门进入房间后，需要放置在房间内部。放置规则为：碎片的几何中心对齐房间内的绿色地标像素位置。若一个房间有多个碎片（通过不同门进入），则按碎片面积从大到小的顺序依次叠放（大的在底层，小的覆盖在上层）。
- 碎片放置后，门的标记像素被擦除（变为黑色），碎片原来的位置也被擦除。地标像素被碎片覆盖。

Key insight: 门框标记颜色是碎片与房间的配对钥匙，而地标像素是碎片在房间内的精确锚点——两层匹配缺一不可。
</new_puzzle>

<new_puzzle>
description: 识别网格中由边框色围成的多个单元格区域，根据区域内"L形指针"图案的朝向，将该区域的图案内容沿指针方向"推送"到相邻单元格中，所有推送基于初始状态同时执行。

Input structure:
- 背景色（bg）为黑色（Black）。
- 橙色（Orange）像素构成完整的网格线，将整个网格分割为若干大小相同的矩形单元格（例如5x5的内部空间）。
- 每个单元格内部可能包含两类内容：一个由红色（Red）像素绘制的3像素L形指针（占据2x2区域的三个格子，缺失的角指示推送方向），以及一个由某种其他颜色绘制的小图案（sprite），图案不超过3x3。
- 有些单元格只有指针没有图案，有些单元格只有图案没有指针，有些两者都有。

Rule:
- 第一层推理（方向解读）：L形指针的缺口方向就是推送方向。2x2区域中缺失的角所在方位即为推送方向：缺口在右侧（右上或右下缺失）→向右推送；缺口在左侧→向左推送；缺口在上侧→向上推送；缺口在下侧→向下推送。当缺口位于对角位置时，水平方向优先。
- 第二层推理（内容传递）：每个含有指针的单元格，将自身的图案（若有）沿指针方向推送到相邻的下一个单元格中。图案在目标单元格中居中放置。若目标单元格原本已有图案，原图案被推送来的图案覆盖替换。
- 第三层推理（同时执行）：所有推送同时发生（使用原始状态计算），而非顺序执行。推送完成后，所有红色L形指针从网格中擦除（变为黑色）。无指针的单元格保持原有图案不变（但可能接收来自邻居的推送图案）。

Key insight: L形指针的缺口朝向编码了推送方向，所有推送基于初始状态同时执行——需要先全局读取所有指针和图案，再一次性完成传递，而非逐个处理。
</new_puzzle>

<new_puzzle>
description: 在包含多个闭合矩形环形轨道的网格中，根据轨道上同色标记点之间的顺时针弧段关系决定是否填充该弧段。

Input structure:
- 背景色（bg）为黑色（Black）。
- 网格中包含若干由灰色（Grey）像素绘制的闭合矩形环形轨道。每条轨道是一个由单像素宽的灰色线段构成的矩形环（即矩形的四条边，无缺口）。不同轨道不重叠但可能嵌套。
- 每条轨道上放有2到4个标记像素，标记像素位于轨道的灰色像素位置上（替换灰色），颜色为非黑色、非灰色的各种颜色。

Rule:
- 第一层推理（轨道与标记归属）：将每个标记像素归属到它所在的轨道。沿轨道按顺时针方向（从轨道左上角出发，沿上边→右边→下边→左边的顺序）排列该轨道上的所有标记。
- 第二层推理（配对与填充规则）：在顺时针序列中，依次将相邻的两个标记形成一对（第1与第2配对，第3与第4配对，依此类推；若标记总数为奇数，最后一个标记与第一个标记配对形成环绕对）。对于每一对标记：若两个标记颜色相同，则它们之间的顺时针弧段（沿顺时针从前一个标记到后一个标记经过的灰色像素）全部填充为该颜色；若两个标记颜色不同，则该弧段保持灰色不变。
- 轨道上未被任何配对覆盖的像素仍保持灰色。

Key insight: 关键在于理解顺时针排列后"奇偶配对"的方式以及"同色填充、异色不填"的规则——标记的空间位置决定弧段范围，颜色一致性决定是否激活填充。
</new_puzzle>

<new_puzzle>
description: 网格边缘的两条刻度轴上包含若干彩色连续段，同色段在行列交叉处生成实心矩形，矩形尺寸由对应刻度段的长度决定。

Input structure:
- 背景色（bg）为黑色（Black）。
- 网格的最左列和最顶行作为"刻度轴"。左侧刻度轴（最左列）包含若干段连续的彩色标记（每段为同一颜色的连续像素，段与段之间由黑色像素间隔）。顶部刻度轴（最顶行）也包含类似的彩色连续段。
- 刻度轴上使用的颜色来自可用色板（Red、Blue、Green、Yellow、Magenta等），同一刻度轴上同一颜色只出现一次。
- 网格内部（去除刻度轴后的区域）初始为全黑色。

Rule:
- 第一层推理（刻度解析）：识别左侧刻度轴上每段连续彩色标记的颜色、起始行位置、以及该段的像素长度（即高度 H）。识别顶部刻度轴上每段连续彩色标记的颜色、起始列位置、以及该段的像素长度（即宽度 W）。
- 第二层推理（颜色匹配与交叉生成）：找到左侧和顶部刻度轴上颜色相同的标记对。对于每一对同色标记，左侧标记提供行范围（从其起始行开始，跨度H行），顶部标记提供列范围（从其起始列开始，跨度W列），在网格内部对应的行列交叉区域绘制一个 H x W 的实心矩形，颜色与标记相同。
- 若左侧有某颜色而顶部没有（或反之），则该标记不产生任何矩形。
- 多个矩形若有重叠区域，后绘制的（颜色在左侧刻度轴上出现位置更靠下的）覆盖先绘制的。

Key insight: 刻度轴上的标记颜色是行列配对的钥匙，同色标记的连续长度分别编码了矩形的高和宽——需要将两条轴上的信息进行交叉组合才能确定每个矩形的位置和大小。
</new_puzzle>

<new_puzzle>
description: 多个彩色形状各自携带一个箭头标记指示投影方向，每个形状沿箭头方向投射出自身轮廓的影子，影子颜色由投影路径上穿过的"染色带"决定。

Input structure:
- 背景色（bg）为黑色（Black）。
- 网格中包含若干个由不同颜色绘制的小型连通形状（面积3到8像素），每个形状旁边紧邻一个由同色绘制的箭头。箭头由3像素组成：2像素直线箭杆加上1像素箭头尖端（箭头尖端位于箭杆末端沿垂直方向偏移1像素处，整体形成类似">"、"<"、"^"或"v"的形状），箭头指向上、下、左、右之一。
- 网格中还包含若干条横跨整行或整列的单像素宽"染色带"，每条染色带为一种独特颜色（与任何形状颜色不同），染色带颜色仅使用 Maroon、Azure 或 Yellow。

Rule:
- 第一层推理（箭头方向识别）：根据箭头的绘制方式确定每个形状的投影方向。箭杆沿投影方向延伸，箭头尖端指向投影方向。
- 第二层推理（影子投射）：将每个形状的每个像素沿箭头方向逐格平移，直到碰到网格边缘或碰到另一个已有的非背景像素（不含染色带——染色带视为可穿越）。平移后的像素组合构成该形状的"影子"。影子的默认颜色为灰色（Grey）。
- 第三层推理（染色带变色）：如果形状到影子之间的投影路径穿过了至少一条染色带，则影子的颜色变为所穿过的最后一条染色带（离影子最近的那条）的颜色，而非默认灰色。若路径上无染色带，影子为灰色。
- 原始形状、箭头和染色带在输出中保持不变，仅在背景上新增影子像素。

Key insight: 箭头定投影方向是第一层，投射轮廓到远端是第二层，染色带对投影路径的拦截决定影子最终颜色是第三层——三层信息叠加才能确定影子的位置和颜色。
</new_puzzle>

<new_puzzle>
description: 网格中包含若干对通过边框颜色配对的"印章"和"画布"正方形，画布角上的红色角标位置编码旋转角度，将印章图案旋转后盖印到对应画布中央。

Input structure:
- 背景色（bg）为黑色（Black）。
- 网格中散布若干小型正方形区域（内部空间为3x3或4x4），分为两类：
  - "印章"：外围有1像素宽的彩色边框，内部包含由另一种颜色绘制的非对称图案（如L形、T形、不规则形状），图案颜色与边框颜色不同。
  - "画布"：外围有1像素宽的彩色边框（与某个印章的边框颜色相同，表示配对），内部全为黑色。画布的四个角的边框像素中，恰好有一个被替换为红色（Red）像素，称为"角标"。
- 每个印章恰好配对一个画布（通过边框颜色相同来确定），内部尺寸也相同。

Rule:
- 第一层推理（配对）：边框颜色相同的印章和画布形成一对。
- 第二层推理（旋转解码）：画布角标所在的角位置编码旋转角度——左上角表示不旋转（0度），右上角表示顺时针旋转90度，右下角表示顺时针旋转180度，左下角表示顺时针旋转270度。
- 第三层推理（盖印）：将印章内部的图案按角标指示的角度顺时针旋转后，填入配对画布的内部区域。画布边框保持不变，角标像素恢复为画布的边框颜色（不再显示红色）。

Key insight: 边框颜色完成配对是第一层，角标位置直观编码旋转量是第二层（它在哪个角，图案的参考方位就转向哪个角），旋转后精确放入画布是第三层。
</new_puzzle>
