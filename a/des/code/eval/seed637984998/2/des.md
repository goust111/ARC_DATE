- `description`：根据围栏内部碎片的形状在外部拼合出完整围栏的缩略图，并用碎片颜色对缩略图分区着色。
- `Input structure`：背景色（black）网格上有一个大型单色围栏（封闭的一像素宽环形边框），围栏内部散落着若干不同颜色的碎片（每个碎片是一个小型连通区域）。围栏外部的某个角落有一个与围栏形状成比例缩小的空心轮廓（缩略框），缩略框内全为背景色。
- `Rule`：
  - 首先识别围栏的完整封闭轮廓以及缩略框的轮廓；缩略框是围栏按整数比例 k 缩小后的版本。
  - 对围栏内部的每个碎片，将其坐标相对于围栏左上角进行归一化，然后除以 k 得到它在缩略框中的对应区域。
  - 在缩略框内部，将每个碎片映射到的区域填充为该碎片的颜色。若多个碎片映射到同一缩略像素，取面积最大的碎片的颜色。
  - 围栏本身和碎片保持不变，仅在缩略框内填色。
- `Key insight`：缩略框是围栏的等比缩小版本，碎片在围栏内的相对位置决定了它们在缩略框中着色的位置——解题者需要先发现缩略框与围栏的缩放关系，再将碎片的空间位置映射到缩略图坐标。
</new_puzzle>

<new_puzzle>
- `description`：用网格边缘的颜色条纹序列作为编织指令，在中央画布上生成交叉编织图案。
- `Input structure`：背景色（black）网格。上边缘有一行彩色像素序列（从左到右），左边缘有一列彩色像素序列（从上到下），这两个序列分别定义经线和纬线的颜色。中央画布区域（排除边缘行列后的内部区域）初始全为背景色。
- `Rule`：
  - 上边缘序列的第 j 个像素颜色 C_j 定义中央画布第 j 列的经线颜色。
  - 左边缘序列的第 i 个像素颜色 C_i 定义中央画布第 i 行的纬线颜色。
  - 编织规则：在交叉点 (i, j)，若 i+j 为偶数（从 0 开始计数），显示经线颜色 C_j（上边缘）；若 i+j 为奇数，显示纬线颜色 C_i（左边缘）。
  - 但存在覆盖规则：若经线颜色与纬线颜色相同，则该交叉点始终显示该颜色，不受奇偶性影响。
- `Key insight`：边缘序列不只是简单的行列填充——解题者需要发现奇偶交替的编织模式，即同一行中经纬颜色交替出现，而同色交叉点打破了交替规律，成为识别编织机制的关键线索。
</new_puzzle>

- `description`：识别网格中散落对象的"投影轮廓"，将所有对象在水平和垂直方向上投影到边框上，再用投影交叉区域的颜色重绘出一个合成对象。
- `Input structure`：背景色（black）网格上散布着若干不同颜色的单色矩形对象（不重叠）。网格的最右列和最底行是空白的投影条带区域（初始为背景色）。网格中还有一个由 grey 边框围成的空矩形区域（合成画布），位于网格的某个固定位置。
- `Rule`：
  - 第一步（投影）：对每个彩色矩形对象，将其行范围投影到最右列（在该列对应的行区间填上该对象的颜色），将其列范围投影到最底行（在该行对应的列区间填上该对象的颜色）。若投影区间有重叠，后投影的颜色覆盖先投影的。
  - 第二步（交叉合成）：在合成画布内部，对于画布中每个像素位置 (r, c)，检查最右列第 r 行和最底行第 c 列的投影颜色。若两者都有非背景色且颜色相同，则该像素填充为该颜色；若两者颜色不同且都非背景色，则填充为最底行的颜色；若其中一个为背景色，则填充为背景色。
  - 原始矩形对象保持不变。
- `Key insight`：解题需要两层推理：第一层是发现对象的行列范围被分别投影到了边缘条带上，第二层是发现合成画布中的颜色由两个投影条带的交叉决定——只有行投影和列投影同时覆盖的区域才产生颜色，这类似于正交投影的交集重建。
</new_puzzle>

- `description`：根据"种子格"中心像素的颜色在颜色图例中查找对应的生长模板，按模板方向从种子格向外生长出图案。
- `Input structure`：背景色（black）网格分为两个区域，由一条 grey 竖线分隔。左侧区域是颜色图例区：包含若干小型 3x3 图案，每个图案的中心像素为一种独特颜色，其余 8 个邻居像素中部分为 maroon、部分为背景色，maroon 像素的位置编码了该颜色的"生长方向"（即中心向哪些邻接方向扩展）。右侧区域是工作画布：散布着若干孤立的单像素"种子"，每个种子的颜色与左侧图例中某个 3x3 图案的中心颜色对应。
- `Rule`：
  - 对右侧每个种子像素，在左侧图例中找到中心颜色匹配的 3x3 图案。
  - 读取该图案中 maroon 像素相对于中心的偏移方向集合（如：上、右上、右）。
  - 从种子位置出发，沿每个偏移方向持续延伸，逐格填充种子的颜色，直到遇到网格边界或另一个已填充的非背景色像素为止。
  - 种子本身保留原色。生长射线之间互相阻挡：先处理距离图例区更近（列号更小）的种子，再处理更远的种子。
- `Key insight`：解题者需要先在左侧图例中破解 3x3 模板的含义——maroon 像素的位置不是装饰而是方向编码，然后将每个种子与其模板配对，最后按特定顺序执行生长。图例解码和顺序依赖构成了两层独立的推理。
</new_puzzle>

- `description`：将网格中的彩色路径段按颜色分组，找到每组的两个断点，用对应颜色的"桥接模板"的形状连接断点。
- `Input structure`：背景色（black）网格上有若干条不同颜色的一像素宽路径段（每种颜色恰好形成两个不相连的连通分量，即路径被断成了两截）。每条路径的两个断点（端点）之间存在一段背景色的空隙。网格底部有一行"桥接模板区"，其中为每种路径颜色提供了一个小型连通形状（用对应颜色绘制），该形状编码了连接两个断点时应使用的桥接走法。
- `Rule`：
  - 对每种颜色，找到其两个连通分量各自最靠近对方的端点（断点 A 和断点 B）。
  - 在底部模板区找到同颜色的桥接模板，读取模板的形状：模板从其最左像素开始逐列扫描，每列中像素相对于前一列像素的行偏移（0 = 水平前进，+1 = 向下弯折，-1 = 向上弯折）构成一个方向序列。
  - 从断点 A 出发，朝断点 B 的大致方向（水平或垂直中选择主方向），按模板方向序列循环重复地逐步铺设桥接像素，直到到达断点 B 所在的行或列，然后直线连接到断点 B。
  - 桥接像素使用与路径相同的颜色。模板区在输出中被清除为背景色。
- `Key insight`：解题的第一层是识别每种颜色的断裂路径及其断点对，第二层是发现底部模板不是装饰而是桥接形状的编码——模板的逐列偏移定义了一种重复的弯折模式，该模式被循环应用于填补断裂间隙。两层推理缺一不可。
</new_puzzle>

- `description`：通过嵌套框架的层级深度决定内部填充图案的旋转次数，最终将旋转后的图案填入最内层。
- `Input structure`：背景色（black）网格上有一个嵌套的矩形框架结构：最外层是某颜色 A 的一像素宽矩形框，框内是背景色间隔，然后是颜色 B 的一像素宽矩形框，以此类推，形成 N 层嵌套框架（N 为 2 到 4 之间）。每层框架颜色各不相同。最内层框架内部有一个背景色的空腔。网格的另一个位置有一个独立的小型彩色图案（种子图案），其颜色与任何框架颜色都不同。
- `Rule`：
  - 数出嵌套框架的层数 N（从最外层到最内层的框架个数）。
  - 将种子图案顺时针旋转 N 次（即旋转 N×90 度）。
  - 将旋转后的图案放置到最内层框架的空腔中，左上角对齐空腔的左上角。
  - 种子图案的原始位置被清除为背景色，框架结构保持不变。
- `Key insight`：表面上只需把图案放入中心，但关键在于发现框架层数与旋转次数之间的隐含对应关系——不同样例中框架层数不同，导致同一图案被旋转不同角度，解题者必须从多个样例中归纳出"层数 = 旋转次数"这一非显然规律。
</new_puzzle>

<new_puzzle>
- `description`：用散落的彩色"钥匙块"解锁对应颜色的"锁孔"，解锁顺序由钥匙块的面积从小到大决定，每次解锁会改变后续锁孔的可见形态。
- `Input structure`：背景色（black）网格上有一个大型 grey 矩形面板，面板上有若干不同颜色的"锁孔"（即面板内部被挖去的、形状各异的孔洞，孔洞边缘像素为某种非 grey 非背景的颜色，内部为背景色）。面板外部散布着若干单色"钥匙块"（小型连通区域），每个钥匙块的颜色与某个锁孔边缘颜色相同。
- `Rule`：
  - 将所有钥匙块按面积（像素数）从小到大排序。
  - 按此顺序依次处理每个钥匙块：找到面板上同颜色边缘的锁孔，将钥匙块的形状（允许旋转和翻转）填入该锁孔内部。钥匙块的形状必须恰好适配锁孔的内部空间。
  - 每当一个锁孔被填充后，该锁孔的边缘颜色像素变为 grey（融入面板），同时面板中与刚填充区域四邻接的下一个锁孔会"扩展"——其内部空间向刚融合的方向增长一行或一列。
  - 所有钥匙块处理完毕后，清除面板外的钥匙块原始位置。
- `Key insight`：解题需要三层推理：第一层是发现钥匙块颜色与锁孔边缘颜色的配对关系；第二层是发现处理顺序由钥匙块面积决定（而非位置或颜色）；第三层是发现每次填充会导致相邻锁孔形态变化，因此后续匹配必须基于更新后的锁孔形状。
</new_puzzle>
