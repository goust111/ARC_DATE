  - 网格中包含若干 45 度斜线标记，由 grey 像素绘制。每个斜线标记仅占 1 个像素，其类型由该像素两侧的 1 像素 azure 辅助标记决定："\" 形斜线在其左上和右下各有一个 azure 像素，"/" 形斜线在其右上和左下各有一个 azure 像素。
  - 网格中包含若干 1x1 的 orange 像素，称为"接收器"。
  - 信号塔、斜线标记及其辅助像素、接收器之间互不重叠。

- `Rule`：
  - 第一层推理——射线传播与反射：每个信号塔从其四条边的中点（对于 2x2 方块，即上边两像素的正上方一格中点取左侧、右边两像素的正右方一格中点取上侧，以此类推）分别向上、下、左、右发射一条射线。射线沿直线传播，逐像素前进，遇到以下情况转向或停止：
    - 遇到 "\" 形 grey 像素：向右的射线转为向下，向下的转为向右，向左的转为向上，向上的转为向左。
    - 遇到 "/" 形 grey 像素：向右的射线转为向上，向上的转为向右，向左的转为向下，向下的转为向左。
    - 遇到网格边界、信号塔或另一个 grey 像素之后的第二次反射则终止（每条射线最多反射 1 次）。
  - 第二层推理——接收器颜色变换：统计每个接收器被多少条射线经过（不论颜色）。若恰好被 1 条射线经过，接收器变为该射线的颜色。若被 2 条或以上射线经过，接收器变为 maroon。若无射线经过，接收器保持 orange 不变。
  - 输出网格与输入尺寸相同。射线路径不画出（不可见），仅改变接收器颜色。信号塔、grey 斜线及 azure 辅助标记保持不变。

- `Key insight`：解题者需要先通过 azure 辅助像素判断每个 grey 像素代表的斜线方向（这是识别层），然后手动追踪射线的反射路径确定哪些接收器被命中（这是推演层），最后发现多重命中导致颜色统一变为 maroon（这是归纳层）——三层认知依次递进。
