- `description`：网格中散布的彩色箭头指向相邻区域的"颜料桶"，颜料桶的颜色沿箭头反方向回流，对箭头所在的封闭区域进行填充；多支箭头指向同一桶时，填充颜色由箭头数量的奇偶性决定。

- `Input structure`：
  - 背景为 black。
  - 网格被 grey 线条（1 像素宽）划分为若干封闭矩形区域。
  - 部分区域内部为空（全 black），部分区域内部中央有一个 2x2 的彩色方块，称为"颜料桶"（颜色为 red、blue、green、yellow、magenta 之一）。
  - 部分区域内部包含一个由 3 个 orange 像素组成的箭头标记。箭头的绘制方式如下：
    - 指向右的箭头：两个像素垂直排列（上下相邻），第三个像素在这两个像素的右侧一列、两行之间的那一行（即右侧中间位置）。
    - 指向左的箭头：两个像素垂直排列，第三个像素在左侧中间位置。
    - 指向下的箭头：两个像素水平排列（左右相邻），第三个像素在这两个像素的下方一行、两列之间的那一列（即下方中间位置）。
    - 指向上的箭头：两个像素水平排列，第三个像素在上方中间位置。
  - 每个包含箭头的区域，其箭头所指方向紧邻的 grey 墙壁另一侧的区域一定包含一个颜料桶。一个颜料桶可能被多个箭头指向。
  - 没有区域同时包含箭头和颜料桶。

- `Rule`：
  - 第一层推理——箭头方向解析与桶定位：识别每个箭头的 3 像素构型，判断其指向方向（上/下/左/右），然后找到箭头方向上穿过 grey 墙壁后到达的相邻区域中的颜料桶，确定该桶的颜色。
  - 第二层推理——回流填充：将颜料桶的颜色填充到箭头所在区域的所有 black 像素上（箭头自身的 orange 像素也被覆盖为该颜色）。
  - 第三层推理——奇偶冲突规则：统计每个颜料桶被多少个箭头指向。若该数量为奇数，则所有指向它的箭头所在区域正常填充桶的颜色。若该数量为偶数，则这些区域全部填充 azure（而非桶的原色）。颜料桶自身所在区域始终不填充（保持原样）。
  - 输出网格尺寸不变，grey 边界不变，颜料桶保持原样，空区域（无箭头无桶的区域）保持 black。

- `Key insight`：箭头的 3 像素构型编码了方向信息（第一层），方向指引颜色回流（第二层），但最隐蔽的是奇偶切换规则——解题者只有在看到某些区域意外变成 azure 时才会开始统计箭头数量并发现奇偶性决定了最终颜色（第三层）。
