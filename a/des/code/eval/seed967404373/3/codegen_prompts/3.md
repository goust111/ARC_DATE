- `Input structure`：
  - bg = black。网格中有若干条不同颜色的路径片段（每种颜色恰好有 2-4 段不相连的片段，每段是沿水平或垂直方向的连续像素条）。
  - 同色路径片段的端点（即片段两端的像素）之间存在唯一的直角连接方式（先水平再垂直，或先垂直再水平），使得所有同色片段恰好围成一个封闭矩形回路。
  - 网格的一个角落区域（如右下角）有一个用 grey 边框隔开的小图例区，图例区内包含若干行，每行左侧是一个颜色像素（标识色），右侧紧邻一个 2×2 的小图案（印章），印章由两种颜色交替排列构成棋盘格或条纹等简单图案。

- `Rule`：
  - 第一步：对每种颜色，将其所有断开的路径片段通过在端点之间补画同色直线段连接起来，形成一个完整的封闭矩形回路。补画规则：两个需要连接的端点之间，沿水平方向画到对齐列，再沿垂直方向画到对齐行（L形连接），路径宽度为 1 像素。
  - 第二步：在图例中找到与该路径颜色匹配的印章图案。
  - 第三步：将封闭回路内部的所有 black 像素用该印章图案进行平铺填充。平铺以回路内部区域的左上角为起点，将 2×2 印章周期性重复铺满整个内部区域。
  - 图例区域在输出中被清除为 black。

- `Key insight`：解题包含三层独立推理——（1）发现断开的同色片段需要补全成封闭矩形，（2）理解图例中颜色标识与印章图案的对应关系，（3）用对应印章平铺填充封闭区域。每一层都需要从样例中归纳非显然的规律。
