- `description`：网格中的每个彩色对象充当"模具"，其轮廓形状在 grey 画布上压印出凹陷，而压印的位置和朝向由对象自身携带的方向标记决定。

- `Input structure`：
  - bg = black。网格被分为左右两个区域（由一条垂直的 maroon 分隔线隔开）。
  - 左侧区域：一个大的 grey 实心矩形（"画布"）。
  - 右侧区域：若干个不同颜色的小型对象（每个对象由同色像素组成，形状不规则但连通）。每个对象内部恰好有一个像素颜色与对象其余部分不同，该像素为 red——这是"锚点"标记。此外，每个对象边缘恰好有一个像素为 green——这是"方向"标记，指示压印朝向。
  - 每个对象的尺寸不超过画布的尺寸。

- `Rule`：
  - 第一步：对每个右侧对象，提取其形状轮廓——即该对象所有同色像素（不含 red 锚点和 green 方向标记）构成的连通区域的形状。
  - 第二步：确定压印朝向。green 标记相对于 red 锚点的方向（上/下/左/右）表示该模具压印到画布上时，模具应面朝画布的哪个边。具体地：若 green 在 red 上方，则模具形状从画布的上边缘向内压印（即模具的 red 锚点对齐到画布上边缘）。其他方向类推。
  - 第三步：确定压印的横向或纵向位置。red 锚点在对象中的相对列位置（从左数第几列占对象总宽度的比例）映射到画布对应边上的同比例位置，将 red 锚点对齐到画布边缘该位置。
  - 第四步：在画布上将模具形状覆盖的区域从 grey 变为 black（即"凹陷"）。多个模具的凹陷可以叠加。
  - 输出仅包含左侧画布区域（不含分隔线和右侧对象）。

- `Key insight`：对象自身携带两个特殊标记像素——red 锚点同时编码了压印的定位基准和横向位置比例，green 方向标记编码了压印朝向画布的哪一侧。解题者需要同时解读两个标记的空间关系才能确定最终压印位置。

## 实现要求

1. `main(grid)` 必须实现新题描述中的确定性转换规则，不能只识别 `generate_input()` 的固定模板。
2. `generate_input()` 必须随机生成多样样例，不能固定死。随机维度应覆盖：网格大小、对象数量、位置、颜色、方向、形状参数或关键分支。
3. 生成器必须保证输入满足 `main()` 的隐式假设：对象不重叠、不越界、特殊标记唯一或可区分、匹配关系无歧义、关键分支出现概率相同。
4. 禁止把 ARC 颜色 id 、亮度、拼写等当作人类不可见的数值语义参与排序、大小比较或隐藏映射。颜色变化必须有可见结构线索。注意颜色亮度、拼写等也是不可见信息，若描述中出现违规的颜色id或者亮度，可自行使用少量的固定颜色替代，但注意生成时要在三个以内输入输出网格中对所有变换100%覆盖度。
5. 输出样例要视觉清晰：避免对象粘连、覆盖关系混乱、同一像素多重语义、过密导致规则不可读。
6. 若规则有多个分支，生成器不能长期固定成一个分支；应让分支在随机样例中合理出现，即每个分支出现的概率平均，所谓的分支是在描述中提到的分支，即规则语义中的不同情况。
7. 代码风格参考 `ARC_code`：使用 `numpy`，必要时使用本地 helper，但目标文件应能被 `SourceFileLoader` 直接加载。
8. 可以在目标目录放公共 helper 文件，但若只实现一道题，优先保持目标文件自包含，减少额外依赖。
