- `Key insight`：解题者需要先破译色板中的"形状→颜色"编码，再将这个映射应用到围栏上；围栏内部形状的自身颜色是干扰项，只有几何轮廓才是匹配键。

- `Input structure`：
  - 背景色为 black。
  - 网格中有若干条彩色线段片段（每条片段为水平或垂直的连续同色像素，长度 2-6 像素），颜色包括 red、blue、green 等。
  - 不同颜色的片段在空间上断开，但同色片段可以通过平移对齐（端点在同一行或同一列且间隔为 1 个 black 像素）首尾衔接。
  - 网格的一个角落有一个小型"颜色转换图例"：由 3x1 或 1x3 的色条组成，每条色条格式为 [颜色A, grey, 颜色B]，表示当颜色 A 的路径段与颜色 B 的路径段在交汇处相遇时，后续应使用的目标颜色。

- `Rule`：
  - 第一步：将同色的线段片段拼接起来——找到能首尾衔接的同色片段（端点在同一行或列且间距恰好 1 像素），在它们之间的 1 像素间隔处填上该颜色，形成连续的单色路径段。
  - 第二步：识别不同颜色路径段的交汇处（两条不同色路径段端点相邻的位置，间隔 1 像素）。
  - 第三步：根据图例的转换规则，在每个交汇处将后续路径段重新着色。具体地：若颜色 A 的路径段末端与颜色 C 的路径段起端相邻，查找图例中 [A, grey, X] 条目，将交汇间隔像素及后续路径段全部染为 X 所指定的颜色。
  - 图例区域在输出中被移除。

- `Key insight`：解题者必须先完成同色片段的空间拼接（第一层），再发现不同色段之间的交汇关系并应用颜色转换图例（第二层）；图例编码的是"来源色→目标色"的有向映射，而非简单替换。

- `description`：在网格中识别被"门"连通的相邻房间，根据房间内标记物的数量决定门的开闭状态，从而确定哪些房间最终连通并统一填色。

- `Input structure`：
  - 背景色为 black。
  - 网格由 grey 像素构成的单像素宽直线墙壁分割成若干矩形房间（类似平面图）。
  - 每面墙壁上最多有一个"门"：门是墙壁上被移除的一个像素宽缺口（即墙壁线段中有一个 black 像素中断）。
  - 每个房间内部可能放有 0 到若干个 red 标记像素（散布在房间内部的 black 区域中，互不相邻）。
  - 网格的一角有一个图例区域：一个小矩形框内展示两种状态——上方是一个带缺口的短墙壁片段旁标注 green 像素（表示"门开"），下方是一个完整短墙壁片段旁标注 maroon 像素（表示"门关"）。

- `Rule`：
  - 第一层推理——判定门的状态：对于每扇门（墙壁缺口），查看门两侧的两个房间。如果两个房间内的 red 标记数量相同，则门"开启"；如果数量不同，则门"关闭"（用 grey 像素填回缺口，恢复完整墙壁）。
  - 第二层推理——连通填色：所有门开启的缺口保持连通。通过开启的门彼此连通的房间被视为一个连通区域，将整个连通区域内所有 black 像素填充为 green。
  - 未与任何其他房间通过开启的门连通的孤立房间，内部填充为 maroon。
  - 所有 red 标记像素在输出中被移除（变回房间的填充色）。
  - 图例区域在输出中被移除。

- `Key insight`：门的开闭取决于两侧房间标记数量是否相等（第一层），而最终的填色取决于开启门所形成的连通分量（第二层）；解题者需要先逐门判定，再全局分析连通性。
</new_puzzle>

- `description`：将散落的彩色碎片按颜色配对拼合成完整矩形，再根据每个矩形内部的孔洞数量，参照图例将矩形排列到输出网格的指定列中。

- `Input structure`：
  - 背景色为 black。
  - 网格中散布着若干彩色碎片（每个碎片是一个不规则的 4-连通区域）。碎片两两同色配对，每对碎片恰好可以无旋转、无翻转地通过平移拼合成一个完整的实心矩形（两块碎片形状互补，像拼图的两半）。
  - 每对碎片拼合后形成的矩形内部可能包含若干个 black 孔洞像素（即碎片上的穿孔），孔洞数量为 0、1、2 或 3。
  - 网格的一侧有一列纵向排列的 grey 参考格（每个参考格是一个小的 grey 实心矩形），从上到下分别有 0、1、2、3 个 black 孔洞，对应输出中从左到右的列位置。

- `Rule`：
  - 第一层推理——配对拼合：找到同色碎片对，将它们在空间中平移拼合成完整矩形。拼合方式由碎片的互补边缘决定——一个碎片的凹处恰好对应另一个的凸处，两者合并后形成无间隙的矩形。
  - 第二层推理——孔洞计数与分类：数出每个拼合矩形中 black 孔洞像素的数量（0、1、2 或 3）。
  - 第三层推理——队形排列：参照 grey 参考格的排列顺序，将拼合好的矩形按孔洞数量放置到输出网格中。孔洞数为 0 的矩形放在最左列，孔洞数为 1 的放在第二列，依此类推。同一列内多个矩形按原始碎片在输入中的最高行位置从上到下排列，矩形之间间隔一行 black。
  - 输出网格仅包含排列好的矩形，背景为 black，参考格不出现在输出中。

- `Key insight`：解题者需要完成三步非平凡推理——先通过形状互补识别配对关系（第一层），再通过孔洞计数对矩形分类（第二层），最后通过参考格破译分类到位置的映射规则（第三层）。碎片的颜色是配对线索而非排序依据。

<new_puzzle>
- `description`：识别网格中的"印章"和"信封"，根据印章上的方向标记将印章图案旋转后盖印到对应颜色的信封空白区域中。

- `Input structure`：
  - 背景色为 black。
  - 网格中有若干个"信封"：每个信封是一个彩色（如 red、blue、green 等）的单像素宽矩形边框，内部为 black，且边框的某一条边上有一个 2 像素宽的缺口（模拟信封开口），缺口位置可在上、下、左、右任一边。
  - 网格中另有若干个"印章"：每个印章是一个与某个信封同色的小型图案（由该颜色像素构成的不规则连通形状，bounding box 尺寸严格小于对应信封内部空间），印章图案的外侧（不与图案主体 4-连通的位置）恰好有一个 yellow 单像素标记。该 yellow 标记位于印章图案 bounding box 的上、下、左、右某一侧（距离 bounding box 边缘 1 像素），指示印章的"原始朝向"。
  - 每个信封颜色恰好对应一个同色印章。

- `Rule`：
  - 第一层推理——匹配：将每个印章按颜色匹配到同色信封。
  - 第二层推理——计算旋转：观察信封缺口所在的边（上/下/左/右）和印章 yellow 标记所在的方向（上/下/左/右）。将印章旋转（以 90 度为单位），使得 yellow 标记方向旋转到与信封缺口方向一致。例如：标记在右侧、缺口在上方，则印章顺时针旋转 90 度。
  - 第三层推理——盖印：将旋转后的印章图案（不含 yellow 标记）居中放置到对应信封的内部 black 区域中。居中方式为：印章 bounding box 在信封内部区域中水平和垂直方向各自居中（若无法精确居中则偏左偏上）。
  - 输出中印章从原始位置消失（替换为 black），yellow 标记也消失，信封边框保留，内部显示盖印后的图案。

- `Key insight`：解题者需要发现颜色匹配关系（第一层），再理解缺口方向与标记方向之间的旋转对应关系（第二层），最后执行旋转与居中放置（第三层）。缺口不是装饰而是旋转指令的编码。
</new_puzzle>
