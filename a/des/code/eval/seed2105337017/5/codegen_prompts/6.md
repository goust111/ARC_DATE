Input structure:
- bg = 最常见颜色（如 black）。网格的最左列是"控制列"，其中包含若干非背景色像素，每个像素占一行，颜色可能重复。
- 网格的最上行是"索引行"，其中每个非背景色像素的颜色各不相同，标记了对应列的归属。
- 网格内部（去掉最左列和最上行后的区域）包含若干"模板行"，每个模板行恰好占据一行，跨越整个内部宽度，由多种非背景色像素构成。同一行中不同位置可能有不同颜色的图案。
- 每个模板行在其最左端像素位置（紧邻控制列右侧的那个像素）有一个颜色标签像素，该标签颜色与索引行中某个像素的颜色相同，用于标识该模板行。

Rule:
- 第一层推理：建立颜色到模板行的映射——对于索引行中的每个颜色 C，找到索引行中颜色为 C 的像素所在的列号 K；然后在内部区域中，找到第 K 列上标签像素颜色为 C 的那一行，即为颜色 C 对应的模板行。
- 第二层推理：从控制列从上到下读取颜色序列。每遇到颜色 C，就在输出中追加 C 所对应的模板行（保持图案不变）。若同一颜色在控制列中出现多次，对应模板行也重复输出多次。
- 输出网格的宽度等于模板行的宽度（不含控制列），高度等于控制列中非背景色像素的总数。控制列和索引行不出现在输出中。

Key insight: 控制列的颜色不直接指向模板行，而是通过索引行建立间接引用——解题者需要发现这一双重索引机制，即颜色先映射到索引行中的列位置，再通过列位置找到对应的模板行。
