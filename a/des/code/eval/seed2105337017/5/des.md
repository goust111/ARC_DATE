<description>
根据围栏颜色在色板中查找对应的填充图案，然后将图案平铺填入围栏内部。

Input structure:
- bg = 最常见颜色（如 black）。网格中散布若干由不同颜色围成的封闭矩形"围栏"，围栏宽度为一个像素，围栏内部全为背景色。
- 网格的一侧边缘区域有一组"色板"：每个色板是一个小矩形区块，其外框颜色与某个围栏的颜色相同，内部填有由两种非背景色像素构成的 2×2 或 3×3 小图案（图案可以不对称）。
- 每个围栏的颜色恰好对应一个色板的外框颜色，且色板数量与围栏数量一致。

Rule:
- 对每个封闭围栏，找到外框颜色与之匹配的色板，提取色板内部的图案（去掉色板外框后剩余的矩形区域）。
- 将该图案以左上角对齐的方式在围栏内部进行周期性平铺（tile），即沿行和列方向重复图案，直到填满围栏内部所有背景色像素。若围栏内部尺寸不是图案尺寸的整数倍，则在右侧和底部截断图案。
- 围栏本身保持不变，色板区域在输出中被擦除为背景色。

Key insight: 色板的外框颜色是查找键，将围栏与其填充图案关联；图案的平铺方式是周期性重复而非拉伸，需要处理边缘截断。
</description>

<description>
识别网格中的"源对象"和"影子对象"配对关系，用源对象的形状覆盖影子对象的位置，覆盖颜色由影子对象决定。

Input structure:
- bg = 最常见颜色。网格中有若干成对出现的对象：每对包含一个"源对象"（多色、形状完整）和一个"影子对象"（单色、形状为源对象的退化版本——仅保留了源对象最外层轮廓的某一条边）。
- 影子对象的颜色各不相同，且影子对象的像素排列构成源对象某一侧边缘（上、下、左或右边缘）的精确投影。
- 源对象与其对应影子对象之间存在唯一匹配：影子对象的长度（像素数）等于源对象在影子对象所对应边方向上的跨度。

Rule:
- 第一层推理：通过比较影子对象的像素数与每个源对象在各方向上的边缘长度，确定每个影子-源的配对关系以及影子代表的是哪条边（上/下/左/右）。
- 第二层推理：将源对象的完整形状"生长"到影子对象所在位置——以影子对象作为对应边，向内侧展开源对象的完整形状。生长后的对象使用影子对象的颜色重绘整个形状（替换源对象的所有原始颜色）。
- 源对象的原始位置被擦除为背景色。

Key insight: 影子对象不仅标记了目标位置，还隐式编码了源对象的朝向（通过指示哪条边）；配对依赖于边缘长度匹配而非空间邻近性。
</description>

<description>
在网格中找到由彩色像素构成的"路径指令序列"，按照指令序列控制一个画笔在空白画布区域绘制轨迹。

Input structure:
- bg = 最常见颜色。网格被一条单像素宽的灰色（grey）分隔线分成两个区域：左侧为"指令区"，右侧为"画布区"（全为背景色）。
- 指令区内有一个起始标记（一个 azure 像素）和从该像素出发的一条由彩色像素构成的单像素宽 4-连通路径。
- 路径上的像素使用四种颜色中的某几种：red 表示"向右画一格"，green 表示"向下画一格"，yellow 表示"向左画一格"，magenta 表示"向上画一格"。
- 画布区的左上角有一个 azure 像素标记画笔起始位置。

Rule:
- 从指令区的 azure 起始标记出发，沿 4-连通路径依次读取每个彩色像素的颜色，得到一个方向指令序列。
- 在画布区，从 azure 起始位置开始，按照指令序列逐步移动画笔。画笔每移动一步，就在新位置绘制一个与当前指令颜色相同的像素。
- 若画笔移动到画布边界之外，则跳过该步指令（不绘制），继续处理下一条指令。
- 指令区在输出中保持不变。

Key insight: 路径的拓扑顺序（从起点沿唯一路径遍历）将二维空间排列的颜色像素转换为一维指令序列；颜色同时编码了方向信息和绘制颜色，这种双重含义需要从样例中归纳发现。
</description>

<description>
根据每个封闭区域内"种子像素"的数量选择对应的几何变换，对区域的边框形状进行变换后输出。

Input structure:
- bg = 最常见颜色（如 black）。网格中有若干互不重叠的封闭矩形边框，每个边框由单一非背景色绘制，宽度为一个像素。
- 每个边框内部散布着若干 orange 像素作为"种子"，种子数量为 1 到 4 之间。
- 边框外部的网格区域全为背景色（除了其他边框）。

Rule:
- 第一层推理：数出每个边框内部 orange 种子像素的数量 N（1 ≤ N ≤ 4）。
- 第二层推理：根据 N 的值对该边框执行对应的几何变换：
  - N=1：保持原样不变（恒等变换）。
  - N=2：将边框沿其水平中轴做上下翻转（垂直镜像）。
  - N=3：将边框绕其中心顺时针旋转 90 度。
  - N=4：将边框缩小为原来的一半尺寸（长宽各取一半，向下取整），放置在原边框区域的左上角，原边框其余区域填为背景色。
- 所有种子像素在输出中被移除（变为背景色）。变换后的边框保持原来的颜色。
- 若旋转后的边框超出原占用区域，则裁剪到原区域范围内。

Key insight: 种子数量不是简单的计数——它是一个查找键，映射到四种截然不同的空间变换；解题者必须从样例中同时归纳出"计数→变换类型"的映射表和每种变换的具体操作。
</description>

<description>
将网格中分散的彩色碎片按颜色分组，在每组内根据碎片的相对位置关系拼合成完整形状，然后按形状面积从大到小垂直排列输出。

Input structure:
- bg = 最常见颜色。网格中散布着多个小的彩色像素块（碎片），每个碎片是一个 4-连通的单色区域，包含 1 到 6 个像素。
- 同一颜色的碎片有 2 到 4 个，分布在网格的不同位置。不同颜色之间的碎片互不接触。
- 每种颜色的所有碎片可以像拼图一样无重叠地拼合在一起，形成一个紧凑的矩形（无空洞）。拼合方式是：保持各碎片的形状不变，仅做平移，使它们紧密相邻形成矩形。

Rule:
- 第一层推理：将所有碎片按颜色分组。对每组碎片，找到唯一的平移组合方式，使所有碎片无重叠、无空隙地拼成一个实心矩形。拼合时碎片不旋转、不翻转，只做平移。
- 第二层推理：计算每个拼合后矩形的面积（像素总数），按面积从大到小排序。
- 输出一个新的紧凑网格：将排序后的矩形从上到下依次排列，每两个矩形之间留一行背景色间隔，每个矩形左对齐。输出网格的宽度等于最宽矩形的宽度，高度为所有矩形高度之和加上间隔行数。

Key insight: 碎片的拼合不依赖碎片在原网格中的绝对位置，而需要发现每组碎片的相对偏移关系使它们恰好填满一个矩形；排序规则需要在拼合完成后才能确定，形成两层依赖的推理链。
</description>

<description>
识别网格中的"模板行"和"控制列"，用控制列中的颜色序列通过索引行间接引用模板行，决定输出中行的排列顺序和重复次数。

Input structure:
- bg = 最常见颜色（如 black）。网格的最左列是"控制列"，其中包含若干非背景色像素，每个像素占一行，颜色可能重复。
- 网格的最上行是"索引行"，其中每个非背景色像素的颜色各不相同，标记了对应列的归属。
- 网格内部（去掉最左列和最上行后的区域）包含若干"模板行"，每个模板行恰好占据一行，跨越整个内部宽度，由多种非背景色像素构成。同一行中不同位置可能有不同颜色的图案。
- 每个模板行在其最左端像素位置（紧邻控制列右侧的那个像素）有一个颜色标签像素，该标签颜色与索引行中某个像素的颜色相同，用于标识该模板行。

Rule:
- 第一层推理：建立颜色到模板行的映射——对于索引行中的每个颜色 C，找到索引行中颜色为 C 的像素所在的列号 K；然后在内部区域中，找到第 K 列上标签像素颜色为 C 的那一行，即为颜色 C 对应的模板行。
- 第二层推理：从控制列从上到下读取颜色序列。每遇到颜色 C，就在输出中追加 C 所对应的模板行（保持图案不变）。若同一颜色在控制列中出现多次，对应模板行也重复输出多次。
- 输出网格的宽度等于模板行的宽度（不含控制列），高度等于控制列中非背景色像素的总数。控制列和索引行不出现在输出中。

Key insight: 控制列的颜色不直接指向模板行，而是通过索引行建立间接引用——解题者需要发现这一双重索引机制，即颜色先映射到索引行中的列位置，再通过列位置找到对应的模板行。
</description>

<description>
在网格中找到多个同色矩形框，根据每个框内部"指针像素"指向的方向，将框中的图案沿传递链平移到下一个框中。

Input structure:
- bg = 最常见颜色。网格中有若干个大小相同的矩形区域，由 grey 边框围成，排列成一行或一列（相邻框共享边框线）。
- 每个矩形框内部包含一个由某种非背景、非灰色颜色绘制的小图案（各框图案不同），以及恰好一个 red 像素作为"指针"。
- 指针像素位于框内部的四条边之一的中点位置（上边中、下边中、左边中或右边中），指示一个方向（上/下/左/右），即从框中心看向指针像素的方向。
- 有且仅有一个框不含指针像素，该框为"终止框"。

Rule:
- 第一层推理：确定传递链的顺序——从每个含指针的框出发，指针方向指向的相邻框就是该框内容的"接收者"。沿着指针方向串联所有框，形成一条从"起始框"（没有任何其他框指向它）到"终止框"的链。
- 第二层推理：沿链条方向传递内容——起始框的图案保持不变；链中每个后续框的图案被替换为其前驱框的原始图案（不含指针像素）。终止框的图案被替换为指向它的前驱框的原始图案。
- 所有指针像素（red）在输出中被移除（变为背景色）。框的灰色边框保持不变。

Key insight: 指针不仅编码方向，还隐式定义了一条单向传递链；内容沿链条"平移"一格，类似于移位寄存器——解题者需要先从指针方向重建完整链路，再执行内容的整体平移。
</description>
</new_puzzle>
