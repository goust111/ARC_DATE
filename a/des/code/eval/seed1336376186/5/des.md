- 在网格中与框架分离的位置，散布着若干小型连通精灵（sprite），每个精灵恰好由一种非背景颜色组成，且每种指定颜色恰好对应一个精灵。

- 对每个框架，找到其内部箭头的颜色 C 和方向 D。
- 在网格中找到颜色为 C 的精灵。

- 框架和箭头保持不变。

Key insight: 框架内箭头同时编码了两层信息——颜色确定配对哪个精灵，方向确定精灵的放置位置和翻转轴。解题者需先通过颜色匹配完成配对，再根据方向完成空间变换，这两步推理缺一不可。

在分隔线划分的多个子区域中，每个区域内的彩色图案充当"印章模板"，而区域边界上的缺口决定了该模板向相邻区域盖章的位置和朝向。

Input structure:
- 背景色 bg 为 Black。网格被一种分隔色（如 Azure）的完整横线和竖线分割为若干矩形子区域（类似九宫格或更大的网格布局）。
- 部分子区域内含有用非背景、非分隔色绘制的小型彩色图案（模板区域），图案不超过子区域大小的一半。其余子区域为空（全为背景色）。
- 每条分隔线上恰好有一个缺口：缺口处的分隔色像素被替换为背景色，缺口宽度为 1 像素。

Rule:
- 对每个含有模板图案的子区域，找到其四条边界分隔线上的所有缺口。
- 对于每个缺口，确定缺口连接的相邻空白子区域。
- 将模板图案复制到该相邻空白子区域中，放置位置满足：模板图案在缺口所在方向上紧贴缺口对侧的分隔线，在垂直于缺口方向上与缺口对齐（模板中心行/列对齐缺口位置）。
- 如果缺口在模板区域的左侧或右侧，图案水平翻转后盖入；如果缺口在上侧或下侧，图案垂直翻转后盖入。
- 分隔线（含缺口）保持不变；模板原始区域保持不变。

Key insight: 解题者需要完成三层推理：第一层是识别分隔线上不显眼的单像素缺口；第二层是理解缺口建立了"模板区域→空白区域"的传输关系；第三层是发现盖章时发生了镜像翻转，翻转轴由缺口方向决定。

<description>
网格中散布的彩色对象按照"嵌套深度"分层：被其他对象完全包围的对象层级更深，输出时每层对象用不同的变换规则重新着色——最外层保持原色，第二层替换为其包围者的颜色，第三层替换为第二层包围者的颜色，以此类推形成颜色传递链。

Input structure:
- 背景色 bg 为网格中最常见的颜色（如 Black）。
- 网格中有若干互不重叠的闭合环形对象（每个对象由单一颜色的像素组成，形成一个封闭环，内部为背景色或包含更小的对象）。
- 这些环形对象形成嵌套关系：某些小环完全位于大环的内部空腔中，可以多层嵌套（如大环包含中环，中环包含小环）。
- 每个环的颜色各不相同，使用 Red、Blue、Green、Yellow、Magenta、Orange 等颜色。

Rule:
- 确定每个环形对象的嵌套深度：不被任何其他环包围的环深度为 0，被一个环包围的深度为 1，被两层环包围的深度为 2，以此类推。
- 深度为 0 的环保持原色不变。
- 深度为 1 的环，其颜色替换为直接包围它的那个深度为 0 的环的颜色。
- 深度为 2 的环，其颜色替换为直接包围它的那个深度为 1 的环的**原始颜色**（变换前的颜色）。
- 以此类推：深度为 N 的环的颜色替换为其直接包围者的原始颜色。
- 输出网格尺寸与输入相同，背景不变，仅环的颜色按上述规则变化。

Key insight: 解题者首先需要识别环形对象之间的空间包含关系来确定嵌套层级，然后需要发现颜色传递规则是"继承直接父环的原始颜色"而非简单的统一重着色。这两步推理要求解题者同时理解空间拓扑和颜色映射逻辑。
</description>

网格中有一张由彩色节点和灰色连线组成的"电路图"，每个节点的颜色在传播过程中会被其所有输入连线对侧节点的颜色"混合替换"；混合规则是：若所有输入颜色相同则采用该颜色，若不同则采用网格角落色块指定的优先级中最高的那个颜色。

Input structure:
- 背景色 bg 为 Black。
- 网格中散布着若干小型方块节点（每个为 2x2 的单色方块），颜色各异，使用 Red、Blue、Green、Yellow、Orange 等。
- 节点之间由 Grey 像素绘制的直线段（水平或垂直，宽度 1 像素）连接，每条连线连接恰好两个节点（Grey 线段的一端紧邻一个节点，另一端紧邻另一个节点）。
- 每条连线的中间位置有一个单像素的箭头标记（用 Maroon 色绘制），紧贴连线的一侧：Maroon 像素在连线上方或左侧表示信号从左方或上方节点流向右方或下方节点；在连线下方或右侧表示信号反向流动。箭头标记指示连线的方向性——信号只能从源节点流向目标节点。
- 网格的左下角有一个小型色块列表（纵向排列的单色像素列），从上到下表示颜色优先级从高到低。

Rule:
- 根据 Maroon 箭头标记确定每条连线的方向，建立有向连接关系。
- 找到所有"源节点"（没有任何入边的节点），它们的颜色保持不变。
- 对于有入边的节点，收集所有通过入边连接的前驱节点的颜色：
  - 若所有前驱节点颜色相同，则当前节点变为该颜色。
  - 若前驱节点颜色不同，查看左下角的优先级列表，取优先级最高的颜色作为当前节点的颜色。
- 按拓扑顺序（从源到汇）逐层传播，直到所有节点颜色确定。
- 输出中仅节点颜色改变，连线和箭头标记保持不变。

Key insight: 第一层推理需要解题者发现 Maroon 标记的位置编码了连线方向（而非仅仅是装饰），从而建立有向图关系；第二层需要发现颜色传播遵循拓扑顺序——源节点不变，下游节点由上游决定；第三层需要归纳出当多色冲突时，角落的色块列表充当优先级裁判。三层机制交织形成一个完整的"信号传播"系统。

- 钥匙像素在输出中被擦除，围栏边框保持不变。

<description>
网格中有若干彩色路径段和若干标记点，需要根据路径段的端点颜色匹配将它们首尾相接拼成一条连续路径，然后在标记点位置沿路径方向生长出与路径段等长的分支。

Input structure:
- 背景色 bg 为 Black。
- 网格中散布着若干彩色线段（每段是水平或垂直的矩形条，宽度为 1 像素，长度各异），每段由单一颜色绘制。
- 不同线段的颜色可能相同也可能不同，但每段的两个端点像素中，恰好有一个端点的颜色被替换为另一种特殊颜色（非该线段主色、非背景色），这个特殊颜色端点与另一段上的同色特殊端点形成配对——表示这两段应在此处对接。
- 网格中还有若干用 Maroon 色绘制的单像素标记点，每个标记点恰好紧邻（4-连通）某条线段的非端点位置。

Rule:
- 第一步（拼接路径）：通过特殊端点颜色匹配规则，将所有线段首尾相接拼成一条不分叉的连续折线路径。具体地，线段 A 的特殊端点颜色若与线段 B 的特殊端点颜色相同，则 A 和 B 在该端对接：将 B 平移使其特殊端点与 A 的特殊端点相邻（沿 A 在该端的延伸方向放置），对接完成后两个特殊端点像素颜色统一变为所连线段的主色。
- 第二步（生长分支）：对每个 Maroon 标记点，确定它紧邻的是拼接后路径的哪个像素，以及标记点相对于该路径像素的方向（上、下、左或右）。从标记点位置开始，沿该方向延伸一条与标记点所邻路径段同色的射线，长度等于该标记点所邻的那一段路径段的像素数量。射线不覆盖已有路径像素，若碰到网格边界则截断。
- Maroon 标记点本身在输出中被擦除（变为背景色）。

Key insight: 第一层推理要求解题者发现特殊端点颜色匹配是拼接依据，理解如何通过平移将散落的线段组装成连续路径；第二层推理要求发现 Maroon 标记点的作用是指示分支生长的位置和方向，且分支长度由所邻路径段的长度编码。两层机制结合产生了从碎片重建到局部生长的复合变换。
