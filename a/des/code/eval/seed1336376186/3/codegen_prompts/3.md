- `Input structure`：
  - 背景为 black。网格中有若干由 grey 像素构成的小型十字形节点（5 个像素：中心 + 上下左右各 1 像素），节点之间由 grey 像素构成的单像素宽直线段相连，形成一个树状网络。
  - 网络的某些节点中心像素被替换为一个彩色像素（如 red、blue 等），称为"种子节点"。
  - 网络中每条连接线段上恰好有一个像素被替换为 yellow，称为"变色器"。
  - 网络的若干叶节点（度为 1 的节点）旁边紧邻一个由 black 包围的小型封闭矩形区域（边框为 grey，内部为 black）。

- `Rule`：
  - 第一层推理——颜色传播规则：从每个种子节点出发，颜色沿网络边传播到相邻节点。每当颜色信号经过一条边上的 yellow "变色器"时，颜色按固定顺序循环切换：Red → Blue → Green → Yellow → Red → ...（该顺序需从样例中归纳）。
  - 第二层推理——填充目标：当颜色传播到达一个叶节点时，将该叶节点旁边的封闭矩形区域内部填充为传播到达时的当前颜色。
  - 若一个节点从多个种子接收到不同颜色，则取该节点所有入边中路径最短（经过边数最少）的那个种子传来的颜色。
  - 网络结构（grey 线条和节点）保持不变，仅填充叶节点旁的矩形区域。

- `Key insight`：解题者首先需要识别出树状网络拓扑和"变色器"的存在，然后归纳出颜色循环切换的固定顺序，最后追踪每条路径上颜色经过多少个变色器来推算终点颜色——这是一个三层结构的推理链。
