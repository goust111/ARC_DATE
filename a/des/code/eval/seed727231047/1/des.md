- `description`：根据封闭区域内部的色块数量，从色谱条中选取对应颜色，对该区域的边框进行重新着色。

- `Input structure`：
  - 背景为黑色。
  - 网格中有若干用灰色线段围成的封闭矩形区域（边框为灰色，宽度为1像素）。
  - 每个封闭矩形内部散布着若干单像素色块（颜色不一，但同一区域内所有色块颜色相同）。
  - 网格底部有一条水平的"色谱条"，由从左到右排列的不同颜色方块组成（例如从左到右依次为 Red、Green、Blue、Yellow、Magenta），每个方块宽1像素、高1像素，彼此紧邻。色谱条与上方的封闭区域之间用一行灰色分隔线隔开。

- `Rule`：
  - 对每个灰色封闭矩形，数出其内部包含的单像素色块数量 N（N 的范围为 1 到色谱条长度）。
  - 在色谱条中，从左到右第 N 个方块的颜色即为该矩形边框的新颜色。
  - 将该矩形的灰色边框全部替换为该新颜色。
  - 矩形内部的色块保持不变；色谱条本身保持不变。

- `Key insight`：解题需要两层推理——第一层是识别出每个封闭区域内的色块数量是一个索引值，第二层是发现底部色谱条是一张查找表，索引值指向色谱条中的位置以决定边框颜色。区域内色块自身的颜色是干扰项，真正起作用的是数量。
</new_puzzle>

- `description`：将散落的形状碎片按颜色配对，然后将每对碎片拼合成一个完整的矩形，输出所有拼合后的矩形。

- `Input structure`：
  - 背景为黑色。
  - 网格中散布着若干不规则的多联骨牌形状（polyomino），每种颜色恰好出现两个形状。
  - 同色的两个形状可以互补拼合成一个实心矩形（无旋转、无翻转，仅需平移对齐）。
  - 不同颜色的形状之间不重叠、不相邻。

- `Rule`：
  - 将同颜色的两个形状识别为一对。
  - 对于每一对，确定它们拼合后形成的最小外接矩形尺寸（宽 W、高 H）。将其中一个形状视为模板，另一个形状恰好填充模板在该 W×H 矩形中的空缺部分。
  - 输出网格中，将每对碎片合并为一个完整的实心矩形，矩形使用该对的颜色填充。
  - 各矩形在输出中从上到下依次排列，左对齐，矩形之间留一行黑色间隔。排列顺序按原始输入中该颜色碎片最上方像素的行号从小到大排序。

- `Key insight`：解题的核心在于识别同色碎片的互补关系——两块碎片并非任意形状，而是同一矩形的互补切割。解题者需要先通过颜色配对，再通过空间互补验证拼合方式，最后按特定规则排列输出。这要求同时进行颜色分组和空间推理两层操作。
</new_puzzle>

- `description`：在网格中，箭头形状指示传播方向，将箭头尾部的图案沿箭头方向复制到箭头前方，且复制次数由箭头的长度决定。

- `Input structure`：
  - 背景为黑色。
  - 网格中包含若干"箭头"和若干"图案块"。
  - 每个箭头由一种颜色绘制，形状为：一条水平或垂直的直线段（箭杆，长度 L 像素），加上末端的一个三角箭头尖（由3个像素组成的"V"形，指向上/下/左/右之一）。具体地：若箭头朝右，则箭杆为水平线段，箭杆右端上方一格和下方一格各有一个同色像素，与箭杆右端像素共同构成向右的三角尖。其他方向类推。
  - 每个箭头的尾端（与箭头尖相反的一端）紧邻一个小型矩形图案块（由多种颜色像素组成，尺寸不超过 4×4）。图案块与箭头尾端之间间隔恰好1个像素。
  - 箭头的颜色与其对应图案块中的任何颜色都不同。

- `Rule`：
  - 对每个箭头，确定其指向方向和箭杆长度 L（不含箭头尖的3个像素）。
  - 从箭头尖端开始，沿箭头指向方向，以图案块自身尺寸为步长，连续复制图案块 L 次。
  - 每次复制时，图案块的朝向保持不变。相邻两个复制之间紧密排列，无间隔。
  - 复制完成后，原始箭头（箭杆和箭头尖）从网格中移除（变为黑色背景），原始图案块保留在原位。

- `Key insight`：箭头同时编码了两个信息——方向和数量。解题者首先需要识别箭头的几何结构以确定传播方向，然后需要发现箭杆的像素长度等于图案的复制次数，而非仅仅是"沿方向填满"。箭头本身在输出中消失这一点也需要从样例中归纳。
</new_puzzle>

- `description`：根据连接线的路径将分散的色块重新排列到目标框架中，连接线的转弯方式决定色块在框架中的旋转角度。

- `Input structure`：
  - 背景为黑色。
  - 网格中有一个灰色边框的空矩形框架（内部为黑色），框架被灰色内部分隔线划分为若干等大的子格（例如 2×3 的子格阵列，每个子格为 3×3）。
  - 框架外部散布着若干小型彩色图案（每个图案为一个与子格同尺寸的多色像素块）。
  - 每个彩色图案通过一条单像素宽的Azure色折线连接到框架边缘的某个入口点。每条折线仅做直角转弯（水平或垂直），且不同折线之间不交叉。
  - 每条折线从图案的某一边出发，经过若干次直角转弯后到达框架边缘上某个子格对应的入口位置。

- `Rule`：
  - 每个图案沿其连接线被"传送"到框架中对应的子格位置。
  - 图案到达子格后需要旋转：连接线从图案出发到到达框架入口，沿途每经过一次向左转弯（相对于行进方向的逆时针90度转），图案顺时针旋转90度一次；每经过一次向右转弯（顺时针90度转），图案逆时针旋转90度一次。
  - 若连接线无转弯（直线连接），图案保持原始朝向不变。
  - 多次旋转累加（例如两次左转等于顺时针旋转180度）。
  - 输出为填满图案的框架，连接线和框架外的原始图案在输出中移除。

- `Key insight`：解题包含三层推理：第一层是识别连接线将图案映射到框架中的哪个子格（空间对应关系）；第二层是发现转弯方向与旋转的对应规则（左转弯导致顺时针旋转，右转弯导致逆时针旋转）；第三层是累加多次转弯带来的旋转效果。连接线不仅是路径指示器，更是旋转指令的编码器。
</new_puzzle>

- `description`：识别网格中被"围墙"包围的房间，根据房间的出口方向选择对应的填充图案，用该图案铺满房间内部。

- `Input structure`：
  - 背景为 Azure。
  - 网格中有若干由 Maroon 像素构成的单像素宽"围墙"线段，围墙彼此连接形成若干封闭的矩形"房间"。
  - 每个房间的围墙上恰好有一个缺口（宽度为1像素），缺口位于房间的上、下、左、右四面墙之一上。
  - 网格的四个角落各放置一个小型参考图案（不超过 3×3），分别位于左上角、右上角、左下角、右下角。每个参考图案由不同颜色像素组成，且四个参考图案彼此不同。
  - 四个角落的参考图案分别对应四个方向：左上角 = 缺口朝上，右上角 = 缺口朝右，左下角 = 缺口朝左，右下角 = 缺口朝下。

- `Rule`：
  - 对每个房间，确定其围墙缺口所在的方向（上/下/左/右）。
  - 根据缺口方向，从对应角落选取参考图案。
  - 将该参考图案以平铺（tile）方式重复填充整个房间内部（不含围墙本身）。平铺从房间内部左上角开始，向右和向下重复，超出房间部分裁剪。
  - 缺口处保持为背景色（Azure），不被图案覆盖。

- `Key insight`：解题的第一层推理是发现每个房间有唯一的缺口，且缺口方向是关键属性；第二层是建立四个角落参考图案与四个方向之间的映射关系（角落位置编码方向：左上对应上，右上对应右，左下对应左，右下对应下）；第三层是将选中的图案以平铺方式填入房间。角落图案的位置-方向映射并非显而易见，需要从多个样例中交叉比对才能确认。
</new_puzzle>

- `description`：在网格中，每个彩色对象根据其所接触的边界颜色进行分裂，分裂方向和份数由边界标记决定。

- `Input structure`：
  - 背景为黑色。
  - 网格被若干单像素宽的彩色水平线和垂直线划分为多个矩形区域。水平线和垂直线各自使用统一的颜色（例如水平线为 Red，垂直线为 Green），两种线颜色不同。
  - 每个矩形区域内部包含一个由某种颜色（非黑色、非线条颜色）填充的实心矩形对象，对象不接触区域边界（与边界之间至少有1像素黑色间距）。
  - 某些水平分隔线上带有等间距的 Yellow 标记像素（位于线段上，替代原来的线条颜色），标记的数量为 K（K >= 2）。
  - 某些垂直分隔线上带有等间距的 Orange 标记像素，标记的数量为 M（M >= 2）。

- `Rule`：
  - 对每个矩形区域中的对象，检查该区域的四条边界线：
    - 若对象上方或下方的水平边界线上有 K 个 Yellow 标记，则将对象沿水平方向等分为 K 份（垂直切割），各份之间留1像素黑色间隔。
    - 若对象左侧或右侧的垂直边界线上有 M 个 Orange 标记，则将对象沿垂直方向等分为 M 份（水平切割），各份之间留1像素黑色间隔。
    - 若同时有水平和垂直标记，则先垂直切割再水平切割（结果为 K×M 个子块）。
    - 若某条边界线无标记，则该方向不切割。
  - 切割后的子块保持在原区域内，整体居中放置。
  - 边界线和标记像素保持不变。

- `Key insight`：解题者需要先识别出网格的分区结构（水平线和垂直线构成网格），然后发现边界线上的彩色标记像素不是装饰而是控制信号，最后归纳出标记数量等于切割份数的规则。关键难点在于发现标记像素的数量（而非位置）才是决定切割方式的参数，且水平标记控制垂直方向的效果（切割方向与标记方向垂直）。
</new_puzzle>

<new_puzzle>
- `description`：将网格中的"种子"像素沿其所在对象的轮廓生长出与轮廓等长的彩色轨迹，生长方向由种子在对象上的位置决定。

- `Input structure`：
  - 背景为黑色。
  - 网格中有若干灰色的封闭形状（由灰色像素构成的实心多联骨牌，每个形状为4-连通的连通分量）。
  - 每个灰色形状的轮廓上（即与黑色背景相邻的灰色像素上）恰好有一个像素被替换为某种非灰色、非黑色的彩色像素（称为"种子"）。不同形状的种子颜色可以不同。
  - 种子像素位于形状轮廓的某个位置。

- `Rule`：
  - 对每个形状，提取其轮廓像素序列（按顺时针方向排列，从种子位置开始）。
  - 从种子位置出发，沿轮廓顺时针方向行走。行走过程中，将经过的每个轮廓像素（原本为灰色）替换为种子的颜色。
  - 行走的步数等于该形状轮廓的总长度的一半（向下取整）。即恰好将轮廓的一半染为种子颜色，另一半保持灰色。
  - 形状内部（非轮廓的灰色像素）保持不变。
  - 种子像素本身也算已被染色的一步。

- `Key insight`：解题的第一层推理是发现种子像素是轮廓染色的起点；第二层是归纳出染色沿顺时针方向进行（需要从多个样例中对比确认方向）；第三层是发现染色长度恰好是轮廓周长的一半，而非其他比例。三层信息都需要从样例中主动归纳，缺一不可。
</new_puzzle>
