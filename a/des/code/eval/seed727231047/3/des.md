- `description`：根据封闭区域内部"种子"像素的颜色，在配色图例中查找对应的填充图案，然后将该图案平铺填满整个封闭区域。

- `Input structure`：
  - 背景色为黑色（black）。
  - 网格中有若干由灰色（grey）像素围成的不规则封闭区域，每个区域内部恰好有一个非黑色、非灰色的"种子"像素（如 red、blue、green 等）。
  - 网格的一侧（例如最底部几行）有一个配色图例区域，由灰色边框框出若干小格子。每个小格子左上角有一个颜色标记像素，格子内部其余位置用两种颜色绘制了一个 2×2 或 3×3 的小型平铺图案（如棋盘格、条纹、L形等），图案的前景色与标记像素相同，背景为黑色。

- `Rule`：
  - 识别所有灰色围成的封闭区域及其内部的种子像素颜色 C。
  - 在图例中找到标记颜色为 C 的格子，提取其中的平铺图案 P。
  - 将图案 P 以周期平铺的方式填满对应封闭区域的全部内部黑色像素（种子像素本身被图案覆盖）。平铺的相位以封闭区域边界框左上角为原点对齐。
  - 图例区域在输出中保持不变。灰色边界保持不变。

- `Key insight`：种子像素不是直接决定填充颜色，而是作为索引去图例中查找一个空间图案；解题者需要先建立"种子颜色→图例图案"的映射，再理解图案是以区域边界框左上角为锚点进行周期平铺的。

- `description`：将散落的彩色碎片按形状匹配嵌入模板中对应的镂空槽位，但每个碎片需要先根据槽位边框上的方向标记进行旋转。

- `Input structure`：
  - 背景色为黑色（black）。
  - 网格中央有一个由 azure 色像素构成的大型模板形状，模板内部有若干镂空的黑色槽位（形状各异，如 L 形、T 形、直线等）。
  - 每个槽位的外侧边框上恰好有一个 red 像素标记，位于槽位的上、下、左、右四侧之一。
  - 模板外部散布着若干彩色碎片（每个碎片颜色各异，如 green、yellow、magenta 等），每个碎片的形状与某个槽位匹配（可能需要旋转 0°、90°、180° 或 270° 后才能吻合）。
  - 每个碎片上也有一个 red 像素标记，位于碎片的上、下、左、右四侧之一。

- `Rule`：
  - 对每个碎片，找到与其形状匹配的槽位（在某个旋转角度下形状完全吻合）。
  - 确定旋转角度的方法：旋转碎片使碎片上的 red 标记所在方位与槽位上的 red 标记所在方位一致（例如碎片标记在右侧、槽位标记也在右侧时，旋转角度为 0°）。
  - 将旋转后的碎片放入对应槽位，碎片像素替换槽位中的黑色像素。
  - 所有 red 标记像素在输出中被移除（恢复为原本的 azure 色或黑色背景）。

- `Key insight`：解题有两层推理——第一层是通过形状匹配确定碎片与槽位的对应关系，第二层是通过比较碎片和槽位上 red 标记的方位来确定精确的旋转角度。仅靠形状匹配可能存在多种旋转方案，red 标记消除了歧义。
</new_puzzle>

- `description`：沿着彩色管道网络传播信号，信号在每个交叉节点处根据节点内部的"开关"像素决定转向，最终在管道末端生成对应长度的输出标记。

- `Input structure`：
  - 背景色为黑色（black）。
  - 网格中有由 grey 像素构成的一格宽管道网络，管道沿水平或垂直方向延伸，在某些位置形成十字交叉节点（即四个方向都有管道延伸的交叉点）。
  - 每个十字交叉节点的中心像素不是 grey，而是 red 或 blue——red 表示信号到达时向右转（相对于信号来向顺时针 90°），blue 表示信号到达时向左转（逆时针 90°）。
  - 管道网络有若干末端（死胡同），其中恰好一个末端标记有一个 green 像素（信号起点），该 green 像素位于管道末端的最外侧一格。
  - 其余末端没有特殊标记。

- `Rule`：
  - 信号从 green 像素出发，沿管道唯一可行的方向前进（因为起点是末端，只有一个方向可走）。
  - 信号沿 grey 管道直线传播，遇到十字交叉节点时读取节点中心的颜色：red 则顺时针转 90°，blue 则逆时针转 90°。
  - 信号经过的每个 grey 像素被重新着色为 yellow，记录信号路径。
  - 信号最终到达某个管道末端停止。统计信号经过的交叉节点总数 N。
  - 在信号终点末端，沿管道向外延伸方向绘制 N 个 orange 像素（紧接在末端之后向外）。
  - 未被信号经过的管道像素保持 grey 不变。

- `Key insight`：解题者需要先理解交叉节点颜色编码的转向规则来追踪信号路径，然后发现输出末端的 orange 标记长度等于路径上经过的交叉节点数量。两层规则——转向逻辑和计数-到-长度映射——需要分别归纳。
</new_puzzle>

- `description`：在网格中识别由不同颜色线段围成的多边形区域，根据每个区域边界上各颜色线段的长度排序来确定该区域的填充颜色，再利用图例确定嵌套区域的填充顺序。

- `Input structure`：
  - 背景色为黑色（black）。
  - 网格中有若干彩色像素构成的一格宽线段（水平或垂直），这些线段首尾相连围成若干封闭的多边形区域。
  - 每个多边形的边界由多段不同颜色的线段组成（例如一个矩形区域的四条边可能分别是 red、blue、green、yellow）。
  - 网格底部有一行"优先级图例"：从左到右排列着若干颜色色块（每个色块为 1×1 像素），色块之间用黑色间隔，顺序表示填充优先级（最左 = 最先填充，即最外层）。

- `Rule`：
  - 对每个封闭区域，统计其边界上每种颜色线段占据的像素数量。
  - 找出该区域边界上像素数量最多的颜色——该颜色即为这个区域的填充色。
  - 用该颜色填满区域内部所有黑色像素。
  - 若某个区域被另一个已填充的区域完全包围（嵌套），填充顺序按照图例的优先级从左到右执行——先填外层再填内层，内层颜色覆盖外层。
  - 边界线段本身保持原色不变。

- `Key insight`：第一层推理是发现填充色由边界上最长（像素最多）的颜色线段决定，而非由任意属性决定。第二层推理是理解图例中颜色的排列顺序决定了嵌套区域的填充执行顺序——先填充图例中靠左的颜色对应的区域，后填充靠右的，从而正确处理嵌套覆盖关系。
</new_puzzle>

- `Input structure`：
  - 背景色为黑色（black）。
  - 网格中有若干由 grey 像素围成的矩形"房间"，彼此不重叠。每个房间的一面墙上有一个缺口（连续缺失若干 grey 像素），缺口形成一个不规则的凹形轮廓——这是"锁孔"。
  - 每个房间内部全部为黑色（空白）。
  - 网格中散布着若干小型彩色图形，每个图形由单一颜色（如 red、blue、green、yellow 等）的像素组成——这些是"钥匙"。
  - 每把钥匙的形状恰好能完美填入某个锁孔的缺口（像拼图一样吻合），但钥匙可能需要旋转 0°/90°/180°/270° 才能匹配。

- `Rule`：
  - 对每把钥匙，找到其形状（在某个旋转下）与某个房间锁孔缺口完全吻合的房间。
  - 将钥匙旋转到正确角度后"插入"锁孔，填补墙壁缺口（钥匙像素替换缺口处的黑色像素）。

  - 未被任何钥匙匹配的房间保持原样（内部仍为黑色）。
  - 钥匙的原始位置变为黑色背景。

- `Key insight`：解题者首先需要发现墙壁缺口的凹形轮廓就是"锁孔"，然后通过形状匹配（含旋转）将钥匙与锁孔配对——这是第一层推理。第二层推理是理解匹配成功后钥匙颜色不仅填补缺口，还会"扩散"填满整个房间内部。两层规则在视觉上表现为"钥匙决定房间颜色"。

- `description`：网格中的彩色"灯塔"向四个方向发射光线，光线颜色在穿过"棱镜"像素时发生变换，最终光线照亮的区域决定了输出中各单元格的颜色。

- `Input structure`：
  - 背景色为黑色（black）。
  - 网格中有若干 2×2 的彩色正方形块，每个块由单一颜色组成（如 red、blue、green 等）——这些是"灯塔"。
  - 网格中散布着单个 grey 像素——这些是"棱镜"。
  - 网格的一个角落有一个小型"变色图例"：若干行，每行包含两个相邻的彩色像素（左侧为输入色，右侧为输出色），表示光线颜色穿过棱镜后的变换规则。

- `Rule`：
  - 每个灯塔从其四条边的中心位置（上边中心、下边中心、左边中心、右边中心）各发射一条光线，光线沿对应方向直线传播。
  - 光线将途经的黑色像素染为灯塔的颜色，遇到非黑色像素（另一个灯塔或已被染色的像素）时停止。
  - 但如果光线途中遇到 grey 棱镜像素，光线不停止——棱镜像素本身变为光线当前颜色，光线穿过后颜色按照变色图例进行变换，然后继续传播。
  - 若两条不同颜色的光线到达同一个像素，该像素颜色取变色图例中排列更靠后（行号更大）的那个颜色。
  - 灯塔本身保持原色不变。

- `Key insight`：解题者需要先理解灯塔发射光线的基本规则，然后发现棱镜不阻挡光线而是改变光线颜色——这需要从变色图例中归纳变换映射。两条光线交叠时的优先级规则（图例行号靠后者胜出）是额外需要从样例中发现的第三层规则。
</new_puzzle>

<new_puzzle>
- `description`：识别网格中散落的多个小图形，按各图形的朝向将它们分组，然后将同组图形合并堆叠到该组对应的"收集框"中。

- `Input structure`：
  - 背景色为黑色（black）。
  - 网格四个角落各有一个由 grey 像素绘制的小型空心正方形框（大小相同，例如 5×5），框内部为黑色。每个框的外侧恰好有一个 maroon 像素，分别位于框的上方、下方、左方、右方——标示该框对应的方向。
  - 网格中央区域散布着若干小型彩色图形（如三角形、箭头等不对称形状），每个图形由同一种非黑色、非灰色颜色的像素组成，形状相同但朝向不同（朝上、朝下、朝左、朝右四种之一）。
  - 每个图形的朝向由其不对称特征决定——例如一个 3 像素的 L 形，开口朝向即为该图形的朝向。

- `Rule`：
  - 确定每个小图形的朝向（上、下、左、右）。
  - 将朝向相同的图形归为一组，对应到 maroon 标记在该方向上的收集框。
  - 将同组的所有图形依次叠放到收集框内部：第一个图形放在框内靠近 maroon 标记那一侧，后续图形紧邻前一个图形向框内部堆叠，图形之间不留间隙。
  - 图形放入框中时保持其原始颜色，但朝向统一旋转为"朝向框内部"（即朝向 maroon 标记的反方向）。
  - 若框内空间不足以容纳所有图形，框沿堆叠方向自动扩展。

- `Key insight`：解题需要三层推理——第一层是识别每个图形的朝向，第二层是通过 maroon 标记建立"方向→收集框"的映射，第三层是理解图形放入框时需要旋转到统一朝向并按序堆叠。仅理解分组规则不够，还必须发现入框时的旋转规范。
</new_puzzle>
