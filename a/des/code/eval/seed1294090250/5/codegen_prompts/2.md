- 通过颜色将每个碎片与对应框架配对。
- 旋转碎片，使得碎片上 red 标记点相对于碎片的方位与框架上 red 标记点相对于框架的方位一致（例如框架标记在顶边，则碎片标记也旋转到顶边）。

Key insight: 颜色匹配只是第一步；关键的第二层推理是发现 red 标记点在碎片和框架上的相对位置编码了旋转角度——解题者需要归纳出"标记点朝向必须对齐"这一非显然规则。
