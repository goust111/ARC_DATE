Input structure:
- bg = black。网格中散布着若干成对出现的小型填充图形（如 3×3 或 4×4 的矩形、十字形等）。
- 每对图形形状完全相同，但颜色不同：一个是"源"（颜色为 red、blue、green 等鲜艳色），另一个是"目标"（统一为 grey 色）。
- 每对源与目标之间由一条 maroon 色的单像素宽路径相连，路径沿正交方向行进，遇墙或边界时转弯。路径不分叉、不交叉。

Rule:
- 将每个 grey 目标图形与通过路径相连的源图形配对。
- 计算连接路径的转弯次数 T（直线段之间的 90° 转角数）。
- 对目标图形进行 T 层同心收缩着色：最外层像素染成源图形的颜色，次外层染成背景色，再次外层染成源的颜色……交替进行，共处理 T 层。若图形太小不足 T 层，则有多少层染多少层。

- 源图形保持原样不变。

Key insight:
