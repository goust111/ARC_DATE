<description>
根据嵌套框架的层级深度，从调色板中选取对应颜色填充每个框架的边框。

Input structure:
- 背景为黑色。网格中散布着若干由灰色像素绘制的矩形框架（单像素宽边框，内部为黑色背景）。
- 框架之间存在嵌套关系：有的框架完全包含在另一个框架内部，形成多层嵌套结构（最多四层）。
- 网格的一条边缘（例如底部一行）放置着一个水平调色板条：从左到右依次排列若干不同颜色的色块（每个色块为 1x1 像素），色块之间没有间隔。

Rule:
- 计算每个灰色框架的嵌套深度：最外层（不被任何其他框架包含的）深度为 1，被一个框架包含的深度为 2，以此类推。
- 调色板条从左到右第 k 个颜色对应深度 k。
- 将每个灰色框架的所有边框像素重新着色为其嵌套深度对应的调色板颜色。
- 调色板条本身在输出中保持不变。

Key insight: 解题者必须先识别框架之间的包含（嵌套）关系并确定每个框架的深度层级，然后再将调色板的位置顺序映射到深度值——两步推理缺一不可。嵌套深度不是直接标注在网格上的，需要通过空间包含关系推断。
</description>

<description>
将网格中分散的碎片拼入由边框颜色标识的目标容器中，拼入位置由碎片内部的锚点标记决定。

Input structure:
- 背景为黑色。网格上有若干矩形"容器"：每个容器由单像素宽的彩色边框围成，内部填充黑色，边框颜色各不相同。每个容器内部恰好有一个与边框同色的单像素"锚点"。
- 容器外部散布着若干小型彩色"碎片"（由多个像素组成的 4-连通区域）。每个碎片内部恰好包含一个特殊像素，该像素的颜色与某个容器的边框颜色相同，碎片的其余像素为另一种统一颜色。

Rule:
- 通过碎片内部特殊像素的颜色，将碎片与对应边框颜色的容器配对。
- 将碎片平移放入容器内部，使碎片中的特殊像素恰好落在容器内部的锚点位置上。
- 碎片的其余像素按照相对位移一并绘制到容器内部（碎片保持原始朝向，不旋转不翻转）。
- 输出网格仅包含所有容器（含已拼入的碎片），容器外部区域全部填充为黑色。碎片原来在容器外的位置被清除。

Key insight: 解题者需要先通过颜色匹配建立碎片-容器配对关系，再利用碎片内嵌的特殊像素与容器内锚点的对齐关系确定精确放置位置——配对和定位是两个独立的推理层。
</description>

<description>
根据种子像素的颜色查找图例中对应的生长模板，然后以种子为起点按模板方向生长出图案，遇墙停止。

Input structure:
- 背景为黑色。网格分为两个区域，由一条完整的灰色分隔线（水平或垂直）隔开。
- 区域一（图例区）：包含若干"生长模板"。每个模板由一个彩色中心像素和从中心向外延伸的若干条同色射线组成（射线沿上下左右四个正方向，每条射线长度相同，为 1-3 个像素）。不同模板的中心颜色各不相同，射线方向组合也不同（例如一个模板可能只有向上和向右的射线，另一个可能有向左、向下、向右三条射线）。
- 区域二（工作区）：散布着若干"种子像素"，每个种子像素的颜色与图例区中某个模板的中心颜色相同。工作区中还有若干灰色的"墙壁"像素块（不规则形状）。

Rule:
- 对工作区中的每个种子像素，在图例区中找到中心颜色与之匹配的生长模板。
- 从种子像素出发，按照模板指示的方向生长射线：在每个指示方向上，从种子位置开始逐格向外扩展同色像素，直到碰到墙壁像素、网格边界、或已有的非背景像素为止（碰到后停止，不覆盖障碍物）。
- 输出为工作区部分，包含所有墙壁和生长后的图案，图例区不出现在输出中。

Key insight: 解题者需要先从图例区解读每个模板编码了哪些生长方向（这需要观察模板的形状结构），然后在工作区中按方向生长并处理障碍物阻断——模板解读和受阻生长是两个需要分别归纳的规则层。
</description>

<description>
根据每个封闭区域内部标记像素的数量，从区域边框上移除对应数量的像素来"开门"。

Input structure:
- 背景为黑色。网格中有若干由彩色像素围成的封闭矩形区域（边框为单像素宽的实心矩形环，各区域边框颜色不同）。
- 每个矩形区域内部散布着若干红色标记像素（位于区域内部的黑色背景上）。
- 每个矩形区域的某一条边上有一个特殊的"门标记"：该边的正中央一个像素被涂为绿色（而非该区域的边框颜色）。

Rule:
- 数出每个封闭区域内部红色标记像素的数量 N。
- 找到该区域边框上的绿色门标记像素，确定其所在的边。
- 以绿色门标记为中心，在该边上移除（变为黑色）连续 N 个边框像素（包含绿色像素本身），形成一个宽度为 N 的缺口（"门"）。如果 N 为偶数，则绿色像素位于缺口偏左（或偏上）的位置，即绿色像素左侧（或上侧）移除 N/2-1 个，右侧（或下侧）移除 N/2 个。
- 移除区域内部所有红色标记像素（变为黑色）。
- 绿色门标记像素本身也被移除（作为缺口的一部分）。

Key insight: 解题者必须先发现内部红色像素的数量与门宽度之间的对应关系（而非与其他属性如区域大小的关系），再理解绿色像素标定了开门的位置和中心——计数到几何变换的映射是核心推理难点。
</description>

<description>
将散落的彩色路径段按颜色连接成完整回路，并用路径所围区域的面积大小决定填充色。

Input structure:
- 背景为黑色。网格中散布着若干彩色像素段（每段是同一颜色的 2-4 个像素组成的水平或垂直直线段）。
- 同一颜色的线段恰好有偶数个端点（即线段末端处沿延伸方向相邻格为黑色的那些点），且同色线段可被连接成恰好一个封闭回路。
- 网格底部有一个小型图例区：水平排列着若干彩色方块（每个为 2x2 像素），按从左到右的顺序排列，颜色各不相同，方块之间间隔一列黑色像素。

Rule:
- 对每种颜色，找到该颜色所有线段的开放端点。
- 将同色的开放端点两两配对：选择使所有连线均为正交折线（仅包含水平和垂直段，最多一次转弯）且互不交叉的唯一配对方案。
- 用该颜色绘制连线段，将碎片连接成封闭回路。
- 连接完成后，每种颜色的回路围成一个封闭区域。数出所有回路围成区域的内部黑色像素数（面积），并按面积从小到大排序。
- 底部图例区的颜色方块从左到右分别对应面积从小到大的回路。将每个回路围成的内部区域填充为图例中对应位置的颜色。
- 输出中移除底部图例区。

Key insight: 解题者面临三层推理：（1）识别同色线段并补全连线形成封闭回路；（2）比较各回路围成区域的面积大小关系；（3）通过面积排序将图例颜色映射到回路内部填充色。每一层都需要独立的归纳过程。
</description>

<description>
在网格中找到"印章"和"画布"，根据画布上已有痕迹推断印章被盖印时的旋转角度，然后补全缺失的印章痕迹。

Input structure:
- 背景为黑色。网格中有一个由灰色边框围成的大矩形区域作为"画布"（内部为黑色背景）。
- 画布外部有一个小型非对称彩色图案作为"印章"（由单一非灰色颜色绘制，形状不具有旋转对称性）。
- 画布内部有若干不完整的印章痕迹：每处痕迹是印章图案在某个旋转状态（0度、90度、180度、270度）下的部分像素，使用与印章相同的颜色。每处痕迹至少保留了原始旋转图案一半以上的像素，其余像素缺失（显示为黑色背景）。
- 每处痕迹的位置互不重叠。

Rule:
- 提取画布外部的印章原始图案。
- 对画布内部每处不完整痕迹，尝试将印章在四个旋转角度（0度、90度、180度、270度）下与痕迹进行匹配：找到唯一一个旋转角度，使得痕迹中已有的所有像素都与旋转后印章图案的对应位置吻合。
- 用匹配到的旋转角度下的完整印章图案补全该处痕迹的缺失像素。
- 输出为画布内部区域（不含灰色边框），所有痕迹均已补全。

Key insight: 印章的非对称性保证了每处痕迹的旋转角度可以被唯一确定。解题者需要先识别印章形状，再对每处痕迹进行心理旋转匹配——形状提取和旋转匹配是两个需要主动推理的步骤。
</description>

<description>
根据连接线将散落的色块分组，再按组内色块的排列顺序对目标网格的行或列重新着色。

Input structure:
- 背景为黑色。网格分为左右两个区域，由一条垂直的灰色分隔线隔开。
- 左侧区域（指令区）：包含若干彩色小方块（每个为 1x1 像素），方块之间由橙色单像素宽的正交连线（水平或垂直线段）连接。通过连线相连的方块构成一个"组"。每组内的方块颜色各不相同，组与组之间的连线不交叉。每组中恰好有一个方块为蓝色。
- 右侧区域（目标区）：是一个由灰色边框围成的矩形网格，内部被灰色线条划分为均匀的单元格（类似棋盘格线）。部分单元格内填有蓝色像素，其余单元格为黑色。

Rule:
- 在左侧指令区中识别每个通过连线相连的组。
- 在每组内，找到蓝色方块的位置，以蓝色方块为起点，沿着连线的路径依次读取经过的方块颜色，形成一个有序颜色序列。
- 在右侧目标区中，每个填有蓝色的单元格对应一个组（按从上到下、从左到右的顺序与各组配对）。
- 以蓝色单元格为起点，沿该单元格所在的行向右依次填入组的颜色序列（蓝色单元格本身保持蓝色，从其右侧下一格开始填入序列中蓝色之后的颜色）。如果序列中蓝色之前还有颜色，则向左填入。
- 输出仅包含右侧目标区域。

Key insight: 解题者需要先从连线拓扑中解析出分组结构和组内的颜色遍历顺序，然后建立左侧组与右侧蓝色单元格的对应关系，最后将颜色序列映射到目标网格——分组解析、配对、序列展开构成三层递进推理。
</description>
</new_puzzle>
