<description>
根据封闭区域内标记像素的颜色，从外部色板中选取对应模板，将模板图案旋转后填入该区域。

Input structure:
- 背景为 black。网格中有若干由 grey 线条围成的不规则封闭区域（每个区域内部为 black，面积不等）。
- 每个封闭区域内部恰好有一个单独的彩色标记像素（颜色各不相同，如 red、blue、green 等）。
- 网格边缘（如最底部两行）排列着若干小型彩色模板图案（3x3 或 4x4），每个模板由单一非 black 颜色绘制在 black 底上，模板的颜色与区域内标记像素的颜色一一对应。
- 每个模板图案的形状不对称，具有明确的朝向。

Rule:
- 对每个封闭区域，找到其内部标记像素的颜色，在边缘色板中找到同色模板。
- 确定标记像素相对于区域几何中心（视觉中点）的方位（上、下、左、右四选一）：标记像素在中心偏上则为"上"，偏下则为"下"，偏左则为"左"，偏右则为"右"。
- 将模板图案按该方位旋转：上=0度，右=顺时针90度，下=180度，左=逆时针90度。
- 将旋转后的模板图案以标记像素所在位置为左上角，盖印到封闭区域内（仅绘制模板中非 black 的像素，不覆盖 grey 墙壁）。
- 移除边缘色板区域，输出仅包含填充后的封闭区域网格。

Key insight: 标记像素的颜色决定"用哪个模板"，标记像素相对于区域中心的偏移方位决定"模板旋转多少度"——两层信息编码在同一个像素中。
</description>

<description>
将散落的彩色碎片按颜色归入对应的容器框中，碎片在框内的摆放位置由容器框上缺口的位置决定。

Input structure:
- 背景为 black。网格中有若干由不同颜色绘制的矩形空心框（每个框用一种独特颜色画边框，内部为 black，大小约 6x6 至 8x8）。
- 每个框的边框上恰好有一个缺口（缺口是边框上一个被 black 替代的像素），缺口可能位于上边、下边、左边或右边。
- 网格的其他位置散落着若干小型彩色碎片（由 2-5 个连通像素组成的小图案），每个碎片的颜色与某个框的边框颜色相同。
- 每个框颜色恰好对应一个碎片（一一配对）。

Rule:
- 将每个碎片与同色的框配对。
- 根据框上缺口所在的边确定碎片进入的方向：缺口在上边，碎片从上方滑入；缺口在右边，碎片从右侧滑入；以此类推。
- 碎片沿进入方向平移，直到碎片的任一像素紧贴框内部的对面墙壁（即碎片滑到底）。碎片在垂直于滑动方向的轴上，与缺口的位置对齐（缺口所在的行或列决定碎片在该轴上的坐标）。
- 将碎片绘制在框内最终位置，擦除碎片原始位置。

Key insight: 缺口不仅标记了碎片的目标框，还同时编码了滑入方向和对齐坐标——解题者必须先识别"缺口在哪一边"来确定方向，再用"缺口在边上的具体位置"来确定横向或纵向对齐。
</description>

<description>
在网格中找到每对同色像素，连接它们形成线段，然后根据线段交叉处的叠加规则生成新颜色。

Input structure:
- 背景为 black。网格中散布着若干成对的彩色像素，每种颜色恰好出现两个像素。颜色种类包括 red、blue、green、yellow 等，共 3-5 种颜色。
- 每对同色像素在同一行或同一列上对齐（即它们之间可以画水平或垂直直线）。
- 不同颜色对的连线会产生交叉。
- 网格的某个角落（如左下角）有一个小型色板方块（如 3x3 或 4x4），色板的行和列分别用对应颜色的像素标注表头，色板内部每个格子填有一种颜色，表示对应行颜色与列颜色交叉时的混合结果。

Rule:
- 对每种颜色，在其两个像素之间画一条该颜色的水平或垂直直线（包含两端像素），线段填充所有中间 black 像素。
- 当两条不同颜色的线段在某个像素位置交叉时，该位置不使用任一线段的颜色，而是查阅角落色板，找到两种颜色对应的混合色填入。
- 输出网格中，非交叉位置保持线段原色，交叉位置使用色板查到的混合色。色板本身在输出中保留不变。

Key insight: 解题者需要先发现"成对像素连线"的基本规则，然后进一步发现角落色板是一个颜色查找表，用于解决交叉点的颜色冲突——两层规则缺一不可。
</description>

<description>
识别网格中每个封闭图形内部的"种子"像素图案，将该图案在图形边界约束下向外扩展一代，然后移除边界，仅保留扩展后的图案。

Input structure:
- 背景为 black。网格中有若干由 grey 像素绘制的封闭图形轮廓（轮廓宽度为 1 像素，形状为不规则多边形，每个图形大小约 7x7 至 12x12）。
- 每个封闭图形的内部包含一个由某种非 black、非 grey 颜色绘制的小型"种子"图案（约 2x3 或 3x3 像素的连通区域），其余内部为 black。
- 每个图形的种子颜色可能不同。

Rule:
- 对每个封闭图形，提取其内部的种子图案。
- 以种子图案为起点，执行一次"生长"：种子中每个彩色像素向四个正方向（上下左右）各扩展一格，但扩展不能越过 grey 轮廓边界，也不能覆盖已有的彩色像素。新扩展的像素使用与种子相同的颜色。
- 生长完成后，移除所有 grey 轮廓像素（替换为 black）。
- 输出仅保留生长后的彩色图案和 black 背景。

Key insight: 解题者首先需要理解 grey 轮廓是生长的边界约束而非输出的一部分，然后发现种子图案的形状经过受限扩展后产生的最终形态——轮廓的不规则形状使每个图形的生长结果不同，迫使解题者真正理解"受边界约束的扩展"机制而非简单的膨胀。
</description>

<description>
根据网格中箭头指示的方向和路径上遇到的色块序列，对目标区域进行逐层同心环着色。

Input structure:
- 背景为 black。网格中有若干由 grey 像素绘制的箭头（每个箭头由一条 3 像素长的直线杆加上一个 3 像素的 V 形箭头尖组成：若箭头朝右，则杆为水平 3 像素，右端上下各加一个 grey 像素构成">"形尖端；其他方向类推。整体约占 3x5 或 5x3 的区域）。
- 每个箭头的杆的起始端（非箭头尖的一端）紧邻一个彩色像素序列：沿箭头反方向排列的 2-4 个不同颜色的单像素点，依次排开，间距为 1 格。
- 网格中还有若干矩形空心框（由 maroon 绘制边框，内部为 black，大小约 5x5 至 9x9）。每个箭头指向恰好一个矩形框（箭头尖沿指向方向延伸可到达该框）。

Rule:
- 对每个箭头，读取其尾部的彩色像素序列（从离箭头杆最近的像素开始，依次向外读取），得到一个有序颜色列表，如 [red, blue, green]。
- 确定箭头指向的矩形框。
- 从矩形框的内部边界开始，向内逐层填充同心矩形环：第一层（最外圈）用颜色列表的第一个颜色，第二层用第二个颜色，以此类推。如果层数超过颜色列表长度，则循环使用列表。
- 擦除箭头和彩色像素序列，仅保留填充后的矩形框和 maroon 边框。

Key insight: 解题者需要完成三层推理——首先识别 grey 像素构成的箭头形状和方向，然后发现箭头尾部的像素序列是颜色指令，最后理解这些颜色按从外到内的同心环顺序填入箭头所指的目标框。箭头同时编码了"指向哪个框"和"颜色读取方向"。
</description>

<description>
将网格中的彩色路径按交叉点拆分为片段，然后根据片段长度从色阶图例中查找对应颜色进行重新着色。

Input structure:
- 背景为 black。网格中有若干由不同颜色绘制的单像素宽路径（每条路径是一系列四连通的同色像素，路径不分叉，两端为自由端点）。
- 不同颜色的路径之间存在交叉：交叉点是某个像素位置同时被两条路径经过，该像素在输入中显示为 orange（交叉标记色）。
- 网格某一侧（如最右列）有一个纵向排列的色阶图例：从上到下排列若干颜色块（如 red、blue、green、yellow），每个颜色块为 1x1 像素，相邻块之间间隔 1 行 black。

Rule:
- 将每条路径在所有 orange 交叉点处断开，形成若干片段。每个片段是交叉点之间（或交叉点到端点之间）的一段连通像素。交叉点像素本身不属于任何片段。
- 统计每个片段的像素数量（长度）。
- 对所有片段按长度从短到长排序。
- 从色阶图例中按从上到下的顺序取颜色，依次分配给排序后的片段：最短的片段重新着色为图例第一个颜色，次短的用第二个颜色，以此类推。长度相同的片段获得相同颜色。
- 交叉点像素保持 orange 不变。擦除色阶图例。

Key insight: 解题者需要先理解 orange 像素是交叉标记并据此拆分路径，然后发现片段长度与色阶图例之间的排序映射关系——拆分规则和重着色规则是两个独立的非显然推理步骤。
</description>

<description>
通过比较多个瓦片副本之间的差异，用多数投票还原出真实图案，并在每个瓦片上高亮标出其与真实图案不同的位置。

Input structure:
- 背景为 black。网格被 azure 色的分隔线均匀划分为 MxN 个大小相同的矩形瓦片（每个瓦片约 4x4 至 6x6）。
- 每个瓦片内部包含由 red 像素绘制的图案（图案占据瓦片内部分位置，其余为 black）。
- 所有瓦片的 red 图案几乎相同，但每个瓦片有 0-2 个像素位置与"真实图案"不同（多了或少了一个 red 像素）。

Rule:
- 确定"共识图案"：对于瓦片内部的每个位置，统计所有瓦片在该位置是 red 还是 black，取多数票（出现更多次的颜色）作为该位置的共识值，由此构建共识图案。
- 对每个瓦片，找出其与共识图案不同的位置（差异像素）。
- 在输出中，所有瓦片的图案统一替换为共识图案（red 和 black）。差异位置额外标记为 yellow（覆盖在共识图案之上，无论该位置共识是 red 还是 black 都变为 yellow）。
- azure 分隔线保持不变。

Key insight: 解题者需要先发现所有瓦片是同一个图案的"带噪声副本"，然后通过多数投票推断出真实图案，最后理解差异位置被高亮标记——核心在于"用冗余副本纠错"的思路，而非简单的找不同。
</description>
</new_puzzle>
