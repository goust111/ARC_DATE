<description>
根据封闭区域内部"种子"像素的颜色，从色彩图例中查找对应的填充图案，将该图案平铺填入该区域。

Input structure:
- 背景为 black。网格中有若干由 grey 线段围成的不规则封闭区域（grey 线宽为 1 像素，形成闭合多边形边界）。
- 每个封闭区域内部恰好有一个非 black、非 grey 的单像素"种子"，颜色各不相同（如 red、blue、green 等）。
- 网格底部或右侧有一排独立的小矩形"图例块"，每个图例块由一个纯色边框包围，边框颜色与某个种子颜色对应；边框内部是一个 2x2 或 3x3 的双色图案（使用该边框颜色与 black 组成棋盘格、条纹或 L 形等不同图案）。

Rule:
- 对每个封闭区域，找到其内部种子像素的颜色 C。
- 在图例块中找到边框颜色为 C 的那个图例块，提取其内部图案 P。
- 将图案 P 以平铺方式填满该封闭区域的所有 black 像素（种子像素所在位置也被覆盖）。平铺的对齐基准为网格左上角 (0,0)，即图案按全局坐标取模映射。
- grey 边界和图例块本身保持不变。

Key insight: 解题需要两层独立的归纳——第一层是发现种子颜色与图例边框颜色的对应关系，第二层是发现图例内部图案以全局坐标为基准进行周期性平铺填充。仅看到"按颜色匹配"不够，还需要发现平铺的对齐方式。
</description>
</new_puzzle>

<description>
将网格中散落的彩色碎片按形状互补性配对拼合，然后按拼合后矩形的面积从小到大纵向排列输出。

Input structure:
- 背景为 black。网格中散布着偶数个小型彩色连通分量（4-连通），每个分量由单一非 black 颜色构成。
- 每两个分量构成一对"互补碎片"：它们颜色不同，但形状恰好可以像拼图一样无缝拼合成一个无孔的实心矩形（不需要旋转或翻转，仅需平移对齐）。
- 同一颜色可能出现在多个分量中，但配对唯一由形状互补决定。

Rule:
- 找到所有互补配对：对每对分量，尝试将它们的边界框对齐后合并，若合并结果恰好填满一个矩形且无重叠、无空隙，则它们配对成功。
- 对每对配对碎片，将两个分量平移到使它们拼合为完整矩形的位置，保留各自原色。
- 将所有拼合后的矩形按面积从小到大排序，从输出网格的顶部开始，逐个向下排列，每两个矩形之间留一行 black 间隔，水平方向左对齐。

Key insight: 核心难点是发现配对不是基于颜色匹配而是基于形状互补——两个碎片拼在一起刚好填满一个矩形。面积排序是第二层独立的规则，需要在完成配对后才能执行。
</description>
</new_puzzle>

<description>
沿着每个彩色箭头指示的方向，将箭头所在封闭房间的墙壁"推开"一格，使房间在该方向上扩张，然后用箭头的颜色填充扩张出来的新空间。

Input structure:
- 背景为 black。网格中有由 grey 像素构成的一格宽的墙壁网络，将网格分隔成若干矩形"房间"（房间内部为 black）。
- 部分房间内部有一个由 3 个像素组成的箭头标记：一个"箭杆"像素和两个对角相邻的"箭翼"像素，三者同色（非 black、非 grey）。箭头朝向由箭杆相对于箭翼中点的偏移方向决定（上、下、左、右四种）。例如：箭杆在上、两个箭翼在箭杆左下和右下，则箭头朝上。
- 没有箭头的房间保持不变。

Rule:
- 对每个含箭头的房间，确定箭头方向 D 和箭头颜色 C。
- 将该房间在方向 D 一侧的整面 grey 墙壁向外平移一格（即原墙壁位置变为 black，墙壁外移一格后在新位置重新绘制 grey 墙壁）。如果外移后的墙壁与另一个房间的墙壁重合，则两面墙合并为一面。
- 房间扩张后多出来的那一行或一列空间（原墙壁所在位置）填充为颜色 C。
- 箭头标记本身从房间中移除（变为 black）。
- 多个房间的扩张互不干扰，按从左到右、从上到下的顺序依次处理。

Key insight: 解题者需要先识别出 3 像素箭头的朝向编码方式（箭杆与箭翼的空间关系），这是第一层非显然的归纳；然后发现墙壁推移与颜色填充的机制是第二层归纳。箭头的绘制方式刻意使得方向判断需要观察像素的对角关系而非简单的线性排列。
</description>
</new_puzzle>

<new_puzzle>
<description>
根据每条彩色路径穿过"染色门"的顺序，对路径上的线段逐段重新着色。

Input structure:
- 背景为 black。网格中有若干由 grey 像素构成的水平和垂直线段，它们首尾相连形成若干条不分叉的折线路径（每个 grey 像素最多与两个 grey 像素 4-连通相邻，路径端点只有一个邻居）。
- 在某些路径的一个端点处放置了一个非 black、非 grey 的彩色像素作为"起点标记"，表示路径的遍历起始端。不同路径的起点标记颜色相同或不同。
- 网格中还散布着若干"染色门"：每个染色门是一个孤立的非 black、非 grey 彩色像素，不与任何 grey 像素 4-连通相邻，但恰好与某条路径上的某个 grey 像素 4-连通相邻（即门像素与路径像素在同一行或同一列且相距 1 格）。染色门的颜色各异。

Rule:
- 对每条有起点标记的路径，从起点标记开始沿路径行走。
- 路径上的线段以拐点（方向改变的位置）为界分为若干"直线段"。
- 初始着色为起点标记的颜色。从起点出发，将当前直线段的所有 grey 像素改为当前颜色。
- 每当行走过程中经过一个与染色门相邻的 grey 像素时，当前颜色切换为该染色门的颜色。此后的直线段使用新颜色。
- 染色门像素本身保持不变。
- 没有起点标记的路径保持 grey 不变。

Key insight: 第一层归纳是发现路径由端点的彩色标记确定遍历方向，第二层是发现染色门不在路径上而是与路径相邻，其作用是在经过时切换后续线段的颜色。解题者需要理解"段"的划分（以拐点为界）和颜色切换的触发条件（经过门的邻接像素时切换，而非到达门时切换）。
</description>

<description>
识别网格中每个彩色图形的轮廓凹槽位置，将匹配形状的小块嵌入凹槽后，根据嵌入块的颜色决定整个图形的输出边框颜色。

Input structure:
- 背景为 black。网格中有 2-4 个较大的单色实心图形（4-连通，颜色为 grey），每个图形的轮廓上有一个矩形凹槽（即边界上缺失了一小块矩形区域，使得该处向内凹进）。
- 网格中另有若干小型彩色实心矩形块（颜色各不相同，如 red、blue、green、orange），散布在大图形之外。每个小矩形块的尺寸恰好与某个大图形凹槽的尺寸完全一致。
- 不同大图形的凹槽尺寸互不相同，因此小块与凹槽之间存在唯一的尺寸匹配。

Rule:
- 对每个 grey 大图形，检测其轮廓上的矩形凹槽的尺寸（宽 x 高）。
- 在散布的小矩形块中，找到尺寸完全匹配的那个小块，记录其颜色 C。
- 将该小块平移嵌入凹槽位置，填补大图形的缺口（小块像素变为颜色 C）。
- 嵌入完成后，将该大图形的整个外轮廓（最外一层像素）从 grey 改为颜色 C，内部像素保持 grey。
- 未被匹配的小块（如果有）从输出中移除（变为 black）。

Key insight: 第一层归纳是发现小块通过尺寸（而非颜色或位置）与凹槽配对；第二层是发现配对后小块的颜色不仅用于填补凹槽，还决定了整个大图形外轮廓的重新着色。两层规则都需要从样例中独立归纳，且第二层规则只有在正确完成第一层配对后才能验证。
</description>

<description>
将网格中的多层嵌套框架"展开"为并排排列的独立框架，每层框架的填充颜色由其嵌套深度对应的颜色序列决定。

Input structure:
- 背景为 black。网格左半部分包含一个多层嵌套的矩形框架结构：最外层是一个由某颜色（如 red）绘制的一像素宽矩形边框，其内部包含另一个由不同颜色绘制的较小矩形边框，以此类推，最内层可能是一个实心小矩形或单个像素。每层边框之间间隔一像素的 black 空隙。层数为 2-4 层。
- 网格右半部分有一个"颜色序列条"：一行或一列由不同颜色像素排成的短序列（如 blue、green、orange 从左到右），像素数量等于嵌套层数。

Rule:
- 将嵌套框架从外到内拆分为独立的各层。第 1 层是最外层边框，第 2 层是次外层边框，依此类推。
- 颜色序列条从左到右（或从上到下）的第 k 个颜色对应第 k 层。
- 输出中，将各层框架并排水平排列（从左到右，层序从外到内），每两层之间留一列 black 间隔。
- 每层框架保持其原始形状和大小，但边框颜色替换为颜色序列条中对应位置的颜色。
- 框架内部（该层边框围成的区域，不含更内层）填充为 black。

Key insight: 第一层归纳是发现嵌套结构需要逐层剥离拆分为独立对象；第二层是发现右侧颜色序列条的位置顺序与嵌套深度的对应关系，从而确定每层的重新着色方案。解题者不能简单地按原色输出，必须发现颜色重映射规则。
</description>

<new_puzzle>
<description>
在网格中找到每对同色标记像素，沿它们之间的最短直角路径画线，线在交叉点处的颜色由交叉线的层级优先关系决定。

Input structure:
- 背景为 black。网格中散布着若干对彩色标记像素，每种颜色恰好出现两次（如两个 red、两个 blue、两个 green 等）。
- 网格中还有若干 grey 像素构成的一像素宽障碍墙段，路径不可穿过。
- 网格边缘某处有一个由各标记颜色按特定顺序排成的单行或单列"优先级条"，从左到右（或从上到下）表示优先级从高到低。

Rule:
- 对每种颜色，连接其两个同色标记像素：从一个标记出发，先沿水平方向画线到与另一个标记同列的位置，再沿垂直方向画线到达另一个标记（形成一条 L 形直角路径）。若水平优先路径被障碍墙阻挡，则改为垂直优先（先垂直再水平）。
- 所有路径画完后，在路径交叉的像素位置，保留优先级条中排位更高（更靠左或更靠上）的颜色。
- 标记像素本身保持原色不变。

Key insight: 第一层归纳是发现同色配对和 L 形路径的画法规则（水平优先，障碍时切换）；第二层是发现交叉点的颜色冲突通过边缘的优先级条来解决，而非简单地后画覆盖先画。两层规则必须同时正确归纳才能复现输出。
</description>
</new_puzzle>
