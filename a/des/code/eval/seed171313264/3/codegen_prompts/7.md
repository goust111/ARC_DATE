Input structure:

Rule:
- 对每种颜色，连接其两个同色标记像素：从一个标记出发，先沿水平方向画线到与另一个标记同列的位置，再沿垂直方向画线到达另一个标记（形成一条 L 形直角路径）。若水平优先路径被障碍墙阻挡，则改为垂直优先（先垂直再水平）。

- 标记像素本身保持原色不变。

Key insight: 第一层归纳是发现同色配对和 L 形路径的画法规则（水平优先，障碍时切换）；第二层是发现交叉点的颜色冲突通过边缘的优先级条来解决，而非简单地后画覆盖先画。两层规则必须同时正确归纳才能复现输出。

1. `main(grid)` 必须实现新题描述中的确定性转换规则，不能只识别 `generate_input()` 的固定模板。
