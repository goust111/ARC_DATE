- `Input structure`：黑色背景上由灰色（Grey）线条围成若干封闭区域。网格右侧有一列纹理图例：每条图例由一个小箭头方向标记（由 3 个同色像素组成的 L 形，开口朝向表示方向：上、下、左、右）和紧邻其旁的一个 3x3 纹理模板组成，共四条图例分别对应四个方向。每个封闭区域内部恰好有一个"种子簇"——由 2-4 个同色非黑非灰像素组成的 L 形小图案，其开口朝向为上、下、左或右之一。
- `Rule`：

  2. 对每个封闭区域，读取其内部种子簇的 L 形开口朝向，匹配到对应方向的图例纹理模板。
  3. 用种子簇的颜色，按匹配到的 3x3 纹理模板在整个封闭区域内进行平铺填充：以区域左上角为起始对齐点，将 3x3 模板周期性铺满区域，模板中"填"的位置涂上种子簇颜色，"不填"的位置保持黑色。
  4. 灰色边界线保持不变；种子簇本身被纹理覆盖（不特殊保留）；图例区域在输出中原样保留。
- `Key insight`：种子簇的几何朝向并非直接控制填充方向，而是作为索引去查询图例中对应的纹理模板；解题者需要先建立"朝向→图例→纹理"的两层映射，再完成区域填充。

- `description`：将散落的彩色碎片按颜色配对，沿两块碎片之间的连线方向将它们滑动合并成完整图形，合并后的图形再根据其面积大小关系进行分层叠放排序。
- `Input structure`：黑色背景上散布着若干彩色连通块（碎片）。同一颜色恰好出现两块碎片，且这两块碎片在水平或垂直方向上严格对齐（即共享同一行区间或同一列区间）。不同颜色的碎片对之间没有空间冲突。输出网格尺寸小于输入。
- `Rule`：
  1. 按颜色将碎片配对，每对两块。
  2. 对于每对同色碎片，确定它们的对齐方向（水平对齐则沿水平方向，垂直对齐则沿垂直方向），将两块碎片沿该方向相向滑动，直到它们的边界像素刚好相邻（中间无间隔），合并成一个完整的连通图形。
  3. 统计每个合并后图形的像素总面积。
  4. 输出时，将所有合并后的图形在一个紧凑网格中从上到下排列：面积最大的图形放在最上方，面积最小的放在最下方。相邻图形之间留一行黑色间隔。每个图形水平居中放置。
- `Key insight`：解题者需要先发现同色碎片是"半成品"需要合并（而非独立对象），再发现合并方向由对齐关系决定，最后发现输出的排列顺序由合并后面积决定——三层递进的规则发现过程。
</new_puzzle>

<new_puzzle>
- `description`：网格中的彩色"门"控制信号路径的走向：信号从源点出发沿直线传播，遇到门时根据门的颜色与朝向发生转弯或分裂，最终到达的终点格被标记。
- `Input structure`：黑色背景。网格中有若干红色（Red）单像素作为"源点"，每个源点的某一侧紧邻一个同色像素（共 2 像素），两像素的排列方向即为信号初始传播方向（例如两像素水平排列且源点在左，则信号向右传播）。网格中散布着若干"门"，每个门由 3 个同色像素组成 L 形（非红色），L 形的直角顶点为门的"枢纽"，两臂分别长 1 像素。不同颜色的门有不同行为。
- `Rule`：
  1. 信号从每个红色源点出发，沿初始方向逐格传播（不留痕迹，只关心终点）。
  2. 信号遇到门的枢纽像素时：
     - 绿色（Green）门：信号转向 90 度，转向方向为门的另一臂所指的方向（即信号从一臂方向进入枢纽，从另一臂方向射出）。
     - 黄色（Yellow）门：信号分裂为两束，一束继续直行，另一束转向 90 度（转向方向同绿色门规则）。
     - 蓝色（Blue）门：信号被吸收并停止，枢纽像素位置即为终点。
  3. 信号若未遇到任何门而到达网格边界，则边界处最后一个格为终点。
  4. 所有终点格被涂上橙色（Orange）。其余所有内容（源点、门、背景）保持不变。
- `Key insight`：解题者需先理解 L 形门的朝向决定了信号的入射和出射关系（并非简单的"碰墙反弹"），再区分三种颜色门的不同行为（转向、分裂、吸收），最后追踪可能因分裂而产生的多条路径。门的颜色编码行为类型、门的几何形状编码方向信息，两者必须同时解读。
</new_puzzle>

<new_puzzle>
- `description`：识别网格中由边框围成的"房间"，根据房间内部小图案的对称性类型选择变换方式，再将变换结果按房间在网格中的空间拓扑关系拼合输出。
- `Input structure`：黑色背景上有若干个由橙色（Orange）边框围成的矩形"房间"，房间之间可能相邻（共享一段橙色边框）或分离。每个房间内部包含一个由单一非黑非橙颜色绘制的小图案（3x3 至 5x5），占据房间内部的一部分区域，其余为黑色。
- `Rule`：
  1. 提取每个房间内部的小图案（去掉橙色边框后的内容）。
  2. 判断每个小图案的对称性类型：
     - 若图案具有水平对称轴（左右对称）：将图案上下翻转。
     - 若图案具有垂直对称轴（上下对称）：将图案左右翻转。
     - 若图案具有 180 度旋转对称：将图案顺时针旋转 90 度。
     - 若图案无任何对称性：保持图案不变。
  3. 输出网格去掉所有橙色边框，仅保留变换后的图案。各图案在输出中的相对位置关系与对应房间在输入中的空间排列关系一致（即若房间 A 在房间 B 的左边，则 A 的变换结果在 B 的变换结果的左边）。相邻图案之间留一列或一行黑色间隔。
- `Key insight`：解题者不仅需要识别每个图案的对称性类型（这本身需要仔细观察），还需发现对称性类型与变换方式之间的"反直觉"对应——拥有水平对称的图案做的是垂直方向的翻转，反之亦然。这种交叉映射关系是核心隐蔽机制。
</new_puzzle>

<new_puzzle>
- `description`：网格中的彩色连通区域扮演"模具"和"印泥"两种角色：模具的形状挖空印泥的形状后，剩余部分被重新着色并放置到模具原来的位置。
- `Input structure`：黑色背景上有若干对彩色连通块。每对由两个不同颜色的连通块组成，它们的边界框（bounding box）恰好大小相同且在水平或垂直方向上紧邻（中间隔一列或一行黑色像素）。每对中，一个连通块面积较大（"印泥"），另一个面积较小（"模具"）。网格底部有一行单像素的颜色图例：若干个不同颜色的单像素从左到右排列，颜色数量等于连通块对数。
- `Rule`：
  1. 将边界框大小相同且紧邻的两个连通块配对。每对中面积较大者为"印泥"，较小者为"模具"。
  2. 将模具的形状覆盖到印泥上（左上角对齐），印泥中与模具重叠的像素被"挖去"（变为黑色），剩余像素保留。
  3. 将挖空后的印泥剩余形状移动到模具原来的位置（左上角对齐），并重新着色为底部图例中对应顺序的颜色（从左到右第一对用图例第一个颜色，第二对用第二个，以此类推；配对顺序按照对的中心点从左到右排列）。
  4. 输出网格中仅保留重新着色后的结果形状和底部图例，其余位置为黑色。
- `Key insight`：解题者需要依次发现三层规则：首先通过边界框匹配进行配对（而非通过颜色），然后理解大小关系决定角色分配和布尔减法操作的方向，最后发现输出颜色由独立的图例行控制而非继承自原有颜色。每一层都需要从样例中独立归纳。
</new_puzzle>
