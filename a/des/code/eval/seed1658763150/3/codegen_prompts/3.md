  - "信号塔"为 3x3 的十字形图案（中心像素 + 四个正交邻居），中心像素颜色为该塔的"信号色"（如 red、blue、green 等），四臂颜色为 grey。十字形的四臂中，某些臂被截断（缺失），表示该塔不向该方向广播。
  - "接收器"为单个 yellow 像素，散布在网格各处。
  - 信号塔的中心像素上方或下方紧邻一个小数字标记：由 1-3 个 maroon 像素组成的竖条，像素数量表示该塔的广播优先级（1 个 = 最先广播，2 个 = 其次，3 个 = 最后）。

- `Rule`：
  - 按优先级从高到低（maroon 像素数从少到多）依次处理每座信号塔。
  - 每座塔从其保留的臂方向发射射线（沿该方向延伸到网格边界），射线穿过 bg 格子但被任何非 bg 像素阻挡（包括其他塔和已染色的接收器）。
  - 射线经过的每个 yellow 接收器被"激活"：若该接收器尚未被激活过，将其颜色改为该塔的信号色；若已经被之前的塔激活过（已有颜色），则将其颜色改为 orange（表示多重信号叠加）。

  - 信号塔自身和 maroon 优先级标记在输出中保持不变。

- `Key insight`：解题需要三层推理——首先从十字形的缺失臂读取广播方向，然后从 maroon 竖条读取处理顺序，最后模拟射线传播时注意阻挡关系和叠加变色规则。处理顺序决定了哪些接收器会变成 orange，因为先到的信号占据接收器后会阻挡后续射线的传播路径。
