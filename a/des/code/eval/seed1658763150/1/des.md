<new_puzzle>
用嵌套框架的层级深度决定填充颜色，再根据框架开口方向将内部最小对象弹射到外部对应边界。

Input structure:
- 背景为黑色的网格。
- 网格中有若干由单一非黑色绘制的矩形框架（单像素宽边框），框架可以嵌套（一个框架完全在另一个框架内部）。
- 每个框架的四条边中恰好有一条边存在一个宽度为 1 像素的缺口（缺口在该边的中点位置）。
- 最内层框架内部包含一个由 grey 像素组成的小型连通图案（不超过 3x3）。

Rule:
- 首先确定每个框架的嵌套深度（最外层深度为 1，次外层为 2，依此类推）。
- 根据嵌套深度为每个框架重新着色：深度 1 用 blue，深度 2 用 red，深度 3 用 green，深度 4 用 yellow（如果存在更多层则按此顺序循环）。
- 然后找到最内层框架内部的 grey 图案。沿该框架缺口的朝向方向（缺口在上边则方向向上，缺口在右边则方向向右，依此类推），将 grey 图案沿该方向"弹射"——图案穿过所有框架的缺口（每个外层框架在同一侧也恰好有缺口供通过），最终停在网格边缘处（图案的边缘紧贴网格边界）。
- 弹射后，grey 图案被重新着色为最内层框架着色后的颜色。
- 原来最内层框架内部的 grey 图案位置变为黑色。

Key insight: 解题者需要先从嵌套层级推导出颜色映射规则（第一层推理），再发现缺口方向决定弹射路径、且图案最终颜色取决于其来源框架的重着色结果（第二层推理）。
</new_puzzle>

<new_puzzle>
将散落的彩色碎片按形状拼入灰色模板的对应槽位，并用碎片之间的邻接关系决定重叠区域的颜色优先级。

Input structure:
- 背景为黑色。
- 网格中央有一个由 grey 像素构成的大型连通区域，形状不规则，内部包含若干不同形状的黑色"槽位"（即 grey 区域中的黑色空洞）。
- 在 grey 区域外部散布着若干小型彩色碎片（每个碎片为单色连通区域，颜色各不相同，如 blue、red、green、orange 等）。
- 每个碎片的形状恰好与 grey 区域内部的某一个槽位形状匹配（允许旋转 0/90/180/270 度，但不允许翻转）。
- 某些碎片在输入网格中彼此相邻（4-连通方向上间隔恰好 1 个黑色像素）。

Rule:
- 将每个彩色碎片与其形状匹配的槽位配对（考虑四种旋转）。
- 将碎片填入对应槽位，使用碎片本身的颜色替换槽位中的黑色像素。
- 填入后，检查 grey 模板中是否存在两个相邻槽位共享边界像素的情况（即两个槽位之间仅隔 1 个 grey 像素的位置）：若填入这两个槽位的碎片在原始输入中也是相邻的（间隔 1 个黑色像素），则将它们之间的 grey 分隔像素替换为两个碎片中面积较大者的颜色。
- 不满足相邻条件的 grey 分隔像素保持不变。

Key insight: 第一层推理是形状匹配与旋转对齐；第二层推理是发现输入中碎片间的空间邻接关系被"编码"到了模板内槽位间分隔像素的颜色变化中，且面积大小决定了颜色优先级。
</new_puzzle>

<new_puzzle>
根据种子像素的颜色从图例区学习生长规则，然后在主画布区让每个种子按规则生长出对应的枝干图案。

Input structure:
- 背景为黑色。网格被一条竖直的 maroon 线分为左右两个区域。
- 左侧为"图例区"：包含若干独立的示范组，每组由一个单独的彩色种子像素（如 blue、green、red）和从该种子生长出的同色枝干构成。枝干由连续的像素沿上下左右方向延伸，每经过一次转弯就缩短一格（第一段长度为 N，第二段为 N-1，第三段为 N-2……直到长度为 1 停止）。每组的初始方向和第一段长度不同。转弯方向固定为交替左转右转（第一次转弯向左，第二次向右，依此类推）。
- 右侧为"主画布区"：仅包含若干散布的单像素种子，颜色与图例区中出现的某种颜色相同。每个种子旁边紧邻（4-连通）一个 yellow 像素，指示初始生长方向（yellow 在种子的上方表示向上，在右侧表示向右，依此类推）。

Rule:
- 从图例区的每个示范组中，识别该颜色枝干的第一段长度 N（从种子出发沿初始方向到第一个转弯前的像素数）。
- 对主画布区中每个种子：读取其 yellow 方向标记确定初始方向，使用该颜色在图例区学到的第一段长度 N，按照"每段比前一段短 1 格、交替左右转弯"的规则生长枝干。
- 生长出的枝干使用种子自身的颜色绘制。
- 移除所有 yellow 方向标记像素（变为黑色）。
- 若枝干生长超出网格边界则在边界处截断。

Key insight: 解题者需要先从图例区反向解析出每种颜色的"首段长度"参数（第一层推理），然后理解递减转弯的生长规则（第二层推理），最后将 yellow 标记解读为方向控制（第三层推理）。
</new_puzzle>

<new_puzzle>
按照颜色配对关系将散落的线段端点两两相连，连线路径需绕过障碍物，连线的绘制颜色由两端点各自所在象限决定。

Input structure:
- 背景为黑色，网格大小约 20x20 至 25x25。
- 网格中央有一个由 grey 像素构成的十字形分隔线，将网格分为四个象限。
- 每个象限的角落处各有一个单像素的颜色标签（分别为 blue、red、green、orange，分布在左上、右上、左下、右下象限），指示该象限的"象限色"。
- 网格中散布着若干成对的彩色端点像素（同色恰好出现两个），颜色包括 magenta、maroon、yellow、azure 等（与象限色不同）。
- 网格中还有若干由 grey 像素构成的小型矩形障碍物（与十字分隔线不相连）。

Rule:
- 将每对同色端点用一条单像素宽的正交折线（仅水平和竖直方向）连接起来。连线不能穿过障碍物或十字分隔线的 grey 像素，也不能与其他连线交叉。
- 连线的绘制颜色不是端点本身的颜色，而是由以下规则决定：找到两个端点分别所在的象限，取这两个象限的象限色；如果两端点在同一象限，连线颜色就是该象限色；如果在不同象限，连线颜色为两个象限色中在网格中出现次数较少的那个（即两个象限标签像素本身不算，只看已绘制的连线像素数量——第一条线默认取行号较小的端点所在象限色）。
- 连接完成后，移除所有端点像素（变为黑色），只保留连线。

Key insight: 第一层推理是发现同色端点需要配对连接并绕障碍；第二层推理是发现连线颜色并非端点色而是由象限标签决定的，需要理解象限归属与颜色选取规则。
</new_puzzle>

<new_puzzle>
识别输入中每个封闭区域内部的"指针"图案，指针指向的相邻区域的颜色将被复制回来填充该区域，形成颜色传递链。

Input structure:
- 背景为黑色。
- 网格中有若干由 grey 单像素线条围成的封闭矩形区域（区域之间共享 grey 边界线，类似棋盘格但大小不一定相同）。
- 每个封闭区域内部填充着某种非黑非 grey 的颜色（如 blue、red、green、yellow、orange 等），并且恰好包含一个由黑色像素组成的小型"箭头"图案。箭头由一条 3 像素长的直线段和末端一侧的 1 个像素构成，形成指向上、下、左或右的方向指示（例如向右的箭头为：三个水平黑像素，最右像素的上方或下方有一个黑像素形成箭尖）。

Rule:
- 读取每个区域内箭头的指向方向。
- 箭头指向该区域的某一条 grey 边界；越过该边界即为相邻区域。
- 将本区域的填充色替换为箭头所指向的相邻区域的**原始**填充色（即变换前的颜色）。
- 所有区域同时执行颜色替换（使用变换前的快照，而非逐个更新）。
- 替换后，移除所有箭头图案（箭头像素变为该区域新的填充色）。
- grey 边界线保持不变。

Key insight: 解题者首先需要识别每个区域内黑色像素构成的箭头形状及其方向（第一层推理），然后理解颜色传递是同时发生的——每个区域获取箭头所指邻居的原始颜色，而非更新后的颜色，这形成了一个并行的颜色置换系统（第二层推理）。
</new_puzzle>

<new_puzzle>
提取网格中多个小图案的对称性类型，将对称性相同的图案归组，然后按组用各组独有的边框样式进行包围。

Input structure:
- 背景为黑色，网格大小约 25x25。
- 网格中散布着 6 到 8 个互不接触的小型彩色图案（每个图案由单一颜色构成，占据约 3x3 到 5x5 的范围）。
- 网格底部有一行"边框样式图例"：由若干小段示例组成，每段包含一个对称性符号和紧邻其右侧的 2x2 边框色块。对称性符号的编码方式为：单个 yellow 像素表示"无对称性"、水平排列的两个 yellow 像素表示"左右对称"、竖直排列的两个 yellow 像素表示"上下对称"、2x2 的四个 yellow 像素表示"四重对称（左右 + 上下）"。

Rule:
- 分析每个散布图案的对称性类型（以图案的紧密包围盒为参考）：是否具有水平轴对称、竖直轴对称、两者皆有、或两者皆无。
- 根据底部图例，查找该对称性类型对应的边框颜色（2x2 色块的颜色）。
- 用该边框颜色在图案的紧密包围盒外围绘制一圈单像素宽的矩形边框（边框与包围盒之间无间隙）。
- 图案本身保持不变，底部图例保持不变。

Key insight: 第一层推理是破解底部图例中 yellow 像素排布与对称性类型之间的编码关系；第二层推理是对每个图案进行视觉上的对称性判断，并匹配到正确的边框颜色。
</new_puzzle>

<new_puzzle>
在网格中找到被"锁"保护的"宝箱"区域，用散落的"钥匙"图案解锁对应的锁，然后将宝箱内部的隐藏图案显现出来。

Input structure:
- 背景为黑色，网格大小约 20x20 至 28x28。
- 网格中有若干由彩色像素填充的矩形"宝箱"区域（每个宝箱为单一颜色的实心矩形，约 4x4 到 6x6）。
- 每个宝箱的某一条边外侧紧贴着一个由 grey 像素构成的小型图案，称为"锁"（约 2x3 或 3x2 大小，形状各异）。
- 网格中其他位置散布着若干由 maroon 像素构成的小型图案，称为"钥匙"。每把钥匙的形状恰好是某把锁的水平或竖直镜像翻转。

Rule:
- 将每把钥匙与其镜像匹配的锁配对（先尝试水平翻转，若不匹配再尝试竖直翻转）。
- 对于已配对的宝箱，"解锁"操作如下：将宝箱内部区域（不含外边框一圈像素）的颜色替换为锁的 grey 色，同时将锁本身移除（变为黑色），钥匙也移除（变为黑色）。
- 未被配对的宝箱保持原样（对应的锁也保留）。
- 未被配对的钥匙保持原样。

Key insight: 第一层推理是识别"锁"和"钥匙"的视觉角色及其镜像匹配关系；第二层推理是理解解锁后宝箱内部的变换方式——外框保留原色而内部变为 grey，形成"打开"的视觉效果。
</new_puzzle>
