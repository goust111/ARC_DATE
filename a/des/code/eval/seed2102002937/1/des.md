<description>
根据封闭区域内标记像素的颜色，在区域边界的对应缺口处生长出与标记数量等长的彩色枝条。

Input structure:
- bg = black 背景。网格中有若干由同一种非背景色（如 blue）绘制的封闭矩形框，每个框的某一条边上恰好有一个单像素宽的缺口（缺口位置各框不同，可能在上、下、左、右任意一边）。
- 每个框内部散布着若干彩色像素（非背景色、非框色），这些像素可能包含多种颜色，但同一个框内所有彩色像素恰好属于同一种颜色。
- 框外部是纯黑背景，无其他干扰物。

Rule:
- 对每个封闭框，首先找到其边界上的缺口位置及缺口朝外的方向（上缺口则方向向上，左缺口则方向向左，依此类推）。
- 数出框内部彩色像素的总数 N。
- 从缺口位置出发，沿缺口朝外的方向，绘制一条长度为 N 的直线，颜色为框内彩色像素的颜色。
- 框内部的彩色像素保持不动，框本身也不变。若枝条超出网格边界则截断。

Key insight：缺口的边决定了生长方向，框内彩色像素的数量决定了枝条长度，颜色由框内像素决定——需要同时识别缺口方位、计数内部像素、匹配颜色三项信息。
</description>

<description>
将网格中散落的彩色碎片按颜色配对后，用两块碎片拼合还原出完整的矩形，并将拼合结果放置在同色锚点标记的位置。

Input structure:
- bg = black 背景。网格中散布着若干彩色碎片，每种非背景颜色恰好出现两块不规则形状的碎片。
- 同色的两块碎片可以通过平移（不旋转、不翻转）无重叠地拼合成一个完整的实心矩形。
- 网格边缘（第一行或第一列）上有若干单像素的锚点标记，每个锚点的颜色与某一对碎片的颜色相同。锚点在边缘上的位置指示该颜色矩形的放置位置（锚点为矩形左上角）。

Rule:
- 对每种颜色，找到对应的两块碎片。
- 确定两块碎片的相对平移偏移量，使它们恰好拼成一个无间隙、无重叠的实心矩形。
- 将拼合后的矩形以该颜色的锚点像素为左上角，绘制到输出网格中。
- 原始碎片位置清除为背景色，锚点本身被矩形覆盖。

Key insight：先要发现同色碎片是互补关系——它们拼成矩形；再要找到边缘锚点确定放置位置。碎片的形状互补性是隐蔽的核心机制，需要从样例中归纳出"两块拼成矩形"的规律。
</description>
</new_puzzle>

<new_puzzle>
<description>
根据带颜色分区的环形轨道上的旋转指令标记，将轨道上的有色像素沿轨道循环移动指定步数后输出。

Input structure:
- bg = black 背景。网格中央有一个由 grey 像素构成的封闭环形轨道（单像素宽，形状为矩形环，沿轨道可唯一确定顺时针遍历顺序）。
- 轨道上某些位置被染成非灰色的彩色像素（如 red、green、blue 等），其余轨道位置保持 grey。
- 轨道外部有若干"旋转指令块"：每个指令块是一个小的同色矩形色块（颜色与轨道上某种彩色像素对应），色块的像素数量表示旋转步数。
- 每个指令块旁边（4-邻接）有一个 maroon 箭头像素，箭头相对于色块的方位表示旋转方向：箭头在色块的右侧或下侧表示顺时针，在色块的左侧或上侧表示逆时针。

Rule:
- 对每种出现在轨道上的颜色，找到对应的外部指令块。
- 从指令块的像素数得到步数 S，从 maroon 像素相对于色块的方位得到旋转方向 D。
- 将轨道上所有该颜色的像素沿轨道方向 D 循环移动 S 步（轨道为循环结构，到头后回到起点继续移动）。
- 不同颜色的移动互不干扰（先计算所有颜色的目标位置，再统一绘制）。
- 如果多种颜色移动后落在同一轨道位置，按颜色在轨道上首次出现的顺时针顺序决定优先级，靠后的覆盖靠前的。

Key insight：需要三层推理——(1) 识别轨道结构并确定遍历顺序，(2) 将外部色块的面积解读为移动步数并从 maroon 像素方位判断方向，(3) 将轨道上的彩色像素按步数和方向做循环位移。外部指令块的"面积=步数"机制和方位编码方向是两个需要分别归纳的隐蔽规律。
</description>
</new_puzzle>

<description>
在网格中找到被墙壁分隔的多个房间，根据每个房间内"种子图案"的对称性类型，用对应颜色填充该房间的空白区域。

Input structure:
- bg = black 背景。网格被 blue 墙壁（单像素宽的水平和垂直线段）划分为若干矩形房间。
- 每个房间内有一个小的单色"种子图案"（由 2~6 个同色像素组成，颜色为非背景、非墙壁色），占据房间的一小部分区域，其余为黑色背景。不同房间的种子图案颜色可以不同。
- 网格的最上方一行（在墙壁系统之外）有一个"图例行"：图例行包含若干彩色小图案，每个小图案由一种颜色的 2~4 个像素组成，图案之间用 black 间隔。每个图例图案本身的形状展示了一种对称性类型——(a) 关于水平中轴左右对称（如两个像素水平排列），(b) 关于垂直中轴上下对称（如两个像素垂直排列），(c) 关于中心旋转 180 度对称（如对角线排列的两个像素），(d) 无任何对称性（如 L 形的三个像素）。

Rule:
- 分析每个房间内种子图案的对称性类型：将种子图案提取为其最小包围矩形内的像素排列，判断其属于水平对称、垂直对称、旋转对称、还是无对称。
- 在图例行中找到具有相同对称性类型的图例图案，获取其颜色。
- 将该房间内所有空白（black）像素填充为该图例颜色，种子图案本身和墙壁保持不变。

Key insight：解题者需要先从图例行中归纳出"每种颜色代表一种对称性类型"的映射规则（通过观察图例图案自身的形状对称性），再判断每个房间内种子图案属于哪种对称类型，最后执行颜色填充。对称性的分类判断和图例的自指性编码是两层独立的非平凡推理。
</description>

<description>
将网格中的彩色路径段按拓扑连接顺序首尾相接地重排到一条水平直线上，颜色顺序由路径的实际走向决定。

Input structure:
- bg = black 背景。网格中有若干不同颜色的路径段（每段是一条连续的、由同色像素组成的水平或垂直直线段，长度各不相同）。
- 这些路径段在空间上首尾相邻：每条路径段的一个端点与另一条路径段的一个端点在 4-邻接方向上相邻（间距恰好 1 像素），从而形成一条从起点到终点的唯一链式序列。
- 链的起点路径段的非连接端旁边有一个 maroon 像素标记（4-邻接），终点路径段的非连接端没有任何相邻的非背景像素。
- 网格下方有一条预先画好的 grey 水平基准线（单像素高，跨越整个网格宽度）。

Rule:
- 从 maroon 标记出发，找到与之相邻的起点路径段，然后沿链式连接顺序依次遍历所有路径段。
- 在 grey 基准线的正上方一行，从左到右，按遍历顺序依次水平绘制每条路径段：每段用其原始颜色绘制，长度等于该段的原始像素数量，段与段之间无间隔紧密相连。
- 原始位置的所有路径段和 maroon 标记清除为背景色，grey 基准线保留。

Key insight：核心难点在于发现路径段之间的首尾链接关系并确定遍历起点（通过 maroon 标记识别）。解题者需要 (1) 理解不同颜色的线段通过端点邻接形成一条逻辑链，(2) 找到 maroon 标记确定链的方向，(3) 将空间中弯折的链"展开"为一维水平序列，其中每段的长度保持不变。
</description>

<description>
根据网格中"染色透镜"的叠加覆盖关系，对背景区域进行多层颜色混合，混合规则由透镜重叠数量决定输出颜色。

Input structure:
- bg = black 背景。网格中有若干半透明的"透镜"——每个透镜是一个实心矩形区域，由某种非背景颜色填充，不同透镜可以相互重叠。
- 每种颜色最多出现一个透镜。所有透镜的颜色各不相同。
- 网格右侧有一列"混合图例"：图例由上到下排列若干单像素，依次表示被 1 个透镜覆盖时的输出颜色、被 2 个透镜覆盖时的输出颜色、被 3 个透镜覆盖时的输出颜色……图例像素之间用 black 间隔，图例的第 k 个非黑像素（从上到下数）对应覆盖层数 k。

Rule:
- 对输出网格中的每个像素位置，计算有多少个透镜覆盖了该位置（即该位置落在多少个矩形内部）。
- 若覆盖数为 0，该位置保持 black。
- 若覆盖数为 k（k >= 1），根据右侧图例，将该位置染为图例中第 k 个颜色。
- 右侧图例列本身在输出中保持不变。

Key insight：解题者需要 (1) 识别出矩形区域是可重叠的透镜而非普通色块，(2) 发现重叠区域的输出颜色既不是任何一个透镜的原色，而是由覆盖层数决定的全新颜色，(3) 从右侧图例中归纳出"层数到颜色"的映射规则。透镜的重叠计数机制和图例的序数编码是两层需要独立发现的规律。
</description>

<new_puzzle>
<description>
在网格中识别由边框颜色编码的"容器"嵌套层级，将最内层容器中的图案向外逐层复制，每层复制时按该层边框的缺口方向做 90 度旋转。

Input structure:
- bg = black 背景。网格中有若干同心嵌套的矩形边框（类似俄罗斯套娃），每层边框用不同的颜色绘制（如最外层 red、中间层 green、最内层 blue），边框为单像素宽的矩形环。
- 每层边框的某一条边上恰好有一个单像素缺口（缺口位置因层而异：可能在上、下、左、右任一边）。
- 最内层边框的内部包含一个小型的多色图案（由 2~8 个像素组成的非对称形状）。
- 各层边框之间的空隙（环形区域）在输入中为 black 背景。

Rule:
- 从最内层向外逐层处理：
  - 第一步：将最内层的图案保持不变。
  - 第二步：将当前图案复制到下一层（外一层）的内部空隙中，但需根据该外层边框缺口的方向进行旋转——缺口在上则不旋转（0 度），缺口在右则顺时针旋转 90 度，缺口在下则旋转 180 度，缺口在左则逆时针旋转 90 度（即顺时针 270 度）。
  - 旋转后的图案居中放置在该层环形空隙内。
  - 第三步：将旋转后的图案作为"当前图案"，继续向更外层重复此过程。
- 所有边框保持不变，缺口保持为 black。

Key insight：解题者需要 (1) 识别嵌套的边框层级结构并确定从内到外的处理顺序，(2) 发现每层边框的缺口方位编码了旋转角度这一隐蔽映射，(3) 理解旋转是累积的——每向外一层，图案会在前一层旋转的基础上再叠加当前层指定的旋转。三层独立的推理环环相扣。
</description>
</new_puzzle>
