<description>
根据框架内部的彩色种子像素生长出与种子颜色匹配的图案模板，然后将生长结果按框架边框颜色指定的翻转方式写入框架内部。

Input structure:
- bg = Black。网格上散布着若干大小不同的空心矩形框架，每个框架的边框由某种非背景颜色绘制（如 Red、Blue、Green 等），框架内部填充背景色。
- 每个框架内部恰好有一个单像素的"种子"像素，颜色与边框颜色不同。
- 在网格的某个角落区域，有一组"图案模板"：每个模板是一个小的连通图案（3×3 至 5×5），由单一颜色绘制在背景上，且每种颜色的模板恰好出现一次。

Rule:
- 第一步（颜色匹配）：将每个框架内部的种子像素颜色与图案模板的颜色进行匹配，找到同色的模板。
- 第二步（翻转规则）：根据框架边框颜色确定翻转方式。网格边缘有一个颜色图例区域，每种边框颜色对应一个小箭头标记（由该颜色绘制的 3 像素 L 形）：L 形开口朝右表示不翻转；开口朝左表示水平翻转；开口朝上表示垂直翻转；开口朝下表示同时水平和垂直翻转。
- 第三步（放置）：将匹配到的模板按照翻转方式变换后，以种子像素为模板左上角的锚点，绘制到框架内部。模板像素覆盖背景色区域；若模板超出框架内部范围则截断。种子像素本身被模板覆盖。

Key insight: 解题需要同时发现两层独立的映射关系——种子颜色决定"画什么"，边框颜色通过箭头图例决定"怎么画"——两层映射互不相关，必须分别从样例中归纳。
</description>
</new_puzzle>

<new_puzzle>
<description>
将网格中散落的彩色碎片按照颜色归组，每组碎片沿其共享的隐含对称轴折叠合并，最终将所有合并结果拼入一个紧凑输出网格。

Input structure:
- bg = Azure。网格上散布着多组彩色像素块，每组由相同颜色的两个不规则碎片组成（碎片之间不相连）。
- 同色的两个碎片在形状上互为镜像的"半块"——它们沿某条水平或垂直的隐含轴线对折后恰好拼合成一个完整的矩形图案（无重叠、无空缺）。
- 不同颜色组的碎片对之间没有空间上的规律性排列。

Rule:
- 第一步（归组）：按颜色将碎片分组，每组恰好两个连通分量。
- 第二步（发现对称轴）：对于每组同色碎片，找到一条水平或垂直的对称轴，使得将其中一个碎片沿该轴翻转后，两碎片恰好无缝拼合成一个矩形区域。判断方法：两碎片的紧凑包围盒在对称方向上长度相同，且翻转后像素互补。
- 第三步（合并）：执行翻转拼合，得到每组的完整矩形图案。
- 第四步（排列输出）：将所有完整矩形图案按其原始位置的行优先顺序（先按碎片对中心行排序，再按中心列排序）从左到右、从上到下排列在输出网格中，矩形之间用 1 像素的背景色间隔分隔。

Key insight: 核心难点不在于颜色归组（颜色相同即同组），而在于发现同色两碎片是某个完整图案沿隐含轴线拆开的两半——需要在心中尝试翻转拼合才能确认轴线方向和拼合方式。
</description>
</new_puzzle>

<description>
在一个被彩色线段网络分割的网格中，根据每个封闭区域内的标记像素数量选择对应的填充纹理，将纹理铺满该区域。

Input structure:
- bg = Black。网格由若干单像素宽的彩色直线段（水平或垂直）分割成多个封闭矩形区域。线段颜色各不相同。
- 部分封闭区域内含有若干散落的 Grey 标记像素（数量从 1 到 4 不等）。
- 网格底部有一行纹理图例区，由 Grey 水平线与底部边界围成的小矩形格子组成。每个图例格子内绘有一种 2×2 的重复纹理图案（使用两种非背景、非灰色的颜色），格子左侧紧邻 1 到 4 个 Grey 像素排成一列，表示该纹理对应的标记数。

Rule:
- 第一步（区域识别）：识别所有被彩色线段围成的封闭矩形区域。
- 第二步（计数匹配）：数出每个区域内 Grey 标记像素的数量 N（0 ≤ N ≤ 4）。若 N = 0，该区域保持背景色不变。
- 第三步（纹理查表）：在图例区找到左侧有 N 个 Grey 像素的那个图例格子，读取其中的 2×2 纹理图案。
- 第四步（填充）：将该 2×2 纹理以平铺方式填满对应区域的全部背景像素，纹理的相位以区域左上角为 (0,0) 对齐。Grey 标记像素被纹理覆盖。彩色线段本身保持不变。

Key insight: 解题者需要先理解底部图例的编码方式（Grey 像素列的长度 = 标记数量），再将其与各区域内的 Grey 像素计数对应——图例本身的结构需要归纳，而非直接给出，构成第一层推理；纹理铺填的相位对齐规则构成第二层。
</description>

<description>
根据彩色"信号塔"的高度和朝向，向指定方向发射与塔高等长的光线，光线在碰到"棱镜"像素时改变方向并继续传播。

Input structure:
- bg = Black。网格上有若干"信号塔"：每座塔是一条垂直或水平的单像素宽彩色线段（长度 2 至 5 像素），由同一种非背景颜色构成。
- 每座塔的一端紧邻一个 Yellow 像素，称为"塔头"，Yellow 像素相对于塔身的方位指示发射方向（例如 Yellow 在塔的上方则向上发射）。
- 网格上散布着若干单独的"棱镜"像素，每个棱镜是一个 Magenta 像素。

Rule:
- 第一步（确定发射参数）：对每座塔，从塔头的 Yellow 像素出发，沿 Yellow 相对塔身的方向发射光线。光线的颜色 = 塔身颜色，光线的剩余传播长度初始值 = 塔身像素数量（不含 Yellow 像素）。
- 第二步（光线传播）：光线从 Yellow 像素的下一格开始，沿发射方向逐格前进，每前进一格将该格涂为当前光线颜色，剩余长度减 1。当剩余长度归零时光线终止。
- 第三步（棱镜折射）：若光线行进过程中到达一个 Magenta 棱镜像素，则：(a) 该棱镜像素被涂为当前光线颜色；(b) 光线方向顺时针旋转 90 度；(c) 剩余长度不变，继续从棱镜的下一格沿新方向传播。一条光线可经过多个棱镜，每次都顺时针转 90 度。
- 第四步（边界与碰撞）：若光线到达网格边界，则直接终止（即使剩余长度未耗尽）。若光线碰到已有的非背景像素（非棱镜），同样终止。Yellow 像素在输出中保留。

Key insight: 解题者需要发现三层结构——塔高编码射程长度（第一层），Yellow 方位编码发射方向（第二层），Magenta 棱镜导致光线转弯但不消耗长度（第三层）。前两层较易从样例归纳，第三层棱镜的"不消耗长度+顺时针转向"规则需要仔细对比有无棱镜的样例才能发现。
</description>

<new_puzzle>
<description>
在网格中找到成对的同色"门框"结构，将一个门框内部的内容通过连接通道传送到另一个门框内部，传送过程中根据通道的转弯次数决定旋转角度。

Input structure:
- bg = Black。网格上有若干对同色的"门框"——每个门框是一个由某种颜色绘制的矩形空心边框（外径 5×5 至 8×8，边框宽 1 像素），同色的门框恰好有两个。
- 每对同色门框之间有一条由同色像素绘制的单像素宽路径（"通道"）连接，路径仅做水平和垂直转弯。
- 其中一个门框的内部含有由其他颜色绘制的小图案（"内容"），另一个门框内部为空（全是背景色）。内容图案不会使用门框的颜色。

Rule:
- 第一步（配对）：按颜色将门框配对。每对中，有内容的门框为"源"，空的为"目标"。
- 第二步（数转弯）：沿连接源与目标的同色通道行走，数出路径的转弯次数 T（0、1、2 或 3 次，从通道离开源门框边框的点开始，到进入目标门框边框的点结束）。
- 第三步（旋转传送）：将源门框内部的内容图案顺时针旋转 T × 90 度，然后放置到目标门框的内部区域。内容的锚点为旋转后图案的左上角对齐目标框内部的左上角。
- 第四步（清理）：源门框的内容保留不变。通道路径保留不变。所有门框边框保留不变。

Key insight: 配对机制（同色门框）是较易发现的表层规则；真正的核心洞见在于通道的"转弯次数"编码了旋转角度——解题者需要追踪每条通道的几何走向并数出拐点数量，然后将其映射为 0°/90°/180°/270° 的旋转，这是一个需要主动空间推理的非平凡归纳步骤。
</description>

<description>
在含有多个彩色矩形区域的网格中，矩形边框上的"缺口"像素决定向外发射同色触角的方向，触角沿途吸附附近的 Grey 靶点并将其着色。

Input structure:
- bg = Black。网格上有若干不重叠的实心彩色矩形区域（颜色各不相同，大小在 3×3 至 6×6 之间）。
- 每个矩形的边框上有 1 至 4 个像素被替换为背景色，形成"缺口"。缺口仅出现在边框上，不出现在矩形角点。
- 网格上另有若干单独的 Grey 像素散布在矩形区域之外，作为"靶点"。

Rule:
- 第一步（识别缺口方向）：对每个矩形，找到其边框上的所有缺口位置。每个缺口所在的边框侧（上、下、左、右）即为该缺口的发射方向。
- 第二步（发射触角）：从每个缺口位置出发，沿缺口方向向外逐格绘制该矩形颜色的像素，直到碰到网格边界或碰到任何非背景像素为止（不覆盖已有像素，触角终止于碰撞点前一格）。
- 第三步（靶点吸附）：若某条触角在延伸过程中经过一个 Grey 靶点像素的相邻格（4-邻接），则该 Grey 靶点被重新着色为触角的颜色（即矩形的颜色）。若一个靶点同时被多条触角相邻，则被最先到达（距离矩形最近）的触角着色。
- 第四步（缺口修复）：所有触角绘制完毕后，将每个矩形边框上的缺口像素恢复为矩形自身的颜色，使矩形恢复为完整的实心矩形。

Key insight: 解题者首先要发现矩形边框上不起眼的缺口（它们看起来像随机缺陷），然后归纳出缺口不仅指示发射方向还产生触角，最后发现触角对 Grey 靶点的吸附着色规则——"缺口即炮口"的隐喻需要跨越视觉直觉的障碍才能归纳出来。
</description>

<description>
将散落在网格中的彩色"钥匙"形状插入颜色匹配的"锁孔"凹槽中，插入后钥匙与锁体融合并改变锁体的内部填充颜色。

Input structure:
- bg = Black。网格上有若干"锁体"：每个锁体是一个较大的单色实心矩形（5×5 至 8×8），其某一侧边缘有一个凹入的缺口（"锁孔"），缺口形状为 1 至 3 像素深、1 至 2 像素宽的矩形凹槽，凹槽内为背景色。
- 每个锁体的锁孔开口一侧旁边（距离 1 像素）有一个由 Orange 像素绘制的"方向指示器"：一个 3 像素的 L 形，L 的长臂指向锁孔的插入方向。
- 网格上另有若干小的彩色连通图案（"钥匙"），每把钥匙的形状与某个锁孔的凹槽形状恰好互补——即钥匙塞入锁孔后恰好填满凹槽。钥匙的颜色与锁体颜色不同。
- 每把钥匙旁边（4-邻接）有一个单像素的颜色标记，其颜色与某个锁体的颜色相同，指示这把钥匙属于哪个锁。

Rule:
- 第一步（钥匙-锁匹配）：通过钥匙旁的颜色标记找到对应的锁体（标记颜色 = 锁体颜色）。
- 第二步（形状验证）：确认钥匙的形状与目标锁体的锁孔凹槽互补。
- 第三步（插入）：将钥匙图案平移到锁孔凹槽的位置，从指示器指定的方向插入，使钥匙恰好填满凹槽。钥匙原来的位置恢复为背景色。
- 第四步（融合变色）：钥匙插入后，锁体内部（不含边框的最外一圈像素）的颜色全部变为钥匙的颜色，而锁体的边框一圈保持原色不变。锁孔位置被钥匙颜色填充。Orange 方向指示器从输出中移除（变为背景色）。颜色标记像素也被移除。

Key insight: 解题包含三层推理——第一层是通过颜色标记建立钥匙到锁的匹配关系；第二层是理解钥匙形状与锁孔的互补关系以及插入的空间操作；第三层是发现插入后锁体内部变色为钥匙颜色的融合规则，这一层最为隐蔽，因为它改变的不是锁孔区域而是整个锁体内部。
</description>
</new_puzzle>
