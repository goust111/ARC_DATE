- `Input structure`：
  - 背景色为 black。
  - 网格中散布着若干条短折线片段，每条片段由一种独特颜色绘制（如 red、blue、green、yellow、orange 等）。
  - 每条片段是一段 2-5 像素长的直线或单次转折的 L 形，占据网格的不同位置，彼此不相连。
  - 每条片段的两个端点像素中，恰好有一个端点相邻位置（上下左右四方向之一）放置了一个 grey 像素作为"出口标记"，另一个端点相邻位置放置了一个 maroon 像素作为"入口标记"。
  - 网格角落有一个由 azure 像素构成的小方块（如 2x2），作为起始锚点。

- `Rule`：
  - 第一步：确定拼接顺序——按片段所用颜色在网格中出现的像素数量从少到多排序。若像素数量相同，则按片段最上方像素所在行号从小到大排序。
  - 第二步：从 azure 锚点位置开始，依次拼接各片段。拼接方式为：取当前序列末端点的 grey 出口标记方向，沿该方向延伸一个像素的间隙（间隙像素保持 black），然后将下一个片段平移，使其 maroon 入口标记对准该间隙像素的延伸方向下一格。片段在平移时保持原始朝向不变。
  - 第三步：输出中移除所有 grey 和 maroon 标记像素（恢复为 black），仅保留 azure 锚点和所有彩色片段像素。输出网格紧凑裁剪到包含所有非 black 像素的最小矩形。

- `Key insight`：像素计数决定拼接顺序，而出口/入口标记同时编码了每个片段的方向性和拼接朝向；解题者需要先从数量排序发现顺序规律，再从标记位置推断空间对接逻辑。

1. `main(grid)` 必须实现新题描述中的确定性转换规则，不能只识别 `generate_input()` 的固定模板。

3. 生成器必须保证输入满足 `main()` 的隐式假设：对象不重叠、不越界、特殊标记唯一或可区分、匹配关系无歧义、关键分支出现概率相同。
