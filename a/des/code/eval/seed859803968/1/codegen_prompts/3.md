  - 边框的四条边上各有若干"缺口"——即 grey 被替换为某种彩色像素的位置。每个缺口恰好 1 像素宽。缺口的颜色和所在边的位置编码了移动指令。
  - 网格内部有若干个 3x3 的单色实心方块，每个方块颜色各不相同，且与缺口中出现的颜色一一对应。

- `Rule`：
  - 第一步（读取指令序列）：按顺时针顺序（从左上角开始，沿上边→右边→下边→左边）依次读取边框上的所有缺口。每个缺口定义一条指令：缺口的颜色指定要移动的方块，缺口所在的边指定移动方向（上边缺口 → 向下移动，右边缺口 → 向左移动，下边缺口 → 向上移动，左边缺口 → 向右移动——即从缺口位置"射入"网格的方向）。
  - 第二步（执行移动）：按指令顺序逐条执行。被指定的 3x3 方块沿指定方向滑动，直到其边缘接触另一个方块的边缘或碰到 grey 边框内侧时停下。
  - 第三步（重叠处理）：如果方块滑动后与另一个方块在某些像素上重叠（因为两个 3x3 区域部分交叉），则重叠像素的颜色变为 yellow，非重叠部分保留各自原色。

- `Key insight`：边框缺口同时编码了"谁移动"和"往哪移动"，顺时针读取顺序决定了执行时序；重叠混色为 yellow 是验证最终状态正确性的关键线索。解题者需要先破解缺口的双重编码，再模拟顺序执行过程。
