Input structure:

- 在网格的四条边各有一个小型彩色标记像素（单像素），颜色与某个矩形对应，标明该矩形应被平移到的目标边。

Rule:
- 首先重建每个矩形的完整形状：被遮挡的矩形可以通过其可见的边缘片段推断出完整的矩形尺寸（至少有两条相邻边的部分可见）。

- 平移后的矩形按原始堆叠顺序重新绘制（底层先画，顶层后画），保持遮挡关系。
- 边缘标记像素在输出中被擦除。

Key insight: 解题者需要先从部分可见的边缘重建被遮挡矩形的完整形状（第一层推理），再通过边缘标记确定每个矩形的平移目标方向（第二层推理），最后保持正确的堆叠绘制顺序使遮挡关系一致（第三层推理）。

## 实现要求

1. `main(grid)` 必须实现新题描述中的确定性转换规则，不能只识别 `generate_input()` 的固定模板。
2. `generate_input()` 必须随机生成多样样例，不能固定死。随机维度应覆盖：网格大小、对象数量、位置、颜色、方向、形状参数或关键分支。

4. 禁止把 ARC 颜色 id 、亮度、拼写等当作人类不可见的数值语义参与排序、大小比较或隐藏映射。颜色变化必须有可见结构线索。注意颜色亮度、拼写等也是不可见信息，若描述中出现违规的颜色id或者亮度，可自行使用少量的固定颜色替代，但注意生成时要在三个以内输入输出网格中对所有变换100%覆盖度。
