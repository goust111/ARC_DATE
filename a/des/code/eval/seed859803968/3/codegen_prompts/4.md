Input structure:
- 背景为黑色。网格中散布着若干彩色碎片（4-连通区域），每个碎片由同一种非黑颜色的像素组成。
- 碎片来自若干个被切割的原始矩形图案。每个原始图案被沿一条锯齿线（仅沿正交方向走的阶梯形折线）切成恰好两个碎片。
- 同一原始图案的两个碎片颜色相同；不同原始图案使用不同颜色。
- 每个碎片在网格中被平移到了随机位置（无旋转、无翻转），碎片之间互不重叠。

Rule:
- 找出所有颜色相同的碎片对（每种颜色恰好出现两个碎片）。
- 对每对碎片，检查它们的锯齿边缘（即碎片边界中非矩形外框的那一侧）：两个碎片的锯齿边缘互为镜像互补。
- 将两个碎片沿锯齿边缘拼合，使它们恰好组成一个完整的实心矩形。拼合方向由锯齿边缘的朝向决定（锯齿沿垂直方向则左右拼合，沿水平方向则上下拼合）。
- 输出网格中，每个拼合后的矩形放置在其两个碎片中靠左上方那个碎片的原始位置，另一个碎片从原位置擦除。

Key insight: 解题者需要先通过颜色配对找到碎片组合（第一层），再通过分析锯齿边缘的互补形状确定拼合方式和方向（第二层）——颜色配对是显然的，但锯齿互补匹配和拼合定位需要空间推理。
