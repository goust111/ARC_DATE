Input structure:
- 背景为黑色。网格中有若干个小型实心正方形对象（3×3大小），每个正方形由单一颜色填充（如红色、绿色、蓝色等，各不相同）。
- 网格中另有若干条彩色直线段（水平或垂直，长度3到8像素，宽度1像素），每条线段的颜色与某个正方形对象的颜色不同。
- 每条线段的一端靠近网格边缘或空旷区域（"尾端"），另一端指向某个正方形对象且与该对象的某一面在同一行或同一列上（"指向端"），两者之间有黑色间隙。

Rule:
- 判断每条线段的指向：线段沿其延伸方向，从尾端向指向端看去，在指向方向上最近的正方形对象即为该线段的目标对象。
- 为目标对象添加一圈1像素宽的边框，边框颜色等于指向它的线段的颜色。若有多条线段指向同一对象，使用距离该对象最近的线段的颜色。
- 在每条线段的尾端（远离目标的那端）生成一个由目标对象原始填充颜色绘制的十字标记（"+"形，5个像素：中心+上下左右各1个像素）。
- 线段本身在输出中保持不变。

Key insight: 解题者先要判断每条线段的指向方向和对应的目标对象（第一层推理），再理解颜色的双向交换逻辑——线段颜色给目标当边框，目标颜色给线段尾端当装饰（第二层推理），形成一种间接的颜色映射关系。
