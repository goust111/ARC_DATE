- `Input structure`：
  - 背景色（bg）为网格中最常见的颜色。
  - 网格中有若干个由Grey颜色绘制的大型连通区域作为"模具"，每个模具内部有一块或多块bg色的空洞（空腔），空洞形状不规则。
  - 在模具外部的bg区域中，散布着若干由不同颜色绘制的小型连通图案（"碎片"），每种颜色的碎片恰好只有一组。
  - 每个模具的外边框上恰好有一个由某种非Grey非bg颜色着色的单像素标记点，该颜色与某组碎片颜色一致，用于指示哪组碎片属于哪个模具。
  - 每个模具内部的空腔形状恰好等于对应颜色碎片的形状的并集（碎片无需旋转，仅需平移即可拼合填满空腔）。

- `Rule`：
  - 通过模具边框上的颜色标记点，将每组碎片与对应模具配对。
  - 对每个模具，找到其内部的空腔区域（bg色连通域）。
  - 将对应颜色的所有碎片平移放入空腔中，使碎片恰好完整覆盖整个空腔，碎片之间不重叠，碎片不超出空腔。
  - 每块碎片的平移量需要解题者从形状匹配中推断——碎片在空腔中的摆放位置是唯一的。
  - 输出网格中，碎片出现在模具空腔内（用碎片自身颜色着色），碎片原来的位置变为bg。

- `Key insight`：首先需要通过颜色标记将碎片与模具配对（第一层推理），然后需要对每组碎片进行空间拼图，找到碎片在空腔中的唯一摆放方式（第二层推理）。模具空腔的形状是碎片形状的精确并集，这是验证正确性的关键约束。

1. `main(grid)` 必须实现新题描述中的确定性转换规则，不能只识别 `generate_input()` 的固定模板。

4. 禁止把 ARC 颜色 id 、亮度、拼写等当作人类不可见的数值语义参与排序、大小比较或隐藏映射。颜色变化必须有可见结构线索。注意颜色亮度、拼写等也是不可见信息，若描述中出现违规的颜色id或者亮度，可自行使用少量的固定颜色替代，但注意生成时要在三个以内输入输出网格中对所有变换100%覆盖度。
