- `description`：将网格中的彩色"种子"像素沿其所在封闭区域的边界生长出与区域周长等长的彩色轮廓线。
- `Input structure`：背景色为黑色。网格中有若干由灰色像素绘制的不规则封闭轮廓（每个轮廓是一圈连通的灰色像素，围出一个黑色内部区域）。每个封闭轮廓的灰色边线上恰好有一个像素被替换为某种彩色（如红色、蓝色、绿色等），这个彩色像素即为"种子"。不同封闭轮廓上的种子颜色各不相同。
- `Rule`：
  1. 找到每个封闭灰色轮廓及其上的彩色种子像素。
  2. 从种子像素出发，沿灰色轮廓的边线进行顺时针行走（沿着轮廓的连通路径），将经过的灰色像素逐一替换为种子的颜色。
  3. 行走恰好进行到轮廓总周长的一半时停止（即轮廓上恰好一半的像素被染成种子颜色，另一半保持灰色）。
  4. "顺时针"的定义：站在轮廓上面朝轮廓内部，向右手方向行走。
  5. 种子像素本身算作已染色的第一个像素。
- `Key insight`：解题者需要观察到每个轮廓恰好被染色了一半，并且染色总是从种子出发沿顺时针方向进行。关键的隐蔽性在于"恰好一半"这个规则——解题者需要通过比较多个样例中不同大小轮廓的染色长度来发现"周长的一半"这一模式，而不是一个固定的步数。顺时针方向则需要通过观察染色朝哪个方向展开来归纳。
