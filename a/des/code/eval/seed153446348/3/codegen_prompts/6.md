description：网格中多个同色连通区域各自包含一个方向标记像素，根据标记指示的方向将每个区域整体平移，平移距离等于该区域在垂直于平移方向上的跨度（宽或高），区域重叠时按面积大小决定遮挡关系。

Input structure：
- 背景色为 azure。网格中散布着若干彩色连通形状（4-连通），每个形状使用独特的颜色（如 red、green、blue、yellow 等）。
- 每个形状内部恰好有一个像素颜色为 maroon，该像素是方向标记。方向标记在形状边界框内的相对位置编码了平移方向：位于边界框顶边内侧 = 向上，底边内侧 = 向下，左边内侧 = 向左，右边内侧 = 向右。"内侧"指该标记像素紧贴边界框的对应边（即该像素所在行等于边界框的最小行则为顶边，等于最大行则为底边，所在列等于最小列则为左边，等于最大列则为右边）。

Rule：
- 第一步：识别每个彩色形状及其内部的 maroon 方向标记像素。
- 第二步：根据标记在形状边界框中的位置确定平移方向（顶边=上、底边=下、左边=左、右边=右）。
- 第三步：计算平移距离——等于该形状在垂直于平移方向上的跨度。即：若平移方向为上或下，则距离 = 形状边界框的宽度（列数）；若平移方向为左或右，则距离 = 形状边界框的高度（行数）。
- 第四步：将每个形状沿确定的方向平移确定的距离（maroon 标记像素在平移后恢复为该形状的颜色，即标记消失）。
- 第五步：若平移后多个形状占据同一像素，面积（像素数）较大的形状在上层（保留其颜色），较小的被遮挡。
- 超出网格边界的部分被裁剪。

Key insight：第一层推理需要发现 maroon 像素在边界框中的位置编码了方向（而不是直觉上以为的"朝 maroon 像素方向移动"），第二层推理需要发现平移距离与形状在正交方向上的跨度相关——这个"正交跨度决定距离"的规则需要跨多个样例比较才能归纳出来。
