description：将网格中散落的灰色形状按其内部孔洞数量分组，然后将同组形状排列到对应颜色图例所指示的目标行中，排列顺序由形状面积从小到大决定。

Input structure：
- 背景色为 black。网格分为左右两个区域，由一条垂直的 maroon 分隔线隔开。
- 左侧区域：散布着若干灰色（grey）形状，形状为 4-连通的不规则多边形，大小和孔洞数量各不相同。孔洞定义为完全被该形状像素包围的 black 连通区域。
- 右侧区域：在最左列有若干彩色方块（如 red、blue、green），每个方块占一个像素，纵向排列，它们之间间隔若干行。每个彩色方块右侧同一行上有一排与该方块孔洞数对应的小圆点（同色），圆点数量即为该颜色代表的孔洞数（例如 red 方块右侧有 0 个圆点表示 0 个孔洞，blue 方块右侧有 1 个圆点表示 1 个孔洞，green 方块右侧有 2 个圆点表示 2 个孔洞）。

Rule：
- 第一步：读取右侧颜色图例，建立"孔洞数 -> 颜色"的映射关系。
- 第二步：对左侧每个灰色形状，计算其孔洞数量（被形状完全围住的 black 区域个数）。
- 第三步：根据孔洞数将灰色形状分组，每组对应图例中的一种颜色。
- 第四步：输出网格中，右侧区域的每个颜色图例行变成一个目标行区域。将对应组的灰色形状按面积（像素数）从小到大，从左到右依次排列在该颜色行中，形状之间间隔 1 列。排列时形状顶部对齐该行顶部。
- 第五步：所有形状重新着色为对应图例颜色。左侧区域清空为 black。

Key insight：需要两步独立的非平凡推理——第一步是通过图例中圆点数量破译"孔洞数->颜色"的编码规则；第二步是发现同组形状按面积排序的规律。仅看单个样例容易遗漏排序规则。
</new_puzzle>
