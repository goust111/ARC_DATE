<description>
根据彩色边框内部的"门"（缺口）位置，将边框外的彩色种子精灵沿门的方向送入框内，种子在框内按照内壁颜色图例生长为对应形状的填充图案。

Input structure:
- 背景为黑色。网格中散布若干矩形彩色边框（每个边框由单一颜色的一圈像素构成，边框颜色各不相同）。
- 每个边框的某一条边上有一个宽度为1像素的缺口（"门"），门的位置在该边的某处。
- 每个边框外部、紧邻门的位置有一个小型彩色精灵（由2-4个像素组成的小图案，颜色与边框颜色不同）。
- 网格的一个角落有一个颜色图例区：图例由若干行组成，每行左侧是一个颜色色块（对应某个边框的颜色），右侧是一个小型模板图案（3×3或4×4的二值图案，前景色为该行的填充色）。

Rule:
- 第一步：对每个边框，识别其门所在的边（上/下/左/右）和门的位置。精灵从门外沿垂直于该边的方向进入边框内部。精灵被放置在门内侧、紧贴门的位置。
- 第二步：在颜色图例中找到与当前边框颜色匹配的行，读取该行的模板图案。
- 第三步：以精灵进入后的位置为起点，将模板图案以平铺（tile）方式填满整个边框内部空间。填充仅覆盖边框内部原本为背景色的区域，精灵本身保留不变。
- 输出时图例区域被清除为背景色。

Key insight:
边框颜色是查找图例的键，但图例提供的不是直接填充色而是一个需要平铺的二维模板——解题者必须先通过边框颜色匹配图例获取模板，再理解模板是周期性铺设而非单次放置。门和精灵的机制是第一层推理（方向与入口），模板平铺是第二层推理。
</description>

<description>
在网格中，多个彩色"信号塔"向四周发射同色射线，射线交叉处的颜色由交叉的两条射线的来源塔的相对高度决定——较高塔的颜色覆盖较矮塔的颜色。

Input structure:
- 背景为黑色。网格中散布若干竖直的彩色矩形条（"信号塔"），每个塔宽度为1像素、高度各不相同（2到8像素不等），颜色各不相同。
- 每个塔的顶部像素上方紧邻一个灰色像素，标记塔顶。
- 塔之间有足够的空间供射线延伸。

Rule:
- 每座信号塔从其顶部灰色标记像素的位置，向上、左、右三个方向各发射一条宽度为1像素的射线（射线颜色与塔身颜色相同）。射线沿直线延伸直到到达网格边界。射线不向下发射（塔身方向）。
- 射线经过其他塔的塔身时，不穿透塔身——射线在接触到任何塔身像素时停止。
- 当两条不同颜色的射线在同一像素交叉时（一条水平一条竖直），该像素的颜色取决于两条射线各自来源塔的高度：来源塔更高的那条射线的颜色胜出，覆盖在该交叉点上。
- 若两座塔高度相同，则交叉点颜色取水平射线的颜色。
- 灰色标记像素在输出中保留。

Key insight:
射线本身的绘制是直观的，但交叉点的颜色冲突解决需要解题者回溯到射线来源塔并比较塔的高度——一个在网格上肉眼可见但需要主动关联的属性。这构成了"射线传播"之上的第二层推理：高度优先级。
</description>

<description>
将网格中散落的彩色碎片拼回到一个带有彩色分区提示的目标框架中，每个碎片的放置位置由其颜色轮廓与框架分区边界的颜色匹配决定，碎片需要旋转到与分区形状吻合的方向。

Input structure:
- 背景为黑色。网格分为左右两个区域（由一列灰色像素分隔）。
- 左侧区域包含一个大型矩形框架，框架内部被彩色线段分割成若干不规则但互不重叠的分区。每个分区由唯一颜色的边界线围成，分区内部为背景色。每个分区的形状是由直角折线围成的简单多边形（所有边平行于坐标轴）。
- 右侧区域散布若干彩色小图案（"碎片"），每个碎片是一个由非背景色像素组成的连通块。每个碎片的边缘像素颜色与左侧某个分区的边界颜色相同，碎片内部像素为另一种统一的填充色。
- 每个碎片的形状恰好与某个分区的内部空间形状相同（可能经过0°/90°/180°/270°旋转）。

Rule:
- 对每个碎片，根据其边缘像素的颜色找到左侧框架中边界颜色匹配的分区。
- 将碎片旋转（0°/90°/180°/270°中的某个角度），使其形状与目标分区的内部空间完全吻合。
- 将旋转后的碎片放入对应分区内部，碎片的填充色像素填入分区的背景色区域。
- 输出仅为左侧框架区域（不含灰色分隔线和右侧区域），框架中所有分区都被对应碎片填满。

Key insight:
解题者需要完成三层推理：首先通过颜色匹配建立碎片与分区的对应关系；然后通过形状比对确定旋转角度；最后将碎片精确放置。颜色是配对的键，而旋转是隐蔽的——因为碎片可能已经接近正确方向，只差90°旋转，需要仔细比对才能发现。
</description>

<description>
网格中的彩色环形轨道上有多个"车厢"在运行，每个轨道的旋转方向由轨道中心标记决定；车厢移动的步数等于同一轨道上车厢的数量；车厢到达特殊颜色站点时改变自身颜色。

Input structure:
- 背景为黑色。网格中有若干互不重叠的封闭环形轨道，每条轨道由单一颜色的像素构成（轨道颜色各不相同），形成一个宽度为1像素的闭合环路（形状为矩形环、L形环或其他直角折线环路，所有转弯均为直角）。
- 每条轨道的环路所围成的内部区域中心附近有一个标记像素：红色标记表示顺时针旋转，蓝色标记表示逆时针旋转。
- 轨道上某些像素被替换为不同于轨道颜色的彩色像素，这些是"车厢"（每条轨道上有1到3个车厢）。
- 轨道上还可能有绿色像素作为"站点"，站点数量为0或1个。

Rule:
- 对每条轨道，数出该轨道上车厢的数量 N。
- 根据轨道中心的标记颜色确定旋转方向（红色=顺时针，蓝色=逆时针）。
- 将该轨道上的每个车厢沿轨道路径按确定的方向移动 N 步（每步移动到轨道上相邻的下一个像素位置）。
- 车厢移动后，若其新位置恰好在一个绿色站点上，则车厢颜色变为绿色（原站点被车厢占据，不再显示为绿色）。若车厢离开了站点，站点恢复绿色。
- 车厢移动后原来的位置恢复为轨道颜色。
- 中心标记像素在输出中保留。

Key insight:
第一层推理是识别环形轨道的走向和旋转方向（由中心标记编码）；第二层推理是发现移动步数并非固定常数，而是等于同轨道上车厢的数量——一个需要从多个样例中对比才能归纳出的规律；第三层是站点触发的颜色变化规则。
</description>

<description>
网格中若干彩色区域各自包含一个"印章"图案和若干散落的标记点；将印章图案依次盖印到每个标记点的位置，但每次盖印时印章需根据标记点相对于区域中心的象限进行对应的镜像翻转。

Input structure:
- 背景为黑色。网格被灰色的十字线（一条水平线和一条竖直线贯穿整个网格）分割为四个象限区域。
- 每个象限中有一个由某种颜色绘制的小型非对称图案（"印章"，大小约3×3到5×5像素），位于该象限的某个固定位置（如靠近十字线交叉点的角落）。
- 每个象限中还散布着1到3个孤立的单像素标记点，标记点的颜色与该象限的印章颜色相同。
- 印章图案是非对称的（即水平翻转或竖直翻转后与原图不同）。

Rule:
- 首先识别十字线将网格分成的四个象限，以及十字线的交叉点位置。
- 在每个象限中，识别印章图案（连通的多像素块）和标记点（孤立的单像素）。
- 对于每个标记点，以标记点为中心放置印章图案的一个副本。但放置前需要根据该象限相对于左上象限的位置关系进行镜像变换：
  - 左上象限：不翻转，直接放置原始印章。
  - 右上象限：将印章水平翻转后放置。
  - 左下象限：将印章竖直翻转后放置。
  - 右下象限：将印章同时水平和竖直翻转（等价于旋转180°）后放置。
- 印章副本放置时，若超出网格边界则裁剪；印章副本不覆盖灰色十字线像素和已有的印章图案。
- 输出中原始标记点被印章副本覆盖。

Key insight:
表面上看每个象限独立操作，但真正的隐蔽规则是翻转方式并非由标记点的局部属性决定，而是由象限在全局坐标系中的位置决定——左上不翻转、右上水平翻转、左下竖直翻转、右下双翻转。解题者需要跨象限比较印章副本的朝向才能归纳出这条全局对称性规则，这是超越"在标记点放置印章"这一显然操作之上的第二层推理。
</description>

<description>
网格中多组形状相同但大小不同的同色嵌套轮廓，根据轮廓的嵌套层级奇偶性进行差异化填充，同时最内层轮廓内部放置一个由该组颜色对应的图例符号。

Input structure:
- 背景为黑色。网格中有若干组彩色嵌套轮廓（每组使用同一种颜色）。每组由2到4个大小递减、形状相似（均为矩形）的同色空心矩形框组成，较小的框完全位于较大框的内部，形成同心嵌套结构。框与框之间有背景色间隔。
- 网格底部有一行图例：图例中每个条目由左侧一个颜色块（对应某组嵌套轮廓的颜色）和右侧一个小型符号图案（用灰色像素绘制的2×2或3×3图案，如实心方块、十字、对角线等）组成。
- 不同组的嵌套轮廓颜色各不相同，且不与图例中的灰色冲突。

Rule:
- 对每组嵌套轮廓，从最外层到最内层依次编号为第1层、第2层、第3层……
- 奇数层轮廓（第1、3层）：轮廓线保持原色不变。该轮廓与下一层轮廓之间的背景色间隔区域保持为背景色。
- 偶数层轮廓（第2、4层）：轮廓线变为黄色。该轮廓与下一层轮廓之间的背景色间隔区域填充为橙色。
- 最内层轮廓的内部区域：在图例中查找与该组颜色匹配的符号图案，将该符号图案居中放置在最内层内部（用灰色绘制）。若内部空间大于符号，则符号居中放置，多余空间保持背景色。
- 输出中图例行被清除为背景色。

Key insight:
解题者需要三层推理：第一层是识别嵌套轮廓的层级结构并建立奇偶分类（这需要从样例中归纳，因为奇偶性的视觉效果不是直观对称的）；第二层是发现偶数层不仅轮廓变色、间隔区域也要填充的双重变换；第三层是通过颜色匹配图例来确定最内层的符号填充内容。三层规则交织在一起，单看一个样例难以完全确定。
</description>

<description>
网格中的彩色路径网络存在多个断点，根据断点两侧路径段的颜色组合在颜色混合图例中查找结果色，用结果色的桥接段修补断点，同时桥接段的形状由断点的间距决定。

Input structure:
- 背景为黑色。网格中有若干条由彩色像素组成的路径（宽度为1像素），路径沿水平或竖直方向延伸，在转角处呈直角弯折。
- 每条路径可能由不同颜色的段组成（如一段红色、一段蓝色），颜色在路径上分段变化。
- 路径上存在若干断点——即路径中间有1到3个像素的背景色间隙，使路径在该处不连通。
- 每个断点的两侧分别是某种颜色的路径端点。
- 网格左上角有一个颜色混合图例：图例为一个小型网格，行标题和列标题各为一种颜色（用单像素表示），网格内的单元格显示行列颜色"混合"后的结果色。例如：红行蓝列的单元格为紫色（magenta），表示红+蓝=紫。

Rule:
- 对每个断点，识别断点两侧路径段的颜色（颜色A和颜色B）。
- 在颜色混合图例中查找（A行，B列）对应的结果色C。若A=B，则图例对角线上的值即为同色结果（通常仍为A）。
- 用颜色C的像素填补断点间隙，将两侧路径段连通。填补的像素沿两端点之间的直线方向排列（水平断点水平填补，竖直断点竖直填补）。
- 输出中图例区域保留不变。

Key insight:
第一层推理是识别路径断点及其两侧的颜色；第二层推理是发现修补色既不是左侧颜色也不是右侧颜色，而是需要查阅图例中两色交叉位置的"混合色"——这打破了"用相邻颜色延伸"的直觉预期。图例的行列对称性（A+B是否等于B+A）也可以作为额外的验证线索。
</description>
</new_puzzle>
