根据嵌套框架的层级深度，将散落的彩色碎片按面积排序后依次填入对应层级的封闭区域。

Input structure:
- bg = 最常见颜色（如 black）。
- 网格中有若干由同一种结构色（如 grey）绘制的嵌套矩形框架，框架之间互不接触，形成从外到内的多层嵌套（例如三层嵌套：最外层框、中间框、最内层框）。每层框架之间的间隔区域构成一个封闭的环形区域。框架线条为 1 像素宽。
- 框架外部散布着若干小型彩色精灵（sprite），每个精灵是一种独特的非 bg、非结构色的纯色连通块。精灵的数量恰好等于嵌套框架形成的封闭区域数量（包含最内层实心区域）。
- 每个精灵的面积（像素数）各不相同。

Rule:
- 首先识别嵌套框架结构，从外到内为每一层封闭环形区域编号（最外层环为第 1 层，次外层为第 2 层，以此类推；最内层实心区域为最后一层）。
- 将所有外部精灵按面积从大到小排序。
- 面积最大的精灵对应最外层（第 1 层）区域，次大对应第 2 层，以此类推。
- 将每一层封闭区域内的所有 bg 像素填充为对应精灵的颜色。框架本身保持结构色不变。

Key insight：解题者需要同时完成两个非平凡推理：（1）识别框架的嵌套层级结构并确定每层封闭区域的内外顺序；（2）发现精灵面积排序与嵌套深度之间的大到小对应映射关系——面积最大的填最外圈，面积最小的填最内层。面积排序需要主动计数并比较。
</description>

<description>
将网格中的彩色路径段按颜色配对，通过折叠网格使配对端点重合，输出折叠后的叠加结果。

Input structure:
- bg = 最常见颜色（如 black）。
- 网格中有一条由 grey 像素绘制的完整水平线或垂直线作为折叠线，将网格分为两个大小相等的半区（折叠线位于网格正中间）。
- 每个半区中各有若干彩色线段（长度 >= 2 的直线 4-连通块），每种颜色在两个半区中各恰好出现一次，形成同色配对。
- 每条线段的一个端点紧贴折叠线（与折叠线相邻），另一端延伸到半区内部。
- 两个半区中同色线段紧贴折叠线的位置不一定相同——它们沿折叠线方向可能错开。

Rule:
- 以折叠线为轴，将上半区（或左半区）翻折到下半区（或右半区）上。翻折后上半区的内容与下半区像素对齐重合。
- 移除折叠线本身。
- 叠加规则：bg + 彩色 = 彩色；同色重合 = 保持该颜色；两种不同彩色重合 = 取两色中在整个输入网格中总像素数较少的那种颜色（稀有色优先覆盖）。
- 输出为折叠叠加后的半区大小的网格。

Key insight：解题者需要三层推理——（1）识别 grey 线为折叠轴并理解折叠的几何翻转映射；（2）发现同色线段在两半区中分别出现并通过折叠合并；（3）发现颜色冲突时的解决规则：不是简单的上覆盖下，而是"全局更稀有的颜色胜出"，需要统计全图中各色像素总数。

<description>
利用网格边缘的旋转方向编码器和内部种子点的初始方向标记，生成同步螺旋扩展的彩色分区图案。

Input structure:
- bg = 最常见颜色（如 black）。
- 网格的四条边上各有一个 1x2 或 2x1 的方向指示块：由一个 red 像素和一个 green 像素相邻组成。从 red 到 green 的方向（上→下、左→右等）编码旋转方向：若沿顺时针读 red→green 的朝向，则旋转方向为顺时针；反之为逆时针。四个指示块编码相同的旋转方向。
- 网格内部有若干单像素的彩色种子点（颜色各不相同，非 bg、非 red、非 green、非 grey）。
- 每个种子点恰好有一个 4-连通相邻的 grey 像素，表示该种子的初始生长方向（从种子指向 grey 的方向）。

Rule:
- 移除所有 grey 像素和边缘的 red-green 方向指示块。
- 所有种子同时逐步生长：每一轮中，每个仍活跃的种子向其当前方向前进一格，将该 bg 像素着色为种子颜色。
- 每步之后检测：若当前方向的下一格已非 bg（被占用或越界），则按全局旋转方向转 90 度，再检测新方向。若新方向也被阻挡，该种子停止生长。
- 生长持续直到所有种子停止。先到达的像素归先到者所有。

Key insight：解题者需要发现三个独立的规则层：（1）边缘 red-green 像素对编码了全局旋转方向（需从四个边的一致编码中归纳）；（2）种子旁的 grey 像素编码了每个种子的初始前进方向（grey 被移除后不再可见）；（3）所有种子同步扩展且碰撞时先到先得，形成螺旋状的领地瓜分效果。
</description>

Rule:

Input structure:
- bg = 最常见颜色（如 black）。
- 网格被一条 grey 分隔线（水平或垂直）分为两个区域。
- 区域一（瓷砖区）：包含若干小型彩色矩形瓷砖（每块为独特颜色的纯色矩形块），散落在 bg 上。每块瓷砖的某一条边的中点位置有一个 maroon 单像素标记（如果边长为偶数则偏左或偏上）。
- 区域二（框架区）：包含一个由 grey 像素构成的矩形网格框架，内部被 1 像素宽的 grey 隔墙分成若干大小各异的格子。每个格子的某一条内壁中点位置也有一个 maroon 单像素标记。每个格子的尺寸恰好与某一块瓷砖匹配（可能需要旋转 90 度）。
- 从每块瓷砖的 maroon 标记引出一条 azure 像素绘制的连线（沿水平和垂直方向折线行走），穿过分隔线连接到某个格子的 maroon 标记。连线之间不交叉。

- 通过追踪每条 azure 连线，确定瓷砖与格子的一一配对关系。

Key insight：解题者需要完成三层推理：（1）追踪 azure 折线连线确定瓷砖与格子的配对关系；（2）比较瓷砖尺寸与格子尺寸判断是否需要 90 度旋转；（3）利用瓷砖和格子各自的 maroon 标记位置确定放置朝向——标记所在边必须面朝格子中标记所在壁的方向，这唯一确定了放置的旋转角度。

将散落的拼图碎片拼入模板轮廓，再根据碎片覆盖底层颜色地图的情况为每块碎片着色。

Input structure:
- bg = 最常见颜色（如 black）。
- 网格包含三类元素：
  1. 底层颜色地图：一个大型矩形区域被划分为若干不规则的彩色色块（如 red、blue、green、yellow 等），这些色块彼此相邻、无间隙地铺满整个矩形区域，形成一幅连续的彩色地图。每个色块是 4-连通的同色区域。
  2. 模板轮廓：在颜色地图之上叠加绘制了一个用 grey 像素勾勒的封闭不规则形状轮廓（1 像素宽边框）。轮廓内部区域的颜色地图被 bg 覆盖（即轮廓内部显示为 bg，看不到底层地图）。
  3. 碎片区：在颜色地图矩形区域之外的 bg 区域中，散布着若干 grey 纯色碎片（不规则形状的 4-连通块）。所有碎片面积之和恰好等于模板轮廓内部的面积。

Rule:
- 将所有 grey 碎片通过平移（不旋转、不翻转）拼入模板轮廓内部，使其恰好无间隙、无重叠地填满整个轮廓内区域。每块碎片的不规则形状使其在模板中的位置唯一确定。
- 拼合后，每块碎片对应了底层颜色地图（被 bg 遮盖但仍然存在）中的一片区域。对每块碎片，统计它覆盖的底层区域中每种颜色的像素数，取像素数最多的颜色作为该碎片的着色颜色。
- 输出为模板轮廓边界框大小的网格：grey 轮廓边框保留，轮廓内部每块碎片区域显示为各自确定的颜色，轮廓外部为 bg。

Key insight：解题者需要完成三层推理：（1）发现散落碎片可以平移拼入模板轮廓——碎片不可旋转翻转，形状唯一确定位置；（2）理解轮廓覆盖下仍有底层颜色地图，碎片的着色取决于其在地图上覆盖的颜色分布；（3）着色不是简单继承所有底层颜色，而是取占比最大的一种颜色（多数决规则），需要对每块碎片逐一判断。

<description>
通过管道网络中的信号传播和彩色门控过滤，确定各出口端口接收到的信号颜色。

Input structure:
- bg = 最常见颜色（如 black）。
- 网格中有一个由 grey 像素构成的管道网络：grey 像素形成 1 像素宽的水平和垂直线段，线段之间通过 T 形交叉或十字交叉相连，构成可分支的路径。
- 管道网络的左侧有若干入口端口（grey 管道的左端点），每个入口端口左侧紧邻一个彩色像素（如 red、blue、yellow 等不同颜色），表示该端口的输入信号颜色。
- 管道网络的右侧有若干出口端口（grey 管道的右端点），初始时出口端口像素为 grey。
- 管道线段中间的某些位置，grey 像素被替换为一个彩色像素（非 bg、非 grey），这些彩色像素嵌在管道路径中充当门控。

Rule:
- 每个入口的彩色信号沿管道向右传播。在 T 形和十字交叉处，信号分裂到所有相连的方向继续传播（不回头——不朝来的方向走）。
- 当信号到达门控像素时：若信号颜色与门控颜色相同，信号通过并继续传播；若颜色不同，信号在此被阻断，不再沿该分支传播。
- 若某个出口端口最终被恰好一种颜色的信号到达，该端口在输出中显示为该信号颜色。若被两种或以上不同颜色信号到达，显示为 maroon。若无任何信号到达，显示为 bg。
- 输出为仅包含所有出口端口的单列网格（从上到下对应出口从上到下的排列），每个像素为该端口的结果颜色。

Key insight：解题者需要逐层推理：（1）追踪管道网络拓扑，理解信号在分支处的分裂行为；（2）从样例中归纳门控的过滤规则——同色通过、异色阻断，这是核心隐蔽机制；（3）理解多信号汇合时的颜色判定——单色保留原色、多色变 maroon、无信号变 bg。
</description>
