- `Input structure`：
  - 网格被单像素宽的红色分隔线（贯穿整行或整列）划分为若干矩形面板（3-4 个面板）。
  - 每个面板内包含一个图案，背景为黑色：
    - 大多数面板中，图案看起来由两种颜色组成——一种是模板色 A，另一种是掩码色 B。实际上是：一个由颜色 A 构成的完整模板图案被一个由颜色 B 构成的较小掩码图案覆盖了部分位置（掩码像素替换了对应位置的模板像素）。
    - 每个面板的颜色 A 和颜色 B 可能不同，但被掩码覆盖前的完整模板形状在所有面板中相同（可能经过旋转或翻转）。
  - 恰好有一个面板只有模板层没有掩码层（仅由单一颜色构成）——这是"参考面板"。

- `Rule`：
  - 第一步（层分离）：在每个含有两种颜色的面板中，利用参考面板确定完整模板的形状。将面板中与模板不属于同一颜色的像素识别为掩码层。
  - 第二步（验证）：将掩码层像素还原为模板色后，所有面板的模板形状应与参考面板一致（允许旋转或翻转），以此验证分离的正确性。
  - 第三步（掩码裁剪输出）：对每个非参考面板，输出其掩码层的最小包围盒裁剪（保留掩码色）。多个裁剪结果按面板在原网格中从左到右、从上到下的顺序，用单像素宽的红色分隔线拼接。参考面板不出现在输出中。

- `Key insight`：表面上每个面板看起来像不同的复杂图案，但实际上它们都是同一个模板叠加了不同的掩码。参考面板（无掩码、单一颜色）是识别共享模板的钥匙；一旦发现模板是共享的，就能理解其他面板中"额外出现的第二种颜色"是掩码层，从而完成分离和裁剪。三层推理：发现共享模板 -> 分离掩码 -> 裁剪输出。

1. `main(grid)` 必须实现新题描述中的确定性转换规则，不能只识别 `generate_input()` 的固定模板。

3. 生成器必须保证输入满足 `main()` 的隐式假设：对象不重叠、不越界、特殊标记唯一或可区分、匹配关系无歧义、关键分支出现概率相同。
4. 禁止把 ARC 颜色 id 、亮度、拼写等当作人类不可见的数值语义参与排序、大小比较或隐藏映射。颜色变化必须有可见结构线索。注意颜色亮度、拼写等也是不可见信息，若描述中出现违规的颜色id或者亮度，可自行使用少量的固定颜色替代，但注意生成时要在三个以内输入输出网格中对所有变换100%覆盖度。

6. 若规则有多个分支，生成器不能长期固定成一个分支；应让分支在随机样例中合理出现，即每个分支出现的概率平均，所谓的分支是在描述中提到的分支，即规则语义中的不同情况。
