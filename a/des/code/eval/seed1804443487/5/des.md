- `Input structure`：
  - 黑色背景上有若干由单一颜色绘制的封闭矩形边框（边框颜色各不相同，如 blue、green、red 等）。

  - 每个种子像素位于矩形内部的某个象限（左上、右上、左下、右下）。

- `Rule`：
  - 对于每个封闭矩形，找到其内部的所有种子像素。
  - 判断每个种子像素相对于矩形中心所处的象限：左上、右上、左下、右下。
  - 将该种子的颜色涂满矩形边框中对应象限的那段边界：左上象限→顶边左半部分 + 左边上半部分；右上象限→顶边右半部分 + 右边上半部分；左下象限→底边左半部分 + 左边下半部分；右下象限→底边右半部分 + 右边下半部分。边的"半部分"以该边的中点为界（中点像素归两侧中靠近拐角的一侧）。
  - 若某段边界未被任何种子覆盖，则保持原来的边框颜色不变。
  - 种子像素本身在输出中被擦除（变为黑色）。

- `Key insight`：种子不是简单地"染色整条边"，而是通过其所处象限精确选择边框的四分之一弧段进行重新着色；解题者必须先识别种子的象限归属，再映射到边框的对应拐角段落——这个象限-到-拐角的映射关系是需要从样例中归纳出的非显然规则。
</new_puzzle>

- `Input structure`：

- `Rule`：
  - 对于每个彩色标记像素，找到与它同色的另一个标记像素；其中一个紧邻（4-连通相邻）某模板图案（"方向标记"），另一个孤立在另一子区域中（"目标标记"）。

  - 所有单像素标记在输出中被擦除（变为黑色）。模板图案保留在原位不变。

- `Key insight`：同色标记对构成"源→目标"链接，但旋转信息并非由目标位置决定，而是由源端标记相对于模板的接触方位编码——解题者需要同时解读配对关系（第一层）和方位编码旋转（第二层）两层信息。

- `Key insight`：解题者需要串联三步推理——首先通过颜色配对找到货物与容器的对应关系，其次识别缺口位置来确定滑入方向和对齐位置，最后理解货物会一直滑到对面内壁才停止。任何单独一步都不足以完成任务。

- `Input structure`：
  - 黑色背景。
  - 散布着 2-4 个单像素彩色"信号塔"（颜色各不相同，如 red、blue、green、yellow）。
  - 若干条由灰色（grey）像素组成的短线段（长度 3-6 像素），每条线段严格沿水平或垂直方向放置，充当"反射墙"。反射墙不与信号塔相邻。

- `Rule`：
  - 每个信号塔向上、下、左、右四个正方向各发射一条射线。
  - 射线沿直线逐像素传播：
    - 遇到反射墙的侧面（即射线行进方向垂直于墙壁朝向）时，射线偏转 90° 进入平行于墙壁的方向，偏转方向为射线碰撞点朝向墙壁中点的反方向（即远离墙壁中心的一侧）。
    - 遇到反射墙的端点（即射线行进方向平行于墙壁朝向，从端部撞入）时，射线直接终止。
    - 遇到网格边界时终止。
  - 每条射线最多偏转两次（防止无限反射）。
  - 射线路径上的所有像素（不含信号塔自身和灰色墙壁）着色为该信号塔的颜色。
  - 若两条不同颜色的射线经过同一像素，该像素最终着色为 maroon。同色射线交叉不做特殊处理。

- `Key insight`：解题者不能简单地画直线——必须逐段追踪每条射线，判断它碰到的是反射墙的侧面（偏转并继续）还是端点（终止），并理解偏转方向取决于碰撞点与墙壁中心的相对位置。所有射线绘制完毕后，交叉点的 maroon 混色是最终的叠加结果。
</new_puzzle>

- `description`：网格的边缘分布着 orange 像素绘制的箭头图案指向内部，网格内部散布着彩色像素点；每个箭头沿其指向方向扫描收集路径上的彩色像素，然后在箭头背面（朝向网格边缘的方向）紧密排列收集到的像素。

- `Input structure`：
  - 黑色背景。
  - 网格四条边上分布着若干由 orange 像素绘制的小型箭头图案，每个箭头占据 3×3 区域。箭头绘制方式：中间一行（或一列）为 3 个 orange 像素组成箭杆，箭杆前端（指向方向）的两侧各有 1 个 orange 像素形成箭头尖。例如指向右的箭头：第 1 行第 3 列为 orange，第 2 行第 1、2、3 列为 orange，第 3 行第 3 列为 orange，其余为黑色。
  - 箭头始终从网格边缘指向内部（上边缘的箭头指向下，下边缘的指向上，左边缘的指向右，右边缘的指向左）。
  - 网格内部散布着各种颜色的单像素点（如 red、blue、green、yellow、magenta），不与箭头重叠。

- `Rule`：
  - 每个箭头沿其指向方向，从箭头尖端沿箭杆中轴线延伸到网格对面边缘，扫描该直线上所有非黑色、非 orange 的彩色像素，按距离箭头从近到远的顺序收集。
  - 收集到的彩色像素从原位擦除（变为黑色）。
  - 在箭头的背面（箭尾朝向网格边缘的方向），沿箭杆中轴线的延长线方向，从紧邻箭头 3×3 区域外侧的第一个像素开始，按收集顺序依次紧密放置这些彩色像素（每个像素占一格，向边缘方向排列）。若背面空间不足（到达网格边缘），多余像素丢弃。
  - 箭头本身（orange 像素）保持不变。
  - 若两个箭头的扫描线交叉于同一彩色像素，该像素归距离它更近的箭头收集（若等距，归行号更小的箭头；行号也相同则归列号更小的箭头）。

- `Key insight`：箭头不是将物体向前推动的"力"，而是沿指向方向扫描的"吸收器"——它收集前方的像素后在自己背后吐出。输出位置在箭头背面而非前方，这与"箭头推动物体"的直觉预期完全相反，是解题者需要突破的认知陷阱。
</new_puzzle>
