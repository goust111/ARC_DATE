- `description`：将网格中的闭合环路按嵌套层级交替染色，同时环路上的缺口标记决定染色从哪一层开始反转。
- `Input structure`：
  - 背景色为 Black。
  - 网格中有若干由 Grey 像素绘制的闭合矩形环路（每个环路是 1 像素宽的矩形框）。
  - 环路之间存在嵌套关系：小环路被大环路包围，形成多层嵌套（如 3-4 层）。
  - 某些环路上有一个单像素的彩色标记（非 Grey、非 Black，如 Red），替换了该环路边框上的一个 Grey 像素。
- `Rule`：
  - 确定环路的嵌套层级：最外层为第 1 层，被其直接包围的为第 2 层，以此类推。
  - 默认染色规则：奇数层（1, 3, 5…）的环路染为 Blue，偶数层（2, 4, 6…）的环路染为 Yellow。
  - 若某个环路上有 Red 标记，则从该层开始，该环路及其内部所有更深层的环路的染色规则反转（Blue 变 Yellow，Yellow 变 Blue）。
  - 若多个不同层级的环路都有 Red 标记，反转效果叠加（二次反转等于恢复原色）。
  - 标记像素本身保持 Red 不变。环路之间的 Black 区域保持不变。
- `Key insight`：解题需要两层推理——第一层是发现嵌套层级决定环路颜色的交替规律（奇蓝偶黄），第二层是发现 Red 标记会触发从该层起向内的颜色反转。仅从外层观察交替染色容易归纳出第一层规则，但内层的"异常"染色必须结合标记位置才能解释，这构成真正的认知挑战。

## 实现要求

1. `main(grid)` 必须实现新题描述中的确定性转换规则，不能只识别 `generate_input()` 的固定模板。
2. `generate_input()` 必须随机生成多样样例，不能固定死。随机维度应覆盖：网格大小、对象数量、位置、颜色、方向、形状参数或关键分支。
3. 生成器必须保证输入满足 `main()` 的隐式假设：对象不重叠、不越界、特殊标记唯一或可区分、匹配关系无歧义、关键分支出现概率相同。
4. 禁止把 ARC 颜色 id 、亮度、拼写等当作人类不可见的数值语义参与排序、大小比较或隐藏映射。颜色变化必须有可见结构线索。注意颜色亮度、拼写等也是不可见信息，若描述中出现违规的颜色id或者亮度，可自行使用少量的固定颜色替代，但注意生成时要在三个以内输入输出网格中对所有变换100%覆盖度。
