- `Input structure`：
  - 背景色为 Black。网格中有若干由 Grey 像素围成的不规则封闭区域（Grey 像素构成厚度为 1 的完整围墙）。
  - 每个封闭区域内部散布着 1 至 3 个不同颜色的"种子"像素（可能是 Red、Blue、Green、Yellow、Orange 等）。
  - 网格的最上方一行是色带图例：每个图例单元由两个像素组成——左侧像素为某种颜色 C，右侧像素为 Maroon、Azure、Magenta 或 Green 中的一种方向色 D。方向色的编码规则为：Maroon = 向上、Azure = 向右、Magenta = 向下、Green = 向左。
  - 同一封闭区域内不会有两个颜色相同的种子。

- `Rule`：
  - 第一步：解析顶部色带图例，建立颜色 C → 方向 D 的映射。
  - 第二步：对每个封闭区域，收集其内部所有种子像素。对于每个种子，根据其颜色 C 查图例得到生长方向 D。计算该种子沿方向 D 到最近一面 Grey 墙壁（或区域边界）的像素距离。
  - 第三步：在同一区域内，按"距墙距离从小到大"的顺序依次处理种子（距离相同则按种子在网格中从上到下、从左到右的顺序）。每个种子沿方向 D 逐格填充 Black 像素为自身颜色 C，直到遇到 Grey 墙壁或已被其他种子填充的像素为止。种子自身原始位置也保留其颜色。
  - 第四步：图例行在输出中保留不变；Grey 围墙保留不变。

- `Key insight`：需要先从图例中归纳出颜色→方向的编码，再发现区域内多个种子的生长优先级取决于它们距目标墙壁的距离——近墙种子先填充，从而"挡住"远墙种子的路径，产生不均匀的领地划分效果。两层推理缺一不可。
