  - 每个彩色区域的底边外侧（紧贴底边下方一行）有 1 至 3 个 Yellow 刻度标记像素，等间距排列。刻度数量 K 表示缩放倍率：1 个 Yellow = 原尺寸，2 个 = 放大 2 倍，3 个 = 放大 3 倍。

  - 第四步：按照彩色区域在网格中从左到右的顺序，依次将缩放后的暗纹绘制到 Grey 画布内部，居中放置。后绘制的暗纹覆盖先绘制的暗纹（重叠区域取后者颜色）。
