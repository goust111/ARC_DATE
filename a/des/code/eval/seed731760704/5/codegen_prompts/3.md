- 背景为 black。若干条由不同颜色（如 red、blue、green、orange 等）构成的单像素宽正交折线路径（仅沿水平和垂直方向延伸，可以有直角拐弯），各路径颜色不同。
- 网格中还散布着若干由 maroon 像素构成的实心正方形方块（边长为 2 至 4 不等），每个方块紧贴（8-邻接）在某条彩色路径的某一段上。每个方块旁边（4-邻接方向上）恰好有一个与某条路径同色的单像素标记点，该标记点指示这个方块作用于哪条路径。

Rule:
- 第一步（指令解读）：对每个 maroon 方块，找到其 4-邻接方向上的彩色标记点，该标记点的颜色即为目标路径颜色。方块的边长 N 即为平移距离。
- 第二步（定位剪切点）：在目标颜色路径上，找到距离 maroon 方块最近的路径像素，该像素即为剪切点。
- 第三步（剪切与平移）：在剪切点处将路径断开为两段。较短的那一段沿路径在剪切点处的延伸方向（远离较长段的方向）平移 N 个像素。平移后的路径段用原色绘制；原位置处留下的空隙用黑色填充。
- 若两段等长，则移动方块标记点一侧的那段。
- maroon 方块和彩色标记点在输出中被移除（变为黑色）。

Key insight: 解题者需要分三层推理——先通过标记点颜色确定方块对应哪条路径（颜色匹配层），再理解方块边长编码平移距离（尺寸编码层），最后理解剪切位置和平移方向的确定方式（空间操作层）。
