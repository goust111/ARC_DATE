- `Key insight`：种子像素同时承担两个角色——它的颜色指向网格边缘的模板查找键，它的位置决定平铺的相位锚点。解题者需要先建立颜色到模板的映射，再理解锚点对齐的平铺机制。

- `Input structure`：
  - bg = 最常见颜色（黑色）。
  - 网格边缘上有若干彩色"起点像素"，每个颜色恰好出现两次，分布在网格的不同边缘。
  - 网格内部由灰色像素组成若干条水平和垂直的通道（宽度为1像素），这些通道相互交叉形成网络。
  - 每个起点像素恰好与一条灰色通道的端点相邻。
  - 在部分通道交叉点处，有一个小的"交换标记"（用 maroon 色像素标记），表示该交叉点是活跃的。

- `Rule`：
  - 每个彩色起点像素沿其相邻的灰色通道发射一条同色射线，射线沿通道行进。
  - 当射线到达一个无交换标记的普通交叉点时，射线保持原方向直行通过。
  - 当射线到达一个有交换标记的交叉点时，射线转向90度（若原来水平行进则改为垂直，反之亦然）。若交叉点有两条可选的转向方向，射线选择能让它更接近网格中心的那个方向。
  - 射线行进直到到达另一个网格边缘为止。
  - 输出网格中，所有灰色通道保持不变，每条射线的路径被绘制为对应的颜色，起点和终点像素保留。交换标记在输出中被移除（变为灰色）。

- `Key insight`：解题者需要先识别通道网络的拓扑结构和交换标记的位置，然后模拟每条射线在交换点处的方向切换，才能确定最终路径。交换标记的存在使得路径不是简单的直线延伸，而是需要逐步追踪的动态过程。

- `Input structure`：

  - 网格中有若干同心嵌套的矩形框架，每个框架由不同颜色的像素绘制（例如从外到内依次为 blue、red、green、yellow），框架之间有背景色间隔。

  - 最外层框架的外侧紧邻一个小型彩色图案（3x3至4x4的非对称形状），颜色为 orange。

- `Rule`：
  - 从最外层框架开始，观察其缺口所在的边：上边缺口代表不旋转（0度），右边缺口代表顺时针旋转90度，下边缺口代表旋转180度，左边缺口代表顺时针旋转270度。
  - 将种子图案按照最外层框架缺口指示的角度旋转，得到第一次变换后的图案。
  - 进入下一层框架，再按该层缺口指示的角度对当前图案进行额外旋转（旋转是累积的）。
  - 依次对每一层框架重复上述操作，直到到达最内层。
  - 在最内层框架内部的中心位置绘制最终旋转后的图案（保持 orange 色）。
  - 所有框架和外部种子图案在输出中保持不变。

- `Key insight`：每层框架的缺口位置编码了一次旋转操作，解题者必须逐层解读缺口方位并累积旋转角度，才能确定最终图案的朝向。这是一个多层级的顺序推理过程，而非一步到位的变换。

  - 网格中还有若干单独的"货物"像素，每个货物是一个1x1的彩色像素，颜色与某个时钟中心颜色C相同。每种颜色C恰好有一个时钟和一个货物。

  - 时钟对象在输出中保持不变，货物的原始位置变为背景色。

- `Key insight`：解题者需要完成两层推理——首先从3x3方块中 maroon 像素的位置解码出方向信息，然后通过中心颜色建立时钟与货物的配对关系。方向解码和颜色配对是两个独立的非平凡归纳步骤。

- `description`：根据"染色源"的颜色和管道网络的连通性，将混合颜色传递到"容器"中。

- `Input structure`：
  - bg = 最常见颜色（黑色）。
  - 网格中有若干"染色源"：每个是一个2x2的实心彩色方块（颜色为 red、blue 或 yellow 之一）。
  - 有若干"容器"：每个是一个3x3的灰色空心方框（中心像素为背景色）。
  - 染色源和容器之间由灰色像素组成的单像素宽管道连接。管道可以水平、垂直延伸并在交叉处以 T 形或十字形分叉。
  - 每条管道从某个染色源的边缘出发，经过若干分叉后连接到一个或多个容器。一个容器可能同时被多条管道从不同染色源连接。

- `Rule`：
  - 追踪每条管道的连通性，确定每个容器被哪些染色源连接。
  - 若容器只被一个染色源连接，容器中心填充该染色源的颜色。
  - 若容器被两个不同颜色的染色源连接，容器中心填充混合色：red + blue = magenta，red + yellow = orange，blue + yellow = green。
  - 若容器被三个不同颜色的染色源连接（red + blue + yellow），容器中心填充 maroon。
  - 若容器被同一颜色的多个染色源连接，视为只有一种颜色，不影响混合结果。
  - 管道、染色源和容器边框在输出中保持不变。

- `Key insight`：解题者首先需要追踪管道网络的连通关系（这在分叉复杂时并非显然），然后需要发现颜色混合的规则体系。两层推理——拓扑连通性判断和颜色组合映射——共同决定最终输出。

  - 若干"信号塔"：每个信号塔是一个2x1或1x2的彩色像素对，方向表示天线朝向（水平放置的向右发射，垂直放置的向上发射）。信号塔颜色各不相同。
  - 若干"棱镜"：每个棱镜是一个由 grey 像素组成的2x2方块，方块的四个角中恰好有一个角被替换为 maroon 像素。maroon 像素所在的角位置决定偏转方向：左上角或右下角表示信号线被沿主对角线方向反射（水平变垂直、垂直变水平，类似"\"镜面）；右上角或左下角表示信号线被沿副对角线方向反射（类似"/"镜面）。
  - 网格角落有一个"颜色映射表"：若干行，每行两个相邻的彩色像素 A-B，表示颜色 A 经过棱镜后变为颜色 B。

- `Rule`：
  - 每个信号塔从天线方向发射一条信号线，颜色与信号塔相同，信号线沿直线延伸。
  - 当信号线到达棱镜时，信号线在棱镜位置停止。从棱镜的出射侧（由 maroon 角位置决定的反射方向）发出新的信号线继续延伸。
  - 经过棱镜后，信号线的颜色按照颜色映射表变换。若映射表中没有对应条目，颜色保持不变。
  - 信号线延伸直到碰到网格边界、另一个信号塔、或已有的信号线像素为止。
  - 信号塔、棱镜和颜色映射表在输出中保持不变。

- `Key insight`：解题者需要同时掌握三层规则：天线朝向决定初始发射方向，棱镜的 maroon 角位置编码反射方向，颜色映射表控制经过棱镜后的颜色变换。三者缺一不可，且需要从样例中分别归纳。
</new_puzzle>
