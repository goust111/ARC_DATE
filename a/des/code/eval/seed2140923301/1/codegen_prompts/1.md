  - 网格中散布若干由单一非bg颜色构成的封闭矩形围栏（宽度为1像素的空心矩形框）。每个围栏恰好在一条边上有一个1像素宽的缺口（即该边上缺少一个像素）。
  - 每个围栏内部含有若干散布的"种子"像素，每个种子颜色各不相同，且与围栏颜色和bg均不同。
  - 围栏外部为纯bg。

- `Rule`：
  - 第一层推理——缺口定位与方向：找到每个围栏边框上唯一的缺口像素位置，该缺口所在边决定生长方向（缺口在顶边则向上生长，缺口在底边则向下，缺口在左边则向左，缺口在右边则向右）。
  - 第二层推理——种子计数与枝条长度：统计围栏内部种子像素的总数量 N。从缺口位置沿生长方向向外画一条长度恰好为 N 个像素的直线段。
  - 第三层推理——种子颜色排序：枝条上的每个像素按照种子在围栏内部从缺口侧到对侧的扫描顺序依次着色。具体而言：缺口在顶边，则按种子所在行从上到下、同行从左到右的顺序排列；缺口在底边，则按行从下到上、同行从左到右；缺口在左边，则按列从左到右、同列从上到下；缺口在右边，则按列从右到左、同列从上到下。枝条第1个像素（紧邻缺口的那个）对应排序后的第1个种子颜色，依次类推。
  - 围栏和内部种子在输出中保持原样不变。

- `Key insight`：缺口同时编码了三重信息——枝条的生长方向、种子的扫描起始侧、以及扫描的主轴与副轴——解题者需要发现缺口方向与种子空间排序之间的系统性关联。

4. 禁止把 ARC 颜色 id 、亮度、拼写等当作人类不可见的数值语义参与排序、大小比较或隐藏映射。颜色变化必须有可见结构线索。注意颜色亮度、拼写等也是不可见信息，若描述中出现违规的颜色id或者亮度，可自行使用少量的固定颜色替代，但注意生成时要在三个以内输入输出网格中对所有变换100%覆盖度。
