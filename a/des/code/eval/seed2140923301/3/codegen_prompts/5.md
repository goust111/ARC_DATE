  - 画布的顶部边框外侧（紧贴边框上方）有一行颜色标记像素，从左到右排列。每个标记像素的颜色对应印章库中某个印章的颜色。标记可以重复。

- `Rule`：
  - 第一步（印章匹配）：读取画布顶部的颜色标记序列，从左到右依次处理。每个标记颜色对应印章库中同色的印章图案。
  - 第二步（首次盖印）：第一个印章盖印到画布内部的左上角（印章的左上角与画布内部区域的左上角对齐）。

- `Key insight`：颜色标记序列同时编码了盖印的顺序和内容，而每次盖印的位置并非固定——它取决于前一次盖印结果的几何形状，形成链式依赖。解题者需要先发现标记→印章的颜色对应关系，再发现"上一个印章的右下角锚点决定下一个印章的放置位置"这一动态定位规则。

1. `main(grid)` 必须实现新题描述中的确定性转换规则，不能只识别 `generate_input()` 的固定模板。

3. 生成器必须保证输入满足 `main()` 的隐式假设：对象不重叠、不越界、特殊标记唯一或可区分、匹配关系无歧义、关键分支出现概率相同。
4. 禁止把 ARC 颜色 id 、亮度、拼写等当作人类不可见的数值语义参与排序、大小比较或隐藏映射。颜色变化必须有可见结构线索。注意颜色亮度、拼写等也是不可见信息，若描述中出现违规的颜色id或者亮度，可自行使用少量的固定颜色替代，但注意生成时要在三个以内输入输出网格中对所有变换100%覆盖度。
