Input structure:

- 每个区域旁边紧邻放置一个单独的grey像素，称为"阴影标记"。阴影标记位于区域的某一侧（上、下、左、右之一），与区域有且仅有一个像素相邻。
- 网格某个角落有一个2x2的"示范方块"：左上和右下为black，左下和右上为该方块所属颜色——这是条纹图案的模板（对角交替）。

Rule:
- 第一步（判定骨架方向）：对每个细长区域，判断其主要延伸方向（水平或垂直）。判定方法为：区域的外接矩形中，较长的边对应骨架方向。若外接矩形为正方形，则骨架方向为水平。
- 第二步（确定阴影方向与深度）：阴影标记相对于区域的方位（上/下/左/右）决定阴影投射方向。阴影的"深度"（即条纹延伸的格数）等于区域在骨架方向上的像素长度除以2（向下取整），最少为1。
- 第三步（绘制条纹阴影）：从区域的每个边缘像素出发，沿阴影方向依次绘制深度个像素。这些像素按照与起始边缘的距离交替使用两种颜色：奇数距离（1, 3, 5...）用区域本身的颜色，偶数距离（2, 4, 6...）用grey。若阴影像素与其他区域或其阴影重叠，后绘制的覆盖先绘制的。绘制顺序按区域面积从小到大。

Key insight:
骨架方向影响阴影深度，而阴影标记的位置决定阴影方向——这两个要素看似无关却共同决定输出。解题者容易将阴影标记误解为指示骨架方向，实际上二者是独立的维度。条纹的交替模式来自角落的示范方块，需要解题者将一个远离区域的全局模板与局部操作关联起来。
