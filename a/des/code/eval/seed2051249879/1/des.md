- `description`：根据彩色种子像素的颜色在封闭区域内生长出与种子颜色对应的纹理图案，纹理的朝向由种子在区域内的相对位置决定。

- `Input structure`：
  - 背景色 = black。网格中有若干由 grey 像素围成的封闭矩形区域（grey 边框宽度为 1 像素）。
  - 每个矩形区域内部恰好有一个单像素"种子"，颜色为 red、blue 或 green 之一。
  - 网格中另有一个独立的"图例区"：三个小矩形色块分别标注 red、blue、green，每个色块旁边紧贴一个 3x3 的纹理样板（由该颜色和 black 组成的二值图案）。

- `Rule`：
  - 第一层推理——颜色-纹理映射：从图例区读取每种颜色对应的 3x3 纹理样板。
  - 第二层推理——朝向确定：种子像素在其所属矩形内部的位置决定纹理的朝向。将矩形内部划分为四个象限（左上、右上、左下、右下）；种子落在哪个象限，纹理就以该象限方向为"起始角"进行 0°/90°/180°/270° 旋转（左上 = 0°，右上 = 90°，右下 = 180°，左下 = 270°）。
  - 将旋转后的 3x3 纹理以平铺方式填满整个矩形内部（裁剪到边界），种子像素自身也被纹理覆盖。

- `Key insight`：解题者需要先从图例区归纳出颜色→纹理的对应关系，再从多个样例中发现种子位置决定纹理旋转角度的规律——两层信息缺一不可，且单看一个样例无法区分旋转规则。
</new_puzzle>

<new_puzzle>
- `description`：将散落的彩色碎片沿"管道"滑入对应颜色的容器中，碎片经过管道弯折处时会被镜像翻转。

- `Input structure`：
  - 背景色 = azure。网格中有若干由 orange 像素绘制的单像素宽"管道"，管道由水平段和垂直段组成，每个管道恰好有一个直角弯折。
  - 每条管道的一端（开口端）紧邻一个小型彩色碎片（连通的非背景色像素块，形状不规则，占 3-6 个像素）。管道的另一端连接一个同色的 "容器"——与碎片同色的单像素宽空心矩形框。
  - 碎片颜色与容器颜色一一配对（如 red 碎片对应 red 容器）。

- `Rule`：
  - 第一层推理——运动方向：碎片沿管道从开口端向容器端滑动。碎片整体沿管道第一段的方向（水平或垂直）平移，直到碎片的前沿到达弯折处。
  - 第二层推理——弯折翻转：碎片经过弯折时，以弯折点所在的行或列为轴进行镜像翻转（水平段转垂直段时沿垂直轴翻转，垂直段转水平段时沿水平轴翻转），然后继续沿管道第二段方向滑动。
  - 碎片最终停在容器内部（碎片的前沿紧贴容器的远端内壁），管道像素保持不变。

- `Key insight`：碎片不仅沿管道移动，还在弯折处发生镜像翻转——解题者需要从样例中注意到碎片形状在弯折前后的左右（或上下）对称变化，才能正确预测最终形态。方向判定本身是显然的，但翻转规则需要从多个样例中对比归纳。
</new_puzzle>

<new_puzzle>
- `description`：在网格中识别"母图案"和若干"子标记"，根据子标记的排列顺序对母图案进行逐步裁剪，最终输出剩余部分。

- `Input structure`：
  - 背景色 = black。网格左侧有一个较大的多色矩形图案（"母图案"，由 2-4 种非背景色组成，尺寸约 6x6 至 10x10）。
  - 网格右侧有 2-4 个小型标记，每个标记是一个单色的 L 形（3 像素组成的直角形状，占据 2x2 区域中的三个格子，缺失一角）。
  - 这些 L 形标记从上到下排列，每个标记的颜色与母图案中使用的某种颜色一一对应。
  - 每个 L 形的缺角方向为四个方向之一（左上、右上、左下、右下）。

- `Rule`：
  - 第一层推理——操作顺序：L 形标记从上到下的排列顺序即为操作的执行顺序。
  - 第二层推理——裁剪方向：每个 L 形的缺角方向指示对母图案进行"象限保留"：缺角朝左上 → 保留母图案的左上四分之一区域（丢弃其余）；缺角朝右下 → 保留右下四分之一区域，以此类推。保留操作基于当前剩余图案的中心点进行对半切割。
  - 第三层推理——颜色验证：每步裁剪后，检查被保留区域中是否包含与当前 L 形标记同色的像素；若包含则裁剪有效，进入下一步；若不包含则跳过该步（母图案保持不变进入下一步）。
  - 输出为所有裁剪步骤执行完毕后的剩余图案（紧凑输出，去除多余背景行列）。

- `Key insight`：解题者需要同时发现三个非显然的规律：标记的纵向排列编码了操作顺序，L 形缺角编码了空间裁剪方向，而标记颜色与母图案颜色的匹配关系则控制着该步是否实际执行——这三层结构互相嵌套，单独看任何一层都无法完整还原规则。
</new_puzzle>

<new_puzzle>
- `description`：根据"染色源"像素的位置和颜色，沿线段网络进行限距传播染色，染色在交叉点处分支并在冲突处按优先级混合。

- `Input structure`：
  - 背景色 = black。网格中有一个由 grey 像素组成的单像素宽线段网络，线段严格沿水平或垂直方向延伸，线段之间通过交叉点（十字或 T 形连接）相连。
  - 网络的若干末端（只有一个邻居的 grey 像素）上放置了"染色源"——一个非 grey 非背景色的单像素（如 red、blue、green 等），直接覆盖在末端 grey 像素上。
  - 每个染色源的颜色互不相同。

- `Rule`：
  - 第一层推理——传播距离：每个染色源从其所在末端开始，沿 grey 线段向网络内部传播自己的颜色，将经过的 grey 像素染为自己的颜色。传播距离等于该染色源所在线段（从末端到第一个交叉点）的长度（像素数）。
  - 第二层推理——交叉点分支：当染色到达一个交叉点时，颜色继续沿所有分支方向传播，剩余传播距离 = 原始距离 - 已走距离。交叉点本身也被染色。
  - 第三层推理——冲突解决：若两种颜色同时到达同一个像素（剩余距离都 >= 0），则该像素染为两种颜色中传播距离更大（原始线段更长）的那种颜色；若传播距离相同，则染为 yellow 表示"混合"。
  - 未被任何颜色到达的 grey 像素保持 grey 不变。

- `Key insight`：解题者首先需要发现传播距离由源头所在线段的长度决定（而非固定值），然后需要理解颜色在交叉点处的分支传播与距离衰减机制，最后需要归纳出冲突解决的优先级规则——三层机制逐步叠加，每层都需要从样例中独立推断。
</new_puzzle>

- `description`：识别网格中的"印章"和"画布"，将印章按画布边框上缺口的位置和方向盖印到画布内部，印章的叠加顺序由缺口尺寸决定。

- `Input structure`：
  - 背景色 = black。网格中有一个较大的 green 空心矩形框（"画布"，内部为背景色，边框宽 1 像素）。
  - 画布边框上有 2-4 个缺口（边框上连续 1-3 个像素被替换为其他颜色，如 red、blue、orange、maroon）。每个缺口恰好在边框的某一侧（上、下、左、右）。
  - 网格中画布外部散布着 2-4 个小型单色图案（"印章"），每个印章的颜色与某个缺口的颜色相同，形状为不规则的连通块（3-8 像素）。

- `Rule`：
  - 第一层推理——印章与缺口配对：颜色相同的印章与缺口配对。每种颜色恰好出现一对。
  - 第二层推理——盖印位置与方向：每个印章从其配对缺口的位置"推入"画布内部。推入方向为从缺口指向画布中心的方向（上边缺口 → 向下推入，左边缺口 → 向右推入，等）。印章被放置的位置为：印章沿边框方向上的中心与缺口的中心对齐，沿推入方向紧贴边框内侧。
  - 第三层推理——叠加顺序：多个印章在画布内部可能重叠。缺口尺寸越大（占据的边框像素越多），该印章越后盖印（即显示在最上层）。若缺口尺寸相同，则按顺时针方向（从画布上边开始）排列，越靠后的越在上层。
  - 输出时画布边框恢复为完整的 green（缺口被填回），内部显示叠加后的印章图案。

- `Key insight`：解题者需要先发现颜色配对关系（较为直观），再推断出缺口位置编码了印章的放置方向和对齐位置，最后从重叠区域的颜色表现中归纳出缺口尺寸决定叠加优先级的规则——前两层虽然视觉上可观察，但第三层的优先级规则需要仔细对比多个样例中的重叠行为才能发现。
</new_puzzle>

- `description`：在网格中找到配对的"钥匙"和"锁"图案，用钥匙的形状从锁的实心区域中"减去"对应部分，然后将被减去的碎片按锁的朝向弹射出去。

- `Input structure`：
  - 背景色 = azure。网格中散布着若干成对的小型图案：
  - "锁"：由某种颜色（如 red、green、maroon 等）填充的实心矩形块（约 3x3 至 5x5），矩形的某一条边的中央有一个单像素的 yellow 标记（标记在矩形外侧紧贴边缘），指示锁的"朝向"。
  - "钥匙"：与锁同色的小型不规则连通图案（2-5 像素），形状可以完全嵌入对应锁的矩形区域中。钥匙图案外围有一圈 grey 单像素宽的边框包裹。

- `Rule`：
  - 第一层推理——配对：相同颜色的钥匙和锁配对。每种颜色恰好出现一对。
  - 第二层推理——形状减去：将钥匙的形状（去掉 grey 边框后的内部图案）对齐到锁的矩形区域中。对齐方式为：钥匙图案的边界框与锁矩形的中心对齐（四舍五入到最近的整数坐标）。锁矩形中与钥匙形状重叠的像素被"减去"（变为背景色）。
  - 第三层推理——碎片弹射：被减去的像素组成一个碎片，该碎片沿锁的 yellow 标记所指方向（标记在哪一侧，碎片就向该侧弹射）平移，直到碎片的最近边缘距离锁的对应边缘恰好 2 个像素的间隔。碎片保持锁的原始颜色。
  - 钥匙及其 grey 边框从网格中移除（变为背景色）。

- `Key insight`：解题者需要从颜色匹配发现配对关系，然后注意到钥匙的形状恰好与锁中被移除的区域吻合（布尔减法），最后从弹射碎片的位置推断出 yellow 标记编码了弹射方向和固定间距——三者结合才能完整还原变换规则。
</new_puzzle>

<new_puzzle>
- `description`：根据封闭矩形区域内"指示棒"的方向和长度，将区域边界上对应位置的边框段向外扩展，形成突起结构。

- `Input structure`：
  - 背景色 = black。网格中有若干由 blue 像素绘制的单像素宽封闭矩形（不同大小，互不重叠）。
  - 每个矩形内部有 1-3 根"指示棒"：每根指示棒是一条由 red 像素组成的短直线段（2-4 像素长），严格沿水平或垂直方向放置。
  - 指示棒的一端紧贴矩形边框的内侧（与边框像素 4-邻接），另一端指向矩形内部。

- `Rule`：
  - 第一层推理——定位与方向：每根指示棒从它接触边框的那一侧确定扩展方向（接触上边框 → 向上扩展，接触左边框 → 向左扩展，等）。指示棒沿边框方向的位置确定突起在边框上的起始列或行。
  - 第二层推理——突起尺寸：指示棒的长度（像素数）决定突起向外延伸的距离。突起的宽度等于 1 像素，用 blue 像素绘制，形成从边框向外伸出的"凸起条"。突起的末端用一个横向的 blue 像素封口（形成 U 形突起的三面：两条平行的纵向线和一条横向封口线，总宽度为 3 像素——中间 1 像素通道加两侧各 1 像素壁）。
  - 指示棒本身（red 像素）在输出中被移除（变为背景色），矩形内部其余区域保持背景色。

- `Key insight`：解题者需要发现指示棒的接触位置编码了"在哪个边的什么位置生长突起"，而指示棒的长度编码了"突起伸出多远"——两个几何属性分别控制突起的位置和大小，且指示棒本身在输出中消失，这使得从输出倒推规则时需要仔细对比输入输出的差异。
</new_puzzle>
