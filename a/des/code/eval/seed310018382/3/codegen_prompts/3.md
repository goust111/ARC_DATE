- `description`：根据围墙上缺口的位置和总数，将围墙内部的种子图案向缺口方向复制生长，生长层数等于缺口总数。

- `Input structure`：
  - bg = black。网格中有若干由 grey 像素组成的封闭矩形围墙（一像素宽边框）。
  - 每个围墙内部包含一个小型彩色"种子图案"（2x2 至 4x4 的非对称形状），使用单一非 grey 非 bg 颜色。
  - 每个围墙的边框上有 1 到 4 个缺口（gap），每个缺口是边框上一个被 bg 替换的像素位置。缺口分布在围墙的不同边上。

- `Rule`：
  - 第一步（确定生长方向）：每个缺口所在的边决定一个生长方向——上边缺口 → 向上生长，右边缺口 → 向右生长，下边缺口 → 向下生长，左边缺口 → 向左生长。
  - 第二步（确定生长层数）：该围墙上缺口的总数 N 即为每个方向的生长层数。
  - 第三步（图案复制生长）：对每个生长方向，将种子图案从围墙外侧的缺口位置开始，沿该方向连续复制 N 次。每次复制紧贴上一次复制的末端，不留间隙。复制时图案保持原始朝向不变。
  - 围墙本身（包括缺口）在输出中被移除（变为 bg），只保留种子图案原位和所有生长出的副本。

- `Key insight`：缺口同时编码两层信息：位置决定方向，总数决定重复次数。解题者需要先数缺口获得全局参数 N，再逐个分析缺口位置获得方向集合——两步推理相互依赖且都来自同一组视觉线索。
</new_puzzle>

## 实现要求

1. `main(grid)` 必须实现新题描述中的确定性转换规则，不能只识别 `generate_input()` 的固定模板。
2. `generate_input()` 必须随机生成多样样例，不能固定死。随机维度应覆盖：网格大小、对象数量、位置、颜色、方向、形状参数或关键分支。
3. 生成器必须保证输入满足 `main()` 的隐式假设：对象不重叠、不越界、特殊标记唯一或可区分、匹配关系无歧义、关键分支出现概率相同。
4. 禁止把 ARC 颜色 id 、亮度、拼写等当作人类不可见的数值语义参与排序、大小比较或隐藏映射。颜色变化必须有可见结构线索。注意颜色亮度、拼写等也是不可见信息，若描述中出现违规的颜色id或者亮度，可自行使用少量的固定颜色替代，但注意生成时要在三个以内输入输出网格中对所有变换100%覆盖度。
