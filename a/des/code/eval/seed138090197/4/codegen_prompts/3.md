- `Input structure`：
  - 背景色为 black。
  - 网格被 azure 色的完整行和列分隔线划分为矩形房间（类似棋盘格式的分隔）。
  - 每个房间内部有恰好一个非 black、非 azure、非 grey 的彩色像素（种子），以及若干 grey 像素作为内部墙壁（位于房间内部，不与 azure 分隔线相邻）。
  - 不同房间的种子颜色可能相同也可能不同。

- `Rule`：
  - 第一层推理——射线扩散：从每个种子像素出发，向上、下、左、右四个方向发射射线，射线沿该方向逐像素前进，遇到 grey 墙壁像素或 azure 分隔线时停止（不包含墙壁/分隔线本身）。射线经过的所有 black 像素被染成种子的颜色。
  - 第二层推理——墙壁移除判定：对房间内每个 grey 墙壁像素，检查其上下左右四个方向中有多少个方向存在同房间的射线（即该方向上相邻的像素已被染色或是种子本身）。若被射线接触的方向数 ≥ 3，则该墙壁像素被移除（变为种子颜色）；否则保留为 grey。墙壁被移除后，不会触发射线的二次扩散——整个过程只执行一轮射线计算。
  - 输出网格尺寸不变，azure 分隔线保持不变。

- `Key insight`：第一步的射线扩散是直观的"遇墙停止"，但第二步墙壁的去留取决于它被射线从几个方向包围——这需要解题者在观察样例时注意到某些墙壁消失而另一些保留，并归纳出"三面包围则移除"的阈值规则。

1. `main(grid)` 必须实现新题描述中的确定性转换规则，不能只识别 `generate_input()` 的固定模板。
