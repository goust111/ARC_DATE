  - 其余矩形区域内，每个区域包含恰好一个单像素的"种子"（颜色为图例中出现过的某种颜色），以及零到若干个 maroon 色的障碍像素。

  - 第三步——输出结果：种子扩展后的像素覆盖原来的 black 背景，maroon 障碍物保持不变，grey 分区线保持不变，图例区域保持不变。

- `Key insight`：图例中每种颜色的空间形状不是要被复制的固定图形，而是编码了"生长方向集合"——解题者需要将图例中的具体形状抽象为方向规则，再将该规则应用到大小各异的区域中，由区域边界和障碍物动态决定最终形状。

- `Input structure`：
  - 背景为 black。
  - 网格分为两个区域，由一条完整的 grey 水平线或垂直线分隔。
  - 一侧为"调色板区域"：包含一个小的彩色矩形（例如 3x2），其中每个像素为不同颜色，形成一个颜色网格图。

- `Rule`：
  - 第一步——拼合：将拼图区域的所有形状通过平移（不旋转、不翻转）拼合成一个紧密的大矩形。拼合方式唯一，因为形状的轮廓彼此互补。

  - 第三步——重新着色：对于大矩形中的每个像素，确定它属于调色板网格的哪个子块位置，将该像素重新着色为调色板中对应位置的颜色。原来的形状边界不再可见，输出为一个按调色板颜色图案着色的大矩形。
  - 输出网格仅包含拼合后的大矩形（紧凑裁剪），不保留原始散落布局。

- `Key insight`：解题者需要先完成空间拼图（识别形状如何拼合成矩形），再发现调色板与大矩形之间的缩放映射关系——拼合是几何推理，着色是比例映射推理，两步都需要非平凡的归纳。

- `Input structure`：
  - 背景为 black。
  - 网格中散布若干"箭头"对象。每个箭头由两部分组成：
    - 箭头头部：固定为 azure 色，由 3 个像素组成一个直角三角形，尖端朝向箭头指向的方向。具体地，以向右的箭头为例，头部为一列两行高的像素加上右侧一行高一格的像素（呈 ">" 形）；其他方向类似旋转。
    - 箭头尾部：从头部底边中心向箭头反方向延伸的一条单像素宽直线段，颜色为某种非 black 非 azure 颜色（如 red、green、yellow 等），长度从 1 到 5 像素不等。
  - 箭头共有四种朝向：上、下、左、右。箭头之间不重叠，且与网格边界保持足够距离。

- `Rule`：
  - 第一步——识别箭头与方向：找到所有箭头对象，通过 azure 头部三角形的尖端朝向确定每个箭头的指向方向。
  - 第二步——确定泼洒距离：每个箭头的泼洒距离等于其尾部的像素长度。
  - 第三步——执行泼洒：从箭头头部尖端像素出发，沿箭头指向方向，用尾部颜色绘制一条单像素宽的射线，射线长度等于泼洒距离。射线像素覆盖 black 背景。
  - 第四步——交叉处理：如果两条射线在同一像素交叉（一条水平一条垂直），该像素着色为 maroon。如果射线碰到已有箭头实体像素，射线在该像素前停止（不覆盖箭头本身）。
  - 输出中箭头本身保持不变，仅在箭头前方添加泼洒射线。

- `Key insight`：azure 三角形统一标识箭头头部并编码方向，但泼洒的颜色和距离都隐藏在尾部属性中——解题者需要先通过头部识别方向，再从尾部提取颜色与长度两个参数，最后理解交叉混色规则。方向识别、参数提取、交叉处理构成三个递进的推理层次。

- `description`：在网格中，每个封闭区域内的小图形充当"印章"，根据区域边框上彩色标记点的位置，将印章图案沿标记点指定的方向盖印到区域外部。

- `Input structure`：
  - 背景为 black。
  - 网格中有若干由 grey 像素绘制的单像素厚封闭矩形边框，形成独立的矩形区域，区域之间不嵌套不重叠。

  - 每个矩形边框的四条边上，有零到若干个像素被替换为与内部印章相同的颜色，这些彩色像素称为"标记点"。标记点只出现在边框的边中间位置（不在角上）。

- `Rule`：
  - 第一步——识别印章与标记点：对每个区域，提取内部印章的形状和颜色，以及边框上所有标记点的位置。
  - 第二步——确定盖印方向与位置：每个标记点所在的边决定盖印方向——标记点在上边则向上盖印，在下边则向下盖印，在左边则向左盖印，在右边则向右盖印。盖印位置为：将印章的几何中心（视觉中点）对齐到标记点沿法线方向外移一定距离处，使得印章副本紧贴边框外侧放置，印章副本最近的一行/列与边框外侧相邻。
  - 第三步——印章方向旋转：盖印时，印章图案需要旋转，使其在区域内的"朝上"方向转为朝向边框外侧。具体地：如果标记点在上边，印章旋转 180 度；如果在右边，顺时针旋转 90 度；如果在左边，逆时针旋转 90 度；如果在下边，不旋转。
  - 第四步——绘制输出：在输出中，原始区域（边框 + 内部印章）保持不变，每个标记点位置的外侧绘制旋转后的印章副本。多个印章副本如果重叠，后绘制的覆盖先绘制的（按标记点从左到右、从上到下的顺序）。

- `Key insight`：标记点同时编码了两个信息——盖印的位置（沿标记点所在边的外法线方向）和印章的旋转角度（由标记点所在的边决定）。解题者需要先理解标记点与方向的对应关系，再发现印章旋转的规律，两层推理缺一不可。

<new_puzzle>
- `description`：网格中散布着多组形状对，每组中一个形状是另一个的"镜像缺损版"；找到配对关系后，用一个形状的完整部分修补另一个形状的缺损区域，最终每对形状合并为一个完整的对称图形。

- `Input structure`：
  - 背景为 black。
  - 网格中散布着偶数个单色形状（每个形状由一种独特颜色的连通像素块组成，不同形状颜色不同）。
  - 这些形状两两配对。每对中的两个形状具有以下关系：它们是同一个左右对称图形的两个"碎片"——将完整对称图形沿垂直对称轴分为左右两半后，一个形状包含完整的左半加上右半的部分像素（右侧有缺损），另一个形状包含完整的右半加上左半的部分像素（左侧有缺损）。两个形状的缺损区域互补：一个缺失的部分恰好是另一个拥有的部分。
  - 配对的两个形状在网格中位置不相邻，需要通过形状互补性来识别配对关系。
  - 每对中，面积较大的形状称为"主体"，面积较小的称为"补丁"。

- `Rule`：
  - 第一步——识别配对：对于每个形状，将其水平翻转后与其他形状进行轮廓比对。如果形状 A 水平翻转后与形状 B 的边界框大小相同，且 A 翻转后有像素的位置与 B 有像素的位置合并后恰好形成一个完整的左右对称图形（无间隙无重叠），则 A 和 B 配对。
  - 第二步——合并修补：以主体（面积较大者）的位置为基准，将补丁水平翻转后平移对齐到主体的边界框上，使得翻转后的补丁像素填补主体的缺损区域。填补的像素使用主体的颜色。
  - 第三步——清理：补丁的原始位置被清除为 black 背景。最终输出中，每对形状合并为一个完整的左右对称图形，位于主体的原始位置，使用主体的颜色。

- `Key insight`：配对的线索不是颜色或位置的接近性，而是形状轮廓的镜像互补性——解题者必须对形状进行心理翻转并检查是否能互补拼合成对称图形，这是一种非平凡的空间推理。选择保留哪个形状的位置和颜色（面积较大者）则是第二层需要归纳的规则。
</new_puzzle>
