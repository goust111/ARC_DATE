- `Input structure`：
  - 背景为 black。
  - 网格中散布若干"箭头"对象。每个箭头由两部分组成：
    - 箭头头部：固定为 azure 色，由 3 个像素组成一个直角三角形，尖端朝向箭头指向的方向。具体地，以向右的箭头为例，头部为一列两行高的像素加上右侧一行高一格的像素（呈 ">" 形）；其他方向类似旋转。
    - 箭头尾部：从头部底边中心向箭头反方向延伸的一条单像素宽直线段，颜色为某种非 black 非 azure 颜色（如 red、green、yellow 等），长度从 1 到 5 像素不等。
  - 箭头共有四种朝向：上、下、左、右。箭头之间不重叠，且与网格边界保持足够距离。

- `Rule`：
  - 第一步——识别箭头与方向：找到所有箭头对象，通过 azure 头部三角形的尖端朝向确定每个箭头的指向方向。
  - 第二步——确定泼洒距离：每个箭头的泼洒距离等于其尾部的像素长度。
  - 第三步——执行泼洒：从箭头头部尖端像素出发，沿箭头指向方向，用尾部颜色绘制一条单像素宽的射线，射线长度等于泼洒距离。射线像素覆盖 black 背景。
  - 第四步——交叉处理：如果两条射线在同一像素交叉（一条水平一条垂直），该像素着色为 maroon。如果射线碰到已有箭头实体像素，射线在该像素前停止（不覆盖箭头本身）。
  - 输出中箭头本身保持不变，仅在箭头前方添加泼洒射线。

- `Key insight`：azure 三角形统一标识箭头头部并编码方向，但泼洒的颜色和距离都隐藏在尾部属性中——解题者需要先通过头部识别方向，再从尾部提取颜色与长度两个参数，最后理解交叉混色规则。方向识别、参数提取、交叉处理构成三个递进的推理层次。
