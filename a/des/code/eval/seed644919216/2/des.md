  - 每个碎片内部的颜色像素分布具有某种对称性：有的左右对称，有的上下对称，有的旋转对称(180度)，有的无对称性。

- `Rule`：
  - 第一层：形状匹配——将每个碎片的外轮廓与各框架缺口的形状进行比较（允许旋转0/90/180/270度），找到唯一匹配的框架-碎片配对。

  - 将碎片填入对应缺口后，碎片原来的位置变为bg。

- `Key insight`：碎片与缺口的配对靠形状轮廓匹配，但同一形状可能有多种旋转方式嵌入缺口——碎片内部颜色图案的对称性类型决定了唯一的放置朝向，这是第二层需要归纳的规则。
</new_puzzle>

- `description`：在网格中找到由分隔线划分的子区域，识别每个区域内的"种子图案"和"生长方向箭头"，将种子图案沿箭头方向进行镜像级联复制，直至碰到区域边界。
- `Input structure`：
  - 背景色(bg)为黑色(black)。
  - 一种颜色（如grey）画出单像素宽的水平和垂直分隔线，将网格划分为若干矩形子区域。
  - 每个子区域内包含两类内容：(a) 一个由若干彩色像素构成的小图案（种子），通常紧贴区域的某一角或某一边；(b) 一个由red色像素组成的箭头标记——箭头由一条3像素长的直线段加上末端两侧各一个像素构成箭头头部（共5个像素），箭头朝向为上、下、左、右四个方向之一。

- `Rule`：
  - 识别每个子区域的边界（由分隔线和网格边缘界定）。
  - 在区域内找到red色箭头，确定其指向方向D。
  - 在区域内找到非bg、非grey、非red的彩色像素群，作为种子图案S。
  - 从种子图案的位置开始，沿方向D进行级联复制：第一次复制是S关于D方向的镜像翻转（如D向右，则左右镜像），放置在种子的D方向紧邻位置；第二次复制再将第一次的结果镜像翻转（恢复原始朝向），继续沿D方向紧邻放置；如此交替镜像，直到下一次复制会超出子区域边界时停止。
  - 箭头标记在输出中被擦除（变为bg）。

- `Key insight`：每个区域独立处理，箭头决定复制的传播方向，而"交替镜像"的复制模式需要从多个样例中观察才能发现——不是简单的平移复制，而是每一步都翻转一次，形成镜像级联的万花筒效果。
</new_puzzle>

  - 网格中散布着若干单色小方块（2x2或3x3的实心正方形），每个方块颜色不同，共N个方块（N在4到6之间）。

- `Rule`：
  - 第一层：从网格中提取"邻接约束"——被grey路径直接相连的两个色块颜色，在输出矩阵中必须处于上下或左右紧邻的格子中。
  - 第二层：将所有N个颜色填入R×C的矩阵模板中（N = R×C），使得每一对被路径连接的颜色都满足矩阵内相邻的约束。每个格子填一种颜色，每种颜色恰好用一次。
  - 输出网格即为这个填好的R×C颜色矩阵，每个格子用对应的颜色填充为与原方块相同大小的实心块，各块紧密排列无间隔。

- `Key insight`：灰色路径不是要在输出中保留的装饰，而是编码了颜色之间的"必须相邻"约束；左下角的空白模板给出了输出的维度；解题者需要把路径网络理解为一个约束图，再把颜色排进矩阵中满足所有约束——这是一个需要两步归纳的过程（先理解路径=相邻约束，再完成排列）。
</new_puzzle>

  - 每个传送门图案的某一侧（上、下、左或右）紧邻一个单像素的red标记点，表示该传送门的"出入口方向"。

- `Rule`：
  - 第一层：传送门配对——在网格中找出所有形状相同的图案对，将它们识别为传送门对（形状相同、颜色不同）。

  - 输出网格在原网格基础上增加了所有传送后延伸出的射线段，其余内容不变。

- `Key insight`：两层核心推理——首先要从网格中众多彩色图案里识别出"形状相同但颜色不同"的配对关系（这不是肉眼立刻能看出的，需要仔细比较形状），然后理解射线通过传送门对实现空间跳跃并继续延伸的机制。传送的连锁效应增加了追踪难度。

- `description`：在一个由彩色像素构成的"电路板"上追踪信号流向，信号在交叉节点处根据节点颜色决定转弯方向，最终信号到达的终点颜色决定整条线路的重绘颜色。
- `Input structure`：
  - 背景色(bg)为black。
  - 网格中有若干条单像素宽的grey色正交线路（水平或垂直的直线段），线路之间通过彩色的"节点"像素相连。节点是线路交汇或转弯的位置，每个节点占一个像素，颜色为red、blue或green之一。
  - 每条线路的一端连接一个节点，另一端要么连接另一个节点，要么是自由端（不连接任何东西，末端紧邻网格边缘或bg）。
  - 网格的某一侧边缘（如左侧）有若干个yellow色像素点，每个yellow像素恰好是某条线路的自由端起点，表示"信号源"。
  - 网格的另一侧边缘（如右侧）有若干个颜色各异的像素点（如magenta、orange、maroon等），每个这样的像素恰好是某条线路的自由端终点，表示"信号终端"。

- `Rule`：
  - 第一层：信号路径追踪——从每个左侧的yellow信号源出发，沿grey线路前进。当信号到达一个节点时，根据节点颜色决定下一步方向：red节点表示向右转（相对于信号到达方向顺时针90度），blue节点表示向左转（逆时针90度），green节点表示直行（方向不变）。从节点沿新方向离开，进入下一条grey线路，继续追踪直到到达一个信号终端。
  - 第二层：线路重绘——每条完整的信号路径（从信号源到信号终端）上的所有grey线段和途经的节点，全部重绘为该路径所到达的终端像素的颜色。不在任何信号路径上的grey线段和节点保持不变。
  - 如果从某个信号源出发追踪到的路径在到达终端之前遇到死胡同（无法继续），则该信号源的线路保持grey不变。

- `Key insight`：两层核心推理——首先要发现节点颜色与转弯方向的对应关系（red=右转、blue=左转、green=直行，这需要从多个样例中观察节点处信号的走向来归纳），然后理解终端颜色反向传播给整条路径。节点颜色不是装饰而是"路由指令"，这一点是解题的关键洞见。
</new_puzzle>
