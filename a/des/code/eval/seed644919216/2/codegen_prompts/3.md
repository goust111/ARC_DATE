  - 网格中散布着若干单色小方块（2x2或3x3的实心正方形），每个方块颜色不同，共N个方块（N在4到6之间）。

  - 网格左下角有一个小的矩形轮廓（用grey色画出边框，内部为bg），尺寸为 R行 x C列（R和C各为2或3），这是输出矩阵的模板。

- `Rule`：
  - 第一层：从网格中提取"邻接约束"——被grey路径直接相连的两个色块颜色，在输出矩阵中必须处于上下或左右紧邻的格子中。
  - 第二层：将所有N个颜色填入R×C的矩阵模板中（N = R×C），使得每一对被路径连接的颜色都满足矩阵内相邻的约束。每个格子填一种颜色，每种颜色恰好用一次。
  - 输出网格即为这个填好的R×C颜色矩阵，每个格子用对应的颜色填充为与原方块相同大小的实心块，各块紧密排列无间隔。

- `Key insight`：灰色路径不是要在输出中保留的装饰，而是编码了颜色之间的"必须相邻"约束；左下角的空白模板给出了输出的维度；解题者需要把路径网络理解为一个约束图，再把颜色排进矩阵中满足所有约束——这是一个需要两步归纳的过程（先理解路径=相邻约束，再完成排列）。

## 实现要求

1. `main(grid)` 必须实现新题描述中的确定性转换规则，不能只识别 `generate_input()` 的固定模板。

4. 禁止把 ARC 颜色 id 、亮度、拼写等当作人类不可见的数值语义参与排序、大小比较或隐藏映射。颜色变化必须有可见结构线索。注意颜色亮度、拼写等也是不可见信息，若描述中出现违规的颜色id或者亮度，可自行使用少量的固定颜色替代，但注意生成时要在三个以内输入输出网格中对所有变换100%覆盖度。
