- `Input structure`：
  - 背景色为 black。
  - 网格中有若干由 grey 线条围成的封闭区域（不规则多边形），每个区域内部有一个或多个小型 black 孔洞（即区域内部被 grey 线切割出的小空缺，形状为 1x1、1x2、2x1 或 2x2 等简单矩形）。

- `Rule`：
  - 第一步：对每个封闭区域，收集其内部所有孔洞，将孔洞按从上到下、从左到右排列，拼成一个"孔洞签名"序列（即孔洞形状的有序列表）。
  - 第二步：在图例区中找到孔洞形状与该区域内某个孔洞完全匹配的条目，读取对应的彩色图案。
  - 第三步：将该彩色图案以平铺方式（tile）填满整个封闭区域的内部（覆盖原来的填充色和孔洞），图案从区域包围盒的左上角开始对齐平铺。孔洞位置也被图案覆盖。grey 边界线条保持不变。
  - 如果一个区域有多个不同形状的孔洞，则使用面积最大的那个孔洞去匹配图例。

- `Key insight`：孔洞的形状是查表键——需要先识别每个封闭区域内孔洞的几何形状，再到图例中匹配，匹配结果决定该区域用哪种图案平铺填充。两步推理缺一不可：识别孔洞形状是第一层，查表平铺是第二层。

- `description`：沿彩色路径传播信号，在每个交叉口根据交叉口中心像素的颜色选择转向方向，最终在路径末端生成与信号源同色的标记。

- `Input structure`：
  - 背景色为 black。
  - 网格中有一个由 grey 像素构成的单像素宽路径网络，路径仅沿水平和垂直方向延伸，路径之间通过十字交叉口连通。
  - 每个交叉口的中心像素被染成 red 或 blue（而非 grey），表示转向指令：red 表示"右转优先"，blue 表示"左转优先"。
  - 路径网络的若干末端（度为 1 的端点）各有一个彩色像素（green、yellow、orange 或 magenta），这些是"信号源"。
  - 路径网络的其余末端是空的（grey 端点，无彩色标记），这些是"接收端"。

- `Rule`：
  - 每个信号源沿其所在路径段向网络内部发射信号。信号沿 grey 路径前进。
  - 当信号到达一个交叉口时，检查交叉口中心像素颜色：
    - red：信号相对于其来时方向右转 90 度继续前进。
    - blue：信号相对于其来时方向左转 90 度继续前进。
  - 如果指定的转向方向没有路径（即那个方向不存在 grey 路径段），则信号改为直行；如果直行也不通，则信号停止。
  - 信号最终到达某个接收端时，将该接收端的 grey 端点像素染成信号源的颜色。
  - 所有信号同时传播，互不干扰（可以有多个信号经过同一交叉口）。
  - 输出网格中，路径和交叉口颜色保持不变，仅接收端端点颜色改变。

- `Key insight`：交叉口中心像素的颜色编码了转向规则（red=右转、blue=左转），解题者需要在脑中沿路径"走一遍"信号传播过程。第一层推理是识别路径拓扑和交叉口转向编码，第二层是追踪每个信号的实际路径以确定它最终到达哪个接收端。
</new_puzzle>

- `description`：将散落的彩色碎片按照边缘锯齿互锁关系拼合，然后根据拼合后每块碎片所处的行列位置，从一个颜色矩阵中查取该位置对应的颜色，将碎片整体重新着色。

- `Input structure`：
  - 背景色为 black。
  - 网格中散布着若干单色碎片（每块碎片是一个 4-连通区域，颜色各不相同，如 red、blue、green、yellow、orange 等）。每块碎片的边缘有凸起和凹陷（锯齿状轮廓），凸起和凹陷的形状能互相嵌合。
  - 网格的一角（例如右下角）有一个小的 N×M 颜色矩阵（由 grey 单像素边框分隔的 N×M 个单色格子），每个格子填充一种颜色。该矩阵的行列数恰好等于碎片拼合后形成的矩形的行列分块数。

- `Rule`：
  - 第一步（拼合）：所有碎片可以无旋转地平移拼合成一个无缝、无重叠的矩形。碎片的锯齿边缘恰好互锁。拼合后的矩形可被均匀划分为 N 行 M 列的等大子区域，每块碎片恰好占据一个子区域。
  - 第二步（着色查表）：拼合后，位于第 i 行第 j 列的碎片，查看颜色矩阵中第 i 行第 j 列格子的颜色，将该碎片整体重新着色为该颜色。
  - 第三步（输出）：输出仅包含拼合并重新着色后的矩形，背景为 black，颜色矩阵和原始散落位置的痕迹均不保留。

- `Key insight`：解题包含两个非平凡推理层——第一层是通过边缘锯齿的互补形状推断碎片之间的邻接关系并确定它们在矩形中的位置（空间推理），第二层是发现角落的颜色矩阵是按行列位置对碎片重新上色的查找表（映射推理）。仅完成拼合或仅发现颜色表都无法得到正确输出。
</new_puzzle>

- `Input structure`：
  - 背景色为 azure。
  - 网格中心有一个大型彩色图案，该图案具有 180 度旋转对称性（即绕中心旋转 180 度后与自身重合）。图案由多种颜色（如 red、green、blue、yellow）组成。
  - 图案上叠放了一到三个单色矩形遮挡块（颜色为 maroon、orange 或 magenta），这些矩形完全覆盖了图案的某些区域。遮挡块的颜色与图案中使用的颜色均不相同。
  - 网格边缘有一个单行或单列的"颜色映射带"：由若干 2 像素宽的色条组成，每个色条的上半（或左半）是某个遮挡块颜色，下半（或右半）是一个图案中使用的颜色。

- `Rule`：
  - 第一步（恢复）：利用图案的 180 度旋转对称性，对每个被遮挡块覆盖的像素，找到它关于图案中心的 180 度旋转对应像素。如果对应像素未被遮挡，则获取其颜色作为该位置的"原始颜色"。
  - 第二步（颜色替换）：查看覆盖该像素的遮挡块颜色，在颜色映射带中找到对应条目。将恢复出的"原始颜色"中属于映射带下半颜色的像素，替换为遮挡块的颜色；其余恢复像素保持原色。
  - 第三步（输出）：移除所有遮挡块，显示完整的图案。被恢复的区域中，符合映射条件的像素显示替换色，其余像素显示旋转对称恢复的原色。遮挡块本身不出现在输出中。

- `Key insight`：三层结构——第一层是识别图案具有 180 度旋转对称性（而非镜像对称），第二层是利用该对称性恢复被遮挡区域的原始内容，第三层是发现颜色映射带的编码规则并对恢复出的特定颜色进行替换。解题者需要同时理解对称恢复和选择性颜色替换两个独立机制。
</new_puzzle>

- `description`：在网格中找到多个同构但不同色的框架结构，根据框架内部种子像素的数量决定向框架外扩展的层数，扩展时颜色沿框架边交替变化。

- `Input structure`：
  - 背景色为 black。
  - 网格中有若干个矩形空心框架（单像素宽边框），每个框架使用不同的颜色（如 red、blue、green 等），框架大小相同（例如都是 5x5）。
  - 每个框架的内部（框架围住的区域）有若干个 yellow 像素散布其中，数量从 1 到 4 不等，其余内部像素为 black。
  - 框架之间有足够间距，互不重叠。

- `Rule`：
  - 第一步（计数）：数出每个框架内部 yellow 像素的数量 N。
  - 第二步（扩展）：以原框架为第 0 层，在其外部依次扩展 N 层同心矩形环。每层环的宽度为 1 像素。
  - 第三步（着色交替）：第 0 层（原框架）保持原色。第 1 层使用 grey，第 2 层使用原框架色，第 3 层使用 grey，第 4 层使用原框架色……即奇数层为 grey，偶数层为原框架色。
  - 第四步（清除种子）：扩展完成后，框架内部的 yellow 像素全部变为 black（即内部恢复为纯 black）。
  - 如果两个框架的扩展层在空间上重叠，则后扩展的层不覆盖先前已绘制的像素（按框架从左上到右下的扫描顺序处理）。

- `Key insight`：yellow 种子像素的数量编码了扩展层数——这是第一层推理（计数决定几何量）。第二层推理是发现扩展环的颜色交替规则（框架原色与 grey 交替），而非简单地用同一颜色扩展。解题者需要同时归纳出"内部计数→外部层数"和"颜色交替模式"两个独立规律。
</new_puzzle>

- `description`：将网格中的彩色线段视为时钟指针，根据指针指向的方向从环形色盘中读取颜色，然后用读取到的颜色填充指针根部所在的封闭格子。

- `Input structure`：
  - 背景色为 black。
  - 网格被 grey 线条划分为若干大小相等的正方形格子（例如 4x4 或 5x5 的格子阵列）。
  - 部分格子的中心有一个固定的 maroon 像素（"轴心"），从轴心出发有一条单色线段（2-3 像素长）向某个方向延伸（上、下、左、右、或四个对角方向，共 8 个可能方向）。每条线段颜色各异。
  - 网格的一角有一个特殊的环形色盘：一个 3x3 区域，中心是 maroon，周围 8 个像素按顺时针方向（从正上方开始：上、右上、右、右下、下、左下、左、左上）分别填充了 8 种不同颜色。

- `Rule`：
  - 第一步（读方向）：对每个有指针的格子，确定指针从轴心指向的方向（8 个方向之一）。
  - 第二步（查色盘）：在环形色盘中，找到与指针方向对应位置的颜色（如指针指向右上，则读取色盘中右上位置的颜色）。
  - 第三步（填充）：将该格子内部（grey 边框以内、指针和轴心以外的所有 black 像素）填充为色盘查到的颜色。
  - 第四步（保留）：指针线段和轴心 maroon 像素保持原色不变，grey 边框不变。没有指针的格子保持全 black。

- `Key insight`：核心推理分两层——第一层是发现每个格子中线段的方向编码了一个"查询"，第二层是识别角落色盘的 8 方位布局并将线段方向映射到色盘上对应位置的颜色。指针本身的颜色是干扰项，真正决定填充色的是指针方向在色盘中对应的颜色。

<new_puzzle>
- `description`：根据网格中配对标记的相对位置关系，在两个标记之间生成特定形状的连接桥，桥的形状由标记的朝向和间距共同决定。

- `Input structure`：
  - 背景色为 black。
  - 网格中散布着若干成对的 L 形标记。每个 L 形由 3 个像素组成（占据 2x2 区域中的 3 个格子，缺少一个角），同一对的两个 L 形颜色相同。不同对使用不同颜色（如 red、blue、green、orange 等）。
  - 每对 L 形的缺角方向（左上、右上、左下、右下）可能相同也可能不同。
  - 同色配对的两个 L 形在网格中沿同一行带或同一列带排列（即它们的包围盒在水平或垂直方向上有重叠）。

- `Rule`：
  - 第一步（配对）：将同色的两个 L 形配为一对。
  - 第二步（判断桥类型）：比较配对中两个 L 形的缺角方向：
    - 如果两个 L 形的缺角方向相互"面对"（即缺角朝向对方的方向），则生成直线桥——用该颜色的单像素宽直线连接两个 L 形最近的边缘。
    - 如果两个 L 形的缺角方向相同（都朝同一方向），则生成 Z 形桥——先沿两个 L 形连线方向走到中点，然后垂直偏移到另一个 L 形的对齐位置，再继续前进。
    - 如果两个 L 形的缺角方向相互"背对"（即缺角都朝远离对方的方向），则生成 U 形桥——桥从一个 L 形的缺角侧出发，向外绕一个矩形弯后到达另一个 L 形的缺角侧。
  - 第三步（绘桥）：桥的宽度为 1 像素，颜色与 L 形相同。桥不穿过其他 L 形或其他桥。

- `Key insight`：L 形标记的缺角方向不仅仅是装饰——两个配对标记的缺角朝向的相对关系（面对、同向、背对）编码了三种截然不同的桥形。解题者第一层需要识别 L 形的朝向和配对规则，第二层需要发现朝向组合与桥形之间的映射关系。
</new_puzzle>
