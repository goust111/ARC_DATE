- `description`：将网格中的管道网络视为电路，根据输入端颜色信号沿管道传播并在交汇处执行颜色混合，最终输出端显示混合后的结果颜色。

- `Input structure`：
  - 背景为黑色。
  - 网格中有由灰色像素绘制的管道网络：管道为 1 像素宽的连通路径，沿水平或垂直方向延伸，在转弯处呈直角。
  - 管道网络有若干"输入端"和若干"输出端"：输入端是管道末端紧邻网格边缘的位置，该末端像素为某种非灰非黑颜色（红色、蓝色或黄色三种之一）；输出端是管道末端紧邻网格边缘但像素为灰色的位置。
  - 管道在内部可能分叉（T 形或十字形交叉点），也可能汇合（两条管道合并为一条）。
  - 汇合点处用一个 Azure 色像素标记。

- `Rule`：
  - 从每个输入端开始，将该输入端的颜色沿管道路径传播：颜色沿灰色管道流动，遇到分叉时向所有分支传播。
  - 当两种颜色在 Azure 标记的汇合点相遇时，执行颜色混合：红色加蓝色等于 Magenta；红色加黄色等于橙色；蓝色加黄色等于绿色。若三种颜色同时汇合，结果为 Maroon。
  - 混合后的颜色继续沿后续管道传播。
  - 最终，每个输出端的灰色像素变为到达该端的颜色。
  - 管道路径上的灰色像素保持灰色不变（仅端点变色）。

- `Key insight`：解题者需要先识别管道的拓扑结构和信号流向（通过端点位置和汇合标记），然后追踪每条路径上的颜色传播，最关键的隐蔽推理在于发现 Azure 像素处的颜色混合规则——它并非简单的覆盖，而是类似颜料混色的组合逻辑，且这个规则需要从多个样例中的不同混合实例归纳得出。
</new_puzzle>

1. `main(grid)` 必须实现新题描述中的确定性转换规则，不能只识别 `generate_input()` 的固定模板。
