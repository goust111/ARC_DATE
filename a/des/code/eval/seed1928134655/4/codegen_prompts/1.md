  - 将每个旗帜与右侧的一个起始标记配对：配对规则为旗帜在左侧区域中从上到下的排列顺序对应起始标记在右侧区域中从上到下（同行则从左到右）的排列顺序。
  - 对每个旗帜，从其配对的起始标记位置出发，按照色带从上到下的顺序依次执行移动：每个色带颜色查图例得到方向，沿该方向画出长度等于该色带在旗帜中的连续重复次数（至少为 1）的线段，线段颜色为该色带颜色。下一段从上一段终点继续。
  - 起始标记的绿色像素保留在输出中。

- `Key insight`：旗帜不是装饰图案，而是一串编码指令——每个色带同时编码了移动方向（通过图例映射）和移动距离（通过连续相同颜色的计数），需要先破解图例再逐步执行路径绘制。

4. 禁止把 ARC 颜色 id 、亮度、拼写等当作人类不可见的数值语义参与排序、大小比较或隐藏映射。颜色变化必须有可见结构线索。注意颜色亮度、拼写等也是不可见信息，若描述中出现违规的颜色id或者亮度，可自行使用少量的固定颜色替代，但注意生成时要在三个以内输入输出网格中对所有变换100%覆盖度。
