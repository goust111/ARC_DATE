- `Input structure`：
  - bg = Black。
  - 网格中有若干个由同一种颜色（如 Azure）绘制的闭合矩形环形轨道（每个环是一个空心矩形，宽度为 1 像素，不同环的大小不同且互不重叠）。
  - 每个环的轨道上有 1-4 个像素被替换为 Maroon 色，作为"节拍标记"。这些标记的位置都在环的某一条边上（上边、下边、左边或右边）。
  - 每个环的内部（环围成的空心区域）有一个小型彩色对象（2-4 个像素组成的连通块，颜色各不相同，与轨道色和标记色不同），位于环内部的某个位置。

- `Rule`：
  - 第一层：移动方向——观察每个环上 Maroon 标记所在的边：标记在上边或右边 → 内部对象沿顺时针方向移动；标记在下边或左边 → 内部对象沿逆时针方向移动。
  - 第二层：移动步数——Maroon 标记的数量即为对象需要移动的步数。每"一步"定义为对象整体沿轨道内侧平移一个像素（对象沿矩形内壁滑动：向右到底则转向下，向下到底则转向左，以此类推；对象保持形状不变，不旋转）。
  - 对象移动后，轨道上的 Maroon 标记恢复为轨道颜色（Azure）。对象的原始位置变为背景色。

- `Key insight`：标记像素承担双重编码——它们的数量是步数，它们所在的边是方向信号；解题者必须同时提取这两层信息才能确定每个环内对象的最终位置。单独观察数量或位置都无法解出完整规则。
</new_puzzle>
