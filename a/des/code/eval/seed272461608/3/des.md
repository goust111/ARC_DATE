<new_puzzle>
- `description`：根据封闭区域内"种子"像素的颜色，在区域边界上找到对应颜色的出口缺口，然后从种子位置向出口方向生长路径树。

- `Input structure`：
  - bg = 背景色（最常见颜色）。一种墙壁颜色（如 green）构成若干封闭的不规则区域，每个区域的边界墙上有一个或多个单像素缺口。
  - 每个缺口像素被涂上了某种非背景、非墙壁的颜色（如 red、blue、yellow 等）。
  - 每个封闭区域内部恰好有一个"种子"像素，颜色与该区域某个缺口的颜色相同。

- `Rule`：
  - 对每个封闭区域，找到其中的种子像素及其颜色 c。
  - 在该区域的边界缺口中，找到颜色同为 c 的缺口位置。
  - 从种子像素出发，沿正交方向（上下左右）在区域内部的 bg 格子上绘制一条最短的 L 形路径（最多一次转弯）到达该缺口，路径颜色为 c。
  - 路径只能经过 bg 格子，不能穿越墙壁或已有路径。
  - 其余不匹配的缺口和种子保持不变。

- `Key insight`：解题者需要先通过颜色匹配将种子与缺口配对（颜色匹配层），再推断出路径规则是"最短 L 形连接"而非自由最短路（几何规则层）。两层规则都不能仅从单一样例中确定。
</new_puzzle>

<new_puzzle>
- `description`：将网格中散落的彩色碎片按颜色分组，每组碎片拼合还原为一个完整矩形，再按矩形面积从小到大依次嵌套堆叠输出。

- `Input structure`：
  - bg = 背景色。网格中散落着若干彩色连通分量（碎片），每种非背景颜色对应 2~4 个碎片。
  - 同一颜色的所有碎片恰好能无重叠地拼合成一个实心矩形（碎片形状互补）。
  - 不同颜色拼合出的矩形尺寸各不相同。

- `Rule`：
  - 将同颜色碎片视为一组，推断每组拼合后的矩形尺寸（即该颜色所有碎片像素总数 = 矩形面积，且只有唯一的宽×高分解方式使碎片能无缝拼合）。
  - 按矩形面积从小到大排序。
  - 输出一个新网格：最大矩形居中放置，次大矩形居中叠放在其上方（覆盖），依次类推，最小矩形在最顶层。
  - 所有矩形共享同一中心点（水平和垂直方向都居中对齐）。

- `Key insight`：解题者首先需要识别出同颜色碎片属于同一矩形的"拆分件"（分组与拼合层），然后需要发现输出的堆叠顺序是按面积排列且居中对齐的嵌套结构（排序与堆叠层）。碎片在输入中的空间位置与输出无关，这增加了迷惑性。
</new_puzzle>

<new_puzzle>
- `description`：网格中的彩色箭头指向相邻区域，每个区域的输出颜色由指向它的所有箭头的来源区域颜色混合决定。

- `Input structure`：
  - bg = 背景色。grey 色线条将网格划分为若干矩形区域（类似九宫格或不规则网格）。
  - 每个区域内部填充了某种纯色（非 grey、非 bg），或者为 bg（空区域）。
  - 部分区域的边界处（紧邻 grey 分隔线内侧）有一个箭头形状的小标记（由 3 个像素构成的 L 形指示器：两个像素构成箭杆，一个像素偏移构成箭头方向），箭头颜色为 maroon。箭头指向该区域的某个正交邻居区域。

- `Rule`：
  - 对每个区域 R，收集所有指向 R 的箭头。每个箭头位于某个来源区域 S 中。
  - 如果恰好有一个箭头指向 R，则 R 的输出颜色变为来源区域 S 的颜色。
  - 如果没有箭头指向 R，则 R 保持原色不变。
  - 如果有多个箭头指向 R，则 R 的输出颜色为所有来源区域中面积最大的那个区域的颜色。
  - 箭头标记本身在输出中被移除（替换为该区域的输出颜色）。

- `Key insight`：解题者需要先理解箭头的方向编码方式（从 3 像素的 L 形中读出指向，标记解码层），再发现颜色传播是"接收端视角"而非"发送端视角"（规则归纳层），最后在多箭头冲突时需要发现面积优先的 tie-break 规则（冲突消解层）。
</new_puzzle>

<new_puzzle>
- `description`：在网格中找到被噪声像素包围的隐藏矩形轮廓，根据轮廓内部的颜色图案推断缺失角落的内容并补全。

- `Input structure`：
  - bg = 背景色（最常见颜色）。网格中有一个由某种边框颜色（如 blue）构成的矩形空心框，框内填充着由 2~3 种颜色组成的规律性图案（如棋盘格、条纹、或 2×2 块状重复等）。
  - 矩形框的一个角落区域（占矩形面积约 1/4）被"擦除"——该角的边框线和内部图案都被替换为 bg。
  - 在矩形框外部的 bg 区域中，散布着若干与框同色的噪声像素（孤立的 blue 像素），以及少量与内部图案颜色相同的噪声像素。

- `Rule`：
  - 忽略所有框外噪声像素（连通分量面积 ≤ 2 的同色像素块视为噪声）。
  - 从保留的三个角推断出完整矩形的边界位置。
  - 分析框内可见区域的颜色图案，识别其周期性重复规则（沿行和列方向的最小重复单元）。
  - 用该重复单元填充缺失角落区域的内部图案，并补全缺失的边框线段。

- `Key insight`：解题者需要先从带噪声的网格中区分出真正的矩形边框与散落的噪声点（去噪与结构识别层），然后从三个可见角推断矩形的完整范围（几何推断层），最后识别内部图案的周期性并外推到缺失区域（图案归纳与补全层）。噪声像素故意使用与目标结构相同的颜色，增加了识别难度。
</new_puzzle>

<new_puzzle>
- `description`：网格中多个形状各异的彩色岛屿通过颜色编码的"桥墩"标记，两两之间架设正交桥梁，桥的宽度由桥墩标记的尺寸决定。

- `Input structure`：
  - bg = 背景色。网格中有若干不规则形状的彩色岛屿（每个岛屿为单一颜色的连通区域，颜色各不相同）。
  - 部分岛屿的边缘上嵌有一个或多个小方块标记（1×1 或 2×2），标记颜色与另一个岛屿的颜色相同。标记占据岛屿边界的最外侧像素位置。

- `Rule`：
  - 如果岛屿 A 的边缘带有颜色为 c_B 的标记，且岛屿 B（颜色为 c_B）的边缘带有颜色为 c_A 的标记，则 A 和 B 需要架桥连接。
  - 桥的方向：从 A 上 c_B 标记的位置出发，沿该标记所在边缘的法线方向（向外正交方向）延伸，直到到达岛屿 B 的边界。桥只能沿水平或垂直方向延伸。
  - 桥的宽度等于标记的边长（1×1 标记 → 宽度 1 的桥，2×2 标记 → 宽度 2 的桥）。
  - 桥的颜色为 grey。
  - 如果从 A 的标记出发沿法线方向无法直线到达 B，则桥做一次直角转弯（L 形），转弯点取使桥总长最短的位置。

- `Key insight`：解题者需要先发现"互相持有对方颜色标记"的配对规则（双向标记配对层），再理解标记尺寸编码桥宽的机制（尺寸语义层），最后推断桥的路径选择规则——优先直线、必要时 L 形转弯且取最短路径（路径构造层）。
</new_puzzle>

<new_puzzle>
- `description`：根据网格边缘的颜色编码刻度尺，对网格内部的彩色条带执行裁剪或延伸，使每个条带的长度与刻度尺上对应颜色段的长度一致。

- `Input structure`：
  - bg = 背景色。网格的最左列（或最上行）是一个"刻度尺"：由多种颜色的连续色段纵向（或横向）排列而成，每个色段长度不同（如 red 占 3 格、blue 占 5 格、yellow 占 2 格等）。
  - 网格内部有若干水平（或垂直）条带，每个条带为某种纯色，颜色与刻度尺中的某一段匹配。条带的当前长度可能与刻度尺中对应色段的长度不同。
  - 每个条带的一端固定（紧贴网格边缘或某个墙壁色障碍物）。

- `Rule`：
  - 对于每个内部条带，在刻度尺中找到与其同色的色段，读取该色段的长度 L。
  - 如果条带当前长度 > L，从条带的自由端（非固定端）裁剪，使其长度变为 L。
  - 如果条带当前长度 < L，从自由端沿原方向延伸，使其长度变为 L。延伸时只覆盖 bg 格子，遇到非 bg 障碍则停止。
  - 刻度尺本身在输出中保持不变。

- `Key insight`：解题者首先需要识别出边缘列/行是一个"刻度尺"而非普通对象（结构角色识别层），然后需要发现条带长度与刻度尺中同色段长度的对应关系（跨区域属性映射层）。刻度尺上色段的排列顺序与条带的空间位置无关，迫使解题者依赖颜色匹配而非位置对应。
</new_puzzle>

<new_puzzle>
- `description`：每个彩色形状根据其内部孔洞的数量，查阅角落图例确定旋转角度，然后原地旋转。

- `Input structure`：
  - bg = 背景色。网格中有若干互不接触的彩色形状（每个形状为单色连通区域），颜色各不相同。
  - 部分形状内部包含 0、1、2 或 3 个由 bg 构成的封闭孔洞（孔洞是被形状像素完全包围的 bg 连通区域）。
  - 网格的某个角落（如右下角）有一个小型"图例区域"，用墙壁色框起，内部展示四个小示意图，从左到右分别标注了 0 孔、1 孔、2 孔、3 孔对应的旋转操作：不旋转、顺时针 90°、顺时针 180°、顺时针 270°。每个示意图由一个简单的 L 形标记在四种朝向下展示。

- `Rule`：
  - 数出每个彩色形状内部的孔洞数 n（0 ≤ n ≤ 3）。
  - 查阅图例区域，找到 n 对应的旋转角度。
  - 以该形状的包围盒中心为旋转中心，将形状旋转对应角度。
  - 旋转后的形状保持其包围盒中心位置不变。图例区域在输出中保持不变。

- `Key insight`：解题者需要先注意到角落的图例区域是一个"解码器"而非普通对象（图例识别层），然后需要发现"孔洞数量"是选择旋转角度的索引键（属性-操作映射层）。孔洞数量是肉眼可数的视觉属性，但将其与旋转操作关联需要主动推理。
</new_puzzle>
