  - 网格中散布着多种颜色的单个像素点（如 red、blue、green、yellow 等）。
  - 在网格的某些行的最左或最右端、某些列的最上或最下端，有用 maroon 像素绘制的小箭头标记。箭头由 3 个 maroon 像素组成：一个像素在边缘上，另外两个像素在其内侧斜对角形成箭头尖端，指示推送方向（向右的箭头：边缘像素在最左列，两个斜对角像素在其右上和右下；向左的箭头：边缘像素在最右列，两个斜对角像素在其左上和左下；向下和向上类似）。
  - 每行或每列最多有一个箭头。没有箭头的行/列不受影响。
- `Rule`：
  - 第一步（方向识别）：根据每个 maroon 箭头的 3 像素形态判断其指向方向（上/下/左/右）。
  - 第二步（推送）：对于带有箭头的每一行/列，收集该行/列中所有非 black、非 maroon 的彩色像素，保持它们的原有线性顺序（从箭头反方向到箭头方向的顺序），将它们紧密堆叠到箭头指向的那一侧边界。堆叠从边界开始向内排列，像素之间无间隙。

- `Key insight`：第一层推理需要从 3 像素的 maroon 标记中归纳出方向编码规则（箭头形态与推送方向的映射），第二层推理需要理解"保序紧密堆叠"的推送机制——像素不是简单移动到边界，而是按原有顺序压缩排列。同一网格中行箭头和列箭头共存时，行操作和列操作独立执行（先行后列），这是第三层需要从样例中发现的执行顺序。
