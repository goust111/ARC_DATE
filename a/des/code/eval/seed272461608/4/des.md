<new_puzzle>
根据围栏缺口方向与内部种子贴壁位置，从缺口向外生长出带侧向分支的彩色树状结构。

Input structure:
- bg = black。网格中散布若干由单一非黑色构成的封闭矩形围栏（壁厚1像素）。
- 每个围栏恰好在一条边上有一个1像素宽的缺口。
- 围栏内部放置了1至3个不同颜色的"种子"像素，每个种子与围栏某一面内壁四连通相邻，且各种子所贴的内壁方向互不相同。

Rule:
- 第一层推理——确定主干方向：围栏缺口所在的边决定"主干生长方向"（缺口在上边则主干向上延伸，缺口在右边则主干向右延伸，以此类推）。
- 第二层推理——确定各种子的分支侧向：每个种子紧贴的那面内壁所朝的方向，就是该种子对应分支的侧向延伸方向。例如种子贴在围栏左内壁，则其分支向左。
- 第三层推理——生长规则：从缺口位置出发，沿主干方向画一条围栏颜色的"主干线"，长度 = 种子总数 * 2 像素。在主干线上，按种子在围栏内沿主干轴方向距缺口从近到远的顺序，每隔2像素处设一个分支节点。每个分支节点向对应种子的侧向延伸一条该种子颜色的线段，线段长度 = 该种子在围栏内部沿主干轴方向距缺口边的像素格数。
- 围栏和内部种子在输出中保留不变。

Key insight: 缺口方向编码主干朝向，种子贴壁方位编码分支侧向，种子沿主轴到缺口的距离编码分支长度——三层信息分别需要独立归纳，共同决定最终的树状结构。
</new_puzzle>

<new_puzzle>
将散布的单色碎片按形状互补性配对为完整矩形，再根据虚拟拼合后两碎片的左右空间关系互换颜色。

Input structure:
- bg = black。网格上散布偶数个单色四连通碎片，每块碎片颜色各不相同。
- 每两块碎片的形状恰好能在同尺寸矩形内无重叠、无缝隙地互补拼合成实心矩形（仅需平移，不需要旋转或翻转）。
- 不同配对组拼成的矩形尺寸可以不同，但同一组内两块碎片的边界框大小相同。

Rule:
- 第一层推理——互补配对：对所有碎片按边界框尺寸分组。在同一尺寸组中，若碎片A的形状恰好等于同尺寸矩形中碎片B形状的补集（即A填满B在矩形内留下的空白），则A与B配对。
- 第二层推理——颜色互换：在虚拟拼合成的矩形中，计算每块碎片所有像素的平均列坐标（在碎片自身边界框内的相对坐标）。平均列坐标较小者为"左片"，较大者为"右片"。将左片的颜色赋给右片，将右片的颜色赋给左片。
- 输出时所有碎片保持原始位置不动，仅改变颜色。

Key insight: 先通过形状互补性发现隐含的配对关系，再通过虚拟拼合后的左右空间位置确定颜色交换方向——配对规则和交换规则是两层独立的非显然推理。
</new_puzzle>

<new_puzzle>
在由grey线划分的棋盘格局中，每个区域内的red箭头指向相邻区域，沿箭头链追踪到无箭头的终点区域后，用终点区域的图案覆盖链上所有区域的图案。

Input structure:
- bg = black。网格被grey色单像素宽的横纵直线均匀划分为大小相同的矩形区域（例如5x5的区域排成3x3或4x4的格局）。
- 每个区域内部包含一个小型彩色图案（3x3以内的sprite，颜色非red非grey非black）。
- 部分区域内还有一个由red像素构成的3像素"箭头"：由一个中心像素、一个沿指向方向与中心相邻的像素、以及一个位于中心像素垂直于指向方向一侧的像素组成，三像素构成L形，其中长边（2像素）指示方向（上、下、左、右之一）。
- 若干区域没有箭头，这些是"终点区域"。

Rule:
- 第一层推理——箭头方向解读：每个区域内的red箭头L形中，两个共线像素的延伸方向即为箭头指向，表示"跳转到该方向的相邻区域"。
- 第二层推理——链式追踪：从含箭头的区域出发，沿箭头方向跳到相邻区域。若该区域也有箭头，继续沿新方向跳转，直到到达没有箭头的终点区域。
- 变换：将终点区域的图案（形状和颜色）复制到链上所有途经区域和起点区域中，替换它们原有的图案，图案放置在区域内相同的相对位置。所有red箭头像素在输出中被移除（变为bg）。终点区域图案不变。

Key insight: 箭头不是描述图案的变换方式，而是构成区域之间的"传递链"——必须沿链逐步追踪到终点，才能确定每个区域最终显示的图案。多条链可能汇聚到同一终点。
</new_puzzle>

<new_puzzle>
根据"钥匙"碎片的形状旋转匹配"锁体"表面的凹槽，匹配成功后用钥匙的颜色填充锁体内部隐藏的空腔。

Input structure:
- bg = black。网格中有若干大型单色实心矩形（"锁体"），每种锁体颜色不同。
- 每个锁体的一条边上刻有一个凹入内部的小型凹槽（"锁孔"），凹槽由bg像素构成，形状为不规则但四连通的区域（深度2-4像素，宽度2-5像素），从锁体边缘向内延伸。
- 每个锁体内部深处还有一个更大的封闭空腔（由bg像素构成的四连通区域，完全被锁体像素包围，与锁孔不连通）。
- 网格上另有若干小型彩色四连通碎片（"钥匙"），颜色各不相同且与所有锁体颜色不同。每把钥匙的形状恰好与某个锁孔的凹槽形状在某个旋转角度（0/90/180/270度）下完全吻合。

Rule:
- 第一层推理——旋转匹配：将每把钥匙尝试0/90/180/270度旋转，与每个锁孔凹槽的形状比对，找到形状完全一致的唯一配对。
- 第二层推理——颜色填充：配对成功后，将该钥匙的颜色填充到对应锁体内部的整个封闭空腔中（空腔内所有bg像素变为钥匙颜色）。
- 钥匙从原位消失（变为bg）。锁孔凹槽保持不变（仍为bg）。锁体外形不变。

Key insight: 钥匙的形状是配对凭据，必须通过旋转匹配发现归属关系；而钥匙的颜色才是最终变换的载体，用来填充锁内不可见的空腔。形状决定归属，颜色决定填充——两层推理目标完全不同。
</new_puzzle>

<new_puzzle>
将分散的同色线段碎片通过端点共线关系连通为完整电路，再判断电路是否形成封闭回路，若是则将回路围住的"灯泡"像素点亮为电路颜色。

Input structure:
- bg = black。网格上有若干不同颜色的单像素宽直线段（水平或垂直方向），每种颜色代表一条独立的"电路"。同一颜色有2至4条不相连的线段，散布在网格各处。
- 网格上另散布若干yellow单像素点（"灯泡"）。

Rule:
- 第一层推理——端点连通：对同一颜色的所有线段，检查是否有两条线段各有一个端点处于同一行或同一列上，且两端点之间的所有像素均为bg。若满足条件，用该颜色画一条直线将这两个端点连接。每个端点至多参与一次连通。
- 第二层推理——回路检测与灯泡点亮：连通完成后，检查每种颜色的像素网络中是否存在封闭回路（即沿该颜色像素的四连通路径能从某像素出发回到自身，且路径长度大于4）。若某颜色电路形成了封闭回路，则回路内部区域（被回路像素完全包围的bg区域）中的所有yellow灯泡像素变为该电路颜色。不在任何回路内部的yellow灯泡保持不变。未形成回路的电路不影响灯泡。
- 输出保留所有线段（含新画的连接线）及灯泡（部分变色）。

Key insight: 必须先通过共线端点关系发现并补全隐含的电路连接，然后才能判断电路拓扑是否形成闭环——连通规则和闭环判定是两层独立推理，灯泡是否变色取决于它是否被闭环包围。
</new_puzzle>

<new_puzzle>
根据容器开口方向沿射线收集外部粒子，将粒子按距离远近排序后从容器底部向开口方向逐个堆叠，保持各粒子原色。

Input structure:
- bg = black。网格中有若干用grey像素绘制的U形容器（三面封闭、一面敞开），壁厚1像素，内部空间宽2-4像素、深2-4像素。每个容器恰好有一个开口方向（上、下、左、右之一），由缺失的那面壁决定。
- 网格上散布若干不同颜色的单像素"粒子"（颜色非grey非black），位于所有容器外部。

Rule:
- 第一层推理——开口方向与粒子捕获：从每个容器的开口处，沿开口方向向外发射覆盖整个开口宽度的平行射线（射线数 = 开口宽度像素数），延伸到网格边缘。射线路径上遇到的所有粒子都被该容器捕获。若某粒子同时在两个容器的射线上，则归属于开口更近的那个容器。
- 第二层推理——堆叠排列：每个容器捕获的粒子按它们距容器开口的距离从近到远排序。排好序后，粒子从容器底部（与开口相对的内壁）开始，沿朝向开口的方向逐像素堆叠。每个粒子占据容器内一行（或一列，取决于开口方向）的中央1个像素位置，保持粒子原始颜色。若容器深度不够容纳全部粒子，多余的丢弃。
- 被捕获的粒子从原位消失（变为bg）。容器形状不变。

Key insight: 容器的几何形状编码了两个关键信息——开口方向决定从哪个方向吸收粒子，而容器深度方向决定堆叠排列的轴向。必须先推断开口朝向，再根据粒子与开口的距离确定堆叠顺序，两步缺一不可。
</new_puzzle>
