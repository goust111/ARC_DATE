<description>
根据种子像素的颜色在网格中生长分形树，树枝在碰到同色边框时停止，不同树的枝干交叉处采用后生长者覆盖。

Input structure:
- 背景色为黑色（black）。网格中散布若干单像素的"种子"，每个种子颜色不同。
- 网格边缘存在若干与种子同色的边框线段（长度大于等于 2 的连续同色像素贴在网格边界上）。
- 每个种子颜色恰好在边界上出现一条对应的同色边框线段。

Rule:
- 第一步：确定每个种子的生长方向。种子向其同色边框线段所在的那条边界的反方向生长（例如边框在网格顶部，则种子向下生长）。
- 第二步：从种子出发，沿生长方向画一条主干线（逐像素延伸），直到碰到网格边界或碰到同色边框线段为止。
- 第三步：主干线上每隔两个像素（即主干的第 1、4、7... 格），向主干的垂直两侧各延伸一条分支线，分支长度等于该像素在主干上的序号（从 1 开始计数），分支碰到网格边界或已有同色像素时提前截断。
- 所有种子按照其在网格中从上到下、从左到右的扫描顺序依次生长；后生长的树枝覆盖先前像素。

Key insight: 需要先通过边框颜色匹配确定每棵树的生长方向，再按序号规律确定分支长度；生长顺序决定了交叉处的覆盖关系。
</description>
</new_puzzle>

<new_puzzle>
<description>
将网格中的多个彩色路径按照路径交叉点处的"立交桥"规则重新着色，使每条路径在视觉上呈现上下穿越关系。

Input structure:
- 背景色为黑色（black）。网格中有若干条由不同颜色绘制的单像素宽路径（4-连通），路径之间存在交叉点。
- 每个交叉点处恰好有两条不同颜色的路径相遇，交叉点本身被标记为灰色（grey）像素。
- 网格的一个角落（如左上角）有一个小的"优先级图例"区域，用一列彩色像素从上到下排列，表示路径的上下层叠顺序（最上方像素代表最上层路径）。

Rule:
- 第一步：从图例中读取路径颜色的层叠优先级，顶部颜色优先级最高（在上层），底部最低（在下层）。
- 第二步：对于每个灰色交叉点，找到在该点交叉的两条路径的颜色。将交叉点像素改为优先级更高（更上层）的那条路径的颜色。
- 第三步：对于优先级较低（下层）的那条路径，将交叉点两侧各一个像素（沿该低优先级路径的行进方向）改为黑色（背景色），模拟被上层路径遮挡的"断口"效果。
- 输出时移除图例区域，只保留处理后的路径网格。

Key insight: 图例定义了全局层叠顺序；交叉点处高优先级路径保持连续，低优先级路径在交叉点附近产生视觉断口，形成"立交桥"效果。需要同时推断图例的含义和断口的生成规则。
</description>

<description>
根据网格中散落的碎片颜色和形状，将它们归位到正确的容器中，容器的"锁"决定碎片需要经过何种旋转才能放入。

Input structure:
- 背景色为黑色（black）。网格中有若干个由绿色（green）像素绘制的矩形容器（空心矩形框），每个容器的一条边上有一个缺口（宽度为 1 像素的断开）。
- 每个容器内部为空（黑色背景）。容器缺口旁边（容器外侧）紧贴一个由红色（red）像素组成的小标记，标记为 1 至 3 个红色像素排成一行或一列，称为"锁标记"。
- 网格中另有若干彩色碎片（非绿色、非红色、非黑色的小型连通图案），散落在容器外部。每个碎片的边界框尺寸恰好与某个容器的内部空间尺寸匹配。

Rule:
- 第一步：将每个碎片与内部空间尺寸匹配的容器配对（每个碎片恰好匹配一个容器，尺寸匹配时可能需要旋转 90/180/270 度后才能吻合）。
- 第二步：读取每个容器的锁标记中红色像素的数量 N（1、2 或 3）。碎片需要顺时针旋转 N 乘以 90 度后放入容器内部。
- 第三步：将旋转后的碎片放置到对应容器的内部空间中（左上角对齐），同时从原位置移除碎片。

Key insight: 配对需要通过尺寸匹配完成（可能需要考虑旋转后的尺寸），而锁标记的像素计数决定了具体的旋转角度——这是两个独立的推理层：先匹配"哪个碎片去哪个容器"，再确定"怎么旋转放进去"。
</description>

<description>
将网格中的彩色像素簇视为"墨水滴"，根据它们之间的连线图案确定合并关系，并按照色卡查表确定混合后的颜色。

Input structure:
- 背景色为黑色（black）。网格中有若干个小型单色像素簇（面积 2 至 6 像素的 4-连通区域），每个簇颜色各异。
- 某些簇之间由灰色（grey）单像素宽的直线段相连（水平或垂直），灰色线段不与簇重叠，而是从一个簇的边缘延伸到另一个簇的边缘。
- 网格底部有一行"色卡"：若干个 1x2 的小方块，每个小方块左半格和右半格各为一种颜色，下方紧贴一个第三种颜色的单像素，表示"左色加右色等于下色"的混合规则。

Rule:
- 第一步：从色卡中读取所有颜色混合规则，建立"颜色A加颜色B得到颜色C"的映射表。
- 第二步：找到所有由灰色线段相连的簇对。对于每一对相连的簇，查表得到它们混合后的目标颜色。
- 第三步：将每对相连簇之间的灰色线段替换为目标混合颜色。同时，如果某个簇连接了多条灰色线段，则该簇本身也变为它与所有邻居依次混合的结果颜色（混合顺序为邻居从上到下、从左到右排列，每次取当前结果色与下一个邻居色查表）。
- 输出时移除底部色卡区域。

Key insight: 色卡是一个需要主动解读的"查找表"，定义了非直觉的颜色混合规则；解题者必须先破译色卡的编码方式，再根据连接关系和混合表推算每个区域的最终颜色。
</description>

<description>
识别网格中由边框围成的"窗户"，根据窗户内部图案的对称性类型，在窗户外侧绘制对应方向的标记箭头。

Input structure:
- 背景色为黑色（black）。网格中有若干个矩形"窗户"，每个窗户由单像素宽的彩色边框围成（不同窗户边框颜色不同）。
- 每个窗户内部有一个由另一种颜色绘制的小图案（3x3 至 5x5 大小），图案不一定对称。
- 窗户之间互不重叠，且间距至少 2 像素。

Rule:
- 第一步：分析每个窗户内部图案的对称性类型：
  -- 若图案仅有水平对称轴（左右镜像对称），标记方向为"上下"。
  -- 若图案仅有垂直对称轴（上下镜像对称），标记方向为"左右"。
  -- 若图案同时有水平和垂直对称轴（双轴对称），标记方向为"四方"。
  -- 若图案无任何对称轴，不绘制箭头。
- 第二步：根据标记方向，在窗户外侧对应方位绘制箭头。箭头由边框同色像素绘制，形状为：沿指向方向延伸 2 像素的线段，末端左右各加 1 像素形成箭尖（即末端为 3 像素的横排或竖排，加上 2 像素的杆）。
  -- "上下"方向：在窗户正上方和正下方各画一个箭头，箭头位于边框顶边和底边的中点外侧，分别指向上和下。
  -- "左右"方向：在窗户正左方和正右方各画一个箭头，箭头位于边框左边和右边的中点外侧，分别指向左和右。
  -- "四方"方向：在窗户四个方位各画一个箭头。
- 箭头起点紧贴窗户边框外侧中点位置。

Key insight: 解题者需要先识别每个内部图案属于哪种对称性类别（这不是直接可见的，需要心理旋转或翻转来验证），然后将对称性类型映射到箭头方位——对称轴的方向与箭头的方向是垂直关系（水平对称轴对应上下箭头），这一映射本身也需要从样例中归纳。
</description>

<description>
根据网格中"时钟"图案的缺口方向发射信号色射线，信号在碰到"镜子"时反射并按映射表改变颜色。

Input structure:
- 背景色为黑色（black）。网格中有若干个 3x3 的"时钟"图案：外圈 8 个像素为蓝色（blue）形成方框，中心 1 个像素为某种非蓝非黑的信号色。
- 方框的某一条边（上、下、左、右）的中间像素缺失（变为黑色），形成一个缺口，表示指针方向（信号从缺口方向射出）。
- 网格中另有若干 1x3 或 3x1 的"镜子"线段，由橙色（orange）像素绘制，方向为水平或垂直。
- 网格右上角有一个颜色映射表区域：两列彩色像素，左列为输入颜色，右列为输出颜色，每行一对，表示信号碰到镜子后颜色如何变化。

Rule:
- 第一步：从每个时钟的缺口方向确定信号的初始传播方向（缺口朝上则信号向上射出，依此类推）。
- 第二步：信号以时钟中心的颜色出发，沿缺口方向逐像素传播，在背景像素上绘制当前信号色。
- 第三步：信号碰到镜子时发生反射——水平镜子（1x3）使垂直运动的信号反转上下方向，垂直镜子（3x1）使水平运动的信号反转左右方向。同时，信号颜色按照右上角的映射表变换为新颜色，后续绘制使用新颜色。
- 第四步：信号碰到网格边界、另一个时钟的蓝色边框、或另一条已有信号路径时停止。
- 输出时保留映射表。

Key insight: 解题者需要同时推断三层规则：缺口编码传播方向、镜子朝向决定反射方式、以及颜色映射表的查表变色规则。信号路径的最终形态是三层规则共同作用的结果。
</description>

<new_puzzle>
<description>
在由灰色线条分隔的区域中，根据邻接关系和"染色约束图例"为未着色区域填入唯一合法的颜色。

Input structure:
- 背景色为黑色（black）。网格被灰色（grey）单像素宽线条分割成若干不规则区域。
- 每个区域内部被填充为某种颜色（非灰色、非黑色），但部分区域被填充为黑色（表示未着色）。
- 网格左侧有一个小的"约束图例"区域，由灰色边框包围。图例内部有若干对紧邻的彩色像素对（水平相邻），每对表示"这两种颜色允许相邻"。

Rule:
- 第一步：读取约束图例，建立允许相邻的颜色对集合。图例中每一对水平相邻的彩色像素代表一条允许规则。
- 第二步：识别所有已着色区域和未着色（黑色填充）区域。两个区域"相邻"指它们之间仅隔一条灰色线条（共享灰色边界）。
- 第三步：为每个未着色区域确定唯一合法颜色——该颜色必须与所有相邻的已着色区域的颜色都构成约束图例中允许的配对，且在所有可用颜色中只有一种颜色满足全部约束。
- 第四步：将未着色区域填充为确定的合法颜色。输出时移除图例区域。

Key insight: 图例定义的是"允许相邻"的配对而非禁止配对——解题者需要先理解图例编码方式，再结合每个空白区域的所有邻居颜色进行约束推理，空白区域的答案由邻居集合和约束表共同唯一确定。
</description>
</new_puzzle>
