- `Input structure`：
  - 背景色（bg）为最常见颜色。
  - 网格中有若干由单一非 bg 颜色（边框色 B）绘制的空心矩形"容器"，容器内部全部为 bg。
  - 每个容器的边框上有 1 至 4 个像素被替换为另一种颜色（标记色 M，所有容器共享同一标记色），这些标记像素位于边框的四条边上。
  - 网格某处有一个"样板区"：一个已经被正确填充的小容器，展示填充规则的效果。

- `Rule`：
  - 第一步（读取标记）：对每个未填充的容器，检查其四条边框边（上、下、左、右）上是否存在标记像素 M。将有标记的边记为"激活边"。
  - 第二步（生成填充图案）：容器内部按行列交替填充两种颜色——边框色 B 和标记色 M。具体规则为：如果"上边"或"左边"被激活，则内部左上角第一个像素为 M，否则为 B；然后沿行和列交替切换颜色（棋盘格式）。若激活边的数量为奇数，则填充为棋盘格（行列同时交替）；若为偶数，则填充为水平条纹（仅逐行交替，同一行内颜色相同）。
  - 样板区容器保持不变，仅对空容器执行填充。

- `Key insight`：标记像素的位置（哪条边被激活）决定棋盘图案的相位起点，而标记的数量奇偶决定填充模式是棋盘还是条纹，需要同时关注标记的空间分布和计数两个维度。

## 实现要求

1. `main(grid)` 必须实现新题描述中的确定性转换规则，不能只识别 `generate_input()` 的固定模板。
2. `generate_input()` 必须随机生成多样样例，不能固定死。随机维度应覆盖：网格大小、对象数量、位置、颜色、方向、形状参数或关键分支。
3. 生成器必须保证输入满足 `main()` 的隐式假设：对象不重叠、不越界、特殊标记唯一或可区分、匹配关系无歧义、关键分支出现概率相同。
4. 禁止把 ARC 颜色 id 、亮度、拼写等当作人类不可见的数值语义参与排序、大小比较或隐藏映射。颜色变化必须有可见结构线索。注意颜色亮度、拼写等也是不可见信息，若描述中出现违规的颜色id或者亮度，可自行使用少量的固定颜色替代，但注意生成时要在三个以内输入输出网格中对所有变换100%覆盖度。
