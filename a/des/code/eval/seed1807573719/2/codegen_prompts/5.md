- `Input structure`：
  - 背景色 bg 为最常见颜色。网格中有若干条水平或垂直的彩色线段（每条线段由同一种非 bg 颜色的连续像素组成，长度 ≥ 2），线段之间不接触、不重叠。
  - 每条线段的一个端点处紧邻一个不同颜色的单像素标记（"发射标记"），标记位于该端点沿线段垂直方向偏移1像素的位置。例如：一条水平线段的左端点上方有一个标记像素，表示该线段向上发射。

- `Rule`：
  - 第一层（发射方向）：每条线段从发射标记所指示的方向发射一组平行射线——标记相对于线段端点的偏移方向（上/下/左/右）即为发射方向。射线从线段上每个像素位置出发（不含标记像素本身），沿发射方向前进，颜色为该线段的颜色。
  - 第二层（接力转发）：当一条射线命中另一条线段的某个像素时，该射线停止。被命中的线段随后从被命中的那个像素位置出发，沿自身的发射方向继续发出一条射线，颜色变为被命中线段的颜色。每条射线最多经历一次接力（即最终由两段组成：原始段 + 接力段）。
  - 第三层（痕迹绘制）：所有射线经过的 bg 像素被染上对应颜色。射线不覆盖已有线段像素或标记像素。未命中任何线段的射线延伸至网格边缘。

- `Key insight`：第一层需要从标记位置推断每条线段的射线发射方向；第二层的"接力"机制并非物理镜面反射，而是被命中线段用自己的方向和颜色重新发射——理解这种"接力"语义是核心难点；第三层则要求正确组合两段不同颜色的路径。三层规则产生的交叉投影图案看似复杂，但每步均为局部确定性操作。

1. `main(grid)` 必须实现新题描述中的确定性转换规则，不能只识别 `generate_input()` 的固定模板。

4. 禁止把 ARC 颜色 id 、亮度、拼写等当作人类不可见的数值语义参与排序、大小比较或隐藏映射。颜色变化必须有可见结构线索。注意颜色亮度、拼写等也是不可见信息，若描述中出现违规的颜色id或者亮度，可自行使用少量的固定颜色替代，但注意生成时要在三个以内输入输出网格中对所有变换100%覆盖度。
