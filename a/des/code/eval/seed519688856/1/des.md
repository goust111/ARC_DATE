<description>
根据彩色种子像素的颜色在网格线划分的格子中生长出对应形状，再按格子间的邻接关系将相邻格子中的形状用桥梁连接。

Input structure:
- 背景色为 black。网格被 grey 线条均匀划分为若干等大的方形格子（例如 5×5 的格子阵列，每个格子内部为 4×4 像素，grey 线宽 1 像素）。
- 每个格子内部要么为空（全 black），要么包含恰好一个彩色"种子像素"（位于格子内部的某个位置），颜色各异（如 red、blue、green、yellow 等）。
- 在网格外部的边缘区域，有若干小型"形状图例"：每个图例由一种颜色绘制一个小图案（如 L 形、T 形、十字形、正方形等），图例的颜色与某个种子像素的颜色一一对应。

Rule:
- 第一步（形状分配）：对于每个含种子像素的格子，找到网格外与该种子颜色相同的形状图例。将该形状图例的图案复制到格子内部，使图案的中心（或左上角，以图例中标记像素为锚点）对齐种子像素的位置。图案使用种子的颜色绘制。
- 第二步（桥梁连接）：检查所有水平或垂直相邻的、且都含有形状的格子对。对于每对这样的相邻格子，在它们共享的 grey 分隔线上，将分隔线中段的 grey 像素替换为 orange，形成一条宽 1 像素的"桥梁"。桥梁的长度等于两个格子中较小形状的宽度（水平相邻时）或高度（垂直相邻时），桥梁居中放置在分隔线上。
- 空格子不参与桥梁连接，与空格子相邻的含形状格子一侧不产生桥梁。

Key insight: 解题需要两层独立归纳——首先需要发现颜色图例与种子之间的匹配关系并理解形状复制规则，然后需要发现相邻非空格子之间的桥梁生成规则及桥梁长度的确定方式。两层规则互相独立，缺一不可。
</description>

<description>
识别网格中被噪声干扰的重复图案瓦片，根据每块瓦片中的"投票像素"修复所有瓦片为一致的干净图案。

Input structure:
- 背景色为 black。整个网格被无缝铺满若干等大的矩形瓦片（例如每块 6×6），没有间隔线。
- 每块瓦片本应是同一个彩色图案的副本，但部分瓦片中有少量像素被随机替换为错误颜色（噪声）。
- 在网格的最右列或最底行之外，有一个单独的小区域包含一个 maroon 色的数字形标记（由 maroon 像素拼成的数字图案，如 "2" 或 "3"），该数字指示每块瓦片中"最多有几个噪声像素"。

Rule:
- 第一步（瓦片分割与对齐）：将网格等分为若干瓦片。瓦片尺寸需要从网格尺寸和重复模式中推断（瓦片尺寸是网格宽高的公因数，且使得大多数瓦片高度相似）。
- 第二步（多数投票修复）：对于瓦片中每个位置 (r, c)，统计所有瓦片在该位置上出现的颜色，取出现次数最多的颜色作为"正确颜色"。
- 第三步（输出）：输出修复后的单块干净瓦片（即多数投票后的结果），尺寸等于一块瓦片的大小。maroon 数字标记不出现在输出中。

Key insight: 解题者需要首先识别出网格是由重复瓦片拼成的（瓦片之间没有显式分隔线，需要从重复模式推断瓦片边界），然后理解噪声修复的逻辑是跨瓦片的逐像素多数投票。maroon 数字标记是干扰项，它暗示噪声量但不直接参与修复算法。
</description>

<description>
将散落的彩色碎片按颜色回填到对应的带缺口框架中，碎片的插入朝向由框架缺口方向决定，且碎片之间存在遮挡优先级。

Input structure:
- 背景色为 azure。网格中有若干彩色矩形框架（仅边框，内部为 azure），每个框架用不同颜色绘制（如 red 框、green 框、yellow 框等）。每个框架的某一条边上有一个连续缺口（缺失若干像素的空洞，宽度各不相同）。
- 在网格中另一区域，散落着若干与框架同色的实心彩色碎片（不规则形状但每个碎片是一个 4-连通区域）。每种颜色恰好有一个框架和一个碎片。
- 每个碎片的最大宽度或最大高度恰好等于其对应框架缺口的长度。

Rule:
- 第一步（颜色匹配）：将每个碎片与同色框架配对。
- 第二步（朝向确定与插入）：确定每个框架缺口所在的边（上、下、左、右）。碎片从缺口方向"推入"框架内部——即碎片沿缺口朝内的方向平移，直到碎片的前缘触碰到框架的对边内壁。碎片在垂直于推入方向的轴上居中对齐缺口位置。
- 第三步（遮挡处理）：如果两个框架在网格中存在重叠区域，则框架面积较小的在上层（优先绘制）。碎片插入后，上层框架及其内部内容覆盖下层的像素。
- 输出中原始碎片的位置被清除为 azure。

Key insight: 解题者需要依次发现三层规则——颜色匹配（直观）、缺口方向决定推入方向并居中对齐（需要归纳）、以及重叠时小框架优先的遮挡规则（需要从有重叠的样例中推断）。缺口方向的判定和推入对齐是核心难点。
</description>

<description>
根据网格中箭头标记的指向，将每个封闭区域内的图案沿箭头方向"挤出"到区域外部，挤出长度由区域内特定颜色像素的数量决定。

Input structure:
- 背景色为 black。网格中有若干用 grey 像素绘制的封闭矩形区域（grey 构成矩形边框，内部非 grey）。
- 每个封闭区域内部包含一个由多种颜色组成的小图案（sprite），以及若干 maroon 像素散布在图案周围（maroon 像素不属于图案本身）。
- 每个封闭区域的某一条 grey 边框外侧紧贴着一个 red 箭头标记。箭头由 3 个 red 像素组成：一个像素为箭头尖端，另外两个像素在尖端的两侧各退一格，形成 "V" 形。箭头尖端指向远离框架的方向（即上、下、左、右之一）。

Rule:
- 第一步（方向读取）：对每个封闭区域，找到其外侧的 red 箭头，确定箭头尖端的朝向（上、下、左、右）。
- 第二步（挤出距离计算）：数出该封闭区域内部 maroon 像素的数量 N。
- 第三步（图案挤出）：将封闭区域内部的图案（不含 maroon 像素和 grey 边框）沿箭头方向复制到区域外部，偏移距离为 N 个像素。即图案整体沿箭头方向平移 N 格后绘制在网格上。原封闭区域内的图案保留不变，maroon 像素在输出中被清除为 black。
- 如果挤出后的图案超出网格边界，则超出部分被裁剪。

Key insight: 解题者需要独立发现两层非平凡规则：第一层是理解箭头标记编码了挤出方向（箭头的 V 形结构及其朝向需要从样例中归纳），第二层是发现 maroon 像素的数量决定挤出距离（maroon 像素看起来像噪声，但实际上是编码信息的计数器）。两层规则在视觉上互不干扰，需要分别发现。
</description>

<description>
在一个由彩色路径网络连接的节点图中，根据路径颜色的混合规则对节点进行重新着色，然后删除所有路径只保留着色后的节点。

Input structure:
- 背景色为 black。网格中散布着若干"节点"——每个节点是一个 3×3 的实心方块，初始颜色为 grey。
- 节点之间由宽度为 1 像素的彩色直线路径连接（水平或垂直），路径颜色各异（如 red、blue、green、yellow 等）。每条路径连接恰好两个节点（路径端点与节点边缘相邻）。
- 一个节点可能连接多条不同颜色的路径（最多四条，分别从上、下、左、右方向接入）。
- 在网格的一个角落区域，有一个"混色图例"：由若干小示例组成，每个示例展示两个颜色方块并排放置，旁边紧跟一个结果颜色方块。例如：red 方块 + blue 方块 → yellow 方块，表示 red 与 blue 混合得 yellow。

Rule:
- 第一步（收集路径颜色）：对每个 grey 节点，收集所有与之相连的路径的颜色，形成一个颜色集合。
- 第二步（颜色混合）：如果节点只连接一条路径，则节点变为该路径的颜色。如果连接两条或更多路径，则根据混色图例依次混合：先取任意两种颜色按图例查找混合结果，再将结果与下一种颜色继续混合（混合顺序不影响结果，因为图例定义的混合操作满足交换律和结合律）。
- 第三步（清理输出）：删除所有路径像素（变为 black），只保留重新着色后的 3×3 节点方块。

Key insight: 解题者需要首先识别出角落的混色图例是一个颜色映射查找表（而非装饰），然后理解节点的最终颜色由其所有相连路径颜色通过图例定义的混合函数迭代组合得到。混色图例的发现和正确应用是核心难点——解题者必须从图例的输入输出对中归纳出混合规则，再将其应用到网络中的每个节点上。
</description>

将网格中的多层嵌套框架逐层拆解展开为水平排列的独立框架，每层框架的填充颜色由其嵌套深度对应的色带决定。

Input structure:
- 背景色为 black。网格左侧区域包含一个多层嵌套的矩形框架结构：最外层是一个大矩形框架（仅边框，某种颜色如 blue），其内部包含一个稍小的矩形框架（另一种颜色如 red），red 框架内部又包含更小的框架（如 green），以此类推，最多嵌套 4-5 层。每层框架之间有 1 像素的 black 间隙。最内层框架的内部为一个实心彩色矩形（某种颜色如 yellow）。
- 网格右侧或底部区域有一条水平"色带"：由若干不同颜色的像素从左到右依次排列（如 orange、maroon、azure、green……），像素数量不少于嵌套层数。

Rule:
- 第一步（层数识别与拆解）：从外到内识别嵌套框架的层数 L（包括最内层的实心矩形）。将每一层视为一个独立的矩形环（最内层为实心矩形）。
- 第二步（尺寸保持展开）：将 L 个层从左到右水平排列，每层之间间隔 1 像素 black。每层保持其原始尺寸——即第 k 层的矩形环被绘制为一个独立的矩形框，外部尺寸与原始嵌套中该层的外边界一致，内部挖空（最内层保持实心）。
- 第三步（色带重着色）：从外层到内层，依次使用色带中从左到右的颜色对每层框架进行重新着色。即最外层框架用色带第 1 个颜色，第二层用色带第 2 个颜色，以此类推。最内层实心矩形用色带第 L 个颜色。
- 输出仅包含展开后的框架序列，原始嵌套结构和色带不保留。

Key insight: 解题者需要发现三层递进规则——首先是嵌套框架的逐层拆解（需要理解嵌套结构的层次关系），然后是保持原始尺寸的水平展开排列（而非统一缩放），最后是色带作为重着色查找表的对应关系（色带位置与嵌套深度一一映射）。嵌套层次的识别和色带映射需要独立归纳。

<description>
根据网格中"传送门"对的颜色匹配关系，将运动中的彩色粒子从一个传送门入口传送到同色传送门出口，并在传送后改变运动方向。

Input structure:
- 背景色为 black。网格中有若干"轨道"——由 grey 像素铺成的水平或垂直直线段（宽度 1 像素）。
- 轨道上放置着若干彩色粒子（单个非 grey、非 black 像素，如 red、blue、green），每个粒子占据轨道上的一个位置。
- 在某些轨道的交叉点或端点处，有成对出现的"传送门"标记：每个传送门是一个 1×2 或 2×1 的彩色小矩形（颜色与粒子颜色不同，如 yellow、maroon 等），跨在轨道上。同色传送门恰好成对出现，分布在不同的轨道上。
- 每个粒子旁边紧邻一个 orange 像素（不在轨道上），orange 像素相对粒子的方位（上、下、左、右）指示粒子的初始运动方向（粒子朝 orange 像素的反方向运动）。

Rule:
- 第一步（方向确定）：每个粒子的运动方向为 orange 标记的反方向。例如 orange 在粒子右边，则粒子向左运动。
- 第二步（移动与传送）：粒子沿运动方向在 grey 轨道上移动。当粒子到达一个传送门时，粒子消失并从同色的另一个传送门处出现。粒子在出现后沿新轨道的方向继续前进（如果传送门连接的是水平轨道与垂直轨道，则方向自然改变为新轨道的走向，保持原来的正/负方向分量）。
- 第三步（最终位置）：粒子在新轨道上继续移动直到到达轨道末端（grey 像素的尽头）为止。粒子最终停在轨道末端的位置。
- 输出中，orange 方向标记被清除为 black，传送门保持不变，粒子出现在其最终停止位置。

Key insight: 解题者需要依次发现三个非显然的规则：orange 像素编码方向的反转约定（不是朝向 orange 而是背离 orange），传送门的同色配对机制（颜色匹配连接两个远距离轨道），以及传送后方向继承规则（沿新轨道方向保持运动感）。三层规则构成了一个完整的粒子传送系统。
</description>
