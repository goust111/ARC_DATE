- `description`：根据每个对象"影子"的投射方向推断全局光源位置，再为缺少影子的对象补画正确方向和长度的影子。
- `Input structure`：
  - 背景色(azure)。网格中有若干小型实心矩形对象（2x2 到 4x4），每个对象用不同颜色绘制。
  - 部分对象旁边带有 grey 像素构成的"影子"——影子是从对象某一侧边缘向外延伸的矩形条带，宽度与对象该侧边等宽，延伸长度为 1-3 像素。所有有影子的对象的影子方向一致（都在对象的同一侧，如都在右侧或都在下方），暗示同一光源。
  - 部分对象没有影子（没有相邻的 grey 像素）。
  - 每个有影子的对象，其影子的延伸长度与对象自身面积相关：对象面积越大，影子越长。具体为：面积 4（2x2）→ 影子长 1，面积 6（2x3 或 3x2）→ 影子长 2，面积 ≥8 → 影子长 3。

- `Rule`：
  - 第一层（推断光源方向）：观察所有已有影子的方向（影子相对于对象的方位），确定全局光源的投射方向（影子出现在对象的哪一侧，则光从对侧照来）。
  - 第二层（推断长度规则）：观察已有影子的长度与对象面积的关系，归纳出面积→影子长度的映射。
  - 第三层（补画影子）：为所有缺少影子的对象，在正确方向上画出正确长度的 grey 影子。影子不覆盖其他对象——如果影子区域被其他对象占据，则影子在该对象边缘处截断。

- `Key insight`：解题者需要从有影子的样本中同时归纳两个独立规则：方向（全局一致）和长度（与面积相关），然后综合应用到缺影子的对象上。方向判断是视觉直觉层，但长度与面积的关系需要跨对象对比才能归纳，构成真正的第二层推理。
</new_puzzle>

## 实现要求

1. `main(grid)` 必须实现新题描述中的确定性转换规则，不能只识别 `generate_input()` 的固定模板。
2. `generate_input()` 必须随机生成多样样例，不能固定死。随机维度应覆盖：网格大小、对象数量、位置、颜色、方向、形状参数或关键分支。
3. 生成器必须保证输入满足 `main()` 的隐式假设：对象不重叠、不越界、特殊标记唯一或可区分、匹配关系无歧义、关键分支出现概率相同。
4. 禁止把 ARC 颜色 id 、亮度、拼写等当作人类不可见的数值语义参与排序、大小比较或隐藏映射。颜色变化必须有可见结构线索。注意颜色亮度、拼写等也是不可见信息，若描述中出现违规的颜色id或者亮度，可自行使用少量的固定颜色替代，但注意生成时要在三个以内输入输出网格中对所有变换100%覆盖度。
