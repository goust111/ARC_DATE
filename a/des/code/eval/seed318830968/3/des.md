<description>
根据嵌套框架的层数选择对应图例中的填充图案，将图案铺入最内层区域。

Input structure:
- 背景为 black。网格中散布若干嵌套的彩色矩形框架（每个框架是单色的空心矩形环，不同层使用不同颜色）。有的对象只有一层框架，有的有两层或三层由外到内嵌套的框架。每个嵌套结构的最内层区域为空（black）。
- 网格的右侧或底部有一个图例区域，由 grey 边框隔开。图例中排列着若干小型图案样本（例如棋盘格、条纹、十字等），每个图案样本的左侧标注了一个数字量的指示：用竖排的小色块数目表示（1个色块、2个色块、3个色块……），色块颜色为 maroon。

Rule:
- 数出每个嵌套矩形结构中框架的层数 N（从外到内，每一个完整的空心矩形环算一层）。
- 在图例中找到 maroon 色块数目等于 N 的那一行图案。
- 将该图案以平铺（tile）的方式填入该嵌套结构最内层的空白区域，图案的左上角与内层区域左上角对齐。
- 框架本身保持不变；图例区域在输出中移除，输出网格仅包含主区域。

Key insight: 解题者需要先识别每个对象的嵌套深度（层数），再将层数作为索引去图例中查找对应的填充图案——两步都需要非平凡的归纳：第一步需要理解"嵌套层数"这个概念，第二步需要发现图例的编码方式（maroon 色块计数）。
</description>

<description>
将散落的彩色碎片沿颜色匹配的"磁力线"滑动到目标框内，碎片进入框后按框内已有碎片的轮廓互锁拼合。

Input structure:
- 背景为 azure。网格中有若干空心矩形框，每个框的边框颜色各不相同（如 red、green、yellow 等）。框的内部为空（azure）。
- 散布在框外的若干小型彩色碎片（形状不规则，占 2-5 个像素的连通区域），每个碎片的颜色与恰好一个框的边框颜色相同。
- 从每个框的一条边（该边有一个 1 像素宽的缺口）向外延伸出一条与框同色的虚线（间隔 1 像素的点线），虚线终止于该框对应颜色的碎片附近。

Rule:
- 每个碎片沿其对应颜色的虚线方向滑动，直到碎片整体进入框的内部（通过缺口进入）。
- 若一个框对应多个同色碎片，则按虚线上距框从近到远的顺序依次进入。第一个碎片紧贴框内与缺口对边的内壁放置；后续碎片紧贴前一个碎片的轮廓放置，沿滑动方向堆叠，碎片之间无间隙。
- 虚线在输出中移除；缺口在输出中被框边框颜色填上（封闭）。

Key insight: 解题者首先要通过颜色匹配和虚线追踪建立碎片-框的配对关系，然后需要理解碎片在框内的堆叠规则——碎片按距离排序后依次紧贴内壁和前序碎片放置，而非简单地居中或随意摆放。
</description>

<description>
根据每个封闭区域内"种子像素"的颜色，从区域边界向内逐层收缩填色，形成等高线式的同心环带图案。

Input structure:
- 背景为 black。网格上有若干由 grey 像素构成的不规则封闭区域边界（类似手绘的闭合曲线，宽度为 1 像素）。每个封闭区域内部除背景外还有恰好一个"种子像素"，颜色各异（如 red、blue、green 等），位于区域内的任意位置。
- 另外，网格的某个角落有一个小的色条图例：从左到右排列 2-4 种颜色，表示从外层到内层的配色顺序。

Rule:
- 对每个封闭区域，从 grey 边界向内逐层剥离。第一层（紧贴边界内侧的像素）填为图例中第一个颜色，第二层填为图例中第二个颜色，以此类推；若层数超过图例长度则循环使用图例颜色。
- 但存在一个例外规则：种子像素所在的那一层及更内层全部填为种子像素的颜色，不再遵循图例循环。
- grey 边界本身保持不变。图例在输出中移除。

Key insight: 解题者需要发现三层递进的规则——(1) 理解"逐层收缩"的等高线填色模式；(2) 发现色条图例控制了颜色循环顺序；(3) 发现种子像素的位置和颜色会覆盖内层的循环规则。种子在不同深度时效果不同，这一交互使得规则不能仅从单一样例看出。
</description>

<description>
在网格上用"路径折叠"规则将蛇形路径压缩为紧凑矩形，路径上的标记点决定折叠位置和方向。

Input structure:
- 背景为 black。网格上有一条由单一前景色（如 orange）组成的连续蛇形路径（宽度 1 像素，沿水平或垂直方向延伸，在若干位置 90 度转弯）。路径从一端到另一端不分叉。
- 路径上有若干标记像素，颜色为 red，分布在路径的某些转弯处（并非所有转弯处都有标记）。
- 路径的两个端点像素颜色为 green。

Rule:
- 将蛇形路径视为一条从 green 端点到另一个 green 端点的有序序列。
- 在每个 red 标记处将路径"折叠"：以 red 标记为轴，将标记之后的路径段翻转 180 度叠到标记之前的路径段上方。折叠方向取决于标记处的转弯方向——若路径在标记处向左转，则向左翻折；向右转则向右翻折。
- 多个 red 标记按路径顺序依次执行折叠。
- 输出为折叠后路径占据的最小外接矩形。重叠的像素保留最后一次覆盖的颜色（orange），red 标记在折叠后变为 maroon，green 端点保持 green。

Key insight: 解题者需要 (1) 追踪蛇形路径的完整走向以确定有序序列；(2) 理解"折叠"操作的几何含义——以标记点为轴将后续路径段镜像翻叠；(3) 发现转弯方向决定翻折方向。多次折叠的累积效果使得仅看输入输出很难一步到位，必须逐步模拟。
</description>

<description>
利用小型"印章"sprite 在网格上沿箭头指示的方向反复盖印，印章每次盖印后根据途经的颜色触发器变换自身图案。

Input structure:
- 背景为 black。网格左上角有一个小矩形区域（3x3 至 5x5），内含一个多色 sprite 图案，作为初始"印章"。
- 网格中有一个由 grey 像素绘制的箭头形状，指示盖印的行进方向。箭头的绘制方式：一条 grey 直线段（长度 3-10 像素，水平或垂直）加上线段末端的一个 V 形箭头头（由 2 个 grey 像素在直线两侧各偏 1 像素构成，指向行进方向）。箭头的起始端（非箭头头一端）与印章区域相邻。
- 网格中散布若干"触发器"像素，每个触发器是一个孤立的单像素，颜色为 red、blue 或 green 之一。

Rule:
- 印章从箭头起始端出发，沿箭头方向每隔一个印章宽度（或高度，取决于方向）的距离盖印一次，直到到达网格边缘。每次盖印将印章图案覆写到当前位置。
- 若某次盖印的区域中包含一个触发器像素，则印章图案在下一次盖印前发生变换：red 触发器使印章顺时针旋转 90 度；blue 触发器使印章左右镜像翻转；green 触发器使印章上下镜像翻转。
- 若一次盖印区域包含多个触发器，按触发器在盖印区域中从左到右、从上到下的顺序依次施加变换。
- 触发器像素在输出中被印章图案覆盖（不保留）。箭头在输出中移除（grey 像素恢复为 black），但印章覆盖过箭头的部分保留印章颜色。

Key insight: 解题者需要 (1) 识别箭头的方向和盖印间距规律；(2) 发现触发器像素引发印章图案变换的规则——不同颜色对应不同的几何变换；(3) 理解变换是累积的——每次触发后印章的新状态会延续到后续所有盖印，而非每次重置。这种状态持续性使得后期的盖印结果依赖于前方所有触发器的累积效果。
</description>

<description>
将网格中的多个"时钟面板"各自按其指针指示的步数推进内部色环旋转，输出旋转后的面板。

Input structure:
- 背景为 black。网格中排列着若干正方形"时钟面板"（大小相同，如 7x7），面板之间由 1 像素宽的 grey 分隔线隔开。
- 每个面板的结构为：最外圈是一圈由多种颜色组成的色环（颜色沿顺时针排列，每个像素一种颜色，形成类似表盘刻度的环带）；中心有一个 1x1 的"轴心"像素（颜色为 maroon）；从轴心向外延伸一条 1 像素宽的"指针"（长度为 2 像素，颜色为 yellow），指向上、下、左、右四个方向之一。
- 面板内的色环与指针之间有 1 像素的 black 间隔带。

Rule:
- 指针方向编码旋转步数：上 = 1 步，右 = 2 步，下 = 3 步，左 = 4 步。
- 将每个面板的外圈色环沿顺时针方向旋转对应步数（即每个像素沿环带顺时针移动 N 个位置）。
- 旋转完成后，移除指针（指针像素变为 black），轴心保留。
- grey 分隔线保持不变。

Key insight: 解题者需要 (1) 识别面板的结构——外圈色环、间隔、指针和轴心；(2) 发现指针方向与旋转步数之间的对应编码（上1右2下3左4，对应顺时针的方位顺序）；(3) 理解色环旋转是沿环带的循环移位而非整体图像旋转。指针方向到步数的编码不是直觉上的"指哪打哪"，需要从多个样例中归纳。
</description>

<description>
根据连通区域的"骨架方向"选择对应的边框样式，为每个区域加上装饰边框。

Input structure:
- 背景为 azure。网格中有若干彩色连通区域（4-连通，每个区域为单色，形状不规则但大致呈elongated 条状——即明显在某个方向上更长）。
- 网格底部有一行图例，由 grey 分隔线隔开。图例中展示三种边框样式与方向的对应关系：一个水平长条旁边画着实线边框样式（用 maroon 像素包围）；一个垂直长条旁边画着虚线边框样式（maroon 像素间隔 1 像素 black）；一个对角长条旁边画着双线边框样式（两层 maroon 像素包围）。

Rule:
- 判断每个连通区域的主方向：若水平跨度大于垂直跨度，主方向为水平；若垂直跨度大于水平跨度，主方向为垂直；若两者相等，主方向为对角。
- 根据主方向在图例中查找对应的边框样式。
- 在每个连通区域的外接矩形外围绘制对应样式的 maroon 边框（边框不覆盖原有区域像素，仅绘制在外接矩形外扩一圈或两圈的 azure 像素上）。
- 若两个区域的边框区域重叠，后绘制的（按区域面积从小到大的顺序）覆盖先绘制的。
- 图例在输出中移除。

Key insight: 解题者需要 (1) 从图例中归纳出方向-边框样式的映射关系；(2) 判断每个区域的主轴方向（通过比较外接矩形的宽高比）；(3) 理解边框绘制的几何规则和重叠时的覆盖优先级。方向判断和样式查找两步推理结合，形成真正的两层结构。
</description>
</new_puzzle>
