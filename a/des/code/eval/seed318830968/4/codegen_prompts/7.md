- `Input structure`：
  - 背景色 = black。
  - 网格中有若干个 3×3 的实心彩色方块，颜色各异（如 red、blue、green、yellow 等）。
  - 部分方块之间由单像素宽的 grey 连接线相连。连接线为水平或垂直直线段，连接两个方块的最近边（从一个方块边缘出发，直线到达另一个方块边缘）。
  - 恰好有一个方块没有入线（没有连接线从其他方块指向它），它是"源头"。
  - 其余方块各有恰好一条入线。整体构成一棵树状结构（源头为根）。
  - 在网格的某个角落有一个 2×2 的"色表"区域：左上为 red，右上为 blue，左下为 green，右下为 yellow。这个色表定义了颜色的循环顺序：red → blue → green → yellow → red ...

- `Rule`：
  - 源头方块保持原色不变。
  - 沿着树的连接方向，每经过一条连接线，方块的颜色变为其父方块颜色在色表循环中的下一个颜色。例如父方块为 red，则子方块变为 blue；父方块为 yellow，则子方块变为 red。
  - 如果原方块的颜色不在色表四色之中（如 orange、magenta 等），则该方块颜色不变，它对下游传导的颜色取其父方块传来的颜色再做一次循环映射。
  - 连接线颜色保持 grey 不变。

- `Key insight`：解题者需要三层推理——首先发现角落色表定义了一个颜色循环顺序，其次识别出方块的树状拓扑结构和传导方向（从无入线的根节点出发），最后理解每经过一条边颜色就在循环表中前进一步。色表、拓扑、映射规则三者缺一不可。
