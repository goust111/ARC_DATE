  - 网格中有若干条彩色直线段（水平或垂直，各自颜色不同，宽度为1像素），它们彼此交叉形成若干交叉点。

- `Rule`：
  - 首先识别图例行中方块的颜色排列顺序，建立颜色到层级的映射（左侧 = 高层级）。
  - 对网格中每个交叉点（两条不同颜色路径相遇的像素），该像素的颜色设为层级更高的那条路径的颜色。
  - 进一步：在交叉点的两侧各1像素处（沿低优先级路径方向），也将这2个像素重新着色为高优先级路径的颜色，形成一个长度为3的"桥"效果——视觉上高层级路径从上方跨过低层级路径。

- `Key insight`：解题者需要先发现图例行的排列顺序编码了层级信息，然后理解交叉点不仅仅是单像素覆盖，而是沿低优先级方向扩展出3像素宽的"桥"——两层推理缺一不可：第一层是从图例推断优先级，第二层是理解桥的扩展规则。
