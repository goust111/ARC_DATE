description: 根据框架内部缺失边的方位，从外部候选精灵中选取对应方位的精灵填入框架，再按框架颜色对精灵进行重新着色。

Input structure:
- 背景色为 black。网格中散布着若干大小不同的空心矩形框架（边框宽度为 1 像素），每个框架用不同颜色绘制（如 red、blue、green 等）。
- 每个框架恰好缺失一条完整的边（上、下、左或右），形成一个开口。
- 框架外部另有若干小型精灵图案（由 yellow 像素绘成），每个精灵具有明确的方向性形态：向上的箭头（一个像素在顶部中央，下方一行三个像素）、向下的箭头（一行三个像素在上，一个像素在底部中央）、向左的箭头（一个像素在左侧中央，右侧一列三个像素）、向右的箭头（一个像素在右侧中央，左侧一列三个像素）。精灵数量与框架数量相同。

Rule:
- 第一层推理：观察每个框架缺失的是哪条边，确定其"开口方位"（上/下/左/右）。
- 第二层推理：将每个精灵的朝向与框架的开口方位进行匹配——开口朝上的框架匹配向上箭头精灵，以此类推。
- 第三层操作：将匹配到的精灵放置到对应框架的内部中心位置，并将精灵的颜色从 yellow 改为该框架的边框颜色。原始位置的精灵被擦除。框架本身保持不变（仍然缺边）。

Key insight: 框架缺失边的方位是隐含的匹配键，需要先识别每个框架的"开口朝向"，再从外部精灵池中按方向对应关系选取正确的精灵，最后执行着色替换——三步中前两步都需要非平凡的归纳推理。
</new_puzzle>

Input structure:
- 背景色为 black。网格中散布着多组彩色像素块，每组使用不同颜色（如 red、blue、green、orange 等）。
- 同一颜色的像素块是若干互不连通的碎片（4-连通分量），每块碎片是一个小型矩形区域（如 1x2、2x1、2x2、1x3 等）。
- 同一颜色的所有碎片恰好可以无重叠无间隙地拼合成一个完整的实心矩形。不同颜色拼合后的矩形大小可能不同。

Rule:
- 第一层推理：识别每种颜色的所有碎片，并推断出它们拼合后应形成的完整矩形的尺寸。拼合方式：将同色碎片按照从左到右、从上到下的顺序依次紧密排列（先填满一行再换下一行），形成目标矩形。

Key insight: 解题者不仅要发现同色碎片能拼成矩形这一空间关系，还要发现排列顺序取决于每组的碎片个数而非面积或颜色——两层规律都需要从样例中独立归纳。
</new_puzzle>

description: 网格中的彩色路径段在交叉点处按交替编织规则呈现，被遮挡处以 grey 标记；需要识别每条路径并还原交叉点处的正确颜色，最终消除所有 grey 标记。

Input structure:
- 背景色为 black。网格中有若干条单像素宽的水平或垂直直线段，每条线段使用不同颜色（如 red、blue、green、magenta 等）。
- 线段之间存在交叉。在每个交叉点处，恰好有一条线段的像素被保留（可见），另一条线段的该像素被替换为 grey 标记色，表示此处被遮挡。
- 每条线段至少参与一个交叉。

Rule:
- 第一层推理：识别每条彩色线段的完整走向（水平或垂直）。grey 像素位于线段交叉处，表示某条线段在此被另一条遮挡。对于每个 grey 像素，确定它属于哪条线段——方法是观察该 grey 像素在水平和垂直方向上哪个方向的两侧（沿同一行或同一列）能延伸到同色像素，该 grey 像素就属于那条线段。
- 第二层推理：发现编织规则——同一条线段在其经过的所有交叉点上交替地处于"上方"（可见）和"下方"（被遮挡为 grey）。即如果一条线段在第一个交叉点可见，则在第二个交叉点被遮挡，在第三个交叉点又可见，以此类推。输入中给出的遮挡关系已满足这一交替规律。
- 输出：将所有 grey 像素替换为其所属线段的颜色。交叉处显示"上方"线段的颜色（即保留输入中已可见的那条线段的颜色）。最终输出中不再有任何 grey 像素，所有交叉点显示可见线段的颜色。

Key insight: grey 标记不是简单的缺损需要填补——它们编码了一个交替编织模式。解题者必须先识别每个 grey 像素属于哪条线段，再发现交叉点处"上/下交替"的编织规律，才能正确还原整个图案。
</new_puzzle>

description: 网格中包含一个由彩色像素构成的"种子图案"和若干 grey 矩形"生长区域"；需要根据种子图案的对称性类型选择不同的平铺策略，将种子扩展填充到每个生长区域中。

Input structure:
- 背景色为 black。网格中有一个由多种颜色像素构成的小型"种子图案"（占据约 3x3 到 5x5 的区域）。
- 网格中另有若干个由 grey 像素填充的矩形区域（"生长区域"），大小各不相同但均为种子图案尺寸的整数倍。
- 种子图案与生长区域不重叠，不相邻。

Rule:
- 第一层推理：分析种子图案的对称性类型：
  - 若种子具有 4 重旋转对称性（旋转 90、180、270 度后均与自身相同），则生长方式为"旋转平铺"——将种子及其 90、180、270 度旋转版本按 2x2 排列成一个超级单元（左上为原始，右上为顺时针 90 度，右下为 180 度，左下为 270 度），再用该超级单元平铺填充生长区域。
  - 若种子仅具有水平镜像对称性（左右翻转后与自身相同，但不具备旋转对称性），则生长方式为"垂直镜像平铺"——将种子与其上下翻转版本按上下排列成 2x1 超级单元，再平铺填充。
  - 若种子仅具有垂直镜像对称性（上下翻转后与自身相同，但不具备旋转对称性），则生长方式为"水平镜像平铺"——将种子与其左右翻转版本按左右排列成 1x2 超级单元，再平铺填充。
  - 若种子无任何对称性，则生长方式为"直接平铺"——直接重复种子图案平铺填充。
- 第二层操作：用确定的生长方式将种子扩展到每个 grey 矩形区域中，完全替换 grey 像素。超级单元从每个生长区域的左上角开始对齐平铺。种子图案本身在输出中保持不变。

Key insight: 种子图案的对称性不是装饰性质——它直接决定了完全不同的平铺策略。解题者必须先判断种子属于哪种对称类型，再推断出对应的生长规则，两步推理缺一不可。
</new_puzzle>

description: 网格中有一组彩色像素塔和一条水平基准线；每座塔需要在基准线的另一侧生成其"倒影"，但倒影的高度不等于塔本身的高度，而等于该塔所包含的不同颜色的数量。

Input structure:
- 背景色为 black。网格中有一条水平的 grey 像素线横贯整个宽度，将网格分为上下两半。
- 上半部分有若干"像素塔"：每座塔占据一列（宽度 1 像素），由若干彩色像素从 grey 线上方向上堆叠而成（塔底紧贴 grey 线正上方一行）。每座塔可包含多种颜色的像素，颜色从下到上依次排列。不同塔的高度和颜色组成各不相同。塔与塔之间至少间隔 1 列。
- 下半部分（grey 线下方）初始为空（black）。

Rule:
- 第一层推理：对每座塔，数出它包含多少种不同颜色，记为 K。
- 第二层推理：在 grey 线下方对应的同一列中，生成该塔的"倒影"。倒影从 grey 线正下方第一行开始向下延伸 K 个像素。倒影的颜色取塔中从底部（紧贴 grey 线的一端）开始的前 K 个像素的颜色，顺序翻转——即塔底第 1 个像素的颜色出现在倒影的第 K 行，塔底第 2 个像素的颜色出现在倒影的第 K-1 行，以此类推。
- grey 线本身保持不变。上半部分的塔保持不变。

Key insight: 倒影高度不是塔的物理高度的镜像复制，而是由塔的颜色多样性决定——解题者需要发现"不同颜色数 -> 倒影高度"这一隐蔽映射，同时还要注意倒影取的是塔底部的颜色子集并翻转，而非整塔翻转。
</new_puzzle>

<new_puzzle>
description: 网格中散布着若干彩色连通区域，每个区域旁边有一个单像素的方向标记；需要将每个区域沿标记指示的方向"挤压投影"为一条单像素宽的线段，线段颜色由区域内占多数的颜色决定。

Input structure:
- 背景色为 black。网格中有若干个多色连通区域（4-连通），每个区域由 2-3 种颜色的像素混合组成，整体形状不规则。
- 每个区域的外侧恰好有一个 orange 单像素标记，标记位于区域边界框的某条边的外侧正中位置：若标记在区域上方，表示方向为"向上"；在下方表示"向下"；在左侧表示"向左"；在右侧表示"向右"。

Rule:
- 第一层推理：确定每个区域的方向标记位于哪一侧，从而确定挤压投影方向。
- 第二层推理：统计每个区域中各颜色的像素数量，找出占多数的颜色（出现次数最多的颜色），作为投影线段的颜色。
- 第三层操作：将每个区域沿标记指示的方向进行"挤压投影"。具体地，若方向为"向上"，则将区域的每一列像素压缩为该列最顶部的一个像素位置，形成一条水平线段；若方向为"向下"，则压缩为每列最底部像素位置的水平线段；若方向为"向左"，则将每一行压缩为该行最左侧像素位置，形成一条垂直线段；若方向为"向右"则压缩为每行最右侧像素位置的垂直线段。线段使用第二步确定的多数颜色绘制。原区域和 orange 标记在输出中被擦除（变为 black）。

Key insight: 解题者需要同时发现三个独立规律：orange 标记的位置编码投影方向、多数颜色决定输出颜色、以及"挤压投影"的具体几何操作——任何一步的缺失都会导致错误输出。
</new_puzzle>
