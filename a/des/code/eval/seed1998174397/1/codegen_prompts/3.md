将网格中的"管道"连通图案按其内部流动标记的方向进行接力传色，最终每段管道的颜色由上游源头决定。

Input structure:
- 背景色为黑色（black）。网格中有若干由灰色（grey）像素组成的直线段（水平或垂直，宽度为 1 像素，长度 3-8 像素），称为"管道段"。
- 管道段之间通过端点直接相邻（4-连通）来首尾相连，形成若干条不分叉的链状路径。每条链的一个端点管道段内部有一个特殊的彩色像素（如红色 red、蓝色 blue 等），位于该管道段的某一端——这个彩色像素称为"源头标记"，其颜色是该链的"源色"。
- 每个管道段的中间位置有一个箭头标记：箭头由 3 个橙色（orange）像素组成，排列成">"、"<"、"^"或"v"形状（即一个中心像素加两个斜对角像素组成箭头尖）。箭头嵌在管道段内部，指示该段内的"流动方向"。

Rule:
- 第一步：识别每条管道链的起点——起点是包含源头彩色标记的那个管道段。
- 第二步：验证流向一致性——从源头出发，沿管道链依次检查每个管道段内部的箭头方向。箭头必须指向"从源头到末端"的方向（即从链的起点向终点）。如果某段管道的箭头方向与链的整体流向一致，该段管道被染为源色；如果箭头方向相反（逆流），该段管道保持灰色不变。
- 第三步：移除所有箭头标记（橙色像素变为该管道段最终的颜色——源色或灰色）。源头彩色标记像素保留。

Key insight:
解题者首先要识别管道链的拓扑连接和源头位置，然后理解箭头表示流向——只有"顺流"的管道段才被上色。这要求解题者进行两层推理：先确定链路结构和流向定义，再判断每段箭头与全局流向的一致性。
