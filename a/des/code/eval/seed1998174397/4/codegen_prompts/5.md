- `Input structure`：
  - bg = 最常见颜色。网格上有若干较大的单色实心连通形状（不规则形状，面积约8-20像素），每个形状内部恰好有一个 red 像素（"锚点"）替代了原本的形状颜色。
  - 网格上另有若干 3x3 的小正方形方块（"印章模板"），每个小方块使用两种颜色构成二色棋盘或条纹图案：其中一种颜色与某个大形状的颜色相同（记为 C），另一种为 bg。每种非bg非red颜色恰好对应一个大形状和一个小方块。

- `Rule`：
  - 对每种颜色 C（非bg、非red）：
    1. 找到颜色为 C 的大形状和颜色为 C 的 3x3 小方块模板。
    2. 确定大形状内 red 锚点在形状边界框中的相对位置：计算锚点离边界框四个角的距离（上下左右像素差之和），选取最近的角作为对齐角（左上、右上、左下、右下之一）。
    3. 将 3x3 模板对齐到大形状边界框的该角，然后以 3x3 为周期在整个边界框区域内平铺。
    4. 对边界框内每个像素位置：如果该位置属于大形状且平铺图案中该位置为颜色 C，则输出 C；如果该位置属于大形状但平铺图案中该位置为 bg，则输出 bg；如果该位置不属于大形状，则输出 bg。
  - 移除所有 red 锚点像素（对应位置按平铺规则决定颜色）和原始 3x3 小方块模板。

- `Key insight`：解题者需要归纳两层非显然规则——第一层是小方块模板与大形状之间通过共享颜色建立配对关系，第二层是形状内部 red 锚点的位置决定了模板平铺的对齐角，使得相同模板在不同锚点位置下产生不同相位的填充图案。
</new_puzzle>
