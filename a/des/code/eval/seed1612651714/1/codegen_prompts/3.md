- `Input structure`：
  - 背景色为 black。
  - 网格中央有一个较大的矩形区域，被单层 grey 边框包围。
  - 边框上的某些连续段被替换为其他颜色（如 red、blue、green 等），形成若干彩色"窗口"。每个窗口是边框上一段连续的同色像素。
  - 矩形内部初始全为 black。

- `Rule`：
  - 第一层推理（射线发射）：每个彩色窗口向矩形内部发射一束与边框垂直的平行射线。窗口在上边框则射线向下，在下边框则向上，在左边框则向右，在右边框则向左。射线覆盖窗口对应的每一列（或每一行）。
  - 第二层推理（长度决定）：每条射线的长度等于该窗口的连续像素数。例如上边框有一个长度为 3 的 red 窗口，则从该窗口的 3 列各自向下发射 3 格长的 red 射线。
  - 第三层推理（交叉混色）：当两条不同颜色的射线交叉在同一像素时，该像素的颜色取为 yellow（无论原始两色是什么，交叉点统一变为 yellow）。若三条或更多射线交叉，同样为 yellow。单一射线覆盖的像素保持射线原色。

- `Key insight`：窗口的长度同时编码了射线的宽度和深度——这是同一个数值的双重用途；交叉产生 yellow 的规则需要从样例中归纳，因为它并非颜色混合的直觉结果。
