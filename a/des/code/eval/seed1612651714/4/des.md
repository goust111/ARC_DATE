<new_puzzle>
description: 根据框架内部的彩色种子像素，向框架缺口方向生长出与种子颜色相同的枝条，枝条的形态由框架外侧的模板精灵决定。

Input structure:
- 背景色 bg 为网格中最常见的颜色。网格上散布若干中空矩形框架（边框颜色各不相同），每个框架的边框上恰好有一个单像素缺口。
- 每个框架内部放置 1-3 个不同颜色的种子像素（非边框色、非背景色）。
- 网格上还散布着若干小型单色精灵（3×3 以内的连通形状），每个精灵的颜色与某个框架内的某个种子颜色相同。

Rule:
- 第一步：对每个框架，找到其边框上的缺口位置，确定缺口朝向的方向（上/下/左/右）。
- 第二步：对框架内的每个种子像素，在网格上找到颜色相同的精灵。该精灵的形状即为"生长单元"。
- 第三步：从缺口位置开始，沿缺口方向依次铺设生长单元的副本。种子像素在框架内部的排列顺序（沿缺口方向的垂直轴从小到大）决定了对应生长单元的铺设先后顺序：第一个种子的精灵副本紧贴缺口，第二个种子的精灵副本紧接其后，依此类推。每个精灵副本之间无间距，紧密排列。
- 第四步：输出中保留框架（含缺口）和生长出的枝条，移除所有原始的独立精灵，种子像素保留在框架内部。

Key insight: 缺口方向决定生长轴向，但枝条的具体形态并非简单直线——需要先通过颜色匹配找到对应精灵作为生长模板，再按种子在框架内的空间排序来确定模板的铺设序列。解题者必须同时发现"缺口→方向"和"种子颜色→精灵形状→铺设顺序"两层非显然的对应关系。
</new_puzzle>

<new_puzzle>
description: 在网格中找到被围栏包围的区域，根据围栏上标记像素的位置将区域内容"翻折"到围栏外侧对应位置。

Input structure:
- 背景色 bg 为最常见颜色。网格上有若干由同一颜色（如 green）构成的单像素宽封闭围栏，围栏围出矩形区域。
- 每个围栏的某一条边上恰好有一个不同颜色的标记像素（如 red），该标记像素替换了围栏边上的一个像素。
- 围栏内部包含由多种颜色构成的图案（非背景色、非围栏色）。

Rule:
- 第一步：识别标记像素所在围栏边的位置（上边/下边/左边/右边）。标记像素所在的边即为"折叠轴"。
- 第二步：将围栏内部的图案沿折叠轴进行镜像翻折，翻折后的图案出现在围栏外侧，紧贴折叠轴所在的围栏边。翻折的结果相当于以折叠轴为对称轴，将内部图案镜像映射到外侧。
- 第三步：标记像素在折叠轴上的具体列（或行）位置决定翻折图案的裁剪范围——只有与标记像素同列（若折叠轴为水平边）或同行（若折叠轴为垂直边）的那一"条"内部图案会被翻折输出；其余部分不翻折。
- 第四步：输出中围栏和内部原始图案保持不变，翻折出的图案叠加在围栏外侧。若翻折图案超出网格边界则截断。

Key insight: 标记像素同时编码了两个信息——它所在的边决定翻折方向，它在边上的位置决定翻折的列/行范围。解题者需要先发现"哪条边翻折"，再发现"标记位置选择哪些内容参与翻折"，这两个规则缺一不可。
</new_puzzle>

<new_puzzle>
description: 网格中的彩色箭头指向目标对象，将每个目标对象用箭头颜色的矩形边框包裹，边框大小由同色箭头的数量决定。

Input structure:
- 背景色 bg 为最常见颜色。网格上散布若干不同颜色和大小的实心矩形对象（每个对象为单一颜色的填充矩形）。
- 网格上还有若干由非背景色构成的箭头形状。每个箭头由一条 3 像素长的直线段（箭杆）和一个在端部的单像素偏移（箭头尖端）组成，箭头整体为 L 形，朝向上/下/左/右四个方向之一。箭杆方向即箭头指向。
- 每个箭头沿其指向方向的延长线上恰好有一个矩形对象（中间可能隔着若干背景像素）。同一个矩形对象可能被多个不同颜色的箭头指向。

Rule:
- 第一步：对每个矩形对象，收集所有指向它的箭头，按颜色分组。
- 第二步：对每种箭头颜色，数出该颜色指向此对象的箭头数量 N。
- 第三步：在矩形对象周围绘制该箭头颜色的矩形边框，边框与对象之间的间距恰好为 N 个像素（即边框的每条边距对象对应边 N 个像素）。边框为单像素宽的矩形环。
- 第四步：若同一对象有多种颜色的箭头指向，则绘制多层嵌套边框，内层边框对应箭头数量较少的颜色（间距小的在内），外层对应箭头数量较多的颜色。若数量相同，则按箭头在网格中出现的位置从上到下、从左到右排序，先出现的在内层。
- 第五步：输出中移除所有箭头，保留原始矩形对象和新绘制的边框。

Key insight: 箭头不仅通过空间指向将自身与目标对象关联，其颜色决定边框颜色，其同色数量决定边框与对象的间距。解题者需要先推断箭头的指向关联机制，再发现"数量→间距"的编码规则，最后处理多层嵌套的排序逻辑。
</new_puzzle>

<new_puzzle>
description: 网格被分隔线划分为若干房间，每个房间内的小色块需要按照隐含的传送规则跳转到另一个房间，跳转目的地由房间边框上的出口颜色和相邻房间入口颜色的匹配决定。

Input structure:
- 背景色 bg 为最常见颜色。网格由单像素宽的 grey 线条分隔成若干矩形房间（类似九宫格或不规则网格）。
- 每个房间的分隔线上有 1-2 个像素被替换为非灰色的彩色像素（如 red、blue、green 等），这些彩色像素位于房间边界上，称为"门"。一个门像素同时属于相邻两个房间的边界。
- 每个房间内部有零或一个小型单色对象（2-4 个像素组成的连通形状），对象颜色各不相同且不与任何门颜色重复。

Rule:
- 第一步：识别每个房间边界上的所有门像素及其颜色。每个门连接两个相邻房间。
- 第二步：对每个包含对象的房间，找到该房间边界上的所有门。对象需要通过与自身像素数量对应的那扇门离开：像素数为 2 选该房间边界上从左到右/从上到下的第一个门，像素数为 3 选第二个门，像素数为 4 选第三个门（若存在）。若只有一个门则直接使用。
- 第三步：通过选中的门进入相邻房间。将对象从原房间移除，放置到目标房间的中心位置（目标房间内部区域的行列中点，向下向右取整）。
- 第四步：输出中所有门像素恢复为 grey（与分隔线一致），对象出现在各自的目标房间中。

Key insight: 门既是房间之间的通道，也是路由选择器。解题者需要先发现房间边界上的彩色像素是"门"，然后发现对象的像素数量决定了选择哪个门通过，最后理解对象通过门后出现在相邻房间的中心。三层规则——识别门、选择门、放置位置——共同构成完整变换。
</new_puzzle>

<new_puzzle>
description: 将网格中散落的碎片拼回到模板轮廓中，碎片之间存在形状重叠，绘制优先级由碎片内部隐藏的标记像素数量决定。

Input structure:
- 背景色 bg 为最常见颜色。网格左侧（或上方）有一个由单一颜色（如 grey）绘制的空心矩形轮廓，轮廓内部为背景色。该轮廓定义了目标拼图区域的大小。
- 网格其余区域散布若干碎片对象。每个碎片是一个不规则连通形状，由两种颜色构成：主体色（占碎片大部分面积）和标记色（占 1-3 个像素，嵌在碎片内部）。不同碎片的主体色各不相同，但所有碎片的标记色使用同一种颜色（如 maroon）。
- 各碎片的外轮廓形状拼合后可以覆盖目标轮廓内部区域，但碎片之间存在局部重叠（并非严格互补）。

Rule:
- 第一步：识别目标轮廓的位置和大小，以及所有碎片。
- 第二步：将每个碎片平移（不旋转、不翻转）到目标轮廓内部，使碎片的形状与轮廓内的对应区域对齐。每个碎片在轮廓内的位置由其形状与轮廓边界的相对关系唯一确定——碎片的凹凸轮廓恰好与轮廓内某一区域的边界吻合。
- 第三步：确定绘制顺序——每个碎片内部标记色像素的数量决定其层级：标记像素越少的碎片层级越低（先绘制），标记像素越多的层级越高（后绘制）。后绘制的碎片在重叠区域覆盖先绘制的碎片。
- 第四步：在输出中，目标轮廓内填入所有碎片（按层级顺序绘制），碎片上的标记色像素替换为该碎片的主体色（标记消失）。轮廓边框保留，网格其余区域变为背景色（原始碎片位置清除）。

Key insight: 碎片拼接本身是一个空间匹配问题，但仅完成拼接不够——碎片之间存在形状重叠，标记像素的数量编码了绘制优先级，决定重叠区域显示哪个碎片的颜色。解题者需要先发现拼接规则，再发现标记数量→层级的隐含排序机制，两层推理缺一不可。
</new_puzzle>
