- `Input structure`：
  - 背景色（bg）为 Black。
  - 网格中有若干彩色精灵，每个精灵为单一颜色的小型连通区域（3~6 像素）。精灵按颜色配对：同一颜色恰好出现两个精灵（形状可不同），不同对的颜色不同。
  - 网格中还有若干由 Grey 绘制的空心矩形框（1 像素宽边框，内部为 bg），各框大小不同，散布在网格中。
  - 每一对同色精灵之间可以画一条曼哈顿最短连线（先水平后垂直的 L 形路径，从一个精灵的最小外接矩形中心到另一个的中心）。这些假想路径可能穿过若干 Grey 矩形框的内部。

- `Rule`：
  - 对每一对同色精灵（颜色 C）：
    1. 确定两个精灵各自最小外接矩形的中心像素（取整）。
    2. 从第一个中心出发，先水平移动到与第二个中心同列，再垂直移动到第二个中心，形成一条 L 形路径。
    3. 该路径上的像素若位于某个 Grey 矩形框的内部，则将该像素填充为 C。
    4. 路径上不在任何 Grey 框内部的像素保持不变（仍为 bg 或原有颜色）。
  - Grey 矩形框本身、精灵本身在输出中保持不变。

- `Key insight`：解题者须推理出两层规则：(1) 同色精灵之间存在隐含的 L 形连线，连线走向为"先水平后垂直"——这需要从多组样例中归纳出连线的转弯规则；(2) 连线只在穿过 Grey 框内部时才可见（被填充），框外部分不显示——Grey 框起到"显影窗口"的作用。第二层规则尤其隐蔽，因为解题者很容易以为应该填充整条路径。
