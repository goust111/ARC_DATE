- `Input structure`：
  - 背景为 black。网格中散布着若干灰色（grey）边框的矩形容器（空心矩形，边框宽度为 1 像素）。

- `Rule`：
  - 第一步：分析每个颜色图例旁的示意图案，识别它代表哪种对称性类型，建立"对称性类型 -> 颜色"的映射表。
  - 第二步：对每个灰色容器，分析其内部图案的对称性类型。
  - 第三步：根据映射表找到该对称性类型对应的颜色，将容器的灰色边框重新着色为该颜色。

- `Key insight`：解题者需要先从图例的示意图案中归纳出"对称性类型"这一抽象概念与颜色的对应关系，再将同一概念应用于容器内部图案的分类——两步归纳缺一不可。

- `description`：将散落的彩色碎片按颜色分组装入同色边框中，装入时碎片需要沿边框缺口方向滑入并堆叠。

- `Input structure`：
  - 背景为 azure。网格中有若干不同颜色的空心矩形边框（每个边框恰好在一条边上有一个连续缺口，缺口宽度 >= 2 像素）。
  - 边框外部散布着与各边框同色的小型实心碎片（不规则形状的连通区域，每个碎片的宽度或高度不超过缺口大小）。
  - 每种边框颜色在网格中恰好出现一个边框和若干同色碎片。

- `Rule`：
  - 对每个边框，找到其缺口所在的边及方向（上、下、左、右）。
  - 收集所有与该边框同色的外部碎片。
  - 按碎片到缺口的距离从近到远排序（距离指碎片沿缺口方向与缺口的像素行/列差值）。
  - 依次将每个碎片沿缺口方向的反方向（即向框内部）平移，直到碎片碰到边框的对面内壁或已堆叠的碎片为止。
  - 碎片保持原始形状和朝向，不旋转。平移后碎片从原位置擦除。

- `Key insight`：颜色同时编码了"归属关系"（碎片属于哪个边框）和"入口方向"（缺口位置决定堆叠方向），解题者需要同时发现这两层对应关系才能正确重建输出。
</new_puzzle>

- `Input structure`：

    1. **印章**：由 grey 像素构成的小型图案（连通区域），形状各不相同（如 L 形、T 形、十字形等）。

    3. **画布**：由 maroon 边框围成的矩形空白区域（内部为 black），每个画布内部的左上角有一个 1x1 的彩色标记像素。

- `Rule`：
  - 第一步：识别每个印章与其相邻印泥的配对关系，从而建立"印章形状 -> 印泥颜色"的映射。
  - 第二步：对每个画布，读取其左上角标记像素的颜色，找到对应颜色的印泥，进而找到该印泥配对的印章。
  - 第三步：将该印章的形状以标记像素为定位点（印章图案的左上角对齐标记像素位置），用印泥颜色绘制到画布内部。标记像素被印章图案覆盖。
  - 印章和印泥在原位置保持不变，画布边框保持不变。

- `Key insight`：解题的核心在于发现三段式间接映射链——印章通过空间邻接关联印泥，印泥通过颜色匹配关联画布——解题者必须依次建立两层映射才能确定在每个画布中绘制什么图案以及用什么颜色。

- `Input structure`：
  - 背景为 black。网格中包含：

- `Rule`：
  - 从每个源头方块出发，将其颜色沿灰色管道路径传播。管道像素被重新着色为传播经过的颜色。

  - 每个末端容器的内部（3x3 空心方块的中心 1x1 像素）填充为到达它的管道最终颜色。
  - 源头方块保持原色不变。

- `Key insight`：解题者需要先追踪每条管道的拓扑走向以确定哪些源头的颜色会在哪些交汇点相遇，再根据颜色组合规则（需从训练样例中归纳出具体的混色映射表）推断末端容器应填充的颜色——管道追踪和混色规则构成两层独立的推理任务。

- `description`：识别网格中被"遮挡"的图层叠放顺序，然后将最底层对象完整还原到输出中。

- `Input structure`：
  - 背景为 black。网格中有若干不同颜色的矩形色块，它们彼此部分重叠，形成类似窗口层叠的视觉效果——上层矩形遮挡住下层矩形的部分区域。
  - 每个矩形是单一颜色的实心矩形。所有矩形的颜色互不相同。
  - 在网格右侧有一列纵向排列的 1x1 颜色标记点（每种颜色出现一次），这些标记点从上到下的排列顺序即为图层从顶层到底层的叠放顺序提示——但该提示列中恰好有一对相邻颜色的顺序是**颠倒的**（即与实际遮挡关系矛盾）。

- `Rule`：
  - 第一步：通过观察矩形之间的实际遮挡关系（哪个颜色覆盖在哪个颜色之上），独立推断出真正的图层顺序，忽略右侧标记列中的错误提示。
  - 第二步：确定遮挡关系后，找到处于最底层的那个矩形。
  - 第三步：输出仅包含该最底层矩形的完整形状（补全被上层矩形遮挡的部分），输出网格大小恰好等于该矩形的完整尺寸，背景为 black，矩形用其原始颜色填充。

- `Key insight`：右侧颜色标记列是一个"几乎正确"的图层顺序提示，其中故意包含一处错误——解题者必须通过网格中矩形的实际遮挡证据来验证并修正这个提示，而非盲目信任它。发现"提示中的错误"本身就是一层推理，随后还需还原被遮挡的完整矩形形状。

- `description`：将网格中的种子像素按照局部邻域模板生长为完整图案，生长代数由种子到最近边界的距离决定。

- `Input structure`：
  - 背景为 black。网格被 green 线条分割为若干大小相同的矩形区域（类似棋盘格的分割线）。
  - 每个区域的中心位置有一个彩色种子像素（颜色各不相同，从 red、blue、yellow、orange、magenta 等中选取）。
  - 网格的左上角区域不含种子像素，而是包含一个 3x3 的"生长模板"——模板中心为 grey，周围 8 个位置中的若干个为 maroon，其余为 black。maroon 位置表示生长方向。

- `Rule`：
  - 第一步：读取生长模板，确定哪些邻域方向是活跃的（即 maroon 标记的方向）。例如，如果模板中上、右、下三个位置为 maroon，则生长方向为上、右、下。
  - 第二步：对每个种子像素，计算它到所在区域四条边界（green 线条）的最短距离（以像素数计），记为 D。
  - 第三步：以种子为起点，沿模板指定的活跃方向，进行 D 代元胞自动机式生长——每一代，所有已着色像素向每个活跃方向扩展 1 像素（仍保持种子颜色），但不越过 green 边界线。
  - 最终输出中，种子像素及其生长结果保留，未被覆盖的区域保持 black，green 分割线保持不变。

- `Key insight`：解题者需要分别发现两个独立规律——生长的方向编码在模板中（需要解读模板含义），生长的代数编码在种子与边界的空间关系中（需要观察不同区域中图案大小的差异并关联到距离）——两层规律交叉作用才能完整解释输出。
</new_puzzle>

- `description`：根据每个封闭区域内"指针"箭头的朝向，从该区域的对应边取出边界颜色序列，将序列写入区域内部。

- `Input structure`：
  - 背景为 black。网格中有若干由 grey 像素围成的封闭矩形区域（grey 构成 1 像素宽的完整矩形边框）。
  - 每个矩形边框的四条边上各有若干像素被替换为其他颜色（非 grey、非 black），形成彩色的边界标记序列。每条边上的彩色像素可能不同，数量也可能不同。
  - 每个封闭区域内部（原本为 black）包含一个由 maroon 像素组成的 3 像素 L 形箭头（2x2 区域中缺少一个角的形状），缺角的方向指示箭头朝向——朝上、朝下、朝左或朝右。

- `Rule`：
  - 第一步：对每个封闭区域，识别内部 L 形箭头的朝向（由缺角方向决定：缺右上 = 朝右，缺左上 = 朝上，缺左下 = 朝左，缺右下 = 朝下）。
  - 第二步：根据箭头朝向，选择该矩形边框对应方向的那条边（朝上 = 取顶边，朝下 = 取底边，朝左 = 取左边，朝右 = 取右边）。
  - 第三步：提取该边上的彩色像素序列（按从左到右或从上到下的顺序），将这些颜色按序逐行或逐列填入区域内部：如果箭头朝上或朝下，则将序列竖向写入区域中央列；如果箭头朝左或朝右，则将序列横向写入区域中央行。起始位置为靠近箭头所指方向的那一端。
  - L 形箭头在输出中被擦除（变为 black），被颜色序列覆盖的位置除外。

- `Key insight`：解题者需要先破译 L 形箭头的"朝向编码"（缺角位置与方向的映射关系需从样例中归纳），再理解箭头朝向与边框选边的对应关系，最后发现颜色序列的写入方式——三层规则环环相扣。
</new_puzzle>
