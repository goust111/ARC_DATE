<new_puzzle index="3">
- `description`：网格中每个彩色对象身上附着若干单像素"标签"，标签的数量决定对象在输出中被复制的份数，复制品沿标签指示的方向依次排列。

- `Input structure`：
  - 背景为 Black。
  - 网格上有若干互不重叠的单色对象（4-连通分量，颜色为非 Black 的各种颜色如 Red、Blue、Green 等），每个对象至少占据 3 个像素。
  - 每个对象的 8-邻域外围（紧贴对象但不属于对象本身的位置）上，有若干 Maroon 单像素"标签"。这些标签全部位于对象的同一侧（例如全在对象的右侧，或全在对象的下方）。
  - 标签所在的那一侧定义了"复制方向"：标签在对象右侧则方向为向右，标签在下方则方向为向下，以此类推（上、下、左、右四个方向之一）。

- `Rule`：
  - 对每个对象，找到其外围的所有 Maroon 标签像素，数出标签数量 N。
  - 确定标签相对于对象的方位（上/下/左/右），此为复制排列方向。
  - 在输出中，沿该方向依次放置 N 个该对象的完整副本。第一个副本紧邻原对象，后续副本紧邻前一个副本（副本之间间距为 1 像素的 Black 间隔）。
  - 原对象保留在原位。所有 Maroon 标签像素在输出中被擦除（变为 Black）。
  - 若复制品超出网格边界则截断。

- `Key insight`：解题者需要发现三层关联：（1）Maroon 像素不是装饰而是功能性标签；（2）标签的空间分布（位于对象哪一侧）编码了方向信息；（3）标签的数量编码了复制次数。三者缺一不可。
</new_puzzle>

## 实现要求

1. `main(grid)` 必须实现新题描述中的确定性转换规则，不能只识别 `generate_input()` 的固定模板。
2. `generate_input()` 必须随机生成多样样例，不能固定死。随机维度应覆盖：网格大小、对象数量、位置、颜色、方向、形状参数或关键分支。
3. 生成器必须保证输入满足 `main()` 的隐式假设：对象不重叠、不越界、特殊标记唯一或可区分、匹配关系无歧义、关键分支出现概率相同。
4. 禁止把 ARC 颜色 id 、亮度、拼写等当作人类不可见的数值语义参与排序、大小比较或隐藏映射。颜色变化必须有可见结构线索。注意颜色亮度、拼写等也是不可见信息，若描述中出现违规的颜色id或者亮度，可自行使用少量的固定颜色替代，但注意生成时要在三个以内输入输出网格中对所有变换100%覆盖度。

6. 若规则有多个分支，生成器不能长期固定成一个分支；应让分支在随机样例中合理出现，即每个分支出现的概率平均，所谓的分支是在描述中提到的分支，即规则语义中的不同情况。
