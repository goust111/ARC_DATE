  - 第一层推理：对比四个象限角落的示范块，归纳出每个象限对应的变换规则（原样 / 水平翻转 / 垂直翻转 / 旋转 180°）。

  - 将变换后的 sprite 放置到其标记像素所在象限内，紧贴 grey 分隔线的交叉点方向排列（按照从交叉点向外的顺序依次排列，不重叠）。原始散落位置的 sprite 被移除。

- `Key insight`：示范块之间的差异编码了四种几何变换；sprite 内的标记颜色不是装饰，而是指向象限的"地址"，决定了该 sprite 要接受哪种变换以及放置到哪个区域。

1. `main(grid)` 必须实现新题描述中的确定性转换规则，不能只识别 `generate_input()` 的固定模板。

4. 禁止把 ARC 颜色 id 、亮度、拼写等当作人类不可见的数值语义参与排序、大小比较或隐藏映射。颜色变化必须有可见结构线索。注意颜色亮度、拼写等也是不可见信息，若描述中出现违规的颜色id或者亮度，可自行使用少量的固定颜色替代，但注意生成时要在三个以内输入输出网格中对所有变换100%覆盖度。
