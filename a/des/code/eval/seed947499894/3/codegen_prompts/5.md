Input structure:

- 上半部分：散布着若干小型图案（由某种前景色如 Blue 绘制的连通形状，每个形状各不相同）。每个图案的正下方紧邻1个不同颜色的单像素标签（如 Yellow、Orange、Maroon 等），标签颜色各不相同。

Rule:
- 第一层：提取上半部分每个图案的形状轮廓（连通像素的相对位置集合），同时记录其正下方标签像素的颜色。
