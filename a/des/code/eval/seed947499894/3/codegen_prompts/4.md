description: 网格中散布着多个带方向缺口的彩色环形框，每个框需要沿缺口方向发射一条与框同色的射线，射线长度等于框内部被标记像素的数量；当射线碰到另一个框的外壁时，被击中的框改变颜色为射线颜色。

Input structure:
- 背景为黑色（Black）。网格中有若干个3x3或5x5的正方形空心框，每个框由单一颜色绘制。
- 每个框的某一条边（上、下、左或右）中央缺失1个像素，形成一个缺口，缺口处为黑色背景。
- 每个框的内部（除缺口外被边框包围的区域）可能包含0到若干个红色（Red）标记像素，其余内部像素为黑色。

Rule:
- 第一层：识别每个框的缺口位置，确定射线发射方向（缺口朝上则射线向上，朝下向下，朝左向左，朝右向右）。
- 第二层：数出每个框内部红色标记像素的数量 N。从缺口位置沿缺口方向向外延伸 N 个像素，绘制一条与框同色的射线。若 N=0 则不发射。
- 第三层：检查每条射线是否碰到了另一个框的外壁像素。如果碰到，被击中的框整体（包括其边框像素）变为射线的颜色。如果射线未碰到任何框，射线仍然保留在输出中。所有框内部的红色标记像素在输出中被移除（变为黑色）。

Key insight: 解题者需要将三个独立机制串联：缺口定方向、内部标记定长度、碰撞定变色。每一步都需要从样例中独立归纳，且射线长度由内部像素数量（一个需要主动计数的视觉量）控制，这使得规则不会在单个样例中被一眼看穿。

1. `main(grid)` 必须实现新题描述中的确定性转换规则，不能只识别 `generate_input()` 的固定模板。
