description: 根据框架内部嵌套的小图案的朝向，从网格边缘的颜色图例中查找对应填充色，再用该颜色填充框架的空白区域。

Input structure:
- 背景为黑色（Black）。网格中散布着若干由同一颜色绘制的矩形空心框架（边框宽1像素），每个框架内部中央放置一个由另一种颜色绘制的3像素L形小图案（占据2x2区域的三个格子，缺一个角）。
- 网格的某一条边缘（顶部或底部）放置一行颜色图例：图例由4对格子组成，每对格子上方是一个与框架内部相同颜色的L形小图案（4种朝向之一：缺口朝左上、右上、左下、右下），下方紧邻一个单独颜色像素作为该朝向对应的填充色。

Rule:
- 第一层：识别每个框架内部L形图案的朝向（即2x2区域中缺失角的位置：左上、右上、左下、右下四种）。
- 第二层：在边缘图例中找到朝向相同的L形图案，读取其下方紧邻像素的颜色，作为该朝向对应的填充色。
- 第三层：将框架内部除L形图案本身之外的所有黑色像素填充为查找到的颜色。框架边框颜色和L形图案颜色保持不变。

Key insight: L形图案的四种旋转朝向构成一套视觉编码，解题者需要先识别朝向、再通过图例解码出颜色映射，最后执行填充。朝向差异是微妙的空间细节，不能仅凭颜色匹配——必须关注几何形状的旋转状态。
</new_puzzle>

<new_puzzle>
description: 将网格中被隔墙分割的多个房间里的彩色像素，按照房间之间共享墙壁上的通道口进行颜色传播，最终每个房间被统一填充为通过通道网络连通的所有房间的混合规则所决定的颜色。

Input structure:
- 背景为黑色（Black）。灰色（Grey）线条将整个网格分割为若干矩形房间。
- 每个房间内部恰好包含一个单色像素（称为种子像素），颜色各不相同（从 Red、Blue、Green、Yellow、Orange、Magenta、Azure、Maroon 中选取）。
- 部分灰色墙壁上存在宽度为1像素的缺口（通道口），连接相邻两个房间。

Rule:
- 第一层：识别房间拓扑——通过通道口判断哪些房间直接相连。
- 第二层：对于每个房间，收集所有通过通道口与之直接相邻的房间的种子颜色（不包括自身）。如果相邻房间数量为0（孤立房间），则该房间填充自身种子颜色。如果相邻房间数量为1，则该房间填充那个唯一邻居的种子颜色。如果相邻房间数量 >= 2，则该房间填充自身种子颜色不变。
- 第三层：用确定的颜色填充整个房间内部（种子像素也被覆盖），灰色墙壁保持不变。

Key insight: 解题者不仅要识别墙壁上的微小通道口来建立房间连接关系，还要发现颜色替换规则取决于邻居数量——恰好一个邻居时发生颜色"入侵"，而孤立或多邻居时保持自身颜色。这种条件性替换规则需要通过多个样例才能归纳。
</new_puzzle>

description: 在网格中找到多个形状相同但大小不同的同心嵌套轮廓，根据轮廓的嵌套层级重新着色，并将最内层轮廓包围的区域用特定颜色标记。

Input structure:
- 背景为黑色（Black）。网格中存在若干组嵌套的闭合轮廓（每组轮廓的形状相似但尺寸递减，一层套一层，类似同心矩形或同心十字等）。所有轮廓最初都用同一种前景色（如 Green）绘制。
- 网格的一角放置一个小型颜色条（纵向排列的若干单像素），从上到下依次表示从最外层到最内层应使用的颜色序列。颜色条的像素数量恰好等于嵌套的最大层数。

Rule:
- 第一层：识别每组嵌套轮廓的层级关系——最外层为第1层，向内依次递增。
- 第二层：读取角落颜色条，建立层级到颜色的映射：颜色条第1个像素对应第1层（最外层），第2个像素对应第2层，以此类推。
- 第三层：将每层轮廓重新着色为对应的颜色。最内层轮廓所包围的纯黑区域用颜色条最后一个颜色（最内层颜色）填充为实心。

Key insight: 解题者需要同时完成三个非平凡推理：（1）在单色轮廓中分辨出哪些像素属于哪一层嵌套（需要理解连通性和包含关系），（2）角落颜色条的顺序对应嵌套深度而非空间位置，（3）最内层的填充规则不同于外层的重着色规则。
</new_puzzle>

<new_puzzle>
description: 网格中散布着多个带方向缺口的彩色环形框，每个框需要沿缺口方向发射一条与框同色的射线，射线长度等于框内部被标记像素的数量；当射线碰到另一个框的外壁时，被击中的框改变颜色为射线颜色。

Input structure:
- 背景为黑色（Black）。网格中有若干个3x3或5x5的正方形空心框，每个框由单一颜色绘制。
- 每个框的某一条边（上、下、左或右）中央缺失1个像素，形成一个缺口，缺口处为黑色背景。
- 每个框的内部（除缺口外被边框包围的区域）可能包含0到若干个红色（Red）标记像素，其余内部像素为黑色。

Rule:
- 第一层：识别每个框的缺口位置，确定射线发射方向（缺口朝上则射线向上，朝下向下，朝左向左，朝右向右）。
- 第二层：数出每个框内部红色标记像素的数量 N。从缺口位置沿缺口方向向外延伸 N 个像素，绘制一条与框同色的射线。若 N=0 则不发射。
- 第三层：检查每条射线是否碰到了另一个框的外壁像素。如果碰到，被击中的框整体（包括其边框像素）变为射线的颜色。如果射线未碰到任何框，射线仍然保留在输出中。所有框内部的红色标记像素在输出中被移除（变为黑色）。

Key insight: 解题者需要将三个独立机制串联：缺口定方向、内部标记定长度、碰撞定变色。每一步都需要从样例中独立归纳，且射线长度由内部像素数量（一个需要主动计数的视觉量）控制，这使得规则不会在单个样例中被一眼看穿。
</new_puzzle>

description: 网格被分为上下两半；上半部分包含若干带颜色标签的模板图案，下半部分包含一个大型拼图板，板上有与模板形状匹配的空洞；需要识别每个空洞匹配哪个模板，并用模板标签颜色（而非模板本身的图案颜色）填充空洞。

Input structure:
- 背景为黑色（Black）。网格由一条水平的灰色（Grey）分隔线分为上下两半。
- 上半部分：散布着若干小型图案（由某种前景色如 Blue 绘制的连通形状，每个形状各不相同）。每个图案的正下方紧邻1个不同颜色的单像素标签（如 Yellow、Orange、Maroon 等），标签颜色各不相同。
- 下半部分：一块由某种统一颜色（如 Green）填充的大型矩形区域，其中挖出了若干空洞（黑色区域）。每个空洞的形状恰好与上半部分某个图案的形状全等（可能经过平移但不旋转不翻转）。

Rule:
- 第一层：提取上半部分每个图案的形状轮廓（连通像素的相对位置集合），同时记录其正下方标签像素的颜色。
- 第二层：提取下半部分每个空洞的形状（黑色连通区域的相对位置集合），将其与上半部分的模板形状逐一比对，找到形状完全匹配的模板。
- 第三层：将每个空洞填充为其匹配模板的标签颜色（注意不是模板图案自身的绘制颜色，而是标签单像素的颜色）。上半部分保持不变。

Key insight: 解题者容易误以为空洞应该被模板图案的颜色填充，但实际上填充色来自模板下方的标签像素。这一间接映射是核心陷阱：形状匹配本身并不困难，真正的隐蔽性在于"使用标签颜色而非图案颜色"这一非直觉规则需要仔细对比样例才能发现。
</new_puzzle>

<new_puzzle>
description: 网格中有若干对相同形状的彩色碎片，每对碎片需要被拼合成一个完整的矩形；拼合方向由碎片各自的平边朝向决定，拼合后的矩形放置在网格中对应颜色的单像素锚点位置。

Input structure:
- 背景为黑色（Black）。网格中散布着若干彩色碎片，每个碎片是一个不规则但有一条完全平直边的连通区域。碎片成对出现，同一对的两个碎片颜色相同、形状互补——将它们沿各自的平边拼合后恰好构成一个实心矩形。
- 网格的边缘区域散布着若干单像素锚点，每个锚点的颜色对应一对碎片的颜色，每种颜色恰好出现一个锚点。

Rule:
- 第一层：按颜色将碎片配对，同色的两个碎片为一对。
- 第二层：对于每对碎片，找到它们各自的平直边。将两个碎片的平直边对齐贴合（一个碎片可能需要平移），拼合成一个实心矩形。拼合方向由平边的朝向决定：若平边朝右则另一个碎片从右侧贴合，朝下则从下方贴合，以此类推。
- 第三层：找到与该对碎片同色的锚点，将拼合后的矩形放置在锚点位置（锚点作为矩形的左上角）。原始碎片从原位移除。

Key insight: 解题者需要先通过颜色配对，再通过平边朝向推断拼合方式（而非尝试所有旋转），最后通过颜色匹配锚点确定放置位置。三步推理中，平边检测是最关键的视觉洞见——它将拼图问题从指数搜索简化为确定性操作。
</new_puzzle>

<new_puzzle>
description: 网格中有一个由多种颜色交替铺设的螺旋路径和若干位于路径上的彩色标记物；将每个标记物沿路径方向滑动，直到它到达路径上与自身颜色相同的色段，然后停留在该色段的起始位置。

Input structure:
- 背景为黑色（Black）。网格中有一条从外圈向内圈顺时针螺旋的路径，路径宽度为1像素。路径由若干颜色段交替组成（例如 Blue 段、Green 段、Yellow 段循环），每段包含连续若干个像素。
- 路径上散布着若干标记物，每个标记物是一个与路径颜色不同的亮色单像素（如 Red、Orange、Maroon），覆盖在路径像素之上。标记物的颜色恰好与路径上某一段的颜色相同。

Rule:
- 第一层：重建被标记物覆盖的路径像素的原始颜色——通过观察路径的颜色交替模式和每段的长度规律推断。
- 第二层：确定路径的行走方向（从外圈起点沿顺时针向内螺旋）。每个标记物沿路径前进方向滑动。
- 第三层：标记物滑动直到遇到路径上与自身颜色匹配的色段，停留在该色段的第一个像素位置。标记物原来的位置恢复为路径的原始颜色。

Key insight: 解题者首先需要识别螺旋路径的颜色分段模式以恢复被遮挡的信息，然后理解标记物"寻找同色路段"的滑动规则。路径的螺旋结构使得"前进方向"不是简单的上下左右，而是沿螺旋弯折的，这增加了空间推理的难度。
</new_puzzle>
