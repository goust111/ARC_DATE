Input structure：
- bg = black 背景。网格上有若干条由不同颜色绘制的单像素宽路径（水平或垂直线段），路径在某些位置正交交叉形成十字交叉口。交叉口处两条路径的像素重叠，该像素显示为两种颜色中编号较小的那种（即视觉上只可见一种颜色，但交叉事实可从路径连续性推断）。
- 网格左边缘有一个 green 像素标记为起点，位于某条路径的端头。
- 网格右边缘有一个 red 像素标记为终点，位于某条路径的端头。
- 网格上方有一行颜色优先级图例：从左到右排列 2–4 个不同颜色的 1×1 像素，表示优先级从高到低。

Rule：
- 信号从起点出发，沿当前路径前进。
- 当信号到达一个交叉口时，该交叉口连接两条不同颜色的路径。信号从一条路径进入交叉口，必须转弯进入另一条路径（不可直行继续同一条路径）。
- 如果交叉口有多个可转弯的方向（左转或右转都通向不同路径），则根据优先级图例选择优先级更高的路径颜色方向。
- 信号沿路径行进直到到达终点。记录信号依次经过的每条路径的颜色序列（不含起点和终点标记色）。
- 在终点位置向下绘制一条垂直彩色条纹，条纹长度等于经过的路径段数，每个像素的颜色按经过顺序从上到下排列。

Key insight：解题者需要三层推理——（1）从路径连续性推断被遮挡的交叉口结构，（2）理解"信号必须换路径"的转弯规则，（3）发现优先级图例决定歧义交叉口的选择——三者共同确定唯一路径和输出条纹。
</new_puzzle>
