Key insight：解题者需要先识别每组嵌套框架的层数（一个需要归纳的视觉计数），再通过图例建立层数到颜色的映射（第二层推理），两步缺一不可。

Input structure：
- bg = black 背景。网格中有 2–3 个大型灰色（grey）矩形模板，每个模板内部有一个不规则形状的镂空区域（bg 色），以及 1–2 个紧贴镂空边缘的小型彩色装饰标记（单像素或 2 像素的 L 形，颜色各异）。

Rule：
- 第一步：将每个彩色碎片与形状匹配的模板镂空配对。碎片需要旋转 R 度（R ∈ {0, 90, 180, 270}）后才能精确填入镂空。

- 清除网格上所有剩余的散落碎片（替换为 bg）。

Key insight：碎片与镂空的形状匹配确定了旋转量 R，这个旋转量不仅用于填充碎片，还隐式传递给模板上的装饰标记——解题者必须发现"碎片旋转量驱动标记旋转"这一隐蔽的联动规则。
</new_puzzle>

Input structure：
- bg = black 背景。网格上有若干条由不同颜色绘制的单像素宽路径（水平或垂直线段），路径在某些位置正交交叉形成十字交叉口。交叉口处两条路径的像素重叠，该像素显示为两种颜色中编号较小的那种（即视觉上只可见一种颜色，但交叉事实可从路径连续性推断）。
- 网格左边缘有一个 green 像素标记为起点，位于某条路径的端头。
- 网格右边缘有一个 red 像素标记为终点，位于某条路径的端头。
- 网格上方有一行颜色优先级图例：从左到右排列 2–4 个不同颜色的 1×1 像素，表示优先级从高到低。

Rule：
- 信号从起点出发，沿当前路径前进。
- 当信号到达一个交叉口时，该交叉口连接两条不同颜色的路径。信号从一条路径进入交叉口，必须转弯进入另一条路径（不可直行继续同一条路径）。
- 如果交叉口有多个可转弯的方向（左转或右转都通向不同路径），则根据优先级图例选择优先级更高的路径颜色方向。
- 信号沿路径行进直到到达终点。记录信号依次经过的每条路径的颜色序列（不含起点和终点标记色）。
- 在终点位置向下绘制一条垂直彩色条纹，条纹长度等于经过的路径段数，每个像素的颜色按经过顺序从上到下排列。

Key insight：解题者需要三层推理——（1）从路径连续性推断被遮挡的交叉口结构，（2）理解"信号必须换路径"的转弯规则，（3）发现优先级图例决定歧义交叉口的选择——三者共同确定唯一路径和输出条纹。
</new_puzzle>

description：在网格中识别由边框颜色编码的"印章"和"画布"，将印章图案按画布边框上缺口的位置和方向盖印到画布内部。

Input structure：
- bg = black 背景。网格上有若干个小型矩形区域（约 3×3 到 5×5）被单像素宽的彩色边框包围，内部有用另一种颜色绘制的非对称图案——这些是"印章"。

- 每个画布的边框上恰好有一个 1 像素的缺口（该像素为 bg 而非边框色）。缺口位于边框的上、下、左、右某一侧。

Rule：
- 通过边框颜色将每个印章与对应画布配对。
- 确定画布边框缺口所在的方向（上/下/左/右）。
- 将印章图案旋转，使印章的原始"顶部"朝向缺口所在方向（即：缺口在右侧则印章顺时针旋转 90°，缺口在下方则旋转 180°，缺口在左侧则逆时针旋转 90°，缺口在上方则不旋转）。
- 将旋转后的印章图案放置在画布内部，紧贴缺口对面的内壁居中对齐。例如缺口在上方，则图案贴画布内部底边居中。
- 印章的原始位置清除为 bg（包括其边框）。

Key insight：边框颜色建立配对关系是第一层推理；缺口方向决定旋转角度是第二层推理；"贴对面内壁"的放置规则是第三层推理——三者组合才能确定图案在画布中的最终位置和朝向。

Input structure：
- bg = black 背景。网格被划分为若干不规则的彩色区域（每个区域为一种非 black 非 grey 的纯色填充，区域之间以 grey 边界线分隔）。
- 一条由 maroon 像素绘制的单像素宽管道穿过多个区域，管道由水平和垂直线段组成，在区域内部拐弯（仅直角弯）。管道的一端标记为 green 像素（入口），另一端标记为 red 像素（出口），两个端点都位于网格边缘。
- 管道在穿越 grey 边界线时，会有 1 像素的断口（该位置既非 maroon 也非 grey，而是 bg），但断口两侧的管道段在同一行或同一列上且相距恰好 2 像素（中间隔着 grey 边界线和 1 个 bg 断口像素），因此管道的连续性可以推断。

- 从 green 入口沿管道前进，依次记录管道经过的每个彩色区域的颜色（同一区域内即使管道拐弯也只记录一次该颜色；只有跨越边界进入新区域时才记录新颜色）。
- 到达 red 出口后，在出口位置向网格外侧方向（即出口所在边缘的法线方向朝外，但由于不能画到网格外，改为朝内）绘制一条长度等于收集到的颜色数量的直线条，每个像素按经过顺序着色，第一个颜色紧贴出口。
- 管道本身（maroon 像素）、入口（green）和出口（red）在输出中保持不变。其余网格内容也保持不变。

Key insight：解题者需要（1）通过断口两侧的对齐关系推断管道穿越边界的连续路径，（2）理解"每进入一个新区域记录一次颜色"的采集规则，（3）在出口处按正确方向和顺序输出颜色条——管道的断口设计增加了路径追踪的非平凡性。

description：根据封闭区域的形状类别（矩形、L 形、T 形），从对应的颜色映射规则中选取填充色，再按区域面积从大到小的顺序叠加半透明效果。

Input structure：
- bg = black 背景。网格上有若干由 grey 像素绘制的单像素宽封闭边框，围成不同形状的区域：有的是矩形，有的是 L 形（两个矩形拼接），有的是 T 形（一个矩形从另一个矩形的中部伸出）。所有区域内部为 bg。
- 网格底部有三组颜色图例，每组由一个微型形状轮廓（用 grey 绘制的 3×3 或 4×3 的矩形/L 形/T 形缩略图）和紧邻其右侧的一个 2×1 彩色方块组成。三组图例分别对应矩形→颜色 A、L 形→颜色 B、T 形→颜色 C。

Rule：
- 对每个封闭区域，判断其形状类别：纯矩形、L 形（可旋转 4 个方向）、或 T 形（可旋转 4 个方向）。
- 通过底部图例查找该形状类别对应的填充颜色。
- 用该颜色填充区域内部（不包括 grey 边框）。
- 当两个区域共享一段 grey 边界（即边框重合）时，共享边界两侧的区域可能重叠 1 像素宽的填充行/列——此时，面积较大的区域的颜色被面积较小的区域的颜色覆盖（小区域优先显示）。
- 底部图例保持不变。

Key insight：第一层推理是识别每个封闭区域的几何形状类别（需要处理旋转变体）；第二层是通过缩略图图例建立形状到颜色的映射；第三层是理解共享边界处的面积优先覆盖规则——形状分类本身就需要非平凡的视觉归纳。
</new_puzzle>
