Input structure:

- 每个矩形的颜色唯一，不存在两个同色矩形。

Rule:
- 解析所有矩形的包含关系，构建嵌套树。一个矩形A直接包含另一个矩形B，当且仅当B的边界框完全在A内部，且不存在第三个矩形C使得B在C内部且C在A内部。
- 对嵌套树进行前序遍历：先父后子，同一父节点下的子节点按其在输入中的左上角列坐标从小到大排列。多棵树之间按根节点的左上角列坐标从小到大排列。
- 输出网格高度与输入相同。按遍历顺序从左到右放置每个矩形，矩形之间留1列black间隔。
- 每个矩形的垂直位置由其嵌套深度决定：深度0（最外层）顶部对齐第0行，深度1顶部对齐第2行，深度D顶部对齐第2D行。
- 放置时只绘制矩形本身（实心填充其颜色），不绘制其内部曾经包含的子矩形（即每个矩形在输出中是纯色填充）。

Key insight:
输入中的空间嵌套关系（谁在谁里面）是隐含的树结构，解题者需要先从视觉重叠中提取出这棵树，然后理解输出是这棵树的前序遍历展开——空间包含关系被转换为线性排列顺序加垂直深度编码。
