<description>
根据边框形状内的种子像素生长出枝条，枝条方向由种子在形状内的相对位置决定，枝条长度由形状面积决定。

Input structure:
- 背景为 black。网格上散布若干不同颜色的封闭矩形边框（边框宽度 1 像素，每个边框颜色不同）。
- 每个矩形边框内部（填充 black）恰好有一个非 black 的"种子"像素，种子颜色与边框颜色不同。
- 网格上另有若干孤立的单色小方块（2x2），每个小方块的颜色与某个边框颜色相同，位于边框外部。

Rule:
- 第一层：对每个矩形边框，数出其内部空白格数（即边框围成的内部面积），该数值 N 决定枝条生长长度。
- 第二层：种子像素在矩形内部的位置决定枝条的生长方向——种子靠近矩形的哪一条边（上/下/左/右），枝条就从种子出发朝该边的反方向（远离最近边的方向）向外延伸。若种子到两条边距离相等，优先选择水平方向（左或右对应的反方向）。
- 第三层：找到与该边框同色的外部 2x2 小方块，枝条的颜色使用该小方块的颜色（即边框颜色），枝条从种子位置出发，沿确定的方向画一条长度为 N 的直线（穿出边框、覆盖背景）。种子像素本身保留原色不变。
- 边框和内部保持不变，仅在网格上新增枝条像素。

Key insight: 面积编码长度、相对位置编码方向、外部色块确认颜色——三层信息分别来自不同的视觉线索，需要逐层推理才能确定最终输出。
</description>
</new_puzzle>

<description>
将散落的彩色碎片按照"钥匙-锁"边缘轮廓匹配嵌入灰色底板的缺口中，碎片需要翻转后颜色由配对规则决定重新上色。

Input structure:
- 背景为 black。网格中央有一块大型 grey 矩形底板，底板边缘有若干矩形缺口（凹进去的区域，露出 black 背景）。
- 底板外部散落着若干小型彩色碎片，每个碎片由单一颜色填充，形状各异（均为连通的矩形区域）。
- 底板内部（非缺口区域）有若干单像素的彩色标记点，每个标记点颜色与某个碎片颜色相同。

Rule:
- 第一层（形状匹配）：每个碎片的形状（像素集合的外轮廓）恰好与底板上某一个缺口的形状互补——碎片需要水平翻转（左右镜像）后才能精确填入缺口。
- 第二层（颜色重映射）：碎片填入缺口时，不使用碎片原色，而是使用底板内部与该碎片同色的标记点所在行对应的另一个标记点的颜色。具体来说：找到与碎片颜色相同的标记点，取该标记点所在行上的另一个不同颜色的标记点，碎片重新着色为后者的颜色。
- 输出时原碎片位置清除为 black，缺口被填入重新上色后的碎片。

Key insight: 形状匹配需要意识到镜像翻转关系，颜色则通过底板内标记点的行共现关系间接传递——两层推理缺一不可。
</description>

<description>
根据模板区域中图案的对称性类型，选择对应的着色方案，将测试区域中的灰色图案重新上色。

Input structure:
- 背景为 black。网格由 azure 色的分隔线（1 像素宽）划分为若干矩形区域（至少 5 个区域）。
- 其中若干区域是"示例区域"，每个示例区域内包含一个由两种非 black 非 grey 颜色绘制的图案，图案由若干像素组成，具有某种对称性（水平对称、垂直对称、旋转 180 度对称、或无对称性）。
- 恰好有一个区域是"色板区域"，其中包含四行单像素色块，每行两个不同颜色的像素，分别对应四种对称类型的着色方案（从上到下依次对应：水平对称、垂直对称、180 度旋转对称、无对称性）。
- 剩余区域是"测试区域"，内含 grey 色的图案（形状与某个示例区域的图案相同或在某种对称变换下等价）。

Rule:
- 第一层（对称性分类）：判断每个示例区域图案的对称性类型——检查图案是否关于其 bounding box 的水平中轴对称、垂直中轴对称、或 180 度旋转对称。若同时满足多种，取最高优先级（水平 > 垂直 > 旋转 > 无）。
- 第二层（方案学习）：观察示例区域中每种对称类型的图案使用了哪两种颜色，验证其与色板区域对应行的两种颜色一致，从而建立"对称类型 → 双色方案"的映射。
- 第三层（测试着色）：对每个测试区域的 grey 图案，判断其对称类型，查找对应的双色方案。图案中位于对称轴上的像素着第一种颜色（色板中该行左侧的颜色），其余像素着第二种颜色（色板中该行右侧的颜色）。

Key insight: 解题者必须先发现对称性是分类依据，再从示例中验证颜色映射，最后将分类规则泛化到灰色测试图案——需要归纳对称性这一抽象视觉属性。
</description>
</new_puzzle>

<description>
在网格中找到被"围栏"包围的区域，根据围栏上缺口的数量和位置，从外部对应方向的"颜料源"吸取颜色，逐层向内填充区域。

Input structure:
- 背景为 black。网格包含若干由 green 像素围成的封闭矩形"围栏"（边框宽 1 像素），围栏内部为 black。
- 每个围栏的边上有 1-3 个缺口（缺口即围栏边上缺失的 1 个 green 像素位置，该位置为 black）。
- 围栏外部，在每个缺口的正外侧方向上（即从围栏内部透过缺口向外看的方向），放置有一个彩色单像素"颜料源"（颜色各异，非 green 非 black）。颜料源与缺口之间可能隔着若干 black 像素。

Rule:
- 第一层（缺口识别与配对）：找到每个围栏上的所有缺口，每个缺口与其正外侧方向上最近的颜料源配对。缺口在围栏的哪条边上决定了填充方向：上边缺口 → 从上向下填充，下边缺口 → 从下向上填充，左边缺口 → 从左向右填充，右边缺口 → 从右向左填充。
- 第二层（单缺口填充）：如果围栏只有一个缺口，则整个内部用该缺口对应颜料源的颜色填满。
- 第三层（多缺口分层填充）：如果围栏有多个缺口且分布在同一条边上，则内部空间沿垂直于该边的方向按缺口的顺序（从左到右或从上到下）等分为若干条带，每条带用对应缺口的颜料源颜色填充。若缺口分布在不同边上，各方向的填充层在内部相遇时，行/列编号较小的方向（上边优先于下边、左边优先于右边）的颜色覆盖另一方。

Key insight: 缺口是"入口"——其位置决定填充方向，其数量决定空间划分方式，多边缺口的融合规则需要从多个样例中才能归纳出优先级。
</description>

<new_puzzle>
<description>
将网格中的多色连通区域拆解为单色层，根据每层的像素数排序后按外部指示条规定的顺序重新堆叠并膨胀合成。

Input structure:
- 背景为 black。网格左侧有一个大型多色连通区域（"主图"），由 3-5 种颜色的像素混合组成，各颜色像素交错排列形成一个整体连通图案。
- 网格右侧有一个垂直的"排序指示条"：一列由若干颜色段组成的竖条，每段为 1 像素高，每段颜色对应主图中使用的一种颜色，段的排列顺序从上到下表示堆叠优先级（上方 = 底层先绘制，下方 = 顶层后绘制可覆盖）。

Rule:
- 第一层（层分离）：将主图按颜色拆分为若干单色层。每层保留该颜色的所有像素位置，其余位置为 black。
- 第二层（排序映射）：读取右侧排序指示条中颜色从上到下的顺序，建立每种颜色的堆叠优先级。指示条最上方的颜色在最底层（最先绘制），最下方的颜色在最顶层（最后绘制，可覆盖其他层）。
- 第三层（膨胀与重新合成）：按指示条规定的顺序，从底层到顶层依次将各单色层绘制到输出网格上。每一层在绘制前，需要将其像素集合向外膨胀 1 像素（即每个该颜色像素的上下左右 4 邻域中的 black 像素也变为该颜色）。膨胀后上层覆盖下层。最终输出仅包含主图 bounding box 大小的区域，排序指示条不出现在输出中。

Key insight: 表面看是简单的颜色分层，但膨胀操作使得堆叠顺序真正产生不同的视觉结果——解题者必须发现膨胀规则并结合指示条的排序才能还原正确输出。
</description>

<new_puzzle>
<description>
识别网格中成对的同色"传送门"，将路径线段从入口门传送到出口门继续延伸，路径颜色在每次传送后按固定色环轮转。

Input structure:
- 背景为 black。网格中有若干"传送门"——每个传送门由 3 个同色像素组成的水平或垂直短线段表示。传送门成对出现（同色的两个传送门互为入口和出口），不同对使用不同颜色。
- 网格中有一条由 red 像素组成的"路径"起始线段（水平或垂直，长度 2-4 像素），路径的一端紧邻某个传送门的侧面。
- 网格上有一个由 yellow 单像素标记的"终点"。

Rule:
- 第一层（传送门配对）：找出所有同色传送门对。路径从起始线段出发沿其延伸方向前进，碰到传送门时进入该门。
- 第二层（传送与延续）：路径碰到传送门 A 后，从其配对传送门 B 的对面一侧继续以相同朝向延伸。传送门 A 和 B 的朝向相同（都是水平或都是垂直），路径从 B 的与 A 入口侧对应的出口侧射出。路径持续直行直到碰到下一个传送门、到达终点、或碰到网格边界停止。
- 第三层（颜色轮转）：路径每通过一次传送门，颜色按固定色环轮转一步：red → green → blue → red → ...。即起始为 red，第一次传送后线段变为 green，第二次变为 blue，第三次回到 red，以此类推。
- 输出：在原网格上画出完整路径（包括所有传送后的新线段），每段使用对应轮转后的颜色。传送门本身和终点标记保持不变。

Key insight: 解题者需要先理解传送门的配对和空间传送机制，再发现路径颜色随传送次数系统性变化的轮转规律——空间跳跃与颜色状态变化叠加构成双层推理。
</description>
</new_puzzle>

<new_puzzle>
<description>
在网格中根据"导轨"形状引导"滑块"运动，滑块停靠位置由导轨上的颜色标记决定，滑块到达后吸收标记颜色并改变自身外观。

Input structure:
- 背景为 black。网格上有若干由 grey 像素绘制的"导轨"——每条导轨是一条水平或垂直的直线（宽 1 像素、长度不等）。
- 每条导轨上有 1-2 个非 grey 非 black 的彩色标记像素，嵌在导轨线中（替换了该位置的 grey 像素）。
- 导轨的一端放置一个由 maroon 像素组成的小型"滑块"（2x2 或 1x2 或 2x1 的矩形），滑块紧贴导轨端点。

Rule:
- 第一层（运动方向）：滑块沿导轨方向从其所在端点向另一端滑动。滑块在导轨上滑动时不覆盖导轨像素——滑块沿导轨平移，离开的位置恢复为 grey（导轨）。
- 第二层（停靠规则）：滑块遇到导轨上的第一个彩色标记时停下，滑块的前沿（朝运动方向的那条边）与标记像素对齐。标记像素被滑块到达后消失（被滑块覆盖）。
- 第三层（颜色吸收）：滑块停靠后，将自身颜色从 maroon 变为所吸收标记的颜色。如果导轨上还有第二个标记，该标记作为滑块的"边框色"——滑块外圈像素变为第二个标记的颜色，内部像素变为第一个标记的颜色（仅当滑块为 2x2 时有内外之分；若滑块为 1x2 或 2x1，则交替着两种颜色）。
- 输出保留所有导轨（grey 像素），滑块显示在新位置并带有新颜色。

Key insight: 导轨决定运动轴、标记决定停靠点和颜色变换——解题者需要发现滑块"吸收"标记颜色的机制，以及双标记时内外着色的嵌套规则。
</description>
</new_puzzle>
