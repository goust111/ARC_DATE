根据围墙内部孔洞的形状匹配外部模板，再按模板中的颜色线索重绘围墙本身。

Input structure:
- 背景色（black）上有若干由同一种颜色（如 blue）构成的封闭围墙区域，每个围墙内部留有一个或多个不规则孔洞（背景色区域）。
- 网格边缘处散布着若干小型"模板块"，每个模板块由两种颜色组成：外框颜色为某种非背景色（如 red、green、orange 等），内部填充的形状恰好与某个围墙的孔洞形状完全一致（像素级匹配）。

Rule:
- 第一步：将每个模板块内部的填充形状与各围墙区域的孔洞形状进行匹配（可能需要旋转 0/90/180/270 度才能匹配上，但不做翻转）。
- 第二步：匹配成功后，将该围墙区域的围墙颜色整体替换为对应模板块的外框颜色；同时将模板块内部填充形状以其原始颜色填入围墙的孔洞中。
- 输出网格中移除所有原始模板块。

Key insight: 孔洞形状是匹配的钥匙——解题者必须先识别出孔洞与模板内部填充的几何对应关系（含旋转），再利用模板外框颜色反向决定围墙的重新着色，形成"形状匹配→颜色传递"的双层推理。
</description>

<description>
将散落的彩色路径片段按颜色接力串联，在交接点处按下一段路径的颜色重绘上一段路径的末端标记。

Input structure:
- 背景色（black）上有若干条由不同颜色绘制的短路径片段（每条由 3-6 个连续像素组成，沿水平、垂直或 45 度方向延伸）。
- 每条路径的一端有一个"末端标记"像素——该像素的颜色与路径主体不同，而是与另一条路径的主体颜色相同。
- 每条路径的另一端是纯色端点（与路径主体颜色一致），表示该路径的起点。

Rule:
- 第一步（建立链接顺序）：通过末端标记颜色找到下一条路径——当前路径末端标记的颜色等于下一条路径的主体颜色。这样所有路径形成一条首尾相接的链（链的第一条路径没有被任何其他路径的末端标记指向）。
- 第二步（延伸连接）：按链的顺序，从每条路径的末端标记出发，沿该路径的延伸方向继续画像素直到碰到下一条路径的起点端，连接线的颜色使用下一条路径的主体颜色。
- 第三步（末端标记重绘）：将每条路径的末端标记像素重绘为该路径自身的主体颜色（消除原始的颜色提示）。

Key insight: 末端标记的"异色"像素既是链接顺序的编码（指向下一条路径的颜色），又是延伸方向的锚点——解题者需先破译颜色链来确定拼接顺序，再理解末端标记在输出中被"吸收"回路径本色。
</description>

<description>
利用网格中的"种子行"和"滤镜列"做矩阵式交叉操作：种子行提供形状模板，滤镜列提供颜色变换规则，二者在交叉单元格处组合生成输出图案。

Input structure:
- 网格被灰色（grey）十字线分成若干矩形单元格（如 3x3 的单元格阵列，每个单元格大小相同，如 5x5 像素）。
- 最上面一行的单元格（种子行）中各包含一个由单色绘制的小形状（如 L 形、T 形、十字形等），形状颜色各不相同。
- 最左边一列的单元格（滤镜列）中各包含两个不同颜色的像素点：一个"源色"像素和一个"目标色"像素，源色像素在上，目标色像素在下。
- 其余内部单元格均为空（全为背景色 black）。

Rule:
- 对于每个内部单元格（位于第 i 行、第 j 列），取种子行第 j 列单元格中的形状作为模板。
- 查看滤镜列第 i 行单元格中的颜色映射：若模板形状的颜色恰好等于该滤镜的"源色"，则将形状以"目标色"绘制到该内部单元格中。
- 若模板形状的颜色与该滤镜的"源色"不匹配，则该内部单元格保持为空。
- 输出时保留灰色分隔线、种子行和滤镜列不变。

Key insight: 这是一个二维查表问题——列决定形状、行决定颜色变换是否激活，解题者必须同时理解"形状来源于列标题"和"颜色匹配来源于行标题"两层规则，且只有颜色匹配时才输出，这增加了一层条件判断的隐蔽性。
</description>

<description>
将封闭区域内的彩色像素视为"投票者"，按多数投票结果决定该区域边界的输出颜色，再将区域内部填充为得票最少的颜色。

Input structure:
- 背景色（black）上有若干个由 grey 像素绘制的封闭区域边框（每个区域为矩形或 L 形等简单多边形，边框厚度为 1 像素）。
- 每个封闭区域内部散布着若干彩色像素点（至少两种不同非 grey、非 black 的颜色），其余内部像素为 black。
- 网格的一个角落处有一个小型"图例区域"：一个 2 行 N 列的小表格，上行是颜色色块，下行是对应的"优先级标记"——由 1 到 N 个同色小点组成的水平点列，点数越少优先级越高。

Rule:
- 第一步（计数）：对每个封闭区域，统计内部每种彩色像素的数量。
- 第二步（确定多数色与少数色）：数量最多的颜色为"多数色"，数量最少的颜色为"少数色"。若出现数量并列，则查阅图例区域，按优先级标记（点数少的优先级高）打破平局。
- 第三步（重绘）：将该区域的 grey 边框重绘为多数色；将该区域内部所有像素（包括原来的彩色像素和 black 像素）全部填充为少数色。
- 输出时移除图例区域。

Key insight: 解题者首先需要发现"数量投票"机制来确定多数色和少数色，然后还需要发现图例中隐藏的平局打破规则（点列长度编码优先级）——两层规则嵌套在一起，且图例的作用只有在遇到平局样例时才能被推断出来。
</description>

<description>
将散落的形状碎片按照画框内锚点位置重新组装，碎片通过内部基准点对齐锚点，重叠区域标记为特殊颜色。

Input structure:
- 背景色（black）上有若干个由不同颜色绘制的小形状碎片（每个碎片 2-5 个像素，形状各异）。
- 网格中另有一个由 grey 像素绘制的矩形"画框"（内部全为 black）。
- 在画框内部，散布着若干单像素的彩色点，每个点的颜色与画框外某个碎片的颜色一一对应。这些点就是"锚点"。
- 每个碎片内部恰好有一个像素被标记为 maroon（与碎片主体颜色不同），这是该碎片的"基准点"。

Rule:
- 第一步（锚点匹配）：将画框内每个彩色锚点与画框外同色碎片配对。
- 第二步（放置碎片）：将每个碎片移动到画框内部，使碎片的 maroon 基准点恰好对齐到画框内的对应锚点位置。放置时碎片的 maroon 像素也被重绘为碎片的主体颜色。
- 第三步（重叠处理）：若多个碎片在画框内有重叠像素，则重叠位置显示为 red（无论原始碎片是什么颜色）。
- 输出仅包含画框内部区域（裁剪输出），移除画框边框本身。

Key insight: 解题者需要三层推理——首先通过颜色匹配找到锚点与碎片的对应关系，然后发现 maroon 像素是碎片内的基准对齐点（而非碎片的几何中心），最后发现重叠区域的特殊着色规则。三层信息分别在不同样例中才能被完整验证。
</description>

<description>
根据封闭迷宫房间之间的门洞位置关系，将颜色沿门洞方向"倒入"相邻房间并按方向填充半区。

Input structure:
- 背景色（black）构成迷宫的墙壁，azure 构成迷宫内部的通道/房间地板。
- 迷宫由若干矩形房间组成，相邻房间之间通过墙壁上的 1 像素宽门洞连通。
- 其中若干房间的地板上有一个彩色像素（如 red、green、yellow 等，每个房间最多一个），作为"染料源"。
- 没有染料源的房间地板全为 azure。

Rule:
- 第一步（识别房间和门洞）：识别所有矩形房间及其之间的门洞连接关系。
- 第二步（染料扩散）：每个染料源向其所在房间的所有门洞方向扩散。扩散规则为：染料源所在房间的地板全部填充为该染料颜色；与之直接相邻（通过一个门洞连接）且无自身染料源的房间，地板填充为该染料颜色，但仅填充靠近门洞那一半的区域（若门洞在房间的北墙，则填充房间的上半部分；若门洞在东墙，则填充右半部分，以此类推）。
- 第三步（多源冲突）：如果一个无源房间通过不同门洞接收到来自不同染料源的颜色，则每个来源各占其对应门洞侧的半区；若两个半区重叠，重叠部分填充为 maroon。
- 有自身染料源的房间不受其他房间扩散影响，始终保持自身染料颜色。

Key insight: 解题者需要先识别出迷宫的房间拓扑结构和门洞位置，再理解"半区填充"的方向性规则（门洞在哪一侧就填哪一半），最后处理多源交汇的冲突合并——三层推理环环相扣，且"半区"的划分依赖于门洞的具体位置而非简单的左右对称。
</description>

<description>
通过对比同色对象的尺寸差异推断缩放因子，再用该因子缩放网格中的目标框架及其内部图案。

Input structure:
- 背景色（black）上有若干对同色对象：每对中一个是"小版本"（如 2x2 的实心方块），另一个是"大版本"（如 4x4 的实心方块），颜色相同。每种颜色恰好出现两个对象。
- 网格中另有一个由 grey 线条绘制的矩形框架（空心），框架内部有一个由某种颜色 C 绘制的小图案。
- 颜色 C 恰好是上述某一对同色对象的颜色。

Rule:
- 第一步（推断缩放因子）：找到颜色 C 对应的那对同色对象，计算大版本边长与小版本边长的比值 K（K 为整数，通常为 2 或 3）。
- 第二步（缩放框架与图案）：将 grey 框架及其内部图案整体放大 K 倍（每个像素变为 KxK 的像素块）。
- 第三步（输出）：输出仅包含缩放后的框架及内部图案，背景为 black。原始的同色对象对和原始框架均不出现在输出中。

Key insight: 同色对象对的尺寸比是隐藏的缩放指令——解题者必须先发现"同色配对"关系，再通过比较配对对象的尺寸差异提取出缩放因子，最后将该因子应用于框架内的图案。缩放因子不是直接给出的，而是需要从视觉对比中推断。
</description>
</new_puzzle>
