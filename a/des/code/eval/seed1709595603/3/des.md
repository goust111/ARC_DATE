<description>
根据边框缺口方向将内部图案"推出"到外部，再用图案的颜色关系决定推出后是否翻转。

Input structure:
- bg = 背景色。网格中散布若干矩形边框（由同一颜色绘制的单像素宽矩形环），每个边框内部包含一个由另一种颜色构成的小型非对称图案（占据内部若干像素）。
- 每个矩形边框恰好有一个缺口（边框上缺少一个像素的位置），缺口位于边框的上、下、左、右某一侧。
- 边框外部、沿缺口方向的区域是空白背景。

Rule:
- 对每个边框，确定缺口所在的方向（上/下/左/右）。
- 将内部图案沿缺口方向平移到边框外部，紧贴边框外侧放置（图案的近边与边框外壁相邻）。
- 判断图案颜色与边框颜色的关系：如果图案颜色在可用颜色列表中排在边框颜色之前（颜色顺序为 Black, Blue, Red, Green, Yellow, Grey, Magenta, Orange, Azure, Maroon），则图案沿推出方向的垂直轴做一次镜像翻转；否则保持原样。
- 平移完成后，清除原边框及其内部所有像素（用背景色填充）。

Key insight: 缺口方向决定推出方位，但图案是否翻转取决于图案色与边框色在色序中的先后关系——这是一个需要从多个样例中归纳出来的隐含排序规则。
</description>
</new_puzzle>

<description>
利用散落的"钥匙"图案解锁对应的"锁"区域，将锁内隐藏的种子颜色向外扩散填充。

Input structure:
- bg = 背景色。网格中有若干由 Grey 像素围成的封闭矩形区域（"锁"），每个锁内部有一个由某种颜色绘制的小型连通图案（"种子"），锁内其余空间为背景色。
- 网格中另有若干独立的小型连通图案（"钥匙"），每把钥匙由两种颜色构成：外轮廓色和内部填充色。钥匙不被 Grey 边框包围，自由散落在背景上。
- 每把钥匙的外轮廓色与某个锁的 Grey 边框上恰好一个像素被替换成的特殊颜色相匹配（即每个锁的 Grey 边框上有一个非 Grey 像素，其颜色对应一把钥匙的外轮廓色）。

Rule:
- 通过边框上特殊像素的颜色将钥匙与锁配对。
- 配对成功后，检查钥匙的内部填充色是否与锁内种子的颜色相同——若相同，则该锁被"解锁"。
- 对于解锁的锁：移除 Grey 边框（填充为背景色），然后以种子图案为起点，将种子颜色沿四方向向外扩散，每扩散一步距离换一次颜色——第一层用钥匙的外轮廓色，第二层用种子颜色，如此交替，直到碰到网格边界或其他非背景像素为止。
- 未解锁的锁及所有钥匙保持原样不变。

Key insight: 解题需要两层归纳——首先通过边框上的特殊颜色像素建立钥匙-锁配对关系，然后通过钥匙内部色与种子色的匹配判断是否解锁；解锁后的扩散规则又是第三层需要发现的模式。
</description>

<new_puzzle>
<description>
根据连接线的拓扑结构对散落的彩色方块进行分组，再将同组方块合并为它们的最小外接矩形并用组内面积最大的方块的颜色填充。

Input structure:
- bg = 背景色。网格中散布若干小型实心矩形方块，每个方块为单一颜色（可以不同）。
- 方块之间有 Grey 单像素宽的连接线段（仅水平或垂直），每条线段连接恰好两个方块（线段端点与方块的边相邻）。
- 连接线形成若干独立的连通分组（即通过线段相连的方块属于同一组，不相连的属于不同组）。

Rule:
- 识别所有方块和 Grey 连接线，根据连接关系将方块分为若干组。
- 对每组方块，计算该组的最小外接矩形（包含组内所有方块的最小轴对齐矩形）。
- 在该组中找到面积最大的方块，以其颜色填充整个外接矩形区域。
- 若组内有多个面积相同且最大的方块，则使用其中行坐标最小（最靠上）的那个的颜色；若行坐标也相同，使用列坐标最小（最靠左）的。
- 移除所有 Grey 连接线（填充为背景色）。
- 不属于任何连接线的孤立方块保持原样不变。

Key insight: 连接线不仅仅是装饰——它们定义了分组拓扑，而输出颜色取决于组内面积排序，这要求解题者先发现分组规则再发现颜色选择规则，两步缺一不可。
</description>
</new_puzzle>

<new_puzzle>
<description>
将网格中的"信号塔"沿其天线方向发射射线，射线遇到"棱镜"对象时按棱镜朝向发生偏转，最终射线路径上的像素用信号塔与棱镜颜色的交替条纹绘制。

Input structure:
- bg = 背景色。网格中有若干"信号塔"：每个信号塔由一个 3x3 的实心彩色方块和一根从方块某一侧中央伸出的单像素宽、长度为 2 的同色"天线"组成（天线指向上/下/左/右之一）。
- 网格中还有若干"棱镜"：每个棱镜是一个由 3 个同色像素构成的直角三角形（即 2x2 区域去掉一个角的 L 形），棱镜颜色与信号塔颜色不同。棱镜的缺角方向决定其"偏转方向"。

Rule:
- 从每个信号塔的天线尖端出发，沿天线指向的方向发射射线。
- 射线沿直线传播，逐像素绘制，直到遇到网格边缘、另一座信号塔、或一个棱镜。
- 遇到棱镜时：射线在棱镜位置发生 90 度偏转——偏转方向由棱镜缺角的朝向决定（缺角在左上则偏向左上对应的 90 度转弯，具体规则：若射线水平到达棱镜且缺角朝上，则射线转向上方；缺角朝下则转向下方；若射线垂直到达且缺角朝左则转向左方，缺角朝右则转向右方）。
- 偏转后射线继续传播，可连续经过多个棱镜。
- 最终绘制整条射线路径：从信号塔出发的前段用信号塔颜色，每经过一个棱镜切换为该棱镜的颜色，直到遇到下一个棱镜再切换，如此交替。棱镜自身像素保持不变。

Key insight: 需要同时理解两个独立机制并将它们叠加——天线确定发射方向、棱镜缺角决定偏转方向是空间推理层；射线颜色按经过的棱镜依次切换是颜色规则层。
</description>
</new_puzzle>

<new_puzzle>
<description>
在被墙壁分割的多个房间中，根据房间内"家具"的对称性类型选择不同的填充策略，再将相邻房间的填充结果通过门洞进行颜色融合。

Input structure:
- bg = 背景色。网格被 Grey 单像素宽的直线墙壁分割成若干矩形房间。
- 相邻房间之间的墙壁上恰好有一个像素的缺口（"门洞"），用背景色表示。
- 每个房间内部有一个由某种非灰非背景颜色构成的小型连通图案（"家具"），家具不接触墙壁。

Rule:
- 对每个房间，判断其家具图案的对称性类型：
  - 若家具关于水平轴对称（上下对称），则用家具颜色对房间内所有背景像素进行水平条纹填充（从房间顶部开始，奇数行填充家具色、偶数行保持背景色）。
  - 若家具关于垂直轴对称（左右对称），则用家具颜色进行垂直条纹填充（从房间左侧开始，奇数列填充、偶数列保持）。
  - 若家具同时具有水平和垂直对称（即具有四重对称），则用家具颜色填充房间内全部背景像素（实心填充）。
  - 若家具无任何对称性，则房间内不进行填充，保持原样。
- 填充完成后处理门洞融合：对每个门洞，查看门洞两侧的两个房间——若两侧都已填充，则在门洞像素处绘制 Red 色；若仅一侧填充，则门洞像素绘制该侧的填充颜色；若两侧都未填充，门洞保持背景色。

Key insight: 解题者需要先发现对称性类型与填充模式之间的对应关系（这不是显然的——需要对比多个样例中不同对称性的家具和各自房间的填充结果），然后再发现门洞颜色取决于相邻房间的填充状态，形成两层独立的归纳推理。
</description>
</new_puzzle>

<new_puzzle>
<description>
从网格边缘的彩色种子像素出发向内生长"藤蔓"，藤蔓遇到障碍物时分叉绕行，最终藤蔓的粗细由其起始种子所在边缘段的长度决定。

Input structure:
- bg = 背景色。网格的四条边缘上分布着若干彩色像素段（每段是连续的同色像素，紧贴边缘排列），不同段颜色不同。
- 网格内部散布若干由 Maroon 构成的小型实心矩形障碍物。
- 网格内部其余区域为背景色。

Rule:
- 每个边缘彩色段作为一颗"种子"，向网格内部（垂直于该段所在边缘的方向）生长藤蔓。
- 藤蔓的宽度等于该种子段的像素长度。例如，一个长度为 3 的边缘段会生长出 3 像素宽的藤蔓带。
- 藤蔓笔直向内生长，逐行/逐列绘制种子颜色的像素。
- 当藤蔓的前进路径被障碍物阻挡时：藤蔓在障碍物前一行/列停止笔直生长，然后从障碍物的两侧各伸出一条宽度为 1 的分支，分支沿平行于边缘的方向绕过障碍物（向两侧各延伸至障碍物边界外一格），再转回原来的生长方向继续前进，但绕行后的藤蔓宽度减少为 1（不再恢复原宽度）。
- 若两条不同颜色的藤蔓在内部相遇（像素重叠），重叠像素使用先到达的藤蔓颜色（即距离边缘更近的种子段的颜色优先；若距离相同，上边缘优先于下边缘，左边缘优先于右边缘）。

Key insight: 种子段的长度编码了藤蔓宽度——这个数值映射关系需要从样例中归纳；障碍物引发的分叉绕行机制是第二层需要发现的空间规则；藤蔓相遇时的优先级判定是第三层。
</description>
</new_puzzle>

<description>
将网格中的多色像素簇视为"邮票"图案，根据同色导引线的指向找到"信封"矩形，再将邮票以导引线端点为锚点盖印到信封内部。

Input structure:
- bg = 背景色。网格中有若干小型多色像素簇（"邮票"），每个邮票由 2-3 种颜色的像素紧密排列而成，整体占据一个小矩形区域（通常 2x3 或 3x3 以内）。
- 从每个邮票的某一侧延伸出一条单像素宽的直线（水平或垂直），该直线颜色与邮票中面积最大的颜色相同（"导引线"）。
- 导引线的另一端连接到一个由 Azure 像素围成的空心矩形边框（"信封"），导引线端点恰好位于信封边框的某个像素上。
- 每个信封恰好连接一条导引线，信封内部为背景色。

Rule:
- 对每个邮票-导引线-信封三元组：
  - 确定导引线连接信封边框的位置（上侧/下侧/左侧/右侧）。
  - 将邮票图案复制到信封内部，放置规则为：邮票沿导引线方向的那一侧边缘紧贴信封边框的连接侧内壁，邮票在垂直于导引线方向上居中放置（若无法精确居中则偏向左上方）。
  - 如果导引线从邮票的右侧或下侧出发，则邮票在盖印前需要旋转 180 度。
- 盖印完成后，移除所有导引线（填充为背景色），邮票原始位置也清除（填充为背景色）。信封边框保留。

Key insight: 导引线的方向同时编码了两个信息——邮票应放入哪个信封（配对关系）以及邮票是否需要旋转（从导引线相对于邮票的出发侧推断），这两层信息需要从样例中分别归纳。
</description>
</new_puzzle>
