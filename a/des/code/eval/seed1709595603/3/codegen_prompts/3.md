Input structure:
- bg = 背景色。网格中散布若干小型实心矩形方块，每个方块为单一颜色（可以不同）。

Rule:
- 识别所有方块和 Grey 连接线，根据连接关系将方块分为若干组。
- 对每组方块，计算该组的最小外接矩形（包含组内所有方块的最小轴对齐矩形）。
- 在该组中找到面积最大的方块，以其颜色填充整个外接矩形区域。
- 若组内有多个面积相同且最大的方块，则使用其中行坐标最小（最靠上）的那个的颜色；若行坐标也相同，使用列坐标最小（最靠左）的。

- 不属于任何连接线的孤立方块保持原样不变。

Key insight: 连接线不仅仅是装饰——它们定义了分组拓扑，而输出颜色取决于组内面积排序，这要求解题者先发现分组规则再发现颜色选择规则，两步缺一不可。
