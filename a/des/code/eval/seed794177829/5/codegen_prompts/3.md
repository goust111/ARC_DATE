Input structure:

Rule:
- 第一步——碎片归位：将每个碎片平移到框架内部，使碎片中锚色像素恰好覆盖在对应颜色的锚点上。碎片不需要旋转或翻转，仅做平移。碎片的主体色像素填入框架内部相应位置，覆盖 black 背景。
- 第二步——射线发射：碎片归位后，统计每个碎片的主体色像素数量 N（不含锚色像素）。然后从该碎片的锚点位置出发，确定锚点距框架四条边中最近的那条边的方向（上/下/左/右）。在框架外部沿该方向射出一条长度为 N 格的射线，用该碎片的主体色绘制，从框架边框外侧紧邻的第一个像素开始延伸。

Key insight: 解题者需要先通过锚色匹配将碎片定位到框架内（颜色配对 + 平移对齐），再发现射线的方向由锚点在框架中的相对位置决定（最近边），射线长度等于碎片主体像素数——这是"拼图归位"与"计数→几何量映射"两层独立推理的叠加。
