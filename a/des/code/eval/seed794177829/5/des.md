<new_puzzle>
description: 根据围墙内部的彩色种子像素贴壁方向，将种子向对面墙壁延伸为条纹填充腔体，再用条纹数量决定围墙外框的重绘颜色。

Input structure:
- 背景色为 black。网格中有若干个由 grey 像素构成的封闭矩形围墙（一像素宽的矩形边框）。
- 每个围墙内部散布着一到三个不同颜色的单像素"种子"，种子颜色各不相同（可能是 red、blue、green、yellow、magenta、orange 等）。
- 每个种子像素恰好紧贴围墙的某一条内壁（上/下/左/右），即该种子与该壁像素四连通相邻。
- 围墙外部的背景上无其他对象。

Rule:
- 第一步——种子生长：每个种子从其所贴内壁的对面方向生长，形成一条一像素宽的水平或垂直条纹，延伸到对面内壁为止。例如种子贴在左壁，则向右延伸直至右壁；种子贴在上壁，则向下延伸直至下壁。如果两条条纹在某一格交叉，则该格采用垂直条纹的颜色（垂直条纹在上层）。
- 第二步——围墙重绘：数出该围墙内部最终生成的条纹总数（即种子个数）。在围墙外部紧邻围墙四周放置一圈一像素宽的新边框，新边框的颜色取决于条纹数量：1 条 → red，2 条 → blue，3 条 → green。原来的 grey 围墙保持不变，新边框画在 grey 围墙外侧一圈。

Key insight: 种子的贴壁方向决定了其条纹的延伸方向（朝对面壁生长），而条纹数量作为计数值映射为外框颜色——解题者需要先归纳"贴壁→反向生长"的空间规则，再发现条纹计数与外框颜色之间的对应关系，两步推理缺一不可。
</new_puzzle>

<new_puzzle>
description: 在网格中找到多个形状相同但大小不同的轮廓对象，按尺寸从小到大排序后，将最小对象的内部图案依次缩放填入更大对象的内部。

Input structure:
- 背景色为 azure。网格中散布着若干个由同一颜色（如 maroon）绘制的封闭轮廓对象，这些轮廓形状完全相同（经过整数倍缩放），但大小各不相同（例如 3x3、6x6、9x9 的同形轮廓）。
- 最小的那个轮廓对象的内部已经填充了由若干颜色组成的图案（每个像素可能是不同颜色）。
- 其余较大的轮廓对象内部为空（填充背景色 azure）。
- 每个轮廓的线条宽度恒为一像素。

Rule:
- 识别所有相同形状的轮廓对象，并按其边界框边长从小到大排序。
- 最小对象是"源"，提取其内部的彩色图案。
- 对于每个较大的对象，计算其边长与最小对象边长的比值 m（为正整数）。将源图案进行 m 倍最近邻缩放（每个源像素变为 m×m 的同色块），然后填入该对象的内部区域。
- 轮廓线本身保持不变，只填充内部区域。

Key insight: 解题者首先需要识别出不同大小的对象其实是同一形状的缩放版本（形状匹配），然后发现最小对象内部的图案是"母版"，每个更大对象的内部是对母版的整数倍像素缩放——缩放比例由轮廓尺寸比直接给出，但需要归纳"最小→源，大→缩放填充"的层级关系。
</new_puzzle>

<new_puzzle>
description: 将散落的彩色碎片通过锚色匹配拼入带有彩色锚点的模板框架中，然后根据每个碎片的主体像素数量，从锚点向最近框架边方向向外射出等长射线。

Input structure:
- 背景色为 black。网格中有一个较大的 grey 矩形框架（一像素宽边框），框架内部的背景为 black，但分布着若干单像素的彩色锚点（颜色各异，如 red、blue、green 等）。
- 框架外部散落着若干小型彩色碎片（四连通的多像素形状），每个碎片恰好使用两种颜色：一种"主体色"填充大部分像素，一种"锚色"仅出现在碎片中的一个像素位置上。
- 每个碎片的"锚色"与框架内部某个锚点颜色一一对应，不重复。

Rule:
- 第一步——碎片归位：将每个碎片平移到框架内部，使碎片中锚色像素恰好覆盖在对应颜色的锚点上。碎片不需要旋转或翻转，仅做平移。碎片的主体色像素填入框架内部相应位置，覆盖 black 背景。
- 第二步——射线发射：碎片归位后，统计每个碎片的主体色像素数量 N（不含锚色像素）。然后从该碎片的锚点位置出发，确定锚点距框架四条边中最近的那条边的方向（上/下/左/右）。在框架外部沿该方向射出一条长度为 N 格的射线，用该碎片的主体色绘制，从框架边框外侧紧邻的第一个像素开始延伸。

Key insight: 解题者需要先通过锚色匹配将碎片定位到框架内（颜色配对 + 平移对齐），再发现射线的方向由锚点在框架中的相对位置决定（最近边），射线长度等于碎片主体像素数——这是"拼图归位"与"计数→几何量映射"两层独立推理的叠加。
</new_puzzle>

<new_puzzle>
description: 根据网格中单像素宽路径的拐弯位置对路径分段，每段颜色由该段上的彩色标记决定，无标记段通过上下文继承规则染色。

Input structure:
- 背景色为 black。网格中有一条由 grey 像素构成的连续单像素宽路径（四连通），路径从网格的一条边缘进入，从另一条边缘离开，中间有若干次直角拐弯。
- 路径沿途的某些像素被替换为彩色标记像素（如 red、blue、green、yellow 等），这些标记像素仍然是路径的一部分（保持路径四连通性）。
- 路径的每个直线段（两次拐弯之间、或边缘到第一个拐弯之间的连续直线部分）上最多有一个彩色标记。

Rule:
- 将路径在每个拐弯处分段，得到若干直线段。拐弯处定义为路径方向发生改变的那个像素，该像素归属于拐弯后的新段。
- 对于包含彩色标记的直线段，将整段所有像素（包括标记像素本身）重绘为该标记的颜色。
- 对于不包含彩色标记的直线段，观察沿路径方向与之相邻的前一段和后一段的颜色：如果两侧相邻段颜色相同，则该段采用相同颜色；如果两侧颜色不同，则该段保持 grey 不变。
- 路径的起始段或末尾段如果没有标记且只有一侧邻段，则采用该邻段的颜色。

Key insight: 解题者首先需要识别路径的拐弯点以完成分段，再发现标记像素决定所在段的颜色，最后归纳出无标记段的上下文继承规则——同色邻段则继承，异色邻段则保持中性。三层认知路径：分段→标记染色→上下文继承，每一层都需要从样例中独立归纳。
</new_puzzle>

<new_puzzle>
description: 从左侧区域中互相遮挡的彩色矩形印章推断层序并还原完整尺寸，然后在右侧区域以锚点为中心按面积从大到小重新居中堆叠。

Input structure:
- 背景色为 azure。网格被一列 maroon 像素竖直分隔为左右两个区域。
- 左侧区域包含若干个不同颜色的矩形"印章"对象（纯色实心矩形），这些印章互相部分重叠遮挡。每个印章颜色唯一。被遮挡的印章只能看到未被覆盖的部分，但由于至少能看到两条相邻完整边（一条完整的水平边和一条完整的垂直边），其完整矩形尺寸可以推断。
- 右侧区域为 azure 空白背景，仅在某个位置有一个单像素的 black 锚点。

Rule:
- 第一步——层序推断：在左侧区域中，根据遮挡关系确定印章的前后层次。如果颜色 A 的可见像素直接切断了颜色 B 的矩形边缘连续性，则 A 在 B 之上（更靠前）。
- 第二步——形状还原：对每个印章，利用其可见的至少两条相邻完整边推断出完整矩形的宽度和高度。可见的完整水平边给出宽度，可见的完整垂直边给出高度。
- 第三步——重新堆叠：在右侧区域中，以 black 锚点为所有印章的中心点，按还原后矩形面积从大到小的顺序依次放置。面积最大的在最底层先放，最小的在最顶层最后放。每个矩形以锚点为中心对齐（若边长为偶数则中心偏左或偏上一格）。后放的矩形遮挡先放的。

Key insight: 解题者需要先从左侧部分可见的形状中推断遮挡层序（谁盖住了谁），再从可见的完整边缘还原每个矩形的完整尺寸，最后按面积排序在新锚点处以居中方式重建堆叠——"读取遮挡关系→补全形状→按新规则重组"形成三层递进推理，其中遮挡层序的推断和形状补全都依赖空间直觉。
</new_puzzle>
