<new_puzzle>
- `description`：根据边框缺口的朝向将内部图案"倒出"，倒出方向由缺口位置决定，倒出的内容在外部按照重力规则堆叠。

- `Input structure`：
  - bg = 背景色（最常见颜色）。
  - 网格中有若干矩形封闭框，每个框由同一种非背景色绘制，框壁厚度为1像素。
  - 每个框的某一侧壁上有一个连续缺口（缺口宽度 >= 1 像素，即该侧壁的若干连续像素被替换为背景色）。
  - 框内部填充有若干彩色像素块（颜色与框色不同），形成不规则图案。

- `Rule`：
  - 第一层：识别每个框的缺口位于哪一侧（上、下、左、右），缺口方向即为"倾倒方向"。
  - 第二层：将框内所有非背景像素沿倾倒方向"滑出"缺口。具体地，将内部图案整体沿缺口方向平移，直到图案完全离开框体。平移后的像素从缺口外侧开始，沿倾倒方向依次排列。如果倾倒方向为"下"，则内部像素按列各自向下滑动，在框外部堆叠到网格底部或遇到障碍物停止（类似重力下落）；其余三个方向同理，按行或列沿对应方向堆叠。
  - 框体本身（包括缺口）保留不变。框内部被清空为背景色。
  - 若多个框的倒出物在同一区域重叠，先处理离堆叠边界更远的框（即上方的框先于下方的框倒出，当倾倒方向为下时）。

- `Key insight`：缺口不仅标记了框的"开口"，更编码了内容物的运动方向；解题者需要先识别缺口朝向，再模拟沿该方向的重力堆叠——两步推理缺一不可。
</new_puzzle>

<new_puzzle>
- `description`：利用散布在网格中的单色"路标"像素构建有向路径，然后沿路径将起点处的彩色图案逐站传递并累积旋转。

- `Input structure`：
  - bg = 背景色。
  - 网格中有一个多色精灵（sprite），占据一个小的矩形区域，作为"源图案"。源图案的某一个角上有一个特殊颜色的像素（如 maroon），标记为"起点标记"。
  - 网格其余位置散布着若干孤立的单像素标记，颜色为 red、blue、green、yellow 四种之一。每种颜色编码一个旋转操作：red = 顺时针90度，blue = 逆时针90度，green = 水平翻转，yellow = 垂直翻转。
  - 从起点标记出发，沿四个正交方向中恰好有一个方向上能找到最近的孤立标记像素（同行或同列，中间无其他标记），该标记即为路径的下一站。从该站出发，再以同样规则找到下一个标记，形成一条不分叉的有向路径。

- `Rule`：
  - 沿路径依次访问每个标记像素。
  - 在每一站，根据该标记的颜色对当前图案执行对应的变换（旋转或翻转）。变换是累积的：第一站变换源图案，第二站在第一站结果的基础上再变换，依此类推。
  - 变换后的图案以该标记像素为定位锚点（对应源图案中起点标记的位置），绘制到网格上。
  - 所有站点的图案都绘制完成后，源图案原始位置保留不变。路标像素被图案覆盖（若图案覆盖到该位置）。
  - 路径终止条件：当前站点沿四个方向都找不到未访问的孤立标记时停止。

- `Key insight`：解题者必须先从散布的像素中重建出一条唯一的有向路径（通过行列对齐和最近原则），然后理解每种标记颜色对应的几何变换，最后追踪累积变换的效果——路径发现与变换累积构成两层独立的推理。
</new_puzzle>

<new_puzzle>
- `description`：网格中多个区域各包含一个不完整的周期图案和一个"样本瓦片"；用样本瓦片的形状修复区域中的图案缺损，但样本瓦片自身的颜色需要通过区域边框颜色查表替换。

- `Input structure`：
  - bg = 黑色背景。
  - 网格被 grey 线条分隔为若干矩形区域。
  - 每个区域内有一个用某种颜色绘制的周期性平铺图案（如锯齿、棋盘、条纹等），但图案中有若干像素被擦除为背景色，形成缺损。
  - 每个区域的一个角落放置了一个小矩形"样本瓦片"，用另一种颜色绘制（与区域图案颜色不同）。样本瓦片展示了该区域的最小重复单元的完整形态。
  - 网格边缘有一行或一列"颜色图例"：由成对的像素组成，每对包含一个样本瓦片颜色和一个图案颜色，表示"当样本瓦片颜色为 A 时，修复用的颜色为 B"。

- `Rule`：
  - 第一层：在每个区域中定位样本瓦片（角落中与图案颜色不同的小矩形），读取其形状作为最小重复单元。
  - 第二层：查找边缘颜色图例，将样本瓦片的颜色映射为该区域图案的实际颜色。
  - 第三层：用正确颜色的重复单元对区域进行完整的周期平铺，覆盖所有缺损位置（即将背景色像素替换为平铺图案的对应颜色）。
  - 样本瓦片本身从输出中移除（替换为背景色）。灰色分隔线保留。

- `Key insight`：三层推理环环相扣——识别样本瓦片的几何形状、通过颜色图例转换颜色、用转换后的瓦片修复周期图案。样本瓦片故意用不同颜色绘制，迫使解题者必须发现并使用颜色映射关系，而不能直接复制粘贴。
</new_puzzle>

<new_puzzle>
- `description`：网格中的彩色箭头指向目标空心框，箭头颜色决定对框内部执行哪种填充操作；箭头本身在输出中消失。

- `Input structure`：
  - bg = 背景色（最常见颜色）。
  - 网格中有若干空心矩形框（由 grey 绘制，壁厚1像素，内部为背景色）。
  - 网格中还有若干"箭头"形状的精灵。每个箭头由一种颜色绘制，形状为：一条长度为3至5像素的直线段（水平或垂直），在一端有一个三角形箭头尖（由3个像素组成的 V 形指向目标方向：朝右时为第一列1个像素、第二列上下各1个像素构成">"形；其余方向同理旋转）。箭头的朝向（尖端方向）指向某个矩形框。
  - 箭头颜色与填充操作的对应关系需要从样例中归纳：red = 用 red 填满框内部所有像素；blue = 用 blue 画框内从左上角到右下角的对角线（宽度1像素）；green = 用 green 画框内十字线（水平中线 + 垂直中线，各宽1像素）；yellow = 用 yellow 在框内绘制一个内缩1像素的矩形轮廓。
  - 每个矩形框可能被零个、一个或多个箭头指向。

- `Rule`：
  - 对每个箭头，沿其朝向（尖端方向）延伸一条射线，命中的第一个矩形框即为其目标。
  - 根据箭头颜色，对目标框内部执行对应的填充操作。
  - 如果同一个框被多个箭头指向，按箭头离框的距离从远到近依次执行操作（远的先画，近的后画，后画的覆盖先画的重叠像素）。
  - 所有箭头在输出中被移除（替换为背景色）。矩形框的 grey 边框保留。

- `Key insight`：解题者需要同时推断两层规则——箭头朝向决定"作用于哪个框"（空间射线匹配），箭头颜色决定"执行何种填充"（颜色-操作映射）。多个箭头作用于同一框时的叠加顺序增加了额外的推理挑战。
</new_puzzle>

<new_puzzle>
- `description`：在被彩色边框分隔的子区域之间建立"传送门"关系：每个区域中的小图案通过匹配门颜色传送到目标区域，并根据两个门的相对壁面位置进行旋转对齐。

- `Input structure`：
  - bg = 背景色。
  - 网格被厚度为1像素的 grey 线条分隔成若干矩形子区域。
  - 每个子区域的边框上恰好有两个位置被替换为特殊颜色的像素（非 grey、非背景色），这些特殊像素称为"门"。每个门占据边框上连续的2个像素。
  - 门的颜色在整个网格中成对出现：颜色相同的两个门分属不同的子区域，构成一对"传送门"。
  - 部分子区域内有一个小型彩色图案（精灵），部分子区域为空。

- `Rule`：
  - 找到包含图案的子区域，以及该区域边框上门的颜色。
  - 通过门颜色匹配，找到目标子区域（拥有同色门的另一个区域）。
  - 确定源门在源区域边框上的位置（上壁、下壁、左壁、右壁）和目标门在目标区域边框上的位置。
  - 将图案旋转，使得图案中朝向源门的那一面在传送后朝向目标门。具体地：计算源门壁面方向到目标门壁面方向需要旋转的角度（例如源门在右壁、目标门在上壁，则图案需顺时针旋转90度），对图案执行该旋转。
  - 将旋转后的图案放置在目标区域内，紧邻目标门的内侧位置（图案的朝门一边贴近门像素）。
  - 源区域中的原始图案被清除为背景色。每个图案只传送一次。

- `Key insight`：门的颜色配对决定传送目标，而门在各自区域边框上的壁面位置差异编码了旋转角度。解题者需要先发现颜色配对的传送关系，再推断壁面位置差异如何映射为具体的旋转变换——两层推理各自需要非平凡的归纳。
</new_puzzle>

<new_puzzle>
- `description`：网格中的多个同构形状各自缺失不同的局部片段；通过叠加所有不完整副本的信息互补恢复出完整形状，再将完整形状回填到每个副本的位置。

- `Input structure`：
  - bg = 背景色。
  - 网格中有 N 个（N >= 3）相同形状的精灵副本，分布在不同位置，互不重叠。
  - 所有副本使用相同的颜色和相同的外轮廓，但每个副本各缺失了不同位置的若干像素（这些像素被替换为背景色）。
  - 没有任何单个副本是完整的，但所有副本的并集恰好能还原出完整形状（即对于完整形状中的每个像素位置，至少有一个副本在该位置保留了原始颜色）。
  - 每个副本可能经历了不同的旋转（0度、90度、180度、270度），但形状本身相同。

- `Rule`：
  - 第一层：识别所有精灵副本，并推断每个副本相对于某个标准朝向的旋转变换。方法是：比较不同副本的现有像素轮廓，找到使各副本的保留像素能够最大程度对齐的旋转关系。
  - 第二层：将所有副本统一变换到标准朝向后，对每个像素位置取并集——如果某位置在任何一个副本中为非背景色，则该位置的正确值为该非背景色。由此重建出完整形状。
  - 第三层：将还原出的完整形状按照每个副本原来的旋转角度逆向旋转，写回每个副本的原始位置，填补所有缺失像素。

- `Key insight`：解题者需要先识别出多个副本是同一形状的不同残缺版本（且可能经过了不同角度的旋转），然后理解它们的信息互补关系——没有单一"模板"直接给出答案，必须综合所有副本才能重建完整形状。旋转对齐是隐藏的前置步骤，不解决它就无法正确合并信息。
</new_puzzle>

<new_puzzle>
- `description`：网格中散布的同色种子像素成对出现；每对种子向各自的垂直方向生长出等长线段，生长方向由配对方向的顺逆时针旋转决定。

- `Input structure`：
  - bg = 背景色。
  - 网格中散布着若干孤立的单像素"种子"，使用 red、blue、green 三种颜色。
  - 同一颜色的种子总是成对出现（即每种颜色的种子数量为偶数）。
  - 每对同色种子之间的连线方向为严格的水平、垂直或45度对角线之一。

- `Rule`：
  - 第一层（配对）：将同色种子按距离最近原则两两配对。每个种子恰好属于一对。
  - 第二层（生长方向推断）：对于每一对种子 A 和 B，确定从 A 到 B 的方向。A 的生长方向定义为该方向顺时针旋转90度后的方向；B 的生长方向定义为从 B 到 A 的方向顺时针旋转90度后的方向。这样 A 和 B 各自向配对连线的两侧伸出枝干。
  - 第三层（生长执行）：从每个种子出发，沿其生长方向画一条与种子同色的线段。线段长度等于该对种子之间的步数距离（水平或垂直方向为像素差的绝对值，对角线方向为沿对角线的像素步数）。生长线段遇到网格边界则截断。
  - 种子像素本身保留。如果两条生长线段在同一像素交叉，交叉点使用 red > blue > green 的优先级覆盖（优先级高的颜色覆盖低的）。

- `Key insight`：解题者必须先发现同色最近配对规则，再推断生长方向与配对方向之间的垂直旋转关系（两个种子各自朝连线的不同侧生长），最后利用种子间距确定线段长度。三层推理中，方向旋转关系是最隐蔽的核心洞见。
</new_puzzle>
