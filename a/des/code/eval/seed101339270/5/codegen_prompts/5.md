- `description`：根据网格中多个"时钟盘面"上指针的朝向对散落的彩色形状进行旋转，然后按照盘面的空间排列顺序将旋转后的形状拼贴到输出网格中。

- `Input structure`：
  - 背景色为 black。网格中包含两类对象：
    - **时钟盘面**：若干 5x5 的方块，中心像素为 grey，从中心向外延伸出一条长度为 2 像素的"指针"（由某种非 grey 非 black 颜色构成），指针指向上、下、左、右四个基本方向之一。盘面的四个角各有一个 grey 像素作为盘面标识。每个盘面的指针颜色各不相同。
    - **彩色形状**：若干不规则的小型单色图案（约 3x4 至 5x5），颜色与某个盘面指针颜色一一对应，散落在网格中。
  - 所有时钟盘面排列成一个规整的 M×N 矩阵（盘面之间间隔相同）。

- `Rule`：
  - 第一层推理——旋转量推断：每个时钟盘面的指针默认"初始方向"为上。指针实际朝向相对于上方向的顺时针旋转角度（0°、90°、180°、270°）即为对应彩色形状需要执行的旋转量。颜色匹配将盘面与形状配对。
  - 第二层推理——排列组装：时钟盘面在网格中排成 M×N 矩阵。将每个盘面替换为其对应的旋转后形状，按照盘面矩阵的行列位置排列。形状之间用单像素宽的 grey 分隔线隔开。
  - 输出网格仅包含排列好的旋转后形状与分隔线，裁剪到最小包围框。

- `Key insight`：时钟指针的朝向不是静态标签，而是编码了旋转变换的具体角度；盘面的空间矩阵排列则定义了输出的拼贴布局——解题者需要先从指针方向推断旋转量，再从盘面位置推断输出排列，两步推理路径完全独立。
</new_puzzle>

## 实现要求

1. `main(grid)` 必须实现新题描述中的确定性转换规则，不能只识别 `generate_input()` 的固定模板。
2. `generate_input()` 必须随机生成多样样例，不能固定死。随机维度应覆盖：网格大小、对象数量、位置、颜色、方向、形状参数或关键分支。
3. 生成器必须保证输入满足 `main()` 的隐式假设：对象不重叠、不越界、特殊标记唯一或可区分、匹配关系无歧义、关键分支出现概率相同。
4. 禁止把 ARC 颜色 id 、亮度、拼写等当作人类不可见的数值语义参与排序、大小比较或隐藏映射。颜色变化必须有可见结构线索。注意颜色亮度、拼写等也是不可见信息，若描述中出现违规的颜色id或者亮度，可自行使用少量的固定颜色替代，但注意生成时要在三个以内输入输出网格中对所有变换100%覆盖度。
