- `Input structure`：
  - 背景为黑色（black）。
  - 网格被 azure 颜色的水平线和垂直线分割成若干矩形子网格（类似九宫格布局）。
  - 每个子网格内包含：
    - 一个"印章"：由某种非背景、非 azure 颜色构成的小型连通图案（如 T 形、L 形等），大小约 2x2 到 4x4，位于子网格的固定位置（如左上角区域）。
    - 若干"墨点"：散布在子网格其余位置的单像素标记，每个墨点的颜色与印章颜色不同，且各墨点颜色互不相同。

- `Rule`：
  - 第一步：在每个子网格中，识别印章图案和所有墨点的位置。
  - 第二步：目测判断每个墨点离印章中心的远近（墨点数量少，通常 2-4 个，肉眼即可区分远近）。
  - 第三步：按从近到远的顺序，依次将印章图案以每个墨点为中心位置"盖印"——即将印章的形状以墨点的颜色绘制到网格上，印章图案的中心对齐墨点位置。
  - 第四步：后盖的印章覆盖先盖的印章（即距离远的墨点对应的盖印结果可以覆盖距离近的）。印章原始位置的图案在输出中被清除为黑色。墨点像素本身被盖印图案覆盖。
  - azure 分隔线保持不变。

- `Key insight`：解题者需要发现三个非显然的规律：（1）印章图案是一个"模板"，墨点位置是"盖印目标"；（2）墨点的颜色决定了该次盖印使用的颜色；（3）盖印的先后顺序由距离决定，而这一顺序通过重叠区域的颜色归属才能被观察到——只有通过仔细对比重叠处保留的是哪个墨点的颜色，才能反推出"后盖覆盖先盖"的远近顺序规则。
