将网格中的多色图案拆解为单色层，每层沿各自锚点标记所指示的方向平移后重新叠合。

Input structure:
- bg = 最常见颜色（black）。网格中央有一个由多种颜色组成的复合图案（各颜色像素相互交织）。
- 网格的四条边上各有若干单像素的锚点标记，每个锚点的颜色对应复合图案中的某一种颜色。
- 每种颜色在边上只出现一个锚点标记。锚点所在的边（上、下、左、右）指示了该颜色层需要平移的方向：上边→向上，下边→向下，左边→向左，右边→向右。
- 锚点在其所在边上的具体位置（距边角的像素偏移量）指示了平移的步数。例如上边第 3 个像素位置的锚点表示该颜色层向上平移 3 步。

Rule:
- 将复合图案按颜色拆解为若干单色二值层（每层只含一种颜色的像素和 bg）。
- 对每层，根据其颜色对应的边缘锚点，确定平移方向和步数。
- 将该层整体沿指定方向平移指定步数。
- 将所有平移后的层重新叠合到 bg 网格上；若多层像素重叠，后叠合的层覆盖先叠合的层（叠合顺序为：锚点从网格边缘顺时针扫描的顺序，从左上角开始）。
- 擦除边缘上的所有锚点标记。

Key insight: 解题需要三层推理——第一层是发现边缘单像素是锚点而非噪声，并通过颜色匹配建立锚点与图案层的对应；第二层是发现锚点所在边编码了方向、锚点在边上的位置编码了距离；第三层是发现重叠时的覆盖优先级由锚点的空间排列顺序决定。
