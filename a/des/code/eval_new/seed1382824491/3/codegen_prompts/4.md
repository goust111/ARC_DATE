- `Input structure`：

  - 画布的上方有一行"水平折叠指令条"：该行的每个像素要么是背景色，要么是 Red。Red 像素所在的列标记了垂直折叠线的位置。
  - 画布的左侧有一列"垂直折叠指令条"：该列的每个像素要么是背景色，要么是 Blue。Blue 像素所在的行标记了水平折叠线的位置。
  - 指令条中 Red 像素最多 1 个，Blue 像素最多 1 个（即最多一次水平折叠 + 一次垂直折叠）。

- `Rule`：
  - 第一层推理——解读折叠指令：如果上方指令条中有 Red 像素在第 c 列，则画布沿第 c 列垂直对折（右半部分翻到左半部分上方）。如果左侧指令条中有 Blue 像素在第 r 行，则画布沿第 r 行水平对折（下半部分翻到上半部分上方）。两个折叠的执行顺序为：先垂直折叠、后水平折叠。
  - 第二层推理——颜色叠加规则：折叠后多层像素重叠时，遵循以下规则：若某位置所有层都是背景色，则输出背景色；若只有一层有非背景色，输出该颜色；若多层都有非背景色，则输出在画布上行号更小（更靠上）的那一层的颜色（即上层优先）。
  - 输出网格仅包含折叠后的画布（尺寸缩小），不包含指令条。

- `Key insight`：解题者需要从边缘的指令条读出折叠线位置和折叠顺序，然后在脑中完成空间翻转——难点在于理解"翻折后哪些像素对齐到同一位置"以及"折叠顺序影响最终哪一层在上方"。指令条的存在使得折叠线不是靠对称性猜测，而是被显式编码的。
