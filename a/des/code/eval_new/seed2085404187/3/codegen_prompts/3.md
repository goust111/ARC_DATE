  - 背景为 black。

- `Rule`：
  - 第一层推理（确定颜色层级）：观察所有训练样例，会发现颜色之间存在固定的优先级顺序（例如 red > green > yellow > orange > magenta），该顺序在所有样例中保持一致，需要从样例的输出中归纳出来。
  - 第二层推理（同步扩展与覆盖）：在每个区域内，所有种子同时开始向四方向（上下左右）逐步扩展，每步扩展 1 像素，填充为种子自身颜色。扩展不越过 azure 墙壁。当两个种子的扩展区域发生碰撞时，优先级高的颜色覆盖优先级低的颜色。最终每个区域内所有 black 像素都被填满。
  - Azure 墙壁保持不变。

- `Key insight`：表面上看是简单的 Voronoi 式填充（离谁近填谁的色），但当两个种子到某像素等距时，颜色优先级才决定归属。解题者必须从多个样例中归纳出隐含的全局颜色优先级顺序，这是第一层非平凡推理；同步扩展的空间填充逻辑是第二层。
