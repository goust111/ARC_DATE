- `Input structure`：
  - 背景为 black。
  - Green 色线条将网格划分为若干矩形区域。
  - 每个区域内部有一个用某种颜色绘制的不对称小图案（占据部分格子），以及恰好两个 yellow 标记像素。
  - 两个 yellow 标记像素位于图案的 bounding box 之外，但仍在该区域内。

- `Rule`：
  - 第一层推理（解码变换类型）：两个 yellow 标记像素的相对位置编码了要执行的几何变换：
    - 两个标记在同一行（水平排列）→ 对图案执行水平翻转（左右镜像）。
    - 两个标记在同一列（垂直排列）→ 对图案执行垂直翻转（上下镜像）。
    - 两个标记既不同行也不同列（对角排列）→ 对图案执行转置（沿主对角线翻转，即行列互换）。
  - 第二层推理（变换的锚点）：变换以图案的 bounding box 中心为锚点，在该区域内原地执行。变换后如果图案超出区域范围则裁剪（但设计上保证不会超出）。
  - 移除两个 yellow 标记像素（变为 black）。Green 分隔线保持不变。

- `Key insight`：yellow 标记的空间排列方式（水平、垂直、对角）本身就是变换指令的编码——这不是"标记在哪里"而是"标记之间的关系是什么"。解题者需要忽略标记的绝对位置，关注它们的相对几何关系。

1. `main(grid)` 必须实现新题描述中的确定性转换规则，不能只识别 `generate_input()` 的固定模板。

4. 禁止把 ARC 颜色 id 、亮度、拼写等当作人类不可见的数值语义参与排序、大小比较或隐藏映射。颜色变化必须有可见结构线索。注意颜色亮度、拼写等也是不可见信息，若描述中出现违规的颜色id或者亮度，可自行使用少量的固定颜色替代，但注意生成时要在三个以内输入输出网格中对所有变换100%覆盖度。
