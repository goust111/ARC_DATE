将网格中的二维条形码解码为颜色指令序列，对指定目标区域执行逐行/逐列染色。

Input structure:
- bg = 背景色。网格被分为两个区域：上方是"条形码区"，包含若干水平彩色条纹（每条纹高度为1像素，颜色和长度各异）；下方是"目标区"，包含一个灰色（5）填充的矩形。
- 两个区域之间由一行分隔线隔开。
- 条形码区左侧有一列单像素标记，颜色为红色（2）或蓝色（1），表示该条纹是行指令还是列指令。

Rule:
- 红色标记的条纹为行指令：条纹的颜色决定染色颜色，条纹的长度（像素数）决定目标区中要染色的行号（从上到下第N行）。
- 蓝色标记的条纹为列指令：条纹的颜色决定染色颜色，条纹的长度决定要染色的列号（从左到右第N列）。

- 行指令染整行，列指令染整列。
- 输出仅包含染色后的目标区矩形（裁剪掉条形码区和分隔线）。

Key insight: 条纹长度是位置索引而非字面尺寸——一根5像素长的条纹意味着"第5行/列"而非"染5个像素"，这种语义转换是主要陷阱。
