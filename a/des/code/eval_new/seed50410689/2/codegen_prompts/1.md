- `Input structure`：
  - 背景色为 black。网格中有若干由 grey 像素围成的不规则封闭区域（墙壁厚度为 1 像素）。

  - 每个封闭区域的外壁（grey 墙壁的外侧、紧邻墙壁的一格）上恰好有一个与该区域种子同色的单像素"出口标记"。出口标记位于墙壁的上、下、左、右某一侧外缘。

- `Rule`：
  - 对每个封闭区域，首先识别其内部种子的颜色 C。
  - 在该区域的 grey 外壁外侧找到颜色为 C 的出口标记，出口标记所在方位（上/下/左/右）即为射线发射方向。
  - 数出该封闭区域内部 black 空白格的数量 N（不含种子本身）。
  - 从出口标记位置开始，沿出口方向向外绘制长度为 N 的射线，颜色为 C。射线遇到其他非 black 像素时截止（即使尚未画满 N 格）。
  - 种子和出口标记保留在原位，grey 墙壁不变。

- `Key insight`：出口标记的颜色将其与对应封闭区域的种子配对，出口相对于墙壁的方位决定射线方向，而封闭区域的内部空白面积决定射线长度——解题者需要同时发现颜色配对、方向编码和面积-长度映射三层规则。
