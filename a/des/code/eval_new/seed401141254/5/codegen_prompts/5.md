  - 在画布外部的网格空白区域散布着若干小型多色精灵（"印章"），每个印章内包含恰好一个像素与某个画布边框标记颜色相同——这个像素称为"锚点"。印章的其余像素使用其他颜色。
  - 每个印章精灵的整体尺寸小于画布内部空间。

- `Rule`：
  - 第一步（颜色匹配）：通过锚点颜色将每个印章与对应的画布配对——锚点颜色与画布边框上的标记颜色相同。
  - 第二步（方位推断与旋转）：确定标记在画布边框的哪条边上：上边 → 0°（不旋转）；右边 → 顺时针 90°；下边 → 180°；左边 → 逆时针 90°（即顺时针 270°）。将印章精灵按该角度旋转。

  - 画布外的印章精灵被擦除（变为 Azure 背景），画布的 Grey 边框保持不变。

- `Key insight`：标记在画布边框上的位置（上/右/下/左）不仅是配对线索的一部分，还隐含地编码了印章需要旋转的角度——解题者必须发现"标记方位 = 旋转角度"这一非显然的对应关系，这是超越简单颜色匹配的第二层推理。
