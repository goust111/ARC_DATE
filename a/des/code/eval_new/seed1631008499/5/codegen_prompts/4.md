- `Rule`：
  - 数出每个框架左上角附近 magenta 层级标记的像素数量，该数量决定该框架的嵌套深度（1 = 最外层，数字越大越靠内层）。
  - 以 grey 锚点为中心，将所有框架重新绘制为同心嵌套结构：最外层框架（层级 1）居中放置于锚点，层级 2 的框架缩放到刚好能放入层级 1 框架内部并居中，以此类推。
  - "缩放"规则：每个框架按其层级被绘制为固定大小——层级 k 的框架边框占据从中心向外第 k 圈的位置（即最外层框架最大，每向内一层，框架的宽和高各缩小 2 像素，即每边各缩进 1 像素）。

  - 若两个框架层级相同（标记数相同），则按框架原始面积从大到小排列为相邻层（大的在外）。

- `Key insight`：框架角落的小点数量不是装饰而是排序键——解题者必须先发现"小点计数→嵌套层级"的编码关系，再理解同心重绘的空间布局规则，最后处理同级框架的 tie-break。这是一个三层推理结构。

1. `main(grid)` 必须实现新题描述中的确定性转换规则，不能只识别 `generate_input()` 的固定模板。

3. 生成器必须保证输入满足 `main()` 的隐式假设：对象不重叠、不越界、特殊标记唯一或可区分、匹配关系无歧义、关键分支出现概率相同。
4. 禁止把 ARC 颜色 id 、亮度、拼写等当作人类不可见的数值语义参与排序、大小比较或隐藏映射。颜色变化必须有可见结构线索。注意颜色亮度、拼写等也是不可见信息，若描述中出现违规的颜色id或者亮度，可自行使用少量的固定颜色替代，但注意生成时要在三个以内输入输出网格中对所有变换100%覆盖度。
