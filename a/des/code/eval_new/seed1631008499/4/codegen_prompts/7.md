- `Input structure`：
  - bg = 最常见颜色（黑色）。网格中有若干由单一颜色构成的矩形"围栏"（每个围栏是一个空心矩形边框，宽度 1 像素）。
  - 每个围栏的某一条边上恰好有一个缺口（连续缺失 1-3 个像素）。
  - 每个围栏的内部散布着若干"种子"像素，种子颜色与围栏颜色不同但在同一个围栏内所有种子颜色相同。
  - 不同围栏的种子颜色可以不同。

- `Rule`：
  - 对每个围栏，确定缺口所在的边（上、下、左、右）以及缺口的位置。
  - 数出围栏内部种子像素的数量 N。
  - 从缺口位置向外（远离围栏内部的方向）发射 N 条平行射线，射线的颜色为种子颜色。射线从缺口处开始，沿缺口朝外的方向延伸，直到到达网格边界。
  - 若缺口宽度为 W 像素，N 条射线在垂直于射线方向上均匀分布在缺口宽度范围内（若 N > W，则射线堆叠，多条射线共用同一列/行位置，此时射线仍为单像素宽）。若 N <= W，射线从缺口的左端/上端开始逐一排列。
  - 围栏和种子像素在输出中保留不变。

- `Key insight`：解题者需要同时理解两个独立的编码：缺口的方位决定了射线的方向，种子的数量决定了射线的条数。围栏既是空间容器又是方向指示器的双重角色需要从样例中归纳。
