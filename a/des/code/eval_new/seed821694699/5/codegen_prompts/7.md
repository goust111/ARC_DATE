将散布在网格中的彩色箭头按照"箭头链"的方式依次连接：每个箭头指向下一个箭头的位置，链中前一个箭头的颜色决定后一个箭头射出的光线颜色，光线沿指向方向延伸直到碰到障碍或边界。

Input structure:
- bg = 最常见颜色（Azure）。网格中散布着若干个由 3x3 像素组成的箭头符号，每个箭头由一种颜色绘制。箭头的绘制方式：中心像素 + 指向方向的 1 个像素 + 垂直于指向方向的 2 个像素构成箭尾（形成 T 字形，T 的竖笔指向方向即为箭头方向）。每个箭头指向四个基本方向之一（上、下、左、右）。
- 网格中还有若干 Grey 的 1x1 障碍像素。
- 恰好有一个箭头的尾部（T 字横笔的中心外侧一格）处有一个 Yellow 标记像素，表示链的起始箭头。

Rule:
- 从 Yellow 标记的起始箭头开始。
- 从当前箭头的尖端沿其指向方向寻找，找到的第一个箭头（按指向方向的直线扫描，箭头的任意像素在扫描线上即算命中）就是链中的下一个箭头。
- 在当前箭头的尖端到下一个箭头之间的 bg 像素上绘制光线，光线颜色 = 当前箭头的颜色。
- 移动到下一个箭头，重复上述过程。
- 当箭头指向方向上没有其他箭头（扫描到边界或只遇到障碍）时，光线从尖端延伸到边界或障碍处停止，链终止。
- 输出中所有箭头保持原样，新增光线，Grey 障碍保持不变，Yellow 标记保持不变。

Key insight: 解题者首先要识别箭头的形状编码（T 字形）和朝向（第一层），然后发现箭头之间通过指向方向形成链式连接关系（第二层），最后发现光线颜色取自发射箭头而非目标箭头的颜色（第三层）。链的顺序完全由空间指向关系决定，而非颜色匹配。
</description>
