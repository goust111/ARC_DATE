将网格中的彩色路径段按照路口处的"信号灯"颜色进行接续拼接，信号灯的颜色指示下一段路径应取哪个颜色的段来衔接。

Input structure:
- bg = Black。网格中有若干条由不同颜色绘制的 1 像素宽的水平或垂直路径段（例如 Red 段、Blue 段、Green 段等），每段为一条直线。
- 路径段的端点处，相邻像素（4-邻域中不在该段上的像素）可能有一个"信号灯"像素：一个与任何路径段颜色都不同的单独颜色像素（Maroon 或 Orange）。
- 网格角落有一个 2x2 的图例区：两行，每行为一个信号灯颜色像素 + 一个路径颜色像素，表示"看到此信号灯颜色 → 下一段应为此路径颜色"。
- 有一条路径段的某个端点标记有 Yellow 像素，表示链的起点。

Rule:
- 从 Yellow 标记的起点路径段开始，沿该段到达其另一端点。
- 在端点处找到信号灯像素，查图例得到下一段路径的颜色 C。
- 在当前端点的 4-邻域（排除已走过的段）中找到颜色为 C 的路径段的端点，将这两个端点之间的 bg 像素填充为 Grey，形成连接桥。
- 沿颜色 C 的路径段继续行进到其另一端点，重复上述过程。
- 当端点处无信号灯或无可连接的路径段时，链终止。
- 输出中，所有被链连接的路径段保持原色，连接桥为 Grey，图例区域清除为 bg，未被链接的路径段也清除为 bg。

Key insight: 图例建立了"信号灯→路径颜色"的间接映射，解题者必须先破译图例的编码方式（第一层），再利用信号灯在路口处进行路径选择和接续（第二层），最后判断哪些段被保留、哪些被移除（第三层）。
