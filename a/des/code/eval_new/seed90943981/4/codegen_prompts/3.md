Input structure:
- bg = Black。网格由Blue像素构成的墙壁划分成若干个封闭"房间"（4-连通的Black区域，被Blue墙壁完全包围）。每个房间是矩形的。

- 同一种颜色的门可能出现多次，连接不同的房间对。
- 有些房间没有任何门（完全封闭），有些房间可能有多扇不同颜色的门。

Rule:

Key insight: 解题者需要先发现门的颜色定义了连通等价类（而非简单的相邻关系），再发现多分组冲突时的稀有色优先规则，两层归纳各自都不显然。
