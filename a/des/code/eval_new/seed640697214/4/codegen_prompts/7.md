  - 每个图案的某些像素被 maroon 色覆盖（"遮挡"）。左图案和右图案被遮挡的位置互补——即左图案中被 maroon 遮挡的像素，在右图案的镜像对应位置一定是可见的，反之亦然。
  - 两个图案之间的间隔区域中有一条水平的单像素宽彩色线段（"桥接线"），颜色为非背景色且非 maroon 的某种颜色。

  - 第一步：识别左右两个镜像图案，以及各自被 maroon 遮挡的区域。

  - 第三步：还原完成后，检查所有刚被还原的像素（原来是 maroon 的位置）：如果还原后的颜色恰好与桥接线的颜色相同，则将该像素改为 grey；否则保持还原色不变。

- `Key insight`：解题者首先需要发现左右图案的镜像关系，然后发现 maroon 是遮挡标记而非图案本色，利用互补原理从对侧镜像位置还原。最后需要发现桥接线颜色的隐蔽作用——它标识出还原像素中与之同色的部分并进行二次变换为 grey。桥接线既充当视觉分隔又充当规则参数，这一双重角色是核心隐蔽点。

1. `main(grid)` 必须实现新题描述中的确定性转换规则，不能只识别 `generate_input()` 的固定模板。
2. `generate_input()` 必须随机生成多样样例，不能固定死。随机维度应覆盖：网格大小、对象数量、位置、颜色、方向、形状参数或关键分支。
3. 生成器必须保证输入满足 `main()` 的隐式假设：对象不重叠、不越界、特殊标记唯一或可区分、匹配关系无歧义、关键分支出现概率相同。
4. 禁止把 ARC 颜色 id 、亮度、拼写等当作人类不可见的数值语义参与排序、大小比较或隐藏映射。颜色变化必须有可见结构线索。注意颜色亮度、拼写等也是不可见信息，若描述中出现违规的颜色id或者亮度，可自行使用少量的固定颜色替代，但注意生成时要在三个以内输入输出网格中对所有变换100%覆盖度。
