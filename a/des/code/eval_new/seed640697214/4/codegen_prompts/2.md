- `description`：沿着彩色路径传播信号，在路径交叉口根据交汇颜色的混合规则决定新颜色并继续传播。

- `Input structure`：
  - bg = 最常见颜色（black）。
  - 网格中有若干条单像素宽的正交路径（水平或垂直线段），每条路径由单一颜色绘制（可用颜色为 red、blue、yellow）。
  - 路径之间存在交叉点：两条不同颜色的路径在某个像素处重叠，该像素显示为其中一种颜色。
  - 每条路径的一端有一个 2x1 或 1x2 的同色方块作为"信号源"标记，标记位于路径端点处，信号从标记端沿路径向另一端传播。

- `Rule`：
  - 信号从每个路径的信号源端出发，沿路径方向传播，将路径上的像素保持原色不变。
  - 当信号到达一个交叉点时，两条路径的颜色发生"混合"：red + blue = magenta，red + yellow = orange，blue + yellow = green。
  - 从交叉点开始，信号继续沿两条路径的非来源方向传播，但传播出去的像素颜色变为混合后的新颜色，覆盖原有路径颜色。
  - 如果混合后的信号再次遇到另一个交叉点，则停止传播——该交叉点像素保持为已有颜色不变。
  - 没有信号到达的路径段保持原色不变。

- `Key insight`：解题者需要三层推理：（1）识别信号源标记（路径端点的加粗方块）确定传播起点和方向；（2）发现交叉口的颜色混合规则——三原色两两混合产生二次色；（3）理解混合信号的传播范围限制——遇到下一个交叉口即停止。每一层都需要从样例中主动归纳。
