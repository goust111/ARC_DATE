- 每个矩形边框的四条边上被涂上了不同片段的颜色——即边框并非纯单色，而是四条边各自由若干连续同色段组成（至少两种颜色交替出现在边框上）。角点像素同时属于两条边，其颜色以水平边为准。
- 每个矩形内部除背景色外，恰好有一个由两个像素组成的"指针"：两个像素 4-连通相邻，颜色相同且不同于背景色和边框上的任何颜色。指针的朝向由两个像素的相对位置决定——水平排列时指向从列号小的像素到列号大的像素的方向（即向右），竖直排列时指向从行号小的像素到行号大的像素的方向（即向下）。注意：向右表示采样右边，向下表示采样底边，以此类推需要通过样例归纳出指针朝向与边的完整映射。

Rule:
- 第一层：识别每个矩形框及其内部的指针，确定指针的朝向（上/下/左/右四种情况之一，实际由两像素的排列唯一确定方向：向右、向下各一种；若要表示向左或向上，则两像素顺序反转，即列号大的在前或行号大的在前——但更简洁的规则是：指针方向就是从第一个像素指向第二个像素的方向，其中"第一个"定义为行号较小者，行号相同则列号较小者）。

- 第三层：用读取到的颜色序列作为重复条纹图案铺满矩形内部。若指针指向上或下（即采样水平边），则内部每一行的颜色按列依次循环使用该序列；若指针指向左或右（即采样竖直边），则内部每一列的颜色按行依次循环使用该序列。指针自身的像素也被条纹覆盖。

Key insight: 指针的朝向同时决定"从哪条边采样"和"沿哪个轴铺设条纹"——解题者需要先识别指针结构并归纳朝向规则，再建立朝向与边框边的对应关系，最后理解条纹的铺设方式是沿采样边的平行方向逐行或逐列重复。
