在网格中，每个彩色"信号塔"向四个正方向发射射线，射线在遇到"镜面"对象时发生 90 度反射并变色，最终射线路径及颜色构成输出。

Input structure:
- bg = black。网格中有若干单像素的"信号塔"，每个信号塔有不同颜色（如 red、blue、green、yellow 等）。
- 网格中还有若干由 grey 像素组成的短线段（长度 2-4 像素），这些线段要么是水平的，要么是垂直的，充当"镜面"。
- 水平镜面将垂直方向的射线反射为水平方向，垂直镜面将水平方向的射线反射为垂直方向。镜面本身在输出中保留。

Rule:
- 第一步：每个信号塔从其位置向上、下、左、右四个方向各发射一条射线，射线颜色与信号塔颜色相同。
- 第二步：射线沿直线传播，逐像素延伸，将经过的 bg 像素染为射线当前颜色。射线遇到以下情况停止或改变：
  - 遇到网格边界：停止。
  - 遇到另一个信号塔：停止（不覆盖信号塔）。
  - 遇到镜面的侧面（即射线行进方向垂直于镜面朝向）：射线在镜面前一格停止，然后从镜面的对应端点沿反射方向继续传播。反射后射线颜色变为 orange。
  - 遇到已被染色的像素：停止（先到先得）。
- 第三步：所有信号塔同时发射，按照距信号塔的步数逐格同步扩展。当两条射线同一步到达同一像素时，该像素染为 maroon。

Key insight: 解题者首先需要识别信号塔和镜面的角色区分，然后理解镜面的反射机制（方向转 90 度且变色为 orange），最后发现同步扩展的冲突规则（同时到达变 maroon）。三层规则递进隐藏，仅从样例的射线路径和颜色变化中可以逐步归纳。
</new_puzzle>
