根据"种子图案"在分区网格中进行元胞自动机式的单步扩散，每个区域的扩散规则由其邻域中已填色区域的数量决定。

Input structure:
- bg = black。网格被单像素宽的 grey 线分割成规则的 N×M 个矩形区域（cell），形成棋盘状布局。
- 少数区域内填有纯色图案（如一个小十字、小 L 形或小方块），这些是"种子区域"。其余区域为空（全 bg）。
- 每个种子区域内的图案颜色各不相同，图案形状也可能不同。

Rule:
- 第一步：识别每个种子区域的图案形状（在区域内的相对位置和占据的像素集合）。
- 第二步：对每个空区域，数其四邻域（上下左右，不含对角）中有多少个区域是非空的（包含种子或已被填充的区域）。该计数 k 决定此空区域是否被填充以及如何填充：
  - k = 0：保持为空。
  - k = 1：将唯一邻居的图案原样复制到此区域（保持图案在区域内的相对位置不变），颜色也相同。
  - k >= 2：将多个邻居中面积最大的那个图案复制到此区域，但颜色改为 red。
- 第三步：此扩散只执行一步——即只有与原始种子直接相邻的空区域会被填充，不进行迭代。

Key insight: 解题者需要先发现网格的分区结构和种子位置，然后归纳出"邻居计数决定填充策略"这一非显然规则——单邻居时忠实复制，多邻居时发生颜色突变并选择面积最大者，这两层判断构成递进的推理结构。
