Input structure:
- bg = black。网格中有若干由 grey 像素围成的封闭矩形区域（灰色边框厚 1 像素），区域大小不等（内部空间从 3x3 到 6x6 不等）。
- 每个封闭区域内部有 1-5 个 green 像素（锚点），它们排列在同一行或同一列上，形成一条水平或垂直的短线段。
- 网格边缘处（紧贴网格的上、下、左或右边界）有若干条彩色色带，每条色带为连续的单色像素行或列（颜色各不相同，如 red、blue、orange、yellow 等），长度不等。

Rule:
- 对每个封闭区域，数出其中 green 锚点的数量 N。
- 在边缘色带中找到长度恰好等于 N 的那条色带，确定其颜色 C。
- 观察区域内锚点的排列方向：若锚点排成水平线，则从锚点所在行的左侧边框内壁开始，向右绘制 N 个颜色为 C 的像素；若排成垂直线，则从锚点所在列的上侧边框内壁开始，向下绘制 N 个颜色为 C 的像素。
- 绘制的 C 色像素覆盖锚点（green 消失）。
- 边缘色带在输出中被擦除（变为 bg）。

Key insight: 锚点同时编码了两个信息——数量决定从哪条色带取色（长度匹配），排列方向决定填充的朝向。解题者需要先发现数量-长度的配对关系，再发现方向由锚点阵列的几何朝向决定，而非由色带位置决定。
