Rule:
- 第一层推理——匹配：每个边框通过缺口方向与钥匙的标记点方位进行匹配。具体地，若边框的缺口在其上边，则寻找标记点位于钥匙上方的那个钥匙，且标记点颜色必须与该边框颜色相同。
- 第二层推理——填充：找到匹配的钥匙后，将钥匙的 3x3 图案按缺口方向旋转后，平铺（tile）到边框内部的 5x5 区域中（左上角对齐，超出部分裁剪），用钥匙图案自身的颜色绘制（非 black 像素覆盖，black 像素保持不变）。旋转规则：缺口在上 → 不旋转；缺口在右 → 顺时针 90°；缺口在下 → 180°；缺口在左 → 逆时针 90°。

Key insight: 缺口方向同时编码两个信息——它既是查找钥匙的索引键（通过标记点方位匹配），又决定了钥匙图案在填充时的旋转角度。解题者需要先发现"缺口方向 = 标记点方位"的对应关系，再发现填充时还需要按缺口方向旋转钥匙图案。
