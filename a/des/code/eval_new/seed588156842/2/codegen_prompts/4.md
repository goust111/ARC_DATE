Input structure:
- 背景色为 black。网格中有若干彩色矩形图形（实心填充，颜色各不相同，如 red、blue、green、yellow、orange），这些矩形在空间上互不重叠。
- 网格的最底行（或最右列）有一排单像素的彩色标记，颜色与上述矩形一一对应，标记从左到右（或从上到下）排成一行。

Rule:
- 第一步：读取底行标记的颜色顺序，这定义了矩形的叠放优先级——左边的标记对应的矩形放在最底层，右边的放在最顶层。
