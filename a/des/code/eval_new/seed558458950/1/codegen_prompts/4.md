Input structure:
- bg = black。网格中有若干由 grey 线条围成的封闭区域（不规则多边形），区域内部为 bg。

- 网格的一侧（如最底部几行）有一排小的正方形纹理样本框，每个样本框由 grey 边框包围，内部是一个 2×2 或 3×3 的重复纹理图案。每个纹理样本框的左上角有一个与种子颜色对应的单像素颜色标签。

Rule:
- 对每个封闭区域，读取其内部种子像素的颜色。

Key insight: 种子颜色是查找纹理的键，而种子位置决定了纹理平铺的相位对齐——相同纹理在不同区域中因种子位置不同而呈现不同的平铺偏移，这要求解题者同时理解"颜色匹配"和"位置锚定"两层机制。
