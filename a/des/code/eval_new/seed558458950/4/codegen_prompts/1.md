- `Rule`：
  - 对于每个框架，找到其边缘上的种子像素，记录种子的颜色 C。

  - 根据种子在框架哪条边上，确定生长方向：种子在上边 → 图案从上向下生长（图案顶部对齐种子列位置）；种子在下边 → 图案从下向上生长（图案底部对齐种子列位置）；种子在左边 → 图案从左向右生长（图案左侧对齐种子行位置）；种子在右边 → 图案从右向左生长（图案右侧对齐种子行位置）。

  - 框架本身和图例区域在输出中保持不变。

- `Key insight`：种子像素同时编码了两层信息——其颜色决定要绘制哪个图例形状，其在框架边缘的位置决定图案的生长方向和旋转方式。解题者需先通过颜色匹配找到对应图例，再通过种子位置推断放置规则。
