Input structure:
- 背景色为 black。
- 网格的四条边上各有若干彩色像素点作为"端口"，每个端口有一种非背景颜色。

- 网格内部完全为 black 背景，没有其他元素。

Rule:
- 每对同色端口之间用直角折线路径连接：路径从一个端口出发，沿该端口所在边的垂直方向向内延伸，然后转弯（仅一次直角转弯），再沿另一端口所在边的垂直方向到达第二个端口。路径宽度为 1 像素。
- 如果两个端口在相对的两条边上且处于同一行或同一列，则路径为一条直线，无需转弯。
- 每条路径用其对应的端口颜色绘制。
- 当两条路径在某个像素位置交叉时，该像素使用网格中存在的、既不属于这两条交叉路径颜色的第三种端口颜色来绘制。如果网格中只有两种端口颜色，则交叉点用 grey 绘制。
- 如果三条或更多路径交叉于同一点，该像素用 grey 绘制。

Key insight:
路径的走法本身是确定的（由端口位置和直角折线规则唯一确定），但真正的推理难度在于交叉点的颜色混合规则：解题者需要先理解路径的生成方式，然后发现交叉点颜色并非简单覆盖，而是遵循一种"互补选择"机制——交叉点取场上第三种颜色。这两层规则需要分别从样例中归纳。
