- `Input structure`：
  - bg = black 背景。
  - 网格中有若干彩色闭合环形区域，每个环由单一颜色构成，形状为实心矩形去除内部矩形后剩余的"回"字形边框（可以是一层厚度为 1 的框，也可以是厚度 2 或 3 的多层嵌套框）。不同的环颜色不同，彼此不接触。
  - 每个环的空心内部（black 区域）中散布着若干 red 小标记像素（单像素点）。不同的环内部有不同数量的 red 标记（0-3 个）。
  - 环外部（背景上）没有 red 标记。

- `Rule`：
  - 第一步——计数：对每个环，数出其内部空心区域中 red 标记像素的数量 N。
  - 第二步——收缩：将该环"向外剥离" N 层。具体操作：每一层剥离是指移除环中所有与 black 背景四连通相邻的像素（即环的最外层像素），将它们变为 black。重复此剥离操作 N 次。
  - 第三步——清理：移除所有 red 标记像素（变为 black）。
  - 若 N = 0，环保持不变（仅移除标记）。若 N 大于等于环的总厚度，环被完全擦除。
  - 输出网格仅包含收缩后剩余的环像素和 black 背景。

- `Key insight`：环的初始厚度是一个视觉陷阱——解题者可能以为厚环和薄环的差异本身就是规则，但实际上控制变量是内部标记数量。解题者需要先发现"标记数量 = 剥离层数"这一隐含映射，再理解"逐层剥离"的具体几何含义（从外侧向内侧腐蚀，类似形态学腐蚀操作）。两步推理分别是：发现计数-剥离的对应关系，以及正确模拟由外向内的逐层剥离过程。
