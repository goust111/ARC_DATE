- `Input structure`：
  - 背景为 black。网格被 grey 色的单像素宽分隔线划分为 N×M 个大小相同的矩形区域（类似表格）。
  - 每个区域内包含两类元素：
    1. 一个"指针"——由 maroon 色像素组成的箭头形状，箭头由 3 个像素构成：一个像素作为箭尾，相邻的一个像素作为箭身，再沿同方向相邻的一个像素作为箭头。箭头方向指向上/下/左/右四个方向之一。
    2. 零个或多个"载荷像素"——非 black、非 grey、非 maroon 的彩色像素，散布在区域内。

- `Rule`：
  - 第一步——确定传递链：每个区域的指针指向一个相邻区域（上/下/左/右）。如果指针指向网格外部（边缘区域指向边界外），则该区域为"终端区域"，不向外传递。
  - 第二步——收集载荷：每个区域收集自身的载荷像素，以及所有通过传递链最终指向本区域的其他区域的载荷像素。传递链可以多级串联（A 指向 B，B 指向 C，则 A 的载荷最终传递到 C）。
  - 第三步——输出绘制：输出网格去掉所有分隔线和指针。每个区域保持原始大小，其中显示该区域最终收集到的所有载荷像素。收集来的外部载荷像素按原始相对位置（相对于来源区域左上角的偏移）放置到目标区域中。若多个像素落在同一位置，保留颜色编号更大的那个（即后来叠加的覆盖先前的，使用颜色在调色板中的顺序：black < blue < red < green < yellow < grey < magenta < orange < azure < maroon）。

- `Key insight`：解题者需要先从箭头方向构建出完整的区域间传递链（可能形成多级串联），再理解载荷像素如何以相对坐标叠加到最终目标区域中——指针网络的全局拓扑而非单个箭头的局部方向才是关键。
