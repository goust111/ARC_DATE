description: 用框架颜色内部的孔洞数量，在颜色图例中查找对应色彩，然后用该色彩填充框架内部。

Input structure:
- 背景为黑色。
- 网格左侧或右侧有一列纵向排列的单像素颜色图例，从上到下依次编号为 1、2、3…（编号隐含在位置中，不显示在网格上）。
- 网格中散布着若干个由同一前景色（如蓝色）绘制的矩形空心框架（边框宽度 1 像素）。
- 每个框架的边框上有若干个 1 像素的缺口（即边框上被背景色替代的像素），缺口数量在 1 到图例颜色总数之间。

Rule:
- 对每个空心框架，数其边框上的缺口数量 N。
- 在颜色图例中找到第 N 个颜色（从上到下第 N 个图例像素的颜色）。
- 用该颜色填充框架内部的所有背景像素（框架边框本身保持原色不变，缺口也保持为背景色）。

Key insight: 框架边框上的缺口不是损坏，而是一种编码——缺口数量是查询颜色图例的索引键，图例的空间顺序提供了数量到颜色的映射。
</new_puzzle>

<new_puzzle>
description: 将散落的彩色碎片按颜色配对后拼合成完整矩形，再按矩形面积从大到小堆叠排列到输出网格中。

Input structure:
- 背景为黑色。
- 网格中有若干个不规则的彩色前景对象（4-连通），每种颜色恰好出现两个对象。
- 同色的两个对象互为互补形状：将它们在各自 bounding box 内的像素取并集后，恰好填满一个与两者 bounding box 同尺寸的实心矩形（即一个对象的非像素位置恰好是另一个对象的像素位置）。

Rule:
- 识别每种颜色的两个对象，将它们按 bounding box 对齐合并，得到一个该颜色的实心矩形。
- 按矩形面积从大到小排序。
- 在一个新的背景画布上，从左上角开始，逐行紧密排列这些实心矩形：每个矩形的左边缘紧贴前一个矩形的右边缘（间隔 1 列背景），若当前行宽度不够则换到下一行（顶部紧贴上方最高矩形的底边再空 1 行）。

Key insight: 碎片的不规则形状具有欺骗性——解题的第一层推理是发现同色碎片互补拼合为矩形，第二层推理是发现矩形按面积降序排列到输出中。
</new_puzzle>

<new_puzzle>
description: 每个封闭区域内的唯一标记像素决定该区域的填充颜色，而区域的边界形状决定填充方向（从标记像素向外扩散到仅占据区域的某一半）。

Input structure:
- 背景为黑色。
- 一种前景色（如灰色）绘制若干封闭的矩形边框（边框宽度 1 像素、无缺口），各矩形不重叠。
- 每个矩形的边框内部恰好有一个非背景、非边框色的单像素标记，颜色各异。
- 每个矩形要么宽大于高（横向矩形），要么高大于宽（纵向矩形）；不出现正方形。

Rule:
- 对每个封闭矩形，找到其内部的标记像素。
- 若矩形为横向（宽 > 高）：以标记像素所在列为分割线，将标记所在那一侧（左半或右半）的所有内部背景像素填充为标记颜色。
- 若矩形为纵向（高 > 宽）：以标记像素所在行为分割线，将标记所在那一侧（上半或下半）的所有内部背景像素填充为标记颜色。
- 标记像素本身也包含在填充区域内。边框保持不变。

Key insight: 矩形的长轴方向决定了分割轴（横向矩形左右分割，纵向矩形上下分割），而标记像素的位置决定了填充哪一半——两条独立的规则需要分别归纳。
</new_puzzle>

<new_puzzle>
description: 根据箭头对象指向的方向，将箭头路径上遇到的第一个彩色方块"推"到该方向上的边界墙壁，然后箭头本身消失。

Input structure:
- 背景为黑色。
- 一种前景色（如灰色）在网格边缘和内部绘制了若干 1 像素宽的直线墙壁段（水平或垂直），这些墙壁把网格分隔成不规则的房间。
- 网格中有若干个由不同颜色构成的 1x1 彩色方块（每个方块是一个像素）。
- 网格中有若干个由红色像素绘制的箭头对象。每个箭头由 5 个像素组成：3 个像素排成一条直线构成箭杆，在箭杆前端的一侧各延伸 1 个像素构成箭头尖端（形成 > < ^ v 四种朝向之一）。每个箭头指向上、下、左、右中的某一个方向。

Rule:
- 对每个箭头，沿其指向方向发射一条射线。
- 射线遇到的第一个彩色方块被选中。
- 将该方块沿箭头方向移动，直到它紧贴该方向上最近的墙壁像素或网格边界（方块的最终位置紧邻墙壁）。
- 箭头自身从输出中删除（变为背景色）。
- 若射线在遇到彩色方块之前先遇到墙壁或网格边界，则该箭头无效果。
- 墙壁和未被箭头选中的方块保持不变。

Key insight: 箭头不是装饰而是操作指令——需要先从箭头的像素形状推断朝向，再沿该方向追踪找到操作对象，最后结合墙壁布局确定终点位置。三步推理链中，箭头朝向识别和墙壁阻挡终点计算是两个独立的非显然子任务。
</new_puzzle>

description: 在周期性条纹背景中，前景对象的轮廓被"印"到条纹上——条纹颜色在对象内部区域反转。

Input structure:
- 网格由交替的两种颜色（如蓝色和绿色）的水平条纹构成，每条宽 1 行，覆盖整个网格。
- 网格中有若干个由另一种颜色（如红色）绘制的 4-连通前景对象，它们叠在条纹之上。

Rule:
- 移除所有红色前景对象像素（恢复为背景条纹）。
- 对于曾被前景对象覆盖的每个像素位置：将该位置本应显示的条纹颜色替换为另一种条纹颜色（蓝变绿、绿变蓝）。
- 其余未被覆盖的条纹区域保持不变。

Key insight: 输出中没有前景对象的原始颜色——对象的形状通过条纹颜色的局部反转来隐式编码，解题者需要发现"对象区域内条纹互换"这一非显然的视觉规律，而不是简单的颜色替换或删除。
</new_puzzle>

description: 将网格中每个 L 形三连块旋转到与其最近角落方向一致的朝向，然后沿对角线滑动到该角落。

Input structure:
- 背景为黑色。
- 网格中散布若干个不同颜色的 L 形三连块（每个占据 2x2 区域中的 3 个像素，缺少一个角）。
- 每个 L 形三连块的颜色唯一（在网格中只出现一次）。
- 网格是正方形。

Rule:
- 对每个 L 形三连块，确定其中心（bounding box 中心）距网格四个角中哪个最近。
- 将该 L 形三连块旋转（0度、90度、180度、270度），使其缺失角朝向该最近角落的方向（即 L 的开口朝向角落）。
- 然后将旋转后的三连块沿对角线方向移动，直到其 bounding box 的某条边紧贴网格边界。
- 所有三连块移动后，若两个三连块发生重叠，则距角落更远的那个（原始位置距角落更远）保持在重叠位置上层（输出中显示上层颜色）。

Key insight: 最近角落同时决定了两件事——旋转朝向和移动方向。解题者需要先发现旋转规则（L 的开口指向角落），再发现移动规则（沿对角线滑向角落），两层规则共享同一个隐含参数（最近角落），这增加了归纳难度。
</new_puzzle>

<new_puzzle>
description: 网格中的彩色种子像素沿其所在通道生长为矩形色带，生长长度等于同色种子在整个网格中的出现次数。

Input structure:
- 背景为黑色。
- 一种前景色（如灰色）绘制了若干条 1 像素宽的水平或垂直通道（直线段），通道之间可以交叉形成网格状结构。
- 通道上零星分布着不同颜色的单像素种子点，种子点覆盖在通道之上。同一颜色可能出现多个种子点。

Rule:
- 统计每种种子颜色在网格中出现的总次数 N。
- 对每个种子像素，沿它所在通道的方向（若在水平通道上则向右生长，若在垂直通道上则向下生长，若在交叉点则向右优先），将种子像素扩展为长度 N 的连续色带（包含种子自身位置）。
- 色带仅覆盖通道像素，不覆盖背景。若色带在到达长度 N 之前遇到通道末端，则在末端停止（不换方向）。
- 色带之间若发生重叠，后处理的颜色（按颜色出现次数从少到多的顺序处理）覆盖先前的颜色。

Key insight: 第一层推理是发现种子颜色的计数决定生长长度（同色种子越多，色带越长），第二层推理是发现生长方向由通道几何结构决定而非由种子自身属性决定。
</new_puzzle>

<new_puzzle>
description: 根据每对同色标记像素之间围成的矩形区域内的背景像素数量，选择对应的填充图案来填充该区域。

Input structure:
- 背景为黑色。
- 网格底部有一行图案样本区：从左到右排列着若干个小的矩形图案（每个图案由独特的非背景颜色绘制，宽度相同，高度相同，图案之间用 1 列背景分隔）。图案样本按从左到右的顺序隐含编号 1、2、3…。
- 网格上方区域散布着若干对同色标记像素。每种标记颜色恰好出现两个像素，这两个像素分别位于某个隐含矩形区域的对角（左上角和右下角）。

Rule:
- 对每对同色标记像素，确定它们定义的矩形区域。
- 统计该矩形区域内（不含标记像素本身）的背景像素数量 M。
- 在图案样本区中找到第 M 个图案（编号从 1 开始）。
- 将该图案以平铺方式填充到矩形区域内（标记像素保持不变，图案从矩形左上角开始铺设，超出矩形部分裁剪）。
- 图案样本区在输出中保持不变。

Key insight: 标记像素的颜色只用于配对（确定哪两个像素定义同一矩形），真正决定填充图案的是矩形内部的空像素数量——这个"面积即索引"的映射是核心隐蔽机制。
</new_puzzle>
