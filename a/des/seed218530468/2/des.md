<new_puzzle>
<description>
根据框架内部的彩色种子像素，沿框架缺口方向向外生长出与种子颜色对应的树状分支，分支的形态由框架的形状决定。

Input structure:
- 背景为黑色（black）。
- 网格中散布若干用同一种颜色（如 blue）绘制的矩形空心框架，每个框架恰好在一条边上有一个单像素宽的缺口。
- 每个框架内部有一个或多个彩色种子像素（非框架色、非背景色），颜色各不相同。
- 框架外部、缺口正对方向上有一排等距的灰色（grey）节点像素，节点数量等于框架内种子像素的数量。

Rule:
- 第一层：识别每个框架的缺口位置和缺口朝向（上/下/左/右）。
- 第二层：将框架内的种子像素按照它们与缺口的垂直距离排序（离缺口最近的排第一）。排序后的种子依次与缺口外的灰色节点按距离从近到远一一配对。
- 第三层：从每个灰色节点出发，向缺口朝向的垂直方向（即左右或上下）两侧各画一条射线，射线长度等于对应种子像素在框架内到框架最近侧壁的像素距离。射线颜色为对应种子像素的颜色。
- 灰色节点本身也被替换为对应种子的颜色。框架和种子像素保持不变。

Key insight:
框架的缺口决定了生长方向，种子到缺口的距离决定了配对顺序，而种子到侧壁的距离编码了分支的展开宽度——三层信息分别来自框架结构的不同几何属性。
</description>
</new_puzzle>

<new_puzzle>
<description>
在由彩色条纹分隔的多个区域中，根据每个区域内小图案的朝向，将该区域的内容旋转到统一朝向后拼合成一幅完整图像。

Input structure:
- 背景为黑色（black）。
- 网格被若干条单像素宽的红色（red）水平线和红色垂直线分割为大小相同的矩形格子（类似九宫格或更大的网格布局）。
- 每个格子内有一个用多种颜色绘制的小图案（sprite），每个小图案内部恰好有一个箭头标记：箭头由三个同色像素组成，一个像素为箭头尖端，另外两个像素从尖端向同一方向的两侧各偏一格形成箭尾（即"V"字形，开口方向即箭头指向的反方向；箭头指向即尖端相对于两个箭尾像素的方向）。
- 箭头标记的颜色为绿色（green），与图案的其他颜色不同。

Rule:
- 第一层：识别每个格子中绿色箭头的指向（上/下/左/右）。所有格子中有且仅有一个格子的箭头指向上方，该格子的内容无需旋转，作为基准朝向。
- 第二层：对其他每个格子，计算其箭头指向与"上方"之间需要顺时针旋转多少个 90 度才能对齐到上方。将该格子的全部内容（包括箭头）做相应旋转。
- 第三层：旋转完成后，移除所有格子中的绿色箭头像素（恢复为黑色背景），然后将所有格子按照它们在原始网格中的行列位置拼合（去掉红色分隔线），输出最终图像。

Key insight:
红色网格线仅用于分隔，绿色箭头仅用于编码旋转量——两者都不会出现在输出中；解题者必须先识别箭头朝向以推断旋转角度，再拼合才能还原被打散并旋转过的完整图像。
</description>
</new_puzzle>

<new_puzzle>
<description>
将散布在网格中的彩色碎片按颜色归类到由同色边框标记的收纳框中，碎片在框内的放置位置由碎片原始位置相对于收纳框的方位决定。

Input structure:
- 背景为黑色（black）。
- 网格中有若干个矩形空心边框，每个边框用不同的颜色绘制（如 blue、red、green 等），边框内部为黑色背景。每个边框的内部面积至少为 3x3。
- 网格中还散布着若干小型连通碎片（每个碎片由 1 到 4 个同色像素组成的四连通区域），碎片的颜色与某个边框的颜色相同。
- 每个颜色至少有一个边框和一个碎片；同一颜色可能有多个碎片但只有一个边框。
- 碎片不会与任何边框重叠，也不会与其他碎片重叠。

Rule:
- 第一层：将每个碎片按颜色匹配到同色的收纳边框。
- 第二层：确定每个碎片相对于其匹配边框中心的大致方位。方位按四象限判定：碎片质心在边框中心的右上方、右下方、左上方、左下方。对应地，碎片将被放置到边框内部的右上角、右下角、左上角、左下角区域，碎片的形状保持不变，紧贴对应角落。
- 第三层：将碎片从原始位置擦除（恢复为黑色），然后在目标边框内的对应角落绘制该碎片。若同一边框有多个碎片落入同一象限，则按碎片面积从大到小、由角落向内依次紧密排列。
- 边框本身保持不变。

Key insight:
颜色匹配确定"去哪个框"，碎片相对于框的空间方位确定"放在框内哪个角"——解题者需要同时推断匹配规则和方位映射规则，两层推理缺一不可。
</description>
</new_puzzle>

<new_puzzle>
<description>
网格中的彩色环形轨道上分布着不同颜色的珠子，每个轨道根据其内部标记像素的数量决定珠子沿轨道顺时针移动的步数。

Input structure:
- 背景为黑色（black）。
- 网格中有若干个互不重叠的封闭环形轨道。每条轨道由同一种颜色（如 grey）的像素组成，形成一个宽度为 1 像素的封闭环路（矩形环或 L 形环等简单形状，保证环路上每个像素恰好有两个同色四连通邻居，从而形成唯一的循环顺序）。
- 每条轨道的部分像素被替换为其他颜色的"珠子"像素（每颗珠子占一个像素，颜色非轨道色、非背景色）。珠子之间不相邻。
- 每条轨道所围成的内部区域中，有若干个用 maroon 颜色绘制的标记像素（与轨道不接触，仅在轨道围成的内部空间中）。

Rule:
- 第一层：识别每条封闭轨道，并确定其内部区域中 maroon 标记像素的数量 N。
- 第二层：确定每条轨道的循环顺序。循环顺序定义为：从轨道最上一行最左一个像素出发，按顺时针方向遍历轨道上的所有像素。
- 第三层：将轨道上的所有珠子沿顺时针方向移动 N 步（N 为该轨道内部 maroon 标记的数量）。移动后珠子占据的位置变为珠子颜色，珠子离开的位置恢复为轨道颜色。
- maroon 标记像素在输出中保持不变。

Key insight:
内部标记像素的数量编码了该轨道的移动步数——解题者必须先发现"数标记"与"移动距离"的对应关系，再理解环形轨道上的顺时针循环移动机制，两层推理各自都需要从样例中归纳。
</description>

<new_puzzle>
<description>
网格中包含若干对形状相同但颜色不同的图案，每对图案之间用一条"桥"连接；桥的绘制方向由图案的缺口位置决定，桥的填充颜色由两个图案的颜色混合规则决定。

Input structure:
- 背景为黑色（black）。
- 网格中散布着偶数个大小和形状完全相同的小型连通图案（每个图案占 3 到 8 个像素）。
- 这些图案两两配对，每对图案的形状相同（平移后完全重合），但颜色不同。每种形状恰好出现两次。
- 每个图案在其外轮廓上恰好有一个凹陷缺口（即图案的边界框中恰好有一个位置本应属于该图案但缺失了像素），缺口朝向上/下/左/右之一。

Rule:
- 第一层（配对）：通过形状匹配将图案两两配对。两个形状相同的图案为一对。
- 第二层（定色）：每对图案有两种颜色。在输入网格中出现的所有颜色按以下固定优先级排列：red > blue > green > yellow > orange > magenta > azure > maroon > grey。每对中优先级较高的颜色作为桥的填充色。
- 第三层（画桥）：从每个图案的缺口位置出发，沿缺口朝向画一条直线（单像素宽），两条直线在交汇点以直角相连形成一条 L 形桥（若两个缺口方向正好相对且在同一行/列上则为一条直线段）。桥的颜色为第二层确定的颜色。若桥的路径经过其他图案或其他桥，则该桥在碰到障碍前停止（不会发生这种情况，因为题目保证路径畅通）。
- 图案本身保持不变。

Key insight:
形状匹配确定哪两个图案是一对，颜色优先级规则确定桥的颜色，缺口位置和朝向确定桥的路径——三层规则分别涉及形状识别、颜色排序、空间路径，需要从样例中逐层剥离和归纳。
</description>

<new_puzzle>
<description>
网格被分为左右两半，左半部分包含一个由多层嵌套矩形框构成的"解码器"，右半部分包含一个由彩色像素组成的密文图案；用解码器中每层框的颜色作为从外到内的逐层替换映射，对密文图案进行颜色替换。

Input structure:
- 背景为黑色（black）。
- 网格的左半部分包含若干个同心嵌套的矩形空心框（每个框一像素宽），从外到内每层框的颜色不同。所有框共享同一中心。嵌套层数为 2 到 4 层。最内层框的内部为黑色。
- 网格的右半部分包含一个小型矩形区域，内部由若干种颜色的像素组成密文图案，这些颜色与嵌套框的颜色有部分重叠。

Rule:
- 第一层：识别左侧嵌套框从最外层到最内层的颜色序列，记为 C1, C2, C3, ...（从外到内）。
- 第二层：构建替换映射。映射规则为：C1 → C2, C2 → C3, C3 → C4, ... 最内层颜色 Cn → C1（形成一个循环）。
- 第三层：对右侧密文图案中的每个像素，若其颜色出现在映射中，则替换为映射后的颜色；若不在映射中（如黑色背景），保持不变。
- 输出仅包含右侧密文图案区域（裁剪输出），左侧解码器不出现在输出中。

Key insight:
嵌套框的空间层次（从外到内）编码了颜色循环替换的顺序——解题者需要先识别嵌套层序，再将其解读为颜色映射规则，最后应用于密文图案。嵌套结构的视觉深度直接转化为替换链的逻辑深度。
</description>
</new_puzzle>

<new_puzzle>
<description>
网格中有若干个彩色"信号塔"和若干个灰色"接收器"方块，每个信号塔向四个正方向发射信号射线，射线遇到接收器后将其染为信号塔的颜色；但当两个不同信号塔的射线同时到达一个接收器时，该接收器被染为这两个信号塔颜色在网格中出现的第三种特殊混合色。

Input structure:
- 背景为黑色（black）。
- 网格中有若干个"信号塔"：每个信号塔是一个 2x2 的同色方块，颜色各不相同（如 red、blue、green 等）。
- 网格中有若干个"接收器"：每个接收器是一个 1x1 的灰色（grey）像素。
- 网格中还有若干个 1x1 的"混合色样本"像素，每个样本恰好位于两个不同颜色信号塔之间的同一行或同一列上，且样本的颜色既非两个信号塔的颜色，也非灰色或黑色。每对信号塔颜色组合最多对应一个混合色样本。

Rule:
- 第一层：识别所有信号塔（2x2 同色方块）和它们的颜色。识别所有灰色接收器。
- 第二层：每个信号塔从其四条边的中心位置（2x2 方块的每条边中间两个像素各自）向外发射水平或垂直射线。射线在碰到信号塔、网格边缘或非黑非灰像素时停止。记录每条射线经过的灰色接收器。
- 第三层：对于只被一个信号塔射线覆盖的接收器，将其染为该信号塔的颜色。对于被两个不同信号塔射线同时覆盖的接收器，找到网格中这两种颜色对应的混合色样本，将接收器染为该样本的颜色。未被任何射线覆盖的接收器保持灰色。
- 信号塔、混合色样本像素和背景保持不变。

Key insight:
解题者需要先理解射线传播机制，再发现混合色样本充当了"双色叠加查找表"——网格本身就编码了颜色混合规则，而非依赖外部知识。三层推理分别对应信号源识别、射线传播、颜色叠加查表。
</description>
</new_puzzle>
