<new_puzzle>
description: 根据每个封闭区域内散落标记像素的颜色，从该区域的"缺口边"向内生长出对应颜色的填充条，填充条长度等于该区域内标记像素的数量。

Input structure:
- 背景为 black。
- 网格中有若干由 grey 像素绘制的矩形框，每个矩形框的四条边中恰好有一条边存在一个单像素宽的缺口（缺口处为 black 背景）。
- 每个矩形框内部散落着若干同色的非 black、非 grey 标记像素（如 red、blue、green 等），不同框内标记颜色互不相同。
- 矩形框外部无前景像素。

Rule:
- 对每个矩形框，首先找到其缺口所在的边及缺口位置。
- 数出框内标记像素的个数 N（N 不超过框在缺口对边方向上的内部长度）。
- 从缺口对面的那条边开始，沿缺口方向（即朝向缺口的方向）生长一条宽度为 1 像素的填充条，长度为 N 个像素，颜色为框内标记像素的颜色。填充条的列（或行）位置与缺口对齐。
- 清除框内原有的散落标记像素（变为 black），保留 grey 框体和缺口不变。

Key insight:
缺口不仅指示了填充条的生长方向和对齐列，还隐含了"从对面起笔"的起点规则；标记像素的角色不是位置线索而是纯粹的计数器。解题者需要同时归纳出三个非显然关联：缺口边 -> 生长方向、缺口位置 -> 填充列、标记数量 -> 填充长度。
</new_puzzle>

<new_puzzle>
description: 网格被分割线划分为若干矩形房间，每个房间内有一个彩色种子图案；根据房间之间共享墙壁上的"门洞"位置，将相邻房间的种子图案沿门洞方向投射到当前房间中。

Input structure:
- 背景为 black。
- azure 色的水平和垂直线条将网格划分为若干矩形房间（类似网格地图）。
- 每条分割线上可能有一个单像素宽的缺口（门洞），门洞处为 black。
- 每个房间内有一个由单一非 black、非 azure 颜色绘制的小型图案（3x3 以内），位于房间内的某个角落。

Rule:
- 对每个房间，检查其四面墙壁上是否存在门洞。
- 对于每个门洞，找到门洞对面的相邻房间及其种子图案。
- 将相邻房间的种子图案复制到当前房间中，放置位置为：图案在当前房间内紧贴门洞所在墙壁的一侧，并且图案的中心与门洞在墙壁方向上对齐。
- 如果一个房间有多个门洞，则叠加多个相邻图案；像素冲突时，后叠加的（按照从上到下、从左到右的门洞顺序）覆盖先叠加的。
- 每个房间原有的种子图案保持不变。

Key insight:
解题者需要三层推理：第一层是识别分割线上的门洞（缺口）；第二层是建立"门洞连接哪两个房间"的拓扑关系；第三层是理解投射方向——图案不是从自己房间通过门洞"走出去"，而是从邻居房间通过门洞"走进来"，即门洞是"导入口"而非"导出口"。
</new_puzzle>

<new_puzzle>
description: 网格中若干彩色条带沿不同方向排列，每个条带内部有一个"空洞"像素；根据空洞在条带中的相对位置，决定该条带向哪个方向平移以及平移多远。

Input structure:
- 背景为 black。
- 网格中有若干互不重叠的彩色条带，每个条带为单一颜色的水平或垂直连续线段，长度为 4-8 像素。
- 每个条带中恰好有一个像素为 black（形成空洞），条带的其余像素为该条带的颜色。
- 条带之间保持至少 2 像素的间隔。

Rule:
- 对每个水平条带：空洞将条带分为左段和右段。若左段比右段长，条带向右平移，距离等于左段长度；若右段比左段长，条带向左平移，距离等于右段长度。平移时空洞被填充为条带颜色（条带变完整）。
- 对每个垂直条带：空洞将条带分为上段和下段。若上段比下段长，条带向下平移，距离等于上段长度；若下段比上段长，条带向上平移，距离等于下段长度。平移时空洞同样被填充。
- 即条带总是朝较短段的方向平移，平移距离等于较长段的像素数。
- 条带从原位置擦除（变为 black），在新位置绘制完整的（无空洞的）条带。

Key insight:
空洞不是缺陷而是编码指令的信息载体：它的不对称位置同时编码了平移方向（朝短段侧）和平移距离（长段的长度）。解题者需要发现"空洞偏向哪边"与"条带移向哪边"之间的反向关系——条带远离空洞偏向的一侧，这个反直觉规则是核心隐蔽点。
</new_puzzle>

<new_puzzle>
description: 网格中有若干由不同颜色绘制的开放折线，每条折线的两个端点各带有一个不同颜色的单像素标记；沿折线末段方向从端点向外延伸，延伸颜色由端点标记决定。

Input structure:
- 背景为 black。
- 网格中有若干条互不接触的折线，每条折线由一种"主体颜色"（如 blue、green、orange 等）的像素组成，沿水平和垂直方向折行，每段至少 2 像素长。
- 每条折线恰好有两个端点（仅有一个同色四邻居的像素）。每个端点的四邻域中恰好有一个非同色、非 black 的像素作为"端点标记"，标记颜色不同于主体颜色（如 red、yellow 等）。
- 同一条折线的两个端点标记颜色互不相同。

Rule:
- 对每条折线的每个端点，确定该端点处折线最后一段的行进方向（从倒数第二个像素指向端点的方向）。
- 从端点出发，沿该方向继续逐像素延伸，使用该端点标记的颜色进行绘制，直到到达网格边界或碰到任何非 black 像素为止。
- 延伸完成后，移除所有端点标记像素（恢复为 black），保留折线主体和新生长的彩色延伸线段。

Key insight:
解题者需要两层非显然推理：第一层是识别端点标记与折线主体的从属关系——标记不是折线的一部分，而是"指令附件"，它编码了延伸线段应使用的颜色；第二层是确定延伸方向——方向不由标记位置决定，而由折线自身末端的走向决定，标记仅提供颜色信息。这两层角色分离（标记管颜色、折线管方向）是解题的核心。
</new_puzzle>

description: 网格中有一个大型 grey 参考图案和若干小型彩色"印章"图案；每个印章是参考图案某个局部的旋转副本，找到匹配位置后用印章颜色覆盖该局部区域。

Input structure:
- 背景为 black。
- 网格中央偏左有一个较大的由 grey 像素组成的连通图案（参考图案），形状不规则但轮廓清晰。
- 网格右侧和下方散布着若干小型彩色图案（印章），每个印章由单一非 black、非 grey 颜色绘制，每个印章的外接矩形不超过 5x5。
- 每个印章的形状恰好与参考图案中某个同尺寸子区域在旋转 0 度、90 度、180 度或 270 度后完全匹配（匹配时要求子区域的外接矩形内 grey 像素与 black 像素的位置分布都完全一致）。

Rule:
- 对每个印章，尝试四种旋转角度，在参考图案中找到唯一一个匹配的子区域。
- 在参考图案中将该子区域内的 grey 像素全部替换为印章的颜色。
- 印章按外接矩形面积从大到小依次处理；面积相同时按颜色在网格中出现位置从上到下、从左到右排序。重叠时后处理的覆盖先处理的。
- 输出中移除所有原始印章位置的像素（变为 black），只保留被着色后的参考图案。

Key insight:
解题者需要在包含旋转变换的条件下进行形状匹配——不能直接平移对比，必须尝试四种旋转才能找到正确的匹配位置。参考图案的不规则形状保证了每个印章的匹配位置和旋转角度唯一，而旋转的引入使得单纯的视觉扫描不够，需要心理旋转能力与局部形状辨别能力的结合。
</new_puzzle>

description: 网格上半部有一组彩色"钥匙"图案，下半部有若干带有彩色边框的 black 矩形"锁孔"；用钥匙颜色匹配锁孔边框颜色，将钥匙图案缩放后填入对应锁孔的内部空间。

Input structure:
- 背景为 black。
- 网格由一条 grey 水平分割线分为上下两部分。
- 上半部包含若干小型彩色图案（钥匙），每个钥匙由一种颜色绘制，外接矩形为 3x3 或 4x4，各钥匙之间不接触。
- 下半部包含若干矩形区域，每个矩形的边框由某种颜色绘制（与某个钥匙颜色相同），边框宽度为 1 像素，内部为 black。不同矩形的边框颜色互不相同，每种颜色恰好对应上半部的一个钥匙。

Rule:
- 将每个钥匙与下方同颜色边框的矩形配对。
- 测量每个矩形的内部空间尺寸（内部宽 x 内部高）。
- 将钥匙图案在其外接矩形内视为二值模板（有色 = 1，black = 0），按最近邻方式缩放到矩形内部空间的尺寸。
- 用钥匙的颜色将缩放后的模板绘制到矩形内部（模板中值为 1 的像素着色，值为 0 的保持 black）。
- 上半部的钥匙从输出中移除（变为 black），保留 grey 分割线和下半部的彩色边框。

Key insight:
解题者需要两层推理：第一层是通过颜色建立钥匙与锁孔的配对关系；第二层是理解缩放逻辑——钥匙的形状按比例放大以适应不同大小的锁孔内部空间，这要求解题者从样例中归纳出"同一图案在不同尺寸下的视觉对应"而非简单复制。
</new_puzzle>

<new_puzzle>
description: 网格中有若干大小不同的同色矩形，以及一个由多种颜色组成的"调色板条"；根据矩形面积的排名将调色板条中对应位置的颜色赋予每个矩形。

Input structure:
- 背景为 black。
- 网格中散布着若干 grey 的实心矩形，大小各不相同（面积互不相等），位置不重叠。
- 网格最下方一行（或最右方一列）是一个水平（或垂直）的"调色板条"，由 N 个连续的单像素组成，每个像素颜色各不相同（N 等于矩形的数量）。调色板条的像素从左到右（或从上到下）排列。

Rule:
- 将所有 grey 矩形按面积从小到大排序。
- 调色板条中从左到右第 k 个颜色分配给面积排名第 k 的矩形（最小面积的矩形获得调色板第一个颜色，次小的获得第二个颜色，依此类推）。
- 将每个矩形的所有 grey 像素重新着色为分配到的颜色。
- 输出中移除调色板条（变为 black）。

Key insight:
解题者需要识别两个独立编码系统并建立它们之间的映射：矩形的面积排序提供了一个隐含的序号，调色板条的空间顺序提供了另一个序号，两者通过序号对齐。关键隐蔽点在于排序依据是面积（而非位置、周长或其他属性），这需要从样例中通过排除法确认。
</new_puzzle>
