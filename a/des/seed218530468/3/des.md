- `description`：根据小色块在框架边缘的附着位置，将框架内部按象限分割并填充对应颜色。
- `Input structure`：背景为 Black。网格中散布若干由 Grey 像素构成的空心矩形框架（单像素厚度）。每个框架的四条边上分别附着零到若干个单像素彩色标记（颜色取自 Red、Blue、Green、Yellow、Orange），每个标记紧贴在框架边的外侧。
- `Rule`：
  - 对每个框架，找到其水平和垂直中轴线，将内部区域分为四个象限（左上、右上、左下、右下）。
  - 每个彩色标记"属于"它所贴靠的那条边；若标记在中轴线一侧，则它指定与该侧相邻的象限的填充颜色。具体地：顶边标记若在中轴偏左则填充左上象限，偏右则填充右上象限；底边标记若在中轴偏左则填充左下象限，偏右则填充右下象限；左边标记若在中轴偏上则填充左上象限，偏下则填充左下象限；右边标记若在中轴偏上则填充右上象限，偏下则填充右下象限。
  - 若同一象限被多个标记指定了不同颜色，使用距离该象限角落更近的那个标记的颜色。
  - 未被任何标记指定的象限保持 Black。
  - 框架本身的 Grey 边框保持不变，彩色标记在输出中被擦除（变回 Black）。
- `Key insight`：标记不是简单地装饰框架边缘——解题者需要先推断出框架被中轴线分为四个象限，再根据标记在边上的偏移位置判断它控制哪个象限的颜色，这是一个"位置→归属→填充"的两层推理。
</new_puzzle>

- `description`：将散落的彩色碎片按形状匹配拼回对应颜色的空心容器内部，碎片进入容器时需要旋转到与容器缺口方向一致的朝向。
- `Input structure`：背景为 Black。网格中有若干不同颜色的空心矩形"容器"（由单像素厚的彩色边框构成），每个容器的边框恰好有一个连续的缺口（缺失 1-3 个像素），缺口位于四条边中的某一条上。网格空白区域散布着若干小型 4-连通彩色碎片（形状各异，每个碎片颜色与某个容器相同）。
- `Rule`：
  - 每个碎片与同色容器配对（每个容器恰好对应一个碎片）。
  - 对每个容器，确定其缺口所在的边以及缺口相对于该边中点的位置。
  - 将碎片平移到容器的内部，具体放置规则：碎片被放置在容器内部靠近缺口那一侧的位置，碎片的重心（最小外接矩形中心）对齐到容器内部空间在缺口方向上的中线处。

  - 原位置的碎片被擦除。容器边框和缺口保持原样不变。
- `Key insight`：解题者需要两步独立推理：第一步是通过颜色匹配碎片与容器的归属关系；第二步是发现缺口方向决定了碎片的旋转角度和放置位置——缺口不仅是容器的视觉特征，更是碎片放置规则的编码。
</new_puzzle>

- `description`：在网格中，每个"种子"像素按照其所在区域的边界形状向外生长出等厚轮廓环，环的层数由同区域内种子的数量决定。
- `Input structure`：背景为 Black。网格被 Grey 线条分割成若干不规则但封闭的区域（Grey 线条宽度为 1 像素，形成完整的分隔网络）。每个区域内部散布着零个或多个同色的单像素"种子"（种子颜色从 Red、Blue、Green、Yellow、Orange 中取，同一区域内所有种子颜色相同，不同区域的种子颜色可能相同也可能不同）。
- `Rule`：
  - 对每个包含种子的区域，数出其中的种子数量 N。
  - 从该区域的边界（紧贴 Grey 线条的内侧像素）开始，向内生长 N 层同心轮廓环，每层宽度为 1 像素，颜色为该区域种子的颜色。
  - 第 1 层是区域边界内侧的所有像素，第 2 层是紧贴第 1 层内侧的所有像素，依此类推。
  - 若区域太小以至于 N 层轮廓在某些位置重叠或无法完全画完，则只画到该区域被完全填满为止。
  - 没有种子的区域保持全 Black。Grey 分隔线保持不变。种子像素本身被轮廓覆盖（若种子位于某层轮廓范围内）或保持原色（若种子在未被轮廓覆盖的内部区域）。
- `Key insight`：解题者必须先识别出 Grey 线条构成的区域分割（这是空间解析层），再发现种子数量等于轮廓层数这一映射关系（这是计数→几何量的转换层），最后执行从边界向内的逐层填充。三层推理共同构成完整规则。
</new_puzzle>

<new_puzzle>
- `description`：每个彩色 L 形指向一个目标方格，目标方格内绘制该 L 形的微缩完整矩形补全。
- `Input structure`：背景为 Black。网格中有若干大小相同的 Grey 空心正方形方格（边长为 5 像素，单像素边框，内部 3×3 为空）。每个方格的外部恰好有一个彩色 L 形物体（由 3 个同色像素组成直角形状），L 形的直角开口朝向某个方向（上、下、左、右之一），并且 L 形的一条臂指向（即最近的延长线经过）恰好一个 Grey 方格。
- `Rule`：
  - 对每个 L 形，确定其"指向"的方格：沿 L 形长臂方向延伸，找到最先遇到的 Grey 方格。
  - L 形本身是一个 2×2 正方形缺了一个角的形状。确定缺失角的位置（左上/右上/左下/右下）。
  - 在目标方格的 3×3 内部空间中，用该 L 形的颜色画出一个 2×2 实心小正方形，放置在 3×3 空间中与缺失角相对的那个角落。例如：L 形缺失右下角，则 2×2 方块画在 3×3 内部的左上角。
  - L 形在原位置保留不动。Grey 方格边框保持不变。
- `Key insight`：解题者需要两步非平凡推理：第一步是识别 L 形的臂方向以确定其指向哪个方格（方向解码层）；第二步是发现 L 形的缺角位置与方格内填充位置之间的"相对"映射关系（形状→位置的反转层）——缺角并非指示填充位置，而是指示填充位置的镜像对角。
</new_puzzle>

<new_puzzle>
- `description`：根据连接线的颜色对网格中的对象进行分组，再按组内对象数量对每组执行不同的几何变换。
- `Input structure`：背景为 Black。网格中有若干小型单色实心矩形对象（每个对象 2×2 或 3×3，颜色为 Grey）。对象之间有单像素宽的彩色连接线（颜色取自 Red、Blue、Green、Orange），每条线水平或垂直地连接恰好两个对象（线从一个对象的边缘像素出发，沿直线到达另一个对象的边缘像素）。同色的连接线将对象串联成组（若 A 和 B 有 Red 线相连，B 和 C 有 Red 线相连，则 A、B、C 属于同一个 Red 组）。
- `Rule`：
  - 首先根据连接线颜色将所有对象分组。擦除所有连接线。
  - 数出每组中对象的数量 N：
    - 若 N = 2：将该组中两个对象用该组连接线的颜色画一条直线连接（与输入线相同路径），并将两个对象本身的颜色从 Grey 改为该组连接线的颜色。
    - 若 N = 3：将该组中三个对象的颜色改为连接线颜色，并在三个对象的外接矩形边界上画一个该颜色的单像素厚空心矩形框。
    - 若 N = 4 或更多：将该组所有对象的颜色改为连接线颜色，并将这些对象的外接矩形内部全部填充为该连接线颜色。
  - 不属于任何组的孤立对象（无连接线）保持 Grey 不变。
- `Key insight`：解题者首先需要通过线的颜色发现分组规则（这并非直观的——线连接的是 Grey 对象而非同色对象）；然后需要发现组内成员数量决定了变换类型，而变换类型是一个离散的阶梯函数（2→连线，3→框，4+→填充）。颜色在此题中同时承担了"分组标签"和"输出着色"的双重角色。
</new_puzzle>

- `description`：将网格中每个彩色箭头所指方向的像素序列"吸收"进箭头体内，箭头长度决定吸收距离。
- `Input structure`：背景为 Black。网格中有若干由单一颜色（非 Black）构成的箭头形对象。每个箭头由一条直线段（箭身，长度 2-5 像素）和一个 V 形箭头尖端（3 个像素组成，开口朝箭身方向）构成，整体指向上、下、左或右。箭头前方（尖端指向的方向）有一列/行彩色像素（可能是多种颜色混合的序列）。
- `Rule`：
  - 对每个箭头，测量其箭身长度 L（不含箭头尖端的像素数）。
  - 从箭头尖端沿指向方向取前方 L 个像素，这些像素构成"被吸收序列"。
  - 将被吸收序列反向排列后，依次替换箭身的像素（从靠近尖端的一端开始填入）。箭头尖端保持原色不变。
  - 被吸收的原始像素位置变为 Black。
  - 若前方不足 L 个非 Black 像素，则只吸收实际存在的像素，箭身中未被填充的位置保持箭头原色。
- `Key insight`：解题者需要先识别箭头形状并推断其指向方向（形状解析层），再发现箭身长度等于吸收距离这一隐含的"自参照"数值关系（长度→距离映射层），最后注意到吸收过程中序列被反转（操作细节层）。反转操作是最隐蔽的一步——仅通过仔细比较输入输出样例中的颜色排列顺序才能发现。
</new_puzzle>

- `description`：通过对比两个相似图案的差异像素来确定"印章"形状，再将印章盖印到网格中标记点指定的位置。
- `Input structure`：背景为 Black。网格被一条 Azure 色的水平分隔线分为上下两个区域。上方区域包含两个相同大小的矩形色块（由同一颜色如 Green 绘制的相同图案），它们左右并列放置，两个图案几乎相同但有若干像素位置不同——其中一个图案在这些位置是 Green，另一个在这些位置是 Black（或反之）。下方区域是一片较大的由某种颜色（如 Yellow）绘制的图案，其中散布着若干 Red 单像素标记点。
- `Rule`：
  - 比较上方两个图案，提取它们的差异：将左图案有色而右图案为 Black 的像素位置集合作为"印章形状"（以差异像素的最小外接矩形为基准进行裁剪）。
  - 对下方区域中的每个 Red 标记点，以该标记点为印章的左上角锚点，将印章形状叠印到下方图案上：印章覆盖的位置全部变为 Magenta 色。

  - 上方区域和 Azure 分隔线保持原样不变。
- `Key insight`：核心挑战在于解题者需要先通过"找不同"提取印章形状（差异检测层），然后理解 Red 标记点是印章的锚定位置（位置编码层），最后执行批量盖印操作。印章不是直接给出的，而是隐藏在两个近似图案的差异之中。
</new_puzzle>

<new_puzzle>
- `description`：每个封闭区域内的彩色像素"传染"相邻区域，传染颜色由区域间共享边界的长度决定优先级。
- `Input structure`：背景为 Black。网格中由 Grey 单像素线条构成一个不规则的网格状分隔系统，将整个网格划分为若干封闭区域。某些区域内有单个彩色像素（颜色取自 Red、Blue、Green、Yellow、Orange，每个有色区域内仅一个彩色像素），其余区域为纯 Black（空区域）。
- `Rule`：
  - 每个含有彩色像素的区域为"源区域"。
  - 每个空区域检查与其共享 Grey 边界的所有相邻源区域。"共享边界长度"定义为两区域之间的 Grey 分隔线段的像素数量。
  - 空区域被染成与其共享边界最长的那个相邻源区域的颜色：在该空区域内所有 Black 像素全部替换为对应颜色。
  - 若存在共享边界长度相同的平局情况，则该空区域保持 Black 不变。
  - 源区域本身保持不变（彩色像素保留，区域内其余部分保持 Black）。Grey 线条保持不变。
- `Key insight`：解题者需要三层推理：第一层是识别 Grey 线条构成的区域分割结构；第二层是发现彩色像素标记了"源"而空区域是"目标"的传播关系；第三层是共享边界长度决定优先级——这个量需要解题者对比不同边界的像素数来判断，而非简单地选择最近邻。边界长度作为一个视觉可数但非显然的属性，提供了恰当的隐蔽性。
</new_puzzle>
