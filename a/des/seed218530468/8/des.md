- `Input structure`：
  - 背景色（black）占据大部分网格。
  - 网格中有若干个由 grey 像素绘制的封闭矩形边框（一像素宽），边框之间互不重叠。
  - 每个封闭边框的内部恰好有一个由某种非背景、非 grey 颜色组成的小型连通色块（1-4 个像素），称为"种子"。
  - 网格的最上方一行存在一个"调色板行"：若干个 1×2 的色对，每个色对左侧像素的颜色表示种子颜色，右侧像素的颜色表示目标边框颜色。色对之间由一个背景像素间隔。

- `Rule`：
  - 第一步（查表匹配）：对于每个封闭边框，识别其内部种子的颜色 C_seed，在调色板行中找到左侧为 C_seed 的色对，读取右侧的颜色 C_frame 作为该边框的目标颜色。
  - 第二步（重绘边框）：将该封闭边框的所有 grey 像素替换为 C_frame。
  - 第三步（擦除种子）：将种子像素替换为背景色。
  - 调色板行本身在输出中被完全擦除（替换为背景色）。

- `Key insight`：grey 边框本身不携带颜色信息——必须先通过内部种子颜色在调色板中查表获得目标颜色，再反向重绘边框，形成"种子决定容器外观"的两层推理。

- `description`：将散布在网格中的多组同色像素对视为端点，在每对端点之间画出 L 形折线路径，折弯方向由端点附近的方向标记决定。

- `Input structure`：
  - 背景色为 black。
  - 网格中有若干种非背景颜色，每种颜色恰好出现两个像素，分别标记一对端点。
  - 每个端点的正上、正下、正左或正右恰好有一个 grey 像素作为"方向标记"，指示该端点发出连线的初始方向（标记在上方表示先向上走，在右方表示先向右走，依此类推）。
  - 不同颜色的端点对在空间上互不干扰（路径不会交叉）。

- `Rule`：
  - 对于每种颜色的两个端点 A 和 B：
    - 从 A 出发，沿 A 的方向标记所指方向画直线段。
    - 从 B 出发，沿 B 的方向标记所指方向画直线段。
    - 两段直线在某行或某列相遇时，在交汇处拐弯连通，形成完整的 L 形或 Z 形折线路径。
  - 路径使用与端点相同的颜色绘制。
  - 所有 grey 方向标记在输出中被擦除（替换为背景色）。

- `Key insight`：仅靠端点位置无法唯一确定连线走向（L 形路径有两种折弯方式）——必须读取每个端点旁的方向标记来消歧，将"方向标记解码"与"路径绘制"组合为两层推理。
</new_puzzle>

- `Input structure`：
  - 背景色为 black。
  - 网格中有若干个大的单色实心矩形（每个矩形一种独特的非背景颜色），每个矩形内部恰好有一个矩形孔洞（孔洞内为背景色）。
  - 每个大矩形的某一侧边框上，孔洞与该侧边框直接相邻（即孔洞"开口"朝向该侧边缘——该侧边框在孔洞对应的位置被移除，形成一个通向外部的缺口）。开口方向可以是上、下、左、右四个方向之一。
  - 网格中另有若干小型模板图案（sprite），每个模板使用与某个大矩形相同的颜色，尺寸与该矩形内孔洞的尺寸完全匹配。模板位于所有大矩形之外的空白区域。

- `Rule`：
  - 第一步（颜色匹配）：将每个模板按颜色匹配到对应的大矩形。
  - 第二步（确定旋转角度）：检查大矩形孔洞的开口方向。定义"默认方向"为上方开口对应 0° 旋转。若开口在右侧则模板顺时针旋转 90°，在下方则旋转 180°，在左侧则旋转 270°。
  - 第三步（旋转并填入）：将模板按确定的角度旋转后，填入对应矩形的孔洞位置。
  - 输出中，原模板所在位置被擦除为背景色。

- `Key insight`：孔洞尺寸与模板的颜色匹配只完成了"哪块放哪里"的判断，但模板需要旋转才能正确填入——旋转角度隐藏在孔洞的开口方向中，解题者必须发现"开口方向编码旋转指令"这一非显然映射关系。
</new_puzzle>

- `Input structure`：
  - 背景色为 black。
  - 网格被 grey 色的等间距水平线和垂直线划分为若干个大小相同的矩形格子（例如每个格子 4×4 像素，不含分隔线）。
  - 部分格子内部散布有 1 到 3 个 red 像素（称为"信号像素"），其余格子内部为全背景色（空格子）。
  - 网格最右侧有一列图例区域，与主网格由双层 grey 线分隔。图例区域纵向排列三个样本格子（尺寸与主网格格子相同），每个样本格子内包含一定数量的 red 像素（分别为 1 个、2 个、3 个），且每个样本格子的剩余像素用一种独特的非背景、非 red、非 grey 填充色绘制特定图案（例如含 1 个 red 像素的样本用 blue 水平条纹填充，含 2 个 red 像素的用 green 棋盘格填充，含 3 个 red 像素的用 yellow 实心填充）。

- `Rule`：
  - 第一步（读取图例）：识别图例区域中的三个样本格子，根据每个样本内 red 像素的数量确定其级别（1/2/3），并记录该级别对应的填充图案及其颜色。
  - 第二步（计数信号）：对主网格中每个非空格子，数出其中 red 像素的数量 N（N 为 1、2 或 3）。
  - 第三步（填充格子）：将该格子内的所有像素（包括原有的 red 像素和背景像素）替换为级别 N 对应的填充图案。空格子保持不变。
  - 输出中图例区域被移除（替换为背景色），grey 分隔线保留。

- `Key insight`：图例中的 red 像素数量并非装饰——它是将图例样本与主网格格子关联的隐含键。解题者必须先发现"信号像素计数 = 图例查找键"这层映射，然后才能理解为何不同格子获得不同的填充图案。
</new_puzzle>

- `description`：将框架外部的彩色碎片沿其锚点所在边的法线方向投射进空心框架内部，投射距离由碎片自身在该方向上的厚度决定。

- `Input structure`：
  - 背景色为 black。
  - 网格中央有一个由 grey 像素绘制的空心矩形框架（一像素宽边框，内部为背景色）。
  - 框架外部散布若干个小型彩色碎片（每个碎片是一个 2-4 像素的连通体，使用独特的非背景、非 grey 颜色）。
  - 每个碎片恰好有一个像素与框架边框的外侧正交相邻（即该像素与框架某条边上的某个 grey 像素在上下或左右方向上直接相邻），该像素称为碎片的"锚点"。锚点所在的框架边决定了投射方向：锚点贴在框架上边外侧 → 向下投射；贴在左边外侧 → 向右投射；贴在下边外侧 → 向上投射；贴在右边外侧 → 向左投射。

- `Rule`：
  - 第一步（确定投射方向）：根据碎片锚点与框架的哪条边相邻，确定碎片向框架内部的投射方向。
  - 第二步（计算投射距离）：测量碎片在投射方向上跨越的像素行数（或列数），该值即为投射距离 D。
  - 第三步（投射绘制）：将碎片整体沿投射方向平移，跳过框架边框本身，使碎片锚点进入框架内部后再继续移动 D-1 个像素（总共使锚点位于框架内壁起算第 D 个位置）。在最终位置用碎片颜色绘制碎片的完整形状。
  - 输出中框架外部的原始碎片被擦除为背景色，grey 框架保留。

- `Key insight`：投射方向可从碎片与边框的邻接关系直接看出，但投射距离的编码是核心难点——碎片沿投射方向的"厚度"同时充当了位移量，使得碎片形状既是要绘制的图案，也是距离指令。
</new_puzzle>

- `Input structure`：
  - 背景色为 black。
  - 网格中有若干个互不重叠的"信封"对象。每个信封由一个单色实心矩形外壳构成（如 red 实心矩形），外壳的某一条边上有一段连续缺口（该段像素为背景色而非外壳颜色），形成"开口"。每个信封的开口位于不同的边（上/下/左/右之一）。
  - 每个外壳内部嵌有一个由另一种颜色组成的小型连通图案（称为"字母"），字母的 bounding box 严格位于外壳内部。
  - 开口的长度（沿边方向的像素数）恰好等于字母在平行于该边方向上的宽度，保证字母可以整体从开口滑出。

- `Rule`：
  - 第一步（识别开口方向）：对每个信封，找到外壳缺口所在的边，确定字母的滑出方向（朝向缺口外侧）。
  - 第二步（滑出字母）：将字母图案整体沿滑出方向平移，直到字母的整个 bounding box 完全离开外壳的范围。字母紧贴外壳外侧放置（字母最近边与开口边缘之间间隔恰好一个像素，即原来边框的位置）。
  - 第三步（修补外壳）：字母原来在外壳内部占据的像素位置用外壳颜色填充，使外壳内部恢复为纯色实心（开口缺口仍然保留）。

- `Key insight`：信封的缺口同时编码了两层信息——它标记了滑出方向（方向推断层），又通过其长度隐式约束了哪个内嵌图案可以通过（尺寸匹配层）。解题者必须先理解"缺口 = 出口方向"的空间关系，再发现字母滑出后外壳被自动修补的规则。
</new_puzzle>

- `description`：在由同心嵌套矩形框组成的"洋葱"结构中，根据最内层核心像素的颜色在调色板中查找颜色序列，然后从内到外依次为每层灰色框架着上对应颜色。

- `Input structure`：
  - 背景色为 black。
  - 网格中有若干个"洋葱"结构，彼此不重叠。每个洋葱由 2-4 层同心嵌套的矩形框组成，每层框为一像素宽的 grey 色环，相邻两层框之间间隔一个像素的背景色。
  - 每个洋葱结构的最内层中心位置有一个 1×1 的彩色像素（"核心"），核心颜色在不同洋葱之间互不相同。
  - 网格的某个角落有一个调色板区域：由若干行组成，每行以一个彩色像素开头（该颜色与某个洋葱的核心颜色相同），紧随其后是 2-4 个不同颜色的像素（数量与对应洋葱的层数相同），形成一个有序颜色序列。不同行之间由一行背景色间隔。

- `Rule`：
  - 第一步（匹配核心到调色板）：对每个洋葱结构，读取其核心颜色 C，在调色板中找到以 C 开头的那一行。
  - 第二步（读取着色序列）：该行中核心颜色 C 之后的像素依次为 C1, C2, C3...，分别对应从最内层框到最外层框的着色颜色。
  - 第三步（逐层着色）：将最内层矩形框的所有 grey 像素重绘为 C1，第二层框重绘为 C2，以此类推直到最外层。核心像素本身在输出中保持原色不变。
  - 调色板区域在输出中被完全擦除为背景色。

- `Key insight`：所有框架初始都是相同的 grey 色，肉眼无法区分不同洋葱结构该用什么颜色——必须依靠最内层核心像素在调色板中查表获得整个着色方案，形成"核心决定外壳外观"的由内而外的三层推理链：识别核心颜色 → 调色板查找 → 按序逐层着色。
</new_puzzle>

- `description`：将网格中各个彩色对象按照其内部孔洞数量进行分组，同组对象被移动到同一水平带中并按面积从小到大排列，不同组之间由灰色水平线分隔。

- `Input structure`：
  - 背景色为 black。
  - 网格中散布若干个彩色连通对象（4-连通），每个对象为单一非背景颜色的连通体，颜色可以重复。
  - 部分对象内部有封闭的背景色孔洞（被对象像素完全包围的背景区域），孔洞数量为 0、1 或 2 个。
  - 对象之间互不接触，各自的 bounding box 不重叠。

- `Rule`：
  - 第一步（分类）：对每个对象，数出其内部封闭孔洞的数量 H（H 为 0、1 或 2）。
  - 第二步（分组排列）：将所有 H=0 的对象归为第一组，H=1 的归为第二组，H=2 的归为第三组。
  - 第三步（输出布局）：输出网格中，从上到下依次放置第一组、第二组、第三组。每组内的对象从左到右按像素面积从小到大排列，对象之间间隔一列背景色。组与组之间由一行 grey 像素构成的水平分隔线隔开。每组占据的行数等于该组中最高对象的 bounding box 高度，所有对象底部对齐于该组的底边。输出网格宽度和高度根据内容自动调整。

- `Key insight`：对象的颜色和形状都是干扰信息——真正的分组键是内部孔洞数量这一拓扑特征。解题者需要先发现"孔洞数量决定分组"这一隐蔽规则，再识别组内按面积排序的第二层规律。
</new_puzzle>
