<new_puzzle>
根据色带图例确定每个封闭区域的"缩放因子"，然后将区域内的种子图案按该因子放大填充。

Input structure：
- 背景为最常见颜色（如 black）。网格中有若干由 grey 线段围成的封闭矩形区域，每个区域内部包含一个小型多色种子图案（占据区域左上角的几个像素）。
- 网格顶部有一条水平色带图例：由若干段不同颜色组成，每段颜色连续出现 N 个像素。色带中出现的每种颜色恰好对应某个封闭区域的 grey 边框上标注的同色角标像素。

Rule：
- 首先识别色带图例中每种颜色的连续像素数 N，该数即为对应区域的缩放因子。
- 通过匹配封闭区域 grey 边框四角之一的彩色角标像素与色带中的颜色，确定该区域使用哪个缩放因子。
- 将区域内的种子图案按缩放因子 N 进行整数放大（每个种子像素变为 N×N 的同色方块），填充到该封闭区域中，覆盖原有种子图案。区域剩余空间保持背景色。
- 色带图例在输出中被移除（替换为背景色）。

Key insight：
色带中每种颜色的长度编码了缩放倍率，角标颜色将区域与图例关联——解题者需要先从色带"读取"每种颜色的长度，再通过角标完成区域到倍率的映射，最后执行图案放大。两步归纳缺一不可。
</new_puzzle>

<new_puzzle>
沿管道网络传递形状，每经过一个交叉节点就对形状执行一次由节点颜色决定的几何变换。

Input structure：
- 背景为 black。网格中有若干由 grey 像素组成的单像素宽管道线段（水平或垂直），管道在交叉点处相交。
- 每个交叉点处的像素被染为非 grey 的颜色（red、blue、green 等），表示该节点的变换类型。
- 管道的一个端点处放置一个 3×3 的彩色小图案（形状各异，如 L 形、T 形、方块等），这是"输入形状"。管道的另一个端点处是一个 3×3 的空框（由 maroon 像素画出的边框，内部为背景色），这是"输出槽位"。

Rule：
- 从输入形状所在端点出发，沿管道向输出槽位方向前进。
- 每经过一个彩色交叉节点，对当前携带的形状执行一次变换：red 节点 = 顺时针旋转 90°，blue 节点 = 水平翻转，green 节点 = 垂直翻转。
- 变换按经过节点的顺序依次叠加。
- 最终将变换后的形状填入输出槽位（替换 maroon 边框内部的背景色区域），输入端的原始形状被清除为背景色。

Key insight：
解题者需要先追踪管道路径确定经过哪些节点及其顺序，再从样例中归纳出每种节点颜色对应的几何变换类型，最后依次应用变换得到最终形状。路径追踪与变换推断构成两层独立的推理。
</new_puzzle>

<new_puzzle>
根据"投票机制"确定每个对象的输出颜色：每个对象被多个重叠的彩色射线覆盖，出现次数最多的射线颜色成为该对象的新颜色。

Input structure：
- 背景为 azure。网格边缘上分布着若干彩色"发射器"像素（如 red、green、yellow），每个发射器朝网格内部沿其所在边的法线方向发射一条同色射线，射线宽 1 像素，一直延伸到对面边缘。
- 网格内部散布着若干由 grey 像素构成的小型 4-连通对象（形状各异，大小 2-6 像素）。

Rule：
- 每个发射器从其位置沿法线方向画一条贯穿整个网格的同色射线（在输出中不可见，仅用于逻辑判定）。
- 对每个 grey 对象，统计有多少条不同颜色的射线穿过它的任意像素。对于每种颜色，计算穿过该对象的该颜色射线的条数。
- 将该对象的所有像素重新染为穿过它的射线中出现次数最多的那种颜色。若存在平局，选择在网格边缘上发射器位置更靠左上（先比行再比列）的那种颜色。
- 输出中发射器像素保持不变，射线本身不绘制，仅对象变色。

Key insight：
射线在视觉上不存在，解题者必须先从边缘发射器位置推断出哪些射线穿过哪些对象，再统计每个对象的颜色"投票"结果。发射器→射线→覆盖判定→投票计数构成多层推理链。
</new_puzzle>

<new_puzzle>
利用小钥匙图案的形状匹配大锁图案中的缺口，并用钥匙的颜色标记匹配方向来决定锁图案的旋转角度。

Input structure：
- 背景为 black。网格分为上下两个区域，由一条水平 grey 分隔线隔开。
- 上方区域包含若干个大型单色图案（"锁"），每个锁是一个近似完整的矩形但有一个凹陷缺口（缺口朝上、下、左或右），锁的颜色各不相同。
- 下方区域包含若干个小型双色图案（"钥匙"）：每把钥匙由一个凸起部分和一个单像素的彩色"柄"组成。凸起部分的形状与某把锁的缺口互补。柄的颜色与某把锁的颜色相同，用于指定配对关系。

Rule：
- 通过柄的颜色将每把钥匙与对应颜色的锁配对。
- 将钥匙的凸起部分旋转/翻转，使其恰好填入锁的凹陷缺口（形状互补匹配）。
- 确定使钥匙填入缺口所需的旋转角度（0°、90°、180°、270°）。
- 将整个锁图案（含已填入的钥匙）按相同角度旋转，作为该锁的输出。
- 输出仅包含旋转后的各个锁图案，按原来的相对位置排列在新的背景网格上。下方的钥匙区域和分隔线被移除。

Key insight：
柄颜色确定配对是第一层推理；形状互补确定钥匙朝向是第二层推理；而最关键的隐蔽机制是：填入钥匙所需的旋转角度同时也是整个锁的旋转角度——解题者必须发现"钥匙的插入方向决定了锁的最终朝向"这一非显然关联。
</new_puzzle>

<new_puzzle>
在网格中找出被"守卫"对象监视的区域并标记，守卫的监视方向由其内部开口朝向决定，监视距离由同色围栏的层数决定。

Input structure：
- 背景为 black。网格中有若干"守卫"对象：每个守卫是一个 3×3 的彩色方块，中心像素为背景色，方块四条边之一上的中点像素也为背景色，形成一个指向某个基本方向（上/下/左/右）的开口——该开口方向即守卫的监视方向。
- 某些守卫外围紧贴着由同色像素构成的 1 像素宽环形围栏（围栏完全包围守卫，不含间隙）。一个守卫可以有 0、1 或 2 层围栏。

Rule：
- 确定每个守卫的监视方向（开口朝向）。
- 统计该守卫的围栏层数 N（0、1 或 2）。
- 从守卫的开口位置出发，沿监视方向画一条射线，长度为 (N+1)×2 个像素。射线用该守卫的颜色绘制，覆盖背景像素。若射线遇到非背景像素则提前停止。
- 守卫本身和围栏保持不变。

Key insight：
解题者需要完成两步独立归纳：第一步是从 3×3 方块的开口位置推断监视方向（开口即朝向），第二步是发现围栏层数与射线长度之间的数值对应关系。仅靠观察方向或仅靠观察长度都无法完整还原规则。
</new_puzzle>

<new_puzzle>
将散落的拼图碎片按边缘齿形互锁规则拼合，碎片的层叠顺序由碎片面积从小到大决定。

Input structure：
- 背景为 black。网格中散布着若干彩色 4-连通对象（"碎片"），每个碎片颜色不同。
- 每个碎片的边缘具有凹凸齿形：凸出的突起（1 像素宽，向外延伸 1 像素）和凹入的缺口（1 像素宽，向内凹陷 1 像素）。
- 网格底部有一条由 grey 像素标出的矩形目标框（仅绘制边框线）。

Rule：
- 将所有碎片按像素面积从小到大排序。
- 按此顺序依次将碎片平移到目标框内，使每个新碎片的凸起恰好嵌入已放置碎片的凹口中（凸凹互补匹配）。第一个碎片放在目标框的左上角对齐。
- 后放入的碎片在重叠位置覆盖先放入碎片的颜色（后来居上）。
- 碎片仅做平移，不旋转或翻转。
- 输出为目标框内部区域的内容（不含 grey 边框线本身）。

Key insight：
碎片的拼合顺序并非由空间位置决定，而是由面积排序决定——这是第一层需要归纳的隐蔽规则。第二层是识别凸凹互锁的空间匹配关系来确定每块碎片的精确放置位置。两层规则协同作用才能生成正确输出。
</new_puzzle>

<new_puzzle>
根据色谱条定义的颜色顺序关系，对主网格中的多色区域执行"边界渗透"：两个相邻色块的交界处，色谱上排位更高的颜色向排位更低的颜色侵蚀一层像素。

Input structure：
- 背景为 black。网格左侧有一列纵向排列的不同颜色像素，形成"色谱条"（如从上到下依次为 red、orange、yellow、green、blue），定义了颜色之间的优先级：越靠上优先级越高。
- 网格右侧是一个大型矩形区域，内部由若干同色连通块（色块）紧密拼接而成，无背景间隙，每个色块的颜色取自色谱条。

Rule：
- 色谱条从上到下定义颜色优先级：位置越高优先级越高。
- 对主区域中每对正交相邻且颜色不同的像素对 (A, B)，若 A 的颜色在色谱上优先级高于 B，则在输出中 B 被替换为 A 的颜色（A 侵蚀 B）。
- 侵蚀仅发生一层：只有直接与更高优先级色块相邻的像素会被改变，不进行连锁传播。
- 若一个像素同时被多个更高优先级的邻居侵蚀，选择优先级最高的那个颜色。
- 色谱条本身在输出中保持不变。

Key insight：
解题者首先需要从色谱条中提取颜色的优先级顺序（这是通过空间排列而非颜色本身的属性定义的），然后理解"高优先级侵蚀低优先级"的单层扩散规则。色谱顺序的归纳与侵蚀方向的发现构成两层独立推理。
</new_puzzle>
