<description>
根据彩色种子像素在封闭房间中的位置，用对应颜色沿墙壁内侧铺设地毯，地毯宽度由房间内种子像素的数量决定。

Input structure:
- 背景为黑色。灰色像素构成多个互不相连的封闭矩形房间（空心矩形框），每个房间的墙壁厚度为一个像素。
- 每个房间内部散布着若干彩色像素（非黑非灰），同一房间内所有彩色像素颜色相同，但不同房间的颜色不同。
- 每个房间内的彩色像素数量为 1、2 或 3。

Rule:
- 对每个封闭房间，数出其内部彩色像素的个数 N（1、2 或 3）。
- 沿房间内壁铺设 N 层厚的"地毯"：即从灰色墙壁内侧向房间中心方向，将最靠近墙壁的 N 层黑色像素全部涂成该房间的彩色像素颜色。地毯覆盖的是一个缩小的矩形环带。
- 原来的彩色种子像素如果恰好落在地毯区域内则被地毯覆盖；如果落在地毯区域之外（即更靠近房间中心），则保持原色不变。
- 灰色墙壁和房间外的黑色背景保持不变。

Key insight: 种子像素的颜色决定地毯颜色，而种子像素的数量决定地毯厚度——解题者需要同时发现"颜色传递"和"计数到几何厚度"两层映射关系。
</description>
</new_puzzle>

<description>
在网格中找到由不同颜色构成的"钥匙"和"锁"配对，将钥匙旋转后插入锁的缺口中，同时根据锁的形状对钥匙进行颜色重映射。

Input structure:
- 背景为黑色。网格中散布着若干小型连通组件，每个组件由恰好两种颜色构成。
- 其中一类组件是"锁"：形状为一个 3x3 或 4x4 的实心方块，方块某一侧有一个矩形凹槽（缺口），缺口处为黑色（背景色）。锁的主体为一种颜色，缺口边缘有一圈单像素宽的第二种颜色作为"锁孔边框"。
- 另一类组件是"钥匙"：形状为一个小的不规则凸起图案（与某个锁的缺口形状互补），由两种颜色构成——主体色与某个锁的主体色相同，边缘色与该锁的锁孔边框色相同。

Rule:
- 通过主体颜色匹配，将每把钥匙与其对应的锁配对。
- 确定锁的缺口方向（上、下、左、右），将钥匙旋转（0/90/180/270度）使其形状恰好能填入缺口。
- 将旋转后的钥匙平移到缺口位置，填满缺口。填入后，钥匙的主体色变为锁的锁孔边框色，钥匙的边缘色变为锁的主体色（即两种颜色互换）。
- 清除钥匙原始位置的像素（变为黑色背景）。

Key insight: 颜色匹配确定配对关系，形状互补确定旋转方向，而插入后的颜色互换规则需要解题者从多个样例中归纳——仅观察单个样例可能误以为颜色不变或只做单向替换。
</description>
</new_puzzle>

<description>
将网格中的彩色路径视为"电路导线"，根据导线交叉处的叠加规则生成输出颜色，同时导线的端点标记决定信号传播方向。

Input structure:
- 背景为黑色。网格中有若干条单像素宽的水平或垂直彩色直线段（导线），每条导线为单一颜色（红、蓝、绿、黄中的一种）。
- 每条导线的一个端点旁有一个相邻的灰色像素（发射端标记），另一端没有标记（接收端）。
- 部分导线在某些像素位置发生正交交叉（一条水平、一条垂直，共享同一个像素格）。交叉处当前显示为其中一条导线的颜色（被覆盖）。

Rule:
- 每条导线从灰色标记端向无标记端传播"信号"。
- 在两条导线交叉的像素处，颜色由以下混合规则决定：红加蓝等于 magenta，红加绿等于 yellow，蓝加绿等于 azure，红加黄等于 orange，其余组合等于 maroon。
- 如果一条导线在到达交叉点之前已经经过了另一个交叉点并被混合过，则它携带混合后的颜色继续传播。但混合只发生在交叉像素本身，导线在交叉点之后的部分恢复为自身原始颜色。
- 输出网格中，所有非交叉像素保持原色不变，所有交叉像素显示混合后的颜色。灰色标记像素保留。

Key insight: 解题者需要首先识别灰色标记确定的信号方向（这决定了哪条线"先到"交叉点），然后发现交叉点的颜色混合规则表——两层发现缺一不可，且混合规则必须从多个样例中的不同颜色组合归纳得出。
</description>
</new_puzzle>

<description>
根据散落的彩色碎片在网格中的空间聚类关系，重建被打散的多层同心矩形框，每个框的颜色和层级由碎片的面积排序决定。

Input structure:
- 背景为黑色。网格中散布着若干组彩色连通区域（碎片），每组碎片颜色相同。每种颜色的碎片有 2 到 6 块不等。
- 网格右下角有一个小的灰色矩形（如 3x3），其内部用不同颜色的单像素从外到内排列，形成一个"图例"，标示同心框从外层到内层的颜色顺序。
- 所有同色碎片的总面积（像素数）各不相同。

Rule:
- 读取右下角图例，从外圈到内圈确定颜色的层级顺序（最外层颜色排第一）。
- 对网格中每种颜色，计算该颜色所有碎片的总像素面积。
- 按图例的层级顺序，构建同心矩形框：最外层框的边长由最外层颜色的总面积决定——该面积恰好等于一个空心矩形环的像素数（即外框面积减去内部空洞面积）。每一层框的厚度均为 1 个像素。
- 将构建好的同心矩形框居中放置在与输入相同大小的黑色网格中。
- 清除所有原始碎片和图例。

Key insight: 解题者需要先破解图例的含义（颜色到层级映射），再发现面积到环形框尺寸的几何对应关系——碎片的空间位置是干扰项，真正决定输出的是每种颜色的总面积和图例中的排列顺序。
</description>

<description>
在网格中识别由墙壁围成的迷宫区域，根据区域内"指示箭头"的方向，将该区域内的所有非箭头对象沿箭头方向推到墙壁边缘，同时箭头自身根据区域的出口位置决定是否变色。

Input structure:
- 背景为黑色。蓝色像素构成迷宫墙壁，将网格划分为若干互不相通的封闭矩形区域。
- 每个区域内有一个由红色像素构成的"箭头"（三像素 L 形，即 2x2 的方格中去掉一个角的像素，缺角方向指示推动方向：缺角朝上表示向下推，缺角朝右表示向左推，以此类推——即推动方向与缺角方向相反）。
- 每个区域内还有 1 到 3 个由其他颜色（绿、黄、orange 等）构成的小型连通对象（1 到 4 像素大小）。
- 部分区域的墙壁上有一个单像素的缺口（出口），用灰色像素标记。

Rule:
- 对每个封闭区域，根据红色箭头的缺角方向确定推动方向（与缺角相反）。
- 将区域内所有非箭头、非墙壁的彩色对象沿推动方向整体平移，直到对象的某个像素紧贴该方向的墙壁（或紧贴已被推到墙边的其他对象）。多个对象按距墙壁从近到远的顺序依次推动，保持相对顺序。
- 推动完成后，检查该区域是否存在灰色出口：若存在，将红色箭头重新着色为 magenta；若不存在出口，箭头保持红色。
- 箭头本身不移动，仅可能变色。墙壁和灰色出口像素保持不变。

Key insight: 解题者需要完成三层推理——第一层：识别 L 形箭头的缺角方向与推动方向的反向映射关系；第二层：理解多对象按距离排序依次推动的堆叠机制；第三层：发现灰色出口的存在与否控制箭头是否变色，这一规则只有在对比有出口和无出口的区域后才能归纳出来。
</description>
</new_puzzle>

<description>
将网格中分散的单色"瓦片"按照隐含的拼图边缘锯齿匹配规则拼合，拼合后根据相邻瓦片的颜色关系对接缝进行染色。

Input structure:
- 背景为黑色。网格中散布着 4 到 6 个矩形连通区域（瓦片），每个瓦片为单一颜色且各不相同。
- 每个瓦片的边缘并非完全平直：某些边上有单像素的凸起（凸齿）或凹陷（凹槽），凸齿和凹槽的位置沿边缘分布。
- 瓦片的核心矩形尺寸相同（如都是 4x5），但凸齿和凹槽使得实际形状略有不同。

Rule:
- 找到能相互咬合的瓦片边缘：一个瓦片某边的凸齿位置恰好对应另一个瓦片对应边的凹槽位置（互补匹配）。每条边最多与一个其他瓦片匹配。
- 将所有瓦片平移拼合到一起，使互补边紧密贴合（凸齿填入凹槽），形成一个更大的矩形。
- 拼合后，在每对相邻瓦片的接缝处（即凸齿与凹槽咬合的像素位置），将该像素颜色改为两个相邻瓦片颜色中在可用颜色列表（Black、Blue、Red、Green、Yellow、Grey、Magenta、Orange、Azure、Maroon）中排序更靠后的那个颜色。
- 清除原始位置的瓦片，只输出拼合后的完整矩形。

Key insight: 解题者首先需要通过凸齿和凹槽的互补关系确定哪些边相邻（这是空间推理层），然后需要从样例中归纳出接缝染色规则——染色并非简单地取某一侧颜色，而是取两色中"排序靠后"的颜色，这一排序规则需要从多个接缝的颜色对比中反向推断。
</description>

<new_puzzle>
<description>
识别网格中的"印章"模板和"画布"区域，根据画布边缘的颜色编码序列确定印章的盖印位置和旋转角度，生成多次盖印叠加后的输出图案。

Input structure:
- 背景为黑色。网格被灰色分隔线分为左右两个区域。
- 左侧区域包含一个小型彩色图案（印章模板），尺寸约 3x3 到 5x5，由 2 到 3 种非黑非灰颜色构成，形状不对称（旋转后可区分方向）。
- 右侧区域是一个较大的黑色矩形（画布），画布的四条边缘外侧各有一行或一列彩色像素作为"编码条"。
- 编码条中出现的颜色只有两种：与印章模板中出现的某两种颜色相同。编码条的大部分位置为黑色（空位），少数位置有彩色像素。

Rule:
- 将画布在水平和垂直方向上按印章模板的宽度和高度等分为若干格子（如画布 12x15、印章 3x5，则分为 4 行 3 列共 12 个格子）。
- 上边编码条中，每个彩色像素所在的列对应一个格子列；左边编码条中，每个彩色像素所在的行对应一个格子行。行列交叉处的格子需要盖印。
- 盖印的旋转角度由编码像素的颜色决定：若行编码和列编码颜色相同，印章不旋转（0度）；若颜色不同，印章顺时针旋转 90 度。
- 在对应格子位置放置（可能旋转后的）印章模板副本。多个盖印之间若有重叠，后盖的（行号更大的优先）覆盖先盖的。

Key insight: 解题者需要依次破解三层机制——第一层：理解编码条的行列交叉定位逻辑；第二层：发现编码条颜色异同与旋转角度的对应关系；第三层：确定重叠时的覆盖优先级规则。仅看一个样例很难同时锁定所有三层。
</description>
</new_puzzle>
