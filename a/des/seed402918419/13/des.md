根据封闭区域内部标记像素的颜色，从对应颜色的外部种子点向封闭区域"灌注"填充路径。

Input structure:
- 背景为黑色。
- 网格中有若干由灰色像素构成的封闭矩形框（框线宽度为1像素）。
- 每个灰色框的内部恰好有一个非黑、非灰的彩色标记像素（如红色、蓝色等）。
- 在灰色框的外部，散布着若干与框内标记颜色相同的单独彩色像素（种子点），每个种子点恰好与某个灰色框的某条边在正交方向上对齐（即种子点与框边在同一行或同一列上）。

Rule:
- 每个种子点根据颜色匹配到内部含有相同颜色标记的灰色框。
- 从种子点出发，沿正交方向（朝向其匹配框的最近边）画一条直线，直到碰到灰色框的外壁为止，路径用种子点的颜色绘制。
- 在灰色框壁上与路径相交的那个像素处"打开入口"：将该灰色像素替换为种子点的颜色。
- 从入口进入框内，沿同一方向继续直线延伸，直到碰到框内的彩色标记像素为止，路径同样用该颜色绘制。
- 其余所有像素保持不变。

Key insight:
框内的标记像素既指定了灌注颜色（用于匹配外部种子），也是路径的终止锚点；种子点与框边的对齐关系决定了入口位置和路径方向，形成从外到内的贯穿连线。
</new_puzzle>

<new_puzzle>
将网格中分散的彩色碎片按照隐含的拼图边缘齿形进行互锁拼合，齿形方向决定拼合顺序。

Input structure:
- 背景为黑色。
- 网格中有若干矩形彩色块（每块为单一颜色的填充矩形），彼此分离。
- 每个矩形块的某一条边上有一个突出的单像素凸起（齿），或者在某一条边上有一个凹进去的单像素缺口（槽）。
- 每对可拼合的块中，一个块的齿与另一个块的槽颜色相同、大小匹配，且齿和槽分别位于面对面的两条边上（如一个块的右边有齿，另一个块的左边有槽）。

Rule:
- 识别所有齿-槽配对：同色的两个矩形块，一个在某边有齿、另一个在对面边有槽。
- 将有齿的块平移，使齿恰好嵌入槽中（齿像素填入槽像素的位置），两个块的对应边紧贴。
- 有槽的块保持位置不变，有齿的块移动到拼合位置。
- 拼合后输出紧凑裁剪（去掉多余的黑色边框行列）。
- 若有多对拼合，按从上到下、从左到右的顺序依次处理槽块的位置。

Key insight:
凸起齿和凹陷槽不仅指示哪两个同色块应该拼合，还通过齿/槽所在的边确定平移方向；解题者需要先识别齿和槽的对应关系（颜色匹配 + 边朝向互补），再确定移动方向和距离。
</new_puzzle>

<new_puzzle>
用"信号塔"像素向四个正交方向广播颜色射线，射线遇到"滤色墙"时变色继续传播。

Input structure:
- 背景为黑色。
- 网格中有若干孤立的彩色单像素点，称为"信号塔"。
- 网格中还有若干由两个不同颜色像素组成的正交相邻对（水平或垂直排列的两像素），称为"滤色墙"。滤色墙中靠近信号塔方向的像素颜色称为"输入色"，另一个像素颜色称为"输出色"。

Rule:
- 每个信号塔向上、下、左、右四个方向发射射线，射线颜色初始为信号塔本身的颜色。
- 射线沿直线传播，将沿途的黑色背景像素染为当前射线颜色。
- 当射线碰到滤色墙时：如果射线当前颜色与滤色墙的"输入色"匹配，则射线穿过滤色墙，从另一侧以"输出色"继续传播；如果颜色不匹配，射线在滤色墙前停止。
- 当射线碰到另一个信号塔或网格边界时停止。
- 两条射线交叉时，后到的射线覆盖先到的（按信号塔从上到下、从左到右的顺序处理）。

Key insight:
滤色墙的两像素排列方向和顺序编码了颜色转换的方向性（哪一侧是输入、哪一侧是输出），解题者必须同时推断出射线传播规则和滤色墙的方向性变色机制，形成两层独立的推理。
</new_puzzle>

<new_puzzle>
根据每个封闭区域的边框形状（矩形 vs 非矩形）选择不同的内部填充策略：矩形区域做棋盘格填充，非矩形区域做洪水单色填充。

Input structure:
- 背景为黑色。
- 网格中有若干由灰色像素围成的封闭区域（灰色像素形成闭合边界，内部为黑色）。
- 部分封闭区域的灰色边框构成完美矩形（即边框恰好是一个矩形环），其余区域的边框为不规则形状（如L形、T形或其他非矩形多边形）。
- 每个封闭区域的灰色边框上恰好有一个非灰色的彩色标记像素（如红色、蓝色等），嵌在边框线中。

Rule:
- 对于边框为完美矩形的封闭区域：用标记像素的颜色和黑色交替填充内部，形成棋盘格图案（标记像素所在角落的内部相邻像素为标记颜色，然后交替排列）。
- 对于边框为非矩形的封闭区域：将内部所有黑色像素全部填充为标记像素的颜色（纯色洪水填充）。
- 灰色边框本身和标记像素保持不变。

Key insight:
解题者需要完成两层推理：第一层是判断每个灰色边框是否构成完美矩形（需要检查边框几何形状），第二层是根据形状分类应用不同的填充模式。边框上的彩色标记同时提供了填充颜色和棋盘格的起始相位。
</new_puzzle>

<new_puzzle>
在嵌套的同心矩形框中，按照从外到内的层级关系依次传递颜色，每层框的颜色由其直接外层框和一个全局"色环"顺序决定。

Input structure:
- 背景为黑色。
- 网格中有若干组同心矩形框（每组由多个矩形环嵌套而成，矩形环之间有黑色间隔）。
- 每组同心框中，最外层的矩形框有明确的颜色（如红色、蓝色等），内层的矩形框全部为灰色。
- 在网格的某个角落（如左上角），有一个小的水平色条序列作为"色环图例"，由若干不同颜色像素排成一行，定义了颜色的循环顺序。

Rule:
- 读取色环图例中的颜色顺序（如：红、蓝、绿、黄，则颜色按此顺序循环）。
- 对于每组同心框，最外层框的颜色已知。在色环中找到该颜色的位置，然后按色环顺序依次为每一层内部灰色框赋色（第二层取色环中下一个颜色，第三层再取下一个，循环使用）。
- 将每层灰色框重新着色为对应的色环颜色。
- 色环图例本身在输出中保持不变。

Key insight:
解题者需要三层推理：首先识别角落的色条是颜色循环的图例而非装饰；其次发现同心框的层级嵌套关系（从外到内的顺序）；最后将外层框的已知颜色作为色环的起始索引，推导出内层各框应有的颜色。色环的循环特性使得不同起始颜色的框组产生不同的内层配色方案。
</new_puzzle>

<new_puzzle>
将散落的彩色线段"折叠"到网格中唯一的矩形框内，折叠轴由线段与框边的接触点决定。

Input structure:
- 背景为黑色。
- 网格中央有一个由灰色像素围成的空心矩形框（内部为黑色），框线宽度为1像素。
- 在矩形框的外部，有若干彩色直线段（水平或垂直），每条线段的一个端点恰好紧贴矩形框的某条外边（与灰色边框正交相邻）。

Rule:
- 每条外部线段以其与灰色框接触的那个端点为铰链，沿铰链做90度折叠，"翻入"矩形框内部。
- 折叠方向：线段从框外翻转到框内。具体地，水平线段接触框的左边或右边时，折叠后变为垂直线段向框内延伸；垂直线段接触框的上边或下边时，折叠后变为水平线段向框内延伸。
- 折叠后的线段保持原来的颜色和长度（像素数不变），从铰链点沿新方向在框内绘制。
- 若折叠后的线段超出框的内部范围，则在框的对面内壁处截断。
- 外部原始线段被擦除（变为黑色），灰色框保持不变。

Key insight:
解题者必须识别出线段端点与框边的接触关系决定了折叠铰链的位置，然后理解折叠操作本质上是将水平运动转换为垂直运动（或反之），铰链点是不动点。这不是简单的平移或旋转，而是以接触点为轴的90度反射折叠。
</new_puzzle>

<new_puzzle>
网格中的彩色"种子"像素按照各自颜色的专属生长规则（正交扩展 vs 对角扩展）同时生长，当两种颜色的生长区域相遇时，用第三种颜色标记边界。

Input structure:
- 背景为黑色。
- 网格中有若干孤立的彩色单像素点，仅使用两种前景色（如红色和蓝色）。
- 网格的某个边缘（如底部一行）有一个两像素的图例：一个红色像素旁边紧邻一个该题使用的"边界色"像素（如黄色），表示红蓝相遇时用黄色标记。

Rule:
- 第一种颜色（如红色）的种子向四个正交方向（上下左右）同时扩展，每步扩展一层，将相邻的黑色背景像素染为红色。
- 第二种颜色（如蓝色）的种子向四个对角方向同时扩展，每步扩展一层，将对角相邻的黑色背景像素染为蓝色。
- 两种颜色同时逐步生长。当某一步中，一个颜色试图染色的像素已经被另一个颜色占据，或两种颜色在同一步试图占据同一个黑色像素，则该像素被标记为边界色（如黄色）。
- 生长持续直到所有黑色背景像素都被填充或标记为边界色。
- 图例本身保持不变。

Key insight:
两层推理缺一不可：第一层需要发现两种颜色采用不同的扩展拓扑（正交 vs 对角），这决定了各自的生长形态（菱形 vs 方形）；第二层需要理解同步生长下的碰撞机制和边界色的含义。图例中的颜色邻接关系暗示了边界色的角色。
</new_puzzle>
