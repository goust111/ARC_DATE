- `description`：在分层网格中，每层的前景图案充当下一层的遮罩模版，逐层级联过滤后输出末层的残留结果。
- `Input structure`：
  - 网格被等宽的 maroon 垂直分隔线分为三个并排面板（从左到右称为第1层、第2层、第3层）。
  - 每个面板大小完全相同，背景为 black。
  - 第1层包含若干由某种颜色（如 red）绘制的4-连通前景区域。
  - 第2层包含若干由另一种颜色（如 green）绘制的4-连通前景区域。
  - 第3层包含若干由第三种颜色（如 yellow）绘制的4-连通前景区域。
  - 三层中的前景图案形状各异，彼此有部分位置重叠、部分不重叠。
- `Rule`：
  - 将第1层前景像素的位置集合作为遮罩，应用到第2层：仅保留第2层中与第1层前景位置重合的像素，第2层其余前景像素清除为 black。
  - 将经过上一步过滤后第2层残留前景像素的位置集合作为新遮罩，应用到第3层：仅保留第3层中与该新遮罩位置重合的像素，第3层其余前景像素清除为 black。
  - 输出为单个面板大小的网格，内容为最终过滤后的第3层图案，保留第3层原有颜色，背景为 black。
- `Key insight`：三层面板构成级联过滤管道——第1层是第2层的筛子，第2层被筛后又变成第3层的筛子。解题者必须识别逐层遮罩传递关系，而非简单的三层叠加或交集运算。
</new_puzzle>

- `Input structure`：
  - 背景为 azure。
  - 网格中散布偶数个4-连通彩色碎片。碎片两两同色，不同对颜色不同。
  - 同色的两个碎片形状互补：将二者的边界框对齐后，两个碎片的像素并集恰好填满整个边界框，无重叠、无空隙。
  - 每个碎片的边界框尺寸与其配对碎片相同。
- `Rule`：
  - 找到所有同色碎片对。
  - 对每对碎片，将两者边界框对齐叠加，得到一个完整的实心矩形，颜色为该对碎片的颜色。
  - 计算每个矩形的面积（宽 x 高）。
  - 构建输出网格：将所有矩形按面积从小到大、从上到下紧密排列，每个矩形左对齐，矩形之间无间距。输出宽度等于最宽矩形的宽度，高度等于所有矩形高度之和，空余位置填充 azure。
- `Key insight`：同色碎片不是冗余——它们是互补拼图碎片。解题者需先发现互补配对关系、将碎片在脑中合并为矩形，再根据面积排序输出，这是两步独立的非平凡推理。

- `Input structure`：
  - 背景为 black。
  - 网格中有若干由 blue 像素围成的封闭矩形房间（边框宽度1像素）。房间之间互不重叠。
  - 每个房间的边框上恰好有一个1像素缺口（"门"）。
  - 每个房间内部有一个小型实心矩形物体（1-3像素宽或高），颜色为非 blue、非 black 的某种颜色，各房间物体颜色互不相同。
- `Rule`：
  - 确定门所在边：上边框缺口 → 朝上，下边框 → 朝下，左边框 → 朝左，右边框 → 朝右。
  - 计算物体在**垂直于门朝向**方向上的像素跨度 L。例如门朝上或朝下时，L = 物体的高度（行数）；门朝左或朝右时，L = 物体的宽度（列数）。
  - 清除房间内的物体像素。
  - 从门缺口紧邻外侧开始，沿门朝向绘制一条长度为 L、宽度为1像素的直线，颜色为该物体颜色。
  - 房间边框（含缺口）保持不变。
- `Key insight`：门的方位编码弹射方向，而物体在正交方向上的尺寸编码射线长度——两个信息分别来自房间结构和物体形状，需要组合推理才能确定输出。

- `Rule`：
  - 内部线段的方向确定填充轴：水平线段 → 水平方向堆叠，垂直线段 → 垂直方向堆叠。

  - 统计与该围栏内线段同色的外部游离像素数量 N，清除这些游离像素。

- `Key insight`：围栏内的线段方向编码填充轴，缺口位置编码填充朝向，外部同色像素数量编码填充深度。三个独立线索需要从不同结构元素中分别提取并组合。

- `Input structure`：
  - 背景为 black。

  - 箭头结构：以中心像素为核心，沿指向方向延伸2个像素（中心 + 前方1格），同时在中心像素的两侧（垂直于指向方向）各延伸1个像素作为侧翼。共5像素组成T形，其中T的竖笔朝向即为箭头指向。
  - 每个箭头的指向为上、下、左、右之一。
- `Rule`：
  - 对每个箭头 A，沿其指向方向做射线搜索，找到射线上命中的第一个其他箭头 B（射线碰到 B 的任意像素即可），形成有向边 A → B。
  - 沿有向边构建链：找到链首（不被任何箭头指向的箭头），依次跟随有向边直到链末端（其射线上无其他箭头）。
  - 在链末端箭头的边界框四角外扩1格的位置（即边界框外扩后矩形的四个顶角位置），各放置1个像素，颜色为链首箭头的颜色。
  - 链首和链中间的箭头保持不变。
- `Key insight`：箭头的T形缺口方向编码指向，指向决定链接关系。解题者需要三步推理：先从形状解读指向方向，再沿射线构建传递链，最后将链首颜色信息传递标记到链末端。

- `Input structure`：
  - 背景为 black。
  - 网格中有一个由 grey 像素构成的连通管道网络，管道宽度恒为1像素，由若干水平和垂直路径组成，路径在交叉点相交。
  - 管道网络的若干死端（度为1的末梢像素）旁各有一个不同颜色的单像素"种子"（4-相邻于该末梢灰色像素），种子颜色互不相同且不含 grey 和 black。
  - 并非所有死端都有种子。
- `Rule`：
  - 所有种子同时从各自相邻的管道末梢开始，沿灰色管道向内扩散，每步将1个相邻的 grey 像素重新着色为自身颜色。
  - 扩散同步进行（所有种子同时各走一步）。
  - 当两个不同颜色的扩散前锋同时到达同一个 grey 像素时，该像素保持 grey 不变，成为边界。
  - 扩散完成后，清除所有种子像素（变为 black）。
  - 输出网格中管道被分段着色，各段之间以 grey 像素为界。
- `Key insight`：管道着色由同步洪水填充决定，而非距离公式。解题者需在脑中模拟同步扩散过程——沿管道路径数格子即可判断每段归属，分界点自然出现在两个种子沿管道等距之处。
</new_puzzle>

  - 网格正中心行和中心列被 red 像素填满，形成十字分隔线，将网格分为四个象限（左上、右上、左下、右下）。

  - 四个端点标记颜色从 {green, yellow, blue, orange} 中各取一个，互不重复。颜色含义：green = 保持原样，yellow = 水平翻转，blue = 垂直翻转，orange = 旋转180度。
  - 每个象限中有一个小型（不超过 3x3）grey 4-连通前景对象。

- `Key insight`：十字末端的四个颜色形成一个行列交叉索引的变换矩阵。解题者需要先破译颜色与操作的对应关系，再理解行列复合机制，两步推理共同决定每个象限的变换结果。

- `description`：根据框架内嵌小方块的颜色查找对应的外部色带图例，用图例中的条纹方向重新填充框架内部。
- `Input structure`：
  - 背景为 black。
  - 网格中有若干大型空心矩形框架（边框颜色各不相同，宽度1像素），框架内部为 black 背景，但每个框架内部的左上角有一个 2x2 的实心小方块，颜色为非框架色的某种颜色。
  - 网格边缘（不与任何框架重叠的区域）有若干"色带图例"：每个图例是一个 3x3 的方格，其边框像素的颜色为某种颜色 C（与某个框架内小方块的颜色 C 一致），内部由 C 色像素组成条纹图案——要么是1像素宽的水平条纹（即中间行填满 C，上下行为 black），要么是1像素宽的垂直条纹（即中间列填满 C，左右列为 black）。
- `Rule`：
  - 对每个框架，读取其内部左上角 2x2 小方块的颜色 C。
  - 在网格边缘找到边框颜色为 C 的 3x3 图例，判断图例内部条纹方向（水平或垂直）。
  - 用颜色 C 按该条纹方向填充框架的全部内部空间：水平条纹则在框架内部每隔一行填一行 C（从内部第一行开始，奇数行填充、偶数行保留 black）；垂直条纹则每隔一列填一列 C（从内部第一列开始，奇数列填充、偶数列保留 black）。
  - 移除原来的 2x2 小方块（被条纹覆盖或清除）。
  - 图例保持不变。
- `Key insight`：框架内的小方块是颜色索引键，用于关联外部图例；图例的条纹方向决定框架的填充模式。解题者需要先建立"小方块颜色 → 图例"的映射，再从图例中提取方向信息，两步查找缺一不可。
</new_puzzle>
