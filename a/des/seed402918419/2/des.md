- `description`：根据边框形状内嵌的缺口方向确定颜色传递链，将每个容器的填充色沿链传递给下一个容器。

- `Input structure`：
  - 背景为黑色（black）。
  - 网格中散布若干大小相同的矩形"容器"，每个容器由某种颜色的边框围成，内部填充另一种纯色。
  - 每个容器的边框在上、下、左、右四边之一有一个恰好 1 像素宽的缺口（缺口处露出背景色）。
  - 所有容器的边框颜色互不相同，且每个容器的填充色恰好等于另一个容器的边框颜色，从而形成唯一的有向环。

- `Rule`：
  - 第一步（建链）：对每个容器，找到其缺口所在的方向（上/下/左/右），沿该方向在网格中寻找最近的另一个容器，确定为该容器的"接收者"。
  - 第二步（传色）：将每个容器当前的填充色传递给它的接收者：接收者的内部填充色被替换为发送者的原始填充色。
  - 边框保持不变，缺口保持不变。若某个容器同时作为多个容器的接收者，以距离最近的发送者的填充色为准。

- `Key insight`：缺口方向决定传递目标（空间寻址），填充色决定传递内容；解题者需要先从缺口方向推断出容器之间的有向连接关系，再沿这些连接执行颜色搬运——两层推理缺一不可。
</new_puzzle>

- `description`：将散落的碎片拼入模板中匹配的空洞，但每个碎片需先按其标记像素指示的次数旋转 90 度。

- `Input structure`：
  - 背景为黑色（black）。
  - 一个由灰色（grey）构成的大型模板形状占据网格中央，模板内部有若干矩形空洞（露出背景色）。
  - 模板外部散布若干小型彩色碎片（sprite），每个碎片由某种非灰非黑颜色的像素构成一个形状。
  - 每个碎片旁边紧邻（8 连通）有若干红色（red）标记像素，标记像素数量为 1、2 或 3。

- `Rule`：
  - 第一步（旋转）：读取每个碎片旁边红色标记像素的数量 N，将该碎片顺时针旋转 N×90 度。
  - 第二步（匹配放置）：旋转后的碎片边界框尺寸与模板中某个空洞的尺寸精确匹配；将碎片放入对应空洞中。
  - 输出为模板区域的紧凑裁剪，所有空洞被碎片填满，红色标记像素在输出中不出现。

- `Key insight`：碎片的原始形状无法直接匹配任何空洞——必须先通过相邻红色像素数量确定旋转量，旋转后才能与空洞尺寸配对。旋转编码层与尺寸匹配层构成双重推理。
</new_puzzle>

- `description`：在分区网格中，根据每个区域内"种子"像素的颜色查找同色边框的图例区域，再用图例区域内的图案填充对应分区。

- `Input structure`：
  - 背景为黑色（black）。
  - 网格被橙色（orange）的十字线分割成若干大小相等的矩形区域（如 3x3 或 4x4 的分区格局）。
  - 大部分分区内部为空（全黑），但各含有一个单独的彩色"种子"像素，位于该分区内的某个位置。
  - 网格边缘（最外圈的分区）中有若干"图例区域"：每个图例区域没有种子像素，而是包含一个由某种颜色构成的小型图案（pattern），且该图例区域的四边橙色边框中有一段被替换为另一种特定颜色。

- `Rule`：
  - 第一步（颜色查找）：对每个含种子像素的空分区，读取种子的颜色 C。
  - 第二步（图例匹配）：在边缘图例区域中，找到边框被替换颜色等于 C 的那个图例。
  - 第三步（图案填充）：将该图例区域内的图案复制到种子所在的空分区中，图案在分区内居中对齐，图案颜色保持图例中的原色不变。
  - 种子像素在输出中被移除（被图案覆盖或变为黑色），橙色分隔线保持不变。

- `Key insight`：种子颜色不是直接用于绘制的颜色，而是用于在图例边框中查找匹配的索引键；图例边框上的彩色替换段是查找入口，图例内部的图案才是填充内容。这构成了"颜色→边框索引→图案内容"的三层间接映射。
</new_puzzle>

- `description`：识别每个对象的对称类型，按对称类型分组后，将同组对象堆叠合并为一个复合形状。

- `Input structure`：
  - 背景为黑色（black）。
  - 网格中散布若干个由不同颜色构成的小型 4 连通对象，对象之间互不接触。
  - 每个对象属于以下三种对称类型之一：仅有水平对称轴、仅有垂直对称轴、同时具有水平和垂直对称轴（含正方形等高度对称形状）。
  - 同一对称类型的对象数量相同（例如每种类型各 2 个）。

- `Rule`：
  - 第一步（分类）：将所有对象按其对称类型分为三组。
  - 第二步（排列合并）：将每组内的对象按其在输入中从上到下、从左到右的出现顺序，在输出中紧密水平排列（对象之间无间隔），形成一个合并行。
  - 第三步（输出布局）：三组合并行按"双轴对称组在顶行、水平对称组在中行、垂直对称组在底行"的固定顺序从上到下排列，行间留一行黑色背景。输出宽度为最宽合并行的宽度，不足的行右侧用黑色填充。

- `Key insight`：表面上对象的颜色和位置各不相同，但真正的分组依据是形状的对称性质——解题者必须识别每个对象的对称类型才能确定分组，再根据分组规则完成排列。对称性分类是一个需要主动推理的非显然步骤。
</new_puzzle>

- `description`：沿彩色路径传播信号，路径交叉处根据两条路径颜色的混合规则生成新颜色。

- `Input structure`：
  - 背景为黑色（black）。
  - 网格中有若干条由不同颜色构成的单像素宽直线路径（水平或垂直），路径从网格一边延伸到另一边。
  - 每条路径的一个端点处（紧贴网格边缘）有一个与路径颜色不同的"信号源"像素。
  - 部分路径在网格内部相互交叉，交叉处原本为背景色。

- `Rule`：
  - 第一步（信号传播）：从每个信号源出发，沿其所在路径的方向传播，将路径上的所有像素替换为信号源的颜色。信号源本身也保留。
  - 第二步（交叉混色）：在两条路径的交叉点处，该像素同时被两个信号覆盖。交叉点的最终颜色取决于两个信号色：如果两个信号色相同，则交叉点为该颜色；如果不同，则交叉点变为绿色（green）。
  - 路径的原始颜色在输出中完全被信号色覆盖。无信号源的路径（如果存在）保持原色不变。

- `Key insight`：解题者首先需要区分"路径色"和"信号源色"——信号源是路径端点处颜色不同的那个像素；然后需要理解信号沿路径覆盖传播的方向性；最后需要发现交叉点的特殊混色规则。路径本身的颜色是干扰信息，真正决定输出的是信号源颜色及其传播。
</new_puzzle>

- `description`：根据封闭区域内的标记像素数量，从外向内逐层剥离边框并重新着色，层数由标记数决定。

- `Input structure`：
  - 背景为黑色（black）。
  - 网格中有若干个由灰色（grey）像素构成的实心矩形区域，大小各异。
  - 每个矩形内部散布若干个蓝色（blue）标记像素，数量为 1 到 3 不等。
  - 网格边缘有一个小型颜色图例：一行包含 3 个相邻像素，从左到右分别为红色（red）、黄色（yellow）、绿色（green），表示第 1 层、第 2 层、第 3 层的着色。

- `Rule`：
  - 读取每个矩形内蓝色标记像素的数量 N（1、2 或 3）。
  - 对该矩形执行 N 层"剥壳着色"：第 1 层将矩形最外圈像素着色为图例第 1 色（红色）；第 2 层将去掉最外圈后的新最外圈着色为图例第 2 色（黄色）；第 3 层类推着色为图例第 3 色（绿色）。
  - 剥壳后剩余的内部像素保持灰色不变。
  - 蓝色标记像素在输出中被移除（变为其所在层应有的颜色）。

- `Key insight`：标记数量不仅是一个计数值，还控制了空间变换的深度——同样的灰色矩形因内部标记数不同而产生不同层数的彩色边框嵌套。解题者需要将"数标记"与"逐层剥壳着色"这两个看似无关的操作关联起来。
</new_puzzle>

- `description`：在网格中找到"钥匙"形状与"锁"形状的互补配对，将钥匙平移插入锁中，完成后用锁的颜色统一填充合并区域。

- `Input structure`：
  - 背景为黑色（black）。
  - 网格中有若干对对象：每对包含一个"锁"（由某种颜色 A 构成的矩形，内部有一个不规则形状的黑色缺口）和一个"钥匙"（由另一种颜色 B 构成的不规则形状，独立存在于网格其他位置）。
  - 每把钥匙的形状恰好与某个锁的缺口形状完全互补（形状相同、大小相同）。
  - 每个锁的边框上有一个由颜色 B（与配对钥匙同色）构成的单像素"提示点"，指示该锁与哪把钥匙配对。

- `Rule`：
  - 第一步（配对）：对每个锁，找到其边框上提示点的颜色 B，在网格中找到颜色为 B 的钥匙对象。
  - 第二步（验证互补）：确认该钥匙的形状与锁的缺口形状互补（即钥匙恰好能填满缺口）。
  - 第三步（合并）：将钥匙的形状平移到锁的缺口位置中，填入后整个矩形区域变为完整的实心矩形，颜色统一使用锁的边框颜色 A。
  - 钥匙原始位置的像素清除为背景色。提示点在输出中变为锁的颜色 A。

- `Key insight`：提示点的颜色是"配对密钥"——它将锁与钥匙通过颜色间接关联，而非通过空间邻近性。解题者需要先通过颜色匹配找到配对关系，再通过形状互补验证配对的正确性，最后执行平移填充。
</new_puzzle>

- `description`：根据箭头指向选择源图案，再根据箭头长度决定图案的缩放倍数，最终在箭头尖端位置绘制缩放后的图案。

- `Input structure`：
  - 背景为黑色（black）。
  - 网格角落有若干个小型彩色图案（每个图案由不同颜色构成，占据 2x2 或 3x3 的区域），每个图案旁标注了一个与图案同色的单像素标签点，位于图案正上方一格处。
  - 网格中央区域有若干个由灰色（grey）像素构成的"箭头"：每个箭头是一条单像素宽的直线段（水平或垂直），末端有一个与某图案同色的像素作为箭头尖端。箭头的起始端为灰色像素。
  - 箭头的长度（灰色像素数量）为 1、2 或 3。

- `Rule`：
  - 第一步（选图案）：每个箭头尖端的颜色 C 指向角落中标签色为 C 的图案。
  - 第二步（定倍数）：箭头中灰色像素的数量 N 即为缩放倍数——将选中的图案每个像素扩展为 N×N 的方块。
  - 第三步（绘制）：以箭头尖端像素为锚点（缩放图案的最近角对齐到尖端），在网格上绘制缩放后的图案。箭头本身（灰色像素和尖端像素）在输出中被图案覆盖或保留在图案下方。

- `Key insight`：箭头同时编码了两个独立信息——尖端颜色选择"画什么"，灰色段长度决定"画多大"。解题者需要分别破解这两层编码才能完成变换。
</new_puzzle>
