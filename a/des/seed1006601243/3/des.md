根据封闭区域内部的色块分布，选择匹配的外部模板，将模板旋转到正确朝向后覆盖填充该区域。

Input structure:
- 背景色为 black。
- 网格中有若干由同一颜色（如 grey）绘制的封闭矩形框，每个框的内部包含少量散落的彩色像素点（每个框内只用一种非背景、非框色的颜色）。
- 网格中还有若干与框大小相同的独立彩色小图案（模板），每个模板由单一颜色绘制在 black 背景上，模板的颜色与某个框内部散落像素的颜色一一对应。
- 每个模板内恰好包含与对应框内部像素数量相同的填充像素，但模板可能处于四种旋转状态（0°/90°/180°/270°）之一。

Rule:
- 通过颜色匹配，将每个模板与其对应的封闭框配对。
- 确定模板需要旋转多少度才能使模板中的填充像素位置与框内部已有的散落像素位置完全重合——即框内已有的像素是模板的一个子集，用于锚定旋转朝向。
- 找到唯一正确的旋转后，将完整模板（旋转后）覆盖到框的内部区域，替换原有内容。
- 输出网格中，框的边框保持不变，框内部显示旋转后的完整模板图案。

Key insight:
框内部的散落像素并非随机装饰，而是旋转后模板的部分像素"泄露"——它们充当锚点，唯一确定模板的旋转角度。解题者需要先通过颜色匹配找到配对关系，再通过子集匹配确定旋转方向，这是两层独立的非平凡推理。
</description>

<description>
在网格中识别多条交叉的隐含路径，根据路径交叉点的重叠规则混合颜色，生成最终的输出网格。

Input structure:
- 背景色为 black。
- 网格的四条边上各有若干彩色像素点作为"端口"，每个端口有一种非背景颜色。
- 同一颜色恰好出现两个端口（分布在不同边上），形成一对。
- 网格内部完全为 black 背景，没有其他元素。

Rule:
- 每对同色端口之间用直角折线路径连接：路径从一个端口出发，沿该端口所在边的垂直方向向内延伸，然后转弯（仅一次直角转弯），再沿另一端口所在边的垂直方向到达第二个端口。路径宽度为 1 像素。
- 如果两个端口在相对的两条边上且处于同一行或同一列，则路径为一条直线，无需转弯。
- 每条路径用其对应的端口颜色绘制。
- 当两条路径在某个像素位置交叉时，该像素使用网格中存在的、既不属于这两条交叉路径颜色的第三种端口颜色来绘制。如果网格中只有两种端口颜色，则交叉点用 grey 绘制。
- 如果三条或更多路径交叉于同一点，该像素用 grey 绘制。

Key insight:
路径的走法本身是确定的（由端口位置和直角折线规则唯一确定），但真正的推理难度在于交叉点的颜色混合规则：解题者需要先理解路径的生成方式，然后发现交叉点颜色并非简单覆盖，而是遵循一种"互补选择"机制——交叉点取场上第三种颜色。这两层规则需要分别从样例中归纳。
</description>

<description>
将散落的彩色碎片按照隐含的层级关系堆叠到目标区域中，层级由碎片的面积决定，面积大的在下、面积小的在上，重叠处小碎片遮挡大碎片。

Input structure:
- 背景色为 black。
- 网格左半部分包含一个由 grey 绘制的矩形目标框（框线为 1 像素宽，内部为 black）。
- 网格右半部分散落着若干彩色碎片（每个碎片是一个连通的非背景色块，各碎片颜色互不相同）。每个碎片的外接矩形尺寸与目标框内部尺寸完全相同。
- 目标框的内部还包含若干单像素的彩色标记点，每个标记点的颜色与右侧某个碎片颜色相同。

Rule:
- 每个碎片需要被放置到目标框内部。放置方式：将碎片平移，使碎片的外接矩形与目标框内部区域完全对齐。
- 碎片的堆叠顺序由碎片的面积（即碎片包含的非背景像素数量）决定：面积最大的碎片最先放置（最底层），面积最小的最后放置（最顶层）。
- 堆叠时，后放置的碎片会遮挡先放置的碎片——即在重叠位置，显示后放置碎片的颜色。
- 目标框内部的单像素标记点在堆叠前被清除（不参与最终输出）。
- 输出仅包含目标框及其内部堆叠后的结果（裁剪为目标框区域）。

Key insight:
标记点的作用是干扰项与验证线索的双重角色——它们的位置恰好是对应碎片中非空像素的位置之一，帮助解题者确认碎片与框的对齐方式，但堆叠顺序必须通过比较碎片面积来推断。解题者需要先发现"碎片外接矩形等于框内部尺寸"这一对齐规则，再发现"面积决定层级"这一堆叠规则，构成两层独立推理。
</description>

<description>
识别网格中由边框颜色编码的嵌套矩形，根据嵌套层数对最内层区域进行对应次数的几何翻转变换。

Input structure:
- 背景色为 black。
- 网格中包含若干组嵌套矩形结构。每组结构由若干同心矩形框组成，每个框用不同颜色绘制，框线宽度均为 1 像素。
- 最内层矩形框的内部包含一个由多种颜色组成的小型非对称图案（图案在四种旋转和两种翻转下均不相同，以便区分变换结果）。
- 不同组的嵌套矩形具有不同的嵌套层数（例如一组有 1 层外框，另一组有 2 层外框，第三组有 3 层外框）。

Rule:
- 对于每组嵌套矩形，计算包围最内层图案的矩形框的层数 N（不含最内层图案本身，仅计外框数量）。
- 对最内层图案执行 N 次翻转操作：第奇数次执行水平翻转（左右镜像），第偶数次执行垂直翻转（上下镜像）。即：1 层 → 水平翻转一次；2 层 → 先水平翻转再垂直翻转；3 层 → 水平、垂直、水平；以此类推。
- 输出网格与输入网格尺寸相同，所有矩形框保持不变，仅最内层图案被替换为变换后的结果。

Key insight:
解题者首先需要识别嵌套矩形的层级结构并准确计数外框层数，然后需要发现层数与翻转次数及翻转轴交替规则之间的对应关系。由于图案是非对称的，不同的翻转序列产生不同的结果，解题者必须从样例中归纳出"奇数次水平、偶数次垂直"的交替规律，而非简单的"翻转 N 次"。这构成了"计数嵌套层"→"推断交替翻转规则"两层非平凡推理。
</description>
</new_puzzle>

<description>
根据种子色块的形状在网格中生长出分形树状结构，生长方向由种子与边界的相对位置决定，分支规则由种子的几何特征编码。

Input structure:
- 背景色为 black。
- 网格中散布着若干小型彩色色块（种子），每个种子是一个由单一颜色构成的连通区域，占据 2 到 5 个像素，形状各不相同（如 L 形、T 形、直线形、方块形等）。
- 每个种子的颜色互不相同。
- 网格的某一条边（上、下、左或右）上有一条与该边平行的 1 像素宽的 grey 色带作为"地面线"。

Rule:
- 每个种子从其位置向"地面线"方向生长出一条主干线：主干线的颜色与种子相同，从种子最靠近地面线的像素出发，沿垂直于地面线的方向逐像素延伸，直到到达地面线。
- 主干线的分支规则由种子的宽度（沿平行于地面线方向的像素跨度）决定：在主干线上，每隔"宽度"个像素产生一对水平分支（向左和向右各延伸，长度等于种子的高度，即沿垂直于地面线方向的像素跨度）。
- 分支在遇到其他种子的主干线或已有分支时停止（不覆盖其他颜色的像素）。
- 种子本身保留在原位不变。
- 如果两个种子在同一行或同一列（取决于地面线方向），它们的主干线共线，则按距离地面线较近的种子优先——较近种子的主干线在交汇点截断较远种子的主干线。

Key insight:
解题者需要经历三层推理：（1）识别地面线位置以确定生长方向；（2）发现种子的"宽度"属性控制分支间距；（3）发现种子的"高度"属性控制分支长度。宽度和高度的定义取决于地面线方向（平行 vs 垂直），这使得规则在不同样例间需要灵活适应，增加了归纳难度。种子形状不仅是视觉标识，更是编码生长参数的信息载体。
</description>
</new_puzzle>
