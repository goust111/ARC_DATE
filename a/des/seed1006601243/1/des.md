<description>
根据框架边缘的颜色标签，将散落的彩色碎片旋转后嵌入中央拼图板的对应凹槽中，碎片的朝向由凹槽开口方向决定。

Input structure:
- 背景为黑色。网格中央有一个由灰色像素构成的大型矩形"拼图板"，板内开有若干矩形凹槽（凹槽区域为黑色背景）。
- 每个凹槽的开口边（与拼图板灰色边缘相邻的那一侧缺少灰色边框）朝向上、下、左或右中的某一方向。
- 每个凹槽的开口边外侧紧贴着一个单像素的颜色标签（非灰色、非黑色），颜色各不相同。
- 拼图板外围散布着若干彩色碎片（由单一非黑色、非灰色颜色构成的连通小形状），每个碎片的颜色与某个凹槽标签颜色一一对应。
- 每个碎片的外接矩形尺寸与对应凹槽的尺寸相同（可能需要旋转 0°/90°/180°/270° 后才吻合）。

Rule:
- 对每个凹槽，找到颜色标签与之匹配的碎片。
- 确定凹槽的开口方向（即凹槽缺少灰色边框的那一侧朝向）。
- 将碎片旋转到这样的朝向：碎片中像素最密集的那一行或列（即碎片的"重心边"）朝向凹槽的封闭底部（与开口方向相反的一侧）。若碎片关于旋转对称则不需要额外旋转。
- 将旋转后的碎片平移填入凹槽区域，碎片像素替换凹槽内的黑色背景。
- 输出中移除拼图板外部的所有碎片和颜色标签，只保留填充完毕的拼图板。

Key insight: 凹槽的开口方向不仅决定了碎片的配对（通过颜色标签），还决定了碎片需要旋转到的朝向——碎片的"重"的一端必须朝向凹槽的封闭底部，这需要解题者同时推理空间方向和碎片的非对称形状特征。
</description>

<description>
在网格中识别由墙壁围成的封闭房间，根据房间内种子像素的颜色从房间的门洞向外"泛洪"走廊，走廊颜色在经过每道门时按固定调色板循环切换。

Input structure:
- 背景为黑色。蓝色像素构成墙壁，将网格划分为若干封闭矩形房间和连接房间的走廊通道。
- 每个房间的墙壁上有且仅有一个宽度为1的缺口（"门洞"），门洞连通走廊。
- 部分房间内部包含一个单像素的"种子"，颜色为红、绿、黄、橙中的某一种；其余房间内部为纯黑色（空房间）。
- 走廊初始全为黑色背景。
- 网格边缘某处有一行或一列由灰色像素组成的"调色板条"，从左到右（或从上到下）依次排列若干不同颜色的像素，定义了颜色循环顺序。

Rule:
- 从每个有种子的房间出发，种子颜色填充整个房间内部（不覆盖墙壁）。
- 颜色随后从门洞流出进入走廊。走廊中的每个黑色像素被染成当前颜色。
- 当颜色流经走廊到达另一个房间的门洞时，进入该房间之前，颜色切换为调色板条中当前颜色的下一个颜色（循环到末尾则回到开头）。
- 新颜色填充这个新房间（如果它是空房间），然后继续从该房间的其他门洞（如果有）向外扩散，每过一道门再切换一次颜色。
- 如果两股不同颜色的流在走廊中相遇，先到达的颜色保留（即离种子房间门数更少的流优先）。
- 调色板条本身在输出中保留不变。

Key insight: 解题者需要先识别调色板条来确定颜色循环顺序，再理解颜色不是在走廊中渐变，而是在每次穿过门洞时离散地跳变——"门洞计数"决定了最终颜色，而非物理距离。
</description>

<description>
将网格中散落的彩色箭头视为指令，按箭头指向依次推动同色方块滑行，方块在遇到墙壁或其他方块时停止；箭头自身的长度决定该次推动的最大滑行格数。

Input structure:
- 背景为黑色。灰色像素构成固定的墙壁障碍物（可以是任意形状的连通块）。
- 网格中有若干彩色小方块（每个方块是 2×2 的同色正方形），颜色各不相同（如红、绿、黄、橙等）。
- 网格中有若干"箭头"标记。每个箭头由一种颜色的像素组成，形状为一条直线段加上末端的一个三角尖头（三角尖头由3个像素组成：尖端1个像素在最前方，后方一行2个像素）。箭头朝向上、下、左或右。箭头的颜色与某个方块的颜色相同，表示该箭头控制该方块。
- 箭头的"长度"定义为组成直线段部分的像素数（不含三角尖头的3个像素）。
- 同一颜色的方块可能对应多个箭头；箭头按照从上到下、从左到右的顺序依次执行。

Rule:
- 按从上到下、从左到右的顺序处理每个箭头。
- 对于当前箭头，找到与之同色的 2×2 方块，沿箭头指向方向滑动该方块。
- 方块最多滑动的格数等于箭头线段的长度。方块在滑动过程中如果碰到墙壁、网格边界或其他方块（任意颜色），则在碰撞前一格停止。
- 如果方块在滑动方向上紧贴障碍物且无法移动，则该箭头指令无效，方块保持原位。
- 所有箭头处理完毕后，从输出中移除所有箭头标记，只保留墙壁和方块的最终位置。

Key insight: 解题者需要发现两层规则——首先，箭头的颜色决定它控制哪个方块、箭头的朝向决定推动方向；其次，箭头线段部分的像素数量限制了最大滑行距离。由于箭头按空间顺序依次执行，先执行的推动会改变方块位置，从而影响后续箭头的推动结果，解题者必须按正确顺序模拟整个过程。
</description>

<description>
网格中有若干对颜色相同的图案，每对图案之间由通道连接；根据连接通道的转弯次数查阅图例确定染色颜色，将通道路径染成对应颜色。

Input structure:
- 背景为黑色。灰色像素构成迷宫状的墙壁网络，将网格分成互相连通的通道。
- 通道中散布着若干彩色小图案（每个图案是3到5个像素组成的小型连通块）。图案成对出现：每种形状恰好出现两次，且同一对的两个图案形状完全相同（不含旋转和翻转）、颜色也相同。
- 每对图案之间通过通道存在唯一的最短路径（通道设计保证最短路径唯一）。
- 网格边缘有一个"图例区"，由若干行组成，每行包含一个数字形状（用像素绘制的1、2、3等）和紧邻其右侧的一个颜色色块。例如数字"1"旁边是红色色块，数字"2"旁边是绿色色块。

Rule:
- 对每对相同的图案，沿通道找到连接它们的最短路径。
- 数该路径上方向改变的次数（即转弯次数）：直线走不算转弯，每次从水平变为垂直或从垂直变为水平计为一次转弯。
- 查阅图例区：转弯次数对应的数字旁边的颜色即为该对图案的标记颜色。
- 在输出中，将连接该对图案的最短路径上的所有通道像素（不含图案本身）染成该标记颜色。图案本身保持原色不变。
- 未被任何路径经过的通道像素保持黑色。

Key insight: 解题者需要先发现图案是成对匹配的（通过形状和颜色的一致性），再发现路径的转弯次数才是决定染色的关键属性，最后通过图例区将转弯次数映射为具体颜色。三层推理环环相扣：配对 → 计数转弯 → 查图例染色。
</description>

<description>
根据网格中"印章"图案与"画布"区域的叠放关系，推断印章的盖印顺序，并将被遮挡的印章部分补全还原。

Input structure:
- 背景为黑色。网格中有一个大的矩形灰色"画布"区域。
- 画布上有若干彩色图案（"印章印记"），每个印章印记由单一非黑色、非灰色颜色构成，形状为简单的几何形状（如L形、T形、十字形等），大小约为 3×3 到 5×5。
- 印章印记之间存在重叠：后盖的印章会覆盖先盖的印章，导致先盖的印章有部分像素被遮挡而不可见。
- 画布外部的黑色背景区域中，每个印章颜色对应一个完整的"印章模板"——与画布上该颜色印记形状相同的完整图案（无遮挡）。
- 画布右侧或下方有一列彩色像素组成的"顺序条"，从某一端到另一端依次排列各印章颜色，表示从最先盖印到最后盖印的时间顺序。

Rule:
- 通过顺序条确定各印章的盖印先后顺序（条的起始端为最先盖印，末端为最后盖印）。
- 对于画布上的每个印章印记，用画布外对应颜色的完整模板来确定其完整形状。
- 按照盖印顺序从最后一个到第一个（逆序）处理：最后盖印的印章在画布上是完整可见的，不需要补全。
- 对于较早盖印的印章，其被后续印章覆盖的部分在画布上不可见；在输出中，将这些被遮挡的像素补全还原为该印章的颜色。但补全时不能覆盖比它更晚盖印的印章的像素。
- 最终输出是画布区域的内容（所有印章均完整显示，后盖的仍然覆盖在先盖的之上），画布外的模板和顺序条被移除。

Key insight: 解题者首先需要发现顺序条编码了盖印顺序，然后利用画布外的完整模板推断每个印章的完整形状，最后按正确的逆序叠放逻辑补全被遮挡的部分。关键难点在于理解顺序条的含义——它不是简单的颜色图例，而是时间顺序编码，这决定了哪些像素应该被补全、哪些应该保持被覆盖状态。
</description>

<description>
在网格中找到由边框颜色围成的若干"容器"，根据容器底部缺口的位置和宽度，将容器内的彩色液体像素向下泄漏到下方容器中，液体在新容器中重新沉积到底部。

Input structure:
- 背景为黑色。网格中有若干矩形"容器"，每个容器由某种非黑色颜色（如蓝色、绿色等）的像素构成四面边框，内部为黑色或填充有彩色"液体"像素。
- 容器在网格中上下排列（可能有水平偏移），呈现层叠结构。
- 每个容器的底部边框可能有一段连续缺口（即底边某几个像素缺失，露出黑色背景），缺口宽度不等。没有缺口的容器底部完整封闭。
- 容器内部的液体像素颜色与容器边框颜色不同，液体像素紧贴容器底部排列（即液体沉在容器底部，上方为黑色空间）。
- 液体的颜色在同一容器内相同，但不同容器的液体颜色可能不同。

Rule:
- 对于底部有缺口的容器，液体从缺口处向下泄漏。
- 泄漏规则：只有位于缺口正上方的液体列会泄漏。泄漏的液体像素从容器中消失，沿垂直方向下落，进入下方第一个能接住它的容器（即缺口正下方存在另一个容器，且液体落点在该容器的左右边框之间）。
- 泄漏的液体进入下方容器后，与该容器中原有的液体合并，所有液体重新沉积到底部——即液体像素按列从容器底部向上紧密堆叠。
- 如果下方没有容器接住泄漏的液体，则液体消失（流出网格）。
- 底部没有缺口的容器不泄漏，液体保持原位。
- 输出中容器边框保持不变，只有液体像素的位置发生改变。

Key insight: 解题者需要先识别容器底部的缺口位置来判断哪些液体列会泄漏，再追踪泄漏液体的垂直落点确定它进入哪个下方容器，最后理解液体在新容器中会重新按重力沉积到底部。缺口的水平位置同时决定了"哪些液体流出"和"流向哪个容器"，这种双重作用是核心难点。
</description>

<description>
网格中有若干彩色环形轨道和在轨道上的标记点，根据轨道外部指示器的形状确定旋转方向和步数，将轨道上所有标记点沿轨道循环移动。

Input structure:
- 背景为黑色。网格中有若干闭合的矩形环形轨道，每条轨道由单一颜色的像素构成（如蓝色、绿色等），形成一个矩形环（即只有外框一圈像素，内部为黑色）。
- 每条轨道上有若干"标记点"：轨道像素中嵌有少量不同颜色的像素（如红色、黄色），这些标记点位于轨道环上。
- 每条轨道的外部紧邻处有一个"指示器"，由灰色像素组成。指示器是一个小型的L形或直线形图案：
  - 如果指示器为顺时针方向的L形（即从水平段到垂直段的转弯方向为顺时针），则该轨道上的标记点沿顺时针方向移动。
  - 如果指示器为逆时针方向的L形，则标记点沿逆时针方向移动。
- 指示器的L形由两段组成，其中较长一段的像素数即为标记点移动的步数。

Rule:
- 对每条轨道，找到与之紧邻的灰色指示器。
- 根据指示器L形的朝向判断旋转方向（顺时针或逆时针）。
- 数指示器较长一段的像素数量 N。
- 将该轨道上的所有标记点沿轨道环移动 N 步（沿矩形环的边按顺时针或逆时针方向，每步移动到轨道上的下一个相邻像素位置）。
- 标记点移动后，原位置恢复为轨道本身的颜色，新位置显示标记点的颜色。
- 指示器在输出中保留不变。

Key insight: 解题者需要同时解读两层信息——指示器L形的弯曲方向编码了旋转方向，而指示器较长臂的长度编码了移动步数。将这两个参数正确提取并应用到对应轨道上的标记点循环移动，需要解题者建立"形状方向→旋转方向"和"长度→步数"的双重映射。
</description>
</new_puzzle>
