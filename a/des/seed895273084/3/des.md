<description>
根据彩色种子像素在封闭区域内的位置，用该颜色沿区域边界内侧生长出与种子到最近边界距离等长的色带。

Input structure:
- 背景色（bg）填充大部分网格。
- 若干由同一种非bg颜色（如 Grey）绘制的封闭矩形轮廓（1像素宽边框），彼此不重叠。
- 每个矩形内部恰好有一个彩色种子像素（颜色各不相同，如 Red、Blue、Green 等），位于矩形内部的某个位置，其余内部为 bg。

Rule:
- 对每个封闭矩形，找到其内部的种子像素。
- 计算种子像素到矩形四条内边界的最短距离 d（以像素格数计）。
- 从矩形内边界向内生长 d 层厚度的色带，颜色为种子像素的颜色。色带沿矩形内壁向内填充 d 层（类似嵌套的矩形环），种子像素本身也包含在内。
- 色带之内剩余的中心区域保持 bg 不变。
- 矩形边框（Grey）保持不变。

Key insight: 种子像素的位置编码了填充厚度——它离最近边界越远，色带越厚；解题者需要发现"种子到边界最短距离 = 内壁色带层数"这一非显然映射。
</description>
</new_puzzle>

<new_puzzle>
<description>
将散布在网格中的彩色碎片按形状配对后合并为完整矩形，合并方向由两片各自缺失角的朝向决定。

Input structure:
- 背景色（bg）占据大部分网格。
- 若干彩色碎片散布在网格上，每个碎片是一个矩形缺了一个直角矩形块后的L形或凹形。
- 碎片成对出现：同一对的两个碎片颜色不同，但它们的缺失部分形状互补——一个的凸出恰好能填入另一个的凹口，拼合后形成一个完整矩形。
- 每个碎片的缺失角位于四个角之一（左上、右上、左下、右下）。

Rule:
- 识别互补配对：两个碎片的外接矩形尺寸相同，且一个的缺失区域与另一个的突出区域在形状和大小上完全匹配。
- 确定拼合方向：将两个碎片拼合时，缺口碎片不动，互补碎片平移过来填入缺口。拼合方向取决于缺口所在的角——缺口在右上则互补片从右侧水平靠入，缺口在左下则互补片从下方垂直靠入，以此类推（缺口的列侧决定水平/垂直，缺口的行侧决定方向）。
- 具体规则：若缺口在左侧两角（左上或左下），互补片从左侧水平拼入；若缺口在右侧两角（右上或右下），互补片从右侧水平拼入。拼合后两片像素合并，重叠区域使用互补片（填入片）的颜色。
- 输出网格尺寸与输入相同，未被使用的区域填充 bg。每对拼合后的完整矩形放置在缺口碎片的原始位置。

Key insight: 解题者首先要识别形状互补的配对关系（非颜色匹配），然后发现缺口角的方位决定了拼合的平移方向——这构成两层独立的推理。
</description>
</new_puzzle>

<description>
利用彩色标尺条的长度确定对应颜色框架内部网格的细分数，然后按细分格涂色。

Input structure:
- 背景色（bg）填充大部分网格。
- 网格中有若干空心矩形框架（1像素宽边框），每个框架用不同颜色绘制（如 Red、Blue、Green）。框架内部为 bg。
- 网格边缘（紧贴顶部或左侧边界）排列着若干水平或垂直的标尺条，每个标尺条是一段连续的单色像素线段。标尺条的颜色与某个框架颜色对应。
- 在每个框架的某一条边（上、下、左或右的外侧）紧贴着一个小的单像素标记点，颜色为 Maroon。

Rule:
- 对每个框架，找到与其颜色相同的标尺条，读取标尺条的长度 n。
- 将框架内部沿标记点所在边的垂直方向均匀细分为 n 等份（若标记在上边或下边则水平细分为 n 列，若标记在左边或右边则垂直细分为 n 行）。若内部宽度或高度不能被 n 整除，则前 (内部尺寸 mod n) 个分区各多占 1 像素。
- 对细分后的 n 个条带，交替填充框架颜色和 bg：第 1 条带填框架颜色，第 2 条带留 bg，第 3 条带填框架颜色……以此类推。
- 框架边框保持不变，标尺条在输出中被擦除（替换为 bg），标记点也被擦除。

Key insight: 解题者需要发现三层结构——(1) 标尺条长度编码细分数量，(2) Maroon 标记点确定细分的方向轴，(3) 交替填色产生条纹图案。标尺条不是直接尺寸而是分区计数，这增加了机制的隐蔽性。
</description>

<description>
根据网格中箭头形状指示的方向，将同色散落像素沿该方向投射并堆叠到墙壁上，箭头颜色决定哪组像素被投射。

Input structure:
- 背景色（bg）填充大部分网格。
- 网格中有若干由 Grey 像素构成的直线段作为"墙壁"，墙壁为水平或垂直线段，固定不动。
- 散布着若干彩色单像素点（如 Red、Blue、Orange），同一颜色的像素构成一组。
- 网格中还有若干小箭头图案。每个箭头由 3 或 5 个像素构成：一个箭头由一个彩色中心像素和从中心向某方向延伸的 1 个同色像素（箭杆）加上垂直于箭杆方向在箭杆末端两侧各 1 个同色像素（箭簇）组成，整体形成 T 形指向某方向。箭头的颜色与某组散落像素颜色相同。每种颜色恰好对应一个箭头。

Rule:
- 对每个箭头，确定其指向的方向（上、下、左、右）——箭簇 T 形的开口朝向即为指向方向。
- 找到与箭头同色的所有散落像素点（不包括箭头自身的像素）。
- 将这些散落像素沿箭头指向的方向投射：每个像素沿该方向移动直到碰到墙壁或网格边缘前一格停下。若多个同色像素投射到同一列（或同一行，取决于方向），它们依次堆叠在墙壁旁。
- 箭头图案在输出中被擦除（替换为 bg）。墙壁保持不变。

Key insight: 解题者需先识别 T 形箭头并解码其指向方向，然后发现箭头颜色将散落像素分组，最后理解投射+堆叠的物理过程——方向解码与颜色分组构成两层非显然的推理。
</description>
</new_puzzle>

<description>
在连通区域之间架设颜色桥梁：桥的颜色由两端区域的颜色混合图例决定，桥的宽度由两区域间重叠范围决定。

Input structure:
- 背景色（bg）填充大部分网格。
- 若干不同颜色的实心矩形块散布在网格中，每个矩形块为单一颜色（如 Red、Blue、Green、Yellow 等）。
- 网格的一个角落（如右下角）有一个小型颜色混合图例：图例由若干条目组成，每个条目是三个紧邻的像素排成一行——左像素颜色 A、右像素颜色 B、中间像素颜色 C，表示颜色 A 和颜色 B "混合"得到颜色 C。

Rule:
- 找到所有矩形块对，它们在水平或垂直方向上有重叠的行范围或列范围（即它们之间可以架设水平桥或垂直桥）。
- 对于每一对可架桥的矩形块（颜色分别为 A 和 B），在图例中查找包含 A 和 B 的条目，读取混合色 C。若图例中无此配对，则不架桥。
- 桥的方向：若两矩形在垂直方向上有列范围重叠，则架设水平桥；若在水平方向上有行范围重叠，则架设垂直桥。
- 桥的宽度等于两矩形重叠范围的长度（重叠的行数或列数）。桥填充两矩形之间的 bg 间隙，颜色为混合色 C。
- 若桥的路径上经过另一个矩形块，则不架桥（路径必须全为 bg）。
- 图例在输出中保持不变。

Key insight: 解题者需要三层推理——(1) 识别角落图例的"颜色混合"语义（左+右=中），(2) 判断哪些矩形对在几何上可以连桥（需要行列范围重叠且路径无阻挡），(3) 发现桥的宽度等于重叠范围而非固定值。图例的混合语义是最隐蔽的一层。
</description>

<description>
将网格中的环形轨道上的彩色珠子按轨道内嵌标记的步数旋转，旋转方向由标记朝向决定。

Input structure:
- 背景色（bg）填充大部分网格。
- 若干由 Grey 像素构成的闭合环形轨道，每条轨道是一个矩形环（即空心矩形的边框，1 像素宽）。不同轨道互不接触。
- 每条轨道上有若干位置被彩色像素替换（如 Red、Blue、Green），这些彩色像素是"珠子"，其余轨道位置保持 Grey。
- 每条轨道的内部（被轨道围起来的 bg 区域）恰好有一个小标记：由 1-4 个 Maroon 像素组成的短线段（水平或垂直）。

Rule:
- 对每条轨道，读取其内部 Maroon 标记的像素数量 k，这就是旋转步数。
- 确定旋转方向：若 Maroon 标记是水平线段，则珠子沿轨道顺时针旋转 k 步；若 Maroon 标记是垂直线段，则珠子沿轨道逆时针旋转 k 步。
- 旋转时，珠子沿轨道路径（按顺时针或逆时针序列）整体平移 k 个位置，轨道上非珠子位置保持 Grey。
- 轨道的路径顺序定义为：从轨道左上角出发，沿顺时针方向依次经过上边、右边、下边、左边的所有像素。
- 旋转完成后，Maroon 标记从输出中擦除（替换为 bg）。

Key insight: 解题者需发现两层机制——(1) 内部标记的像素数编码旋转步数，(2) 标记的朝向（水平vs垂直）编码旋转方向。轨道本身作为载体是显然的，但步数和方向的编码方式需要从多个样例对比才能归纳出来。
</description>

<description>
根据容器内色块的层叠顺序和外部排序键，重新排列容器内的色层。

Input structure:
- 背景色（bg）填充大部分网格。
- 若干垂直的"容器"：每个容器由两条平行的垂直 Grey 线段构成（间距 1-3 像素宽），底部由一条水平 Grey 线段封闭，顶部开口。容器内部从底部向上堆叠着若干不同颜色的水平色层，每层高度为 1 像素，宽度填满容器内部。
- 在每个容器的正上方（距容器顶部 1 像素间隔处）有一个垂直排列的"排序键"：由若干彩色像素从上到下排列成一列，每个像素颜色恰好对应容器内某一色层的颜色。

Rule:
- 对每个容器，读取其上方排序键中的颜色序列（从上到下）。
- 将容器内的色层按排序键指定的顺序重新排列：排序键最下方的颜色放在容器底部，排序键最上方的颜色放在容器顶部。
- 色层的厚度保持不变（均为 1 像素），仅改变上下顺序。
- 排序键在输出中被擦除（替换为 bg）。容器的 Grey 边框保持不变。

Key insight: 解题者需要发现容器上方的彩色像素列不是装饰而是排序指令，且排序键的阅读方向（上到下映射为顶到底）定义了重排的目标顺序——关键在于识别排序键与容器的空间配对关系以及方向映射规则。
</description>
</new_puzzle>
