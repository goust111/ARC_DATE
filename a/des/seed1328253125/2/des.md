description: 根据容器内部图案的旋转对称阶数，从色板中选取对应颜色，重新填充容器内部。

Input structure:
- bg = black。网格中散布若干由 grey 边框围成的矩形容器，每个容器内部包含由单一颜色绘制的小图案（如 L 形、T 形、十字形等）。
- 网格的一角放置一个色板区域：色板由若干竖条色块组成，从左到右排列，每个色块宽 1 列、高 3-4 行，颜色各不相同。色板从左到右的位置编号为 1、2、3、4……

Rule:
- 对每个容器，观察其内部图案的旋转对称性：将图案旋转 90°、180°、270° 后与原图案重合的次数决定其旋转对称阶数。无旋转对称（仅 360° 自身重合）阶数为 1；180° 对称阶数为 2；90° 对称阶数为 4。
- 用旋转对称阶数作为索引，从色板中选取对应位置的颜色（阶数 1 → 色板第 1 条，阶数 2 → 第 2 条，阶数 4 → 第 4 条）。
- 将容器内部图案的颜色替换为所选颜色，图案形状保持不变。grey 边框不变。

Key insight: 解题者需要先识别每个图案的旋转对称阶数（这需要在脑中旋转图案来判断），再将阶数映射到色板索引完成重新着色——两步都需要非显然的归纳。
</new_puzzle>

<new_puzzle>
description: 在网格中找到由边框围成的多个房间，根据房间之间门洞的连通关系，将同一连通区域内的所有房间地板涂为相同颜色。

Input structure:
- bg = black。网格被 maroon 色的线段分隔成若干矩形房间（类似平面图），每个房间内部初始为 black。
- 部分相邻房间之间的 maroon 墙壁上有 1 像素宽的缺口（门洞），表示两个房间相连。
- 网格边缘某处放置一排彩色方块作为色板，色板中有若干不同颜色的小方块（如 red、blue、green、yellow 等），从左到右排列。
- 每个独立连通区域（通过门洞互相可达的房间集合）中恰好有一个房间的地板上预先放置了一个与色板中某颜色相同的单像素标记点。

Rule:
- 首先通过门洞（maroon 墙壁上的 1 像素缺口）判断房间之间的连通性，将所有通过门洞链式相连的房间归为同一连通区域。
- 找到每个连通区域中带有标记点的房间，读取标记点的颜色。
- 将该连通区域内所有房间的整个地板（内部 black 像素）全部填充为标记点的颜色。
- 墙壁（maroon）和门洞保持不变。

Key insight: 门洞只有 1 像素宽，极易被忽略，解题者必须仔细扫描墙壁上的微小缺口来判断连通性；然后还需将连通区域与标记颜色对应，形成"结构识别 → 颜色传播"的双层推理。
</new_puzzle>

<new_puzzle>
description: 将散落的彩色碎片按颜色分组后分别拼合，再根据拼合后形状的面积从小到大，依次嵌套放入由外到内的同心框架中。

Input structure:
- bg = azure。网格中散布若干小型彩色碎片（不规则形状的连通区域），每种颜色有 2-3 个碎片。
- 网格一侧有若干由 grey 线条绘制的同心矩形框架（类似靶环），框架层数等于颜色种类数。每层框架之间的间距不等。

Rule:
- 第一步（拼合）：将同色碎片视为被拆散的拼图。将它们平移拼合（不旋转）成一个紧凑的矩形或近矩形形状。拼合方式唯一——碎片边缘的锯齿状互补轮廓只有一种无缝对接方式。
- 第二步（排序与嵌套）：计算每种颜色拼合后形状的面积（像素数）。面积最小的形状放入最内层框架，面积最大的放入最外层框架，依此类推。
- 将每个拼合后的形状居中放入对应的框架层内部。碎片从原位置擦除（恢复为 bg 色）。

Key insight: 解题者需要先完成空间拼合（识别互补轮廓），再按面积排序分配到嵌套层级——"拼图重组"和"面积排序嵌套"是两个独立的非显然推理步骤。
</new_puzzle>

<new_puzzle>
description: 每个彩色种子沿箭头指示方向生长出藤蔓，藤蔓的长度由种子所在封闭区域的内部空闲格数决定，藤蔓遇到障碍物时按规则转向。

Input structure:
- bg = black。网格中有若干由 green 像素构成的不规则封闭围栏（围栏内部为 black 空地）。
- 每个围栏内部恰好有一个彩色种子像素（颜色各不相同，如 red、blue、orange、yellow 等）。
- 每个种子像素的正上、正下、正左或正右方紧邻一个 maroon 像素，该 maroon 像素作为箭头，指示种子的初始生长方向（种子→maroon 的方向即为生长方向）。

Rule:
- 对每个种子，计算其所在围栏内部的空闲格数 N（不计种子自身和 maroon 箭头）。
- 从种子位置开始，沿箭头方向逐格生长藤蔓（用种子颜色填充 black 格子），总共生长 N 格。
- 当藤蔓前方遇到 green 围栏或网格边缘时，顺时针转 90° 继续生长；若顺时针方向也被阻挡，则再转 90°（即掉头），以此类推。
- 藤蔓不会覆盖已有颜色的格子（围栏、种子、其他藤蔓）；如果所有方向都被阻挡则停止生长。
- maroon 箭头像素在输出中被擦除（恢复为 black）。

Key insight: 解题者需要三层推理——识别 maroon 像素编码的方向、数出围栏内空闲格数作为生长长度、理解碰壁时的顺时针转向规则。空闲格数决定藤蔓长度这一映射关系是最隐蔽的一层。
</new_puzzle>

<new_puzzle>
description: 根据模板行中颜色块的排列顺序，对网格中每一列的彩色像素进行垂直重排，使各列的颜色出现顺序与模板一致。

Input structure:
- bg = black。网格的最底行（或最顶行）是一条"模板行"，由若干种颜色按特定顺序排列（例如：red、blue、green、yellow 从左到右各占若干格，形成色带）。
- 模板行上方的主网格区域中，每列散布着若干彩色像素（颜色均属于模板中出现的颜色集合），各像素之间可能有 black 间隔。同一列中可能有多个相同颜色的像素，也可能缺少某些颜色。

Rule:
- 读取模板行，提取颜色的优先级顺序（从左到右首次出现的颜色排在前面）。例如模板从左到右依次首次出现 red、blue、green、yellow，则优先级为 red > blue > green > yellow。
- 对主网格中的每一列，收集该列所有非 black 像素及其颜色。
- 按照模板定义的颜色优先级对这些像素进行排序（优先级高的颜色排在上方）。同一颜色的多个像素保持相对顺序不变。
- 将排序后的像素从该列顶部起依次紧密放置（之间不留 black 间隔），剩余格子填充 black。
- 模板行本身在输出中保持不变。

Key insight: 解题者首先需要发现最底行并非普通数据而是一个"排序指令"——它编码了颜色的优先级；然后需要理解每列独立按此优先级重排并向顶部紧缩。模板的"指令"身份是关键的隐蔽层。
</new_puzzle>
