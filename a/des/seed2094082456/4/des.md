description：根据每个封闭区域内部的标记像素数量，从颜色条纹图例中选取对应行的颜色，将该封闭区域的边框重新着色。

Input structure：
- 背景为黑色（Black）。
- 网格左侧有一个垂直的颜色条纹图例：从上到下排列若干行，每行为一种颜色的实心水平条（宽度为2像素），行号从1开始。
- 网格其余区域包含若干由灰色（Grey）像素组成的封闭矩形边框（一像素厚），每个矩形内部可能散布着若干红色（Red）单像素标记点，其余为黑色背景。

Rule：
- 对于每个灰色封闭矩形边框，数出其内部红色标记像素的数量 N（N >= 1 且 <= 图例行数）。
- 在颜色图例中找到从上往下第 N 行对应的颜色。
- 将该矩形的灰色边框全部重新着色为该颜色。
- 移除矩形内部所有红色标记像素（替换为黑色背景）。
- 颜色图例本身保持不变。

Key insight：
- 标记像素不是装饰——它们的数量是索引值，用来在图例中查找边框的目标颜色。解题者需要先发现"计数→查表"的映射关系，再发现图例的行序对应关系。
</new_puzzle>

description：将网格中每个彩色对象沿其内部箭头方向平移，平移距离等于箭头长度，到达新位置后移除箭头。

Input structure：
- 背景为黑色（Black）。
- 网格中有若干单色的4-连通前景对象，每个对象由一种非黑非灰颜色绘制。
- 每个对象的内部恰好嵌入一个由灰色（Grey）像素绘制的箭头。箭头由一条直线段（水平或垂直）和末端一个像素的正交偏移构成，形成"L"形箭头，长边指示方向，短边指示箭头尖端侧。具体地：箭头的"杆"是一段长度为 L 的水平或垂直灰色像素直线；箭头的"头"是杆的一端向垂直于杆方向偏移一个像素的单个灰色像素，表示箭头指向杆的另一端（即远离箭头头部的方向）。

Rule：
- 对于每个彩色对象，识别其内部的灰色箭头。
- 箭头的方向定义为：从箭头头部（有正交偏移像素的一端）指向杆的另一端。
- 平移距离等于箭头杆的长度 L（像素数）。
- 将整个彩色对象（不含灰色箭头像素）沿箭头方向平移 L 个像素。
- 原位置清除为黑色背景；灰色箭头像素也不出现在输出中。

Key insight：
- 灰色箭头同时编码了两种信息：方向和距离。解题者需要先识别出箭头的结构以确定方向，再用箭头杆的长度作为平移量——一个嵌入对象内部的自描述指令。
</new_puzzle>

Input structure：
- 背景为黑色（Black）。
- 网格被灰色（Grey）的完整行和完整列分割为若干等大的矩形面板（例如 2x2 或 3x2 排列的面板）。
- 每个面板内包含若干由蓝色（Blue）像素绘制的4-连通前景对象。
- 每个面板的某一条灰色分隔边（上、下、左或右边框）上恰好有一个单像素的颜色标记（非黑非灰非蓝），标记颜色各面板互不相同。

Rule：
- 第一步——确定重着色：对于每个面板，将其内部所有蓝色前景对象重新着色为该面板边框上颜色标记的颜色。
- 第二步——确定层叠顺序：统计每个面板内蓝色前景对象的数量。对象数量最少的面板位于最顶层，数量最多的位于最底层。

Key insight：
- 这是一道三层推理题：第一层需要发现边框标记决定颜色替换；第二层需要发现对象数量决定面板堆叠的优先级；第三层需要理解面板合成时黑色背景作为透明层的叠加规则。三者共同决定最终输出。
</new_puzzle>

description：网格中包含多个相同形状但不同颜色的对象，根据对象之间的邻接关系构建"传染链"，沿链条方向依次将每个对象重着色为链中下一个对象的原始颜色。

Input structure：
- 背景为黑色（Black）。
- 网格中有若干形状完全相同但颜色各异的前景对象（每个对象为单一颜色的4-连通区域）。
- 恰好有一个对象与一个单像素的maroon（Maroon）标记相邻（4-邻接），该标记不属于任何对象。
- 部分对象之间存在4-邻接关系（即边框像素彼此相邻），形成一条从标记对象出发的唯一链状路径（每个对象最多与链中的前驱和后继相邻，不形成分支或环）。

Rule：
- 从与 maroon 标记相邻的对象开始，沿邻接关系依次访问链上的每个对象。
- 链上每个对象被重着色为它在链中下一个对象的原始颜色。
- 链上最后一个对象（没有下一个邻接对象的）被重着色为 maroon 标记的颜色（Maroon）。
- Maroon 标记像素本身在输出中被移除（替换为黑色背景）。
- 不在链上的对象（与链无邻接关系的孤立对象）保持不变。

Key insight：
- Maroon标记不是颜色指令，而是链条的起点标识。解题者需要先通过邻接关系发现对象之间的链状结构，再发现颜色沿链条向前传递一步的规律，最后发现链尾的特殊着色规则。
</new_puzzle>
