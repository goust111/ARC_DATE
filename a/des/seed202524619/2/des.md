<description>
根据框架内部的缺失色层推断对应的修补图案，并从外部色块库中选取正确图案填入框架。

Input structure:
- 背景色（bg）为最常见颜色。网格中有若干个大小相同的正方形框架，框架边框颜色统一（如 grey）。
- 每个框架内部包含一个多色图案，但每个框架恰好缺少一种颜色的像素层（被替换为背景色），不同框架缺少的颜色不同。
- 网格边缘有一个"色块库"区域，其中排列着若干个与框架内部尺寸相同的小图案块，每个小图案块仅由单色像素组成，颜色各不相同。

Rule:
- 对比所有框架的内部图案，找出每个框架缺少的那一层颜色。方法是：在其他框架中出现但在当前框架中完全缺失的颜色即为缺失色。
- 在色块库中找到与缺失颜色相同的单色图案块。
- 将该图案块叠加到框架内部，仅在框架内当前为背景色的位置填入图案块对应的像素。

Key insight: 需要跨框架交叉比对才能发现每个框架缺了哪种颜色；色块库提供的不是整体替换图案，而是单独一层的"补丁"，必须与框架中已有内容无冲突地叠加。
</description>

<description>
将网格中的多个形状按照"容器-钥匙"配对关系嵌套组装，钥匙的朝向决定其插入容器的方位。

Input structure:
- 背景色为 black。网格中散布着两类对象：
  - "容器"：较大的空心矩形，边框为某种颜色（如 blue、red、green 等），内部为背景色，且恰好有一侧边框上存在一个宽度为 2 的缺口。
  - "钥匙"：较小的实心 L 形或 T 形图案，颜色与某个容器的边框颜色相同，且钥匙的突出臂指向某个方向（上/下/左/右）。
- 每种颜色恰好对应一个容器和一个钥匙。

Rule:
- 通过颜色匹配将每个钥匙与其同色容器配对。
- 观察钥匙突出臂的方向：该方向指示钥匙应从容器的哪一侧缺口插入。
- 如果钥匙突出臂方向与容器缺口方向一致，直接将钥匙平移到容器缺口处，使钥匙的突出臂封住缺口并嵌入容器内部。
- 如果方向不一致，将钥匙旋转（90° 的倍数）使突出臂对准缺口方向后再插入。
- 钥匙插入后其主体位于容器内部，突出臂恰好填满缺口。

Key insight: 颜色配对是第一层推理；缺口位置与钥匙朝向的匹配是第二层推理——钥匙必须旋转到正确方向后才能"锁入"容器，最终缺口被封住。
</description>

<description>
网格中的小图标作为"种子"，按照相邻色带所编码的生长步数，向特定方向复制扩展出图标序列。

Input structure:
- 背景色为 black。网格中有若干个小型多色图标（sprite），每个图标占据约 3×3 的区域。
- 每个图标的某一侧（上/下/左/右之一）紧邻一条由单色像素组成的短色带（长度为 1 到 4 个像素），色带的颜色不同于图标颜色和背景色。
- 每个图标的另一侧（与色带相对的一侧）紧邻一个单像素的方向标记，方向标记的颜色与色带颜色相同。

Rule:
- 色带所在的一侧确定"生长方向的反面"，即方向标记所在的一侧为生长方向。
- 色带的像素长度 N 表示需要沿生长方向复制图标 N 次。
- 从图标当前位置出发，沿生长方向每隔一个图标宽度（留出一行/列间隔）依次放置 N 个图标副本。
- 方向标记像素在输出中被移除；色带保留原位。

Key insight: 色带同时编码了两个信息——它的位置隐含地定义了生长方向（向对面延伸），它的长度定义了复制次数。方向标记的存在是验证方向判断的线索，但真正的方向信息来源于色带与图标的相对位置关系。
</description>

<description>
在包含多个"教室"分区的网格中，根据教室内"老师"图案的形状变换规则，对同一教室内的所有"学生"图案施加相同变换。

Input structure:
- 背景色为 black。网格被 grey 分隔线划分为若干个等大的矩形分区（"教室"）。
- 每个教室内有一个用特殊颜色 maroon 绘制的图案对（"老师"）：由两个相邻的小图形组成，一个标记为"变换前"（左侧或上方），另一个标记为"变换后"（右侧或下方），两者之间用一个 orange 像素分隔。老师图案对展示了某种几何变换（如水平翻转、顺时针旋转 90°、上下翻转等）。
- 每个教室还包含若干个其他颜色的小图案（"学生"），这些图案形状各异。

Rule:
- 在每个教室中，通过比较老师的"变换前"和"变换后"图形，推断出该教室的变换规则（旋转角度或翻转轴）。
- 对该教室内的每一个学生图案，在其原位置施加同样的变换。
- 老师图案对本身在输出中被移除（替换为背景色）。

Key insight: 每个教室有自己独立的变换规则，必须从老师的示范对中归纳出来；不同教室的规则可能不同，因此不能将一个教室的规则套用到另一个教室。解题者需要先"读懂"每个老师在教什么变换，再将其应用于学生。
</description>

<description>
将散落在网格中的碎片拼入一个带有彩色锚点的目标框架中，碎片的颜色边缘与框架锚点的颜色对齐决定了放置位置和朝向。

Input structure:
- 背景色为 black。网格中有一个较大的空心矩形框架，边框为 grey。
- 框架内部为背景色，但框架的内壁上分布着若干个彩色锚点像素（如 red、blue、green、yellow），每种颜色恰好出现 2 到 3 个像素，形成该颜色的锚点组。
- 框架外部散布着若干个不规则的小碎片（每个碎片由多种颜色组成），碎片的边缘像素中包含与框架锚点相同的颜色。

Rule:
- 每个碎片的边缘上恰好有一种颜色与框架内壁的某组锚点颜色相同——这决定了碎片与框架的配对关系。
- 将碎片移入框架内部，使碎片边缘上的彩色像素与框架内壁上同色的锚点像素在空间上紧密相邻（碎片边缘像素与锚点像素在上下或左右方向相邻）。
- 如果碎片需要旋转（0°/90°/180°/270°）才能使其边缘彩色像素与锚点对齐，则旋转后放置。
- 碎片放置后，其边缘彩色像素紧贴锚点，碎片主体填入框架内部的背景区域。

Key insight: 碎片与框架的匹配需要两步推理：第一步是通过边缘颜色找到碎片属于哪组锚点；第二步是通过锚点的空间排列确定碎片的旋转角度和精确位置——锚点的几何分布就是碎片边缘彩色像素的"接口规格"。
</description>

<description>
根据网格中"信号塔"发射的彩色信号线的交汇模式，在交汇点生成由混色图例决定的新颜色。

Input structure:
- 背景色为 black。网格中分布着若干个"信号塔"——每个信号塔是一个 1×1 的彩色像素，坐落在一个 3×3 的 grey 底座中央。
- 网格底部有一个单行的"混色图例"：由多个 1×3 的色条组成，每个色条的左像素和右像素分别是两种输入颜色，中间像素是这两种颜色的"混合结果色"。

Rule:
- 每个信号塔从其位置向四个正方向（上下左右）发射一条与塔身同色的信号线，信号线延伸直到碰到网格边缘或另一座信号塔的底座。信号线宽度为 1 像素。
- 当两条不同颜色的信号线在某个像素位置交叉时，该位置形成交汇点。
- 在混色图例中查找这两种颜色的组合，将交汇点像素染为图例中指定的混合结果色。
- 如果交汇的两种颜色在图例中没有对应条目，则交汇点保持为背景色。
- 信号线在非交汇位置保持其原色。

Key insight: 信号线的绘制是第一层推理——需要理解塔向四方延伸直线；交汇点的混色是第二层推理——需要通过图例解码两色交汇的结果，而非简单叠加。图例的存在暗示混色规则是任意指定的而非可预测的。
</description>

<description>
将网格中的"密码锁"图案按照同行/同列的"密码提示条"指定的颜色排列顺序重新着色，锁内图案的空间结构保持不变。

Input structure:
- 背景色为 black。网格中分布着若干个多色图案块（"密码锁"），每个锁由 3 到 5 种颜色的像素组成，形成一个紧凑的连通区域。
- 网格的最左列和最上行分别放置着若干条短色带（"密码提示条"），每条色带由 3 到 5 个不同颜色的像素按顺序排列。
- 每个密码锁恰好与一条左侧提示条同行、与一条顶部提示条同列。

Rule:
- 找到每个密码锁对应的行提示条和列提示条。
- 行提示条定义了颜色的"重要性排序"：提示条中从左到右第 1 个颜色是最重要的，依次递减。
- 列提示条定义了"空间映射规则"：提示条中从上到下第 k 个颜色表示锁中面积第 k 大的颜色层应被重新着色为该颜色。
- 统计密码锁中每种颜色的像素数量，按面积从大到小排序。如果面积相同，则按行提示条中的重要性排序打破平局。
- 将面积排名第 k 的颜色层的所有像素重新染为列提示条中第 k 个颜色，像素位置保持不变。

Key insight: 行提示条和列提示条承担不同角色——列提示条提供新颜色映射，行提示条提供面积平局时的排序依据。解题者需要同时理解两条提示条的不同功能，并正确地将面积排序与颜色替换对应起来。
</description>
</new_puzzle>
