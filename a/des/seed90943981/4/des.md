<description>
根据框架的嵌套深度从边缘色条图例中查找对应颜色，对每层框架重新着色。

Input structure:
- bg = Black。网格中有若干个Grey矩形框架（宽度1像素的空心矩形边框），框架之间存在嵌套关系：较小的框架完全位于较大框架的内部，形成多层嵌套结构（最多4层）。同一层级可能有多个并列的框架。
- 网格最左列（第0列）从上到下排列着若干个彩色像素（每个占一个格子，彼此不相邻），颜色互不相同。从上到下第1个像素代表嵌套深度1（最外层框架），第2个代表深度2，依此类推。这些像素与任何框架不接触。
- 框架内部可能存在孤立的小彩色像素点，这些是干扰项。

Rule:
- 第一步：构建嵌套层级。识别所有Grey矩形框架（每个框架是一个宽度1像素的完整闭合矩形边框）。根据空间包含关系确定每个框架的嵌套深度——不被任何其他框架包含的框架深度为1，被恰好一个框架包含的深度为2，以此类推。
- 第二步：读取颜色图例。最左列的彩色像素从上到下依次对应深度1、2、3……的目标颜色。
- 第三步：重新着色。将每个Grey框架的全部边框像素替换为其嵌套深度对应的图例颜色。框架内部的背景色保持Black不变，所有干扰像素点被擦除为Black。最左列的图例像素在输出中也被擦除。

Key insight: 解题者需要先从空间包含关系推断出嵌套层级（而非仅靠框架大小），再将左侧看似无关的彩色像素识别为按深度排列的颜色映射表，两个非显然的归纳步骤缺一不可。
</description>

<description>
沿链式路径传递图案，图案在每个中继节点处发生顺时针旋转，且图案颜色继承自前一个节点。

Input structure:
- bg = Black。网格中有若干个彩色"节点"——每个节点是一个3×3的实心彩色方块，各节点颜色互不相同（不含Black和Grey）。
- 节点之间由宽度为1像素的Grey直线段（纯水平或纯垂直）连接，所有节点形成一条无分支的链式路径（恰好两个端点节点只有一条连接线，其余节点各有两条）。
- 链的起始节点定义为两个端点中行号更小的那个（若行号相同则取列号更小的）。起始节点的3×3区域内，有一个2×2的子图案占据四个角位之一（左上、右上、左下、右下），该子图案用Grey绘制，覆盖在节点颜色之上。其余所有节点的3×3区域为纯色，没有子图案。

Rule:
- 第一步：确定遍历顺序。从起始节点出发，沿Grey连接线依次经过每个节点直到链的另一端。
- 第二步：传播图案位置。起始节点的Grey子图案所在角位（左上/右上/右下/左下）为初始位置。每到下一个节点，子图案的角位顺时针旋转90度（左上→右上→右下→左下→左上，循环往复）。
- 第三步：传播图案颜色。每个非起始节点上绘制的子图案，其颜色不是Grey，而是链中前一个节点的主体颜色（即方块本身的颜色）。
- 输出时，起始节点保持原样不变，每个后续节点在其3×3纯色方块的对应角位覆盖绘制2×2的子图案。Grey连接线和背景保持不变。

Key insight: 解题者需要同时发现三条规则——图案角位逐节点顺时针旋转、图案颜色来自前驱节点而非当前节点、遍历顺序由端点位置决定——三者交织构成三层推理。
</description>

<description>
将网格中被墙壁分隔的多个房间按照门的连通关系合并着色，门的颜色决定合并后的房间颜色。

Input structure:
- bg = Black。网格由Blue像素构成的墙壁划分成若干个封闭"房间"（4-连通的Black区域，被Blue墙壁完全包围）。每个房间是矩形的。
- 某些相邻房间之间的共享墙壁上有一个1像素宽的"门"——即墙壁上恰好有一个像素被替换为非Black、非Blue的彩色像素。门的颜色可以是Red、Green、Yellow、Magenta、Orange等。
- 同一种颜色的门可能出现多次，连接不同的房间对。
- 有些房间没有任何门（完全封闭），有些房间可能有多扇不同颜色的门。

Rule:
- 第一步：识别连通分组。两个房间若通过同色的门直接或间接相连，则属于同一分组。具体地：如果房间A和房间B之间有一扇Red门，房间B和房间C之间也有一扇Red门，则A、B、C属于同一个Red分组。但如果A和B之间是Red门、B和C之间是Green门，则A和B属于Red分组，B和C属于Green分组（B同时属于两个分组）。
- 第二步：着色。对每个分组，将该分组中所有房间的内部（Black区域）填充为该分组的门颜色。若一个房间属于多个分组（有多种颜色的门），则该房间填充为这些颜色中在网格中出现次数最少的那种门颜色（即最稀有的颜色优先）。
- 第三步：无门房间保持Black不变。墙壁（Blue像素）和门像素在输出中保持不变。

Key insight: 解题者需要先发现门的颜色定义了连通等价类（而非简单的相邻关系），再发现多分组冲突时的稀有色优先规则，两层归纳各自都不显然。
</description>

<new_puzzle>
<description>
通过形状轮廓的缺口方向确定投射方向，将形状内部的彩色种子沿该方向射出并在碰到障碍时停止着色。

Input structure:
- bg = Black。网格中散布着若干个Grey像素构成的近闭合矩形框（3×3到6×6不等），每个框的边缘恰好有一个1像素的缺口（即边框上缺少一个Grey像素）。缺口位于框的上、下、左、右四条边之一的中间位置。
- 每个框的内部恰好有一个非Black、非Grey的彩色像素（种子像素），位于框内的某个位置。
- 网格中还散布着若干个孤立的Maroon像素作为障碍物，不与任何框接触。

Rule:
- 第一步：确定投射方向。每个框的缺口所在边决定投射方向——缺口在上边则方向向上，缺口在下边则方向向下，缺口在左边则方向向左，缺口在右边则方向向右。
- 第二步：投射着色。从种子像素出发，沿投射方向逐像素绘制一条种子颜色的射线。射线穿过框的缺口后继续向外延伸（框的缺口位置也被种子颜色覆盖），直到射线碰到网格边缘或碰到Maroon障碍物时停止（障碍物本身不被着色）。框内部从种子到缺口之间的路径上的像素也被种子颜色填充。
- 第三步：保留框架。Grey框边保持不变（除了缺口位置被射线颜色覆盖）。种子像素本身也保留为原色。Maroon障碍物保持不变。

Key insight: 解题者需要先发现缺口方向与投射方向的对应关系（而非简单地"朝空旷处移动"），再发现射线的起点是种子像素而非缺口本身，最终理解障碍物的阻断作用——框的缺口既是方向指示器又是射线的出口通道。
</description>
</new_puzzle>

<new_puzzle>
<description>
在拼图模板中根据外部碎片的形状匹配空洞，但填充颜色由碎片与空洞之间的相对位置关系（上下左右）经过一个颜色置换表转换后决定。

Input structure:
- bg = Black。网格可分为三个水平区域，由两条横贯全宽的Grey水平线分隔。
- 顶部区域：一个颜色置换表。表由若干对紧邻的彩色像素组成，每对的左像素为"输入颜色"，右像素为"输出颜色"，对与对之间间隔1列Black。例如 (Red→Blue, Green→Yellow) 表示Red映射为Blue，Green映射为Yellow。
- 中部区域：一个由Maroon像素构成的大型模板形状，模板内部有若干个不规则的空洞（被Maroon边界完全包围的Black连通区域）。
- 底部区域：若干个彩色小碎片（连通分量），每个碎片的形状恰好与模板中的一个空洞形状全等（可能需要平移，但不需旋转或翻转）。不同碎片颜色可能相同或不同。

Rule:
- 第一步：形状匹配。对每个空洞，在底部区域找到形状与之全等的碎片（仅平移匹配）。每个碎片恰好匹配一个空洞，一一对应。
- 第二步：颜色转换。确定每个碎片相对于其匹配空洞的方位——碎片的质心（连通分量的视觉中心）位于空洞质心的上方/下方/左方/右方。根据方位选择置换表中的变换次数：上方=应用1次置换，右方=应用2次，下方=应用3次，左方=应用4次（即恢复原色）。每次"应用置换"是指将当前颜色按置换表映射为对应的输出颜色（若颜色不在表中则保持不变）。
- 第三步：填充。将每个空洞用经过颜色转换后的碎片颜色填充。模板Maroon像素保持不变。底部碎片和顶部置换表在输出中被擦除。输出网格仅包含中部区域（从第一条Grey线到第二条Grey线之间的内容），Grey线本身也被擦除。

Key insight: 解题者需要三步归纳——(1) 形状匹配确定碎片-空洞对应，(2) 相对方位决定置换次数，(3) 置换表定义颜色映射关系。三层规则环环相扣，仅凭形状匹配无法得出正确颜色。
</description>
</new_puzzle>
