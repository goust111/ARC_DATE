<description>
根据彩色钥匙条的缺口位置解锁对应颜色的锁框，将锁框内部的图案沿缺口方向"推出"并印到框外。

Input structure:
- 背景色（bg）为网格中最常见的颜色。
- 若干矩形空心框（锁框），每个框由单一非bg颜色绘制，框内包含一个由另一种颜色构成的小图案（2-4个像素的不规则形状）。
- 每个锁框的某一侧边上恰好有一个1像素宽的缺口（即该侧边有一个像素被bg替代）。
- 网格边缘处有若干水平或垂直的细条（钥匙条），每根钥匙条由某种颜色构成，长度为3-5像素，其中恰好有一个像素是bg色（即钥匙条上也有一个缺口）。
- 每根钥匙条的颜色与恰好一个锁框的颜色匹配。

Rule:
- 将每根钥匙条与同色的锁框配对。
- 钥匙条上缺口的相对位置（在条的左端/右端/中间，或上端/下端/中间）决定了锁框的哪一侧被"打开"：钥匙条缺口靠左/上 → 锁框左/上侧打开；缺口靠右/下 → 锁框右/下侧打开；缺口居中 → 对应方向由钥匙条的朝向决定（水平条→上侧，垂直条→左侧）。
- "打开"意味着：将框内的小图案沿打开方向平移，直到图案完全移出锁框，紧贴在锁框该侧外壁。
- 移出后，锁框内部变为纯bg；锁框边框保持不变（缺口保留）；钥匙条从网格中擦除。

Key insight:
钥匙条上缺口的相对位置编码了锁框的解锁方向——解题者需要先建立"钥匙缺口位置→锁框开启侧"的映射规则，再执行图案的平移推出。这形成两层推理：第一层是发现钥匙条缺口位置与锁框开启方向的对应关系，第二层是确定图案的平移方向和最终位置。
</description>

<description>
在被隔断墙分割的区域中，根据区域内种子像素的颜色查找同色模板图案，然后将模板图案按区域形状裁剪后填入该区域。

Input structure:
- 背景色（bg）为网格中最常见的颜色。
- 一组由 maroon 色线条构成的直线隔断墙将网格分成若干不规则的封闭区域（每个区域面积约为 4x4 到 8x8）。
- 网格的一个角落（如左上角）有一个由隔断墙围成的"图例区"，内部包含若干小矩形子框，每个子框用不同颜色绘制一个 3x3 或 4x4 的图案（模板图案），子框之间用隔断墙分隔。
- 在图例区之外的每个封闭区域中，恰好有一个非bg、非maroon的单像素（种子像素），其颜色与图例区中某个模板图案的颜色相同。

Rule:
- 对图例区外的每个封闭区域，找到其中的种子像素颜色。
- 在图例区中找到同色的模板图案。
- 将模板图案以平铺方式（tile）填满整个区域：以种子像素所在位置为锚点，将模板图案的中心对齐到种子像素，然后向四周周期性平铺，直到覆盖区域内所有bg像素。
- 超出区域边界的部分被裁剪（不绘制到隔断墙上或其他区域中）。
- 图例区本身保持不变。

Key insight:
解题者需要发现两层结构：第一层是识别图例区中的模板图案，并通过颜色匹配将种子像素与模板配对；第二层是理解填充方式——模板以种子像素为锚点进行周期性平铺，而非简单地单次印章，且受区域形状裁剪。种子的位置决定了平铺的相位偏移，因此不同区域即使使用同一模板，填充结果也因种子位置不同而不同。
</description>

<description>
将网格中散落的彩色箭头沿其指向方向发射射线，射线经过"棱镜"三角形时发生颜色分裂——一条射线保持原色继续前进，另一条射线以棱镜颜色向垂直方向偏折。

Input structure:
- 背景色（bg）为网格中最常见的颜色。
- 若干彩色箭头散布在网格中。每个箭头由3个同色像素组成：一个"头"像素和两个"尾翼"像素。头像素位于尾翼前方一行/列，两个尾翼像素分别位于头像素后方一行/列的左右两侧（形成 V 字），由此可判断箭头的朝向（上、下、左、右四个方向之一）。
- 若干由不同颜色构成的小型实心直角三角形（棱镜），每个棱镜占 3 个像素，呈 L 形排列（两像素在同一行相邻，第三像素在其中一个的上方或下方）。
- 棱镜的颜色与箭头的颜色均不相同。

Rule:
- 每个箭头从其头像素出发，沿朝向方向发射一条1像素宽的射线（用箭头自身颜色绘制），逐像素延伸，遇到网格边缘则停止。
- 若射线命中一个棱镜的任意像素，则发生"分裂"：
  （a）原色射线穿透棱镜，继续沿原方向前进直到网格边缘。
  （b）从命中点额外发射一条新射线，颜色为棱镜的颜色，方向为原方向顺时针旋转90度，延伸到网格边缘。
- 分裂产生的新射线若再命中另一个棱镜，不再继续分裂（只分裂一次）。
- 箭头本身保留在原位；棱镜保留在原位。射线绘制时不覆盖已有的非bg像素。

Key insight:
解题者需要三层推理：第一层是从3像素的V形结构判断每个箭头的朝向方向；第二层是理解射线遇到棱镜时的分裂行为——原色穿透加垂直偏折；第三层是确定偏折方向固定为顺时针90度而非逆时针。箭头形状编码方向、棱镜颜色编码偏折射线的颜色，两者共同决定输出图案。
</description>

根据网格中"链条"的拓扑连接顺序，将链条上每个环节的颜色替换为其在链中所处位置对应的调色板颜色。

Input structure:
- 背景色（bg）为网格中最常见的颜色。
- 网格中有若干条由多个小方块（2x2像素的实心正方形）首尾相连组成的"链条"。相邻方块之间共享一条边（即一个方块的右边紧贴下一个方块的左边，或一个方块的下边紧贴下一个方块的上边），形成蛇形路径。
- 每条链条中的方块颜色各不相同（每个方块是一种非bg颜色）。
- 网格的最下方一行有一个水平排列的调色板条：由若干不同颜色的单像素从左到右排成一行，像素之间无间隔。调色板条的长度等于链条中方块的最大数目。
- 每条链条的一个端点方块（链头）紧邻网格边缘（即该方块有一条边在网格边界上），另一个端点（链尾）不紧邻边缘。

Rule:
- 对每条链条，从链头开始，沿着方块的连接顺序依次编号：链头为第1个，下一个相邻方块为第2个，以此类推直到链尾。
- 将调色板条中从左到右第 k 个颜色赋给链条中第 k 个方块：即链头变为调色板第1个颜色，第2个方块变为调色板第2个颜色，依此类推。
- 调色板条本身在输出中被擦除（变为bg）。
- 若多条链条共存，它们共用同一个调色板，各自独立从第1个位置开始映射。

Key insight:
解题者需要两层关键推理：第一层是识别出2x2方块通过共享边连接形成链条的拓扑结构，并找到链头（紧邻网格边缘的端点方块）以确定遍历起点和顺序；第二层是发现底部调色板条提供了一个按位置索引的颜色映射表，链条中第k个方块的颜色由调色板第k个位置决定，而非由方块原始颜色决定。
</description>

将网格中散落的彩色碎片拼回到灰色骨架上，拼接位置由碎片轮廓与骨架缺口的形状匹配决定，拼接后碎片颜色根据骨架上相邻已填充区域的颜色进行"传染"变色。

Input structure:
- 背景色（bg）为网格中最常见的颜色。
- 网格中央有一个由 grey 像素构成的大型不规则连通形状（骨架），骨架内部有若干处缺口（bg色的凹陷区域），每个缺口的形状各不相同（如L形、T形、直条形等），面积在2-5像素之间。
- 网格的四周散布着若干彩色碎片，每个碎片是一个由单一非bg、非grey颜色构成的小型连通形状，面积也在2-5像素之间。每个碎片的形状（可经0/90/180/270度旋转）恰好与骨架中某一个缺口的形状完全吻合。
- 碎片数量与缺口数量相等，且一一对应。
- 骨架的某些缺口边缘（与缺口相邻的grey像素的外侧）紧邻一个已经被某种非bg、非grey颜色填充的小区域（"色源"标记，1-2个像素），这些色源标记在输入中已经存在于骨架上。

Rule:
- 对每个碎片，通过尝试四种旋转找到与其形状匹配的骨架缺口。
- 将碎片移入匹配的缺口位置（碎片从原位置擦除）。
- 填入后，检查该缺口的边缘是否存在色源标记（与缺口相邻的非bg、非grey像素）：
  - 若存在色源标记，则将填入的碎片颜色替换为色源标记的颜色。
  - 若不存在色源标记，则碎片保持其原始颜色不变。
- 骨架的grey像素和色源标记在输出中保持不变。

Key insight:
解题者需要三层推理：第一层是通过形状匹配（允许旋转）将每个碎片与骨架缺口配对——这需要视觉上比对轮廓；第二层是发现碎片填入缺口后并非保持原色，而是要检查缺口周围是否存在色源标记；第三层是理解"传染"规则——色源标记的颜色会覆盖碎片的原始颜色，而没有色源的缺口中碎片保留原色。这使得碎片的最终颜色不由碎片自身决定，而由其嵌入位置的上下文决定。

<description>
在由通道连接的多个房间中，根据房间内旗帜的朝向决定通道中液体的流向，液体从源头房间出发沿通道流动，最终将所有可达房间染上源头的颜色。

Input structure:
- 背景色（bg）为网格中最常见的颜色。
- 由 black 像素构成的粗墙壁将网格分隔成若干矩形房间（每个房间内部为bg）。
- 相邻房间之间的墙壁上有1像素宽的开口（通道），连接两个房间。
- 每个房间内部有一个"旗帜"标记：由2个同色像素组成，一个像素（旗杆）紧贴房间某侧内壁，另一个像素（旗面）在旗杆的某个方向上与旗杆相邻。旗面相对于旗杆的方向（上、下、左、右）即为该房间的"出口方向"。
- 恰好有一个房间是"源头房间"：该房间内除旗帜外，还有一个额外的单像素标记（颜色与旗帜不同），称为"源头标记"。源头标记的颜色即为液体颜色。

Rule:
- 从源头房间开始，液体尝试流出：检查该房间旗帜指示的出口方向上是否存在通道（墙壁上的开口）。
  - 若该方向有通道，液体流过通道进入相邻房间，将该房间所有bg像素染为液体颜色。
  - 若该方向无通道，液体不流出，该房间仍被染色（源头房间始终被染色）。
- 对每个新被液体到达的房间，重复上述过程：检查该房间旗帜的出口方向是否有通道，有则液体继续流向下一个房间。
- 液体不会回流到已经被染色的房间。流动持续直到无法到达新房间为止。
- 旗帜标记和源头标记在输出中保留，黑色墙壁保留。

Key insight:
解题者需要两层关键推理：第一层是从2像素旗帜的几何排列中解读出每个房间的"出口方向"——旗面相对于旗杆的偏移方向即为液体被允许流出的方向；第二层是理解液体的传播是有方向约束的链式反应——每个房间只向旗帜指定的方向输出液体，因此即使一个房间有多个通道，液体也只从旗帜指向的那个方向流出，这使得液体的扩散路径不是简单的洪水填充，而是一条由旗帜方向决定的有向路径。
</description>

<description>
将网格中多个重叠透明图层按遮挡关系分离，根据每个图层的角落标记颜色确定其深度顺序，然后将所有图层水平并排展开在输出网格中。

Input structure:
- 背景色（bg）为网格中最常见的颜色。
- 输入网格中包含若干矩形区域相互重叠。每个矩形由单一颜色的边框绘制（1像素宽），内部为bg。
- 矩形之间存在遮挡：前方矩形的边框会覆盖后方矩形的边框像素。
- 每个矩形的四个角落中，恰好有一个角落的像素被替换为另一种特殊颜色（角标颜色），该角标颜色在整个网格中仅出现在角标位置。
- 不同矩形的角标颜色不同。
- 角标所在的角落位置编码了该矩形的深度层级：左上角 → 最前层（深度1），右上角 → 第二层，右下角 → 第三层，左下角 → 第四层。若矩形超过四个，则循环使用（第五个矩形角标又在左上角，深度5）。

Rule:
- 识别输入中所有矩形：通过边框颜色和角标位置重建每个矩形的完整边界（包括被遮挡的部分）。
- 根据角标所在角落位置确定每个矩形的深度排序。
- 输出网格的高度与输入相同，宽度为所有矩形宽度之和加上间隔（每两个矩形之间留1列bg）。
- 将矩形按深度从左到右排列：最前层在最左，最深层在最右。每个矩形完整绘制（无遮挡），角标像素恢复为矩形的边框颜色。

Key insight:
解题者需要三层推理：第一层是从重叠的混合图像中分离出各个独立矩形，需要利用边框颜色的一致性来重建被遮挡的部分；第二层是发现每个矩形恰好有一个角落颜色与众不同（角标），并建立角标位置到深度层级的映射规则（左上→1，右上→2，右下→3，左下→4）；第三层是理解输出格式——将分离后的矩形按深度顺序水平排列展开，去除所有遮挡。
</description>
