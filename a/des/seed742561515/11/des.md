将散落的彩色碎片按形状配对后，用配对双方的重叠区域构建输出拼图。

Input structure：
- 背景为主色（如 black）。网格中散布着若干单色连通对象，每个对象由一种非背景色构成。
- 这些对象成对出现：每对中的两个对象形状不同、颜色不同，但它们的最小外接矩形（bbox）尺寸完全相同。
- 每种 bbox 尺寸恰好只出现一对对象，因此配对关系唯一。

Rule：
- 将所有对象按 bbox 尺寸进行配对。
- 对于每一对对象，将它们各自的形状掩码对齐到相同大小的 bbox 左上角，对两个掩码取逻辑"与"——即仅保留两个对象都有像素的位置。
- 重叠区域中，属于面积较大的那个对象的位置保留该对象颜色，属于面积较小的那个对象的位置保留该对象颜色；若某位置两者都覆盖，则使用面积较大对象的颜色。
- 将所有配对的重叠结果按原始配对中靠上对象的行坐标从上到下排列，每个结果之间留一行背景行，组成输出网格。宽度取所有结果中的最大宽度，较窄的结果居左对齐，右侧填充背景色。

Key insight：配对依据不是颜色而是 bbox 几何尺寸的匹配，且输出只保留两个形状的交集区域，迫使解题者同时完成"尺寸配对"和"掩码交集"两层推理。
</new_puzzle>

根据边框缺口的位置和数量，从内部图案库中选取对应图案填入每个围栏。

Input structure：
- 背景为主色（如 black）。网格中有若干用同一种颜色（如 grey）绘制的封闭矩形围栏（一像素宽边框）。
- 每个围栏的边框上有 1 至 4 个单像素缺口（背景色），缺口分布在不同边上。
- 网格的底部（或右侧）有一排小型样本图案，每个样本是一个独立的小矩形区域，内含彩色像素构成的花纹，各样本大小可能不同。
- 样本数量恰好等于围栏中出现的不同缺口数的种类数（例如缺口数分别为 1、2、3，则有 3 个样本）。

Rule：
- 统计每个围栏边框上的缺口总数 N。
- 将底部样本按面积从小到大排序，编号 1、2、3……
- 缺口数为 N 的围栏对应编号为 N 的样本。
- 将对应样本平铺（tile）填满该围栏的内部区域（不含边框本身），平铺从围栏内部左上角开始，超出部分裁剪。
- 围栏边框、缺口、以及底部样本区域在输出中保持不变。

Key insight：解题者首先需要识别出缺口数量是分类键，然后需要发现样本的排序依据是面积而非位置顺序——这两层映射关系都需要从样例中归纳。
</new_puzzle>

将网格中的彩色路径按照路径端点所在象限进行颜色交换重绘。

Input structure：
- 背景为主色（如 black）。网格正中央有一个十字分隔线，由一种特殊颜色（如 grey）绘制，将网格分成四个象限（左上、右上、左下、右下）。
- 网格中有若干条不同颜色的曲线路径（宽度为 1 像素的 4-连通链），每条路径从一个象限出发、穿过十字线、终止于另一个象限。路径不会穿过十字线像素本身，而是通过十字线上的单像素缺口穿越。
- 每条路径的两个端点分别位于不同的象限。没有两条路径共享同一个缺口。

Rule：
- 对于每条路径，确定其起点所在象限 A 和终点所在象限 B。
- 查找另一条路径，其起点在象限 B、终点在象限 A（即连接方向恰好相反的配对路径）。
- 将这两条配对路径互换颜色：原来颜色为 C1 的路径变为 C2，原来颜色为 C2 的路径变为 C1。
- 十字线和背景保持不变。若某条路径没有配对（即不存在反向路径），则该路径颜色不变。

Key insight：解题者需要先追踪每条路径穿越了哪两个象限（空间推理），再发现颜色交换是基于象限对的"反向配对"关系（结构推理），而非简单的颜色映射或位置变换。
</new_puzzle>

将每个封闭区域内的散点按密度等级转化为同心收缩填充环。

Input structure：
- 背景为主色（如 black）。网格中有若干用同一颜色（如 blue）绘制的封闭矩形轮廓（一像素宽），大小各异。
- 每个矩形内部散布着若干同色（如 red）的散点像素，散点数量在不同矩形之间各不相同。
- 矩形之间不重叠、不相邻。

Rule：
- 对每个矩形，统计其内部散点的数量 N。
- 从该矩形内壁开始，向内逐层收缩绘制填充环。第 1 层环是紧贴矩形边框内侧的一圈像素，第 2 层是再向内收缩一圈的像素，依此类推。
- 恰好绘制 N 层填充环，使用散点的颜色（如 red）填充这些层。
- 若 N 大于可绘制的最大层数（即矩形太小），则整个内部全部填满。
- 清除原始散点，仅保留填充环。矩形边框保持不变。

Key insight：散点本身的位置无关紧要——它们仅仅是计数器；解题者需要发现"散点数 = 填充环层数"这一非显然的数量-几何映射关系，而非试图移动或连接散点。
</new_puzzle>

<new_puzzle>
通过箭头指示的传递链将源色块的颜色逐级传播到空白容器中。

Input structure：
- 背景为主色（如 black）。网格中有以下三类元素：
  1. **源色块**：若干个 2x2 的实心彩色方块，每个颜色不同。
  2. **空白容器**：若干个 2x2 的方块，内部全部为一种占位色（如 grey），表示"待填充"。
  3. **箭头**：由一种特定颜色（如 maroon）绘制的 3 像素 L 形标记，形如 "╗"、"╔"、"╝"、"╚" 四种朝向之一。每个箭头位于某个色块或容器的相邻位置，其 L 形开口方向指向另一个色块或容器。
- 箭头构成从源色块到空白容器的有向链：源色块 → 箭头 → 中间容器 → 箭头 → 下一个容器 → …… 每条链以一个源色块为起点，以一个或多个空白容器为终点。链可以分叉（一个节点通过多个箭头指向多个后续节点）。

Rule：
- 从每个源色块出发，沿箭头方向传播颜色。
- 链上的第一个空白容器被填充为源色块的颜色。
- 链上的第二个空白容器被填充为源色块颜色与背景色交替的棋盘格图案（2x2 中左上和右下为源色，右上和左下为背景）。
- 链上的第三个及之后的空白容器全部填充为背景色（即变为空）。
- 箭头标记在输出中被擦除（变为背景色）。源色块保持不变。

Key insight：解题者需要完成三层推理：（1）识别 L 形标记是方向箭头并确定指向关系，（2）沿箭头重建传播链的拓扑顺序，（3）发现填充规则随链上距离递变（实心 → 棋盘格 → 清空），而非简单的颜色复制。
</new_puzzle>

根据围栏内部"钥匙"形状在外部"锁孔"图案中找到匹配位置，并将锁孔所在对象整体着色。

Input structure：
- 背景为主色（如 black）。网格中有两类区域：
  1. **围栏区**：由一种颜色（如 green）绘制的小型封闭矩形，内部包含一个由另一种颜色（如 yellow）绘制的小型连通形状（"钥匙"），钥匙形状各不相同。每个围栏内恰好一把钥匙。
  2. **锁区**：由一种统一颜色（如 azure）绘制的较大连通对象，每个锁对象内部有一个与背景色相同的"锁孔"——即对象内部的一个封闭空洞。每个锁对象恰好一个锁孔。
- 围栏数量等于锁对象数量。每把钥匙的形状在平移归一化后与恰好一个锁孔的形状完全匹配。

Rule：
- 将每把钥匙的形状掩码进行平移归一化（左上角对齐到原点）。
- 将每个锁孔的形状掩码同样进行平移归一化。
- 将形状完全匹配的钥匙与锁孔配对。
- 对于每一对配对，将该锁对象的所有 azure 像素重新着色为对应钥匙的颜色（yellow 等）。同时将钥匙像素从围栏内擦除（变为背景色）。
- 围栏边框保持不变。

Key insight：解题者首先需要识别出围栏内的小形状和锁对象中的空洞之间存在"钥匙-锁孔"的形状匹配关系，然后通过归一化比对完成配对，最后用钥匙的颜色重绘整个锁对象——匹配依据是拓扑形状而非颜色或位置。
</new_puzzle>

<new_puzzle>
将多层透明叠片的遮挡顺序反转，重新绘制叠片堆叠后的可见结果。

Input structure：
- 背景为主色（如 black）。网格分为左右两半（由一列特殊颜色如 grey 的分隔线隔开）。
- 左半部分显示若干不同颜色的矩形叠片按某种从下到上的顺序堆叠后的结果：上层遮挡下层，每个叠片是实心矩形，重叠处只显示最上层颜色。
- 右半部分为空白（全为背景色），大小与左半部分相同。

Rule：
- 从左半部分的叠片堆叠图中，推断出每个叠片的完整矩形范围和堆叠顺序（从下到上）。
  - 每个叠片的完整矩形可通过其可见像素的外接矩形恢复。
  - 堆叠顺序通过重叠位置的可见颜色判断：可见的颜色在被遮挡的颜色之上。
- 在右半部分，按**反转后的堆叠顺序**重新绘制所有叠片：原来最上层的变为最底层，原来最底层的变为最上层。
- 左半部分保持不变。

Key insight：解题者首先需要从遮挡结果中逆向还原每个矩形的完整边界和层序（参考题 18 的机制），然后需要发现右半部分不是简单复制而是层序完全反转后的重新渲染——这要求对"遮挡"概念的双向理解。
</new_puzzle>
