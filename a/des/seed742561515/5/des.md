<description>
根据封闭区域内部孔洞标记的数量，从色带图例中查找对应颜色，用该颜色重新填充整个封闭区域。

Input structure:
- 背景为 black。
- 网格底部有一条水平色带图例，由若干连续的单行色块组成，从左到右依次代表数量 1、2、3、4……每个色块宽度为 2 像素，颜色各不相同（例如依次为 red、green、blue、yellow 等）。色带上方有一条 grey 水平分隔线横贯整个网格宽度。
- 分隔线上方散布着若干用 maroon 像素绘制的单像素宽封闭轮廓（形状不规则但保证封闭）。每个封闭轮廓的内部区域由背景色 black 填充，但其中散落着若干 orange 单像素点作为"孔洞标记"。

Rule:
- 对每个 maroon 封闭轮廓，数出其内部 orange 像素点的数量 N。
- 在底部色带图例中找到第 N 个色块对应的颜色 C（从左到右第 1 个色块对应 N=1）。
- 将该封闭轮廓内部所有 black 背景像素和所有 orange 像素统一填充为颜色 C。
- maroon 轮廓本身保持不变，色带图例和分隔线保持不变。

Key insight:
- 孔洞标记的数量是查表索引而非装饰——解题者需要先数孔洞，再从色带中定位对应颜色，最后才执行填充。两步都需要非平凡的归纳：第一步发现"数量决定颜色"，第二步发现"色带顺序即数量映射"。
</description>

<description>
将散落的彩色碎片沿其自身箭头指向滑动，直到碎片的凹口与目标框架的凸起完全咬合，然后用碎片的颜色填充框架对应区域。

Input structure:
- 背景为 black。
- 网格中央有一个用 grey 像素绘制的矩形框架（单像素宽边框），框架的四条边上各有若干向内突出的 grey 凸起（每个凸起为 1 像素宽、1-2 像素长的短条）。
- 框架外部散布着若干彩色碎片（每个碎片是一个由同色像素组成的 4-连通小形状）。每个碎片有且仅有一条边缘带有凹口（缺失像素的位置）。
- 每个碎片旁边紧邻一个由同色像素绘制的 3 像素长的箭头，箭头朝向上、下、左、右之一。箭头的绘制方式：3 个像素排成一行或一列，指向方向的端点额外在两侧各有 1 个同色像素构成箭尖（共 5 个像素组成 T 形指示方向）。

Rule:
- 读取每个碎片旁边箭头所指的方向。
- 将碎片沿该方向平移，直到碎片边缘的凹口与框架边上的某个凸起在位置上完全对齐吻合（凸起恰好填入凹口）。
- 碎片停止后，将碎片覆盖的所有像素（包括框架边框内侧的区域）染为碎片颜色。
- 箭头在输出中被擦除（变为背景色）。框架的其余 grey 边框保持不变。

Key insight:
- 箭头只给出运动方向，停止位置由凹凸匹配决定——解题者需先识别碎片的凹口形状，再在框架边上找到互补的凸起，才能确定最终位置。方向与形状匹配构成两层独立推理。
</description>

<description>
根据每个封闭房间内"钥匙"的形状，在房间的对应墙壁上开门（擦除墙壁像素），然后从门口向外发射与钥匙同色的射线直到碰到另一面墙或网格边界。

Input structure:
- 背景为 black。
- 网格中有若干用 blue 像素绘制的单像素宽矩形"房间"（封闭矩形框）。房间之间互不重叠但可能共用墙壁段。
- 每个房间内部恰好有一个由非 blue、非 black 颜色绘制的小形状"钥匙"。钥匙是一个 L 形、T 形或直线形的 3-4 像素 4-连通体。
- 钥匙的朝向指示开门方向：钥匙的"柄"（最长的连续直线段）平行于某条墙壁，"齿"（从柄末端垂直伸出的像素）指向上、下、左、右中的一个方向。

Rule:
- 读取每个房间中钥匙的齿所指方向 D。
- 在钥匙的齿所指方向上找到对应的那面房间墙壁。
- 在该墙壁上，与钥匙的柄对齐的位置处，擦除与柄等长的连续墙壁像素（将 blue 变为 black），形成"门"。
- 从门口的每个被擦除像素出发，沿方向 D 向外逐像素绘制钥匙颜色的射线，直到遇到 blue 墙壁像素或网格边界时停止（不覆盖墙壁像素）。
- 钥匙本身在输出中保持不变。

Key insight:
- 钥匙同时编码三层信息：颜色决定射线颜色，齿的方向决定开门的墙壁，柄的长度和位置决定门的宽度和在墙上的精确位置。解题者需要逐层解读钥匙的几何属性才能确定完整的变换。
</description>

<description>
识别网格中由边框颜色编码的同心矩形嵌套层级，将最内层容器中的种子图案逐层向外复制，每经过一层容器边框就顺时针旋转 90 度，并将图案颜色变为该层边框的颜色。

Input structure:
- 背景为 black。
- 网格中有若干层同心矩形边框，每层边框颜色不同（例如最外层 red、中间层 green、最内层 blue），边框均为单像素宽，层与层之间有背景间隔。
- 最内层矩形边框的内部包含一个由 yellow 像素绘制的小图案（种子图案），该图案不对称，占据内层空间的一部分。
- 每层边框的某一条边的中央位置有一个 orange 单像素标记（"传递口"），标记位于边框线上。

Rule:
- 从最内层开始，将种子图案复制到下一层的内部空间中（即内层边框与外一层边框之间的环形区域）。
- 复制时，图案相对于传递口的位置放置：从内层传递口"传出"，从外层传递口"传入"，图案的参考点对齐到外层传递口位置。
- 每向外传递一层，图案顺时针旋转 90 度。
- 图案的颜色在每一层都变为该层边框的颜色。
- 如果旋转后的图案超出该层环形区域的范围，则裁剪超出部分。
- 所有边框和传递口标记保持不变。最内层的原始 yellow 种子图案也保持不变。

Key insight:
- 解题者需要先识别嵌套层级结构和每层的传递口位置（第一层推理），再发现"每层旋转 90 度"的传递规则（第二层推理），最后理解图案颜色跟随目标层边框颜色变化（第三层推理）。三层规则共同作用才能确定最终输出。
</description>

<description>
根据网格中散落的"路标"像素与路径的行列对齐关系触发转向，路标颜色决定转向方向，从起点绘制一条折线路径直到离开网格。

Input structure:
- 背景为 black。
- 网格左上角有一个 green 单像素作为起点，起点右侧紧邻一个 green 像素表示初始方向为向右。
- 网格中散布着若干 red 和 blue 单像素"路标"。red 路标表示"右转 90 度"，blue 路标表示"左转 90 度"。
- 路标不在起点所在的行或列上，而是分布在网格的其他位置。

Rule:
- 从起点沿初始方向（向右）开始绘制 grey 路径线。
- 路径沿当前方向逐像素直线前进。前进过程中，检测路径当前所在的行或列上是否存在路标像素：水平移动时检测当前经过的每一列中是否有路标与路径同列，垂直移动时检测当前经过的每一行中是否有路标与路径同行。
- 当路径前进到某像素位置，其列号（水平移动时）或行号（垂直移动时）首次与某个尚未使用过的路标一致时，在当前位置触发转向：按路标颜色指示的方向转弯（red 右转、blue 左转）。
- 转弯后沿新方向继续直线前进，重复上述检测。
- 路径在到达网格边界时停止。
- 已使用的路标不会被再次触发。路标像素在输出中保持原色不变。

Key insight:
- 路标并不在路径上，而是通过"同行或同列"的空间对齐关系间接控制路径的转弯位置——解题者需要发现这种隐含的行列投影触发机制（第一层推理），再通过路标颜色区分左转和右转（第二层推理）。
</description>

<description>
将网格中每个彩色对象按照"投票点缺失方向"确定投影方向，然后在该方向上紧邻对象生成其单色影子，影子颜色由对象到投影方向网格边界的距离通过色带图例查表确定。

Input structure:
- 背景为 black。
- 网格中散布着若干彩色对象，每个对象由单一颜色的 4-连通像素组成，形状不规则。
- 每个对象的四周（上、下、左、右四个方向）的背景区域中，恰好有三个方向各放置了一个 grey 单像素"投票点"，投票点位于对象边界框外侧、与对象最近边缘相距 1 像素处，剩余一个方向没有投票点。
- 网格最底行有一个 maroon 色带图例：从左到右排列的色块依次对应距离值 1、2、3、4……每个色块宽 1 像素、高 1 像素。

Rule:
- 对每个对象，找出四个基本方向（上、下、左、右）中缺少 grey 投票点的那个方向——该方向即为影子投射方向。
- 将对象的整个形状沿投射方向平移，平移距离等于对象在投射方向上的跨度（即对象边界框在该方向上的长度），使得影子紧邻对象放置且不重叠。
- 影子的颜色确定方式：数出对象边界框中心到投射方向所指网格边界之间有多少个像素格的距离 D，在 maroon 色带图例中从左到右第 D 个色块的颜色即为影子颜色。
- 原始对象和 grey 投票点在输出中保持不变。若影子部分超出网格范围则裁剪。

Key insight:
- "三缺一"的投票点布局隐含指定了投影方向（缺失即方向），这是第一层非显然推理。影子颜色不由对象本身决定，而由对象到目标边界的空间距离通过图例间接编码，构成第二层独立推理。两层信息来源完全不同，必须分别归纳。
</description>

<new_puzzle>
<description>
在网格中根据边框上同色"种子对"的位置绘制连接线将网格内部切割为矩形区域，然后对区域按扫描顺序进行奇偶交替着色。

Input structure:
- 背景为 black。
- 网格的边框（最外一圈像素）上有偶数个彩色像素，它们两两配对：同色的两个像素构成一个"种子对"。每对的颜色互不相同（例如一对 red、一对 green、一对 blue）。
- 网格内部（非边框区域）全部为 black 背景。
- 每个种子对的两个像素分别位于边框的对向边上：若两像素在同一行则分别位于左右边框，若两像素在同一列则分别位于上下边框。

Rule:
- 对于水平配对的种子对（两个同色像素在同一行的左右边框上）：用该颜色绘制连接两像素的完整水平线段（覆盖该行从左边框到右边框的所有像素）。
- 对于垂直配对的种子对（两个同色像素在同一列的上下边框上）：用该颜色绘制连接两像素的完整垂直线段（覆盖该列从上边框到下边框的所有像素）。
- 这些彩色线将网格内部切割为若干矩形区域。
- 对所有矩形区域按从上到下、从左到右的扫描顺序编号（先按区域左上角的行坐标排序，行相同则按列坐标排序），从 1 开始。
- 编号为奇数的区域填充 grey，编号为偶数的区域保持 black 不变。
- 所有绘制的彩色线条保持原色不变。

Key insight:
- 解题者需要先完成"识别边框同色像素→配对→判断连线方向→绘制分割线"的步骤，再执行"区域识别→扫描排序→奇偶着色"的第二层推理。分割线的走向由种子对在边框上的位置关系隐含决定，而着色规则需要从样例中独立归纳。
</description>
</new_puzzle>
