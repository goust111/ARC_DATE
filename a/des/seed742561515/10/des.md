- `description`：根据框架内部碎片的拼合结果选择对应的颜色图例，再用该图例颜色重绘框架外部的投影轮廓。

- `Input structure`：
  - 背景为 black。
  - 网格中散布若干由 grey 单像素厚边框围成的矩形"容器"，每个容器内部包含若干不同颜色的小碎片（2-4 个像素的连通块），这些碎片之间有 black 间隙。
  - 网格底部有一行"颜色图例区"：若干 3x1 的色块，每个色块由一种独特颜色填充（如 red、blue、green、yellow 等），色块之间用 black 间隔。每个色块下方紧贴一个 1 像素的 maroon 标记，标记的水平偏移量为 0、1 或 2（即位于色块的左、中、右列）。
  - 每个容器外部（正上方）有一个由 grey 像素画出的矩形轮廓（未填充），其尺寸与容器相同。

- `Rule`：
  - 第一步——拼合判定：对每个容器，将其内部所有碎片在容器局部坐标中进行上下左右平移，判断它们是否能无重叠地恰好拼满容器内部空间。统计每个容器成功拼合后碎片的数量 N（碎片数范围 2-4）。
  - 第二步——图例匹配：在底部图例区中，找到 maroon 标记水平偏移量等于 N-2 的那个色块（偏移 0 对应 N=2，偏移 1 对应 N=3，偏移 2 对应 N=4），取该色块的颜色。
  - 第三步——重绘投影：将容器正上方的 grey 矩形轮廓用匹配到的图例颜色重绘（替换 grey 像素），容器自身和内部碎片保持不变。

- `Key insight`：碎片数量不是直接可读的数字，而需要通过心理拼图确认哪些碎片属于有效拼合；maroon 标记的位置编码了碎片数量到颜色的映射关系，解题者必须同时发现拼合规则和编码规则两层逻辑。
</new_puzzle>

<new_puzzle>
- `description`：沿每个箭头指示的方向，将箭头尾部连接的色带"折叠"到箭头头部一侧，折叠后色带的颜色层叠顺序反转。

- `Input structure`：
  - 背景为 azure。
  - 网格中有若干水平或垂直的多色条带，每条带由 2-5 个不同颜色的单像素宽段组成，各段首尾相连形成一条直线。
  - 每条色带的一端紧邻一个箭头标记。箭头由 maroon 像素绘制，形状为：一个 1 像素的箭杆沿色带方向延伸 1 格，加上一个 3 像素的 V 形箭头尖（箭头尖指向色带方向）。箭头位于色带的某一端。

- `Rule`：
  - 确定折叠轴：箭头所在端为"折叠起始端"，折叠轴是箭头尖端所指向的那个像素位置（即箭头与色带相邻的那个色段的末端边缘）。
  - 执行折叠：以折叠轴为镜像线，将箭头同侧的色带段翻折到轴的另一侧。翻折后各段覆盖在原有色段之上。
  - 层叠规则：翻折的段覆盖原有段——即在重叠位置，翻折过来的颜色替换原色。未被覆盖的原色段保持不变。
  - 移除箭头标记和箭杆，只保留折叠结果。
  - 折叠后色带总长度缩短为原来的较长半段的长度（若色带有 5 段，箭头在第 2 段侧，则将前 2 段翻折覆盖到后 3 段上，结果长度为 3 段）。

- `Key insight`：箭头指示的不是移动方向，而是折叠方向——需要像折纸一样将色带的一半翻转叠加到另一半上，理解"覆盖"而非"拼接"是关键认知跳跃。同时解题者需要看出折叠轴的位置由箭头端点决定。
</new_puzzle>

- `description`：识别网格中"种子图案"与"生长区域"的对应关系，将种子图案按照生长区域的形状进行平铺填充，填充方向由区域内的方向标记决定。

- `Input structure`：
  - 背景为 black。
  - 网格中有若干由 green 像素围成的封闭区域（不规则多边形轮廓，单像素宽边界，内部为 black）。每个封闭区域内部恰好有一个 red 单像素标记。
  - 网格中另有若干独立的小型彩色图案（"种子"），每个种子是一个 2x2 至 3x3 的多色连通块，不与任何 green 边界接触。每个种子旁边（4-邻接）有一个 red 单像素标记。
  - 每个封闭区域内部还有一个 orange 单像素标记，位于 red 标记的上方、下方、左方或右方（4-邻接方向之一）。

- `Rule`：
  - 配对：每个 green 封闭区域通过其内部 red 标记与外部种子旁的 red 标记进行配对——配对依据是 red 标记在网格中的行号或列号最接近的种子（每个区域唯一匹配一个种子）。
  - 确定平铺起始角：orange 标记相对于 red 标记的方向指示平铺的起始角——orange 在 red 上方表示从区域顶部开始向下铺，orange 在 red 右方表示从区域右侧开始向左铺，以此类推。
  - 平铺填充：从起始角开始，将种子图案按其原始尺寸在封闭区域内部进行周期性平铺（像贴瓷砖），仅绘制落在区域内部 black 像素上的部分，不覆盖 green 边界、red 和 orange 标记。
  - 移除区域外的种子和其旁边的 red 标记。

- `Key insight`：解题者需要发现三层独立的非显然规则——配对机制（距离最近的 red 标记）、起始方向编码（orange 相对 red 的位置）、以及平铺而非缩放的填充方式——每一层都无法仅凭一个样例确认。
</new_puzzle>

- `description`：根据"信号塔"发出的彩色脉冲在导线网络中的传播与混色结果，确定每个终端节点的最终颜色。

- `Input structure`：
  - 背景为 black。
  - 网格中有由 grey 像素绘制的单像素宽导线网络，导线沿水平或垂直方向延伸，在交叉点形成 T 形或十字形分叉。
  - 导线的若干末端（度为 1 的端点）旁边紧邻一个 2x2 的纯色方块，称为"信号塔"，颜色为 red、blue 或 yellow 之一。
  - 导线的其他末端（度为 1 的端点）旁边紧邻一个 2x2 的 black 方块（四周有 grey 单像素边框），称为"终端节点"。
  - 导线网络保证每个终端节点可以沿导线到达至少一个信号塔。

- `Rule`：
  - 每个信号塔沿其连接的导线发送自身颜色的"脉冲"。脉冲沿导线传播，在分叉点同时进入所有分支。
  - 当两种不同颜色的脉冲到达同一个终端节点时，进行减色混合：red + blue = magenta，red + yellow = orange，blue + yellow = green。
  - 当三种颜色的脉冲同时到达时，结果为 maroon。
  - 当只有一种颜色到达时，终端保持该颜色。
  - 用混合后的颜色填充每个终端节点的 2x2 内部区域（替换 black），grey 边框保留。导线和信号塔保持不变。

- `Key insight`：解题者首先需要识别导线网络的拓扑连接关系（哪些信号塔能到达哪些终端），然后发现颜色混合规则遵循直觉上的三原色减色混合，而非简单替换或覆盖。网络分叉使得追踪路径本身就需要视觉推理，混色规则则构成第二层需要归纳的逻辑。
</new_puzzle>

<new_puzzle>
- `description`：将网格中每个"建筑物"按照其内部"电梯井"标记的层数进行垂直切片重排，切片顺序由屋顶旗帜颜色在色谱中的排列决定。

- `Input structure`：
  - 背景为 azure。
  - 网格中有若干矩形"建筑物"，每栋建筑由不同颜色的像素填充（如 red、green、yellow 等），宽度为 4-8 像素，高度为 3-6 像素，建筑物之间用 1-2 列 azure 背景分隔。
  - 每栋建筑物内部有一列 black 像素，从建筑底部向上延伸但不到顶部，称为"电梯井"。电梯井的高度（black 像素数）为 1-3。
  - 每栋建筑物顶部正中有一个 1 像素的"旗帜"标记，颜色为 maroon、orange 或 yellow 之一（与建筑本体颜色不同）。

- `Rule`：
  - 第一步——切片：每栋建筑按照电梯井高度 H 被水平切分为 H 个等高切片（从上到下编号 1 到 H）。如果建筑高度不能被 H 整除，则最底部的切片包含多余的行。
  - 第二步——排序：所有建筑物的切片按照旗帜颜色分组（同色旗帜的建筑为一组），组内按建筑在网格中从左到右的原始顺序排列。组间的排列顺序为：maroon 组在最左，orange 组居中，yellow 组在最右。
  - 第三步——重排输出：在输出网格中，将所有切片按排序结果从左到右排列，每个切片宽度保持原建筑宽度，切片之间用 1 列 azure 分隔。每个切片的高度统一为所有切片中的最大高度（不足的切片底部用 azure 填充）。移除旗帜标记和电梯井（black 像素替换为建筑本体颜色）。

- `Key insight`：电梯井的高度决定切片数量而非移动距离，这一点违反"高度=位移"的常见直觉；旗帜颜色的排序规则需要跨多个样例对比才能归纳出固定的色谱顺序（maroon < orange < yellow）。两层规则——切片粒度和排序依据——必须同时正确归纳才能得到唯一正确输出。
</new_puzzle>

<new_puzzle>
- `description`：每个封闭房间内的"光源"通过门洞向相邻房间投射光锥，光锥颜色在穿过每道门时发生一次色相旋转。

- `Input structure`：
  - 背景为 black（表示空地/房间内部）。
  - 网格中有由 grey 像素构成的单像素宽墙壁，将网格分隔为若干矩形房间。
  - 每道墙壁上恰好有一个 1 像素宽的缺口（black 像素），即"门洞"，连通相邻的两个房间。
  - 部分房间内有一个 2x2 的纯色方块作为"光源"，颜色为 red、green 或 blue 之一。每个光源所在房间只有一个光源。

- `Rule`：
  - 光源向其所在房间的所有门洞投射光线。投射方式：从光源中心到门洞画一条轴对齐的直线（仅水平或垂直），将该直线经过的所有 black 像素染为光源颜色。若光源与门洞不在同一行或同一列，则不投射。
  - 光线穿过门洞后进入相邻房间，继续沿相同方向延伸直到撞击对面墙壁，但颜色发生一次旋转：red → green → blue → red。
  - 如果光线在相邻房间中沿延伸方向恰好对准该房间的另一个门洞，光线继续穿透该门洞进入下一个房间，再次旋转颜色，以此类推。
  - 多条光线交汇在同一像素时，使用混色规则：red + green = yellow，red + blue = magenta，green + blue = azure，三色交汇 = grey。光源本身和墙壁不变。

- `Key insight`：解题者需要分别发现三层规则——光线只沿轴对齐方向传播（非辐射状）、穿门时的颜色旋转序列（red → green → blue → red）、以及多光线交汇时的混色规则。每一层都需要对比多个样例才能确认，且颜色旋转是最隐蔽的一层，因为它要求解题者注意穿过门洞前后颜色的系统性变化。
</new_puzzle>

<new_puzzle>
- `description`：根据"模具"形状在"原料板"上冲压出对应的镂空，再将冲下来的碎片按模具边框颜色指定的旋转角度放置到收集区。

- `Input structure`：
  - 背景为 black。
  - 网格左半部分是一块大矩形"原料板"，由某种纯色（如 orange）填充，边缘无边框。
  - 网格右半部分有若干小型"模具"，每个模具由彩色单像素边框包围（边框颜色各不相同，如 red、blue、green、yellow），内部是一个由 black 和 grey 像素组成的形状模板——grey 像素表示冲压区域，black 像素表示保留区域。
  - 网格底部有一个由 maroon 单像素边框围成的空矩形"收集区"，内部全为 black。

- `Rule`：
  - 冲压顺序：模具按其在网格中从上到下的位置依次使用。
  - 冲压位置：每个模具的形状模板（grey 像素构成的图案）在原料板上寻找唯一的对齐位置——使得模板的 grey 像素恰好全部落在原料板的尚存纯色像素上。将这些像素从原料板上移除（变为 black），形成镂空。
  - 旋转编码：模具边框颜色决定冲下碎片的旋转角度——red 表示 0 度（不旋转），blue 表示 90 度顺时针，green 表示 180 度，yellow 表示 270 度顺时针。
  - 放置碎片：将旋转后的碎片（保持原料板颜色）依次放入收集区，从收集区左上角开始，按从左到右、从上到下的顺序紧密排列（碎片的包围盒之间不重叠，每个碎片的包围盒紧贴前一个碎片包围盒的右侧，行满换下一行）。

- `Key insight`：解题者需要分别发现冲压对齐规则（模具形状与原料板的唯一匹配）、颜色-旋转编码（需要跨样例对比边框颜色与碎片朝向的对应关系）、以及收集区的紧密排列规则。冲压的顺序性意味着后续模具的可用区域依赖前序冲压结果，增加了推理的前后依赖性。
</new_puzzle>
