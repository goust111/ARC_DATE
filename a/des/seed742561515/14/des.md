<description>
根据框架内部色块的排列方式推断其所属的外部图例编号，再用图例对应的标记颜色重新填充该色块区域。

Input structure
- 背景为黑色（Black）。
- 网格左侧有一列纵向排列的小型图例方块，每个图例方块是一个 2x2 的纯色区域，颜色各不相同（如 Red、Blue、Green 等），图例方块从上到下依次排列，间距为一行。
- 网格右侧有若干个由灰色（Grey）边框围成的矩形框架（边框厚度为一像素），每个框架内部包含若干个相同颜色的小色块（1x1 像素），这些色块散布在框架内部的黑色背景上。
- 每个框架内部色块的数量各不相同，且恰好等于某个图例方块在左侧图例列中的从上到下的序号（从 1 开始计数）。

Rule
- 对每个灰色框架，数出其内部色块的数量 N。
- N 即为左侧图例列中第 N 个图例方块的序号。
- 将该框架内部所有色块的颜色替换为第 N 个图例方块的颜色。
- 灰色边框、黑色背景和左侧图例保持不变。

Key insight
- 框架内色块的数量不是装饰属性，而是一个索引键；解题者需要先发现"数量 = 图例序号"这一非显然映射，再用映射结果进行颜色替换——两步推理缺一不可。
</description>

<description>
将每个前景对象沿其内部箭头指示的方向平移，平移距离等于该对象被另一个对象遮挡的像素数量。

Input structure
- 背景为黑色（Black）。
- 网格中有若干个不同颜色的矩形实心对象（如 Red、Blue、Green、Orange 等），部分对象之间存在重叠。
- 每个矩形对象的内部都嵌有一个用 Yellow 像素绘制的箭头标记：箭头由一条 3 像素长的直线段加上末端的一个像素偏移构成，形状类似 "→"（水平向右：第一行中间一个黄色像素在右端，第二行三个黄色像素水平排列，第三行中间一个黄色像素在右端）、"←"、"↑" 或 "↓"，分别指示右、左、上、下四个方向。箭头始终位于矩形的中心位置。
- 重叠区域显示为上层对象的颜色（即上层对象完全覆盖下层对象的对应像素）。

Rule
- 对每个对象，首先根据其完整矩形区域与其他对象的重叠，计算该对象被遮挡（被其他对象覆盖）的像素数量 D。
- 然后按照该对象内部箭头指示的方向，将整个对象（包括箭头）平移 D 个像素。
- 平移后，对象原来占据但现在空出的区域恢复为黑色背景。
- 被遮挡像素数为 0 的对象不移动。
- 最终叠放顺序不变。

Key insight
- 箭头给出方向，但距离隐藏在对象间的遮挡关系中——解题者必须先推断每个对象的完整矩形范围（包括被遮挡部分），才能计算出位移量，这需要从可见边界反推被遮挡的完整形状。
</description>

根据分隔线两侧区域中种子像素的颜色和位置，将种子沿分隔线对称镜像到对侧，并用种子颜色对其所在封闭腔室进行洪水填充。

Input structure
- 背景为黑色（Black）。
- 网格中有一条用 Grey 像素绘制的连续折线（仅由水平和垂直线段组成），将网格划分为两个不相连的区域（左右或上下）。折线从网格的一条边延伸到另一条边，完全分隔两侧。
- Grey 折线内部包含若干个用 Maroon 像素绘制的短墙段（水平或垂直，长度 2-4 像素），这些短墙段与 Grey 折线相连，在折线的一侧形成若干个封闭的腔室。
- 每侧有若干个不同颜色的种子像素（如 Red、Blue、Green、Orange），每个种子像素位于某个封闭腔室内部。
- 折线两侧的腔室结构不同：一侧有 Maroon 墙段形成腔室，另一侧没有墙段。

Rule
- 找到 Grey 折线，确定其将网格分为哪两个区域。
- 对于有 Maroon 墙段的一侧：将该侧的 Maroon 墙段结构沿 Grey 折线做轴对称镜像，在对侧生成对应的 Maroon 墙段，使两侧腔室结构对称。
- 对于每个种子像素：将其沿 Grey 折线做轴对称镜像到对侧的对应腔室中。
- 对每个种子像素（包括原始位置和镜像位置），用该种子的颜色对其所在封闭腔室进行洪水填充（填充至 Grey 或 Maroon 边界为止）。
- Grey 折线和 Maroon 墙段保持不变。

Key insight
- 解题者需要先识别出不对称的墙段结构并推断镜像规则，再理解种子的镜像和填充是两个独立操作——墙段镜像创建腔室结构，种子镜像确定填充位置，填充本身才是最终输出，三层推理层层递进。
</description>

<description>
每个前景环形对象内部的空心区域形状编码了一种旋转操作，将该环形对象按此旋转量旋转后放回原位。

Input structure
- 背景为黑色（Black）。
- 网格中有若干个彼此不接触的前景对象，每个对象由某种颜色（如 Red、Blue、Green、Orange 等）的像素组成。
- 每个对象是一个"有孔环形"：外轮廓为一个矩形区域（尺寸不一），内部有一个矩形孔洞（孔洞内为黑色背景）。
- 每个对象的外轮廓是彩色像素，但外轮廓并非均匀纯色——对象的四条边（上、下、左、右）中恰好有一条边使用 Azure 像素绘制，其余三条边使用对象的主色绘制。
- 孔洞的位置在对象内部不居中，而是偏向对象的某一个角落（左上、右上、左下、右下之一）。

Rule
- 对每个环形对象，确定其内部孔洞偏向的角落位置。
- 孔洞偏向左上角 → 不旋转（0 度）；偏向右上角 → 顺时针旋转 90 度；偏向右下角 → 旋转 180 度；偏向左下角 → 顺时针旋转 270 度。
- 将整个对象（包括彩色像素和孔洞）按上述角度绕对象自身中心旋转。
- 旋转后对象放回其原始边界框的位置（中心不变）。
- Azure 边标记随对象一起旋转。

Key insight
- 孔洞的偏移方向不是随机装饰，而是旋转角度的编码器；Azure 边标记在旋转后的位置变化为解题者提供了验证线索——先发现孔洞位置与旋转角度的对应关系，再观察 Azure 边标记的变化来确认旋转方向。
</description>

将散落的彩色碎片拼入网格中央的模板轮廓中，拼入位置由碎片边缘的锯齿缺口与模板内部隔墙的锯齿凸起互锁决定。

Input structure
- 背景为黑色（Black）。
- 网格中央有一个用 Grey 像素绘制的大型矩形模板框架，框架内部被 Grey 隔墙分成若干个不规则形状的腔室。隔墙厚度为一像素，与框架边框相连。
- 每个腔室的形状都不是简单矩形——隔墙上有锯齿状凸起（一个像素的突出），使腔室边界呈现独特的锯齿轮廓。
- 模板外部散布着若干个彩色碎片（每个碎片由同一种颜色的像素组成，颜色各不相同，如 Red、Blue、Green、Orange、Maroon 等）。每个碎片的形状与模板内某个腔室的形状完全吻合——碎片边缘有对应的锯齿缺口，与腔室隔墙上的锯齿凸起互锁。
- 碎片可能需要旋转（0、90、180 或 270 度）才能匹配腔室。

Rule
- 对模板内的每个腔室，在外部碎片中寻找形状完全匹配的碎片（允许旋转）。
- 匹配条件：碎片的像素形状经过旋转后，与腔室内的黑色空间逐像素一致（包括锯齿缺口与凸起的互锁）。
- 将匹配的碎片以正确的旋转角度放入对应腔室中。
- 输出仅包含模板框架区域的裁剪：Grey 框架和隔墙不变，每个腔室填充为匹配碎片的颜色。
- 每个碎片恰好匹配一个腔室，无歧义。

Key insight
- 简单的面积或边界框匹配不足以确定拼入关系——锯齿互锁是唯一的匹配签名；解题者需要先注意到隔墙凸起与碎片缺口的对应关系，再通过旋转尝试找到唯一匹配，最后完成填充。形状匹配的精细程度远超矩形拼图。
</description>

在由彩色节点和连接线段组成的网络中，找到每对同色节点之间的路径，并将路径上的线段染为该节点颜色。

Input structure
- 背景为黑色（Black）。
- 网格中有若干个用 Grey 像素绘制的线段网络：线段为水平或垂直的一像素宽直线，线段之间在交叉点相连，形成一个不规则的网格状网络。
- 网络的某些端点或交叉点处有彩色节点（2x2 的纯色方块），每种颜色恰好出现两个节点（如两个 Red、两个 Blue、两个 Green 等）。
- 彩色节点覆盖在 Grey 网络之上（即节点下方原本是 Grey 线段的交叉/端点位置）。
- 网络中任意两个同色节点之间恰好存在唯一一条沿 Grey 线段的简单路径（网络无环）。

- 对每对同色节点，沿 Grey 线段网络找到连接它们的唯一路径。

- 彩色节点本身保持不变。

Key insight
- 网络是无环的树结构，因此同色节点间的路径唯一且可通过视觉追踪确定——解题者需要先识别出网络的树性质（无环），再对每种颜色追踪唯一路径并染色。关键在于发现未被染色的 Grey 分支是"死胡同"，它们帮助区分正确路径与干扰分支。

<description>
根据每个封闭区域内"指示像素"的数量和颜色，决定该区域的边框绘制样式：数量控制边框厚度，颜色控制边框颜色。

Input structure
- 背景为黑色（Black）。
- 网格中有若干个由 Grey 单像素线段围成的封闭矩形区域，区域之间不重叠但可能共享边界线段。每个矩形区域内部为黑色背景。
- 部分矩形区域内部散布着若干个同色的指示像素（颜色为 Red、Blue、Green、Orange 等非 Grey 非 Black 颜色），每个区域内的指示像素颜色相同。
- 部分矩形区域内部没有指示像素（完全为黑色）。

Rule
- 对每个包含指示像素的矩形区域：
  - 数出指示像素的数量 N。
  - 将该区域的 Grey 边框替换为指示像素的颜色，并向区域内部加厚边框至 N 像素宽（即边框从外向内扩展，原始 Grey 线条位置为第 1 层，向内每增加一层像素直到达到 N 层）。
  - 如果 N 超过区域内部可容纳的最大厚度（即区域会被完全填满），则整个区域填充为该颜色。
- 没有指示像素的区域，其 Grey 边框保持不变。
- 指示像素本身被边框扩展覆盖（它们只是控制信号，不保留在输出中）。

Key insight
- 指示像素扮演双重角色：颜色决定"用什么画"，数量决定"画多厚"——解题者需要同时发现这两个维度的编码方式，且"向内加厚"的方向选择需要从多个样例中归纳确认。
</description>
</new_puzzle>
