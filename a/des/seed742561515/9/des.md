<new_puzzle>
根据框内图案的对称类型选择对应的染色图例，再用该图例颜色填充框外的延伸射线。

Input structure:
- 背景为黑色。网格中散布若干由灰色像素构成的矩形空心框，每个框内包含一个由单一前景色绘制的小型图案（3x3 至 5x5）。
- 网格角落区域放置三个颜色图例块：一个蓝色小方块标注"水平对称"、一个绿色小方块标注"垂直对称"、一个红色小方块标注"旋转对称（180度）"。每个图例块旁边紧贴一条由橙色像素组成的短射线（2 像素长），指示射线的发射方向（上、下、左或右）。
- 每个灰色框的四条边中恰好有一条边存在一个单像素缺口。

Rule:
- 第一步：判断每个灰色框内图案的对称类型——仅具有水平反射对称、仅具有垂直反射对称、或仅具有 180 度旋转对称（每个图案恰好属于其中一类）。
- 第二步：根据对称类型匹配角落的颜色图例，获取对应颜色（水平对称对应蓝色，垂直对称对应绿色，旋转对称对应红色）。
- 第三步：从灰色框的缺口位置出发，沿缺口朝外的方向，用匹配到的颜色画一条射线，射线一直延伸到网格边缘或碰到其他灰色框为止。
- 灰色框本身、框内图案以及角落图例块保持不变。

Key insight:
对称类型分类是第一层非平凡推理（需要逐个检验图案的对称性），颜色图例匹配是第二层推理（需要发现角落图例块与对称类型的对应关系），射线方向由缺口决定——三层信息共同决定输出。
</new_puzzle>

<new_puzzle>
将散落的彩色碎片按嵌套轮廓线索组装成俄罗斯套娃式的同心框架。

Input structure:
- 背景为黑色。网格分为左右两个区域，由一条灰色竖线分隔。
- 左侧区域包含若干不同颜色的 4-连通单色碎片对象，每个碎片是一个空心矩形框的形状（即环形），大小各不相同。
- 右侧区域包含一组由洋红色像素绘制的嵌套矩形轮廓线（仅绘制四个角的角标记，每个角标记为 L 形的 3 像素），这些角标记定义了若干同心矩形的位置和大小。

Rule:
- 第一步：根据右侧的洋红色角标记，推断出每一层同心矩形的确切尺寸（宽度和高度）。每四个 L 形角标记确定一个矩形。
- 第二步：将左侧的空心矩形碎片按外围尺寸与右侧推断出的矩形进行一一匹配（每个碎片恰好匹配一个矩形层）。
- 第三步：在输出中，移除灰色分隔线和右侧的角标记，将每个碎片平移到其匹配的矩形位置上，使碎片的外边缘与角标记定义的矩形重合，形成嵌套的同心框架结构。
- 碎片保持各自原来的颜色不变，多个碎片嵌套时不发生重叠（因为它们是不同大小的空心框）。

Key insight:
角标记仅给出四个角而非完整轮廓，解题者必须先从角标记反推出完整矩形尺寸（第一层推理），再将碎片与矩形按尺寸配对（第二层推理），最后正确放置碎片（空间对齐）。碎片的颜色和角标记的层数共同编码了组装顺序。
</new_puzzle>

<new_puzzle>
沿每个箭头指示的方向，将箭头源头的色带图案"印章式"逐格复制，直到碰到挡板或网格边缘，且每次复制时根据经过的色环改变印章颜色。

Input structure:
- 背景为黑色。网格中存在以下元素：
  - 若干条由单一颜色填充的短横条或短竖条（长度 2-4 像素），称为"色带"。
  - 每条色带的一端紧邻一个由橙色像素构成的箭头标记。箭头标记为 3 像素的 L 形：沿色带延伸方向的 1 像素柄 + 垂直于柄的 2 像素横杠，横杠朝向指示发射方向（上、下、左或右，且方向垂直于色带的走向）。
  - 散布的灰色单像素点称为"挡板"。
  - 网格中有若干由不同颜色绘制的单像素点称为"色环"，它们位于色带与挡板之间的空白路径上。

Rule:
- 对每条色带，沿箭头指示的方向（垂直于色带走向），将色带的形状逐格平移复制。每复制一步，色带图案平移一个像素。
- 复制持续进行，直到色带副本的任何像素碰到灰色挡板、另一条色带或网格边缘。
- 如果复制路径上经过一个色环像素，则从该色环位置开始，后续所有副本的颜色替换为色环的颜色。若路径上有多个色环，每次都替换为最近经过的色环颜色。
- 色环像素本身在输出中被色带副本覆盖。灰色挡板保留不变。箭头标记在输出中移除（替换为背景色）。

Key insight:
第一层推理是理解箭头与色带的空间关系以确定复制方向，第二层推理是发现色环充当"颜色切换开关"——副本的颜色不是固定的，而是在路径上被色环动态修改。解题者需要同时追踪空间传播和颜色状态变化。
</new_puzzle>

<new_puzzle>
根据每个封闭区域内种子像素的数量，从调色板行中选取对应位置的颜色，对该区域进行洪水填充。

Input structure:
- 背景为黑色。网格底部有一行单像素高的"调色板行"，由若干不同颜色的连续色段组成（例如：3 格蓝色、3 格红色、3 格绿色等），每个色段宽度相同（均为 W 格），色段之间无间隔。调色板行从左到右定义了位置编号 1, 2, 3, 依此类推。
- 网格上方有若干由灰色像素绘制的封闭多边形区域（4-连通闭合边界），区域之间互不嵌套、互不接触。
- 每个封闭区域内部散布着若干黄色单像素点，称为"种子像素"。不同区域内的种子像素数量各不相同。

Rule:
- 对每个灰色封闭区域，数其内部黄色种子像素的数量 N（N 不超过调色板色段总数）。
- 从调色板行中取第 N 个色段的颜色 C。
- 用颜色 C 洪水填充该封闭区域的整个内部（覆盖原有的黄色种子像素和黑色背景），但不改变灰色边界。
- 调色板行本身在输出中保持不变。

Key insight:
解题者必须首先发现底部色条是一个有序调色板（第一层推理：识别调色板结构与索引含义），然后发现种子像素的数量是索引键（第二层推理：计数到查表到填充）。表面上看起来像简单的"按颜色填充"，实际上颜色的选取需要跨区域比较种子数量与调色板位置的对应关系。
</new_puzzle>

<new_puzzle>
将每个对象的镜像投射到由该对象的指示线所指向的目标框内，并根据目标框的边框颜色对镜像进行重新着色。

Input structure:
- 背景为黑色。网格中包含以下元素：
  - 若干个由不同前景色绘制的小型 4-连通非对称图案对象（约 3x3 至 5x5 像素），称为"源对象"。
  - 若干个由不同颜色绘制的空心矩形框，称为"目标框"。每个目标框的内部为黑色背景，框的边框为单一颜色，且各目标框的边框颜色互不相同。每个目标框的内部尺寸恰好能容纳一个源对象的镜像。
  - 从每个源对象的一侧边缘延伸出一条由该源对象同色像素构成的单像素宽直线（水平或垂直），称为"指示线"。指示线的另一端紧邻某个目标框的外壁。每个源对象恰好有一条指示线连接到一个目标框，每个目标框恰好被一条指示线指向。

Rule:
- 第一步：沿每条指示线，确定源对象与目标框的配对关系。
- 第二步：确定镜像类型——若指示线为水平方向，则对源对象做左右镜像；若指示线为垂直方向，则对源对象做上下镜像。
- 第三步：将镜像后的图案放置在目标框内部的中心位置，并将图案的颜色替换为目标框边框的颜色。
- 源对象、指示线和目标框边框在输出中保持不变，仅在目标框内部新增镜像图案。

Key insight:
第一层推理是通过指示线追踪确定源与目标的配对（指示线容易被误认为装饰），第二层推理是发现指示线的方向同时编码了镜像的轴向（水平线对应水平翻转，垂直线对应垂直翻转），第三层是颜色并非保持源色而是采用目标框的边框色。三条独立规则需要从样例中分别归纳。
</new_puzzle>

<new_puzzle>
识别每行中重复图案的缺失片段，用该行独有标记色填补缺失，同时将完整图案的冗余副本擦除。

Input structure:
- 背景为黑色。网格被若干条水平灰色分隔线划分为若干水平条带（每条带高度相同）。
- 每个条带内包含同一个小型图案（约 3x4 像素）的若干个副本，这些副本沿水平方向排列且间距相等。所有副本使用同一种前景色绘制。
- 在每个条带中，恰好有一个副本存在缺失——即该副本的部分像素被擦除为背景色，形成不完整的图案。其余副本均完整。
- 每个条带中还有一个孤立的单像素标记点，颜色与该条带的前景色不同且各条带的标记色互不相同，该标记点位于缺失副本的正上方或正下方（在相邻的灰色分隔线上）。

Rule:
- 第一步：对每个条带，通过比较多个副本，识别出哪个副本是不完整的（有像素缺失）。
- 第二步：通过完整副本推断出缺失副本应有的完整形状，找出缺失的具体像素位置。
- 第三步：用该条带的标记色（而非该条带的前景色）填充缺失像素，使不完整副本在形状上变完整，但缺失部分以标记色显示。
- 第四步：擦除该条带中所有完整副本（将其像素替换为背景色），仅保留被修补后的那一个副本。
- 灰色分隔线和标记点在输出中保持不变。

Key insight:
第一层推理需要发现同一条带中的多个图案是同一模板的副本，并找到不完整的那个（需要逐个比对）。第二层推理需要理解输出不是简单修补，而是反转了"完整"与"缺失"的地位——保留修补后的缺陷副本、删除所有完整副本。第三层推理是发现标记色与缺失部分的着色关系，标记色用于区分原始像素和修补像素。
</new_puzzle>
