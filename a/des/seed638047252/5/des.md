<description>
根据封闭区域内部的色块"投票"结果，将区域边框重绘为得票最多的颜色，并用该颜色填充区域内的所有空白像素。

Input structure:
- bg = 最常见颜色（如 black）。
- Grey 线段构成若干互不相交的封闭矩形边框（一像素宽），将网格划分为多个矩形区域。
- 每个封闭区域内部散布着若干不同颜色的单像素点（如 red、blue、green 等），其余内部像素为 bg。
- 区域外部（边框之外的空间）可能也有少量 bg 像素，但没有彩色像素。

Rule:
- 对每个 grey 边框围成的封闭矩形区域，统计其内部各非 bg 颜色的像素数量。
- 找出数量最多的颜色 C（保证每个区域有唯一的最多颜色，不会出现平局）。
- 将该区域的所有 grey 边框像素重绘为 C。
- 将该区域内部所有 bg 像素也填充为 C，但保留原有其他颜色像素不变。
- 区域外部的像素保持不变。

Key insight: 内部散落的彩色像素不是装饰，而是对边框颜色的"投票"——需要先分区、再计票、最后用胜出颜色同时改写边框和背景，三步缺一不可。
</description>

<description>
将网格中分散的彩色碎片按形状配对，然后将每对碎片叠合为一个完整矩形，叠合位置由两块碎片的互补关系决定。

Input structure:
- bg = 最常见颜色（如 black）。
- 网格中散布着若干彩色连通区域（4-连通），每个区域是单一非 bg 颜色。
- 这些区域恰好可以两两配对：同一对中的两个区域形状互补——将它们叠放后恰好拼成一个无缝的实心矩形（矩形的宽和高由该对的最小外接矩形决定）。
- 配对的两个区域颜色不同，但它们的最小外接矩形尺寸相同。
- 每对中一个区域的像素恰好占据外接矩形中另一个区域像素未覆盖的位置（即它们是同一矩形中的正/负形）。

Rule:
- 找出所有外接矩形尺寸相同的区域对；对于同一尺寸的两个区域，将它们各自在外接矩形中的相对位置提取出来，验证二者的像素位置集合互补（合在一起恰好填满整个矩形）。
- 对于每个配对，以两个区域中行坐标更小者（若行相同则列坐标更小者）的位置为锚点，将另一个区域平移叠合上去，使二者共享同一外接矩形。
- 输出中只保留叠合后的结果：矩形内每个像素保持其原始颜色（来自哪个碎片就是哪个颜色），原位置清空为 bg。

Key insight: 配对依据不是颜色而是几何互补——两块碎片像拼图一样恰好填满同一矩形；解题者必须先通过外接矩形尺寸筛选候选对，再通过正/负形验证唯一匹配。
</description>

<description>
沿彩色"管道"传递信号：管道入口处的种子颜色经过管道中的"滤色器"逐段变色，最终在管道出口处输出变换后的颜色。

Input structure:
- bg = 最常见颜色（如 black）。
- Grey 像素构成若干一像素宽的正交折线路径（管道），每条管道是一条从端点到端点的简单路径，没有分叉。
- 每条管道的一个端点旁边紧邻一个 2x2 的单色方块（种子），种子颜色为非 bg、非 grey 的某种颜色。
- 管道路径中间某些位置上，grey 像素被替换为一个非 bg、非 grey 的彩色像素，称为"滤色器"。
- 每条管道的另一个端点旁边有一个 2x2 的 bg 区域（输出槽），等待被填色。
- 网格边缘有一个"色环图例"：由 6 个不同颜色的像素排成一行或一列的环形序列（如 red → blue → green → yellow → orange → magenta → red ...），表示颜色的循环顺序。

Rule:
- 沿每条管道从种子端向输出端遍历。
- 初始信号颜色 = 种子方块的颜色。
- 每经过一个滤色器像素，信号颜色在色环图例上向前推进一步（即变为色环中当前颜色的下一个颜色）。滤色器本身的颜色不影响变换，仅作为"需要变色一次"的触发标记。
- 到达输出端时，将输出槽的 2x2 区域填充为当前信号颜色。
- 管道上的 grey 像素和滤色器像素保持不变。

Key insight: 解题者需要同时发现两个非显然规律——(1) 色环图例定义了颜色递进顺序，(2) 管道中每个滤色器触发一次颜色步进而非直接替换颜色；最终输出颜色取决于种子颜色在色环上前进的步数。
</description>

<description>
根据网格中"镜面墙"的朝向，将每个彩色源对象反射到墙的另一侧，反射像的颜色由墙的颜色决定。

Input structure:
- bg = 最常见颜色（如 black）。
- 若干条 maroon 色的水平或垂直直线段（一像素宽、长度 ≥ 3），称为"镜面墙"。每面墙的一侧（且仅一侧）紧邻一个由若干像素组成的小型彩色图案（源对象），源对象为单一非 bg、非 maroon 颜色。
- 每面墙的两端各有一个端点像素；其中一个端点像素的颜色被替换为另一种非 bg、非 maroon 的颜色（"端点标记色"），另一个端点保持 maroon。
- 源对象一定位于墙的某一侧，墙的另一侧在对应位置全为 bg。

Rule:
- 对每面镜面墙，找到其一侧的源对象。
- 将源对象沿墙所在的轴做镜像翻转，映射到墙的另一侧对称位置。
- 反射像不使用源对象的原始颜色，而是使用墙端点标记色作为反射像的颜色。
- 源对象保持不变，墙保持不变（包括端点标记色像素）。
- 若反射像位置超出网格范围，则裁剪掉超出部分。

Key insight: 解题者需要同时识别三层结构——(1) 哪条线段是镜面墙、源对象在墙的哪一侧，(2) 反射操作是沿墙轴的镜像翻转，(3) 反射像的颜色并非继承源对象而是取自墙的端点标记色——只有将三者结合才能确定输出。
</description>

<description>
在网格中根据"路标"箭头依次连接散布的彩色节点，形成一条有序路径，路径线段的颜色由起点节点决定，终点节点决定下一段颜色。

Input structure:
- bg = 最常见颜色（如 black）。
- 若干个 3x3 的单色实心方块散布在网格中，每个方块颜色各不相同，称为"节点"。
- 每个节点（除最后一个外）的某一侧（上/下/左/右）紧邻一个由同色像素构成的 L 形"路标"箭头（占据 2x2 区域中的 3 个像素，缺失的角指示射出方向）。路标颜色与其所属节点颜色相同。
- 有一个节点没有路标，它是路径的终点。
- 有一个节点的路标颜色与节点自身颜色不同——路标使用的是另一个节点的颜色——它是路径的起点。起点节点路标的颜色指向它应连接的下一个节点。

Rule:
- 找到起点节点（路标颜色 ≠ 节点自身颜色的那个）。
- 起点节点的路标颜色 C₁ 指示下一个要连接的节点（即颜色为 C₁ 的节点）。
- 从起点中心沿路标箭头指示的方向（由 L 形缺角决定：缺角在 2x2 的哪个角落决定了向上/下/左/右中的一个方向）画一条一像素宽的直线段，颜色为起点节点的颜色，直到到达目标节点（C₁）的同行或同列，然后转 90° 朝向目标节点画到目标节点边缘停止。转角处的像素属于第一段颜色。
- 到达 C₁ 节点后，C₁ 节点的路标指示下一个目标节点 C₂，重复上述过程：从 C₁ 出发，画 C₁ 颜色的线段到 C₂。
- 依次类推，直到到达终点节点（无路标的节点）。
- 所有节点保持不变，路标箭头保持不变。

Key insight: 解题者需要发现三层嵌套规则——(1) 路标的 L 形缺角编码行进方向，(2) 路标颜色与节点颜色不同时标识起点、路标颜色指向下一目标节点形成链式连接顺序，(3) 连线采用正交折线且颜色继承出发节点——三层结构共同决定了路径拓扑和着色方案。
</description>

<description>
将网格中的彩色"种子带"沿封闭边框内壁螺旋生长，生长圈数由边框上的缺口数量决定。

Input structure:
- bg = 最常见颜色（如 black）。
- 若干个不同颜色的矩形封闭边框（一像素宽），边框颜色各不相同，边框之间互不重叠。
- 每个边框的某一条边的内侧紧贴一行（或一列）彩色像素，称为"种子带"。种子带颜色与边框颜色不同，种子带长度等于该边内侧的可用长度。
- 每个边框上有若干个缺口（边框像素被 bg 替代的位置），缺口数量为 1 到 4 不等。

Rule:
- 对每个边框，数出其缺口数量 N。
- 从种子带出发，沿边框内壁顺时针方向螺旋生长 N 圈。每"一圈"定义为种子带颜色沿内壁铺满一整圈（四条边的内侧各一行/列像素）。
- 第一圈紧贴边框内壁（距边框 1 像素），第二圈在第一圈内侧（距边框 2 像素），依此类推。
- 如果螺旋向内生长时空间不足（矩形太小），则在空间耗尽处停止。
- 边框上的缺口在输出中被修补（恢复为边框颜色）。
- 种子带本身算作第一圈的一部分。

Key insight: 缺口数量不是破损——它是编码螺旋圈数的计数信号；解题者需要先发现"缺口数 = 生长圈数"的对应关系，再理解螺旋的生长方向和层叠方式，两步归纳缺一不可。
</description>

<new_puzzle>
<description>
识别网格中的"模板区域"和"实例区域"，用模板的结构修复实例中被遮挡的部分，遮挡物的形状决定输出中需要保留的额外标记。

Input structure:
- bg = 最常见颜色（如 black）。
- 网格中有若干对矩形区域。每对中的一个是"模板"——由某种颜色 A 绘制的完整图案（连通的像素图形），背景为 bg，外围有一圈一像素宽的 grey 边框。
- 每对中的另一个是"实例"——与模板具有相同的 grey 边框尺寸，内部应包含与模板相同的图案（颜色也是 A），但图案被一个不同颜色 B 的矩形色块部分遮挡（B 覆盖在 A 之上）。
- 模板与实例的配对依据：它们的 grey 边框尺寸完全相同，且内部图案颜色 A 相同。
- 每个模板恰好对应一个实例，反之亦然。

Rule:
- 对每对模板-实例：
  - 找到实例中颜色 B 的矩形遮挡区域。
  - 用模板中对应位置的像素替换实例中被 B 遮挡的区域——即恢复实例中 A 的完整图案。
  - 在恢复后的实例中，将原本被遮挡且模板中为 bg 的位置标记为颜色 B（即遮挡矩形与模板图案 A 不重叠的部分保留为 B）。
  - 模板区域在输出中被完全清除为 bg（包括其 grey 边框）。

Key insight: 解题者需要三步推理——(1) 通过边框尺寸和图案颜色配对模板与实例，(2) 理解遮挡物下方的原始图案可从模板恢复，(3) 遮挡物的"非重叠部分"（遮挡区中模板为空的地方）作为新标记保留——模板既是修复工具又在完成任务后被消除。
</description>
</new_puzzle>
