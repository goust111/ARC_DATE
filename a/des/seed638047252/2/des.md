<description>
根据框架边缘缺口的形状从候选碎片中选出匹配碎片，再按缺口对侧的色标将碎片重新上色后嵌入框架。

Input structure:
- bg = black。网格中有一个大型单色（如 blue）矩形空心框架，框架壁厚 1 像素。
- 框架四条边上各有 0-2 个缺口（即框架壁上连续缺失的像素段），每个缺口宽 2-4 像素。
- 每个缺口在框架内部紧邻对侧壁处有一个 1 像素的色标（颜色各不相同，如 red、green、yellow 等）。色标位于缺口正对面的框架内壁上。
- 框架外部散落若干小碎片（每个碎片由 2-4 个同色像素组成，颜色均为框架色），碎片形状各异。

Rule:
- 对每个缺口：在框架壁上，缺口形成一个特定宽度和朝向的开口。
- 在框架外部的候选碎片中，找到形状恰好能填满该缺口的碎片（碎片像素数等于缺口像素数，且排列方向与缺口一致）。
- 找到缺口正对面框架内壁上的色标像素，读取其颜色。
- 将匹配碎片平移到缺口位置，填入框架壁，颜色改为色标的颜色（而非原来的框架色）。
- 色标像素本身被擦除（变为 bg）。
- 未被匹配的多余碎片保持不动。

Key insight: 解题需要两层独立推理——第一层是通过形状匹配将碎片与缺口配对，第二层是发现缺口对侧的色标决定了碎片嵌入后的最终颜色，色标并非装饰而是重上色指令。
</description>

<description>
将散落的彩色种子像素沿其所在行/列的通道滑动到交叉点，在交叉点处按两通道颜色的叠加规则生成新颜色。

Input structure:
- bg = black。网格上有若干水平和垂直的灰色（grey）通道，每条通道宽 1 像素，形成一个正交网格状结构。通道之间的交叉点也是灰色像素。
- 部分通道上（非交叉点位置）放置了单个彩色像素（如 red、blue、yellow），称为"种子"。每条通道上最多有一个种子。
- 网格边缘外没有通道延伸。

Rule:
- 每个种子沿其所在通道向交叉点方向滑动：水平通道上的种子水平滑动，垂直通道上的种子垂直滑动。
- 种子始终滑向离它最近的交叉点。如果种子两侧等距各有一个交叉点，则向左/向上滑动（优先级：左 > 上）。
- 种子到达交叉点后停下，将该交叉点像素染为种子颜色。
- 如果一个交叉点同时被两个种子到达（一个从水平通道、一个从垂直通道），则该交叉点的颜色按固定混色规则确定：red + blue = magenta，red + yellow = orange，blue + yellow = green，其他任意两色组合 = maroon。
- 种子原来所在的位置恢复为灰色通道像素。
- 仅被一个种子到达的交叉点直接变为该种子颜色。没有种子到达的交叉点保持灰色。

Key insight: 核心隐蔽性在于混色规则——解题者必须先发现种子的滑动目标是最近交叉点，再从多个样例中归纳出交叉点处两色叠加的混色映射表，两层推理缺一不可。
</description>
</new_puzzle>

<description>
依据小型"编织图样"模板，将大网格中交错排列的彩色条带在交叉区域进行上下层遮挡，生成编织效果。

Input structure:
- bg = black。网格左上角有一个小型方阵（如 4x4），由两种颜色（如 red 和 blue）组成棋盘式或自定义交替图案，称为"编织图样"。图样中 red 表示"水平条在上"，blue 表示"垂直条在上"。
- 网格主区域中有若干水平彩色条带（每条带高 2 像素，颜色各异但都不是 red 或 blue）和若干垂直彩色条带（每条带宽 2 像素，颜色各异）。条带之间有间隔。
- 水平条带和垂直条带在主区域内形成若干矩形交叉区域。在输入中，所有交叉区域的像素颜色均为水平条带的颜色（即默认水平在上）。

Rule:
- 将编织图样视为一个周期性平铺模板。把主区域中所有交叉区域按行列顺序编号（从左上角开始，先行后列）。
- 第 i 行第 j 列的交叉区域对应编织图样中位置 (i mod H, j mod W) 的像素（H、W 为图样高宽）。
- 若该图样像素为 red：交叉区域保持水平条带颜色不变（水平在上）。
- 若该图样像素为 blue：交叉区域的像素全部改为对应垂直条带的颜色（垂直在上）。
- 非交叉区域的条带像素和 bg 不变。编织图样本身在输出中保留不动。

Key insight: 解题者需要三层推理——首先识别左上角小方阵是控制模板而非装饰，其次理解交叉区域的行列编号与模板的周期性映射关系，最后发现模板中两种颜色分别代表"哪条带在上层"的遮挡指令。
</description>

<description>
根据封闭区域内"锚点"像素的数量，从外部色带中截取等长片段填入该区域，填充方向由锚点的排列朝向决定。

Input structure:
- bg = black。网格中有若干由 grey 像素围成的封闭矩形区域（灰色边框厚 1 像素），区域大小不等（内部空间从 3x3 到 6x6 不等）。
- 每个封闭区域内部有 1-5 个 green 像素（锚点），它们排列在同一行或同一列上，形成一条水平或垂直的短线段。
- 网格边缘处（紧贴网格的上、下、左或右边界）有若干条彩色色带，每条色带为连续的单色像素行或列（颜色各不相同，如 red、blue、orange、yellow 等），长度不等。

Rule:
- 对每个封闭区域，数出其中 green 锚点的数量 N。
- 在边缘色带中找到长度恰好等于 N 的那条色带，确定其颜色 C。
- 观察区域内锚点的排列方向：若锚点排成水平线，则从锚点所在行的左侧边框内壁开始，向右绘制 N 个颜色为 C 的像素；若排成垂直线，则从锚点所在列的上侧边框内壁开始，向下绘制 N 个颜色为 C 的像素。
- 绘制的 C 色像素覆盖锚点（green 消失）。
- 边缘色带在输出中被擦除（变为 bg）。

Key insight: 锚点同时编码了两个信息——数量决定从哪条色带取色（长度匹配），排列方向决定填充的朝向。解题者需要先发现数量-长度的配对关系，再发现方向由锚点阵列的几何朝向决定，而非由色带位置决定。
</description>

<description>
在分隔的子网格中，依据"影子"轮廓与原始图形的差异区域确定平移向量，然后将同一向量应用于另一个子网格中的图形。

Input structure:
- bg = black。网格被一条 1 像素宽的 grey 竖线均匀分为左右两个子网格。
- 左侧子网格包含：一个由某种颜色（如 red）绘制的小型连通图形（3-6 像素），以及同一图形的一个"影子"副本，影子用另一种颜色（如 azure）绘制。影子与原图形形状完全相同，但位置存在平移偏移（水平和/或垂直偏移若干格）。影子与原图的像素可能部分重叠，重叠处显示为原图颜色（red 覆盖 azure）。
- 右侧子网格包含：一个由第三种颜色（如 yellow）绘制的另一个小型连通图形，没有影子。

Rule:
- 在左侧子网格中，通过比较 red 图形和 azure 影子的位置差异，推断出平移向量 (dr, dc)——即影子相对于原图的行偏移和列偏移。
- 将该平移向量 (dr, dc) 应用到右侧子网格中的 yellow 图形：在 yellow 图形当前位置偏移 (dr, dc) 处，绘制一份 yellow 图形的副本。
- 左侧子网格保持不变。右侧子网格中原始 yellow 图形保留，新副本也用 yellow 绘制。若副本超出子网格边界则截断。
- 分隔线保持不变。

Key insight: 左侧子网格是一个"指令面板"，解题者必须从原图与影子的空间关系中提取出隐含的平移向量，然后将这个向量作为操作指令施加到右侧完全不同的图形上。难点在于当影子与原图部分重叠时，需要仔细辨别哪些像素属于影子、哪些属于原图，从而准确推断偏移方向和距离。
</description>

<description>
根据每个房间中"门"的位置和数量，从走廊中吸取对应数量的彩色标记，沿门的反方向在房间内铺设路径。

Input structure:
- bg = black。网格中有若干由 maroon 像素围成的矩形封闭"房间"（边框厚 1 像素），以及连接房间的 1 像素宽 maroon 走廊。
- 每个房间的边框上有 1-3 个缺口（各 1 像素宽），即"门"，门连通走廊。
- 走廊中散布着单个彩色像素标记（如 red、blue、green、yellow），每个走廊段中的标记颜色相同但数量不等。
- 每个房间内部完全为 bg。

Rule:
- 对每个房间，找出它的所有门。统计该房间的门数量 D。
- 对每个门，沿走廊方向（从门向外）找到该走廊段中的彩色标记。取距离门最近的 D 个标记（如果标记不足 D 个则取全部），记录其颜色 C。
- 从门的位置向房间内部（与走廊方向相反的方向）延伸，绘制一条长度为 D 的直线路径，颜色为 C。
- 被吸取的走廊标记从走廊中擦除（变为 bg）。
- 如果路径在房间内撞到对面墙壁，则在墙壁处停止（不穿墙）。

Key insight: 门的数量 D 同时控制两件事——从走廊吸取多少个标记，以及向房间内铺设多长的路径。解题者需要先发现门数与路径长度的对应关系，再发现颜色来源是对应走廊中最近的标记，两个规则通过"门"这一枢纽相互关联。
</description>
</new_puzzle>

<description>
将散落的图形碎片按照"旋转罗盘"指示的角度旋转后，拼入中央拼图框的对应槽位。

Input structure:
- bg = black。网格中央有一个大型正方形区域（如 10x10），由 grey 边框围成，内部被 grey 十字线分为四个等大的象限（左上、右上、左下、右下），每个象限内部为 bg。
- 每个象限的正中央有一个 1 像素的彩色标记（如 red、blue、green、yellow），颜色各不相同。
- 中央框外的四个角落区域各有一个小型彩色图形碎片（2-5 像素的连通形状），碎片的颜色与某个象限中央标记颜色相同。
- 网格中还有一个"旋转罗盘"：一个 3x3 的小方阵位于网格某条边的中央位置，罗盘中心为 grey，四个正方向格子（上、右、下、左）各有一个箭头标记。箭头用 orange 像素绘制：上方格子中 1 个 orange 像素表示"不旋转"，右方格子中 1 个 orange 像素表示"顺时针 90 度"，下方格子中 1 个 orange 像素表示"180 度"，左方格子中 1 个 orange 像素表示"逆时针 90 度"。罗盘中实际只有一个方向格子包含 orange 像素。

Rule:
- 每个碎片通过颜色与象限中央标记配对，确定它应被放入哪个象限。
- 读取旋转罗盘指示的旋转角度。
- 将每个碎片按罗盘指示的角度旋转后，平移到其目标象限中，使碎片的中心（边界框中心）与象限中央标记重合。
- 碎片像素覆盖象限内的 bg 像素。中央标记被碎片覆盖（消失）。
- 碎片原来所在的角落区域清空为 bg。罗盘在输出中被擦除。

Key insight: 解题包含三层推理——第一层是颜色配对确定碎片的目标象限，第二层是识别罗盘结构并解读其旋转指令（orange 像素在罗盘的哪个方位决定旋转角度），第三层是将统一的旋转应用于所有碎片后精确定位到各自象限中心。
</description>
</new_puzzle>
