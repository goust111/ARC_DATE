<new_puzzle>
根据框架内标记像素的颜色，在框架外侧对应方向生长出与框架同色的"枝条"，枝条长度由框架内同色标记的数量决定。

Input structure:
- bg = black。网格中有若干单色矩形空心框架（frame），每个框架用不同颜色绘制（如 red、blue、green 等）。
- 每个框架内部散布着少量单像素标记点，这些标记点的颜色各异，但均取自网格中其他框架的颜色。
- 框架大小不一，位置不重叠，彼此之间留有足够空间。

Rule:
- 第一步：对每个框架 F，检查其内部的标记像素。每种标记颜色 C 对应网格中颜色为 C 的另一个框架 G。
- 第二步：确定框架 F 内颜色为 C 的标记像素所在的方位——标记像素相对于框架 F 中心偏向哪一侧（上、下、左、右），即为生长方向。若同色标记有多个，取它们整体的重心方位。
- 第三步：从框架 F 对应方向的外侧边缘中点出发，沿该方向向外生长一条宽 1 像素的直线"枝条"，颜色为框架 F 自身的颜色，长度等于框架 F 内颜色为 C 的标记像素个数。
- 每种标记颜色各生长一条枝条，不同枝条互不覆盖。

Key insight: 框架内部的彩色标记像素扮演双重角色——其颜色指向另一个框架建立关联，其在框架内的空间位置决定枝条生长方向，其数量决定枝条长度。解题者需要同时识别颜色映射和空间方位两层信息。
</new_puzzle>

<new_puzzle>
将网格中散落的碎片拼回原始图案，拼合的依据是碎片边缘的颜色"锯齿"必须互补咬合。

Input structure:
- bg = black。网格中散布着若干矩形碎片（connected components），每个碎片的内部为某种纯色填充，但碎片的一条或多条边缘上镶嵌有不规则的单像素凸起和凹陷——凸起用另一种颜色绘制，凹陷表现为边缘上的 bg 缺口。
- 网格角落有一个小的灰色（grey）矩形参考框，标明输出网格的目标尺寸（参考框的宽度和高度即为输出尺寸）。

Rule:
- 第一步：识别每个碎片的四条边缘轮廓。每条边缘上的凸起像素序列构成该边的"齿型签名"——记录凸起在边上的相对位置。
- 第二步：两个碎片可以拼接，当且仅当一个碎片某条边的凸起位置恰好对应另一个碎片对应边的凹陷位置，且反之亦然——即两条边的齿型互补。
- 第三步：将所有碎片通过互补匹配无缝拼合，形成一个完整矩形。碎片不旋转、不翻转，仅平移。拼合后，凸起像素填入对方的凹陷处，边缘变得齐平，凸起像素的颜色保留。
- 输出为拼合后的完整矩形，尺寸与灰色参考框一致。

Key insight: 碎片边缘上看似装饰性的彩色凸起和黑色凹口实际是拼合密码——只有齿型互补的边才能对接，这既决定了哪些碎片相邻，也决定了它们的相对平移量。
</new_puzzle>

<new_puzzle>
根据"种子图案"在分区网格中进行元胞自动机式的单步扩散，每个区域的扩散规则由其邻域中已填色区域的数量决定。

Input structure:
- bg = black。网格被单像素宽的 grey 线分割成规则的 N×M 个矩形区域（cell），形成棋盘状布局。
- 少数区域内填有纯色图案（如一个小十字、小 L 形或小方块），这些是"种子区域"。其余区域为空（全 bg）。
- 每个种子区域内的图案颜色各不相同，图案形状也可能不同。

Rule:
- 第一步：识别每个种子区域的图案形状（在区域内的相对位置和占据的像素集合）。
- 第二步：对每个空区域，数其四邻域（上下左右，不含对角）中有多少个区域是非空的（包含种子或已被填充的区域）。该计数 k 决定此空区域是否被填充以及如何填充：
  - k = 0：保持为空。
  - k = 1：将唯一邻居的图案原样复制到此区域（保持图案在区域内的相对位置不变），颜色也相同。
  - k >= 2：将多个邻居中面积最大的那个图案复制到此区域，但颜色改为 red。
- 第三步：此扩散只执行一步——即只有与原始种子直接相邻的空区域会被填充，不进行迭代。

Key insight: 解题者需要先发现网格的分区结构和种子位置，然后归纳出"邻居计数决定填充策略"这一非显然规则——单邻居时忠实复制，多邻居时发生颜色突变并选择面积最大者，这两层判断构成递进的推理结构。
</new_puzzle>

<new_puzzle>
在网格中，每个彩色"信号塔"向四个正方向发射射线，射线在遇到"镜面"对象时发生 90 度反射并变色，最终射线路径及颜色构成输出。

Input structure:
- bg = black。网格中有若干单像素的"信号塔"，每个信号塔有不同颜色（如 red、blue、green、yellow 等）。
- 网格中还有若干由 grey 像素组成的短线段（长度 2-4 像素），这些线段要么是水平的，要么是垂直的，充当"镜面"。
- 水平镜面将垂直方向的射线反射为水平方向，垂直镜面将水平方向的射线反射为垂直方向。镜面本身在输出中保留。

Rule:
- 第一步：每个信号塔从其位置向上、下、左、右四个方向各发射一条射线，射线颜色与信号塔颜色相同。
- 第二步：射线沿直线传播，逐像素延伸，将经过的 bg 像素染为射线当前颜色。射线遇到以下情况停止或改变：
  - 遇到网格边界：停止。
  - 遇到另一个信号塔：停止（不覆盖信号塔）。
  - 遇到镜面的侧面（即射线行进方向垂直于镜面朝向）：射线在镜面前一格停止，然后从镜面的对应端点沿反射方向继续传播。反射后射线颜色变为 orange。
  - 遇到已被染色的像素：停止（先到先得）。
- 第三步：所有信号塔同时发射，按照距信号塔的步数逐格同步扩展。当两条射线同一步到达同一像素时，该像素染为 maroon。

Key insight: 解题者首先需要识别信号塔和镜面的角色区分，然后理解镜面的反射机制（方向转 90 度且变色为 orange），最后发现同步扩展的冲突规则（同时到达变 maroon）。三层规则递进隐藏，仅从样例的射线路径和颜色变化中可以逐步归纳。
</new_puzzle>

<new_puzzle>
将网格中每个多色对象拆解为单色层，按层的面积从大到小依次堆叠到目标区域，形成"考古地层"式的嵌套输出。

Input structure:
- bg = black。网格左半部分包含若干多色对象（8-connected components），每个对象由 2-4 种颜色的像素混合组成，形成不规则但紧凑的图案。
- 网格右半部分有与左侧对象数量相同的空矩形框（用 grey 单像素线绘制），每个框的大小足以容纳对应对象的外接矩形。框内全为 bg。
- 左侧对象与右侧框通过从上到下的排列顺序一一对应（第一个对象对应第一个框，依此类推）。

Rule:
- 第一步：对每个多色对象，将其拆解为若干"单色层"——同一颜色的所有像素构成一层，记录每层在对象外接矩形内的相对位置。
- 第二步：按每层包含的像素数量从大到小排序。面积最大的层最先放置（最底层），面积最小的层最后放置（最顶层）。
- 第三步：在对应的右侧框内，依次将各层叠放到框的中心位置。后放置的层会覆盖先放置的层——即面积小的层叠在面积大的层之上，遮挡其下方的像素。
- 所有层以其自身形状的几何中心与框的中心对齐放置。若某层宽或高为偶数，中心取偏左上的像素。

Key insight: 原始对象中各颜色像素看似随意混合，但它们实际上是多个独立单色形状的叠加。解题者必须先发现"按颜色拆层"的分解思路，再发现"按面积排序后重新堆叠"的重组规则——输出中可见的图案是面积排序后从大到小叠放的结果，与输入中的混合外观截然不同。
</new_puzzle>

<new_puzzle>
网格中的封闭区域形成一棵隐含的"包含树"，根据每个区域在树中的深度交替填充两种颜色，同时将叶节点区域标记为第三种特殊颜色。

Input structure:
- bg = black。网格中有一种前景色（如 blue）绘制的线条，这些线条形成多层嵌套的封闭轮廓——外层大轮廓包含内层小轮廓，小轮廓可能再包含更小的轮廓，形成 3-4 层嵌套。
- 轮廓线条为单像素宽的连通闭合曲线，轮廓之间不接触。
- 所有轮廓内外的非线条区域在输入中均为 bg。

Rule:
- 第一步：识别所有 bg 连通区域（4-connected），并根据"被多少层轮廓包围"确定每个区域的嵌套深度。最外层（不被任何轮廓包围的背景）深度为 0。
- 第二步：构建包含树——深度为 d 的区域是深度为 d-1 的区域的子节点。
- 第三步：对于深度为奇数的区域（1, 3, 5...），填充为 yellow；深度为偶数且大于 0 的区域（2, 4...），填充为 green。深度为 0 的外部背景保持 black。
- 第四步：在包含树中，没有子区域的叶节点区域（即不再包含更深层轮廓的最内层区域），无论其深度奇偶，统一覆盖填充为 red。
- 轮廓线条本身保持原色 blue 不变。

Key insight: 解题者需要先通过视觉识别嵌套层次建立"包含树"结构，然后发现深度奇偶决定填充颜色的交替规则，最后还需发现叶节点的特殊覆盖规则——这一例外打破了简单的奇偶交替模式，构成第三层需要独立归纳的推理。
</new_puzzle>

<new_puzzle>
网格中散落的箭头指向各自的目标对象，每个目标对象按箭头数量进行等分切割，切割方向由箭头的朝向多数投票决定。

Input structure:
- bg = black。网格中有若干彩色矩形对象（每个矩形为单一颜色填充，颜色各异，尺寸不同）。
- 网格中还有若干由 grey 像素绘制的小箭头（每个箭头占 3x3 像素区域：一条 3 像素长的轴线加上轴线末端的两个像素构成箭尖，形成 5 像素的箭头形状）。箭头朝向为上、下、左、右之一。
- 每个箭头的轴线延长方向上最先遇到的彩色矩形即为该箭头指向的目标对象。

Rule:
- 第一步：对每个彩色矩形，收集所有指向它的箭头。
- 第二步：统计这些箭头的朝向——若水平朝向（左或右）的箭头更多，则切割方向为垂直切割（用垂直线将矩形等分）；若垂直朝向（上或下）的箭头更多，则切割方向为水平切割（用水平线将矩形等分）。朝向数相同时，默认垂直切割。
- 第三步：将矩形沿确定的方向等分为 k 份，k 等于指向该矩形的箭头总数。等分线用 bg 色（黑色单像素线）绘制，将矩形切开。若矩形在该方向的像素数不能被 k 整除，则前若干份各多 1 像素（从左到右或从上到下分配余量）。
- 箭头本身在输出中被擦除（变为 bg）。

Key insight: 解题者需要先建立箭头到矩形的指向关系（通过延长线追踪），然后发现箭头朝向的多数投票决定切割方向（这是反直觉的——箭头朝向并非直接指定切割方向，而是通过垂直/水平多数票间接决定），最后发现箭头数量等于切割份数。三个规则层层递进，且投票到正交切割这一反转最具隐蔽性。
</new_puzzle>
