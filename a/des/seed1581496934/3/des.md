<new_puzzle>
description: 根据封闭区域内部的小色块"投票"结果，决定该区域的填充颜色，并将落选色块替换为胜选颜色。

Input structure:
- 背景色为 black。网格被 grey 线条分割为若干不规则的封闭区域（区域形状各异，但均由 grey 单像素宽的墙壁围成）。
- 每个封闭区域内部散布着若干单像素色块（可能包含 red、blue、green、yellow 等多种颜色），其余内部像素为 black 背景。
- 每个区域内至少有两种不同颜色的色块。

Rule:
- 第一步（投票统计）：对每个封闭区域，统计其内部各颜色色块的数量。数量最多的颜色为该区域的"胜选颜色"；若出现平局，则选择在区域内位置最靠上（行号最小）、再靠左（列号最小）的那个色块的颜色。
- 第二步（区域填充）：将该封闭区域内所有 black 背景像素替换为胜选颜色。
- 第三步（色块统一）：将该区域内所有非胜选颜色的色块也替换为胜选颜色。最终每个区域内部全部变为单一的胜选颜色。
- grey 墙壁保持不变。

Key insight: 解题者需要先识别出 grey 墙壁围成的封闭区域（区域分割），再在每个区域内部独立完成颜色"多数决"统计——两步推理缺一不可：区域边界的识别决定了统计范围，而统计结果决定了填充颜色。
</new_puzzle>

<new_puzzle>
description: 将散落的彩色碎片根据形状互补关系配对拼合，拼合后的完整矩形移动到网格边缘的对应颜色锚点处。

Input structure:
- 背景色为 azure。网格内散布着若干彩色碎片（每个碎片是一个 4-连通的不规则形状，使用 red、green、yellow、magenta 等颜色）。
- 每两个碎片恰好可以拼合成一个无缝的矩形（碎片 A 的形状与碎片 B 的形状互补，二者拼在一起刚好填满一个轴对齐的矩形区域，无重叠无空隙）。
- 互补的两个碎片颜色不同。
- 网格的四条边缘上各有若干单像素的彩色锚点（颜色与碎片颜色对应），锚点的 4-邻域全部为背景色或网格边界。

Rule:
- 第一步（配对）：找到形状互补的碎片对。方法是：对每个碎片计算其最小包围矩形，两个碎片的最小包围矩形尺寸相同，且将它们的包围矩形对齐叠放后，一个碎片占据的像素恰好是另一个碎片未占据的像素（即互为补集）。每个碎片恰好有唯一的互补配对。
- 第二步（锚点匹配）：拼合后的矩形包含两种颜色。在网格边缘找到与这两种颜色都匹配的锚点对（同一条边上、且间距等于矩形沿该边方向的长度减一）。
- 第三步（放置）：将拼合后的矩形平移到锚点对所指示的位置，使矩形的对应颜色角与锚点重合。原碎片位置恢复为背景色。

Key insight: 解题者必须先完成"形状互补配对"这一空间推理，再利用边缘锚点的颜色和间距信息确定放置位置——配对机制和定位机制是两个独立的非平凡推理层。
</new_puzzle>

<new_puzzle>
description: 每个彩色对象充当"印章"，沿其内部箭头所指方向反复盖印自身副本，直到遇到与该对象同色的边框线停止，盖印间距由对象内部的特殊标记行/列数决定。

Input structure:
- 背景色为 black。网格中散布着若干彩色对象（每个对象是一个紧凑的矩形色块，使用 red、blue、green、orange 等颜色）。
- 每个对象内部恰好有一个由 yellow 像素构成的箭头图案：箭头由一条 3 像素长的直线段（箭身）和末端两侧各一个像素（箭头尖）组成，箭头方向为上、下、左、右之一。例如，向右的箭头形如：中间行三个 yellow 像素，上一行和下一行的最右列各一个 yellow 像素。
- 每个对象内部还有若干 maroon 像素排成一行或一列（与箭头方向垂直），maroon 像素的数量即为盖印步长。
- 网格中还有若干与对象同色的单像素宽直线段，平行于箭头方向，充当"挡板"。

Rule:
- 对每个对象，读取其内部箭头方向和 maroon 标记数量 N。
- 从对象当前位置出发，沿箭头方向每隔 N 个像素的间距（从对象边缘起算，间距为 N 个 black 像素）放置该对象的完整副本（包括 yellow 箭头和 maroon 标记）。
- 当下一个副本的任何像素会覆盖到与该对象同色的挡板线时，停止盖印（该副本不放置）。
- 不同对象的副本若发生重叠，后处理的对象覆盖先处理的（处理顺序按对象在网格中从上到下、从左到右排列）。

Key insight: 解题者需要三层推理：（1）识别对象内部 yellow 箭头的朝向以确定运动方向；（2）数出 maroon 标记的像素数以确定盖印间距；（3）找到同色挡板线以确定终止位置。三层信息分别编码在不同的视觉元素中，缺少任何一层都无法完成变换。
</new_puzzle>

<new_puzzle>
description: 网格中的彩色"管道"片段需要根据端口颜色首尾相接拼成完整回路，最终将回路内部围成的区域填充为回路共有的背景底色。

Input structure:
- 背景色为 grey。网格中散布着若干矩形管道片段，每个片段是一个 3 像素宽的直线段或 L 形弯头，由某种主色绘制（如 blue、red、green 等），主色构成管道壁。
- 每个管道片段的两个开放端口（即管道壁在片段边缘处断开的位置）各有一个单像素的端口标记色，端口标记色与主色不同。
- 同一种端口标记色在整个网格中恰好出现两次（分属两个不同片段的端口）。

Rule:
- 第一步（连接配对）：将拥有相同端口标记色的两个端口配对。每一对端口之间用该标记色画一条单像素宽的直线连接（水平或垂直，两个待连接端口必定共行或共列）。
- 第二步（回路识别）：所有片段和连接线共同构成若干封闭回路。每条回路由多个片段的主色管道壁和多段连接线组成。
- 第三步（区域填充）：对每条封闭回路，找出其内部围成的区域（使用 4-连通洪水填充从回路外部排除法确定内部）。将内部的所有 grey 背景像素替换为该回路中所有管道片段共有的、出现次数最多的主色。

Key insight: 解题者需要先通过端口颜色匹配将碎片逻辑连接起来（非空间邻接而是颜色符号匹配），再追踪连接后的拓扑结构判断封闭性，最后从管道壁的主色中提取填充色——这是"符号匹配→拓扑推理→属性提取"的三层结构。
</new_puzzle>

<new_puzzle>
description: 根据网格中"样本行"展示的局部替换规则，对网格下方的目标图案执行对应的图案替换，其中替换规则的适用范围由目标图案中隐藏的分区边界决定。

Input structure:
- 背景色为 black。网格被一条横向的 magenta 分隔线分为上下两部分。
- 上半部分包含若干"样本行"，每行展示一个局部替换规则：左侧是一个小型彩色图案（如 3x3），中间有一个 yellow 单像素箭头（箭头形状为：一列三个 yellow 像素作为箭身，箭身右端的上下各一个 yellow 像素作为箭头尖，整体指向右方），右侧是与左侧同尺寸的替换后图案。每行恰好一对"原图案到替换图案"。
- 下半部分是一个较大的目标区域，其中包含由 orange 细线（单像素宽）划分的若干子区域。每个子区域内部包含一个与某条样本行左侧图案完全匹配（形状和颜色均相同）的图案实例。
- 同一种样本图案可能在目标区域中出现多次（在不同子区域中）。

Rule:
- 对下半部分的每个子区域，找到其内部包含的图案，与上半部分的样本行左侧图案逐一比对，确定匹配的替换规则。
- 将子区域内的匹配图案替换为对应样本行右侧的替换后图案（位置不变，仅颜色和内部结构改变）。
- orange 分区线和 magenta 分隔线保持不变。
- 上半部分的样本行保持不变。

Key insight: 解题者需要完成两层非平凡推理：（1）从上半部分的多个样本行中归纳出"图案到替换"的映射字典（每对样本的差异方式可能各不相同，需逐对理解）；（2）在下半部分中，先识别 orange 线划分的子区域边界，再在每个子区域内定位并匹配图案，最后执行替换。分区边界的存在防止了跨区域的错误匹配，增加了空间定位的推理难度。
</new_puzzle>
