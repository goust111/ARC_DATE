description
根据框架对象的边缘缺口方向，从散落的碎片中选取匹配碎片，旋转后嵌入缺口，再用碎片内部的颜色标记决定整个框架的填充色。

Input structure
- 背景为黑色。
- 网格中有一个较大的单色矩形框架（仅边框，内部为背景色），框架的边缘上有若干个连续缺口（缺口处为背景色）。
- 框架外部散布着若干小型彩色碎片对象，每个碎片由两种颜色组成：外层轮廓色与框架颜色相同，内部恰好有一个像素为另一种颜色（标记色）。
- 每个碎片的轮廓形状恰好能匹配框架上某一个缺口的形状（可能需要旋转 0/90/180/270 度）。

Rule
- 对框架边缘上的每个缺口，找到外部碎片中轮廓形状与该缺口形状匹配的那个碎片（允许旋转）。
- 将匹配碎片旋转到正确朝向后，将其轮廓像素填入缺口位置，使框架边缘恢复完整。
- 读取该碎片内部标记色像素的颜色，用该颜色填充框架内部所有背景像素。
- 若多个缺口的碎片标记色不同，则框架内部按行分段填充：从上到下，每个缺口对应的标记色填充框架内部等高的水平条带，条带数量等于缺口数量，条带顺序与缺口在框架边缘上从上到下、从左到右的出现顺序一致。
- 碎片原位置清除为背景色。

Key insight
碎片不仅仅是拼图块——其轮廓形状决定嵌入位置，而内部隐藏的标记色像素决定框架内部的填充配色方案。解题者需要同时完成形状匹配和颜色传递两层推理。
</new_puzzle>

<new_puzzle>
description
将网格中的彩色种子像素沿其所在象限的对角方向生长为矩形色块，色块的边长由同色种子的数量决定。

Input structure
- 背景为灰色。
- 网格正中央有一条完整的水平分割线和一条完整的垂直分割线，均为黑色，将网格分为四个象限。
- 每个象限中散布着若干单像素的彩色种子，颜色可能为红、蓝、绿、黄、橙等。
- 同一种颜色的种子可能出现在同一象限内的不同位置，也可能出现在不同象限。

Rule
- 首先统计每种颜色在整个网格中出现的种子总数 N。
- 对每个种子像素，以该像素为起点，向其所在象限的对角方向（即远离中心十字的方向）生长一个 N×N 的实心矩形色块，颜色与种子相同。
- 具体方向：左上象限的种子向左上生长，右上向右上，左下向左下，右下向右下。种子像素位于色块最靠近中心十字的那个角。
- 若色块超出网格边界，则在边界处裁剪。
- 若两个色块区域重叠，后绘制的色块（按行优先、从左到右的种子顺序）覆盖先绘制的。
- 黑色十字线和种子像素本身保持不变。

Key insight
种子颜色的全局计数决定了每个种子生长的尺寸，而种子所在象限决定了生长方向。解题者必须先发现"同色种子总数=边长"的数量规律，再结合象限位置推断方向，两层规律缺一不可。
</new_puzzle>

<new_puzzle>
description
识别输入网格中被遮挡的周期图案的平铺单元，利用未遮挡区域重建平铺单元后，将遮挡物替换为其内部孔洞形状所指定的旋转版本。

Input structure
- 网格由一个小尺寸（如 3×3 或 4×4）的多色平铺单元周期性铺满。
- 网格上有若干个单色实心矩形遮挡物，每个遮挡物的颜色与平铺单元中的任何颜色都不同。
- 每个遮挡物内部恰好有一个由背景色组成的孔洞（连通区域），孔洞的形状为以下四种之一：朝上的 L 形、朝右的 L 形、朝下的 L 形、朝左的 L 形。这四种 L 形分别对应 0 度、90 度、180 度、270 度旋转。

Rule
- 首先利用所有未被遮挡物覆盖的像素，推断出底层的周期性平铺单元。
- 对每个遮挡物矩形区域，用推断出的平铺单元恢复该区域本应显示的图案。
- 然后读取该遮挡物内部孔洞的 L 形朝向，将恢复出的图案块围绕其中心旋转对应角度（朝上=0 度，朝右=90 度，朝下=180 度，朝左=270 度），再填入遮挡物区域。
- 孔洞本身也被旋转后的图案覆盖（即最终输出中不保留孔洞）。

Key insight
遮挡物不仅标记了需要修复的区域，其内部孔洞的形状还编码了一条隐藏指令——恢复的图案需要额外旋转。解题者需要先完成周期图案重建，再识别孔洞形状与旋转角度的对应关系，形成两层独立的归纳任务。
</new_puzzle>

<new_puzzle>
description
在网格中找到所有由边框围成的封闭房间，根据房间内标记点的数量选择对应的填充图案模板，再根据标记点的颜色决定模板的配色。

Input structure
- 背景为黑色。
- 网格中有若干条蓝色线段（水平或垂直，宽度为一个像素），这些线段相互连接形成若干个封闭的矩形房间。
- 每个房间内部可能包含零个或多个单像素标记点，标记点的颜色为非黑色、非蓝色的前景色（如红、绿、黄、橙等）。
- 网格的一个角落（如左上角）有一排图案模板展示区：展示区包含若干个小矩形样例，每个样例旁边标注了对应的标记点数量（通过在样例左侧放置相应数量的竖排灰色像素来表示）。每个样例内部展示了一种二值填充图案（用白色和黑色表示）。

Rule
- 识别所有由蓝色线段围成的封闭矩形房间。
- 数出每个房间内的标记点数量 K。
- 在展示区中找到左侧有 K 个灰色像素的样例，获取其对应的填充图案。
- 将该填充图案按周期平铺到房间内部（不覆盖蓝色墙壁），其中样例中的白色像素替换为房间内标记点的颜色（若房间内有多种标记色，取出现次数最多的那种），黑色像素保持为黑色背景。
- 不含标记点的房间（K=0）保持内部全黑不变。
- 展示区本身在输出中保持不变。

Key insight
解题需要三层推理：第一层是识别蓝色线段构成的封闭房间结构；第二层是通过标记点数量在展示区查表获取正确的填充图案；第三层是用标记点颜色对图案进行配色替换。展示区的灰色像素数量是连接房间与图案的隐含索引键。
</new_puzzle>

<new_puzzle>
description
将散布的彩色箭头对象沿其指向方向发射射线，射线在碰到其他箭头时停止，最终根据每个箭头收到的射线数量来决定该箭头是否保留及其颜色变换。

Input structure
- 背景为黑色。
- 网格中散布着若干个由 3×3 像素绘制的箭头对象。每个箭头由一种前景色绘制，形状指示方向：朝上的箭头为底行三像素加中列顶部两像素（形成 T 形上指），朝下为顶行三像素加中列底部两像素，朝左为右列三像素加中行左侧两像素，朝右为左列三像素加中行右侧两像素。
- 箭头颜色各异，可为红、绿、蓝、黄、橙、紫等。
- 箭头之间至少间隔两个像素，不会相邻或重叠。

Rule
- 每个箭头从其 3×3 区域的尖端像素出发，沿箭头指向方向发射一条宽度为 1 像素的射线，射线颜色与箭头本身相同。
- 射线逐格延伸，直到碰到另一个箭头的任意像素（不含自身）或到达网格边界时停止。射线的终点像素不覆盖被碰到的箭头。
- 所有射线同时发射（互不阻挡，射线不会阻止其他射线）。
- 发射完所有射线后，统计每个箭头被多少条来自其他箭头的射线命中（射线终点恰好与该箭头的某个像素相邻）。
- 被 0 条射线命中的箭头从输出中删除（替换为背景色）。
- 被 1 条或以上射线命中的箭头保留，且其颜色变为命中它的第一条射线（按从上到下、从左到右的发射者顺序）的颜色。
- 所有射线本身保留在输出中。

Key insight
箭头的方向决定射线路径，但箭头最终是否存活及其颜色取决于其他箭头射线的命中情况。解题者必须先理解箭头形状与方向的编码关系，再模拟射线传播，最后推断命中计数对箭头存亡和变色的影响——三层推理环环相扣。
</new_puzzle>

<new_puzzle>
description
根据网格边缘的颜色编码序列，逐层向内剥离边框并重新着色，剥离层数和颜色顺序由边缘序列决定。

Input structure
- 网格为一个较大的纯色矩形（如全部为绿色），尺寸至少 10×10。
- 网格的最上方一行（第 0 行）包含一个从左端开始的短颜色序列：若干个连续像素依次为不同颜色（例如红、蓝、黄），序列结束后该行剩余像素恢复为网格底色。
- 颜色序列长度为 K（K 一般为 2 到 5）。

Rule
- 读取第 0 行左端的颜色序列，记为 C1, C2, ..., CK。
- 将网格最外层边框（第 0 圈）所有像素重新着色为 C1。
- 将次外层边框（第 1 圈）所有像素重新着色为 C2。
- 依此类推，第 i 圈着色为 C(i+1)，直到 K 层全部着色完毕。
- 第 K 圈及更内部的所有像素保持原始底色不变。
- "第 i 圈"定义为：距离网格边缘恰好 i 个像素的所有位置构成的环形边框。

Key insight
第 0 行的颜色序列看似装饰，实际上既编码了剥离层数又编码了每层的颜色。解题者需要发现边缘序列与同心边框之间的对应关系——序列的第 N 个颜色恰好是从外向内第 N 圈边框的颜色。这是一个从线性序列到二维环形结构的映射规律。
</new_puzzle>

<new_puzzle>
description
将输入中的多个相同形状但不同颜色的对象按颜色条指定的顺序堆叠到基准位置，堆叠顺序决定遮挡关系，最终输出堆叠后的合成图像。

Input structure
- 背景为黑色。
- 网格中散布着若干个形状完全相同（平移后重合）的对象，每个对象颜色不同。
- 网格右下角有一个小型颜色条：若干个单像素从上到下排列，颜色对应网格中出现的对象颜色，排列顺序为从上到下即为堆叠时从底到顶的顺序。
- 每个对象由单一颜色绘制，内部无孔洞。

Rule
- 识别所有前景对象，确认它们的平移归一化形状相同。
- 读取右下角颜色条，获取堆叠顺序（颜色条最上方的颜色在最底层，最下方的颜色在最顶层）。
- 选择颜色条中最底层（最上方）颜色对应的对象位置作为输出的基准位置。
- 按照堆叠顺序，将每个对象依次平移到基准位置并叠加绘制。后绘制的对象覆盖先绘制的。
- 输出为以基准位置对象的边界框为范围的裁剪结果，仅包含堆叠后的合成图像。
- 颜色条本身不出现在输出中。

Key insight
所有对象形状相同这一事实需要解题者主动验证，而非显然可见。颜色条不是装饰而是堆叠顺序的密钥。解题者需要先发现形状一致性，再解读颜色条的排序语义，最后执行有遮挡关系的叠加合成——每一步都需要独立的归纳推理。
</new_puzzle>
