<new_puzzle>
description：根据每个封闭区域内部标记像素的颜色，从区域边框上找到同色缺口，再将区域内容沿缺口方向平移出去并填充到外部空白处。

Input structure
- 背景为黑色。网格中有若干个由同一种非背景颜色（如蓝色）绘制的单像素厚矩形边框，每个矩形边框恰好有一个单像素缺口（缺口处为背景色）。
- 每个矩形边框的内部包含一个由某种颜色绘制的小型图案（sprite），该图案的颜色与边框颜色不同。
- 矩形边框外部的空间全部为背景色。
- 每个边框的缺口分别位于上、下、左、右四条边之一。

Rule
- 对每个矩形边框，定位其唯一的单像素缺口所在的边（上/下/左/右），确定该缺口指示的方向（缺口在上边则方向向上，缺口在下边则方向向下，以此类推）。
- 将矩形内部的图案沿该方向平移，平移距离等于图案边缘到缺口所在边的像素距离加上边框厚度（即一个像素），使图案完全移出边框。
- 在输出中，原始边框保留但缺口被补全（用边框颜色填上），矩形内部变为纯背景色，图案出现在边框外部的新位置上。

Key insight
缺口既是方向指示器又是"出口"——解题者需要先识别缺口位置以确定弹出方向，再理解边框在输出中被修复而内容被弹射出去这一双重变换。
</new_puzzle>

<new_puzzle>
description：将散落的彩色碎片按颜色配对后拼合为完整的矩形，再按矩形面积从小到大排列输出。

Input structure
- 背景为黑色。网格中散落着若干彩色碎片，每种非背景颜色恰好出现两个不规则的四连通碎片。
- 同色的两个碎片形状互补：将它们适当平移（不旋转、不翻转）后可以精确拼合成一个无间隙、无重叠的实心矩形。
- 不同颜色的碎片之间没有重叠，且碎片之间在原图上有足够间隔。

Rule
- 对每种颜色，找到其两个碎片。将其中一个碎片平移到另一个碎片旁边，使二者精确拼合成一个完整的实心矩形（拼合方式唯一）。
- 计算每个拼合后矩形的面积（宽 × 高）。
- 在输出网格中，按面积从小到大，将这些完整矩形从左到右水平排列，相邻矩形之间间隔一列背景色，所有矩形顶部对齐于第一行。
- 输出网格的高度等于最大矩形的高度，宽度等于所有矩形宽度之和加上间隔列数。

Key insight
解题者需要先通过形状互补关系推断出哪两个碎片能拼成矩形（这是第一层推理），再发现输出排列顺序由面积决定（这是第二层推理），两层规律都需要从样例中归纳。
</new_puzzle>

<new_puzzle>
description：用网格边缘的彩色标尺行/列确定每个内部对象的裁剪窗口，输出裁剪后的对象按标尺颜色分组堆叠。

Input structure
- 背景为黑色。网格的第一行和第一列是"标尺"：第一行由若干段连续的彩色像素构成（每段为一种颜色，段与段之间无间隔），第一列也由若干段连续的彩色像素构成。
- 第一行各段的长度定义了列方向的分区宽度，第一列各段的长度定义了行方向的分区高度。二者交叉形成若干矩形分区。
- 在网格内部（去掉第一行和第一列后的区域），某些分区中包含由单一非背景颜色绘制的图案，其余分区为空（全背景色）。
- 每个图案所在分区的行标尺颜色和列标尺颜色唯一确定该分区的"坐标"。

Rule
- 找出所有包含非空图案的分区。
- 对每个非空分区，将其内容裁剪为图案的最小包围盒（去掉周围多余的背景行/列）。
- 将裁剪后的图案按其所在分区的列标尺颜色分组：同一列标尺颜色的图案从上到下垂直排列，相邻图案之间间隔一行背景色。
- 各组之间从左到右水平排列，组间间隔一列背景色。列标尺颜色的左右顺序与其在第一行中出现的先后顺序一致。
- 每个裁剪图案保留其原始颜色。

Key insight
标尺行和标尺列联合定义了一个二维索引系统——解题者先要理解标尺如何划分分区（第一层），再发现输出按列标尺颜色分组排列（第二层），最后注意图案被裁剪到最小包围盒而非保留原始分区尺寸（第三层）。
</new_puzzle>

<new_puzzle>
description：根据每个彩色环形边框内部小色块的位置，选择对应方向的外部箭头图案，将其颜色替换为环的颜色后绘制在环的外侧。

Input structure
- 背景为黑色。网格中有若干个由不同颜色绘制的 5×5 空心正方形环（边框宽度为一个像素，内部 3×3 区域为背景色，只有一个像素被一个统一的"指示色"，如红色，填充）。
- 指示色像素位于 3×3 内部区域的上、下、左、右四个边中间位置之一（不会出现在角落）。
- 在网格的某个角落区域，有四个用灰色绘制的小箭头模板（每个为 3×3 大小），分别朝上、下、左、右，排成 2×2 方阵。箭头朝上的模板画法为：第一行中间一个像素，第二行三个像素，第三行中间一个像素；其余方向依此旋转 90/180/270 度。

Rule
- 对每个彩色空心环，检查其内部 3×3 区域中指示色像素的位置：上中 → 方向"上"，下中 → 方向"下"，左中 → 方向"左"，右中 → 方向"右"。
- 从灰色箭头模板方阵中选取对应方向的 3×3 箭头模板。
- 将模板中的灰色像素替换为该环的边框颜色。
- 将替换颜色后的箭头绘制在环的外侧：箭头紧贴环对应方向的外边。例如方向为"上"时，箭头的底边紧贴环顶边的上方。箭头在垂直于方向的轴上与环居中对齐。
- 输出中，原始环保持不变，内部指示色像素被清除为背景色，灰色模板方阵被清除为背景色。

Key insight
解题需要三层推理：第一层是发现内部指示色像素的位置编码了方向，第二层是识别角落的灰色图案是可选的箭头模板库，第三层是理解箭头颜色继承自对应环的边框颜色并绘制在环外侧的正确位置。
</new_puzzle>

<new_puzzle>
description：将网格中分散的同色像素对用直线连接，连线交叉处产生的新颜色由两条交叉线的颜色混合规则决定。

Input structure
- 背景为黑色。网格中有若干种非背景颜色的像素，每种颜色恰好出现两个像素点（即成对出现）。
- 同色像素对要么在同一行（水平对齐），要么在同一列（垂直对齐），不会出现对角线对齐的情况。
- 不同颜色的像素对分别沿水平或垂直方向对齐，使得某些连线之间会产生交叉点。
- 网格边缘有一个"混色图例"：一个小矩形区域，其中若干行各包含两个颜色像素和一个结果色像素，表示"当这两种颜色的线交叉时，交叉点应填充该结果色"。图例格式为每行三个像素：第一个和第三个为两种输入色，中间为结果色。

Rule
- 对每对同色像素，在它们之间画一条与行或列对齐的直线（包含两个端点之间的所有像素），颜色与该对像素相同。
- 当两条不同颜色的直线在某个像素位置交叉时，查找混色图例中包含这两种颜色的那一行，将交叉点像素填充为图例中给出的结果色。
- 如果某个像素只被一条线覆盖，则填充为该线的颜色。
- 混色图例区域在输出中被清除为背景色。

Key insight
解题者首先要发现同色像素对之间需要连线（第一层），然后注意到交叉点的颜色不是简单覆盖而是遵循特定的混合规则（第二层），最后要识别出边缘图例提供了混色查找表（第三层）。三层推理环环相扣。
</new_puzzle>

<new_puzzle>
description：根据网格中"种子"像素在封闭区域内的位置，让种子沿区域边界的内壁生长出与边界等长的彩色描边，生长方向由种子相对于区域中心的方位决定。

Input structure
- 背景为黑色。网格中有若干个用灰色绘制的封闭矩形边框（单像素厚），每个边框的内部区域大部分为背景色。
- 每个灰色矩形内部恰好有一个彩色"种子"像素（颜色各不相同），位于内部区域的某条边的中点附近（紧贴灰色边框内壁的上边、下边、左边或右边的中间位置）。

Rule
- 对每个灰色矩形，找到其内部的种子像素，确定种子紧贴的是哪一条内壁（上/下/左/右）。
- 从种子位置出发，沿该内壁向两侧延伸，用种子的颜色填充整条内壁（即紧贴灰色边框内侧的一整行或一整列像素），直到遇到矩形边框的角落为止。
- 种子像素本身也包含在描边中。灰色边框保持不变，其他区域保持不变。

Key insight
解题者需要先识别种子像素贴靠的是哪条内壁（通过种子与灰色边框的相邻关系判断），再理解生长规则是沿着该内壁填满一整条线——方向判定依赖空间邻接关系而非简单的坐标计算。
</new_puzzle>

<new_puzzle>
description：将多个重叠的透明彩色层按遮挡关系分离，然后将各层按从小到大的面积顺序嵌套为同心框架输出。

Input structure
- 背景为黑色。网格中可见若干种非背景颜色的像素，这些像素实际上来自若干个不同颜色的实心矩形的叠放。
- 这些矩形具有不同的尺寸，中心点大致重合，较小的矩形叠在较大的矩形上方，遮挡了下方矩形的中心部分。
- 因此每个较大矩形只有未被遮挡的边缘"框"部分可见，最小的矩形完全可见。
- 每种颜色只对应一个矩形。

Rule
- 通过可见的边缘区域推断每个矩形的完整尺寸：对每种颜色，其可见像素形成一个框形区域（或对于最顶层，一个完整矩形），该框的外边界即为该矩形的实际边界。
- 确定所有矩形的完整尺寸后，按面积从小到大排序。
- 在输出网格中，将这些矩形重新绘制为同心嵌套结构：最大的矩形在最外层，最小的在最内层，所有矩形共享同一个中心点。相邻层之间间隔一个像素的背景色形成"间隙环"。
- 输出网格的尺寸恰好容纳最外层矩形加上所有间隙。

Key insight
第一层推理是从遮挡碎片还原每个矩形的完整尺寸（逆向遮挡推理），第二层是发现输出将这些矩形重新组织为等间距同心框架——输入编码的是自由叠放，输出编码的是规则嵌套，两者的几何组织原则完全不同。
</new_puzzle>
