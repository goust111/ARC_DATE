- `description`：根据框架内部的彩色种子像素生长出与种子颜色相同的填充图案，生长方向由框架缺口位置决定，最终将所有框架按生长后面积从大到小堆叠到输出画布上。
- `Input structure`：背景为 Black。网格中散布若干由单一颜色绘制的一像素厚矩形框架（如 Red 框、Blue 框等），每个框架的某一条边上恰好有一个单像素缺口。每个框架内部恰好有一个与框架颜色不同的彩色种子像素（如框架为 Red，种子为 Green）。
- `Rule`：
  1. 对每个框架，找到其边上的缺口所在方位（上、下、左、右）。
  2. 从种子像素出发，沿缺口的**反方向**逐行（或逐列）生长：在框架内部，从种子所在行/列开始，向缺口反方向逐步填充整行/整列，直到碰到框架边界为止，填充颜色为种子颜色。
  3. 计算每个框架内被填充的像素总数（即生长后的面积）。
  4. 在与最大框架等大的输出画布上，按面积从小到大的顺序依次放置各框架（含其内部填充），小面积在下、大面积在上，各框架左上角对齐画布左上角。重叠处上层覆盖下层。
- `Key insight`：缺口方位决定生长方向的反转是第一层推理；生长面积决定堆叠顺序是第二层推理——两层规则都需要从样例中独立归纳。

- `description`：网格中每个封闭区域内的小图案是一条"指令"，指令按区域从左到右、从上到下的顺序依次作用于一个初始种子图案，每条指令对种子执行特定的几何变换，最终输出累积变换后的图案。
- `Input structure`：背景为 Black。网格被 Grey 线条分割成若干个大小相等的矩形区域（如 5x5），排列成规则的行列网格。第一个区域（左上角）包含一个由某种颜色（如 Red）绘制的小图案作为"种子"。其余每个区域包含一个由 Azure 像素绘制的小符号，这些符号是几何变换指令：
  - 水平线（3 个水平排列的像素）= 水平翻转
  - 垂直线（3 个垂直排列的像素）= 垂直翻转
  - 右下对角线（从左上到右下的 3 个像素）= 顺时针旋转 90 度
  - 左下对角线（从右上到左下的 3 个像素）= 逆时针旋转 90 度
  网格的最后一个区域（右下角）为空（纯背景色），这是输出区域。
- `Rule`：
  1. 提取左上角区域中的种子图案。
  2. 按从左到右、从上到下的阅读顺序依次读取每个非空、非种子区域中的 Azure 指令符号。
  3. 对当前图案依次执行每条指令对应的几何变换。
  4. 将最终变换结果绘制到右下角的空区域中，颜色保持种子的原始颜色。
  5. 输出网格与输入网格相同，唯一区别是右下角区域被填入了最终图案。
- `Key insight`：Azure 符号的形状编码几何变换类型是第一层推理；变换按区域阅读顺序累积作用是第二层推理——解题者需要先破译每种符号的含义，再按正确顺序串联执行所有变换。
</new_puzzle>

- `description`：将散落的彩色线段按颜色分组后首尾拼接成完整折线，拼接顺序由线段端点处的方向标记决定，最后将每条折线平移至输出画布的指定锚点。
- `Input structure`：背景为 Black。网格中散布着若干条单像素宽的水平或垂直彩色线段，每种颜色有 2-4 条线段。每条线段的一个端点旁（四邻域中某个空位）有一个 Grey 像素作为"出口标记"，标记的位置指示该端点的延伸方向（例如 Grey 在线段右端点的右边，表示该端点向右延伸）。此外，网格的最底行有若干单独的彩色像素作为"锚点"，每种颜色恰好一个锚点。
- `Rule`：
  1. 按颜色将线段分组。
  2. 在每组内，找到只有一个端点带 Grey 出口标记的线段，该端点为折线的起始端。
  3. 从起始线段的无标记端出发，寻找同组中另一条线段，其某个端点的 Grey 标记方向与当前端点的延伸方向匹配（即这条新线段的入口方向恰好接上上一段的出口方向），将其拼接上去。
  4. 重复步骤 3，直到所有同色线段都被拼接完毕，形成一条完整的折线。
  5. 拼接时，每条新线段的入口端与上一段的出口端重合在同一个像素上（共享一个端点像素）。
  6. 将拼接好的折线整体平移，使折线起始端点对齐到底行对应颜色的锚点位置。
  7. 移除所有 Grey 标记和底行锚点，只保留拼接并平移后的折线。
- `Key insight`：Grey 标记编码了方向信息用于确定拼接顺序是第一层推理；端点方向匹配实现首尾衔接是第二层推理——解题者需要先理解 Grey 标记的方向语义，再用它推导出唯一的拼接序列。
</new_puzzle>

- `Rule`：
  1. 通过颜色匹配找到每个窗户对应的外部碎片组。

  4. 将变换后的碎片填入对应空缺区域，颜色保持不变。
  5. 外部碎片从原位置删除（变为背景色），窗户框架和已有图案保持不变。
- `Key insight`：颜色匹配确定碎片归属是第一层推理；碎片需要几何变换后才能与空缺形状吻合是第二层推理——解题者必须同时在心中旋转碎片并匹配空缺形状，这要求空间推理能力。
</new_puzzle>
