<description>
根据框架内部的色块拼接模式，推断缺失象限的内容，并用镜像-旋转复合变换填充，同时对标记像素进行颜色转换。

Input structure:
- 背景色（bg）为网格中最常见的颜色。
- 网格被一条水平分隔线和一条垂直分隔线（均为 grey 色）等分为四个象限。
- 三个象限各包含一个由多种非背景色组成的不规则图案（motif），其中恰好一个象限为空（仅含 bg）。
- 每个非空象限的图案与其水平相邻象限的图案呈左右镜像关系，与其垂直相邻象限的图案呈上下镜像关系。因此对角象限的图案是 180 度旋转关系。
- 在三个非空象限中，恰好有一个象限的图案中存在一个 red 像素（标记像素），其余象限的对应位置为普通颜色。

Rule:
- 第一步：识别空象限的位置（左上、右上、左下、右下之一）。
- 第二步：根据空象限与其相邻两个非空象限的空间关系，确定需要对哪个相邻象限的图案施加哪种镜像操作（水平相邻则左右镜像，垂直相邻则上下镜像）来生成空象限的内容。由于两个相邻象限都能生成该空象限的内容，两者结果一致（它们本身就是对角关系，即 180 度旋转）。
- 第三步：在生成的空象限图案中，找到 red 标记像素经变换后的新位置，将该位置改为 green 色。
- 输出网格与输入尺寸相同，仅空象限被填充，其余部分不变。

Key insight：解题者需要先发现三个已有图案之间的镜像/旋转对称关系，然后利用该对称性重建第四个象限；第二层推理是发现 red 标记在变换后变为 green——这不是简单的颜色复制，而是标记像素在新位置发生了颜色转换。
</description>

将网格中的多个"信号塔"沿各自天线方向广播色带，色带在交叉点处按叠加规则混色。

Input structure:
- 背景色为 black。
- 网格中散布若干个 3x3 的"信号塔"对象。每个信号塔由一个 grey 色的 3x3 实心方块构成，且在其四条边（上、下、左、右）中恰好有一条或两条边的中央像素被替换为某种非 grey、非 black 的颜色（称为"天线"）。天线颜色即为该方向广播的信号颜色。
- 天线所在边的方向即为信号的广播方向（例如上边中央为天线，则信号向上广播）。

Rule:
- 对每个信号塔的每个天线，从天线位置出发，沿天线朝外的方向逐格绘制宽 1 格的色带，颜色与天线颜色相同，一直延伸到网格边界为止。色带不覆盖任何信号塔本身（遇到其他信号塔的 grey 像素时跳过该格，色带继续在信号塔另一侧延伸）。
- 当两条不同颜色的色带交叉于同一像素时，该像素的颜色由以下固定混色规则决定：red + blue = magenta，red + yellow = orange，blue + yellow = green。若交叉的两色不属于上述三对之一（例如同色交叉），则保留先到者的颜色（按从左到右、从上到下的信号塔扫描顺序）。
- 三条及以上色带交叉时，依次按上述两两混色规则叠加（按信号塔扫描顺序）。

Key insight：第一层推理是识别天线方向并理解信号沿该方向无限广播；第二层推理是发现交叉点不是简单覆盖或保留，而是遵循一套特定的"颜色混合"映射规则（red+blue=magenta 等），解题者需要从样例中的交叉点颜色反推这套映射。
</description>

<description>
在网格中识别由边框颜色编码的嵌套层级关系，将最内层图案按边框颜色指定的平铺方式填充各层间隙。

Input structure:
- 背景色为 black。
- 网格中有若干个矩形嵌套结构。每个嵌套结构由 2 到 3 层同心矩形边框组成，每层边框厚度为 1 像素，颜色各不相同。相邻层之间间隔 1 像素的 black 间隙。
- 最内层矩形的内部填充有一个由某种颜色组成的小图案（2x2 到 3x3 大小的非 black 像素组合）。
- 不同嵌套结构的层数可能不同。

Rule:
- 第一步：识别每个嵌套结构的层级数和最内层的填充图案。
- 第二步：从最内层向外逐层处理每个 black 间隙区域。每层间隙的填充方式由该间隙外侧边框的颜色决定：
  - 若外侧边框为 blue：将内层图案在间隙中沿水平方向周期性平铺（仅水平重复，垂直方向不重复，间隙中每行都填入图案对应行的水平平铺结果）。
  - 若外侧边框为 red：将内层图案在间隙中沿垂直方向周期性平铺（仅垂直重复，水平方向不重复）。
  - 若外侧边框为 green：将内层图案在间隙中同时沿水平和垂直方向二维周期性平铺。
  - 若外侧边框为 yellow：将间隙全部填充为内层图案中出现次数最多的颜色（纯色填充）。
- 第三步：每层间隙填充时使用的"内层图案"始终是最原始的内核小图案（2x2 或 3x3），而非逐层累积后的结果。
- 所有边框像素在输出中保持不变。

Key insight：解题者需要发现三层嵌套的推理结构：（1）识别同心矩形的嵌套层级；（2）发现边框颜色与填充方式之间的映射关系（blue=水平平铺、red=垂直平铺等），这需要从多个样例中归纳；（3）理解每层间隙填充的"种子"始终是最内层的原始小图案，而不是逐层累积的结果——这一点必须通过对比不同层数的嵌套结构才能确认。
</description>

在网格中根据"种子"图案的连通形状在底部纹理图例中找到匹配的纹理，并将该纹理绘制到种子所在位置。

Input structure:
- 背景色为 black。
- 网格底部有一排"纹理图例"：若干个矩形色块（高度相同，宽度相同，例如都是 4x3），彼此间隔 1 列 black 分隔。每个矩形色块内部包含由两种非 black 颜色组成的独特纹理图案（如条纹、棋盘格、L 形重复等）。
- 网格上方区域散布若干"种子"对象。每个种子对象是一个由单一非 black 颜色组成的小型连通区域（4-连通），像素数量在 2 到 6 之间。
- 每个种子对象的连通形状（忽略颜色和位置，仅看相对像素排列，不考虑旋转和翻转）与恰好一个纹理图例中某种颜色像素的连通区域形状完全匹配。

Rule:
- 第一步：对每个种子对象，提取其连通形状（相对像素坐标的集合，以左上角为原点归一化）。
- 第二步：在底部纹理图例中逐个搜索，对每个图例提取其内部各颜色像素的所有 4-连通区域，将每个区域的形状同样归一化。找到与种子形状完全匹配的那个连通区域所在的图例。
- 第三步：以种子对象的外接矩形（bounding box）左上角为锚点，将匹配到的纹理图例完整地绘制到网格上方区域，尺寸与图例矩形相同。纹理块覆盖种子的原始像素及其周围的 black 像素。
- 输出时底部图例行保持不变。

Key insight：核心难点在于发现种子形状与纹理图例之间的"形状嵌入"匹配关系——种子的形状是纹理内部某个同色连通区域的精确副本，这是一种隐蔽的索引方式。解题者必须先理解种子的"形状"是一把钥匙，然后在图例的内部结构中找到对应的锁，而不是简单地按颜色或位置对应。
</description>

<description>
根据封闭区域内箭头标记的指向，将区域内散落的色块按距缺口的远近排序后，从缺口推出并在外部排列。

Input structure:
- 背景色为 black。
- 网格中有一个由 grey 像素组成的矩形封闭边框（厚度 1 像素），边框的某一条边上恰好有一个宽度为 1 格的缺口（即该位置的 grey 像素缺失，为 black）。
- 边框内部有若干个 1x1 的彩色像素（各不相同的非 black、非 grey 颜色），散布在不同位置。
- 边框内部还有一个由 maroon 色组成的"箭头"标记。箭头形状为一条 3 像素长的线段加 1 个像素的尖端（总共 4 像素），构成一个指向上、下、左或右的箭头。箭头的尖端指向恰好朝向缺口所在的边。具体绘制方式：若箭头指向右，则由左到右依次为 3 个水平排列的 maroon 像素，加上右侧 1 个 maroon 像素在中间行偏移构成尖端；类似地，指向上的箭头由 3 个垂直排列的 maroon 像素加顶部 1 个居中像素构成。

Rule:
- 第一步：确定箭头的朝向（即缺口所在边的方向）。
- 第二步：将边框内所有彩色像素（不含 maroon 箭头像素）沿箭头方向排序——在箭头指向的坐标轴上，离缺口近的排在前。若两像素在该轴上坐标相同，则按垂直于箭头方向的坐标从小到大排序。
- 第三步：在缺口外侧，沿与箭头方向垂直的方向排成一行（或一列），依次放置排好序的彩色像素，第一个像素紧邻缺口外侧。
- 输出中边框内部全部变为 black（所有彩色像素和箭头都被清除），边框本身保留（含缺口），缺口外侧新增排好序的彩色像素行（或列）。

Key insight：解题者首先要识别出 maroon 像素构成的箭头并判断其朝向，这决定了操作方向；第二层推理是发现色块在输出中的排列顺序并非随意，而是由它们在输入中相对于缺口的"深度"决定——越靠近缺口的像素越先被推出，同深度的按次要坐标排序。箭头同时编码了排序主轴和推出方向。
</description>

<description>
将蛇形路径上的像素按颜色分组，每组独立收缩到各自的质心位置，形成紧凑的色簇。

Input structure:
- 背景色为 black。
- 网格中有一条由非 black 像素组成的 4-连通蛇形路径（无分支，每个像素恰好有 1 或 2 个路径邻居）。路径上的像素使用 2 到 4 种不同颜色，同色像素在路径上形成连续的段（即路径可以看作若干单色段首尾相连）。
- 路径之外可能有若干孤立的 grey 像素作为"锚点"标记，每个锚点与路径不相邻。

Rule:
- 第一步：沿路径从一个端点到另一个端点遍历，将路径分割为若干单色段。记录每段的颜色和包含的像素坐标列表。
- 第二步：对每个单色段，计算其所有像素的行坐标平均值和列坐标平均值，分别取整，作为该段的"质心"。
- 第三步：将每个单色段的所有像素平移，使段的质心移动到距离该段质心最近的 grey 锚点位置。若没有足够的锚点，则保持质心位置不变，仅将段内像素紧凑排列为以质心为中心的最小矩形填充。
- 第四步：输出中原路径位置变为 black，各色段出现在新位置，grey 锚点保留。若多个段移动后有重叠，后出现的段（沿路径遍历顺序靠后的段）覆盖先出现的段。

Key insight：第一层推理是识别蛇形路径并将其分割为单色段——这需要理解路径的连通结构和颜色分界；第二层推理是发现每个色段不是原地保留而是整体迁移到 grey 锚点处——解题者需要理解锚点与色段之间的对应关系（最近距离匹配）；第三层是理解段内像素在目标位置被紧凑重排而非保持原始相对位置。
</description>

<description>
在点阵网格中，用"传播者"像素的颜色和所在区域的形状共同决定填充规则，将每个封闭区域变换为特定的输出图案。

Input structure:
- 背景色为 black。
- 网格中由 azure 色像素绘制的单像素宽直线（水平和垂直）将整个网格划分为若干矩形区域。azure 线构成完整的网格线系统（从边到边贯穿），类似表格。
- 每个矩形区域内部要么全是 black（空区域），要么包含恰好一个非 black、非 azure 的彩色像素（"传播者"）。
- 传播者的位置可能在区域内的任意位置（不一定居中）。

Rule:
- 第一步：识别所有矩形区域及其内部的传播者（如果有的话）。空区域在输出中保持不变。
- 第二步：对每个有传播者的区域，判断区域的形状特征：
  - 若区域的宽度 > 高度（横向矩形）：用传播者的颜色填充该区域内所有像素为水平条纹——从传播者所在行开始，每隔一行填充一行（传播者所在行填充，下一行不填，再下一行填充，依此类推；向上同理）。
  - 若区域的高度 > 宽度（纵向矩形）：用传播者的颜色填充垂直条纹——从传播者所在列开始，每隔一列填充一列。
  - 若区域为正方形：用传播者的颜色填满整个区域（实心填充）。
- 第三步：azure 网格线在输出中保持不变。

Key insight：第一层推理是理解 azure 线划分了独立的区域，每个区域独立处理；第二层推理是发现区域的形状（横向/纵向/正方形）决定了填充样式（水平条纹/垂直条纹/实心），这是一条需要从多个样例中归纳的隐蔽规则；第三层是条纹的相位由传播者的具体位置锚定——条纹从传播者所在的行或列开始，以该位置为基准交替填充。
</description>
