<description>
根据框架缺口方向，将内部图案沿缺口方向"挤出"到框架外部，并用缺口对侧的边框颜色重新着色挤出部分。

Input structure:
- 黑色背景上有若干矩形框架，每个框架由单像素宽的边框构成。框架的四条边各自可能使用不同颜色（从红、蓝、绿、黄中选取），且框架的某一侧边框存在一个连续缺口（宽度为2-4个像素，即该侧边框有2-4个像素缺失为黑色）。
- 每个框架内部包含一个由灰色像素绘制的小型连通图案（如L形、T形、十字形等），图案不接触边框，完全位于框架内部。
- 缺口所在边的颜色与对侧边的颜色不同。

Rule:
- 对每个框架，找到缺口所在的边（上/下/左/右），即边框中存在连续黑色间断的那一侧。
- 将框架内部的灰色图案沿缺口方向平移，平移距离等于图案在该方向上的跨度加上图案到缺口边框的距离，使得图案从缺口处完整穿出框架，图案尾端与缺口所在边框齐平。
- 穿出后位于框架外部的图案像素，重新着色为缺口对侧边框的颜色；仍留在框架内部的图案像素保持灰色。
- 框架本身保持不变（包括缺口处的黑色间断）。

Key insight: 缺口方向决定图案的平移方向，而对侧边框颜色决定挤出部分的重新着色——解题者需要同时识别缺口位置和对侧边颜色这两个独立信息并将它们组合使用。
</description>

<description>
将散落的单色碎片按颜色配对后拼合成完整矩形，再根据拼合矩形的尺寸比例在目标区域中绘制对应大小的色块。

Input structure:
- 黑色背景上散布着若干单色连通碎片，每种非背景颜色（红、蓝、绿、黄等）恰好出现两个碎片。
- 网格底部有一个灰色边框围成的矩形目标区域，目标区域内部被灰色水平线均匀分成若干行格子，格子数量等于颜色种类数。
- 每对同色碎片的形状互补——将两者仅通过平移（不旋转、不翻转）拼合后恰好构成一个无孔洞的实心矩形。

Rule:
- 对每种颜色，找到该颜色的两个碎片，通过平移将它们拼合成一个完整的实心矩形。记录拼合矩形的宽度和高度。
- 按拼合矩形的面积（宽×高）从小到大排序。面积最小的颜色对应目标区域最上方的格子，面积最大的对应最下方的格子。
- 在每个对应格子的左上角，绘制一个与碎片同色的实心矩形，其宽度等于拼合矩形的宽度，高度等于拼合矩形的高度（若格子容纳不下则按比例截取到格子边界）。
- 碎片在原位置保持不变。

Key insight: 解题者首先要发现同色碎片能互补拼合成矩形的规则，然后还需根据拼合结果的面积确定在目标区域中的排列顺序——碎片配对拼合和面积排序是两层独立的非显然推理。
</description>

<description>
沿彩色导轨传播信号，信号在经过交叉点时根据交叉导轨的颜色发生颜色变换，最终在每条导轨末端生成变换后颜色的标记。

Input structure:
- 黑色背景上有若干条单像素宽的水平或垂直彩色直线段（导轨），使用红、蓝、绿、黄等颜色。
- 部分导轨在某些位置相互交叉（交叉点处两条导轨共享同一个像素，该像素显示为洋红色，以区别于任何单条导轨的颜色）。
- 每条导轨的一个端点旁边紧邻一个2x2的同色实心方块作为"信号源"，另一个端点为空（信号终点）。
- 网格左下角有一个颜色映射图例：若干行，每行包含三个相邻的像素 [信号色, 交叉色, 结果色]，例如 [红, 蓝, 绿] 表示红色信号经过蓝色导轨的交叉后变为绿色。

Rule:
- 信号从每条导轨的信号源端（有2x2方块的端点）出发，沿导轨传播到终点（无方块的端点）。
- 信号初始颜色等于导轨自身的颜色。每经过一个交叉点（洋红色像素），需要确定与之交叉的另一条导轨的颜色，然后查找图例中"当前信号色 + 交叉导轨颜色"对应的结果色，将信号颜色更新为该结果色。
- 如果一条导轨经过多个交叉点，信号按照从信号源到终点的顺序依次变换颜色。
- 在每条导轨的终点旁绘制一个2x2的实心方块，颜色为信号最终变换后的颜色。
- 导轨本身、交叉点（洋红色）和信号源方块保持不变。

Key insight: 解题者需要先从图例中归纳出颜色变换规则（三元组映射），然后追踪每条导轨上交叉点的顺序来逐步推导信号颜色的链式演变——图例解读和路径追踪构成两层独立推理。
</description>

<description>
识别围墙中的缺口，根据缺口朝向的外部色块颜色来填充围墙内部区域，同时用特殊颜色标记缺口位置。

Input structure:
- 黑色背景上有若干由灰色像素构成的近似封闭的矩形环形围墙（单像素宽），每个围墙围出一块黑色内部区域。
- 部分围墙是完整封闭的（四条边无断裂），部分围墙恰好有一个单像素宽的缺口（灰色边框中缺失了一个像素）。
- 围墙外部的黑色背景上散布着若干大型单色连通色块（使用红、蓝、绿、黄等颜色），每个色块面积远大于围墙。
- 有缺口的围墙，其缺口外侧（从围墙内部穿过缺口向外看）方向上能直线到达某个外部色块。

Rule:
- 对完整封闭的围墙：其内部区域保持黑色不变，不做任何处理。
- 对有缺口的围墙：
  1. 找到缺口位置（灰色围墙中唯一缺失像素的位置）。
  2. 从缺口位置向围墙外侧方向做射线扫描，找到该射线首先命中的外部色块，记录其颜色。
  3. 将该围墙包围的整个内部黑色区域填充为该外部色块的颜色。
  4. 将缺口位置本身填充为橙色，作为缺口标记。
- 围墙灰色像素、外部色块本身均保持不变。

Key insight: 解题者首先要仔细观察区分完整围墙和有缺口围墙（缺口仅一个像素，容易忽略），然后对有缺口的围墙，需要判断缺口朝向哪个外部色块来决定填充颜色——缺口检测和方向关联构成两层推理。
</description>

<description>
根据种子像素的颜色匹配生长模板，根据种子旁的方向标记确定模板旋转角度，然后以种子为锚点放置旋转后的模板。

Input structure:
- 黑色背景网格，左侧为模板区，右侧为画布区，以一条垂直的灰色单像素宽分隔线隔开。
- 模板区包含若干小型图案模板（3x3至5x5大小），每个模板由一种独特非背景颜色绘制（如红、蓝、绿等），模板形状各异且不对称（如阶梯形、钩形等），使得旋转后能产生可区分的不同朝向。每个模板中恰好有一个像素被标记为洋红色，表示该模板的"锚点"。不同模板之间至少间隔2个黑色像素。
- 画布区散布着若干单个彩色像素（种子），每个种子的颜色与模板区中某个模板的颜色相同。每个种子的4-邻域中恰好有一个相邻位置放置了一个由黄色像素组成的方向标记：单个黄色像素在种子的上方表示"向上"，在下方表示"向下"，在左方表示"向左"，在右方表示"向右"。

Rule:
- 对每个种子像素，根据其颜色找到模板区中对应颜色的模板。
- 确定种子旁黄色方向标记的位置（上/下/左/右），即为生长方向。
- 模板的默认朝向为"向上"（即锚点在模板底部区域，模板主体向上展开）。根据方向标记将模板旋转：向上不旋转，向右顺时针旋转90度，向下旋转180度，向左逆时针旋转90度（即顺时针270度）。
- 将旋转后的模板放置在画布上，使模板中锚点（原洋红色像素）的位置与种子像素位置重合。放置时所有像素（包括锚点位置）都使用模板的颜色绘制。
- 黄色方向标记在输出中被移除（变为黑色背景）。模板区保持不变。
- 若多个模板实例有重叠，按种子从上到下、从左到右的顺序依次绘制，后绘制的覆盖先绘制的。

Key insight: 解题者需要三层推理——首先通过颜色匹配将种子关联到对应模板，然后解读方向标记以确定旋转角度，最后通过洋红色锚点的对齐来精确定位模板的放置位置。三个步骤各自需要独立的模式识别与归纳。
</description>

<description>
在网格中找到彩色边框围成的矩形空腔，将边框外侧紧邻的图案向内镜像投影，并根据颜色链表逐层变换投影颜色。

Input structure:
- 黑色背景上有若干不同颜色的矩形环形边框（单像素宽，如红色边框、蓝色边框等），每个边框围出的内部为黑色空腔，空腔尺寸至少5x5。
- 每个边框的外部紧邻位置（距边框外侧1像素处）散布着一些绿色像素，这些像素形成不规则的图案，分布在边框外围的各个方向。
- 网格右下角有一条颜色链：一行相邻像素依次排列，例如 [绿, 黄, 橙, 红]，表示第一层投影用绿色，第二层用黄色，第三层用橙色，第四层用红色。

Rule:
- 对每个矩形边框，收集其外侧紧邻（距边框1像素）的所有绿色像素，记录每个绿色像素相对于边框对应边的位置（即它在哪条边外侧，距该边的哪个端点多远）。
- 将这些外部像素"镜像投影"到边框内部：每个外部像素关于其最近的边框边做镜像反射，映射到边框内部对应的对称位置。投影的像素颜色使用颜色链的第一个颜色。
- 第一层投影完成后，将第一层的所有像素再向空腔中心方向各收缩1像素（行坐标和列坐标各向中心移动1），颜色变为颜色链的第二个颜色，形成第二层。
- 继续逐层收缩和变色，直到颜色链用完或收缩后的像素位置重叠到空腔中心。
- 边框本身和外部绿色像素保持不变。

Key insight: 解题者需要先理解"外部图案关于边框镜像投影到内部"的空间映射关系，然后发现每层收缩时颜色按照颜色链依次变换——空间镜像规则和颜色链式变换构成两层独立推理。
</description>

<description>
根据重叠区域边缘的截断模式推断多个单色层的前后遮挡关系，然后将各层的完整形状还原并按深度顺序分离排列。

Input structure:
- 黑色背景上有一个大型复合区域，由3-4种不同颜色（如红、蓝、绿、黄）的像素混合构成。这些颜色实际上是若干独立的单色形状层层叠放的结果——上层遮挡下层，重叠处只显示最上层的颜色。
- 每种颜色的可见部分自身连通。在两种颜色相邻的边界处，被遮挡颜色的轮廓呈现非自然的平直截断（轮廓突然以直线终止于遮挡色的边界），而遮挡色的轮廓是平滑连续的弧形或自然转角。
- 每个独立形状层的完整形状（包括被遮挡部分）都是简单的凸形或近凸形（如矩形、圆角矩形、椭圆形区域），使得被遮挡部分可以通过轮廓延伸自然推断。

Rule:
- 分析每种颜色可见区域的轮廓特征：如果颜色A的轮廓在与颜色B的交界处出现平直截断（边缘突然变成直线并终止），而颜色B的轮廓在该交界处保持自然弧度，则A被B遮挡，即B在A的上方。
- 根据所有成对的遮挡关系，确定从底层到顶层的完整深度排序。
- 对每种颜色，还原其完整形状：在截断边缘处，沿截断前的轮廓弧度方向自然延伸，直到形成封闭轮廓后填充，恢复被上层遮挡的隐藏部分。
- 输出网格将各层完整形状按深度顺序从左到右水平排列，层间留1列黑色间隔。最底层在最左边，最顶层在最右边。每层形状用其原本的颜色绘制。

Key insight: 解题者需要先从轮廓截断模式推断层间遮挡关系（观察哪种颜色的边缘被截断、哪种保持自然），然后利用遮挡关系恢复被遮挡部分的完整形状——遮挡推理和形状补全是两层非显然的视觉推理，且深度排序本身需要综合多对遮挡关系来确定。
</description>
</new_puzzle>
