- `description`：根据每个封闭矩形框边缘缺口的方向，查找网格边缘的方向-颜色图例，用图例中的配对颜色替换框内的填充色。
- `Input structure`：
  - 背景为 black。
  - 网格中有若干由同一种前景色（如 blue）绘制的一像素厚封闭矩形框，每个框的某一侧边上恰好有一个单像素宽的缺口。
  - 每个框内部填充着某种非背景、非框色的纯色（如 red、green 等）。
  - 网格的一条边缘（如最底行）排列着一个颜色图例：图例由四组 1x2 竖直色块对组成，每对的上格为某种填充色，下格为另一种颜色。四组从左到右分别对应缺口朝上、朝右、朝下、朝左四个方向。
- `Rule`：
  - 识别每个封闭矩形框及其缺口所在的边（上、下、左、右）。
  - 缺口方向决定查询图例中的哪一组（第1组=上，第2组=右，第3组=下，第4组=左）。
  - 在该组中找到与框内当前填充色匹配的上格条目，读取其下格颜色。
  - 将该框内部所有填充色像素替换为读取到的新颜色。
  - 框本身、背景及图例保持不变。
- `Key insight`：缺口方向不是直接指示空间操作，而是作为查表索引——它选择图例中的哪一列映射表，再由框内的原始颜色在该映射表中查找替换色。解题者需先发现"方向→图例列"的对应关系，再发现"原色→新色"的查表机制，构成两层独立的归纳推理。
</new_puzzle>

<new_puzzle>
- `description`：将散落的彩色碎片按颜色配对，在每对碎片之间绘制连线，连线颜色由碎片所在的背景条纹色决定。
- `Input structure`：
  - 网格被若干条全宽水平条纹分为交替的两种背景色带（如 grey 和 azure 交替），每条色带高度相同（如 3 行）。
  - 在这些色带上散布着若干小型彩色像素块（1-2 像素），每种非背景、非条纹颜色恰好出现两次，形成配对。
  - 同一颜色的两个碎片总是位于不同的色带中，且二者在同一列或呈水平/竖直直线关系。
- `Rule`：
  - 找到每种颜色的两个碎片，二者之间用竖直直线段相连（因为它们在同一列）。
  - 连线上每个像素的颜色不是碎片本身的颜色，而是该像素所在色带的背景条纹色（grey 或 azure）。
  - 碎片本身的像素保持原色不变。
  - 连线只绘制在两碎片之间的区域，不延伸到碎片之外。
- `Key insight`：连线的路径由同色碎片对的空间关系决定，但连线的颜色由其经过的背景区域动态决定——穿过 grey 条纹的部分画 grey，穿过 azure 条纹的部分画 azure。解题者需要先发现"同色配对→连线"的结构规则，再发现"连线颜色来自所在条纹而非碎片颜色"的着色规则，两层推理缺一不可。
</new_puzzle>

<new_puzzle>
- `description`：识别网格中的"印章"模板和"画布"区域，根据画布边缘的方向标记将印章旋转后盖印到画布内的对应位置。
- `Input structure`：
  - 背景为 black。
  - 网格中有一个由非背景色（如 red）绘制的小型非对称图案（约 3x3 到 5x5），作为"印章模板"。印章的某一个角落像素颜色与其余像素不同（如 green），作为"方向锚点"。
  - 网格中另有一个较大的矩形区域，内部全部为某种纯色填充（如 grey），作为"画布"。
  - 画布的四条外边各有零个或多个单像素标记点（颜色为 yellow），紧贴画布边缘外侧一格。每个标记点表示一个盖印位置。
- `Rule`：
  - 印章模板在默认状态下，方向锚点位于左上角。
  - 对于画布上边的标记：印章不旋转（锚点朝上），以标记点列坐标为水平对齐中心、从画布顶行开始向下盖印。
  - 对于画布右边的标记：印章顺时针旋转 90 度（锚点朝右），以标记点行坐标为垂直对齐中心、从画布最右列开始向左盖印。
  - 对于画布下边的标记：印章旋转 180 度（锚点朝下），以标记点列坐标为水平对齐中心、从画布底行开始向上盖印。
  - 对于画布左边的标记：印章逆时针旋转 90 度（锚点朝左），以标记点行坐标为垂直对齐中心、从画布最左列开始向右盖印。
  - 盖印时，印章的非背景像素覆写画布上的对应像素，但不覆写画布外部的像素。后盖的印章可以覆盖先盖的。
  - 印章模板、标记点在输出中保持不变。
- `Key insight`：方向锚点（特殊颜色角）是推断旋转规则的关键——解题者必须先发现锚点的位置含义，再发现标记所在边与旋转角度的对应关系，最后理解盖印的对齐方式。三层推理环环相扣。
</new_puzzle>

<new_puzzle>
- `description`：在网格中找到若干带有不同颜色边框的矩形"容器"，将面积最小容器中的图案复制到所有空容器内部，复制品的颜色替换为目标容器的边框色。
- `Input structure`：
  - 背景为 black。
  - 网格中有 3-5 个由不同单色绘制的一像素厚矩形边框（"容器"），互不重叠，大小两两不同。
  - 恰好一个容器（面积最小的那个）内部包含由某种非背景、非边框颜色绘制的图案（"内容物"），其余容器内部为 black。
- `Rule`：
  - 计算每个容器的内部面积（不含边框），面积最小且有内容物的容器为源容器。
  - 将源容器中的内容物图案复制到每个空容器的内部，放置于目标容器内部的左上角（紧贴边框内侧）。
  - 复制时，内容物的颜色替换为目标容器的边框颜色。
  - 源容器本身的内容物保持原色不变。
  - 如果目标容器内部空间不足以放下完整图案，则裁剪超出部分。
- `Key insight`：解题者需要先识别哪个容器是"源"（面积最小且有内容物），再理解图案被复制到其他容器时颜色会变为目标容器的边框色。"最小容器是源"是第一层推理，"边框色决定复制品颜色"是第二层推理，两者需独立归纳。
</new_puzzle>

<new_puzzle>
- `description`：根据每个彩色对象中嵌入的单像素"种子"的行列位置，从种子出发向外生长十字线，十字线的水平臂长等于种子同行内的宿主对象像素数，垂直臂长等于种子同列内的宿主对象像素数。
- `Input structure`：
  - 背景为 black。
  - 网格中有若干个由同一种前景色（如 blue）绘制的不规则 4-连通对象。
  - 每个对象内部恰好嵌入了一个不同颜色的单像素点（"种子"），种子颜色各不相同（如 red、green、yellow 等），且种子的 4 个邻居中至少 3 个是前景色像素。
- `Rule`：
  - 对于每个对象中的种子，数出该对象中与种子在同一行的前景色像素数量，记为 H；数出该对象中与种子在同一列的前景色像素数量，记为 V。
  - 从种子位置出发，向左和向右各延伸 H 个像素，向上和向下各延伸 V 个像素，绘制十字线。
  - 十字线的颜色为种子的颜色。
  - 十字线延伸到对象外部的背景上，但遇到其他前景色对象的像素时停止（不覆写其他对象）。
  - 种子本身保留原色，原有的前景色对象像素保持不变。
- `Key insight`：种子颜色决定十字线的颜色，但十字线的长度并非由种子本身决定，而是由种子在宿主对象中的行列切片上"看到"的对象宽度和高度编码。解题者必须先发现种子与宿主对象的嵌入关系，再发现长度编码规则（同行/同列像素计数），两层推理相互独立。
</new_puzzle>

- `description`：网格中的箭头形状指示投射方向，将箭头尾部相邻的彩色方块沿箭头方向滑动，方块每穿过一条"棱镜条"颜色就循环移位一次。
- `Input structure`：
  - 背景为 black。
  - 网格中有若干个由 grey 像素绘制的箭头形状。每个箭头由一条 3 像素长的直线段（箭杆）和箭杆末端像素的两个对角邻居像素（箭头尖端）组成，共 5 个像素，指向上、下、左或右之一。
  - 每个箭头的尾部（箭杆远离尖端的一端）紧邻一个 2x2 的纯色方块，方块颜色为 red、blue、green 或 yellow 之一。
  - 网格中有一条或多条横跨整个网格宽度或高度的单像素宽直线，颜色为 maroon，称为"棱镜条"。
- `Rule`：
  - 每个 2x2 方块沿其对应箭头的指向方向滑动，直到碰到网格边缘或另一个非背景像素为止（方块停在障碍物前一格）。
  - 滑动过程中，方块每穿过一条棱镜条，其颜色按固定循环移位一次：red → green → blue → yellow → red。
  - 方块移动后，原位置变为 black；箭头从输出中移除（变为 black）；棱镜条保留。
- `Key insight`：箭头的朝向解读是第一层推理（需从箭杆加 V 形尖端归纳出方向）；方块穿越棱镜条后颜色循环变换是第二层推理（需从多个样例归纳颜色循环顺序）；方块滑动到障碍物停止是第三层空间推理。三层机制叠加使单个样例难以确定完整规则。
</new_puzzle>

<new_puzzle>
- `description`：将铺满网格的同色区域视为"国家"，每个国家内部唯一的异色像素（"首都"）的颜色决定该国家边境像素的重绘颜色。
- `Input structure`：
  - 网格由若干大块纯色区域铺满，区域间直接相邻无间隔，类似政治地图。
  - 每种颜色构成一个 4-连通的连通块，称为"国家"。
  - 每个国家内部恰好有一个像素的颜色与该国家主色不同，称为"首都"；各国首都颜色互不相同且不与任何国家的主色重复。
- `Rule`：
  - 找出每个国家内部的首都像素及其颜色。
  - 对于每个国家，找到所有边界像素——即该国家中至少有一个 4-邻居属于不同国家（不同主色区域）的像素。
  - 将这些边界像素的颜色替换为该国家首都的颜色。
  - 首都像素本身保持不变。
  - 国家内部的非边界、非首都像素保持原来的主色不变。
- `Key insight`：解题者首先需要发现每个同色区域内唯一的异色像素是特殊标记（"首都"），然后需要理解边界像素的定义（与异色区域相邻），最后发现边界像素被重绘为首都颜色而非邻国颜色。"首都→边境色"的间接映射是核心隐蔽机制。
</new_puzzle>

<new_puzzle>
- `description`：网格中有若干"窗户"（带有彩色窗框的矩形空洞），窗外是黑色背景上的彩色"风景"对象；通过每扇窗户只能看到与窗框颜色相同的风景对象，将这些可见对象裁剪到窗户视口范围内绘制在窗户内部。
- `Input structure`：
  - 背景为 black。
  - 网格中有若干个由不同颜色绘制的一像素厚矩形框（"窗框"），窗框内部为 black（"窗户"）。
  - 网格背景上还散布着若干由各种颜色绘制的小型 4-连通对象（"风景"），这些对象不与任何窗框重叠。
  - 每种风景对象的颜色恰好与某个窗框的颜色相同。
- `Rule`：
  - 对于每个窗框，找到所有与该窗框颜色相同的风景对象。
  - 将这些风景对象的像素"投影"到窗户内部：保持风景对象的绝对行列坐标不变，只有落入窗框内部区域（不含窗框本身）的风景像素被绘制，其余被裁剪掉。
  - 投影到窗户内的像素保持原色。
  - 窗框本身保持不变，窗户内没有被投影覆盖的像素保持 black。
  - 风景对象在窗户外的原始位置变为 black（被移除）。
- `Key insight`：解题者需先发现窗框颜色与风景颜色的匹配关系（颜色相同的属于同一扇窗），再发现投影规则是基于绝对坐标的裁剪而非平移——风景对象不移动，只是只有落在窗口范围内的部分才显示。"颜色匹配→归属"是第一层推理，"绝对坐标裁剪→视口"是第二层推理。
</new_puzzle>
