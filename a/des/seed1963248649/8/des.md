# 第一步：分析与思考

## 参考题中的基础操作提炼

参考题覆盖了以下核心操作类型：
- **空间移动与对齐**：对象向边界/锚点滑动（#6, #17）、对象平移对接（#18）、容器按步数移动（#5）
- **形状识别与分类**：完整正方形检测（#12）、十字形识别（#20）、箭头方向解读（#14）
- **图案转移与填充**：边缘相对图案的移植（#7）、嵌套矩形层叠（#19, #16）
- **连接与路径**：对角线连接（#2）、路径绕障（#8）、线段修复（#13）
- **信息编码与解码**：颜色编码方向（#17）、蓝色像素编码距离（#8）、灰色计数编码步数（#5）、标记物编码方向（#3）
- **汇总与压缩**：表格槽位汇总（#9）
- **对称与镜像**：沿轴线镜像（#15）
- **序列外推**：帧动画预测下一帧（#11）
- **反转与互补**：行颜色反转（#4）

## 非显而易见的串联可能性

1. **形状属性作为编码信号**：一个对象的几何属性（周长、凹凸性、孔洞数）可以不是变换的对象本身，而是编码了另一个对象应如何被操作的指令。例如，一个对象的凸出数量编码另一个对象的旋转次数。

2. **拓扑关系作为操作选择器**：两个对象之间的空间关系（包含、相邻、对齐）不是直接产生输出的线索，而是决定"对它们施加哪种操作"的选择器。

3. **颜色频率动态分配角色**：颜色出现的频率不仅能区分前景/背景，还可以动态分配角色——最少出现的颜色是"种子"，中频的是"模板"，最多的是"填充"。

4. **负空间携带信息**：关键信息不在前景对象中，而在对象之间留出的背景空隙的形状或尺寸里。

5. **对象间的"对话"**：两个对象各自提供变换的不同维度——一个提供"做什么"，另一个提供"怎么做"。需要同时解读两者才能确定输出。

6. **拓扑属性的对偶反转**：有洞/无洞、连通/断开等拓扑属性可以触发互逆的变换——存在某种属性的对象执行操作 A，不存在的执行操作 B，而 A 和 B 恰好互为逆操作。

7. **视觉符号需要"语义解码"**：网格上的图案可以编码抽象概念（如数字、方向、优先级），解题者必须先将视觉信号"翻译"为语义，然后再在语义层面执行运算，最后重新编码回视觉图案。

## 寻找全新的因果与编码机制

- 一个对象的轮廓可以作为另一个区域的裁剪蒙版或生长模板
- 对象内部的像素分布对称性类型（点对称 vs 线对称 vs 无对称）可以编码不同的变换类别
- 网格中看似装饰性的重复图案实际上是变换指令的编码载体
- 对象间的相对距离差异可以构成排序键，驱动重排或分层操作
- 同一种颜色在不同上下文中扮演不同角色（边框处是"容器"，内部是"填充"，孤立时是"标记"），角色由连通性决定

- `description`：根据每个封闭围栏上唯一缺口的方向，将围栏内部的彩色种子像素从缺口射出，在围栏外画一条射线直到碰壁。
- `Input structure`：背景为 black。网格中有若干个由 grey 像素构成的近闭合矩形框（每个框恰好有一条边存在一个单像素宽的缺口，缺口位于该边的中央位置）。每个框的内部恰好有一个彩色前景像素（颜色各不相同，可以是 red、blue、green、yellow 等），位置在框内任意处。框的大小为 4×4 到 7×7 不等（外部尺寸），壁厚为 1 像素。不同框之间至少间隔 2 个像素。
- `Rule`：
  1. 对每个 grey 矩形框，定位其唯一缺口，确定缺口所在的方向（上、下、左、右）。
  2. 将框内的彩色像素移除原位，沿缺口方向平移至缺口位置。
  3. 从缺口处继续沿同方向，用该颜色逐像素绘制一条直线，直到碰到网格边缘或另一个 grey 框的外壁像素为止（不含碰到的壁像素本身）。

- `Key insight`：框的缺口不是残缺而是"出口方向指示器"——种子像素像弹丸一样从缺口射出，在外面拉出一条彩色轨迹。解题者需要意识到：（a）缺口位置决定运动方向，（b）种子原位被清除，（c）射线从缺口外侧开始绘制、遇障碍停止。难点在于将"结构缺陷"重新解读为"方向编码"。

- `Key insight`：变换规则是"拓扑反转"——有洞变无洞，无洞变有洞。难点在于解题者需要同时观察两类对象的变化，发现它们执行的是互逆操作，并且操作选择的判据是洞的有无这一拓扑属性——而非颜色、大小、位置等更直觉的属性。

- `description`：网格中有若干对"信号塔"和"接收器"，信号塔发出的彩色信号沿直线传播并在遇到 grey 镜面时反射 90 度，最终到达接收器后将其着色。
- `Input structure`：背景为 black。网格中有以下元素：
  - **信号塔**：若干个 2×2 的彩色正方形（颜色各不相同，如 red、blue、green 等），每个信号塔有且仅有一侧的中心位置（紧邻 2×2 方块外侧）有一个同色的单像素突出作为"发射口"，发射口的方向即为信号初始传播方向。
  - **镜面**：若干个由 grey 像素构成的单像素宽斜线段（45 度，即沿主对角线方向或反对角线方向），长度为 2-4 像素。每条镜面只有两种朝向之一：左上-右下（"\" 方向）或左下-右上（"/" 方向）。
  - **接收器**：若干个 maroon 色的 1×1 单像素，分布在网格各处。
- `Rule`：
  1. 对每个信号塔，从其发射口沿发射方向逐像素绘制该信号塔颜色的直线。
  2. 当信号线碰到一个 grey 镜面像素时，信号改变方向：碰到 "\" 镜面时水平运动变垂直、垂直运动变水平（具体地：向右碰"\"转向下，向下碰"\"转向右，向左碰"\"转向上，向上碰"\"转向左）；碰到 "/" 镜面时类似反射（向右碰"/"转向上，向上碰"/"转向右，向下碰"/"转向左，向左碰"/"转向下）。
  3. 信号线继续沿新方向传播，可以多次反射。
  4. 当信号线到达一个 maroon 接收器像素时，将该接收器重新着色为信号的颜色，信号停止传播。
  5. 当信号线到达网格边缘而未碰到接收器时，信号消失（线条仍保留在输出中）。
  6. 信号线经过的所有背景像素都被着色为信号颜色。镜面本身保持 grey 不变。信号塔保持不变。
- `Key insight`：这道题结合了方向编码（发射口位置）和路径追踪（沿直线反射），但核心难点在于理解 grey 斜线段的"镜面"语义——它们看上去只是倾斜的线段，但功能是 90 度反射器。解题者需要先从样例中观察信号线的折弯规律，归纳出反射规则，然后追踪路径确定哪个接收器被哪个信号塔点亮。

<new_puzzle>
- `description`：将网格中重叠的半透明彩色矩形区域拆解为独立图层，根据重叠处的"混合色"反推每层的原始颜色和覆盖范围，输出各图层按大小排列的分离视图。
- `Input structure`：背景为 black。网格中可见若干个轴对齐的矩形区域。部分区域颜色纯净（如纯 red、纯 blue），部分区域显示"混合色"——当两个矩形重叠时，重叠区域显示第三种颜色，该颜色由特定映射规则定义：red+blue → magenta，red+green → yellow，blue+green → azure，任意颜色+grey → orange。每个矩形只有一种原始颜色（red、blue、green 或 grey 之一）。矩形总数为 2-4 个，任意两个矩形最多有一个重叠区域。
- `Rule`：
  1. 识别所有纯色区域和混合色区域。
  2. 由混合色反推参与重叠的两个原始颜色（magenta → red 和 blue，yellow → red 和 green，azure → blue 和 green，orange → 含 grey 的组合）。
  3. 重建每个矩形的完整范围：纯色区域加上与之颜色匹配的混合色区域合并得到完整矩形。
  4. 输出网格宽度 = 各矩形宽度之和 + 矩形间一列 black 间隔，高度 = 最大矩形高度。将所有矩形按面积从小到大从左到右排列，每个矩形用其原始纯色绘制完整形状，矩形间用一列 black 分隔。
- `Key insight`：网格呈现的是多个矩形"叠印"后的合成结果，混合色是两个图层的"视觉加法"。解题者需要逆向思维——从合成后的画面中识别出混合色，利用颜色映射关系还原出原始图层，再将它们分离展示。核心认知挑战是把"看到的颜色"拆解为"两个隐藏颜色的叠加"。
</new_puzzle>
