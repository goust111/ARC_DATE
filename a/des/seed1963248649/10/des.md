# 第一步：分析与思考

## 参考题中的基础操作归纳

纵观 20 道参考题，可以提炼出以下基础操作族：

1. **空间映射与投影**：将外部线索投射到内部区域（如 #4 外部轨迹映射到框架内部，#15 小精灵拉伸填入框架）。
2. **基于冗余的恢复**：多个副本之间互相校验，找出损坏位置（#1 瓦片冗余恢复）。
3. **颜色/属性的循环置换**：对象保持空间位置不动，颜色标签按某种序做轮换（#3 颜色绕分隔器旋转）。
4. **度量驱动位移**：对象自身属性（面积、像素数）决定自身运动量（#13 面积决定下移距离）。
5. **基于图例/调色板的查找替换**：网格中嵌入一个小图例来定义颜色映射关系（#10 调色板填充空心精灵）。
6. **结构标记的裁剪/提取**：用"缺失"或"异常"位置来界定裁剪区域（#14 缺失交叉点标记裁剪角）。
7. **局部对称恢复**：利用网格的对称性来推断被遮挡区域（#7 反射对称恢复隐藏区域）。
8. **多面板选择合并**：从并列面板中各取一部分合成输出（#16 三面板各取一个对象）。
9. **方向/朝向编码的信息传递**：物理朝向（如杯的尾刺方向）编码动作方向（#5 杯形容器弹射内容物）。
10. **分类后差异化着色**：按几何属性将像素分类，再按类别分配新颜色（#8 对角线方向分类着色）。

## 非显而易见的串联方式与信息编码思考

- **拓扑特征作为隐含参数**：对象的"孔洞数"、"端点数"、"分叉数"等拓扑特征，可以作为排序键、索引、或运算参数，而人类需要"数"这些特征才能发现规则。
- **相邻关系图作为隐含结构**：多个对象之间的邻接关系构成一个抽象图，图的性质（如连通分量、度数）可以决定变换行为。
- **"影子"与"光源"隐喻**：一个标记点充当"光源"，对象像"遮光体"一样投下阴影——阴影的形状取决于光源位置和物体轮廓的几何关系。
- **路径折叠/展开**：一条在网格中蜿蜒的路径可以被"展开"成直线，或反过来，一条直线按某种模式被"折入"网格。
- **对象间的"对话"**：一个对象的某个属性（颜色、形状、朝向）回答另一个对象提出的"问题"（缺失部分、空洞形状），两者之间的匹配关系不是基于位置接近，而是基于形状互补或属性对应。
- **时间轴编码在空间中**：网格的行或列代表一个过程的不同时间步，输出是执行完所有时间步后的最终状态。
- **负空间携带信息**：背景色区域的形状本身编码了关键信息，而不仅仅是前景对象。

<new_puzzle>
- `description`：根据每个封闭区域被几种不同颜色的边界线段包围的情况，用出现次数最多的那种边界颜色来填充该封闭区域。

- `Input structure`：
  - 背景色为 black。
  - 网格中有多条由不同颜色（如 red、blue、green、yellow 等）绘制的一像素宽直线段（水平或垂直），这些线段互相交叉，将网格分割成若干封闭的矩形区域。
  - 所有线段在交叉点处互相穿过（交叉点处是两条线段颜色的叠加，取先绘制的颜色）。
  - 每个封闭矩形区域的四条边可能来自不同颜色的线段。

- `Rule`：
  - 找出网格中由线段围成的所有矩形封闭区域（不含线段本身的像素）。
  - 对每个封闭区域，统计其四条边界上所涉及的线段颜色，选出出现次数最多的颜色（即覆盖该区域边界像素最多的颜色）。
  - 用该颜色填充这个封闭区域的内部。
  - 所有线段像素本身保持不变。
  - 若边界上出现颜色数量并列最多的情况，选择在这些颜色中色号字典序较小的那个（如 blue < green < red）。

- `Key insight`：
  - 解题者需要意识到每个封闭区域的填充颜色并非由区域内部的任何标记决定，而是由围成它的边界线段的颜色"投票"决定——需要沿着每个矩形区域的四条边分别统计各种颜色覆盖的长度，取最长者。
</new_puzzle>

<new_puzzle>
- `description`：将网格中散落的单色碎片按形状互补配对，每对碎片合并后恰好填满一个固定大小的矩形模板，用配对双方的两种颜色分别标记合并后矩形中各自贡献的区域。

- `Input structure`：
  - 背景色为 black。
  - 网格中散布若干个由不同颜色构成的 4-连通单色碎片（每个碎片只有一种颜色）。
  - 碎片的总数为偶数。
  - 所有碎片的面积相同（均为 N 个像素）。
  - 存在一个固定的矩形尺寸 R×C（其中 R×C = 2N），使得每两个碎片恰好可以在平移（不旋转、不翻转）下拼合成一个完整的 R×C 实心矩形。
  - 每个碎片在该矩形模板内的摆放位置是唯一确定的：碎片的 bounding box 不超过 R×C，碎片的像素在 R×C 内占据某些位置，其互补碎片的像素恰好占据 R×C 内剩余的所有位置。

- `Rule`：
  - 推断出矩形模板大小 R×C（通过观察碎片的 bounding box 和面积来确定）。
  - 将每个碎片的形状视为 R×C 矩形中的一组坐标，计算其互补形状（即 R×C 矩形中该碎片未覆盖的坐标集合）。
  - 找到另一个碎片，其形状（在 R×C 中的坐标集合）恰好等于这个互补形状——这两个碎片形成一对。
  - 在输出中，对于每一对碎片，在从左到右、从上到下的顺序排列的若干并排矩形区域中（矩形之间间隔一列 black），绘制 R×C 矩形，其中一个碎片贡献的像素保持该碎片的颜色，另一个碎片贡献的像素保持该碎片的颜色。

- `Key insight`：
  - 核心难点在于发现碎片的配对不是基于颜色相似或空间邻近，而是基于形状互补——两个碎片像拼图一样恰好填满同一个矩形。解题者需要先从样例中推断出隐含的矩形模板尺寸，再通过形状匹配找到配对关系。
</new_puzzle>

<new_puzzle>
- `description`：网格中每个有色区域像液体一样受重力影响"流淌"到最低处，但不同颜色的液体互不混合、互不穿越，最终按密度（由颜色的像素总量决定）从下到上分层沉积。

- `Input structure`：
  - 背景色为 black。
  - 网格底部有一条水平的 grey 线段作为"地面"。
  - grey 地面上方有若干个由 grey 像素构成的垂直"挡板"，将地面上方的空间分割成若干个竖直的"容器槽"（每个槽是一个矩形区域，底部是 grey 地面，两侧是 grey 挡板或网格边缘，顶部敞开）。
  - 在这些容器槽的上方（可能远高于挡板顶部），散布着若干种不同颜色的 4-连通色块，每种颜色可能出现多个独立的色块。

- `Rule`：
  - 统计每种非背景、非 grey 颜色在全网格中的总像素数量，作为该颜色的"密度"。像素总量越大，密度越大。
  - 确定每个色块所在的水平位置区间，判断它位于哪个容器槽的正上方（一个色块完全位于某个槽的水平范围内）。
  - 将同一个容器槽上方的所有色块按密度从大到小排列：密度最大的颜色沉到最底部，密度最小的在最上方。
  - 在输出中，grey 结构保持不变。每个容器槽内部，从底部地面开始，按密度从大到小依次向上堆叠水平实心矩形色带。每个色带的宽度等于容器槽的内宽，高度等于该颜色在该容器槽中的总像素数除以容器槽内宽（向上取整）。
  - 清除原来散落在上方的色块。

- `Key insight`：
  - 解题者需要发现"重力沉降"的隐喻：颜色不是按空间位置高低排列，而是按全局像素总量（密度）排列——全网格中某颜色的总面积越大，沉降后该颜色越靠下。同时需要注意每个色块归属于其正下方的容器槽，而非随意流动。
</new_puzzle>

<new_puzzle>
- `description`：每个前景对象是一个"印章"，它在自身所在行方向上反复盖印自身的形状，盖印的次数等于该对象内部包含的不同颜色数量。

- `Input structure`：
  - 背景色为 black。
  - 网格中有若干个互不相邻的小型多色对象（每个对象是一个 4-连通区域，占据少量像素，bounding box 不超过 4×4）。
  - 每个对象由 1 到 3 种不同颜色的像素组成。
  - 对象之间间距足够大，保证盖印不会重叠。

- `Rule`：
  - 对每个对象，计算其内部包含的不同颜色种类数 K。
  - 以该对象的 bounding box 中心为起点，沿该对象中心所在行向右方，等间距（间距 = 对象 bounding box 宽度 + 1）复制该对象 K 次（不含原始对象本身，即额外复制 K 份）。
  - 每次复制保持对象的完整形状和颜色不变。
  - 若复制的位置超出网格右边界，则跳过该复制。
  - 原始对象保留在原位。

- `Key insight`：
  - 解题者容易注意到对象被复制了若干次，但需要反复对比才能发现复制次数不是由对象大小、位置或形状决定，而是由对象内部颜色的多样性（不同颜色数量）决定的。单色对象复制 1 次，双色复制 2 次，三色复制 3 次。
</new_puzzle>

<new_puzzle>
- `description`：网格中有若干个由同一种颜色绘制的闭合矩形轮廓，每个轮廓内部藏有一个小标记点。将每个矩形沿标记点所指示的最近边做镜像翻转，翻转后的副本以另一种颜色绘制并拼接在该边外侧。

- `Input structure`：
  - 背景色为 black。
  - 网格中有若干个用 blue 像素绘制的闭合矩形轮廓（一像素宽的矩形边框）。
  - 每个矩形轮廓内部恰好有一个 red 像素（标记点），位于轮廓内部的某个位置（不在边框上）。
  - 矩形之间不重叠，且间距足够大以容纳翻转后的副本。

- `Rule`：
  - 对每个 blue 矩形轮廓，找到其内部的 red 标记点。
  - 计算该 red 标记点到矩形四条边的曼哈顿距离，确定距离最近的那条边（若有并列，取上 > 下 > 左 > 右的优先级中最先者）。
  - 将整个矩形轮廓（包含 red 标记点）沿最近边为对称轴做镜像翻转。
  - 翻转后的副本中，原来的 blue 像素改为 green，原来的 red 标记点改为 yellow。
  - 翻转副本放置在原矩形该边的外侧，紧贴该边（共享该边的像素行或列）。
  - 原始矩形和标记点保留不变。

- `Key insight`：
  - 解题者需要首先发现每个矩形都多出了一个镜像副本，然后需要弄清镜像轴的选择机制。关键洞见是镜像轴并非固定方向，而是由内部标记点的偏心位置决定——标记点偏向哪条边，就沿那条边翻转。标记点在视觉上很容易被忽略，因为它只是矩形内部的一个小点。
</new_puzzle>

<new_puzzle>
- `description`：网格中的每条彩色路径是一条"传送带"，路径上散落的货物像素会沿传送带方向移动，移动距离等于该传送带上货物的总数。

- `Input structure`：
  - 背景色为 black。
  - 网格中有若干条由不同颜色绘制的一像素宽连续路径（每条路径是水平和垂直线段首尾相连的折线，用同一种颜色绘制，如 blue、green、red 等）。
  - 每条路径有一个明确的起点和终点（起点和终点是路径中度数为 1 的端点像素）。
  - 路径上的某些像素被替换为 yellow 像素，表示"货物"。这些 yellow 像素仍位于路径轨迹上。
  - 不同路径之间不交叉。

- `Rule`：
  - 对每条路径（同色连续折线），将其像素按从起点到终点的顺序排列（起点定义为两个端点中行号较小的那个，行号相同则列号较小的）。
  - 统计该路径上 yellow 货物像素的数量 M。
  - 将每个 yellow 货物像素沿路径方向（从起点到终点）前移 M 步（一步 = 沿路径前进一个像素位置）。
  - 若前移后位置超出路径终点，则该货物从路径终点"掉落"——在终点处沿路径最后一段的方向继续延伸到网格中（用 yellow 绘制），每超出一步延伸一个像素。
  - 原来货物所在的路径位置恢复为路径本身的颜色。

- `Key insight`：
  - 解题者需要将有色折线理解为有方向的"轨道"，yellow 像素理解为轨道上的移动体。关键难点在于发现移动距离不是固定常数，而是由同一条轨道上货物的总数决定的——货物越多，每个货物移动越远。这种"集体属性决定个体行为"的模式需要跨样例对比才能归纳。
</new_puzzle>

<new_puzzle>
- `description`：网格中每个前景色块充当"种子"，从它的位置开始向外逐层生长，生长层数由种子的面积决定，不同种子之间竞争空间，碰撞处互相中和为背景色。

- `Input structure`：
  - 背景色为 black。
  - 网格中有若干个互不相连的小型单色色块（每个色块是一个 4-连通区域，面积在 1 到 5 像素之间），颜色各不相同。
  - 色块之间有足够的间距。

- `Rule`：
  - 对每个色块，计算其面积 A（像素数量），A 即为该色块的"生长代数"。
  - 模拟 A 代简化生长过程：每一代中，将该色块当前所有像素的所有 4-邻居中为 black 的位置，全部染上该色块的颜色（即每代向外扩展一层）。
  - 如果两个不同颜色的色块在同一代中试图占据同一个 black 像素，则该像素保持 black（两者都无法占据）。
  - 所有色块同时执行各自的生长过程，逐代同步推进。一个色块达到自己的最大代数后停止生长，但其他未达到最大代数的色块继续生长。
  - 输出为所有生长完成后的最终网格状态。

- `Key insight`：
  - 解题者需要发现两个关键机制：（1）每个色块的扩展层数等于其初始面积——面积越大的种子生长得越远；（2）不同颜色的生长区域在碰撞边界处互相"中和"为背景色，形成自然的分界线。这两个机制共同决定了最终的空间分布图案。
</new_puzzle>

<new_puzzle>
- `description`：网格中有一个大型图案和若干小型"滤镜"块；每个滤镜块定义一组颜色替换规则，按从上到下的顺序依次应用到大图案上，输出是所有滤镜叠加后的结果。

- `Input structure`：
  - 背景色为 black。
  - 网格左侧有一个大型矩形多色图案（由多种颜色的像素组成，bounding box 约 10×10 到 15×15）。
  - 网格右侧有若干个小型矩形"滤镜"块（每个滤镜块恰好是 2 行 × W 列的结构）。
  - 每个滤镜块的第一行是一组颜色像素，表示"源颜色"序列；第二行是对应位置的"目标颜色"序列。每个滤镜块的列数至少为 1。
  - 每个滤镜块旁边（正上方一行）有一个 maroon 像素标记，其列坐标对齐到滤镜块的左边缘。

- `Rule`：
  - 识别大图案区域和所有滤镜块。
  - 按滤镜块从上到下的顺序依次应用滤镜。
  - 应用一个滤镜时：读取其第一行（源颜色列表）和第二行（目标颜色列表），建立一一对应的颜色映射关系。
  - 将大图案中所有匹配源颜色的像素替换为对应的目标颜色。
  - 每个滤镜在前一个滤镜的结果上叠加操作。
  - 输出为仅包含应用完所有滤镜后的大图案（裁剪到大图案的 bounding box 大小）。

- `Key insight`：
  - 解题者需要发现右侧的小块并非独立的对象，而是"颜色映射指令"——每个小块的两行分别定义了一组颜色替换规则。更隐蔽的是这些滤镜的应用有先后顺序（从上到下），且后面的滤镜作用于前面滤镜已经修改过的图案上，因此同一个像素可能被多次变换，最终颜色取决于滤镜链的顺序。
</new_puzzle>
