# 第一步：分析与思考

## 参考题中涉及的基础操作梳理

从20道参考题中可提炼出以下基础操作类型：

1. **空间变换**：平移、旋转、翻转、缩放（参考4的按比例缩放、参考6的尺寸循环）
2. **模板印章/Kronecker积**：用一个掩码控制另一个掩码的铺展（参考1）
3. **形状匹配与配对**：通过形状、颜色、计数等属性将对象配对（参考2、3、13）
4. **控制信号解码**：网格中的标记像素编码移位量、模板索引或选择信号（参考9、12、16）
5. **路径与连通性**：绘制路线、绕障碍物走、绳索缠绕（参考18、19）
6. **条件着色/传播**：根据邻接关系或条件有选择地涂色（参考10、15）
7. **序列/周期生成**：基于控制值展开一维序列并换行（参考20）
8. **拼接组装**：连接器像素驱动的拼图拼合（参考5）
9. **裁剪与提取**：根据标记或结构特征从网格中提取子区域（参考16、17）
10. **方向/位置编码**：L形缺角决定方向（参考14），列位置决定路径拓扑（参考18）

## 非显而易见的串联方式与创新方向

**对象自身几何属性作为隐式操作指令**：多数参考题中，"该怎么变换"由外部控制信号（标记像素、分隔线位置、锚点颜色）显式指定。但如果对象的某个内在几何特征——比如其对称性阶数、凸/凹性、分支数——本身就隐式编码了变换类型或参数，解题者就需要先发现"对象哪个属性才是关键"，再推断属性值与变换之间的映射。

**叠加/干涉作为信息显影**：大多数题目中每个前景像素的含义独立于其他像素。如果引入"叠加"概念——多个隐含层各自投影到同一画布上，只有叠加区域才产生可见输出——则解题者需要逆向推理出各隐含层的存在。

**"负空间"与"正空间"的角色互换**：参考题几乎都在操作前景对象，但背景空隙本身也可以携带信息。如果输出取决于背景区域的几何属性（而非前景），解题者需要视角翻转。

**相对关系作为变换参数**：两个对象之间的空间关系（距离、对齐方式、包含关系）可以编码操作类型。例如距离远近决定是否保留，相对方位决定移动方向。

**隐藏的序列/路径**：表面看起来是二维噪声的网格中，可能隐藏着一条由某种规则（如颜色循环）定义的一维路径，输出是提取该路径。

**骨架/侵蚀**：对形状进行保持连通性的迭代腐蚀，提取其拓扑骨架——这是一种在参考题中未出现的形态学操作。

# 第二步：全新 ARC 谜题

<new_puzzle>
- `description`：每个彩色像素向所在行和列投射十字影响，仅在多重交叉点处显色——叠加次数决定输出颜色。
- `Input structure`：
  - 背景色为 black。网格尺寸约 10×10 到 14×14。
  - 网格上散布着若干孤立的彩色像素（每个像素的4-连通邻居全为 black），颜色从 red、blue、green、yellow、magenta 中选取，各像素颜色不必相同。像素数量约3到6个。
- `Rule`：
  - 保留所有原始彩色像素在原位，颜色不变。
  - 每个彩色像素对其所在的整行和整列宣称"影响"：即该行全部格子和该列全部格子都被该像素影响（像素自身所在格除外）。
  - 对每个 black 格子，统计它被多少个不同像素影响（即有多少条十字经过它）：
    - 被 0 或 1 个像素影响：保持 black。
    - 被恰好 2 个像素影响：填充为 grey。
    - 被 3 个及以上像素影响：填充为 orange。
  - 输出网格尺寸与输入相同。
- `Key insight`：表面上每个像素的行和列都被"照亮"了，但输出中绝大部分行列像素仍为 black——只有行列交叉处（同时属于两个不同像素的影响范围）才显色。解题者需要克服"整行整列都变色"的第一直觉，发现输出规律实际上是"交叉计数阈值"：单次覆盖不可见，双重及以上覆盖才产生输出，且颜色编码的是覆盖次数而非源颜色。
</new_puzzle>

<new_puzzle>
- `description`：散落的"缺臂十字"对象各自沿缺口反方向同步滑动，碰撞后停止，对撞空隙标为特殊颜色。
- `Input structure`：
  - 背景色为 black。网格尺寸约 12×12 到 18×18。
  - 网格上有若干个"缺臂十字"对象，每个对象由同一种颜色绘制（不同对象颜色不同，从 red、blue、green、yellow 中选取）。
  - 每个缺臂十字的形状为：一个中心像素加上3个正交方向各延伸1个像素（共4像素），形成"T"形。缺失的第4个臂的方向是该对象的"缺口方向"。例如：中心在 (r,c)，若 (r,c+1) 是缺失的臂，则缺口朝右。
  - 对象之间互不相邻（任意两个对象的像素之间至少间隔1格 black）。
  - 网格边缘视为墙壁。
- `Rule`：
  - 每个对象的运动方向 = 缺口方向的反方向。即：缺口朝右的对象向左滑动；缺口朝上的对象向下滑动；以此类推。
  - 所有对象同步滑动，每轮所有对象同时向各自的方向移动1格。
  - 当某对象的前沿下一步将与网格边界或任何已停止对象的像素重叠时，该对象立即停止（停在当前位置）。已停止的对象成为后续其他对象的障碍。
  - 当两个对象相向而行且下一步会相互侵入时，两者都在当前位置停止。此时两者之间的1格空隙（若存在）标记为 maroon。
  - 输出中，对象原始位置被擦除为 black，对象在最终停止位置以原色绘制。
- `Key insight`：核心困难在于识别方向编码方式——对象外观近似对称的十字形，需要仔细观察才能找出缺失的那一臂，而运动方向是缺口的反方向（即"三臂伸展侧"），这与将缺口视为"指向"的直觉相反。其次是同步运动和碰撞的模拟。
</new_puzzle>

<new_puzzle>
- `description`：在满屏色块中发现由颜色循环序列定义的唯一路径，保留路径、清除其余。
- `Input structure`：
  - 网格尺寸约 9×9 到 13×13，所有格子都被彩色像素填满，无 black 背景。
  - 使用5种颜色（从 red、blue、green、yellow、magenta 中选取），看似随机分布。
  - 左上角 (0,0) 和右下角 (H-1,W-1) 的像素颜色相同，作为路径的起点和终点。
  - 这5种颜色之间存在一个固定的循环序列（如 red → green → blue → yellow → magenta → red → ...），需要从样例中推断。
- `Rule`：
  - 从左上角出发，每一步移动到4-连通邻居（上下左右）中颜色等于循环序列中下一种颜色的那个邻居。
  - 因为题目构造保证每一步恰好只有一个合法邻居满足颜色条件，所以路径是唯一确定的。
  - 路径最终到达右下角。
  - 输出中：路径上的像素保持原色；路径之外的所有像素变为 black。
- `Key insight`：输入看起来像毫无规律的彩色噪声，而输出是一条从左上到右下的蜿蜒路径。解题者需要：(1) 观察到输出保留的像素形成连续路径；(2) 检查路径上相邻像素的颜色变化，发现固定的循环模式；(3) 从多个样例中确认同一个循环序列。难点在于满屏颜色的视觉干扰下，"循环颜色序列"这一隐藏秩序极不直观。
</new_puzzle>

<new_puzzle>
- `description`：根据同色对象群体内的相对距离排名，淘汰最孤立的对象、保留最亲近的对象。
- `Input structure`：
  - 背景色为 black。网格尺寸约 15×15 到 20×20。
  - 网格上散布着若干个小型单色4-连通对象（每个对象3到6像素），颜色从 red、blue、green、yellow 中选取。
  - 每种颜色恰好出现3个对象。同色的3个对象形状可以不同。
  - 任意两个对象之间互不相邻（像素级别至少间隔1格 black）。
- `Rule`：
  - 对每种颜色的3个对象，两两计算曼哈顿距离（取两个对象各自像素之间曼哈顿距离的最小值作为两对象间的距离）。
  - 每种颜色的3个对象产生3对距离。找出距离最小的那一对——这两个对象是"最亲近对"，保留。
  - 第3个对象（不属于最亲近对的那个）被删除，其像素变为 black。
  - 若出现距离并列（两对距离相同且都是最小值），则保留共享对象最多的组合；如果仍然无法区分，则保留包含在输入中位置最靠上（行号最小）对象的那一对。
  - 不同颜色独立处理。保留的对象保持原位和原色不变。
- `Key insight`：规则不取决于对象的绝对位置、形状或大小，而取决于同色对象三元组内的相对距离排名。消失的总是离"最近同伴对"最远的那个第三者。解题者需要逐色分析，发现"被删除的对象"是同色群体中最孤立的那一个，而保留的是距离最近的一对。
</new_puzzle>

<new_puzzle>
- `description`：左侧对象的旋转对称阶数决定其在右侧面板中被复制的份数和排列方式——对称性越高，副本越少。
- `Input structure`：
  - 背景色为 black。网格尺寸约 20×20 到 25×25。
  - 一条宽1列的 grey 垂直分隔线将网格分为左半和右半，各约9到12列宽。
  - 左半包含若干小型单色对象（每个3到7像素，颜色各不相同，如 red、blue、green、yellow、magenta 等），对象之间互不相邻。
  - 右半在输入中全部为 black。
- `Rule`：
  - 对左侧每个对象，以其像素集合的最小外接矩形为基准，判断其旋转对称阶数：
    - 4阶对称（旋转90°后像素集合不变）：在右侧放置1份原样副本。
    - 2阶对称（旋转180°后不变，但90°后改变）：在右侧放置2份副本，一份为原始朝向，一份旋转90°，两份上下排列，间隔1行 black。
    - 1阶（无旋转对称性）：在右侧放置4份副本，分别为旋转0°、90°、180°、270°，以2×2方式排列（左上0°，右上90°，左下180°，右下270°），相邻副本间隔1列/1行 black。
  - 右侧多组副本从上到下排列，按左侧对象的行坐标（最小行号）从小到大排序，组与组之间间隔2行 black。
  - 每组副本的列起始位置 = 分隔线右侧第2列（即分隔线列+2）。
  - 左半和分隔线在输出中保持不变。
- `Key insight`：右侧副本数只有1、2、4三种，且与左侧对象的"华丽程度"（形状复杂度）并无直接关联——真正的决定因素是旋转对称阶数。反直觉的是：对称性越高的对象产生越少的副本。解题者需要从右侧的数量差异反推，找到左侧对象的对称性与副本数量之间的反比关系。
</new_puzzle>

<new_puzzle>
- `description`：边缘标记像素构成坐标系，内部同色对象被"导航"到标记指定的目标位置。
- `Input structure`：
  - 背景色为 black。网格为正方形，尺寸约 12×12 到 16×16。
  - 最底行（行 H-1）有若干单像素标记，分布在不同列上，每个标记颜色各不相同（从 red、blue、green、yellow、magenta 中选取）。
  - 最右列（列 W-1）有若干单像素标记，分布在不同行上，颜色集合与底行标记颜色集合完全相同，一一对应。
  - 网格内部（不含底行和最右列）有若干小型单色矩形对象（1×1 到 2×3），每个对象的颜色恰好在底行/右列标记中出现一次。
  - 对象之间互不相邻，对象也不与标记相邻。
- `Rule`：
  - 对每个内部对象，找到底行中同色标记所在的列 c_dest，以及右列中同色标记所在的行 r_dest。
  - 将该对象平移到以 (r_dest, c_dest) 为左上角的位置。
  - 底行标记和右列标记在输出中保持不变。
  - 对象移动后不会与其他移动后的对象或标记重叠（题目构造保证无冲突）。
  - 原始位置的像素变为 black。
- `Key insight`：底行和右列的同色标记共同构成一个"坐标寻址系统"——它们不是装饰或边框的一部分，而是为每种颜色的对象指定了目标坐标。解题者需要发现颜色是将"内容对象"与其"目标地址"联系起来的键：先按颜色匹配，再通过两条边上的标记位置读出行坐标和列坐标。
</new_puzzle>

<new_puzzle>
- `description`：对大型不规则色块执行保连通性的迭代腐蚀，提取其拓扑骨架并变色输出。
- `Input structure`：
  - 背景色为 azure。网格尺寸约 15×15 到 20×20。
  - 网格上有2到4个较大的单色不规则连通区域（4-连通），每个区域至少占8个像素，颜色从 red、green、yellow、magenta 中选取。
  - 每种颜色只出现一个区域。区域之间不接触（像素级别无4-连通相邻）。
- `Rule`：
  - 对每个彩色区域独立进行以下操作：
    - 找出所有"边界像素"（该像素至少有一个4-连通邻居不属于本区域——即为 azure 或属于其他区域）。
    - 在所有边界像素中，逐一检查：如果移除该像素后剩余的本区域像素仍为4-连通的，则标记该像素为"可移除"。
    - 同时移除所有"可移除"的边界像素（将它们变为 azure）。
    - 重复以上过程，直到某轮没有任何像素被移除。
  - 最终剩余的像素即为该区域的骨架。
  - 输出中，骨架像素统一用 blue 绘制（无论原始颜色），原始区域的非骨架像素变为 azure。
  - 网格其余部分保持不变。
- `Key insight`：输出中的 blue 细线条总是位于原始色块的"最深处"——像是河流的干流而非支流。这不是简单的缩小或边框提取，而是"保持连通性的最大腐蚀"（拓扑骨架）。解题者需要注意到：(1) 输出线条的形状取决于原始区域的拓扑而非仅是几何外轮廓；(2) 比较不同形状的输入和输出，发现"突出部"会被完全吃掉而"走廊"被保留，从而推断出迭代剥皮规则。
</new_puzzle>

<new_puzzle>
- `description`：封闭区域按围成它的不同线段数量分类着色——边界成分数量决定填充颜色。
- `Input structure`：
  - 背景色为 black。网格尺寸约 12×12 到 18×18。
  - 网格上有若干条直线段（水平或垂直），每条线段由连续的同色像素组成，线段颜色从 red、blue、green、yellow、magenta 中选取。
  - 不同线段颜色不同（或可以相同，但通过位置和方向可区分）。
  - 线段相互交叉，在网格上形成若干封闭区域和若干非封闭区域（与网格边缘相通）。
  - 封闭区域是指完全被线段像素包围的 black 连通区域（4-连通），其中该区域的4-连通边界全部是线段像素。
- `Rule`：
  - 保留所有线段像素不变。
  - 对每个封闭区域（即不与网格边缘相通的 black 连通分量），统计其边界上涉及多少种不同颜色的线段（即围成该区域的线段来自几种不同颜色）：
    - 1种颜色：不填充，保持 black。
    - 2种颜色：填充为 orange。
    - 3种颜色：填充为 maroon。
    - 4种及以上颜色：填充为 grey。
  - 非封闭区域（与网格边缘连通的 black 区域）保持 black。
- `Key insight`：直觉上会以为填充颜色取决于区域面积、形状或位置，但实际取决于围成该区域的线段涉及的"颜色种类数"。解题者需要：(1) 注意到不同封闭区域被填上了不同颜色；(2) 排除面积、形状等显而易见的候选特征；(3) 发现关键在于追踪每个区域的边界，统计边界上有几种不同颜色的线段参与。对于交叉较复杂的情况，这需要仔细辨认。
</new_puzzle>
