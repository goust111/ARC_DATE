# 第一步：分析与思考

## 参考题中的基础操作梳理

参考题涵盖了以下核心操作类别：
- **空间移动**：重力下落（#1, #16）、沿路径滑动（#6）、向目标平移（#8, #4）
- **射线/投射**：从标记点发射射线（#2, #3, #11）、射线碰撞检测
- **形状识别与匹配**：归一化形状匹配上色（#15）、查表匹配（#17）、glyph查找（#7）
- **聚合/合并**：多层叠加（#10）、拼图组装（#9）、计数转点（#19）
- **序列/排序操作**：扫描序着色（#5）、路径颜色翻转（#18）
- **压缩/符号化**：3x3符号缩为1像素后滑动（#12）、散射像素压回锚点（#13）
- **镜像/对称**：跨分隔线镜像反射（#14）
- **控制像素/标记语义**：角落标记控制填充（#20）、标记决定方向（#3）

## 非显而易见的串联方式思考

1. **拓扑属性作为隐藏分类器**：物体是否存在"内部像素"（被同色邻居完全包围、不接触背景的像素）这种拓扑属性，可以用肉眼在网格上直接辨认，却不容易被解题者意识到这才是分类判据。它和物体大小、颜色无关，而是一种关于"厚薄"的几何性质。

2. **颜色作为操作指令的配对密钥**：颜色通常被看作标识物体身份的标签，但它也可以充当"链接"——将网格不同位置的元素配对。例如物体的颜色匹配边缘上某个"接收器"的颜色，从而间接指定了运动方向和目标区域。

3. **全局空间位置编码操作类型**：一个物体自身的形状和颜色不变，但它在全局坐标系中所处的象限位置却可以决定对它施加什么变换。这种"位置即指令"的关系在参考题中未见，但在视觉上是可观察的。

4. **可见性与距离的复合条件**：射线投射通常只考虑方向和碰撞，但如果同时要求"最近且可见"，遮挡关系就会让直觉距离判断失效——最近的源可能被墙壁挡住，真正生效的是较远但有通路的源。

5. **对称性作为分流器**：物体自身是否具有某种对称性（如左右镜像对称）可以将物体分成两类，一类不变、一类被变换。这种分类依据需要解题者逐一检验每个物体的形状，是一种视觉上可行但认知负担较高的判断。

6. **负空间中的微结构**：边框上一个像素的缺口在视觉上极易被忽略，但它可以携带方向信息。解题者需要在看似连续的围墙中精确定位这些微小缺口，才能理解物体的运动方向。

7. **种子颜色编码图案类型**：一个像素的颜色不止标识归属，还可以编码一种"填充纹理"——不同颜色对应水平条纹、垂直条纹或棋盘格等不同的空间图案，且图案的相位锚定在各自区域的局部坐标上。

## 创新方向

遵循记忆中的反馈，参考题仅作为格式和难度基准。以下新题追求的是全新的认知路径——解题者需要发现什么样的隐蔽规律才能从输入推出输出，而非仅在参考题的机制上做微调。

<new_puzzle>
- `description`：根据每个彩色物体是否存在"内部像素"（不接触背景的像素），决定保留还是擦除该物体。
- `Input structure`：
  - 背景为Black，网格中散布若干不同颜色的4-连通实心物体，每个物体占据至少3个像素。
  - 物体颜色各不相同，可能使用Red、Blue、Green、Yellow、Orange、Magenta等。
  - 物体形状各异：有的紧凑（接近正方形），有的细长或呈分支状。
- `Rule`：
  - 对每个4-连通前景物体，检查其每个像素的4-邻居：统计周长P（至少有一个4-邻居为背景的像素数）和面积A（物体像素总数）。
  - 若P等于A（即该物体的每个像素都至少接触一个背景像素，没有完全被同色像素四面包围的内部像素），则保留该物体，颜色和形状不变。
  - 若P小于A（即物体存在至少一个所有4-邻居都是同色像素的内部像素），则将整个物体擦除为背景色Black。
  - 背景像素始终不变。
- `Key insight`：判断标准不是物体的大小、颜色或位置，而是物体是否存在"内部像素"——即被同色像素四面包围、不与背景接触的像素。等价于判断物体是否为"宽度恰好为1"的薄壳结构：所有线条状、L形、U形等每像素都暴露在外的物体存活；而紧凑填充的块状物体（如3x3实心方块）因存在内核像素而被消除。解题者需要从多个样例中逐步排除大小、颜色等干扰假设，最终锁定这个拓扑判据。
</new_puzzle>

<new_puzzle>
- `description`：将网格中的内部彩色物体投射到与其同色的边框线段上，投射方向由线段所在的网格边缘决定。
- `Input structure`：
  - 背景为Black。
  - 网格的四条边缘上分布有若干彩色线段：每段线段由连续的同色像素组成，紧贴网格边缘（第一行、最后一行、第一列或最后一列）。各线段颜色互不重复。例如，第一行的第3到第7列为Red，第一列的第4到第8行为Blue。
  - 网格内部（不在边缘行/列）散布若干4-连通单色物体，每个物体的颜色恰好匹配某一条边缘线段的颜色。
- `Rule`：
  - 对每个内部物体，找到颜色相同的边缘线段，确定该线段所在的边：上边（第一行）→物体向上投影；下边（最后一行）→向下投影；左边（第一列）→向左投影；右边（最后一列）→向右投影。
  - 投影方式：物体的每个像素沿投影方向滑动到网格边缘的第一行/最后一行/第一列/最后一列。投影后，像素在垂直于投影方向的坐标不变（向上/下投影时列坐标不变，向左/右投影时行坐标不变）。
  - 仅保留投影后落在对应边缘线段覆盖范围内的像素（即向上投影时，像素的列坐标必须在该线段的列范围内）；超出线段范围的投影像素被丢弃。
  - 投影后的像素覆盖在边缘线段上方/下方/左方/右方紧邻的那一行或列（即线段内侧的相邻位置），而非直接覆盖线段像素。保留的投影像素以物体颜色绘制。
  - 清除内部物体的原始像素。边缘线段本身保持不变。
- `Key insight`：颜色在这里扮演了"地址"角色——它将内部物体与边缘的接收线段配对，同时隐式指定了投影方向。解题者需要发现三重关联：（1）颜色匹配确定配对，（2）线段所在的边确定方向，（3）线段的范围确定有效投影区域。只关注其中任何两个都无法得出正确答案。
</new_puzzle>

<new_puzzle>
- `description`：网格中心有一个Grey标记点，每个前景物体根据其所在象限被施加不同角度的旋转。
- `Input structure`：
  - 背景为Black，网格尺寸为奇数行乘奇数列（保证唯一中心像素存在）。
  - 网格正中心的像素为Grey，作为坐标原点标记。
  - 中心行（Grey所在行）和中心列（Grey所在列）上除Grey外没有其他前景像素，起到"坐标轴"分隔作用。
  - 网格的四个象限中各散布若干小型4-连通单色物体（每个不超过5个像素），颜色各异（Red、Blue、Green、Yellow、Orange等）。每个物体完全位于某一个象限内，不跨越中心行或中心列。
- `Rule`：
  - 以Grey像素为原点定义四个象限（不含中心行和中心列）：
    - 右上象限（行号小于中心行，列号大于中心列）：物体顺时针旋转90度。
    - 左上象限（行号小于中心行，列号小于中心列）：物体旋转180度。
    - 左下象限（行号大于中心行，列号小于中心列）：物体逆时针旋转90度（等同顺时针270度）。
    - 右下象限（行号大于中心行，列号大于中心列）：物体不旋转，保持不变。
  - 旋转锚点为每个物体自身包围盒的中心。旋转后的物体居中放置在原包围盒中心位置上。物体颜色不变。
  - Grey中心像素保持不变。背景不变。
- `Key insight`：旋转角度完全不由物体自身的形状、颜色或大小决定，而是由其在全局网格中的空间位置（象限）决定。右下象限是"零度基准"，从右下开始逆时针方向每跨一个象限增加90度旋转。解题者须先注意到中心Grey点的坐标轴意义，再从不同象限物体的形变差异中归纳出位置-旋转的映射。
</new_puzzle>

<new_puzzle>
- `description`：网格中有若干信号源像素和若干Grey空心矩形框；每个框的内部填充色取决于沿轴向可见且距离最近的信号源颜色。
- `Input structure`：
  - 背景为Black。
  - 若干单像素的"信号源"散布在网格中，颜色各异（如Red、Blue、Green、Orange等），每种颜色最多出现一次。
  - 若干用Grey像素绘制的1像素厚空心矩形框散布在网格中，框内全为Black。框与框不重叠也不相邻。
  - 所有信号源均位于所有框的外部。
- `Rule`：
  - 对每个Grey空心框，逐一检查每个信号源的"可见性"：
    - 从信号源像素出发，沿上、下、左、右四个方向各射出一条射线。
    - 若某条射线在到达该框的Grey外壁之前，不经过任何其他Grey框壁像素，也不经过任何其他信号源像素，则该射线命中该框，称该信号源对此框"可见"。
  - 在所有对此框可见的信号源中，选择与该框曼哈顿距离最小的那个（曼哈顿距离定义为信号源像素与框最近Grey壁像素之间的曼哈顿距离，保证该最近信号源唯一）。
  - 用该最近可见信号源的颜色填充框内部所有Black像素。
  - 若没有任何信号源对某框可见，则该框内部保持Black不变。
  - Grey框壁保持不变。信号源像素保持不变。
- `Key insight`：空间上距离最近的信号源未必"可见"——中间可能有其他框的墙壁挡住了直线路径。解题者需要同时考虑两个条件：（1）轴向直线可达（可见性），（2）距离最近。仅凭距离远近或仅凭方向都无法得到正确答案。遮挡关系使得看似简单的"最近匹配"问题变得需要仔细追踪每条射线。
</new_puzzle>

<new_puzzle>
- `description`：封闭区域内的单个种子像素的颜色决定该区域的填充纹理类型（水平条纹、垂直条纹或棋盘格）。
- `Input structure`：
  - 背景为Black。
  - 网格中有用Grey像素绘制的若干封闭围墙。围墙为任意形状的4-连通闭合环路，厚度1像素。每段围墙完全由Grey像素组成，构成一个封闭区域。
  - 每个封闭区域（围墙内部的连通Black区域）内恰好有一个单像素的彩色"种子"，颜色为Red、Blue或Green之一。
  - 围墙外部的Black背景中没有种子像素。不同区域可以有相同颜色的种子。
- `Rule`：
  - Red种子 → 水平条纹填充：以该区域包围盒的顶行为基准，区域内像素若其行号与包围盒顶行的偏移量为偶数（0, 2, 4, ...）则填充Red，偏移量为奇数（1, 3, 5, ...）则保持Black。仅填充属于该封闭区域内部的像素。
  - Blue种子 → 垂直条纹填充：以该区域包围盒的最左列为基准，区域内像素若其列号与包围盒最左列的偏移量为偶数则填充Blue，奇数则保持Black。仅填充该区域内部像素。
  - Green种子 → 棋盘格填充：以区域包围盒左上角为基准，区域内像素若（行偏移 + 列偏移）为偶数则填充Green，奇数则保持Black。仅填充该区域内部像素。
  - 种子像素不特殊保留，被其对应的纹理规则覆盖（即种子位置按同一公式决定是填色还是Black）。
  - Grey围墙保持不变。围墙外部的Black背景保持不变。
- `Key insight`：解题的核心在于识别颜色与纹理类型之间的映射关系。输出中的条纹/棋盘图案看起来复杂，但本质上只由种子的颜色决定。解题者需要从不同区域对比中发现：（1）同色种子总是产生相同类型的纹理，（2）不同色种子产生不同纹理，（3）纹理相位锚定在各自区域的包围盒上而非全局坐标。第三点意味着相邻区域即使纹理类型相同，条纹也未必对齐——这会干扰解题者试图寻找全局模式的直觉。
</new_puzzle>

<new_puzzle>
- `description`：根据物体是否具有水平镜像对称性将其分为两类：对称物体保持不变，非对称物体被水平翻转并改为最近对称物体的颜色。
- `Input structure`：
  - 背景为Black。
  - 网格中有若干分离的4-连通单色物体，颜色各异（如Red、Blue、Green、Yellow、Orange、Magenta等）。
  - 每个物体至少占据3个像素，物体之间互不接触（不4-相邻）。
  - 部分物体的形状沿其包围盒的垂直中轴具有左右镜像对称性，另一部分不具有。
- `Rule`：
  - 对每个物体，判定其形状是否关于自身包围盒的垂直中轴左右对称。判定方法：将物体形状提取为其包围盒内的二值掩码，检查该掩码水平翻转后是否与原掩码完全一致。
  - 对称物体：位置、形状、颜色均保持不变。
  - 非对称物体：
    1. 形状变换：将其二值掩码沿包围盒垂直中轴水平翻转，翻转后的形状放回原包围盒位置。
    2. 颜色变换：计算该非对称物体的包围盒中心到每个对称物体的包围盒中心的曼哈顿距离，选择距离最近的对称物体（保证唯一），将非对称物体的颜色改为该最近对称物体的颜色。
  - 背景保持Black不变。
- `Key insight`：解题者需要先发现隐蔽的分类维度——对称性，这需要对每个物体逐一做视觉上的镜像检验。然后需要发现双重变换规则：非对称物体同时发生形状翻转和颜色替换，而对称物体完全不变。对称物体既是"免变换"的特权对象，又是非对称物体颜色变换的"供体"。这种"分类 + 双重变换 + 就近配对"的三层结构使得规则很难从单个样例中一次性识别。
</new_puzzle>

<new_puzzle>
- `description`：网格中由Azure边框围成若干矩形房间，每个房间边框上有一个1像素缺口（门），房间内的物体朝门方向滑出房间。
- `Input structure`：
  - 背景为Black。
  - 网格中有若干用Azure像素绘制的矩形房间。每个房间是一个完整的矩形边框（外轮廓），壁厚1像素。不同房间可以共享墙壁。
  - 每个房间的边框上恰好有一个1像素的缺口（该位置是Black而非Azure），即"门"。门位于某条边的非角落位置。
  - 每个房间内部恰好有一个小型4-连通彩色物体（颜色非Black、非Azure），物体不接触任何Azure墙壁（物体与墙壁之间至少有1个Black像素的间距）。
- `Rule`：
  - 确定每个房间的门所在的边：门在上壁则方向为"上"，门在下壁则方向为"下"，门在左壁则方向为"左"，门在右壁则方向为"右"。
  - 将房间内的物体沿门的方向平移。物体穿过门（缺口），继续沿同方向移动，最终停在房间外部：物体的尾沿（离门最远的那一边）紧贴门所在墙壁的外侧。
  - 具体来说，物体最终位置满足：物体完全位于房间外部，沿移动方向上物体的后缘与门所在壁的外表面相邻（间距为0，紧贴）。物体在垂直于移动方向上的坐标不变。
  - 清除物体在房间内的原始位置像素为Black。
  - Azure边框（包括缺口处的Black像素）保持不变。
  - 若物体移到网格外，裁切超出部分。
- `Key insight`：题目的核心困难在于发现"门"——Azure边框上仅有的1像素Black缺口在视觉上非常不显眼，尤其当网格较大、房间较多时。解题者需要逐个房间仔细检查边框完整性来定位门。一旦找到门，运动方向就确定了（朝向门）。物体不是被推到房间对面墙壁，而是穿过门到外面去——这与常见的"重力下落"或"撞墙停止"模式不同。
</new_puzzle>
