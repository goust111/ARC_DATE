# 第一步：分析与思考

## 参考题中的基础操作梳理

从20道参考题中可以提取出以下基础操作类别：

1. **图论操作**：将网格编码为图，执行最短路径（#1, #5）
2. **空间变换**：剪切/旋转/平移（#8 剪切, #11 上移, #20 循环滚动）
3. **属性解耦与重组**：同一对象的不同属性独立变换（#4 颜色与高度分别循环移位）
4. **模板印章**：用模板填充或覆盖标记位置（#3, #7）
5. **统计/计数编码**：对象数量转化为柱状图（#12, #6 高度算术）
6. **方向编码**：用sprite形状或标记位置编码方向（#16, #9, #10）
7. **组装/对接**：通过颜色端口匹配拼接对象（#18）
8. **遮挡与射线**：对角线射线传播与遮挡分区（#19）
9. **控制信号解码**：特殊列/行编码操作参数后被移除（#20）
10. **序列推进**：根据属性序列移动标记（#17）
11. **块级重排**：对整块进行排列操作（#15）
12. **几何填充**：基于方向/距离的渐变填充（#14）

## 非显而易见的串联方式思考

- **形状即指令**：对象的轮廓或拓扑结构不仅仅是被变换的对象，而是编码了变换本身的规则。例如一个L形不仅是一个需要移动的物体，它的弯折方向可能决定了其它对象的旋转方式。
- **负空间即信息**：背景中被对象围出的"洞"或空隙，其形状、面积或位置承载着关键变换参数，而解题者往往只关注前景对象。
- **拓扑不变量作为匹配键**：两个形状不按颜色或位置匹配，而是按"孔的数量"或"凸包与实际面积的差"等拓扑/几何属性来配对。
- **相对关系即输出**：输出不是对输入对象的变换，而是对输入中对象之间关系（距离、角度、包含关系）的可视化编码。
- **时间轴嵌入在空间中**：网格的某一维度隐含了一个时间序列或演化过程，输出是该过程向前推进一步的结果。
- **信息通过"回声"传递**：一个区域的图案在另一个位置以变形或部分衰减的方式出现，衰减模式本身编码了目标信息。

- `description`：根据封闭区域内被困住的颜色，为该区域的围墙染上对应颜色。

- `Input structure`：
  - 背景为 black。
  - 网格中散布着若干由 grey 像素组成的不规则封闭围墙（围墙宽度为1像素，4-连通封闭，即从围墙内部无法沿上下左右四个方向穿越围墙到达网格边缘）。
  - 每个封闭围墙内部恰好包含一个单像素的彩色标记（颜色各不相同，可能为 red、blue、green、yellow、magenta 等）。
  - 网格中还可能存在未封闭的 grey 线段（即其围成的区域可以经 black 像素连通到网格边缘），这些线段内部也可能有彩色像素。

- `Rule`：
  - 识别所有由 grey 像素围成的4-连通封闭区域（即从区域内部任一 black 像素出发，沿上下左右走，无法不经过 grey 像素就到达网格边界的区域）。
  - 对于每个封闭区域，找到其内部唯一的彩色标记像素的颜色 C。
  - 将构成该封闭区域围墙的所有 grey 像素重新染为颜色 C。
  - 区域内部的彩色标记像素保持不变。
  - 未封闭的 grey 线段保持 grey 不变；未封闭区域内的彩色像素也保持不变。

- `Key insight`：解题者必须区分"封闭"和"未封闭"的 grey 结构——只有真正围成密闭区域的围墙才会被重新染色，而判断封闭性需要进行连通性分析（从内部能否走到边界）。未封闭结构是干扰项。
</new_puzzle>

<new_puzzle>
- `description`：将每个彩色对象沿其自身最长轴方向"投影"到最近的同色边界线上，在路径上留下逐渐稀疏的痕迹。

- `Input structure`：
  - 背景为 black。
  - 网格的四条边界各有一条单像素宽的纯色边框线，四条边颜色各不相同（例如上边为 red，右边为 blue，下边为 green，左边为 yellow）。
  - 网格内部散布若干小型单色4-连通对象（每个对象的颜色恰好与某一条边框线颜色相同）。
  - 每个对象至少占据2个像素，形状不对称，因此可以明确区分其"最长轴"方向（水平或垂直）。

- `Rule`：
  - 对每个内部对象，确定其颜色 C 并找到与之同色的边框线所在的方向 D（上/下/左/右）。
  - 确定该对象的最长轴方向。如果最长轴方向与朝向同色边框的方向一致（即对象需要沿其长轴投影才能到达同色边框），则进行投影。
  - 投影方式：从对象朝向同色边框的每个边缘像素出发，沿方向 D 逐像素延伸至边框。延伸路径上的像素按以下规则间隔绘制：距对象距离为奇数的像素染为 C，距离为偶数的像素保持 black，形成虚线效果。
  - 如果对象的最长轴方向与朝向同色边框的方向不一致（即垂直关系），则该对象不做任何变换，原样保留。
  - 边框线和所有对象本身保持不变。

- `Key insight`：解题者需要同时发现两个隐含规则——颜色与边框的匹配确定投影方向，而对象自身最长轴与该方向的一致性决定是否真正执行投影。仅颜色匹配不够，还需要几何轴向的"确认"。
</new_puzzle>

- `description`：网格中每个"房间"内的小标记编码了一个旋转指令，按指令旋转房间内的主体图案。

- `Input structure`：
  - 背景为 black。
  - Azure 色的单像素宽十字线将网格均匀分割为 N×M 个大小相同的矩形房间（N、M 至少为2）。
  - 每个房间内包含一个由某种颜色（非 black、非 azure）绘制的主体图案（可以是任意小形状，占据房间内部分像素）。
  - 每个房间的四个角落位置（即房间内部的左上、右上、左下、右下四个角像素）中，恰好有一个角落像素被染为 red。其余三个角落为 black。

- `Rule`：
  - red 角落标记编码旋转量：左上角 = 不旋转（0度），右上角 = 顺时针旋转90度，右下角 = 旋转180度，左下角 = 逆时针旋转90度（即顺时针270度）。
  - 对每个房间，根据其 red 标记位置确定旋转量，然后将该房间内的主体图案（不含 red 标记和 azure 分割线）绕房间中心旋转相应角度。
  - 旋转后的图案放回房间原位。red 标记本身在输出中被清除为 black。
  - Azure 分割线保持不变。

- `Key insight`：解题者需要发现每个房间角落里不起眼的 red 单像素并非图案的一部分，而是一个旋转控制信号；进一步需要推断出角落位置与旋转角度之间的映射关系（左上=0°、右上=90°、右下=180°、左下=270°）。
</new_puzzle>

<new_puzzle>
- `description`：根据两个对象之间的空间排列关系（上下/左右/对角），选择对应的合并模式将它们叠合到一起。

- `Input structure`：
  - 背景为 black。
  - 网格中恰好有两个大小相同的矩形区域，每个区域内部有一个不同颜色的图案（例如一个 red 图案、一个 blue 图案），它们的外接矩形尺寸完全相同（W×H）。
  - 两个区域不重叠，它们在网格中的相对位置属于以下之一：水平并排（左右关系）、垂直排列（上下关系）、或对角排列。

- `Rule`：
  - 输出是一个 W×H 大小的网格（即与每个区域的外接矩形大小一致）。
  - 将两个区域各自裁剪为其 W×H 外接矩形。
  - 根据两个区域的空间排列关系决定合并方式：
    - 若两区域呈**左右关系**（中心点纵坐标接近、横坐标不同）：将左侧区域的图案**水平翻转**后，与右侧区域的图案逐像素叠合。叠合规则：若某像素在两个图案中都非 black，则输出 green；若只有一个非 black，保留该颜色；若都是 black，则输出 black。
    - 若两区域呈**上下关系**（中心点横坐标接近、纵坐标不同）：将上方区域的图案**垂直翻转**后叠合，叠合规则相同。
    - 若两区域呈**对角关系**（中心点横纵坐标都有显著偏移）：将左上方/右上方的区域图案**旋转180度**后叠合，叠合规则相同。
  - 重叠像素统一变为 green，体现两个图案的"交集"。

- `Key insight`：解题者需要首先识别两个区域的空间排列关系（不是通过颜色或标记，而是通过它们在网格中的相对位置），然后推断出不同排列对应不同的翻转/旋转预处理方式。输出中的 green 像素揭示了两个经过空间变换后的图案的重叠部分。
</new_puzzle>

- `description`：每条彩色"蛇"沿自身身体方向继续生长，生长长度等于该蛇当前身体中颜色突变的次数。

- `Input structure`：
  - 背景为 black。
  - 网格中有若干条"蛇"——每条蛇是一个宽度为1像素的4-连通路径（不分叉、不成环），路径上的像素由两种颜色交替排列（例如 red 和 yellow 交替，或 blue 和 magenta 交替）。
  - 每条蛇的两个端点中，恰好有一个端点相邻的下一个背景像素所在方向是明确的延伸方向（即该端点只有一个相邻 black 像素沿蛇身方向的延长线上）。另一个端点可能靠近墙壁或其他蛇。
  - 蛇与蛇之间不相邻。

- `Rule`：
  - 对每条蛇，统计其身体上"颜色突变"的次数 T（即沿路径从一端走到另一端，相邻像素颜色不同的次数——例如 red-yellow-red-yellow 有3次突变）。
  - 从蛇的可生长端点开始，沿蛇身方向的延长线继续生长 T 个像素。
  - 新生长的像素继续蛇身原有的颜色交替模式（从端点颜色开始交替）。
  - 如果生长过程中遇到网格边界或其他非 black 像素，则提前停止。

- `Key insight`：解题者需要识别出蛇身上颜色交替产生的"突变次数"与生长长度之间的数值对应关系。每条蛇的突变次数不同（取决于蛇的长度和颜色分布），因此生长长度也各不相同。关键难点在于发现"突变次数"这个非直观的计数量恰好控制了延伸距离。
</new_puzzle>

- `description`：将散落的碎片按照它们内部"缺口"的形状拼入中央拼图框架的对应凸起位置。

- `Input structure`：
  - 背景为 black。
  - 网格中央有一个较大的 grey 矩形框架，框架的四条边上各有若干向外凸出的小突起（突起形状各不相同，每个突起由几个 grey 像素组成，从矩形边缘向外延伸）。
  - 网格四周散布着若干小型彩色碎片对象（每个碎片是一个4-连通的单色对象，颜色各不相同，可能是 red、blue、green、yellow 等）。
  - 每个碎片的形状是一个小矩形，但矩形的某一条边上有一个与框架某个凸起形状完全吻合的凹口（缺口）。
  - 碎片数量与凸起数量相同，且形状一一匹配。

- `Rule`：
  - 对每个框架凸起，找到其形状与某个碎片凹口完全互补的那个碎片。
  - 将该碎片平移（不旋转）到框架旁，使其凹口恰好卡住对应的凸起——即碎片的缺口像素与凸起像素完全重合对齐，碎片的实体部分紧贴在框架外侧。
  - 碎片就位后，凸起处重叠的像素显示为碎片的颜色（碎片颜色覆盖 grey）。
  - 框架本身其余部分保持 grey 不变。

- `Key insight`：解题者需要将每个碎片的"缺口形状"与框架的"凸起形状"进行互补匹配——这不是简单的颜色匹配或位置匹配，而是几何形状的阴阳互补。碎片不需要旋转，因此凹口的朝向也隐含了该碎片应该贴合在框架的哪一侧。
</new_puzzle>

<new_puzzle>
- `description`：网格中的每个彩色像素是一颗"种子"，根据其颜色确定的生长规则，在空白区域中生长出特定形状的结构，先种下的种子优先占据空间。

- `Input structure`：
  - 背景为 black。
  - 网格中散布着少量单像素的彩色种子点（可能的颜色有 red、blue、green、yellow），每种颜色至少出现一次。
  - 种子点之间有足够的空间。

- `Rule`：
  - 每种颜色对应一种生长形状模式：
    - Red：生长为菱形（曼哈顿距离 ≤ R 的所有像素），R 为该 red 种子到最近的其他任意种子的曼哈顿距离减1。
    - Blue：生长为正方形（切比雪夫距离 ≤ R 的所有像素），R 的定义相同。
    - Green：生长为十字形（与种子同行或同列、且距离 ≤ R 的像素），R 的定义相同。
    - Yellow：生长为 X 形（与种子在对角线上、且切比雪夫距离 ≤ R 的像素），R 的定义相同。
  - 所有种子同时开始生长。当多个种子的生长区域发生重叠时，距离种子更近的像素优先归属（按该颜色对应的距离度量）。若距离相同，则该像素保持 black（不归属任何种子）。
  - 生长不超出网格边界。

- `Key insight`：解题者需要发现颜色不仅决定了"领地"的染色，还决定了领地的形状模式（菱形/方形/十字/X形）。进一步需要发现每个种子的生长半径来自于"到最近邻种子的距离"，这构成了一种隐含的空间自适应机制。
</new_puzzle>

<new_puzzle>
- `description`：根据每个封闭管道的入口颜色和出口颜色，推断管道内流动方向，并用渐变色填充管道内部。

- `Input structure`：
  - 背景为 black。
  - 网格中有若干条由 grey 像素组成的宽度为1像素的管道路径（4-连通路径，不分叉）。
  - 每条管道的两个端点像素分别被染为两种不同颜色（例如一端为 red，另一端为 blue）。这两个端点颜色确定了管道的"流动方向"：从暖色端（颜色序定义：red > orange > yellow > green > blue > magenta，值大为暖）流向冷色端。
  - 管道之间不相邻。

- `Rule`：
  - 对每条管道，确定暖色端（起点）和冷色端（终点）。
  - 沿管道路径从起点到终点逐像素编号（起点为第0个，终点为第 L 个，L为管道中间grey段的长度加1）。
  - 将管道路径上的中间 grey 像素按如下方式重新染色：前半段（距起点更近的一半）染为起点颜色，后半段（距终点更近的一半）染为终点颜色。若管道中间像素数为奇数，则正中间那个像素染为 green。
  - 起点和终点像素颜色保持不变。

- `Key insight`：解题者需要发现管道两端颜色的"温度"（暖/冷）关系决定了填充方向，而不是简单地从左到右或从上到下。填充的本质是将管道内部一分为二（或一分为三），根据流动方向从源色过渡到目标色。
</new_puzzle>
