# 第一步：分析与思考

## 参考题中的基础操作梳理

参考题涵盖了以下核心操作族：
- **空间变换**：平移、旋转、镜像、滑动（如题1排序堆叠、题6位移、题11角落顺时针复制、题20滑动到对边）
- **形状匹配与填充**：模板-空腔配对、互补形状嵌入（如题12互补匹配、题15矩形空腔拼图、题19投影对齐）
- **排序与重排**：按距离、面积、遮挡层级排列（如题1边线距离排序、题2面积排序、题5遮挡层拓扑排序）
- **信息编码与解码**：颜色图例、数量-颜色映射、坐标系编码（如题7位置图例、题14长度-颜色映射、题17对角标记-填充图例）
- **路径与传播**：蛇形路径展开、射线填充、三角生长（如题8蛇形展开、题4周期射线、题9交替三角生长）
- **物理模拟**：重力下落、碰撞停止（如题13管道下落）

## 非显而易见的串联方式

1. **拓扑信息决定几何操作**：题5中遮挡关系（拓扑排序）决定绘制顺序（几何操作）。这种"关系推断→操作参数"的链条可以拓展——比如连通性决定颜色、邻接关系决定变换方向。

2. **形状本身作为指令**：题19中bar的投影形状作为"钥匙"编码对齐信息。进一步想象：对象的轮廓、缺口、凸起本身可以编码数字、方向或操作类型。

3. **双重角色对象**：题6中灰色路径既是视觉装饰，又编码了位移矢量——但解题者必须忽略路径弯折、只看端点。类似地，某些对象可以同时是"装饰"和"指令"。

4. **全局约束从局部线索推断**：题4中射线方向由边界像素密度决定——这是一个全局属性由分散的局部线索汇聚而来。

5. **负空间作为信息载体**：题12中左侧模板的"缺失部分"定义了匹配目标。空洞、间隙、缺口可以是核心信息源。

## 更深层的创新方向

- **对象之间的对话**：两个对象通过某种共享属性（如周长相等、颜色互补、面积之比为整数）建立映射关系，这种关系本身决定变换。
- **网格的元结构**：将网格本身视为某种编码媒介——行列交叉处的颜色可以解读为矩阵运算的结果、布尔运算的输出等。
- **时间序列压缩在空间中**：网格从左到右或从上到下编码了某个过程的多个时间步，输出是最终状态或某个中间状态。
- **自指规则**：变换规则的参数隐藏在输入网格中某个不起眼的位置，解题者必须先"找到说明书"再执行操作。

<new_puzzle>
- `description`：根据每个封闭区域内部的孤立像素数量，用对应数量的同心收缩环填充该区域。

- `Input structure`：
  - 背景色为 Black。
  - 网格中有若干由 Grey 像素围成的封闭区域（形状不规则但保证封闭，区域之间不重叠）。
  - 每个封闭区域内部散布着若干孤立的 Red 像素（即与其他 Red 像素不4-连通的单独红点）。
  - 这些 Red 像素的数量在1到4之间。
  - 封闭区域内部除 Red 像素外全部是 Black 背景。

- `Rule`：
  - 保留所有 Grey 边界不变。
  - 对每个封闭区域，统计其内部孤立 Red 像素的数量 N。
  - 清除该区域内所有 Red 像素（变为 Black）。
  - 从 Grey 边界向内逐层收缩（每层收缩1个像素），依次用 Blue、Green、Yellow、Orange 四种颜色交替填充前 N 层（第1层 Blue，第2层 Green，第3层 Yellow，第4层 Orange）。内部剩余区域保持 Black。
  - 若区域太小以至于收缩不到 N 层，则填满为止。

- `Key insight`：封闭区域内看似随意散布的红点实际上是"计数器"，它们的数量决定了该区域被同心环填充的层数。解题者需要意识到红点的空间位置无关紧要，只有数量有意义。
</new_puzzle>

<new_puzzle>
- `description`：将网格中的彩色箭头沿其指向方向发射，箭头飞越的轨迹用箭头颜色填充，直到碰到另一个对象或网格边界后停止，并在停止处"印章"出箭头的镜像副本。

- `Input structure`：
  - 背景色为 Black。
  - 网格中散布着若干由非背景色绘制的小型箭头。每个箭头占据一个 3×3 的区域，绘制方式如下：
    - 朝右箭头：中间行三格全部填色，上行第三列填色，下行第三列填色（即 ">" 形）。
    - 朝左箭头：中间行三格全部填色，上行第一列填色，下行第一列填色（即 "<" 形）。
    - 朝上箭头：中间列三格全部填色，第一行左列填色，第一行右列填色（即 "^" 形）。
    - 朝下箭头：中间列三格全部填色，第三行左列填色，第三行右列填色（即 "v" 形）。
  - 每个箭头使用一种颜色（可以是 Red、Blue、Green、Yellow、Magenta 中的任意一种），不同箭头颜色可以不同也可以相同。

- `Rule`：
  - 保留所有原始箭头不变。
  - 每个箭头沿其指向方向发射一条射线（宽度为1像素，沿箭头尖端所在列或行的中心线延伸）。
  - 射线颜色与箭头颜色相同。
  - 射线遇到另一个箭头的任何像素或网格边界时停止（不覆盖已有非背景像素）。
  - 在射线终点处（射线最后一个像素的外侧），绘制原箭头关于射线方向的镜像翻转副本。即朝右箭头在终点处变为朝左箭头，朝上箭头变为朝下箭头，以此类推。镜像副本颜色与原箭头相同。
  - 若终点处空间不足以放置完整的3×3镜像副本（被边界截断或与其他对象重叠），则只绘制不冲突的部分像素。

- `Key insight`：箭头既是发射源也是障碍物。解题者需要同时理解箭头的方向语义（决定射线方向）和箭头作为实体的阻挡作用（停止其他箭头的射线）。射线终点处的镜像副本是容易遗漏的细节——它不是简单的复制，而是关于运动方向的翻转。
</new_puzzle>

<new_puzzle>
- `description`：将网格视为一张"选票统计表"，每行代表一个候选色，每列代表一个投票区；根据每列中各色的像素数量多寡在输出的底部绘制"获胜色柱状图"。

- `Input structure`：
  - 网格尺寸约 15×15 到 25×25。
  - 背景色为 Black。
  - 网格被 Grey 竖线均匀分割为若干等宽的列区域（每个列区域宽度相同，至少3列像素宽）。Grey 竖线宽度为1像素。
  - 每个列区域内散布着若干彩色像素（可能出现 Red、Blue、Green、Yellow 四种颜色），位置随机但每种颜色的像素数量不同（同一列区域内无并列）。
  - 网格最底部预留若干行全为 Black 的空行（至少与列区域数相同行数）。

- `Rule`：
  - 保留上方所有内容不变（Grey 分隔线和彩色像素）。
  - 对每个列区域，统计其中每种颜色的像素数量，找出数量最多的颜色作为该区域的"获胜色"。
  - 在底部空行区域中，为每个列区域绘制一个填充柱：柱的颜色为该区域的获胜色，柱的宽度等于列区域的宽度（不含Grey分隔线），柱的高度等于获胜色在该区域中的像素数量。
  - 所有柱从底部边界向上生长，底边对齐网格最下沿。

- `Key insight`：上方区域看似杂乱的彩色像素其实是"选票"，Grey 竖线划分了"投票区"。解题者需要意识到每列区域内颜色像素的数量才是关键信息，而非它们的位置或形状。底部柱状图的高度和颜色完全由计数决定。
</new_puzzle>

<new_puzzle>
- `description`：网格中的每个彩色连通块是一块"拼图碎片"，将所有碎片按照边缘锯齿的互锁关系滑动拼合成一个无缝矩形。

- `Input structure`：
  - 背景色为 Black。
  - 网格中有若干彩色的4-连通块（每块使用不同颜色，可用颜色包括 Red、Blue、Green、Yellow、Magenta、Orange），这些连通块之间互不接触，由 Black 背景分隔。
  - 每个连通块的外形都是矩形加上若干凸出的1像素"齿"和对应的凹入的1像素"槽"。具体来说：每块有一个基础矩形体，某些边上凸出1×1的齿（该像素属于此块），对边上对应位置凹入1×1的槽（该像素缺失）。
  - 所有碎片拼合后恰好构成一个无缝的完整矩形（无重叠、无间隙）。
  - 碎片在输入中的位置是打散的（平移到网格的不同位置），但不旋转。

- `Rule`：
  - 找到所有碎片块。
  - 通过边缘齿-槽的互锁匹配关系，确定每对相邻碎片的拼接方式：一块的凸齿恰好嵌入另一块同位置的凹槽。
  - 将所有碎片平移到正确位置，拼合成完整矩形。
  - 输出网格仅包含拼合后的矩形（裁剪掉多余的背景），每个像素保留其所属碎片的颜色。

- `Key insight`：碎片的边缘凸凹模式是唯一的拼接线索。解题者不能依靠颜色顺序或位置排列——必须检查每对碎片的边缘轮廓是否互补锁合。这类似物理拼图中的锯齿配合，但编码在离散像素网格上。
</new_puzzle>

<new_puzzle>
- `description`：网格中有若干"时钟"图案，每个时钟显示一个"时间"；输出中将每个时钟的指针拨转到下一个整点位置。

- `Input structure`：
  - 背景色为 Black。
  - 网格中有若干独立的"时钟"图案，彼此不重叠。每个时钟由以下部分组成：
    - 一个 5×5 的 Grey 像素圆环（即 5×5 正方形去掉四个角和中心后剩余的12个边缘像素）。
    - 中心1个像素为 Maroon（表盘中心）。
    - 从中心向外延伸的一条"指针"：由1个 Red 像素组成，位于中心的上、下、左、右四个正交邻居之一（即指针只指向12点、3点、6点、9点四个方向之一）。
    - 指针指向上方（中心正上方1格）= 12点，指向右方 = 3点，指向下方 = 6点，指向左方 = 9点。
  - 时钟之间至少间隔1个像素的 Black 背景。

- `Rule`：
  - 保留所有 Grey 圆环和 Maroon 中心不变。
  - 将每个时钟的 Red 指针顺时针旋转90度到下一个位置：
    - 12点 → 3点（上→右）
    - 3点 → 6点（右→下）
    - 6点 → 9点（下→左）
    - 9点 → 12点（左→上）
  - 即：清除原指针位置的 Red 像素（恢复为 Black），在顺时针方向的下一个正交邻居位置绘制 Red 像素。

- `Key insight`：解题者需要首先识别出5×5的圆环结构是"表盘"，中心旁的红色像素是"指针"，然后理解变换规则是顺时针旋转一格（90度）。难点在于从视觉上把这些像素组合解读为"时钟"隐喻，而非简单的几何变换——一旦建立了这个隐喻，规则就很直观。
</new_puzzle>

<new_puzzle>
- `description`：根据每个彩色区域边界上的"缺口"位置和朝向，从缺口处向外溢出洪水填充，用该区域的颜色淹没外部背景直到遇到其他区域或网格边界。

- `Input structure`：
  - 背景色为 Black。
  - 网格中有若干由不同颜色填充的实心矩形区域（每个矩形使用一种独特的颜色，可用 Red、Blue、Green、Yellow、Orange、Magenta）。
  - 每个矩形的边界上恰好有一个1像素宽的"缺口"——即矩形边缘的某一个像素被替换为 Black，使得矩形内部通过这个缺口与外部 Black 背景连通。
  - 各矩形之间由 Black 背景分隔，互不接触。

- `Rule`：
  - 对每个有缺口的矩形，从缺口位置开始，向外部进行洪水填充（flood fill），将与缺口4-连通的所有外部 Black 像素替换为该矩形的颜色。
  - 洪水填充在遇到非 Black 像素（其他矩形的边界或填充）或网格边界时停止。
  - 所有矩形的洪水填充同时进行：如果两个矩形的洪水区域争夺同一个 Black 像素，则使用曼哈顿距离更近的那个矩形的颜色（距离从各自缺口计算）。若距离相同，则保持 Black 不变。
  - 原始矩形（包括缺口处的 Black 像素）保持不变——缺口仍为 Black。

- `Key insight`：每个矩形几乎封闭但留有一个微小缺口，这个缺口既是视觉上容易忽略的瑕疵，也是决定洪水方向的唯一出口。解题者需要精确定位每个矩形上的缺口位置，然后理解颜色从缺口"泄漏"并扩散到外部空间。多个矩形的洪水区域可能竞争，此时距离裁决规则是额外的隐蔽细节。
</new_puzzle>

<new_puzzle>
- `description`：网格中有一条由 Grey 像素标出的路径和若干彩色"旅客"像素，每个旅客沿路径行走其颜色编码的步数后停下，输出显示所有旅客的最终位置。

- `Input structure`：
  - 背景色为 Black。
  - 网格中有一条由 Grey 像素组成的单像素宽4-连通路径（无分支，有且仅有两个端点）。路径可以弯曲转折。
  - 路径上某些 Grey 像素被替换为彩色像素（旅客），使用以下颜色之一：Red、Blue、Green、Yellow、Orange。
  - 颜色编码步数：Red = 1步，Blue = 2步，Green = 3步，Yellow = 4步，Orange = 5步。
  - 路径的一个端点用 Maroon 像素标记（表示路径方向的起点）；另一个端点为普通 Grey。

- `Rule`：
  - 确定路径方向：从 Maroon 端点出发，沿路径行进到另一个端点为正方向。
  - 每个彩色旅客沿正方向移动其颜色对应的步数（沿路径上的 Grey/彩色像素逐格前进）。
  - 旅客移动后，其原位置恢复为 Grey。
  - 若旅客移动过程中到达路径终点（非 Maroon 端点）仍有剩余步数，则停在终点不再移动。
  - 若多个旅客移动后落在同一位置，颜色叠加规则：取步数较大的旅客的颜色（即保留移动距离更远的那个旅客的颜色）。
  - Maroon 端点标记在输出中保持不变。

- `Key insight`：路径上的彩色像素不是静态标记——它们是"旅客"，颜色隐含了移动距离。解题者必须：(1) 识别出 Maroon 端点标定了路径方向；(2) 发现颜色与步数的对应关系（需要从多个样例中通过对比推断出映射表）；(3) 沿弯曲路径正确计步。颜色-步数映射是最核心也最隐蔽的规则。
</new_puzzle>
