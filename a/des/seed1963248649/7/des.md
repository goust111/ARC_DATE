# 第一步：分析与思考

## 参考题中的基础操作类别

1. **空间重定位**：将对象从一处移动到另一处（参考14将对象从下括号移到上括号；参考7将对角线段向前推进；参考8将边带移到对面）。
2. **计数-编码转换**：用数量信息决定几何尺寸或重复次数（参考1用像素计数决定矩形尺寸；参考9用对象计数决定条形长度；参考19用连通分量数决定重复次数）。
3. **模板-模板交互**：一个图案作为模具作用于另一个图案（参考17将图案作为镂空模版打入实心块；参考11用周围块推断中心块）。
4. **条件分支与筛选**：根据某种属性（颜色频率、位置关系）做二选一或多选一（参考2根据顶行重复颜色选取角落裁剪；参考9根据标记颜色筛选对象）。
5. **方向线索解读**：网格中某个结构编码了方向信息，驱动后续操作（参考3的实心边线编码方向；参考18的T形标记的柄指向目标区域；参考5的十字臂尖端决定螺旋起始方向）。
6. **区域填充与膨胀**：通过扩展或填充改变区域属性（参考16将稀疏点的bbox扩展并填充配对色；参考20通过膨胀交集找到中间通道；参考10用右邻色填充带状区域的空隙）。
7. **修复与归一化**：将不规则形状归一化为标准形式（参考15将任意前景形状重塑为居中水平线段；参考3将嵌入的标记修复为主体颜色）。

## 非显而易见的串联方式与信息编码思考

- **拓扑属性作为隐性指令**：一个区域的孔洞数、连通分量数、周长等拓扑量可以编码操作参数（而非显式的数值标注），迫使解题者发现"形状的拓扑特征就是指令"。
- **对称性破缺作为选择机制**：当网格中存在近似对称但有微小差异时，差异点本身编码了变换方向或目标选择。解题者需要先感知对称性的存在，再定位破缺处。
- **负空间携带信息**：对象之间的空隙形状、背景被分割出的区域本身包含规则所需的关键信息，而非对象本身。
- **时序推演式思维**：输入可以表示一个动态过程的某个中间快照，输出是下一步或最终稳态，解题者需要推断底层的演化规律。
- **颜色作为相对排序而非绝对标签**：颜色的语义不由颜色本身决定，而由其在网格中的空间分布特征（如面积排名、位置排序）动态赋予含义。
- **路径的端点连接关系**：多条视觉上相似的路径混杂在一起，其身份只能通过追踪端点的连接对象来区分——考验的是"连通性追踪"能力。
- **距离值作为参数**：一个标记到某个参照物的距离本身就是后续操作的参数值（如缺口宽度、重复次数），这需要解题者将空间距离理解为"被编码的数字"。

<new_puzzle>
- `description`：利用每个封闭轮廓内部被隔墙分割出的隔间数量，在调色板中索引出对应颜色来填充该轮廓的内部。
- `Input structure`：
  - 背景色为 black。
  - 网格中有若干个由 green 像素绘制的封闭轮廓形状（4-连通闭合曲线，宽度 1 像素），彼此不接触、不重叠。
  - 每个封闭轮廓内部可能有 green 的内部隔墙（与轮廓同色的像素，将内部空间分割成多个独立的 black 区域）。无隔墙时内部是一个连续的 black 区域；有隔墙时内部被分割成 2、3 或 4 个独立的 4-连通 black 区域（称为"隔间"）。
  - 网格中另有一个独立的"调色板条"：位于网格的一条边缘附近，由一行或一列相邻的 4 个不同颜色的色块组成（如 blue、red、yellow、maroon，每个色块为 1x1 像素），从左到右（或从上到下）排列。调色板条与所有轮廓形状不接触。

- `Rule`：
  - 对每个封闭轮廓形状，统计其内部独立的 4-连通 black 区域（隔间）的数量 N。N 的范围为 1 到 4。
  - 用调色板条中第 N 个颜色（从左/上开始、以 1 开始索引）填充该轮廓内部的所有 black 隔间像素。
  - 轮廓本身的 green 像素（包括外轮廓和内隔墙）保持不变。
  - 调色板条保持不变。
  - 轮廓外部的 black 背景保持不变。

- `Key insight`：解题者需要意识到每个轮廓内部的空间被隔墙分成了不同数量的隔间，而隔间数量才是选择填充颜色的索引。并非轮廓的大小、位置或外形决定颜色，而是内部的拓扑分区数量。这要求解题者仔细观察轮廓内部的结构差异，而非轮廓外部的属性。
</new_puzzle>

<new_puzzle>
- `description`：在一个近似对称的图案中找到唯一的对称破缺像素，修复对称性，并从该位置向四个正交方向发射射线直到碰到前景像素或网格边缘。
- `Input structure`：
  - 背景色为 black。
  - 网格中有一个由 azure 像素组成的大型图案（约 15-40 个像素），该图案关于其边界框中心呈近似 180 度旋转对称（中心对称）。
  - 图案中恰好有一个像素位置打破了中心对称：要么该位置应有 azure 像素却为 black（"缺失型"），要么该位置应为 black 却有 azure 像素（"多余型"）。可以通过将每个像素与其关于 bbox 中心的对称位置进行对比来找到该破缺点。
  - 网格中另有一个孤立的 red 单像素标记，位于图案外部的 black 背景上，不与图案 4-连通相邻。

- `Rule`：
  - 确定 azure 图案的边界框中心 (Cr, Cc)。
  - 对图案 bbox 内每个像素 (r, c)，检查它与对称点 (2*Cr - r, 2*Cc - c) 的颜色是否一致。找到唯一不一致的像素对，确定破缺点 P。
  - 修复对称性：如果 P 处为 black 但其对称点为 azure，则将 P 设为 azure；如果 P 处为 azure 但其对称点为 black，则将 P 设为 black。
  - 从 P 的位置出发，向上、下、左、右四个方向逐像素绘制 red 射线，每条射线延伸到碰到 azure 像素或网格边界为止（不覆盖 azure 像素，射线仅在 black 像素上绘制）。
  - 移除原始的 red 标记像素（将其位置恢复为 black）。

- `Key insight`：解题者必须先识别出图案具有中心对称性，再通过逐像素对比找到唯一的对称违反点。red 标记只提示了射线的颜色，并不指示破缺点的位置——位置信息完全来自对称性分析。规则的隐蔽性在于：解题者首先要"看到"对称性的存在，然后才能定位破缺。
</new_puzzle>

<new_puzzle>
- `description`：根据每个彩色条形的方向标记，将其向指定方向投射到网格边界，在边界上绘制与条形等长的垂直段或水平段。
- `Input structure`：
  - 背景色为 black。
  - 网格中有若干个互不接触的短条形对象（每个条形为同一颜色的像素组成的 1 像素宽、2-5 像素长的水平线段或垂直线段）。每个条形的颜色各不相同，颜色选自 red、green、yellow、orange、azure 等。
  - 每个条形的一端（沿长轴方向的某一端外侧）紧贴着一个 maroon 单像素标记。即该 maroon 像素与条形端头像素 4-连通相邻，且位于条形长轴的延长线上。

- `Rule`：
  - 对每个条形，maroon 标记标注了条形的"尾端"，条形从尾端指向另一端的方向即为"发射方向"。
  - 从条形的非标记端（"头端"）出发，沿发射方向画一条直线，延伸到网格边界。
  - 在射线到达的网格边界位置处，沿边界方向（即垂直于射线方向）绘制一段与条形颜色相同、长度相同的线段。该边界线段以射线到达的边界像素为中心展开。例如：水平条形向右发射，则射线到达右边界某行时，在右边界最后一列上以该行为中心绘制一段垂直线段，长度等于原条形长度。若线段长度为偶数，则中心偏上（或偏左）。
  - 移除所有 maroon 标记像素（恢复为 black）。
  - 原始条形对象保持不变。
  - 射线路径上不绘制任何内容（射线本身不可见）。

- `Key insight`：解题者需要发现 maroon 标记并非装饰或无关噪声，而是方向指示器——它标注了条形的"尾端"，从而定义了投影方向。进一步需要理解：条形的长度信息被"旋转 90 度"搬运到了目标边界上（水平条形在边界上产生垂直段，反之亦然）。
</new_puzzle>

<new_puzzle>
- `description`：多条同色路径密集交织在网格中，通过追踪每条路径两个端点各自相邻的彩色标记来确定该路径应被重新着色的颜色。
- `Input structure`：
  - 背景色为 black。
  - 网格中有 3-6 条由 grey 像素绘制的路径。每条路径是 1 像素宽的 4-连通像素链（无分支），路径之间不 4-连通相邻，但在网格中相互交错穿梭、间距很小（可能仅 1 像素间隔），视觉上难以直接分辨每条路径的走向。
  - 每条路径恰好有两个端点（度为 1 的像素，即仅有一个 4-连通的 grey 邻居）。
  - 每个端点恰好有一个彩色单像素标记与之 4-连通相邻（标记颜色非 black、非 grey）。每条路径两端的标记颜色相同。不同路径可以共享相同的标记颜色，也可以颜色各异。

- `Rule`：
  - 对每条 grey 路径，从一个端点出发沿 4-连通追踪到另一个端点，确定该路径所属的两个标记。
  - 将该路径上所有 grey 像素重新着色为其端点标记的颜色。
  - 保留所有彩色标记像素不变。
  - 背景保持 black。

- `Key insight`：所有路径初始都是同一种 grey 色，无法靠颜色区分。解题者必须通过 4-连通追踪来分离不同路径，然后根据端点标记确定每条路径的新颜色。关键困难在于路径在网格中密集纠缠（虽然不直接相连，但间距极小），需要仔细追踪连通性。解题者从样例中需要归纳的核心规律是"端点的标记颜色决定整条路径的颜色"。
</new_puzzle>

<new_puzzle>
- `description`：每个矩形房间内有一个偏心放置的彩色标记，标记到最近墙壁的距离决定了在那面墙上打开的缺口宽度。
- `Input structure`：
  - 背景色为 black。
  - 网格中有若干个由 blue 像素绘制的空心矩形"房间"（矩形边框，墙壁厚度恒为 1 像素，内部为 black），房间彼此不接触、不重叠。每个房间至少 5x5（含墙壁），最大不超过 12x12。
  - 每个房间内部恰好有一个非 black、非 blue 的彩色单像素标记。标记不在房间内部的正中心，而是偏向某一面墙。标记的颜色在不同房间可以不同，但颜色本身对规则无影响。

- `Rule`：
  - 对每个房间，计算内部标记到四面内壁的距离（上内壁 = 标记行 - 房间顶部墙行 - 1；下内壁 = 房间底部墙行 - 标记行 - 1；左内壁 = 标记列 - 房间左墙列 - 1；右内壁 = 房间右墙列 - 标记列 - 1）。
  - 找到距离最小的那面墙。若有并列，按优先级选择：上 > 左 > 下 > 右。
  - 在最近的那面墙上打开缺口：将墙壁上的部分 blue 像素改为 black。缺口位置以标记在该墙方向上的正交投影为中心。缺口宽度（沿墙壁方向的像素数）等于标记到该墙的距离值。
  - 缺口居中规则：设缺口宽度为 W，标记投影到墙上的坐标为 P。缺口覆盖从 P - floor(W/2) 到 P - floor(W/2) + W - 1 的范围（即偏左或偏上对齐）。若缺口范围超出墙壁端点则截断到墙壁范围内。
  - 标记本身保持不变。

- `Key insight`：解题者需要发现两个相互关联的隐蔽规则：（1）标记的偏心方向决定了哪面墙被打开——标记靠近哪面墙就开哪面墙；（2）标记到该墙的距离编码了缺口的宽度——越近则缺口越窄，越远则缺口越宽。标记的颜色是干扰项，真正的信息完全来自标记的空间位置。解题者很可能先注意到颜色差异而走弯路，需要转换思路去关注位置关系。
</new_puzzle>

<new_puzzle>
- `description`：网格中若干对同色像素之间的曼哈顿距离决定了连接它们的线段使用什么颜色，依据一个隐含的距离-颜色映射表。
- `Input structure`：
  - 背景色为 black。
  - 网格中散布着若干个彩色像素点，这些像素点使用 2-4 种不同的前景色，每种颜色恰好出现 2 个像素（即形成 2-4 对配对）。
  - 网格的最底部一行（或最右侧一列）是一个"颜色图例行"：包含若干个不同颜色的单像素，从左到右（或从上到下）排列，颜色各不相同，且与上方配对像素的颜色都不同。图例行中的像素数量等于配对数。

- `Rule`：
  - 对每一对同色像素，计算它们之间的曼哈顿距离。
  - 将所有配对按曼哈顿距离从小到大排序。
  - 图例行中的颜色从左到右（或从上到下）分别对应距离从小到大的配对。
  - 对每一对同色像素，用其对应的图例颜色绘制连接线：从一个像素到另一个像素，先水平移动再垂直移动（L 形路径），沿途所有 black 像素都着图例色。若路径上遇到已有前景色像素则跳过该像素不覆盖。
  - 保留原始配对像素和图例行不变。

- `Key insight`：解题者需要发现三层逻辑的嵌套：（1）同色像素自然配对；（2）每对的曼哈顿距离建立了一个排序；（3）图例行中颜色的位置顺序与距离排序一一对应，从而确定连接线的颜色。仅看单个样例很难确定图例颜色的分配规则，必须对比多个样例中距离与颜色分配的关系才能发现"距离排名决定图例索引"这一规律。
</new_puzzle>

<new_puzzle>
- `description`：将网格中每个"箭头"形状指向的方向上第一个遇到的目标对象染成箭头的颜色，箭头本身消失。
- `Input structure`：
  - 背景色为 black。
  - 网格中有若干个小型"箭头"形状，每个箭头由同一颜色的 5 个像素组成：一个 1x3 的水平或垂直杆，加上杆一端中心像素两侧各延伸 1 像素形成的箭镞（形成 T 字或倒 T 字、左 T 或右 T 的形状），箭头方向为杆从箭镞端指向无箭镞端的方向。例如：向右的箭头由第 r 行 c 列的竖直 3 像素（(r-1,c), (r,c), (r+1,c)）加上 (r, c+1) 和 (r, c+2) 两个像素组成——箭镞在左，杆向右延伸，指向右方。每个箭头颜色各不相同。
  - 网格中还有若干个 grey 的小型矩形块（2x2 或 3x3 的实心 grey 方块），作为"目标对象"。

- `Rule`：
  - 对每个箭头，确定其指向方向（上/下/左/右）。
  - 从箭头杆的末端（非箭镞端）出发，沿指向方向逐像素扫描，找到射线路径上第一个碰到的 grey 目标对象（射线碰到目标对象的任意一个像素即视为命中该对象）。
  - 将该目标对象的所有 grey 像素重新着色为箭头的颜色。
  - 每个目标对象最多被一个箭头命中（题目保证不会有两个箭头指向同一个目标）。
  - 擦除箭头本身（将其 5 个像素恢复为 black）。
  - 未被任何箭头命中的目标对象保持 grey 不变。

- `Key insight`：解题者需要先识别出 5 像素的 T 形结构是"箭头"，然后判断箭头的朝向（箭镞的宽端是尾部，窄杆的末端是头部，指向从尾到头）。核心困难在于正确解读 T 形的方向性——这不是对称的形状，T 的横杠是尾部而非头部，这与某些直觉相反。
</new_puzzle>
