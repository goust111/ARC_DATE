<description>
根据颜色围栏内部的种子像素形状，选择匹配的外部模板并将其缩放填充到围栏内部。

Input structure:
- bg = 最常见颜色。网格中散布着若干由单一颜色构成的矩形围栏（空心矩形框），每个围栏内部为背景色，但包含一个由另一种颜色绘制的小型连通形状（称为"种子"）。
- 围栏外部散布着若干独立的小型单色连通图案（称为"模板"），每个模板的颜色各不相同。
- 每个模板的形状在经过某种旋转或翻转后，与某个围栏内的种子形状完全一致（像素级匹配）。

Rule:
- 对每个围栏，找到其内部的种子形状，然后在所有外部模板中寻找形状匹配的模板（允许旋转和翻转）。
- 确定匹配后，将种子形状从围栏内部移除（恢复为背景色）。
- 将匹配到的模板图案按比例放大，使其恰好填满围栏内部区域（即模板的包围盒等比缩放到围栏内部尺寸），放大后的图案使用模板自身的颜色绘制。
- 外部的模板保持不变。

Key insight: 种子形状是模板的微缩版本，起到"选择键"的作用——解题者需要先通过形状匹配（含旋转/翻转）将种子与模板配对，再将模板放大填入围栏，而非简单地复制种子本身。
</description>

<description>
沿彩色管道网络传递染料，管道交叉处按优先级规则决定输出颜色，最终为每段管道末端的容器着色。

Input structure:
- bg = 最常见颜色。网格中有若干由 grey 像素构成的单像素宽管道，管道沿水平或垂直方向延伸，在交叉点处形成十字或T字连接。
- 管道的某些末端（死端）连接着一个 2x2 的 grey 方块，称为"容器"。
- 管道的另一些末端连接着一个 2x2 的彩色方块（非 grey、非背景色），称为"染料源"，其颜色即为该源注入管道的染料颜色。
- 每个管道交叉点的中心像素被标记为 maroon 色，表示该处是"混合节点"。

Rule:
- 每个染料源沿其连接的管道方向注入染料，染料沿管道传播直到到达容器或混合节点。
- 在混合节点处，来自不同方向的染料汇合。混合节点有且仅有两条输入管道和一条或两条输出管道。输出管道的染料颜色取决于两条输入染料的颜色：按照固定的视觉深浅优先级排序（Red > Blue > Green > Yellow > Orange），优先级较高的颜色覆盖较低的颜色，输出该较高优先级的颜色。
- 染料继续沿输出管道传播，直到到达下一个混合节点或容器。
- 最终，每个容器被填充为到达它的染料颜色。管道本身（grey 像素）保持不变，混合节点的 maroon 标记也保持不变。

Key insight: 解题者需要首先识别管道网络的拓扑结构和流向（从染料源到容器），然后在每个混合节点处应用颜色优先级覆盖规则——这要求追踪多条路径并在交汇处做出正确的颜色判断，而非简单的单路径传播。
</description>

<description>
识别网格中嵌套矩形边框的层级关系，将最内层图案沿每层边框缺口所指方向逐层向外复制并平移。

Input structure:
- bg = 最常见颜色。网格中包含若干嵌套的空心矩形边框，每个边框由单一颜色绘制，不同层的边框颜色不同。
- 边框严格嵌套：最外层边框包含一个较小的边框，该较小边框又包含更小的边框，以此类推，形成 2-4 层嵌套。
- 每个边框的四条边中恰好有一条边存在一个 1 像素宽的缺口（即该边上有一个像素被背景色替代）。
- 最内层边框内部包含一个小型彩色填充图案（连通区域），其颜色与所有边框颜色均不同。

Rule:
- 从最内层开始，将内部图案复制到当前边框与外一层边框之间的环形区域中。
- 复制时，图案的放置位置相对于其原始位置发生平移：平移方向由当前层边框的缺口所在边决定（缺口在上边则向上平移，缺口在右边则向右平移，以此类推），平移距离等于当前层边框与外层边框之间的间距。
- 对每一层重复此操作：将上一步产生的图案（已含平移）再次按当前层缺口方向平移到下一环形区域中。
- 最内层的原始图案保持不变。

Key insight: 解题者需要发现三层结构——首先识别嵌套边框的层级关系，然后发现每层边框上的缺口编码了平移方向，最后理解图案是从内向外逐层累积平移的。缺口作为方向编码器的角色是关键的隐蔽洞见。
</description>
</new_puzzle>

<new_puzzle>
<description>
将网格中散落的彩色碎片按照隐含的拼图边界线重新归位，边界线由网格边缘上的彩色标记暗示。

Input structure:
- bg = 最常见颜色。网格被划分为若干不规则区域，但区域边界本身不可见（边界像素为背景色）。
- 每个区域内部原本应包含一个完整的单色填充，但每个区域中有一块矩形子区域的像素被"交换"到了另一个区域的对应位置，形成错位。具体而言：恰好有若干对区域发生了矩形块互换，每对中两个矩形块大小相同。
- 网格边缘（最外一圈像素）上绘制有若干段不连续的彩色路径（每段由一种非背景色的像素组成），这些路径片段描画出了隐含区域边界的局部轮廓。

Rule:
- 首先，利用边缘路径片段推断出完整的区域边界线（边界线将网格分割为若干连通区域）。边界线沿水平或垂直方向延伸，边缘路径片段是边界线与网格边缘的交点处的标记。
- 在每个区域内部，识别颜色异常的矩形块——该块的颜色与区域主体颜色不同。
- 找到颜色匹配的配对：区域 A 中异常块的颜色等于区域 B 的主体颜色，且区域 B 中异常块的颜色等于区域 A 的主体颜色，且两个异常块大小相同。
- 将每对异常块交换回各自的正确区域（即将它们的像素互换），使每个区域恢复为纯色填充。
- 边缘路径标记在输出中被移除（恢复为背景色）。

Key insight: 解题者需要先从边缘的零散路径片段推断出不可见的区域划分（第一层推理），然后在每个区域中识别出"入侵"的异色矩形并找到其配对区域（第二层推理），最后执行交换还原。边界推断和颜色配对是两个独立的非平凡推理步骤。
</description>
</new_puzzle>

<new_puzzle>
<description>
根据网格中锚点像素的空间排列推断出隐含的周期铺贴单元，然后用该单元铺满遮罩框内部区域。

Input structure:
- bg = 最常见颜色。网格中散布着若干种不同颜色的单像素点（称为"锚点"），每种颜色的锚点恰好出现 2-4 次。
- 网格中还存在一个由 grey 像素绘制的封闭轮廓（空心多边形，仅由水平和垂直线段组成），称为"遮罩框"。
- 遮罩框内部为背景色（待填充区域）。

Rule:
- 对于每种颜色的锚点，观察同色锚点之间的空间间距。所有颜色的锚点共享相同的两个基本平移间距（水平周期 dx 和垂直周期 dy），这两个间距定义了一个铺贴晶格。
- 以所有锚点的位置为约束，推断出一个 dx × dy 大小的铺贴单元（tile）。在该 tile 中，每个锚点颜色占据其在 tile 内的相对位置，其余位置为背景色。
- 用该 tile 周期性地铺满整个网格。
- 输出仅保留遮罩框内部区域的铺贴结果；遮罩框本身及框外区域全部设为背景色。输出网格大小与输入相同。

Key insight: 解题者必须先从散落锚点的空间分布中发现隐含的周期性铺贴结构（通过观察同色点之间的间距推断平移周期），然后构建铺贴单元，最后将遮罩框理解为裁剪窗口而非变换对象。周期性的发现是核心的隐蔽洞见，因为锚点看起来是随机散布的。
</description>
</new_puzzle>
