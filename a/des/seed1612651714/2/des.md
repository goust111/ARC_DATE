根据封闭区域内部种子像素的颜色，从区域外部的颜色图例中查找对应的填充图案，将该图案平铺填满整个封闭区域。

Input structure:
- bg = black。网格中有若干由灰色（Grey）像素围成的封闭区域，每个区域内部恰好有一个单独的彩色"种子"像素（非黑、非灰）。
- 网格的最底部几行是"图例区"，由一条完整的灰色水平分隔线与上方隔开。图例区包含若干小型矩形图案样本，每个样本由 2x2 或 3x3 的多色像素块组成，样本之间用黑色间隔。每个样本的左上角像素颜色各不相同，作为该样本的"索引色"。

Rule:
- 对于上方每个封闭区域，读取其内部种子像素的颜色。
- 在图例区中找到索引色与该种子颜色匹配的图案样本。
- 将该图案样本以平铺方式（从区域包围盒的左上角开始重复铺设）填满封闭区域内所有黑色像素，种子像素本身也被图案覆盖。
- 灰色边界和图例区保持不变。

Key insight: 种子像素不是填充色本身，而是指向图例区中一个多色图案的查找键；解题者需要先建立"种子色 → 图案"的映射，再执行空间平铺。
</description>

<description>
将散落的彩色碎片按照颜色匹配嵌入到框架对象的同色边框缺口中，碎片从缺口方向滑入并停靠在框架内壁。

Input structure:
- bg = black。网格中有一个较大的矩形"框架"对象，框架由单一颜色（如 Azure）的像素构成，形成一个空心矩形环，但环的四条边上各有若干缺口（连续缺失的像素段）。
- 每个缺口处的框架边上紧邻缺口两端各有一个彩色标记像素（非框架色、非黑色），同一缺口两端标记颜色相同。
- 框架外部散布着若干小型彩色碎片（连通块），每个碎片的颜色与某个缺口的标记颜色相同。碎片的宽度（若缺口在水平边上）或高度（若缺口在垂直边上）恰好等于对应缺口的长度。

Rule:
- 对每个缺口，根据标记颜色找到框架外部颜色匹配的碎片。
- 确定缺口所在的边（上/下/左/右），碎片沿垂直于该边的方向从外侧滑入框架内部。
- 碎片滑入后停靠位置：碎片沿滑入方向移动，直到碎片的任意像素将要碰到框架对面内壁（即框架对侧边的像素）时停止，碎片最终贴靠在对面内壁上。
- 碎片原始位置变为黑色，缺口处保持缺失（不补回框架色）。缺口两端的彩色标记像素保留。

Key insight: 缺口两端的同色标记是碎片与缺口的配对线索；碎片不是填充缺口本身，而是穿过缺口滑入框架内部并停靠在对面墙壁上，需要同时推断配对关系和滑入停靠逻辑。
</description>

<description>
网格中多个有色区域各自拥有独立的旋转对称性；找到每个区域内破坏该旋转对称的噪声像素，将噪声像素的颜色替换为该区域的主色以恢复对称，然后将所有被修正的噪声像素收集起来，按照它们在各自区域内的相对位置，重新绘制在网格右下角的一个独立小区域中。

Input structure:
- bg = black。网格中有若干不重叠的彩色矩形区域，每个区域由一种主色填充并包含一个具有 180 度旋转对称性的图案（由第二种颜色绘制）。
- 每个区域中有 1-3 个"噪声"像素：它们是第三种颜色，放置在破坏 180 度旋转对称性的位置上（即该像素关于区域中心的对称位置处不存在同色像素）。
- 网格右下角有一个与所有区域不重叠的空白（黑色）矩形区域，由细的 Maroon 色边框围起来，内部为黑色。

Rule:
- 第一层：对每个彩色区域，找出其 180 度旋转对称中心（区域包围盒的几何中心），识别出破坏对称性的噪声像素——即那些在旋转 180 度后没有同色对应像素的第三色像素。
- 第二层：在每个区域内，将噪声像素替换为该区域的主色（恢复旋转对称）。同时记录每个噪声像素在其所属区域包围盒内的相对坐标（行, 列）。
- 第三层：将所有噪声像素按它们各自的第三色颜色，绘制到右下角 Maroon 边框内的小区域中。绘制位置为：噪声像素在原区域包围盒内的相对坐标直接映射到小区域内的相同相对坐标处。

Key insight: 解题需要三层独立推理——先识别每个区域的旋转对称并找出噪声（第一层），然后修复原区域（第二层），最后将噪声信息提取并汇总到独立的收集区（第三层）。旋转对称的判断和噪声的空间映射是两个不同的非平凡推理步骤。
</description>

<description>
根据网格中"信号线"的拓扑连接关系，将线路两端的源图案通过逻辑"与"运算合成到线路中间的空白画布上。

Input structure:
- bg = black。网格中有若干条由 Grey 像素组成的单像素宽折线路径（"信号线"），每条信号线连接两个端点。
- 每条信号线的两个端点处各有一个相同尺寸的小型 NxN 矩形区域（"源图案"），源图案内部由某种非灰非黑的颜色绘制图案（部分像素为该色，其余为黑色），两端源图案颜色不同。
- 每条信号线的中间位置有一个 NxN 的空白矩形区域（全黑），由单像素宽的 Orange 边框标记（"画布"）。
- 信号线从源图案边缘出发，经过若干转折到达画布边缘，再继续到达另一端的源图案。

Rule:
- 对每条信号线，识别其两端的源图案 A 和 B（各为 NxN 二值图案，有色像素为 1，黑色为 0）。
- 对 A 和 B 执行逐像素"与"操作：只有当 A 和 B 在同一位置都有非黑像素时，画布中对应位置才绘制像素。
- 画布中绘制的像素颜色为：取两个源图案中颜色排序靠后的那个颜色（按 Red < Green < Yellow < Blue < Magenta < Azure 的固定顺序，取较大者）。
- 源图案和信号线保持不变，仅画布内部被填充。

Key insight: 信号线定义了哪两个源图案需要合成（拓扑配对），而合成操作是空间上的逐像素"与"——只有两个图案重叠的部分才会出现在画布上。颜色选择规则需要从多个样例中归纳固定的颜色优先级顺序。
</description>

<description>
网格中的彩色箭头指向相邻的图案块，箭头颜色决定对图案块施加何种几何变换，多箭头时按距离顺序复合变换。

Input structure:
- bg = black。网格中有若干个大小相同的 NxN 图案块（N 通常为 4 或 5），每个图案块由多种颜色的像素构成不同图案，图案块之间有至少 2 像素的黑色间隔。
- 部分图案块的某一侧（上/下/左/右）紧邻一个由 3 个像素组成的箭头标记。箭头的绘制方式为：一个像素作为箭头尖端，紧邻箭头尖端的后方（远离图案块的方向）有两个像素并排作为箭尾，形成一个指向图案块的三角形箭头。箭头整体为单一颜色。
- 没有箭头的图案块保持不变。一个图案块可能有多个箭头从不同方向指向它。

Rule:
- 每种箭头颜色对应一种固定的几何变换（需从样例中归纳）：
  - Red 箭头 = 水平翻转（左右镜像）
  - Green 箭头 = 垂直翻转（上下镜像）
  - Blue 箭头 = 顺时针旋转 90 度
  - Yellow 箭头 = 逆时针旋转 90 度
- 如果一个图案块被多个箭头指向，按箭头距离图案块的远近顺序依次施加变换（最近的箭头先施加，结果再被下一个箭头变换）。若距离相同，按顺时针方向（从上方开始：上→右→下→左）的顺序施加。
- 箭头标记在输出中被擦除（变为黑色），图案块被变换后的结果覆写。

Key insight: 解题者需要两层推理：第一层是从多个样例中归纳出每种颜色对应的几何变换类型（颜色-变换映射），第二层是在多箭头情况下推断变换的复合顺序规则。箭头颜色不直接描述变换的视觉含义，必须通过对比输入输出来反推映射关系。
</description>

<description>
网格被分为左右两半，左半部分包含一组带有彩色标签的"模板行"，右半部分包含一个由黑色和灰色像素组成的"编织指令图"；根据指令图中每个像素的灰/黑状态选择对应行的模板，逐行编织出输出图案。

Input structure:
- bg = black。网格由一条垂直的 Maroon 分隔线分为左右两部分。
- 左半部分：包含若干条水平的彩色条纹（"模板行"），每条条纹高 1 像素，由多种颜色组成不同的水平图案。每条条纹的最左端有一个标签像素，标签颜色在该条纹中仅出现一次（用于标识该条纹）。条纹之间用黑色行间隔。
- 右半部分：一个矩形区域，仅由两种颜色组成——Grey 和 black，形成一个二值矩阵（"编织指令图"）。指令图的行数等于输出的总行数，列数等于左半部分条纹的数量。

Rule:
- 指令图的每一列对应左半部分的一条模板条纹（按从上到下的顺序一一对应）。
- 对于指令图的每一行，检查该行中哪一列是 Grey 像素（每行恰好有一个 Grey 像素），该列对应的模板条纹即为输出中该行的图案。
- 输出网格的宽度等于模板条纹的长度（不含标签像素），高度等于指令图的行数。
- 输出逐行构建：第 i 行取指令图第 i 行中 Grey 像素所在列对应的模板条纹内容（去除标签像素后的部分）。

Key insight: 解题者需要先理解左右两部分的角色分工（模板库 vs. 选择指令），再建立指令图的列与模板条纹的对应关系，最后理解 Grey 像素作为"行选择器"的编织逻辑。这是一个"数据与控制分离"的编程式推理结构。
</description>

<description>
网格中散布着多个同色的小型"钥匙"图形和多个同色的"锁"图形，每把钥匙通过形状互补匹配一个锁；将钥匙旋转到能与锁咬合的方向后，沿锁的开口方向平移嵌入锁中，钥匙与锁重叠的区域变为第三种颜色。

Input structure:
- bg = black。网格中有若干个由 Blue 像素组成的小型连通块（"钥匙"），以及若干个由 Red 像素组成的较大连通块（"锁"）。
- 每个锁是一个近似矩形的形状，但有一侧带有一个缺口（凹进去的区域）。缺口的形状各不相同。
- 每把钥匙是一个小型连通块，其形状经过 0/90/180/270 度旋转后恰好能与某个锁的缺口形状完全互补（即钥匙能精确填满缺口）。
- 钥匙和锁的数量相同（一一配对）。

Rule:
- 对每个锁，找到其缺口的形状和朝向（缺口开口朝上/下/左/右）。
- 在所有钥匙中找到形状互补的那一把（可能需要旋转钥匙 0/90/180/270 度才能匹配）。
- 将匹配的钥匙从缺口开口方向平移，直到钥匙完全嵌入缺口中（钥匙的像素填满锁的缺口区域）。
- 嵌入后，钥匙与锁接触的像素变为 Green 色（表示咬合区域）。具体来说，钥匙填入缺口后，钥匙像素中与锁的 Red 像素四方向相邻的那些像素变为 Green，其余钥匙像素保持 Blue。
- 钥匙的原始位置变为黑色。

Key insight: 解题需要三步非平凡推理：首先通过形状互补性在钥匙和锁之间建立配对（形状匹配含旋转），然后确定正确的旋转角度和平移方向（由缺口朝向决定），最后理解咬合区域的变色规则（仅与锁体相邻的钥匙像素变色）。
</description>
</new_puzzle>
