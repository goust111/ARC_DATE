<description>
根据封闭区域内部的种子颜色确定该区域的"主人"，再按主人颜色对区域边框进行接力式重绘。

Input structure:
- bg = black。网格中有若干由 grey 线条绘制的封闭矩形区域，区域之间可能共享边框线段。
- 每个封闭区域内部恰好有一个单像素种子点，颜色各不相同（如 red、blue、green、yellow 等）。
- 部分矩形区域之间存在共享边框段（即两区域紧邻，中间只有一条 grey 线）。

Rule:
- 第一步：每个封闭区域"认领"其内部种子点的颜色，称为该区域的主人颜色。
- 第二步：对每段边框线段判断归属——若该线段仅属于一个区域的边界，则将其重绘为该区域的主人颜色；若该线段是两个区域的共享边框，则将其重绘为这两个区域的主人颜色中、在可用颜色列表（按 red、blue、green、yellow、orange、magenta 固定顺序）中排位更靠前的那个颜色。
- 第三步：移除所有种子点（恢复为 bg）。
- 输出网格中只保留重绘后的彩色边框线条和黑色背景。

Key insight: 共享边框的归属需要先识别相邻区域各自的种子颜色，再通过一个固定的颜色优先级来决定共享段的颜色——解题者必须同时发现"种子→区域归属"和"颜色优先级裁决共享边"两层规则。
</description>
</new_puzzle>

<description>
在网格中找到散落的碎片精灵，将它们沿各自指示箭头方向滑动并拼合到目标框架的对应槽位中，拼合后根据碎片重叠层数改变颜色。

Input structure:
- bg = black。网格右侧有一个由 grey 线条绘制的矩形框架，框架内部有若干形状各异的 bg 色槽位（孔洞）。
- 网格左侧散落着若干彩色碎片精灵（每个精灵由单一颜色的连通像素组成）。
- 每个碎片精灵的正旁边（上下左右之一）有一个 maroon 单像素箭头标记，标记相对于碎片质心的方位指示了该碎片的滑动方向（标记在碎片右侧→碎片向右滑动，标记在碎片上方→碎片向上滑动，以此类推）。

Rule:
- 每个碎片沿其箭头标记指示的方向平移，直到碎片的形状与框架中某个槽位完全吻合（形状匹配，无需旋转或翻转）。
- 碎片填入槽位后，若某个像素位置只被一个碎片覆盖，该像素保持碎片原色。
- 若某个像素位置被两个碎片覆盖（槽位形状允许部分重叠），该像素变为 yellow。
- 箭头标记在输出中被移除。框架线条保持 grey 不变。

Key insight: 解题者需先从箭头标记的相对位置推断滑动方向（非箭头形状，而是标记与碎片的空间关系），再识别形状匹配确定目标槽位，最后发现重叠像素的颜色合并规则——三层独立推理。
</description>

<new_puzzle>
<description>
网格中有若干彩色"源环"和"靶环"，根据环的缺口朝向将源环内部图案"投射"到对应靶环内部。

Input structure:
- bg = black。网格中散布若干 3×3 的正方形环（环由 8 个像素组成，中心 1 像素为 bg 或包含图案色）。
- 每个环恰好有一个缺口（环的 8 个边框像素中恰好 1 个为 bg），缺口可位于上、下、左、右四个正方位之一（即顶边中央、底边中央、左边中央、右边中央）。
- 环分为两类：源环——环的边框颜色为某种颜色 C，且中心像素为另一种非 bg 颜色 P（图案色）；靶环——环的边框颜色为某种颜色 C（与某个源环相同），但中心像素为 bg。
- 同一边框颜色 C 恰好有一个源环和一个或多个靶环。

Rule:
- 将每个源环与所有同色靶环配对。
- 从源环中心取图案色 P。
- 将靶环的中心像素填充为 P。
- 在每个配对靶环中，从缺口位置向环外部延伸一条射线（沿缺口朝向），射线长度由源环缺口方向与靶环缺口方向之间的顺时针旋转步数决定：同向（0 步 90° 旋转）→长度 1，顺时针差 1 步→长度 2，差 2 步（即对向）→长度 3，差 3 步→长度 4。射线颜色为 P。
- 源环保持不变。

Key insight: 解题者需要发现三层规则——(1) 同色环配对，(2) 源环中心色决定射线颜色，(3) 源与靶的缺口方向差异（顺时针旋转步数）决定射线长度。缺口方向差异是一个需要主动归纳的非显然规律。
</description>
</new_puzzle>

<description>
网格被分为上下两个面板：上面板包含若干带彩色标签的"模板条"，下面板是一块空画布。根据模板条的长度和标签颜色，在画布上生成嵌套的同心矩形环框。

Input structure:
- bg = black。一条水平 grey 分隔线将网格分为上下两个面板。
- 上面板中有若干水平彩色线段（模板条），每条线段由单一颜色组成，各线段颜色互不相同，线段之间不接触。每条线段左端紧贴一个 1 像素的标签像素，标签颜色与线段颜色不同，标签颜色为另一种非 bg 颜色。
- 下面板初始为全 bg。

Rule:
- 对上面板中的所有模板条，按线段长度从长到短排序。
- 最长的线段对应最外层矩形环框：在下面板中心绘制一个正方形环框，边长等于该线段长度，环框颜色为该线段左端标签的颜色。
- 第二长的线段对应第二层环框：在前一层内部绘制一个更小的同心正方形环框，边长等于该线段长度，颜色为该线段的标签颜色。
- 依次类推，每条线段产生一层环框，由外到内嵌套。
- 最短的线段对应最内层：绘制一个实心正方形（非空心环框），边长等于该线段长度，颜色为该线段标签颜色。
- 上面板在输出中保持不变。

Key insight: 解题者需要发现两层独立规则——(1) 线段长度决定嵌套顺序和环框边长（长→外，短→内），(2) 环框的颜色并非线段本身的颜色，而是线段左端标签像素的颜色。仅观察线段颜色会导致错误，必须注意到标签的存在。
</description>
</new_puzzle>

<description>
网格中有一个大型连通的彩色路径网络和若干散落的单色小图案，需要识别路径网络中每个"房间"（封闭区域）的形状，与外部小图案进行形状匹配，然后将匹配到的小图案的颜色沿该房间相邻的路径段向外扩散。

Input structure:
- bg = black。网格中有一个由 azure 像素组成的连通路径网络（线宽 1 像素），路径围成若干封闭的矩形"房间"（内部为 bg）。
- 路径网络之外的区域散布着若干小型彩色图案（每个图案由单一非 bg、非 azure 颜色组成），每个图案的形状各不相同。

Rule:
- 对每个房间，提取其内部 bg 区域的形状（即房间的宽×高矩形）。
- 在外部小图案中找到包围盒形状与房间内部形状完全一致的那个图案（允许 90° 旋转匹配）。
- 找到匹配图案后，取该图案的颜色 C。
- 将与该房间直接相邻的所有 azure 路径段（构成该房间四面墙壁的路径像素）重绘为颜色 C。
- 若某段路径同时是两个房间的墙壁，且两个房间匹配到不同颜色，则该段路径被重绘为在网格中位置更靠上（行号更小）的那个房间所匹配的颜色。
- 外部小图案在输出中被移除（恢复为 bg）。
- 不与任何房间相邻的路径像素保持 azure。

Key insight: 解题者需要依次发现：(1) 外部图案的包围盒形状与房间内部形状存在对应关系（形状匹配层）；(2) 匹配后图案的颜色决定了该房间墙壁路径的重绘颜色（颜色传递层）；(3) 共享墙壁的颜色冲突通过位置优先级裁决（tie-break 层，但这一层是从前两层推理自然延伸出的可验证规则）。
</description>

<description>
网格中有若干"印章"模板和一个带有彩色标记点的画布区域。每个标记点的颜色选择对应的印章模板，标记点在画布内的局部位置决定印章的旋转角度，最终在标记点处盖印旋转后的模板。

Input structure:
- bg = black。网格由一条垂直 grey 分隔线分为左右两部分。
- 左半部分被水平 grey 分隔线进一步切分为若干小格子，每个格子内有一个小型图案（印章模板），每个模板使用不同的单一颜色绘制。
- 右半部分是一块大画布（bg 背景），画布上散布着若干单像素彩色标记点。每个标记点的颜色与某个左侧印章模板的颜色一致。
- 画布在概念上被均匀划分为 2×2 的象限（以画布中心为分界）。

Rule:
- 每个标记点与同色印章模板配对。
- 标记点所在象限决定旋转角度：左上象限→0° 不旋转，右上象限→顺时针 90°，右下象限→顺时针 180°，左下象限→顺时针 270°。
- 将旋转后的印章模板以标记点为中心锚点盖印到画布上（模板的几何中心与标记点对齐）。
- 若同一颜色有多个标记点，每个标记点各自独立盖印。
- 左半部分（模板区域）在输出中保持不变。

Key insight: 解题者需发现两层非显然规则——(1) 标记点颜色是印章选择键（颜色匹配层）；(2) 标记点在画布中的象限位置编码了旋转角度（空间位置→旋转映射层）。第二层尤其隐蔽，因为解题者必须发现画布被隐式划分为四个象限，且每个象限对应不同的旋转量。
</description>

<new_puzzle>
<description>
网格中有若干由不同颜色绘制的"链条"（像素序列），每条链条的两个端点各连接一个彩色"锚点"像素。规则要求根据两个锚点的颜色关系来变换链条本身的形态。

Input structure:
- bg = black。网格中有若干链条，每条链条是由单一颜色（链体色）绘制的 4-连通像素路径（宽度 1 像素，无分支，仅两个端点）。
- 每条链条的两个端点各自正交相邻一个锚点像素，锚点颜色与链体色不同。一条链条的两个锚点颜色可以相同也可以不同。
- 不同链条之间互不接触，锚点也不共享。

Rule:
- 若一条链条的两个锚点颜色相同：将链条收缩为一条直线——保留两个端点，将它们之间的链体像素重新排列为连接两端点的最短正交路径（先水平再垂直的 L 形路径），多余像素移除（恢复为 bg）。
- 若一条链条的两个锚点颜色不同：将链条扩展为填充矩形——以链条两个端点为对角顶点，绘制一个实心矩形，颜色为链体色。
- 锚点像素在输出中保持不变。

Key insight: 解题者需要发现控制变换模式的关键信号是两个锚点颜色是否相同（同色→收缩为直线，异色→扩展为矩形）。这一规则在表面上并不明显，因为链条本身的形态各异，解题者容易被链条形状分散注意力，而真正的决定因素是端点锚点的颜色关系。
</description>
</new_puzzle>
