<description>
根据嵌套框架的层级深度对内部标记像素执行螺旋方向的颜色传播。

Input structure:
- 背景色网格上有若干由同一颜色绘制的嵌套矩形框架（框架之间不共享边），形成从外到内的层级结构。
- 每层框架的内部恰好有一个非背景、非框架色的标记像素，标记像素颜色各不相同。

Rule:
- 计算每个标记像素所在的嵌套深度（最外层框架内部为深度1，次内层为深度2，依此类推）。
- 奇数深度的标记像素沿顺时针螺旋方向，在其所在框架内壁与下一层框架外壁之间的环形区域内填充该标记颜色；偶数深度则沿逆时针螺旋方向填充。
- 螺旋从标记像素位置起始，沿对应方向逐圈填充背景像素，遇到框架边界或已填充像素则转向，直到环形区域内所有背景像素被覆盖。
- 最内层框架内部若有标记，则直接填满该框架内部所有背景像素。

Key insight:
嵌套深度的奇偶性决定了螺旋填充的旋转方向；标记像素既标识颜色又标识起始点，而框架边界自然约束了填充范围。
</description>
</new_puzzle>

<description>
将散布的单色碎片按照轮廓互补性拼合到唯一的缺口模板中，并依据拼入位置的象限确定碎片的重着色。

Input structure:
- 背景色网格中有一个较大的单色矩形区域，其中挖去了若干不规则的连通缺口（缺口为背景色）。
- 网格其他位置散布着若干小型单色连通碎片，每个碎片的形状恰好与模板中某个缺口在平移下完全吻合。
- 模板的四个象限（以模板中心为界）各用一种不同的分隔色在模板边缘做了单像素标记。

Rule:
- 将每个碎片平移至其唯一匹配的缺口位置。
- 确定该缺口中心落在模板的哪个象限，将碎片重着色为该象限对应的边缘标记颜色。
- 输出中，模板保留原色，碎片以新颜色填入缺口，边缘标记像素保留。

Key insight:
碎片与缺口的形状匹配确定位置，但最终颜色不由碎片原色决定，而由目标位置在模板中的象限归属决定——解题者必须同时完成几何匹配和空间分区推理。
</description>

<new_puzzle index="3">
<description>
沿网格线折叠透明层，将多层标记像素叠加合成最终颜色。

Input structure:
- 正方形网格被一条水平或垂直的单色折线均分为两半。
- 两半各包含若干散布的彩色标记像素（颜色不超过四种），其余为背景色。
- 折线颜色在网格中仅出现于该线。

Rule:
- 沿折线将网格对折（水平线则上下对折，垂直线则左右对折），使两半重叠。
- 输出为对折后的半幅网格。
- 重叠位置若仅一侧有标记，保留该标记颜色。
- 若两侧均有标记且颜色相同，保留该颜色。
- 若两侧均有标记但颜色不同，输出为网格中出现的第三种非背景、非折线颜色（即"混合色"，保证唯一存在）。

Key insight:
折叠操作将空间压缩，双层冲突时的颜色合成规则需要解题者识别"混合色"这一隐含角色——它从未直接参与折叠的任何一侧，却是冲突解决的唯一输出。
</description>
</new_puzzle>

<new_puzzle index="4">
<description>
根据种子像素的局部邻域密度选择不同的元胞自动机规则，演化一步后输出。

Input structure:
- 背景色网格上散布着两种前景色的像素：一种为"活跃色"，一种为"休眠色"。
- 活跃色像素数量远多于休眠色。
- 无重叠，所有前景像素均为孤立像素或小型簇。

Rule:
- 对每个背景像素，计算其 Moore 邻域（8邻居）中活跃色像素的数量 A 和休眠色像素的数量 D。
- 若 A >= 2 且 D == 0，该像素变为活跃色。
- 若 D >= 1 且 A >= 1，该像素变为休眠色。
- 若 A == 0 且 D >= 2，该像素变为活跃色（休眠色"唤醒"周围区域）。
- 其余情况保持背景色。
- 原有的活跃色和休眠色像素保持不变。

Key insight:
两种前景色各自触发不同的生长规则，且它们的共存邻域产生第三种行为——解题者必须从样例中分离出三条独立的邻域条件判断规则。
</description>
</new_puzzle>

<description>
将环形轨道上的彩色令牌按照轨道中心指示器的箭头方向旋转指定步数。

Input structure:
- 背景色网格中有一个由单一颜色绘制的封闭环形轨道（宽度为1像素的矩形环路）。
- 轨道上散布着若干彩色令牌像素（每个令牌颜色不同，均非背景色和轨道色）。
- 环形轨道围成的内部区域中央有一个由非对称形状构成的方向指示器，其朝向（上/下/左/右）编码旋转方向。
- 内部区域中还有 N 个小型标记点（同一颜色），N 编码旋转步数。

Rule:
- 确定方向指示器的朝向：上或右为顺时针，下或左为逆时针。
- 计算内部标记点的数量 N 作为步数。
- 将轨道上所有令牌沿轨道路径按指定方向移动 N 步（轨道像素间按 Manhattan 邻接顺序遍历）。
- 轨道本身和指示器保持不变，令牌出现在新位置。

Key insight:
解题者需要同时解码两个独立信息源：指示器的几何形状编码方向，内部标记点的数量编码步数；然后在一维环路上执行循环位移。
</description>
</new_puzzle>

<new_puzzle index="6">
<description>
识别网格中隐藏的数字乘法表关系，将不符合乘法表规律的单元格修正为正确颜色。

Input structure:
- 网格被均匀的单色格线划分为 R 行 C 列的单元格阵列。
- 第 0 行和第 0 列的单元格各填充不同的纯色，充当行/列表头。
- 内部单元格 (i,j) 的颜色应等于"第 i 行表头色的索引 × 第 j 列表头色的索引"对颜色总数取模所对应的颜色。
- 少数内部单元格被故意填入了错误颜色。

Rule:
- 从第 0 行和第 0 列读取颜色序列，建立颜色到整数索引的映射（按出现顺序从 1 开始编号）。
- 对每个内部单元格，计算 (行索引 × 列索引) mod K（K 为不同颜色总数），找到对应的正确颜色。
- 将所有错误单元格修正为正确颜色，其余不变。

Key insight:
网格是一个伪装的模运算乘法表；解题者必须从表头建立颜色-数字映射，然后用乘法模运算验证每个单元格，而非简单地寻找视觉模式。
</description>
</new_puzzle>

<new_puzzle index="7">
<description>
沿每个彩色箭头的指向方向推动同行/列的目标块，直到碰撞停止。

Input structure:
- 背景色网格中有若干由三个同色像素组成的 L 形箭头（一个像素为箭杆，两个像素为箭头尖端，整体形状指示上/下/左/右方向）。
- 同一行或同一列上有一个或多个小型矩形目标块（另一种统一颜色）。
- 箭头颜色各不相同，目标块颜色统一。

Rule:
- 每个箭头推动其所在行（左/右箭头）或所在列（上/下箭头）中沿箭头方向最近的目标块。
- 目标块沿箭头方向滑动，直到碰到网格边缘或另一个已静止的目标块为止。
- 处理顺序：箭头按距其最近目标块的距离从小到大依次执行（距离相同则按行优先顺序）。
- 箭头本身在输出中被擦除（变为背景色）。

Key insight:
推动顺序至关重要——距离最近的箭头先执行，其推动结果可能阻挡后续箭头的目标块行程，形成连锁堆叠效应。
</description>
</new_puzzle>

<description>
根据桥梁像素的颜色在岛屿之间传播水位高度，将低于水位的背景区域填充为水色。

Input structure:
- 背景色网格中有若干互不相连的单色"岛屿"连通区域（均为同一种岛屿色）。
- 某些岛屿对之间由单像素宽的彩色"桥梁"线段连接（桥梁颜色各异）。
- 网格最左列或最右列上有一个特殊标记像素（水源标记），其颜色与所有桥梁颜色和岛屿色不同。

Rule:
- 水源标记所在的岛屿（或与之相邻的岛屿）水位为 0。
- 每座桥梁的颜色索引值（在调色板中的编号）表示该桥梁造成的水位落差。
- 从水源岛屿出发，沿桥梁传播：经过桥梁到达下一个岛屿时，水位增加该桥梁的颜色索引值。
- 对每个岛屿，将其下方（从岛屿底部边缘向下）水位值对应行数的背景像素填充为水色（水源标记的颜色）。
- 岛屿和桥梁像素保持不变。

Key insight:
桥梁颜色不是装饰而是编码了数值信息（水位落差）；解题者需要建立颜色到数字的映射，然后沿图结构传播累加值，最终转化为空间上的填充高度。
</description>
</new_puzzle>

<description>
将输入网格视为二维条形码，按行读取编码位并将解码结果渲染为像素字形。

Input structure:
- 网格高度固定，宽度为 N 的倍数。
- 每 N 列为一个编码组，组内每行包含一段由两种前景色交替排列的条纹。
- 一种前景色代表"1"，另一种代表"0"。
- 网格底部有一行用第三种颜色标记的校验行。

Rule:
- 对每个编码组，逐行读取"1"/"0"序列，得到一个二进制矩阵。
- 将该二进制矩阵解释为一个小型像素字形（"1"位置填前景色，"0"位置填背景色）。
- 输出网格将所有解码出的字形水平排列，字形之间用单列背景色分隔。
- 校验行被丢弃，不出现在输出中。

Key insight:
输入网格本身就是编码后的数据——每个编码组的空间排列直接映射为输出字形的像素矩阵，解题者必须识别出"行即位序列"的编码规则，而非将条纹视为装饰图案。
</description>

<description>
将多个重叠的半透明图层按深度顺序合成，根据遮挡关系推断各图层的完整形状并输出最底层。

Input structure:
- 背景色网格上可见若干颜色不同的矩形区域，部分区域相互重叠。
- 重叠处只显示最上层的颜色（完全遮挡）。
- 每种颜色的矩形恰好出现一个，且每个矩形至少有一个角完全可见（未被遮挡）。

Rule:
- 通过分析每种颜色的可见像素分布，推断每个矩形的完整边界框。
- 根据遮挡关系建立图层深度顺序：若颜色 A 的可见区域"切割"了颜色 B 的连续区域，则 A 在 B 之上。
- 输出仅包含最底层矩形的完整形状（用其颜色填充），其余区域为背景色。
- 输出网格裁剪为最底层矩形的边界框大小。

Key insight:
解题者需要从部分可见信息反向推断完整几何形状，并通过遮挡拓扑排序确定深度——最底层矩形的大部分区域可能被上层覆盖，必须从暴露的角点推断其完整范围。
</description>

<new_puzzle index="11">
<description>
根据围栏内外标记像素的数量差异，决定对围栏执行膨胀还是收缩操作。

Input structure:
- 背景色网格中有一个由单色像素构成的封闭围栏（宽度1像素的任意凸多边形轮廓，仅使用水平和垂直线段）。
- 围栏内部散布若干"内标记"像素（统一颜色 A），围栏外部散布若干"外标记"像素（统一颜色 B）。
- A 和 B 颜色不同，也不同于围栏色和背景色。

Rule:
- 计算内标记数量 Nin 和外标记数量 Nout。
- 若 Nin > Nout，围栏向外膨胀 (Nin - Nout) 个像素（围栏每条边向外平移该距离）。
- 若 Nout > Nin，围栏向内收缩 (Nout - Nin) 个像素。
- 若 Nin == Nout，围栏不变。
- 膨胀/收缩后的新围栏用原围栏色绘制，原围栏像素中不属于新围栏的部分变为背景色。
- 所有标记像素在输出中被擦除（变为背景色）。

Key insight:
标记像素不是装饰元素而是控制指令——它们的数量差编码了操作方向和幅度，解题者必须先计数再判断几何变换类型。
</description>
</new_puzzle>

<description>
将散落的线段碎片连接成一棵最小生成树，用碎片自身的颜色绘制连接路径。

Input structure:
- 背景色网格上有若干短小的单色水平或垂直线段（每段2-4像素长），颜色各不相同。
- 每条线段视为一个节点，节点位置为线段的中心像素。
- 线段之间无直接接触。

Rule:
- 以每条线段的中心像素为节点，计算所有节点对之间的 Manhattan 距离。
- 构建最小生成树（距离相同时选择节点行坐标更小的边，再按列坐标排序）。
- 对于生成树中的每条边，用该边两端节点中颜色索引较小的那个颜色，沿 Manhattan 路径（先水平后垂直）绘制连接线。
- 原有线段保留不变。

Key insight:
解题者需要识别出碎片是图的节点而非边，然后从空间距离重建最小生成树结构——连接路径的颜色选择规则增加了额外的推理维度。
</description>
</new_puzzle>
