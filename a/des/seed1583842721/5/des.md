<description>
根据框架内部的色块排列模式，选择匹配的外部碎片填入框架缺口，碎片需旋转至与缺口边缘花纹对齐。

Input structure:
- 背景色（bg）填充大部分网格。
- 网格中有一个大型矩形框架，由单一颜色绘制，框架宽度为一个像素。框架的四条边上各有一个连续缺口（缺口长度为2-4像素，即框架边上有2-4个连续像素被替换为bg）。
- 框架内部：在紧贴框架内壁的位置，每条边的缺口两侧各有1-2个彩色像素（非bg、非框架色），这些像素构成"边缘花纹"。
- 框架外部：散落着若干L形或直线形的小碎片（每个碎片由2-4个像素组成），每个碎片恰好有一种颜色。碎片的数量等于缺口数量。

Rule:
- 每个缺口的两侧边缘花纹形成一个独特的颜色对（按从缺口一端到另一端的顺序读取）。
- 每个外部碎片的颜色与某个缺口的某一侧边缘花纹颜色相同——找到碎片颜色同时出现在某缺口边缘花纹中的那个缺口，即为该碎片的目标缺口。
- 将碎片旋转（0°/90°/180°/270°），使其形状恰好嵌入缺口的空位（碎片的像素数等于缺口长度）。
- 旋转后的碎片平移到缺口位置，填补框架上的空缺。碎片保持自身颜色。
- 擦除碎片原始位置。

Key insight: 缺口两侧的边缘花纹颜色是配对密钥——它指定了哪个碎片属于哪个缺口；而碎片的几何形状与缺口的几何形状决定了唯一的旋转角度。两层推理缺一不可：颜色配对确定归属，形状匹配确定朝向。
</description>

<description>
将网格中散落的单色条带按照锚点行的颜色顺序，垂直堆叠到锚点所在列，堆叠时条带之间按照各自原始行距保持间隔。

Input structure:
- 背景色（bg）占据大部分网格。
- 网格底部有一行"锚点行"：该行包含若干不同颜色的单像素点，每个点占据不同的列，其余位置为bg。
- 网格其余区域散布着若干水平条带（每条宽1像素、长度不等），每条条带颜色单一，且与锚点行中的某个锚点颜色相同。同一颜色可能有多条条带。
- 每种锚点颜色对应的所有条带，它们的行号各不相同。

Rule:
- 对每个锚点颜色，收集所有同色条带。
- 将这些条带按原始行号从大到小排序（离锚点行最近的排第一）。
- 将排序后的第一条条带水平平移，使其左端对齐到锚点所在列，并垂直放置在锚点正上方一行。
- 后续每条条带同样左端对齐到锚点列，垂直放置时，与前一条条带之间的行间距等于它们在原始输入中的行间距。
- 擦除所有条带的原始位置。锚点行保持不变。

Key insight: 锚点行不仅指定了颜色归属和目标列位置，条带之间的原始垂直间距也被保留到输出中——解题者需要同时发现"按颜色归组并移动到锚点列"和"保持原始行间距"两个独立规律。
</description>

<description>
在网格中找到由边框围成的若干封闭房间，每个房间内有一个彩色种子像素；种子的颜色决定该房间墙壁的绘制规则——暖色种子使墙壁向内加厚一层，冷色种子使墙壁保持不变但房间内部填充种子色。

Input structure:
- 背景色（bg）填充网格。
- 一种中性色（grey）绘制墙壁，墙壁为一像素宽的线段，将网格分隔成若干互不相通的矩形封闭房间。
- 每个房间内部恰好有一个彩色种子像素（非bg、非grey）。种子颜色分为两组：暖色组（red、orange、yellow、maroon）和冷色组（blue、green、azure）。

Rule:
- 对每个房间，检查其种子像素的颜色类别：
  - 若种子为暖色：将该房间四周的grey墙壁向房间内部加厚一层（即墙壁内侧紧邻的一圈bg像素变为grey），种子像素保持不变。
  - 若种子为冷色：房间内所有bg像素填充为种子的颜色，墙壁不变，种子像素融入填充色中。
- 不属于任何房间的bg区域保持不变。

Key insight: 种子颜色不仅标识房间，还编码了两种截然不同的空间变换模式。解题者需要从样例中发现暖色/冷色的二分法，并分别归纳出"墙壁加厚"与"区域填充"这两套规则——单看一个样例中的单个房间无法区分这两种模式。
</description>

<description>
网格中的每个彩色箭头指向一个目标对象，将箭头的颜色"注入"到目标对象中，替换目标对象内部与箭头尾部标记色相同的像素。

Input structure:
- 背景色（bg）填充网格。
- 网格中有若干"箭头"：每个箭头由一条3像素长的直线段构成（水平或垂直），箭头的三个像素中，头部1个像素为一种颜色（称为"注入色"），中间1个像素也为注入色，尾部1个像素为另一种不同颜色（称为"标记色"）。箭头的方向为从尾部指向头部。
- 网格中另有若干较大的多色对象（4连通，面积>=4），这些对象由多种颜色组成，其中包含一些与某个箭头的标记色相同的像素。

Rule:
- 对每个箭头，沿其指向方向做射线延伸，找到射线首先命中的大型多色对象——该对象即为箭头的目标。
- 在目标对象内部，将所有与该箭头标记色相同的像素替换为该箭头的注入色。
- 擦除所有箭头（将箭头的3个像素恢复为bg）。
- 如果某个大型对象被多个箭头命中，则依次应用所有命中箭头的替换规则（各箭头的标记色互不相同，因此应用顺序不影响结果）。

Key insight: 箭头编码了两层信息——方向确定"替换谁"（射线命中），而箭头自身的双色结构确定"替换什么"和"替换成什么"（标记色->注入色）。解题者必须同时发现箭头的指向语义和颜色替换语义。
</description>

<description>
网格被分为左右两个面板；左面板中的多个小图案是右面板大图案的局部碎片，根据碎片在大图案中的相对位置（上半/下半/左半/右半），对碎片施加对应方向的镜像翻转后拼回大图案。

Input structure:
- 网格由一条垂直的分隔线（单一颜色，贯穿整个网格高度）分成左右两个面板。
- 右面板包含一个大型图案的"骨架"：用一种轮廓色绘制的连通形状，内部有若干矩形空腔（空腔内为bg）。
- 左面板包含若干小型彩色碎片（每个碎片是一个紧凑的矩形色块区域），碎片数量等于右面板骨架中的空腔数量。每个碎片的尺寸恰好等于某个空腔的尺寸。

Rule:
- 将每个左面板碎片与右面板中尺寸匹配的空腔配对（尺寸唯一匹配）。
- 确定每个空腔相对于骨架整体包围盒中心的位置：
  - 若空腔中心在骨架中心的上方，则碎片做上下镜像翻转。
  - 若空腔中心在骨架中心的下方，则碎片保持原样不翻转。
  - 若空腔中心在骨架中心的左侧，则碎片做左右镜像翻转。
  - 若空腔中心在骨架中心的右侧，则碎片保持原样不翻转。
  - 上下和左右翻转独立判定，可以叠加。
- 将翻转后的碎片填入对应空腔。
- 输出仅为右面板（不含分隔线和左面板）。

Key insight: 碎片-空腔的尺寸匹配是第一层推理（决定"哪块填哪里"），空腔相对于骨架中心的方位决定翻转方式是第二层推理（决定"怎么填"）。两层规则需要对比多个样例才能分别发现。
</description>

<description>
网格中有若干对形状相同但颜色不同的单色对象，每对之间画连线；连线颜色取自面积较大的对象，连线方向由两对象的相对位置决定，且连线在中点处断开一个像素的间隙，间隙像素染为面积较小对象的颜色。

Input structure:
- 背景色（bg）填充大部分网格。
- 网格中散布着偶数个小型单色对象（4连通，面积2-6像素），它们两两形状完全相同（允许旋转0°/90°/180°/270°后重合），但每对中两个对象颜色不同。
- 不同对的形状互不相同，保证配对唯一。
- 同一对的两个对象在水平或垂直方向上对齐（即包围盒中心在同一行或同一列），且中间路径上没有其他对象。

Rule:
- 通过形状匹配（允许旋转）找到所有配对。
- 对每一对，沿两个对象对齐的方向，在两者最近边缘之间画一条1像素宽的直线段，颜色为该对中面积（像素数）较大对象的颜色；若面积相同，则取行号或列号较小的对象的颜色。
- 找到该线段的中间像素（若线段长度为偶数，取靠近较小面积对象的那个中间像素），将该像素的颜色替换为面积较小对象的颜色。
- 原始对象保持不变。

Key insight: 解题者首先需要发现"形状配对"规则——这要求在心中旋转各对象进行几何比较，是一个非显然的归纳步骤。第二层是发现连线颜色由面积大小决定，且中点标记使用另一颜色。两层规则各自需要对比多个样例才能确认。

<description>
网格包含一个大型多色拼图和一个小型"调色板"区域；调色板中每行显示一个颜色对（旧色→新色），输出时仅将拼图边界层（与bg相邻的最外圈像素）中匹配旧色的像素替换为新色，内部像素不变。

Input structure:
- 背景色（bg）填充网格。
- 网格一角（如左下角）有一个小型矩形"调色板"区域，用边框色围住。调色板内部每行有两个像素：左侧为一种颜色（旧色），右侧为另一种颜色（新色），表示一条替换规则。调色板行数为2-4行。
- 网格其余区域有一个大型多色连通拼图对象（4连通），由多种颜色组成，形状不规则。

Rule:
- 从调色板中读取所有颜色替换规则（旧色→新色）。
- 识别大型拼图对象，找到其所有"边界像素"——即与bg通过4邻接相邻的拼图像素（拼图最外一层）。
- 对每个边界像素：若其颜色匹配调色板中某条规则的旧色，则替换为对应的新色。
- 拼图内部（非边界）的像素即使颜色匹配也不替换。
- 调色板区域在输出中保持不变。

Key insight: 调色板提供的替换规则本身很容易发现，但真正的难点在于发现替换仅作用于拼图的边界层——内部相同颜色的像素被保留。解题者需要对比输入输出，注意到只有外缘像素发生了变化，从而归纳出"边界限定"这一隐蔽的空间约束。
</description>

<description>
网格中有若干个由同一颜色绘制的闭合矩形环，每个环内部有一个小型彩色图案；输出时，每个环根据其内部图案的偏移方向向该方向平移，直到环的外边缘碰到网格边界或另一个已停止的环。

Input structure:
- 背景色（bg）填充大部分网格。
- 若干个1像素宽的闭合矩形环，全部用同一种颜色（如 blue）绘制。环的大小各不相同（从3x3到7x7不等）。
- 每个环的内部空间中有一个小型彩色图案（1-3个像素，非bg、非环色）。该图案不居中——它偏向环内部空间的某一侧（上、下、左或右），即图案像素全部位于环内部空间的上半部/下半部/左半部/右半部。
- 环之间在输入中互不重叠且有间距。

Rule:
- 对每个环，观察其内部图案相对于环内部空间中心的位置：若图案像素全部在内部空间的上半部分则方向为上，全部在下半部分则为下，全部在左半部分则为左，全部在右半部分则为右。
- 将整个环（包括其内部图案）沿该方向平移，直到环的外边缘紧贴网格边界，或紧贴另一个已经停止的环的外边缘。
- 处理顺序：距离目标边界最近的环优先移动（即沿移动方向，前方空间最少的环先处理）。
- 擦除环的原始位置。

Key insight: 内部图案的偏移方向编码了环的移动方向——这一信息不是通过颜色或标记直接给出的，而是通过图案在环内的空间位置隐式传达的。解题者需要发现"图案偏向哪侧，环就往哪侧滑动"这一空间映射关系。
</description>
</new_puzzle>
