<description>
根据框架内部种子像素的颜色找到对应的外部模板精灵，再按种子在框架内的象限位置对模板进行旋转后填入框架。

Input structure：
- 背景为黑色。网格中散布着若干用 grey 像素绘制的正方形空心框架（边长为奇数，如 5×5 或 7×7，边框厚度为 1 像素）。
- 每个框架的内部恰好有一个非黑色、非灰色的"种子像素"，位于内部区域的四个象限之一（左上、右上、左下、右下）。种子像素的颜色在整个网格中不唯一——多个框架可能有相同颜色的种子。
- 网格中还散布着若干独立的小型彩色精灵（4-连通的单色图案，不与任何框架接触），每个精灵的颜色各不相同，且每种颜色在所有框架种子中至少出现一次。每个精灵的形状不对称（即旋转 90°、180°、270° 后形状不同）。

Rule：
- 第一层：对每个框架，根据种子像素的颜色，找到网格中与之颜色相同的独立精灵作为模板。
- 第二层：根据种子像素在框架内部区域中所处的象限确定旋转角度——左上象限不旋转（0°），右上象限顺时针旋转 90°，右下象限顺时针旋转 180°，左下象限顺时针旋转 270°。
- 将旋转后的模板精灵绘制到框架内部区域的中心位置（以内部区域的中心为精灵的中心对齐），覆盖原有的种子像素。框架外部的独立精灵保持不变。

Key insight：
种子像素同时承载两重信息——颜色决定"画什么"（模板选择），位置决定"怎么画"（旋转方向）。解题者必须先发现颜色匹配关系，再发现象限-旋转的映射，两层规则缺一不可。
</description>

<description>
沿着每条彩色路径的方向将路径末端的形状"推"到路径对面，推送距离等于路径的像素长度。

Input structure：
- 背景为黑色。网格中有若干小型单色形状（每个形状由 2-4 个同色像素组成的 4-连通区域）。
- 每个形状恰好有一个像素与一条单像素宽的直线路径（水平或垂直）相邻，路径由与形状不同的另一种颜色绘成。路径从形状的某一侧出发，沿水平或垂直方向延伸若干格后终止。
- 不同形状的路径颜色各不相同，路径之间互不交叉。

Rule：
- 第一层：识别每个形状及其关联的路径，确定路径的方向（上/下/左/右）和长度（路径包含的像素数）。
- 第二层：路径指示推送方向——形状应沿路径所指的方向移动。但移动距离不是到路径末端，而是等于路径像素数量的步数，从形状的当前位置开始计算。
- 在输出中：擦除原始形状和路径，在新位置绘制形状（保持原色和原形状）。若形状被推到网格边界外，则裁剪超出部分。

Key insight：
路径不是轨道（形状不沿路径移动），而是方向标和距离尺——路径的朝向决定推送方向，路径的长度决定推送距离。解题者容易误以为形状沿路径滑动到终点，但对比样例会发现移动距离与路径长度一致、而非与路径终点位置一致。
</description>
</new_puzzle>

<description>
在分隔线两侧分别识别"钥匙"形状和"锁"形状，将每把钥匙旋转至能嵌入对应锁的缺口的方向，然后用钥匙颜色填充锁的缺口。

Input structure：
- 背景为黑色。网格中间有一条完整的单像素宽的 grey 水平或垂直分隔线，将网格分为两个区域。
- 分隔线一侧（"钥匙侧"）包含若干小型彩色 4-连通形状，每个颜色不同——这些是"钥匙"。
- 分隔线另一侧（"锁侧"）包含若干较大的 maroon 色 4-连通形状，每个 maroon 形状内部有一个由黑色像素构成的缺口区域（即 maroon 形状的外包围盒内部有一块连通的黑色区域不与外部黑色背景相连）。每个缺口的形状恰好与某把钥匙在某个旋转状态（0°/90°/180°/270°）下完全吻合。
- 每个锁的缺口旁边（在 maroon 形状的外边缘上）有一个与某把钥匙颜色相同的单像素标记，指示该锁与该颜色的钥匙配对。

Rule：
- 第一层：通过颜色标记将每把钥匙与对应的锁配对——锁边缘的彩色标记颜色与钥匙颜色相同。
- 第二层：找到钥匙的哪个旋转状态（0°/90°/180°/270°）与锁的缺口形状完全匹配。
- 用该钥匙的颜色填充锁的缺口（即将缺口中的黑色像素替换为钥匙的颜色）。钥匙侧的原始钥匙形状保持不变，锁边缘的彩色标记也保持不变。

Key insight：
颜色标记解决"谁配谁"的问题，但这只是第一层；第二层需要空间推理——解题者必须在心中旋转钥匙形状去匹配缺口轮廓。两层推理相互独立：配对靠颜色，旋转靠形状拟合。
</description>

<description>
每个彩色区域根据其邻接的边框段数量生长出相应层数的同色外壳，但生长方向仅限于有边框的那些边。

Input structure：
- 背景为黑色。网格中有一个大型 grey 矩形边框（仅一像素宽的四条边），边框内部为黑色背景。
- 边框内部散布若干小型单色矩形色块（每个色块颜色不同，不与边框接触），每个色块为 1×1 至 3×3 的实心矩形。
- 边框的四条边（上、下、左、右）各自可能是完整的，也可能有一段被擦除（即该段用黑色替代了 grey）。每条边要么完整存在，要么完整缺失——不存在部分缺失的情况。

Rule：
- 第一层：检查 grey 边框的四条边哪些存在、哪些缺失。将存在的边数记为 N（N 的范围为 1 到 4）。
- 第二层：对边框内部的每个彩色色块，向存在边框的那些方向分别生长 N 层同色像素外壳。"生长"指：第 1 层在色块的对应方向紧邻处扩展一行/列同色像素，第 2 层在第 1 层的基础上继续向同方向扩展一行/列，以此类推共 N 层。仅在有边框的方向上生长——缺失边框对应的方向不生长。
- 生长不超过边框的内侧边界。若生长到边框内侧即停止。色块在没有边框的方向上保持原始大小。

Key insight：
边框的缺失模式同时编码了两个独立信息：缺失的边决定了生长的"方向集合"，而剩余边的数量决定了生长的"层数"。解题者必须分别发现这两条规则并组合应用——仅发现其中一条无法正确推导输出。
</description>

<description>
根据每个彩色形状的孔洞数量，从色标图例中选取对应颜色，用该颜色沿形状的凹陷方向填充射线至网格边缘。

Input structure：
- 背景为黑色。网格左侧或上侧有一列/一行彩色图例方块，从上到下（或从左到右）分别标注 0 个孔洞、1 个孔洞、2 个孔洞……所对应的颜色。每个图例方块是一个 2×2 的实心彩色方块，颜色各不相同，相邻方块之间间隔 1 行/列黑色。
- 网格主区域散布若干 grey 色的 4-连通形状，每个形状可能包含 0、1 或 2 个孔洞（被 grey 像素完全封闭的内部黑色连通区域）。每个形状有一个明显的凹口（形状的外边界上有一处凹陷——形状包围盒内的非封闭黑色区域从某个方向（上/下/左/右）向外敞开）。
- 每个形状的孔洞数量与图例中某个方块的序号对应。

Rule：
- 第一层：对每个 grey 形状，数出其封闭孔洞的数量（0、1 或 2），然后在图例中找到对应序号位置的颜色。
- 第二层：识别每个形状的凹口朝向（上/下/左/右）。从凹口处沿凹口敞开方向发射一条与凹口等宽的射线，射线一直延伸到网格边缘，用第一层确定的颜色绘制这条射线。
- 射线不覆盖任何非黑色像素（遇到其他形状或图例时中断）。原始 grey 形状和图例保持不变。

Key insight：
孔洞数量是拓扑属性，决定"用什么颜色画"；凹口方向是几何属性，决定"往哪里画"。这两个视觉线索来自同一个形状的不同层面，解题者必须同时识别拓扑特征和几何特征才能完成变换。
</description>

<description>
在每个隔间内，根据隔间开口方向将内部图案翻转，再根据隔间内标记像素的颜色重新着色。

Input structure：
- 背景为黑色。网格中有若干由 azure 像素构成的矩形隔间，每个隔间是三面封闭、一面缺失的 U 形围墙（围墙厚度 1 像素）。缺失的那一面即为"开口方向"（上/下/左/右之一）。
- 每个隔间内部包含一个用 grey 像素绘制的小型非对称 4-连通图案（旋转和翻转后形状不同）。所有隔间内的 grey 图案形状相同，但可能有不同的朝向。
- 每个隔间内还有一个单独的彩色标记像素（非黑色、非灰色、非 azure），位于隔间内部的某个角落。不同隔间的标记颜色可能不同。

Rule：
- 第一层：确定每个隔间的开口方向。根据开口方向对隔间内的 grey 图案做镜像翻转——开口朝上或朝下时做左右镜像翻转，开口朝左或朝右时做上下镜像翻转。翻转以图案自身的包围盒中心为轴。
- 第二层：将翻转后的图案从 grey 重新着色为该隔间内标记像素的颜色。
- 输出中 azure 围墙保持不变，标记像素保持不变，只有 grey 图案像素发生位置变化和颜色替换。

Key insight：
围墙的开口方向不仅是视觉特征，更是翻转指令的编码——开口朝向的轴线垂直方向即为镜像轴。解题者需要先发现开口方向与翻转方向的关系（这在单个样例中可能有多种解读，必须对比多个样例才能确认），再发现标记像素控制最终颜色。
</description>

<description>
将每个 L 形指示箭头所指方向上的第一个目标色块复制到箭头尖端，复制时按箭头短臂的长度缩放色块。

Input structure：
- 背景为黑色。网格中有若干由单一颜色绘制的 L 形箭头：每个箭头由两条互相垂直的线段组成，共享一个拐角端点。其中较长的一条为"长臂"，较短的一条为"短臂"。短臂始终从长臂的一个端点（非拐角端点）出发，向垂直于长臂的方向延伸。箭头的"指向"定义为：从拐角沿长臂指向短臂所在的那个端点。
- 网格中还有若干彩色矩形色块（实心，颜色各不相同且与箭头颜色不同），散布在箭头之间。

Rule：
- 第一层：确定每个箭头的指向方向（上/下/左/右）。从箭头尖端（长臂上与短臂相连的那个端点）沿指向方向做射线，找到射线碰到的第一个彩色矩形色块。
- 第二层：测量箭头短臂的长度（像素数，含拐角共享像素）。设短臂长度为 K。将目标色块按比例缩放：色块的每个像素变成 K×K 的同色方块（即宽度和高度都乘以 K）。
- 将缩放后的色块绘制在箭头尖端的前方，紧贴尖端沿指向方向放置。缩放色块的近边中心与箭头尖端对齐。原始色块和箭头保持不变。

Key insight：
L 形箭头编码了三重信息：长臂和短臂的空间关系确定指向方向，射线投射找到操作目标，短臂长度控制缩放倍数。解题者需要依次破解方向、目标、缩放三层机制。
</description>

<new_puzzle>
<description>
根据每行中彩色标尺的长度，将同行的形状在垂直方向上复制相应次数，形成纵向堆叠；堆叠方向由标尺相对于形状的位置决定。

Input structure：
- 背景为黑色。网格被若干条完整的水平 grey 分隔线分成若干行带（每条分隔线厚度 1 像素）。
- 每个行带内恰好包含两个对象：一个是小型彩色 4-连通形状（2-5 像素），一个是同色的水平直线段（"标尺"），二者颜色相同但不相邻。标尺和形状在同一行带中，但可能在不同的行位置上。
- 不同行带的对象颜色可能不同也可能相同。标尺的长度（像素数）在 1-4 之间。

Rule：
- 第一层：对每个行带，识别其中的形状和标尺。标尺的像素数 N 即为复制次数。
- 第二层：确定堆叠方向——如果标尺在形状的左侧，则形状向上复制；如果标尺在形状的右侧，则形状向下复制。
- 在输出中，保留原始形状不动，并沿确定的方向紧邻复制 N 份形状的副本（每份副本与前一份紧邻无间隔，副本保持原形状和原颜色）。副本可以穿越 grey 分隔线（覆盖分隔线像素）并进入相邻行带。擦除标尺。

Key insight：
标尺是一个双重编码器件：其长度编码复制次数，其相对于形状的左右位置编码上下堆叠方向。解题者容易先发现长度-次数关系，但必须再发现左右位置到上下方向的非直觉映射（左→上、右→下），这需要对比多个样例才能确认。
</description>
</new_puzzle>
