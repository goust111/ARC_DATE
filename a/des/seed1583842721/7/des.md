<description>
将散落的碎片拼入棋盘格网格中，根据碎片落入的格子奇偶性决定是否对碎片做颜色反转。

Input structure：
- 背景为黑色。网格中有一个由两种颜色（如 blue 和 red）交替铺设的棋盘格矩形区域，其中若干格子被挖空（替换为黑色），形成空洞。
- 棋盘格外部散布着若干小型双色碎片（每个碎片恰好使用 blue 和 red 两种颜色），每个碎片的形状与某个空洞区域完全吻合。
- 每个碎片旁边有一个单像素的 grey 标记点，指示该碎片属于哪个空洞（标记点与目标空洞在同一行或同一列上，且是该方向上距离最近的空洞）。

Rule：
- 第一层：通过 grey 标记点的行列对齐关系，将每个碎片与棋盘格中的一个空洞配对。
- 第二层：检查空洞左上角格子在棋盘格中的奇偶性——若左上角是"浅色格"（与棋盘格左上角同色），则碎片原样填入；若左上角是"深色格"（与棋盘格左上角异色），则将碎片中的 blue 和 red 互换后填入。
- 输出中棋盘格的已有部分保持不变，碎片填入空洞后恢复完整的棋盘格图案。grey 标记点和外部碎片原位置被擦除。

Key insight：
碎片本身已经包含正确的棋盘着色，但只有一半的空洞可以直接使用——另一半需要颜色反转。解题者必须发现棋盘格的奇偶相位决定了是否反转，而非简单的形状匹配填充。
</description>

<description>
沿每个彩色种子像素向外做螺旋生长，螺旋的旋转方向由种子所在的网格象限决定，生长步数由种子颜色在色谱图例中的位序决定。

Input structure：
- 背景为黑色。网格的一条边（如顶边）排列着一行彩色图例像素，从左到右颜色各不相同，形成一个有序色谱（如 red, green, blue, yellow, ...）。
- 网格内部散布着若干单像素的彩色种子，每个种子的颜色与图例中的某个颜色相同。种子之间距离足够远，生长后不会重叠。
- 网格可以被中心点划分为四个象限（左上、右上、左下、右下）。

Rule：
- 第一层：根据种子颜色在顶边图例中的位置（从左往右第 1、2、3 ... 个），确定该种子的螺旋生长步数 N。
- 第二层：根据种子所处的象限确定螺旋旋转方向——左上和右下象限为顺时针螺旋，右上和左下象限为逆时针螺旋。
- 从种子像素出发，沿确定的旋转方向画出一条单像素宽的螺旋线，螺旋每转过一个直角后延伸长度加 1（即第一段 1 格，第二段 1 格，第三段 2 格，第四段 2 格，第五段 3 格...），共画 N 段。螺旋线使用种子的颜色绘制。

Key insight：
图例的排列顺序是一把隐藏的标尺——颜色的位序编码了生长量，而非颜色本身的视觉属性。象限到旋转方向的映射则遵循对角线对称性（主对角线上的象限同向），需要对比不同象限的样例才能归纳。
</description>

<description>
识别网格中每条闭合围栏内部被困住的"动物"数量，然后在围栏外壁上按该数量打开等量的缺口。

Input structure：
- 背景为黑色。网格中有若干由 grey 像素构成的不规则闭合围栏（1 像素宽的封闭曲线，4-连通），围栏之间互不接触。
- 每个围栏内部有若干小型彩色形状（"动物"），每个动物是 1-3 个同色像素的 4-连通区域。同一围栏内的动物颜色可能相同也可能不同。
- 每个围栏的外壁上有若干被特殊标记的位置——这些位置的 grey 像素被替换为 yellow 像素，表示"潜在缺口"。潜在缺口的数量总是大于或等于围栏内的动物数量。

Rule：
- 第一层：对每个围栏，数出内部动物的数量 N。
- 第二层：在围栏外壁的 yellow 标记位置中，按从上到下、从左到右的顺序选取前 N 个，将这些位置的像素从 yellow 改为黑色（即打开缺口）。剩余的 yellow 标记位置恢复为 grey（即变回普通围墙）。
- 围栏内的动物保持原位不变。

Key insight：
yellow 标记是"候选门"而非"确定门"——只有与内部动物数量匹配的前几个候选门会被打开，其余恢复为墙壁。解题者需要先发现动物计数与缺口数量的对应关系，再发现选取顺序的扫描规则。
</description>

将网格中的多层嵌套矩形框架由内向外逐层"展开"成水平条带，条带排列顺序由嵌套深度决定，条带颜色保持不变。

Input structure：
- 背景为黑色。网格的一侧（如左半部分）包含多层同心嵌套的矩形框架，每层框架颜色不同、厚度均为 1 像素。最外层框架最大，最内层最小，各层之间间隔 1 像素的黑色间隙。最内层框架内部是一个实心的彩色矩形核心。
- 网格的另一侧（如右半部分）为纯黑色的空白区域，其高度足以容纳展开后的所有条带。

Rule：
- 第一层：识别嵌套框架的层级结构，从最内层（核心）到最外层编号为 1, 2, 3, ...
- 第二层：将每一层"展开"——即将该层框架的所有像素按从上到下、从左到右的扫描顺序排成一条水平直线段。核心矩形也同样展开为一条直线段。
- 第三层：在右侧空白区域，从上到下依次排列这些条带——最内层（层 1）在最上方，最外层在最下方。每条条带左端对齐，条带之间间隔 1 行黑色。条带保持对应层的原始颜色。
- 输出仅包含右侧区域（即裁剪掉左侧的原始嵌套结构）。

Key insight：
展开操作将二维的嵌套空间结构线性化为一维条带，条带长度自然反映了每层框架的周长（外层更长）。解题者需要理解"展开"是将环形像素序列拉直，而非简单地提取某行或某列。
</description>

<description>
根据每个封闭区域内的"投票"像素颜色的多数决结果，对该区域的边界重新着色。

Input structure：
- 背景为白色。网格中有若干由 grey 像素绘制的封闭区域边界（1 像素宽的闭合曲线），区域之间可以共享边界段。
- 每个封闭区域内部散布着若干单像素的彩色"投票"点，颜色为 red、blue 或 green 中的一种或多种。每个区域内至少有 1 个投票点，且不会出现票数完全相同的平局。
- 不同区域的投票结果可能不同。

Rule：
- 第一层：对每个封闭区域，统计其内部各颜色投票点的数量，确定票数最多的颜色（多数色）。
- 第二层：将该区域的全部边界像素（grey）重新着色为该区域的多数色。
- 若某段边界被两个区域共享，则该段边界取两个区域多数色中票数更高的那个颜色（绝对票数多的区域优先）。
- 内部的投票点在输出中被擦除（变为白色背景）。

Key insight：
共享边界的归属问题是关键难点——它不属于任何单个区域，而是由相邻区域之间的"投票竞争"决定。解题者必须先发现多数决规则，再发现共享边界的仲裁机制，后者需要跨区域比较绝对票数。
</description>

<description>
追踪每条彩色蛇从头部出发的爬行轨迹，蛇在遇到墙壁时按照身体花纹编码的转向序列决定左转还是右转。

Input structure：
- 背景为黑色。网格中有若干 grey 像素构成的墙壁，形成一个迷宫式的通道网络（通道宽度为 1 像素）。
- 通道中有若干"蛇"，每条蛇由 3-6 个像素组成的 4-连通直线段，使用两种颜色交替排列（如 red-blue-red-blue 或 green-yellow-green）。蛇的一端（头部）与一条通道的起点相邻，另一端（尾部）远离通道。
- 蛇头朝向通道延伸的方向，初始行进方向由此确定。

Rule：
- 第一层：识别每条蛇的头部位置和初始行进方向。从蛇的头部开始沿通道前进，每次遇到 T 形或 L 形交叉口时需要转向。
- 第二层：蛇身体的颜色序列（从头到尾读取）编码了转向指令序列——颜色 A 表示左转，颜色 B 表示右转。遇到第 1 个交叉口时使用序列中第 1 个颜色的指令，遇到第 2 个交叉口时使用第 2 个颜色的指令，依此类推。若交叉口数量超过蛇身长度，则循环使用该序列。
- 在输出中，蛇沿通道爬行后的最终位置被绘制出来（保持原始花纹和方向），蛇经过的通道格子恢复为黑色。蛇走到通道尽头（死胡同）时停止。

Key insight：
蛇的花纹不是装饰——它是一套预编程的转向指令。解题者需要发现双色交替模式与左右转向的对应关系，并在心中模拟蛇在迷宫中的逐步移动。

<description>
将每对同色标记像素之间的曼哈顿最短路径全部着色，路径交叉处使用混合色规则。

Input structure：
- 背景为黑色。网格中散布着若干成对出现的彩色单像素标记，每种颜色恰好出现两次。不同颜色对之间距离足够远。
- 网格中还有一个位于角落的 2×N 色彩混合图例，图例的每一行包含两种颜色和它们的混合结果色（如 red + blue = magenta）。

Rule：
- 第一层：对每对同色标记，找出它们之间所有曼哈顿最短路径所覆盖的像素集合（即距离场中两点之间的全部最短路径像素），用该颜色填充这些像素。
- 第二层：若两种不同颜色的路径区域在某些像素上重叠，则查阅角落的混合图例，将这些像素替换为对应的混合结果色。
- 标记像素本身保持原色不变（即使处于重叠区域）。

Key insight：
两个曼哈顿等距点之间的最短路径集合形成一个矩形区域（而非单条路径），这一几何事实是理解输出形状的关键。混合图例则为颜色叠加提供了确定性规则，避免了歧义。

<description>
根据灰色管道网络的拓扑结构，将输入端口注入的颜色沿管道传播，在分叉处进行颜色分裂、在汇合处进行颜色叠加。

Input structure：
- 背景为黑色。网格中有一个由 grey 像素构成的管道网络——单像素宽的连通路径，包含直线段、L 形拐弯、T 形分叉和十字交叉。
- 管道网络在网格边缘有若干开口端点（"端口"）。部分端口旁边的边缘像素被涂上了颜色（red、blue 或 yellow），表示该端口有颜色输入。未标记的端口是输出端口。
- 网络中没有环路（即管道构成一棵树或森林）。

Rule：
- 第一层：从每个有颜色输入的端口出发，沿管道网络向内传播颜色。管道上的 grey 像素被替换为传播到的颜色。
- 第二层（分叉）：当管道在 T 形分叉处一分为二时，颜色同时传入两个分支，两个分支都被染上相同的颜色。
- 第三层（汇合）：当两种不同颜色在某个汇合点相遇时，发生颜色混合——red + blue = magenta，red + yellow = orange，blue + yellow = green。混合后的颜色继续沿汇合后的管道传播。三色汇合时结果为 white。
- 输出端口处的管道末端像素显示最终传播到的颜色。

Key insight：
管道网络是一个颜色运算的物理计算图——分叉是复制操作，汇合是加法操作。解题者需要将空间拓扑转化为数据流图，追踪颜色信号在网络中的传播与混合。
</description>
</new_puzzle>
