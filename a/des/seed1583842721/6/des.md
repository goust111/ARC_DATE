<description>
根据彩色种子像素在封闭围栏内执行洪水填充，围栏外的同色种子则触发边界描边。

Input structure:
- 背景为最常见颜色。网格中散布若干由单一非背景色构成的封闭矩形围栏（一像素宽边框，内部为背景色）。
- 每个围栏内部恰好有一个彩色种子像素（颜色与围栏色不同）；网格中还存在若干不在任何围栏内部的孤立彩色像素。

Rule:
- 对于围栏内部的种子像素：用种子颜色填充该围栏内部所有背景像素（洪水填充），围栏边框保持不变。
- 对于围栏外部的孤立彩色像素：找到距离该像素最近的围栏，用该像素的颜色重新绘制该围栏的整个边框，然后清除该孤立像素。
- 若某围栏同时拥有内部种子和外部描边像素，两个操作均执行。

Key insight:
- 同样是彩色像素，位于围栏内外决定了完全不同的操作语义：内部触发填充，外部触发描边重染。
</description>
</new_puzzle>

<new_puzzle index="2">
<description>
将散落的碎片拼图按颜色编码的榫卯凹凸关系组装成完整矩形。

Input structure:
- 背景色上散布若干不重叠的多色块状碎片，每个碎片的主体为一种颜色，边缘有一到两个单像素凸起或单像素凹槽，凸起/凹槽使用第二种颜色标记。
- 凸起标记色与另一碎片的凹槽标记色相同时，表示这两个碎片在该方向上可以拼接。

Rule:
- 识别每个碎片边缘的凸起和凹槽位置及其标记颜色。
- 将标记颜色匹配的凸起与凹槽对齐，把所有碎片平移拼合成一个无缝矩形。
- 输出仅保留拼合后的矩形，所有凸起/凹槽标记像素恢复为对应碎片的主体颜色。

Key insight:
- 边缘标记色是隐式的配对钥匙——凸起和凹槽通过共享标记色声明彼此的邻接关系与对齐偏移。
</description>
</new_puzzle>

<new_puzzle index="3">
<description>
按照箭头像素指示的方向，将每行或每列的前景像素序列循环移位相应步数。

Input structure:
- 网格边缘（最外一圈）为控制区，内部为操作区。
- 控制区中，左侧和右侧边缘列上的非背景像素是行操作箭头，顶部和底部边缘行上的非背景像素是列操作箭头。
- 箭头颜色编码移位步数（按颜色在调色板中的序号）；箭头位于左侧表示该行右移，右侧表示左移；顶部表示下移，底部表示上移。
- 操作区内部有若干前景像素散布在背景上。

Rule:
- 对每个有箭头标记的行或列，将操作区内该行/列的所有前景像素（保持相对顺序）沿箭头方向循环移位，步数等于箭头颜色的调色板序号。
- 行操作先于列操作执行。
- 控制区（边缘）在输出中被裁去，仅输出操作区结果。

Key insight:
- 边缘箭头同时编码了操作轴（行/列）、方向（由箭头在哪一侧决定）和步数（由颜色序号决定），三重信息压缩在单个像素中。
</description>
</new_puzzle>

<new_puzzle index="4">
<description>
根据网格中星座状的点阵图案，在点之间绘制引力线并在交叉点生成新颜色。

Input structure:
- 黑色背景上散布着若干彩色像素点，每种颜色恰好出现两个像素。
- 同色的两个像素构成一个"星对"。

Rule:
- 对每个星对，沿连接两点的直线（Bresenham 直线）绘制该颜色的连线，两端点保留。
- 当两条不同颜色的连线在同一像素交叉时，该像素颜色变为两种颜色的调色板序号之和对 10 取模所对应的颜色。
- 若三条及以上连线交叉，依次两两累加取模。

Key insight:
- 交叉点的颜色不属于任何输入颜色，而是由相交线段的颜色通过模运算合成——解题者必须先画线再算交叉色。
</description>
</new_puzzle>

<new_puzzle index="5">
<description>
识别被噪声像素污染的对称图形，清除破坏对称性的噪声并补全缺失像素以恢复完美对称。

Input structure:
- 背景色上有一个较大的前景色连通图形，该图形"几乎"关于某条轴（水平、垂直或对角线）对称。
- 少量像素被添加（噪声）或被删除（缺口），使对称性不完美。
- 网格角落有一个 1x1 的标记像素，其颜色指示对称轴类型：红色=垂直轴，蓝色=水平轴，绿色=主对角线，黄色=副对角线。

Rule:
- 根据角落标记确定对称轴类型，对称轴穿过图形的质心。
- 对于图形中每个像素，检查其关于对称轴的镜像位置：若镜像位置为背景色，则填入前景色（补全缺失）。
- 对于仅在一侧出现而镜像侧为背景的孤立像素（与主体不4-连通的像素），判定为噪声并清除为背景色。
- 清除角落标记像素。

Key insight:
- 补全与清除是对称修复的两面：连通的不对称像素需要在镜像侧补全，而孤立的不对称像素则是应删除的噪声。
</description>
</new_puzzle>

<new_puzzle index="6">
<description>
将螺旋路径上的颜色序列按层级展开为嵌套矩形环。

Input structure:
- 网格中有一条从外圈顺时针螺旋向中心的单像素宽彩色路径，路径上的像素使用多种颜色。
- 路径中颜色相同的连续段构成一个"色段"。

Rule:
- 从螺旋外端开始，按顺序读取每个色段及其长度。
- 输出一个新网格：第一个色段构成最外层矩形环，第二个色段构成次外层矩形环，依此类推。
- 每层环的周长等于对应色段的像素数量；环的颜色为该色段的颜色。
- 输出网格尺寸恰好容纳所有嵌套环，中心若有剩余空间则填充背景色。

Key insight:
- 一维螺旋路径中的色段长度直接编码了二维嵌套矩形环的周长——解题者需要从线性序列重建层级化的空间结构。
</description>
</new_puzzle>

<new_puzzle index="7">
<description>
用模板印章在画布上逐步盖印，后印覆盖先印，根据数字标记确定盖印顺序。

Input structure:
- 网格被分隔线分为左右两个面板。
- 左面板包含若干小型彩色图案（印章模板），每个模板左上角有一个灰色数字标记像素（颜色深浅编码顺序：最浅=第一个，最深=最后一个）。
- 右面板是纯背景色的画布，画布上散布着与印章数量相同的单像素锚点，每个锚点颜色与某个印章模板的主色相同。

Rule:
- 按灰度从浅到深的顺序依次将印章盖印到画布上。
- 每个印章以其匹配颜色的锚点为定位中心进行放置。
- 后盖的印章覆盖先盖的印章重叠区域。
- 输出仅包含右面板画布的最终结果。

Key insight:
- 灰度标记编码了画家算法的 Z 序——最终可见的像素取决于盖印顺序，而非印章大小或位置。
</description>
</new_puzzle>

<new_puzzle index="8">
<description>
在管道网络中追踪流体流向，根据阀门状态决定终端出口的颜色。

Input structure:
- 网格中有由灰色像素构成的正交管道网络（水平和垂直线段），管道交叉处形成 T 形或十字路口。
- 管道的一端（源头）有一个彩色像素标记流体颜色。
- 管道的若干末端（终端）为黑色像素。
- 部分交叉处有红色或绿色的单像素"阀门"：绿色允许流体直行，红色强制流体转弯。

Rule:
- 流体从源头沿管道流动，遇到绿色阀门时保持原方向继续直行，遇到红色阀门时转弯 90 度（优先右转，若右转不通则左转）。
- 无阀门的交叉处流体向所有可通方向分流。
- 将所有流体可达的终端像素染为源头流体颜色；不可达的终端保持黑色。
- 管道和阀门本身颜色不变。

Key insight:
- 红绿阀门将拓扑上全连通的管道网络切割成方向受限的有向图——可达性取决于路径上阀门颜色的排列。
</description>
</new_puzzle>

<new_puzzle index="9">
<description>
根据种子位置在 Voronoi 图上生成区域，然后仅保留与边界相邻的区域的颜色。

Input structure:
- 白色背景网格上散布若干不同颜色的单像素种子点。
- 网格边缘有一圈黑色边框。

Rule:
- 对每个非边框像素，计算其到所有种子点的曼哈顿距离，将该像素染为最近种子的颜色（平局时选调色板序号较小的颜色）。
- 生成完整 Voronoi 划分后，检查每个区域是否有像素与黑色边框 4-连通相邻。
- 保留与边框相邻的区域的颜色不变；将不与边框相邻的内部区域的所有像素重置为白色背景。
- 黑色边框保留。

Key insight:
- Voronoi 划分是中间步骤而非最终结果——边框邻接性作为二次过滤器决定哪些区域可见，迫使解题者先构建再筛选。
</description>
</new_puzzle>

<new_puzzle index="10">
<description>
将棋盘上的棋子按博弈规则移动一步，被吃掉的棋子从棋盘消失。

Input structure:
- 网格为交替的两色方格棋盘图案（如浅灰和深灰）。
- 棋盘上放置若干彩色像素代表棋子，分为两组颜色（暖色组：红/橙/黄 vs 冷色组：蓝/青/绿）。
- 恰好有一个棋子周围带有一圈单像素的高亮标记环（该棋子所在方格的四邻像素被标记为特殊颜色），表示"该棋子即将移动"。

Rule:
- 被标记的棋子沿对角线方向向对方阵营最近的棋子移动一步（类似跳棋规则）。
- 若目标对角位置有对方棋子且跳跃落点为空，则跳过并吃掉该对方棋子（被吃棋子消失，移动棋子落在跳跃落点）。
- 若无可吃的棋子，则向对方阵营方向的空对角格移动一步。
- 清除高亮标记环，恢复棋盘底色。

Key insight:
- 高亮标记环不是装饰而是行动指令——解题者必须识别棋子阵营划分、找到唯一被选中的棋子、判断吃子还是普通移动。
</description>
</new_puzzle>

<new_puzzle index="11">
<description>
根据输入网格中色块的面积比例关系，生成对应比例的分形缩放输出。

Input structure:
- 网格中有两个不重叠的矩形色块 A 和 B，颜色不同，其余为背景色。
- 色块 A 的面积严格是色块 B 面积的整数倍 N。

Rule:
- 将色块 B 作为基础单元，在 B 的每个像素位置放置一个缩小到 1x1 的 A 色副本（即用 A 的颜色替换 B 中每个像素）。
- 同时将色块 A 作为画布，在 A 内部以 B 的形状（按比例缩放至 A 的尺寸）绘制 B 色像素。
- 输出网格仅包含变换后的 A 区域（裁剪到 A 的边界框）。

Key insight:
- 面积倍数 N 暗示了分形嵌套层级——大色块内嵌小色块的形状，实现互为图底的视觉反转。
</description>
</new_puzzle>

<new_puzzle index="12">
<description>
沿河流路径传播颜色渐变，在支流汇合处混合上游颜色。

Input structure:
- 黑色背景上有灰色像素构成的树状分支路径（无环），末梢端点各有一个彩色像素作为颜色源。
- 路径有一个唯一的根节点（汇合终点），标记为白色像素。

Rule:
- 从每个末梢彩色源沿路径向根节点方向传播颜色：路径上的灰色像素被染为该源的颜色。
- 当两条支流在汇合点相遇时，汇合点及其下游路径的颜色取两个上游颜色的调色板序号平均值（向下取整）对应的颜色。
- 若三条支流汇合，依次两两平均。
- 根节点的白色被最终汇合颜色替换。

Key insight:
- 树状拓扑决定了颜色混合顺序——解题者必须从叶到根逐级推算混合结果，而非简单的空间插值。
</description>
</new_puzzle>
