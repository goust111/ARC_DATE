- `description`：将稀疏排列的彩色像素根据其所在面板的分隔线颜色进行分组，用同组像素的边界框生成实心矩形，然后按面板顺序拼接输出。
- `Input structure`：背景为 Black。网格被若干全高的单像素宽分隔列分成等宽面板，每条分隔列可能使用不同颜色。每个面板内散布着若干孤立的彩色前景像素，颜色各异。
- `Rule`：
  - 识别分隔列及其颜色；将面板按从左到右排序。
  - 在每个面板内，将所有前景像素的颜色替换为该面板左侧分隔列的颜色（最左面板使用右侧分隔列颜色）。
  - 计算每个面板内所有前景像素的最小边界框，将该边界框内全部填充为对应分隔颜色。
  - 输出网格仅包含这些实心矩形，按面板的从左到右顺序紧密排列，中间无分隔，矩形上边对齐于输出顶行。
- `Key insight`：分隔列不仅是结构标记，更是颜色指令——每个面板继承相邻分隔线的颜色，而非保留原始像素颜色。解题者需要先发现分隔线颜色→面板填充色的映射，再发现像素→边界框→实心矩形的聚合规则。
</new_puzzle>

<new_puzzle>
- `description`：识别网格中被墙壁包围的房间，根据房间内种子像素的数量决定该房间的填充颜色，颜色来自房间入口处的门像素。
- `Input structure`：背景为 Azure。Grey 像素形成单像素厚的正交墙壁网络，将网格划分为若干封闭房间（4-连通背景区域不接触网格边界）。每个房间内散布着若干 Red 种子像素。每个房间的墙壁上恰好有一个非 Grey 非背景色的"门"像素（替换了一个墙壁像素），不同房间的门颜色可能不同。
- `Rule`：
  - 找到所有不接触网格边界的 4-连通背景区域作为房间。
  - 对每个房间，数出其中 Red 种子像素的数量 N。
  - 找到该房间墙壁上的门像素颜色 C。
  - 若 N 为奇数，用颜色 C 填充整个房间（覆盖种子像素和背景像素）。
  - 若 N 为偶数，仅将种子像素重绘为 C，其余背景像素不变。
  - 门像素本身保持不变；墙壁和网格外部区域不变。
- `Key insight`：门像素提供填充颜色，但填充方式由种子数量的奇偶性决定——这两个属性在视觉上都可以直接获取，但它们的组合关系是隐蔽的。
</new_puzzle>

<new_puzzle>
- `description`：在多层嵌套框架中，将每层框架的缺口方向作为路径指令，从最内层向外逐步绘制一条折线路径。
- `Input structure`：背景为 Black。网格中心有若干层同心的单像素厚彩色矩形框架，从内到外每层使用不同颜色。每层框架恰好有一个单像素缺口（框架某边缺少一个像素）。最内层框架内部有一个单独的 Yellow 起点像素。
- `Rule`：
  - 从 Yellow 起点像素开始，向最内层框架缺口方向画一条直线，穿过缺口到达内外框架之间的间隙。
  - 到达间隙后，转向下一层框架的缺口方向，继续画直线穿过该缺口。
  - 重复此过程直到穿过最外层框架到达网格边界。
  - 路径的每一段使用其穿过的框架的颜色绘制。
  - 所有框架像素和起点像素保持不变。
- `Key insight`：嵌套框架的缺口位置编码了一条折线路径的转向序列；解题者必须发现路径是从内到外逐层穿越的，而每段路径的颜色继承自被穿越的框架层。
</new_puzzle>

<new_puzzle>
- `description`：将网格中每个对象的形状与图例中的模板进行旋转匹配，用匹配的旋转角度决定该对象内部标记像素的移动方向。
- `Input structure`：背景为主色。网格左侧有一列图例区域，包含若干小型模板形状，每个模板旁边有一个 Arrow 标记（由三个像素组成的 L 形：两个像素构成杆，第三个像素在杆末端的一侧，形成指向某个基本方向的箭头）。网格右侧散布着若干与模板同色的较大对象，每个对象内部恰好有一个不同颜色的标记像素。
- `Rule`：
  - 对每个右侧对象，将其形状（仅主体色，忽略标记像素）与图例模板进行旋转匹配（允许0/90/180/270度旋转），找到唯一匹配的模板及旋转角度 R。
  - 读取该模板旁箭头指示的方向 D。
  - 将方向 D 也旋转 R 度，得到最终移动方向 D'。
  - 将对象内的标记像素沿方向 D' 移动，直到到达对象边界外的第一个背景像素位置。
  - 对象主体保持不变。
- `Key insight`：匹配旋转角度不仅用于识别对象类别，还作为方向变换算子作用于图例箭头——这使得解题者需要同时推断形状匹配和方向旋转两层关系。
</new_puzzle>

<new_puzzle>
- `description`：将分隔面板中的多色条纹图案按条纹宽度排序，重新排列到输出面板中，条纹颜色不变但位置重新分配。
- `Input structure`：背景为 Black。网格由一条全高 Grey 分隔列分为左右两个等大面板。左面板包含若干水平条纹，每条条纹占一行或多行，各条纹颜色不同。右面板为空白（全背景色）。
- `Rule`：
  - 在左面板中，识别所有连续同色的水平条纹段（每段由一种非背景色填满若干连续行）。
  - 按条纹宽度（占据的行数）从小到大排序。
  - 将排序后的条纹从上到下依次填入右面板，保持每条条纹的原色和原宽度。
  - 左面板保持不变；分隔列保持不变。
- `Key insight`：输出不是左面板的简单复制或翻转——条纹的空间顺序被按宽度重新排列。解题者必须发现排序准则是条纹宽度而非颜色或原始位置。
</new_puzzle>
