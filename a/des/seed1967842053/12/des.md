<description>
根据封闭区域内部"种子"像素的颜色，在区域的边框上找到同色缺口，然后从缺口向外喷射该颜色的射线直至网格边缘；同时将边框缺口修补为边框颜色。

Input structure:
- 背景为黑色（black）。
- 网格中有若干用同一种颜色（如 grey）绘制的封闭矩形边框（边框宽度为 1 像素）。
- 每个矩形边框上恰好有一个 1 像素宽的缺口（该缺口处为背景色）。
- 每个矩形边框内部恰好有一个"种子"像素，颜色各不相同（如 red、blue、green 等），且种子像素不与边框相邻。
- 缺口所在边框段的外侧方向即为射线方向（上/下/左/右）。

Rule:
- 对每个封闭矩形边框：
  1. 找到边框上的缺口位置，确定缺口朝外的方向（即从矩形中心看向缺口的那个基本方向）。
  2. 读取该矩形内部种子像素的颜色。
  3. 将缺口处的像素修补为边框颜色（grey），使矩形变为完整闭合。
  4. 从缺口原位置沿朝外方向，逐像素绘制种子颜色的射线，直到到达网格边界为止。射线不会覆盖已有的非背景像素。
- 其余所有像素保持不变。

Key insight: 需要同时关联两个独立特征——缺口位置决定射线方向，而内部种子颜色决定射线颜色——两者分属不同的空间位置，解题者必须先建立"边框缺口↔内部种子"的对应关系，再执行几何操作。
</description>

<description>
将网格中散落的彩色碎片按照"钥匙-锁"匹配规则拼入对应的灰色模板框架中，匹配依据是碎片的外轮廓与模板内空腔的形状完全吻合。

Input structure:
- 背景为黑色（black）。
- 网格中有若干个灰色（grey）的矩形框架，每个框架内部挖去了一个不规则的连通空腔（空腔为背景色），空腔形状各不相同。
- 网格中另有若干个散落的彩色连通碎片（每个碎片为单一颜色，颜色各不相同，如 red、blue、green、orange 等），碎片不与任何框架相邻。
- 每个碎片的形状恰好与某一个框架空腔的形状完全相同（像素级一致，无需旋转或翻转）。
- 碎片数量与框架数量相等。

Rule:
- 对每个灰色框架，找到其内部空腔的形状。
- 在散落的碎片中找到形状完全匹配的那一个（平移即可对齐，无旋转无翻转）。
- 将该碎片平移到空腔对应位置，填入框架中，保持碎片原色。
- 移除碎片在原位置的像素（恢复为背景色）。
- 灰色框架和背景保持不变。

Key insight: 解题者需要完成两层推理——第一层是识别"形状匹配"作为配对规则（而非颜色或位置），第二层是在多个形状相似但细节不同的碎片和空腔之间找到精确的一一对应。
</description>

<description>
网格中的每个彩色对象根据其所在象限决定变换方式：对象被复制到以网格中心为原点的对称象限位置，并且复制品的颜色由原始象限中另一个对象的颜色决定。

Input structure:
- 背景为黑色（black）。
- 网格尺寸为奇数×奇数，中心行和中心列由 grey 像素构成十字分隔线，将网格分为四个象限（左上、右上、左下、右下）。
- 每个象限中恰好有两个不同颜色的 4-连通单色对象（形状各异），对象不接触灰色十字线。
- 四个象限共 8 个对象，使用 4 种颜色，每种颜色恰好出现 2 次，且同色的两个对象分布在对角象限（如左上和右下各一个）。

Rule:
- 保留灰色十字线不变。
- 对每个象限中的两个对象 A 和 B：
  1. 将 A 的形状关于网格中心做 180 度点对称，映射到对角象限。
  2. 映射后的副本不使用 A 的颜色，而使用同象限中另一个对象 B 的颜色。
  3. 对 B 做同样操作：形状对称映射，颜色取同象限的 A 的颜色。
- 原始对象保留在原位。
- 若映射副本与对角象限中已有的原始对象重叠，原始对象的像素优先保留。

Key insight: 三层推理——首先识别灰色十字线划分象限的结构，其次发现对角象限之间的 180 度形状对称关系，最后发现颜色并非随形状一起对称，而是来自同象限的"邻居"对象，形成了"形状走对角、颜色走邻居"的交叉映射。
</description>

<description>
网格中有多条由不同颜色绘制的水平或垂直线段，每条线段的两个端点各带有一个箭头标记；根据箭头的朝向对线段进行裁剪或延伸，使线段的端点恰好停在箭头所指方向遇到的第一个障碍物边缘。

Input structure:
- 背景为黑色（black）。
- 网格中散布着若干灰色（grey）的实心矩形障碍物（大小不一，互不重叠）。
- 有若干条彩色线段（每条线段为单一颜色，颜色各不相同，如 red、blue、green、orange 等），每条线段为水平或垂直直线，宽度为 1 像素。
- 每条线段的两个端点处各有一个 maroon 像素作为箭头标记。箭头标记位于线段端点沿线段方向向外延伸一格的位置（即标记不在线段上，而在线段的延长线上紧邻端点）。
- 每个 maroon 标记的一侧（沿线段延长方向再外一格）要么是背景色，要么是灰色障碍物。

Rule:
- 对每条线段的每个端点：
  1. 从该端点出发，沿箭头标记所指的方向（即从线段内部向端点、再向外的方向）逐像素扫描。
  2. 如果该方向上遇到灰色障碍物，将线段在该端延伸至障碍物边缘前一格（不覆盖障碍物）。
  3. 如果该方向上直到网格边界都没有障碍物，则将线段从该端裁剪——移除从原端点到线段中点方向的像素，使该端收缩至原长度的一半（向下取整）。
- 移除所有 maroon 箭头标记。
- 障碍物和背景保持不变。

Key insight: 两层非平凡推理——第一层需要识别 maroon 标记与线段端点的空间关系来确定每端的"意图方向"，第二层需要根据该方向上是否存在障碍物来决定执行截然不同的操作（延伸 vs 裁剪），而非统一的单一变换。
</description>

<description>
网格被分隔线划分为若干小房间，每个房间内有一个彩色"灯"像素和若干黑色"墙"像素；灯向四个方向照射直到被墙或房间边界阻挡，照亮的格子变为灯的颜色；最后统计每个房间中被照亮的格子数量，并用该数量替换房间在输出中的排列顺序。

Input structure:
- 网格由 azure 色的单像素宽分隔线划分为若干大小相同的正方形房间（如 5×5），排列成 M 行 N 列的网格布局。
- 每个房间的背景为 grey。
- 每个房间内恰好有一个彩色像素（"灯"），颜色从 red、blue、green、orange、yellow、magenta 中取，同一网格内所有灯颜色互不相同。
- 每个房间内还有若干 black 像素作为内部墙壁，位置各不相同。

Rule:
- 第一步——照亮：对每个房间，灯从自身位置向上、下、左、右四个方向逐格照射，将路径上的 grey 格子改为灯的颜色，遇到 black 墙壁或房间边界（azure 分隔线）时停止（墙壁和分隔线不被照亮）。灯自身的格子也算作被照亮。
- 第二步——排序：统计每个房间中被照亮的格子总数。按照亮数量从大到小对房间排序。
- 第三步——重排：将排序后的房间按照从左到右、从上到下的顺序重新放置到原网格布局中（保持每个房间内部的照亮后状态不变，包括灯、墙壁和被照亮的格子）。
- azure 分隔线保持不变。

Key insight: 三层结构——第一层需要理解灯的十字形照射机制及墙壁的遮挡效果，第二层需要发现照亮面积作为排序键（而非灯的颜色或位置），第三层需要识别排序后房间整体被重新排列到网格中的规律。每一层都需要从样例中独立归纳，单看任何一层都不够。
</description>

<description>
网格中散布的小型彩色图案充当"邮票"，而相同颜色的单像素标记充当"收件地址"；每个邮票被复制到其对应颜色标记的位置，但复制时需要根据标记相对于邮票的方向进行 90 度旋转。

Input structure:
- 背景为黑色（black）。
- 网格中有若干小型多像素连通图案（"邮票"），每个邮票由单一颜色构成（如 red、blue、green 等），形状各异（非对称），占据约 3-6 个像素。
- 每种邮票颜色在网格中恰好还有一个相同颜色的孤立单像素（"标记"），标记与邮票不相邻，标记位于邮票的某个大致基本方向上（即标记相对于邮票边界框中心大致位于正上方、正下方、正左方或正右方）。
- 不同颜色的邮票和标记互不重叠。

Rule:
- 对每对同色的邮票和标记：
  1. 确定标记相对于邮票的大致方向：比较标记位置与邮票的边界框中心，取行差和列差绝对值更大的那个轴，确定为上/下/左/右之一。
  2. 根据方向执行旋转：标记在邮票上方→不旋转（0°），标记在右方→顺时针 90°，标记在下方→180°，标记在左方→逆时针 90°。
  3. 将旋转后的邮票图案复制到标记位置，使旋转后图案的边界框中心对齐标记像素。
- 移除原始邮票（恢复为背景色）。
- 移除标记像素（被复制的图案覆盖，或若图案中心不在标记精确位置则标记也清除）。

Key insight: 两层推理——第一层需要发现同色配对规则（邮票与单像素标记按颜色匹配），第二层需要发现标记的相对方位决定了图案旋转角度，而非简单的平移复制。由于邮票形状非对称，旋转效果在样例中可被观察到但需要仔细比对才能归纳出方向-旋转的映射关系。
</description>

<description>
网格中有若干条不同颜色的路径从边缘出发向内延伸；每条路径末端有一个不同颜色的"信号"像素，信号颜色指示该路径应该与哪条其他路径连接；连接方式是从两条待配对路径的末端之间画一条 L 形折线桥梁。

Input structure:
- 背景为黑色（black）。
- 网格中有偶数条（如 4 或 6 条）彩色路径，每条路径是由单一颜色构成的宽度为 1 的折线（水平和垂直线段的组合），从网格的某条边出发，向网格内部延伸若干格后终止。
- 每条路径的末端（远离边缘的端点）旁边恰好有一个不同颜色的单像素，称为"信号"像素。信号像素与路径末端 4-邻接。
- 信号像素的颜色与网格中另一条路径的颜色相同，表示这两条路径应该被连接。配对是双向一致的：如果路径 A 的信号颜色等于路径 B 的颜色，那么路径 B 的信号颜色也等于路径 A 的颜色。

Rule:
- 对每一对待连接的路径：
  1. 取两条路径各自的末端位置。
  2. 从一端水平延伸、再垂直延伸到另一端（形成 L 形折线），使用两条路径中颜色字母序靠前的那个颜色绘制桥梁。
  3. 如果水平优先的 L 形会穿过已有的非背景像素，则改为垂直优先的 L 形。
- 移除所有信号像素（恢复为背景色）。
- 原始路径保持不变。

Key insight: 两层推理——第一层需要发现信号像素的颜色匹配机制（间接配对：信号色=对方路径色），第二层需要发现连接采用 L 形折线且桥梁颜色取决于两条路径颜色的比较规则。信号色的间接匹配是解题的关键突破口。
</description>
</new_puzzle>
