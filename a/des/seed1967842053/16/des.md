将每个封闭区域内的彩色碎片按照区域外壁缺口方向平移出去，碎片颜色决定它使用哪个缺口。

Input structure
- 背景为最常见颜色。
- 网格中有若干用同一种边框颜色（如 grey）绘制的封闭矩形区域，每个矩形边框的某一侧有一个单像素宽的缺口。
- 每个矩形内部包含一个或多个小型单色连通块（碎片），碎片颜色各不相同。
- 在网格的边缘或角落处，有一组颜色图例：每个图例由一个颜色像素和一个箭头状标记（由两个同色像素组成的短线段，指向上/下/左/右之一）组成，表示"该颜色对应该方向"。

Rule
- 首先读取图例，建立颜色到方向的映射。
- 对每个封闭矩形区域，找到其边框上的缺口位置和缺口朝向。
- 对区域内的每个碎片，根据碎片颜色在图例中查到其对应方向。
- 如果碎片的颜色方向与该矩形缺口的朝向一致，则将碎片沿缺口方向平移，直到碎片完全移出矩形（碎片出现在矩形外部，紧邻缺口外侧）。
- 如果碎片的颜色方向与缺口朝向不一致，则该碎片原地消失（被背景色替代）。
- 边框和图例保持不变。

Key insight
图例不是装饰，而是颜色到方向的查找表；只有方向匹配缺口的碎片才能"逃出"矩形，其余被淘汰。解题者需要先破译图例的方向编码，再判断每个碎片的命运。

<new_puzzle>
根据种子图案的对称性类型选择不同的铺贴方式，将种子扩展填满整个网格。

Input structure
- 背景为最常见颜色。
- 网格左上角有一个小型矩形种子图案（如 3x3 或 4x4），由两种前景色绘制在背景上。
- 网格右上角有两到三个微型示意图（各 2x2），每个示意图旁标注一种颜色的单像素标记。这些示意图分别展示不同的铺贴模式：一个表示简单平移重复，一个表示每行水平镜像交替，一个表示棋盘式旋转 180 度交替。
- 种子图案本身具有某种对称性特征：若种子存在水平对称轴，则选择平移重复；若种子存在垂直对称轴但无水平对称轴，则选择水平镜像交替；若种子无任何轴对称性，则选择棋盘式旋转交替。

Rule
- 分析种子图案的对称性：检查是否存在水平翻转不变、垂直翻转不变。
- 根据对称性从右上角的示意图中选择对应的铺贴模式。
- 用选中的铺贴模式将种子图案重复扩展，填满整个网格（裁剪到网格边界）。
- 右上角的示意图区域也被铺贴内容覆盖。

Key insight
解题者需要两步非平凡推理：第一步是识别种子图案的对称性类别，第二步是将对称性类别与右上角示意图建立对应关系以确定铺贴规则。示意图本身就是一个需要破译的图例。
</new_puzzle>

<new_puzzle>
将散落的彩色线段视为指针，根据指针指向的方向通过底部图例查得填充色，再填充对应的正方形框内部。

Input structure
- 背景为 black。
- 网格中有若干相同大小的空心正方形边框（如 5x5），边框颜色为 grey，框内为背景色。
- 每个正方形的中心像素是一个彩色点（非 grey、非 black），颜色各不相同。
- 从每个中心像素出发，有一条由同色像素组成的长度为 2 的直线段（4-连通），指向上、下、左、右四个方向之一，形成"指针"。
- 在网格底部有一行图例：四个不同颜色的色块从左到右排列，分别对应上、右、下、左四个方向的填充颜色。

Rule
- 读取底部图例，建立方向到填充颜色的映射（从左到右依次对应上、右、下、左）。
- 对每个正方形框，观察其中心指针指向的方向。
- 用图例中该方向对应的填充颜色，填充该正方形框的全部内部空白区域（不覆盖边框和指针本身）。
- 指针和边框颜色不变，图例保持不变。

Key insight
中心彩色像素和延伸线段构成方向指示器，但填充颜色不是由指针本身的颜色决定，而是由指针指向的方向通过底部图例间接查表得到。解题者必须先识别指针方向，再通过图例映射得到填充色——两步推理缺一不可。
</new_puzzle>

<new_puzzle>
每个前景对象根据自身包含的孔洞数量，被分派到网格四个角落之一，并在角落处生成该对象的缩略副本。

Input structure
- 背景为最常见颜色。
- 网格中散布着若干不重叠的单色连通前景对象（4-连通），每个对象颜色不同。
- 每个对象的形状可能包含零个、一个、两个或三个被对象像素完全包围的背景色孔洞（孔洞为被前景像素四面封闭的背景区域，且不接触网格边界）。
- 网格的四个角落区域（左上、右上、左下、右下）最初为空（纯背景）。

Rule
- 对每个前景对象，计算其包含的孔洞数量 H（0、1、2 或 3）。
- 孔洞数量决定该对象副本放置的角落：H=0 对应左上角，H=1 对应右上角，H=2 对应左下角，H=3 对应右下角。
- 将该对象的边界框内容（包括对象像素和内部孔洞）等比缩小为原来的一半（每 2x2 像素块取左上角像素），生成缩略图。
- 将缩略图放置在对应角落，紧贴网格边角。
- 若多个对象映射到同一角落，按照对象面积从大到小的顺序，依次沿角落的对角线方向排列（不重叠）。
- 原始对象保持不变。

Key insight
孔洞数量是分类键而非装饰细节，但孔洞只有在识别出对象的完整封闭边界后才能确认。解题者需要先准确分割对象并检测内部孔洞，再通过孔洞计数到角落映射完成分派——分割检测与映射规则是两个独立的推理层。
</new_puzzle>

<new_puzzle>
沿每条 grey 路径从信号源端点传播颜色，路径交叉点处按照网格边缘的图层顺序图例决定最终颜色。

Input structure
- 背景为 black。
- 网格中有若干条由 grey 像素组成的一像素宽路径（4-连通），路径之间可以有交叉（即某些 grey 像素同时属于两条路径的交汇处）。
- 每条路径的一个端点被涂成了独特的非 grey、非 black 颜色（如 red、blue、green 等），该端点即为该路径的"信号源"。
- 在网格的左侧边缘，有一列由小色块从上到下排列的图层顺序图例，排列了所有出现的信号源颜色，从上到下表示优先级从高到低。

Rule
- 从每条路径的信号源端点开始，沿着 grey 路径像素传播信号源颜色，将路径上的所有 grey 像素替换为该信号源颜色。
- 当两条路径在交叉像素处相遇时，该像素的最终颜色由图层顺序图例决定：优先级更高（在图例中位置更靠上）的颜色覆盖优先级更低的颜色。
- 信号源端点像素本身保持原色不变。
- 不属于任何路径的背景像素保持 black。

Key insight
单独的路径着色很直观，但交叉点的颜色冲突需要参考图层图例来裁决。解题者必须先追踪每条路径的归属（哪个信号源能到达哪些像素），再在冲突像素处查阅优先级图例——路径追踪和优先级查表构成两层独立推理。
</new_puzzle>

<new_puzzle>
将网格中的每个 U 形容器旋转到开口朝上，再根据容器内部标记点的数量从顶部刻度条中选色填充容器内部。

Input structure
- 背景为最常见颜色。
- 网格中有若干由同一颜色（如 grey）绘制的 U 形容器对象，每个容器是一个三面封闭、一面开口的矩形槽（宽 3 至 5 像素，深 3 至 5 像素），开口方向可以朝上、下、左或右。
- 每个容器内部散落着若干单像素的 maroon 标记点（数量 1 到 4 不等）。
- 网格顶部有一个水平颜色刻度条：从左到右排列 4 个不同颜色的色块，分别对应标记数量 1、2、3、4。

Rule
- 对每个容器，首先确定其开口方向，然后将整个容器（含内部标记点）旋转，使开口统一朝上。
- 计算该容器内部 maroon 标记点的数量 N。
- 从顶部刻度条中取第 N 个颜色（从左数第 N 个色块）。
- 用该颜色填充容器旋转后的全部内部空白区域（覆盖标记点和原有背景区域），容器的 grey 边框保持不变。
- 刻度条保持不变。

Key insight
解题需要三层推理：第一层识别容器的开口方向并确定旋转量，第二层计数容器内部标记点，第三层通过计数结果查阅刻度条选取填充色。每一层都需要独立归纳——方向识别不能替代计数，计数不能替代查表。
</new_puzzle>

<new_puzzle>
将分散在网格中的矩形碎片按照边缘锯齿轮廓的互补性配对拼合，拼合后用两块碎片颜色中在固定颜色序列里排序靠后的那个颜色统一重绘。

Input structure
- 背景为 black。
- 网格中有偶数个（4 到 6 个）相同大小的矩形碎片，每个碎片由单一前景色填充。
- 每个碎片的一条边（上、下、左或右）具有锯齿状凹凸轮廓：某些像素向外凸出一格，其余像素向内凹入一格，形成交错的齿形边缘。
- 碎片总是成对互补的：一个碎片某边的凸出位置恰好对应另一个碎片对面边的凹入位置，使得两者可以完美咬合。
- 互补碎片对的锯齿边总是面对面的（如一个的右边锯齿和另一个的左边锯齿互补）。

Rule
- 找到所有互补碎片对：两个碎片的锯齿轮廓完全互补（凹凸互为镜像）。
- 将每对碎片中距离较远的那个沿锯齿边的法线方向平移，直到两个碎片的锯齿完美咬合（凸入凹，无重叠无间隙）。
- 拼合后的整体用两个碎片颜色中在固定颜色序列 blue、red、green、yellow、grey、magenta、orange、azure、maroon 中排序靠后的那个颜色统一重绘。
- 背景保持不变。

Key insight
锯齿轮廓的互补匹配是空间推理层——需要通过视觉比对凹凸模式找到配对；颜色选择规则是第二推理层——需要从样例中发现最终颜色不是两色混合而是遵循一个固定的颜色优先序列，取排序靠后者。两层规则的线索来源完全不同（形状匹配 vs. 颜色次序归纳）。
</new_puzzle>
