description：根据封闭区域内部"种子像素"的颜色，从区域轮廓的图例色带中查找对应的填充纹理，再用该纹理铺满整个封闭区域。

Input structure：
- 背景为黑色（black）。
- 网格中存在若干由同一种墙壁颜色（grey）绘制的封闭区域轮廓，每个区域是由灰色像素围成的不规则封闭多边形。
- 网格的最上方一行或两行是"图例色带"：由若干小方块组成，每个小方块宽 2 至 3 像素、高 2 至 3 像素，内部用两种颜色交替形成棋盘格或条纹纹理。每个小方块的左上角像素颜色称为该纹理的"索引色"。
- 每个封闭区域内部恰好有一个非黑色、非灰色的单像素"种子"，其颜色与图例色带中某个小方块的索引色一致。

Rule：
- 保留灰色轮廓不变。
- 对每个封闭区域，读取其内部种子像素的颜色，在图例色带中找到索引色匹配的小方块。
- 将该小方块的纹理以平铺方式（tile）填充到封闭区域内部的所有黑色像素位置（种子像素本身也被纹理覆盖），平铺的对齐方式以封闭区域的 bounding box 左上角为原点。
- 图例色带区域在输出中被清除为黑色。

Key insight：解题者需要先识别出图例色带中每个小方块所编码的纹理模式及其索引色，再将种子颜色与索引色配对，最后按正确的对齐方式铺设纹理——这是一个"读图例→配对→铺设"的三层推理过程。
</new_puzzle>

description：将散落的彩色碎片按形状互补原则配对拼合，并用配对双方各自的颜色渲染拼合结果中属于自己的那一半。

Input structure：
- 背景为黑色（black）。
- 网格中散布着若干彩色小对象，每个对象是一个 4-连通的单色区块，颜色各不相同。
- 这些对象总数为偶数，每两个对象恰好能互补拼成同一种目标矩形（宽和高在所有配对中相同），即一个对象的像素集合与另一个对象的像素集合在适当平移后，合并恰好填满一个完整的矩形，且无重叠。
- 输出网格只包含拼好的矩形，每个矩形紧凑排列（按行优先、从左到右、从上到下排列），矩形之间有一列黑色分隔。

Rule：
- 确定目标矩形的尺寸：找到任意一个对象的 bounding box，目标矩形的宽和高是所有对象 bounding box 的最大宽度和最大高度。
- 对每个对象，将其像素规范化到 bounding box 左上角对齐的位置，形成一个布尔掩码。
- 找到两个对象 A 和 B，使得 A 的掩码与 B 的掩码互补（A 为 true 的位置 B 为 false，反之亦然，且合并后恰好填满目标矩形）。
- 输出中，每个拼合矩形内，属于 A 的像素保持 A 的颜色，属于 B 的像素保持 B 的颜色。
- 拼合矩形按配对中较小面积对象的原始行坐标从上到下排列。

Key insight：解题者首先需要发现所有碎片都是同一矩形的互补切割，然后通过形状匹配找到正确的配对——关键洞见是"形状互补"而非颜色或位置相近。
</new_puzzle>

description：根据每个房间中箭头指示的方向，将房间内的彩色像素"推"向箭头所指的墙壁并堆叠，同时箭头本身决定了堆叠后像素的排列顺序。

Input structure：
- 背景为黑色（black）。
- 灰色（grey）像素构成网格线，将整个网格分割成若干大小相同的矩形"房间"。
- 每个房间内散布着若干彩色像素（非黑色、非灰色），颜色可以重复。
- 每个房间内恰好有一个由 red 像素绘制的箭头形状。箭头由一个 3 像素长的直线段（箭杆）加上箭杆末端两侧各 1 像素的斜向突出（箭头尖端）组成，总共 5 个红色像素。箭头朝向上、下、左、右四个方向之一。

Rule：
- 读取每个房间中箭头的朝向，确定推送方向（箭头所指方向）。
- 移除箭头本身的红色像素。
- 收集房间内所有剩余的彩色像素。按照与推送方向垂直的轴排序这些像素：若箭头朝左或朝右，则按像素的行坐标从小到大排序；若箭头朝上或朝下，则按像素的列坐标从小到大排序。同一行（或同一列）内的多个像素保持它们原始的相对顺序。
- 将排好序的像素依次紧密堆叠到箭头所指方向的墙壁上：第一个像素紧贴墙壁，后续像素依次向反方向排列。像素在垂直于推送方向的位置上保持其原始坐标不变。
- 房间内其余位置变为黑色。

Key insight：解题者需要先识别出每个房间中的箭头形状并判断其朝向（这需要区分箭头与普通彩色像素），然后理解箭头同时编码了两层信息——推送的方向以及堆叠的轴向排列规则。
</new_puzzle>

description：在一个由多色条纹组成的网格中，找到被"入侵色"污染的条纹行/列，用该条纹的原始颜色修复污染像素，同时将入侵色的来源对象标记为该条纹的颜色。

Input structure：
- 网格由完整的水平条纹组成，每条条纹占一行或多行（连续相同颜色的行），条纹颜色各不相同，背景无特殊含义（整个网格被条纹铺满）。
- 网格中有若干小型矩形"入侵块"（每个由单一颜色填充，尺寸在 2×2 到 4×4 之间）叠加在条纹之上。每个入侵块的颜色与它所覆盖的条纹颜色不同，因此在视觉上形成明显的"补丁"。
- 每个入侵块恰好完全落在一条条纹内部（不跨越条纹边界）。
- 入侵块的颜色一定是网格中某条其他条纹的颜色——即入侵色来自另一条条纹。

Rule：
- 对每个入侵块，确定它所在的条纹（通过入侵块上下相邻行的颜色来推断该条纹的原始颜色）。
- 用该条纹的原始颜色覆盖入侵块的所有像素，修复条纹。
- 找到入侵色所对应的"来源条纹"（即颜色与入侵块相同的那条条纹）。
- 在来源条纹中，将与入侵块相同列范围、相同行数的对应区域，重新着色为被入侵条纹的颜色。这相当于"交换"了两条条纹在该列范围内的颜色。

Key insight：表面上看是"修复被污染的条纹"，但真正的规则是一个双向颜色交换——入侵块不仅标记了被覆盖的位置，还隐含地指定了来源条纹上需要进行对称标记的位置。解题者需要发现这种"镜像交换"关系。
</new_puzzle>

description：每个彩色对象根据其所在象限获得一种变换方式（旋转或翻转），变换类型由网格中心的指示符编码。

Input structure：
- 背景为黑色（black）。
- 网格的正中心有一个由灰色（grey）像素构成的十字形分隔线（一行加一列），将网格分为四个象限（左上、右上、左下、右下）。
- 十字交叉点处有一个 3×3 的"指示器"区域，四个角各占一个像素，每个角的像素颜色编码了对应象限的变换类型：blue 表示顺时针旋转 90°，red 表示逆时针旋转 90°，green 表示水平翻转，yellow 表示垂直翻转。指示器中心和十字臂为灰色。
- 每个象限中有一个由单色像素组成的不规则小对象（4-连通，颜色非黑非灰，且与指示器角的四种颜色不同），对象不接触灰色分隔线。

- 读取指示器四个角像素的颜色，确定每个象限对应的变换类型。
- 对每个象限中的对象，以该对象的 bounding box 中心为变换中心，施加该象限对应的变换。
- 变换后的对象放置回其原始 bounding box 中心位置。
- 移除灰色十字线和指示器，输出网格仅保留黑色背景和变换后的四个对象。

Key insight：解题者首先需要注意到十字交叉点处的 3×3 指示器，然后破译四个角像素颜色与变换类型之间的映射关系（这需要对比多个样例），最后对每个象限中的对象正确施加变换——关键是指示器的颜色编码需要从样例中归纳而非先验知识。
</new_puzzle>

description：将网格中的多个"信号塔"同时向外广播同心方形波纹，波纹相遇处按颜色混合规则生成新颜色。

Input structure：
- 背景为黑色（black）。
- 网格中有若干单像素的"信号塔"，每个信号塔是一个孤立的彩色像素，颜色为 blue、red 或 yellow 之一。
- 信号塔之间有足够的距离，使得波纹扩展时能观察到交叠区域。

Rule：
- 每个信号塔向外发射同心方形波纹（即以信号塔为中心，Chebyshev 距离为 1、2、3… 的方形环），但只绘制奇数环（第 1 环、第 3 环、第 5 环……），偶数环保持黑色。
- 每个波纹环的颜色与信号塔颜色相同。
- 当两个不同颜色信号塔的波纹环覆盖同一个像素时，采用颜色混合：blue + red = magenta，blue + yellow = green，red + yellow = orange。三色同时覆盖则变为 grey。
- 信号塔本身的像素保持原色不变。
- 波纹扩展到网格边界即停止。

Key insight：解题者需要先发现波纹只出现在奇数距离处（偶数距离为空），这解释了为什么波纹呈现间隔条纹而非连续扩散；然后需要归纳出两色交叠区域的颜色混合规则——这两层规律必须同时掌握才能正确预测输出。
</new_puzzle>

description：网格中的每个封闭"容器"形状内含有散落的彩色像素，需要将这些像素按颜色分组后，在容器内部按容器开口方向重新排列为紧密的彩色柱状堆叠。

Input structure：
- 背景为黑色（black）。
- 网格中有若干由 grey 像素绘成的"容器"——每个容器是一个矩形框，但恰好有一条边缺失（即三面封闭、一面开口的 U 形结构）。开口方向可以朝上、下、左或右。
- 每个容器内部散布着若干彩色像素（非黑非灰），颜色可能有多种，每种颜色出现一个或多个像素。

Rule：
- 确定每个容器的开口方向（缺失边所在的方向）。
- 收集容器内部所有彩色像素，按颜色分组。
- 将像素按组重新排列：以与开口方向相反的墙壁为底（即像素"沉"到封闭端），每种颜色形成一条紧贴封闭端的连续柱（柱的方向与开口方向平行）。
- 颜色组的排列顺序：在垂直于开口方向的轴上，按该颜色组中像素的原始平均坐标从小到大排列（即保持颜色组间的大致相对位置）。
- 同组内像素沿柱方向紧密排列，从封闭端开始堆叠。
- 容器灰色边框保持不变，容器内部未被填充的区域变为黑色。

Key insight：解题者需要先识别每个容器的开口方向（通过观察矩形框缺少哪条边），再理解开口方向决定了"重力方向"（像素沉向封闭端），最后发现颜色分组的排列顺序取决于原始分布位置——开口方向编码了物理重力，颜色间的空间关系被保留为排列顺序。
</new_puzzle>

description：网格被分为左右两个面板：左侧面板包含若干带有缺口的彩色矩形框，右侧面板包含与缺口形状匹配的彩色碎片；将碎片嵌入对应框的缺口中，并根据嵌入后框是否完整来决定框的填充方式。

Input structure：
- 背景为黑色（black）。
- 一条垂直的灰色（grey）分隔线将网格分为左右两个面板。
- 左侧面板中有若干彩色矩形框（仅绘制边框，内部为黑色），每个框的某一条边上有一个连续的缺口（缺少若干像素的凹陷）。每个框颜色不同。
- 右侧面板中有若干小型彩色碎片（4-连通单色对象），每个碎片的颜色与左侧某个框的颜色相同，碎片的形状恰好能填入对应颜色框的缺口（形状和尺寸完全匹配）。
- 可能有一个框在右侧找不到对应碎片（缺口无法修复）。

Rule：
- 对每个左侧的框，在右侧面板中找到同色碎片。
- 将碎片嵌入框的缺口位置，使框的边框变得完整。
- 如果框成功修复为完整矩形框，则将框内部用该框的颜色实心填充。
- 如果框在右侧没有对应碎片（无法修复），则框保持原样（仅边框，内部黑色，缺口仍在）。
- 输出中移除灰色分隔线和右侧面板，仅保留左侧面板区域。

Key insight：解题者需要完成三层推理：（1）通过颜色匹配找到框与碎片的配对关系；（2）理解碎片是用来填补缺口的"拼图块"；（3）发现修复完整性决定了最终的填充/不填充结果——只有完整修复的框才会被填满，这一条件规则需要从样例中归纳。
</new_puzzle>
