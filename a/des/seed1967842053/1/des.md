description：根据封闭区域内部的孔洞数量，在色板中查找对应颜色，用该颜色重新填充该封闭区域。

Input structure：
- 背景为黑色。
- 网格上方有一行色板行：从左到右排列若干种颜色的单像素色块，相邻色块之间用黑色间隔。色板中第 k 个色块（从 1 开始计数）对应"孔洞数量 = k"。
- 色板行下方隔一行黑色分隔行后，是主区域。主区域中有若干个由同一种前景色（例如 grey）绘制的封闭形状。每个形状是一个连通的边框环（4-连通），其内部可能包含零个或多个黑色孔洞（即被边框完全包围的黑色连通区域）。
- 不同封闭形状之间互不接触。

Rule：
- 对主区域中的每个封闭形状，计算其内部的黑色孔洞数量 N（N ≥ 1）。
- 在色板行中找到第 N 个色块的颜色 C。
- 将该封闭形状的所有边框像素重新涂为颜色 C，孔洞保持黑色不变。
- 色板行和分隔行在输出中保持不变。

Key insight：孔洞数量是一个需要主动识别和计数的视觉属性，它作为索引在色板中查找颜色；解题者需要先发现"孔洞数→色板索引"的映射关系，再发现重涂规则。
</new_puzzle>

<new_puzzle>
description：将散落的箭头形状解读为方向指令，沿箭头方向将同色源方块推送到目标位置，并在路径上留下渐变痕迹。

Input structure：
- 背景为黑色。
- 网格中有若干彩色正方形方块（3×3 实心），每个方块颜色不同。
- 每个方块的正上方、正下方、正左方或正右方（恰好一个方向）紧邻放置一个同色的箭头标记。箭头标记由 3 个像素组成：一个像素位于尖端，两个像素组成尖端后方的横排或竖排（形成 T 字形的一半），箭头的尖端方向即为推送方向。具体而言：向右箭头为第一列一个像素居中、第二列上下两个像素；向左箭头为第二列一个像素居中、第一列上下两个像素；向下箭头为第一行左右两个像素、第二行一个像素居中；向上箭头为第二行左右两个像素、第一行一个像素居中。
- 箭头标记与其对应方块之间无间隔，直接相邻。

Rule：
- 每个方块沿其箭头指示的方向滑动，直到方块的前沿碰到网格边界或另一个已固定的方块为止。
- 方块按照滑动距离从大到小的顺序依次处理（滑动距离最远的先移动并固定）。
- 方块滑动后，其原始位置到最终位置之间的路径上（不含最终方块位置），每个经过的列或行用该方块颜色的单像素宽线条标记。
- 箭头标记本身在输出中被擦除（变为黑色）。

Key insight：解题者首先需要识别 3 像素的 T 形标记编码了方向信息，然后需要发现处理顺序取决于滑动距离排序，最后才能正确推导所有方块的最终位置——三层推理环环相扣。
</new_puzzle>

description：将网格中对称轴两侧不对称的像素识别为"损坏"，用轴对称位置的颜色修复它们，再根据被修复像素的总数选择输出边框颜色。

Input structure：
- 背景为黑色。
- 网格右侧有一列色板列：从上到下排列若干种颜色的单像素色块，相邻色块之间用黑色间隔。色板中第 k 个色块（从 1 开始计数）对应"损坏像素数量 = k"。
- 色板列左侧隔一列黑色分隔列后，是主区域。主区域包含一个或多个彩色图案，每个图案本应具有左右镜像对称性，但其中若干像素被替换为 maroon 色（表示损坏）。
- 每个图案被一个单像素宽的 grey 边框包围，边框形成矩形。不同图案的边框之间互不接触。

Rule：
- 对每个被 grey 边框包围的图案区域：
  1. 找到图案内容（边框内部）的垂直对称轴（即水平方向的中轴线列）。
  2. 将所有 maroon 像素识别为损坏点，用其关于对称轴的镜像位置上的颜色替换（镜像位置一定是非 maroon 的正常像素）。
  3. 计算该图案中被修复的 maroon 像素总数 M。
  4. 在色板列中找到第 M 个色块的颜色，将该图案的 grey 边框全部重涂为此颜色。
- 色板列和分隔列在输出中保持不变。

Key insight：第一层推理需要发现 maroon 是损坏标记且图案具有对称性可用于修复；第二层推理需要发现修复数量与色板的索引映射关系决定了边框颜色——两层归纳缺一不可。
</new_puzzle>

description：根据容器内部填充物的层数确定旋转角度，将每个容器及其内容物整体旋转后放回原位。

Input structure：
- 背景为黑色。
- 网格中有若干个互不接触的"容器"。每个容器由一种颜色绘制的 U 形、L 形或直角槽状边框构成（边框为单像素宽，开口朝向上、下、左或右中的某一个方向）。
- 每个容器的凹槽内部从封闭底部开始，有若干层不同颜色的水平或垂直条纹填充（每层为一行或一列同色像素，层与层紧邻排列，从封闭端向开口端堆叠）。填充层不会超出容器开口。
- 不同容器的填充层数不同，范围为 1 到 3 层。

Rule：
- 对每个容器，计算其内部填充层的数量 N。

- 旋转以容器的外接矩形中心为轴心，旋转后放回该外接矩形所在位置。
- 若旋转后容器内容超出原外接矩形范围，则扩展到新的外接矩形位置（保证不与其他容器重叠）。

Key insight：解题者先要识别出 U 形边框的开口方向和内部分层结构，再发现填充层数编码了旋转次数，最后将整体旋转正确角度——关键在于"层数→旋转量"的非显然映射。
</new_puzzle>

description：在棋盘状网格中，根据每个彩色区域的邻居区域数量，在该区域中心种下对应大小的十字花纹。

Input structure：
- 网格被单像素宽的黑色网格线分割成规则的矩形单元格阵列（例如每个单元格为 5×5，网格线将它们分隔开）。
- 每个单元格内部填充为某种纯色（非黑色），颜色从可用色集中选取。相邻单元格（共享网格线边的单元格）颜色可能相同也可能不同。
- 多个颜色相同且通过共享网格线边相邻的单元格构成一个"彩色区域"（类似连通分量，但以单元格为单位，非像素）。

Rule：
- 对每个彩色区域，计算与其相邻（通过网格线边共享边界）的其他不同色区域的数量 K。
- 在该区域每个单元格的中心像素绘制一个白色十字标记。十字标记的每条臂长度为 K 个像素（从中心向上、下、左、右各延伸 K 个像素）。若臂超出单元格内部边界则截断到单元格边界。
- 若 K = 0（该区域没有不同色邻居），则不绘制任何标记。
- 黑色网格线保持不变。

Key insight：解题者需要先理解单元格级别的连通区域划分（而非像素级别），再发现"不同色邻居区域数→十字臂长"的映射关系——区域划分和邻居计数都需要在单元格抽象层面推理，而非直接在像素层面操作。
</new_puzzle>

description：将网格中的多个小图案视为拼图碎片，根据边缘颜色匹配规则拼合成一个无缝矩形，并移除拼接边上的匹配色带。

Input structure：
- 背景为黑色。
- 网格中散落着若干个矩形彩色图案碎片，碎片之间互不接触。
- 每个碎片的某些边缘（上、下、左、右）有一行或一列单像素宽的纯色边带（边带颜色与碎片内部主体颜色不同）。没有边带的边缘直接以碎片内部颜色结束。
- 两个碎片如果各自有一条边带且边带颜色相同、边带长度相同，则这两条边带是匹配的拼接口：一个碎片的右边带与另一个碎片的左边带匹配，或一个碎片的下边带与另一个碎片的上边带匹配。

Rule：
- 找到所有匹配的边带对，将碎片按匹配关系拼接在一起。
- 拼接时，两个匹配的边带重叠合并并从输出中移除（即拼接缝处不保留边带像素，两碎片的内部内容直接相邻）。
- 没有边带的边缘即为最终拼合矩形的外边界。
- 输出仅包含拼合完成的矩形，裁剪掉所有黑色背景。

Key insight：解题者首先需要识别边缘色带是拼接编码而非图案内容，然后通过颜色匹配确定碎片间的邻接关系和方向，最后理解边带在拼合时被移除——从"分散碎片"到"拼接规则"到"边带消除"构成三层推理。
</new_puzzle>

description：根据每个封闭围栏内种子像素的颜色，从网格边缘的样板行中查找对应的填充纹理，将该纹理平铺填满围栏内部。

Input structure：
- 背景为黑色。
- 网格最上方若干行是样板区：包含若干个小矩形纹理样板（例如 2×2 或 3×3 的重复单元），每个样板用不同的单色边框包围。样板之间用黑色间隔。样板边框的颜色即为该纹理的"键色"。
- 样板区下方隔一行黑色分隔行后，是主区域。主区域中有若干个用 grey 像素绘制的封闭围栏（单像素宽的闭合环形边框，形状为矩形）。
- 每个围栏内部恰好有一个单像素的"种子"，种子的颜色与某个样板边框的键色相同。除种子外围栏内部全为黑色。

Rule：
- 对每个围栏，读取其内部种子像素的颜色，找到样板区中具有相同键色边框的纹理样板。
- 提取该样板边框内部的纹理图案（不含边框本身）。
- 将该纹理图案以平铺方式填充围栏内部的所有黑色区域（从围栏内部左上角开始，纹理图案按行列重复铺设，超出围栏内部范围的部分截断）。种子像素本身也被纹理覆盖。
- 围栏边框、样板区和分隔行在输出中保持不变。

Key insight：解题者需要先发现样板区的边框颜色是索引键，再发现围栏内的种子颜色是查找键，最后理解纹理以平铺方式填充——"键色匹配"和"平铺填充"两个非显然规则构成双层推理。
</new_puzzle>

<new_puzzle>
description：识别网格中形状相同但大小不同的同色对象对，将小对象放置到大对象内部的对应位置形成嵌套，同时小对象原位置用大对象颜色的缩小轮廓替代。

Input structure：
- 背景为黑色。
- 网格中有若干个前景对象，每种颜色恰好出现两个对象。
- 同色的两个对象形状相同（其中一个是另一个的等比缩放版本，缩放比例为 2 倍），但大小不同：一个较大，一个较小。大对象是空心的（仅有单像素宽的边框轮廓），小对象是实心的。
- 不同颜色的对象对之间互不接触，且大对象内部足以容纳对应的小对象。

Rule：
- 对每对同色对象，将小的实心对象从原位置移除，放置到大的空心对象内部的正中央位置（若无法精确居中则偏左上）。
- 小对象原来所在的位置，绘制一个与小对象外接矩形相同大小的空心边框轮廓，颜色与该对象颜色相同（即用空心版本替代原来的实心版本）。
- 大对象的空心边框保持不变，内部现在包含了移入的小实心对象。

Key insight：解题者需要先发现同色对象的形状匹配关系和大小差异，再发现"实心移入空心内部、原位留空心"的交换式嵌套规则——形状匹配是隐蔽的第一层推理，嵌套放置是第二层。
</new_puzzle>
