用每个封闭区域内部的标记颜色重绘该区域的边界，同时根据标记像素的数量决定边界的生长方向。

Input structure：
- 背景为 black。网格中有若干由 grey 像素围成的封闭区域（一像素宽的闭合轮廓，形状各异，如矩形、L形等）。
- 每个封闭区域内部恰好包含一种非 black、非 grey 的标记颜色像素（如 red、blue、green 等），标记像素数量为 1 到 4 个不等，分散在区域内部。
- 不同封闭区域的标记颜色可以相同也可以不同。

Rule：
- 对每个封闭区域，识别其内部标记像素的颜色 C 和数量 N。
- 将该区域的 grey 边界像素全部重绘为颜色 C。
- 若 N = 1，边界保持原始一像素宽度不变。
- 若 N = 2，将边界向外扩展一层——在原边界外侧所有 4-邻接的 black 像素也涂为 C，形成两像素宽的边界。
- 若 N = 3，边界向内收缩一层——原边界保留为 C，同时将边界内侧 4-邻接的原区域内部像素也涂为 C。
- 若 N = 4，边界同时向内和向外各扩展一层，形成三像素宽的边界。
- 内部标记像素在输出中被清除为 black。
- 不属于任何封闭区域边界的 grey 像素保持不变。

Key insight：
- 标记颜色决定边界的重绘色，而标记数量编码了边界的生长方向（仅保持、外扩、内缩或双向扩展）。解题者需要同时归纳颜色映射规则和数量到生长方向的对应关系，这两个维度需要独立发现。
</new_puzzle>

将散落的彩色碎片滑入各自匹配的框架中，匹配依据是碎片的轮廓与框架内壁锯齿的空间互补性。

Input structure：
- 背景为 azure。网格中有若干由 maroon 像素绘制的矩形框架，每个框架内壁带有不规则的凹凸锯齿——部分内壁像素向内突出或缺失，形成独特的边缘图案。
- 框架内部其余区域为 azure（空的）。
- 网格中散落着若干小型彩色碎片（每个碎片为一种独特颜色，如 red、blue、green 等），碎片为 4-连通区域，每个碎片的外形轮廓各不相同。
- 每个碎片恰好与某个框架内壁的某段锯齿互补：碎片的凸出部分恰好对应框架内壁的凹陷处，碎片放入后与框架内壁严丝合缝。
- 每个框架只对应一个碎片，每个碎片只对应一个框架。

Rule：
- 对每个碎片，遍历所有框架，寻找唯一的一个框架使得碎片无需旋转、仅通过平移即可嵌入框架内部并与某段内壁锯齿完全互补。
- 将碎片平移到匹配框架内的嵌合位置，在对应像素上绘制碎片颜色。
- 清除碎片原始位置的像素为 azure。
- 框架本身（maroon 像素）及未被碎片覆盖的框架内部区域保持不变。

Key insight：
- 匹配关键不是颜色、面积或数量，而是碎片形状与框架内壁锯齿在空间上的互补性。解题者需要先注意到框架内壁的不规则凹凸不是噪声而是有意义的图案，再通过形状匹配找到每个碎片的归宿。
</new_puzzle>

<new_puzzle>
根据种子像素在单元格内的象限位置，在该单元格中绘制特定方向和相位的对角条纹。

Input structure：
- 背景为 black。网格被 grey 线条均匀分隔成若干大小相同的正方形单元格（grey 线为一像素宽的完整水平线和垂直线，构成规则网格）。每个单元格内部尺寸相同（例如 5×5）。
- 部分单元格内恰好有一个彩色种子像素（非 black、非 grey），位于单元格内部的某个位置。其余单元格为空（全 black）。

Rule：
- 对每个含有种子像素的单元格，确定种子像素的颜色 C 以及其在单元格内的象限位置（以单元格中心像素为参照划分四个象限）：
  - 左上象限（种子在中心的左上方）：在单元格内绘制主对角线方向（左上→右下）的条纹，填充所有满足"行偏移与列偏移之差为偶数"的像素为 C（偏移相对于单元格左上角）。
  - 右下象限：同样绘制主对角线方向条纹，但填充"行偏移与列偏移之差为奇数"的像素为 C（与左上象限条纹错开一格）。
  - 右上象限：绘制副对角线方向（右上→左下）的条纹，填充"行偏移与列偏移之和为偶数"的像素为 C。
  - 左下象限：副对角线方向条纹，填充"行偏移与列偏移之和为奇数"的像素为 C。
- 种子像素本身被条纹覆盖。Grey 分隔线和空单元格保持不变。

Key insight：
- 种子像素的象限位置同时编码了两个独立参数：对角线方向（主对角线 vs 副对角线）和条纹相位（奇数 vs 偶数），解题者需要将一个二维的位置信号拆解为两个一维的绘制参数。
</new_puzzle>

<new_puzzle>
每个彩色对象的"尾巴"指示移动方向，同色边框标尺的长度决定移动距离，对象移走后留下 grey 尾迹。

Input structure：
- 背景为 black。网格四条边上各有一段彩色边框标尺：每条标尺是紧贴网格边缘的一行或一列连续同色像素（如 red 占据顶边最左 3 格、blue 占据右边最上 5 格等），颜色各不相同，长度各不相同。
- 网格内部有若干小型彩色对象（4-连通，2-6 像素大小，形状各异），每个对象的颜色恰好与某条边框标尺的颜色匹配。每种颜色只出现一个对象和一条标尺。
- 每个对象恰好有一个"尾巴"——从对象主体延伸出的一个单像素突出，使得去掉该像素后剩余部分仍然 4-连通。尾巴的方向为上、下、左、右之一（从对象主体指向尾巴像素的方向）。

Rule：
- 对每个彩色对象，尾巴方向即为移动方向 D。
- 找到与该对象同色的边框标尺，标尺的像素长度 L 即为移动距离。
- 将整个对象（含尾巴）沿方向 D 平移 L 格。
- 对象原始位置的每个像素变为 grey（留下尾迹）。
- 若平移会使对象超出网格边界，则对象在刚好触及边界时停止。
- 边框标尺在输出中保持不变。

Key insight：
- 解题者需要独立发现三层编码：（1）尾巴突出的方向编码了移动方向；（2）颜色匹配将对象链接到边框标尺；（3）标尺长度编码了移动距离。三个信息来源分别是对象的局部几何形状、颜色匹配和边框的全局属性。
</new_puzzle>

根据封闭围栏内"投票像素"的多数颜色决定获胜方，将围栏外通过缺口相连的落败色区域重绘为获胜色。

Input structure：
- 背景为 black。网格中有若干由 grey 像素围成的封闭围栏（闭合的一像素宽多边形轮廓）。
- 每个围栏内部包含若干彩色像素，恰好使用两种不同颜色（如 red 和 blue），两种颜色的像素数量不等。
- 每个围栏的外壁上恰好有两个缺口（各缺失一个 grey 像素的位置）。每个缺口外侧紧邻一个由纯色填充的 4-连通矩形区域（称为"候选区域"）。两个候选区域的颜色分别与围栏内部出现的两种颜色一一对应。
- 不同围栏之间互不接触，围栏及其外部候选区域构成独立组。

Rule：
- 对每个围栏，统计内部两种颜色像素的数量，数量严格更多的颜色为"获胜色"，另一个为"落败色"。
- 找到围栏外侧通过两个缺口分别连接的两个候选区域。
- 将颜色为落败色的候选区域整体重绘为获胜色。
- 围栏内部所有彩色像素清除为 black。
- Grey 围栏像素保持不变（含缺口位置仍为 black）。获胜色的候选区域保持不变。

Key insight：
- 解题者需要两层独立推理：（1）在围栏内部通过多数投票确定获胜色——这需要归纳出"多数原则"而非面积、位置等其他属性；（2）通过缺口的空间连通性找到外部候选区域并将投票结果映射到空间操作。围栏同时充当投票容器和连接外部区域的拓扑中介。
</new_puzzle>

<new_puzzle>
在分层地图中，每个高度层的颜色环向内收缩一格后露出下层颜色，最终形成嵌套等高线效果。

Input structure：
- 网格表示一幅俯视"地形图"。背景为 black，代表最低层（高度 0）。
- 网格中有若干彩色区域，每种颜色代表一个高度层。高度层的排列满足嵌套关系：高层区域完全被低层区域包围（如 blue 区域包围 red 区域，red 区域包围 green 区域）。
- 高度层从外到内依次递增，颜色顺序在所有样例中固定（例如外层为 blue、中层为 red、内层为 green）。
- 每个颜色区域是一个 4-连通的区域，形状不规则但始终为凸形或近凸形。

Rule：
- 输出网格尺寸与输入相同。
- 每个颜色区域向内收缩一格：将该颜色区域的最外圈像素（即 4-邻接方向上至少有一个不属于该区域的像素的那些像素）移除。
- 被移除的像素显示为其下一层的颜色：最外层颜色被移除后露出 black（高度 0）；中间层被移除后露出外层颜色；内层被移除后露出中间层颜色。
- 若某个颜色区域收缩后完全消失（面积太小），则该区域所有像素显示为下层颜色。
- 不属于任何彩色区域的 black 像素保持不变。

Key insight：
- 解题者需要先识别出颜色区域之间的嵌套包含关系（从而确定高度层序），再理解每层独立收缩并露出下层的"剥皮"操作。嵌套关系的判断和收缩操作是两个独立的推理步骤——单纯观察收缩无法解题，还必须理解层级关系才能确定收缩后露出的颜色。
</new_puzzle>

<new_puzzle>
将每根彩色线段折叠到其同色锚点处，折叠方向由锚点相对于线段中点的位置决定，折叠后线段的两半重叠并合成新颜色。

Input structure：
- 背景为 black。网格中有若干彩色直线段（水平或垂直），每根线段为单一颜色、一像素宽。
- 每根线段附近（不在线段上）恰好有一个同色的单独锚点像素。
- 网格中还有一个"合成图例"：一个小区域展示两种颜色叠加后的结果色。例如图例中 red 像素旁有 blue 像素，下方对应一个 magenta 像素，表示 red + blue = magenta。

Rule：
- 对每根线段，找到其同色锚点。锚点投影到线段所在直线上的位置即为折叠点。
- 将线段在折叠点处对折：较短的一半翻转到较长的一半上（若折叠点不在中点，则短半段翻到长半段上）。折叠后短半段与长半段的一部分像素重叠。
- 重叠区域的像素不保留原色，而是查阅合成图例：若两根不同颜色的线段重叠区域相交，重叠像素显示为图例中对应的合成色。
- 同一根线段自身折叠重叠的部分保持原色不变。
- 折叠后，线段仅占用折叠后的位置（原始位置中不再被占用的像素清除为 black）。
- 锚点在输出中被清除为 black。合成图例保持不变。

Key insight：
- 解题者需要三层推理：（1）通过颜色匹配确定每根线段的锚点，并理解锚点投影到线段上的位置是折叠点；（2）执行折叠操作确定重叠区域；（3）通过合成图例将重叠处的颜色混合规则具体化。折叠机制和颜色合成机制是两个独立发现的规则层。
</new_puzzle>

<new_puzzle>
根据箭头指向选择源图案的某一行或某一列，将其复制到箭头所在的空白条中并沿箭头方向对齐。

Input structure：
- 背景为 black。网格中有一个矩形"源图案"区域，由多种颜色填充，形成一个小型彩色图案（例如 5×5 的图案块）。
- 网格中另有若干 grey 条带（一像素宽的水平或垂直直线段），每根条带的一端有一个彩色箭头标记。箭头由 3 个同色像素组成尖头形状：一个顶点像素加两个对角像素（形成 "V" 形），箭头的尖端指向条带的延伸方向。
- 箭头的颜色是源图案中出现的某种颜色。
- 水平条带的长度等于源图案的宽度；垂直条带的长度等于源图案的高度。

Rule：
- 对每根 grey 条带及其箭头标记：
  - 若条带为水平方向：在源图案中找到箭头颜色出现次数最多的那一行，将该行的像素序列复制到条带上，替换 grey 像素。
  - 若条带为垂直方向：在源图案中找到箭头颜色出现次数最多的那一列，将该列的像素序列复制到条带上，替换 grey 像素。
  - 复制时保持像素的相对顺序（水平条带保持左到右，垂直条带保持上到下）。
- 箭头标记在输出中被清除为 black。
- 源图案本身保持不变。

Key insight：
- 箭头颜色不是用于给条带上色的，而是作为索引键在源图案中选择特定的行或列。解题者需要先发现箭头颜色与源图案的行/列选择之间的关系（最多出现次数），再将选中的行列内容复制到条带上。颜色的角色从"外观属性"变为"查找键"是核心认知跳跃。
</new_puzzle>
