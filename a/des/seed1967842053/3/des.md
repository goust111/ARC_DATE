- `description`：根据彩色种子像素在封闭围栏内"生长"出同心矩形环，生长层数由围栏外部同色标记像素的数量决定。

- `Input structure`：
  - 背景为黑色（black）。
  - 网格中有若干用不同颜色绘制的一像素宽封闭矩形围栏（hollow rectangular frames），每个围栏颜色各不相同。
  - 每个围栏的正内部（interior）恰好有一个与围栏颜色不同的单像素"种子"，种子颜色在整个网格中唯一对应该围栏。
  - 在围栏外部、远离所有围栏的区域，散落着若干与各种子颜色相同的独立标记像素。

- `Rule`：
  - 对每个围栏，找到其内部的种子像素颜色 C，然后统计网格中围栏外部颜色为 C 的标记像素总数 N。
  - 以种子像素为中心，用种子颜色 C 向外逐层绘制同心矩形环，共绘制 N 层。每层环比上一层在四个方向各扩展一个像素。
  - 若生长的环碰到围栏边界，则在该边界处停止（被围栏像素裁剪，不覆盖围栏本身）。
  - 围栏外部的标记像素在输出中被擦除为背景色。

- `Key insight`：
  - 围栏外部散落的标记像素不是装饰，而是"燃料计数器"——其数量决定种子向外扩展的层数。解题者需要先建立"种子颜色与围栏"的配对关系，再将外部同色像素的计数转化为几何生长的步数，形成两层独立的推理。
</new_puzzle>

<new_puzzle>
- `description`：将网格中散落的彩色碎片按颜色归类，根据碎片上附着的方向标记旋转后拼合填满参考轮廓的内部区域。

- `Input structure`：
  - 背景为灰色（grey）。
  - 网格左侧有一个用红色（red）绘制的单像素宽封闭轮廓（目标形状），轮廓内部为背景色。
  - 网格右侧散落着若干彩色碎片（4-连通的单色块），每个碎片颜色各不相同，且所有碎片恰好可以无重叠地拼合填满目标轮廓的内部区域。
  - 每个碎片的边缘恰好有一个绿色（green）单像素标记，标记位于碎片四个方向（上、下、左、右）边界上某一侧。

- `Rule`：
  - 绿色标记在碎片上的相对位置指示碎片需要的旋转：标记在碎片顶部表示不旋转（0度）；标记在碎片右侧表示顺时针旋转 90 度；标记在碎片底部表示旋转 180 度；标记在碎片左侧表示顺时针旋转 270 度。
  - 旋转后，移除所有绿色标记像素，将每个碎片平移到目标轮廓内部使其恰好拼满轮廓内部区域，不留空隙不重叠。
  - 输出仅保留红色轮廓和填充后的彩色碎片，背景保持灰色。

- `Key insight`：
  - 解题者不仅需要识别碎片的形状与轮廓区域的匹配关系（空间拼图层），还需要先从绿色标记的方位推断出每块碎片的旋转角度（方向编码层），两层推理缺一不可。
</new_puzzle>

- `description`：将网格中每个彩色封闭图形按其内部孔洞数量分组，同组图形用图例指定颜色的折线相连。

- `Input structure`：
  - 背景为黑色（black）。
  - 网格上半部分是图例区：包含若干水平排列的小方块，每个小方块由特定颜色的实心正方形组成，正方形内挖有 0、1、2 或 3 个单像素的黑色孔洞。每个小方块展示了"该颜色对应孔洞数为 K"的映射关系（颜色各不相同）。
  - 网格下半部分散布着若干用橙色（orange）像素绘制的 4-连通封闭图形，每个图形的内部（被橙色完全包围的黑色区域）包含 0 至 3 个不等的单像素孔洞。

- `Rule`：
  - 统计下半部分每个橙色图形内部的孔洞数量 K。
  - 从图例区查找孔洞数为 K 对应的连线颜色 C。
  - 将所有孔洞数相同的图形用颜色 C 的折线首尾相连：连线连接每对同组图形中心点之间最近的边界像素对，走先水平后垂直的 L 形折线。
  - 若某组只有一个图形，则不画连线，但将该图形内部所有孔洞像素填充为对应颜色 C。

- `Key insight`：
  - 图例区的小方块既是颜色样本又是孔洞计数的视觉编码——解题者需要先"数图例中的孔洞来解码映射表"，再"数下方图形中的孔洞来分类对象"，最后用映射表给出的颜色来绘制连线。核心难点在于发现图例中的孔洞数量本身就是分类键。
</new_puzzle>

<new_puzzle>
- `description`：在嵌套矩形围栏中找到同色标记对，沿共线方向铺设铁轨，铁轨样式（实线或虚线）由标记点的围栏嵌套深度之和的奇偶性决定。

- `Input structure`：
  - 背景为黄色（yellow）。
  - 网格中有若干用黑色（black）像素绘制的一像素宽嵌套矩形围栏（concentric rectangular frames），围栏之间有间隔。
  - 散布在网格各处的是成对的彩色标记像素（每种非黑色、非黄色的前景色恰好出现两次），两个同色标记必定位于同一行或同一列上。
  - 每个标记像素位于某一层围栏的内部或所有围栏的外部。

- `Rule`：
  - 对每对同色标记 A 和 B，确定它们共享的行或列，沿该行或列从 A 到 B 铺设铁轨。
  - 统计标记 A 所在位置被多少层黑色围栏包围（即"嵌套深度"），记为 dA；同理得到 dB。取 D = dA + dB。
  - 若 D 为偶数（包含 0），铁轨为实线：将 A 到 B 之间该行或列的所有背景像素都涂为标记颜色。
  - 若 D 为奇数，铁轨为虚线：从 A 出发，沿路径交替涂色和跳过（涂一个像素、跳一个像素、涂一个像素，依此类推），遇到黑色围栏像素时跳过围栏但不中断交替节奏。
  - 黑色围栏像素本身不被覆盖，保持黑色。

- `Key insight`：
  - 解题者需要完成三层推理：首先识别同色标记的配对关系，然后判断每个标记的围栏嵌套深度，最后根据深度之和的奇偶性选择实线或虚线的铺设模式。嵌套深度的判定是纯视觉的（数包围层数），而奇偶性决定样式的规则需要从多个样例中归纳。
</new_puzzle>

<new_puzzle>
- `description`：根据散落的 L 形箭头指示物的方向、臂长和颜色，将同色矩形容器内的填充图案沿箭头方向循环滚动。

- `Input structure`：
  - 背景为灰色（grey）。
  - 网格中有若干矩形容器，每个容器由一种颜色的单像素宽边框围成，内部填充着由黑色（black）和 azure 像素组成的二值图案。不同容器的边框颜色各不相同。
  - 每个容器附近有一个同色的 L 形箭头指示物：由一条水平臂和相连的一条垂直短杠（1 像素）组成，短杠位于水平臂的一端。短杠在臂的上方表示方向"向上"，在下方表示"向下"，在左端表示"向左"，在右端表示"向右"。水平臂的像素数量即为臂长。
  - 箭头的颜色与且仅与一个容器的边框颜色匹配。

- `Rule`：
  - 对每个容器，找到与其边框同色的箭头。
  - 读取箭头指示的方向 D 和臂长 L。
  - 将容器内部的图案沿方向 D 循环滚动 L 步：图案像素沿 D 方向平移 L 格，超出容器内部边界的部分从对面重新进入。
  - 箭头指示物在输出中保留不变，容器边框不变。

- `Key insight`：
  - 箭头同时编码了三种信息：颜色决定作用对象、短杠位置决定滚动方向、臂长决定滚动步数。解题者需要先破译箭头的三重编码机制，再将其应用于对应容器的图案变换——箭头解码和图案滚动构成两层推理。
</new_puzzle>

<new_puzzle>
- `description`：将多色条纹带按照颜色优先级塔排序，同时根据条纹带中主键色段长度的奇偶性决定是否镜像翻转条纹带内部。

- `Input structure`：
  - 背景为黑色（black）。
  - 网格左侧有一个"优先级塔"：由若干不同颜色的单行色块从上到下堆叠而成，形成一个垂直的颜色序列（最上面的颜色优先级最高，依次递减）。
  - 网格右侧有若干水平的多色条纹带，每条条纹带占据一行，由左到右排列着若干长度不等的连续色段。每条条纹带中恰好有一个色段的颜色出现在优先级塔中（称为"主键色段"），其余色段颜色不在塔中出现。
  - 各条纹带之间用一行黑色背景分隔。

- `Rule`：
  - 找到每条条纹带中的主键色段及其颜色。
  - 根据优先级塔中该颜色的位置（从上到下的排名），对所有条纹带重新排列：优先级最高的颜色对应的条纹带排在最上面。
  - 在重新排列的同时，检查每条条纹带的主键色段长度：若长度为奇数则保持条纹带原始的左右顺序，若长度为偶数则将整条条纹带左右镜像翻转。
  - 输出中条纹带之间仍保留一行黑色分隔。

- `Key insight`：
  - 优先级塔提供了行间排序的依据，但解题者还需要发现第二层规则：主键色段的长度奇偶性控制着条纹带内部是否镜像翻转。排序层和镜像层各自需要独立归纳，且镜像条件隐藏在色段长度中而非颜色本身中，增加了隐蔽性。
</new_puzzle>

<new_puzzle>
- `description`：沿彩色管道网络传输信号色块，信号在管道分叉口根据分叉臂的宽度选择较宽的通道继续前进，最终填充管道末端的收集槽。

- `Input structure`：
  - 背景为黑色（black）。
  - 网格中有用蓝色（blue）像素绘制的连通管道网络：管道由宽度为 1 至 3 个像素的水平或垂直通道组成，通道之间通过 T 形分叉口连接。
  - 管道的一个端点（入口）处紧邻一个 2x2 的彩色信号块（颜色非蓝色、非黑色），信号块的朝管道开口的一侧与管道入口端相接。
  - 管道的若干末端（死端）各有一个宽度与末端通道相同、深度为 2 像素的空槽（被蓝色管道壁围成的背景色矩形凹槽）。

- `Rule`：
  - 信号从入口沿管道向前传播，传播方向是沿管道纵向远离入口的方向。
  - 当信号到达分叉口时，比较各分支管道的宽度（像素列数或行数）。信号仅进入宽度严格最大的分支；若最大宽度不唯一，则信号同时进入所有最宽分支（信号复制）。
  - 信号到达死端时，用信号色填满该死端的空槽区域。
  - 管道本身的蓝色像素保持不变，入口处的信号块在输出中被擦除为背景色。

- `Key insight`：
  - 管道宽度不仅是视觉装饰，还是路由选择的关键判据。解题者需要先识别管道的拓扑结构（哪些通道在哪里分叉），然后在每个分叉口比较通道宽度以确定信号流向——拓扑识别和宽度比较构成两层独立推理。
</new_puzzle>
