将散落的彩色碎片按形状匹配填入带缺口的框架中，并根据框架边框颜色对碎片重新着色。

Input structure:
- 背景为黑色。网格中包含若干个由同一种颜色（如 grey）绘制的矩形框架，每个框架的边框完整但内部有一个不规则缺口（缺口区域为背景色）。
- 网格中还散布着若干个由不同颜色绘制的小型不规则形状碎片，每个碎片的形状恰好与某个框架内部的缺口形状完全吻合（平移后重合，无需旋转）。
- 每个框架的四条边中恰好有一条边的颜色与其余三条不同，该特殊边的颜色即为"目标色"。

Rule:
- 对每个框架，在所有散落碎片中找到形状与其内部缺口完全匹配的那一块。
- 将该碎片平移到框架缺口位置，填入缺口。
- 填入后，将碎片的颜色替换为该框架特殊边的颜色（目标色）。
- 框架本身保持不变，未被匹配的碎片不会出现在输出中。

Key insight:
- 第一层推理：通过形状匹配将碎片与框架配对；第二层推理：框架四边中颜色不同的那一条边决定了碎片填入后的最终颜色，而非碎片原本的颜色。

根据种子图案的对称性类型选择对应的铺设策略，将种子图案扩展为周期平铺。

Input structure:
- 背景为黑色。网格左侧有一个小型彩色种子图案（矩形区域，尺寸约 3x3 到 5x5）。
- 网格右侧有一个较大的空白矩形目标区域，其边框由 azure 颜色绘制，内部为背景色。
- 目标区域的宽和高均为种子图案宽和高的整数倍（2 倍或 3 倍）。

Rule:
- 检测种子图案的对称性类型：
  - 若种子图案具有水平反射对称性（左右对称），则用"水平翻转交替"方式铺设：奇数列放原图，偶数列放水平镜像。
  - 若种子图案具有垂直反射对称性（上下对称），则用"垂直翻转交替"方式铺设：奇数行放原图，偶数行放垂直镜像。
  - 若种子图案既无水平也无垂直对称性，则用"180 度旋转交替"方式铺设：棋盘格式排列，白格放原图，黑格放 180 度旋转版本。
- 将铺设结果填入目标区域内部，azure 边框保持不变。

Key insight:
- 解题者必须先判断种子图案属于哪种对称性类别（这本身需要非平凡的观察），然后才能确定使用哪种铺设规则——对称性类型与铺设策略之间的映射关系是隐蔽的，仅靠单个样例难以确定。

<new_puzzle>
从重叠的透明彩色层中还原每层的原始形状，根据层叠顺序线索重新分离绘制。

Input structure:
- 背景为黑色。网格中央是一个由多种颜色混合而成的矩形区域，该区域是若干个单色矩形层叠放的结果——后放的层会遮挡先放的层。
- 网格的顶部边缘有一行单像素的彩色标记点，从左到右排列，每个标记点的颜色对应一个层的颜色，排列顺序即为层叠顺序（最左的标记对应最底层，最右的对应最顶层）。
- 每个层是一个实心矩形，且每个层至少有一个像素在最终叠合结果中可见（即未被完全遮挡）。

Rule:
- 读取顶部标记行确定层的颜色和叠放顺序（从左到右 = 从底到顶）。
- 在叠合区域中，最顶层颜色完全可见；被遮挡的层需要根据可见边缘推断其完整矩形范围。
- 输出时，将所有层按照从底到顶的顺序重新绘制在同样大小的画布上，但每相邻两层之间插入一列背景色作为分隔——即输出宽度 = 所有层矩形宽度之和 + (层数-1) 列分隔列。每个层绘制为其完整的实心矩形（包括在输入中被遮挡的部分），高度与输入叠合区域相同，垂直位置保持原位。

Key insight:
- 第一层推理：从顶部标记读出叠放顺序；第二层推理：对每个被部分遮挡的矩形层，利用其可见的边缘像素推断出完整矩形边界（因为每层都是实心矩形，只需确定四条边的位置）；第三层推理：按序分离展开排列。
</new_puzzle>

<new_puzzle>
用路径网络中的彩色叶子节点作为颜色源，沿连线向内传播颜色，对沿途的灰色节点和连线染色，交汇处保持灰色。

Input structure:
- 背景为黑色。网格中有若干个 3x3 的实心方块作为"节点"，部分节点为彩色（red、blue、green 等），其余节点为 grey。
- 节点之间由单像素宽的 grey 直线段（水平或垂直）连接，形成一个树状路径网络（无环路）。
- 每个彩色节点恰好位于网络的叶子位置（度为 1，即只连接一条线段）。

Rule:
- 从每个彩色叶子节点开始，沿其唯一的连线方向向网络内部传播该颜色。
- 传播过程中，将沿途经过的 grey 连线段和 grey 节点都染为该传播颜色。
- 传播沿路径逐段推进，每条连线段（即两个相邻节点之间的直线段）视为一步，可通过直接数线段数量来确定传播距离。
- 当两个不同颜色的传播在同一条连线段上相遇（即从该线段两端的节点分别被不同颜色到达）时，该连线段保持 grey 不变，两端节点各自保留已到达的颜色。
- 若一个 grey 节点只被一种颜色到达（无论从几条路径），则正常染为该颜色。

Key insight:
- 解题者需要先识别出树状网络结构和彩色叶子的位置，然后模拟从每个叶子同时出发的颜色"洪泛"过程。关键在于发现交汇规则：当两种颜色从一条线段的两端同时到达时，该线段保持灰色成为"边界"——这一规则需要从多个样例中对比染色边界的位置才能归纳出来。
</new_puzzle>

将网格中的多个图案块按照边缘锁扣标记的配对关系拼合成一个完整矩形。

Input structure:
- 背景为黑色。网格中散布着若干个矩形彩色图案块，每个图案块用一种独特的填充色绘制。
- 每个图案块的某些边缘上有 maroon 像素标记，分为两种角色：
  - "凸出"标记：图案块边缘外侧紧邻的一个 maroon 像素，向外凸出一格。
  - "凹入"标记：图案块边缘上的一个像素为背景色（缺口），且该缺口外侧紧邻一个 maroon 像素。
- 每个凸出标记恰好对应另一个图案块上的一个凹入标记。

Rule:
- 识别每个图案块边缘上的凸出（maroon 像素伸出主体外一格）和凹入（边缘有 1 像素背景色缺口，缺口外侧紧邻 maroon 标记）。
- 将凸出与凹入配对：两者必须在互补方向上（如一个朝右凸出对应另一个朝左凹入），且 maroon 标记在所在边上的相对偏移位置（距该边起始端的像素数）相同。
- 按配对关系平移图案块，使每对凸出-凹入对齐嵌合，所有块拼成一个无缝矩形。
- 输出为拼合后的矩形：凸出位置恢复为所属块的填充色，凹入缺口填充为接收方块的填充色，所有 maroon 标记消失。

Key insight:
- 第一层推理：识别 maroon 像素的双重语义——凸出标记和凹入标记的视觉表现不同（凸出在块外、凹入则是块边缘的缺口加外侧标记），需要区分这两种角色。第二层推理：通过标记在边缘上的相对位置和朝向进行跨块配对，确定所有块的空间拼合关系。
</new_puzzle>

根据封闭区域内指南针标记的方向和区域内部面积，将每个区域沿指定方向平移对应步数。

Input structure:
- 背景为 black。网格中有若干个由 grey 单像素宽边框围成的封闭矩形区域，每个区域内部填充了一种独特的颜色。
- 每个区域内部的某个角落有一个由 2 个相邻像素组成的"指南针"标记：一个 red 像素和一个与之水平或垂直相邻的 orange 像素。从 red 到 orange 的方向即为平移方向（上、下、左或右四个方向之一）。
- 不同区域的内部尺寸不同，但均为较小的矩形（内部面积不超过 10）。

Rule:
- 对每个封闭矩形区域，读取其内部指南针标记确定平移方向（red→orange 的偏移方向）。
- 计算该区域内部（不含 grey 边框）的像素总数（即内部宽度 x 内部高度），该数值为平移步数。
- 将整个区域（含 grey 边框和内部内容）沿指定方向平移该步数。
- 所有区域平移后绘制在同一画布上；原始位置被擦除为背景色。
- 平移后若区域之间发生重叠，面积更大的区域绘制在上层（面积小的先绘制，面积大的后绘制覆盖）。

Key insight:
- 第一层推理：需要识别出每个区域角落里红-橙两像素构成的方向编码；第二层推理：需要发现平移距离等于区域自身的内部面积——这个"面积即距离"的映射关系是隐蔽的，必须从多个样例中通过对比不同大小区域的不同移动距离才能归纳出来。
</new_puzzle>

<new_puzzle>
根据网格四条边框上的颜色序列编码的行列置换关系，对内部图案同时执行行重排和列重排。

Input structure:
- 网格最外一圈像素为控制边框，内部为一个彩色图案。
- 左侧边框从上到下的每个像素各有不同颜色，构成一个颜色序列 L；右侧边框从上到下也各有不同颜色，构成序列 R。L 和 R 包含完全相同的颜色集合，但顺序不同。
- 顶部边框从左到右的每个像素各有不同颜色，构成序列 T；底部边框从左到右也各有不同颜色，构成序列 B。T 和 B 包含完全相同的颜色集合，但顺序不同。
- 四个角落像素为黑色，不参与编码。

Rule:
- 左侧边框表示内部图案当前各行的标签（第 i 行的标签 = L[i]）；右侧边框表示目标行顺序的标签（第 j 行的目标标签 = R[j]）。
- 对内部图案进行行重排：将标签为 C 的行（在左侧边框中 C 所在的行）移动到右侧边框中 C 所在的行位置。
- 同理，顶部边框为列的当前标签，底部边框为列的目标标签，按相同逻辑对列执行重排。
- 行重排和列重排独立作用于两个轴，效果叠加。
- 输出仅包含重排后的内部图案，不含外圈边框。

Key insight:
- 解题者首先需要发现四条边框不是装饰而是编码了置换信息；其次需要理解左-右边框对构成行的"源→目标"映射、顶-底边框对构成列的"源→目标"映射；最后需要将两个独立的置换同时应用到图案上——三层认知缺一不可。
</new_puzzle>
