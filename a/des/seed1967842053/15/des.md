<new_puzzle>
将散布的彩色碎片按形状匹配嵌入模板框架的缺口中，并根据碎片嵌入后所处的框架区域重新着色。

Input structure：
- 背景为最常见颜色（black）。
- 网格中有一个大型灰色（grey）矩形框架，框架为一像素宽的矩形边框，框架内部被一条水平灰色分割线和一条垂直灰色分割线分成四个象限区域。
- 框架的外边框上有若干缺口（缺口处为背景色），每个缺口形状不同（例如 1×2、L 形等，均为小型连通区域，不超过 4 个像素）。
- 网格其余位置散布着若干与缺口形状完全匹配的单色碎片（每个碎片颜色各不相同），碎片颜色均不是灰色或背景色。
- 框架四个象限的内部区域各自被填充了不同的底色（red、blue、green、yellow 四种颜色之一），底色仅覆盖象限内部非灰色的区域。

Rule：
- 对每个框架缺口，找到形状完全匹配的散布碎片（允许旋转 0°/90°/180°/270°，不允许翻转）。
- 将匹配碎片平移并旋转到缺口位置，填补缺口。
- 确定该缺口所在的框架边段属于哪个象限（以分割线为界，缺口中心像素更靠近哪个象限即属于该象限）。
- 将嵌入后的碎片颜色替换为该象限对应的底色。
- 框架、分割线、象限底色以及未被碎片占据的背景均保持不变。

Key insight：碎片与缺口的匹配是一层推理（形状旋转匹配），但碎片最终着什么色取决于缺口在框架上的空间归属（哪个象限），这是第二层推理——解题者必须先发现象限着色规则，才能确定输出颜色。
</new_puzzle>

<new_puzzle>
在包含若干彩色矩形对的网格中，每对同色矩形之间的空白区域被填充为该颜色，但填充遇到其他颜色矩形时被阻断裁剪。

Input structure：
- 背景为最常见颜色（black）。
- 网格中有若干种前景色，每种颜色恰好出现两个互不相连的实心矩形。
- 同色的两个矩形要么在同一行带（行范围有重叠）要么在同一列带（列范围有重叠），但不会同时在两个方向上重叠。
- 不同颜色的矩形之间可能在空间上存在夹挤关系。

Rule：
- 对每种前景色，找到其两个矩形。
- 若两个矩形行范围有重叠，则在它们的共享行范围内、两个矩形之间的列间隙中填充该颜色。
- 若两个矩形列范围有重叠，则在共享列范围内、两个矩形之间的行间隙中填充该颜色。
- 填充仅覆盖背景色像素——如果间隙中已有其他颜色的矩形像素，则保留该已有像素不被覆盖。
- 所有颜色的填充互不覆盖已有的非背景像素，原始矩形保持不变。

Key insight：每对同色矩形之间的"桥接"方向需要通过行列重叠关系来判断（第一层推理），而填充范围在遇到其他颜色矩形时会被"阻断裁剪"——解题者需要发现已有矩形充当了遮挡墙的角色（第二层推理）。
</new_puzzle>

<new_puzzle>
根据封闭区域内标记像素的颜色，从网格边缘的调色板条中查找对应的填充图案，将该图案平铺填满整个封闭区域。

Input structure：
- 背景为最常见颜色（black）。
- 网格中有若干由灰色（grey）像素围成的封闭区域（灰色像素构成一像素宽的闭合矩形边界），封闭区域大小各不相同，每个封闭区域内部除背景外恰好有一个单独的标记像素，颜色各不相同。
- 网格的最底部两行是一条调色板条：调色板条被灰色竖线分隔成若干小格，每个小格宽 2 像素、高 2 像素，其中左上角一个像素为彩色标记（颜色与某个封闭区域的标记色对应），其余三个像素绘有一个 2×2 的小型图案的其余部分（由该标记色和另一种颜色组成，如棋盘格、L形、对角等）。

Rule：
- 对每个灰色封闭区域，读取其内部标记像素的颜色。
- 在调色板条中找到标记色相同的小格，提取该小格中完整的 2×2 图案。
- 将该 2×2 图案以平铺（tile）方式填充到对应封闭区域的内部（覆盖原来的背景和标记像素），平铺从封闭区域内部左上角像素开始对齐，超出范围的裁剪。
- 灰色边界保持不变，调色板条保持不变。

Key insight：标记像素不是输出的一部分，而是一个"索引键"，用于在调色板条中查表获取填充图案（第一层推理——发现标记与调色板的对应关系）；图案的铺设方式是周期性平铺而非拉伸（第二层推理——从样例中归纳出平铺对齐规则）。
</new_puzzle>

<new_puzzle>
网格中每个矩形房间有一扇门（边框缺口），将房间内的对象沿门的方向推出，推出距离等于对象的像素数量。

Input structure：
- 背景为最常见颜色（black）。
- 网格中有若干个由 blue 像素围成的矩形"房间"（一像素宽的蓝色矩形边框），房间互不相交。
- 每个房间的边框上恰好有一个一像素宽的缺口（门），门的位置可以在上、下、左、右任一侧。
- 每个房间内部有一个由单一非蓝色、非背景色构成的小型 4-连通对象（形状各异，像素数不超过 6）。

Rule：
- 对每个房间，识别门所在的方向（上/下/左/右）。
- 数出房间内对象的像素数量 N。
- 将该对象整体沿门的方向平移 N 个像素（对象形状和颜色不变）。平移后对象穿过门的缺口落在房间外部。
- 清除对象在原位置的像素（原位置恢复为背景色）。
- 蓝色房间边框（含门的缺口）保持不变。

Key insight：门的位置决定了推出方向（视觉上一眼可得），而推出距离来自对象自身的像素数量——解题者需要发现"像素数量 = 位移量"这一非显然的对应关系（核心推理层），并且注意对象是通过门缺口被推到房间外部的。
</new_puzzle>

<new_puzzle>
将网格中由分隔线划分的子区域按照各区域内红色箭头标记所指方向进行循环滚动排列。

Input structure：
- 背景为最常见颜色（black）。
- 网格被一像素宽的 grey 水平线和垂直线分割成 M×N 个大小相同的矩形子区域（类似表格，M 行 N 列）。
- 每个子区域内部包含一个由某种前景色绘制的图案（不含 red 和 grey），以及一个由 red 像素绘制的箭头标记。
- 箭头标记由三个 red 像素组成：一个像素为箭头尖端，另外两个像素呈 V 形分布在尖端的正后方和斜后方。例如向右的箭头：尖端在最右列，左邻一个像素、左上或左下邻一个像素。箭头方向为上、下、左、右之一。
- 同一行的所有子区域的箭头方向一致（全部指左或全部指右）。

Rule：
- 对每一行子区域：若箭头指向右，将该行所有子区域的图案内容（不含箭头标记和分隔线）循环右移一个子区域的位置（最右侧区域图案移到最左侧）；若指向左，循环左移一个子区域的位置。
- 移动时仅移动非 red、非 grey、非背景色的图案像素，以子区域为单位整体搬移。
- 移动完成后删除所有 red 箭头标记像素（恢复为背景色），灰色分隔线保持不变。

Key insight：解题者首先需要识别出红色三像素标记是箭头且从形状判断指向方向（第一层推理——归纳箭头编码规则），然后发现每行子区域是整体循环滚动而非单个区域移动（第二层推理——从多个样例中归纳循环移位机制），还需注意箭头本身不参与移动而是在输出中被擦除。
</new_puzzle>

<new_puzzle>
根据网格中每个彩色对象所接触的边界类型组合（网格边缘、灰色隔墙、或两者兼有）对对象进行分类重新着色。

Input structure：
- 背景为最常见颜色（black）。
- 网格内部有若干条 grey 直线段（水平或垂直，一像素宽），这些灰色线段将网格空间部分分隔但不完全封闭——它们是"隔墙"。
- 网格中散布着若干个由 red 像素构成的 4-连通单色对象，大小和形状各异，但都是 red。
- 每个红色对象至少与一种边界 4-邻接：网格边缘（对象的某个像素位于网格的最外围行或列）或灰色隔墙（对象的某个像素与灰色像素 4-邻接）。

Rule：
- 对每个红色对象，判断其边界接触情况：
  - 若对象仅接触网格边缘（不与任何灰色像素 4-邻接）→ 重新着色为 blue。
  - 若对象仅接触灰色隔墙（没有像素位于网格最外围行列，但与灰色像素 4-邻接）→ 重新着色为 green。
  - 若对象同时接触网格边缘和灰色隔墙 → 重新着色为 yellow。
- 灰色线段和背景保持不变。

Key insight：所有对象初始时看起来完全相同（全是红色），解题者需要发现着色规则不取决于对象的形状或大小，而取决于对象与两种不同类型边界的接触组合——首先要识别"网格边缘"和"灰色墙"是两种不同的边界类型（第一层推理），再通过对照样例归纳出三种接触情况与三种输出颜色的映射关系（第二层推理）。
</new_puzzle>

<new_puzzle>
在网格中找到由分隔线形成的表格，根据每个单元格内对象的形状对称性类型，将对象替换为该对称性类型对应的"签名色块"。

Input structure：
- 背景为最常见颜色（black）。
- 网格被 grey 水平线和垂直线分割成若干大小相同的矩形单元格。
- 每个单元格内部有一个由 orange 像素绘制的 4-连通对象，形状各异。
- 网格最左列的单元格是"图例列"：图例列中每个单元格的 orange 对象展示了一种对称性类型的范例，且该单元格的左上角有一个非 orange、非 grey、非背景色的单像素色标（如 red、blue、green 等），每种对称性类型对应不同的色标颜色。
- 对称性类型包括：无对称性、仅水平对称、仅垂直对称、水平且垂直对称（即同时具备水平和垂直反射对称）。

Rule：
- 从图例列中学习对称性类型到颜色的映射：检查每个图例单元格中 orange 对象的对称性类型，将其与该单元格的色标颜色关联。
- 对非图例列的每个单元格，判断其内部 orange 对象的反射对称性类型。
- 将该对象的所有像素替换为图例中对应对称性类型的色标颜色。
- 图例列保持不变，灰色分隔线保持不变。

Key insight：解题者需要首先识别图例列的作用——图例中的对象不是需要变换的内容而是"字典"（第一层推理），然后归纳出分类依据是对称性类型而非对象的具体形状（第二层推理——从多个不同形状但相同对称性的对象被映射到同一颜色中发现规律），最后通过图例查表完成颜色替换。
</new_puzzle>

<new_puzzle>
网格中每个封闭围栏内有若干彩色像素，将这些像素按颜色分组后沿围栏内壁不同边依次紧密排列。

Input structure：
- 背景为最常见颜色（black）。
- 网格中有若干个由 maroon 像素绘制的矩形围栏（一像素宽的闭合矩形边框），围栏大小各异且互不重叠。
- 每个围栏内部散布着若干彩色像素（非 maroon、非背景色），可能包含 2-4 种不同颜色，每种颜色出现 1-5 个像素，位置随机分布在围栏内部。

Rule：
- 对每个围栏，统计其内部各颜色的像素数量。
- 按像素数量从多到少排序各颜色（数量相同时按颜色在围栏内首次出现的行优先、列次优先的位置排序）。
- 清除围栏内部所有原有像素（恢复为背景色）。
- 将排序后的颜色依次沿围栏内壁排列：数量最多的颜色从围栏内部左上角开始沿顶边内壁向右紧密排列；排第二的颜色紧接着继续排列（如果顶边排满则转到右边内壁向下继续）；以此类推，按顺时针方向沿内壁连续铺设。
- 围栏边框保持不变。

Key insight：解题者需要发现散乱的内部像素在输出中被"整理"到了内壁上（第一层推理——识别输出的空间模式），然后归纳出排列顺序是按各颜色数量降序、沿内壁顺时针紧密排列的规则（第二层推理——从数量到顺序的映射机制）。
</new_puzzle>
