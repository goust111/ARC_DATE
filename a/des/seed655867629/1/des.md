<description>
根据彩色种子像素在封闭区域内的相对位置，确定该区域的填充图案方向，再用区域边框颜色选择填充色，生成定向条纹。

Input structure:
- bg = black。网格中有若干由单一颜色像素绘制的封闭矩形边框（边框颜色各不相同，如 red、blue、green 等），矩形内部为 black 背景。
- 每个矩形内部恰好有一个 yellow 种子像素。
- 网格右下角有一个小型图例区域，由 grey 边框围成，内部包含若干行，每行左侧是一个颜色方块、右侧紧邻一个不同颜色方块，形成"边框色 → 填充色"的映射表。

Rule:
- 第一层：对每个封闭矩形，观察 yellow 种子像素在矩形内部的位置。将矩形内部区域（不含边框）在水平和垂直方向各分为两半，种子落在哪个半区决定条纹方向：左半区 → 竖直条纹；右半区 → 水平条纹；上半区 → 从左上到右下的对角条纹（间隔 1 像素的平行斜线）；下半区 → 从右上到左下的对角条纹。若种子同时满足两个条件（如左上），取水平/垂直优先于对角（即左半区或右半区的判定优先）。
- 第二层：在图例中查找该矩形边框颜色对应的填充颜色。
- 用查到的填充颜色，按第一层确定的方向，在矩形内部（不含边框）画出间隔为 1 像素的条纹（即一列/行/对角线填色、一列/行/对角线留 black，交替进行）。条纹从矩形内部左上角像素开始计数。
- yellow 种子像素在输出中被条纹覆盖（不保留）。

Key insight: 种子像素不是标记"画在哪里"，而是编码"画什么方向"——它在区域内的相对位置是方向指令；而填充颜色则由另一个独立的图例映射决定，需要解题者同时归纳两层独立规则。
</description>
</new_puzzle>

<new_puzzle>
<description>
将散落的单色碎片精确嵌入带有形状缺口的大型拼图板中，再根据碎片嵌入后与板上已有彩色锚点的邻接关系，对碎片重新着色。

Input structure:
- bg = black。网格中有一个大型 grey 连通区域（"拼图板"），板上有若干形状各异的 black 缺口（即 grey 区域中的 black 洞）。
- 拼图板的 grey 区域中散布着少量彩色像素（red、blue、green 等），这些是"锚点"，每种颜色恰好出现一次。
- 在拼图板外部（black 背景区域），散布着若干由 orange 像素组成的小型连通碎片，每个碎片的形状恰好与板上某个缺口完全吻合（无需旋转或翻转）。

Rule:
- 第一层（形状匹配）：将每个 orange 碎片平移，使其形状精确填入拼图板上形状相同的 black 缺口中。每个碎片恰好对应一个缺口，一一匹配。
- 第二层（邻接着色）：碎片嵌入后，检查该碎片的所有像素的四方向邻居。若碎片的某个像素与板上的某个彩色锚点四方向相邻（即上下左右紧贴），则整个碎片重新着色为该锚点的颜色。若碎片与多个锚点相邻，取与碎片相邻像素数最多的锚点颜色（保证唯一）。若碎片不与任何锚点相邻，则保持 orange。
- 输出网格与输入尺寸相同；碎片从原位置消失，出现在缺口位置并被重新着色；其余部分不变。

Key insight: 第一步需要纯粹的形状匹配推理（在多个缺口和碎片之间找到一一对应），第二步需要发现嵌入后的空间邻接关系决定颜色——两层推理缺一不可，且第二层只有在完成第一层后才能判断。
</description>
</new_puzzle>

<new_puzzle>
<description>
在网格中识别由不同颜色组成的"信号链"，沿链传播时每经过一个中继节点就对携带的图案执行一次 90 度旋转，最终在链末端输出累计旋转后的图案。

Input structure:
- bg = black。网格被 grey 线条划分为若干等大的方格单元（类似棋盘格局，每个单元内部为 N×N 区域，grey 线条宽 1 像素）。
- 其中一个单元内包含一个由多种颜色组成的小型图案（"源图案"），该单元的左上角有一个 yellow 像素标记。
- 若干其他单元内各有一个单色像素（"中继节点"），颜色为 red、blue 或 green 之一。
- 恰好一个单元为全 black 且右下角有一个 maroon 像素标记（"目标单元"）。
- 中继节点之间通过颜色相同且在同一行或同一列上形成链式连接：同色中继节点在行/列方向上依次排列，构成一条从源图案出发、经过若干中继、到达目标单元的唯一路径。

Rule:
- 第一层（路径发现）：从源图案单元出发，找到与其同行或同列的最近中继节点，由此进入信号链。沿链依次经过每个中继节点，每次转到下一个中继时方向可能改变（行→列或列→行），直到到达目标单元。
- 第二层（累计旋转）：每经过一个中继节点，源图案顺时针旋转 90 度一次。经过 K 个中继节点后，图案累计旋转 K×90 度。
- 第三层（输出）：将累计旋转后的图案绘制在目标单元内。其余所有内容（grey 网格线、中继节点、源图案）保持不变。

Key insight: 解题者需要先通过颜色和空间位置重建出唯一的传播路径（非显然，因为中继节点散布在网格中），再数出路径上的中继节点数量以确定旋转次数——路径发现和旋转累计是两层独立的推理。
</description>
</new_puzzle>

<new_puzzle>
<description>
每个彩色区域内部隐藏着一个"印章模板"，需要先从区域的边界轮廓形状中解码出印章，再将印章按区域内标记点指定的位置重复压印。

Input structure:
- bg = black。网格中有若干互不接触的彩色连通区域（每个区域由单一颜色的像素组成，如 red、blue、green 等）。
- 每个区域的外部轮廓（最外层像素的排列）构成一个封闭形状，该形状可能是矩形、L 形、T 形等。
- 每个区域内部（被该颜色像素完全包围的 black 像素）存在若干孤立的 yellow 像素作为"压印标记"。
- 网格的最底部一行是一个图例行：从左到右排列着若干小型形状样本，每个样本由 grey 像素绘制，样本之间用至少 2 列 black 间隔。这些样本分别是：一个 1×1 方块、一个 2×2 方块、一个 L 形（3 像素）、一个 T 形（4 像素）等基本形状。

Rule:
- 第一层（轮廓解码）：对每个彩色区域，提取其外部轮廓的形状类别。将轮廓的凸出部分（即轮廓 bounding box 中被占用但不属于最小外接矩形内部填充的突出部分）提取出来——这个凸出部分的形状就是"印章模板"。具体而言：计算区域的 bounding box，找到 bounding box 内被区域颜色占据但若区域是完美矩形则不会存在的那些像素，这些像素的相对排列就是印章形状。若区域本身就是完美矩形，则印章为 1×1 单像素。
- 第二层（压印）：在每个 yellow 标记像素的位置，以该标记为印章左上角，用该区域的颜色绘制印章模板的形状。印章像素覆盖原有的 black 背景。
- 输出中 yellow 标记像素被印章覆盖（不保留），图例行保持不变。若印章压印超出区域内部的 black 空间则截断（不画到区域边界之外）。

Key insight: 区域的外部轮廓形状不仅仅是容器——它的"非矩形偏差"编码了要在内部压印的图案。解题者必须先发现轮廓形状与印章之间的映射关系，再执行压印操作。
</description>

<new_puzzle>
<description>
识别网格中由不同颜色边框构成的嵌套矩形层级，根据嵌套深度对最内层区域执行不同的几何变换（旋转或翻转），变换类型由嵌套层数的奇偶性决定。

Input structure:
- bg = black。网格中有若干组"嵌套矩形"：每组由多个不同颜色的矩形边框（宽 1 像素）逐层嵌套，外层矩形严格包含内层矩形，层与层之间有 black 间隔。
- 每组嵌套矩形的最内层（最小的矩形）内部包含一个由多种颜色组成的小型图案（非边框颜色）。
- 不同组之间互不重叠，在网格上空间分离。

Rule:
- 第一层（嵌套层级识别）：对每组嵌套矩形，从外到内数出边框层数 D（例如：只有一个边框则 D=1，两层嵌套边框则 D=2，以此类推）。
- 第二层（变换选择与执行）：
  - 若 D 为奇数，将最内层图案顺时针旋转 90 度。
  - 若 D 为偶数，将最内层图案沿垂直轴左右翻转。
- 第三层（输出）：输出网格中，所有边框层保持不变，仅最内层图案被替换为变换后的结果。

Key insight: 边框的颜色是视觉干扰项——真正决定变换类型的是嵌套的层数（奇偶性）。解题者需要先发现"数边框层"这一非显然操作，再发现奇偶性与变换类型的映射关系，两层推理相互独立。
</description>

<new_puzzle>
<description>
根据网格中彩色"管道"的连接拓扑对颜色信号进行混合：两种颜色的管道在交汇点合流后，下游管道变为第三种颜色（由固定的颜色混合图例决定）。

Input structure:
- bg = black。网格左上角有一个小型"混色图例"：若干行，每行由三个相邻像素组成，前两个像素颜色不同（代表输入色 A 和 B），第三个像素是它们的混合结果色 C。例如：red + blue → magenta，red + yellow → orange，blue + yellow → green。
- 网格主区域中有若干条由单色像素组成的水平或垂直线段（"管道"），每条管道宽 1 像素。管道端点处可能与另一条管道的端点在同一像素位置相交（"交汇点"），交汇点处该像素为 grey。
- 部分管道的一端连接交汇点，另一端是自由端（不连接任何东西）；自由端管道已有确定的颜色。
- 部分管道两端都连接交汇点，这些管道初始为 grey（颜色待定）。

Rule:
- 第一层（信号传播方向）：自由端管道是"源管道"，其颜色已知。信号从源管道流向交汇点。
- 第二层（颜色混合）：当一个交汇点恰好有两条源管道（或已确定颜色的管道）汇入时，查阅混色图例，找到这两种颜色对应的混合色。将该交汇点下游的 grey 管道着色为混合色。
- 第三层（级联传播）：新着色的管道可能连接到更下游的交汇点，在那里与另一条管道再次混合。重复混合过程直到所有 grey 管道都被着色。
- 交汇点像素（grey）在输出中保持 grey。混色图例保持不变。

Key insight: 解题者需要首先理解图例定义的颜色混合映射表，然后从网格中的管道拓扑结构推断出信号流动方向（从自由端向交汇点），最后沿拓扑顺序级联应用混色规则——图例解读、流向推断、级联混合构成三层独立推理。
</description>
</new_puzzle>

<new_puzzle>
<description>
在网格中找到多组"镜像对"物体，根据每对之间的对称轴类型决定如何合并它们，再用合并结果的重叠关系选择输出颜色。

Input structure:
- bg = black。网格中散布着若干由单一颜色像素组成的小型图形（sprite），每个 sprite 是一个四连通区域。
- 这些 sprite 成对出现：每对中的两个 sprite 形状相同，颜色相同，且关于某条隐含的水平线或垂直线互为镜像。不同对之间颜色不同。
- 网格右侧有一列由 grey 像素组成的垂直色条（宽 1 像素），作为分隔符。分隔符右侧有两个小方块：上方是 azure 方块（2×2），下方是 maroon 方块（2×2），分别代表"水平对称"和"垂直对称"的标签。

Rule:
- 第一层（配对与对称轴识别）：对每种颜色，找到该颜色的两个 sprite。判断它们是关于某条水平轴还是垂直轴互为镜像（通过观察两个 sprite 的相对位置和形状翻转方式确定）。
- 第二层（合并）：将每对 sprite 沿其对称轴"折叠合并"——即将两个 sprite 的像素叠加到以对称轴为中心的同一区域。合并后，某些像素位置可能只有一个 sprite 贡献（单层），某些位置两个 sprite 都贡献（双层重叠）。
- 第三层（着色输出）：在输出中，只保留合并后的图形。对于水平对称的配对（标签色 = azure），将重叠像素（双层）着色为 azure，非重叠像素保持原色。对于垂直对称的配对（标签色 = maroon），将重叠像素着色为 maroon，非重叠像素保持原色。
- 输出网格尺寸与输入相同。分隔符和标签方块在输出中被移除（变为 black）。每对合并后的图形绘制在对称轴附近的正确位置上。

Key insight: 解题者首先需要识别哪些 sprite 构成镜像对并判断对称轴方向（这不是简单的视觉识别，因为对称轴本身不可见），然后理解"折叠合并"操作的含义，最后根据对称类型将重叠区域映射到不同颜色——三层推理环环相扣。
</description>
</new_puzzle>
