# 第一步：分析与思考

## 参考题中的基础操作分类

通过对20道参考题的深入分析，可以提取出以下基础操作类别：

### 1. 空间投射与射线操作
- 题3（从菱形边缘标记向内发射射线直到被阻挡）、题8（从矩形四个方向投射射线直到蓝色阻挡）都涉及**射线发射与阻挡**。
- 题12（品红粒子沿走廊移动，遇阻转弯）则是**路径追踪**的变体。

### 2. 形状识别与分类
- 题6（根据物体是否有凹口来决定滑动方向和颜色）、题10（按对角线方向分类前景像素）涉及**基于形态特征的分类**。
- 题4（将3x3空心符号识别为单像素）涉及**符号缩放/解码**。

### 3. 全局变换与对称
- 题18（以十字线为轴做四象限反射）涉及**对称轴反射**。
- 题13（将局部裁剪匹配回完整的二值图案及其旋转/翻转变体）涉及**二面体群匹配**。
- 题7中的L标记触发旋转是**条件旋转**。

### 4. 信息编码方式
- 题5（颜色编码位移方向和距离）：**颜色=运动指令**。
- 题9（中心像素的颜色确定幸存颜色，同色像素的象限确定方向）：**空间分布编码方向**。
- 题17（标记颜色索引模板，局部位置索引输出块）：**多维编码**。
- 题2（最多数的标记颜色决定输出框架颜色）：**多数投票**。

### 5. 区域操作
- 题19（沿连通线找封闭区域并填充种子颜色）：**连通性驱动的洪泛填充**。
- 题14（用模板在纯色块上打孔）：**模板冲压/镂空**。
- 题11（提取行列完整覆盖的双色子网格）：**完备矩形识别**。

### 6. 物理模拟
- 题16（推矩形到边缘，沿途劈开垂直障碍）：**推挤与分裂**。
- 题15（三角形精灵沿标记方向逐步移动并消耗标记）：**逐步消耗行走**。

## 非显而易见的串联方式

1. **分类结果驱动空间变换**：一个物体的形态分类（如凹口检测）不仅决定颜色，还可以作为另一个物体的变换参数（如射线方向、填充模板选择）。这建立了"形态 → 参数 → 变换"的间接因果链。

2. **连通性定义计算域**：射线操作通常在全局坐标中执行，但如果射线的起始点、方向和作用范围都由连通区域的拓扑性质（如封闭性、连通分量数、洞的数量）决定，就产生了"拓扑 → 几何"的非直觉映射。

3. **信息的多级编码**：颜色可以同时编码多种信息——既标记某个对象的身份，又通过其在网格中的相对位置编码另一层含义（例如方向或优先级）。解题者需要逐层剥离这些编码。

4. **隐式模板匹配**：网格中的某个区域不直接呈现模板，而是通过"缺失"来暗示模板——比如一组规则排列中某些位置的空缺共同拼出一个隐藏图案。

5. **计数结果作为空间参数**：某种颜色像素的数量不仅用于分类，还直接转化为空间操作的参数（如偏移量、旋转角度、重复次数），这在参考题中尚未组合出现。

6. **对象间的传递关系**：A物体的属性决定B物体的变换，B物体变换后的属性又决定C物体的变换——形成链式推理。

- `description`：根据每个封闭区域内部的"缺口指向"确定该区域的填充颜色，缺口指向由区域边界上唯一的断开位置决定。

- `Input structure`：
  - 背景色为 black。
  - 网格中有若干用 grey 像素绘制的一像素宽的封闭矩形框（每个框的四条边各由连续 grey 像素组成）。
  - 每个矩形框的四条边中，恰好有一条边上存在一个连续 2 像素的缺口（即该边上有两个相邻位置是 black 而非 grey）。
  - 网格中还有一个颜色调色板区域，位于网格最下方一行，由四段相邻的色块组成，从左到右分别为 red、blue、green、yellow，每段宽度为 2 像素，它们之间无间隔。

- `Rule`：
  - 检查每个 grey 矩形框，找到其唯一缺口所在的边。
  - 缺口在上边 → 填充 red；缺口在右边 → 填充 blue；缺口在下边 → 填充 green；缺口在左边 → 填充 yellow。
  - 填充操作：将该矩形框严格内部（不含边框本身）的所有 black 像素改为对应颜色。
  - 矩形框自身保持 grey 不变，缺口位置保持 black 不变。
  - 调色板行保持不变。

- `Key insight`：解题者需要注意到每个框恰好有一条边有断裂，而这个断裂方向与调色板中颜色的排列顺序（上右下左 = 红蓝绿黄）之间存在对应关系。颜色信息不是直接标注在框上，而是通过框自身结构的"缺陷"来间接编码。

- `description`：将每种前景颜色的散布像素视为包围盒的角标记，绘制该颜色的轴对齐最小外接矩形边框，清除矩形内部的原始像素。

  - 背景色为 black。
  - 网格中有 3-4 种不同的前景颜色（如 red、blue、green）。
  - 每种颜色有 3-6 个散布的像素点，它们互不相邻。

- `Rule`：
  - 对每种前景颜色，找出该颜色所有像素中行号的最小最大值和列号的最小最大值，确定其轴对齐最小外接矩形。

  - 原始散布像素中，位于矩形边框位置上的保留其颜色（成为边框的一部分），位于矩形严格内部的被清除为 black。
  - 处理顺序：按颜色在网格中首次出现的行号升序排列，逐个绘制。后绘制的边框覆盖先绘制的。

- `Key insight`：每种颜色散布的像素不直接保留，它们的作用是定义一个包围矩形的极值范围。解题者必须理解这些像素是"测量标记"而非内容本身——它们的极值坐标才是有意义的信息，用于生成几何框架。

- `description`：网格中的彩色"种子"像素沿灰色线段网络传播，在每个交叉点强制转弯，最终在到达线段末端时放置一个 orange 标记。

- `Input structure`：
  - 背景色为 black。
  - 网格中有若干由 grey 像素组成的水平和垂直线段（长度至少3像素，宽度1像素）。这些线段在某些位置以 T 字形或十字形交叉，交叉处共享一个 grey 像素。
  - 有 1-3 个非 grey、非 black 的彩色像素（如 red、blue），每个位于某条 grey 线段的一个端点的相邻位置。具体地，彩色像素紧靠线段端点外侧，沿线段延伸方向的反方向放置（例如一条向右延伸的水平线段，其左端点的左边相邻像素是彩色种子）。
  - 每条线段至多关联一个种子。线段网络是连通的或由若干连通分量组成。

- `Rule`：
  - 从每个彩色种子像素出发，进入其相邻的 grey 线段端点，沿线段方向前进。
  - 沿当前方向行进，逐个经过 grey 像素。
  - 当到达一个交叉点（该 grey 像素在当前行进方向的垂直方向上也有相邻的 grey 像素），必须转弯90度进入垂直方向的线段。若垂直方向两侧都有 grey 像素，选择行号或列号更小的方向（即向上优先于向下，向左优先于向右）。
  - 当到达一个线段末端（当前方向上下一个像素不是 grey，且垂直方向也没有 grey 像素可转弯），在该末端 grey 像素的下一个位置（沿行进方向）放置一个 orange 像素。
  - 所有 grey 线段和彩色种子保持不变。

- `Key insight`：灰色线段网络构成一个隐含的路径图，彩色种子是起点。解题者需要追踪种子沿线段行进、在交叉处强制转弯的确定性路径——核心难点在于发现"交叉必须转弯"的规则以及转弯方向的消歧规则。路径的最终落点用 orange 标记，这使得因果链跨越了整个线段网络。
</new_puzzle>

<new_puzzle>
- `description`：在每个带框区域内部，保留像素数最少的颜色，清除所有其他颜色。

- `Input structure`：
  - 背景色为 black。
  - 网格中有若干互不重叠的矩形区域，每个区域由一个 azure 色的一像素宽完整边框围成。
  - 每个矩形框的内部（不含边框）填充有 2-4 种不同的前景颜色（非 black、非 azure），每种颜色占据若干像素，可以是任意形状的连通或非连通区域。
  - 不同矩形框内使用的颜色可能相同也可能不同。
  - 每个矩形框内部，各颜色占据的像素总数两两不等（无并列）。

- `Rule`：
  - 对每个 azure 边框矩形，统计其内部每种非 black、非 azure 颜色的像素总数。
  - 找出像素数最少的那个颜色。
  - 将该矩形内部所有**非该最少颜色**的前景像素替换为 black。
  - 该最少颜色的像素保持原位不变。
  - azure 边框保持不变。
  - 矩形外部的 black 背景不受影响。

- `Key insight`：直觉会倾向于关注面积最大、最显眼的颜色区域，但实际规则恰恰相反——被保留的是最不起眼、像素最少的颜色。解题者必须反直觉地将注意力转向"少数"而非"多数"。此外，每个矩形是独立处理的，颜色的"少数"地位是局部判断而非全局判断。
</new_puzzle>

<new_puzzle>
- `description`：网格中有若干带方向的箭头，每个箭头的指向标识其对应的目标色块，箭头的尾巴长度编码目标色块的旋转角度。

- `Input structure`：
  - 背景色为 black。
  - 网格中有若干小型（占据 3x3 至 5x5 像素范围的）单色非对称形状，每个形状使用唯一的颜色（如 red、green、blue、yellow 等），称为"目标色块"。每个色块至少有4个像素，形状不对称（即旋转90度后与原形不同）。
  - 每个目标色块在其四个基本方向（上、下、左、右）之一的远处（间隔至少3个 black 像素），有一个同颜色的箭头图案。
  - 箭头图案由头部和尾巴组成：
    - 头部为3个像素排成的直角三角形：中心像素1个，沿箭头指向方向偏移1像素；中心像素的指向方向的垂直两侧各1个像素。头部的尖端即为中心像素偏移后的那个像素，它指向上/下/左/右之一。
    - 尾巴为从中心像素向箭头指向的反方向延伸的直线，长度 L 为1、2或3个像素。
  - 箭头的尖端方向指向其配对的目标色块所在的方向（即从箭头出发沿尖端方向可以到达目标色块）。

- `Rule`：
  - 对每个箭头，沿其尖端方向找到同色的目标色块（即该方向上最近的同色物体）。
  - 读取箭头尾巴长度 L：L=1 → 目标色块顺时针旋转90度；L=2 → 顺时针旋转180度；L=3 → 顺时针旋转270度。
  - 计算目标色块的外接矩形中心，将色块绕该中心顺时针旋转相应角度后放回原位（中心对齐，外接矩形位置不变）。
  - 所有箭头图案在输出中被清除为 black。
  - 目标色块在旋转后放回原外接矩形中心位置。

- `Key insight`：箭头编码了两层独立信息：指向方向标识"哪个色块是目标"（方向性配对），尾巴长度编码"旋转多少度"（量化参数）。解题者需要先识别箭头的方向结构来建立配对关系，再通过度量尾巴长度来推断变换参数。两层信息需要分别解码后组合使用。
</new_puzzle>

<new_puzzle>
- `description`：根据同色平行线对之间的间距查阅调色板确定填充颜色，将线对之间的间隙填满。

- `Input structure`：
  - 背景色为 black。
  - 网格中有若干对平行的线段。每对线段由相同颜色的像素组成（如一对 red 水平线、一对 blue 垂直线等），共 3-5 对，颜色各不相同。
  - 同一对中的两条线段长度相同、方向相同（均为水平或均为垂直），且在垂直于线段方向上对齐（即两条水平线段的列范围完全相同，或两条垂直线段的行范围完全相同）。
  - 每对线段之间的垂直间距（gap，即两线段之间有多少行/列的 black 像素）为 1、2 或 3。
  - 网格左下角有一个 3 行 1 列的小型调色板，从下到上三个像素颜色分别为 green、yellow、orange，对应 gap=1、gap=2、gap=3 的填充颜色。

- `Rule`：
  - 识别每对同色平行线段，测量它们之间的 gap（两线段之间的 black 行/列数）。
  - 从调色板中查找 gap 值对应的填充颜色：gap=1 → green（调色板最下方），gap=2 → yellow（调色板中间），gap=3 → orange（调色板最上方）。
  - 将两条线段之间、水平/垂直对齐范围内的所有 black 像素填充为该颜色。
  - 原始线段颜色保持不变。
  - 调色板区域保持不变。

- `Key insight`：决定填充颜色的既不是线段自身的颜色，也不是线段的位置，而是线段之间的空间距离——这是一种"几何度量编码语义"的模式。解题者需要跨过"颜色对应颜色"的直觉思路，发现"距离对应颜色"的隐藏映射。调色板的顺序提供了线索，但首先要识别"间距"是核心变量。
</new_puzzle>

<new_puzzle>
- `description`：每个彩色标记像素按曼哈顿距离归属于最近的灰色矩形，每个灰色矩形被重新着色为归属于它的多数票颜色。

- `Input structure`：
  - 背景色为 black。
  - 网格中有 2-4 个互不相邻的小型实心 grey 矩形（大小为 2x2 或 3x3），称为"候选框"。候选框之间至少间隔 3 个像素。
  - 网格中散布着 6-12 个彩色单像素标记，颜色可为 red、blue、green 或 yellow。
  - 每个彩色标记与所有候选框之间至少间隔 1 个像素（不直接相邻）。
  - 彩色标记之间也互不相邻。

- `Rule`：
  - 对每个彩色标记像素，计算它到每个 grey 候选框的曼哈顿距离（距离定义为该标记到候选框中最近一个 grey 像素的曼哈顿距离）。
  - 将该标记分配给距离最近的候选框。若到多个候选框距离相等，优先分配给行号最小的候选框的左上角所在行更小的那个；若行号也相同，分配给列号更小的那个。
  - 对每个候选框，统计分配到它的所有标记中各颜色的出现次数，找出出现次数最多的颜色。（保证不会出现平局。）
  - 将该候选框的所有 grey 像素替换为该多数颜色。
  - 若某个候选框没有任何标记分配到它，则保持 grey 不变。
  - 所有彩色标记像素在输出中被清除为 black。

- `Key insight`：灰色矩形不是静态装饰，而是竞争选票的"候选者"。解题者需要意识到：(1) 空间邻近性决定了每个标记的归属关系（类似 Voronoi 分区），(2) 在每个归属组内进行多数投票决定最终颜色。从样例中必须同时发现空间分区机制和统计聚合机制，这两层规则叠加增加了归纳的难度。
</new_puzzle>

<new_puzzle>
- `description`：网格中隐藏着两个按棋盘格交错嵌入的图案，将它们分离、压缩到半尺寸后叠合为输出。

- `Input structure`：
  - 网格尺寸为偶数 x 偶数（例如 10x10、12x12 或 14x14）。
  - 背景色为 black。
  - 前景由两种颜色组成，例如 red 和 blue。
  - red 像素只出现在行号与列号奇偶性相同的位置（即 (r+c) 为偶数的位置：(0,0), (0,2), (1,1), (1,3), (2,0), (2,2) ...）。
  - blue 像素只出现在行号与列号奇偶性不同的位置（即 (r+c) 为奇数的位置：(0,1), (1,0), (1,2), (0,3) ...）。
  - 每种颜色各自构成一个可辨认的简单图案（如 L 形、T 形、十字、方框等），但由于棋盘格交错分布，两个图案在视觉上互相干扰、难以直接辨认。

- `Rule`：
  - 输出网格尺寸为 (输入行数/2) x (输入列数/2)。
  - 构建网格 A：提取输入中所有 (r, c) 满足 r 为偶数且 c 为偶数的像素，按 (r/2, c/2) 放入 A。
  - 构建网格 B：提取输入中所有 (r, c) 满足 r 为奇数且 c 为奇数的像素，按 ((r-1)/2, (c-1)/2) 放入 B。
  - 将网格 B 上下翻转（第一行变最后一行、最后一行变第一行）得到 B'。
  - 叠合 A 和 B'：对于输出每个位置 (i, j)，如果 A[i][j] 不是 black 则输出 A[i][j] 的颜色；否则如果 B'[i][j] 不是 black 则输出 B'[i][j] 的颜色；否则输出 black。

- `Key insight`：输入看似是杂乱的红蓝像素散布，实际上隐藏着两个按棋盘格规律交错嵌入的独立图案。解题者需要发现坐标奇偶性是分离信号的密钥——这一线索极难从视觉上直接观察，需要逐像素对比坐标才能发现。更深层的挑战是察觉其中一个图案需要上下翻转才能与另一个正确对齐，形成有意义的叠合输出。
</new_puzzle>
