# 第一步：分析与思考

## 参考题中的基础操作梳理

参考题覆盖了以下核心操作族：
- **几何变换**：旋转、翻转、平移、缩放、循环滚动（题2、3、14、17、20）
- **印章/铺贴**：将模板像素按掩码扩展或重复铺设（题1、6、16）
- **颜色映射/替换**：通过图例或查找表重新着色（题11、12、18）
- **路径与射线**：沿方向发射射线、沿路径传播、碰撞转向（题4、7、10、19）
- **形状匹配与填充**：用形状特征做索引匹配并填色（题8）
- **标记-锚点-传送**：通过颜色标记建立对应关系实现跨位置复制（题5、9）
- **序列/排序/外推**：按空间顺序赋色或外推运动帧（题3、12、13）

## 非显而易见的串联方式思考

1. **结构自身作为编码载体**：大多数题目中存在"控制信息"与"数据信息"的分离——控制信息编码在位置、形状、颜色等维度中。非显然的做法是让同一对象同时承担数据和控制角色，其角色随上下文切换。

2. **拓扑信息作为隐式参数**：参考题主要使用几何属性（位置、大小、颜色），较少利用拓扑属性（连通性、包围关系、邻接图结构）。连通分量之间的邻接关系、包围层级、以及同色区域之间的"可达性"都可以成为新的信息通道。

3. **变换的条件依赖性**：参考题中的变换通常对所有对象统一执行。如果变换规则本身由对象的某个局部特征决定（不同对象执行不同变换），则推理难度大幅上升。

4. **空间频率与周期性**：重复模式的周期、相位、偏移量可以编码信息——这是参考题中较少触及的维度。

5. **负空间与补集思维**：参考题多关注"前景做了什么"，而"背景形成了什么形状"这种图-底反转式的推理可以构建新颖的认知路径。

<new_puzzle>
- `description`：根据每个封闭区域被包围的层数，用对应深度的颜色为其着色。

- `Input structure`：
  - 背景为 black。
  - 网格中有若干用同一种前景色（如 blue）绘制的闭合轮廓线（线宽为1像素，4-连通闭合）。
  - 这些轮廓可以嵌套：一个轮廓完全被另一个轮廓包围在内部，形成多层嵌套结构（最多3-4层）。
  - 轮廓线之间不相交、不共享像素。
  - 轮廓内外的空白区域均为 black。

- `Rule`：
  - 保留所有 blue 轮廓线不变。
  - 对每个 black 连通区域（4-连通），计算它被多少层轮廓线包围（即从该区域出发，沿任意方向到达网格边界需穿越多少条轮廓线——取奇偶交叉计数法中的最小穿越数）。
  - 深度 0（最外层，与网格边界连通）的区域保持 black。
  - 深度 1 的区域填充 red。
  - 深度 2 的区域填充 green。
  - 深度 3 的区域填充 yellow。
  - 深度 4 的区域填充 magenta。
  - 若有更多层，依此循环。

- `Key insight`：解题者需要认识到颜色不是由区域的形状、大小或位置决定的，而是由该区域在嵌套层级中的"深度"——即被多少层闭合轮廓包围——决定的。核心认知路径是"拓扑包围深度 → 颜色映射"。
</new_puzzle>

<new_puzzle>
- `description`：在网格中找出每个同色区域的"骨架"（最长内部路径），然后仅保留骨架像素、擦除其余部分。

- `Input structure`：
  - 背景为 black。
  - 网格中有若干不同颜色的连通前景区域（4-连通），每个区域由同色像素组成，形状不规则但宽度至少为2-3像素（即不是单像素线条，而是有面积的"胖"形状）。
  - 不同颜色的区域彼此不接触。

- `Rule`：
  - 对每个前景连通区域，找到该区域内最长的一条4-连通路径，路径上每个像素都属于该区域，且路径不重复经过任何像素。这条路径称为该区域的"骨架"。
  - 若最长路径不唯一，选择起始像素行号最小的那条；若仍平局则选起始列号最小的。
  - 输出中仅保留骨架路径上的像素（保持原色），其余所有前景像素替换为 black。
  - 背景保持 black 不变。

- `Key insight`：解题者需要意识到每个"胖"形状被削减为一条贯穿其中的最长线条。核心认知路径是从"面积形状"到"内部最长路径提取"——这不是简单的边界描绘或缩小，而是一种拓扑骨架化操作。
</new_puzzle>

<new_puzzle>
- `description`：每个前景对象按照其面积大小排名决定在输出中的垂直排列顺序，面积最大的放在最上方。

- `Input structure`：
  - 背景为 black。
  - 网格中散布着若干独立的多色前景对象（8-连通分量），每个对象的形状和大小各不相同。
  - 每个对象占据一个紧凑的矩形区域（对象内部可能有 black 空洞）。
  - 对象之间不接触、不重叠。
  - 输入中对象的位置是随意的。

- `Rule`：
  - 对每个前景对象，计算其非 black 像素的数量（即面积）。
  - 将所有对象裁剪为最小包围矩形（bbox）。
  - 在输出网格中，按面积从大到小的顺序，将对象从上到下垂直排列。
  - 每个对象左对齐（bbox 的左边缘对齐到输出网格的第 0 列）。
  - 相邻对象之间间隔恰好 1 行 black 像素。
  - 输出网格的宽度等于所有对象 bbox 宽度的最大值，高度等于所有 bbox 高度之和加上间隔行数。
  - 对象内部的颜色和形状完全保持不变。

- `Key insight`：解题者需要发现输出中对象的排列顺序不是由位置、颜色或形状决定的，而是由每个对象的像素面积决定——面积最大者在最上方。核心认知路径是"计数每个对象的面积 → 排序 → 重新排列"。
</new_puzzle>

<new_puzzle>
- `description`：将散落在网格中的彩色像素按颜色分组，每组内的像素沿最短路径相互"吸引"聚合为一个紧密团块。

- `Input structure`：
  - 背景为 black。
  - 网格中散布着若干孤立的单像素前景点，共使用 2-4 种不同颜色。
  - 每种颜色有 2-5 个像素，分布在网格的不同位置。
  - 同色像素之间的距离各不相同。

- `Rule`：
  - 对每种颜色，找到该颜色所有像素的几何质心（所有像素行坐标的平均值取整、列坐标的平均值取整，四舍五入）。
  - 将该颜色的每个像素移动到距离质心最近的空闲位置：第一个像素占据质心本身，后续像素按照与质心的曼哈顿距离从近到远依次放置在质心周围尚未被占据的格子中（距离相同时，行号小者优先；行号相同则列号小者优先）。
  - 不同颜色组的质心和放置过程互相独立（若两组占据同一格子则颜色按字母序靠后的覆盖靠前的）。
  - 背景保持 black。

- `Key insight`：解题者需要认识到每种颜色的散落像素并非随意移动，而是向该颜色的"重心"汇聚，形成紧密聚类。核心认知路径是"识别颜色分组 → 发现质心作为吸引点 → 理解聚合机制"。
</new_puzzle>

<new_puzzle>
- `description`：网格中的每条水平色带被当作一个独立的"信号行"，根据该行中特定标记色出现的列位置，对该行的非标记内容进行循环左移。

- `Input structure`：
  - 网格由若干水平色带组成，每条色带高度为1行。
  - 每行包含一种主体前景色的像素序列，以及恰好一个 red 标记像素。
  - 不同行的主体前景色可以不同。
  - 背景为 black，行的两端可能有 black 像素作为填充。
  - red 标记像素位于该行的某个位置，替换了该位置原本应有的主体色或 black。

- `Rule`：
  - 对每一行，记录 red 标记像素所在的列索引 c。
  - 移除 red 标记像素，将其替换为该行的主体前景色（即该行中出现次数最多的非 black 非 red 颜色）。
  - 将该行的全部内容循环左移 c 个位置（即列索引 0 处的像素移到末尾方向）。
  - 输出网格形状与输入相同。

- `Key insight`：解题者需要发现每行中的 red 像素并非装饰或数据，而是一个"指令"——它的列位置编码了该行需要循环左移的偏移量。移除标记后行内容完整，移位后产生输出。核心认知路径是"标记位置 → 位移量编码 → 行内循环移位"。
</new_puzzle>

<new_puzzle>
- `description`：输入网格的每一列是一个"投票通道"，输出只保留每列中出现次数最多的颜色，将该列全部填充为胜出颜色。

- `Input structure`：
  - 网格为矩形，无明显背景色——每个格子都有非 black 颜色。
  - 每列包含 2-3 种不同颜色的像素，混合排列。
  - 不同列的颜色组合可能不同。
  - 网格高度至少为 5 行，宽度至少为 3 列。

- `Rule`：
  - 对每一列，统计该列中每种颜色出现的次数。
  - 找出出现次数最多的颜色（保证每列有唯一的众数颜色，不存在平局）。
  - 将输出网格中该列的所有格子都填充为这种胜出颜色。
  - 输出网格尺寸与输入相同。

- `Key insight`：解题者需要发现输出中每列变为单一颜色，而该颜色恰好是输入中该列的"多数色"。核心认知路径是"逐列统计 → 多数投票 → 统一填充"。这要求解题者从全局视角观察列方向的统计规律，而非关注局部形状或空间关系。
</new_puzzle>

<new_puzzle>
- `description`：在网格中，每个前景对象的"影子"被投射到由该对象内部唯一的方向标记像素所指示的方向上。

- `Input structure`：
  - 背景为 black。
  - 网格中有若干独立的前景对象（8-连通分量），每个对象主体使用一种颜色。
  - 每个对象内部恰好有一个与主体颜色不同的"方向标记"像素。方向标记的位置相对于对象 bbox 中心的方位（上、下、左、右）指示影子投射方向：标记在中心上方表示影子向上投射，标记在右方表示影子向右投射，以此类推。若标记恰好处于对角线位置，取行偏移和列偏移中绝对值较大的维度作为主方向。
  - 对象之间不接触。

- `Rule`：
  - 对每个对象，确定其方向标记相对于 bbox 中心的主方位（上/下/左/右）。
  - 将该对象整体沿该方向复制一份，偏移量等于对象在该方向上的 bbox 尺寸（即影子紧贴对象边缘）。
  - 影子使用 grey 颜色绘制，形状与原对象完全相同（包括主体和标记位置，但全部画为 grey）。
  - 原对象保持不变（包括标记像素的颜色）。
  - 若影子超出网格边界，则裁剪到边界内。

- `Key insight`：解题者需要发现每个对象内部那个"异色像素"不是噪声或装饰，而是一个方向指示器——它在对象内的相对位置编码了影子投射的方向。核心认知路径是"异色标记的相对方位 → 投射方向 → 影子生成"。
</new_puzzle>

<new_puzzle>
- `description`：网格被划分为若干矩形面板，每个面板中包含一个图案；输出将所有面板中的图案叠加到一个同尺寸面板上，重叠处使用颜色混合规则。

- `Input structure`：
  - 背景为 black。
  - 网格被 grey 分隔线（宽度1像素）切分为 2×2 或 1×N 排列的等大矩形面板。
  - 每个面板内部有一个稀疏图案，使用各不相同的单一前景色绘制在 black 背景上。
  - 不同面板中的图案形状各异，可能局部重叠也可能不重叠。

- `Rule`：
  - 移除 grey 分隔线。
  - 创建一个与单个面板等大的输出网格。
  - 将所有面板的图案叠加到输出网格上：对于输出网格的每个格子，查看所有面板中对应位置的像素。
  - 若该位置只有一个面板有非 black 像素，输出该颜色。
  - 若该位置有恰好两个面板有非 black 像素，输出 maroon。
  - 若该位置三个及以上面板有非 black 像素，输出 orange。
  - 若所有面板该位置均为 black，输出 black。

- `Key insight`：解题者需要发现输出是多个面板的"叠加投影"，且重叠区域的颜色不是由原色决定而是由重叠计数决定——单层保留原色、双层变 maroon、三层及以上变 orange。核心认知路径是"面板对齐叠加 → 重叠计数 → 分级着色"。
</new_puzzle>
