# 第一步：分析与思考

## 参考题中涉及的基础操作归纳

从 20 道参考题中可以提炼出以下基础操作类别：

1. **几何变换类**：旋转（90°/180°/270°）、镜像反射、平移滑动、缩放（放大/缩小）。
2. **模式识别与重建类**：周期性瓦片推断与修复、从不完整副本中恢复完整模板（并集重建）、遮挡下的背景恢复。
3. **空间关系与运动类**：沿路径移动到终点、重力下落与容器填充、滑动到障碍物边缘、绕障碍物绕行。
4. **匹配与配对类**：颜色匹配（标记与精灵配对）、形状匹配（缩放后的孔洞与拼块）、对称性分类与着色。
5. **结构分析类**：识别封闭区域（U 形容器、框架中的孔）、边界特征检测（凸起与凹口）、连通分量分析。
6. **组合与排列类**：按面积排序拼接、交换面板内容、拼装矩形。

## 非显而易见的串联方式思考

- **拓扑属性作为隐含编码**：一个图形的拓扑特征（如孔的数量、连通分量数、边界的弯折次数）可以编码为一个数值，而这个数值可以控制另一处的变换参数（如重复次数、颜色选择、偏移量）。这不同于直接的颜色匹配或形状匹配——信息是通过结构的"复杂度"隐含传递的。

- **阴影/投影作为信息通道**：一个三维暗示的二维投影——想象网格中的对象有"高度"（用颜色深浅或层叠关系暗示），而输出是它们在某个方向上的投影/阴影。这把空间遮挡关系变成了信息。

- **路径的语义化**：连通路径不仅是运动轨道，其几何特征（弯折方向序列、长度编码）本身可以成为指令序列，控制另一个对象的变换。

- **对称性破缺作为信号**：一个近乎对称的图形中的不对称部分，恰好编码了需要执行的操作——破缺本身就是信息。

- **负空间（背景形状）的语义角色**：前景对象围合出的背景区域的形状，可以作为一个独立的"隐形对象"参与变换逻辑。

## 创新方向

我将围绕以下全新的核心推理机制设计谜题：

1. **拓扑量化驱动变换**：图形的孔洞数量作为隐含参数控制另一处的行为。
2. **负空间形状提取与复用**：前景围合出的背景区域作为独立对象被提取和复制。
3. **路径弯折序列作为指令**：折线路径的转弯方向编码变换指令。
4. **遮挡顺序推断与分离**：从部分可见的重叠图形推断堆叠顺序并分离还原。
5. **对称轴方向作为传播方向**：对象的对称轴决定它向外发射影响的方向。
6. **边界周长作为抽象量化指标**：二维形状到一维长度的信息压缩。
7. **迷宫内的配对连线**：在约束环境中找到同色端点并连接。

<new_puzzle>
- `description`：提取前景封闭环形对象围合出的内部背景区域（负空间），用该环形的颜色填充负空间形状作为输出。

- `Input structure`：
  - 背景色为 Black。
  - 网格中有若干用不同颜色绘制的封闭环形前景对象（每个对象由单一颜色的像素组成，形成一个封闭的一像素宽环形轮廓）。
  - 每个封闭环形内部包含一片连通的 Black 背景区域（即"洞"）。
  - 环形之间互不接触、互不重叠。

- `Rule`：
  - 输出网格大小与输入相同，全部填充 Black 背景。
  - 对每个封闭环形对象，找到其内部的封闭 Black 背景区域（洞）。
  - 将该洞的形状（保持原始像素位置不变）用该环形对象的颜色填充到输出网格中。
  - 环形轮廓本身不出现在输出中，只有洞的形状以对应颜色出现。

- `Key insight`：输出中的对象不是输入中可见的前景，而是前景围合出来的不可见负空间；每个负空间继承了围合它的轮廓的颜色。解题者需要意识到"要画的东西是看不见的洞，不是看得见的框"。

<new_puzzle>
- `description`：根据每个 Grey 图形内部封闭孔洞的数量，从调色板中选取对应序号的颜色对该图形重新着色。

- `Input structure`：
  - 背景色为 Black。
  - 网格右下角有一个由 Maroon 边框围出的小矩形调色板区域（宽度足以容纳所有色块，高度为 3 行——顶行和底行是 Maroon 边框，中间行排列色块）。调色板中间行自左向右排列着若干单像素色块，颜色各不相同（例如依次为 Blue、Red、Green、Yellow、Orange），分别对应编号 0、1、2、3、4。
  - 网格其余区域散布着若干用 Grey 绘制的 4-连通实心前景图形，彼此不接触。
  - 每个 Grey 图形都是一个有可能包含孔洞的区域——某些图形有 0 个内部封闭孔洞，某些有 1 个，某些有 2 个，以此类推。孔洞是被 Grey 像素在 4-连通意义下完全包围的连通 Black 区域。

- `Rule`：
  - 输出网格大小与输入相同。调色板区域保持不变。
  - 对每个 Grey 图形，计算其内部封闭 Black 孔洞的数量 n（不计算与网格边缘相连的 Black 区域）。
  - 将该图形的所有 Grey 像素替换为调色板中第 n 个位置（从 0 开始，自左向右计数）的颜色。
  - 孔洞区域保持 Black 不变。

- `Key insight`：图形的着色不取决于位置、大小或外形轮廓，而取决于其拓扑属性——内部孔洞的数量。解题者需要发现"颜色由洞的数目决定"这一反直觉的映射关系，并利用调色板进行对照。关键困难在于：一个大而简单的实心图形（0 个洞）和一个小而有洞的图形可能外观上看起来完全不同，但决定颜色的唯一因素是孔洞计数。
</new_puzzle>

<new_puzzle>
- `description`：沿每条 Grey 折线路径标记拐弯处的像素颜色——左转为 Red、右转为 Blue，直行和端点保持 Grey。

- `Input structure`：
  - 背景色为 Black。
  - 网格中有一条或多条由 Grey 像素组成的一像素宽折线路径。每条路径是 4-连通的，从一端到另一端不分叉，且每个 Grey 像素最多有两个 Grey 4-邻居（即路径无交叉无分支）。
  - 路径由水平段和垂直段交替组成，在方向变化处产生 90 度拐弯。
  - 每条路径恰好有两个端点（只有一个 Grey 4-邻居的像素），其中一个端点旁紧邻一个 Green 单像素标记（与端点 4-相邻），用来指示遍历起始端。Green 标记不属于路径本身。

- `Rule`：
  - 从带有 Green 标记的端点出发，沿路径依次遍历每个 Grey 像素。
  - 在遍历过程中，对于每个拐弯处的像素（即前一段行进方向与后一段行进方向发生 90 度变化的像素），判断转弯方向：如果相对于当前行进方向向左转，则将该像素改为 Red；如果向右转，则改为 Blue。
  - 所有非拐弯处的路径像素（包括两个端点和所有直行像素）保持 Grey。
  - Green 起始标记像素在输出中移除（变为 Black）。

- `Key insight`：路径本身的几何位置没有变化，改变的只是拐弯点的颜色。解题者需要发现标记颜色与转弯方向（左/右）之间的对应关系，并且需要注意 Green 标记指示了遍历的起始方向（因为同一个拐弯从不同方向经过时，左右判断会反转）。核心在于将路径的局部几何特征（相对转弯朝向）映射为颜色属性。
</new_puzzle>

<new_puzzle>
- `description`：将部分重叠的彩色矩形按遮挡关系从前到后排序，在输出中从左到右依次排列完整还原的矩形。

- `Input structure`：
  - 背景色为 Black。
  - 网格中有若干不同颜色的实心矩形（至少 3 个），它们部分重叠。
  - 每个矩形颜色唯一（不同矩形颜色不同），且每个矩形的四条边中至少有两条相邻边完全可见（未被遮挡），从而可以唯一推断出该矩形的完整宽度和高度。
  - 重叠处，位于前面的矩形完全遮挡后面的矩形像素（类似画家算法）。
  - 没有矩形被完全遮挡（每个矩形至少有部分像素可见）。
  - 矩形之间的遮挡关系形成一个全序（即可以从最前到最后排成唯一的线性顺序，不存在循环遮挡）。

- `Rule`：
  - 推断每个矩形的完整尺寸：利用可见的至少两条相邻边推断出完整的宽度和高度。
  - 确定遮挡顺序：如果颜色 A 的像素覆盖了颜色 B 本应出现的矩形范围内的位置，则 A 在 B 前面。最前面（不被任何其他矩形遮挡）的排第一，最后面的排最后。
  - 输出网格高度等于所有矩形中的最大高度，宽度等于所有矩形宽度之和加上 (矩形数 - 1) 列 Black 间隔。
  - 从左到右按从前（最上层）到后（最底层）的顺序排列每个完整矩形，底部对齐，相邻矩形之间隔一列 Black。

- `Key insight`：解题者需要从部分可见的重叠矩形中"逆向推理"出每个矩形的完整尺寸以及它们的前后层次关系。关键困难在于：被遮挡的矩形的真实大小只能通过其可见边缘间接推断，而遮挡顺序需要通过分析哪些颜色在重叠区域"赢了"来确定。这是一个需要同时进行空间推理和逻辑推断的综合任务。
</new_puzzle>

<new_puzzle>
- `description`：每个彩色对象沿自身唯一对称轴方向向两侧发射同色射线，直到碰到网格边缘或其他对象。

- `Input structure`：
  - 背景色为 Black。
  - 网格中散布着若干小型彩色前景对象（每个对象由单一颜色的 4-连通像素组成，像素数在 3 到 8 之间）。
  - 每个对象恰好有一条反射对称轴，属于以下四种之一：水平轴、垂直轴、45 度对角轴（左上-右下方向）、135 度对角轴（右上-左下方向）。
  - 对象之间不接触、不重叠，且彼此之间的距离足以容纳射线。

- `Rule`：
  - 对每个对象，识别其唯一的反射对称轴方向。
  - 沿该对称轴从对象的边界向两侧延伸射线：
    - 水平对称轴：射线向左和向右延伸（沿水平方向）。射线起点为对象在对称轴所在行上最左和最右像素的外侧一格。
    - 垂直对称轴：射线向上和向下延伸（沿垂直方向）。射线起点为对象在对称轴所在列上最上和最下像素的外侧一格。
    - 45 度对角轴：射线沿左上和右下方向延伸（逐像素对角移动，行列各变化 1）。
    - 135 度对角轴：射线沿右上和左下方向延伸。
  - 射线使用该对象自身的颜色逐像素绘制，遇到网格边缘或已有非 Black 像素（包括其他对象或其他射线）时停止（不覆盖已有像素）。
  - 所有对象的射线同时确定（不存在先后顺序依赖）：若两条射线同时到达同一空白像素，该像素保持 Black。

- `Key insight`：射线的方向不是由对象的位置或颜色决定的，而是由对象自身的几何对称性决定的。解题者必须先识别每个对象的对称轴类型，才能预测射线方向。两个外观相似但对称轴不同的对象会产生完全不同方向的射线。核心推理是"形状的对称性 -> 射线方向"这个非直觉的因果链。
</new_puzzle>

<new_puzzle>
- `description`：将网格中每个彩色连通前景区域的边界周长计算出来，在输出中按周长从小到大排列为对应长度的水平彩色线段。

- `Input structure`：
  - 背景色为 Black。
  - 网格中有若干不同颜色的 4-连通实心前景对象（每个对象颜色唯一），彼此不接触，且都不含孔洞。
  - 对象的形状各异——有的紧凑（如正方形），有的细长（如 L 形或长条），导致相同面积的对象可能有不同的周长。

- `Rule`：
  - 对每个前景对象，计算其边界周长 p。周长定义为：该对象所有像素的 4-邻域中，朝向背景（Black）或网格边缘外部的边的总数。例如，一个孤立的单像素周长为 4；一个 2x2 的正方形周长为 8；一个 1x3 的横条周长为 8。
  - 输出网格宽度等于所有对象中最大周长值，高度等于前景对象的数量。
  - 将所有对象按周长从小到大排序（若周长相同，则按对象在输入中最上最左像素的位置排序——先比较行号，行号相同比较列号，靠上靠左的排在前面）。
  - 第 i 个对象（从上往下，i 从 0 开始）在输出网格的第 i 行从第 0 列开始，绘制一条长度为 p 像素的水平线段，颜色为该对象的颜色。
  - 其余位置为 Black。

- `Key insight`：输出中完全看不到原始对象的形状——形状信息被压缩为一个数值（周长）。解题者需要发现"线段长度 = 轮廓周长"这一抽象映射。关键困难在于：面积大的对象未必周长大（例如 3x3 正方形面积为 9、周长为 12；而 1x7 的长条面积为 7、周长为 16），因此排序结果违反基于面积的直觉。解题者必须尝试多种量化方式后才能锁定"周长"这一指标。
</new_puzzle>

<new_puzzle>
- `description`：在迷宫通道中找到每对同色标记像素之间的最短路径并用该颜色连线，路径交叉处用特殊颜色标记。

- `Input structure`：
  - 背景色为 Black。
  - 网格中有 Grey 像素组成的一像素宽墙壁结构，将 Black 背景分割成相互连通的通道网络。
  - 网格中散布着若干成对出现的彩色单像素标记（例如两个 Red 像素、两个 Blue 像素、两个 Green 像素等）。每种非 Grey、非 Black 颜色恰好出现两次。
  - 所有标记像素都位于通道中（Black 背景上），不在墙壁上。
  - 迷宫结构保证每对同色标记之间存在唯一一条最短 4-连通路径（沿 Black 像素行走，不穿越 Grey 墙壁）。

- `Rule`：
  - 对每对同色标记像素，沿 Black 通道找到它们之间的唯一最短 4-连通路径。
  - 将路径上的所有 Black 像素替换为该标记颜色（两个标记端点本身保持原色不变）。
  - 如果两条不同颜色的路径经过同一个像素（该像素同时位于两条最短路径上），则该像素着色为 Maroon（而非任一路径的颜色），表示"交叉桥接"。
  - Grey 墙壁像素和未被任何路径经过的 Black 像素保持不变。

- `Key insight`：解题者需要发现每种颜色恰好有两个像素是"需要连接的端点对"，然后在迷宫通道中为每对端点找到最短路径并着色。交叉点的 Maroon 特殊颜色是重要线索——它暗示了多条路径的存在以及交叉的处理规则。核心推理路径是：识别配对关系 -> 寻路 -> 处理冲突，三步环环相扣。
</new_puzzle>
