# 第一步：分析与思考

## 参考题中的基础操作梳理

参考题覆盖了以下核心操作族：
- **空间位移**：按自身面积下移/上移（#5, #6），沿方向滑到边缘（#19），重力下落到分隔线（#2）
- **对接/嵌入**：射线投射寻找方向将组件嵌入腔体（#1），子图案填充目标空洞（#14）
- **重着色/颜色交换**：根据标记颜色统一着色（#15），颜色互换后拆分对象（#20）
- **图案生成**：同心带状填充（#13），嵌套L边框+对角线（#3），角落模板展开（#17）
- **选择与裁剪**：顶边线索选择角落裁剪（#18），角落物体顺时针复制（#10）
- **排序/层级推断**：交叉遮挡推断层级顺序（#11），区域颜色多集补全（#8）
- **级联传播**：射线网络链式激活（#7），标记驱动的扫描线填充（#12）
- **几何变换**：180度旋转十字（#19），稀疏帧填密并排列精灵（#4），菱形方向臂补全（#16）

## 操作间非显而易见的串联方式

1. **属性作为隐式地址**：物体的某个可见属性（如面积、颜色频次、边长奇偶性）不用于自身变换，而是作为索引去选择另一个物体或网格位置。这种"属性即指针"的间接映射很难被直觉发现。

2. **拓扑关系编码语义**：两个对象之间的相对位置关系（如对齐的列数、包围关系、接触边数）可以编码一个离散指令——比如"做哪种变换"或"用哪种颜色"。

3. **对称性缺口作为信息载体**：一个几乎对称的图案中，打破对称的那个局部可以编码方向、选择或数量信息，而不仅仅是"需要被修复的缺陷"。

4. **计数结果的空间化表达**：某个计数结果不作为数字使用，而是转化为空间上的几何结构（如线段长度、环的层数、偏移量），使得数值推理隐藏在视觉图案中。

5. **条件分支由视觉特征触发**：同一网格中不同对象因自身形状/尺寸/颜色满足不同条件而执行不同的变换路径，但解题者需要从样例中反向推断分支条件。

6. **路径追踪作为信息传递**：从一个标记出发沿某种规则（如颜色引导、边界反弹）追踪路径，路径经过的区域被改变，而路径本身的几何形状又决定最终输出的某个属性。

<new_puzzle>
- `description`：根据每个封闭区域内部的孤立像素数量，用对应层数的同心收缩边框填充该区域。

- `Input structure`：
  - 背景色为 black。
  - 一种前景色（如 grey）绘制若干封闭的不规则多边形轮廓（轮廓线宽为1像素，4-连通封闭）。
  - 每个封闭区域内部散布若干孤立的 red 像素（与任何其他 red 像素不相邻）。
  - 轮廓外部没有 red 像素。

- `Rule`：
  - 对每个 grey 轮廓围成的封闭区域，计数其内部 red 像素的数量 N。
  - 从该区域的内边界开始，向内逐层收缩（每层收缩1像素，使用切比雪夫距离），依次用以下固定颜色序列的前 N 种颜色着色各层：blue, green, yellow, magenta, orange, azure, maroon。若 N 大于序列长度则循环使用。
  - 第1层（紧贴轮廓内侧的像素）涂序列第1色，第2层涂第2色，依此类推，共涂 N 层。超过 N 层的内部像素保持 black。
  - red 像素本身被所在层的颜色覆盖（即 red 像素消失）。
  - grey 轮廓保持不变。

- `Key insight`：区域内散布的孤立红色像素并不标记位置或方向，而是纯粹作为计数器使用——它们的数量决定同心填充的层数。解题者需要意识到红点的空间位置无关紧要，唯一重要的是它们在每个区域内的总数。
</new_puzzle>

<new_puzzle>
- `description`：每个前景对象按其自身轮廓的凸包与实际形状之间的差异区域进行自我补全，补全部分用不同颜色标记。

- `Input structure`：
  - 背景色为 black。
  - 网格中散布若干互不相邻的单色 4-连通前景对象，每个对象使用不同颜色（从 blue, red, green, yellow, magenta 中选取）。
  - 每个对象都是非凸的（即其凸包严格大于其自身像素集合）。
  - 对象之间距离足够大，使得任意两个对象的凸包不重叠。

- `Rule`：
  - 对每个前景对象，计算其像素集合的凸包（凸包定义为：包含所有对象像素的最小凸多边形，离散化到网格上）。
  - 凸包内但不属于原始对象的像素（即"凹陷缺口"）用 orange 填充。
  - 原始对象像素颜色保持不变。
  - 背景其余部分保持 black。

- `Key insight`：解题者需要识别出变换并非简单的孔洞填充或边界扩展，而是精确地计算每个形状的凸包——输出中新增的 orange 像素恰好是原形状相对于其凸包的"凹陷"。这要求理解凸包的几何概念并在离散网格上正确应用。
</new_puzzle>

<new_puzzle>
- `description`：网格中每条彩色线段充当"传送门"，将与其一端对齐的对象传送到另一端对应位置。

- `Input structure`：
  - 背景色为 black。
  - 若干条 red 直线段（水平或垂直，宽1像素，长度至少3像素）分布在网格上，互不相交。
  - 若干个小型单色 4-连通对象（颜色各异，非 red、非 black），每个对象的边界框的某一边与恰好一条 red 线段的某一端紧密相邻（即对象的一侧紧贴线段端点，中间无间隙）。
  - 每条 red 线段至多关联一个对象（在线段的某一端）。线段的另一端是空的（背景色）。

- `Rule`：
  - 对于每条 red 线段，确定其关联对象所在的端（"入口端"）和另一端（"出口端"）。
  - 将对象从入口端移除，在出口端的对应位置重新绘制该对象。"对应位置"的定义：对象相对于入口端点的偏移关系，镜像翻转到出口端点。具体来说，如果线段是水平的，对象在左端，则将对象水平翻转后放置在右端的对称位置；如果线段是垂直的，对象在上端，则将对象垂直翻转后放置在下端的对称位置。
  - red 线段本身保持不变。
  - 原对象位置恢复为背景色。

- `Key insight`：红色线段不是障碍物或边界，而是传送通道。解题者需要发现对象总是从线段的一端"穿过"到另一端，并且在穿过过程中发生了沿线段方向的镜像翻转。关键在于识别线段端点与对象的邻接关系，以及翻转轴即为线段本身的方向。
</new_puzzle>

<new_puzzle>
- `description`：网格被分隔成若干房间，每个房间的"门"（边界上的缺口）决定房间内部的填充图案旋转方向。

- `Input structure`：
  - 背景色为 black。
  - green 像素构成网格状的墙壁，将整个网格分隔为若干矩形房间（每个房间内部为纯 black 的矩形区域，被 green 墙壁包围）。
  - 每个房间的墙壁上恰好有一个1像素宽的缺口（"门"），即该边上有一个 green 像素被替换为 black。门可以在房间的上、下、左、右任意一边。
  - 每个房间内部左上角有一个 blue 像素作为种子标记。

- `Rule`：
  - 从每个房间左上角的 blue 种子像素开始，绘制一个顺时针螺旋线，螺旋线颜色为 blue。螺旋线从种子位置出发，初始方向由门的位置决定：
    - 门在上边 → 初始方向向右
    - 门在右边 → 初始方向向下
    - 门在下边 → 初始方向向左
    - 门在左边 → 初始方向向上
  - 螺旋线沿初始方向前进，每当碰到墙壁或已有螺旋线像素时顺时针转向90度继续前进，直到无法前进为止。
  - 螺旋线填满房间内部所有 black 像素（种子像素视为螺旋线起点）。
  - green 墙壁和门的缺口保持不变。

- `Key insight`：所有房间都生成了螺旋线，但不同房间的螺旋线起始方向不同，导致最终图案的旋转朝向不同。解题者需要发现门的位置（墙壁上的1像素缺口）是决定螺旋起始方向的关键——门不是用来连接房间的通道，而是一个旋转方向的编码信号。
</new_puzzle>

<new_puzzle>
- `description`：每个前景对象根据其颜色在整个网格中出现的频率排名，被缩放为对应的尺寸。

- `Input structure`：
  - 背景色为 black。
  - 网格中有若干个小型矩形色块（每个色块为纯色填充的矩形，宽高均为2x2像素），每个色块使用不同颜色，颜色从 blue, red, green, yellow, magenta, orange, azure, maroon 中选取。
  - 此外，网格中散布有与这些色块颜色相同的孤立单像素（不与任何色块相邻，也不互相相邻），作为频率标记。
  - 每种前景颜色的总像素数（色块像素 + 散布像素）各不相同。

- `Rule`：
  - 统计每种前景颜色在整个网格中的总像素数。
  - 按总像素数从少到多排序，得到排名 rank（从1开始）。
  - 将每个2x2色块替换为 rank x rank 大小的同色正方形，以原色块左上角为锚点向右下方扩展。
  - 散布的孤立像素全部清除为背景色。
  - 若扩展后的正方形超出网格边界，则裁剪到网格边界内。

- `Key insight`：散布在网格各处的孤立像素看似是噪声或装饰，实际上它们与色块合计的总数决定了该颜色的频率排名，而排名又转化为色块的缩放倍数。解题者需要发现两个反直觉的关联：(1) 分散的像素与色块在逻辑上属于同一组；(2) 重要的不是像素总数本身，而是各颜色之间的相对排名。
</new_puzzle>

<new_puzzle>
- `description`：将网格中的箭头形状对象沿其指向方向发射，箭头在碰到其他对象时将目标对象"推动"一格并自身停止。

- `Input structure`：
  - 背景色为 black。
  - 网格中有若干 4-连通前景对象，分为两类：
    - **箭头**：由5个像素组成的箭头形状，颜色为 red。箭头的绘制方式为：一个3像素的直线段作为箭杆，箭杆前端（尖端方向）的左右各1像素构成箭头尖。例如，向右的箭头形状为：中间行3个像素从左到右，加上最右列的上下各1个像素（即 ">" 形）。箭头可朝上、下、左、右四个方向。
    - **目标块**：由各种颜色（非 red、非 black）组成的矩形实心色块（尺寸不一），静止在网格中。
  - 箭头与目标块之间有间距，箭头的尖端方向上存在至少一个目标块。

- `Rule`：
  - 每个 red 箭头沿其尖端指向的方向移动，直到箭头尖端的下一个像素是某个目标块的边缘像素为止（即箭头紧贴目标块停下）。
  - 被箭头紧贴的目标块沿同一方向被推动恰好1个像素。
  - 若目标块被推动后又紧贴另一个目标块，不会产生连锁推动——只有箭头直接接触的目标块被推动。
  - 箭头的原始位置恢复为背景色。
  - 若箭头指向方向上没有目标块（直到网格边缘都没有），箭头移动到网格边缘停下，不推动任何东西。

- `Key insight`：箭头形状本身编码了移动方向——解题者需要识别出5像素的 ">" 形图案是一个朝右的箭头，从而推断移动方向。难点在于从形状中读出方向信息，并理解箭头是"发射体"而目标块是"被推体"的物理隐喻，而非简单的平移或复制。
</new_puzzle>

<new_puzzle>
- `description`：网格中有若干带缺口的矩形环，每个环的缺口位置和宽度编码了一条"指令"，决定环内部区域如何被填充。

- `Input structure`：
  - 背景色为 black。
  - 若干个不同颜色的矩形环（1像素宽的矩形轮廓框，每个使用不同颜色如 blue, green, yellow, magenta 等），彼此不重叠、不相邻。
  - 每个矩形环的四条边中恰好有一条边存在一个连续缺口（该边上若干连续像素缺失，恢复为 black）。缺口位置可在上、下、左、右任意一边。
  - 缺口宽度为1到3像素不等。

- `Rule`：
  - 缺口所在的边决定填充方向：
    - 缺口在上边 → 内部从下向上逐行填充
    - 缺口在下边 → 内部从上向下逐行填充
    - 缺口在左边 → 内部从右向左逐列填充
    - 缺口在右边 → 内部从左向右逐列填充
  - 缺口宽度决定填充的行/列数：缺口宽度为 W 像素，则从填充起始方向开始填充 W 行（或列）。
  - 填充颜色与矩形环自身颜色相同。
  - 未被填充的内部像素保持 black，矩形环本身（包括缺口处的空缺）保持不变。

- `Key insight`：矩形环的缺口同时编码了两个维度的信息：缺口的位置（上/下/左/右）编码填充方向，缺口的宽度编码填充量。解题者需要同时发现这两层编码关系——仅注意到缺口位置或仅注意到缺口宽度都无法完整解释所有样例。
</new_puzzle>

<new_puzzle>
- `description`：网格中散布的彩色像素对根据连线方向不同而触发不同的区域标记行为——水平配对在两点之间画水平带，垂直配对在两点之间画垂直带，而对角配对则填充两点定义的矩形区域。

- `Input structure`：
  - 背景色为 black。
  - 网格中散布若干对相同颜色的像素（每种颜色恰好出现两次），使用的颜色包括 blue, red, green, yellow, magenta, orange 等。
  - 同色像素对之间的空间关系分为三种情况：
    - 同行（相同 row，不同 column）：水平对
    - 同列（相同 column，不同 row）：垂直对
    - 既不同行也不同列：对角对
  - 不同颜色的像素对之间不存在空间冲突。

- `Rule`：
  - **水平对**：将同行两个像素之间（含两端像素）的所有像素填充为该颜色，形成一条水平线段。
  - **垂直对**：将同列两个像素之间（含两端像素）的所有像素填充为该颜色，形成一条垂直线段。
  - **对角对**：将以两个像素为对角顶点的矩形区域内的所有像素填充为该颜色（实心矩形）。
  - 若不同颜色的填充区域重叠，则后处理的颜色覆盖先处理的（处理顺序按颜色对中两像素的左上角像素的行优先坐标从小到大排列）。

- `Key insight`：所有颜色对都执行"连接两点"的操作，但连接方式取决于两点的空间关系——这不是一个统一的规则，而是一个隐含的条件分支。解题者需要注意到同行对只画线段而非矩形、同列对也只画线段，只有对角放置的点对才展开为矩形区域。这个分支条件隐藏在点对的几何关系中，不容易一眼看穿。
</new_puzzle>
