# 第一步：分析与思考

## 参考题中的基础操作梳理

参考题涉及的基础操作包括：边缘匹配排序（#1）、标记-中心提取（#2）、投影对齐与堆叠（#3）、跨框架槽位推断（#4）、缺陷检测与光晕标记（#5）、区域颜色旋转（#6）、标记传播到邻接区域（#7）、局部反转（#8）、稀疏采样补全矩形（#9）、路径规避带参数化禁区（#10）、轴线指导镜像/填充（#11）、缩放-反射复制（#12）、颜色-方向匹配位移（#13）、行内颜色反转（#14）、对称拼图组装（#15）、连接器配对组装（#16）、轮廓膨胀/收缩（#17）、图例驱动填充（#18）、连接器-锚点角色互换（#19）、控制位驱动差异行为（#20）。

## 非显而易见的串联方式与信息编码思考

1. **形状本身作为指令编码器**：一个对象的几何形态（凹凸、缺口方向、不对称点）不仅是需要被变换的对象，更可以编码"如何变换其他对象"的指令。例如，一个形状的轮廓拐角序列可以编码一条路径的转弯指令。

2. **拓扑关系作为隐性通道**：两个对象之间的"包围"、"穿越"、"桥接"等拓扑关系可以传递信息。比如一根线段穿过几个区域决定了那些区域的排列顺序。

3. **缺失信息的反面推理**：网格中"不存在"的东西可能是关键线索——某种颜色在某个区域的缺失、某个方向上的空白、某种对称性的破缺，都可以作为变换的触发条件。

4. **视觉遮挡与图层还原**：多个对象在视觉上重叠时，需要根据部分可见信息推断完整形态，这模拟了人类的遮挡补全能力。

5. **因果链跨区域传播**：一个区域的变换结果成为另一个区域变换的前提条件，形成级联效应，需要找到正确的执行顺序。

6. **对象间的"对话"关系**：两个对象各自提供部分信息，组合起来才能确定变换规则——比如一个提供"做什么"，另一个提供"在哪做"。

<new_puzzle>
- `description`：根据每个封闭区域内部"缺口墙壁"的方向，将区域内的彩色像素沿该方向推出并堆积在区域外壁上。

- `Input structure`：
  - 背景色为 black。
  - 网格中有若干由 grey 像素构成的近似矩形封闭围墙，每个围墙恰好在一面墙壁上有一个连续缺口（即该面墙壁有一段被删除，形成开口）。
  - 每个封闭区域内部散落着若干彩色像素（非 grey、非 black），颜色各异但每个区域内的所有彩色像素同色。
  - 围墙之间不重叠，且彼此之间有足够间距。

- `Rule`：
  - 对每个围墙区域，找到其缺口所在的方向（上、下、左、右）。
  - 将该区域内部的所有彩色像素视为独立个体，各自沿缺口方向平移，穿过缺口，直到碰到网格边界或另一个 grey 围墙的外壁，然后紧贴停靠。像素之间也会相互堆叠（后续像素停靠在已停靠像素之前）。
  - 平移时保持像素在垂直于推出方向的轴上的坐标不变。
  - 只有位于缺口列（或行）范围内的像素才会被推出；不在缺口范围内的像素保持原位。
  - 围墙本身（grey 像素）保持不变。

- `Key insight`：围墙缺口的位置同时编码了两层信息——推出的方向和哪些像素会被推出（只有与缺口在同一行/列的像素才穿过缺口）。解题者需要先识别每个围墙的开口方向，再判断哪些内部像素在缺口的"投影范围"内。
</new_puzzle>

<new_puzzle>
- `description`：将网格中的多条折线路径按照它们与"调色板行"的交叉顺序重新着色，每条路径获得其穿越的调色板色块的颜色。

- `Input structure`：
  - 背景色为 black。
  - 网格顶部有一行"调色板行"：由若干不同颜色的连续色段组成（例如从左到右依次为 red 段、blue 段、green 段、yellow 段），段与段之间没有间隔，每段宽度不等。调色板行占据第 0 行整行。
  - 网格其余部分有若干条由 grey 像素绘制的折线路径（4-连通），每条路径从调色板行的正下方（第 1 行）某处起始，向下延伸，可以水平或垂直转折，但各路径之间不交叉、不接触。
  - 每条路径恰好有一个像素位于第 1 行，直接位于调色板行的某个色段下方。

- `Rule`：
  - 每条 grey 折线路径的起始像素（第 1 行）位于调色板行某个颜色段的正下方。
  - 将该路径的所有像素重新着色为其起始像素正上方调色板色段的颜色。
  - 调色板行本身保持不变。

- `Key insight`：所有路径在输入中都是同一种 grey 色，视觉上无法区分；解题者必须先对路径做连通分量分析，将每条路径追溯到其起点，再通过起点与调色板行的空间对应关系确定每条路径应获得的颜色。路径的走向和形状本身不影响着色——唯一决定因素是起点在调色板中的位置。
</new_puzzle>

<new_puzzle>
- `description`：网格中散布着若干"时钟"图案，每个时钟的指针方向决定了其周围卫星像素的旋转偏移量，输出时将卫星像素绕时钟中心旋转相应角度。

- `Input structure`：
  - 背景色为 black。
  - 网格中有若干个"时钟"结构，每个时钟由以下部分组成：
    - 一个 3×3 的 grey 方块作为钟面（中心像素为 grey）。
    - 从 3×3 方块中心向外延伸出一条由 red 像素构成的长度为 2 的直线段，方向为上、右、下、左四个基本方向之一，称为"指针"。指针方向分别编码旋转量：上=0°（不旋转）、右=顺时针90°、下=180°、左=逆时针90°（即顺时针270°）。
    - 在 3×3 钟面外围（5×5 范围内，不含指针方向），有 1-3 个彩色"卫星"像素，颜色各异（非 grey、非 red、非 black），位于钟面的四个正交邻接位置（上、下、左、右各一格）或四角位置。
  - 各时钟结构之间不重叠，间距足够。

- `Rule`：
  - 对每个时钟，读取其 red 指针方向，确定旋转角度（上=0°、右=90°顺时针、下=180°、左=270°顺时针）。
  - 将该时钟的所有卫星像素绕钟面中心按该角度顺时针旋转到新位置。
  - 旋转后，卫星像素出现在新坐标上，原位置恢复为 black。
  - red 指针和 grey 钟面保持不变。

- `Key insight`：red 指针看起来像是时钟结构的装饰元素，但实际上它编码了一个旋转指令。解题者需要发现：(1) 指针方向与卫星位移之间的对应关系，(2) 旋转是以钟面中心为原点的刚体变换。容易犯的错误是把指针理解为指示卫星移动的目标方向，但实际上指针指的是旋转量。
</new_puzzle>

<new_puzzle>
- `description`：在一张包含"源图案"和若干"投影屏幕"的网格中，根据每面屏幕相对于源图案的方位，将源图案的对应正交投影（行剖面或列剖面）绘制到屏幕上。

- `Input structure`：
  - 背景色为 black。
  - 网格中央偏某方向有一个由多种颜色构成的小型矩形图案（例如 5×5），称为"源图案"，其内部像素颜色丰富。
  - 网格中另有若干条由 grey 像素构成的单像素宽直线段，称为"屏幕"。每条屏幕要么是水平的，要么是垂直的。
  - 水平屏幕的长度等于源图案的列数；垂直屏幕的长度等于源图案的行数。
  - 每条屏幕与源图案之间有明确的空间方位关系（位于源图案的正上方、正下方、正左方或正右方，即屏幕的中点与源图案在相应轴上对齐）。

- `Rule`：
  - 位于源图案正上方或正下方的屏幕是水平的：将源图案的每一列压缩为该列中出现次数最多的非 black 颜色（若平局则取该列中最靠近屏幕方向的那个颜色），生成一个 1×W 的颜色行，绘制到屏幕上替换 grey 像素。
  - 位于源图案正左方或正右方的屏幕是垂直的：将源图案的每一行压缩为该行中出现次数最多的非 black 颜色（若平局则取该行中最靠近屏幕方向的那个颜色），生成一个 H×1 的颜色列，绘制到屏幕上替换 grey 像素。
  - 源图案本身保持不变。

- `Key insight`：屏幕的朝向和位置决定了投影的类型——水平屏幕接收列投影，垂直屏幕接收行投影。这是一种"正交投影"的空间推理：解题者需要理解源图案在不同轴向上被压缩的方式，以及屏幕位置如何选择投影轴。平局打破规则（选最靠近屏幕的颜色）增加了一层需要从样例中发现的隐蔽细节。
</new_puzzle>

<new_puzzle>
- `description`：网格中有多个彩色岛屿和连接它们的灰色桥梁，根据桥梁的长度将对应岛屿的颜色混合，短桥连接的岛屿互换颜色，长桥连接的岛屿各自保留原色。

- `Input structure`：
  - 背景色为 black。
  - 网格中有若干个由单一非 black、非 grey 颜色填充的矩形区域，称为"岛屿"。每个岛屿大小为 2×2 或 3×3，颜色各不相同。
  - 岛屿之间通过 grey 像素构成的单像素宽水平或垂直直线段相连，称为"桥梁"。桥梁的两端分别紧邻（4-连通）两个不同岛屿的边缘。
  - 每个岛屿最多连接两座桥梁。网格中的桥梁将所有岛屿连成若干条链（不分叉）。
  - 桥梁长度各异（以像素数计量，不含岛屿自身的像素）。

- `Rule`：
  - 在每条链中，找到最短的那座桥梁（链内桥梁长度两两不同）。
  - 最短桥梁两端的两个岛屿互换颜色。
  - 链中其他桥梁连接的岛屿保持原色不变。
  - 所有桥梁（grey 像素）保持不变。
  - 若某条链只有一座桥梁，则该桥梁即为最短桥，两端岛屿互换颜色。

- `Key insight`：解题者可能首先尝试基于岛屿大小、颜色或位置来寻找规则，但实际驱动变换的是桥梁长度这一不太起眼的几何属性。进一步的隐蔽性在于：只有每条链中最短的桥才触发互换，其余桥梁是"沉默"的。需要对比多个样例才能排除其他假设，锁定"链内最短桥触发互换"这一规则。
</new_puzzle>

<new_puzzle>
- `description`：网格被划分为若干矩形房间，每个房间有一扇门（墙壁缺口）和一个彩色种子像素；输出时种子像素按照"洪水填充"方式扩散到整个房间，但门的存在允许颜色溢出到相邻房间——最终每个房间被最先到达它的颜色填满。

- `Input structure`：
  - 背景色为 black（代表空地板）。
  - 网格由 grey 像素构成的单像素宽墙壁分隔为若干矩形房间。墙壁构成完整的网格状结构，但每面内墙上恰好有一个 1 像素宽的缺口，称为"门"。
  - 外围边界完全封闭（无缺口）。
  - 部分房间内有一个彩色种子像素（非 grey、非 black），位于房间内部任意位置。每个有种子的房间只有一个种子，颜色各不相同。部分房间没有种子。

- `Rule`：
  - 模拟同步洪水填充：每一步，每个已着色像素向其 4-连通邻居中的 black 像素扩散自身颜色。grey 墙壁像素永远不会被覆盖。
  - 门（墙壁缺口）允许颜色穿过进入相邻房间。
  - 当两种颜色同时到达同一像素时（曼哈顿距离到各自最近种子相等），该像素保持 black（两色抵消，不着色）。
  - 填充完成后，每个房间的内部大部分被最先到达的颜色占据；距离恰好相等的边界像素保持 black。
  - 种子像素保持原色。Grey 墙壁保持不变。

- `Key insight`：表面上看是简单的填色问题，但门的位置和种子到门的距离共同决定了哪个颜色先"入侵"无种子的房间。解题者需要理解：(1) 填充是逐步扩散的距离竞赛，(2) 门是颜色通行的唯一通道，(3) 种子到目标房间的曼哈顿路径长度（经过门）决定了胜负。等距冲突区域保持 black 这一规则需要从样例中仔细观察才能发现。
</new_puzzle>

<new_puzzle>
- `description`：网格中有若干"信封"图案（由外框和内部信纸组成），根据信封开口方向将信纸抽出并放置在信封外侧的对应位置。

- `Input structure`：
  - 背景色为 black。
  - 网格中有若干个"信封"结构，每个信封由以下部分组成：
    - 一个由某种颜色（如 blue、green、orange 等，各信封颜色不同）构成的矩形空心外框（单像素宽），大小至少为 5×5。
    - 外框的四条边中，恰好有一条边的中间部分被删除了 1-3 个像素（形成开口），称为"信封口"。开口处为 black。
    - 外框内部有一个由另一种颜色构成的更小实心矩形，称为"信纸"。信纸与外框之间有至少 1 像素的 black 间隙。信纸的大小刚好可以从开口方向滑出（信纸在开口方向上的正交维度不超过开口宽度）。
  - 各信封之间有足够间距。

- `Rule`：
  - 对每个信封，确定其开口方向（上、下、左、右）。
  - 将信纸从信封内部移除（原信纸位置变为 black）。
  - 将信纸放置在信封外侧、开口方向一侧，紧贴外框外壁。具体位置：信纸沿开口方向平移，保持在垂直于开口方向的轴上居中于开口位置，信纸的靠近外框一侧紧贴外框外边缘（间距为 1 像素）。
  - 外框（含开口）保持不变。

- `Key insight`：关键在于识别外框上的缺口——它不是破损，而是功能性的"出口"。信纸的移动方向完全由开口方向决定，而非由信纸或信封的颜色、大小决定。解题者需要先识别出"信封-信纸"结构，再发现开口方向与信纸位移方向的对应关系。容易混淆的是将开口理解为"入口"而非"出口"，但对比样例可以消除歧义。
</new_puzzle>
