根据封闭区域内部的颜色种类数，选择对应的边框模板为该区域加壳。

Input structure:
- bg = azure。网格上散布着若干不规则的封闭前景区域（4-连通连通块），每个区域由多种非背景色像素混合组成，且各区域彼此不相邻（至少间隔 2 格）。
- 网格底部有一排"模板条"区域，由 grey 竖线分隔成若干小格。每个小格包含两部分：上方是一个小型封闭环形边框图案（如 3x3 方环、3x3 菱形环——即四角缺失的方环、3x3 十字环——即四角缺失且四边中点外凸一格的环），下方是用 maroon 像素拼成的简易数字图案（1、2、3、4，高度不超过 3 像素，宽度不超过 3 像素，形如像素字体的阿拉伯数字）。

Rule:
- 对网格上每个封闭前景区域，数其内部包含多少种不同的非背景色（范围 1-4）。
- 在底部模板条中找到 maroon 数字与该颜色种类数相等的小格，取其中的环形边框图案作为边框样式。
- 以该区域的 bounding box 为基准向外扩展 1 格，用匹配到的环形图案的角部样式处理四角：方环模板 → 四角填满（标准矩形框）；菱形环模板 → 四角各空一格；十字环模板 → 四角各空一格且四边中点各向外多延伸一格。边框线宽始终为 1 像素。
- 边框颜色 = 该区域中占据像素数最多的那种前景色。
- 底部模板条区域在输出中被移除（输出网格高度相应缩小）。

Key insight: 颜色种类数是检索边框模板的隐含键；解题者需先识别模板条中数字图案与数值的对应关系，再对每个区域进行颜色种类计数并匹配模板，最后确定边框颜色为面积最大色——这是三层独立推理。
</new_puzzle>

<new_puzzle>
沿着彩色路径行走，在每个拐弯处根据转向方向在外侧播种颜色标记，播种颜色与转向方向相反。

Input structure:
- bg = black。网格中有一条由 green 像素构成的单像素宽的 4-连通路径（无分叉），路径从网格的某一条边的像素出发，蜿蜒后终止于另一条边的像素。
- 路径的起点（靠近网格边缘的端点，若两端都在边缘则取行号更小的，行号相同则取列号更小的）旁边恰好有两个紧贴的彩色像素：一个 red、一个 blue，分别位于起点相对于路径初始前进方向的左侧和右侧。

Rule:
- 从路径起点出发，确定初始前进方向（沿路径走向下一个 green 像素的方向）。根据起点旁 red 和 blue 的位置确定"左色"和"右色"：若 red 在前进方向左侧则左色 = red、右色 = blue，反之亦然。
- 沿路径逐格行走。每当路径发生 90 度转弯时，判断是左拐还是右拐。
- 若左拐：在拐弯格的右侧（外侧）紧邻的背景格上放置"左色"像素。
- 若右拐：在拐弯格的左侧（外侧）紧邻的背景格上放置"右色"像素。
- 即播种颜色与转弯方向相反——左拐播右侧但用左色，右拐播左侧但用右色。
- 若外侧目标格已被非背景色占据，则跳过不播种。
- 路径本身和起点旁的 red/blue 标记保持不变。

Key insight: 起点旁的两色标记定义了左右颜色约定，但播种规则是"反向"的——左拐时在外侧（右侧）播左色，右拐时在外侧（左侧）播右色。解题者必须先从标记推断左右颜色映射，再发现转弯方向与播种颜色之间的反转关系，这两步归纳缺一不可。
</new_puzzle>

将散落的形状碎片根据锯齿边缘的互补性配对拼合为矩形，并按面积排序输出。

Input structure:
- bg = azure。网格中散布着偶数个（4-8 个）非背景色的 4-连通连通块，每个块仅使用一种非背景色。
- 每个块的整体轮廓近似矩形，但恰好有一条边呈锯齿状（凸凹交替），其余三条边平直。锯齿边朝向上、下、左或右之一。
- 锯齿的凹凸深度为 1 格，即凸出部分比基线多 1 格，凹入部分比基线少 1 格。

Rule:
- 两个块可以配对当且仅当：（a）它们的锯齿边朝向正好相对（一个朝右、另一个朝左；或一个朝下、另一个朝上），（b）两者的锯齿边长度相同，（c）将两块锯齿边对齐时，一个的凸出位置恰好对应另一个的凹入位置（形状完全互锁），拼合后形成无间隙的完整矩形。
- 将配对的两块沿锯齿边平移拼合（不旋转、不翻转），合并后矩形中每个像素保留其原始颜色。
- 输出网格中，所有合并后的矩形按面积（像素总数）从小到大从左到右排列，矩形之间间隔 1 列背景色，所有矩形底边对齐于输出网格底部。输出网格高度 = 最高矩形的高度，宽度 = 所有矩形宽度之和 + 间隔列数。

Key insight: 配对的核心在于识别锯齿边的正负互锁关系（凸对凹）——这不是颜色匹配或简单大小匹配，而需要观察空间形状的互补性。配对后再按面积排序输出是第二层独立推理。
</new_puzzle>

<new_puzzle>
根据"信号塔"的天线方向发射射线，每个"接收器"取命中它的最近信号塔的颜色。

Input structure:
- bg = black。网格中有两类对象：
- 信号塔：一个 3x3 的实心彩色方块（各塔颜色互不相同，如 red、blue、green、yellow 等），其某一侧（上、下、左或右）紧贴着一段由 grey 像素组成的 1 像素宽、长 2 格的直线段——即"天线"，天线从方块边缘向外延伸，指示广播方向。
- 接收器：一个 2x2 的 grey 方块，分散在网格各处，不与任何信号塔相邻。

Rule:
- 每座信号塔沿其天线所指方向（从天线末端继续延伸的方向）发射一条 1 像素宽的虚拟射线，射线沿天线延长线方向逐格前进直到网格边界。射线不在输出中实际绘制，仅用于判定命中关系。
- 若射线经过某个接收器所占的 2x2 区域中的任意一格，则该接收器"收到"该信号塔的信号。
- 每个接收器可能被多条射线命中。对于每个被命中的接收器，比较所有命中它的信号塔到该接收器的直线格数距离（射线从天线末端到接收器被命中像素经过的格数），取距离最小的信号塔的颜色，将该接收器的 2x2 区域从 grey 重绘为该颜色。
- 若距离最小的信号塔有多个（平局），取这些信号塔中在网格上位置最靠上（行号最小）的，若行号也相同则取最靠左（列号最小）的。
- 未被任何射线命中的接收器保持 grey 不变。
- 信号塔及其天线在输出中保持不变。

Key insight: 解题者需要三步推理——首先识别天线方向以确定每座塔的射线路径，然后判断哪些接收器被哪些射线命中，最后通过简单数格比较距离远近决定接收器的最终颜色。天线方向的识别和距离比较都是肉眼可直接完成的视觉判断。
</new_puzzle>

<new_puzzle>
在嵌套同心框架内部，根据框架层数对最内层图案的颜色进行迭代映射变换。

Input structure:
- bg = black。网格中有若干独立的"嵌套框架"对象（彼此不相邻，间隔至少 2 格）。
- 每个嵌套框架由 1-4 层同心矩形环构成，每层环使用各不相同的纯色，环宽均为 1 像素。最内层（最中心）包含一个由若干种非背景色像素组成的小图案（3x3 或 4x4 大小的简单几何形如 L 形、T 形等）。
- 网格的左下角落有一个"颜色映射图例"：由若干行组成，每行恰好包含两个水平相邻的像素——左侧像素颜色为"原色"，右侧像素颜色为"目标色"。每行之间间隔 1 行背景色。图例定义了一组颜色→颜色的替换映射（例如 red→blue、blue→green、green→red）。

Rule:
- 对每个嵌套框架，数其环的层数 N（从最外环到最内层图案之间有多少个矩形环）。
- 对最内层图案中的每个像素，应用颜色映射图例 N 次迭代：第 1 次将所有匹配原色的像素替换为目标色；第 2 次对第 1 次的结果再次应用同一套映射；如此重复共 N 次。若某像素颜色不在图例的"原色"列中，则该像素在该次迭代中保持不变。
- 各层矩形环本身保持不变，仅最内层图案的颜色发生变化。
- 图例区域在输出中保持不变。

Key insight: 环的层数不仅是装饰——它决定了颜色映射的迭代次数。若图例包含颜色链（如 A→B、B→C），单次映射将 A 变为 B，但两次迭代后 A 变为 C。解题者需要先理解图例定义的映射关系，再发现层数控制迭代次数，最后追踪多次映射后的颜色链式传递效果。
</new_puzzle>

<new_puzzle>
在网格中根据"窗户"图案的朝向和所在楼层，确定其照明颜色：朝向决定色系，楼层决定深浅。

Input structure:
- bg = azure。网格中有若干"建筑"——由 grey 像素构成的大矩形块（宽 5-8 格，高 8-15 格），矩形内部被 grey 填满。
- 每栋建筑内部有若干 2x2 的"窗户"孔洞（孔洞内为背景色），排列成若干行若干列的网格状布局。每个窗户的某一侧（上、下、左或右）紧邻一个 1x2 或 2x1 的"窗台"——由 maroon 像素组成的小条，窗台方向指示窗户朝向。
- 网格底部（建筑下方）有一个"调色板"行：包含两组颜色对。第一组由 red 和 yellow 像素（从左到右排列，间隔 1 格），第二组由 blue 和 green 像素。两组之间间隔 2 格背景色。

Rule:
- 窗户朝向（窗台所在方向）分为水平类（左或右）和垂直类（上或下）。
- 调色板中第一组颜色（red、yellow）对应水平类窗户，第二组颜色（blue、green）对应垂直类窗户。
- 对每栋建筑，将窗户按行分层：最上面一行窗户为顶层，最下面一行为底层。若窗户在建筑上半部分（从顶层起算在前一半的行），使用该色系的第一个颜色（水平类用 red，垂直类用 blue）；若在下半部分，使用第二个颜色（水平类用 yellow，垂直类用 green）。若窗户行数为奇数，正中间行归入上半部分。
- 将每个窗户的 2x2 背景色孔洞填入对应颜色。窗台（maroon）保持不变。
- 调色板行在输出中保持不变。

Key insight: 解题者需要先通过窗台位置推断每个窗户的朝向（水平 vs 垂直），再从调色板中理解两组颜色分别对应两种朝向类别，最后发现楼层高低（上半 vs 下半）在同一色系中选择具体颜色——三步推理环环相扣，且朝向与色系的对应关系必须从样例中归纳，无法从单一样例确定。
</new_puzzle>
