<description>
根据框架内部缺口的朝向选择对应的外部碎片，再按碎片上标记色块的数量决定填入时的旋转次数。

Input structure:
- bg = Black。网格中散布若干大小相同的正方形空心框架（边框颜色各不相同，如 Red、Blue、Green 等），每个框架恰好在四条边之一上有一个 2 格宽的缺口（即该边被打断）。
- 框架外部散落着与框架数量相同的实心矩形碎片，每块碎片的尺寸恰好能填满框架的内部空腔。碎片由两种颜色组成：主体色与框架颜色一一对应（用于匹配），以及 1-3 个 Orange 标记像素分布在碎片的一条边上。

Rule:
- 第一步（匹配）：将每块碎片与边框颜色相同的框架配对。
- 第二步（旋转）：数出碎片上 Orange 标记像素的个数 N（1、2 或 3）。将碎片顺时针旋转 N×90° 后，放入框架内部。
- 第三步（放置）：碎片放入后，Orange 标记像素保留在输出中；框架缺口保持不变（不被填充）。碎片原来的位置变为 Black 背景。

Key insight:
缺口方向本身只是视觉线索而非直接规则——真正决定碎片朝向的是 Orange 标记的数量所编码的旋转次数。解题者必须同时发现颜色匹配规则和标记-旋转编码两层逻辑。
</description>

<description>
在网格中找到被分隔线划分的多个区域，根据每个区域内"种子图案"的对称性类型决定该区域的填充方式。

Input structure:
- bg = Azure。网格被 Grey 分隔线划分为若干矩形区域（类似窗格）。
- 每个区域内有一个由单色像素组成的小型"种子图案"（3×3 至 5×5），位于区域的左上角。种子图案使用不同颜色（Red、Green、Blue、Yellow、Magenta 等）。
- 种子图案具有以下三种对称性之一：(a) 水平对称（左右镜像）、(b) 垂直对称（上下镜像）、(c) 既水平又垂直对称（四向对称）。

Rule:
- 若种子图案仅具有水平对称性：将种子图案沿水平方向镜像复制，铺满该区域的整个宽度（从左向右重复"原始-镜像-原始-镜像..."的序列），垂直方向不扩展。
- 若种子图案仅具有垂直对称性：将种子图案沿垂直方向镜像复制，铺满该区域的整个高度（从上向下重复"原始-镜像-原始-镜像..."的序列），水平方向不扩展。
- 若种子图案同时具有水平和垂直对称性：将种子图案沿两个方向同时镜像平铺，铺满整个区域。
- 超出区域边界的部分被裁剪。种子图案自身的颜色保持不变。

Key insight:
解题者不仅需要识别每个种子的对称类型（这需要逐个检查，不能一眼看出），还需要发现对称类型与铺展方向之间的非直觉映射关系——水平对称导致水平铺展，而非直觉上的"已经对称所以不需要铺展"。
</description>

<description>
将散落的彩色"箭头"按其指向方向发射射线，射线遇到其他箭头时被吸收，最终用吸收者的颜色回填射线路径。

Input structure:
- bg = Black。网格中散布若干由 5 个像素组成的十字形箭头（一个中心像素 + 上下左右各一个像素），但其中恰好一个方向的臂被移除，形成 T 形。缺失臂的反方向即为箭头的"指向方向"。例如：缺失上臂的 T 形指向下方。
- 每个箭头有自己的颜色（Red、Blue、Green、Yellow、Magenta 等），所有箭头颜色互不相同。
- 箭头之间有足够间距，不会直接相邻。

Rule:
- 从每个箭头的中心出发，沿其指向方向逐格延伸一条射线（像素逐格填充）。
- 射线在以下情况停止：(a) 碰到网格边界；(b) 碰到另一个箭头的任意像素。
- 若射线碰到了另一个箭头 B，则整条射线（不含发射者自身像素和被击中箭头的像素）用被击中箭头 B 的颜色填充。
- 若射线碰到网格边界而非箭头，则整条射线用发射者自身的颜色填充。
- 所有射线同时计算（即一条射线不会阻挡另一条射线；先确定所有终点，再统一绘制）。
- 箭头本身的像素保持不变。

Key insight:
解题者首先需要从 T 形缺口推断箭头指向（第一层：缺失方向的反向），然后需要发现射线颜色取决于"谁接收了射线"而非"谁发射了射线"（第二层：吸收者决定颜色的逆直觉规则）。
</description>

<description>
根据封闭区域的"嵌套深度"为其上色，深度由一套隐含的颜色梯度序列决定。

Input structure:
- bg = Black。网格中由 Grey 线条绘制了若干嵌套的封闭矩形轮廓（即矩形套矩形，可能有 2-4 层嵌套）。不同组的嵌套矩形之间互不重叠。
- 在网格的一条边（如最上方一行）有一个小的颜色图例条：从左到右依次排列 4 个不同颜色的单像素点（如 Red、Blue、Green、Yellow），它们之间用 Black 背景隔开。

Rule:
- 将图例条从左到右读取为深度颜色序列：第 1 个颜色对应深度 1，第 2 个对应深度 2，以此类推。
- 对于每组嵌套矩形，最外层 Grey 轮廓和网格边界（或其他轮廓）之间的空间深度为 0（保持 Black 背景）。
- 最外层 Grey 轮廓内部（到下一层轮廓之间）的区域深度为 1，填充第 1 个图例颜色。
- 第二层轮廓内部区域深度为 2，填充第 2 个图例颜色。依此类推。
- Grey 轮廓线本身保持 Grey 不变。
- 图例条在输出中被擦除（变为 Black）。

Key insight:
解题者需要先发现边缘的颜色图例条并将其读取为有序序列（第一层推理），然后理解"嵌套深度"的概念——每穿过一层 Grey 边界深度加 1（第二层推理），最后将两者关联起来完成填色。单独看嵌套或单独看图例都不足以解题。
</description>

<description>
在网格中找到配对的形状，将每对中较小形状"投影"到较大形状内部，投影位置由两者的相对方位决定。

Input structure:
- bg = Black。网格中有若干成对的单色实心形状（连通区域）。同一对的两个形状颜色相同，不同对颜色不同（如一对 Red、一对 Blue、一对 Green 等）。
- 每对中，一个形状明显较大（面积至少为另一个的 4 倍），另一个较小。两个形状不相邻，有明显间距。
- 较大形状是填满的矩形；较小形状是不规则的（非矩形）连通图案。

Rule:
- 按颜色将形状两两配对。
- 确定较小形状相对于较大形状的方位：较小形状的中心在较大形状中心的哪个方向（上、下、左、右、左上、右上、左下、右下，共八个方向，取最近的主方向）。
- 将较小形状的图案以 Maroon 色"盖印"到较大矩形内部对应的角落或边缘位置：若小形状在大形状的左上方，则盖印到大矩形的左上角（小形状左上角对齐大矩形左上角内侧）；若在正上方，则盖印到大矩形的顶部中央；以此类推，共八个锚定位置。
- 盖印时，Maroon 像素覆盖大矩形原有的颜色像素。小形状本身从原位置擦除（变为 Black）。

Key insight:
解题者首先需要通过颜色匹配发现配对关系（第一层），然后需要发现"小形状的方位决定了它被印入大形状的哪个角落"这一空间映射规则（第二层），最后注意到投影使用了独立的 Maroon 颜色而非保持原色（容易被忽略的细节）。
</description>

<description>
根据连接线的路径形态选择变换方式：直线连接的对象互换位置，折线连接的对象互换颜色。

Input structure:
- bg = Black。网格中有若干小型单色实心方块（3×3），颜色各不相同（Red、Blue、Green、Yellow 等）。
- 方块之间由 Grey 像素绘制的连线成对连接：每条连线从一个方块的边缘出发，经过若干格到达另一个方块的边缘。
- 连线有两种形态：(a) 直线——水平或垂直的一条直线段；(b) 折线——恰好包含一个 90° 拐角的 L 形线段。
- 每个方块恰好被一条连线连接到另一个方块（即方块两两配对，不会出现一个方块连多条线的情况）。

Rule:
- 对于被直线连接的一对方块：两个方块互换位置（各自移动到对方原来的位置），颜色保持不变，连线保留。
- 对于被折线连接的一对方块：两个方块保持原位不动，但互换颜色，连线保留。
- 连线本身（Grey 像素）在输出中保持不变。

Key insight:
解题者首先需要识别方块之间的配对关系（通过连线追踪），然后需要发现连线的几何形态（直 vs. 折）决定了变换的类型（换位 vs. 换色）——这是一个"形态编码操作类型"的隐蔽规则，仅从一个样例难以区分两种情况。
</description>

<description>
在网格中识别由边框围成的"房间"，根据房间入口的数量决定内部填充图案的密度层级。

Input structure:
- bg = Azure。网格中由 Maroon 像素绘制了若干不规则但封闭的"房间"轮廓（连通的 Maroon 边框围成的区域）。
- 每个房间的 Maroon 边框上有 1 至 3 个"入口"——即边框上被打断的 1 格宽缺口（缺口处为 Azure 背景色）。
- 每个房间内部（Azure 区域中）有一个小的单色"种子像素"，颜色为 Red、Green 或 Blue 之一。

Rule:
- 数出每个房间边框上入口（缺口）的数量 N（1、2 或 3）。
- 根据 N 用种子像素的颜色填充房间内部：
  - N=1：仅在种子像素所在行（房间内部范围）画一条水平线。
  - N=2：用种子颜色填充房间内部所有的偶数行（从房间内部顶行开始计数，第 0、2、4... 行填充，奇数行保持 Azure），形成水平条纹。
  - N=3：用种子颜色完全填满房间内部。
- Maroon 边框和入口缺口保持不变。

Key insight:
解题者需要先注意到边框上不起眼的缺口并将其识别为"入口"（第一层：缺口不是噪声而是信息载体），然后发现入口数量与填充密度之间的对应关系——1 个入口对应一条线、2 个对应条纹、3 个对应实心填充（第二层：数量编码密度等级）。种子像素仅提供颜色，不参与密度决定。
</description>
</new_puzzle>
