根据框架颜色在色环上的相对位置，决定框架内图案的旋转角度，然后将旋转后的图案填入对应的空白框架中。

Input structure:
- 背景为黑色。网格中分布着若干大小相同的正方形空心框架（边框宽度为1像素），每个框架使用不同的颜色（如 Red、Blue、Green、Yellow 等）。
- 部分框架内部包含由单一颜色绘制的小型图案（非对称形状，占据框架内部区域的部分像素），另一部分框架内部为空（全黑）。
- 含图案的框架和空框架之间存在一一配对关系：每对中含图案框架和空框架的边框颜色不同，但图案颜色相同，框架尺寸完全相同。
- 网格边缘有一个由若干颜色块排成一行或一列的色环图例，颜色按固定顺序排列（例如从左到右依次为 Red、Green、Blue、Yellow、Orange）。

Rule:
- 首先识别色环图例中各颜色的排列顺序，将其视为一个循环序列。
- 将含图案的框架与空框架配对：对于每个空框架，找到与之图案颜色相同的含图案框架作为其源。
- 计算源框架边框颜色在色环中的位置到目标空框架边框颜色在色环中的位置之间的步数差（沿色环顺序方向计数）。
- 步数差为1则将图案顺时针旋转90度，步数差为2则旋转180度，步数差为3则逆时针旋转90度（即顺时针270度），步数差为0则不旋转。
- 将旋转后的图案绘制到空框架的内部，图案颜色与源框架中的图案颜色相同。其余所有元素（框架边框、色环图例、原始含图案的框架）保持不变。

Key insight:
- 解题者需要先发现色环图例定义了颜色之间的顺序关系，再发现配对框架的边框颜色在色环中的距离编码了旋转角度——两步归纳缺一不可。
</new_puzzle>

<new_puzzle>
根据每个封闭区域内标记像素的数量，从共享调色板中选取对应颜色，再按标记像素所指示的方向对该区域执行单色条纹填充。

Input structure:
- 背景为黑色。网格中由 Grey 颜色的线段（水平和垂直，宽度1像素）划分出若干矩形封闭区域。
- 每个封闭区域内部放置了若干相同颜色的标记像素（标记颜色为 Maroon），数量从1到N不等（N不超过调色板长度）。
- 在网格的一条边缘（例如最底行）放置了一个调色板条：由若干不同颜色的像素按从左到右的顺序排列（例如 Red、Blue、Green、Yellow、Orange），每个颜色占1个像素，调色板条的背景与网格背景相同。
- 每个区域内的标记像素要么全部排列在同一行（水平排列），要么全部排列在同一列（垂直排列）。

Rule:
- 数出每个封闭区域内 Maroon 标记像素的数量 k。
- 从调色板条中取第 k 个颜色（从左起第 k 个），作为该区域的填充颜色。
- 观察该区域内标记像素的排列方向：若标记像素水平排列，则对该区域进行水平条纹填充（从区域顶部开始，奇数行填充选定颜色，偶数行保持黑色）；若标记像素垂直排列，则进行垂直条纹填充（从区域左侧开始，奇数列填充选定颜色，偶数列保持黑色）。
- 填充时覆盖原有标记像素。Grey 分隔线和调色板条保持不变。

Key insight:
- 标记像素同时编码了两层信息：数量决定颜色查表索引，排列方向决定条纹朝向，解题者需要分别发现这两个独立的编码通道。
</new_puzzle>

<new_puzzle>
识别每个L形物体的朝向，将其缺失的象限用从相邻色块读取的颜色补全为完整矩形，然后按面积从大到小的顺序将所有完整矩形从左到右排列输出。

Input structure:
- 背景为黑色。网格中散布着若干L形物体，每个L形物体由单一颜色的像素组成，形状为一个矩形去掉其四个角之一所形成的L形（即占据了矩形四个象限中的三个）。
- 每个L形物体的缺失象限（即被去掉的那个角对应的区域）紧邻放置了一个小型单色正方形色块（1x1或2x2），该色块的颜色与L形物体不同，用于指示补全该象限时应使用的填充颜色。
- 不同L形物体的大小（对应矩形的尺寸）可能不同。

Rule:
- 对每个L形物体，确定其对应完整矩形的范围以及缺失象限的位置。
- 读取紧邻缺失象限的色块颜色，用该颜色填充缺失象限，使L形物体变为由两种颜色组成的完整矩形（三个象限为原色，一个象限为色块颜色）。
- 计算每个补全后矩形的面积（宽 x 高）。
- 在输出网格中，将所有补全后的矩形按面积从大到小、从左到右依次排列，相邻矩形之间留1列黑色间隔，顶部对齐。输出网格高度等于最大矩形的高度，宽度恰好容纳所有矩形及间隔。

Key insight:
- 解题者需要先识别L形的缺失方位并利用相邻色块确定填充颜色（第一层归纳），然后发现输出中矩形的排列顺序由面积排序决定（第二层归纳），最后理解输出是重新排列而非原位修改（第三层结构认知）。
</new_puzzle>

<new_puzzle>
将每个图案沿其内部 Magenta 标记像素暴露于背景的方向平移，直到 Magenta 像素与同色锚点重合。

Input structure:
- 背景为黑色。网格中存在若干由不同颜色绘制的小型图案（每个图案由一种非黑色颜色构成的4-连通区域组成，形状不规则且不对称）。
- 每个图案内部恰好有一个像素被替换为 Magenta 色，且该 Magenta 像素位于图案的边缘位置（即图案轮廓上的一个像素），其朝向图案外部的一侧暴露于黑色背景。
- 从 Magenta 像素出发，沿其暴露于背景的方向（上、下、左、右中的一个），在背景中存在一个孤立的同色（与图案主体颜色相同）单像素点，称为锚点。Magenta 像素与锚点之间的连线方向为上、下、左或右之一，且路径上无其他非黑色像素阻挡。

Rule:
- 对每个图案，找到其内部的 Magenta 像素，确定该 Magenta 像素暴露于背景的方向（即该像素的上下左右四个邻居中，朝向黑色背景且不属于图案的那个方向）。
- 沿该方向搜索，找到最近的同色锚点像素。
- 将整个图案（包括把 Magenta 像素恢复为图案原色）平移，使原来的 Magenta 像素位置移动到锚点位置。
- 原位置的图案像素被擦除为黑色。锚点被图案覆盖。
- 若平移后图案部分超出网格边界，则裁剪掉超出部分。

Key insight:
- Magenta 像素不仅标识了图案中的锚定参考点，还通过其在图案边缘暴露的方向暗示了搜索锚点的方向。解题者需要先发现 Magenta 是边缘方向指示器（第一层），再发现沿指示方向上的同色孤立点是平移目标（第二层），最后理解平移对齐的机制是将 Magenta 位置映射到锚点位置（第三层）。
</new_puzzle>

<new_puzzle>
将散落的拼图碎片按照边缘锯齿的互补咬合关系和边线颜色匹配拼接成完整矩形，拼接缝用边线颜色着色。

Input structure:
- 背景为黑色。网格中散布着若干矩形碎片，每个碎片由一种主体颜色填充。
- 每个碎片的一条或多条边缘带有锯齿状凸起或凹陷：凸起表现为碎片边缘向外多出的1像素突出部分（使用碎片主体颜色），凹陷表现为碎片边缘向内缺少的1像素凹口（该处为黑色像素）。无锯齿的边缘是平整的。
- 每个碎片带有锯齿的边缘上额外附着一条宽1像素的彩色边线（颜色与主体色不同），紧贴在锯齿的外侧，跟随凸起和凹陷的轮廓形状。
- 两个可拼接碎片的锯齿图案互补（一个的凸起位置对应另一个的凹陷位置，反之亦然），且它们对应边缘的彩色边线颜色相同。

Rule:
- 找到所有碎片，识别每个碎片各边的锯齿图案（凸起和凹陷的位置序列）和边线颜色。
- 通过同时匹配互补锯齿图案和相同边线颜色，确定哪些碎片的哪些边应拼接在一起。
- 将碎片平移到正确的相对位置，使互补锯齿完美咬合（凸起嵌入凹陷），两个碎片的主体之间无间隙。
- 拼接完成后，移除所有彩色边线像素，并将咬合交界处（原来凸起和凹陷相接的那一列或那一行像素）统一替换为该对边线原来的颜色，形成1像素宽的彩色拼接缝。
- 输出紧凑裁剪后的拼合结果。

Key insight:
- 解题者首先需要发现锯齿的凸凹互补关系决定了碎片的空间拼接方式（第一层），然后发现边线颜色的一致性是确认配对的验证机制（第二层），最后理解拼合后边线被移除并转化为拼接缝着色（第三层）。
</new_puzzle>

<new_puzzle>
根据种子像素在模板中的相对位置，以种子为中心生长出缩小的模板副本，再依据包围关系决定重叠时的绘制优先级。

Input structure:
- 背景为黑色。网格中存在一个较大的"模板轮廓"——由 Grey 像素绘制的空心图形（如空心十字、空心菱形或空心矩形框），占据网格的主要区域。模板图形的线条宽度为1像素。
- 模板轮廓内部和外部散布着若干孤立的彩色种子像素（每个种子一种独特颜色，如 Red、Blue、Green 等），每个种子仅占1个像素。
- 种子数量不超过5个。

Rule:
- 以每个种子像素为中心点，生成一个与 Grey 模板轮廓形状完全相同但每个维度的尺寸缩小为原来的三分之一（向下取整）的副本，使用该种子的颜色绘制副本轮廓。
- 副本的几何中心与种子像素位置对齐。
- 移除原始的 Grey 模板轮廓（将其像素还原为黑色）。
- 若多个副本存在像素重叠，则根据包围关系决定优先级：若一个副本的中心（种子位置）位于另一个副本的封闭内部区域中，则被包围的副本绘制在上层，覆盖包围者的重叠像素。若两个副本之间无包围关系，则在输入网格中种子位置更靠右的副本绘制在上层；若列坐标相同，则更靠下的在上层。
- 种子像素本身被副本轮廓覆盖（若种子恰好落在缩小后轮廓的像素位置上）或保持为种子颜色（若种子位于副本内部空白处）。

Key insight:
- 解题者需要先认出 Grey 轮廓是所有副本共享的形状模板（第一层），再发现副本是以种子为中心、尺寸为模板三分之一的缩小版（第二层），最后从样例中归纳出重叠时"被包围者在上"的绘制优先级规则（第三层）。
</new_puzzle>
