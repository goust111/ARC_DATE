<description>
根据封闭区域内部的孔洞数量，从颜色图例中查找对应颜色，再用该颜色填充区域边框。

Input structure
- 背景为 black。网格中有若干由 grey 像素围成的封闭区域（一像素宽的闭合边框），每个区域内部可能包含零个或多个由 blue 像素构成的小实心方块（孔洞标记）。
- 网格的一角（例如左下角）有一个竖直排列的颜色图例：图例由若干行组成，每行左侧是一个用 grey 像素写成的简单计数符号（一个点、两个点、三个点……分别表示数量 1、2、3……），右侧紧邻一个彩色像素（如 red、green、yellow、orange 等），表示该数量对应的填充颜色。零个孔洞对应图例中没有计数符号、仅有彩色像素的那一行。

Rule
- 对每个 grey 封闭区域，数出其内部 blue 小方块的个数 n。
- 在颜色图例中找到数量 n 对应的颜色 c。
- 将该封闭区域的 grey 边框像素全部替换为颜色 c，同时清除区域内部的所有 blue 小方块（变为 black）。
- 图例本身保持不变。

Key insight
孔洞数量并非直接决定颜色——需要先识别图例中计数符号与颜色的映射关系，再用这层映射把每个区域的孔洞计数翻译成边框颜色。两步归纳缺一不可：一是发现"数孔洞"，二是发现"查图例"。
</description>
</new_puzzle>

<description>
将散布在网格中的彩色线段按颜色分组，每组线段首尾相接拼成一条折线路径，然后将路径围成的区域用该颜色填充。

Input structure
- 背景为 black。网格中散布着若干条短线段（长度 2-4 像素的水平或竖直连续同色像素段）。
- 每种颜色恰好出现偶数条线段。同色线段之间存在唯一的无歧义首尾拼接顺序：每条线段的一个端点与同色另一条线段的一个端点处于同一行或同一列且之间无其他同色像素，形成"接力"关系。
- 网格边缘有一个小的排序提示区域：一列彩色像素从上到下排列，给出各颜色的绘制（图层）优先级，顶部颜色最先绘制（最底层）。

Rule
- 对每种颜色，将其所有线段按接力关系依次连接：在相邻两条线段的对接端点之间画一条直线（水平或竖直），形成一条封闭或开放折线。
- 如果折线封闭，则用该颜色填充折线围成的内部区域（包括折线本身）。
- 如果折线开放（两端未相接），则仅保留折线本身，不做填充。
- 按排序提示从先到后依次绘制各颜色层，后绘制的颜色覆盖先绘制的颜色。
- 清除排序提示区域。

Key insight
需要三层推理：第一层是发现同色线段之间的"接力端点"拼接规则，第二层是判断拼接后折线是否封闭从而决定是否填充，第三层是通过边缘提示区域确定颜色图层的叠加顺序。
</description>
</new_puzzle>

<description>
每个彩色对象像"印章"一样，在网格上沿自身形状暗示的方向周期性复制，复制次数等于对象旁边标记像素的数量。

Input structure
- 背景为 black。网格中有若干个 4-连通的单色对象，每个对象的颜色各不相同。
- 每个对象紧邻（8-连通相邻但不重叠）若干个 grey 标记像素，这些标记像素的数量表示复制次数。
- 每个对象的形状具有唯一的不对称性，暗示一个方向：对象的像素质量分布偏向某一侧（即对象的 bounding box 中，像素集中在某个象限或某条边），该偏向方向的反方向即为复制的行进方向。具体判定方式：将对象的 bounding box 一分为四，像素最多的象限所在的方向为"重心偏向"，复制方向为其对角方向。

Rule
- 对每个对象，确定其复制方向（重心偏向的对角方向）和复制次数 n（相邻 grey 像素数量）。
- 沿复制方向，以对象 bounding box 的尺寸为步长，依次放置 n 个该对象的副本。副本保持原始形状和颜色。
- 清除所有 grey 标记像素。
- 若副本超出网格边界则裁剪。

Key insight
解题者需要先发现 grey 标记数量编码复制次数（通过对比不同样例中标记数与副本数的对应关系），再发现复制方向由对象自身形状的不对称性决定（而非标记像素的位置），两层规律都需要从样例中主动归纳。
</description>
</new_puzzle>

<description>
将网格中的多个矩形"窗户"根据其内部图案的旋转对称阶数进行排序，然后按排序结果重新排列窗户的位置。

Input structure
- 背景为 black。网格中有若干个等大的正方形区域，每个区域由一像素宽的 grey 边框围成（称为"窗户"）。
- 每个窗户内部包含一个由某种非 black、非 grey 颜色绘制的图案。不同窗户的图案颜色各不相同。
- 窗户在网格中排成一行（水平排列），窗户之间有固定间距。
- 网格底部有一条由 maroon 像素构成的水平箭头（由一条水平线段加末端的两个对角像素构成三角箭头形状），箭头指向左或右，指示排序方向。

Rule
- 分析每个窗户内部图案的旋转对称性：判断图案在 90 度、180 度、270 度旋转下是否与自身重合。旋转对称阶数定义为：4 阶（90 度即重合）、2 阶（180 度才重合）、1 阶（无旋转对称）。
- 按旋转对称阶数对窗户排序：若箭头指右则从左到右按阶数从低到高排列，若箭头指左则从高到低排列。
- 阶数相同的窗户保持它们在输入中的相对顺序不变。
- 将排序后的窗户图案（含边框）放回原来的位置槽中。箭头保持不变。

Key insight
表面上窗户只是位置变化，解题者需要发现排列顺序取决于内部图案的旋转对称阶数——这需要在脑中尝试旋转每个图案来判断对称性，然后还需注意底部箭头决定了排序的升降方向。
</description>
</new_puzzle>

<new_puzzle>
<description>
网格中的每个彩色种子像素根据其所在区域的围墙形状生长出与围墙互补的填充图案。

Input structure
- 背景为 black。网格被 grey 像素构成的直线（水平和竖直）分割成若干个大小相同的矩形房间。
- 每个房间的四面墙（上、下、左、右边界上的 grey 像素段）可能存在缺口——即墙上某些位置的 grey 像素被移除，露出 black 背景。
- 部分房间内部恰好有一个非 black、非 grey 的彩色种子像素；其余房间为空（全 black 内部）。

Rule
- 对每个含种子像素的房间，检查其四面墙的缺口位置。
- 在房间内部（不含墙壁），生成一个填充图案：对于房间内部的每个像素位置，如果该位置"投影"到最近的墙壁上时命中缺口（即该像素所在行投影到左墙或右墙时对应位置是缺口，或所在列投影到上墙或下墙时对应位置是缺口），则将该像素填充为种子颜色。
- 更精确地说：对于房间内部坐标 (r, c)，若该行对应的左墙位置是缺口或右墙位置是缺口，则填充整行在房间内的该像素；若该列对应的上墙位置是缺口或下墙位置是缺口，则填充该像素。最终填充的像素是两个方向缺口投影的并集。
- 种子像素本身保留。空房间保持不变。

Key insight
解题者首先要发现房间墙壁的缺口是关键信息而非随机噪声，其次要发现填充规则是缺口位置向房间内部的"正交投影"——缺口所在的行或列会在房间内部产生一整条彩色线。墙壁的缺口模式与内部填充图案之间的互补映射关系是核心洞见。
</description>
</new_puzzle>
