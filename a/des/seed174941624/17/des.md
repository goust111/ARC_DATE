Input structure:
- 背景为最常见颜色（如 black）。网格中有若干由 grey 线段围成的封闭矩形区域，每个区域内部恰好有一个非背景、非 grey 的彩色标记像素（如 red、blue、green 等）。

- 对每个封闭矩形区域，读取其内部标记像素的颜色。
- 在图例区域中找到索引颜色与该标记颜色匹配的小格，提取该小格的二值图案作为平铺单元。
- 用该图案从区域左上角开始逐行逐列周期性平铺，填充整个封闭区域的背景像素（保留 grey 边框和标记像素不变）。

Key insight: 标记像素不是简单的填充色，而是图例的查找键；真正的填充内容是图例中对应的空间图案，需要先建立"颜色→图案"的映射，再执行平铺。

description: 将散布在网格中的彩色箭头按其指向方向发射射线，射线在碰到另一支箭头时触发颜色传递，最终每支箭头被重新着色为它所接收到的射线颜色。

Input structure:
- 背景为 black。网格中散布着若干由三个像素组成的箭头：一个"头"像素和两个"尾"像素，尾像素排列在头像素的某一侧，形成指向四个正交方向之一的箭头形状。具体地，向右箭头为：尾像素在 (r-1,c-1) 和 (r+1,c-1)，头像素在 (r,c)；向左箭头为尾像素在 (r-1,c+1) 和 (r+1,c+1)，头像素在 (r,c)；向上箭头为尾像素在 (r+1,c-1) 和 (r+1,c+1)，头像素在 (r,c)；向下箭头为尾像素在 (r-1,c-1) 和 (r-1,c+1)，头像素在 (r,c)。每支箭头三个像素颜色统一，且不同箭头颜色各异。
- 网格中还有若干单独的 grey 像素作为墙壁障碍。

Rule:
- 每支箭头从其头像素出发，沿箭头指向方向逐格发射射线（用该箭头自身颜色绘制），射线遇到 grey 墙壁则停止（不覆盖墙壁），遇到另一支箭头的任意像素也停止（不覆盖该箭头像素）。
- 射线绘制完毕后，检查每支箭头：如果有其他箭头的射线恰好停在与该箭头相邻的一格（即射线终点紧挨着该箭头的某个像素），则该箭头"接收"了那条射线的颜色。
- 每支箭头的最终颜色取决于它接收到的射线数量：若未接收任何射线，保持原色不变；若恰好接收一条射线，箭头三个像素全部重新着色为射线的颜色；若接收两条及以上射线，箭头着色为 maroon。
- 射线本身（非箭头像素）在输出中保留。

Key insight: 箭头既是射线的发射源又是其他射线的接收者；需要先完成所有射线的绘制，再根据"被多少条射线命中"来决定箭头自身的重着色规则，这构成两层独立的推理。
</new_puzzle>

Input structure:

description: 识别网格中被遮挡的矩形对象的完整形状，通过遮挡层序关系还原每个矩形的原始颜色和完整范围，然后按面积从小到大重新堆叠绘制。

Input structure:
- 背景为 black。网格中有若干互相重叠的实心彩色矩形（每个矩形颜色唯一），重叠处后绘制的矩形覆盖先绘制的矩形。
- 在网格的最左列，从上到下排列着若干单像素彩色标记，每个标记的颜色对应网格中某个矩形的颜色，标记的排列顺序从上到下代表原始绘制顺序（最上面的标记代表最先绘制即最底层）。

Rule:
- 通过左列标记确定原始绘制顺序（从上到下对应从底层到顶层）。
- 根据绘制顺序，逐层还原每个矩形的完整边界框：顶层矩形完全可见；被遮挡的矩形需要通过其可见部分推断完整矩形——每个矩形的行范围为其所有可见像素行坐标的最小值到最大值，列范围同理，保证还原结果是完整的轴对齐矩形。
- 计算每个矩形的面积（行数乘以列数）。
- 清空画布，按面积从小到大重新绘制所有矩形（最小的最先绘制即处于最底层，最大的最后绘制即处于最顶层），每个矩形保持其原始位置不变。
- 左列标记在输出中移除。

Key insight: 原始堆叠顺序（由标记给出）用于还原被遮挡矩形的真实尺寸，但输出的堆叠顺序由面积决定——解题者需要先利用层序信息做"考古式"还原，再按全新的面积规则重排，两步推理缺一不可。
</new_puzzle>

Input structure:
- 背景为 black。网格中有若干 grey 像素构成的墙壁（形成通道和房间结构）。

- 网格中有若干可移动对象：每个对象是一个 1x1 的 yellow 像素，紧邻该像素的某一侧有一个 orange 像素作为方向指示器（orange 在 yellow 的右侧表示对象向右运动，在上侧表示向上运动，以此类推）。

- 每个可移动对象沿其 orange 指示器所指方向直线运动，穿过背景像素。

- 对象通过传送门后，该对传送门的颜色变为 maroon（表示已使用）。
- 多个对象按从上到下、从左到右的顺序依次处理。

Key insight: 解题者首先需要通过颜色配对识别传送门关系，然后模拟对象的分段运动路径——传送门打破了空间连续性，使得对象的最终位置无法通过简单的直线追踪获得，必须理解"入口→出口"的空间映射。
</new_puzzle>

description: 根据种子像素在网格分区中的位置选取对应的生长规则从图例中读取，然后让种子按规则迭代生长，步数由种子自身颜色在样例可推断的色谱中的排位决定。

Input structure:
- 背景为 black。网格被一条 grey 水平线分为上下两个区域。
- 上方区域是图例：被 grey 竖线分成左右两半。左半部分展示一个"左规则"——在一个小方格（如 3x3）中心有一个 green 像素，周围特定位置（如中心的上方和右方）也有 green 像素，表示每步生长时向上和向右各扩展一格。右半部分展示一个"右规则"——类似地在中心周围的不同位置（如中心的下方和左方）有 green 像素，表示每步向下和向左扩展。
- 下方区域是主画布：被一条 grey 竖线分为左右两半。每半中散布着若干彩色种子像素（单个像素），颜色各不相同（可能为 red、blue、yellow、orange 等）。

Rule:
- 位于左半画布的种子使用"左规则"生长，位于右半画布的种子使用"右规则"生长。
- 每个种子的生长步数等于其颜色在色谱顺序中的排位。色谱顺序本身需要从训练样例中归纳得出（例如通过观察不同颜色种子的生长结果大小来推断排位），而非预先告知。
- 每步生长的操作为：将当前所有属于该种子的像素，按规则指定的方向各复制一格（新像素颜色与种子相同）。生长不会超出画布边界，也不会覆盖已有的非背景像素。
- grey 分隔线和图例在输出中保留不变。

Key insight: 解题者需要完成三层推理——第一层：从图例中解读两种空间生长方向模式；第二层：通过对比不同颜色种子的生长结果归纳出颜色→步数的映射（色谱排序）；第三层：将位置决定的规则与颜色决定的步数组合，模拟每个种子的最终形态。
</new_puzzle>

description: 在网格中识别多个形状相似但大小不同的空心框对象，按面积排序后将它们移动到指定位置组装成同心嵌套结构。

Input structure:
- 背景为 black。网格中散布着若干彩色空心矩形框（每个框颜色唯一），每个框是一个一像素厚的矩形环，内部全为背景色。这些框的宽高比相同但尺寸各不相同（如 3x3、5x5、7x7、9x9 的空心方环）。各框互不重叠，周围至少间隔一格背景色。
- 网格中有一个由 grey 像素标记的单一目标位置点（单个像素）。

Rule:
- 按外边界面积从大到小对所有空心框排序。
- 将最大的框移动到以 grey 目标点为中心的位置（grey 点恰好位于该框的几何中心像素处）。
- 将次大的框移动到同一中心点，使其恰好嵌套在前一个框内部且中心对齐。
- 依次将更小的框逐层嵌套放入，每层中心对齐。
- 所有框的原始位置清除为背景色；grey 目标点在最终输出中如果被最内层框像素覆盖则显示框的颜色，否则保留 grey。
- 输出中只在目标位置出现嵌套组装后的同心结构。

Key insight: 各个散布的空心框看似独立，但它们相同的宽高比暗示了嵌套关系；解题者需要发现"按尺寸排序加中心对齐嵌套"的组装规则，而非简单的移动或填充——目标点标记了组装位置，尺寸排序决定了嵌套层序。
</new_puzzle>
