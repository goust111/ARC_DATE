description：根据封闭区域内部"锚点色"在区域边界上的投影位置，用锚点色填充边界对应的那一整条边。

Input structure：
- 背景为最常见颜色（如 black）。
- 网格中有若干由同一种前景色（如 blue）绘制的一像素宽封闭矩形框（各框大小不同，互不重叠）。
- 每个矩形框内部恰好有一个非背景、非框色的单像素"锚点"，颜色各异（如 red、green、yellow 等），位于框内某处。
- 矩形框的四条边各自是一段连续的水平或垂直线段（包含四个角像素）。

Rule：
- 对每个封闭矩形框，找到其内部唯一的锚点像素。
- 将锚点的行坐标与矩形框上下两条水平边比较：锚点更靠近哪条水平边，就用锚点的颜色重绘该整条水平边（覆盖原来的框色）。
- 将锚点的列坐标与矩形框左右两条垂直边比较：锚点更靠近哪条垂直边，就用锚点的颜色重绘该整条垂直边（覆盖原来的框色）。
- 如果锚点到对面两条平行边距离相等（正好居中），则两条边都不重绘。
- 锚点像素本身在输出中被擦除为背景色；未被重绘的边保持原来的框色不变。

Key insight：
锚点并非简单标记"属于哪个框"，而是通过其在框内的相对偏移位置，分别在水平和垂直两个维度上独立选择要染色的边——解题者需要同时在两个轴上做"更近哪一侧"的判断，并理解两个维度是解耦的。
</new_puzzle>

description：将散落的同色像素对用直线段连接，再根据每条线段穿过的"染色带"来决定线段的最终颜色。

Input structure：
- 背景为最常见颜色（如 black）。
- 网格中有若干条一像素宽的完整水平"染色带"，每条横跨整个网格宽度，颜色各不相同（如 red、green、orange 等），彼此不相邻。
- 网格中散布着若干对颜色相同的单像素点（如 blue 点成对出现），每对点之间恰好在同一行或同一列上对齐。同色点恰好出现两个，颜色与染色带颜色均不同。
- 每对同色点之间的连线（水平或垂直的一像素宽直线段）恰好穿过且仅穿过一条染色带。

Rule：
- 对每对同色像素点，沿它们的共享行或共享列画出一像素宽的直线段（包含两个端点）连接它们。
- 找到该线段穿过的那条染色带（线段与染色带交叉的那一行或列）。
- 将整条线段（包括两个端点）的颜色替换为该染色带的颜色。
- 染色带本身在输出中保持不变。

Key insight：
第一层推理是识别同色配对并连线，第二层推理是发现线段的最终颜色并非保持原色、而是由它穿过的那条"染色带"决定——染色带充当了"通道滤镜"，对经过的线段施加颜色转换。
</new_puzzle>

description：在网格中找到由框线围成的若干房间，根据每个房间内的"门"的数量选择对应的填充图案模板来填充该房间。

Input structure：
- 背景为最常见颜色（如 black）。
- 一种前景色（如 grey）构成一像素宽的正交线段网络，将网格划分为若干矩形"房间"（内部全为背景色的矩形区域）。
- 每个房间的边界墙上有零个或多个一像素宽的"门"（即墙上缺少灰色像素的间隙，每个门恰好一个像素宽）。
- 网格的某个角落区域（如左上角）排列着若干小矩形"图案模板"，每个模板是一个被灰色边框包围的小矩形，内部用某种非背景色填充成特定图案（如全填 red、棋盘格 green、竖条纹 blue 等）。这些模板从左到右依次排列，分别编号为 1 号、2 号、3 号……（按从左到右顺序）。

Key insight：
解题者首先需要发现角落的小矩形是"图案模板字典"而非普通房间，然后需要在每个房间的墙壁上仔细数出缺口（门）的数量，最后将门的数量作为索引从字典中查找对应图案——这是一个"识别字典→计数属性→查表映射"的三层推理链。
</new_puzzle>

description：每个前景对象根据自身形状中的"缺角"方向，向该方向发射一条对角射线，射线命中的对象被重绘为发射者的颜色。

Input structure：
- 背景为最常见颜色（如 black）。
- 网格中有若干个互不接触的单色矩形对象（至少 2x2），每个对象颜色各不相同（如 red、blue、green、yellow 等）。
- 每个矩形对象恰好有一个角像素被擦除为背景色（即该矩形缺了一个角），其余像素完整保留。

Rule：
- 对每个带有缺角的矩形对象，确定缺角所在的方位（左上、右上、左下、右下）。
- 从缺角位置出发，沿该对角线方向（例如左上角缺失则向左上方向）发射一条一像素宽的 45 度对角射线，射线逐像素延伸。
- 射线在碰到网格边界前若命中（接触到）另一个对象的任何像素，则停止。
- 被命中的目标对象的所有像素（保持其原始形状，包括它自己可能有的缺角）被重绘为射线发射者的颜色。
- 射线本身不在输出中绘制（输出中不可见）。
- 射线发射者自身保持原样（包括缺角）。
- 如果射线到达网格边界都未命中任何对象，则不产生任何变化。

Key insight：
缺角不是随机缺陷，而是一个方向指示器——解题者需要先识别出每个矩形的"缺了哪个角"，推断出这意味着一个对角线方向，然后沿该方向追踪找到目标，最终理解命中的对象会被"同化"为发射者的颜色。认知路径是"形状缺陷→方向编码→对角线射线追踪→颜色传播"。
</new_puzzle>

description：网格中散布着若干"源图案"和"目标框"，将每个源图案旋转后填入配对的目标框中，旋转角度由目标框角上的彩色标记决定。

Input structure：
- 背景为最常见颜色（如 black）。
- 网格中散布着若干小型多色图案（"源图案"），每个占据一个紧凑的矩形包围盒（约 3x3 至 5x5），由多种非背景色像素组成。
- 网格中还有若干与源图案包围盒大小相同的空心矩形框（"目标框"），用 grey 绘制一像素宽边框，内部全为背景色。
- 每个目标框恰好有一个角的像素被替换为某种非灰色、非背景的颜色标记（如 red、blue、green、yellow）。
- 每个源图案的包围盒中恰好有一个角的像素与某个目标框角标记颜色相同——以此建立源与目标的配对关系。
- 颜色标记所在的角位置编码旋转角度：左上角 = 0 度（不旋转），右上角 = 顺时针 90 度，右下角 = 180 度，左下角 = 顺时针 270 度。这里的角位置指的是标记在目标框上的位置。

Rule：
- 通过匹配"源图案角上的彩色像素"与"目标框角上的彩色标记"，将每个源图案与一个目标框配对。
- 读取目标框上彩色标记所在的角位置，确定旋转角度。
- 将配对的源图案按该角度顺时针旋转，然后填入目标框内部（覆盖背景色，框线保持不变）。
- 源图案的原始位置在输出中被擦除为背景色。
- 目标框角上的彩色标记在输出中恢复为 grey（与框线一致）。

Key insight：
解题者需要完成三步非平凡推理：（1）通过角像素颜色匹配发现源与目标的配对关系；（2）发现彩色标记在目标框上的角位置编码了旋转信息而非仅仅是匹配标记；（3）正确执行旋转后填充——角标记同时承担了"配对键"和"旋转指令"的双重语义。
</new_puzzle>

description：每个前景对象沿其内部"指针条"指向的方向平移，平移距离等于同色"计数区"中标记像素的个数。

Input structure：
- 背景为最常见颜色（如 black）。
- 网格分为左右两个区域，由一条一像素宽的垂直分隔线（如 grey）隔开。
- 左侧区域包含若干互不接触的单色矩形对象（如 red、blue、green），每个对象内部嵌有一条一像素宽、长度为 2 的"指针条"，指针条颜色为 maroon，位于对象的某条边的中央位置。指针条所贴靠的那条边指示了该对象将要移动的方向（例如指针条贴在对象的右边缘内侧，表示向右移动）。
- 右侧区域包含若干小矩形"计数框"，每个计数框的边框颜色与左侧某个对象的颜色相同，框内散布若干 maroon 色的标记像素。

Rule：
- 对左侧每个对象，通过指针条贴靠的边确定移动方向（贴靠上边→向上，贴靠下边→向下，贴靠左边→向左，贴靠右边→向右）。
- 在右侧找到同色边框的计数框，数出其内部 maroon 标记像素的数量 D。
- 将该对象（包含指针条）整体沿确定的方向平移 D 个像素。原来位置变为背景色。
- 如果平移会导致对象超出左侧区域或与分隔线重叠，则对象停在边界处。
- 分隔线和右侧区域在输出中保持不变。

Key insight：
方向和距离分别编码在两个不同的视觉结构中——指针条编码方向（通过其在对象内的位置），计数框编码距离（通过内部标记数量）——解题者需要分别破解这两层编码，再通过颜色匹配将它们关联起来。
</new_puzzle>

description：在网格中找到若干"源图案"和"目标区域"，根据目标区域已有的部分像素与源图案的匹配关系确定正确的翻转方式，然后用翻转后的源图案补全目标区域。

Input structure：
- 背景为最常见颜色（如 black）。

- 网格中还有若干个与源图案大小相同的"目标区域"，每个目标区域中仅保留了源图案经过某种翻转（水平翻转、垂直翻转、或 180 度旋转）后的 2-3 个像素作为"线索像素"，其余位置为背景色。

Key insight：
解题者首先需要识别出源图案和目标区域的对应关系，然后需要发现目标区域中稀疏的线索像素不是随机残留、而是某种翻转操作的部分结果——必须通过逐一尝试不同翻转方式并与线索像素比对来确定正确的变换，这要求解题者理解"部分信息约束完整变换"的逻辑。

description：网格中的每个彩色L形对象根据其开口方向在开口处"生长"出一个矩形填充区，填充区的大小由同行或同列的色标决定。

Input structure：
- 背景为最常见颜色（如 black）。
- 网格中有若干个单色L形对象（每个由两条等长的正交一像素宽线段在端点处垂直相接构成，形成一个直角），颜色各不相同（如 red、blue、green 等）。每个L形有一个"开口方向"——即直角的外侧方向。
- 网格的最右列是一列"色标"：若干不同颜色的像素纵向排列，每种颜色出现一次。色标中某种颜色所在的行号（从色标顶部开始计数，从 1 开始）表示该颜色对应的"生长尺寸"值。

Rule：
- 对每个L形对象，确定其开口方向（上、下、左、右四种之一）。
- 在色标列中找到与该L形同色的色标像素，读取其从色标顶部起的序号 S。
- 在L形开口方向上，以L形的两条臂的末端为边，生长出一个 S 像素深的实心矩形填充区，颜色与L形相同。该矩形的宽度等于L形开口的跨度（即两臂末端之间的距离加一），深度为 S。
- L形本身保持不变，色标列保持不变。

Key insight：
解题者需要先理解L形的几何结构以确定"开口方向"和"开口跨度"，然后需要发现最右列色标的排列顺序编码了一个"颜色→数值"的映射关系，最后将这两层信息组合起来——在开口方向上按映射数值生长矩形。认知链条是"几何方向识别→色标序号解码→定向生长"。
</new_puzzle>
