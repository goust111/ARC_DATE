<new_puzzle>
description：根据每个封闭区域内部散落标记像素的颜色，从区域边框上对应颜色的缺口处向外生长出与区域内部面积等长的射线。

Input structure：
- 背景为 black。
- 网格中有若干个由同一颜色（如 grey）绘制的单像素宽矩形边框，每个边框构成一个封闭区域。
- 每个矩形边框上恰好有一个缺口（缺口为边框上缺失的一个像素），缺口像素被涂成某种非 grey、非 black 的颜色（如 red、blue、green 等），该颜色称为"缺口色"。
- 每个封闭区域内部散布着若干单像素标记点，这些标记点各有颜色，其中恰好有一种颜色与该区域边框上缺口的颜色相同。

Rule：
- 第一步：对于每个封闭矩形区域，找到其内部所有标记像素，识别出与该区域缺口色相同的标记像素并记录其数量 N。
- 第二步：计算该封闭区域的内部面积 A（即边框内部所有格子的总数，包含标记像素和 black 像素）。
- 第三步：从缺口位置向外（即远离区域内部的方向）沿缺口所在边的法线方向，生长一条长度恰好为 A 的射线，射线颜色为缺口色。射线仅覆盖 black 背景像素；若遇到非 black 像素则跳过该像素继续延伸（不改变非 black 像素），直到累计涂满 A 个 black 像素或到达网格边界为止。
- 第四步：将区域内部与缺口色相同的标记像素清除为 black（其余标记像素保留不变）。

Key insight：解题者需要先建立"缺口色"与"内部标记色"的对应关系来确认规则存在，再发现射线长度并非取决于匹配标记的数量，而是取决于封闭区域的内部面积——这是一个需要跨多个样例才能区分的非显然映射。内部同色标记被清除则是第三层需要归纳的细节。
</new_puzzle>

<new_puzzle>
description：将网格中散落的彩色碎片按形状互补关系配对拼合成矩形，然后按拼合后矩形的大小从小到大依次排列到输出网格中。

Input structure：
- 背景为 black。
- 网格中散布着若干个由不同颜色构成的小型 4-连通对象，每个对象是某种不规则形状。
- 这些对象总数为偶数，每两个对象互为"形状互补"：即它们拼合后恰好构成一个无空洞的实心矩形。同一对互补对象使用不同的颜色。
- 每个对象在输入中的位置是随意散落的，不表示任何配对关系。

Rule：
- 第一步（配对）：遍历所有对象，找到形状互补的配对。具体地，对于两个对象 A（颜色 cA）和 B（颜色 cB），将 A 的像素集合放在某个矩形的左上角对齐，若 B 经过平移后恰好填满该矩形中 A 未占据的所有格子，则 A 和 B 互补配对。注意 B 不需旋转或翻转，仅需平移。
- 第二步（拼合）：将每对互补对象拼合成一个实心矩形，矩形内保留两种原色——A 的像素保持 cA，B 的像素保持 cB。
- 第三步（排列输出）：将所有拼合后的矩形按面积从小到大排序（面积相同则按矩形宽度从小到大），在输出网格中从左到右依次排列，矩形之间间隔一列 black，所有矩形顶边对齐于输出网格的第一行。

Key insight：表面上看对象是随机散落的彩色碎片，解题者需要发现"形状互补拼合成矩形"这一隐藏几何关系来完成配对，而非依赖颜色或位置邻近性；然后还需发现输出的排列顺序取决于拼合后矩形的面积大小，这是第二层需要归纳的规律。
</new_puzzle>

<new_puzzle>
description：每个彩色对象充当"印章"，以自身所接触的镜轴线段为对称轴进行镜像翻转，翻转副本的颜色由该镜轴线段的颜色决定。

Input structure：
- 背景为 black。
- 网格中存在若干条单像素宽的直线段（水平或垂直），每条线段有各自的颜色（如 red、blue、green 等），这些线段称为"镜轴"。
- 网格中还存在若干个由 grey 构成的不规则 4-连通对象，每个 grey 对象恰好有一侧边缘与某条镜轴线段相邻（即该对象至少有一个像素与该镜轴线段的某个像素 4-邻接）。
- 每个 grey 对象仅与一条镜轴相邻；每条镜轴可以与零个或多个 grey 对象相邻。

Rule：
- 保留输入中所有镜轴线段和原始 grey 对象不变。
- 对于每个 grey 对象，找到它所相邻的唯一镜轴线段。
- 将该 grey 对象以镜轴线段所在直线为对称轴做镜像翻转，在镜像位置绘制副本。
- 副本的颜色不是 grey，而是该镜轴线段的颜色。
- 若镜像位置与已有非 black 像素重叠，则镜像副本像素覆盖已有像素。

Key insight：解题者首先需要发现 grey 对象与彩色线段之间的邻接关系确定了"谁沿谁翻转"，然后需要发现翻转副本的颜色继承自镜轴而非原对象——两层规律缺一不可：第一层是空间操作（镜像），第二层是颜色重映射（由镜轴决定）。仅观察输出中出现的彩色形状与 grey 形状的几何对称性容易发现镜像关系，但副本颜色来源需要跨样例比对才能确认。
</new_puzzle>

<new_puzzle>
description：在由网格线划分的棋盘格中，空格子的图案由其所有已填充邻居图案的像素级异或叠加决定，填充按扫描线顺序逐步传播。

Input structure：
- 背景为 black。
- 网格被 maroon 单像素宽的十字网格线均匀划分为 N×M 个大小相同的正方形格子（类似棋格结构）。
- 部分格子内部包含由 yellow 绘制的小型二值图案（图案占据格子内部的若干像素位置），其余格子内部完全为 black（即空格子）。
- 已填充的格子中，图案各不相同。
- 所有空格子都恰好可以由其相邻已填充格子的图案唯一确定。

Rule：
- 第一步（识别格子坐标）：根据 maroon 网格线确定每个格子的行列位置及其内部区域。
- 第二步（传播填充）：对于每个空格子，找到与它上下左右 4-邻接的所有已填充格子，将这些邻居的图案进行"异或叠加"——即对于格子内部每个像素位置，若该位置在奇数个邻居图案中被涂色则涂 yellow，若在偶数个邻居图案中被涂色（包括零个）则留 black。
- 第三步：将异或叠加的结果作为该空格子的图案填入。
- 若有多轮空格子需要填充（即某些空格子的邻居本身也是空格子），则按从上到下、从左到右的扫描线顺序逐个填充；每个格子一旦填充即视为已填充，可作为后续空格子的邻居参与计算。

Key insight：解题者需要首先识别出网格线划分的棋盘格结构，然后发现空格子的图案并非简单复制某个邻居，而是所有邻居图案的像素级"异或"（奇偶叠加）——这要求精确对比多个样例中空格子与其邻居的像素关系。传播顺序（扫描线序）是第三层需要归纳的规律，因为先被填充的空格子会作为邻居影响后续空格子的结果。
</new_puzzle>

<new_puzzle>
description：每个前景对象根据自身包含的封闭孔洞数量查找对应的颜色图例，用图例中的两种颜色分别对对象内部和外轮廓进行重新着色。

Input structure：
- 背景为 black。
- 网格的最右侧若干列构成"图例区"，图例区与主区域之间由一列 maroon 分隔线隔开。图例区内从上到下排列着若干个小正方形色块，色块之间间隔一行 black。每个色块由两种颜色构成：外圈一像素宽的边框色和内部填充色。这些色块从上到下依次对应孔洞数量 0、1、2、3……
- 网格主区域中有若干个由 grey 绘制的较大 4-连通前景对象，形状各异。部分对象内部有封闭的 black 孔洞（被对象像素 4-连通完全包围、不与网格边缘的 black 背景连通的 black 区域），孔洞数量从 0 到若干不等。

Rule：
- 第一步（数孔洞）：对于主区域中每个 grey 对象，计算其内部封闭孔洞的数量 H。
- 第二步（查图例）：在图例区中找到从上到下第 H+1 个色块（第一个色块对应 H=0），读取该色块的内部填充色 cFill 和边框色 cBorder。
- 第三步（重着色）：将该 grey 对象的所有像素重新涂为 cFill。
- 第四步（描边）：找到该对象中与 black 背景 4-邻接的所有像素（即外轮廓像素），将这些像素改涂为 cBorder。对象内部不与背景邻接的像素保持 cFill。
- 图例区和 maroon 分隔线在输出中保持不变。

Key insight：解题者面临两层推理挑战。第一层：需要发现对象的孔洞数量是选择图例的索引键——这并非显而易见，因为对象的大小、形状、位置等表面属性都可能是干扰项，需要跨样例验证。第二层：需要发现图例中的两种颜色分别对应对象的"内部填充"和"外轮廓描边"两种不同的着色操作，而非简单地将对象整体涂成一种颜色。两层规律需要同时被发现才能正确预测输出。
</new_puzzle>

<new_puzzle>
description：网格中多个 chevron 箭头各自沿指向方向移动，移动距离等于箭头尾部所在行或列中与箭头同色的边缘标记点数量，箭头经过的路径被涂为 grey 轨迹。

Input structure：
- 背景为 black。
- 网格中有若干个由不同颜色绘制的"箭头"对象。每个箭头由一个 3×3 的 chevron 形状构成，指向上、下、左、右四个方向之一。具体绘制方式（以向右箭头为例）：左列三个像素全涂色，中列仅中间一个像素涂色，右列仅中间一个像素涂色——构成指向右侧的尖角形。向上、向左、向下的箭头分别为该形状顺时针旋转 90°、180°、270° 的版本。
- 网格的最外圈边缘行和边缘列上散布着一些单像素标记点，颜色与某些箭头颜色相同。这些标记点不与任何箭头直接相邻。

Rule：
- 第一步（确定移动距离）：对于每个箭头，找到箭头的"尾部边"（与指向方向相反的那一侧，即向右箭头的尾部边为其最左列）。确定尾部边中心像素所在的行号（若箭头水平指向）或列号（若箭头垂直指向）。计算该行或该列的最外圈边缘上与箭头同色的标记点数量 D。
- 第二步（移动箭头）：将箭头沿其指向方向整体平移 D 个像素。清除箭头原始位置的像素。若箭头移出网格边界，则仅绘制仍在网格内的部分像素。
- 第三步（绘制轨迹）：箭头原始位置与新位置之间、不属于新箭头的空出区域，全部涂为 grey。
- 边缘标记点在输出中保持不变。

Key insight：解题者需要先识别 3×3 chevron 形状为箭头并判断其朝向，然后发现移动距离的编码方式——不是箭头自身的大小或颜色编号，而是与箭头同色的、位于箭头尾部行/列边缘的标记点数量。这需要跨越"空间位置"和"计数"两个维度进行关联推理。轨迹颜色统一为 grey 而非箭头本身颜色是额外需要归纳的细节。
</new_puzzle>

description：网格中的每个彩色矩形根据其内部唯一 orange 把手像素所贴近的边缘方向，沿该边缘向外做镜像翻转展开，翻转副本中把手像素被替换为矩形自身颜色。

Input structure：
- 背景为 black。
- 网格中有若干个不同颜色的实心矩形（颜色各不相同，可为 red、blue、green、azure 等），称为"窗户"。
- 每个窗户内部恰好有一个 orange 单像素标记，称为"把手"。把手位于窗户内部的某一侧最边缘行或最边缘列上（即把手在窗户最上行、最下行、最左列或最右列）。

Rule：
- 第一步（确定把手侧）：对于每个窗户，找到其内部的 orange 把手像素，判断把手位于窗户的哪一侧边缘——若把手在窗户最上行则为上侧，在最下行则为下侧，在最左列则为左侧，在最右列则为右侧。
- 第二步（镜像翻转）：以窗户把手侧的外边缘线为翻转轴，将整个窗户（含把手）做镜像翻转，在窗户外部相邻位置生成一个翻转副本。
- 第三步（绘制结果）：原始窗户保留不变。翻转副本绘制在窗户外侧，副本中原窗户颜色的像素保持该颜色不变，但副本中对应 orange 把手位置的像素改为窗户自身的颜色（即副本中不出现 orange 像素）。
- 若翻转副本部分超出网格边界，则仅绘制在边界内的部分。若副本像素与其他已有非 black 像素位置重叠，副本像素覆盖已有像素。

Key insight：解题者需要发现三层规律：第一层是识别每个矩形内部的 orange 像素为功能性标记而非装饰；第二层是发现 orange 像素的位置决定了翻转方向（最贴近哪一侧边缘）；第三层是发现翻转副本中 orange 像素经历了颜色替换。仅从输出中新出现的形状与原始矩形的几何对称性容易猜到镜像操作，但翻转轴的决定机制和 orange 像素的颜色处理细节需要仔细对比多个样例才能确认。
</new_puzzle>
