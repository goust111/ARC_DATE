<description>
根据围栏内部染色区域的形状，在围栏外部对应边生成该形状的镜像投影，投影颜色由围栏颜色决定。

Input structure
- 背景为黑色。网格中散布若干由同一种非黑色颜色（如 grey）绘制的一像素厚封闭矩形围栏。
- 每个围栏内部有一个由另一种非黑色颜色绘制的连通染色区域（形状各异），该染色区域恰好触碰围栏的某一条边（上、下、左或右），但不触碰其余三条边。
- 不同围栏可使用不同颜色作为其内部染色区域的颜色。

Rule
- 对每个围栏，找到其内部染色区域所触碰的那条围栏边（称为"接触边"）。
- 将染色区域相对于接触边做镜像翻转，得到镜像形状。
- 将镜像形状绘制在围栏外部、紧贴接触边的外侧，颜色改用围栏的颜色（如 grey）。
- 围栏内部的原始染色区域保持不变，围栏本身也保持不变。

Key insight
染色区域触碰围栏的哪一侧决定了投影方向，而投影的颜色并非继承自染色区域本身，而是继承自围栏——解题者必须同时识别"方向由接触边决定"和"颜色由围栏决定"这两个独立规则。
</description>
</new_puzzle>

<description>
将散落在网格中的彩色碎片按颜色分组，每组碎片拼合成一个完整矩形，再按矩形面积从大到小在输出中自上而下堆叠排列。

Input structure
- 背景为黑色。网格中有多种非黑色前景颜色，每种颜色由若干分离的小块（4-连通对象）组成。
- 同一颜色的所有小块恰好能无重叠地拼成一个实心矩形（即它们的像素总数等于某个宽x高的矩形面积，且形状互补）。
- 不同颜色拼成的矩形大小各不相同。

Rule
- 对每种前景颜色，将其所有碎片收集起来，通过平移拼合成唯一的实心矩形。拼合方式可由碎片的相对位置关系推断：同一颜色各碎片的包围盒并集恰好就是目标矩形的尺寸，碎片在包围盒中的相对位置即为它们在矩形中的位置。
- 计算每个拼合矩形的面积（像素总数）。
- 在输出网格中，将这些矩形按面积从大到小、自上而下逐个放置，每个矩形左对齐于第 0 列，矩形之间无间隔紧密排列。
- 输出网格宽度等于最宽矩形的宽度，高度等于所有矩形高度之和。

Key insight
第一层推理在于发现同色碎片需要合并而非独立处理，且合并方式由碎片在原图中的相对空间关系决定；第二层推理在于发现输出的排列顺序取决于拼合后的面积而非原始位置或颜色。
</description>

<description>
利用网格中的"钥匙"形状去匹配对应的"锁孔"形状，匹配成功后用钥匙的颜色填充锁孔内部空腔。

Input structure
- 背景为黑色。网格中有若干由不同颜色绘制的实心对象（称为"钥匙"），以及若干由同一种颜色（如 grey）绘制的一像素厚环形轮廓对象（称为"锁"）。
- 每把锁的轮廓围出一个封闭空腔，空腔的形状恰好与某一把钥匙的形状在经过旋转 0 度、90 度、180 度或 270 度后完全吻合。
- 每把钥匙恰好匹配一把锁，每把锁恰好匹配一把钥匙。

Rule
- 对每把锁，提取其内部空腔的形状掩模。
- 对每把钥匙，提取其形状掩模，尝试四种旋转（0 度、90 度、180 度、270 度）。
- 找到空腔形状与某把钥匙某个旋转后的形状完全相同的唯一配对。
- 用该钥匙的颜色填充对应锁的内部空腔像素。
- 钥匙对象从网格中移除（变为背景色），锁的轮廓保持不变。

Key insight
解题者不能简单地按颜色匹配，而必须通过空间形状比对（含旋转）来发现钥匙与锁孔的对应关系；钥匙消失、锁孔被填色这一视觉变化隐藏了"形状是匹配键、颜色是填充值"的双重角色分离。
</description>

<description>
在由彩色路径段构成的网络中，找到每条路径的断裂处，用该路径距断裂处较近一端的端点标记颜色补全断裂段。

Input structure
- 背景为黑色。网格中有若干条由不同颜色绘制的一像素宽直线段（水平或垂直），它们首尾相接构成若干条折线路径。
- 每条路径的两个自由端点（不与任何同色像素相邻的末端像素）各自紧邻一个不同颜色的单像素标记（标记与路径端点在四方向上相邻）。
- 每条路径恰好有一处断裂：路径上有一段连续的像素被擦除为黑色，造成路径断成两截。

Rule
- 识别每条折线路径及其两个端点标记的颜色。
- 找到路径的断裂处——断裂处两侧的路径末端各有一个悬空端（只有一个同色邻居的像素）。
- 在两个悬空端之间沿直角路径（延续悬空端已有的方向直到对齐另一悬空端，再转弯连接）补全缺失像素。
- 补全像素的颜色不使用路径原色，而使用路径两端标记颜色中、靠近该断裂处较近一侧端点的那个标记颜色。
- 端点标记和原始路径像素均保持不变。

Key insight
第一层推理是识别断裂位置（通过悬空端检测），第二层推理是发现补全颜色并非路径本身的颜色，而取决于路径两端的标记——且是"距断裂处更近的那一端"的标记颜色，这要求解题者同时关注路径的拓扑断裂和端点标记的空间归属。
</description>

<description>
将散落在网格中的彩色种子像素，沿各自所在区域的通道方向生长为条带，条带长度由同区域内种子的数量决定。

Input structure
- 背景为黑色。网格被若干条一像素宽的 grey 分隔线划分为矩形区域（分隔线贯穿整个网格宽度或高度）。
- 每个矩形区域内散布着若干同色的单像素种子点，不同区域的种子颜色各不相同。
- 每个矩形区域要么是宽大于高的横向区域，要么是高大于宽的纵向区域（不会出现正方形区域）。

Rule
- 对每个矩形区域，判定其方向：宽 > 高为横向区域，高 > 宽为纵向区域。
- 统计该区域内种子像素的数量 N。
- 对该区域内的每个种子像素，沿区域方向（横向区域向右，纵向区域向下）生长一条长度为 N 的条带（包含种子本身），颜色与种子相同。若条带超出区域边界则截断至边界。
- 种子原位置已包含在条带内，grey 分隔线保持不变。

Key insight
第一层推理是发现区域的长宽比决定了生长方向（而非种子的排列方式或其他属性）；第二层推理是发现条带长度等于同区域内种子的总数，即"数量既是群体属性也是个体参数"——每个种子的生长长度不由自身决定，而由它所在群体的规模决定。
</description>
</new_puzzle>

<description>
在包含多个图案块的网格中，识别"多数派"图案并将所有"少数派"图案替换为多数派图案，同时用 red 标记少数派图案中与多数派不同的像素位置。

Input structure
- 背景为黑色。网格中有若干个大小相同、彼此分离的矩形图案块，每个图案块由多种非黑色颜色组成。
- 大部分图案块是同一个图案的精确副本（多数派），少数图案块在某些像素位置的颜色与多数派不同（少数派）。
- 图案块之间至少间隔一行或一列黑色背景。

Rule
- 对所有图案块按像素逐位比较，通过多数投票确定每个局部坐标上的"共识颜色"，得到多数派图案。
- 找到所有与共识图案存在差异的图案块（少数派）。
- 将每个少数派图案块替换为共识图案的副本。
- 在替换后的副本中，将原先与共识不同的那些像素位置改为 red（而非共识颜色）。
- 多数派图案块保持不变。

Key insight
与简单的"找不同"不同，解题者必须先通过多块比较建立共识基准（这本身需要归纳），然后在修复少数派时并非简单复制共识，而是在差异位置使用标记色——输出同时承载了"修复"和"标注差异"双重语义。
</description>

<new_puzzle>
<description>
根据每个封闭区域内部"指针"像素所指方向，将该区域的填充色传播到相邻区域，形成颜色级联覆盖。

Input structure
- 背景为黑色。网格由一像素宽的 grey 线条划分为若干封闭矩形区域。
- 每个区域被一种均匀的非黑非灰填充色完全填充。
- 某些区域内包含恰好一个由另一种颜色绘制的单像素"指针"标记，指针位于区域内的某一边缘（上边缘、下边缘、左边缘或右边缘的中点位置），表示指向对应方向。
- 并非所有区域都有指针。

Rule
- 对每个含指针的区域 A，确定指针所指方向（指针贴近哪一边缘就指向那个方向）。
- 沿该方向找到与 A 相邻（共享一段 grey 边界）的区域 B。
- 将 B 的填充色替换为 A 的填充色。
- 如果 B 本身也含有指针，则 B 的传播继续执行（使用 B 现在被替换后的新颜色），形成级联。
- 级联按指针方向逐步传播，直到到达无指针的区域或网格边界为止。
- 指针标记在输出中被移除（变为该区域的填充色），grey 分隔线保持不变。

Key insight
第一层推理是识别指针位置编码了方向信息（贴近哪侧边缘就指向哪侧）；第二层推理是发现颜色传播存在级联效应——一个区域被覆盖后，它自身的指针会用新获得的颜色继续传播，因此处理顺序（从传播链的源头开始）是正确求解的关键。
</description>
</new_puzzle>

<new_puzzle>
<description>
在一个包含"模具"和"原料条"的网格中，用模具的轮廓形状裁切原料条，裁切结果放置在模具内部。

Input structure
- 背景为黑色。网格上半部分包含若干个由 grey 绘制的一像素厚封闭轮廓（称为"模具"），每个模具围出一个不规则形状的空腔。
- 网格下半部分包含若干条水平的彩色条带，每条条带为一像素高、横跨多列的实心色段，颜色各不相同。
- 彩色条带的数量与模具的数量相同。条带按从上到下的顺序与模具按从左到右的顺序一一对应。

Rule
- 将第 k 条条带（从上到下第 k 条）与第 k 个模具（从左到右第 k 个）配对。
- 对每个模具，逐行扫描其内部空腔：对于空腔的每一行，用配对条带的颜色填充该行中属于空腔的像素。
- 填充效果相当于用条带颜色"灌入"模具内部。
- 原来的条带区域清除为黑色背景。模具轮廓保持不变。

Key insight
解题者需要首先建立条带与模具之间的排序配对规则（纵向顺序对横向顺序），这不是基于颜色或形状的匹配，而是基于空间位置的序数对应——这种"跨维度序数映射"是核心隐蔽机制；第二步才是直观的填充操作。
</description>
</new_puzzle>
