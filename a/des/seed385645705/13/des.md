<new_puzzle>
description：根据边框缺口的朝向将内部碎片"倒出"到外部，碎片沿缺口方向平移至网格边缘，同时边框缺口被修补完整。

Input structure：
- 背景为主色（如 black）。
- 网格中有若干个由同一颜色绘制的矩形空心边框（一像素宽），每个边框的某一侧恰好有一个连续缺口（即该侧边框线上有若干连续像素缺失）。
- 每个边框内部散布着若干彩色碎片像素（颜色各异，与边框颜色不同）。
- 边框外部在缺口方向上直到网格边缘的区域为空白背景。

Rule：
- 对每个边框，首先识别缺口所在的边（上、下、左、右）以及缺口的列/行范围。
- 将边框内部所有非背景、非边框色的碎片像素，沿缺口方向平移，平移距离等于从碎片当前位置到该方向网格边缘的距离减去碎片与边框该侧内壁的距离（即碎片保持与边框内壁的相对间距不变，但参考系变为网格边缘）。
- 修补缺口：将缺口处缺失的边框像素补回边框颜色，使边框变为完整的矩形。
- 边框内部原有碎片的位置清为背景色。

Key insight：缺口不是损坏——它指示了碎片的"倒出"方向；碎片保持在边框内的相对布局被整体搬运到网格边缘对齐，同时边框自身被"封口"，仿佛容器被清空后关闭。
</new_puzzle>

<new_puzzle>
description：将散落的彩色像素按颜色分组，每组像素的最小外接矩形用该组颜色绘制为一像素宽的矩形框，框内的原始像素被擦除。

Input structure：
- 背景为主色（如 orange）。
- 网格中散布着多种颜色的孤立像素或小像素簇（每种非背景颜色出现 2 到 6 个像素）。
- 不同颜色的像素在空间上可能交错分布，但同色像素之间不会重叠。

Rule：
- 对每种非背景颜色，找到该颜色所有像素的最小外接矩形（即包围所有该色像素的最小轴对齐矩形）。
- 用该颜色绘制这个矩形的一像素宽边框（四条边完整绘制）。
- 擦除矩形内部所有原始的该颜色像素（替换为背景色）；边框像素如果恰好落在原始像素位置，则保留为边框。
- 不同颜色的边框如果有重叠像素，后处理的颜色（按颜色在网格中首次出现的行优先、列其次的顺序排序，较晚出现的颜色后处理）覆盖先处理的颜色。

Key insight：解题者需要先识别出颜色分组，再推断出"包围框替换散点"的规则，而非简单的逐像素变换；颜色处理顺序由首次出现位置决定，这是第二层需要归纳的规律。
</new_puzzle>

<new_puzzle>
description：网格中的彩色"钥匙"形状需要与对应颜色的"锁孔"形状配对，钥匙被旋转并平移嵌入锁孔的缺失部分，使锁孔补全为完整矩形。

Input structure：
- 背景为主色（如 black）。
- 网格中散布着若干对同色物体，每种非背景颜色恰好有两个 4-连通分量。
- 每对中，较大的分量是一个矩形但缺少了一个角落区域（形成 L 形、T 形或凹形），称为"锁孔"。
- 较小的分量是一个与缺失区域形状相同但可能经过 0°、90°、180° 或 270° 旋转的碎片，称为"钥匙"。
- 钥匙的像素数量恰好等于锁孔缺失的像素数量。

Rule：
- 对每种颜色，识别其两个分量中哪个是锁孔（面积较大者）、哪个是钥匙（面积较小者）。
- 确定锁孔的完整矩形外接框，找出缺失区域的形状。
- 找到钥匙需要旋转的角度（0°/90°/180°/270°），使其形状与缺失区域完全匹配。
- 将旋转后的钥匙平移嵌入缺失区域，补全矩形。
- 擦除钥匙原来位置的像素（替换为背景色）。

Key insight：解题者需要先发现"每种颜色的两个分量是互补关系"，再推断出"旋转匹配缺口"的规则；旋转角度需要通过形状对比来确定，而非简单的平移对齐。
</new_puzzle>

<new_puzzle>
description：网格中有一条由路径色绘制的迷宫路径和若干彩色"阀门"像素，输出中路径被分段染色——每段的颜色由该段两端阀门颜色的"混合"决定（混合规则从色环图例中读取）。

Input structure：
- 背景为主色（如 black）。
- 网格左上角有一个小的色环图例：3 到 5 个不同颜色的像素排成一个环形（如 2x2 或十字形），相邻像素表示可以混合的颜色对，它们之间的混合结果是环中与这两个颜色都相邻的第三个颜色。
- 主区域中有一条由 grey 像素组成的 4-连通路径（一像素宽，无分支）。
- 路径上间隔分布着若干彩色像素（非灰、非背景），这些是"阀门"，它们的颜色都出现在色环图例中。

Rule：
- 路径的两个端点也是阀门（彩色像素）。
- 路径被阀门分割为若干段，每段由灰色像素组成，两端各有一个阀门。
- 对每段路径，查看两端阀门的颜色：在色环图例中，找到与这两个颜色都相邻的第三个颜色，用该颜色重绘这段灰色路径。
- 阀门像素本身保持不变。

Key insight：色环图例定义了颜色混合规则，解题者需要先从图例中归纳出"两色相邻则混合为共同邻居色"的映射关系，再将其应用到路径分段上。路径的分段是第一层结构发现，色环查表是第二层推理。
</new_puzzle>

<new_puzzle>
description：网格中分布着若干形状相同但大小不同的同构图形，输出中每个图形内部被填充的颜色取决于该图形在所有同构图形中的面积排名——排名与网格边缘的调色板条目一一对应。

Input structure：
- 背景为主色（如 azure）。
- 网格的某一条边（如底边）紧贴着一行调色板像素，由 K 个不同颜色从左到右排列，每个颜色占一个像素，颜色之间无间隔。
- 主区域中有恰好 K 个由同一轮廓色（如 maroon）绘制的一像素宽空心图形（如三角形、菱形、或不规则多边形），它们形状完全相同（全等或缩放关系），但大小不同（缩放比例各异）。
- 所有图形的内部为背景色。

Rule：
- 将 K 个图形按面积（内部像素数）从小到大排序。
- 将调色板从左到右的颜色依次分配给排序后的图形：最小的图形获得调色板最左颜色，次小获得第二个颜色，以此类推。
- 用分配到的颜色填充对应图形的内部区域（轮廓保持不变）。
- 调色板像素在输出中被擦除（替换为背景色）。

Key insight：解题者需要三步推理：（1）发现所有轮廓是同一形状的不同缩放版本；（2）识别底边的像素条是调色板而非装饰；（3）归纳出"面积排序对应调色板索引"的映射规则。调色板的移除进一步确认了它是元信息而非输出的一部分。
</new_puzzle>

<new_puzzle>
description：网格中散布着由不同颜色标记的"种子"像素和由墙色构成的障碍线段，每颗种子沿四个正交方向生长出射线直到碰到墙壁或网格边缘，射线交叉处的颜色由交叉射线数量决定。

Input structure：
- 背景为主色（如 black）。
- 网格中有若干由 grey 像素构成的一像素宽水平或垂直线段，作为墙壁。
- 散布着 2 到 4 颗"种子"像素，每颗颜色不同（如 red、blue、green），种子不与墙壁相邻。

Rule：
- 每颗种子向上、下、左、右四个方向各发射一条射线（一像素宽），射线颜色与种子相同。
- 射线在碰到墙壁像素、网格边缘或另一颗种子时停止（不覆盖墙壁或种子）。
- 如果两条不同颜色的射线经过同一个背景像素，该像素的颜色变为 yellow（固定的混合色，不区分具体是哪两种颜色混合）。
- 如果三条或更多不同颜色的射线交叉于同一像素，该像素颜色变为 orange。
- 墙壁和种子像素保持不变。

Key insight：解题者首先要发现种子发射正交射线至障碍物的规则，然后归纳出射线交叉的颜色叠加逻辑（两色交叉变 yellow，三色以上交叉变 orange）。墙壁不仅是视觉分隔，更是限制射线长度的关键机制。
</new_puzzle>

<new_puzzle>
description：网格中的多个矩形区域各自包含一种条纹花纹，输出中每个矩形的花纹被面积更大的相邻矩形的花纹所覆盖，花纹从共享边处保持相位连续。

Input structure：
- 背景为主色（如 black）。
- 网格被若干由 grey 像素构成的一像素宽网格线划分为矩形区域（类似窗格），每个区域内部填充着由两种颜色交替构成的花纹。
- 花纹类型有两种：水平条纹（每行一种颜色交替）和垂直条纹（每列一种颜色交替）。
- 每个矩形的花纹颜色对和类型各不相同。

Rule：
- 将所有矩形区域按面积从大到小排序。
- 按面积从大到小的顺序处理：面积最大的矩形保留自身花纹不变。
- 对每个后续矩形，检查与它共享 grey 网格线边的所有相邻矩形中，是否有已经被处理过（即面积更大）的矩形。
- 如果有，则当前矩形的花纹被替换为与其共享边最长的那个已处理邻居的花纹（花纹的相位从共享边处延续，保持连续性）。
- 如果没有已处理的邻居（不应发生，因为面积最大的优先处理），保留自身花纹。
- Grey 网格线保持不变。

Key insight：解题者需要发现三层规则：（1）矩形按面积排序决定处理顺序；（2）花纹从大面积区域向小面积区域"传播"；（3）传播时花纹的相位从共享边处保持连续，而非简单复制。相位连续性是最隐蔽的一层。
</new_puzzle>
