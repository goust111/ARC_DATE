<description>
根据框架内部种子像素的颜色，从外部候选模板中选取匹配模板，再按种子像素的空间分布决定模板的旋转方向，最终将旋转后的模板缩放填入框架。

Input structure
- 背景为 black。网格中有一个由 grey 像素构成的矩形框架（空心边框），框架内部大部分为 black，但散落着少量彩色种子像素（颜色各异）。
- 框架外部散布着若干小型彩色图案（候选模板），每个模板是一个由单一前景色绘制的连通形状，不同模板使用不同颜色，且每个模板的边界框为正方形。
- 框架内部的种子像素恰好只使用了外部某一个模板的颜色，且种子像素的数量等于该模板中前景像素的数量。

Rule
- 第一步：找到框架内部种子像素的颜色 c，在外部候选模板中找到颜色为 c 的那个模板。
- 第二步：将种子像素视为一个整体，判断它们的质心相对于框架中心落在哪个象限（左上、右上、左下、右下）。左上对应 0 度（不旋转），右上对应顺时针 90 度，右下对应 180 度，左下对应顺时针 270 度。
- 第三步：将选中的模板按第二步确定的角度旋转，然后整数倍缩放使其恰好填满框架内部区域，用模板颜色 c 绘制缩放后的图案，覆盖框架内部原有内容。框架本身保持不变。

Key insight
种子像素同时编码了两层信息：颜色决定选哪个模板，空间分布决定旋转方向。解题者需要先通过颜色匹配完成模板选择，再通过象限判断完成旋转推理，两步推理缺一不可。
</description>

<description>
将网格中散落的彩色碎片按形状互补关系配对，配对后用较大碎片的颜色重绘较小碎片，再将每对碎片平移拼合成完整矩形。

Input structure
- 背景为 black。网格中散布着若干彩色前景对象，每个对象是单色的四连通区域。
- 这些对象可以两两配对：同一对中两个对象的形状互补——即把它们的边界框对齐后，一个对象的前景像素恰好填满另一个对象在同尺寸矩形中的空缺（二者合并恰好构成一个实心矩形），但配对的两个对象颜色不同。
- 每对中两个对象的边界框尺寸相同。网格中对象总数为偶数，恰好能完全配对。

Rule
- 对每一对互补对象，比较二者的前景像素数量，将像素较少的那个对象重新着色为像素较多的那个对象的颜色。
- 将每对中的两个对象沿最短轴向方向平移，使它们的边界框完全重合，从而拼合成一个纯色实心矩形。
- 如果平移路径上有其他对象，则沿另一轴向平移；拼合后的矩形放置在较大碎片（像素更多者）的原始位置。

Key insight
解题者首先需要发现"形状互补"这一配对关系（而非颜色匹配或位置邻近），然后需要发现面积大小决定了颜色继承方向和最终位置——两层规律都需要从样例中独立归纳。
</description>

<description>
网格中的彩色条带按照隐含的编织规则交叉：根据条带的宽度奇偶性决定交叉处谁在上方，上方条带覆盖下方条带的像素。

Input structure
- 背景为 black。网格中有若干水平条带和若干垂直条带，每条条带是一个单色的、宽度为 1 至 4 像素的矩形长条，从网格一侧延伸到另一侧。
- 水平条带和垂直条带各自颜色不同，且它们在交叉处会产生重叠区域。在输入中，所有交叉处都被统一填为 grey（灰色），隐藏了原本的覆盖关系。

Rule
- 对每个交叉区域，检查在此处交叉的水平条带宽度 wH 和垂直条带宽度 wV。
- 如果 wH 为奇数，则水平条带在此交叉处位于上方：将交叉区域填为水平条带的颜色。
- 如果 wH 为偶数，则垂直条带在此交叉处位于上方：将交叉区域填为垂直条带的颜色。
- 非交叉区域的条带像素保持原色不变；背景保持 black。

Key insight
解题者必须先识别出 grey 区域是交叉处的遮罩，然后追踪每个交叉处对应的水平和垂直条带，最后发现覆盖关系取决于水平条带宽度的奇偶性——而非条带颜色或位置。条带宽度是肉眼可数的（1-4 像素），但将其与覆盖关系关联需要非平凡的归纳。
</description>

<new_puzzle>
<description>
在一个包含多个封闭区域的网格中，根据每个区域边界上"门"（缺口）的数量，用对应数量的同心收缩层填充该区域的内部。

Input structure
- 背景为 black。网格中有一个由 blue 像素绘制的连通边界结构，将网格划分为若干封闭区域（类似房间）。
- 每个封闭区域的边界上有 1 到 4 个"门"——即边界线上宽度恰好为 1 像素的缺口（black 像素打断了 blue 边界）。
- 每个封闭区域内部初始全为 black。
- 网格外围有一个颜色图例：4 个小色块从左到右排列，分别为 red、green、yellow、orange，对应数字 1、2、3、4。

Rule
- 对每个封闭区域，数出其边界上的门（缺口）数量 n（n 从 1 到 4）。
- 从颜色图例中查找 n 对应的颜色 c。
- 从该区域的边界向内逐层收缩：第 1 层（紧贴边界内侧的像素）填充颜色 c，第 2 层继续向内收缩填充 c，直到填满 n 层为止。若区域太小不足 n 层，则填满所有可用层。
- 收缩层之内若仍有空间，保持 black 不变。边界结构保持 blue 不变。

Key insight
解题者需要完成三层推理：（1）识别边界上的缺口即为"门"；（2）发现门的数量通过图例映射到填充颜色；（3）发现门的数量同时还决定了填充的层数——同一个计数值同时控制颜色和几何深度，这种双重绑定是机制的核心隐蔽性所在。
</description>
</new_puzzle>

<description>
网格中的每个彩色对象充当"印章"，在其自身尖端朝向的方向上按自身形状重复盖印，印记颜色由对象内部嵌入的单个异色像素决定。

Input structure
- 背景为 black。网格中有若干彩色四连通前景对象，每个对象是单色的连通区域，但其内部恰好有一个像素是不同颜色的"标记点"。
- 每个对象的形状具有一个可识别的"尖端"方向：对象边界框中，某一侧的前景像素行（或列）最窄（像素数最少），该侧即为尖端朝向的方向（上、下、左或右）。
- 对象之间不接触，且对象与网格边缘之间有足够空间。

Rule
- 对每个对象，确定其尖端方向 d。
- 从对象当前位置出发，沿方向 d 平移一个边界框长度（沿 d 方向的维度），放置该对象形状的一个副本。继续沿同方向重复放置副本，直到下一个副本会超出网格边界为止。
- 所有副本（印记）使用对象内部标记点的颜色绘制，而非对象本身的颜色。
- 原始对象保持不变（保留其原色和标记点）。

Key insight
解题者需要独立发现两条规律：（1）盖印方向由对象形状的不对称性（尖端朝向）编码，而非由标记点位置或对象在网格中的位置决定；（2）印记颜色由内嵌标记点的颜色决定，而非对象自身颜色。形状同时编码了"印章模板"和"运动方向"，标记点编码了"墨水颜色"，三者角色分离是核心难点。
</description>

<description>
网格中散落的单像素标记点沿轴向对齐于中央锚点，每个标记点在其所在轴的垂直方向上生成等长双侧射线，射线长度等于标记点到锚点的步数。

Input structure
- 背景为 black。网格中央有一个由 grey 像素构成的小型十字形锚点（上下左右各延伸 1 像素的加号形状）。
- 网格中散布着若干单像素的彩色标记点（颜色各不相同），每个标记点位于锚点的上、下、左、右四个轴向方向之一上（即与锚点共享同一行或同一列）。
- 同一轴向方向上可能有多个标记点，但它们颜色不同。

Rule
- 对于每个标记点，计算它到锚点中心的步数 k（沿轴向的像素间距）。
- 找到该标记点所在轴向的垂直方向（如标记点在锚点正上方，则垂直方向为左和右）。
- 从标记点位置出发，沿两个垂直方向各画一条长度为 k 个像素的射线，颜色与标记点相同。
- 锚点保持不变，原始标记点保留。

Key insight
解题者需要发现每个标记点生成的射线方向与它自身相对于锚点的方向垂直——而非平行，这是一个反直觉的映射。同时射线长度等于标记点到锚点的距离，即同一个空间关系同时编码了两个输出属性（方向取垂直、长度取距离），两层规律需要分别归纳。
</description>

<description>
在一个包含多层嵌套框架的网格中，根据每层框架的颜色在外围调色板中的排列顺序，决定该层内部内容的旋转角度，逐层向内累积旋转后输出。

Input structure
- 网格由若干同心矩形框架嵌套组成，从外到内共 2 至 4 层，每层框架是 1 像素宽的单色空心矩形边框，各层颜色不同。
- 最内层框架的内部包含一个由多种颜色组成的小型图案（核心图案）。
- 网格最上方一行是调色板行：从左到右排列着若干单像素色块，颜色顺序与框架层颜色对应。调色板中颜色的位置编号（从左起第 1、2、3、4 个）对应旋转次数（顺时针旋转 90 度的次数）。

Rule
- 读取调色板行，记录每种颜色的位置编号 p（从 1 开始）。
- 从最外层框架开始，向内逐层处理。对于第 i 层框架，查找其颜色在调色板中的位置编号 p_i。
- 将该层框架内部的所有内容（包括更内层的框架和核心图案）整体顺时针旋转 p_i × 90 度。
- 逐层向内重复此操作，旋转效果累积叠加。
- 框架边框本身不参与旋转，仅其包裹的内容旋转。调色板行在输出中移除。

Key insight
解题者首先要发现调色板行的颜色顺序与旋转次数的对应关系，然后要意识到旋转是从外向内逐层累积的——内层内容受到所有外层旋转的叠加影响。如果只看最终输出与输入的差异，核心图案的总旋转角度是所有层旋转的总和，但中间层框架内容的旋转角度各不相同，这为归纳规则增加了结构深度。
</description>
</new_puzzle>

<new_puzzle>
<description>
网格中的连通前景区域各自包含一条隐藏的直线分界，将每个区域沿分界线切分为两个纯色半区后，交换两半的颜色。

Input structure
- 背景为 black。网格中有若干互不接触的彩色前景区域，每个区域恰好使用两种颜色（形成双色连通对象）。
- 每个双色对象内部存在一条沿水平或垂直方向的直线（脊线），使得该直线一侧的所有像素为颜色 A，另一侧的所有像素为颜色 B。脊线本身不是一个可见的分界——两种颜色在脊线处直接相邻。
- 不同对象的双色组合各不相同。

Rule
- 对每个双色对象，找到将其分为纯色 A 区域和纯色 B 区域的那条直线（水平或垂直）。
- 交换两半的颜色：原来颜色 A 的像素改为颜色 B，原来颜色 B 的像素改为颜色 A。
- 所有对象都执行相同的颜色交换操作。背景保持不变。

Key insight
表面上看每个对象只是"颜色互换"，但解题者需要先识别出每个对象内部的直线分界结构——这在某些不规则形状中并不显然，因为对象的外轮廓可能是锯齿形或 L 形的。真正的难点在于确认"沿直线切分后两半各自纯色"这一结构性前提，而非简单的全局颜色替换（因为不同对象使用不同的颜色对，全局替换无法同时满足所有对象）。
</description>
</new_puzzle>
