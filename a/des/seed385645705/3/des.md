- `description`：根据封闭区域内"种子"像素的颜色，从角落图例区查找对应的填充纹理模板，以种子为锚点对该区域进行平铺填充。

- `Input structure`：
  - 背景为 black。
  - 网格中有若干由 grey 像素绘制的不规则封闭围栏（围栏为 4-连通的闭合环形，围栏宽度为 1 像素），围栏之间互不接触。
  - 每个封闭围栏内部恰好有一个非 black、非 grey 的"种子"像素（如 red、blue、green 等），位于区域内部的某个位置。
  - 在网格的左上角有一个用 grey 边框隔离的"图例区"，图例区内排列着若干小的矩形纹理样本，样本之间用 black 行分隔。每个纹理样本是一个 3x3 的图案块，内部用两种颜色绘制：一种是某前景色（与某个种子颜色相同），另一种是 black。每种前景色恰好对应一个独特的 3x3 纹理图案。

- `Rule`：
  - 第一步：识别图例区中的所有纹理样本，建立"颜色 -> 3x3 纹理图案"的映射表。
  - 第二步：对每个封闭围栏区域，读取其内部种子像素的颜色，查表获得对应的 3x3 纹理图案。
  - 第三步：以种子像素所在位置为铺贴锚点（种子像素对应纹理图案的中心格），将该 3x3 纹理图案以平铺方式（tile）填满整个封闭区域内部。铺贴仅填充围栏内部的 black 像素，不覆盖围栏本身，也不覆盖种子像素（种子像素保持原色）。

- `Key insight`：解题者需要先发现角落图例区的存在并理解它是颜色到纹理的查找表，再理解铺贴的锚点由种子位置决定（不同种子位置会导致同一纹理的相位偏移），两步推理缺一不可。
</new_puzzle>

- `description`：将每个彩色对象沿其方向标记指示的方向投影，投影长度由网格边缘对应方向的刻度条全局决定。

- `Input structure`：
  - 背景为 black。
  - 网格最上方一行是"水平刻度条"：从第 0 列开始有一段连续的 maroon 像素，其余为 black。maroon 段的像素数记为 Lh。
  - 网格最左侧一列是"垂直刻度条"：从第 0 行开始有一段连续的 maroon 像素，其余为 black。maroon 段的像素数记为 Lv。
  - 网格内部（不含刻度条所在行列）散布若干互不接触的单色实心矩形对象（颜色各异，如 red、blue、green 等）。
  - 每个矩形对象的正右方或正下方（不会同时两个方向）紧邻一个 grey 像素作为"方向标记"。方向标记在对象右侧表示向右投影，在对象下方表示向下投影。

- `Rule`：
  - 对于方向标记在右侧的对象：投影方向为向右，投影长度等于 Lh。从该对象的右边缘下一列开始（覆盖方向标记），向右延伸 Lh 个像素，在对象所占的每一行都绘制与该对象同色的投影条。
  - 对于方向标记在下方的对象：投影方向为向下，投影长度等于 Lv。从该对象的下边缘下一行开始（覆盖方向标记），向下延伸 Lv 个像素，在对象所占的每一列都绘制与该对象同色的投影条。
  - 投影不超出网格边界，超出部分截断。
  - 刻度条本身保持不变。

- `Key insight`：解题者需要发现三个独立规则并将它们组合：(1) grey 标记决定投影方向，(2) 投影长度不由对象自身属性决定而是由网格边缘的刻度条全局控制，(3) 水平投影读水平刻度、垂直投影读垂直刻度——方向与刻度条之间存在对应关系。
</new_puzzle>

- `description`：根据框架内部孔洞的形状匹配外部碎片，将匹配碎片填入孔洞，同时按匹配结果对框架边框进行分段重染。

- `Input structure`：
  - 背景为 black。
  - 网格中散布若干由 grey 边框围成的矩形框架（边框厚度 1 像素），每个框架内部有一个或多个由背景色构成的连通孔洞区域，孔洞形状各异。
  - 框架外部散布若干由单一非 grey、非 black 颜色填充的小型实心碎片（如 red、blue、green 等），每个碎片是一个 4-连通的实心块。
  - 碎片的数量与所有框架中孔洞的总数相等，且每个碎片的形状（在旋转和翻转下）恰好与某一个孔洞匹配。

- `Rule`：
  - 第一步：将每个碎片的形状（经旋转/翻转归一化后）与所有框架中的孔洞形状进行匹配，找到唯一的一一对应关系。
  - 第二步：将碎片以正确的旋转/翻转姿态填入其匹配的孔洞中，碎片原位恢复为背景色。
  - 第三步：对于每个框架，找到与其内部孔洞匹配的碎片集合。将该框架的 grey 边框按顺时针方向（从左上角开始）均等分为 N 段（N = 该框架拥有的孔洞数量），每段重染为对应匹配碎片的颜色。分段顺序按孔洞在框架内从上到下、从左到右排列时所匹配碎片的颜色依次赋予。

- `Key insight`：解题者需要先完成形状匹配（碎片到孔洞），再利用匹配结果反过来决定框架边框的颜色分段——边框颜色编码的是"哪些碎片属于这个框架"，而非碎片本身的空间位置。形状匹配和边框染色是两层独立的非平凡推理。
</new_puzzle>

<new_puzzle>
- `description`：将网格中散落的同色像素对用线段连接，线段的绘制样式（实线或虚线）取决于连接路径是否穿过障碍物。

- `Input structure`：
  - 背景为 black。
  - 网格中散布若干 grey 的实心矩形障碍物（互不接触，不接触网格边缘）。
  - 网格中有若干组彩色像素对：每种非 black、非 grey 的颜色恰好出现两个像素（如两个 red、两个 blue、两个 green 等），这些像素不在障碍物上。
  - 每对同色像素要么处于同一行，要么处于同一列（不会斜对）。

- `Rule`：
  - 对于每对同色像素，沿它们共享的行或列在两者之间画一条连接线（包括两个端点像素本身），颜色与该对像素相同。
  - 判断这条连接路径上是否存在 grey 障碍物像素：
    - 若路径上无障碍：绘制实线，即连接路径上每个像素都染为该颜色。
    - 若路径上有障碍：绘制虚线，即连接路径上非障碍像素每隔一个染色——从距网格左上角更近的端点开始，第 1 个像素染色、第 2 个跳过、第 3 个染色，以此类推。障碍物像素本身保持 grey 不变。
  - 所有障碍物保持原样不变。

- `Key insight`：解题者需要首先识别出同色像素配对和连接方向（这一步相对直观），然后发现实线与虚线的区别规律——关键洞见是虚线模式仅在连接路径穿越障碍时才出现，障碍的存在与否决定了绘制样式的切换。
</new_puzzle>

- `description`：在镜像轴两侧比较近似对称的对象，用基准侧修补残缺侧的缺失像素，同时将残缺侧原有的错误像素标记为 maroon。

- `Input structure`：
  - 背景为 black。
  - 网格正中央有一条由 yellow 像素绘制的单像素宽直线（垂直线或水平线），将网格分为左右两半或上下两半。该线即为镜像轴。
  - 镜像轴两侧各有若干彩色对象（4-连通实心块），它们关于镜像轴近似对称：大部分像素关于轴有镜像对应，但少量像素存在差异（一侧有而另一侧缺失，或颜色不一致）。
  - 镜像轴一侧的非背景像素总数严格多于另一侧。像素更多的一侧为"基准侧"，另一侧为"残缺侧"。

- `Rule`：
  - 第一步：通过比较两侧非背景像素总数，确定基准侧和残缺侧。
  - 第二步：将基准侧的所有像素镜像投射到残缺侧。对于残缺侧原本为背景但基准侧对应位置有前景的像素，用基准侧的颜色填入（修补缺失）。
  - 第三步：对于残缺侧原本存在前景像素但基准侧对应位置为背景的位置，将该像素重染为 maroon（标记为"错误位置"）。对于残缺侧原有颜色与基准侧不同的位置，同样将残缺侧该像素重染为 maroon。
  - 镜像轴本身（yellow 线）保持不变。基准侧保持不变。

- `Key insight`：解题者需要先发现 yellow 线是对称轴，再通过像素计数判断哪侧是基准侧（这需要主动比较而非直接可见），最后理解修补与错误标记是同时进行的两个操作——仅修补是不够的，差异像素的 maroon 标记是规则的隐藏第二层。
</new_puzzle>

<new_puzzle>
- `description`：每个彩色矩形根据其可见邻居数量，从标记点出发向外生长出对应数量的触角线段。

- `Input structure`：
  - 背景为 black。
  - 网格中有若干互不重叠的单色实心矩形区域（颜色各异，如 red、blue、green、orange 等），矩形之间至少间隔 2 个像素。
  - 每个矩形的某一条边（上、下、左或右）上恰好有一个 azure 像素标记，该标记替换了该边上的一个原色像素。azure 标记所在的边称为该矩形的"生长边"。

- `Rule`：
  - 第一步：对每个矩形，计算它的"可见邻居"数量 N。可见邻居定义为：从该矩形的某条边沿垂直于该边的方向直线看去，能直接看到另一个矩形的边（两者之间无第三个矩形阻挡），且两个矩形在平行于视线方向的坐标轴上有行或列重叠。
  - 第二步：从该矩形的 azure 标记位置出发，沿生长边的外法线方向绘制 N 条平行线段。每条线段长度为 3 个像素，颜色与矩形原色相同。若 N 条线段需要沿生长边分布，则以 azure 标记为中心，向两侧对称排列，相邻线段间隔 1 个像素。若生长边长度不足以容纳所有线段，则从 azure 标记开始向边的两端交替放置。
  - 第三步：azure 标记像素恢复为矩形原色。

- `Key insight`：解题者需要先推断"可见邻接"这一非平凡的空间关系（不是简单的 4-邻接或距离最近，而是"沿轴向视线可达且有行列重叠"），再将邻居计数转化为触角数量的几何输出，两层推理相互独立且都需要从样例中归纳。
</new_puzzle>

<new_puzzle>
- `description`：将棋盘格图案中每个 2x2 块按其四邻域的颜色多数投票结果重新着色，迭代直至图案收敛为大色块区域。

- `Input structure`：
  - 网格为正偶数边长的方阵（如 12x12、16x16）。
  - 整个网格被完全填满，没有背景色的概念。
  - 网格被划分为若干 2x2 的非重叠块，每个块内四个像素颜色相同，构成一个"超级像素"。
  - 使用 3 到 5 种颜色，初始状态下超级像素颜色呈不规则分布，看似杂乱。
  - 网格的四个角落各有一个 2x2 块的颜色是独特的（该颜色仅在该角落出现），作为"锚点色"。

- `Rule`：
  - 将网格视为超级像素的阵列（每个超级像素是一个 2x2 块）。
  - 对每个非锚点的超级像素，查看其上下左右四个相邻超级像素（边界处缺失的邻居不计入）。
  - 将该超级像素重染为其四邻域中出现次数最多的颜色。若有平局，保持原色不变。
  - 锚点色的超级像素永不改变。
  - 以上投票步骤执行恰好两轮（第一轮的输出作为第二轮的输入）。

- `Key insight`：解题者需要发现三层结构：(1) 网格的基本单元不是单个像素而是 2x2 超级像素，(2) 变换规则是局部多数投票而非简单的颜色替换或移动，(3) 投票迭代恰好两轮而非一轮——仅做一轮无法与样例输出匹配，必须观察到两轮迭代才能得到正确结果。
</new_puzzle>
