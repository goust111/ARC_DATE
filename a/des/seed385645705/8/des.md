<description>
根据每个封闭区域内部的孔洞数量，从颜色图例条中选取对应颜色，重新填充该区域的轮廓。

Input structure：
- 网格背景为黑色。
- 网格中有若干个由同一种非背景颜色（如蓝色）绘制的封闭矩形轮廓，每个轮廓宽度为一个像素。每个轮廓内部被挖去了不同数量的孔洞（孔洞为背景色像素，即轮廓内部某些位置被置为黑色），轮廓内部未被挖去的部分保持该轮廓颜色。各轮廓的孔洞数量互不相同。
- 网格底部有一行水平颜色图例条，由若干个不同颜色的像素从左到右排列，每个色块为 1 像素宽、1 像素高，颜色各不相同，依次对应数量 1、2、3、4……

Rule：
- 对每个封闭矩形轮廓，计数其内部的孔洞像素数量 N。
- 在颜色图例条中找到从左数第 N 个色块的颜色。
- 将该矩形轮廓的所有非背景像素（即轮廓线条和内部填充像素）重新着色为图例条中第 N 个色块的颜色，孔洞保持为背景色不变。

Key insight：
- 孔洞数量是查询颜色图例的索引键；解题者需要先数出每个封闭区域的孔洞数量，再将该数量映射到图例条的对应位置获取新颜色——这构成两层非平凡推理：第一层是发现孔洞数量与颜色图例的对应关系，第二层是理解图例条的位置编码方式。
</description>

<description>
将散落的单色矩形碎片按其形状与大模板边缘上的对应缺口匹配，然后沿缺口所在边的法线方向将碎片滑入模板填补缺口。

Input structure：
- 网格背景为黑色。
- 网格中央有一个大型单色（如灰色）实心矩形模板，模板的四条边缘各被挖去了若干个矩形缺口（即边缘部分像素被置为背景色）。每个缺口的形状（宽×高）各不相同。
- 模板外部散落着若干个单色矩形碎片，每个碎片颜色各不相同且与模板颜色不同，每个碎片的形状（宽×高）恰好与模板上某一个缺口的形状完全匹配。碎片数量等于缺口数量，一一对应。

Rule：
- 对每个碎片，找到模板边缘中与其形状（宽×高）完全匹配的唯一缺口。
- 将碎片沿缺口所在边的法线方向（朝向模板内部的方向）平移，直到碎片恰好填入缺口位置。具体地：上边缺口从上方向下滑入，下边缺口从下方向上滑入，左边缺口从左方向右滑入，右边缺口从右方向左滑入。
- 碎片保持其原始颜色，填入缺口后成为模板的一部分。模板其余部分保持不变。

Key insight：
- 碎片与缺口的匹配依据是形状尺寸而非颜色或位置邻近性；滑入方向由缺口所在边决定。解题者需要先通过形状匹配确定配对关系，再根据缺口在模板哪条边上推断平移方向——两步推理都需要从样例中归纳。
</description>

识别每个 L 形对象的开口朝向，根据朝向从调色板中选色重新着色该 L 形，再沿短臂方向发射一条与短臂等长的射线。

Input structure：
- 网格背景为黑色。
- 网格中有若干个灰色的 L 形对象，彼此不接触。每个 L 形由一条长臂和一条短臂组成，两臂在一个角像素处垂直连接，长臂的像素数量严格多于短臂。L 形的开口方向有四种：右上、右下、左上、左下——开口方向是指 L 形内侧空白区域所朝的方向。
- 网格最左列有一个垂直排列的调色板，从上到下依次为四个不同颜色的单像素，分别对应四种开口方向：第 1 个颜色对应开口朝右上，第 2 个颜色对应开口朝右下，第 3 个颜色对应开口朝左下，第 4 个颜色对应开口朝左上。调色板像素之间间隔一个背景像素。

Rule：
- 对每个灰色 L 形对象，判断其开口朝向（右上、右下、左下、左上之一）。
- 根据开口朝向从调色板中获取对应颜色，将该 L 形的所有像素重新着色为该颜色。
- 从 L 形短臂的末端像素（远离角像素的那端）出发，沿短臂延伸的方向继续画一条射线，射线长度等于短臂的像素数量（不含角像素），射线颜色与 L 形相同。若射线方向上遇到非背景像素则在该像素之前停止。

Key insight：
- 第一层推理：识别 L 形的开口朝向并与调色板位置建立映射关系——需要从样例中归纳出调色板的排列顺序与开口方向的对应规则。第二层推理：发现射线沿短臂方向延伸且长度等于短臂长度——这要求解题者区分长臂与短臂并发现长度关联。
</description>

Input structure：
- 网格背景为黑色。
- 网格被若干条完整的灰色水平线和垂直线划分为 N 个等大的矩形面板（例如 2 行 × 3 列 = 6 个面板），灰色线宽度为 1 像素。
- 每个面板内有若干个非背景、非灰色的前景像素，构成一个小型图案。各面板内前景像素的总数互不相同。

Rule：
- 计算每个面板内前景像素的总数。
- 按像素数量从少到多对面板排序。
- 将排序后的面板按阅读顺序（从左到右、从上到下）依次放入原始的面板网格位置中，灰色分隔线保持不变。
- 排序后排名为奇数（第 1、3、5……）的面板，其图案保持原样。
- 排序后排名为偶数（第 2、4、6……）的面板，其图案在面板内做水平翻转（左右镜像）。

Key insight：
- 第一层推理：发现面板需要按前景像素数量排序并重新排列位置。第二层推理：发现排名的奇偶性决定了图案是否被水平镜像翻转。两层规则需要分别从不同样例的对比中独立归纳。

<description>
在网格中识别由同色像素对构成的"传送门"，将一条直线路径通过传送门跳转到配对门位置继续延伸，生成完整路径。

Input structure：
- 网格背景为黑色。
- 网格中有若干对颜色标记像素，每种非背景、非绿色的颜色恰好出现两个像素，它们构成一对"传送门"。不同门对使用不同颜色（如红色一对、蓝色一对、橙色一对）。每个传送门像素独立放置，不与其他非背景像素相邻。
- 网格中有一条由绿色像素组成的直线路径段，从网格的某条边缘出发，沿水平或垂直方向延伸，路径段的末端像素与某个传送门像素正交相邻。

Rule：
- 路径从网格边缘出发沿直线行进，到达与传送门像素相邻时"穿过"该门。
- 穿过规则：找到与该门同色的另一个门像素，路径从另一个门像素的同侧继续沿相同方向延伸。具体地，若路径从左向右行进到达红色门 A 的左侧，则从红色门 B 的右侧继续向右延伸。
- 延伸的路径继续用绿色绘制。若延伸过程中路径的末端再次与另一个传送门像素正交相邻，则重复上述跳转过程。
- 路径延伸直到到达网格边缘时停止。
- 在输出中，所有路径段均为绿色，传送门像素保持其原始颜色不变。

Key insight：
- 第一层推理：识别出同色像素对构成传送门的概念——路径并非简单地碰到障碍物停止，而是发生了空间跳转。第二层推理：理解跳转后路径的方向保持不变，且从配对门的对应侧继续延伸。第三层推理（在有多对门的样例中）：路径可以经过多次跳转形成折叠的长路径。
</description>

<description>
将网格中多色对象拆分为单色层，按面积从大到小排序后重新排列为由内到外的同心轮廓环。

Input structure：
- 网格背景为黑色。
- 网格中央有一个紧凑的多色对象，由 2 至 4 种不同的前景颜色组成。对象整体 4-连通。
- 对象中每种颜色的像素各自构成一个 4-连通区域，各色层的像素面积互不相同。

Rule：
- 确定多色对象的几何中心位置（取对象边界框的中心像素）。
- 将对象拆分为若干单色层，按每层的像素面积从大到小排序。
- 清除原始对象，从中心开始重建：面积最大的颜色填充为中心的一个实心小矩形，该矩形的边长等于该层像素面积的平方根向下取整（面积较小时可以为 1×面积 的横条）。若面积为完全平方数则绘制正方形，否则绘制面积相同的最接近正方形的矩形（宽 ≥ 高，宽 × 高 = 面积）。
- 面积第二大的颜色绘制为紧贴第一层外部的一圈宽度为 1 像素的轮廓环，仅填充与内层正交相邻且当前为背景的像素。
- 面积第三大的颜色绘制为紧贴第二层外部的一圈轮廓环，以此类推。
- 输出为以中心为核心、各色层由内到外排列的同心嵌套结构。

Key insight：
- 第一层推理：发现原始对象的空间布局被完全抛弃，颜色被重新组织为同心结构。第二层推理：发现颜色在同心结构中从内到外的排列顺序由其原始面积从大到小决定——面积最大的颜色占据核心，面积最小的颜色位于最外圈。
</description>

<description>
在网格中找到被不同颜色遮挡物覆盖的棋盘格区域，移除遮挡物并恢复底层的全局棋盘格图案，同时将遮挡物的颜色信息记录到网格边缘的对应位置。

Input structure：
- 网格展示一个由两种颜色（如蓝色和绿色）交替排列的完整棋盘格图案，覆盖整个网格（每个 1×1 格子一种颜色，相邻格子颜色不同）。
- 棋盘上叠加了若干个纯色矩形遮挡物，每个遮挡物使用一种与棋盘两色均不同的颜色（如红色、橙色、黄色等），完全覆盖其下方的棋盘格像素。遮挡物之间不重叠。
- 网格的最后一行（底边）全部为背景色黑色，用于记录信息。

Rule：
- 移除所有遮挡物，恢复其下方的棋盘格图案。棋盘格的相位全局统一：位置 (r, c) 处的颜色取决于 r+c 的奇偶性，与网格中已暴露的棋盘像素一致。
- 对每个被移除的遮挡物，在最后一行（黑色记录行）中，于该遮挡物水平范围的最左列位置放置一个该遮挡物颜色的像素，作为颜色记录标记。

Key insight：
- 第一层推理：识别底层图案为全局统一相位的棋盘格，遮挡物是叠加在棋盘之上的独立对象——需要理解棋盘格的奇偶规律以正确恢复被遮挡区域。第二层推理：发现遮挡物的颜色信息被"下沉"记录到底部记录行中，记录位置与遮挡物的水平位置相关联。
</description>
