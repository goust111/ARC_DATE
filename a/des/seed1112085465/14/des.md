- `description`：将网格中每个对象按其 bbox 的宽高比分类，然后用分类对应的颜色重新绘制该对象的 bbox 矩形轮廓（一像素厚），擦除原始对象。
- `Input structure`：背景为 black。网格中有若干由同一颜色（grey）构成的 4-连通前景对象，形状各异。每个对象的 bbox 宽高比可分为三类：宽 > 高（横向）、宽 < 高（纵向）、宽 = 高（正方形）。
- `Rule`：
  - 对于每个 grey 对象，计算其 bbox 的宽度 w 和高度 h。
  - 如果 w > h（横向），绘制 blue 的一像素厚 bbox 矩形轮廓。
  - 如果 w < h（纵向），绘制 red 的一像素厚 bbox 矩形轮廓。
  - 如果 w = h（正方形），绘制 green 的一像素厚 bbox 矩形轮廓。
  - 擦除原始 grey 对象（bbox 轮廓覆盖在其位置上）。矩形轮廓内部为背景色。
- `Key insight`：对象的具体形状被抽象为其 bbox 的宽高关系——颜色编码的是比例类别，而非形状细节。

- `description`：在包含"源面板"和"映射表"的网格中，将源面板中每种颜色通过映射表查找替换颜色，映射表的读取方向由源面板中的方向标记决定。
- `Input structure`：背景为 black。一条全高的 grey 垂直分隔条将网格分为左右两部分。左半部分（"源面板"）包含一个彩色图案和一个由 maroon 像素构成的 2 像素直线方向标记（水平或垂直）。右半部分（"映射表"）是一个 Nx2 的颜色对阵列，每行包含一个"输入色"和一个"输出色"。
- `Rule`：
  - 如果方向标记是水平的，则映射表按正常顺序读取（每行左→输入色，右→输出色）。
  - 如果方向标记是垂直的，则映射表反向读取（每行左→输出色，右→输入色）。
  - 将源面板中的图案按映射表进行颜色替换。
  - 输出仅包含替换后的源面板图案（不含方向标记、分隔线和映射表）。
- `Key insight`：方向标记控制映射表的读取方向——同一张映射表在不同方向标记下产生完全不同的颜色替换结果。解题者需要先发现方向标记的作用，再正确应用映射。
</new_puzzle>

- `description`：将网格中的"双层嵌套框架"按内外层颜色关系进行变换：内层框架向外扩展一层，外层框架向内收缩一层，两者在中间位置交换。
- `Input structure`：背景为 azure。网格中有若干"双层嵌套框架"结构，每个结构由一个较大的一像素厚外层矩形框架和一个较小的一像素厚内层矩形框架组成，两层框架共享同一中心，内外层之间有恰好一个像素的间距，间距区域为背景色。外层和内层使用不同颜色。
- `Rule`：
  - 对于每个双层嵌套框架：
    - 记录外层颜色 c_out 和内层颜色 c_in。
    - 擦除整个结构。
    - 在内层原来的位置绘制颜色为 c_out 的框架（即内层大小不变但颜色变为 c_out）。
    - 在外层原来的位置绘制颜色为 c_in 的框架（即外层大小不变但颜色变为 c_in）。
  - 效果：两层框架的颜色互换，但位置和大小不变。
- `Key insight`：变换不是移动框架，而是交换颜色——内层和外层各自保持位置不动，仅颜色互换。这种"位置不变、属性互换"的模式需要仔细观察才能发现。
</new_puzzle>

- `description`：根据网格中"影子"对象与"实体"对象的偏移关系，推断光源方向，然后为所有没有影子的实体对象添加正确方向的影子。
- `Input structure`：背景为 azure。网格中有若干由不同颜色构成的 4-连通单色实心矩形"实体"对象。某些实体对象旁边有一个形状相同但颜色为 grey 的"影子"对象，影子相对于实体有一致的偏移量（如所有影子都在实体的右下方偏移 2 行 1 列）。某些实体对象没有影子。
- `Rule`：
  - 从已有的实体-影子对中推断全局的影子偏移向量 (dr, dc)（影子位置 = 实体位置 + 偏移）。
  - 对于每个没有影子的实体对象，在偏移位置绘制 grey 的影子（与实体同形同大小）。
  - 影子绘制在实体的"下方层"（即影子不覆盖实体像素；如果影子位置与其他实体重叠，影子被遮挡的部分不绘制）。
  - 已有的影子和实体保持不变。
- `Key insight`：已有的影子-实体对是推断"光源方向"的线索——偏移量是全局一致的，解题者需要先从已知对中提取偏移量，再应用到缺失影子的对象上。
</new_puzzle>

- `description`：在网格中找到每对"锁"和"钥匙"对象，将钥匙的形状从锁的边框中"挖去"，然后将挖去后的锁输出。
- `Input structure`：背景为 black。网格中有若干由不同颜色构成的实心矩形"锁"对象，每个锁的某一边紧贴着一个形状不规则的同色"凸起"（作为钥匙孔形状的一部分）。网格中还有若干小型彩色"钥匙"精灵，每个钥匙的形状与某个锁的凸起形状完全相同（经过旋转后），且钥匙颜色与对应锁的颜色相同。
- `Rule`：
  - 按颜色将钥匙与锁配对。
  - 在锁的凸起位置（钥匙孔），将凸起像素擦除为背景色（形成与钥匙形状完全吻合的缺口）。
  - 擦除原位置的钥匙精灵。
  - 锁的矩形主体保持不变。
- `Key insight`：钥匙不是"插入"锁中，而是定义了从锁上"切除"的形状——钥匙形状与凸起形状的匹配关系决定了切除区域。
</new_puzzle>
