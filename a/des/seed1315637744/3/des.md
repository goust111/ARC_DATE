- `description`：根据封闭区域内部标记像素的颜色，从颜色图例中查找对应的平移方向，将区域内的图案沿该方向穿过边框缺口"挤出"到外侧。

- `Input structure`：
  - 背景为 black。
  - 网格中散布若干个由单一颜色绘制的一像素宽矩形边框（每个边框颜色各不相同）。
  - 每个矩形边框的四条边中恰好有一条边存在一个连续缺口（缺口宽度 >= 2 像素），缺口处为背景色。
  - 每个矩形边框内部包含一个小型非背景色图案（由若干像素组成的任意连通形状），图案颜色与边框颜色不同。
  - 在网格的某个角落存在一个颜色图例区：若干对 (颜色块, 方向箭头)，箭头由同色像素绘制，形状为三像素的直线段加一个像素的箭头尖端，分别指向上/下/左/右四个方向之一。每个标记色恰好在图例中出现一次。

- `Rule`：
  - 第一步：对每个矩形边框，观察其内部图案的颜色，在颜色图例中找到该颜色对应的方向。
  - 第二步：确认该矩形边框上缺口所在的边与图例指示的方向一致（这是输入的保证）。
  - 第三步：将内部图案沿缺口方向平移，使图案整体穿过缺口，最终图案的最近边紧贴边框外侧一像素处。图案在边框内部的原始位置清除为背景色。
  - 边框本身（包括缺口）保持不变。

- `Key insight`：内部图案的颜色并非装饰——它是查找图例的索引键，图例将颜色映射为平移方向；缺口是图案的"出口"，方向由颜色-图例映射决定，而非由缺口位置直接决定（尽管两者一致，解题者需要先发现图例映射关系才能确信规则）。
</new_puzzle>

- `description`：将散落的同色闭合边框和小块按嵌套深度重新着色，颜色顺序由网格底部调色板行从左到右的排列决定。

- `Input structure`：
  - 背景为 black。
  - 网格最底部一行是调色板行：从左到右排列若干不同颜色的像素块（每块宽 2 像素、高 1 像素），颜色互不相同，块与块之间有 1 像素背景间隔。
  - 网格其余区域包含若干个由同一种前景色（如 grey）绘制的闭合一像素宽矩形边框。
  - 这些矩形边框存在嵌套关系：某些边框完全位于另一个边框内部，形成多层嵌套（最多 4 层）。同一嵌套层级内的边框互不重叠。
  - 除了矩形边框，还有若干小型填充矩形块（面积 <= 6 像素），同样为 grey，散布在各层嵌套区域内。

- `Rule`：
  - 确定每个对象（边框或小块）的嵌套深度：不被任何边框包围的对象深度为 0，被一层边框包围的深度为 1，以此类推。
  - 调色板行从左到右的第 k 个颜色对应深度 k（从 0 开始）。
  - 将每个对象重新着色为其嵌套深度对应的调色板颜色。
  - 调色板行本身在输出中保持不变。

- `Key insight`：所有前景对象初始为同一颜色，解题者必须先识别出包含关系构成的嵌套层级，再将嵌套深度与调色板位置对应——两步推理缺一不可，单看对象外观无法确定输出颜色。
</new_puzzle>

<new_puzzle>
- `description`：在由彩色折线路径组成的网络中，每条路径的终点处生长出一个与路径转弯次数等边长的实心方块。

- `Input structure`：
  - 背景为 black。
  - 网格中有若干条由不同颜色绘制的一像素宽路径，每条路径由水平和垂直线段首尾相接组成（即折线路径）。
  - 每条路径有一个"起点端"和一个"终点端"。起点端用一个 2x2 的同色实心方块标记（方块的一个角像素与路径第一个像素 4-连通）。终点端为路径的另一端，是一个普通的单像素末端。
  - 不同路径之间不接触、不交叉。

- `Rule`：
  - 对每条路径，计算其转弯次数 T（路径从水平变为垂直或从垂直变为水平的次数）。
  - 在路径的终点端，以终点像素为锚点，生成一个边长为 T 的实心正方形，颜色与路径相同。锚点位于正方形的哪个角取决于路径最后一段的行进方向：向右则锚点为左上角，向左则为右下角，向下则为右上角，向上则为左下角。
  - 路径本身（包括起点方块标记）保持不变。

- `Key insight`：起点的 2x2 方块不是需要变换的对象，而是用来区分起点和终点的标记；核心推理在于发现"转弯次数"这一沿路径才能观察到的属性决定了终点方块的大小，而方块的朝向由路径末段方向决定。
</new_puzzle>

<new_puzzle>
- `description`：网格被分隔线划分为若干子区域，每个子区域内有一个不对称的"种子图案"和若干靶点像素；将种子图案旋转复制到每个靶点位置，旋转角度由靶点相对于种子图案中心的方位决定。

- `Input structure`：
  - 背景为 black。
  - Azure 色的完整行和完整列将网格分割为矩形子区域（类似九宫格，但行列数不固定）。
  - 每个子区域内恰好包含：
    - 一个由某种颜色绘制的小型连通图案（3 至 5 像素），称为"种子图案"，图案具有不对称形状（旋转 90/180/270 度后形状不同）。
    - 一到三个单独的 red 像素，称为"靶点"。靶点不与种子图案相邻。
  - 种子图案在不同子区域中颜色不同，但同一子区域内种子图案只有一种颜色。

- `Rule`：
  - 对每个子区域，找到种子图案的 bounding box 中心。
  - 对每个靶点像素，判断它位于种子图案中心的哪个大致方位：取靶点与种子中心的行差和列差，以绝对值较大的分量确定主方向——上方、下方、左方或右方。
  - 方位映射旋转角度：上方 = 0 度（保持原样），右方 = 顺时针 90 度，下方 = 180 度，左方 = 顺时针 270 度。
  - 将种子图案按对应角度旋转后，以靶点像素为新图案 bounding box 中心的位置进行绘制，颜色使用种子图案的原色。
  - 靶点的 red 像素被图案覆盖（不保留）。
  - 原始种子图案保持不变。

- `Key insight`：靶点的位置不仅决定"在哪里复制"，还通过其相对于种子中心的方位隐式编码了"旋转多少度"——解题者需要同时发现复制和旋转两个规则，并理解方位-角度的映射关系。
</new_puzzle>

<new_puzzle>
- `description`：两个相同形状但不同颜色的矩形边框重叠放置，重叠像素显示为第三种混合色；将两个边框沿各自箭头方向分离，分离距离等于重叠像素的数量。

- `Input structure`：
  - 背景为 black。
  - 网格中央区域可见一个复合图形，由三种颜色组成：颜色 A、颜色 B、颜色 C。
  - 该复合图形实际上是两个形状完全相同的一像素宽矩形边框的重叠结果：边框 1 为颜色 A，边框 2 为颜色 B，两者重叠的像素显示为颜色 C。
  - 在网格的上方有一行"方向提示"：一个颜色 A 的 1x1 像素后面紧跟一个由颜色 A 的 3 像素水平或垂直线段构成的箭头（末端有一个像素偏移表示方向——向左、向右、向上或向下）；同行另一侧有颜色 B 的类似箭头，方向与颜色 A 的箭头恰好相反。

- `Rule`：
  - 第一步：识别重叠结构——颜色 C 的像素是两个边框共享的位置，由此推断两个边框各自的完整形状（A 的完整边框 = A 像素 + C 像素的位置；B 的完整边框 = B 像素 + C 像素的位置）。
  - 第二步：计算颜色 C 的像素总数 N。
  - 第三步：将边框 1 的所有像素（全部着色为 A）沿方向提示中颜色 A 箭头指示的方向平移 N 个像素；将边框 2 的所有像素（全部着色为 B）沿颜色 B 箭头指示的方向平移 N 个像素。
  - 第四步：在输出网格中绘制两个分离后的完整边框，背景保持 black。方向提示行保持不变。

- `Key insight`：颜色 C 具有双重含义——它既标识了重叠位置（用于还原各边框的完整形状），又通过其像素计数决定了分离距离。解题者需要三层推理：识别重叠合成机制、理解方向提示、发现计数决定位移量。
</new_puzzle>

<new_puzzle>
- `description`：网格中散布着若干近似对称的图形，每个图形有一处异色像素破坏对称性；修复对称后，提取所有破缺像素的颜色按图形从左到右排列，输出为单行网格。

- `Input structure`：
  - 背景为 black。
  - 网格中有若干个互不接触的前景图形，每个图形由单一颜色绘制。
  - 每个图形"几乎"具有某种对称性（左右对称、上下对称或 180 度旋转对称），但恰好有一个像素被替换为另一种颜色，破坏了对称性。
  - 被替换的那个像素的颜色与该图形的主体颜色不同，且在整个网格中每个图形的"破缺像素"颜色各不相同。

- `Rule`：
  - 对每个图形，通过观察大部分像素满足的对称关系来检测其对称类型。
  - 找到破坏对称性的那个异色像素。
  - 找到该破缺像素在对称变换下的对应位置：如果对应位置是背景色，则在该位置补上图形主体颜色的像素；如果对应位置已有主体颜色像素，则将破缺像素本身改回主体颜色。
  - 修复完成后，收集每个图形中破缺像素在修复前的颜色，按图形 bounding box 左边界从左到右排序。
  - 输出为单行网格（高度 1），依次排列这些破缺颜色像素，像素间无间隔。

- `Key insight`：每个图形的对称类型不同且未被显式标注，解题者需要先为每个图形独立判断它"想要"哪种对称，然后找到唯一的异色破缺点；最终输出并非修复后的网格，而是提取破缺颜色的序列——这一"信息提取而非图形修复"的输出模式增加了额外的推理层。
</new_puzzle>

<new_puzzle>
- `description`：一条 grey 折线路径穿过网格中若干彩色矩形区域，路径在每次穿出矩形后变为该矩形的颜色，直到进入下一个矩形时恢复为 grey。

- `Input structure`：
  - 背景为 black。
  - 网格中有若干个互不重叠的实心矩形区域，每个矩形用不同的颜色填充（如 blue、red、green、yellow 等）。
  - 一条一像素宽的 grey 折线路径从网格的一条边进入，穿过若干矩形区域，最终从另一条边离开。路径由水平和垂直线段组成。
  - 路径穿过矩形时，矩形内部被路径占据的像素显示为 grey（路径覆盖了矩形的颜色）。
  - 路径不会两次穿过同一个矩形。

- `Rule`：
  - 将路径视为从入口端到出口端的有序像素序列。
  - 路径在进入第一个矩形之前保持 grey。
  - 当路径穿过一个矩形区域时，路径在该矩形内部的段保持 grey 不变。
  - 路径离开该矩形后，从离开点到进入下一个矩形之前的所有路径像素，重新着色为刚离开的矩形的颜色。
  - 路径离开最后一个矩形后，剩余路径像素着色为最后一个矩形的颜色。
  - 矩形区域本身保持不变（除了被路径覆盖的像素仍为 grey）。

- `Key insight`：路径的颜色变化不是由它当前所在的区域决定，而是由它"上一个穿过的"矩形决定——存在一个时间滞后效应。解题者需要识别路径的行进方向和穿越顺序，理解"染色发生在离开之后而非进入之时"这一反直觉规则。
</new_puzzle>
