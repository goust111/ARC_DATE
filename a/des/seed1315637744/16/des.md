- `description`：根据框架内部缺口的朝向，从外部候选精灵中选出匹配的精灵，旋转后填入框架内部，并用框架颜色重绘精灵轮廓。
- `Input structure`：背景上散布着若干单色矩形框架（空心矩形），每个框架恰好在一条边上有一个连续缺口（缺口宽度各不相同）。框架外部另有若干独立的小型单色填充精灵，每个精灵的外接矩形的某一条边的长度恰好等于某个框架缺口的宽度。
- `Rule`：
  1. 对每个框架，测量其缺口的宽度（缺口连续背景像素数）和缺口所在的边（上/下/左/右）。
  2. 在候选精灵中找到外接矩形有一条边长度等于该缺口宽度的精灵（每个精灵恰好匹配一个框架）。
  3. 将精灵旋转，使其匹配边朝向缺口方向，然后将精灵平移到框架内部，紧贴缺口对面的内壁居中放置。
  4. 精灵放入后，将精灵中与框架边缘相邻的像素重绘为框架的颜色，其余保持精灵原色。
  5. 输出仅保留框架及其内部内容，裁剪到所有框架的最小包围矩形。
- `Key insight`：缺口宽度不是装饰性的——它是将精灵与框架配对的唯一键值；缺口朝向决定精灵的旋转角度，而精灵进入框架后轮廓色的改变需要解题者注意到框架颜色对精灵边缘的"感染"规则。

- `description`：将网格中散布的彩色线段视为"编织线"，根据交叉处的上下叠压关系推断每根线的深度层级，然后仅保留最顶层的线段。
- `Input structure`：背景色网格上有若干条水平或垂直的单色线段（每种颜色恰好一条线段，宽度为1像素）。线段之间存在交叉点，交叉处只显示一种颜色——即视觉上"压在上面"的那条线的颜色。每条线段至少有一个交叉点。
- `Rule`：
  1. 根据每条线段的可见端点和颜色连续性，重建每条线段的完整范围（包括被遮盖的交叉点）。
  2. 在每个交叉点处，可见颜色的线段"压住"被遮盖颜色的线段，建立偏序关系：被压者 < 压者。
  3. 对所有线段按此偏序进行拓扑排序，找到唯一的全序（题目保证不存在环且全序唯一）。
  4. 输出中仅绘制排序后深度最浅（最顶层）的那一条线段，其余线段及交叉点全部擦除为背景色。
- `Key insight`：表面上看这是一个"取最上层"的问题，但关键在于许多交叉点处看到的颜色并不直接涉及最顶层线——解题者必须通过传递关系（A 压 B，B 压 C，则 A 在 C 之上）来推断全局最顶层，而非仅看局部交叉。
</new_puzzle>

- `Input structure`：背景色网格中有一个大的矩形区域由两种非背景色交替填充形成完美棋盘格图案。该棋盘格区域中有一个矩形子块（边界与棋盘格对齐）被整体平移了恰好一格（上、下、左或右），导致该子块内的颜色与周围棋盘格不再对齐——子块边缘出现连续同色的相邻像素对（正常棋盘格中不会出现）。子块平移后露出的原位置被背景色填充。

  4. 输出裁剪为棋盘格区域的外接矩形。
- `Key insight`：解题者不能直接"看到"子块的边界——必须通过检测棋盘格图案中哪些地方出现了奇偶性违例（同色相邻）来反推子块的范围和位移方向。这是一个"通过图案破缺定位异常"的推理过程。

- `description`：将散落的彩色像素按颜色分组，每组像素的凸包区域用该颜色填充，但填充时各颜色层按像素数量从少到多依次叠加，数量少的层被数量多的层覆盖。
- `Input structure`：背景色网格上散布着多种非背景色的单独像素点（每种颜色至少2个像素、至多6个像素）。同一颜色的像素不相邻。不同颜色的像素数量两两不同。
- `Rule`：
  1. 将所有非背景像素按颜色分组，统计每组的像素数量。
  2. 对每组颜色，找到该组所有像素的最小轴对齐包围矩形（bounding box），将该矩形内所有像素填为该颜色。
  3. 按像素数量从少到多的顺序依次绘制各颜色层：先绘制像素最少的颜色组的包围矩形，再绘制次少的，依此类推。后绘制的层会覆盖先绘制的层。
  4. 最终在输出中，像素数量最多的颜色组的矩形在最上层（完全可见），像素最少的在最底层（可能被部分或完全遮盖）。
- `Key insight`：解题者首先需要发现"包围矩形填充"的规则，然后还需发现叠加顺序不是随机的——它由每种颜色原始散点的数量决定。这两步推理缺一不可：仅看到矩形填充不够，还必须归纳出数量决定图层顺序的隐含规则。
</new_puzzle>

- `description`：网格中每个封闭区域内的彩色种子像素会沿该区域的边界墙壁"生长"，生长方向由种子相对于区域重心的位置决定，生长长度等于区域内种子像素的总数。
- `Input structure`：背景色网格被一种墙壁颜色（如 grey）的线条分割成若干不规则的封闭区域。每个区域内部有若干散布的彩色像素（种子），颜色各不相同，每个区域内种子数量为1到4个不等。
- `Rule`：
  1. 识别由墙壁颜色分隔的所有封闭区域。
  2. 对每个区域，统计其内部种子像素的总数 N。
  3. 对每个种子像素，判断它位于所在区域的哪个象限（以区域的视觉中心为参考，分为左上、右上、左下、右下）。
  4. 根据象限确定生长方向：左上象限的种子向上生长，右上象限的种子向右生长，左下象限的种子向左生长，右下象限的种子向下生长。
  5. 从种子位置沿生长方向连续绘制 N 个同色像素（不包含种子本身），遇到墙壁或网格边界时停止（即使尚未画满 N 个像素）。
- `Key insight`：解题者需要发现三层结构：第一层是识别封闭区域并计数种子数；第二层是发现生长长度等于区域内种子总数（而非该种子自身的属性）；第三层是发现生长方向由种子在区域内的相对位置（象限）决定，而非由颜色或绝对位置决定。
</new_puzzle>

<new_puzzle>
- `description`：在包含多个"信号塔"和"接收器"的网格中，每座信号塔向四个正方向广播其颜色射线，射线被墙壁阻断；接收器收集所有到达它的射线颜色，并变为这些颜色中在参考色环上最近的混合色。
- `Input structure`：背景色网格上有若干黑色墙壁像素形成障碍。网格中散布着两类特殊像素：信号塔（彩色像素，位于墙壁形成的通道中）和接收器（用 grey 标记的像素）。信号塔有不同颜色，每种颜色最多出现两次。
- `Rule`：
  1. 每座信号塔从自身位置向上、下、左、右四个方向各发射一条射线，射线颜色与信号塔相同。
  2. 射线沿直线传播，遇到墙壁、网格边界或另一座信号塔时停止（不穿透）。射线经过的背景像素在输出中保持背景色不变（射线是不可见的传播路径）。
  3. 当射线到达一个 grey 接收器像素时，该接收器"接收"此颜色。一个接收器可能被多条不同颜色的射线到达。
  4. 如果接收器只收到一种颜色，它变为该颜色。如果收到多种颜色，它变为其中像素数量最多的那种信号塔颜色（即网格中该颜色信号塔数量最多的颜色）。若仍平局，则保持 grey 不变。
  5. 未被任何射线到达的接收器保持 grey。
- `Key insight`：解题者首先需要理解射线沿正方向传播并被墙壁阻断的机制，然后需要发现接收器的变色规则不是简单的"任意到达色"，而是涉及对全局信号塔数量的统计来打破平局——这要求解题者同时关注局部的射线传播路径和全局的颜色频率。
</new_puzzle>

<new_puzzle>
- `description`：网格中的每个彩色对象是一枚"印章"，需要根据对象内部的标记像素确定盖章位置和旋转角度，在目标画布上印出对象的轮廓。
- `Input structure`：网格被一条单像素宽的分隔线（如 grey）分为左右两部分。左半部分包含若干彩色4-连通对象（印章），每个对象内部恰好有一个不同颜色的标记像素（锚点）。右半部分是目标画布，画布上有若干与各印章锚点颜色相同的单独标记像素，且每个标记像素旁边紧邻一个箭头形状的小标记（由2个同色像素组成：标记像素本身加上其上/下/左/右方向的一个同色像素，形成长度为2的短线段），箭头指向的方向表示印章需要旋转的方向。
- `Rule`：
  1. 在左半部分找到每个印章对象及其内部锚点颜色。
  2. 在右半部分找到与锚点颜色匹配的目标标记（2像素短线段）。
  3. 短线段的朝向确定旋转：向上=不旋转，向右=顺时针90度，向下=180度，向左=逆时针90度。
  4. 将印章旋转到指定角度后，平移使其锚点像素与目标标记的起始像素（非延伸方向的那个像素）重合。
  5. 输出仅包含右半部分画布，移除所有目标标记，绘制上旋转平移后的印章轮廓（仅绘制印章对象的边界像素，内部填为背景色）。
- `Key insight`：解题者需要发现三个非显然的规则：锚点颜色是配对键；2像素线段的方向编码旋转角度；输出的不是完整印章而是其轮廓——这三层规则需要从样例中逐步归纳。
</new_puzzle>

<new_puzzle>
- `description`：在网格中识别由同色像素构成的"路径"和路径端点处的彩色标签，将每条路径收缩为连接其两个端点的最短轴对齐折线，并用端点标签的混合规则重新着色。
- `Input structure`：背景色网格上有若干条由同一种颜色（如 blue）绘制的曲折路径（宽度1像素，4-连通，无分支）。每条路径的两个端点各自紧邻一个不同颜色的标签像素（标签不在路径上，而是与端点4-相邻）。不同路径的标签颜色对可能不同。
- `Rule`：
  1. 找到所有路径及其两个端点，以及每个端点旁的标签颜色。
  2. 擦除原始路径。
  3. 对每条路径，绘制从一个端点到另一个端点的最短轴对齐折线（先水平后垂直，即L形路径），用路径原色绘制。
  4. 折线的前半段（从起点到拐角）使用一个端点的标签颜色，后半段（从拐角到终点）使用另一个端点的标签颜色。起点定义为行号较小的端点（若行号相同则列号较小的端点）。
  5. 拐角像素（折线转弯处）使用两个标签颜色中在网格中出现次数较多的那个颜色。
  6. 标签像素本身保留不变。
- `Key insight`：解题者需要先理解路径被"拉直"为L形折线的几何变换，再发现折线的着色规则——前后两段分别继承对应端点的标签色，拐角处的颜色选择基于全局标签频率。路径的简化和重新着色是两个独立但交织的推理层。
</new_puzzle>
