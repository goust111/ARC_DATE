<description>
根据边框缺口方向将内部碎片弹射出框，再用碎片颜色决定弹射后的形态变换。

Input structure：
- 背景为黑色。网格中有若干由灰色像素围成的矩形空心框（边框宽度1像素）。
- 每个框的某一侧边框上恰好有一个连续缺口（缺口宽度等于框内某个彩色碎片的对应边长度）。
- 框内有一个或多个单色4-连通碎片对象。其中恰好有一个碎片的宽度或高度与缺口宽度相同（称为"可弹射碎片"）。
- 框外的黑色背景上无其他对象。

Rule：
- 识别每个灰色框及其缺口所在的边（上/下/左/右）。
- 找到框内与缺口尺寸匹配的可弹射碎片。
- 将该碎片沿缺口方向平移出框，紧贴框外侧放置（碎片与框外壁相邻）。
- 弹射后的形态变换：若碎片颜色为红色，则碎片保持原样；若碎片颜色为蓝色，则碎片沿弹射方向做镜像翻转；若碎片颜色为绿色，则碎片旋转180度。
- 框内该碎片原位置变为黑色背景；框内其余碎片和灰色边框保持不变。

Key insight：
缺口的位置和尺寸决定了哪个碎片被弹射以及弹射方向，而碎片自身的颜色则隐含地编码了弹射后的几何变换类型——解题者需要同时发现尺寸匹配规则和颜色-变换对应关系这两层独立规律。
</description>

<description>
将散落的彩色种子像素沿通道网络传播，在通道交叉点按颜色混合规则生成新颜色。

Input structure：
- 背景为黑色。网格中有一个由灰色像素构成的单像素宽正交通道网络（类似管道），通道之间通过交叉点或T形接口相连。
- 通道的若干末端（死胡同）各有一个彩色种子像素（颜色为红、蓝或黄三种之一），种子像素紧邻灰色通道的端点。
- 通道交叉点处为灰色像素。

Rule：
- 每个种子颜色沿其相邻的灰色通道向内扩散，将通道上的灰色像素重新着色为该种子颜色，直到遇到交叉点或另一种颜色。
- 当两种不同的种子颜色从不同方向到达同一个交叉点时，交叉点像素着色为混合色：红+蓝=magenta，红+黄=orange，蓝+黄=green。
- 若三种颜色同时到达同一交叉点，则交叉点着色为灰色（保持不变）。
- 扩散后，从交叉点出发的下游通道使用交叉点的混合颜色继续扩散，直到遇到下一个交叉点或通道末端。
- 种子像素本身保持原色不变。

Key insight：
解题者首先需要识别通道的拓扑结构和种子位置，然后发现颜色沿通道传播并在交叉点按固定的两两混合规则产生新颜色——关键在于理解混合色还会继续作为新的"种子"向下游传播，形成级联混色链。
</description>

<description>
用小图案模板的孔洞位置作为索引，从色板条中选色，将模板中的实心部分重新着色。

Input structure：
- 背景为黑色。网格上半部分包含一个水平排列的色板条：由若干等宽的彩色竖条紧密排列组成（每个竖条为单一非黑色颜色，宽度为1列，高度相同），色板条被灰色边框包围。
- 网格下半部分散布若干小型图案模板（每个模板为一个由单一前景色构成的小型4-连通对象，面积不超过约15像素），模板内部可能含有黑色孔洞像素（即被前景色包围的黑色像素）。

Rule：
- 数出每个模板内部的黑色孔洞像素数量N（无孔洞则N=0）。
- 以N作为从左到右的索引（从0开始），在色板条中找到第N个竖条的颜色。
- 将该模板的所有前景像素重新着色为该索引对应的颜色，孔洞保持黑色。
- 色板条及其灰色边框在输出中保持不变。

Key insight：
模板的外部形状是干扰项，真正决定输出颜色的是每个模板内部被包围的孔洞数量——解题者需要发现孔洞计数与色板条位置之间的对应关系，这构成了一层需要主动推理的隐含映射。
</description>

<description>
根据箭头指向选择目标区域，再根据箭头长度决定在目标区域中绘制的填充层数。

Input structure：
- 背景为黑色。网格中有若干灰色矩形区域（大小不一，内部为灰色填充）。
- 每个灰色矩形的某一侧外部紧邻一个由红色像素组成的箭头。箭头的绘制方式为：一条沿水平或垂直方向的直线段（箭头杆），末端带一个由3个像素组成的三角尖端（即杆末端像素加上垂直于杆方向的上下或左右各一个像素），箭头尖端指向灰色矩形。
- 箭头杆的长度（不含尖端，以像素数计）在1到4之间。

Rule：
- 箭头尖端所指的方向确定从灰色矩形的哪一侧开始填充。
- 箭头杆的像素数量N决定填充的层数：从箭头指向的那一侧向内，将灰色矩形最外N层像素重新着色为红色（逐层剥皮式填充，类似洋葱层）。若N大于等于矩形在该方向上深度的一半，则填充到矩形中心为止。
- 箭头本身在输出中被擦除（变为黑色背景）。
- 无箭头的灰色矩形保持不变。

Key insight：
箭头同时编码了两个独立信息：方向编码填充起始边，长度编码填充深度。解题者需要先识别箭头结构并解析其朝向，再发现杆长度与填充层数之间的数值对应关系——两层规律缺一不可。
</description>

<description>
按遮挡关系对重叠色块分层，再将各层按面积从大到小重新排列为不重叠的水平序列。

Input structure：
- 背景为黑色。网格中有若干不同颜色的矩形色块，这些色块部分重叠，形成遮挡关系（上层色块覆盖下层色块的部分像素）。
- 每种非黑颜色恰好对应一个矩形色块。
- 重叠区域显示的是最上层色块的颜色。

Rule：
- 通过分析可见像素和被遮挡的边界，推断出每个矩形色块的完整尺寸（宽和高）。被遮挡的矩形可以通过其可见的L形、U形或条形残留边界推断出完整边界。
- 确定每个色块的面积（宽x高）。
- 输出为单行高度等于所有色块中最大高度的网格，将所有色块按面积从大到小、从左到右排列，相邻色块之间间隔1列黑色背景，每个色块垂直底部对齐。

Key insight：
输入中的遮挡关系是干扰也是线索——解题者必须先从部分可见的边缘重建每个被遮挡矩形的完整尺寸，然后发现输出的排列规则是按面积排序而非按原始位置或遮挡层级排序。重建隐藏尺寸和发现排序依据构成两层独立的推理。
</description>

<description>
识别网格中的"印章"模板和"信封"区域，将印章图案旋转后盖印到每个信封的指定角落。

Input structure：
- 背景为黑色。网格中有一个用灰色边框围起来的小型正方形区域（边长3到5），内部包含一个由某种彩色像素构成的非对称小图案，该区域即为"印章模板"。
- 网格中另有若干个较大的矩形区域，由另一种统一的颜色（如azure）填充，称为"信封"。
- 每个信封的恰好一个角落像素被替换为一个独特的彩色标记像素（非黑、非azure、非印章模板颜色），该标记像素指示盖印位置。

Rule：
- 提取印章模板的内部图案（不含灰色边框）。
- 对每个信封，找到其角落标记像素所在的角（左上/右上/左下/右下）。
- 根据角落位置旋转印章图案：左上角不旋转（0度），右上角旋转90度顺时针，右下角旋转180度，左下角旋转270度顺时针。
- 将旋转后的图案覆盖绘制到信封的该角落区域，图案颜色替换为标记像素的颜色。标记像素本身被图案覆盖。
- 印章模板区域（含灰色边框）在输出中保持不变。

Key insight：
解题者需要三步推理：首先识别哪个小区域是模板、哪些是信封；其次发现角落标记的位置决定旋转角度（而非颜色决定旋转）；最后发现标记的颜色决定了盖印后的着色——角落位置编码旋转，标记颜色编码着色，两者分别独立控制不同的变换维度。
</description>

<description>
将围栏内的动物（小图案）按围栏开口方向释放，释放距离由围栏内同伴数量决定。

Input structure：
- 背景为黑色。网格中有若干由maroon像素围成的矩形围栏（边框宽度1像素），每个围栏的某一侧有一个宽度为2像素的缺口（开口）。
- 每个围栏内部有1到4个小型彩色4-连通对象（每个对象由同一种颜色构成，面积2到4像素），这些对象颜色各不相同。
- 围栏外部的黑色背景上没有其他对象。

Rule：
- 识别每个围栏的开口方向（上/下/左/右）和围栏内部的对象数量N。
- 将围栏内的所有对象沿开口方向平移，平移距离为N个像素（即围栏内有3个对象则每个对象移动3像素）。
- 平移后的对象出现在围栏外部，保持原始形状和颜色。
- 围栏（包括缺口）保持不变，围栏内部对象原来的位置变为黑色。

Key insight：
开口方向容易从围栏形状直接看出，但平移距离并非由开口大小或对象大小决定，而是由围栏内共存的对象总数决定——解题者需要发现"同伴数量"这一非直觉的数值映射关系，这是区别于简单"弹射"机制的核心推理层。
</description>

<description>
根据连接线的路径形状对端点对象执行对应的几何变换，再将变换结果写回原位。

Input structure：
- 背景为黑色。网格中有若干成对出现的小型彩色矩形对象（每对由相同颜色标识），每对对象之间由一条灰色单像素宽的正交折线连接。
- 连接线只走水平和垂直方向，可能包含0次、1次或2次直角转弯。
- 每个彩色对象是一个不超过4x4的非对称小矩形。

Rule：
- 识别每对同色对象及其之间的灰色连接线。
- 统计连接线的转弯次数：
  - 0次转弯（直线）：将两个对象各自原地做水平镜像翻转。
  - 1次转弯（L形）：将两个对象各自原地旋转90度（旋转方向与L形转弯方向一致——若连接线从水平转向上方则逆时针旋转，转向下方则顺时针旋转）。
  - 2次转弯（Z形/S形）：将两个对象各自原地旋转180度。
- 变换后的对象绘制在原始位置（以对象的左上角为锚点），灰色连接线保持不变。

Key insight：
连接线不仅表示配对关系，其几何形状（弯折次数和方向）还隐含编码了要执行的变换类型——解题者需要从连接线的拓扑形态中归纳出转弯次数到变换类型的映射规则，这比简单的颜色匹配或方向判断多了一层结构性推理。
</description>
</new_puzzle>
