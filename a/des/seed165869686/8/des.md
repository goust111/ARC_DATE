description：根据封闭区域内部的"种子"颜色，从区域图例中查找对应的填充图案，再将该图案平铺到整个封闭区域内部。

Input structure：
- 背景色（bg）为网格中最常见的颜色。
- 网格中存在若干由 grey 像素围成的封闭矩形区域（grey 像素构成完整的矩形边框，宽度为 1 像素）。
- 每个封闭区域内部恰好有一个非背景色的单像素"种子"，位于区域内部的左上角位置。
- 网格的最上方一行（或最左方一列）排列着若干小的 3x3 矩形"图例块"，每个图例块由 1 像素宽的边框包围，边框颜色各不相同，内部是一个 2x2 的双色棋盘格图案（两种颜色交替排列）。
- 每个种子像素的颜色恰好与某个图例块的边框颜色匹配。

Rule：
- 对于每个封闭的 grey 矩形区域，找到其内部的种子像素颜色 C。
- 在图例中找到边框颜色为 C 的图例块，读取其内部 2x2 的棋盘格图案（包括两种颜色及其排列方式）。
- 将该 2x2 棋盘格图案以平铺方式填满整个封闭区域的内部（不含 grey 边框），从区域内部左上角开始平铺，种子像素本身也被覆盖。
- 图例块在输出中保持不变；grey 边框保持不变。

Key insight：种子颜色是查找图例的索引键，而图例内部的 2x2 图案不仅编码了填充颜色，还编码了空间排列方式——解题者需要先建立"种子→图例边框颜色"的映射，再将图例内部的图案作为瓷砖模板进行平铺，这构成两层独立的推理。
</new_puzzle>

description：将散落的彩色碎片按颜色归组后拼入对应颜色的矩形框架的缺口中，碎片形状恰好与框架缺口互补。

Input structure：
- 背景色（bg）为网格中最常见的颜色。
- 网格中有若干个不同颜色的矩形框架，每个框架由某种非背景色像素围成一圈（宽度 1 像素），但每个框架的边框上恰好缺失了一个连续的矩形缺口（即边框有一段是背景色）。框架内部全部为背景色。
- 网格的另一区域（与框架不重叠）散落着若干小的实心彩色碎片（4-连通的单色连通分量），每个碎片的颜色与某个框架的边框颜色相同。
- 每种颜色的碎片形状恰好与同色框架缺口的形状（大小和轮廓）完全相同。

Rule：
- 对于每个矩形框架，识别其边框颜色 C 和缺口位置及形状。
- 在散落碎片中找到颜色为 C 的碎片。
- 将该碎片从原位置移除（恢复为背景色），然后将其平移到框架缺口处，精确填补缺口，使框架成为完整的矩形边框。
- 碎片不需要旋转或翻转，只需平移。
- 框架内部保持为背景色不变。

Key insight：解题者需要先通过颜色匹配将碎片与框架配对（第一层推理），然后理解碎片并非填入框架内部而是补全框架边框本身的缺口（第二层推理——"填充"的目标是边框而非内部空间，这与直觉相反）。

<new_puzzle>
description：根据每行箭头指向的方向，将该行中所有散落的彩色像素按颜色分组后依次紧密堆叠到箭头所指的那一侧墙壁，堆叠顺序由像素距箭头的远近决定。

Input structure：
- 背景色（bg）为网格中最常见的颜色。
- 网格的最左列或最右列中，某些行包含一个由 red 像素构成的 3 像素箭头（一个水平线段像素加上两个斜向像素构成箭头尖），箭头朝左或朝右。没有箭头的行保持全背景色。
- 在有箭头的每一行中（箭头列之外的区域），散布着若干不同颜色的非背景色像素点，每种颜色在该行中出现 1 到 3 次。
- 同一行中不同颜色像素的出现次数可能不同。

Rule：
- 对于每个包含箭头的行，确定箭头方向（左或右）。
- 收集该行中所有非背景、非箭头颜色的像素，按颜色分组，记录每种颜色的像素数量。
- 将所有像素从原位置清除。
- 按照颜色在该行中首次出现的列位置从靠近箭头侧到远离箭头侧排序。
- 将排序后的颜色组依次紧密排列到箭头所指方向的墙壁边（若箭头朝右，则从该行最右端开始向左堆叠；若箭头朝左，则从该行最左端——箭头之后的第一个可用位置——开始向右堆叠）。每个颜色组内部连续排列，组与组之间紧密相邻无间隔。
- 箭头本身在输出中被移除（替换为背景色）。

Key insight：箭头不仅编码了堆叠方向，还隐含了排序基准——颜色组的堆叠顺序取决于它们原始位置与箭头的远近关系（离箭头近的颜色先贴墙），而非按颜色本身的某种属性排序。解题者需要先理解方向编码，再发现排序规则依赖于空间位置，构成两层推理。
</new_puzzle>

description：识别网格中由分隔线划分的多个子区域，根据每个子区域内部"标尺条"的长度确定该区域的缩放比例，然后将区域内的图案按该比例缩放后输出。

Input structure：
- 背景色（bg）为网格中最常见的颜色。
- 一条水平的 azure 分隔线和一条垂直的 azure 分隔线将网格分成四个矩形子区域（类似十字分割）。
- 每个子区域内包含两样东西：(a) 一个由某种前景色构成的小型图案（4-连通对象，占据 2x2 到 4x4 的范围），以及 (b) 一根由 maroon 像素构成的水平或垂直直线段（"标尺条"），位于子区域的边缘位置（紧贴 azure 分隔线或网格边界）。
- 四个子区域中的图案形状完全相同（颜色可能不同），但标尺条的长度各不相同（长度为 1 到 4 像素）。

Rule：
- 对于每个子区域，读取标尺条的像素长度 L（1、2、3 或 4）。
- 将该子区域中的图案按比例 L 进行整数倍放大：原图案中的每个像素变成 L x L 的同色像素块。
- 输出网格不再保留分隔线和标尺条。输出为四个缩放后的图案排列在一个新的网格上，按照原来四个子区域的相对位置（左上、右上、左下、右下）排列，图案之间间隔 1 列/行的背景色。
- 输出网格的大小根据缩放后的图案大小自动确定。

Key insight：标尺条的长度是缩放因子的视觉编码——解题者需要先发现四个区域包含相同图案（第一层），再发现 maroon 线段的长度控制缩放比例（第二层），最后理解输出的重新排列方式（第三层）。标尺条的方向（水平或垂直）是干扰项，只有长度有意义。
</new_puzzle>

<new_puzzle>
description：在网格中找到多个同构的彩色"钥匙"形状和对应的"锁孔"轮廓，将每把钥匙旋转到能插入对应锁孔的朝向后填入锁孔。

Input structure：
- 背景色（bg）为网格中最常见的颜色。
- 网格中散布着若干"锁孔"：每个锁孔是一个由 grey 像素围成的封闭轮廓（宽度 1 像素），内部为背景色，形状为 L 形、T 形或十字形等非对称形状。每个锁孔的 grey 轮廓外侧某一边紧邻一个单像素的彩色"标记点"。
- 网格中还散布着若干实心的彩色"钥匙"对象（4-连通单色连通分量），每把钥匙的颜色与某个锁孔标记点的颜色相同。
- 每把钥匙的形状与对应锁孔的内部空腔形状相同，但可能经过 0 度、90 度、180 度或 270 度的旋转。
- 标记点的位置（锁孔的上、下、左、右哪一侧）编码了钥匙需要旋转的信息：标记点在锁孔上方表示不旋转（0度），标记点在右侧表示顺时针旋转 90 度，标记点在下方表示旋转 180 度，标记点在左侧表示顺时针旋转 270 度。

Rule：
- 通过颜色匹配将每把钥匙与对应的锁孔配对。
- 确定标记点相对于锁孔轮廓的方位（上/右/下/左）。
- 将钥匙按标记点指示的角度旋转。
- 将旋转后的钥匙平移到锁孔内部，精确填满空腔（钥匙像素替换空腔中的背景色像素）。
- 钥匙原来的位置被清除为背景色；标记点在输出中被移除；grey 轮廓保持不变。

Key insight：解题者需要完成三层推理：(1) 颜色匹配建立钥匙-锁孔配对，(2) 标记点的方位编码旋转角度而非仅仅标识对应关系，(3) 旋转后的钥匙形状恰好与锁孔空腔互补。标记点同时承担了"配对索引"和"旋转指令"两个功能，这是机制隐蔽性的来源。
</new_puzzle>

description：将网格中各个房间内的彩色像素沿"传送门"配对通道转移到另一个房间，传送后像素在目标房间中的相对位置保持点对称。

Input structure：
- 背景色（bg）为网格中最常见的颜色。
- 网格被 black 像素构成的墙壁分隔为若干个大小相同的矩形"房间"（墙壁宽度 1 像素）。
- 每个房间的某一面墙上恰好有一个 2 像素宽的缺口（墙壁中断处），缺口两侧的墙壁像素被替换为某种非黑非背景的颜色——该颜色即为这个缺口的"传送门颜色"。
- 每种传送门颜色在整个网格中恰好出现两次（分属两个不同房间的缺口），构成一对传送门。
- 部分房间内部包含若干散落的彩色非背景像素（与传送门颜色不同）。

Rule：
- 识别所有传送门配对（同色缺口配对）。
- 对于每个包含内部像素的房间，找到该房间的传送门颜色 C，以及与之配对的另一个房间（拥有同色传送门 C 的房间）。
- 将源房间内的所有彩色像素移除，在目标房间中以房间中心为对称中心做点对称（180 度旋转）后放置。即：若源像素在源房间内部的相对坐标为 (r, c)（以房间左上角内部为原点），则在目标房间中放置到 (H-1-r, W-1-c)，其中 H 和 W 是房间内部的高度和宽度。
- 若目标房间原本也有像素，则该房间的像素同时通过其自身的传送门转移走（所有传送同时发生，不会冲突）。
- 传送门缺口颜色像素和 black 墙壁在输出中保持不变。

Key insight：解题者需要三层推理：(1) 识别墙壁缺口处的彩色像素是传送门标记而非普通对象，(2) 通过颜色匹配找到传送门配对关系，(3) 发现传送后像素的位置经过了 180 度旋转而非简单平移——这需要对比多个样例中像素在源房间和目标房间的相对位置才能归纳出来。
</new_puzzle>

<new_puzzle>
description：根据网格中"染色池"的嵌套层数重新着色每个池的边框，层数越深颜色越按固定序列推进。

Input structure：
- 背景色（bg）为网格中最常见的颜色。
- 网格中存在若干个由同一种前景色（如 blue）绘制的嵌套矩形边框。每个矩形边框宽度为 1 像素，边框之间间隔 1 像素的背景色。
- 这些矩形边框构成明显的嵌套结构：最外层边框包围第二层，第二层包围第三层，以此类推。嵌套层数从 1 到 4 不等。
- 网格的某个角落（如右下角）有一个小的 1 列 N 行的"色带"图例，从上到下排列着 N 种不同颜色（N 等于最大嵌套深度），色带用 grey 单像素边框包围。

Rule：
- 确定每个矩形边框的嵌套深度（最外层为深度 1，下一层为深度 2，依此类推）。
- 读取色带图例中从上到下的颜色序列，记为 C1、C2、C3、C4...
- 将深度为 k 的矩形边框重新着色为 Ck。
- 色带图例在输出中被移除（替换为背景色），其 grey 边框也被移除。
- 背景色和矩形边框之间的间隔保持不变。

Key insight：解题者需要先识别嵌套结构并正确计算每个边框的深度层级（第一层推理），再发现角落的色带是深度到颜色的映射表（第二层推理）。嵌套深度不是靠颜色区分的（输入中所有边框同色），而是靠空间包含关系判断的，这使得深度判定成为一个非平凡的视觉推理步骤。
</new_puzzle>
