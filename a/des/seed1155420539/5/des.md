<new_puzzle>
description：根据封闭区域内部"种子"像素的颜色，从区域的颜色图例中查找对应的填充图案，将该图案平铺填入整个封闭区域。

Input structure：
- 背景为 black。
- 网格中有若干由同一颜色（如 grey）绘制的一像素宽封闭矩形框，框之间互不重叠、互不接触。
- 每个封闭矩形框的内部恰好包含一个单像素"种子"，其颜色为非 black、非框色的某种前景色（如 red、blue、green 等）。种子的位置在框内任意。
- 网格的一侧（例如最左列或最上行附近）有一组"颜色图例"：每个图例由一个与种子颜色相同的单像素标签紧邻一个小矩形图案块组成。图案块使用两种颜色（black 和一种装饰色）绘制，尺寸与对应封闭框的内部空间无关（图案块固定为 2x2 或 3x3）。标签像素位于图案块的正左方一格。

Rule：
- 对每个封闭矩形框，读取其内部种子像素的颜色。
- 在颜色图例中找到标签颜色与种子颜色一致的那个图例，取出其图案块。
- 将该图案块以平铺（tile）方式填满封闭框的整个内部区域：图案块的左上角对齐框内部区域的左上角，沿行和列重复铺设，超出内部区域的部分截断。
- 移除种子像素（即种子所在位置也被图案覆盖）。
- 颜色图例区域在输出中保持不变。

Key insight：
- 解题需要两步非平凡推理：第一步是识别出图例区域中"标签+图案"的配对关系，理解标签颜色是索引键；第二步是发现图案并非缩放到框的大小，而是以原始尺寸周期性平铺填充。单看一个样例可能误以为图案被拉伸，但多个不同大小的框会揭示平铺机制。
</new_puzzle>

<new_puzzle>
description：将网格中散布的彩色像素按颜色分组，每组像素的包围盒区域用该颜色的实心矩形替换，重叠区域的颜色由后绘制的层覆盖，而绘制顺序由每组像素的数量从少到多决定。

Input structure：
- 背景为 black。
- 网格中散布着多种前景色的单像素点（每种颜色至少 2 个、至多 6 个像素）。
- 每种前景色的像素数量互不相同。
- 同一颜色的像素不会全部共线（即每种颜色的像素集合的轴对齐包围盒面积大于零）。

Rule：
- 对每种前景色，计算其所有像素的轴对齐最小包围盒（bounding box）。
- 按每种颜色的像素数量从少到多排序，确定绘制顺序。
- 按此顺序依次在输出网格上绘制实心矩形：每个矩形覆盖该颜色包围盒的全部区域，使用该颜色填充。
- 后绘制的矩形覆盖先绘制的矩形在重叠区域的颜色。
- 不属于任何包围盒的区域保持 black 背景。

Key insight：
- 第一层推理：识别出每种颜色的散点定义了一个矩形区域（包围盒），输出将散点扩展为实心矩形。第二层推理：发现重叠区域的颜色取决于绘制顺序，而绘制顺序由各颜色的原始像素数量决定——像素越多的颜色越后绘制，因此在重叠中"胜出"。像素数量是可以直接在网格上数出来的视觉量。
</new_puzzle>

<new_puzzle>
description：在由彩色边框围成的多个房间组成的迷宫中，每个房间有一个彩色标记，根据标记颜色与边框颜色的匹配关系打开对应的"门"（将边框上的该色段替换为背景色），从而连通相邻房间。

Input structure：
- 背景为 black。
- 网格被一像素宽的彩色线段分割成若干矩形"房间"。每段边框线（两个交叉点之间的一段连续同色线）使用单一颜色，但不同段可以使用不同颜色（如 red、blue、green、yellow 等）。
- 每个房间内部恰好包含一个单像素标记，标记的颜色是该网格中某段边框所使用的颜色之一。
- 交叉点像素（即两条边框线的交点）统一使用 grey 颜色，不属于任何一段边框线。

Rule：
- 对每个房间，读取其内部标记像素的颜色。
- 在该房间的四面边框中，找到颜色与标记颜色一致的那一段边框线。
- 将该段边框线上除 grey 交叉点外的所有像素替换为 black（即"打开门"），同时移除房间内的标记像素。
- 如果一个房间的四面边框中没有与其标记颜色匹配的段，则该房间保持不变（标记也保留）。
- grey 交叉点始终保持不变。

Key insight：
- 第一层推理：识别出网格是由不同颜色的边框段构成的房间网格，交叉点是固定的 grey 锚点。第二层推理：发现每个房间内部标记的颜色不是装饰性的，而是一个"钥匙"——它指定要消除哪一段同色边框，从而在该方向打开通道。需要注意的是"门"打开的是整段同色边框，而不仅仅是标记正对的一个像素。
</new_puzzle>

<new_puzzle>
description：将网格中的多个小型形状按照各自缺失角的方位进行旋转，使所有形状的缺失角统一朝向同一方向（由网格边缘的方向指示器决定），然后将旋转后的形状移动到网格上按行列排列的锚点位置。

Input structure：
- 背景为 black。
- 网格的某一条外边缘（上、下、左或右）上有一个由 maroon 像素构成的单像素宽箭头标记，箭头指向网格内部的某个正交方向（上、下、左或右）。箭头由三个像素组成：一个"尖端"像素和两个与尖端正交对称相邻的"翼"像素，尖端朝向网格内部。
- 网格内部散布着若干个 3x3 的 L 形形状（即 3x3 方块去掉一个角的像素，剩余 8 个像素）。每个 L 形使用同一种前景色，不同 L 形颜色可相同或不同。每个 L 形的缺失角可以在四个角位之一（左上、右上、左下、右下）。
- 网格内部另有若干个由 orange 单像素构成的锚点，锚点数量与 L 形数量相同。锚点在网格中按行优先排列时，与 L 形按行优先排列一一对应。

Rule：
- 读取 maroon 箭头标记，确定目标方向（箭头尖端所指的方向）。目标方向对应一个"目标缺失角方位"：箭头指向上方对应目标缺失角在左上；箭头指向右方对应目标缺失角在右上；箭头指向下方对应目标缺失角在右下；箭头指向左方对应目标缺失角在左下。
- 对每个 L 形，判断其当前缺失角方位，将其旋转（0度、90度、180度或270度）使缺失角方位变为目标方位。
- 将所有 L 形按行优先顺序（先按原始位置的行坐标排序，行相同则按列坐标排序）与 orange 锚点按行优先顺序一一配对。
- 将每个旋转后的 L 形移动到对应的 orange 锚点位置，使 L 形的 3x3 包围盒中心对齐 orange 锚点。
- 移除 maroon 箭头标记和所有 orange 锚点，清除 L 形原始位置。

Key insight：
- 第一层推理：需要发现边缘的 maroon 箭头不仅指定了一个方向，还通过一套固定映射规则将方向转化为"缺失角方位"。第二层推理：发现所有 L 形都必须旋转到同一个目标缺失角方位，而每个形状需要的旋转量取决于其自身当前的缺口位置。第三层推理：L 形与锚点的配对关系是通过各自在网格中的空间位置按行优先排序建立的，而非通过颜色匹配。
</new_puzzle>

<new_puzzle>
description：在输入网格中找到由边框包围的两个子图案，将其中一个子图案视为"模板"、另一个视为"数据"，用数据图案中每个前景像素的位置在模板图案的对应位置采样颜色，生成最终输出。

Input structure：
- 背景为 black。
- 网格中有两个尺寸相同的矩形区域，各自被一像素宽的边框包围。两个边框颜色不同（例如一个 red 边框、一个 blue 边框）。两个矩形内部区域尺寸完全相同（例如都是 5x5）。
- 其中一个矩形（"模板"）内部包含多种颜色的图案，没有 black 像素（即内部每个位置都有非背景颜色）。
- 另一个矩形（"数据"）内部是由 black 背景和单一前景色构成的二值图案，前景色与该矩形的边框颜色相同。
- 在两个矩形之外、网格的某个角落有一个单像素指示器，颜色与"模板"矩形的边框颜色相同，用于标识哪个矩形是模板。

Rule：
- 通过角落的单像素指示器颜色识别模板矩形：指示器颜色与哪个矩形边框颜色一致，那个就是模板。另一个是数据矩形。
- 输出网格的尺寸等于两个矩形的内部区域尺寸。
- 对数据矩形内部的每个位置：如果该位置是前景像素，则输出该位置采用模板矩形内部对应位置的颜色；如果该位置是 black 背景，则输出该位置为 black。
- 即：数据矩形的前景形状充当遮罩（mask），模板矩形提供颜色，两者叠加生成输出。

Key insight：
- 第一层推理：需要识别出两个边框矩形扮演不同角色（模板 vs. 数据），而角色的分配由角落单像素指示器的颜色决定——这个指示器容易被忽略或误认为噪声。第二层推理：发现数据矩形的二值图案不是要直接输出的内容，而是一个空间遮罩，必须与模板矩形在对应位置上进行采样组合。这种"一个提供形状、一个提供颜色"的分离机制是核心难点。
</new_puzzle>
