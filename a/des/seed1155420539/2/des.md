<new_puzzle>
description：根据封闭区域内部的色块数量，选取对应颜色的"钥匙"像素来重新着色该封闭区域的边框。

Input structure：
- 背景色 bg 为最常见颜色。
- 网格中散布若干由同一种前景色（如 blue）绘制的封闭矩形边框（一像素宽），每个边框内部包含若干不同颜色的独立单像素色块（色块之间不相邻）。
- 在网格的某个固定区域（如最下方一行或最右侧一列）存在一排"钥匙"像素，每个钥匙像素颜色各不相同，它们从左到右（或从上到下）排列，位置索引从 1 开始递增。

Rule：
- 对每个封闭矩形边框，数出其内部包含的色块数量 N（N 不超过钥匙像素总数）。
- 在钥匙像素序列中找到第 N 个钥匙像素，取其颜色 C。
- 将该矩形边框的所有边框像素从原色重新着色为 C，内部色块和背景保持不变。
- 钥匙像素本身在输出中保持原样。

Key insight：边框内部色块的数量是一个索引值，指向钥匙序列中的对应颜色；解题者需要先建立"数量→索引→颜色"的映射关系，再将该颜色反向应用到边框上——这是两层非平凡推理：第一层是发现内部数量与钥匙位置的对应，第二层是发现重着色目标是边框而非内部。
</new_puzzle>

<new_puzzle>
description：将网格中的箭头形状对象沿其指向方向推送，直到碰到同色目标块，然后目标块吸收箭头的颜色变为双色条纹。

Input structure：
- 背景色 bg 为最常见颜色（如 black）。
- 网格中有若干"箭头"对象和若干"目标块"对象。
- 箭头对象由一种颜色绘制，形状为 3 行 3 列的右向箭头（第 1 行第 3 列一个像素，第 2 行第 1-3 列三个像素成水平线，第 3 行第 3 列一个像素，构成"▶"形），箭头可经旋转 90°/180°/270° 变为朝上/左/下方向。箭头的朝向由其尖端像素相对于横杆的位置决定。
- 目标块为 3×3 的实心正方形，颜色与某个箭头不同。
- 每个箭头在其指向方向的射线上恰好有一个目标块（中间全是背景色）。

Rule：
- 识别每个箭头的朝向（通过尖端位置判断），确定其指向方向。
- 将箭头沿指向方向平移，直到箭头的尖端像素与目标块的最近边相邻（即紧贴目标块停下）。
- 箭头在新位置处保留原色绘制，原位置清除为背景。
- 目标块被"激活"：其 3×3 区域变为水平条纹图案——奇数行（第 1、3 行）保持目标块原色，偶数行（第 2 行）变为该箭头的颜色。

Key insight：解题者首先需要从箭头形状中解读出方向信息，然后发现箭头会沿方向滑动到目标块旁停下，最后还需归纳出目标块的条纹重着色规则（箭头颜色仅填入中间行）。三层推理依次为：方向解读、滑动停靠、条纹激活。
</new_puzzle>

<new_puzzle>
description：在网格中找到由边框颜色配对的矩形容器，交换它们的内部填充图案，同时根据两容器之间连线上的中继标记对图案进行旋转变换。

Input structure：
- 背景色 bg 为最常见颜色（如 black）。
- 网格中有偶数个矩形容器（通常为 4 或 6 个），每个容器由单像素宽的彩色边框围成，内部填充一个由另一种颜色组成的小图案（非对称的 2×2 或 3×3 像素形状）。
- 容器的边框颜色两两配对：恰好有两个容器共享同一种边框颜色。
- 在每对同色边框容器之间的背景区域中，存在 0 个、1 个或 2 个 grey 单像素中继标记，排列在两容器中心连线的大致方向上。

Rule：
- 将边框颜色相同的两个容器配对。
- 对于每一对容器 A 和 B，数出它们之间的 grey 中继标记数量 K（K 为 0、1 或 2）。
- 将 A 的内部图案取出，顺时针旋转 K×90°，然后放入 B 的内部区域（居中放置）；同时将 B 的内部图案取出，同样顺时针旋转 K×90°，放入 A 的内部区域。
- 边框保持不变，grey 中继标记在输出中保持原位。

Key insight：解题者需要先通过边框颜色匹配发现容器的配对关系（第一层），再注意到中继标记的数量决定了旋转角度（第二层），最后理解两个容器的内容是交换而非单向复制（第三层）。中继标记的数量编码了旋转次数这一映射关系是核心隐蔽机制。
</new_puzzle>

<new_puzzle>
description：根据每个彩色区域的边界缺口方向，从缺口处向外生长出与区域面积等长的单色射线。

Input structure：
- 背景色 bg 为最常见颜色（如 black）。
- 网格中有若干个由不同颜色填充的矩形实心区域（每个区域颜色唯一），每个矩形的四条边中恰好有一条边存在一个单像素宽的缺口（即该边上有一个像素是背景色而非区域色）。
- 各矩形互不接触，周围有足够的背景空间。

Rule：
- 对每个彩色矩形区域，找到其边界上唯一的缺口像素位置，并确定缺口所在的边（上、下、左、右）。
- 计算该矩形区域的面积（即像素总数），记为 N。
- 从缺口位置出发，沿缺口朝外的方向（即远离矩形内部的方向），在背景上连续绘制 N 个像素的射线，颜色与矩形相同。
- 若射线延伸过程中到达网格边界，则在边界处截断（不环绕）。
- 矩形本身保持不变（包括缺口处仍为背景色）。

Key insight：解题者需要完成两层推理——第一层是发现缺口位置决定了射线的生长方向（缺口即"出口"），第二层是发现射线长度并非固定值而是恰好等于该矩形的面积像素数。面积作为几何计数量转化为一维长度，这种跨维度的映射是核心洞见。
</new_puzzle>

<new_puzzle>
description：将散落的彩色碎片按颜色归入对应颜色边框的收纳格中，碎片在格内的放置行由碎片原始位置相对于收纳格的方位决定。

Input structure：
- 背景色 bg 为最常见颜色（如 black）。
- 网格中有若干个"收纳格"：每个收纳格是一个由某种颜色绘制的矩形空心边框（单像素宽），内部为背景色，内部高度恰好为 2 行或 3 行，宽度足以容纳碎片。每个收纳格的边框颜色各不相同。
- 在收纳格外部，散落着若干小型彩色碎片（4-连通的 1-3 个像素组成的小形状）。每个碎片的颜色与恰好一个收纳格的边框颜色相同。
- 同一颜色的碎片可能有多个（通常 2-3 个），分布在对应收纳格的不同方位（上方、下方）。

Rule：
- 将每个碎片按颜色匹配到对应的收纳格。
- 判断碎片位于收纳格的上方还是下方（比较碎片的中心行与收纳格的中心行）：
  - 位于收纳格上方的碎片，放入收纳格内部的第一行（最顶行），保持碎片形状不变，水平方向从收纳格内部左端开始依次排列（多个上方碎片按其原始列坐标从小到大排列，相邻碎片之间留一个像素间隔）。
  - 位于收纳格下方的碎片，放入收纳格内部的最后一行（最底行），排列规则同上。
- 原始碎片位置清除为背景色。
- 收纳格边框保持不变。

Key insight：解题者需要三层推理——第一层是通过颜色匹配将碎片与收纳格配对，第二层是发现碎片的上下方位决定了它在收纳格中被放置的行位置（上方碎片进顶行、下方碎片进底行），第三层是发现多个同侧碎片的水平排列顺序由它们原始列坐标决定。方位信息从全局空间关系转化为局部放置规则是核心隐蔽机制。
</new_puzzle>
