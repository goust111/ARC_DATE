<new_puzzle>
<description>
根据彩色框架内部的缺口方向，将框架内的小图案"弹射"到框架外，并用缺口对侧边框上的标记颜色重新着色弹射出的图案。

Input structure
- 背景为黑色。
- 网格中有若干个由单一颜色绘制的矩形空心框架（宽度为1像素的矩形环），每个框架恰好有一个1像素宽的缺口（即框架边上有一个像素被擦除为背景色）。
- 每个框架内部包含一个由另一种颜色组成的小型连通图案（如L形、T形、小方块等），该图案不与框架接触。
- 每个框架与缺口对侧的那条边上，恰好有一个像素被替换为第三种颜色（"标记色"），该标记色与框架色和内部图案色均不同。

Rule
- 对于每个框架，找到其缺口所在的边（上/下/左/右）。
- 将框架内部的小图案沿缺口方向平移到框架外部：图案从缺口"飞出"，移动直到图案的后端（与缺口方向相反的一端）刚好离开框架边界一格。
- 弹射后的图案不再保留原色，而是用该框架上与缺口对侧那条边上的标记色像素的颜色重新着色。
- 框架本身保持不变（包括缺口和标记色像素）。
- 图案原来在框架内部的位置被清除为背景色。

Key insight
- 第一层推理：缺口决定弹射方向——这是视觉可见的。第二层推理：弹射图案的新颜色不是由图案自身或框架主色决定，而是由框架对侧边上的异色标记像素决定——需要解题者注意框架边上的单个异色像素并归纳其作为"染色源"的规则。
</description>
</new_puzzle>

<new_puzzle>
<description>
将输入网格中散落的彩色碎片拼合回各自所属的残缺模板对象中，拼合位置由碎片与模板缺口的形状匹配决定，拼合后整个模板对象按其完整面积从小到大、从左到右排列在输出网格底部。

Input structure
- 背景为黑色。
- 网格中有若干个不同颜色的大型连通对象（"模板"），每个模板内部存在一个或多个由背景色构成的矩形空洞（缺口）。
- 网格中还散落着若干小型彩色连通对象（"碎片"），每个碎片的形状恰好与某个模板中某个缺口的形状完全一致（经过平移对齐后像素完全吻合），但碎片的颜色与其目标模板的颜色不同。
- 每个缺口恰好对应唯一一个碎片，每个碎片恰好对应唯一一个缺口。

Rule
- 第一步：对每个碎片，通过形状匹配找到它所属的模板及对应缺口位置，将碎片"嵌入"缺口中（碎片保留自身颜色填入缺口）。
- 第二步：将所有补全后的模板对象裁剪为各自的最小包围矩形。
- 第三步：按每个补全模板的总像素面积（非背景像素数）从小到大排序，在一个新的背景画布上从左到右依次排列，相邻模板之间间隔一列背景色，所有模板底部对齐于画布最底行。

Key insight
- 第一层需要跨对象的形状匹配——碎片的颜色是干扰项，只有形状才是匹配依据。第二层需要发现输出的排列规则是按面积排序而非按输入中的空间位置排列。两层推理都需要主动归纳。
</description>
</new_puzzle>

<new_puzzle>
<description>
每个彩色对象像"印章"一样沿其内部箭头方向反复盖印，盖印间距等于对象自身在该方向上的跨度，盖印次数等于对象内部包含的特殊标记像素的数量。

Input structure
- 背景为灰色。
- 网格中有若干个彩色连通对象，每个对象由一种主色构成。
- 每个对象内部嵌有若干个黑色标记像素（数量为1到4个不等），以及恰好一个由红色像素组成的箭头标记。箭头标记由3个红色像素组成：一个"尖端"像素和两个与尖端相邻的"翼"像素，三者构成一个指向上/下/左/右四个基本方向之一的箭头形状。具体地：朝上的箭头为尖端在上、两翼分别在尖端的左下方和右下方（即尖端正下方的左右两侧）；朝右的箭头为尖端在右、两翼分别在尖端的左上方和左下方（即尖端正左方的上下两侧）；朝下和朝左的箭头类推。

Rule
- 对于每个对象，首先识别其红色箭头所指方向和黑色标记像素的数量N。
- 从对象的原始位置开始，沿箭头方向重复盖印该对象N次。每次盖印的偏移量等于对象包围矩形在箭头方向上的边长（即盖印副本紧邻前一个副本，无重叠无间隔）。
- 盖印的副本仅保留主色像素，不包含箭头和黑色标记。
- 原始对象保留（包括箭头和标记）。
- 如果盖印副本超出网格边界，则该副本被裁剪（仅绘制网格内的部分）。

Key insight
- 第一层推理：需要识别3像素箭头的朝向来确定盖印方向——箭头的形状编码了方向信息，需要从样例中归纳箭头像素排布与方向的对应关系。第二层推理：盖印次数不由对象大小或位置决定，而由对象内部黑色标记像素的计数决定——这是一个"数量驱动几何操作"的非显然映射。
</description>
</new_puzzle>

<new_puzzle>
<description>
在网格中，每条彩色"导线"连接两个不同颜色的端点色块；输出时将每条导线重新着色为其两端颜色的"混合色"，混合规则由网格中的一个独立色表区域定义。

Input structure
- 背景为黑色。
- 网格的左上角有一个由灰色单像素边框围成的小型矩形"色表"区域。
- 色表内部排列为若干行，每行有3个像素：前两个像素分别为颜色A和颜色B，第三个像素为颜色C，表示"当颜色A与颜色B配对时，结果为颜色C"。色表各行之间由一行背景色分隔。
- 色表外的主工作区中有若干条由绿色像素组成的单像素宽"导线"路径（4-连通线段或折线），每条导线的两端各连接一个2x2的纯色方块（"端点"），两端方块的颜色不同。
- 每条导线恰好连接两个端点，不会分岔，不同导线之间不交叉。

Rule
- 对于每条导线，找到其两端端点方块的颜色，形成一个颜色对(A, B)。
- 在色表中查找包含该颜色对的行（颜色对的顺序无关，即{A,B}和{B,A}查找同一行），读取该行第三个像素的颜色C。
- 将该导线的所有绿色像素重新着色为颜色C。
- 端点方块和色表区域保持不变。

Key insight
- 第一层推理：必须先解读色表的编码格式——理解色表中每行前两个像素是输入颜色对、第三个像素是输出色，这本身需要从样例中归纳。第二层推理：需要追踪每条导线连接的两个端点，并将端点颜色对拿去查表得出导线的新颜色，是"解读图例+路径追踪+查表着色"的三步组合推理。
</description>
</new_puzzle>

<new_puzzle>
<description>
网格中每个封闭房间内的彩色像素"投票"决定该房间所属墙壁的输出颜色；当一段墙壁被两个房间共享时，取像素数量更多的那个房间的颜色。

Input structure
- 背景为黑色。
- 灰色像素构成单像素宽的墙壁网络，将网格划分为若干个封闭的矩形"房间"（每个房间是一个由灰色墙壁围成的矩形区域，内部为背景色）。
- 每个房间内部散布着若干个彩色像素（非黑非灰），同一房间内所有彩色像素为同一种颜色，但不同房间的颜色可能相同也可能不同。
- 每个房间内的彩色像素数量各不相同（从1个到若干个不等）。

Rule
- 对于每个房间，记录其内部彩色像素的颜色C和数量N。
- 对于每一段墙壁（两个墙壁交叉点之间的连续灰色直线段），它被一个或两个房间共享：
  - 如果该墙段仅与一个房间相邻（例如位于网格最外围边缘），则将该墙段的所有像素着色为该房间的颜色C。
  - 如果该墙段被两个房间共享（墙段两侧各有一个房间），则比较两个房间的彩色像素数量，将墙段着色为数量更多的那个房间的颜色。若数量相同，则墙段保持灰色不变。
- 墙壁交叉点像素（与三段或更多墙段相连的灰色像素）保持灰色不变。
- 房间内部的彩色像素在输出中被清除为背景色。

Key insight
- 第一层推理：需要发现房间内的彩色像素并非直接影响自身所在位置的输出，而是作为"选票"间接影响周围墙壁的着色——像素的作用是间接的投票而非直接的保留。第二层推理：共享墙壁的颜色由相邻两个房间的票数竞争决定，需要理解"多数获胜"的比较机制，并注意交叉点保持中性灰色。
</description>
</new_puzzle>

<new_puzzle>
<description>
网格中的彩色条带按照与之垂直交叉的标记线的颜色进行分段重着色，每个交叉点将条带切分为区段，各区段的新颜色由切分它的两条相邻标记线的颜色共同决定。

Input structure
- 背景为黑色。
- 网格中有若干条水平的蓝色长条带（高度为1像素，宽度跨越大部分网格）。
- 若干条垂直的单像素宽彩色短线段（"标记线"）从上方或下方穿过这些水平条带。每条标记线的颜色各异（使用红、绿、黄、橙等颜色，但不使用蓝色）。
- 每条标记线与每条水平条带恰好交叉于一个像素点。交叉处的像素在输入中显示为标记线的颜色（标记线覆盖条带）。

Rule
- 对于每条水平条带，沿水平方向找出所有与之交叉的标记线，按列坐标从左到右排列。
- 这些交叉点将条带切分为若干个区段：最左端到第一个交叉点之前、两个相邻交叉点之间、最后一个交叉点之后到最右端。
- 条带最左端到第一个交叉点之前的区段，着色为第一条标记线的颜色。
- 最后一个交叉点之后到最右端的区段，着色为最后一条标记线的颜色。
- 两个相邻交叉点之间的区段：如果左侧标记线和右侧标记线颜色相同，则该区段着色为该颜色；如果不同，则该区段保持蓝色（原色）不变。
- 交叉点像素本身保持标记线的颜色不变。

Key insight
- 第一层推理：需要发现垂直标记线不仅标记位置，还通过自身颜色控制条带的分段重着色——标记线的角色是"颜色注入器"。第二层推理：相邻两个标记线之间区段的颜色取决于两端标记线颜色是否一致——相同则采用该色，不同则保持原色。这个"一致性判断"规则需要从多个样例中观察归纳，不能仅从单个交叉点推断。
</description>
</new_puzzle>

<new_puzzle>
<description>
将网格中每个由外壳和内核组成的嵌套对象拆开：外壳移动到网格边缘对应的角落，内核留在原地，内核的颜色根据外壳移向的角落位置而改变。

Input structure
- 背景为灰色。
- 网格中有若干个"嵌套对象"，每个嵌套对象由两部分组成：一个较大的空心矩形"外壳"（单像素宽的矩形环，某种颜色），以及一个较小的实心矩形"内核"（另一种颜色），内核完全位于外壳内部且不与外壳接触。
- 每个嵌套对象整体位于网格的某个象限区域内（左上、右上、左下、右下之一），且每个象限最多一个嵌套对象。
- 网格的四个角落各有一个2x2的彩色方块（"角落标记"），四个角落标记的颜色各不相同。

Rule
- 对于每个嵌套对象，确定它位于哪个象限。
- 将外壳从原位置移除，平移到该象限对应的网格角落，使外壳的外边缘与网格的两条边界对齐（即外壳贴到角落）。外壳覆盖该角落的角落标记。
- 内核留在原来的位置不动，但颜色改变为该象限角落标记原本的颜色。
- 清除外壳原来位置的像素为背景色。

Key insight
- 第一层推理：需要发现外壳与内核的拆分移动规则——外壳飞向角落，内核留在原地，这需要对比输入输出才能归纳出来。第二层推理：内核的新颜色不由其自身或外壳颜色决定，而是由目标角落处原有标记的颜色决定——角落标记是一个颜色字典，被外壳覆盖后"转移"到了内核上。这构成了"空间移动+颜色转移"的双层非显然规则。
</description>
</new_puzzle>
