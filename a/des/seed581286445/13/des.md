<new_puzzle>
用框架颜色对内部碎片进行归属判定，再按碎片数量决定框架的填充方向。

Input structure：
- 背景为最常见颜色。
- 网格中有若干个不同颜色的单像素厚矩形空心框架，框架之间互不重叠。
- 框架内部散落着若干个小型单色连通体（碎片），每个碎片由 2-4 个同色四连通像素组成。碎片的颜色与其所在框架的颜色不同，且可能与其他框架的颜色相同，也可能是独立颜色。
- 每个框架内部至少有 1 个碎片，至多有 4 个碎片。同一框架内的所有碎片颜色相同。

Rule：
- 第一步（碎片计数）：对每个框架，统计其内部碎片的数量 N。
- 第二步（填充方向）：根据碎片数量 N 决定该框架内部的填充方式：
  - N=1：从框架内部的顶边向下填充 1 行，颜色为该碎片的颜色。
  - N=2：从框架内部的左边向右填充 2 列，颜色为碎片的颜色。
  - N=3：从框架内部的底边向上填充 3 行，颜色为碎片的颜色。
  - N=4：从框架内部的右边向左填充 4 列，颜色为碎片的颜色。
- 填充时覆盖背景色像素，但保留原有碎片像素和框架像素不变。
- 若填充区域超出框架内部范围，则裁剪到框架内部边界。

Key insight：
碎片的数量不仅决定填充的厚度，还隐含编码了填充方向（上→左→下→右的顺序对应 1→2→3→4），解题者需要同时从数量中推断出这两层信息。
</new_puzzle>

<new_puzzle>
根据彩色种子像素在象限中到分隔线的距离，在对角象限中绘制对应大小的矩形。

Input structure：
- 背景为最常见颜色。
- 网格中有一条完整的水平分隔线和一条完整的垂直分隔线，两者颜色相同（如 Grey），将网格分成四个象限区域。
- 每个象限内恰好包含一个单像素的彩色种子点（四个种子颜色各不相同）。
- 每个象限除种子外均为背景色。

Rule：
- 第一步（距离读取）：测量每个种子到水平分隔线的行距 dh 以及到垂直分隔线的列距 dv。
- 第二步（对角映射）：每个种子的颜色被用来填充其对角象限（关于十字交叉点中心对称的那个象限）。在对角象限中，从紧邻交叉点的内角处开始，画一个宽度为 dv、高度为 dh 的实心矩形，矩形从交叉点的内角向该象限的外角方向延伸，颜色为对应种子的颜色。
- 原有种子像素保留，分隔线保留不变。若两个矩形在交叉点附近重叠，后绘制的（按左上→右上→左下→右下象限顺序处理种子）覆盖先绘制的。

Key insight：
种子的颜色决定"画什么颜色"，种子到十字线的两个距离决定"在对角象限画多大的矩形"——这是一个位置信息跨象限传递的机制，解题者需先发现对角映射关系，再发现距离编码尺寸的规则。
</new_puzzle>

<new_puzzle>
识别封闭围栏中的缺口方向，将围栏内部的图案从缺口方向"推出"到围栏外部对应位置。

Input structure：
- 背景为最常见颜色。
- 网格中有若干个由单一颜色（如 Blue）构成的近似矩形的封闭围栏，每个围栏恰好有一个一像素宽的缺口。缺口位于围栏的某一条边（上、下、左或右）上。
- 每个围栏内部有一个小型多色图案（标记形状），由 2-6 个非背景、非围栏色的像素组成，形成一个紧凑形状。
- 围栏之间互不接触，围栏外部是纯背景。

Rule：
- 第一步（缺口检测）：找到每个围栏边上缺失的那个像素位置，确定缺口所在的边（上/下/左/右）。
- 第二步（图案提取）：提取围栏内部标记形状的最小包围盒内容。
- 第三步（外部放置）：将标记形状的最小包围盒副本放置到围栏外侧：副本紧贴围栏外壁、位于缺口所在边的外侧，副本的中心列（若缺口在上或下边）或中心行（若缺口在左或右边）与缺口像素的列或行对齐。
- 围栏内部的原始标记形状被擦除为背景色。围栏本身（包括缺口处仍保持缺失）保持不变。

Key insight：
围栏的缺口不仅标记了"出口方向"，还决定了副本放置的轴线对齐方式；内部形状是需要被"释放"到外部的内容。解题者需要先发现"缺口即出口"的空间逻辑，再发现形状从内部消失、在外部出现的搬运对齐规则。
</new_puzzle>

<new_puzzle>
利用边缘图例条中颜色的排列顺序作为优先级，对十字形对象重叠区域中被抹去的像素进行裁决填充。

Input structure：
- 背景为最常见颜色。
- 网格的最左列是一个"优先级图例条"：由若干种不同颜色自上而下排列，每种颜色恰好占一个像素，其余位置为背景色。图例条中颜色的排列顺序定义优先级：越靠上的颜色优先级越高。
- 网格其余区域包含若干个单色的十字形对象。每个十字由一个中心像素加上上下左右各延伸相同长度的臂构成（臂长 1-3 像素），十字的颜色均出现在图例条中。
- 不同十字形对象可能在臂部发生空间重叠。重叠区域在输入中显示为背景色（即冲突导致的空白）。

Rule：
- 第一步（十字还原）：根据每个十字的中心和臂长推断出其完整覆盖范围（中心同行同列、臂长范围内的所有像素）。
- 第二步（冲突识别）：找到所有显示为背景色但被两个或以上十字覆盖范围同时包含的像素。
- 第三步（优先级裁决）：对每个冲突像素，根据图例条中的顺序选择优先级最高的那个十字颜色进行填充。
- 非冲突区域的背景像素保持不变，十字形对象原有的已着色像素保持不变。图例条保持不变。

Key insight：
输入中的"空白"并非真正的空白，而是多个十字形重叠后故意留下的冲突标记。图例条的排列顺序是隐含的"图层优先级"，解题者需要先从十字的中心和臂推断出每个空白像素的重叠归属，再用图例条打破平局。这是一个"推断隐藏冲突→查表裁决"的两层结构。
</new_puzzle>

<new_puzzle>
将散布的同色像素对解读为"传送门"，把与传送门标记重合的前景对象搬运到配对传送门位置，并按边缘映射表对搬运后的对象进行颜色替换。

Input structure：
- 背景为最常见颜色。
- 网格中有若干对颜色相同的单像素标记，每种标记颜色恰好出现两次，形成"传送门对"。不同传送门对的颜色不同。
- 网格中还有若干个小型多色四连通前景对象（3-8 个像素），每个对象的包围盒内恰好包含某个传送门标记像素。每个传送门标记最多被一个前景对象的包围盒包含。有些传送门标记不被任何对象包围盒包含（即该传送门端是空的接收点）。
- 网格最底部两行是一个"颜色映射表"，宽度等于网格宽度。映射表第一行和第二行的每一列形成一对颜色映射关系（非背景色的列才有效）。

Rule：
- 第一步（传送门配对）：找到所有同色像素对，每对构成一个传送门。
- 第二步（对象归属）：确定哪个前景对象"坐落在"哪个传送门标记上（即对象包围盒包含该标记）。
- 第三步（传送搬运）：将对象从当前传送门位置搬运到同色传送门对的另一个标记位置。搬运时保持对象相对于传送门标记像素的偏移不变。原位置的对象像素被擦除为背景。
- 第四步（颜色重映射）：搬运后，对象中每个像素的颜色根据映射表进行替换——在映射表中找到该颜色出现的列，用同列另一行的颜色替换。若某像素颜色不在映射表中，则保持不变。
- 传送门标记像素本身在输出中保留。映射表保留不变。

Key insight：
解题者需要发现三层独立的非显然规则：（1）同色像素对是传送门而非装饰；（2）对象通过传送门"瞬移"到配对位置；（3）搬运后还需查阅底部映射表进行颜色变换。每一层都无法仅靠上一层推断，必须分别从样例中归纳。
</new_puzzle>

<new_puzzle>
从多米诺骨牌信号塔沿排列方向发射颜色射线，射线在遇到 2x2 棱镜方块时发生 90 度偏转并变为棱镜的第二种颜色后继续传播。

Input structure：
- 背景为最常见颜色。
- 网格中有若干个"信号塔"：每个信号塔是一个两像素的同色多米诺骨牌（水平排列或垂直排列）。
- 网格中还有若干个"棱镜"对象：每个棱镜是一个 2x2 的实心正方形，由两种颜色构成——其中一条对角线上的两个像素为一种颜色（棱镜入射色），另一条对角线上的两个像素为另一种颜色（棱镜出射色）。
- 信号塔和棱镜之间不接触，互相不重叠。

Rule：
- 从每个水平多米诺的左端向左和右端向右各发射一条射线；从每个垂直多米诺的上端向上和下端向下各发射一条射线。射线颜色为信号塔的颜色。
- 射线沿行或列逐像素前进，将经过的背景像素染为射线当前颜色。
- 当射线到达某个棱镜 2x2 方块的边缘时，射线停止，不染棱镜像素。然后从棱镜的与射线入射方向垂直的一侧（顺时针旋转 90 度的方向）发出一条新射线，新射线颜色为棱镜的出射色。
- 新射线继续沿直线传播，直到遇到网格边界、另一个棱镜、或另一个信号塔为止。
- 若两条射线经过同一像素，后处理的射线覆盖先处理的（按信号塔从左到右、从上到下的顺序处理）。
- 信号塔和棱镜的原始像素保持不变。

Key insight：
多米诺骨牌的方向编码了射线的发射轴线，2x2 棱镜同时编码了"在哪里转弯"和"转弯后变成什么颜色"。解题者需要先发现射线的传播方向由多米诺朝向决定，再发现棱镜的偏转与变色双重功能，两层机制叠加才能推导完整输出。
</new_puzzle>

<new_puzzle>
在表格化分区网格中，根据边界线上的否决标记剔除被否决颜色的投票像素后，用各区域内多数颜色填充该区域。

Input structure：
- 背景为最常见颜色。
- 网格被 Grey 色的单像素厚直线分成若干矩形区域（类似表格），Grey 线条构成完整的行列分隔网格。
- 每个矩形区域内散布着若干彩色像素（投票像素），颜色可能为 Red、Blue、Green、Yellow 等，其余为背景色。每个区域内至少有 3 个投票像素。
- 在某些 Grey 分隔线段上，存在一个非 Grey、非背景色的单像素标记（"否决标记"），位于两个相邻区域之间的边界线上。

Rule：
- 第一步（否决剔除）：对于每个否决标记，找到它所在边界线两侧的两个相邻区域。在计票时，忽略这两个区域中所有与否决标记同色的投票像素（像素本身视觉上仍保留不变，只是不参与计数）。
- 第二步（多数投票）：在每个区域内，统计剔除后剩余投票像素中每种颜色的数量，找到数量最多的颜色作为该区域的填充色。若存在数量平局，选择在该区域中出现位置最靠上的像素所属颜色；若行号也相同，选最靠左的。
- 第三步（区域填充）：将每个区域内的所有背景像素填充为该区域的多数颜色。原有投票像素、Grey 线条和否决标记均保持不变。

Key insight：
直觉上看到区域内散布的彩色点会想到"多数决"填充规则，但边界线上不起眼的否决标记会跨区域地使某种颜色的票数无效化。解题者需要先发现边界标记的"远程颜色否决"机制，才能正确执行投票计数，形成真正的两层推理。
</new_puzzle>

<new_puzzle>
根据每个封闭区域内"指针"像素所指方向，从该区域的边界沿指针方向向外搜索，找到最近的同色区域，然后将两个区域都重新着色为指针的颜色。

Input structure：
- 背景为最常见颜色。
- 网格中有若干个由不同颜色构成的封闭四连通单色区域（色块），形状不规则但各自四连通，区域之间被背景色隔开（至少一像素间距）。
- 每个色块内部恰好有一个不同于色块颜色和背景色的单像素"指针"。指针像素在色块中的位置偏向色块的某一侧（上/下/左/右），即指针像素到色块包围盒某一条边的距离最小，该最近边的方向就是指针所指方向。若到两条边距离相同，优先选择水平方向（左或右）。
- 每种色块颜色在网格中恰好出现两次（即有两个同色色块形成一对）。

Rule：
- 第一步（指针方向判定）：对每个色块，找到其内部指针像素距离色块包围盒最近的那条边，该边的朝外法线方向即为指针方向。
- 第二步（配对验证）：从色块沿指针方向向外搜索（沿指针像素所在的行或列延伸），检查该方向上是否存在与当前色块同色的配对色块。若存在，则这两个色块构成一个配对。
- 第三步（重着色）：将配对的两个色块（包括其所有像素）全部重新着色为指针的颜色。两个配对色块中指针颜色应相同。指针像素本身也变为指针颜色（即指针像素与色块融为一体）。
- 不满足配对条件的色块保持不变。背景保持不变。

Key insight：
解题者需要先通过指针在色块中的偏心位置推断"方向"，再沿该方向搜索发现同色配对机制，最后理解指针颜色是重着色的目标色。三层信息（方向→配对→着色）分别嵌入在指针的位置、色块的颜色和指针的颜色中。
</new_puzzle>
