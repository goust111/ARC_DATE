<description>
根据内部标记像素的排列方向选择镜像轴，再用框架颜色的缺口位置决定镜像后的偏移方向。

Input structure：
- 背景为黑色（black）。
- 网格中散布若干互不相连的矩形框架对象，每个框架由单色一像素厚的边框构成，内部填充背景色。
- 每个框架的边框上恰好有一个缺口（一个像素的断开），缺口位于四条边之一。
- 每个框架内部包含若干同色标记像素（与边框颜色不同），这些标记像素排成一条直线段，方向为水平或垂直。

Rule：
- 第一步：判断每个框架内部标记像素排列的方向。若标记像素排列为水平方向，则该对象的镜像轴为垂直轴（左右翻转）；若标记像素排列为垂直方向，则镜像轴为水平轴（上下翻转）。
- 第二步：对整个框架（含内部标记）执行上述翻转操作，得到翻转后的副本。
- 第三步：判断缺口所在的边。将翻转后的副本沿缺口方向平移，使副本紧贴原始框架的缺口侧外部（副本与原始框架之间无间隙，缺口与副本对应边对齐）。
- 原始框架保留不动，输出中同时包含原始框架和平移后的翻转副本。背景保持黑色。

Key insight：
标记像素的排列方向决定镜像方式（水平排列→左右翻转，垂直排列→上下翻转），而框架边框上的缺口位置决定翻转副本的放置方向——两层信息编码在不同的视觉特征中，需要分别归纳。
</description>

将分散的彩色碎片按形状互补性配对拼合，再按拼合后矩形的面积从小到大排列输出。

Input structure：
- 背景为黑色（black）。
- 网格中散布若干互不相连的单色4-连通对象，每个对象的颜色各不相同。
- 这些对象可以两两配对：同一对中的两个对象形状互补——即把其中一个对象旋转0/90/180/270度后，两者可以无重叠地拼合成一个实心矩形（无孔洞）。
- 每一对中两个对象的颜色不同，但配对关系是唯一的（每个对象只属于一对）。

Rule：
- 第一步：识别哪些对象可以互补拼合成矩形。对每两个对象，尝试将其中一个旋转（0/90/180/270度），看能否与另一个拼合形成完整矩形。找到所有唯一配对。
- 第二步：对每一对，确定拼合所需的旋转角度和相对位移，生成拼合后的矩形。拼合后的矩形中，每个像素保留其来源对象的原始颜色（即矩形由两种颜色组成）。
- 第三步：按拼合后矩形的面积从小到大排列（面积相同则按矩形宽度从小到大），每两个矩形之间用一列背景色分隔，所有矩形顶部对齐于第0行，从左到右排列。

Key insight：
配对的线索不是颜色而是形状互补——需要先发现"两个碎片能拼成矩形"这一空间关系，再发现输出中的排序依据是拼合后的面积，两层规律都需要从样例中独立归纳。
</description>

用色条图例解码网格中的多层叠印顺序，按叠印顺序重建无遮挡的完整对象并排列输出。

Input structure：
- 背景为黑色（black）。
- 网格分为上下两个区域，由一行灰色（grey）分隔行隔开。
- 上方区域是图例区：包含一行从左到右排列的单色小方块（每个方块为3x3纯色），方块之间有一列背景间隔。方块的颜色从左到右定义了叠印优先级：最左侧优先级最低（最底层），最右侧优先级最高（最顶层）。
- 下方区域是画布区：包含若干重叠的单色矩形对象。每个矩形都是实心的，颜色对应图例中的某个方块颜色。矩形之间存在重叠，重叠处显示优先级更高的颜色（即更靠右的图例颜色覆盖更靠左的）。

Rule：
- 第一步：从图例区的色块左右顺序读取叠印优先级。
- 第二步：在画布区中，根据重叠规则和可见像素，推断每个颜色对应的完整矩形边界。对于被遮挡的矩形，其被遮挡的部分可通过可见边缘的行列范围推断出完整的包围盒（每个对象都是完整的实心矩形）。
- 第三步：将每个颜色的完整矩形（无遮挡版本）按图例的从左到右顺序，从左到右排列输出。每两个矩形之间用一列背景色分隔，所有矩形顶部对齐。图例区和分隔行不出现在输出中。

Key insight：
图例色块的顺序编码了遮挡层级——左侧色块对应的对象在最底层，被其他对象覆盖最多。需要先理解图例定义的是叠印顺序而非简单的颜色映射，再利用可见边缘反推被遮挡矩形的完整尺寸，最后按图例顺序排列输出。

根据种子像素在封闭区域内的数量选择填充图案，再根据区域的形状对称性决定图案的朝向。

Input structure：
- 背景为黑色（black）。
- 网格中有若干由蓝色（blue）一像素厚线条围成的封闭区域（区域内部为背景色或含有种子像素）。蓝色线条形成的边界彼此不连通，构成独立的封闭多边形。
- 每个封闭区域内部散布若干红色（red）种子像素。
- 网格右侧或底部有一个图案图例区，由灰色（grey）边框包围。图例区内从上到下排列若干小图案模板，每个模板之间用一行灰色分隔。模板按从上到下的顺序编号为1、2、3……每个模板是一个用绿色（green）像素在黑色背景上绘制的小型图案。

Rule：
- 第一步：数出每个封闭区域内红色种子像素的数量 N（N 不超过图例中模板的总数）。选择图例中第 N 个模板作为该区域的填充图案。
- 第二步：判断每个封闭区域的形状对称性——若区域关于垂直轴对称，则图案保持原样（不旋转）；若区域关于水平轴对称但不关于垂直轴对称，则图案顺时针旋转90度；若区域既不关于水平也不关于垂直轴对称，则图案旋转180度。
- 第三步：将选定的图案（经过旋转处理后）以平铺方式填入封闭区域内部（仅覆盖背景色像素，红色种子像素被图案替换）。平铺从区域包围盒的左上角开始，图案在水平和垂直方向重复，超出区域边界的部分被裁剪。
- 蓝色边界线和图例区在输出中保留不变。

Key insight：
种子像素的数量选择"用哪个图案"，而封闭区域自身的几何对称性决定"图案以何种朝向铺设"——两个决策依据分别编码在区域内部的离散标记和区域边界的整体形态中，需要独立发现这两层规律。

Input structure：
- 背景为黑色（black）。
- 网格中有一个由灰色（grey）像素构成的一像素厚墙壁形成的迷宫结构。迷宫内部的通道宽度恰好为一个像素。
- 迷宫中有若干"房间"——即由灰色墙壁围成的大于1x1的矩形空腔（内部全为背景色）。
- 恰好有一个房间内包含一个彩色像素作为起点标记（颜色非灰色非黑色）。
- 迷宫外部（网格边缘区域）有一行或一列从左到右（或从上到下）排列的彩色像素序列，每个像素颜色不同，作为路径指令序列。

Rule：
- 第一步：从起点标记所在房间出发。该房间与若干通道相连（通道是墙壁上的一像素宽开口）。
- 第二步：读取路径指令序列的第一个颜色 C1。从起点房间的所有出口通道中选择一条进入。沿通道行走，通道中的每一个交叉口（即该像素的四邻域中有超过两个非墙壁像素）需要选择转向方向：若交叉口呈T字形（三个方向可走），选择右转（相对于进入方向）；若交叉口呈十字形（四个方向可走），选择直行。沿此规则行走直到抵达下一个房间。用颜色 C1 填充这个房间的内部。
- 第三步：继续读取路径指令的下一个颜色 C2，从刚填充的房间出发，重复上述行走与转向规则，抵达下一个房间并用 C2 填充。
- 依此类推，直到路径指令序列用完为止。起点房间用起点标记的颜色填充。迷宫墙壁和通道保持不变。

Key insight：
路径指令序列决定每一步的填充颜色和步数，但选择哪条路径取决于交叉口的局部几何形态（T字形右转、十字形直行）——需要先归纳出颜色序列与房间填充的对应关系，再归纳出交叉口形态决定转向的规则，两者缺一不可。

提取每个带框对象的内部图案，根据框架颜色在颜色环上的相邻关系确定拼接顺序，再根据框架缺失边的方位确定拼接方向。

Input structure：
- 背景为黑色（black）。
- 网格中散布若干互不相连的带框矩形对象。每个对象由一个单色一像素厚的矩形框架和框架内部的多色图案组成。
- 每个框架的四条边中恰好有一条边完全缺失（即该侧无边框像素），形成一个"开口"矩形（类似U形或C形）。
- 网格中还有一个独立的"颜色环"图例：由若干不同颜色的像素首尾相连排成一个封闭环形（环的每个像素颜色不同，且这些颜色恰好对应所有框架的颜色）。

Rule：
- 第一步：读取颜色环图例，确定框架颜色的环形顺序（顺时针方向读取）。
- 第二步：按颜色环的顺序排列所有带框对象。相邻两个对象（在颜色环上相邻的框架颜色）需要拼接在一起。
- 第三步：确定拼接方向——每个对象的开口方向（缺失边的方位：上/下/左/右）指示该对象需要与下一个对象拼接的方向。将下一个对象的内部图案（不含框架）放置在当前对象开口方向的外侧，紧贴开口边缘。
- 第四步：输出为所有内部图案按上述规则依次拼接后的组合图形。第一个对象保留其完整的三面框架，后续对象只保留内部图案。框架颜色环图例不出现在输出中。

Key insight：
颜色环编码了拼接顺序——需要从环形图例中归纳出框架颜色之间的前后关系；而每个框架的开口方向编码了拼接的空间方位——两层信息分别来自全局图例和局部框架形态，必须同时正确解读才能完成拼合。

将网格中的箭头对象作为投影指令，沿箭头方向将源色带投影到目标区域，投影长度由箭头自身的长度决定。

Input structure：
- 背景为黑色（black）。
- 网格中包含若干"色带"——每个色带是一条水平或垂直的单色线段（长度>=2），颜色各不相同。

- 箭头方向与其相邻色带的延伸方向垂直。

Rule：
- 第一步：识别每个箭头以及它所邻接的色带。

Key insight：
箭头既编码了投影方向（通过箭头尖朝向），又编码了投影距离（通过箭头直线段的长度L）——需要同时从箭头形态中提取这两项信息。色带与箭头的邻接关系确定了"谁被投影"，箭头的几何属性确定了"往哪投影多远"。

<description>
识别每个封闭区域中"指针"像素所指示的相邻区域，建立区域间的有向传递链，沿链传播颜色直到终端区域。

Input structure：
- 背景为黑色（black）。
- 网格中由蓝色（blue）一像素厚线条分割成若干不规则的封闭区域。每个区域的内部或为纯背景色，或包含以下元素之一：
  - 一个单色填充（非蓝色非黑色），表示该区域是"源区域"。
  - 一个"指针"像素：一个孤立的红色（red）像素，位于区域内部且4-连通邻接蓝色边界的某一侧。指针像素靠近哪一侧边界，就指向边界另一侧的相邻区域。
  - 空白（纯背景），表示该区域是"终端区域"。
- 每个非空非源区域恰好有一个指针像素。源区域无指针。

Rule：
- 第一步：识别所有源区域及其填充颜色。
- 第二步：从每个源区域出发，找到与该源区域共享蓝色边界且其指针指向本源区域方向的相邻区域——但这不是传播方向。传播方向是：从源区域开始，查看每个与源区域相邻的区域，如果该区域的指针指向远离源区域的方向（即指向该区域的另一侧边界），则颜色沿指针方向传播到指针所指的下一个区域。
- 简化规则：每个有指针的区域，指针指向其某个相邻区域。从源区域开始，颜色传入一个有指针的区域后，沿指针方向继续传递到指针所指的下一个区域，直到到达终端区域（空白区域）为止。
- 第三步：将传播链上经过的所有区域（包括终端区域，不包括源区域）都填充为源区域的颜色。源区域保持原样，蓝色边界保持不变，指针像素被填充色覆盖。

Key insight：
每个区域内指针像素的位置编码了一个方向信息——它靠近哪面墙就指向墙另一侧，从而构成区域间的有向传递链。需要先理解指针像素的位置语义（靠近哪面边界=指向对面），再沿链路追踪颜色传播路径，两层推理环环相扣。
</description>
