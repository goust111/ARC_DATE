- `description`：将网格中散落的彩色箭头按其指向方向发射射线，射线在遇到其他箭头时被该箭头"捕获"并改变颜色为捕获者的颜色，最终每个箭头周围形成属于自己颜色的射线领地。

- `Input structure`：

- `Rule`：
  - 从每个箭头的头部像素出发，沿箭头指向的方向（上、下、左、右之一）逐格绘制该箭头颜色的射线像素。

  - 所有箭头同时发射，射线之间互不阻挡（仅箭头实体阻挡射线）。
  - 箭头本身保持原色不变。

- `Key insight`：解题者需要先识别出 3 像素 L 形结构的朝向来确定射线发射方向（这是第一层非显然推理），然后理解射线末端变色的"捕获"机制（第二层推理）。箭头的形状编码了方向信息，而非仅仅是位置标记。

- `Input structure`：
  - 背景为 black。
  - 网格中间有一条完整的水平 grey 分隔线，将网格分为上下两个等高区域。
  - 上半区域（指令区）包含若干条由不同颜色构成的水平或垂直线段，每条线段长度至少为 3 像素且颜色互不相同。每条线段要么是完全水平的，要么是完全垂直的。
  - 下半区域（操作区）包含若干个彩色对象，每个对象的颜色与指令区某条线段的颜色相同，形成配对关系。

- `Rule`：
  - 对指令区中的每条线段，确定其方向和在指令区中的位置坐标。将该位置映射到下半区域的对应位置（即行坐标相对于分隔线做镜像映射），得到一条虚拟折叠轴。
  - 对每个下半区域的彩色对象，找到与其颜色配对的折叠轴。
  - 将该对象沿其配对的折叠轴做镜像翻转：如果轴是水平的，则上下翻转；如果轴是垂直的，则左右翻转。
  - 翻转后的像素覆盖到网格上；原始位置的像素保留。如果翻转像素与原始像素重叠，保持该颜色不变。
  - grey 分隔线在输出中移除，输出仅包含下半区域（高度减半）。

- `Key insight`：解题者需要三层推理：第一层，识别上下分区结构和颜色配对关系；第二层，理解上半区线段的方向和位置需要映射到下半区成为折叠轴——这不是简单的复制，而是坐标变换；第三层，对象沿轴镜像后与原始形态叠加，需要理解水平轴和垂直轴分别对应不同的翻转方向。

- `Key insight`：解题者需要两层非平凡推理：第一层是发现缺口方向与边界标记的对应关系（缺口朝向哪个方向，就去哪条边界找锚点）——这一映射规则需要从多个样例中归纳；第二层是理解同组内多个不同大小的环要嵌套成同心结构而非简单堆放，且缺口方向在嵌套后保持一致。

- `description`：网格中的彩色路径在交叉点处按"上下层"关系交织，需要识别每条路径的完整走向，然后将处于最上层的路径保留原色，被遮挡的路径段改为 grey。

- `Input structure`：
  - 背景为 black。
  - 网格中有若干条单像素宽的彩色路径（每条路径一种颜色，颜色互不相同），路径沿水平或垂直方向延伸并可能转弯（仅 90 度直角转弯）。
  - 某些路径在交叉点处共享同一个像素位置。在输入中，交叉像素显示的是"上层"路径的颜色。
  - 每条路径的两个端点处各有一个相同颜色的 2×2 方块作为端点标记。

- `Rule`：
  - 通过端点标记（2×2 方块）识别每条路径的颜色和起止位置。
  - 追踪每条路径从一个端点到另一个端点的完整走向（路径在交叉点处直行穿过，不转弯）。
  - 在交叉点处，输入中显示的颜色即为上层路径。被遮挡的路径段（交叉点像素处非该路径颜色）记录为下层。
  - 输出中：上层路径保持原色；下层路径在交叉点前后各一个像素的范围内（即交叉点本身加上交叉点两侧各 1 个像素，共 3 个像素）被改为 grey，表示"穿入桥下"的视觉效果。
  - 端点标记和非交叉区域的路径像素保持原色不变。

- `Key insight`：解题者需要先通过端点标记确定每条路径的归属和走向（第一层推理），然后在交叉点处判断哪条路径在上、哪条在下（第二层推理——上层路径就是交叉点显示的颜色），最后理解下层路径不仅在交叉点变 grey，还要向两侧各延伸 1 像素形成"穿桥"效果（第三层推理）。

- `Input structure`：
  - 背景为 black。
  - 网格中排列着若干个大小相同的矩形瓷砖（如 4×4），瓷砖之间由 1 像素宽的背景色间隔分隔，形成规则的网格布局。
  - 每块瓷砖内部由恰好两种颜色构成，且被一条对角线（从左上到右下或从右上到左下）分为两个三角形区域，每个三角形填充一种颜色。
  - 大多数瓷砖的对角线方向相同（例如都是左上到右下），但恰好有一块瓷砖的对角线方向相反（右上到左下）。

- `Rule`：
  - 识别所有瓷砖的对角线分割方向。
  - 找到唯一一块对角线方向与多数瓷砖不同的"异类"瓷砖。

  - 其他所有瓷砖和背景保持不变。

- `Key insight`：解题者需要先在视觉上区分"对角线方向"这个微妙属性（第一层推理——所有瓷砖形状和大小相同，差异仅在于对角线方向，容易被颜色差异干扰），然后理解异类瓷砖的修正方式是 180 度旋转而非简单的颜色交换（第二层推理），最后注意高亮边框是画在瓷砖外部的间隔像素上而非瓷砖内部（细节层）。

<new_puzzle>
- `description`：网格左侧的"种子列"中每个彩色像素向右生长出一条水平枝干，枝干的长度由该像素所在行中右侧最近的同色像素的距离决定；枝干末端向上和向下各生长出一个与枝干等长的垂直分支，形成 T 形树结构。

- `Input structure`：
  - 背景为 black。
  - 网格最左列（第 0 列）包含若干个不同颜色的单像素"种子"，其余位置为背景色。种子之间不相邻。
  - 网格中其他位置散布着若干个彩色单像素"距离标记"，每个距离标记的颜色与某个种子相同，且与该种子位于同一行。每个种子在同一行中恰好有一个对应的距离标记。

- `Rule`：
  - 对最左列的每个种子像素（颜色 C，位于第 r 行第 0 列），在第 r 行中找到同色的距离标记（位于第 r 行第 d 列）。
  - 从种子位置向右绘制一条长度为 d 的水平枝干（即从第 0 列到第 d-1 列的第 r 行全部填充为颜色 C）。距离标记本身（第 d 列）不包含在枝干中，在输出中被移除。
  - 在枝干的末端像素（第 r 行第 d-1 列）处，向上和向下各绘制一条长度为 d 的垂直分支（即从第 r-1 行到第 r-d 行，以及从第 r+1 行到第 r+d 行，均在第 d-1 列上填充为颜色 C）。如果分支超出网格边界，则在边界处截断。
  - 不同颜色的 T 形树结构之间不会重叠（题目保证）。

- `Key insight`：解题者需要先发现"距离标记"的作用——它不是输出的一部分，而是编码了生长长度的控制信号（第一层推理：标记的列位置就是长度参数）；然后理解同一个长度参数同时控制水平枝干和垂直分支的长度，形成对称的 T 形结构（第二层推理：一个参数复用于两个维度）。
</new_puzzle>
