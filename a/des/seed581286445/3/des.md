- `description`：根据封闭区域内部标记像素的颜色，在该区域对应的边框缺口方向上向外生长出与标记数量等长的射线，射线颜色由边框颜色与调色板的配对规则决定。

- `Input structure`：
  - 背景为 Black。
  - 网格中有若干个由单一颜色（如 Blue、Green、Red 等）绘制的矩形边框，每个边框恰好有一个单像素宽的缺口位于某一侧边的中间位置。
  - 每个边框内部的封闭区域包含若干个散布的标记像素，这些标记像素都是同一种颜色（与边框颜色不同）。
  - 网格边缘另有一个 2 行 N 列的调色板区域：第一行列出若干边框颜色，第二行列出对应的射线颜色，形成边框颜色到射线颜色的映射表。

- `Rule`：
  - 对每个矩形边框，首先找到其唯一的缺口所在的方向（上、下、左、右）。
  - 数出该边框内部标记像素的个数 N。
  - 从缺口位置出发，沿缺口朝外的方向画一条长度为 N 的射线。
  - 射线的颜色通过调色板查找：以该边框的颜色在调色板第一行中找到对应列，取第二行同列的颜色作为射线颜色。
  - 其余所有像素保持不变。

- `Key insight`：
  - 解题需要三层独立推理：第一层是识别调色板并建立边框颜色到射线颜色的映射；第二层是发现缺口方向决定射线的生长方向；第三层是内部标记像素的数量决定射线长度。三者缺一不可，且每一层都需要从样例中归纳得出。
</new_puzzle>

- `description`：将网格中每个彩色 L 形对象旋转后嵌入与其配对的灰色 L 形凹槽中，配对依据是凹槽内隐藏的单像素颜色标记。

- `Input structure`：
  - 背景为 Black。
  - 网格中散布着若干个由 Grey 像素构成的 L 形凹槽。每个凹槽是在一个 3x3 的区域中，用 Grey 像素填充除了某个 2x1 角落之外的所有边缘像素，从而形成一个 L 形的内部空腔（空腔由 3 个背景色像素组成 L 形）。空腔中恰好有一个像素被涂成了某种非黑非灰的颜色（如 Red、Blue 等），作为隐藏标记。
  - 网格中另有若干个独立的彩色 L 形对象（由 3 个像素组成的 L 形），每个对象的颜色各不相同，且恰好与某个凹槽内部隐藏标记的颜色一致。
  - 彩色 L 形对象的朝向可能与对应凹槽的空腔形状不同，需要旋转 0/90/180/270 度才能恰好填入。

- `Rule`：
  - 通过颜色匹配将每个彩色 L 形对象与包含同色隐藏标记的灰色凹槽配对。
  - 将彩色 L 形对象从原位置擦除（恢复为背景色）。
  - 将该彩色 L 形旋转至能完美填入配对凹槽空腔的朝向。
  - 将旋转后的彩色 L 形绘制到凹槽空腔内，覆盖原来的背景像素和隐藏标记像素。
  - 灰色凹槽边框保持不变。

- `Key insight`：
  - 第一层推理：识别灰色凹槽内部的单像素彩色标记并理解其为配对钥匙，而非装饰。第二层推理：发现彩色 L 形需要旋转才能匹配凹槽空腔的朝向，旋转角度由凹槽的几何形状唯一确定。标记像素本身在填入后被覆盖消失，是纯粹的控制信号。
</new_puzzle>

- `description`：每个带颜色边框的封闭房间内有若干散点，将散点沿边框上唯一开口的方向"倒出"，在房间外形成等长的线段，同时房间内的散点被清除。

- `Input structure`：
  - 背景为 Black。
  - 网格中有若干个由不同前景色绘制的矩形边框（每个边框一种颜色，如 Red、Blue、Green）。每个边框在其某一侧恰好有一个宽度为 1 像素的开口。
  - 每个边框内部散布着若干个 Orange 像素（散点），位置随机但都在边框围成的区域内。
  - 各边框之间互不重叠，且边框外侧在开口方向上有足够的空间。

- `Rule`：
  - 对每个边框，找到其开口所在的边及开口在该边上的位置（对应的行或列）。
  - 统计该边框内部 Orange 散点的总数 N。
  - 将边框内所有 Orange 散点擦除为背景色。
  - 从开口位置出发，沿开口朝外的方向，以开口所在的列（若开口在上或下边）或行（若开口在左或右边）为位置，绘制一条长度为 N 的连续 Orange 像素线段。线段从紧邻开口外侧的第一个像素开始，逐像素向外延伸。
  - 边框本身保持不变。

- `Key insight`：
  - 解题者需要同时归纳两个独立规律：开口方向决定散点"倾倒"的方向，而散点数量决定外部线段的长度。边框颜色是干扰项——它不参与任何规则运算，仅用于视觉区分不同房间。关键在于发现散点并非按原始空间位置映射到外部，而是被"计数化"为一条等长线段。
</new_puzzle>

- `description`：在分隔线划分的多个面板中，每个面板包含一个彩色图案和一个指示箭头；将每个面板的图案按箭头指向投射到相邻面板中，投射后的图案颜色取自源面板的底色。

- `Input structure`：
  - 背景为 Black。
  - 由 Grey 像素组成的单像素宽的完整水平线和竖直线将网格分割成 2x2（共 4 个）矩形面板。
  - 每个面板内有以下元素：一种独特的底色（如 Blue、Red、Green、Yellow，每个面板不同），填满面板作为面板自身的背景；一个由另一种颜色绘制的小型图案（4-连通的前景像素块，如 T 形、十字形等，占据 3-6 个像素）；一个由 Maroon 像素绘制的箭头。箭头由一条 3 像素长的水平或竖直直线段加上末端两侧各一个斜向像素组成（共 5 像素），箭头头部指向上、下、左、右四个方向之一。
  - 每个箭头始终指向一个通过分隔线与当前面板相邻的面板。

- `Rule`：
  - 对每个面板，读取其箭头朝向，确定目标面板（箭头指向的那侧相邻面板）。
  - 将当前面板中图案的形状掩码（仅记录图案像素的相对位置）复制到目标面板中相同的相对位置。
  - 复制时使用当前面板（源面板）的底色来绘制这些图案像素。
  - 若目标面板中同一位置已有该面板自身的原始图案像素，则投射的像素不覆盖该图案像素（原始图案优先）。
  - 擦除所有面板中的 Maroon 箭头像素（恢复为该面板的底色）。
  - 每个面板自身的原始图案保持不变。

- `Key insight`：
  - 第一层推理：识别 Maroon 箭头的方向编码及其与面板邻接关系的对应——箭头是传输指令而非移动指令，图案不是被移走而是被复制到相邻面板。第二层推理：发现投射到目标面板的颜色既不是图案自身的颜色也不是目标面板的底色，而是源面板的底色，这一反直觉的颜色选择规则需要通过比对多个样例才能确认。
</new_puzzle>

- `description`：网格中有若干对同色矩形，每对之间存在一个黄色标记像素指定镜像轴；将较小矩形关于该轴镜像折叠到较大矩形上，重叠区域变为 Grey。

- `Input structure`：
  - 背景为 Black。
  - 网格中有若干对实心矩形，每对矩形颜色相同（如一对 Red、一对 Blue、一对 Green）。每对中一个矩形面积严格大于另一个。
  - 每对矩形在水平或竖直方向上排列——即它们的中心在同一行或同一列上大致对齐。
  - 在每对矩形之间的空白区域中，存在恰好一个 Yellow 像素。若两矩形左右排列，则该 Yellow 像素所在的列即为竖直镜像轴线；若两矩形上下排列，则该 Yellow 像素所在的行即为水平镜像轴线。

- `Rule`：
  - 对每对同色矩形，找到它们之间的 Yellow 标记像素，确定镜像轴线（竖直或水平）。
  - 将较小矩形关于该轴线做镜像翻转，得到翻转后的新位置坐标。
  - 擦除原始较小矩形（恢复为背景色）。
  - 擦除 Yellow 标记像素（恢复为背景色）。
  - 在翻转后的位置上绘制像素：若该位置原本属于较大矩形（发生重叠），则将该像素改为 Grey；若该位置原本为背景色，则绘制为该对矩形的原始颜色。
  - 较大矩形中未被重叠覆盖的部分保持原色不变。

- `Key insight`：
  - 第一层推理：发现 Yellow 标记不是装饰而是镜像轴线的定位锚点，且轴线方向由矩形对的排列方向自动确定。第二层推理：镜像操作的对象始终是较小矩形（而非较大的），且目的是将小矩形"折叠"向大矩形所在侧。第三层推理：重叠区域的颜色变化规则——重叠处统一变为 Grey 而非简单覆盖或混合——需要从样例中独立归纳。
</new_puzzle>

<new_puzzle>
- `description`：网格中每个同心环结构编码了"生长指令"，中心种子图案按照环的层数逐层向外膨胀，每层膨胀使用从内到外对应层环的颜色。

- `Input structure`：
  - 背景为 Black。
  - 网格中有若干个独立的同心环形结构，每个结构由 2-3 层不同颜色的单像素宽矩形环嵌套而成（从外到内颜色不同，例如最外层 Blue、中间层 Red、最内层 Green）。
  - 每个同心环结构的最内层环围成的中心空心区域包含一个由 Orange 像素绘制的小型种子图案（如单个像素、2 像素直线、L 形等，占据 1-3 个像素）。

- `Rule`：
  - 对每个同心环结构，从内到外识别各层环的颜色序列 C1（最内层）, C2, ..., CN（最外层），N 为环的总层数。
  - 读取中心区域的 Orange 种子图案的形状。
  - 擦除整个同心环结构（所有环层像素恢复为背景色），仅保留种子图案。
  - 以种子图案为起点，执行 N 次 4-连通膨胀操作：第 k 次膨胀将当前图形的所有外边界（即 4-连通邻居中至少有一个背景像素的前景像素）的每个背景邻居像素涂上颜色 Ck。
  - 种子图案本身保持 Orange 颜色不变。

- `Key insight`：
  - 第一层推理：环结构不是输出的一部分，而是"指令编码器"——环的层数决定膨胀执行的次数，每层环的颜色按从内到外的顺序依次指定每次膨胀新增像素的颜色。第二层推理：膨胀的基础形状取决于中心种子图案的具体几何形态，不同的种子会产生截然不同的输出轮廓，因此环的方形几何形态本身是无关的干扰信息。
</new_puzzle>

- `description`：网格左半部分的彩色矩形框各有一个缺口，右半部分的同色小方块是修补信号；识别配对后用边框颜色填补缺口，小方块被擦除，但缺口的形状由边框自身决定而非由小方块形状决定。

- `Input structure`：
  - 背景为 Black。
  - 一条竖直的 Grey 像素分隔线将网格分为左右两半。
  - 左半部分包含若干个由不同颜色绘制的单像素宽矩形边框（如 Red 框、Blue 框、Green 框），每个边框在其某一条边上有一个由 2-4 个连续像素组成的缺口（该段边框像素被移除为背景色），缺口可出现在矩形四条边中的任意一条上。
  - 右半部分包含若干个实心的彩色小方块（大小为 1x1 或 1x2 或 2x1），每个小方块的颜色与左侧某个矩形边框的颜色相同。每种颜色在左侧恰好出现一个边框，在右侧恰好出现一个小方块。

- `Rule`：
  - 通过颜色将右侧的小方块与左侧的矩形边框一一配对。
  - 将右侧所有小方块擦除（恢复为背景色）。
  - 对每个左侧矩形边框，找到其缺口的位置和形状（缺口由哪些像素位置构成）。
  - 用该边框的颜色填充缺口中所有缺失的像素，使矩形边框恢复为完整的封闭矩形。
  - 分隔线和边框内部区域保持不变。

- `Key insight`：
  - 第一层推理：右侧小方块通过颜色与左侧边框建立配对，小方块的存在是"激活修补"的信号。第二层推理：小方块的尺寸和形状是干扰信息——修补的形状完全由边框自身缺口的几何形状决定，与小方块无关。解题者必须克服"小方块是拼图块"的直觉假设，意识到小方块仅仅是配对触发器。
</new_puzzle>
