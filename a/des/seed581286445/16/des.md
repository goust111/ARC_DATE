<new_puzzle>
将网格中散落的彩色"钥匙"形状嵌入对应颜色边框的"锁孔"中，嵌入前需将钥匙旋转至与锁孔缺口朝向一致。

Input structure：
- 背景为 Black。网格中散布若干中空矩形框（"锁"），每个锁的边框颜色不同（如 Red、Blue、Green 等）。
- 每个锁的边框在某一侧（上/下/左/右）有一个连续缺口（宽度≥2 像素），缺口处边框像素缺失，露出背景色。
- 锁的内部全为背景色。
- 网格中另有与锁数量相同的小型 4-连通单色填充对象（"钥匙"），每把钥匙的颜色与某个锁的边框颜色相同。
- 每把钥匙的形状恰好能以 0°/90°/180°/270° 中的某个旋转角度精确填入对应锁的缺口区域（缺口的宽度和深度与旋转后的钥匙外轮廓吻合）。

Rule：
- 对每个锁，找到与其边框颜色相同的钥匙。
- 确定锁的缺口朝向（缺口在边框的哪一侧）。
- 将钥匙旋转（0°/90°/180°/270°），使其形状恰好填满缺口区域：钥匙的长边与缺口的开口方向垂直对齐，短边深入锁内部的深度等于缺口深度。
- 将旋转后的钥匙平移到缺口位置绘制，补全锁的边框。
- 清除钥匙原始位置的像素，输出仅包含补全后的锁。

Key insight：
颜色匹配确定钥匙-锁配对，但缺口朝向决定旋转角度——解题者需先识别缺口方向，再从四种旋转中选出唯一能几何吻合的那个。
</new_puzzle>

<new_puzzle>
根据每个封闭区域内"种子"像素的颜色，从种子位置向外逐层扩展填充，不同区域的填充在共享门处竞争，先到者占据像素。

Input structure：
- 背景为 Azure。Grey 色的线段将网格分隔为若干不规则封闭区域。
- 每个封闭区域内恰好有一个非背景、非 Grey 的单像素"种子"（颜色各不相同，如 Red、Blue、Green、Yellow 等）。
- 部分区域之间的 Grey 墙壁上有单像素宽的"门"——即墙壁中断一个像素的位置，使相邻区域通过该门相通。

Rule：
- 从每个种子像素同时开始，逐层（4-连通邻域，每一轮所有种子各扩展一层）向外扩展，将背景像素染为该种子的颜色。
- Grey 墙壁像素不可被染色，也不可穿越（除非通过门）。
- 门可以被穿越：扩展波前到达门的一侧时，下一层可通过门进入相邻区域继续扩展。
- 若两个颜色的扩展在同一轮同时到达同一个背景像素，该像素保持背景色不被染色（竞争抵消）。
- 扩展持续直到所有可达的背景像素都被处理。输出为填充后的网格，Grey 墙壁保持不变。

Key insight：
门的存在使填充可以跨区域蔓延，解题者必须先识别墙壁中的门位置来判断区域连通性，再通过种子到门的相对距离推断哪个颜色会率先穿过门占领相邻区域——两层推理缺一不可。
</new_puzzle>

<new_puzzle>
网格中每个彩色对象是一个"印章"，其投影方向由同色箭头点指示；将每个印章沿箭头方向逐步复制，副本的颜色依序替换为调色板条中的下一个颜色。

Input structure：
- 背景为 Black。网格底部有一行"调色板条"：一排连续像素，从左到右各不相同的颜色（如 Red、Orange、Yellow、Green、Blue），它们定义了一个颜色序列。
- 网格其余区域有若干小型 4-连通单色填充对象（"印章"），每个印章的颜色是调色板条中的某个颜色。
- 每个印章旁边（4-邻域中某个方向上间隔 1 像素）有一个与印章同色的单像素"箭头点"，箭头点相对于印章整体重心的方向（上/下/左/右）指示投影方向。

Rule：
- 找到调色板条，记录其颜色序列 C0, C1, C2, …, Cn。
- 对每个印章，确定其颜色在调色板条中的位置 i，以及箭头点指示的方向 D。
- 从印章位置开始，沿方向 D 每隔（印章在 D 方向上的跨度 + 1）个像素绘制印章的副本，第一个副本颜色为 C(i+1)，第二个为 C(i+2)，依此类推，直到颜色序列用尽或副本超出网格边界。
- 原始印章和箭头点保留，调色板条保留。

Key insight：
调色板条既编码了颜色变换顺序又限定了副本数量；箭头点看似装饰实则编码方向——解题者需要先发现调色板条的作用（确定颜色迭代规则），再识别箭头点与方向的关系，两步归纳缺一不可。
</new_puzzle>

<new_puzzle>
网格中每行包含一组几乎左右对称的彩色像素序列；根据行内对称缺陷像素所在侧，将该行整体平移，并在输出中修复缺陷使之完美对称。

Input structure：
- 背景为 Black。网格中每一行独立包含一段连续的彩色像素序列（长度和颜色各行不同），其余位置为背景色。
- 每行的彩色序列几乎关于自身中心呈左右镜像对称，但恰好有一个像素位置破坏了对称性——该位置的颜色与其镜像位置的颜色不同（称为"缺陷像素"）。

Rule：
- 对每一行，找到其彩色序列的中心，识别唯一的对称缺陷像素及其所在侧（左半或右半）。
- 若缺陷在左半侧，将该行整体向左平移 1 格；若缺陷在右半侧，将该行整体向右平移 1 格。超出网格的像素裁剪，空出的位置填充背景色。
- 最终输出中，修复缺陷像素：将缺陷像素的颜色替换为其镜像位置的颜色，使该行变为完美对称。

Key insight：
解题者首先需要发现每行"几乎对称"的结构并定位唯一的缺陷像素（第一层推理），然后理解缺陷位置编码了平移方向（第二层推理），最后注意到缺陷本身在输出中被修复（第三层推理）——三层规则层层递进。
</new_puzzle>

<new_puzzle>
在网格中找到由不同颜色段拼成的环形路径，根据环上每段的长度决定其在输出中的径向膨胀厚度，将细环变为粗细不均的宽环。

Input structure：
- 背景为 Black。网格中有一个由多种颜色段首尾相连组成的单像素宽闭合环路（环路沿 4-连通路径行进，每段是一种颜色的连续像素序列，相邻段颜色不同）。
- 环路围成一个封闭的内部区域（内部全为背景色）。
- 环路外部也全为背景色。

Rule：
- 识别闭合环路，将其分解为若干连续同色段。
- 对每一段，数出该段包含的像素数 L。
- 在输出中，将该段的每个像素向环路内侧法线方向扩展 L 个像素（含原始像素本身），即该段的径向厚度变为 L 像素，颜色不变。
- 扩展后的像素若与其他段的扩展区域重叠，则保留先绘制的段的颜色（按环路顺序，从环路上 Red 段开始顺时针依次绘制，先绘制的段不被后续段覆盖）。
- 环路外侧不扩展。

Key insight：
解题者需先发现环由多色段拼成并正确分段（第一层），再发现每段长度等于其膨胀厚度（第二层），还需理解膨胀方向始终朝向环的内侧而非外侧（第三层）。段长度与几何厚度的对应关系是核心的非显然洞见。
</new_puzzle>

<new_puzzle>
网格中散布着若干对颜色相同的矩形对象；每对中较小的对象是"模板"，较大的对象是"画布"——将模板的内部图案平铺到画布中。

Input structure：
- 背景为 Azure。网格中有若干 4-连通单色填充矩形对象，颜色各不相同（如 Red、Green、Blue 等）。
- 每种颜色恰好出现两个矩形：一个较小（"模板"），一个较大（"画布"）。
- 画布的宽和高分别是模板的整数倍。
- 模板矩形内部某些像素被替换为其他颜色（非背景色、非该矩形自身颜色），形成一个小图案。

Rule：
- 对每种颜色，找到模板和画布（面积小的是模板）。
- 计算画布宽度 / 模板宽度 = Kw，画布高度 / 模板高度 = Kh。
- 将画布在内部划分为 Kw × Kh 个与模板同尺寸的子块（平铺）。
- 将模板的图案（包括被替换的像素位置及颜色）复制到画布的每个子块中——即画布中每个子块都呈现出与模板相同的内部图案。
- 模板对象从输出中移除。

Key insight：
配对依据是颜色匹配而非空间邻近，模板与画布的尺寸整数倍关系暗示了平铺操作——解题者需先通过颜色配对（第一层），再发现倍数关系决定平铺网格（第二层），最后将模板图案复制到每个子块中（第三层）。
</new_puzzle>

<new_puzzle>
网格中有若干"信号塔"（竖条）和"接收器"（横条），接收器上每个像素被染为水平方向上距它最近的信号塔的颜色；等距时使用边缘图例查找混合色。

Input structure：
- 背景为 Black。网格中有若干竖直的单像素宽彩色条（"信号塔"），每条高度≥3 像素，颜色各不相同。
- 网格中另有若干水平的单像素宽 Grey 条（"接收器"），每条宽度≥2 像素。
- 信号塔和接收器不相交。
- 网格边缘有一个小型"混合图例"：两个不同颜色的单像素上下相邻，旁边紧邻一个第三种颜色的单像素，表示"这两种颜色混合后得到该第三种颜色"。图例可能有多组。

Rule：
- 对每个接收器（Grey 横条）上的每个像素，计算它与每座信号塔之间的水平列数差（该像素的列号与塔所在列号之差的绝对值）。
- 找到距离该像素最近的塔，将该像素染为该塔的颜色。
- 若有两座塔与该像素等距，查找混合图例中这两种颜色对应的混合色，将该像素染为混合色。
- 信号塔本身保留不变，混合图例保留不变。

Key insight：
解题者需先理解"竖条=塔、横条=接收器"的角色分配（第一层），再发现着色规则是基于水平距离的最近塔原则（第二层），最后通过图例破解等距时的混合色映射（第三层）。混合图例是解开歧义情况的关键线索。
</new_puzzle>

<new_puzzle>
网格中有一个通道迷宫和一列彩色路标序列；路标颜色编码了在岔路口的相对转弯指令，输出为沿指令行走后的路径。

Input structure：
- 背景为 White。Grey 像素构成迷宫墙壁，墙壁之间形成单像素宽的通道网络。
- 迷宫的一个边缘通道口处有一个 Red 像素标记入口，另一个边缘通道口处有一个 Blue 像素标记出口。
- 在迷宫外部，沿网格的某一边缘排列着一行彩色像素序列（"路标序列"），使用 Green、Yellow、Orange、Maroon 四种颜色，每种颜色对应一个相对转弯方向（如 Green=直行、Yellow=左转、Orange=右转、Maroon=掉头），具体映射需从样例中归纳。

Rule：
- 从 Red 入口进入迷宫，初始朝向为从入口像素进入迷宫内部的唯一可行方向。
- 沿当前方向在通道中直行，直到到达一个岔路口（有两个或以上可选前进方向，不含来路）。
- 到达岔路口时，读取路标序列的下一个颜色，执行对应的转弯操作（左转/右转/直行/掉头是相对于当前朝向而言）。
- 继续前进到下一个岔路口，重复上述过程，直到到达 Blue 出口或路标序列用尽。
- 输出中，迷宫墙壁保持 Grey，走过的通道像素被染为 Magenta，未走过的通道保持 White，入口 Red 和出口 Blue 保留。

Key insight：
路标序列不编码绝对方向而是相对转弯指令——解题者需先从样例中归纳出颜色到转弯动作的映射（第一层），再理解指令仅在岔路口触发而非每步触发（第二层），最后结合迷宫结构执行路径追踪验证假设（第三层）。
</new_puzzle>
