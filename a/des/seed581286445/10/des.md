根据封闭区域内部"种子"颜色的数量，从区域边框向内逐层填充对应颜色环。

Input structure:
- 背景为主色（如 black）。
- 网格中散布若干由单一颜色（如 grey）绘制的封闭矩形边框，边框宽度为一个像素。
- 每个封闭矩形内部的背景区域中散落着若干不同颜色的单像素点（种子），每种颜色最多出现一次。
- 种子颜色互不相同，且与边框颜色和背景色不同。

Rule:
- 对每个封闭矩形，收集其内部所有种子像素，按照种子在矩形内部从上到下、从左到右的扫描顺序排列，得到一个颜色序列。
- 从矩形边框内侧开始，第一层（紧贴边框内壁的一圈像素）填充序列中第一个颜色，第二层（再向内缩一圈）填充第二个颜色，依此类推。
- 如果种子数量不足以填满所有层，最内层剩余区域保持背景色。
- 如果层数少于种子数量（即矩形太小），多余的种子被忽略。
- 原始种子像素被填充层覆盖。边框本身保持不变。

Key insight:
- 种子的作用不是标记位置，而是以其数量和扫描顺序定义一个由外向内的颜色填充序列；解题者需要先识别种子的排序规则，再理解"层数 = 种子个数"的映射关系。
</new_puzzle>

将散落的彩色像素"收集"到同色锚点方块上，收集方向由锚点方块缺失的角决定，形成对角射线。

Input structure:
- 背景为主色（如 black）。
- 网格中有若干不同颜色的 2×2 方块，但每个方块恰好缺少一个角上的像素（该像素保持为背景色），形成一个 L 形三像素结构。每种颜色只出现一个这样的锚点。
- 同一颜色的若干单像素点散布在网格各处（远离锚点）。

Rule:
- 对每个锚点，识别其缺失角的方向（左上、右上、左下、右下）。缺失角的方向定义一个对角方向向量（例如缺失左上角意味着向量指向左上方）。
- 统计该颜色散落单像素的数量 N。
- 从锚点缺失角位置开始，沿缺失角对角方向依次放置 N 个该颜色像素：第一个放在缺失角位置（补全 2×2 方块），第二个放在沿对角方向再远一格的位置，依此类推，形成一条长度为 N 的对角线。
- 散落像素的原始位置被清除为背景色。锚点的原始三个像素保持不变。

Key insight:
- 2×2 方块缺失角的位置同时编码了两个信息：对角线的延伸方向和起始位置。解题者需要先识别"L 形即缺角方块"的模式，然后推断缺角方向与像素排列方向的对应关系，最后理解散落像素的数量决定了对角线的长度。
</new_puzzle>

用每行/每列中的孤立像素作为行列寻址标记，在空心矩形框内部绘制十字交叉线。

Input structure:
- 背景为主色（如 black）。
- 网格中分布着若干由不同颜色绘制的空心矩形框（仅一像素宽的边框，内部为背景色）。这些矩形互不重叠。
- 在某些行中（矩形外部区域），存在一个孤立的彩色单像素点（行标记）；在某些列中（矩形外部区域），也存在一个孤立的彩色单像素点（列标记）。
- 每个矩形恰好被一个行标记和一个列标记"十字瞄准"：即恰好有一个行标记位于该矩形上边框行与下边框行之间（含边框行），恰好有一个列标记位于该矩形左边框列与右边框列之间（含边框列）。

Rule:
- 对每个空心矩形，找到与其行范围重叠的行标记和与其列范围重叠的列标记。
- 在矩形内部，沿行标记所在行画一条水平线（使用行标记的颜色），横跨矩形内部全宽；沿列标记所在列画一条垂直线（使用列标记的颜色），纵跨矩形内部全高。
- 如果水平线和垂直线在矩形内部有一个交叉点，该交叉像素使用行标记的颜色（行优先覆盖）。
- 矩形边框本身不变。行标记和列标记在输出中被清除为背景色。

Key insight:
- 解题者首先需要发现孤立像素是"行/列寻址标记"而非装饰或噪声；其次需要建立"行标记→水平线、列标记→垂直线"的双轴映射，并确定每个标记归属于哪个矩形；最后需要归纳交叉点的颜色优先级规则。三层推理环环相扣。
</new_puzzle>

<new_puzzle>
将左侧模板中标记像素的相对位置"印"到右侧同色碎片上，模板本身被清除。

Input structure:
- 背景为主色（如 black）。
- 网格左半区有若干小的矩形"模板"，彼此不重叠。每个模板由单一颜色填充，但其中有若干像素被替换为一种独特的标记色（每个模板使用不同的标记色）。模板整体仍为矩形轮廓。
- 网格右半区散布着若干与模板尺寸完全相同的纯色矩形碎片（无标记、完全由单色填满）。每个碎片的主色与某个模板的主色相同。
- 每个模板恰好与右侧一个碎片通过主色一一对应，且碎片的尺寸与对应模板完全相同。

Rule:
- 将每个右侧碎片与左侧同色模板配对。
- 在碎片上，将模板中标记色像素所处的相对位置（以模板左上角为原点的局部坐标）对应的像素替换为该模板的标记色。
- 碎片其余像素保持其主色不变，碎片位置不变。
- 左侧模板区域在输出中全部清除为背景色。

Key insight:
- 核心推理分两层：第一层需要通过颜色匹配建立碎片与模板的对应关系；第二层需要将模板中标记色的局部坐标映射到碎片上——模板不是要被"修复"，而是作为一种空间印章模式施加于碎片。
</new_puzzle>

<new_puzzle>
围栏内的色带序列定义嵌套层次，输出为按该序列从外到内绘制的同心方环。

Input structure:
- 背景为主色（如 black）。
- 网格中有一个由 grey 像素构成的封闭矩形围栏（一像素宽边框）。
- 围栏内部从左到右紧密排列着若干不同颜色的竖直色带（每条色带宽一像素，高度等于围栏内部高度），色带之间无间隔、无背景色分隔。色带颜色互不相同。
- 围栏外部散布着若干单色连通对象（形状各异），每个对象的颜色恰好是围栏内某条色带的颜色，每种色带颜色在外部恰好对应一个对象。

Rule:
- 读取围栏内从左到右的色带颜色序列，得到嵌套层次顺序（最左 = 最外层环，最右 = 最内层中心）。
- 统计色带数量 N，创建一个边长为 2N−1 的正方形输出网格。
- 按色带序列从外到内绘制同心正方形环：第一个颜色填充最外圈环，第二个颜色填充次外圈环，直到最后一个颜色填充正中心的单个像素。
- 输出仅包含该同心方环图案，不包含围栏、色带或外部对象。

Key insight:
- 围栏内的色带是一份嵌套层次的"图例"，外部散落对象仅起到颜色验证的干扰作用。解题者容易误以为外部对象的面积或位置决定嵌套层次，但实际排列顺序完全由围栏内色带的左右空间位置决定。需要先识别围栏作为图例容器的角色，再理解色带位置→同心环层级的映射。
</new_puzzle>

<new_puzzle>
根据彩色标记在分隔线上的位置，将对应子区域内的图案沿标记指定的轴翻转。

Input structure:
- 背景为主色（如 black）。
- 网格被若干一像素宽的 grey 直线（完整的行或列）分割为若干矩形子区域。
- 每个子区域内部包含一个由某种非背景、非 grey 颜色绘制的小型图案（形状不对称，以便区分翻转前后）。
- 在每个子区域的某一条 grey 分隔线上（该区域的上、下、左或右边界），恰好有一个像素被替换为一种特殊标记色（如 red）。每个子区域最多有一个这样的标记。

Rule:
- 对每个子区域，检查其四条边界分隔线上是否有标记色像素。
- 如果标记在子区域的上边界或下边界上，则将该子区域内部的图案做上下（垂直轴）翻转。
- 如果标记在子区域的左边界或右边界上，则将该子区域内部的图案做左右（水平轴）翻转。
- 如果子区域边界上没有标记，该子区域图案保持不变。
- 翻转是相对于子区域内部空间的中心进行的。分隔线上的标记像素在输出中恢复为 grey。

Key insight:
- 分隔线上的标记像素容易被忽视为噪声或损坏，但它实际编码了翻转操作的轴向。解题者需要先发现标记的存在和归属（属于哪个子区域的哪条边界），然后归纳"上下边界→垂直翻转、左右边界→水平翻转"的映射规则。标记的位置而非颜色才是关键信息。
</new_puzzle>

<new_puzzle>
根据各连通区域中"指针"像素相对于区域质心的朝向，选择对应方向的相邻区域颜色来重绘当前区域。

Input structure:
- 背景为主色（如 black）。
- 网格被 grey 的完整行和完整列分割成若干大小相同的正方形子区域，排列成规则的行列网格（如 3×3 或 4×4 的子区域阵列）。
- 每个子区域内部填充一种纯色（非背景、非 grey），且每个子区域中恰好有一个像素被替换为另一种特殊颜色（如 maroon），称为"指针"。
- 指针在子区域内的位置不固定，可以在上半部、下半部、左半部或右半部。

Rule:
- 对每个子区域，判断其指针像素位于子区域内部中心点的哪一侧（上、下、左、右）。判定方法：比较指针与子区域中心的行列坐标，取偏移绝对值较大的轴为主方向。
- 指针朝向上方：该子区域的填充色替换为正上方相邻子区域的填充色。朝向下方：替换为正下方相邻子区域的填充色。朝向左方：替换为左侧相邻子区域的填充色。朝向右方：替换为右侧相邻子区域的填充色。
- 如果指针指向的方向没有相邻子区域（即该子区域在网格边缘），则该子区域填充色不变。
- 所有指针像素在输出中被替换为该子区域的新填充色。grey 分隔线保持不变。

Key insight:
- 解题者需要先发现每个区域中的异色像素是"指针"而非噪声，然后推断指针在区域内的偏移位置编码了一个方向（而非距离或颜色信息），最后理解该方向指向的是"颜色来源"邻居。整个规则形成一个"指针解引用"的抽象操作——每个区域通过自身的指针去读取邻居的颜色。
</new_puzzle>

将每个彩色对象按其内部孔洞数量进行复制平铺，孔洞数量同时决定平铺的列数和对象的重着色。

Input structure:
- 背景为主色（如 black）。
- 网格上半区有一行彼此分离的彩色连通对象（8-连通），每个对象由单一非背景色绘制。不同对象颜色不同。
- 每个对象内部可能包含零个或多个"孔洞"（被对象像素完全包围的背景色区域，每个孔洞至少一个像素）。
- 网格下半区有一行同样数量的小型方形色块（每个色块为 1×1 或 2×2），颜色与上方对象一一对应（按左右位置对齐），作为颜色图例。

Rule:
- 对每个上半区对象，数其内部孔洞的数量 H。
- 在输出中，按对象从左到右的顺序依次排列：每个对象被水平复制 H 次（如 H=3 则并排放三份），相邻副本之间间隔一列背景色。
- 若某对象 H=0（无孔洞），则该对象不出现在输出中（被完全省略）。
- 所有对象副本统一使用该对象在下半区图例中对应色块的颜色重新着色。
- 不同对象组之间间隔两列背景色。下半区图例不出现在输出中。

Key insight:
- 解题者需要独立发现两个非显然规则并组合：第一层是孔洞计数决定复制次数（孔洞数量作为"倍率"而非装饰），第二层是图例色块决定输出颜色（而非使用对象原色）。仅从样例中需要同时归纳这两个映射关系才能完整解题。
</new_puzzle>
