- `description`：根据封闭区域内部小色块的排列方向，选择对应方向的翻转方式来镜像整个封闭区域的轮廓形状。

- `Input structure`：
  - 背景为黑色（black）。
  - 网格中有若干个由同一种颜色（如 blue）绘制的封闭轮廓形状（4-连通的单像素宽边框，内部为黑色背景）。
  - 每个封闭轮廓内部恰好有两个相邻的小色块（非边框色、非背景色），这两个小色块水平相邻或垂直相邻，颜色相同（可能是 red、green 或 yellow 等）。
  - 每个封闭轮廓的外部紧邻一侧有一个与内部小色块同色的单像素标记点，标示输出位置。

- `Rule`：
  - 对每个封闭轮廓，观察其内部两个相邻小色块的排列方向：
    - 若两个小色块水平排列（同行相邻），则将该轮廓形状沿水平轴上下翻转。
    - 若两个小色块垂直排列（同列相邻），则将该轮廓形状沿垂直轴左右翻转。
  - 翻转后的轮廓以外部标记点为锚点（标记点对应翻转后轮廓中距离原轮廓最近的角点），用原轮廓的颜色绘制在输出网格上。
  - 原轮廓保留不变；内部小色块和外部标记点在输出中被擦除（变为背景色）。

- `Key insight`：内部小色块不是装饰，它们的排列方向（水平 vs 垂直）决定了翻转轴的选择；外部标记点不是装饰，它确定了翻转副本的放置位置。解题者需要先识别"方向→翻转轴"的映射关系，再理解标记点的锚定作用。
</new_puzzle>

- `description`：将散落的彩色碎片按颜色配对后拼合，再根据拼合后形状是否为矩形来决定保留或擦除。

- `Input structure`：
  - 背景为黑色（black）。
  - 网格中散布着若干个 4-连通的单色前景对象（碎片），每种非背景颜色恰好出现两个独立的碎片。
  - 同色的两个碎片在行或列方向上对齐（即它们的边界框在某一维度上有重叠），且它们之间有足够的空间互不接触。
  - 每对同色碎片的形状互补：沿它们对齐的轴平移拼合后，恰好能组成一个无孔洞的连通区域。

- `Rule`：
  - 对每种颜色，找到其两个碎片，将较远的那个沿两者对齐的方向（水平或垂直）平移，直到与另一个碎片的边缘刚好接触（无重叠、无间隙），形成拼合体。
  - 检查拼合体的形状：
    - 若拼合体恰好是一个实心矩形（边界框内无背景像素），则在输出中保留该拼合体。
    - 若拼合体不是实心矩形（边界框内存在背景像素空洞），则在输出中将该颜色的所有像素擦除为背景色。
  - 未参与拼合的像素均为背景色。

- `Key insight`：解题者首先需要发现同色碎片的平移拼合规则（非显然的第一层），然后需要发现矩形判定作为筛选条件（非显然的第二层）。拼合本身并不是最终目标，拼合后的几何属性才决定去留。
</new_puzzle>

<new_puzzle>
- `description`：用网格边缘的"色带顺序"作为调色板，按对象到边缘的层数为每个对象重新上色。

- `Input structure`：
  - 背景为黑色（black）。
  - 网格的最外一圈像素（第 0 行、最后一行、第 0 列、最后一列）由若干种颜色的连续色带组成，从左上角顺时针排列，每段色带长度不等但至少 2 个像素，颜色互不相同。按顺时针读取这些色带得到一个有序颜色序列（如 red, blue, green, yellow）。
  - 网格内部（去掉最外圈后）包含若干个互不接触的 4-连通单色前景对象，对象颜色为 grey。
  - 这些灰色对象分布在不同的"深度层"：有的紧贴最外圈边框（与边框的最小正交距离为 1），有的更靠内部。

- `Rule`：
  - 顺时针读取最外圈的色带，得到有序颜色序列 C1, C2, C3, ..., Ck。
  - 对每个灰色对象，计算其所有像素到网格边缘的最小正交距离（即该像素所在行列到四边的最小值），取对象内所有像素中该值的最小值作为对象的"深度" d（d 大于等于 1）。
  - 将深度 d 的对象重新上色为序列的第 d 个颜色（从 1 开始索引）。若 d 超过序列长度 k，则循环使用序列。
  - 最外圈色带在输出中保持不变。

- `Key insight`：边缘色带不是装饰边框，而是一个有序调色板——解题者需要发现顺时针读取色带顺序这一非显然的编码方式（第一层推理），然后需要发现对象的"深度"（到边缘的最小距离）作为调色板索引（第二层推理）。两层信息的来源不同（边缘 vs 内部），增加了归纳难度。
</new_puzzle>

<new_puzzle>
- `description`：每个彩色对象向其内部唯一缺口方向"生长"出与自身面积等长的射线，射线遇到其他对象时将对方染成射线发射者的颜色。

- `Input structure`：
  - 背景为黑色（black）。
  - 网格中有若干个不同颜色的 4-连通前景对象，每个对象由不超过 8 个像素组成。
  - 每个对象的形状几乎是一个实心矩形，但恰好在某一侧边缘缺少一个像素（形成一个凹口）。缺口总是在对象边界框的某条边（上、下、左、右）上。
  - 对象之间在水平或垂直方向上保持足够间距。

- `Rule`：
  - 对每个对象，找到其边界框中缺失的那个像素所在的方向（上、下、左、右），该方向即为"生长方向"。
  - 从缺口像素的位置开始，沿生长方向向外（远离对象）画一条单像素宽的射线，射线颜色与该对象相同，射线长度等于该对象的像素总数。
  - 若射线在达到预定长度之前碰到另一个对象的像素，射线在接触点停止，被碰到的整个对象重新上色为射线发射者的颜色。
  - 若射线未碰到任何对象或到达网格边界，射线正常绘制到预定长度（在网格边界处截断）。
  - 所有射线同时发射，不分先后；若两条射线交叉，交叉点保留行索引较小者的颜色（若行索引相同则保留列索引较小者）。

- `Key insight`：缺口方向决定射线方向（第一层：从"几乎矩形"中找凹口的朝向），对象面积决定射线长度（第二层：面积到长度的转换），碰撞导致颜色传染（第三层：射线的目的不仅是画线，更是改变其他对象的颜色）。三层机制相互独立但共同作用于最终输出。
</new_puzzle>

- `description`：根据框架内标记像素的连线方向，选取对应方向的外部模板，将模板缩放后填入框架。

- `Input structure`：
  - 背景为黑色（black）。
  - 网格中有一个较大的由 grey 像素构成的矩形空心框架（单像素宽边框，内部为背景色），框架内部恰好有两个相同颜色的单像素标记点。
  - 框架外部有若干个小型前景图案（模板），每个模板由不同的非灰色、非背景色绘制，尺寸不超过 5x5。
  - 模板分为两类：宽度大于高度的（横向模板）和高度大于宽度的（纵向模板）。恰好有一个横向模板和一个纵向模板。

- `Rule`：
  - 观察框架内两个标记点的相对位置：
    - 若两个标记点在同一行（水平连线），选择横向模板。
    - 若两个标记点在同一列（垂直连线），选择纵向模板。
    - 若两个标记点既不同行也不同列（对角连线），选择面积较大的那个模板。
  - 将选中的模板按整数倍缩放（每个像素扩展为 n*n 的同色块），使其恰好能填满框架内部空间（不含框架边框本身）。缩放倍数 n 由框架内部的宽高与模板的宽高唯一确定。
  - 用缩放后的模板填充框架内部，替换掉原有的背景色和标记点。
  - 框架本身和未被选中的模板在输出中保持不变。

- `Key insight`：标记点的空间关系（水平/垂直/对角）是选择模板的隐藏密钥（第一层推理），而模板需要整数倍缩放以匹配框架尺寸（第二层推理）。解题者必须先破解选择逻辑，再理解缩放填充机制。
</new_puzzle>

- `description`：将每个对象按其"邻居数量"分组，同组对象合并到最大成员的位置并叠加绘制。

- `Input structure`：
  - 背景为黑色（black）。
  - 网格中有若干个不同颜色的 4-连通前景对象，每个对象占据 3 到 10 个像素不等，形状各异。
  - 对象之间可能紧邻（正交方向上间隔恰好 1 个像素）或远离。没有对象直接接触（共享边）。
  - 每个对象的"邻居数量"定义为：与该对象的边界框在正交方向上间隔恰好 1 个像素的其他对象的数量（即紧邻对象数）。

- `Rule`：
  - 计算每个对象的邻居数量。
  - 将邻居数量相同的对象归为同一组。
  - 对每一组：找到该组中面积最大的对象（若面积并列则取行索引最小者），以其位置为锚点。
  - 将同组其他对象平移至锚点对象的位置：每个对象的边界框左上角对齐到锚点对象的边界框左上角，以各自原色绘制，后绘制的覆盖先绘制的（按面积从大到小的顺序绘制，最小的在最上层）。
  - 不属于任何多成员组的孤立对象（邻居数量唯一）保持原位不变。

- `Key insight`：解题者需要首先发现"邻居数量"这一隐含的分组依据（第一层——需要观察对象间距来判定邻接关系），然后发现同组对象向最大成员位置汇聚并叠加的合并规则（第二层——面积决定锚点，绘制顺序决定可见性）。分组依据不是颜色或形状，而是拓扑邻接关系，这增加了归纳难度。

- `description`：每个"容器"对象吞噬其开口方向上最近的"食物"对象，将食物的颜色填入容器内部空腔。

- `Input structure`：
  - 背景为黑色（black）。
  - 网格中有若干个"容器"对象：每个容器是一个由单一颜色（如 blue、green 等）绘制的 U 形或 C 形结构（三面封闭、一面开口的单像素宽壁），开口朝向上、下、左或右四个基本方向之一。容器的内部空腔为背景色。
  - 网格中还有若干个"食物"对象：每个食物是一个小型实心单色块（1 到 4 个像素的 4-连通区域），颜色与所有容器颜色不同。
  - 每个容器的开口方向上至少有一个食物对象（沿开口方向的直线延伸范围内）。

- `Rule`：
  - 对每个容器，确定其开口方向（U 形缺口所在的那一侧）。
  - 沿开口方向向外扫描，找到距离容器开口边缘最近的食物对象（以食物边界框到容器开口的最短正交距离计算）。
  - 将该食物对象从原位置擦除（变为背景色）。
  - 用该食物的颜色填充容器的内部空腔（容器壁围成的背景区域）。
  - 容器壁本身颜色不变。若某个食物不是任何容器的最近食物，则保留在原位。

- `Key insight`：解题者需要先识别容器的开口朝向（第一层——从 U/C 形结构中判断缺口方向），然后沿该方向找到最近的食物并将食物颜色"注入"容器内部（第二层——理解"吞噬"机制：食物消失、容器内部被染色）。容器的壁色与食物色完全独立，输出中容器呈现双色（壁色加内部填充色）。
</new_puzzle>
