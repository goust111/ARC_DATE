<description>
根据边框缺口方向确定源图案的旋转方式，再用旋转后的图案填充框内空白区域。

Input structure:
- bg = 最常见颜色（black）。网格中有若干个由同一颜色绘制的矩形边框（如 blue），每个边框的某一侧有一个单像素宽的缺口（缺口位置可在上、下、左、右侧）。
- 每个边框内部为空（bg），边框外部某处有一个小型多色图案（sprite），该图案的外轮廓颜色与对应边框颜色相同，以此建立配对关系。
- 图案在原始朝向下，其"开口侧"或"标记侧"始终朝上（即图案有一个视觉上不对称的方向性特征，例如顶部有一行独特颜色的像素）。

Rule:
- 将每个小型图案与同色边框配对。
- 观察边框缺口所在的方向（上、下、左、右）。
- 将图案旋转，使图案的标记侧朝向缺口所在的方向（上→不旋转，右→顺时针90°，下→180°，左→逆时针90°）。
- 将旋转后的图案放置到边框内部的中心位置。
- 边框外部的原始图案被擦除（变为 bg）。

Key insight: 缺口方向不仅标记了"入口"，还编码了图案需要旋转的角度；配对依靠边框颜色与图案轮廓颜色的匹配，而旋转角度必须通过缺口位置独立推断。
</description>
</new_puzzle>

<description>
将散布的彩色碎片按形状拼入模板孔洞，再根据拼合后每个孔洞区域内碎片颜色的数量关系决定该区域的最终统一填充色。

Input structure:
- bg = 最常见颜色（black）。网格中央有一个大型灰色（grey）实心板，板上有若干个不规则形状的孔洞（bg 区域）。
- 板外散落着若干彩色碎片，每个碎片由多个相连像素组成，颜色各异（如 red、green、blue、yellow 等），每个碎片的形状恰好是某个孔洞的一部分。
- 同一个孔洞可能由两到三个碎片拼合而成（碎片形状互补，拼合后恰好覆盖整个孔洞）。
- 每个碎片旁边（8邻域内）有一个与该碎片颜色相同的单像素标记点，位于板的边缘上，指示该碎片属于哪个孔洞（标记点与孔洞在板边缘相邻）。

Rule:
- 通过板边缘的标记点颜色，将碎片分组到对应孔洞。
- 在同一孔洞的碎片组中，尝试所有碎片的平移组合（不旋转不翻转），使它们恰好无重叠地填满整个孔洞。
- 拼合完成后，统计该孔洞区域内各碎片颜色所占的像素数量，将整个孔洞区域统一填充为占据像素数最多的那个颜色。
- 擦除板外的所有碎片和标记点。

Key insight: 解题需要两层推理——第一层是通过边缘标记点建立碎片与孔洞的归属关系并完成形状拼合；第二层是发现最终填充色并非简单地保留各碎片原色，而是取拼合后面积最大的碎片颜色作为整个孔洞的统一色。
</description>
</new_puzzle>

<description>
在网格中找到被墙壁分隔的若干房间，根据房间内种子像素的颜色沿墙壁缺口向相邻房间"传播"颜色，传播时颜色按经过的门洞数量逐级变淡（按固定色序递降）。

Input structure:
- bg = 最常见颜色（black）。网格由 maroon 色墙壁分隔成若干个矩形房间。
- 每面墙上恰好有一个单像素宽的缺口（门洞），连通相邻两个房间。
- 部分房间内有一个彩色种子像素（颜色各不相同，可能是 red、orange、yellow、green 等）。
- 存在一个全局色序链，在每组训练样例中保持一致，例如：red → orange → yellow → green → azure（由"浓"到"淡"）。

Rule:
- 从每个含种子像素的房间出发，种子颜色填充整个房间（所有 bg 像素变为种子色）。
- 颜色通过门洞向相邻的空房间传播：传播后颜色降一级（按色序链，red 变 orange，orange 变 yellow，依次类推）。
- 继续从新填充的房间通过其门洞向下一个空房间传播，颜色再降一级。
- 如果一个空房间可被多个源到达，取色序链中较"浓"（较靠前）的颜色。
- 到达色序链末尾后不再继续传播，该方向停止。

Key insight: 门洞不仅是连通关系的标记，还是颜色衰减的计数器——解题者必须先从样例中归纳出隐含的色序链，再理解颜色随传播距离（经过的门洞数）逐级递变的规则，而多源竞争时的"取浓"规则增加了第三层推理。
</description>
</new_puzzle>

<description>
识别网格中的若干条折线路径，根据路径拐点数量从预设的调色板行中选取对应颜色，对整条路径重新着色。

Input structure:
- bg = 最常见颜色（black）。网格底部有一行单像素高的调色板（palette row），由若干种不同颜色从左到右排列，每种颜色占一个像素，颜色之间无间隔。调色板第 1 格对应"0 个拐点"，第 2 格对应"1 个拐点"，依次类推。
- 网格上方分布着若干条互不相连的折线路径，每条路径由 grey 像素组成，宽度为 1 像素，沿水平或垂直方向延伸，在拐点处改变方向（90° 转弯）。
- 每条路径的两个端点各自只有一个路径邻居。

Rule:
- 对每条 grey 路径，追踪其走向并计数拐点数量（方向改变的次数，直线路径拐点为 0）。
- 用拐点数量作为索引，从底部调色板行中取对应位置的颜色（从左起第 1 格为索引 0）。
- 将整条路径的所有 grey 像素重新着色为该颜色。
- 调色板行本身在输出中保持不变。

Key insight: 解题者需要先意识到底部色条是"查找表"而非装饰，再独立发现索引键是每条路径的拐点数——两者的关联在视觉上并不直接，必须通过对比多个样例中路径形态与最终颜色的对应关系来归纳。
</description>
</new_puzzle>

<new_puzzle>
<description>
将网格中的多色图案拆解为单色层，每层沿各自锚点标记所指示的方向平移后重新叠合。

Input structure:
- bg = 最常见颜色（black）。网格中央有一个由多种颜色组成的复合图案（各颜色像素相互交织）。
- 网格的四条边上各有若干单像素的锚点标记，每个锚点的颜色对应复合图案中的某一种颜色。
- 每种颜色在边上只出现一个锚点标记。锚点所在的边（上、下、左、右）指示了该颜色层需要平移的方向：上边→向上，下边→向下，左边→向左，右边→向右。
- 锚点在其所在边上的具体位置（距边角的像素偏移量）指示了平移的步数。例如上边第 3 个像素位置的锚点表示该颜色层向上平移 3 步。

Rule:
- 将复合图案按颜色拆解为若干单色二值层（每层只含一种颜色的像素和 bg）。
- 对每层，根据其颜色对应的边缘锚点，确定平移方向和步数。
- 将该层整体沿指定方向平移指定步数。
- 将所有平移后的层重新叠合到 bg 网格上；若多层像素重叠，后叠合的层覆盖先叠合的层（叠合顺序为：锚点从网格边缘顺时针扫描的顺序，从左上角开始）。
- 擦除边缘上的所有锚点标记。

Key insight: 解题需要三层推理——第一层是发现边缘单像素是锚点而非噪声，并通过颜色匹配建立锚点与图案层的对应；第二层是发现锚点所在边编码了方向、锚点在边上的位置编码了距离；第三层是发现重叠时的覆盖优先级由锚点的空间排列顺序决定。
</description>
</new_puzzle>
