# 第一步：分析与思考

## 参考题目中涉及的基础操作归纳

从20道参考题中可以提取以下基础操作类别：

1. **空间平移与滑动**：将对象沿某方向平移直到碰到边界/分隔线（题1滑动到分隔线、题4按面积向上平移、题6推到网格边缘）。
2. **旋转与翻转**：围绕枢轴点旋转（题3的90度旋转）、镜像反射（题16跨标记线反射）。
3. **压缩与紧凑化**：将分散元素向某方向压缩（题7棋盘压缩、题14射线回压到锚点）。
4. **形态学操作**：膨胀求交集取中间通道（题15）、填充孔洞（题17）。
5. **序列/排列变换**：颜色序列反转（题12）、块重排（题13）。
6. **拓扑/边界特征检测**：检测封闭孔洞（题1）、边界凹凸配对（题9）、十字形检测（题19）。
7. **缩放与嵌套**：按比例放大后匹配拼入（题8）、嵌套方框构建（题18）。
8. **编码与解码**：图案作为编码器生成周期格（题20）、面积编码为位移量（题4）。
9. **区域分割与标记导向**：分隔线划分区域（题1、题10）、标记像素指示方向（题6、题7）。
10. **属性到几何的映射**：像素数→线长（题11）、条纹高度→框架厚度（题18）、计数→嵌套直方图（题5）。

## 非显而易见的串联方式思考

- **拓扑特征作为操作参数**：一个对象的孔洞数量或连通分量数可以编码另一个操作的重复次数或位移量。比如，某对象内部的封闭孔洞数量决定了另一个对象需要旋转多少次。
- **路径几何隐含排序信息**：路径上相邻颜色的变化次数可以作为排序键来重排其他对象。
- **边界形状作为信息通道**：一个对象的轮廓凹凸模式可以编码二进制信号，用来控制另一个区域中对象的显示/隐藏。
- **相对位置关系编码变换类型**：两个标记点的相对方位（上下左右、对角）不仅指示方向，还可以指定具体的变换类型（平移 vs 旋转 vs 翻转）。
- **颜色频率作为空间索引**：某种颜色在网格中出现的次数可以指向特定行号或列号，建立颜色统计与空间坐标之间的映射。
- **遮挡关系还原**：多个半透明层叠图案可以通过颜色混合规则推断原始层序，从而还原出被遮挡的部分。

<new_puzzle>
- `description`：根据每个彩色对象内部封闭孔洞的数量，将该对象沿其最近网格边缘方向平移相应的格数。

- `Input structure`：
  - 背景为 black。
  - 网格中散布若干个由单一非背景色组成的4-连通封闭形状（如不规则多边形轮廓），每个形状的颜色互不相同。
  - 每个形状内部可能包含零个、一个或多个由背景色组成的封闭孔洞（完全被该形状像素包围的 black 连通区域）。
  - 所有形状彼此不相邻，且与网格边缘之间有足够空间供平移。

- `Rule`：
  - 对每个彩色形状，计算其内部封闭孔洞的数量 N。
  - 确定该形状重心到网格四条边（上、下、左、右）的距离，选择距离最近的那条边作为平移方向（若存在并列，优先级为：上 > 右 > 下 > 左）。
  - 将该形状整体朝最近边方向平移 N 个像素（保持形状和颜色不变）。
  - 若 N = 0（无孔洞），形状保持原位不动。
  - 平移后形状不会超出网格边界，也不会与其他形状重叠（题目保证输入满足此条件）。

- `Key insight`：解题的关键在于意识到每个形状的"运动量"并非来自其大小、位置或颜色，而是来自其拓扑特征——内部封闭孔洞的数量。孔洞数量是一个需要仔细检查每个形状内部连通性才能确定的属性，它与形状的外观大小并无直接关联。平移方向则由形状在网格中的空间位置决定。
</new_puzzle>

<new_puzzle>
- `description`：将网格中彩色"箭头"指向的目标区域用该箭头的颜色填充，箭头本身在输出中消失。

- `Input structure`：
  - 背景为 black。
  - 网格中有若干个由 grey 色组成的矩形区域（实心填充），彼此不重叠，大小各异。
  - 网格中另有若干个由不同颜色（如 red、blue、green 等）组成的"箭头"形状。每个箭头由一个三角形箭头头部和一条一像素宽的直线尾巴组成。三角形头部的绘制方式：沿箭头指向方向，顶端一个像素，向后每行宽度增加2（即1、3、5...），形成等腰三角形；尾巴从三角形底边中心沿反方向延伸若干格。
  - 每个箭头的尾巴方向沿四个基本方向之一（上、下、左、右），箭头头部指向相反方向。
  - 每个箭头沿其指向方向延伸的直线上恰好会穿过一个 grey 矩形。

- `Rule`：
  - 对每个箭头，沿其头部指向的方向画一条射线。
  - 找到该射线首先命中的 grey 矩形。
  - 将该 grey 矩形的所有像素重新着色为该箭头的颜色。
  - 在输出中删除所有箭头像素（变为 black 背景）。
  - 若某个 grey 矩形没有被任何箭头指向，则保持 grey 不变。

- `Key insight`：解题者需要首先识别出"箭头"这种特定的几何结构（三角形 + 线段尾巴），然后理解箭头的方向性——它像指针一样指向某个目标矩形。核心推理是"方向性指派"：箭头的颜色通过空间射线投射被传递给远处的目标对象。难点在于从样例中识别出箭头形状与射线投射规则，而不是简单的邻接关系。
</new_puzzle>

<new_puzzle>
- `description`：每个彩色区域的边界轮廓上的"角点"数量决定了该区域在输出中应被缩放到的边长，所有区域在输出中以缩放后的正方形形式按特定顺序排列。

- `Input structure`：
  - 背景为 black。
  - 网格中有若干个由不同单色组成的4-连通实心区域，形状均为直角多边形（所有边与网格轴线平行），但各区域的大小和形状各不相同。
  - 区域之间互不接触。
  - 每个区域的直角多边形轮廓上存在若干个"角点"——角点定义为：该前景像素的4-邻域中恰好有2个同色前景邻居，且这2个邻居分别位于不同轴线方向（即一个水平方向邻居和一个垂直方向邻居）。

- `Rule`：
  - 对每个彩色区域，计算其角点数量 C。
  - 在输出网格中，将每个区域替换为一个 C × C 的实心正方形，颜色与原区域相同。
  - 输出网格为单行排列：所有正方形从左到右按角点数量从小到大排列（若角点数相同，按原区域在输入中从左到右的出现顺序排列），相邻正方形之间用一列 black 背景分隔。
  - 输出网格的高度等于最大的 C 值，较小的正方形底部对齐（即顶部留空补 black）。

- `Key insight`：解题者需要发现变换的关键不是区域的面积、颜色或位置，而是其轮廓的几何复杂度——角点的数量。一个简单矩形有4个角点（生成4×4正方形），而一个L形有6个角点（生成6×6正方形），一个T形有8个角点（生成8×8正方形）。这建立了"形状复杂度→输出尺寸"的非直觉映射。
</new_puzzle>

<new_puzzle>
- `description`：识别网格中由分隔线围成的各个房间，根据每个房间内"门"（分隔线上的缺口）的朝向，将房间内的所有内容物沿该方向推出到相邻房间中。

- `Input structure`：
  - 背景为 black。
  - 网格被 grey 色的单像素宽直线（水平线和垂直线）分割成若干个矩形"房间"。grey 线段构成完整的网格状结构，但某些线段上存在恰好一个像素宽的缺口（即该位置为 black 而非 grey），这些缺口就是"门"。
  - 部分房间内部包含由各种非 black、非 grey 颜色组成的小图案（形状各异，可以是单个像素、小方块、或其他小形状）。
  - 每个含有内容物的房间恰好只有一扇门（一个缺口），位于该房间四面墙壁中的某一面上。
  - 门朝向的相邻房间保证为空且空间足够。

- `Rule`：
  - 找到每个包含内容物的房间。
  - 确定该房间唯一的门（grey 线段上的缺口）位于哪面墙（上、下、左、右）。
  - 将房间内的所有内容物整体沿门的朝向平移，穿过门进入相邻房间，平移距离为恰好使内容物的整体中心落在相邻房间的中心位置。
  - 原房间清空为 black。
  - 所有 grey 分隔线（包括门/缺口）保持不变。
  - 空房间和无门房间不受影响。

- `Key insight`：解题者首先需要感知"房间"结构——由 grey 线组成的网格分隔，然后注意到墙壁上微小的单像素缺口（门）。关键发现是：门不仅标识了房间的出口位置，更指定了内容物的运动方向。这是一个空间隐喻式的规则——物体像通过门"逃离"房间一样被推到另一侧。难点在于找到门——它只是 grey 线段上一个不起眼的缺失像素。
</new_puzzle>

<new_puzzle>
- `description`：网格中的每条彩色线段充当"镜子"，将沿垂直方向射来的同色光点反射90度后沿水平方向延伸（或反之），直到碰到网格边缘或另一面镜子。

- `Input structure`：
  - 背景为 black。
  - 网格中有若干条由不同颜色组成的短线段（长度2-4像素），每条线段严格沿水平或垂直方向放置。这些线段就是"镜子"。
  - 网格中另有若干个由 maroon 色组成的单像素"光源点"，分布在网格边缘（第一行、最后一行、第一列或最后一列）。
  - 每个光源点所在的行或列上恰好有一条与之垂直的彩色线段（即光源在边缘发出的射线会命中该线段）。

- `Rule`：
  - 每个 maroon 光源点从网格边缘向内发出一条射线（方向由其所在边缘决定：顶边向下，底边向上，左边向右，右边向左）。
  - 沿射线路径绘制 maroon 像素，直到遇到第一条彩色线段（镜子）。
  - 射线在命中镜子的那个像素处发生90度反射：如果射线水平入射到垂直镜子，则反射后变为垂直方向（向上或向下，选择能继续延伸更远距离的方向；若相等则向上/向左优先）；反之亦然。
  - 反射后的射线继续以该镜子的颜色（非 maroon）绘制，沿新方向延伸直到碰到网格边缘或另一条镜子为止。
  - 若反射光线碰到另一条镜子，则再次反射，以新镜子的颜色继续延伸，以此类推。
  - 所有原有的镜子线段和光源点保持不变。

- `Key insight`：解题者需要将这些分散的短线段理解为"镜子"，将边缘的 maroon 点理解为"光源"。核心推理是光线反射模型——入射方向和镜子朝向共同决定反射方向。难点在于从样例中推断出反射行为的规则，尤其是当存在多次反射时，颜色会在每次反射时改变为新镜子的颜色，这为追踪光路提供了视觉线索。
</new_puzzle>

- `description`：网格中若干个相同形状但不同颜色的对象，根据各自颜色在一条隐含"色谱带"上的位置关系进行空间排序重排。

- `Input structure`：
  - 背景为 black。
  - 网格上方有一条水平的"色谱带"——一行由若干种颜色从左到右排列的连续像素条（每种颜色恰好占据一个像素），定义了颜色之间的排序关系。
  - 网格下方区域散布着若干个形状完全相同但颜色各异的4-连通前景对象。这些对象的颜色均出现在色谱带中。
  - 这些对象在输入中随机分布，彼此不重叠。

- `Rule`：
  - 读取色谱带从左到右的颜色顺序，建立颜色排序规则。
  - 找到所有形状相同的前景对象。
  - 在输出中，将这些对象水平排列成一行，从左到右按照色谱带中的颜色顺序排列。
  - 对象之间间隔一列 black 背景。
  - 所有对象底部对齐，整体在输出网格中水平居中、垂直居中。
  - 色谱带在输出中不再出现。

- `Key insight`：解题者需要发现网格顶部那一行看似装饰性的彩色像素条其实编码了排序规则。对象本身的空间位置在输入中是无序的，它们必须按照色谱带定义的颜色先后关系重新排列。关键挑战是识别色谱带的功能——它不是装饰，而是一个排序密钥。
</new_puzzle>

<new_puzzle>
- `description`：在由多种颜色构成的连通前景图案中，找到每种颜色子区域的"质心"像素，仅保留这些质心像素并用 red 标记，其余所有像素变为背景色。

- `Input structure`：
  - 背景为 black。
  - 网格中有一个大型连通前景图案，由多种颜色（如 blue、green、yellow、orange 等，至少3种）组成。
  - 在这个大图案中，相同颜色的像素构成一个或多个4-连通子区域。每种颜色恰好构成一个4-连通子区域。
  - 每个同色子区域的形状各异（可能是矩形、L形、不规则形状等）。

- `Rule`：
  - 对每种前景颜色，找到该颜色所有像素组成的子区域。
  - 计算该子区域的几何质心坐标（所有像素行坐标的平均值取整、列坐标的平均值取整，均向下取整）。
  - 若质心位置处的像素恰好是该颜色，则在输出中将该像素标记为 red。
  - 若质心位置处的像素不是该颜色（质心落在其他颜色区域或背景上），则找到该子区域中距离质心最近（曼哈顿距离）的像素，将该像素标记为 red（若有并列，选行号较小的；仍并列则选列号较小的）。
  - 输出网格中，除被标记为 red 的质心像素外，所有其他像素均变为 black。

- `Key insight`：解题者需要从样例中发现"每种颜色只留下一个像素"这一现象，进而推断出保留的是哪个特定像素。关键在于意识到保留的位置不是任意的，而是每个颜色区域的空间重心。这要求对不同颜色区域分别进行空间分析，找到它们的中心代表点。
</new_puzzle>

<new_puzzle>
- `description`：网格中的封闭围栏内有若干散落对象，根据围栏缺口方向和围栏内对象的"重量"（像素数），让对象像受重力影响一样从缺口"倒出"，在围栏外堆叠。

- `Input structure`：
  - 背景为 black。
  - 网格中有一个由 blue 色组成的封闭矩形框架（边框宽度为一像素），但框架的某一条边上有一段连续缺口（2-4像素宽的空缺）。
  - 框架内部有若干个由不同颜色组成的小型4-连通对象，散落在框内不同位置。
  - 框架外部是空的 black 背景。

- `Rule`：
  - 确定框架缺口所在的边（上、下、左、右）。缺口所在的边定义了"重力方向"——即物体将从缺口"掉出"的方向。
  - 将框架内的所有对象按照各自像素数量从大到小排序。
  - 将排序后的对象依次从缺口处"倒出"：
    - 若缺口在底边，对象从缺口正下方开始向下堆叠；若缺口在右边，对象从缺口正右方开始向右堆叠；以此类推。
    - 每个对象在输出中被重新绘制为 1×N 的条形（N为其像素数量），沿重力方向依次紧密排列。条形的颜色保持与原对象相同。
    - 条形的非重力方向位置居中于缺口中心。
  - 框架内部在输出中变为全 black（对象已被倒出）。
  - 框架本身（包括缺口）保持不变。

- `Key insight`：解题者需要理解三层机制的组合：(1) 缺口位置决定"出口方向"，如同容器倾倒；(2) 对象被"液化"为与其面积等量的条形；(3) 条形按面积大小排序堆叠。难点在于发现对象不是原样移出，而是被重新编码为面积等价的一维条形，以及排列顺序由面积大小决定。
</new_puzzle>
