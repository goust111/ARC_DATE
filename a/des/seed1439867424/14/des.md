# 第一步：分析与思考

## 参考题中的基础操作类别

1. **空间位移与对齐**：像素/对象按规则平移、旋转、反射（题4裂缝分离、题14颜色编码位移、题15矩形移动、题20旋转90°）
2. **填充与补全**：根据形状边界或隐含轮廓填充区域（题1连接标记、题2补全被遮挡形状、题3用调色板填充空心精灵）
3. **图例/调色板解码**：网格内某个区域充当颜色映射或参数编码（题3边缘调色板、题5拼图+图例、题6微缩图例、题18粉色控制像素）
4. **周期与平铺**：基于种子/模体进行递归或周期性复制（题10边框段周期重复、题16递归分形平铺）
5. **计数与统计**：对离散对象计数并将结果编码回网格（题19计数对象填入图例）
6. **缺陷检测与修复**：识别结构中的异常并标记或修复（题8缺陷高亮、题11去除阶梯噪声补线）
7. **排序与堆叠**：根据某种度量对对象排序并重新排列（题12对齐线段、题17按距离排序堆叠）

## 非显而易见的串联方式思考

- **拓扑属性作为隐含编码**：一个封闭区域的"孔洞数"或连通分量的"欧拉数"可以编码数值信息，而不需要显式的计数标记。这种信息对人眼可见但不直觉——需要"数洞"而非"数块"。
- **路径的可达性作为选择条件**：不是根据颜色或位置，而是根据两个对象之间是否存在一条不被阻断的路径来决定变换行为。这把"连通性"变成了规则的隐含判据。
- **形状的边界行为编码方向**：一个不规则形状的"尖端"指向的方向可以编码一个指令（如移动方向），但解题者必须先识别出哪个端是"尖端"。
- **颜色频率差异作为参数**：同色像素的数量差异不是用来计数输出，而是用来确定变换参数（如移动距离、缩放因子）。
- **对象间的空间拓扑关系作为匹配键**：两个对象不是通过颜色匹配，而是通过它们之间的空间包含/相邻/环绕关系来配对。
- **网格的"负空间"携带信息**：真正的信息不在前景像素中，而在前景之间的背景间隙的形状或宽度中。

<new_puzzle>
- `description`：根据每个前景形状中"孔洞"的数量，将该形状移动到网格中对应编号的目标槽位。
- `Input structure`：
  - 背景为 black。
  - 网格底部有一行从左到右等距排列的小正方形灰色（grey）槽位框，框内为 black，槽位框从左到右依次代表编号 0、1、2、3…（编号不显式标注，仅靠位置隐含）。
  - 网格上方散布若干个由同一颜色（非 black、非 grey）构成的封闭或半封闭不规则形状。每个形状使用不同的颜色（如 red、blue、green、yellow 等）。
  - 部分形状内部包含被自身像素完全围合的 black 区域（"孔洞"），孔洞数量从 0 到 3 不等。每个形状的孔洞数量互不相同。
- `Rule`：
  - 计算每个前景形状内部封闭的 black 连通区域（4-连通）的数量，即"孔洞数"。注意：与网格边界相连的 black 区域不算孔洞。
  - 将每个形状从其原始位置擦除（恢复为 black），然后将其整体（保持形状和颜色不变）放置到底部槽位行中编号等于其孔洞数的槽位上方，形状的最低行紧贴槽位框的顶边，水平居中对齐。
  - 槽位框本身保持不变。
- `Key insight`：解题者需要意识到决定每个形状去向的关键不是形状的颜色、大小或位置，而是其内部被完全围合的背景空洞的数量——这是一种拓扑属性而非几何属性。必须仔细区分"真孔洞"（被形状完全包围的 black 区域）和"凹陷"（与外部背景连通的 black 区域）。
</new_puzzle>

<new_puzzle>
- `description`：每个前景对象沿着其"尖端"指示的方向滑动，直到碰到网格边界或另一个对象为止。
- `Input structure`：
  - 背景为 black。
  - 网格中散布若干个由不同颜色构成的小型凸多边形形状（3×3 到 5×5 范围内），每个形状恰好有一个"尖端"——即形状在某个方向上只有一个像素宽的突出部分（类似箭头尖端）。例如：一个形状主体是 2×2 的方块，但在其右侧中间多出一个像素，则该形状的尖端朝右。
  - 每个形状的尖端方向为上、下、左、右四个正方向之一。
  - 形状之间互不接触，且离网格边界有足够空间。
- `Rule`：
  - 识别每个形状的"尖端方向"：找到形状中唯一一个在某正方向上是该形状最外侧且在垂直于该方向上邻居最少的像素，该像素突出的方向即为尖端方向。更精确地说：对形状的每个边界像素，检查它在上下左右四个方向上是否是该方向上形状的最远像素且在垂直方向上只有自身一列/行，若是则该方向为尖端方向。
  - 将整个形状沿尖端方向平移，直到形状的前沿（尖端方向上的最外像素）碰到网格边界或另一个已经固定的形状的边缘（紧邻但不重叠）。
  - 处理顺序：按尖端方向到最近障碍物距离从小到大处理（距离最短的先移动并固定）。
  - 形状移动后，原位置恢复为 black。
- `Key insight`：解题的关键在于发现形状的不对称突出部分编码了运动方向——形状本身就是"箭头"。解题者需要从形状的几何轮廓中提取方向信息，而不是寻找颜色或位置上的规律。移动顺序由距离决定，确保结果唯一确定。
</new_puzzle>

<new_puzzle>
- `description`：根据前景条纹之间背景间隙的宽度，选择性地合并相邻条纹或保留间隙。
- `Input structure`：
  - 背景为 black。
  - 网格中包含若干条水平的彩色条纹（每条条纹覆盖整行宽度，高度为 1 到 3 个像素不等），条纹之间被不同宽度的 black 间隙分隔。
  - 所有条纹使用同一种前景色（如 blue）。
  - 间隙宽度（即相邻两条条纹之间的 black 行数）在 1 到 4 行之间变化。
  - 网格中还有一个位于左侧或右侧边缘的小型"标尺"：一个由 red 像素构成的竖直线段，其长度为 T 个像素（T 在 1 到 3 之间）。
- `Rule`：
  - 读取红色标尺的长度 T。
  - 从上到下扫描所有相邻条纹对之间的间隙。
  - 若间隙宽度 ≤ T，则将该间隙填充为条纹颜色（blue），使两条条纹合并为一条。
  - 若间隙宽度 > T，则保留该间隙不变。
  - 红色标尺在输出中被擦除（恢复为 black）。
- `Key insight`：解题者必须先注意到边缘那个不起眼的红色竖线并非装饰，而是一个"阈值标尺"——它的物理长度直接定义了间隙合并的阈值。信息的编码方式是空间度量（线段的像素长度）而非颜色或数量，且标尺远离主要图案区域，容易被忽略。
</new_puzzle>

<new_puzzle>
- `description`：将网格中由墙壁分隔的迷宫房间按照房间之间的连通门数量重新着色——门越多颜色越"暖"。
- `Input structure`：
  - 背景为 black（代表墙壁/边界）。
  - 网格被 black 线条分隔成若干个不规则的封闭矩形房间，每个房间内部填充为 grey。
  - 部分相邻房间之间的 black 墙壁上有恰好 1 像素宽的缺口（门），使两个房间在 4-连通意义上通过该缺口相连。
  - 每个房间有 0 到 4 扇门不等。
- `Rule`：
  - 对每个 grey 房间，计算它的"门数"——即该房间的 grey 像素通过 4-连通缺口能直接到达多少个不同的相邻房间。
  - 根据门数重新着色房间内部所有像素（替换 grey）：
    - 0 扇门 → blue
    - 1 扇门 → green
    - 2 扇门 → yellow
    - 3 扇门 → orange
    - 4 扇门 → red
  - black 墙壁和门缺口保持不变。
- `Key insight`：解题者的直觉可能会先关注房间的大小、位置或形状，但真正的分类依据是每个房间与其邻居之间的连通门数——一种需要仔细追踪墙壁缺口的拓扑度量。颜色映射的"冷到暖"梯度是发现规则的线索：门越多（连通性越高），颜色越暖。
</new_puzzle>

<new_puzzle>
- `description`：每个前景色块被其自身边界框的"阴影"替换——色块缩回到边界框的一个角落，角落的选择由色块在边界框内的质心偏移方向决定。
- `Input structure`：
  - 背景为 black。
  - 网格中散布若干个不规则形状的单色前景色块（每个色块使用不同颜色，如 red、blue、green、yellow、magenta 等），各色块互不接触。
  - 每个色块的形状不对称——它的像素质心（所有像素坐标的平均值）不在其最小外接矩形（bounding box）的几何中心上。
- `Rule`：
  - 对每个色块，计算其最小外接矩形（bounding box），以及色块所有像素的质心（行坐标平均值，列坐标平均值）。
  - 将质心与 bounding box 中心比较：质心偏左上 → 选择左上角；质心偏右上 → 右上角；质心偏左下 → 左下角；质心偏右下 → 右下角。（先比较行方向：质心行 < 中心行为"上"，否则为"下"；再比较列方向：质心列 < 中心列为"左"，否则为"右"。）
  - 在输出中，擦除原始色块，然后在其 bounding box 内，将该色块的所有像素平移，使色块的 bounding box 角落对齐到所选的目标角落。即：如果选择左上角，则将色块平移使其最小行和最小列与 bounding box 的最小行和最小列对齐；如果选择右下角，则平移使其最大行和最大列与 bounding box 的最大行和最大列对齐；以此类推。
  - 平移后超出 bounding box 范围的像素被裁剪掉。
- `Key insight`：解题者需要发现色块的"重心偏移方向"决定了它被推向 bounding box 的哪个角落——像是重力作用，色块沿着自身质量分布不均匀的方向"滑落"到角落。这要求对每个形状进行视觉上的"重心判断"，而不是匹配颜色或计数。
</new_puzzle>

<new_puzzle>
- `description`：在网格中找到"信号源"像素和"天线"线段，将信号沿天线的方向广播，遇到反射墙时改变方向，最终在信号路径上留下轨迹。
- `Input structure`：
  - 背景为 black。
  - 网格中有若干条 grey 线段（水平或竖直，长度 ≥ 2），它们充当"反射墙"。
  - 恰好有一个 red 像素（信号源）和一个与之相邻的 blue 短线段（1 到 3 像素长，水平或竖直），blue 线段充当"天线"，指示信号的初始发射方向（从 red 像素沿 blue 线段延伸的方向发射）。
  - grey 反射墙的朝向（水平或竖直）决定了反射行为。
- `Rule`：
  - 从 red 信号源出发，沿 blue 天线指示的方向发射一条射线。
  - 射线沿直线前进，经过的每个 black 背景像素被标记为 yellow。
  - 当射线碰到一条 grey 反射墙时，发生镜面反射：碰到水平墙则垂直分量反转（上变下或下变上），碰到竖直墙则水平分量反转（左变右或右变左）。初始方向为四个正方向之一（上/下/左/右），遇到水平墙变为反向的竖直运动，以此类推——即正方向碰墙后仍为正方向。
  - 射线最多反射 20 次（防止无限循环），或者碰到网格边界时终止。
  - red、blue、grey 像素在输出中保持不变，仅 black 背景像素被标记为 yellow。
- `Key insight`：解题者需要理解三个层次：(1) blue 线段的朝向编码了初始方向，(2) grey 墙壁的朝向决定了反射方式，(3) 信号以"光线反射"的物理直觉在网格中弹跳。关键难点在于识别出 blue 线段是方向指示器而非普通障碍物，以及正确理解正交反射（非45度斜线反射）的规则。
</new_puzzle>

<new_puzzle>
- `description`：网格中的每个彩色"种子"像素在其周围生长出一个与其颜色对应的固定形状图案，生长被其他种子的生长区域或网格边界阻断。
- `Input structure`：
  - 背景为 black。
  - 网格中散布若干个孤立的单像素前景点（"种子"），每个种子使用以下颜色之一：red、blue、green、yellow。
  - 种子之间有足够间距（至少 4 个像素）。
  - 无其他前景内容。
- `Rule`：
  - 每种颜色对应一个固定的 5x5 生长图案（以种子像素为中心）：
    - red → 菱形（曼哈顿距离 ≤ 2 的所有像素）
    - blue → 十字形（与种子同行或同列且切比雪夫距离 ≤ 2 的所有像素）
    - green → 完整 5x5 正方形
    - yellow → 仅四个对角线方向的像素（与种子在同一对角线上且切比雪夫距离 ≤ 2 的像素，形成 X 形）
  - 所有种子同时生长。若两个种子的生长区域发生重叠，重叠像素归属于距离更近的种子（使用曼哈顿距离）。若距离相等，该像素保持 black（不被任何种子占据）。
  - 生长区域超出网格边界的部分直接裁剪。
- `Key insight`：解题者首先会注意到每个种子周围出现了不同形状的图案，必须将颜色与形状对应起来。更深层的挑战是理解重叠区域的归属规则——等距冲突像素保持背景色，这需要从样例中仔细观察"消失的像素"来推断。颜色不仅是视觉标识，更是形状生成指令。
</new_puzzle>
