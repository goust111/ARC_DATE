# 第一步：分析与思考

## 参考题中的基础操作梳理

纵观20道参考题，涉及的基础操作包括：裁剪/提取（#1）、生长/收缩（#2）、计数驱动尺寸（#3）、滑动/平移（#4）、模板印章/铺贴（#5, #12）、连通域汇总（#6）、向量位移与射线（#7）、级联激活/传播（#8）、对角镜像复制（#9）、序列包装/换行（#10）、轮廓提取与重绘（#11）、拼图装配（#14, #15）、螺旋路径生长（#16）、对称补全（#17）、局部擦除（#18）、碰撞检测（#19）、旋转+堆叠+加框（#20）。

## 非显而易见的串联方式与信息编码思考

1. **拓扑特征作为隐藏控制信号**：参考题中信息编码方式多为位置、颜色、面积、频率等直观属性。但拓扑特征（如连通域中的"洞"的数量、对象的欧拉数、轮廓的凹凸性）是一种肉眼可见但不易联想到的编码维度——比如一个对象有几个洞就决定它的变换模式。

2. **边界接触关系作为隐式排序键**：对象是否接触网格边缘、接触哪条边缘，这种空间关系可以隐式地定义对象的处理优先级或分组，而非使用颜色或面积。

3. **对象间的相对朝向作为指令**：两个对象的相对位置不仅是空间关系，还可以编码一个变换指令——比如对象A在对象B的左上方意味着"向左上平移"，而距离编码平移量。

4. **颜色出现的行/列位置编码数值信息**：一个颜色像素出现在第几行或第几列，这个位置本身就是一个数值，可以用来控制变换的参数。

5. **缺失模式作为正面信息**：参考题#9用"缺失角"来编码方向。更广泛地，一个几乎完整的结构中"缺了什么"可以是关键信息——缺失本身定义了输出。

6. **对象自身形状编码其变换方式**：对象不仅是被变换的目标，其形状本身就是变换指令的一部分——比如一个L形表示"旋转90度"，一个T形表示"翻转"。

7. **多层信息的交叉解码**：一个操作的结果需要结合两个不同来源的信息才能确定，单独看任何一个来源都无法推断。

# 第二步：全新 ARC 谜题

<new_puzzle>
- `description`：根据每个彩色对象内部"洞"的数量，选择对应的填充图案来填充该洞。

- `Input structure`：
  - 背景色为 black。
  - 网格中散布若干个由同一颜色构成的 8-connected 封闭对象，每个对象围成的内部可能包含 0、1 或 2 个 black 的"洞"（即不与网格边缘相连的 black 连通域）。
  - 网格底部有一个用 grey 线条围出的图例区域，内含两个小图案样本，从左到右分别标记为"1号图案"和"2号图案"，每个图案是一个 3x3 的彩色小方块（使用 red 和 blue 两种颜色绘制，各图案不同）。图例区域内两个图案之间用一列 grey 竖线分隔。

- `Rule`：
  - 找到所有不接触网格边缘的 black 连通域（即"洞"）。
  - 对每个彩色封闭对象，计算其围成的洞的数量 H。
  - 如果 H = 0，该对象不做任何改变。
  - 如果 H = 1，将该唯一的洞用"1号图案"铺贴填充（图案从洞的 bounding box 左上角开始铺贴，超出洞的范围的部分裁剪掉，只在洞的像素位置绘制图案颜色）。
  - 如果 H = 2，将两个洞分别用"2号图案"铺贴填充（规则同上）。
  - 对象本身的颜色保持不变，图例区域在输出中被移除（输出网格高度相应减少）。

- `Key insight`：洞的数量不仅决定了"是否填充"，还决定了"用哪个图案填充"——洞的计数是对图例的索引，而不是简单的"有洞就填"。解题者需要注意到有洞数量为2的对象使用了与洞数量为1的对象不同的图案，从而发现计数与图案选择之间的对应关系。
</new_puzzle>

<new_puzzle>
- `description`：每个小型彩色精灵按照自身形状所暗示的方向的反方向滑动，直到撞上同色的边框段后停下并"融合"进边框。

- `Input structure`：
  - 背景色为 black。
  - 网格边缘存在不完整的彩色边框段：某些颜色（如 red、green、blue）各自在网格的上/下/左/右边缘的某一段连续区域铺设了 1 像素宽的边框线（每种颜色只出现在一条边上）。
  - 网格内部散布着若干小型 4-connected 单色精灵（2-4 个像素），每个精灵的颜色与某一个边框段相同。
  - 每个精灵的形状不是对称的：它是一个有"尖端"的形状（例如一个 1x3 的水平条带最右端多一个像素形成箭头状，或一个 L 形，其中一臂比另一臂长）。精灵形状的"长臂"或"尖端"指向某个基本方向（上、下、左、右）。

- `Rule`：
  - 确定每个精灵的"指向方向"：精灵 bounding box 中最长的连续臂所指的方向即为指向方向。如果精灵是 L 形，长臂末端的延伸方向即为指向方向。
  - 每个精灵沿其指向方向的**反方向**整体平移（即精灵"背对着"它的尖端方向移动），保持形状不变，直到精灵的任一像素恰好与同色边框段相邻（4-adjacent）。
  - 停下后，精灵的像素合并到边框中（颜色保持不变），原始位置清除为 black。
  - 如果精灵的指向方向的反方向上没有同色边框，则该精灵不移动。

- `Key insight`：精灵向自己尖端的反方向运动——就像箭头指向"来的地方"而不是"去的地方"。解题者的直觉会认为精灵应该朝尖端方向移动，但对比样例后会发现实际方向恰好相反，这种反直觉的方向编码是核心发现。
</new_puzzle>

<new_puzzle>
- `description`：网格中散布的单像素标记之间的曼哈顿距离决定了在两者中点处绘制的正方形的边长。

- `Input structure`：
  - 背景色为 black。
  - 网格中有若干对同色单像素标记点。每种非 black 颜色恰好出现两个像素，形成一对。可能存在 2-4 对不同颜色（如一对 red、一对 blue、一对 green）。
  - 没有其他前景像素。

- `Rule`：
  - 对每种颜色，找到该颜色的两个像素 A 和 B。
  - 计算 A 和 B 之间的曼哈顿距离 D。
  - 令边长 S = D（如果 D 为偶数）或 S = D - 1（如果 D 为奇数），保证 S 为偶数。
  - 在 A 和 B 的中点（取整到最近的整数坐标）处，以该颜色绘制一个 S x S 的实心正方形，正方形的中心为该中点（即正方形从中点向四周各延伸 S/2 - 1 个像素）。
  - 如果正方形超出网格边界，裁剪到网格范围内。
  - 原始的两个标记像素被正方形覆盖（如果它们在正方形范围内）或保留（如果在范围外）。
  - 当多个正方形重叠时，后绘制的颜色覆盖先绘制的；绘制顺序按 S 值从大到小（即大正方形先画，小正方形后画覆盖在上面）。

- `Key insight`：两个同色点之间的距离不是用来连线或画路径的——它是一个数值参数，控制在中点处生成的几何形状的大小。解题者通常会先尝试连线、画矩形框等直觉方案，但需要发现距离到边长这一非常规的数值映射关系。
</new_puzzle>

<new_puzzle>
- `description`：将网格中的彩色路径视为"管道"，追踪每条管道的走向，在管道每次转弯处放置一个与转弯角度对应的标记色。

- `Input structure`：
  - 背景色为 black。
  - 网格中有若干条由同一种颜色（如 orange）绘制的单像素宽路径。每条路径是一个 4-connected 的像素链，没有分叉（每个像素最多有 2 个同色 4-neighbor）。路径的两个端点各只有 1 个同色邻居。
  - 不同路径之间不接触（彼此不 4-adjacent）。
  - 网格角落处有一个 2x3 的图例区域：第一行放置 red 和 green 两个像素，第二行放置对应的转弯示意——red 下方的示意为一个"直角转弯"（L 形的 2 像素 grey 标记），green 下方的示意为一个"非转弯/直行"（一条 2 像素 grey 直线标记）。这里 red 表示"直角拐弯"，green 表示"直行通过"。

- `Rule`：
  - 对每条路径，从任一端点开始逐像素遍历。
  - 在路径的每一个非端点像素处，检查该像素的前驱和后继方向是否发生了改变（即路径在此处是否转弯）。
  - 如果路径在该像素处发生了 90 度转弯（前驱方向与后继方向垂直），将该像素改为 red。
  - 如果路径在该像素处没有转弯（前驱方向与后继方向相同，即直行），像素保持原色 orange 不变。
  - 端点像素保持 orange 不变。
  - 图例区域在输出中保留不变。

- `Key insight`：路径本身兼做"数据"和"待标注的画布"——解题者需要理解路径的几何走势，并识别出转弯点是被重新着色的对象。图例的作用容易被忽视，但它精确定义了"什么形状被标记为什么颜色"。核心认知路径是：先发现输出中新出现的颜色只在路径的弯折处出现，再与图例匹配确认规则。
</new_puzzle>

<new_puzzle>
- `description`：网格被分成若干矩形房间，每个房间有一扇"门"（墙壁上的缺口）；从起点房间开始，按照房间内彩色箭头的指示依次穿过门进入下一个房间，最终在路径经过的所有门的位置标上特定颜色。

- `Input structure`：
  - 背景色为 black。
  - 网格被 grey 线条分隔成若干不重叠的矩形房间（grey 线条宽度为 1 像素，构成房间的墙壁）。
  - 每个房间的墙壁上恰好有 1-2 个缺口（即 grey 墙壁中断了 1 个像素的位置），这些缺口就是"门"，连通相邻房间。
  - 每个房间内部有且仅有一个由 3 个同色像素组成的箭头形状：一个像素作为箭头杆，两个像素作为箭头头部（形成一个指向上/下/左/右的箭头尖）。箭头的绘制方式为：箭头杆是 1 个像素，位于箭头头部的正后方；箭头头部是 2 个像素，分别位于杆的前方像素的两侧（垂直于指向方向）。例如，一个指向右的箭头：杆在 (r, c)，头部在 (r-1, c+1) 和 (r+1, c+1)。箭头颜色各不相同（颜色不影响规则）。
  - 恰好有一个房间内部有一个额外的 yellow 单像素标记，该房间为起点房间。

- `Rule`：
  - 从起点房间（包含 yellow 标记的房间）开始。
  - 读取当前房间内箭头的指向方向（上/下/左/右）。
  - 在该方向上找到当前房间墙壁上的门（缺口）。如果该方向上有多个门，选择离箭头最近的那个。如果该方向没有门，则寻找最接近该方向的门（优先顺时针偏转90度方向）。
  - 将该门的位置（grey 缺口处的 black 像素）标记为 red。
  - 穿过该门进入下一个房间，重复上述过程。
  - 当到达一个之前已经访问过的房间，或到达一个没有未访问过的相邻房间可去时，停止。
  - 输出网格中：所有墙壁、箭头、背景保持不变；所有被穿过的门的位置从 black 变为 red；yellow 起点标记保留。

- `Key insight`：解题者需要将网格理解为一张"房间地图"，并追踪一条由箭头指引的路径。关键难点在于：箭头不指向目标房间本身，而是指向"该方向上的门"——必须先理解房间的空间结构和门的位置，才能追踪路径。容易让解题者困惑的是箭头颜色各不相同（实际上颜色是干扰项，只有方向有意义），以及要发现路径是一个链式过程而非独立的逐房间操作。
</new_puzzle>

<new_puzzle>
- `description`：根据每个前景对象与最近网格边缘的距离，对该对象施加对应层数的"轮廓膨胀"——越靠近中心的对象膨胀越多层。

- `Input structure`：
  - 背景色为 black。
  - 网格中散布若干个小型单色 4-connected 前景对象（每个对象 2-6 像素），所有对象使用相同颜色（如 azure）。
  - 对象之间有足够的间距（相互之间至少间隔 4 个 black 像素）。
  - 没有其他标记或图例。

- `Rule`：
  - 对每个前景对象，计算其所有像素到最近网格边缘的最小距离 D（取所有像素中的最小值，即该对象离边缘最近的那个像素到边缘的切比雪夫距离，即 min(行号, 列号, 总行数-1-行号, 总列数-1-列号) 的最小值）。
  - 令膨胀层数 L = D（即距离边缘 1 像素的对象膨胀 1 层，距离边缘 3 像素的膨胀 3 层，紧贴边缘 D=0 的不膨胀）。
  - 对该对象执行 L 次"轮廓膨胀"：每次膨胀是将对象当前所有像素的 4-adjacent 的 black 像素变为该对象的颜色，形成一圈新的轮廓。重复 L 次。
  - 如果两个对象膨胀后重叠，重叠像素保持颜色不变（先到先得，按对象在网格中从上到下、从左到右的顺序处理）。

- `Key insight`：直觉上会认为所有对象都经历了相同的膨胀操作，但仔细对比不同样例后会发现靠近中心的对象膨胀得更多，而靠近边缘的对象几乎不变。关键洞见是：对象的"离边缘距离"本身就是控制变换强度的隐式参数——空间位置编码了变换的幅度。
</new_puzzle>

<new_puzzle>
- `description`：网格中包含若干由墙壁分隔的封闭区域和一个"种子色"像素；从种子所在区域开始逐层向外扩散填充，但每穿过一道墙壁进入新的一层区域，填充颜色就按照色带图例前进一步，循环使用。

- `Input structure`：
  - 背景色为 black。
  - 网格中有一组由 grey 像素绘制的墙壁线条，将网格分割成若干个不规则的封闭区域（每个区域是一个 4-connected 的 black 连通域，被 grey 墙壁和/或网格边缘包围）。
  - 墙壁是连续的 grey 像素线，宽度为 1 像素。
  - 恰好一个区域内包含一个 red 单像素标记，即"种子"。
  - 网格右下角有一个 1 行 N 列的色带图例（N 为 3-5），由左至右排列若干种颜色（如 red, blue, green, yellow），展示色环顺序。色带图例用 grey 边框围住，与主网格墙壁区分。

- `Rule`：
  - 种子所在区域（距离种子 0 道墙壁）用色环中第 1 种颜色（色带最左边的颜色）填充所有 black 像素。
  - 与种子区域共享墙壁的相邻区域（BFS 距离 = 1，即需穿过 1 道墙壁）用色环中第 2 种颜色填充。
  - 与那些区域共享墙壁的下一层区域（BFS 距离 = 2）用色环中第 3 种颜色填充。
  - 依此类推。如果色环用完，从头循环（第 N+1 层回到第 1 种颜色）。
  - "共享墙壁"定义为：两个区域之间存在一段 grey 墙壁，墙壁两侧分别有属于这两个区域的像素与该墙壁像素 4-adjacent。
  - 灰色墙壁保持不变。种子标记被同色填充覆盖。色带图例在输出中保留不变。
  - "距离"定义为从种子区域到目标区域需要穿越的最少墙壁数量（即区域邻接图上的 BFS 最短距离）。

- `Key insight`：这道题表面看像简单的洪水填充，但填充色不是固定的——它随着"穿墙次数"变化。解题者需要发现：(1) 颜色按区域整体着色而非按像素逐个变化；(2) 颜色切换的触发条件是跨越墙壁进入新区域；(3) 色带图例定义了颜色循环的顺序。核心认知路径是从"为什么不同区域颜色不同"出发，追踪到与种子区域的拓扑距离。
</new_puzzle>
