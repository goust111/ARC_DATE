<description>
根据封闭区域内部"种子"像素的颜色，在网格边缘找到同色标记以确定镜像方式，然后从边框缺口向外生长出镜像翻转的副本。

Input structure:
- 背景色为 Black。网格中散布若干由同一颜色（如 Blue）绘制的封闭矩形边框（1 像素宽的空心矩形），每个矩形边框恰好有一个缺口（1 像素宽的断开处），缺口处的像素为背景色。
- 每个矩形边框内部正中央有一个"种子"像素，其颜色与 Red、Green、Yellow、Orange 等颜色之一相同。
- 网格边缘（上/下/左/右四条边）上散布着若干单像素标记，颜色各异，每种颜色恰好出现一次，且与某个矩形内部种子像素的颜色一一对应。

Rule:
- 第一层推理：对于每个封闭矩形，找到其边框上的缺口位置（上/下/左/右哪条边）。缺口所在的边决定了"生长方向"——即从缺口向外延伸的方向（缺口在上边则向上生长，在右边则向右生长，以此类推）。
- 第二层推理：在网格边缘上找到与该矩形内部种子颜色相同的标记像素。该标记像素所在的网格边缘（上/下/左/右）决定了副本的"镜像轴"——若标记在上边缘或下边缘，则对矩形做水平镜像（上下翻转）；若标记在左边缘或右边缘，则对矩形做垂直镜像（左右翻转）。
- 最终输出：将镜像后的矩形边框副本（含种子像素一并镜像）沿生长方向紧贴缺口外侧放置，副本的边框颜色改为种子像素的颜色，种子像素本身改为原边框颜色。原矩形保持不变，网格边缘的标记像素被移除（变为背景色）。

Key insight:
解题者需要独立发现两个非显然的对应关系：（1）缺口位置决定生长方向；（2）网格边缘的同色标记决定镜像方式。两层信息缺一不可，单看缺口或单看标记都无法确定最终输出。
</description>
</new_puzzle>

<new_puzzle>
<description>
将网格中部分重叠的多个彩色图案按照底部色带编码的绘制顺序还原完整形状，然后以反转顺序重新堆叠。

Input structure:
- 背景色为 Black。网格中有若干个小型彩色图案（每个图案由单一颜色构成，颜色各不相同，如 Red、Blue、Green、Yellow 等），每个图案为不规则但连通的形状（约 4-8 像素）。
- 这些图案在网格上有部分重叠。在重叠区域，后绘制的图案覆盖先绘制的图案，因此只能看到最上层的颜色。
- 网格底部有一行色带（1 像素高，宽度等于图案数量），从左到右排列着所有图案的颜色，按照原始绘制顺序（最先绘制的在最左）。这行色带不与任何图案重叠，与图案之间至少间隔一行背景色。

Rule:
- 第一层推理：读取底部色带，得到原始绘制顺序（从左到右对应从底层到顶层）。
- 第二层推理：根据该顺序，推断每个图案的完整形状——被遮挡的像素可以通过以下方式恢复：在重叠区域，被更晚绘制的颜色覆盖的像素属于更早绘制的图案。具体地，从最顶层图案开始向下逐层剥离：最顶层图案的可见区域即其完整形状；移除最顶层后，次顶层图案的可见区域加上刚被最顶层覆盖的相邻连通区域构成其完整形状；以此类推。每个图案的完整形状是一个连通区域。
- 第三层推理：将绘制顺序完全反转——原来最先绘制（最底层）的图案变为最后绘制（最顶层），依次类推。用反转后的顺序重新堆叠所有完整图案（位置不变），生成输出网格。底部色带也相应反转顺序。

Key insight:
解题者首先需要意识到底部色带编码了绘制顺序，然后利用该顺序逆向还原被遮挡的完整图案形状，最后将堆叠顺序反转。核心难点在于从部分可见的重叠结果中还原每个图案的完整轮廓，这需要结合绘制顺序和连通性进行推理。
</description>

<new_puzzle>
<description>
网格中散布着若干"旋转盘"（十字形结构带有对角指针），根据指针位置和顺时针规则读取扇区颜色，按阅读顺序填入角落的空白模板。

Input structure:
- 背景色为 Black。网格中分布着若干个"旋转盘"，每个旋转盘由以下部分组成：一个十字形结构，中心为 1 个 Grey 像素，从中心向上、下、左、右各延伸 2 个像素形成四个臂（共 9 个像素的十字）。四个臂各自涂有不同颜色（上臂 2 像素同色、右臂 2 像素同色、下臂 2 像素同色、左臂 2 像素同色），四种颜色互不相同，取自 Red、Blue、Green、Yellow、Orange、Azure 等。
- 每个旋转盘的四个对角位置（中心的左上方 1 格、右上方 1 格、右下方 1 格、左下方 1 格）中，恰好有一个位置放置了一个 Maroon 像素作为"指针"，其余三个对角位置为背景色。
- 网格的某个角落有一个由 Grey 像素绘制的小型模板框架（1 行 N 格的水平格子，N 等于旋转盘的数量），每格为 1x1 像素，格与格之间由 Grey 像素分隔，格子内部为背景色。
- 旋转盘之间互不重叠，按从左到右、从上到下的顺序可以排出明确的阅读序。

Rule:
- 第一层推理：对于每个旋转盘，根据 Maroon 指针的对角位置确定它夹在哪两个相邻臂之间。指针在右上角夹在上臂和右臂之间；在右下角夹在右臂和下臂之间；在左下角夹在下臂和左臂之间；在左上角夹在左臂和上臂之间。
- 第二层推理：确定读取规则——从指针位置出发，沿顺时针方向遇到的第一个臂即为该旋转盘的"读数"。例如指针在右上角，顺时针方向下一个臂是右臂，则读数为右臂的颜色；指针在左下角，顺时针方向下一个臂是左臂，则读数为左臂的颜色。
- 最终输出：按照旋转盘的阅读顺序（从左到右、从上到下），将每个旋转盘的读数颜色依次填入角落模板的对应格子中。其余部分保持不变。

Key insight:
解题者需要首先理解十字形结构是一个有四个彩色扇区的转盘，然后发现对角像素是指向扇区间隙的指针，最后需确定"顺时针取下一个臂"这一读取规则。指针位置与颜色读取之间的映射并不直观——指针并非直接指向某个臂，而是指向两臂之间的间隙，需要通过顺时针约定来消歧。
</description>

<new_puzzle>
<description>
网格被彩色分隔线划分为多个区域，每个区域内有一个小图案；找到颜色唯一的分隔线来定位目标区域对，再根据分隔线方向对该区域对的图案进行叠加组合，结果写入指定输出区。

Input structure:
- 背景色为 Black。网格被若干条 1 像素宽的水平和垂直彩色直线分割成若干矩形区域（如 3x3 或 4x3 的网格布局）。这些分隔线的颜色取自 Red、Blue、Green、Yellow 等，同一方向和位置的分隔线颜色一致且贯穿整行或整列。
- 每个矩形区域内部包含一个小型图案（由 Grey 像素绘制，约 3x3 到 4x4 大小），图案形状各不相同（如 T 形、L 形、十字形、直线段、方块等），在区域内居中放置，周围为背景色。
- 网格右下角的一个区域比其他区域略大，内部为空（全为背景色），由 Maroon 边框单独包围，大小恰好可容纳一个小图案。此区域不与分隔线网格对齐，明显区别于其他区域。
- 所有分隔线中，恰好有一条线的颜色在整个网格中只出现一次（唯一色），其余分隔线的颜色都至少出现两次。

Rule:
- 第一层推理：统计每种分隔线颜色出现的次数，找到颜色唯一的那条分隔线。该线是水平或垂直的，它将两个相邻区域分开——这两个区域是需要操作的"目标对"。
- 第二层推理：根据唯一分隔线的方向确定叠加方式。若该线为水平线（分隔上下两个区域），则将上方区域的图案与下方区域的图案做逐像素叠加——两个图案对齐中心，任一图案在该位置有 Grey 像素则输出为 Grey，否则为背景色。若该线为垂直线（分隔左右两个区域），叠加方式相同，仍为逐像素取并集。
- 最终输出：将叠加后的组合图案写入右下角 Maroon 边框内的空白区域，居中放置。网格其余部分（所有区域的原始图案、分隔线）保持不变。

Key insight:
解题者需要首先在多条分隔线中发现"颜色唯一性"这一隐蔽线索来定位目标区域对，这需要统计和比较，仅看单个样例不容易确认规则；然后理解分隔线方向与叠加操作的关联。两层推理中，第一层的"唯一色筛选"是关键的非显然步骤。
</description>

<new_puzzle>
<description>
网格中有多个彩色图形各自缺失一块边缘；散落的同色碎片需要经过正确旋转后嵌入对应图形的缺口，使图形恢复完整。

Input structure:
- 背景色为 Black。网格中有若干个大型彩色图形（每个图形由单一非 Grey 颜色绘制，颜色各不相同，如 Red、Blue、Green、Yellow 等）。每个图形为连通的填充区域，形状近似矩形或 L 形等简单几何形状（约 5x5 到 8x8 像素），但其边缘上有一处明显的凹陷缺口（缺口为背景色区域，形状不对称，大小约 2x1 到 3x2 像素，凹入图形内部）。
- 网格中另有若干个小型 Grey 边框矩形"托盘"（约 4x4 到 5x5，边框为 1 像素宽的 Grey），托盘之间互不重叠且不与大型图形重叠。每个托盘内部放置一个小型碎片，碎片的颜色与某个大型图形的颜色相同（颜色一一对应，不会有两个托盘内碎片同色）。
- 碎片的形状与对应图形缺口的形状互补（碎片恰好能填满缺口），但碎片在托盘中可能经过了 0 度、90 度、180 度或 270 度的旋转，不一定与缺口当前朝向匹配。碎片形状不对称，因此不同旋转角度下形状不同。

Rule:
- 第一层推理：通过颜色匹配确定每个碎片属于哪个大型图形——碎片颜色与图形颜色相同即为配对。
- 第二层推理：对于每对配对的碎片和图形，确定碎片需要旋转多少度才能精确填入缺口。具体方法：将碎片依次尝试 0 度、90 度（顺时针）、180 度、270 度（顺时针）旋转，找到唯一一种旋转使得碎片形状与缺口形状完全吻合（碎片的像素恰好覆盖缺口的所有背景像素，且不超出缺口范围）。
- 最终输出：将每个碎片从托盘中取出，以正确的旋转角度填入对应图形的缺口位置，碎片像素的颜色与图形颜色一致。托盘被清除——整个托盘区域（包括 Grey 边框和内部）变为背景色。图形的缺口被填满后恢复为完整形状。背景和其他未涉及的像素保持不变。

Key insight:
颜色匹配是直观的第一步，但核心推理在于空间旋转匹配——碎片形状不对称意味着四种旋转中只有一种能正确嵌入缺口，解题者必须在心中将碎片旋转并与缺口形状比对。这种空间推理在多个图形同时存在时尤其考验观察力，因为需要对每一对独立完成旋转匹配。
</description>
</new_puzzle>
