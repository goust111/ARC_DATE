<new_puzzle>
根据对象内部孔洞的拓扑结构选择匹配的填充模板，再将模板图案嵌入孔洞内部。

Input structure
- 背景为主色（如 black）。
- 网格中有若干个由同一前景色（如 green）构成的大型封闭轮廓对象，每个轮廓内部包含一个或多个不同形状的孔洞（被背景色填充的封闭区域）。
- 网格的某个边缘区域（如最右侧几列）排列着若干小型彩色模板图案，每个模板由独特颜色绘制，且模板的外轮廓形状各不相同。
- 每个模板的外轮廓形状恰好与某个轮廓对象内的某个孔洞形状完全一致（平移后吻合）。

Rule
- 对每个大型轮廓对象内的每个孔洞，在模板区域中找到外轮廓形状与该孔洞完全匹配的模板。
- 将匹配到的模板图案（保持其内部细节和颜色）平移并填入对应的孔洞位置。
- 模板区域本身在输出中被擦除为背景色。
- 大型轮廓对象的前景色像素保持不变。

Key insight
解题者不能仅靠模板颜色或大小来匹配，必须识别出孔洞的精确形状并与模板的外轮廓进行形状配对——这是一个"锁与钥匙"式的空间匹配问题，核心推理在于从形状而非颜色建立对应关系。
</new_puzzle>

<new_puzzle>
将散落的单色像素碎片按颜色归组，再根据每组像素数量的排名来决定该组在输出中的排列位置和方向。

Input structure
- 背景为主色（如 grey）。
- 网格中散落着多种颜色的单个像素点（每种颜色出现若干个，数量各不相同，数量范围为 2 到 7）。
- 网格的左下角有一个小型"方向图例"：由 maroon 色绘制的 L 形箭头，箭头的两臂分别指向右和上，表示"排名第一的颜色水平排列在最底行，排名第二的垂直排列在最左列"的交替规则。

Rule
- 统计每种非背景、非图例颜色的像素总数。
- 按像素数量从多到少排名。
- 排名为奇数的颜色（第1、第3、第5...）：将该颜色的所有像素合并为一条水平线段，从输出网格的右下角开始，沿底部向左排列；多个奇数排名的颜色依次向上堆叠（每种颜色占一行）。
- 排名为偶数的颜色（第2、第4、第6...）：将该颜色的所有像素合并为一条垂直线段，从输出网格的右下角开始，沿右侧向上排列；多个偶数排名的颜色依次向左堆叠（每种颜色占一列）。
- 输出网格尺寸恰好能容纳所有排列后的线段，多余区域为背景色。方向图例不出现在输出中。

Key insight
第一层推理是发现需要按颜色计数并排序；第二层推理是从图例的 L 形结构中归纳出奇数排名走水平、偶数排名走垂直的交替排列规则——图例不是装饰，而是编码了排列方向的交替模式。
</new_puzzle>

<new_puzzle>
用网格中的"路标"箭头为每个彩色方块指定传送目的地，再将方块沿箭头链逐跳传递到终点位置。

Input structure
- 背景为主色（如 black）。
- 网格中有若干个 2x2 的实心彩色方块（颜色各不相同，如 red、blue、green 等）。
- 网格中还散布着若干由 orange 色绘制的"路标箭头"：每个箭头由 3 个像素组成，呈 L 形，其中 2 个像素构成箭杆（沿某个轴对齐），1 个像素在箭杆末端的垂直方向偏移一格构成箭头尖端，箭头方向由箭杆指向尖端的方向决定（上、下、左、右四种之一）。
- 每个彩色方块的 4 邻域（上下左右紧邻方块外侧一格）中恰好有一个路标箭头。

Rule
- 对每个彩色方块，找到与其相邻的路标箭头，读取箭头方向。
- 沿箭头方向平移方块，直到方块的边缘抵达另一个路标箭头所在的行或列（即方块移动到下一个路标箭头旁边停下）。
- 到达新位置后，读取这个新路标箭头的方向，继续沿新方向平移，重复上述过程。
- 当方块沿箭头方向移动但前方没有更多路标箭头时，方块移动到网格边缘停下。
- 所有方块同时按各自的箭头链独立移动（不互相阻挡）。路标箭头在输出中保留不变。

Key insight
解题者必须先识别出 L 形像素组合编码了方向信息，然后理解每个方块不是只移动一次，而是沿路标箭头构成的"接力链"逐段传递——核心难点在于追踪多跳传递路径并发现方块在每个路标处改变方向的机制。
</new_puzzle>

<new_puzzle>
根据封闭区域内部的"种子色"确定该区域的生长规则，将区域边界向外扩展，扩展层数等于种子像素的数量，扩展颜色由相邻区域的边界色决定。

Input structure
- 背景为主色（如 azure）。
- 网格中有若干个由不同颜色绘制的单像素厚度的封闭矩形边框（如 red 边框、green 边框、yellow 边框），边框之间不接触，也不嵌套。
- 每个矩形边框内部（被边框围起来的区域）除了背景色外，还包含若干个 maroon 色的"种子像素"，散落在内部的不同位置。不同边框内部的种子数量不同（范围 1 到 4）。

Rule
- 对每个封闭矩形边框，统计其内部 maroon 种子像素的数量 N。
- 以该矩形边框为基础，向外扩展 N 层同心矩形环。每层环的厚度为 1 个像素。
- 所有扩展层的颜色与原始边框颜色相同。
- 扩展过程中，如果某层环的像素会与另一个边框的原始边界或扩展层重叠，则该像素不绘制（先到先得：种子数量少的边框先扩展）。
- 种子像素在输出中被擦除为背景色；原始边框保留。

Key insight
第一层推理是发现内部种子像素的数量控制了边框向外扩展的层数；第二层推理是发现当多个边框的扩展区域冲突时，种子数量较少的边框优先扩展——优先级不是由边框大小或颜色决定，而是由种子计数的反序决定，需要从多个样例中对比冲突区域才能归纳出这一排序规则。
</new_puzzle>

<new_puzzle>
识别网格中由分隔线划分的子区域，在每个子区域内找到唯一的彩色标记，然后根据相邻子区域标记颜色的配对关系决定是否擦除分隔线段。

Input structure
- 背景为主色（如 black）。
- 网格被 grey 色的水平线和垂直线划分为若干矩形子区域（类似棋盘格的分隔方式，但分隔线不一定等距）。灰色线条厚度为 1 像素，贯穿整个网格的宽度或高度。
- 每个子区域内部恰好包含一个单像素的彩色标记（颜色从 red、blue、green、yellow、orange 中取），标记位于子区域内部的任意位置。
- 整个网格中每种标记颜色恰好出现偶数次（即标记颜色成对出现）。

Rule
- 找到所有标记颜色的配对：同色的两个标记构成一对。
- 对于每一对同色标记，找到它们所在的两个子区域之间的所有 grey 分隔线段（即沿从一个子区域到另一个子区域的最短矩形路径上经过的所有分隔线段）。
- 擦除这些分隔线段（将其改为背景色），但仅擦除两个配对子区域之间"共享边界"上的那一段分隔线——即两个子区域若在水平或垂直方向上直接相邻，擦除它们之间的那段 grey 线；若不直接相邻，则不擦除任何线段。
- 所有标记像素在输出中保留不变。
- 不与任何配对关联的分隔线段保持不变。

Key insight
第一层推理是发现同色标记构成配对关系；第二层推理是理解只有当配对标记所在的子区域直接相邻时，才擦除它们之间的分隔墙——这意味着解题者需要同时关注颜色配对和空间邻接两个独立条件的交集，而非简单地连接所有同色标记。对角相邻或隔了多个区域的同色配对不会导致任何擦除，这是区分正确规则的关键陷阱。
</new_puzzle>
