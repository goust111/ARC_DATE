description：根据框架内部孔洞的形状匹配散落的填充碎片，将碎片旋转后嵌入对应孔洞，再用孔洞所在框架的边框颜色重新着色碎片。

Input structure：
- 背景为 black。
- 网格中有若干个由单一颜色绘制的矩形空心框架（边框宽度为 1 像素），每个框架内部存在一个或多个由背景色构成的不规则孔洞（即框架内部某些位置缺失了边框颜色的像素，形成连通的背景色区域）。不同框架使用不同颜色（如 red、blue、green 等）。
- 在框架外部的背景区域中，散落着若干个由 grey 像素构成的小型连通碎片（4-连通）。每个碎片的形状恰好与某个框架内部的某个孔洞形状相同，但可能经过 0/90/180/270 度旋转。
- 碎片数量与所有框架中孔洞的总数量一一对应。

Rule：
- 对于每个框架内部的每个孔洞，在散落碎片中找到形状匹配的那个碎片（可能需要旋转 0/90/180/270 度才能完全吻合）。
- 将该碎片旋转到正确朝向后，填入孔洞的位置，像素颜色从 grey 改为该框架的边框颜色。
- 框架本身和背景保持不变；碎片原始位置恢复为背景色。

Key insight：解题需要两层推理——第一层是通过形状匹配（含旋转）将碎片与孔洞配对，第二层是理解碎片填入后要继承所在框架的颜色而非保留原色。碎片的旋转使得形状匹配不能直接目视比对，需要心理旋转。
</new_puzzle>

<new_puzzle>
description：读取网格边缘的方向箭头标记，沿箭头指示的方向逐层剥离多色嵌套矩形框架，将剥离的层按原始尺寸重新排列到箭头所在边。

Input structure：
- 背景为 black。
- 网格中央有一组同心嵌套的矩形框架，从外到内每层使用不同颜色（如最外层 red、次外层 blue、再内层 green、最内层 yellow），每层框架宽度为 1 像素，层与层之间无间隔（紧密嵌套）。
- 网格的四条边（上、下、左、右）中恰好有一条边上放置了一个由 orange 像素构成的箭头标记。箭头为 3 像素的 V 形：若在上边则尖端朝下（一个顶点像素位于某列，其左下和右下各一个像素），若在下边则尖端朝上，若在左边则尖端朝右，若在右边则尖端朝左。箭头尖端始终指向网格内部方向。

Rule：
- 确定箭头所在的边，该边即为"堆叠目标边"。
- 将嵌套框架从外到内逐层拆解。拆解后，每层框架保持其原始矩形尺寸和颜色。
- 按从外到内的顺序，将各层框架依次紧贴堆叠目标边放置：最外层框架紧贴该边，次外层紧贴最外层内侧，依此类推。若堆叠目标边为上边，则各层从上往下排列；若为左边，则从左往右排列；其余类推。
- 各层框架在堆叠时，沿垂直于堆叠方向的轴居中对齐（与原始嵌套的中心对齐位置一致）。
- 箭头标记在输出中移除。

Key insight：解题者首先需要识别嵌套框架的层次结构及每层的颜色和尺寸，然后理解箭头标记指示的是框架"展开"后的堆叠方向。核心难点在于理解空间展开操作：嵌套的同心结构被拆成独立层后按原始尺寸沿指定方向重新排列，而非简单平移或缩放。
</new_puzzle>

<new_puzzle>
description：根据网格中彩色种子像素的邻域空闲方向生长枝条，枝条长度由同色种子的总数决定。

Input structure：
- 背景为 black。
- 网格中散布着若干单像素的彩色种子点，使用 2 至 4 种不同颜色（如 red、blue、green、yellow）。每种颜色的种子点数量在 2 到 5 之间。
- 每个种子点的上下左右四个方向中，恰好有一个方向是"最大开放方向"——即沿该方向到网格边界的距离最长，且该方向路径上全为 black 像素（无遮挡）。如果存在多个等长的无遮挡方向，则取最先遇到的（按上、右、下、左的优先顺序）。

Rule：
- 统计每种颜色的种子点总数 N。
- 对于每个种子点，确定其最大开放方向。
- 从该种子点出发，沿最大开放方向画一条长度为 N 的直线（种子本身算第 1 个像素，再向外延伸 N-1 个像素），颜色与种子相同。
- 如果枝条在到达长度 N 之前碰到网格边界，则在边界处截断。

Key insight：解题需要两步非显然推理——第一步需归纳出枝条长度等于同色种子的数量（这需要跨多个样例对比同色种子数与枝条长度的关系），第二步需理解每个种子的生长方向由其空间位置决定（选择最长的无遮挡方向）。两个规则维度（长度来源和方向来源）分别编码在不同的视觉特征中。
</new_puzzle>

<new_puzzle>
description：将网格中的多色矩形按颜色图例指定的层叠顺序重新堆叠绘制，重叠区域显示优先级更高的颜色。

Input structure：
- 背景为 black。
- 网格分为左右两个区域，由一列 grey 像素分隔。
- 左侧区域是"图例区"：从上到下排列着若干个单像素色块，每行一个，颜色各不相同（如从上到下依次为 red、blue、green）。图例中的颜色顺序表示层叠优先级，最上方的颜色在最顶层，最下方的在最底层。
- 右侧区域是"拼图区"：包含若干个不同颜色的实心矩形（每个矩形为 4-连通的单色区域）。这些矩形的边界框存在空间重叠——在输入中，重叠区域当前显示的颜色可能并不遵循图例的层叠顺序（即底层颜色可能错误地显示在顶层之上）。

Rule：
- 读取左侧图例，从上到下确定颜色的层叠顺序（上方 = 顶层，下方 = 底层）。
- 对于右侧拼图区中每种颜色，通过其当前可见像素的边界框推断出该颜色矩形的完整范围（即使部分区域被其他颜色遮挡，边界框仍能从可见部分推断）。
- 按图例的层叠顺序重新绘制：先绘制最底层颜色的完整矩形，再依次绘制更高层的完整矩形（后绘制的覆盖先绘制的）。
- 最终输出仅包含右侧拼图区的重绘结果（移除图例区和 grey 分隔线），输出网格的尺寸等于右侧区域的尺寸。

Key insight：输入中重叠区域的显示颜色故意违反图例顺序，形成视觉误导。解题者必须首先理解图例代表"正确的层叠顺序"，然后利用每种颜色可见部分的边界框推断其被遮挡前的完整矩形范围，最后按图例顺序重新渲染遮挡关系。三层推理环环相扣：图例解读、矩形范围推断、层叠重绘。
</new_puzzle>

<new_puzzle>
description：识别被 maroon 标记像素桥接的矩形对象对，将每对对象沿桥接轴线合并为实心矩形，合并后使用面积较小者的颜色。

Input structure：
- 背景为 black。
- 网格中有若干个单色实心矩形对象（4-连通），每个对象使用 red、blue、green、yellow、orange 等颜色之一。不同对象可以使用相同颜色，但每个对象在空间上独立（不相邻不重叠）。
- 某些对象对之间存在恰好一个 maroon 像素作为"桥接标记"。桥接标记位于两个对象之间的空隙中，且与这两个对象在同一行或同一列上对齐——即从标记沿水平或垂直方向分别可以直线到达两个对象，路径上无其他非背景像素。
- 每个对象最多参与一次桥接。
- 未被桥接的对象独立存在，不受影响。

Rule：
- 找到所有 maroon 桥接标记像素。对于每个标记，沿其所在行和列搜索，确定它桥接的两个对象（沿同一轴线方向两侧最近的两个非背景连通对象）。
- 比较被桥接的两个对象的像素面积（即各自包含的像素数量）。选择面积较小的那个对象的颜色作为"合并颜色"。若面积相同，选择在网格中位置更靠上的对象的颜色（若行相同则选更靠左的）。
- 用合并颜色填充两个对象的合并边界框（即包围两个对象的最小矩形）的所有像素，形成一个新的实心矩形。这会覆盖两个原始对象、它们之间的空隙以及桥接标记。
- 未被桥接的对象保持原样，maroon 标记在合并过程中被覆盖。

Key insight：解题有三层推理结构——第一层是识别 maroon 像素的桥接功能（它标记了同轴线上需要合并的对象对），第二层是理解合并操作是将两个对象的合并边界框填充为实心矩形（而非简单连线或拼接），第三层是发现填充颜色取决于两个被桥接对象的面积比较（面积较小者的颜色胜出）。面积比较是人眼通过数像素即可直观判断的视觉量。
</new_puzzle>
