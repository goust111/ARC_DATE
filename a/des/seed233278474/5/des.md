<new_puzzle>
description：根据每个封闭区域内部散落碎片的颜色，从外部色板中查找匹配色条，用该色条的排列方式重新铺设该区域的内部。

Input structure：
- 背景为最常见颜色（如 Black）。
- 网格中有若干由 Grey 线条围成的封闭矩形区域，每个区域内部散落着少量单色像素碎片（颜色各不相同，如 Blue、Red、Green 等）。
- 网格的某一侧（如最右列或最底行附近）排列着若干水平色条（每条由 2-4 个连续像素组成），每条色条恰好包含两种颜色：一种"索引色"和一种"填充色"交替排列。索引色出现在色条的第一个像素位置，填充色出现在其余位置。
- 每种索引色在所有色条中唯一出现一次，且恰好与某个封闭区域内部碎片的颜色相同。

Rule：
- 对每个封闭矩形区域，识别其内部散落碎片的颜色 C。
- 在外部色条中找到索引色为 C 的那一条色条，读取该色条的填充色 F 以及色条的长度 L。
- 将该封闭区域的内部全部清空，然后用填充色 F 画出水平条纹：从区域内部的第一行起，每隔一行绘制一整行 F 色像素，其余行保持背景色。
- 保留所有 Grey 边框线条不变，删除外部色条。

Key insight：区域内碎片的颜色不是最终填充色，而是索引键——解题者需要先建立"碎片色→色条→填充色"的查表映射，再用查到的填充色按条纹规则重绘区域内部。这是两层独立推理：第一层是颜色索引匹配，第二层是条纹填充模式。
</new_puzzle>

<new_puzzle>
description：将网格中每个彩色箭头沿其指向方向发射射线，射线遇到其他箭头时改变方向为被击中箭头的朝向，最终所有射线路径上的像素染成起始箭头的颜色。

Input structure：
- 背景为 Black。
- 网格中散布着若干由非背景色绘制的小箭头（每个箭头占 3×3 区域）。箭头的绘制方式：中心像素着色，加上朝向方向的一个像素着色，再加上朝向方向两侧各一个像素形成箭头尖端。例如一个向右的箭头在 3×3 区域内为：第一行第三列、第二行第一至三列、第三行第三列着色（形成 ">" 形状）。
- 每个箭头有自己的颜色（如 Red、Blue、Green、Orange 等），不同箭头颜色可能相同也可能不同。
- 每个箭头朝向四个正方向之一（上、下、左、右）。

Rule：
- 同时从每个箭头的尖端像素出发，沿箭头朝向发射一条单像素宽的射线。
- 射线逐格延伸，将经过的背景像素染成该射线起始箭头的颜色。
- 当射线到达网格边界时停止。
- 当射线到达另一个箭头的 3×3 占位区域时，该射线停止，但被击中的箭头被"激活"：如果该箭头尚未发射过射线，则立刻从其尖端发射一条新射线，方向为自身朝向，颜色继承击中它的射线的颜色（而非自身原色）。
- 激活过程级联进行，直到没有新箭头被击中。
- 箭头本身的像素保持原色不变。

Key insight：解题者需要发现三层规则——首先识别箭头形状以确定朝向，其次理解射线的级联激活机制（类似多米诺骨牌链式反应），最后发现被激活箭头发射的射线继承的是上游颜色而非自身颜色，这使得颜色沿着激活链传播。
</new_puzzle>

<new_puzzle>
description：根据每个色块在网格中所占行列跨度的奇偶性，决定该色块是保留还是被擦除，然后将所有保留色块沿各自最近的网格边缘方向平移至紧贴边缘。

Input structure：
- 背景为 Black。
- 网格中有若干互不重叠的单色矩形色块（实心填充），颜色各异（如 Red、Blue、Green、Yellow、Magenta 等）。
- 每个色块的宽度和高度各为 1 到 6 个像素不等。
- 色块分布在网格的各个位置，不接触网格边缘。

Rule：
- 对每个矩形色块，计算其行跨度（高度）和列跨度（宽度）。
- 如果行跨度与列跨度的奇偶性相同（都是奇数或都是偶数），则保留该色块；否则擦除该色块（变为背景色）。
- 对每个保留的色块，确定其中心到网格四条边缘的距离，找到最近的那条边缘。
- 将该色块沿垂直于该边缘的方向平移，直到色块的对应边紧贴该网格边缘。色块的形状和大小不变，平行于边缘的坐标不变。
- 如果两个色块平移后会重叠，先平移距离目标边缘更近的色块，后平移的色块紧贴在先到达色块的外侧。

Key insight：第一层隐蔽推理是发现奇偶性过滤规则——解题者需要注意到消失的色块恰好是宽高奇偶性不一致的那些；第二层推理是发现保留色块的移动方向由"最近边缘"决定而非固定方向，需要观察每个色块与四条边缘的相对位置。
</new_puzzle>

<new_puzzle>
description：将网格中由隔板分隔的多个面板视为同一图案的不同遮罩视图，通过叠加所有面板的可见部分还原出被遮挡的完整图案。

Input structure：
- 背景为 Black。
- 网格被若干条单像素宽的 Grey 竖线等距分割成 K 个大小相同的矩形面板（K 通常为 3 或 4）。
- 每个面板内部包含同一个彩色图案的一个"遮罩视图"：图案本身由多种非背景、非 Grey 颜色组成，但每个面板中有若干矩形区域被 Maroon 色的实心矩形遮盖，遮住了图案的一部分。
- 关键约束：任何一个图案像素位置，在所有面板中至少有一个面板没有被 Maroon 遮盖——即所有面板的遮罩合在一起不会同时覆盖图案的同一位置。

Rule：
- 输出为单个面板大小的网格，包含完整的还原图案。
- 对于输出中的每个像素位置 (r, c)，遍历所有面板在该局部位置的像素值：
  - 如果某个面板在 (r, c) 处不是 Maroon 也不是背景色，则输出该面板的颜色。
  - 如果多个面板在同一位置都显示了非遮罩颜色，它们必然相同（因为是同一图案），取任意一个即可。
  - 如果所有面板在该位置都是背景色（即图案本身此处就是空的），输出背景色。
- 不输出 Grey 隔板线和 Maroon 遮罩色。

Key insight：解题者首先需要识别出多个面板展示的是"同一图案的不同部分"而非不同图案——这需要注意到非遮挡区域的像素在面板间是一致的。然后需要理解 Maroon 矩形是遮挡物而非图案本身的一部分，最终通过跨面板信息融合来还原完整图案。核心认知挑战在于从"多个残缺视图"到"信息互补叠加"的推理跳跃。
</new_puzzle>

<new_puzzle>
description：识别网格中每对同色标记点之间的隐含矩形区域，根据矩形内部已有的局部图案，通过旋转对称性补全整个矩形的填充。

Input structure：
- 背景为 Black。
- 网格中有若干对同色的单像素标记点，每种颜色恰好出现两个标记点。可用颜色包括 Red、Blue、Green、Yellow、Orange 等。
- 每对同色标记点定义一个轴对齐矩形的两个对角顶点（即两个标记点分别位于矩形的左上-右下或右上-左下对角）。
- 在每个这样的隐含矩形内部（不含标记点本身所在的边界行列），有一个角落区域（占矩形内部面积的四分之一，即左上、右上、左下或右下象限之一）填充了由 Azure 色像素组成的小图案，其余三个象限为背景色。

Rule：
- 对每对同色标记点，确定它们定义的矩形边界。
- 在矩形内部找到已有 Azure 图案所在的象限。
- 将该 Azure 图案通过 180 度旋转对称复制到对角象限（即左上与右下互为对角，右上与左下互为对角）。
- 再将已有图案分别水平翻转到同行的相邻象限、垂直翻转到同列的相邻象限，从而填满全部四个象限。
- 翻转和旋转后的图案像素颜色改为该矩形对应标记点的颜色（而非保持 Azure）。
- 原始 Azure 图案也改为标记点颜色。
- 标记点本身保留不变。
- 不同颜色对定义的矩形互不重叠。

Key insight：解题者需要依次发现三层规则：第一层是识别同色点对定义矩形区域；第二层是理解 Azure 局部图案需要通过四重对称（水平翻转+垂直翻转+180度旋转）填满整个矩形；第三层是发现填充后的颜色不是 Azure 而是替换为对应标记点的颜色。颜色替换规则使得仅观察单个样例时容易误以为图案本身就是标记色，需要多个样例才能分离出"Azure 是模板色"这一关键信息。
</new_puzzle>
