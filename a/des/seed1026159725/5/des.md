<new_puzzle>
- `description`：根据每个前景对象边界框的宽高比（宽>高、高>宽、或正方形）分别施加不同的几何变换后重新排列。
- `Input structure`：背景为主色。网格中散布若干个不同颜色的单色 4-连通前景对象，形状各异。每个对象的边界框宽高比各不相同，可能是横向矩形（宽>高）、纵向矩形（高>宽）或正方形（宽=高）。
- `Rule`：
  - 横向矩形对象 → 顺时针旋转 90 度，放置在输出网格的左列。
  - 纵向矩形对象 → 水平翻转，放置在输出网格的右列。
  - 正方形对象 → 保持不变，放置在输出网格的中间列。
  - 各列内部对象按原始面积从大到小从上到下排列，对象间以一行背景色分隔。
  - 输出网格宽度为三列对象最大宽度之和加上分隔列。
- `Key insight`：宽高比不仅是分类依据，还隐含了对应的变换操作——解题者需要同时发现分类规则和每类对应的变换方式。
</new_puzzle>

<new_puzzle>
- `description`：在含有路径网络的网格中，找到连接两个端点标记的唯一通路，用端点颜色重新着色该通路，同时将通路经过的交叉点标记为特殊颜色。
- `Input structure`：背景为主色。网格中有一种颜色（如 grey）绘制的一像素宽正交路径网络，形成若干交叉和分支。网络中恰好有两个不同颜色的端点标记像素（例如 red 和 blue），分别位于路径的不同末端。路径网络中可能存在死胡同分支。
- `Rule`：
  - 在路径网络中找到从 red 端点到 blue 端点的唯一简单路径（不经过重复节点）。
  - 将该路径上所有 grey 像素重新着色为 green。
  - 路径经过的每个交叉点（4-邻域中有超过 2 个路径像素的点）额外标记为 yellow。
  - 不在通路上的路径分支保持 grey 不变。
  - 两个端点标记保持原色。
- `Key insight`：路径网络中的死胡同分支是干扰——解题者需要找到真正连通两端点的唯一路径。交叉点的特殊着色增加了第二层规律。
</new_puzzle>

<new_puzzle>
- `description`：将多个面板中的对象按面积排序后叠加到单一画布上，面积最小的对象位于最上层。
- `Input structure`：背景为主色。网格被分隔列分为若干个等宽面板。每个面板内有一个不同颜色的单色前景对象，对象大小各异。所有面板使用相同的背景色。
- `Rule`：
  - 提取每个面板内的前景对象及其相对于面板的局部坐标。
  - 按对象的像素面积从大到小排序。
  - 创建一个单面板大小的输出画布。
  - 按面积从大到小依次将对象绘制到输出画布上（使用其局部坐标），后绘制的覆盖先绘制的。
  - 因此面积最小的对象位于最上层，面积最大的位于最下层。
- `Key insight`：面板的左右顺序是干扰——真正决定叠加层级的是对象面积。小面积在上、大面积在下的叠加顺序是核心规律。
</new_puzzle>

<new_puzzle>
- `description`：在由两种颜色交替填充的棋盘格网格中，找到每个"岛屿"（同色连通区域），根据岛屿面积决定其输出颜色。
- `Input structure`：网格完全由两种颜色（如 blue 和 orange）组成，形成不规则的区域分布（非标准棋盘格）。每种颜色形成若干个 4-连通的区域（岛屿）。每个岛屿面积范围 1~10 像素。
- `Rule`：
  - 找到所有 4-连通的同色区域。
  - 面积为奇数的区域着色为 red。
  - 面积为偶数的区域着色为 green。
  - 面积最大的区域（无论奇偶）着色为 yellow。
  - 如果最大面积有平局，则所有平局区域都着色为 yellow。
- `Key insight`：输入的两种颜色在输出中完全被抛弃——输出颜色由区域面积的奇偶性决定，最大面积区域有特殊规则。解题者需要先发现面积奇偶规律，再发现最大面积的例外规则。
</new_puzzle>

<new_puzzle>
- `description`：网格中的每个彩色对象根据其与同色孤立标记点的相对方位，施加对应方向的 90 度旋转后平移到标记点位置。
- `Input structure`：背景为主色。网格中有若干个多像素的彩色 4-连通前景对象，以及若干个同色的孤立单像素标记点。每种前景色恰好有一个多像素对象和一个单像素标记点。标记点位于对象的严格上方、下方、左方或右方之一。
- `Rule`：
  - 将每种颜色的多像素对象与同色单像素标记点配对。
  - 判断标记点在对象中心的哪个方位（上/下/左/右）。
  - 标记在上方 → 对象旋转 0 度；标记在右方 → 顺时针旋转 90 度；标记在下方 → 旋转 180 度；标记在左方 → 逆时针旋转 90 度。
  - 擦除原对象和标记点，将旋转后的对象放置在标记点位置（标记点对齐到旋转后对象的中心）。
- `Key insight`：标记点不仅是目的地——它相对于源对象的方位编码了旋转角度。解题者需要发现方位-旋转的固定映射关系。
</new_puzzle>
