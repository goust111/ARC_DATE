<description>
根据封闭区域内部的"钥匙"图案，从外部候选印章中选取匹配的印章，将其旋转后嵌入区域的缺口中，完成封闭。

Input structure:
- 背景为 Black。网格中有若干用同一种颜色（如 Green）绘制的不规则封闭框架，每个框架的边界上恰好有一个缺口（连续缺失 2-4 个像素的开口）。
- 每个封闭框架的内部包含一个由另一种颜色（如 Red）绘制的小型图案（称为"钥匙"），钥匙图案的形状各不相同。
- 网格的边缘区域散布着若干由 Magenta 绘制的小型图块（称为"候选印章"），每个候选印章的形状恰好与某个钥匙图案全等（可能经过 0/90/180/270 度旋转）。

Rule:
- 对每个封闭框架，提取其内部的 Red 钥匙图案的形状。
- 在所有 Magenta 候选印章中找到与该钥匙形状全等的那个（允许旋转匹配）。
- 确定框架缺口的位置和朝向，将匹配到的候选印章旋转至正确方向，使其恰好填入缺口（印章像素替换缺口处的 Black 像素，颜色变为框架颜色 Green）。
- 填入后，删除该候选印章原来的位置（变为 Black），同时删除框架内部的 Red 钥匙图案（变为 Black）。
- 未被匹配的候选印章保持不变。

Key insight: 框架内部的钥匙图案不是装饰，而是索引——它指定了哪个外部印章属于该框架；缺口的几何形状则决定了印章需要旋转到哪个朝向才能完成封闭。解题需要两层归纳：先发现钥匙-印章的形状配对关系，再发现印章旋转方向由缺口朝向决定。
</description>

<description>
将散落在网格中的彩色线段按颜色分组，每组线段首尾相接拼成一条完整路径，路径的排列顺序由独立的颜色序列条决定。

Input structure:
- 背景为 Black。网格中散布着若干短线段（长度 2-5 像素的水平或垂直直线），每条线段是单一颜色，颜色种类有 3-5 种（如 Blue、Red、Yellow、Orange）。
- 同一颜色的线段有 2-4 条，它们的端点可以通过平移对齐实现首尾相接（即一条线段的末端像素与另一条线段的首端像素在平移后重合）。
- 网格底部有一行单独的颜色序列条：由若干单像素组成，从左到右每个像素的颜色代表一种线段颜色，指定了各颜色路径在输出中从上到下的排列顺序。

Rule:
- 对每种颜色，找到该颜色的所有线段，通过平移将它们首尾相接拼成一条连续折线路径（每两条相邻线段共享一个端点像素）。拼接顺序是唯一的——只有一种排列能让所有线段无间隙、无重叠地连成一条路径。
- 将每条拼好的路径平移到输出网格中，使路径的起点（最左上角的像素）对齐到网格左侧。
- 各颜色路径按底部序列条从左到右的颜色顺序，从上到下依次排列，路径之间留一行 Black 间隔。
- 输出网格的宽度为最长路径的包围盒宽度，高度为所有路径包围盒高度之和加上间隔行数。

Key insight: 解题的第一层推理是发现同色线段需要像拼图一样首尾拼接成连续路径（拼接顺序由端点匹配唯一确定）；第二层推理是发现底部颜色序列条控制了各路径在输出中的垂直排列顺序。
</description>

<description>
网格中的每个彩色矩形区域是一块"模具"，模具的孔洞图案决定了它如何"冲压"背景层，标记颜色控制正向或反向冲压，最终输出所有模具冲压效果的叠加结果。

Input structure:
- 背景为 Grey。网格中有若干互不重叠的矩形区域，每个矩形由一种非 Grey、非 Black 的颜色填充（如 Blue、Red、Green 等），但矩形内部有若干像素是 Black 的（形成孔洞图案）。
- 每个矩形的正上方紧邻一行中有一个单像素标记，标记颜色为 Yellow 或 Orange，分别代表两种不同的冲压操作。

Rule:
- Yellow 标记表示"正向冲压"：将该矩形内 Black 孔洞的图案复制到输出中对应位置，孔洞像素在输出中变为该矩形的填充颜色（非 Black 部分保持 Grey）。
- Orange 标记表示"反向冲压"：将该矩形内非 Black（即填充色）像素的图案复制到输出中对应位置，这些像素在输出中变为该矩形的填充颜色（Black 孔洞部分保持 Grey）。
- 输出网格尺寸与输入相同。所有矩形区域和标记在输出中消失（变为 Grey），只保留冲压产生的颜色像素。
- 若多个冲压结果在同一像素重叠，后处理的矩形（按从上到下、从左到右的矩形中心位置排序）覆盖先前的结果。

Key insight: 解题的核心在于发现标记颜色控制了"图-底反转"——Yellow 标记让孔洞变成输出图案（正向），Orange 标记让实体部分变成输出图案（反向）。解题者必须先识别这个正/反规则，再理解所有模具的效果叠加在同一个 Grey 画布上。
</description>

<description>
识别网格中由边框围成的多个房间，根据房间之间共享墙壁上的"窗户"（彩色缺口）颜色，将相邻房间的地板重新染成窗户的颜色，冲突时由窗户的空间位置决定优先级。

Input structure:
- 背景为 Black。网格中有一个由 Maroon 像素绘制的连通墙壁网络，将网格分割成若干矩形"房间"（墙壁厚度为 1 像素）。
- 每个房间的内部填充一种颜色（初始地板色），不同房间的地板色可能相同也可能不同。
- 某些相邻房间之间的共享墙壁上有 1-2 个像素被替换为非 Maroon 的颜色（如 Blue、Green、Yellow 等），这些彩色像素称为"窗户"。每面共享墙上最多一个窗户颜色。

Rule:
- 找到所有窗户像素。每个窗户连接两个相邻房间。
- 对于每个窗户，将其两侧的两个房间的地板颜色都重新染成该窗户的颜色。
- 若一个房间被多个不同颜色的窗户影响，则按窗户颜色在该房间边界上出现的位置从上到下、从左到右的顺序，取第一个窗户的颜色。
- 颜色不传播——只有直接与窗户相邻的两个房间受影响，不会链式扩散。
- 墙壁（包括窗户像素）保持不变。

Key insight: 解题的第一层推理是识别墙壁中的非 Maroon 像素不是损坏而是功能性的"窗户"标记；第二层推理是发现窗户颜色决定了其两侧房间的最终地板色，且当冲突时有基于窗户空间位置的优先级规则。解题者需要从样例中同时归纳出窗户的作用和冲突解决机制。
</description>

将网格中的多层嵌套框架"展开"为并排排列的独立框架，每层框架的内部填充颜色由右侧调色板的纵向顺序与嵌套深度的对应关系决定。

Input structure:
- 背景为 Black。网格分为左右两个区域（由一列 Grey 像素分隔）。
- 左侧区域包含一个多层嵌套的矩形框架结构：最外层是一个矩形边框（厚度 1 像素，某种颜色），其内部包含一个更小的矩形边框，以此类推，嵌套 2-4 层。每层边框之间填充 Black。每层边框的颜色各不相同。
- 右侧区域包含一列纵向排列的小色块（每个色块为 1x1 或 2x2 的单色方块），从上到下排列，色块数量等于嵌套层数。

Rule:
- 将左侧嵌套框架逐层拆解：最外层框架为第 1 层，次外层为第 2 层，依此类推。
- 每层框架保持其原始尺寸（包围盒大小），但内部不再包含更深层的框架——内部全部填充为右侧调色板中对应位置的颜色（第 1 层用右侧从上到下第 1 个色块颜色填充，第 2 层用第 2 个色块颜色填充，以此类推）。
- 输出网格中，各层框架按从外到内的顺序从左到右水平排列，框架之间留一列 Black 间隔。
- 每层框架的边框保持其原始颜色不变，仅内部填充色由调色板决定。
- 移除 Grey 分隔列和右侧调色板。

Key insight: 解题需要三层推理：第一层是识别左侧结构为嵌套框架并理解需要逐层拆解；第二层是发现右侧色块纵向顺序与嵌套深度一一对应，作为填充色的调色板；第三层是理解拆解后的每层框架保持原始尺寸（而非裁剪到该层边框大小），内部用调色板颜色替换而非保留原内容。

网格中的箭头指示器指向某个目标对象，将目标对象的形状"投影"到箭头的尾部，箭头本身在输出中消失。

Input structure:
- 背景为 Black。网格中散布着若干小型彩色对象（3-8 像素，形状各异，如 L 形、T 形、方块等），每个对象为单一颜色。
- 网格中还有若干由 Azure 像素绘制的箭头指示器。每个箭头由一条 3-5 像素的直线段（箭头柄）加上末端的一个像素偏移构成箭头尖端，箭头整体呈现明确的指向方向（上、下、左、右四个方向之一）。箭头的绘制方式：柄为一条水平或垂直直线，尖端像素位于柄末端沿指向方向前进一格再向垂直于柄的方向偏移一格的位置（形成">"形状的简化箭头）。
- 每个箭头沿其指向方向延伸，在该方向上最先遇到的彩色对象即为该箭头的目标对象。

Rule:
- 对每个箭头，沿其指向方向找到最近的彩色对象作为目标。
- 将目标对象的形状（相对像素模式）复制到箭头尾端（即箭头柄远离尖端的那一端），使得复制图案的最靠近箭头的边缘紧贴箭头尾端。
- 复制图案的颜色取目标对象的颜色（而非箭头的 Azure 颜色）。
- 箭头本身（Azure 像素）在输出中被移除（变为 Black）。
- 原始目标对象保持不变。

Key insight: 解题的第一层推理是识别箭头的结构并判断其指向方向；第二层推理是发现箭头指向的目标对象的形状被"反向投射"到箭头尾部——箭头不是标记目标，而是将目标的形状搬运到自己的反方向末端。解题者需要先理解箭头的方向语义，再归纳出形状复制的放置规则。
</description>

<description>
网格中的色带编码了折叠指令：沿色带将网格对折，重叠部分按颜色优先级合并，输出为折叠后的单层结果。

Input structure:
- 背景为 Black。网格为矩形，内部散布着各种颜色的像素图案。
- 网格中有一条横跨整个宽度的水平色带（或横跨整个高度的垂直色带），色带为单一颜色（如 Red），宽度为 1 像素。色带将网格分为两半。
- 两半的尺寸可能不等。较大的一半包含更多的图案内容。

Rule:
- 色带是折叠轴。将较小的一半沿色带翻折，叠到较大一半上（类似纸张对折）。
- 翻折后，较小一半的像素与较大一半的对应像素重叠。重叠规则：若两个像素都非 Black，保留较大一半的像素；若只有一个非 Black，保留非 Black 的那个；若都是 Black，保持 Black。
- 较大一半中未被较小一半覆盖的区域（因为较小一半更短）保持原样。
- 色带本身在输出中移除。
- 输出网格尺寸等于较大一半的尺寸。

Key insight: 解题者需要首先识别色带不是装饰而是折叠轴线，然后理解"对折"操作——较小一半的内容被镜像翻转后叠加到较大一半上。关键在于从样例中归纳出折叠方向（总是小半叠向大半）和重叠时的颜色优先级规则（大半一侧优先）。
</description>
</new_puzzle>
