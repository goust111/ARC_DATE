<description>
根据每个封闭区域内部标记像素的颜色，从颜色图例面板中选取对应的小型图案，将其平铺填充到该封闭区域中。

Input structure:
- 背景为主色（black）。网格被分为两个区域：左侧为图例面板，右侧为主画布，两者之间由一列grey分隔线隔开。
- 图例面板中有若干个小型图案（每个图案为3x3或4x4的多色像素块），每个图案左侧紧邻一个单独的颜色标识像素（如red、blue、green等），该像素的颜色即为该图案的"索引色"。
- 主画布中有若干用grey线条围成的封闭区域（形状不规则，但内部面积至少为图案面积的两倍）。每个封闭区域内部恰好有一个与某索引色相同颜色的单像素标记。

Rule:
- 对每个封闭区域，找到其内部标记像素的颜色，在图例面板中匹配同色索引对应的图案。
- 以标记像素所在位置为锚点（锚点对应图案左上角），将该图案在封闭区域内部进行平铺（向右、向下重复），超出封闭区域边界的部分裁剪掉。
- 移除标记像素本身（被图案覆盖）。封闭区域的grey边界线和图例面板保持不变。

Key insight:
解题需要两层推理：第一层是发现左侧面板是颜色索引到图案的映射表；第二层是理解标记像素不仅指定了使用哪个图案，还通过其位置确定了平铺的起始锚点，从而决定图案在区域内的相位偏移。

Key insight:

Input structure:
- 背景为black。网格中央有一个grey色的矩形空心框（框线宽1像素），框的内部被一条水平grey线和一条垂直grey线分为四个等大的象限（左上、右上、左下、右下）。
- 框外的四个方向（上方、下方、左方、右方）各有零或一个单色前景对象（形状各异，颜色各异，每个对象为一个4连通区域）。
- 每个对象距离框边缘至少2个像素。

Rule:
- 位于框上方的对象：进行垂直翻转（上下镜像），然后放入框内的上半部分（左上或右上象限），水平位置保持其相对于框中心竖线的一侧不变。
- 位于框下方的对象：进行垂直翻转，放入框内的下半部分，水平位置同理。
- 位于框左方的对象：进行水平翻转（左右镜像），放入框内的左半部分，垂直位置保持其相对于框中心横线的一侧不变。
- 位于框右方的对象：进行水平翻转，放入框内的右半部分，垂直位置同理。
- 对象放入框内时，紧贴对应的框内壁。框外的原始对象被清除。

Key insight:
解题需要两步推理：第一步是发现对象所在方向决定了翻转轴（上下方向的对象用水平轴翻转，左右方向的对象用垂直轴翻转）——这模拟了"镜面反射入框"的效果；第二步是理解对象在次要方向上的偏移决定了它落入哪个具体象限。
</description>

- 背景为black。网格中有若干个"箭头"对象，每个箭头由一种前景色绘制。箭头的结构为：一个三角形的箭头尖端（3像素宽的等腰直角三角形，例如朝右的箭头尖端为：第一行1像素、第二行2像素、第三行1像素的右侧堆叠）加上一条从三角形底部延伸出的直线箭杆（长2-4像素）。

- 矩形区域的缺口被填满后，该区域恢复为完整矩形。

Key insight:
解题者需要先识别箭头的方向编码（三角形的朝向），理解箭杆是方向指示器而非有效载荷，然后发现箭头尖端的几何形状恰好是目标区域缺口的"拼图块"——箭头既指示了移动方向，其尖端又提供了修补形状。

<description>
在包含多个嵌套矩形框的网格中，根据每层框的颜色在一个独立的颜色序列条中的排列顺序，决定该层框内部的填充内容是保留还是清除，从而产生选择性"剥洋葱"效果。

Input structure:
- 背景为black。网格分为左右两部分，由一列grey分隔线隔开。
- 右侧为主画布，包含一组同心嵌套的矩形框（3-5层），每层框的颜色不同，框线宽1像素。最内层框的内部填充了一种特殊颜色（与所有框色不同）的实心区域。
- 左侧为颜色序列条：一列纵向排列的单像素色块，从上到下排列了主画布中所有框的颜色（顺序可能与嵌套层级不同）。序列条中某些颜色像素的右侧紧邻一个yellow标记像素，另一些则没有。

Rule:
- 读取左侧颜色序列条，识别哪些框颜色带有yellow标记。
- 在右侧主画布中，对于带yellow标记的框层：保留该框线及其内部所有内容不变。
- 对于不带yellow标记的框层：移除该层框线，将原框线位置替换为该框内侧下一层的颜色（如果下一层也被移除，则继续向内查找，直到找到一个保留层或最内层填充色）。
- 最终效果是：被标记的框层保留，未标记的框层"透明化"消失，内部内容向外可见。

Key insight:
解题需要三层推理：第一层是发现左侧序列条是一个查找表，将颜色映射到保留/移除决策；第二层是理解"移除框线"意味着用内层颜色填充而非简单变黑；第三层是处理连续多层被移除时的递归填充逻辑——最终的视觉效果类似于从嵌套结构中有选择地抽取特定层。
</description>

<description>
将网格中的多条折线路径按照路径上嵌入的颜色节点进行分段，然后将每段独立抽出、拉直，按原路径顺序水平排列在输出网格中。

Input structure:
- 背景为black。网格中有一条或多条由grey像素组成的折线路径（4连通，宽度1像素），路径可以有直角转弯。
- 每条路径上嵌入了若干个彩色节点像素（非grey、非black），这些节点将路径自然分割为若干段。路径的两个端点也各有一个彩色节点。
- 不同路径之间不相连，且颜色节点的颜色在同一路径内不重复。

Rule:
- 对每条路径，沿路径从一端到另一端遍历，按遇到彩色节点的顺序将路径分为若干段。每段包含起止两端的彩色节点以及中间的grey像素。
- 计算每段的像素总长度（包含两端节点）。

- 多段从上到下逐行排列，段与段之间间隔一行黑色背景。多条路径之间间隔两行黑色背景。
- 输出网格的宽度为所有段中最长段的长度，较短的段左对齐。

Key insight:
解题者需要先沿折线路径"行走"以确定分段顺序（转弯使得段数和段长不能简单地通过视觉估计），然后理解拉直操作保留的是拓扑长度而非空间位置——核心洞见是折线的几何形状被丢弃，只有路径的连通长度和节点顺序被保留到输出中。

<description>
在网格中识别由彩色边框围成的多个"容器"，根据容器底部开口的宽度和位置，让容器内部的彩色"沙粒"像素在重力作用下从开口漏出，堆积在下方的平台上。

Input structure:
- 背景为black。网格底部有一条横跨整个宽度的maroon色水平线作为"地面"。
- 地面上方有若干个用不同颜色边框画成的矩形"容器"（开口朝下，框线宽1像素）。每个容器的底边有一段缺口（宽1-3像素），缺口两侧的底边框仍然存在。
- 每个容器内部散布着若干个与容器边框同色的单像素"沙粒"。沙粒数量不超过10个。
- 容器悬浮在地面上方，容器底部缺口与地面之间有空白空间。

Rule:
- 清空每个容器内部的所有沙粒像素。
- 对每个容器，将其沙粒从缺口"落下"：在缺口正下方、地面正上方的区域，从地面开始向上逐像素堆叠沙粒，颜色与容器边框色相同。
- 堆叠宽度等于缺口宽度。沙粒逐行填满：先填满最底行（紧贴地面），填满后向上一行继续，直到所有沙粒用完。
- 如果沙粒总数不能整除缺口宽度，最上面一行从左到右部分填充。
- 容器边框保持不变（包括缺口的形状）。

Key insight:
解题需要两层推理：第一层是理解容器的底部缺口既决定了沙粒"漏出"的水平位置，也决定了堆积的宽度；第二层是发现沙粒总数决定了堆积的高度——这实际上是将容器内部的离散像素数量转换为一个矩形堆积的几何形状。
</description>

<description>
在网格中，多个相同形状但不同颜色的对象各自拥有一条同色的"投影线"，根据投影线与对象的相对方向以及投影线的长度，将对象沿该方向复制出一个"影子"副本，并根据投影线的端部标记决定影子是原样还是镜像翻转。

Input structure:
- 背景为black。网格中有若干个小型前景对象（3-5像素的4连通区域），每个对象颜色不同。
- 每个对象的某一侧边缘有一条同色的直线段（水平或垂直，长度2-5像素）从对象延伸出去，称为"投影线"。投影线的起点与对象相邻，终点为远离对象的一端。
- 投影线的终点像素颜色为yellow（而非对象本色），作为终止标记。如果终点像素为orange，则表示需要镜像。

Rule:
- 对每个对象，确定投影线的方向（上、下、左、右）和长度L。
- 在投影线延伸方向上，距离对象原始位置L个像素处，放置该对象的一个副本。
- 如果投影线终点为yellow，副本保持原样；如果为orange，副本沿投影线方向的垂直轴进行镜像翻转（水平投影线→上下翻转，垂直投影线→左右翻转）。
- 副本使用对象的原色绘制。投影线（包括终点标记）被清除为背景色。原始对象保留。

Key insight:
投影线承载三重信息：方向决定副本放置的方位，长度决定副本与原件的间距，终点颜色决定副本是否翻转——解题者需要同时解码这三个维度才能正确生成输出。
</description>
