- `description`：根据围栏颜色区内的"种子"像素数量，将该区域内部填充为对应层数的同心收缩环。

- `Input structure`：
  - 背景为主色（如 black）。
  - 网格中有若干由单一颜色（如 blue）绘制的闭合矩形围栏（宽度为 1 像素的空心矩形框）。
  - 每个围栏内部的背景区域中散布着若干单像素的"种子"，种子颜色与围栏颜色不同（如 red）。
  - 围栏外部可能还有与围栏同色但不构成闭合矩形的零散像素，这些是干扰物。

- `Rule`：
  - 第一步：识别每个闭合矩形围栏，统计其内部种子像素的数量 N。
  - 第二步：从围栏内壁向内逐层收缩，绘制 N 层同心矩形环。第 1 层紧贴围栏内壁，使用种子的颜色（如 red）；第 2 层在第 1 层内壁再收缩一圈，使用围栏的颜色（如 blue）；第 3 层再收缩，回到种子颜色；以此交替。若收缩到中心仍不足 N 层，则停在最内层（即 N 不会超过可绘制的最大层数）。
  - 第三步：移除所有种子像素（它们的位置被环纹覆盖或还原为背景）。围栏本身保持不变，围栏外像素不变。

- `Key insight`：种子像素不是要保留的标记——它们的数量决定了内部填充的环数，而环的颜色在种子色与围栏色之间交替。解题者必须先发现"数种子"这一隐含步骤，再发现"交替色同心环"的填充规则。
</new_puzzle>

- `description`：每个前景对象根据其内部孔洞的形状，在网格中找到形状匹配的独立色块作为"印章"，然后将印章颜色沿孔洞所在方向向外喷射为射线。

- `Input structure`：
  - 背景为主色（如 black）。
  - 网格中有若干较大的单色前景对象（如 green），每个对象内部可能包含一个或多个由背景色构成的孔洞（4-连通的背景区域被对象完全包围）。
  - 网格中还散布着若干较小的独立单色色块（形状各异，颜色各不相同，如 red、yellow、orange 等），这些色块不与任何大对象相邻。
  - 每个小色块的形状（归一化后，即平移到原点）恰好与某个大对象内部的某个孔洞形状一致。

- `Rule`：
  - 第一步：为每个大对象的每个孔洞，在小色块中找到归一化形状匹配的那个色块，记下其颜色 C。
  - 第二步：确定该孔洞相对于所属大对象的方位——孔洞中心比对象中心偏左/偏右/偏上/偏下（取主方向）。
  - 第三步：从大对象外轮廓上、孔洞正对的那一侧边缘的每个像素，向外（远离对象方向）发射一条颜色为 C 的射线，一直延伸到网格边界，但不覆盖其他前景对象或小色块。
  - 小色块本身保持不变，大对象本身保持不变。

- `Key insight`：小色块不是装饰——它们的形状是查找键，颜色是射线颜色；孔洞不仅提供形状匹配的信息，还通过其在对象中的相对方位决定射线的发射方向。解题者需要同时发现"形状匹配确定颜色"和"孔洞方位确定射线方向"两层规则。
</new_puzzle>

<new_puzzle>
- `description`：网格中的彩色路径片段需要根据路口处"信号灯"像素的颜色，选择正确的转弯方向延伸，最终将路径延长至边界。

- `Input structure`：
  - 背景为主色（如 black）。
  - 网格中有若干条由同一种颜色（如 blue）绘制的直线路径片段，每条路径片段为水平或垂直方向、宽度为 1 像素的线段。
  - 某些路径片段的一端终止于一个"信号灯"像素——该像素与路径正交方向上紧邻路径末端，颜色为 red 或 green（不是路径颜色也不是背景色）。信号灯像素位于路径末端的左侧或右侧（相对于路径前进方向）。
  - 每条路径片段的另一端要么连接到网格边界，要么连接到另一条路径片段。

- `Rule`：
  - 第一步：识别每条路径片段的"开放端"——即没有连接到边界或其他路径的那一端。
  - 第二步：在开放端处，检查正交方向上是否存在信号灯像素。若信号灯在路径前进方向的左侧，则路径在此处左转 90°；若在右侧，则右转 90°。
  - 第三步：路径在转弯后继续以路径颜色直线延伸，直到遇到网格边界或另一条已有路径片段为止。
  - 第四步：若延伸后的新路径末端又遇到一个信号灯像素，重复上述转弯与延伸过程，直到路径到达网格边界。
  - 信号灯像素在输出中保持不变。

- `Key insight`：信号灯的空间位置（左/右）不是绝对的，而是相对于路径当前前进方向定义的——解题者必须先推断出每条路径片段的"行进方向"（从已连接端指向开放端），然后才能正确解读信号灯的含义。多次转弯形成的折线路径使得方向感需要持续追踪。
</new_puzzle>

- `description`：将散落的彩色碎片按照"框架模板"中标注的颜色槽位拼入，但每个碎片需要先根据其边缘缺口的位置确定唯一的旋转角度。

- `Input structure`：
  - 背景为主色（如 black）。
  - 网格左侧（或上方）有一个由 grey 像素构成的大型矩形"框架模板"，模板内部被划分为若干矩形槽位，每个槽位的边缘有一个单像素的颜色标记（非 grey、非背景色），标记颜色各不相同。
  - 网格右侧（或下方）散布着若干彩色碎片，每个碎片是一个小矩形色块（单色，颜色与某个槽位标记一致），但碎片的某一条边上有一个单像素的缺口（该位置为背景色）。
  - 每个槽位恰好比对应碎片大出一圈（即碎片尺寸 + 四周各留 1 像素背景间距），且槽位内部当前为背景色。

- `Rule`：
  - 第一步：通过颜色匹配，将每个碎片分配到对应颜色标记的槽位。
  - 第二步：观察每个槽位的颜色标记位于槽位的哪一侧边缘（上/下/左/右）。
  - 第三步：旋转碎片（0°/90°/180°/270°），使碎片上的缺口朝向槽位标记所在的那一侧。
  - 第四步：将旋转后的碎片居中放入槽位中。
  - 碎片原来的位置还原为背景色。框架模板和颜色标记保持不变。

- `Key insight`：颜色匹配只完成了碎片到槽位的分配；缺口方向与标记方向的对齐才决定旋转角度。解题者需要先发现"颜色 = 分配键"，再发现"缺口必须面向标记"这一旋转规则——两层规则缺一不可。
</new_puzzle>

<new_puzzle>
- `description`：网格中的多个"容器"对象各自包含不同数量的彩色球，需要根据球的数量将容器按从少到多的顺序重新排列，同时容器的开口方向决定球在输出中的排列轴。

- `Input structure`：
  - 背景为主色（如 black）。
  - 网格中有若干个"容器"对象，每个容器由 grey 像素构成 U 形的三面围边（即一个矩形缺少一条边），开口朝上/下/左/右之一。
  - 每个容器内部包含若干单像素的彩色球（每个容器内球的颜色都一致，不同容器球色不同）。球的数量在 1-5 之间。
  - 容器之间互不重叠，散布在网格各处。

- `Rule`：
  - 第一步：统计每个容器内部球的数量。
  - 第二步：按球数从少到多对容器排序（球数相同时按输入中的行优先顺序）。
  - 第三步：构造输出网格，将排序后的容器依次水平排列（左到右为球数递增），容器之间间隔 1 列背景色。
  - 第四步：关键变换——在输出中，每个容器的球不再画在容器内部，而是从容器开口方向向外排成一条直线。球的排列起点紧贴开口边缘外侧，每个球占一个像素，依次向外延伸。容器本身（grey 围边）保持原样。
  - 输出网格高度取所有容器加上最长球列所需的最大高度，宽度取所有容器并排加间隔的总宽度。

- `Key insight`：球的数量决定排列顺序（第一层推理），但球在输出中的空间布局由容器开口方向决定（第二层推理）。解题者容易只注意到排序规则，而忽略球从内部"倒出"到开口外侧这一空间变换。
</new_puzzle>

<new_puzzle>
- `description`：网格中的彩色像素对通过"镜面墙"反射连接——找到每对同色像素之间的镜面墙段，然后沿反射路径画线将它们相连。

- `Input structure`：
  - 背景为主色（如 black）。
  - 网格中有若干条由 grey 像素构成的直线墙段（水平或垂直，宽度 1 像素），墙段可能不连续。
  - 散布着若干成对的同色像素（每种非背景、非 grey 颜色恰好出现两个像素），这些像素不在墙上。
  - 每对同色像素之间无法用直线连接（被墙段阻挡），但恰好可以通过在某一段墙上做一次镜面反射（入射角 = 反射角，45° 对角线反射）实现连接。

- `Rule`：
  - 第一步：对每对同色像素 A 和 B，找到它们之间的连接路径——从 A 发出一条 45° 对角线射线，该射线撞击某段墙后发生镜面反射（水平墙使垂直分量翻转，垂直墙使水平分量翻转），反射后的射线恰好经过 B。
  - 第二步：沿该反射路径（A → 墙上反射点 → B）画出该颜色的像素线。路径上的每个经过的单元格都涂上该颜色。
  - 第三步：墙段本身不变，反射点处墙的像素也不变（线在墙的紧邻像素处终止，不覆盖墙本身）。

- `Key insight`：同色像素对的连接不是直线也不是 L 形绕路——而是严格的光学反射路径。解题者必须识别出墙段充当镜面，然后对每对像素验证唯一的反射几何关系。核心难点在于发现"反射"这一非显然的空间机制，而非路径搜索。
</new_puzzle>

<new_puzzle>
- `description`：网格被分成若干矩形区域，每个区域内有一个"指针"箭头和一个"目标"色块；将每个区域内的色块搬移到指针所指向的相邻区域中，放置在该相邻区域的镜像对称位置。

- `Input structure`：
  - 背景为主色（如 black）。
  - 网格被 maroon 色的水平线和垂直线均匀分割成 N×M 个大小相等的矩形区域（类似九宫格或更大的网格）。
  - 每个矩形区域内包含两个元素：
    1. 一个由 3 个像素组成的 L 形"指针"箭头（由 red 像素构成），指向上/下/左/右之一（L 的短边指示方向）。
    2. 一个小型彩色色块（2×2 或 3×1 等小形状，颜色各不相同，非 red 非 maroon 非背景色），位于区域内的某个位置。
  - 所有区域的指针都指向一个有效的相邻区域（不会指向网格外部）。

- `Rule`：
  - 第一步：识别每个区域中指针的朝向，确定其指向的相邻区域。
  - 第二步：计算色块在当前区域内的相对位置（相对于区域左上角的偏移量）。
  - 第三步：将色块从当前区域移除，放置到指针所指的相邻区域中。放置时，色块的位置要做一次关于指针方向轴的镜像翻转——若指针向右，则色块在目标区域中的列坐标做左右镜像（相对于区域中心）；若指针向下，则行坐标做上下镜像；以此类推。
  - 第四步：如果目标区域已有来自其他区域的色块被搬入，后到的色块叠加在上方（覆盖）。指针本身在输出中移除（变为背景色）。分割线保持不变。

- `Key insight`：指针给出了色块的传送方向，但色块到达目标区域后的放置位置不是简单复制——而是沿传送方向轴做了镜像翻转。解题者需要先发现"指针 = 传送方向"（第一层），再发现"到达后做方向轴镜像"（第二层），两步缺一都无法完全还原输出。
</new_puzzle>
