<new_puzzle>
description：根据封闭区域内部标记像素的颜色，从颜色图例中查找对应的填充模板，将模板平铺填满该区域。

Input structure：
- 背景为主色（Black）。
- 网格中有若干由同一种边框颜色（Grey）围成的封闭矩形区域，每个区域内部大部分为背景色，但包含一到两个散落的彩色标记像素。
- 网格右侧或底部有一个图例区，图例区由若干小方块组成，每个小方块左上角第一个像素的颜色为索引色，其余像素构成一个 2×2 或 3×3 的填充模板（模板内可含多种颜色）。

Rule：
- 对每个封闭矩形区域，找到其内部所有标记像素的颜色（忽略背景色和边框色）。
- 若区域内只有一种标记颜色，在图例中找到索引色与之匹配的模板。
- 若区域内有两种标记颜色，将两个对应模板逐像素叠加：第二种颜色的模板中非背景像素覆盖第一种模板的对应位置（按标记像素在区域内从左到右的出现顺序决定先后）。
- 用最终模板从区域左上角开始周期性平铺，填满整个区域内部（不覆盖边框）。
- 图例区和边框保持不变。

Key insight：标记像素的颜色是查图例的键，而非填充色本身；多标记时需要按空间顺序叠加模板再平铺，解题者必须先发现"颜色→模板"的映射关系，再发现多标记的叠加规则。
</new_puzzle>

<new_puzzle>
description：将每个彩色对象沿其内部箭头形孔洞指示的方向平移，平移距离等于同色对象的个数，到达目标位置后对象之间按面积从大到小的顺序分层堆叠。

Input structure：
- 背景为 Black。
- 网格中分布着若干单色 4-连通对象，每个对象内部恰好有一个由背景色像素构成的箭头形孔洞。箭头形孔洞由三个背景像素组成：一个中心像素和两个分别位于中心像素同侧相邻位置的像素，三像素排列形成一个指向某方向的尖角，尖角的开口方向（上、下、左、右之一）即为箭头指向。
- 同一种颜色可能出现多个对象。

Rule：
- 对每种颜色，统计该颜色的对象总数 N。
- 每个对象沿其内部箭头指向的方向平移 N 个像素。
- 平移后若多个对象占据同一像素，面积较大的对象在下层，面积较小的对象覆盖在上层（即小对象的颜色优先显示）。
- 箭头孔洞在平移后的对象中保留。

Key insight：平移方向由对象自身的孔洞形状编码，而平移距离由全局的同色对象计数决定；解题者需要分别发现方向编码机制和距离机制这两层独立规则。
</new_puzzle>

<new_puzzle>
description：在网格中找到所有同色边缘像素对，将每对像素之间用 L 形管道连接，管道在交叉处按端点间边缘跨度的优先级叠加。

Input structure：
- 背景为 Black。
- 网格边缘分布着若干彩色像素，每种颜色恰好出现两个像素，分别位于网格的不同边（上、下、左、右边缘）。
- 网格内部有若干 Grey 像素作为障碍物。

Rule：
- 对每种颜色，找到其两个边缘像素，画一条从一个像素到另一个像素的 L 形路径（先沿一个轴方向走到与目标像素对齐的行或列，再转弯沿另一轴走到目标像素）。
- L 形路径的转弯方向选择规则：优先选择不经过障碍物的路径；若两个方向都不经过障碍物，选择先水平后垂直的路径。
- 路径上的所有像素染为该颜色。
- 当两条不同颜色的路径在同一像素交叉时，保留两端像素沿网格边缘顺时针方向走的较长弧所对应的那条路径的颜色。

Key insight：每对同色像素的连接方式是确定性的 L 形管道，而交叉冲突的解决依赖于端点对在边缘上的顺时针弧长跨度——这是一个需要从样例中归纳的隐含优先级规则。
</new_puzzle>

<new_puzzle>
description：根据网格中散布的彩色矩形的空间包含关系构建层级树，再将树结构渲染为嵌套的同心矩形框。

Input structure：
- 背景为 Black。
- 网格中有若干不同颜色的实心矩形色块，它们可能相互嵌套（一个矩形完全位于另一个矩形内部），但不会部分重叠。
- 每种颜色只出现一个矩形。
- 网格的一个角落（如右下角）有一个单色指示像素，其颜色为某个矩形的颜色，标记该矩形为"根节点"。

Rule：
- 根据空间包含关系，将所有矩形组织成一棵树：如果矩形 A 直接包含矩形 B（即 B 在 A 内部且没有其他矩形 C 使得 B 在 C 内且 C 在 A 内），则 B 是 A 的子节点。
- 从角落指示像素确定根节点。
- 输出网格为正方形，边长等于矩形总数的两倍减一。
- 从外向内绘制同心矩形框：根节点颜色画最外层的一像素宽边框，根节点的子节点按照它们在输入中的面积从大到小依次画内层边框，每层向内缩进一像素。
- 子节点的子节点紧接在父节点边框之后继续向内嵌套，深度优先、面积优先。

Key insight：输入的空间包含关系是一棵隐含的层级树，解题者需要先从嵌套矩形中提取树结构，再理解输出的同心框是树的深度优先遍历渲染——两步都需要非平凡的归纳。
</new_puzzle>

description：识别网格中每个封闭环的旋转对称阶数，用该阶数在底部颜色图例中查找对应颜色，替换环中心的灰色像素。

Input structure：
- 背景为 Black。
- 网格中分布着若干由彩色像素围成的封闭环形对象（环为一像素宽的闭合回路，形状各异），每个环在其几何中心位置有一个待着色的 Grey 像素。
- 网格底部有一行颜色图例：从左到右依次排列若干种颜色，位置间隔一个背景像素。第 1 个颜色对应旋转对称阶数 1（即无旋转对称），第 2 个对应阶数 2（即 180° 旋转后与自身重合），第 4 个对应阶数 4（即 90° 旋转后与自身重合），中间未使用的位置为背景色。

Rule：
- 对每个封闭环，检测其像素集合的旋转对称性：将环的像素集合分别绕其几何中心旋转 90°、180°、270°，找到最高的旋转对称阶数 k（即旋转 360°/k 后形状与自身完全重合的最大 k 值，k 取自 1、2、4）。
- 在底部图例中找到第 k 个位置的颜色。
- 将环中心的 Grey 像素替换为该颜色。
- 环本身、图例和背景保持不变。

Key insight：解题者必须先识别每个环的旋转对称阶数这一几何属性，再通过图例将阶数映射为颜色——对称性判断和图例查找构成两层独立的推理。
</new_puzzle>

<new_puzzle>
description：将输入网格中的多条彩色折线按照交叉点处的上下穿越关系重新着色，使每条折线在每个交叉点交替执行"上穿"和"下穿"，呈现编织效果。

Input structure：
- 背景为 Black。
- 网格中有若干条一像素宽的彩色折线（每条折线为一种独特颜色），折线由水平和垂直线段组成，在转角处直角转弯。
- 折线之间存在交叉（两条折线的路径共享同一个像素位置），交叉点处的像素当前全部显示为 Grey 作为待定标记。
- 每条折线的两个端点位于网格边缘。

Rule：
- 对每条折线，沿其从一端到另一端的方向遍历，记录它经过的所有交叉点（即 Grey 像素的位置）。
- 折线的起始端定义为行号更小的端点；若行号相同则取列号更小的端点。
- 从起始端出发，该折线在第一个交叉点为"上穿"（交叉点显示该折线颜色），第二个交叉点为"下穿"（交叉点显示另一条折线的颜色），依此交替。
- 每个交叉点恰好有两条折线经过；若两条折线在同一交叉点都标记为"上穿"，则取起始端行号更小的折线优先显示。
- 非交叉点的像素保持原折线颜色不变。

Key insight：解题者需要先识别出 Grey 像素是两条折线的交叉点，再发现每条折线沿自身路径交替上下穿越的编织规则——交叉点识别和交替穿越模式是两个需要分别归纳的推理层。
</new_puzzle>

<new_puzzle>
description：将散落的彩色碎片通过旋转匹配拼入灰色模板的孔洞中。

Input structure：
- 背景为 Black。
- 网格左半部分有若干个由 Grey 像素构成的实心矩形模板，每个模板内部有一个不规则的背景色孔洞（形状各异，均为 4-连通区域）。
- 网格右半部分散落着若干个彩色碎片（每个碎片为一种独特颜色的 4-连通区域），碎片的形状恰好等于某个模板孔洞旋转 0°、90°、180° 或 270° 后的形状。
- 每个碎片恰好匹配一个模板孔洞，每个孔洞恰好被一个碎片匹配，不存在歧义。

Rule：
- 对每个彩色碎片，在所有模板孔洞中找到其形状经旋转后能精确匹配的唯一孔洞。
- 将碎片旋转到正确的角度后，放入对应模板的孔洞位置中，碎片颜色保持不变。
- 右半部分的碎片原始位置清除为背景色。
- 模板的 Grey 像素和其余背景保持不变。

Key insight：碎片与孔洞之间不是直接的形状匹配，而是需要尝试旋转才能找到唯一嵌合方式；解题者需要在心中旋转碎片进行形状比对来确定匹配和放置方式。
</new_puzzle>
