- `description`：根据封闭围栏内部的种子颜色，选取对应颜色图例中的填充纹理，将围栏内部填满该纹理。

- `Input structure`：
  - 背景为黑色。
  - 网格上方有一组"颜色图例"：每个图例由一个小矩形纹理图案（3×3 或 4×4，用某种非背景色绘制）和紧贴其下方中心列的一个单独彩色像素（种子色）组成。不同图例的纹理图案形状各不相同，种子色也各不相同。
  - 网格下方有若干用灰色像素围成的封闭围栏（一像素宽的闭合矩形框）。每个围栏内部恰好有一个单独的彩色像素（种子像素），其颜色与某个图例的种子色相同。围栏内部其余位置为背景色。

- `Rule`：
  - 第一步：对每个围栏，读取其内部种子像素的颜色，在上方图例区找到种子色相同的图例，获取该图例的纹理图案。
  - 第二步：将该纹理图案以平铺方式填充围栏内部的全部空间（种子像素本身也被覆盖）。平铺时纹理图案的左上角与围栏内部区域的左上角对齐，向右向下重复铺设，超出围栏内部的部分截断。纹理使用图例中纹理原本的颜色绘制。
  - 灰色围栏本身保持不变；图例区域保持不变。

- `Key insight`：种子像素不是装饰，而是查表键——它将围栏映射到上方图例区的特定纹理。解题者需要先建立"种子色→纹理形状"的映射关系，再将纹理平铺填入对应围栏，两步推理缺一不可。

- `Input structure`：
  - 背景为黑色。
  - 网格中有若干用不同颜色绘制的一像素宽矩形空心框架（如红色框、蓝色框），每个框架内部全为背景色。
  - 网格中还有若干灰色的小型 4-连通碎片（不规则形状，面积 2-6 像素）。
  - 每个灰色碎片的正旁边（上下左右之一，间隔恰好一格）有一个绿色单像素箭头标记。箭头标记相对于碎片的方位指示了碎片的滑动方向（例如绿色标记在碎片的左侧，表示碎片向左滑动）。
  - 每个碎片沿滑动方向直线平移后，其边界像素恰好会接触到某一个框架的内侧边缘（紧贴框架内壁）。

- `Rule`：
  - 第一步：确定每个碎片的滑动方向——绿色标记在碎片的哪个方向，碎片就向该方向滑动。
  - 第二步：将碎片沿该方向平移，直到碎片的前缘像素紧贴目标框架内壁（碎片完全落入框架内部）。
  - 第三步：碎片着色——碎片不再使用灰色，而是使用它所进入的那个框架的边框颜色来绘制。
  - 原位置的灰色碎片和绿色标记被擦除（变为背景色）。框架边框保持不变。

- `Key insight`：绿色标记既不是装饰也不是颜色线索，而是方向编码器；碎片的最终颜色由目的地框架决定，而非自身颜色。解题者需要同时推断方向机制和颜色重映射机制。
</new_puzzle>

- `description`：每个彩色对象根据自身包含的孔洞数量，在对应行的信号灯格中点亮相应数量的灯。

- `Input structure`：
  - 背景为黑色。
  - 网格左侧有若干彩色的 4-连通对象（面积 8-20 像素），每个对象内部可能包含 0 到 3 个被对象像素完全包围的背景色"孔洞"（每个孔洞为一个 4-连通的背景色区域，完全被该对象的像素封闭）。不同对象颜色不同。
  - 网格右侧有一列竖直排列的"信号灯格"：每行有 3 个水平排列的灰色小方格（1×1 像素），行数与左侧对象数量相同。信号灯格各行从上到下的排列顺序与左侧对象从上到下的排列顺序一一对应（按对象的最高像素行坐标排序）。

- `Rule`：
  - 第一步：对左侧每个彩色对象，数其内部孔洞的数量 N（0 ≤ N ≤ 3）。
  - 第二步：在右侧对应行的信号灯格中，从左到右将前 N 个灰色方格改为该对象的颜色，其余方格保持灰色。
  - 左侧对象保持不变。

- `Key insight`：解题者需要识别出"孔洞"这一拓扑特征（而非对象的面积、颜色或外形），并将其与右侧信号灯的点亮数量关联。孔洞数量是视觉上可数的（最多 3 个），但需要主动观察对象内部的封闭空间。

- `description`：将连接线两端的对象互换位置，且每个对象到达新位置后必须旋转为原先占据该位置的对象的朝向。

- `Input structure`：
  - 背景为黑色。
  - 网格中有若干成对出现的彩色小型对象（面积 3-5 像素），每对中的两个对象颜色相同、形状相同但朝向不同（朝向为 0°、90°、180°、270° 四种之一，例如一个 L 形的四种旋转变体）。
  - 每对对象之间由一条与该对颜色相同的一像素宽直线段（水平或竖直）相连。连接线的两端分别接触两个对象。
  - 不同对之间颜色不同，互不接触。

- `Rule`：
  - 对每对通过连接线相连的同色对象 A 和 B，交换它们的位置：将 A 平移到 B 的原始锚点位置，将 B 平移到 A 的原始锚点位置（锚点定义为对象边界框的左上角）。
  - 交换位置后，A 采用 B 原先的朝向（旋转状态），B 采用 A 原先的朝向。
  - 连接线保持不变（因为互换后两端点的几何距离不变）。

- `Key insight`：解题者容易注意到位置交换，但朝向也同步交换是隐蔽的第二层规则。仅交换位置而不改变朝向会得到错误答案——必须注意到每个对象"继承"了目标位置原有对象的旋转状态。
</new_puzzle>

- `Input structure`：
  - 背景为黑色。

  - 第一步：从上方对照区提取所有颜色映射对。每对旗帜中左旗色块颜色为原色，右旗色块颜色为目标色，建立映射表。

- `Key insight`：上方的旗帜对不是装饰，而是颜色替换字典。解题者需要先从成对旗帜中归纳出"旧色→新色"的映射表，再将该映射应用于下方模板——两个步骤都需要主动推理：第一步需发现配对关系和映射方向，第二步需正确应用查表替换。

- `description`：识别每个容器的开口方向，将对应方向上最近的自由色块吸入容器内部并填满容器。

- `Input structure`：
  - 背景为黑色。
  - 网格中有若干用蓝色像素绘制的"容器"：每个容器是一个三面封闭、一面开口的矩形凹槽（类似 U 形、倒 U 形、左 C 形或右 C 形，壁厚一像素），内部为背景色。开口方向为上、下、左、右之一。容器内部空间为矩形，宽和高各 2-4 像素。
  - 网格中还散落着若干小型单色实心方块（2×2 或 3×3），每个方块的颜色各不相同（红色、绿色、黄色、maroon 等）。这些方块未与任何容器接触。
  - 每个容器的开口方向延伸出去，沿该方向在同一行或同一列上恰好有一个自由色块与容器开口对齐（色块的行范围或列范围与容器开口范围有重叠）。

- `Rule`：
  - 第一步：确定每个容器的开口方向（观察蓝色边界哪一面缺失即可判断）。
  - 第二步：从容器开口沿开口方向向外搜索，找到第一个对齐的自由色块。
  - 第三步：擦除该自由色块的原始位置（变为背景色），将容器内部空间全部填充为该色块的颜色。
  - 蓝色容器壁保持不变。

- `Key insight`：容器的开口方向是隐含的空间线索——它既决定了"吸入"的搜索方向，又筛选了候选色块。解题者必须先推断开口方向的识别规则，再据此完成定向匹配和颜色填充，形成"方向判定→定向搜索→填充"的三层推理链。
</new_puzzle>
