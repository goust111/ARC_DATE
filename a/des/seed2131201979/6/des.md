<new_puzzle>
description：根据框架内部的彩色种子像素反推其所属的模板轮廓，再用轮廓内的孔洞数量决定输出中该轮廓的缩放倍率，最终将所有缩放后的轮廓按孔洞数从多到少从左到右拼接输出。

Input structure：
- 背景为 black。
- 网格上半部分包含若干小型镂空模板（每个模板是一个由单一非背景色绘制的封闭矩形轮廓，轮廓线宽 1 像素，内部可能有 1 至 4 个同色像素形成"孔洞桩"——即轮廓内部的非背景像素点）。每个模板使用不同颜色。
- 网格下半部分有一个较大的 grey 矩形边框（线宽 1 像素）。
- 边框内部散布着若干彩色像素点，每个像素的颜色与上方某个模板颜色相同。这些像素的位置恰好落在该模板轮廓内某个孔洞桩的对应相对位置上（即种子像素记录了模板内部孔洞桩的局部偏移）。

Rule：
- 第一步：对边框内每个彩色种子像素，根据颜色找到上方对应模板。
- 第二步：统计每个模板轮廓内部的孔洞桩数量 H。
- 第三步：将每个模板以 H 倍像素缩放（每个原始像素变为 H×H 的同色块），但只保留轮廓线像素的缩放结果（内部孔洞桩不绘制到输出中）。
- 第四步：将所有缩放后的轮廓按 H 值从大到小、从左到右排列，轮廓之间间隔 1 列 black，生成输出网格（高度取最大缩放轮廓的高度，较矮的轮廓顶部对齐）。

Key insight：
- 种子像素的作用不是被复制，而是用来把颜色与模板配对；真正决定输出的是模板内部的孔洞桩数量，它同时充当缩放因子和排序键——解题者需要先完成颜色配对，再发现孔洞数的双重角色。
</new_puzzle>

<new_puzzle>
description：识别被噪声打断的环形路径，用路径的旋转方向决定内部填充颜色，再根据环内封闭面积裁剪出对应大小的输出方块。

Input structure：
- 背景为 azure。
- 网格中有若干由不同颜色绘制的闭合环形路径（路径宽度 1 像素，由上下左右相邻像素组成 4-连通环路）。
- 每条路径上恰好有 1 至 2 个像素被替换成了 grey（噪声断点），使路径表面上看起来不闭合。
- 网格左下角有一个 2×1 的图例：上方像素为 red，下方像素为 green。

Rule：
- 第一步：对每条路径，将 grey 噪声像素恢复为该路径颜色（通过两端邻居均为同色来识别），使路径重新闭合。
- 第二步：沿闭合路径行走，判断旋转方向——顺时针或逆时针（沿路径行走时，左转多于右转为逆时针，右转多于左转为顺时针）。
- 第三步：根据图例，顺时针路径的内部填充 red，逆时针路径的内部填充 green。路径本身的颜色保持不变。
- 第四步：输出网格仅保留所有路径及其填充区域的最小外接矩形裁剪，背景仍为 azure。

Key insight：
- grey 噪声的修复是第一层推理（需要发现断点规律），路径旋转方向决定填充色是第二层推理（需要归纳图例与方向的对应关系），两层都需要从样例中主动发现非显然规律。
</new_puzzle>

description：将散落的彩色碎片按颜色归入对应的容器格子，碎片在容器内的放置位置由容器边框上的缺口方向决定。

Input structure：
- 背景为 black。
- 网格中有若干个大小相同的正方形容器（边长 5 像素的 grey 矩形边框，内部 3×3 为背景色）。每个容器的边框上恰好有一个 1 像素宽的缺口（某条边的中间像素缺失）。
- 每个容器的边框四角之一被涂成了一种非 grey 非背景色的标记色（每个容器标记色不同）。
- 网格中还散布着若干小型彩色碎片（每个碎片是 1 至 3 个同色 4-连通像素组成的小形状），碎片颜色与某个容器的标记色相同。

Rule：
- 第一步：通过颜色匹配，将每个碎片分配给对应标记色的容器。
- 第二步：确定容器缺口所在的边（上、下、左、右）。
- 第三步：将碎片放入容器内部 3×3 区域，放置规则为：碎片从缺口方向"滑入"容器，紧贴缺口对面的内壁。具体地，碎片保持原始形状不旋转，沿缺口朝向容器内部的方向平移，直到碎片的最远端像素接触对面内壁。碎片在垂直于滑入方向的轴上居中放置（若无法精确居中则偏向标记角所在的一侧）。
- 第四步：输出网格与输入大小相同，容器和碎片就位后，原始散落碎片的位置清除为背景色。

Key insight：
- 颜色配对只是入门，缺口方向决定滑入轴向是第一层需要归纳的规律，标记角位置作为居中歧义的 tie-break 是第二层需要发现的隐蔽规则。
</new_puzzle>

<new_puzzle>
description：用分隔线将网格切成区域，每个区域内的散点图案作为"邮票"印到由锚点颜色指定的目标区域中，印章的朝向由锚点在区域内的相对象限决定。

Input structure：
- 背景为 black。
- 网格被 1 像素宽的 grey 十字分隔线（一条水平线和一条垂直线贯穿全格）切成四个矩形区域。
- 每个区域内包含：（a）若干同色像素组成的一个小图案（邮票），（b）恰好 1 个不同于邮票颜色的单像素锚点。
- 锚点的颜色与另一个区域中的邮票颜色相同（形成跨区域颜色配对）。每个区域的邮票颜色各不相同。

Rule：
- 第一步：通过颜色匹配建立配对——区域 A 的锚点颜色 = 区域 B 的邮票颜色，意味着区域 B 的邮票将被印到区域 A 中。
- 第二步：确定区域 B 中锚点位于邮票外接矩形的哪个象限（左上、右上、左下、右下）。这决定邮票的旋转：左上 = 不旋转，右上 = 顺时针 90°，右下 = 180°，左下 = 逆时针 90°。
- 第三步：将旋转后的邮票绘制到区域 A 中，以区域 A 的锚点位置为邮票外接矩形的中心。邮票颜色保持区域 B 中的原色。
- 第四步：输出网格保留 grey 分隔线，各区域仅显示印入的邮票（原区域的邮票和锚点均清除）。

Key insight：
- 跨区域颜色配对是第一层推理，锚点象限编码旋转角度是第二层推理，两者结合才能确定最终输出——单独看任何一个区域都无法推断完整规则。
</new_puzzle>

<new_puzzle>
description：通过门像素的颜色选择通道方向，将信号色从发射端沿通道传播到接收端，接收端的形状根据通道转弯次数发生变形。

Input structure：
- 背景为 black。
- 网格中有若干条由 grey 像素组成的直线通道（宽 1 像素），通道之间通过单像素"门"连接（门是一个非 grey 非背景色的像素，恰好连接两条正交通道的端点）。
- 每条通道网络的一端有一个 2×2 的同色方块作为"发射端"，发射端颜色与通道中所有门的颜色均不同。
- 每条通道网络的另一端有一个 2×2 的 maroon 方块作为"接收端"。
- 不同通道网络之间无连接。

Rule：
- 第一步：从发射端出发，信号沿 grey 通道传播。到达门像素时，信号转入门所连接的另一条正交通道继续传播。
- 第二步：记录信号从发射端到接收端经过的门的数量 T（即转弯次数）。
- 第三步：将接收端的 2×2 maroon 方块变形——若 T=0，保持 2×2 方块；若 T=1，变为 3×1 竖条（向通道到达方向的反方向延伸 1 像素）；若 T=2，变为 1×3 横条（同理延伸）；若 T≥3，变为十字形（中心 1 像素加四方向各延伸 1 像素）。变形后的形状使用发射端的颜色绘制，替代原 maroon。
- 第四步：输出网格中，通道和门保持不变，发射端保持不变，仅接收端发生上述变形和变色。

Key insight：
- 门的存在不仅是路径连接器，其数量隐式编码了接收端的几何变形规则；解题者需要先理解信号沿通道-门网络的传播路径（第一层），再发现转弯次数与输出形状的映射关系（第二层），最后注意到输出颜色来自发射端而非通道（第三层）。
</new_puzzle>

<new_puzzle>
description：在棋盘格背景上，根据每个彩色块与最近同色块的相对方位，在两者之间绘制 L 形连接线，连接线的拐弯方向由块的面积奇偶性决定。

Input structure：
- 背景为由 blue 和 azure 交替组成的棋盘格（1×1 像素粒度）。
- 棋盘上放置若干矩形彩色块（每个块为单色，颜色非 blue 非 azure，面积 2 至 6 像素不等）。
- 每种非背景色恰好出现两个块，形成配对。两个配对块不在同一行也不在同一列（保证连接线为 L 形而非直线）。

Rule：
- 第一步：对每对同色块，确定两者外接矩形中心的行列差，连接线从一个块的中心出发到另一个块的中心，形成一个直角拐弯的 L 形路径（先水平后垂直，或先垂直后水平）。
- 第二步：计算该颜色两个块的总像素面积之和。若总面积为偶数，L 形路径先水平后垂直（拐点与起点同行、与终点同列）；若总面积为奇数，L 形路径先垂直后水平（拐点与起点同列、与终点同行）。
- 第三步：用该对块的颜色绘制 L 形连接线（线宽 1 像素），覆盖棋盘格背景。连接线不包括块本身已有的像素。
- 第四步：输出网格保留棋盘格背景、所有彩色块，以及新绘制的 L 形连接线。

Key insight：
- 配对块的颜色匹配是显而易见的，但 L 形拐弯方向的决定因素是两块面积之和的奇偶性——这需要解题者对比多个样例中不同拐弯方向的案例，才能发现面积和的奇偶规律，而非简单的位置关系。
</new_puzzle>

<new_puzzle>
description：根据边框上彩色刻度标记的间距推断网格分割方式，将内部图案按分割区域重新排列，排列顺序由每个区域内特殊标记像素的颜色在色谱中的可见排序决定。

Input structure：
- 背景为 black。
- 网格最外圈是 1 像素宽的 grey 边框。
- 边框的顶边和左边上各有若干单像素彩色刻度标记（非 grey 非 black），顶边刻度标记指定垂直切割线的列位置，左边刻度标记指定水平切割线的行位置。
- 这些切割线将边框内部划分为若干矩形区域。
- 每个矩形区域内有一个由 orange 像素组成的小图案（形状各异），以及恰好 1 个非 orange 非背景的单像素标记点。各区域的标记点颜色互不相同。

Rule：
- 第一步：根据顶边和左边的刻度标记位置，在边框内部画出隐含的切割线，将内部分成 R 个矩形区域。
- 第二步：提取每个区域的标记点颜色，按照以下固定可见色序排列：red, orange, yellow, green, blue, magenta, maroon（即色谱从暖到冷再到暗）。注意 orange 图案像素不算标记点。
- 第三步：创建输出网格——将所有区域裁剪出来（保留区域内 orange 图案和标记点），按标记点颜色在上述色序中的顺序，从左到右、从上到下以行优先方式排列到一个紧凑网格中。区域之间用 1 像素 grey 间隔分隔。每个区域统一缩放或裁剪到相同大小（取所有区域的最大宽度和最大高度），较小区域用 black 填充空余部分。

Key insight：
- 边框刻度标记隐式定义了分割线是第一层推理（刻度位置不在内部画出，需要解题者自己推断）；标记点颜色决定重排顺序是第二层推理；两层结合才能完成从输入到输出的变换。
</new_puzzle>
