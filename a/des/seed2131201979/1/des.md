<description>
根据彩色锚点之间的连线方向，将网格中散落的灰色形状沿对应方向滑动并嵌入同色边框的矩形容器内部。

Input structure：
- 背景为黑色。
- 网格中分布着若干单色矩形边框（仅边框，内部为背景色），每个边框使用不同的非灰色前景色（如红色、蓝色、绿色等）。
- 每个矩形边框的某一条边上恰好有一个单像素缺口。
- 网格中另有若干灰色的小型连通形状（4-连通，面积不超过 5 像素）。
- 每个灰色形状旁边恰好有一个与某个矩形边框同色的单像素"锚点"，锚点与灰色形状 4-相邻。
- 锚点颜色在所有矩形边框中唯一匹配一个边框。

Rule：
- 对每个灰色形状，找到其相邻锚点的颜色，匹配到对应颜色的矩形边框。
- 确定该矩形边框缺口所在的边（上、下、左、右）。
- 将灰色形状沿缺口朝向的反方向（即从缺口外侧穿过缺口进入内部的方向）平移，直到形状完全位于矩形边框内部且紧贴缺口对面的那条边。
- 形状进入后，用边框颜色填充缺口像素，封闭边框。
- 原灰色形状所在位置和锚点像素清除为背景色。
- 没有匹配灰色形状的矩形边框保持不变。

Key insight：锚点颜色是形状与容器的配对密钥，而缺口位置同时编码了滑入方向和最终停靠位置；解题者需先通过颜色匹配建立对应关系，再从缺口推断运动方向——两步推理缺一不可。
</description>

<description>
在网格中，每个封闭区域内的小色块充当"邮票"，将其图案按区域边界上标记线段的数量进行重复平铺，覆盖整个封闭区域。

Input structure：
- 背景为黑色。
- 网格中有若干由蓝色像素围成的封闭矩形区域（蓝色像素构成完整的矩形边框，内部为背景色）。
- 每个矩形边框的外侧某些边上附有短小的橙色线段（1-3 像素长，紧贴边框外侧且与边框平行）。
- 每个封闭矩形内部恰好包含一个由非蓝色、非橙色前景色构成的小型矩形图案（"邮票"），位于矩形内部的某个角落，面积不超过 3×3。

Rule：
- 对每个蓝色矩形区域，数出其外侧附着的橙色线段的数量 N。
- 将矩形内部的邮票图案提取出来。
- 若 N 为偶数，将邮票在矩形内部沿水平方向重复平铺，直到填满矩形内部的整个宽度（超出部分裁剪）。
- 若 N 为奇数，将邮票在矩形内部沿垂直方向重复平铺，直到填满矩形内部的整个高度（超出部分裁剪）。
- 平铺从邮票原本所在的角落开始，逐行或逐列复制邮票。
- 蓝色边框和橙色标记保持不变。

Key insight：橙色线段的数量不是简单的重复次数，而是通过奇偶性决定平铺方向——这要求解题者先计数再判断奇偶，两个认知步骤共同决定输出模式。
</description>

<description>
网格中散布的彩色"种子"像素根据其所处的同心环层数生长为对应边长的实心正方形，生长方向由种子相对于网格中心的象限决定。

Input structure：
- 背景为黑色。
- 网格为正方形（边长为奇数，如 11×11、13×13 等）。
- 网格中央有一个灰色单像素标记，标示网格中心。
- 围绕中心有若干以灰色绘制的同心正方形环（仅环的边框，宽度为 1 像素），环与环之间间隔 1 像素背景色。从内到外依次为第 1 环、第 2 环……
- 在某些环上或环内的区域中，散布着若干彩色单像素种子（每个种子颜色各不相同，不使用灰色和黑色）。

Rule：
- 对每个彩色种子像素，确定它位于第几层环（若在第 k 层环的边框上或在第 k 层与第 k+1 层之间的间隔区域内，则归属于第 k 层）。中心灰色像素到第 1 环之间的区域归属于第 1 层。
- 种子生长为边长等于 k 的实心正方形，颜色与种子相同。
- 生长方向：种子相对于网格中心所处的象限决定正方形的展开锚点——右下象限以种子为左上角展开，左下象限以种子为右上角展开，右上象限以种子为左下角展开，左上象限以种子为右下角展开（即向远离中心的方向生长）。
- 若种子恰好在水平或垂直轴线上，则视为相邻的顺时针方向的象限。
- 生长后的正方形不会超出网格边界（可以假设输入保证这一点）。
- 灰色同心环和中心标记在输出中被清除为背景色，仅保留生长后的彩色正方形。

Key insight：解题者需要先识别同心环结构并确定每个种子的环层归属（决定生长尺寸），再根据象限判断生长方向——环层提供"多大"，象限提供"往哪长"，两条独立线索共同决定输出。
</description>

<description>
将网格中由不同颜色连通区域组成的"拼图碎片"按照边界颜色匹配规则拼接，然后根据拼接后形成的封闭回路内外关系重新着色。

Input structure：
- 背景为黑色。
- 网格中散布着若干矩形色块，每个色块由两种颜色组成：内部填充色（占据大部分面积）和边缘标记色（沿色块的一条或两条边绘制，宽度为 1 像素）。
- 每种边缘标记色恰好出现在两个不同色块上（即标记色成对出现）。
- 色块之间互不接触，间隔至少 2 像素背景。

Rule：
- 找到所有边缘标记色的配对：对每种标记色，找到共享该标记色的两个色块。
- 将配对的两个色块平移，使它们的同色标记边紧密相邻（标记边面对面贴合，标记像素相邻但不重叠）。拼接顺序：从网格中最左上的色块开始，依次拼接。
- 拼接完成后，所有标记色像素重新着色为灰色，形成灰色边界线。
- 检查灰色边界线是否围成了封闭区域：
  - 被灰色边界线完全包围的内部填充区域保持原色不变。
  - 未被灰色边界线完全包围的填充区域（即与网格边界连通）重新着色为 Azure。
- 输出为拼接后所有色块的最小外接矩形（紧凑裁剪），背景为黑色。

Key insight：边缘标记色是拼接配对的密钥（第一层推理），而拼接后灰色边界的拓扑封闭性决定了区域的最终着色（第二层推理）——解题者必须先完成空间拼接，再判断封闭关系。
</description>

<description>
网格中的彩色路径网络将信号从"源"节点传播到"终"节点，路径交叉处的颜色混合规则决定最终每段路径的输出颜色。

Input structure：
- 背景为黑色。
- 网格中有若干由单一颜色绘制的 1 像素宽路径（4-连通线段），颜色包括红色、蓝色、黄色等。
- 每条路径的一端有一个 2×2 的同色实心方块（"源"节点），另一端有一个 2×1 或 1×2 的同色条形标记（"终"节点）。
- 某些路径在中间会与其他路径交叉（共享一个像素点）。交叉点处的像素在输入中显示为灰色。

Rule：
- 从每个源节点沿路径追踪到其终节点。
- 当路径经过灰色交叉点时，该路径"吸收"在同一交叉点交叉的另一条路径的颜色。
- 颜色吸收规则（基于视觉直觉的混合）：红色 + 蓝色 → Magenta；红色 + 黄色 → 橙色；蓝色 + 黄色 → 绿色。相同颜色交叉保持不变。
- 吸收发生后，从交叉点到终节点的路径段全部重新着色为混合后的新颜色。
- 若一条路径经过多个交叉点，则依次吸收（从源到终的顺序），每次用当前累积颜色与新交叉路径的原色混合。
- 源节点的 2×2 方块颜色保持不变；终节点的条形标记颜色更新为路径到达时的最终颜色。
- 未经过任何交叉点的路径颜色保持原样。
- 灰色交叉像素在输出中保持灰色。

Key insight：解题者需要先识别路径的源和终（通过端点形状区分），再沿路径追踪交叉点的颜色混合序列——端点形状编码了信号方向，交叉点的灰色标记揭示了混合位置，最终颜色是沿路径累积混合的结果。
</description>

<description>
网格中每个彩色形状的"影子"被投射到一面灰色"镜墙"上，影子的投射方向由形状内部的单像素箭头标记决定，影子长度由形状的面积决定。

Input structure：
- 背景为黑色。
- 网格中有一条贯穿整个网格的灰色直线（水平或垂直），宽度为 1 像素，充当"镜墙"。
- 镜墙两侧分布着若干彩色实心形状（4-连通，每个形状为单一非灰非黑颜色）。
- 每个形状内部恰好有一个与形状颜色不同的单像素标记（箭头标记），该标记的颜色为 Maroon。Maroon 标记在形状内部的相对位置编码了投射方向：标记位于形状最左列 → 向左投射；最右列 → 向右投射；最上行 → 向上投射；最下行 → 向下投射。

Rule：
- 计算每个形状的面积（像素数，不含 Maroon 标记）。
- 根据 Maroon 标记的位置确定投射方向。
- 从形状朝投射方向看，在镜墙表面上找到形状在该方向上的正交投影区域（即形状在镜墙上的"影子范围"——形状沿投射方向投影到镜墙上覆盖的那些灰色像素）。
- 从该投影区域出发，沿投射方向的反方向（即远离形状的一侧）延伸，长度等于形状面积的像素数，用形状的颜色绘制实心矩形条带。条带的宽度等于投影区域的宽度。
- 原始形状和 Maroon 标记保持不变。
- 镜墙上被投影覆盖的灰色像素保持灰色。

Key insight：Maroon 标记的相对位置是方向编码（第一层推理），形状面积转化为影子长度（第二层推理），而镜墙既是投影面又是反射分界线——影子出现在形状的对侧。
</description>

<description>
网格中的多个"迷宫房间"各自包含一个彩色起点和一个出口标记，将每个房间的内壁按照从起点到出口的最少转弯路径依次染色。

Input structure：
- 背景为黑色。
- 网格被灰色墙壁分割成若干矩形"房间"（灰色像素构成 1 像素宽的网格线，将整个网格划分为规则的矩形单元）。
- 某些相邻房间之间的灰色墙壁上有 1 像素的缺口（"门"）。
- 每个房间内部为背景色，部分房间的内部包含一个彩色单像素"起点"标记，以及在该房间某面内壁（紧贴灰色墙壁的内侧一圈像素位置）上有一个同色的单像素"出口"标记。
- 起点标记位于房间内部非墙壁相邻的位置，出口标记位于墙壁相邻的位置。

Rule：
- 对每个包含起点和出口的房间，找到从起点到出口的路径：路径沿 4-连通方向行走，只经过该房间内部的背景色像素。
- 在所有可达路径中，选择转弯次数最少的路径（转弯定义为行进方向改变）。若转弯次数相同，选择总长度最短的。
- 将该路径上的所有像素染为起点/出口的颜色。
- 不含起点和出口的房间保持不变。
- 灰色墙壁和门保持不变。

Key insight：解题者不需要计算精确距离，而是视觉上识别"最少拐弯"的路径——在矩形房间中，这等价于找到一条最多两段的折线路径（先水平再垂直，或反之），核心在于通过起点和出口的相对位置判断最自然的行走路线。
</description>

<description>
每个彩色对象根据其内部"指示孔洞"的形状在网格边界上找到匹配的凹槽，然后将自身颜色填充到该凹槽中。

Input structure：
- 背景为黑色。
- 网格四周的边界由灰色像素构成一圈宽度为 2 像素的边框。
- 灰色边框的内侧表面上有若干凹槽——即边框中缺失像素形成的小型凹陷区域（每个凹槽为一个连续的缺口，形状各异，深度为 1 像素，宽度 1-4 像素）。
- 网格内部（边框围成的区域内）散布着若干彩色实心形状（4-连通，每个形状为单一颜色）。
- 每个彩色形状内部恰好有一个由背景色构成的孔洞（形状像素完全包围的背景色区域）。每个孔洞的形状与边框上某个凹槽的形状完全一致（无需旋转或翻转）。

Rule：
- 提取每个彩色形状内部孔洞的形状（像素图案）。
- 在灰色边框的凹槽中找到与孔洞形状完全匹配的凹槽（形状和大小一致，不旋转不翻转）。
- 用该彩色形状的颜色填充匹配的凹槽像素。
- 原始彩色形状和灰色边框的其余部分保持不变。
- 每个孔洞形状恰好匹配一个凹槽，一一对应。

Key insight：形状内部的孔洞不是缺陷而是"钥匙"，凹槽是"锁"——解题者需要先发现孔洞与凹槽的形状对应关系（第一层推理），再用形状颜色作为填充色完成凹槽填色（第二层推理）。这与参考题中"外部精灵填充内部孔洞"的逻辑恰好相反。
</description>
