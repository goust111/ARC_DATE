- `description`：根据封闭区域内部的种子颜色选择对应的边框图案模板，用该模板替换区域的边框。
- `Input structure`：背景为最常见颜色。网格中有若干用grey像素绘制的封闭矩形边框，每个矩形内部恰好有一个非背景、非grey的种子像素。网格边缘或角落处放置着若干"图案模板"——每个模板是一条短的装饰线段（由交替排列的两种颜色组成，如red-black-red或green-black-green），模板的第一个像素颜色即为该模板的标识色。
- `Rule`：
  1. 识别每个grey封闭矩形边框及其内部的种子像素颜色。
  2. 在网格边缘找到标识色与种子颜色相同的图案模板。
  3. 将该矩形的grey边框替换为对应模板的周期性重复：沿矩形边框顺时针方向，用模板的颜色序列循环填充每个边框像素。
  4. 种子像素保留不变，模板本身在输出中被擦除为背景色。
- `Key insight`：种子像素不是装饰，而是查找键——它将每个矩形与远处的边框样式模板配对；解题者需先发现种子颜色与模板标识色的对应关系，再理解模板如何沿边框周期性铺设。
</new_puzzle>

- `description`：将散落的彩色碎片按形状互补关系拼合，再按拼合体的面积从小到大垂直堆叠到输出网格中。
- `Input structure`：背景为black。网格中散布着若干彩色像素块（4-连通分量），每个分量的颜色各不相同。这些分量恰好可以两两配对：同一对中的两个分量形状互补，即将其中一个平移后与另一个合并恰好形成一个无间隙的实心矩形。每对分量中两个颜色不同。
- `Rule`：
  1. 找到所有4-连通的彩色分量，计算每个分量的bounding box。
  2. 将分量两两配对：两个分量的bounding box尺寸相同，且将一个分量叠加到另一个分量上后，二者像素恰好互补（填满整个bounding box，无重叠无间隙）。
  3. 合并每对分量为一个矩形，矩形中每个像素保留其原始颜色。
  4. 按每个拼合矩形的面积从小到大排序，将它们从上到下垂直堆叠在输出网格中，相邻矩形之间留一行背景色间隔，左对齐。
- `Key insight`：碎片的形状本身编码了配对信息——互补形状是唯一的匹配依据；解题者需先通过视觉直觉识别哪些碎片能拼成矩形，再按面积排序堆叠，两步推理缺一不可。
</new_puzzle>

- `description`：沿每个箭头指向的方向将箭头体拉伸至撞到同色锚点，然后用锚点颜色填充箭头扫过的矩形区域。
- `Input structure`：背景为最常见颜色。网格中有若干"箭头"和若干"锚点"。箭头由5个同色像素组成：一个3像素的横排或竖排作为箭头头部，加上从中间像素向后延伸的2个像素作为箭杆（整体呈T字形，T的横笔画指向前进方向）。锚点是孤立的单个彩色像素（与所有箭头颜色不同）。每个箭头的前进方向上恰好有且仅有一个锚点。
- `Rule`：
  1. 识别每个箭头及其朝向（T字横笔画所指方向即为前进方向）。
  2. 沿前进方向找到该箭头射线上最近的锚点。
  3. 将箭头头部的3像素宽度保持不变，从箭头头部沿前进方向拉伸至锚点所在行/列（含锚点），形成一个3×L的实心矩形（L为箭头头部到锚点的距离加1）。
  4. 该矩形使用锚点的颜色绘制。箭杆像素被擦除为背景色。原箭头头部像素也被锚点颜色覆盖。锚点本身被包含在矩形中。
- `Key insight`：箭头的朝向决定拉伸方向，但最终颜色不来自箭头自身而来自目标锚点——解题者需先从T形结构推断方向，再发现颜色来源于锚点而非箭头，这是两个独立的非显然发现。
</new_puzzle>

- `description`：根据彩色路径的拓扑连接关系对区域重新着色——两条路径若共享一个交叉点则它们的颜色混合。
- `Input structure`：背景为black。网格中有若干条由不同颜色绘制的单像素宽路径（水平或垂直线段的组合），路径之间可能在某些像素处交叉。交叉点处像素为grey，表示此处有两条路径重叠。网格中还有若干用背景色包围的封闭矩形区域（边框为grey），每个区域内部全为背景色。每个封闭区域恰好被两条不同颜色的路径从外侧触碰（路径的端点4-邻接到区域边框）。
- `Rule`：
  1. 识别所有彩色路径（同色4-连通像素链，grey交叉点同时属于所有经过它的路径）。
  2. 对于每条路径，追踪其经过的grey交叉点，确定它与哪些其他路径共享交叉。
  3. 识别每个grey边框封闭区域，找到4-邻接触碰该区域边框的两条路径的颜色。
  4. 如果这两条路径之间存在至少一个grey交叉点（即它们在某处交叉），则将该封闭区域内部填充为这两条路径中在ARC调色板中排列靠前的颜色（调色板顺序：blue, red, green, yellow, grey, magenta, orange, azure, maroon）。
  5. 如果两条路径之间不存在交叉点，则填充为调色板中排列靠后的颜色。
- `Key insight`：区域的填充色不仅取决于哪两条路径触碰它，还取决于这两条路径在网格其他位置是否发生交叉——解题者必须追踪全局路径拓扑关系才能确定局部区域的颜色，这需要先发现"路径交叉"这一隐蔽条件，再理解颜色选择规则。
</new_puzzle>

<new_puzzle>
- `description`：将网格中的多层嵌套框架拆解，按嵌套深度将每层框架平铺到输出网格的独立行区域中，最外层在最上方。
- `Input structure`：背景为black。输入网格中有一组同心嵌套的矩形框架（每个框架是1像素宽的矩形环），每层框架颜色不同，框架之间填充背景色。框架严格嵌套：最外层框架的bounding box最大，最内层最小，且每层框架的中心大致对齐。最内层框架内部可能有一个实心的单色小矩形作为核心。
- `Rule`：
  1. 识别所有矩形框架层，从外到内编号为第1层、第2层……直至最内层的核心实心矩形。
  2. 输出网格的宽度等于最外层框架的宽度，高度等于所有层高度之和加上层间的1行背景色间隔。
  3. 从输出网格顶部开始，将最外层框架（第1层）水平居中放置；然后空一行背景色，放置第2层框架（也水平居中）；依此类推直到核心矩形。
  4. 每个框架保持原始颜色和原始尺寸（宽度和高度不变），仅进行垂直拆分和重新排列。
- `Key insight`：输入看起来是一个复杂的多色同心图案，解题者需要认识到每种颜色对应一个独立的矩形环层，然后发现输出是将这些层按深度顺序垂直展开——这要求先完成"嵌套层识别"的结构分析，再执行"按序平铺"的空间重排，两层推理相互依赖。
</new_puzzle>

<new_puzzle>
- `description`：每个彩色像素向其最近的同色像素方向生长出一条射线，射线长度等于两者之间的空格数；不同颜色的射线交叉处变为yellow。
- `Input structure`：背景为black。网格中稀疏分布着若干彩色像素，每种非背景颜色恰好出现2个像素，且同色的两个像素必定在同一行或同一列上（即共享行坐标或列坐标）。同色两像素之间全为背景色。
- `Rule`：
  1. 对每种颜色，找到其两个像素的位置。它们位于同一行或同一列。
  2. 从每个像素出发，沿朝向同色伙伴的方向生长一条射线。射线长度等于两像素之间的背景像素数量（即间距减1）。射线的颜色与该像素相同。
  3. 两条同色射线会在中间相遇或重叠，重叠部分保持原色。
  4. 如果不同颜色的射线经过同一个像素位置，该位置变为yellow。
  5. 原始的彩色像素保留不变。
- `Key insight`：射线长度不是固定的，而是由同色像素对之间的间距决定——间距大的颜色射线长，间距小的射线短。解题者需先发现"同色配对"的结构，再归纳出"间距决定射线长度"的规则，最后注意不同色射线交叉产生yellow的叠加规则，三层推理逐步深入。
</new_puzzle>

<new_puzzle>
- `description`：识别输入中被破坏的对称图案，根据未被破坏部分的对称性修复破损区域，然后将所有被修复的像素统一标记为特殊颜色。
- `Input structure`：背景为最常见颜色。输入网格包含一个大致具有某种对称性（水平镜像、垂直镜像或180度旋转对称，具体哪种需从样例推断）的彩色图案。图案中有若干像素被"破坏"——即被替换为一种在正确图案中不应出现的干扰色（干扰色是网格中出现次数最少的非背景颜色）。
- `Rule`：
  1. 确定图案的对称类型：检查非干扰色像素，找出它们满足的对称关系（水平翻转、垂直翻转或180度旋转）。对称轴/中心为图案bounding box的几何中心。
  2. 找到所有干扰色像素（出现次数最少的非背景颜色的像素）。
  3. 对每个干扰色像素，通过对称关系找到其对称位置的像素颜色，用该颜色替换干扰色像素，完成修复。
  4. 将所有被修复的像素（原来是干扰色的位置）额外标记：在输出中，这些位置使用maroon色，而非修复后的"正确"颜色。
- `Key insight`：解题者需要完成三层推理：首先从大部分完好的像素中识别出对称类型，然后利用对称性推断被破坏像素的"正确"值以验证自己的对称假设，最后发现输出并非简单修复而是将破损位置标记为统一的maroon色——修复过程是中间推理步骤，最终输出是对破损位置的定位标记。
</new_puzzle>
