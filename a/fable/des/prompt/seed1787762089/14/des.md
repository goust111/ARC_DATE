- `Rule`：第一步，对每对 Azure 端点，沿其共同的行或列画一条 Azure 直线段连接两端（端点保持 Azure，阀门像素保持自身颜色不被覆盖）。第二步，每个阀门沿垂直于所在线段的方向，向两侧各画一条射线，颜色为阀门自身颜色，每侧长度等于该阀门同色团块的像素个数（不含阀门本身），越出网格则截断。第三步，把每个同色团块整体涂回 Black（团块被"消耗"）。
- `Key insight`：阀门像素是分光器——直线穿过它时折出垂直射线；但射线的长度不是延伸到边界，而是由网格另一处同色团块的大小决定，团块是"燃料"，用完即从输出中消失。三层归纳（连线、垂直发射、长度来自远端计数）的线索分布在网格的不同位置。
- `source`：取自参考题 19 的"线上触发像素发射垂直射线"机制（变异：从对角线系统改为正交线系统，且射线不再无限延伸）+ 参考题 9 的"某种像素计数决定动作幅度"机制 + 参考题 4 的"同色远程配对建立对象关联"机制。新组合点：射线长度由远端同色团块的像素数提供并伴随团块消耗，使解题者必须建立"阀门颜色 → 远端团块 → 计数 → 长度"的跨位置推理链。

- `Input structure`：整个网格被 1 像素宽的 Grey 整行整列分隔线划分成 3×4（或 4×3）个等大 block。其中 8 个 block 是同一 motif 的完整拷贝（motif 含 2~3 种颜色，其中一种是 motif 的内部底色）；恰好 2 个 block 是"墨块"——整块被单一纯色填满，两块颜色不同（如 Red 与 Azure），且这两种颜色不在 motif 中出现；恰好 2 个 block 是"受损拷贝"——motif 的若干像素被 motif 内部底色覆盖。每个墨块与恰好一个受损 block 位于 block 点阵的同一行，每个点阵行至多包含一对。
- `Rule`：第一步，识别墨块（整块单一颜色、且该颜色不在其他 block 中出现），把它们排除后，对其余 block 逐局部坐标取多数颜色，得到共识 motif。第二步，找出与共识 motif 不一致的 2 个受损 block，其不一致的局部坐标即缺失像素。第三步，把每个受损 block 的缺失像素涂成与它位于同一点阵行的墨块的颜色（其余像素保持共识 motif）；把每个墨块整块替换为一份完整的共识 motif。分隔线与完整拷贝保持不变。
- `Key insight`：纯色块不是"损坏最严重的拷贝"，而是供色图例，必须排除在多数投票之外并最终被替换；修补颜色不是固定的，而要通过 block 点阵的同行关系把墨块与受损块配对。三层归纳缺一不可：共识母版、墨块的图例身份、同行配对规则。
- `source`：取自参考题 13 的"多 block 多数共识定位受损像素"机制 + 参考题 15 的"图例结构只供色、不属于输出内容"机制。变异点：参考题 13 的标记色固定为 Blue，这里改为由场景内的墨块图例动态提供，且引入 block 点阵的同行配对作为第三层，把"用什么颜色修补哪个块"变成需要归纳的跨 block 关系。

- `Rule`：第一步，对比图例框内左右两个演示形状，唯一确定所演示的几何变换。第二步，在场景中找出掩码与演示原形完全一致的 sprite（忽略颜色）。第三步，对每个匹配 sprite 就地施加该变换：变换后的掩码放回原 bounding box（正方形 bbox 保证位置不变），颜色保持不变；不匹配的 sprite 原样保留。第四步，把图例框及框内两个演示形状全部涂回 Black。

- `source`：取自参考题 5 的"场景内规则示例定义操作"机制（变异：规则示例从颜色替换对变为几何变换演示对，需要归纳的从颜色映射变成变换类型）+ 参考题 1 的"对象绕自身就地施加 90° 变换"机制 + 参考题 7 的"图例样本不保留进输出"机制。新组合点：变换类型逐题可变且必须现场归纳，再叠加跨颜色形状匹配的适用性判定。

- `description`：只有带孔洞的区域参与变色：它们的颜色按面积从大到小的排名循环移位一格，区域本身不动。
- `Input structure`：背景为 Orange 的实心场。场中嵌着 5~7 个互不接触的单色 4-connected 区域，颜色互不相同（取自 Blue、Red、Green、Yellow、Magenta、Azure、Maroon）。其中 3~5 个区域内部各含恰好一个被完全包围的 Orange 孔洞（孔洞为 1~3 个像素），其余区域完全实心。所有带孔区域的像素面积两两明显不同（相邻排名差至少 3 个像素，保证肉眼可分大小）。
- `Rule`：实心区域完全不变。带孔区域保持形状与位置不动，仅重新上色：把所有带孔区域按像素面积从大到小排序，每个区域取面积排名紧随其后（小一名）的区域的颜色，面积最小的区域取面积最大的区域的颜色，即颜色沿面积排名循环移位一格。孔洞保持为 Orange。
