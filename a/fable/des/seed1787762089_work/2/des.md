- `Input structure`：Black 背景，网格约 20×20 至 26×26。网格左下角沿左边缘有一个竖直图例：每个条目是一对水平相邻像素（左为源色、右为目标色），条目之间空一行；源色与目标色全部互不相同，取自 Blue、Red、Green、Yellow、Magenta、Orange、Azure、Maroon（不用 Grey）。场地中散布 2 至 3 个实心正方形，颜色为图例中的源色（每个源色恰一个正方形），边长为 2、3、4 各不相同；每个正方形恰有一个 Grey 单像素与其某个角对角相邻（占据角的对角外侧格）。生成时保证每个正方形沿其复制方向的路径不与其他正方形、其他路径或图例重叠。
- `Rule`：第一步，删除图例和所有 Grey 点（涂回 Black）。第二步，把每个正方形整体重涂为图例中其源色对应的目标色。第三步，设正方形边长为 N，沿"正方形中心指向其 Grey 点"的对角方向，把该正方形（已换色）反复平移复制，每次平移量为行、列各 2N 格（即相邻两份拷贝之间留出 N 格的对角空隙），直到拷贝完全超出网格为止；与网格部分相交的拷贝裁剪保留出界内的部分。输出为全部复制完成后的网格。
- `Key insight`：三个参数分别藏在三处——新颜色要查角落图例，复制方向由角上的灰点编码，而复制间隔既不固定也不在图例里，它等于正方形自己的边长，必须跨样例对比不同尺寸的正方形才能归纳出来。
- `source`：取自参考题 1/14 的"图例换色"机制、参考题 18 的"motif 以等于自身长度的空隙周期重复"机制、参考题 2 的"少量像素指示对角方向"机制。新组合点：把参考题 18 的一维边框重复迁移为二维对角复制，且"间隔=自身尺寸"从全局常量变为逐对象参数；方向线索从对象自身分离为外部灰点。

- `description`：把边框上的彩色线段沿边框顺时针周期复制，复制间隔不等于线段长度，而等于场内同色离散对象的数量。
- `Input structure`：Black 背景的矩形网格，约 12×14 至 18×20。网格最外圈边框上有一段长度 n（3 至 5）的颜色 C 连续线段（C 取自 Blue、Red、Green、Yellow、Magenta、Orange、Azure、Maroon，可跨过网格角），边框其余部分为 Black。网格内部散布 m 个（2 至 4 个）颜色 C 的单像素点，互不 8-相邻。生成时保证边框一周的总格数恰为 (n+m) 的整数倍，且不同样例的 n 与 m 不相等（防止两种解释重合）。
- `Rule`：第一步，把场内全部 C 色点清为 Black。第二步，把边框一周视为一条顺时针循环路径，从原线段沿顺时针方向的末端开始：跳过 m 个边框格，画一段长度 n 的 C 色线段，再跳过 m 格，再画 n 格，如此重复，直到绕回原线段的起点（由于周长整除，最后一段恰好衔接）。输出为完成绘制后的网格。
- `Key insight`：解题者的第一直觉是像"等距重复"那样取间隔等于线段长度，但样例会否定它——场内那些散点不是要变换的对象，而是间隔参数：复制空隙的格数等于场内同色对象的个数。
- `source`：逆向构造自参考题 18（保留其"边框循环路径上 motif 周期重复"的输出结构），融合参考题 16 的"场内对象计数"与参考题 12 的"计数值用作几何量"机制。变异点：参考题 18 的核心规律"空隙=motif 长度"被替换为"空隙=场内计数"，使输出形态相似但推理路径完全不同，且新增"场内对象只是参数、需被清除"这一认知反转。

- `description`：对场上每个彩色点先后串联查询两个图例——顶行图例把点色映射为中间色，左列图例再以中间色为键给出长度——然后以该点为中心画对应尺寸的空心方框。
- `Input structure`：Black 背景，网格约 18×18 至 24×24。第 0 行是图例 A：若干对水平相邻像素（左为源色 X、右为中间色 Y），对与对之间至少空一格。第 0 列是图例 B：每个条目由一个中间色 Y 的像素和紧贴其正下方的 L 个（1 至 3 个）Grey 像素组成的竖条构成，条目之间至少空一格；图例 B 的条目颜色恰为图例 A 中出现的各中间色，各条目的 L 互不相同。两图例不占用左上角格。场地中（避开第 0 行和第 0 列）散布若干源色单像素点，每个源色至少一个点。所有源色与中间色互不相同且不含 Grey，取自 Blue、Red、Green、Yellow、Magenta、Orange、Azure、Maroon。生成时保证各点之间距离足够大，使所有输出方框互不重叠且不触及图例区域。
- `Rule`：第一步，把图例 A、图例 B 全部清为 Black。第二步，对场上每个颜色为 X 的点：在图例 A 中查得 X 对应的中间色 Y；再在图例 B 中找到颜色为 Y 的条目，数出其 Grey 竖条长度 L；以该点为中心绘制一个边长为 2L+1 的一像素厚空心正方形框，框颜色为 Y；点本身保留原色 X 不变。方框出界部分裁剪。输出为完成全部绘制后的网格。
- `Key insight`：两个图例必须串联使用——图例 B 的键不是场上点的颜色，而是图例 A 的输出色；直接拿点色去查图例 B 会一无所获。颜色、尺寸两个参数经一条两级查询链才能取齐。
- `source`：取自参考题 1/5/14 的"图例映射"机制、参考题 7 的"图例颜色与场上要素靠颜色链接"机制、参考题 12 的"可数长度用作几何尺寸"机制。新组合点：参考题中图例都是单级查表，这里把两个图例串成两级链（A 的输出是 B 的键），解题者必须发现中间色这个隐藏的接力棒。
</new_puzzle>

<new_puzzle>
- `description`：把每个实心方块嵌入内腔尺寸与它严丝合缝的空心框中，并让方块与框互换颜色。
- `Input structure`：Black 背景，网格约 16×16 至 22×22。场上散布 2 至 3 个空心正方形框（一像素厚边，内腔为 Black，内腔边长为 2、3、4 中互不相同的值）和同样数量的实心正方形块（边长与各框的内腔边长一一对应）。框与块的颜色全部互不相同，取自 Blue、Red、Green、Yellow、Magenta、Orange、Azure、Maroon，且框色与块色之间没有任何颜色对应关系。框与块互不接触、不贴网格边。
- `Rule`：对每个实心块：找到内腔边长等于其边长的那个框；把块从原位置清除（涂回 Black），平移放入该框的内腔（恰好填满整个内腔）；同时颜色互换——放入后的块整体重涂为该框原来的颜色，框的边整体重涂为该块原来的颜色。框的位置不动。输出为全部嵌入与换色完成后的网格。
- `Key insight`：配对的纽带与颜色无关，是几何上的严丝合缝——块的尺寸恰好等于某个框的内腔尺寸；而且归位不是简单放入，块与框还要交换彼此的颜色，单看任一对象无法解释它的新颜色从何而来。
- `source`：取自参考题 6 的"按内部区域判别对象类型（框 vs 实心）"机制、参考题 20 的"反直觉匹配后停靠并换色"机制。变异点：参考题 20 的匹配键是颜色（外层色对填充色），这里变异为纯几何键（内腔尺寸=块尺寸），颜色被刻意打乱以排除颜色匹配假设；停靠方式从底部对齐变为完全嵌入内腔。
</new_puzzle>
