  - 第一层（容器分类得方向）：对每个 Grey 容器，取它的 normalized 外轮廓形状，在图例中找到形状完全相同的那一行，读出该行对应的箭头方向。同一形状的所有容器都得到同一方向，与位置无关。

  - 第三层（颜色跨容器传递并填充）：把每个被命中"目标容器"的内部空腔（其原有种子像素也一并覆盖），整片染成命中它的那个"发射容器"的种子颜色。若一个容器被多个发射容器命中，则采用发射容器种子颜色按色名字母序最靠前的那一个（如 Azure < Green < Red < Yellow），保证唯一。从未被任何探针命中的容器内部保持原样（仅保留其原种子）。

import hashlib

print("variants", len(sigs))
assert len(sigs) >= 20
