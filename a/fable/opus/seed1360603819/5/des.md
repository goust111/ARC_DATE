<new_puzzle>
<description>
按每个色块的"孔洞数"在图例中查到一个长度，再让每个色块沿其所附短箭头方向射出该长度的同色射线。
</description>

Input structure
- 背景为 Black。
- 网格左上角有一列竖直排列的"图例条"：从上到下若干行，每行是一条水平的实心短条，颜色统一为 Grey，各短条长度互不相同；这些 Grey 短条之间相隔一行空背景，整体靠在网格最左侧成一竖列。
- 网格其余区域散布若干个互不接触的彩色实心对象（4-连通，单色，非 Grey、非 Black），每个对象是一个矩形外框内部带有若干个 Black 孔洞（被对象完全包围的背景像素连通块）。
- 每个彩色对象的外侧紧贴一个长度为 3 像素的同色"箭头"：箭头是一条直线杆身加一个向旁侧凸出一格的箭尖，指示一个上/下/左/右的正交方向，并紧贴对象某一条边的外侧。

Rule
- 第一步（建立"次序 → 长度"映射）：把左上角的 Grey 图例条按它们在网格中从上到下的位置编号为第 1、第 2、第 3……条。每条图例条的长度是一个被打乱、与编号无关的给定值；解题者需归纳出"第 h 条图例条的长度代表孔洞数为 h 时的射线长度"，即查表键是"位置次序"而非"长度本身"。
- 第二步（数孔洞并查表）：对每个彩色对象，数出它内部 Black 孔洞的连通块个数 h；在图例中取从上到下的第 h 条，读出其长度 L。
- 第三步（射线）：从该对象沿其箭头所指方向，紧贴对象那条边的外侧起，画一条长度为 L 的同色直线射线（方向与箭头一致），射线被网格边界裁剪。保留所有原对象、孔洞、箭头与图例不变，只新增射线。

Key insight
- 图例条的"位置次序"才是查表键（第 h 条），而它的"长度"是被查出的值；孔洞数 h 既不等于长度也不等于位置长度，必须先建立"次序↔孔洞数"再读"长度"，两层缺一不可。

source
- 取自参考题 10（固定位置图例：用位置而非形状/颜色作为标签查表）与参考题 8（用对象自身的某个计数量作为几何位移/长度量）的机制；新组合点在于把"计数量"换成孔洞数，并让它不直接当射线长度，而是先经由"位置次序图例"二次查表得到长度，把参考题 10 的"位置即标签"与参考题 8 的"计数即长度"串成两层依赖管道。变异点是图例条长度被打乱，迫使解题者分离"次序键"与"长度值"。
</new_puzzle>

<new_puzzle>
<description>
先用红框内的孔洞数给每个框排出循环顺序，再让每个框的内容色块颜色按该顺序循环传递一格，最后按各框传得的新颜色把框内孔洞分别填色或留空。
</description>

Input structure
- 背景为 Black。
- 网格中散布若干个空心的 Red 方框（边框为 Red，内部为 Black），大小可不同。
- 每个方框内部除 Black 外，含有恰好一个非 Black、非 Red 的实心"内容色块"，形状不规则但连通。
- 每个方框内部还含有若干个被内容色块或边框完全包围的 Black 孔洞（小空洞），不同方框的孔洞数互不相同。
- 此外，网格右侧有一列竖直排列的 Grey 短条作为"奇偶图例"：图例由上下两条 Grey 短条组成，上面一条短、下面一条长，分别代表"奇/偶"两类；解题者需结合样例归纳出哪一条对应"奇数"。

Rule
- 第一步（用孔洞数定序）：对每个 Red 方框，数出其内部被完全包围的 Black 孔洞个数 n（不数与框外连通的背景）。把所有方框按 n 从小到大排成一个循环序列（n 严格互不相同，保证排序唯一）。
- 第二步（颜色循环传递）：沿这个循环序列，把每个方框的内容色块颜色替换为序列中下一个方框（n 更大者；n 最大的回卷到 n 最小的）的内容色块颜色。内容色块的形状与位置保持不变，只换颜色。
- 第三步（按奇偶图例处理孔洞）：对每个方框，看它"传入的新颜色"是否等于它"原来的内容颜色"——若孔洞数 n 为奇则把该框内所有 Black 孔洞填成新颜色，若 n 为偶则孔洞保持 Black；"奇/偶应填还是应留"这一对应需通过右侧 Grey 奇偶图例与样例共同归纳确定，而非默认。
- Red 边框、Black 背景、图例本身全部不变。

Key insight
- 三层依赖：孔洞数先定循环序（决定颜色怎么传），再决定每个框该用哪条图例（奇偶），最后图例又裁决孔洞是否上色；同一个 n 在不同层承担不同角色，且奇偶图例的含义只能从样例归纳，单看一个框无法同时读出排序键、奇偶规则与填洞结果。

source
- 取自参考题 4（沿循环序把各框内部色块颜色旋转一格、色块形状不动）、参考题 11/2（用孔洞这类隐蔽结构属性做判定）与参考题 10（用一个固定位置图例把奇偶映射到"填/不填"动作）的机制；变异点在于参考题 4 的循环次序由可见 Blue 连线给出，本题改为孔洞数升序这一不可见全局排序，并新增第三层——用孔洞数奇偶经图例查表决定孔洞着色，使 n 一量三用，认知路径质变。
</new_puzzle>

<new_puzzle>
<description>
按每个箭头所指目标色块的像素个数，决定该箭头自身要平移几格，再画出平移后的箭头。
</description>

Input structure
- 背景为 Black。
- 网格中有若干个单色"箭头"对象：每个箭头是一条直的杆身加一个箭尖，至少 3 像素，明确指向上/下/左/右四个正交方向之一，不同箭头颜色可不同。
- 网格中还有若干个实心彩色"靶块"（4-连通、单色、矩形或不规则），数量与箭头相同；每个箭头沿其指向方向的延长线上，恰好命中唯一一个靶块（即该靶块是这个箭头方向射线第一个碰到的对象），且不同箭头命中不同靶块。

Rule
- 第一步（箭头配靶）：对每个箭头，沿其指向方向发射一条假想射线，命中的第一个靶块即为该箭头的"目标靶块"。需归纳出"箭头指向决定它对应哪个靶块"。
- 第二步（用靶块像素数定位移）：数出目标靶块的像素总数 m。把该箭头整体沿其指向方向平移 m 格（保持箭头形状与颜色不变），原位置清为背景，画出平移后的箭头；平移被网格边界裁剪。
- 所有靶块保持原样不变，只有箭头移动。

Key insight
- 决定每个箭头位移量的数值不在箭头身上，而在它所指向的另一个对象（靶块）的大小里；必须先归纳"指向→配对靶块"，再归纳"靶块面积→自身位移格数"，位移依据与被变换对象分离，避免层塌缩。

source
- 取自参考题 8（用某对象的像素计数作为正交位移量）与参考题 12（用一个对象的某属性作为查找键去另一个对象处取值、实现跨对象间接传递）的机制；变异点在于参考题 8 中"位移量=对象自身面积"，这里把面积来源外移到"箭头所指的靶块"，让位移量成为跨对象查得的值，把"自身计数即位移"升级为"指向配对+异物计数"两层依赖。
</new_puzzle>

<new_puzzle>
<description>
先按各灰色道路接触种子区的一端给道路上色，再让上好色的道路把它另一端的方框内部按该色填满。
</description>

Input structure
- 背景为 Black。
- 网格中有若干条 Grey 的细道路（1 像素宽的正交折线），互不连接，每条是一条独立连通折线，恰有两个端点。
- 每条道路的一个端点紧贴一小片单色"种子区"（实心色块，非 Grey、非 Black、非 Azure，不同道路的种子色可不同）。
- 每条道路的另一个端点紧贴一个空心方框（边框为 Azure，内部为一片被边框完全包围的 Black 区域）。

Rule
- 第一步（道路染色）：对每条 Grey 道路，找出它两端中紧贴种子区的那一端，把整条道路重绘为该种子区的颜色。需归纳出"道路从它接触的种子区继承颜色"。
- 第二步（找方框端）：每条已染色道路的另一端紧贴一个 Azure 方框，需归纳出"染色道路指向它要作用的那个方框"——配对关系由道路另一端的位置决定。
- 第三步（填框）：用该道路当前的颜色，把它所指 Azure 方框内部被边框包围的 Black 区域整体填满为该颜色；Azure 边框保持不变。所有道路保留染色后的结果，种子区不变。

Key insight
- 颜色先从种子区流入道路（第一层），再从道路流入方框（第三层），中间还要靠"道路另一端"完成道路与方框的配对（第二层）；颜色的最终归属（哪个种子色填进哪个框）跨越了道路这个中介，单看任一方框无法直接读出它该填什么色。

source
- 取自参考题 2（沿路径网络从相邻种子区继承颜色）与参考题 12（沿 Grey 轨迹的端点确定作用目标、做色彩的间接转移）的机制；变异点在于参考题 2 染完色即结束，本题把染色结果作为第三阶段"填框"的输入，并用道路两端分别承担"取色端"与"作用端"，形成种子→道路→方框的三层颜色管道，配对关系藏在道路另一端，避免层塌缩。
</new_puzzle>

<new_puzzle>
<description>
先按每条彩色线的长度排出层叠顺序，再按该顺序在所有交叉点上让长线压住短线，重绘整幅交叠图。
</description>

Input structure
- 背景为 Black。
- 网格中有若干条直线段，每条为不同颜色（非 Black），方向可为水平、竖直或 45 度对角；每条线一像素宽、完整连续（无断口），不同线长度互不相同。
- 这些线两两可能在某些格子上交叉重叠；输入中每个交叉格按"某种给定次序"显示其中一条线的颜色，但这一显示次序与正确答案无关，仅作干扰。

Rule
- 第一步（按长度定层序）：测量每条线的像素长度，按长度从短到长排出一个层叠顺序——短线在下、长线在上。需归纳出"线越长层级越高"这一非显然规律，而非按颜色、按位置或按输入显示的遮挡关系。
- 第二步（重绘交叠）：保持每条线的完整几何位置，重新绘制整幅图：在任意多条线共同经过的格子上，只显示层级最高（最长）那条线的颜色；其余格按各自唯一经过的线着色，无线经过处为 Black。
- 输出与输入同尺寸，所有线的端点与走向不变，仅每个交叉格的可见颜色按新层序确定。

Key insight
- 真正决定遮挡的"层序"并不写在输入的可见交叠里（输入交叉色是干扰），而要从每条线的长度独立归纳出来；必须先建立"长度→层级"的全局排序，再用它去裁决每一个交叉点，两层缺一不可。

source
- 取自参考题 6（多条直线交叠、交叉点显示上层颜色，需恢复完整线并定层序）与参考题 19（用线段的某个全局量——这里是长度——作为统一裁决依据）的机制；变异点在于参考题 6 的层序由"可见交叉色"提供局部约束再求唯一拓扑链，本题把层序来源整体替换为"线长排序"，并故意让输入交叉色成为误导，使解题路径从"读交叉求拓扑序"质变为"量长度定层序再重绘"。
</new_puzzle>
