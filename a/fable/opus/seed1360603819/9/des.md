<new_puzzle>
description
- 先由图例小方块上的孔洞数解码每种"墙"颜色的转向规则，再让从源方块发出的射线依此转向并绘制轨迹。

Input structure
- 背景为 Black。
- 网格左上角有一条横向的"图例带"：图例带是若干个并排的 3x3 实心小方块，相互之间隔一列 Black。每个图例小方块为某种颜色（如 Blue、Red、Green、Magenta），且方块内部被挖去 1 个或 2 个 Black 像素的孔洞（孔洞位于方块的非边角内部位置）。每种墙颜色在图例带中只出现一次。
- 图例带下方的主区域中有：一个 Azure 的 2x2 实心源方块；以及若干个散布的单像素"墙"，每个墙的颜色取自图例带中出现过的颜色。

Rule
- 输出中删除整条图例带（图例带占据的行全部恢复为 Black）。
- 第一层：读出每种墙颜色的转向规则。规则由该颜色图例小方块中的孔洞个数决定：孔洞数为 1 表示该颜色墙令射线顺时针转 90 度；孔洞数为 2 表示该颜色墙令射线逆时针转 90 度。
- 第二层：从 Azure 源方块的四条边各发射一条射线，分别朝上、下、左、右。射线以 Azure 逐格涂染所经过的 Black 单元。当射线即将进入一个墙像素所在的单元时，不覆盖该墙像素，而是查出该墙颜色对应的转向规则，按规则改变前进方向后从墙的相邻单元继续前进。
- 射线碰到网格边缘即停止。墙像素本身在输出中保留原色不变。

Key insight
- 图例方块的"孔洞数"不是噪声而是转向编码；必须先把每种颜色翻译成顺/逆时针，再让射线在主区域里依颜色查表转弯，两层缺一不可。

source
- 取自参考题 17（图例编码转向 + 方块发射四向射线遇障转弯）与参考题 20（孔洞计数）。变异点：把参考题 17 中"图例条位置左右"这一编码方式替换为参考题 20 风格的"图例方块内孔洞数量"编码，使第一层从"读位置"变成"数孔洞再映射方向"的非平凡归纳；射线机制保留但编码层质变。
</new_puzzle>

<new_puzzle>
description
- 先按每个对象的孔洞数确定它在颜色环里前进几步从而完成差异化颜色轮换，再把轮换后的颜色应用回原对象。

Input structure
- 背景为 Black。
- 网格中散布着若干个 4-连通的实心轮廓对象，每个对象内部可能包围 0 个或多个 Black 孔洞。
- 这些对象的颜色互不相同，且它们的颜色恰好构成一个固定的"颜色环"：环的顺序为 Blue → Red → Green → Yellow → Magenta → 回到 Blue（实际题目只用到其中连续的一段，且每种颜色在网格中只属于一个对象）。

Rule
- 第一层：对每个对象，数出它内部包围的 Black 孔洞个数 k（k 可为 0）。
- 第二层：每个对象的新颜色 = 在上述固定颜色环中，从该对象原颜色出发沿环前进 k 步所到达的颜色。前进时只在网格实际使用到的那一段连续颜色子环内循环。
- 对象不发生任何几何移动，孔洞保持为 Black，仅把每个对象的全部实心像素重绘为它各自算出的新颜色。

Key insight
- 孔洞数不是用来标记对象，而是"沿颜色环前进的步数"；每个对象前进的步数不同，因此这不是统一旋转而是逐对象的差异化轮换，必须先数孔洞再查环。

source
- 取自参考题 7（颜色按固定环轮换）与参考题 20（数对象内部孔洞）。变异点：参考题 7 是所有区域统一前进 1 步的整体旋转，本题把"前进步数"由每个对象自身的孔洞数决定，使颜色轮换从全局同步变为逐对象差异化，第一层（数孔洞→步数）成为不可省略的独立归纳层。
</new_puzzle>

<new_puzzle>
description
- 先从训练样例对中归纳一个精灵变换操作，再数出每个测试精灵的标记点个数以决定该操作要重复施加几次，最后输出结果。

Input structure
- 背景为 Black。
- 网格中有若干个 Grey 的方形空心边框（hollow square frame），每个边框内部装着一个小精灵图案。
- 其中恰有一对边框构成"训练对"：第一个边框内部是源精灵 A，第二个边框内部是把某个固定几何操作（在水平镜像、垂直镜像、顺时针旋转 90 度三者中确定的一种）施加到 A 一次所得的精灵 B；这一对边框的左上外侧各放置 Orange 单像素分别标 1 个点和 2 个点，用来指明谁是输入谁是结果（1 个点者为输入）。
- 其余边框为"测试边框"：每个测试边框内部有一个精灵，且该边框的左上外侧放置 1 到 3 个 Orange 标记点。

Rule
- 第一层：由训练对的 A→B 推断出那个唯一的几何操作 f（水平镜像 / 垂直镜像 / 顺时针旋转 90 度三者之一）。
- 第二层：对每个测试边框，数出其外侧 Orange 标记点的个数 m，表示要把操作 f 连续施加 m 次到该测试精灵上。
- 输出保持所有边框位置与边框本身不变，删除全部 Orange 标记点，并把每个测试边框的内部精灵替换为施加 f 共 m 次后的结果；训练对的两个边框在输出中其内部精灵都替换为对 A 施加 f 一次的结果（即都等于 B）。

Key insight
- 训练对只告诉你"是哪一种操作"，标记点个数才告诉你"施加几次"；解题者必须先从一对样例归纳出操作类别，再用计数控制重复次数，二者结合才能确定每个测试精灵的最终朝向。

source
- 取自参考题 5（用训练对 A→B 归纳变换并迁移到测试精灵）与参考题 16/20（用可见标记/计数控制数量）。变异点：参考题 5 是把规则原样施加一次，本题增加第二层"用标记点数控制 f 的重复次数"，使同一个操作因计数不同而产生不同结果，把单层类比变成"归纳操作 + 计数重复"的两层管道。
</new_puzzle>

<new_puzzle>
description
- 先用被标记母题内部的彩色槽位解码出整个母题阵列的配色，再让一束从边缘射入的射线按配色逐格染色，并在穿过不同颜色母题时改变间隔的绘制颜色。

Input structure
- 背景为 Black。
- 网格主体是一个由若干个相同小母题（motif）排成的矩形阵列；母题之间、母题与外缘之间各隔一行/一列 Black。每个母题是同色的实心小方块（例如 3x3 的 Grey 方块）。
- 阵列中恰有一个母题被改造为"图例母题"：它内部的若干像素被替换为不同颜色（如 Blue、Red、Green），其余像素保持母题原色；这些彩色像素按它们在图例母题中的相对位置，编码了输出阵列里每个母题应有的颜色。
- 网格最左列有一个单像素 Magenta 的"射手"，位于阵列某一行所在的行高范围内。

Rule
- 第一层：把图例母题内部的彩色像素读作一张"颜色地图"——图例母题中位于第 i 行第 j 个槽位的颜色，规定了输出阵列中第 i 行第 j 列那个母题应被重绘成的颜色；图例母题中仍保持母题原色的槽位，对应母题保持原色。据此把整个母题阵列重绘为彩色阵列（阵列几何、间隔保持不变，图例母题本身也按其所在槽位被重绘）。
- 第二层：Magenta 射手从最左列沿它所在的行向右发射一束射线。射线进入母题阵列后逐个穿过同一行上的彩色母题；每当它进入一个母题方块，就把该方块整体重绘为 Magenta，并记住该母题在第一层中被赋予的颜色 C，作为"通行色"。在两个母题之间的 Black 间隔格上，射线以"通行色 C"逐格涂染。射线到达网格右缘停止；射手像素本身保留为 Magenta。

Key insight
- 第一层是把一个母题内部的彩色槽位翻译成整张阵列的配色（迷你图例放大到整体）；第二层是射线把"刚穿过的母题颜色"带到下一段间隔上染色，因此间隔的颜色取决于第一层算出的母题配色——两层严格依赖，必须先解码配色才能知道射线在每段间隔涂什么颜色。

source
- 取自参考题 2（母题内部彩色槽位作为整阵列重绘图例）与参考题 12/17（射线穿行并随接触对象改变绘制内容）。变异点：参考题 2 解码后即结束，本题把解码结果当作第二层射线染色的输入——射线在间隔上的颜色由它刚穿过的母题颜色决定，新增了一条"配色驱动射线着色"的依赖链，构成真三层（数出阵列规格、解码配色、射线按配色染色）。
</new_puzzle>

<new_puzzle>
description
- 先把各灰条的接触像素数转移成相邻矩形的边条宽度并按链序上色，再沿单一连接链把所有矩形上新生成边条的颜色序列整体反转。

Input structure
- 背景为 Black。
- 网格中有若干个 Yellow 的实心矩形，沿一条水平或垂直主轴排成一列，相邻矩形之间由一条单像素宽的 Maroon 连接段相连，使所有矩形构成一条无分支的链（恰有两端）。
- 每个 Yellow 矩形的某一条边上 4-接触着若干根 Grey 的单像素宽细条（细条方向与接触边垂直）；不同矩形接触的灰条数量不同；可能有矩形没有任何接触灰条。

Rule
- 第一层：对每个 Yellow 矩形，数出 4-接触它的 Grey 灰像素总数 n。把所有原始 Grey 像素恢复为 Black（清除）。在该矩形内部，从被接触的那条边开始向矩形内部方向，把 n 行（若灰条水平接触）或 n 列（若灰条垂直接触）整体重绘为一种"边条色"。每个矩形使用的边条色由它在链上的位置顺序依次取自固定调色序列 Blue、Red、Green、Magenta、Orange（链的一端为第 1 个矩形）；没有接触灰条的矩形不生成边条但仍占用一个调色位次。
- 第二层：沿 Maroon 连接链从一端走到另一端，得到各有边条矩形的"边条色"按链顺序排成的颜色串（只统计实际生成了边条的矩形）。把这串颜色按相反顺序重新分配回这些矩形：第一个有边条的矩形改用原本最后一个的边条色重绘其边条，依此类推。矩形位置、Yellow 主体、Maroon 链均不动，只有新生成边条的颜色被整体反转。

Key insight
- 第一层把"灰像素计数"转成"边条宽度"并按链序上色；第二层沿链把这些边条颜色串整体反转。第二层需要的颜色串只有在第一层完成计数与上色后才存在，且反转依赖整条链的全局顺序，单看一个矩形无法读出两层规则。

source
- 取自参考题 13（灰像素计数→相邻矩形边对齐条纹）与参考题 9（沿单一路径反转颜色序列）。变异点：参考题 13 到生成条纹即结束，本题把生成的边条颜色串接到参考题 9 的"沿路径反转"机制上，使"计数→上色"的产物成为"沿链反转"的输入，形成真三层（数灰条、按链序上色成边条、沿链反转边条色），层间严格依赖且判断依据分散在不同矩形与整条链上，避免层塌缩。
</new_puzzle>

<new_puzzle>
description
- 先找出每一格点阵行中"独一无二"的那个精灵，再按这些精灵各自的孔洞数把它们沿固定颜色环换色，输出成单列。

Input structure
- 背景为 Black。
- 网格被一种 Grey 的均匀网格线划分成大小相等的方形单元，排成若干行若干列；每个单元内部装着一个由 Blue 画成的精灵图案。
- 每一行单元中，恰有一个单元的精灵图案与该行其余单元不同（其余单元的精灵彼此相同）。
- 每个精灵内部可能包围 0 个或多个 Black 孔洞。

Rule
- 第一层：对每一行，找出图案在该行中只出现一次的那个"异类"单元（其余为重复）。
- 第二层：对每个被选出的异类精灵，数出它内部包围的 Black 孔洞数 k，并把它的前景色由 Blue 沿固定颜色环 Blue → Red → Green → Yellow → Magenta 前进 k 步换成新颜色（k 为 0 则保持 Blue）。
- 输出为一个单列点阵：保留原各行的高度与 Grey 网格线结构，每行只放入该行选出的异类精灵（已按其孔洞数换色），其余单元内部清为 Black。

Key insight
- 第一层是逐行"找异类"，第二层是按异类自身的孔洞数沿颜色环换色；前者决定"挑谁"，后者决定"染成什么色"，且染色依据（孔洞数）只对被挑出的精灵有意义，两层依次依赖。

source
- 取自参考题 18（逐行找唯一异类并抽成单列）与参考题 20/7（数孔洞 + 沿颜色环按步换色）。变异点：参考题 18 抽出异类后原样保留，本题给抽出环节叠加"按孔洞数沿环换色"的第二层，使输出不仅是位置重排还携带由对象自身属性算出的颜色变化，把单层抽取扩展为"挑选 + 计数换色"的两层管道。
</new_puzzle>
