## 新题 1：头部像素定向射线

**组合逻辑**：[射线延伸](方向不再由边缘或开口决定，而由头部标记像素相对精灵体体部的方位编码) + [擦除](射线完成后清除原始精灵体) + [封闭区域](已有，约束射线终止)

**来源原语**：射线延伸(ray_extend) ← aba27056/f9a67cb5；擦除(erase) ← 494ef9d7/fbf15a0b；封闭区域(enclosed_region) ← aba27056/7447852a；标记像素(marker_pixel) ← 8886d717；精灵体(sprite) ← 8ee62060

**依赖链**：头部像素与体部的空间方位 → 编码射线方向（位置信息转化为方向参数，源题中不存在此结构关系） → 射线沿该方向延伸至边界色或网格边缘 → 原始精灵体和头部像素擦除。移除头部方位检测则方向不确定；移除边界约束则射线无终止条件；移除擦除则输出残留原始图形。

从每个封闭区域内精灵体的头部像素出发，沿头部相对体部的方位发射射线至区域边界，然后擦除原始精灵体。

**输入结构**：约 12×12 黑(0)背景网格。绿(3)像素构成连通的边界线，将网格分割为 3~4 个封闭区域（每个区域面积约 8~20 像素）。每个区域内有一个小型 4-连通单色精灵体（3~5 像素，颜色各不相同，从蓝(1)、红(2)、黄(4)、品红(6)中选取），紧邻精灵体的某一侧有一个灰(5)像素作为"头部"。头部与体部恰好 4-邻接，且头部在体部的上/下/左/右某一方向上。不同区域内的精灵体形状可以不同（但均为无旋转对称性的不规则形状），头部朝向也各不相同。生成约束：每个头部到其所在区域边界之间至少有 2 个空像素的直线通道。

**规则**：
1. 对每个封闭区域，定位其中的精灵体（非黑、非绿的连通分量）和紧邻的灰(5)头部像素。
2. 计算头部像素相对于精灵体几何质心（所有体部像素坐标的均值，向最近整数取整）的方位，取最近的基本方向：头部在质心正上方或偏上 → 上；偏右 → 右；偏下 → 下；偏左 → 左。
3. 从头部像素出发，沿该方向逐像素延伸射线，将经过的每个黑(0)像素涂为精灵体的体部颜色。射线遇到绿(3)边界像素或到达网格边缘时停止，不涂终点的边界像素。
4. 将原始精灵体的全部体部像素和灰(5)头部像素设为黑(0)。
5. 绿(3)边界线和其余背景不变。

**关键洞察**：灰色头部像素不是装饰——它相对于精灵体体部的方位是一个方向指令，决定射线的发射朝向；必须对比多个示例才能发现"头部方位 = 射线方向"这一非显然映射。

## 实现要求

1. `main(grid)` 必须实现新题描述中的确定性转换规则，不能只识别 `generate_input()` 的固定模板。
2. `generate_input()` 必须随机生成多样样例，不能固定死。随机维度应覆盖：网格大小、对象数量、位置、颜色、方向、形状参数或关键分支。
3. 生成器必须保证输入满足 `main()` 的隐式假设：对象不重叠、不越界、特殊标记唯一或可区分、匹配关系无歧义、关键分支出现概率相同。
4. 禁止把 ARC 颜色 id 、亮度、拼写等当作人类不可见的数值语义参与排序、大小比较或隐藏映射。颜色变化必须有可见结构线索。注意颜色亮度、拼写等也是不可见信息，若描述中出现违规的颜色id或者亮度，可自行使用少量的固定颜色替代，但注意生成时要在三个以内输入输出网格中对所有变换100%覆盖度。
5. 输出样例要视觉清晰，人类必须能从输入输出对中肉眼辨认出规律。具体要求：避免对象粘连、覆盖关系混乱、同一像素多重语义；不同逻辑步骤产生的结果不要大面积层叠在一起导致无法分辨哪个颜色属于哪个步骤；输入中各元素之间保持足够间距，输出中新增的标记/填充/路径等应与背景和已有元素在颜色上有明显区分；若规则涉及多层叠加，生成时控制对象密度和尺寸，确保叠加区域只占少数像素而非铺满整个网格。
6. 若规则有多个分支，生成器不能长期固定成一个分支；应让分支在随机样例中合理出现。分支概率不必平均——难以发现的隐蔽分支（如少数情况下才触发的特殊规则）应适当提高出现概率，确保在 3 个训练示例中至少出现一次，否则求解者无法归纳该规则。对于颜色映射类规则，确保 2 个左右的示例即可覆盖所有映射关系（每种颜色→颜色的映射至少在某个示例中出现过）。
