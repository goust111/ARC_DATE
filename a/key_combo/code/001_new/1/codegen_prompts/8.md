## 新题 8：标记对定裁剪与条件旋转

**组合逻辑**：[裁剪·标记对齐指定半区](已有) + [旋转](创新：标记所在半区的编号隐式编码是否旋转) + [擦除](清除标记)

**来源原语**：裁剪(crop)/标记对齐指定半区(marker_selects_half)/保留标记半区(keep_marked_half)/擦除(erase) ← fbf15a0b；旋转(rotate) ← 8e5a5113；标记像素(marker_pixel) ← fbf15a0b

**依赖链**：标记对齐方向 → 确定裁剪轴（行对齐→水平切，列对齐→竖直切） → 标记所在半区 → 确定保留哪一半 → 标记所在半区编号（第一半 vs 第二半）→ 决定是否旋转（同一组标记像素同时编码裁剪对象和旋转决策）。源题中标记仅选择半区；此题中标记的位置额外编码一个布尔旋转参数。

根据标记对的对齐方向裁剪出包含它们的半区，若标记位于第二半区（右半或下半）则将结果顺时针旋转 90°，最后擦除标记。

**输入结构**：约 12×12 黑(0)背景网格，包含若干非黑前景像素构成的内容图案（颜色和形状不限）。网格中恰有两个橙(7)标记像素，它们共享同一行或同一列。两个标记像素位于网格的同一半区内（若共享一行，则两者都在左半区或都在右半区；若共享一列，则都在上半区或都在下半区）。标记像素不与任何内容图案像素重叠。生成约束：两个半区都包含非黑内容，使得裁剪结果非空白。

**规则**：
1. 找到两个橙(7)标记像素。
2. 若两标记共享同一行（行坐标相同）：以网格水平中线切分为左半和右半；保留包含两标记的那一半。
3. 若两标记共享同一列（列坐标相同）：以网格竖直中线切分为上半和下半；保留包含两标记的那一半。
4. 判断保留的半区是第一半区还是第二半区（左或上 = 第一；右或下 = 第二）。
5. 若为第二半区，将裁剪结果整体顺时针旋转 90°；若为第一半区，不旋转。
6. 将输出中的橙(7)标记像素设为黑(0)。

**关键洞察**：源题 fbf15a0b 中标记像素仅选择保留哪个半区；此题中标记所在的半区编号还隐式编码了一个旋转决策——同一对标记像素承载两个不同的信息（选区 + 旋转），必须对比多个示例才能发现第二半区触发旋转这一隐蔽规则。
