## 新题 7：色数决定提取周期

**组合逻辑**：[计数](创新：计数结果不映射为图形属性，而作为采样周期参数) + [提取](按周期性索引选取) + [等分网格](已有结构)

**来源原语**：计数(counting) ← 6e02f1e3；提取(extract) ← c3202e5a；等分网格(equal_partition)/分隔线(divider_line) ← c3202e5a；等间隔采样填充(periodic_fill) ← 7447852a → 改为等间隔采样提取

**依赖链**：全局色数统计 → 得到周期值 K → 按 K 的倍数索引选取单元 → 提取并拼接输出。全局属性（色数）决定局部操作（选哪些单元），两者不在同一层面——必须先做全局扫描才能进行局部提取。

统计所有单元中出现的不同前景色总数 K，每隔 K 个单元提取一个，按行排列为输出。

**输入结构**：约 3×21 或 3×24 黑(0)背景网格。灰(5)完整竖线将网格等分为 N 个大小相同的小单元排成一行（N = 7~8，每个单元约 3×3）。每个单元内有一个由单色前景像素构成的小图案（1~4 像素，颜色从蓝(1)、红(2)、绿(3)、黄(4)、品红(6)中选取）。整个网格中共使用 K 种不同的前景色（2 ≤ K ≤ 4），但各单元可能重复使用相同颜色。生成约束：N 可被 K 整除或 N ≥ 2K，保证至少能提取 2 个单元。

**规则**：
1. 识别灰(5)分隔线，将网格划分为 N 个单元，从左到右编号 0, 1, 2, ..., N−1。
2. 统计所有单元中出现的不同前景色（非黑、非灰）的种类数 K。
3. 提取索引为 0, K, 2K, 3K, ... 的单元（即每隔 K 个取一个，从第 0 个开始）。
4. 将提取出的单元从左到右水平拼接为输出（单元之间无分隔线）。

**关键洞察**：源题 7447852a 用固定周期（每 3 个）选取区域；此题的周期由输入内容动态决定——全局色数这一跨单元属性直接控制采样策略，使得计数和提取之间产生"内容决定结构"的非平凡耦合。
