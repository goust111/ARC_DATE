## 新题 9：归一化后色数决定平铺倍数

**组合逻辑**：[缩放·归一化到固定尺寸](已有) + [计数](创新：对归一化后的内容统计色数) + [平铺](创新：平铺倍数不由空间尺寸决定，而由色数决定)

**来源原语**：圆角边框(rounded_frame)/归一化到固定尺寸(normalize_size)/裁剪(crop)/缩放(resize) ← db118e2a；计数(counting) ← 6e02f1e3；平铺(tiling)/边长决定重复数(side_len_determines_rep) ← ccd554ac → 改为色数决定重复数

**依赖链**：圆角边框检测 → 裁剪内部图案 → 归一化到固定尺寸 → 统计归一化结果中的前景色数 K → 以 K 为倍数平铺归一化图案。归一化使不同大小的输入产生可比的色数；色数决定平铺倍数——输入的"内容丰富度"直接控制输出的"空间规模"。

提取圆角边框内的图案并归一化到 3×3，统计其中不同前景色数 K，将归一化结果平铺为 K×K 的方阵。

**输入结构**：约 7×7 至 11×11 黑(0)背景网格。网格中有一个由单色（灰(5)）构成的圆角矩形边框：四角像素为黑(0)，其余外边界像素为灰(5)，形成圆角效果。边框内部有一个由 1~3 种非黑、非灰前景色构成的图案（总共 2~6 个前景像素，4-连通或不连通均可）。边框尺寸可变（5×5 至 9×9），内部图案的边界框不超过边框内部空间。生成约束：归一化到 3×3 后，图案的前景色数 K ∈ {2, 3, 4}（保证平铺倍数在合理范围内）。

**规则**：
1. 识别灰(5)圆角矩形边框（四角为黑(0)的矩形灰边界）。
2. 裁剪出边框的严格内部区域（不含边框线）。
3. 将内部图案的边界框（包含所有非黑像素的最小矩形）缩放（最近邻插值）到 3×3。
4. 统计 3×3 归一化结果中不同前景色（非黑(0)）的种类数 K。
5. 将 3×3 归一化结果作为瓦片，水平方向重复 K 次、竖直方向重复 K 次，构成 (3K)×(3K) 的输出。

**关键洞察**：源题 ccd554ac 中平铺倍数等于输入的边长（空间属性决定空间属性）；此题中平铺倍数等于归一化后的色数（内容属性决定空间属性）——这一跨域映射是核心发现，需对比不同色数的示例才能归纳。
