## 新题 11：模板尺寸定间距的边缘印章

**组合逻辑**：[印章覆盖](已有) + [等距偏移](创新：间距不是固定值，而由模板的空间尺寸动态决定) + [重涂色](由边缘标记颜色决定) + [从边缘推进](已有方向)

**来源原语**：印章覆盖(stamp_overlay) ← c803e39c/db118e2a；等距偏移(equidistant_offset) ← 05269061；边缘标记(edge_marker)/从边缘推进(advance_from_edge) ← f9a67cb5；模板(template) ← 8e5a5113；重涂色(recolor) ← e9b4f6fc

**依赖链**：模板尺寸 → 决定印章间距（模板的空间属性作为布局参数，源题中无此关系） → 边缘标记位置决定印章列/行起点 → 标记颜色决定印章前景色 → 从边缘向内等距印章。模板同时提供"印什么"和"隔多远"两个信息，移除模板则形状和间距都不确定。

从网格边缘的每个标记像素出发，向内部等距印章模板，间距等于模板在印章方向上的尺寸，颜色取标记颜色。

**输入结构**：约 15×15 黑(0)背景网格。网格的一条边（如左边缘列）上有 2~3 个单色标记像素（颜色各不相同，从蓝(1)、红(2)、黄(4)中选取），其余边缘像素为黑(0)。网格的一个角（如右上角）有一个由栗(9)像素构成的小型模板图案（矩形边界框 2×2 至 4×4，4-连通，非全满），模板内的背景像素为黑(0)。生成约束：各标记像素在垂直于边缘方向上的坐标间距 ≥ 模板在该方向上的尺寸，保证不同标记的印章行不重叠。模板到标记所在边缘的距离 ≥ 模板宽度（保证至少能印一个）。

**规则**：
1. 识别边缘标记（左边缘列上的非黑单像素）和模板（角落的栗(9)连通分量，记录其边界框尺寸 H×W）。
2. 确定印章方向：从标记所在边缘向对面边缘的方向（标记在左边 → 向右印章）。
3. 对每个标记像素 (r, c_edge)：从 (r, c_edge + W) 开始，以 W 为间距，依次放置模板副本（中心对齐到标记的行位置，水平起点为 c_edge + W, c_edge + 2W, c_edge + 3W, ...），直到模板的边界框超出网格右边缘时停止。
4. 每个印章副本中，将模板的栗(9)前景像素替换为该标记的颜色；模板内的黑(0)像素保持为黑(0)。
5. 原始模板（角落）在输出中保持不变。边缘标记像素保持不变。

**关键洞察**：源题 05269061 用固定的 3 偏移量做等距重复；此题的间距由模板自身的宽度动态决定——模板承担双重角色：既定义印章形状，又定义印章间距，是"同一对象的两种属性分别控制两个操作参数"的紧耦合结构。

## 实现要求

1. `main(grid)` 必须实现新题描述中的确定性转换规则，不能只识别 `generate_input()` 的固定模板。
2. `generate_input()` 必须随机生成多样样例，不能固定死。随机维度应覆盖：网格大小、对象数量、位置、颜色、方向、形状参数或关键分支。
3. 生成器必须保证输入满足 `main()` 的隐式假设：对象不重叠、不越界、特殊标记唯一或可区分、匹配关系无歧义、关键分支出现概率相同。
4. 禁止把 ARC 颜色 id 、亮度、拼写等当作人类不可见的数值语义参与排序、大小比较或隐藏映射。颜色变化必须有可见结构线索。注意颜色亮度、拼写等也是不可见信息，若描述中出现违规的颜色id或者亮度，可自行使用少量的固定颜色替代，但注意生成时要在三个以内输入输出网格中对所有变换100%覆盖度。
5. 输出样例要视觉清晰，人类必须能从输入输出对中肉眼辨认出规律。具体要求：避免对象粘连、覆盖关系混乱、同一像素多重语义；不同逻辑步骤产生的结果不要大面积层叠在一起导致无法分辨哪个颜色属于哪个步骤；输入中各元素之间保持足够间距，输出中新增的标记/填充/路径等应与背景和已有元素在颜色上有明显区分；若规则涉及多层叠加，生成时控制对象密度和尺寸，确保叠加区域只占少数像素而非铺满整个网格。
6. 若规则有多个分支，生成器不能长期固定成一个分支；应让分支在随机样例中合理出现。分支概率不必平均——难以发现的隐蔽分支（如少数情况下才触发的特殊规则）应适当提高出现概率，确保在 3 个训练示例中至少出现一次，否则求解者无法归纳该规则。对于颜色映射类规则，确保 2 个左右的示例即可覆盖所有映射关系（每种颜色→颜色的映射至少在某个示例中出现过）。
