## 新题 10：按面积排序的区域分级填色

**组合逻辑**：[排序](创新：排序依据从空间位置改为区域面积) + [洪泛填充](创新：填充颜色由全局排名而非固定周期决定) + [计数](统计区域面积)

**来源原语**：排序(sorting)/区域排列顺序(region_order)/洪泛填充(flood_fill)/等间隔采样填充(periodic_fill) ← 7447852a；计数(counting) ← 6e02f1e3；封闭区域(enclosed_region) ← 7447852a/aba27056

**依赖链**：边界线分割 → 识别封闭区域 → 计算每个区域的像素面积 → 按面积升序排序 → 排名决定填充颜色。计数结果驱动排序；排序结果驱动颜色分配；填充需要精确的区域边界——全局排名与局部填充之间构成非平凡耦合。

计算边界线划分的每个封闭区域的面积，按面积从小到大排名，按排名填充对应颜色。

**输入结构**：约 12×12 黑(0)背景网格。一条连通的红(2)边界线（宽度一像素，可弯折、可分支）将网格分割为 4~6 个大小各异的封闭区域（每个区域的黑(0)像素面积互不相同）。边界线与网格边缘共同围成封闭区域（区域可以以网格边缘为一侧边界）。区域内全部为黑(0)。生成约束：各区域面积严格不相等，避免排名并列。

**规则**：
1. 以红(2)为分隔色，找出所有由黑(0)像素构成的 4-连通封闭区域。
2. 计算每个区域的像素面积（黑(0)像素数量）。
3. 按面积从小到大排序，赋予排名：最小 = 排名 1，次小 = 排名 2，依此类推。
4. 对每个区域进行洪泛填充，颜色由排名决定：排名 1 → 蓝(1)，排名 2 → 绿(3)，排名 3 → 黄(4)，排名 4 → 品红(6)，排名 5 → 橙(7)，排名 6 → 栗(9)。
5. 红(2)边界线保持不变。

**关键洞察**：源题 7447852a 按空间位置（从左到右）排序区域并等间隔填色；此题按面积排序并按排名映射颜色——排序依据和填色规则都不同，求解者必须发现"面积大小 = 排名 = 颜色"这一三级映射链。

## 实现要求

1. `main(grid)` 必须实现新题描述中的确定性转换规则，不能只识别 `generate_input()` 的固定模板。
2. `generate_input()` 必须随机生成多样样例，不能固定死。随机维度应覆盖：网格大小、对象数量、位置、颜色、方向、形状参数或关键分支。
3. 生成器必须保证输入满足 `main()` 的隐式假设：对象不重叠、不越界、特殊标记唯一或可区分、匹配关系无歧义、关键分支出现概率相同。
4. 禁止把 ARC 颜色 id 、亮度、拼写等当作人类不可见的数值语义参与排序、大小比较或隐藏映射。颜色变化必须有可见结构线索。注意颜色亮度、拼写等也是不可见信息，若描述中出现违规的颜色id或者亮度，可自行使用少量的固定颜色替代，但注意生成时要在三个以内输入输出网格中对所有变换100%覆盖度。
5. 输出样例要视觉清晰，人类必须能从输入输出对中肉眼辨认出规律。具体要求：避免对象粘连、覆盖关系混乱、同一像素多重语义；不同逻辑步骤产生的结果不要大面积层叠在一起导致无法分辨哪个颜色属于哪个步骤；输入中各元素之间保持足够间距，输出中新增的标记/填充/路径等应与背景和已有元素在颜色上有明显区分；若规则涉及多层叠加，生成时控制对象密度和尺寸，确保叠加区域只占少数像素而非铺满整个网格。
6. 若规则有多个分支，生成器不能长期固定成一个分支；应让分支在随机样例中合理出现。分支概率不必平均——难以发现的隐蔽分支（如少数情况下才触发的特殊规则）应适当提高出现概率，确保在 3 个训练示例中至少出现一次，否则求解者无法归纳该规则。对于颜色映射类规则，确保 2 个左右的示例即可覆盖所有映射关系（每种颜色→颜色的映射至少在某个示例中出现过）。
