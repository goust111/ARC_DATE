## 新题 6：嵌套边框深度分层填色

**组合逻辑**：[裁剪·完整边框检测](创新：不是选最大/最小，而是检测所有完整边框并建立嵌套层次) + [填充](填色由嵌套深度决定) + [计数](计算嵌套深度)

**来源原语**：矩形框(rectangular_frame)/完整边框检测(complete_border_check) ← 1a6449f1；填充(fill) ← aba27056/d22278a0；计数(counting) ← 6e02f1e3；内部包含(interior_containment) ← aba27056；嵌套层(nested_layer) ← 8fff9e47

**依赖链**：完整边框检测 → 建立嵌套包含层次 → 计算每个边框的深度 → 深度映射为填充颜色 → 填充框间环带。边框检测决定哪些参与嵌套；包含关系决定层次；深度决定颜色；填充需要精确的环带区域——四步因果链中每步的输出改变下一步的输入。

识别所有完整矩形边框并计算嵌套深度，将每层框间环带填充为由深度决定的颜色。

**输入结构**：约 15×15 黑(0)背景网格。网格内有 2~4 个同色（灰(5)）的完整矩形边框（一像素宽的闭合矩形环），严格嵌套（每个内层边框的边界框完全在外层边框的内部区域内，各层之间至少间隔 1 像素）。最内层边框的内部为黑(0)。边框之间和最外层边框之外也是黑(0)。可能存在 1~2 个不完整的矩形边框（边框有缺口），它们不参与嵌套层次。生成约束：嵌套层数 2~4 层；不完整边框不与完整边框在嵌套关系上产生歧义（不完整边框要么在最外层之外，要么在最内层之内）。

**规则**：
1. 识别所有由灰(5)像素构成的完整矩形边框（四条边都完整无缺口的一像素宽闭合矩形）。忽略不完整边框。
2. 建立嵌套关系：若边框 A 的内部区域完全包含边框 B，则 B 嵌套在 A 内。
3. 计算每个完整边框的嵌套深度：最外层深度 = 1，被一层包围 = 2，依此类推。
4. 对每个完整边框，填充其"环带区域"——即该边框内部区域减去其内部所有更深层边框（含边框线）占据的区域。填充颜色按深度映射：深度 1 → 黄(4)，深度 2 → 蓝(1)，深度 3 → 红(2)，深度 4 → 绿(3)。
5. 最内层边框的内部区域（无更深层边框）也按其深度 +1 对应颜色填充。
6. 灰(5)边框线本身不变。最外层边框之外的区域不变。不完整边框的像素不变。

**关键洞察**：源题 1a6449f1 只关心"最大完整边框"并提取其内容；此题要求建立完整的嵌套层次结构——深度决定颜色的映射规则必须通过对比多个示例才能发现（深度 1 不是颜色编号 1）。

## 实现要求

1. `main(grid)` 必须实现新题描述中的确定性转换规则，不能只识别 `generate_input()` 的固定模板。
2. `generate_input()` 必须随机生成多样样例，不能固定死。随机维度应覆盖：网格大小、对象数量、位置、颜色、方向、形状参数或关键分支。
3. 生成器必须保证输入满足 `main()` 的隐式假设：对象不重叠、不越界、特殊标记唯一或可区分、匹配关系无歧义、关键分支出现概率相同。
4. 禁止把 ARC 颜色 id 、亮度、拼写等当作人类不可见的数值语义参与排序、大小比较或隐藏映射。颜色变化必须有可见结构线索。注意颜色亮度、拼写等也是不可见信息，若描述中出现违规的颜色id或者亮度，可自行使用少量的固定颜色替代，但注意生成时要在三个以内输入输出网格中对所有变换100%覆盖度。
5. 输出样例要视觉清晰，人类必须能从输入输出对中肉眼辨认出规律。具体要求：避免对象粘连、覆盖关系混乱、同一像素多重语义；不同逻辑步骤产生的结果不要大面积层叠在一起导致无法分辨哪个颜色属于哪个步骤；输入中各元素之间保持足够间距，输出中新增的标记/填充/路径等应与背景和已有元素在颜色上有明显区分；若规则涉及多层叠加，生成时控制对象密度和尺寸，确保叠加区域只占少数像素而非铺满整个网格。
6. 若规则有多个分支，生成器不能长期固定成一个分支；应让分支在随机样例中合理出现。分支概率不必平均——难以发现的隐蔽分支（如少数情况下才触发的特殊规则）应适当提高出现概率，确保在 3 个训练示例中至少出现一次，否则求解者无法归纳该规则。对于颜色映射类规则，确保 2 个左右的示例即可覆盖所有映射关系（每种颜色→颜色的映射至少在某个示例中出现过）。
