## 新题 1：头部像素定向射线

**组合逻辑**：[射线延伸](方向不再由边缘或开口决定，而由头部标记像素相对精灵体体部的方位编码) + [擦除](射线完成后清除原始精灵体) + [封闭区域](已有，约束射线终止)

**来源原语**：射线延伸(ray_extend) ← aba27056/f9a67cb5；擦除(erase) ← 494ef9d7/fbf15a0b；封闭区域(enclosed_region) ← aba27056/7447852a；标记像素(marker_pixel) ← 8886d717；精灵体(sprite) ← 8ee62060

**依赖链**：头部像素与体部的空间方位 → 编码射线方向（位置信息转化为方向参数，源题中不存在此结构关系） → 射线沿该方向延伸至边界色或网格边缘 → 原始精灵体和头部像素擦除。移除头部方位检测则方向不确定；移除边界约束则射线无终止条件；移除擦除则输出残留原始图形。

从每个封闭区域内精灵体的头部像素出发，沿头部相对体部的方位发射射线至区域边界，然后擦除原始精灵体。

**输入结构**：约 12×12 黑(0)背景网格。绿(3)像素构成连通的边界线，将网格分割为 3~4 个封闭区域（每个区域面积约 8~20 像素）。每个区域内有一个小型 4-连通单色精灵体（3~5 像素，颜色各不相同，从蓝(1)、红(2)、黄(4)、品红(6)中选取），紧邻精灵体的某一侧有一个灰(5)像素作为"头部"。头部与体部恰好 4-邻接，且头部在体部的上/下/左/右某一方向上。不同区域内的精灵体形状可以不同（但均为无旋转对称性的不规则形状），头部朝向也各不相同。生成约束：每个头部到其所在区域边界之间至少有 2 个空像素的直线通道。

**规则**：
1. 对每个封闭区域，定位其中的精灵体（非黑、非绿的连通分量）和紧邻的灰(5)头部像素。
2. 计算头部像素相对于精灵体几何质心（所有体部像素坐标的均值，向最近整数取整）的方位，取最近的基本方向：头部在质心正上方或偏上 → 上；偏右 → 右；偏下 → 下；偏左 → 左。
3. 从头部像素出发，沿该方向逐像素延伸射线，将经过的每个黑(0)像素涂为精灵体的体部颜色。射线遇到绿(3)边界像素或到达网格边缘时停止，不涂终点的边界像素。
4. 将原始精灵体的全部体部像素和灰(5)头部像素设为黑(0)。
5. 绿(3)边界线和其余背景不变。

**关键洞察**：灰色头部像素不是装饰——它相对于精灵体体部的方位是一个方向指令，决定射线的发射朝向；必须对比多个示例才能发现"头部方位 = 射线方向"这一非显然映射。

## 新题 2：边缘线重力堆叠

**组合逻辑**：[滑动](从单像素对扩展到多像素精灵体整体平移) + [擦除](清除原位置) + [边缘线·边缘指示方向](创新：边缘线不再指示射线方向，而编码"重力方向") + [相邻即停止](从像素对扩展到精灵体之间的碰撞停止)

**来源原语**：滑动(slide) ← 494ef9d7；擦除(erase) ← 494ef9d7；边缘线(edge_line) ← 8886d717；边缘指示方向(edge_indicates_direction) ← 8886d717；相邻即停止(adjacent_stop) ← 494ef9d7；精灵体(sprite) ← 8ee62060；内部朝向不变(orientation_preserved) ← 8ee62060

**依赖链**：边缘线位置 → 编码重力方向 → 精灵体沿重力方向整体滑动 → 精灵体之间碰撞检测决定停止位置 → 处理顺序由到边缘的距离决定（近者先落）。边缘线同时决定方向和目标面；碰撞规则将独立的滑动操作耦合为有序堆叠过程。

多个精灵体在边缘线指示的重力方向上整体滑动并堆叠，保持各自形状不变。

**输入结构**：约 15×15 黑(0)背景网格。一条完整的单色实线（橙(7)）占据网格的某一条边（如最下方一整行、最右方一整列等），作为"地面"。网格内散布 3~5 个小型 4-连通单色精灵体（各 3~6 像素，颜色互不相同，从蓝(1)、红(2)、绿(3)、黄(4)、品红(6)中选取）。各精灵体的边界框互不重叠，且在重力方向上互不对齐（即投影到垂直于重力的轴上时，各精灵体的投影区间互不相交），以保证不存在滑动路径冲突。生成约束：每个精灵体与边缘线之间至少有 1 行/列空隙。

**规则**：
1. 识别边缘线所在的边，确定重力方向：边缘线在底边 → 重力向下；在顶边 → 向上；在右边 → 向右；在左边 → 向左。
2. 按各精灵体到边缘线的距离从近到远排序（距离 = 精灵体边界框在重力方向上最靠近边缘线的边到边缘线的像素间隔）。
3. 按此顺序依次处理每个精灵体：将其整体沿重力方向逐像素滑动，保持内部像素布局不变（不翻转、不旋转）。滑动直到精灵体的某个像素与边缘线或已固定的其他精灵体 4-邻接时停止。
4. 将每个精灵体原来位置的像素设为黑(0)。
5. 边缘线本身不变。

**关键洞察**：源题中边缘线指示单像素标记的射线方向；这里边缘线编码整个场景的重力方向，精灵体作为刚体在重力下堆叠——碰撞停止规则将原本独立的滑动操作耦合为全局有序过程。

## 新题 3：标记象限编码旋转与涂色

**组合逻辑**：[旋转](创新：旋转角度不是逐槽位累加，而由标记像素在槽位内的象限位置独立编码) + [重涂色](由标记像素的颜色决定) + [模板·槽位](已有结构)

**来源原语**：旋转(rotate) ← 8e5a5113；重涂色(recolor) ← e9b4f6fc；模板(template)/槽位(slot)/分隔线(divider_line) ← 8e5a5113；标记在面板象限内(marker_in_panel_quadrant) ← 19bb5feb；彩色标记(colored_marker) ← 19bb5feb

**依赖链**：标记像素的象限位置 → 决定旋转角度（位置编码变换参数，源题中无此关系）；标记像素的颜色 → 决定重涂色目标色。同一个标记像素同时编码两个独立参数（旋转 + 颜色），缺少任一参数则输出不确定。

读取每个空槽位中标记像素的象限位置和颜色，将模板旋转至对应角度并涂为对应颜色后填入该槽位。

**输入结构**：约 14×14 黑(0)背景网格。灰(5)分隔线（完整行或完整列）将网格等分为 4~5 个大小相同的矩形槽位。第一个槽位（最左或最上）包含一个由单色非背景像素组成的模板图案（4~8 像素，4-连通，无旋转对称性，颜色为栗(9)）。其余每个槽位内恰好有一个单色彩色标记像素（1 个像素，颜色从蓝(1)、红(2)、绿(3)、黄(4)中选取，各槽位颜色可不同），该标记像素位于槽位内部的四个象限之一（以槽位中心为原点划分左上/右上/左下/右下）。生成约束：模板的边界框严格小于槽位尺寸减 2（保证旋转后仍在槽位内）；每个标记像素明确落在某一象限内，不在中心线上。

**规则**：
1. 提取第一个槽位中的模板图案（记录相对于槽位中心的像素偏移）。
2. 对每个后续槽位，找到其中的彩色标记像素，确定其所在象限：
   - 左上象限 → 旋转 0°（不旋转）
   - 右上象限 → 顺时针旋转 90°
   - 右下象限 → 旋转 180°
   - 左下象限 → 顺时针旋转 270°
3. 将模板按确定的角度旋转，将其所有像素的颜色替换为该标记像素的颜色，放置到该槽位中心。
4. 移除标记像素（被旋转后的模板覆盖，或若未被覆盖则设为黑(0)）。
5. 第一个槽位（模板源）保持原样不变。

**关键洞察**：源题中旋转角度沿槽位顺序累加（0°→90°→180°→...）；此题中每个槽位的旋转由其内部标记像素的位置独立编码——同一个标记像素同时承载空间信息（象限→旋转）和颜色信息（→涂色），需对比多个示例才能发现象限-旋转的对应关系。

## 新题 4：区域矩阵的拉丁方填色

**组合逻辑**：[补全·拉丁方约束](创新：约束对象从单像素提升到整个空间区域) + [洪泛填充](将约束求解结果写回空间域) + [等分网格](提供矩阵结构)

**来源原语**：补全(completion) ← 4cd1b7b2；拉丁方约束(latin_square_constraint) ← 4cd1b7b2；洪泛填充(flood_fill) ← 7447852a；等分网格(equal_partition)/分隔线(divider_line) ← c3202e5a/8e5a5113；封闭区域(enclosed_region) ← 7447852a

**依赖链**：灰分隔线 → 将网格抽象为 N×N 单元矩阵 → 已填单元提供部分约束 → 拉丁方求解确定空单元颜色 → 洪泛填充将颜色写入空间区域。分隔结构定义约束拓扑；约束求解在抽象层面决定颜色；填充在物理层面执行结果——三层缺一不可。

将灰线分隔的 N×N 单元矩阵视为部分填充的拉丁方，求解后将确定颜色洪泛填充到对应空单元中。

**输入结构**：约 11×11 或 14×14 黑(0)背景网格。灰(5)完整行和完整列将网格严格等分为 N×N 个大小相同的正方形单元（N = 3 或 4，每个单元约 3×3 或 4×4 像素）。部分单元被单一非黑、非灰颜色完全填满（如整个单元全为蓝(1)），作为已知条目；其余单元内部全为黑(0)，作为空白待填。使用的颜色恰好 N 种（如 N=3 时用蓝(1)、红(2)、绿(3)；N=4 时加黄(4)）。已填单元已满足拉丁方约束：每行每列各颜色恰出现一次。空白单元的数量和位置保证拉丁方有唯一解。

**规则**：
1. 识别灰(5)分隔线，将网格划分为 N×N 单元矩阵，按行列编号 (r, c)。
2. 读取每个已填单元的颜色（该单元内所有像素的唯一非黑、非灰颜色）。
3. 对每个空白单元 (r, c)，确定唯一满足约束的颜色：第 r 行中未出现的颜色 ∩ 第 c 列中未出现的颜色。
4. 将空白单元内的全部黑(0)像素设为该确定颜色（等效于洪泛填充）。
5. 灰(5)分隔线和已填单元保持不变。

**关键洞察**：源题 4cd1b7b2 在单像素级别做拉丁方补全；此题将约束提升到由分隔线定义的空间区域级别——求解者必须先识别出"单元矩阵"这一抽象结构，再在其上应用约束推理，最后将抽象解映射回空间填充。

## 新题 5：镜像着陆涂色

**组合逻辑**：[平移·镜像位置](已有) + [重涂色](创新：颜色不由显式图例指定，而由着陆位置处的色域隐式决定) + [擦除](清除源侧和色域标记)

**来源原语**：平移(translate)/镜像位置(mirrored_position)/内部朝向不变(orientation_preserved) ← 8ee62060；重涂色(recolor) ← e9b4f6fc；擦除(erase) ← 494ef9d7/fbf15a0b；分隔线(divider_line) ← 8e5a5113

**依赖链**：镜像变换确定精灵体着陆位置 → 着陆位置与目标半区的色域重叠关系确定新颜色 → 精灵体被涂为该颜色。镜像决定"去哪"，色域决定"变什么色"，两者通过空间重叠产生因果耦合——源题中不存在这种"目的地决定属性"的结构关系。

将左半区的精灵体镜像到右半区对应位置，根据着陆处色域的颜色重涂精灵体，然后清除色域和源侧。

**输入结构**：约 15×14（宽为偶数）黑(0)背景网格。一条完整的灰(5)竖线将网格等分为左右两半。左半区有 2~3 个小型 4-连通单色精灵体（各 3~5 像素，颜色互不相同，如栗(9)、品红(6)、橙(7)）。右半区有 2~3 个不重叠的实心矩形色域（每个色域是一个纯色填满的矩形，颜色互不相同，从蓝(1)、红(2)、绿(3)、黄(4)中选取，面积至少 3×3）。生成约束：每个精灵体的水平镜像位置（以灰竖线为对称轴）的边界框严格落在右半区的某一个色域内部，且不同精灵体的镜像落在不同的色域上。

**规则**：
1. 将每个左半区精灵体水平镜像到右半区：对精灵体的每个像素 (r, c)，新位置为 (r, grid_width − 1 − c)。精灵体内部像素的相对布局关于竖轴翻转（即精灵体本身也被水平翻转）。
2. 确定每个镜像精灵体所落入的色域（其边界框完全在某个色域的范围内）。
3. 将镜像精灵体的所有前景像素涂为该色域的颜色。
4. 输出中：左半区全部设为黑(0)；右半区的色域像素设为黑(0)（仅保留涂色后的镜像精灵体）；灰(5)分隔线保留。

**关键洞察**：源题 e9b4f6fc 用显式的二像素图例指定颜色替换；此题中没有图例——着陆位置本身就是颜色来源，镜像变换和颜色决定通过空间重叠隐式耦合。

## 新题 6：嵌套边框深度分层填色

**组合逻辑**：[裁剪·完整边框检测](创新：不是选最大/最小，而是检测所有完整边框并建立嵌套层次) + [填充](填色由嵌套深度决定) + [计数](计算嵌套深度)

**规则**：
1. 识别所有由灰(5)像素构成的完整矩形边框（四条边都完整无缺口的一像素宽闭合矩形）。忽略不完整边框。
2. 建立嵌套关系：若边框 A 的内部区域完全包含边框 B，则 B 嵌套在 A 内。
3. 计算每个完整边框的嵌套深度：最外层深度 = 1，被一层包围 = 2，依此类推。
4. 对每个完整边框，填充其"环带区域"——即该边框内部区域减去其内部所有更深层边框（含边框线）占据的区域。填充颜色按深度映射：深度 1 → 黄(4)，深度 2 → 蓝(1)，深度 3 → 红(2)，深度 4 → 绿(3)。
5. 最内层边框的内部区域（无更深层边框）也按其深度 +1 对应颜色填充。
6. 灰(5)边框线本身不变。最外层边框之外的区域不变。不完整边框的像素不变。

5. 按排序后的块顺序，从最外层到最内层填充每个象限：第 i 个块（i 从 0 开始）的左上像素填入左上象限的第 i 层同心环、右上像素填入右上象限的第 i 层、左下填入左下象限的第 i 层、右下填入右下象限的第 i 层。第 0 层为象限最外圈，第 1 层为次外圈，依此类推，最内层为中心像素。
6. 若 N 为奇数，最内层为象限中心的单个像素；若 N 为偶数，最内层为中心的 2×2 区域。

**关键洞察**：源题 8fff9e47 用固定的空间顺序（逆序行主序）确定层序；此题中层序由块的内容丰富度（色数）动态决定——看起来相同的展开机制因排序键不同而产生完全不同的输出，求解者必须发现"色数排序"这一隐藏的重排规则。
