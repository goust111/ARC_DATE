带尾箭头沿指向发射射线，射线可从网格对边折返续行，
折返次数的额度写在箭头的尾巴长度里。

输入结构：
- 背景为最常见色，散布若干实心墙块。
- 若干直线形箭头：一个彩色头格接一段灰色直尾（长度不一），

规则：
- 每个箭头自头格前方一格起，沿指向逐格用头色涂写射线。
- 射线越出网格边缘时，从同一行（列）的对侧边缘续入；每个箭头
  允许的折返次数等于其尾部灰格数减一。
- 射线在墙块前一格停止；额度用尽后到达网格边缘即停；若绕回

关键洞察：
- 尾巴不是装饰：尾长一格的箭头是停在边缘的普通射线，长尾箭头
  却能把边缘当作虫洞折返——先识破环面拓扑，再发现折返次数被
  编码在尾长里，两层洞察缺一不可。

p = Path("/home/lixinyu/snap/a/key_combo/code/fable/6/015/3.py")
mod = SourceFileLoader("new_arc_task", str(p)).load_module()
sigs = set()
for i in range(100):
    inp = mod.generate_input()
    out = mod.main(inp)
    assert isinstance(inp, np.ndarray)
    assert isinstance(out, np.ndarray)
    assert inp.ndim == 2 and max(inp.shape) <= 30, f"input grid exceeds 30x30: {inp.shape}"
    assert out.ndim == 2 and max(out.shape) <= 30, f"output grid exceeds 30x30: {out.shape}"
    sigs.add(hashlib.md5(inp.tobytes() + str(inp.shape).encode()).hexdigest())
print("variants", len(sigs))
assert len(sigs) >= 20
