```text
从互相遮挡的实心矩形中推断出完整的上下层全序,再把层序循环移位——最顶层沉底、其余各升一层——重新绘制。

输入结构:
- 黑色背景上有若干实心单色矩形,颜色互不相同。
- 每个矩形至少部分可见,可见像素的包围盒等于其完整范围。
- 层序中相邻的任意两个矩形都有重叠区域,保证全序可从遮挡关系唯一推出。

规则:
- 由每种颜色可见像素的包围盒恢复矩形的完整位置与尺寸。
- 对每对重叠矩形,重叠区显示谁的颜色谁就在上,由此汇总出唯一的上下全序。
- 将全序循环移位:原最顶层放到最底,其余每层上移一位;按新序自底向顶在空画布上重绘所有完整矩形。

关键洞察:
- 输入的层序从未显式给出,必须由每处重叠的可见颜色拼出全序;诱饵是简单反转或保持层序,而轮转要求对全序的完整重构,任何一处推错都会在输出中留下痕迹。
```
