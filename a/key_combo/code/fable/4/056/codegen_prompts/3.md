### docstring

```text
在每个含有标记像素的封闭腔体内，按沿腔体内部绕行的最短步数（测地距离）画出循环色环，无标记的腔体保持原样。

输入结构
- 黑色背景上灰色墙体围出若干形状各异的封闭腔体，其中包含凸形腔体与凹形、回廊形腔体。
- 部分腔体内恰有一个非灰色标记像素，其余腔体完全为空。
- 标记颜色属于固定色环序列中的某一色。

规则
- 对每个含标记的腔体，以标记为源点，只允许走腔体内部的四邻步，计算每格的最短路径距离。
- 距离 0 的源点保持标记色；距离每增加 1，颜色从标记色出发沿固定色环 黄→绿→红→青 循环前进一格。
- 灰色墙体、无标记腔体和腔体外背景全部保持不变。

关键洞察
- 色环的层级不是曼哈顿距离而是绕墙的测地距离——在凸腔体中两者恰好一致（这正是陷阱），而在凹形回廊中色带必须沿走廊拐弯延伸，直线距离很近的两格可能相差许多环。
```
