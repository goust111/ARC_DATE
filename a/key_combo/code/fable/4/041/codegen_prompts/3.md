### docstring

```text
网格满足"每次反射同时执行一次固定颜色对换"的四象限对称，补全被抹空的那个象限。

输入结构
- 偶数尺寸网格均分为四个象限，其中一个象限被整块抹成填充色，
  该填充色不在其余画面中出现。
- 其余三个象限满足：共享镜像轴的两个象限互为几何镜像，且颜色经过
  同一个固定的两两对换置换；对角象限之间为点对称且颜色不变
  （对换作用两次自我抵消）。
- 置换只交换部分颜色对，其余颜色是不动点。

规则
- 从可见的相邻象限对的对应像素中读出颜色对换表。
- 按"几何镜像 + 颜色对换"（相邻象限）或"点对称 + 颜色不变"（对角象限）
  的复合关系，从已知象限重建被抹空的象限。
- 输出补全后的完整网格。

关键洞察
- 不动点颜色让部分区域看起来是纯几何镜像，这是诱饵；
  真正的对称操作是反射与颜色对换的复合，沿对角方向对换恰好自我抵消，
  三条对称关系必须整体自洽才能补出缺失象限。
```
