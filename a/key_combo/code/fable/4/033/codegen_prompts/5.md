```text
找到唯一有对称破缺的精灵，用对称性补上缺格，并把修复后的精灵搬到由缺格
局部坐标命名的槽位。

输入结构：
- 正方形画布被整行整列的灰色分隔线划成 3×3 个 3×3 瓦片。
- 若干瓦片内各有一个彩色精灵；除一个精灵外，其余精灵均具有某种精确对称
  （镜像或旋转）。
- 唯一的例外精灵恰有一个本应着色却是黑色的缺格：补上该格后它恢复对称，
  且不存在通过删除单格恢复对称的读法。

规则：
- 逐瓦片检查对称性，找到唯一破缺的精灵及其缺格。
- 依对称性把缺格补成精灵颜色，得到修复精灵。
- 缺格在其瓦片内的局部 (行, 列) 即目标槽位的宏观 (行, 列)：把修复精灵
  完整复制到该槽位。
- 其余所有非分隔线格清为黑色，灰色分隔线保留。

关键洞察：
- 那个黑色缺格身兼三职：它的存在从一群完美对称的诱饵精灵中挑出源精灵，
  它的对称伙伴给出修复内容，它的局部坐标给出投递地址。
```
