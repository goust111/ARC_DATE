```text
数出场上有多少个对象与角落图例框中的原型符号在旋转、镜像与游程压缩意义下同形，
输出一行相应长度的青色格。

输入结构：
- 背景为黑色。一角有一个灰色边框的小图例，框内是一个单色原型符号。
- 场上散布若干单色对象：一部分是原型经旋转、镜像并且（或）沿行列拉伸后的副本，颜色任意；
  另一部分是形状不同的干扰对象，其中可以有与原型同色的。

规则：
- 把每个场上对象裁剪到包围盒，把相邻重复的行与列折叠去除拉伸，得到压缩掩码；原型同样压缩。
- 统计压缩掩码与原型压缩掩码经旋转或镜像后完全相同的对象个数 k（颜色不参与判定）。
- 输出一个 1×k 的网格，全部涂青色。

关键洞察：
- 原型的颜色是诱饵：同色不同形不算，异色同形要算；"同形"必须在去拉伸后的拓扑层面判定，
  直接比像素会漏掉被拉长的副本。
```
