```text
一幅块拼图与它的旋转缩略图各缺一处，先推断旋转角，再让两者互相修补。

输入结构：
- 背景上分离放置两个矩形区域：大图由 n×n 个 k×k 单色色块拼成，小图为 n×n 像素。
- 小图是大图按 90°、180° 或 270° 之一旋转后的逐块缩影：小图第 (i,j) 像素的颜色
  等于大图对应块的颜色。
- 大图恰有一个色块整块缺失（呈背景色），小图恰有一个像素缺失；两处缺失经旋转
  对应后位置不同。
- 输入保证可见部分只与唯一一个旋转角完全吻合。

规则：
- 用可见的块与像素找出唯一自洽的旋转角。
- 按该对应关系，用小图对应像素的颜色把大图缺失块整块填实，用大图对应块的颜色
  填补小图缺失像素。
- 其余一切保持不变。

关键洞察：
- 两个表示互为参照，没有哪一方是完整的"原本"，修复必须双向进行；而对应关系
  本身也是隐藏的——旋转角只能从两处残缺之外的重叠证据中反推。0° 不在候选之列，
  直接按原位对照会在每个示例上失败。
```
