```text
由残缺的对角光路反推物理过程：补全轨迹缺口，并放回被擦掉的红色镜子。

输入结构：
- 黑色背景上有一条蓝色 8 连通对角折线，是某条射线走过的轨迹，但轨迹上有
  若干段缺口；轨迹的转折点处本应各有一段红色镜子，其中大多数已被擦除，
  仅个别保留作为样例。

- 按"射线沿对角直线前进、遇红镜翻转一个坐标方向"的物理规则重放光路，
  把所有缺口补成蓝色，缺口的走向由两侧线段的对角方向唯一接续确定。
- 在每个没有现存镜子的转折点补画红镜：翻转行方向的转折补水平镜段，翻转
  列方向的转折补垂直镜段，镜段落在转折点沿原前进方向的下一格位置。
- 干扰彩条与保留的红镜原样不动。

关键洞察：
- 参与规则的镜子几乎从未被画出，画面上只有它们造成的拐折残迹；每处拐折
  翻转的是行还是列坐标，唯一决定所补镜子的朝向与位置。彩条上的蓝色穿孔
  恰是反证：能被直穿的条不是反射体，只有红色才是镜子。
```
