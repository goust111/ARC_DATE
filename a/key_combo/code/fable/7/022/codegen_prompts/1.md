```text
依左至右将每个灰色字形自身唯一的对称性作为变换，依次复合施加于多色精灵并输出结果。

输入结构
- 黑色背景。上部横排若干（一至三个）3×3 灰色字形，由灰格与黑格组成，彼此以黑列分隔。
- 下部有一个多色精灵。

- 按从左到右的顺序读取字形。
- 每个字形贡献一步变换：即该字形自身在哪种对称操作下保持不变，就对精灵施加哪种操作。

- 输出为最终精灵裁剪至其包围盒的结果。

关键洞察
- 字形不是需要跨示例查表记忆的任意代码：它的形状就是操作本身——检测字形自身的不变对称，
  就读出了要施加的变换。码表从未给出，却处处自明。
```
