### docstring

```text
以精灵内的灰色锚点为原点,把两颗孤立灰点读作两条平移生成元,用它们张成的
点阵在整幅画布上盖章。

输入结构
- 黑色背景;一个小的多色精灵,其内部恰有一格是灰色锚点。
- 画布上另有两个孤立的灰色像素,不与精灵相接。

规则
- 设两条向量分别从锚点指向两个孤立灰点。
- 对所有整数组合 a·v1 + b·v2 平移精灵并全部画出,越出画布的部分裁掉;
  各拷贝互不重叠(输入保证)。
- 灰色锚点作为精灵的一格随每份拷贝一同画出;两个孤立灰点被对应拷贝覆盖。

关键洞察
- 两个孤立像素不是噪声、端点或搬运目的地,而是生成元;输入只画了"一个
  原胞和两条向量",输出才是被它们张成的整张点阵图案。
```
