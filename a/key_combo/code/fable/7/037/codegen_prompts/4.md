一句话总述
按7x7选择器的象限标记把同色缺角环精灵放进对应象限，放置前旋转每个精灵，
使缺口一律落在朝向画布中心的内角。

输入结构
- 背景中有一个7x7选择器块：主体一色，四个3x3象限中心处至多各有一枚标记像素。

规则
- 输出为7x7背景画布，中间一行一列留空，形成四个3x3象限。
- 每枚标记指定一个象限；把同色精灵复制进该象限。
- 复制前将精灵旋转0/90/180/270度，使缺角格恰好位于该象限中离画布中心最近的角上。

关键洞察
精灵在输入中的朝向是干扰信息：朝向不从输入继承，而由装配约束统一决定——
四个缺口都要咬向共同的中心，像拼片互相扣合；只做"按位复制"会在朝向上全错。
