### docstring

```text
实心方块沿分叉河道滑行，进入唯一"既够得着又恰好合身"的口袋；被瓶颈隔断的同尺寸口袋只是诱饵。

输入结构
- 背景为主色；河道色构成一条带分叉的连通通道。
- 通道的各个端点接有边长不一的正方形口袋（口袋区域也是河道色）。
- 通道上有一个 N×N 的异色实心方块（mover）。

规则
- 方块只能在整体处于河道内的前提下滑动，因此宽度小于 N 的路段无法通过。
- 在所有边长恰为 N 的口袋中，找到方块沿通道可达的那一个，
  把方块移入该口袋并恰好填满；方块原位置恢复为河道色。
- 边长不为 N 的口袋，以及因瓶颈而不可达的 N×N 口袋，全部保持不变。

关键洞察
- 目的地由"尺寸恰配"与"通行可达"两个条件共同锁定，缺一不可。
- 单看形状最匹配或距离最近的口袋，往往正是被窄口挡住的诱饵；
  必须沿通道逐段核对通行宽度才能排除它。
```
