### docstring

```text
把条带块逐层的颜色序列沿一条单色路径转录展开，路径形状是新的一维载体。

输入结构
- 网格被一条全宽分隔线分成两侧。
- 一侧是条带块：全部由平行的色带构成，可能是竖直条带（逐列同色）也可能是水平条带（逐行同色），各条带颜色互不相同、厚度不一。
- 另一侧背景上有一条灰色的 4-连通单像素宽路径，恰有两个端点，其中恰有一个端点贴网格边界；路径格数恰等于条带块沿其排列方向的总厚度。

规则
- 先判定条带朝向，把条带块读成逐层颜色序列：每层一项，保留厚度带来的重复（宽 3 的红条带贡献连续三项红）。
- 从贴边端点出发沿路径逐格行走，把该序列依次写到路径的每一格上。
- 输出中条带块与分隔线全部置为背景，只留下被重新着色的路径。

关键洞察
- 路径的灰色不是身份而是空白磁带；条带块的二维外形是冗余的，它的本质是一条一维色序，被搬运到路径这个新的一维载体上，厚度体现为路径上的行程长度。
- 第一眼会想把条带折叠去重的压缩直觉是陷阱：路径长度只与不折叠的逐层序列对得上。
```
