```text
一句话总述
边缘图例给出"旧色→新色"的单跳词典，每个色块沿词典链前进的步数等于它内部
背景色孔洞的数量。

输入结构
- 网格主体是背景上的若干单色色块，每个色块内部封闭着 0 个、1 个或多个背景色
  孔洞（不与外部背景连通）。
- 一条 2×N（或 N×2）图例贴在网格一边：靠外一行是旧色、靠内一行是对应新色。
- 词条可链式衔接（某词条的新色是另一词条的旧色）且无环。
- 训练对中存在同色但孔洞数不同的两个色块，它们的输出颜色不同。

规则
- 读出图例的旧→新单跳映射。
- 对每个色块数出其内部封闭孔洞数 k，把色块颜色沿映射连续代换恰好 k 次
  （若中途颜色不在任何旧色中则停在该色）。
- k=0 的色块保持原色。
- 输出中孔洞保持背景色不变，整条图例区域擦为背景。

关键洞察
第一眼像固定换色表，但同色色块产出不同结果，迫使寻找第二变量——色块自身的
孔洞数是它在映射链上要走的步数；图例提供路径，对象自身编码里程。
```
