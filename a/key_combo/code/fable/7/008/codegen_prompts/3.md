```text
从边缘标记射出一条看不见的直线，沿途穿过的空心矩形框依次被"上一站"的颜色填充。

输入结构：
- 黑色背景网格的某条边上有一个单独的彩色标记像素。
- 场内散布若干一格厚、颜色互不相同的空心矩形框，内部均为空。
- 部分框正好横在从该边缘像素垂直射入网格的直线路径上，其余框偏离路径。

规则：
- 从边缘标记垂直于所在边射入一条不落墨的直线，直到离开网格。
- 路径穿过的第一个框，其内部填充边缘标记的颜色；此后每个被穿过的框，其内部填充上一个被穿过的框的边框颜色。
- 射线本身不画出，未被穿过的框保持空心，其余一切不变。

关键洞察：
- 填充颜色沿穿越顺序接力传递：每个框把自己的边框色交给下一个框，源头是边缘标记；路径与顺序都必须从几何上重建，画面里没有任何一条现成的线。
```
