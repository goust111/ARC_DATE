一句话总述：
沿灰色标尺逐份平铺左端母题，标尺上的红、蓝刻痕分别是竖直翻转与水平镜像
的持续开关，两个状态位独立累积。

输入结构：
- 黑色背景上有一条水平灰色标尺条，长度是母题宽度的整数倍；标尺上散布
  若干格被红色或蓝色刻痕像素替换，每份母题对应的标尺区段内至多含一个刻痕。
- 标尺最左一段的正下方附着一个彩色矩形母题，母题上下不对称且左右不对称；
  标尺其余下方为空。

规则：
- 从左到右按母题宽度把标尺下方划分为等宽区段，逐段铺放母题。
- 维护两个独立的翻转状态位，初始均为原始朝向：某区段的标尺部分含红刻痕时，
  从该区段起竖直翻转位取反；含蓝刻痕时，从该区段起水平镜像位取反。
- 每个区段按两个状态位的当前组合铺放母题（原样 / 竖直翻转 / 水平镜像 /
  双翻转即旋转 180° 的效果）。
- 标尺与刻痕本身保持不变。

关键洞察：
- 刻痕不是局部装饰而是持续生效的开关，且两种颜色控制两条互不干扰的对称轴；
  翻转是双位状态机而非逐份交替——只看仅含红刻痕且逐份出现的示例会误以为
  是简单的交替翻转，含蓝刻痕与空区段的示例会推翻该假设。
