```text
一句话总述：按图例条给出的层序把若干同尺寸面板作为不透明图层叠放，冲突处由
更靠上的图层覆盖。

输入结构：
- 分隔色背景中放着若干同尺寸矩形面板，每个面板由统一底色加若干彩色笔画构成，
  并在固定角落带有一个不参与图案的标签像素，各面板标签颜色互不相同。
- 网格某处另有一条与面板无关的窄色条，由各标签颜色排成一行或一列，不含底色。

规则：
- 色条按从左到右（竖条则从上到下）的顺序给出图层自底向顶的叠放次序，
  标签色相同的面板即对应该次序中的位置。
- 新建一块同尺寸底色面板，按次序把各面板的笔画依次盖上：后盖的笔画覆盖
  先盖的笔画。
- 标签像素与色条本身不出现在输出中。

关键洞察：
- 面板叠加不是透明取并集：孤立的色条并非装饰，而是唯一给出遮挡次序的图例，
  冲突像素的归属完全由它决定。
```
