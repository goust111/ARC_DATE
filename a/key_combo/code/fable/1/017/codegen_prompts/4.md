## 4. 指针环搬运

### docstring

```text
每个精灵内部的黄色像素以局部坐标写出一个宏格地址，所有精灵同时沿这些指针搬到目标槽位，并把黄格补回本色。

输入结构
- 画布被贯穿的灰色分隔行与分隔列切成 3×3 的宏格阵列，每个宏格是 3×3 的小方块区域。
- 部分宏格内有单色精灵，其中恰有一格被黄色覆盖；其余宏格全为背景。
- 把黄色像素在本宏格内的行列位置读作（宏行，宏列），这些指针在有精灵的宏格之间构成一个环：每个精灵指向的槽位互不相同，且恰好都是有精灵的槽位。

规则
- 对每个精灵，读出其黄色像素的局部坐标，作为它要搬去的宏格地址。
- 所有精灵同时搬运：整块图案平移到目标宏格的对应位置，黄色格恢复为该精灵的本色。
- 空宏格保持背景，灰色分隔线原样保留。

关键洞察
- 黄色像素不是要保留的图案内容，而是一条写在图案坐标系里的地址：局部行列即宏观行列；由于指针构成环，逐个"复制过去"会互相覆盖，必须理解为同时置换。
```
