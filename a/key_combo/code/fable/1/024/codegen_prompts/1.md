## 1. 边界播撒，近者优先

```text
每个边界标记以其同色散点的个数为周期向网格内部播撒射线，交叉处距离己方标记近者获胜，散点本身全部抹除。

输入结构
- 黑色背景网格，四条边界上有若干不同颜色的标记像素，均不在角落。
- 网格内部散布这些颜色的孤立散点，位置任意。
- 每种颜色恰有一个边界标记；散点个数因颜色而异。

规则
- 对每种颜色 c，数出内部散点的个数 k，并删除这些散点。
- 从 c 的边界标记向网格内部（垂直于所在边）播撒：在距标记 k、2k、3k……格处
  各涂一个 c 色像素，直到越出对侧边界为止。
- 横向与纵向的播撒射线若命中同一格，保留距自己标记更近的那个颜色
  （示例中不出现等距冲突）。
- 边界标记本身保留。

关键洞察
- 散点是纯粹的计数材料，既不保留也不与标记连线；个数被读成播撒的节拍（周期），
  而交叉竞争由"离源更近"裁决，与颜色和处理顺序无关。
```
