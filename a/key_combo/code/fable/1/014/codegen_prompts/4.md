把三块带蓝色角标的灰色矩形按角标旋回统一朝向后叠加投票，输出获得至少两票的红色图案。

输入结构：
- 黑色背景上散布三个同尺寸灰色矩形，各自被旋转 0°、90°、180°
  或 270° 后放置。
- 每个矩形恰有一个角格为蓝色（方向锚点），内部散布若干红色格。
- 三者是同一幅隐藏图案的三次含噪记录：可能漏画部分真格，
  也可能混入个别多余格。

规则：
- 将每个矩形旋转到使蓝色角标位于左上角的朝向。
- 逐格比对三份记录：在至少两份中为红色的格子判定为真。
- 输出一个该尺寸的灰色矩形，真格涂红，左上角保留蓝色锚点，
  其余为灰色。

关键洞察：
- 三个矩形不是三个独立物体，而是同一幅从未被完整画出的图案的
  三次含噪观测；取交集会丢真格、取并集会收噪声，
  唯有先按锚点对齐、再做多数表决才能还原真相。
