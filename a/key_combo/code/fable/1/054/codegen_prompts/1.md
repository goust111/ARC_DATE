依据上方演示面板现场学到的"哪种颜色反射、哪种颜色可穿透"，在下方主面板中延伸对角蓝色射线。

输入结构
- 一条实心分隔行把网格分为上方小演示面板和下方大主面板。
- 演示面板画有一条已完成的蓝色对角射线轨迹，途中与两种颜色的直线段相遇：
  在其中一种线段处轨迹发生折返，在另一种线段处轨迹径直穿过并覆盖对方。
- 主面板含一条尚未延伸的蓝色对角射线种子，以及同样这两种颜色的若干水平或竖直线段。

规则
- 从演示轨迹读出两种颜色的角色：使轨迹改变方向的是镜子色，被轨迹覆盖穿过的是透明色。

- 从射线种子朝可延伸的对角方向连续涂蓝：下一格若是镜子色则不涂该格，
  遇水平镜翻转行方向、遇竖直镜翻转列方向后继续；其余任何格（含透明色线段）一律涂成蓝色，直到射线离开面板。

关键洞察
- 哪种颜色是镜子不是固定规定：两种颜色在不同示例对中会互换角色，
  必须先从演示轨迹反推出本输入的光学规则，再去推主面板的弹射路径。
