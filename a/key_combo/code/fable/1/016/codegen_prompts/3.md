## 3. 东向沉降与靠山传色

- tags:

### docstring

```text
所有前景对象向右滑动沉降；停稳后每个对象改涂成它沿"依靠链"追溯到的、直接顶住右边界的那个根对象的颜色。

输入结构：
- 背景色占主导，其余为若干互不相触的单色 4 连通对象，颜色各异。
- 对象的行带互相交叠，使沉降后一些对象顶在其他对象的左侧。
- 构造保证沉降终态中每个对象的右侧至多与一个对象相邻，但一个对象的左侧可以同时被多个对象依靠。

规则：
- 把每个对象视为保持形状的刚体，同步向右滑动，直到所有对象都被右边界或无法再动的对象挡住。
- 在终态中，若对象 A 的某格与对象 B 的某格左右相邻且 B 在右，则 A 依靠 B。
- 直接接触右边界的对象保留自身颜色；其余对象沿依靠关系一路向右追溯到接触边界的根对象，整体改涂成根对象的颜色。

关键洞察：
- 输出颜色由碰撞因果链决定：不是按行带取最右者的颜色，而是问"谁挡住了我、又是谁挡住了它"，一路问到墙根。一个高大的根对象可以沿多条支链把自己的颜色传给不同行带的对象，专门击破"逐行看最右"的捷径。
```
