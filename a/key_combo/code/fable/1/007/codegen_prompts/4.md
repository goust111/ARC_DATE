## 4. 缝合边界的传送门射线

- tags:
  - 操作:路径绘制
  - 操作:重涂色
  - 对象:边界标记
  - 对象:成对传送门
  - 关系:同色配对
  - 关系:拓扑缝合
  - 条件:非门边界格终止

### docstring

```text
从红色起点射出的轨迹在边界的同色成对门之间瞬移续行，画出穿越缝合拓扑的完整红色轨迹。

输入结构
- 单一背景色网格，边界上有一枚红色起点标记。
- 另有若干对传送门标记：每种颜色恰好两枚、都位于边界上，颜色互不相同且不为红色。
- 所有标记都不在网格角上。

规则
- 射线自红色起点向网格内部垂直射入，沿直线前进，途经的背景格逐格染红。
- 当射线到达某个边界格：若该格是传送门，则从同色的另一枚传送门格续行，方向为垂直于新边界指向网格内部，传送门格本身保持原色。
- 若到达的边界格不是传送门，则把该格染红并停止。
- 轨迹可以与先前已染红的格相交并继续穿过。

关键洞察
- 边界上的同色成对标记把网格的边"缝"在了一起：射线在门处既不反弹也不绕行，而是从配对的另一处继续；整条轨迹在被缝合的拓扑里其实是一条直线，门的配对关系（而非位置远近）决定它下一段出现在哪里。
```
