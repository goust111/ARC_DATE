```text
每个图块里藏着一个异色像素，它的颜色点名链中下一个图块的主色；按这条隐形链表的顺序修复并拼接所有图块。

输入结构
- 背景上散布若干同尺寸、同一图案但主色各不相同的图块。
- 除一个图块（链尾）是干净的以外，每个图块的图案中恰有一个像素被替换
  成另一图块的主色（异色像素）。
- 图块在画面上的空间排列与链序无关。

规则
- 把每个异色像素读作"本图块指向以该颜色为主色的图块"的指针。
- 链头是主色未被任何异色像素点名的图块；从链头出发沿指针依次访问全部
  图块。
- 将每个图块的异色像素修复为其自身主色，再按访问顺序把图块从左到右
  拼接成一行输出。

关键洞察
- 顺序信息不在几何位置上，而是以"污点颜色=下一块的身份"的方式藏在
  图案内部；污点既是需要修复的缺陷，又是唯一的排序线索——先当指针用，
  再当噪声修。
```
