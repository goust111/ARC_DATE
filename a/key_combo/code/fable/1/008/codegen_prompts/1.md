## 1. 框阵拉丁方（边框即调色板）

- 标签：
  - 操作:填充
  - 对象:空心矩形
  - 对象:对象格阵
  - 关系:行列唯一约束（作用于对象层）
  - 条件:内部色禁用自身边框色

### docstring

```text
在空心方框阵列中为每个空框内部填色，使框阵的内部色构成拉丁方，且任何框的内部色不得与其自身边框色相同。

输入结构：
- 背景为黑色，画布上排列着 n 行 n 列大小相同的空心正方形框。
- 每个框的边框为一种非黑颜色，全部边框颜色恰好构成一个 n 色调色板。
- 部分框的内部已被某调色板颜色实心填满，其余框内部仍是黑色空白。

规则：
- 保持所有边框与已填内部不变。
- 为每个空白内部选一种调色板颜色，使得：框阵的每一行、每一列中，
  n 种颜色作为内部色各出现一次；且每个框的内部色不等于该框自己的边框色。
- 已给线索恰好使同时满足两条约束的填法唯一。

关键洞察：
行列唯一约束作用在"框的阵列"这一抽象层而非像素行列上；调色板并未单独
给出，它藏在边框颜色的集合里，而每个框的边框色同时又是对其内部的一条
否定线索——只用拉丁方约束无法定解，必须把"内部异于边框"当作第二套约束
联立使用。
```
