```text
补上每个三角标组缺失的第四角，补角颜色由整组相对中央调色块所处的象限
查表决定。

输入结构
- 背景为单一颜色；网格中有唯一一个实心 2x2 调色块，四格颜色互不相同。
- 四周散布若干灰色三角标组：每组三个单像素，恰为某个正方形的三个角，
  第四个角缺失。
- 每组整体位于调色块的左上、右上、左下、右下四个象限之一。

规则
- 对每组补出正方形缺失的第四角像素，位置由缺角决定。
- 补角颜色不取灰色：以标组中心相对调色块中心所处的象限为索引，查
  调色块中同象限那一格的颜色作为补角颜色。
- 原有三个灰角与调色块全部原样保留。

关键洞察
- 缺角的方向只决定"画在哪"，与颜色无关；颜色由整组的宏观方位查中央
  色表——示例中特意安排了缺角方向与整组方位不一致的标组，用来戳破
  "按缺角方向取色"的第一直觉。
```
