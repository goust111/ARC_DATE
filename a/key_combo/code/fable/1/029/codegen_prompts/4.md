## 4. 连锁感染

### docstring

```text
定向种子发出一条不可见射线，被击中的空心矩形内部染上射线的颜色，并从其余三边中点向外再发射自身边框色的射线，感染沿链条级联。

输入结构
- 黑色背景上分布若干互不接触的空心矩形，边框颜色互异、边长均为奇数。
- 一处种子由一个彩色像素与一个紧邻的灰色像素组成，灰色像素指示发射方向；
  种子色不同于任何矩形边框色。
- 布局保证：每条射线至多击中一个矩形，每个矩形至多被一条射线击中，
  级联过程无环。

规则
- 种子沿灰色像素所指方向发出一条射线（射线本身不画出）。
- 射线击中某个空心矩形的边框时，该矩形内部被整体填充为该射线的颜色；
  随后该矩形从其余三条边的中点向外各发出一条新射线，
  新射线的颜色是这个矩形自身的边框色。
- 级联进行到所有射线都射出网格或落空为止。
- 输出：所有边框、种子与方向标保持原样，被感染矩形的内部按感染它的
  射线颜色填充，未被击中的矩形内部保持黑色。

关键洞察
- 每个矩形内部的颜色记录的是"谁感染了它"而不是"它自己是谁"；
  必须沿几何可达性追出整条感染谱系，颜色沿链条逐级更替，
  仅看单个矩形无法判定其内部颜色。
```
