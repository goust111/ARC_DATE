```text
一句话总述
每个彩色碎片内部的标记像素指向八个方位之一，把灰色大矩形中对应方位的黑色孔洞填成碎片主色，碎片本身从输出中擦除。

输入结构
- 网格中央有一个灰色实心大矩形，内部挖有若干黑色孔洞；每个孔洞整体位于矩形中心的某个方位（上、下、左、右或四个斜角），不同孔洞的方位互不相同。
- 矩形外散布若干碎片，每个碎片由一种主色像素和恰好一个异色标记像素构成，标记像素不在碎片包围盒中心。
- 部分碎片的形状与某个孔洞的形状完全相同，但那不一定是它的目标孔洞。

规则
- 对每个碎片，取标记像素相对碎片包围盒中心的行列偏移符号，得到八向之一。
- 将灰矩形中位于中心同方位的孔洞的全部黑色像素填成该碎片的主色。
- 输出中所有碎片区域恢复为背景；未被任何碎片指向的孔洞保持黑色；灰矩形保持不变。

关键洞察
- 形状吻合是精心布置的陷阱：碎片不是拼图块而是寻址指令，孔洞按"方位对方位"接收颜色；必须发现碎片内部标记像素这一隐蔽入口，才能得到正确配对。
```
