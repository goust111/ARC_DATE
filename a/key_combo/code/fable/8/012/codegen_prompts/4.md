### docstring

```text
把地图中每个亮格替换成小印章，印章顺时针旋转的刻数等于该亮格到地图中心格的环距。

输入结构：
- 黑底上有两个部件：一个 n×n 的非对称彩色印章精灵，和一个边长为奇数的单色宏地图。
- 地图的中心格永远是亮格，其余亮格散布在中心周围的各层同心方环上。

规则：
- 输出是地图尺寸乘以 n 的黑底大网格，地图每格对应一个 n×n 的块。
- 对每个亮格，取它到中心格的棋盘距离（行差与列差中的较大者）d，把印章顺时针旋转 d 个 90 度后贴入对应块；中心格 d 为 0，贴原样印章。
- 地图的暗格对应的块保持全黑。

关键洞察：
- 印章的朝向没有写在任何格子里，也不是按方位查表——它随亮格离中心的环距逐层累进，中心的原样印章是唯一的定盘星；只有同时读出“粗到细替换”与“径向递增旋转”两层规律，输出才能成立。
```
