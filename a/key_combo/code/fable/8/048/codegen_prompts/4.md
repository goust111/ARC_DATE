### docstring

```text
以图例区展示的彩色小形状为瓦片库存，对灰色掩码做唯一精确覆盖并按图例配色。

输入结构
- 背景为黑色。左上角有一个由单色边线围出的图例区，内部并列摆放若干个小形状，每个形状单独一色。

规则
- 仅用图例中的形状（只允许平移，不旋转不翻转，可重复使用也可不用），对灰色掩码做恰好一次的精确覆盖；该覆盖唯一。
- 将每块放置的瓦片重涂为它在图例中的颜色。
- 图例区及其边线保持不变。

关键洞察
- 瓦片形状不是固定约定而是由图例定义的库存；个别图例瓦片在某些示例中从未被使用，是诱饵；瓦片之间可以互锁，局部背景形状不能作为切分依据，唯一性来自整体的精确覆盖。
```

    1. Pick grid dimensions (3 rows, width 8-14)
    2. Choose 3 distinct non-bg colors as native colors, one per row
    3. Optionally choose 0-2 distractor colors disjoint from native set
    4. For each row, place native-color pixels (30-70% of width), ensuring native is strictly most frequent non-bg, or if tied, its leftmost occurrence is before any tied color
    5. Fill remaining cells with bg and optional distractor pixels (0-3 per row)
    6. Verify each row's native is unambiguously recoverable via the frequency + leftmost tiebreak rule

2. `generate_input()` 必须随机生成多样样例，不能固定死。随机维度应覆盖：网格大小、对象数量、位置、颜色、方向、形状参数或关键分支。注意若描述中存在若干，需实现而不是只有单个，包括object或者对应关系等等。且若涉及到最短路径，则输入网格中必涉及到多条路径，对选择造成干扰。
