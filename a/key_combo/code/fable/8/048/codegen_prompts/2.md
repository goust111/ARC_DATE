### docstring

```text
左侧键值柱以码段高度为键、值段颜色为值，按对象的封闭孔洞数查表配色，查不到码的对象整体删除。

输入结构
- 背景为黑色。左侧若干从顶行垂下的柱，每根柱由两段构成：上段为统一码色（青色）、高度各柱不同，底端一格为该柱的值色（各柱不同）。
- 右侧若干互不接触的灰色连通对象；对象内部有封闭的背景孔洞，边缘另有开向外部的背景凹槽（非封闭）。

规则
- 数出每个灰色对象的封闭孔洞数 n（开向外部的凹槽不计）；若存在码段高度恰为 n 的柱，则该对象整体重涂为该柱底端的值色（孔洞与凹槽保持背景）。
- 若不存在码段高度为 n 的柱，则该对象整体擦除为背景。
- 输出中删去全部键值柱。

关键洞察
- 柱不是调色板序列而是键值表：整柱视为一种颜色、或按位置顺序一一对应都是诱饵（首个示例中位置顺序恰好成立）；对象侧真正的键是封闭孔数，凹槽是伪孔；查不到键的对象被过滤删除，三层判据缺一不可。
```
