```text
从五帧含噪动画中恢复干净精灵，并输出按恒定位移外推的第六帧。

输入结构
- 网格由满宽分隔行分成五个等大的黑底面板，构成一条动画带。
- 同一个多色精灵每帧按恒定向量平移。
- 每帧的精灵有零至两个像素被破坏（被抹成背景或改成错误颜色）；
  精灵同一相对位置的像素在至少四帧中保持正确。

规则
- 识别精灵的逐帧恒定位移，把五帧对齐到同一坐标系。
- 对精灵每个相对位置在五帧间取多数颜色，得到干净精灵。
- 把干净精灵放到第五帧位置再加一次恒定位移处，
  输出单个面板大小的第六帧，不含任何噪声像素。

关键洞察
- 任何单帧都不可信，而答案帧在输入中根本不存在：
  必须先做运动补偿把五帧对齐、逐像素投票去噪，
  再把时间轴向前推一步——直接平移复制最后一帧会把它的噪声一起带走。
```
