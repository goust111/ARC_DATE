```text
依照图例条的长度排名重新决定重叠矩形的前后层序，并重绘整块画布。

输入结构
- 网格由一条满宽灰色分隔线分为上方画布与下方图例区。
- 画布为黑底，数个互相重叠的异色实心矩形按某个隐藏层序绘制而成，
  每个矩形的四条边都至少有一段未被遮挡。
- 图例区为若干水平细条，颜色与画布矩形一一对应，长度互不相同。

规则
- 由可见部分恢复每个矩形的完整范围（四边均有可见段，故完整边界可唯一还原）。
- 图例条越长，对应颜色的矩形在输出中的图层越靠上。
- 按此层序自底向上重绘所有完整矩形；输出仅画布部分，不含分隔线与图例区。

关键洞察
- 图例条不是装饰而是深度表：输入中呈现的遮挡关系是干扰信息，
  真实层序由长度排名给出；且重绘前必须先从可见边框把被遮挡的矩形范围推理还原，
  因为换序后原本被盖住的部分会重新露出。
```
