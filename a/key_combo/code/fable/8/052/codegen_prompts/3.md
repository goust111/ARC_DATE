## 3. 孔洞奇偶指路的双墙堆积

### docstring

```text
按封闭孔洞总面积的奇偶把空心物体推向左墙或右墙堆积，并在落位后用墙色灌满孔洞。

输入结构：
- 网格最左整列与最右整列分别被两种不同颜色的墙填满。
- 中间区域散布若干第三种颜色的 8 连通空心物体，每个物体在内部封闭若干背景孔洞格。
- 物体颜色与两侧墙色都不同。

规则：
- 统计每个物体封闭孔洞的总格数：偶数则目标为左墙，奇数则目标为右墙。
- 把物体从原位清除；同一目标墙的物体按初始位置距该墙由近到远依次水平
  滑向该墙，直到碰到墙或已停稳的物体为止，保持形状不变。
- 每个物体停稳后，将其封闭孔洞填充为目标墙的颜色。
- 两根墙保持不变。

关键洞察：
- 滑动方向与物体自身颜色无关，由孔洞总面积的奇偶裁决；孔洞先充当方向
  指令，落位后又被目标墙色灌注，成为墙的印记。
```

    separation: min Manhattan gap >= 3 between any two objects
    border_margin: >= 1 cell from all grid edges
    fg_density: 10-15% of total grid cells [observed]
  output:
    shape: NxN square where N = number of fg objects
    content: bg everywhere except main diagonal filled with fg color

generation_strategy:
  approach: direct (input-first) -- output is trivially derived from object count
  steps:
    1. Pick N from 2-5 (number of objects)
    2. Pick grid dimensions H in [max(8, 2*N+2)..16], W in [max(10, 2*N+2)..12]
    3. Pick bg=0, fg=8 (or any single non-bg color)
    4. For each of N objects, generate a random 4-connected blob of 2-8 pixels
    5. Place blobs on the grid with >= 3 Manhattan gap between any two and >= 1 cell border margin; retry placement if overlap or gap violated
    6. Output is NxN grid of bg with fg on the diagonal

## 实现要求

1. `main(grid)` 必须实现新题描述中的确定性转换规则，不能只识别 `generate_input()` 的固定模板。禁止不同的input网格输出相同的output网格。
2. `generate_input()` 必须随机生成多样样例，不能固定死。随机维度应覆盖：网格大小、对象数量、位置、颜色、方向、形状参数或关键分支。注意若描述中存在若干，需实现而不是只有单个，包括object或者对应关系等等。且若涉及到最短路径，则输入网格中必涉及到多条路径，对选择造成干扰。
3. 生成器必须保证输入满足 `main()` 的隐式假设：对象不重叠、不越界、特殊标记唯一或可区分、匹配关系无歧义、关键分支出现概率相同。
4. 禁止把 ARC 颜色 id 、亮度、拼写等当作人类不可见的数值语义参与排序、大小比较或隐藏映射。颜色变化必须有可见结构线索。注意颜色亮度、拼写等也是不可见信息，若描述中出现违规的颜色id或者亮度，可自行使用少量的固定颜色替代，但注意生成时要在三个以内输入输出网格中对所有变换100%覆盖度。

6. 若规则有多个分支，生成器不能长期固定成一个分支；应让分支在随机样例中合理出现。分支概率不必平均——难以发现的隐蔽分支（如少数情况下才触发的特殊规则）应适当提高出现概率，确保在 3 个训练示例中至少出现一次，否则求解者无法归纳该规则。对于颜色映射类规则，确保 2 个左右的示例即可覆盖所有映射关系（每种颜色→颜色的映射至少在某个示例中出现过）。
