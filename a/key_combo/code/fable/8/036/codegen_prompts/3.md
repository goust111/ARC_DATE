## 3. 条纹只是量尺，杂点才是答案

- tags:
  - operation:去噪, denoise
  - operation:裁剪, crop
  - object:条纹行列, stripe_line
  - object:噪声像素, noise_pixel
  - relation:主色占优, dominant_color
  - condition:噪声即输出, noise_is_output
- 参考题目题号: 19（e26a3af2）、12（8e5c0c38）、11（73182012）

### docstring

```text
判定条纹方向、按各线主色识破杂点，然后输出的不是洗净的条纹，而是全部杂点在其外接框内组成的图形。

输入结构
- 画布铺满横条纹或竖条纹（不同示例方向不同），每条线都有唯一主色，无独立背景色。
- 稀疏杂点打破条纹：杂点颜色可以与其他条纹线的主色相同，但不出现黑色。
- 全部杂点在其外接框内构成一个连贯图形。

规则
- 分别按行、按列统计主色覆盖数，取覆盖显著更高的方向为条纹方向。
- 与所在条纹线主色不同的像素即杂点。
- 输出为杂点外接框大小的网格：杂点保持原色与相对位置，其余格涂黑色。

关键洞察
- 这不是把画布洗干净的去噪题：条纹与主色只是判定"谁是杂点"的量尺，真正要交付的恰是被去掉的那部分；又因杂点可穿别的条纹主色的"伪装"，不能靠调色板差集抓杂点，只能逐线判定。
```
