找出叠印后重叠处相互抵消恰得第三个精灵的那对精灵，输出被抵消而从未现身的公共部分。

输入结构
- 黑底红前景，六个 4x4 精灵区排成 2 行 3 列，以空行空列分隔，每区一个
  非空掩码。
- 恰有一组三元组 (A,B,C) 满足 C 等于 A 与 B 的逐像素对称差：恰属 A、B
  之一的像素在 C 中存在，同属二者的像素在 C 中消失；且 A∩B 非空、
  A 与 B 各有独有像素。
- 另有一组满足简单并集关系 D∪E=F 的诱饵三元组混在其中。

规则
- 找到唯一满足对称差关系的三元组 (A,B,C)。
- 输出一个 4x4 网格：A 与 B 的交集像素涂绿，其余为黑。

关键洞察
- C 是 A、B 叠印后重叠处相互抵消的残影；答案掩码（交集）在整个画面任何
  位置都从未出现，它恰等于 (A∪B) 与 C 的差。按更显眼的并集关系配对会
  落入诱饵三元组，但那无法解释全部示例对。
