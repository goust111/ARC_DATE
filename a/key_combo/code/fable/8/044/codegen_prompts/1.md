## 1. 图例行序定倍数

- tags:
  - operation:像素放大, pixel_scaling
  - operation:擦除, erase
  - object:图例, legend
  - object:单色对象, mono_object
  - relation:行序编码倍数, order_encodes_scale

- 参考题目: `305b1341`, `f25fbde4`, `b5ca7ac4`

### docstring

```text
按图例行序决定的倍数就地放大各色对象，重叠处按图例行序分层覆盖。

输入结构
- 背景色网格，第 0 列自第 0 行起为单列图例，每行一个颜色样本格。
- 画布其余部分散布若干单色 4 连通对象，颜色恰为图例中出现的颜色。
- 示例保证放大后的对象之间存在重叠区域。

规则
- 清除图例列。
- 图例第 k 行（从 1 数起）颜色对应的每个对象，以其 bbox 左上角为锚，
  整体像素放大 k 倍：每个像素变为 k×k 色块，形状内的背景间隙同步放大。
- 放大结果之间重叠时，图例靠前行的颜色画在上层：按图例从最后一行到
  第一行的顺序依次绘制，后画者覆盖先画者。

关键洞察
- 图例列并不给出任何配色映射；行号本身就是数据——同一个序号既是该色
  对象的放大倍数，又是它在遮挡冲突中的层级。
```
