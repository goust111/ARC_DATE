## 4. 图例环与最近分区

- 参考题目题号：ac0c2ac3、df978a02、edb79dae、e760a62e

### docstring

```text
以两枚种子为中心，在各自最近分区内按图例序列逐环上色，等距处留缝。

输入结构
- 主画布为背景色，含两个不同颜色的孤立种子像素。
- 画布右侧隔一条分隔列有一竖直图例条，自上而下列出若干颜色。

规则
- 对画布每个背景像素，计算它到两枚种子的切比雪夫距离，归属距离更近的种子。
- 归属某种子且距离为 d 的像素，涂成图例自上而下第 d 个颜色；种子自身 d=0 保持原色。
- 距离超过图例长度的像素保持背景；到两枚种子距离相等的像素保持背景，形成分界缝。
- 输出仅保留主画布区域，去掉分隔列与图例条。

关键洞察
- 环不是各自画满整幅再互相覆盖：每个像素先按"最近者得"划归领地，环只在领地内生长。
- 图例是"距离→颜色"的有序调色带而非对象；分界缝是双方并列僵持留下的痕迹。
```
</new_puzzle>

    bg_row: entire row is BLACK; 0-1 rows, at the top [observed]
  grey_shape:
    connected_components: 2-3 (4-connected)
    composition: union of 2-5 axis-aligned rectangles (each 1-4 rows x 2-8 cols)
    rectangles are 4-adjacent (share edge) forming connected irregular shapes
    some components are single rectangles, others are L/T-shaped unions
    grey never appears in col 0; may start as early as col 1
    grey may extend to grid edges (rows or cols)
    total_grey_pixels: 25-55% of grid
  col_1: always bg [observed, except train_0 where grey starts col 1]
  transform: replace every grey pixel with the control color from its row's col 0

generation_strategy:
  approach: output-first
  steps:
    1. Pick grid 12x12, bg=BLACK. Choose 2-3 control colors (non-BLACK, non-GREY).
    2. Build the output first. Place 2-4 axis-aligned colored rectangles (2-8 cols wide, 2-5 rows tall)
       starting at col >=1, ensuring rectangles are 4-adjacent to at least one other (connected groups of 2-3 components).
       Leave col 0 free for controls; separate rectangles from col 0 by >=1 bg col [observed].
    3. Assign each row that overlaps any rectangle a control color from the palette.
       Fill every rectangle cell in that row with the row's control color. Use each color in
       runs of 1-4 consecutive rows to create a striped pattern.
    4. Write col 0 of each active row to its control color. Remaining rows are all-bg (0-1 at top).
    5. Derive input from output by replacing all non-bg non-col0 pixels with GREY.
       This guarantees the grey shape, control markers, and transformation are all consistent.
