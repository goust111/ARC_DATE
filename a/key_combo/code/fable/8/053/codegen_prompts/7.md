### docstring

```text
一句话总述：在主图案中找出钥匙图形的全部出现位置，用这些位置的排布方向
决定对整幅主图案施加哪种变换。

输入结构：
- 网格底部以一条分隔线隔出一个小的单色钥匙图形。
- 分隔线上方是多色主图案，与钥匙同形状的图形（颜色不限）在其中出现若干次。
- 每个示例中这些出现位置或全部同行、或全部同列、或既不全同行也不全同列。

规则：
- 在主图案中找到钥匙形状的所有出现位置（不旋转不翻转，忽略颜色）。
- 出现位置全部同行则输出主图案的左右镜像；全部同列则输出上下镜像；
  两者都不满足则输出旋转 180 度的主图案。
- 输出不包含分隔线与钥匙图形。

关键洞察：
- 钥匙图形本身不参与任何变换，它的价值全在"出现在哪儿"：多个出现位置的
  共线方向才是真正的变换指令，而钥匙自己的形状走向是无关的诱饵。
```

generation_strategy:

    2. Design source rectangle (3-5 x 4-5) with 2-3 interior marker pixels; ensure marker mask has >=2 unique transforms.
    3. Place source on grid filled with fill_color + marker pixels.
    4. Pick 1-5 match count. For each match, choose a transform of the marker mask.
       Place the transformed rectangle (marker pixels + fill_color cells) on the grid ensuring no overlap with source or other matches.
       Allow partial off-grid placement (all marker pixels must be in-bounds).
    5. Build the output grid (source + all filled matches).
    6. Derive input by removing fill_color from match slots (replace with bg), keeping marker pixels.
    7. Scatter 11-35 distractor marker-color pixels on remaining bg cells, verifying none create accidental match slots.
