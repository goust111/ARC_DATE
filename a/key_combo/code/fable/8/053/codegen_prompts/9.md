## 9. 镜带修复

- tags:
  - operation:平铺, tiling
  - operation:镜像, mirror
  - operation:修复, repair
  - object:瓦片, tile
  - object:破损像素, corrupted_pixel
  - relation:中间行翻转的周期结构, mirrored_band_period
  - condition:结构反推恢复, restore_from_structure
- 参考题目：17 (00576224)、10 (cfb2ce5a)

### docstring

```text
一句话总述：识别"整图由瓦片平铺、且中间瓦片行整体左右镜像"的构造，据此
把被涂改的少数像素改回去。

输入结构：
- 网格本应由一个小瓦片按阵列平铺构成，其中位于中间的那一行瓦片整体使用
  瓦片的左右镜像，其余瓦片行使用原瓦片；瓦片自身左右不对称，镜像行因此
  与其余行可分辨。
- 少数像素被涂改成了别的颜色，破坏了这一构造。
- 涂改像素远少于遵循构造的像素，且同一瓦片内坐标在全图各处至多被涂改
  一次，保证多数表决可恢复。

规则：
- 反推瓦片内容：对瓦片内每个坐标，聚合所有瓦片格位（中间行先左右翻转
  回原方向）上该坐标的颜色，取多数色。
- 用反推出的瓦片按同一构造（中间瓦片行镜像）重绘全图，即把每个被涂改
  像素恢复为构造要求的颜色。
- 输出与输入同尺寸。

关键洞察：
- 朴素的周期检测会在中间带上失败——那里的"错位"不是破损而是整行镜像；
  只有察觉这一层构造，冗余才能对齐，破损像素才有唯一的正确恢复值。
```
</new_puzzle>

      Each marker group defines a translation of its template. The shift aligns marker cells
      with same-color cells in the template. Maximal-overlap shift is selected.
      Stamped template must fit in grid, not overlap any source template, and not conflict
      with existing non-bg cells.
  erasure: if a template color is single-pixel AND unused by any marker, that pixel is erased to bg in output [observed, rare - 1/5 examples]
  spacing: all output components are 8-disconnected (Chebyshev >= 2 between any two components)

generation_strategy:
  approach: output-first
  steps:
    1. Choose grid size (13-24, square). Pick background color.
    2. Design 1-3 template sprites (5-10 cells each, 2-4 colors, 3x3-5x5 bbox, 8-connected).
       Ensure one dominant color and 1+ minority colors. Pick one non-majority color per template as its marker_color (1-2 cells of that color in template).
    3. For each template, choose 1-2 placement shifts. Stamp the full template at each shifted position. Verify all stamps fit in grid, don't overlap each other or source templates, and maintain Chebyshev >= 2 between all component pairs.
    4. Build input by removing stamped cells (set to bg) EXCEPT the marker-color cells at each placement (these become the markers). Keep source templates intact.
    5. Optionally add erasure: if a template has a single-pixel color not used as marker, include it in input but erase in output (rare variant).
    6. Validate: all markers are 8-disconnected from templates and each other; marker color uniquely identifies its template; marker relative positions match template subset.
