### docstring

```text
每根色条是一条按颜色寻址的指令——凡含有该颜色的图案行循环右移条长格。

输入结构：
- 一条贯通的灰色分隔列把网格分成左窄右宽两个面板。
- 左面板散放若干水平实心条，颜色互不相同、长度不一、竖直位置任意。
- 右面板为彩色图案，每行至多含一种指令色（左侧条色之一）的像素。

规则：
- 对左面板每根颜色 c、长度 n 的条：右面板中所有含 c 色像素的行
  整体向右循环平移 n 格，移出右端的像素从左端回卷。
- 不含任何指令色的行保持不动。
- 输出仅为处理后的右面板，分隔列与左面板裁去。

关键洞察：
- 条与行的对应不看竖直位置而看内容——条的颜色出现在哪些行，
  指令就作用于哪些行；条在左面板中的竖直摆放位置是诱饵。
```
