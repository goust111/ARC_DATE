### docstring

```text
按从外部穿门进入所需的最少门数给每个房间染色。

输入结构：
- 黑色背景，灰色墙线构成多房间平面图。
- 墙上留 1 像素宽的缺口作为门；部分房间完全密闭无门。

规则：
- 与画布边界连通的背景为外部，记距离 0；背景像素只能经由门穿墙。
- 每个房间的距离 = 从外部到达它所需穿过的最少门数。
- 距离 1 的房间染蓝、距离 2 染红、距离 3 染绿、距离 4 染黄；
  无门可达的房间保持黑色；墙保持灰色不变。

关键洞察：
- 染色与房间的几何位置无关——紧贴画布边界的房间也可能距离很大；
  唯一的度量是门链上的拓扑深度，而不是"内外"或"远近"的直观印象。
```

<description>
Complete straight same-color marker segments across the tiled lattice.

Input structure
The grid is a 3x3 array of equal 2x2 tiles separated by full-width and
full-height separator lines.  Each tile is mostly the same base color, with
a few non-base marker pixels at fixed local offsets inside their tiles.

Rule
For each marker color and local tile offset, connect any pair of markers
that lie in the same tile row or same tile column by recoloring the base
cells between them to that marker color at the same local offset.

Key insight
The colored pixels are endpoints in tile coordinates, not free cells in the
raw grid; the missing pixels are found by completing axis-aligned segments
in the 3x3 tile lattice while preserving the endpoint's local position.
</description>

spec:
  grid: always 8x8
  separator:
    color: single color forming full-width rows and full-height columns
    rows: [2, 5]; cols: [2, 5] — creates a 3x3 lattice of 2x2 tiles
  tiles:
    layout: 3x3 grid, each tile is 2x2
    fill: uniform base color (distinct from separator); base != separator
  markers:
    count_groups: 1-2 marker groups per grid
    each_group:
      color: unique, distinct from base and separator
      local_offset: one fixed (local_r, local_c) in {0,1}x{0,1} per color
      shape: straight line (2 endpoints) or L-shape (3 endpoints, 1 at corner)
      tile_positions: endpoints always at extremes (tile 0 and tile 2 in each spanned axis)
      straight: 2 points sharing same tile-row or tile-col, spanning 0..2
      L-shape: 3 points forming an L — one horizontal pair + one vertical pair meeting at a corner tile
    no_overlap: two markers may share a tile if at different local offsets [observed]
  colors: 3-4 distinct colors total (separator + base + 1-2 marker colors)
  output_rule: for each marker group, fill all base cells between endpoints along shared tile-row/col at the same local offset

generation_strategy:
  approach: output-first
  steps:
    1. Fix grid=8x8, separator at rows=[2,5] cols=[2,5], pick separator color
    2. Pick base color (distinct from separator)
    3. Choose 1-2 marker groups; for each pick a unique marker color and a random local offset in {0,1}x{0,1}
    4. For each group, build the OUTPUT shape in the 3x3 tile lattice:
       - straight: pick axis (H or V), pick fixed coord (0-2), fill all 3 tiles in that line
       - L-shape: pick a corner tile of the 3x3 grid, fill the full row + full column through that corner (5 tiles)
    5. Derive INPUT endpoints by keeping only the extreme tiles of each segment (remove interior fills):
       - straight: keep tiles at positions 0 and 2
       - L-shape: keep the 3 corner/endpoint tiles (two ends of the H-segment + far end of V-segment)
    6. Render grid: fill all tiles with base color, place marker pixels at their local offsets, fill separator lines

## 实现要求

1. `main(grid)` 必须实现新题描述中的确定性转换规则，不能只识别 `generate_input()` 的固定模板。禁止不同的input网格输出相同的output网格。
2. `generate_input()` 必须随机生成多样样例，不能固定死。随机维度应覆盖：网格大小、对象数量、位置、颜色、方向、形状参数或关键分支。注意若描述中存在若干，需实现而不是只有单个，包括object或者对应关系等等。且若涉及到最短路径，则输入网格中必涉及到多条路径，对选择造成干扰。
3. 生成器必须保证输入满足 `main()` 的隐式假设：对象不重叠、不越界、特殊标记唯一或可区分、匹配关系无歧义、关键分支出现概率相同。
4. 禁止把 ARC 颜色 id 、亮度、拼写等当作人类不可见的数值语义参与排序、大小比较或隐藏映射。颜色变化必须有可见结构线索。注意颜色亮度、拼写等也是不可见信息，若描述中出现违规的颜色id或者亮度，可自行使用少量的固定颜色替代，但注意生成时要在三个以内输入输出网格中对所有变换100%覆盖度。
5. 输出样例要视觉清晰，人类必须能从输入输出对中肉眼辨认出规律。具体要求：避免对象粘连、覆盖关系混乱、同一像素多重语义；不同逻辑步骤产生的结果不要大面积层叠在一起导致无法分辨哪个颜色属于哪个步骤；输入中各元素之间保持足够间距，输出中新增的标记/填充/路径等应与背景和已有元素在颜色上有明显区分；若规则涉及多层叠加，生成时控制对象密度和尺寸，确保叠加区域只占少数像素而非铺满整个网格。
6. 若规则有多个分支，生成器不能长期固定成一个分支；应让分支在随机样例中合理出现。分支概率不必平均——难以发现的隐蔽分支（如少数情况下才触发的特殊规则）应适当提高出现概率，确保在 3 个训练示例中至少出现一次，否则求解者无法归纳该规则。对于颜色映射类规则，确保 2 个左右的示例即可覆盖所有映射关系（每种颜色→颜色的映射至少在某个示例中出现过）。
