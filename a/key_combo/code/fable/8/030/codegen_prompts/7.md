找到画面中唯一互为镜像的一对精灵，读出它们示范的镜像轴，并对其余每个精灵原地施加同一种镜像。

输入结构：
- 背景为最常见色，其上散布若干互不接触的 4-连通多色精灵。

- 在所有精灵的紧致裁剪间做匹配，找出唯一互为镜像的一对，并判定它们相差的是左右镜像还是上下镜像。

- 那一对示范精灵自身保持原样。

关键洞察：
- 重复出现的图案不是要提取的答案，而是画在图里的一条指令：
