## 6. 对角导线

- 参考题目：6, 5, 7（396d80d7, 60a26a3e, de1cd16c）
- tags:
  - operation:重涂色, recolor
  - operation:传播, propagate
  - object:小方块, small_block
  - object:源块, source_block
  - relation:仅对角邻接, diagonal_only_adj
  - relation:正交邻接, orthogonal_adj
  - condition:对角导通正交断路, diagonal_conducts_orthogonal_breaks
  - condition:近源胜出等距保持, nearer_source_wins_tie_keeps

### docstring

```text
红蓝两个源块的颜色沿"仅对角接触"的方块链竞相传播，任何存在共边接触的方块都是断路器。

输入结构：
- 黑色背景上散布若干同尺寸的灰色小方块，另有恰好一红一蓝两个源块。
- 有些方块两两只在角上（对角）接触，有些方块与邻块共享边（正交接触）。
- 两个源块自身不与任何方块共边。

规则：
- 与任何方块存在共边接触的方块为绝缘块：既不能被染色，也不向外传导。
- 从红、蓝两个源块同时出发，沿"仅对角接触"的非绝缘方块链逐步传播各自颜色。
- 每个可达的灰块染成链步数较近的那个源的颜色；到两源链步数相等的灰块保持灰色。
- 绝缘块与两源均不可达的方块保持灰色。

关键洞察：
- 连通性判断被整体反转：角接触是导线、边接触是断路器；
  在这张反转的连通图上，还要以链距离做两源竞争，等距处留下灰色的"分水岭"。
```
</new_puzzle>

    so column-overlapping objects stack without crossing.
  output: same grid size; objects preserve shape/color/column; only row changes.
  feasibility: after packing, closed-zone bottom row < open-zone top row (>= 3 row gap observed)

generation_strategy:
  approach: output-first
  steps:
    1. Choose grid H x W in [13,17].
    2. Choose n_closed in [2,3], n_open in [2,4], total in [4,7].
    3. Generate closed rectangular frames (3-5 x 3-5) and open cross sprites (3-5 x 3-5, random arm lengths 1-3).
    4. Assign 3-4 foreground colors; some colors may be shared across 1-2 objects.
    5. Pack closed frames at top of grid (row 0 onward, respecting column overlaps) and open crosses at bottom (row H-1 upward). Ensure a gap >= 3 empty rows between the two zones. This is the OUTPUT.
    6. Derive INPUT by scattering each object to a random row in the middle region, keeping its column fixed. Ensure no pixel overlaps.

## 实现要求

1. `main(grid)` 必须实现新题描述中的确定性转换规则，不能只识别 `generate_input()` 的固定模板。禁止不同的input网格输出相同的output网格。
2. `generate_input()` 必须随机生成多样样例，不能固定死。随机维度应覆盖：网格大小、对象数量、位置、颜色、方向、形状参数或关键分支。注意若描述中存在若干，需实现而不是只有单个，包括object或者对应关系等等。且若涉及到最短路径，则输入网格中必涉及到多条路径，对选择造成干扰。

6. 若规则有多个分支，生成器不能长期固定成一个分支；应让分支在随机样例中合理出现。分支概率不必平均——难以发现的隐蔽分支（如少数情况下才触发的特殊规则）应适当提高出现概率，确保在 3 个训练示例中至少出现一次，否则求解者无法归纳该规则。对于颜色映射类规则，确保 2 个左右的示例即可覆盖所有映射关系（每种颜色→颜色的映射至少在某个示例中出现过）。
