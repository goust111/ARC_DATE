## 3. 缺口通行与染指

- tags:
  - operation:射线延伸, ray_extend
  - operation:重涂色, recolor
  - object:空心矩形, hollow_frame
  - object:标记像素, marker_pixel

  - condition:撞墙染色, stamp_on_block
- 参考题目题号：19 (5b37cb25)、4 (e39e9282)、6 (ec883f72)、2 (50c07299)

### docstring

```text
每个标记沿直线冲向所在矩形框的缺口逃出，途中可穿过任何恰好对准的缺口，撞墙时把停下的格子染成墙的颜色。

输入结构：
- 背景上有若干个一格厚、颜色互不相同的空心矩形框，每个框的墙上恰缺一格（缺口）。
- 每个框内部恰有一个标记像素，与本框缺口同行或同列。
- 各标记的直线路径互不相交。

规则：
- 每个标记沿指向本框缺口的方向做直线运动：穿过缺口继续前进；途中若恰好经过
  其他框的缺口位置则径直穿过，框的内部可以自由穿越。
- 当前方一格是某面墙的墙体像素时停止。
- 把走过的所有格子涂成该标记的颜色，但停止处的最后一格改涂成挡住它的那面墙的颜色。
- 若一路无阻，轨迹一直画到网格边缘，标记本身消失。

关键洞察：
- 缺口不是缺陷而是门：看似必然被前方矩形拦下的射线，只要与那个框的缺口对准
  就会穿过去，因此不能在第一次"相撞"处停笔。
- 轨迹终点的颜色由"谁挡住它"决定，而不是由标记自身决定。
```
