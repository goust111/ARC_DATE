## 7. 条高定节拍

- tags:
  - operation:重涂色, recolor
  - operation:计数, counting
  - object:轨迹路径, trace_path
  - object:竖条, bar
  - object:端点标记, endpoint_marker

- 参考题目题号：3 (a5f85a15)、1 (08ed6ac7)、20 (9841fdad)

### docstring

```text
每条蛇形路径按其种子端颜色找到同色竖条，以竖条高度为周期，沿路径打节拍式重涂。

输入结构：
- 背景上有若干条一格宽、4 连通、互不接触的蛇形开放路径，每条主体为一种颜色，
  且恰有一个端点像素是另一种颜色（种子端）。
- 另有若干根实心竖条，颜色与各条路径的种子端颜色一一对应，高度互不相同。

规则：
- 对每条路径，找到与其种子端同色的竖条，记其高度为 k。
- 从种子端（序号 0）沿路径逐格编号，把序号为 k 的整数倍的格子改涂成种子端颜色，
  其余路径格保持主体色。
- 竖条保持不变。

关键洞察：
- 竖条既不是要重涂的对象也不是干扰项，而是节拍器：它的高度作为参数被传递给
  另一个对象使用。
- 种子端同时承担"计数起点"与"配对钥匙"两个角色，不同路径的节拍周期互不相同。
```

```yaml
    4. Choose grid size large enough for both objects plus padding. Place mask and template in non-overlapping positions with >=1 edge padding each.
    5. Fill mask fg positions with color 8 to build the input grid. Template is placed as-is.
    6. Output is derived by replacing mask-color pixels with colors from the scaled rotated template.
```

2. `generate_input()` 必须随机生成多样样例，不能固定死。随机维度应覆盖：网格大小、对象数量、位置、颜色、方向、形状参数或关键分支。注意若描述中存在若干，需实现而不是只有单个，包括object或者对应关系等等。且若涉及到最短路径，则输入网格中必涉及到多条路径，对选择造成干扰。
