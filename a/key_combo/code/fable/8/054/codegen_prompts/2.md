### docstring

```text
一句话总述：
把散落的灰色部件按接口颜色两两配对、依伸出方向贴合，平移拼成唯一一条链后紧裁输出。

输入结构：
- 黑色背景上散落若干互不接触的灰色部件。
- 每个部件带一个或两个接口像素（非灰非黑），接口像素恰有一个灰色四邻，即从部件边缘向外伸出一格。
- 每种接口颜色在全图恰好出现两次，且分属两个不同部件；恰有两个部件只带一个接口，其余部件各带两个接口。

规则：
- 颜色相同的两个接口互为对接口。对接时只做平移：把一个部件移动到使两个对接口像素相邻、且各自的伸出方向恰好相对。
- 从任一只带一个接口的部件出发，沿接口配对逐个拼接所有部件，得到唯一的链条。
- 拼接完成后，把所有接口像素重涂为灰色，再对全部非背景像素做紧致裁剪作为输出。

关键洞察：
- 接口颜色是跨部件的配对签名，整幅拼装是接口配对图上唯一的一条链；对接的相对位置不靠形状试拼，而由"接口相邻、伸出方向相对"唯一锁定。
```

<description>
List the colors of overlaid straight lines in their only possible bottom-to-top crossing order.

Input structure
The background is the dominant color. Every foreground color is the visible part
of one full one-cell-thick horizontal, vertical, or 45-degree diagonal line.
Higher lines may hide pixels of lower lines at crossings.

Rule
Recover each full line from its visible collinear pixels. At any cell where
multiple recovered lines cross, the visible color is above every other line
through that cell. Return the unique ordering of all line colors that respects
those above/below constraints and whose consecutive colors are lines that
geometrically cross.

Key insight
The visible crossing colors give a partial layer order, and the intended answer
is the unique Hamiltonian chain through the line-intersection graph from the
bottom layer to the top layer.
</description>

  "dst": "replace grid with a one-row color sequence",
  "match_cond": "bottom-to-top layer order from crossings: visible color is above every other line through that pixel",
  "transform": "output the unique order that also forms a chain of geometrically crossing consecutive lines",
  "grid_shape": "1 x number of foreground colors"
}
</annotation>

```yaml
spec:
  grid: square, 7-16 rows/cols; size scales with line count (~3x)
  background: 7 [observed]; dominant color
  lines:
    count: 2-6 distinct foreground colors, each a full 1-cell-thick straight line
    types: horizontal (H), vertical (V), diag-down (D, slope +1), diag-up (U, slope -1)
    span: each line extends across entire grid dimension (H/V always full width/height; D/U clipped at grid edges)
    same-kind: two lines of the same type never cross (parallel); different-kind pairs cross at 0 or 1 cell
    positions: no two lines of the same type share the same parameter (row/col/diagonal offset)
  layering:
    lines are stacked bottom-to-top; at each crossing cell the topmost line's color is visible
    hidden pixels: 0 (top layer) up to ~3 per line; every line has >=2 visible pixels so its type is inferrable
  output:
    shape: 1 x N (N = number of lines)
    content: unique Hamiltonian chain through the crossing graph, ordered bottom-to-top
    consecutive colors in the chain must be lines that geometrically cross
    layer constraints (visible color > hidden colors at each crossing) pin the chain to exactly 1 valid permutation
  crossing_graph:
    not all pairs need to cross (same-kind don't; rare different-kind misses for short diagonals)
    the graph plus layer constraints must yield exactly one valid Hamiltonian chain

    4. Assign N distinct non-background colors to the N lines.
    5. Render grid: fill with background. Draw lines bottom-to-top; each line overwrites all its cells, so higher layers naturally occlude lower ones at crossings.
    6. Verify every line has >=2 visible pixels (so its type/direction is recoverable).
```
