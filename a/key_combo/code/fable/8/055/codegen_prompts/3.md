## 3. 同心计数框

- 参考题目题号：5（a3325580）、13（45a5af55）、12（5289ad53）

  - condition:忽略干扰项, ignore_distractors

### docstring

```text
把每种颜色的重复小件按"单件面积定层序、件数定层厚"压缩成一组同心方框。

输入结构：
- 黑色背景上散落若干单色 4-连通对象。
- 同色对象的形状与大小完全相同；不同颜色的单件面积互不相同。
- 各色对象的件数与其单件面积无固定关系，摆放位置无规律。

规则：
- 对每种颜色统计两个数：单件面积 a 与件数 n。
- 颜色按单件面积 a 从小到大自内向外排层。
- 最内层颜色画成边长等于其件数 n 的实心正方形；其后每种颜色依次向外
  包一圈厚度等于其件数 n 的正方形框。
- 输出即这组同心方框，边长由各层厚度完全决定。

关键洞察：
- 对象的形状与位置全是干扰项；每种颜色只留下两个数——单件面积决定这层
  排在里还是外，件数决定这一层有多厚，两个独立统计量分别编码了同心结构
  的层序与几何。
```
</new_puzzle>

1. `main(grid)` 必须实现新题描述中的确定性转换规则，不能只识别 `generate_input()` 的固定模板。禁止不同的input网格输出相同的output网格。
2. `generate_input()` 必须随机生成多样样例，不能固定死。随机维度应覆盖：网格大小、对象数量、位置、颜色、方向、形状参数或关键分支。注意若描述中存在若干，需实现而不是只有单个，包括object或者对应关系等等。且若涉及到最短路径，则输入网格中必涉及到多条路径，对选择造成干扰。

6. 若规则有多个分支，生成器不能长期固定成一个分支；应让分支在随机样例中合理出现。分支概率不必平均——难以发现的隐蔽分支（如少数情况下才触发的特殊规则）应适当提高出现概率，确保在 3 个训练示例中至少出现一次，否则求解者无法归纳该规则。对于颜色映射类规则，确保 2 个左右的示例即可覆盖所有映射关系（每种颜色→颜色的映射至少在某个示例中出现过）。
