  - condition:满杯溢出, overflow_above_rim
  - condition:脱靶落底, missed_sand_settles

### docstring

```text
灰沙沿所在列下落，落进杯口的入杯染色并按数量堆积，装满则向杯口上方溢出，
脱靶的沙落到画布底部堆成灰堆。

输入结构：
- 黑色背景上有若干开口朝上的单色杯形轮廓，各杯杯口的水平开口区间互不重叠。
- 每个杯内恰有一个非背景、非杯壁色的标记像素。
- 画布上方散落若干灰色孤立像素（沙粒），其所在列可能位于某个杯口区间内，
  也可能不在任何杯口上方。

规则：
- 每粒沙沿所在列竖直下落：若该列位于某杯的杯口开口区间内，则计入该杯；
  否则落到画布底部，在该列与同列其他脱靶沙自底向上堆叠，保持灰色。
- 每个杯把计入的沙粒与杯内标记像素（标记本身算一粒已在杯中的沙）合计
  为 n 粒，全部染成标记色，在杯内自底向上逐行堆积，未满的一行自左向右填；
  杯内装满仍有剩余时，以杯内同宽的列范围在杯口上方继续逐行向上堆积。
- 所有沙粒与标记的原位清空，杯壁保持不变。

关键洞察：
- 杯口的水平开口区间在几何上认领沙列，标记色只负责染色、不负责认领；
  沙的数量守恒决定各杯液面高度乃至溢出到杯口之上，而脱靶的沙以原色在
  画布底部各自成堆。
```
