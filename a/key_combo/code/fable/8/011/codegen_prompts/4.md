```text
总述
右边与底边是两条颜色表头，内部每个彩色像素被重新安置：它的目标格是"其颜色在右表头出现的所有行"与"在底表头出现的所有列"的全部交叉格。

输入结构
- 最右一列与最下一行是表头，其余为内部区域，内部以背景色为主。
- 表头由若干非背景颜色组成，同一颜色可以在一条表头中出现零次、一次或两次。
- 内部散布若干单像素，颜色取自表头用到的颜色集合。

规则
- 对每个内部像素的颜色 c：取右表头中所有颜色为 c 的行组成行集，取底表头中所有颜色为 c 的列组成列集。
- 擦除该像素原位置，把行集与列集的每一个交叉格都涂成 c。
- 若某一侧表头中 c 出现零次，交叉格集合为空，该像素被直接删除。
- 表头两条边保持不变；不同颜色的目标格互不冲突。

关键洞察
- 同一条规则在不同例子里呈现出"移动、复制成两份或四份、凭空消失"三种截然不同的表象；把它们统一起来的是表头出现位置集合的笛卡尔积——颜色在表头中的出现次数不是噪声，而是目标对象的重数。
```
