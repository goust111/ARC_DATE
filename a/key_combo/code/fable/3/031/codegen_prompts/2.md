```text
把互为镜像的容器两两配对，用配对镜像把彼此的内容搬运合并，同时修补双方墙上的缺口。

输入结构：
- 黑色背景上有偶数个彼此分离的单色闭合环形墙容器，每面墙恰缺失一个像素。
- 每面墙自身形状不具有任何镜像对称性。
- 容器可两两配对：一对容器的墙在补上缺口后恰好互为镜像（左右镜像或上下镜像之一，外加平移）。
- 每对容器的内部各含一些另一色像素，是同一图案被拆开的两半：一半在 A 中，另一半以镜像形式在 B 中。

规则：
- 按"墙形状经镜像加平移后全等"给容器配对，并由墙的逐像素对应关系确定唯一的镜像变换。
- 把 A 的内部像素经该变换映入 B，与 B 的内容取并；反之亦然。
- 两面墙的缺口也由对方对应位置的墙像素修补。
- 输出中每对容器均封闭，且内含同一图案的两个互为镜像的完整副本。

关键洞察：
- 单个容器自身毫无对称可用，补全素材藏在另一个容器里；墙的轮廓是配对与对准的唯一钥匙——先把它当形状匹配问题解出等距变换，修缺口与并内容只是同一变换的两次使用。
```
