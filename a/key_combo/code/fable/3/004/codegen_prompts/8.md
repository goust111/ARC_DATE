### docstring

```text
形状沿行、颜色沿列各自恰好出现一次，用这两条不同轴向的约束补全空单元。

输入结构：
- 分隔线把网格分成 N×N 个单元，每个单元含一个小图形，图形具有形状与颜色两个属性。
- 少数单元为空，空位两两不同行且不同列。
- 每一行中 N 种形状各出现一次；每一列中 N 种颜色各出现一次。
- 形状在列方向、颜色在行方向都可重复，形状与颜色的搭配无全局规律。

规则：
- 对每个空单元：形状取其所在行缺失的那种形状，颜色取其所在列缺失的那种颜色。
- 以该形状、该颜色绘制图形补入空单元，其余不变。

关键洞察：
- 两个属性遵守的是不同方向的“恰一次”约束：按行数颜色、按列数形状都会陷入矛盾——
  必须发现形状认行、颜色认列，两条轴各管一个维度。
```
