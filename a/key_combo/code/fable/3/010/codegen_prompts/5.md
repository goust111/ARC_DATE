网格是同一瓦片沿一条轴的两份拷贝，但第二份经过了未知的颜色双射置换，两半
各有黑色缺失；修复须先反解色映射再互相借色，双方同缺处用瓦片内部最强自平移
兜底。

输入结构：
- 网格是某矩形瓦片沿水平或垂直轴复制成的两份相邻拷贝，第二份的每种颜色都被

- 瓦片自身含有更小的内部周期结构。

规则：
- 找出复制轴：在该轴向上两半的对应格（双方可见处）构成一致的颜色一一对应
  关系，另一轴则出现映射冲突。
- 由对应格恢复完整的颜色双射。
- 输出第一半色系下的单个瓦片：第一半可见处取原色，第一半缺失而第二半可见处
  取第二半颜色经逆映射后的颜色。
- 两半同处皆缺失时，用已恢复瓦片中可见像素的最强无冲突自平移向量恢复该格颜色。

关键洞察：
- 两半乍看是两幅无关图案，隐藏的复制关系必须透过颜色双射才能看见；借色必须
  先反解映射，映射也补不上的洞再靠瓦片自身更细的周期，三层机制逐级兜底。
