```text
按同色散点的个数把每根柱改写到新高度，再用新旧高度的涨落方向决定柱的输出颜色。

输入结构:
- 底边上立着若干互不接触、颜色各异、高矮不一的一格宽竖柱。
- 柱子上方的空区散布若干彩色单像素散点，散点颜色都取自柱子的颜色集合。

规则:
- 每根柱的新高度等于与它同色的散点个数：柱子在原列从底边向上重画到该高度；
  同色散点个数为零的柱整根删除，所有散点从画面中清除。
- 比较每根存留柱的新旧高度：变高的柱整根重涂为蓝色，变矮的柱整根重涂为红色，
  高度恰好不变的柱保持自己的原色。

关键洞察:
- 同一份计数被使用了两次：先作为改写后的几何高度，再与被覆盖掉的原始高度做差决定颜色；
  输出中柱的颜色编码的是画面上已经消失的信息（旧高度），
  只看输出柱形或只做直方图统计都推不出蓝红的由来，必须同时握住改写前后两个状态。
```
