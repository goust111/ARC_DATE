### docstring

```text
按每只杯子开口的反方向作为其自身重力，把杯内散落的标记像素沉淀成贴底
液面；装不下的部分从开口喷出为间隔点线。

输入结构：
- 黑色背景上有若干灰色杯状轮廓，开口方向各不相同（上、下、左、右），
  开口宽度为奇数。
- 每只杯的内部是矩形区域，垂直重力方向的宽度记为w，沿重力方向的深度
  记为d。
- 每只杯的内部散落着若干个该杯专属的一种标记色像素；不同杯的标记色
  可以不同。

规则：
- 对每只杯：数出内部标记像素总数k，清空内部。
- 以开口反方向为"下"：从杯底起整层铺设，共铺 k÷w 层（k保证是w的
  倍数），层色为该杯标记色。
- 若层数超过深度d，先铺满全部d层，把多出的 e=k÷w−d 层记为溢出量，
  从开口中线正外侧第一格起，沿开口方向每隔一格涂一个标记色像素，
  共e个。
- 杯轮廓保持不变。

关键洞察：
- 开口不是缺口而是每只杯私有的重力方向说明；散点的意义不在位置而在
  数量，数量先折算为液面层数，超出容积的余量再改写为逃逸点线——
  同一批像素依次穿过"计数→液面→溢出"三层规则。
```
