```text
沿蛇形路径找出两侧珠数相等的隐藏轴珠，把两侧珠子各自沿路径弧长镜像换位。

输入结构:
- 黑色背景上一条一格宽、4-连通、不自交的灰色蛇形路径，
  两端点各只有一个路径邻居。
- 路径上的若干格被彩色珠子占据，珠子总数为奇数；珠色可以重复，
  轴珠的颜色没有任何特殊性。
- 个别示例中恰有一颗颜色全局唯一的珠子，但它并不是轴珠，只是诱饵。

规则:
- 将路径从一端到另一端线性化；沿路径顺序数珠，
  两侧珠子数目相等的那颗珠子是轴珠。
- 轴珠保持原位；对轴珠的每一侧，取该侧从紧邻轴珠的路径格到端点格的格序列，
  把该侧珠子在此序列中的占位整体反转（沿弧长镜像换位，珠子带着颜色移动）。
- 腾空的珠格恢复为灰色路径；路径形状与背景保持不变。

关键洞察:
- 轴珠不由颜色标出，而由"两侧珠数平衡"这一隐含性质决定；
  变换发生在路径展开后的弧长坐标系里，
  画面上珠子的跳动只是一维镜像折叠回二维的影像。
```
