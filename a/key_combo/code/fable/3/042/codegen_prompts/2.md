```text
把账本条里每种颜色按格数分配给面积相等的空腔并整腔填充。

输入结构:
- 背景为黑色。画面一角有一条一格高的彩色"账本条"，由若干段连续同色格组成。
- 其余画面上散布若干灰色空心矩形框，每框内部为一块黑色空腔，
  框边上嵌有一个非灰色单像素标记。
- 每种账本颜色的格数都恰好等于某个空腔的面积，账本颜色与空腔一一对应；
  其中存在格数相同的颜色与面积相同的空腔。

规则:
- 统计账本条中每种颜色的格数。
- 为每个空腔选择一种账本颜色整体填充，需满足：该颜色格数等于空腔面积，
  且该颜色不等于此框标记的颜色。
- 全部空腔与全部账本颜色须构成一一对应；填充后将账本条清为黑色，
  框与标记保持不变。

关键洞察:
- 账本条不是图案而是资源清单：颜色的"数量"兑换成空腔的"面积"；
  当两种颜色数量相同、两个空腔面积相同时，只有框上的禁用标记能锁定唯一分配。
```
