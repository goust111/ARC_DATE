- 由三个完整瓦片确定母版及已出现的三个旋转角，构造未出现的第四个

- 把这些缺失格组成的掩码裁剪到其自身外接矩形，涂成红色输出，其余
  为背景。

关键洞察
- 用来比对的"完整参照"从未在画面上出现——它必须先由旋转家族补全出来；
