从彩色种子块出发，按世代逐层把灰色区块染成与其共享边界最长的已染色邻块的颜色。

输入结构
- 黑色背景上分布若干 4 连通区块：少数是彩色种子块，其余全部为灰色。
- 区块之间可以边相邻；一个灰色区块可能同时与多个区块相邻。

规则
- 第 0 代为全部彩色种子块。
- 每一代同时处理：所有与至少一个已染色区块边相邻的灰色区块，统计它与
  每个已染色区块共享的边数，取共享边数最大的那个已染色区块的颜色
  （以本代开始时的染色状态为准）。
- 重复直到没有灰色区块。输入保证每次比较都有唯一最大值。

关键洞察
- 染色不是一次性的全局多数决：一个灰块即使与某种颜色的"最终势力"接壤
  更多，只要它在更早的世代先被别的颜色够到，就已经定色——颜色沿邻接链
  一代一代传播，时序本身是规则的一部分。
