```text
边缘源像素射出的直线劈开途经对象并使两半滑开，滑开的半块又逐级推动挡路的其他对象。

输入结构
- 黑色背景上散布若干个单色 4 连通实心对象。
- 某一网格边缘上有一个红色源像素，它所在的行（或列）即射线路径，射线
  垂直于该边缘贯穿整个网格。
- 对象可能与该行相交，也可能恰好停在其他对象的滑移路径上。

规则
- 与射线所在行相交的对象：其恰好位于该行上的像素被抹去；位于该行上方
  的像素整体上移一格，位于下方的像素整体下移一格（列方向射线时改为
  左右平移）。
- 任何对象或半块平移后若与另一对象重叠，被撞的对象沿同方向整体平移
  一格，如此逐级传递，直到不再有重叠；输入保证推挤不越出网格。
- 未受波及的对象保持原状。最后把射线所在的整行（列）涂成红色。

关键洞察
- 裂缝不是预先用标记色画在对象内部，而是由穿场而过的射线现场制造；
  且开裂的后果不止于被劈开的对象——滑开的半块像多米诺一样把接触链上
  的对象逐个推离，一处开裂可以改变远处对象的位置。
```
