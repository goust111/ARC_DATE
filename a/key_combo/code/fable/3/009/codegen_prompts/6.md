### docstring

```text
沿树形管道以直线段为单位推进液面，各分支同时前进，输出下一帧。

输入结构：
- 网格被通宽分隔行分成若干等大面板，每块面板画着同一条单格宽的树形通道，入口为根，含拐角与分叉点。
- 把通道按拐角与分叉点切成直线段并按距入口的段深度编号；第 n 块面板中，彩色液体恰好占据段深度不超过 n 的所有通道格，到达末端的分支停止。
- 从入口数起的前两段直线段长度相等。

规则：
- 输出一块面板大小的下一帧：液体扩展到段深度不超过 n+1 的所有通道格。
- 通道与面板其余内容原样保留。

关键洞察：
- 推进的度量单位是"直线段"而非格数或直线距离——前两段等长是诱饵，会诱导"每帧前进固定格数"的假设，该假设从第三帧起失效；
- 分叉处液体分头同时推进，分隔行把网格变成时间轴，答案是从未出现过的下一帧。
```
