```text
拔掉嵌在围墙缺口上充当门塞的灰点，把貌似封闭的腔室焊通成套间，再按套间内真正的计数灰点总数查乱序高度码表上色。

输入结构：
- 轮廓色的围墙在背景上划出若干腔室，视觉上每个腔室都是完全封闭的。
- 灰色单像素分两种放置而颜色毫无差别：一种散落在腔内背景上（计数筹码），四邻皆为背景；另一种恰好嵌在围墙线的一格缺口里（门塞），沿墙方向的两个邻格均为围墙色、垂直墙方向的两个邻格均为两侧腔室的背景。
- 网格一侧竖立若干互不相触的单色竖条，颜色互不相同、高度互不相同，左右排列次序与高度故意无关。
- 保证：拔掉全部门塞后，按四连通并合出的每个套间，其腔内计数灰点总数恰等于某一竖条的高度；门塞不计入任何点数。

规则：
- 把嵌在围墙缺口上的灰点识别为门：该格视为通道，属于套间背景；散落腔内的灰点仍是计数筹码。
- 以围墙像素为障碍对背景做四连通划分，经门格连通的腔室合并为同一套间。
- 对每个套间数出计数灰点总数 n，找到高度恰为 n 的竖条，把该套间的全部背景格（含门格与筹码所在格）填成该条的颜色，筹码随之抹去。
- 围墙、竖条与套间之外的背景保持不变。

关键洞察：
- 同一种灰点有两种身份，身份不写在颜色上而写在拓扑位置上——嵌进墙线的是门塞、浮在房中的是筹码；不拔门塞则房间划分错，把门塞当筹码则点数错，任何一处认错都会让整张"高度=数量"的乱序码表查错行，全盘染错。
```
