从顶行水源落下的水沿货架漫流，货架缺口由横向周期唯一还原，缺口漏水、真端溢流。

输入结构：
- 背景为最常见色；架子色像素构成若干水平线段，全部架子行的布局沿水平方向按同一最小周期重复。
- 若干本应是架子的格子被抹成背景色，形成缺口；未被抹去的架子像素足以唯一推断该周期，缺口在输出中保持背景、不予修补。
- 贴着顶行有一个或多个水色像素，是水源。

规则：
- 先由现存架子像素推断唯一最小横向周期，得出每行架子的完整应有跨度；"应有架子却是背景"的格子即缺口。
- 水从每个水源竖直下落，途经的背景格染成水色，落到某架子段上后沿该架子上方一行向左右两侧漫延。
- 漫延的一侧若先到达缺口正上方，则水灌入缺口（缺口格染成水色）并从缺口下方继续竖直下落，该侧漫延到此为止；若先越过架子的真实端点，则在端点外一格处拐落，从那里继续竖直下落。
- 每一股继续下落的水按同样规则递归处理，直到抵达底边或既有水体。

关键洞察：
- 缺口旁的背景与端点外的背景在画面上一模一样，但一个让水"穿架而漏"、一个让水"绕端而溢"；把架子的断口当成两段独立货架去模拟会得到完全不同的水路，唯一能区分二者的是横向周期相位。
