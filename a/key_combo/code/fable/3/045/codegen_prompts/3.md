```text
散点穿过带缺口的多层筛条下落，停在第一个能接住它的支撑之上并逐个堆叠，落定后取承接筛条的颜色，全部漏过者被擦除。

输入结构
- 背景画布上有若干条水平、一像素厚、颜色互不相同的筛条，各条在不同列位置留有缺口。
- 筛条上方散布同一种颜色的孤立源像素。

规则
- 源像素按所在列竖直下落：正下方紧邻格是筛条像素或已落定像素时停下，
  是缺口或空格则穿过继续下落。
- 同一列的多个源像素按位置低者先落，后落者堆叠在先落者正上方。
- 落定后，源像素改涂为其所在堆最底部所接触的那条筛条的颜色。
- 穿过所有筛条仍未被接住的源像素从输出中擦除。
- 筛条保持不变，源像素原位置清空。

关键洞察
- 缺口不是损坏而是通道：每列的落点由该列自上而下第一个非缺口筛条决定；
  源像素并不保留自己的颜色，而是被承接它的筛条整堆重染。
```
