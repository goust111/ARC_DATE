### docstring

```text
由颜色配对选出的首发精灵开始滑动，撞击逐个唤醒后续精灵，形成一条连锁推移。

输入结构：
- 背景为黑色，青色像素构成固定墙段。
- 若干单色四连通精灵，每个精灵内嵌恰好一个异色标记像素；标记位于精灵包围盒某条边
  的中点格，从包围盒中心指向标记的轴向即该精灵的滑动方向。
- 另有恰好一个孤立单像素控制点，其颜色与且仅与一个精灵的嵌入标记同色。
- 布局保证每次滑动最多与一个精灵相撞，且每个被触发的精灵至少能滑动一步。

规则：
- 标记颜色与控制点相同的精灵为首发者，沿自身方向滑动，直到再进一步就会与墙、网格
  边缘或其他精灵重叠为止。
- 若停下是因为顶住了另一个精灵，被顶住的精灵随即被触发，沿它自己的标记方向以同样
  方式滑动，如此传递下去。
- 从未被触发的精灵保持原位；控制点被消耗擦除；所有精灵连同其嵌入标记整体移动。

关键洞察：
- 控制点不是目的地而是点火器：它只指定链条的第一环；每个精灵的行进方向由自己的
  标记决定，全图的变化是一次沿碰撞链传播的多米诺推移，而不是所有精灵的同时滑动。
```
