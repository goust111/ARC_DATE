```text
推断整幅噪声大图的放大倍率，把它净化并压缩回原始小图。

输入结构
- 输入网格是某张小图按同一整数倍率放大的结果：小图的每个格子被放大成一个同色方块，方块内部混入了少量杂色噪点。
- 使每个方块内部都存在绝对多数色成立的倍率只有一个（不含一倍）。
- 至多有一个方块内部两种颜色数量恰好打平；还原出的小图整体左右镜像对称，且打平方块的镜像对应方块干净无歧义。

规则
- 找出唯一使所有方块都有绝对多数色（至多一块打平）的整除倍率。
- 按该倍率把网格切成方块，每块取多数色作为小图对应格子的颜色。
- 若有打平的方块，用小图的左右镜像对称性，取其对称位置格子的颜色定夺。
- 输出这张净化后的小图。

关键洞察
- 倍率没有写在任何地方，只能由块内颜色是否近乎纯净这一统计特征反推；而最后一块打不平的歧义，要靠先看出成品图的镜像对称才能裁决——两步推断层层递进，缺一步就得不到唯一答案。
```
