```text
用底图的双轴对称表决显影出带洞的入侵残迹，再用入侵图形自身的对称补全洞格，裁剪输出完整入侵图形。

输入结构
- 画布绘有同时具有左右镜像与上下镜像对称的多色底图，底图不含黑色。
- 一个自身左右对称的入侵图形整体覆写了一块区域，逐格以入侵图形各格自身颜色覆写；
  凡覆写色恰与该格底图原色相同的格，画面上不留任何痕迹（天然隐身）。
- 任一格与其三个底图对称伙伴中至多一个被覆写；入侵图形每对自身镜像格中至少一格可显影；
  入侵图形紧致包围框的左右边界列上均有可见残迹格。

规则
- 对每个格取其左右镜像、上下镜像、中心旋转三个底图伙伴，按多数表决还原底图。
- 与还原值不同的格即可见残迹；残迹因隐身格而带洞。
- 以残迹紧致包围框的竖直中线为入侵图形自身的对称轴，把每个洞格补为其在入侵图形内镜像位置的颜色。
- 输出补全后入侵图形的紧致包围框裁剪：图形格保留各自颜色，形外格置黑。

关键洞察
- 入侵图形在画面上从未完整出现，需要两层不同的对称先后接力——底图的双轴对称负责显影，
  入侵图形自身的左右对称负责补洞；把显影出的带洞残迹直接当答案是第一眼陷阱。
```
