```text
让每个方向色像素射出一条看不见的墙，再从种子像素泛洪，涂满没有被隐形墙围住的连通区域。

输入结构
- 背景为黑色。
- 网格上散布若干单像素方向源：红=向右、蓝=向下、绿=向左、黄=向上（码表在全部示例中固定）。
- 恰有一个橙色种子像素，橙色不在方向码表内。

规则
- 每个方向源沿自身编码方向逐格推进，直到网格边缘或撞到任何非背景像素前停下；推进经过的格子记为隐形墙。
- 隐形墙、方向源与种子都不可通行；从种子做四连通泛洪，把可达的背景格全部涂成橙色。
- 输出中方向源保持原样，隐形墙所在格保持黑色，其余不变。

关键洞察
- 围住种子的墙从未被画出：颜色只给出方向，射线因互相截断而留下缺口，
  泛洪是否漏出完全取决于这些看不见的墙段拼没拼严。
```

```bash
p = Path("/home/lixinyu/snap/a/key_combo/code/fable/2/014/1.py")
mod = SourceFileLoader("new_arc_task", str(p)).load_module()
sigs = set()
for i in range(100):
    inp = mod.generate_input()
    out = mod.main(inp)
    assert isinstance(inp, np.ndarray)
    assert isinstance(out, np.ndarray)
    assert inp.ndim == 2 and max(inp.shape) <= 30, f"input grid exceeds 30x30: {inp.shape}"
    assert out.ndim == 2 and max(out.shape) <= 30, f"output grid exceeds 30x30: {out.shape}"
    sigs.add(hashlib.md5(inp.tobytes() + str(inp.shape).encode()).hexdigest())
print("variants", len(sigs))
assert len(sigs) >= 20
```
