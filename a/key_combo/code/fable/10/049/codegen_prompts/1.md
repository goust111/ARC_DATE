## 1. 隐形停靠环

- 参考题目: `6ad5bdfd`(15), `4a1cacc2`(19), `f8b3ba0a`(12), `aaef0977`(7)
- tags:
  - operation:滑动, slide
  - operation:计数, counting
  - object:孤立标记像素, marker_pixel
  - object:多连块, polyomino
  - relation:面积决定停距, area_sets_distance
  - relation:小件优先结算, smallest_first_settling
  - condition:同侧唯一落点, same_side_unique_stop
  - condition:占环让位外移, occupied_ring_yield

### docstring

```text
每个物体沿它与标记共线的方向移动到"距离等于自身格子数"的停靠环上，环位被占则向外让位。

输入结构
- 黑色背景；恰有一个红色标记像素。
- 若干互不同色的单色四连通物体，每个物体与标记同行或同列，
  可分布在标记的上下左右四个方向上；物体不含红色。

规则
- 物体按格子数从小到大依次结算。
- 每个物体只沿它与标记共线的那条直线移动，且始终留在标记同侧；
  目标位置是其最近端到标记的直线距离恰好等于自身格子数——
  离标记过近的物体向外后退，过远的物体向内靠拢。
- 若目标位置已被先结算的物体占用，则沿同方向继续外退到最近的
  不重叠位置；标记不动，物体原位清空。

关键洞察
- 标记周围有一组从未画出的同心停靠环，每个物体的环半径由它自身的
  面积决定；这不是引力吸附——太近的物体反而后退，且小物体优先入环，
  大物体被迫让位外移。
```
</new_puzzle>

    For each connectable color, chain its components in row-major order.
    Each consecutive pair gets a shortest Manhattan L-path (at most 1 bend).

  approach: output-first (build connected chains, then erase paths to get input)
  steps:
    1. Pick grid size in range. Fill with BLUE background.
    2. Place 1-2 horizontal teal wall segments (length 1-8) at distinct rows with >=1 row gap.
    3. For each of 1-4 connectable colors, build a chain of 2-4 small components (1-3 cells) connected by L-shaped paths. Place the full chain (components + path cells) ensuring no overlap with walls or other colors. Use row-major ordering for component placement.
       Avoid ambiguous connector choices: for every adjacent component pair, multiple shortest clear routes are allowed only when prior chain direction or a unique same-color marker determines the chosen route.
       Avoid retracing: while drawing the chain, reject any candidate connector that would traverse a same-color path cell already added by an earlier connector.
    4. For each of 0-4 distractor colors, place a single 1-cell component on an empty bg cell.
    5. Validate all paths are clear (no collision between colors or with walls).
    6. Erase all path cells (set back to bg) to produce the input grid; keep components.
    7. Verify solver reproduces the output from the generated input.
