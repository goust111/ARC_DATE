## 1. 逐色隐形镜轴

- 参考题目: 9 (1f876c06)、16 (538b439f)、3 (6cdd2623)
- tags:
  - operation:镜像, reflect
  - operation:对称补全, symmetry_completion

  - object:前景精灵, sprite
  - relation:同色配对, same_color_pairing
  - relation:私有镜轴, per_color_mirror_axis
  - condition:成对定轴, pair_defines_axis
  - condition:排列方向编码轴向, pair_orientation_encodes_axis

### docstring

```text
每种颜色的孤立像素对各自定义一条从未画出的镜轴，同色的多像素对象须关于自己那条轴补出镜像。

输入结构：
- 黑背景上散布若干孤立单像素，按颜色两两成对。
- 某对的两像素若同行，则定义一条垂直镜轴（该对的垂直平分列）；若同列，则定义一条水平镜轴（该对的水平平分行）。
- 每种成对颜色另有一个同色的多像素连通对象，整体位于该色轴的一侧。
- 不同颜色的轴位置与方向互不相同。

规则：
- 逐色处理：找到该色的孤立像素对，判断其排列方向，得出该色的隐形镜轴。
- 将该色的多像素对象关于这条轴镜像复制到另一侧。
- 保留全部输入像素。

关键洞察：
- 不存在全局对称轴——每种颜色携带自己的私有镜轴，且轴的方向也由像素对自身的排列方向编码。
- 把某个对象误用位置上更近的他色轴是刻意的诱饵；把像素对当作需要连线的端点是第二重诱饵。
```

       majority color fills most pixels (>=5 of 9). b00[2,2] must differ from majority.
    4. Build b01 (edge seed): random 3x3, LR-symmetric, mostly majority color.
       b01[2,1] should be non-majority (it becomes an inner-boundary pixel).
    5. Derive all 8 blocks via D4 symmetry. Assemble 9x9 motif; set center block to bg.
    6. Choose (r0, c0) with r0 in [3, N-12], c0 in [3, N-12]. Place motif on bg grid.
    7. Verify expanded 5x5 block region fits in grid (guaranteed by step 6).

## 实现要求

1. `main(grid)` 必须实现新题描述中的确定性转换规则，不能只识别 `generate_input()` 的固定模板。禁止不同的input网格输出相同的output网格。
2. `generate_input()` 必须随机生成多样样例，不能固定死。随机维度应覆盖：网格大小、对象数量、位置、颜色、方向、形状参数或关键分支。注意若描述中存在若干，需实现而不是只有单个，包括object或者对应关系等等。且若涉及到最短路径，则输入网格中必涉及到多条路径，对选择造成干扰。
3. 生成器必须保证输入满足 `main()` 的隐式假设：对象不重叠、不越界、特殊标记唯一或可区分、匹配关系无歧义、关键分支出现概率相同。
4. 禁止把 ARC 颜色 id 、亮度、拼写等当作人类不可见的数值语义参与排序、大小比较或隐藏映射。颜色变化必须有可见结构线索。注意颜色亮度、拼写等也是不可见信息，若描述中出现违规的颜色id或者亮度，可自行使用少量的固定颜色替代，但注意生成时要在三个以内输入输出网格中对所有变换100%覆盖度。

6. 若规则有多个分支，生成器不能长期固定成一个分支；应让分支在随机样例中合理出现。分支概率不必平均——难以发现的隐蔽分支（如少数情况下才触发的特殊规则）应适当提高出现概率，确保在 3 个训练示例中至少出现一次，否则求解者无法归纳该规则。对于颜色映射类规则，确保 2 个左右的示例即可覆盖所有映射关系（每种颜色→颜色的映射至少在某个示例中出现过）。
