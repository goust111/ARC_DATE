### docstring

```text
仅凭上、左两条边缘投影条与少量内部提示点，重建出互相遮挡的实心彩色矩形。

输入结构：
- 网格顶行与最左列是两条投影条：顶行每格显示该列从上向下看最先碰到的矩形的颜色（该列无矩形则为背景）；最左列每格显示该行从左向右看最先碰到的矩形的颜色。
- 内部画布本身为空，只有每个矩形各有一个同色单像素提示点，落在该矩形应占的区域内。
- 各矩形颜色互不相同，摆放与层级由两条投影条加提示点唯一确定。

规则：
- 由两条投影条的同色连续区段与提示点联立，确定每个矩形的行区间与列区间；被遮挡的区段用提示点消歧。
- 在画布上画出所有实心矩形，前后覆盖关系须与两条投影条完全一致（先画远者，后画近者覆盖）。
- 输出中清除两条投影条（还原为背景），保留重建出的矩形。

关键洞察：
- 参与规则的矩形从未被画出，画面上只有它们的两个一维投影与一粒内点。
- 两条视图各自都有被遮挡的盲区，必须交叉印证并借提示点解出唯一的摆放与前后层级。
```

```yaml
    - radius = D-1, range 1-5; the red square is the largest that stops one cell short of every grey blocker
  constraints:
    - radius >= 1 for every yellow marker (so min Chebyshev dist to any grey >= 2)
    - red square must fit entirely within grid (no clipping)
    - red squares of different yellow markers must not overlap [observed]
    - yellow and grey pixels are preserved in output (red only replaces black)

generation_strategy:
  approach: output-first
  steps:
    1. choose grid size H x W (9-30 x 8-20) and number of yellow markers N (1-3)
    2. for each yellow marker, pick a radius R (1-5); place yellow at position (r,c) such that the (2R+1)-square fits in grid (r >= R, r+R < H, c >= R, c+R < W)
    3. ensure squares do not overlap (Chebyshev between any two yellows > sum of their radii)
    4. for each yellow marker, place at least one grey pixel at Chebyshev distance exactly R+1 (this is the constraining blocker); ensure grey is within grid bounds
    5. optionally scatter additional grey pixels, each at Chebyshev distance > R+1 from its nearest yellow (so they don't reduce any radius below R)
    6. verify no grey pixel is within Chebyshev distance R of any yellow (would invalidate radius)
    7. input = black grid with yellow + grey pixels; output = run solver
```
</generation_spec>
</reference_puzzle>
