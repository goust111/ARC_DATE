## 1. 依长度顺序下落的横条

- tags:
  - operation:重力下落, gravity_drop
  - operation:排序, sorting
  - object:水平条, horizontal_bar
  - object:地面, floor
  - relation:长度排名决定次序, length_rank_order
  - condition:先落定者为后落者障碍, sequential_stacking
- 参考题目题号: 9 (963c33f8), 13 (a61f2674), 17 (17b80ad2)

### docstring

```text
一句话总述
按横条长度从长到短的顺序令其依次竖直下落，先落定的横条成为后落横条的支撑，输出最终堆叠状态。

输入结构
- 背景为黑色，底行为一条灰色地面。
- 空中悬浮若干互不同色的一格高水平横条，长度两两不同，列区间相互重叠。
- 横条初始的竖直高低顺序与长度顺序被刻意错开。

规则
- 将所有横条按长度从长到短排序，依次处理。
- 每根横条保持所在列区间不变，竖直下落，直至其正下方任一列碰到地面或已落定的横条，即停在其上一行。
- 先落定的横条视为静止障碍，参与之后所有横条的支撑判定。
- 输出中地面保持不变，空中不再有悬浮横条。

关键洞察
- 横条之间列区间重叠，落定结果依赖下落次序；逐条核对可发现"按初始高度先低后高下落"与示例矛盾，唯一自洽的次序是按长度从长到短——长度排名在这里扮演的是时间轴的角色，而不是筛选或涂色的依据。
```

  marker_color: one non-blue color (2-8), used only for corner brackets
  frames:
    count: 2-4 non-overlapping rectangles, no bboxes overlap
    corners: four 2x2 L-triomino brackets (TL, TR, BL, BR) at bbox corners
    dimensions: 5-14 per side, height != width (non-square)
    gap: frame bboxes must not overlap (>=0 cells apart)
  blue_motif:
    placement: 2-10 blue(1) pixels in the interior (rows top+1..bottom-1, cols left+1..right-1)
    side: all blue pixels lie strictly in one half, never crossing the reflection axis
    axis: wide frames (w>h) reflect LR; tall frames (h>w) reflect TB
    density: ~10-20% of interior area
    no_overlap: blue never overlaps marker cells or their reflections
  distractors:
    count: 6-13 blue pixels scattered outside all frames, mostly isolated (1-2 cell clusters)
    ratio: ~35-47% of total blue pixel count
  output_rules:
    - keep all marker pixels unchanged
    - for each frame, keep original blue and add its LR/TB reflection
    - erase all blue pixels outside frames

generation_strategy:
  approach: output-first
  steps:
    1. Pick grid size 20-28 x 21-28 and marker color from {2-8}
    2. Place 2-4 non-overlapping non-square rectangular frames (h,w in 5-14, h!=w)
       with 2x2 L-triomino corners at each bbox corner; ensure bboxes don't overlap
    3. For each frame, determine reflection axis (LR if wide, TB if tall);
       randomly place 2-10 blue pixels in one half of the interior (avoiding
       marker cells); verify reflections also avoid marker cells (always true
       since corners are on edge rows/cols and blue is in interior)
    4. Scatter 6-13 distractor blue pixels on empty cells outside all frames
    5. This is the input; output = reflect blue inside frames + erase distractors
