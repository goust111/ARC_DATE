## 4. 按象限转印的刻痕模板

- 参考题目题号: 20 (63613498), 3 (52364a65), 17 (c48954c1)
- tags:
  - operation:形状匹配, shape_match
  - operation:重涂色, recolor
  - operation:镜像, mirror
  - object:模板, template
  - object:L形框, L_frame
  - relation:子形嵌入, subshape_embedding
  - relation:象限决定翻转, quadrant_flip
  - condition:嵌入处刻痕, carve_at_embedding

### docstring

```text
灰色 L 框内的模板经所在象限对应的镜像翻转后，在每个外部对象内部找到唯一嵌入位置，并把那里的像素刻成灰色。

输入结构：
- 黑色背景上有一个灰色 L 框，框内是一个无镜像对称性的单色模板。
- 网格其余部分按中心分四个象限，若干单色大对象各居一个象限，颜色与模板不同。
- 每个对象仅在按其象限翻转后的模板下才恰有唯一的子形嵌入位置，未翻转的
  模板在该对象中没有嵌入位置。

规则：
- 提取模板掩码；对右侧象限的对象先左右翻转掩码，下方象限先上下翻转，
  右下象限两者皆翻，模板所在象限不翻。
- 在每个对象内部找到翻转后掩码的唯一嵌入位置。
- 把嵌入处的对象像素重涂为灰色，其余像素不变。

关键洞察：
- 模板不是整形匹配而是要在对象体内寻找的子形，且它随对象所处象限先行转身，
  翻转错了就找不到嵌入位。
```

```yaml
    right_half: left-right mirror of input

generation_strategy:
  steps:
    1. Pick rows in 2-5, cols in 2-5 (eval uses 3x3 but solver is general).
    2. Fill grid with 0. Randomly place 1-ceil(rows*cols/2) cells of color 7.
    3. Reject if grid is left-right symmetric (ensures non-trivial output).
    4. Return the grid as input.
```
</generation_spec>

## 实现要求

1. `main(grid)` 必须实现新题描述中的确定性转换规则，不能只识别 `generate_input()` 的固定模板。禁止不同的input网格输出相同的output网格。
2. `generate_input()` 必须随机生成多样样例，不能固定死。随机维度应覆盖：网格大小、对象数量、位置、颜色、方向、形状参数或关键分支。注意若描述中存在若干，需实现而不是只有单个，包括object或者对应关系等等。且若涉及到最短路径，则输入网格中必涉及到多条路径，对选择造成干扰。

6. 若规则有多个分支，生成器不能长期固定成一个分支；应让分支在随机样例中合理出现。分支概率不必平均——难以发现的隐蔽分支（如少数情况下才触发的特殊规则）应适当提高出现概率，确保在 3 个训练示例中至少出现一次，否则求解者无法归纳该规则。对于颜色映射类规则，确保 2 个左右的示例即可覆盖所有映射关系（每种颜色→颜色的映射至少在某个示例中出现过）。
