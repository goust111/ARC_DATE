```text
把源图案透过分隔线上唯一的小孔投影到另一侧的屏幕上，成一幅只在屏内保留的倒像。

输入结构
- 一条整行或整列的分隔线上恰有一个背景色缺口，即小孔。
- 分隔线一侧有一个多色源图案；另一侧有一块单色实心矩形屏幕，屏幕不与分隔线相贴，其余全为背景。

规则
- 以小孔单元为对称中心，把源图案的每个像素点对称映射到另一侧，颜色不变。
- 只有落在屏幕矩形内部的映射像素才被画出并覆盖屏色；落在屏外或网格外的一律舍弃。
- 源图案、分隔线、小孔与屏幕其余部分保持原样。

关键洞察
- 轴镜像的诱饵会把像投错位置甚至投不到屏上——成像上下、左右同时颠倒，只有以孔为中心的点对称才与屏上落点一致；屏幕既是画布也是裁剪窗，屏外的像根本不存在。
```

```yaml
  steps:
    1. Choose grid size N in [6..13], make NxN grid
    2. Choose K shape pairs in [1..5]; pick K distinct small 4-connected polyomino shapes (2-6 cells, bbox <= 3x3)
    3. Assign each shape a template color (non-blue, non-black); a color may repeat across shapes but all shapes must be distinct
    4. Place all 2K objects (K templates + K blue copies) on the grid with no overlap and min Manhattan gap >= 2
    5. Grid size must be large enough: roughly N >= 6 + (K-1)*2 to fit objects comfortably
    6. Input = grid with templates in their assigned colors and copies in blue; output = same grid with blue replaced by matched template colors
```
</generation_spec>

## 实现要求

1. `main(grid)` 必须实现新题描述中的确定性转换规则，不能只识别 `generate_input()` 的固定模板。禁止不同的input网格输出相同的output网格。
2. `generate_input()` 必须随机生成多样样例，不能固定死。随机维度应覆盖：网格大小、对象数量、位置、颜色、方向、形状参数或关键分支。注意若描述中存在若干，需实现而不是只有单个，包括object或者对应关系等等。且若涉及到最短路径，则输入网格中必涉及到多条路径，对选择造成干扰。

4. 禁止把 ARC 颜色 id 、亮度、拼写等当作人类不可见的数值语义参与排序、大小比较或隐藏映射。颜色变化必须有可见结构线索。注意颜色亮度、拼写等也是不可见信息，若描述中出现违规的颜色id或者亮度，可自行使用少量的固定颜色替代，但注意生成时要在三个以内输入输出网格中对所有变换100%覆盖度。

6. 若规则有多个分支，生成器不能长期固定成一个分支；应让分支在随机样例中合理出现。分支概率不必平均——难以发现的隐蔽分支（如少数情况下才触发的特殊规则）应适当提高出现概率，确保在 3 个训练示例中至少出现一次，否则求解者无法归纳该规则。对于颜色映射类规则，确保 2 个左右的示例即可覆盖所有映射关系（每种颜色→颜色的映射至少在某个示例中出现过）。
