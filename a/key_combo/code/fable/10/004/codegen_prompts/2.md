### docstring

```text
把散落在不同象限的篡改点经反射折叠到同一象限坐标系，用三票表决的真值颜色拼合出从未画出的幽灵图形。

输入结构:
- 背景网格中有一个偶数高宽的前景面板，其四个象限本应互为左右、上下与 180 度反射。
- 若干位置的像素被改写，改写只使用面板中本来就存在的颜色（无突兀新色）。
- 篡改点可以分散在不同象限，但任一对称轨道（同一象限坐标对应的四个位置）中至多一个位置被改写。

规则:
- 裁剪面板；对每个象限坐标，把四个象限经反射对齐后的四个值做多数表决，三票一致者为该处真值。
- 收集所有与真值不符的位置，把每个失配位置经反射折叠到左上象限坐标系。
- 输出一个象限大小的网格：背景色打底，在折叠后的每个失配坐标画出表决得到的真值颜色。

关键洞察:
- 篡改用伪装色完成且分散于多个象限，既不能靠颜色突兀发现，也不存在可整体裁剪的"坏象限"
  （第一个示例中篡改恰好集中于一个象限，是引向"找坏象限"的诱饵）；
  要求输出的图形在输入中从未完整出现，只能逐轨道表决、再把碎片折叠进规范坐标系拼合，
  且必须画真值颜色而非篡改后的现有颜色。
```

    role: 1-3 panels contain target objects; any panel without a target still contains at least one multicolor distractor object
  target_objects:
    definition: 4-connected non-panel-color component inside a panel bbox that touches exactly 1 bbox side at exactly 1 marker pixel; the rest of the object extends inward away from the side
    count_per_grid: 1-4 total targets across all panels
    side_contact: exactly 1 cell of marker color on the contact side
    shape: 4-connected blob, may be chain (max_degree<=2) or branched (max_degree 3-4); rooted at one side
    size: 2-13 cells; depth from contact side 1-10
    colors: 1-8 distinct colors including marker; interior cells are random non-panel colors
    holes: usually 0, rarely 1 panel-colored hole enclosed by the object
  distractor_objects:
    definition: non-panel-color components inside panel bbox that touch 0 or >=2 sides, or touch 1 side with multiple colors
    panel_coverage: REQUIRED; together with targets, every panel has at least one 4-connected multicolor object
    count_per_panel: 1-6
    size: 1-27 cells
  transform:
    for each target object, fill enclosed panel-colored holes and recolor entire filled shape to its marker color
    all other pixels unchanged

generation_strategy:
  approach: output-first
  steps:
    1. Choose grid size (20-30 x 20-30). Fill entire grid with uniform random noise (all 10 colors).
    2. Choose 2-4 panel colors (distinct from each other). For each, carve a monochrome rectangular-ish blob into the noise at non-overlapping positions (flood-fill style or thick connected region within chosen bbox).
    3. For 1-3 panels, build the OUTPUT target: pick a contact side and marker color (!=panel_color). Place a solid marker-colored blob touching that side at exactly 1 side cell, then grow inward only (size 3-13 cells, 4-connected). This is the output state.
    4. Derive INPUT: replace each target blob cell with a random non-panel color (may include marker with some probability), except the cell(s) on the contact side which stay as marker color. Ensure the object remains one 4-connected component of non-panel colors.
    5. Add distractor non-panel objects in each panel: place 1-6 small components that touch 2+ sides of the bbox (corners/edges), using random colors != panel_color. Ensure every panel has at least one 4-connected object using 2+ colors, either from a target object or from a multicolor distractor.
    6. Verify: each target touches exactly 1 side with uniform marker; distractors touch >=2 sides or have mixed side colors.
