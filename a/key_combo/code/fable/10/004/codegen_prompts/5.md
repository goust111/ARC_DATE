### docstring

```text
把红色源车道精灵的总覆盖面积按面积守恒兑换成最近绿色目的车道的新精灵，并沿既有栅格向上堆叠。

输入结构:
- 背景为最常见色；红色细标记条与绿色细标记条各自划定若干竖直车道。
- 每条红车道内等间距排布若干同形同色的小精灵；每条绿车道内已自底向上堆叠若干同形同色精灵。
- 不同车道的精灵单体面积可以不同。

规则:
- 每条红车道的精灵全部消失，其总面积转移给最近的绿车道。
- 该绿车道按自身精灵的形状与颜色，沿已有堆叠的等间距栅格向上逐个填入新精灵，
  直到新增精灵的总面积恰等于转来的面积。
- 所有标记条移除。

关键洞察:
- 守恒的量是覆盖面积而不是个数；每条绿车道的"兑换率"由它自己精灵的单体面积隐式给出。
  按个数守恒去数（第一个示例中两侧单体面积恰好相同时看似成立）在单体面积不同的示例上立即失败。
```

Recolor each side-marked multicolor object embedded in a monochrome panel to its marker color.

Input structure:
- Same-color 4-connected components form monochrome panel regions.
- The bounding box of a panel may contain 4-connected non-panel-color objects.
- A target object touches exactly one side of its panel bbox, and all of its
  pixels on that side have one marker color.

Rule:
- For every target object, fill any panel-colored holes enclosed by the object.
- Recolor the object and filled holes to the side marker color.
- Leave all other pixels unchanged.

Key insight:
- A multicolor object's single contact side identifies both which object should
  be normalized and which color should replace it.

<description>
Convert each hollow 3x3 symbol to one pixel and slide the pixels clockwise from the marked edge.

Input structure
- The grid has a background, one full-edge marker line, and monochrome hollow 3x3 foreground symbols.
- The symbols lie on a coarse row/column lattice; fully empty lattice rows or columns are absent from the output.

Rule
- Replace each hollow 3x3 symbol with one pixel of its color in the corresponding coarse-grid cell.
- The marker edge gives the compaction direction by clockwise border travel: top -> right, right -> down, bottom -> left, left -> up.
- Preserve the order of non-background pixels while sliding them as far as possible in that direction.

Key insight
- The large picture is a scaled symbolic grid, and the blue edge marker acts as a gravity direction rather than as output content.
</description>
