### docstring

```text
从角落标记出发做洪泛判定各精灵是否可达，可达者平移到水平镜像位置，不可达者被抹除。

输入结构
- 背景为最常见色；蓝色墙体把网格分隔出若干区域，部分墙体与边界相连构成真实隔断。
- 某个角上有一枚洋红标记像素。
- 若干多色小精灵散布各区域，其镜像落点保证为空。

规则
- 从洋红标记做四连通洪泛（蓝墙阻挡），标出可达背景。
- 与可达背景相邻的精灵整体平移到水平镜像列位置 new_c0 = 宽度 − 精灵宽 − 原c0，
  行位置与内部像素布局不变（不翻转图形本身）。
- 被墙隔死、不可达的精灵整体抹为背景。
- 墙与标记原样保留。

关键洞察
- 变换不是无条件的——精灵的命运由它与角落标记之间的连通性决定；
  且"镜像"作用于位置而非形状，二者都判对才能得到输出。
```

```yaml
  motif:
    size: 3x3 (square, = N x N)
    fg_color: any single non-zero color (1-9)
    fg_pixel_count: 3-5 out of 9 [observed 4-5]
    connectivity: not required (1-3 components observed)
    placement: aligned to one of the 9 block positions (block_r, block_c) in {0..2}^2
    self_reference: the block position (block_r, block_c) must itself be a fg pixel in the motif
  output:
    rule: for each fg pixel (r,c) in motif, paste motif into block (r,c); rest is bg
    grid_size: same as input (9x9)
    input_is_subset_of_output: true (the input motif appears as one stamp in the output)

generation_strategy:
  approach: output-first (build output, then extract one stamp block as input)
  steps:
    1. Pick N=3, fg_color from 1-9, bg=0.
    2. Generate a random 3x3 binary mask with 3-5 fg pixels.
    3. Build the 9x9 output by stamping the motif into each block (r,c) where mask[r][c]=1.
    4. Pick any fg pixel position (br,bc) in the mask.
    5. Create 9x9 input as all bg, then paste the motif into block (br,bc).
```
</generation_spec>
</reference_puzzle>

2. `generate_input()` 必须随机生成多样样例，不能固定死。随机维度应覆盖：网格大小、对象数量、位置、颜色、方向、形状参数或关键分支。注意若描述中存在若干，需实现而不是只有单个，包括object或者对应关系等等。且若涉及到最短路径，则输入网格中必涉及到多条路径，对选择造成干扰。
