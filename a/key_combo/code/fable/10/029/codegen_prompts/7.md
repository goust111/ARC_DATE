### docstring

```text
整幅图是某个未给出母版的自相似展开，找出唯一与自指一致性冲突的块并修复。

输入结构
- 网格边长为 n²（n 为 3 至 5），可按 n×n 划分为 n² 个块。
- 除一个块外，非空块内容均为同一 n×n 图案 P，且"哪些块非空"的占用布局恰好等于 P 的前景布局。
- 唯一的坏块或是该空处被涂了杂色，或是该有图案处内容被破坏。

规则
- 由多数一致的非空块读出图案 P。
- 用"占用布局必须等于 P"这一约束定位唯一坏块。
- 将坏块修复为一致状态：该处按 P 应为空则清为背景，应有图案则重涂为 P。
- 输出完全自洽的展开图。

关键洞察
- 块内容与块占用布局互为同一母版的两级拷贝；这种自指一致性既是识别结构的钥匙，
  也是定位与修复坏块的唯一依据——母版本身从未单独出现。
```

```yaml
    chokepoints: 0-3 narrow segments (width < N, length 1-6 pixels) that block the NxN square;
      channel width changes (either taper or widen back to N) are gradual (max 1 pixel difference between adjacent cells)
    no internal bg islands
  transform:
    BFS on NxN-placement graph from mover toward dest
    if reachable — mover overwrites dest position, original mover position filled with river
    if blocked — mover moves to farthest BFS-reachable position, dest unchanged, original mover position filled with river
  outcome: ~50% reached (0 chokepoints), ~50% stuck (1-3 chokepoints, requires N >= 2)

generation_strategy:
  approach: output-first
  steps:
    - Decide reached or stuck (~50/50), then pick N (1-4 for reached; 2-4 for stuck)
    - Pick grid size H=W (10-20, H/N >= 5)
    - Carve channel: divide grid into coarse cells (spacing N+2), self-avoiding random walk
      on coarse grid, render as N-wide corridors connecting consecutive cell centers
    - Place dest at one end of the path (touching grid edge), mover at the other end (near grid edge, interior)
    - For stuck: narrow 1-3 segments between mover and dest to width < N;
      verify with BFS on NxN-placement grid that dest is unreachable
    - Build output: place mover at BFS-farthest reachable position from mover start; fill start with river;
      place dest only if stuck (if reached, mover overwrites dest)
    - Derive input: restore mover to start, restore dest, fill mover's output position with river
    - Final validation: main(input) == expected output
```
</generation_spec>
</reference_puzzle>
