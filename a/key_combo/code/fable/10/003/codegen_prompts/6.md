### docstring

```text
以共享边长的多数决逐波给拼图区域染色，先染成的区域在下一波成为新的颜色源。

输入结构
- 网格被黑色与灰色的4连通区域交错铺满（同色区域互不相邻）。
- 少数彩色标记像素嵌在部分区域内部，是最初的颜色源。

规则
- 第一波：每个含有或边邻接标记像素的区域，
  染成与其共享边数最多的标记的颜色。
- 之后每一波：每个尚未染色、但与已染色区域边邻接的区域，
  统计与各颜色共享的边界长度，染成共享边界最长的那个颜色；
  构造保证每次统计无并列。
- 重复直到所有黑灰区域染毕；标记像素保持原样。

关键洞察
- 颜色不是从最近的标记一步读出的：远离标记的区域由先染色的邻区
  逐波接力决定，共享边界最长的邻居才有话语权，
  染色次序本身参与决定结果。
```

  bars:
    count: 1-4 obstacle bars, each a 1-cell-wide line perpendicular to the path direction
    orientation: horizontal bars for vertical path, vertical bars for horizontal path
    wall_attachment: each bar touches one side-wall and leaves a gap on the other; consecutive bars alternate walls (left/right or top/bottom)
    length: 6-15 cells; spans 32-79% of cross-axis
    color_pattern: from wall-attached end toward open end, alternating B-R-B-R...B (length 2*blue_count-1), then solid R for the remainder
    blue_count: 1-4 per bar; encodes keepout radius (path must stay Manhattan distance > blue_count from every bar cell)
    cross_gap: cross-axis uncovered cells = cross_size - bar_length >= blue_count + 1
  layout:
    bars sorted along main axis from start edge; inter-bar gap >= blue_A + blue_B + 1
    start-to-first-bar gap >= first_bar_blue + 1
    last-bar-to-end gap >= 1
    start cross-axis position falls within first bar's covered range [observed]
  output:
    green path from start edge to opposite edge, right-angle turns around bar keepout zones (2 turns per bar)
    blue pixels all become red; path painted green on bg cells

generation_strategy:
  approach: path-first
  steps:
    1. Pick grid size, main axis direction (vert/horiz), start edge, and bar count N (1-4)
    2. Assign blue counts b_1..b_N (each 1-4) and choose alternating wall sides for bars
    3. Place bars along main axis with sufficient spacing; inter-bar gap >= b_i + b_{i+1} + 1; start gap >= b_1 + 1; end gap >= 1
    4. For each bar, pick length so cross-gap >= b_i + 1; fill color pattern B-R alternating from wall end
    5. Run the solver (Dijkstra pathfinding) to get the green path; verify it reaches the opposite edge
    6. Place green start pixel on the start edge within the first bar's cross-axis coverage
    7. Output = input + green path painted + blue->red; input = grid with bars + green start only
