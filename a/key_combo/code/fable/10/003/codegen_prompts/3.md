- 参考题目：11（321b1fc6）、3（898e7135）

### docstring

```text
把多色模板按各自的倍率与朝向转印到每个放大占位体上，并挖掉与占位色同色的模板格。

输入结构
- 黑色背景上有一个小的多色模板精灵。
- 另有若干大的单色占位体：每个都是模板掩码按某整数倍率做块级放大、
  再经过旋转或翻转得到；倍率与朝向因物体而异。
- 可能存在一个尺寸恰为模板整数倍但形状不同构的干扰物体。

规则
- 对每个占位体，找出使其块级下采样后与模板掩码重合的倍率 k 与朝向。
- 按该倍率与朝向把模板各格颜色以 k×k 块转印到占位体上；
  但模板中颜色等于该占位体自身颜色的格子，转印为背景（挖空）。
- 擦除原模板；下采样后与模板不同构的干扰物体保持原样。

关键洞察
- 占位色不只是待覆盖的底色，它还是删除键：
  每个副本都缺失模板中与自己同色的那些块，因此各副本互不相同。
```

<description>
Dock train sprites onto station groups by matching coupler count, then orient via divider-color markers.

Input structure:
- bg; colored stripes (edge + internal) partition grid into rectangular regions.
- Color 8 forms train bodies; color 9 marks both isolated stations and train-attached couplers.
- Stripe-colored pixels on trains are orientation markers.

Rule:
- Stations = 8-connected 9-clusters not adjacent to any 8. Trains = components containing 8.
- Match train to station group where |couplers| == |station size|.
- Rotate/flip train so marker pixels face the same-color boundary stripe of the target region.
- Translate so couplers align exactly onto station cells; erase original position.

Key insight: Coupler count selects the docking target; marker color encodes which boundary stripe to face, fixing the unique orientation.
</description>

    sizes: distinct per example, drawn from {1, 2, 4} [observed] (1x1 dot, 1x2 line, 2x2 block)

    markers: 2-3 non-bg pixels on the train bbox colored with stripe colors; each marker color equals a boundary-stripe color of the TARGET region; markers are positioned so that, relative to the coupler centroid, each marker lies toward the side where its matching boundary stripe sits (this uniquely determines rotation/flip)

  transform (input -> output):

  invariants:
    - count(8) preserved between input and output
    - count(9) halved: couplers removed, stations remain
    - stripes, bg, region geometry unchanged

  approach: output-first (assembled docked state), then undock and scatter trains back into the grid
  steps:
    - 1. pick grid H,W (13-30 x 16-28), bg color, and 2-4 edge stripe positions (each 2-4 thick) with distinct non-bg/8/9 colors

    - 5. place 2-3 markers on the docked sprite using the exact boundary-stripe colors of that station's region; position each marker so that, relative to the coupler centroid of the docked train, it lies on the side toward the matching boundary stripe (this encodes the orientation)
    - 6. record the docked sprite's bbox, coupler-9 cells, and marker positions; this is the output state
    - 7. to derive the input: for each docked train, pick a random flip/rotation (not all identity) and a random translation that places the transformed sprite (minus its 9s -> they become fresh couplers adjacent to 8s) inside some region (any region), not overlapping stripes, stations, or other trains, and keeping >=1 cell clearance
    - 8. clear the docked 8s from output-region (leaving stations intact) and paint the scattered (pre-docked) trains at their input positions with their couplers as 9s; this yields the input grid
    - 9. sanity: verify train coupler count = target station size (unique match), markers present and colored with target-region stripe colors, stations untouched by any 8
