## 3. 弯折数决定所在的环层

- 参考题目题号：6 (5587a8d0)、7 (e509e548)

  - object:嵌套方环, nested_square_ring
  - relation:弯折数索引层级, bend_count_indexes_layer

  - condition:面积属性为干扰, area_is_distractor

### docstring

```text
按每个折线对象的弯折数把它的颜色放进同心方环的对应层，缺失的层留空。

输入结构：
- 黑色背景上有若干条宽度为一的单色折线，颜色互不相同。
- 每条折线的拐角（行进方向改变处）个数互不相同。
- 生成保证：折线的像素面积顺序与弯折数顺序故意不一致，且弯折数序列
  中存在空缺（例如出现 1、2、4 而缺 3）。

规则：
- 数出每条折线的拐角个数 b。
- 设 B 为出现过的最大弯折数，输出边长为 2*B-1 的正方形网格。
- 弯折数为 b 的折线颜色填充从中心向外数的第 b 层：b=1 是中心单格，
  b=2 是包住中心的一圈方环，依此类推。
- 没有任何对象对应的层整层保持黑色。

关键洞察：
- 决定嵌套次序的量是形状的拐角拓扑而非面积或位置，且画布尺寸由最大
  弯折数而非对象个数决定——空缺的弯折数会在成品里留下黑色的空环。
```
