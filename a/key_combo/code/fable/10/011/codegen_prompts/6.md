## 6. 双轴括号与调色板定序

- 参考题目: `505fff84`, `bae5c565`, `668eec9a`

### docstring

```text
用同色的行界标与列界标交叉圈定子窗口，再按顶行调色板的颜色次序把窗口内容水平拼接。

输入结构
- 顶行是一条调色板行，从左到右列出若干颜色；其下方为主画布。
- 对调色板中的每种颜色，主画布左边缘列上恰有该色两个像素，夹出
  一个行区间；底边缘行上恰有该色两个像素，夹出一个列区间。
- 各颜色的行区间高度全部相同；边缘上还可能出现不在调色板中的
  颜色界标（干扰）。

规则
- 对调色板中的每种颜色，取其行区间与列区间的交叉区域作为该色窗口，
  拷贝窗口内部内容（不含界标本身）。
- 按调色板行中颜色从左到右的次序，把各窗口水平拼接为输出。
- 边缘颜色不在调色板中的窗口整组舍弃。

关键洞察
- 提取范围没有画在任何一处：行界标与列界标分别躺在两条边上，必须
  按颜色跨边配对才能交叉定位出窗口；输出的次序也不取窗口的空间位置，
  而听从调色板行。
```

```yaml
    shape: hollow rectangle (single-pixel border), largest such component
    color: distinct from bg and template colors
    interior: scale*th x scale*tw where (th,tw) is template bbox, scale 2-4 (uniform)
  fill:
    color: one color distinct from bg, frame, and all template colors
    seed: 2-3 complete scale x scale blocks placed at positions of the matching template's True pixels
    seed_fraction: 20-60% of matching template's True pixels are seeded
    disambiguation: seed pixels must be a subset of exactly one template's scaled mask (no other template's scaled mask covers all seeds)
  output: crop to frame; interior = full block-scaled matching template painted with fill color, rest bg

generation_strategy:
  approach: output-first
  steps:
    1. Choose template bbox shape (th x tw) from {(3,3),(3,4),(4,3)}, scale from 2-4.
    2. Generate N=2-5 distinct binary masks of shape (th,tw) with density 50-83%. One is the target.
    3. Build output interior = np.kron(target_mask, ones(scale,scale)) painted with fill_color on bg.
    4. Pick 2-3 True-pixel positions from target mask; place corresponding full blocks as seeds in a copy of interior (remaining True positions cleared to bg). Verify no other template's scaled mask also covers all seeds; if so, add another seed block or regenerate masks.
    5. Wrap seed interior with frame border to form the frame region.
    6. Assign distinct colors to bg(=8), frame, fill, and each template.
    7. Assemble 27x21 grid: bg row 0, templates in rows 1-(th), gap rows of bg, frame placed below with bg padding around/below.
```
</generation_spec>
</reference_puzzle>

1. `main(grid)` 必须实现新题描述中的确定性转换规则，不能只识别 `generate_input()` 的固定模板。禁止不同的input网格输出相同的output网格。
2. `generate_input()` 必须随机生成多样样例，不能固定死。随机维度应覆盖：网格大小、对象数量、位置、颜色、方向、形状参数或关键分支。注意若描述中存在若干，需实现而不是只有单个，包括object或者对应关系等等。且若涉及到最短路径，则输入网格中必涉及到多条路径，对选择造成干扰。

6. 若规则有多个分支，生成器不能长期固定成一个分支；应让分支在随机样例中合理出现。分支概率不必平均——难以发现的隐蔽分支（如少数情况下才触发的特殊规则）应适当提高出现概率，确保在 3 个训练示例中至少出现一次，否则求解者无法归纳该规则。对于颜色映射类规则，确保 2 个左右的示例即可覆盖所有映射关系（每种颜色→颜色的映射至少在某个示例中出现过）。
