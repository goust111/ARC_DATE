## 3. 带假指针的色标链

- 参考题目: `668eec9a`, `891232d6`, `505fff84`
- tags:

  - condition:有出边无入边者为链头, out_edge_no_in_edge_head
  - condition:回边假指针, back_edge_fake_pointer
  - condition:忽略干扰项, ignore_distractors

### docstring

```text
从双重特征锁定链头，沿端点色标遍历线段链，绕过指向已访问线段的假指针，把链序压缩为色条输出。

输入结构
- 背景占主导，网格中散布若干条颜色互不相同的一格宽线段。
- 链上每条线段（除链尾外）至少一端贴有一个单独的异色像素色标，
  色标颜色等于某条线段的主体色；部分线段两端各有一个色标，其中
  恰有一个指向链中更早出现过的线段（假指针）。
- 另有孤立干扰线段：既不带任何色标，主体色也不被任何色标引用。
- 链头带色标但不被引用；链尾被引用但不带色标。

规则
- 链头是“带色标且不被任何色标引用”的唯一线段（孤立线段虽不被
  引用但无色标，据此排除）。
- 从链头出发，每步在当前线段的色标中选择指向尚未访问线段的那一个
  前进，直至到达链尾，得到链上全部线段的唯一排列。
- 输出为 N 行 3 列网格（N 为链上线段数，不含孤立干扰），第 k 行
  整行涂成链中第 k 条线段的主体色。

关键洞察
- 线段的位置、长度与方向全部无关；链头必须由“有出边、无入边”
  两个特征联合锁定，遍历途中还要识破指回旧线段的假指针，孤立线段
  永远进不了输出。
```
