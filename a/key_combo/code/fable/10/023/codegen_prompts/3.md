## 3. 带相位的刻度阵列

- 参考题目题号：10（34cfa167）、3（a406ac07）、20（ad7e01d0）
- tags:
  - operation:周期延伸, periodic_extend
  - operation:印章覆盖, stamp
  - object:刻度像素, tick_pixel
  - object:印章精灵, stamp_sprite
  - relation:行列交叉, row_col_intersection
  - relation:相位偏移, phase_offset
  - condition:前两刻度定周期, first_two_ticks_define_period

### docstring

```text
将上缘与左缘各自只给出前两项的周期刻度外推成整条边，再以给定精灵相对最近交叉点的
偏移为全局相位，在每个交叉点的同偏移处印一份拷贝。

输入结构
- 黑底网格；顶行有两个同色刻度像素，最左列有两个另一色刻度像素，分别是两组等差
  刻度的前两项。
- 网格内部另有一个小的多色精灵，其中心并不落在任何行列交叉点上，而是偏离最近
  交叉点一个小于半周期的偏移向量。

规则
- 由顶行两刻度的列距与左列两刻度的行距得到两个周期，分别向右、向下补齐刻度至边界。
- 行刻度所在行与列刻度所在列的每个交叉点构成点阵；读出精灵中心相对其最近交叉点的
  偏移向量。
- 在每个交叉点加上该偏移的位置，以之为中心印一份精灵拷贝；原精灵即阵列中的一员，
  保持原位；拷贝互不重叠，越界的交叉点不印；刻度（含补齐部分）保留。

关键洞察
- 第一眼会以为精灵应对准交叉点印制，但训练对显示所有拷贝都带同一个偏移——原精灵
  不是独立模板，而是这个周期阵列中唯一露出的样本，它的位置本身编码了全局相位。
```

    innermost: solid, 2x2 to 3x4 [observed]
  input_placement:
    rects scattered arbitrarily over the wallpaper grid; some overlap, some disjoint
    at least 1 rect is fully disjoint from all others [observed]
    all foreground pixels overwrite wallpaper; partially occluded frames remain identifiable via bbox
  output:
    crop to outermost rect's bbox; fill with 0; paint rects largest-to-smallest
    each nested rect placed at lower-left of parent's usable region
generation_strategy:
  approach: output-first
  steps:
    1. Pick N=3-4 foreground colors (all non-zero, mutually distinct).
    2. Build the nesting chain from innermost to outermost. Choose innermost solid size (2x2 to 3x3).
       For each successive layer, choose frame or solid (solids first, then frames). Ensure the child
       fits inside the parent's usable region with margin >= 0 in each dimension.
    3. Render the output by painting largest-to-smallest at lower-left nesting positions on a zeros grid.
    4. Pick 2-4 wallpaper colors (disjoint from foreground, can include 0). Build a small periodic tile
       (2x2 or 3x3) using those colors such that max component size <= 3 in tiled plane.
    5. Create the input grid large enough to hold the outermost rect plus margins (>= 1 on each side).
       Fill with the tiled wallpaper.
    6. Place foreground rects at random positions on the wallpaper grid. Allow partial overlaps between
       some rects; ensure at least one rect is fully disjoint. Overwrite wallpaper pixels with rect pixels.

1. `main(grid)` 必须实现新题描述中的确定性转换规则，不能只识别 `generate_input()` 的固定模板。禁止不同的input网格输出相同的output网格。
2. `generate_input()` 必须随机生成多样样例，不能固定死。随机维度应覆盖：网格大小、对象数量、位置、颜色、方向、形状参数或关键分支。注意若描述中存在若干，需实现而不是只有单个，包括object或者对应关系等等。且若涉及到最短路径，则输入网格中必涉及到多条路径，对选择造成干扰。
