## 9. 压缩域周期

- 参考题目题号: 2 (`9f236235`)、1 (`e95e3d8e`)
- tags:
  - operation:压缩, compress
  - operation:周期修复, periodic_repair
  - object:分隔线, separator_line
  - object:单色区域, uniform_region
  - object:错格, corrupted_cell
  - relation:压缩域周期对齐, compressed_domain_periodicity
  - condition:残差类多数色修复, residue_majority_repair

### docstring

```text
把分隔网格压缩成区域色小图，在小图上找最小周期矩形，把少数错格修复为其残差类的多数色，输出修复后的小图。

输入结构：
- 分隔线把网格分成行宽与列宽都不均匀的单色区域，每区一色。
- 区域色构成的小图是某个最小周期矩形的平铺，但少数区域被改成了偏离色。
- 错格足够少，使周期与每个残差类的多数色都唯一可定。

规则：
- 压缩：每个区域取其颜色，得到与区域行列数一致的小图。
- 在小图上找唯一的最小面积周期矩形，使每个行列残差类内存在明显多数色。
- 把与所在残差类多数色不一致的格子改为多数色。
- 输出为修复后的小图。

关键洞察：
- 因为区域宽高不均，像素域里根本不存在周期；周期结构只在压缩后的
  区域尺度上成立，错格是压缩域里的坏像素，必须先换尺度再修复。
```

```yaml
  transform: each marker pixel is replaced by its visible orbit mate via the 2-axis mirror; if all mates are hidden/out-of-bounds, use transposed upper-left representative

generation_strategy:
  approach: output-first
  steps:
    1. Generate a random 16x16 fundamental domain using 7-8 colors from {1..6,8,9}
    2. Mirror it to build the full 32x32 symmetric pattern
    3. Crop to 30x30 (rows 0-29, cols 0-29)
    4. Choose marker dimensions (2-10 x 2-10) and place it at a random position within the 30x30 grid
    5. Verify marker is the ONLY solid rectangle in the grid (reject or recolor if not)
    6. Verify marker bbox does not overlap its own mirror bbox (31-r1..31-r0, 31-c1..31-c0)
    7. Extract output = pattern values under marker region
    8. Overwrite marker region with color 7 to produce the input
```
</generation_spec>
</reference_puzzle>

2. `generate_input()` 必须随机生成多样样例，不能固定死。随机维度应覆盖：网格大小、对象数量、位置、颜色、方向、形状参数或关键分支。注意若描述中存在若干，需实现而不是只有单个，包括object或者对应关系等等。且若涉及到最短路径，则输入网格中必涉及到多条路径，对选择造成干扰。

6. 若规则有多个分支，生成器不能长期固定成一个分支；应让分支在随机样例中合理出现。分支概率不必平均——难以发现的隐蔽分支（如少数情况下才触发的特殊规则）应适当提高出现概率，确保在 3 个训练示例中至少出现一次，否则求解者无法归纳该规则。对于颜色映射类规则，确保 2 个左右的示例即可覆盖所有映射关系（每种颜色→颜色的映射至少在某个示例中出现过）。
