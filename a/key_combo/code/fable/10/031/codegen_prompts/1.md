## 1. 对称缺口成形

- 参考题目题号: 6 (8e5c0c38)、12 (903d1b4a)、18 (72ca375d)
- tags:
  - operation:对称补全, symmetry_completion
  - operation:裁剪, crop
  - object:色层, color_layer
  - object:对称轴, symmetry_axis
  - relation:逐色处理, per_color_processing
  - condition:缺口集合即输出图形, missing_cells_form_output

### docstring

```text
收集各色层相对自身镜像轴缺失的像素位置，这些缺口本身拼成要输出的图形。

输入结构：
- 黑色背景上有若干种非黑颜色，每种颜色的像素关于某条属于自己的竖直轴几乎镜像对称。
- 每种颜色都有少量像素在轴另一侧缺少镜像伙伴，缺失位置在输入中是黑色。
- 不同颜色的对称轴位置互不相同。

规则：
- 对每种颜色，找出使未配对像素最少的竖直镜像轴。
- 对每个缺少镜像伙伴的像素，取其关于该轴的镜像位置，记为该颜色的一个缺口。
- 汇总所有颜色的缺口位置，取它们的最小包围框裁剪，缺口处涂对应颜色，其余为黑。

关键洞察：
- 表面上像逐色去噪或补全对称，实际上既不删也不补：真正的答案是那些"本应存在
  却没画出来"的格子集合，它们共同构成一个从未在输入中出现过的图形。
```

```yaml
    4. Choose mask top-left (r0,c0) with r0+h<=n, c0+w<=n. Verify every cell in the mask rectangle has >=1 non-masked D4-symmetric copy (reject otherwise; rejection rate is low for small masks on a 24x24 grid).
    5. Overwrite mask cells with color 3 to produce the input grid.
    6. Output is the h x w crop with colors looked up from the full pattern (step 2).
```

## 实现要求

1. `main(grid)` 必须实现新题描述中的确定性转换规则，不能只识别 `generate_input()` 的固定模板。禁止不同的input网格输出相同的output网格。
2. `generate_input()` 必须随机生成多样样例，不能固定死。随机维度应覆盖：网格大小、对象数量、位置、颜色、方向、形状参数或关键分支。注意若描述中存在若干，需实现而不是只有单个，包括object或者对应关系等等。且若涉及到最短路径，则输入网格中必涉及到多条路径，对选择造成干扰。
3. 生成器必须保证输入满足 `main()` 的隐式假设：对象不重叠、不越界、特殊标记唯一或可区分、匹配关系无歧义、关键分支出现概率相同。
4. 禁止把 ARC 颜色 id 、亮度、拼写等当作人类不可见的数值语义参与排序、大小比较或隐藏映射。颜色变化必须有可见结构线索。注意颜色亮度、拼写等也是不可见信息，若描述中出现违规的颜色id或者亮度，可自行使用少量的固定颜色替代，但注意生成时要在三个以内输入输出网格中对所有变换100%覆盖度。

6. 若规则有多个分支，生成器不能长期固定成一个分支；应让分支在随机样例中合理出现。分支概率不必平均——难以发现的隐蔽分支（如少数情况下才触发的特殊规则）应适当提高出现概率，确保在 3 个训练示例中至少出现一次，否则求解者无法归纳该规则。对于颜色映射类规则，确保 2 个左右的示例即可覆盖所有映射关系（每种颜色→颜色的映射至少在某个示例中出现过）。
