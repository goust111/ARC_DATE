## 5. 形色双拉丁消元

- 参考题目题号: 1 (8d5021e8)、7 (39a8645d)、12 (903d1b4a)
- tags:
  - operation:补全, complete
  - object:精灵体阵列, sprite_array
  - relation:阵列排布, array_layout
  - relation:行列拉丁约束, latin_square_constraint
  - condition:形状颜色解耦, shape_color_decoupled
  - condition:双空格消元, two_blank_elimination

### docstring

```text
在形状与颜色各自满足行列不重复的精灵阵列中，用消元法补出两个空位上的精灵。

输入结构：
- 网格划分为 n×n 个等距摆放的精灵位，每个位置放一个小精灵。
- 所有精灵共有 n 种形状与 n 种颜色：每行每列的 n 个形状互不相同，每行每列的
  n 种颜色也互不相同。
- 形状与颜色的绑定不固定，同一形状在不同位置可以是不同颜色。
- 恰有两个精灵位是空的，且位于同一行的不同列。

规则：
- 该行缺少两种形状与两种颜色。
- 对每个空位，看其所在列已有的形状与颜色，从行缺失集合中排除已在该列出现者，
  剩下的形状与颜色即属于该空位。
- 输出与输入同尺寸的网格，在两个空位画上推得的精灵，其余保持不变。

关键洞察：
- 空位上该画的"形状-颜色"组合很可能从未在输入中整对出现过：形状约束与颜色约束是
  两张相互独立的拉丁方，必须分别消元再拼合，而不是从画面上找一个现成精灵来抄。
```
</new_puzzle>
