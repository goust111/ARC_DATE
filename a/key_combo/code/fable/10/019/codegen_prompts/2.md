### docstring

```text
为散落的四个带噪旋转副本恢复旋转对应，用轨道多数表决重建瓦片，并按灰色角标锚定输出朝向。

输入结构
- 背景网格上散落四个 N×N 的正方形副本，互不相触。
- 它们本是同一张多色瓦片的四个旋转版本（0、90、180、270 度各一），但摆放位置
  随意、旋转关系未标注。
- 若干格子被改成了错误颜色，污染可落在任意副本，但每个旋转轨道（四个互为旋转
  对应的格子）中至多一个被污染，污染色不固定；瓦片自身不具有任何非平凡旋转
  自对称。
- 其中恰有一个副本的包围盒外侧斜角处紧贴一枚灰色角标像素。

规则
- 为四个副本找出唯一能使逐格颜色高度一致的旋转对齐方式。
- 对齐后每个格子取四个见证值中的多数颜色作为真值。
- 以带灰色角标的那个副本的摆放朝向为基准，输出重建后的 N×N 瓦片。

关键洞察
- 旋转对应关系没有被位置或标注给出，只能从"正确对齐时几乎处处一致、错误对齐
  时大面积冲突"中反推；带角标的副本只提供朝向基准，它自身同样可能被污染，
  直接抄它必错。
```

Recolor each closed orthogonal line loop so convex bend pixels are yellow and concave bend pixels are red.

Input structure
- The grid has a dominant background and exactly one foreground color.
- The foreground forms one or more 4-connected one-pixel-wide closed cycles; every foreground pixel has degree 2.
Rule
- Trace each cycle and inspect the turn at each foreground pixel.
