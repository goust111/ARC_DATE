## 4. 计数差位移向量

- 参考题目题号: `16 (2a28add5)`, `4 (4364c1c4)`, `12 (d968ffd4)`
- tags:
  - operation:计数, counting
  - operation:平移, translate
  - object:主体块, main_block
  - object:力点, force_dot
  - relation:同带对齐, band_aligned
  - condition:计数差决定位移, count_diff_displacement

### docstring

```text
每个主体对象按四个方向上"力点"像素的计数差构成的二维向量整体平移。

输入结构
- 背景色占多数;若干单色多格主体对象,形状颜色各异;
- 大量统一颜色的单像素力点,每个力点恰好落在某一个主体的行带或列带内
  (即与该主体的 bbox 同行区间或同列区间)。

规则
- 对每个主体统计:L=行带内位于其左侧的力点数,R=右侧;
  U=列带内位于其上方的力点数,D=下方;
- 主体水平平移 R-L 格(正向右),垂直平移 D-U 格(正向下),
  两个方向同时结算;
- 输出中所有力点消失,主体形状与颜色不变,原位置变为背景。

关键洞察
- 力点不是要连线、包围或吸附的目标;单看一个示例像"移动到最近的点旁",
  这一读法在其余示例上会失败;
- 每侧的个数之差构成一个位移向量,方向与距离全部来自计数差。
```
