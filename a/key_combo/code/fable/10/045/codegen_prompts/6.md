### docstring

```text
抹去每个带灰色提手的模板图形，把每个有模板可查的孤立像素替换为按提手
对位的完整模板副本，无模板可查的孤立像素则作为噪点清除。

输入结构：
- 背景为主导色；部分前景颜色各有一个多像素模板簇，簇内嵌着一个灰色
  提手像素。
- 网格中散布若干各色孤立单像素，互不相邻也不邻接任何簇；其中一些
  孤立像素的颜色并没有对应的模板簇。

规则：
- 将每个模板簇从原位置整体抹为背景。
- 对每个有同色模板的孤立像素，把模板（含灰色提手）原样平移到"提手
  像素恰好落在该孤立像素所在格"的位置整体盖出，出界部分裁掉——因此
  该孤立像素在输出中变成灰色。
- 颜色没有模板的孤立像素一律抹为背景；不同印章互不重叠（由输入保证）。

关键洞察：
- 孤立像素分成两类命运——有模板的是锚点、没模板的是噪点；且印章是
  含提手的精确副本，对齐基准是模板内那个偏心的灰格而非形状中心或
  角落，所以每个锚点像素在输出里恰好被灰色顶替。
```
</new_puzzle>

    1. pick grid H (10-20), W (10-30), N (3-5)
    2. build the 4-fold symmetric output first
       a. design one NxN source shape in the TL quadrant (random sparse, density 0.40-0.70, not a solid rect)
       b. reflect it to all 4 quadrants to form the complete symmetric pattern
    3. place marker (2x2) so the TL source bbox bottom-right is diag-adjacent to marker top-left

    4. derive input by erasing the 3 reflected copies, keeping only the original TL quadrant source pixels

## 实现要求

1. `main(grid)` 必须实现新题描述中的确定性转换规则，不能只识别 `generate_input()` 的固定模板。禁止不同的input网格输出相同的output网格。
2. `generate_input()` 必须随机生成多样样例，不能固定死。随机维度应覆盖：网格大小、对象数量、位置、颜色、方向、形状参数或关键分支。注意若描述中存在若干，需实现而不是只有单个，包括object或者对应关系等等。且若涉及到最短路径，则输入网格中必涉及到多条路径，对选择造成干扰。
3. 生成器必须保证输入满足 `main()` 的隐式假设：对象不重叠、不越界、特殊标记唯一或可区分、匹配关系无歧义、关键分支出现概率相同。
4. 禁止把 ARC 颜色 id 、亮度、拼写等当作人类不可见的数值语义参与排序、大小比较或隐藏映射。颜色变化必须有可见结构线索。注意颜色亮度、拼写等也是不可见信息，若描述中出现违规的颜色id或者亮度，可自行使用少量的固定颜色替代，但注意生成时要在三个以内输入输出网格中对所有变换100%覆盖度。
5. 输出样例要视觉清晰，人类必须能从输入输出对中肉眼辨认出规律。具体要求：避免对象粘连、覆盖关系混乱、同一像素多重语义；不同逻辑步骤产生的结果不要大面积层叠在一起导致无法分辨哪个颜色属于哪个步骤；输入中各元素之间保持足够间距，输出中新增的标记/填充/路径等应与背景和已有元素在颜色上有明显区分；若规则涉及多层叠加，生成时控制对象密度和尺寸，确保叠加区域只占少数像素而非铺满整个网格。
6. 若规则有多个分支，生成器不能长期固定成一个分支；应让分支在随机样例中合理出现。分支概率不必平均——难以发现的隐蔽分支（如少数情况下才触发的特殊规则）应适当提高出现概率，确保在 3 个训练示例中至少出现一次，否则求解者无法归纳该规则。对于颜色映射类规则，确保 2 个左右的示例即可覆盖所有映射关系（每种颜色→颜色的映射至少在某个示例中出现过）。
