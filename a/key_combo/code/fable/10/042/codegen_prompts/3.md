### docstring

```text
把柱条按高度重新分配到保色的槽位后，超过该槽净空的部分沿天花板折向空间更大的一侧。

输入结构：
- 底部有一条横贯全宽的灰色(5)基线；若干互不同色的单色竖直柱条立在基线上，
  各占一列（槽位）。
- 顶部悬着灰色天花板：每一列从顶边垂下一段长短不一的灰柱，
  柱条与天花板之间是黑色空间。

规则：
- 将柱条形状按高度从矮到高排序，槽位按从左到右排序；
  第 i 矮的形状放入第 i 左的槽位，并重涂成该槽位原柱条的颜色。
- 放置时柱条从基线向上生长；若柱高不超过该槽的净空
  （基线到该列天花板底端的距离），则原样立直。
- 若柱高超过净空，竖直部分长到紧贴天花板底端为止，剩余长度在天花板正下方
  那一行水平延伸，折向左右两侧中连续空格更多的一侧
  （构造保证两侧不等，且横段不会碰到其他柱条）。
- 基线与天花板保持不变。

关键洞察：
- 折不折、往哪折都取决于排序之后柱条落在哪个槽：
  净空是槽位的属性而高度是形状的属性，
  必须先完成高度—槽位的重分配才能判断每根柱条的折叠形态。
```

  rule:
    move_direction: away from marker side to opposite grid edge (left->right, right->left, top->bottom, bottom->top)

    marker_block: unchanged
    final_position: object bbox flush against target grid edge, same row (horizontal) or column (vertical)

generation_strategy:
  approach: output-first
  steps:
    1. Choose grid H x W (5-18 each), object count N (1-4), and marker color (use 1).

    3. Build each output object at its target-edge position: construct a random 5-color cross (center=4, arms from remaining non-bg non-marker colors), attach the direction-appropriate marker block.
    4. Derive input by inverting the transformation: rotate the cross block 180 degrees back, then place the composite at a random interior position along its movement axis (>= 2 cells from target edge). Verify no overlap with other input objects.
