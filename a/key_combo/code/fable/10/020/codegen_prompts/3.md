### docstring

```text
根据残存的周期回声点反推每行被抹去的色条长度，重建色条并补全整条回声序列。

输入结构：
- 一条近实心的分隔列把网格分成两侧：条侧已被完全抹成背景，回声侧留有稀疏的
  彩色残迹点。
- 每个残迹点原本位于距分隔列 k×L 格处（k≥1），其中 L 是该行原色条的长度；
  部分周期位（包括可能的第一个）已丢失。
- 同一颜色的条在所有行中长度相同；有的行可能只剩一个残迹点。

规则：
- 对每种颜色，收集其所有残迹点到分隔列的距离，取最大公约数得到该色条长 L。
- 在条侧紧贴分隔列重建长度 L 的同色条（每个有残迹的行一条）。
- 在回声侧把该行所有 k×L 位置补满同色像素，直到画布边界。

关键洞察：
- 生成元从未在画面上出现，只能从回声间距的公约数反推；第一个残迹点的距离并不
  可靠，它可能已经是第二个节拍。
- 孤点行自己无法定周期，必须借同色富行的公约数——颜色是跨行共享周期的钥匙。
```

<description>
Repeat each colored diagonal every three offsets to fill the 7x7 grid with an interlaced pattern.

Input structure:
- The input is a 7x7 black grid containing three full diagonals.
- Each diagonal has a distinct non-black color.
- The diagonals run in the same slope direction.

Rule:
- For every non-black input cell, draw its full diagonal in the output.
- Redraw that same diagonal color at offsets spaced by three rows.
- Clip the repeated diagonals to the 7x7 canvas.

Key insight:
- A single colored diagonal defines a whole congruence class modulo three; repeating all three
  classes creates the final interlacing.
