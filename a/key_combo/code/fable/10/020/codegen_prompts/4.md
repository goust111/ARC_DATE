### docstring

```text
在想象中把左上角种子自相似展开并铺满整个坐标系，输出只是红框内部看到的那一小片。

输入结构：
- 网格左上角是一个种子矩形：其最后一行与最后一列为实心次色，构成 L 形图例；
  其余部分由背景色与一种主色组成种子掩码。
- 画布另一处有一个红色空心矩形框，框内为空；红色不在种子中出现。

规则：
- 以种子掩码做一层自相似替换：主色格换成一份主色重绘的种子掩码副本，背景格
  换成一份次色重绘的种子掩码副本，得到放大一层的图案。
- 把该图案以画布左上角为原点周期平铺，覆盖整个画布坐标系——这一步只在想象中
  进行，不实际绘制。
- 输出为红框内部矩形区域在这张虚拟大图上对应坐标处的内容。

关键洞察：
- 参与规则的大图案从未被画出，画面上只有它的生成元；红框不是要填的容器，而是
  对准虚拟图案的取景窗，窗的位置坐标决定看到哪一片。
```

Draw a polyline by decoding 3x3 glyph instructions read across a divided grid.

Input structure:

generation_strategy:
  approach: output-first
  steps:
    1. Pick interior H in [2,5], W in {4,6} (always even)
    2. Pick 3 distinct non-zero colors -- marker=4, left_color, right_color
    3. Build motif (H x W) -- left W/2 cols use colorA, right W/2 cols use colorB, each region 4-connected, whole motif connected, density 0.45-0.75
    4. Build output: frame corners=4, left bar=left_color, right bar=right_color, interior=oriented motif (colorA mapped to left_color side)
    5. Build 13x13 input -- place frame at random valid position
    6. Coin-flip whether to flip the motif horizontally before placing it (swaps colorA/colorB sides)
    7. Place the (possibly flipped) motif at a non-overlapping location on the grid with 0-4 row gap from frame

## 实现要求

2. `generate_input()` 必须随机生成多样样例，不能固定死。随机维度应覆盖：网格大小、对象数量、位置、颜色、方向、形状参数或关键分支。注意若描述中存在若干，需实现而不是只有单个，包括object或者对应关系等等。且若涉及到最短路径，则输入网格中必涉及到多条路径，对选择造成干扰。

6. 若规则有多个分支，生成器不能长期固定成一个分支；应让分支在随机样例中合理出现。分支概率不必平均——难以发现的隐蔽分支（如少数情况下才触发的特殊规则）应适当提高出现概率，确保在 3 个训练示例中至少出现一次，否则求解者无法归纳该规则。对于颜色映射类规则，确保 2 个左右的示例即可覆盖所有映射关系（每种颜色→颜色的映射至少在某个示例中出现过）。
