### docstring

```text
在两门框之间标出可能被走到的格与必然被走到的格：前者涂黄，后者涂红。

输入结构：
- 背景网格上有两个小门框对象，各含一个中心标记；每个标记恰有一个背景四邻——
  门洞缺口，再向外一格是外门格。
- 两门框之间散布若干前景障碍。

规则：
- 把所有前景格视为障碍；只允许朝对方外门格方向的行/列单调步。
- 考虑两外门格之间全部这样的最短单调路径。
- 被至少一条路径经过的背景格涂黄；被每一条路径都经过的背景格涂红（红优先于黄）；
  两个门洞缺口同样参与归类。

关键洞察：
- 输出的两种颜色编码的是模态差异：可能经过是路径的并集，必然经过是路径的交集
  ——障碍收窄处的瓶颈格才是红色的来源。
```

Input structure:

    shape: (seed_h+1) x (seed_w+1), where seed is seed_h x seed_w
    last row and last column of legend are solid secondary color (L-shaped border)
    upper-left seed_h x seed_w sub-region is the seed
  seed:
    size: 2-3 rows x 2-3 cols
    contains only background and primary color cells
    must have >=1 primary cell AND >=1 background cell
    primary density: 0.33-0.67
  grid_vs_seed: H/seed_h == W/seed_w (same tiling ratio both dims)
  grid_min: H >= seed_h^2 and W >= seed_w^2 (show full 2-level fractal)
  rest_of_grid: all cells outside legend box are background in input
  output_rule: |
    Two-level fractal tiling. For each cell (r,c):
      inner = seed_mask[r % seed_h, c % seed_w]
      meta  = seed_mask[(r // seed_h) % seed_h, (c // seed_w) % seed_w]
      color = primary if inner&meta, secondary if inner&!meta, background otherwise

generation_strategy:
  approach: direct construction (input is simple, output is deterministic)
  steps:
    1. Pick 3 distinct colors for bg, primary, secondary
    2. Pick seed_h in [2,3], seed_w in [2,3]
    3. Generate a random seed_h x seed_w binary mask with >=1 true and >=1 false
    4. Pick a tiling multiplier K in [3..5] such that seed_h*K <= 30 and seed_w*K <= 30
    5. Set H = seed_h * K (+ optional 0-1 remainder), W = seed_w * K (+ same remainder ratio)
       Ensure H/seed_h == W/seed_w (both integer or both same fraction)
    6. Build grid of size H x W filled with bg
    7. Place seed at [0:seed_h, 0:seed_w] using primary color for mask=1, bg for mask=0
    8. Fill L-border -- row seed_h cols [0:seed_w+1] and col seed_w rows [0:seed_h] with secondary
