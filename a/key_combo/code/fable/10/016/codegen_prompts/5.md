### docstring

```text
各种子的波前按绕墙最短路距离扩张并按奇偶显隐，多源等距的格标黄，
墙后的波前发生绕射式弯折。

输入结构
- 黑色背景上散布若干不同颜色的孤立种子像素。
- 另有若干一格厚的灰色墙线段；墙不封闭，只作局部遮挡。

规则
- 对每个非墙格，计算它到各种子的 4 连通最短路步数，路径不得穿过墙格。
- 取最小距离：若由两个及以上种子同时取得，该格涂黄。
- 否则设唯一最近种子的距离为 d：d 为偶数（含 0）时涂该种子的颜色，
  d 为奇数时保持黑色。
- 墙保持灰色；不可达格保持黑色。

关键洞察
- 开阔处的环看似规整的菱形距离环，但真正的度量是受墙阻挡的测地
  距离——墙的背面出现绕射式弯折波前与距离阴影；奇偶显隐与等距平局
  的黄色裁决线叠加在这个测地距离场之上，三层都认对才能重建输出。
```

    gray_marker: exactly 1 GRAY pixel, 4-connected to at least one non-gray pixel
  target_marker:
    single isolated GRAY pixel on background, not 4-adjacent to any non-bg pixel
  layout:
    exactly 2 components in input -- source sprite and target marker
    manhattan distance between gray markers >= 5
    translated copy must land entirely on background (no overlap with source)
    translated copy must stay within grid bounds
  transform:
    copy non-gray pixels of source offset by (target_gray - source_gray)
    erase target marker to background; keep source sprite unchanged

generation_strategy:
  approach: output-first (build output with both copies, then derive input)
  steps:
    1. Choose grid size in range 9-12 x 10-12
    2. Design a small 4-connected multicolor sprite (3-5 x 2-6 bbox, 2-5 colors, density 0.5-1.0)
    3. Pick one pixel position within the sprite as the gray anchor point
    4. Place two copies of the sprite on the grid such that they do not overlap and both fit in bounds; the anchor pixel of each copy defines the two gray marker positions
    5. This is the output (minus the target gray marker, which is erased)
    6. To get input -- remove the second copy entirely and place a single GRAY pixel at the second anchor position; restore the first copy including its gray anchor
    7. Validate -- exactly 2 gray pixels in input, exactly 2 non-bg components, copy region was all-bg in input
