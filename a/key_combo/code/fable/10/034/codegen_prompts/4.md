## 4. 分隔线是运算符

- 参考题目题号: 8 (6430c8c4)、5 (94f9d214)、14 (e87109e9)
- 难度评审: 达标
- tags:
  - operation:布尔运算, boolean_op
  - operation:折叠合并, fold_merge
  - object:掩码, mask
  - object:分隔线, divider_line
  - condition:线色编码运算, divider_color_encodes_op
  - condition:线厚编码优先级, divider_thickness_encodes_precedence

### docstring

```text
三层掩码折叠成一层，每条分隔线的颜色指定运算种类、厚度指定运算次序。

输入结构：
- 网格由三个等大的矩形掩码竖直堆叠而成，两条满宽分隔线夹在层与层之间：一条 1 行厚，另一条 2 行厚，二者厚度必不相同。
- 每个掩码含同一背景色与各自的一种前景色。
- 分隔线颜色只有灰、黄两种：灰=交集（两层同为前景才记前景），黄=对称差（恰一层为前景记前景）；颜色与厚度独立取值。

规则：
- 先对厚分隔线两侧相邻的两个掩码按其颜色对应的运算合并。
- 再把结果与剩下的掩码按细分隔线颜色对应的运算合并。
- 输出一个掩码大小的网格：最终为前景的格涂绿，其余为背景色。
- 示例保证两种结合顺序会得到不同结果，颠倒次序即错。

关键洞察：
- 分隔线不是分界而是算式：线色写着“算什么”，线厚写着“先算谁”。
- 不读出运算优先级，就算认对了运算种类也会折叠出错误答案。
```

    3. Compute fixed_rows/fixed_cols (sum of non-stretch run widths per axis).
    4. Generate 1-2 target rectangles with dimensions > (fixed_rows, fixed_cols). Each target is solid outer_color.
    5. Place exemplar and targets on the grid with >=1 bg gap between all pairs and to grid edges. No overlapping.
    6. Input = grid with solid outer_color targets. Output = grid with targets replaced by stretched exemplar.

2. `generate_input()` 必须随机生成多样样例，不能固定死。随机维度应覆盖：网格大小、对象数量、位置、颜色、方向、形状参数或关键分支。注意若描述中存在若干，需实现而不是只有单个，包括object或者对应关系等等。且若涉及到最短路径，则输入网格中必涉及到多条路径，对选择造成干扰。
