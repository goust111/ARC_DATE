## 4. 镜像负片修补

- tags:
  - operation:镜像, mirror
  - operation:修复异常, repair

  - object:分隔列, separator_column
  - object:损伤格, damaged_cell
  - relation:镜像加色置换, mirror_plus_color_permutation
  - condition:置换方向区分, permutation_direction_matters
- 参考题目题号：3 (e84fef15)、4 (d511f180)、20 (6f473927)

### docstring

```text
左右两半经竖直分隔线互为"镜像+颜色置换"的冗余副本，用干净格子推断颜色置换并修补两侧的损伤格。

输入结构：
- 一条满高灰色分隔列把网格分成等宽两半。
- 右半是左半左右镜像后再经过一个固定颜色双射 σ 重涂的副本；σ 不是恒等，也不必是对合。
- 两半中各有少量格子被损伤色（仅此用途的颜色）覆盖；同一对镜像位置不会同时损伤。
- 每种参与的颜色都在至少一处无损伤的镜像格对中出现。

规则：
- 以分隔列为轴建立左右镜像配对。
- 用所有无损伤的配对格恢复颜色双射 σ（左色→右色）。
- 左半的损伤格取其镜像伙伴的颜色经 σ 反向映射修复；右半的损伤格取镜像伙伴颜色经 σ 正向映射修复。
- 输出完整修复后的网格（含分隔列）。

关键洞察：
- 冗余关系不是恒等复制而是"镜像∘置换"——直接抄镜像格颜色会得到错误答案。
- σ 不是对合，必须先从干净格对中重建这张看不见的颜色对照表，并按损伤格所在的一侧区分正向与反向使用。
```

    structure: N copies of sprite stacked vertically with no gap, each in its legend-ordered color
    position: top-to-bottom matches legend left-to-right order
    existing_instances: 1-2 of N sprites present in input at correct stack positions
    missing_instances: remaining 1-4 sprites absent from input
    existing ranks: consecutive [observed]; may be any subset of 0..N-1
  output:
    erase legend, fill all N stack slots with the sprite mask in legend-ordered colors
    grid size unchanged

generation_strategy:
  approach: output-first
  steps:
    1. Pick N in 3-5, pick N distinct non-black colors, define legend order
    2. Generate a random LR-symmetric sprite mask (3-5 rows x 6-8 cols, density ~0.5-0.6, 8-connected, touches all bbox edges)
    3. Build output -- place full N-high sprite stack at a chosen (row, col); each slot gets its legend-ordered color
    4. Choose grid size so stack + legend both fit with >=1 cell margin on each side
    5. Place the 3xN legend rectangle at a non-overlapping position on the grid
    6. Choose 1-2 consecutive ranks to keep as existing sprites; erase the rest from the stack to get input
    7. Verify legend is detectable as the only solid multi-color vertical-bar rectangle
