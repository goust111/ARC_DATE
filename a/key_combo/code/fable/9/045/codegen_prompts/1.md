## 1. 光迹反推镜位

  - object:隐形镜子, hidden_mirror

- 参考题目题号: 508bd3b6、a2fd1cf0

### docstring

```text
由光线留下的折线残迹逆向推出每一面看不见的镜子的位置。

输入结构
- 黑色背景上有一个青色起点像素，一条绿色对角折线路径从它出发，
  经若干次转折后延伸到网格边缘。
- 折线的转折有两类成因：碰到网格边缘反弹（转折点位于边缘行或
  边缘列上），或碰到看不见的镜子反弹（转折点位于网格内部）。
- 每个示例中两类转折都会出现；镜子本身在输入中完全不出现。

规则
- 复制输入。
- 沿路径从青色起点走到终点，找出每一个转折点。
- 对每个位于网格内部的转折点，沿其入射方向越过转折点一格，把
  该格涂成红色（即"若未反弹、光线本应进入的下一格"）。
- 位于边缘行或边缘列上的转折点不产生任何输出。

关键洞察
- 需要输出的对象（镜子）从未被画出，只能由路径几何逆推；
  并且必须先区分转折的成因——边界成因的转折是干扰，只有内部
  转折才对应一面镜子。
```

    bbox: exactly 5x5 (matches interior size)
    pixel_count: 11-13 (density 0.44-0.52)
    symmetry: no LR, UD, or rotational symmetry [observed]
  placement:
    source_bbox: offset 1-2 cells (manhattan distance) from interior alignment
    source partially overlaps interior and partially extends outside frame
    source never overlaps marker corner pixels
    translated object fits entirely within interior with no overlap on markers
  output:
    erase object from source position; place unchanged mask at interior-aligned position
    marker corners unchanged; bg elsewhere unchanged

generation_strategy:
  approach: output-first
  steps:
    1. Pick grid size H x W in [7..10] x [7..10]
    2. Pick two distinct non-bg colors for marker and object
    3. Place 7x7 marker frame (4 corner pixels) so frame fits in grid with 0-2 cell margins on each side
    4. Generate a random 5x5 asymmetric single-4-connected sprite with 11-13 filled cells
    5. Place sprite aligned to interior (output position) -- this is the output
    6. Choose displacement (dr, dc) with 1 <= |dr|+|dc| <= 2 such that shifted bbox stays in grid
       and shifted sprite pixels land only on bg cells (no overlap with marker corners)
    7. Build input by erasing sprite from interior position and drawing it at shifted position

## 实现要求

1. `main(grid)` 必须实现新题描述中的确定性转换规则，不能只识别 `generate_input()` 的固定模板。禁止不同的input网格输出相同的output网格。
2. `generate_input()` 必须随机生成多样样例，不能固定死。随机维度应覆盖：网格大小、对象数量、位置、颜色、方向、形状参数或关键分支。注意若描述中存在若干，需实现而不是只有单个，包括object或者对应关系等等。且若涉及到最短路径，则输入网格中必涉及到多条路径，对选择造成干扰。
3. 生成器必须保证输入满足 `main()` 的隐式假设：对象不重叠、不越界、特殊标记唯一或可区分、匹配关系无歧义、关键分支出现概率相同。
4. 禁止把 ARC 颜色 id 、亮度、拼写等当作人类不可见的数值语义参与排序、大小比较或隐藏映射。颜色变化必须有可见结构线索。注意颜色亮度、拼写等也是不可见信息，若描述中出现违规的颜色id或者亮度，可自行使用少量的固定颜色替代，但注意生成时要在三个以内输入输出网格中对所有变换100%覆盖度。

6. 若规则有多个分支，生成器不能长期固定成一个分支；应让分支在随机样例中合理出现。分支概率不必平均——难以发现的隐蔽分支（如少数情况下才触发的特殊规则）应适当提高出现概率，确保在 3 个训练示例中至少出现一次，否则求解者无法归纳该规则。对于颜色映射类规则，确保 2 个左右的示例即可覆盖所有映射关系（每种颜色→颜色的映射至少在某个示例中出现过）。
