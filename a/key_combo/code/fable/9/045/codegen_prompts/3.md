## 3. 人人缺角，唯一认领

### docstring

```text
在一群都缺角的矩形中找出延长线上有同色补丁的那一个，让它飞去认领并补上自己的缺口。

输入结构
- 黑色背景上有若干实心单色矩形，每个矩形都缺一个角格，缺角
  方位各不相同。
- 画面散布若干杂色单像素点；其中恰有一个矩形满足：沿它缺角
  所指的对角方向延长线上存在一颗与它同色的孤立像素（补丁）。
- 其余矩形的延长线上没有任何同色点；散点中混有与某些矩形
  同色、但不在其延长线上的像素，以及各种异色像素。

规则
- 对每个矩形，从缺角格出发沿指向缺角的对角方向作射线检验，
  找出延长线上命中同色孤立像素的唯一矩形。
- 在全黑画布上，把该矩形沿这一对角方向逐步平移（每步一行
  一列），直到它的缺角格位置恰好与补丁像素重合。
- 画出补全后的完整矩形；其余矩形与全部散点一律清除。

关键洞察
- 每个矩形都有缺陷，"找唯一异常者"失效——选择键不是缺陷
  本身，而是缺陷方向、环境射线与同色命中的联合条件；同色
  散点必须同时通过方向检验才算数；补丁像素既决定平移距离，
  又亲自补上缺口。
```
</new_puzzle>
