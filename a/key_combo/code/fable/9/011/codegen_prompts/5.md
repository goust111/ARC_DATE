### docstring

```text
横向拼接的每个瓦片都是首块的翻转副本且都被噪声污染，需姿态归一化后逐格多数表决还原干净基块。

输入结构：
- 网格由 k 个等宽的列块横向拼成（k≥4），块宽整除总宽。
- 每块本应是同一基块经恒等、左右翻、上下翻或180度旋转之一得到的副本，但每一块都被少量噪声像素改写，没有任何一块是干净的。

规则：
- 先为每块判定其相对首块的变换姿态：取使它与其他块归一化结果整体吻合最多的那一个。
- 把所有块按各自姿态还原到首块方向后对齐，逐格取严格多数颜色，得到干净基块。
- 输出该基块（按最左块的姿态方向摆放）。

关键洞察：
- 既没有干净参照可抄，也不能直接跨块逐格表决——必须先解决"每块各自被翻转了什么姿态"这个鸡生蛋问题，对齐之后多数表决才有意义。
```

    shape: square, size = N*S + (N-1) where N = cells per side, S = cell side
    N: 4-6
    S: 3-5 (all cells identical size; S = output side length)
    overall_size: 15-35
  separators:
    color: one non-black color; forms complete row and column lines
    count: N-1 horizontal + N-1 vertical, evenly spaced
  cells:
    total: N*N (16-36)
    background: black (0)
    target: exactly 1 cell with all foreground pixels in a single non-black color (not necessarily != sep color)
    distractors: all other cells have >=2 distinct foreground colors
    no_empty_cells: every cell has >=1 foreground pixel [observed]
    fg_density: 8-44% per cell; target 24-44%; distractors 8-44%
    distractor_colors_per_cell: 2-7 distinct fg colors
    colors_used: all 9 non-black colors (1-9) appear somewhere across cells [observed]
    sep_color_in_cells: separator color may appear as noise inside distractor cells
  output: the target cell extracted verbatim (S x S)

generation_strategy:
  approach: direct construction (constraints are easy to satisfy forward)
  steps:
    1. Pick N in [4,6], S in [3,5]. Compute grid_size = N*S + N - 1.
    2. Pick separator color from 1-9. Fill separator rows/cols.
    3. Pick target cell position (random row_band, col_band) and its fg color (any non-black color).
       Place 2-ceil(S*S*0.44) monochromatic pixels in the target cell on black background.
    4. Fill each distractor cell with 2-ceil(S*S*0.44) fg pixels using >=2 distinct non-black colors.
       Ensure every cell has >=1 fg pixel. Spread all 9 non-black colors across cells.
    5. Return the grid as input; the target cell content is the output.
