## 8. 弯道计步

- tags:
  - operation:滑动, sliding
  - operation:计数, counting
  - object:轨道点, track_dot
  - object:计数标记, tally_marker
  - relation:折线轨道, bent_track
  - condition:标记差定步数, marker_difference_steps
- 参考题目: 8, 20

### docstring

```text
红色对象沿绿色点铺成的折线轨道移动，步数等于黄色标记数减去青色标记数，可正可负。

输入结构:
- 黑色背景上有一条由等距绿色点组成的轨道，轨道可以在中途拐弯。
- 一个红色对象覆盖在某个轨道点位上；轨道恰有一端紧邻一个蓝色端标像素，正方向指向蓝色端标。
- 网格角落区域散布若干黄色与青色单像素标记，不与轨道相连。

规则:
- 沿轨道点的相邻顺序确定点位序列，红色对象当前位于其中某一点位。
- 计算黄色标记数减青色标记数得到带符号步数，正数朝蓝色端标方向沿点位序列移动，负数反向移动。
- 重绘全部绿色点位，再把红色对象平移到目标点位上，对象与点位的相对姿态保持不变。

关键洞察:
- 轨道是折线，步数是沿点位序列的序数移动而非欧氏位移；两色标记不是各自计数，而是相互抵消后给出一个带符号的移动量。
```

    object_bbox: spans full band height [observed]
    each_object_shape: matches exactly one hole shape from the left panel (shuffled across bands)
    object_colors: all distinct, all != frame color, all != bg(0)
  output: left panel only with each hole recolored by the color of the right-panel object whose normalized shape matches that hole; no bg remains
  color_constraints: bg=0; frame color and object colors all distinct from each other

generation_strategy:
  approach: output-first
  steps:
    1. Choose panel_width (5-6), n_bands (3-4), band_height (2-3). Compute grid height = n_bands * (band_height + 1) + 1.
    2. Choose frame_color (non-zero). Choose n_bands distinct fill colors (all != 0, != frame_color).
    3. For each band, generate a random 4-connected shape within band_height x (panel_width-2) bbox with fill ratio 0.55-1.0 and full band height span. Ensure all shapes are unique when normalized.
    4. Build output (left panel): frame everywhere, each band's hole region filled with its assigned color.
    5. Derive left panel (input left half): replace each colored hole region with bg(0), restoring frame elsewhere.
    6. Build right panel: for each band, place one of the shapes (shuffled assignment) using the color that matches that shape, positioned within the same-height band on bg. Ensure the shape placed in band_i is NOT the shape from hole_i (at least partially shuffled).
    7. Concatenate left panel and right panel to form input grid.

2. `generate_input()` 必须随机生成多样样例，不能固定死。随机维度应覆盖：网格大小、对象数量、位置、颜色、方向、形状参数或关键分支。注意若描述中存在若干，需实现而不是只有单个，包括object或者对应关系等等。且若涉及到最短路径，则输入网格中必涉及到多条路径，对选择造成干扰。
