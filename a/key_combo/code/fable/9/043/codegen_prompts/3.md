### docstring

```text
同色的两枚边缘标记以十字投影定出中心，同色内部散点的数量定出半径，画出空心菱形。

输入结构
- 黑色背景。对每种出现的前景色 c：上边或下边恰有一枚 c 色边缘标记，左边或右边也恰有一枚，另有若干枚 c 色单像素散布在内部。
- 一个网格中有两到三种前景色；各色菱形互不重叠且完整落在网格内；散点不落在任何菱形轮廓上。

规则
- 对每种颜色 c：取水平边标记所在列与竖直边标记所在行，交点即为中心。
- 数出内部 c 色散点的个数 r，并把这些散点全部擦成背景。
- 以中心为原点，把曼哈顿距离恰为 r 的所有格涂成 c 色，形成空心菱形轮廓；边缘标记保持不变。

关键洞察
- 内部散点不是待连接的几何素材而是计数器：它们的位置毫无意义，个数才是半径；中心也不在任何散点上，而由两枚边缘标记的十字投影交点给出。
```
