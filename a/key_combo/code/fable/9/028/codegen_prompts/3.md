### docstring

```text
把完整标注从模板精灵经唯一的旋转镜像对齐传给每个副本，且凡经过镜像的副本必须交换两种标记色。

输入结构
- 背景上散布若干8连通精灵，全部由同一骨架色构成同一个不对称形状
 （彼此相差旋转或镜像），每个精灵含恰好一个锚点色像素。
- 恰有一个精灵额外带有两种标记色的完整标注，其余精灵只有骨架与锚点。

规则
- 以完整标注的精灵为模板；对每个副本求出把模板骨架与锚点同时映上去
  的唯一刚体变换（旋转/镜像加平移）。
- 沿该变换把模板的全部标记像素盖印到副本上，骨架与锚点保持不变。
- 若该变换含镜像（副本与模板手性相反），盖印时将两种标记色互换；
  纯旋转则保持原色。

关键洞察
- 标注并非原样搬运：形状的手性决定一次调色板置换，只有比对训练示例
  中镜像副本的着色才能发现"翻面即换色"这条隐藏在对齐之后的第二层
  规则。
```

```yaml
    symmetry: NOT left-right symmetric (required so mirror is visually distinct)
  dst:
    shape: all-black rectangle, same dimensions as src
  layout:
    src and dst row-disjoint with >=1 row gap
    columns may overlap but bboxes do not intersect
    both fit within grid with >=0 margin on all sides
  output:
    paste fliplr(src) over dst; rest of grid unchanged

generation_strategy:
  approach: output-first
  steps:
    1. Pick bg from non-black colors; pick 2 src colors (non-bg, non-black).
    2. Pick motif dimensions H in [3,5], W in [4,6].
    3. Fill an HxW motif with the 2 src colors (minority 20-45%), ensuring it is NOT LR-symmetric.
    4. Place src bbox and dst bbox on the 12x12 grid so rows are disjoint with >=1 gap, columns allow overlap, both fit in grid.
    5. Build the output grid: bg everywhere, src motif at src position, fliplr(src) at dst position.
    6. Build the input grid: same as output but dst region is all black.
```
</generation_spec>
</reference_puzzle>
