## 1. 缺角连锁点火

- 参考题目题号: 1 (5c0a986e), 3 (a8c38be5), 20 (3ac3eb23)

### docstring

```text
从唯一的大缺角方块开始，沿缺口方向发射对角射线，被击中的方块依次点火，未被击中的方块保持沉默。

输入结构
- 黑色背景上散布若干"2x2 缺一角"的彩色方块（三格 L 形），以及恰好一个"3x3 缺一角"的大方块。
- 每个方块的缺角位置指向四个对角方向之一。

规则
- 大方块首先点火：从其缺角处沿缺口所指的对角方向、用自身颜色画射线，直到下一格将进入任一方块或离开网格为止。
- 被射线停在身旁（即被击中）的方块随之点火，同样从自己的缺角方向发射射线。
- 已点火的方块不再重复点火；从未被击中的方块不发射任何射线。
- 输出保留所有方块原样，叠加全部射线。

关键洞察
- 缺角既是方向编码又是激活接口；哪些方块发光不由方块自身属性决定，而由点火因果链的可达性决定。
```

```yaml
  input_placement:
    the input contains a strict subset of the mask's active positions filled with minority cells
    minority_cells_given: 3-4
    remaining active positions hold majority pattern (to be completed in output)
    placement_offset: (top, left) in 0..4 — positions the 3x3 mask within the 7x7 cell grid
    uniqueness: exactly 1 valid placement exists (solver asserts this)
  output:
    all mask-active positions filled with minority pattern; mask-inactive keep majority
    grid structure and dividers unchanged

generation_strategy:
  approach: output-first
  steps:
    1. Pick 4 distinct colors — assign roles separator, maj_exclusive, shared, min_exclusive.
    2. Design majority 3x3 pattern using {shared, maj_exclusive}; design minority 3x3 pattern
       using {shared, min_exclusive} with min_exclusive as the more frequent color (6-7 of 9 pixels).
       Ensure the two patterns are distinct.
    3. Derive the binary mask from the minority pattern (active = min_exclusive pixels).
    4. Pick placement offset (top, left) so the 3x3 mask fits inside the 7x7 grid.
    5. Build the full output — fill all 49 cells with majority, then overwrite mask-active
       positions (offset by top,left) with minority pattern. Add separator divider lines.
    6. Choose a strict subset of mask-active positions (3-4 cells) to keep as minority in the
       input; replace the rest with majority. Verify exactly 1 valid placement exists
       (reject if ambiguous).
```

## 实现要求

1. `main(grid)` 必须实现新题描述中的确定性转换规则，不能只识别 `generate_input()` 的固定模板。禁止不同的input网格输出相同的output网格。
2. `generate_input()` 必须随机生成多样样例，不能固定死。随机维度应覆盖：网格大小、对象数量、位置、颜色、方向、形状参数或关键分支。注意若描述中存在若干，需实现而不是只有单个，包括object或者对应关系等等。且若涉及到最短路径，则输入网格中必涉及到多条路径，对选择造成干扰。

6. 若规则有多个分支，生成器不能长期固定成一个分支；应让分支在随机样例中合理出现。分支概率不必平均——难以发现的隐蔽分支（如少数情况下才触发的特殊规则）应适当提高出现概率，确保在 3 个训练示例中至少出现一次，否则求解者无法归纳该规则。对于颜色映射类规则，确保 2 个左右的示例即可覆盖所有映射关系（每种颜色→颜色的映射至少在某个示例中出现过）。
