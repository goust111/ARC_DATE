### docstring

```text
被灰线隔开的横向条带是同一幅画被打乱的切片，依靠斜带跨条带的连续性排回原序，并把唯一被左右翻转的条带翻回来，输出去掉灰线的完整原画。

输入结构
- 网格由若干等高条带组成，相邻条带之间以整行灰色分隔线隔开。
- 原画包含一条贯穿全高的粗斜带，它在每个条带内表现为一段斜线段。
- 条带的上下顺序被打乱，且恰有一个条带还被左右镜像过。

规则
- 以斜带在每个条带上、下边缘所处的列位置为接口，寻找使所有接口逐一衔接、斜带整体连续的唯一排列。
- 若某条带内斜带的走向与全局方向相反，先将该条带左右翻转再入列。
- 按还原顺序拼接条带并删除灰色分隔线，输出完整原画。

关键洞察
- 分隔线诱导人把条带当作独立对象逐条处理；真正的对象是那条从未完整出现的斜带，它的连续性同时给出条带顺序与翻转判定。
```

```yaml
  noise: in input, both regions have a random mix of payload and black (density ~0.40-0.59 payload) [observed]
  output: same size; red pixels preserved; fill_side solid payload; clear_side solid black

generation_strategy:
  approach: output-first
  steps:
    1. Pick grid 10x10, choose one payload color (not black/red).
    2. Draw a red divider path from one border to another (e.g. left-to-right or left-to-bottom) using 8-connected steps; ensure it never touches (H-1,0). Path length 10-17 pixels.
    3. Flood-fill from (H-1,0) on non-red mask (4-connected) to get fill_side; verify remaining non-red forms exactly one connected component (the clear_side). Reject or redraw if not exactly 2 regions or smaller fraction < 0.25.
    4. Build output: red pixels stay, fill_side = payload, clear_side = black.
    5. Build input from output: for each non-red cell, randomly assign payload or black with ~50% probability, regardless of which region it belongs to. This creates the noisy mix on both sides.
```
</generation_spec>
