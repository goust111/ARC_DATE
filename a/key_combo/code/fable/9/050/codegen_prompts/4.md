### docstring

```text
把精灵按包围盒裁下沿布局轴紧密拼接：形状顺序按孔洞数排，颜色顺序仍按原位置排。

输入结构：
- 背景网格上散布若干互不相触的单色精灵，包围盒同形。
- 每个精灵封闭的孔洞个数互不相同，颜色互不相同。
- 精灵中心在行或列方向的展布更宽，确定水平或垂直布局轴。

规则：
- 沿布局轴按位置给精灵排出位置序，同时按封闭孔洞个数从少到多排出孔数序。
- 输出为各包围盒裁片沿布局轴的紧密拼接：第 i 块的形状取孔数序第 i 名的
  精灵，但整块重涂为位置序第 i 名精灵的颜色。
- 水平轴从左到右、垂直轴从上到下拼接。

关键洞察：
- 颜色留在原来的位置序列上，形状却按孔洞计数重新排队，输出像是精灵们
  互换了身体；当两种顺序恰好一致时输出退化为普通紧排，这是埋给
  "按位置拼接"假设的诱饵。
```

```yaml
    j-th swatch recolors j-th template (aligned by column position)
  markers:
    middle-band cells (compressed, excluding thick sep cols) contain marker pixels
    color = one of the K template_colors
    count: total 60-100% of N*N cells across all templates; 0-100% per template
    disjoint: different template markers occupy disjoint (r mod N, c mod N) slots
    tile_column_uniform: each tile column in the middle band contains markers of exactly one template color; there is a 1-to-1 mapping from templates to tile columns (not necessarily identity)
    placement: arbitrary within middle band (not required to match template shape)
  output:
    shape: (N*N) x (N*N)
    construction: for each marker at (r,c) colored c_j (template j), paint template_mask[j] recolored to palette[j] at output block (r%N * N, c%N * N)

generation_strategy: |
  Output-first, then invert. Build the stamp decisions, then place markers.
  1. Sample N in 3-5, K in 3-4; choose bg=0, sep=5.
  2. Pick K distinct template colors and K palette colors (both subsets of 1-9 minus bg,sep; palette may reuse template colors).
  3. For each template j: sample an N x N binary mask (single 8-connected component, density 50-100%, include some symmetric and some not).
  4. Assign stamp placements: for each of the N*N slots (rr,cc), randomly pick one template index (or leave empty with small prob, target ~75-90% slot coverage). Ensures disjoint per-template slot sets.
  5. Assign a random 1-to-1 mapping from templates to tile columns. For each (j, slot) assignment, place marker of color tcols[j] at row r in [N+1, 2N] where (r-(N+1)) % N == rr, in the tile column assigned to template j at local column cc.
  6. Build the full input grid:
     - Place K templates in top band (row 0..N-1), separated by 1-col sep gaps.
     - Stamp dashed thick_sep rows at row N and 2N+1, thick_sep cols at N, 2N+1, ..., using the dashed pattern (sep at even positions within each tile, bg at odd).
     - Write markers into the middle band cells chosen in step 5.
     - Put palette swatches in bottom band: one palette_color pixel (or small cluster) roughly centered in each tile column.
     - Optionally pad with trailing bg rows/cols (0-2 rows, 0-7 cols).
  7. Run the solver on the constructed input and assert the output matches the constructed stamp-map rendering.
```
