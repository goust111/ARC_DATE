## 4. 被遮挡的循环色环场

- 参考题目题号: 6 (d22278a0)、7 (bda2d7a6)、1 (67b4a34d)

  - object:隐含中心, hidden_center
  - relation:切比雪夫距离取余循环, chebyshev_modulo_color_cycle
  - condition:中心与相位由残迹反推, center_and_phase_from_fragments
  - condition:截止半径限定环场, cutoff_radius_bounds_field

### docstring

```text
由可见的同心方环片段反推未画出的环心、颜色循环序列与环场截止半径，重建被实心矩形遮住区域的图案。

输入结构
- 画面本是围绕某中心格生成的同心方环场：第 k 圈（Chebyshev 距离 k）的颜色由一个长度不定（各题不同，如 3 或 4）的颜色序列按 k 对周期取余循环给出。
- 环场只画到某个最大半径，此外皆为背景色。
- 其上覆盖一块实心矩形遮挡，遮挡覆盖中心格及内侧数圈。
- 输出尺寸等于遮挡矩形。

规则
- 由可见环线的角点与间距唯一确定中心位置。
- 沿可见半径方向读出颜色循环序列及其相位。
- 由最外一圈环色与背景的分界确定截止半径。
- 对遮挡内每格，若其到中心的 Chebyshev 距离不超过截止半径，按距离对周期取余填入序列对应色，否则填背景色。

关键洞察
- 镜像对称补全失效：遮挡盖住中心，对称对应点同在遮挡内。
- 视觉延拓也不可靠——中心与内侧数圈整体缺失，环的确切边界、色序相位与截止范围都必须从残存片段反推出来才能落格。
```

1. `main(grid)` 必须实现新题描述中的确定性转换规则，不能只识别 `generate_input()` 的固定模板。禁止不同的input网格输出相同的output网格。
2. `generate_input()` 必须随机生成多样样例，不能固定死。随机维度应覆盖：网格大小、对象数量、位置、颜色、方向、形状参数或关键分支。注意若描述中存在若干，需实现而不是只有单个，包括object或者对应关系等等。且若涉及到最短路径，则输入网格中必涉及到多条路径，对选择造成干扰。

6. 若规则有多个分支，生成器不能长期固定成一个分支；应让分支在随机样例中合理出现。分支概率不必平均——难以发现的隐蔽分支（如少数情况下才触发的特殊规则）应适当提高出现概率，确保在 3 个训练示例中至少出现一次，否则求解者无法归纳该规则。对于颜色映射类规则，确保 2 个左右的示例即可覆盖所有映射关系（每种颜色→颜色的映射至少在某个示例中出现过）。
