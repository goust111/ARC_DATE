## 5. 多尺度残片互补重建

### docstring

```text
多个不同放大倍数的残缺像素放大副本互相拼出从未完整出现的原型，再各自按原型补全缺块。

输入结构：
- 黑色背景上散布若干对象，它们都是同一个小型多色图案的像素放大副本：
  图案的每个像素被放大为 n×n 的同色实心块，不同副本的 n 各不相同（含 n=1）。
- 每个副本都缺失了若干整块（缺失处为背景），没有任何一个副本是完整的；
  各副本的缺失位置互补，合起来覆盖完整图案且无矛盾。
- 每个副本四角的块均保留。

规则：
- 对每个副本，由其内部同色实心块的边长读出放大倍数 n，将其缩回 1 倍。
- 把所有缩回结果按包围盒对齐叠合，缺失处互补，得到完整的原型图案。
- 再对每个副本：凡原型有色而副本对应 n×n 块为背景的位置，补上该色的整块。
- 输出为全部副本补全后的场景。

关键洞察：
- 完整图案在输入中从未被画出，它分散在不同尺度的残片里；
  必须先跨尺度归一、互补重建原型，才能回头补全每一个副本。
```

  approach: output-first (build settled state, then extend paths to get input)
  steps:
    1. Choose grid size H x W in [9,14].
    2. Decide component counts: N_active in [1,2], N_static_gate = N_static_marker in [0,2].
    3. For each component (active or static-gate), place a gate on a grid boundary edge.
       Gate = end-center-end triplet; center on edge, axis along edge. Ensure gates are well-separated.
    4. For each gate, determine parking cell (1 step inward from center, perpendicular to edge).
    5. For active components, place marker_color at parking (this is the output state).
    6. To build input, grow an L-shaped path from parking: arm1 extends 0-1 extra cells perpendicular to edge,
       then arm2 extends 1-10 cells parallel to edge. Place the marker adjacent to the far end of arm2
       (on the grid boundary). Remove marker from parking. This reverses the solver transform.
    7. For static-gate components, grow a similar L-path from parking (no marker needed).
    8. Place N_static_marker isolated marker pixels on the grid boundary, not adjacent to any component.
    9. Validate: all components are 4-connected-disjoint; no overlaps; solver recovers the output.
