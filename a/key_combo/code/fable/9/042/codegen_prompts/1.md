## 1. 弹道与隧道

### docstring

```text
让每枚中心弹子从发射框缺口射出，经双缺口隧道框转向中继，最终停进接收框中心或贴壁停下。

输入结构
- 黑背景大网格上散布若干 3x3 单色矩形边框。
- 每个边框的八个边界格中缺失一或两个非角格（缺口）。
- 恰有一个缺口且中心有一枚异色像素（弹子）的框是发射框。
- 恰有一个缺口且中心为空的框是接收框。
- 恰有两个缺口且中心为空的框是隧道框。
- 保证每条弹道不成环、不与其他弹道交叠。

规则
- 每枚弹子从所在框中心沿"缺口相对中心方向"射出并直线飞行。
- 若下一步将进入某框的实体边界格，弹子停在紧贴该框外侧的格上。
- 若飞行线恰好命中某框的缺口格：该框是接收框时，弹子穿入并停在其中心；
  该框是隧道框时，弹子穿入后立即从另一缺口射出，沿新方向继续飞行。
- 若飞出画面，该弹子消失。
- 所有框保持不变，弹子原中心位置清为背景。

关键洞察
- 缺口数量决定框的角色：一个缺口是端点（发射口或接收洞），两个缺口是
  改变方向的中继隧道。
- 弹子的终点由整条连锁路径决定，而非离它最近的目标；对齐缺口的相遇
  不是碰撞而是通行。
```

```yaml
    clear_all: fill grid with background
    fill_block: each singleton color written to the block cell in its matching quadrant
    quadrant_mapping: upper-left singleton -> block[0,0], upper-right -> block[0,1], lower-left -> block[1,0], lower-right -> block[1,1]

generation_strategy:
  approach: output-first
  steps:
    1. Pick grid size 10x10, bg=0, block_color=8
    2. Place 2x2 block at (r, c) ensuring >=2 rows above, >=2 rows below (r+1), >=2 cols left, >=2 cols right (c+1)
    3. Pick 4 distinct colors from {1-9} minus block_color for the four quadrants
    4. Build output by filling block cells with those 4 colors, rest bg
    5. For each quadrant color, randomly place a singleton in the valid region (strictly above/below and left/right of block), avoiding collisions with other singletons
    6. Input = output but replace 4 block cells with block_color, and add the 4 singletons at their scattered positions
```
</generation_spec>

## 实现要求

1. `main(grid)` 必须实现新题描述中的确定性转换规则，不能只识别 `generate_input()` 的固定模板。禁止不同的input网格输出相同的output网格。
2. `generate_input()` 必须随机生成多样样例，不能固定死。随机维度应覆盖：网格大小、对象数量、位置、颜色、方向、形状参数或关键分支。注意若描述中存在若干，需实现而不是只有单个，包括object或者对应关系等等。且若涉及到最短路径，则输入网格中必涉及到多条路径，对选择造成干扰。

6. 若规则有多个分支，生成器不能长期固定成一个分支；应让分支在随机样例中合理出现。分支概率不必平均——难以发现的隐蔽分支（如少数情况下才触发的特殊规则）应适当提高出现概率，确保在 3 个训练示例中至少出现一次，否则求解者无法归纳该规则。对于颜色映射类规则，确保 2 个左右的示例即可覆盖所有映射关系（每种颜色→颜色的映射至少在某个示例中出现过）。
