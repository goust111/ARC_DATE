### docstring

```text
用指示像素消除对称歧义，把多色源精灵经旋转或镜像印到每个同掩码的单色占位对象上，再擦除源精灵。

输入结构
- 背景上有一个连通的多色源精灵，内嵌恰一枚指示色像素。
- 另有若干单色占位对象，其掩码与源精灵掩码经某个旋转/镜像后重合，
  且各内嵌恰一枚同指示色像素。
- 掩码本身具有旋转或镜像对称性，仅凭外形无法唯一确定所需变换。

规则
- 对每个占位对象，选取既使掩码重合、又使指示像素位置对齐的那个
  二面体变换。
- 按该变换把源精灵的全部颜色印到占位对象位置。
- 最后把源精灵擦为背景。

关键洞察
- 掩码的对称性使多个变换都能令外形吻合，唯一的定向依据是那枚
  不起眼的指示像素；它同时提供对应点与朝向。
- 若只做形状匹配而忽略指示像素，输出在对称掩码上会印错方向。
```

<description>
Fill the 2x2 marker block with the singleton colors found in matching surrounding quadrants.

Input structure
- The grid has a dominant background, one solid 2x2 foreground marker block, and four other foreground singleton pixels.
- Each singleton lies diagonally outside the marker block: above/below it and left/right of it.

Rule
- Clear all foreground pixels from the canvas.
- Place each singleton color into the cell of the marker block in the same relative quadrant: upper-left, upper-right, lower-left, or lower-right.

Key insight
- The 2x2 block is a compact target window; each scattered singleton's side relative to that block determines its destination cell.

1. `main(grid)` 必须实现新题描述中的确定性转换规则，不能只识别 `generate_input()` 的固定模板。禁止不同的input网格输出相同的output网格。
2. `generate_input()` 必须随机生成多样样例，不能固定死。随机维度应覆盖：网格大小、对象数量、位置、颜色、方向、形状参数或关键分支。注意若描述中存在若干，需实现而不是只有单个，包括object或者对应关系等等。且若涉及到最短路径，则输入网格中必涉及到多条路径，对选择造成干扰。
3. 生成器必须保证输入满足 `main()` 的隐式假设：对象不重叠、不越界、特殊标记唯一或可区分、匹配关系无歧义、关键分支出现概率相同。
4. 禁止把 ARC 颜色 id 、亮度、拼写等当作人类不可见的数值语义参与排序、大小比较或隐藏映射。颜色变化必须有可见结构线索。注意颜色亮度、拼写等也是不可见信息，若描述中出现违规的颜色id或者亮度，可自行使用少量的固定颜色替代，但注意生成时要在三个以内输入输出网格中对所有变换100%覆盖度。

6. 若规则有多个分支，生成器不能长期固定成一个分支；应让分支在随机样例中合理出现。分支概率不必平均——难以发现的隐蔽分支（如少数情况下才触发的特殊规则）应适当提高出现概率，确保在 3 个训练示例中至少出现一次，否则求解者无法归纳该规则。对于颜色映射类规则，确保 2 个左右的示例即可覆盖所有映射关系（每种颜色→颜色的映射至少在某个示例中出现过）。
