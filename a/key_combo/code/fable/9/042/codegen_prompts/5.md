### docstring

```text
由顶边与左边的同色投影段还原从未画出的矩形，并按"小面积在上"的层序叠绘。

输入结构
- 背景网格；第 0 行（第 1 列起）有若干互不重叠的水平彩色段，
  第 0 列（第 1 行起）有若干互不重叠的竖直彩色段。
- 颜色两两配对：每种颜色恰好一横一竖。
- 内部画布为纯背景。

规则
- 每对同色段确定一个矩形：列范围取自顶行段、行范围取自左列段。
- 在内部画布绘制全部实心矩形；重叠处由面积较小的矩形覆盖面积较大的。
- 最后把第 0 行与第 0 列清为背景。

关键洞察
- 参与规则的矩形从未被画出，画面上只有它在两条边上的正交投影；
  同色的一横一竖才是一个对象的两个残迹。
- 重叠层序不由输入顺序或位置决定，而由面积决定，必须从重叠示例反推；
  "把边缘颜色向内延伸成条带"是诱饵。
```
