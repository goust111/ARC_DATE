## 1. 双管倒灌

- 参考题目题号: 4 (aba27056), 6 (b2bc3ffd), 9 (668eec9a), 20 (beb8660c)
- tags:
  - operation:计数, counting
  - operation:顺序反转, order_reversal
  - operation:射线延伸, ray_extend
  - object:管状容器, tube_container
  - object:液体段, liquid_segment
  - relation:开口朝向, opening_direction
  - condition:容量守恒与溢出, conservation_overflow

### docstring

```text
把源管中的液体按倒出顺序灌入目标管，颜色段相对封底整体反转，装不下的部分从目标管开口溢出成直线。

输入结构
- 黑色背景上有两个灰色管壁围成的容器，内部为一格宽的弯折走廊，各有唯一的一格开口，走廊另一端封死。
- 其中一个容器（源管）内自封底起连续填有若干段不同颜色的液体格，其余走廊格为空；另一个容器（目标管）内部全空。

规则
- 液体自源管开口逐格倒出：离开口越近的格越先流出。
- 先流出的液体沉到目标管封底，之后逐格排向开口；因此以"距封底的次序"看，颜色段在目标管中整体反转，每段内部长度不变。
- 若液体总量超过目标管走廊容量，装不下的液体从目标管开口沿开口朝外方向排成一条直线，先溢出的紧贴开口。
- 源管内部全部清空，管壁与其余一切保持不变。

关键洞察
- 倒灌是"先进先出"到"先进先沉"的转换：段序相对封底整体反转，而不是原样平移；溢出的长度由两管容量之差决定，溢出的方向由目标管开口朝向决定。
```

```yaml
    gap: the cell adjacent to marker through the gap is the doorway; one more step in same direction is the exterior cell
    exterior_cell: must be in-bounds and bg; marker needs >=2 cells clearance to grid edge in gap direction
    separation: >=5 rows and >=5 cols between marker centers
  corridor:
    endpoints: the two exterior cells (always differ in both row and col)
    monotone_moves: only steps toward the other endpoint (at most down/up + left/right)
    fill: union of all bg cells reachable from both endpoints via monotone steps within the bounding box, treating frame/marker pixels as blockers
  output:
    paint corridor fill cells + both doorway gap cells YELLOW; keep frame and marker unchanged

generation_strategy:
  approach: output-first
  steps:
    1. Pick grid 15x15. Place two marker positions in diagonally opposite quadrants with >=5 row and >=5 col separation between them, and each >=2 cells from the nearest edge in at least one cardinal direction.
    2. For each marker, choose a gap direction (N/S/E/W) such that the exterior cell (marker + 2*gap_dir) is in-bounds. Build the 3x3 frame (8 surrounding cells = frame_color, except the gap cell = bg).
    3. Compute exterior cells. Verify they differ in both row and col (diagonal corridor). If not, re-pick gap directions.
    4. Run solver's monotone BFS from both endpoints; compute the yellow region. Verify the path is non-empty (it always will be if no extra obstacles exist and endpoints differ in both dimensions).
    5. Return the input grid (frames + markers on black bg); output is computed by solver.
```
