## 7. 暗渠连通

  - relation:底部连通, bottom_connectivity

  - condition:下游连锁, downstream_cascade

### docstring

```text
泉水注入地形盆地后逐层上升，底部暗渠使相连盆地按连通器原理同水位上涨，联合水体升至最低沿口即外溢下行，直到水流出网格；未被水系触及的盆地保持干涸。

输入结构
- 网格下部为单色实心地形，轮廓起伏形成多个盆地。
- 地形内部藏有一条一格高的背景色水平暗渠，连通其中两个盆地的底部。
- 地形上方某处有一个标记色泉眼格；任何两个相关沿口不等高。

规则
- 水自泉眼竖直落到地表，落在坡面则沿地表向低处流动直至进入盆地。
- 盆地水面逐层上升；若该盆地经暗渠与另一盆地底部连通，两盆水面始终保持同高一起上升，暗渠自身也充满水。
- 水面升到当前连通水体所有沿口中最低的那个沿口高度时，从该沿口外溢，沿其外侧坡面下行注入下一个盆地，继续找平-外溢；水从网格边缘流出即结束。
- 输出把所有蓄水格与充水暗渠格染蓝，过流坡面不留痕，泉眼与地形保持不变。

关键洞察
- 一个泉眼看似只灌一侧，暗渠却让远处盆地同水位蓄水；溢出口要在连通水体的全部沿口中取最低，而不是就近取——"全图找平"和"只灌下游"都是诱饵。
```

<description>
Stamp source sprites into a destination frame via color-matched singleton markers.

Input structure:
- Two bordered rectangles: source (multi-cell sprites) and destination (singleton markers).
- Each sprite has an anchor pixel — its least-frequent color. Markers share these colors.

Rule:
- Match each destination marker to the source sprite with the same anchor color.
- Translate the sprite so its anchor overlaps the marker position.
- Output is the destination rectangle, interior cleared before stamping.

Key insight: The rarest color per sprite doubles as a template key and positioning anchor.
</description>

## 实现要求

1. `main(grid)` 必须实现新题描述中的确定性转换规则，不能只识别 `generate_input()` 的固定模板。禁止不同的input网格输出相同的output网格。
2. `generate_input()` 必须随机生成多样样例，不能固定死。随机维度应覆盖：网格大小、对象数量、位置、颜色、方向、形状参数或关键分支。注意若描述中存在若干，需实现而不是只有单个，包括object或者对应关系等等。且若涉及到最短路径，则输入网格中必涉及到多条路径，对选择造成干扰。
3. 生成器必须保证输入满足 `main()` 的隐式假设：对象不重叠、不越界、特殊标记唯一或可区分、匹配关系无歧义、关键分支出现概率相同。
4. 禁止把 ARC 颜色 id 、亮度、拼写等当作人类不可见的数值语义参与排序、大小比较或隐藏映射。颜色变化必须有可见结构线索。注意颜色亮度、拼写等也是不可见信息，若描述中出现违规的颜色id或者亮度，可自行使用少量的固定颜色替代，但注意生成时要在三个以内输入输出网格中对所有变换100%覆盖度。
5. 输出样例要视觉清晰，人类必须能从输入输出对中肉眼辨认出规律。具体要求：避免对象粘连、覆盖关系混乱、同一像素多重语义；不同逻辑步骤产生的结果不要大面积层叠在一起导致无法分辨哪个颜色属于哪个步骤；输入中各元素之间保持足够间距，输出中新增的标记/填充/路径等应与背景和已有元素在颜色上有明显区分；若规则涉及多层叠加，生成时控制对象密度和尺寸，确保叠加区域只占少数像素而非铺满整个网格。
6. 若规则有多个分支，生成器不能长期固定成一个分支；应让分支在随机样例中合理出现。分支概率不必平均——难以发现的隐蔽分支（如少数情况下才触发的特殊规则）应适当提高出现概率，确保在 3 个训练示例中至少出现一次，否则求解者无法归纳该规则。对于颜色映射类规则，确保 2 个左右的示例即可覆盖所有映射关系（每种颜色→颜色的映射至少在某个示例中出现过）。
