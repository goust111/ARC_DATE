### docstring

```text
让每个彩色孤立像素沿直线射出，经由矩形边框上的缺口穿行并转向，沿途填充每个被穿过的空心矩形内部。

输入结构
- 黑色背景上有若干灰色空心矩形边框，矩形之间互不接触。
- 每个矩形边框上恰有两个单格缺口，两缺口或位于一对对边上且同行同列对齐（直穿门），或位于一对邻边上（转向门）。
- 另有若干彩色孤立像素，每个像素恰有一个方向与某个矩形的一个缺口同行或同列，且这条视线中间无任何前景阻挡。

规则
- 每个彩色像素沿其唯一的对齐方向直线前进，途经的背景格画为该像素的颜色。
- 射线从缺口格进入矩形后，该矩形内部全部填充为该颜色，随后从另一个缺口离开：两缺口在对边时方向不变，在邻边时行进方向转过九十度（离开方向为出口所在边的外法线方向）。
- 离开后继续直行，若再与下一个矩形的缺口对齐则重复进入、填充、离开的过程。
- 射线撞到无缺口的灰色边框壁或走出画布边缘时终止。
- 灰色边框保持不变，射线经过的缺口格写为线路颜色，源像素保留原位。

关键洞察
- 缺口是门，整条路线由各矩形上两扇门的相对位置逐段决定；内部填色只是路线的副产品，真正要恢复的是那条会在箱子里转弯的隐形光路。
```

```yaml
    colors: exactly 2 non-bg non-grey colors
    symmetry: neither LR nor UD symmetric
    connectivity: single 4-connected component
    position: anywhere on grid, separated from all targets by >=1 bg cell
  grey_targets:
    count: 2-3 solid grey (5) rectangles
    shape: identical to template dimensions
    separation: each pair of objects (template + targets) separated by >=1 bg cell
  output:
    each grey target replaced by an exact copy of the template
    template and background unchanged

generation_strategy:
  approach: output-first
  steps:
    1. Pick grid 10x10, choose 2 non-bg non-grey colors
    2. Generate a th x tw template (3-4 each) using those 2 colors, fully occupied, 4-connected, not LR/UD symmetric
    3. Pick N=2-3 target slots; place template + N grey rectangles (all th x tw) on grid with >=1 bg-cell gap between every pair of bboxes and within grid bounds
    4. Output = grid with template pattern at all N+1 positions
    5. Input = output but replace the N target copies with solid grey (5)
```
</generation_spec>
</reference_puzzle>

## 实现要求

1. `main(grid)` 必须实现新题描述中的确定性转换规则，不能只识别 `generate_input()` 的固定模板。禁止不同的input网格输出相同的output网格。
2. `generate_input()` 必须随机生成多样样例，不能固定死。随机维度应覆盖：网格大小、对象数量、位置、颜色、方向、形状参数或关键分支。注意若描述中存在若干，需实现而不是只有单个，包括object或者对应关系等等。且若涉及到最短路径，则输入网格中必涉及到多条路径，对选择造成干扰。
3. 生成器必须保证输入满足 `main()` 的隐式假设：对象不重叠、不越界、特殊标记唯一或可区分、匹配关系无歧义、关键分支出现概率相同。
4. 禁止把 ARC 颜色 id 、亮度、拼写等当作人类不可见的数值语义参与排序、大小比较或隐藏映射。颜色变化必须有可见结构线索。注意颜色亮度、拼写等也是不可见信息，若描述中出现违规的颜色id或者亮度，可自行使用少量的固定颜色替代，但注意生成时要在三个以内输入输出网格中对所有变换100%覆盖度。

6. 若规则有多个分支，生成器不能长期固定成一个分支；应让分支在随机样例中合理出现。分支概率不必平均——难以发现的隐蔽分支（如少数情况下才触发的特殊规则）应适当提高出现概率，确保在 3 个训练示例中至少出现一次，否则求解者无法归纳该规则。对于颜色映射类规则，确保 2 个左右的示例即可覆盖所有映射关系（每种颜色→颜色的映射至少在某个示例中出现过）。
