## 3. 分隔色刻度的叠加

### docstring

```text
按各面板内分隔色散点的数量决定遮挡层序，把等大的图案面板由深到浅叠加成一幅输出。

输入结构
- 若干等大的图案面板被同一颜色的竖直分隔条隔开。
- 每个面板内除黑色透明格与本面板的图案色外，还散布若干与分隔条同色的孤立像素。
- 各面板中这种分隔色孤立像素的数量互不相同。

规则
- 数出每个面板内分隔色孤立像素的个数：个数越少的面板层次越深，个数越多的越靠前。
- 先删去这些孤立像素，再从最深层的面板开始，依次把每个面板的非黑图案格覆盖到输出画布上。
- 输出为单个面板的大小。

关键洞察
- 面板的左右排列顺序是诱饵；真正的层序由混在图案里、与分隔条同色的像素充当的深度刻度给出，它们本身不属于任何图案，数完即弃。
```

```yaml
    rule: translate each piece (no rotation) so its red connectors overlap matching reds on the growing assembly
    overlap: only red pixels may overlap between sprites; non-red pixels never conflict
    output: single 4-connected assembled structure on otherwise empty grid
  input_layout:
    sprites_scattered: all sprites placed non-overlapping with >= 2 Chebyshev gap between any pair
    grid_large_enough: grid must fit both scattered input and assembled output

generation_strategy:
  approach: output-first (build assembled jigsaw, then scatter to get input)
  steps:
    1. Choose grid size 22-26.
    2. Design anchor (3x3 yellow block + 2-4 red connectors on distinct edges).
    3. Build connection tree with 4-6 piece nodes; assign each node a degree (leaves=1, internal=2+).
    4. For each piece, design a frame/bracket sprite with reds = 2 * degree, placed on appropriate edges to match its tree neighbors.
    5. Assemble all pieces onto the anchor by aligning red connector pairs; verify no non-red overlap and assembly fits in grid.
    6. Record each piece's assembled position; this is the output.
    7. Scatter pieces to random non-overlapping positions (>= 2 gap) on the grid to produce the input. Anchor keeps its assembled position.
```
</generation_spec>
</reference_puzzle>
