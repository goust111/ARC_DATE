## 2. 隐藏对称元素的双洞互补

### docstring

```text
先从残缺图案反推出未画出的点对称中心与镜像轴，再沿复合对称轨道修复两个互相遮挡对称像的黑洞。

输入结构：
- 一个多色图案占据网格的一部分，图案同时满足绕某个隐藏中心格的点对称
  和关于某条隐藏竖直轴的镜像对称。
- 中心与轴都不在网格几何中心上，画面上没有任何标记指出它们的位置。
- 图案上叠着两个实心黑色矩形洞；部分洞内格子的单步对称像恰好落进另一个洞。

规则：
- 用洞外像素推断出唯一无矛盾的点对称中心与竖直镜像轴；两者复合还派生出
  一条隐藏水平轴。
- 洞内每格沿这三个变换生成的轨道寻找任一洞外已知格取值；单步像落在另一
  洞里的格子，必须经两种对称的复合变换走两步才能取到洞外的值。
- 输出修复完成的整幅网格。

关键洞察：
- 对称本身不难，难在对称元素从未被画出且不与画布中心重合，必须先从残缺
  图案里反推出中心与轴的位置；两洞互相遮挡又逼迫解题者把两种对称复合起来
  使用，单用任何一种反射都补不全。
```

      Each pipe row (except last) contributes 2 tokens (left+right edge); route
      them downward and pack at segment endpoints. Ensure at least one token
      traverses >=3 levels for non-trivial paths.
    - Invert to get input -- undo gate rotation (replace each 3-tall 6-post
      with 1x3 horizontal 7-bar in the wall row, remove 6-posts from pipe rows),

1. `main(grid)` 必须实现新题描述中的确定性转换规则，不能只识别 `generate_input()` 的固定模板。禁止不同的input网格输出相同的output网格。
2. `generate_input()` 必须随机生成多样样例，不能固定死。随机维度应覆盖：网格大小、对象数量、位置、颜色、方向、形状参数或关键分支。注意若描述中存在若干，需实现而不是只有单个，包括object或者对应关系等等。且若涉及到最短路径，则输入网格中必涉及到多条路径，对选择造成干扰。

6. 若规则有多个分支，生成器不能长期固定成一个分支；应让分支在随机样例中合理出现。分支概率不必平均——难以发现的隐蔽分支（如少数情况下才触发的特殊规则）应适当提高出现概率，确保在 3 个训练示例中至少出现一次，否则求解者无法归纳该规则。对于颜色映射类规则，确保 2 个左右的示例即可覆盖所有映射关系（每种颜色→颜色的映射至少在某个示例中出现过）。
