## 4. 看不见的条纹场

### docstring

```text
两个种子像素定义一个从不画出的周期条纹场，网格中的灰点按落在哪条虚拟条纹
上被重涂或抹去。

输入结构:
- 黑底网格上恰有两个异色种子像素（颜色 A 与颜色 B）和若干灰色散点。
- 若某个种子贴着左右侧边缘，条纹取整行方向；否则取整列方向。
- 两种子间距 d 决定条纹以 2d 为周期向两侧无限重复。

规则:
- 不画出任何条纹，两个种子保持原样。
- 每个灰点：其所在行（或列）与 A 种子所在行（列）相差 2d 的整数倍，
  涂成 A 色；与 B 种子所在行（列）相差 2d 的整数倍，涂成 B 色；
  两者皆不满足则抹为黑。

关键洞察:
- 源题里铺满画面的条纹在这里从未出现；两颗种子只是隐形坐标系的生成元，
  灰点的命运由它们在这套看不见的周期相位场中的位置决定。
```

## 实现要求

1. `main(grid)` 必须实现新题描述中的确定性转换规则，不能只识别 `generate_input()` 的固定模板。禁止不同的input网格输出相同的output网格。
