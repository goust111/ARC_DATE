## 2. 沿十字折叠湮灭

### docstring

```text
把网格沿画中偏置的十字分隔线折成四层，只有恰好一层前景到达的位置才显色，重叠即湮灭。

输入结构
- 一条整行与一条整列的灰色分隔线（不在网格中央）把网格分成四个大小
  不等的象限。
- 每个象限是黑底上的一种单色掩码，四个象限的颜色互不相同。

规则
- 以十字交点为折叠中心，把四个象限沿分隔线翻折对齐：右上象限左右翻转、
  左下象限上下翻转、右下象限双向翻转，镜轴均为分隔线。
- 输出画布取最大覆盖范围：行数为上、下两侧象限高度的较大者，列数为
  左、右两侧象限宽度的较大者；各层以贴近折叠中心的角对齐。
- 对每个位置统计"覆盖到该位置的层"中前景的个数：恰好一层为前景时输出
  该层的颜色；零层，或两层及以上（无论颜色异同）时输出黑色。
- 小象限够不到的位置只由够得到的层参与统计。

关键洞察
- 折叠轴是画中偏置的十字而不是网格中线，四层的覆盖范围因此各不相同；
  这既不是四象限镜像拼贴也不是固定优先级的覆盖合成——折叠后相互重叠
  的前景彼此湮灭，答案只保留折叠中"独占"的前景像素。
```

```yaml
  approach: output-first (build full symmetric pattern, then place mask)
  steps:
    1. Choose n=24. Enumerate all 78 D4 orbits of the n x n grid.
    2. Pick k=5-8 colors from {1,2,4,5,6,7,8,9} (exclude 0 and 3). Assign each orbit a random color from this palette to build the full symmetric pattern.
    3. Choose mask dimensions h in [2,8], w in [2,8] with area in [9,56].
    4. Choose mask top-left (r0,c0) with r0+h<=n, c0+w<=n. Verify every cell in the mask rectangle has >=1 non-masked D4-symmetric copy (reject otherwise; rejection rate is low for small masks on a 24x24 grid).
    5. Overwrite mask cells with color 3 to produce the input grid.
    6. Output is the h x w crop with colors looked up from the full pattern (step 2).
```
