## 4. 残迹滑移饰带

### docstring

```text
由一条完整行带和远处一小撮残迹像素反推出整条滑移反演饰带，并把它铺满全画布。

输入结构：
- 背景画布上有一条完整的水平行带，带内图案恰由两种前景色构成。
- 在画布竖直方向的另一处，留有寥寥数个前景像素，它们是该饰带某个远端副本的
  残迹，既不完整也不与原带同相。

规则：
- 饰带由第 0 号副本（原带）沿竖直方向逐份延展而成：第 k 号副本相对第 k-1 号
  副本上下翻转、两种前景色互换，并整体水平平移固定偏移 s 列。
- 偏移 s 不在画面中直接给出，必须让某号副本恰好与残迹像素逐格吻合才能解出。
- 解出后把所有副本（含翻转、换色、平移的累计效果）向上下铺满画布，
  超出边界的部分裁掉，残迹随之被补全。

关键洞察：
- 残迹是从未完整画出的副本留下的证据；解题需要同时锁定三件事——
  相邻副本的几何翻转、双色对合、水平滑移量——任何一件单独都无法与残迹吻合，
  必须联立求解才能确定唯一答案。
```
