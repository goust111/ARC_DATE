### docstring

```text
底部编码行里每种颜色出现的次数，决定上方同色标记像素长出的实心方形光环的半径；没上榜的颜色被抹除。

输入结构
- 一条灰色实心分隔行横贯全宽，其下方恰有一个非背景编码行，其余为黑色背景。
- 分隔行上方散布若干孤立的彩色单像素标记。
- 网格保证：任意两个光环互不重叠；光环可在网格边缘被裁剪。

规则
- 对每种颜色 c，数它在编码行中出现的次数 k。
- 上方每个颜色为 c 的标记像素，以自身为中心涂一个边长 2k+1 的实心 c 色方块（越界部分裁掉）。
- 上方颜色未在编码行中出现的标记像素被擦除为背景。
- 分隔行与编码行保持不变。

关键洞察
- 编码行不是要匹配的目标而是一张"图例"：颜色的出现频率被读作几何参数（光环半径），
  频率为零则读作"删除"；第一个用例中各色都恰出现一次，看起来像固定的 3x3 光晕，
  这个假象要靠后续用例拆穿。
```

```yaml
    count: 7-10 total (2 terminals + 5-8 stations)
    no_overlap: squares do not touch each other; separated by >= 1 bg pixel
  graph:
    edges: 7-11 track segments, each 8-adjacent to exactly 2 node squares (simple graph, no multi-edges)
    connected: always
    cycles: 1-2 independent cycles (E - V + 1)
    shortest_path: 2-3 edges between the 2 terminals, always unique
  track_segments:
    pixel_count: 2-20 per segment; use 8-connected diagonal/cardinal steps
    shape: mostly L-shaped or diagonal; 0-2 direction changes per segment
  output:
    station squares on shortest path recolored to green(3)
    track segments on shortest path recolored to grey(5)
    everything else unchanged

generation_strategy:
  approach: graph-first, then embed spatially
  steps:
    1. Pick grid size S in [15,30], node size N in {2,3}, 4 colors excluding green(3)/grey(5).
    2. Build abstract graph: V=7-10 nodes (2 terminal + rest station), E=V+{0,1,2} edges.
       Ensure connected, 1-2 cycles, and unique shortest path of 2-3 edges between terminals.
    3. Place NxN squares on grid with sufficient spacing (>= N+2 gap between centers).
    4. Route track segments between connected node pairs using (N-1)-wide 8-connected paths
       (horizontal, vertical, and diagonal steps). Segments must not overlap each other or squares.
    5. Verify: each track component touches exactly 2 node squares via 8-adjacency; BFS shortest
       path is unique. Retry routing or placement if violated.
    6. Output is derived by recoloring shortest-path stations to green and shortest-path tracks to grey.
```
</generation_spec>
</reference_puzzle>
