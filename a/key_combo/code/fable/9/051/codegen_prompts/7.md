### docstring

```text
2x2 方块的缺角标记发射一颗对角弹球，弹球在网格边缘反弹、留下轨迹，最终击中的障碍物被染成标记色。

输入结构
- 背景为黑色。恰有一个 2x2 方块，其中三格为青色填充色、一格为红色标记，标记位于方块某个角。
- 另有若干实心的彩色矩形障碍物，与方块互不接触。
- 网格保证：弹球在有限步内必定命中某个障碍物。

规则
- 发射方向：由与标记对角相对的那个填充格指向标记格，并沿该对角方向继续向外。
- 弹球从标记格外的第一格开始，沿对角方向逐格前进，把经过的黑色格涂成红色。
- 当下一步将越出网格边界时，把越界的行分量或列分量取反（撞角则两个分量同时取反），继续前进。
- 当下一步将进入某个障碍物时，弹球终止，整个被命中的障碍物重涂为红色。
- 2x2 方块本体与未被命中的障碍物保持不变。

关键洞察
- 画面上没有任何箭头：发射方向由"哪一角缺了填充色"这一几何残迹给出；
  轨迹要经历若干次镜面反弹，最后一击把命运传递给被命中者——
  第一个示例的直线命中会诱导人忽略反弹规则。
```

```yaml
    grey_unchanged: true
    black_other_parity_unchanged: true

generation_strategy:
  approach: direct construction
  steps:
    1. Choose grid size H in [13,15], W in [13,17] (odd values preferred to match eval)
    2. Place 2-4 irregular grey blobs near edges/corners using random walks or flood fills, targeting 30-45% grey coverage; ensure no row/col is fully grey
    3. Compute the largest 4-connected non-grey component; if it covers < 50% of grid, regenerate blobs
    4. Pick a random marker color from {1,2,3,4,6,7,8,9}
    5. Choose a random cell in the main open component that has all 4 neighbors also in the component and Manhattan distance >= 3 to nearest grey; place the marker
    6. Output is derived by applying the parity-fill rule (no inversion needed — input is the constructed grid)
```
</generation_spec>
</reference_puzzle>

2. `generate_input()` 必须随机生成多样样例，不能固定死。随机维度应覆盖：网格大小、对象数量、位置、颜色、方向、形状参数或关键分支。注意若描述中存在若干，需实现而不是只有单个，包括object或者对应关系等等。且若涉及到最短路径，则输入网格中必涉及到多条路径，对选择造成干扰。

6. 若规则有多个分支，生成器不能长期固定成一个分支；应让分支在随机样例中合理出现。分支概率不必平均——难以发现的隐蔽分支（如少数情况下才触发的特殊规则）应适当提高出现概率，确保在 3 个训练示例中至少出现一次，否则求解者无法归纳该规则。对于颜色映射类规则，确保 2 个左右的示例即可覆盖所有映射关系（每种颜色→颜色的映射至少在某个示例中出现过）。
