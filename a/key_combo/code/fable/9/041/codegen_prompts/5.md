## 5. 绕墙泛洪：同速扩张、异色等距成缝

- 参考题目：12（332202d5）、10（c61be7dc）、18（cf133acc）
- tags:
  - operation:最近扩散, nearest_fill
  - operation:填充, fill
  - object:种子色块, seed_blob
  - object:墙壁, wall
  - relation:通路距离分区, geodesic_partition
  - condition:异色等距为缝, diff_color_tie_seam
  - condition:同色汇合无缝, same_color_merge

### docstring

```text
让所有种子在墙壁间同速泛洪扩张：每格归最先到达者，异色等距的锋面留成背景缝，同色汇合则无缝合并。

输入结构：
- 网格含背景色、固定颜色 W 的墙壁像素（曲折壁段与豁口，不构成完全封闭房间），
  以及若干种子色块；种子颜色可能互异，也可能有两个种子同色。
- 开阔区里种子间的直线远近与绕墙通路远近被刻意设计得不一致。

规则：
- 所有种子同时以四连通逐步扩张（同速）；墙壁不可穿越也不被染色。
- 每个背景格染成最先到达它的种子的颜色。
- 若同一步有颜色不同的种子同时到达某格，该格永久保留背景色且不再向外传播；
  若同时到达者颜色相同，正常染色并继续传播。
- 输出扩张终止后的整幅网格（墙壁保持 W）。

关键洞察：
- 距离是绕墙的通路距离而非直线距离：区域会穿过豁口绕到墙背面，
  仅凭直线最近分区（首例开阔区给出的假象）会画错边界。
- 等距锋面是否留缝取决于双方颜色——异色势力间留背景缝，同色势力无缝并流；
  缝格不传播，还会在墙角后方拖出缝的延伸。
```

```yaml
    all intermediate cells between marker and anchor must be background in the input
  output:
    anchor and all markers unchanged; intermediate cells painted with the aligned marker's color
    unaligned markers remain as-is with no line drawn

generation_strategy:
  approach: output-first
  steps:
    1. Place 2x2 anchor (color 3) with margins >= 2 from all edges on a 10x10 bg-0 grid.
    2. Pick 1-2 marker colors (not 3 or 0).
    3. For 1-4 anchor sides, choose one side and place a marker of a random marker color
       at distance 2-6 along that row/column, ensuring the straight path to anchor is clear.
       Paint the full line (marker through adjacent-to-anchor) on the output grid.
    4. Place 1-6 unaligned markers at random positions that share neither anchor rows nor
       anchor columns, avoiding all occupied cells.
    5. Derive input by erasing all painted line cells except the original marker endpoints.
```
</generation_spec>
</reference_puzzle>
