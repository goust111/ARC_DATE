### docstring

```text
先辨认四个象限各自承载的对称变换，再用轨道多数表决剥离载体，读出散布其中的隐藏图形。

输入结构：
- 2N×2N 网格由分隔十字分成四个 N×N 象限。
- 每个象限是同一未知基底（本身无任何自对称）经八种方形对称变换（四旋转、四镜像）
  中某一种得到的像；四个象限的变换互不相同，且不固定为某种布局，须逐例推断。
- 把基底同一格在四象限的四个对应像素称为一条"轨道"；若干轨道中恰有一个像素被改成
  统一的信号色 M，其余轨道的四个像素完全一致。M 也出现在基底调色板中。

规则：
- 为每个象限确定其对称变换：取使四象限在全部轨道上最大程度一致的唯一解。
- 对每条轨道取四票多数（3:1）确定基底本色，找出所有持异议的像素。
- 把每个异议像素经其所在象限变换的逆映回基底坐标。
- 输出 N×N 网格：背景 0，仅在映回的位置画信号色 M。

关键洞察：
- 四个象限不是要构造的风车，而是信息载体；变换识别与多数表决互为前提——
  不解出各象限的变换就对不上轨道，不容忍每轨道一票反对又解不出变换。
- 信号色也在基底调色板中，凭颜色直接挑像素会混入载体本色，异议只能靠表决分离。
```

    at least 1 pair of frames has overlapping bboxes; 1-3 pairs overlap
    non-overlapping frames separated by >=1 bg cell [observed]
    all visible pixels of a frame lie on the border of its SxS bbox
  output_rule: |
    sort frames by size descending; create NxN grid; draw each as a centered
    concentric ring (outermost = largest frame, innermost = smallest)
generation_strategy:
  approach: output-first
  steps:
    1. pick N from 8-10; compute sizes = [N, N-2, ..., 1 or 2]; assign a unique color to each
    2. build the NxN output with concentric frames (validates ring structure)
    3. choose input side S = N + randint(4, 9) (ensuring S <= 30)
    4. for each frame (size, color), pick a random top-left (r, c) on the SxS input grid
       such that at least 1 row and 1 col of the frame is visible; allow partial off-grid
    5. ensure at least 1 pair of frame bboxes overlap
    6. draw frames onto the input in a random order; later draws overwrite earlier pixels
    7. verify each color's max(bbox_h, bbox_w) still equals its intended size
       (if occluded color lost its max dimension, re-pick positions and retry)

1. `main(grid)` 必须实现新题描述中的确定性转换规则，不能只识别 `generate_input()` 的固定模板。禁止不同的input网格输出相同的output网格。
2. `generate_input()` 必须随机生成多样样例，不能固定死。随机维度应覆盖：网格大小、对象数量、位置、颜色、方向、形状参数或关键分支。注意若描述中存在若干，需实现而不是只有单个，包括object或者对应关系等等。且若涉及到最短路径，则输入网格中必涉及到多条路径，对选择造成干扰。

6. 若规则有多个分支，生成器不能长期固定成一个分支；应让分支在随机样例中合理出现。分支概率不必平均——难以发现的隐蔽分支（如少数情况下才触发的特殊规则）应适当提高出现概率，确保在 3 个训练示例中至少出现一次，否则求解者无法归纳该规则。对于颜色映射类规则，确保 2 个左右的示例即可覆盖所有映射关系（每种颜色→颜色的映射至少在某个示例中出现过）。
