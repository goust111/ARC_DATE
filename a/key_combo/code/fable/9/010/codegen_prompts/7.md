## 7. 滤镜光路

- tags:
  - operation:射线延伸, ray_extend
  - operation:重涂色, recolor
  - object:方向帽, direction_cap
  - object:空心矩形框, hollow_frame
  - object:对角镜, diagonal_mirror
  - relation:状态沿路径累积, state_accumulates_along_path
  - condition:穿框换色, recolor_on_pass

### docstring

```text
从带帽起点发射一条光线，穿过空心框就换成框色，撞上对角镜就转向，画出分段变色的完整光路。

输入结构:
- 背景网格上有一枚起点像素，旁边贴着指明初始方向的两像素同色帽。
- 路径沿线分布若干颜色互不相同的一格厚空心矩形框，光线总是垂直穿过框壁、从内部穿出对壁。
- 路径上还可能有由两枚对角相邻灰像素构成的对角镜，其对角走向即镜面方向；镜与框不重叠。

规则:
- 从起点沿帽方向逐格延伸光线，初始颜色为起点色。
- 每当光线穿入一个框（越过框壁进入内部）后，其后所有线段改用该框的颜色，直到再次换框。
- 遇到灰镜按光学反射折转 90 度继续延伸；光线到达网格边缘为止。
- 框壁、镜、起点与帽保持原样，光线只画在背景格上。

关键洞察:
- 框不是障碍也不是填充目标，而是串联的染色滤镜；输出每一段的颜色记录的是
  "最近穿过哪个框"这一路径历史状态，镜只改方向不改状态。
```
</new_puzzle>

    6. Randomly assign src, dst, odd to column positions 0, 1, 2.
    7. Assemble input grid: stack bands with 1-row bg separators, tile columns at cols [0:2], [3:5], [7:9].
    8. Assemble output grid: stack output tiles with 1-row bg separators, width = 2.
    9. Validate: solver produces exactly 1 unambiguous candidate per band.

## 实现要求

1. `main(grid)` 必须实现新题描述中的确定性转换规则，不能只识别 `generate_input()` 的固定模板。禁止不同的input网格输出相同的output网格。
2. `generate_input()` 必须随机生成多样样例，不能固定死。随机维度应覆盖：网格大小、对象数量、位置、颜色、方向、形状参数或关键分支。注意若描述中存在若干，需实现而不是只有单个，包括object或者对应关系等等。且若涉及到最短路径，则输入网格中必涉及到多条路径，对选择造成干扰。

6. 若规则有多个分支，生成器不能长期固定成一个分支；应让分支在随机样例中合理出现。分支概率不必平均——难以发现的隐蔽分支（如少数情况下才触发的特殊规则）应适当提高出现概率，确保在 3 个训练示例中至少出现一次，否则求解者无法归纳该规则。对于颜色映射类规则，确保 2 个左右的示例即可覆盖所有映射关系（每种颜色→颜色的映射至少在某个示例中出现过）。
