### docstring

```text
一句话总述：
多条灰色满行/满列候选轴中只有一条是图案的真对称轴，删除假轴并用真轴的镜像修复所有被轴条压住的格子。

输入结构：
- 一幅多色图案上叠画着若干条一格宽的灰色满行条与满列条（候选轴），灰色不在图案本体中出现。
- 把全部灰条覆盖的格子视为未知后，图案恰好关于其中一条灰条严格镜像对称（不含轴上格），
  关于其余每条灰条都存在可见的违例。
- 候选轴的摆放保证：任何被压住格子的镜像格可见，或可经对称传递链最终由可见格推出。

规则：
- 逐条检验候选轴：把所有灰条格视为未知，判断图案是否关于该条严格对称。
- 保留唯一通过检验的真轴条；其余假轴条全部删除。
- 被假轴压住的每个格子，用它关于真轴的镜像位置的颜色恢复；
  镜像位置同被压住时，沿对称关系传递直至由可见格定值。

关键洞察：
- 灰条既是候选答案又是遮挡噪声：判定对称时必须先把包括真轴在内的所有灰条都当作缺失，
  选出真轴后又要反过来用它把假轴留下的空洞补全——同一批灰条先后扮演
  "待检验的假设"与"待修复的破坏"两个角色，顺序颠倒任何一步都无法完成。
```

  output: canvas-sized grid; main_color everywhere except teal stamp pasted at each teal macro-cell position (RED pixels in stamp become main_color)

generation_strategy:
  approach: output-first

    6. Pick cell_size in {1, 2}; build pattern (macro_h*cell_size x macro_w*cell_size) where each cell block is uniform TEAL or main_color per selector
    7. Build canvas as solid main_color rectangle matching output dims
    8. Assemble input grid: place control at ~(1,1), pattern 1 col to its right (same top row), canvas below both with 1-row gap, pad with BLACK border

## 实现要求

1. `main(grid)` 必须实现新题描述中的确定性转换规则，不能只识别 `generate_input()` 的固定模板。禁止不同的input网格输出相同的output网格。
2. `generate_input()` 必须随机生成多样样例，不能固定死。随机维度应覆盖：网格大小、对象数量、位置、颜色、方向、形状参数或关键分支。注意若描述中存在若干，需实现而不是只有单个，包括object或者对应关系等等。且若涉及到最短路径，则输入网格中必涉及到多条路径，对选择造成干扰。
3. 生成器必须保证输入满足 `main()` 的隐式假设：对象不重叠、不越界、特殊标记唯一或可区分、匹配关系无歧义、关键分支出现概率相同。
4. 禁止把 ARC 颜色 id 、亮度、拼写等当作人类不可见的数值语义参与排序、大小比较或隐藏映射。颜色变化必须有可见结构线索。注意颜色亮度、拼写等也是不可见信息，若描述中出现违规的颜色id或者亮度，可自行使用少量的固定颜色替代，但注意生成时要在三个以内输入输出网格中对所有变换100%覆盖度。
5. 输出样例要视觉清晰，人类必须能从输入输出对中肉眼辨认出规律。具体要求：避免对象粘连、覆盖关系混乱、同一像素多重语义；不同逻辑步骤产生的结果不要大面积层叠在一起导致无法分辨哪个颜色属于哪个步骤；输入中各元素之间保持足够间距，输出中新增的标记/填充/路径等应与背景和已有元素在颜色上有明显区分；若规则涉及多层叠加，生成时控制对象密度和尺寸，确保叠加区域只占少数像素而非铺满整个网格。
6. 若规则有多个分支，生成器不能长期固定成一个分支；应让分支在随机样例中合理出现。分支概率不必平均——难以发现的隐蔽分支（如少数情况下才触发的特殊规则）应适当提高出现概率，确保在 3 个训练示例中至少出现一次，否则求解者无法归纳该规则。对于颜色映射类规则，确保 2 个左右的示例即可覆盖所有映射关系（每种颜色→颜色的映射至少在某个示例中出现过）。
