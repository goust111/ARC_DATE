```text
在所有从未画出的候选光路中，只把能将两个红色方块连成一体的那条唯一光链显影到输出上。

输入结构
- 黑色背景网格，含两个相距较远的 2×2 红色方块。
- 若干蓝色像素两两处于同一对角线上，构成候选连线的端点对。
- 若干品红触发像素散布，其中一部分恰好位于某条候选对角线段的路径上。

规则
- 每对对角对齐的蓝色像素定义一条候选对角线段（输入中不画出）。
- 若品红像素位于某候选线段上，则以它为分束点，向与该线段垂直的两个对角方向各延伸一条品红候选射线，直至网格边界或红方块。
- 全部候选线段与候选射线按八连通构成一张接触图，其中恰有一条由若干段依次接触构成的链使两个红方块连通。
- 输出仅绘制这条链上的线段（蓝色）与射线（品红色），其余候选一律不画；红方块与背景保持不变。

关键洞察
- 桥梁在输入中并不存在，必须先在脑中生成全部候选光路，再用"两红块是否连通"这一判定反向筛掉所有未被实现的候选；不在成功链上的分束点与端点对全是诱饵。
```

```yaml
    ensures: no other color pair satisfies the cross-product condition
  uniqueness: exactly one pair satisfies pixels == active_rows * active_cols with 0 < active < grid_size

generation_strategy:
  approach: output-first
  steps:
    - Choose N (3-4), block_size (3-5), internal_sep (1-3), border_top/bottom (>=internal_sep, 2-5)
    - Pick 4 distinct colors; assign 2 as target_pair (bg+fg), 2+ as filler
    - Build the output (N*block_size square): fill with bg, draw a 1-pixel-wide connected fg shape spanning all block-rows and block-cols
    - Construct input grid by inserting separator rows/cols of width internal_sep between block groups, plus border padding
    - Fill all separator cells (sep_row x any_col UNION any_row x sep_col) with random mix of filler colors
    - Verify uniqueness: confirm no other pair of input colors satisfies the cross-product condition (guaranteed by construction since filler colors span all rows/cols via separators)
```
</generation_spec>
