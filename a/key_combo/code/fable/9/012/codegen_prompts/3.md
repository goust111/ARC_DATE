## 3. 角括号里长出的矩形

### docstring

```text
把成对的同色角括号按其开口姿态补全为从未画出的实心矩形或空心框，重叠处按"面积小者盖在上层"叠放。

输入结构：
- 背景上散布若干 L 形角括号；除少数干扰外，每种颜色恰有两个括号，
  且这两个括号的拐角互为某个矩形的一对对角。
- 同色括号对有两种姿态：两括号开口相向（都朝向矩形内部），
  或开口相背（都朝向矩形外部）；两种姿态在示例中都会出现。
- 不同颜色括号对所暗示的矩形两两之间存在重叠；各矩形面积互不相同。
- 另有一到两个找不到同色搭档的孤立角括号作为干扰。

规则：
- 将每对同色角括号视为一个矩形的两个对角：开口相向的补全为该色实心矩形，
  开口相背的补全为该色一格厚的空心框（内部保持透出下层）。
- 按矩形面积从大到小依次绘制到背景画布上，面积小的后画、盖在上层；
  空心框只遮盖其边框经过的格子，框内区域露出更早画下的内容。
- 找不到搭档的孤立括号原样保留在最终画面上。

关键洞察：
- 画面里从未出现任何完整矩形——括号既是矩形的生成元，其开口姿态又是产物形态的编码：
  相拥者实心、相背者镂空；重叠区域的归属由面积排序与实空形态共同决定，
  必须先"想象出"全部矩形并读出各自的姿态，才能算出每一格最终露出的颜色。
```
