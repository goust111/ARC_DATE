## 新题 1：孔洞编码的角落位移

**组合逻辑**：[计数·背景孔洞](已有) → [复制·角落对象](创新：目标角由孔洞数参数化，不再固定为"下一角")

**来源原语**：
- 计数(op), 背景孔洞(obj), 孔洞数量唯一(cond) ← 358ba94e
- 复制(op), 角落对象(obj), 接触两边缘(rel), 顺时针到下一角(cond), 忽略干扰项(cond) ← bc93ec48

**依赖链**：孔洞计数产生整数 h，该整数直接参数化角落复制的目标位置（顺时针第 h 个角落）。删除计数则无法确定目标角；删除角落识别则无法确定搬移对象。

将锚定在角落的前景块按其内部孔洞数搬移到顺时针方向第 h 个角落，忽略非角落干扰块。

**输入结构**：
- 网格约 15x15，黑(0)背景。
- 2-4 个单色 4-连通前景块分别锚定在不同网格角落——每块的边界框同时紧贴该角的两条相邻边缘。每块前景像素数 8-12，边界框 5x5。
- 每块 5x5 边界框内部的背景像素即"孔洞"，孔洞数 h 在 {1, 2, 3} 中且各块互不相同。不同示例中同类对象的具体像素排布不同，但边界框始终 5x5。
- 网格中可能存在 1-2 个不触及任何角落的干扰前景块（边界框至多接触一条边缘），它们保持原位不参与搬移。
- 生成约束：任意两个角落对象搬移后的目标角不重合。

**规则**：
1. 识别角落对象：边界框同时触及网格两条相邻边缘的 4-连通前景块。其余前景块为干扰项，保持不动。
2. 对每个角落对象，计算其 5x5 边界框内的背景像素数量 h（1 <= h <= 3）。
3. 将该对象搬移到当前角落顺时针方向第 h 个角落（h=1 下一角，h=2 对角，h=3 前一角）。搬移时保持像素相对于边界框的排布不变，将边界框对齐到目标角的两条边缘。
4. 原位置的所有像素恢复为黑(0)背景。
5. 干扰块和已经是背景的区域保持不变。

**关键洞察**：孔洞数不是用于筛选异常值（如 358ba94e 中找唯一孔洞数的块），而是编码了搬移距离；需要对比多个示例才能归纳出"h 即顺时针步数"的映射，而非固定"总是移到下一角"。
