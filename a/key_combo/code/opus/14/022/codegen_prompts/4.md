## 新题 4：标记定向投射与距离优先叠加

**组合逻辑**：[投影·接触边决定方向](创新：标记数量编码投射距离) + [透明叠加·图层优先级](创新：投射距离短者优先)

**来源原语**：
- 投影(op), 标记像素(obj), 小方块(obj), 接触边决定投影(rel), 颜色决定投影深度(cond) ← e39e9282
- 透明叠加(op), 图层优先级(rel), 底层最优先(cond) ← 6a11f6da
- 平移(op), 无重叠间距(rel) ← 5521c0d9

**依赖链**：标记的位置决定投射方向，标记的数量决定投射距离，两者共同确定目标位置。当多个投射结果空间重叠时，距离优先级规则决定最终颜色。方向→距离→冲突解决三层逻辑缺一不可。

将带有侧边标记的小方块沿标记指示方向投射，投射距离等于标记像素数，重叠时距离短的方块覆盖距离长的。

**输入结构**：
- 网格约 15x15，黑(0)背景。
- 3-4 个实心 3x3 小方块，每个方块使用不同的单一前景色（如蓝(1)、绿(3)、黄(4)、橙(7)）。
- 每个方块的恰好一侧（上、下、左或右）紧邻 1-3 个栗(9)标记像素，排成一行或一列紧贴该侧。标记像素数量在不同方块之间可以不同。
- 生成约束：方块初始位置互不相邻（间距至少 2 像素）；投射后至少存在一对方块的目标区域有重叠，以测试优先级规则。

**规则**：
1. 对每个方块，确定投射方向：栗(9)标记像素在方块的哪一侧，方块就向该侧的反方向投射（标记在上方 → 向下投射，标记在右侧 → 向左投射，以此类推）。
2. 投射距离 = 该方块侧边的栗(9)标记像素数量（1-3 格）。方块整体平移相应距离。
3. 清除所有方块和标记的原始位置（恢复为背景）。
4. 在目标位置绘制各方块。若两个方块的目标区域重叠，投射距离较短的方块优先（其像素覆盖在上层）。投射距离相同时，行坐标更小的方块优先。

**关键洞察**：标记不仅编码方向（哪一侧），还编码距离（几个像素），且投射方向与标记位置相反——这一"反向"规则需要对比多个示例才能确认。距离优先级更是隐蔽规则：仅在重叠发生时才可观察。
