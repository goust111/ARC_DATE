## 新题 7：孔洞数定包络尺寸与标记色定包络颜色

**组合逻辑**：[计数·背景孔洞](已有) → 包络半径 + [标记像素颜色](已有) → 包络颜色 ⇒ [包络生成](创新：尺寸与颜色由两个独立属性分别决定)

**来源原语**：
- 计数(op), 前景块(obj), 背景孔洞(obj), 孔洞数量唯一(cond) ← 358ba94e
- 包络生成(op), 菱形轮廓(obj), 中心对称(rel), 逐步收缩(cond) ← c97c0139
- 标记像素(obj), 接触边决定投影(rel) ← e39e9282
- 擦除(op) ← 009d5c81

**依赖链**：孔洞数独立决定包络半径，标记颜色独立决定包络颜色。两个属性分属不同来源（块内部结构 vs. 外部标记），缺少任一属性都无法完全确定输出——删除孔洞计数则包络大小未知，删除标记颜色则包络颜色未知。

围绕带孔洞的前景块生成正方形包络框，框的厚度等于孔洞数，框的颜色由邻近标记像素的颜色决定。

**输入结构**：
- 网格约 20x20，黑(0)背景。
- 3-4 个灰(5) 4-连通前景块，每块边界框 5x5，块有实心灰色外壳但内部包含 1-3 个背景孔洞（各块孔洞数互不相同）。不同示例中块的具体像素排布不同。
- 每块附近（边界框外 1-2 像素处）有一个孤立的非灰非黑像素（颜色为蓝(1)、红(2)或绿(3)之一），作为该块的颜色标记。每块恰好关联一个标记（取最近的标记，各标记与各块一一对应）。
- 各块之间间距足够大（边界框间距至少 8 像素），使最大包络（3 层厚）也不会重叠。
- 生成约束：标记与最近块的距离唯一确定配对（无歧义）。

**规则**：
1. 对每个灰(5)前景块，计算其 5x5 边界框内的背景像素数 h（1 <= h <= 3）。
2. 将每个标记像素与距离其边界框中心最近的前景块配对。
3. 以该块的 5x5 边界框为核心，向外扩展 h 层正方形边框（第 1 层为 7x7 的最外圈像素，第 2 层为 9x9 的最外圈像素，以此类推）。每层边框颜色 = 配对标记像素的颜色。仅在背景像素上绘制边框。
4. 擦除所有标记像素（恢复为背景）。原灰色前景块保持不变。

**关键洞察**：包络的两个参数（尺寸和颜色）由两个完全独立的信息源编码——尺寸来自块的内在拓扑属性（孔洞数），颜色来自外部标记的色彩。求解者必须分别发现两条独立规则并同时应用，任一规则的缺失都会导致输出不确定。
