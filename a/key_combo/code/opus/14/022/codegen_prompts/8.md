## 新题 8：交替旋转的周期平铺

**组合逻辑**：[平铺·最小周期检测](已有) + [旋转·整图半周旋转](创新：180 度旋转仅施加于偶数编号的周期副本，奇数副本不变)

**来源原语**：
- 平铺(op), 补全(op), 最小周期单元(obj), 局部图案(obj), 列周期重复(rel), 最小周期扩展(cond) ← d8c310e9
- 旋转(op), 画布(obj), 整图半周旋转(cond) ← 6150a2bd

**依赖链**：周期检测确定基本瓦片，旋转规则决定每个副本的朝向。删除周期检测则无法确定瓦片宽度；删除旋转规则则退化为简单平铺。两者耦合点在于：瓦片内容和旋转状态共同决定每一列的最终像素值。

检测最小列周期，用交替的正向和 180 度旋转副本铺满网格宽度。

**输入结构**：
- 网格约 7x20，黑(0)背景上有单一前景色（如蓝(1)）绘制的图案。
- 图案从左边缘开始，占据前 2P 列（P 为最小列周期，3 <= P <= 5），其中前 P 列和后 P 列的内容呈 180 度旋转关系。网格右侧剩余列为全背景。
- 图案在 P 宽度内不具有 180 度旋转对称性（否则交替规则不可观察）。
- 不同示例中，P 值和图案内容不同。

**规则**：
1. 检测最小列周期 P：从可见的前 2P 列中推断——前 P 列为基本瓦片 T，后 P 列为 T 的 180 度旋转。
2. 从左到右用交替副本填充整个网格宽度：第 1 个副本（列 0 至 P-1）为 T；第 2 个副本（列 P 至 2P-1）为 T 旋转 180 度；第 3 个副本为 T；第 4 个为旋转 T；以此类推。
3. 若最后一个副本超出网格宽度，截断到网格右边缘。

**关键洞察**：与简单平铺（d8c310e9）不同，这里的"周期"实际为 2P——但基本构造单元仍是 P，只是奇偶副本的朝向不同。若求解者仅检测表观周期 2P 并简单重复，在 P 非对称时可以得到相同结果，但更深层的理解是交替旋转。需要对比多个示例（不同 P 值）来排除"纯 2P 周期"的假说。
