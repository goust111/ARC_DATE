## 新题 6：像素膨胀引发连通合并，合并后内部区域重涂

**组合逻辑**：[像素放大/pixel_expand](创新：仅膨胀孤立像素为 2x2 块，不做全局缩放) → [连通分量/connected_component + 邻域全包含/full_neighborhood_inside_component](膨胀后重新检测连通分量及内部像素) → [重涂色/recolor + 标记在分量内/marker_inside_component](内部像素重涂为该分量中标记像素的颜色)

**来源原语**：pixel_expand（参考题 46f33fce）、connected_component + full_neighborhood_inside_component + singleton_marker + solid_interior + recolor（参考题 09c534e7）

**依赖链**：像素膨胀改变连通拓扑 → 新的连通分量可能由原先不相邻的元素合并而成 → 在新分量中检测 3x3 邻域全包含的内部像素 → 内部像素的重涂颜色来自该分量中唯一的标记像素。膨胀前后拓扑不同是核心——不膨胀则无合并，无合并则无内部区域。

孤立像素膨胀为 2x2 块后可能与邻近簇合并为更大连通分量，合并后产生的内部像素被重涂为该分量标记像素的颜色。

**输入结构**：黑(0)背景网格，约 12x12。包含两类前景元素：(1) 若干灰(5)孤立单像素，彼此不相邻；(2) 若干小型 4-连通灰(5)簇（每个 3-5 像素，形状不规则），每个簇内部嵌入恰好一个非灰色的标记像素（颜色取自红(2)、蓝(1)、绿(3)、黄(4），不同簇的标记颜色不同）。生成约束：部分孤立像素与某个簇的边界框距离恰好为 1（膨胀后会合并），部分孤立像素远离所有簇（膨胀后仍孤立）；每个簇至多与膨胀后的一个孤立像素合并；合并后的分量至少有一个像素满足 3x3 邻域全在分量内。

**规则**：
1. 识别所有灰(5)孤立单像素（8-邻域内无其他非背景像素的前景像素）。
2. 将每个孤立像素膨胀为 2x2 灰(5)块：以原像素为左上角，向右和向下各扩展一格。膨胀像素仅覆盖背景格，不覆盖已有前景像素。
3. 膨胀完成后，重新计算所有非背景像素的 4-连通分量。原先不相邻的孤立像素（现为 2x2 块）可能与邻近的簇合并为同一分量。
4. 对每个包含标记像素的连通分量，找出所有 3x3 邻域完全被该分量包含的像素（即该像素的 8 个邻居全部属于同一分量）。这些像素为该分量的"内部像素"。
5. 将内部像素重涂为该分量中标记像素的颜色。标记像素自身保持原色。所有非内部的分量像素保持灰(5)。
6. 膨胀后仍孤立（未与任何含标记的簇合并）的 2x2 块保持灰(5)不变。

**关键洞察**：膨胀本身不产生视觉上有意义的变化，但它改变了连通拓扑——原本不相邻的元素合并后才可能产生 3x3 全包含的内部区域。重涂的范围和颜色都取决于膨胀引发的合并结果，而非原始布局。
