## 新题 7：形状循环变换解码网格分块地址

**组合逻辑**：[形状变换 shape_transform](已有) + [裁剪 crop](已有) + [重涂色 recolor](已有) + [传输 transmit](创新：线路传递的不是形状本身，而是颜色信息作为重涂参数)

**来源原语**：形状变换/形状循环映射/令牌(a47bf94d)、传输/端点配对/线路网络(a47bf94d)、裁剪/网格分块/取角落分块(5bd6f4ac)、重涂色(48634b99)

**依赖链**：令牌形状循环变换 → 变换后的形状类型作为地址索引 → 从网格分块中裁剪对应区块 → 线路终端的颜色决定裁剪区块的重涂色。四步中任一步缺失或顺序错误则无法得到正确输出。

一句话总结：将 3x3 令牌做一步形状循环变换，用变换后的形状类型选定 3x3 区块阵列中的对应区块并裁剪输出，区块中的前景色改为线路另一端指示像素的颜色。

**输入结构**：约 19x19 的网格，背景为黑(0)。网格主体为一个 3x3 排列的区块阵列，每个区块 5x5，区块之间由 1 像素宽的灰(5)分隔线隔开（阵列整体占 17x17，分隔线在第 5、11 列和第 5、11 行）。每个 5x5 区块内包含一个由灰(5)像素组成的小图案（4-连通，3-8 像素，各区块图案不同且形状不规则）。在网格主体右侧或下方的空白区域，放置一个 3x3 令牌——三种形状之一：实心块（全部 9 个像素填充）、X 形（4 个角像素 + 中心像素共 5 像素）、或菱形（中心 + 上下左右 4 个像素共 5 像素），令牌颜色为栗(9)。从令牌中心出发，一条 1 像素宽的栗(9)线路（水平或垂直直线，或一次直角折线）连接到一个孤立的单像素指示像素，该指示像素的颜色从红(2)、绿(3)、蓝(1)、黄(4)中选取。生成约束：令牌形状在不同示例中不同（以便求解者归纳形状→位置映射）；指示像素颜色在不同示例中可能不同。

**规则**：
1. 对令牌执行一步形状循环变换：实心块 → 菱形，菱形 → X 形，X 形 → 实心块。
2. 变换后的形状类型映射到 3x3 区块阵列中的位置：菱形 → 第 0 行第 2 列（右上角区块），X 形 → 第 1 行第 1 列（正中央区块），实心块 → 第 2 行第 0 列（左下角区块）。
3. 裁剪出对应位置的 5x5 区块（仅含区块内容，不含分隔线）。
4. 沿令牌的栗(9)线路找到另一端的指示像素，读取其颜色。
5. 将裁剪出的 5x5 区块中所有灰(5)前景像素重涂为指示像素的颜色，黑(0)背景像素保持不变。
6. 输出为重涂后的 5x5 区块。

**关键洞察**：令牌的形状不是直接输出的视觉内容，而是经过一步循环变换后充当"地址"——它指定去九宫格的哪个区块提取数据。令牌本身在输出中不出现，线路仅传递颜色信息用于重涂。形状的含义是间接的（需先变换再解码为位置），这与参考题中令牌直接作为视觉输出物的用法截然不同。
