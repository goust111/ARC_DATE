## 新题 8：控制点计数三角与顶行色序循环填充

**组合逻辑**：[计数/counting + 三角区域](创新：计数决定三角形状的边界，而非填充色) + [平铺/tiling + 顶行色序](创新：循环色序填充三角内部，而非矩形区域)

**来源原语**：计数、角落控制点(corner_control)、三角区域(triangle_region)、计数决定尺寸(count_determines_size)、最大分量保留(largest_component_kept) 来自 902510d5；填充(fill)、平铺(tile)、顶行色序(top_row_color_sequence)、分隔行(separator_row)、分隔下循环填色(below_separator_cycle_fill) 来自 bd4472b8

**依赖链**：顶行色序提供填充模板（数据源 A）→ 控制点计数决定三角边长（数据源 B）→ 角落像素决定三角方位 → 三角边界裁剪循环填充结果。A 和 B 独立提取，在几何填充时汇合。

计算散落控制点数量作为三角形边长，以角落像素定位三角形，用顶行色序循环填满三角形内部。

**输入结构**：
- 网格约 12x12，背景黑(0)。
- 顶行（第 0 行）包含 2~4 种非黑颜色的像素序列（如蓝(1)、红(2)、绿(3)交替），形成一个色序模板。顶行中无黑(0)像素。
- 第 1 行为全灰(5)分隔行。
- 第 2 行及以下为工作区域，背景黑(0)。
- 工作区域中，恰好一个网格角落（左下、右下之一，因顶行被色序和分隔行占据，仅考虑下方两角）有一个栗(9)像素，指示三角形顶点所在角。
- 工作区域中散落 3~10 个同色单像素控制点，颜色为橙(7)。橙(7)不出现在顶行或分隔行。
- 生成约束：控制点数量不超过工作区域的行数和列数中的较小值。

**规则**：
1. 提取顶行的色序模板 P = [c0, c1, c2, ...]，长度为 L。
2. 计算工作区域中橙(7)控制点的数量 S。
3. 找到栗(9)角落像素所在的角，以该角为直角顶点定义一个边长为 S 的直角等腰三角形。三角形的两条直角边沿网格边缘延伸。三角形内部定义为：像素到角落所在行边缘的距离 dr 和到角落所在列边缘的距离 dc 满足 dr + dc < S 的所有工作区域单元格。
4. 对三角形内部的每个单元格 (r, c)，按行优先顺序编号 i（从 0 开始，i 按照先行后列递增），将其颜色设为 P[i mod L]——即用顶行色序循环填充。
5. 三角形外部的工作区域保持黑(0)。
6. 栗(9)角落像素和橙(7)控制点在输出中均擦除为黑(0)。
7. 顶行色序和灰(5)分隔行在输出中保持不变。

**关键洞察**：三角形的边界和填充内容来自两个完全无关的信息源——边长来自控制点计数，填充色序来自顶行模板。单独看三角形看不出色序从何而来，单独看顶行看不出它被用于填充什么形状。必须跨区域关联才能完整理解规则。
