## 新题 6：障碍折线路由驱动的列选择性反转

**组合逻辑**：[射线延伸/ray_extend + 障碍决定转向](创新：路由不绘制彩色路径，而是生成列激活掩码) + [反转/invert + 逐行独立](创新：反转仅作用于路由激活的列，而非整行)

**来源原语**：射线延伸(ray_extend)、边缘标记(edge_marker)、障碍像素(obstacle_pixel)、障碍决定转向(obstacle_turn) 来自 891232d6；反转(invert)、逐行独立(row_independent)、主色与背景互换(native_bg_swap) 来自 2de01db2

**依赖链**：路由生成列激活掩码（空间分析） → 逐行独立的主色检测（颜色分析） → 掩码与主色联合决定每个像素的输出颜色。路由分析和颜色分析完全独立，在最终着色时才汇合。

从底边标记向上射线延伸，遇障碍右移一列后继续上行，路径经过的(行,列)形成激活集合；每行中仅激活列的像素执行主色/背景反转。

**输入结构**：
- 网格约 14x14，背景黑(0)。
- 每行包含若干非黑像素，每行有一种"主色"——该行中出现次数最多的非黑颜色。不同行的主色可以不同（如某行主色蓝(1)、另一行主色绿(3)等）。行内可能有少量其他非黑色的"干扰像素"。
- 底边（最后一行）有 1~2 个红(2)标记像素，它们同时也属于该行内容的一部分。
- 网格中散布 2~5 个橙(7)像素作为障碍。障碍不在底行。
- 生成约束：每条路由从底边标记出发向上至少经过一个障碍；路由右移后不会碰到同一行的第二个障碍；路由不会超出网格右边界。

**规则**：
1. 从每个底边红(2)标记像素出发，沿当前列逐行向上前进，构建一条路径：
   - 检查当前列中上一行的像素：若不是橙(7)障碍，则前进到上一行同列，将该 (行, 列) 加入激活集合。
   - 若上一行同列是橙(7)障碍：不进入障碍单元格，将当前列号 +1（右移一列），然后从障碍所在行开始继续向上前进，将 (障碍所在行, 新列) 加入激活集合。
   - 到达第 0 行时停止（第 0 行对应的列也加入激活集合）。
2. 合并所有路由的激活集合。
3. 对每行独立确定主色：该行中出现次数最多的非黑颜色；若出现次数并列，取在该行中最先（最左）出现的颜色。
4. 对每行的每个像素：
   - 该像素所在列在激活集合中：执行反转——主色像素变为黑(0)，非主色像素（包括黑(0)和干扰色）变为该行主色。
   - 该像素所在列不在激活集合中：保持不变。
5. 橙(7)障碍像素在输出中始终保持橙(7)，不参与反转。

**关键洞察**：路由是一条折线，每遇到障碍就右移一列——但路由本身在输出中不可见，它只充当"哪些列参与反转"的隐性控制。求解者必须同时推断路由规则（向上走、遇障碍右移）和反转规则（主色与背景互换），并理解二者通过列激活关系耦合。单看反转效果无法解释为何某些列被反转而另一些没有，必须发现路由的存在。
