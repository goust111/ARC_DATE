## 新题 4：标记列传播与计数三角楔形裁剪

**组合逻辑**：[传播/propagate + 逐列填充/column_fill](已有) + [计数/counting](创新：散落控制点的数量决定楔形几何尺寸) + [擦除/erase](创新：三角楔形边界裁剪传播结果)

**来源原语**：传播、逐列填充、底行标记选定列(bottom_marker_selects_column)、纵向色带(vertical_color_band) 来自 17b80ad2；计数、角落控制点(corner_control)、三角区域(triangle_region)、计数决定尺寸(count_determines_size) 来自 902510d5

**依赖链**：底行标记选定列 → 列传播生成纵向色带（中间结果 A）；散落控制点计数 → 确定三角边长（中间结果 B）；A 和 B 独立计算后联合应用：楔形裁剪色带。两条支线并行且最终汇合。

在标记列中向上传播颜色形成纵向色带，同时计算散落控制点的数量作为三角楔形的边长，最终只保留楔形区域内的色带像素。

**输入结构**：
- 网格约 15x15，背景黑(0)。
- 底行包含 2~4 个非黑标记像素（颜色各异，如蓝(1)、绿(3)），标记对应的列。
- 在每个标记列中，底行标记之上散布 1~3 个非黑像素（颜色可与底行标记不同），这些像素是色带的端点。
- 网格四角中恰好一个角落有一个非黑像素（栗(9)），指示楔形的顶点角。该颜色不在任何标记列中出现。
- 在网格其余区域（非标记列、非角落）散落 3~8 个同色单像素控制点，颜色为灰(5)。灰(5)不在标记列或角落中出现。
- 生成约束：控制点数量不超过网格边长；楔形区域与至少两个标记列有交集。

**规则**：
1. 识别底行的标记像素，确定标记列。
2. 在每个标记列中，从底行向上扫描，记住最近遇到的非黑颜色。将该列中每个黑(0)像素替换为记住的颜色，形成纵向色带。遇到新的非黑色时更新记忆。非标记列不做任何传播。
3. 计算所有灰(5)控制点的数量 S。
4. 找到栗(9)角落像素所在的角（左上、右上、左下、右下之一），以该角为顶点定义一个直角三角形区域：三角形的两条直角边分别沿该角所在的行边缘和列边缘延伸，直角边长度均为 S。
5. 三角形内部定义为：像素到该角所在行边缘的距离 dr 和到该角所在列边缘的距离 dc 满足 dr + dc < S 的所有单元格。
6. 输出网格中，仅保留三角形区域内的传播结果（色带像素）；三角形区域内的非标记列像素保持黑(0)。
7. 三角形区域外的所有像素设为黑(0)（包括原本的色带、标记、控制点等）。
8. 栗(9)角落像素和灰(5)控制点在输出中均擦除为黑(0)。

**关键洞察**：传播和计数是两个完全独立的分析——传播只关心标记列内部的颜色序列，计数只关心散落的灰点。两者的输出在空间裁剪这一步才汇合。单个示例中可能恰好所有色带都在三角形内，使裁剪不可见，必须对比多个示例才能发现三角形边界的存在及其与控制点数量的关系。
