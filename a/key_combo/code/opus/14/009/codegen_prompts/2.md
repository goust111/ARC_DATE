## 新题 2：框内标记计数驱动模板平铺次数

**组合逻辑**：[计数](创新：计数结果不渲染为视觉计数器，而是参数化另一操作的重复次数) + [平铺](创新：重复次数由计数动态决定，方向由模板与框的邻接位置决定)

**来源原语**：计数(c8b7cc0f)、框内包含(c8b7cc0f)、忽略干扰项(c8b7cc0f)、矩形框(c8b7cc0f)、标记像素(c8b7cc0f)、平铺(e8dc4411)、邻接触碰(e8dc4411)、模板(e8dc4411)

**依赖链**：计数框内标记 → 得到数值 N → N 决定模板向外平铺的次数；同时，模板与框的邻接侧决定平铺方向。计数和邻接分析缺一不可：没有计数则不知铺多少份，没有邻接分析则不知往哪铺。

统计每个矩形框内部的标记像素数量 N，然后将紧贴该框外侧的小模板形状向远离框的方向平铺 N 份。

**输入结构**：约 20x20 的黑(0)背景网格。网格上有 2~4 个橙(7)的 1 像素厚矩形框（内部空间 3x3 到 5x5）。框内散布着若干蓝(1)标记像素（1~5 个），框外也散布着若干蓝(1)干扰像素。每个框的外侧恰好有一个绿(3)的小模板形状（4-连通，2~4 像素的不规则小图形）紧贴框的某一条边（上/下/左/右），即模板中至少有一个像素与该框的外壁 4-相邻。不同框的模板贴靠方向可以不同。生成约束：每个框的模板平铺展开后不超出网格边界，不同框的平铺结果互不重叠。

**规则**：
1. 对每个橙(7)矩形框，统计严格位于框内部的蓝(1)像素数量 N（框外的蓝像素是干扰项，忽略）。
2. 确定该框外侧绿(3)模板贴靠的是哪一条边（上/下/左/右）。
3. 以模板自身的边界框尺寸为步长，沿远离框的方向（贴靠上边则向上，贴靠右边则向右，依此类推）依次放置 N 个模板的平移副本。第一个副本紧邻原始模板，第二个紧邻第一个副本，以此类推。
4. 所有副本使用绿(3)绘制，仅绘制模板形状中的非背景像素。
5. 原始框、框内标记、原始模板和所有干扰像素均保持不变。

**关键洞察**：框内标记数不是被渲染成计数图案（如 3x3 计数格），而是直接驱动了一个空间操作的重复参数。框外的同色标记是干扰项——必须对比多个示例才能确认"只计框内"这一规则。模板贴靠的边暗示了平铺方向，这一空间关系在任何源题中均不存在。
