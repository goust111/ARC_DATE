## 新题 3：枢轴旋转引发合并后按连通性重涂色

**组合逻辑**：[旋转/半周](原有) → [连通分量分析](创新：旋转后产生的连通性合并是涌现效应) → [重涂色](创新：颜色由合并后的连通分量成分决定)

**来源原语**：旋转(90347967)、枢轴像素(90347967)、点对称(90347967)、绕枢轴半周旋转(90347967)、重涂色(67385a82)、连通分量(67385a82)、面积比较(67385a82)

**依赖链**：180 度旋转改变所有形状的空间位置 → 原本分离的形状可能在新位置上 4-连通合并 → 合并后的连通分量被重涂色为品红(6)，未合并的保持原色。旋转是产生合并的唯一途径，合并判定依赖旋转后的位置，重涂色依赖合并判定——三步紧密耦合且存在涌现效应。

将所有前景形状绕灰色枢轴像素做 180 度点反射；反射后，因空间重排而与其他形状 4-连通合并的连通分量被重涂色为品红(6)，未发生合并的形状保持原色。

**输入结构**：约 15x15 的黑(0)背景网格。一个灰(5)枢轴像素位于网格的非中心位置。4~6 个小型前景形状散布于网格上，每个形状是单色 4-连通区域（2~5 像素），使用蓝(1)、红(2)、绿(3)、黄(4)中的不同颜色（每种颜色至多使用一次）。形状之间互不 4-相邻。生成约束：对所有形状做 180 度点反射后，恰好有部分形状在反射后的位置上与其他反射后的形状 4-连通相邻（即合并），其余形状反射后仍然互不相邻。所有反射位置不超出网格边界。同一形状不与自身的反射重叠。

**规则**：
1. 对每个非黑(0)、非灰(5)的前景像素 (r, c)，计算其关于灰(5)枢轴像素 (pr, pc) 的 180 度反射位置：(2*pr - r, 2*pc - c)。
2. 在输出网格中，将反射位置绘制为该像素的原始颜色。原始位置清除为黑(0)。灰(5)枢轴像素保持原位。
3. 在反射后的网格中，计算所有非背景、非枢轴像素的 4-连通分量。
4. 若某连通分量包含来自两个或以上原始形状的像素（即不同颜色的像素在反射后 4-相邻合并），将该连通分量的所有像素重涂色为品红(6)。
5. 若某连通分量的所有像素来自同一个原始形状（同色且反射后未与其他形状合并），保持其原始颜色不变。

**关键洞察**：品红像素标记了旋转后的"碰撞区"。求解者必须先模拟 180 度旋转得到新位置布局，再分析连通性以确定哪些形状合并——这是旋转操作的涌现效应，无法从单个形状的变换中预测。必须对比多个示例才能确认重涂色规则针对的是"跨色合并"而非"面积阈值"。
