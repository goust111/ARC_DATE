## 新题 2：配对围墙洪水擦除

**组合逻辑**：[diagonal_pairing + pair_defines_rect](已有) → [fill](创新：填充矩形作为墙壁而非最终输出) → [flood_fill + inside_outside_partition](已有) → [erase + hit_erases_whole](创新：擦除对象基于洪水可达性而非射线)

**来源原语**：diagonal_pairing / pair_defines_rect（参考题 56ff96f3）、fill（参考题 56ff96f3）、flood_fill / inside_outside_partition / indicator_pixel / wall_boundary（参考题 7491f3cf）、erase（参考题 2f767503）

**依赖链**：同色像素对定义矩形的对角 → 填充矩形形成墙壁结构 → 指示像素发起洪水填充，被墙壁阻挡，将空间分为可达区和不可达区 → 位于可达区内的目标对象被整体擦除。配对关系创造了源题中不存在的围墙拓扑；洪水填充不再用于选择源面板，而是用于决定擦除目标。

**输入结构**：约 14x14 网格，黑(0) 背景。包含以下元素：
- 2~3 种前景色（如蓝(1)、红(2)、绿(3)），每种颜色恰好出现两次，各为孤立单像素——这些是角标记。每对同色像素的位置保证：它们定义的轴对齐矩形互不重叠（矩形边界可以共线但内部不交叉）。
- 一个黄(4) 指示像素（单像素），位于所有矩形围成的区域之外（即从黄色像素出发沿网格边界可到达网格边缘，不穿过任何矩形）。
- 若干橙(7) 目标对象（各 2~5 像素，4-连通），散布在网格中。生成约束：每个橙色对象要么完全在某个矩形围成的内部区域内，要么完全在外部区域内（不横跨墙壁）；至少有一个橙色对象在洪水可达区内，至少有一个在不可达区内。
- 角标记与橙色对象互不接触；黄色指示像素与角标记互不接触。

**规则**：
1. 对每种前景色（蓝(1)、红(2)、绿(3)），取其两个像素的坐标，计算轴对齐矩形的边界框，将该边界框内所有像素填充为该颜色。这些填充矩形构成墙壁。
2. 从黄(4) 指示像素出发，做 4-连通洪水填充，将墙壁像素（任何非黑(0)、非黄(4)、非橙(7) 的像素）视为障碍。所有被洪水到达的像素（含指示像素自身）构成"可达区"。
3. 对于每个橙(7) 目标对象（4-连通分量）：若该对象的所有像素均在可达区内，则将其所有像素重涂为黑(0)（擦除）。若对象有任何像素不在可达区内，则整个对象保留不变。
4. 墙壁（填充矩形）、黄色指示像素、以及未被擦除的橙色对象在输出中保持不变。

**关键洞察**：同色像素对看似是简单标记，实际上它们隐式定义了矩形墙壁，这些墙壁将网格空间分区。求解者必须先发现"配对→矩形→墙壁"这一非显然的构建链，才能理解哪些橙色对象会被擦除。需对比多个示例才能排除"按位置""按颜色"等错误假设，确认擦除取决于洪水可达性。
