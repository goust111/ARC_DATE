## 新题 4：标记距离决定嵌套层叠画序

**组合逻辑**：[complete + nested_rectangle + outer_to_inner](已有) + [distance_mapping + manhattan_distance](创新：距离不用于生成同心环，而用于决定矩形的绘制优先级) → [stacking + conflict_priority](创新：冲突解决不按固定的大-小顺序，而按与标记的距离动态排序)

**来源原语**：complete / nested_rectangle / sparse_rect_layer / outer_to_inner / large_first_small_over（参考题 5751f35e）、distance_mapping / manhattan_distance / marker_pixel（参考题 aaef0977）、stacking / conflict_priority（参考题 03560426）

**依赖链**：稀疏的矩形层被补全为实心矩形 → 标记像素的位置决定了每个矩形的优先级（以矩形中心到标记的曼哈顿距离排序）→ 矩形按距离从远到近依次绘制，近者覆盖远者。标记位置改变则叠画顺序改变，最终可见颜色分布随之改变。距离映射从"生成颜色环"被改造为"决定绘制序"，这是全新的结构关系。

**输入结构**：约 15x15 网格，黑(0) 背景。包含以下元素：
- 3~5 种前景色（如蓝(1)、红(2)、绿(3)、黄(4)、灰(5)），每种颜色有若干散落的像素（3~8 个），这些像素都位于同一个轴对齐矩形的边界框上（不一定覆盖整条边）。这些是稀疏矩形层的采样点。
- 各颜色的边界框面积互不相同（保证无面积并列）。边界框之间存在嵌套或部分重叠关系（不全嵌套，允许部分重叠）。
- 一个橙(7) 标记像素（单像素），位于网格中某处（可以在某个矩形内部，也可以在所有矩形外部）。
- 生成约束：移动标记到不同位置时，至少有一对矩形的距离排序会改变（即距离排序不退化为固定的面积排序）；各颜色的稀疏像素足以唯一确定其矩形边界框（至少标记两条不同的边）。

**规则**：
1. 对每种前景色，取其所有像素的轴对齐边界框作为该颜色的完整矩形。
2. 计算橙(7) 标记像素到每个矩形中心（边界框中心，若为非整数则取四舍五入）的曼哈顿距离。
3. 按距离从大到小的顺序依次绘制矩形（距离最大的最先画，距离最小的最后画，后画覆盖先画）。若两个矩形距离相同，则面积较小者后画（小的覆盖大的）。
4. 橙(7) 标记像素在最终输出中保留（画在最顶层）。
5. 所有矩形外部的区域保持黑(0) 背景。

**关键洞察**：叠画顺序不是由矩形的几何嵌套关系决定，而是由标记像素到每个矩形中心的曼哈顿距离决定。同样的一组矩形，标记在不同位置会产生不同的叠画结果。求解者必须对比多个示例（标记位置不同）才能排除"大的先画""外层先画"等错误假设，发现距离才是排序依据。
