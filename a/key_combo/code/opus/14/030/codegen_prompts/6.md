## 新题 6：洪水分区内逐行局部翻转

**组合逻辑**：[flood_fill + wall_boundary + inside_outside_partition](已有) → [local_reverse + independent_side_reverse](创新：翻转不作用于固定的中心分隔像素两侧，而作用于洪水分区确定的"内部"区域中的每一行)

**来源原语**：flood_fill / wall_boundary / inside_outside_partition / indicator_pixel（参考题 7491f3cf）、local_reverse / center_symmetry / independent_side_reverse / pixel_segment（参考题 833966f4）

**依赖链**：墙壁像素形成封闭边界 → 洪水填充从指示像素出发确定"外部"区域，剩余为"内部"→ 内部区域中每行的非背景像素序列被原地翻转，外部区域不变。洪水分区决定翻转范围，翻转改变内部像素排列。两者共同决定输出，缺一不可。

**输入结构**：约 11x11 网格，黑(0) 背景。包含以下元素：
- 灰(5) 墙壁像素组成一个封闭的不规则环形边界（4-连通环，保证将网格分为内外两个区域）。墙壁不碰触网格边缘（即外部区域与网格边缘相连）。墙壁形状在不同示例中不同（不固定为矩形）。
- 一个黄(4) 指示像素位于墙壁外部（与网格边缘在同一 4-连通分量中）。
- 墙壁内部区域包含若干行的彩色像素图案：各行中有不同颜色的非背景像素（如蓝(1)、红(2)、绿(3) 等），形成在行内有意义的左右排列顺序。内部不同行的非背景像素数量和颜色组合可以不同。
- 墙壁外部区域（除指示像素外）可以有少量装饰性的彩色像素（如橙(7)），用于迷惑。
- 生成约束：内部区域至少有 3 行包含 2 个以上非背景像素（使得翻转有可观测效果）；外部装饰像素（若有）在翻转前后的位置不变（因为它们不在内部区域）。

**规则**：
1. 从黄(4) 指示像素出发，做 4-连通洪水填充，将灰(5) 墙壁像素视为障碍。所有被洪水到达的像素构成"外部区域"。
2. 未被洪水到达、且不是墙壁的像素构成"内部区域"。
3. 对内部区域的每一行独立处理：提取该行中所有属于内部区域的像素位置及其颜色值，将这些颜色值的顺序翻转（左右互换），然后放回原位置。即若该行内部区域像素从左到右的颜色序列为 [A, B, C, D]，则变为 [D, C, B, A]，仍在原来的列位置上。
4. 墙壁像素、指示像素、外部区域的所有像素（含装饰像素）保持不变。

**关键洞察**：外部的装饰像素不受影响——只有墙壁围住的内部像素才被逐行翻转。求解者需先识别墙壁和洪水分区机制（哪些像素算"内部"），再发现内部像素的逐行翻转规则。仅看单个示例可能误以为是全局水平镜像或某种重涂色。
