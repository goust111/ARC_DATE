## 新题 2：双少数蓝图竞争叠加

**组合逻辑**：[缩放](保留) + [透明叠加](创新：叠加对象从面板变为两个竞争的分形蓝图) → 冲突解决使用稀有度优先规则（全新结构关系）

**来源原语**：缩放/scale(来自 b99e7126) + 透明叠加/transparent_overlay(来自 281123b4) + 少数单元/minority_cell(来自 b99e7126) + 多数单元/majority_cell(来自 b99e7126) + 分隔网格/separator_grid(来自 b99e7126) + 自相似/self_similarity(来自 b99e7126) + 图层优先级/layer_priority(来自 281123b4) + 少数图案为蓝图/minority_pattern_as_blueprint(来自 b99e7126)

**依赖链**：识别两种少数单元 → 分别缩放为网格级蓝图 → 蓝图重叠位置需冲突解决 → 少数单元数量更少者优先。若不先完成两个缩放，无法发现重叠；若不计数比较稀有度，重叠区域的填充无法确定。缩放、叠加、计数三者耦合。

在含两种不同少数单元的分隔网格中，分别将每种少数图案缩放为网格级蓝图，重叠位置以更稀有的类型优先。

**输入结构**：约 15x15 的网格，由单色分隔线（栗(9)，1 像素宽）分为 5x5 的单元阵列，每个单元内部为 2x2 的图案区域。大多数单元（约 17~19 个）共享相同的内部图案（多数图案），称为 M 型。剩余单元分为两类少数图案——A 型和 B 型，各出现 2~4 次，且 A 型出现次数严格少于 B 型。A 型和 B 型的内部图案互不相同，也与 M 型不同。每种少数图案的内部 2x2 像素视为一个二值蓝图（非背景像素=活跃，背景像素=非活跃），它指示该类少数单元应在 5x5 单元阵列的哪些位置出现。生成约束：A 型和 B 型的蓝图各自与其在阵列中的实际位置一致（已有的少数单元位于蓝图活跃位置）；两种蓝图的活跃位置存在至少 1 个重叠单元格。

**规则**：
1. 识别分隔线颜色（完全覆盖某些行和列的单色），确定单元阵列的大小和每个单元的边界。
2. 统计每个单元的内部图案，按出现频率分为多数图案 M、少数图案 A、少数图案 B 三类。
3. 对 A 型和 B 型分别提取内部图案作为二值蓝图：在 2x2 图案中，非背景(非0)像素位置为活跃。
4. 将每个蓝图缩放到 5x5 单元阵列级别：蓝图中的活跃位置对应阵列中应放置该少数图案的单元。
5. 对阵列中每个单元确定输出图案：
   - 若该位置仅被 A 蓝图标记为活跃 → 填入 A 型图案。
   - 若该位置仅被 B 蓝图标记为活跃 → 填入 B 型图案。
   - 若该位置被两个蓝图同时标记 → 填入出现次数更少的那种少数图案（A 型次数 < B 型次数，所以填 A 型）。
   - 若该位置不被任何蓝图标记 → 保持 M 型图案。
6. 输出网格保持与输入相同的尺寸和分隔线结构。

**关键洞察**：源题 b99e7126 只有一种少数图案，缩放后直接填充即可；源题 281123b4 的叠加优先级由固定的循环位置决定。这里两种分形蓝图在同一网格上竞争，优先级由蓝图源的稀有度（出现次数）决定——这是源题中不存在的"稀有度→优先级"结构关系。
