## 新题 1：射线补墙洪泛分区

**组合逻辑**：[射线延伸](创新：射线作为结构墙而非视觉轨迹) + [洪泛填充] + [重涂色]（三者紧耦合：射线结果决定拓扑，拓扑决定涂色）

**来源原语**：射线延伸(ray_extend, 来自 9344f635/ac605cbb) + 洪泛填充(flood_fill, 来自 7b6016b9/8f3a5a89) + 重涂色(recolor, 来自 62ab2642) + 微型标记(micro_marker, 来自 9344f635) + 墙壁障碍(wall_barrier, 来自 8f3a5a89) + 封闭区域(enclosed_region, 来自 7b6016b9) + 朝向决定方向(orientation_determines_direction, 来自 9344f635) + 内外分区(in_out_partition, 来自 7b6016b9) + 边界连通分内外(border_in_out, 来自 7b6016b9)

**依赖链**：标记朝向 → 射线方向 → 射线与已有墙段拼合为完整围栏 → 洪泛填充识别内外 → 内部区域涂红、外部涂绿。若不先射线补墙，墙段有缺口，洪泛无法形成封闭区域；若不洪泛，无法区分内外；三步缺一不可。

从彩色标记的朝向发射射线补全不完整的灰墙，再用洪泛填充将墙围出的封闭区域涂红、外部涂绿。

**输入结构**：约 15x15 的网格，背景为黑(0)。灰(5) 像素构成若干不连续的墙段（每段为 3~8 像素的水平或垂直直线），这些墙段大致围出一到两个区域但留有缺口。在缺口附近散布 2~4 个同色的 2 像素标记（domino）：水平排列的标记表示水平方向，垂直排列的表示垂直方向。每个标记颜色各不相同（从蓝(1)、红(2)、绿(3)、黄(4) 中选取），但在射线阶段仅用灰(5) 绘制射线。生成约束：每个标记发出的射线恰好能填补一段墙的缺口，使墙段连为完整围栏；标记不在墙段上；所有标记射线互不交叉。

**规则**：
1. 对每个 2 像素标记，判断其朝向：若两像素水平相邻则为水平标记，若垂直相邻则为垂直标记。
2. 从标记中心位置沿其朝向的两个方向同时发射灰(5) 射线，每条射线延伸直到碰到已有的灰(5) 墙段像素或网格边界时停止（终点处不覆盖已有墙像素）。
3. 射线绘制完成后，擦除所有彩色标记像素（标记本身不保留）。
4. 此时灰墙段加灰射线构成完整的墙网络。从网格四条边界出发，对所有通过黑(0) 像素 4-连通可达的区域进行洪泛标记为外部。
5. 将外部黑像素重涂为绿(3)。
6. 将剩余黑像素（被墙完全包围、无法从边界到达的区域）重涂为红(2)。
7. 所有灰(5) 像素（原墙段 + 射线）保持不变。

**关键洞察**：标记在源题中仅用于发射视觉轨迹或行列条；这里标记的朝向信息被重新解读为"墙缺口的方向"，射线不是装饰而是结构性补墙。拓扑分区（内/外）完全取决于射线能否正确封闭围栏——朝向判断错误会导致缺口未补、洪泛穿透、内外颠倒。
