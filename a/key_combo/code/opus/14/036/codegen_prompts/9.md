## 新题 9：象限镜像叠加的密度优先级

**组合逻辑**：[镜像](创新：镜像类型由象限位置编码而非固定) + [透明叠加](保留) + [计数](创新：像素密度决定图层优先级而非循环位置)（三条独立规则必须同时正确才能得到正确输出）

**来源原语**：镜像/mirror(来自 2dee498d) + 透明叠加/transparent_overlay(来自 281123b4) + 计数/counting(来自 f931b4a8) + 四象限/four_quadrants(来自 f931b4a8) + 面板/panel(来自 281123b4) + 控制区域/control_region(来自 f931b4a8) + 图层优先级/layer_priority(来自 281123b4) + 像素数决定尺寸/pixel_count_sets_size(来自 f931b4a8，创新为像素数决定优先级)

**依赖链**：四个象限各自镜像变换（变换类型由位置决定）→ 变换后四个图层叠加为一个象限大小的输出 → 叠加冲突由原始（变换前）象限的前景像素密度解决。三条规则（位置→变换类型、密度→优先级、透明叠加机制）各自独立，但输出是三者的联合结果。

四个象限的图案分别经过位置编码的镜像变换后透明叠加，冲突像素由原始象限中前景像素最少者优先。

**输入结构**：一个偶数边长的正方形网格（如 12x12），由一行一列的灰(5) 十字线分成四个大小相等的象限（每象限约 5x5 或 6x6，不含分隔线本身）。每个象限内有一种独特的前景颜色（从蓝(1)、红(2)、绿(3)、黄(4) 中选取）的图案，背景为黑(0)。四个象限的前景像素数互不相同。不同示例中，图案形状不同、像素数不同、颜色分配不同。

**规则**：
1. 移除灰(5) 十字分隔线，提取四个象限的图案。
2. 对每个象限施加由其位置决定的镜像变换：
   - 左上象限：水平翻转（左右镜像）。
   - 右上象限：垂直翻转（上下镜像）。
   - 左下象限：180° 旋转（等价于水平+垂直翻转）。
   - 右下象限：不变换（保持原样）。
3. 计算每个象限在变换前的前景像素数量 N（非黑非灰像素的个数）。
4. 将四个变换后的象限叠加为一个象限大小的输出。叠加规则：
   - 黑(0)像素视为透明。
   - 若某位置只有一个象限有非透明像素，使用该像素。
   - 若多个象限在同一位置有非透明像素（冲突），选择原始前景像素数 N 最小的那个象限的颜色（更稀疏的图案优先）。
   - 若该位置所有象限都是透明的，输出黑(0)。
5. 输出仅为叠加后的单个象限大小的网格，不包含分隔线。

**关键洞察**：源题 281123b4 的叠加优先级由面板的循环位置固定决定（第三面板最前）。这里优先级由内容属性（像素密度）决定——更稀疏的图案总是可见的，更密集的被遮挡。求解者若假设位置决定优先级（如源题），会在多个示例间得到矛盾的结果；只有统计每个象限的像素数并发现"少即优先"规则才能一致解释所有示例。同时，镜像变换类型由位置编码——求解者需要同时独立发现两条规则。
