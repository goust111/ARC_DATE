## 新题 8：中心竞争者的收缩射线与碰撞标记

**组合逻辑**：[生长+收缩](保留面积比较机制) + [射线延伸](创新：收缩的对象从缩退点发射射线) + [重涂色](创新：碰撞点产生新颜色)（三路耦合：面积决定角色，角色决定行为，行为产生交互）

**来源原语**：生长/grow(来自 df978a02) + 收缩/shrink(来自 df978a02) + 射线延伸/ray_extend(来自 ac605cbb/9344f635) + 重涂色/recolor(来自 ac605cbb) + 前景对象/fg_object(来自 df978a02) + 中心间隙/center_gap(来自 df978a02) + 标记像素/marker_pixel(来自 ac605cbb) + 轨迹线段/trail_segment(来自 ac605cbb) + 面积最大者/largest_area(来自 df978a02) + 轨迹交叉/trail_intersection(来自 ac605cbb) + 最大外扩余内缩/max_grow_rest_shrink(来自 df978a02) + 交叉产生对角线/cross_spawns_diagonal(来自 ac605cbb)

**依赖链**：面积比较 → 确定最大者（生长）和其余者（收缩） → 收缩者失去中心端像素，从该像素位置向外发射灰射线 → 最大者向外侧生长三像素帽 → 若两条灰射线相交，交点涂橙并沿左下对角线延伸橙线。面积→角色分配→几何变形→射线拓扑→碰撞检测，五步链式耦合。

四个围绕中心间隙的对象中，最大者向外生长，其余三个收缩并从收缩点向外发射灰色射线，射线交叉点产生橙色对角线。

**输入结构**：约 15x15 的网格，背景为黑(0)。有一个约 3x3 的黑色中心间隙区域。四个 4-连通的单色对象（各用不同颜色：蓝(1)、红(2)、绿(3)、黄(4)）分别从上、下、左、右四个方位指向中心间隙。每个对象由 4~10 像素组成，为不规则的连通形状，各自有一个像素最接近中心间隙（中心端像素）。四个对象的面积互不相同，且恰好有一个面积最大。生成约束：中心间隙与每个对象之间至少隔 1 像素；各对象沿其所在方位排列（上方对象的所有像素都在中心间隙上方等）。

**规则**：
1. 找到中心间隙——距四个对象边界框中心最近的背景连通区域。
2. 计算每个对象的面积，确定唯一面积最大者。
3. 对三个非最大对象：
   a. 找到其中心端像素（距中心间隙最近的那个像素）。
   b. 将该像素涂为黑(0)（收缩一像素）。
   c. 从该像素的原位置出发，沿远离中心的基本方向（上方对象向上、下方对象向下、左方对象向左、右方对象向右）发射灰(5) 射线，延伸直到碰到网格边界为止。
4. 对最大对象：
   a. 确定其远离中心的外侧方向。
   b. 找到该对象在外侧边缘的中间列（若水平方向的对象则为中间行），在该位置的外侧添加一个 3 像素的 T 形帽（沿外侧方向伸出 1 像素，并在垂直方向各扩展 1 像素），颜色与该对象相同。
5. 检查所有灰射线之间的交叉：若两条射线（一条水平一条垂直）在同一像素位置交叉，将该像素涂为橙(7)，并从该位置沿左下对角线方向逐像素延伸橙色线，直到碰到非黑像素或网格边界为止。
6. 所有未被修改的像素保持原色。

**关键洞察**：源题 df978a02 中生长/收缩是终态操作，不产生后续效果。源题 ac605cbb 中射线从固定标记发出，碰撞规则是预设的。这里收缩操作"释放"了一个像素位置，该位置成为射线的发射点——收缩不仅是形态变化，更是射线拓扑的起点。面积比较的结果（谁最大）间接决定了哪些方向会有射线、射线能否交叉、以及对角线出现在哪里。
