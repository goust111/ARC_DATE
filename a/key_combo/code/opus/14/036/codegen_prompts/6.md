## 新题 6：面积排序决定四角旋转印章

**组合逻辑**：[分离](保留) + [旋转](创新：旋转角度由面积排名决定而非固定位置) + [印章覆盖](保留但布局由排名决定)

**来源原语**：分离/separate(来自 b1fc8b8e) + 旋转/rotate(来自 ed98d772) + 印章覆盖/stamp_overlay(来自 b1fc8b8e) + 精灵体/sprite(来自 b1fc8b8e) + 连通区域/connected_region(来自 62ab2642) + 四角布局/four_corner_layout(来自 b1fc8b8e) + 阵列排布/array_layout(来自 ed98d772) + 面积最大者/largest_area(来自 df978a02/62ab2642) + 插入空行列间隔/insert_blank_gap(来自 b1fc8b8e) + 四旋转组成风车/four_rot_pinwheel(来自 ed98d772)

**依赖链**：识别四个连通分量 → 测量各自面积 → 面积排序确定排名 → 排名同时决定角落位置和旋转角度 → 按分配印章到输出。面积比较是中枢节点：若不比较面积，位置和旋转都无法确定；若不分离各分量，面积无法测量。

将四个不同大小的前景连通分量按面积从小到大排序，依排名分配到输出网格的四个角落，并分别施加 0°/90°/180°/270° 旋转。

**输入结构**：约 10x10 的网格，背景为黑(0)，前景为单一颜色（如蓝(1)）。前景像素构成恰好 4 个 4-连通分量，每个分量为 3~8 像素的不规则形状（非矩形），四个分量的像素数互不相同。分量在网格中紧凑排列，彼此不连通但可能相邻（8-邻域接触但 4-连通不连通）。不同示例中分量的形状、大小、排列位置都不同。

**规则**：
1. 找出所有 4-连通的前景分量，共 4 个。
2. 计算每个分量的面积（像素数），按面积从小到大排序，排名 1（最小）到 4（最大）。
3. 计算每个分量的边界框。取四个边界框中最大的宽度 W_max 和最大的高度 H_max。
4. 构建输出网格：大小为 (2 * H_max + 1) x (2 * W_max + 1)，背景为黑(0)。中间有一行一列的空白间隔。
5. 将排名 1 的分量（最小）放置在左上角区域（H_max x W_max），不旋转（0°），左上角对齐到边界框原点。
6. 将排名 2 的分量放置在右上角区域，顺时针旋转 90°。
7. 将排名 3 的分量放置在左下角区域，旋转 180°。
8. 将排名 4 的分量（最大）放置在右下角区域，顺时针旋转 270°。
9. 每个分量在其区域内左上角对齐（旋转后的边界框左上角与区域左上角重合）。

**关键洞察**：源题 b1fc8b8e 中四个副本相同，位置固定；源题 ed98d772 中旋转角度由象限位置决定。这里四个分量大小不同，面积排名同时编码位置和旋转——最小的分量不旋转且在左上角，最大的旋转最多且在右下角。求解者必须发现"面积→排名→(位置,旋转)"这一三重绑定关系。

<description>
Rotate each 2x2 block's four diagonal corner colors clockwise, then extend the rotated colors outward as diagonal rays.

Input structure
- The background is the dominant color.
- One foreground color forms one or more solid 2x2 blocks.
- Each block has four non-background, non-block corner pixels diagonally adjacent to it.

Rule
- Around every block, move the NW corner color to NE, NE to SE, SE to SW, and SW to NW.
- From each rotated corner, paint along the outward diagonal until the grid edge or another 2x2 block is reached.
- If a ray reaches a same-colored outgoing corner of another block that has its own visible continuation, stop the incoming ray at that junction.

Key insight
- The 2x2 blocks are color rotators and ray blockers; the corner pixels are not independent dots but the four ports of each block.
