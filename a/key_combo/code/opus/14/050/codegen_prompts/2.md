## 新题 2：重叠框架的遮挡分层与深度缩放标记外移

**组合逻辑**：[层序推断/layer_infer] + [排序/sort](创新：层序位置作为位移量的标量因子) + [平移/translate](创新：位移距离由层深决定) + [擦除/erase]

**来源原语**：层序推断/layer_infer、遮挡层次/occlusion_order、唯一序链/unique_chain（22425bda）；平移/translate、擦除/erase、内外对角/interior_exterior_diagonal、标记内角移外角/markers_inner_to_outer（952a094c）

**依赖链**：多个矩形框重叠，交叉点处可见颜色揭示遮挡顺序。每个框的内角标记需移至外角，但位移距离等于该框的层深编号。层深推断依赖交叉分析，位移计算依赖层深，标记落点依赖框的几何结构和位移距离。三者形成不可分割的推理链。

推断多个重叠矩形框的遮挡层序，将每个框的内角标记沿对角线外移，外移距离等于该框从底部计起的层深编号。

**输入结构**：约 15x15 的网格，黑(0)背景。3~4 个单像素宽的矩形框，每个框使用不同的非黑非灰颜色（从蓝(1)、红(2)、绿(3)、黄(4)中选取）。框的大小不等（边长 4~8），位置使得每对框至少有一条边重叠（共享像素）。每个框恰好在其内部的一个角落处有一个与框同色的标记像素（紧邻框的内角，不在框边上）。不同示例中框的大小、位置、层序和标记角落不同。生成时保证：任意两框至少有一个交叉点可见；层序唯一确定（无环）；标记外移后不会超出网格或互相重叠。

**规则**：
1. 识别每个矩形框及其颜色。矩形框是四边闭合的单像素宽环，颜色均一。
2. 在框边重叠处，可见颜色是上层框的颜色。利用所有重叠处的可见颜色信息，推断唯一的从底到顶层序。
3. 为每个框分配层深编号 k（最底层 k=1，次底层 k=2，依此类推）。
4. 擦除所有框内角处的标记像素（恢复为黑(0)）。
5. 对每个框，找到其标记所在的内角，确定对角线方向上的外角位置（框的外接矩形向外扩展 1 格后的对应角）。从该外角位置出发，再沿同一对角线方向额外平移 (k-1) 格。在最终位置绘制该框颜色的标记像素。
6. 所有框的边保持不变（包括被遮挡的部分仍保留上层颜色）。

**关键洞察**：层深编号不仅决定哪个框在交叉处可见，还作为标量因子控制标记的外移距离。仅看一个示例无法区分"所有标记外移固定距离"和"外移距离随层深变化"两种假设——必须对比多个示例中不同层深的标记位移才能归纳出规则。
