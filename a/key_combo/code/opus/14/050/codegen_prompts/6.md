## 新题 6：方向标记门控的选择性连接与晶格放大

**组合逻辑**：[连线/connect](创新：连接权限由方向标记双向门控) + [像素放大/pixel_scale] + [方向编码/direction_encoding](创新：编码连接许可而非目标位置)

**来源原语**：连线/connect、同色邻接/same_color_adjacent、同色邻居连接/same_color_connect、连接条/connector_bar、逻辑点阵/logical_dot_lattice（33067df9）；方向编码/direction_encoding、着色标记/colored_marker、色块决定输出位置/color_direction_determines_placement（a8c38be5）

**依赖链**：方向标记不是简单标签——它编码每个点的连接许可方向。两个同色邻居之间的连接只有在双方都许可对方所在方向时才成立（双向门控）。连接决策完成后，整个晶格被放大，连接条填入放大后的间隙。标记解读、双向验证和放大三者环环相扣。

在稀疏点阵中，方向标记控制每个点允许向哪些方向连接同色邻居，放大后用连接条表现连通关系。

**输入结构**：约 9x9 的网格，黑(0)背景。前景像素排列在逻辑行列上（逻辑行列之间有 1 格黑色间隔），形成一个 3x3 或 4x4 的逻辑点阵。每个逻辑点为一个 1x1 的彩色像素，使用 2~3 种颜色（从红(2)、绿(3)、蓝(1)中选取）。部分逻辑点在其 4-邻域中有一个灰(5)标记像素（位于逻辑点与相邻间隔格之间的间隔格上），标记的方向（上/下/左/右）即该点的许可连接方向的反方向——标记在点的左侧意味着该点仅许可向右连接。没有标记的逻辑点许可所有四个方向。每个逻辑点最多有一个标记。不同示例中点的颜色分布、标记的位置和方向不同。生成时保证：至少有一对同色邻居因单向门控而不连接（一端许可但另一端不许可）。

**规则**：
1. 识别逻辑点阵：逻辑行列由包含前景像素的行/列定义，间隔行列为纯黑行/列。
2. 对每个逻辑点，检查其 4-邻域（在间隔格上）是否有灰(5)标记。若有，该点的许可连接方向为标记所在方向的反方向（标记在左→许可向右，标记在上→许可向下，依此类推）。若无标记，该点许可所有四个方向。
3. 两个同色的逻辑邻居（水平或垂直相邻的逻辑点）之间绘制连接条，当且仅当：（a）二者颜色相同，且（b）两端都许可对方所在的方向（左点许可向右 AND 右点许可向左）。
4. 放大输出：每个逻辑点扩展为 3x3 的同色实心块；每个间隔列/行扩展为宽/高 2 像素的间隙。已建立连接的邻居对之间的间隙用 3x2 或 2x3 的同色条填充。未连接的间隙保持黑(0)。
5. 灰(5)标记在放大后的输出中不保留（不绘入输出）。

**关键洞察**：连接不是"有标记就连"或"同色就连"，而是双向门控：两个邻居必须互相许可。一个标记同时禁止了该点在标记方向上的连接并启用了反方向的连接，但对方也必须许可才行。这种双向条件只有对比包含单向拒绝的示例才能归纳出来。
