## 新题 7：二面体模板定位与对角相位着色补全

**组合逻辑**：[模板匹配/template_matching] + [补全/complete](创新：补全颜色由局部坐标系下的对角同余决定) + [重涂色/recolor](由二面体方向变换后的对角相位决定)

**来源原语**：模板匹配/template_matching、二面体变换/dihedral_transformation、唯一匹配/unique_match、旋转反射等价/rotation_reflection_equivalence（269e22fb）；模板提取/template_extraction、对齐签名匹配/alignment_signature_matching（79369cc6）；对角线同余/diagonal_residue、对角周期补缺失/missing_by_diagonal_cycle（c3f564a4）

**依赖链**：一个标准模板的像素颜色由对角同余规则决定（颜色 = palette[(r+c) mod K]）。模板的多个副本以不同二面体方向出现在网格上，部分像素缺失（黑色）。补全每个副本时，必须先确定该副本的二面体方向，然后在该方向的局部坐标系中计算对角同余，最后映射到颜色。方向检测和颜色计算不可分离——错误的方向产生错误的对角相位，导致错误的颜色。

识别每个模板副本的二面体方向，在局部坐标系中用对角同余规则补全缺失像素。

**输入结构**：约 20x20 的网格，黑(0)背景。一个 4x4 或 5x5 的标准模板，其像素颜色由 3 种非黑颜色按对角同余规则着色：位于模板局部坐标 (lr, lc) 的像素颜色为 palette[((lr + lc) mod 3)]，palette 从 {红(2), 绿(3), 蓝(1)} 中选取。模板中另有 2~3 个品红(6)像素作为方向签名（在所有副本中保持品红，不参与对角着色）。网格上放置 3~5 个该模板的副本，每个副本是标准模板经某种二面体变换（8 种之一：4 种旋转 x 2 种反射）后放置的。每个副本有 2~4 个像素被替换为黑(0)（缺失）。至少有一个副本完整（无缺失），作为模板推断的参考。不同示例中模板大小、颜色选择、副本数量、方向和缺失位置不同。生成时保证：每个副本的品红签名足以唯一确定其二面体方向。

**规则**：
1. 从完整副本（无黑色缺失的副本）提取标准模板，记录品红(6)签名像素的相对位置和对角着色的 palette 映射。
2. 对每个不完整副本，利用其品红(6)签名像素的相对位置，与标准模板的所有 8 种二面体变换进行匹配，确定该副本的方向 T。
3. 对副本中每个黑(0)缺失像素，计算其在副本边界框中的位置，通过 T 的逆变换映射回标准模板的局部坐标 (lr, lc)。
4. 根据 palette[((lr + lc) mod 3)] 确定该缺失像素应有的颜色，填入。
5. 品红(6)签名像素在所有副本中保持不变。
6. 完整副本保持不变。

**关键洞察**：对角同余规则在旋转和反射下不是不变的——旋转 90 度后，原来的 (r+c) mod 3 变成了 (-r+c+const) mod 3 或其他形式。因此同一个标准位置在不同方向的副本中呈现不同颜色。求解者必须同时推断对角着色规则和方向变换的复合效果，而非分别独立处理。

## 实现要求

1. `main(grid)` 必须实现新题描述中的确定性转换规则，不能只识别 `generate_input()` 的固定模板。禁止不同的input网格输出相同的output网格。
2. `generate_input()` 必须随机生成多样样例，不能固定死。随机维度应覆盖：网格大小、对象数量、位置、颜色、方向、形状参数或关键分支。注意若描述中存在若干，需实现而不是只有单个，包括object或者对应关系等等。且若涉及到最短路径，则输入网格中必涉及到多条路径，对选择造成干扰。

4. 禁止把 ARC 颜色 id 、亮度、拼写等当作人类不可见的数值语义参与排序、大小比较或隐藏映射。颜色变化必须有可见结构线索。注意颜色亮度、拼写等也是不可见信息，若描述中出现违规的颜色id或者亮度，可自行使用少量的固定颜色替代，但注意生成时要在三个以内输入输出网格中对所有变换100%覆盖度。

6. 若规则有多个分支，生成器不能长期固定成一个分支；应让分支在随机样例中合理出现。分支概率不必平均——难以发现的隐蔽分支（如少数情况下才触发的特殊规则）应适当提高出现概率，确保在 3 个训练示例中至少出现一次，否则求解者无法归纳该规则。对于颜色映射类规则，确保 2 个左右的示例即可覆盖所有映射关系（每种颜色→颜色的映射至少在某个示例中出现过）。
