## 新题 3：标记像素双重角色——编织底色与模板印章

**组合逻辑**：[排序](已有原语) + [编织填充](创新：编织的颜色不来自交叉条而来自排序后的标记序列) + [印章覆盖](创新：印章位置由标记本身决定，印章叠加在编织之上)

**来源原语**：排序拼接/sort_and_concatenate(12997ef3), 按位置排序标记/sort_markers_by_position(12997ef3), 多像素模板/multi_pixel_template(12997ef3), 单像素标记/single_pixel_marker(12997ef3), 编织填充/weave_fill(f3e14006), 奇偶交替颜色/parity_alt_color(f3e14006), 标记对定义跨度/marker_pair_span(f3e14006), 印章覆盖/stamp_overlay(0e206a2e), 冲突优先级/conflict_priority(c92b942c)

**依赖链**：标记像素被排序后，前两名的颜色决定编织底纹的两种交替色；同时每个标记的空间位置决定模板印章的放置坐标；印章颜色取对应标记色且覆盖编织底纹。标记既是编织的色源又是印章的锚点，删除排序则编织颜色不确定，删除编织则背景缺失，删除印章则标记位置信息未被使用。

在标记对定义的矩形区域内铺设由排序前两色交替的编织底纹，再在每个标记位置印上以该标记色重涂的模板。

**输入结构**：黑(0)背景网格，约 15x15。包含：(a) 一个由灰(5)构成的小型 4-连通形状（3-5 像素），作为模板，位于网格某角落。(b) 4-6 个单像素标记，每个标记颜色各不相同（从红(2)、蓝(1)、绿(3)、黄(4)、橙(7)、品红(6)中选取），全部位于同一行（或同一列）。(c) 同一行（或列）上另有两个青(8)像素，分别位于所有标记的两侧外围，定义编织区域的跨度端点。生成约束：标记之间至少间隔 2 个空格（为模板印章留出空间）；模板边界框的宽和高均不超过标记间最小间距；青像素之间的跨度覆盖所有标记。

**规则**：
1. 将所有非青、非灰、非背景的单像素标记按其在共享行（或列）上的位置排序：共享行时从左到右，共享列时从上到下。记排序结果为 M1, M2, ..., Mk。
2. 两个青(8)像素定义编织矩形区域：若标记共享一行，则该行为矩形的行跨度中心，列跨度为两个青像素之间（含青像素列），矩形高度等于灰模板边界框高度；若标记共享一列，类似地定义垂直矩形。
3. 在编织矩形内填充交替棋盘格：行索引 + 列索引为偶数的位置填 M1 的颜色，奇数位置填 M2 的颜色（行列索引从矩形左上角起算，均从 0 开始）。
4. 将灰模板裁剪到边界框。对每个标记 Mi，以 Mi 的位置为锚点（对齐模板边界框的中心），将模板印章重涂为 Mi 的颜色后叠加到编织区域上，印章像素覆盖编织底纹（模板边界框内的背景位置不覆盖）。
5. 青(8)像素在输出中被编织底纹或印章覆盖。灰模板在原位置保持不变。编织区域外保持黑背景。

**关键洞察**：标记像素在这道题中同时承担三重角色——排序序列决定编织配色、空间位置决定印章锚点、自身颜色决定印章涂色——求解者必须识别出同一组元素的三种不同用途。
