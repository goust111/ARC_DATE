## 新题 10：图例排位重涂色与射线遮挡填充

**组合逻辑**：[排位对应/rank_correspond](创新：图例排位不直接给出颜色，而是给出射线方向) → [射线延伸/ray_extend + 射线遇障停止/ray_stops_at_block] → [填充/fill](创新：射线围合区域内填充图例映射色)

**来源原语**：排位对应(fafd9572), 颜色图例(fafd9572), 图例位映射色(fafd9572), 射线延伸(6ffe8f07), 射线遇障停止(6ffe8f07), 特定色为墙壁(6ffe8f07), 填充(305b1341), 列遮挡(6d58a25d)

**依赖链**：精灵体按空间排位与图例像素配对 → 图例像素颜色不是重涂目标色，而是编码射线方向 → 每个精灵体从其位置沿图例编码方向发射射线，遇蓝(1)障碍停止 → 射线从精灵体到障碍之间围成的矩形区域用精灵体自身颜色填充。排位决定方向指令，方向指令决定射线几何，射线几何决定填充范围。

精灵体按空间排位与图例配对获取方向指令，沿指令方向射出射线直到遇障，精灵体与障碍之间的列/行用精灵体色填充。

**输入结构**：黑(0)背景，约 18x18 网格。网格中有 3~4 个同色（橙(7)）的小型 4-连通精灵体（每个 3~5 像素），位于不同位置。网格右上角有一个紧凑的图例区域，由 3~4 个单像素组成，排列成一列或一行，颜色取自绿(3)=左、黄(4)=下、品红(6)=上、青(8)=右（可重复）。图例像素的排列顺序（若为列则从上到下，若为行则从左到右）与精灵体的空间排位一一对应（精灵体按边界框左上角坐标排序：先按行从上到下，同行则按列从左到右）。网格中另有若干蓝(1)单像素或小型蓝(1)对象作为障碍物。生成约束：每个精灵体沿其分配方向的射线路径上至少有一个蓝(1)障碍；不同精灵体的填充区域互不重叠。

**规则**：
1. 识别所有橙(7)精灵体，按边界框左上角坐标排序（先行后列），得到排位序列 S1, S2, ..., Sn。
2. 识别图例区域中的像素序列 L1, L2, ..., Ln（若图例为纵向排列则从上到下，横向则从左到右）。
3. 将 Si 与 Li 配对。Li 的颜色编码方向：绿(3)=左，黄(4)=下，品红(6)=上，青(8)=右。
4. 对每个精灵体 Si，从其边界框的对应边（左=左边缘全列, 右=右边缘全列, 上=上边缘全行, 下=下边缘全行）沿分配方向发射射线：
   - 方向为左：从精灵体边界框每一行的最左列向左逐像素延伸，遇到蓝(1)像素或网格左边界时停止（不含蓝像素本身）。
   - 方向为右：从精灵体边界框每一行的最右列向右延伸，同理。
   - 方向为上：从精灵体边界框每一列的最上行向上延伸，同理。
   - 方向为下：从精灵体边界框每一列的最下行向下延伸，同理。
5. 将射线扫过的所有黑(0)像素涂为橙(7)（精灵体自身颜色）。不覆盖蓝(1)障碍、图例像素或其他精灵体像素。
6. 图例区域保持不变。

**关键洞察**：图例像素的颜色不是精灵体的目标涂色（精灵体保持橙(7)），而是编码精灵体应当发射射线的方向——这反转了图例的常见用途；求解者必须先通过空间排位建立精灵体与图例的对应关系，才能得知每个精灵体的射线方向。
