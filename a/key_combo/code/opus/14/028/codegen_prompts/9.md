## 新题 9：原型锚点定位与空腔嵌套旋转

**组合逻辑**：[形状匹配/shape_match + 旋转反射等价/rotation_reflection_eq](将工具与框架配对) → [嵌套/dock](创新：嵌套时锚点颜色决定旋转角度而非仅匹配面积) → [颜色互换/color_swap](创新：仅在特定旋转角度下触发)

**来源原语**：形状匹配(2a5f8217), 旋转反射等价(bd14c3bf), 嵌套(a25697e4), 空腔(a25697e4), 面积匹配(a25697e4), 颜色互换(a25697e4), 反射触发色换(a25697e4), 最少色为锚点(a251c730), 颜色匹配(a251c730)

**依赖链**：每个可移动工具有一个稀有色锚点像素 → 锚点颜色与边框框架上的标记颜色匹配确定配对 → 工具必须旋转/翻转使其非锚点区域恰好填满框架空腔 → 若最终嵌套使用了反射（而非纯旋转），则工具两种颜色互换。颜色匹配决定配对，面积匹配+旋转确定嵌套姿态，反射判定触发颜色互换——三步判断串联。

通过锚点颜色将工具与框架配对，旋转/翻转工具填入空腔，若使用了反射则互换工具双色。

**输入结构**：黑(0)背景，约 16x16 网格。边缘区域有 2~3 个灰(5)边框框架（1 像素厚边框围成的矩形，内部为黑(0)空腔），每个框架的某一面墙壁上恰有 1 个彩色单像素标记（取自红(2)、绿(3)、蓝(1)），标记颜色各不相同。框架空腔形状各不相同（矩形，但宽高比各异，如 2x3、3x2、2x4 等）。网格中央区域有对应数量的可移动工具，每个工具由两种颜色组成（一种为主色占多数像素，一种为稀有锚点色仅 1 像素），工具为 4-连通的不规则形状（5~10 像素）。每个工具的锚点颜色与某个框架标记颜色相同。生成约束：每个工具恰好可以通过某种旋转或翻转使其形状（含锚点位置）适配入对应框架空腔，其中锚点像素落在标记像素位置上；每对工具-框架配对在旋转/翻转变换中是唯一的。

**规则**：
1. 识别所有框架（灰(5)边框 + 黑(0)空腔）及其标记颜色和标记位置。识别所有可移动工具及其锚点颜色（像素数最少的颜色）。
2. 通过锚点颜色 = 标记颜色将每个工具与唯一框架配对。
3. 对每个配对，尝试所有 8 种旋转/翻转变换（4 种旋转 x 是否水平翻转），找到使工具形状恰好填满框架空腔、且工具锚点像素落在框架标记位置的唯一变换。
4. 判断最终使用的变换是否包含反射（翻转）：若包含反射，则将该工具的两种颜色互换（主色变为锚点色，锚点色变为主色）；若仅为纯旋转（0/90/180/270 度，不含翻转），则颜色保持不变。
5. 将变换后的工具放入框架空腔，覆盖原空腔中的黑(0)像素。擦除工具原始位置（涂黑(0)）。框架边框和标记像素保持不变（工具锚点像素叠在标记位置上，用工具的锚点色覆盖）。

**关键洞察**：求解者不仅要找到正确的旋转/翻转使工具嵌入空腔，还必须判断该变换是否包含反射——这个看似纯几何的判断会触发颜色层面的变化（双色互换），将空间推理和颜色推理耦合在一起。
