## 新题 2：嵌套深度决定镜像轴向的对称补全

**组合逻辑**：[规范化·包含树分析](已有) → [对称补全](创新：镜像轴由包含深度动态决定，而非固定双轴) + [包含树](已有) + [标记方块→对称中心](已有)

**来源原语**：规范化·包含树·嵌套框架·封闭区域·拓扑决定布局(2d0172a1), 对称补全·镜像·标记方块·对称中心·标记定义双轴镜像(4938f0c2)

**依赖链**：必须先构建包含树确定每个区域的嵌套深度；深度的奇偶性决定在该区域内执行水平镜像还是垂直镜像；每个区域内的标记方块定义镜像中心。去掉包含树分析则镜像轴无法确定；去掉镜像操作则深度分析无用。拓扑结构成为操作的参数选择器，而非两个独立操作的串联。

解析嵌套矩形框架的包含深度，在每层区域内以标记方块为中心执行单轴对称补全，镜像轴方向由该区域的嵌套深度奇偶性决定。

**输入结构**：约 19x19 网格，背景黑(0)。2~3 层嵌套的灰(5) 矩形单像素宽边框，每层边框完全包围内层。在最内层和各层之间的环形区域中各有一个绿(3) 的 2x2 实心标记方块。在部分区域中（不必每个区域都有），标记方块的某一侧（或两侧、三侧）有红(2) 前景像素构成的不规则 4-连通形状（3~7 像素），这些前景像素仅出现在标记方块的一个或两个象限中，不跨越标记方块的中心轴线。生成约束：前景形状的镜像补全结果不会超出其所在区域的边框范围。

**规则**：
1. 识别所有灰(5) 矩形边框，构建包含树。最外层边框深度 = 0，其内部直接子边框深度 = 1，依次递增。未被任何边框包围的区域（即最外层边框外部）深度 = -1，不参与变换。
2. 对每个深度 >= 0 的区域（边框内部、两层边框之间、或最内层边框内部），找到该区域中的绿(3) 2x2 标记方块。以标记方块几何中心为镜像中心。
3. 若该区域的深度为偶数（0, 2, ...），执行**水平轴**镜像：对区域内每个红(2) 像素，计算其关于标记方块中心的上下对称位置，在对称位置涂红(2)（仅覆盖黑(0) 像素）。
4. 若该区域的深度为奇数（1, 3, ...），执行**垂直轴**镜像：对区域内每个红(2) 像素，计算其关于标记方块中心的左右对称位置，在对称位置涂红(2)（仅覆盖黑(0) 像素）。
5. 灰(5) 边框、绿(3) 标记方块均保持不变。不含红色前景的区域不做任何操作。
6. 边界处理：镜像后的像素若落在灰(5) 边框上或区域外，不绘制（生成约束保证这不会发生）。

**关键洞察**：参考题 4938f0c2 中标记方块总是触发固定的双轴镜像，而这里每个标记方块只执行单轴镜像，且选择哪条轴取决于该方块在嵌套层次中的位置——拓扑结构编码了操作参数，而非直接编码操作结果。需对比多个示例才能归纳出深度奇偶与轴向的对应关系。
