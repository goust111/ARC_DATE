## 新题 1：对角射线激活选择性同余填充

**组合逻辑**：[射线延伸](创新：射线用于选择而非重涂色) → [循环填充](已有) + [对角线激活](创新：激活的结果是选中对象，而非改变颜色) + [同余类交错铺满](已有)

**来源原语**：射线延伸·对角线激活·底色决定涂色(d07ae81c), 循环填充·同余类交错铺满·对角线·等距偏移(05269061), 标记像素(9caba7c3/d07ae81c), 擦除(d23f8c26)

**依赖链**：标记像素的对角射线决定哪些对角线段被"激活"（选择机制）；被激活的线段才触发同余类铺满（填充机制）；未被激活的线段被擦除。射线的几何路径同时承载"选择"和"铺满方向"两重语义——去掉射线则不知选哪些线段，去掉铺满则激活毫无意义。

将标记像素的对角射线作为选择器，仅让射线穿过的对角线段按其同余类周期性铺满整个网格，未被射线选中的线段被擦除。

**输入结构**：约 15x15 网格，背景黑(0)。网格上散布 2~3 个红(2) 标记像素。另有 3~5 条 NW-SE 方向的短对角线段（每条 2~4 像素），每条使用不同颜色（从蓝(1)、绿(3)、黄(4)、品红(6) 中选取）。各对角线段互不相邻，与红标记像素也不相邻。生成约束：每条对角线段的像素均满足 row - col = 常数（即同一条 NW-SE 对角线上），不同线段的 (row - col) mod 3 值互不相同；至少一条线段不被任何红标记的射线穿过。

**规则**：
1. 从每个红(2) 标记像素出发，沿 NW-SE 方向和 NE-SW 方向分别向两端延伸射线至网格边界，标记射线经过的所有格子为"已激活"（红标记自身也算已激活）。
2. 对每条彩色对角线段：若其至少一个像素位于已激活格子上，则该线段被"选中"。
3. 对每条选中的线段：计算其 NW-SE 同余偏移量 d = (row - col) mod 3。将网格中所有满足 (row - col) mod 3 = d 的黑(0) 格子涂上该线段的颜色。若线段自身的像素也在这些位置上，保持原色不变。
4. 未被选中的对角线段的所有像素擦除为黑(0)。
5. 红(2) 标记像素在输出中保持不变。
6. 冲突解决：若两条选中线段的同余偏移量相同（生成约束已排除此情况，但作为安全规则），按线段中心像素到最近红标记的曼哈顿距离排序，距离小的颜色优先（覆盖距离大的）。

**关键洞察**：红标记的对角射线并不直接改变任何颜色，而是充当"选通门"——射线穿过哪些线段决定了哪些同余类被铺满、哪些被清除。同一条射线可能同时选中多条不同偏移量的线段，导致多个同余类同时铺满而形成交错图案。
