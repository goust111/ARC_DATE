## 新题 4：连通拓扑分类门控双模式扩展

**组合逻辑**：[模式检测·拓扑分类](创新：检测的不是固定图案而是连通性质) ⇒ 分支 { [掩码映射](已有) | [像素放大](已有) } + [对角链式连接](已有作为分类依据) + [自身色选掩码](已有)

**来源原语**：模式检测(1818057f), 八连通区域·对角链式连接·仅对角接触变色(ecb67b6d), 掩码映射·像素放大·自身色选掩码·全局掩码·块单元(973e499e)

**依赖链**：先将每个 8-连通彩色区域按内部 4-连通结构分类——若 4-连通子块仅通过对角角点连接（对角链），则归为"链式区域"；否则归为"实心区域"。分类结果决定该区域使用哪种扩展模式：链式区域使用自身色掩码映射（每个像素扩展为一个微型掩码），实心区域使用简单像素放大（每个像素变为 2x2 同色块）。去掉拓扑分类则不知用哪种扩展；去掉扩展操作则分类无用。分类本身是一个推理步骤，而非简单属性读取。

按 8-连通区域的内部 4-连通拓扑分类，对角链式区域进行自身色掩码映射扩展，实心连通区域进行像素放大扩展。

**输入结构**：约 7x7 网格，背景黑(0)。网格上有 3~5 个 8-连通的单色区域，各区域使用不同颜色（从蓝(1)、红(2)、绿(3)、黄(4)、灰(5) 中选取），每个区域 3~6 像素。区域之间至少间隔 1 个黑(0) 像素。部分区域是"对角链式"的：由 2~3 个 4-连通子块组成，子块之间仅通过对角角点相连（如一个像素在 (r,c)、另一个在 (r+1,c+1)，它们 8-连通但不 4-连通）。其余区域是"实心"的：整个区域构成单个 4-连通块。生成约束：至少有一个链式区域和一个实心区域。

**规则**：
1. 识别所有非黑 8-连通区域。对每个区域，分解为 4-连通子块。
2. 分类：若一个 8-连通区域包含多个 4-连通子块，且每对相邻子块仅通过对角角点相连（不存在共享边的像素对），则该区域为"链式"。否则（整个区域是单个 4-连通块）为"实心"。
3. 构建输出网格：输出尺寸 = 输入行数 x 输入行数 乘以 输入列数 x 输入列数（即输入每个像素对应输出的一个与输入同尺寸的块）。
4. 对输入中的每个像素 (r, c)：
   - 若 (r, c) 是黑(0) 背景，对应输出块全部填黑(0)。
   - 若 (r, c) 属于**链式区域**且颜色为 c_val：输出块是输入网格的"c_val 色掩码"——在输出块中，原输入中颜色为 c_val 的位置填 c_val，其余填黑(0)。
   - 若 (r, c) 属于**实心区域**且颜色为 c_val：输出块全部填 c_val（等效于简单像素放大）。
5. 输出块按输入像素的行列顺序拼接，无间隔。

**关键洞察**：两种扩展模式在参考题中各自独立使用。这里它们共存于同一张输出网格中，由每个像素所属区域的拓扑分类来选择——求解者必须先理解对角连通性的概念，再将其映射到正确的扩展规则，形成"分类→分支执行"的推理结构。
