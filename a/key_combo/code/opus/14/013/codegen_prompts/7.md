## 新题 7：对角射线通道门控逐步标记迁移

**组合逻辑**：[射线延伸](创新：射线定义可通行通道而非涂色目标) ⊗ [逐步推进·循环迁移](创新：迁移不再沿固定车道而是沿射线通道) + [对角线激活](创新：激活产生通道约束) + [标记条·边缘满条](已有)

**来源原语**：射线延伸·对角线激活·标记像素·基底色区域(d07ae81c), 生长·逐步推进·循环迁移·边缘满条·标记条·重涂色(758abdf0)

**依赖链**：标记像素的对角射线在网格上刻画出"可通行通道"；边缘满条发射标记条沿车道向对侧迁移，但标记条只能移动到位于已激活通道上的格子——若下一步位置不在通道上则标记条停滞。通道网络与迁移规则同时约束输出，两套系统交织：去掉射线则所有标记条都停滞（无路可走）；去掉迁移规则则通道只是无意义的标记。

标记像素的对角射线定义可通行通道，边缘标记条仅沿通道内的车道逐步迁移。

**输入结构**：约 13x13 网格，背景黑(0)。网格的左边缘（第 0 列）有一条完整的蓝(1) 竖条（从第 0 行到最后一行全部填蓝(1)），即边缘满条。在第 1 列中，部分行有红(2) 单像素标记条（紧邻蓝条右侧），其余行为黑(0)。网格内部散布 2~4 个绿(3) 标记像素（不在第 0 或 1 列）。生成约束：每个红(2) 标记条所在行上，至少有一个绿(3) 标记像素的某条对角射线穿过该行的第 2 列位置（否则该标记条永远无法前进，题目保证每个标记条至少可以走一步）。

**规则**：
1. 从每个绿(3) 标记像素出发，沿 NW-SE 和 NE-SW 两个方向分别向两端延伸射线至网格边界。将射线经过的所有格子标记为"通道"（绿(3) 标记像素自身也是通道）。
2. 对每个红(2) 标记条像素（位于第 1 列、第 r 行）执行迁移：
   - 检查第 2 列第 r 行是否为通道且当前为黑(0)。若是，将该位置涂红(2)，并将第 1 列第 r 行的红(2) 擦除为黑(0)——标记条向右移动一格。
   - 若第 2 列第 r 行不是通道或不是黑(0)，标记条不移动，保持在第 1 列。
3. 对已移动到第 2 列的标记条，继续检查第 3 列同行位置是否为通道且为黑(0)。若是，继续移动（擦除旧位置，涂新位置）。重复此过程直到下一列同行位置不是通道、不是黑(0)、或超出网格。
4. 当一个标记条到达网格最后一列（第 W-1 列）时，将该位置改涂为蓝(1)（与边缘满条同色），表示迁移完成。
5. 绿(3) 标记像素在输出中保持不变。蓝(1) 边缘满条保持不变。迁移过程中标记条不会覆盖绿(3) 像素（遇到绿像素则停止，停在前一格）。
6. 处理顺序：从上到下逐行处理标记条，同行内不存在多个标记条。

**关键洞察**：参考题中标记条的迁移是沿固定车道无条件推进，对角射线则用于涂色。这里对角射线创造了稀疏的"通道网络"，标记条的水平迁移被限制在通道交叉点上——射线的几何角度决定了哪些行列交叉处是可通行的，相当于用对角线几何编码了一张隐式的通行许可表。
