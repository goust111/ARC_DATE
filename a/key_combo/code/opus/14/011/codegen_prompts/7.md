## 新题 7：控制像素定色的弹性拉伸孔洞填充

**组合逻辑**：[弹性拉伸](已有) + [封闭孔洞·创新：孔洞不是保留不填，而是用外部控制色填充](创新改造) + [列范围包含](已有) + [控制色决定填色](已有) + [模板填充](已有)

**来源原语**：弹性拉伸/elastic_stretching(40f6cd08)、模板填充/template_filling(40f6cd08)、按目标尺寸调整/resize_to_target(40f6cd08)、封闭孔洞/enclosed_hole(5adee1b2)、孔洞保留不填/holes_preserved(5adee1b2→反转使用)、列范围包含/column_span_contains(ddf7fa4f)、控制色决定填色/control_fill_color(ddf7fa4f)、控制像素/control_pixel(ddf7fa4f)

**依赖链**：弹性拉伸将范例适配到目标尺寸 → 拉伸过程中范例的孔洞按比例放大成为目标中的孔洞 → 列范围包含找到覆盖该目标的控制像素 → 控制像素的颜色填充孔洞。删除弹性拉伸则目标无内容；删除孔洞检测则不知道哪些区域需要额外填充；删除控制像素查找则不知道用什么颜色填孔洞。参考题 5adee1b2 中孔洞保留不填，这里反转为孔洞用外部信号填充。

将含孔洞的多色范例弹性拉伸到各目标矩形后，用顶行控制像素的颜色填充拉伸后产生的放大孔洞。

**输入结构**：约 16x18 网格，黑(0)背景。顶行（行 0）有 2~3 个单像素控制像素，颜色各不同（从红(2)、蓝(1)、黄(4)中选取），其余为背景。网格中有一个多色范例矩形（约 5x5，外框橙(7)，内部含 2~3 种颜色的花纹，且内部有 1~2 个封闭孔洞——即被花纹完全包围的背景(0)像素连通区域，每个孔洞 1~3 像素）。另有 2~3 个纯橙(7)目标矩形，尺寸各不同（均大于范例），彼此不重叠。每个目标矩形的列范围恰好包含一个控制像素的列坐标。生成约束：不同目标矩形包含不同的控制像素；范例的行程编码结构允许弹性拉伸（行和列各有一条可拉伸的内部行程）。

**规则**：
1. 识别范例矩形（唯一的内部多色、四角橙(7)的矩形）。
2. 对每个纯橙(7)目标矩形：
   a. 对范例做弹性拉伸以适配目标尺寸：行程编码后保持边界行程固定，仅拉伸内部行程。
   b. 用拉伸后的花纹替换目标矩形的橙像素。
   c. 在拉伸后的花纹中定位所有封闭孔洞（被非背景像素完全 4-连通包围的背景区域）。
   d. 找到列坐标落在该目标矩形列范围 [col_min, col_max] 内的顶行控制像素。
   e. 将该目标内所有封闭孔洞像素填充为控制像素的颜色。
3. 范例矩形本身保持不变（其孔洞仍为背景）。
4. 顶行控制像素保持不变。

**关键洞察**：范例中的孔洞是故意设计的"待填槽位"——拉伸后孔洞按比例放大，而填充颜色不由范例内部决定，而由目标矩形上方的控制像素从外部注入。同一个范例在不同目标处产生不同颜色的孔洞填充。
