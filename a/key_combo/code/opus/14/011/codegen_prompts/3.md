## 新题 3：引导边定向的弹性拉伸填充

**组合逻辑**：[弹性拉伸](已有) + [旋转/镜像](已有) + [颜色匹配朝向·创新：匹配对象不是边框控制条而是目标矩形上的引导边](创新改造) + [按目标尺寸调整](已有) + [裁剪](已有)

**来源原语**：弹性拉伸/elastic_stretching(40f6cd08)、旋转/rotate(fc7cae8d)、镜像/reflect(fc7cae8d)、颜色匹配朝向/color_match_orientation(fc7cae8d)、按目标尺寸调整/resize_to_target(40f6cd08)、裁剪/crop(fc7cae8d)、引导边/guide_edge(fc7cae8d)、多色范例矩形/multicolor_exemplar_rect(40f6cd08)、纯色目标矩形/solid_target_rect(40f6cd08)

**依赖链**：引导边颜色匹配确定范例需要哪种二面体变换 → 变换后的范例才能正确弹性拉伸到目标尺寸 → 拉伸完成后裁剪掉引导边得到最终输出。方向错误则拉伸后内部花纹朝向错误；不拉伸则尺寸不合；不裁剪则多出引导边像素。三步紧密串联，缺一不可。

将一个带引导边的多色范例矩形，根据每个目标矩形自身引导边的颜色朝向做旋转/镜像变换，再弹性拉伸至目标尺寸，最后裁去引导边。

**输入结构**：约 18x18 网格，黑(0)背景。包含一个多色范例矩形（约 5x5，含 3~4 种前景色构成的内部花纹，四角共享同一外框色橙(7)；范例的上边缘外侧附加 1 像素高的红(2)引导行，左边缘外侧附加 1 像素宽的蓝(1)引导列）。另有 2~3 个纯橙(7)目标矩形，尺寸各不同（从 4x6 到 7x9 不等）。每个目标矩形也在其两个相邻边外侧各附加 1 像素的引导边，颜色为红(2)和蓝(1)，但朝向可能不同（例如某目标的红引导在下边、蓝引导在右边）。生成约束：各目标的引导边朝向组合互不相同；范例的内部花纹在行程编码后恰好有一条可拉伸的内部行程（行和列各一条）；目标矩形不含引导边的尺寸均大于范例不含引导边的尺寸。

**规则**：
1. 识别范例矩形：唯一一个内部含多种颜色且四角为橙(7)的矩形（不含引导边时的范围）。记录其红(2)引导边和蓝(1)引导边各在哪一侧（上/下/左/右）。
2. 对每个目标矩形，读取其红(2)引导边和蓝(1)引导边各在哪一侧。
3. 确定将范例的引导边朝向变为目标引导边朝向所需的唯一二面体变换（0/90/180/270度旋转，可叠加水平或垂直镜像）。
4. 对范例（不含引导边的核心部分）施加该变换。
5. 对变换后的范例做弹性拉伸以适配目标矩形的尺寸（不含引导边）：对行程编码后的行和列，保持所有边界行程不变，仅拉伸唯一的内部行程使总尺寸匹配目标。
6. 用拉伸结果替换目标矩形的纯橙区域。
7. 擦除所有引导边像素（涂为背景(0)）。
8. 范例本身（含其引导边位置）也擦除为背景(0)。

**关键洞察**：同一个范例花纹在不同目标处既要旋转/镜像到正确朝向，又要拉伸到正确尺寸——两个约束独立作用但必须同时满足，仅看单个示例无法区分"固定朝向+拉伸"和"变朝向+拉伸"。
