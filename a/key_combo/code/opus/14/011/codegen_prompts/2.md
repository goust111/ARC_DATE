## 新题 2：射线门控的端点匹配行填充

**组合逻辑**：[同色配对](已有) + [射线投射·创新：不是从镂空体射向源区域，而是从匹配的左标记射向右标记](创新改造) + [碰撞阻挡](已有) + [填充·创新：填充范围由射线可达距离截断，非全行](创新改造)

**来源原语**：同色配对/same_color_pairing(22eb0ac0)、两端同色整行填充/full_row_fill_endpoints_match(22eb0ac0)、射线投射/ray_cast(3d588dc9)、碰撞阻挡/collision_blocking(1f642eb9)、忽略干扰项/ignore_distractors(3d588dc9)

**依赖链**：同色配对决定哪些行是候选行 → 射线投射检测候选行中的障碍 → 碰撞阻挡决定填充截止位置 → 填充范围由射线可达距离动态确定。删除同色配对则不知道哪些行应被处理；删除射线投射+碰撞则无法确定填充范围（全填或部分填）。在参考题 22eb0ac0 中匹配即全行填充，这里匹配只是授权，实际范围由射线决定。

在左右边界标记颜色匹配的行中，从左标记向右发射射线，射线被行内障碍物截止后，仅填充射线实际经过的背景区域。

**输入结构**：约 12x12 网格，黑(0)背景。每行的最左列(列 0)和最右列(列 W-1)各有一个前景像素作为边界标记，部分行的左右标记同色，部分行不同色。标记颜色从红(2)、绿(3)、黄(4)、蓝(1)中选取。在网格内部（列 1 到 W-2），部分行中存在 1~2 个灰(5)障碍像素，这些障碍像素仅出现在标记匹配的行中（不匹配的行内部无障碍）。生成约束：至少有 2 行标记匹配且行内有障碍，至少有 1 行标记匹配但行内无障碍，至少有 2 行标记不匹配。

**规则**：
1. 复制输入网格作为输出。
2. 对每一行，比较列 0 和列 W-1 的标记颜色。
3. 若两端标记颜色不同，该行不做任何修改。
4. 若两端标记颜色相同（设为颜色 C），从列 1 开始向右逐列扫描：
   a. 若当前像素为背景(0)，涂为颜色 C。
   b. 若当前像素为灰(5)障碍，停止扫描，该像素及其右侧所有像素保持不变（包括右端标记）。
   c. 若扫描一直到列 W-2 均未遇到障碍，则列 1 到 W-2 所有背景像素全部涂为颜色 C。
5. 边界标记像素（列 0 和列 W-1）始终保持原色不变。
6. 灰(5)障碍像素始终保持不变。

**关键洞察**：边界颜色匹配只是填充的"授权"，不保证全行填充——障碍物的位置决定实际填充长度，因此一个匹配行的填充可能只覆盖左半部分。必须对比多个示例才能区分"匹配无障碍→全行填充"与"匹配有障碍→截断填充"两种情况。

<description>
Decode a block-grid image by swapping each sprite-coded cell with a solid cell and each blank cell with the sprite.

Input structure
The grid is partitioned by black separator rows and columns into equal-size
square blocks. Each block is either a copy of one two-color sprite or a
uniform blank block of the sprite's minority color; grey pixels are erased
cells that act as wildcards.

Rule
Infer the repeated sprite from fully visible mixed-color blocks. Replace a
block matching that sprite, ignoring grey erasures, with a solid block of
the sprite's majority color. Replace a uniform blank block with the sprite.
Separator rows and columns, including grey erasures on them, become black.

Key insight
The small sprite is a block-level code for one macro-cell state, and the
uniform minority-color block is the other state; the output renders the
opposite code in each macro-cell while cleaning erased pixels.
