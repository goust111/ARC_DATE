## 新题 9：复制放置旋转变体选择

**组合逻辑**：[复制放置](已有) + [标记交叉定位](已有) + [旋转·创新：不是整体旋转网格，而是根据颜色匹配从多个旋转变体中选择](创新改造) + [颜色匹配配对](已有) + [擦除](已有)

**来源原语**：复制放置/replicate_stamp(247ef758)、标记交叉定位/marker_intersection_positioning(247ef758)、颜色匹配配对/color_match_pairing(247ef758)、框架标记/frame_marker(247ef758)、旋转/rotate(fc7cae8d/412b6263)、擦除/erase(247ef758)、分隔列/separator_column(247ef758)

**依赖链**：标记交叉定位确定复制位置 → 每个位置的标记颜色决定选哪个旋转变体 → 选定的变体被复制放置到该位置 → 原始精灵区域被擦除。删除交叉定位则不知道放哪里；删除旋转变体选择则所有位置放同一个朝向（错误）；删除擦除则原位残留。参考题 247ef758 中所有位置放同一个精灵，这里每个位置根据颜色放不同旋转变体。

在框架边缘标记的行列交叉点处放置精灵体，但每个交叉点根据其行标记颜色从精灵的多个旋转变体中选择对应的朝向。

**输入结构**：约 18x18 网格，黑(0)背景。右侧有一个灰(5)线条构成的矩形框架（约 10x10），框架的左边缘和右边缘上各有若干彩色标记像素替换灰色边框像素，同色标记在左右边缘成对出现（同行左右各一个同色标记表示该行是目标行）。框架的上边缘和下边缘同理，同列上下各一个同色标记表示该列是目标列。目标位置为所有目标行与目标列的笛卡尔积。左侧有一列灰(5)分隔列。分隔列左侧上下排列 2~4 个精灵体变体，每个约 3x3 像素，它们是同一个基础精灵的 0/90/180/270 度旋转版本。每个变体在其左上角有一个 1 像素的颜色标签，标签颜色与框架上的某种行标记颜色一一对应。生成约束：变体数量等于不同行标记颜色数量；每种行标记颜色恰好对应一个旋转变体；列标记颜色只有一种（所有列标记同色），与行标记颜色均不同。

**规则**：
1. 识别框架、标记、分隔列和精灵变体。
2. 确定目标行：框架左边缘和右边缘同行位置有相同颜色标记的行。
3. 确定目标列：框架上边缘和下边缘同列位置有相同颜色标记的列。
4. 目标位置 = 目标行 x 目标列的笛卡尔积（框架内部坐标）。
5. 对每个目标位置，读取该位置所在目标行的行标记颜色，找到左侧颜色标签匹配的精灵变体。
6. 将匹配的精灵变体（去除颜色标签像素后）以目标位置为中心放置到框架内部。后处理的位置覆盖先处理的（按目标位置从上到下、从左到右的顺序依次放置）。
7. 擦除分隔列左侧的所有精灵变体（变为背景(0)），保留分隔列本身。

**关键洞察**：同一个基础精灵在不同目标行以不同旋转朝向出现——行标记颜色是旋转选择的密钥。仅看单个示例时，若某示例只有一个目标行，无法区分"所有位置用同一朝向"和"按行选择朝向"。
