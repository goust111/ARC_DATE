## 新题 8：双色精灵体投射与碰撞变色

**组合逻辑**：[投射](已有) + [碰撞阻挡](已有) + [色彩互换·创新：不是精灵对接色条时的固定映射，而是精灵碰撞目标对象时发生的颜色交换](创新改造) + [双色精灵体·创新：不是对接到色条，而是投射到中心对象](创新改造)

**来源原语**：投射/project(1f642eb9)、碰撞阻挡/collision_blocking(1f642eb9)、边界像素投射目标/border_projected_to_target(1f642eb9)、色彩互换/color_swap(7c66cb00)、颜色反转映射/inverted_color_mapping(7c66cb00)、双色精灵体/two_tone_sprite(7c66cb00)、目标对象/target_object(1f642eb9)、画布边界/canvas_boundary(1f642eb9)

**依赖链**：投射确定精灵体的着陆位置 → 碰撞阻挡确定停止点（精灵体边缘刚好触及目标对象） → 色彩互换在放置时将精灵体的外色与目标对象色交换。删除投射则不知道精灵去哪里；删除碰撞则精灵穿过目标；删除色彩互换则输出颜色错误。参考题 1f642eb9 只投射单像素，这里投射的是多像素双色精灵体；参考题 7c66cb00 中精灵对接色条，这里精灵投射到中心对象。

将边界上的双色精灵体沿其朝向投射到中心目标对象，在碰撞位置放置精灵并交换其外层颜色与目标对象颜色。

**输入结构**：约 14x14 网格，黑(0)背景。网格中心区域有一个青(8)的 4-连通目标对象（不规则形状，约 10~15 像素）。网格边缘区域（不必紧贴边界，但在目标对象外围）有 2~4 个双色精灵体。每个精灵体是一个 3~5 像素的 4-连通小图形，由外层色（占多数像素，构成轮廓）和内层色（占少数像素，1~2 像素，被外层包围或邻接）组成。每个精灵体的外层色互不相同，均非黑(0)非青(8)。每个精灵体与目标对象在同一行或同一列上，且两者之间的直线路径上无其他非背景像素。生成约束：精灵体沿其投射方向滑动时，其最靠近目标的像素恰好在目标对象的某个边界像素的相邻位置停下（4-邻接碰撞）；不同精灵体到达目标的不同侧面，着陆区域互不重叠。

**规则**：
1. 识别青(8)目标对象和所有双色精灵体。
2. 对每个精灵体，确定其投射方向：精灵体与目标对象共享行或共享列，投射方向为从精灵体指向目标对象的水平或垂直方向。
3. 将精灵体沿投射方向逐像素滑动，直到精灵体的任何像素与目标对象的任何像素形成 4-邻接（碰撞）。将精灵体放置在碰撞位置。
4. 放置时执行颜色互换：精灵体的外层颜色全部改为青(8)（与目标对象同色，视觉上融入目标边缘），精灵体的内层颜色改为精灵体原来的外层色。
5. 擦除精灵体原始位置的像素（变为背景(0)）。
6. 目标对象本身的像素保持不变。
7. 若多个精灵体的着陆区域有像素重叠（生成约束保证不会发生），则距目标更近的精灵体优先。

**关键洞察**：颜色互换使精灵体的外壳"融入"目标对象的颜色，而内核"显现"为原来的外壳色——最终效果是目标对象边缘长出了彩色标记点，这些标记点的颜色是精灵体投射前的外层色。需要同时理解投射机制和颜色反转才能正确重建输出。
