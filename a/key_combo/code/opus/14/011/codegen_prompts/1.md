## 新题 1：循环邻色膨胀光晕

**组合逻辑**：[膨胀](已有) + [排列顺序](已有) + [循环相邻·创新：从竖向色带间的循环改为空间对象间的循环](创新改造) + [图例映射](已有) → 光晕颜色不由自身图例决定，而由循环右邻的图例决定

**来源原语**：膨胀/dilate(5adee1b2)、排列顺序/ordering(4364c1c4)、循环相邻/cyclic_adjacent(c4d1a9ae)、图例映射/legend_mapping(5adee1b2)、空缺借邻色填充/gap_borrows_neighbor(c4d1a9ae)

**依赖链**：排列顺序确定循环邻居身份 → 循环邻居身份决定从图例中取哪个颜色 → 膨胀产生光晕区域 → 光晕区域被涂上由邻居决定的颜色；排列顺序同时作为膨胀重叠时的冲突裁决依据。删除排列顺序则无法确定谁是谁的循环邻居也无法解决重叠；删除图例则不知道对象颜色与光晕颜色的映射；删除膨胀则无光晕区域可涂。

将多个单色对象按空间顺序排成循环链，每个对象的膨胀光晕颜色取自其循环右邻在图例中的映射色，重叠区域由排序靠前者胜出。

**输入结构**：约 15x15 网格，黑(0)背景。网格左边缘有一组 2x2 色块构成的颜色图例，每个色块左列为对象色、右列为光晕色（共 3~5 组，上下排列，各组间隔至少 1 行背景）。网格其余区域散布 3~5 个单色 4-连通不规则前景对象（各 4~8 像素），每个对象的颜色恰好是某组图例的左列色。所有对象互不相邻（任意两个对象的边界框间至少隔 2 列或 2 行）。生成约束：每种对象颜色在图例中恰好出现一次；对象数量等于图例组数。

**规则**：
1. 保持所有输入像素不变（图例、对象、背景均保留）。
2. 按各对象边界框左上角的列优先、行次优先排序（列小者先；列相同则行小者先），得到唯一的从左到右顺序，编号 1, 2, ..., N。
3. 将这 N 个对象视为循环链：对象 k 的"循环右邻"是对象 (k mod N)+1。
4. 对每个对象做 1 像素膨胀：将其边界框扩大 1 格（上下左右各 1 像素，裁剪到网格边界），扩大区域中所有背景(0)像素标记为该对象的光晕候选区。
5. 每个对象的光晕颜色 = 其循环右邻的对象色在图例中对应的光晕色（即查图例右列）。
6. 按排序编号从 1 到 N 依次涂光晕：将每个对象的光晕候选区中仍为背景(0)的像素涂为该对象的光晕颜色。已被先涂的光晕或原有前景占据的像素不覆盖。
7. 图例区域的像素永远不被光晕覆盖（图例色块视为前景）。

**关键洞察**：每个对象的光晕颜色不是查自己的图例行，而是查循环右邻对象的图例行——必须先确定空间排序才能知道谁是谁的邻居，再通过邻居的颜色间接查表。
