## 新题 1：射线穿框计数染色

**组合逻辑**：[掏空](创新：使实心矩形变为可穿透框架) → [射线延伸](创新：射线穿越框架边界而非停止) → [计数](创新：统计穿越框架边界次数) → [重涂色](创新：穿越数映射为颜色)

**来源原语**：掏空/hollowing(4347f46a)、射线延伸/ray_extend(ecdecbb3)、计数/counting(e50d258f, d0f5fe59)、重涂色/recolor(ea32f347)、实心矩形/solid_rectangle(4347f46a)、控制像素/control_pixel(ecdecbb3)、内部包含/containment(4347f46a)、投射/perpendicular_cast(ecdecbb3)

**依赖链**：掏空将实心矩形变为仅保留边框的空心框架，这使得射线能穿越多层框架而不被第一个实心面挡住；射线穿越边框的次数编码了控制像素在嵌套结构中的几何深度；穿越次数再通过固定映射表决定控制像素的最终颜色。四步环环相扣——不掏空则射线无法穿透，不投射射线则无法得到穿越数，不计数则无法确定目标颜色。

将黑色背景上嵌套的蓝色实心矩形掏空为框架，然后统计每个灰色控制像素的四方向射线穿越框架边界的总次数，按穿越数重涂控制像素颜色。

**输入结构**：黑(0)背景，约15x15网格。若干蓝(1)单色实心矩形（每个至少3像素宽、3像素高），矩形之间存在嵌套关系（小矩形完全在大矩形内部），但任意两个矩形的边框像素互不共享。若干灰(5)控制像素散布在矩形外部或嵌套间隙中（控制像素与任何矩形像素不4-邻接）。生成约束：嵌套层数至少为2（即存在矩形A包含矩形B再包含矩形C的结构）；控制像素至少4个，分布在不同嵌套深度的位置。

**规则**：
1. 对每个蓝(1)实心矩形执行掏空操作：保留其一像素宽边框，将边框严格内部的所有像素设为黑(0)。
2. 从每个灰(5)控制像素出发，向上、下、左、右四个基本方向各发射一条射线，射线沿直线前进直到离开网格边界。
3. 统计每个控制像素的四条射线穿越蓝(1)边框像素的总次数：每条射线每经过一个蓝(1)像素计为一次穿越（进入一个框架的边框算一次，离开同一框架的另一侧边框再算一次）。
4. 按穿越总数对控制像素重涂颜色：0次 → 保持灰(5)，2次 → 红(2)，4次 → 绿(3)，6次 → 黄(4)，8次及以上 → 橙(7)。
5. 蓝(1)边框像素和黑(0)背景保持不变。

**关键洞察**：掏空操作是射线能够穿透多层结构的前提——实心矩形会完全阻挡射线，而空心框架仅在边框处产生可计数的穿越事件。穿越总数直接编码了控制像素在嵌套层次中的几何深度，而这个深度信息只有在掏空之后才能通过射线投射获得。
