## 新题 6：延伸投票选取框架裁剪

**组合逻辑**：[延伸](创新：朝最近框架边延伸而非朝边缘条) → 延伸方向标记框架(涌现：延伸操作变为投票机制) → [计数](创新：计算每个框架的得票数) → [裁剪](创新：选取标准从面积最大变为得票最多) + [重涂色](保留)

**来源原语**：延伸/extend(642248e4)、朝近端扩展/toward_nearer_expand(642248e4)、控制像素/control_pixel(642248e4)、裁剪/crop(fcb5c309)、最大框决定裁切/largest_frame_crops(fcb5c309 → 创新为most_voted_frame_crops)、矩形框架/rect_frame(fcb5c309)、面积最大选取/largest_area_select(fcb5c309)、重涂色/recolor(fcb5c309)、计数/counting(e50d258f)

**依赖链**：每个控制像素向最近的矩形框架边延伸一个像素（投票），不同控制像素可能投票给不同框架 → 汇总每个框架收到的投票数 → 得票最多的框架被选中裁剪（面积仅作为平局打破条件）→ 裁剪结果中框架像素被重涂为控制像素的颜色。延伸操作的方向和投票目标无法独立于框架位置确定，计数结果无法独立于延伸结果确定，裁剪目标无法独立于计数结果确定。

红色控制像素各自朝最近的蓝色矩形框架边延伸一个像素作为"投票"，得票最多的框架被裁剪输出，裁剪结果中框架像素重涂为红色。

**输入结构**：黑(0)背景，约16x16网格。至少3个蓝(1)单像素宽矩形框架（空心矩形，仅有边框），大小各不相同（边框围成的内部面积互不相等）。若干红(2)控制像素散布在框架外部（不在任何框架的边框上或内部）。生成约束：框架互不重叠、互不嵌套；每个控制像素在至少一个基本方向上能看到某个框架的边框像素（即同行或同列存在框架边框像素）；至少存在一个框架得到的投票数严格多于其他所有框架。

**规则**：
1. 对每个红(2)控制像素，在上、下、左、右四个方向上分别寻找最近的蓝(1)框架边框像素。取四个方向中距离最近的那个方向（曼哈顿距离）。若多个方向距离相同，优先选择按顺时针顺序较早的方向（上 > 右 > 下 > 左）。
2. 在该最近方向上，将控制像素旁的一个背景像素填为红(2)（即从控制像素向该方向延伸一个像素）。被延伸像素所指向的框架获得一票。
3. 统计每个框架收到的总票数。选取得票最多的框架。若票数相同，选取边框围成内部面积最大的框架。
4. 裁剪被选中框架的边界框（包含其完整边框）。
5. 在裁剪结果中，将所有蓝(1)框架像素重涂为红(2)，其他像素不变。
6. 输出裁剪后的网格。

**关键洞察**：源题中控制像素朝近端边缘条延伸一个像素（方向由两条边缘条的距离比较决定），这里延伸方向由最近框架的位置决定——延伸操作从一个简单的距离响应变成了聚合投票机制。选取裁剪目标的标准从"面积最大"变为"得票最多"，使得输入中控制像素的分布成为决定输出的关键因素。
