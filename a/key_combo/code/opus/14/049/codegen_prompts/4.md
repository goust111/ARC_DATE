## 新题 4：排序驱动偏移阴影与镜像

**组合逻辑**：[排序/长度排名](创新：排名编码阴影偏移方向而非颜色) → [偏移阴影](创新：偏移方向由排名决定而非固定) + [镜像](创新：指示像素仅决定镜像轴，颜色由固定规则给出)

**来源原语**：排序/sorting(ea32f347)、长度排名/length_ranking(ea32f347)、排名决定颜色/rank_determines_color(ea32f347 → 创新为rank_determines_direction)、偏移阴影/offset_shadow(310f3251)、阴影像素/shadow_pixel(310f3251)、镜像/mirror(b775ac94)、指示像素/indicator_pixel(b775ac94)、邻接/adjacency(b775ac94)、细条/thin_bar(ea32f347)

**依赖链**：长度排名提供排名值 → 排名值编码为阴影偏移方向（排名1向右、排名2向下、排名3向右下），替代了源题中排名→颜色的映射 → 每根条按其排名方向生成蓝色阴影 → 指示像素确定镜像轴 → 条和阴影一起被镜像，镜像副本使用固定的绿色和黄色。排名、阴影方向、镜像轴三条信息链在输出中交汇，缺少任何一条都无法重建完整输出。

将三根不等长灰色细条按长度排名，排名决定其蓝色阴影的偏移方向，再以各条旁的红色指示像素为轴将条及其阴影一起镜像，镜像副本使用绿色条和黄色阴影。

**输入结构**：黑(0)背景，约14x16网格。恰好三根灰(5)单像素宽直条（可以是水平或竖直的），长度互不相同（如3、5、7像素）。每根条的某一侧有一个红(2)指示像素与条4-邻接（三根条的指示像素分别在条的不同侧，如一个在条的上方、一个在左方、一个在下方）。生成约束：三根条互不4-邻接且与网格边界至少间隔2像素；每根条的阴影和镜像副本不超出网格边界。

**规则**：
1. 按像素数量从多到少对三根灰(5)条排序，分别得到排名1（最长）、排名2（中等）、排名3（最短）。
2. 根据排名确定阴影偏移方向：排名1的条 → 阴影向右偏移1像素（即阴影中每个像素比原条对应像素列号+1）；排名2的条 → 阴影向下偏移1像素（行号+1）；排名3的条 → 阴影向右下偏移1像素（行号+1且列号+1）。
3. 在偏移位置绘制该条的阴影副本，颜色为蓝(1)。原条保留灰(5)不变。若阴影像素与原条像素重叠，保持灰(5)。
4. 以每根条旁的红(2)指示像素为镜像中心，将该条及其阴影一起做点对称（180度旋转）镜像：镜像后的条颜色为绿(3)，镜像后的阴影颜色为黄(4)。
5. 若镜像副本的像素与原始条/阴影像素重叠，后绘制的镜像副本覆盖之前的像素。红(2)指示像素保留不变。

**关键洞察**：长度排名在源题中直接映射为条的颜色（一步完成），这里排名映射为阴影偏移方向（改变了后续操作的几何形态）。指示像素在源题中同时决定镜像轴和副本颜色，这里只决定镜像轴（颜色由固定规则给出）。两种"属性→参数"映射相互独立但在空间上交织，构成了非平凡的推理图。
