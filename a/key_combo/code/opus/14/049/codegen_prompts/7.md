## 新题 7：异常值象限驱动印章渲染

**组合逻辑**：[相等比较 + 异常值选择](保留核心) → 异常值图案提取为印章模板(创新：异常值不直接输出而成为中间工具) → [印章渲染](创新：模板来自异常值而非预定义区域) + 标记像素定位印章(保留)

**来源原语**：异常值选择/outlier_selection(88a62173)、相等比较/equality_comparison(88a62173)、象限/quadrant(88a62173)、分隔十字/separator_cross(88a62173)、输出唯一象限/output_unique_quadrant(88a62173 → 创新为outlier_as_template)、印章渲染/stamp_rendering(65b59efc)、模板掩码/template_mask(65b59efc)、标记像素/marker_pixel(65b59efc)、编码映射/encoding_map(65b59efc)

**依赖链**：四个象限比较找到异常值 → 异常值图案成为印章模板（形状和颜色均保留）→ 模板在标记区域的指定位置被反复印章 → 输出仅包含印章结果。异常值识别是获取模板的唯一途径（模板在输入中没有额外标注），印章位置由标记像素决定，两者缺一不可。

将分隔十字分割的四个象限中的异常值图案提取为印章模板，在独立标记区域中按红色标记像素的位置重复印章该模板。

**输入结构**：约15x21网格（或21x15），分为左右两个大区域，由两列黑(0)分隔。左侧区域为约15x15，被黑(0)分隔十字（中间行和中间列全为黑(0)）分为4个等大象限。三个象限包含相同的单色图案（如蓝(1)的4-连通小图形，3~8像素），第四个象限包含不同颜色和形状的图案（如绿(3)的另一4-连通小图形）——这是异常值。右侧区域为标记区域，尺寸为象限尺寸的整数倍（如1x2个象限大小），黑(0)背景上散布若干红(2)标记像素。生成约束：异常值象限的图案完全在象限内部（不触碰分隔十字）；标记区域可被精确划分为若干与象限等大的块；至少2个块包含红(2)标记像素，至少1个块不包含。

**规则**：
1. 比较左侧区域的四个象限图案（忽略黑(0)背景，仅比较非背景像素的位置和颜色）。找到唯一不同的象限——异常值象限。
2. 提取异常值象限的非背景像素图案作为印章模板（记录每个非背景像素相对于象限左上角的行列偏移及其颜色）。
3. 将右侧标记区域划分为与象限等大的块（从左上角开始，按行列顺序切割）。
4. 对每个包含至少一个红(2)标记像素的块：在该块的对应位置上印上模板图案（按模板中记录的偏移和颜色绘制像素）。已有的红(2)标记像素被模板覆盖（若重叠）。不包含红(2)标记像素的块保持全黑(0)。
5. 输出仅为右侧标记区域（去掉左侧象限区域和分隔列）。

**关键洞察**：异常值象限在源题中被直接裁剪输出，这里变为中间产物——它是印章操作的模板来源。求解者需要先通过象限比较发现异常值（非显然步骤），再将异常值的几何结构解码为可复用的印章掩码，最后在标记区域中按激活条件应用。三步紧耦合且任何一步都无法跳过。
