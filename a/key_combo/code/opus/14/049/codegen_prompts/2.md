## 新题 2：连线围区泛洪

**组合逻辑**：[连线](保留核心：同色配对连接) + [竖线交叉优先](保留) → 线段交叉围成封闭区域(涌现结构) → [泛洪填充](创新：填充由线段围成的涌现区域) + 最近线段决定填色(创新)

**来源原语**：连线/draw_line(40853293)、同色配对/same_color_pairing(40853293)、行列对齐/row_col_align(40853293)、竖线交叉优先/vertical_priority_at_cross(40853293)、泛洪填充/flood_fill(b9e38dc0)、填充种子/fill_seed(b9e38dc0)、线段/line_segment(40853293)

**依赖链**：连线操作将分散的标记像素对连成线段，线段在网格上交叉围成封闭区域——这些区域是连线操作的涌现产物，在连线前不存在。泛洪填充利用这些涌现区域作为边界，而填充颜色由种子到最近线段的距离决定。交叉优先规则既影响交叉点处的可见颜色，又隐含地影响了区域的边界判定。

连接同色标记像素对形成交叉线段，线段围成的封闭区域从灰色种子泛洪填充，填充色取距种子最近的线段颜色。

**输入结构**：黑(0)背景，约14x14网格。至少4对前景色标记像素，每种颜色恰好出现两次，两个同色像素共享行或列。使用的颜色包括蓝(1)、红(2)、绿(3)、黄(4)等（每对一种颜色）。若干灰(5)种子像素分别位于连线后将被线段围成的封闭区域内部。生成约束：标记像素对的连线必须产生至少3个交叉点；交叉点与线段共同围成至少2个完全封闭的区域（四面均被线段包围，不接触网格边界）；每个封闭区域内恰好有一个灰(5)种子像素；种子不位于任何线段上；至少存在两个封闭区域，其最近线段颜色不同。

**规则**：
1. 用一像素宽直线连接每对同色标记像素（包含两个端点），线段颜色为该对标记的颜色。
2. 当水平线段和竖直线段在同一像素处交叉时，该像素显示竖直线段的颜色（竖线优先）。
3. 线段在网格上将背景划分为若干区域。找到所有完全被线段像素包围的封闭区域（区域内任何像素的4-连通路径均无法在不经过线段像素的情况下到达网格边界）。
4. 对每个封闭区域内的灰(5)种子像素，计算种子到该区域所有边界线段像素的曼哈顿距离，取最小值对应的线段颜色作为该区域的填充色。若最近距离对应多条不同颜色的线段，取其中竖直线段的颜色（与交叉优先规则一致）。
5. 从种子像素开始，用确定的填充色泛洪填充整个封闭区域（填充在遇到线段像素或网格边界时停止）。种子像素被填充色覆盖。
6. 非封闭区域（可达网格边界的区域）内的灰(5)像素保持不变。线段像素保持不变。

**关键洞察**：封闭区域是连线操作的涌现产物——线段交叉在网格上自然围成了这些区域，它们在输入中不存在任何对应结构。填充色的决定规则与交叉优先规则使用相同的"竖直优先"逻辑，形成统一的非显然偏好，需要对比多个示例才能发现这种一致性。
