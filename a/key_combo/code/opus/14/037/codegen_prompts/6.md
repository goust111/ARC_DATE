## 新题 6：去噪与补周期的相互约束

**组合逻辑**：[对角噪声 + 擦除](已有) ⇄ [周期瓦片 + 最小周期推断填补](已有)（双向约束：去噪需要周期信息区分噪声与图案，补周期需要去噪后的干净样本）

**来源原语**：对角噪声(diagonal_noise)·擦除(erase)·忽略干扰项(ignore_distractors)·间隙长度限制(gap_length_constraint)·补线(line_completion) ← 7b80bb43；周期瓦片(periodic_tile)·缺失单元(missing_cell)·最小周期推断填补(smallest_period_inferred_fill) ← 29ec7d0e

**依赖链**：画布同时存在对角噪声和周期缺失 → 噪声像素可能恰好位于周期位置上（看似合法）→ 判断某像素是噪声还是周期图案需要同时考虑其连通性（是否仅有对角邻居）和周期一致性（是否符合最小周期）→ 两个约束必须联合求解

在一个既有对角阶梯噪声又有周期性缺失的网格上，同时去除噪声并补全周期图案，两个任务相互依赖。

**输入结构**：约 14x14 的黑(0)背景网格。存在一种前景色（如蓝(1)）构成的周期图案，最小周期为 p（水平和垂直周期相同，p 取 3 或 4）。该周期图案的部分单元被删除（显示为黑(0)），形成"缺失单元"。此外，有若干蓝(1)像素构成 45 度对角阶梯链——每个对角噪声像素与其他蓝(1)像素仅有对角邻接（8-连通但 4-断连）。关键复杂性：某些对角噪声像素恰好位于 (row mod p, col mod p) 与周期图案一致的位置上，表面上看与周期图案兼容。生成约束：真实的周期图案瓦片中，每个非背景位置至少在网格中出现 2 次作为干净样本（无对角邻接的孤立噪声），确保有足够信息进行消歧。

**规则**：
1. 识别所有仅有对角前景邻居、没有任何正交前景邻居的蓝(1)像素，标记为"疑似噪声"。
2. 对剩余的蓝(1)像素（非疑似噪声），推断最小周期 p：找到最小的 p 使得所有剩余蓝(1)像素在 (row mod p, col mod p) 位置上一致。
3. 用推断出的周期 p 反过来验证疑似噪声：若某个疑似噪声像素的 (row mod p, col mod p) 位置在周期瓦片中应为前景色，且该像素至少有一个正交方向上的相邻周期位置也有前景像素（只是因为缺失而暂时不可见），则该像素是被误判的真实图案像素，不应删除。否则确认为噪声，删除。
4. 删除确认的噪声像素后，补全所有缺失单元：对每个黑(0)位置，若 (row mod p, col mod p) 在周期瓦片中应为前景色，则填入蓝(1)。

**关键洞察**：去噪和补周期不是先后两步，而是相互约束的联合推理——仅靠连通性无法区分恰好落在周期位置的噪声，仅靠周期性无法区分落在周期位置的噪声与真正的缺失单元；必须同时使用两个约束才能消歧。

The grid is a rectangular periodic color table with black 0 cells as missing entries; each position in the true repeating tile is visible at least once.

Rule

Key insight
The nonzero pixels are samples of one complete repeating tile, so the repair follows from periodicity rather than from numeric color ordering.
