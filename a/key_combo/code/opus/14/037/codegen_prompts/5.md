## 新题 5：突起朝向的条件分叉——填充与射线的互斥选择

**组合逻辑**：[叶状突起 + 突起定行列](已有) → 条件分叉{水平突起 → [填充 + 内外色互换](创新组合)；垂直突起 → [射线延伸 + 重涂色](创新组合)} → 两条分支的结果在同一画布上叠加

**来源原语**：叶状突起(leaf_protrusion)·突起定行列(leaf_selects_row_col)·双色矩形(bicolor_rectangle)·内外色互换延伸(swap_extend) ← f1cefba8；填充(fill)·空心矩形(hollow_rectangle)·孔洞在框内(hole_inside_frame) ← e73095fd；射线延伸(ray_extend) ← 256b0a75

**依赖链**：突起方向判断 → 触发完全不同的操作分支 → 两个分支修改同一画布的不同区域，但射线可能穿过已填充的矩形内部，需要分支间协调优先级

对每个空心矩形的突起方向做分叉：水平突起触发内部填充并反转内外色，垂直突起触发从突起端射出射线并沿途重涂。

**输入结构**：约 16x16 的黑(0)背景网格。包含 3~4 个互不相邻的空心矩形（每个矩形由单色轮廓围成，内部为黑(0)，轮廓宽度 1 像素，矩形外尺寸 4x4 至 6x6 不等）。每个矩形使用不同的轮廓色（从蓝(1)、红(2)、绿(3)、黄(4)中选取）。每个矩形恰好有一个单像素叶状突起——从轮廓某条边的中点向外延伸一个像素，颜色为橙(7)。突起方向：若突起从矩形的左边或右边伸出则为"水平突起"；若从上边或下边伸出则为"垂直突起"。生成约束：同一行/列上不会有两个矩形的垂直/水平突起同时射线方向相对（避免射线冲突歧义）。

**规则**：
1. 对每个空心矩形，找到其橙(7)突起像素，判断突起方向（突起相对于轮廓的朝向）。
2. **水平突起分支**：将该矩形内部（轮廓围成的黑(0)区域）填充为橙(7)，同时将该矩形的轮廓色改为黑(0)（内外色互换：原来轮廓有色内部黑，变为轮廓黑内部有色）。删除突起像素。
3. **垂直突起分支**：保留矩形不变。从突起像素位置沿突起朝向发射一条射线，射线颜色为该矩形的轮廓色，逐格延伸直到网格边缘或遇到任何非黑(0)像素（不覆盖终点像素）。删除原始突起像素，射线取代之。
4. 冲突处理：若垂直分支的射线穿过已被水平分支填充的矩形内部区域，射线像素覆盖填充色（射线优先）。处理顺序：先执行所有水平分支的填充，再执行所有垂直分支的射线。

**关键洞察**：同一种结构特征（突起）在不同朝向下触发完全不同的操作——这不是参数化的同一操作，而是真正的逻辑分叉；两个分支的结果在空间上可能交互（射线穿过填充区），需要跨分支的优先级规则。
