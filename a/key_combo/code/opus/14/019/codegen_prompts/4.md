## 新题 4：双粒子走廊追踪与交叉环形涂色

**组合逻辑**：[路径追踪(path_trace)] x 2（两个粒子独立追踪） → 交叉检测（创新：从静态行列交叉变为动态路径交叉） → [描边(outline)/重涂色(recolor)](创新：环形涂色的中心色由路径长度比较决定)

**来源原语**：路径追踪(path_trace)+粒子(particle)+走廊(corridor)+平行色条(parallel_colored_bar)+同色夹道(same_color_flanking)+碰撞转向(collision_turn) from 9bbf930d、描边(outline)+交叉点(crossing_point)+交叉邻域环涂色(crossing_ring_recolor) from 67a423a3、重涂色(recolor) from 67a423a3

**依赖链**：走廊结构决定每个粒子的路径几何；两条路径的几何共同决定交叉位置；交叉位置触发环形涂色；路径长度比较决定交叉格中心色。这是一个分支-汇合结构：两个独立的路径追踪在交叉检测处汇合。

两个不同颜色的粒子在走廊网格中追踪各自路径，路径交叉处画黄色环，交叉格保留路径更长的粒子颜色。

**输入结构**：约 15x15 的网格，背景为橙(7)。偶数行上有彩色壁条（使用蓝(1)、绿(3)等颜色，每行壁条单色），壁条覆盖偶数行的大部分格但留有若干缺口（形成走廊入口/出口）。奇数行为走廊通道（大部分为橙(7)背景格）。一个品红(6)粒子和一个红(2)粒子分别位于第 0 列的两个不同奇数行上。生成约束：两粒子的路径在走廊中恰好交叉一次（即恰好有一个格被两条路径都经过）；走廊结构保证每个粒子在每个转弯处有唯一可转方向；交叉格的切比雪夫距离 1 邻域不超出网格边界。

**规则**：
1. 每个粒子从起始位置向右移动。经过的每个橙(7)背景格替换为该粒子的颜色（品红(6)或红(2)），形成轨迹。
2. 当粒子的下一格为非橙非背景色（壁条色）时，粒子无法前进，转向 90 度进入垂直方向的走廊：检查上方和下方，选择有橙(7)背景格且该格两侧（同行左右）为同色壁条所夹的方向。沿该方向前进直到再次被壁条阻挡，再次转弯进入水平走廊。到达网格边缘时停止。
3. 两个粒子的轨迹独立计算——一个粒子的轨迹不构成另一个粒子的障碍。
4. 轨迹计算完成后，找到所有交叉格（同一格被两条轨迹都经过的位置）。
5. 对每个交叉格，计算两个粒子从各自起点到该交叉格经过的格数（含起点和交叉格本身）。交叉格的颜色取路径更长的粒子的颜色。
6. 以每个交叉格为中心，对其切比雪夫距离 1 的 8 个邻居格执行：若邻居为粒子轨迹色（品红(6)或红(2)）或背景色（橙(7)），替换为黄(4)；若为壁条色则保持不变。

**关键洞察**：交叉格的中心色不取决于粒子的起始位置远近（欧氏距离），而取决于沿走廊实际行走的路径长度——一个起点近但走了很多弯的粒子可能反而路径更长。必须完整追踪两条路径并比较走廊长度，才能确定交叉格颜色。
