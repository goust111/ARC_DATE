## 新题 7：对称补全后逆向展开为色条

**组合逻辑**：[对称补全(symmetry_completion)](已有) → 同心层识别（创新：同心结构只有在补全后才能被识别） → [展开嵌套(unfold_nest)](创新：作为参考题 15 的逆操作使用，从嵌套结构提取色条而非从色条构建嵌套)

**来源原语**：对称补全(symmetry_completion)+精灵体(sprite)+对称图案(symmetric_pattern)+中心对齐(center_alignment)+角落补全四重对称(corners_to_fourfold_symmetry) from 4290ef0e、展开嵌套(unfold_nest)+块单元(block_cell)+象限(quadrant)+嵌套层(nested_layer)+块序映射层序(block_order_maps_layer)+逆序读取(reverse_order_read) from 8fff9e47、同心方形层(concentric_square_layer)+由外到内嵌套(outside_in_nesting) from 3ee1011a

**依赖链**：角落片段必须先完成四重对称补全才能重建完整图案；完整图案才呈现出同心方形层结构（不补全则层数和颜色分布不确定）；同心层结构被逆向展开为 2x2 块序列（逆序读取：内层先、外层后）。对称补全的输出是展开操作的输入前提，不可跳过。

从散布的角落片段补全四重对称同心图案，然后按内到外顺序将各层象限色拆解为 2x2 色块竖条。

**输入结构**：约 11x11 的黑(0)背景网格。网格中散布若干彩色像素组，每种颜色形成一个"角-L"形片段——占据某个象限角落的 L 形区域（如一个 3 像素的 L 形，覆盖角落的一行一列交汇处及其各延伸 1 像素）。使用 3-5 种非黑颜色（如蓝(1)、绿(3)、黄(4)、灰(5)、青(8)）。不同颜色的片段出现在不同角落（左上、右上、左下、右下），每种颜色至少有一个角落的片段可见。片段的尺寸隐含了该颜色对应的同心层的大小。生成约束：补全后所有颜色恰好形成一个以网格中心为中心的同心方形结构，共 N 层（3 <= N <= 5）；外层到内层尺寸递减；重叠区域内层覆盖外层；每种颜色对应唯一一层。

**规则**：
1. 对每种颜色，将其可见的角-L 片段反射到所有四个象限角落，完成四重对称。反射以网格中心为对称中心，对每个可见片段同时做水平和垂直镜像到其他三个象限。
2. 将所有补全后的颜色层叠加到同一 11x11 画布上，以网格中心对齐。当多层重叠时，边界框更小的层（更内层）覆盖更大的层（更外层）。
3. 识别叠加后的同心方形结构的各层，从外到内编号 1, 2, ..., N。
4. 对每一层，提取其四个象限的代表色——该层环形区域在左上象限取 (top, left) 角像素色、右上象限取 (top, right) 角像素色、左下象限取 (bottom, left) 角像素色、右下象限取 (bottom, right) 角像素色（由于四重对称补全，同一层四个象限颜色相同）。
5. 将每层的四个象限色打包为一个 2x2 块（左上象限色 → 块 (0,0)、右上象限色 → 块 (0,1)、左下象限色 → 块 (1,0)、右下象限色 → 块 (1,1)）。
6. 按从内层到外层的顺序（第 N 层在最上方，第 1 层在最下方）纵向排列这些 2x2 块，形成一个 4 列宽、2N 行高的竖条。

**关键洞察**：这是参考题 15（将色条折叠为嵌套象限）的逆过程，但输入不是完整的嵌套图案而是残缺的角落片段。求解者必须先识别对称补全规则重建完整的同心结构，再识别逆向展开规则。两步规则各自独立不可解——不补全则层数和颜色不确定，不知道展开规则则输出格式不确定。
