## 新题 1：错切后周期填色

**组合逻辑**：[错切(shear)] → [周期填充(periodic_fill)](创新：周期填充的作用域被限定在错切产生的空隙内，而非整行/整列) → [擦除(erase)](清除标记)

**来源原语**：错切(shear) from 3cd86f4f、周期填充(periodic_fill)+周期步长(periodic_step)+同余对齐(modular_alignment) from 16de56c4、边界点(boundary_dot)+伴随点(companion_dot) from 16de56c4、行偏移递变(row_offset_progress) from 3cd86f4f

**依赖链**：错切决定哪些单元格被腾空（形成可填充的空隙区域）；红标记决定周期步长；绿标记决定填充起点和颜色；空隙范围约束了周期填充的作用域。三者缺一则输出不确定。

将矩形色块错切为平行四边形，用标记像素编码的周期模式填补错切产生的空隙。

**输入结构**：约 12x15 的黑(0)背景网格。网格中部有一个蓝(1)实心矩形色块（约 6 行 x 8 列）。在蓝色块所覆盖的某些行上（色块外部），每行有恰好两个红(2)标记像素和一个绿(3)标记像素，均位于蓝色块左侧或右侧的背景区域中。不同行的红标记间距可能不同。不含红/绿标记的行不执行周期填充。生成约束：红标记和绿标记仅出现在蓝色块覆盖的行上；每行最多一对红标记和一个绿标记；绿标记的列位置落在蓝色块错切前覆盖的列区间内。

**规则**：
1. 对蓝色块执行下-左错切：将色块的第 r 行（r 从 0 开始，0 为色块最上行）向左平移 r 列。放置在宽度为 W+H-1 的画布上（W 为原矩形宽度，H 为原矩形高度），画布左上角与原矩形左上角对齐后再左移 H-1 列。超出网格左边界的像素丢弃；原矩形中因平移而空出的列位置变为黑(0)。
2. 对于每个包含两个红(2)标记的行，计算步长 step = 两个红标记之间的列间距绝对值。
3. 以该行绿(3)标记的列坐标为起始列 c0，在该行中从 c0 开始，每隔 step 列放置一个绿(3)像素（即列坐标 c0, c0+step, c0+2*step, ...），但仅填充同时满足以下两个条件的格：(a) 该格当前为黑(0)；(b) 该格的列坐标落在错切前蓝色块所覆盖但错切后变为黑(0)的列区间内（即因错切腾出的空隙列）。
4. 删除所有红(2)标记像素（替换为黑(0)）。绿(3)标记像素保留在输出中。

**关键洞察**：周期填充仅作用于错切产生的空隙区域，而空隙宽度随行号递增（第 r 行空隙宽度为 r），因此即使相邻行使用同样的周期步长，填充出的绿像素数量也随行递增——需要同时理解错切的行偏移递变和周期的模对齐才能确定输出。
