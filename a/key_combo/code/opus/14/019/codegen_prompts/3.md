## 新题 3：按面积排序后按秩旋转拼接

**组合逻辑**：[裁剪(crop)] → [计数(counting)](创新：计数对象为像素面积，作为排序键) → [排序(sorting)] → [旋转(rotate)](创新：旋转角度由排序秩决定而非自身属性) → [拼接(pack)]

**来源原语**：裁剪(crop)+拼接(pack) from 50aad11f、排序(sorting)+按长度降序(desc_segment_length) from 3ee1011a（将"长度"替换为"面积"）、旋转(rotate)+整体半周旋转(half_turn_rotation) from 3c9b0459（从固定 180 度改为排序秩驱动的可变角度）、顺序一一对应(order_correspondence) from 9b365c51

**依赖链**：像素面积决定排序位置；排序位置决定旋转角度（第 k 个旋转 (k-1)x90 度）；旋转改变图形外观和边界框尺寸；拼接顺序也由排序决定。某个图形的最终朝向取决于它在所有图形中的面积排名，而非图形自身可见属性。

按像素面积对多个不规则图形排序，排名决定旋转角度，最后按序裁剪拼接。

**输入结构**：约 18x18 的黑(0)背景网格。含 4 个分离的单色 4-连通前景图形，每个使用不同颜色（如蓝(1)、红(2)、绿(3)、黄(4)）。每个图形由 3-8 个像素组成，形态不规则（非正方形、非对称），保证 90 度旋转后视觉上可区分于原始朝向。各图形之间至少间隔 3 个背景像素。生成约束：各图形的像素数量互不相同；每个图形的边界框为非正方形矩形（保证旋转后边界框尺寸变化可观察）。

**规则**：
1. 将每个图形裁剪到其最小边界框（框内非该图形的像素填黑(0)）。
2. 统计每个图形的像素数量（非黑像素计数）。
3. 按像素数量升序排列所有图形。
4. 对排序后的第 k 个图形（k 从 1 开始），以其边界框为单位执行顺时针旋转 (k-1) x 90 度。旋转操作：90 度旋转将 (r, c) 映射到 (c, H-1-r)（H 为旋转前高度），边界框尺寸相应从 HxW 变为 WxH。
5. 将旋转后的图形从左到右拼接，相邻图形之间插入 1 列黑(0)分隔符。垂直方向顶部对齐，较矮的图形底部以黑(0)补齐至最高图形的高度。

**关键洞察**：旋转角度由排序排名决定，而非图形自身的任何几何属性——必须先计算所有图形的面积并比较排名，才能确定任何一个图形的旋转量。仅看单个示例可能无法区分"按面积排序"和"按左上角位置排序"等其他排序规则，需要对比多个示例中面积排名与旋转量的一致性。

6. 若规则有多个分支，生成器不能长期固定成一个分支；应让分支在随机样例中合理出现。分支概率不必平均——难以发现的隐蔽分支（如少数情况下才触发的特殊规则）应适当提高出现概率，确保在 3 个训练示例中至少出现一次，否则求解者无法归纳该规则。对于颜色映射类规则，确保 2 个左右的示例即可覆盖所有映射关系（每种颜色→颜色的映射至少在某个示例中出现过）。
