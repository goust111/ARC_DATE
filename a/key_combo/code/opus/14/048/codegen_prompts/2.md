## 新题 2：空心框填充后桥接

**组合逻辑**：[hollow_rectangle + erase + fill](来自d5d6de2d，创新：填充色取原边框色而非统一颜色) → [connect + same_color_pair + shortest_gap_first](来自f3b10344，创新：桥接对象是填充操作产生的矩形而非输入中直接可见的矩形)

**来源原语**：hollow_rectangle, frame_encloses_interior, erase, fill, interior_recolor (d5d6de2d)；solid_rect, same_color_pair, bridge_bar, facing_gap, shortest_gap_first, connect (f3b10344)

**依赖链**：填充操作将空心框转化为实心矩形并消除边框，从而创造出桥接操作的输入对象。桥接的目标、颜色和候选路径全部由填充步骤的结果决定——求解者无法直接从输入中的空心框形态推断桥接模式，必须先在脑中执行填充变换。

擦除空心矩形框的边框，将每个框的封闭内部填充为该框的边框色，然后用青(8)桥接同色的填充矩形。

**输入结构**：
- 网格约 15x15~20x20，黑(0)背景。
- 4~6 个一像素厚的空心矩形框，每个至少 4x4（确保有非空内部）。
- 框的颜色从 {蓝(1), 红(2), 黄(4), 品红(6)} 中选取，每种颜色恰好出现 2 个框（构成可桥接的配对）。
- 青(8)在输入中不出现。
- 同色的两个框在水平或垂直方向上有至少 3 行/列的边界框跨度重叠，且重叠方向的间隙中全为背景色。
- 框之间不嵌套、不相交、不相邻。
- 生成约束：不同颜色对的间隙方向可以不同（有的水平配对，有的垂直配对），确保求解者不会误以为方向固定。

**规则**：
1. 对每个空心矩形框，将其严格内部（不含边框像素）的所有黑(0)像素填充为该框的边框颜色。
2. 将所有原边框像素擦除为黑(0)。此时网格上出现若干实心彩色矩形（尺寸=原框内部尺寸）。
3. 对每对同色实心矩形，找到它们在行跨度或列跨度上重叠至少 3 行/列的方向（水平或垂直）。
4. 确定重叠的行/列范围，两端各收缩 1 行/列。
5. 在收缩后的范围内，用青(8)填充两矩形之间所有间隙中的背景像素。
6. 若某对同色矩形在水平和垂直方向都有有效重叠（均 >= 3），选间隙像素数更少的方向进行桥接。

**关键洞察**：填充操作不是最终目的而是中间步骤——它将空心框（内部为背景色）转换为可配对的实心块，桥接作用于这些"被创造出来的"中间对象。输出中既看不到原始框边界也看不到填充的中间态，只剩下实心块加桥接条。
