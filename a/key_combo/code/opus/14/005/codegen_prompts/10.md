## 新题 10：虚线条纹的同心框架构建

**组合逻辑**：[嵌套包裹/条高决定框厚](源自 45a5af55，框厚来自条纹高度) + [填充/单像素间隙补填](创新：虚线条纹的间隙模式转移到 2D 框架的周长上) + [擦除](源自 f76d97a5，间隙位置在框架上留空)

**来源原语**：嵌套包裹/nested_wrapping(45a5af55), 填充/fill(a699fb00), 色条/color_stripe(45a5af55), 同心正方形层/concentric_square_frame(45a5af55), 逐层构建/layer_by_layer_build(45a5af55), 条高决定框厚/stripe_height_as_thickness(45a5af55), 虚线段/dashed_segment(a699fb00), 单像素间隙补填/single_gap_filled(a699fb00), 邻接/adjacency(a699fb00)

**依赖链**：条纹高度决定框架层厚度 → 条纹是实心还是虚线决定对应框架层的填充模式 → 虚线间隙的位置模式沿框架周长映射为周期性缺口。条纹的几何属性（高度）和内部模式（实心/虚线）分别控制框架的不同特征。

从水平条纹自下而上构建同心正方形框架，实心条纹产生完整框架层，虚线条纹产生带周期性缺口的框架层。

**输入结构**：约 8x15 的网格（宽大于高）。自上而下堆叠 4~6 条横跨全宽的水平条纹，颜色各不相同（从前景色中选取），高度 1~3 行。条纹分两种：实心条纹（整行全为该颜色）和虚线条纹（该颜色像素与黑(0)像素在行内交替排列，间隔恰好 1 像素）。同一条纹内所有行的模式相同（若虚线则每行都是虚线，位相一致）。条纹之间无间距直接堆叠。生成约束：至少有一条实心条纹和一条虚线条纹；条纹颜色互不相同。

**规则**：
1. 从下到上读取条纹。最下方条纹为最内层，最上方为最外层。
2. 最内层条纹构成中心实心正方形，边长 = 该条纹高度（行数）。若该条纹为虚线，中心正方形也按虚线模式局部留空（按行优先顺序遍历正方形像素，虚线条纹第一行的着色/留空交替模式循环应用于正方形所有像素）。
3. 每个后续条纹在当前形状外包裹一层正方形框架，厚度 = 该条纹高度。
4. 实心条纹对应的框架层：所有像素填充为该条纹颜色。
5. 虚线条纹对应的框架层：从框架左上角开始，沿框架周长（上边从左到右、右边从上到下、下边从右到左、左边从下到上）顺序排列像素。按虚线条纹第一行的着色/留空交替模式（着色像素→填充该色，黑像素→留黑(0)）循环映射到周长上的每个径向位置。同一径向位置上框架的所有厚度层像素状态一致（全填或全空）。
6. 输出尺寸由所有条纹高度之和决定：边长 = 2 x (所有高度之和) - 最内层高度。

**关键洞察**：虚线条纹的 1D 交替间隙模式并非直接"缩放"到 2D 框架的每一行/列，而是沿框架周长重新映射——这种 1D 到 2D 的拓扑变换需要理解周长遍历顺序。仅看单个示例无法区分"按行填充"和"沿周长填充"的差异。
