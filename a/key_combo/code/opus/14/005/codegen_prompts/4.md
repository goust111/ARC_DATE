## 新题 4：十字双功能的对称补全与象限着色

**组合逻辑**：[裁剪/边框](源自 77fdfe62，保留内部) + [对称补全/双轴对称](源自 60d73be6，十字轴线同时担任分区轴) + [重涂色/角标色定象限](源自 77fdfe62，创新为对称后再着色)

**来源原语**：裁剪/crop(77fdfe62), 对称补全/symmetry_complete(60d73be6), 重涂色/recolor(77fdfe62), 边框/frame(77fdfe62), 十字轴线/cross_axis(60d73be6), 角标像素/corner_pixel(77fdfe62), 稀疏标记/sparse_marker(60d73be6), 象限/quadrant(77fdfe62), 双轴对称/biaxial_symmetry(60d73be6), 四象限镜像填充/quadrant_mirror(60d73be6), 角标色定象限涂色/corner_sets_quadrant(77fdfe62)

**依赖链**：裁剪获得内部区域 → 十字轴线既是对称轴又是象限分界 → 对称补全确定所有标记位置 → 象限归属决定每个标记的最终颜色。十字的双重身份（对称轴+分区线）使三步紧耦合：对称补全使用十字的几何位置，着色使用十字划分出的象限归属。

裁剪出框内区域后，以内部十字为对称轴将稀疏标记反射到四个象限，再按角标颜色对每个象限的标记统一着色。

**输入结构**：约 17x17 的网格。一个灰(5)单色边框（两条水平满行线 + 两条垂直满列线构成矩形框）。框的四个对角外角各有一个前景色像素（四种不同颜色，从{蓝(1), 红(2), 绿(3), 黄(4), 品红(6), 橙(7)}中选取），作为象限图例。框内区域约 13x13：包含一个由栗(9)色构成的十字（一整行 + 一整列的栗色像素），将内部分为四个象限。在某一个象限（如左上象限）中散布 2~4 个白色... 不对，ARC 没有白色。在某一个象限中散布 2~4 个青(8)标记像素，其余三个象限无标记。生成约束：标记不接触十字轴线；十字轴线恰好在内部区域的中间行和中间列（保证四象限等大）。

**规则**：
1. 裁剪掉灰(5)边框及其外部，输出仅包含框内矩形区域（含十字轴线）。
2. 识别栗(9)色十字（内部的完整行和完整列）。以该十字为双对称轴，将每个青(8)标记像素反射到另外三个象限的对应位置（跨行反射、跨列反射、跨两轴反射），共得到最多 4 倍的标记。
3. 根据标记所在象限，将其重涂为对应的角标颜色：左上象限 → 框左上外角色，右上象限 → 框右上外角色，左下象限 → 框左下外角色，右下象限 → 框右下外角色。
4. 十字轴线的栗(9)色像素保留不变。背景像素（黑(0)）保留不变。
5. 框外的四个角标像素不出现在输出中（已被裁剪）。

**关键洞察**：栗色十字不是普通装饰——它同时担任对称反射的几何轴和象限划分的逻辑边界。仅凭单个示例无法区分"按角标色直接放置标记"和"先反射再按象限着色"，必须对比多个示例（标记在不同象限、不同位置）才能归纳出双重机制。

1. `main(grid)` 必须实现新题描述中的确定性转换规则，不能只识别 `generate_input()` 的固定模板。禁止不同的input网格输出相同的output网格。
2. `generate_input()` 必须随机生成多样样例，不能固定死。随机维度应覆盖：网格大小、对象数量、位置、颜色、方向、形状参数或关键分支。注意若描述中存在若干，需实现而不是只有单个，包括object或者对应关系等等。且若涉及到最短路径，则输入网格中必涉及到多条路径，对选择造成干扰。

6. 若规则有多个分支，生成器不能长期固定成一个分支；应让分支在随机样例中合理出现。分支概率不必平均——难以发现的隐蔽分支（如少数情况下才触发的特殊规则）应适当提高出现概率，确保在 3 个训练示例中至少出现一次，否则求解者无法归纳该规则。对于颜色映射类规则，确保 2 个左右的示例即可覆盖所有映射关系（每种颜色→颜色的映射至少在某个示例中出现过）。
