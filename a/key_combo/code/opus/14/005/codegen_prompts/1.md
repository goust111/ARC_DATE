## 新题 1：主干选通虚线补填

**组合逻辑**：[连线/连接到主干](源自 bf89d739，改造为空间选通器) + [填充/单像素间隙补填](源自 a699fb00，触发条件由主干掩码限定) + [擦除](源自 f76d97a5，清除非选通区域)

**来源原语**：连线/connect_to_spine(bf89d739), 填充/single_gap_filled(a699fb00), 掩码决定保留/mask_determines_keep(f76d97a5), 虚线段/dashed_segment(a699fb00), 控制像素/control_pixel(bf89d739), 主干线段/spine_segment(bf89d739)

**依赖链**：主干构建确定绿色(3)线段的空间位置 → 绿色线段充当空间掩码，限定哪些虚线间隙有资格被补填 → 未被掩码覆盖的间隙不补填。删除主干构建则无法确定掩码位置；删除间隙补填则主干无用武之地。

在黑色背景上，红色控制像素通过正交线段连接到主干，所形成的绿色路径网络选通蓝色虚线中哪些间隙被补填为红色。

**输入结构**：约 15x18 的黑(0)背景网格。含 4~6 个红(2)像素，其中恰好两个共享同一行或同一列（构成主干对）。另有 3~5 条水平蓝(1)虚线段，每条由蓝像素与单像素黑间隙交替组成，长度 5~11 像素，分布在网格不同行。虚线段之间不相邻（行间距至少 2）。非主干红像素分布在主干的垂直跨度范围内（若主干水平则在主干列跨度内），保证每个非主干红像素到主干有无阻碍的正交路径。生成约束：绿色连接线段（尚未绘制）会穿过某些虚线间隙所在的行列交叉点，但不会穿过蓝色像素本身。

**规则**：
1. 找到共享同一行或同一列的两个红(2)像素，将它们之间的黑(0)像素涂绿(3)，两端红像素保持红色不变，形成主干线段。
2. 对每个非主干红像素，沿垂直于主干的方向绘制绿(3)线段直到接触主干线段所在的行或列（不覆盖主干线段上的绿像素——那些已经是绿色；也不覆盖端点的红像素）。连接线段只覆盖黑(0)像素。
3. 检查每条蓝(1)虚线段中的每个单像素黑间隙：若该间隙像素恰好位于某条绿(3)线段（主干或连接段）所经过的列（若主干水平）或行（若主干垂直）上，则将该间隙涂红(2)。
4. 不满足上述条件的间隙保持黑(0)不变。
5. 所有绿(3)线段、红(2)像素、蓝(1)像素均保留在输出中。

**关键洞察**：绿色主干网络不是装饰线条，而是空间选通掩码——虚线间隙是否补填取决于它与主干网络的列（或行）对齐关系，必须先完成主干构建才能判定补填位置。
