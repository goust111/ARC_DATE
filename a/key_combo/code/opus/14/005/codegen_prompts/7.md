## 新题 7：直角路径生成控制精灵并像素放大

**组合逻辑**：[连线/直角路径](源自 d4a91cb9，路径充当控制精灵的形状生成器) + [像素放大/像素展开为瓦片](源自 bf45cf4b，将路径生成的掩码逐像素展开)

**来源原语**：连线/draw_line(d4a91cb9), 像素放大/pixel_upscale(bf45cf4b), 端点像素/endpoint_pixel(d4a91cb9), 直角路径/right_angle_path(d4a91cb9), 控制精灵/control_sprite(bf45cf4b), 多色瓦片/polychrome_tile(bf45cf4b), 行列交汇/row_col_intersection(d4a91cb9), 拐角由终点列定/corner_at_target_col(d4a91cb9), 掩码映射/mask_mapping(bf45cf4b), 像素展开为瓦片/filled_pixel_expands_to_tile(bf45cf4b)

**依赖链**：端点位置决定直角路径形状 → 路径占用的像素构成二值控制掩码 → 掩码中每个填充像素展开为多色瓦片的完整副本、每个空白像素展开为背景区域。路径几何直接决定了放大后图案的空间结构——改变端点位置就改变输出形状。

从红色端点到青色端点绘制黄色直角路径，将路径及端点构成的边界框作为二值控制精灵，按多色瓦片逐像素放大输出。

**输入结构**：约 12x12 的黑(0)背景网格。含一个红(2)像素和一个青(8)像素，二者不在同行也不在同列。另有一个独立的多色正方形瓦片（如 3x3 或 4x4），使用 2~3 种非黑前景色（如绿(3)、蓝(1)、黄(4)），放置在远离两个端点的区域。三个元素（红像素、青像素、瓦片）互不相邻。生成约束：红像素与青像素的行差和列差均至少为 2（保证路径有可见的 L 形转折）；瓦片不与路径区域重叠。

**规则**：
1. 从红(2)像素出发，沿水平方向画黄(4)像素直到到达青(8)像素所在列，然后沿垂直方向画黄(4)像素直到到达青(8)像素所在行。红和青端点像素保持原色。
2. 计算路径（含两个端点）的边界框。在该边界框内构建二值掩码：路径像素（黄、红、青）= 填充，黑色背景 = 空白。
3. 以该掩码为控制精灵，以输入中的多色瓦片为图块，执行像素放大：掩码中每个填充像素替换为瓦片的完整副本，每个空白像素替换为与瓦片同尺寸的黑(0)区域。
4. 输出网格尺寸 = (边界框高 x 瓦片高) 行 x (边界框宽 x 瓦片宽) 列。输入中的端点颜色和路径颜色不保留在输出中——一切填充位置统一展开为瓦片。

**关键洞察**：直角路径不是最终输出的视觉元素，而是中间步骤产生的控制精灵形状。端点的空间位置通过路径几何间接决定了放大后图案的 L 形轮廓——这种"路径即控制精灵"的关系在单个示例中容易被误解为简单缩放。
