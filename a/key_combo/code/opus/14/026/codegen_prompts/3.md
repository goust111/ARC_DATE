## 新题 3：孔洞数定缩放因子——计数驱动的模板印章

**组合逻辑**：[counting/hole_count](创新：孔洞数映射为缩放因子而非颜色) → [pixel_scaling + stamp]

**来源原语**：counting、enclosed_background_region、hole_count_to_color_mapping（来自 37d3e8b2，重新映射为 hole_count_to_scale）；pixel_scaling、stamp、template、scale_correspond（来自 447fd412）；foreground_object（来自 37d3e8b2）

**依赖链**：孔洞计数产出一个数值，该数值参数化模板的缩放倍数。缺少计数则缩放因子未知，缺少模板则无物可缩放，缺少印章操作则缩放后的模板无处放置。三者通过"孔洞数→缩放因子→印章尺寸"链式耦合。

数每个前景对象内部的封闭孔洞数作为缩放因子，将小模板按该倍数放大后印章在对象位置。

**输入结构**：约 16x16 黑(0)背景。左上角（行 0-2、列 0-2 范围内）有一个小模板图案，由蓝(1)像素组成，为一个不对称的 4-连通小图形（3-5 个像素，包围盒 2x3 或 3x3）。网格其余区域散布 2-3 个较大的灰(5)前景对象，每个对象为大致矩形的实心填充块（约 5x5 至 6x6），内部挖有 1 至 3 个孔洞（被灰像素完全包围的 4-连通黑(0)背景区域）。各对象间距不小于 8 格，保证最大缩放（3 倍）后的印章不相互重叠。生成约束：每个对象的孔洞数互不相同。

**规则**：
1. 识别左上角区域的蓝(1)小图案作为模板，记录其包围盒内的像素相对坐标。
2. 对每个灰(5)对象，计算其内部 4-连通封闭背景区域的数量 k（1、2 或 3）。
3. 将模板按因子 k 放大：模板的每个像素扩展为 k x k 的蓝(1)方块。
4. 将放大后的模板印章到该灰对象的包围盒左上角对齐位置（放大模板的左上角与灰对象包围盒的左上角重合）。
5. 灰(5)对象本身被擦除（变为黑(0)），仅保留蓝(1)印章。
6. 左上角的原始模板从输出中移除（变为黑(0)）。
7. 超出网格边界的印章部分裁剪丢弃。

**关键洞察**：灰对象内部的孔洞不是装饰——它们是缩放因子的数值编码。一个有两个孔洞的对象获得 2 倍放大的印章，三个孔洞则 3 倍。必须对比多个示例才能确认孔洞数→缩放因子的映射（而非孔洞数→颜色）。
