## 新题 2：缺口射线索引格子块多数色填充框体

**组合逻辑**：[射线延伸 ray_extend](创新：射线不是填色工具而是空间索引指针) + [多数决 majority_vote](已有) → [洪泛填充 flood_fill](已有) + [修补 repair](创新：修补缺口而非修补主体缺陷)

**来源原语**：洪泛填充 flood_fill、射线延伸 ray_extend、空心矩形 rectangular_frame、边框缺口 border_gap、缺口方向决定射线 gap_direction_determines_ray（参考题 551d5bf1）；多数决 majority_vote、填色块 filled_block、分隔行列 separator_row_col、格子格局 lattice_layout、每块取唯一多数色 majority_color_per_block（参考题 af24b4cc）

**依赖链**：缺口位置 → 射线方向 → 射线命中格子块 → 多数决读取该块颜色 → 用该颜色填充对应框体内部 → 修补缺口恢复完整边框。射线是选择器而非涂色器，多数决是解码器而非压缩器。删除射线则不知选哪块；删除多数决则噪声像素导致歧义；删除填充则无输出变化。

每个蓝色框体的缺口发射射线指向格子区域，射线命中的格子块经多数决得到一个颜色，用该颜色填充框体内部并修补缺口。

**输入结构**：约 18x20 的黑(0)背景网格，分为上下两个区域。上方区域（约前 10 行）包含一个矩形格子：由灰(5)分隔行和分隔列将区域划分为 2~3 行 x 3~4 列的等尺寸格子块（每块约 3x3），每块内有一个占多数的非黑非灰颜色（如红(2)、绿(3)、黄(4)等），并混有 1~2 个不同颜色的噪声像素（保证多数色唯一）。下方区域（约后 8 行）包含 2~3 个蓝(1)空心矩形框（4-连通的 1 像素宽实心边框，内部为黑(0)，边框宽高各 4~6 格）。每个框的顶边有且仅有一个非角落位置的缺失像素（缺口），其他三条边完整。各框水平间距至少 2 格，互不重叠。生成约束：每个缺口的列坐标落在格子的某一列带（两条灰色分隔列之间的区域）内；不同框的缺口对应不同的格子列带。

**规则**：
1. 对每个蓝(1)框体，定位其顶边的缺口像素位置 (r_gap, c_gap)。
2. 从缺口向上发射射线：从 (r_gap - 1, c_gap) 开始，逐行递减行号，跳过黑(0)和灰(5)像素，直至遇到第一个非黑非灰非蓝的像素。该像素属于某个格子块。
3. 确定该格子块的边界：从命中像素出发，找到它所在的、被灰色分隔行/列包围的矩形区域。
4. 对该格子块内所有像素计算多数色（出现次数最多的颜色，保证唯一）。
5. 用多数色填充该框体的内部（所有严格在边框内的黑色像素）。
6. 将缺口像素涂为蓝(1)，修补边框使其完整。
7. 格子区域、灰色分隔线、蓝色边框像素均保持不变。

**关键洞察**：缺口不是向外溢出颜色的出口（与参考题 551d5bf1 的用法相反），而是向内选取颜色来源的瞄准器；格子块中的噪声像素使得直接读取射线首个命中色会出错，必须对整个块做多数决才能确定正确填色。
