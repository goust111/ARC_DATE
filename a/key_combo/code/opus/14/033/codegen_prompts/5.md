## 新题 5：降采样掩码分组驱动跨框图案联合补全

**组合逻辑**：[降采样 downsample](已有) → [分组 grouping](创新：分组依据不是颜色而是外部空间掩码) → [对称补全 pattern_union_completion](已有，但作用于掩码定义的组而非颜色定义的组)

**来源原语**：降采样 downsample、单色图案 mono_pattern、整数缩放对应 int_scale_correspond（参考题 6ecd11f4）；分组 grouping、对称补全 pattern_union_completion、彩色边框 colored_frame、内部图案 internal_motif、同色框共享图案 same_color_frames_share_motif、按边框颜色分组 group_by_frame_color（参考题 42918530）

**依赖链**：大图案降采样 → 得到二值掩码 → 掩码将框体分为"覆盖组"和"未覆盖组" → 组内框体联合补全内部图案。分组标准来自外部空间信号而非框体自身颜色，颠覆了参考题 42918530 的"同色即同组"假设。删除降采样则分组标准消失；删除联合补全则组内信息不共享。

大尺度单色图案降采样后形成二值分组掩码，决定哪些小框共享内部图案并相互补全。

**输入结构**：约 20x20 的黑(0)背景网格，分为上下两个区域。上方区域包含一个大的单色黄(4)图案，占据一个矩形区域（如 9x12 或 12x12 格），该图案是一个小型二值模板（如 3x4 或 4x4 的黄/黑模式）的整数倍放大（倍率 k=3，即每个模板像素对应 kxk 的同色方块）。下方区域包含一个 m 行 x n 列的框体网格（m、n 与降采样后的模板尺寸匹配），框体间以 1 格黑色间距排列。每个框体为 3x3 大小（含 1 像素宽彩色边框），边框颜色使用蓝(1)、红(2)、绿(3)中的某一种。框体内部（1x1 的中心格）可能有一个与边框同色的像素（表示该框有内部图案），也可能为黑(0)。同一颜色的框可能分布在掩码的不同区域。生成约束：(a) 降采样后的模板恰好有 m 行 x n 列；(b) 每个分组（覆盖/未覆盖）内至少有 2 个框；(c) 同一组内的框的内部图案取并集后不与任何已有内部像素矛盾。

**规则**：
1. 裁剪黄(4)图案到其包围框。判断缩放倍率 k：k 为黄色图案的包围框宽度除以框体网格的列数（或高度除以行数，两者应一致）。
2. 将黄色图案降采样为 m x n 的二值掩码 M：每个 k x k 块中只要有一个黄色像素，对应掩码单元为 1（覆盖）；否则为 0（未覆盖）。
3. 将框体网格中第 i 行第 j 列的框映射到 M[i][j]。掩码值为 1 的框归入"覆盖组"，掩码值为 0 的框归入"未覆盖组"。
4. 在每个组内，收集所有框的内部像素位置的并集（位置相对于框的左上角）。将该并集中的所有位置在组内每个框中都涂上该框自身的边框颜色。原本已有内部像素的位置保持不变（颜色一致，无冲突）。
5. 擦除整个黄色图案区域（设为黑(0)）。
6. 输出下方区域的框体网格（含补全后的内部图案），保持框间间距和框边框不变。

**关键洞察**：框的边框颜色不决定分组——相同颜色的框可能因掩码覆盖状态不同而分属不同组，进而拥有不同的补全图案。分组的依据隐藏在一个看似无关的大尺度图案中，只有通过降采样建立空间对应关系才能发现。
