## 新题 1：奇方阵中心锚定字形印章

**组合逻辑**：[标注中心](已有) + [奇偶性](已有) → [编码映射](创新：将几何尺寸映射为字形索引) → [图案印章](已有) + [擦除](已有)

**来源原语**：标注中心、奇偶性、奇边长才标注 ← 22806e14；图案印章、编码映射、字形字典 ← dfadab01；擦除 ← 22806e14

**依赖链**：奇偶性筛选决定哪些方阵参与后续处理 → 通过筛选的方阵的边长值作为字形字典的索引键 → 标注中心确定印章的锚点坐标 → 图案印章在锚点处绘制对应字形 → 擦除原方阵像素。删除奇偶性筛选则无法确定目标集合；删除边长编码则无法确定印哪个字形；删除中心标注则无印章坐标；删除擦除则输出叠加不清。

对每个奇边长实心方阵，用其边长值查字形字典，在方阵中心位置印上对应字形并擦除原方阵。

**输入结构**：约 20x20 的黑(0)背景网格。散布 4~6 个绿(3)实心正方形，边长从 3 到 9 不等，既有奇数也有偶数边长，各方阵互不重叠且不相邻（任意两方阵边界框间距至少 1 像素）。网格最下方两行为字形图例区：用灰(5)分隔符将图例区分为 3~4 个等宽槽位，每个槽位内放置一个 3x3 的红(2)字形图案（各字形形状不同，如十字、角标、对角线等），槽位从左到右分别对应奇数边长 3、5、7（若有第四槽位则对应 9）。生成约束：所有奇边长方阵的边长值都能在字形图例中找到对应槽位。

**规则**：
1. 扫描网格中所有绿(3)实心正方形（4-连通单色区域且边界框为正方形且完全填满）。
2. 对每个方阵，计算其边长 s。若 s 为偶数，保留该方阵不做任何改动。
3. 若 s 为奇数，执行以下步骤：
   a. 计算中心像素坐标 (r_center, c_center) = (r_top + s//2, c_left + s//2)。
   b. 在字形图例中，按槽位从左到右的顺序，将第 k 个槽位（k 从 0 开始）对应边长 2k+3。找到 s 对应的槽位，提取其 3x3 字形。
   c. 将该 3x3 字形以 (r_center - 1, c_center - 1) 为左上角印到网格上，使用红(2)绘制字形的前景像素，字形的背景像素不覆盖（透明处理）。
   d. 将原方阵的所有绿(3)像素替换为黑(0)，但已印上的红(2)字形像素保留。
4. 擦除字形图例区（最下方两行全部置为黑(0)）。
5. 处理顺序：按方阵边界框左上角坐标从上到下、从左到右依次处理。由于生成约束保证方阵互不重叠，处理顺序不影响最终结果。

**关键洞察**：方阵的几何属性（边长）同时扮演两个角色——奇偶性决定是否参与变换，具体数值决定查字典的索引键——这种"属性双重复用"在任何单一参考题中都不存在。
