## 新题 7：行-列乘积提取加象限着色边框

**组合逻辑**：[提取 + 行列乘积完整](已有) + [裁剪](已有) → [象限与边距分层 + 相对位置决定颜色](创新：为提取结果添加由上下文编码的象限边框)

**来源原语**：提取、裁剪、行列乘积完整、双色图像 ← b71a7747；象限与边距分层、相对位置决定颜色、边框区域 ← 639f5a19

**依赖链**：行列乘积准则在多色网格中唯一锁定一对颜色 → 裁剪活跃行列得到紧凑双色子图 → 子图的尺寸决定边框大小 → 非目标颜色（被排除的填充色/分隔色）按出现频率排序编码四个象限的边框色。删除乘积提取则无内容可框；删除象限边框则提取结果缺少上下文编码；删除填充色排序则边框颜色不确定。

从多色网格中提取满足行-列乘积性质的双色图像，再用被排除颜色按频率为提取结果添加四象限着色边框。

**输入结构**：约 15x15 的网格，无统一背景色。包含 4~6 种颜色，其中恰好存在一对颜色（如蓝(1)和绿(3)）满足：它们的像素集合覆盖了某些行和某些列的完整笛卡尔积（即将这些行和列抽出后，每个交叉点都恰好是这两色之一）。其余颜色为填充色/分隔色，分布在目标颜色对未覆盖的行列上。每种填充色的像素总数互不相同。生成约束：满足行列乘积性质的颜色对唯一；填充色至少 2 种（以支持象限着色）。

**规则**：
1. 枚举所有可能的双色对，检查行列乘积性质：对颜色对 (a, b)，找出 a 或 b 出现的所有行 R 和所有列 C，检查 R x C 的每个交叉位置是否都恰好是 a 或 b。找到唯一满足此性质的颜色对。
2. 提取紧凑子图：只保留 R 中的行和 C 中的列，按原顺序排列，得到一个 |R| x |C| 的双色子图。
3. 统计所有非目标颜色（既不属于目标对，也不是黑(0)）的像素数，按像素数从多到少排序。若黑(0)不在目标对中且有黑(0)像素存在，也参与排序。取前四名颜色分别记为 F1, F2, F3, F4（若不足四种，循环使用已有颜色）。
4. 为子图添加 2 像素宽边框：输出尺寸为 (|R|+4) x (|C|+4)。子图放置在中央，偏移 (2,2)。
5. 边框象限着色：
   a. 上左象限（行 0~1 且列 0 至 (|C|+4)/2 - 1，以及行 2 至 (|R|+4)/2 - 1 且列 0~1）涂 F1。
   b. 上右象限（行 0~1 且列 (|C|+4)/2 至 |C|+3，以及行 2 至 (|R|+4)/2 - 1 且列 |C|+2 至 |C|+3）涂 F2。
   c. 下左象限（行 (|R|+4)/2 至 |R|+1 且列 0~1，以及行 |R|+2 至 |R|+3 且列 0 至 (|C|+4)/2 - 1）涂 F3。
   d. 下右象限（行 (|R|+4)/2 至 |R|+1 且列 |C|+2 至 |C|+3，以及行 |R|+2 至 |R|+3 且列 (|C|+4)/2 至 |C|+3）涂 F4。
   e. 四个 2x2 角块由两个象限共享，取行号更小的象限色（上优先于下）；行号相同时取列号更小的象限色（左优先于右）。
6. 输出仅包含带边框的子图，不保留原网格。

**关键洞察**：被行列乘积准则"淘汰"的颜色并非废弃信息——它们的统计频率编码了提取结果的装饰结构，形成"内容来自合格者，形式来自淘汰者"的双重利用关系。
