## 新题 8：行均匀性检测驱动选择性图案倍增

**组合逻辑**：[检测 + 单色行标记否则黑](创新：检测结果不直接输出，而是驱动逐行缩放决策) → [像素放大 + 图案倍增填框](创新：仅对满足条件的行执行 2x 垂直缩放) + [矩形边框](创新：边框自适应内容高度)

**来源原语**：检测、单色行标记否则黑、行 ← 25d8a9c8；像素放大、图案倍增填框、矩形边框、内部图案 ← e7a25a18

**依赖链**：逐行检测内部图案的均匀性 → 均匀行触发 2x 垂直缩放（该行复制为两行） → 非均匀行保持 1x → 组装后内容总高度改变 → 矩形边框自适应新高度包裹内容。删除行检测则无法区分哪些行要缩放；删除选择性缩放则检测结果无消费者；删除边框自适应则输出尺寸与内容不匹配。

检查矩形框内每行的颜色均匀性，将均匀行纵向加倍、非均匀行保持不变，边框自动适配新的总高度。

**输入结构**：约 12x10 的黑(0)背景网格。中央有一个绿(3)单像素厚矩形边框（宽度 W >= 6，高度 H >= 5），框内有一个多色图案（使用蓝(1)、红(2)、黄(4)等颜色，不含绿(3)和黑(0)），占满框内区域（无黑色像素在框内）。框内图案的各行中，部分行是单色的（该行所有像素颜色相同），部分行包含多种颜色。生成约束：至少有一行均匀且至少有一行非均匀；框内不含绿(3)像素。

**规则**：
1. 识别绿(3)矩形边框，提取其内部图案（边框内壁之间的矩形区域，高度 h = H-2，宽度 w = W-2）。
2. 逐行检查内部图案（从上到下，第 0 行到第 h-1 行）：
   a. 若第 i 行所有 w 个像素颜色相同，标记为"均匀行"。
   b. 否则标记为"非均匀行"。
3. 构建新的内部图案：从上到下遍历原图案各行——均匀行输出两次（垂直加倍），非均匀行输出一次。设新图案高度为 h'。
4. 构建输出：创建 (h'+2) x (w+2) 的网格。外围一圈为绿(3)边框。内部填入步骤 3 构建的新图案。
5. 输出网格的背景部分（若有）为黑(0)。输出尺寸即为 (h'+2) x (w+2)，不保留原网格中边框外的内容。

**关键洞察**：输出网格的行数无法预先确定——它涌现自对输入每行的逐一检测结果，迫使求解者必须先完整分析输入内容才能确定输出的几何尺寸。
