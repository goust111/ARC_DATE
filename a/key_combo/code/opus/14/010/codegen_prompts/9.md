## 新题 9：棋盘格计数匹配周期瓦片面积

**组合逻辑**：[补全 + 周期延拓](已有) → [计数](创新：统计补全后的有效像素总数) → [像素数匹配格数](创新：将面积计数与棋盘格数配对) + [填充 + 棋盘格图案](已有) + [擦除](已有)

**来源原语**：补全、周期延拓、重复瓦片、占位符区域 ← 50a16a69；计数、填充、棋盘格图案、空心矩形、像素数匹配格数、标记像素 ← df8cc377；擦除 ← 22806e14

**依赖链**：周期延拓将占位符区域补全为完整瓦片 → 计数补全后非背景像素总数 N → 在下半区多个空心矩形中计算各自棋盘格数 → 找到棋盘格数 = N 的矩形 → 同时找到散布标记中像素数 = N 的颜色 → 用该颜色填充匹配矩形的棋盘格 → 擦除所有散布标记。删除补全则 N 无法确定；删除计数则棋盘格匹配无键值；删除棋盘格匹配则计数结果无消费者。

将半可见的周期图案补全后统计前景像素总数，以此数值匹配下方空心矩形的棋盘格数和散布标记的像素数，三者一致时填色。

**输入结构**：约 20x20 的黑(0)背景网格，水平分为上下两区。上区（约占上方 8~10 行）：左上部分为一个可见的重复瓦片图案（使用蓝(1)和红(2)两色，瓦片最小周期约 2x2 至 4x4），右下部分为灰(5)占位符区域，形成 L 形遮挡。下区（约占下方 8~10 行）：包含 2~3 个黄(4)单像素厚空心矩形框（内部为黑(0)，各框大小不同，框间不重叠不相邻），以及散布在框外的单像素标记，分 2~3 种颜色（如绿(3)、品红(6)、橙(7)），每种颜色的像素总数互不相同。生成约束：上区补全后的非黑非灰像素总数恰好等于某一个空心矩形框内棋盘格数，也恰好等于某一种散布标记的像素数；三者的匹配是唯一的。

**规则**：
1. 识别上区的可见瓦片图案和灰(5)占位区域。从可见部分推断最小周期瓦片 T（最小的矩形使得可见部分可由 T 的平移周期拼出）。
2. 用 T 的周期延拓覆盖整个上区（包括占位符区域），将灰(5)像素替换为对应的瓦片颜色。
3. 统计补全后上区中所有非黑(0)像素的总数 N。
4. 对下区每个黄(4)空心矩形框，计算其内部棋盘格数：从框内左上角像素开始，按棋盘格模式（(r+c) % 2 == 0 的位置，其中 r、c 为框内相对坐标）计数，得到该框的格数 G_k。
5. 找到满足 G_k = N 的唯一矩形框。
6. 统计每种散布标记颜色的像素总数，找到像素数 = N 的唯一颜色 C。
7. 用颜色 C 填充步骤 5 找到的矩形框的棋盘格位置（(r+c) % 2 == 0 的内部像素涂为 C，其余内部像素保持黑(0)）。
8. 擦除所有散布标记（下区中非黄(4)、非黑(0)且不属于任何矩形框的单像素全部置为黑(0)）。
9. 上区保持补全后的状态。未匹配的矩形框保持空心不变。

**关键洞察**：周期图案的像素面积看似纯粹是上区的属性，实际上是连接上区内容和下区容器的"数值钥匙"——三个独立的计数（瓦片面积、棋盘格数、标记数量）必须同时吻合才能确定唯一操作。
