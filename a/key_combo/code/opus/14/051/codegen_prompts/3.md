## 新题 3：对称轨道揭示隐藏方向指令

**组合逻辑**：[对称补全](还原被遮罩的图案) → [条件判断：轨道期望色](对称轨道揭示标记位置的"本应颜色") → [平移/对角偏移](期望色决定偏移方向) — 非线性结构：对称分析的结果不直接进入下一步操作，而是充当条件判断的输入

**来源原语**：对称补全+八重对称轨道+遮罩像素(symmetry_completion+eightfold_orbit+mask_pixel, 参考题 929ab4e9), 平移+对角偏移+源色决定方向(translate+diagonal_offset+source_color_decides, 参考题 1e5d6875), 擦除(erase, 参考题 a78176bb)

**依赖链**：对称补全还原完整图案 → 完整图案揭示每个标记位置的"轨道期望色" → 期望色作为隐式指令决定对角偏移方向 → 偏移产生新像素。对称补全的输出并非直接传递给平移操作，而是经过一层"期望色解码"才变为方向指令。

在具有四重旋转对称的正方形图案中，还原灰色遮罩像素以确定完整对称结构，再利用对称轨道解码橙色标记的"本应颜色"，将该颜色作为方向指令生成对角偏移副本。

**输入结构**：黑(0)背景，约 11x11 正方形网格。中央区域有一个使用红(2)和蓝(1)两色构成的图案，该图案在四重旋转对称下不变（即 90 度旋转后图案与自身重合）。部分图案像素被灰(5)遮罩替换（每个对称轨道中至少保留一个可见像素）。另有 2~4 个橙(7)标记像素，每个橙标记替换了图案中的某个红或蓝像素（标记位置属于图案区域）。生成约束：每个橙标记的对称轨道中至少有一个非橙非灰的可见像素，以便确定该轨道的本应颜色；各标记的对角偏移结果不超出网格边界。

**规则**：
1. 识别图案的四重旋转对称结构。对每个灰(5)遮罩像素，找到其四重旋转轨道中的可见（非灰非橙）像素颜色，将灰像素替换为该颜色。
2. 对每个橙(7)标记像素，通过其四重旋转轨道确定该位置"本应"的颜色（轨道中非橙像素的颜色）。
3. 若本应颜色为红(2)：在距橙标记沿"朝向网格中心"方向偏移一步的对角位置绘制一个绿(3)像素。
4. 若本应颜色为蓝(1)：在距橙标记沿"远离网格中心"方向偏移一步的对角位置绘制一个黄(4)像素。
5. "朝向/远离网格中心"指：计算标记到网格中心的向量，选择行和列分量均朝向（或远离）中心的对角方向。
6. 橙标记像素保留为橙(7)。绿/黄像素若落在已有非黑像素上，则不绘制。

**关键洞察**：橙色标记是被篡改的对称像素，其"真实身份"（红或蓝）被对称结构隐藏起来，只有先完成对称还原才能解码方向指令——方向信息不在标记本身，而在它"本应是什么"中。
