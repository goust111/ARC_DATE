## 新题 4：柱高排序重分配后的同色滑动归位

**组合逻辑**：[排序/重分配](已有) + [滑动/同色配对](创新：滑动目标不是原始柱位置而是排序后的新位置) + [碰撞阻挡](创新：重分配改变了碰撞判定的几何条件) + [无匹配色则删除](已有)

**来源原语**：排序/高度排序/重分配/槽位保持颜色(31f7f899)、滑动/同色配对/碰撞阻挡/无匹配色则删除(1a07d186)、柱状条/基线(31f7f899)、满行列条(1a07d186)、孤立像素(1a07d186)

**依赖链**：柱高排序产生新的柱-槽分配方案 -> 槽位颜色不变但柱形互换，改变了每个位置的颜色标签 -> 散布像素按颜色匹配排序后的柱而非排序前的柱 -> 像素滑动方向和距离由排序后的布局决定

先按高度排序重分配柱状条，再让散布像素滑向颜色匹配的（已重新排列的）柱，排序改变了滑动目标位置。

**输入结构**：约 10x18 的网格，黑(0)背景。底部有一行灰(5)基线横贯全宽。基线上方有 4 根垂直柱状条，每根宽 1 像素，高度互不相同（范围 2~7 格），颜色分别为红(2)、蓝(1)、绿(3)、黄(4)，从左到右排列在不同列上，柱间至少隔 2 列。基线下方无内容。在基线上方、柱状条右侧的空白区域中，散布 3~5 个孤立彩色像素，每个像素的颜色为上述四种柱色之一（可重复），且不与任何柱同列。可能有 0~1 个像素的颜色为橙(7)（不匹配任何柱色）。生成约束：各柱高度互不相同；散布像素所在行高度不超过基线上方最高柱的顶端行；每个散布像素向左水平滑动到匹配色柱时路径上无其他柱阻挡（在排序前的布局中如此，但排序后不保证——排序后路径上可能出现新柱阻挡，此时像素停在新柱旁边）。

**规则**：
1. 将四根柱状条按高度从矮到高排序（高度相同时不会发生，已由生成约束保证）。
2. 将排序后的柱形（高度轮廓）依次放入从左到右的四个原始槽位中。每个槽位保持其原始颜色不变——即最左槽始终为红(2)、第二槽为蓝(1)、第三槽为绿(3)、最右槽为黄(4)，但槽内的柱高度变为排序后对应位置的高度。
3. 对每个散布像素，找到与其颜色相同的柱（排序后颜色由槽位决定，位置可能已改变高度但列位置不变）。从该像素出发向左水平滑动（每步左移一列）。
4. 滑动过程中，若下一格是任何柱的像素或基线像素，则停在当前位置（碰撞阻挡）。若滑动到达目标柱的相邻右侧一格，则停在该格。
5. 颜色为橙(7)的像素无匹配柱，直接擦除（置为黑(0)）。
6. 输出为完成排序和滑动后的完整网格。

**关键洞察**：排序只改变柱的高度轮廓而不改变槽位颜色和列位置，但高度变化意味着某些原本"空旷"的行现在有了柱像素阻挡，散布像素的滑动路径因此被截断在不同位置——求解者必须先完成排序才能判断滑动结果。

6. 若规则有多个分支，生成器不能长期固定成一个分支；应让分支在随机样例中合理出现。分支概率不必平均——难以发现的隐蔽分支（如少数情况下才触发的特殊规则）应适当提高出现概率，确保在 3 个训练示例中至少出现一次，否则求解者无法归纳该规则。对于颜色映射类规则，确保 2 个左右的示例即可覆盖所有映射关系（每种颜色→颜色的映射至少在某个示例中出现过）。
