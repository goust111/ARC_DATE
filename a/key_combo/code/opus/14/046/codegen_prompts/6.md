## 新题 6：行对齐偏移后十字交叉生成与消除

**组合逻辑**：[滑动/边界对齐](创新：行偏移改变了标记像素的绝对列坐标) + [射线延伸/十字图案](创新：十字由行对齐后的标记像素生成，而非固定位置的实心方块) + [交叉点重置背景](已有) + [重涂色](已有)

**来源原语**：滑动/对齐/色段/同行排列/边界对齐(984d8a3e)、射线延伸/十字图案/实心方块/行列对齐/交叉点重置背景(e9bb6954)、重涂色(50846271)、标记像素(50846271)

**依赖链**：色段右边界对齐确定每行的滑动量 -> 滑动改变标记像素的列坐标 -> 新列坐标决定十字图案的水平位置 -> 多个十字的交叉区域被重置为背景色

先将每行的色段滑动对齐，色段中嵌入的标记像素跟随偏移到新位置，然后从标记像素生成行列十字，交叉处重置。

**输入结构**：约 12x12 的网格，黑(0)背景。网格包含三种颜色：黑(0)为背景、绿(3)为"主色段"色、灰(5)为"侧色"。每行有一段连续的绿(3)色段，色段左侧填充灰(5)，色段右侧填充灰(5)（与 984d8a3e 结构类似但侧色相同）。各行绿色段长度相同，但起始列不同，导致右边界参差不齐。在绿色段中，某些行包含恰好一个红(2)标记像素（替换该位置的绿色），共 2~4 个标记像素分布在不同行。生成约束：标记像素所在行互不相同；对齐后任意两个标记像素不同列（确保十字无完全重合）；对齐后至少有一对标记像素的十字产生交叉（即标记像素 X 的行与标记像素 Y 的列有交点）。

**规则**：
1. 找到所有行中绿(3)色段右边界列的最小值 min_right。
2. 将每行整体水平滑动，使该行的绿色段右边界对齐到 min_right 列。滑动时行内所有像素（含灰色侧边和红色标记）随之平移，超出左边界的像素丢弃，右侧空出的格填充灰(5)。
3. 对齐完成后，找到所有红(2)标记像素的新位置。
4. 从每个红(2)标记像素出发，向上、向下、向左、向右各延伸射线，将射线路径上的所有格（含标记像素本身所在的整行和整列）重涂为红(2)。射线覆盖时：红(2)覆盖绿(3)和灰(5)，但不覆盖黑(0)背景（射线仅在非黑格上绘制，遇黑格跳过继续延伸至行/列末端——即射线是该行/列中所有非黑格的重涂，不是连续线段）。
5. 若两个不同标记像素的十字在某非黑格相交（即该格同时位于标记 X 的行/列和标记 Y 的行/列），将该格重置为绿(3)（原始主色段色），而非红色。
6. 黑(0)背景格始终不变。

**关键洞察**：行滑动改变了标记像素的绝对列位置，从而改变了十字图案的几何布局和交叉位置。同一组标记像素在不同的滑动量下会产生不同的交叉模式——求解者必须先完成对齐计算才能确定哪些格被重置。
