## 新题 7：轨迹终点定位条件性对称修复或互换

**组合逻辑**：[沿路径移动](创新：路径终点不是移动目的地，而是目标区域的坐标指针) + [对称补全](创新：补全不总是发生，取决于路径终点是否指向缺失区域) + [镜像](已有) + [条件分支：修复 vs 互换]（创新组合）

**来源原语**：沿路径移动/轨迹路径/标记像素(c9680e90)、对称补全/缺失区域/镜像/镜像补缺并裁出(9ecd008a)、分隔行(c9680e90)、裁剪(9ecd008a)

**依赖链**：源像素沿轨迹移动到终点 -> 终点坐标映射到上方网格中的某个区块 -> 判断该区块是否为缺失区域 -> 若是：镜像补全缺失区域 -> 若否：将该区块内容与镜像补全后的缺失区域内容互换

沿轨迹找到终点位置，终点映射到镜像对称网格中的一个区块；如果该区块是黑色缺失区域则直接镜像修复，如果不是则将其与修复后的缺失区域内容互换。

**输入结构**：约 14x14 的网格。上方区域（约 8 行）包含一个左右镜像对称的彩色图案（使用红(2)、蓝(1)、绿(3)等颜色，黑(0)背景），但其中恰好有一个 3x3 的纯黑(0)缺失区域打破了对称性。该缺失区域的镜像对应位置是完整的彩色区块。上方区域可以被划分为若干个不重叠的 3x3 区块（网格尺寸保证这一点）。一行品红(6)分隔行横贯全宽。下方区域（约 5 行）包含：一个橙(7)源像素和一条由黄(4)像素组成的 4-连通轨迹与源像素相连。轨迹是无分叉的单路径，终点为轨迹的非源端。生成约束：将终点的列坐标和行坐标分别对 3 取模后映射到上方区域的某个 3x3 区块（列坐标 / 3 = 区块列索引，终点行坐标在下方区域中的相对行 = 区块行索引），该映射始终指向一个有效的 3x3 区块。不同示例中，终点有时指向缺失区域本身，有时指向其他非缺失区块。

**规则**：
1. 在下方区域中，从橙(7)源像素出发，沿黄(4)轨迹 4-连通逐步行走至轨迹终点（轨迹中离源像素最远的端点）。
2. 计算终点在下方区域中的相对位置：rel_row = 终点行 - 分隔行行号 - 1，rel_col = 终点列。
3. 将 rel_row 和 rel_col 映射到上方区域的 3x3 区块索引：block_row = rel_row，block_col = rel_col / 3（整数除法）。定位到上方区域的目标 3x3 区块。
4. 通过左右镜像找到缺失区域的修复内容：对缺失区域中的每个格 (r, c)，从镜像列 (r, W-1-c)（W 为上方区域宽度）复制颜色，得到修复补丁 P。
5. 条件判断：
   - 若目标区块就是缺失区域（3x3 全黑）：将修复补丁 P 填入缺失区域，上方区域其余部分不变。
   - 若目标区块不是缺失区域：将目标区块的当前内容 Q 复制到缺失区域位置，将修复补丁 P 复制到目标区块位置（即互换：缺失处填 Q，目标处填 P）。
6. 输出仅为修改后的上方区域（不含分隔行和下方区域）。

**关键洞察**：轨迹的几何形状编码了一个"地址"，指向上方网格中的某个区块。求解者不仅要完成镜像修复，还要判断轨迹指向的是不是缺失区域本身——这个条件分支只有对比多个示例（有的指向缺失区域，有的不指向）才能归纳出来。
