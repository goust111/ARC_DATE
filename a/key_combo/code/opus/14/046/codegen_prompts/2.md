## 新题 2：滑动对齐后逐像素差异裁剪

**组合逻辑**：[滑动对齐](创新：两个精灵体沿不同轴滑动到同一区域) + [逐像素比较](创新：比较对象不是预置面板而是滑动后的重叠区域) + [裁剪](已有) + [差异分类着色](已有)

**来源原语**：滑动对齐/颜色匹配锚点/边缘位置决定轴(581f7754)、逐像素比较/差异分类着色(d47aa2ff)、裁剪(dc0a314f, 5117e062)、标记像素(581f7754, 5117e062)

**依赖链**：锚点边缘位置决定每个精灵体的滑动轴 -> 滑动后两个精灵体的边界框产生重叠区域 -> 重叠区域内逐像素比较产生差异着色图 -> 裁剪出仅包含重叠区域的输出

两个带标记像素的精灵体分别沿锚点指定的轴滑动，在重叠区域做逐像素比较并着色输出。

**输入结构**：约 15x15 的网格，黑(0)背景。网格内部有两个多色精灵体（每个精灵体由 2~3 种非黑非青颜色组成，4-连通，边界框约 4x4~5x5，形状不规则且互不相同）。每个精灵体内部恰好有一个橙(7)标记像素。网格边界上有两个孤立的橙(7)锚点像素（4-邻居均为黑(0)或网格外）：一个位于顶边（非角落），另一个位于右边（非角落）。两个精灵体初始位置互不重叠，且与边界锚点不相邻。生成约束：顶边锚点与一个精灵体的标记像素同列时该精灵体无需滑动，但此情况不会出现——两个锚点分别对应两个精灵体（按如下匹配规则），滑动后两个精灵体的边界框有至少 2x2 的重叠区域。

**规则**：
1. 将两个精灵体分别标记为 A 和 B。精灵体 A 是标记像素距顶边锚点的曼哈顿距离较小者，精灵体 B 是另一个。
2. 精灵体 A 对应顶边锚点：将 A 整体水平滑动，使 A 的标记像素所在列与顶边锚点所在列对齐（行位置不变）。
3. 精灵体 B 对应右边锚点：将 B 整体垂直滑动，使 B 的标记像素所在行与右边锚点所在行对齐（列位置不变）。
4. 计算滑动后 A 和 B 边界框的重叠矩形区域。
5. 在重叠区域内逐像素比较：
   - 若 A 和 B 在该格都有非黑像素且颜色相同：输出该颜色。
   - 若 A 和 B 在该格都有非黑像素但颜色不同：输出黄(4)。
   - 若仅 A 有非黑像素：输出红(2)。
   - 若仅 B 有非黑像素：输出蓝(1)。
   - 若两者在该格均为黑(0)：输出黑(0)。
6. 输出仅为裁剪后的重叠矩形区域。

**关键洞察**：锚点的边缘位置（顶边 vs 右边）分别决定了对应精灵体的滑动轴（水平 vs 垂直），滑动距离取决于标记像素与锚点的列/行差，而最终的比较结果完全由滑动后的重叠几何决定——改变任一锚点位置都会改变重叠区域形状和比较结果。

<description>
Decode a block-grid image by swapping each sprite-coded cell with a solid cell and each blank cell with the sprite.

Input structure
The grid is partitioned by black separator rows and columns into equal-size
square blocks. Each block is either a copy of one two-color sprite or a
uniform blank block of the sprite's minority color; grey pixels are erased
cells that act as wildcards.

Rule
Infer the repeated sprite from fully visible mixed-color blocks. Replace a
block matching that sprite, ignoring grey erasures, with a solid block of
the sprite's majority color. Replace a uniform blank block with the sprite.
Separator rows and columns, including grey erasures on them, become black.

Key insight
The small sprite is a block-level code for one macro-cell state, and the
uniform minority-color block is the other state; the output renders the
opposite code in each macro-cell while cleaning erased pixels.
