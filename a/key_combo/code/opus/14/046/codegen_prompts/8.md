## 新题 8：标记选取精灵体后按像素数排序平移拼装

**组合逻辑**：[标记选精灵涂色](创新：标记不仅选择精灵体，还决定输出色) + [计数](创新：像素数不决定尺寸而是决定排列顺序) + [排序](创新：排序依据是精灵体面积而非柱高) + [平移拼接/拼合覆盖](创新：拼接方式是垂直堆叠而非水平排列)

**来源原语**：标记像素/邻接接触/标记选精灵涂色/忽略干扰项(5117e062)、计数(31aa019c)、排序/高度排序(31f7f899)、平移拼接/拼合覆盖/像素数定尺寸(83b6b474)、裁剪(5117e062)

**依赖链**：青色标记像素筛选出目标精灵体集合 -> 统计每个目标精灵体的非青像素数 -> 按像素数升序排列 -> 依次垂直堆叠各精灵体的裁剪边界框

用青色标记像素选出若干精灵体，统计每个被选精灵体的面积并按面积排序，最后将它们垂直堆叠输出。

**输入结构**：约 15x15 的网格，黑(0)背景。网格中散布 5~7 个小型 4-连通单色精灵体（每个精灵体由同一种非黑非青颜色构成，像素数 3~8 不等，形状不规则，边界框不超过 4x4）。不同精灵体可以使用相同颜色。其中 3~4 个精灵体各有一个青(8)标记像素与之 4-连通相邻（标记像素不属于精灵体本身，仅与精灵体的恰好一个像素 4-邻接）。未被标记的精灵体为干扰项。生成约束：被标记的精灵体像素数互不相同（确保排序无歧义）；各精灵体边界框互不重叠且互不相邻（间距至少 1 格）；每个精灵体至多有一个青色标记。

**规则**：
1. 找到所有青(8)标记像素。对每个青标记，找到与之 4-连通的非黑非青精灵体（即标记的 4-邻居中属于某精灵体的那个像素所在的连通分量）。该精灵体即为"选中精灵体"。
2. 对每个选中精灵体，统计其非青像素数量（即精灵体本身的面积，不含标记像素）。
3. 按像素数从小到大排序选中精灵体。像素数相同不会发生（生成约束保证）。
4. 对每个选中精灵体，裁剪其最小边界框（仅含精灵体像素，不含标记像素；边界框内精灵体像素保留原色，非精灵体格为黑(0)）。
5. 将裁剪后的边界框从上到下按排序顺序垂直堆叠：最小面积的在最顶部，最大面积的在最底部。各边界框之间用 1 行黑(0)分隔。所有边界框左对齐，宽度统一为所有边界框中最大的宽度（较窄的边界框右侧用黑(0)填充至统一宽度）。
6. 输出为堆叠后的整体矩形。未被选中的精灵体和所有青色标记像素均不出现在输出中。

**关键洞察**：青色标记同时承担"选择"和"排除"双重角色——它选中精灵体参与排序，但自身不计入面积，也不出现在输出中。求解者必须先通过标记筛选，再数面积排序，最后拼装——三步之间任一步的结果都影响最终输出。
