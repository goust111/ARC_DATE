## 新题 1：镜像墙壁塑形对角射线

**组合逻辑**：[镜像](创新：镜像产物不直接画出，而是作为射线的隐形障碍) + [射线延伸](创新：多方向对角射线受隐形墙约束截断) + [碰撞停止] + [重涂色](已有)

**来源原语**：镜像/镜像对称(dc0a314f, 9ecd008a)、射线延伸/对角方向(623ea044, e179c5f4)、碰撞停止(80a900e0)、重涂色(e179c5f4)

**依赖链**：左半区图案经镜像计算出右半区的虚拟墙位置 -> 虚拟墙位置截断从起点像素出发的四条对角射线 -> 射线路径与最终显现的墙像素共同构成输出，重叠处墙色覆盖射线色

从左半区的图案推断右半区的隐形障碍，再由这些障碍塑造起点像素发出的对角射线长度，最终将射线与显现的障碍叠合输出。

**输入结构**：约 15x15 的网格，黑(0)背景。一条灰(5)竖线将网格等分为左右两半（位于正中列，宽 1 像素）。左半区散布若干红(2)像素（3~7 个，4-连通的小块或孤立点，不接触灰线也不接触网格边界）。右半区仅有一个蓝(1)孤立像素，位于右半区中部偏上。生成约束：蓝像素关于灰线的镜像位置不在任何红像素上；左半区图案关于灰线的镜像投射到右半区后，至少有一个镜像红像素恰好落在蓝像素某条对角射线的路径上。

**规则**：
1. 以灰(5)竖线为对称轴，计算左半区每个红(2)像素在右半区的镜像位置，记为"虚拟墙"集合（此时不绘制）。
2. 从蓝(1)像素出发，沿四个对角方向（右上、右下、左上、左下）各发射一条射线。每条射线逐步延伸，每步行进一格对角距离。
3. 射线的每一步检查目标格：若目标格是虚拟墙位置、灰线、或超出网格边界，则该射线在上一步停止（停止格不包含目标格）。若目标格是另一条射线已绘制的像素，继续穿过不停止。
4. 所有射线绘制完毕后，将虚拟墙集合中的每个位置绘制为红(2)。
5. 若某格同时是射线像素和虚拟墙像素，最终颜色为红(2)（墙色覆盖射线色）。
6. 左半区保持原样不变，灰线保持原样不变。四条射线按右上、右下、左上、左下的固定顺序依次绘制（射线之间不互相阻挡）。

**关键洞察**：虚拟墙在输出中才可见，求解者必须先通过镜像推算墙位置，再在脑中模拟射线碰撞，才能得出射线长度——镜像与射线延伸通过"隐形障碍"这一中间产物紧密耦合。

1. `main(grid)` 必须实现新题描述中的确定性转换规则，不能只识别 `generate_input()` 的固定模板。禁止不同的input网格输出相同的output网格。
2. `generate_input()` 必须随机生成多样样例，不能固定死。随机维度应覆盖：网格大小、对象数量、位置、颜色、方向、形状参数或关键分支。注意若描述中存在若干，需实现而不是只有单个，包括object或者对应关系等等。且若涉及到最短路径，则输入网格中必涉及到多条路径，对选择造成干扰。

4. 禁止把 ARC 颜色 id 、亮度、拼写等当作人类不可见的数值语义参与排序、大小比较或隐藏映射。颜色变化必须有可见结构线索。注意颜色亮度、拼写等也是不可见信息，若描述中出现违规的颜色id或者亮度，可自行使用少量的固定颜色替代，但注意生成时要在三个以内输入输出网格中对所有变换100%覆盖度。

6. 若规则有多个分支，生成器不能长期固定成一个分支；应让分支在随机样例中合理出现。分支概率不必平均——难以发现的隐蔽分支（如少数情况下才触发的特殊规则）应适当提高出现概率，确保在 3 个训练示例中至少出现一次，否则求解者无法归纳该规则。对于颜色映射类规则，确保 2 个左右的示例即可覆盖所有映射关系（每种颜色→颜色的映射至少在某个示例中出现过）。
