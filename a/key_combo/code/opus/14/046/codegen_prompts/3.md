## 新题 3：唯一频率色定位对角线，对角线筛选目标并描框

**组合逻辑**：[计数/频率唯一性](已有) + [射线延伸/对角方向](创新：对角线不是纯装饰而是空间筛选器) + [描边/框](创新：框不是围绕频率目标本身，而是围绕被对角线穿过的其他像素) + [擦除](已有)

**来源原语**：计数/最低频色定位目标(31aa019c)、射线延伸/对角方向/过像素画双对角线(623ea044)、描边/框(31aa019c)、擦除(e9bb6954, 1a07d186)、忽略干扰项(50846271)

**依赖链**：颜色频率统计定位唯一出现的源像素 -> 源像素决定双对角线的原点和颜色 -> 对角线路径与其他散布像素的交叉判定 -> 被穿过的像素获得红框，未被穿过的像素被擦除

统计颜色频率找出唯一色像素作为对角线原点，对角线穿过的其他像素被描框保留，其余擦除。

**输入结构**：约 12x12 的网格，黑(0)背景。网格中散布 8~14 个非黑孤立像素（彼此不 4-连通），使用 3~4 种颜色。其中恰好一种颜色只出现 1 次（该像素为"源像素"），其余颜色各出现 2 次或更多。生成约束：源像素不在网格边角；从源像素出发的两条完整对角线（左上-右下、右上-左下延伸至网格边界）至少各穿过 1 个其他非黑像素；至少有 1 个非黑像素不在任一对角线上（作为被擦除的干扰项）。

**规则**：
1. 统计每种非黑颜色的出现次数，找到恰好出现 1 次的颜色，该颜色的唯一像素即为源像素。
2. 从源像素出发，沿四个对角方向（左上、右上、左下、右下）各画一条射线延伸至网格边界，射线颜色为源像素的颜色。射线绘制时穿过所有像素（不因碰到非黑像素而停止）。
3. 检查每个非源的非黑像素是否位于这两条对角线上（即是否与源像素的行差绝对值等于列差绝对值）：
   - 若在对角线上：保留该像素原色，并在其周围绘制一个 3x3 红(2)框（框的 8 个外围格填充红(2)，中心保留原像素颜色；若框的某些格超出网格边界，则舍弃超出部分；若框的某格与对角线射线重合，红(2)覆盖射线色）。
   - 若不在对角线上：擦除该像素（置为黑(0)）。
4. 源像素本身保留原色，不描框。
5. 多个被框像素的 3x3 红框若有重叠格，该格仍为红(2)。

**关键洞察**：频率分析决定对角线原点，但对角线的几何路径才是真正的筛选机制——同一批散布像素在不同源像素位置下会产生完全不同的"存活/擦除"分组，需要对比多个示例才能发现"对角线穿过"而非"距离最近"是筛选标准。
