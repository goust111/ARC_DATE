## 新题 10：面板比较差异区域的循环层深填色

**组合逻辑**：[逐像素比较/差异分类着色](创新：比较不是最终输出而是中间步骤，产生差异区域掩码) + [循环填充/层深度递增](创新：填充的区域由差异比较决定而非预定义的对角带) + [调色板行](已有) + [裁剪](已有)

**来源原语**：逐像素比较/面板/分隔列/面板对齐/差异分类着色(d47aa2ff)、循环填充/层深度递增/调色板行/层深模色板取色(b457fec5)、裁剪(dc0a314f)、重涂色(b457fec5)

**依赖链**：左右面板逐像素比较产生差异掩码（三类：共有、仅左、仅右）-> 每类差异区域作为独立的填充目标 -> 从各区域的重心出发计算层深 -> 用调色板行循环填色

比较两个面板的差异，将差异区域按类别分组，每组按距离组重心的层深做循环调色板填色。

**输入结构**：约 10x21 的网格。一列栗(9)分隔列将网格分为等宽的左面板和右面板（各约 10x10）。两个面板各包含若干非黑前景像素（使用红(2)、蓝(1)、绿(3)等颜色），在黑(0)背景上形成图案。两面板的图案有部分重叠、部分差异（即某些位置两面板颜色相同，某些位置仅一侧有前景色）。网格最底行为一行调色板像素：从左到右依次为 2~4 种不同颜色（如橙(7)、黄(4)、品红(6)），剩余格为黑(0)。生成约束：仅出现在左面板的前景像素集合构成一个 4-连通区域；仅出现在右面板的前景像素集合也构成一个 4-连通区域（两个差异区域各自连通但互相不连通）；调色板颜色不包含面板中使用的前景色或栗(9)。

**规则**：
1. 移除分隔列，将左右面板按单元格位置对齐比较（第 i 行第 j 列 vs 第 i 行第 j 列）。
2. 分类每个单元格：
   - 类型 S（共有）：两面板在该位置都有非黑像素且颜色相同。
   - 类型 L（仅左）：仅左面板有非黑像素。
   - 类型 R（仅右）：仅右面板有非黑像素。
   - 类型 O（两面板均为黑(0)）：忽略。
3. 对类型 S 的格保留原色不变。
4. 对类型 L 的连通区域：计算该区域所有格坐标的算术平均值作为重心 (cr, cc)（四舍五入到最近整数）。对区域中每个格 (r, c)，层深 d = max(|r - cr|, |c - cc|)。将该格重涂为调色板中第 (d mod 调色板长度) 个颜色（调色板从索引 0 开始，按最底行从左到右的非黑像素顺序排列）。
5. 对类型 R 的连通区域：同样计算重心和层深，同样使用调色板循环填色，但调色板的起始偏移为 1（即该格颜色为调色板第 ((d + 1) mod 调色板长度) 个颜色）。
6. 输出为一个与单面板等大的网格（10x10），包含处理后的 S、L、R 类型格，O 类型格为黑(0)。最底行调色板不出现在输出中。

**关键洞察**：像素比较不是终点而是起点——它产生的差异区域成为循环填色的画布。"仅左"和"仅右"区域使用相同调色板但起始偏移不同，求解者必须对比多个示例才能发现偏移差异，而非简单地认为两类区域用同一套规则。
