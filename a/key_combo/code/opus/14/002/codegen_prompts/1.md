## 新题 1：蛇径编码色环

**组合逻辑**：[遍历顺序](创新：蛇形路径的邻接访问顺序编码颜色置换关系) + [重涂色](已有) + [膨胀](创新：光晕颜色由置换结果决定而非标记原色)

**来源原语**：蛇形路径·遍历顺序·端点（7b5033c1），重涂色·固定颜色置换映射（0d3d703e），膨胀·光晕·邻域扩展·标记保留原色（4258a5f9），单像素标记（963f59bc）

**依赖链**：蛇形路径的遍历顺序产出标记的访问序列 -> 访问序列定义颜色的循环置换映射 -> 置换映射决定每个标记的光晕颜色 -> 光晕绘制时标记自身保留原色。去掉遍历则无法确定置换；去掉置换则光晕颜色无定义；去掉光晕则输出退化为零散色点。

一句话总结：追踪蛇形路径经过各彩色标记的先后顺序，由此建立一组循环色彩置换，为每个标记绘制置换后颜色的光晕，标记本身保留原色。

**输入结构**：约 12x12 的黑(0)背景网格。一条灰(5)蛇形路径在网格中蜿蜒，由 4-连通单色像素组成，恰好有两个端点（仅一个 4-邻居为灰色的像素）。路径不分叉、不自交。网格中另有 3~5 个不同颜色的单像素标记（从红(2)、绿(3)、蓝(1)、黄(4)、橙(7)中选取），每个标记不在蛇形路径上，但恰好与蛇形路径的某一个像素 4-相邻。每个标记恰好与蛇形路径的一个像素相邻（不会有标记与蛇形路径的多个像素相邻）。不同标记相邻的蛇形路径像素互不相同。生成约束：任意两个标记的 3x3 邻域互不重叠；所有标记距网格边缘至少 1 像素。

**规则**：
1. 确定蛇形路径的遍历方向：从两个端点中选取行号更小者出发；若行号相同，选列号更小者。从该端点沿唯一的 4-连通路径依次访问每个灰(5)像素。
2. 按遍历顺序记录蛇形路径依次经过（4-相邻）的标记颜色，形成一个有序颜色列表，例如 [红(2), 蓝(1), 黄(4), 绿(3)]。
3. 建立循环置换映射：列表中第 i 个颜色映射到第 (i+1) 个颜色；最后一个颜色映射到第一个。例如上述列表产生映射 红->蓝, 蓝->黄, 黄->绿, 绿->红。
4. 擦除整条蛇形路径（全部灰像素变为黑(0)背景）。
5. 对每个标记像素，将其 3x3 邻域（以标记为中心，裁剪到网格边界内）中的所有黑(0)背景像素涂为该标记的**置换后颜色**（即步骤 3 中映射到的颜色）。
6. 所有标记像素自身保留其**原始颜色**不变（覆盖在光晕之上）。
7. 若多个标记的 3x3 光晕在某像素重叠（按生成约束不会发生，但作为边界规则说明），后处理的标记覆盖先处理的；处理顺序为遍历访问顺序。

**关键洞察**：蛇形路径本身不出现在输出中，它的唯一作用是通过遍历顺序编码一组颜色循环置换；若不追踪路径就无法确定哪种颜色映射到哪种颜色。遍历的起始端点选择规则（左上优先）需要对比多个示例才能归纳。

## 实现要求

1. `main(grid)` 必须实现新题描述中的确定性转换规则，不能只识别 `generate_input()` 的固定模板。禁止不同的input网格输出相同的output网格。
2. `generate_input()` 必须随机生成多样样例，不能固定死。随机维度应覆盖：网格大小、对象数量、位置、颜色、方向、形状参数或关键分支。注意若描述中存在若干，需实现而不是只有单个，包括object或者对应关系等等。且若涉及到最短路径，则输入网格中必涉及到多条路径，对选择造成干扰。
3. 生成器必须保证输入满足 `main()` 的隐式假设：对象不重叠、不越界、特殊标记唯一或可区分、匹配关系无歧义、关键分支出现概率相同。
4. 禁止把 ARC 颜色 id 、亮度、拼写等当作人类不可见的数值语义参与排序、大小比较或隐藏映射。颜色变化必须有可见结构线索。注意颜色亮度、拼写等也是不可见信息，若描述中出现违规的颜色id或者亮度，可自行使用少量的固定颜色替代，但注意生成时要在三个以内输入输出网格中对所有变换100%覆盖度。
5. 输出样例要视觉清晰，人类必须能从输入输出对中肉眼辨认出规律。具体要求：避免对象粘连、覆盖关系混乱、同一像素多重语义；不同逻辑步骤产生的结果不要大面积层叠在一起导致无法分辨哪个颜色属于哪个步骤；输入中各元素之间保持足够间距，输出中新增的标记/填充/路径等应与背景和已有元素在颜色上有明显区分；若规则涉及多层叠加，生成时控制对象密度和尺寸，确保叠加区域只占少数像素而非铺满整个网格。
6. 若规则有多个分支，生成器不能长期固定成一个分支；应让分支在随机样例中合理出现。分支概率不必平均——难以发现的隐蔽分支（如少数情况下才触发的特殊规则）应适当提高出现概率，确保在 3 个训练示例中至少出现一次，否则求解者无法归纳该规则。对于颜色映射类规则，确保 2 个左右的示例即可覆盖所有映射关系（每种颜色→颜色的映射至少在某个示例中出现过）。
