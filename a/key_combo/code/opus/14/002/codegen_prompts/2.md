## 新题 2：对称缺陷播种填充

**组合逻辑**：[对称补全](创新：缺陷像素不再是待恢复的遮挡区，而是标识填充种子的信号) + [区域填充](创新：填充边界来自对称图案本身) + [重涂色](已有：缺陷修复)

**来源原语**：对称补全·双轴镜像对称·遮挡由镜像恢复（67b4a34d），区域填充（1190bc91），重涂色（0d3d703e），前景对象（963f59bc）

**依赖链**：双轴对称分析发现缺陷像素的位置与颜色 -> 缺陷颜色成为区域填充的种子色，缺陷位置成为填充起点 -> 对称图案的前景像素充当填充边界 -> 填充完成后修复缺陷像素为正确前景色以恢复对称。去掉对称分析则无法定位缺陷；去掉填充则仅修复几个像素毫无意义；去掉修复则对称性仍然破缺。

一句话总结：在一个近乎双轴对称的前景图案中找到打破对称的缺陷像素，以缺陷为种子在对称图案围出的封闭区域内扩散填充缺陷颜色，最后将缺陷本身修复为正确前景色。

**输入结构**：约 13x13 的黑(0)背景网格（行列数均为奇数，使对称中心恰好落在一个像素上）。一组蓝(1)前景像素构成一个关于网格中心同时具有水平和垂直镜像对称的图案。该图案可以是任意连通或不连通的对称形状（如十字、菱形边框、对称散点等），但其前景像素将背景划分为若干 4-连通封闭区域（封闭指被前景像素和/或网格边界完全围合）。图案中恰好有 2~3 个"缺陷"像素：这些位置本应为蓝(1)前景（由双轴对称可推知），但实际被替换成了各不相同的非黑非蓝颜色（从红(2)、绿(3)、黄(4)中选取）。每个缺陷像素所在的封闭背景区域互不相同。生成约束：缺陷像素始终位于封闭区域的边界上（即至少有一个 4-邻居是黑(0)背景且属于某个封闭区域），保证缺陷处于其所属封闭区域的入口位置。

**规则**：
1. 通过双轴（水平 + 垂直）镜像对称分析，找到所有不满足对称性的像素位置。这些位置即为缺陷，它们的实际颜色是非蓝非黑的特殊颜色。
2. 对每个缺陷像素，将其位置临时恢复为蓝(1)前景色（即假装对称完好），然后从缺陷的那个位置出发，向该位置 4-邻域中属于黑(0)背景的方向进行 4-连通区域填充，填充色为该缺陷的原始特殊颜色。填充在遇到蓝(1)前景像素或网格边界时停止。
3. 填充完成后，将所有缺陷位置的像素永久修复为蓝(1)（恢复完美对称）。
4. 若某个封闭区域不含任何缺陷像素，则该区域保持黑(0)背景不变。
5. 不同缺陷的填充区域不会重叠（由生成约束保证：每个缺陷在不同封闭区域的边界上）。

**关键洞察**：缺陷像素身兼两职——它既是打破对称性的"错误"，又是区域填充的种子和颜色来源。必须先利用对称性找到缺陷，才能确定填充位置和颜色；但填充的边界恰恰是对称图案本身。这一双重角色使得对称分析和区域填充不可分离。对称类型为双轴（非单轴），需对比多个示例方可确认。
