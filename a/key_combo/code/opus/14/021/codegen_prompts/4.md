## 新题 4：菱形边界对称补全后射线填充

**组合逻辑**：[对称补全(symmetry_completion)](已有, 创新：从矩形网格内部缺口填充变为菱形边界像素恢复) + [射线延伸(ray_extend)](已有) ← [双轴镜像轨道(two_axis_orbit)](已有, 创新：轨道作用于菱形边界而非矩形内部) + [遇阻停止(stop_at_blocker)](已有, 创新：阻挡物包含对称补全新生成的边界像素)

**来源原语**：对称补全/双轴镜像轨道/缺失像素/轨道内已知色唯一(af22c60d), 射线延伸/菱形框/侧标记/遇阻停止/框内填充(95755ff2)

**依赖链**：菱形边界的缺口 → 通过双轴镜像轨道补全边界 → 补全后的边界改变了菱形内部的阻挡几何 → 侧标记的射线在新几何下延伸直到被阻挡（包括新补全的像素）。对称补全的输出直接修改了射线延伸的约束条件。

先用双轴对称补全修复残缺的菱形边界，再从外侧标记向内发射射线，射线在补全后的完整几何中遇阻停止。

**输入结构**：约 17x17 的网格，绿(3) 色背景，包含：(a) 一个以网格中心为中心的单像素厚菱形框，菱形边界像素为蓝(1) 色，但有 3~5 个边界像素缺失（为绿色背景）；菱形关于水平中线和垂直中线具有双轴对称性。(b) 菱形外侧的上、下、左、右四个方向各有 0~2 个彩色标记像素（使用红(2)、黄(4)、橙(7) 等非蓝非绿色），位于菱形外接矩形的边上且在菱形对应边的法线方向上。(c) 菱形内部有 1~3 个灰(5) 色阻挡像素。（生成约束：缺失的边界像素在两个对称轴的镜像轨道中至少有一个已知同伴，保证补全唯一；每个标记像素的射线路径在补全前和补全后经过不同数量的内部像素，保证补全对结果有实质影响。）

**规则**：
1. 识别菱形框的水平和垂直对称轴（过菱形中心的水平线和垂直线）。
2. 对菱形边界上每个缺失像素（绿色背景位置但位于菱形几何边界上），收集其在两轴下的镜像轨道中所有已知（蓝色）的边界像素颜色，用唯一已知色填充该缺口。（本题中边界统一为蓝(1)，但对称轨道机制保证了缺口位置的确定。）
3. 边界补全后，每个外侧标记像素沿其所在边法线方向向菱形内部发射射线（上侧标记向下、右侧标记向左、下侧标记向上、左侧标记向右）。
4. 沿射线路径，将菱形严格内部的绿色背景像素涂为该标记的颜色。遇到任何非背景像素（包括蓝色边界像素——无论原有还是新补全的——以及灰色阻挡像素）时停止，不修改该阻挡像素。
5. 保留所有原始元素（包括补全后的边界、标记像素、阻挡像素）不变。

**关键洞察**：对称补全的结果直接改变了射线的可达范围——某条射线在残缺边界下本可穿透到更远处，但补全后新增的蓝色边界像素截断了它。两个操作共享菱形边界这一空间结构，前者修改它，后者依赖它，形成因果耦合。仅看单个示例难以区分"射线是被原有边界还是补全边界截断"。
