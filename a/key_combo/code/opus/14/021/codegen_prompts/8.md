## 新题 8：转置对称检测驱动表格单元分色填充

**组合逻辑**：[镜像(reflect)/沿主对角线转置(transpose_along_diagonal)](已有, 创新：转置不是整体变换，而是用于逐单元格对称性检测) + [填充(fill)](已有) + [重涂色(recolor)](已有) ← [对角对称(diagonal_symmetry)](已有, 创新：从整体网格属性变为单元格级别的布尔分类器) + [表格行列位(table_row_col_pos) + 角落与内部分色(corner_interior_differ)](已有, 创新：位置分色规则的作用对象由对称检测结果过滤)

**来源原语**：镜像/方阵/对角线/对角对称/沿主对角线转置(9dfd6313), 填充/分隔线网格/网格单元格/表格行列位/角落与内部分色(e9c9d9a1)

**依赖链**：将每个单元格与其转置配对单元格比较 → 判定每对是否对角对称 → 对称状态 + 单元格在表格中的位置（角落/内部/边缘）联合确定填充颜色。对称检测的布尔结果作为分色规则的第二维度输入。

检测方阵表格中每个单元格与其转置伙伴是否图案匹配，结合表格位置对单元格进行分色填充。

**输入结构**：约 17x17 的正方形网格，黑(0) 色背景，绿(3) 色分隔线将其划分为 4x4 共 16 个等大正方形单元格（每格约 3x3 内部空间）。整体表格是正方形，因此主对角线上的单元格 (i,i) 有对应转置伙伴 (i,i) 即自身，非对角线单元格 (i,j) 的转置伙伴为 (j,i)。每个单元格内部有一个由 1~4 个非绿非黑像素组成的小图案（使用灰(5) 色），形态各异。部分单元格对 (i,j) 和 (j,i) 的图案互为转置（即 (j,i) 的图案是 (i,j) 图案沿主对角线的镜像），其余单元格对不满足此关系。对角线上的单元格 (i,i) 的图案可能具有也可能不具有关于自身主对角线的对称性。（生成约束：16 个单元格中，角落单元格至少有一个是对称的，至少有一个不是对称的，保证位置和对称性两个维度都有变化。）

**规则**：
1. 对每个单元格 (i,j)，取出其 3x3 内部图案 P(i,j) 和其转置伙伴 (j,i) 的图案 P(j,i)。
2. 若 P(i,j) 沿主对角线镜像后等于 P(j,i)（即 P(i,j) 转置 == P(j,i)），则标记 (i,j) 为"对称"。对角线上的单元格 (i,i)：若 P(i,i) 自身关于主对角线对称，标记为"对称"，否则为"非对称"。
3. 分色规则（对称 + 位置联合决定）：
   - 对称 + 角落位置（表格的四个角：(0,0), (0,3), (3,0), (3,3)）→ 填充红(2) 色
   - 对称 + 严格内部位置（行列均不在外层：行 1~2 且列 1~2）→ 填充橙(7) 色
   - 对称 + 非角落的边缘位置 → 填充黄(4) 色
   - 非对称（任何位置）→ 填充蓝(1) 色
4. "填充"指将该单元格内所有非绿色像素（包括原灰色图案和黑色空位）统一替换为分配的颜色。绿色分隔线保持不变。

**关键洞察**：源题的表格分色仅依赖位置；源题的转置是整体网格操作。本题中转置对称性成为逐单元格的分类器，其分类结果与位置信息交叉后才决定颜色——既非纯位置规则也非纯对称规则，而是两者的联合判定。必须对比多个示例才能拆分出"位置"和"对称性"两个独立维度。
