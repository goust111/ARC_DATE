## 新题 9：路径连通筛选有效角点后缩小复制

**组合逻辑**：[缩小复制(shrink_copy)](已有) + [擦除(erase)](已有) ← [路径连通(path_connectivity)](已有, 创新：从颜色转移的路由变为角点有效性的过滤器) + [角点定义正方形(corners_define_square) + 已知角点推断中心(infer_center_from_known_corners)](已有, 创新：需先筛选有效角点，再执行几何推断)

**来源原语**：缩小复制/角点标记/中心像素/对角线位置/角点定义正方形/已知角点推断中心(11e1fe23), 路径网络/路径连通/端点决定目标/擦除(d35bdbdc)

**依赖链**：灰色路径连通性筛选"有效"标记像素 → 有效标记中找到三个构成正方形角点的组 → 推断第四角和中心 → 在中心处绘制缩小复制。路径连通是几何推断的前置过滤器：不筛选则会把干扰标记纳入角点计算导致错误。

沿灰色路径网络识别互相连通的角点标记，从中推断正方形几何并在中心绘制缩小复制。

**输入结构**：约 15x15 的网格，黑(0) 色背景。包含：(a) 5~7 个非背景单像素标记，使用红(2)、绿(3)、蓝(1) 等颜色（其中恰好 3 个位于某个轴对齐正方形的三个角上，其余为干扰标记）；(b) 灰(5) 色单像素宽路径段形成网络，连接部分标记。3 个角点标记通过灰色路径彼此 8-连通可达（可能经由中间路径节点，但不经过其他标记），干扰标记要么不与路径网络相连，要么虽连接到路径但无法通过路径到达任何角点标记。（生成约束：正方形的中心是整数坐标；正方形足够大使缩小复制与原角点标记不重叠；干扰标记不在推断的正方形几何附近。）

**规则**：
1. 沿灰(5) 色路径追踪 8-连通性。仅保留通过灰色路径彼此互相可达的标记像素集合（"有效标记"）。擦除所有非有效标记（替换为黑色背景）。
2. 有效标记恰好 3 个，位于某轴对齐正方形的三个角上。推断第四个角的位置。
3. 计算正方形中心（四角坐标的算术平均）。在中心位置绘制一个灰(5) 色像素。
4. 对每个有效角点标记，在中心与该角点方向上距中心一个对角步的位置，绘制一个与该角点同色的像素（即角点图案的缩小复制）。
5. 擦除所有灰色路径段（替换为黑色），保留原始 3 个角点标记和新绘制的中心+缩小复制。

**关键洞察**：源题中三个角点标记是唯一的前景像素，无需筛选；本题中网格上散布了干扰标记，路径连通性是唯一的过滤手段。如果忽略路径连通而尝试对所有标记做几何分析，会因干扰标记导致多种可能的正方形解释。路径网络在视觉上像装饰线条，但功能上是关键的逻辑过滤器。

6. 若规则有多个分支，生成器不能长期固定成一个分支；应让分支在随机样例中合理出现。分支概率不必平均——难以发现的隐蔽分支（如少数情况下才触发的特殊规则）应适当提高出现概率，确保在 3 个训练示例中至少出现一次，否则求解者无法归纳该规则。对于颜色映射类规则，确保 2 个左右的示例即可覆盖所有映射关系（每种颜色→颜色的映射至少在某个示例中出现过）。
