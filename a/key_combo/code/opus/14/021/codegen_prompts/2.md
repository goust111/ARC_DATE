## 新题 2：三角朝向编码叠加层序

**组合逻辑**：[透明叠加(transparent_overlay)](已有) + [重涂色(recolor)](已有, 创新：叠加前需根据三角朝向动态确定层序，而非固定象限位置) ← [朝向编码方向(orientation_encodes_direction)](已有, 创新：从编码射线方向变为编码层叠优先级) + [三角精灵体(triangle_sprite)](已有, 创新：从射弹发射器变为层序标识符)

**来源原语**：透明叠加/象限掩码/层叠顺序/四象限折叠同画布(75b8110e), 三角精灵体/朝向编码方向(409aa875)

**依赖链**：每个象限内的三角精灵朝向 → 解码为该象限的层叠优先级 → 按此优先级顺序将四个象限掩码叠加到同一画布。三角方向不解码则层序未知；层序不确定则叠加结果不确定。

解码每个象限角落处三角标记的朝向以确定四层掩码的叠加优先级，折叠到半尺寸画布。

**输入结构**：约 14x14 的网格，均匀黑(0) 色背景，被两条交叉的虚拟中线分为 2x2 四个等大区域（各约 7x7）。每个区域包含：(a) 一组单色前景像素形成一个掩码图案，四个区域分别使用红(2)、绿(3)、黄(4)、蓝(1) 四种不同颜色；(b) 在该区域的某个角落处（紧贴区域角），有一个由灰(5) 色组成的 3 像素轴对齐 L 形三角精灵（占据角落的 2x2 区域中的 3 格）。四个三角精灵的 L 形缺口方向各不相同，分别指向四个对角方向之一。不同示例中，同一象限内的三角朝向不同（生成约束：四个三角的缺口方向互不相同，构成四个对角方向的一个排列）。各区域的彩色掩码像素之间存在部分重叠位置（即叠加到同一画布时会有像素冲突）。

**规则**：
1. 识别每个区域角落的灰(5) 色 L 形三角精灵，确定其缺口方向（L 形中 2x2 正方形缺失的那个角的方向）。
2. 缺口方向到层叠优先级的映射：缺口朝左上 = 优先级 1（最底层，最先绘制），缺口朝右上 = 优先级 2，缺口朝左下 = 优先级 3，缺口朝右下 = 优先级 4（最顶层，最后绘制）。
3. 从每个区域提取彩色掩码（不含灰色三角），作为一个图层。
4. 创建一个区域大小的黑色输出画布。按层叠优先级从低到高的顺序，依次将四个掩码图层绘制到画布上，后绘制的覆盖先绘制的。
5. 输出该半尺寸画布。

**关键洞察**：源题中层叠顺序由象限位置硬编码（左上最先、右上最后）；本题中层叠顺序由三角精灵的朝向编码，同一象限在不同示例中可能有不同的层叠优先级。必须对比多个示例才能归纳出"缺口方向→优先级"的映射关系，因为仅看一个示例无法区分"位置决定层序"与"朝向决定层序"。
