## 新题 10：紧密拼接后涌现最大空矩形并填充

**组合逻辑**：[裁剪(crop) + 拼接(concatenate)](已有) + [搜索(search) + 填充(fill)](已有) ← [布局轴方向(layout_axis_direction) + 按位置紧密排列(tight_packing_by_position)](已有, 创新：紧密排列不是最终输出，而是中间步骤，其结果空间中涌现新几何特征) + [最大矩形填充(largest_rect_filled) + 最小边长约束(min_side_constraint)](已有, 创新：搜索目标不存在于原始输入中，仅在拼接后涌现)

**来源原语**：裁剪/拼接/连通精灵/布局轴方向/按位置紧密排列(67636eac), 搜索/填充/空心矩形区域/背景空间/最大矩形填充/最小边长约束(3eda0437)

**依赖链**：多个精灵裁剪+紧密拼接 → 拼接结果中精灵间隙形成新的空矩形区域 → 搜索最大空矩形 → 填充该矩形。空矩形在原始分散布局中不存在——它是拼接操作的涌现产物。

将分散的精灵紧密拼接后，在拼接结果中搜索并填充最大的涌现空矩形。

**输入结构**：约 15x20 的网格，黑(0) 色背景，包含 3~5 个单色（红(2) 色）8-连通精灵，彼此分离（最近像素间距 >= 3）。所有精灵的边界框形状相同（如都是 5x4）。精灵中心沿一个主轴（水平或垂直）分布，在该轴方向的跨度明显大于正交方向。每个精灵是不规则形状（非矩形填充），在其边界框内留有黑色空洞。（生成约束：精灵的具体形状经设计使得紧密拼接后，相邻精灵边界框之间的空洞对齐，形成至少一个 2x2 或更大的连续黑色矩形；该最大矩形在原始分散布局中不存在且唯一。）

**规则**：
1. 将每个精灵裁剪到其边界框。
2. 确定精灵的布局轴：若精灵中心在列方向的跨度大于行方向，为水平布局；否则为垂直布局。
3. 沿布局轴按精灵中心坐标排序，将裁剪后的边界框紧密拼接（去除所有间距，边框紧邻）。
4. 在拼接后的矩形画布中，枚举所有宽和高均 >= 2 的全黑矩形区域，找到面积最大者（若平局取最靠左上角的）。
5. 将该最大全黑矩形填充为绿(3) 色。
6. 输出拼接后的画布（含绿色填充的矩形和红色精灵像素）。

**关键洞察**：紧密拼接本身不产生最终输出——它创造了一个新的空间排列，在这个排列中涌现出一个在原始输入中根本不存在的几何特征（最大空矩形）。解题者必须先在脑中模拟拼接过程，才能预测空矩形的位置和大小。两步操作之间的耦合是涌现性的：拼接改变了空间拓扑，搜索依赖新拓扑。
