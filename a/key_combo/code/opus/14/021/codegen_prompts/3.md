## 新题 3：路径连通选靶 + 端点朝向旋转印章

**组合逻辑**：[印章覆盖(stamp_overlay)](已有) + [旋转(rotate)](已有) ← [路径连通(path_connectivity)](已有, 创新：从颜色转移的选靶机制变为印章分发的路由机制) + [朝向编码方向(orientation_encodes_direction)](已有, 创新：从射弹方向变为旋转角度编码) + [形状匹配(shape_matching)](已有)

**来源原语**：印章覆盖/空位接受印章/支撑签名匹配(e5062a87), 路径网络/路径连通/端点决定目标(d35bdbdc), 旋转(46442a0e), 朝向编码方向/三角精灵体(409aa875)

**依赖链**：路径连通性筛选出可到达的槽位（不可达的即使形状匹配也不接受印章）→ 每个可达槽位端点处的 L 形标记朝向决定印章的旋转角度 → 旋转后的印章覆盖到对应槽位。三个约束（形状匹配、路径可达、旋转角度）同时作用，缺一不可。

通过灰色路径网络将模板精灵路由到匹配的空槽位，按各槽位端点处方向标记的朝向旋转后印入。

**输入结构**：约 20x20 的网格，黑(0) 色背景。包含以下元素：(a) 一个红(2) 色模板精灵（4-连通，约 4~8 像素），周围附带灰(5) 色支撑结构像素（与精灵像素在同一边界框内，定义支撑签名）；(b) 4~6 个空槽位，每个由灰(5) 色支撑结构组成，形状与模板的支撑签名完全匹配，模板的红色像素对应位置为黑(0) 色；(c) 灰(5) 色单像素宽路径段从模板延伸，但仅连接其中 2~4 个槽位（部分槽位虽然形状匹配但无路径可达）；(d) 在每个槽位的路径入口处（路径与槽位支撑结构相邻的位置旁），有一个由橙(7) 色组成的 3 像素 L 形标记，L 形的缺口朝向四个正交方向之一（上、右、下、左）。不同槽位的 L 形标记朝向不同（生成约束：模板精灵不具 90 度旋转对称性，确保不同旋转产生可区分的结果）。

**规则**：
1. 识别模板精灵（红(2) 色图案）及其灰(5) 色支撑签名。
2. 扫描所有候选槽位：支撑结构与模板的灰色支撑签名完全匹配，且模板红色像素对应位置为黑色。
3. 在匹配的槽位中，仅保留通过灰色路径与模板 8-连通可达的槽位。
4. 对每个可达槽位，读取其路径入口旁的橙色 L 形标记，确定旋转角：缺口朝上 = 0 度，缺口朝右 = 90 度顺时针，缺口朝下 = 180 度，缺口朝左 = 270 度顺时针。
5. 将模板的红色图案以该旋转角旋转后，印入该槽位（红色像素覆盖对应黑色位置）。
6. 移除所有灰色路径段和橙色 L 形标记。保留模板本体、印章结果和所有灰色支撑结构。未被路径连接的槽位保持空（黑色）不变。

**关键洞察**：形状匹配是必要非充分条件——形状匹配但无路径可达的槽位不接受印章；路径可达也是必要非充分条件——还必须形状匹配。两重过滤同时生效后，旋转角度由第三个独立信号（L 形标记朝向）编码。仅看单个示例难以区分"路径连通是否是必需条件"——需要对比有路径连接和无路径连接的同形状槽位。
