## 新题 5：掩码并集识别互换色对的选择性段内互换

**组合逻辑**：[形状匹配(shape_matching) → 像素并集(pixel_union)](已有, 创新：并集检测不再标记操作数/目标，而是输出一个颜色对) + [颜色互换(color_swap)](已有, 创新：互换的色对不是预定义的固定映射，而是由并集检测动态确定) ← [对边配对(opposite_edge_pair)](已有) + [配对间像素互换(toggle_between_pairs)](已有, 创新：互换的颜色不固定，由另一个分析步骤确定)

**来源原语**：像素并集/双掩码并集等三/精灵体(fea12743), 颜色互换/标记像素/对边配对/配对间像素互换/网格边缘(d2acf2cb)

**依赖链**：六个精灵的掩码分析（找到并集关系的三元组）→ 两个操作数精灵的颜色确定互换色对 → 边缘标记对选定的行/列段内，执行该色对的互换。并集分析的输出（颜色对）是互换操作的输入参数；标记对选定作用范围。三者同时约束输出。

通过精灵掩码的并集关系发现两个互换颜色，然后在边缘标记对选定的行列段内执行该色对互换。

**输入结构**：约 18x18 的网格，黑(0) 色背景。包含两个区域：(a) 网格上半区：六个约 4x4 的单色精灵排列成 3x2 阵列，行间列间有 1~2 行/列黑色间隔。六个精灵分别使用红(2)、绿(3)、蓝(1)、黄(4)、橙(7)、青(8) 六种不同颜色，每个精灵在其 4x4 边界框内有非空前景掩码。恰好存在唯一一对精灵，其前景掩码的逐像素 OR 等于第三个精灵的掩码（每个操作数至少贡献一个唯一像素）。(b) 网格下半区：一个由多种颜色（包括上述六色中的至少四种）填充的约 8x8 彩色区域，黄(4) 色标记像素成对出现在该区域的对边上（左右边配对选定行、上下边配对选定列），共 2~3 对标记。（生成约束：操作数精灵的两种颜色在下半区的彩色区域中都有出现；彩色区域中不含上半区精灵。）

**规则**：
1. 在上半区的六个精灵中，将每个精灵裁剪到其 4x4 边界框，提取前景掩码（二值化为"有色/无色"）。
2. 枚举所有精灵对 (A, B)，检查是否存在第三个精灵 C 使得 mask(A) OR mask(B) == mask(C)，且 A 和 B 各自至少有一个 C 没有的像素不成立（即 A 和 B 的并集恰好等于 C，A 和 B 各自贡献至少一个独有像素）。找到唯一的 (A, B, C) 三元组。
3. 记录 A 和 B 的颜色为互换色对 (colorA, colorB)。
4. 在下半区，识别黄(4) 色标记对：左边沿与右边沿同行的标记对选定该行的严格内部段，上边沿与下边沿同列的标记对选定该列的严格内部段。
5. 在每个选定段内，将 colorA 的像素重涂为 colorB，将 colorB 的像素重涂为 colorA。其余颜色不变。
6. 上半区精灵、黄色标记和选定段之外的所有像素保持不变。

**关键洞察**：互换哪两种颜色并非预定义常量，而是由一个形状分析问题（掩码并集三元组检测）的输出动态决定。仅看下半区无法知道互换什么；仅看上半区无法知道互换发生在哪里。两个分析（掩码并集 + 边缘标记配对）各提供互换操作的一个关键参数。
