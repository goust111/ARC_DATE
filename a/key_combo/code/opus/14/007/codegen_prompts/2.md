## 新题 2：对称修复驱动的印章模板

**组合逻辑**：[对称补全](已有) + [裁剪](已有) + [印章覆盖](创新：模板不是预先给定的，而是通过对称修复动态生成) + [分隔行](已有) + [锚点像素](已有)

**来源原语**：对称补全/symmetry_completion(参考题 981571dc)、裁剪/crop(参考题 6b9890af, da6e95e5)、印章覆盖/stamp(参考题 a9f96cdd, b4a43f3b)、分隔行/separator_row(参考题 b4a43f3b)、锚点像素/anchor_pixel(参考题 a9f96cdd)、镜像对应/mirror_correspondence(参考题 981571dc)、推断对称轴/infer_symmetry_axes(参考题 981571dc)

**依赖链**：上半区的残缺图案通过对称轴推断 → 镜像对应修复缺失像素 → 修复后的完整图案裁剪为印章模板 → 模板被印在下半区的每个锚点位置。对称修复的结果直接决定印章内容，跳过修复则模板不完整、输出错误。

将上半区一个有像素缺失的双轴对称图案修复完整后，作为印章模板，粘贴到下半区每个锚点像素的位置上。

**输入结构**：约 18x10 的黑(0)背景网格，被一条完整的灰(5)水平分隔行分为上下两区。上半区（约 7 行）包含一个由多种颜色组成的图案，该图案具有关于自身中心的垂直和水平双轴对称性，但有 2-4 个像素被擦除为黑(0)（形成缺口）。该图案的边界框约 5x5 至 7x7，非黑像素至少使用 2 种颜色。擦除的像素分布使得从任意单轴都不能独立恢复所有缺失像素——至少需要两轴协同才能完全修复。下半区（约 10 行）是黑(0)背景上散布的 2-4 个红(2)锚点像素，锚点之间距离足够大，使得以锚点为中心粘贴上半区图案的边界框时彼此不重叠且不越界。生成约束：上半区图案在修复后具有严格的双轴对称性；下半区锚点位置确保粘贴后图案完全在网格内。

**规则**：
1. 在上半区，从所有非黑像素中推断垂直和水平两条对称轴的位置。
2. 对每个黑(0)像素，通过垂直轴和水平轴的镜像位置查找非黑像素：如果某个镜像位置有非黑像素，则用该颜色填补当前位置。如果两个轴的镜像都给出非黑候选且颜色不同，取通过两轴同时镜像（对角镜像）的第三个候选位置的颜色；若仍不唯一，保留与垂直轴镜像相同的颜色。
3. 将修复后的上半区图案裁剪为其最小边界框，得到印章模板 T。
4. 在下半区，对每个红(2)锚点像素，将 T 的中心像素对齐到锚点位置，粘贴 T 的全部非黑像素（覆盖锚点本身和周围的黑像素）。
5. 输出仅包含下半区（灰分隔行及上半区被移除）。

**关键洞察**：上半区的受损图案不能直接用作印章——它必须先经过双轴对称修复才能获得完整模板。缺失像素的位置经过设计，使得单看一个示例时可能误判对称轴位置，必须对比多个示例才能确认对称修复规则优先级。

## 实现要求

1. `main(grid)` 必须实现新题描述中的确定性转换规则，不能只识别 `generate_input()` 的固定模板。禁止不同的input网格输出相同的output网格。
2. `generate_input()` 必须随机生成多样样例，不能固定死。随机维度应覆盖：网格大小、对象数量、位置、颜色、方向、形状参数或关键分支。注意若描述中存在若干，需实现而不是只有单个，包括object或者对应关系等等。且若涉及到最短路径，则输入网格中必涉及到多条路径，对选择造成干扰。
3. 生成器必须保证输入满足 `main()` 的隐式假设：对象不重叠、不越界、特殊标记唯一或可区分、匹配关系无歧义、关键分支出现概率相同。
4. 禁止把 ARC 颜色 id 、亮度、拼写等当作人类不可见的数值语义参与排序、大小比较或隐藏映射。颜色变化必须有可见结构线索。注意颜色亮度、拼写等也是不可见信息，若描述中出现违规的颜色id或者亮度，可自行使用少量的固定颜色替代，但注意生成时要在三个以内输入输出网格中对所有变换100%覆盖度。
