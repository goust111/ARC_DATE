## 新题 4：频率过滤后碎片空间展布重建同心环

**组合逻辑**：[连通检测 + 计数](已有) + [跳过最高频](已有) + [同心层填充](已有) — 创新：统计频率用于颜色级过滤，过滤后存留颜色的全局空间展布范围（而非原始碎片帧大小）决定同心环尺寸

**来源原语**：
- 连通检测、单色连通体、计数、按数量降序 ← 参考题 2753e76c
- 跳过最高频、频率排序 ← 参考题 f8b3ba0a
- 同心层填充、同心正方形层、嵌套层次、按边长降序排列 ← 参考题 c658a4bd
- 忽略干扰项 ← 参考题 d4469b4b / a3325580

**依赖链**：连通检测 → 按颜色计数分量数 → 最高频颜色作为干扰项被剔除 → 存留颜色的全局 bounding box 边长作为环尺寸 → 按边长降序排列为同心环。删除频率过滤则多一个颜色进入环构建导致错误输出；删除全局 bbox 计算则不知环大小；删除同心构建则无输出结构。

一句话总结：在散落的彩色碎片中，剔除分量数最多的干扰颜色，将剩余颜色按其全局空间展布范围从大到小排为居中同心方环。

**输入结构**：约 16x16 黑(0)背景网格。网格上散布着 4-5 种非黑颜色的像素碎片。每种颜色形成多个小型 4-连通分量（每个分量 2-8 像素，形状不规则），各颜色的分量数互不相同。其中一种颜色的分量数严格多于其他所有颜色（至少多 2 个），此为干扰色。各颜色的碎片分布范围不同——有的颜色的碎片分散在网格的较大区域内，有的集中在较小区域。生成约束：(a) 剔除干扰色后，剩余每种颜色的全局正方形 bounding box 边长（见规则第 3 条定义）两两不同且均为奇数；(b) 最大的全局正方形 bbox 边长不超过 15。

**规则**：
1. 对每种非黑颜色，检测其所有 4-连通分量，统计分量数量。
2. 找出分量数最多的颜色 C_max，将该颜色的所有像素在输出中丢弃（不参与后续步骤）。
3. 对每种存留颜色 c，计算包含 c 的所有像素的最小轴对齐 bounding box 的行跨度 H 和列跨度 W，取 S_c = max(H, W) 作为该颜色的"展布边长"。
4. 将存留颜色按 S_c 从大到小排序。
5. 创建正方形输出网格（边长 = 最大的 S_c）。以网格中心为对称中心，从外到内依次绘制居中同心正方形环：最外环使用 S_c 最大的颜色，次外环使用 S_c 次大的颜色，以此类推。每个正方形环的边长等于该颜色的 S_c 值，绘制时只画外边框（宽 1 像素），内部由更内层的环或黑(0)背景填充。
6. 若相邻两层环的 S_c 值差恰好为 2，则两环紧密嵌套（无间隙）；若差大于 2，两环之间出现黑色背景间隙。

**关键洞察**：分量数最多的颜色是噪声干扰，必须通过统计识别并丢弃。存留颜色的输入坐标被完全抛弃——重建依据不是碎片的原始位置，而是它们在空间中的"展布范围"（全局 bbox 边长）。这是从统计度量（频率过滤）到几何度量（空间展布）再到结构重建（同心环）的三级跳跃，每级的输出改变了下一级的输入数据结构。
