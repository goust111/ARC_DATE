## 新题 2：质心导向重力与极值距离筛选

**组合逻辑**：[重力下落](创新：方向由质心偏移决定) + [排序](已有) + [重涂色 + 擦除](已有) — 创新：每个精灵有独立的重力方向，由其与吸引子的几何关系决定；落定后按距离执行极值筛选

**来源原语**：
- 重力下落、穿透与停靠 ← 参考题 84ba50d3
- 质心偏移定位 ← 参考题 4e45f183
- 排序、重涂色、擦除、保留极值高度分色 ← 参考题 a61f2674
- 距离 ← 参考题 b8cdaf2b

**依赖链**：吸引子位置 + 精灵质心 → 计算偏移方向 → 确定每个精灵的重力向量 → 精灵沿各自方向下落并停靠 → 计算落定后距吸引子的距离 → 按距离排序 → 仅保留最近和最远两个精灵并分别重涂色。删除方向计算则重力无定义；删除重力则位置不变导致距离排序结果不同；删除极值筛选则输出包含所有精灵。

一句话总结：精灵各自朝向吸引子方向坠落至网格边缘，落定后仅保留离吸引子最近（蓝）和最远（红）的两个精灵。

**输入结构**：约 15x15 黑(0)背景网格。网格中某个非中心、非边缘位置有一个栗(9)单像素标记作为"吸引子"。网格上散布 4-6 个小型精灵（各为不同非黑非栗颜色，4-连通，3-5 像素，形状各异），与吸引子互不相邻且不重叠。生成约束：(a) 每个精灵沿其确定的重力方向下落时，路径上不会与其他精灵的最终停靠位置冲突（即无论处理顺序如何，最终结果相同）；(b) 落定后各精灵到吸引子的曼哈顿距离两两不同，确保最近和最远唯一。

**规则**：
1. 栗(9)单像素为吸引子 A。
2. 对每个精灵 S，计算从 S 的 bounding box 中心（行列坐标各取 bounding box 上下/左右的算术均值并取整）到 A 的行偏移 dr（A 行号 - S 中心行号）和列偏移 dc（A 列号 - S 中心列号）。
3. 将偏移量化为四个基本方向之一：取 |dr| 和 |dc| 中较大者对应的轴方向（dr > 0 则向下，dr < 0 则向上，dc > 0 则向右，dc < 0 则向左）。若 |dr| = |dc|，优先取垂直方向（即按 dr 的符号取上或下）。
4. 将精灵整体沿该方向平移，保持内部像素布局不变，直至精灵 bounding box 的前沿抵达网格边缘（最前沿行/列触碰第 0 行/第 0 列/最后一行/最后一列）。
5. 所有精灵落定后，计算每个精灵新 bounding box 中心到 A 的曼哈顿距离。
6. 距离最小的精灵重涂为蓝(1)；距离最大的精灵重涂为红(2)。
7. 所有其他精灵擦除为黑(0)背景。
8. 吸引子标记自身也擦除为黑(0)背景。

**关键洞察**：每个精灵拥有个性化的重力方向——这不是全局物理力，而是由精灵与吸引子的空间关系编码的定向推力。初始位置编码了方向信息，但最终位置（经重力后）编码了距离排名，两层信息在不同阶段各自发挥不同的决策作用。
