## 新题 3：标尺长度像素放大与镜像位置放置

**组合逻辑**：[像素放大](已有) + [平移/镜像](已有) + [归一化朝向](已有) — 创新：标尺的长度被重新解释为缩放因子（而非平铺重复次数），标尺同时编码大小、位置和朝向三重信息

**来源原语**：
- 标尺条、端部附着、标尺长度决定重复 ← 参考题 9c1e755f（长度含义被创新为缩放因子）
- 像素放大 ← 参考题 8a6d367c
- 平移、镜像位置、内部朝向不变 ← 参考题 8ee62060
- 归一化朝向、宽高互换 ← 参考题 d749d46f

**依赖链**：标尺方向 → 决定是否旋转母题以归一化朝向 → 标尺长度 → 作为像素放大的缩放因子 → 标尺位置 → 水平镜像得到放置位置 → 将放大后的母题绘制到镜像位置。删除归一化则竖直标尺产生错误朝向的放大图；删除镜像则不知放置位置；删除缩放则母题尺寸错误。

一句话总结：从标尺末端提取母题，按标尺长度像素放大，将放大结果放置到标尺的水平镜像位置。

**输入结构**：约 20x18 黑(0)背景网格。网格左半区有 2-3 条灰(5)标尺条，部分为水平方向、部分为竖直方向，长度各为 2-4 格。每条标尺的一端紧邻附着一个小型彩色母题（bounding box 为 2x2 或 2x3，使用非黑非灰颜色，每条标尺的母题颜色和形状各异）。水平标尺的母题附着在其右端，竖直标尺的母题附着在其下端。标尺条之间互不相邻。右半区为空白黑色背景，用于放置放大后的母题。生成约束：每条标尺的缩放后母题尺寸（= 母题 bounding box 各维度 x 标尺长度）不超过网格右半区的可用空间，且不同标尺对应的放大结果在右半区互不重叠。

**规则**：
1. 对每条标尺条依次处理（按标尺 bounding box 左上角的行优先、列次优先排序）：
   a. 提取其末端附着的母题，裁剪到最小 bounding box。
   b. 若标尺为竖直方向，将母题顺时针旋转 90 度（归一化为水平朝向）；若标尺为水平方向，母题保持不变。
   c. 记录标尺的长度 L（以格数计，不含母题本身）。
   d. 对（可能已旋转的）母题进行像素放大：母题中每个像素扩展为 L x L 的同色方块，背景像素扩展为 L x L 的背景块。
   e. 计算标尺条的水平镜像列位置：设标尺 bounding box 的最左列为 c0、bounding box 宽度（含母题整体的宽度）为 w，镜像后的最左列 = grid_width - w - c0。
   f. 将放大后的母题绘制到镜像位置，其顶行与原始标尺 bounding box 的顶行齐平。
2. 原始标尺条和母题在输出中保持不变。
3. 若多个放大母题在镜像区域有重叠（根据生成约束不应发生），后处理的覆盖先处理的。

**关键洞察**：标尺条承担三重角色——末端标识母题（"是什么"），长度编码缩放因子（"放大多少"），位置编码目标放置点（"放在哪儿"，通过水平镜像推算）。竖直标尺额外触发母题旋转，使得标尺方向也隐含了朝向信息。这种多义复用在参考题中不存在：9c1e755f 的标尺只控制平铺重复次数，8ee62060 的镜像不涉及缩放，8a6d367c 的缩放因子来自帧尺寸而非标尺。

Input structure

Rule
