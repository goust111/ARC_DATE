## 新题 9：十字标记臂色选取滑动体并确定碰撞优先级

**组合逻辑**：[图案识别/十字标记](已有) → [同色匹配](创新：匹配对象从精灵-框架变为标记臂色-矩形体) → [滑动/沿杆滑至锚定物](创新：滑动的选择性由标记匹配决定) → [碰撞阻挡](创新：碰撞优先级由标记重复色规则决定) → [擦除](已有)

**来源原语**：图案识别/十字标记/中心与臂颜色/重复色为答案/忽略干扰项(642d658d)、滑动/矩形体/连接杆/碰撞阻挡/沿杆滑至锚定物(98cf29f8)、同色匹配(8f215267)、擦除(98cf29f8)

**依赖链**：识别十字标记并提取臂色 → 臂色匹配矩形体决定哪些体需要滑动 → 重复臂色规则确定优先滑动体 → 优先体先滑动，其终止位置成为后续体的障碍 → 连接杆指示滑动方向后被擦除。这是一个"隐式编码"型题目：十字标记的几何结构编码了滑动选择和碰撞优先级两条信息。

识别黄心十字标记的臂色，匹配对应的矩形体进行滑动，重复出现的臂色对应的矩形体优先移动。

**输入结构**：约 18x18 的网格，黑(0)为背景。网格中散布 3~5 个不同颜色的矩形体（每个为 2x2 至 3x4 的实心单色矩形，颜色从蓝(1)、红(2)、绿(3)、橙(7)、品红(6)中选取）。每个矩形体有一条单像素宽的同色连接杆从矩形体某一侧向一个基数方向延伸 2~5 格。网格中另有 2~4 个黄(4)中心十字标记（每个为黄(4)中心像素加四个同色正交邻接臂像素），各标记的臂色为上述矩形体颜色之一。生成约束：恰好有一种臂色出现在两个或更多标记上（重复色），其余臂色各出现一次；每种出现在标记臂上的颜色都对应一个矩形体；至少一个矩形体的颜色不出现在任何标记臂上；连接杆方向上无其他矩形体直接阻挡（但优先体滑动后可能阻挡后续体）。

**规则**：
1. 找到所有黄(4)中心的十字标记，提取每个标记的臂色（四臂颜色相同）。
2. 统计各臂色的出现次数。恰好出现 2 次以上的臂色为"优先色"。
3. 颜色与某标记臂色匹配的矩形体标记为"活跃体"。颜色不匹配任何标记臂色的矩形体保持静止。
4. 优先色对应的活跃体首先滑动：沿其连接杆方向移动，移动距离等于连接杆长度，直到矩形体到达网格边缘或碰到另一个矩形体（以先到者为准）。连接杆在滑动后擦除。
5. 其余活跃体随后滑动：规则同上，但此时优先体的终止位置已成为新障碍。多个非优先活跃体之间按其边界框左上角行优先、列其次的顺序依次滑动。
6. 十字标记在输出中保持不变。静止矩形体保持不变。

**关键洞察**：十字标记不是装饰而是操作指令——臂色选择了哪些矩形体参与滑动，而同一臂色在多个标记上的重复出现编码了碰撞优先级；不识别标记就无法确定移动顺序。
