## 新题 1：迷宫路径距离决定精灵排列顺序

**组合逻辑**：[洪泛填充](创新：不用于着色而用于计算BFS距离) → [面积排序](创新：排序键由迷宫拓扑距离替代面积) → [基线对齐排列](已有) → [擦除](已有)

**来源原语**：洪泛填充/路径连通(b782dc8a)、排序/面积排序(4df5b0ae, beb8660c)、精灵体(4df5b0ae, e41c6fd3)、迷宫走廊(b782dc8a)、基线对齐排列(4df5b0ae)

**依赖链**：迷宫的拓扑结构决定 BFS 距离 → BFS 距离作为排序键替代几何属性 → 排序结果决定精灵体的输出排列位置。删除迷宫则距离无法计算；删除排序则布局无法确定；删除精灵提取则无输出内容。

从迷宫入口出发计算到各精灵体的路径距离，按距离远近排列精灵体。

**输入结构**：约 18x18 的网格，黑(0)为背景。青(8)像素构成迷宫壁，形成单像素宽的走廊网络（走廊为黑(0)像素），走廊保证连通且无环路。3~5 个单色 4-连通精灵体（每个 3~6 像素，颜色各不相同，从红(2)、绿(3)、蓝(1)、橙(7)、品红(6)中选取）分别嵌在不同的走廊死端处（精灵体的某一像素与走廊黑像素 4-邻接）。一个栗(9)像素位于网格某一边缘的走廊入口处，作为 BFS 起点。生成约束：从栗(9)起点到各精灵体的最短路径长度互不相同；精灵体互不接触。

**规则**：
1. 从栗(9)起点出发，沿黑(0)走廊像素进行 4-连通 BFS 扩展。每个走廊像素记录其 BFS 距离值。青(8)壁和精灵体像素不可通行。
2. 对每个精灵体，取其所有像素中与走廊黑像素 4-邻接的像素，找到这些邻接走廊像素中 BFS 距离最小的值，作为该精灵体的距离键。
3. 按距离键从小到大排序所有精灵体。
4. 提取每个精灵体的边界框（框内非精灵体像素视为透明）。
5. 输出网格高度等于最高精灵体的边界框高度，宽度等于所有边界框宽度之和加上间隔列数（相邻精灵体之间 1 列黑(0)间隔）。按排序结果从左到右放置精灵体，底部对齐。
6. 栗(9)起点、迷宫壁、走廊均不出现在输出中。

**关键洞察**：精灵体的排列顺序既不由其空间坐标决定，也不由其面积决定，而由迷宫的拓扑路径长度决定——两个在网格上相邻的精灵体，在迷宫路径中可能相距很远。

- Each marker has exactly one background 4-neighbor, the doorway gap; the next cell outward is the exterior doorway cell.

- Treat all existing foreground cells as blockers.
- Between the two exterior doorway cells, allow only row/column steps that move toward the other exterior cell.
- Paint every background cell that lies on some such path from one exterior cell to the other, plus the two doorway gaps, yellow.

Key insight
- The output is not a single chosen route: it is the union of all shortest monotone paths that can pass between the two frames.
