## 新题 4：精灵面积排名重写行控制色驱动占位符重涂

**组合逻辑**：[计数](创新：计数对象从精灵实例数变为单个精灵的像素面积) → [排序](已有) → [行首色决定填色](创新：控制色不是预设而是由排序结果动态指派) → [重涂色](已有)

**来源原语**：计数/前景像素(d631b094)、排序/面积排序(4df5b0ae, 8abad3cf)、重涂色/占位像素/控制像素/行首色决定填色(c9f8e694)、擦除(98cf29f8)

**依赖链**：精灵面积测量 → 面积排名建立排序 → 排序名次与行位置配对 → 配对结果替换控制像素颜色 → 新控制色决定占位符最终颜色。任何一步被删除，控制像素的颜色指派都无法确定，占位符颜色也随之失效。

测量散落精灵体的面积并排名，用排名顺序重新指派各行的控制色，再据此重涂占位符。

**输入结构**：约 15x15 的网格，黑(0)为背景。第 0 列的若干行各有一个控制像素（颜色各不相同，从红(2)、蓝(1)、绿(3)、橙(7)中选取），这些行散布着灰(5)占位像素形成的连通形状（每个形状跨 1~3 行，同一行内可有多个灰(5)像素，形状在行间通过 4-连通相连）。网格右半区散布着与控制像素同色的单色 4-连通精灵体（每种颜色恰好 1 个精灵体，每个 3~8 像素），精灵体之间互不接触，也不接触占位像素或控制像素。生成约束：精灵体数量等于控制像素行的数量；各精灵体面积互不相同；控制像素行从上到下排列。

**规则**：
1. 测量每个精灵体的像素面积。
2. 按面积从小到大排列所有精灵体，建立排名序列 S1, S2, ..., Sn（S1 面积最小）。
3. 将控制像素行按从上到下编号为第 1 行、第 2 行、...、第 n 行。
4. 将第 k 行的控制像素颜色替换为排名第 k 的精灵体 Sk 的颜色（即面积最小的精灵体颜色指派给最上方的控制行，依此类推）。
5. 对每个含控制像素的行，将该行所有灰(5)占位像素重涂为该行当前控制像素的颜色。
6. 擦除右半区所有精灵体。

**关键洞察**：原始控制像素的颜色是"假线索"——它们会被精灵面积排名的结果完全覆盖；真正决定占位符颜色的是精灵体之间的面积大小关系。
