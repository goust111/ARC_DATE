## 新题 6：十字射线划分区域后以边界主色洪泛填充

**组合逻辑**：[射线延伸](已有) → [交叉点特殊着色](已有) → [洪泛填充](创新：填充色不由种子决定而由围成区域的边界颜色组成决定) → [碰撞阻挡](创新：墙壁阻断射线传播而非物体滑动)

**来源原语**：射线延伸/孤立像素/十字图案/交叉点特殊着色(23581191)、洪泛填充/路径连通(b782dc8a)、碰撞阻挡(98cf29f8)

**依赖链**：种子像素发出射线 → 射线被墙壁截断形成有限线段 → 线段与墙壁共同划分空间为封闭区域 → 每个封闭区域的边界颜色组成决定填充色 → 交叉点标记为特殊色。这是一个"结构解构"型题目：输入看似简单（两个像素和几段墙），但输出需要理解射线、墙壁、区域划分三者的交互。

从两个种子像素发射十字射线（遇墙停止），射线和墙壁将网格划分为区域，每个封闭区域按边界主色填充。

**输入结构**：约 15x15 的网格，黑(0)为背景。两个孤立前景像素分别为橙(7)和蓝(1)，不在同一行或同一列。3~5 段青(8)墙壁线段散布在网格中（每段为水平或垂直的连续青(8)像素，长度 3~7，不与种子像素同行同列位置重叠但可能截断射线路径）。生成约束：两个种子像素的射线至少各被一段墙壁截断；射线和墙壁共同形成的线段网络至少划分出 3 个完全封闭区域（四面均有射线或墙壁或网格边缘围合）；两个种子像素不被同一封闭区域包含。

**规则**：
1. 从橙(7)像素出发，沿其所在行向左右、所在列向上下各发射一条射线。射线沿途将黑(0)像素涂为橙(7)。射线遇到青(8)墙壁像素或网格边缘时停止（不覆盖墙壁像素，停在墙壁前一格）。
2. 从蓝(1)像素出发，以相同方式发射四条蓝(1)射线。蓝射线遇到青(8)墙壁、橙(7)射线像素或网格边缘时停止。
3. 在橙(7)射线与蓝(1)射线交叉的位置（某像素同时处于一条橙射线和一条蓝射线的延伸路径上），将该像素标记为红(2)。
4. 射线和墙壁将网格划分为若干区域。对每个完全封闭的区域（由射线像素、墙壁像素和网格边缘围合，内部全为黑(0)），统计其边界上橙(7)像素数和蓝(1)像素数（不含红(2)和青(8)）。
5. 若边界上橙(7)像素多于蓝(1)像素，用橙(7)填充该区域。反之用蓝(1)填充。相等时用红(2)填充。
6. 不完全封闭的区域（与网格边缘相邻且无射线/墙壁围合的区域）不填充，保持黑(0)。

**关键洞察**：射线不只是视觉线条而是空间划分的边界；每个被围合区域的填充色取决于围合它的两种射线的数量对比——这一规则需要对比多个示例中不同区域的填充结果才能归纳。
