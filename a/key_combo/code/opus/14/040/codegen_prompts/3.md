## 新题 3：框架同色精灵计数驱动地形列重涂

**组合逻辑**：[计数/同色匹配](已有) → [列高度极值](创新：不再标记唯一极值，而用计数结果选取多个极值列) → [重涂色](创新：重涂对象从像素变为整列地形上方区域)

**来源原语**：计数/空心框架/图案精灵体/同色匹配/计数映射点数(8f215267)、地形轮廓/列高度极值(e45ef808)、重涂色(c9f8e694, e45ef808)、擦除(98cf29f8)

**依赖链**：同色精灵计数给出每种颜色的数量 → 数量值选取地形中对应数目的最深列 → 被选列的地形上方背景被重涂为框架颜色。删除计数则不知道选几列；删除地形深度分析则不知道选哪些列；删除重涂则无可见输出变化。

统计每个框架颜色对应的精灵数量，用该数量选取地形中最深的若干列并涂上框架颜色。

**输入结构**：约 20x15 的网格，黑(0)为背景。网格分三个纵向区域：(a) 顶部区域（约 4 行）散布 3~8 个小型单色 4-连通精灵体（每个 2~4 像素），颜色从蓝(1)、绿(3)、橙(7)中选取，可有多个同色精灵体。(b) 中间区域（约 4 行）包含 2~3 个空心矩形框架，每个框架颜色从蓝(1)、绿(3)、橙(7)中选取且与至少一个精灵体颜色匹配，框架之间不重叠，框架内部为黑(0)。(c) 底部区域（约 7 行）为灰(5)地形轮廓：每列由若干黑(0)背景像素后接连续灰(5)像素直到底部，各列地形起始行不同形成起伏轮廓。生成约束：每种框架颜色对应的精灵计数互不相同且均不超过地形总列数的一半；各列地形深度（地形起始行以上的黑(0)像素行数）互不相同。

**规则**：
1. 对每种框架颜色 C，统计顶部区域中颜色为 C 的精灵体数量，记为 N(C)。
2. 计算地形轮廓中每列的"深度"（该列地形起始行以上的黑(0)像素行数）。
3. 将所有列按深度从大到小排序。对每种框架颜色 C，选取排名前 N(C) 的深度最大的列。
4. 将被选列中地形起始行以上的所有黑(0)像素重涂为颜色 C。
5. 若两种颜色的选取列有冲突（同一列被多种颜色选取），以计数 N 较大的颜色优先。
6. 擦除顶部区域的所有精灵体。框架保持原样。地形灰(5)像素不变。

**关键洞察**：精灵体的数量不是直接变成输出图案，而是间接控制"选取几列地形进行涂色"——计数结果经过地形深度排序的中介才映射到空间位置。
