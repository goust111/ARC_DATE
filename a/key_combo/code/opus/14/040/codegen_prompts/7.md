## 新题 7：瓦片降噪后的色频编码线段排序键

**组合逻辑**：[降噪](已有) → [压缩](已有) → [计数](创新：计数对象从精灵体变为粗网格中的同色像素频率) → [排序](创新：排序键不是线段自身属性而是外部色频查表) → [按长度递增堆叠](创新：堆叠顺序由色频替代长度)

**来源原语**：降噪/瓦片/噪声像素/忽略标记取主色/网格分块(5614dbcf)、压缩(5614dbcf, 80214e03)、计数(8f215267, d631b094)、排序/线段/条带/按长度递增堆叠(beb8660c)

**依赖链**：瓦片降噪 → 压缩产出粗网格 → 粗网格中各色频率计算 → 色频作为线段的排序键（通过颜色匹配关联） → 排序后堆叠输出。删除降噪则粗网格颜色可能被灰噪声干扰导致频率错误；删除压缩则无法统计色频；删除色频计算则排序键未知；排序和堆叠缺一则输出布局无法确定。

将瓦片网格去噪压缩后统计各色出现频率，用频率作为排序键重排下方的彩色线段并堆叠。

**输入结构**：约 21x15 的网格，黑(0)为背景。上半区（约 9 行 = 3 块行 x 3 像素）包含一个由 3x3 瓦片组成的矩阵（至少 3 行 4 列瓦片）。每个瓦片由一种主色填充（从蓝(1)、红(2)、绿(3)、橙(7)中选取，至少 8/9 像素为主色），部分瓦片包含 1~2 个灰(5)噪声像素。纯背景瓦片（全为黑(0)或仅含灰(5)和黑(0)）也存在。下半区（约 6 行）有一条栗(9)全宽条带在最底行，其上方散布 2~4 条单像素厚的水平彩色线段（各线段颜色从蓝(1)、红(2)、绿(3)、橙(7)中选取，颜色各不相同，长度各不相同）。生成约束：线段颜色集合是瓦片主色集合的子集；各颜色在粗网格中的出现频率互不相同。

**规则**：
1. 对上半区的瓦片矩阵：将每个 3x3 瓦片替换为其非灰(5)、非黑(0)的主色（仅含灰和黑的瓦片替换为黑(0)），得到粗网格。
2. 在粗网格中统计每种非黑(0)颜色出现的像素数，得到色频映射 F(C)。
3. 对下半区的每条水平线段，通过颜色匹配查表获取其排序键 F(线段颜色)。
4. 按排序键从小到大排列线段。排序键相同时（生成约束保证不会发生），按线段长度从短到长排列。
5. 清除下半区线段的原始位置。将排序后的线段从上到下（键值最小的在最上方）逐行放置在栗(9)条带正上方的连续行中，每条线段右对齐到网格右边缘。
6. 上半区瓦片矩阵在输出中保持原样（不压缩）。栗(9)条带不变。

**关键洞察**：线段的排列顺序不由其自身长度或位置决定，而由上半区瓦片网格中同色瓦片的出现频率决定——瓦片区域是一张隐藏的排序查找表。
