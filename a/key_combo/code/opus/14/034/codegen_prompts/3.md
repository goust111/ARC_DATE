## 新题 3：去遮挡-镜像补全-隐藏锚点转印

**组合逻辑**：[擦除](已有) → [镜像补全](已有) → [锚点发现](创新：锚点物理隐藏在遮挡物下，只有擦除后才出现) → [平移复制](已有)

**来源原语**：擦除、镜像、遮挡、填充矩形、去遮挡后镜像还原 from 3345333e；平移复制、锚点对齐、源锚点、目标锚点、锚点偏移对应 from 2c737e39

**依赖链**：遮挡矩形同时隐藏了精灵体的缺失部分和源锚点标记。擦除遮挡物后，需要镜像补全精灵体才能确定哪些恢复出的像素是精灵体的一部分、哪些是锚点标记（锚点颜色不同于精灵体颜色）。锚点标记与网格上的孤立目标标记配对后，确定平移复制的偏移量。四个步骤构成严格的信息依赖链，任何一步被跳过都会导致后续步骤无法执行。

移除遮挡矩形，镜像补全精灵体还原完整形状，发现隐藏在遮挡区域内的锚点标记，将完整精灵体复制到对应的目标锚点位置。

**输入结构**：
- 约 25x25 黑(0)背景网格
- 2-3 个单色精灵体（各 12-20 像素，4-连通，不规则形状但具有左右镜像对称），颜色各不同（如蓝(1)、绿(3)、品红(6)）
- 每个精灵体的对称轴一侧被一个纯色填充矩形（栗(9)色，约 4x5 像素）部分遮挡，矩形恰好覆盖精灵体对称轴一侧的所有像素以及对称轴上的部分像素。被遮挡的区域在输入中显示为栗(9)色
- 在每个遮挡矩形所覆盖的区域内——确切地说，在被遮挡的精灵体像素之间的黑色空隙处——隐藏着一个灰(5)像素（源锚点）。该灰像素在输入中被栗(9)矩形覆盖，不可见
- 网格的空旷区域（距离所有精灵体和遮挡矩形至少 5 像素的位置）有与精灵体数量相同的孤立灰(5)目标锚点像素
- 生成约束：(a) 精灵体镜像补全后互不重叠；(b) 每个源锚点与距其最近的目标锚点配对时无歧义（最近距离唯一，使用曼哈顿距离）；(c) 平移复制后的精灵体副本不与原始精灵体、其他副本或遮挡矩形原位置重叠；(d) 遮挡矩形内的灰(5)像素位于精灵体补全后的像素之间的空隙处（即该灰像素的位置在补全后的精灵体掩码中是黑(0)背景）

**规则**：
1. 识别所有栗(9)色 4-连通填充矩形区域，将其所有像素擦除为黑(0)。
2. 擦除后，原矩形区域内显露出两类像素：灰(5)像素（源锚点）和黑(0)像素（精灵体的缺失部分和空隙）。精灵体的可见部分保持原色。
3. 对每个精灵体执行左右镜像补全：检测精灵体当前可见像素的竖直对称轴（沿列方向），将可见像素关于该轴镜像，在缺失位置填充精灵体颜色。对称轴位置取可见像素列范围的中点。
4. 补全后，确认灰(5)像素不属于任何精灵体（灰与精灵体颜色不同）。将每个灰(5)像素识别为源锚点，归属于其最近的精灵体（欧氏距离到精灵体最近像素最小的那个）。
5. 将每个源锚点与距其曼哈顿距离最近的孤立灰(5)目标锚点配对。
6. 对每个精灵体，计算源锚点到配对目标锚点的偏移向量 (dr, dc)，将补全后的完整精灵体平移 (dr, dc) 绘制到输出网格上。原始位置的精灵体保持不变。
7. 将所有灰(5)像素（源锚点和目标锚点）擦除为黑(0)。

**关键洞察**：源锚点被遮挡矩形物理覆盖，在输入中完全不可见。只有先擦除遮挡物并镜像补全精灵体后，才能在原遮挡区域中分辨出"属于精灵体的像素"和"不属于精灵体的灰色锚点"——后者才是控制复制目标的关键信息。
