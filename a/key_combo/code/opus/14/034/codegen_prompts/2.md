## 新题 2：平移-旋转双约束联合修复

**组合逻辑**：[补全/inpaint（平移轨道）](已有) + [对称补全（旋转轨道）](已有) → 联合约束求解（创新：两种对称性必须交替迭代使用，单独任何一种都不够）

**来源原语**：补全、平移对称、周期瓦片、轨道可见色填缺失 from 0dfd9992；对称补全、旋转对称、四次旋转闭合 from e40b9e2f

**依赖链**：这不是流水线结构，而是同时约束满足。网格同时具有平移周期性和瓦片内旋转对称性。某些缺失像素仅能由平移轨道恢复，某些仅能由旋转轨道恢复，而第三类像素的两种轨道中都存在其他缺失值——必须先通过一种对称恢复轨道中的中间值，再通过另一种对称间接恢复目标像素。两种对称约束交替迭代，不存在固定执行顺序。

利用网格的平移周期性和每个瓦片内部的旋转对称性联合恢复所有被遮挡像素，两种约束交替迭代求解。

**输入结构**：
- 约 16x16 网格，由 2x2 排列的四个 8x8 瓦片组成（瓦片之间无分隔线，直接拼接，左上瓦片占行 0-7 列 0-7，右上占行 0-7 列 8-15，依此类推）
- 四个瓦片是同一个基础图案的平移副本（内容完全相同）
- 基础图案本身具有 4 重旋转对称（以瓦片中心为轴，90° 旋转不变），使用 3-4 种颜色（蓝(1)、红(2)、绿(3)、黄(4)）在黑(0)背景上绘制，非黑像素约占瓦片面积的 40-60%
- 网格中 15-25 个像素被替换为灰(5)，表示缺失数据。灰(5)像素的分布经过精心设计，分为三类：
  - A 类（约 1/3）：该像素在至少一个其他瓦片的对应位置是非灰的，可仅通过平移对称恢复
  - B 类（约 1/3）：该像素在所有四个瓦片的对应位置都是灰(5)，但在同一瓦片内的 90°/180°/270° 旋转轨道中至少有一个位置是非灰的，可仅通过旋转对称恢复
  - C 类（约 1/3）：该像素在所有四个瓦片的对应位置都是灰(5)，且在同一瓦片内的旋转轨道中也全为灰(5)——但其旋转轨道中的某个灰像素属于 A 类（可通过平移先恢复），恢复后该位置变为非灰，从而通过旋转对称间接解锁 C 类目标像素
- 生成约束：使用两种对称联合迭代求解后，每个灰像素的颜色唯一确定；不存在需要三次以上迭代才能恢复的像素

**规则**：
1. 识别平移周期：网格由 2x2 相同瓦片组成，周期向量为 (8,0) 和 (0,8)。
2. 识别旋转对称：每个瓦片以其几何中心（第 3.5 行、第 3.5 列，相对于瓦片左上角）为旋转中心，具有 4 重旋转对称。
3. 第一轮——平移修复：对每个灰(5)像素，检查其在其他三个瓦片中对应位置的颜色。若找到非灰颜色，将目标像素替换为该颜色。若多个非灰副本存在，它们必然颜色相同（由周期性保证）。
4. 第二轮——旋转修复：对每个仍为灰(5)的像素，检查其在同一瓦片内 90°、180°、270° 旋转位置的颜色。若找到非灰颜色（包括第一轮中刚恢复的），将目标像素替换为该颜色。
5. 如果仍有灰(5)像素残留，重复步骤 3-4 直到所有灰像素被恢复（生成约束保证最多两轮迭代即可完成）。
6. 输出与输入同尺寸，所有灰(5)像素被替换为正确颜色，其余像素不变。

**关键洞察**：C 类像素在四个瓦片中的对应位置和瓦片内的旋转轨道中初始全部为灰——单独使用任何一种对称都无法恢复它。但其旋转轨道中包含一个 A 类像素，该像素可先通过平移对称恢复，恢复后的值再通过旋转对称传递给 C 类目标。必须交替使用两种约束才能解锁所有缺失值。

<description>
Recolor each closed orthogonal line loop so convex bend pixels are yellow and concave bend pixels are red.

Input structure
- The grid has a dominant background and exactly one foreground color.
- The foreground forms one or more 4-connected one-pixel-wide closed cycles; every foreground pixel has degree 2.
Rule
- Trace each cycle and inspect the turn at each foreground pixel.
- Straight pixels keep the original foreground color.
- Bend pixels whose turn direction is the majority direction for that cycle are convex corners and become yellow.
- Bend pixels whose turn direction is the minority direction for that cycle are concave corners and become red.
Key insight
- A simple rectilinear closed boundary has exactly four more convex bends than concave bends, so convexity can be inferred structurally from the majority turn sign within each traced cycle.
