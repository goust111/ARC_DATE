## 新题 7：交替转向路径上的锚点印章

**组合逻辑**：[路径模拟](已有) + [交替转向](已有) + [平移复制](创新：在路径每个转向点处以该点为锚印下精灵体副本) + [重涂色（颜色循环）](已有)

**来源原语**：路径模拟、交替转向、碰撞停止、粒子、起始标记、颜色循环 from 195c6913；平移复制、锚点对齐、源锚点、锚点偏移对应 from 2c737e39；重涂色 from 4ff4c9da

**依赖链**：交替转向规则决定了粒子在边界碰撞时左转还是右转，由此确定路径的每个转向点坐标。这些坐标作为锚点，将精灵体副本印到对应位置。每个印章的颜色由其在路径中的转向顺序决定——第 k 个转向点使用颜色循环的第 k 色。路径模拟→转向点发现→锚点印章→循环取色形成四环依赖链，且交替转向的左/右交替模式使得转向点位置不可由简单规律预测。

粒子沿路径行进并在边界碰撞时交替左右转向，每个转向点处印下一个精灵体副本并按颜色循环着色。

**输入结构**：
- 约 18x18 黑(0)背景网格
- 网格的一个角落（如左下角）有一个黄(4)起始标记像素，指示粒子的初始位置和方向（粒子从该像素出发，初始方向向上）
- 网格某处有一个 2x2 红(2)方块作为终止标记——粒子到达时停止
- 网格顶部有一行 1xN 的颜色图例（N=3 或 4），从左到右排列 N 种颜色（如蓝(1)、绿(3)、品红(6)），定义颜色循环
- 网格中间有一个小型单色精灵体（3-5 像素，4-连通，如灰(5)色），其中一个像素标记为源锚点（橙(7)色，区别于精灵体的其余灰色像素）
- 生成约束：(a) 粒子路径在碰到终止标记前至少有 3 次边界碰撞（转向）；(b) 精灵体的印章位置互不重叠；(c) 印章不覆盖起始标记、终止标记或颜色图例；(d) 精灵体足够小（3-5 像素），以确保多个印章可以放入网格

**规则**：
1. 读取颜色图例确定颜色循环序列 C[0..N-1]。
2. 粒子从黄(4)起始标记出发，初始方向为向上。粒子不在路径上画线（不同于参考题 195c6913——这里路径不可见，只有印章可见）。
3. 粒子沿当前方向逐像素前进。若下一像素超出网格边界，触发碰撞转向：
   - 记录当前位置为第 k 个转向点（k 从 0 开始计数）。
   - 若 k 为偶数：逆时针转 90°（左转）。
   - 若 k 为奇数：顺时针转 90°（右转）。
   - 沿新方向继续前进。
4. 若粒子的下一像素属于红(2)终止标记的 2x2 区域，粒子停止。
5. 在每个转向点位置，以该点为锚印下精灵体副本：计算源锚点（橙(7)像素）到转向点的偏移，将精灵体整体平移该偏移量。
6. 第 k 个转向点的印章颜色为 C[k mod N]：精灵体副本的所有像素（包括原锚点位置）统一涂为该颜色。
7. 若多个印章在某些像素位置重叠，后印的覆盖先印的（转向顺序靠后的优先）。
8. 原始精灵体（含锚点）保留在原位不变。起始标记、终止标记和颜色图例保持不变。

**关键洞察**：交替左转/右转的规则使得粒子路径呈现不对称的锯齿形——连续两次碰撞的转向方向相反，导致转向点的空间分布不可由简单的反射规律预测。必须完整模拟粒子路径才能确定所有印章位置和颜色。
