## 新题 1：噪声量编码条纹排序权重

**组合逻辑**：[去噪/denoise] + [计数/counting](创新：噪声数量作为排序键) → [重排/rearrange](创新：按噪声键垂直重排行)

**来源原语**：去噪、主色占优、条纹行列、噪声像素（参考题 e26a3af2）；计数（参考题 edcc2ff0/54db823b/6455b5f5）；重排、基线对齐（参考题 3d6c6e23）

**依赖链**：噪声计数提取排序键 → 去噪销毁噪声但保留干净条纹 → 按已提取的键对干净条纹重排。排序键在去噪时被销毁，因此必须先计数后去噪；去噪后的单色行才能正确排列，因此必须先去噪后重排。三步缺一不可。

将含噪水平条纹的网格清洗并按每行噪声像素数从少到多自上而下排列。

**输入结构**：一个约 8x12 的矩形网格，黑(0)为背景。网格由水平色带行组成——每行有一个主色（非黑，取自 1-9 中的若干种），同时散布 0-3 个噪声像素（颜色与该行主色不同，可为任意非主色颜色或黑色）。不同行的主色可以相同也可以不同。每行至少有 60% 像素为主色，确保主色唯一可辨。各行的噪声数量互不相同（保证排序无歧义）。

**规则**：
1. 对每一行，统计噪声像素数量（与该行主色不同的像素数），记为该行的"权重"。
2. 去噪：将每一行所有像素替换为该行的主色，得到纯色行。
3. 将所有纯色行按权重从小到大自上而下排列。权重最小的行排在最顶部，权重最大的行排在最底部。
4. 输出排列后的纯色行组成的网格（尺寸不变）。

**关键洞察**：噪声像素具有双重身份——它既是需要清除的污染，又是编码最终行序的隐藏参数。排序键在去噪过程中被不可逆地销毁，求解者必须意识到噪声数量"先用后弃"的时序约束。
