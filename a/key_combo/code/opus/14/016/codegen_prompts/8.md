## 新题 8：条纹噪声中的图例标记双重身份

**组合逻辑**：[去噪/denoise](主色覆盖全列) + [展开/expand](图例锚定对齐)（创新：噪声像素中的一部分同时是图例标记，需在去噪前识别分离） → [重涂色/recolor]

**来源原语**：去噪、条纹行列、噪声像素、主色占优、主色覆盖全行列（参考题 e26a3af2）；展开、边缘图例串、孤立标记、颜色位置匹配、图例锚定对齐（参考题 5af49b42）；重涂色（参考题 150deff5/edcc2ff0）

**依赖链**：网格是垂直条纹 + 噪声的叠加，部分噪声像素的颜色恰好出现在底部图例中 → 这些像素是"图例标记"而非普通噪声 → 必须在去噪前识别并记录它们的位置和颜色 → 去噪时将所有噪声（含标记）清除为条纹主色 → 在干净条纹上，于每个标记的原始位置展开图例串。去噪和展开不可互换：先展开会在噪声背景上产生错误叠加，先去噪会销毁标记信息。

识别垂直条纹中嵌入的图例标记像素，去噪后在标记原始位置展开底部图例串。

**输入结构**：一个约 12x12 的网格。
- 网格主体为垂直色带条纹——每列有一个主色（非黑），占该列至少 70% 的像素。
- 散布若干噪声像素（与所在列主色不同的像素）。噪声像素分两类：(a) 普通噪声——颜色不出现在底部图例中；(b) 图例标记——颜色出现在底部图例中。求解者需通过颜色匹配区分两类。
- 最底行（最后一行）为一条水平图例串，包含若干种颜色按固定顺序排列。图例串中每种颜色只出现一次。图例串不参与条纹结构（不受去噪影响）。
- 图例标记不位于最底行，且每个标记的颜色在图例中有唯一对应位置。
- 生成约束：各列的主色都不出现在图例串中（确保主色与图例颜色集合不交叉）；同一行上不会有多个图例标记的展开区域重叠。

**规则**：
1. 识别最底行的图例串及其颜色序列。
2. 对网格中非最底行的每个像素，判断其是否为噪声（与所在列主色不同）。若是噪声且其颜色出现在图例串中，标记为"图例标记"并记录其行、列坐标和颜色。
3. 去噪：对非最底行的每一列，将所有像素替换为该列的主色（噪声和标记均被覆盖）。最底行的图例串保持不变。
4. 对每个已记录的图例标记：在图例串中找到该颜色的位置索引 k。将完整图例串水平复制到该标记原始所在行，水平平移使图例第 k 个位置对齐标记的原始列坐标。超出网格左右边界的部分裁剪。图例串覆盖该行的条纹颜色。
5. 多个标记按其行号从上到下依次处理，后处理的覆盖先处理的（同行不会有冲突，由生成约束保证）。
6. 输出完整网格（含最底行图例）。

**关键洞察**：噪声像素中隐藏着一类具有语义的"图例标记"，它们与普通噪声在外观上无法区分——唯一的甄别依据是其颜色是否出现在图例串中。去噪操作会不加区分地清除两类噪声，因此求解者必须在去噪前通过颜色交叉比对完成标记识别。信息的提取（标记识别）和销毁（去噪）在时序上形成不可逆耦合。

## 实现要求

1. `main(grid)` 必须实现新题描述中的确定性转换规则，不能只识别 `generate_input()` 的固定模板。禁止不同的input网格输出相同的output网格。
2. `generate_input()` 必须随机生成多样样例，不能固定死。随机维度应覆盖：网格大小、对象数量、位置、颜色、方向、形状参数或关键分支。注意若描述中存在若干，需实现而不是只有单个，包括object或者对应关系等等。且若涉及到最短路径，则输入网格中必涉及到多条路径，对选择造成干扰。

6. 若规则有多个分支，生成器不能长期固定成一个分支；应让分支在随机样例中合理出现。分支概率不必平均——难以发现的隐蔽分支（如少数情况下才触发的特殊规则）应适当提高出现概率，确保在 3 个训练示例中至少出现一次，否则求解者无法归纳该规则。对于颜色映射类规则，确保 2 个左右的示例即可覆盖所有映射关系（每种颜色→颜色的映射至少在某个示例中出现过）。
