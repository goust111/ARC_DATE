## 新题 3：标记颜色定向移动后距离编码拉伸量

**组合逻辑**：[移动/move](颜色决定目标边) + [计数/counting](创新：记录移动前的垂直距离) → [擦除/erase] → [拉伸/stretch](创新：拉伸量来自标记原始距离而非外部锚点)

**来源原语**：移动、边框、颜色匹配边、颜色决定目标边（参考题 d687bc17）；拉伸、空心矩形、标记决定拉伸终点（参考题 b548a754）；擦除（参考题 d687bc17/edcc2ff0）

**依赖链**：标记的颜色确定它要移动到的边 → 标记的原始位置到目标边的距离编码了该边的拉伸量 → 移动后标记到达边沿，距离信息被消耗 → 按已记录的距离对各边执行拉伸。标记像素同时编码方向（颜色）和位移量（位置），两条信息从同一像素中提取但驱动不同操作。

将框内标记按颜色移至匹配边，并按标记原始距离拉伸该边。

**输入结构**：一个约 15x15 的网格，黑(0)背景。中央有一个一像素宽的空心矩形框，框的四条边各用不同颜色：上边蓝(1)、下边绿(3)、左边红(2)、右边黄(4)。框的四角为黑(0)。框的内部（黑色区域）散布 1-4 个标记像素，每个标记的颜色与四条边中的恰好一条相同。不同标记可以匹配同一条边。生成约束：每个标记到其匹配边的垂直/水平距离至少为 2，且拉伸后框不超出网格边界。

**规则**：
1. 对每个框内标记像素，记录它到匹配颜色边的垂直距离（若匹配上/下边）或水平距离（若匹配左/右边），记为 d。
2. 将所有内部标记像素擦除（设为黑色）。
3. 对每条有匹配标记的边，将该边向外拉伸 d 个像素。若同一边有多个标记，取最大距离。无匹配标记的边不动。
4. 按拉伸后的新尺寸重绘空心矩形框（保持原来的四边颜色、一像素宽度、黑色角和黑色内部）。
5. 框外保持黑色背景。

**关键洞察**：每个标记像素是一个二维编码器——其颜色通道选择拉伸方向，其空间坐标通道量化拉伸幅度。这两条信息在标记被擦除后均不可再读取，因此必须在同一遍扫描中同时提取。
