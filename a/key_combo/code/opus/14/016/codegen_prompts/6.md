## 新题 6：对称修复后识别周期并向下延伸

**组合逻辑**：[对称补全/symmetric_completion](控制标记指示源侧) → [补全/completion] + [平移/translate](创新：对称修复后的行图案才展现周期平移结构)

**来源原语**：对称补全、对称轴、控制标记、控制标记指示源侧、轴对称反射（参考题 5b692c0f）；补全、平移、行图案、画布、周期平移、周期偏移延续行（参考题 53b68214）；对称轨道、掩码像素（参考题 3631a71a）

**依赖链**：图案的一侧被损坏 → 控制标记标识可信侧 → 镜像修复损坏侧 → 修复后的完整行才呈现周期平移结构 → 由周期和偏移量向下延伸至目标行数。若不先修复对称，损坏像素会干扰周期检测；若不执行周期延伸，输出行数不足。

先修复半边损坏的对称图案，再利用修复后显现的周期平移规律向下补全网格。

**输入结构**：一个宽 10、高 4-6 行的矩形网格。
- 背景色为黑(0)，前景用一种非黑颜色（如蓝(1)）。
- 网格包含一条垂直的黄(4)轴线（单像素宽，贯穿所有行），以及一个偏离轴线的黄(4)控制像素，位于轴线某一侧。
- 控制像素所在侧（源侧）的前景图案是完整正确的。
- 另一侧（目标侧）有 1-3 个前景像素被替换为灰(5)（掩码色）。
- 源侧的行图案在垂直方向上呈现固定周期 p（2 或 3 行）和固定水平偏移 dx 的平移序列关系，但目标侧因掩码污染而无法直接观察到该周期性。
- 生成约束：网格高度小于 10，且 p 和 dx 可从源侧唯一确定。

**规则**：
1. 识别黄(4)轴线和控制像素。控制像素所在侧为源侧。
2. 将源侧的前景/背景图案镜像到目标侧，替换所有灰(5)掩码像素。同时移除黄(4)轴线和控制像素（设为背景色黑(0)），得到修复后的完整行。
3. 从修复后的完整行中推断最小垂直周期 p 和水平偏移 dx：即每隔 p 行，行内的前景像素整体水平移动 dx 列（循环取模）。
4. 将修复后的行复制到一个宽 10、高 10 的黑色画布的顶部。
5. 对于缺失的底部行（第 h 行到第 9 行），每行的图案等于其上方第 p 行的图案水平移动 dx 列后的结果。超出网格边界的像素丢弃。

**关键洞察**：掩码损坏隐藏了周期结构——如果直接对含掩码的行做周期检测，会得到错误的周期或偏移。求解者必须先信任控制标记指示的源侧、通过镜像修复另一侧，然后才能在干净数据上推断周期平移规律。对称修复是周期检测的前提条件，而非独立步骤。

## 实现要求

1. `main(grid)` 必须实现新题描述中的确定性转换规则，不能只识别 `generate_input()` 的固定模板。禁止不同的input网格输出相同的output网格。
2. `generate_input()` 必须随机生成多样样例，不能固定死。随机维度应覆盖：网格大小、对象数量、位置、颜色、方向、形状参数或关键分支。注意若描述中存在若干，需实现而不是只有单个，包括object或者对应关系等等。且若涉及到最短路径，则输入网格中必涉及到多条路径，对选择造成干扰。

4. 禁止把 ARC 颜色 id 、亮度、拼写等当作人类不可见的数值语义参与排序、大小比较或隐藏映射。颜色变化必须有可见结构线索。注意颜色亮度、拼写等也是不可见信息，若描述中出现违规的颜色id或者亮度，可自行使用少量的固定颜色替代，但注意生成时要在三个以内输入输出网格中对所有变换100%覆盖度。

6. 若规则有多个分支，生成器不能长期固定成一个分支；应让分支在随机样例中合理出现。分支概率不必平均——难以发现的隐蔽分支（如少数情况下才触发的特殊规则）应适当提高出现概率，确保在 3 个训练示例中至少出现一次，否则求解者无法归纳该规则。对于颜色映射类规则，确保 2 个左右的示例即可覆盖所有映射关系（每种颜色→颜色的映射至少在某个示例中出现过）。
