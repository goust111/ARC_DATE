## 新题 5：筛选后物体总数编码场景循环位移

**组合逻辑**：[计数/counting] + [擦除/erase](标记色筛选物体) → [计数/counting](创新：存活物体总数成为位移参数) → [循环位移/cyclic_roll] → [裁剪/crop]

**来源原语**：计数、擦除、指示条、标记色筛选物体、条长等于物体计数（参考题 edcc2ff0）；循环位移、裁剪、控制列、标记位定位移量（参考题 6d1d5c90）

**依赖链**：指示条标记颜色决定场景中哪些物体存活 → 存活物体数量决定指示条条长并同时作为循环位移量 → 位移应用于筛选后的场景 → 裁剪去除指示条。筛选决策和位移参数从同一次计数中同时产生，不可拆分为独立子问题。

用指示条筛选场景物体，存活物体的总数决定场景的垂直循环滚动量。

**输入结构**：一个约 12x15 的网格，分为上下两部分：
- 上部指示条区（约 3 行）：黑(0)背景，第 0 列每行各有一个彩色单像素标记（1-3 个标记，颜色各异）。
- 下部场景面板（其余行）：有一种非黑的统一背景色（如灰(5)），其上散布若干 4-连通前景物体，颜色取自 2-4 种。
- 标记颜色都是场景中出现的物体颜色的子集。
- 生成约束：存活物体的总数不超过场景面板的行数（确保循环位移有意义且不退化为恒等变换），且总数大于 0。

**规则**：
1. 对指示条中的每种标记颜色，统计场景面板中该颜色的 4-连通物体数量。
2. 在指示条中，将每个标记替换为从第 0 列开始的水平同色条，长度等于该颜色的物体计数。计数为 0 的标记擦除。
3. 场景面板中，颜色不在标记集合中的前景物体全部涂为场景背景色（即擦除）。
4. 将所有标记颜色的物体计数求和，得到总数 S。
5. 将筛选后的场景面板整体向下循环位移 S 行（底部溢出的行从顶部重新进入）。
6. 输出仅包含位移后的场景面板（指示条区域移除）。

**关键洞察**：指示条执行双重功能——它既是颜色筛选器（决定哪些物体存活），又是位移量编码器（存活物体总数 = 滚动行数）。位移量不是独立参数，而是从筛选结果中涌现的：改变筛选标记会同时改变存活的物体和滚动距离，两者不可独立调整。
