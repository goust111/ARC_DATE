## 新题 3：切比雪夫路径兼做对角射线屏障

**组合逻辑**：[connect + chebyshev_shortest](连线生成路径) <-> [ray_extend + diagonal_radiation](路径充当射线障碍物，创新：同一结构同时扮演连接器和屏障两种角色)

**来源原语**：connect, start_marker, end_marker, path, chebyshev_shortest, between_endpoints (参考题 992798f6); ray_extend, diagonal_radiation, extend_to_edge, isolated_pixel (参考题 ea786f4a)

**依赖链**：路径连接两个端点标记 -> 路径像素成为射线的不可穿透屏障 -> 射线从第三个发射点沿四对角方向延伸直到碰到路径或网格边缘。路径的几何形状（由端点位置唯一确定）直接决定每条射线的长度和终止位置。

先用切比雪夫最短路径连接两个端点，再从第三个发射点向四个对角方向发射射线，射线遇路径即停。

**输入结构**：黑(0)背景，约 15x15 网格。包含恰好三个特殊像素：一个蓝(1)像素和一个红(2)像素作为路径端点，以及一个绿(3)像素作为射线发射点。三个像素互不在同一行或同一列上，蓝(1)和红(2)之间在行方向和列方向上均有距离（保证路径包含对角段和直走段）。绿(3)像素位于蓝-红连线的一侧。生成时保证：(a) 绿(3)不在未来路径上；(b) 至少有两条对角射线会被路径截断（即射线在到达网格边界前先碰到路径）；(c) 至少有一条对角射线不被路径截断而到达网格边缘。不同示例中三个像素的位置不同。

**规则**：
1. 保留输入的蓝(1)、红(2)、绿(3)像素不变。
2. 从蓝(1)像素朝红(2)像素绘制切比雪夫最短路径：从蓝(1)的下一像素开始，先沿对角方向（每步行列各变化 1，朝红(2)靠近）行走，对角段走完后沿剩余的较长轴方向直走，到达红(2)的前一像素为止。路径像素（不含蓝(1)和红(2)本身）涂为灰(5)。
3. 从绿(3)像素出发，向四个对角方向（右下、右上、左下、左上）各发射一条射线，射线像素涂为橙(7)。
4. 每条射线逐像素延伸：当下一个目标位置超出网格边界，或该位置已有非黑(0)像素（灰(5)路径、蓝(1)/红(2)端点等），该射线停止。停止时的阻挡像素不被涂色，射线不包含阻挡位置。
5. 若某对角方向的第一步即遇阻挡或越界，则该方向不产生任何射线像素。

**关键洞察**：灰(5)路径同时扮演"连接器"（连接两端点）和"屏障"（截断对角射线）两种角色；路径的弯折几何直接塑造了射线辐射的不对称图案——改变端点位置会改变路径形状，进而改变哪些射线被截断。

    each_color: non-bg; colors usually distinct per object, but same color on different objects allowed
    area: 3-12 pixels per object
    bbox: 2-5 rows x 2-5 cols
    shape: irregular (L, T, cross, etc.), single 8-connected component
  shape_grouping:
    rule: count how many objects share the same binary shape up to rotation/flip
    duplicated: shape occurring >=2 times → objects move to TOP (row 0)

  transformation:
    vertical_only: each object translated vertically; c0 preserved
    top: dest_r0 = 0
    bottom: dest_r0 = H - object_bbox_height
  output_constraints:
    no_overlap: objects must not overlap after placement at top/bottom
    sufficient_gap: grid tall enough that top objects and bottom objects don't collide

generation_strategy:
  approach: output-first, then scatter to get input
  steps:
    1. Pick H, W in [19, 30]
    2. Choose 4-6 objects; create >=1 duplicated shape group and >=1 unique shape
    3. For each template, grow a random 8-connected shape of area 3-12 within a 2-5 x 2-5 bbox
    4. Duplicate-group members are copies of a template under random rotation/flip; singleton shapes must not match any other shape up to rotation/flip
    5. Assign each object a distinct non-bg color (reuse allowed if needed for >9 objects)
    6. Place duplicated-shape objects at row 0 and unique-shape objects at row H-h in the output grid
    7. Ensure no pixel overlap among all placed objects
    8. Build input by moving each object to a random row in the interior, preserving c0
    9. Validate main(input) == output
