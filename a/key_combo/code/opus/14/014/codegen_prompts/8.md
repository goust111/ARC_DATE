## 新题 8：裁剪半区后空行列标记触发邻接重涂色

**组合逻辑**：[裁剪](标记像素选择半区) + [标记](空行列涂标记色) + [重涂色](创新：由标记线邻接关系触发局部变色)

**来源原语**：裁剪、标记像素、标记对齐指定半区、保留标记半区（参考题 fbf15a0b）；标记、全空行列、空行列涂标记色（参考题 c1d99e64）；重涂色（多源）；邻接（参考题 7f4411dc）

**依赖链**：裁剪决定保留哪半边内容→保留内容的分布决定哪些行列全空→全空行列被涂标记色→标记色线的邻接像素被重涂色。四步形成级联：改变裁剪选择则空行列分布变化，进而标记线位置变化，进而重涂色目标变化。整条链不可跳步。

按标记像素选择保留的半区，在半区内找到全空行列涂为标记色，再将与标记线 4-邻接的特定颜色像素重涂为另一颜色。

**输入结构**：约 12x18 网格（宽度为偶数），黑(0)背景。网格内有若干蓝(1)和红(2)的前景图案（不规则 4-连通形状，3-8 像素），分布在左右两个半区中。两个绿(3)标记像素位于同一行，且都在同一个半区（左半或右半）内。部分行或列在被选中的半区内恰好全为黑(0)背景（即前景图案的排布留出了完整的空行或空列）。不同示例中图案的形态、位置和空行列分布不同。生成约束：两个绿(3)标记共享同一行且在同一半区；被选半区内至少有 1 个全空行和 1 个全空列；蓝(1)像素中至少有部分与全空行列 4-邻接、部分不邻接。

**规则**：
1. 两个绿(3)标记共享一行。保留包含两个标记的那个半区（左半或右半，宽度为原宽度的一半）。
2. 在保留的半区中，将绿(3)标记像素擦除为黑(0)背景。
3. 找到半区中所有完全由黑(0)组成的行和列。
4. 将这些全空行和全空列中的所有像素涂为黄(4)。
5. 对半区中每个蓝(1)像素，检查其 4-邻居中是否有黄(4)像素（即是否与新涂的标记线相邻）。
6. 若蓝(1)像素与至少一个黄(4)像素 4-邻接，将该蓝(1)像素重涂为红(2)。
7. 红(2)像素不受此规则影响，保持原色。
8. 输出为处理后的半区网格。

**关键洞察**：裁剪决定内容→内容决定空行列→空行列决定标记线→标记线决定哪些蓝色像素变红。这条四步级联意味着同一个输入的左半区和右半区会产生完全不同的标记线和重涂色结果。选择哪半区不是随意的——它由绿色标记的位置决定。邻接重涂色规则（蓝变红而非红变蓝、只检查 4-邻接而非 8-邻接）需要对比多个示例才能归纳。

    reps_per_axis: 2-5 in each direction
    symmetry: no consistent pattern [observed]

    exactly 1 copy of the tile exists in the input cavity (seed_px == tile_seed_px)
    the tile's top-left is phase-aligned with the cavity origin (offset % tile_dim == 0)
  transform: tile each cavity by repeating its seed tile periodically across the full rectangle

generation_strategy:
  approach: output-first
  steps:
    1. Choose grid dims (19-26 x 13-22). Place 1-3 non-overlapping axis-aligned rectangles
       for cavities (6-12 x 6-15 each) with >=2 wall cells between any pair and all borders.
    2. For each cavity, pick a unique seed color (not 0 or 8). Design a random tile
       (2-3 x 2-5) with 56-78% density such that tile dims divide cavity dims and

    3. Fill all non-cavity cells with wall color 8, cavity background with 0.
