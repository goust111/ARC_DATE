## 新题 2：非对称检测定位支架扩展

**组合逻辑**：[对称检测](检测结果不是裁剪输出而是坐标输入) + [扩展填充](扩展目标由检测坐标决定) + [标记对齐格子边界](已有)

**来源原语**：对称检测、前景对象、唯一非轴对称、异常值选择（参考题 73ccf9c2）；扩展填充、骨架格子、空心小框、标记像素、标记对齐格子边界、标记跨度决定范围（参考题 97239e3d）

**依赖链**：对称检测的输出不是被裁剪的对象本身，而是该对象在格子坐标系中的行列位置。这组坐标成为扩展填充操作的输入——决定在哪一行和哪一列的格子边界上涂色、在哪些框心中填色。删除检测步骤则无从知道扩展哪一行列；删除扩展步骤则检测结果无处使用。

在支架格子中找到唯一形状不对称的框心图案，沿其所在格子行和列进行支架边界扩展与框心填充。

**输入结构**：约 19x19 网格，黑(0)背景。灰(5)像素构成一个规则的支架格子，由 4x4 排列的空心 3x3 框组成（框的外边缘为灰(5)，框心 1x1 为黑(0)），相邻框之间共享边界行/列。每个框的中心单元格内放置一个 1-3 像素的小图形（颜色为蓝(1)、红(2)、绿(3)、黄(4)中的任意一种，每个框可不同）。这些小图形中，恰好一个在其所占的 1x1（或周围 3x3）局部区域内不具备左右镜像对称性；其余所有图形都是左右对称的。不同示例中，非对称图形位于不同的格子位置，图形形态各异（但始终是 1-3 像素的 4-连通体）。生成约束：恰好一个非对称图形；格子至少 3x3 排列以保证行列扩展可见。

**规则**：
1. 识别支架格子结构，将其分解为格子行和格子列（由灰(5)框边界定义）。
2. 检查每个框中心图形的左右镜像对称性（将图形在其紧凑边界框内做左右翻转，比较翻转前后的前景掩码是否一致）。
3. 找到唯一不对称的图形，记录其所在的格子行索引 R 和格子列索引 C（从 0 开始）。
4. 将第 R 行所有框的灰(5)边界段重涂为红(2)；将第 C 列所有框的灰(5)边界段重涂为红(2)。
5. 在第 R 行与第 C 列交叉处的框（即非对称图形所在的框），将框心填充为红(2)。在第 R 行其余框和第 C 列其余框中，将框心填充为绿(3)。
6. 不在第 R 行也不在第 C 列的框保持不变。

**关键洞察**：非对称图形本身不出现在输出中（它只是一个定位信号）。它的格子坐标驱动了一个完全不同的视觉操作——十字形支架扩展。检测的产物是位置信息而非对象本身，这使两步操作成为不可分割的推理链。交叉框用红(2)填心、非交叉行列框用绿(3)填心这一区分规则需要对比多个示例才能归纳。

## 实现要求

1. `main(grid)` 必须实现新题描述中的确定性转换规则，不能只识别 `generate_input()` 的固定模板。禁止不同的input网格输出相同的output网格。
2. `generate_input()` 必须随机生成多样样例，不能固定死。随机维度应覆盖：网格大小、对象数量、位置、颜色、方向、形状参数或关键分支。注意若描述中存在若干，需实现而不是只有单个，包括object或者对应关系等等。且若涉及到最短路径，则输入网格中必涉及到多条路径，对选择造成干扰。
3. 生成器必须保证输入满足 `main()` 的隐式假设：对象不重叠、不越界、特殊标记唯一或可区分、匹配关系无歧义、关键分支出现概率相同。
4. 禁止把 ARC 颜色 id 、亮度、拼写等当作人类不可见的数值语义参与排序、大小比较或隐藏映射。颜色变化必须有可见结构线索。注意颜色亮度、拼写等也是不可见信息，若描述中出现违规的颜色id或者亮度，可自行使用少量的固定颜色替代，但注意生成时要在三个以内输入输出网格中对所有变换100%覆盖度。
5. 输出样例要视觉清晰，人类必须能从输入输出对中肉眼辨认出规律。具体要求：避免对象粘连、覆盖关系混乱、同一像素多重语义；不同逻辑步骤产生的结果不要大面积层叠在一起导致无法分辨哪个颜色属于哪个步骤；输入中各元素之间保持足够间距，输出中新增的标记/填充/路径等应与背景和已有元素在颜色上有明显区分；若规则涉及多层叠加，生成时控制对象密度和尺寸，确保叠加区域只占少数像素而非铺满整个网格。
6. 若规则有多个分支，生成器不能长期固定成一个分支；应让分支在随机样例中合理出现。分支概率不必平均——难以发现的隐蔽分支（如少数情况下才触发的特殊规则）应适当提高出现概率，确保在 3 个训练示例中至少出现一次，否则求解者无法归纳该规则。对于颜色映射类规则，确保 2 个左右的示例即可覆盖所有映射关系（每种颜色→颜色的映射至少在某个示例中出现过）。
