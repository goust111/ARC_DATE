## 新题 3：镜像堆叠创建邻接用于选择性擦除

**组合逻辑**：[镜像](作为中间计算手段而非最终目的) + [拼接](创建新空间拓扑) + [擦除](邻接阈值过滤，创新：在合成网格上执行)

**来源原语**：镜像、拼接、画布、翻转副本堆叠拼接（参考题 4c4377d9）；擦除、孤立像素、矩形、邻接、邻接不足则删除、忽略干扰项（参考题 7f4411dc）

**依赖链**：镜像拼接不是最终输出，而是一步空间构造——它在接合缝处为原本孤立的像素创造新的 4-邻居关系。后续的邻接过滤利用这些新关系决定哪些像素存活。没有镜像就没有新邻接；没有过滤则镜像毫无意义。两步在拓扑层面耦合。

将输入网格垂直翻转后堆叠于原网格上方，在合成网格中按邻接支持度擦除孤立像素，保留矩形结构。

**输入结构**：约 10x8 网格，黑(0)背景。网格中有 2-3 个小矩形（2x3 或 3x2，4-连通），颜色为蓝(1)。另有 4-8 个散落的蓝(1)单像素（噪声），这些噪声像素在颜色上与矩形无法区分。部分噪声像素位于网格的顶部两行或底部两行（靠近将要产生接合缝的边缘）。不同示例中矩形的位置、数量和噪声分布各不相同。生成约束：矩形的每个像素至少有 2 个蓝(1) 4-邻居（在原始网格中即满足）；噪声像素在原始网格中最多有 1 个蓝(1) 4-邻居；至少有一个噪声像素位于第 0 行或最后一行。

**规则**：
1. 将输入网格按上下方向垂直翻转，得到镜像副本。
2. 将镜像副本放在原始网格上方，拼接为高度翻倍、宽度不变的合成网格。
3. 在合成网格中，对每个蓝(1)像素计算其蓝(1) 4-邻居数量。
4. 保留拥有 2 个及以上蓝(1) 4-邻居的像素；将少于 2 个的蓝(1)像素擦除为黑(0)。
5. 输出即为过滤后的合成网格。

**关键洞察**：镜像拼接并非装饰性操作——它在接合缝两侧创造新的邻接关系。原始网格中位于第 0 行的噪声像素在合成网格中获得了来自镜像副本的邻居，可能因此从 1 个邻居增加到 2 个而存活；而远离接合缝的噪声像素不获得新邻居仍被擦除。矩形在原始网格中已有充足邻接，镜像后支持度更高。邻接阈值（恰好 2）须从多个示例中归纳——阈值 1 或 3 会产生不同的存活集合。

Recolor each closed orthogonal line loop so convex bend pixels are yellow and concave bend pixels are red.

6. 若规则有多个分支，生成器不能长期固定成一个分支；应让分支在随机样例中合理出现。分支概率不必平均——难以发现的隐蔽分支（如少数情况下才触发的特殊规则）应适当提高出现概率，确保在 3 个训练示例中至少出现一次，否则求解者无法归纳该规则。对于颜色映射类规则，确保 2 个左右的示例即可覆盖所有映射关系（每种颜色→颜色的映射至少在某个示例中出现过）。
