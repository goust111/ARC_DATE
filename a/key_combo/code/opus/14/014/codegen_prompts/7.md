## 新题 7：下采样揭示碎片用于精灵体印章补全

**组合逻辑**：[下采样](几何压缩使离散像素塌缩为可识别图案) + [印章覆盖](在压缩网格上执行精灵体补全) + [颜色重叠匹配](已有) + [最大重叠确定位置](已有)

**来源原语**：下采样、分隔行列、奇偶索引分离、保留偶索引交叉（参考题 68b67ca3）；印章覆盖、多色精灵体、部分掩码、颜色重叠匹配、最大重叠确定位置、冲突优先级（参考题 d6542281）

**依赖链**：原始网格中，分隔行列将有效像素隔开，使得部分掩码的各像素在空间上不连续，无法直接识别为精灵体碎片。下采样移除分隔行列后，像素塌缩为紧凑排列，碎片的空间关系才呈现出与精灵体的匹配。下采样是解锁模式识别的前提，而精灵体补全是下采样的唯一目的。

在含分隔行列的稀疏网格中，下采样去除分隔后在紧凑网格上识别精灵体碎片并补全为完整精灵体。

**输入结构**：约 19x19 网格（奇数尺寸，确保偶索引位置为 10x10）。所有奇数索引行和奇数索引列全为黑(0)（分隔行列）。偶数行与偶数列的交叉位置构成 10x10 的有效载荷。载荷中大部分为黑(0)背景，包含一个多色精灵体（由 2-3 种非黑颜色组成，共 6-12 个有效像素，4-连通），以及 1-2 组散落的同色像素（颜色与精灵体中的某种颜色匹配，每组 2-4 个有效像素）。这些散落像素实际上是精灵体的部分副本，但在 19x19 原始网格中因被分隔行列打断而无法直接看出空间对应关系。不同示例中精灵体形态和散落碎片的位置各不相同。生成约束：每组散落像素对应精灵体在某个平移位置的子集，且该平移位置唯一（最大重叠唯一）；精灵体和散落碎片在 10x10 载荷中不重叠；精灵体在载荷中足够远离边缘以保证碎片补全后不越界。

**规则**：
1. 下采样：移除所有奇数索引行和列，保留偶数行与偶数列交叉处的像素，得到 10x10 紧凑网格。
2. 在紧凑网格中，识别多色精灵体（最大的多色 8-连通前景区域）。
3. 对每组散落的同色像素，测试精灵体在所有可能平移位置下的颜色重叠：将精灵体中与散落像素同色的部分逐一对齐，计算散落像素与精灵体像素的精确颜色匹配数。
4. 选取匹配数最大的平移位置（保证唯一）。
5. 在该平移位置印章完整精灵体。若印章位置的某像素已有非背景前景色（来自已有的散落像素），保留原有像素颜色不覆盖。
6. 输出为补全后的 10x10 紧凑网格。

**关键洞察**：在原始 19x19 网格中，散落像素被分隔行列物理隔断，看起来只是随机噪点。只有下采样让它们塌缩到紧凑空间后，它们之间的相对位置才暴露出与精灵体的匹配关系。下采样不是信息丢失，而是信息显现——它是模式识别的先决条件。冲突优先级规则（已有像素优先还是印章优先）需要对比多个示例才能确定。

## 实现要求

1. `main(grid)` 必须实现新题描述中的确定性转换规则，不能只识别 `generate_input()` 的固定模板。禁止不同的input网格输出相同的output网格。
2. `generate_input()` 必须随机生成多样样例，不能固定死。随机维度应覆盖：网格大小、对象数量、位置、颜色、方向、形状参数或关键分支。注意若描述中存在若干，需实现而不是只有单个，包括object或者对应关系等等。且若涉及到最短路径，则输入网格中必涉及到多条路径，对选择造成干扰。
3. 生成器必须保证输入满足 `main()` 的隐式假设：对象不重叠、不越界、特殊标记唯一或可区分、匹配关系无歧义、关键分支出现概率相同。
4. 禁止把 ARC 颜色 id 、亮度、拼写等当作人类不可见的数值语义参与排序、大小比较或隐藏映射。颜色变化必须有可见结构线索。注意颜色亮度、拼写等也是不可见信息，若描述中出现违规的颜色id或者亮度，可自行使用少量的固定颜色替代，但注意生成时要在三个以内输入输出网格中对所有变换100%覆盖度。

6. 若规则有多个分支，生成器不能长期固定成一个分支；应让分支在随机样例中合理出现。分支概率不必平均——难以发现的隐蔽分支（如少数情况下才触发的特殊规则）应适当提高出现概率，确保在 3 个训练示例中至少出现一次，否则求解者无法归纳该规则。对于颜色映射类规则，确保 2 个左右的示例即可覆盖所有映射关系（每种颜色→颜色的映射至少在某个示例中出现过）。
