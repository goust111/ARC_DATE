## 新题 2：路径生长驱动的递归印章

**组合逻辑**：[path_grow + obstacle_deflection](已有) → [pixel_scaling + recursive_stamp](创新：印章掩模由动态路径而非静态像素决定)

**来源原语**：path_grow/obstacle_deflection/control_pixel/blocker（来自 712bf12e）、pixel_scaling/recursive_stamp/cell_block_mapping/input_pattern（来自 cce03e0d）

**依赖链**：路径生长的轨迹决定了印章掩模的形状 → 印章掩模决定了放大输出中哪些块接收原始图案的复制 → 障碍像素既偏转路径又出现在每份印章副本中，形成双重角色的紧耦合。

从底行控制像素向上生长路径，路径遇障碍向右偏转；路径覆盖的所有像素构成印章掩模，用于在放大网格中递归印章整幅原始图案。

**输入结构**：一个 5x5 的网格。底行（第 4 行）含 1~3 个红(2)控制像素，其余底行像素为黑(0)。网格内部散布若干灰(5)障碍像素（不在底行）。其余像素使用蓝(1)、绿(3)等非红非灰非黑颜色构成一个小图案。生成约束：每条路径至少能向上行进 2 步（不会被堵死在底行附近）；从一个控制像素出发的路径不会经过另一个控制像素的起始位置。

**规则**：
1. 从每个红(2)控制像素出发，逐步向上生长路径：若当前格的正上方为非灰且在网格内，则移动到正上方并将该格标记为"已访问"；若正上方为灰(5)障碍或超出边界，则尝试移动到当前格的右侧一格——若该格为非灰且在网格内，则移动到该格并标记为"已访问"，然后从该格继续尝试向上；若右侧也不可用（灰或超出边界），路径终止。
2. 收集所有被任一路径访问的格（包括初始红像素位置）构成"印章掩模"集合。
3. 构建 25x25（即 5x5 个 5x5 块）的输出网格，初始全黑(0)。将输入的 5x5 网格视为块索引模板：对于印章掩模中的每个格 (r,c)，将原始 5x5 输入图案完整复制到输出中对应的块位置（输出行 r*5 到 r*5+4、输出列 c*5 到 c*5+4），像素值保持与输入完全一致（包括红、灰、黑等所有颜色）。
4. 印章掩模之外的块全部保持黑(0)。

**关键洞察**：障碍像素承担双重角色——它们既偏转路径（改变掩模形状），又作为输入图案的一部分出现在每份印章副本中。移动一个障碍，同时改变了"哪些块被印章"和"每份印章里包含什么内容"。
