## 新题 4：分隔网格中异常图案擦除与同类通道连线

**组合逻辑**：[separator_row/col 定义单元格](创新：分隔线同时作为区域边界和连线通道) → [pattern_once + outlier_selection](已有) → [draw_line 通过 background_channel](创新：连线介质从瓦片间背景改为分隔线本身) + [erase](已有)

**来源原语**：separator_row, alignment（来自 99b1bc43）；extract, uniqueness_filter, pattern_once, outlier_selection（来自 aee291af）；draw_line, background_channel（来自 b7f8a4d8）；erase（来自 22208ba4）

**依赖链**：分隔线划分单元格 → 逐单元格提取图案并互相比较 → 找到仅出现一次的异常图案并擦除 → 对拥有相同图案的相邻单元格，将它们之间共享的分隔线段重涂为该图案颜色以示连接。分隔线的双重角色（边界+通道）是源题中不存在的结构关系

灰色分隔线将网格划分为若干单元格，每格内有小图案；擦除唯一不重复的异常图案，并将拥有相同图案的相邻格子间的分隔线段涂为该图案颜色。

**输入结构**：黑(0)背景，约 15x15 网格。灰(5)分隔线（单像素宽的完整横线和竖线）将网格均匀划分为 3x3 或 3x4 的单元格阵列（每个单元格约 3x3 至 4x4 内部像素）。每个单元格内部包含一个单色小图案（2-5 像素的 4-连通图形），使用的颜色从蓝(1)、红(2)、绿(3)、黄(4)、橙(7)中选取，同一图案类型的所有实例使用相同颜色。大多数图案在多个单元格中重复出现（平移后掩码相同），恰好有一个单元格的图案是唯一的（其掩码不同于其他所有单元格的图案）。生成约束：拥有相同图案的单元格中至少有两个在水平或垂直方向相邻（共享一段分隔线），以保证连线规则可展示；异常单元格至少有一个相邻格包含重复图案（非孤立角落）。

**规则**：
1. 按分隔线划分单元格，提取每个单元格内部的图案掩码（相对于单元格左上角的像素偏移集合）。
2. 比较所有单元格的掩码（仅平移等价，不考虑旋转/翻转）：找到恰好只出现一次的掩码，对应的单元格为异常单元格。
3. 将异常单元格内的图案像素全部擦除（置为黑(0)）。
4. 对每对水平或垂直相邻的单元格，若二者掩码相同，则将它们之间共享的灰(5)分隔线段重涂为该图案的颜色。共享分隔线段指两个相邻单元格之间那段分隔线（不包括分隔线与其他分隔线的交叉点像素——交叉点保持灰(5)不变）。
5. 与异常单元格相邻的分隔线段不受影响（即使邻格含重复图案，该分隔线段也保持灰(5)，因为异常格无匹配）。
6. 不相邻的同图案单元格之间不连线。

**关键洞察**：分隔线扮演双重角色——既是划分单元格的边界（决定比较单元），又是相同图案之间的连线介质。异常图案被擦除而非被连接，这一差异处理需要对比多个示例才能确认：擦除不是因为颜色或位置特殊，而是因为图案掩码唯一。
