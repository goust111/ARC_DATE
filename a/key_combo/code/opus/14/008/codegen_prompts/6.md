## 新题 6：重复色边界矩形内移与异或重叠消解

**组合逻辑**：[repeated_color_moves → translate](已有) → [xor_overlay](创新：从双掩码对称差改为多个平移后矩形的重叠消解规则) + [border_aligned](已有)

**来源原语**：translate, erase, boundary_rectangle, repeated_color_obj, border_aligned, repeated_color_moves（来自 22208ba4）；xor_overlay, disagreement_cells_painted（来自 99b1bc43）

**依赖链**：判断哪种颜色是重复色 → 重复色矩形从边界向内平移 → 平移后多个矩形可能重叠 → 重叠区域适用异或规则（偶数层覆盖变为背景，奇数层保留颜色）而非简单合并。删除重复色判断则不知谁移动，删除平移则无位移，删除异或规则则重叠处理错误

重复色的边界矩形向内平移后，重叠区域不是合并而是异或消除——被偶数个矩形覆盖的像素恢复为背景色。

**输入结构**：黑(0)背景，约 14x14 网格。网格边缘贴有若干单色实心矩形，每个矩形至少一条边与网格边缘对齐。其中恰好一种颜色（如蓝(1)）以多个独立矩形出现（即该色有 3-4 个分离的 4-连通分量），这是"重复色"。其他颜色各只出现一个矩形（"单例色"，如红(2)、绿(3)），也贴在网格边缘。生成约束：重复色矩形大小可不同；至少有两个重复色矩形在内移后发生重叠（它们的平移后区域有公共像素），以展示异或规则；至少有一个重复色矩形内移后不与任何其他重复色矩形重叠，以展示无重叠时的正常保留。

**规则**：
1. 统计每种非背景颜色的 4-连通分量数量。分量数 >= 2 的颜色为"重复色"（保证恰好一种）。分量数 = 1 的为"单例色"。
2. 单例色矩形保持不变。
3. 清除所有重复色矩形的原始位置（置为黑(0)背景）。
4. 对每个重复色矩形，确定其平移方向和距离：
   - 该矩形贴在网格的哪条边（上/下/左/右），就向对侧方向平移。
   - 若贴上边，向下平移该矩形自身的高度；若贴下边，向上平移高度；若贴左边，向右平移宽度；若贴右边，向左平移宽度。
   - 若矩形同时贴两条边（位于角落），沿两个方向各自平移对应的高/宽。
5. 计算所有平移后矩形的覆盖叠加：对输出网格中每个像素，计算有多少个平移后的重复色矩形覆盖它。
6. 异或规则：覆盖次数为奇数的像素涂为重复色；覆盖次数为偶数（含 0）的像素保持为黑(0)背景。
7. 平移后的矩形若与单例色矩形重叠，单例色像素优先保留（重复色不覆盖单例色位置）。

**关键洞察**：与参考题 22208ba4 不同，重叠的平移矩形不是简单合并，而是遵循异或逻辑——两个矩形重叠的区域反而变回背景。这一规则仅当示例中出现实际重叠时才可观察到。若所有示例都无重叠，则无法区分合并与异或，因此至少需要一个有重叠的示例来归纳此规则。
