## 新题 1：墙壁分室的选择性镜像

**组合逻辑**：[aspect_ratio_mirror_axis](已有) → [reachability](创新：从聚集筛选改为镜像资格判定) → [mirror](创新：从整体镜像改为按可达性选择性镜像) + [erase](已有)

**来源原语**：mirror, rectangular_frame, corner_marker, internal_pattern, aspect_ratio_mirror_axis（来自 93c31fbe）；wall_barrier, reachability（来自 dd6b8c4b）；erase（来自 22208ba4）

**依赖链**：框体宽高比决定镜像轴方向 → 墙壁决定蓝色像素的反射目标位置是否被阻挡 → 反射目标位置空闲的蓝色像素被镜像，被墙壁占据的位置则该蓝色像素被擦除 → 三者缺一不可：无宽高比则不知轴向，无墙壁检测则全部镜像（结果错误），无擦除规则则被阻挡像素留存（结果错误）

将框体宽高比确定的镜像轴与墙壁对反射位的逐像素遮挡结合，仅镜像反射目标未被墙壁占据的前景像素，被遮挡者擦除。

**输入结构**：黑(0)背景，约 18x18 网格。网格中有 3-4 个一像素厚的灰(5)矩形边框，各框大小不同（有的宽大于高，有的高大于宽，有的接近正方形但严格不等），彼此不重叠不相邻。每个框内部一侧（左半或上半）分布若干蓝(1)像素，构成一个 4-连通的不规则图形（3-8 像素，非对称）。部分框内部还散布品红(6)像素构成短墙段（1-3 像素的水平或垂直线段），墙段不接触蓝色像素，但可能占据蓝色像素反射后的对称位置。生成约束：每个框内至少有一个蓝色像素的反射目标位置被墙壁占据，至少有一个未被占据，以保证同一框内既有镜像又有擦除。不同框中墙壁数量和位置不同。

**规则**：
1. 对每个灰(5)边框，计算其内部区域（不含边框本身）的宽度 W 和高度 H。
2. 若 W > H（宽框），镜像轴为该框内部区域的垂直中线（列坐标 = 内部左列 + W/2，W 保证为偶数）；若 H > W（高框），镜像轴为水平中线（行坐标 = 内部顶行 + H/2，H 保证为偶数）。
3. 对该框内每个蓝(1)像素，计算其关于镜像轴的对称位置。
4. 若对称位置在框内部且为黑(0)背景，则在对称位置放置蓝(1)像素，原位保留。
5. 若对称位置被品红(6)墙壁占据，则擦除原位蓝(1)像素（置为黑(0)），墙壁保持不变。
6. 若对称位置恰好在镜像轴上（仅当内部宽/高为奇数时发生，但生成约束保证为偶数，因此不会发生），忽略。
7. 灰(5)边框和品红(6)墙壁在输出中保持不变。

**关键洞察**：墙壁不是整体阻断镜像，而是逐像素地判定——同一框内的蓝色像素，有的能被镜像（反射位无墙），有的被擦除（反射位有墙）。必须对比多个示例中不同墙壁布局产生的不同镜像缺口，才能归纳出"反射位被墙占据则擦除源像素"这条隐蔽规则。
