## 新题 7：二面体匹配补全的风车拼图

**组合逻辑**：[dihedral_equiv + shape_match](创新：从等价分类改为确定每个象限碎片对应的旋转角度) → [completion](创新：在旋转坐标系下补全碎片) → [concatenate + rotations_pinwheel](已有框架，但内容由补全生成)

**来源原语**：rotate, concatenate, square_canvas, array_layout, rotations_pinwheel（来自 7fe24cdd）；completion, fragment, template_sprite, translate_align, fragment_anchor_place（来自 fd096ab6）；dihedral_equiv, shape_match, normalized_mask（来自 6165ea8f）

**依赖链**：识别完整象限（模板） → 将每个碎片象限的像素与模板的四种旋转逐一匹配 → 匹配结果同时确定该象限的旋转角度和缺失像素位置 → 补全缺失像素 → 将四个完整象限按风车排列拼接。碎片匹配与旋转确定是同一步（不可分离），补全依赖匹配结果，拼接依赖补全结果

正方形网格分为四象限：一个象限有完整图案，其余三个象限各含部分像素（碎片）。通过二面体匹配确定每个碎片对应完整图案的哪种旋转，补全后按风车排列拼合。

**输入结构**：黑(0)背景，正方形网格（边长 2N，N 为 5-7），被等分为四个 NxN 象限（左上、右上、左下、右下）。左上象限包含一个完整的单色图案（如蓝(1)，约 8-15 像素的不规则 4-连通图形，占据象限内约 30%-60% 面积，非对称且无旋转自等价）。其余三个象限各包含 3-5 个同色（与左上相同颜色）像素，这些像素构成左上图案经某种旋转（90度顺时针、180度、270度顺时针之一）后的一个子集。不同象限对应不同旋转角度（三个非左上象限分别对应三种旋转之一，但不一定按空间位置对应——例如右上象限的碎片可能对应 180 度旋转而非 90 度）。生成约束：每个碎片象限中的像素数量足以唯一确定对应的旋转角度（不存在歧义）；补全后的像素不超出各自象限边界。

**规则**：
1. 识别完整象限：四个象限中非背景像素数量最多的那个为模板象限（生成约束保证唯一）。提取其图案掩码 M（相对于象限左上角的坐标集）。
2. 生成 M 的三种非恒等旋转版本：M90（顺时针 90 度）、M180（180 度）、M270（顺时针 270 度），坐标均相对于 NxN 象限左上角。
3. 对每个碎片象限，提取其非背景像素的坐标集 F（相对于该象限左上角）：
   a. 检查 F 是否为 M90 的子集。若是，该象限对应 90 度旋转。
   b. 否则检查 F 是否为 M180 的子集。若是，该象限对应 180 度旋转。
   c. 否则检查 F 是否为 M270 的子集。若是，该象限对应 270 度旋转。
   d. 生成约束保证恰好匹配一种旋转。
4. 对每个碎片象限，将其对应旋转版本中尚未被碎片像素覆盖的位置补全为蓝(1)。
5. 输出即为补全后的四象限网格（保持原始象限位置不变）。

**关键洞察**：象限的空间位置不决定旋转角度——右上象限的碎片未必是 90 度旋转，可能是 180 度甚至 270 度。必须通过碎片像素与模板各旋转版本的子集匹配来确定实际旋转角度。这与参考题 7fe24cdd（位置直接决定旋转）和 fd096ab6（仅平移无旋转）都不同。需要对比多个示例中不同象限-旋转对应关系才能排除"位置决定旋转"这一简单假设。
