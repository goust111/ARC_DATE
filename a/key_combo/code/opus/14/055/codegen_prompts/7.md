## 新题 7：三标记点定矩形后按标记分布做半区双色描边

**组合逻辑**：[补全/complete](三点定矩形框) + [描边/border_drawing](绘制边框) + [重涂色/recolor](半区分色) ← [标记像素分布](编码分色规则)

**来源原语**：补全、标记像素、空心矩形、包围盒、三点定矩形框（e7639916）；描边、边框、半区分色、排序（1bfc4729）

**依赖链**：三个标记点确定矩形几何（无标记则无框可画）；标记在矩形边上的分布（2+1）确定分色轴和颜色归属（无分布分析则分色歧义）；描边和分色必须同时完成（先画再分色则等效，但分色规则依赖标记位置，不可独立确定）

三个标记像素确定矩形框的边界，其中两个标记在同一边、一个在另一边，这种 2-vs-1 分布决定矩形框的双色分割方式。

**输入结构**：约 12x12 网格，黑(0)背景。恰好三个红(2)色标记像素，它们位于其共同包围盒的边界上。其中两个标记位于包围盒的同一条边（均在顶边、均在底边、均在左边或均在右边），第三个标记位于对边（若两个在顶边，第三个在底边；若两个在左边，第三个在右边）。生成约束：包围盒至少 4x4；三个标记不共线；两个同边标记不在角点上（确保可区分边归属）。

**规则**：
1. 计算三个红(2)标记像素的包围盒。
2. 识别"双标记边"（含 2 个标记的那条边）和"单标记边"（含 1 个标记的对边）。
3. 确定分割轴：若双标记边和单标记边是水平边（顶/底），则沿包围盒的水平中线上下分割；若为垂直边（左/右），则沿垂直中线左右分割。
4. 绘制包围盒的完整矩形边框。包含双标记边的那一半边框涂绿(3)，包含单标记边的那一半边框涂蓝(1)。分割线上的像素归入双标记边一侧。
5. 恢复三个原始红(2)标记像素（覆盖在边框之上）。

**关键洞察**：标记像素承担双重功能——既定义矩形几何（包围盒），又通过 2-vs-1 的非对称分布编码边框的颜色分割规则。仅看一个示例可能无法区分"按标记数分色"和"按方位固定分色"，需要多个示例确认。

## 实现要求

1. `main(grid)` 必须实现新题描述中的确定性转换规则，不能只识别 `generate_input()` 的固定模板。禁止不同的input网格输出相同的output网格。
2. `generate_input()` 必须随机生成多样样例，不能固定死。随机维度应覆盖：网格大小、对象数量、位置、颜色、方向、形状参数或关键分支。注意若描述中存在若干，需实现而不是只有单个，包括object或者对应关系等等。且若涉及到最短路径，则输入网格中必涉及到多条路径，对选择造成干扰。
3. 生成器必须保证输入满足 `main()` 的隐式假设：对象不重叠、不越界、特殊标记唯一或可区分、匹配关系无歧义、关键分支出现概率相同。
4. 禁止把 ARC 颜色 id 、亮度、拼写等当作人类不可见的数值语义参与排序、大小比较或隐藏映射。颜色变化必须有可见结构线索。注意颜色亮度、拼写等也是不可见信息，若描述中出现违规的颜色id或者亮度，可自行使用少量的固定颜色替代，但注意生成时要在三个以内输入输出网格中对所有变换100%覆盖度。
5. 输出样例要视觉清晰，人类必须能从输入输出对中肉眼辨认出规律。具体要求：避免对象粘连、覆盖关系混乱、同一像素多重语义；不同逻辑步骤产生的结果不要大面积层叠在一起导致无法分辨哪个颜色属于哪个步骤；输入中各元素之间保持足够间距，输出中新增的标记/填充/路径等应与背景和已有元素在颜色上有明显区分；若规则涉及多层叠加，生成时控制对象密度和尺寸，确保叠加区域只占少数像素而非铺满整个网格。
6. 若规则有多个分支，生成器不能长期固定成一个分支；应让分支在随机样例中合理出现。分支概率不必平均——难以发现的隐蔽分支（如少数情况下才触发的特殊规则）应适当提高出现概率，确保在 3 个训练示例中至少出现一次，否则求解者无法归纳该规则。对于颜色映射类规则，确保 2 个左右的示例即可覆盖所有映射关系（每种颜色→颜色的映射至少在某个示例中出现过）。
