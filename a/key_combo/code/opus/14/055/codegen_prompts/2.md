## 新题 2：网格缺失交叉点裁剪后印章到标记槽位

**组合逻辑**：[裁剪/crop](由缺失交叉点定界) → [印章覆盖/stamp](裁剪结果作为模板) ← [标记像素](选择目标槽位)

**来源原语**：裁剪、网格线、缺失交叉点、四角围合、背景色空洞（a644e277）；印章覆盖、槽位、分隔列、标记像素、标记选槽接收精灵（363442ee）

**依赖链**：缺失交叉点确定裁剪范围（无法跳过裁剪直接印章，因为模板不是预给的）；裁剪产出的子图成为印章模板（裁剪目标与印章来源耦合）；标记像素选择目标槽位（无标记则不知道印在哪）

在网格结构中通过缺失交叉点定位并裁剪出一个子区域，将裁剪结果作为印章模板，印到右侧面板中被标记像素选中的槽位里。

**输入结构**：约 20x15 网格。左半部分：由橙(7)色线条组成的规则网格（水平线和垂直线，间距约 3 个像素），网格单元内散布少量彩色像素（红(2)、蓝(1)等，各单元内容不同）。恰好四个网格线交叉点被替换为黑(0)背景色，这四个缺失点构成一个轴对齐矩形的四角。右半部分（以灰(5)分隔列隔开）：一列等大槽位，每个槽位尺寸与四角围合的裁剪区域相同。部分槽位中心有一个红(2)标记像素，其余槽位为纯黑(0)。生成约束：四个缺失交叉点构成的矩形至少包含两个完整网格单元；标记槽位至少 1 个、至多 4 个。

**规则**：
1. 在左侧网格中找到四个黑(0)色的缺失交叉点（它们本应是橙(7)色）。
2. 以这四个点为角，做包含性裁剪（含边界上的网格线），得到一个子图作为印章模板。
3. 在右侧面板中，找到中心含有红(2)标记像素的槽位。
4. 将裁剪模板逐像素覆盖到每个被标记的槽位中（模板完全替换槽位原有内容）。未被标记的槽位、分隔列、左侧网格均保持不变。

**关键洞察**：印章模板不是直接给出的，而是通过网格缺失交叉点的结构性信号间接定义的——求解者必须先识别缺失模式完成裁剪，才能获得印章内容。
