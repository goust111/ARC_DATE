## 新题 3：镜像异或检测不对称像素并按半区着色

**组合逻辑**：[镜像/reflect](生成参照) → [异或/xor](检测不对称) → [重涂色/recolor](按空间位置分色)

**来源原语**：镜像、阵列排布（8d5021e8）；异或、掩码、逐像素异或输出（3428a4f5）；重涂色、按原色区分涂色（bcb3040b）；面积排名（a8d7556c——此处改为位置判断）

**依赖链**：镜像产生参照副本（无镜像则无法执行异或比较）；异或揭示原图与镜像的差异像素（无异或则不知道哪些像素不对称）；半区着色依赖异或结果的空间位置（无位置判断则不知道涂什么色）

将一个近似左右对称的精灵体自我镜像后做异或，找出不对称像素，然后根据不对称像素在对称轴左侧还是右侧分别着不同颜色。

**输入结构**：约 10x10 网格，黑(0)背景。一个红(2)色单连通精灵体（约 12~20 像素），关于其包围盒的垂直中轴线近似对称，但有 1~3 个像素打破对称（某些位置多出或缺少像素）。无其他前景色。生成约束：不对称像素在左侧和右侧均有分布（不全在一侧）；精灵体包围盒宽度为奇数（确保中轴线落在像素中心上）。

**规则**：
1. 计算红(2)精灵体的包围盒，确定垂直中轴线。
2. 将精灵体关于中轴线做左右镜像，生成一个虚拟的镜像副本（仅用于比较，不画在输出中）。
3. 逐像素异或原图与镜像：原图有色而镜像无色的像素，以及原图无色而镜像有色的像素，均为"不对称像素"。
4. 对称像素（原图和镜像都有色）保持红(2)不变。
5. 不对称像素中，位于中轴线左侧（含轴线上）的涂绿(3)，位于右侧的涂蓝(1)。
6. 背景保持黑(0)。

**关键洞察**：镜像不是输出操作而是一种分析工具——它生成参照以暴露原图的不对称结构；异或的结果不直接输出，而是驱动后续的空间着色决策。需要对比多个示例才能归纳出左/右对应绿/蓝的映射。
