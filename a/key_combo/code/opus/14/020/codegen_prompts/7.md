## 新题 7：锚块吸附的距离分级涂色轨迹

**组合逻辑**：[吸附](已有) + [计数](创新：计数对象从像素数变为移动距离) → [重涂色](创新：由距离区间映射颜色，而非像素数映射) + [轨迹着色](创新：轨迹不涂黑而是涂为距离对应色)

**来源原语**：吸附(snap) ← 1b8318e3；重涂色(recolor) ← 6e82a1ae/ac0c2ac3；计数(counting) ← 6e82a1ae/81c0276b；孤立像素(singleton_pixel) ← 1b8318e3；锚块(anchor_block) ← 1b8318e3；外框边缘(outer_frame) ← 1b8318e3；最近距离(nearest_distance) ← 1b8318e3；最短距离分配(nearest_frame_assign) ← 1b8318e3；像素数映射颜色(count_to_color) ← 6e82a1ae → 创新为距离映射颜色；轨迹涂黑(trail_painted_black) ← 8b9c3697 → 创新为轨迹涂色

**依赖链**：每个孤立像素吸附到最近锚块的外框 → 移动距离（king-move 步数）决定颜色映射 → 轨迹（起点到终点的路径）和终点像素统一涂为该距离对应的颜色。距离测量既驱动吸附目标选择，又驱动最终涂色——同一个量的双重作用构成耦合。

将散落的孤立像素吸附到最近的灰色锚块外框上，根据移动距离将轨迹和终点统一涂为对应颜色，孤立像素的原始颜色为干扰项。

**输入结构**：约 12x12 的网格，黑(0)为背景。2 个灰(5)实心 2x2 锚块，位置互不相邻（king-move 距离 >= 5）。5~6 个孤立单像素，颜色各不相同（如红(2)、蓝(1)、绿(3)、黄(4)、橙(7)等），散布在网格内。生成约束：每个孤立像素到其最近锚块的 king-move 距离两两不同，且涵盖距离 2、距离 3~4、距离 5 以上三个区间各至少一个像素；无平局（每个孤立像素有唯一最近锚块）。

**规则**：
1. 灰(5) 2x2 锚块保持不变。
2. 对每个孤立像素，计算其到每个锚块的 king-move（切比雪夫）距离，取最近锚块。距离定义为从像素到锚块 4 个格中最近那格的切比雪夫距离。
3. 将孤立像素吸附到最近锚块的一格外框上：外框 = 锚块 2x2 区域外围一圈（共 12 格）。目标格为外框中与孤立像素切比雪夫距离最小的格，若有多个等距格取行号最小者，再行号相同取列号最小者。
4. 确定移动距离 D = 孤立像素原始位置到目标外框格的切比雪夫距离。根据 D 选择轨迹颜色：
   - D <= 2：轨迹颜色为绿(3)
   - 3 <= D <= 4：轨迹颜色为红(2)
   - D >= 5：轨迹颜色为蓝(1)
5. 绘制从孤立像素原始位置到目标格的 king-move 最短路径（每步沿 8 方向中使切比雪夫距离减小最快的方向移动）。路径上的所有中间格和目标格均涂为步骤 4 确定的轨迹颜色。
6. 孤立像素的原始位置也涂为轨迹颜色（作为轨迹的起点）。
7. 孤立像素的原始颜色在输出中不再保留——被轨迹颜色覆盖。

**关键洞察**：孤立像素的原始颜色（红、蓝、绿、黄、橙等）是纯粹的干扰项，最终颜色完全由移动距离决定。求解者必须通过对比多个示例中不同原始颜色但相同距离区间的像素得到相同最终颜色，才能排除颜色保留或颜色映射的假设。
