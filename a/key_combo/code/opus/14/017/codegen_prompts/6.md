## 新题 6：像素计数同时决定楔形底边长度与填充颜色

**组合逻辑**：[计数 + 排序](统计三种前景色的像素数量并排序) → [填充](中位数确定基础线段长度，最大/最小数确定上下楔形颜色)

**来源原语**：计数、排序、前景色掩码、面积排序、按像素数降序(f8ff0b80)；填充、线段、三角楔形、距离递变、逐行宽度递变成楔(a65b410d)

**依赖链**：计数结果通过排序产生三个角色——最大值对应上楔颜色、最小值对应下楔颜色、中位值同时确定基础线段长度并对应线段本身的颜色。单一的计数操作同时驱动了几何参数（线段长度）和颜色分配（楔形着色），形成"一源多果"的扇出结构，与线性流水线不同。删除计数则长度和颜色均无法确定；删除楔形填充则计数结果无几何表达。

统计三种前景色的像素数量，按数量排序后：中位数色的像素数决定基线段长度并成为线段颜色，最多色填充上方扩展楔形，最少色填充下方收缩楔形。

**输入结构**：约 13x13 的网格，背景为黑(0)。网格中散布着三种颜色的前景像素：红(2)、蓝(1)、绿(3)。每种颜色各自构成一个或多个 4-连通的不规则小区域（每个区域 2-8 像素），三种颜色的总像素数互不相同且均不超过 10。网格中无其他前景元素。生成约束：中位数色的像素总数在 3-7 之间（确保线段长度适中）；三种颜色的像素数两两不同。

**规则**：
1. 分别计数红(2)、蓝(1)、绿(3)的总像素数。
2. 按像素数从大到小排列三种颜色，记为 C_max、C_mid、C_min。
3. 输出网格的列数等于 C_mid 的像素数，行数等于列数的两倍减一（即 2 * C_mid_count - 1）。
4. 在输出网格的正中行（第 C_mid_count 行，从 1 计数），绘制一条贯穿全行的水平线段，颜色为 C_mid。
5. 线段上方的每一行，左对齐填充 C_max 色，填充宽度 = C_mid_count + 该行到线段行的距离（向上每远一行宽度加 1），超出网格右边界的部分截断。
6. 线段下方的每一行，左对齐填充 C_min 色，填充宽度 = C_mid_count - 该行到线段行的距离（向下每远一行宽度减 1），宽度减至 0 时停止。
7. 线段行的像素保持 C_mid 色（覆盖楔形色）。

**关键洞察**：中位数对应的颜色承担双重角色——既是线段颜色，又决定了输出网格的尺寸。这个"中位数"身份必须对比多个示例才能确认（排除"最大数"或"最小数"决定长度的假设）。
