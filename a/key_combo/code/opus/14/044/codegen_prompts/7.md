## 新题 7：帧内散落像素连接同色框边后按边分段计数渲染柱状图

**组合逻辑**：[裁剪(crop)](已有) + [连线(connect)](创新：连线方向由颜色对应的框边方位决定，非对角线而是正交方向) + [散落连接同色框边(scatter_connect_side)](已有) + [计数(counting)](创新：计数对象从单色像素变为每条框边上连接到的散落像素数) + [计数渲染柱状图(counts_as_histogram)](创新：柱状图的列不按调色板固定顺序，而按框边位置映射——上/右/下/左)

**来源原语**：裁剪/矩形框/散落像素/颜色对应边/散落连接同色框边(5daaa586), 计数/柱状条/调色板顺序/计数渲染柱状图(f3cdc58f)

**依赖链**：识别矩形框和散落像素 → 按颜色将散落像素连接到对应框边 → 统计每条框边被连接的散落像素数量 → 在裁剪后的框内底部区域用框边颜色渲染柱状图。删掉连线则无法确定哪些像素属于哪条边（计数无依据）；删掉计数则柱状图无高度信息；删掉裁剪则输出范围不确定。

裁剪矩形框，将散落像素连接到同色框边，再按每边的连接数在框内绘制柱状图。

**输入结构**：黑(0)背景，约 20x20 网格。网格中有一个由四条完整线段构成的矩形框（约 12x12），四条边颜色各不相同（从蓝(1)、红(2)、绿(3)、黄(4)中各取一色，上边为一色、右边为一色、下边为一色、左边为一色）。四个角点颜色取该角相邻的两条边中行号或列号更小的那条边的颜色。矩形框外部散布若干单色像素，每个散落像素的颜色恰好与四条框边中的某一条相同。散落像素总数 8~14 个，每种框边颜色至少有 1 个、至多 5 个散落像素。矩形框内部初始全为黑色。生成约束：框的内部高度至少为 6 行（足以容纳柱状图）；框的内部宽度至少为 8 列（足以放下 4 列柱状图加间隔）。

**规则**：
1. 裁剪：输出为矩形框的精确边界框（含框线本身）。
2. 连线：对每个散落像素，沿垂直于其同色框边的方向画一条直线段，从散落像素出发延伸到同色框边上对应的像素为止（即行或列对齐的投影点）。连线颜色与散落像素和框边颜色相同。若散落像素在框外（裁剪前），连线中位于裁剪区域外的部分丢弃，仅保留进入裁剪区域后的部分。
3. 计数：统计四条框边各自有多少个散落像素与之颜色匹配（即被连接到该边的散落像素数）。
4. 柱状图渲染：在裁剪后框内部的底部区域绘制 4 列柱状图。四列从左到右分别对应上边、右边、下边、左边（固定框边方位顺序）。每列宽 1 像素，列与列之间间隔 1 像素黑色，4 列整体水平居中于框内部。每列从框内部底边向上填充该边颜色，高度等于该边的散落像素计数。
5. 连线像素与柱状图像素若重叠，柱状图覆盖连线。框线本身保持不变。

**关键洞察**：散落像素的颜色同时承载两层语义——它既决定连线方向（指向同色框边），又贡献给该框边的柱状图计数；求解者必须先理解颜色-框边对应关系，才能同时完成连线和计数两个操作。

## 实现要求

1. `main(grid)` 必须实现新题描述中的确定性转换规则，不能只识别 `generate_input()` 的固定模板。禁止不同的input网格输出相同的output网格。
2. `generate_input()` 必须随机生成多样样例，不能固定死。随机维度应覆盖：网格大小、对象数量、位置、颜色、方向、形状参数或关键分支。注意若描述中存在若干，需实现而不是只有单个，包括object或者对应关系等等。且若涉及到最短路径，则输入网格中必涉及到多条路径，对选择造成干扰。
3. 生成器必须保证输入满足 `main()` 的隐式假设：对象不重叠、不越界、特殊标记唯一或可区分、匹配关系无歧义、关键分支出现概率相同。
4. 禁止把 ARC 颜色 id 、亮度、拼写等当作人类不可见的数值语义参与排序、大小比较或隐藏映射。颜色变化必须有可见结构线索。注意颜色亮度、拼写等也是不可见信息，若描述中出现违规的颜色id或者亮度，可自行使用少量的固定颜色替代，但注意生成时要在三个以内输入输出网格中对所有变换100%覆盖度。

6. 若规则有多个分支，生成器不能长期固定成一个分支；应让分支在随机样例中合理出现。分支概率不必平均——难以发现的隐蔽分支（如少数情况下才触发的特殊规则）应适当提高出现概率，确保在 3 个训练示例中至少出现一次，否则求解者无法归纳该规则。对于颜色映射类规则，确保 2 个左右的示例即可覆盖所有映射关系（每种颜色→颜色的映射至少在某个示例中出现过）。
