## 新题 5：周期传播与同心带互补修复

**组合逻辑**：[周期性填充](修复可传播的像素) + [同心层填充](修复在所有周期副本中均缺失的系统性空洞) ← [对角线标记](提供同心带的颜色序列)——两种修复机制互补，非流水线

**来源原语**：补全/填充/周期性格/缺失像素/平移等价/平移向量决定填充(484b58aa), 同心层填充/空心矩形框/对角线标记/嵌套层次/对角序映射色环(99306f82)

**依赖链**：这是一个互补约束结构。周期传播能恢复大部分缺失像素（只要某个周期副本在该位置有可见色），但若某些同心带在所有副本中均被擦除，则传播无能为力。此时同心层规则接管：对角线标记给出从外到内的颜色序列，可填充那些系统性空缺的带。反过来，若没有周期传播提供的部分结构信息，也无法判断哪些带缺失、哪些存在。两者必须协同工作。

在含有系统性缺失的周期性同心嵌套图案中，先用最强平移向量传播可见像素恢复大部分内容，再用对角线标记提供的颜色序列填充剩余的整带空缺。

**输入结构**：约 18x18 网格。网格大部分区域显示一个周期性着色图案，但许多像素为黑(0)表示缺失。该图案的一个完整周期单元格（约 6x6~8x8）本应是一组同心矩形带：最外圈一像素宽的带为某色，向内依次嵌套更多带，直到中心。但在输入中，某 1~2 条完整的同心带在所有周期副本中均被擦除为黑(0)（系统性缺失），其余像素中约 30%~40% 随机缺失（局部缺失，可通过周期传播恢复）。在网格左上角（不与周期图案重叠的区域），有一串对角线标记像素：从左上到右下，每步行+1列+1，每个标记为一种颜色，颜色顺序对应同心带从外到内的颜色序列。对角线标记数量等于完整单元格的同心带总数。生成约束：周期平移向量的最大支持度无歧义（即最强平移向量唯一）；对角线标记不与周期图案区域重叠。

**规则**：
1. 找到非零平移向量中，重叠可见像素（两端均非黑(0)）数量最多且无颜色矛盾的向量（如 484b58aa）。利用该向量及其逆向量的传递闭包，将同一等价类中的可见颜色传播到类内所有黑(0)像素。
2. 传播完成后，检查周期单元格：某些同心带位置仍全为黑(0)（因为这些带在所有副本中均缺失，传播无法恢复）。
3. 读取对角线标记颜色序列（从左上到右下），对应同心带从最外层到最内层。
4. 对照传播后的单元格，确定哪些带已恢复（有颜色）、哪些带仍缺失（全黑）。用对角线标记中对应层的颜色填充所有仍缺失的带。
5. 用完全修复的单元格铺满整个周期区域。对角线标记像素从输出中移除（它们是指令，不是输出内容）。

**关键洞察**：周期传播和同心带规则各自只能修复一类缺失——传播修复随机散布的局部缺失，同心带规则修复在所有副本中一致缺失的系统性空洞。两者的修复范围互补且不重叠，缺少任何一个都无法完成重建。
