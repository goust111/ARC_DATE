## 新题 7：外部连通分量计数决定内部同心带层数

**组合逻辑**：[计数](创新：计数结果不输出为柱状图，而是编码为同心嵌套深度) + [同心层填充](创新：带颜色不由对角线标记静态给出，而由外部对象的数量动态决定) + [排序](决定颜色到层深度的映射顺序)

**来源原语**：计数/连通分量/固定色序/基线对齐(aaecdb9a), 同心层填充/空心矩形框/嵌套层次(99306f82), 排序/按高度排列(b7999b51)

**依赖链**：外部连通分量按颜色分组并计数 → 计数结果排序（多→少）→ 排序后的颜色序列成为同心带的从外到内颜色映射 → 计数最多的颜色涂最外圈带，计数最少的涂最内层。外部对象的空间分布编码了内部装饰信息，这种跨区域的信息传递是核心创新。

统计矩形框外各色 8-连通对象的数量，按数量降序排列这些颜色，然后用排列后的颜色序列从外到内填充矩形框的同心嵌套带。

**输入结构**：约 16x16 网格，背景黑(0)。网格中央有一个一像素厚的绿(3)矩形框，内部空（约 8x8~10x10 的空腔）。矩形框外部散布着若干单色 8-连通前景对象（每个对象 2~5 像素），颜色选自红(2)、蓝(1)、黄(4)、灰(5)等，3~4 种颜色，每种颜色有不同数量的对象（如红色 4 个对象、蓝色 2 个、黄色 1 个）。生成约束：各颜色的对象数量互不相同（无平局）；颜色种类数不超过矩形框内可容纳的最大同心带数（即 min(框内宽, 框内高) / 2 向上取整）；外部对象不与矩形框相邻。

**规则**：
1. 对矩形框外部的每种前景色，统计其 8-连通对象的数量（如 aaecdb9a）。
2. 将颜色按对象数量从多到少排序。数量相同时（生成约束保证不会发生），按固定色序 grey(5), red(2), teal(8), maroon(9), pink(6) 中的先后顺序排列。
3. 用排序后的颜色序列从外到内填充矩形框的内部空间（如 99306f82）：最外一圈（紧贴框内壁的像素环）涂排序第一的颜色（数量最多），下一圈向内缩一像素涂第二颜色，依次类推。若颜色用完而同心带仍有剩余，最后一种颜色填满剩余的所有内层（包括中心）。
4. 矩形框本身（绿(3)）保持不变。外部对象保持不变。

**关键洞察**：框外散落的对象看似随机噪声，实际上它们的数量分布编码了框内同心装饰的配色方案——每种颜色在外部出现的对象越多，它在内部就越靠外层（面积越大）。

<description>
Replace each teal macro-cell in the upper-right pattern with the teal mask from the left control sprite.

Input structure:
- The black background contains three 4-connected foreground components.
- A left control sprite is a full rectangle of red and teal pixels.
- An upper-right pattern is a full rectangle of the main color and teal pixels, arranged as uniform macro-cells.
- A lower solid rectangle of the main color gives the final output size.

Rule:
- Compress the upper-right pattern into macro-cells, using the lower rectangle size divided by the control
  sprite size to determine the compressed pattern dimensions.
- Make an output filled with the main color.
- For each teal macro-cell, paste the control sprite's teal mask into the corresponding output block, turning
  the control sprite's red pixels into the main color.

Key insight:
- The upper-right object is not copied directly; it is a coarse stencil whose teal cells are substituted by
  the entire teal mask from the separate red/teal control sprite.
