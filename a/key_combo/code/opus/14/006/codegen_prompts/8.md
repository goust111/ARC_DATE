## 新题 8：内嵌标记计数决定旋转拼贴的副本数与角度序列

**组合逻辑**：[计数(counting)](创新：标记数同时编码副本数量和旋转序列) → [裁剪(crop)] → [旋转(rotate)](创新：每个副本的旋转角度由其在序列中的位置决定) → [拼接(concatenate)](创新：拼接为 K 份而非固定 2 份)

**来源原语**：裁剪(crop, 28bf18c6)、拼接(concatenate, 28bf18c6 → 创新为多副本拼接)、旋转(rotate, 84551f4c)、计数(counting, d4b1c2b1/52fd389e)、精灵体(sprite, 28bf18c6)、内嵌标记计数(embedded_marker_count, 52fd389e)、计数决定扩展量(count_determines_expansion, 52fd389e → 创新为计数决定拼接数和旋转序列)、编码映射(encoding_map, 52fd389e)

**依赖链**：精灵体内嵌标记像素的数量 K 同时决定三件事：(a) 裁剪后制作 K 个副本，(b) 第 i 个副本顺时针旋转 i x 90 度，(c) 标记像素在输出中被擦除。K 是连接计数、旋转和拼接的枢纽参数，且标记在输出中消失，迫使求解者从输入中读取后在输出中验证。

裁剪精灵体后，按内嵌标记数制作多份渐进旋转的副本并水平拼接，同时擦除标记。

**输入结构**：约 10x10 的黑(0)背景网格。含 1 个单色精灵体，主体为蓝(1)（4-连通，5-8 像素），其中嵌有 K 个红(2)标记像素（K 为 2 或 3，因示例而异）。精灵体含标记在内的整体为 4-连通。精灵体边界框为正方形（宽=高），且边长为奇数（如 3x3 或 5x5），保证旋转后尺寸不变。精灵体形状不具有 90 度旋转对称性（即旋转 90 度后与原图不同），以确保旋转效果可观察。生成约束：不同示例中 K 的值应不同（一个示例 K=2，另一个 K=3），以便求解者通过对比推断 K 与副本数/旋转的关系。

**规则**：
1. 裁剪精灵体（含红(2)标记像素）到其最小边界框。
2. 统计边界框内红(2)标记像素的数量 K。
3. 生成 K 个副本。第 i 个副本（i 从 0 开始）围绕边界框中心顺时针旋转 i x 90 度：
   - 第 0 个副本：旋转 0 度（原样）
   - 第 1 个副本：旋转 90 度
   - 第 2 个副本（若 K=3）：旋转 180 度
4. 在所有副本中，将红(2)标记像素重涂为蓝(1)（擦除标记）。
5. 将 K 个副本从左到右水平拼接，相邻副本之间插入 1 列黑(0)间隔。
6. 输出拼接后的结果。

**关键洞察**：红色标记像素是"自毁型信息载体"——它们在输入中编码了副本数量和旋转序列，但在输出中被擦除。求解者在输出中只看到蓝色副本的旋转排列，必须回到输入中数红色像素才能理解为什么是这么多个副本、为什么每个旋转了不同角度。
