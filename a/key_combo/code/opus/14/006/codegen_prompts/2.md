## 新题 2：分区结构双重编码——内容与放大倍率

**组合逻辑**：[计数(counting)](创新：统计非空分区数作为放大因子) + [像素放大(pixel_upscale)](创新：倍率来自同一结构的填充统计而非全局色数)

**来源原语**：计数(counting, 1190e5a7/d4b1c2b1)、像素放大(pixel_upscale, d4b1c2b1)、分隔栅格(divider_grid, 1190e5a7)、矩形区域(rectangular_region, 1190e5a7)、网格采样(grid_sampling, 90c28cc7)、分区数定输出尺寸(partition_sets_size, 1190e5a7 → 创新)、色数决定倍率(color_count_scale, d4b1c2b1 → 创新为填充区数决定倍率)

**依赖链**：红(2)分割条将网格切分为 R x C 个区域 → 每个区域内可能有或无一个彩色像素 → 非空区域的总数 K 成为放大因子 → 以 R x C 的"有/无"模式作为低分辨率图案 → 将其放大 K 倍输出。分区结构同时提供图案内容和缩放参数，两个用途不可分割。

将红色条分隔的网格视为低分辨率图案，以其中非空区域的计数作为像素放大倍率输出。

**输入结构**：约 12x12 的黑(0)背景网格。红(2)单像素宽的水平条和垂直条贯穿整个网格宽度/高度，将网格分为 R x C 个矩形区域（R、C 各 2-4）。每个区域内部尺寸相同（至少 2x2）。部分区域正中央放置一个彩色像素（颜色非红(2)、非黑(0)，可为蓝(1)、绿(3)、黄(4)等不同颜色），其余区域内全为黑(0)。生成约束：非空区域数 K 满足 2 <= K <= 4，以保证输出尺寸合理（最大 4R x 4C）。不同示例的 K 值应不同。

**规则**：
1. 识别红(2)分割条，确定 R x C 的分区网格。
2. 构建 R x C 的低分辨率图像：若区域内含彩色像素，该位置取该像素的颜色；若区域为空，该位置取黑(0)。
3. 统计低分辨率图像中非黑(0)像素的总数 K。
4. 将低分辨率图像进行 K 倍像素放大：每个像素替换为 K x K 的同色实心方块。
5. 输出仅包含放大后的图像，不包含红色分割条。

**关键洞察**：同一个分区结构被双重使用——既是内容的载体（哪些位置有什么颜色），又是缩放参数的来源（非空位置的数量）。求解者必须遍历所有分区才能同时获取图案和倍率。

## 实现要求

1. `main(grid)` 必须实现新题描述中的确定性转换规则，不能只识别 `generate_input()` 的固定模板。禁止不同的input网格输出相同的output网格。
2. `generate_input()` 必须随机生成多样样例，不能固定死。随机维度应覆盖：网格大小、对象数量、位置、颜色、方向、形状参数或关键分支。注意若描述中存在若干，需实现而不是只有单个，包括object或者对应关系等等。且若涉及到最短路径，则输入网格中必涉及到多条路径，对选择造成干扰。
3. 生成器必须保证输入满足 `main()` 的隐式假设：对象不重叠、不越界、特殊标记唯一或可区分、匹配关系无歧义、关键分支出现概率相同。
4. 禁止把 ARC 颜色 id 、亮度、拼写等当作人类不可见的数值语义参与排序、大小比较或隐藏映射。颜色变化必须有可见结构线索。注意颜色亮度、拼写等也是不可见信息，若描述中出现违规的颜色id或者亮度，可自行使用少量的固定颜色替代，但注意生成时要在三个以内输入输出网格中对所有变换100%覆盖度。
5. 输出样例要视觉清晰，人类必须能从输入输出对中肉眼辨认出规律。具体要求：避免对象粘连、覆盖关系混乱、同一像素多重语义；不同逻辑步骤产生的结果不要大面积层叠在一起导致无法分辨哪个颜色属于哪个步骤；输入中各元素之间保持足够间距，输出中新增的标记/填充/路径等应与背景和已有元素在颜色上有明显区分；若规则涉及多层叠加，生成时控制对象密度和尺寸，确保叠加区域只占少数像素而非铺满整个网格。
6. 若规则有多个分支，生成器不能长期固定成一个分支；应让分支在随机样例中合理出现。分支概率不必平均——难以发现的隐蔽分支（如少数情况下才触发的特殊规则）应适当提高出现概率，确保在 3 个训练示例中至少出现一次，否则求解者无法归纳该规则。对于颜色映射类规则，确保 2 个左右的示例即可覆盖所有映射关系（每种颜色→颜色的映射至少在某个示例中出现过）。
