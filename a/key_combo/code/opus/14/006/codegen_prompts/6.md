## 新题 6：连通分量面积分类驱动同心方框色带与层数

**组合逻辑**：[计数(counting) + 面积分级(area_ranking)](创新：面积分类同时决定组件重涂色和同心生长的色带结构) → [重涂色(recolor)] + [生长(grow)](两个操作由同一分类结果平行驱动并在空间上交织)

**来源原语**：重涂色(recolor, e8593010)、生长(grow, 5c2c9af4)、计数(counting, d4b1c2b1/1190e5a7)、连通分量(connected_component, e8593010)、同心方框层(concentric_layer, 5c2c9af4)、种子像素(seed_pixel, 5c2c9af4)、面积分级(area_ranking, e8593010)、面积决定颜色(area_determines_color, e8593010 → 创新为面积同时决定颜色和同心层参数)

**依赖链**：黑色连通分量按面积分为三类 → 每类的计数（A1、A2、A3）同时决定两件事：(a) 对应类别的重涂颜色，(b) 同心方框中该颜色的层数 → 同心方框和重涂组件在空间上交织，组件像素优先于同心方框像素。面积分类是一个决策节点，同时向两个操作分发参数。

统计灰色网格上黑色连通分量的面积分布，同时据此重涂各分量并从种子生长出反映面积分布的彩色同心方框。

**输入结构**：约 15x15 的灰(5)背景网格。散布多个黑(0)的 4-连通分量，每个分量的面积恰好为 1、2 或 3（各面积类别至少出现 1 个分量，总共 4-7 个分量）。另有恰好 1 个红(2)种子像素，位于网格内部（不在边界行/列），不与任何黑色分量相邻。生成约束：三种面积类别的分量数量（A1、A2、A3）互不相同，以确保同心色带宽度不同从而可区分；A1+A2+A3 <= 8，以保证同心方框不过大。不同示例中 A1、A2、A3 的值应不同。

**规则**：
1. 识别所有黑(0)的 4-连通分量，按面积分类：面积 1 的分量有 A1 个，面积 2 的有 A2 个，面积 3 的有 A3 个。
2. 重涂各分量：面积 1 → 绿(3)，面积 2 → 蓝(1)，面积 3 → 黄(4)。
3. 以红(2)种子像素为中心，向外生长同心方框边框。从里到外依次为：
   - 第 0 层：中心像素本身，保持红(2)。
   - 第 1 至第 A1 层：颜色为绿(3)（对应面积 1 类的计数）。
   - 第 A1+1 至第 A1+A2 层：颜色为蓝(1)（对应面积 2 类的计数）。
   - 第 A1+A2+1 至第 A1+A2+A3 层：颜色为黄(4)（对应面积 3 类的计数）。
   每一层是以种子为中心、边长为 2k+1 的正方形边框（k 为层号）。
4. 同心方框像素若与已重涂的分量像素重叠，保留分量的颜色（分量优先于同心方框）。超出网格边界的同心方框像素舍弃。
5. 灰(5)背景和不受影响的区域保持不变。

**关键洞察**：面积分类是一个"一次计算、双重使用"的决策节点——它既决定了分量的目标颜色，又决定了同心方框每段色带的宽度。同心方框本质上是面积分布的"空间直方图"，而分量重涂是同一分类的"就地标注"。两个输出视觉上交织在一起，需要同时理解才能完整推断规则。

2. `generate_input()` 必须随机生成多样样例，不能固定死。随机维度应覆盖：网格大小、对象数量、位置、颜色、方向、形状参数或关键分支。注意若描述中存在若干，需实现而不是只有单个，包括object或者对应关系等等。且若涉及到最短路径，则输入网格中必涉及到多条路径，对选择造成干扰。

6. 若规则有多个分支，生成器不能长期固定成一个分支；应让分支在随机样例中合理出现。分支概率不必平均——难以发现的隐蔽分支（如少数情况下才触发的特殊规则）应适当提高出现概率，确保在 3 个训练示例中至少出现一次，否则求解者无法归纳该规则。对于颜色映射类规则，确保 2 个左右的示例即可覆盖所有映射关系（每种颜色→颜色的映射至少在某个示例中出现过）。
