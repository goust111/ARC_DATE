## 新题 1：重叠深度热力图

**组合逻辑**：[透明叠加](创新：多层深度计数而非二值并集) + [重涂色](创新：色彩指引块作为深度图例而非象限映射) + [擦除](已有)

**来源原语**：透明叠加(dae9d2b5), 重涂色(7c008303), 填充矩形(20818e16), 色彩指引块(7c008303), 逐格对齐(dae9d2b5), 擦除(0607ce86)

**依赖链**：叠加计数产生深度值 → 深度值通过指引条的有序映射转化为颜色 → 指引条本身被擦除。若不计算重叠深度，则不知使用指引条中的第几个颜色；若无指引条，则深度值无法转换为输出颜色。两步互为必要条件。

将多个灰色矩形的重叠深度逐像素量化，再按角落色彩指引条的顺序映射为不同颜色，指引条本身从输出中擦除。

**输入结构**：约 15x15 的网格，黑(0)背景。网格内散布 3-5 个灰(5)填充矩形，尺寸各异（宽 2-6、高 2-6 像素），彼此部分重叠，无两个矩形的边界框完全相同。网格的某一角落（如左下角）放置一条 1xK 的水平色彩指引条（K 等于网格中实际出现的最大重叠深度），指引条中依次排列 K 种不同的非黑(0)、非灰(5)颜色（例如 K=3 时依次为蓝(1)、红(2)、绿(3)），指引条不与任何灰色矩形重叠。不同示例中指引条使用的颜色可能不同。

**规则**：
1. 对网格中每个像素，计算覆盖它的灰(5)矩形数量，得到该像素的重叠深度 d（d=0 表示无矩形覆盖）。
2. 指引条是有序深度图例：从左到右，第 1 个颜色对应深度 1，第 2 个颜色对应深度 2，以此类推直到第 K 个颜色对应深度 K。
3. 将每个深度 d>=1 的像素替换为指引条中第 d 个颜色。深度 0 的像素保持黑(0)。
4. 将指引条本身的像素替换为黑(0)（擦除）。

**关键洞察**：灰色矩形不是保留在输出中的对象而是深度探测器；角落的色彩指引条不是空间映射而是有序的深度图例。仅凭单个示例可能误将映射理解为"按矩形编号着色"或"按位置着色"，需要对比多个示例（不同矩形排列、不同图例颜色）才能确认规则是按重叠层数映射。
