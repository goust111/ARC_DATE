## 新题 1：像素数同时编码邻域几何与扩展深度

**组合逻辑**：[计数(counting)](创新：从全局统一系数改为逐对象双重编码) + [描边(mark_neighbors)](创新：邻域几何不由颜色决定而由像素数奇偶决定) → 扩展深度由像素数量值决定

**来源原语**：计数(counting) ← ac0a08a4；描边/mark_neighbors ← 0ca9ddb6, b27ca6d3；对角邻接(diagonal_adjacency)/正交邻接(orthogonal_adjacency) ← 0ca9ddb6；尺寸分类(size_classification) ← b27ca6d3；数量决定倍率(count_determines_scale) ← ac0a08a4

**依赖链**：每个连通分量的像素数 N 同时决定两件事——N 的奇偶性选择邻域几何类型（偶数→对角，奇数→正交），N 的数值决定扩展层数（偶数为 N/2 层，奇数为 (N-1)/2 层）。删除像素计数则无法确定几何和深度；删除几何选择则无法区分标记方向；删除深度规则则无法确定扩展范围。三者缺一不可。

一句话总结：根据每个彩色连通分量的像素数，用奇偶性选择对角或正交邻域，用数值大小决定扩展层数，围绕该分量绘制对应颜色的标记光晕。

**输入结构**：约 17x17 的黑(0)背景网格。散布 4-6 个单色 4-连通前景分量，每个分量由 3-7 个像素组成，每个分量的颜色互不相同（使用蓝(1)、红(2)、绿(3)、品红(6)、橙(7)等）。分量形态不限（可为线段、折线、不规则团块等），但各分量之间的间距足够大（最小间距 >= 最大可能扩展半径 + 1），保证在最大层数扩展后各分量的标记区域互不重叠。生成约束：每个分量的像素数至少为 3，且至少有一个偶数像素数分量和一个奇数像素数分量。

**规则**：
1. 识别所有 4-连通的非黑前景分量，记每个分量的像素数为 N。
2. 若 N 为偶数：以该分量的每个像素为中心，向外扩展 N/2 层对角邻域（第 1 层为每个前景像素的 4 个对角邻居，第 2 层为第 1 层所有像素的对角邻居中尚未被标记的位置，依此类推），标记色为黄(4)。
3. 若 N 为奇数：以该分量的每个像素为中心，向外扩展 (N-1)/2 层正交邻域（第 1 层为每个前景像素的 4 个正交邻居，后续层同理），标记色为橙(7)。
4. 扩展时超出网格边界的位置跳过。
5. 原始前景像素保持不变，不被标记色覆盖。
6. 若不同分量的标记区域意外重叠（违反生成约束时的兜底），像素数更大的分量的标记优先。

**关键洞察**：像素数的奇偶性和数值是一个量的两个面——奇偶选择标记的几何形状（对角菱形 vs 正交十字），数值选择光晕的厚度。仅看单个示例可能猜到固定几何和固定层数，必须对比多个分量和多个示例才能归纳出双重编码规则。

## 实现要求

1. `main(grid)` 必须实现新题描述中的确定性转换规则，不能只识别 `generate_input()` 的固定模板。禁止不同的input网格输出相同的output网格。
2. `generate_input()` 必须随机生成多样样例，不能固定死。随机维度应覆盖：网格大小、对象数量、位置、颜色、方向、形状参数或关键分支。注意若描述中存在若干，需实现而不是只有单个，包括object或者对应关系等等。且若涉及到最短路径，则输入网格中必涉及到多条路径，对选择造成干扰。
3. 生成器必须保证输入满足 `main()` 的隐式假设：对象不重叠、不越界、特殊标记唯一或可区分、匹配关系无歧义、关键分支出现概率相同。
4. 禁止把 ARC 颜色 id 、亮度、拼写等当作人类不可见的数值语义参与排序、大小比较或隐藏映射。颜色变化必须有可见结构线索。注意颜色亮度、拼写等也是不可见信息，若描述中出现违规的颜色id或者亮度，可自行使用少量的固定颜色替代，但注意生成时要在三个以内输入输出网格中对所有变换100%覆盖度。
5. 输出样例要视觉清晰，人类必须能从输入输出对中肉眼辨认出规律。具体要求：避免对象粘连、覆盖关系混乱、同一像素多重语义；不同逻辑步骤产生的结果不要大面积层叠在一起导致无法分辨哪个颜色属于哪个步骤；输入中各元素之间保持足够间距，输出中新增的标记/填充/路径等应与背景和已有元素在颜色上有明显区分；若规则涉及多层叠加，生成时控制对象密度和尺寸，确保叠加区域只占少数像素而非铺满整个网格。
6. 若规则有多个分支，生成器不能长期固定成一个分支；应让分支在随机样例中合理出现。分支概率不必平均——难以发现的隐蔽分支（如少数情况下才触发的特殊规则）应适当提高出现概率，确保在 3 个训练示例中至少出现一次，否则求解者无法归纳该规则。对于颜色映射类规则，确保 2 个左右的示例即可覆盖所有映射关系（每种颜色→颜色的映射至少在某个示例中出现过）。
