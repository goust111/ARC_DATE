## 新题 5：异色矩形沿角标对角平移并分裂碰撞体

**组合逻辑**：[颜色异常值选择(outlier_color_selection)](创新：从象限选取改为矩形选取) → [平移(translate) + 角位指示方向(corner_indicates_dir)](已有，但只施加于异常值对象) → [分裂(split)](创新：分裂由平移碰撞触发而非预设路径)

**来源原语**：颜色异常值选择(outlier_color_selection) ← 0b148d64；平移(translate)/填充矩形(filled_rectangle)/控制像素(control_pixel)/角位指示方向(corner_indicates_dir)/对角固定步移(diagonal_fixed_step) ← 470c91de；分裂(split)/穿越并分开(pass_through_split)/轴线排列(axis_arrangement) ← 9f669b64；擦除(erase) ← 多题

**依赖链**：异常值颜色检测 → 选定唯一运动体 → 控制像素确定对角运动方向 → 运动体沿对角线持续平移直到碰撞或到达边界 → 若碰撞到另一矩形则将被碰撞矩形沿垂直于运动方向的轴分裂。三个环节缺一不可：不知谁是异常值则不知谁运动；不知角位则不知方向；不知分裂规则则碰撞无法处理。源题中三者分属不同谜题（0b148d64 做颜色异常值选取、470c91de 做角位平移、9f669b64 做穿越分裂），这里它们形成全新的"选择→运动→碰撞交互"链，且碰撞的对象和分裂方向都取决于运动方向，产生涌现效应。

一句话总结：在若干带角标的彩色矩形中找出颜色唯一的异常矩形，沿其角标方向对角平移，若碰撞到另一矩形则将该矩形沿运动垂直方向一分为二。

**输入结构**：约 18x18 的黑(0)背景网格。4 个填充矩形（约 3x2 到 4x3 大小），每个矩形有一种主体颜色。其中 3 个矩形共享同一颜色（如红(2)），第 4 个矩形为不同颜色（如绿(3)）——即颜色异常值。每个矩形的一个角上有一个青(8)控制像素（替换该角的一个像素）。4 个矩形在网格中分散放置，保证异常矩形沿其青(8)角标指示的对角方向移动时，路径上恰好经过一个同色（红(2)）矩形。生成约束：异常矩形的移动路径不经过多于一个其他矩形；至少有一个红(2)矩形不在运动路径上。

**规则**：
1. 识别所有填充矩形（将每个矩形的青(8)像素视为其角上的控制标记，该位置实际属于矩形）。
2. 统计每个矩形的主体颜色（非青色的颜色），找到颜色唯一的异常矩形。
3. 异常矩形的青(8)控制像素所在角的方向即为运动方向（如青(8)在右上角→运动方向为右上，即行 -1、列 +1）。
4. 将异常矩形的青(8)像素恢复为矩形主体颜色，得到完整矩形。
5. 擦除异常矩形的原始位置（涂为黑(0)）。
6. 沿运动方向逐步平移该矩形（每步行列各移 1），直到矩形的下一步位置与另一个矩形重叠或矩形边缘触及网格边界。
7. 若因碰撞停止：异常矩形停在碰撞前最后的合法位置。被碰撞的矩形沿垂直于运动方向的轴被分裂——将被碰撞矩形沿异常矩形运动路径的投影线一分为二，两半各向垂直方向外移 1 格。被碰撞矩形的青(8)控制像素随其所在半边移动。
8. 若因边界停止：异常矩形停在最后的合法位置，无分裂发生。
9. 未被碰撞的矩形保持原位不变（保留其青(8)控制像素）。

**关键洞察**：其他矩形上的青(8)角标是视觉诱饵——它们暗示所有矩形都会移动，但实际上只有颜色异常值才动。分裂方向取决于运动方向（垂直于运动轴），而非被碰撞矩形的自身属性，这需要对比多个示例（不同运动方向产生不同分裂轴）才能归纳。
