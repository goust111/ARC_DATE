## 新题 1：箭头定向模板旋转印章

**组合逻辑**：[朝向推断/dir_inference](创新：从控制射线方向改为控制模板旋转角度) + [印章覆盖/stamp_overlay] + [擦除/erase]（已有原语）

**来源原语**：朝向推断、缺角指示方向（参考题 6e19193c）；印章覆盖、模板掩码（参考题 e6721834、5a5a2103）；擦除（参考题 fd02da9e）

**依赖链**：箭头精灵体的缺角方向决定模板的旋转角度；旋转后的模板替换箭头原位——不推断方向就无法选择旋转，不擦除箭头就会与模板冲突。

根据每个箭头精灵体的朝向，将唯一模板旋转至对应角度后印章到箭头所在位置。

**输入结构**：黑(0)背景网格，约 15x15。左上角 3x3 区域有一个蓝(1)的非对称模板精灵体（3~5 个前景像素构成的不规则连通图案，不具备 90 度旋转对称性）。网格其余区域散布 3~5 个绿(3)箭头精灵体，每个占据 2x3 或 3x2 的边界框，形状为矩形缺去一个角像素（保留 5 个像素），各箭头之间至少间隔 4 个像素。每个箭头恰好缺去四个角之一，缺角位置各异。生成约束：箭头旋转印章后不会超出网格边界，不同箭头的印章区域不重叠。

**规则**：
1. 识别左上角 3x3 区域中的蓝(1)非对称模板。
2. 对每个绿(3)箭头，定位其边界框中唯一的黑(0)角像素，根据缺角位置确定指向方向：缺左上角→指向左上→旋转 0 度，缺右上角→指向右上→顺时针旋转 90 度，缺右下角→指向右下→旋转 180 度，缺左下角→指向左下→顺时针旋转 270 度。
3. 擦除该箭头的所有绿(3)像素（还原为黑(0)）。
4. 将模板按确定角度旋转后，以蓝(1)色印章在箭头边界框中心位置（取边界框中心行列，向下向右取整），模板中心对齐该位置。
5. 箭头按其边界框左上角的行优先、列次优先顺序依次处理。
6. 左上角模板本身在输出中保留不变。

**关键洞察**：箭头的缺角在源题中用于推断射线延伸方向，在此处被重新解释为模板旋转角度的编码；模板的非对称性使得四种旋转产生四种不同输出，缺角方向与旋转角度的对应关系需要对比多个示例才能归纳。
