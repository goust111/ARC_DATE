## 新题 4：射线围区边界色洪泛填充

**组合逻辑**：[连线/line_drawing] + [射线延伸/ray_extend + 触发点分束/trigger_splits_beam](创新：分束产生的几何分区作为洪泛填充的目标) + [洪泛填充/flood_fill](创新：填充色由围区边界颜色组成决定)

**来源原语**：连线、对角线段连接、同色配对、端点对（参考题 1f876c06）；射线延伸、触发像素、触发点分束、对角对齐（参考题 db695cfb）；洪泛填充（参考题 4e469f39）

**依赖链**：对角连线建立基础线网→触发像素在线上产生垂直分束射线→线网和射线共同围合出封闭区域→洪泛填充根据围区边界颜色组成选择填充色。四步之间逐级依赖：没有连线就没有线网，没有分束就没有足够的围区，没有边界色分析就无法确定填充色。

对角线连接同色像素对，触发像素在对角线上发射垂直射线，围出的封闭区域按边界颜色组成进行洪泛填充。

**输入结构**：黑(0)背景网格，约 15x15。蓝(1)像素成对出现，每对位于同一条 45 度对角线上，共 2~3 对（4~6 个蓝像素）。品红(6)像素 1~3 个，每个恰好位于某对蓝(1)像素的对角连线路径上（即品红像素与该对的两个蓝像素共线于同一条 45 度对角线）。每条对角连线上最多一个品红触发像素。生成约束：连线和射线形成的线网至少围合出 2 个不接触网格边的封闭区域；不同对角连线互不交叉（但分束射线可以与其他连线交叉）。

**规则**：
1. 对每对蓝(1)像素，沿 45 度对角方向绘制蓝(1)线段连接它们（包含两端点和中间所有像素）。
2. 对每个品红(6)触发像素，判断它所在对角线的方向（左上-右下或右上-左下），发射与该方向垂直的两条 45 度射线（即旋转 90 度方向），从触发像素出发向两侧延伸至网格边界，使用品红(6)绘制。
3. 颜色优先级：蓝(1)覆盖品红(6)。交叉位置显示蓝(1)。
4. 识别所有被线条和网格边界完全包围的黑(0)4-连通封闭区域（不包含任何接触网格边缘的区域）。
5. 对每个封闭区域，检查其边界（与该区域 4-邻接的所有非黑像素）的颜色：若边界全为蓝(1)→填充红(2)；若边界全为品红(6)→填充绿(3)；若边界同时包含蓝(1)和品红(6)→填充黄(4)。
6. 接触网格边缘的背景区域保持黑(0)不变。

**关键洞察**：触发像素的分束射线在源题中是纯粹的视觉输出，此处射线与连线共同创造几何分区——分区的存在完全依赖于分束行为。填充颜色由封闭区域边界的颜色组成决定，而非固定映射，需要对比多个区域和示例才能归纳出三种边界组成到三种填充色的规则。
