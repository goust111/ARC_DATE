## 新题 7：门控走廊中的累积旋转移动

**组合逻辑**：[移动](创新：移动不再是单步到达目标，而是逐段通过多个门) + [旋转](创新：旋转不是一次性 180 度，而是每过一个门累积 90 度) + [障碍门处标记通道](创新：标记形状随旋转后的矩形朝向变化)

**来源原语**：移动/同轴对齐的矩形对/障碍段/障碍门处标记通道(fc10701f), 旋转(99caaf76), 重涂色(多题), 擦除(多题)

**依赖链**：识别起止矩形和走廊上的门 → 移动过程中每过一个门旋转 90 度 → 旋转改变矩形宽高 → 标记形状取决于当前朝向 → 最终矩形朝向取决于门的总数。删除门识别则不知何处旋转；删除旋转则标记形状和终态朝向错误；删除移动则无空间变换。

一个彩色矩形沿走廊向目标移动，每穿过一个障碍门旋转 90 度，到达目标位置时朝向由经过的门数决定。

**输入结构**：约 7x20 的网格（窄高或宽矮，走廊沿长轴方向），背景为黑(0)。走廊一端（如最左侧）有一个橙(7)的 2x3 实心矩形（宽 2 高 3），另一端（如最右侧）有一个同尺寸位置放置的栗(9)实心矩形标记目标区域。两者之间共用行跨度（如果走廊水平）。走廊中间有 1~3 组灰(5)障碍段，每组由走廊两侧的灰(5)像素构成"门"——两侧灰(5)像素在门所在列各占若干行，中间留出恰好能让当前朝向的矩形通过的缺口。生成约束：走廊足够宽（7 行），使得矩形旋转后（3x2 变 2x3 或反之）仍能在走廊中纵向居中通过；各门之间水平间距至少 4 列。

**规则**：
1. 识别橙(7)矩形（起始）、栗(9)矩形（目标）和所有灰(5)障碍门。确定移动方向为从橙(7)矩形指向栗(9)矩形的水平或垂直方向。
2. 擦除橙(7)矩形为黑(0)。保留栗(9)矩形和灰(5)障碍门。
3. 将橙(7)矩形沿移动方向逐列（或逐行）平移。每当矩形完全通过一个灰(5)门（矩形后缘离开门所在列/行后），将矩形顺时针旋转 90 度。旋转以矩形中心为轴，旋转后矩形在走廊的垂直于移动方向的维度上居中放置。
4. 矩形通过每个门时，在门的缺口处（矩形穿越门时门所在列/行中矩形占据的非灰像素位置）涂上红(2)标记。标记的形状反映矩形穿越该门时的当前朝向（第一个门时矩形是原始 2x3，标记宽 2；若经过一次旋转后矩形变 3x2，下一个门标记宽 3；以此类推）。
5. 矩形到达栗(9)标记区域后，用橙(7)覆盖栗(9)的位置，矩形的最终朝向为初始朝向经过 N 次 90 度顺时针旋转的结果（N 为门的数量）。
6. 灰(5)障碍门和红(2)门标记保留在输出中。

**关键洞察**：门的数量不仅产生标记效果，还累积改变矩形的朝向，导致后续门的标记形状和最终矩形形态都是门数量的函数。需要对比不同门数量的示例才能发现旋转是累积的而非交替的。
