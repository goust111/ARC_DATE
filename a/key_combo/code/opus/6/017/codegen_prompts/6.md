## 新题 6：奇偶条件像素放大与掩码分化

**组合逻辑**：[像素放大](创新：放大规则不再统一，由像素所属对象的属性决定放大方式) + [掩码映射](创新：掩码选择在自身色选掩码的基础上增加条件分支) + [标注中心](创新：中心标注不是最终输出，而是改变该像素放大时所用掩码的控制信号) + [奇偶性](创新：奇偶性不直接作用于输出，而是分流放大算法)

**来源原语**：像素放大/掩码映射/自身色选掩码/全局掩码/块单元(973e499e), 标注中心/奇偶性/奇边长才标注/十字标记(22806e14), 擦除(多题)

**依赖链**：判断每个正方形的边长奇偶 → 奇边长正方形标注中心 → 逐像素放大时根据像素是否为标注中心、所属正方形的奇偶类别选择不同的掩码规则 → 生成最终输出。删除奇偶判定则无法分流放大规则；删除中心标注则中心像素的特殊掩码丢失；删除像素放大则无输出。

将输入中的每个像素放大为与输入同尺寸的块，但奇边长正方形的像素使用自身色掩码，偶边长正方形的像素使用全填充块，中心标注像素使用十字掩码。

**输入结构**：一个 4x4 或 5x5 的小网格。网格中包含 2~3 个不同颜色的实心正方形（边长 1~3，颜色从蓝(1)、红(2)、绿(3)中选取，互不相同），其余位置为黑(0)背景。正方形之间不重叠不相邻。生成约束：至少一个奇边长（1 或 3）和一个偶边长（2）的正方形。黄(4)不出现在输入中，保留作为标注色。

**规则**：
1. 识别每个实心正方形及其边长。
2. 对边长为奇数的正方形，将其中心像素颜色改为黄(4)作为标注。边长为 1 的正方形只有一个像素，即中心，也标注为黄(4)。偶边长正方形不做标注。
3. 将标注后的网格进行像素放大：输入每个像素扩展为一个与输入网格同尺寸的块（输入为 NxM 则每个块也是 NxM），输出网格为 (N*N)x(M*M)。
4. 块内容规则按像素所属类别分三种情况：
   - 属于偶边长正方形的像素（颜色 c）：块内所有位置都填充为 c（实心块）。
   - 属于奇边长正方形的非中心像素（颜色 c）：块内仅在标注后输入中颜色也为 c 的位置填充 c，其余为黑(0)（自身色掩码）。
   - 中心标注像素（黄(4)）：块内仅在标注后输入中颜色为黄(4)的位置（即所有被标注的中心位置）填充黄(4)，其余为黑(0)（黄色掩码）。
5. 黑(0)背景像素的块全部为黑(0)。

**关键洞察**：同一张输入网格被同时用作放大对象和掩码模板，但不同类别的像素读取掩码的方式不同——偶边长正方形的像素忽略掩码直接全填充，奇边长正方形的像素按自身色选掩码，中心标注像素按标注色选掩码。三种放大方式共存于同一输出中，需要对比多个示例才能区分这三条规则。
