## 新题 4：对角滑动后形状等价检测与条件变色

**组合逻辑**：[平移/对角固定步移](创新：滑动不是一步而是滑到边界) + [旋转翻转等价](创新：不用于建表，而是作为滑动后对象间的关系判据) + [重涂色](创新：变色条件是后验的空间邻接+形状等价的合取)

**来源原语**：平移/角位指示方向/对角固定步移(470c91de), 控制像素(470c91de), 旋转翻转等价/形状匹配(6165ea8f), 重涂色(多题), 抵达边界(99caaf76)

**依赖链**：识别控制像素角位 → 对角滑动至边界 → 滑动后检测邻接对 → 对邻接对做形状等价判定 → 等价对变色/非等价对保持。删除滑动则对象位置不变、邻接关系不同；删除等价判定则无法区分变色对象；删除控制像素则无法确定滑动方向。

每个精灵体沿控制像素指示的对角方向滑到网格边界，滑动后彼此邻接的精灵体若形状旋转翻转等价则重涂为红色。

**输入结构**：约 15x15 的网格，背景为黑(0)。网格中有 4~6 个小型 4-连通单色精灵体（每个 3~6 像素，形状不规则但各自紧致在 3x3 包围框内，颜色从蓝(1)、绿(3)、黄(4)、品红(6)、橙(7)中选取，各精灵体颜色互不相同）。每个精灵体恰好有一个像素被替换为青(8)作为控制像素，该控制像素位于精灵体包围框的四个角之一。精灵体初始分布在网格中部区域，彼此不相邻。生成约束：每个精灵体沿其控制像素所在角的对角方向滑到边界后，至少有一对精灵体的包围框 8-邻接（包围框之间无间隔或仅隔 1 行/列）；至少存在一对邻接且形状等价的精灵体和一对邻接但形状不等价的精灵体。

**规则**：
1. 识别每个精灵体及其青(8)控制像素。将控制像素视为精灵体的一部分，其原本颜色视同精灵体颜色。
2. 确定控制像素在精灵体 3x3 包围框中的角位：左上 → 向左上滑，右上 → 向右上滑，左下 → 向左下滑，右下 → 向右下滑。
3. 擦除所有精灵体的原位置为黑(0)。
4. 沿确定的对角方向逐步平移精灵体（包含控制像素位置），直到精灵体包围框的某条边触及网格边界。按各精灵体到边界的距离从近到远依次放置（距离相同则按精灵体包围框左上角行优先、列次之排序），先放置的占据位置，后放置的若冲突则停在冲突前一格。
5. 所有精灵体放置完毕后，检查每对精灵体是否 8-邻接（两者包围框之间在水平或垂直方向存在相邻或重叠的行/列区间，且最近像素的切比雪夫距离 <= 1）。
6. 对每对 8-邻接的精灵体，提取各自的归一化掩码（去除控制像素后的形状紧致掩码），判断是否在旋转(0/90/180/270度)或翻转(水平/垂直)下等价。
7. 若一对邻接精灵体形状等价，将两者所有像素（包括控制像素位置）重涂为红(2)。若不等价，保留各自原色。一个精灵体若与多个邻接精灵体中至少一个等价，即重涂为红(2)。
8. 控制像素在输出中不单独显示，已融入精灵体颜色（红(2)或原色）。

**关键洞察**：滑动终点由控制像素角位和网格边界共同决定，而形状等价判定发生在滑动之后——同一组精灵体在不同输入布局下可能因滑动后邻接关系不同而产生不同的变色结果。必须对比多个示例才能排除"按颜色变色"或"按面积变色"等错误假设。
