## 新题 7：射线-编织交叉着色

**组合逻辑**：[射线延伸/ray_extend]（已有原语）+ [编织填充/weave_fill]（创新：原题中编织由标记对定义的矩形区域内奇偶交替，此处编织图案由射线交叉自然产生），以 [触发点分束/trigger_splits_beam] 作为射线生成条件，[奇偶交替颜色/parity_alt_color] 作为交叉着色规则

**来源原语**：射线延伸、触发像素、触发点分束、对角对齐 ← db695cfb；编织填充、交叉条、奇偶交替颜色 ← f3e14006；连线 ← db695cfb；标记对定义跨度 ← f3e14006

**依赖链**：发射初始射线 → 触发像素将射线分束为垂直方向射线 → 初始射线与分束射线在网格上交叉形成网状结构 → 交叉点处根据经过的射线数量奇偶性决定着色（奇数次经过用射线色，偶数次经过用分束色）。删去分束则无交叉；删去奇偶着色则交叉点颜色不确定

从边界发射正交射线，触发像素将射线分束为垂直方向，射线交叉点处按经过次数的奇偶性交替着色形成编织图案

**输入结构**：
- 背景：黑(0)。网格约 18x18。
- 网格左边界和上边界各有 2-4 个蓝(1)发射器像素（位于边界行/列上）。左边界的发射器向右发射水平射线，上边界的发射器向下发射垂直射线。
- 网格内部散布 3-6 个品红(6)触发像素。每个触发像素恰好位于某条射线路径上（与某个发射器同行或同列）。
- 生成约束：每条射线路径上至少有 1 个触发像素。水平射线和垂直射线之间存在多个交叉点。触发像素不位于射线交叉点上。

**规则**：
1. 从每个发射器像素发射一条射线：左边界发射器向右发射水平射线，上边界发射器向下发射垂直射线。射线延伸至网格对侧边界。射线像素初始着蓝(1)色。
2. 每条射线经过触发像素时发生分束：在触发像素位置，向两个垂直于原射线的方向各发射一条新射线（水平射线的触发点发射上下两条垂直分束射线，垂直射线的触发点发射左右两条水平分束射线），新射线延伸至网格边界。分束射线着品红(6)色。触发像素本身保留品红(6)。
3. 处理所有交叉点（两条射线路径共享的像素）：统计经过该像素的射线总数 N。
   - N 为奇数：该像素着蓝(1)（初始射线色）。
   - N 为偶数且 N >= 2：该像素着品红(6)（分束色）。
4. 非交叉的射线像素保留其射线颜色（初始射线为蓝(1)，分束射线为品红(6)）。
5. 发射器像素保留蓝(1)。背景和不在任何射线路径上的位置保持黑(0)。

**关键洞察**：编织图案不是预先定义的，而是从射线交叉中涌现——触发像素的位置决定了分束射线的方向，进而决定了交叉点的分布和奇偶性，最终产生非规则的编织纹理。
