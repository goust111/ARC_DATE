## 新题 5：参考像素条件分叉变换

**组合逻辑**：[反转/invert] + [滑动/slide]（已有原语，创新：两个操作不是串联执行，而是由条件判断在每一行中二选一）+ [对齐比较/aligned_comparison]（创新：原题中比较决定像素的移动方向，此处比较决定整行执行哪种操作），以 [逐行独立/row_independent] + [颜色匹配定去向/color_match_dest] 作为条件框架

**来源原语**：反转、逐行独立、主色与背景互换、主色像素、干扰色像素 ← 2de01db2；滑动 ← f0100645；对齐比较、颜色匹配定去向、分隔线、参考像素、源像素 ← 7d7772cc；碰撞停止 ← f0100645

**依赖链**：分隔线将网格分为参考区和操作区 → 逐行将参考像素与操作区该行的主色比较 → 匹配时对该行执行反转（主色与背景互换）→ 不匹配时将该行非背景像素向分隔线滑动压缩 → 分叉条件和两种操作缺一不可

逐行对比参考像素与操作区主色：匹配则反转该行，不匹配则将该行内容向分隔线滑动压缩

**输入结构**：
- 背景：黑(0)。网格约 15x20（15行20列）。
- 一条垂直灰(5)分隔线位于约第 4 列，从顶到底贯通。
- 分隔线左侧（第 0-3 列）为参考区：每行在第 2 列有一个彩色参考像素（从红(2)、蓝(1)、绿(3)、黄(4)中取值），其余位置为黑(0)背景。不同行的参考像素颜色可能相同或不同。
- 分隔线右侧（第 5 列至最右列）为操作区：每行包含一个由 3-8 个像素组成的彩色图案。每行的主色（该行中出现次数最多的非黑颜色）唯一确定。部分行中混有 1-2 个其他颜色的干扰像素。
- 生成约束：每行操作区的主色与参考像素颜色的匹配/不匹配大致各半。操作区中每行的非背景像素不接触分隔线（至少间隔 1 列背景）。

**规则**：
1. 对每行独立处理。确定该行操作区的主色：该行第 5 列到最右列中出现次数最多的非黑颜色；若有多色并列，取最靠左首次出现的颜色。
2. 将该行参考像素颜色与操作区主色比较：
   - **匹配**：对该行操作区执行反转——主色像素变为黑(0)，操作区中所有黑(0)像素和干扰色像素统一变为主色。
   - **不匹配**：将该行操作区中所有非黑像素（保持各自颜色不变）整体向左滑动，直到最左侧的非黑像素紧贴分隔线右侧（第 5 列）。像素之间的相对位置保持不变，原位置空出的部分填充为黑(0)。
3. 参考区和分隔线保持不变。

**关键洞察**：参考像素不仅是颜色标签，它实质上是一个逐行的操作选择器——同一个网格中不同行执行完全不同的变换，这个分叉决策只能通过对比多个示例中参考色与主色的匹配关系来归纳。

## 实现要求

1. `main(grid)` 必须实现新题描述中的确定性转换规则，不能只识别 `generate_input()` 的固定模板。禁止不同的input网格输出相同的output网格。

3. 生成器必须保证输入满足 `main()` 的隐式假设：对象不重叠、不越界、特殊标记唯一或可区分、匹配关系无歧义、关键分支出现概率相同。
4. 禁止把 ARC 颜色 id 、亮度、拼写等当作人类不可见的数值语义参与排序、大小比较或隐藏映射。颜色变化必须有可见结构线索。注意颜色亮度、拼写等也是不可见信息，若描述中出现违规的颜色id或者亮度，可自行使用少量的固定颜色替代，但注意生成时要在三个以内输入输出网格中对所有变换100%覆盖度。

6. 若规则有多个分支，生成器不能长期固定成一个分支；应让分支在随机样例中合理出现。分支概率不必平均——难以发现的隐蔽分支（如少数情况下才触发的特殊规则）应适当提高出现概率，确保在 3 个训练示例中至少出现一次，否则求解者无法归纳该规则。对于颜色映射类规则，确保 2 个左右的示例即可覆盖所有映射关系（每种颜色→颜色的映射至少在某个示例中出现过）。
