## 新题 4：空间环序驱动的分割-换色-对角拼合

**组合逻辑**：[分割 split](已有) + [重涂色 recolor](创新：换色目标由空间环形顺序决定，非固定交换) + [对角邻接拼合 diagonal_adj_join](已有) + 空间环序推断（新关系：对象的空间位置隐式编码颜色流转方向）

**来源原语**：分割 split / 对角邻接拼合 diagonal_adj_join / 颜色互换且偏移 color_swap_offset / 双色物体 bicolor_object（参考题 fc4aaf52）、重涂色 recolor（参考题 de809cff）、环形周期 cyclic_period（参考题 30f42897）

**依赖链**：空间位置分析 → 环形顺序推断 → 各对象的"下一位"确定 → 分割 → 上半部换色为下一位对象的调色板 → 对角偏移拼合。环序推断是换色的决策节点：不知道顺序就不知道谁的颜色流向谁。

将环形排列的双色矩形对象各自水平分割，上半部采用环序中下一个对象的配色后对角拼回。

**输入结构**：约 20x20 黑(0)背景网格。4 个小矩形对象（各约 4x6 至 6x8 像素，偶数高度），分别位于网格的四个象限区域（左上、右上、右下、左下），彼此不相邻。每个对象使用两种前景色：一种为底色（占多数像素），一种为图案色（占少数像素，形成一个 4 连通的不规则小图形，3-6 像素）。四个对象共使用 8 种不同的前景色（即无颜色复用）。各示例中，4 个对象在网格中的精确位置不同，但始终各占一个象限。

**规则**：
1. 计算每个对象的边界框中心坐标，以网格中心为原点计算其极角（arctan2），按极角从小到大排列得到顺时针环形序列：对象 A → B → C → D → A。
2. 对每个对象，沿其边界框的水平中线将其分为上半部和下半部。
3. 对每个对象的上半部执行换色：将其底色替换为环序中下一位对象的底色，将其图案色替换为下一位对象的图案色。下半部保持原色不变。
4. 将换色后的上半部向右滑动，直到上半部的左下角像素与下半部的右上角像素呈对角相邻（即上半部左下角在下半部右上角的右上方一格）。
5. 输出中，上半部和下半部之间可能出现的间隙保持为背景色。

**关键洞察**：颜色流转方向（谁的上半部取谁的调色板）由对象在网格中的空间位置隐式编码为顺时针环序，而非由颜色本身或对象大小决定。仅凭一个示例可能把环序误判为逆时针或按行列顺序，需要多示例对比才能确定是极角排序的顺时针方向。
