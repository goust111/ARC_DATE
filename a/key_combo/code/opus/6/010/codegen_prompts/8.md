## 新题 8：射线连接与级联染色

**组合逻辑**：[射线延伸 ray_cast](创新：射线不用于擦除而用于建立精灵间的连接) + [连线 connect](创新：连线端点由射线命中决定而非预定义) + [重涂色 recolor](创新：染色沿射线命中链级联传播) + 处理顺序依赖（新关系：射线长度决定处理顺序，先处理的染色影响后处理的颜色）

**来源原语**：射线延伸 ray_cast / 反向投射 opposite_direction / 首个障碍 first_obstacle（参考题 9f8de559）、连线 connect / 端点对应 endpoint_match / 颜色角色互换 color_role_swap（参考题 c6141b15）、重涂色 recolor（参考题 de809cff）、精灵体 sprite / 尾刺 tail_spike（参考题 3dc255db）

**依赖链**：尾刺方向读取 → 射线发射与命中检测 → 射线长度排序确定处理顺序 → 逐个连线 + 命中目标染色 → 被染色后的精灵以新颜色参与后续连线。处理顺序创造了级联效应：A 染了 B 的色，B 再以新色去染 C、画连线。

每个精灵沿尾刺方向射出射线命中另一精灵并将其染为自己的颜色，按射线长度从短到长依次处理，被染色的精灵以新颜色继续参与后续射线。

**输入结构**：约 18x18 黑(0)背景网格。4-5 个小型单色精灵体（各为 4 连通的不规则图形，3-5 像素，各精灵颜色互不相同，使用如红(2)、蓝(1)、绿(3)、黄(4)、灰(5)中的颜色）。每个精灵有一个 1 像素的尾刺从其边界向外突出（尾刺颜色与精灵主体相同）。尾刺的朝外方向即为该精灵的射线发射方向。生成约束：从每个精灵的尾刺沿发射方向射出的射线恰好命中另一个精灵的主体像素（不会射向空旷区域或射出网格边界）；各射线长度（尾刺尖端到命中像素的曼哈顿距离）互不相同；不存在两个精灵互相命中对方的情况（即射线命中图构成一棵有向树或森林，无环）。

**规则**：
1. 对每个精灵，识别其尾刺像素及其朝外方向（尾刺与精灵主体相邻的方向的反方向）。
2. 从每个尾刺的尖端出发，沿发射方向逐像素延伸射线，直到遇到第一个非背景像素（该像素属于另一个精灵的主体）。记录射线长度（经过的背景像素数 + 1）和命中的目标精灵。
3. 按射线长度从短到长对所有精灵排序，确定处理顺序。
4. 按顺序逐个处理每个精灵：
   a. 用该精灵当前颜色画一条连线，从其尾刺尖端沿发射方向直到命中目标的像素位置（含两端点，连线颜色 = 发射精灵当前颜色）。
   b. 将命中目标精灵的所有像素（含其尾刺）重涂为发射精灵的当前颜色。
5. 所有精灵处理完毕后，输出最终网格。精灵主体、尾刺、连线均保留。

**关键洞察**：由于按射线长度排序处理，先被染色的精灵在后续步骤中以新颜色发射射线和画连线。最终颜色分布取决于处理链的拓扑结构——一条长级联链（A→B→C→D）会让 A 的颜色传播到所有下游精灵。仅凭射线命中关系无法确定最终颜色，必须考虑处理顺序带来的级联效应。
