## 新题 3：缺角三角形充当区域填充模板

**组合逻辑**：[缺角定位](创新：缺角形状用作填充模板而非连线) + [形状匹配/缩放对应] + [填充]

**来源原语**：标记像素(1478ab18)、包围方块(1478ab18)、缺角定位(1478ab18)、缺角为直角顶点(1478ab18)、直角三角形(1478ab18)、形状匹配(898e7135)、缩放对应(898e7135)、封闭区域(88e364bc)、填充(aaef0977)、重涂色(aaef0977)、擦除(52364a65)

**依赖链**：三个同色标记点的缺角位置 → 确定直角三角形的朝向 → 三角形作为二值模板 → 按边界框边长与封闭矩形区域尺寸匹配 → 模板内像素填充为标记颜色

从标记点方阵的缺角推断三角形朝向，将该三角形作为模板填充到尺寸匹配的矩形区域内。

**输入结构**：网格约 20×20，背景黑(0)。网格中有若干组标记点（每组 3 个同色像素），每组使用不同颜色（如红(2)、绿(3)、蓝(1)等，共 2~4 组）。每组 3 个像素恰好占据一个正方形边界框（边长 S，S 在 3~6 之间）的三个角位置，第四个角为背景色（即缺角）。此外网格中有若干个灰(5)色轴对齐矩形框（由灰色像素围成的 1 像素宽矩形边框，内部为背景色），每个框的内部空间为正方形且边长等于某组标记点的边界框边长 S。标记点组数与矩形框数量相同。生成约束：不同标记组的边界框不重叠且不与矩形框重叠；每组标记点的边界框边长唯一（无两组边长相同）；矩形框内部为空（纯背景色）。

**规则**：
1. 对每组同色标记点，确定其 S×S 边界框中缺失的角位置（左上/右上/左下/右下）。
2. 根据缺角构造一个 S×S 的直角三角形二值模板：缺角位置为直角顶点，两条直角边沿边界框的两条边延伸，斜边连接另外两个有标记的角。模板中三角形区域内的像素（从直角顶点出发，第 i 行含 i+1 个或 S-i 个像素，取决于朝向，使整体构成一个填满半个正方形的阶梯形三角区域）标记为"填充"，其余标记为"背景"。具体地：若缺角在左上，则第 r 行（从 0 开始）的填充像素为列 0 到列 r（含），构成左上→右下的三角形。若缺角在右上，则第 r 行的填充像素为列 (S-1-r) 到列 (S-1)。若缺角在左下，则第 r 行的填充像素为列 0 到列 (S-1-r)。若缺角在右下，则第 r 行的填充像素为列 r 到列 (S-1)。
3. 将每组标记点与内部边长相同的灰色矩形框配对（唯一匹配）。
4. 在每个配对的矩形框内部，按三角形模板填充：模板中"填充"位置的像素涂为对应标记组的颜色，"背景"位置保持黑(0)。模板左上角对齐矩形框内部空间的左上角。
5. 标记点像素在输出中擦除为背景色。灰色矩形框边框保留不变。

**关键洞察**：三个标记点的"缺角"不是用来画线（如源题 1478ab18），而是定义一个三角形的朝向——几何推理的结果被重新用作另一个区域的空间填充模板，配对关系则由尺寸而非颜色决定。
