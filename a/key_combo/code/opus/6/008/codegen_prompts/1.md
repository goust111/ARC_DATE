## 新题 1：形状普查同心构建器

**组合逻辑**：[translate_normalize](已有) → [same_shape → marker_grouping](创新：平移归一化后按形状分组，标记色标识组别) → [count](已有，但作用对象变为"组内实例数") → [nested_wrapping](已有，但厚度来源于计数而非色条高度) → [recolor](已有)

**来源原语**：translate_normalize、same_shape（ad38a9d0）；count（aaecdb9a）；nested_wrapping、layer_by_layer_build、concentric_square_frame（45a5af55）；recolor（多题）

**依赖链**：平移归一化确定形状等价类 → 等价类决定分组和标记色 → 组内计数决定同心框每层厚度 → 各组成员的空间位置决定层的排列顺序 → 最终构建同心正方形结构

将散布的小图形按形状分组，用各组实例数量作为层厚构建同心正方形框架，层序由空间位置决定。

**输入结构**：约 20x20 网格，背景黑(0)。散布 8-15 个小型 4-连通单色图形，主体为灰(5)，每个 3-6 像素。每个图形中恰好有一个像素被替换为非灰色标记色（从红(2)、蓝(1)、绿(3)、黄(4)中取）。拥有相同平移归一化掩码（含标记像素相对位置）的图形总是共享相同的标记色。共有 3-5 个不同的形状组，每组 1-4 个实例。各图形互不相邻，且不触碰网格边界。生成约束：不同形状组的标记色两两不同；同组内图形可能位于网格任意位置。

**规则**：
1. 对每个灰色图形做平移归一化（将边界框左上角对齐到原点），得到归一化掩码（含标记像素在掩码中的相对坐标）。
2. 将归一化掩码完全相同的图形归为一组，每组的标识色即为其标记色。
3. 对每组计算实例数量 C。
4. 对各组按以下方式排序：取该组中所有成员的边界框左上角，找行号最小的那个（若行号相同取列号最小的），以此作为该组的排序键，按行优先、列其次升序排列。
5. 构建同心正方形框架：排序第一的组形成中心实心正方形，边长 = 该组的实例计数 C，颜色 = 该组标记色。排序第二的组在中心外围包裹一层正方形框，框厚度 = 该组 C，颜色 = 该组标记色。依此类推逐层向外包裹。
6. 输出：仅包含该同心正方形结构的最小边界框（背景为黑(0)），结构居中。

**关键洞察**：形状恒等性决定分组，空间位置决定层序，实例计数决定层厚——三个逻辑上独立的属性共同约束输出，缺少任何一个都无法唯一确定结果。
