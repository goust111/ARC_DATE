## 新题 3：压缩后象限旋转

**组合逻辑**：[compress/compact_to_anchor](已有) → [rotate/quadrant_rotation](已有，但旋转对象是压缩后的象限内容而非原始网格)

**来源原语**：compress、compact_to_anchor、anchor_block、ray_pixel、ray_belongs_anchor（f28a3cbb）；rotate、tile、quadrant_rotation、quadrant（cf5fd0ad）

**依赖链**：散布像素沿视线压缩至锚块 → 压缩结果改变各象限的空间内容 → 象限旋转对压缩后的臂结构施加几何变换 → 四象限旋转后涌现出向心对称图案

将四个象限中散布的射线像素压缩到各自锚块后，对每个象限施加不同角度的旋转，使外指的压缩臂变为向心对称图案。

**输入结构**：16x16 网格，背景黑(0)。网格被等分为 4 个 8x8 象限。每个象限包含恰好一个 3x3 实心锚块，颜色分别为红(2)、蓝(1)、绿(3)、黄(4)（每象限一个唯一颜色），锚块中心位于该象限的中心位置（即距象限边界各 2-3 像素）。每个锚块有 2-5 个同色散布像素，分别位于从锚块出发的行、列或对角线视线上（同一视线上可有多个），均在同一象限内且不触碰象限边界。生成约束：每个锚块至少有两个不同方向的散布像素。

**规则**：
1. 对每个锚块，将其所有同色散布像素沿各自视线（行/列/对角线）向锚块方向滑动，直到紧贴锚块边缘或紧贴另一个已滑动到位的同色像素。原始散布位置清除为背景。
2. 压缩完成后，对每个象限独立施加旋转：左上象限旋转 180 度，右上象限顺时针旋转 90 度，左下象限逆时针旋转 90 度，右下象限不旋转（0 度）。旋转以象限中心为中心。
3. 输出：16x16 网格，各象限内容为压缩 + 旋转后的结果。

**关键洞察**：压缩将散布像素聚拢为方向性的"臂"结构（如从锚块向右和向下各伸出几个像素）。这些臂的朝向在压缩阶段看似随意，但经过特定的象限旋转后，原本朝外的臂统一转向网格中心，四个锚块的臂形成一个向心对称图案——这种涌现效应只有压缩和旋转联合才能产生。
