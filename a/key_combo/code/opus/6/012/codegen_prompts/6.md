## 新题 6：嵌入修补计数驱动的边框方向位移

**组合逻辑**：[修补](已有：嵌入标记回填为主体色) + [平移 × 颜色匹配边](创新：孤立标记的位移方向由边框边颜色匹配决定，而非由边缘线方向决定) + [计数](创新：嵌入标记的修补总数编码孤立标记的位移距离)

**来源原语**：修补(repair) ← 8886d717; 嵌入与孤立(embedded_vs_isolated) ← 8886d717; 主体对象(main_object) ← 8886d717; 标记像素(marker_pixel) ← 8886d717; 平移(translate) ← 342dd610; 颜色匹配边(color_match_side) ← 5034a0b5; 边框边(frame_side) ← 5034a0b5; 朝匹配边移动(move_toward_match) ← 5034a0b5

**依赖链**：分类标记为嵌入/孤立 → 嵌入标记被修补并计数 N → 孤立标记颜色匹配边框某侧 → 朝该侧平移 N 格。修补和计数是一个操作的两个产出；N 同时作为平移距离使用。删除修补则无法得到 N，删除匹配则无法确定方向。两条逻辑线在"N"处交汇。

嵌入标记被修补为主体色，修补数量成为孤立标记向其颜色匹配的边框边方向位移的距离。

**输入结构**：约 14x14 的网格。一个单像素宽的矩形边框占据网格边缘，四条边颜色各不相同：顶边蓝(1)、底边绿(3)、左边黄(4)、右边红(2)，四角为黑(0)背景。边框内部（中心约 12x12 区域）背景黑(0)，其中有一个橙(7)的 4-连通主体对象（15~25 像素，不规则形状）。主体对象内嵌入了 1~3 个标记像素，颜色为灰(5)，每个标记至少 3 个 4-邻居为橙(7)。主体对象外的背景区域散布 2~4 个孤立灰(5)标记像素（不与主体对象 4-邻接），每个孤立标记的颜色为灰(5)，但在该标记正上方/下方/左方/右方的边框边上有一个特殊的品红(6)提示像素，替代了该位置原本的边框颜色。生成约束：每个孤立标记恰好对应一个品红提示像素，且该提示像素所在的边框边的原始颜色唯一确定一个方向。

**规则**：
1. 识别主体对象（橙(7)的最大 4-连通分量）。
2. 分类灰(5)像素：若至少 3 个 4-邻居为橙(7)则为"嵌入标记"，否则为"孤立标记"。
3. 将所有嵌入标记重涂为橙(7)（修补），记修补总数为 N。
4. 对每个孤立标记，找到与之同行或同列的品红(6)边框提示像素。该提示像素所在的边确定方向（顶边→向上，底边→向下，左边→向左，右边→向右）。
5. 将每个孤立标记沿该方向平移 N 格。若平移后超出边框内部区域则停在边框内侧。
6. 将品红(6)提示像素恢复为其所在边框边的原始颜色。

**关键洞察**：修补嵌入标记不仅是修复操作，其数量还隐式编码了另一组标记的位移距离——两个看似独立的标记群通过"修补计数=位移步数"这一隐藏关系绑定在一起。
