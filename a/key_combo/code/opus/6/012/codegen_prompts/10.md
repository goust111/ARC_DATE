## 新题 10：相对方位定位后的偏移复制阴影

**组合逻辑**：[定位 × 相对方位](创新：控制像素不再选择 3x3 内部的单个槽位，而是选择目标区域中的一个子图形) + [偏移复制](创新：被选中的子图形的相对位移被当作阴影偏移量，应用于整个目标区域)

**来源原语**：定位(locate) ← 18286ef8; 相对方位(relative_position) ← 18286ef8; 方位决定槽位(position_selects_slot) ← 18286ef8; 控制像素(control_pixel) ← 18286ef8; 目标区域(target_region) ← 18286ef8; 偏移复制(offset_copy) ← 35ab12c3; 阴影像素(shadow_pixel) ← 35ab12c3

**依赖链**：控制像素的相对方位 → 选择目标区域中的子图形 → 子图形相对于区域中心的偏移量 → 整个目标区域沿该偏移量做阴影复制。方位选择决定了偏移量的值，偏移量决定了阴影位置——两步之间信息发生了形态转换（从空间索引变为向量），不是简单传递。

控制像素的相对方位选出目标区域中的一个子图形，该子图形相对于区域中心的位移向量成为整个区域的阴影偏移。

**输入结构**：约 15x15 的网格，背景黑(0)。网格中有一个约 7x7 的目标区域，由灰(5)像素构成一个 3x3 的大格子结构（每格约 2x2 像素，格间有 1 像素间隔），共 9 个格子排列成 3x3。其中一个格子的像素被涂为红(2)（"选中标记"），其余 8 格为灰(5)。目标区域外有恰好一个品红(6)的控制像素。生成约束：控制像素与目标区域不在同一行也不在同一列（即相对方位不会落在"同行/同列"的歧义情况）；目标区域整体偏移后不超出网格。

**规则**：
1. 定位目标区域（灰(5)和红(2)像素的联合 bbox）和控制像素（品红(6)）。
2. 判断控制像素相对于目标区域 bbox 中心的方位：行方向（上/中/下）和列方向（左/中/右），组合成九宫格方位之一（如"左上"、"右下"等）。
3. 该方位对应目标区域 3x3 格子中的一个格子位置（左上=第0行第0列，右下=第2行第2列）。
4. 计算被选中格子的中心像素相对于整个目标区域中心像素的偏移向量 (dr, dc)。
5. 将控制像素重涂为红(2)。
6. 将整个目标区域沿 (dr, dc) 偏移复制一份作为"阴影"：阴影像素只画在背景像素上（不覆盖已有非背景像素），阴影颜色为青(8)。
7. 原始目标区域保持不变。红色选中格保持红色。

**关键洞察**：控制像素既不移动也不重涂目标——它的方位信息被"翻译"成目标区域内的一个几何位移向量，该向量又驱动了一个完全不同的操作（阴影复制）。信息的表征形式跨越了两次转换：空间方位 → 格子索引 → 位移向量 → 阴影位置。
