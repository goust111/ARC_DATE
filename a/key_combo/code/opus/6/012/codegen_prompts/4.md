## 新题 4：宽度决定穿透的标记推移与邻接传色

**组合逻辑**：[推移](已有) + [重力下落 × 穿透与停靠](创新：穿透/停靠逻辑不再是纯重力，而是由固定标记驱动的水平推移中遇到分隔墙时的行为) + [重涂色 × 邻接传色](创新：推移完成后精灵的新邻居决定其最终颜色)

**来源原语**：推移(push) ← 5623160b; 接触侧决定方向(contact_side_dir) ← 5623160b; 穿透与停靠(pass_through_or_stop) ← 84ba50d3; 宽度决定行为(width_determines_behavior) ← 84ba50d3; 分隔墙线(separator_wall) ← 3bd292e8; 邻接传色(adjacency_color_transfer) ← 800d221b; 固定标记(fixed_marker) ← 5623160b

**依赖链**：标记接触侧 → 推移方向 → 精灵宽度决定是否穿透分隔墙 → 最终停靠位置 → 邻接关系 → 传色。五步链中每一步的输入都依赖前一步的输出，且宽度判定与邻接传色形成非线性交互：穿透的精灵可能在墙另一侧遇到新邻居，从而继承完全不同的颜色。

精灵被固定标记沿接触方向推移，遇到分隔墙时窄精灵穿透、宽精灵停靠，最终位置的邻居颜色决定精灵的重涂色。

**输入结构**：约 16x20 的网格，背景黑(0)。一条红(2)垂直分隔墙（宽 1 像素）将网格分为左右两半。左半和右半各有 2~3 个 4-连通单色精灵（颜色取自蓝(1)、绿(3)、黄(4)、灰(5)、品红(6)），每个精灵 4~10 像素。每个精灵恰好在一个基数方向上 4-邻接一个栗(9)固定标记像素（标记位于精灵的左、右、上或下侧）。分隔墙两侧底部各有一个 2x2 的单色"锚块"（橙(7)或青(8)），锚块不移动。生成约束：精灵的推移方向至少有一个朝向分隔墙；每个精灵在推移方向上的"宽度"（垂直于推移方向的跨度）要么为 1 像素，要么 >=2 像素；推移路径上除分隔墙外无其他障碍。

**规则**：
1. 保留所有栗(9)标记像素和红(2)分隔墙像素不变。
2. 确定每个精灵的推移方向：从精灵中心指向远离标记的方向（标记在左则向右推，依此类推）。
3. 计算每个精灵在垂直于推移方向上的跨度 w。
4. 将每个精灵沿推移方向平移：
   - 若路径上遇到分隔墙且 w = 1：精灵穿透分隔墙（删除墙上对应的 1 个像素），继续前进直到碰到网格边界或锚块而停止。
   - 若路径上遇到分隔墙且 w >= 2：精灵在分隔墙前一格停靠。
   - 若路径上无分隔墙：精灵前进直到碰到网格边界或锚块而停止。
   - 处理顺序：离分隔墙近的精灵先处理。
5. 所有精灵停靠后，对每个精灵检查其是否有 4-邻接的非背景、非标记、非墙的邻居块（其他精灵或锚块）。若有，将该精灵整体重涂为面积最大的邻居的颜色；若有多个面积相同的最大邻居，取行坐标最小者的颜色。若无邻居，保持原色。

**关键洞察**：宽度不仅决定精灵能否穿墙，还间接决定了精灵在墙的哪一侧停靠——这改变了它的邻居集合，从而改变了最终重涂色的结果。穿墙与否导致同一精灵可能继承完全不同的颜色。
