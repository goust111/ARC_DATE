## 新题 3：枢纽路径计数驱动的同心填充

**组合逻辑**：[flood_fill × 同心正方形层](创新：同心带的调色板不由标记深度定义，而由路径分支的邻接计数排序生成) + [计数](创新：路径分支对种子区域的邻接数编码调色板顺序) + [重涂色](已有：路径分支继承种子色)

**来源原语**：flood_fill ← 13e47133; 同心正方形层(concentric_square_layers) ← 13e47133; 距离决定调色板(distance_determines_palette) ← 13e47133; 路径网络(path_network) ← 800d221b; 中心枢纽(hub_square) ← 800d221b; 种子区域(seed_region) ← 800d221b; 邻接计数决定色(adjacency_count_determines_color) ← 800d221b; 连通分量计数(component_count) ← b0039139

**依赖链**：路径分支邻接种子区域的分支数 → 对种子颜色按分支数从少到多排序形成调色板 → 枢纽内部用该调色板做同心矩形带循环填充 → 路径分支本身重涂为其接触最多的种子颜色。分支计数同时驱动了两个不同操作（调色板排序和路径重涂），删除任一环节均无法确定输出。

路径网络的分支邻接计数生成调色板排序，再以此调色板对中心枢纽做同心矩形带循环填充，同时路径分支按邻接规则继承种子色。

**输入结构**：约 20x20 的网格，背景黑(0)。灰(5)像素构成一个薄型正交路径网络（线宽 1 像素），网络中心有一个 4x4 或 5x5 的灰(5)实心正方形枢纽。从枢纽向外延伸 3~5 条路径分支，每条分支末端或侧面 4-邻接一个 2x2~3x3 的单色种子区域。种子颜色取自蓝(1)、红(2)、绿(3)、黄(4)、品红(6)（各不相同）。不同种子区域可能有不同数量的路径分支与之邻接（1~3 条）。生成约束：每条路径分支恰好邻接一个种子区域；枢纽不直接邻接任何种子区域；种子区域之间不相邻。

**规则**：
1. 识别灰(5)的最大连通分量为路径网络。在网络中找到最大的全灰正方形作为枢纽，其余灰像素为路径分支像素。
2. 将路径分支分割为独立的 4-连通段（在枢纽边界处断开）。
3. 对每个种子区域，计算与之 4-邻接的路径分支段数，记为 count(seed)。
4. 按 count 从小到大对种子颜色排序，形成调色板 P = [c1, c2, ...]。若两个种子的 count 相同，按种子区域质心的行坐标从小到大排列。
5. 对枢纽内部每个像素计算其到枢纽边界的 Chebyshev 距离 d。将该像素涂为 P[d mod len(P)]。枢纽边界像素（d=0）涂为 P[0]。
6. 每条路径分支段重涂为其 4-邻接的那个种子区域的颜色。
7. 种子区域本身保持不变。

**关键洞察**：路径拓扑（每个种子被多少分支触碰）不是视觉元素，而是隐式编码了枢纽同心填充的调色板排列顺序——必须对比多个示例才能发现分支计数与调色板排序之间的对应关系。
