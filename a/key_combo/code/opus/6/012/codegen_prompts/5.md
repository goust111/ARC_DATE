## 新题 5：极角描边与二部图交替着色

**组合逻辑**：[描边连线](已有) + [flood_fill × 交替着色](创新：连线围成的闭合区域不做简单填充，而是根据区域邻接图的二部图性质交替上色) + [忽略干扰项](创新：干扰点的判据不是模板匹配，而是能否参与形成有效闭合多边形)

**来源原语**：描边连线(outline_tracing) ← 35ab12c3; 极角排序(polar_angle_ordering) ← 35ab12c3; 忽略干扰项(ignore_distractors) ← 35ab12c3/652646ff; 二部图结构(bipartite_structure) ← 3bd292e8; 交替着色(alternating_coloring) ← 3bd292e8; 四邻接连通(four_neighbor_connect) ← 3bd292e8; flood_fill ← 13e47133

**依赖链**：极角排序 → 顶点连线形成闭合多边形 → 多边形围成的区域形成邻接图 → 二部图着色决定每个区域的填充色。干扰项识别依赖于能否形成有效闭合轮廓（几何约束），删除后无法正确建图；区域着色依赖于轮廓闭合（拓扑约束），删除后无区域可填。

同色顶点按极角连线围出闭合区域，这些区域按邻接关系做二部图交替着色，无法形成有效闭合轮廓的孤立点被忽略。

**输入结构**：约 18x18 的网格，背景黑(0)。网格中有 2~3 组颜色不同的顶点集合（蓝(1)、绿(3)、黄(4)），每组 3~5 个像素，散布在网格中。同组顶点按其质心的极角排序后，相邻顶点之间可以画水平、垂直或 45 度对角线段（路径上无非背景障碍），形成闭合多边形。另有 2~3 个"干扰"像素，颜色与某组顶点相同，但将其加入该组后无法形成全部边段都通畅的闭合多边形。网格右下角有两个相邻的色板像素：灰(5)和品红(6)，分别作为二部图着色的两种填充色。生成约束：每组有效顶点至少 3 个，形成的多边形互不交叉但可以嵌套或相邻（共享边或顶点）；所有多边形共同将网格划分为至少 3 个区域。

**规则**：
1. 对每组颜色，收集该色的所有像素。尝试按极角排序后连线：若加入某个像素后，形成的某条边段不是水平/垂直/45度，或边段内部有非背景像素阻挡，则该像素为干扰项，从集合中移除。重复直到剩余像素能形成有效闭合多边形。
2. 用每组的有效顶点按极角排序连线，绘制闭合多边形轮廓，线段颜色为该组顶点颜色。
3. 轮廓将网格分割为若干 4-连通区域。构建区域邻接图（两个区域若隔着轮廓线 4-邻接则相连）。
4. 对邻接图做二部图二着色。将包含网格 (0,0) 的外部区域标记为 A 类。A 类区域填充灰(5)，B 类区域填充品红(6)。
5. 轮廓像素保持其原有颜色不变。色板像素保持不变。干扰像素擦除为背景色。

**关键洞察**：干扰项不是随机噪声而是几何上"差一点可行"的顶点——必须通过尝试连线并检验路径通畅性来识别；轮廓的拓扑结构（而非颜色）决定了区域如何交替着色。
