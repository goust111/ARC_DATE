## 新题 2：互补形状的克罗内克印章

**组合逻辑**：[形状匹配](已有) + [印章覆盖 × 克罗内克积](创新：匹配的两个形状不是"源填入模板"，而是互为 Kronecker 乘积的两个因子) + [计数](创新：连通分量计数决定使用哪对调色板颜色)

**来源原语**：形状匹配(shape_match) ← 18447a8d; 互补形状(complementary_shape) ← 18447a8d; 克罗内克积(kronecker_product) ← c803e39c; 印章覆盖(stamp_overlay) ← c803e39c; 连通分量计数(component_count) ← b0039139; 面板提供调色板(panel_as_palette) ← c803e39c

**依赖链**：互补形状匹配确定配对 → 每对中较大形状做外层掩码、较小形状做内层图案(Kronecker) → 源形状的连通分量数选择调色板行 → 调色板颜色填入 Kronecker 结果。不做匹配不知道哪两个形状组合；不计数不知道用哪组颜色。

互补形状配对后，以较大者为外层布局、较小者为内层图案做 Kronecker 展开，展开所用的前景/背景色由源形状的连通分量数从调色板中选取。

**输入结构**：约 20x20 的网格，背景黑(0)。左半区有 2~3 个灰(5)模板矩形（每个约 4x4~5x5），每个模板内有一个由背景像素构成的不规则缺口（3~6 像素的 4-连通区域）。右半区有与缺口数量相同的独立小形状，每个形状由不同颜色绘制（蓝(1)、绿(3)、黄(4)等），形状像素数 3~6，可以是单连通或多连通（1~3 个 4-连通分量）。网格底部有一个调色板行：3 列，每列 2 个像素高，自左向右分别对应分量数 1、2、3，每列上方像素为前景色、下方像素为背景色（取自红(2)、品红(6)、橙(7)、青(8)、栗(9)的不同组合）。生成约束：每个右侧形状归一化后恰好与某个左侧缺口形状全等（唯一配对）；不同形状的连通分量数不完全相同以展示规则差异。

**规则**：
1. 将每个右侧形状归一化为相对坐标集合（平移使最小行列为 0），同样归一化每个左侧缺口形状。
2. 匹配：找到归一化形状完全相同的唯一配对（右侧形状 S 配左侧缺口 G）。
3. 计算每个右侧形状 S 的 4-连通分量数 k。
4. 从底部调色板第 k 列取前景色 Cf 和背景色 Cb。
5. 以缺口 G 的归一化形状为外层掩码、S 的归一化形状为内层图案，计算 Kronecker 积：外层掩码的每个前景像素替换为内层图案（前景色 Cf），外层掩码的每个背景像素替换为与内层图案等大的纯 Cb 块。
6. 将 Kronecker 积结果放置在对应模板缺口的位置（左上角对齐缺口 bbox 左上角），超出网格的部分截断。
7. 清除右侧原始形状像素为背景。调色板行保持不变。

**关键洞察**：互补形状在原题中是"源填入缺口"的简单嵌合；这里两个互补形状变成 Kronecker 乘积的两个因子，匹配关系同时决定了空间映射和代数运算的操作数。
