## 新题 9：侧边接触定色后位置图例填充

**组合逻辑**：[重涂色/recolor + 接触侧定色/contact_side_color](创新：接触侧确定的颜色不直接涂色，而是选择使用哪套位置图例) + [填充/fill + 位置对应颜色/position_to_color](创新：位置图例不唯一固定，而是多套图例由接触侧颜色索引)

**来源原语**：recolor, contact_side_color, multicolor_obj, side_marker, panel_region, contained_in (c3fa4749); fill, position_to_color, bordered_region, fixed_legend, fill_missing (a834deea)

**依赖链**：位置填充需要知道使用哪套图例 → 图例选择由面板区域的侧边标记颜色决定 → 侧边标记颜色检测需要识别"哪种颜色出现在对象触碰面板边界的那条边上" → 该检测结果不涂色（与参考题 c3fa4749 不同），而是索引到多套图例中的一套 → 然后按该图例的位置映射填充内部缺失位。接触侧定色和位置填充通过"颜色作为图例索引"这一语义桥梁耦合。

由对象触碰面板边界的侧边颜色选择对应的位置图例，再按图例填充对象内部的缺失位。

**输入结构**：约 18x18 的网格，背景为黑(0)。网格中有 2~3 个灰(5)面板区域（每个面板为 7x7 的实心灰正方形）。每个面板的 5x5 内部区域（去掉 1 像素厚的灰边框）包含一个 4-连通的前景对象（3~8 像素，颜色选自红(2)、蓝(1)、绿(3)中的某一种）。该对象恰好接触面板 5x5 内部区域的一条边（上、下、左或右），且对象在该边上的所有像素颜色一致（此颜色即为该对象的"侧边色"）。5x5 内部区域中，对象未覆盖的位置为黑(0)背景。网格的某个角落（如左下角）有一个颜色图例区，包含 2~3 套 3x3 的位置图例，每套图例的 9 个位置各有一个颜色编号（使用 ARC 颜色 1~9），不同图例的颜色分配不同。每套图例旁标有一个索引色像素（如红(2)像素旁放一套图例、蓝(1)像素旁放另一套），索引色像素为 1 个独立像素，4-邻接于对应图例的左侧或上侧。

生成约束：面板中对象的侧边色与某套图例的索引色相同；每种出现的侧边色恰好对应一套图例；不同面板中的对象可以有相同或不同的侧边色。

**规则**：
1. 对每个面板，识别其 5x5 内部区域中的前景对象，确定对象触碰内部边界的那条边，读取该边上的对象像素颜色作为"侧边色 S"。
2. 在图例区中，找到索引色等于 S 的那套 3x3 位置图例 L。
3. 将面板的 5x5 内部区域视为一个网格。对 5x5 中每个黑(0)背景位置 (r, c)（r, c 各从 0 到 4），查找位置图例 L 中对应位置 (r mod 3, c mod 3) 的颜色（当 5x5 大于 3x3 时，图例按周期平铺），如果该位置原本为黑(0)，则填充为图例颜色；如果该位置已被前景对象占据，保持不变。
4. 面板灰(5)边框保持不变。图例区保持不变。背景保持不变。

**关键洞察**：侧边颜色在本题中不用于"重涂对象"（与参考题 c3fa4749 不同），而用于"选择填充规则"——它是一个索引，指向多套位置图例中的某一套。同一颜色对象在不同面板中可能因位置不同而触碰不同边，但只要侧边色相同就使用同一图例。需要对比至少两个面板的输出才能确认"侧边色→图例"的映射关系，且需要排除"触碰哪条边→图例"这一干扰假说（因为不同面板中同色对象可能触碰不同边但使用相同图例）。
