## 新题 3：旋转后对角连接

**组合逻辑**：[旋转/rotate + 中心点不变/center_fixed](已有：每根条绕自身中心旋转 90 度) + [连线/connect + 对角偏移/diagonal_offset](创新：连接对象从"静态矩形对"变为"旋转后的条端点对"，连接的几何关系由旋转后的位置决定)

**来源原语**：rotate, thin_bar, center_fixed, orient_swap_keep (f0f8a26d); connect, same_color_rect_pair, diagonal_segment, diagonal_offset, diagonal_fill (342ae2ed)

**依赖链**：对角连接需要知道端点位置 → 端点位置取决于旋转后的条的位置 → 旋转改变了条的朝向和端点坐标 → 因此连接目标不是输入中可见的端点，而是必须先完成心算旋转才能确定的端点。旋转的输出是连接的输入前提，且两者作用于同一批对象（条既是旋转目标又是连接端点来源）。

将每根条绕中心旋转 90 度，然后用对角线段连接同色条对旋转后的最近对角端点。

**输入结构**：约 18x18 的网格，背景为黑(0)。网格中有 2~4 对单像素宽的前景条（4-连通，奇数长度 3~7 像素，水平或垂直放置）。每对条颜色相同，不同对颜色不同，使用红(2)、蓝(1)、绿(3)、黄(4)中的 2~4 种。同色的两根条在输入中不相邻、不共线。每根条的中心像素（奇数长度的正中像素）坐标确定。生成约束：每根条绕中心旋转 90 度后不超出网格边界；旋转后，同色两根条的端点中恰好存在一对端点具有对角偏移关系（即行差的绝对值等于列差的绝对值，且均不为 0）；旋转后不同条的像素不重叠；对角连接线段上的像素不与其他条或连接线段重叠。

**规则**：
1. 对每根条，保持其中心像素位置和长度不变，将朝向旋转 90 度（水平变垂直，垂直变水平）。擦除旋转前的像素，在新位置绘制旋转后的像素，颜色不变。
2. 对每对同色条（旋转后），找到具有对角偏移关系的那对端点（即两端点的行差绝对值等于列差绝对值）。
3. 在这对端点之间绘制 45 度对角线段（不含两个端点本身，因为端点已属于条），颜色与条相同。对角线段上的每个像素 (r, c) 满足 r 和 c 在两端点的 r 和 c 之间逐步各变化 1。
4. 各颜色独立处理，处理顺序不影响结果。

**关键洞察**：输入中同色条对的端点并不具有对角偏移关系——对角关系只在旋转之后才出现。求解者不能直接从输入几何中读出连接路径，必须先在心中完成所有条的旋转，然后才能判断哪些端点应被连接。单个示例中可能看到旋转和连接同时发生，但需要多个示例才能确认"先旋转再连接"的顺序，以及"对角偏移端点对"的选取标准。
