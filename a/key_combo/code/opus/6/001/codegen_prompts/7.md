## 新题 7：点对称选择裁剪目标并调色带重涂

**组合逻辑**：[点对称/point_symmetry + 绕中心点旋转对称/center_rotational](创新：点对称不用于"生成镜像副本"，而用于"检测哪个对象具有点对称性"作为选择条件) + [裁剪/crop](已有：裁剪选中对象) + [重涂色/recolor + 调色带指定列色/palette_assigns_color](已有：逐列用调色带颜色重涂)

**来源原语**：point_symmetry, center_rotational (e729b7be); crop (42f14c03, 278e5215); recolor, monochrome_mask, palette_strip, column_correspondence, palette_assigns_color (278e5215)

**依赖链**：调色带重涂需要知道作用于哪个对象 → 目标对象由点对称性检测选出 → 检测需要逐一测试每个前景对象是否绕自身几何中心具有 180 度旋转对称性 → 选出的对象被裁剪 → 裁剪结果被调色带逐列重涂。点对称性从"生成操作"变为"判别条件"，与裁剪和重涂形成三步耦合。

在多个前景对象中找到唯一具有 180 度旋转对称性的对象，裁剪其边界框，按调色带逐列重涂。

**输入结构**：约 20x20 的网格，背景为黑(0)。网格中有 3~5 个灰(5)4-连通前景对象（每个 8~20 像素，形状各异）。其中恰好 1 个对象具有 180 度旋转对称性（即绕其边界框中心旋转 180 度后与自身完全重合），其余对象不具有此对称性。网格底部或顶部有一个 1 行 W 列的调色带（W 等于对称对象边界框的宽度），调色带由 2~4 种颜色组成（选自红(2)、蓝(1)、绿(3)、黄(4)），每列一个颜色。调色带与所有前景对象不相邻（至少间隔 1 行）。生成约束：恰好 1 个对象具有 180 度旋转对称性；调色带宽度恰好等于该对象边界框宽度；其他对象的边界框宽度至少有一个与调色带宽度不同（提供额外线索，但不是充分条件）。

**规则**：
1. 对每个灰(5)前景对象，测试其是否具有 180 度旋转对称性：提取对象的边界框内的像素集，将非对象像素视为背景；将该像素集绕边界框中心旋转 180 度；若旋转后与原像素集完全重合则判定为对称。
2. 选择唯一的对称对象，裁剪其边界框（大小为 H x W）。
3. 读取调色带（1 x W），第 j 列的颜色记为 P[j]。
4. 在裁剪结果中，对每个灰(5)像素，将其颜色替换为该像素所在列 j 对应的调色带颜色 P[j]。背景（黑(0)）像素保持不变。
5. 输出为 H x W 的重涂后子网格。

**关键洞察**：点对称性在本题中不是一个操作（不生成镜像副本），而是一个筛选条件——用于从多个候选对象中选出唯一的裁剪目标。这与参考题 e729b7be 中"补全对称副本"的用法完全不同。单个示例中，求解者可能误以为选择标准是"面积最大"或"最接近调色带"，需要多个示例才能排除这些假说并确认对称性是真正的选择标准。
