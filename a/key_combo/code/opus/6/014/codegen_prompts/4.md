## 新题 4：切换射线破坏空心精灵体的填充资格

**组合逻辑**：[射线延伸(ray_extend) + 切换重涂(toggle_recolor)](保留) → [封闭区域(enclosed_region)](创新：射线可能破坏封闭性) → [填充(fill) + 边框色映射填充色(border_to_fill_mapping)](保留映射但条件受射线影响)

**来源原语**：射线延伸、切换重涂、控制像素、同列对齐、颜色匹配（981add89）；填充、封闭区域、调色板图例、编码映射、边框色映射填充色（dbff022c）；空心精灵体（dbff022c）

**依赖链**：控制像素发射切换射线→射线穿过空心精灵体时可能擦除边框像素→被擦破的精灵体不再形成封闭区域→调色板虽有映射但因封闭性丧失而无法填充。射线处理和填充判定之间存在因果依赖：不处理射线就无法知道哪些精灵体仍然封闭。

顶行控制像素向下发射切换射线，可能擦破空心精灵体边框；仅对射线处理后仍保持内部封闭的精灵体，用调色板图例映射的颜色填充。

**输入结构**：约 14x14 网格，黑(0)背景。3~4 个空心精灵体散布在网格中部和下部，每个精灵体是一个用单色边框围成的封闭区域（边框颜色各不相同，从蓝(1)、红(2)、绿(3)、黄(4)中选取；边框宽 1 像素；内部为黑(0)背景的矩形空洞，空洞至少 2x2）。网格右侧边缘有一个 2 列 N 行的调色板图例（N 等于精灵体数量）：左列为各边框色，右列为对应的填充色（如蓝(1)→橙(7)、红(2)→青(8)等）。顶行（第 0 行）有 1~2 个控制像素，颜色与某些精灵体的边框色相同。生成约束：至少一个控制像素的列与某个精灵体的边框像素所在列对齐（使得射线会穿过该边框），至少一个精灵体不被任何射线穿过边框。

**规则**：
1. 读取右侧边缘的调色板图例，建立边框色→填充色映射。
2. 对每个顶行控制像素，沿其所在列向下发射切换射线（从第 1 行到最后一行）：
   - 遇到与控制像素颜色相同的非背景像素→将该像素擦除为背景色（切换效果的"关"）。
   - 遇到其他非背景像素→将该像素涂为控制像素的颜色（切换效果的"开"）。
   - 控制像素本身保留。
3. 射线处理按控制像素从左到右的顺序执行（左列的控制像素先处理，其结果影响后续射线）。
4. 所有射线处理完毕后，检测每个精灵体的封闭性：对精灵体原始边框范围内的内部区域做 4-连通洪泛，若洪泛结果不触及网格边界且不触及边框外部的背景区域，则该精灵体仍然封闭。
5. 对仍然封闭的精灵体，用调色板映射的填充色填充其内部空洞。
6. 不再封闭的精灵体（边框被射线擦破）的内部保持背景色。
7. 最后将调色板图例区域清除为背景色。

**关键洞察**：调色板为所有精灵体都提供了填充映射，但切换射线可能擦除精灵体的边框像素（当射线颜色与边框色相同时发生切换"关"），破坏封闭性。一个精灵体是否被填充不取决于调色板中是否有它的条目，而取决于它是否在射线处理后仍保持封闭——这是源题(dbff022c)中不存在的条件门控。
