## 新题 1：对称轴约束下的线网双侧修复

**组合逻辑**：[镜像 + 沿轴反射](从单向反射改为双侧互补推断) + [间隙填充 + 端点朝向](从单侧修复改为受对称约束的双侧协同填充) + [补全 + 从平行行列推断](作为双侧均损情况的兜底策略)

**来源原语**：镜像/沿轴反射(ad3b40cf), 间隙填充/端点朝向(faa9f03d), 补全/从平行行列推断(b7955b3c), 对称轴(ad3b40cf), 线段网络(faa9f03d)

**依赖链**：对称轴确定反射映射关系 → 每个间隙需判断对侧是否完好来决定修复来源 → 双侧均损的间隙无法从对侧获得信息，必须转入沿行/列的局部推断 → 三种修复策略的选择本身依赖于全局对称结构的完整性分析

将一个沿对称轴两侧各有残损的线段网络修复为完整且关于轴完美对称的网络。

**输入结构**：约 15x15 网格，背景黑(0)。一整列灰(5)像素位于靠近中央的某一列，作为垂直对称轴。轴两侧分布着由红(2)和蓝(1)像素构成的水平/垂直线段网络，每条线段宽度为 1 像素。两侧的网络在完整状态下应关于灰轴完美对称，但当前各有若干间隙（线段中缺失的连续段落）。部分间隙仅出现在一侧（对侧对应位置完好），部分间隙在两侧的镜像位置同时出现。每条线段至少有一端可见（不会出现完全被间隙吞没的线段）。生成约束：不同线段的间隙互不重叠在同一行或同一列上，以保证局部推断的唯一性。

**规则**：
1. 输出网格必须满足：所有非灰、非黑像素关于灰(5)轴列完美镜像对称。灰轴列本身保持不变。
2. 对于仅在一侧存在的间隙：将对侧对应位置的完好线段反射到本侧，填充间隙。填充使用对侧像素的颜色。
3. 对于在两侧镜像位置同时存在的间隙（即双侧对应位置均为黑(0)背景）：沿该间隙所在的行（若为水平线段间隙）或列（若为垂直线段间隙），从间隙向两端扫描，取最先遇到的同方向完好线段的颜色来填充整个间隙。若两端颜色不同，取距间隙中心更近的那端的颜色；若等距，取轴侧（靠近灰轴的那端）的颜色。
4. 间隙填充不改变任何已有的非背景像素。处理顺序不影响结果，因为各间隙的修复信息来源互不依赖（由生成约束保证）。

**关键洞察**：这不是简单地将一侧镜像到另一侧——两侧各有独特的损伤，必须从对方获取互补信息；当双侧同时损伤时，对称约束失效，退化为局部行列推断，但推断结果仍须满足全局对称——这形成了一个约束满足问题而非线性流程。
