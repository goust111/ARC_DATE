## 新题 7：反对角线段接力与循环变色

**组合逻辑**：[平移绘制 + 长度递增 + 同反对角线](多段接力前进) ⊗ [循环迁移 + 重涂色](每次前进伴随颜色循环) + [碰撞停止](段间碰撞截断后续段)

**来源原语**：平移绘制/对角线段/长度递增/同反对角线(50c07299), 循环迁移(758abdf0), 重涂色(bd5af378/758abdf0), 碰撞停止(e87109e9/17829a00), 擦除(多题)

**依赖链**：每条对角线段独立按递增长度前进 → 前进后颜色发生循环迁移（原色信息丢失）→ 多条线段的前进可能在空间上碰撞 → 碰撞导致后处理的线段被截短且不变色 → 处理顺序和碰撞结果共同决定最终颜色分布

多条不同色的反对角线段各自沿其反对角线方向前进并加长一格，同时颜色循环迁移；若前进位置与其他线段冲突则被截断且不变色。

**输入结构**：约 15x15 网格，背景黑(0)。包含 2-3 条反对角线段（沿右上方向的对角线），每条由不同颜色的连续像素组成，颜色从红(2)、蓝(1)、绿(3)中选取（恰好每色一条）。每条线段长度 1-3 像素，位于不同的反对角线上。各线段互不相邻、互不接触。生成约束：在至少一个示例中，某条线段的前进目标区域与另一条线段的当前或前进后位置存在空间冲突（共享至少一个格子）；在至少一个示例中，所有线段均能无冲突地完成前进。

**规则**：
1. 确定处理顺序：按每条线段最高像素（行号最小者）的位置排列，行号小的先处理；行号相同时列号小的先处理。
2. 依次处理每条线段：
   a. 擦除当前线段（所有像素置为黑(0)）。
   b. 计算新位置：新线段起点为原线段右上端点沿反对角线方向（行-1，列+1）的下一格，新长度 = 原长度 + 1，沿同一反对角线方向（行+1，列-1）延伸。
   c. 碰撞检测：逐格检查新位置，若某格已被非黑像素占据（属于其他线段，无论是原始位置还是已前进后的位置），则新线段在该格之前截断（不包含该格），长度不再递增到完整值。
   d. 若新线段实际绘制长度 >= 1（至少画了 1 格），执行颜色循环迁移：红(2) -> 蓝(1) -> 绿(3) -> 红(2)。用迁移后的颜色绘制新线段。
   e. 若新线段因碰撞被截断为 0 格（无法绘制任何像素），则该线段消失，不绘制任何内容，也不变色。
3. 所有线段处理完毕后，输出结果网格。

**关键洞察**：颜色循环迁移导致追踪变得困难——曾经的红色线段变成了蓝色，而原本的蓝色线段变成了绿色，身份在视觉上发生了交换。处理顺序决定碰撞结果：先处理的线段占据空间后会阻挡后处理的线段，而被截断的线段保留原色（不循环），这需要对比有碰撞和无碰撞的示例才能发现。
