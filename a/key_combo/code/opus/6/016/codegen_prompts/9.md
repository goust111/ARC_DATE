## 新题 9：标记边转移后十字触发周期扩展

**组合逻辑**：[平移(translate)](已有) + [边缘带(edge_strip)](已有) + [标记指示活跃边(marker_active_edge)](已有) + [含轨迹色行列移动(trail_color_move)](已有) + [擦除(erase)](已有) → [周期平铺(periodic_tiling)](已有，创新：扩展源不是预置标记块而是转移后才出现在十字旁的边带切片) + [邻接侧决定方向(adjacency_side_determines_dir)](已有) + [不覆盖源对象(preserve_source_object)](已有)

**来源原语**：平移、擦除、边缘带、标记像素、标记指示活跃边、含轨迹色行列移动（d255d7a7）；周期平铺、十字图案、邻接侧决定方向、不覆盖源对象（53fb4810）

**依赖链**：标记像素定位活跃边 → 轨迹色行/列的边带切片被转移到对侧 → 转移后的切片落在十字图案旁边 → 十字的邻接侧决定扩展方向 → 切片图案周期性向外延伸到网格边界。删除边带转移则十字旁无图案可扩展（扩展源不存在）；删除周期扩展则转移仅是搬运无后续功能；十字的存在将两步操作桥接起来。

标记像素指定活跃边，轨迹色行/列的边带切片被搬运到对侧边缘；搬运后某些切片恰好落在十字图案旁，十字按邻接侧方向将切片图案周期性地向外延伸至网格边界。

**输入结构**：
- 背景为黑(0)，网格约 16x16。
- 网格某一条边（上/下/左/右之一）有一条 2 像素厚的图案化边带，使用红(2)和绿(3)像素交替排列形成非平凡图案。
- 若干橙(7)标记像素散布在该同侧边缘附近（距该边 1-3 行/列以内），标识活跃边。
- 蓝(1)轨迹像素稀疏地分布在与活跃边垂直的若干行或列上（如活跃边为左边，则蓝点分布在若干行上），指示哪些垂直方向的线需要搬运边带。
- 1-2 个黄(4)十字图案（'+'形，5 像素：中心 + 四臂各一格）位于网格内部，放置位置使得边带转移到对侧后，至少一个转移切片恰好与某个十字的某一臂相邻。
- 生成约束：十字与活跃边不在同一侧；转移后切片与十字的邻接关系明确（仅在一个臂的一侧相邻）。

**规则**：
1. 找到橙(7)标记像素最多的那条网格边缘，确定为活跃边。
2. 对每条与活跃边垂直的行或列：若其上有蓝(1)轨迹像素，则将该行/列在活跃边一侧的 2 像素厚边带切片原样复制到对侧边缘的对应位置。
3. 复制完成后，擦除所有蓝(1)轨迹像素为背景色。橙(7)标记像素保持不变。活跃边原始边带保持不变。
4. 检查每个黄(4)十字图案的四臂：若某臂外侧紧邻一个刚转移过来的边带切片，确定该切片位于十字的哪一侧（上/下/左/右）。
5. 从十字出发，沿远离十字的方向（即从十字中心指向该邻接侧的反方向的反向——即沿邻接侧方向，从十字向外），将该边带切片的 2 像素图案周期性重复延伸，直到到达网格边界。
6. 周期扩展不覆盖黄(4)十字像素本身，也不覆盖其他已有的非背景像素。

**关键洞察**：十字图案在边带转移之前没有任何可操作的邻接内容——它们充当的是"延迟触发器"，只有当边带切片被搬运到对侧并落在十字旁边时，扩展操作才被激活。边带转移和周期扩展通过十字的空间位置桥接成一个因果链。

## 实现要求

1. `main(grid)` 必须实现新题描述中的确定性转换规则，不能只识别 `generate_input()` 的固定模板。禁止不同的input网格输出相同的output网格。
2. `generate_input()` 必须随机生成多样样例，不能固定死。随机维度应覆盖：网格大小、对象数量、位置、颜色、方向、形状参数或关键分支。注意若描述中存在若干，需实现而不是只有单个，包括object或者对应关系等等。且若涉及到最短路径，则输入网格中必涉及到多条路径，对选择造成干扰。
3. 生成器必须保证输入满足 `main()` 的隐式假设：对象不重叠、不越界、特殊标记唯一或可区分、匹配关系无歧义、关键分支出现概率相同。
4. 禁止把 ARC 颜色 id 、亮度、拼写等当作人类不可见的数值语义参与排序、大小比较或隐藏映射。颜色变化必须有可见结构线索。注意颜色亮度、拼写等也是不可见信息，若描述中出现违规的颜色id或者亮度，可自行使用少量的固定颜色替代，但注意生成时要在三个以内输入输出网格中对所有变换100%覆盖度。
5. 输出样例要视觉清晰，人类必须能从输入输出对中肉眼辨认出规律。具体要求：避免对象粘连、覆盖关系混乱、同一像素多重语义；不同逻辑步骤产生的结果不要大面积层叠在一起导致无法分辨哪个颜色属于哪个步骤；输入中各元素之间保持足够间距，输出中新增的标记/填充/路径等应与背景和已有元素在颜色上有明显区分；若规则涉及多层叠加，生成时控制对象密度和尺寸，确保叠加区域只占少数像素而非铺满整个网格。
6. 若规则有多个分支，生成器不能长期固定成一个分支；应让分支在随机样例中合理出现。分支概率不必平均——难以发现的隐蔽分支（如少数情况下才触发的特殊规则）应适当提高出现概率，确保在 3 个训练示例中至少出现一次，否则求解者无法归纳该规则。对于颜色映射类规则，确保 2 个左右的示例即可覆盖所有映射关系（每种颜色→颜色的映射至少在某个示例中出现过）。
