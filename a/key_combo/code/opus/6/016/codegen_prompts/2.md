## 新题 2：分区门控的周期射线填充

**组合逻辑**：[填充(flood_fill)](已有) + [内外分区(inside_outside_partition)](已有) → [周期填充(periodic_fill)](已有，创新：周期填充被限制在分区内部) + [周期步长(periodic_step)](已有，创新：步长由同区域内点对间距决定)

**来源原语**：填充、内外分区、指示像素、墙壁边界（7491f3cf）；周期填充、周期步长、边界点、伴随点（16de56c4）

**依赖链**：洪水填充确定内外分区 → 分区决定哪些点对有效配对 → 点对间距决定周期 → 周期填充被限制在各自分区内。删除分区则点对配对不明确（同色点可能散布在两侧）；删除周期填充则分区结果无下游消费。

用墙壁和指示像素将网格分成内外两区，每区内的同色点对定义一条周期射线，射线仅在本区域内延伸。

**输入结构**：
- 背景为黑(0)，网格约 18x18。
- 灰(5)像素形成一条 4-连通的墙壁路径，从网格的一条边连通到另一条边，将网格分为恰好两个区域。墙壁宽度为一像素。
- 一个蓝(1)指示像素位于墙壁一侧的某个区域内（标记该区域为"内侧"）。
- 每个区域内各有恰好两个红(2)点和两个绿(3)点。同区域内的两个同色点共享同一行或同一列。
- 生成约束：同区域内同色两点之间不被墙壁阻隔（中间路径在区域内连通）；各色点对的周期互不相同。

**规则**：
1. 从蓝(1)指示像素出发执行 4-连通洪水填充，被灰(5)墙壁阻挡。所有被填充到的像素所在区域为"内侧"，其余非墙壁像素所在区域为"外侧"。
2. 对每个区域内的每对同色点（两个红点或两个绿点），确定它们共享的行或列（即射线的轴线），以及它们在该轴线上的间距 D（沿共享行的列间距或沿共享列的行间距），D 即为周期。
3. 从距网格边缘较近的那个点出发，沿射线方向（远离边缘方向）每隔 D 个像素放置一个该颜色的像素，直到遇到墙壁或网格边界为止。
4. 每条射线仅在其所属区域（内侧或外侧）的像素位置上绘制；若某个周期位置落在墙壁上或另一个区域中，则跳过该位置并继续后续位置。
5. 墙壁、指示像素和原始色点保持不变。
6. 若两条不同颜色的射线要占据同一像素，周期较小（更密集）的颜色优先。

**关键洞察**：墙壁不仅是视觉分割线——它决定了哪些同色点构成有效配对（必须在同一区域内），并且限制了周期射线的传播范围。不先做洪水填充分区，就无法判断哪两个同色点该配对。

- bg = most common color.  Sparse non-bg dots of several colors.
- All repeating colors originate from the same grid edge (top, bottom,

  their gap defines the step.
- Every non-bg dot lies on a shooting-direction line that contains a
  repeating color.

Rule:
- Determine the unique shooting edge; left/right → rows, top/bottom → columns.
- For each shooting-direction line, the repeating color has exactly 2 dots;
  step = gap between them, offset = first position mod step.

  a companion: it absorbs the ray and becomes the fill color, limiting the
  fill range to the span between repeating and companion dots.

- Without a companion the repeating color fills the entire line.

Key insight: the shooting edge is identified by counting boundary dots;
the gap between the two marker dots is the period; a companion sharing the
modular class acts as a wall that stops the ray and dictates the paint color.
