## 新题 6：蓝点双重编码的排列间距

**组合逻辑**：[排序(sort)](已有) + [面积排序(area_ordering)](创新：面积含蓝点像素，蓝点同时编码另一属性) → [拼接(concatenate)](已有) + [基线对齐排列(baseline_aligned_pack)](已有) → [重涂色(recolor)](创新：排列完毕后擦除蓝点) + [像素计数编码半径→像素计数编码间距](创新改造)

**来源原语**：排序、面积排序、基线对齐排列、精灵体（4df5b0ae）；像素计数编码半径（cb2d8a2c）；重涂色（多题共有）

**依赖链**：蓝像素计数 → 间距参数 AND 蓝像素计入面积 → 面积排序 → 左到右基线对齐排列（间距由左侧精灵的蓝点数决定）→ 消除蓝点。蓝点同时影响排序（通过面积）和间距（通过计数），构成分叉汇合依赖，删除蓝点统计则排序和间距均不可确定。

精灵体按面积（含蓝点）从小到大排列，排列后相邻精灵间的间距等于左侧精灵的蓝点数，最后将蓝点重涂为精灵本色。

**输入结构**：
- 背景为青(8)，网格约 15x20。
- 3-5 个单色 4-连通前景精灵体，各自颜色互不相同（如红(2)、绿(3)、黄(4)、品红(6)、橙(7)等），每个精灵由 3-8 个像素组成，形状不规则（不全是矩形）。
- 每个精灵内部有 0-3 个蓝(1)像素嵌入其连通体中。蓝像素是精灵形状的一部分（与精灵其余像素 4-连通），但颜色为蓝色以区分。
- 网格最底行为一条完整的橙(7)基线。
- 精灵散布在网格上方各处，彼此不相邻。
- 生成约束：各精灵的面积（含蓝像素）互不相同；各精灵的蓝像素数量互不相同（若某精灵无蓝像素则其蓝数为 0）。

**规则**：
1. 对每个精灵，统计其总面积（所有像素数，含蓝点）和蓝点数量 B。
2. 按面积从小到大排序所有精灵。
3. 从网格左侧开始，在基线上方逐个放置排序后的精灵：每个精灵底部对齐基线行上方一行，保持精灵原始形状和内部结构。
4. 相邻精灵之间的水平间距（前一个精灵边界框右边缘到下一个精灵边界框左边缘之间的空列数）等于前一个精灵的蓝点数 B。若 B = 0，则间距为 1（最小间距）。第一个精灵的左边缘紧贴网格第 0 列。
5. 所有精灵放置完毕后，将每个精灵内部的蓝(1)像素重涂为该精灵的主色（非蓝的那种颜色）。
6. 基线保持不变。背景区域保持青(8)。

**关键洞察**：蓝点承担双重角色——它们计入精灵面积（影响排序位置），同时编码排列间距（影响布局密度）。给精灵增加蓝点既提升其排序名次又增大其后方间距，形成一个内在的权衡张力，使得排序和布局不可分割。
