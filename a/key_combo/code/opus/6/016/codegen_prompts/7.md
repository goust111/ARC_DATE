## 新题 7：镜像生成配对后绕障连线

**组合逻辑**：[镜像(mirror)](已有) + [轴线决定变换(axis_determines_op)](已有) → [连线(connect)](已有) + [同色分量依序连接(same_color_chain)](创新：被连接的分量由镜像步骤创建) + [绕障碍最短路径(shortest_detour)](已有) + [障碍墙(obstacle_wall)](已有，创新：障碍不被镜像，造成不对称路径约束)

**来源原语**：镜像、轴线决定变换、引导线（4e7e0eb9）；连线、同色分量依序连接、绕障碍最短路径、障碍墙（f8f52ecc）

**依赖链**：引导线方向 → 镜像轴确定 → 将单侧彩色分量镜像到另一侧（产生同色配对）→ 同色对之间寻找绕障最短路径连接。删除镜像则只有单分量无需连接；删除连线则镜像仅是视觉对称无功能意义；障碍墙不被镜像使得路径规划必须面对不对称约束。

引导线确定镜像轴，将一侧的彩色分量翻转到空白侧，随后每对同色分量（原件与镜像件）用绕障 L 形最短路径连接。障碍墙不参与镜像，造成不对称的路由环境。

**输入结构**：
- 背景为黑(0)，网格约 18x18。
- 一条完整的绿(3)引导线贯穿网格：若为水平线则占据某一整行（从第 0 列到最后一列），若为竖直线则占据某一整列（从第 0 行到最后一行）。引导线将网格分为两个半区。
- 一个半区（"源半区"）内有 2-3 个小型 4-连通单色分量，各自颜色互不相同且不为黑(0)、绿(3)、灰(5)，每个分量 2-5 个像素。另一个半区（"空半区"）无彩色分量。
- 灰(5)障碍墙片段散布在两个半区中（两侧都有），每段为 1-3 像素的短线段。
- 生成约束：源半区的每个分量镜像后不与任何障碍墙重叠；每对同色分量之间存在至少一条不穿越障碍和其他颜色的 L 形路径。

**规则**：
1. 根据引导线的方向确定镜像轴：水平引导线 → 上下镜像；竖直引导线 → 左右镜像。
2. 将源半区的所有彩色分量（非障碍、非引导线）关于引导线做镜像，在空半区的对应位置绘制颜色相同的副本。灰(5)障碍墙不参与镜像。
3. 现在每种颜色有两个 4-连通分量（原件在源半区，副本在空半区）。对每种颜色，用该颜色绘制一条连接两个分量的最短 L 形路径（仅水平和竖直段，至多一个直角弯）。
4. 路径不得穿越灰(5)障碍墙、其他颜色的分量或其他颜色的连线路径。路径可以穿越引导线（引导线不是障碍）。
5. 若某种颜色的 L 形路径有多个等长选择，选择弯折点行号更小（更靠上）的那条；若行号相同则选择弯折点列号更小（更靠左）的。
6. 处理顺序：按每种颜色原件分量的左上角像素的行优先、列次优先的顺序逐色处理。先处理的颜色的连线成为后续颜色的障碍。
7. 引导线、障碍墙和源半区的原始分量保持不变。

**关键洞察**：镜像步骤不只是对称装饰——它创造了连线操作所需的"目标"分量。因为障碍墙不参与镜像，两侧的障碍分布不对称，导致连线路径不能简单地沿镜像轴对称规划，必须实际计算绕障路由。

1. `main(grid)` 必须实现新题描述中的确定性转换规则，不能只识别 `generate_input()` 的固定模板。禁止不同的input网格输出相同的output网格。
2. `generate_input()` 必须随机生成多样样例，不能固定死。随机维度应覆盖：网格大小、对象数量、位置、颜色、方向、形状参数或关键分支。注意若描述中存在若干，需实现而不是只有单个，包括object或者对应关系等等。且若涉及到最短路径，则输入网格中必涉及到多条路径，对选择造成干扰。

6. 若规则有多个分支，生成器不能长期固定成一个分支；应让分支在随机样例中合理出现。分支概率不必平均——难以发现的隐蔽分支（如少数情况下才触发的特殊规则）应适当提高出现概率，确保在 3 个训练示例中至少出现一次，否则求解者无法归纳该规则。对于颜色映射类规则，确保 2 个左右的示例即可覆盖所有映射关系（每种颜色→颜色的映射至少在某个示例中出现过）。
