## 新题 8：面板压缩编码相位，解码为周期格点

**组合逻辑**：[压缩(compress)](已有) + [拼接(concatenate)](已有) + [逆序扫描(reverse_scan)](已有) + [空行丢弃(empty_rows_discarded)](已有) → [解码(decode)](创新：压缩后的色条序列被重新解释为空间编码) + [平铺(tile)](已有) + [相位编码(phase_encoding)](已有)

**来源原语**：压缩、拼接、逆序扫描、空行丢弃、分栏面板、分隔列、非空行（25c199f5）；解码、平铺、相位编码、轮廓字形、周期格点（eee78d87）

**依赖链**：面板逆序扫描 → 非空行提取与丢弃空行 → 压缩成有序色条列 → 色条列被解码为 3x3 二值字形 → 字形决定相位瓦片 → 周期平铺生成格点 + 中心栗色覆盖。压缩步骤的输出不再是最终答案（源题中它是），而是下一步解码的输入；解码步骤将一维颜色序列重新诠释为二维空间结构。信息经历了两次表征变换（二维面板→一维序列→二维相位格点）。

三个面板的非空色条行按逆序扫描提取并压缩为一列颜色序列，该序列被解码为 3x3 相位字形，进而周期平铺为格点图案。

**输入结构**：
- 输入网格约 6x20，由两条全高黄(4)分隔列将其分为三个等宽面板（每个面板约 6 列宽、6 行高）。
- 背景为黑(0)。
- 每个面板内有若干占据整行的单色水平条纹（每条一像素厚，颜色为前景色），其余行为空（全为背景色）。
- 所有面板中的色条颜色合计恰好覆盖 N 种不同的前景色（N 为 4-9），每种颜色在所有面板中恰好出现一次。
- 生成约束：按逆序扫描（从右面板到左面板，每个面板内从上到下）提取非空行后，得到的有序颜色序列长度 N 满足 N <= 9，且该序列可被解释为 3x3 网格的逐行扫描标记（颜色出现的位置对应 3x3 网格中的前景像素）。

**规则**：
1. 从右面板开始，向左逐面板扫描；每个面板内从上到下读取行。
2. 对每一行，若包含非背景像素则保留其颜色，若为全背景行则丢弃。
3. 将所有保留的颜色按读取顺序排成序列 [C1, C2, ..., CN]。
4. 将该序列映射到 3x3 网格的行优先扫描位置（位置 0 = 第0行第0列，位置 1 = 第0行第1列，...，位置 8 = 第2行第2列）：序列中有颜色的位置标记为前景（1），序列未覆盖的位置（若 N < 9）标记为背景（0），得到一个 3x3 二值字形。
5. 将该 3x3 字形解释为相位瓦片：前景位置 → 橙(7)，背景位置 → 黑(0)。
6. 创建 15x15 的黑(0)输出网格，用该 3x3 相位瓦片周期性铺满。
7. 在输出网格中心的 6x6 区域，将原始 3x3 字形做 2x2 平铺，前景像素涂为栗(9)，覆盖该区域中已有的橙(7)像素。

**关键洞察**：面板压缩在源题中是最终输出，在本题中仅是中间编码步骤——其产出的颜色序列不代表视觉答案，而是一个需要被空间解码的密码。信息从二维分布（面板中的色条位置）经压缩成一维（颜色序列），再经解码回到二维（相位格点），经历两次表征变换。
