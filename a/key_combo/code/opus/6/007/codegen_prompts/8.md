## 新题 8：标记路由与拓扑条件分支重涂色

**组合逻辑**：[移动](创新：标记按相对顺序决定移动目的地) + [重涂色](创新：重涂方案由目标对象的拓扑属性分支选择) + [填充] + [描边] ← [标记在矩形外侧·相对顺序决定出口](路由规则) + [包含关系·封闭孔洞·有孔触发重涂](拓扑判断) + [频率排序·少数色替换](备选重涂方案)

**来源原语**：移动·标记在矩形外侧·相对顺序决定出口·标记像素·擦除（e4941b18），重涂色·描边·封闭孔洞·有孔触发重涂·包含关系（aa4ec2a5），频率排序·少数色替换（9caf5b84）

**依赖链**：网格中有若干独立的前景对象和一行标记像素在对象上方 → 标记像素成对出现，每对中两个标记颜色不同 → 每对标记的左右相对顺序决定它们"指向"对象群的哪一侧（左侧标记先→指向左半区对象，右侧标记先→指向右半区对象） → 标记被移动（路由）到其指向的最近对象上 → 被标记选中的对象执行拓扑条件分支重涂色：若对象有封闭孔洞 → 对象体涂青(8)、孔洞填品红(6)、外侧描红(2)轮廓；若对象无孔洞 → 对象中少数色像素被替换为橙(7)

标记对按左右顺序路由到目标对象，然后根据目标对象是否含孔洞来分支选择两套不同的重涂色方案。

**输入结构**：
- 约 18x22 网格，背景色为黑(0)。
- 网格中部偏下区域有 4~6 个分离的 4-连通前景对象，由 2~3 种颜色组成（如蓝(1)和绿(3)混合），面积 8~20 像素。部分对象内部有 4-连通的黑(0)封闭孔洞（完全被对象像素包围），部分对象没有孔洞。
- 对象按水平位置可分为左半区和右半区（以网格中线为界，每半区至少 1 个对象）。
- 网格最上方一行有 2~3 对标记像素。每对标记由一个红(2)像素和一个灰(5)像素组成，水平相邻。不同标记对之间间隔至少 2 个背景格。
- 生成约束：标记对的数量 <= 对象数量的一半（不是每个对象都会被选中）；左半区和右半区中各自至少有一个含孔洞对象和一个不含孔洞对象。

**规则**：
1. 对每一对标记，判断其内部顺序：若红(2)在灰(5)左边 → 该标记对指向左半区；若灰(5)在红(2)左边 → 该标记对指向右半区。
2. 在指向的半区中，选择离该标记对水平中心最近的尚未被选中的对象作为目标（按对象 bbox 中心的水平距离衡量）。若距离相等，选择 bbox 中心更靠上的对象。
3. 擦除该标记对（恢复为背景色）。
4. 对选中的目标对象执行拓扑分支：
   - **有孔洞分支**：将对象所有像素重涂为青(8)；将对象内部的每个封闭孔洞（4-连通背景区域完全被对象像素包围）填充为品红(6)；在对象+孔洞填充的整体外围画 1 像素宽的红(2) 8-邻接轮廓。
   - **无孔洞分支**：统计该对象使用的各颜色的像素数量；将出现次数最少的颜色的所有像素替换为橙(7)；若多色并列最少则全部替换。
5. 标记对按从左到右的顺序依次处理（先处理左边的标记对）。
6. 未被任何标记对选中的对象保持原样不变。

**关键洞察**：标记对的内部排列顺序（红-灰 vs 灰-红）是一个隐蔽的方向编码，必须对比多个示例才能归纳出这条规则。更深层的洞察是：同一个"选中"操作之后分叉为两种完全不同的视觉效果（有孔→青+品红+红轮廓 vs 无孔→少数色→橙），使得求解者需要同时推断路由规则和两套分支规则。
