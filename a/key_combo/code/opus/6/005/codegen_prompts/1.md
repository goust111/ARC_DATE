## 新题 1：标记穿透格子的选择性重力

**组合逻辑**：[压缩/compress](创新：压缩结果不用于输出缩略图，而是作为重力路径的透明性判据) → [重力下落/gravity_drop](创新：不是无条件下落，而是根据颜色匹配选择性穿透) → [填充/fill](已有原语，但填充目标由重力路径终点决定)

**来源原语**：压缩/compress(80214e03, 996ec1f3), 重力下落/gravity_drop(db7260a4, 28a6681f), 填充/fill(db7260a4), 格子结构/lattice(80214e03), 主色代表区域/dominant_per_region(996ec1f3), 去噪取主色/denoise_majority(996ec1f3)

**依赖链**：压缩提取每个格子块的主色 → 主色与标记色的匹配关系决定重力路径中哪些块可穿透 → 第一个不可穿透块成为填充目标。三步之间有信息变换：压缩输出是颜色标签，重力消耗这些标签做路径选择，填充将路径终点的块内容替换。

将标记像素沿格子列向下坠落，穿过主色匹配的块，在首个主色不匹配的块中停下并以标记色充满该块内部。

**输入结构**：约 15x15 的网格。背景为黑(0)。网格内有一个由黑(0) 1像素分隔线划分的矩形格子（如 3列x4行的块阵列，每块 3x3 像素）。每块内部由一种主色前景像素填充，混有少量噪声像素（其他前景色，占比不超过 30%）。主色取自红(2)、绿(3)、蓝(1)、黄(4) 等。格子顶部上方有一行黑(0) 背景行，其中放置 1-3 个彩色标记像素，每个标记的列位置严格对齐到某一格子列的中心列。标记颜色是格子中出现的主色之一。生成约束：每个标记所在的格子列中至少有一个块的主色与该标记不同；多个标记的路径终点不会落在同一块。

**规则**：
1. 对每个格子块，统计其内部出现频率最高的非背景色，定义为该块的主色。
2. 每个标记像素沿其所在列垂直向下逐块检查。
3. 若当前块的主色等于标记色，标记穿透该块（继续向下检查下一块）。
4. 若当前块的主色不等于标记色，标记停在该块：用标记色替换该块内部所有像素（含噪声像素和原主色像素），分隔线不变。
5. 标记像素从原位置擦除（置为黑(0)）。
6. 未被任何标记触及的块保持原样（含噪声）。
7. 多个标记独立处理（生成约束保证终点不重叠）。

**关键洞察**：必须先对噪声块做"去噪压缩"提取主色，才能判断哪些块对标记透明——压缩不是最终输出，而是重力路径决策的隐式中间步骤。
