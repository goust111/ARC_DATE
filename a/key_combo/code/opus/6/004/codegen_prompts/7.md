## 新题 7：计数排序框架瀑布堆叠

**组合逻辑**：[计数/counting](已有) → [排序/sort](已有) → [堆叠/stack](已有) + [绘点/draw_dots](已有)；创新点在于计数结果同时作为排序键和点数内容，框架的空间布局由计数结果全面重组

**来源原语**：计数/counting、擦除/erase、绘点/draw_dots、空心框架/hollow_frame、图案精灵体/pattern_sprite、同色匹配/same_color_matching、计数映射点数/count_maps_to_dots（来自 8f215267）；排序/sort、堆叠/stack、按频率降序/descending_freq（来自 bd283c4a）；按数量排序/count_ordering（来自 b1986d4b）

**依赖链**：同色匹配计数 → 计数值同时决定排序键和点数 → 排序决定堆叠顺序 → 堆叠 + 绘点生成输出。计数具有双重角色（排序 + 渲染），去掉计数则排序和点数均不可知；去掉排序则堆叠顺序不确定；去掉堆叠则框架保持原位。

统计每个空心框架的同色小图案数量，按数量降序将框架纵向堆叠，并在每个框架内部用点标示其数量。

**输入结构**：黑(0)背景，约 18x18 网格。3-5 个空心矩形框架，每个框架由单一颜色构成（从蓝(1)、红(2)、绿(3)、黄(4)、橙(7)中选取，各框架颜色互不相同），框架大小各异但内部至少 3 行 5 列（保证能容纳点）。若干小型单色图案精灵体（3-5 像素，4-连通，不规则形状）散布在框架之外的背景区域，每个精灵体的颜色与某一个框架颜色相同。每种颜色对应的精灵体数量互不相同（无平局），范围 1-5 个。生成约束：框架互不重叠且不与精灵体重叠。

**规则**：
1. 对每个框架颜色 C，统计网格中与之同色的精灵体数量，记为该框架的"计数值" T_C。
2. 擦除所有精灵体（替换为背景色）。
3. 将各框架按计数值从大到小排序。
4. 裁剪每个框架至其边界框，然后在新的输出网格上从上到下依次堆叠：计数值最大的框架在最上方，次大的在其下方，以此类推。所有框架左对齐。相邻框架之间间隔 1 行背景。输出网格宽度等于最宽框架的宽度，高度恰好容纳所有框架加间隔。
5. 在每个堆叠后的框架内部，沿框架内腔的中间行（若内腔行数为偶数则取上中行）从左侧内壁起每隔 1 个空格绘制一个点（点颜色为该框架自身颜色），共绘制 T_C 个点。即：第 1 个点在内壁左起第 1 列，第 2 个点在左起第 3 列，第 3 个点在左起第 5 列，以此类推。

**关键洞察**：计数值承担双重角色——既是排序的键（决定框架的上下位置），又是渲染的内容（决定框架内部绘制几个点）。求解者必须识别出同一数值在两个不同的操作中分别发挥作用。
