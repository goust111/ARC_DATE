## 新题 5：柱状高度算术驱动楔形展开深度

**组合逻辑**：[计数/counting + 高度加减运算](已有) → [擦除/erase + 填充/fill + 逐行扩展楔形](已有)；创新点在于算术运算的结果不被渲染为可见柱状条，而是作为隐式参数控制另一个几何操作的幅度

**来源原语**：计数/counting、柱状条/vertical_bar、结果槽/result_slot、颜色编码正负/color_encodes_sign、高度加减运算/height_arithmetic（来自 37ce87bb）；擦除/erase、填充/fill、调色板行/palette_row、标记竖条/marker_bar、以缺口为中心/centered_on_gap、逐行扩展楔形/row_expand_wedge（来自 bae5c565）

**依赖链**：颜色编码加减 → 算术求和 → 楔形展开行数。算术结果是楔形展开的唯一深度参数；去掉算术则深度不可知，去掉楔形则算术结果无几何表达。

网格上半部有调色板行和标记竖条，下半部有正/负计数柱；正柱高度之和减去负柱高度之和，决定调色板从缺口向下展开多少行楔形。

**输入结构**：黑(0)背景，约 15x20 网格。顶行为调色板行：一行多色像素（从蓝(1)、红(2)、绿(3)、黄(4)、灰(5)中选取）横跨网格全宽，其中恰好有一个黑(0)缺口。调色板行下方紧接一条垂直的橙(7)标记竖条（2-4 像素高），位于缺口所在列。网格下半部分（与上半部分之间有至少 3 行空白隔开）有若干底部对齐的单像素宽垂直柱状条：青(8)柱为正值，红(2)柱为负值。柱状条高度各异（1-6 像素），互不相邻，各占一列。生成约束：正柱高度总和严格大于负柱高度总和；结果值 H 不超过网格剩余可用行数（标记竖条底部到网格底边的距离）。

**规则**：
1. 计算所有青(8)柱的高度之和 S_pos，以及所有红(2)柱的高度之和 S_neg。
2. 计算展开深度 H = S_pos - S_neg。
3. 清除网格中除调色板行以外的所有内容（柱状条、标记竖条均擦除为背景色）。
4. 从调色板行的下一行开始，以缺口列为中心，逐行向下扩展楔形：第 k 行（k = 1, 2, ..., H）在缺口的左右各复制 k 个调色板列的颜色（从缺口向两侧取，若不足 k 列则取到调色板边界为止）。
5. 楔形中缺口列始终填充橙(7)（标记竖条的颜色）。
6. 展开恰好 H 行后停止，H 行以下保持背景色。

**关键洞察**：柱状条的高度算术（源题中产出一根可见的灰色结果柱）在此不产生任何可见输出，而是作为一个隐式数值参数注入到完全不同的几何操作（楔形展开）中。求解者需要识别两个在视觉上毫无关联的区域之间的数值桥梁。
