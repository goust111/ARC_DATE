## 新题 2：方位编码射线的距离递变楔形填充

**组合逻辑**：[方位对应/direction_correspondence](创新：方位邻居从装饰角色变为射线方向编码器) → [射线延伸/ray_cast](创新：射线方向由邻居编码而非固定向下) → [距离递变/distance_gradient + 填充/fill](创新：沿射线方向产生逐行递变宽度的楔形，而非固定宽度填充)

**来源原语**：方位对应、十字图案、方位决定颜色（来自 d364b489）；射线延伸、列遮挡（来自 6d58a25d）；距离递变、三角楔形、填充、逐行宽度递变成楔（来自 a65b410d）

**依赖链**：每个标记像素的方位邻居确定射线方向 → 射线方向确定楔形的展开轴 → 沿射线每远离标记一格，楔形垂直于射线方向扩展一格 → 多个楔形可能重叠，需按标记到重叠格的距离解决冲突。方位编码、射线长度、楔形宽度三者逐级耦合。

从每个标记像素出发，根据其唯一方位邻居确定射线方向，沿该方向投射楔形：距离每增加一格，楔形垂直宽度扩展一格，形成三角扇面；多楔重叠处取距源标记更近者的颜色。

**输入结构**：约 18x18 的黑(0)背景网格。网格中有 2~4 个标记像素，颜色互不相同，取自蓝(1)、红(2)、绿(3)、黄(4)。每个标记像素恰好有一个 4-邻居位置放置了灰(5)像素，指示射线方向（灰在标记上方 → 向上射线，灰在下方 → 向下，灰在左 → 向左，灰在右 → 向右）。各标记之间距离足够大（边界框间距 >= 5），保证楔形在多数区域不重叠。生成约束：不同标记的方位邻居方向不全相同（至少两个方向不同）；标记不在网格边缘上（保证方位邻居有空间放置）。

**规则**：
1. 对每个标记像素，找到其唯一的灰(5) 4-邻居，确定射线方向：灰在标记的上方 → 射线向上，下方 → 向下，左方 → 向左，右方 → 向右。
2. 从标记位置出发沿射线方向逐格前进。设当前距离为 d（d=1, 2, 3, ...），在射线前进方向的第 d 格处，同时在垂直于射线方向的两侧各扩展 (d-1) 格，形成宽度为 (2d-1) 的一排填充。填充颜色为该标记的颜色。
3. 楔形填充在遇到网格边界时裁剪（超出部分丢弃），但不因此停止——继续沿射线方向前进直到射线本身到达网格边界。
4. 灰(5)方位指示像素在输出中擦除（恢复为黑(0)背景）。
5. 若两个楔形覆盖同一格，取该格到其源标记的切比雪夫距离（行差与列差的较大值）较小者的颜色。若距离相同，取行号较小的标记的颜色（行号相同则取列号较小者）。
6. 标记像素自身保留其原色。

**关键洞察**：方位邻居不是装饰性十字臂而是方向编码器，它决定了楔形展开的整个空间轴向；楔形的宽度又由射线距离逐级递增，使得方向选择的微小变化产生完全不同的空间覆盖模式。

## 实现要求

1. `main(grid)` 必须实现新题描述中的确定性转换规则，不能只识别 `generate_input()` 的固定模板。禁止不同的input网格输出相同的output网格。
2. `generate_input()` 必须随机生成多样样例，不能固定死。随机维度应覆盖：网格大小、对象数量、位置、颜色、方向、形状参数或关键分支。注意若描述中存在若干，需实现而不是只有单个，包括object或者对应关系等等。且若涉及到最短路径，则输入网格中必涉及到多条路径，对选择造成干扰。
3. 生成器必须保证输入满足 `main()` 的隐式假设：对象不重叠、不越界、特殊标记唯一或可区分、匹配关系无歧义、关键分支出现概率相同。
4. 禁止把 ARC 颜色 id 、亮度、拼写等当作人类不可见的数值语义参与排序、大小比较或隐藏映射。颜色变化必须有可见结构线索。注意颜色亮度、拼写等也是不可见信息，若描述中出现违规的颜色id或者亮度，可自行使用少量的固定颜色替代，但注意生成时要在三个以内输入输出网格中对所有变换100%覆盖度。
5. 输出样例要视觉清晰，人类必须能从输入输出对中肉眼辨认出规律。具体要求：避免对象粘连、覆盖关系混乱、同一像素多重语义；不同逻辑步骤产生的结果不要大面积层叠在一起导致无法分辨哪个颜色属于哪个步骤；输入中各元素之间保持足够间距，输出中新增的标记/填充/路径等应与背景和已有元素在颜色上有明显区分；若规则涉及多层叠加，生成时控制对象密度和尺寸，确保叠加区域只占少数像素而非铺满整个网格。
6. 若规则有多个分支，生成器不能长期固定成一个分支；应让分支在随机样例中合理出现。分支概率不必平均——难以发现的隐蔽分支（如少数情况下才触发的特殊规则）应适当提高出现概率，确保在 3 个训练示例中至少出现一次，否则求解者无法归纳该规则。对于颜色映射类规则，确保 2 个左右的示例即可覆盖所有映射关系（每种颜色→颜色的映射至少在某个示例中出现过）。
