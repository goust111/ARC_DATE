## 新题 7：格子缺失交叉点裁剪后同心层色序反转

**组合逻辑**：[裁剪/crop](已有) + [四角围合/four_corner_bound + 缺失交叉点/missing_intersection](已有) → [同心方框层/concentric_layer](创新：层的深度基准从网格边缘改为裁剪边界) → [层色序内外翻转/reverse_layer_colors](创新：反转的对象从预设同心环改为由裁剪动态确定的深度层)

**来源原语**：裁剪、四角围合、缺失交叉点、背景色空洞、网格线（来自 a644e277）；同心方框层、深度排序、层色序内外翻转、重涂色（来自 85c4e7cd）

**依赖链**：缺失的格子交叉点确定裁剪矩形的四个角 → 裁剪后的子网格边界成为深度 0 → 每个像素的深度（到最近裁剪边界的切比雪夫距离）决定其所属的同心层 → 收集各深度层的颜色序列后反转重涂。裁剪边界直接改变深度分配——如果四个缺失交叉点位置不同，同一像素可能属于不同深度层，导致完全不同的颜色反转结果。

在格子结构中找到四个背景色缺失交叉点确定的矩形裁剪区域，将裁剪结果视为同心矩形环，按从外到内收集颜色序列后反转各层颜色。

**输入结构**：约 17x17 的网格。一种颜色（如橙(7)）形成规则的一像素宽水平线和垂直线，构成格子结构（行间距和列间距相等，约 3~4 格）。格子线的交叉点通常为橙(7)色，但恰好有 4 个交叉点为背景黑(0)色（缺失交叉点）。这 4 个缺失点恰好构成一个矩形的四角（不一定是最小矩形，但四点共构成一个轴对齐矩形）。格子单元格（格子线围成的矩形区域）内部填充有不同颜色，整体形成同心矩形色带模式——从裁剪区域的最外层到最内层，每层一种颜色，颜色序列无重复。使用的填充色取自蓝(1)、红(2)、绿(3)、黄(4)、灰(5)、品红(6)中的 3~5 种。生成约束：四个缺失交叉点定义的裁剪矩形内至少包含 3 层深度（保证反转效果可见）；格子线颜色不参与同心层颜色序列。

**规则**：
1. 识别格子线颜色（形成规则水平和垂直线的唯一非背景色，此处为橙(7)）。
2. 找到恰好 4 个格子交叉点位置为背景黑(0)色的缺失交叉点。
3. 取这 4 个点的最小行、最大行、最小列、最大列，定义裁剪矩形。进行包含边界的裁剪。
4. 在裁剪后的子网格中，计算每个非格子线像素的"深度"：该像素到裁剪矩形边界的切比雪夫距离（即 min(到上边距离, 到下边距离, 到左边距离, 到右边距离)）。格子线像素保持原色不变。
5. 收集深度序列：深度 0 的非格子线像素颜色为 color_0，深度 1 的为 color_1，……直到最大深度。（同一深度的所有非格子线像素颜色相同。）
6. 将颜色序列反转：深度 0 重涂为 color_max，深度 1 重涂为 color_(max-1)，……深度 max 重涂为 color_0。格子线像素和缺失交叉点像素保持不变。
7. 输出裁剪后的子网格（含反转后的颜色和保持不变的格子线）。

**关键洞察**：裁剪边界不是由内容决定而是由格子结构的缺陷（缺失交叉点）决定，而裁剪边界又定义了同心层的深度基准——移动缺失交叉点会改变裁剪范围，进而改变所有像素的深度分配，导致完全不同的颜色反转映射。裁剪与反转通过深度计算紧密耦合。
</new_puzzle>
