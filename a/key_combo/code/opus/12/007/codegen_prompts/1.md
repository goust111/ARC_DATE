## 新题 1：遮挡层序决定条纹填充顺序

**组合逻辑**：[层序推断/layer_infer](已有) + [遮挡层次/occlusion_order](已有) → [排序/sort](创新：排序键从空间位置改为遮挡深度) → [填充/fill](创新：条纹颜色序列由遮挡推断结果决定) + [条纹决定填充轴/stripe_determines_fill_axis](创新：轴的选择从条纹朝向改为直线类型的多数投票)

**来源原语**：层序推断、遮挡层次、直线、交叉点、唯一序链（来自 22425bda）；排序、条纹、正方形区域、填充、条纹决定填充轴（来自 8e1813be）

**依赖链**：交叉点处的可见颜色 → 推断出唯一的从底到顶遮挡序列 → 该序列成为条纹颜色的排列顺序；同时，各直线的朝向统计（水平多还是垂直多）决定条纹是按行填还是按列填。两条信息流汇合后才能生成正方形区域内的最终条纹图案。

将多条交叉直线的遮挡堆叠顺序推断出来，再按该顺序将各线颜色作为条纹依次填入灰色正方形区域，条纹方向由直线类型的多数投票决定。

**输入结构**：约 15x15 的黑(0)背景网格。网格中有 N 条（3~6 条）不同颜色的一像素宽直线，每条为全贯穿的水平线、垂直线或 45 度对角线之一。各线颜色互不相同，取自蓝(1)、红(2)、绿(3)、黄(4)、品红(6)、橙(7)。直线两两之间存在交叉点；在交叉点处仅一种颜色可见，其余被遮挡。此外网格中另有一个 NxN 的灰(5)实心正方形区域（N 等于直线数量），与所有直线不重叠。生成约束：直线的遮挡序从底到顶存在唯一 Hamiltonian 链（即相邻层的线必须几何上交叉）；正方形区域不被任何直线穿过。

**规则**：
1. 对每条直线，根据其可见的共线像素恢复完整直线轨迹（被遮挡的像素由共线推断补全）。
2. 在每个交叉单元格处，可见颜色的线位于不可见颜色的线之上。收集所有这些"上/下"约束对。
3. 从约束对中推断唯一的从最底层到最顶层的全排列（即唯一 Hamiltonian 链，相邻元素的线必须几何交叉）。
4. 统计所有直线中水平线与垂直线的数量（对角线不计入任何一方）。若水平线数量 >= 垂直线数量，填充轴为"行"（每行一色）；否则填充轴为"列"（每列一色）。
5. 将灰(5)正方形作为输出画布。按从底层到顶层的遮挡序列，依次用每条线的颜色填充正方形的第 1 行/列、第 2 行/列……（行模式：第 1 行 = 最底层颜色，逐行向下；列模式：第 1 列 = 最底层颜色，逐列向右）。
6. 输出仅为正方形区域的内容（裁剪输出）。

**关键洞察**：条纹的颜色排列不是由空间位置或颜色编号决定，而是由直线交叉处的视觉遮挡关系推断出的唯一层序决定；同时填充方向由直线类型的多数投票决定——两个独立推断汇合才能确定输出。
