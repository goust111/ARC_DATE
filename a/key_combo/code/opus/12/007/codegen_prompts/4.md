## 新题 4：条纹编码镜像瓦片阵列

**组合逻辑**：[条纹/stripe](创新：条纹从被填充对象变为二值编码信号) → [镜像/mirror](创新：镜像不是全局固定模式而是由条纹逐位控制) + [平铺/tiling](创新：阵列方向由条纹朝向决定) → [阵列排布/array_layout](已有)

**来源原语**：平铺、镜像、瓦片、阵列排布、中间行翻转（来自 00576224）；条纹、条纹决定填充轴、顺序对应（来自 8e1813be）；掩码映射（来自 bf45cf4b）

**依赖链**：条纹的颜色序列编码了一个二值模式（哪些瓦片需要镜像），条纹的空间朝向（水平/垂直）同时决定了瓦片阵列的排列方向和镜像轴。两条信息从同一个条纹对象中提取但作用不同，缺一不可。

将一个多色瓦片按条纹编码排列成一维阵列：条纹中颜色 A 对应原始瓦片、颜色 B 对应水平或垂直镜像瓦片，条纹朝向同时决定阵列排列方向和镜像翻转轴。

**输入结构**：约 12x12 的黑(0)背景网格。网格中包含两个互不接触的前景元素：(a) 一个 3x3 或 4x4 的多色瓦片（使用 2~4 种非背景色，内部图案非对称以使镜像效果可辨），位于网格一角附近；(b) 一条单像素宽的条纹，由两种交替出现的颜色组成（如红(2)和绿(3)），长度为 N（3~6 格），严格水平或严格垂直放置。条纹中的两种颜色在整条条纹中仅使用这两种，但排列不一定是严格交替的（如红-绿-红-红-绿）。生成约束：条纹的两种颜色与瓦片使用的颜色均不重叠（颜色互斥）；条纹长度 N 与瓦片尺寸 S 满足 N*S 不超过 25（保证输出网格合理）。

**规则**：
1. 识别瓦片：网格中包含多种非背景色的矩形连通区域即为瓦片。识别条纹：单像素宽、仅含两种颜色的水平或垂直线段即为条纹。
2. 设条纹中按出现顺序（水平条纹从左到右，垂直条纹从上到下）排列的像素颜色为 c_1, c_2, ..., c_N。将第一个出现的颜色定义为"原始色"A，另一种定义为"镜像色"B。
3. 确定阵列排列方向和镜像轴：若条纹为水平方向，则瓦片从左到右水平拼接，镜像操作为左右翻转；若条纹为垂直方向，则瓦片从上到下垂直堆叠，镜像操作为上下翻转。
4. 依次处理条纹中每个位置 i（i=1 到 N）：若 c_i = A，放置瓦片原样；若 c_i = B，放置瓦片的镜像版本。各瓦片紧邻拼接，无间隔。
5. 输出为拼接后的瓦片阵列（水平拼接时输出尺寸为 S x (N*S)，垂直堆叠时为 (N*S) x S）。

**关键洞察**：条纹既不是待填充的目标也不是视觉装饰，而是一个二值控制信号——它的颜色序列编码了镜像模式，它的空间朝向编码了排列轴和翻转轴。从同一个对象中同时提取两种不同性质的信息是非显然的。
