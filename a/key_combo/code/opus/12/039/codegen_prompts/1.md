## 新题 1：嵌套深度编码载荷位移量

**组合逻辑**：[计数(counting)](创新：嵌套层数作为位移参数) + [循环位移(cyclic_roll)](已有) + [层序反转(layer_order_reversal)](已有) — 嵌套结构既是参数编码器又是变换目标

**来源原语**：计数(counting) ← 1190e5a7；循环位移(cyclic_roll) ← 79cce52d；层序反转(layer_order_reversal) ← 8dae5dfc；嵌套矩形层(nested_rect_layer) ← 8dae5dfc；控制列(control_column) ← 79cce52d；双轴偏移编码(dual_axis_offset) ← 79cce52d

**依赖链**：嵌套结构的层数 → 水平位移量；控制列中标记的行位置 → 垂直位移量；嵌套结构自身同时经历层序反转。位移量的推断和层序反转共享同一输入结构但产生不同输出，两者必须同时正确才能得到完整解。

将嵌套矩形的颜色层数作为载荷的水平循环位移量，控制列标记位置作为垂直位移量，同时反转嵌套结构自身的颜色层序。

**输入结构**：约 15x15 的网格。左半部分包含一个同心嵌套矩形结构（3~5 层不等，每层颜色不同，使用红(2)、蓝(1)、绿(3)、黄(4)等，层与层之间无间隙，最外层紧贴左半区边界）。左半区与右半区之间有一列宽为 1 的灰(5)色分隔列（即控制列），该列中恰好有一个非灰的标记像素（颜色为橙(7)），其余均为灰(5)。右半区为载荷区域，包含一个由多种颜色（与嵌套结构颜色无重叠）组成的非对称图案，占据整个右半区。生成约束：嵌套层数在 3~5 之间；载荷区域宽高均不小于嵌套层数；不同示例中嵌套层数和标记行位置均不同。

**规则**：
1. 识别灰(5)色控制列，将网格分为左侧嵌套区和右侧载荷区。
2. 对嵌套矩形结构逐层剥离（从最外层开始，每次剥去当前外边界的均匀颜色层），统计总层数 N。
3. 读取控制列中橙(7)标记像素的 0-based 行索引 M（从控制列顶部起算）。
4. 移除控制列。
5. 对载荷区域执行循环位移：向右循环移 N 列，向下循环移 M 行。
6. 对嵌套矩形结构执行层序反转：将第 k 层（从外到内编号 0..N-1）的颜色替换为第 (N-1-k) 层的原颜色，即最外层与最内层互换颜色，以此类推。
7. 输出由反转后的嵌套区和位移后的载荷区水平拼接而成（无控制列）。

**关键洞察**：嵌套矩形结构承担双重角色——它的层数是载荷位移的隐式参数，同时自身也是变换的目标。仅看单个示例无法区分层数计数规则与位移量的关系，需要对比不同嵌套深度的示例才能归纳出"层数 = 水平位移量"。
