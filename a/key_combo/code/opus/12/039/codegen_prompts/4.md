## 新题 4：恢复遮挡后按遮损比重涂色

**组合逻辑**：[遮挡恢复(occlusion_restore)](已有) + [计数(counting)](创新：计算遮挡比而非绝对面积) + [重涂色(recolor)](创新：遮挡比排名决定新颜色分配) — 恢复后的面积信息反馈到颜色决策

**来源原语**：遮挡恢复(occlusion_restore) ← c6e1b8da；计数(counting) ← 8597cfd7/1190e5a7；重涂色(recolor) ← 83302e8f/f76d97a5；实心矩形(solid_rectangle) ← c6e1b8da；两区域比较(region_comparison) ← 8597cfd7；图层优先级(layer_priority) ← e99362f0

**依赖链**：遮挡恢复 → 获得每个矩形的真实面积 → 计算遮挡像素数与真实面积之比 → 按遮挡比排序 → 用底部色条中对应位置的颜色重涂 → 以原始图层顺序绘制。遮挡比无法在恢复之前计算，色条位置无法在排序之前映射。

先恢复被遮挡的矩形，统计每个矩形的遮挡比例，再按比例排名从底部色条获取新颜色，最后以原始遮挡层序绘制。

**输入结构**：约 14x14 的网格，黑(0)背景。包含 3~4 个不同颜色的实心矩形（颜色为蓝(1)、红(2)、绿(3)、黄(4)等），彼此部分重叠，形成可辨认的遮挡层次关系（上方矩形覆盖下方矩形的部分区域，被遮挡部分的像素在输入中显示为上方矩形的颜色）。网格最底部一行为色条行：包含与矩形数量相同的单像素色块（颜色互不相同，与矩形颜色不重叠，可使用橙(7)、品红(6)、青(8)等），从左到右排列，其余为黑(0)。生成约束：每个矩形至少有一部分未被遮挡（以便识别其颜色和边界框的至少两个角点）；各矩形的遮挡比例互不相同；色条中的颜色数量等于矩形数量。

**规则**：
1. 识别所有实心矩形。对每个矩形，根据其可见像素推断完整边界框，将被遮挡区域恢复为该矩形的颜色，得到每个矩形的完整面积 A。
2. 统计每个矩形在输入中被其他矩形遮挡的像素数 O（即恢复后新增的像素数）。计算遮挡比 R = O / A。
3. 按遮挡比 R 从大到小对矩形排序。遮挡比最大的矩形排第 1，最小的排最末。
4. 读取底部色条行中从左到右的颜色序列。将排名第 k 的矩形重涂为色条中第 k 个颜色（k 从 1 开始）。
5. 移除底部色条行。
6. 按原始遮挡层序（从底层到顶层）逐层绘制重涂后的矩形：先绘制最底层矩形的完整区域，再绘制上方矩形覆盖其上。
7. 输出的网格行数比输入少 1（去掉色条行）。

**关键洞察**：色条的排列顺序不是直接对应矩形的左右位置或颜色编号，而是对应遮挡比排名——被遮挡越严重的矩形获得色条中越靠左的颜色。必须先恢复遮挡才能计算比例，必须计算比例才能确定颜色映射，仅看单个示例难以确定排序依据。
