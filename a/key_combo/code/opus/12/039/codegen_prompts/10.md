## 新题 10：灰色掩码从反转镜像嵌套中采样颜色

**组合逻辑**：[擦除(erase)](已有) + [层序反转(layer_order_reversal)](已有) + [镜像(mirror)](已有) + [洪泛填充(flood_fill)](创新：掩码像素按距离从变换后结构中采样颜色) — 层序反转和镜像改变了最近邻关系，掩码采样依赖变换后的空间布局

**依赖链**：嵌套结构层序反转 → 颜色重排 → 水平镜像 → 改变空间颜色分布；灰色掩码像素保留位置 → 从反转镜像后的嵌套结构中取最近颜色 → 掩码被重涂。层序反转和镜像必须在掩码采样之前完成，因为它们改变了最近颜色的分布。

嵌套矩形的颜色层序反转并水平镜像后，散布的灰色掩码像素从变换后的结构中按曼哈顿距离采样颜色。

**输入结构**：约 14x14 的网格，黑(0)背景。网格中央偏左有一个嵌套矩形结构（3~4 层同心矩形，由外到内颜色分别为如蓝(1)、红(2)、绿(3)、黄(4)，每层厚度 1~2 像素，最外层边界框约 8x8~10x10）。在嵌套结构外部的网格区域中，散布 5~8 个灰(5)色单像素（掩码像素），位置不规则分布于嵌套结构的上方、右侧和下方。另外还散布 2~4 个与嵌套结构同色的干扰像素（如蓝(1)或红(2)的孤立单像素），位于嵌套结构外部。生成约束：灰色掩码像素的位置使得其最近嵌套像素分布在不同层上（以便展示层序反转对采样的影响）；嵌套结构不在网格正中心（偏左），使得水平镜像产生可观察的位置变化；不同示例中嵌套层数和颜色排列不同。

**规则**：
1. 识别嵌套矩形结构，通过逐层剥离确定层序（从外到内）。
2. 将干扰像素（嵌套结构外部的非黑、非灰像素）擦除为黑(0)。
3. 对嵌套结构执行层序反转：最外层颜色 ↔ 最内层颜色，第二层 ↔ 倒数第二层，以此类推。
4. 对反转后的嵌套结构执行水平镜像（以嵌套结构自身的边界框垂直中轴为镜像轴），镜像后结构仍在其原始边界框位置内。
5. 对每个灰(5)掩码像素，计算它到反转镜像后的嵌套结构中每个非黑像素的曼哈顿距离。取距离最小的像素的颜色。若距离相同，取行号更小的像素；行号也相同则取列号更小的像素。
6. 将灰色掩码像素重涂为步骤 5 中确定的颜色。
7. 输出网格：黑色背景 + 反转镜像后的嵌套结构（在原位置）+ 重涂后的掩码像素（在原位置）。

**关键洞察**：灰色掩码像素是"探针"——它们从变换后（而非原始）嵌套结构中采样颜色。水平镜像改变了哪些嵌套像素距某个掩码最近，层序反转改变了那些像素的颜色——两个变换叠加后，掩码获得的颜色与直觉预期不同。仅看原始输入中掩码与嵌套结构的相对位置无法直接推出掩码颜色，必须先推断出层序反转和镜像两步变换。

1. `main(grid)` 必须实现新题描述中的确定性转换规则，不能只识别 `generate_input()` 的固定模板。禁止不同的input网格输出相同的output网格。
2. `generate_input()` 必须随机生成多样样例，不能固定死。随机维度应覆盖：网格大小、对象数量、位置、颜色、方向、形状参数或关键分支。注意若描述中存在若干，需实现而不是只有单个，包括object或者对应关系等等。且若涉及到最短路径，则输入网格中必涉及到多条路径，对选择造成干扰。

4. 禁止把 ARC 颜色 id 、亮度、拼写等当作人类不可见的数值语义参与排序、大小比较或隐藏映射。颜色变化必须有可见结构线索。注意颜色亮度、拼写等也是不可见信息，若描述中出现违规的颜色id或者亮度，可自行使用少量的固定颜色替代，但注意生成时要在三个以内输入输出网格中对所有变换100%覆盖度。
