## 新题 9：栅格分区计数定输出尺寸，增长色与萎缩色双区填充

**组合逻辑**：[计数(counting)](创新：同时用于结构计数和统计比较两种不同目的) + [选择(selection)](创新：按增长差选择两种颜色分别填充) + [裁剪(crop)](创新：输出尺寸由分区计数决定而非直接裁剪) — 分区结构编码输出维度，分隔线划分统计边界

**来源原语**：计数(counting) ← 1190e5a7/8597cfd7；选择(selection) ← 8597cfd7；裁剪(crop) ← 2dc579da（概念性：输出尺寸由输入结构决定）；分隔栅格(divider_grid) ← 1190e5a7；矩形区域(rectangular_region) ← 1190e5a7；横分隔线(divider) ← 8597cfd7；标记掩码(marker_mask) ← 8597cfd7；两区域比较(region_comparison) ← 8597cfd7；分区数定输出尺寸(partition_sets_size) ← 1190e5a7；最大增长差(maximum_growth_difference) ← 8597cfd7

**依赖链**：栅格分隔线 → 分区行数 R 和列数 C → 输出尺寸 RxC；灰色分隔线 → 上下半区划分 → 各颜色上下计数差 → 增长色（最大正差）和萎缩色（最大负差/最小差）→ 输出上半填增长色、下半填萎缩色。两种计数（结构性和统计性）在不同层面上共同决定输出。

栅格条数定输出维度，灰色分隔线上下两侧的颜色分布差异定输出的双色填充方案。

**输入结构**：约 18x18 的网格。有一种非黑非灰的前景色（如青(8)）构成若干全行线条和全列线条（线宽 1 像素），将网格分割为矩形区域矩阵（例如 3 行 x 4 列 = 12 个区域）。除此之外，有一条全宽灰(5)色水平线将网格大致分为上半部和下半部（灰线可能与某条青色横线重合，也可能独立存在于两条横线之间）。各矩形区域内散布单像素的彩色标记（颜色从蓝(1)、红(2)、绿(3)、黄(4)、橙(7)中选取），每个区域 0~3 个标记。网格背景色为黑(0)。生成约束：至少有 3 种标记颜色出现在上下两半区中；各颜色的上下分布差互不相同；灰线恰好有一条。

**规则**：
1. 识别全行/全列的青(8)分隔线。统计分隔线将网格分成的区域行数 R 和区域列数 C。
2. 识别灰(5)全宽水平分隔线，将网格分为上半区和下半区。
3. 对每种标记颜色，统计其在上半区的像素总数 U 和下半区的像素总数 D。计算增长差 G = D - U。
4. 选择增长差 G 最大的颜色作为"增长色"；选择增长差 G 最小的颜色作为"萎缩色"。
5. 输出一个 R 行 x C 列的纯色网格（每个像素对应原网格中的一个区域位置）：
   - 若 R 为偶数：上半部 R/2 行填增长色，下半部 R/2 行填萎缩色。
   - 若 R 为奇数：上半部 (R-1)/2 行填增长色，中间行填增长色，下半部 (R-1)/2 行填萎缩色。

**关键洞察**：栅格的物理分隔线编码了输出的抽象维度（行列数），而灰色线与栅格线属于不同的结构层——前者是统计边界，后者是空间分割。两种"计数"（分隔线数 vs 像素数比较）在不同抽象层次上协同决定输出，仅看一个示例无法同时确定尺寸规则和颜色选择规则。
