## 新题 5：标记选象限叠加，非标记象限缩微嵌入

**组合逻辑**：[裁剪(crop)](已有) + [透明叠加(transparent_overlay)](已有) + [缩小复制(shrink_copy)](创新：非选中象限缩小后嵌入叠加结果中心) — 同一分隔结构驱动全尺寸叠加与缩微嵌入两种不同操作

**来源原语**：裁剪(crop) ← 2dc579da；透明叠加(transparent_overlay) ← e99362f0；缩小复制(shrink_copy) ← 11e1fe23；分隔十字(separator_cross) ← 2dc579da/e99362f0；象限(quadrant) ← e99362f0；标记像素(marker_pixel) ← 2dc579da；图层优先级(layer_priority) ← e99362f0；象限位决定层序(quadrant_layer_order) ← e99362f0

**依赖链**：十字分隔 → 四象限提取；标记像素位置 → 区分主象限与副象限；主象限对齐叠加（层序由象限在网格中的位置决定）→ 得到基底画布；副象限 2:1 缩微 → 嵌入基底画布中心（层序同样由原象限位置决定）。标记选择、叠加、缩微三个操作相互约束。

四象限中标记象限全尺寸叠加为基底，非标记象限缩微后嵌入基底中心，所有层序由象限的原始网格位置决定。

**输入结构**：约 17x17 的网格（奇数边长，使十字恰好居中，每个象限为 8x8）。一条全宽行和一条全高列由品红(6)色组成十字分隔，将网格分为四个 8x8 象限。四个象限各有一种前景色（从蓝(1)、红(2)、绿(3)、黄(4)中选取）在黑(0)背景上组成一个 4-连通图案（4~10 像素的不规则形状）。恰好两个象限中各含一个橙(7)色标记像素（位于该象限图案外部的背景位置上）。生成约束：四个象限的图案颜色互不相同；标记像素所在的两个象限不相邻（即一个在左上/右下，一个在右上/左下，或一个在左上/右下对角等）；每个象限的图案边界框不超过 6x6，确保缩微后（4x4 范围内）不会与全尺寸图案严重冲突。

**规则**：
1. 移除品红(6)十字分隔线，提取四个 8x8 象限。
2. 包含橙(7)标记的两个象限为"主象限"，不含标记的两个为"副象限"。移除所有标记像素（还原为黑(0)背景）。
3. 将两个主象限按本地坐标对齐叠加到一个 8x8 画布上。层序规则：按象限在原网格中的位置编号（左上=0，右上=1，左下=2，右下=3），编号小的先绘制（作为底层），编号大的后绘制（作为顶层，覆盖冲突像素）。
4. 对每个副象限，执行 2:1 缩微：将 8x8 图案缩为 4x4（每 2x2 区域取左上像素值；若左上为背景则取该 2x2 区域中任一非背景像素；若全为背景则为背景）。
5. 将两个缩微副象限放置于叠加画布的中心 4x4 区域（行 2~5、列 2~5）。层序同样按原象限位置编号，编号小的先绘制，编号大的覆盖。缩微图案覆盖在主象限叠加结果之上。
6. 输出 8x8 画布。

**关键洞察**：标记像素不属于图案本身，而是象限的选择信号——有标记的象限提供全尺寸的背景层，无标记的象限被压缩后镶嵌在中心。仅看单个示例难以区分层序规则是由颜色还是由位置决定的，需要对比标记在不同象限组合中的示例。
