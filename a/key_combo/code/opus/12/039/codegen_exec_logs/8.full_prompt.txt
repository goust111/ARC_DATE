## 新题 8：十字射线分区后按区域形状分类填充

**组合逻辑**：[射线延伸(ray_extend)](创新：从十字图案八方向发射分区射线) + [洪泛填充(flood_fill)](创新：填充颜色由区域几何形状分类决定) + [选择(selection)](创新：孤立像素选中所在区域) — 射线创造的分区形状成为填充条件的判据

**来源原语**：射线延伸(ray_extend) ← fe9372f3/705a3229；洪泛填充(flood_fill) ← 83302e8f；选择(selection) ← 8597cfd7；十字图案(plus_pattern) ← fe9372f3；封闭背景区域(enclosed_bg) ← 83302e8f；孤立像素(isolated_pixel) ← 705a3229；网格边缘(grid_edge) ← fe9372f3/705a3229；八方向发射(eight_dir_emit) ← fe9372f3；射线遮挡分区(ray_partition) ← 1190bc91；完整与缺损区异色(intact_broken_differ) ← 83302e8f；投射到最近边界(projection_to_nearest_edge) ← 705a3229

**依赖链**：十字图案位置 → 八方向射线发射 → 射线将网格分割为若干区域 → 判断每个区域形状（矩形 vs 非矩形）→ 孤立像素标记所在区域 → 根据区域形状类别决定填充规则（直接填色 vs 颜色映射转换）。射线分区是填充的前提，区域形状分类是填充规则的选择条件。

从十字图案发射八方向灰色射线将网格分割为区域，含孤立彩色像素的区域被填充——矩形区域直接用像素颜色填充，非矩形区域用固定映射色填充。

**输入结构**：约 15x15 的网格，黑(0)背景。网格中有一个红(2)色五像素十字图案（中心一像素 + 四个基数方向邻居各一像素）。十字图案不在网格正中心（偏向某个象限），使得八方向射线将网格分成大小和形状各异的区域。另有 3~5 个孤立的单像素散布于网格中（颜色各不相同，从蓝(1)、绿(3)、黄(4)、橙(7)、品红(6)中选取），每个像素不在十字图案上也不在射线路径上。生成约束：十字图案的位置使得至少存在 2 个矩形区域和 2 个非矩形区域；每个孤立像素落在不同区域中；至少有一个孤立像素在矩形区域中，至少有一个在非矩形区域中。

**规则**：
1. 保留红(2)十字图案。
2. 从十字中心向 8 个方向（上、下、左、右、左上、右上、左下、右下）发射灰(5)色射线至网格边缘。基数方向（上下左右）射线为连续灰色像素；对角方向射线同样为连续灰色像素（沿 45 度斜线逐像素填充）。射线不覆盖十字图案本身的像素。
3. 射线和十字图案将网格分割为若干 4-连通背景区域（仅考虑黑(0)像素的连通分量）。
4. 对每个区域，计算其面积 S 和其 4-连通边界框面积 B。若 S = B，该区域为"矩形区域"；若 S < B，为"非矩形区域"。
5. 对每个包含孤立彩色像素的区域：
   - 若为矩形区域：用该像素的颜色填充整个区域。
   - 若为非矩形区域：用该像素颜色的固定映射色填充整个区域。映射关系为：蓝(1)↔黄(4)，绿(3)↔品红(6)，橙(7)↔青(8)。即若像素为蓝(1)则填黄(4)，若为黄(4)则填蓝(1)，以此类推。
6. 不包含孤立像素的区域保持黑(0)不变。

**关键洞察**：同一颜色的孤立像素在不同位置可能产生不同的填充结果——取决于它所在区域的几何形状是否为矩形。区域形状由十字图案的位置间接决定，仅看单个示例中某种颜色的填充结果无法确定颜色映射规则，必须对比矩形区域和非矩形区域中同色像素的不同表现。
