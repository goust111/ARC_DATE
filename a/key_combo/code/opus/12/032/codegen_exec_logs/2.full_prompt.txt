## 新题 2：递减模板沿对角射线印章

**组合逻辑**：[颜色索引模板(color_indexes_template)](已有) + [对角方向(diagonal_dir) + 角位控制射线(corner_controls_ray)](创新：从 2x2 种子扩展改为任意模板沿对角递减印章) + [递减填充(shrinking_fill) + 逐步缩短行程(progressively_shortened)](创新：递减逻辑从边缘行程改为模板层级裁剪)

**来源原语**：颜色索引模板、模板掩码、调色板、解码 ← 65b59efc；对角方向、种子块、角位控制射线、射线延伸 ← 1f0c79e5；递减填充、逐步缩短行程、外推 ← 9772c176

**依赖链**：种子像素颜色 → 查找匹配的模板 → 种子旁红像素的相对位置 → 编码对角方向 → 沿该方向逐步印章模板 → 每步印章时模板从外圈向内逐层裁剪 → 印章序列形成锥形渐消轨迹

在网格上，每个彩色种子像素通过颜色选择模板、通过相邻红像素选择对角方向，沿该方向反复印章所选模板，且每一步模板从外圈剥离一层像素，形成递减消逝的斜向轨迹。

**输入结构**：
- 网格约 18x18，黑(0)背景
- 网格左上角有 2~3 个模板，每个为 5x5 的单色连通图案（颜色各不相同，如绿(3)、青(8)、品红(6)），模板之间间隔至少 1 列背景；模板形状各异（一个可能是十字形、一个是 L 形等，均为 4-连通，像素数 8~15）
- 网格下半区域散布 2~4 个种子像素，每个种子的颜色与某个模板颜色相同
- 每个种子像素恰好有一个红(2)像素与其 8-邻域相邻，位于种子的四个对角方向之一（左上/右上/左下/右下）
- 生成约束：不同种子的对角方向可以不同；各种子沿其对角方向有至少 10 格空间供印章展开；种子的颜色分配使得每个模板至少被一个种子引用

**规则**：
1. 识别左上角的模板区域：每个模板是一个连续的单色非黑非红连通块，记录其颜色 C 和相对形状（以模板包围盒左上角为原点的像素坐标集合 S_C）。
2. 对每个种子像素（颜色为 C_seed、位置 (r_s, c_s)），找到颜色 C_seed 对应的模板 S_{C_seed}。
3. 确定该种子旁红(2)像素相对于种子的位置，得到对角方向向量 (dr, dc)，其中 dr, dc 各为 +1 或 -1。
4. 第 k 步印章（k = 0, 1, 2, ...）：将模板 S_{C_seed} 的包围盒中心对齐到位置 (r_s + k*dr*W, c_s + k*dc*W)，其中 W 为模板包围盒宽度与高度的较大值。但在第 k 步，从模板中移除所有距包围盒边缘不超过 k 像素的像素（即剥离 k 层外壳）。将剩余像素绘制到对应网格位置，颜色为 C_seed。
5. 当第 k 步剥离后模板像素为空（k 足够大使整个模板被剥完），或者模板中心已超出网格边界时，停止。
6. 第 0 步在种子位置印章完整模板。印章从 k=0 开始按 k 递增顺序绘制。k=0 的种子位置印章覆盖原始种子像素。
7. 输出中移除所有红(2)控制像素（替换为黑(0)背景）。多个种子的印章轨迹若有重叠，后绘制的（k 值更大的步骤）覆盖先绘制的；若来自不同种子的同一 k 步重叠，按种子行号从小到大的顺序绘制（行号大的覆盖行号小的）。

**关键洞察**：源题 1f0c79e5 中沿对角线复制的是固定的 2x2 方块，源题 9772c176 中递减的是一维边缘行程。此处将两者耦合——沿对角射线行进的是从模板外圈逐层裁剪的二维图案，产生了"锥形衰减轨迹"这一源题中不存在的视觉结构。颜色编码选择模板内容，空间编码选择方向，递减规则控制轨迹形态，三者缺一则逻辑不完整。
