## 新题 5：边界图例编码逐色反射轴

**组合逻辑**：[逐色独立变换(per_color_transform) + 包围盒内翻转(flip_within_bbox)](已有) + [编码映射(encoding_map) + 边界图例(border_legend)](创新：图例从编码移动方向改为编码反射轴类型) + [标记颜色对应(marker_color_match)](已有)

**来源原语**：逐色独立变换、包围盒内翻转、单色掩码、包围盒、镜像 ← e74e1818；编码映射、边界图例、颜色关联区域 ← 88e364bc；标记颜色对应、外部标记决定朝向 ← 94133066

**依赖链**：每种前景颜色匹配一个同色边界图例 → 图例内两个点的排列编码反射轴（水平排列→左右镜像，垂直排列→上下镜像，对角排列→转置）→ 对该颜色的掩码在其包围盒内执行对应反射 → 不同颜色获得不同的反射变换

网格中多种颜色的掩码各自需要在包围盒内反射，但反射轴不固定——每种颜色通过匹配边缘上同色图例来解码该颜色专属的反射方式。

**输入结构**：
- 网格约 14x14，黑(0)背景
- 3 种非黑颜色（如蓝(1)、绿(3)、橙(7)）各形成一个 4-连通的不规则掩码（5~12 像素），掩码之间不相邻，包围盒不重叠
- 每个掩码形状刻意不对称——上下不对称、左右不对称、也非对角对称——使得不同反射方式产生不同结果
- 网格最外圈边缘（第 0 行、最后一行、第 0 列、最后一列）上有 3 个小图例矩形，每个为 3x3，填充色分别为蓝(1)、绿(3)、橙(7)中的一种，与三种掩码一一对应
- 每个 3x3 图例的中心格子为灰(5)（固定中心点），另有一个灰(5)指示点位于图例的边缘格子上（非中心），其余格子保持图例的填充色。中心点与指示点的相对位置编码反射方式：若指示点在中心的正左或正右 → 该颜色掩码执行左右镜像；若指示点在中心的正上或正下 → 执行上下镜像；若指示点在中心的对角位置 → 执行沿主对角线转置
- 生成约束：三个图例编码的反射方式两两不同（一个左右、一个上下、一个转置）；图例放置在边缘且不与掩码的包围盒重叠；若某掩码被指定为转置，其包围盒必须为正方形（行数=列数），以保证转置后包围盒不变

**规则**：
1. 识别网格边缘上的 3 个 3x3 图例。每个图例的填充色 C 是非灰的那种颜色。
2. 在每个图例中找到两个灰(5)像素：中心像素 (r_center, c_center) 和指示像素 (r_ind, c_ind)。计算偏移 (dr, dc) = (r_ind - r_center, c_ind - c_center)。
3. 解码反射轴：若 dr = 0 且 dc != 0 → 左右镜像（水平翻转）；若 dr != 0 且 dc = 0 → 上下镜像（垂直翻转）；若 dr != 0 且 dc != 0 → 沿主对角线转置。
4. 对每种颜色 C 的掩码，找到其包围盒 [r0, r1] x [c0, c1]。
5. 执行该颜色对应的反射变换：
   - 左右镜像：掩码中每个像素 (r, c) 移至 (r, c0 + c1 - c)。
   - 上下镜像：掩码中每个像素 (r, c) 移至 (r0 + r1 - r, c)。
   - 主对角线转置：掩码中每个像素 (r, c) 移至 (r0 + (c - c0), c0 + (r - r0))。
6. 所有颜色独立处理，互不影响。输出中清除原始掩码像素（替换为黑(0)），在新位置绘制变换后的掩码。图例在输出中移除（替换为黑(0)）。

**关键洞察**：源题 e74e1818 中所有颜色统一执行垂直翻转，此处反射轴变成由外部图例逐色编码的参数——必须先解码图例才能确定每个掩码的变换方式。源题 88e364bc 的图例编码的是移动方向，此处创新为编码几何变换类型，两种编码机制的作用域从"区域内像素移动"变为"掩码整体几何变换"。
