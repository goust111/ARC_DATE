## 新题 7：转置后标记漂移驱动奇偶填充

**组合逻辑**：[沿主对角线转置(transpose_along_diagonal) + 对角对称(diagonal_symmetry)](已有) + [坐标奇偶匹配(coord_parity_match) + 填充(filling)](创新：转置改变标记坐标从而改变奇偶格点定义) + [碰撞停止(collision_stop)](创新：灰障碍阻断填充连通性)

**来源原语**：沿主对角线转置、对角对称、方阵、对角线、反射 ← 9dfd6313；坐标奇偶匹配、奇偶格点、标记像素、填充、同奇偶背景涂色 ← d492a647；碰撞停止 ← 88e364bc

**依赖链**：输入方阵含一条对角线和若干前景像素及一个特殊标记 → 转置方阵（对角线不动，前景像素行列互换）→ 标记像素的行列坐标在转置后改变 → 新坐标的奇偶性定义一个奇偶格点 → 从标记的新位置出发，沿该奇偶格点 4-连通扩散填充标记颜色 → 灰(5)障碍阻断填充连通性 → 最终图案由转置后的几何布局和奇偶格点共同决定

将一个含有对角线的方阵转置后，特殊标记像素的坐标发生变化，导致其奇偶格点定义改变；以新的奇偶格点为基础从标记位置出发扩散填充，灰障碍阻断连通。

**输入结构**：
- 网格为正方形，边长 11~15（奇数，保证对角线穿过中心），黑(0)背景
- 主对角线（从左上到右下）上所有格子为蓝(1)
- 灰(5)障碍像素散布在非对角线位置上，约 8~15 个，不形成大块连通区域，每个障碍为孤立单像素或 2 像素小块
- 恰好一个红(2)标记像素位于非对角线位置，且其行列坐标 (r_m, c_m) 满足 r_m != c_m（确保转置后位置改变）
- 可选：少量绿(3)前景像素散布于非对角线位置（作为装饰，转置后移动但不参与填充逻辑）
- 生成约束：红标记的转置前后奇偶组合不同——即 (r_m mod 2, c_m mod 2) != (c_m mod 2, r_m mod 2)，这等价于 r_m 和 c_m 的奇偶性不同（一奇一偶）；灰障碍不在对角线上

**规则**：
1. 对整个方阵执行主对角线转置：每个像素 (r, c) 的值移至位置 (c, r)。对角线上的像素（r = c）不动。转置后红标记从 (r_m, c_m) 移至 (c_m, r_m)。
2. 在转置后的网格上，读取红(2)标记的新坐标 (c_m, r_m)，计算奇偶格点：p_r = c_m mod 2, p_c = r_m mod 2。
3. 定义"格点格子"：转置后网格中所有满足 r mod 2 = p_r 且 c mod 2 = p_c 的格子。
4. 从红标记的新位置 (c_m, r_m) 出发，执行受限 4-连通扩散填充：填充扩展到所有通过格点格子 4-连通（仅沿上下左右方向，每步移动 2 格到达下一个格点格子）可达的格点格子上的黑(0)背景。扩散被以下条件阻断：(a) 目标格子不是格点格子；(b) 目标格子是灰(5)障碍；(c) 目标格子已有非黑颜色（蓝对角线、绿前景等）；(d) 从当前格点格子到目标格点格子的路径中间格子（非格点格子）包含灰(5)障碍——此条不适用，因为填充直接在格点格子间跳跃，不经过中间格子。
5. 所有被填充到达的格点背景格子涂为红(2)。红标记本身保持红(2)。
6. 未被填充的黑(0)格子、蓝(1)对角线、灰(5)障碍、绿(3)前景均保持转置后的状态。

**关键洞察**：转置看似只是几何变换，但它改变了红标记的坐标，从而改变了奇偶格点的定义——这是两个操作间的参数级耦合。求解者必须先执行转置才能知道该填充哪个奇偶格点，而奇偶格点反过来又在转置后的障碍布局中扩散，形成"几何变换改变参数、参数控制拓扑扩散"的推理链。灰障碍的位置在转置前后发生变化，进一步增加了预测难度。
