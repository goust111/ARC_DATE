## 新题 1：奇偶格点定义重力地面

**组合逻辑**：[坐标奇偶匹配(coord_parity_match)](创新：奇偶格点从"涂色目标"变为"物理地面拓扑") + [重力下落(gravity_drop)](已有) + [墙分隔区域(wall_partitions_regions)](已有)

**来源原语**：坐标奇偶匹配、奇偶格点、标记像素、同奇偶背景涂色 ← d492a647；重力下落、碰撞停止、封闭区域、编码映射 ← 88e364bc；墙分隔区域、连通区域、分隔墙 ← 62ab2642

**依赖链**：灰墙划分出独立区域 → 每个区域中蓝标记的坐标定义该区域的奇偶格点 → 奇偶格点决定哪些背景格子是"实心地面" → 黄像素在重力作用下仅能停靠在实心格子上 → 不同区域因标记位置不同产生不同的地面拓扑 → 相同重力规则在不同区域产生截然不同的落点分布

在灰墙分隔的多个区域中，每个区域内的蓝标记像素以其坐标奇偶性定义一个隐形地面格点，黄色像素在重力作用下仅降落并停靠在该格点对应的格子上。

**输入结构**：
- 网格约 14x14，黑(0)背景
- 灰(5)单像素宽直线墙将网格分为 3~4 个矩形区域（墙沿整行或整列贯穿，区域面积各不相同）
- 每个区域内恰好一个蓝(1)标记像素，位于该区域内部（非墙上）；不同区域的蓝标记在区域内的相对位置不同（如一个在偶行偶列、另一个在奇行偶列），从而产生不同的奇偶格点
- 每个区域的上半部分散布 2~4 个黄(4)可移动像素，彼此不相邻，且不与蓝标记同行
- 生成约束：黄像素初始不在区域最底行；每个区域至少有 3 行高度供黄像素下落；各区域的蓝标记奇偶组合不全相同（至少两个区域的格点不同）

**规则**：
1. 对每个灰墙分隔的矩形区域独立处理。
2. 读取该区域中蓝(1)标记像素的绝对坐标 (r_m, c_m)，计算 p_r = r_m mod 2、p_c = c_m mod 2。
3. 该区域内，满足 r mod 2 = p_r 且 c mod 2 = p_c 的黑(0)格子为"实心格子"；其余黑(0)格子为"透明格子"。蓝标记本身所在的格子视为实心格子。
4. 每个黄(4)像素向下移动（行号增大方向）。它跳过所有透明格子，在以下情况停止：(a) 到达一个实心格子，且该实心格子的正下方是透明格子、灰墙或区域底边界——像素停在该实心格子上；(b) 到达一个实心格子，且该格子正下方的实心格子已被另一个黄像素占据——像素停在当前实心格子上。
5. 处理顺序：在每个区域内，从行号最大的黄像素开始逐个向上处理（先安置最底部的，再安置上方的）。
6. 蓝(1)标记像素和灰(5)墙在输出中保持不变。若黄像素下落路径经过蓝标记所在格子，蓝标记不受影响，黄像素继续向下穿过（蓝标记格子不阻挡黄像素）。

**关键洞察**：奇偶格点在源题 d492a647 中用于"填涂颜色"，此处被创新为定义"重力可停靠的地面拓扑"——同一个 parity 机制从视觉效果变为物理约束。不同区域的标记位置不同导致地面格点不同，必须逐区域独立推断标记位置才能预测落点。

## 实现要求

1. `main(grid)` 必须实现新题描述中的确定性转换规则，不能只识别 `generate_input()` 的固定模板。禁止不同的input网格输出相同的output网格。
2. `generate_input()` 必须随机生成多样样例，不能固定死。随机维度应覆盖：网格大小、对象数量、位置、颜色、方向、形状参数或关键分支。注意若描述中存在若干，需实现而不是只有单个，包括object或者对应关系等等。且若涉及到最短路径，则输入网格中必涉及到多条路径，对选择造成干扰。

4. 禁止把 ARC 颜色 id 、亮度、拼写等当作人类不可见的数值语义参与排序、大小比较或隐藏映射。颜色变化必须有可见结构线索。注意颜色亮度、拼写等也是不可见信息，若描述中出现违规的颜色id或者亮度，可自行使用少量的固定颜色替代，但注意生成时要在三个以内输入输出网格中对所有变换100%覆盖度。

6. 若规则有多个分支，生成器不能长期固定成一个分支；应让分支在随机样例中合理出现。分支概率不必平均——难以发现的隐蔽分支（如少数情况下才触发的特殊规则）应适当提高出现概率，确保在 3 个训练示例中至少出现一次，否则求解者无法归纳该规则。对于颜色映射类规则，确保 2 个左右的示例即可覆盖所有映射关系（每种颜色→颜色的映射至少在某个示例中出现过）。
