## 新题 6：方向标记滑动穿越房间网格重涂色

**组合逻辑**：[滑动 slide](创新：标记不是滑向固定目标物，而是沿指示方向穿越整个房间网格) + [洪泛填充 flood_fill](创新：从分区后选边填充改为标记轨迹选中房间填充) + [重涂色 recolor](创新：重涂色的范围由滑动轨迹与房间网格的交集决定)

**来源原语**：滑动 slide / 行列对齐 row_col_aligned / 最近者进入内部 nearest_enters（参考题 d6e50e54），洪泛填充 flood_fill / 四连通分区 four_connected_partition（参考题 782b5218），重涂色 recolor（参考题 0d87d2a6），框架房间 framed_room / 走廊通道 corridor（参考题 3ad05f52），分隔墙 divider_wall（参考题 782b5218）

**依赖链**：识别房间网格结构 → 解读每个标记的方向指示 → 沿指示方向滑动标记穿越多个房间 → 标记轨迹经过的所有房间被重涂色为标记颜色。删去方向解读则不知道滑动方向；删去房间识别则不知重涂范围；删去重涂色则输出无变化。

灰色线条将网格分成房间阵列，每个方向标记沿指示方向穿越多个房间，所经房间全部涂为标记颜色。

**输入结构**：黑(0)背景网格，约 15x15。灰(5)水平线和竖直线将网格分隔为矩形房间阵列（3x3 或 3x4 等均可，灰线宽 1 像素）。每个房间是一个被灰线完全围合的黑色矩形区域。部分房间内包含一个由两个同色像素组成的 1x2 或 2x1 多米诺骨牌状标记（颜色取自 {红(2)、蓝(1)、绿(3)、黄(4)}，不同标记颜色不同）。多米诺骨牌的两个像素相邻：第一个像素（在该颜色中行号更小的，行号相同则列号更小的）为「锚点」，第二个像素的位置相对于锚点指示滑动方向（右方 → 向右滑动，下方 → 向下滑动，左方 → 向左滑动，上方 → 向上滑动）。生成约束：至少两个标记的滑动轨迹经过同一个房间（以展示冲突解决）；标记数量 2-4 个。

**规则**：
1. 对每个标记，确定其锚点和滑动方向。
2. 从标记所在房间开始，沿滑动方向逐个房间前进（穿越灰色分隔线），直到到达网格边界外侧的最后一个房间。标记经过的所有房间（包括起始房间）构成其「轨迹房间集合」。
3. 对轨迹房间集合中的每个房间，将其内部所有非灰像素（包括原有的标记像素）重涂为该标记的颜色。
4. 若两个标记的轨迹经过同一房间，该房间涂为锚点距该房间更近的标记的颜色（曼哈顿距离，以锚点像素到房间中心点计算）。若距离相等，涂为处理顺序靠后的标记的颜色。处理顺序：按标记锚点位置从上到下、从左到右。
5. 不在任何标记轨迹中的房间保持黑(0)。
6. 所有灰(5)分隔线像素保持不变。

**关键洞察**：多米诺方向不是指向某个目标对象（参考题 d6e50e54 中标记指向矩形），而是定义了一条扫描线穿越房间网格。标记轨迹与房间分区的交集决定了重涂范围——这是滑动操作与空间分区的结构性耦合，两者在源题中各自独立。
