## 新题 3：粗粒度压缩编码精灵镜像平铺指令

**组合逻辑**：[压缩 compress](创新：压缩结果从二元有/无扩展为三态——原样/镜像/空白) + [平铺 tiling](创新：非固定四象限铺展，由压缩模板控制) + [镜像 mirror](创新：是否镜像由压缩编码中的标记颜色决定)

**来源原语**：压缩 compress / 含标记涂标记色 marker_presence_color（参考题 e57337a4），平铺 tiling / 翻转形成对称铺展 mirror_symmetric_expand（参考题 62c24649），镜像 mirror（参考题 62c24649），标记像素 marker_pixel / 粗粒度块 coarse_block / 阵列排布 array_layout（参考题 e57337a4），精灵体 sprite（参考题 72ca375d）

**依赖链**：识别左半区精灵体并裁剪 → 压缩右半区为三态模板 → 模板每个单元决定放置原样精灵、镜像精灵还是空白 → 组装为平铺输出。删去压缩则不知道哪些位置放什么变体；删去镜像则无法生成正确的翻转版精灵体；删去裁剪则没有平铺内容。

将右半区的标记分布压缩为三态空间指令模板，根据模板用左半区的精灵体（原样或水平镜像）平铺生成输出。

**输入结构**：黑(0)背景网格，约 20x12。一条灰(5)竖直分隔线将网格分为左右两半。左半区包含一个小型单色精灵体（前景色如红(2)，3-5 像素宽、3-5 像素高，形状不对称以便区分原样与镜像）。右半区的尺寸在高和宽上均可被 3 整除，可视为 3x3 的等大矩形块阵列。每个块内部要么为空（全黑），要么散布有蓝(1)标记像素，要么散布有绿(3)标记像素。每个非空块内的标记只有一种颜色。生成约束：每个训练样例中至少有 2 个蓝标记块和 2 个绿标记块。

**规则**：
1. 从左半区裁剪精灵体至其边界框，得到高 h、宽 w 的精灵图案。
2. 对右半区进行 3x3 粗粒度压缩：对每个块，若块内含蓝(1)标记 → 编码为「原样」；含绿(3)标记 → 编码为「镜像」；无标记 → 编码为「空白」。
3. 构建 3x3 平铺输出网格（高 = 3h，宽 = 3w）：对 3x3 模板的每个单元 (i, j)：
   - 「原样」→ 在对应位置粘贴裁剪精灵体原样。
   - 「镜像」→ 在对应位置粘贴精灵体的水平镜像（左右翻转）。
   - 「空白」→ 在对应位置放置 h x w 的全黑矩形。
4. 输出即为组装完成的平铺网格。灰分隔线和右半区均不出现在输出中。

**关键洞察**：右半区不是一幅缩放后的图像（参考题 e57337a4 的压缩是「有/无」二元码），而是一套空间指令集——标记颜色编码变换类型（蓝=原样，绿=镜像），标记所在块的位置编码放置坐标。需要多个示例才能确认蓝→原样 vs. 绿→镜像的映射关系（单个示例中两个假设可能等价）。

## 实现要求

1. `main(grid)` 必须实现新题描述中的确定性转换规则，不能只识别 `generate_input()` 的固定模板。禁止不同的input网格输出相同的output网格。
2. `generate_input()` 必须随机生成多样样例，不能固定死。随机维度应覆盖：网格大小、对象数量、位置、颜色、方向、形状参数或关键分支。注意若描述中存在若干，需实现而不是只有单个，包括object或者对应关系等等。且若涉及到最短路径，则输入网格中必涉及到多条路径，对选择造成干扰。
3. 生成器必须保证输入满足 `main()` 的隐式假设：对象不重叠、不越界、特殊标记唯一或可区分、匹配关系无歧义、关键分支出现概率相同。
4. 禁止把 ARC 颜色 id 、亮度、拼写等当作人类不可见的数值语义参与排序、大小比较或隐藏映射。颜色变化必须有可见结构线索。注意颜色亮度、拼写等也是不可见信息，若描述中出现违规的颜色id或者亮度，可自行使用少量的固定颜色替代，但注意生成时要在三个以内输入输出网格中对所有变换100%覆盖度。
5. 输出样例要视觉清晰，人类必须能从输入输出对中肉眼辨认出规律。具体要求：避免对象粘连、覆盖关系混乱、同一像素多重语义；不同逻辑步骤产生的结果不要大面积层叠在一起导致无法分辨哪个颜色属于哪个步骤；输入中各元素之间保持足够间距，输出中新增的标记/填充/路径等应与背景和已有元素在颜色上有明显区分；若规则涉及多层叠加，生成时控制对象密度和尺寸，确保叠加区域只占少数像素而非铺满整个网格。
6. 若规则有多个分支，生成器不能长期固定成一个分支；应让分支在随机样例中合理出现。分支概率不必平均——难以发现的隐蔽分支（如少数情况下才触发的特殊规则）应适当提高出现概率，确保在 3 个训练示例中至少出现一次，否则求解者无法归纳该规则。对于颜色映射类规则，确保 2 个左右的示例即可覆盖所有映射关系（每种颜色→颜色的映射至少在某个示例中出现过）。
