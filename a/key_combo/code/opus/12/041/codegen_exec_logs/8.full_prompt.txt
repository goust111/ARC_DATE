## 新题 8：最短路径长度阈值决定端点重涂色

**组合逻辑**：[寻路 pathfinding](创新：路径长度被量化并用于分类决策，而非仅确定路径像素) + [重涂色 recolor](创新：重涂色的目标颜色不由接触或固有属性决定，而由路径长度阈值决定) + [计数 counting](创新：计数路径步数作为中间判据)

**来源原语**：寻路 pathfinding / 最短路径 shortest_path / 端点分量 endpoint_component（参考题 3ad05f52），重涂色 recolor / 接触则重涂 recolor_on_contact（参考题 0d87d2a6），走廊通道 corridor（参考题 3ad05f52），计数 counting（参考题 aaecdb9a）

**依赖链**：识别同色端点对 → 在迷宫中寻找最短路径 → 计算路径长度 → 长度与阈值比较 → 比较结果决定端点和路径的重涂颜色。删去寻路则无法确定长度；删去计数/比较则不知选哪种颜色；删去重涂则输出无变化。

在迷宫中找到同色端点对之间的最短路径，路径长度是否超过阈值决定了端点和路径被涂成哪种颜色。

**输入结构**：黑(0)背景网格，约 15x15。灰(5)像素构成迷宫墙壁（连通的灰色结构形成通道和死胡同）。迷宫中有 2-3 对同色端点：每对由两个相同颜色的单像素标记组成（如两个红(2)像素为一对、两个蓝(1)像素为一对、两个绿(3)像素为一对）。所有非墙壁、非端点像素为黑(0)（可通行）。生成约束：每对端点之间存在唯一最短 4-连通路径（无并列最短路径）；不同对的路径互不共享像素；训练样例中至少一对路径长度 <= 5 且至少一对 > 5。

**规则**：
1. 对每对同色端点，在可通行像素（黑色像素）中寻找 4-连通最短路径。
2. 计算路径长度（路径上的可通行像素数，不含两个端点本身）。
3. 若路径长度 <= 5：将两个端点和整条路径的所有像素涂为黄(4)。
4. 若路径长度 > 5：将两个端点和整条路径的所有像素涂为橙(7)。
5. 端点原有颜色被覆盖。灰色墙壁像素和不在任何路径上的黑色像素保持不变。

**关键洞察**：端点的原始颜色仅作为配对标识——在输出中完全被丢弃。输出颜色由路径长度这一全局迷宫属性决定。阈值 5 是一个隐含参数，必须通过比较多个示例中不同长度路径的输出颜色才能归纳得出（单个示例可能支持多种阈值假设）。
