## 新题 5：平移后自交取交集揭示形状内核

**组合逻辑**：[平移(translate)](创新：平移不用于移动像素到新位置，而是生成形状的副本以进行集合运算) + [透明叠加(transparent_overlay)](创新：不取并集而取交集) + [重涂色(recolor)](已有) + [颜色编码位移(color_encoded_disp)](创新：位移方向由边界标记的位置编码而非前景像素颜色编码)

**来源原语**：平移、颜色编码位移、颜色决定偏移(342dd610)；透明叠加、逐格对齐(dae9d2b5)；双面板背景交集(0c9aba6e)；边界标记、标记指定观察方向(f341894c)；重涂色(e0fb7511)

**依赖链**：边界标记的边缘位置 → 位移方向和距离 → 原始形状与位移副本的空间对齐 → 两者的逐像素交集决定输出形状。标记位置决定位移向量，位移向量决定副本位置，副本位置决定交集区域——三者串联且每步的输出实质改变下一步的输入。

在边框上放置一个标记像素，其所在边缘编码平移方向。将前景形状沿该方向平移固定距离生成副本，输出原始形状与副本的位置交集，以新颜色绘制。

**输入结构**：
- 约 12x12 网格，背景为黑(0)。
- 一个绿(3)的 4-连通前景形状，由 6~15 个像素组成，形状不规则但连通，不触碰网格边缘（距边缘至少 3 个像素）。
- 网格最外圈（边框行/列）上恰好有一个红(2)单像素标记，位于四条边中的某一条上。该标记不与绿(3)形状相邻。
- 生成约束：绿(3)形状在标记所指方向上的"厚度"大于 2（即沿该方向平移 2 后，交集非空）。

**规则**：
1. 识别红(2)边界标记的位置。标记所在边缘决定平移方向：上边缘 → 向下平移，下边缘 → 向上平移，左边缘 → 向右平移，右边缘 → 向左平移（即标记指向网格内部的方向）。
2. 平移距离固定为 2 个像素。
3. 将绿(3)形状沿确定的方向平移 2 像素，得到一个虚拟副本（不实际绘制）。
4. 在一个干净的黑(0)网格上（与输入同尺寸，不含标记和原始形状），在原始形状与虚拟副本重叠的每个像素位置涂上蓝(1)。
5. 不重叠的位置保持黑(0)。红(2)标记不出现在输出中。

**关键洞察**：这不是两个独立形状的并集（与 dae9d2b5/195ba7dc 不同），而是同一形状与自身平移副本的交集。交集揭示了形状在指定方向上的"内核"——沿该方向足够厚的部分。红(2)标记的边缘位置编码的不是颜色信息（与 f341894c 不同），而是几何操作的方向参数。
