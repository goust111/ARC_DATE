## 新题 6：封闭区域拓扑计数编码自身旋转角度后加框堆叠

**组合逻辑**：[旋转(rotate)](创新：旋转角度不由外部标记指定，而由输入形状自身的拓扑属性——封闭区域数量——隐式编码) + [拼接/副本堆叠(concatenate/copy_stacking)](已有) + [边框(frame)](已有) + [封闭区域(enclosed_region)](创新：封闭区域不作为涂色目标，而作为变换参数的编码载体)

**来源原语**：旋转、拼接、副本堆叠、边框(412b6263)；封闭区域、连通分量、面积排名(a8d7556c)

**依赖链**：红色形状的拓扑结构（包含几个完全封闭的黑色区域）→ 封闭区域计数 N → 旋转角度 = N x 90 度顺时针 → 旋转后的网格被复制并垂直堆叠 → 加蓝色边框输出。形状的拓扑决定了自身如何被变换——这是一种自编码结构，删去拓扑分析则无法确定旋转角度，删去旋转则堆叠结果错误。

统计前景形状内部的封闭区域数量作为旋转次数，对整个网格施加相应角度的顺时针旋转，然后将旋转结果复制两份垂直堆叠并加蓝色边框。

**输入结构**：
- 约 7x7 正方形网格，背景为黑(0)。
- 一个红(2)像素构成的较大连通形状，占据网格中央区域（约 15~30 个像素），形状不规则。
- 该红色形状内部可能包含 0~3 个完全封闭的黑(0)区域（"洞"）：每个洞是一个由红(2)像素在 4-连通意义下完全包围的黑(0) 4-连通分量，且该黑色分量不与网格边缘的黑色背景 4-连通相连。
- 输入中不包含蓝(1)像素。
- 生成约束：不同示例的封闭区域数量不同，以便求解者归纳计数与旋转的映射关系。

**规则**：
1. 识别红(2)形状内部的封闭黑(0)区域：找出所有不与网格四边的黑(0)背景 4-连通相连的黑(0) 4-连通分量，即为封闭区域。记其数量为 N。
2. 将整个网格顺时针旋转 N x 90 度（N=0 不旋转，N=1 旋转 90 度，N=2 旋转 180 度，N=3 旋转 270 度）。
3. 将旋转后的网格复制两份，垂直拼接（上下排列）。
4. 在拼接结果的外围添加 1 像素宽的蓝(1)边框。在上下两个副本之间也插入 1 行蓝(1)分隔行。
5. 边框和分隔行的四个角像素（最左和最右两端）涂为黑(0)而非蓝(1)。
6. 输出尺寸：宽 = 输入宽 + 2，高 = 输入高 x 2 + 3（上边框 1 行 + 上副本 + 分隔行 1 行 + 下副本 + 下边框 1 行）。

**关键洞察**：旋转角度没有通过任何显式标记或控制条给出——它编码在形状自身的拓扑结构中（孔洞数量）。求解者必须从多个示例中推断"孔洞数 = 旋转次数"这一隐含映射。形状既是被变换的对象，又是编码变换参数的载体，构成自指结构。
