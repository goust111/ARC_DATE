## 新题 7：风车拼贴后跨边界连通分量变色

**组合逻辑**：[旋转(rotate)](已有) + [拼接/阵列排布(concatenate/array_layout)](已有) + [重涂色(recolor)](创新：涂色判据不基于原始图中的属性，而基于拼贴构造后涌现出的跨象限连通性) + [连通性(connectivity)](创新：连通性不在原始输入中评估，而在旋转拼贴构造出的新空间中评估)

**来源原语**：旋转、拼接、正方形画布、阵列排布、四旋转组成风车(7fe24cdd)；重涂色、连通分量、连通性、面积大于一则涂(e0fb7511)

**依赖链**：原始小网格 → 四个旋转副本拼成 2x2 风车 → 拼贴在象限边界处产生新的像素邻接关系 → 跨越象限边界的 4-连通分量被识别 → 跨边界分量重涂为新颜色，单象限分量保持原色。旋转拼贴创造了源题中不存在的空间关系（边界邻接），而连通性评估在这个涌现的新空间上进行——两者紧密耦合。

将正方形输入旋转四次拼成风车形拼贴，然后检测跨越象限边界的前景连通分量并将其重涂为新颜色。

**输入结构**：
- 一个正方形网格（5x5 或 6x6），背景为黑(0)。
- 若干蓝(1)前景像素构成一个或多个小型 4-连通图形（总计 4~10 个蓝色像素），形状不对称（不具有 90 度旋转对称性，以确保不同旋转副本的边界对齐情况因示例而异）。
- 生成约束：至少存在一个旋转拼贴后跨越象限边界的连通分量，且至少存在一个不跨越边界的分量（以提供对比）。

**规则**：
1. 设输入为 NxN 的网格 G。构造 2Nx2N 的风车拼贴：
   - 左上象限：G 的原始副本。
   - 右上象限：G 顺时针旋转 90 度。
   - 左下象限：G 逆时针旋转 90 度（即顺时针 270 度）。
   - 右下象限：G 旋转 180 度。
2. 在 2Nx2N 拼贴中，识别所有蓝(1)像素的 4-连通分量。
3. 对每个分量，检查它是否包含来自两个或更多不同象限的像素（即该分量跨越了象限边界）。
4. 跨越象限边界的分量：将其所有像素重涂为红(2)。
5. 完全位于单个象限内的分量：保持蓝(1)不变。
6. 黑(0)背景不变。输出为 2Nx2N 的拼贴网格。

**关键洞察**：风车拼贴本身是确定性的（与 7fe24cdd 规则相同），但拼贴后哪些分量跨越边界取决于输入形状在各旋转方向上的边缘像素分布——这是一种涌现属性，仅凭原始小网格难以直接预判，必须实际构造拼贴后才能评估连通性。求解者需要同时在脑中旋转形状并追踪边界处的像素对齐。
