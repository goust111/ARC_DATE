## 新题 3：角括号几何长度编码位移量，内嵌标记指定擦除色

**组合逻辑**：[循环位移(cyclic_roll)](创新：位移量不由控制列的标记位置编码，而由角括号的臂长编码) + [擦除(erase)](创新：擦除目标不由独立的选择器确定，而由同一角括号内的标记确定) + [角括号(corner_bracket)](创新：角括号承担双重功能——几何属性编码变换参数，同时内部标记指定擦除对象)

**来源原语**：循环位移、行偏移编码、标记位定位移量(6d1d5c90)；擦除、角括号、标记在括号内部、按标记色选择同色、保留标记本身(1e81d6f9)

**依赖链**：角括号的短臂像素数 → 整体网格的行循环下移量 → 位移后的网格布局 → 标记颜色指定的像素在位移后的位置被擦除。角括号同时为两个操作提供参数，两个操作共享同一结构但提取不同信息维度。

读取角括号的短臂长度作为循环下移量，对网格行施加循环位移，然后擦除与括号内标记同色的所有像素（保留标记本身），最后移除角括号。

**输入结构**：
- 约 10x10 网格，背景为黑(0)。
- 一个灰(5)角括号：由两条互相垂直的灰(5)像素臂在一个角点处相连，形成 L 形开口结构。两臂长度不同（短臂 2~4 像素，长臂 4~7 像素，均含角点像素）。角括号位于网格的某个角落区域，朝向网格内部开口。
- 角括号的开口区域内（在角括号边界框内、角括号像素之外）恰好有一个标记像素，颜色为红(2)、蓝(1)或绿(3)之一。
- 网格其余区域包含一个由多种颜色（含标记同色）构成的图案，至少使用 3 种非背景、非灰(5)颜色。
- 生成约束：短臂长度严格小于网格行数；标记颜色在图案中至少出现 2 次。

**规则**：
1. 识别灰(5)角括号，测量其两臂的像素长度（含共享角点），取较短臂的长度 L。
2. 将整个网格的所有行循环下移 L 行（第 i 行移到第 (i+L) mod H 行，H 为网格高度）。此步包括角括号和标记像素自身也参与位移。
3. 位移后，读取角括号内标记像素的颜色 C。将网格中所有颜色为 C 的像素改为黑(0)背景，但标记像素本身保持颜色 C 不变。
4. 将角括号的所有灰(5)像素改为黑(0)背景。
5. 输出处理后的网格，尺寸不变。

**关键洞察**：角括号在源题中仅作为颜色选择器（通过内部标记指定擦除目标），但在本题中它同时承担了变换参数编码的角色——其几何尺寸（短臂长度）编码了循环位移量。求解者必须从同一结构中读取两种不同性质的信息（几何度量和颜色编码），且位移先于擦除执行，使得擦除的空间效果依赖于位移结果。
