## 新题 1：镜像缺陷定位与差异提取

**组合逻辑**：[镜像(mirror)](已有) + [提取(extract)](已有) + [擦除(erase)](已有) → 组合创新：镜像一致性验证作为缺陷检测条件，差异像素提取作为输出

**来源原语**：镜像(mirror)←0c786b71, 提取(extract)←d9fac9be, 四象限对称(four_quadrant_symmetry)←0c786b71, 颜色异常值选择(outlier_color_selection)←0b148d64, 裁剪(crop)←0b148d64

**依赖链**：必须先理解四象限镜像关系才能判断哪个象限不一致；必须通过对比重建"正确版本"才能定位差异像素；最终提取依赖于前两步的结果。三步缺一不可。

从一个被篡改的四象限镜像马赛克中找出破坏对称性的象限，提取其中与正确版本不同的像素。

**输入结构**：约 14×14 的网格，由一条水平和一条垂直的黑(0)分隔线将网格分为四个大小相同的象限（每个约 6×6）。四个象限中填有由蓝(1)和红(2)像素构成的图案（背景为黑(0)）。其中三个象限构成合法的镜像马赛克关系：右下象限为"原始"，左下为原始的左右镜像，右上为原始的上下镜像，左上为原始的180度旋转。第四个象限（被篡改的那个）总体形状与其应有的镜像版本一致，但其中恰好有 1~3 个像素的颜色被改动（从蓝(1)变为红(2)或反之，或从前景色变为黑(0)，或从黑(0)变为前景色）。生成约束：被篡改的象限在不同示例中位置不同（可能是任意一个象限）；篡改的像素数量和位置在不同示例中不同；三个未篡改象限严格满足镜像关系。

**规则**：
1. 识别四个象限及其分隔线位置。
2. 对每个象限，检验它与其他三个象限的镜像一致性：将其他三个象限按镜像关系映射到该象限的坐标系中，比较像素是否完全匹配。被篡改的象限与至少两个其他象限的映射不一致。
3. 利用三个一致象限中的任意一个，通过对应的镜像变换重建被篡改象限的"正确版本"。
4. 逐像素比较被篡改象限的实际内容与正确版本，找出所有不同的像素位置。
5. 输出一个与象限等大的网格（约 6×6），背景为黑(0)，仅在差异像素位置保留被篡改象限中的实际颜色。

**关键洞察**：异常象限的检测不是通过颜色频率（不同于 0b148d64 的颜色异常值），而是通过几何对称性验证——必须理解镜像变换才能判断哪个象限"不对"，这把镜像构造规则从生成工具变成了验证工具。

## 实现要求

1. `main(grid)` 必须实现新题描述中的确定性转换规则，不能只识别 `generate_input()` 的固定模板。禁止不同的input网格输出相同的output网格。
2. `generate_input()` 必须随机生成多样样例，不能固定死。随机维度应覆盖：网格大小、对象数量、位置、颜色、方向、形状参数或关键分支。注意若描述中存在若干，需实现而不是只有单个，包括object或者对应关系等等。且若涉及到最短路径，则输入网格中必涉及到多条路径，对选择造成干扰。
3. 生成器必须保证输入满足 `main()` 的隐式假设：对象不重叠、不越界、特殊标记唯一或可区分、匹配关系无歧义、关键分支出现概率相同。
4. 禁止把 ARC 颜色 id 、亮度、拼写等当作人类不可见的数值语义参与排序、大小比较或隐藏映射。颜色变化必须有可见结构线索。注意颜色亮度、拼写等也是不可见信息，若描述中出现违规的颜色id或者亮度，可自行使用少量的固定颜色替代，但注意生成时要在三个以内输入输出网格中对所有变换100%覆盖度。
5. 输出样例要视觉清晰，人类必须能从输入输出对中肉眼辨认出规律。具体要求：避免对象粘连、覆盖关系混乱、同一像素多重语义；不同逻辑步骤产生的结果不要大面积层叠在一起导致无法分辨哪个颜色属于哪个步骤；输入中各元素之间保持足够间距，输出中新增的标记/填充/路径等应与背景和已有元素在颜色上有明显区分；若规则涉及多层叠加，生成时控制对象密度和尺寸，确保叠加区域只占少数像素而非铺满整个网格。
6. 若规则有多个分支，生成器不能长期固定成一个分支；应让分支在随机样例中合理出现。分支概率不必平均——难以发现的隐蔽分支（如少数情况下才触发的特殊规则）应适当提高出现概率，确保在 3 个训练示例中至少出现一次，否则求解者无法归纳该规则。对于颜色映射类规则，确保 2 个左右的示例即可覆盖所有映射关系（每种颜色→颜色的映射至少在某个示例中出现过）。
