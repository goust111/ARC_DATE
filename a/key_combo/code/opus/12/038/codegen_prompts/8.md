## 新题 8：标记密度编码放大倍率的模板复制

**组合逻辑**：[选择](创新：最少标记选出模板而非直接输出) + [计数](创新：标记数编码缩放因子) + [像素放大](创新：放大倍率因对象而异，由计数结果决定) + [重涂色](创新：放大时用目标矩形的填充色替换模板的填充色) + [最少标记数](已有)

**来源原语**：选择(7bb29440), 裁剪(7bb29440), 前景矩形(7bb29440), 标记像素(7bb29440), 最少标记数(7bb29440), 计数(37ce87bb), 像素放大(46f33fce), 缩放(46f33fce), 重涂色(9caf5b84)

**依赖链**：标记数最少的矩形被选为模板（选择）→ 其他矩形各自的标记数成为各自的缩放因子（计数→缩放因子）→ 模板按缩放因子放大并重涂为各目标矩形的填充色（像素放大+重涂色），替换各目标矩形

最稀疏的对象成为蓝图，其余对象的内部标记密度编码了蓝图应被放大到多大——密度即倍率指令。

**输入结构**：约 15x15 的黑(0)背景网格。网格中有 3~5 个互不相邻的实心前景矩形（每个矩形为一种颜色的实心区域，不同矩形颜色各不相同，如红(2)、蓝(1)、绿(3)、黄(4)），尺寸均为 3x2 或 2x3。每个矩形内部有 0~3 个灰(5)标记像素（标记覆盖了矩形填充色的对应格）。生成约束：恰好有一个矩形的标记数严格最少（无平局），且该矩形标记数为 0 或 1；其他矩形的标记数均 >= 2，互不相同且不超过 3。各矩形之间间距足够大，放大后的对象不会重叠或超出网格边界。

**规则**：
1. 统计每个前景矩形内部灰(5)标记像素的数量。
2. 标记数严格最少的矩形成为"模板"。裁剪该模板（保留其形状和内部标记的相对位置），记录其填充色为"模板色"。
3. 对于每个非模板矩形：
   a. 取其标记数 n 作为缩放因子。
   b. 将模板按 n 倍放大（每个像素变为 n x n 的块）。
   c. 将放大后图案中的"模板色"像素全部替换为该非模板矩形自身的填充色。灰(5)标记像素放大后仍为灰(5)。
   d. 将放大后的图案放置到以该非模板矩形原始边界框左上角为锚点的位置，覆盖原矩形及其周围的黑色区域。
4. 模板矩形本身保持原尺寸、原位置、原颜色不变。
5. 生成约束：所有放大后图案不会相互重叠，也不会超出网格边界，也不会覆盖模板矩形。

**关键洞察**：灰色标记在模板选择和放大倍率中起双重作用——数量最少使一个矩形成为蓝图，而其他矩形的标记数量则编码了该蓝图应被放大的倍率；标记不是噪声，而是元指令。

## 实现要求

1. `main(grid)` 必须实现新题描述中的确定性转换规则，不能只识别 `generate_input()` 的固定模板。禁止不同的input网格输出相同的output网格。
2. `generate_input()` 必须随机生成多样样例，不能固定死。随机维度应覆盖：网格大小、对象数量、位置、颜色、方向、形状参数或关键分支。注意若描述中存在若干，需实现而不是只有单个，包括object或者对应关系等等。且若涉及到最短路径，则输入网格中必涉及到多条路径，对选择造成干扰。
3. 生成器必须保证输入满足 `main()` 的隐式假设：对象不重叠、不越界、特殊标记唯一或可区分、匹配关系无歧义、关键分支出现概率相同。
4. 禁止把 ARC 颜色 id 、亮度、拼写等当作人类不可见的数值语义参与排序、大小比较或隐藏映射。颜色变化必须有可见结构线索。注意颜色亮度、拼写等也是不可见信息，若描述中出现违规的颜色id或者亮度，可自行使用少量的固定颜色替代，但注意生成时要在三个以内输入输出网格中对所有变换100%覆盖度。
5. 输出样例要视觉清晰，人类必须能从输入输出对中肉眼辨认出规律。具体要求：避免对象粘连、覆盖关系混乱、同一像素多重语义；不同逻辑步骤产生的结果不要大面积层叠在一起导致无法分辨哪个颜色属于哪个步骤；输入中各元素之间保持足够间距，输出中新增的标记/填充/路径等应与背景和已有元素在颜色上有明显区分；若规则涉及多层叠加，生成时控制对象密度和尺寸，确保叠加区域只占少数像素而非铺满整个网格。
6. 若规则有多个分支，生成器不能长期固定成一个分支；应让分支在随机样例中合理出现。分支概率不必平均——难以发现的隐蔽分支（如少数情况下才触发的特殊规则）应适当提高出现概率，确保在 3 个训练示例中至少出现一次，否则求解者无法归纳该规则。对于颜色映射类规则，确保 2 个左右的示例即可覆盖所有映射关系（每种颜色→颜色的映射至少在某个示例中出现过）。

8. 可以在目标目录放公共 helper 文件，或从 `arc_utils.py` 摘取少量必要函数；若只实现一道题，优先保持目标文件自包含，减少额外依赖。
