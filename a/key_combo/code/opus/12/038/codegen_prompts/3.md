## 新题 3：揭露隐藏障碍的方向性滑动

**组合逻辑**：[擦除](创新：擦除对象不是前景主体而是障碍的遮罩) + [滑动](创新：滑动方向由行程颜色编码) + [遮挡](来自遮挡题，用于隐藏障碍) + [靠近障碍停止](已有)

**来源原语**：擦除(3345333e), 填充矩形(3345333e), 遮挡(3345333e), 滑动(9c56f360), 可移动行程(9c56f360), 固定障碍(9c56f360), 靠近障碍停止(9c56f360)

**依赖链**：擦除遮罩矩形暴露被隐藏的障碍 → 障碍的完整集合决定滑动终点 → 行程颜色决定滑动方向（非来自任一源题的结构关系）

先撕掉遮罩露出隐藏的障碍像素，再根据行程颜色决定滑动方向——向左还是向右取决于行程自身的颜色。

**输入结构**：约 12x15 的网格，背景为黑(0)。网格中有两种颜色的水平行程：红(2)行程和蓝(1)行程，每种各 2~4 个，分布在不同行中，每个行程宽 2~5 像素，紧贴网格的左边缘或右边缘。另有绿(3)孤立单像素散布在网格中作为障碍（每行 0~2 个）。此外，有 1~2 个黄(4)实心矩形（宽 2~4、高 2~4）覆盖了部分绿(3)障碍像素——这些障碍被遮挡而不可见。生成约束：每个行程所在行至少有一个障碍（可能被遮挡），且遮挡矩形下至少隐藏了一个障碍。

**规则**：
1. 识别所有黄(4)实心矩形（4-连通同色连通分量且为矩形形状）并擦除为黑(0)，暴露其下方被覆盖的绿(3)障碍像素。
2. 红(2)行程向左滑动：在其所在行内向左移动，遇到最近的绿(3)障碍像素时停在障碍右侧相邻格（行程左端紧贴障碍右侧）；若该行无障碍则滑到最左列。
3. 蓝(1)行程向右滑动：在其所在行内向右移动，遇到最近的绿(3)障碍像素时停在障碍左侧相邻格（行程右端紧贴障碍左侧）；若该行无障碍则滑到最右列。
4. 行程滑动后原位置变为黑(0)，行程保持其长度和颜色不变。绿(3)障碍像素（含被揭露的）保持原位。
5. 生成约束：黄(4)矩形不会覆盖任何行程像素，只覆盖障碍像素和背景像素。不同行程的滑动路径互不冲突（不同行）。

**关键洞察**：擦除遮罩前可见的障碍是不完整的——若仅按可见障碍计算滑动终点，部分行程会滑过头或滑到错误位置；真正的终点由遮罩下隐藏的障碍决定。
