## 新题 1：频率定角色的滑动与重涂

**组合逻辑**：[频率排序](创新：频率决定像素角色而非筛选) + [滑动](已有) + [重涂色](创新：重涂色由滑动落点决定) + [同行阻挡](已有) + [靠近障碍停止](已有)

**来源原语**：频率排序(9caf5b84), 滑动(9c56f360), 重涂色(2204b7a8/9caf5b84), 同行阻挡(9c56f360), 靠近障碍停止(9c56f360), 可移动行程(9c56f360), 固定障碍(9c56f360), 标记像素(2204b7a8)

**依赖链**：全局频率统计为每种颜色分配角色（移动者/障碍/标记）→ 障碍位置约束移动者的滑动终点 → 滑动后移动者所在行决定同行标记的重涂色

输入中三种前景色扮演的角色由各自的全局像素数决定：最多的滑动、次多的阻挡、最少的被重涂——频率即指令。

**输入结构**：约 10x15 的网格，背景为黑(0)。恰好有三种前景色（如红(2)、蓝(1)、绿(3)），每种颜色的总像素数互不相同（生成约束）。其中一种颜色以连续水平行程（3~6 像素宽）出现在若干行的右边缘，另一种颜色以孤立单像素散布在网格各处，第三种颜色同样以孤立单像素出现但数量最少。同一行内最多有一个行程和若干孤立像素。哪种颜色承担哪种形态在不同示例中不固定——唯一确定角色的线索是全局像素总数。

**规则**：
1. 统计整个网格中每种前景色的总像素数。最多的色为"移动色"，次多的为"障碍色"，最少的为"标记色"。
2. 每一行中，移动色的连续行程向左滑动，遇到同行中最近的障碍色像素时停在其右侧相邻格；若同行无障碍色像素则滑到最左列。移动色行程保持其长度和颜色不变，原位置变为黑(0)。
3. 障碍色像素位置不变。
4. 滑动完成后，对于每个标记色像素：若该像素所在行存在移动色行程（已滑到新位置），则将标记色像素重涂为移动色；若该行无移动色行程，则将标记色像素变为黑(0)（擦除）。
5. 生成约束：三种前景色的总像素数两两不同且差距明显（至少相差 3），保证角色分配无歧义。

**关键洞察**：同一种形态（孤立像素）在不同示例中可能扮演障碍或标记的不同角色——角色不由形态决定，而由全局频率决定；必须对比多个示例才能排除"按颜色身份硬编码角色"的假说。
