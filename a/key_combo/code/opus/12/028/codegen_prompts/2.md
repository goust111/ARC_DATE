## 新题 2：象限标记的方向条纹填充

**组合逻辑**：[对角映射/标记块→象限区域]（颜色选择） + [交替填色/条纹]（图案生成） + [象限几何→条纹方向（创新）]

**来源原语**：填充/标记块/象限区域/对角映射/标记色填对角区（93b581b8），交替填色/条纹/阵列排布/奇偶决定颜色（db3e9e38），平铺/种子像素/种子定条纹周期（0a938d79）

**依赖链**：2x2 标记块通过对角映射指定每个象限的颜色（源自 93b581b8），但填充方式不是实心色块，而是交替条纹（源自 db3e9e38/0a938d79）。条纹方向由象限区域自身的宽高比决定——这是一个在源题中不存在的新条件，将标记块的颜色指派与象限的几何属性交织在一起。

2x2 标记块通过对角映射指派各象限颜色，但每个象限以交替条纹方式填充，条纹方向由该象限自身的宽高比决定。

**输入结构**：黑(0)背景，网格尺寸至少 10x10（行数与列数不必相等）。网格内有且仅有一个 2x2 前景块，四个像素使用四种互不相同的非黑颜色（如左上红(2)、右上蓝(1)、左下黄(4)、右下绿(3)）。2x2 块不在网格的精确几何中心，其上下左右各至少有 3 行/列的空间。生成约束：网格的行数和列数不相等，且 2x2 块的位置使得四个象限区域中至少有一个宽>高、至少有一个高>宽。

**规则**：
1. 保留 2x2 标记块不变。
2. 标记块将网格分为四个象限区域（标记块本身不属于任何象限）。每个标记像素通过对角映射指定对面象限的填充颜色：左上像素→右下象限，右上像素→左下象限，左下像素→右上象限，右下像素→左上象限。
3. 对每个象限区域，计算其宽度（列数）和高度（行数）：
   - 若宽度 > 高度：绘制水平交替条纹。从该象限最靠近标记块的那一行开始，第一行填指定颜色，第二行填黑(0)，第三行填指定颜色，依此交替，直到象限边界（被网格边缘裁剪）。
   - 若高度 > 宽度：绘制垂直交替条纹。从该象限最靠近标记块的那一列开始，第一列填指定颜色，第二列填黑(0)，第三列填指定颜色，依此交替。
   - 若宽度 == 高度：整个象限实心填充指定颜色（不使用条纹）。
4. 条纹仅覆盖象限内的像素，不侵入标记块或其他象限。

**关键洞察**：同一个 2x2 标记块既编码颜色分配（对角映射），又间接决定各象限的几何形状（标记块的偏心位置造成各象限宽高比不同）。颜色规则和方向规则必须同时正确才能得到正确输出，而方向规则需要对比多个不同标记位置的示例才能归纳。
