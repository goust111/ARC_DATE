## 新题 4：方块参数化网格与对角射线弹射

**组合逻辑**：[边长决定间距 + 生成网格](已有) → [射线延伸 + 碰撞反弹](已有，但反射面从实心矩形变为刚生成的网格线——创新：网格线作为反射面是两道源题中都不存在的结构关系)

**来源原语**：生成网格/generate_grid、实心方块/solid_square、网格线/grid_line、边长决定间距/side_length_determines_spacing、等距参数化/uniform_parameterized_spacing（来自 695367ec）；射线延伸/ray_cast、对角线段/diagonal_segment、碰撞反弹/collision_bounce、射线遇障碍翻转/ray_flips_on_obstacle、反射/reflect、射线路径/ray_path（来自 508bd3b6）

**依赖链**：方块边长决定网格间距 → 网格线的位置决定射线反弹的时机和方向 → 射线路径完全由网格参数和初始方向共同决定。不同的方块边长产生不同的网格布局，即使初始射线方向相同，最终弹射图案也完全不同。网格生成不是装饰背景而是射线行为的决定性约束。

用输入方块的边长生成等距网格线，然后从一个对角种子线段出发射出对角射线，射线遇网格线即反弹，直到回到起点或到达网格边界。

**输入结构**：约 21x21 的黑(0)背景网格（尺寸形如 k*(s+1)，其中 s 为方块边长，k 为格子数，保证网格线恰好铺满）。网格中有一个红(2)实心方块，边长 s 为 2-4 像素，位于网格某个角落或边缘区域。另有一段青(8)对角线段（2 个像素，相邻且在对角方向上），位于网格中远离红方块的位置。对角线段不与网格边缘重合。生成约束：网格尺寸确保网格线从第 s 列/行开始，每隔 s+1 个像素出现一条完整行/列；对角线段的起始位置不在将要生成的网格线上。

**规则**：
1. 读取红(2)方块的边长 s。
2. 在黑(0)背景上绘制灰(5)网格线：在第 s 列、第 2s+1 列、第 3s+2 列……画完整的纵向线（整列涂灰(5)）；在第 s 行、第 2s+1 行、第 3s+2 行……画完整的横向线（整行涂灰(5)）。列号和行号从 0 开始计数。
3. 保持红(2)方块不变（方块像素覆盖在网格线上层）。
4. 确定青(8)对角线段的方向（NE/NW/SE/SW）：两个像素的相对位置定义初始射线方向。取靠近网格中心的那个像素作为射线发射点。
5. 从发射点沿初始对角方向逐像素前进，将经过的像素涂为绿(3)。当射线的下一个目标像素是灰(5)网格线时：若碰到的是水平网格线（横向线），翻转垂直分量（上变下或下变上）；若碰到的是垂直网格线（纵向线），翻转水平分量；若碰到交叉点（两条网格线的交叉像素），同时翻转水平和垂直分量。射线不进入灰色像素，在碰撞点的前一个像素处转向。
6. 射线在以下任一条件下终止：(a) 回到发射点，形成闭合环路；(b) 到达网格边界（行号或列号超出网格范围）。
7. 青(8)对角线段保持原色。绿(3)射线像素覆盖在黑(0)背景上但不覆盖灰(5)网格线、红(2)方块或青(8)线段。

**关键洞察**：网格线在源题 695367ec 中是纯装饰性的输出，在源题 508bd3b6 中反射面是给定的红色矩形。本题的创新在于：一个操作（生成网格）的输出成为另一个操作（射线弹射）的结构约束——网格线既是视觉产物又是物理反射面。改变方块边长一个像素就会完全重排网格线位置，导致射线路径全局性地改变。
