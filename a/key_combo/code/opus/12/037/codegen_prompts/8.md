## 新题 8：控制像素多重编码射线方向与长度

**组合逻辑**：[控制像素 + 计数决定扩展量](已有，但"扩展量"重新解释为射线长度——创新) + [质心偏移定向](已有，但偏移对象从精灵体体块变为块内控制像素——创新) → [射线延伸](已有) + [碰撞反弹](已有，但弹射面是其他方块而非预设障碍——创新)

**来源原语**：矩形块/rectangular_block、控制像素/control_pixel、计数决定扩展量/count_determines_expansion、编码映射/encoding_map（来自 52fd389e）；射线延伸/ray_extend、质心偏移定向/centroid_bias_dir、方向精灵体/directional_sprite（来自 13f06aa5）；碰撞反弹/collision_bounce、射线遇障碍翻转/ray_flips_on_obstacle、反射/reflect（来自 508bd3b6）；擦除/erase（来自多题）

**依赖链**：同一组控制像素同时编码两个参数——数量编码射线长度，空间分布编码射线方向。这两个参数缺一不可：方向正确但长度错误 → 射线终止位置错误；长度正确但方向错误 → 射线目标完全偏离。此外，射线碰到其他方块时反弹，因此各方块的射线之间存在空间交互。

从每个方块射出一条射线，射线方向由块内控制像素相对于块中心的偏移反向决定，射线长度等于控制像素数量，遇到其他方块时反弹并继续。

**输入结构**：约 18x18 的黑(0)背景网格。4-6 个小型矩形方块，每个方块主体由黄(4)像素组成（3x3 到 4x4 像素），内部嵌入 1-4 个红(2)控制像素。红色像素在方块内偏向某一侧（非居中分布），使得红色像素的质心与方块整体质心之间存在明确的偏移方向。不同方块的控制像素数量不同。方块之间间距不小于 4 像素。生成约束：每个方块内的红色像素质心与方块质心的偏移量化到四个基本方向（上/下/左/右）后唯一确定；各方块的射线路径在当前布局下不产生歧义（射线不同时碰到两个方块的边界）。

**规则**：
1. 对每个黄(4)方块，识别其中的红(2)控制像素。
2. 计算控制像素的数量 n——这是该方块射线的最大行进距离（以像素为单位）。
3. 计算控制像素的质心 C_r 和方块所有像素（含控制像素）的质心 C_b。计算从 C_b 到 C_r 的偏移向量，取其反方向——这是射线的发射方向。将此方向量化到四个基本方向（上/下/左/右）中偏移分量绝对值最大的那个方向。若水平和垂直偏移相等，取水平方向（左或右）。
4. 从方块在射线方向上的边界像素的外侧第一个像素开始，沿射线方向逐像素绘制绿(3)像素，每绘制一个像素消耗 1 步距离。
5. 若射线在耗尽 n 步之前碰到另一个黄(4)方块的边界，射线在碰撞点前一个像素处反弹：翻转射线方向为反方向（上变下、左变右），继续以剩余步数绘制。一条射线最多反弹一次（若反弹后再次碰到方块，射线在碰撞前一个像素处终止）。
6. 射线到达网格边界时直接终止（即使步数未耗尽）。
7. 所有原始方块保持不变（黄色和红色像素不被覆盖）。绿(3)射线像素仅绘制在黑(0)背景上。

**关键洞察**：同一组红色像素被"读取两次"——一次数个数（编码射线长度），一次看位置分布（编码射线方向）。在源题 52fd389e 中控制像素只编码一个量（膨胀距离），在源题 13f06aa5 中方向编码来自体块像素而非内嵌标记。本题的创新是单一输入特征的双重解码，两次解码的结果协同决定了一个复合行为。
