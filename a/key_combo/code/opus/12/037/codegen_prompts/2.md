## 新题 2：条纹去噪后路径吸色反转

**组合逻辑**：[去噪 + 主色占优](已有) → [端到端遍历](已有) → [颜色序列反转](已有，但作用对象从路径自身颜色变为路径沿途吸收的外部条纹颜色——创新)

**来源原语**：去噪/denoise、主色占优/dominant_color、主色覆盖全行列/dominant_fills_line、条纹行列/stripe_line、噪声像素/noise_pixel（来自 e26a3af2）；颜色序列反转/reverse_color_seq、端到端遍历/endpoint_traversal、单像素宽路径/one_pixel_path、端点像素/endpoint_pixel、形状不变仅反色序/shape_fixed_reversed（来自 5792cb4d）

**依赖链**：去噪改变了每行的颜色值，路径遍历读取的条纹颜色取决于去噪结果，颜色反转的输入序列取决于路径遍历的读数。三个环节形成严格的数据依赖链：去噪不正确 → 读取的条纹色错误 → 反转后的序列错误。同时，路径的几何走向决定了它穿越条纹的顺序，因此路径形状也影响最终结果。

清洗含噪水平条纹至各行主色，然后沿一条蜿蜒路径读取其所穿过的行主色序列，将该序列反转后重新涂回路径像素。

**输入结构**：约 15x15 的网格，由水平行条纹构成——每行有一个主色（从蓝(1)、红(2)、黄(4)、灰(5)、品红(6)、橙(7)、栗(9)中选取，相邻行颜色不同），每行含 1-3 个噪声像素（颜色为其他条纹色或黑(0)，但不是绿(3)）。一条绿(3)的 4-连通单像素宽路径蜿蜒穿过网格，从网格某一边的一个像素出发，到达另一边的一个像素结束，路径恰好有两个端点且无分支。路径跨越至少 4 个不同条纹行。生成约束：绿(3)不作为任何条纹的主色或噪声色；路径的每个像素所在行的主色即使去掉该路径像素后仍可由剩余像素的众数唯一确定。

**规则**：
1. 对每一行，统计该行中所有非绿(3)像素的颜色频次，频次最高的颜色即为该行的主色。将该行所有非绿(3)像素涂为主色（去噪）。
2. 找到绿(3)路径的两个端点（仅有一个绿色 4-邻居的绿色像素）。选择行号较小的端点作为起点；若行号相同则选列号较小的。
3. 从起点沿 4-连通路径遍历到终点，对路径上的每个像素，记录其所在行的主色（步骤 1 确定的），得到颜色序列 S = [c_1, c_2, ..., c_n]。
4. 将 S 反转为 S' = [c_n, c_{n-1}, ..., c_1]。
5. 按遍历顺序，将路径的第 i 个像素涂为 S'[i]。
6. 非路径像素保持步骤 1 去噪后的状态。

**关键洞察**：路径自身不携带需要反转的颜色信息——它必须从外部环境（已去噪的条纹）"采样"颜色。去噪步骤不是独立的预处理，而是为反转步骤提供正确输入的必要前置条件。仅看单个示例对，若噪声恰好不影响路径像素所在行的主色判断，可能误以为不需要去噪；必须对比含不同噪声分布的多个示例才能确认去噪是规则的一部分。

  the output is the clean striped canvas hidden under the noise.

## 实现要求

1. `main(grid)` 必须实现新题描述中的确定性转换规则，不能只识别 `generate_input()` 的固定模板。禁止不同的input网格输出相同的output网格。
2. `generate_input()` 必须随机生成多样样例，不能固定死。随机维度应覆盖：网格大小、对象数量、位置、颜色、方向、形状参数或关键分支。注意若描述中存在若干，需实现而不是只有单个，包括object或者对应关系等等。且若涉及到最短路径，则输入网格中必涉及到多条路径，对选择造成干扰。
3. 生成器必须保证输入满足 `main()` 的隐式假设：对象不重叠、不越界、特殊标记唯一或可区分、匹配关系无歧义、关键分支出现概率相同。
4. 禁止把 ARC 颜色 id 、亮度、拼写等当作人类不可见的数值语义参与排序、大小比较或隐藏映射。颜色变化必须有可见结构线索。注意颜色亮度、拼写等也是不可见信息，若描述中出现违规的颜色id或者亮度，可自行使用少量的固定颜色替代，但注意生成时要在三个以内输入输出网格中对所有变换100%覆盖度。
5. 输出样例要视觉清晰，人类必须能从输入输出对中肉眼辨认出规律。具体要求：避免对象粘连、覆盖关系混乱、同一像素多重语义；不同逻辑步骤产生的结果不要大面积层叠在一起导致无法分辨哪个颜色属于哪个步骤；输入中各元素之间保持足够间距，输出中新增的标记/填充/路径等应与背景和已有元素在颜色上有明显区分；若规则涉及多层叠加，生成时控制对象密度和尺寸，确保叠加区域只占少数像素而非铺满整个网格。
6. 若规则有多个分支，生成器不能长期固定成一个分支；应让分支在随机样例中合理出现。分支概率不必平均——难以发现的隐蔽分支（如少数情况下才触发的特殊规则）应适当提高出现概率，确保在 3 个训练示例中至少出现一次，否则求解者无法归纳该规则。对于颜色映射类规则，确保 2 个左右的示例即可覆盖所有映射关系（每种颜色→颜色的映射至少在某个示例中出现过）。
