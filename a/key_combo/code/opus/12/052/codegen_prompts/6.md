## 新题 6：对称轨道约束下的轮廓逐行填充

**组合逻辑**：[填充/fill + 行内边界配对/row_boundary_pairing + 逐行跨度填充/row_span_fill](已有) ⊕ [对称补全/symmetry_completion + 对称轨道映射/symmetry_orbit_mapping](创新：对称单位从单像素扩展到整个轮廓形状) → 两种约束同时作用（非流水线）

**来源原语**：填充/fill、轮廓线/outline、封闭区域/enclosed_region、行内边界配对/row_boundary_pairing、逐行跨度填充/row_span_fill（来自 22168020）；对称补全/symmetry_completion、对称图案/symmetric_pattern、掩码像素/masked_pixel、对称轨道映射/symmetry_orbit_mapping（来自 47996f11）

**依赖链**：非掩码轮廓可直接逐行填充确定其颜色与形状 → 网格整体的对称轴必须从所有轮廓（含掩码与非掩码）的位置布局中推断 → 掩码轮廓的完整边界由其对称伙伴的非掩码轮廓镜像得到 → 镜像后的边界再行逐行填充。删去填充则无法确定非掩码轮廓的视觉效果；删去对称映射则掩码轮廓无法恢复。

可见轮廓逐行填充后，通过整体对称轴将可见轮廓镜像到被掩码遮蔽的位置，恢复完整图案。

**输入结构**：约 13x13 的网格（宽度为奇数，使垂直中心轴明确位于列 (W-1)/2），背景黑(0)。包含 4-6 个由斜向边界像素构成的轮廓形状（同参考题 22168020：每行恰好两个同色像素标记左右边界）。这些轮廓形状关于网格垂直中心轴成对对称排列——左侧的每个形状在右侧有一个镜像对应物。部分轮廓的边界像素为正常颜色（如蓝(1)、红(2)、绿(3)），称为"可见轮廓"；其余轮廓的边界像素被替换为品红(6)，称为"掩码轮廓"。每个掩码轮廓的对称伙伴均为可见轮廓，反之亦然。生成约束：可见轮廓与掩码轮廓数量相等；可见轮廓的颜色互不相同。

**规则**：
1. **填充可见轮廓**：对每个非品红(6) 轮廓，逐行处理其占据的每一行。在每行上找到该轮廓的左右两个边界像素，将它们之间（含端点）的所有格子涂为该轮廓的颜色。
2. **确定对称轴**：取网格的垂直中心列 c_axis = (W-1)/2。
3. **重建掩码轮廓**：对每个品红(6) 轮廓形状，找到其对称伙伴——将该掩码轮廓每个品红像素 (r, c) 关于 c_axis 做水平镜像得到 (r, W-1-c)，该位置应属于某个可见轮廓。该可见轮廓即为对称伙伴。
4. **填充掩码轮廓**：将对称伙伴的边界像素逐行水平镜像，得到掩码轮廓的真实边界。用伙伴的颜色替换品红像素并逐行填充掩码轮廓的内部。
5. **冲突处理**：若可见轮廓的填充区域与重建后的掩码轮廓的填充区域重叠，可见轮廓的颜色优先。
6. 背景中不属于任何轮廓的像素保持黑(0)。

**关键洞察**：品红像素在源题 47996f11 中遮蔽的是全局对称图案中的单个格子，在本题中遮蔽的是整个轮廓形状的边界——对称操作的粒度从像素级跃升到对象级。求解者需要先识别出品红构成的是完整轮廓而非散布掩码，再从全局布局推断对称轴，最后通过镜像恢复轮廓并填充。
