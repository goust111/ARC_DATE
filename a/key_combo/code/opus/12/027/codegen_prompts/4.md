## 新题 4：缺口射线测距与跨分区回响

**组合逻辑**：[缺口定射线向](已有) + [射线延伸](已有) + [洪泛填充](已有) + [网格分区](已有) → 创新结构关系：射线被分区边界截断，截断长度编码为信息，在相邻分区中生成等长的"回响"条纹

**来源原语**：
- 缺口定射线向(gap_determines_ray) + 洪泛填充(flood_fill) ← 292dd178
- 射线延伸(ray_extend) ← 292dd178, 891232d6
- 网格分区(grid_partition) + 分隔线(separator_line) ← 6773b310
- 缺口矩形框(one_gap_rect_frame) ← 292dd178
- 重涂色(recolor) ← 292dd178, c7d4e6ad

**依赖链**：缺口 → 射线方向 → 射线沿该方向延伸直到分区边界（分隔线） → 射线长度 L 作为测距信息 → 在分隔线另一侧的相邻分区中，沿同轴画 L 格的"回响"条纹（颜色=边框前景色） → 回响条纹的存在又可能影响其他边框的射线（如果回响进入了另一个边框的射线路径）。缺口方向决定通信通道，分区位置决定射线长度，射线长度决定回响尺寸——三重耦合。

缺口矩形框的射线被分区边界截断，截断长度作为"信号"在相邻分区中生成等长的彩色条纹。

**输入结构**：
- 黑(0)背景，约 20x20 网格。
- 灰(5)像素构成完整的水平和垂直分隔线，将网格分为 2x2（共 4 个）矩形分区。每个分区内部尺寸约 8x8。
- 其中 2~3 个分区各包含一个 4x4 缺口矩形边框（4-连通，一个非角落边界像素缺失），每个边框使用不同的前景色（从蓝(1)、绿(3)、黄(4)、橙(7)中选取）。
- 其余分区为空（仅含黑背景）。
- 生成约束：每个边框的缺口外向方向指向一条分隔线（即缺口射线会先碰到分隔线而非网格边界）。缺口射线指向的相邻分区不包含另一个边框（是空分区），以避免回响条纹与边框冲突。不同边框的回响条纹不会在同一分区中的同一行/列重叠。

**规则**：
1. 对每个缺口矩形边框，定位缺口及其外向方向。
2. 将边框的 2x2 内部和缺口像素涂为红(2)。
3. 从缺口外向邻格开始，沿外向方向逐格画红(2)射线，直到下一格是灰(5)分隔线或网格边界为止（不覆盖分隔线）。记录射线长度 L（新画的红像素数量，不含缺口像素自身）。
4. 确定射线指向的相邻分区：跨过分隔线，找到分隔线另一侧的分区。
5. 在该相邻分区中，从紧邻分隔线内侧的第一个像素开始，沿射线的同一方向，画 L 格的条纹，颜色为该边框的原始前景色（蓝/绿/黄/橙）。若条纹在画完 L 格之前遇到非黑像素或分区的另一侧分隔线，则提前终止。
6. 所有灰(5)分隔线保持不变。所有边框的原始前景像素保持不变。

**关键洞察**：源题 292dd178 的射线延伸到网格边界，不受任何中间结构约束。本题的创新在于：分区边界截断射线，而截断本身携带了几何信息（缺口到分区边界的距离），这个信息被"投射"到相邻分区中——射线不再是视觉效果，而是跨分区的信息传递通道。求解者必须理解"测距→编码→跨界再现"这个三步过程，而非简单的直线延伸。需对比多个示例（不同缺口位置、不同分区尺寸）才能归纳出"回响长度=截断射线长度"这一非显然规则。
