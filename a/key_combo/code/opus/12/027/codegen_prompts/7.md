## 新题 7：标记配对印章覆盖与频率分层

**组合逻辑**：[标记颜色配对](已有) + [印章覆盖](已有，创新改造：原题中印章不重叠，现在允许重叠并需要解决冲突) + [计数/频率排序](已有，创新改造：频率不再生成柱状图，而是决定印章的绘制层级) + [擦除](已有) → 标记配对决定"印什么在哪"，频率排序决定"重叠时谁在上"

**来源原语**：
- 标记颜色配对(marker_color_pairing) ← 414297c0
- 印章覆盖(stamp_overlay) + 颜色重叠匹配(color_overlap_match) ← d6542281
- 计数(counting) + 频率排序(frequency_ranking) ← 9af7a82c
- 擦除(erase) ← b9630600, 321b1fc6
- 多色精灵体(multicolor_sprite) ← d6542281
- 标记像素(marker_pixel) ← 414297c0

**依赖链**：标记颜色 → 配对精灵体（确定每个目标位置使用哪个精灵） → 多个精灵印章在网格上可能空间重叠 → 计算每个精灵体的原始像素总数 → 按像素数降序排列 → 像素数多的精灵后绘制（覆盖在上层） → 擦除所有原始精灵体。频率排序不是生成柱状图，而是解决空间冲突——这是频率信息的全新用途。

将多色精灵体通过标记色配对印章到目标位置，重叠时按精灵体原始像素数决定层级（大者在上），最后擦除原始精灵。

**输入结构**：
- 黑(0)背景，约 18x18 网格。
- 3~4 个多色精灵体（每个由 2~3 种非黑颜色组成，总像素 4~10 个，8-连通），分布在网格的上半区。每个精灵体内部恰好包含一个独特颜色的"签名像素"：该颜色在整个精灵体中仅出现一次，且不在其他精灵体中出现。精灵体之间不接触。
- 网格的下半区散布若干单像素的"目标标记"，每个标记的颜色与某个精灵体的签名像素颜色相同。目标标记的数量可能多于精灵体数量（同一精灵体可能有多个目标标记）。
- 生成约束：至少存在两个目标标记，使得以它们为锚点印章对应精灵体后，印章区域在空间上有部分重叠（至少 1 个像素重叠）。各精灵体的原始非黑像素总数互不相同。

**规则**：
1. 识别所有多色精灵体及其签名像素颜色。识别方法：精灵体中恰好出现一次且不在其他精灵体中出现的颜色即为签名色。
2. 对每个目标标记，通过签名色匹配找到对应的精灵体。
3. 计算每个精灵体的原始非黑像素总数 S。
4. 按 S 从小到大的顺序依次印章：对每个精灵体（从像素最少的开始），对其所有匹配的目标标记，将精灵体以签名像素为锚点对齐到目标标记位置，复制精灵体的所有非签名像素到对应偏移位置。签名像素位置保留目标标记的颜色。超出网格边界的像素丢弃。
5. S 较大的精灵体后印章，覆盖先前印章的像素（后绘制者优先）。
6. 印章全部完成后，擦除所有原始精灵体（它们在上半区的原始位置全部涂为黑(0)）。
7. 目标标记被印章像素覆盖后不再单独可见。

**关键洞察**：源题 414297c0 的印章不涉及重叠冲突，源题 9af7a82c 的频率排序只生成柱状图。本题的创新在于：频率信息被重新赋予了"空间仲裁"的角色——当两个印章在同一像素位置冲突时，不是用固定规则（如"后来的覆盖"）解决，而是用精灵体的像素面积作为优先级。求解者必须同时推断标记配对规则（决定印在哪）和面积层级规则（决定谁在上），任一规则单独都不足以确定重叠区域的输出颜色。需对比重叠区域和非重叠区域的多个示例来归纳层级规则。
