## 新题 2：模板匹配驱动的选择性重力下落

**组合逻辑**：[归一化形状比对](已有) + [重涂色/匹配模板则重涂](已有) + [重力下落](已有，创新改造：原作用于粗栅格中的所有非背景像素，现仅作用于通过形状匹配筛选出的对象) → 形状匹配将对象分为"可动"与"固定"两类，固定对象充当重力下的地形障碍

**来源原语**：
- 归一化形状比对(normalized_shape_matching) ← 4ff4c9da
- 匹配模板则重涂(recolor_on_match) ← 4ff4c9da
- 重力下落(gravity_drop) ← afe3afe9
- 模板对象(template_object) ← 4ff4c9da
- 连通分量(connected_component) ← 4ff4c9da

**依赖链**：模板形状 → 匹配判定（哪些对象可动） → 非匹配对象自动成为障碍 → 重力作用于匹配对象（下落距离取决于障碍位置） → 最终布局同时依赖形状分类结果和空间位置关系。形状匹配决定"谁动"，空间布局决定"动到哪"，两者缺一不可。

将与青色模板同形的对象重涂为青色并向下做重力下落，其余对象不动并充当地形。

**输入结构**：
- 黑(0)背景，约 15x15 网格。
- 一个青(8)小对象（3~6 像素，4-连通，形状不规则）作为模板，位于网格的某个角落区域。
- 5~8 个单色小对象（每个 3~6 像素，4-连通），颜色分别为蓝(1)、红(2)、绿(3)、黄(4)中的某一种。其中部分对象的归一化 4-连通掩码与青(8)模板相同（平移等价），其余对象掩码不同。
- 所有对象互不接触（任意两对象的像素之间至少间隔 1 个黑像素）。
- 生成约束：至少 2 个对象匹配模板，至少 2 个不匹配。每个匹配对象的正下方（沿其各像素列向下延伸到网格底部的路径上）至少存在一个不匹配对象或网格底部作为着陆面。匹配对象下落后不会相互重叠（各匹配对象下落路径在列维度无冲突，或冲突时按从下到上顺序处理即可避免）。

**规则**：
1. 提取青(8)模板对象的归一化 4-连通掩码（平移归一化：将边界框左上角对齐到原点）。
2. 对网格中所有非黑、非青的 4-连通对象，逐一计算其归一化掩码，与模板掩码比对。掩码相同者标记为"可动对象"。
3. 将所有可动对象重涂为青(8)。
4. 对可动对象施加向下重力：每个可动对象整体保持形状不变，逐行向下平移，直到其任何像素的正下方紧邻一个非黑像素（不匹配对象的像素或网格底部的虚拟边界）。处理顺序：按对象边界框底部行号从大到小（最靠底的先处理），若底部行号相同则按左上角列号从小到大。
5. 擦除青(8)模板对象本身（涂为黑(0)背景）。
6. 所有不匹配对象保持原位置和原颜色不变。

**关键洞察**：源题 4ff4c9da 的形状匹配仅决定重涂颜色，源题 afe3afe9 的重力作用于所有非背景像素。本题的创新在于：形状匹配不仅决定颜色变换，更决定了对象的物理角色（可动 vs 地形），而重力下落的结果依赖于不匹配对象的空间分布——同一套形状匹配结果在不同空间布局下产生完全不同的输出。这种"分类即赋予物理属性"的结构关系是两道源题都不具备的。
