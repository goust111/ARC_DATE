## 新题 3：分区内独立频率柱状图

**组合逻辑**：[网格分区](已有) + [计数](已有) + [频率排序/频率降序柱状图](已有，创新改造：原作用于整个网格生成单一柱状图，现在每个分区内独立生成局部柱状图) + [填充](已有) → 分区定义计数范围，计数结果在分区几何约束下生成柱状图

**来源原语**：
- 网格分区(grid_partition) + 分隔线(separator_line) ← 6773b310
- 计数(counting) ← 9af7a82c, 6773b310, fcc82909
- 频率排序(frequency_ranking) + 频率降序柱状图(descending_frequency_histogram) ← 9af7a82c
- 排序(sort) ← 9af7a82c
- 填充(fill) ← fb791726

**依赖链**：分隔线 → 确定分区边界 → 每个分区内独立统计各颜色像素数 → 按频率降序排列颜色 → 在该分区内原地生成顶对齐柱状图（柱高=频率，柱色=对应颜色） → 分区尺寸约束柱状图布局。分区边界同时定义统计范围和输出画布，计数结果决定柱高，三者紧耦合。

将分隔线划分的每个分区中的散布彩色像素统计频率，原地替换为顶对齐的频率降序柱状图。

**输入结构**：
- 黑(0)背景，约 17x17 网格。
- 灰(5)像素构成完整的水平分隔线和垂直分隔线（每条线贯穿整行或整列），将网格分为 2x2 或 2x3 个矩形分区。每个分区的内部尺寸至少为 4x4（不含分隔线）。
- 每个分区内散布 2~3 种非黑(0)非灰(5)颜色的像素（如蓝(1)、红(2)、绿(3)、黄(4)、橙(7)等），每种颜色 1~4 个像素，位置随机分布在分区内部。不同分区可包含不同的颜色组合。
- 生成约束：每个分区内不同颜色的像素数量互不相同（无频率平局）。每个分区的宽度（列数）不小于该分区内出现的颜色种类数（保证每种颜色至少有一列空间放置柱状图柱）。每个分区的高度（行数）不小于该分区内最高频率颜色的像素数（保证最高柱不超出分区）。

**规则**：
1. 识别所有灰(5)分隔线，确定各矩形分区的边界（分区内部不含分隔线像素）。
2. 对每个分区，统计其中各非黑非灰颜色的像素数量。
3. 将颜色按像素数降序排列。
4. 清空该分区内部为黑(0)。
5. 在该分区内部生成顶对齐柱状图：从分区内部的最左列开始，第一列对应频率最高的颜色，从该分区内部的第一行（最上方）向下填充该颜色，填充行数等于其像素计数；第二列对应次高频颜色，同样从顶部向下填充；以此类推。未使用的列保持黑(0)。
6. 所有灰(5)分隔线保持不变。

**关键洞察**：源题 9af7a82c 对整个网格做单一柱状图，源题 6773b310 在分区内做简单的标记计数（双标记→蓝）。本题的创新在于：分区结构同时定义了统计范围和输出画布的几何约束——柱状图必须在分区内部生成，分区尺寸隐式限制了可表达的频率范围。求解者必须同时理解分区语义（空间分割）和柱状图语义（频率编码），两者不可分离。需对比多个示例才能区分"分区内局部统计"与"全局统计后切割放回"这两种可能的规则。

<description>
Fill enclosed regions along a line seeded by unique border pixels.

Input structure:
- bg = most common color.
- Colored lines/drawings on the grid.
- Unique single-pixel colors on the grid border mark seed endpoints of each line.

Rule:
- Each border seed pixel connects (8-connected) to a line drawing.
- Find closed bg cavities whose boundary touches that line.
- Flood-fill each such cavity with the seed pixel's color.

Key insight: Only cavities reachable through the seed's own line get filled; the seed's unique color acts as a per-line fill label.

1. `main(grid)` 必须实现新题描述中的确定性转换规则，不能只识别 `generate_input()` 的固定模板。禁止不同的input网格输出相同的output网格。
2. `generate_input()` 必须随机生成多样样例，不能固定死。随机维度应覆盖：网格大小、对象数量、位置、颜色、方向、形状参数或关键分支。注意若描述中存在若干，需实现而不是只有单个，包括object或者对应关系等等。且若涉及到最短路径，则输入网格中必涉及到多条路径，对选择造成干扰。
