## 新题 4：排名双用——奇偶筛选与缩放因子

**组合逻辑**：[排序 + 奇偶交替选择](筛选存活对象) ⊗ [像素放大/格位映射](放大倍率由同一排名值决定) — 排名同时充当筛选条件和变换参数，不可拆分

**来源原语**：排序/奇偶交替选择/沿轴排列/忽略干扰项(817e6c09)，像素放大/格位映射(cce03e0d)，擦除(a934301b)

**依赖链**：水平排序产生排名；排名的奇偶性决定对象是否存活（筛选）；存活对象的排名数值同时作为其像素放大的缩放因子。排名承担双重角色——删除排序则既无法筛选也无法确定缩放因子；删除筛选则所有对象都会放大；删除放大则筛选无后续变换。

将水平排列的小图形按位置排序，保留奇数排名的图形，并以各自的排名值为倍率进行像素放大。

**输入结构**：
- 黑(0)背景，约 20x20 网格。
- 网格上散布 5~7 个单色 4-连通小图形（每个 3~5 像素），每个图形使用不同颜色（从蓝(1)、红(2)、绿(3)、黄(4)、橙(7)、青(8)、栗(9)中选取），各图形的左边界列互不相同。
- 另外散布 2~3 个单像素的品红(6)干扰点，不与任何图形相邻。
- 生成约束：图形的边界框互不重叠；每个图形的边界框不超过 3x3；放大后的图形（以排名为倍率）能完全放入约 30x30 的输出网格中；图形数量为奇数（保证筛选后至少保留 3 个）。

**规则**：
1. 忽略所有品红(6)单像素干扰点。
2. 将剩余图形按其左边界列从左到右排序，赋予排名 1, 2, 3, ...。
3. 保留排名为奇数的图形（1, 3, 5, ...），擦除排名为偶数的图形。
4. 对每个存活图形，以其排名值 k 为缩放因子进行像素放大：将图形裁剪到边界框，对边界框内每个像素生成一个 k x k 的块——若原像素为图形色则填充该图形色，若为黑(0)背景则填充黑(0)。
5. 输出网格中，将所有放大后的图形按原排名从左到右排列，相邻图形之间间隔 1 列黑(0)背景。输出高度为所有放大后图形中的最大高度，较矮的图形顶部对齐。

**关键洞察**：排名不只是排序后的标签——它同时扮演两个角色：奇偶性决定生死，数值大小决定放大倍率。排名靠右的存活图形反而被放大得更多。
