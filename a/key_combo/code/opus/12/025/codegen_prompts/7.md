## 新题 7：面积门控结构提升——连线与边框分色

**组合逻辑**：[计数 + 面积分级](区分对象的结构角色) → [连线](贯穿线由"主导"对象生成) + [描边 + 半区分色](边框颜色由面积比较而非位置决定) — 面积比较的结果同时流入两个并行操作

**来源原语**：计数/面积分级/连通分量/面积决定颜色(e8593010)，连线/描边/半区分色/边框/孤立像素(1bfc4729)，擦除(a934301b)，面积筛选(a3325580)

**依赖链**：面积统计将对象分为"主导"和"次要"两类；主导对象触发水平贯穿线绘制；主导对象间的面积相对大小决定边框上下半区的颜色分配。次要对象被擦除。删除面积统计则无法分类对象；删除连线则主导对象无视觉效果；删除边框分色则面积比较无最终体现。

统计各前景对象的面积，面积最大的两个对象触发贯穿线，面积较大者的颜色占据边框上半区，面积较小者占据边框下半区，其余对象被擦除。

**输入结构**：
- 黑(0)背景，偶数高度的正方形网格（如 14x14 或 16x16）。
- 网格上有 4~6 个单色 4-连通前景对象，每个对象使用不同颜色（从蓝(1)、红(2)、绿(3)、黄(4)、橙(7)、青(8)中选取），面积各不相同（3~12 像素），形态为不规则连通图形。
- 面积最大的两个对象分别位于网格的上半区和下半区（各自的边界框中心行一个在上半、一个在下半），但面积更大的那个未必在上半区。
- 生成约束：面积最大的两个对象面积不同（无并列）；所有对象互不相邻。

**规则**：
1. 计算每个前景对象的 4-连通面积。
2. 选出面积最大的两个对象，记为 A（面积更大）和 B（面积次大）。
3. 擦除所有其他对象（像素变为黑(0)）。
4. 通过 A 的边界框中心行绘制一条全宽水平线，颜色为 A 的颜色；通过 B 的边界框中心行绘制一条全宽水平线，颜色为 B 的颜色（边界框中心行 = 上边界行 + 下边界行的平均值向下取整）。
5. 绘制 1 像素宽的网格边框。边框的上半区（从第 0 行到第 H/2-1 行，H 为网格高度）着色为 A 的颜色，下半区（从第 H/2 行到第 H-1 行）着色为 B 的颜色。
6. 水平线与边框重叠处，边框颜色覆盖水平线颜色。
7. A 和 B 的原始对象像素保留在输出中（不被水平线或边框覆盖——水平线绘制时跳过原始对象所占像素，对象位于边框行/列时，对象颜色保持不变）。

**关键洞察**：在参考题 1bfc4729 中，边框上下半区的颜色由像素的垂直位置决定——上面的像素染上色，下面的染下色。在本题中，边框颜色分配由面积大小决定：面积更大的对象无论在网格哪个位置，其颜色总是占据上半边框。位置决定线条，面积决定边框。
