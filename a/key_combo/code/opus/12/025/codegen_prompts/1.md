## 新题 1：折叠臂指向重涂色

**组合逻辑**：[折叠](折叠方向不再是视觉变换，而作为空间指针) → [重涂色](目标由折叠臂的朝向动态确定) + [面积分级](解决多个折叠臂指向同一区域的冲突)

**来源原语**：折叠/固定端与活动端/空间大侧折入(230f2e48)，重涂色/单色区域(21897d95)，面积分级(e8593010)

**依赖链**：折叠方向的计算结果决定了哪个相邻区域被重涂色；当多根杆的折叠臂同时指向同一区域时，折叠臂所在区域的面积排名决定最终涂色优先级。三者缺一不可：无折叠则无方向指针，无重涂色则折叠无语义后果，无面积分级则冲突无法消解。

将网格中单色区域内嵌入的直线杆在铰接点处折叠，折叠臂指向的相邻区域被重涂为折叠臂所在区域的颜色，面积较大区域的折叠臂优先。

**输入结构**：
- 黑(0)背景上，约 18x18 的网格被灰(5)分隔线划分为 4~6 个大小不等的单色矩形区域，每个区域用不同颜色填充（从蓝(1)、红(2)、绿(3)、黄(4)、橙(7)、青(8)中选取），区域之间以一像素宽灰(5)线分隔。
- 其中 2~4 个区域内各包含一根贯穿区域的直线杆（水平或垂直），杆的颜色为品红(6)。每根杆的一个端点处有一个栗(9)像素作为端点标记，杆上某个非端点位置有一个灰(5)像素作为铰接标记。
- 每根杆的长度等于其所在区域在该方向上的跨度（即杆从区域一侧延伸到另一侧）。
- 铰接标记将杆分为固定段（端点标记一侧）和活动段（另一侧）。
- 生成约束：不同区域内的杆折叠后指向的相邻区域最多有一对冲突（即最多两根杆指向同一邻居区域）。

**规则**：
1. 对每根杆，保留从端点标记到铰接标记的固定段不变。
2. 将活动段从铰接标记处折叠 90 度，方向选择与铰接标记到最近网格边缘距离较远的那一侧（即空间更大的一侧），折叠后活动段变为垂直于原方向的射线，长度等于活动段原长度，超出所在区域边界的部分进入相邻区域。
3. 折叠臂进入的第一个相邻区域（穿过灰(5)分隔线后到达的区域）被标记为"目标区域"。
4. 每个目标区域被重涂为指向它的折叠臂所在源区域的颜色。
5. 冲突解决：若两根杆的折叠臂指向同一目标区域，以源区域面积（像素数）较大者的颜色为准。
6. 没有被任何折叠臂指向的区域保持原色不变。
7. 折叠后的杆（含品红(6)像素、栗(9)端点标记和灰(5)铰接标记）保留在输出中。

**关键洞察**：折叠操作的几何朝向不是为了改变杆的视觉形态，而是充当一个空间指针，选择哪个相邻区域将被重涂色——需要先计算折叠方向，才能确定重涂色的目标。
