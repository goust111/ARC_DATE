## 新题 1：对称侵蚀后的拓扑分类填充

**组合逻辑**：[镜像/反射对称](分析工具) + [重涂色/擦除](创新：擦除对象从"标记"变为"非对称像素") → [洪泛填充](创新：填充颜色由拓扑变化前后的对比决定)

**来源原语**：反射对称·交集差集分别着色(a8610ef7) + 重涂色(a8610ef7) + 洪泛填充·封闭腔体·区域可达性(8b7bacbf, 543a7ed5) + 连通可达(8b7bacbf)

**依赖链**：对称分析决定哪些像素被擦除 → 擦除改变前景形状的拓扑结构（可能打破封闭边界） → 比较擦除前后每个腔体的封闭性变化 → 变化类型决定填充颜色。三步之间存在信息变换：对称性→几何变化→拓扑变化→颜色编码。

输入中有一个复杂的连通前景形状，它将背景分隔出若干封闭腔体；对该形状做垂直镜像分析后擦除非对称像素，导致部分腔体的边界被破坏而与外部连通；最终根据每个腔体在擦除前后的封闭性变化分别着色。

**输入结构**：
- 约 15x15 网格，黑(0) 背景。
- 一种前景色（蓝(1)），形成单个 4-连通的复杂连通形状（约 40~60 像素），近似但不完全垂直对称。
- 该形状将背景划分为：外部区域（从网格边界可达）和 3~5 个封闭腔体（从网格边界不可达的背景连通分量）。
- 关键约束：部分非对称像素（仅存在于形状中、但其关于网格垂直中心线的镜像位置不是前景像素的那些像素）恰好位于某些腔体的边界上；擦除它们后会使部分腔体与外部连通。
- 生成约束：至少存在一个腔体在擦除后仍然封闭，至少存在一个腔体在擦除后变为开放。

**规则**：
1. 计算网格的垂直中心线（列索引 = (宽度-1)/2，若宽度为偶数则取左半列）。
2. 对每个蓝(1)前景像素，检查其关于垂直中心线的镜像位置：若镜像位置也是蓝(1)前景像素，则该像素属于"对称交集"；否则属于"非对称差集"。
3. 将所有"非对称差集"像素擦除为黑(0)，"对称交集"像素保持蓝(1)。
4. 在擦除后的网格上，从网格四条边界出发做 4-连通洪泛扩散，标记所有从边界可达的黑(0)像素为"外部"。
5. 对于原始网格中的每个封闭腔体（擦除前从边界不可达的背景连通分量）：
   - 若该腔体的所有像素在擦除后仍然从边界不可达（仍封闭）→ 填充黄(4)。
   - 若该腔体中至少有一个像素在擦除后变为从边界可达（封闭性被破坏）→ 填充绿(3)。
6. 外部背景区域保持黑(0)。

**关键洞察**：填充颜色不是由腔体自身属性决定，而是由对称侵蚀引发的拓扑变化决定——求解者需要同时推断对称轴、擦除规则和拓扑比较三层逻辑。

2. `generate_input()` 必须随机生成多样样例，不能固定死。随机维度应覆盖：网格大小、对象数量、位置、颜色、方向、形状参数或关键分支。注意若描述中存在若干，需实现而不是只有单个，包括object或者对应关系等等。且若涉及到最短路径，则输入网格中必涉及到多条路径，对选择造成干扰。
