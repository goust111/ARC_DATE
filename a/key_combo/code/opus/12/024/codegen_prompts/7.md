## 新题 7：标记像素双参数编码矩形内部的周期格点

**组合逻辑**：[填充·保留边框填内部](已有，填充内容从实心色变为周期格点) + [循环填充·周期相位对齐](创新：相位由外部标记位置编码) + [擦除·标记色定边框色](创新：标记同时提供格点颜色和相位参数，然后被擦除)

**来源原语**：最大实心矩形·保留边框填内部·内部区域(e88171ec) + 循环填充·对角线格点·周期相位对齐(c1990cce) + 中心标记像素(c1990cce, fc754716) + 擦除·标记色定边框色(fc754716) + 忽略干扰项(e88171ec)

**依赖链**：最大矩形检测确定填充区域 → 标记像素颜色确定格点颜色 → 标记像素列坐标确定格点相位 → 三个参数（区域、颜色、相位）共同确定输出中的每一个像素。标记像素承担双重编码角色（颜色+位置），这种信息复用使得单一对象同时约束两个独立参数。

在含有多个黑色矩形的噪声网格中找出最大矩形，保留其边框，内部用标记像素编码的周期性对角格点图案填充。

**输入结构**：
- 约 16x16 网格，灰(5) 背景，其上散布少量随机噪声像素（颜色随机，约 5~10 个，充当干扰项）。
- 2~4 个不同大小的实心黑(0)矩形（每个矩形内部全部为黑(0)），最大矩形的尺寸至少 6x6，面积严格唯一最大。
- 网格上有一个标记像素（颜色取自 {蓝(1), 红(2), 绿(3), 黄(4), 橙(7)} 之一），位于所有黑色矩形之外。
- 生成约束：最大矩形内部至少 4x4（去掉边框后的区域足够展示格点图案）；标记像素不与任何矩形相邻。

**规则**：
1. 找到面积最大的实心黑(0)轴对齐矩形（在所有可能的轴对齐黑色矩形中面积最大的那个）。
2. 保留该矩形的 1 像素宽黑(0)边框不变。
3. 在矩形的严格内部区域（去掉四边各 1 像素后的区域），绘制 NW-SE 方向的对角格点：对每个内部像素 (r, c)，若 (r + c) mod 4 == (标记像素的列坐标) mod 4，则涂为标记像素的颜色；否则保持灰(5)背景色。
4. 将标记像素擦除（替换为灰(5)背景色）。
5. 所有其他矩形和噪声像素保持不变。

**关键洞察**：标记像素是一次性控制信号——它的颜色和位置各编码一个独立参数（格点颜色和相位偏移），用后即被擦除，求解者必须从格点图案的颜色和偏移同时反推标记的两个属性。

Input structure

- The panels are 4-connected regions of non-separator cells, and all panel

Rule
- Create one blank panel of that common shape.
- For each input panel, copy every non-blank mark to the same relative

Key insight
- The large separator color is not part of the answer; the answer is the
  transparent overlay of the small drawings inside its panels.
