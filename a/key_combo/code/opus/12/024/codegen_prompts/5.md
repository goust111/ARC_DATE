## 新题 5：外部条形段像素数限定腔体洪泛填充容量

**组合逻辑**：[计数](创新：计数对象从方块变为条形段像素) + [洪泛填充](创新：填充被外部数值截断而非自然终止) + [擦除](条形段在输出中被擦除)

**来源原语**：计数·像素数转为条纹(d93c6891) + 洪泛填充·种子像素·封闭腔体·种子色标记填充(8b7bacbf) + 能量上限步数(271d71e2) + 相邻接触(d93c6891) + 擦除(d93c6891)

**依赖链**：外部条形段的像素数 → 同色种子的填充容量 → 容量与腔体大小的关系决定是完全填充还是部分填充 → 部分填充的边界形状由 BFS 扩散顺序决定。外部计数和内部几何两路信息在填充操作处汇合，缺任一路则无法确定输出。

线条画围出若干封闭腔体，每个腔体内有一个种子像素；线条画外部贴着同色条形段，条形段的像素数就是该种子的填充容量。填充从种子向外 BFS 扩散，容量耗尽即停。

**输入结构**：
- 约 14x14 网格，黑(0) 背景。
- 一个 4-连通的红(2)线条画（1 像素宽的连通线段网络），将网格内部分隔为 3~5 个大小不等的封闭腔体（腔体内部为黑(0)背景，从网格边界不可达）。
- 每个腔体内恰有一个种子像素，颜色各不相同，取自 {蓝(1), 绿(3), 黄(4), 橙(7), 灰(5)}。
- 在线条画的外部（从网格边界可达的区域），每种种子颜色对应一条同色条形段：1 像素宽的水平或垂直线段，4-连通接触红(2)线条画的外侧边界。条形段长度 2~8 像素不等。
- 生成约束：至少一个腔体的面积（黑色像素数）大于其对应条形段的像素数（会部分填充）；至少一个腔体面积小于等于对应条形段像素数（会完全填充）。

**规则**：
1. 对每条彩色条形段，计算其像素数 → 记为该颜色的填充容量 C。
2. 对每个封闭腔体，找到其内部的种子像素，确定种子颜色。
3. 从种子像素出发，做 4-连通 BFS 洪泛扩散（仅扩散到腔体内的黑(0)像素），将遍历到的像素重涂为种子颜色。
4. BFS 层序：按曼哈顿距离从小到大扩散；同一距离层内按行从上到下、同行按列从左到右的顺序处理。
5. 当已涂色的像素数（含种子自身）达到 C 时立即停止，即使腔体内还有未涂色的黑(0)像素。若腔体内黑(0)像素数+1（种子） <= C，则腔体被完全填充。
6. 填充完毕后，擦除所有外部条形段（替换为黑(0)），红(2)线条画保持不变。

**关键洞察**：同一个填充操作的输出形状由两个独立信息源共同决定——腔体几何（控制 BFS 路径）和外部条形段长度（控制何时截断）。求解者必须从部分填充的边界形状反推出容量限制机制。
