## 新题 6：格点补全中旋转角度由位置奇偶性决定

**组合逻辑**：[补全/印章覆盖](已有) + [旋转](已有) + [格点对齐](已有) → [行列奇偶决定填充](创新：奇偶性不再控制颜色填充，而是控制精灵体的旋转角度) → [笛卡尔积缺位填充](已有)

**来源原语**：补全(#5b526a93)、印章覆盖(#f5c89df1)、旋转(#7df24a62)、同形精灵体(#5b526a93)、行列格点(#5b526a93)、格点对齐(#5b526a93)、笛卡尔积缺位填充(#5b526a93)、模式匹配(#7df24a62)、行列奇偶决定填充(#ba9d41b8)

**依赖链**：格点对齐确定所有合法槽位坐标；已占据槽位中的精灵体朝向呈棋盘分布——位置奇偶性决定旋转角度（源题中精灵完全相同无旋转，棋盘奇偶仅用于颜色填充）。求解者必须同时推断基础精灵形状、格点间距、以及奇偶-旋转映射规则三者，缺一不可。补全空槽时必须根据该槽的行列索引奇偶性选择正确的旋转朝向。

在矩形格点上补全缺失的精灵体，但每个槽位中的精灵朝向由其行列索引之和的奇偶性决定——偶数位置为原始朝向，奇数位置为 180 度旋转。

**输入结构**：约 18x18 的黑(0)背景网格。包含若干蓝(1)色精灵实例，排列在一个行列格点上（行间距和列间距均匀且相等，均 ≥ 精灵边界框尺寸+1）。每个精灵为同一个 3~5 像素的 4-连通非对称形状（即该形状旋转 180 度后与原形状不同），占据其边界框的一部分。格点上已占据的槽位中：行索引与列索引之和为偶数的槽位放置原始朝向精灵，之和为奇数的槽位放置 180 度旋转后的精灵。格点至少有 3 行 3 列，缺失 2~4 个槽位（包含偶数位和奇数位的缺失）。生成约束：至少存在一个完整行和一个完整列以确定格点间距；精灵形状在 180 度旋转下不对称。

**规则**：
1. 识别所有蓝(1)色 4-连通分量。通过对比各分量的形状，确定基础精灵模板（出现频率最高的形状为 0 度朝向模板）。
2. 利用已有精灵的左上角坐标推断行列格点结构（等间距的行起始坐标集合和列起始坐标集合）。
3. 确定每个已占据槽位的行索引 i 和列索引 j（从 0 开始计数）。验证：(i+j) 为偶数的槽位包含 0 度朝向精灵，(i+j) 为奇数的槽位包含 180 度旋转精灵。
4. 对每个空槽位 (i, j)：若 (i+j) 为偶数，粘贴 0 度朝向的精灵模板，颜色为青(8)；若 (i+j) 为奇数，粘贴 180 度旋转的精灵模板，颜色为青(8)。
5. 已有精灵保持蓝(1)不变。

**关键洞察**：精灵体并非全部相同——它们遵循一个位置奇偶性驱动的旋转规律，这一规律必须通过对比不同格点位置上精灵的朝向差异才能发现，而补全空位时必须应用该规律选择正确旋转。
