## 新题 7：角落扩展后洪泛填充划分领地

**组合逻辑**：[平移/相对位置保持展开](已有) → [洪泛填充](创新：四个角落像素变为四个洪泛种子，填充区域被墙壁拓扑约束) + [障碍物](已有) → 面积比较(创新：填充区域重叠时按面积大小决定优先级)

**来源原语**：平移(#66e6c45b)、前景块(#66e6c45b)、网格角落(#66e6c45b)、块内位置对应角落(#66e6c45b)、相对位置保持展开(#66e6c45b)、洪泛填充(#9edfc990)、障碍物(#9edfc990)、四邻连通(#9edfc990)、种子沿连通域扩散(#9edfc990)、面积比较(#694f12f3)

**依赖链**：2x2 块的四种颜色分配到四个角落——这决定了四个洪泛种子的位置和颜色。灰色墙壁将网格分割为不规则区域，每个种子从其角落向内洪泛扩散。当两个洪泛区域经由不同通道到达同一个腔室时产生冲突，此时面积更大的洪泛区域覆盖较小的。角落展开、墙壁拓扑和冲突解决三者交织为一个同时约束满足问题。

将中央 2x2 色块的四种颜色送到对应角落，然后从四个角落同时洪泛填充，灰色墙壁限制扩散范围，冲突区域由面积更大的填充方覆盖。

**输入结构**：约 13x13 的黑(0)背景网格。中央偏附近有一个 2x2 前景色块，四个像素颜色互不相同，取自蓝(1)、红(2)、绿(3)、黄(4)。网格中散布灰(5)色墙壁像素，形成不规则的连通障碍结构，将网格分割为若干大小不等的腔室。四个角落像素 (0,0)、(0,W-1)、(H-1,0)、(H-1,W-1) 初始为黑(0)。生成约束：每个角落必须属于一个包含至少 3 个黑色像素的腔室；至少有一个腔室与两个以上角落的腔室均 4-连通（即存在冲突区域）；2x2 块所在位置周围为灰色墙壁包围（块本身不参与洪泛，仅提供颜色信息）。

**规则**：
1. 读取 2x2 色块中各像素的颜色和相对位置：左上像素颜色 → 网格左上角 (0,0)；右上 → (0,W-1)；左下 → (H-1,0)；右下 → (H-1,W-1)。
2. 将 2x2 色块的四个像素设为黑(0)（清除原位置）。
3. 将四种颜色放置到对应的网格角落像素上。
4. 从每个角落像素同时发起洪泛填充：沿 4-连通黑(0)像素扩散，灰(5)墙壁为障碍不可穿越。每个种子将其可达的所有黑色像素染为种子颜色。
5. 当某个黑色像素同时可被两个以上种子的洪泛到达时（属于同一连通腔室但与多个角落相通），该像素归属于洪泛面积最大的种子（即从该种子出发总共能到达最多黑色像素的那一方）。面积仍相同时，按种子颜色编号从小到大优先（蓝(1) > 红(2) > 绿(3) > 黄(4)）。
6. 灰(5)墙壁保持不变。

**关键洞察**：四个角落不只是目的地——它们是领地种子，墙壁拓扑决定了每个种子的势力范围，而冲突区域的归属取决于各种子总可达面积的比较，这一信息无法从局部判断。

<description>
Paint yellow the background cells on the unobstructed shortest monotone corridor between two doorway frames.

Input structure
- The grid has a background, two small frame objects in one foreground color, and one center marker in each frame.
- Each marker has exactly one background 4-neighbor, the doorway gap; the next cell outward is the exterior doorway cell.

Rule
- Treat all existing foreground cells as blockers.
- Between the two exterior doorway cells, allow only row/column steps that move toward the other exterior cell.
- Paint every background cell that lies on some such path from one exterior cell to the other, plus the two doorway gaps, yellow.

Key insight
- The output is not a single chosen route: it is the union of all shortest monotone paths that can pass between the two frames.
</description>

2. `generate_input()` 必须随机生成多样样例，不能固定死。随机维度应覆盖：网格大小、对象数量、位置、颜色、方向、形状参数或关键分支。注意若描述中存在若干，需实现而不是只有单个，包括object或者对应关系等等。且若涉及到最短路径，则输入网格中必涉及到多条路径，对选择造成干扰。
