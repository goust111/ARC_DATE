## 新题 3：洪泛可达性选择矩形框进行内部填充

**组合逻辑**：[洪泛填充](已有) → [邻接接触](创新：洪泛到达的区域与矩形框的邻接关系成为选择条件) → [填充](创新：不再对所有矩形统一操作，而是仅填充被洪泛"触及"的矩形) + [擦除](已有)

**来源原语**：洪泛填充(#9edfc990)、种子像素(#9edfc990)、障碍物(#9edfc990)、四邻连通(#9edfc990)、矩形框(#c8b7cc0f)、矩形内部(#ba9d41b8)、框内包含(#c8b7cc0f)、邻接接触(#48d8fb45)、填充(#694f12f3)、种子沿连通域扩散(#9edfc990)

**依赖链**：灰色墙壁将网格分割为多个连通腔室；洪泛填充从种子出发，仅能到达与种子同腔室的区域；矩形框是否被填充取决于其边框是否与洪泛到达的区域 4-邻接。墙壁拓扑决定了哪些矩形"可达"——这是一个隐式的连通性选择机制，不能通过距离或方位简单判断。

种子像素发起洪泛填充，灰色墙壁限制填充范围；只有边框与已填充区域直接相邻的矩形框才会被选中，其内部被填充为种子颜色。

**输入结构**：约 20x20 的黑(0)背景网格。包含：(1) 3~5 个单像素厚的矩形框，每个框至少 4x4，框颜色各不相同且均非黑(0)、非灰(5)、非蓝(1)，框内部为黑(0)；(2) 灰(5)色墙壁像素组成的不规则连通障碍结构，将矩形框之间的黑色区域分割成若干互不连通的腔室；(3) 一个蓝(1)种子像素位于某个腔室中。矩形框的边框像素同样作为洪泛障碍。生成约束：种子所在腔室与部分矩形框 4-邻接，但不与全部矩形框邻接（灰色墙壁阻断了到其余矩形的路径）；不同示例中种子位置和墙壁布局不同，导致可达矩形集合不同。

**规则**：
1. 从蓝(1)种子像素出发，沿 4-连通方向遍历所有可达的黑(0)背景像素。灰(5)墙壁像素和所有矩形框的边框像素均为障碍，不可穿越。
2. 对每个矩形框 F，检查 F 的外边框像素是否有至少一个 4-邻居是被洪泛到达的黑色像素（或种子像素本身）。
3. 若 F 的外边框与洪泛区域 4-邻接，则将 F 内部（边框包围的黑色区域）全部填充为蓝(1)。
4. 未被洪泛区域触及的矩形框保持原样（内部仍为黑色）。
5. 清除所有灰(5)墙壁像素（设为黑(0)），清除种子像素和洪泛区域中所有被染色的像素（设为黑(0)）。最终网格上只剩矩形框（边框保留原色，被选中的框内部为蓝(1)，未被选中的框内部为黑(0)）。

**关键洞察**：灰色墙壁是不可见的连通性控制结构——它们在输出中消失，但正是它们决定了种子的洪泛能触及哪些矩形框，从而决定哪些矩形被填充。

<description>
Draw a green one-cell border around every adjacent red pair while leaving isolated red pixels unchanged.

Input structure
- The grid is a black background containing only red foreground pixels.
- Each 4-connected red object is either a single pixel or a two-pixel horizontal/vertical domino.

Rule
- Preserve all input pixels.
- For each red domino, expand its bounding box by one cell in all directions, clipped to the grid.
- Paint the perimeter of that expanded box green wherever it is currently black.

Key insight
- The green marks are not drawn around all red pixels, only around the 4-connected red objects of area two.

## 实现要求

1. `main(grid)` 必须实现新题描述中的确定性转换规则，不能只识别 `generate_input()` 的固定模板。禁止不同的input网格输出相同的output网格。
2. `generate_input()` 必须随机生成多样样例，不能固定死。随机维度应覆盖：网格大小、对象数量、位置、颜色、方向、形状参数或关键分支。注意若描述中存在若干，需实现而不是只有单个，包括object或者对应关系等等。且若涉及到最短路径，则输入网格中必涉及到多条路径，对选择造成干扰。
3. 生成器必须保证输入满足 `main()` 的隐式假设：对象不重叠、不越界、特殊标记唯一或可区分、匹配关系无歧义、关键分支出现概率相同。
4. 禁止把 ARC 颜色 id 、亮度、拼写等当作人类不可见的数值语义参与排序、大小比较或隐藏映射。颜色变化必须有可见结构线索。注意颜色亮度、拼写等也是不可见信息，若描述中出现违规的颜色id或者亮度，可自行使用少量的固定颜色替代，但注意生成时要在三个以内输入输出网格中对所有变换100%覆盖度。
5. 输出样例要视觉清晰，人类必须能从输入输出对中肉眼辨认出规律。具体要求：避免对象粘连、覆盖关系混乱、同一像素多重语义；不同逻辑步骤产生的结果不要大面积层叠在一起导致无法分辨哪个颜色属于哪个步骤；输入中各元素之间保持足够间距，输出中新增的标记/填充/路径等应与背景和已有元素在颜色上有明显区分；若规则涉及多层叠加，生成时控制对象密度和尺寸，确保叠加区域只占少数像素而非铺满整个网格。
6. 若规则有多个分支，生成器不能长期固定成一个分支；应让分支在随机样例中合理出现。分支概率不必平均——难以发现的隐蔽分支（如少数情况下才触发的特殊规则）应适当提高出现概率，确保在 3 个训练示例中至少出现一次，否则求解者无法归纳该规则。对于颜色映射类规则，确保 2 个左右的示例即可覆盖所有映射关系（每种颜色→颜色的映射至少在某个示例中出现过）。
