## 新题 3：封闭区域奇偶性选择面板变换类型

**组合逻辑**：[计数/counting](已有) → 条件分支（创新：奇偶判定 × 引导线有无 = 四路决策表） → [镜像/mirror](已有) / [填充/flood_fill](已有) / 旋转(创新)

**来源原语**：计数(89565ca0), 镜像(4e7e0eb9), 重涂色(4e7e0eb9), 九宫面板(4e7e0eb9), 引导线(4e7e0eb9), 轴线决定变换(4e7e0eb9), 封闭区域(89565ca0), 区域数映射长度(89565ca0)

**依赖链**：面板内线条画分割出若干封闭背景区域 → 计数区域数得到 N → N 的奇偶性与引导线的有无组合成四种情况 → 每种情况对应不同的变换操作（镜像/填充反转/旋转/不变）

网格被分成若干面板，每个面板包含线条画和可能的引导线；面板内封闭区域的数量决定对该面板施加哪种几何变换。

**输入结构**：约 21x21 网格，由单像素宽灰(5)网格线分隔为 3x3 共 9 个面板，每个面板内部约 6x6。每个面板内部包含：(a) 一个由某种非黑非灰颜色构成的线条画（4-连通的单色像素集合，形成 1~3 个封闭的黑(0)背景区域，像素数 6~15），以及 (b) 可能存在的引导线——面板内部中间行或中间列被另一种非黑非灰颜色完全填满的单行/单列线段。不同面板的线条画颜色可以相同也可以不同。生成约束：9 个面板中至少出现全部四种组合情况（奇数+有引导线、偶数+有引导线、奇数+无引导线、偶数(>0)+无引导线）各至少一例；引导线颜色在整个网格中统一；每个面板的封闭区域数不超过 3。

**规则**：
1. 对每个面板，将其线条画像素作为障碍，计算面板内 4-连通的黑(0)背景区域中被线条画完全包围的数量 N（与面板边缘相连的背景区域不算封闭）。
2. 判断该面板是否包含引导线（中间行全填 = 水平引导线；中间列全填 = 竖直引导线）。
3. 按以下决策表变换面板内容（引导线和线条画一起变换，灰色网格线不变）：
   - N 为奇数且有水平引导线：沿引导线上下镜像翻转面板内容。
   - N 为奇数且有竖直引导线：沿引导线左右镜像翻转面板内容。
   - N 为偶数（N>0）且有引导线：将所有封闭背景区域填充为引导线的颜色，同时将原线条画像素改为黑(0)（图底反转）。
   - N 为奇数且无引导线：将面板内容旋转 180 度。
   - N 为偶数（N>0）且无引导线：将所有封闭背景区域填充为线条画的颜色（仅填充，不擦除线条画）。
   - N = 0（无封闭区域）：面板保持不变。
4. 变换后的面板放回原位，灰(5)网格线保持不变。

**关键洞察**：单独知道引导线类型不足以确定操作（与 4e7e0eb9 不同，那里引导线类型直接决定操作），单独知道区域数也不够——必须同时确定两者才能查表。需要对比包含不同组合情况的多个示例才能归纳出完整的决策表。
