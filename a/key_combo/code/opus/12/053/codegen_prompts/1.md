## 新题 1：遮挡深度决定同心层数

**组合逻辑**：[排序/sort](已有) + [遮挡顺序/occlusion_order](已有) → [计数/counting](创新：遮挡入度作为层数参数) → [同心层填充/concentric_fill](创新：层数由外部参数控制而非固定)

**来源原语**：排序(c920a713), 遮挡顺序(c920a713), 交叉处可见性(c920a713), 矩形边框(c920a713), 同心层填充(a3f84088), 按距离循环配色(a3f84088), 计数(89565ca0)

**依赖链**：交叉分析得到遮挡有向图 → 每个边框的入度（被多少个边框遮挡）成为该边框的同心层数参数 → 按遮挡顺序从底到顶逐层绘制同心方环 → 高层边框覆盖低层重叠区域

从重叠矩形边框的交叉可见性推断遮挡等级，每个边框的遮挡入度决定其内部绘制多少层同心方环，最终按从底到顶的顺序叠加输出。

**输入结构**：约 15x15 黑(0)背景网格。3~4 个一像素厚的轴对齐矩形边框，每个边框使用不同的非黑颜色（如红(2)、蓝(1)、绿(3)、黄(4)）。边框两两有部分重叠，在交叉点处只有一个颜色可见（记录遮挡关系）。每个边框的完整矩形至少 5x5，保证有足够空间绘制多层同心环。生成约束：遮挡关系构成全序（无环），即存在唯一的从底到顶排列；每个边框的可见像素足以确定其完整边界框。

**规则**：
1. 对每种颜色，取其所有可见像素的边界框作为该边框的完整矩形。
2. 在两个边框的周长交叉处，若颜色 B 覆盖了颜色 A，则添加有向边 A→B（A 被 B 遮挡）。
3. 对每个边框计算入度 d（被多少个其他边框遮挡）。令该边框的同心层数 = d + 1。
4. 在每个边框的边界框内部绘制同心方环：从最外层开始，颜色交替为"边框本色 → 黑(0) → 边框本色 → 黑(0) → ..."，共绘制 d+1 层。若空间不足以放下所有层，截断到能容纳的最大层数。
5. 按遮挡顺序从底（入度最大的）到顶（入度=0的）依次绘制。后绘制的覆盖先绘制的像素。

**关键洞察**：遮挡深度不仅决定绘制顺序，还编码了每个边框内部的同心层数——被压在最底下的边框反而拥有最多的同心环层（因为入度最高），形成"越被遮挡越复杂"的反直觉映射。需要对比多个示例才能发现入度与层数的对应关系。
