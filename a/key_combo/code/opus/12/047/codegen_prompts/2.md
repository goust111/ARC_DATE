## 新题 2：标记像素计数决定菱形轮廓收缩或膨胀

**组合逻辑**：[计数](创新：计数结果的奇偶性决定几何变换方向) + [收缩/膨胀] + [擦除]（计数、收缩/膨胀均为已有原语，"计数奇偶驱动收缩/膨胀选择"是创新结构关系）

**来源原语**：计数/按数量排序(b1986d4b), 收缩/膨胀/菱形轮廓/半径微调(d753a70b), 擦除(bae5c565), 标记像素(e760a62e)

**依赖链**：计数每个菱形内部的标记像素数 -> 奇偶性决定是收缩还是膨胀 -> 执行半径调整 -> 擦除标记像素。删除计数则不知道该收缩还是膨胀；删除收缩/膨胀则计数结果无用。

统计每个菱形轮廓内部的标记像素数量，奇数则收缩一层、偶数则膨胀一层，最后清除所有标记。

**输入结构**：16x16 的橙(7)背景网格。包含 3~4 个不同颜色的一像素厚曼哈顿菱形轮廓（颜色从红(2)、蓝(1)、绿(3)、灰(5)中选取，每个菱形一种颜色）。菱形半径为 2~5，中心距足够大使得膨胀一层后菱形之间不重叠。每个菱形的严格内部区域（不含轮廓本身）散布有 1~4 个黄(4)标记像素。生成约束：收缩后的菱形半径不小于 1；膨胀后不超出网格边界且不与其他菱形（含其变换后形态）重叠。

**规则**：
1. 对每个菱形轮廓，计算其严格内部（曼哈顿距离小于半径的像素集合中）黄(4)标记像素的数量 N。
2. 若 N 为奇数，将该菱形半径减 1（收缩一层）；若 N 为偶数（且 N > 0），将该菱形半径加 1（膨胀一层）。
3. 以原菱形中心为圆心、新半径重绘菱形轮廓，颜色保持不变。
4. 清除所有黄(4)标记像素为背景色橙(7)。
5. 背景和其他非菱形、非标记的像素保持不变。

**关键洞察**：标记像素不是简单装饰——它们的数量奇偶性隐式编码了几何变换方向；仅看单个示例可能恰好所有菱形都是奇数标记（全收缩），需要对比多个示例才能发现偶数情况下的膨胀规则。
