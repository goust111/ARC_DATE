## 新题 11：精灵体内标记色选择描边色，描边区域再做对称轴镜像

**组合逻辑**：[描边](创新：描边目标不是孤立点而是不规则精灵体) + [重涂色/标记色决定描边色] + [镜像/对称轴借用]（描边、重涂色、镜像均为已有原语，"精灵体描边+全局对称展开"是创新结构关系——非流水线，描边和镜像共同约束输出）

**来源原语**：描边/空心矩形/标记色决定描边色(913fb3ed), 重涂色(67385a82), 镜像/对称体/对称轴借用/借轴复制非对称体(4c5c2cf0), 精灵体(a8c38be5)

**依赖链**：识别精灵体及其内部标记颜色 -> 标记颜色通过映射表确定描边颜色 -> 在精灵体外围画描边轮廓 -> 识别对称体并提取其对称轴 -> 将描边后的精灵体（含轮廓）整体关于该轴做镜像。删除描边则无轮廓可镜像；删除镜像则描边不扩展；删除标记色映射则描边颜色不确定。

精灵体按内部标记色获得特定颜色的外围描边，然后整个描边结果关于场景中对称体的轴做镜像复制。

**输入结构**：约 16x16 的黑(0)背景网格。包含 1~2 个不规则的单色 4-连通精灵体（灰(5)，3~6 像素，非对称形状）。每个精灵体内部（或紧邻的唯一像素）有一个标记像素：绿(3)、红(2)或青(8)中的一种。另有一个蓝(1)的小图案（约 3x3 或 5x5，具备水平和竖直双轴对称，如十字或正方形），这是对称体。所有图形互不接触，精灵体的外围一圈（描边区域）也不与其他图形重叠。生成约束：对称体不在网格中心；精灵体位于对称体的对称轴一侧（使得镜像后的精灵体落在另一侧空白区域）。

**规则**：
1. 对每个灰(5)精灵体，找到其内部或 4-邻域中唯一的彩色标记像素，确定标记颜色。
2. 颜色映射（与参考题 913fb3ed 相同）：绿(3)标记 -> 描边色为品红(6)；红(2)标记 -> 描边色为蓝(1)；青(8)标记 -> 描边色为黄(4)。
3. 将精灵体的外轮廓（精灵体像素的 8-邻域中所有背景像素）涂为对应描边色。精灵体本身和标记像素保持不变。
4. 识别蓝(1)对称体，提取其水平和竖直对称轴（以对称体中心为交点）。
5. 对每个精灵体及其描边轮廓的所有像素，计算它们关于两条轴的全部镜像位置（水平镜像、竖直镜像、双轴镜像共 3 个副本），在镜像位置绘制相同颜色的像素。若镜像位置已有非背景像素，不覆盖。
6. 对称体本身保持不变。

**关键洞察**：描边色由标记映射决定（需要从多个示例归纳映射表），而镜像轴由对称体位置决定（需要识别对称体并定位其中心）——两个独立规则系统共同决定输出，且对称体的偏心位置使得镜像结果在视觉上不对称于网格中心，增加推理难度。

```yaml
    adjacency: all 4-neighbors of every red pixel are either red or the carrier color (never the other color)
    no_row_overlap: red objects within the same carrier region never share rows [observed]
    gap: each object has gap>=1 to destination edge (never starts already flush)
  rule:
    blue carrier -> slide red object right until flush with right edge of blue region
    teal carrier -> slide red object left until flush with left edge of teal region
    shape and rows preserved; simultaneous moves; moved objects must not overlap
  slide_distance: 1-10 cells; gap_before equals slide distance

generation_strategy:
  approach: output-first
  steps:
    1. Choose grid size H,W in [9,15]. Pick split type (horiz or vert) and split position (30-70%).
    2. Fill the grid: one half blue, other half teal. Assign which color is which.
    3. For each carrier region, place 2-3 red rectangles at the destination (flush) position.
       Choose rectangle sizes from observed set. Ensure no row overlap within same carrier.
    4. Verify no overlap between placed red objects.
    5. To derive input: for each red object, slide it away from the flush edge by a random
       gap (1 to max available space), moving it in the opposite direction of the rule.
       Blue objects move left (away from right edge); teal objects move right (away from left edge).
    6. Validate all red objects remain within their carrier region after displacement.
```
