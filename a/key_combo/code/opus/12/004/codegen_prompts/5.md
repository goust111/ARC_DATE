## 新题 5：十字分割象限继承环形着色

**组合逻辑**：[填充 + 偶数切比雪夫距离（创新：环形填充颜色不统一，由所在象限的色键决定）] + [擦除（色键精灵用后擦除）] + [交叉点中心]

**来源原语**：填充/fill、偶数切比雪夫距离/even_chebyshev_distance、交叉点中心/intersection_center、十字前景/foreground_cross（759f3fd3）；擦除/erase（252143c9/009d5c81）；象限/quadrant（7953d61e/252143c9）

**依赖链**：十字交叉点确定环形中心 → 切比雪夫距离确定哪些像素属于偶数环 → 每个偶数环像素所在的象限决定它采用哪个色键的颜色 → 色键精灵本身被擦除。十字同时承担"分割象限"和"生成环形中心"两个角色；象限同时承担"定义区域"和"携带色键"两个角色。单独的环形逻辑或单独的象限逻辑都无法生成正确输出。

用前景十字将网格分成四个象限，每个象限内放置一个小色键精灵；以十字交叉点为中心画切比雪夫偶数距离环，每个环像素着色为其所在象限的色键颜色，色键精灵本身被擦除。

**输入结构**：约 17x17 的奇数边长正方形网格，背景为黑(0)。一条灰(5)前景色占据完整的一行和完整的一列，形成十字交叉。十字将网格分为四个象限区域。每个象限内有一个单像素的色键点，颜色互不相同，分别为红(2)、蓝(1)、绿(3)、黄(4)，位于该象限内靠近十字交叉点的位置（距交叉点 2~4 像素）。色键点以外的象限区域全为黑(0)背景。生成约束：四个色键点存在且颜色互不相同；色键点不在十字上。

**规则**：
1. 找到灰(5)十字的交叉点位置 (cr, cc)——该位置同时是灰色全行和灰色全列的交点。
2. 识别四个象限区域：左上（行 < cr 且列 < cc）、右上（行 < cr 且列 > cc）、左下（行 > cr 且列 < cc）、右下（行 > cr 且列 > cc）。
3. 找到每个象限内唯一的色键像素，记录其颜色。
4. 对每个象限内的每个黑(0)背景像素，计算其到交叉点 (cr, cc) 的切比雪夫距离 d = max(|r - cr|, |c - cc|)。
5. 若 d 为偶数，将该像素重涂为该像素所在象限的色键颜色。
6. 若 d 为奇数，该像素保持黑(0)。
7. 擦除每个色键像素（将其位置替换为该象限的环形规则结果——即根据该色键像素自身到交叉点的切比雪夫距离奇偶性决定是涂色还是保持黑色）。
8. 灰(5)十字保持不变。

**关键洞察**：输出呈现出"四色棋盘环"的视觉效果——同一个切比雪夫距离环在穿过不同象限时颜色不同。这不是四个独立的单色环形图案，而是一个以交叉点为中心的统一距离场被象限边界切割后分别着色的结果。
