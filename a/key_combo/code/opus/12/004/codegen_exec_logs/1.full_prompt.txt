## 新题 1：剪切量编码重涂色与直立还原

**组合逻辑**：[剪切变换（创新：剪切量作为编码信号而非视觉变换）] + [重涂色（创新：由几何测量值触发而非字形形状）] + [计数] + [碰撞优先级（创新：同一测量值同时决定颜色、还原量和叠放优先级）]

**来源原语**：剪切变换/shear_transform、偏移随行距增/offset_grows_with_distance（423a55dc）；重涂色/recolor、按形状映射颜色/shape_to_color_mapping（009d5c81）；计数/counting（b0c4d837/29623171）；排列顺序/ordering（4364c1c4）

**依赖链**：测量每个对象的剪切量 → 剪切量同时决定三件事：（1）查图例获得目标颜色用于重涂色，（2）确定反向剪切的偏移量用于直立还原，（3）确定叠放优先级用于还原后重叠区域的冲突解决。三条用途共享同一个测量值，删除任何一条都会导致输出错误或不确定。

将多个倾斜的前景对象通过测量其倾斜程度查表重涂色，然后拉直还原，重叠处按倾斜程度决定谁在上层。

**输入结构**：约 18x18 的网格，背景为黑(0)。网格底部一行是颜色图例：从左到右依次放置 1、2、3、4 个连续像素的色块，每个色块使用不同颜色（如 1 像素宽 = 红(2)，2 像素宽 = 蓝(1)，3 像素宽 = 绿(3)，4 像素宽 = 黄(4)），色块之间用 1 个黑(0)像素间隔。网格上方区域有 3~4 个灰(5)的 4-连通单色对象（每个约 8~15 像素），每个对象都呈现不同程度的左倾剪切——即对象的底行不动，往上每一行相对底行向左偏移 k 列（k 为该行到底行的垂直距离乘以该对象的剪切系数）。不同对象的剪切系数分别为 1、2、3、4 中的不同值。生成约束：各对象在还原直立后不会超出网格边界；还原后任意两个对象的包围框至少在某些行有列重叠（以测试叠放优先级）。

**规则**：
1. 对每个灰(5)对象，测量其剪切量 S：计算其最底行最左像素的列号减去其最顶行最左像素的列号。S 即为每行的累积偏移行数（因为剪切系数 = S / (底行行号 - 顶行行号)，但这里直接用总偏移 S 作为图例索引）。
2. 在底部图例中，找到宽度恰好为 S 个像素的色块，读取该色块的颜色 C。
3. 将该对象的所有灰(5)像素重涂为颜色 C。
4. 对该对象执行反向剪切还原：对于对象中位于行 r、列 c 的像素，将其移动到 (r, c + (bottom - r))，其中 bottom 是该对象最底行的行号。超出网格右边界的像素丢弃。
5. 当多个还原后的对象像素落在同一格时，S 值较大的对象覆盖 S 值较小的对象（高剪切量 = 高优先级）。
6. 图例行在输出中保留不变。

**关键洞察**：剪切量不是需要修复的视觉缺陷——它是一个编码信号，同时承载颜色映射、几何还原和叠放优先级三重信息。必须在还原之前测量剪切量，因为还原后编码信息消失。
