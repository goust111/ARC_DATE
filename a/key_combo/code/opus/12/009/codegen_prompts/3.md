## 新题 3：路径生长划分区域与标记像素定色填充

**组合逻辑**：[生长 grow / 寻路 pathfinding](已有) + [遇障碍则绕行 detour_on_obstacle](已有) → [洪泛填充 flood_fill](创新：填充对象不是预设区域而是路径动态生成的区域) → [重涂色 recolor](创新：填充颜色由区域内含的标记像素决定，而非行键或固定规则)

**来源原语**：生长 grow / 寻路 pathfinding / 起点像素 start_pixel / 障碍像素 blocker_pixel / 逐步推进 stepwise_advance / 遇障碍则绕行 detour_on_obstacle (d9f24cd1), 洪泛填充 flood_fill / 封闭区域 enclosed_region / 区域排列顺序 region_order (7447852a), 重涂色 recolor / 控制像素 control_pixel (c9f8e694), 标记像素 marker_pixel (97239e3d)

**依赖链**：路径生长输出的红色轨迹充当区域分隔线，定义了洪泛填充的封闭区域边界；每个区域内的标记像素颜色决定该区域的填充色。路径的具体走向（受障碍影响）直接改变区域形状，从而改变哪个标记落入哪个区域。三个环节环环相扣：删除路径则区域不存在；删除标记则填充色未定义；改变障碍布局则路径变化导致标记归属区域发生变化。

从底部起点向上生长路径（遇障碍右绕），路径将网格分割成若干封闭区域，每个区域用其内部标记像素的颜色填充。

**输入结构**：约 16x16 的黑(0)背景网格。底行有 2~3 个红(2)起点像素，位于不同列。灰(5)障碍像素散布在网格内部（不在最外一圈边界上）。另有若干单像素标记，颜色取自蓝(1)、绿(3)、黄(4)，放置在网格内部的空白区域（不与障碍相邻）。生成约束：红色路径生长完成后，路径轨迹加上网格边界将黑色区域分割成若干 4-连通分量；每个分量内恰好包含一个标记像素（保证填充色唯一确定）。标记像素本身不在任何路径上，也不与障碍相邻。

**规则**：
1. 对每个红(2)起点像素，从其位置开始逐步向上生长路径：每步尝试向上移动一格。若上方格为灰(5)障碍，则改为向右移动一格。若右方也不可行（障碍或超出网格），路径终止。路径持续生长直到到达顶行或终止。路径经过的每个格（含起点）涂为红(2)。
2. 所有路径生长完毕后，红(2)路径像素和灰(5)障碍像素视为边界。找到所有被边界和网格边缘围成的 4-连通黑(0)区域。
3. 对每个黑色区域，找到其中唯一的标记像素（蓝(1)、绿(3)或黄(4)）。将该区域内所有黑(0)像素洪泛填充为该标记的颜色。
4. 标记像素本身保留原色不变。红(2)路径和灰(5)障碍保留不变。

**关键洞察**：红色路径并非最终输出的主体——它们是"隐形的刀"，将网格切割成区域。求解者必须先完整模拟路径生长（包括所有绕行），才能确定区域边界，进而才能知道每个标记像素控制哪片区域的颜色。

<description>
Draw a green one-cell border around every adjacent red pair while leaving isolated red pixels unchanged.

Input structure
- The grid is a black background containing only red foreground pixels.
- Each 4-connected red object is either a single pixel or a two-pixel horizontal/vertical domino.

Rule
- Preserve all input pixels.
- For each red domino, expand its bounding box by one cell in all directions, clipped to the grid.
- Paint the perimeter of that expanded box green wherever it is currently black.

Key insight
- The green marks are not drawn around all red pixels, only around the 4-connected red objects of area two.

1. `main(grid)` 必须实现新题描述中的确定性转换规则，不能只识别 `generate_input()` 的固定模板。禁止不同的input网格输出相同的output网格。
2. `generate_input()` 必须随机生成多样样例，不能固定死。随机维度应覆盖：网格大小、对象数量、位置、颜色、方向、形状参数或关键分支。注意若描述中存在若干，需实现而不是只有单个，包括object或者对应关系等等。且若涉及到最短路径，则输入网格中必涉及到多条路径，对选择造成干扰。
3. 生成器必须保证输入满足 `main()` 的隐式假设：对象不重叠、不越界、特殊标记唯一或可区分、匹配关系无歧义、关键分支出现概率相同。
4. 禁止把 ARC 颜色 id 、亮度、拼写等当作人类不可见的数值语义参与排序、大小比较或隐藏映射。颜色变化必须有可见结构线索。注意颜色亮度、拼写等也是不可见信息，若描述中出现违规的颜色id或者亮度，可自行使用少量的固定颜色替代，但注意生成时要在三个以内输入输出网格中对所有变换100%覆盖度。

6. 若规则有多个分支，生成器不能长期固定成一个分支；应让分支在随机样例中合理出现。分支概率不必平均——难以发现的隐蔽分支（如少数情况下才触发的特殊规则）应适当提高出现概率，确保在 3 个训练示例中至少出现一次，否则求解者无法归纳该规则。对于颜色映射类规则，确保 2 个左右的示例即可覆盖所有映射关系（每种颜色→颜色的映射至少在某个示例中出现过）。
