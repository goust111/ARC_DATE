## 新题 5：压缩后稀疏标记做四象限镜像，镜像结果按沙漏距离重涂色

**组合逻辑**：[坐标压缩/coordinate_compression](已有) → [对称补全/symmetry_complete + 四象限镜像填充](已有) → [沙漏距离谓词/hourglass_distance_predicate + 重涂色/recolor](创新：将沙漏距离判定应用于镜像产生的新像素而非原有像素)

**来源原语**：坐标压缩/coordinate_compression、分隔线/separator_line、块距离/block_distance、沙漏距离谓词/hourglass_distance_predicate（参考题 7d419a02）；对称补全/symmetry_complete、十字轴线/cross_axis、稀疏标记/sparse_marker、双轴对称/biaxial_symmetry、四象限镜像填充/quadrant_mirror（参考题 60d73be6）

**依赖链**：分隔线必须先压缩去除才能得到正确的像素距离→压缩坐标下做四象限镜像补全→镜像结果中每个像素按沙漏距离谓词决定是否重涂色。去掉压缩则距离计算错误；去掉镜像则待涂色的像素不完整；去掉沙漏判定则无颜色区分。

去除分隔线后在压缩坐标中对稀疏标记做十字轴四象限镜像补全，再按各像素到十字中心的沙漏距离关系将落入沙漏内的镜像像素重涂为第二色。

**输入结构**：约 15x15 的黑(0)背景网格。网格中有若干条完整的灰(5)分隔行和分隔列（仅沿一个轴方向，例如 2~3 条灰色完整行），将网格分成条带。有一条完整的品红(6)行和一条完整的品红(6)列形成十字轴线。在十字轴线的一个象限中散布 3~5 个蓝(1)稀疏标记像素（单像素点）。生成约束：分隔线均平行于同一轴（全是行或全是列）；稀疏标记仅出现在一个象限中；十字轴线不与分隔线重叠。

**规则**：
1. 删除所有灰(5)分隔行或分隔列，将其上下（或左右）的网格部分合拢，得到压缩后的网格。品红(6)十字轴线和蓝(1)标记的相对位置随之更新。
2. 对压缩网格中每个蓝(1)标记像素，计算其关于品红(6)十字行的镜像位置、关于品红(6)十字列的镜像位置、以及关于两者交叉点的中心对称位置。在这三个镜像位置放置蓝(1)像素（超出网格边界则忽略）。
3. 确定沙漏方向：分隔线所沿的原始轴为沙漏窄轴，垂直方向为沙漏开口轴。
4. 对压缩网格中所有蓝(1)像素（含原始标记和镜像生成的），计算其到十字交叉点的窄轴距离 dn 和开口轴距离 do（以像素为单位）。若 dn > 0 且 do > 0 且 dn <= do，则该像素落入沙漏内，将其重涂为黄(4)。
5. 十字交叉点上的像素保持品红(6)不变。十字轴线上（非交叉点）的像素保持品红(6)。dn = 0 或 do = 0 的蓝(1)像素保持蓝(1)。

**关键洞察**：镜像补全和沙漏重涂色的耦合在于——镜像产生的像素处于不同象限，其到十字中心的距离关系各不相同，因此同一个原始标记的四个副本可能有的被重涂、有的不被重涂，产生对称但不均匀的颜色分布。

## 实现要求

1. `main(grid)` 必须实现新题描述中的确定性转换规则，不能只识别 `generate_input()` 的固定模板。禁止不同的input网格输出相同的output网格。
2. `generate_input()` 必须随机生成多样样例，不能固定死。随机维度应覆盖：网格大小、对象数量、位置、颜色、方向、形状参数或关键分支。注意若描述中存在若干，需实现而不是只有单个，包括object或者对应关系等等。且若涉及到最短路径，则输入网格中必涉及到多条路径，对选择造成干扰。
3. 生成器必须保证输入满足 `main()` 的隐式假设：对象不重叠、不越界、特殊标记唯一或可区分、匹配关系无歧义、关键分支出现概率相同。
4. 禁止把 ARC 颜色 id 、亮度、拼写等当作人类不可见的数值语义参与排序、大小比较或隐藏映射。颜色变化必须有可见结构线索。注意颜色亮度、拼写等也是不可见信息，若描述中出现违规的颜色id或者亮度，可自行使用少量的固定颜色替代，但注意生成时要在三个以内输入输出网格中对所有变换100%覆盖度。
5. 输出样例要视觉清晰，人类必须能从输入输出对中肉眼辨认出规律。具体要求：避免对象粘连、覆盖关系混乱、同一像素多重语义；不同逻辑步骤产生的结果不要大面积层叠在一起导致无法分辨哪个颜色属于哪个步骤；输入中各元素之间保持足够间距，输出中新增的标记/填充/路径等应与背景和已有元素在颜色上有明显区分；若规则涉及多层叠加，生成时控制对象密度和尺寸，确保叠加区域只占少数像素而非铺满整个网格。
6. 若规则有多个分支，生成器不能长期固定成一个分支；应让分支在随机样例中合理出现。分支概率不必平均——难以发现的隐蔽分支（如少数情况下才触发的特殊规则）应适当提高出现概率，确保在 3 个训练示例中至少出现一次，否则求解者无法归纳该规则。对于颜色映射类规则，确保 2 个左右的示例即可覆盖所有映射关系（每种颜色→颜色的映射至少在某个示例中出现过）。
