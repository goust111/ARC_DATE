## 新题 8：边缘带迁移后的图案作为精灵体做交替翻转平铺

**组合逻辑**：[平移/translate + 擦除/erase + 标记指示活跃边](已有) → [裁剪/crop](已有，提取迁移结果) → [平铺/tile + 交替翻转平铺/alternating_reflections_tiling](创新：平铺对象不是原始输入而是迁移后的边缘带图案)

**来源原语**：平移/translate、擦除/erase、边缘带/edge_strip、标记像素/marker_pixel、标记指示活跃边/marker_active_edge、含轨迹色行列移动/trail_color_move（参考题 d255d7a7）；平铺/tile、精灵体/sprite、阵列排布/array_layout、交替翻转平铺/alternating_reflections_tiling（参考题 8d5021e8）

**依赖链**：标记像素确定活跃边→边缘带内容迁移到对侧→迁移后的图案被裁剪为精灵体→精灵体做交替翻转平铺填充网格。去掉迁移则精灵体内容错误；去掉平铺则输出不完整。

将标记指示的边缘带迁移到对侧边缘，裁剪迁移后的图案为精灵体，再用交替翻转平铺将该精灵体填满输出网格。

**输入结构**：约 12x6 的黑(0)背景网格（高大于宽）。网格顶部 2~3 行构成边缘带，包含蓝(1)轨迹色像素形成简单图案（非对称，3~6 个蓝色像素）。网格最左列或最右列有一个红(2)标记像素，位于顶部边缘带所在的行中，指示顶边为活跃边。其余行为黑(0)背景，可能有少量蓝(1)轨迹像素散布（表示轨迹残留）。生成约束：边缘带图案在裁剪后可形成一个适合平铺的矩形精灵体；输出网格尺寸为精灵体高度的 3 倍、宽度的 2 倍。

**规则**：
1. 识别红(2)标记像素位置，确定其最近的网格边（此处为顶边）为活跃源边。
2. 读取顶部边缘带（从第 0 行起、向下直到连续全黑行之前的所有行），记录其中蓝(1)像素的图案。记边缘带高度为 H、网格宽度为 W。
3. 将边缘带图案复制到网格底部对应位置（底部 H 行），保持列坐标不变。
4. 擦除顶部边缘带（设为黑(0)），擦除红(2)标记像素，擦除网格中所有残留的蓝(1)轨迹像素。
5. 裁剪底部 H 行 x W 列的矩形区域作为精灵体 S。
6. 构建输出网格（3H 行 x 2W 列）：
   - 中间行带（第 H 行至第 2H-1 行）：左半拼 S 的左右镜像，右半拼 S 原样。
   - 顶行带（第 0 行至第 H-1 行）：将中间行带上下翻转后放入。
   - 底行带（第 2H 行至第 3H-1 行）：同样将中间行带上下翻转后放入。

**关键洞察**：平铺的内容不是静态给定的——它是边缘迁移操作的产物，迁移改变了图案的位置但保留了形态，然后才进入平铺流程。两个参考题中分别独立的操作（迁移和平铺）在此形成了"一个操作的输出是另一个操作的输入模板"的耦合。
