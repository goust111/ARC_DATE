## 新题 4：腔室内标记位置编码旋转角度，精灵体旋转后嵌入腔室

**组合逻辑**：[格点骨架/lattice_frame + 封闭腔室/enclosed_cavity + 标记指定腔室](已有对象) → [标记位置编码旋转](创新：标记在腔室内的相对位置决定旋转角度，而非单纯指定目标) → [旋转/rotate + 对接拼合/docking](已有操作，创新触发条件)

**来源原语**：格点骨架/lattice_frame、封闭腔室/enclosed_cavity、标记像素/marker_pixel、标记指定腔室/marker_designates_cavity（参考题 17b866bd）；旋转/rotate、对接拼合/docking、颜色匹配配对/color_match_pairing、对称消歧旋转/symmetry_disambiguates_rotation（参考题 2c181942）

**依赖链**：标记像素的颜色与外部精灵体配对→标记在腔室内的角落位置编码旋转角度→精灵体按该角度旋转后嵌入腔室。去掉标记位置信息则旋转角度未知；去掉颜色匹配则不知道哪个精灵体进入哪个腔室。

读取格点骨架中每个腔室内标记像素的颜色和角落位置，将颜色匹配的外部精灵体旋转到标记指定的方向后嵌入对应腔室。

**输入结构**：约 20x20 的黑(0)背景网格。网格中有一个青(8)格点骨架，形成 2x2 或 2x3 的规则腔室阵列，每个腔室内部为 4x4 的黑(0)空间。若干腔室（2~4 个）的内部四角之一有一个单独的彩色标记像素（颜色各不同，从蓝(1)、红(2)、黄(4)、橙(7)中选取）。网格中骨架外围的空白区域散布着与标记像素同色的小精灵体（4-连通，4~8 像素，非对称形状，每色一个）。生成约束：每个精灵体的边界框不超过 4x4（恰好可放入腔室内部）；精灵体本身不具有四重旋转对称性（确保旋转有意义）；每个腔室最多一个标记。

**规则**：
1. 识别青(8)格点骨架及其所有封闭腔室（4x4 内部空间）。
2. 对每个含标记像素的腔室，记录标记的颜色 C 和它在 4x4 内部空间中的角落位置：左上角 → 0 度，右上角 → 90 度顺时针，右下角 → 180 度，左下角 → 270 度顺时针。
3. 在骨架外找到颜色为 C 的精灵体，将其裁剪为最小边界框。
4. 将该精灵体按步骤 2 确定的角度顺时针旋转。
5. 擦除腔室内的标记像素，将旋转后的精灵体放入该腔室的内部空间中，左上角对齐。精灵体的有色像素覆盖黑(0)背景，精灵体边界框中的黑(0)像素不覆盖腔室原有内容。
6. 无标记的腔室保持原样（内部全黑）。擦除骨架外原精灵体所在位置的像素（设为黑(0)）。

**关键洞察**：标记像素承担双重角色——颜色用于配对（哪个精灵体进入哪个腔室），位置用于编码旋转指令（角落位置 = 旋转角度）——这种"同一元素的不同属性驱动不同逻辑"在参考题中不存在。
