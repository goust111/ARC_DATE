## 新题 7：走廊路径段长编码同心层厚度，转弯处障碍色指定层色

**组合逻辑**：[射线延伸/ray_extend + 转弯/turn + 碰撞转向/collision_turn](已有) → [路径段长度 → 嵌套层厚度](创新：路径几何参数编码构建参数) → [嵌套包裹/nested_wrapping + 逐层构建](已有操作，层参数由路径提供)

**来源原语**：射线延伸/ray_extend、转弯/turn、起点条/start_bar、障碍像素/blocker_pixel、走廊路径/corridor_path、碰撞转向/collision_turn、遇障碍直角转/right_turn_at_block（参考题 6bcdb01e）；嵌套包裹/nested_wrapping、逐层构建/layer_by_layer_build、同心正方形层/concentric_square_frame、条高决定框厚/stripe_height_as_thickness（参考题 45a5af55）

**依赖链**：路径必须先完整追踪才能得到各段长度→段长度序列决定同心方框的各层厚度→转弯处的障碍像素颜色决定各层颜色。路径追踪、厚度提取、颜色提取三者紧密交织在同一走廊结构中。

从边界起点条出发沿走廊行进，每遇障碍像素转弯，最终离开网格；将每段直线的长度作为同心方框的层厚、转弯处障碍的颜色作为层色，在网格中心构建嵌套同心方框。

**输入结构**：约 20x20 的黑(0)背景网格。网格某条边上有一个绿(3)起点条（2 像素，4-连通，其中一个像素在网格边界上）。网格内散布若干单像素障碍点，障碍颜色各不相同，从蓝(1)、红(2)、黄(4)、橙(7)中选取（3~5 个障碍像素），排列形成一条单像素宽的走廊。走廊每段路径长度在 2~5 像素之间。生成约束：走廊路径的每个转弯处恰好只有一个合法的 90 度转向（无歧义）；最终路径会离开网格边界；路径段数等于障碍像素数加 1；网格中心区域（用于绘制同心方框）足够空旷。

**规则**：
1. 从起点条的边界像素出发，沿通过另一个起点像素的方向进入网格。将经过的黑(0)像素涂为绿(3)。
2. 当下一个像素是障碍像素时，记录当前直线段的长度 L（从上一个转弯点或起点到当前位置的绿色像素数），以及该障碍像素的颜色 C。然后转向唯一可行的 90 度方向继续行进。
3. 当下一个像素超出网格边界时，记录最后一段的长度 L_last，停止行进。
4. 设共记录了 N 个障碍像素（产生 N 个颜色 C1...CN 和 N+1 段长度 L1...LN+1）。
5. 以网格中心像素为中心点，用绿(3)填充一个边长为 (2 * L1 - 1) 的实心正方形作为最内层。
6. 第 i 层（i = 1 到 N）：在当前形状外围包裹一层厚度为 L_{i+1} 的正方形框，颜色为 Ci。
7. 超出网格边界的部分裁剪掉。擦除走廊路径上的绿色像素和障碍像素（设为黑(0)），仅保留同心方框。

**关键洞察**：走廊路径的几何结构（段长和障碍颜色）同时编码了同心方框的两种参数（厚度和颜色），路径追踪是一次性的信息提取过程，提取完毕后路径本身被擦除——走廊是指令而非输出。
