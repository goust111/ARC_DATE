## 新题 1：标记投票决定同心层序

**组合逻辑**：[计数/投票](创新：投票结果不输出单色，而驱动空间排序) + [排序](创新：排序键由投票计数产生，非原始长度) + [同心层填充](已有原语) + [标记归属区域](已有原语)

**来源原语**：计数/投票(de1cd16c)、标记像素/色块区域/标记归属区域/最多标记区胜出(de1cd16c)、排序/按长度降序(3ee1011a)、同心层填充/同心方形层/由外到内嵌套(3ee1011a)

**依赖链**：标记像素的区域归属决定每个区域的票数 -> 票数大小决定排序顺序 -> 排序顺序决定同心层的由外到内赋色。删去投票环节则无法确定层序；删去同心填充则投票结果无处输出；删去归属判断则无法分配票数。

将分布在多个色块区域中的标记像素按归属计数，按得票数从多到少依次填入同心方环的从外到内各层，输出一个紧凑的同心方阵。

**输入结构**：约 15x15 的网格，黑(0)背景。网格中有 3~5 个大的单色矩形区域（每个区域使用不同颜色，如蓝(1)、绿(3)、黄(4)、品红(6)），各区域互不重叠且互不相邻（最小间距 1 像素）。一种稀有颜色——红(2)——仅以单像素形式散布在这些矩形区域内部，总数 5~12 个。每个红(2)标记像素严格位于某个矩形区域的内部（4-邻域全部为该区域颜色）。不同区域中的红(2)标记数量互不相同。生成约束：区域数量 N 满足 3 <= N <= 5；每个区域至少包含 1 个标记像素；各区域的标记数互不相等。

**规则**：
1. 找到全局最稀有的非背景颜色（出现次数最少），这些像素即为标记像素。
2. 对每个标记像素，检查其 4-邻域确定所属区域颜色。统计每种区域颜色包含的标记数。
3. 按标记数从大到小对区域颜色排序。
4. 令 N = 区域颜色种数，创建 (2N-1) x (2N-1) 的输出网格。
5. 最外层方环（第 0 层）填入标记数最多的区域颜色，第 1 层填入第二多的，依此类推，最内层（中心 1x1 像素）填入标记数最少的区域颜色。
6. 处理顺序冲突规则：标记数相等时不会出现（生成约束已保证互不相等）。

**关键洞察**：标记像素本身不出现在输出中——它们通过"投票"间接决定了颜色在几何结构中的空间排列，同一组区域颜色换不同的标记分布会产生完全不同的同心层序。
