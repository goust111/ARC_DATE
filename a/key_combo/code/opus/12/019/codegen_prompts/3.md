## 新题 3：指示像素引导周期条纹投射与计数冲突裁决

**组合逻辑**：[射线延伸](已有原语) + [周期掩码](已有原语) + [方向指示](创新：指示像素不再在矩形边框上，而在独立条纹源中，同时携带方向和优先级信息) + [计数](创新：条纹源内部像素数量作为冲突优先级)

**来源原语**：射线延伸/矩形边框/周期条纹/标记条/周期掩码/条纹延伸全行列(6a980be1)、方向指示/指示像素/指示侧扩展至边界(b527c5c6)、计数(de1cd16c)

**依赖链**：指示像素确定每个条纹源的投射方向 -> 周期掩码确定投射的行/列选择 -> 计数解决交叉覆盖冲突。删去指示像素则方向不确定；删去周期提取则不知道投射哪些行列；删去计数则交叉区域无法裁决。

从多个带指示像素的条纹源中提取周期模式，沿指示方向向画布边缘投射，交叉区域由条纹源内前景像素数量多者覆盖。

**输入结构**：约 20x20 的网格，黑(0)背景。网格中有 2~3 个互不重叠的小矩形区域（每个约 4x6 到 6x8 像素），每个矩形区域由一种边框颜色（如蓝(1)、绿(3)、品红(6)）绘制一像素宽的边框。每个矩形内部在水平方向或垂直方向上有周期性条纹：某些行或列填充了另一种颜色（橙(7)），其余内部行/列为黑(0)。条纹周期为 2 或 3（即每隔 1 或 2 行/列出现一行/列橙色）。每个矩形的边框上恰好有一个红(2)指示像素，替换了该位置的边框颜色。指示像素所在的边（上/下/左/右）决定投射方向。生成约束：不同矩形的投射方向允许相同或不同；每个矩形内部的橙(7)条纹像素总数互不相同。

**规则**：
1. 对每个矩形区域，定位其红(2)指示像素。指示像素所在边决定投射方向：上边 -> 向上投射；下边 -> 向下投射；左边 -> 向左投射；右边 -> 向右投射。
2. 提取该矩形内部的周期条纹模式：记录哪些行（若条纹为水平方向）或哪些列（若条纹为垂直方向）包含橙(7)像素，得到一组相对偏移值。
3. 将条纹模式沿投射方向延伸到画布边缘：对于水平条纹向上/下投射的情况，将条纹行模式沿列方向扩展至画布全宽，从矩形边界开始、向投射方向复制周期模式直到画布边缘，使用该矩形的边框颜色绘制；对于垂直条纹向左/右投射的情况，类似地将列模式沿行方向扩展至画布全高。
4. 指示像素自身沿投射方向画一条红(2)直线至画布边缘。
5. 冲突解决：当两个矩形的投射区域重叠时，内部橙(7)条纹像素总数较多的矩形优先（其颜色覆盖对方）。红(2)指示线始终覆盖一切。
6. 原始矩形区域保留不变（边框和内部条纹均保留）。

**关键洞察**：矩形内部的条纹既编码了"投射什么模式"，其像素总数又隐式编码了冲突时的优先级——同一组条纹像素同时承担了内容和权重两个角色，求解者必须同时识别两种功能。
