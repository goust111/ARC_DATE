## 新题 2：形状等价类决定射线朝向

**组合逻辑**：[形状匹配/旋转翻转等价](已有原语) + [射线延伸](已有原语) + [朝向与背离](创新：不再由颜色决定方向，而由同形组内相对距离决定) + [分隔线](已有原语)

**来源原语**：形状匹配/归一化掩码/旋转翻转等价/等价涂指定色(6165ea8f)、射线延伸/分隔线/朝向与背离/颜色决定射线方向(8d510a79)、忽略干扰项(6165ea8f)

**依赖链**：旋转翻转等价检测将精灵体分组 -> 组内距离比较确定哪个精灵体朝向分隔线、哪些背离 -> 射线方向由此确定。删去等价检测则无法分组，无法确定谁朝谁背；删去分隔线则无"朝向/背离"的参照；删去射线延伸则分组结果无输出形式。

在分隔线两侧识别出形状等价的精灵体对，每组中离分隔线最近的精灵体向分隔线发射射线，其余向画布边缘发射射线；无等价伙伴的精灵体不发射。

**输入结构**：约 18x20 的网格，黑(0)背景。一条完整的灰(5)水平直线将网格分为上下两半（灰线占据某一行的全部列）。上下两半各散布 3~5 个小型单色精灵体（4-连通，3~6 像素，各自颜色不同，使用蓝(1)、红(2)、绿(3)、黄(4)、品红(6)、橙(7)中的若干种）。部分精灵体在旋转或翻转（8 种二面体变换）下形状相同，形成 2~3 个等价组，每组恰好 2 个成员。其余精灵体无等价伙伴。精灵体之间互不接触，且不与灰线相邻。生成约束：每个等价组的两个成员分别位于灰线的上下两侧；同一侧不会有两个互相等价的精灵体。

**规则**：
1. 检测灰(5)水平分隔线。
2. 提取每个非背景、非灰色的 4-连通分量作为精灵体。将每个精灵体裁剪到其紧凑边界框，得到归一化掩码。
3. 对所有精灵体两两比较归一化掩码（考虑 8 种二面体变换：4 个旋转 x 2 个翻转），形状相同的归为一组。
4. 对于每个等价组（恰好 2 个成员）：计算每个成员到灰线的最小曼哈顿距离（精灵体任意像素到灰线所在行的最小行距）。距离较小的成员为"近端"，距离较大的为"远端"。
5. 近端精灵体：从其离灰线最近的像素出发，沿垂直方向（朝灰线方向）画一条射线，射线在灰线前一行停止（不覆盖灰线），颜色为该精灵体自身颜色。
6. 远端精灵体：从其离灰线最远的像素出发，沿垂直方向（远离灰线方向）画一条射线，射线延伸到画布边缘，颜色为该精灵体自身颜色。
7. 无等价伙伴的精灵体保持原样，不发射任何射线。
8. 若两条射线经过同一像素，后处理的覆盖先处理的。处理顺序：按精灵体边界框左上角的行优先、列次优先排序。

**关键洞察**：颜色不再直接编码射线方向——求解者必须先通过形状匹配发现哪些精灵体是"同类"，然后在同类内部通过与分隔线的距离比较推断朝向/背离关系，这两个判断层层嵌套，缺一不可。
