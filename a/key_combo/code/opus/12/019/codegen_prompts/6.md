## 新题 6：重力落轨后沿周期轨道碰撞滑行

**组合逻辑**：[重力下落](已有原语) + [滑动](创新：滑动不在自由空间而是沿离散轨道) + [周期条纹作为轨道](创新：周期条纹不再是投射模式而是物理运动轨道) + [碰撞阻挡/远近序处理](已有原语)

**来源原语**：重力下落/碰撞停止(28a6681f)、滑动/连通分量/碰撞阻挡/重力远近序处理(5ffb2104)、周期条纹(6a980be1)

**依赖链**：周期条纹定义哪些行是合法轨道 -> 重力下落将对象安置到最近的下方轨道 -> 碰撞滑行按远近序在轨道上排列最终位置。删去轨道则对象落到底部而非离散位置；删去重力则对象不会到达轨道；删去碰撞序则同轨道对象可能重叠。

彩色对象在重力下落时只能停在周期分布的灰色轨道行上，落定后在同一轨道上向右滑行直至碰撞停止，最右侧对象先定位。

**输入结构**：约 18x16 的网格，黑(0)背景。灰(5)水平轨道行以固定周期出现（每隔 3 或 4 行一条，全宽灰线）。在轨道行上方的空间中散布 4~7 个小型彩色对象（每个为单色 4-连通分量，2~4 像素，颜色各异，使用蓝(1)、红(2)、绿(3)、黄(4)、品红(6)、橙(7)）。这些对象悬浮在轨道之间的黑色区域中。生成约束：每个对象的宽度不超过 2 像素；同一轨道上方区域最多出现 3 个对象（防止过度拥挤）；没有对象直接处于另一个对象正下方（无垂直遮挡）。

**规则**：
1. 识别所有灰(5)水平全宽行作为轨道。
2. 每个彩色对象向下移动，直到其最底部像素的下一行是灰(5)轨道行。对象停在该轨道行的正上方（对象底部像素行 = 轨道行 - 1）。若对象下方没有轨道行（已在最低轨道下方），对象落到网格底部边缘。
3. 落定后，统计每条轨道上（即紧贴其上方的）有哪些对象。对每条轨道，按对象边界框最右列从大到小排序（即最右侧的对象先处理）。
4. 最右侧对象不移动（已就位）。第二右的对象向右平移，直到其右边缘紧贴已就位对象的左边缘（间距 0，相邻）或到达网格右边缘。依次处理更左的对象，每个向右滑行直至碰到已定位对象或右边缘。
5. 对象保持原始形状和颜色，灰(5)轨道行保持不变。对象像素覆盖在背景之上（不覆盖灰线）。

**关键洞察**：周期轨道间距决定了哪些对象会"合流"到同一轨道上（间距不同，分组不同），而同轨道上的碰撞滑行又受分组结果制约——轨道周期是控制最终布局的隐藏参数。
