## 新题 7：空洞拓扑选面板、对称修复缺失、空洞填色后象限提取

**组合逻辑**：[计数/counting](创新：空洞数量用于面板选取而非重涂判据) + [对称补全/symmetry_completion](创新：修复面板中的缺失像素) + [填充/fill](创新：修复后新封闭的空洞被填色) + [裁剪/crop](创新：提取象限而非整体)

**来源原语**：裁剪/crop、象限/quadrant、角落象限提取/corner_quadrant_extraction、四向反射对称/four_way_reflective_symmetry（来自 73182012）；对称补全/symmetry_completion、双轴镜像对称/bilateral_mirror_symmetry、遮挡由镜像恢复/occluded_recovered_by_mirror（来自 67b4a34d）；封闭区域/enclosed_region、有空洞则重涂/recolor_if_hole（来自 810b9b61）；前景面板/foreground_panel（来自 73182012）；缺失像素补新色/missing_new_color（来自 6d75e8bb）；计数/counting（来自 e50d258f）

**依赖链**：空洞拓扑检测 → 选取目标面板 → 对称修复缺失像素 → 修复可能封闭新空洞 → 所有空洞填新色 → 提取左上象限。对称修复改变了拓扑结构（封闭原本因缺失而开放的区域），使填色操作产生修复前不存在的效果。

在多个四向对称面板中，选取包含最多封闭空洞的面板，用对称性修复其缺失像素，将修复后的所有封闭空洞填充新颜色，最终输出左上象限。

**输入结构**：约 20x20 的黑(0)背景网格，包含 3 个互不相邻的前景矩形面板。每个面板具有偶数高度和偶数宽度（约 8x8 或 10x10），由非黑(0)的前景色像素构成图案。每个面板具有四向反射对称性（上下、左右镜像），但其中一个面板有 2-4 个像素被替换为黑(0)背景色（造成对称性局部破损）。面板内的图案包含形状各异的前景结构，部分结构包围了黑(0)空洞（4-连通的黑(0)区域被前景像素完全环绕）。不同面板的空洞数量不同。生成约束：空洞数最多的面板唯一确定，且该面板恰好是有缺失像素的面板；该面板的缺失像素中至少有一个位于某结构的边界上，使得修复前该结构旁的黑(0)区域与外部连通（非封闭），修复后变为完全封闭的空洞。

**规则**：
1. 对每个面板，统计其内部严格封闭的空洞数量（4-连通黑(0)区域，所有方向被前景像素完全包围、不与面板外部黑(0)连通）。
2. 选取空洞数最多的面板作为目标面板。
3. 目标面板具有四向反射对称性（左右 + 上下镜像），但有若干像素缺失（被替换为黑(0)）。对每个缺失位置，从其水平镜像、垂直镜像或 180 度旋转对应位置中找到非黑(0)值，用该值填补缺失像素。优先使用水平镜像位置的值；若该位置也缺失，使用垂直镜像；若仍缺失，使用 180 度对应位置。
4. 修复后重新检测面板内所有封闭空洞（修复可能封闭了新的区域）。将所有封闭空洞中的黑(0)像素填充为红(2)。
5. 输出目标面板左上象限（即面板高度/2 行、宽度/2 列的左上角区域）。

**关键洞察**：面板选取基于修复前的空洞计数，但修复操作本身会创造新的封闭空洞（因为缺失像素恢复后封闭了原本与外部连通的区域）。填色操作作用于修复后的拓扑，包括这些新产生的空洞。选取、修复、填色三步形成因果链，且修复步骤改变了拓扑状态。

```yaml
    single isolated pixels (area=1), scattered on bg
    total: 7-32 across the grid
    per enclosed region: 3-7 markers with 2-3 distinct colors; one color is strictly most frequent (majority)
    stray markers: 0-14 pixels outside all enclosed regions, removed in output
  colors: outline colors and marker colors may overlap (test_0) but each outline has a unique color
  rule:
    keep all outline pixels unchanged
    fill each enclosed interior with the majority marker color found inside it
    remove all isolated marker pixels (both stray and inside-region ones replaced by fill)
    open outlines and bg unchanged

generation_strategy:
  approach: output-first
  steps:
    1. Choose grid size in [16-26] x [14-24].
    2. Choose 1-4 outline colors (distinct). For each, decide closed (loop) or open (path), with at least 1 closed and at most 1 open.
    3. Build closed outlines as 1-pixel-thick rectilinear loops (irregular polygons with 8-14 corners, bbox 6x6 to 13x11). Place non-overlapping on the grid with min manhattan gap >= 3.
    4. Optionally build 1 open outline as a 1-pixel-thick rectilinear path (no enclosed region).
    5. For each closed outline, flood-fill its enclosed interior to determine the fill region.
    6. For each enclosed region, pick a majority marker color (distinct from outline colors and bg). Place 2-6 marker pixels of that color inside the region, plus 1-2 minority-color markers (fewer count than majority). Record the fill color = majority color.
    7. The output is: outlines + filled interiors. The input is: outlines + marker pixels inside regions (unfilled interior is bg) + 0-14 stray marker pixels scattered on bg cells outside all outlines.
```
