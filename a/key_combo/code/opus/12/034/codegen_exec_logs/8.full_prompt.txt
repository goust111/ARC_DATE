## 新题 8：正交色条周期延伸在交叉点编织

**组合逻辑**：[周期延伸](创新：双方向同时延伸) + [编织填充](创新：仅在延伸交叉点生效而非预定义矩形区域) + [长度即周期](已有) + [奇偶交替颜色](创新：用行列坐标奇偶决定编织色)

**来源原语**：周期延伸、色条、长度即周期、近者优先（1ae2feb7）；编织填充、交叉条、奇偶交替颜色（f3e14006）

**依赖链**：水平色条向右周期延伸 + 垂直色条向下周期延伸 → 延伸产生的覆盖区域大部分不冲突 → 在水平与垂直延伸重叠的像素上按行列坐标奇偶做编织交替

一句话总结：将水平和垂直色条各自按自身长度为周期延伸至全网格，交叉点处以行列坐标奇偶交替选取水平或垂直色。

**输入结构**：约 16x16 的黑(0)背景网格。2-3 条水平色条位于网格左侧（每条占据一行的连续 2-4 个像素，颜色各不相同，选自红(2)、绿(3)、蓝(1)）。1-2 条垂直色条位于网格顶部（每条占据一列的连续 2-4 个像素，颜色各不相同，选自黄(4)、橙(7)、品红(6)）。水平色条和垂直色条的颜色互不重复。水平色条的最左像素紧贴网格左边缘（第 0 列）；垂直色条的最上像素紧贴网格上边缘（第 0 行）。水平色条与垂直色条不在同一像素上（即原始色条不重叠）。生成约束：至少有一条水平色条的行与一条垂直色条的列在延伸后产生交叉。

**规则**：
1. 对每条水平色条（颜色 C_h，长度 L_h，所在行 r_h），从色条右端下一像素起，沿水平方向以 L_h 为周期重复绘制：每隔 L_h 个黑(0)像素绘制一段长度 L_h 的 C_h 色段，直到超出网格右边界（末段可不完整）。原始色条像素保持不变。
2. 对每条垂直色条（颜色 C_v，长度 L_v，所在列 c_v），从色条下端下一像素起，沿垂直方向以 L_v 为周期重复绘制：每隔 L_v 个黑(0)像素绘制一段长度 L_v 的 C_v 色段，直到超出网格下边界（末段可不完整）。原始色条像素保持不变。
3. 若某像素仅被水平延伸覆盖（该像素位于某水平色条的周期延伸段上，且不在任何垂直延伸段上），涂为对应水平色 C_h。若仅被垂直延伸覆盖，涂为 C_v。
4. 若某像素同时被水平延伸（色 C_h）和垂直延伸（色 C_v）覆盖（交叉点），按该像素的行列坐标 (r, c) 判定：若 (r + c) 为偶数，涂为 C_h（水平色）；若 (r + c) 为奇数，涂为 C_v（垂直色）。行列坐标从 0 开始计数。
5. 原始色条像素（水平和垂直）始终保持原色不变，不被其他方向的延伸或编织规则覆盖。

**关键洞察**：交叉点的颜色不是简单的覆盖或混合——而是由行列坐标的奇偶性决定的棋盘式编织。只有观察到同一交叉区域内颜色交替排列且交替模式与空间坐标奇偶一致，才能归纳出编织规则。单独观察水平或垂直延伸无法预测交叉点行为。
