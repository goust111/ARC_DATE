## 新题 4：面板叠加碰撞点成为射线起点

**组合逻辑**：[透明叠加](创新：碰撞点不是错误而是功能元素) + [射线延伸](创新：射线从叠加产生的碰撞标记出发) + [重涂色](已有)

**来源原语**：透明叠加、分隔行、等高面板、前景不冲突（e98196ab）；射线延伸（cad67732）；重涂色（c8f0f002）

**依赖链**：两个面板透明叠加 → 前景碰撞点标记为栗(9) → 从碰撞点向四方向射线延伸 → 射线遇到非背景像素停止 → 射线路径重涂为栗(9)

一句话总结：删除分隔行并叠加两个面板，将前景碰撞点标记为栗色并向四方向射出射线直到遇障碍。

**输入结构**：约 11x15 的网格，黑(0)背景。一条蓝(1)水平分隔行横贯全宽，将网格分为上下两个等高面板（各约 5x15）。上面板：4-6 个单色前景像素，颜色选自红(2)、绿(3)、黄(4)，散布于不同位置。下面板：4-6 个单色前景像素，颜色同样选自红(2)、绿(3)、黄(4)，散布于不同位置。两面板中大部分前景像素在局部坐标上不重合，但恰好有 1-2 对像素在同一局部坐标上碰撞（即上面板的第 r 行第 c 列与下面板的第 r 行第 c 列都是前景像素）。生成约束：碰撞点的两个前景像素颜色不同；非碰撞前景像素在叠加后互不遮挡。

**规则**：
1. 删除蓝(1)分隔行。
2. 将下面板按局部行列对齐叠加到上面板上。对每个像素位置：
   - 若只有一个面板有前景像素，保留该前景像素及其颜色。
   - 若两个面板在同一局部坐标均有前景像素（碰撞），将该位置重涂为栗(9)。
   - 若两个面板均为背景，保持黑(0)。
3. 从每个栗(9)碰撞标记出发，沿上、下、左、右四个方向延伸射线。射线沿直线逐像素前进，将经过的黑(0)背景像素重涂为栗(9)。射线在遇到非背景像素（任何非黑(0)的像素，包括其他碰撞标记或保留的前景像素）或网格边界时停止，停止点像素不变。
4. 非碰撞的前景像素保持其原色不变。

**关键洞察**：叠加不是简单的合并——碰撞点被重新定义为射线发射源。碰撞的位置和数量由两个面板的前景布局共同决定，而射线的长度则取决于叠加后的全局前景分布。两步操作形成紧密耦合：叠加创造碰撞标记，射线利用叠加后的空间布局来确定传播范围。
