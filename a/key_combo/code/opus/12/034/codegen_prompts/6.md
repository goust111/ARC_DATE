## 新题 6：对称性筛选模板、像素计数配对目标

**组合逻辑**：[裁剪 + 镜像检测](创新：对称性作为角色分类器) + [计数](创新：像素数作为跨类配对键) + [印章覆盖](创新：形状来自模板、颜色和位置来自目标)

**来源原语**：镜像、对称、对称图案选取（d56f2372）；裁剪、包围框（d56f2372, bc1d5164）；印章覆盖、精灵体、颜色配对（3e980e27）；计数、保留颜色与面积（dce56571）

**依赖链**：裁剪所有精灵体并检测垂直镜像对称 → 对称精灵体为"模板"、非对称为"目标" → 按像素计数配对（相同像素数的模板与目标配对） → 将模板形状以目标颜色印章到目标包围框位置 → 擦除模板原位置

一句话总结：检测各精灵体的垂直对称性以分类模板和目标，按像素面积配对后，将模板形状以目标颜色印章到目标位置并擦除模板。

**输入结构**：约 20x20 的黑(0)背景网格。6 个小型单色精灵体（每个 4-连通、3-7 像素），颜色各不相同，选自蓝(1)、红(2)、绿(3)、黄(4)、橙(7)、品红(6)。其中 3 个精灵体的裁剪包围框具有垂直镜像对称性（掩码左右翻转后与原掩码完全相同），另 3 个不具有。像素计数配对：每个对称精灵体恰好有一个非对称精灵体与之像素数相同（如对称体 A 有 5 像素、非对称体 D 也有 5 像素），三对配对的像素数互不相同。精灵体互不相邻（包围框间至少间隔 2 像素）。生成约束：同一配对中的模板和目标包围框尺寸不必相同（像素数相同但形状不同）。

**规则**：
1. 裁剪每个精灵体到其最小包围框。
2. 检测每个裁剪结果是否满足垂直镜像对称（掩码左右翻转后与原掩码完全相同）。对称者标记为"模板"，非对称者标记为"目标"。
3. 计算每个精灵体的前景像素数。将像素数相同的一个模板与一个目标配对。
4. 对每一配对：在目标精灵体的包围框左上角位置，以目标精灵体的颜色印章模板的裁剪掩码（即用模板的形状、目标的颜色绘制）。若模板包围框大于目标包围框，超出部分正常绘制（不裁剪，仅在超出网格边界时丢弃）；若小于，未覆盖的原目标像素被擦除为黑(0)。
5. 擦除每个模板精灵体的原始位置（重涂为黑(0)）。
6. 未被配对的精灵体（如果存在）保持不变。

**关键洞察**：形状、颜色、位置三个属性分别来自不同来源——形状来自对称模板，颜色和位置来自非对称目标。配对键不是颜色也不是空间邻近，而是像素面积相等。求解者需要同时发现对称性分类规则和面积配对规则，两者缺一不可。
