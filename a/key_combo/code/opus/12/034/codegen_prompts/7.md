## 新题 7：像素面积奇偶决定裁剪后平铺的涂色方案

**组合逻辑**：[裁剪](已有) + [平铺](已有) + [重涂色](创新：由奇偶性决定涂色规则) + [奇偶性](创新：应用于面积而非边长)

**来源原语**：裁剪、角落图案、角落对应、最小包围框收缩（bc1d5164）；平铺、周期格点（eee78d87）；重涂色、逐像素替换（c8f0f002）；奇偶性（22806e14）

**依赖链**：裁剪四个角落图案 → 计算各图案前景像素面积 → 奇偶性判定 → 奇数面积涂为绿(3)、偶数面积涂为蓝(1) → 以裁剪包围框为单元平铺填满各象限 → 移除分隔十字

一句话总结：将四角的小图案按像素面积奇偶重涂为两种颜色之一，再以裁剪块为单元平铺各自的象限区域并移除中央分隔十字。

**输入结构**：约 13x13 的网格。一条 1 像素宽的灰(5)十字（一横行 + 一纵列交于网格中心）将网格分为四个 6x6 象限。每个象限中有一个小型红(2)前景图案（2-6 个 4-连通像素，形态各异——含弯折、阶梯等非矩形形态），背景为黑(0)。生成约束：每个图案的包围框不大于 3x3，以确保平铺时在 6x6 象限内至少重复 2 次；四个图案中至少一个像素数为奇数、至少一个为偶数。

**规则**：
1. 裁剪每个象限的红(2)前景图案到其最小包围框。
2. 计数每个裁剪图案中的前景像素数。
3. 若像素数为奇数，将该图案的红(2)前景重涂为绿(3)。若像素数为偶数，重涂为蓝(1)。
4. 以裁剪后的包围框为平铺单元，在对应的 6x6 象限内重复平铺该图案（从象限左上角开始，按行优先、列优先依次铺设；超出象限边界的部分裁切丢弃）。平铺时仅绘制前景像素，黑(0)背景像素不覆盖已有内容。
5. 删除灰(5)分隔十字，将四个 6x6 象限直接拼合生成 12x12 的输出网格。

**关键洞察**：所有输入图案均为红色，但输出中部分变绿、部分变蓝——颜色切换由像素面积的奇偶性决定而非图案形状或空间位置。不同示例中形状相似但像素数不同的图案会获得不同颜色，迫使求解者排除形状假设并归纳出面积奇偶规则。
