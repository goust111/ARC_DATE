## 新题 4：内部密度分拣与互补拼合重涂色

**组合逻辑**：[邻域全包含测试](分类分量为"厚实"或"纤细") + [擦除](移除纤细分量) + [无重叠拼合](创新：将存活的厚实分量做最密平移拼合) + [重涂色](创新：拼合结果中每个分量涂其标记色)

**来源原语**：邻域全包含(full_neighborhood_inside_component) + 连通分量(connected_component) + 单点标记(singleton_marker) + 重涂色(recolor) 来自参考题 09c534e7；擦除(erase) 来自参考题 d59b0160；无重叠拼合(non_overlap_pack) + 互补拼合(complement_fit) + 最密堆叠最小框(densest_minimal_bbox) 来自参考题 681b3aeb

**依赖链**：3x3 邻域测试 → 分类厚实/纤细 → 纤细被擦除（过滤）→ 厚实分量裁剪后做最密拼合 → 标记色决定拼合后的着色。内部密度测试的结果决定了拼合问题的输入集，标记像素同时承担分类辅助和着色指令的双重角色。

用 3x3 邻域测试区分厚实与纤细分量，擦除纤细分量后将两个厚实分量做最密平移拼合，再按各自标记色重涂。

**输入结构**：约 15x10 的网格，黑(0)背景。包含恰好 4 个互不接触的蓝(1) 4-连通分量。每个分量内恰好有一个颜色各异的单点标记像素（标记色取自 {红(2), 绿(3), 黄(4), 橙(7)}，全局不重复）。其中 2 个分量是"厚实"的——至少有一个蓝(1)像素的 8 个邻居全部属于同一分量（即存在实心内部）；另外 2 个是"纤细"的——每个蓝(1)像素都至少有一个邻居不属于该分量（线状或窄条形态，宽度不超过 1 像素）。生成约束：两个厚实分量的形状互补——在最优平移拼合下，合并的边界框中空白像素不超过 2 个。每个分量的像素数在 5~12 之间。

**规则**：
1. 对每个蓝(1) 4-连通分量，检查是否存在至少一个非标记蓝像素，其 3x3 邻域（8 个邻居）全部属于该分量。有则分类为"厚实"，否则为"纤细"。
2. 将两个纤细分量的所有像素（含标记）擦除为黑(0)。
3. 分别裁剪两个厚实分量的最小边界框。
4. 枚举两个裁剪块的所有相对平移偏移量。对每个偏移量，将两块放在一张画布上（不允许任何非黑像素重叠）。在所有合法放置中，选择合并后最小外接边界框面积最小的方案。若有多个方案面积相同，选择第一个块（按其标记像素行号较小者）位于左上方的方案。
5. 在最终拼合的输出中，将每个厚实分量的所有蓝(1)像素重涂为该分量的标记色。标记像素本身也涂为该标记色。输出尺寸等于合并后的最小外接边界框。

**关键洞察**：3x3 邻域测试在本题中的作用与参考题 09c534e7 完全不同——参考题用它定位分量内部像素做局部重涂，本题用它做整体分量级别的二元分类（留/弃），分类结果决定哪些形状进入后续的空间拼合问题。

    wall_thickness: >=2 cells between any cavity edge and grid border or another cavity
    each_contains: empty_color background + exactly 1 seed color (distinct per cavity)
  tile:
    dims: 2-3 rows x 2-5 cols
    density: 56-78% seed pixels within tile bbox (rest empty)
    divisibility: cavity_h % tile_h == 0 AND cavity_w % tile_w == 0
    reps_per_axis: 2-5 in each direction
    symmetry: no consistent pattern [observed]
  seed_placement:
    exactly 1 copy of the tile exists in the input cavity (seed_px == tile_seed_px)
    the tile's top-left is phase-aligned with the cavity origin (offset % tile_dim == 0)
  transform: tile each cavity by repeating its seed tile periodically across the full rectangle

generation_strategy:
  approach: output-first
  steps:
    1. Choose grid dims (19-26 x 13-22). Place 1-3 non-overlapping axis-aligned rectangles
       for cavities (6-12 x 6-15 each) with >=2 wall cells between any pair and all borders.
    2. For each cavity, pick a unique seed color (not 0 or 8). Design a random tile
       (2-3 x 2-5) with 56-78% density such that tile dims divide cavity dims and
       reps >= 2 per axis. Tile the full cavity to get the output.
    3. Fill all non-cavity cells with wall color 8, cavity background with 0.
    4. To get the input, for each cavity keep only 1 phase-aligned copy of the tile
       (pick a random valid tile-origin within the cavity), erase all other seed pixels to 0.

## 实现要求

1. `main(grid)` 必须实现新题描述中的确定性转换规则，不能只识别 `generate_input()` 的固定模板。禁止不同的input网格输出相同的output网格。
2. `generate_input()` 必须随机生成多样样例，不能固定死。随机维度应覆盖：网格大小、对象数量、位置、颜色、方向、形状参数或关键分支。注意若描述中存在若干，需实现而不是只有单个，包括object或者对应关系等等。且若涉及到最短路径，则输入网格中必涉及到多条路径，对选择造成干扰。
3. 生成器必须保证输入满足 `main()` 的隐式假设：对象不重叠、不越界、特殊标记唯一或可区分、匹配关系无歧义、关键分支出现概率相同。
4. 禁止把 ARC 颜色 id 、亮度、拼写等当作人类不可见的数值语义参与排序、大小比较或隐藏映射。颜色变化必须有可见结构线索。注意颜色亮度、拼写等也是不可见信息，若描述中出现违规的颜色id或者亮度，可自行使用少量的固定颜色替代，但注意生成时要在三个以内输入输出网格中对所有变换100%覆盖度。

6. 若规则有多个分支，生成器不能长期固定成一个分支；应让分支在随机样例中合理出现。分支概率不必平均——难以发现的隐蔽分支（如少数情况下才触发的特殊规则）应适当提高出现概率，确保在 3 个训练示例中至少出现一次，否则求解者无法归纳该规则。对于颜色映射类规则，确保 2 个左右的示例即可覆盖所有映射关系（每种颜色→颜色的映射至少在某个示例中出现过）。
