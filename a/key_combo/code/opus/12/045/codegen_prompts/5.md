## 新题 5：滑动距离柱状图

**组合逻辑**：[滑动/碰撞停止/近者优先](已有) → [计数](创新：计量的不是像素数而是位移量) → [排序/计数渲染柱状图](创新：柱高编码运动距离，列序编码空间位置)

**来源原语**：滑动/近者优先/碰撞停止/同色物体朝同色墙(#12 f0100645), 计数/排序/计数渲染柱状图/调色板顺序(#11 f3cdc58f)

**依赖链**：滑动操作产生的位移量是柱状图的数据来源——不是对像素计数，而是对运动距离计数。删除滑动则无距离可测；删除柱状图渲染则滑动结果（对象贴墙排列）不符合输出格式。柱状图的列排序由对象在原始输入中的垂直位置决定，而非固定的调色板序或颜色编号，必须对比多个示例才能区分。

将各色对象滑向同色墙壁，测量每个对象的滑动距离，以距离为柱高、原始纵向位置为列序渲染柱状图。

**输入结构**：约 12x12 的网格，黑(0)背景。第 0 列（最左列）为灰(5)实心墙壁列。3~5 个小型 4-连通单色对象（各使用不同颜色：红(2)、绿(3)、蓝(1)、黄(4)、橙(7)中选取，每个对象 2~4 像素）分布在网格中，均位于墙壁列右侧。各对象在不同行上，不共享列，边界框互不重叠。生成约束：每个对象与墙壁列的水平间距各不相同（使滑动距离互不相等）；所有对象滑向墙壁后不会相互碰撞（各对象所占行不重叠）。

**规则**：
1. 将每个彩色对象向左水平滑动（朝灰色墙壁方向），直到该对象的最左像素紧贴墙壁列右侧（第 1 列）或紧贴已到位的其他对象右侧。按对象最左像素到墙壁的距离从近到远依次处理（近者先滑）。
2. 记录每个对象的滑动距离 D = 滑动前最左像素列号 - 滑动后最左像素列号。
3. 清空整个网格为黑(0)。构建输出网格：宽度等于对象个数，高度等于所有 D 中的最大值。
4. 将对象按其原始输入中边界框顶行行号从小到大排序（行号最小的分配到输出第 0 列，依次递增）。
5. 对每个对象，在其分配的输出列中从底行向上填充 D 格该对象的颜色，形成底对齐的柱状条。

**关键洞察**：柱状图柱高不是像素计数而是滑动位移——距墙越远的对象产生越高的柱。列排序取决于对象在原始输入中的纵向排列而非颜色编号或其他属性，需要对比多组示例才能排除其他排序假设。
