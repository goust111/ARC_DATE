## 新题 4：切比雪夫距离双重定义的十字涂色

**组合逻辑**：[切比雪夫距离/距离映射](创新：同一度量同时控制十字臂长和重叠优先级) + [重涂色/十字图案](已有，但臂长变为动态而非固定半径)

**来源原语**：切比雪夫距离/距离映射/中心对齐(#18 ac0c2ac3), 重涂色/十字图案/标记推断十字涂底(#7 50846271), 忽略干扰项(#7 50846271)

**依赖链**：切比雪夫距离在本题中承担双重角色——既决定每个标记的十字臂长度，又决定重叠时的优先级排序。这两个约束通过同一度量值同时生效，构成了隐式的双重约束满足结构：改变任一标记的距离会同时改变它的形状和它与其他十字的遮挡关系。

每个标记像素以自身到中心的切比雪夫距离为臂长画十字，距离近的十字虽短但在重叠处优先覆盖。

**输入结构**：11x11 的奇数网格，灰(5)填满作为基底色。若干黑(0)格子散布其中作为障碍（3~6 个，不相邻）。网格正中央 (5,5) 处放置橙(7)像素作为距离参考中心。3~4 个不同颜色的标记像素（红(2)、蓝(1)、绿(3)、栗(9)各至多一个）分布在网格中，每个标记到中心的切比雪夫距离互不相同。生成约束：至少有一对标记的十字图案在某些格子上重叠；所有标记不与中心同行同列（确保十字臂在四个方向均有延伸）；障碍不位于标记的正交方向第一格（确保每条臂至少长 1）。

**规则**：
1. 对每个彩色标记像素 (r, c)，计算其到橙色中心 (5,5) 的切比雪夫距离 d = max(|r-5|, |c-5|)。
2. 以该标记为中心，向上、下、左、右四个正交方向各延伸 d 格，形成十字图案。每条臂逐格延伸，遇到黑(0)障碍格或网格边界时提前停止（障碍格本身不被涂色，臂在障碍前一格终止）。
3. 将十字覆盖的所有灰(5)格子重涂为该标记的颜色。标记格自身保持原色不变。
4. 当不同标记的十字在某格重叠时（两个以上标记都试图涂色该格），切比雪夫距离 d 较小的标记优先——即距离中心更近的标记的颜色覆盖距离更远的。
5. 黑(0)障碍、橙(7)中心、各标记像素本身均不被改变。

**关键洞察**：距离中心近的标记画出的十字更短，但在重叠区域反而拥有更高的绘制优先级——"小而强"的反直觉规则。求解者容易误以为面积更大（距离更远）的十字优先，需要对比多个示例中的重叠区域才能发现距离与优先级的反向关系。
