## 新题 3：邻接清洗后的面板叠加与间隔重涂

**组合逻辑**：[erase + recolor](创新：邻接判定同时执行清洗和归并) → [transparent_overlay](已有) → [sort + recolor](创新：叠加后的合并排序决定间隔重涂目标)

**来源原语**：erase / merge_or_delete / adjacency（参考 7e0986d6），transparent_overlay / union_foreground / separator_row / panel（参考 ce4f8723 + d19f7514），sort / every_nth_selection / sort_by_position / recolor（参考 22a4bbc2）

**依赖链**：邻接清洗改变每个面板中色条的形态 → 叠加时清洗后的形态决定并集的形状 → 合并后的色条按位置排序，间隔选取决定最终重涂目标。清洗结果实质性改变叠加输入，叠加结果实质性改变排序输入。

两个面板各自经过噪声清洗后对齐叠加为一个合并视图，合并后的色条按位置排序、每隔两个重涂为指定颜色。

**输入结构**：约 12x25 的网格，背景为黑(0)。一条品红(6) 全宽分隔行将网格分为等高的上下两个面板（各约 12x12）。每个面板包含 3~5 个水平色条（各为单色的轴对齐实心矩形，高 1~2 行、宽 4~8 列），颜色取自蓝(1)、灰(5)、橙(7)、青(8)（同一面板内颜色不重复）。每个面板还散布着黄(4) 噪声像素（每个噪声为 1~2 像素的小连通分量，共 4~8 个噪声分量）。生成约束：部分噪声像素与色条 4-邻接接触 >= 2 个色条像素，部分噪声与色条接触 < 2 个；两面板的色条在垂直对齐后存在部分重叠和部分互补区域。

**规则**：
1. 在每个面板中独立执行噪声清洗：找出所有 4-连通分量，面积 < 4 的为噪声分量，面积 >= 4 的为色条分量。对每个噪声分量，统计其像素与色条分量的 4-邻接接触数。接触数 >= 2 的，将噪声像素重涂为接触最多的那个色条的颜色（并入色条）；接触数 < 2 的，将噪声像素擦除为黑(0)。若与两个色条接触数相同，选上方（行号较小）的色条。
2. 移除分隔行，将清洗后的上下面板逐格对齐。在每个单元格：若两面板均为前景，保留上面板的颜色；若仅一个面板为前景，保留该颜色；若均为背景，保持黑(0)。
3. 在合并结果中识别所有 4-连通前景分量（即合并后的色条），按其边界框左上角的位置排序（先按行从上到下，行相同则按列从左到右）。
4. 排序后，将排名第 1、第 4、第 7、... 的色条（即每隔 3 个，从第 1 个开始）重涂为红(2)。其余色条保持合并叠加后的颜色不变。

**关键洞察**：噪声清洗的归并操作会扩大色条的边界，直接影响叠加后的前景并集形状；而叠加创造了一个新的色条集合（来自两个面板的色条可能合并为一个更大的连通分量），排序和间隔选取作用于这个新集合而非任何单一面板。需要对比多个示例才能发现"每隔 3 个重涂"的间隔规则。
