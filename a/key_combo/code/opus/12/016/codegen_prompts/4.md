## 新题 4：膨胀邻接图的度数编码

**组合逻辑**：[dilate_intersect](已有) → [counting](创新：计算每个分量的膨胀重叠邻居数) → [encoding + sort](创新：度数排序后编码为水平色条长度)

**来源原语**：dilate_intersect / path_gap_overlap（参考 f1bcbc2c），counting / count_mapping（参考 ff28f65a），encoding / count_sets_positions（参考 ff28f65a），sort / sort_by_position（参考 22a4bbc2）

**依赖链**：膨胀创造原本不存在的重叠区域 → 重叠定义了分量间的邻接关系图 → 度数统计压缩几何信息为标量 → 排序和编码将标量映射为输出图案。每一步的输出在本质上改变下一步的输入形态（从几何 → 拓扑图 → 数值 → 像素编码）。

多个孤立前景分量经膨胀后产生重叠关系，构成隐式邻接图；每个分量的邻接度数被编码为对应颜色的水平色条长度，按度数降序排列。

**输入结构**：约 15x15 的网格，背景为黑(0)。包含 4~6 个孤立的 4-连通单色前景分量，每个分量 3~8 像素，形状不规则，颜色各不相同（取自蓝(1)、红(2)、绿(3)、黄(4)、灰(5)、橙(7)）。任意两个分量之间的最近距离为 1~3 像素（即它们不接触但相距很近）。生成约束：至少有两对分量的间距恰为 1 像素（膨胀后必定重叠），至少有一对分量的间距 > 2 像素（膨胀后不重叠）；各分量的邻接度数不全相同。

**规则**：
1. 对每个前景分量做 1 像素的 8-邻域膨胀（将分量的每个像素的 8 个邻居标记为该分量的膨胀区域，不覆盖其他分量的原始像素）。
2. 检查每对分量的膨胀区域是否存在重叠像素（即两个分量的膨胀区各自标记了同一个空白像素）。若存在重叠，则这两个分量之间有一条"邻接边"。
3. 对每个分量，统计其邻接边的数量，即为该分量的"度数"。
4. 按度数降序排列所有分量；度数相同时，按分量边界框左上角的位置排序（先行后列，行号小的优先）。
5. 输出为一个 Nx(最大度数) 的网格（N 为分量数量），第 k 行对应排序后第 k 个分量：从左起填充该分量颜色，填充长度等于该分量的度数；若度数为 0，该行全部为黑(0)。

**关键洞察**：输入中分量之间并不直接接触，邻接关系完全由膨胀操作创造——间距恰为 1 的分量膨胀后重叠，间距 > 2 的则不重叠。输出完全丢弃了形状和位置信息，只保留了由空间距离编码的拓扑连接度。需要对比多个示例才能归纳膨胀半径恰为 1 以及度数 → 色条长度的映射规则。
