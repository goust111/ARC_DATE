## 新题 7：递增堆叠中的标记阻断与连通选择

**组合逻辑**：[stack](已有) + [counting](创新：标记位置在堆叠过程中造成断裂) → [erase + keep_largest_component](已有) → [draw_line](已有，连接最大连通分量的极端点)

**来源原语**：stack / color_run / row_by_row_increment / row_incremental_expand（参考 bbc9ae5d），counting（参考 ff28f65a），erase / connected_component / area_comparison / keep_largest_component（参考 1f85a75f），draw_line / marker_pixel（参考 7ec998c9）

**依赖链**：标记像素位置在堆叠的逐行扩展中制造空隙 → 空隙将前景分裂为多个连通分量 → 保留最大连通分量并擦除其余 → 在最大分量的极端点之间画线。标记位置决定了哪些行有缺口、缺口位置决定了连通性、连通性决定了保留哪些像素。

从单行色段逐行递增堆叠，但输入行中的标记像素位置在每行的对应列强制留空，造成前景断裂；保留面积最大的连通分量，在其最高和最低像素之间画一条垂直线。

**输入结构**：一行宽为 W（W 为偶数，10~16）的网格。前 L 个像素（L 在 3~6 之间）为蓝(1)（色段），其余为黑(0)。在该行的非色段区域中，有 2~3 个红(2) 标记像素散布在不同列位置。生成约束：至少一个标记像素的列号 < W/2（会在堆叠中期被色段扩展触及），至少一个标记像素的列号 >= W/2（色段扩展在到达该位置前已因行数限制停止，不受影响）；标记像素不相邻。

**规则**：
1. 以输入行为模板，生成 W/2 行的堆叠网格（行号从 0 开始）。第 k 行的蓝(1) 色段长度为 min(L + k, W)，从左端开始向右填充。
2. 在每一行中，如果某列的位置在输入行中是红(2) 标记像素，则该列在此行强制为黑(0)（即使色段扩展已覆盖到此列）。标记像素本身不出现在输出网格中。
3. 堆叠完成后，将整个前景（所有蓝(1) 像素）按 4-连通分量分组，找到面积最大的连通分量。若最大面积不唯一，选择边界框左上角行号最小的那个。
4. 将非最大连通分量的所有蓝(1) 像素擦除为黑(0)。
5. 在保留的最大连通分量中，找到最上方像素（行号最小；若有多个取列号最小者）和最下方像素（行号最大；若有多个取列号最大者）。从最上方像素到最下方像素画一条红(2) 垂直直线（若两者不在同一列，则画一条 Manhattan 折线：先垂直走到目标行，再水平走到目标列）。
6. 折线经过的蓝(1) 像素保持蓝(1)（线画在蓝色之上时保持蓝色不变），折线经过的黑(0) 像素变为红(2)。

**关键洞察**：标记像素表面上只是输入行中的静态点，但它们在堆叠过程中扮演"柱状屏障"角色——当色段扩展到标记列时，该列始终留空，像一根垂直的墙壁切断前景。这种切断效果是否发生取决于色段是否增长到了标记所在列，即取决于标记列号与色段初始长度及总行数的关系。需要多个示例才能归纳标记的阻断机制。
