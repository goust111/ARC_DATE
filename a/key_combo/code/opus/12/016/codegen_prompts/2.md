## 新题 2：稀疏边界补全引导的分层射线投影

**组合逻辑**：[complete](已有) → [ray_extend](已有) + [recolor](创新：投影穿越已补全的嵌套边界时动态变色)

**来源原语**：complete / sparse_rect_layer / outer_to_inner（参考 5751f35e），ray_extend / displacement_vec / copy_dir_and_color（参考 045e512c），recolor（参考 22a4bbc2）

**依赖链**：补全稀疏边界 → 确定嵌套层区域 → 射线投影穿越各层时根据所在层的边界颜色进行重涂色。补全结果决定色区边界，色区边界决定投影的颜色分段，形成信息变换链。

将中心精灵体沿位移向量反复投影，但投影副本在穿越已补全的嵌套矩形边界时变为该边界的颜色，产生分层着色的投影序列。

**输入结构**：约 20x20 的网格，背景为黑(0)。2~3 种颜色（如蓝(1)、灰(5)、栗(9)）的稀疏像素各自暗示一个轴对齐矩形边界，这些矩形严格嵌套（蓝最外、灰次之、栗最内），面积互不相同。最内层矩形中心有一个 3x3 的单色小精灵体（红(2)，不规则形状，4~6 像素）。最外层矩形之外有 1~3 个该精灵体的部分副本（与精灵体形状相同的子集，各 2~3 像素），每个副本颜色为绿(3)。生成约束：稀疏边界每条边至少有 2 个采样像素；各部分副本与中心精灵体的位移向量方向互不相同（如一个偏右上、一个偏左下）。

**规则**：
1. 将每种边界颜色的稀疏像素补全为完整的轴对齐矩形框（单像素宽边框），按子框与父框一像素内缩匹配至少三边时扩展至完整内缩的规则处理（同参考 5751f35e 的补全逻辑）。
2. 找到中心精灵体与每个部分副本之间的位移向量（使精灵体覆盖该副本的最大位移）。
3. 沿每个位移向量方向，从中心精灵体位置开始反复平移，每步平移量等于位移向量本身。对每个平移产生的副本：
   - 判断该副本的几何中心落在哪一层嵌套区域内（最内层、中间层、最外层、或已出界）。
   - 将副本的所有像素重涂为该层矩形边界的颜色。若中心落在最内层，重涂为栗(9)；中间层为灰(5)；最外层为蓝(1)。
   - 若副本的几何中心落在矩形边界之外（出界），则不绘制该副本，投影在此方向停止。
4. 原始精灵体保持红(2)。部分副本在输出中被擦除（涂为黑(0)）。已补全的矩形边界保持其颜色不变。
5. 多个投影方向的副本若占据同一像素，后绘制的（按位移向量的角度从 0 度顺时针排序）覆盖先绘制的。

**关键洞察**：稀疏边界的补全不仅用于"看到完整矩形"，更关键的是划定了颜色区域——同一投影序列中的相邻副本可能因跨越边界而颜色不同。需要对比多个示例才能归纳"副本颜色取决于所在层而非投影方向"这一隐蔽规则。
