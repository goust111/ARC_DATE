## 新题 8：折线路径的中轴提取与嵌套深度重涂

**组合逻辑**：[draw_line](已有) + [clip/center_axis_only](创新：从折线路径中提取通过中轴列的片段) + [complete + recolor](创新：中轴片段的颜色由其穿越的嵌套层深度决定)

**来源原语**：draw_line / folded_path / column_alignment / center_offset_selects_corner（参考 7ec998c9），clip / center_column / center_axis_only / foreground_pixel（参考 d23f8c26），complete / nested_rectangle / outer_to_inner（参考 5751f35e），recolor（参考 b74ca5d1）

**依赖链**：标记像素决定折线路径的走向 → 中轴列裁剪只保留路径与中轴的交集 → 嵌套矩形补全划定深度层 → 中轴上的每个像素根据其所在层深度重涂颜色。折线走向决定中轴上哪些像素被点亮，嵌套深度决定这些像素的颜色，两套结构在中轴列上交汇。

多条折线路径穿越网格，仅保留它们通过中轴列的部分；这些中轴像素再根据所在的嵌套矩形深度层重涂为对应层的颜色。

**输入结构**：约 15x15 的网格（列数为奇数），背景为黑(0)。2~3 种颜色（如灰(5)、橙(7)）的稀疏像素暗示 2~3 个轴对齐嵌套矩形边界（不经过中轴列）。在嵌套矩形之外或之间，有 2~4 个绿(3) 标记像素分布在不同行，且不在中轴列上。整个网格中不存在蓝(1) 像素（蓝将用于输出）。生成约束：各标记像素所在列与中轴列的左右关系不全相同（有的在左，有的在右）；稀疏矩形的每条边至少有 2 个采样像素；中轴列与每个嵌套矩形层在至少 3 行的区间重叠。

**规则**：
1. 补全稀疏像素为完整的嵌套矩形边框（同参考 5751f35e 的补全逻辑）。确定嵌套层级：最外层为深度 1，次层为深度 2，最内层为深度 3（以此类推）。
2. 为每个标记像素生成一条折线路径：从标记像素所在列出发，垂直涂满该列（从网格顶到底）；然后根据标记像素相对中轴列的位置连接角落——若标记在中轴列的左侧，从该列顶端水平连线到右上角、从底端连线到左下角；若在右侧则反之（顶端连左上角、底端连右下角）。路径颜色暂定为蓝(1)。
3. 在所有折线路径绘制完毕后，执行中轴裁剪：仅保留中轴列（第 (W-1)/2 列，W 为网格宽度）上的蓝(1) 像素。所有非中轴列的蓝(1) 像素擦除为黑(0)。
4. 对中轴列上保留的每个蓝(1) 像素，判断其所在的嵌套层深度：
   - 若该像素在所有矩形之外，深度为 0，颜色保持蓝(1)。
   - 若在深度 d 层内（d >= 1），将该像素重涂为该层矩形边框的颜色。
5. 标记像素保持绿(3) 不变。已补全的矩形边框保持其颜色不变。中轴列上未被任何折线路径覆盖的像素保持黑(0)。
6. 多条折线路径在中轴列同一像素重叠时，该像素仍为单个前景像素，按嵌套深度规则着色（颜色取决于位置而非路径来源）。

**关键洞察**：折线路径的走向由标记位置决定，但最终只有路径与中轴列的交集部分被保留——不同标记产生不同的交集段落。这些交集段落的颜色又由嵌套结构决定，而嵌套结构需要从稀疏像素补全后才能确定。两套独立的几何结构（折线路径和嵌套矩形）在中轴列这一"探针"上交汇产生最终输出。需要对比多个示例才能分离"路径决定位置"与"嵌套决定颜色"两条独立规则。
