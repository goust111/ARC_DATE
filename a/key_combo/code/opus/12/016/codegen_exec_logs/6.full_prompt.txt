## 新题 6：放大使能的标记旋转对接

**组合逻辑**：[pixel_upscale](创新：放大不是目的而是为对接创造空间条件) → [ray_cast + dock](已有) + [rotate](创新：旋转角度由组件内部标记像素的局部位置编码)

**来源原语**：pixel_upscale / uniform_scale_factor（参考 c59eb873），dock / ray_cast / interior_socket / movable_component / structure / ray_inferred_direction / trail_painted_black（参考 8b9c3697），rotate / half_turn_rotation（参考 3c9b0459），marker_pixel（参考 7ec998c9）

**依赖链**：放大创造了容纳组件的物理空间（1x1 腔变为 2x2） → 射线投射在放大后的网格上找到组件 → 标记像素位置决定旋转 → 旋转后的组件对接入腔体。放大是后续所有操作的前提条件（非放大态下腔体装不下组件），不可跳过。

将整个网格 2 倍放大后，结构体的单像素腔体变为 2x2 空间，此时可移动组件通过射线定位并根据其内部标记像素的方位旋转后对接入腔体。

**输入结构**：约 9x9 的网格（输出为 18x18），背景为黑(0)。包含 2~3 个"结构体"，每个是一个由灰(5) 像素围成的 3x3 方框，中心为 1 个黑(0) 像素（即单像素腔体）。在结构体之外散布 2~3 个"可移动组件"，每个组件是一个 L 形或 T 形的 4-连通小图形（恰好 4 像素），由蓝(1) 像素构成，其中恰好 1 个像素为红(2)（标记像素）。组件数量 <= 结构体数量。生成约束：每个组件从其位置沿某个基本方向（上、下、左、右之一）做射线可以到达某个结构体的腔体（穿过的路径上只有黑(0) 像素）；不同组件指向不同的结构体。

**规则**：
1. 将整个输入网格做 2 倍像素放大：每个像素变为 2x2 同色块。此时每个结构体的中心腔体从 1x1 变为 2x2，组件从 4 像素变为 4 个 2x2 块（共 16 像素，占据一个 4x4 子区域的部分）。
2. 在放大后的网格上，从每个结构体的 2x2 腔体中心向四个基本方向（上、下、左、右）发射射线。首先命中的可移动组件（蓝(1)/红(2) 像素）为该结构体的配对组件，射线方向为对接方向。
3. 确定组件的旋转角度：在放大前的原始组件中，标记像素（红(2)）相对于组件边界框中心的方位决定旋转——标记在边界框上方 → 0 度；右方 → 顺时针 90 度；下方 → 180 度；左方 → 顺时针 270 度。（上方定义为行号较小的一侧；若标记恰在中心行或中心列，取其偏离的另一个轴的方位。）
4. 对放大后的组件施加该旋转（围绕组件边界框中心旋转），然后沿对接方向平移，直到组件的中心 2x2 块与腔体的 2x2 空间完全重合。将组件绘制到腔体位置。
5. 组件从原始位置移走后，将其原位置的所有像素涂为黑(0)。组件滑动经过的路径（从原位到对接位之间的像素）涂为栗(9)。
6. 未被任何射线命中的多余组件（如果有）保持不动。

**关键洞察**：放大操作看似只是视觉缩放，但实际上是对接操作的物理前提——原始网格中 1x1 的腔体无法容纳多像素组件，放大后 2x2 的腔体才能装入旋转后的组件。标记像素在组件中的位置同时编码了旋转信息，与射线方向无关（这是一个需要对比多个示例才能分离的隐蔽规则）。
