## 新题 5：路径追踪定向的空区瓦片填充

**组合逻辑**：[search](已有) + [path_trace](已有) → [tiling + rotate](创新：粒子最终行进方向决定瓦片旋转角度，空区定位决定填充区域)

**来源原语**：search / empty_rect_region / largest_rect_filled / min_side_constraint（参考 3eda0437），path_trace / particle / corridor / collision_turn / collision_stop（参考 9bbf930d），tiling / tile / alternating_flip / concatenation（参考 bc4146bd），rotate / half_turn_rotation（参考 3c9b0459）

**依赖链**：路径追踪的终态方向 → 决定瓦片的基础旋转角。空区搜索 → 决定填充位置和尺寸。两条独立信息在瓦片填充步骤汇合：一条提供"怎么放"（方向），一条提供"放在哪"（区域）。路径还被着色，与填充结果共存于输出中。

一个粒子在色条走廊中追踪路径直到停止，其最终行进方向决定瓦片的旋转朝向；同时搜索网格中最大空矩形区域，将旋转后的瓦片平铺填入该区域。

**输入结构**：约 18x18 的网格，背景为黑(0)。橙(7) 色条以偶数行的水平段和偶数列的垂直段形式分布，形成走廊结构（走廊为色条之间的单像素宽通道）。一个品红(6) 粒子（单像素）位于网格左边缘的某个走廊入口。一个 3x3 的瓦片图案由绿(3) 像素构成（不规则、非对称形状，4~6 像素，其余为黑），位于网格右下角的 3x3 区域内。网格中存在若干全黑的矩形空区（由走廊结构围出），其中恰好一个空区的面积最大且两个维度均 >= 3。生成约束：粒子的路径追踪有且仅有一条确定性路线（每次碰撞只有一个合法转向方向）；最大空区的长宽均为 3 的倍数（确保瓦片能整除填充）。

**规则**：
1. 从品红(6) 粒子出发执行路径追踪：粒子沿当前方向直线前进，遇到橙(7) 色条时转向 90 度进入有黑(0) 空间的垂直走廊（若两侧都有走廊，选择两侧有同色色条夹道的那个方向）。粒子到达网格边缘或完全被堵时停止。记录粒子停止时的最终行进方向。
2. 将粒子经过的所有黑(0) 像素涂为品红(6)，形成路径轨迹。
3. 搜索网格中所有全黑矩形区域（宽高均 >= 3），选出面积最大的那个。
4. 根据粒子最终行进方向确定瓦片的基础旋转角度：向右 → 0 度；向下 → 顺时针 90 度；向左 → 180 度；向上 → 顺时针 270 度。
5. 将旋转后的瓦片平铺填入最大空区：从空区左上角开始，按行优先逐个放置瓦片。奇数位置（从 0 计数，位置 1、3、5...）的瓦片额外旋转 180 度（即与基础旋转叠加 180 度）。
6. 右下角原始瓦片位置的像素在输出中擦除为黑(0)。

**关键洞察**：粒子的路径追踪和空区搜索是两个独立的感知过程，但它们的结果在瓦片填充步骤交汇——追踪提供方向信息，搜索提供空间信息，缺少任何一个都无法确定最终输出。需要对比多个示例才能发现旋转角度与行进方向的映射关系（方向→角度的具体对应在单个示例中有多种可能解释）。
