## 新题 5：重叠空心矩形的深度分层填充

**组合逻辑**：[hollow_rectangle + center_marker 识别](从标记像素和可见边框碎片还原每个矩形的完整范围) ⊗ [重叠深度计算](逐像素统计被多少个矩形内部覆盖——同时约束满足) → [size_to_color_mapping 变体](深度→颜色映射)

**来源原语**：hollow_rectangle, center_marker, fill, size_to_color_mapping, marker_centered_inside_frame (00dbd492); greedy_selection, non_overlapping_constraint (31adaf00); stamp_overlay (92e50de0)

**依赖链**：标记像素定位矩形中心 → 从中心向外搜索边框确定矩形范围 → 但边框在重叠处被遮挡，需要结合所有矩形的信息交叉推断 → 确定所有矩形后计算每个像素的覆盖深度 → 深度映射到颜色。矩形范围推断和深度计算是同时约束满足问题，而非逐对象独立处理。

多个空心矩形相互重叠，根据标记像素和可见边框碎片还原所有矩形的完整范围，再按每个像素被覆盖的矩形内部数量（深度）分级着色。

**输入结构**：
- 网格约 18x18，背景黑(0)。
- 3-4 个红(2)空心矩形边框，边长为奇数（范围 5-13），矩形中心各不相同。矩形之间有部分重叠——一个矩形的内部区域与另一个矩形的边框或内部交叉。
- 每个矩形的几何中心有一个红(2)标记像素，标记像素始终可见（不被其他矩形的边框覆盖）。
- 当两个矩形的边框在同一像素重叠时，该像素仍显示为红(2)；当一个矩形的边框像素落在另一个矩形的内部区域时，边框像素可见（红色覆盖黑色内部）。
- 生成约束：每个矩形至少有两条完整边可见（未被其他矩形的边框像素部分遮挡到无法推断长度）；至少两个矩形的内部区域有非空交集。

**规则**：
1. 识别所有红(2)标记像素（不在任何矩形边框上、在某矩形几何中心的孤立红像素）。每个标记对应一个矩形。
2. 对每个标记像素，从该位置向四个方向（上下左右）搜索最近的红(2)边框像素，从而确定该矩形的半边长和完整边界。若某方向的边框被另一个矩形的边框遮挡（红像素属于两个矩形），则利用对称性（中心到已知边的距离）推断该方向的边界。
3. 对每个非边框非标记的像素位置 (r, c)，计算它被多少个矩形的内部区域严格包含（位于该矩形边框之内、非边框本身），记为深度 d。
4. 按深度着色：d = 0 → 黑(0)不变；d = 1 → 青(8)；d = 2 → 黄(4)；d = 3 → 绿(3)；d >= 4 → 品红(6)。
5. 所有红(2)边框像素和红(2)标记像素在输出中保持红(2)不变。

**关键洞察**：被遮挡的边框必须从标记位置和矩形的对称性推断——如果标记到上边框的距离为 3 行，那么到下边框也必须是 3 行，即使下边框被另一个矩形的边框穿过。这种交叉推断使得各矩形的范围确定不能独立进行。
