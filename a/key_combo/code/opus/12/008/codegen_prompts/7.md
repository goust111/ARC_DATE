## 新题 7：对角射线间隙中的贪心正方形邻接着色

**组合逻辑**：[ray_extend + both_diags_through_pixel](多源对角射线划定间隙区域) → [greedy_selection + largest_first_priority](间隙中贪心提取最大不重叠正方形) → [recolor 由邻接射线色决定](正方形颜色取决于与其边界 4-邻接的射线中最多出现的源色)

**来源原语**：ray_extend, isolated_pixel, diagonal_dir, both_diags_through_pixel, canvas_boundary (623ea044); greedy_selection, blank_square_region, largest_first_priority, non_overlapping_constraint, minimum_side_length_constraint (31adaf00); recolor (cfb2ce5a/94be5b80)

**依赖链**：射线的空间布局同时决定两件事——(a) 间隙区域的形状（限制可提取的正方形大小），(b) 邻接颜色信息（决定正方形的填充色）。这不是纯流水线：射线位置对正方形大小和颜色施加同时约束，求解者必须从全局射线网格推断局部正方形属性。

多个孤立像素各发射四条对角射线，射线交织成网格状结构；在射线之间的黑色间隙中贪心提取最大不重叠正方形，每个正方形的颜色由其周围射线的源像素颜色多数决定。

**输入结构**：
- 网格约 16x16，背景黑(0)。
- 2-3 个孤立非黑像素，颜色各不相同（如红(2)、蓝(1)、绿(3)），位置使得其对角射线将网格分割为多个黑色间隙区域。
- 生成约束：孤立像素不在网格边角；射线之间的黑色区域中至少存在 2 个边长 >= 2 的不重叠正方形区域。

**规则**：
1. 按孤立像素在网格中的位置排序（行优先，同行按列），按此顺序依次为每个像素绘制四条对角射线。射线颜色为该像素的颜色，从该像素位置出发沿四个对角方向逐格延伸至网格边界。若射线路径上的某格已被先前绘制的射线占据，则该格保持先前颜色（先绘制优先），当前射线在该处断开但继续向同方向延伸（跳过已占据格继续检查后续格，若后续格为黑则涂色）。
2. 射线绘制完成后，在所有黑(0)像素中搜索边长 >= 2 的全黑轴对齐正方形候选区域。
3. 从最大边长到最小边长贪心选择不重叠的正方形。同边长的候选按左上角行优先、列次优先排序。
4. 对每个选中的正方形，统计其边界（四条边上的像素）向外 4-邻接的所有射线像素的颜色。取出现次数最多的颜色作为该正方形的填充色。若多色出现次数相同，取其中在输入网格中源像素（孤立像素）位置靠左上（行优先、列次优先）的那个颜色。
5. 将选中正方形填充为确定的颜色。未被选中的黑像素保持黑(0)。射线像素保持原色。孤立像素保持原色。

**关键洞察**：射线几何同时扮演"区域划定者"和"颜色提供者"两个角色——改变任一孤立像素的位置不仅改变间隙的大小形状，还改变每个正方形周围的颜色比例，因此射线布局对输出的影响是全局性的。
