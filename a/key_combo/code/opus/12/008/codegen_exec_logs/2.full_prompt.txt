## 新题 2：双掩码异或区域中的贪心正方形分级着色

**组合逻辑**：[xor_overlay](双掩码逐像素异或产生活跃区域) → [greedy_selection + largest_first_priority + non_overlapping_constraint](在活跃区域中贪心提取最大不重叠正方形) → [size_to_color_mapping](按正方形边长映射颜色)

**来源原语**：xor_overlay, separator_row, foreground_mask, disagreement_cells_painted (99b1bc43); boolean_op, mask_region, alignment (6430c8c4); greedy_selection, blank_square_region, largest_first_priority, non_overlapping_constraint, minimum_side_length_constraint (31adaf00); size_to_color_mapping (00dbd492)

**依赖链**：分隔行分割上下两层掩码 → 异或运算产生不规则的活跃像素区域 → 区域的几何形状限制可提取的正方形大小 → 贪心选择从大到小提取不重叠正方形 → 正方形边长决定填充颜色。每一步的输出是下一步的必要输入，且异或区域的形状由两层掩码共同决定，无法从任一层单独推断。

两层掩码的对称差产生不规则前景区域，在其中贪心提取最大不重叠正方形，再按边长分级着色。

**输入结构**：
- 网格约 15x20（15 列、20 行），中间有一条全宽红(2)分隔行将网格分为等高的上下两层。
- 上层掩码：黑(0)背景上有蓝(1)前景像素构成 2-4 个不规则 4-连通区域（每个区域 5-15 像素）。
- 下层掩码：黑(0)背景上有黄(4)前景像素构成 2-4 个不规则 4-连通区域，与上层的前景区域有部分空间重叠、部分独立。
- 生成约束：上下两层尺寸相同（去除分隔行后行列数一致）；异或后的活跃区域中至少存在一个边长 >= 3 的全活跃正方形子区域。

**规则**：
1. 移除红(2)分隔行，将上下两层掩码逐像素对齐（第 i 行第 j 列对应）。
2. 对每个像素位置，若恰好一层为前景（蓝或黄）、另一层为背景（黑），标记为活跃；两层都是前景或都是背景则标记为非活跃。初始时活跃像素涂绿(3)。
3. 在活跃像素区域中搜索所有边长 >= 2 的全活跃轴对齐正方形候选区域。
4. 从最大边长到最小边长依次处理候选：若候选正方形不与任何已选中的正方形重叠，则选中。同边长候选按左上角行优先、列次优先排序（即从上到下、从左到右）。
5. 对选中的正方形重涂颜色：边长 2 → 青(8)，边长 3 → 黄(4)，边长 4 → 橙(7)，边长 >= 5 → 品红(6)。未被选中的活跃像素保持绿(3)。非活跃像素为黑(0)。
6. 输出网格的尺寸等于单层掩码的尺寸（分隔行已移除）。

**关键洞察**：两层掩码的前景区域越多重叠，异或后的活跃区域就越小、越碎片化，可提取的正方形也越小——求解者需要同时理解异或语义和贪心提取策略，二者缺一不可。
