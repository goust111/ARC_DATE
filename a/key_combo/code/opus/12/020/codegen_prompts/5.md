## 新题 5：对角错切射线与障碍阴影

**组合逻辑**：[ray_extend](创新：射线沿错切方向而非正交方向传播) + [shear + row_offset_incr](创新：错切规则应用于射线路径而非物体移动) → [obstacle_casts_shadow](创新：阴影沿错切方向投射)

**来源原语**：ray_extend、gap_bisect（参考题 d968ffd4）；shear、row_offset_incr（参考题 9f41bd9c）；obstacle_casts_shadow（参考题 b9e38dc0）；marker_pixel（参考题 dc1df850）

**依赖链**：标记像素的行位置决定射线起点 → 错切规则将射线路径从水平弯折为对角 → 障碍物沿错切方向投射阴影，阻断后续射线。射线路径的几何形状和阴影区域都由错切方向决定。

左侧标记像素沿对角错切路径向右发射彩色射线，灰色障碍物沿同一错切方向投射阴影阻挡射线。

**输入结构**：约 14x18 的网格（行数 14，列数 18），背景为黑(0)。左侧第 0 列有 3-5 个标记像素，分布在不同行，颜色各异（使用红(2)、蓝(1)、绿(3)、黄(4)等）。网格中散布 2-4 个灰(5)矩形障碍物（每个 1x2 或 2x1）。生成约束：标记像素之间至少间隔 2 行；障碍物不在第 0 列；不同标记像素的错切射线路径在未被阻挡时不会重叠（即在错切方向上各占不同的对角线带）。

**规则**：
1. 每个标记像素从其所在格 (r, 0) 向右发射射线。射线路径遵循错切规则：从起点出发，每向右移动一列，同时向下移动一行。即射线经过的格子序列为 (r, 0), (r+1, 1), (r+2, 2), ... , (r+c, c)。
2. 射线用标记像素的颜色逐格绘制，遇到以下情况停止：到达网格边界（底边或右边）；或遇到灰(5)障碍物像素。
3. 障碍物投射阴影：当射线被障碍物阻断时，从障碍物位置沿同一错切方向（继续每列下移一行）延伸一个阴影带直到网格边界。阴影带内的格子不绘制任何射线颜色（即使有其他射线路径经过该格）。
4. 射线的绘制按标记像素从上到下的顺序依次处理。先绘制的射线像素不会被后绘制的覆盖。阴影带内的格子对所有后续射线同样生效（不可绘制）。
5. 障碍物自身保持灰(5)不变。

**关键洞察**：射线不走水平直线而走对角错切路径，这意味着来自不同行的射线在空间上呈平行对角带分布。障碍物的阴影也沿对角方向投射，一个障碍物可能同时遮蔽多条潜在射线路径。错切方向（每列下移一行 vs 上移一行）需对比多个示例确认。
