## 新题 6：分形蓝图定位后的同色连线

**组合逻辑**：[scale + self_similarity + minority_pattern_as_blueprint](已有：少数单元内部图案作为宏观放置蓝图) → [connect + same_color_chain](创新：蓝图确定的单元位置间进行同色最短路径连线) ← [shortest_detour](创新：连线路径需绕过分隔线和异色单元)

**来源原语**：scale、self_similarity、minority_pattern_as_blueprint、minority_cell、majority_cell、separator_grid（参考题 b99e7126）；connect、same_color_chain、shortest_detour（参考题 f8f52ecc）

**依赖链**：少数单元的内部图案编码了宏观放置蓝图 → 蓝图决定哪些单元格被填充为少数单元 → 填充后的少数单元按颜色分组 → 同色单元之间通过分隔通道以最短 L 形路径连线。蓝图放置决定了连线的拓扑结构。

用少数单元的自相似蓝图确定哪些单元格应被填充，然后在分隔线通道中连接所有同色的少数单元。

**输入结构**：约 19x19 的网格，由灰(5)分隔线划分为 4x4 的单元阵列（每个单元 4x4 像素，分隔线 1 像素宽）。大多数单元内部为全黑(0)（多数单元）。已有 2-3 个单元为少数单元，内部包含一个小彩色图案：每个少数单元内有一个 2-3 像素的彩色标记，使用红(2)或蓝(1)。少数单元内部的非标记像素中，有特定位置的像素为栗(9)（作为蓝图标记）。生成约束：所有少数单元的内部布局相同（含标记颜色和栗色蓝图标记的位置相同），仅标记颜色可能不同；少数单元在 4x4 阵列中的位置与其内部栗(9)像素在 4x4 内部空间中的位置自相似对应。

**规则**：
1. 识别少数单元（内部含有非黑像素的单元）。提取少数单元内部的栗(9)像素位置作为蓝图图案。
2. 将蓝图图案缩放到单元阵列层级：栗色像素在 4x4 内部空间中的位置对应 4x4 单元阵列中的单元坐标。在所有蓝图指示的位置放置少数单元的副本（已有的少数单元保持不变，新放置的少数单元复制已有少数单元的内部图案，标记颜色按行优先顺序交替使用红(2)和蓝(1)）。
3. 放置完毕后，将所有少数单元按其标记颜色分为两组（红组和蓝组）。
4. 在每组内，按单元位置的行优先顺序将相邻单元依次连线：在灰(5)分隔线的像素通道中，用该组颜色绘制最短 L 形路径连接每对相邻单元（路径仅经过分隔线像素，将分隔线像素重涂为连线颜色）。
5. 两种颜色的连线路径不可交叉。若存在冲突，红(2)路径优先占据该分隔线像素，蓝(1)路径绕行。

**关键洞察**：自相似蓝图决定了少数单元的空间分布，而空间分布直接决定了连线的拓扑复杂度——不同的蓝图产生截然不同的连线图案。蓝图的解码（栗色像素位置 → 单元阵列坐标的映射）需对比多个示例确认。
