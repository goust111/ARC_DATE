## 新题 4：镜像扩展后的涌现封闭与泛洪填充

**组合逻辑**：[mirror + four_way_symmetric_expansion](已有：四向镜像扩展) → [flood_fill](创新：在镜像创造的新拓扑结构中填充) ← [partial_enclosure + opening_direction](创新：原始开口在镜像对称轴处可能闭合，产生涌现封闭区域)

**来源原语**：mirror、four_way_symmetric_expansion（参考题 833dafe3）；flood_fill、partial_enclosure、fill_seed、opening_direction（参考题 b9e38dc0）

**依赖链**：原始图案中的半封闭墙有开口 → 四向镜像后，对称轴处的镜像墙可能与原墙拼合形成完全封闭区域（涌现效应）→ 泛洪填充从种子像素出发，封闭区域被完全填充而开放区域填充受限。镜像操作改变了拓扑结构，拓扑结构决定填充范围。

将含有半封闭墙和填充种子的小图案四向镜像扩展，镜像在对称轴处创造新的封闭区域，泛洪填充揭示哪些区域因镜像而变得封闭。

**输入结构**：一个较小的矩形网格（约 6x6），背景为黑(0)。网格内有灰(5)像素构成的半封闭墙结构（一段连续的 L 形或 U 形墙线，由 3-6 个灰色像素组成，形成一个有明确开口方向的半包围区域）。半封闭区域内部有一个红(2)种子像素。墙的开口朝向网格的某一边缘（上、下、左或右）。生成约束：墙结构不触及网格边缘（至少距边缘 1 像素），使得镜像后墙段之间有空隙或接合的可能；种子像素被墙半包围但可通过开口连通到外部。

**规则**：
1. 将输入网格作为右下象限，执行四向镜像扩展（与参考题 833dafe3 相同）：左右镜像 → 左下象限，上下镜像 → 右上象限，双轴镜像 → 左上象限。输出网格尺寸为输入的 2 倍。
2. 镜像后，灰色墙段也被复制到四个象限。在对称轴处，来自相邻象限的墙段可能首尾相接，形成原本不存在的完全封闭区域。
3. 对输出网格中的每个红(2)种子像素（共 4 个，分布在四个象限），执行泛洪填充：从种子像素出发，向 4-邻域的黑(0)背景格扩散红(2)色，灰(5)墙像素阻止扩散。
4. 若种子像素位于完全封闭区域内（因镜像拼合而封闭），则该区域被完全填充。若种子像素位于仍有开口的区域内，填充扩散到整个连通的背景区域。
5. 灰色墙和红色种子/填充像素共存；墙不被覆盖。

**关键洞察**：原始图案中墙的开口方向决定了镜像后哪些对称轴处会发生墙段拼合——朝向网格内部的开口在镜像后闭合（形成涌现封闭），朝向网格边缘的开口则保持开放。这是一个纯粹的涌现效应：单独看原始图案和镜像操作都不会产生封闭区域，只有两者结合才会出现。
