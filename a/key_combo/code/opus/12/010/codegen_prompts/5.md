## 新题 5：字形解码色 + 周期瓦片推断 = 双源汇合涂色

**组合逻辑**：[查表映射](字形解码颜色) + [平铺/补全](推断周期瓦片几何) + [重涂色](将瓦片中的占位色替换为解码色) —— 两个独立信息源分别提供"什么颜色"和"什么形状"，汇合后才能确定输出

**来源原语**：查表映射、编码字形、字形映射颜色、编码映射 (ed74f2f2, 9110e3c5)；平铺、补全、重复瓦片、遮挡区域、可见像素约束推断、最小周期推断填补 (ca8f78db, 29ec7d0e)；重涂色 (fafd9572)

**依赖链**：字形解码 -> 目标颜色 C；可见像素 -> 推断瓦片几何 T；用 C 替换 T 中的灰色 -> 输出。两路信息独立，但输出同时依赖两者。

从一个编码字形中解读目标颜色，从一个被遮挡的周期图案中推断重复瓦片的几何形状，然后用解读的颜色替换瓦片中的灰色像素并铺满整个图案区。

**输入结构**：约 12x12 的网格，背景为黑(0)。左上角 3x3 区域包含一个灰(5) 编码字形（5 个灰像素组成的特定形状，其余为黑）。该字形可以是以下三种之一：T 形（顶部三格 + 中下一格 + 底中一格）、右下折线（左上一格 + 中行中格 + 中行右格 + 下行右两格）、十字形（中心 + 上下左右各一格）。其余区域（从第 0 行第 4 列起至右下角）是一个周期色彩图案，使用灰(5) 和黑(0) 两色（灰为前景，黑为背景），但部分单元被栗(9) 矩形遮挡（栗色块覆盖了若干像素）。生成约束：遮挡区不覆盖字形区域；每个瓦片残基类的灰像素在未被遮挡处至少出现一次，使瓦片可唯一推断。

**规则**：
1. 解码字形：T 形 -> 蓝(1)，右下折线 -> 红(2)，十字形 -> 绿(3)。设解码颜色为 C。
2. 在图案区中，将栗(9) 像素视为未知，根据所有非栗像素推断最小矩形重复周期 (p_r, p_c)，使得每个非栗像素的颜色与 (row mod p_r, col mod p_c) 一致。构建 p_r x p_c 的瓦片 T。
3. 用瓦片 T 铺满整个图案区，替换所有像素（包括栗色遮挡区和原有像素）。
4. 在铺设结果中，将所有灰(5) 像素重涂为解码颜色 C。黑(0) 像素不变。
5. 字形区域保持原样（灰色字形不被重涂，因为它不在图案区内）。

**关键洞察**：字形和周期图案各自解决了一半问题——字形给出"涂什么颜色"，周期图案给出"涂在哪里"。两个信号源完全独立，只在最终输出阶段汇合。

Input structure
The grid is a rectangular periodic color table with black 0 cells as missing entries; each position in the true repeating tile is visible at least once.

Rule
Infer the smallest period p where all nonzero cells agree by (row mod p, column mod p), build that p x p tile, and replace every cell by the corresponding tile color.

Key insight
The nonzero pixels are samples of one complete repeating tile, so the repair follows from periodicity rather than from numeric color ordering.
</description>

      Colors used: 1..p. First row/col all 1s.
