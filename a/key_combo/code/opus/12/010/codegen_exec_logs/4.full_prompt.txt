## 新题 4：邻接过滤后的十字扩展色由存活数全局控制

**组合逻辑**：[擦除](邻接过滤) -> [计数](存活十字数) -> [扩展](正交对角分工) —— 过滤改变存活集合，存活总数全局回馈到每个存活者的扩展配色

**来源原语**：擦除、孤立像素、邻接、邻接不足则删除 (7f4411dc)；扩展、十字图案、正交对角分工、臂色中心色分延 (0962bcdd)；计数、像素数映射颜色 (6e82a1ae)

**依赖链**：邻接过滤决定哪些十字存活 -> 存活数 N 作为全局信号 -> N 的奇偶决定所有存活十字的对角扩展颜色。单看一个十字无法确定其扩展色，必须知道全局存活数。

过滤掉孤立噪声像素后，统计存活十字数量，然后将每个存活十字扩展为 5x5 图案，其中对角扩展的颜色由存活总数的奇偶性全局决定。

**输入结构**：约 15x15 的黑(0) 网格。4~6 个两色 3x3 十字图案散布其中：每个十字的 4 个臂为橙(7)，中心为黄(4)。另有若干橙(7) 噪声像素随机散布在非十字位置。生成约束：噪声像素与十字的臂像素不直接 4-邻接（确保过滤不会误伤十字臂）；至少有一个十字的某个臂像素恰好只有 1 个橙色 4-邻居（即中心），该十字将因过滤被整体移除。不同示例中存活十字数量的奇偶性不同。

**规则**：
1. 对每个橙(7) 像素，统计其橙色 4-邻居数量。移除所有橙色 4-邻居数 < 2 的橙像素（变为黑(0)）。
2. 检查每个十字是否仍完整（中心 + 4 臂均保留）。不完整的十字整体移除（所有残余像素变黑）。
3. 统计存活的完整十字数量 N。
4. 对每个存活十字执行 5x5 扩展：
   - 正交方向（上下左右）：在原臂外侧延伸 1 像素，颜色为臂色橙(7)。
   - 对角方向（四角）：若 N 为奇数，对角像素涂黄(4)（中心色）；若 N 为偶数，对角像素涂绿(3)。
5. 中心像素保持黄(4) 不变。

**关键洞察**：每个十字的扩展配色不是由自身属性决定，而是由全局存活十字总数的奇偶性统一控制——噪声分布间接影响存活数，从而影响所有存活者的外观。需要对比多个示例中噪声不同、存活数奇偶不同的情况才能归纳出这条隐式全局规则。

    2. On a 10x10 grid, design an LR-symmetric connected blob of D (36-48 cells, spanning 6-8 rows). For each active row, pick an even width (2-10) centered at col 4.5; optionally add symmetric internal gaps. Ensure the blob is connected.

## 实现要求

1. `main(grid)` 必须实现新题描述中的确定性转换规则，不能只识别 `generate_input()` 的固定模板。禁止不同的input网格输出相同的output网格。
2. `generate_input()` 必须随机生成多样样例，不能固定死。随机维度应覆盖：网格大小、对象数量、位置、颜色、方向、形状参数或关键分支。注意若描述中存在若干，需实现而不是只有单个，包括object或者对应关系等等。且若涉及到最短路径，则输入网格中必涉及到多条路径，对选择造成干扰。
3. 生成器必须保证输入满足 `main()` 的隐式假设：对象不重叠、不越界、特殊标记唯一或可区分、匹配关系无歧义、关键分支出现概率相同。
4. 禁止把 ARC 颜色 id 、亮度、拼写等当作人类不可见的数值语义参与排序、大小比较或隐藏映射。颜色变化必须有可见结构线索。注意颜色亮度、拼写等也是不可见信息，若描述中出现违规的颜色id或者亮度，可自行使用少量的固定颜色替代，但注意生成时要在三个以内输入输出网格中对所有变换100%覆盖度。
5. 输出样例要视觉清晰，人类必须能从输入输出对中肉眼辨认出规律。具体要求：避免对象粘连、覆盖关系混乱、同一像素多重语义；不同逻辑步骤产生的结果不要大面积层叠在一起导致无法分辨哪个颜色属于哪个步骤；输入中各元素之间保持足够间距，输出中新增的标记/填充/路径等应与背景和已有元素在颜色上有明显区分；若规则涉及多层叠加，生成时控制对象密度和尺寸，确保叠加区域只占少数像素而非铺满整个网格。
6. 若规则有多个分支，生成器不能长期固定成一个分支；应让分支在随机样例中合理出现。分支概率不必平均——难以发现的隐蔽分支（如少数情况下才触发的特殊规则）应适当提高出现概率，确保在 3 个训练示例中至少出现一次，否则求解者无法归纳该规则。对于颜色映射类规则，确保 2 个左右的示例即可覆盖所有映射关系（每种颜色→颜色的映射至少在某个示例中出现过）。
7. 代码风格参考 `ARC_code`：使用 `numpy`，并把 `/home/lixinyu/snap/new/solvers/arc_utils.py` 作为公共参考工具箱，优先复用其中已经稳定的 bbox、连通域、裁剪、变换和颜色工具；目标文件必须能被 `SourceFileLoader` 直接加载。
8. 可以在目标目录放公共 helper 文件，或从 `arc_utils.py` 摘取少量必要函数；若只实现一道题，优先保持目标文件自包含，减少额外依赖。
