## 新题 8：三角数位置选择 + 图例循环涂色 + 噪声过滤

**组合逻辑**：[擦除](噪声过滤) -> [图案识别](三角数位置判定) -> [循环填充](图例排位驱动色循环) —— 三级递进筛选：物理过滤、数学过滤、序位着色

**来源原语**：擦除、孤立像素、邻接、邻接不足则删除 (7f4411dc)；图案识别、忽略干扰项 (642d658d, 9110e3c5)；循环填充、色彩循环、递增间距序列、三角数位置 (72207abc)；重涂色、颜色图例、排位对应、图例位映射色 (fafd9572)

**依赖链**：邻接过滤去噪 -> 存活对象中识别三角数列位置（数学过滤）去干扰 -> 对通过双重过滤的对象按位置排位 -> 排位索引驱动图例色循环。四个阶段逐级缩小目标集，每级的输出是下一级的输入。

先过滤噪声，再从存活的精灵体中筛选出位于三角数列位置的目标，最后按位置排位用图例中的颜色循环重涂。

**输入结构**：约 20x8 的网格，背景为黑(0)。中间行（第 3~4 行，高 2 行）散布若干相同形状的灰(5) 小精灵体（4-连通，3~5 像素的不规则形状），每个精灵体占据一个不同的列区间。精灵体出现在多个列位置，其中一部分位于三角数列位置（以精灵体边界框最左列计算：第 0, 1, 3, 6, 10, 15... 列），另一部分位于非三角数列位置（干扰体）。另有若干孤立灰(5) 噪声像素散布在非精灵体位置。顶行（第 0 行）左侧有一条紧凑色带：3~4 个相邻像素，每个一种不同颜色（如蓝(1)、红(2)、绿(3)），定义颜色循环图例。生成约束：噪声像素与精灵体不 4-邻接；色带与精灵体/噪声不相邻；三角数位置的精灵体数量 > 图例颜色数（确保循环生效）。

**规则**：
1. 移除噪声：灰(5) 像素若其灰色 4-邻居数 < 2，则变为黑(0)。（精灵体像素因内部连通性而保留。）
2. 识别所有存活的完整精灵体（4-连通分量）。
3. 对每个精灵体，取其边界框最左列的列号 c。检查 c 是否为三角数（即存在非负整数 n 使得 c = n(n+1)/2）。非三角数位置的精灵体整体移除（变为黑(0)）。
4. 对存活的三角数位置精灵体，按列号从小到大排位：rank = 0, 1, 2, ...
5. 读取顶行色带中的颜色序列（从左到右）作为循环 C，长度为 L。
6. 将 rank 为 k 的精灵体的所有灰(5) 像素重涂为 C[k mod L]。
7. 色带保持不变。背景不变。

**关键洞察**：精灵体经历了双重筛选——先是物理层面的邻接噪声过滤，再是数学层面的三角数列位置判定。两层筛选缺一不可：仅噪声过滤会保留干扰精灵体，仅位置判定会被噪声残留干扰形状识别。最终的颜色由通过双重筛选后的排位决定，而非由原始位置或像素数决定。
