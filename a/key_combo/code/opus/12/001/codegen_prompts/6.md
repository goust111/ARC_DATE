## 新题 6：周期与镜像双重约束的缺失修复

**组合逻辑**：[补全/平移对称](已有原语) + [镜像/翻转行序](创新——镜像不是输出变换而是与周期性并列的修复约束)（非流水线结构：两种约束同时作用，无固定执行顺序）

**来源原语**：补全/平移对称/轨道可见色填缺失/周期瓦片(0dfd9992) + 镜像/翻转行序/整幅画布(68b16354)

**依赖链**：黑色遮挡破坏了画布的完整性→部分遮挡可通过周期轨道的其他可见成员恢复→但某些周期轨道的所有成员均被遮挡→此时必须利用垂直镜像对称：被遮挡位置的镜像位置（或其周期轨道的某个成员）是可见的→两种约束互相补充，缺一不可

一句话总结：同时利用平移周期性和上下镜像对称性修复画布中被黑色遮挡破坏的像素，任一约束单独均不足以完全恢复。

**输入结构**：
- 网格约 12x12。
- 未遮挡像素使用 3-4 种颜色（蓝(1)、红(2)、绿(3)、黄(4) 等，不含黑(0)），构成一个同时具备以下两种对称性的图案：
  - 平移周期性：存在最小平移向量 (dx, dy)（如 (3, 0) 和 (0, 4)），使图案在两个方向上重复。
  - 垂直镜像对称：将行序翻转后（第 r 行与第 H-1-r 行交换），非遮挡像素的颜色不变。
- 部分像素被替换为黑(0)（遮挡）。遮挡分布经过设计：
  - 类型 A 遮挡：其周期轨道中至少有一个非黑成员→仅凭周期性即可恢复。
  - 类型 B 遮挡：其周期轨道的所有成员均为黑色，但其镜像位置（第 H-1-r 行，同列）是非黑的→仅凭镜像即可恢复。
  - 类型 C 遮挡：其周期轨道全黑，且镜像位置也是黑色，但镜像位置的周期轨道中有非黑成员→必须先用周期性恢复镜像位置，再用镜像恢复自身（或等价地，先用镜像找到对应位置，再用周期性找到可见成员）。
- 生成约束：所有遮挡均属于 A/B/C 三类之一；不存在两种约束都无法解决的遮挡。

**规则**：
1. 检测非黑像素的最小平移周期向量组 (dx, dy)：找到能解释所有可见像素的最小正整数平移。
2. 对每个黑(0) 像素 (r, c)，尝试用以下方法恢复颜色：
   a. 周期轨道法：收集 {(r + k*dy, c + k*dx) | k 为整数, 位置在网格内} 中所有非黑像素的颜色。若存在唯一颜色，则填入该颜色。
   b. 若周期轨道全黑：取镜像位置 (H-1-r, c)。若该位置非黑，填入该位置的颜色。
   c. 若镜像位置也是黑色：对镜像位置 (H-1-r, c) 执行周期轨道法——收集 {(H-1-r + k*dy, c + k*dx)} 中的非黑颜色，若存在唯一颜色，则将该颜色填入原位置 (r, c)。
3. 输出完整恢复的网格（无黑色像素）。

**关键洞察**：遮挡模式经过对抗性设计——存在周期轨道被整体摧毁的"死轨道"，仅凭周期性无法恢复。镜像对称提供了打破死锁的第二条信息通道，但某些位置需要两种约束级联使用（先周期再镜像或先镜像再周期），任何单一约束都不完备。
