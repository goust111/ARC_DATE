## 新题 3：平行四边形围栏内的种子周期填充

**组合逻辑**：[连线/draw_line](创新：对角分解画平行四边形轮廓，而非只画一条线段) + [平铺/tiling](创新：在非矩形的平行四边形内部做周期平铺，保持种子相位) + [填充/fill](创新：填充域由几何构造动态定义，而非由预设的墙壁围出)

**来源原语**：连线/draw_line、对角分解/diag_decompose、标记为对顶点/markers_as_vertices、平行四边形轮廓/parallelogram（来自 cb227835）；平铺/tiling、种子图案/seed_pattern、保持种子相位/preserve_seed_phase（来自 a57f2f04）；标记像素/marker_pixel（来自 cb227835, a57f2f04）

**依赖链**：标记像素对的偏移向量经对角分解后定义平行四边形的形状 → 平行四边形的内部区域是平铺的目标域 → 种子图案提供平铺瓦片及相位参考。去掉对角分解则不知平行四边形形状；去掉种子则不知用什么图案填充；去掉平铺则平行四边形内部为空。三者紧耦合：几何构造定义域，种子定义内容，平铺执行填充。

由同色标记像素对的对角分解向量构造平行四边形围栏，在围栏内部用邻近种子图案做相位对齐的周期平铺。

**输入结构**：约 22x22 的网格，黑(0)背景。包含 2-3 对同色标记像素，每对使用不同颜色（例如一对红(2)、一对蓝(1)）。每对标记之间的偏移向量同时具有非零的行分量和列分量，且行分量与列分量的绝对值不相等（例如 dr=5, dc=3）。在每对标记中按光栅序靠前的那个标记的正下方一行（如果正下方被占用则在正右方一列），有一个小的种子图案：一个由 2-4 个像素组成的 4-连通簇，使用一种"填充色"（不同于任何标记色，从黄(4)、品红(6)、灰(5)中选取），其包围框大小为 2x2 或 2x3。不同标记对的种子图案颜色和形状可以不同。生成约束：各对标记定义的平行四边形互不重叠或仅少量重叠（重叠面积不超过各自面积的 10%）；种子图案不位于任何平行四边形内部。

**规则**：
1. 对每对同色标记像素，计算从光栅序靠前的标记 P1 到另一个标记 P2 的偏移向量 (dr, dc)。
2. 将偏移向量分解为两个分量：
   - 对角分量 D：方向 = (sign(dr), sign(dc))，步数 = min(|dr|, |dc|)
   - 轴向分量 A：偏移减去对角分量后的剩余部分（纯水平或纯垂直）
3. 以 P1 为起点，D 和 A 为相邻两边，构造平行四边形的四个顶点：P1, P1+D, P1+A, P1+D+A（= P2）。
4. 沿四条边画绿(3)轮廓线（含顶点）。使用 Bresenham 直线算法连接相邻顶点。标记像素保留原色不变（不被绿色覆盖）。
5. 找到与该标记对关联的种子图案（位于 P1 正下方一行或正右方一列的那个非背景非标记色簇）。
6. 以种子图案的包围框为瓦片周期，以种子在网格中的实际位置为相位参考，将该瓦片在整个网格上做无限周期延伸，但仅保留落在平行四边形内部（严格在轮廓线以内、不含轮廓线本身）的像素。
7. 如果两个平行四边形的内部有重叠区域，按标记对中 P1 行号较小者优先（P1 行号相同则列号较小者优先），优先者的填充覆盖后者。
8. 种子图案像素保持不变（不被清除）。

**关键洞察**：平行四边形的形状不是预定义的——它由标记对的偏移向量的对角-轴向分解动态决定，不同示例中偏移向量不同则平行四边形的倾斜方向和纵横比完全不同。求解者需要从多个示例中归纳出分解规则（取 min 为对角步数、剩余为轴向），而非记忆某个固定形状。
