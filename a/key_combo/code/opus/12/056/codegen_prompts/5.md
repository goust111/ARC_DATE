## 新题 5：凸耳镜像复原模板后格网印章

**组合逻辑**：[镜像/mirror](创新：凸耳指示镜像轴用于复原一个残缺模板，而非在对侧放置副本) + [印章覆盖/stamp_overlay](创新：模板不是直接可见的完整图案，而是需要先通过镜像操作重建)

**来源原语**：镜像/mirror、凸耳/tab、凸耳决定镜像轴/tab_determines_axis、对侧放置/opposite_place（来自 dc2e9a9d）；印章覆盖/stamp_overlay、分隔线划分/separator_partition、格网/lattice、标记单元格/marker_cell、示例邻域传递同色/exemplar_copied_to_same_color（来自 39e1d7f9）

**依赖链**：凸耳位置 → 确定镜像轴 → 镜像复原出完整模板（含移除凸耳） → 模板被印章到所有同色标记单元格。去掉镜像则模板残缺；去掉印章则只有一个复原模板无法传播；去掉凸耳则不知如何镜像。

识别格网中一个带凸耳的残缺图案，通过凸耳指示的轴镜像复原完整模板，然后将复原模板印章到格网中所有同色标记单元格。

**输入结构**：约 17x17 的网格。灰(5)分隔线将网格划分为规则的单元格格网（例如 4x4 个单元格，每个单元格 3x3 像素）。绝大多数单元格内部为黑(0)背景。一个单元格内包含一个"残缺模板"：由某种颜色（如红(2)）绘制的一个非对称 4-连通图案（3-5 像素），该图案只占据单元格的一半（左半或右半、上半或下半），在靠近单元格某条边的位置有一个同色的单独凸出像素（凸耳），凸耳与图案主体通过恰好 1 像素的间隙分离，位于图案的对称缺失侧。另有 2-4 个单元格各包含一个该颜色（红(2)）的单独标记像素（位于单元格中央）。其余单元格均为纯黑(0)背景。生成约束：镜像复原后的完整模板必须完全容纳在单个单元格内部，不超出单元格边界。凸耳恰好位于残缺图案该侧的边缘行或列上。

**规则**：
1. 在格网中找到包含多于 1 个非背景像素的单元格，该单元格即为"模板单元格"。
2. 在模板单元格内，识别凸耳像素：与图案主体不直接 4-连通、但距离主体恰好 1 像素的孤立同色像素。凸耳所在的单元格边缘（左/右/上/下）即为镜像轴边缘。
3. 以凸耳所在边缘为镜像轴，将图案主体（不含凸耳）做镜像翻转，与原图案合并，得到完整的对称模板。凸耳像素从模板中移除。
4. 在格网中找到所有包含单个同色标记像素的单元格。
5. 将完整模板印章到每个标记单元格中，以单元格中心对齐（模板居中放置）。标记像素被模板覆盖。
6. 模板单元格中的残缺图案被替换为完整的复原模板（同样居中放置），凸耳消失。
7. 灰(5)分隔线保持不变。如果模板像素与分隔线重叠，分隔线优先（不被覆盖）。

**关键洞察**：凸耳在源题(dc2e9a9d)中指示"在对侧放一个镜像副本"，但在本题中它的含义完全不同——凸耳指示"图案本身是残缺的，缺失的那一半在凸耳侧"。凸耳不是模板的一部分而是控制信号，需要多个示例（不同凸耳方向、不同残缺侧）才能归纳出这一规则。

## 实现要求

1. `main(grid)` 必须实现新题描述中的确定性转换规则，不能只识别 `generate_input()` 的固定模板。禁止不同的input网格输出相同的output网格。
2. `generate_input()` 必须随机生成多样样例，不能固定死。随机维度应覆盖：网格大小、对象数量、位置、颜色、方向、形状参数或关键分支。注意若描述中存在若干，需实现而不是只有单个，包括object或者对应关系等等。且若涉及到最短路径，则输入网格中必涉及到多条路径，对选择造成干扰。
3. 生成器必须保证输入满足 `main()` 的隐式假设：对象不重叠、不越界、特殊标记唯一或可区分、匹配关系无歧义、关键分支出现概率相同。
4. 禁止把 ARC 颜色 id 、亮度、拼写等当作人类不可见的数值语义参与排序、大小比较或隐藏映射。颜色变化必须有可见结构线索。注意颜色亮度、拼写等也是不可见信息，若描述中出现违规的颜色id或者亮度，可自行使用少量的固定颜色替代，但注意生成时要在三个以内输入输出网格中对所有变换100%覆盖度。

6. 若规则有多个分支，生成器不能长期固定成一个分支；应让分支在随机样例中合理出现。分支概率不必平均——难以发现的隐蔽分支（如少数情况下才触发的特殊规则）应适当提高出现概率，确保在 3 个训练示例中至少出现一次，否则求解者无法归纳该规则。对于颜色映射类规则，确保 2 个左右的示例即可覆盖所有映射关系（每种颜色→颜色的映射至少在某个示例中出现过）。
