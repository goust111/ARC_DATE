## 新题 5：对称补全后的逻辑或非合并

**组合逻辑**：[对称补全/symmetry_completion](已有) → [逻辑运算/logical_op](已有，NOR) —— 但前者的输出实质性地改变后者的输入（占位符的修复直接影响 NOR 结果）

**来源原语**：对称补全、占位标记、对称图案、双轴反射轨道、轨道内唯一可见色（参考题 903d1b4a）；逻辑运算、二值掩模、分隔条、逐像素对应、逻辑或非合并（参考题 1b2d62fb）

**依赖链**：两个半区各自包含带占位符的不完整掩模，必须先通过对称补全修复占位符才能得到完整掩模；完整掩模才能执行逻辑 NOR；若跳过对称补全，NOR 的输入缺失，结果不确定。反过来，若只做对称补全不做 NOR，输出只是两个修复后的半区拼合，与正确输出不同。

先通过双轴对称修复两个被占位符破坏的掩模，再计算修复后掩模的逐像素逻辑或非。

**输入结构**：约 15x9 的网格。一条全高蓝(1)竖直分隔条将网格分为左右两个等大半区（每半区约 7 列宽）。每个半区包含一个栗(9)色像素构成的图案，以黑(0)为背景。每个半区的栗色图案本身具有上下和左右双轴反射对称性，但其中部分像素被替换为绿(3)占位标记。每个占位标记的双轴反射轨道内（在同一半区内反射）至少有一个可见的栗(9)像素或可见的黑(0)像素，使得修复值唯一确定。左右两个半区的图案形状不同。生成约束：每个半区内的绿色占位符数量为 2-5 个；修复后的两个掩模不完全相同（否则 NOR 全为黑色，过于平凡）；修复后至少存在一些"双方均为黑"的位置，以产生非空的 NOR 输出。

**规则**：
1. 识别蓝(1)分隔条，确定左右两个半区。
2. 对左半区：将其视为独立的矩形网格，以栗(9)为前景、黑(0)为背景。找到所有绿(3)占位像素。对每个绿色像素，计算其在半区内的水平镜像位置和垂直镜像位置（以半区的中心行和中心列为轴）。在同一反射轨道（最多 4 个位置）中，找到唯一的非绿可见值（栗或黑），将绿色替换为该值。
3. 对右半区执行相同的对称补全操作。
4. 补全后，将左右两个半区视为同尺寸的二值掩模（栗=活跃，黑=非活跃），逐像素对应。
5. 计算逻辑 NOR：对于每个对应位置，若左、右半区对应像素均为黑（均非活跃），输出青(8)；否则输出黑(0)。
6. 输出为一个与半区等大的网格（不含分隔条），只包含青(8)和黑(0)。

**关键洞察**：绿色占位符不是装饰——它们是待修复的"未知数"，修复结果直接决定 NOR 输出中哪些位置为青色。一个绿色像素被修复为栗色还是黑色，可能翻转对应 NOR 输出位置的值。

## 实现要求

1. `main(grid)` 必须实现新题描述中的确定性转换规则，不能只识别 `generate_input()` 的固定模板。禁止不同的input网格输出相同的output网格。
2. `generate_input()` 必须随机生成多样样例，不能固定死。随机维度应覆盖：网格大小、对象数量、位置、颜色、方向、形状参数或关键分支。注意若描述中存在若干，需实现而不是只有单个，包括object或者对应关系等等。且若涉及到最短路径，则输入网格中必涉及到多条路径，对选择造成干扰。
3. 生成器必须保证输入满足 `main()` 的隐式假设：对象不重叠、不越界、特殊标记唯一或可区分、匹配关系无歧义、关键分支出现概率相同。
4. 禁止把 ARC 颜色 id 、亮度、拼写等当作人类不可见的数值语义参与排序、大小比较或隐藏映射。颜色变化必须有可见结构线索。注意颜色亮度、拼写等也是不可见信息，若描述中出现违规的颜色id或者亮度，可自行使用少量的固定颜色替代，但注意生成时要在三个以内输入输出网格中对所有变换100%覆盖度。
5. 输出样例要视觉清晰，人类必须能从输入输出对中肉眼辨认出规律。具体要求：避免对象粘连、覆盖关系混乱、同一像素多重语义；不同逻辑步骤产生的结果不要大面积层叠在一起导致无法分辨哪个颜色属于哪个步骤；输入中各元素之间保持足够间距，输出中新增的标记/填充/路径等应与背景和已有元素在颜色上有明显区分；若规则涉及多层叠加，生成时控制对象密度和尺寸，确保叠加区域只占少数像素而非铺满整个网格。
6. 若规则有多个分支，生成器不能长期固定成一个分支；应让分支在随机样例中合理出现。分支概率不必平均——难以发现的隐蔽分支（如少数情况下才触发的特殊规则）应适当提高出现概率，确保在 3 个训练示例中至少出现一次，否则求解者无法归纳该规则。对于颜色映射类规则，确保 2 个左右的示例即可覆盖所有映射关系（每种颜色→颜色的映射至少在某个示例中出现过）。
