## 新题 9：遮挡恢复后的缺陷条检测与标注

**组合逻辑**：[镜像](已有：利用对称性恢复被遮挡区域) + [裁剪](已有：提取恢复后的子图) + [重涂色](创新：在恢复的子图中检测缺陷并标注，缺陷定义来自不同原语)

**来源原语**：镜像(mirror) + 裁剪(crop) + 遮挡块(occluder) + 被遮区域(occluded_region) + 镜像对称(mirror_symmetry) + 反射恢复遮挡(reflection_recovers) ← dc0a314f；重涂色(recolor) + 缺陷条(defect_bar) + 实心矩形(solid_rectangle) ← 9b5080bb

**依赖链**：先通过镜像恢复被遮挡区域→在恢复的图案中识别近实心矩形及其缺陷条→将缺陷条重涂标注色。恢复操作产出的图案本身包含需要进一步分析的结构，不是简单的"恢复即终"。

利用场景的镜像对称恢复被遮挡的图案，然后在恢复的图案中找出近实心矩形的缺陷条并标注为特定颜色。

**输入结构**：约 15x15 的方形网格。网格整体具有近似的垂直或水平镜像对称性。网格中有一个由品红(6)像素组成的实心方形遮挡块（3x3 至 5x5），品红色仅出现在该遮挡块中。被遮挡区域下方隐藏着一个图案，该图案包含一个近实心的蓝(1)矩形，矩形有 1~2 个缺陷条（缺陷条为垂直于矩形最近边的两像素短条，由背景色构成）。遮挡块对面的镜像位置可以看到完整的对应图案。生成约束：遮挡块不跨越对称轴；遮挡块的镜像位置不含品红色像素；被隐藏的蓝色矩形完全在遮挡块范围内。

**规则**：
1. 识别品红(6)遮挡块（唯一最大的品红色实心方形）。
2. 确定场景的对称轴方向（水平或垂直）。
3. 将遮挡块区域关于对称轴做镜像反射，从反射位置提取图案，用该图案替换遮挡块区域（恢复被隐藏的内容）。
4. 在恢复后的图案中找到蓝(1)矩形核心（最大的蓝色矩形子区域）。
5. 识别该矩形的缺陷条：矩形核心边缘处缺失的像素和单像素突出构成的垂直于最近核心边的两像素短条。
6. 将缺陷条像素涂为红(2)。输出仅为遮挡块区域大小的子网格，包含恢复并标注缺陷后的图案。

**关键洞察**：恢复操作不是最终目的——恢复出的图案本身包含需要进一步处理的缺陷结构，这些缺陷在遮挡状态下不可见，必须先恢复才能检测。两步操作紧密耦合：跳过恢复则无图案可分析，跳过缺陷检测则输出不完整。
