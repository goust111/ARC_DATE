## 新题 4：分隔线对齐比较门控花纹转移

**组合逻辑**：[对齐比较/aligned_comparison](从移动单像素改为门控整体操作) + [颜色匹配定去向/color_match_dest](创新：匹配 -> 转移花纹，不匹配 -> 擦除目标框) + [空心矩形 + 内部花纹/hollow_rect + interior_motif](从无条件转移改为由比较结果条件触发) + [印章覆盖/stamp_overlay + 重涂色/recolor](花纹在转移过程中变色) + [擦除/erase](不匹配时整框擦除)

**来源原语**：aligned_comparison, color_match_dest, separator_line (7d7772cc); hollow_rect, interior_motif, stamp_overlay, patterned_frame_template, size_match (f21745ec); recolor, erase (多源)

**依赖链**：尺寸匹配确定哪些框配对，颜色比较决定配对后是转移花纹还是擦除目标框，转移时花纹还需重涂为目标框色。三个环节缺一不可：没有尺寸匹配则配对错误，没有颜色比较则不知哪些框获得花纹哪些被擦除，没有重涂色则花纹颜色错误。

分隔线两侧各有若干矩形框；左侧框含花纹，右侧框为空。按尺寸配对后，分隔线上的参考像素颜色决定是否将花纹转移到右侧框。

**输入结构**：
- 黑(0)背景，约 20x15 网格
- 一条贯穿全高的灰(5)垂直线位于网格中部，作为分隔线
- 左侧：2~3 个单像素厚的彩色空心矩形框（每个框一种非黑非灰颜色，如蓝(1)、红(2)、绿(3)），每个框内部有同色的花纹像素（不对称图案，约 3~6 个像素）
- 右侧：与左侧数量相同的空心矩形框（每个框一种非黑非灰颜色，如黄(4)、橙(7)、品红(6)），内部无花纹（全为黑(0)背景）
- 左右框通过外部尺寸（高 x 宽）一一配对：每个左框恰好有一个右框与其外部尺寸相同，且不存在两个左框尺寸相同
- 在分隔线列上，每对配对框各有一个参考像素：左框的参考像素颜色为 C_left，右框的参考像素颜色为 C_right，两者位于同一行
- 生成约束：至少一对 C_left == C_right，至少一对 C_left != C_right

**规则**：
1. 通过外部尺寸（高度和宽度）将左右框一一配对
2. 对每一对，检查其在分隔线上的参考像素颜色：
   - 若 C_left == C_right：将左框的内部花纹复制到右框的对应内部位置，花纹像素重涂为右框的边框颜色
   - 若 C_left != C_right：将右框整体擦除为背景(0)（边框和内部全部清除）
3. 左侧所有内容（框、花纹、参考像素）保持不变；分隔线保持不变

**关键洞察**：分隔线上的参考像素不属于任何框的结构——它们是独立的比较通道，门控了完全不同的两种操作（花纹转移 vs. 整框擦除）。必须对比多个示例才能发现颜色匹配/不匹配分别触发哪种操作。
