## 新题 3：孔洞双重角色——计数定复制数，种子定内容

**组合逻辑**：[计数/counting](计封闭孔洞数 = 平铺次数) + [封闭孔洞/enclosed_hole](双重角色：被计数 + 容纳种子) + [种子像素/seed_pixel](创新：种子不从候选库选模板，而是自身即为模板) + [平铺/tile](按孔洞数水平重复) + [裁剪/crop](提取种子图案)

**来源原语**：counting, enclosed_hole, enclosed_region (0a2355a6); seed_pixel, seed_selects_template (8a6d367c); tile, pixel_count_sets_size_copies (91413438); crop (b94a9452)

**依赖链**：孔洞同时承担两个不可替代的角色：全部孔洞的数目决定输出的重复次数，唯一含种子的孔洞提供重复的内容。删除计数则不知复制几份，删除种子提取则不知复制什么。两者绑定在同一结构（孔洞）上，无法独立求解。

数封闭孔洞得重复次数，从唯一含种子的孔洞中提取图案，水平平铺该图案相应次数。

**输入结构**：
- 黑(0)背景，约 15x15 网格
- 1~2 个 4-连通单色前景对象（颜色如蓝(1)或红(2)），每个对象封闭 2~4 个 4-连通的黑(0)内部孔洞
- 每个对象中恰好一个孔洞内含有 1~4 个种子像素（颜色与对象色不同，如绿(3)或黄(4)），构成一个小图案（紧凑边界框 2x2 或 3x3 以内）
- 其余孔洞为纯黑(0)，不含任何非背景像素
- 不同对象互不接触，且都不触碰网格边缘
- 若有多个对象，它们的孔洞数互不相同

**规则**：
1. 对每个对象，计数其封闭的黑(0)孔洞总数 N（含有种子的孔洞也计入）
2. 找到含有种子像素的那个孔洞，将种子像素裁剪到其紧凑边界框
3. 将裁剪出的种子图案水平平铺 N 次，相邻副本之间间隔 1 列黑(0)
4. 若有多个对象，按各对象最上端像素的行坐标从小到大排列，依次将其平铺行纵向堆叠，相邻行之间间隔 1 行黑(0)
5. 输出仅包含平铺结果，原对象及其边框均不保留

**关键洞察**：空孔洞没有视觉内容却影响输出的宽度（它们贡献计数）；含种子的孔洞既贡献计数又提供内容——孔洞的双重角色是解题关键，单个示例无法分辨"复制次数 = 孔洞数"和"复制次数 = 种子像素数"等替代假说。
