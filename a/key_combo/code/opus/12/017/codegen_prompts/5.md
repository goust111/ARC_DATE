## 新题 5：频率选精灵 + 频率定对角变色周期

**组合逻辑**：[计数/counting + 形状相同/shape_identity + 最高频精灵输出/most_frequent_sprite_output](从输出单份改为输出对角阵列) + [对角偏移重复/diag_offset_repeat + 尺寸决定步幅/size_determines_stride](从矩形改为精灵体) + [周期内指定位变色/cyclic_pos_recolored](创新：周期长度 = 频率计数值而非固定值 3) + [擦除/erase](非选中精灵移除)

**来源原语**：counting, shape_identity, most_frequent_sprite_output (39a8645d); diag_offset_repeat, size_determines_stride (e619ca6e); stamping, cyclic_pos_recolored (d304284e); erase (多源)

**依赖链**：频率计数同时决定两件事——哪种精灵被选中（最高频者），以及对角印章序列中的变色周期（频率值 K）。精灵的边界框尺寸决定步幅。三者缺一不可：不计数则不知选谁也不知周期；不知步幅则排布错误；不知周期则变色位置错误。

从多种重复精灵中选出最高频者，沿两条对角线反复印章；每隔 K 份（K = 频率计数值）将该份变色为红(2)。

**输入结构**：
- 黑(0)背景，约 18x18 网格
- 8~12 个小型单色精灵体（每个 3~6 像素，8-连通），分属 2~3 种形状类型
- 每种形状类型使用各自独有的颜色（如蓝(1)的 L 形散布、绿(3)的 T 形散布等，不同示例中具体形状不同，但同类型内形状一致）
- 恰好一种形状类型的出现次数严格多于其他任何类型（唯一最高频）
- 各精灵体互不接触，且不触碰网格边缘
- 记最高频类型的频率为 K（K >= 2），其边界框尺寸为 H x W

**规则**：
1. 将每个精灵体归一化到其紧凑边界框掩码，以（形状掩码 + 颜色）作为类型标识
2. 统计各类型出现次数，选出唯一最高频类型，记其频率为 K，边界框为 H x W
3. 将所有非最高频精灵擦除为背景(0)
4. 从每个保留的最高频精灵实例的左上角出发，沿右下方向以步幅 (H, W) 反复印章：偏移 (H, W), (2H, 2W), ...；同时沿左下方向以步幅 (H, -W) 反复印章：偏移 (H, -W), (2H, -2W), ...
5. 对每条对角方向的印章序列，从第 1 份印章开始编号（原实例不算，编号 0）：编号为 K 的整数倍的印章（第 K 份、第 2K 份、...）重涂为红(2)，其余保持原色
6. 超出网格边界的部分裁剪丢弃；原精灵实例保持原色不变

**关键洞察**：频率计数 K 同时控制精灵筛选和变色节奏——不计算频率就无法确定对角线上哪些位置变色。仅看单个示例可能将变色位置误读为固定间隔，需要多个示例（K 值不同）才能发现 K = 频率。

1. `main(grid)` 必须实现新题描述中的确定性转换规则，不能只识别 `generate_input()` 的固定模板。禁止不同的input网格输出相同的output网格。
2. `generate_input()` 必须随机生成多样样例，不能固定死。随机维度应覆盖：网格大小、对象数量、位置、颜色、方向、形状参数或关键分支。注意若描述中存在若干，需实现而不是只有单个，包括object或者对应关系等等。且若涉及到最短路径，则输入网格中必涉及到多条路径，对选择造成干扰。
