## 新题 6：孔洞拓扑解码 + 外部图例映射压缩

**组合逻辑**：[解码/decode](从读取槽位颜色改为读取拓扑特征) + [计数/counting](计封闭孔洞数作为解码键) + [图例映射/legend_mapping](创新：图例将孔洞数映射为颜色，而非位置映射颜色) + [压缩/compress + 每区域折叠单像素/region_to_pixel](将解码后的阵列压缩为小网格)

**来源原语**：decode, repeated_motif, legend_mapping, slot_determines_color (1be83260); counting, enclosed_hole, hole_count_to_color_mapping (0a2355a6); compress, grid_partition, region_to_pixel (780d0b14)

**依赖链**：图例将孔洞数映射为颜色（不是硬编码映射，每个示例的图例可能不同）；孔洞计数将每个花纹的拓扑特征转化为图例查找键；压缩将阵列坍缩为小网格。删除图例则映射关系不确定，删除计数则查找键不确定，删除压缩则输出格式错误。

外观相似的花纹阵列中，每个花纹内部孔洞数不同；外部色条图例将孔洞数映射为颜色；输出为每花纹一像素的压缩网格。

**输入结构**：
- 黑(0)背景，约 20x20 网格
- 一个 R x C 的矩形阵列由相同外形的小花纹组成（每个花纹 5x5，含 1 像素厚的灰(5)外框），花纹之间间隔 1 列/行背景
- 每个花纹的外框形状完全一致，但内部 3x3 区域中，0~4 个格子为黑(0)背景（即封闭孔洞），其余为灰(5)前景
- 不同花纹的孔洞数可能不同（0 到 4 均可出现）
- 阵列外部（如右侧或下方）有一条 5 格长的色条图例，用品红(6)单像素框围住以标识
- 图例的 5 个格子从左到右（或从上到下）分别编号 0~4，每格填有一种颜色（使用蓝(1)、红(2)、绿(3)、黄(4)、橙(7)等），表示孔洞数为该编号时的输出颜色
- 同一输入中图例不含重复颜色

**规则**：
1. 识别花纹阵列的 R x C 布局和外部图例色条
2. 对阵列中每个花纹，计算其内部 3x3 区域中 4-连通的封闭黑(0)孔洞数 H（0 <= H <= 4）
3. 在图例中查找编号 H 对应的颜色 C
4. 输出 R x C 网格，每个格子的颜色为该位置花纹解码后的颜色 C

**关键洞察**：花纹外形完全一样，差异隐藏在内部拓扑（孔洞数）中；图例将拓扑特征翻译为颜色，且图例内容随示例变化，因此不能记忆固定映射。必须同时发现"看的是孔洞数"和"查的是外部图例"这两层间接关系。
