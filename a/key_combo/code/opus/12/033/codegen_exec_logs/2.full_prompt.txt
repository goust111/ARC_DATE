## 新题 2：孔洞拓扑编码循环色移

**组合逻辑**：[计数](孔洞拓扑计数) → [循环移位](创新：移位量由拓扑特征——孔洞数——决定，而非由空间属性如高度决定) + [填充](创新：填充孔洞以销毁编码证据)

**来源原语**：循环移位、有序槽位、色与高反向轮转(2601afb7)；孔洞、封闭区域、内外边界(d931c21c)；计数(bd283c4a)；填充(d5d6de2d)

**依赖链**：孔洞计数是循环移位的参数来源；移位改变了每个框架的颜色；随后孔洞被填充为统一色，擦除了决定移位量的证据。求解者必须在证据被销毁前的输入中读取孔洞数量，再反推输出中的颜色排列。

统计每个空心矩形框内的孔洞数量，以此数量作为循环色移量重排各框架颜色，然后将所有孔洞填为绿色。

**输入结构**：黑(0)背景，约 16x18。N 个（3-5 个）空心矩形框沿水平方向从左到右排列，互不重叠，间距 2-3 列。每个框的边框为单像素厚的单色边框（每个框颜色不同，使用红(2)、蓝(1)、黄(4)、品红(6)、橙(7)等），框的内部为黑(0)。部分框的内部含有 0、1 或 2 个小型黑(0)孔洞——这些孔洞是框内部被额外的同色像素围成的封闭小区域（孔洞的 4-连通黑色分量不与框外部的黑色背景连通）。孔洞的形状为不规则的小型连通区域（2-4 像素），不同框内的孔洞形状可以不同。生成约束：所有框的孔洞数量不全相同（至少两个框的孔洞数不同）；循环移位后每个槽位的颜色与输入不完全相同（即变换可被观测到）。

**规则**：
1. 将 N 个空心矩形框按其边界框左上角的列坐标从小到大排序，依次编为槽位 0, 1, ..., N-1。
2. 记录每个槽位 i 的框边框颜色 C_i 和其内部孔洞数量 H_i。
3. 循环色移：槽位 i 的输出颜色 = 槽位 (i - H_i) mod N 的输入颜色 C_{(i - H_i) mod N}。即孔洞数 H_i 决定该框从左侧第 H_i 个位置借来颜色（循环取模）。
4. 用新颜色重涂每个框的所有边框像素。
5. 将所有框内部的孔洞像素（原本被同色边框围住的黑色封闭区域）填充为绿(3)。

**关键洞察**：孔洞的数量是拓扑属性，在空间上分散且形状不规则，不易直觉关联到颜色的代数运算。填充孔洞为绿色后，输出中已无法直接看到各框的孔洞数量，求解者必须从输入中提取拓扑信息、与输出的颜色排列对比，才能归纳出"孔洞数 = 移位量"这条隐蔽规则。
