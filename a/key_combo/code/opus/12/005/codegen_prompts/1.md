## 新题 1：多源并发生长与拓扑间隙分类

**组合逻辑**：[生长(grow)](创新：多源同步扩展，冲突像素生成新障碍) + [连通分量检测(connected_component_detection)] + [重涂色(recolor) + 拓扑分类(topological_classification)]（标注：生长为创新改造，冲突标记机制为新增；连通分量检测、拓扑分类为已有原语直接使用）

**来源原语**：生长/同心方框层/种子像素(5c2c9af4)、连通分量检测/边界可达性/拓扑分类(84db8fc4)、重涂色(多源)

**依赖链**：多源同步生长产生领地划分与冲突标记 → 冲突标记与原始障碍共同界定背景间隙的连通结构 → 对间隙进行拓扑分类（是否可达网格边缘）→ 分类结果决定间隙涂色。冲突标记是生长的涌现产物，它改变了拓扑结构：若无冲突标记，某些间隙可能与边界相通；有了冲突标记，这些间隙被封死变为内陷区域。

从多个种子同步向外逐层生长，生长冲突产生新的障碍像素，最终对残留的背景间隙按是否可达网格边界进行拓扑分类并涂色。

**输入结构**：约 15x15 的黑(0)背景网格。网格上散布 3~5 段灰(5)短线段（每段 2~4 像素，水平或垂直），作为初始障碍。另有 2~3 个种子像素，每个种子颜色不同（从红(2)、绿(3)、蓝(1)中选取），彼此不相邻，且不与灰障碍相邻。生成约束：种子位置和障碍布局保证生长过程中至少产生 2 个冲突像素，且最终残留的黑(0)间隙中至少有 1 个可达边界、至少有 1 个被完全封闭。

**规则**：
1. 所有种子同步向外生长。每一步中，每个种子的生长前沿向外扩展一层（曼哈顿距离加一），试图占据所有 4-邻接的黑(0)背景像素。已被占据的像素（障碍、其他种子领地、其他种子本身）不可被占据。
2. 若同一步中有两个或更多种子同时试图占据同一个黑(0)像素，该像素不归属任何种子，而被标记为灰(5)——与初始障碍同色，成为新的障碍像素。
3. 生长持续进行，直到所有种子都无法再扩展为止。
4. 生长完成后，识别网格中所有残留的黑(0)像素，将它们按 4-连通划分为若干连通区域。
5. 对每个黑(0)连通区域判断拓扑类别：若该区域中至少有一个像素位于网格最外圈（第 0 行、最后一行、第 0 列或最后一列），则该区域为"边缘可达区域"，将其所有像素重涂为橙(7)；否则该区域为"封闭区域"，将其所有像素重涂为黄(4)。
6. 所有灰(5)像素（原始障碍 + 冲突标记）、种子像素、生长占据的像素均保持不变。

**关键洞察**：冲突标记是多源生长的涌现产物而非输入的一部分——它们可以封堵原本通向网格边界的路径，从而将本应是边缘可达的间隙变为封闭区域。求解者必须先完成生长（含冲突解决），才能判断哪些间隙是封闭的。
