## 新题 4：面积排序叠加与干扰去除

**组合逻辑**：[裁剪·保留最大分量·忽略干扰项](已有) + [计数·面积排序](已有) → [叠加](创新：叠加的图层顺序由像素面积而非空间位置决定)

**来源原语**：裁剪·保留最大分量·忽略干扰项·按面积筛选(337b420f)，计数·面积排序·按像素数降序(f8ff0b80)，叠加(337b420f)

**依赖链**：各面板中分量面积筛选 → 保留最大分量 → 跨面板比较像素面积以确定叠加顺序 → 叠加时遮挡关系由面积排序而非面板位置决定 → 遮挡区域的最终颜色取决于面积排名

三个面板各保留最大前景分量后，按像素面积从小到大依次叠加到单一画布上，面积最大的分量在最上层，遮挡重叠区域。

**输入结构**：5x17 网格，由三个 5x5 面板和两条一像素宽的黑(0)分隔列组成（与参考题 337b420f 结构相同）。每个面板有统一的非黑背景色（如灰(5)），以及恰好一种前景色的像素，分成 2-3 个 4-连通分量。三个面板的前景色互不相同（如蓝(1)、红(2)、绿(3)）。生成约束：每个面板内最大分量唯一（无并列）；三个面板的最大分量像素面积互不相等；至少有两个分量在叠加到 5x5 画布时的边界框存在重叠。

**规则**：
1. 在每个面板中，识别所有 4-连通前景分量，仅保留像素数最大的一个，丢弃其余分量。
2. 统计三个幸存分量各自的像素面积（像素数量）。
3. 按像素面积从小到大排序。将三个分量依次绘制到一个 5x5 的背景画布上（背景色与面板背景色相同），保持每个分量在其原面板中的局部坐标。
4. 面积最小的分量先绘制（底层），面积最大的后绘制（顶层）。后绘制的分量像素覆盖先绘制的。

**关键洞察**：叠加顺序不是面板的空间排列顺序（左中右），而是像素面积的数值顺序。在某些示例中，面积最大的分量来自中间面板或右侧面板，求解者必须通过对比多个示例、观察重叠区域的颜色来归纳出面积决定图层优先级的规则。
