## 新题 2：封闭面积参数化锯齿平铺

**组合逻辑**：[计数·封闭背景区域](已有) → [旋转·对角锯齿排布·交替旋转换色](创新：矩形条的宽高不是直接给出，而是由两个封闭形状的内部面积隐式编码)

**来源原语**：计数·封闭背景区域(8ba14f53)，平铺·旋转·对角锯齿排布·交替旋转换色(fd4b2b02)

**依赖链**：两个封闭形状各自包围的黑像素数 → 分别编码矩形条的宽度和高度 → 矩形条的几何参数决定了整个锯齿平铺的周期和形态 → 形状的空间位置同时决定锯齿种子的放置坐标

输入中两个封闭前景形状各自包围不同数量的黑像素，这两个面积值分别编码一个矩形条的宽和高，以该条为种子在全网格上生成交替旋转换色的对角锯齿平铺。

**输入结构**：约 20x20 网格，黑(0)背景。包含两个 4-连通单色前景对象：一个绿(3)，一个品红(6)。两个对象互不接触，分别位于网格左半区和右半区。每个对象是封闭形状（形成闭合边界，内部包围若干黑像素），像素数约 10-20，封闭的黑像素数在 2-5 之间。生成约束：两个对象的封闭面积不相等；封闭面积值使得生成的矩形条为非正方形。

**规则**：
1. 对每个前景对象，计算其边界框内、不与边界框边缘通过黑像素 4-连通的黑像素数量（封闭面积）。
2. 左侧对象（边界框左边缘 x 坐标较小者）的封闭面积为矩形条宽度 W，右侧对象的封闭面积为矩形条高度 H。
3. 擦除两个原始对象。以左侧对象边界框的左上角为种子位置，放置一个 H 行 x W 列的绿(3)矩形条。
4. 沿两条 45 度对角线方向，以行偏移 (H+W)、列偏移 (H+W) 为周期重复放置绿(3)条的拷贝。在同一对角线上相邻两个绿条之间，放置一个 90 度旋转后的 W 行 x H 列品红(6)矩形条。
5. 在另一条 45 度对角线方向上同样生成交替排列。超出网格边界的部分裁剪丢弃。

**关键洞察**：输入形状的拓扑属性（封闭面积）隐式编码了输出几何图案的参数。求解者无法从形状的外轮廓直接读出矩形条的尺寸，必须先计算孔洞面积，再用该值构造周期性平铺。
