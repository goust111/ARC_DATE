## 新题 6：边框色驱动的区域内扫描线填充

**组合逻辑**：[填充(fill)/逐行扫描(row_scan)](已有) + [裁剪(crop)/完整边框检测(complete_border_check)](已有) → [框定区域内局部扫描线填充，填充色由框色决定](创新：同一种轮廓图案在不同框内产生不同颜色的填充结果)

**来源原语**：填充/轮廓像素/跨度/逐行扫描/填充轮廓间区域 ← aa18de87；裁剪/矩形框/内部区域/边框包围内容/完整边框检测 ← 1a6449f1

**依赖链**：检测完整矩形边框 → 在每个框的严格内部独立执行扫描线填充 → 填充色取决于边框颜色 → 嵌套框需要从内向外处理。边框检测确定了填充区域的边界和颜色，填充操作依赖于边框属性，二者不可分离。

在不同颜色的矩形边框内部，对相同的对角线轮廓图案执行扫描线填充，填充颜色随边框颜色而异。

**输入结构**：约 20x20 网格，背景灰(5)。2~3 个完整的 1 像素厚矩形边框，颜色各不相同（如蓝(1)、红(2)、绿(3)）。每个框的严格内部以灰(5)色为底，包含若干黑(0)色像素形成对角线轮廓笔画（从左上到右下或从右上到左下的斜线段）。各框内的轮廓图案可以不同（不同的斜线组合）。框之间不重叠，不嵌套。生成约束：每个框内的每一行至少有 0 或 2 个以上的黑色轮廓像素（保证扫描线有成对的端点或该行不需要填充）。

**规则**：
1. 检测所有完整的同色矩形边框（边框的四条边完整无缺）。
2. 对每个边框，取其严格内部区域（去除边框本身的像素）。
3. 在该内部区域内逐行扫描：在每行中，从左到右找到所有黑(0)色轮廓像素。对每对相邻的轮廓像素（第 1 和第 2 个、第 3 和第 4 个……），将它们之间的所有灰(5)色像素重涂为该边框的颜色。
4. 轮廓像素本身保持黑(0)色不变。
5. 不在任何边框内部的灰(5)色像素和黑(0)色像素保持不变。
6. 边框像素保持不变。

**关键洞察**：完全相同的扫描线填充算法，在蓝色边框内产生蓝色填充、在红色边框内产生红色填充。边框不仅是空间定界器，还是颜色参数的来源。这种"容器决定内容颜色"的关系是扫描线填充和边框检测两个独立概念的交叉涌现。
