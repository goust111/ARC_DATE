## 新题 7：格子连线后的交替可见性

**组合逻辑**：[连线(connect)/填充(fill)](已有) + [擦除(erase)/交替(alternating)](已有) → [格子连线 + 基于瓦片奇偶性的交替擦除](创新：连线填充完成后，沿连线路径按瓦片位置的奇偶性交替擦除，产生间断条纹效果)

**来源原语**：连线/填充/格子瓦片/端点标记/同行列对齐/同色同子格位置 ← a096bf4d；擦除/交替/中线交替打孔 ← 3bdb4ada

**依赖链**：按子格位置分组端点 → 在共享瓦片行或列的端点之间填充连线 → 沿连线路径按瓦片索引奇偶性交替擦除填充 → 起始相位由端点瓦片位置决定。连线确定了路径，交替擦除依赖路径和起始相位，起始相位依赖端点位置——三者循环依赖。

在瓦片格子中连接同色端点后，沿连线按瓦片奇偶性交替保留和擦除填充色，形成间断虚线。

**输入结构**：约 19x19 网格，由灰(5)色分隔行和分隔列划分为 4x4 阵列的瓦片。每个瓦片内部为 3x3，背景黑(0)。部分瓦片的特定子格位置（2x2 内部的四个位置之一，但此处瓦片内部为 3x3，用左上/右上/左下/右下四个角像素位置代替）有彩色端点标记。端点标记有 2~3 种颜色（如蓝(1)、红(2)、绿(3)），每种颜色恰好出现 2 个端点标记。同色的两个端点标记占据相同的子格位置（如都在瓦片内部的左上角像素），且共享同一瓦片行或同一瓦片列。生成约束：同色端点之间的瓦片路径上无其他颜色端点标记占据相同子格位置。

**规则**：
1. 按颜色和子格位置分组端点标记（每组恰好 2 个端点）。
2. 对每组，确定两端点的瓦片坐标。若共享瓦片行，连线方向为水平；若共享瓦片列，连线方向为垂直。
3. 在两端点之间的每个中间瓦片中，将对应子格位置的像素填充为该端点颜色。
4. 对连线路径上的所有瓦片（含两端点瓦片），按瓦片行主序为每个瓦片编号（从 0 开始：行号 x 列数 + 列号）。
5. 取起始端点（编号较小的瓦片）的编号奇偶性作为相位基准：若编号为偶数，偶数编号瓦片保留填充、奇数编号瓦片擦除；若编号为奇数，奇数编号瓦片保留填充、偶数编号瓦片擦除。
6. "擦除"指将该瓦片中对应子格位置的像素恢复为黑(0)色。
7. 若两条不同颜色的连线在同一瓦片的同一子格位置交叉且都需保留，该像素显示在网格中端点标记总数更多的颜色（生成约束保证不会出现相同数量的情况）。
8. 分隔线和其他未涉及的像素保持不变。

**关键洞察**：交替的相位不取决于连线本身的方向或长度，而取决于端点所在瓦片在全局阵列中的位置奇偶性。两条平行的连线如果起始瓦片的奇偶性不同，其间断模式会错开，产生需要对比多个示例才能归纳出的隐蔽规则。
