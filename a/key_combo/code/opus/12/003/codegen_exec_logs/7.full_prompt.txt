## 新题 7：面积排序后按视线间距编码的间隔拼合碎片

**组合逻辑**：[排序/sort](已有) + [拼合填充/packing](创新：碎片间距不固定为 0 或 1，而是由视线间距编码) + [射线延伸/ray_extend](创新：用于测量间距而非绘制)

**来源原语**：排序/sort（4df5b0ae）、面积排序/area_ordering（4df5b0ae）、基线对齐排列/baseline_aligned_pack（4df5b0ae）、精灵体/sprite（4df5b0ae）、拼合填充/packing（b7cb93ac）、多连块碎片/polyomino_fragment（b7cb93ac）、无重叠拼合/non_overlap_packing（b7cb93ac）、射线延伸/ray_extend（696d4842）、标记像素/marker_pixel（696d4842）、视线匹配/sightline_matching（696d4842）、间距编码尾长/gap_distance_encodes_tail_length（696d4842，创新为间距编码排列间隔）

**依赖链**：面积排序决定碎片排列顺序。视线匹配将每个标记与碎片配对。标记到碎片的间距编码该碎片左侧的空白列数。三个信息（排列位置、碎片身份、间隔宽度）分别来自三个不同的原语，缺一不可。

将散落的单色碎片按面积从小到大排列，每个碎片左侧空白列数等于其对应标记到碎片的视线间距，碎片底部对齐。

**输入结构**：约 14×14 的网格，黑(0)为背景。3~4 个单色 4-连通碎片（每个 3~8 像素，颜色各不相同，如红(2)、蓝(1)、绿(3)、黄(4)），形状不规则，散布在网格上半部分。同时有 3~4 个灰(5)单像素标记散布在网格下半部分。每个标记恰好沿垂直方向（向上）与某个碎片的最下方像素有无阻挡视线，间距 >= 0 且各不相同。生成约束：标记-碎片匹配唯一（一对一）；碎片面积互不相同；所有碎片排列后（含间隔）的总宽度不超过网格宽度。

**规则**：
1. 将每个灰(5)标记与其垂直向上视线可达的碎片配对，记录间距 S（标记与碎片最下方像素之间的背景行数，不含两端）。
2. 将所有碎片按像素面积从小到大排序。面积相同时按碎片包围盒左上角的列坐标从左到右排序。
3. 构建输出网格（高度 = 所有碎片包围盒的最大高度，宽度 = 所有碎片包围盒宽度之和 + 所有间距之和）：从左到右依次放置排好序的碎片，每个碎片底部对齐输出网格底部。碎片之间插入的空白列数 = 该碎片（非前一个碎片）对应的标记间距 S。第一个碎片（面积最小者）左侧也插入其对应标记的间距 S 列空白。
4. 每个碎片保持原色和形状（包围盒裁剪，内部背景保持黑(0)）。空白区域为黑(0)。
5. 标记像素不出现在输出中。

**关键洞察**：标记到碎片的垂直间距不是用于连线或着色——它编码了该碎片在最终排列中左侧的空白间隔。间距越大，碎片前面的留白越多。这一编码规则与面积排序规则交织：必须同时知道排列顺序和间隔宽度才能确定输出。
