## 新题 2：周期推断约束断线修复阈值

**组合逻辑**：[周期瓦片推断](已有) → [间隙阈值导出](创新：瓦片最小周期维度成为补线的最大允许间隙) → [标记替换](已有) + [补线](已有，但阈值由周期推断结果决定)

**来源原语**：周期瓦片/periodic_tile、行列周期/row_col_period、标记为缺失值/markers_missing_val（参考题12 f823c43c）；补线/line_completion、间隙长度限制/gap_length_constraint（参考题3 7b80bb43）；重涂色/recolor（多道参考题）

**依赖链**：周期推断恢复背景瓦片 → 最小周期维度生成补线阈值 → 补线操作依据该阈值决定填补哪些断口、保留哪些断口 → 跳过周期推断则既无法恢复粉色缺失值，也无法获得正确的间隙阈值

利用背景周期瓦片的最小维度周期作为断线修复的最大允许间隙，同时恢复瓦片中被标记遮蔽的缺失值。

**输入结构**：约14x14网格。背景为一个由蓝(1)和绿(3)两色构成的矩形重复瓦片图案（如交错条纹或格子，行周期P_r和列周期P_c可不相等，范围2-5）。若干红(2)水平或垂直线段叠画在瓦片上方，每条线段至少3像素长。部分红线段存在1-4像素的间隙（间隙处显示的是下层瓦片的蓝或绿色）。另有若干品红(6)像素替换了瓦片中的某些非红色位置（不出现在红线段上）。生成约束：品红像素不超过总非红像素的15%，以保证瓦片周期可推断；每条红线段的间隙不超过2个；至少有一个间隙长度恰好等于min(P_r, P_c)，至少有一个间隙长度恰好等于min(P_r, P_c)+1（确保阈值判断可被观察到）。不同示例中瓦片周期不同，从而产生不同的阈值行为。

**规则**：
1. 将红(2)和品红(6)像素视为"未知"，从剩余蓝/绿像素推断最小矩形瓦片周期（行周期P_r，列周期P_c）。
2. 计算间隙阈值 G = min(P_r, P_c)。
3. 将每个品红(6)像素替换为其网格坐标对应的瓦片颜色（蓝或绿）。
4. 对每条红线段，检测其间隙（连续非红像素段）。若间隙长度 <= G，将间隙填充为红(2)；若间隙长度 > G，保留间隙处的瓦片颜色不变。
5. 处理顺序：先恢复品红缺失值（步骤3），再判断间隙（步骤4），因为间隙像素需要正确的瓦片底色来确认它们不是红线的一部分。

**关键洞察**：瓦片周期承担双重职责——既定义背景图案的恢复规则，又隐式决定了线段修复的严格程度。周期越大允许修复的间隙越长；不同示例中周期变化导致同样长度的间隙在一个示例中被修复、在另一个示例中被保留，迫使求解者发现周期与阈值的关联。
