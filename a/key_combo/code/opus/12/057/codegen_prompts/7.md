## 新题 7：互补形状选取裁剪并由标记数决定翻转

**组合逻辑**：[互补形状匹配](已有) → [裁剪](已有，但选取标准从标记计数变为形状匹配) → [计数](已有) → [条件镜像](创新：标记计数的奇偶决定是否水平翻转裁剪结果)

**来源原语**：形状匹配/shape_match、互补形状/complementary_shape、缺口形状唯一配对/unique_complement、模板缺口/template_gap（参考题5 18447a8d）；裁剪/crop、计数/counting、标记像素/marker_pixel、包含/containment、标记最多者选取/rectangle_with_most_markers_selected（参考题6 8efcae92）；镜像/mirror（参考题8 de493100）

**依赖链**：模板缺口形状提取 → 与各矩形内部的源形状做互补匹配 → 唯一匹配者被选中裁剪 → 裁剪区域内标记计数决定是否翻转 → 形状匹配和标记计数分别控制"选哪个"和"怎么输出"

从模板缺口形状出发找到唯一互补匹配的矩形，裁剪该矩形，再根据其内部标记数的奇偶决定是否水平翻转输出。

**输入结构**：黑(0)背景网格，约18x18。左上区域有一个青(8)模板矩形（约4x4至6x6），内部缺少若干像素形成一个连通缺口（缺口为黑色，形状为3-5像素的4-连通图形）。网格其余区域散布3-4个绿(3)实心矩形（大小各异，约4x5至6x7），互不重叠，与模板矩形也不重叠。每个绿矩形内部包含一个红(2)的4-连通小图形（3-5像素，各矩形中的红图形形状互不相同），以及0-3个蓝(1)标记像素（单像素，不与红图形4-邻接）。生成约束：恰好一个绿矩形中的红图形归一化后（平移至左上角）与模板缺口形状全等；不同示例中匹配的矩形位置不同；匹配矩形中的蓝标记数在不同示例中奇偶不同。

**规则**：
1. 提取青模板中的缺口形状：模板边界框内黑色像素构成的4-连通区域，归一化为左上角起始。
2. 对每个绿矩形，提取其内部的红(2)图形，归一化为左上角起始。
3. 找到唯一的绿矩形，使其红图形归一化形状与模板缺口归一化形状完全相同——该矩形被选中。
4. 裁剪选中的绿矩形（取其完整边界框内容，包含绿底、红图形、蓝标记）。
5. 统计裁剪结果中蓝(1)标记像素的数量M。
6. 若M为奇数，将裁剪结果沿垂直中轴水平翻转（左右镜像）。若M为偶数（含0），保持裁剪结果不变。
7. 在最终输出中，将红(2)图形像素重涂为青(8)（表示该形状是模板缺口的互补）。

**关键洞察**：选择"裁剪哪个矩形"需要空间形状分析（互补匹配），而决定"输出的朝向"需要计数分析（标记奇偶）——两种完全不同类型的推理同时作用于最终结果。标记像素容易被误认为是选择标准（"选标记最多的"），但实际上它们控制的是输出方向，形成认知陷阱。
