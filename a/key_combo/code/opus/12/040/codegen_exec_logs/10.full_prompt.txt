**依赖链**：等差序列外推补全被裁切的矩形笔画 -> 补全后的嵌套笔画围合出同心环状区域 -> 将每个环状区域视为一个分区 -> 按区域面积从小到大排序 -> 从内到外依次涂色

补全等差递进的矩形笔画，由补全后的嵌套矩形围合出环状分区，按分区面积排序并依次涂上预定义颜色。

**输入结构**：约 18x18 的黑(0)背景网格。包含 2~3 个可见的同色矩形边框笔画（颜色为灰(5)，每个笔画是矩形边框的某几条边，如顶边+右边、或左边+底边+右边），每个笔画宽 1 像素。这些笔画的 bbox 按等差递增（相邻笔画的 bbox 宽度和高度各差一个固定常数 d，中心对齐）。最大的笔画部分被网格边界裁切（仅可见的像素存在）。另外，在最内层笔画围合的区域内有一个小的彩色标记像素（颜色非黑非灰，如红(2)），标记该区域。

生成约束：至少 2 个笔画完全可见（在网格内）；等差序列允许向外推 1~2 个笔画（但这些笔画因被画布裁切而部分可见或不可见）；所有笔画使用同一组边（如都是"顶边+右边"），保证形态一致。

**规则**：
1. 从可见笔画推断 bbox 的等差递增规则（中心坐标、宽高增量 d）。向两个方向（更大和更小）外推 bbox 序列，直到笔画完全超出网格边界。
2. 绘制所有推断出的笔画（包括原本因裁切而不完整的部分——只绘制在网格内的像素），颜色为灰(5)。
3. 补全后的嵌套矩形笔画将网格分为若干同心区域：最内层区域由最小笔画围合，每对相邻笔画之间围合一个环状区域，最外层笔画之外到网格边界是最外层区域。
4. 计算每个区域的像素面积（不含笔画像素本身），按面积从小到大排序。
5. 按排序顺序依次涂色：面积最小的区域涂蓝(1)，第二小涂红(2)，第三小涂绿(3)，第四小涂黄(4)，依此类推（最多用到第 7 个颜色橙(7)）。灰(5)笔画像素保持不变。
6. 输出完整网格。

**关键洞察**：可见笔画本身只是等差序列的中间几项——你必须先补全隐藏的项才能知道有多少个围合区域。补全改变了分区数量，从而改变了涂色方案。而且由于笔画是部分边框（不是完整矩形），围合区域的边界判定需要结合笔画形态和网格边界共同确定。需要对比多个示例来确认等差规则和涂色顺序。

Paint yellow the background cells on the unobstructed shortest monotone corridor between two doorway frames.

Input structure
- The grid has a background, two small frame objects in one foreground color, and one center marker in each frame.
- Each marker has exactly one background 4-neighbor, the doorway gap; the next cell outward is the exterior doorway cell.

Rule
- Treat all existing foreground cells as blockers.
- Between the two exterior doorway cells, allow only row/column steps that move toward the other exterior cell.
- Paint every background cell that lies on some such path from one exterior cell to the other, plus the two doorway gaps, yellow.

Key insight
- The output is not a single chosen route: it is the union of all shortest monotone paths that can pass between the two frames.
