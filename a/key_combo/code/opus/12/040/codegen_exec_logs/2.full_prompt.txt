## 新题 2：路径可达性筛选锚点叠加

**组合逻辑**：[路径追踪](已有，创新：路径可达性作为筛选条件) + [透明叠加+锚点对齐](已有，创新：仅叠加被路径选中的精灵) + [裁剪](已有)

**来源原语**：路径追踪+引导像素+路径连接+终点相邻（来自 9ba4a9aa）；透明叠加+锚点像素+锚点对齐+锚点重合叠加（来自 137eaa0f）；裁剪（来自 67636eac/137eaa0f）

**依赖链**：引导像素路径从源点出发连接到部分精灵 -> 只有路径可达的精灵参与叠加 -> 可达精灵通过锚点像素对齐叠加 -> 裁剪叠加结果

追踪引导像素路径，筛选出路径可达的精灵体，将它们按灰色锚点对齐叠加后裁剪输出。

**输入结构**：约 20x20 的黑(0)背景网格。包含 4~6 个互不相邻的多色精灵体，每个精灵占约 3x3 到 5x5 区域，由一种独有前景色加恰好一个灰(5)锚点像素构成（如精灵 A 是蓝(1)+灰(5)，精灵 B 是红(2)+灰(5)等，每个精灵的主色互不相同）。网格的某一条边（如左边缘）上有一个橙(7)源像素。从源像素出发，有一条由橙(7)像素构成的路径，路径像素两两之间曼哈顿距离为 2（即每隔一个格子放一个橙像素，形成疏松的水平/垂直路径），路径分叉或转向后终止于某些精灵的邻近位置（路径末端像素与精灵 bbox 边缘 4-相邻）。路径仅连接到部分精灵（2~4 个），其余精灵无路径到达。生成约束：路径不穿越任何精灵的 bbox；路径的每一段沿水平或垂直方向延伸；被路径连接的精灵数量至少为 2。

**规则**：
1. 从橙(7)源像素出发，沿橙(7)引导像素追踪路径（每步在水平或垂直方向跳 2 格寻找下一个橙像素）。记录路径到达的所有精灵（路径末端像素与精灵 bbox 4-相邻）。
2. 忽略所有未被路径到达的精灵。
3. 将每个被选中的精灵裁剪为其 bbox 大小的小图。
4. 将所有被选中精灵的小图叠加：以每个精灵的灰(5)锚点像素为对齐点，将所有小图放置在同一坐标系中，使锚点重合。叠加时，非黑像素覆盖黑像素；若多个精灵在同一位置都有非黑像素，则按精灵被路径到达的先后顺序（路径追踪中先到达的精灵在下层，后到达的在上层），后层覆盖前层。
5. 裁剪叠加结果到包含所有非黑像素的最小 bbox，输出该裁剪图。丢弃所有路径像素和未选中精灵。

**关键洞察**：路径追踪不是为了找到一个目标对象，而是为了筛选哪些精灵参与后续的锚点叠加。路径的拓扑结构（连接了哪些精灵）直接决定了叠加的合成图案，改变路径连接就会改变输出。需要对比多个示例才能确认未连接的精灵被排除而非以某种默认方式参与。
