## 新题 4：线段排序确定模板旋转角度

**组合逻辑**：[排序+最高行决定序](已有，创新：排序位次编码旋转角度) + [旋转](已有，创新：旋转角度由外部排序结果参数化) + [像素放大+印章覆盖](已有，创新：放大后印章到排序对应位置)

**来源原语**：排序+线段对象+顺序排列+最高行决定序（来自 668eec9a）；旋转+像素放大+多色模板（来自 103eff5b）；印章覆盖+位置对应（来自 20fb2937）

**依赖链**：线段对象按最高行排序得到颜色序列 -> 序列中的位次决定旋转角度 -> 多色模板按该角度旋转 -> 旋转后的模板放大 2 倍印章到对应输出行

将线段对象按其最高行排序，排序位次决定小模板的旋转角度，将旋转并放大后的模板按序纵向排列输出。

**输入结构**：约 15x15 的黑(0)背景网格，包含两类元素：
- 线段对象：3~4 条不同颜色的 4-连通单色线段（每条 1 像素宽，长 2~5 像素，可为水平、垂直或对角方向），颜色互不相同（如蓝(1)、红(2)、绿(3)），分布在网格各处，彼此不接触。每条线段所占的最高行（行号最小的行）互不相同。
- 多色模板：一个位于网格角落的 2x2 小方块，四个像素各有不同颜色（如左上黄(4)、右上橙(7)、左下青(8)、右下栗(9)），与线段颜色均不同。

生成约束：线段数量 N 在 3~4 之间；模板固定为 2x2 且四色互不相同；线段的最高行互不相同以保证排序唯一。

**规则**：
1. 提取所有线段对象，记录每条线段的颜色和其占据的最高行（行号最小）。
2. 按最高行从小到大排序线段颜色，得到一个长度为 N 的有序颜色列表。列表中位次从 0 开始编号。
3. 提取 2x2 多色模板。
4. 对每个位次 k（0, 1, ..., N-1），将模板顺时针旋转 k x 90 度（位次 0 不旋转，位次 1 旋转 90 度，位次 2 旋转 180 度，位次 3 旋转 270 度）。
5. 将每个旋转后的 2x2 模板像素放大 2 倍（变为 4x4）。
6. 构建输出：宽 4 像素，高 4xN 像素。从上到下，按位次 0 到 N-1 依次纵向排列 N 个 4x4 放大模板。相邻模板之间无间隔。

**关键洞察**：线段本身的形状和长度无关紧要，只有它们的垂直位置顺序有意义——排序位次直接编码了旋转角度。需要对比多个示例（线段位置不同导致旋转顺序不同）才能区分"按位次旋转"与"按颜色编号旋转"或"固定旋转"等假设。
