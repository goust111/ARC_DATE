## 新题 9：裂缝分割后对角邻接重组与颜色互换

**组合逻辑**：[擦除+滑动+沿短轴分裂](已有，创新：分裂后不是平行分离而是对角重组) + [对角邻接拼合+颜色互换](已有，创新：颜色互换发生在分裂重组之后的特定半区) + [镜像](已有，创新：镜像轴由分裂方向决定)

**来源原语**：擦除+滑动+裂缝标记线+沿短轴分裂+两侧等距分离（来自 2faf500b）；分割+对角邻接拼合+颜色互换且偏移+双色物体（来自 fc4aaf52）；镜像（来自 9f236235）

**依赖链**：裂缝线擦除并分裂物体为两半 -> 其中一半左右镜像 -> 镜像后的半区与另一半对角邻接拼合 -> 拼合后对两半区的颜色执行互换

擦除裂缝线分裂物体，将一半镜像后与另一半对角拼合，再对两半执行颜色互换。

**输入结构**：约 14x14 的黑(0)背景网格，包含 1~2 个互不相邻的双色 4-连通物体。每个物体由两种非黑前景色构成（如蓝(1)和红(2)混合），像素数约 10~24，bbox 为非正方形矩形。每个物体内有一条橙(7)裂缝标记线，宽 1 像素，沿 bbox 较短轴方向完整穿过物体（将物体分为两半）。

生成约束：裂缝将物体分为的两半在像素结构上不对称（镜像后形状会变化）；两半中蓝(1)和红(2)均存在；物体的 bbox 足够大，使得对角拼合后不会超出网格边界。

**规则**：
1. 对每个物体，擦除其橙(7)裂缝标记线（设为黑(0)），将物体分为两个 4-连通的半区 A 和 B。约定 A 为上半区（水平裂缝时）或左半区（垂直裂缝时），B 为另一半。
2. 将半区 B 沿裂缝方向做镜像翻转：若裂缝为水平线，则 B 做上下镜像；若裂缝为垂直线，则 B 做左右镜像。镜像以 B 自身的 bbox 中心为轴。
3. 保持 A 在原位不动。将镜像后的 B 平移，使 B 的 bbox 左上角位于 A 的 bbox 右下角的对角相邻位置（即 B 左上角 = A 右下角 + (1, 1)）。
4. 在 A 和 B 中执行颜色互换：A 中所有蓝(1)变红(2)、红(2)变蓝(1)；B 中同样互换。
5. 输出结果网格。未被物体覆盖的位置保持黑(0)。

**关键洞察**：裂缝不只是切割线——它同时决定了镜像的轴向（水平裂缝导致上下镜像，垂直裂缝导致左右镜像）。镜像改变了半区的形状，使得对角拼合产生新的整体轮廓，而颜色互换在拼合后进行，进一步掩盖了原始物体的外观。需要对比多个示例（水平裂缝 vs 垂直裂缝）才能确认镜像轴与裂缝方向的关系。

## 实现要求

1. `main(grid)` 必须实现新题描述中的确定性转换规则，不能只识别 `generate_input()` 的固定模板。禁止不同的input网格输出相同的output网格。
2. `generate_input()` 必须随机生成多样样例，不能固定死。随机维度应覆盖：网格大小、对象数量、位置、颜色、方向、形状参数或关键分支。注意若描述中存在若干，需实现而不是只有单个，包括object或者对应关系等等。且若涉及到最短路径，则输入网格中必涉及到多条路径，对选择造成干扰。
3. 生成器必须保证输入满足 `main()` 的隐式假设：对象不重叠、不越界、特殊标记唯一或可区分、匹配关系无歧义、关键分支出现概率相同。
4. 禁止把 ARC 颜色 id 、亮度、拼写等当作人类不可见的数值语义参与排序、大小比较或隐藏映射。颜色变化必须有可见结构线索。注意颜色亮度、拼写等也是不可见信息，若描述中出现违规的颜色id或者亮度，可自行使用少量的固定颜色替代，但注意生成时要在三个以内输入输出网格中对所有变换100%覆盖度。
5. 输出样例要视觉清晰，人类必须能从输入输出对中肉眼辨认出规律。具体要求：避免对象粘连、覆盖关系混乱、同一像素多重语义；不同逻辑步骤产生的结果不要大面积层叠在一起导致无法分辨哪个颜色属于哪个步骤；输入中各元素之间保持足够间距，输出中新增的标记/填充/路径等应与背景和已有元素在颜色上有明显区分；若规则涉及多层叠加，生成时控制对象密度和尺寸，确保叠加区域只占少数像素而非铺满整个网格。
6. 若规则有多个分支，生成器不能长期固定成一个分支；应让分支在随机样例中合理出现。分支概率不必平均——难以发现的隐蔽分支（如少数情况下才触发的特殊规则）应适当提高出现概率，确保在 3 个训练示例中至少出现一次，否则求解者无法归纳该规则。对于颜色映射类规则，确保 2 个左右的示例即可覆盖所有映射关系（每种颜色→颜色的映射至少在某个示例中出现过）。
