## 新题 7：角标色选定重涂目标与交替位跳选

**组合逻辑**：[裁剪(crop) + 角标记像素(corner_marker)](已有) → [角标色决定重涂(corner_color_sets_recolor)](已有) + [交替选取(alternating_selection) + 奇偶位决定涂色(parity_position_recolor)](创新：角标色仅作用于交替位置上的像素)

**来源原语**：
- 裁剪(crop)、角标记像素(corner_marker)、边框(frame)、中心图案(central_pattern)、角标色决定重涂(corner_color_sets_recolor)、内部包含(containment) ← 3de23699
- 交替选取(alternating_selection)、奇偶位决定涂色(parity_position_recolor)、前景像素序列(foreground_sequence) ← d406998b
- 重涂色(recolor) ← 多题共有

**依赖链**：角标记像素的颜色决定重涂目标色，但重涂不作用于全部前景像素——只作用于沿扫描序列的交替位置（奇数位）。偶数位像素保持原色。角标色提供"涂什么颜色"，交替选取提供"涂哪些像素"，二者缺一不可。

提取边框内的中心图案，按逐行扫描序列对前景像素编号，奇数位重涂为角标色，偶数位保持原色。

**输入结构**：
- 约 12×12 的网格，背景色为黑(0)。
- 网格中央有一个由前景色 A（如蓝(1)）构成的不规则图案（4-连通，6~15 像素），被一层 1 像素宽的前景色 B（如绿(3)）边框完整包围（边框为该图案包围盒向外扩展 1 像素的矩形环）。边框的四个角上各有一个前景色 C（如红(2)）的角标记像素（取代该位置的边框像素 B）。
- 角标色 C、边框色 B、图案色 A 三者互不相同且均非背景色。
- 图案不接触边框（图案像素与边框像素之间有至少 1 像素的背景间隔，或图案像素不位于边框内侧紧邻位置——即图案位于边框内部但不紧贴边框）。
- 生成约束：图案的前景像素数 >= 4，以确保交替选取有意义。不同示例中图案形状不同。

**规则**：
1. 找到四个角标记像素（颜色 C），确定角标色。
2. 裁剪到所有非背景像素的包围盒，然后移除最外一层像素（即边框层，包括角标记像素和边框像素），得到中心区域（仅包含颜色 A 的前景像素和黑(0) 背景像素）。
3. 对中心区域中的前景像素（颜色 A）按逐行扫描顺序（从上到下逐行、每行从左到右）编号为 1, 2, 3, ...。
4. 奇数编号（1, 3, 5, ...）的前景像素重涂为角标色 C；偶数编号（2, 4, 6, ...）的前景像素保持原色 A。
5. 输出裁剪后的中心区域（含背景像素和重涂/保持后的前景像素）。

**关键洞察**：角标色不再是"全部重涂"的信号（区别于参考题 3de23699），而是与逐行扫描序列的奇偶性交织——求解者必须同时推断角标色的含义和交替选取规则，仅看一个示例无法区分"全部重涂"和"交替重涂"。
