## 新题 8：蛇形路径跨越分隔线后的分段交替着色

**组合逻辑**：[蛇形路径(snake_path) + 遍历顺序(traversal_order)](已有) + [分隔线(separator_line)](已有，创新：分隔线不用于计数而用于路径分段) → [交替选取(alternating_selection) + 重涂色(recolor)](创新：段级而非像素级的交替) → [展直(straighten)](已有)

**来源原语**：
- 蛇形路径(snake_path)、端点(endpoint)、遍历顺序(traversal_order)、展直(straighten)、保留像素序(preserve_pixel_order) ← 7b5033c1
- 分隔线(separator_line) ← 7039b2d7
- 交替选取(alternating_selection)、奇偶位决定涂色(parity_position_recolor) ← d406998b
- 重涂色(recolor) ← 多题共有

**依赖链**：分隔线将蛇形路径切割为若干段，段的编号按遍历顺序从起点端依次递增。奇数段和偶数段交替重涂为不同颜色。最终将路径展直为单列，保持遍历顺序。分隔线决定分段边界，遍历顺序决定段编号，奇偶性决定颜色——三个原语层层嵌套。

蛇形路径被分隔线切割为若干段，沿遍历方向对段交替着色后展直输出为单列。

**输入结构**：
- 约 15×15 的网格，背景色为黑(0)。
- 灰(5) 像素构成 1~3 条完整的水平或垂直分隔线（贯穿网格全宽或全高，1 像素宽）。分隔线之间互不交叉。
- 一条由绿(3) 像素组成的蛇形路径（4-连通简单链，无分叉，恰好 2 个端点）在网格中蜿蜒。路径穿越分隔线时，穿越点处的像素为绿(3)（覆盖灰色分隔线像素位置）。路径至少穿越每条分隔线一次。
- 路径总像素数 >= 8。路径穿越分隔线的总次数 >= 2（即路径被切为至少 3 段）。
- 生成约束：路径不沿分隔线方向行走（路径穿越分隔线时是垂直穿过，即路径从分隔线的一侧直接穿到另一侧，穿越处前后各至少有 1 个路径像素不在分隔线上）。

**规则**：
1. 找到蛇形路径的两个端点，选择行号较小的端点作为起点（行号相同则选列号较小的）。
2. 从起点沿路径遍历。每当路径像素从分隔线的一侧穿越到另一侧时（即当前像素和前一个像素分属分隔线的两侧，或当前像素恰好位于分隔线上），视为进入新的一段。将路径分为段 1, 段 2, 段 3, ...（段 1 从起点开始到第一次穿越分隔线之前的最后一个像素，穿越分隔线处的路径像素归入穿越后的新段作为该段的第一个像素）。
3. 对奇数编号段（段 1, 段 3, ...）的所有像素重涂为红(2)；偶数编号段（段 2, 段 4, ...）的所有像素重涂为蓝(1)。
4. 将重涂后的路径展直为 N×1 的单列（N = 路径像素总数），按遍历顺序从上到下逐行排列每个像素的颜色。
5. 输出仅包含路径像素的颜色序列，不包含分隔线或背景。

**关键洞察**：分隔线在参考题中用于计数分区以决定输出网格尺寸，但在此题中它们切割蛇形路径形成一维分段，段的奇偶性才是着色依据——分隔线的功能从"空间分区的计数信号"变为"一维序列的分段标记"，彻底改变了其原语角色。

## 实现要求

1. `main(grid)` 必须实现新题描述中的确定性转换规则，不能只识别 `generate_input()` 的固定模板。禁止不同的input网格输出相同的output网格。
2. `generate_input()` 必须随机生成多样样例，不能固定死。随机维度应覆盖：网格大小、对象数量、位置、颜色、方向、形状参数或关键分支。注意若描述中存在若干，需实现而不是只有单个，包括object或者对应关系等等。且若涉及到最短路径，则输入网格中必涉及到多条路径，对选择造成干扰。
3. 生成器必须保证输入满足 `main()` 的隐式假设：对象不重叠、不越界、特殊标记唯一或可区分、匹配关系无歧义、关键分支出现概率相同。
4. 禁止把 ARC 颜色 id 、亮度、拼写等当作人类不可见的数值语义参与排序、大小比较或隐藏映射。颜色变化必须有可见结构线索。注意颜色亮度、拼写等也是不可见信息，若描述中出现违规的颜色id或者亮度，可自行使用少量的固定颜色替代，但注意生成时要在三个以内输入输出网格中对所有变换100%覆盖度。
5. 输出样例要视觉清晰，人类必须能从输入输出对中肉眼辨认出规律。具体要求：避免对象粘连、覆盖关系混乱、同一像素多重语义；不同逻辑步骤产生的结果不要大面积层叠在一起导致无法分辨哪个颜色属于哪个步骤；输入中各元素之间保持足够间距，输出中新增的标记/填充/路径等应与背景和已有元素在颜色上有明显区分；若规则涉及多层叠加，生成时控制对象密度和尺寸，确保叠加区域只占少数像素而非铺满整个网格。
6. 若规则有多个分支，生成器不能长期固定成一个分支；应让分支在随机样例中合理出现。分支概率不必平均——难以发现的隐蔽分支（如少数情况下才触发的特殊规则）应适当提高出现概率，确保在 3 个训练示例中至少出现一次，否则求解者无法归纳该规则。对于颜色映射类规则，确保 2 个左右的示例即可覆盖所有映射关系（每种颜色→颜色的映射至少在某个示例中出现过）。
