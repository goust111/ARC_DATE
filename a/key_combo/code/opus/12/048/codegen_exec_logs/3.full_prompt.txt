## 新题 3：孔洞拓扑路由压缩方向

**组合逻辑**：[计数(count) + 封闭区域(enclosed_region)](已有) → [边缘标记(edge_marker) → 标记定压缩方向(marker_sets_dir)](创新：孔洞数选择标记从而选择方向) → [压缩(compact)](已有) + [擦除(erase) + 忽略干扰项(ignore_distractors)](已有)

**来源原语**：
- 封闭区域(enclosed_region)、孔洞数映射颜色(hole_count_to_color_mapping)、忽略干扰项(ignore_distractors) ← e3721c99
- 压缩(compact)、边缘标记(edge_marker)、标记定压缩方向(marker_sets_dir) ← 5e6bbc0b
- 计数(count) ← 7039b2d7
- 擦除(erase) ← 91714a58

**依赖链**：边缘标记的位置定义了"方向词典"（哪个边 = 哪个方向序号）；灰色精灵体的孔洞数量在词典中查找对应的方向；精灵体沿该方向压缩至网格边缘。孔洞数超出词典条目数的精灵体被视为干扰项并擦除。拓扑属性（孔洞数）到空间操作（压缩方向）的映射是本题核心，二者缺一不可。

根据灰色精灵体的孔洞数量，从边缘标记定义的方向词典中查找对应方向，将精灵体整体平移至该方向的网格边缘；孔洞数无匹配的精灵体被擦除。

**输入结构**：
- 约 18×18 的网格，背景色为黑(0)。
- 网格的 2~4 条边上各有一个单像素的彩色标记（如左边缘有红(2)、上边缘有蓝(1)、右边缘有绿(3)），颜色互不相同，不在角落位置。这些标记从左边缘开始顺时针编号为 1, 2, 3, ...（即若标记分布在左、上、右三边，则左=1, 上=2, 右=3）。
- 网格内部散布 3~5 个灰(5) 精灵体（4-连通单色连通分量，每个 5~15 像素，形状不规则）。每个精灵体内部可能包含 0~4 个封闭孔洞（孔洞 = 被精灵体像素完全包围的黑(0) 背景连通区域，使用 4-连通判定）。
- 不同精灵体的孔洞数可能相同或不同。
- 生成约束：至少有 1 个精灵体的孔洞数为 0 或超出边缘标记数量（作为干扰项），至少有 2 个精灵体的孔洞数在 1 到标记数量之间（有有效匹配）。各精灵体互不接触。多个精灵体移向同一边缘时，它们在平行于边缘方向上的投影互不重叠。

**规则**：
1. 识别所有边缘标记像素并按从左边缘开始顺时针排列，依次编号 1, 2, 3, ...。每个编号对应一个方向：编号 k 的标记所在边缘就是方向 k 的目标边缘（左/上/右/下）。
2. 对每个灰(5) 精灵体，计数其封闭孔洞数 h（4-连通黑(0) 背景区域被该精灵体的像素完全包围）。
3. 若 h 在 1 到标记总数之间（含），将该精灵体整体平移至编号 h 对应的网格边缘。平移方式：保持精灵体在平行于目标边缘方向上的坐标不变，在垂直于目标边缘的方向上移至紧贴该边缘（精灵体最外像素位于边缘行或边缘列）。多个精灵体移向同一边缘时，按它们到该边缘的原始距离从近到远依次堆叠（先到的紧贴边缘，后到的紧贴前一个精灵体）。
4. 若 h = 0 或 h 超出标记总数，擦除该精灵体（像素改为背景色）。
5. 边缘标记像素保持不变。

**关键洞察**：精灵体的去向不是由其颜色或位置决定，而是由其拓扑属性（孔洞数量）在边缘标记定义的方向词典中查表得到的——这是拓扑到空间操作的跨域映射，仅看单个示例无法确定映射规则。
