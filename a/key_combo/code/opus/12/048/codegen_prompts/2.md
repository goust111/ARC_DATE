## 新题 2：噪声像素计数编码嵌套目标

**组合逻辑**：[擦除(erase) + 仅保留最大矩形(only_largest_rectangle_retained)](已有) → [计数(count)](创新：噪声像素数而非矩形面积作为匹配键) → [嵌套(dock) + 面积匹配(area_matching)](已有，但匹配键改为噪声数)

**来源原语**：
- 擦除(erase)、实心矩形(solid_rectangle)、噪声像素(noise_pixel)、仅保留最大矩形(only_largest_rectangle_retained)、面积比较(area_comparison) ← 91714a58
- 嵌套(dock)、边框框架(border_frame)、空腔(cavity)、面积匹配(area_matching) ← a25697e4
- 计数(count) ← 7039b2d7

**依赖链**：对每种前景色，找到最大实心矩形并分离出噪声像素。噪声像素的数量（而非矩形面积）作为与边框空腔的匹配键。矩形被嵌套进匹配的空腔中。噪声在提取矩形时被丢弃，但其数量信息编码了嵌套目标——噪声不是冗余信息，而是隐式编码。

从噪声混杂的色块中提取最大实心矩形，用噪声像素数量匹配边框空腔的面积，将矩形嵌入对应空腔。

**输入结构**：
- 约 20×20 的网格，背景色为黑(0)。
- 2~3 个灰(5) 边框框架紧贴网格边界，每个框架内部有一个矩形空腔（全为黑(0) 背景），空腔面积互不相同（如 4、6、9 等）。框架之间互不重叠。
- 网格内部（不与边框重叠的区域）有 2~3 种非背景、非灰色的前景色（如红(2)、蓝(1)、绿(3)）。每种前景色的像素分布为：一个实心矩形（面积 >= 4，高宽均 >= 2）加上若干散落的同色噪声像素（不与该矩形 4-连通相邻）。
- 关键约束：每种前景色的噪声像素数量恰好等于某一个空腔的面积，且不同前景色的噪声数量互不相同，与空腔面积形成一一对应。每种前景色的矩形尺寸可以放入其匹配空腔中（矩形的宽 <= 空腔的宽、矩形的高 <= 空腔的高）。
- 前景色的数量等于边框框架的数量。

**规则**：
1. 对每种非背景、非灰色的前景色，找到其最大实心矩形（面积最大、高宽均 >= 2 的轴对齐矩形）。该颜色的其余像素为噪声，计数噪声像素数量 N。
2. 将噪声数量 N 与各空腔面积匹配：噪声数 = 空腔面积的配对。
3. 将该颜色的实心矩形放入匹配的空腔中，左上角对齐空腔的左上角。矩形保持原色。空腔中未被矩形覆盖的像素保持背景色。
4. 擦除所有噪声像素（改为背景色）。原矩形位置也改为背景色（矩形已移入空腔）。保留所有灰(5) 边框像素。

**关键洞察**：噪声像素通常被视为需要清除的干扰，但在此题中，噪声的数量本身就是将矩形路由到正确空腔的编码信号——丢弃噪声前必须先计数。
