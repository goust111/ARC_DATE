## 新题 4：射线长度编码碎片平移量

**组合逻辑**：[射线延伸(ray_extension) + 遇障碍截断(truncate_at_blocker)](已有) → [计数(count)](创新：射线长度作为平移参数) → [移动(move) + 互补拼合(complement_fit)](已有，但平移量由射线决定)

**来源原语**：
- 射线延伸(ray_extension)、障碍像素(blocker_pixel)、遇障碍截断(truncate_at_blocker)、实心正方形(solid_square) ← 212895b5
- 移动(move)、碎片(fragment)、互补拼合(complement_fit)、同色碎片拼成矩形(same_color_join) ← fe45cba4
- 计数(count) ← 7039b2d7

**依赖链**：实心正方形向四个正方向延伸射线，障碍像素截断射线。每条射线的长度（不含正方形自身像素）编码了该方向上碎片对的平移距离。碎片按该距离移动后与其锚定碎片互补拼合成矩形。射线结构、障碍位置、碎片形状三者紧密耦合：改变任一障碍的位置都会改变某对碎片的拼合位置。

从实心正方形向上下左右延伸射线至障碍截断，每条射线的长度决定该方向上一对碎片的平移距离，移动碎片后与锚定碎片互补拼合成完整矩形。

**输入结构**：
- 约 20×20 的网格，背景色为黑(0)。
- 网格中心附近有一个灰(5) 实心 3×3 正方形。
- 黄(4) 像素作为障碍散布在正方形的上、下、左、右四个正方向上（每个方向恰好 1 个障碍像素，与正方形同行或同列），距离正方形的距离各不相同（2~6 像素）。
- 网格的四个象限（以正方形中心为原点划分）中，每个象限包含恰好一对同色碎片（4 对共用 4 种不同颜色：红(2)、蓝(1)、绿(3)、橙(7)）。每对碎片中，一个是锚定碎片（距正方形较近），另一个是可移动碎片（距正方形较远）。两个碎片的形状互补——将可移动碎片沿特定方向平移到正确位置后，二者的并集恰好构成一个实心矩形（面积 4~9 像素）。
- 象限与射线方向的对应：右侧象限（正方形右方）对应向右射线，下方象限对应向下射线，左侧象限对应向左射线，上方象限对应向上射线。
- 生成约束：每条射线长度（从正方形边到障碍之间的空白像素数）等于对应象限内可移动碎片到其锚定碎片的所需平移像素数（沿射线方向的分量）。碎片在垂直于射线的方向上已经对齐，只需沿射线方向平移。各碎片对互不干涉。

**规则**：
1. 从灰(5) 正方形的每条边的中心像素出发，沿正方向（上/下/左/右）逐像素延伸，遇到黄(4) 障碍像素时停止（不含障碍本身也不含正方形边缘像素）。记录每条射线的长度 L（中间空白像素数）。
2. 对每个象限，找到该象限中的碎片对（同色的两个 4-连通分量）。识别可移动碎片（包围盒中心离正方形中心更远的那个）和锚定碎片（包围盒中心离正方形中心更近的那个）。
3. 将可移动碎片沿对应射线方向（朝向正方形的方向）平移 L 个像素（L 为该象限对应射线的长度），使其与锚定碎片互补拼合为实心矩形。
4. 擦除可移动碎片的原始位置（改为背景色）。灰(5) 正方形和黄(4) 障碍像素保持不变。射线本身不绘制在输出中。

**关键洞察**：障碍像素不仅截断射线，更隐式编码了碎片的精确平移距离——射线的几何结构和碎片的空间关系之间存在跨区域的参数级耦合，求解者需要对比多个示例才能发现这一数值对应关系。
