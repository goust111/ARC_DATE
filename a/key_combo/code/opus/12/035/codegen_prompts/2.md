## 新题 2：重力沉降入格栅分区变色

**组合逻辑**：[滑动/重力沉降(gravity_settling)] + [分区涂色(zone_coloring)/按边界框内外分色(color_by_bounding_box_membership)] → 耦合点：沉降的落点位置决定像素变色规则，落点依赖于格栅的几何布局

**来源原语**：滑动/重力沉降/前景像素/基线行(3618c87e)、间隙填充/分区涂色/块阵列/网格沟槽/边界框/内部与外部沟槽(137f0df0)

**依赖链**：重力沉降确定每个像素的终点坐标，分区涂色根据终点是否在块阵列边界框内部决定像素的输出颜色。二者通过"落点坐标"这一中间量紧耦合——不执行重力沉降则不知落点在哪个区、不知分区规则则沉降后颜色不确定。

将悬浮的彩色像素沿列下沉至格栅沟槽中，根据落点属于格栅内部沟槽还是外部延伸沟槽来决定像素的最终颜色。

**输入结构**：
- 黑(0)背景网格，约 15x20（15列20行）。
- 网格下半部分（约第 10~18 行）包含灰(5) 2x2 块组成的矩形格栅阵列，块间以 1 像素宽的黑色沟槽分隔。格栅的块阵列边界框不覆盖整个网格宽度——左右各留 2~3 列的外延沟槽区。
- 网格上半部分（第 0~8 行）散布 4~6 个橙(7)单像素，每个橙像素所在列恰好对应某条垂直沟槽的列坐标（即该列在格栅区域内是沟槽，不会被块占据）。不同像素位于不同列。
- 生成约束：每个橙像素的正下方列路径上无灰块阻挡（橙像素对齐沟槽列），保证每个像素都能沉降到格栅底部或网格底部。

**规则**：
1. 每个橙(7)像素沿其所在列向下移动，直到到达该列最低的空背景格（即该列中最靠底部的黑(0)格），遵循重力沉降规则。
2. 确定落点坐标后，判断该坐标是否在灰块阵列的边界框内部（边界框 = 所有灰块的最小外接矩形）：
   - 若落点在边界框**内部**的沟槽格：将该像素涂为红(2)。
   - 若落点在边界框**外部**的沟槽延伸格（与沟槽同行或同列，但列坐标超出边界框左右范围）：将该像素涂为蓝(1)。
   - 若落点在格栅区域的上方（即该列沟槽上方的空白区，像素因无更低空格而停留在格栅上方）：保持橙(7)不变。
3. 灰块保持不变，其余背景像素保持黑(0)。
4. 各像素独立沉降，互不干扰（生成约束保证不同像素在不同列）。

**关键洞察**：同为橙色的像素在沉降后变成不同颜色，其最终颜色完全取决于落点所在列是否在块阵列边界框内——这是一个仅通过多个示例对比（观察不同列的落点颜色差异）才能归纳出的隐蔽规则。
