## 新题 5：滑动压缩与计数决定镜像轴

**组合逻辑**：[完整方块过滤/忽略干扰项](已有原语) → [滑动/压缩到标记旁](已有原语) → [计数](创新：对齐到不同标记的有效对象数决定镜像轴) → [镜像](创新：轴类型由计数结果动态选择)

**来源原语**：滑动/压缩到标记旁/行列对齐(ae3edfdc), 完整方块过滤/忽略干扰项(3b4c2228), 计数(3b4c2228), 镜像(7468f01a/74dd1130), 标记像素(ae3edfdc), 擦除(ae3edfdc)

**依赖链**：过滤决定哪些对象参与滑动，滑动结果改变空间布局，滑动后每个标记旁的有效对象计数决定镜像轴的选择。镜像轴不是固定的——它是过滤和计数的下游产物。干扰项如果未被正确过滤，会改变计数结果，从而选择错误的镜像轴，导致输出完全不同。

过滤出有效方块后滑动到对齐标记旁，根据各标记吸引到的方块数量选择镜像轴，最后对整个画面执行镜像。

**输入结构**：约 12x12 的网格，黑(0)为背景。网格中有 2 个单像素标记：一个红(2)标记和一个蓝(1)标记，二者不共享任何行或列。网格中散布若干小型前景对象：其中一部分是实心 2x2 方块（"有效对象"），颜色为绿(3)、黄(4)、橙(7)等；另一部分是非方形的单色形状（"干扰项"），如单像素、1x3 横条、L形（2-4 像素，4-连通），颜色与有效对象相似。生成约束：每个有效 2x2 方块与恰好一个标记共享行或列（不会同时与两个标记对齐）；干扰项也可能碰巧与标记共享行或列；两个标记吸引到的有效方块数量不相等。

**规则**：
1. 过滤：仅保留恰好占据 2x2 区域的实心单色方块为有效对象，忽略所有其他前景形状（干扰项从画面中擦除）。
2. 对每个有效方块，确定与之行对齐或列对齐的唯一标记，沿共享轴方向滑动方块直到方块边缘紧邻该标记。
3. 计数：分别统计红(2)标记和蓝(1)标记各自吸引到的有效方块数量。
4. 镜像轴选择：若红标记吸引的方块更多，则对整个画面做水平翻转（左右镜像）；若蓝标记吸引的方块更多，则对整个画面做垂直翻转（上下镜像）；若数量相等，则沿主对角线转置。
5. 标记像素在镜像后保留。

**关键洞察**：干扰项在视觉上与有效方块相似，且可能与标记对齐，但它们不应参与滑动和计数。如果错误地将干扰项计入，标记的计数结果可能翻转，导致选择完全不同的镜像轴。镜像轴的选择规则（红多→水平、蓝多→垂直、相等→转置）需要对比多个示例才能归纳——单个示例只能观察到一种镜像类型。
