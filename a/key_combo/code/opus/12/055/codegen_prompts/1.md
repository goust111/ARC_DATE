## 新题 1：轴对齐双功能印章

**组合逻辑**：[共行列对齐](创新：对齐轴同时决定匹配关系和变换类型) → [旋转](创新：仅在列对齐时触发) + [印章覆盖] + [重涂色]

**来源原语**：共行列对齐(963f59bc), 引导掩码/包围框包含(bf699163), 印章覆盖/标记选槽接收精灵(363442ee), 旋转(cf5fd0ad/67c52801), 重涂色(7d1f7ee8)

**依赖链**：对齐轴检测同时输出两个结果——匹配关系和变换类型。匹配决定哪个精灵体进入哪个引导区域，轴类型决定精灵体是否旋转。重涂色依赖匹配关系确定目标颜色。三个输出共享同一个决策节点，删除对齐检测则匹配、变换、颜色全部无法确定。

根据精灵体与引导掩码的轴对齐方式，将精灵体原样或旋转后印入对应引导区域，并继承引导掩码的颜色。

**输入结构**：约 15x20 的网格，黑(0)为背景。一条灰(5)竖直分隔列将网格分为左右两个面板。左面板包含 3 个小型非对称单色精灵体（每个 4-7 像素，4-连通），颜色分别为红(2)、绿(3)、蓝(1)，垂直排列，相邻精灵体之间至少隔 2 行背景。右面板包含 3 个稀疏引导轮廓，颜色分别为黄(4)、橙(7)、栗(9)，每个引导轮廓由 4-6 个像素构成，其紧边界框定义一个矩形目标区域，大小足以容纳任何左面板精灵体。生成约束：每个引导轮廓与恰好一个精灵体共享中心行（行对齐）或共享中心列（列对齐），但不会同时共享两者；每个精灵体最多被一个引导轮廓对齐。

**规则**：
1. 对每个引导轮廓，找到与之共享中心行或中心列的唯一精灵体，建立匹配关系。
2. 若匹配为行对齐（引导轮廓的纵向中心行 = 精灵体的纵向中心行）：将精灵体原样（不变换）印入引导轮廓边界框的中心位置。
3. 若匹配为列对齐（引导轮廓的横向中心列 = 精灵体的横向中心列）：将精灵体顺时针旋转 90 度后印入引导轮廓边界框的中心位置。
4. 印入的精灵体重涂为对应引导轮廓的颜色。
5. 擦除引导轮廓像素。左面板精灵体和分隔列保持不变。
6. 居中时若产生半像素偏移，向左上取整。

**关键洞察**：单一几何特征（共享行还是共享列）同时控制了两个独立的输出维度：精灵体-引导区域的配对关系，以及精灵体是否需要旋转。仅看一个示例可能只出现行对齐或只出现列对齐，需对比多个示例才能发现轴类型决定变换类型的隐蔽规则。
