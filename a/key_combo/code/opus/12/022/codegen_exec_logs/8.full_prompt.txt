## 新题 8：开口矩形框的对称补全与缺口方向棋盘格填充

**组合逻辑**：[对称补全](创新：补全开口框为完整矩形) + [填充](创新：按缺口方向决定棋盘格起始相位) + [洪泛填充](已有：内部填充)

**来源原语**：对称补全/矩形框/行列对齐(#19 256b0a75)、洪泛填充/开顶矩形框/缺口不对称(#11 4e469f39)、填充/棋盘格图案(#8 df8cc377)、方向帽/帽向决定射线(#11 4e469f39)

**依赖链**：检测开口矩形框（三面封闭、一面有缺口） → 补全缺口使框成为完整矩形 → 确定缺口所在的方向（上/下/左/右） → 用缺口方向决定棋盘格的起始相位 → 以棋盘格模式填充框内部

一句话总结：将三面封闭的矩形框补全第四面边框，然后用棋盘格模式填充框内部，棋盘格的起始相位由缺口原来所在的方向决定。

**输入结构**：约 14x14 的网格，黑(0)背景。2~3 个灰(5)开口矩形框（一像素宽边框，三面完整、一面完全开口），各框的开口方向不同（一个上方开口、一个右侧开口等），框的内部为黑色。每个框的开口侧靠近开口端有一个 2 像素的灰(5)方向帽（与框相连的两个额外灰色像素，形成 L 角标记，指示原来的开口方向）。框的内部面积至少 3x3。各框之间不重叠不相邻。生成约束：不同框的开口方向至少有两种不同（以便从示例中归纳方向-相位映射）；框的内部面积不全相同。

**规则**：
1. 对每个开口框，补全缺失的第四面边框：在开口方向上补画一行（或一列）灰(5)像素使框成为完整的封闭矩形。方向帽保留但不算作边框的一部分。
2. 确定每个框原来的开口方向：上/下/左/右。
3. 以棋盘格模式填充框内部（仅内部黑(0)像素），填充颜色为红(2)。棋盘格的起始相位由开口方向决定：
   - 上方开口：内部左上角像素为红(2)着色（偶相位起始）。
   - 下方开口：内部左上角像素为黑(0)留空（奇相位起始）。
   - 左方开口：内部左上角像素为红(2)着色（偶相位起始），但棋盘格按列优先交替而非行优先。
   - 右方开口：内部左上角像素为黑(0)留空（奇相位起始），棋盘格按列优先交替。
4. 棋盘格中非着色位置保持黑(0)。框的灰(5)边框和方向帽不变。

**关键洞察**：所有框都做了相同的补全+填充操作，但棋盘格的视觉效果因开口方向不同而不同——上开口和下开口的棋盘格行列相同但相位反转，左开口和右开口则额外改变了扫描方向。这个方向-相位映射是隐蔽规则，必须对比至少两个不同开口方向的框才能归纳。

## 实现要求

1. `main(grid)` 必须实现新题描述中的确定性转换规则，不能只识别 `generate_input()` 的固定模板。禁止不同的input网格输出相同的output网格。
2. `generate_input()` 必须随机生成多样样例，不能固定死。随机维度应覆盖：网格大小、对象数量、位置、颜色、方向、形状参数或关键分支。注意若描述中存在若干，需实现而不是只有单个，包括object或者对应关系等等。且若涉及到最短路径，则输入网格中必涉及到多条路径，对选择造成干扰。

4. 禁止把 ARC 颜色 id 、亮度、拼写等当作人类不可见的数值语义参与排序、大小比较或隐藏映射。颜色变化必须有可见结构线索。注意颜色亮度、拼写等也是不可见信息，若描述中出现违规的颜色id或者亮度，可自行使用少量的固定颜色替代，但注意生成时要在三个以内输入输出网格中对所有变换100%覆盖度。
