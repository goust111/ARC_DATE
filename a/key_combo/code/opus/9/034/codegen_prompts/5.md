## 新题 5：前景计数决定颜色反转图案的平铺重复次数

**组合逻辑**：[颜色反转] + [平铺] + [计数](创新：计数值决定平铺重复次数而非像素放大倍率)（颜色反转和平铺为已有组合(48131b3c)，但原题固定 2x2 平铺；计数(ac0a08a4) 原用于像素放大；创新在于计数→平铺次数这一新映射关系）

**来源原语**：颜色反转/平铺/二值图案/阵列排布/反转后再平铺(48131b3c)，计数/前景像素/数量决定倍率/前景数为放大系数(ac0a08a4)

**依赖链**：计数前景像素 → 得到 N → 颜色反转 → 将反转后的图案 NxN 平铺。同一组前景像素既是被反转的对象又是决定平铺次数的编码源，形成自参照闭环。

统计前景像素数 N，交换前景色与背景色，然后将反转后的图案在水平和垂直方向各重复 N 次。

**输入结构**：一个小型网格（3x3 至 5x5），恰好包含两种颜色：黑(0) 作为背景和一种前景色（如蓝(1)）。前景像素形成一个连通或非连通的图案，像素数 N 在 2~4 之间。不同示例中网格尺寸可相同但前景像素数 N 不同。生成约束：N >= 2 且 N <= 4，以保证输出网格尺寸合理。

**规则**：
1. 计数网格中所有非黑(0) 前景像素的数量，记为 N。
2. 颜色反转：将所有黑(0) 像素替换为前景色，将所有前景色像素替换为黑(0)。
3. 将反转后的网格作为瓦片，在水平方向重复 N 次、垂直方向重复 N 次，拼成 NxN 瓦片阵列。
4. 输出网格尺寸为 (N * 输入高度) x (N * 输入宽度)。

**关键洞察**：前景像素数同时控制了"瓦片内容"（反转后前景变少、背景变多）和"瓦片数量"（N 越大重复越多）。改变一个前景像素会同时改变瓦片形态和阵列大小，产生非线性的输出变化。仅凭单个示例无法区分"固定 NxN 平铺"和"计数决定平铺次数"。
