## 新题 2：矩形边框编码周期掩码控制泛洪填充形态

**组合逻辑**：[泛洪填充] + [周期掩码](创新：掩码由空间分离的边框内条纹编码) + [擦除]（泛洪填充为已有原语，创新在于"空间分离的编码器控制填充输出"这一结构关系）

**来源原语**：泛洪填充/半封闭墙/填充种子/开口方向/障碍投射阴影(b9e38dc0)，矩形边框/周期条纹/周期掩码/条纹延伸全行列(6a980be1)，擦除(f45f5ca7)

**依赖链**：边框内部的条纹间距定义周期掩码 → 泛洪填充产生连续填充区域 → 周期掩码裁剪填充区域为条纹形态 → 边框被擦除。边框是"控制结构"而非输出元素；填充区域的最终形态同时取决于墙体几何和边框条纹，二者缺一不可。

用一个空间上远离的矩形边框内部的条纹图案，作为泛洪填充结果的行掩码，使填充区域呈现周期性条纹而非实心块。

**输入结构**：约 18x18 的网格，背景为黑(0)。网格右上区域有一个蓝(1) 单像素宽矩形边框（约 6x6），边框内部在每隔 2 行（即第 1、4、7... 行，以边框内部顶行为第 0 行计）绘有红(2) 水平条纹，每条条纹横跨边框内部全宽。网格左下区域有一个绿(3) U 形墙体（3 面封闭，1 面开口朝右），墙体围成的内部区域约 4x4，内部有一个黄(4) 填充种子像素。开口方向的外侧可能有 1~2 个灰(5) 障碍像素。生成约束：边框和墙体在空间上不重叠且不相邻；墙体开口方向的外部空间足够容纳射出的填充区域；障碍像素仅出现在开口方向的射出路径上。

**规则**：
1. 从矩形边框内部提取周期行掩码：记录边框内部哪些行有红(2) 条纹。将该行间距模式推广到整个网格坐标系——以边框内部第一条条纹的全局行号为锚点，每隔相同间距的全局行标记为"活跃行"。
2. 从黄(4) 种子像素开始泛洪填充：用黄(4) 填充种子所在的封闭区域全部黑(0) 格；填充穿过墙体开口向外辐射，沿开口方向扩展到网格边界或遇到非背景像素停止。灰(5) 障碍像素沿开口方向投射阴影——障碍像素保持不变，障碍正后方（沿开口方向）的所有格不被填充。
3. 对泛洪填充结果施加周期行掩码：仅保留"活跃行"上的黄(4) 填充像素；非活跃行上的黄(4) 像素恢复为黑(0)。
4. 擦除矩形边框及其内部所有内容（蓝(1) 框线和红(2) 条纹全部恢复为黑(0)）。
5. 绿(3) 墙体和灰(5) 障碍保持不变。

**关键洞察**：矩形边框不出现在输出中——它是一个纯粹的"规则编码器"，其内部条纹的行间距决定了泛洪填充的最终形态。两个空间上完全分离的结构（边框和墙体）通过抽象的周期规则产生耦合。
