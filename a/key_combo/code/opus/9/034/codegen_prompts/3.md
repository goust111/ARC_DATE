## 新题 3：逐区域计数决定各自放大倍率的提取堆叠

**组合逻辑**：[裁剪] + [计数](创新：每个提取区域独立计数作为各自放大系数) + [像素放大] + [堆叠]（均为已有原语，创新在于"区域内计数 → 区域级放大"的逐实例参数化）

**来源原语**：裁剪/堆叠/标记块/行对齐配对/按顺序堆叠/忽略干扰项(aab50785)，计数/像素放大/前景数为放大系数/数量决定倍率(ac0a08a4)

**依赖链**：标记块定界提取 → 区域内计数 → 计数值成为该区域的放大系数 → 放大后的区域堆叠。每个区域的放大系数不同，导致堆叠输出中各层尺寸不一。删除提取则无区域可数；删除计数则无法确定放大倍率；删除放大则堆叠尺寸无法统一到正确值。

提取标记块之间的图案，每个图案的前景像素数决定自身的放大倍率，放大后垂直堆叠。

**输入结构**：约 20x12 的网格，背景为黑(0)，散布少量灰(5) 噪声像素（干扰项）。红(2) 像素组成若干 2x2 方块，这些方块按行对齐配对（同一两行跨度内恰好有左右两个红方块），共 3 对。每对红方块之间有一个小图案（由蓝(1)、绿(3)、黄(4) 等颜色的 4-连通非背景像素组成，像素数范围 2~4，形状各不相同）。3 对标记块从上到下排列，相邻对之间至少隔 2 行。生成约束：每个提取区域的非背景像素数互不相同（如分别为 2、3、4）；提取区域的宽度相同（等于两个红方块内侧之间的距离）；高度均为 2（与红方块的行跨度相同）。

**规则**：
1. 识别所有红(2) 2x2 方块，按行对齐配对（共享相同两行跨度的左右两个方块为一对）。
2. 对每一对标记块，裁剪出两个方块内侧边之间的矩形区域（不含标记块本身），忽略区域外的灰(5) 噪声像素。
3. 对每个裁剪出的区域，计数其中非黑(0) 像素的数量 K。
4. 将该区域进行 K 倍像素放大：区域中每个像素替换为 KxK 的同色方块。
5. 按源位置从上到下的顺序，将所有放大后的区域垂直堆叠（第一对的放大区域在最上方，紧接第二对，依此类推，中间无间隔）。
6. 输出网格的宽度等于最大放大区域的宽度（较窄的放大区域左对齐，右侧补黑(0)）；高度等于所有放大区域高度之和。

**关键洞察**：同一组前景像素同时决定了"放大什么"和"放大多少"——像素越多的区域反而被放大得更多，形成自参照式的尺寸膨胀。不同示例中前景像素数不同，导致放大倍率不同，仅凭单个示例无法确认"计数 = 放大倍率"这一规则。
