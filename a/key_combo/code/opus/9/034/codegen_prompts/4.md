## 新题 4：缺失区域补全后按指示像素方向镜像并重涂色

**组合逻辑**：[补全](创新：补全的形状影响镜像结果) + [镜像] + [重涂色]（均为已有原语，创新在于"补全恢复的几何体成为镜像的正确输入"这一依赖关系）

**来源原语**：补全/不完整矩形/边界框推断/缺失像素补新色(6d75e8bb)，镜像/指示像素/邻接/指示定镜像与色(b775ac94)，重涂色(31f7f899)

**依赖链**：边界框推断 → 缺失像素补全 → 补全后的完整形状作为镜像输入 → 指示像素决定镜像轴和重涂色 → 镜像副本放置在指示像素侧。不补全就镜像会得到错误形状；没有指示像素就无法确定镜像方向和颜色。

先用新颜色补全不完整精灵的边界框内缺失像素，再按邻接指示像素的位置方向镜像整个补全结果，并将镜像副本重涂为指示像素的颜色。

**输入结构**：约 14x14 的网格，背景为黑(0)。网格中有 2~3 个不完整的单色精灵（每个精灵是一组 4-连通的同色像素，颜色各不相同，如蓝(1)、绿(3)、黄(4)；每个精灵有 4~8 个像素）。每个精灵的边界框内存在 1~3 个黑(0) 空洞（缺失像素）。每个精灵恰好有一个指示像素（颜色不同于精灵颜色且不同于其他指示像素，如红(2)、品红(6)、橙(7)）通过 4-邻接（上下左右）恰好接触精灵的边界框外侧的一条边（上边、下边、左边或右边的某个位置）。生成约束：不同精灵及其指示像素在空间上互不重叠；每个精灵的边界框加上其镜像副本的空间不超出网格边界且不与其他精灵冲突；每个精灵至少有一个缺失像素使得补全前后形状不同。

**规则**：
1. 对每个精灵，计算其所有像素的边界框（最小包围矩形）。
2. 将边界框内的黑(0) 空洞像素填充为红(2)，完成矩形补全。原精灵颜色像素保持不变。
3. 确定每个精灵的指示像素位置：指示像素在边界框的哪一侧（上→水平轴镜像放在上方；下→水平轴镜像放在下方；左→垂直轴镜像放在左方；右→垂直轴镜像放在右方）。
4. 以边界框的对应边为镜像轴，将补全后的整个边界框区域（含原始颜色和红(2) 补全像素）做镜像翻转。
5. 将镜像副本中所有非黑像素重涂为指示像素的颜色（不区分原始像素和补全像素，统一涂为指示色）。
6. 将镜像副本放置在原始精灵的指示像素侧，紧贴边界框外边（镜像副本的近边与原始边界框的对应边相邻，中间无间隔）。指示像素被镜像副本覆盖。
7. 处理顺序：按精灵边界框左上角的行列坐标排序（行优先，行相同则列小的优先），依次处理。若镜像副本与已放置的其他元素重叠，后放置的覆盖先放置的。

**关键洞察**：补全步骤看似简单的"填洞"，但它决定了镜像结果的形状——精灵缺失的像素在镜像副本中变为可见的指示色块，使得补全和镜像产生紧密的几何依赖。指示像素同时编码镜像轴方向和输出颜色，单个示例无法确定这一双重编码规则。
