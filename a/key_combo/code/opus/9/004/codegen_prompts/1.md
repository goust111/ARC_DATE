## 新题 1：尾部长度编码图层优先级的矩形恢复

**组合逻辑**：[occlusion_restore](已有) → [tail_vector → priority_encoder](创新：尾部长度不再编码位移，而是编码图层优先级) → [fill/interior_region](已有) → [conflict_priority](已有，但优先级键来自尾部长度)

**来源原语**：occlusion_restore / tail_vector / tail_displacement (c6e1b8da), fill / interior_region / border / keep_border_fill_in (e88171ec), conflict_priority (9344f635)

**依赖链**：尾部向量的长度决定了图层优先级 → 优先级决定了遮挡恢复后矩形的绘制顺序 → 绘制顺序决定了重叠区域显示哪个矩形的内部填充。删去尾部长度语义，就无法确定图层顺序；删去遮挡恢复，就不知道矩形的完整范围；删去内部填充，就无法区分哪些像素来自哪个矩形。

恢复所有被遮挡的矩形，按尾部长度排出图层顺序后，由短尾（高优先级）矩形覆盖长尾（低优先级）矩形，并将各矩形内部填充为统一颜色。

**输入结构**：约 14x14 的黑(0)背景网格。包含 3-4 个不同颜色的实心矩形（取自蓝(1)、红(2)、绿(3)、黄(4)），每个矩形至少 4x4。部分矩形相互重叠（一个颜色遮住另一个的局部）。每个矩形从其某一条边向外延伸出一条同色的、一像素宽的直线尾部，长度在 1-4 像素之间，各矩形的尾部长度互不相同。生成约束：每个矩形的完整范围（不计遮挡）至少 4x4，使其内部严格内部区域非空；尾部不与其他矩形的主体或尾部接触。

**规则**：
1. 识别每个矩形及其尾部。尾部与矩形某一条边连续，宽度为一像素，沿基数方向延伸。
2. 恢复每个矩形的完整边界框范围——将被其他矩形遮挡的像素恢复为该矩形的颜色。
3. 擦除所有尾部像素（置为背景色黑(0)）。
4. 计算各矩形的图层优先级：尾部越短，优先级越高（越后绘制，在最上层）。
5. 按优先级从低到高（尾部最长者先绘制，最短者最后绘制）逐个绘制矩形。每个矩形的绘制方式为：外围一像素边框保持原色，严格内部像素填充为灰(5)。
6. 后绘制的矩形在重叠区域覆盖先绘制的矩形。

**关键洞察**：尾部看上去是位移向量（如参考题 c6e1b8da），但实际上是图层优先级编码器——长度编码"谁在上面"。必须对比多个示例中不同尾部长度与不同重叠结果的对应关系，才能归纳出"短尾在上"的规则。
