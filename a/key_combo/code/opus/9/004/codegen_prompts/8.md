## 新题 8：连线路径激活骨架格子框

**组合逻辑**：[connect / fill_between_markers](已有) → [scaffold_lattice / hollow_cell_frame](已有) → [expand_fill / marker_lattice_align](已有，但激活条件从标记位置变为连线路径经过) → [conflict_priority](已有)

**来源原语**：connect / row_col_aligned / fill_between_markers / marker_pixel / line_segment (dbc1a6ce), scaffold_lattice / hollow_cell_frame / expand_fill / marker_lattice_align / marker_span_extent (97239e3d), conflict_priority / row_overrides_column (9344f635)

**依赖链**：同色标记对之间画连线 → 连线路径穿过骨架的边界行/列 → 路径经过的框被激活并填充连线颜色 → 两条不同颜色的连线穿过同一框时需要冲突解决。删去连线，框无从知道该激活哪些；删去骨架结构，无法定义"框"和"经过"；删去冲突解决，多色交叉处输出不确定。

同色标记对之间的连线在骨架格子上画出路径，路径经过的每个空心框的中心被填充为连线颜色。

**输入结构**：约 17x17 的黑(0)背景网格。一个由灰(5)空心 3x3 小框组成的规则骨架格子，小框之间间隔一行一列的边界带。各小框中心像素为黑(0)（空心）。在骨架的边界交叉点上分布着若干彩色标记像素，颜色取自蓝(1)、红(2)、绿(3)，每种颜色恰好出现两个，构成同色对。每对标记共享同一行或同一列（行列对齐）。生成约束：不同颜色的连线路径至少有一个交叉框（经过同一个小框），以便出现冲突场景；标记不占据小框的中心位置。

**规则**：
1. 对每对同色标记，沿它们共享的行或列画一条连线：将两标记之间（不含标记本身）的所有背景像素涂为该标记颜色。连线经过的灰(5)骨架像素保持灰(5)不变。
2. 识别连线路径经过哪些骨架小框：若连线经过某小框的边界行或列（即连线像素出现在该小框的同一行或同一列的边界区域），则该小框被激活。
3. 将每个被激活的小框的中心像素填充为激活它的连线颜色。
4. 若同一个小框被两条不同颜色的连线激活（交叉），则水平方向的连线优先——中心像素涂为水平连线（同行标记对）的颜色。
5. 未被任何连线激活的小框的中心保持黑(0)。
6. 标记像素保持原色；骨架框体保持灰(5)。

**关键洞察**：标记本身并不直接选择要填充的框（与参考题 97239e3d 不同）——标记通过连线间接激活沿途的框。一对标记可以激活一整串框，形成"路径效应"。冲突解决规则（水平优先）只有在出现交叉路径的示例中才能被归纳出来。
