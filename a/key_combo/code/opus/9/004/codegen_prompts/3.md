## 新题 3：多标记方向编码镜像轴的精灵反射

**组合逻辑**：[micro_marker/domino](已有) → [orientation_determines_direction → orientation_determines_mirror_axis](创新：朝向不再决定行/列涂色方向，而是决定镜像反射轴) → [mirror](已有) → [recolor](已有)

**来源原语**：micro_marker / orientation_determines_direction (9344f635), mirror / contact_edge_align (11dc524f), recolor (604001fa), erase (604001fa)

**依赖链**：多米诺的朝向决定了镜像轴的类型（水平朝向→垂直轴，竖直朝向→水平轴）→ 多米诺的位置决定了轴的坐标 → 镜像操作依赖轴的类型和位置生成反射副本 → 反射副本使用新颜色绘制。删去朝向解读，就不知道做哪种反射；删去镜像操作，就无法生成副本；删去重涂色，就无法在视觉上区分原件与副本。

每个精灵旁的多米诺标记编码了该精灵的反射轴——水平多米诺意味着左右翻转，竖直多米诺意味着上下翻转。

**输入结构**：约 13x13 的黑(0)背景网格。包含 2-3 个不同颜色的 4-连通精灵体（取自蓝(1)、绿(3)、黄(4)），每个精灵 3-7 像素，形状不规则且非对称（使镜像结果可见差异）。每个精灵有且仅有一个与之 4-邻接（共享至少一条边）的红(2)多米诺标记——由两个红(2)像素组成的水平对（同行相邻两列）或竖直对（同列相邻两行）。各多米诺之间互不接触，也不与非对应的精灵接触。生成约束：每个精灵的反射副本（按下述规则生成）完全在网格内且不与其他精灵、副本或多米诺重叠。

**规则**：
1. 为每个精灵找到其唯一的 4-邻接红(2)多米诺。
2. 若多米诺为水平对（两像素同行），则镜像轴为竖直线，通过多米诺两像素列坐标的中点（即两列的算术平均值）。
3. 若多米诺为竖直对（两像素同列），则镜像轴为水平线，通过多米诺两像素行坐标的中点。
4. 将精灵的每个像素关于该轴做反射，生成镜像副本。副本颜色统一为橙(7)。
5. 擦除所有多米诺像素（置为黑(0)）。
6. 原精灵保持其原色不变。

**关键洞察**：水平排列的多米诺触发的是竖直轴反射（左右翻转），这与直觉（水平→水平操作）相反。必须对比包含不同朝向多米诺的多个示例，才能归纳出"朝向与反射轴垂直"的规则。

## 实现要求

1. `main(grid)` 必须实现新题描述中的确定性转换规则，不能只识别 `generate_input()` 的固定模板。禁止不同的input网格输出相同的output网格。
2. `generate_input()` 必须随机生成多样样例，不能固定死。随机维度应覆盖：网格大小、对象数量、位置、颜色、方向、形状参数或关键分支。注意若描述中存在若干，需实现而不是只有单个，包括object或者对应关系等等。且若涉及到最短路径，则输入网格中必涉及到多条路径，对选择造成干扰。
3. 生成器必须保证输入满足 `main()` 的隐式假设：对象不重叠、不越界、特殊标记唯一或可区分、匹配关系无歧义、关键分支出现概率相同。

6. 若规则有多个分支，生成器不能长期固定成一个分支；应让分支在随机样例中合理出现。分支概率不必平均——难以发现的隐蔽分支（如少数情况下才触发的特殊规则）应适当提高出现概率，确保在 3 个训练示例中至少出现一次，否则求解者无法归纳该规则。对于颜色映射类规则，确保 2 个左右的示例即可覆盖所有映射关系（每种颜色→颜色的映射至少在某个示例中出现过）。
