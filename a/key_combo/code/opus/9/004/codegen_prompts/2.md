## 新题 2：菱形容器中的重力下落

**组合逻辑**：[diamond_frame](已有) → [area_determines_role](已有) → [gravity_drop](已有，但容器从矩形网格改为菱形) → [stop_at_blocker](已有) → [collision_stop](已有)

**来源原语**：diamond_frame / fill_inside_frame / stop_at_blocker (95755ff2), gravity_drop / area_determines_role / stop_at_bottom (6ca952ad), collision_stop (11dc524f)

**依赖链**：菱形框定义了非矩形的重力容器边界 → 面积区分移动者与阻挡者 → 重力驱动移动者下落，但停止条件同时依赖菱形边界（V 形底部）和阻挡像素 → 移动者之间按初始高度排序处理以避免穿越。删去菱形框，重力问题退化为普通矩形下落；删去面积区分，无法判断谁该移动；删去碰撞停止，对象会穿越彼此。

将菱形框内的多像素对象向下做重力下落，单像素阻挡物固定不动；对象遇到菱形斜边、阻挡物或已落定的其他对象时停止。

**输入结构**：约 17x17 的黑(0)背景网格。中央有一个完整的一像素厚菱形框，颜色为红(2)，菱形的四个顶点分别位于网格上下左右边界附近。菱形内部有 2-3 个不同颜色的 4-连通对象（取自蓝(1)、绿(3)、黄(4)），每个对象 3-6 像素，形状不规则（非矩形），初始位于菱形内部的上半区域。菱形内部还有 1-2 个灰(5)单像素作为固定阻挡物。生成约束：初始时所有对象和阻挡物互不接触，且均严格位于菱形内部（不触碰菱形框）。

**规则**：
1. 菱形内部的单像素灰(5)对象为固定阻挡物，永不移动。
2. 菱形内部面积 >= 3 的多像素彩色对象为"下落体"。
3. 将每个下落体逐行向下平移。下落体在以下任一条件满足时停止：(a) 其任一像素的下一行位置落在菱形框上或菱形外部；(b) 其任一像素的下一行位置是阻挡物；(c) 其任一像素的下一行位置已被另一个已落定的下落体占据。
4. 处理顺序：按下落体最低像素的行坐标从大到小（最靠近底部的先处理），保证先落定的不被后处理的穿越。
5. 所有下落体落定后，菱形框、阻挡物和落定对象保持各自颜色；菱形内部未被占据的像素仍为黑(0)。

**关键洞察**：菱形的 V 形底部使"地面"随水平位置变化——中央列可下落最远，侧边列很快就被斜边拦住。同样的重力规则因容器几何而产生非对称的落定格局，需要对比多个示例才能确认容器形状而非对象属性决定最终位置。
