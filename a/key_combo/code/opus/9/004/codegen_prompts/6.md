## 新题 6：等差序列定位缺失件 + 锚点定义镜像轴

**组合逻辑**：[arithmetic_progression / completion](已有) → [square_anchor / anchor_as_axis](已有，但锚点位于等差缺口处而非独立放置) → [mirror](已有) → [recolor](已有)

**来源原语**：arithmetic_progression / completion / rect_side_stroke (f8c80d96), mirror / square_anchor / anchor_as_axis / contact_edge_align (11dc524f), recolor (604001fa)

**依赖链**：等差递推发现精灵序列中的缺口位置 → 锚点恰在缺口处，确认位置并提供镜像轴 → 缺口处不是放一个普通副本而是放原件的镜像 → 镜像副本使用新颜色以区分。删去等差递推，就不知道缺口在哪里；删去锚点，就不知道镜像方向；删去镜像，就变成简单的补全题。

沿一条轴线等距排列的同形精灵缺少一个成员，缺口处的锚点方块标记了镜像轴，补全的是原件的反射副本而非直接复制。

**输入结构**：约 18x18 的黑(0)背景网格。包含 3-4 个相同的蓝(1)4-连通精灵体（4-8 像素，形状不规则且非对称），沿水平或竖直方向排列，各精灵边界框的左上角坐标在该轴方向构成等差数列。数列中恰有一个位置缺失（无精灵）。缺失位置处放置一个红(2)的 2x1 或 1x2 实心方块锚点，其长轴垂直于数列排列方向。生成约束：镜像副本在缺口位置不与任何已有精灵重叠；锚点的中心坐标与缺口位置预期的精灵边界框边缘对齐。

**规则**：
1. 识别精灵序列的等差递推模式：所有同色精灵的边界框左上角沿某一轴方向（水平或竖直）等间距排列。
2. 通过等差间距推断缺失成员应在的位置。
3. 红(2)锚点方块标记了缺口位置。锚点的长边定义了镜像轴：长边所在直线即为反射线。
4. 取任一现有精灵的形状模板，关于锚点长边做镜像反射，将反射结果放置在缺口位置。
5. 镜像副本统一涂色为绿(3)。
6. 擦除锚点方块（置为黑(0)）。
7. 原有蓝(1)精灵保持不变。

**关键洞察**：缺口的位置由等差序列决定（"在哪里"），但填入的不是精灵原样而是镜像版本（"长什么样"），这由锚点的朝向编码。两个独立的信息源（序列间距 + 锚点方向）共同约束了一个输出，单独任何一个都不够。
