## 新题 8：色带镜像边界限定精灵体对齐范围

**组合逻辑**：[mirror + band_flip_opposite](已有，色带镜像建立上下对称边框) × [align + coordinate_aligned_to_template + shape_matching](创新：对齐的目标坐标不来自同形模板，而来自镜像色带的颜色分段边界)

**来源原语**：mirror、colored_row_band、canvas_boundary、symmetry、band_flip_opposite（496994bd）；align、sprite、template、shape_matching、coordinate_aligned_to_template（1caeab9d）

**依赖链**：色带镜像到对侧形成上下框架 → 色带中的颜色分段定义水平区间 → 精灵体按颜色匹配被归入对应区间 → 在区间内执行水平居中对齐。色带不只是装饰框——其颜色分段结构编码了精灵体的目标位置。

顶部色带镜像到底部形成框架，色带中各色段定义水平区间，同色精灵体水平居中对齐到对应区间内。

**输入结构**：黑(0)背景，约 20x12 网格。顶部 1~2 行是满宽度的色带，由若干连续的同色列段组成（如：前 5 列蓝(1)、中间 7 列红(2)、后 8 列绿(3)），颜色数量为 3~4 种。网格中部（第 3 行至倒数第 3 行）散布若干小的 4-连通单色精灵体（3~6 像素），每个精灵体的颜色与色带中的某一种颜色相同。同色精灵体的形状可能不同。底部行为空（全背景色）。生成约束：每种色带颜色对应 1~2 个同色精灵体；精灵体初始位置的水平范围可能跨越其对应色段的边界；不同色的精灵体可能在垂直方向上有重叠行。

**规则**：
1. 将顶部色带垂直翻转后复制到底部对应行，形成上下对称的色带框架。中间内容区保持不变。
2. 读取色带的颜色分段：从左到右扫描，将连续同色列归为一段，记录每段的颜色、起始列和结束列。
3. 对网格中部的每个精灵体，根据其颜色找到色带中对应的分段区间 [col_start, col_end]。
4. 将该精灵体水平平移，使其边界框在水平方向上居中于 [col_start, col_end] 区间。垂直位置不变。平移时仅移动精灵体像素到新位置，原位置清为背景色。
5. 若同一色段内有多个精灵体，按其初始行位置从上到下依次处理，确保互不重叠（若居中后会重叠，后处理的精灵体向下偏移一行直到不重叠）。

**关键洞察**：色带的颜色分段不只是视觉框架——它编码了同色精灵体的目标水平区间。镜像操作让框架结构在上下两端可见，暗示色带具有功能性意义，但分段边界与对齐的关系需要对比多个示例才能确认。
