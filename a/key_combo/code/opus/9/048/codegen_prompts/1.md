## 新题 1：轮廓围合反转十字扩展方向

**组合逻辑**：[contour_enclosure](已有) + [expand + ortho_diag_role_split](创新：围合状态反转正交/对角的角色分配) + [flood_fill](已有，但填充依赖扩展后的剩余空间)

**来源原语**：contour_line、enclosed_bg_region、contour_enclosure（753ea09b）；expand、cross_pattern、ortho_diag_role_split、arm_center_split_growth（0962bcdd）；flood_fill、small_regions_filled（753ea09b）

**依赖链**：轮廓围合检测 → 围合状态决定扩展角色分配方向 → 扩展后的像素改变围合区域的剩余背景形状 → 剩余背景被填充。围合判定改变扩展的语义，扩展结果改变填充的范围，三者循环约束。

输入中的十字图案根据是否处于轮廓围合区域内，以相反的方式扩展；扩展后围合区域内的剩余背景被填充为轮廓色。

**输入结构**：黑(0)背景，约 20x20 网格。灰(5)像素组成若干 8-连通闭合轮廓线（每条轮廓围成一个 6x6 至 8x8 的封闭区域）。网格中散布若干 3x3 十字图案，每个十字的臂色为橙(7)、中心色为黄(4)。部分十字位于灰色轮廓围合的封闭区域内部，部分位于外部。十字之间互不相邻（任意两个十字的 5x5 扩展足迹不重叠）。生成约束：每个封闭区域内恰好有一个十字，且十字的 5x5 扩展足迹完全落在封闭区域内部。

**规则**：
1. 将所有前景像素（灰色轮廓 + 十字像素）作为屏障，对背景做 4-连通分量分析。面积最大的两个背景分量视为"外部"，其余为"围合内部"。
2. 对于位于围合内部的十字（其中心像素属于某个围合区域）：**反转角色**——中心色黄(4)沿正交方向（上下左右）各延伸一格，臂色橙(7)沿四个对角方向各延伸一格，形成 5x5 足迹。
3. 对于位于外部的十字：**标准角色**——臂色橙(7)沿正交方向各延伸一格，中心色黄(4)沿四个对角方向各延伸一格，形成 5x5 足迹。
4. 扩展完成后，重新对背景做 4-连通分量分析。将仍处于灰色轮廓围合内部（不与外部连通）的所有背景像素填充为灰(5)。

**关键洞察**：同一个十字图案的两种颜色在扩展时的生长方向并非固定——它取决于十字是否被轮廓线围住。必须对比围合内外的十字扩展结果才能归纳出角色反转规则。
