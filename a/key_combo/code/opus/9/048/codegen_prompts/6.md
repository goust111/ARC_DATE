## 新题 6：调色板序列按交替翻转层分配给波形堆叠

**组合逻辑**：[stacking + alternating_flip + one_row_overlap](已有) × [recolor + order_correspondence](创新：每层堆叠的波形从调色板中取不同颜色，翻转层的调色板读取方向也翻转)

**来源原语**：mirror、stacking、wave_pattern、alternating_flip、one_row_overlap（eb281b96）；recolor、palette_column、target_column_run、order_correspondence、column_run_group_match（9b365c51）

**依赖链**：调色板列提供颜色序列 → 波形堆叠决定层数和翻转状态 → 翻转状态决定调色板的读取方向（正序/逆序） → 读取方向决定每层中各列段的颜色。调色板映射和几何翻转形成双向耦合。

将波形图案交替翻转堆叠，每层的颜色由调色板列按对应方向分配——正常层正序读取调色板，翻转层逆序读取。

**输入结构**：黑(0)背景，约 20x8（宽x高）网格。网格左侧有 3~5 个相邻的满高度调色板列（每列单一颜色，颜色各不相同，如蓝(1)、红(2)、绿(3)、黄(4)等）。网格右侧有一个灰(5)的波形图案，高度为 h 行（约 4~5 行），宽度与调色板列数相同。波形图案中每列有一个连续的灰色垂直段（列段），不同列的段起止行不同，形成波浪形轮廓。生成约束：调色板列的数量等于波形图案的列数；波形图案的相邻列段至少共享一行（确保一行重叠拼接时有公共像素行）。

**规则**：
1. 读取调色板列从左到右的颜色序列：P = [P1, P2, ..., Pk]。
2. 提取波形图案（灰色区域）的边界框作为种子波形。
3. 将种子波形堆叠 4 次（原始、垂直翻转、原始、垂直翻转），每相邻两层共享一行重叠（重叠行取非背景像素）。
4. 对第 i 层（从上到下，i=0,1,2,3）的波形，将其各列段按从左到右的顺序与调色板对应重涂色：
   - 若 i 为偶数（原始层）：第 j 列段涂为 P[j]。
   - 若 i 为奇数（翻转层）：第 j 列段涂为 P[k-1-j]（调色板逆序）。
5. 擦除原始调色板列（涂为背景色）。重叠行若有两层颜色冲突，上层覆盖下层。

**关键洞察**：翻转层不仅几何翻转，调色板的读取方向也同步翻转。仅看单层无法发现逆序规则，必须对比正常层和翻转层的颜色分配才能归纳出方向耦合关系。
