## 新题 4：切比雪夫方块内容按提示精灵体旋转

**组合逻辑**：[fill + chebyshev_dist + blocker_dist_size](已有) × [rotate + pixel_count_encodes_rotation](创新：方块不是纯色填充，而是填充后内部图案按提示编码旋转)

**来源原语**：fill、marker_pixel、blocker_pixel、square_region、chebyshev_dist、blocker_dist_size（ff72ca3e）；rotate、cue_sprite、same_color_matching、pixel_count_encodes_rotation（6ffbe589）

**依赖链**：切比雪夫距离决定方块大小 → 方块内填入标记色对应的种子图案 → 提示精灵体的像素数决定图案旋转角度。方块尺寸约束了图案的可用空间，旋转改变了图案朝向，两者在同一区域内交叉作用。

在每个黄色标记周围画出由灰色阻挡像素限定的最大方块，方块内填入种子图案，图案的旋转角度由对应颜色的外部提示精灵体编码。

**输入结构**：黑(0)背景，约 18x18 网格。网格中有 2~3 个黄(4)标记像素和若干灰(5)阻挡像素（与 ff72ca3e 类似的布局）。网格的一条边缘（如底边）有 2~3 个小的单色提示精灵体，颜色分别为蓝(1)、红(2)、绿(3)等，每个提示精灵体是一个 4-连通图形（1~7 像素）。网格中还有对应数量的"种子图案"，每个种子图案是一个 3x3 的非对称单色小图形（颜色与某个提示精灵体相同），位于远离标记和阻挡的位置。生成约束：每个黄色标记的切比雪夫距离到最近灰色阻挡 >= 4（确保方块内能容纳 3x3 种子图案）；黄色标记数量等于种子图案数量，且按从左到右的顺序一一对应；种子图案颜色各不相同。

**规则**：
1. 对每个黄(4)标记，计算到最近灰(5)阻挡的最小切比雪夫距离 d。以标记为中心，画一个半径为 d-1 的正方形区域（即边长 2(d-1)+1），仅改变背景像素，填充为栗(9)作为方块底色。
2. 将黄色标记按从左到右排序，种子图案也按从左到右排序，建立一一对应。
3. 对每个种子图案，找到与其同色的提示精灵体，计算提示精灵体的像素数 p。旋转角度 = (p mod 4) x 90°（顺时针）。
4. 将种子图案的 3x3 边界框内容顺时针旋转上述角度后，放置在对应方块的中心位置（方块中心即黄色标记位置，种子图案的 3x3 边界框中心对齐标记位置）。种子图案像素覆盖方块底色。
5. 擦除原始种子图案位置（涂为背景色）和提示精灵体（涂为背景色）。黄色标记和灰色阻挡保留。

**关键洞察**：方块的尺寸由空间距离决定，方块内图案的朝向由外部提示精灵体的像素数量编码决定——两个看似独立的属性（大小和旋转）分别由不同机制控制，但在同一输出区域交汇。
