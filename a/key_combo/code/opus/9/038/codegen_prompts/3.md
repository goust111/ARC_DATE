## 新题 3：安全路径形状作为自相似展开的印章模板

**组合逻辑**：[寻路/pathfinding + 邻域禁区/neighbor_exclusion](原有：找到安全路径) → [裁剪/crop](原有：将路径裁至边界框) → [自相似嵌套/self_similar_nesting + 印章覆盖/stamp](创新：路径形状不是最终输出，而是被用作自展开的模板与内容)

**来源原语**：寻路(cc9053aa)、邻域禁区(cc9053aa)、端点(cc9053aa)、障碍物(cc9053aa)、自相似嵌套(8f2ea7aa)、前景位置决定印章(8f2ea7aa)、印章覆盖(8f2ea7aa)、裁剪(a251c730)

**依赖链**：障碍禁区筛选出唯一安全路径 → 路径裁剪为方形模板 → 模板的前景像素位置决定印章放置位，模板本身就是印章内容 → 自相似展开。删除寻路则模板未知；删除自相似展开则路径只是路径，无展开结构。

在障碍物禁区约束下找出两端点间的唯一安全路径，将路径形状裁剪为紧凑模板，再以该模板为基础做自相似展开。

**输入结构**：约 7x7 的网格（因为输出为模板尺寸的平方，需保持可控），黑(0) 背景。青(8) 像素构成一个 4-连通的轨道网络，轨道区域紧凑地分布在约 3x3 的范围内。网格中恰好有两个栗(9) 端点像素位于轨道上。1-2 个橙(7) 像素位于轨道附近（不在轨道上）。生成约束：橙像素的 8 邻域禁区移除部分轨道连接后，两端点之间仅存在唯一一条 4-连通简单路径；该路径裁剪至边界框后恰好填充一个 NxN 的正方形区域（N = 2 或 3），且输出网格尺寸为 NxN 的平方（即 4x4 或 9x9）。

**规则**：
1. 将每个橙(7) 像素及其 8 邻域标记为禁区。禁区内的青像素视为不可通行。
2. 在剩余可通行的青(8)/栗(9) 像素中，找到两个栗端点之间的唯一 4-连通简单路径。
3. 将路径（含两个栗端点）裁剪至其边界框，得到一个 NxN 的二值模板：路径像素为前景，其余为背景。前景统一标记为栗(9)。
4. 创建 N^2 x N^2 的输出网格，初始化为黑(0)。将输出划分为 NxN 个大小为 NxN 的块。
5. 对模板中每个前景像素位于局部坐标 (r, c) 处，将整个模板复制粘贴到输出的第 (r, c) 块中，前景像素涂为栗(9)。
6. 所有其他块保持黑(0)。

**关键洞察**：路径不是最终答案——它是被"发现"的中间产物，其形状既决定了自展开的印章内容，又决定了印章的放置掩模。谜题有两层结构推导：先寻路，再展开。
