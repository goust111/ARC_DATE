## 新题 9：镜像打破自相似——原始位图定位、反射位图填充

**组合逻辑**：[自相似嵌套/self_similar_nesting](创新：前景位置定位不变，但填充内容不再是自身而是自身的镜像) ← [镜像/mirror](创新：镜像不作用于空间对象，而是生成印章内容的变体) ← [标记像素/marker_pixel](原有：红像素指示镜像方向)

**来源原语**：自相似嵌套(8f2ea7aa)、前景位置决定印章(8f2ea7aa)、印章覆盖(8f2ea7aa)、镜像(2bcee788)、标记像素(2bcee788)、标记侧翻转且变色(2bcee788)

**依赖链**：红色标记确定镜像轴 → 模板被镜像产生变体 → 原始模板的前景位置决定"在哪里放"，镜像变体决定"放什么"。模板同时扮演定位掩模（原始版本）和内容来源（反射版本）两个角色，由红色标记将这两个角色劈开。删除镜像则退化为普通自相似展开（与参考题相同）；删除自相似展开则镜像无处放置。

以原始紧凑模板的前景像素为放置掩模，以该模板的镜像版本为印章内容，做非对称自相似展开。

**输入结构**：约 6x6 或 9x9 的网格（尺寸 = 模板尺寸 N 的平方），黑(0) 背景。网格中有一个占据 NxN 边界框（N=2 或 N=3）的紧凑单色前景模板，颜色为蓝(1)，非对称形状（这样镜像后与原始不同）。模板某一侧紧邻有 1-2 个红(2) 标记像素，指示镜像方向（与参考题 2bcee788 中的标记用法一致）。生成约束：模板至少有 2 个前景像素且非对称（镜像后形状不同）；红标记仅触碰模板的一条边。

**规则**：
1. 将前景蓝(1) 模板从边界框中裁剪出来（不含红像素），得到原始 NxN 位图 M。
2. 根据红(2) 标记触碰的边确定镜像轴：触碰右边 → 垂直轴（左右翻转）；触碰左边 → 垂直轴（左右翻转）；触碰上边 → 水平轴（上下翻转）；触碰下边 → 水平轴（上下翻转）。对 M 执行镜像，得到 M'。
3. 创建 N^2 x N^2 的输出网格，全部初始化为黑(0)。
4. 将输出划分为 NxN 个大小为 NxN 的块。对于原始位图 M 中每个前景像素位于局部坐标 (r, c)，将**镜像位图 M'** 复制粘贴到输出的第 (r, c) 块中，前景像素涂蓝(1)。
5. 所有其他块保持黑(0)。红(2) 像素不出现在输出中。

**关键洞察**：标准自相似展开中模板既是位置掩模又是印章内容（两者相同）。这里红色标记将两者解耦：原始模板做位置掩模，镜像模板做印章内容。由于模板非对称，镜像后内容不同于掩模，产生了非对称的嵌套结构——这在参考题 8f2ea7aa 的纯自相似展开中不可能出现。

6. 若规则有多个分支，生成器不能长期固定成一个分支；应让分支在随机样例中合理出现。分支概率不必平均——难以发现的隐蔽分支（如少数情况下才触发的特殊规则）应适当提高出现概率，确保在 3 个训练示例中至少出现一次，否则求解者无法归纳该规则。对于颜色映射类规则，确保 2 个左右的示例即可覆盖所有映射关系（每种颜色→颜色的映射至少在某个示例中出现过）。
