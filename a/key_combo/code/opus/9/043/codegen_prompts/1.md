## 新题 1：树干分区的计数染色

**组合逻辑**：[连线 draw_line] + [洪泛填充 flood_fill](创新：填充色由分支计数决定) + [计数 counting](创新：计数对象是围绕区域的控制像素)

**来源原语**：连线/控制像素/主干线段/共行列定义主干/连接到主干(bf89d739)；洪泛填充/区域包含(a64e4611)；计数(8f215267)；连通分量(42a50994)

**依赖链**：控制像素的空间分布决定主干和分支的走向 → 主干+分支将网格分割成若干封闭区域 → 每个封闭区域边界上的控制像素数量决定该区域的填充颜色。删除连线步骤则无法形成分区；删除计数步骤则无法确定填充色；删除填充步骤则分区信息无处表达。

树干结构将网格切分成封闭区域，每个区域的边界控制像素数量编码了它应被填充的颜色。

**输入结构**：约 15x15 的黑(0)背景网格。散布若干红(2)控制像素（约 5~8 个）。其中恰好有两个红像素共享同一行或同一列，这对像素定义主干线段。其余红像素均位于主干沿垂直方向的跨度范围内（即每个非主干红像素都可以沿垂直于主干的方向投影到主干上）。生成约束：主干+分支将网格切分出的完全封闭区域至少 3 个，每个封闭区域边界上的红像素数量各不相同且均在 1~4 之间。主干长度至少 6 像素。所有红像素不在网格边缘行/列上。

**规则**：
1. 找到共享同一行或同一列的那对红(2)像素，它们之间的直线段即为主干。将主干上两端点之间的背景像素涂为绿(3)，保留两端红像素不变。
2. 对每个非主干红像素，沿垂直于主干的方向画一条绿(3)线段连接到主干（线段不覆盖红像素本身，也不覆盖主干上已有的绿/红像素，仅填充其间的背景像素）。
3. 绿线段 + 红像素 + 网格边界共同将网格分割为若干 4-连通背景区域。识别每个背景区域。
4. 对每个完全被绿线/红像素/网格边界包围的封闭背景区域，统计其边界上（4-邻接）接触的红(2)控制像素数量 K。按以下映射填充该区域的所有背景像素：K=1 → 蓝(1)，K=2 → 黄(4)，K=3 → 橙(7)，K=4 → 品红(6)。
5. 接触网格最外缘（即区域延伸到网格边界外）的背景区域不填充，保持黑(0)。
6. 所有红像素和绿线段保持不变。

**关键洞察**：主干和分支不仅是视觉连接线——它们是空间分区器。同一组控制像素既定义了线段结构，又通过自身在分区边界上的位置编码了每个区域应得到的颜色。颜色映射 K→color 需要对比多个示例才能归纳（不同示例中 K 值分布不同）。
