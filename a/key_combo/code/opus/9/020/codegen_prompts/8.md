## 新题 8：镜像扩展中的定向印章

**组合逻辑**：[镜像/mirror + 拼接/assembly](已有) + [印章覆盖/stamping](已有) — 标记位置随镜像复制到四个象限，但印章内容不随镜像翻转（对称性中的不对称）

**来源原语**：镜像/mirror、拼接/assembly、画布/canvas、象限/quadrant、四象限排布/four_quadrant_layout、翻转形成对称铺展（来自 62c24649、833dafe3）；印章覆盖/stamping、精灵体/sprite、模板掩码/template_mask（来自 d304284e、5a5a2103）

**依赖链**：镜像扩展将整个网格（含精灵体和标记像素）复制到四个象限 → 标记像素的位置随镜像出现在四处 → 在每个标记位置处印章精灵体 → 但印章始终保持原始方向（不随象限的翻转方向变化）→ 叠加处印章覆盖镜像图案

小网格被镜像扩展为四象限对称图案，其中的标记像素也被复制到四处，但在每个标记位置印章的精灵体始终保持原始方向而不随象限翻转。

**输入结构**：网格约 5x6 至 7x7（小尺寸），黑(0) 背景。包含一个小型前景精灵体（3-6 像素，单色，如绿(3)），形状不对称（不具备水平或垂直对称性，确保翻转后外观可区分）。另有 1-2 个标记像素，颜色与精灵体不同（如红(2)），位于网格中非精灵体占据的位置。生成约束：精灵体形状在不同示例中不同但始终不对称；标记像素与精灵体不相邻（至少间隔 1 个像素）；精灵体的包围框足够小，使得在标记位置印章时不会超出扩展后网格的边界。

**规则**：
1. 将原始网格镜像扩展为 2x2 四象限图案：左上 = 原始；右上 = 左右镜像；左下 = 上下镜像；右下 = 左右 + 上下镜像。扩展后网格尺寸为原始的两倍（2H x 2W）。
2. 在扩展后的网格中，原始的标记像素出现在四个对称位置（每个象限一个）。
3. 在每个标记位置，以标记像素为锚点（精灵体包围框左上角对齐到标记位置），印章精灵体的掩码。印章始终使用精灵体的**原始方向**（不随所在象限的翻转方向做镜像变换）。印章颜色使用标记像素的颜色（如红(2)）。
4. 印章覆盖该位置已有的任何像素（包括镜像产生的图案）。
5. 四个标记位置的印章均独立执行，若多个印章重叠，后处理的覆盖先处理的（处理顺序：左上 → 右上 → 左下 → 右下）。

**关键洞察**：镜像操作使整个网格（包括背景图案和标记位置）都产生了对称翻转，但印章操作打破了这种对称——四个象限的印章内容完全一致、方向相同，而非随象限翻转。求解者必须注意到背景图案是对称的而印章不是。若精灵体本身碰巧对称，单个示例无法暴露方向规则，需对比使用不对称精灵体的示例才能确认印章不跟随翻转。

6. 若规则有多个分支，生成器不能长期固定成一个分支；应让分支在随机样例中合理出现。分支概率不必平均——难以发现的隐蔽分支（如少数情况下才触发的特殊规则）应适当提高出现概率，确保在 3 个训练示例中至少出现一次，否则求解者无法归纳该规则。对于颜色映射类规则，确保 2 个左右的示例即可覆盖所有映射关系（每种颜色→颜色的映射至少在某个示例中出现过）。
