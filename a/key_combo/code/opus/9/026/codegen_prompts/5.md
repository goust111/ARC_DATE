## 新题 5：镜像验证筛选标记后填充楔形

**组合逻辑**：[镜像](创新：不生成镜像副本，而是用镜像对应关系做真伪验证) → [忽略干扰项](已有) → [填充](已有) + [三角楔形区域](已有) + [标记像素](已有) + [对角线边界](已有)

**来源原语**：镜像/分隔行/镜像对应/源色由反射匹配(c9680e90), 填充/三角楔形区域/标记像素/对角线边界/标记定义楔形范围(896d5239), 忽略干扰项(35ab12c3)

**依赖链**：镜像对应筛选出真标记 → 真标记的空间分布定义楔形几何 → 楔形几何确定填充区域。去掉镜像验证则干扰标记混入，楔形范围错误；去掉楔形构建则空有真标记无法生成填充。

利用分隔线两侧的镜像对应关系区分真标记与干扰像素，仅用通过验证的真标记在上半区构建 45 度三角楔形并填充。

**输入结构**：约 20x15 的网格，黑(0)背景。正中间有一整行灰(5)像素构成的水平分隔行，将网格分为等高的上半区和下半区。上半区散布若干绿(3)像素，其中一部分是"真标记"，另一部分是"干扰像素"。下半区也有若干绿(3)像素，它们的位置恰好是某些上半区真标记关于分隔行的镜像位置（即：真标记在 (r, c)，其镜像在 (separator_row + (separator_row - r), c)）。下半区没有多余绿像素。上半区干扰像素在下半区没有对应镜像。生成约束：上半区的真标记中，存在 1-2 个楔形尖端像素，每个尖端像素沿两个 45 度对角方向各有至少一个真标记作为边界线索，且距离尖端相同；干扰像素不落在任何真标记楔形的内部或边界上。

**规则**：
1. 对上半区每个绿(3)像素 (r, c)，计算其关于分隔行的镜像位置 (r', c)。若下半区 (r', c) 也是绿(3)像素，则该上半区像素为真标记；否则为干扰项。
2. 擦除所有干扰项（上半区无镜像对应的绿像素清为黑(0)）。擦除下半区所有绿像素和灰(5)分隔行（清为黑(0)）。
3. 在上半区剩余的真标记中，识别楔形尖端：若一个真标记像素在两个互补的 45 度方向（如左上+左下、右上+右下、左上+右上、左下+右下）上各有至少一个其他真标记，且在两个方向上最近真标记的距离（切比雪夫距离）相同，则该像素为楔形尖端。
4. 对每个尖端，楔形高度 = 该尖端沿两条对角射线方向上连续存在真标记的最远距离。在尖端与两条射线围成的三角区域内，将所有非绿像素填充为青(8)。
5. 保留所有真标记的绿(3)像素不变。

**关键洞察**：下半区不是输出的一部分，而是一张"验证底片"——仅通过跨分隔行的镜像匹配才能区分真标记和干扰像素，这一筛选步骤必须先于楔形构建。
