## 新题 4：嵌套层数驱动反序柱状图

**组合逻辑**：[层序反转](创新：不改变原矩形外观，而是把层序反转后的颜色序列输出为柱状图条) → [计数](创新：计层数而非计对象数) → [排序](已有，按水平位置) → [堆叠/柱状图](已有)

**来源原语**：层序反转/嵌套矩形层/嵌套层次/颜色序列逆转(8dae5dfc), 计数/排序/柱状图/面积筛选(a3325580), 堆叠/嵌套遮罩/按数量排序(b1986d4b)

**依赖链**：嵌套层剥离提供层数和各层颜色 → 层数决定柱状图高度，逆序颜色决定柱状图各行填色 → 水平位置排序决定柱的左右顺序。三步互相依赖：不剥层就不知道颜色和数量；不计数就不知道输出尺寸；不排序就不知道柱的排列。

将每个嵌套矩形的层数作为对应柱状图柱的高度，柱内颜色从底到顶按层序反转（最内层色在底、最外层色在顶），柱的左右顺序由矩形在输入中的水平位置决定。

**输入结构**：约 20x20 的网格，黑(0)背景。3-5 个填充矩形散布在网格中，互不重叠。每个矩形由若干层向内嵌套的单色矩形层构成（每层为均匀的矩形边框，最内层可以是实心矩形），层数在 2-5 层之间，不同矩形的层数可以不同。每层颜色取自蓝(1)、红(2)、绿(3)、黄(4)、品红(6)、橙(7)、青(8)、栗(9)，同一矩形内各层颜色两两不同。各矩形的水平位置（边界框左边缘列号）两两不同。生成约束：至少两个矩形的层数不同。

**规则**：
1. 对每个矩形，从最外层向内逐层剥离：每次移除当前最外圈的均匀颜色边框，记录该层颜色，直到无法再剥为止。记层数为 L_i，外到内颜色序列为 [c_1, c_2, ..., c_{L_i}]。
2. 设最大层数 L_max = max(L_i)。输出网格高度 = L_max，宽度 = 矩形个数。
3. 按各矩形边界框左边缘列号从小到大排序，依次对应输出的第 1 列、第 2 列……
4. 对第 j 个矩形（排序后），其对应输出列从底行（第 L_max 行）开始向上填色：底行填最内层颜色 c_{L_j}，次底行填 c_{L_j - 1}，……顶部填最外层颜色 c_1。若 L_j < L_max，则该列最上方 (L_max - L_j) 个像素保持黑(0)。

**关键洞察**：层序反转不体现在原矩形的重涂上，而是体现在输出柱状图的颜色排列中——最内层变成柱底、最外层变成柱顶，必须对比多个示例中层数不同的矩形才能归纳出这一反转规则。
