## 新题 7：周期补全后极角连线成封闭轮廓

**组合逻辑**：[补全/平移等价](已有，用于填补缺失顶点) → [描边连线/极角排序](已有，将完整顶点集连成轮廓) ← 互相依赖：需要部分完整簇确定周期向量，周期向量又用于补全不完整簇

**来源原语**：补全/周期性格/缺失像素/平移等价/平移向量决定填充(484b58aa), 描边连线/轮廓顶点/极角排序/路径需通畅(35ab12c3)

**依赖链**：完整顶点簇提供周期平移向量 → 平移向量补全缺失顶点 → 完整簇的顶点按极角排序后连线。去掉周期补全则缺失簇无法描边；去掉描边则补全后的顶点没有最终呈现形式；且周期向量的发现依赖于已有完整簇的模式。

在一个周期性排布的顶点格阵中补全缺失的顶点，然后将每个完整簇的顶点按极角排序连成封闭多边形轮廓。

**输入结构**：约 20x20 的网格，黑(0)背景。红(2)像素标记轮廓顶点，分布为若干"簇"，每簇 4-6 个顶点围绕一个共同质心。各簇按某个二维平移向量 (dr, dc) 周期排列（即簇 i 的质心 + k*(dr,dc) = 簇 j 的质心）。部分簇保持完整（所有顶点都存在），部分簇有 1-2 个顶点缺失（对应位置为黑(0)）。每个完整簇的顶点按极角排序后，相邻顶点之间可以用水平、垂直或 45 度线段连接。生成约束：至少 2 个完整簇和至少 1 个不完整簇；平移向量 (dr, dc) 使得各簇互不重叠；不完整簇的缺失顶点在补全后不与其他簇的顶点位置冲突。

**规则**：
1. 在所有可见红(2)像素中，找到使重叠可见像素数量最大且无颜色矛盾的非零平移向量 (dr, dc)（与参考题 484b58aa 相同的方法）。
2. 利用 (dr, dc) 及其逆向量，将同一平移等价类中的像素聚合。若等价类中某些位置为黑(0)但等价类中其他位置为红(2)，则将黑(0)位置补全为红(2)。
3. 将所有红(2)像素（含补全的）按空间邻近性分为各簇（每簇为一组距离某质心较近的顶点）。
4. 对每个簇，计算其顶点的质心，按各顶点相对质心的极角从 0 度开始逆时针排序。
5. 按排序顺序，在相邻顶点之间（包括最后一个与第一个之间）画橙(7)线段，仅沿水平、垂直或 45 度方向画直线。若两相邻顶点之间无法用单条水平/垂直/45 度直线连接，则不画该段（保留间隙）。
6. 保留所有红(2)顶点像素不变，橙(7)线段像素不覆盖红(2)像素。

**关键洞察**：周期补全和极角连线相互依赖——不补全就有的簇缺顶点导致轮廓缺边，但不识别已有完整簇的轮廓模式就难以发现周期向量。解题者需要同时利用两种结构信息。
