## 新题 8：滑动触发锚定物嵌套层反转

**组合逻辑**：[滑动](已有，沿连接杆方向) → 接触事件 → [层序反转](创新：不是全局执行，而是由滑动接触事件有条件触发于锚定物上)

**来源原语**：滑动/连接杆/锚定物/碰撞阻挡/矩形体/沿杆滑至锚定物(98cf29f8), 层序反转/嵌套矩形层/嵌套层次/颜色序列逆转(8dae5dfc)

**依赖链**：滑动决定哪些锚定物被接触 → 被接触的锚定物执行层序反转，未被接触的保持不变。若不滑动，不知道哪些锚被触发；若不做层反转，滑动本身无法产生完整输出变化。

将矩形体沿连接杆方向滑动至锚定物旁，被滑动体接触的嵌套层锚定物执行层颜色反转，未被接触的锚定物保持原样。

**输入结构**：约 18x18 的网格，黑(0)背景。网格中有 3 个"锚定物"：每个锚定物是一个填充矩形（约 4x4 到 6x6），由 2-3 层向内嵌套的单色矩形层构成，各层颜色不同（取自蓝(1)、红(2)、绿(3)、黄(4)、品红(6)、橙(7)中的不同色）。另有 2 个"滑动体"：每个滑动体由一个灰(5)的实心小矩形（2x2 或 2x3）加一条灰(5)的一像素宽连接杆构成，连接杆从矩形体某边缘像素向某基本方向（上/下/左/右）笔直延伸 2-5 格。每个滑动体的连接杆方向上恰好有一个锚定物。生成约束：2 个滑动体指向不同的锚定物（即有 2 个锚被接触、1 个锚不被接触）；滑动路径上无其他障碍物；滑动体滑到终点后与锚定物 4-邻接但不重叠。

**规则**：
1. 对每个滑动体，擦除其连接杆像素（清为黑(0)）。
2. 将滑动体的矩形部分沿连接杆方向平移，移动距离等于连接杆长度（像素数），使矩形体最终与连接杆方向上最近的锚定物 4-邻接。
3. 对被滑动体接触（4-邻接）的锚定物：从外向内逐层剥离，记录颜色序列 [c_1, c_2, ..., c_L]（c_1 最外），然后将第 k 层重涂为 c_{L+1-k}（即最外层涂原最内层色，最内层涂原最外层色）。
4. 未被任何滑动体接触的锚定物保持原样不变。
5. 滑动体矩形保持灰(5)不变。

**关键洞察**：滑动不只是物理位移——它是层序反转的触发器。同一种嵌套矩形锚定物，被接触的和未被接触的输出完全不同。解题者必须同时理解滑动机制和层反转规则，且需要对比有接触和无接触的锚定物才能归纳出条件触发的逻辑。
