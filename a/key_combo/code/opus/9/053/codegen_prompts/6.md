## 新题 6：间隙分治场影响下落射线变色

**组合逻辑**：[间隙对半分](创新：对半分不直接产生可见填充，而是在逻辑上建立左右两个"影响域") → [射线延伸/沿列填至底](创新：射线穿过影响域时改变颜色，而非保持源色) → [奇数间隙留中线](创新：中线列上的射线保持原色不变色，成为唯一可区分的线索)

**来源原语**：间隙对半分(d968ffd4), 奇数间隙留中线(d968ffd4), 矩形(d968ffd4), 射线延伸(d037b0a7), 同列传播(d037b0a7), 沿列填至底(d037b0a7), 前景源像素(d037b0a7)

**依赖链**：两个矩形的位置和间隙宽度确定影响域的分界；源像素的列位置决定它落入哪个影响域（或中线）；影响域决定射线变色为哪种颜色。三层信息逐级约束最终输出，且影响域本身不可见——它只通过射线的颜色变化间接体现。

两个同行对齐矩形之间的间隙被逻辑对半分为两个影响域；从间隙上方落下的射线穿过左域变左色、穿过右域变右色，中线列射线保持原色。

**输入结构**：
- 黑(0)背景网格，约 14x16。
- 网格中部偏下：两个同高度、同行范围的实心单色矩形，水平并列，中间有宽度为 G（3~7）的黑色间隙。左矩形颜色为蓝(1)，右矩形颜色为红(2)。两个矩形高度相同（2~4 行），宽度相同（2~4 列）。
- 间隙上方（矩形上边界之上至少 3 行的区域）：散布若干黄(4)的孤立前景像素，每列最多一个。这些像素的列坐标全部落在间隙的列范围 [gap_left, gap_right] 之内。
- 生成约束：间隙列范围内至少有 3 个黄(4)源像素，分布在间隙的左半、右半和中线（若 G 为奇数）上各至少一个。G 为偶数时无中线列。

**规则**：
1. 确定左矩形的右边界列 c_L 和右矩形的左边界列 c_R。间隙列范围为 [c_L+1, c_R-1]，宽度 G = c_R - c_L - 1。
2. 将间隙列范围逻辑对半分：
   - 左半域 = 列 [c_L+1, c_L + floor(G/2)]（包含 floor(G/2) 列）。
   - 右半域 = 列 [c_R - floor(G/2), c_R-1]（包含 floor(G/2) 列）。
   - 若 G 为奇数，正中列 c_mid = c_L + 1 + floor(G/2) 既不属于左域也不属于右域，为中线列。
3. 对每个黄(4)源像素 (r_src, c_src)，向下延伸一条垂直射线，从 r_src 行开始一直到网格最后一行（包含 r_src 本身），规则如下：
   - 从 r_src 到矩形上边界行的前一行：射线颜色为黄(4)（保持源色）。
   - 从矩形上边界行开始到网格最后一行：
     - 若 c_src 在左半域内，射线颜色变为蓝(1)。
     - 若 c_src 在右半域内，射线颜色变为红(2)。
     - 若 c_src 在中线列上（G 为奇数时），射线颜色保持黄(4)不变。
   - 射线在经过矩形所在行时，不覆盖矩形本身的像素（矩形像素优先保留）。
4. 保留两个矩形的所有原始像素不变。

**关键洞察**：间隙的逻辑对半分在视觉上完全不可见——没有分隔线、没有填充色——它只通过射线在穿过矩形高度后的颜色突变来间接表达。求解者必须从射线颜色的规律反推出隐藏的空间分区规则。奇数间隙时中线射线不变色，是验证分区规则的关键线索。
