## 新题 2：负空间涌现滑件

**组合逻辑**：[透明叠加/逐像素比较](已有) → [共同背景标前景](创新：标出的前景不是最终输出，而是产生新的可滑动对象) → [滑动](创新：滑动对象不是输入中的原有图形，而是叠加运算涌现的负空间碎片) → [颜色匹配/同色滑向同色边](已有)

**来源原语**：透明叠加(94f9d214), 逐像素比较(94f9d214), 共同背景标前景(94f9d214), 滑动(17829a00), 颜色匹配(17829a00), 同色滑向同色边(17829a00), 碰撞停止(17829a00), 边界色条(17829a00), 掩码(94f9d214)

**依赖链**：叠加比较产生"共同空白区"对象——这些对象在任一输入半区中都不存在，只在比较后涌现。涌现对象的形状决定了滑动后的最终布局。若跳过叠加，无从知道哪些像素构成滑件；若跳过滑动，只得到中间掩码而非最终输出。

将上下两个掩码的共同空白区域标记为新对象，再将这些对象按颜色规则滑向匹配的边界色条。

**输入结构**：
- 黑(0)背景网格，约 14x14。
- 第一行：全宽的蓝(1)色条（边界色条）。
- 最后一行：全宽的红(2)色条（边界色条）。
- 中间区域被一条全宽的黄(4)分隔行分为上半区和下半区，上半区和下半区行数相同。
- 上半区：黑(0)背景上有若干绿(3)前景像素组成一个 4-连通图形。
- 下半区：黑(0)背景上有若干绿(3)前景像素组成另一个 4-连通图形，与上半区形状不同但占据的行列范围有重叠。
- 生成约束：两个半区的形状叠加后，"双方都是黑(0)"的区域能形成至少两个互不相邻的 4-连通区块，每个区块面积在 2~8 像素之间。

**规则**：
1. 将上半区和下半区逐像素比较（位置对应）。标记出两半区在同一位置都是黑(0)背景的单元格集合，称为"共同空白集"。
2. 将共同空白集中的像素按 4-连通性分为独立区块。
3. 对每个区块：计算其质心行坐标（所有像素行号的算术平均，四舍五入到最近整数）。若质心在该半区上半部分（质心行 < 半区行数 / 2），该区块被标记为蓝(1)；否则标记为红(2)。
4. 在一个与单个半区同尺寸的空白黑(0)画布上放置所有标记后的区块（保持各像素的原始相对位置）。
5. 蓝(1)区块整体向上滑动，直到其最上方像素到达画布第一行（紧贴上边界）。红(2)区块整体向下滑动，直到其最下方像素到达画布最后一行（紧贴下边界）。若多个同色区块滑动后会重叠，按原始质心距目标边界的距离从近到远依次放置，后放置的区块在碰到已放置区块时停止。
6. 输出该画布（不含边界色条和分隔行）。

**关键洞察**：可滑动的对象在输入中根本不存在——它们是两个掩码的"共同缺失"，只有通过逐像素比较才能发现。求解者需要先做减法（找负空间），再做物理运动（滑动），两步之间有因果依赖。
