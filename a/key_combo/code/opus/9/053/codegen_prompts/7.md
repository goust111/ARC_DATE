## 新题 7：标记交叉分区内对角色带同心填充

**组合逻辑**：[连线/标记展为整行整列](已有) → [行列交叉](创新：交叉线不仅是绘制对象，还将区域分割为子矩形) → [同心层填充](创新：不是填充整个框体，而是逐子矩形独立填充) → [对角序映射色环](创新：对角标记不是全局的，而是按空间归属分配给不同子矩形)

**来源原语**：连线/draw_line(8731374e), 标记展为整行整列(8731374e), 行列交叉(8731374e), 标记像素(8731374e), 矩形(8731374e), 同心层填充(99306f82), 对角序映射色环(99306f82), 嵌套层次(99306f82), 对角线标记(99306f82), 空心矩形框(99306f82), 裁剪(8731374e)

**依赖链**：标记像素的行列展开产生分割线 → 分割线将工作区切成子矩形 → 每个子矩形内部的对角单色点提供该区的色带调色板 → 色带按对角序从外到内填充。删除展开则无分区；删除对角点则无调色板；删除同心填充则无最终图案。分区结构同时决定了对角点的归属——同一个对角点落在不同分区中会产生不同结果。

标记像素展开为整行整列形成网格分区，每个分区内部按其包含的对角标记点的颜色序列进行同心层填充。

**输入结构**：
- 黑(0)背景网格，约 18x18。
- 一个灰(5)实心矩形占据网格的中央区域（约 14x14），作为工作区。
- 工作区内有 2~3 个标记像素，颜色为橙(7)，彼此不同行不同列。
- 工作区内另有若干单色单像素点（每个点颜色不同，从蓝(1)、红(2)、绿(3)、黄(4)、品红(6)中选取），这些点沿若干条从左上到右下的对角线排列（每条对角线上的点行号递增、列号递增、相邻点行差=列差=1）。不同对角线上的点颜色互不相同。
- 生成约束：橙(7)标记像素将工作区分割后，每个子矩形内至少有一条对角线上的 1~3 个单色点；每个子矩形的最短边至少 4 像素（确保能形成至少一层同心带）。对角线上的点不与橙(7)标记像素同行或同列。

**规则**：
1. 对每个橙(7)标记像素，将其所在的整行和整列（在工作区范围内）全部涂为橙(7)。这些橙色行/列将工作区分割为若干子矩形。
2. 对每个子矩形（由橙色行/列围成的区域，不含橙色行/列本身）：
   a. 收集该子矩形内部的所有对角标记点。
   b. 按对角方向排序：行号小的排前面；行号相同则列号小的排前面。
   c. 从外到内逐层填充同心矩形带：第一个点的颜色填最外层环，第二个点的颜色填次外层环，依此类推。最后一个点的颜色填充剩余的中心区域。
   d. 若对角点数量少于可填充的层数（层数 = min(子矩形半宽, 子矩形半高)，其中半宽 = ceil(宽/2)，半高 = ceil(高/2)），则最内层颜色向中心延伸填满。
   e. 若对角点数量多于可填充层数，多余的点忽略（只使用前"层数"个点的颜色）。
3. 保留所有橙(7)行/列像素不变。工作区外部保持黑(0)不变。
4. 对角标记点本身被同心填充覆盖（它们只是调色板信息，不保留在输出中）。

**关键洞察**：标记像素的行列展开同时完成两件事——绘制可见的橙色网格线，以及将空间分割为独立填充区域。对角标记点的空间归属由分割结果决定，同一组对角点在不同分割方案下会分配到不同子矩形、产生不同的填充结果。求解者必须先理解分区，再理解每个区的独立调色板。
