## 新题 4：投影重叠与标尺联合约束区域平铺

**组合逻辑**：[列投影重叠](已有) → [较长侧优先](已有) → [标尺长度决定重复](创新：标尺不控制自身附着图案的平铺，而是控制由投影重叠确定区域内的平铺行数) → [平铺](创新：平铺区域的列范围由投影重叠决定，行范围由较长侧+标尺长度共同决定)

**来源原语**：列投影重叠(770cc55f), 较长侧优先(770cc55f), 边缘线段(770cc55f), 分隔行(770cc55f), 标尺条(9c1e755f), 标尺长度决定重复(9c1e755f), 端部附着(9c1e755f), 瓦片图案(9c1e755f), 平铺(9c1e755f)

**依赖链**：投影重叠确定平铺的列范围和活动侧（上或下）；标尺长度确定瓦片重复行数；瓦片图案来自标尺端部。三个约束缺一不可——没有投影重叠则不知道填哪些列，没有较长侧判断则不知道填哪一侧，没有标尺则不知道重复几次。

两条边缘线段的列投影重叠确定填充的列范围，较长线段选择活动半区，标尺条的长度决定在该半区内将端部瓦片图案重复几行。

**输入结构**：
- 黑(0)背景网格，约 15x18。
- 第一行（顶行）：一条连续的蓝(1)水平线段，长度 L1（3~8 像素），起始列不固定。
- 最后一行（底行）：一条连续的蓝(1)水平线段，长度 L2（3~8 像素，L1 != L2），起始列不固定。
- 顶行与底行的列范围有部分重叠（重叠宽度至少 2 列）。
- 中间某一行是全宽红(2)分隔行，将上半区和下半区分开。
- 网格左侧或右侧边缘：一条垂直灰(5)标尺条，长度 R（2~5 像素）。在标尺条的一端（上端或下端）紧邻一个小矩形瓦片图案（1~3 行 x 重叠宽度列），由非黑非灰非红非蓝颜色组成（如绿(3)或黄(4)）。
- 生成约束：瓦片图案的列数等于顶行与底行的列投影重叠宽度；标尺长度 R 乘以瓦片行数不超过活动半区的可用行数。

**规则**：
1. 计算顶行线段与底行线段的列投影重叠区间 [c_left, c_right]。
2. 判断哪条线段更长：若 L1 > L2，活动半区 = 上半区（从顶行下方到分隔行上方）；若 L2 > L1，活动半区 = 下半区（从分隔行下方到底行上方）。L1 = L2 的情况不会出现（生成约束保证）。
3. 读取标尺条长度 R 和端部附着的瓦片图案 P。
4. 在活动半区内，沿重叠列范围 [c_left, c_right]，从靠近活动线段的一侧开始，将瓦片图案 P 沿行方向重复 R 次（每次紧接上一次，无间隔）。具体地：若活动半区在上方，从紧邻顶行线段的下一行开始向下铺 R 次 P；若在下方，从紧邻底行线段的上一行开始向上铺 R 次 P。
5. 活动半区内重叠列范围之外、以及非活动半区，均保持黑(0)背景不变。保留顶行线段、底行线段、分隔行、标尺条和原始瓦片图案不变。

**关键洞察**：平铺操作的三个参数（列范围、起始侧、重复次数）分别由三个不同的输入特征提供，没有一个特征能独立确定平铺结果；求解者必须同时归纳出三条子规则并将它们整合。
