## 新题 9：标记阈值擦除后归一化朝向排列

**组合逻辑**：[计数/标记包含于对象/标记超阈值则擦除](counting, marker_in_object, erase_above_threshold) → [擦除](erase) → [归一化朝向/宽高互换](normalize_orient, width_height_swap) → [排列](arrange)。源题中擦除和排列分别独立工作——擦除按标记数过滤对象，排列将所有矩形双份打包。这里擦除决定了哪些矩形参与排列，排列的维度计算依赖于擦除后的幸存集合，两者形成筛选-处理流水线。

**来源原语**：计数(counting) ← 8efcae92/a934301b；标记像素(marker_pixel) ← 8efcae92/a934301b；标记包含于对象(marker_in_object) ← a934301b；标记超阈值则擦除(erase_above_threshold) ← a934301b；擦除(erase) ← a934301b/a416fc5b；归一化朝向(normalize_orient) ← d749d46f；宽高互换(width_height_swap) ← d749d46f；排列(arrange) ← d749d46f；矩形(rectangle) ← d749d46f；前景对象(foreground_object) ← a934301b

**依赖链**：对每个矩形计数其内部标记像素 → 标记数 >= 2 的矩形被擦除 → 幸存矩形各自归一化朝向（长边水平） → 按原始左右顺序在新画布上顶对齐排列。去掉计数擦除则所有矩形参与排列、输出尺寸和内容均不同；去掉归一化则高矩形保持纵向、排列形状不同；去掉排列则幸存矩形仍散落在原位、无输出变换。

将含过多红色标记的矩形擦除后，把幸存矩形归一化为横向，按原始位置顺序排成一行输出。

**输入结构**：约 12x18 的网格。背景为黑(0)。网格上有 4~6 个分离的蓝(1)实心矩形（各矩形互不相邻，尺寸在 2x3 到 4x6 之间，有的宽大于高、有的高大于宽、有的为正方形）。部分矩形内部含有红(2)标记像素（替换了对应位置的蓝色像素），每个矩形内 0~3 个。生成约束：至少有一个矩形含 0 个标记、至少有一个含 1 个标记、至少有一个含 2 个或更多标记；擦除后至少幸存 2 个矩形。

**规则**：
1. 识别所有蓝(1)实心矩形（矩形内部的红(2)像素视为该矩形的一部分，不改变矩形边界）。
2. 对每个矩形，计数其内部红(2)标记像素的数量。
3. 擦除所有含 2 个或更多红色标记的矩形——将其全部像素（含蓝和红）恢复为黑(0)背景。保留含 0 或 1 个标记的矩形（其红色标记像素在幸存矩形中也保留）。
4. 对每个幸存矩形，归一化其朝向：若高度 > 宽度，将矩形顺时针旋转 90°（使其变为宽度 > 高度）。若已经是宽 >= 高，保持不变。旋转时矩形内部的红色标记像素一同旋转。
5. 按幸存矩形在输入中的原始位置从左到右排序（依据矩形边界框左上角的列坐标升序；列坐标相同时按行坐标升序）。
6. 在新的输出画布上，将排序后的归一化矩形从左到右依次排列，每两个矩形之间间隔 1 列黑(0)背景，所有矩形顶部对齐于第 0 行。输出画布高度 = 所有归一化矩形中的最大高度，宽度 = 所有归一化矩形宽度之和 + (矩形数 - 1) 个间隔列。

**关键洞察**：标记像素在本题中也承担双重角色——其数量决定矩形是否被擦除（过滤功能），而幸存矩形内部的标记像素又作为纹理细节被保留到最终输出中（内容功能）；擦除步骤改变了参与排列的矩形集合，进而改变了输出画布的尺寸和内容排布，两者不可分割。
