## 新题 1：标记计数选矩形 — 十字线环形填充

**组合逻辑**：[计数](counting) + [标记最多者选取](rectangle_with_most_markers_selected) → [连线/画布全长十字线](draw_line, canvas_spanning_cross) → [填充/偶数切比雪夫距离](fill, even_chebyshev_distance) → [原对象遮挡叠加](object_occludes_overlay)。计数与连线来自不同源题，这里计数结果决定十字线的唯一中心点，是源题中不存在的因果关系。

**来源原语**：计数(counting) ← 8efcae92；标记最多者选取(rectangle_with_most_markers_selected) ← 8efcae92；连线/画布全长十字线(draw_line, canvas_spanning_cross) ← 41e4d17e；偶数切比雪夫距离(even_chebyshev_distance) ← 759f3fd3；填充(fill) ← 759f3fd3；原对象遮挡叠加(object_occludes_overlay) ← 41e4d17e；空心矩形(hollow_rectangle) ← 41e4d17e；标记像素(marker_pixel) ← 8efcae92；中心对齐(center_alignment) ← 41e4d17e；交叉点中心(intersection_center) ← 759f3fd3

**依赖链**：标记计数从多个矩形中选出唯一目标 → 目标中心确定十字线位置 → 十字线交叉点成为切比雪夫距离原点 → 距离奇偶性决定哪些背景像素被填充 → 所有矩形轮廓层叠在填充和十字线之上。去掉计数步骤则中心点无法确定；去掉十字线则距离原点缺失；去掉遮挡规则则矩形被环形覆盖。

在所有蓝色空心矩形中，找到包含最多红色标记的那个，以其中心画出全幅十字线，再以该交叉点为圆心画出切比雪夫距离偶数环，最后将所有矩形轮廓绘制在最顶层。

**输入结构**：约 15x15 的网格。背景为青(8)。网格上散布 3~5 个蓝(1)空心矩形（单像素宽边框、内部为青(8)背景，尺寸在 3x3 到 6x6 之间，互不重叠且互不相邻）。部分矩形的内部含有若干红(2)标记像素（每个矩形内 0~4 个，分布不均）。生成约束：恰好有一个矩形的红色标记数严格最多（无平局）。

**规则**：
1. 对每个蓝(1)空心矩形，计数其内部（不含矩形边框本身）所含红(2)标记像素的数量。
2. 选出红色标记数最多的唯一矩形，将其边界框中心（向下取整）作为十字线中心 (cr, cc)。
3. 以中心 (cr, cc) 画一条贯穿整个网格的粉(6)水平线（占满该行所有列）和一条贯穿整个网格的粉(6)垂直线（占满该列所有行）。
4. 对每个非十字线、非蓝色矩形边框的像素 (r, c)，计算其到中心的切比雪夫距离 d = max(|r - cr|, |c - cc|)。若 d 为正偶数且该像素当前为青(8)背景，则将其重涂为黄(4)。
5. 将所有蓝(1)矩形轮廓像素和红(2)标记像素重新绘制在最顶层（覆盖下方的黄色填充和粉色十字线）。

**关键洞察**：环形填充的中心并非预先给定的几何特征，而是由分散在多个矩形内部的标记像素计数竞争产生的；必须先完成跨矩形的统计比较，才能确定几何变换的参数。
