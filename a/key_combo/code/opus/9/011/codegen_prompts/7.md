## 新题 7：引导掩码选纵条 — 障碍墙截断不对称延伸

**组合逻辑**：[引导掩码/包围框包含/唯一被框选对象](guide_mask, bbox_containment, uniquely_enclosed) → [延伸填充/距离控制高度/不对称递变](extension_fill, distance_controls_height, asymmetric_gradient) + 障碍截断（创新：将"障碍像素"从空间阻挡重新用作延伸的硬边界墙，其他纵条充当隐式障碍物）。源题中延伸填充无任何阻挡地向两侧生长，这里引入了选择性障碍和方向性截断，延伸形状由种子高度和障碍位置共同决定。

**来源原语**：引导掩码(guide_mask) ← bf699163；包围框包含(bbox_containment) ← bf699163；唯一被框选对象(uniquely_enclosed) ← bf699163；延伸填充(extension_fill) ← 5207a7b5；纵条(vertical_bar) ← 5207a7b5；距离控制高度(distance_controls_height) ← 5207a7b5；不对称递变(asymmetric_gradient) ← 5207a7b5；障碍像素(obstacle_pixel) ← 31adaf00

**依赖链**：引导掩码的包围框从多根纵条中选出种子纵条 → 种子高度 h 确定延伸公式 → 向左延伸 h+2d、向右延伸 h-2d → 非种子纵条充当墙壁，在其所在列截断延伸（该方向不再向更远处延伸） → 最终形状由种子属性和墙壁位置共同决定。去掉引导掩码则种子不确定；去掉延伸公式则变换消失；去掉墙壁截断则所有示例输出形状可由简单公式预测、无需推理阻挡。

从多根纵条中用引导掩码选出种子纵条，以其高度为基准向两侧不对称延伸，但延伸在遇到其他纵条时被截断。

**输入结构**：约 15x20 的网格。背景为黑(0)。从网格顶部边缘向下延伸 4~6 根灰(5)纵条，每根宽 1 像素，高度各不相同（3~10 像素），彼此间隔至少 3 列。若干黄(4)引导像素散布在网格中（不与任何纵条同列），它们的集体包围框恰好包含一根灰色纵条（不包含其他纵条）。生成约束：被选中的种子纵条左右两侧各至少有一根其他纵条作为墙壁；种子纵条不在网格最左列或最右列。

**规则**：
1. 收集所有黄(4)像素，计算其集体包围框。在该包围框内恰好有一根灰(5)纵条——此为种子纵条，高度 h，位于列 c0。
2. 向左延伸：对种子纵条左侧每一列（距离种子 d = 1, 2, 3, ...），从第 0 行向下涂青(8)色，涂满 min(h + 2d, 网格行数) 个像素。逐列向左扩展，直到遇到最近的一根灰(5)纵条所在列——该列本身不涂色，且不继续向更左延伸。
3. 向右延伸：对种子纵条右侧每一列（d = 1, 2, 3, ...），从第 0 行向下涂粉(6)色，涂满 max(h - 2d, 0) 个像素（结果为 0 时该列不涂色）。同样在遇到最近的灰(5)纵条时停止（该列不涂色，不继续向更右延伸）。右侧延伸也会因 h - 2d 递减到 0 而自然终止，两个终止条件取先到达的那个。
4. 所有灰(5)纵条保持不变（绘制在延伸色之上）。黄(4)引导像素在输出中保留。

**关键洞察**：延伸的最终轮廓不仅取决于种子纵条的高度（控制基础梯形形状），还取决于相邻纵条的位置（控制截断边界）——两者缺一不可；必须同时推断出不对称增长公式和墙壁截断规则才能正确预测输出。
