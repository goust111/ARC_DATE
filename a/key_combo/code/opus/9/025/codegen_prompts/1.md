## 新题 1：多源对角射线的交叉计数驱动角落三角形

**组合逻辑**：[射线延伸/对角方向](创新：多源点同时发射双对角线，交叉点成为涌现的计数目标) + [轨迹交叉](创新：不同源射线的重叠产生交叉标记) → [计数/计数决定尺寸](创新：按象限统计交叉点数量) → [填充/三角区域](创新：交叉计数驱动对应角落的三角形边长)

**来源原语**：
- 射线延伸(ray_extend)、对角方向(diagonal_dir)、过像素画双对角线(both_diags_through_pixel)、孤立像素(isolated_pixel)、画布边界(canvas_boundary) -- 623ea044
- 轨迹交叉(trail_intersection) -- ac605cbb
- 计数(counting)、计数决定尺寸(count_determines_size)、三角区域(triangle_region)、角落控制点(corner_control) -- 902510d5
- 擦除(erase) -- 902510d5

**依赖链**：多个孤立像素各自向四个对角方向发射射线至边界 → 不同源像素的射线在空间上交叉产生交叉点（涌现现象，任何单源都无法产生）→ 以网格中心为分界将交叉点按四个象限统计 → 每个象限的交叉点计数成为对应角落三角形的边长 → 角落控制标记被擦除并替换为三角形

输入中散布的孤立像素各自画出双对角线；由此涌现的交叉点被按象限计数，每个象限的计数转化为对应角落的实心直角三角形的边长。

**输入结构**：
- 黑(0)背景，约15x15的正方形网格
- 散布3~5个孤立前景像素，每个像素颜色从蓝(1)、红(2)、绿(3)中选取（允许同色重复），彼此不在同一行、同一列、同一条对角线上
- 网格四角(即(0,0)、(0,W-1)、(H-1,0)、(H-1,W-1))各有一个灰(5)像素作为角落控制标记
- 生成约束：所有孤立像素距网格边界至少2格；各像素位置保证四个象限中至少有三个象限包含交叉点；网格高和宽均为奇数，使中心行和中心列唯一确定

**规则**：
1. 对每个孤立前景像素，沿四个对角方向（左上、右上、左下、右下）画射线至网格边界，射线颜色为该像素自身的颜色。射线覆盖经过的每个像素；若该像素已有颜色（来自其他射线），后绘制的覆盖先绘制的
2. 射线全部绘制完成后，标记交叉点：逐像素检查，若某个像素同时被来自两个或以上不同源像素的射线经过（不论最终显示什么颜色），则该像素为交叉点，将其重涂为黄(4)
3. 以网格中心行和中心列为分界线，将网格划分为四个象限（左上、右上、左下、右下）；中心行和中心列上的交叉点不计入任何象限
4. 分别统计四个象限内的黄(4)交叉点数量，记为 N_左上、N_右上、N_左下、N_右下
5. 擦除四角的灰(5)标记像素（恢复为黑(0)）
6. 在每个角落绘制边长为对应N值的实心直角三角形，颜色为橙(7)：直角顶点在角落像素处，两条直角边分别沿该角落的两条网格边界方向延伸。三角形区域定义为：从角落出发，行距离r与列距离c满足 r+c < N 的所有像素。若N=0则不绘制
7. 三角形像素覆盖该区域内已有的任何颜色（射线色、交叉点色）

**关键洞察**：交叉点不存在于输入中——它们是多条对角射线叠加后的涌现结构。求解者必须先绘制所有射线并追踪每个像素被哪些源经过，才能识别交叉点、完成象限计数、最终确定三角形尺寸。
