## 新题 3：十字标记臂色频次筛选生成桥接控制序列

**组合逻辑**：[图案识别/计数](创新：十字标记的臂色频次筛选出有效标记子集) → [重排](创新：有效标记按空间位置排列为控制序列) → [连线桥/bridge_drawing](创新：桥色由出发标记的臂色决定，非固定色)

**来源原语**：
- 十字标记(plus_marker)、图案识别(pattern_recognition)、计数(counting)、重复色为答案(repeated_color_answer)、忽略干扰项(ignore_distractors)、中心与臂颜色(center_and_arm_color) -- 642d658d
- 连线桥(bridge_drawing)、带框方块(framed_square)、控制序列(control_sequence)、访问顺序编码(visitation_order_encoding)、行列对齐(row_column_alignment)、最近优先(nearest_preferred) -- 3e6067c3
- 擦除(erase) -- df8cc377

**依赖链**：识别所有黄心十字标记并统计各臂色出现次数 → 出现次数>=2的臂色为有效色，对应标记被保留 → 保留标记按列坐标排序形成控制序列 → 按序列顺序在上半区的带框方块之间画桥 → 干扰标记被擦除

带框方块散布在网格上半部分，十字标记散布在下半部分；识别出臂色重复出现的十字标记后，按其列位置从左到右排列成控制序列，依次连接内部色匹配的带框方块。

**输入结构**：
- 黑(0)背景，约18x18网格
- 上半区（前9行）：4~5个带框方块，每个3x3像素（含边框），边框为灰(5)，内部1x1像素为各不相同的填充色，从蓝(1)、红(2)、绿(3)、橙(7)、栗(9)中选取；方块之间互不接触
- 下半区（后9行）：6~8个十字标记，每个由黄(4)中心像素和四个正交相邻的同色臂像素组成；臂色从蓝(1)、红(2)、绿(3)、橙(7)、栗(9)中选取（同色可出现在多个标记中）；标记之间互不重叠
- 生成约束：恰好有2~3种臂色出现在2个或以上十字标记中（有效色），其余臂色各只出现1次（干扰项）；每种有效色恰好匹配上半区一个带框方块的内部填充色；各十字标记的中心列坐标互不相同

**规则**：
1. 识别所有十字标记：黄(4)中心像素且四个正交邻居存在且颜色相同（非黑非黄）
2. 统计每种臂色出现在多少个十字标记中。出现次数>=2的臂色为"有效色"
3. 擦除所有臂色非有效色的十字标记（将其5个像素恢复为黑(0)）
4. 将保留的十字标记按中心列坐标从小到大排序，读取臂色形成控制序列 [c1, c2, ..., ck]
5. 按控制序列依次连接带框方块：对每对相邻颜色 (ci, ci+1)，找到内部填充色为 ci 的方块 Si 和内部填充色为 ci+1 的方块 Si+1
6. 在 Si 与 Si+1 之间画桥：比较两方块中心的行差和列差，选择差值较小的维度作为桥的延伸方向（若行差<=列差则画水平桥，否则画垂直桥）；桥为1像素宽的直线段，颜色为 ci，连接两方块边框之间的间隙部分
7. 若同一方块被多次访问，多条桥可连接到该方块的不同边

**关键洞察**：十字标记既是待识别的图案对象，又是隐式的控制指令编码器。干扰标记的存在迫使求解者先通过频次统计完成筛选，才能从保留标记的空间排列中读取桥接顺序——跳过识别步骤则无法确定控制序列。
