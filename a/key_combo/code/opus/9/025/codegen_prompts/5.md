## 新题 5：精灵体按尺寸嵌入空腔后标记像素的切比雪夫连接

**组合逻辑**：[嵌入填充/尺寸匹配/唯一槽位配对](已有) → [连线/切比雪夫最短路径](创新：连接端点是嵌入操作后重新定位的标记像素) → [重涂色](创新：每段路径颜色由出发端标记所在精灵体的主体色决定)

**来源原语**：
- 嵌入填充(inlay_fill)、模板框架(template_frame)、精灵体(sprite)、矩形空腔(rectangular_cavity)、尺寸匹配(size_matching)、唯一槽位配对(unique_slot_pairing) -- 5dbc8537
- 连线(connect)、路径(path)、起终点之间(between_endpoints)、切比雪夫最短路径(chebyshev_shortest) -- 992798f6
- 标记像素(marker_pixel) -- ac605cbb
- 重涂色(recolor) -- 7e02026e

**依赖链**：识别模板框架中的矩形空腔及外部精灵体 → 按尺寸一一匹配将精灵体嵌入空腔 → 嵌入改变了精灵体内标记像素的绝对坐标 → 以嵌入后的标记像素新坐标为端点，沿切比雪夫最短路径依次连线 → 每段路径颜色取自出发端标记所在精灵体的主体色

模板框架中的矩形空腔与外部精灵体按尺寸一一匹配后嵌入；每个精灵体内含一个黄色标记像素；嵌入后标记像素获得新坐标，依次以切比雪夫最短路径连接相邻标记，路径颜色取自出发端精灵体的主体色。

**输入结构**：
- 黑(0)背景，约18x20网格
- 网格中央偏左有一个灰(5)大型模板框架（约10x12的实心灰色区域），内部包含3个矩形空腔（黑(0)区域），尺寸各不相同（如2x3、3x2、2x4等，高x宽）
- 模板框架外侧（右方或下方）有3个矩形精灵体，每个由一种主体色填充（分别为蓝(1)、红(2)、绿(3)，各不相同），尺寸分别与三个空腔一一匹配
- 每个精灵体内恰好有1个像素为黄(4)（标记像素），其余像素为该精灵体的主体色
- 生成约束：精灵体与空腔的尺寸匹配唯一确定；三个空腔在模板内从上到下排列（上方空腔的最高行 < 下方空腔的最高行），保证连接顺序明确

**规则**：
1. 识别灰(5)模板框架的边界框（最小包围所有灰像素的矩形），以及框架内部的黑(0)矩形空腔（四连通黑色区域，且四周被灰色像素包围）
2. 识别模板外部的精灵体：框架边界框外的非黑非灰四连通区域，每个区域的边界框尺寸即为精灵体尺寸
3. 将每个精灵体与尺寸完全匹配的空腔配对，然后将精灵体的所有像素（含黄色标记）平移嵌入空腔的左上角对齐位置
4. 嵌入完成后，找到三个黄(4)标记像素的新坐标，按行坐标从小到大排序为 P1、P2、P3
5. 对每对相邻标记 (Pi, Pi+1) 画切比雪夫最短路径（king-move路径）：先沿对角方向（同时缩小行差和列差）移动 min(|delta_row|, |delta_col|) 步，再沿剩余轴直线移动补足差值
6. P1到P2的路径颜色为P1所在精灵体的主体色；P2到P3的路径颜色为P2所在精灵体的主体色
7. 路径像素仅绘制在黑(0)背景像素上；若路径需经过非背景像素（灰边框或精灵体内部像素），该像素颜色不变，路径跳过该像素继续绘制后续步
8. 输出保留完整的模板框架、嵌入后的精灵体及连接路径

**关键洞察**：精灵体嵌入空腔后标记像素的坐标发生了不可预测的变化，连接路径的走向完全依赖于嵌入结果——求解者不能在嵌入前预判路径，必须先完成匹配和嵌入才能确定标记的最终位置。
