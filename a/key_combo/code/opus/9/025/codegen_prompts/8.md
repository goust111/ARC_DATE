## 新题 8：完整对称图案的壳色远程决定虚线段间隙填充颜色

**组合逻辑**：[补全/形状匹配](创新：完整图案不再补全局部拷贝，而是作为颜色参数的远程提供者) → [填充/单像素间隙补填](创新：间隙填充颜色不固定，由最近完整图案的壳色动态指定) → [擦除](创新：完整图案完成颜色传递后从输出中移除)

**来源原语**：
- 补全(completion)、对称图案(symmetric_motif)、模板精灵体(template_sprite)、形状匹配(shape_match)、完整图案推断缺失(motif_infers_missing) -- 72322fa7
- 填充(fill)、虚线段(dashed_segment)、邻接(adjacency)、单像素间隙补填(single_gap_filled) -- a699fb00
- 擦除(erase) -- 902510d5
- 标记像素(marker_pixel) -- ac605cbb

**依赖链**：识别完整3x3对称图案（中心色+壳色+壳掩码）→ 每条水平虚线段寻找距自身最近的完整图案 → 取该图案的壳色作为间隙填充色 → 填充虚线段中的所有单像素间隙 → 最后擦除所有完整图案

水平虚线段中的单像素黑色间隙需要补填，但补填颜色不固定——每条虚线段取其最近的完整对称图案的壳色作为填充色；填充完成后所有图案从输出中消失。

**输入结构**：
- 黑(0)背景，约15x20网格
- 3~4条水平虚线段，每条由同一种颜色的前景像素水平排列组成（颜色从蓝(1)、绿(3)、橙(7)中选取），相邻同色像素之间间隔恰好1格黑(0)像素；不同虚线段颜色可相同也可不同；每条虚线段包含5~11个像素位置（含间隙）
- 2~3个完整的3x3对称图案散布在网格中，与虚线段不重叠不相邻：每个图案有1个中心像素和至少4个对称分布的壳像素（壳像素在中心的正交和/或对角邻居位置，满足四重旋转对称或双轴镜像对称）；中心色为灰(5)，不同图案的壳色各不相同，从红(2)、黄(4)、品红(6)中选取
- 生成约束：每条虚线段有唯一最近的完整图案（按虚线段中间像素到图案中心的曼哈顿距离，无平局）；壳色与任何虚线段自身颜色不相同

**规则**：
1. 识别所有完整3x3对称图案：灰(5)中心像素周围有至少4个同色非灰非黑壳像素，壳像素位置关于中心满足四重旋转对称或双轴镜像对称
2. 识别所有水平虚线段：同色非黑像素沿水平方向排列，相邻同色像素之间恰好间隔1格黑(0)像素，虚线段至少包含3个同色像素
3. 对每条虚线段，确定其中间像素的坐标（虚线段所有像素按列排序后取中间位置的像素），计算该坐标到每个完整图案中心的曼哈顿距离，取距离最小的图案
4. 读取该最近图案的壳色，将虚线段中所有单像素黑(0)间隙（左邻和右邻都是虚线段同色像素的黑像素）填为该壳色
5. 所有虚线段处理完毕后，擦除所有完整图案（将图案占据的9个像素全部恢复为黑(0)）
6. 输出保留虚线段原始像素、间隙填充像素及其他未涉及的背景像素

**关键洞察**：完整对称图案在输出中完全消失——它们的唯一作用是为附近的虚线段远程提供间隙填充颜色。图案是"一次性颜色指令"：求解者必须先识别图案并提取壳色，再通过距离匹配确定每条虚线段的归属，最后才能执行填充和擦除。
