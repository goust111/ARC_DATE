## 新题 2：反弹射线穿越空心矩形激活方向敏感的棋盘格填充

**组合逻辑**：[射线延伸/反弹路径/边界反射](已有) → [包含判定](创新：射线是否穿过矩形内部作为激活条件) → [填充/棋盘格图案](创新：棋盘格的两色排列由射线进入矩形时的水平运动方向决定)

**来源原语**：
- 反弹路径(bouncing_path)、边界反射(boundary_reflection)、起点像素(start_pixel) -- e179c5f4
- 空心矩形(hollow_rect)、棋盘格图案(checkerboard)、包含(containment) -- df8cc377
- 填充(fill) -- a699fb00
- 重涂色(recolor) -- 7e02026e

**依赖链**：起点像素发射反弹对角射线 → 射线在网格边界间来回弹跳 → 射线路径穿过某些空心矩形的内部区域 → 被穿过的矩形被"激活"→ 射线首次进入每个矩形内部时的水平分量方向（向右或向左）决定棋盘格的起始颜色排列

一条从起点像素出发的反弹对角射线在网格边界间往复弹跳；射线穿过空心矩形内部即激活该矩形，在其内部填入棋盘格图案，棋盘的颜色排列由射线进入时的水平方向决定。

**输入结构**：
- 黑(0)背景，约20x20网格
- 一个蓝(1)像素作为起点，位于网格中不属于任何矩形的位置
- 3~4个不重叠的空心矩形，边框为灰(5)，边框厚度1像素，内部为黑(0)；每个矩形的内部高和宽均为奇数（3~7像素），保证存在中心格
- 生成约束：矩形之间至少间隔2格；起点不在任何矩形的内部或边框上；反弹射线路径至少穿过2个矩形的内部，且至少有1个矩形未被穿过

**规则**：
1. 从蓝(1)起点像素出发，初始方向为右上（行-1，列+1），逐步画蓝(1)射线
2. 射线到达网格左或右边界时水平方向反转；到达上或下边界时垂直方向反转；到达角落时水平和垂直方向同时反转。射线在经过的每个像素上画蓝(1)，但不改变灰(5)边框像素的颜色
3. 射线遇到灰(5)矩形边框像素时穿透继续（不视为反射壁），仅在网格四边反射
4. 射线行进至路径回到起点位置时停止；若路径长度超过200步仍未回到起点，也停止
5. 判定每个空心矩形是否被激活：若射线路径中至少有一个像素落在该矩形的内部（不含边框），则该矩形被激活
6. 对每个被激活的矩形，确定射线首次进入其内部时的水平运动方向：
   - 若该步水平分量向右（列坐标增大），则棋盘格A模式——内部左上角格为红(2)，与之行列坐标奇偶性相同的格为红(2)，不同的格为绿(3)
   - 若该步水平分量向左（列坐标减小），则棋盘格B模式——内部左上角格为绿(3)，与之行列坐标奇偶性相同的格为绿(3)，不同的格为红(2)
7. 棋盘格仅填充矩形内部中射线未经过的黑(0)像素；射线经过的内部像素保持蓝(1)
8. 未被激活的矩形保持原样（内部全黑）

**关键洞察**：反弹射线的几何轨迹同时编码了两类信息——"哪些矩形被激活"和"以什么颜色排列填充"——这两个判定不可分离，因为它们都取决于射线穿越矩形的具体路径段。
