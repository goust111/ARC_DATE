## 新题 7：格线缺失交叉点定位数据区后列像素计数构建金字塔

**组合逻辑**：[裁剪/背景色空洞/四角围合](已有) → [计数/提取](创新：裁剪区内前景像素按列统计，计数值编码金字塔参数) → [堆叠/居中金字塔/奇数宽度递增](创新：列计数拆解为1+3+5+...序列构建底部对齐的并排金字塔)

**来源原语**：
- 裁剪(crop)、网格线(lattice_line)、缺失交叉点(missing_intersection)、四角围合(four_corner_bound)、背景色空洞(background_hole) -- a644e277
- 堆叠(stack)、居中金字塔(centered_pyramid)、基线对齐(baseline_aligned)、奇数宽度递增(odd_width_increment)、前景列像素(column_pixels) -- 3d6c6e23
- 计数(counting) -- 642d658d
- 纯色单元格(solid_cell)、格内判定(cell_interior_test) -- 458e3a53

**依赖链**：在格线网格中找到四个背景色空洞交叉点 → 确定裁剪矩形 → 裁剪区内的格线单元格包含前景像素 → 按单元格列统计每列的前景像素总数（必须为完全平方数）→ 分解为1+3+5+...奇数行宽序列 → 在输出中底部对齐并排构建金字塔

格线网格中四个背景色空洞标定裁剪区域；区域内各列的前景像素总数为完全平方数，分解为奇数宽度行序列后在输出底部构建并排金字塔。

**输入结构**：
- 黑(0)背景，约17x17网格
- 灰(5)色格线形成规则网格：水平线和垂直线均为1像素宽，间距为3（即每两条相邻平行线之间有2像素宽的单元格空间）；格线将网格分割为多个2x2像素的单元格
- 大部分格线交叉点（水平线与垂直线的交汇像素）为灰(5)，但恰好4个交叉点为黑(0)（背景色空洞），这4个点构成一个轴对齐矩形的四角
- 该矩形围定区域内的部分单元格含有前景像素，颜色从蓝(1)、红(2)、绿(3)中选取；同一单元格列内所有前景像素颜色相同
- 生成约束：裁剪区域包含2~4列单元格；每列中前景像素的总数为完全平方数（1、4或9）；不同列可以有不同的平方数和不同的颜色

**规则**：
1. 识别灰(5)格线的所有交叉点：同时属于某条水平线和某条垂直线的灰像素
2. 找到其中4个为黑(0)的交叉点位置，确定它们围成的矩形的行范围和列范围
3. 裁剪该矩形（含边界格线）内的所有内容
4. 在裁剪区内，按单元格列逐列扫描（从左到右），统计每个单元格列j中所有前景像素（非黑非灰）的数量Nj和颜色Cj
5. 对每列计算金字塔层数 Lj = sqrt(Nj)（Nj保证为完全平方数）
6. 构建输出网格：
   - 输出高度 = max(Lj)（所有列中最高的金字塔层数）
   - 每个金字塔的最大底行宽度 = 2*Lj - 1；金字塔之间有1列黑(0)间隔
   - 输出宽度 = 所有金字塔底行宽度之和 + (列数-1) 个间隔列
7. 对第j列金字塔（Lj层），从底部第1行开始：底行宽度2*Lj-1居中绘制，第2行宽度2*Lj-3居中绘制，...，顶行宽度1；颜色为Cj
8. 所有金字塔底部对齐，按原始裁剪区中的列顺序从左到右排列

**关键洞察**：缺失交叉点不是视觉缺陷而是数据区域的定位标记；数据区域内的像素数量编码了金字塔的结构参数——这层编码关系只有在完成裁剪并统计后才能被发现和利用。
