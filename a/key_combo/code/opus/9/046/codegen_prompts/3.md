## 新题 3：半区异或生成中间标记场，标记的边界状态决定扩展行为

**组合逻辑**：[异或合成](已有) → [中间标记场生成](创新) → [边界标记 → 连线 | 内部标记 → 光环扩展](创新分支，来自已有操作)

**来源原语**：异或合成(xor_compositing)、半区掩码(half_mask)、恰一为前景(exactly_one_foreground) 来自 31d5ba1a；连线(draw_line)、边界定位(boundary_pos)、边界标记定贯穿线(boundary_marker_span) 来自 6cdd2623；邻域扩展(neighborhood_expand)、光环区域(halo_region)、仅填背景格(only_fill_background) 来自 dc1df850

**依赖链**：异或合成是中间计算，产出标记场 → 每个标记的网格边界位置决定它的行为分支（贯穿线 vs. 光环扩展）。异或不是最终输出而是生成下一步操作的输入数据；没有异或就没有标记来源，没有边界/内部分支就不知道如何处理标记。

一句话总结：将上下两半区前景掩码做异或得到中间标记；位于输出网格边界上的标记投射贯穿线，其余标记展开光环。

**输入结构**：偶数行高的网格（例如 10x10 或 12x10），黑(0)背景。上半区包含一组蓝(1)前景像素组成的图案，下半区包含一组绿(3)前景像素组成的图案。两半区高度相同、宽度相同。两个图案各为若干不规则的 4-连通色块，有部分位置重叠、部分不重叠。生成约束：异或结果（恰一为前景的位置）中，至少有 1 个位于半区尺寸网格的边界上，至少有 2 个位于内部；异或结果的像素总数不超过 8 个。

**规则**：
1. 将上半区和下半区按位置对齐，计算对称差（异或）：位置 (r,c) 为"异或阳性"当且仅当上半区 (r,c) 和下半区 (r,c) 中恰好有一个为前景色。
2. 构建与半区同尺寸（宽同输入、高为输入高度的一半）的全黑(0)输出网格。在每个异或阳性位置放置一个红(2)标记像素。
3. 对每个处于输出网格边界上的红(2)标记（第 0 行、最后一行、第 0 列、最后一列）：若位于上/下边界，绘制一条贯穿该列全高的垂直线，颜色黄(4)；若位于左/右边界，绘制一条贯穿该行全宽的水平线，颜色黄(4)。若标记同时在角落（属于两条边界），则同时绘制水平和垂直两条线。
4. 对每个不在输出网格边界上的红(2)标记：将其 Chebyshev 距离为 1 的邻域（3x3 区域）内所有黑(0)格涂为橙(7)，不覆盖已有的红(2)标记或黄(4)线像素。
5. 所有红(2)标记像素保留。黄(4)线先于橙(7)光环绘制；光环不覆盖线。

**关键洞察**：异或不是答案而是中间产物——它生成一个标记场，每个标记的处理方式取决于它在输出网格中的空间位置类型（边界 vs. 内部），形成一个由位置驱动的行为分支。

## 实现要求

1. `main(grid)` 必须实现新题描述中的确定性转换规则，不能只识别 `generate_input()` 的固定模板。禁止不同的input网格输出相同的output网格。
2. `generate_input()` 必须随机生成多样样例，不能固定死。随机维度应覆盖：网格大小、对象数量、位置、颜色、方向、形状参数或关键分支。注意若描述中存在若干，需实现而不是只有单个，包括object或者对应关系等等。且若涉及到最短路径，则输入网格中必涉及到多条路径，对选择造成干扰。
3. 生成器必须保证输入满足 `main()` 的隐式假设：对象不重叠、不越界、特殊标记唯一或可区分、匹配关系无歧义、关键分支出现概率相同。
4. 禁止把 ARC 颜色 id 、亮度、拼写等当作人类不可见的数值语义参与排序、大小比较或隐藏映射。颜色变化必须有可见结构线索。注意颜色亮度、拼写等也是不可见信息，若描述中出现违规的颜色id或者亮度，可自行使用少量的固定颜色替代，但注意生成时要在三个以内输入输出网格中对所有变换100%覆盖度。

6. 若规则有多个分支，生成器不能长期固定成一个分支；应让分支在随机样例中合理出现。分支概率不必平均——难以发现的隐蔽分支（如少数情况下才触发的特殊规则）应适当提高出现概率，确保在 3 个训练示例中至少出现一次，否则求解者无法归纳该规则。对于颜色映射类规则，确保 2 个左右的示例即可覆盖所有映射关系（每种颜色→颜色的映射至少在某个示例中出现过）。
