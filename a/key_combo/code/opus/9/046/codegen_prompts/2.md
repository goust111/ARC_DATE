## 新题 2：精灵体对称类型同时决定目标槽位与反射轴

**组合逻辑**：[对称类型分类](已有) → [对称类型决定槽位](创新，替代标记选槽) + [跨轴反射](已有，轴由分类结果确定) → [印章覆盖](已有)

**来源原语**：对称类型决定颜色(symmetry_det_color)、单像素为噪声(singleton_noise) 来自 a09f6c25；印章覆盖(stamp)、槽位(slot)、分区(partition)、标记选槽接收精灵(marker_selects_slot_for_sprite) 来自 363442ee；镜像(mirror)、跨轴反射(reflection_across_axis) 来自 88207623

**依赖链**：对称类型分类 → 同时决定 (a) 精灵体被路由到哪个槽位、(b) 精灵体沿哪个轴进行反射。分类结果承载双重功能：路由键与变换指令。删除分类步骤，则既不知道目标槽位也不知道反射轴；删除反射或印章，则分类无下游用途。

一句话总结：将左侧面板中的精灵体按其反射对称类型路由到右侧对应槽位，并在放入前沿自身对称轴做一次反射。

**输入结构**：约 15x18 网格，黑(0)背景。一条灰(5)竖直分隔列将网格分为左右两个面板。左面板包含 3 个单色 4-连通精灵体（各 3-8 像素），颜色互不相同，分别取自红(2)、蓝(1)、绿(3)。右面板被两条灰(5)水平分隔行等分为三个高度相同的槽位（从上到下依次为槽 A、槽 B、槽 C），每个槽位初始为全黑(0)。生成约束：三个精灵体恰好具有三种不同的反射对称类型——水平轴对称、垂直轴对称、对角轴对称各一个；每个精灵体的边界框完全位于槽位的可容纳区域内。

**规则**：
1. 对左面板的每个精灵体，判定其唯一的反射对称类型：水平轴对称、垂直轴对称或对角轴对称。
2. 水平轴对称的精灵体 → 路由至槽 A（最上方）；垂直轴对称 → 槽 B（中间）；对角轴对称 → 槽 C（最下方）。
3. 将每个精灵体沿其自身的对称轴进行反射，得到反射后的图形。
4. 将反射后的精灵体印章到目标槽位中，水平和垂直均居中对齐于槽位区域。保留精灵体的原始颜色。
5. 保留灰(5)分隔列和分隔行。左面板的原始精灵体保持不变。

**关键洞察**：对称类型承担双重角色——它既是路由键（决定去哪个槽），又是变换指令（决定沿哪条轴反射）。求解者无法将分类与反射解耦为两个独立步骤，因为同一个分析结果同时驱动两个不同的下游效果。
