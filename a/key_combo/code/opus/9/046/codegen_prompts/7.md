## 新题 7：奇偶棋盘过滤的克罗内克自展开与色彩翻转

**组合逻辑**：[二值掩码提取 + 克罗内克自积](已有) → [棋盘格奇偶过滤](创新条件) + [重涂色：奇偶决定颜色互换](创新)

**来源原语**：像素放大(pixel_scaling)、印章覆盖(stamp_overlay)、控制像素(control_pixel)、格位映射(cell_block_mapping)、递归印章(recursive_stamp) 来自 cce03e0d；二值掩码(binary_mask)、自相似嵌套(self_similar_nest)、掩码克罗内克自积(kronecker_self) 来自 80af3007；棋盘格图案(checkerboard_pattern) 来自 80a900e0；重涂色(recolor) 来自 a09f6c25 / 85c4e7cd

**依赖链**：掩码提取 → 克罗内克展开确定哪些宏块应有内容 → 棋盘奇偶过滤进一步筛选可活跃的宏块 → 偶位宏块保持原色、奇位宏块颜色互换。四步之间每一步的输出决定下一步的行为：掩码给出结构，克罗内克给出分形，棋盘给出筛选，奇偶给出色变——任意一步被删除都得到不同（错误的）输出。

一句话总结：将一个双色小精灵体做克罗内克自积展开，但只在宏块坐标和为偶数的位置放置原色副本、坐标和为奇数的位置放置双色互换副本，其余宏块留空。

**输入结构**：小网格（4x4 至 5x5），黑(0)背景。包含一个边界框恰好为 NxN（N=3 或 4）的精灵体，使用两种非背景色：红(2)和蓝(1)。精灵体边界框内至少有 3 个像素为红(2)、至少有 2 个像素为蓝(1)，其余为黑(0)。生成约束：精灵体边界框的位置位于输入网格的左上角对齐。

**规则**：
1. 提取精灵体的 NxN 边界框作为掩码 M，其中每个格为红(2)、蓝(1)或黑(0)。
2. 构建 (N*N) x (N*N) 的全黑(0)输出网格，划分为 NxN 个 NxN 大小的宏块。
3. 对宏块坐标 (i, j)（0-indexed），若 M[i][j] 不是黑(0)（即该格在掩码中是精灵体的一部分）：
   - 若 (i + j) 为偶数：将该宏块填入 M 的原色副本（红保持红，蓝保持蓝）。
   - 若 (i + j) 为奇数：将该宏块填入 M 的颜色互换副本（红(2) ↔ 蓝(1)互换，黑(0)仍为黑(0)）。
4. 若 M[i][j] 是黑(0)，则该宏块保持全黑(0)，无论 (i+j) 的奇偶性。

**关键洞察**：输出既不是纯克罗内克自积，也不是纯棋盘——而是两者的交集再叠加颜色翻转规则。求解者需要同时发现三层结构：哪些宏块被激活（由掩码决定）、激活的宏块中哪些保持原色/哪些互换（由坐标奇偶决定）、以及宏块内部的内容（掩码自身）。
