## 新题 8：擦除单像素噪声后镜像补全空白半区

**组合逻辑**：[擦除 · 单像素为噪声](已有) → [清洗后的下半区](中间产物) → [镜像 · 对称补全 · 空白半区补全](已有，但输入经过清洗)

**来源原语**：擦除(erase)、单像素为噪声(singleton_noise) 来自 a09f6c25；镜像(mirror)、对称补全(symmetry_complete)、半区(half_panel)、翻转对称(flip_symmetry)、空白半区补全(fill_blank_half) 来自 f25ffba3

**依赖链**：擦除步骤移除单像素噪声 → 清洗后的下半区成为镜像的数据源 → 上半区由清洗结果的行序翻转填充。如果不擦除噪声，镜像会将噪声像素也复制到上半区，产生错误输出；如果不镜像，擦除本身无法填充空白半区。两步之间存在真实的数据依赖：擦除改变了镜像的输入内容。

一句话总结：先识别并移除下半区中的单像素噪声，再将清洗后的下半区翻转填入空白的上半区。

**输入结构**：偶数行高的网格（如 12x10 或 14x10），黑(0)背景。上半区（前一半行）完全为黑(0)。下半区包含若干多像素 4-连通前景色块（颜色取自蓝(1)、绿(3)、黄(4)、橙(7)等，可有多种颜色），以及 2-4 个孤立的单像素前景点（颜色可与多像素色块相同或不同），散布在下半区各处。生成约束：所有多像素色块的边界框位于下半区内部（不紧贴半区分界线），确保镜像后不会溢出上半区；单像素噪声不与任何多像素色块 4-连通相邻。

**规则**：
1. 在下半区中识别所有 4-连通前景分量。
2. 将像素数为 1 的分量（单像素噪声）设为黑(0)（擦除）。
3. 将清洗后的下半区按行序翻转（最后一行变为第一行、倒数第二行变为第二行...），生成上半区内容。
4. 将翻转结果填入上半区。下半区保持清洗后的状态（噪声已移除）。

**关键洞察**：空白上半区不是下半区的直接镜像——而是去噪后下半区的镜像。单像素噪声是陷阱：直接镜像会产生对称但错误的输出，求解者必须先识别噪声规则（单像素 = 噪声）再执行镜像。

## 实现要求

1. `main(grid)` 必须实现新题描述中的确定性转换规则，不能只识别 `generate_input()` 的固定模板。禁止不同的input网格输出相同的output网格。
2. `generate_input()` 必须随机生成多样样例，不能固定死。随机维度应覆盖：网格大小、对象数量、位置、颜色、方向、形状参数或关键分支。注意若描述中存在若干，需实现而不是只有单个，包括object或者对应关系等等。且若涉及到最短路径，则输入网格中必涉及到多条路径，对选择造成干扰。
3. 生成器必须保证输入满足 `main()` 的隐式假设：对象不重叠、不越界、特殊标记唯一或可区分、匹配关系无歧义、关键分支出现概率相同。
4. 禁止把 ARC 颜色 id 、亮度、拼写等当作人类不可见的数值语义参与排序、大小比较或隐藏映射。颜色变化必须有可见结构线索。注意颜色亮度、拼写等也是不可见信息，若描述中出现违规的颜色id或者亮度，可自行使用少量的固定颜色替代，但注意生成时要在三个以内输入输出网格中对所有变换100%覆盖度。
5. 输出样例要视觉清晰，人类必须能从输入输出对中肉眼辨认出规律。具体要求：避免对象粘连、覆盖关系混乱、同一像素多重语义；不同逻辑步骤产生的结果不要大面积层叠在一起导致无法分辨哪个颜色属于哪个步骤；输入中各元素之间保持足够间距，输出中新增的标记/填充/路径等应与背景和已有元素在颜色上有明显区分；若规则涉及多层叠加，生成时控制对象密度和尺寸，确保叠加区域只占少数像素而非铺满整个网格。
6. 若规则有多个分支，生成器不能长期固定成一个分支；应让分支在随机样例中合理出现。分支概率不必平均——难以发现的隐蔽分支（如少数情况下才触发的特殊规则）应适当提高出现概率，确保在 3 个训练示例中至少出现一次，否则求解者无法归纳该规则。对于颜色映射类规则，确保 2 个左右的示例即可覆盖所有映射关系（每种颜色→颜色的映射至少在某个示例中出现过）。
