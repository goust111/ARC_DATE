## 新题 5：边缘链排序驱动环形色轮换

**组合逻辑**：[排序/边缘像素匹配链接](已有) → 链序涌现环形结构（创新：线性链首尾相连视为环）→ [重涂色/顺时针轮换](已有，创新：轮换顺序由边缘链给出而非物理连接线）

**来源原语**：排序、精灵体、分隔线、边缘像素匹配、链式连接排序（78332cb0）；重涂色、环形连接、内部遮罩、顺时针轮换（ad173014）

**依赖链**：边缘匹配确定链序，链序定义环（首尾相连），环序决定内部遮罩颜色的轮换方向和对应关系。不知道链序就无法确定哪个方块的颜色传给哪个方块；不做颜色轮换则仅有空间重排而无色彩变换。

将分隔网格中的精灵体方块按边缘前景匹配链接成序列，视该序列为环，沿环顺时针轮换每个方块内部遮罩的颜色，最后按链序排列输出。

**输入结构**：
- 约 20x20 网格，由灰(5)分隔行和列划分为矩形排列的等大小方块（如 2x3 排列的 6 个方块，每块 5x5）。分隔宽度 1 格。
- 每个方块内含一个精灵体：黑(0)局部背景上的多色图案。每个精灵体由两部分组成——边缘结构像素（位于方块 4 条边的前景像素）和内部遮罩像素（不触及方块边的前景像素）。边缘结构像素为统一颜色红(2)；内部遮罩像素为另一种颜色，各方块的内部遮罩颜色互不相同（取自 {蓝(1), 绿(3), 黄(4), 橙(7), 青(8), 品红(6)}）。
- 边缘连接规则：两个方块可"连接"当且仅当一个方块的某条边上的前景像素位移模式与另一方块的对面边上的前景像素位移模式完全匹配（即 A 的右边缘红像素行偏移集合 = B 的左边缘红像素行偏移集合，或 A 的下边缘列偏移集合 = B 的上边缘列偏移集合）。
- 生成约束：所有方块可唯一链接成一条水平链（每个方块恰好与 1 或 2 个方块的左右边缘匹配），链长度等于方块总数。链的方向为水平匹配（右边缘 vs 左边缘）。

**规则**：
1. 对所有方块，尝试左右边缘匹配：若方块 A 的右边缘前景偏移集合与方块 B 的左边缘前景偏移集合一致，则 A→B 形成链接。找到唯一的完整链 S₁→S₂→…→Sₙ（每个方块恰出现一次）。
2. 将此链视为环：Sₙ 的"下一个"是 S₁。
3. 顺时针轮换内部遮罩颜色：每个方块 Sₖ 保留自身的内部遮罩形状和边缘结构不变，但将内部遮罩颜色替换为前一个方块 Sₖ₋₁ 的内部遮罩颜色（S₁ 的遮罩颜色来自 Sₙ）。
4. 输出为 1×N 的水平方块条带（按链序 S₁ 到 Sₙ 从左到右排列），方块间以灰(5)分隔列隔开，每块 5x5。边缘结构和遮罩形状来自各方块自身，遮罩颜色来自轮换结果。

**关键洞察**：边缘匹配给出的线性链并非在输入中以连接线形式可见——必须通过比较边缘像素模式推断链序。环形轮换的方向（前一个方块的颜色传给后一个）以及链首尾成环这两条规则，都需要对比多个示例才能归纳。

## 实现要求

1. `main(grid)` 必须实现新题描述中的确定性转换规则，不能只识别 `generate_input()` 的固定模板。禁止不同的input网格输出相同的output网格。
2. `generate_input()` 必须随机生成多样样例，不能固定死。随机维度应覆盖：网格大小、对象数量、位置、颜色、方向、形状参数或关键分支。注意若描述中存在若干，需实现而不是只有单个，包括object或者对应关系等等。且若涉及到最短路径，则输入网格中必涉及到多条路径，对选择造成干扰。
3. 生成器必须保证输入满足 `main()` 的隐式假设：对象不重叠、不越界、特殊标记唯一或可区分、匹配关系无歧义、关键分支出现概率相同。
4. 禁止把 ARC 颜色 id 、亮度、拼写等当作人类不可见的数值语义参与排序、大小比较或隐藏映射。颜色变化必须有可见结构线索。注意颜色亮度、拼写等也是不可见信息，若描述中出现违规的颜色id或者亮度，可自行使用少量的固定颜色替代，但注意生成时要在三个以内输入输出网格中对所有变换100%覆盖度。

6. 若规则有多个分支，生成器不能长期固定成一个分支；应让分支在随机样例中合理出现。分支概率不必平均——难以发现的隐蔽分支（如少数情况下才触发的特殊规则）应适当提高出现概率，确保在 3 个训练示例中至少出现一次，否则求解者无法归纳该规则。对于颜色映射类规则，确保 2 个左右的示例即可覆盖所有映射关系（每种颜色→颜色的映射至少在某个示例中出现过）。
