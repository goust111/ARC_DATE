## 新题 2：邻接标记着色的矩形框填充与面积优先级冲突解决

**组合逻辑**：[填充fill](创新：填充色由外部邻接标记决定) + [计数counting](创新：面积计数用于冲突解决) + [擦除erase](已有)

**来源原语**：填充、空心矩形框、标记像素、标记相对方位 ← 94414823；邻接接触、标记选中邻接体 ← 48d8fb45；计数 ← dc2aa30b / ae58858e

**依赖链**：邻接关系将标记分配给矩形框 → 标记颜色决定该框的填充色 → 当两个框的内部区域在空间上重叠时，各框面积的大小关系决定重叠区域的最终颜色。三步环环相扣：没有邻接分配就不知道填什么颜色；没有面积比较就无法解决重叠冲突。

在 94414823 中，标记的方位决定象限分配，不涉及多框重叠；在 48d8fb45 中，标记选中邻接体后直接裁剪输出。本题将"邻接选择"用于颜色传递，并引入面积比较作为冲突解决规则——标记、填充、面积三者构成源题中不存在的决策链。

根据外部标记的邻接关系确定每个矩形框的填充色，重叠区域按框内面积小者优先的规则着色。

**输入结构**：约 14x14 的网格，灰(5)背景。网格中包含：
- 2~3 个空心矩形框，由蓝(1)像素构成，边框宽度恰好 1 像素，内部为灰(5)背景色。框的尺寸不一（内部面积各不相同，最小 3x3，最大 6x6）。
- 部分矩形框的边框在空间上交叉或重叠（边框像素可以共享，内部区域可以部分重叠）。
- 每个矩形框的外侧恰好有一个单像素标记，标记与该框的某一条边的某个像素 4-邻接。不同框的标记颜色互不相同，取自 {红(2), 绿(3), 黄(4)}。标记不会与两个框同时邻接。
- 生成约束：至少一对矩形框的内部区域存在重叠；每个标记恰好与一个矩形框的边框邻接。

**规则**：
1. 对每个单像素标记，找到与其 4-邻接的蓝(1)矩形框边框，将该标记的颜色指定为该框的"填充色"。
2. 用指定的填充色填满每个矩形框的内部区域（原本为灰(5)的所有像素）。蓝(1)边框像素保持不变。
3. 若两个矩形框的内部区域在空间上重叠（同一像素同时属于两个框的内部），则该像素着内部面积较小的框的填充色。面积定义为该框内部灰(5)像素的总数（未填充前）。生成约束保证不存在面积相同的两个框。
4. 擦除所有标记像素为灰(5)背景色。

**关键洞察**：重叠区域的颜色不是由绘制顺序或位置决定，而是由框内面积的相对大小决定——小框优先。此规则无法从不包含重叠的示例中推断，必须对比有重叠和无重叠的示例才能归纳。

```yaml
    edge_assignment: each segment sits on exactly one of the 4 diamond edges (TR/TL/BL/BR)
  output_rule: |
    From each endpoint of each outer segment, cast a diagonal ray in the outward direction
    (perpendicular to segment, away from diamond). Paint over bg cells with segment color
    until hitting grid edge. Each segment emits exactly 2 rays.
  ray_length: 0-19 pixels per endpoint; all rays reach grid boundary [observed]

generation_strategy:
  approach: output-first
  steps:
    1. Choose grid dimensions within range. Fill with checkerboard (top-left=1).
    2. Pick 1-3 diamond count and assign distinct non-bg colors (from 2-9).
    3. For each diamond, choose 2-4 edges (TR/TL/BL/BR) to receive outer segments.
    4. Assign a segment color per edge (non-bg, differs from diamond color).
    5. Build output-first -- place each diamond, then for each segment edge, compute the
       full ray pair (from both endpoints outward to grid edge) and paint them.
       Verify no ray collides with existing non-bg pixels; reject or retry placement if so.
    6. Derive input by removing all ray pixels (restoring bg checkerboard values at those cells),
       keeping only diamonds and outer segments.
```
</generation_spec>
</reference_puzzle>

2. `generate_input()` 必须随机生成多样样例，不能固定死。随机维度应覆盖：网格大小、对象数量、位置、颜色、方向、形状参数或关键分支。注意若描述中存在若干，需实现而不是只有单个，包括object或者对应关系等等。且若涉及到最短路径，则输入网格中必涉及到多条路径，对选择造成干扰。

6. 若规则有多个分支，生成器不能长期固定成一个分支；应让分支在随机样例中合理出现。分支概率不必平均——难以发现的隐蔽分支（如少数情况下才触发的特殊规则）应适当提高出现概率，确保在 3 个训练示例中至少出现一次，否则求解者无法归纳该规则。对于颜色映射类规则，确保 2 个左右的示例即可覆盖所有映射关系（每种颜色→颜色的映射至少在某个示例中出现过）。
