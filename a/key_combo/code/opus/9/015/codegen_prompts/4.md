## 新题 4：笛卡尔积定位 + 象限旋转复制模板

**组合逻辑**：[填充fill / 边缘标记笛卡尔积edge_marker_cartesian_product](已有：定位交叉点) → [图案复制pattern_replication + 旋转rotation](已有：复制并旋转模板) → [象限位置对应quadrant_correspondence](创新：旋转角度由交叉点所在象限决定，而非由源角决定)

**来源原语**：填充fill(2281f1f4), 边缘标记笛卡尔积edge_marker_cartesian_product(2281f1f4), 行列交叉row_col_intersection(2281f1f4), 标记像素marker_pixel(2281f1f4), 图案复制pattern_replication(4c416de3), 旋转rotation(4c416de3), 象限位置对应quadrant_correspondence(0bb8deee), 各角独立着色per_corner_coloring(4c416de3), 模板template(1e32b0e9)

**依赖链**：笛卡尔积确定 WHERE（模板放在哪），象限确定 HOW（旋转几度），行标记颜色确定 WHAT COLOR（模板涂什么色）。三条独立信息流在每个交叉点汇聚：移除笛卡尔积则无放置位置；移除旋转则无法解释不同交叉点的模板朝向差异；移除颜色映射则无法确定每个副本的颜色。

边缘标记定义行列交叉点，在每个交叉点放置一个小模板的旋转副本——旋转角度取决于交叉点在网格中的象限位置，颜色取决于选中该行的标记颜色。

**输入结构**：
- 网格约 20x20，背景黑(0)。
- 顶行有 3-4 个灰(5)标记像素，标示选中的列。
- 最右列有 3-4 个彩色标记像素（红(2)、绿(3)、蓝(1)等，每行标记颜色不同），标示选中的行及该行对应的颜色。
- 左下角有一个 3x3 的模板精灵体，由灰(5)像素绘制，包含不对称图案（如仅占据 3x3 中的 4 个像素，形成非对称的连通图形），使得 0°/90°/180°/270° 旋转后的形状各不相同。
- 网格中心行和中心列将网格分为四个象限（上左、上右、下左、下右）。

**规则**：
1. 收集顶行的灰(5)标记像素位置作为选中列集合 S_col；收集最右列的彩色标记像素位置和颜色作为选中行集合 S_row（每个元素为 (行号, 颜色)）。
2. 对 S_row 和 S_col 的笛卡尔积中的每个交叉点 (r, c)，放置一份 3x3 模板的副本，以 (r, c) 为中心。
3. 副本的颜色为选中该行的标记像素的颜色。
4. 副本的旋转角度由 (r, c) 所在的象限决定：上左象限 = 0°（原始朝向）；上右象限 = 顺时针 90°；下左象限 = 顺时针 270°；下右象限 = 顺时针 180°。象限边界（中心行、中心列）上的点归入上方/左方的象限。
5. 交叉点按行优先、列其次的顺序处理。若副本之间有像素重叠，后处理的覆盖先处理的。
6. 保留所有原始标记像素和模板精灵体。

**关键洞察**：单看一个示例，可能误以为旋转角度是随机的或由颜色决定的。必须对比多个示例、将交叉点位置映射到象限，才能归纳出"旋转角度由象限决定"这一隐蔽规则——而非由颜色或处理顺序决定。
