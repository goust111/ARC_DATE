## 新题 2：端点连线穿越封闭区域的灌色

**组合逻辑**：[连线draw_line](已有) → [区域填充flood_fill](创新：填充色不是标记本身的颜色，而是穿过该区域的连线颜色) → [冲突优先级conflict_priority](创新：多条线穿过同一区域时，以区域内线段长度最长者为准)

**来源原语**：连线draw_line(253bf280), 同行列端点间填充fill_between_aligned_endpoints(253bf280), 行列对齐row_col_align(253bf280), 区域填充flood_fill(1190bc91), 标记像素marker_pixel(253bf280), 矩形框架rect_frame(fcb5c309), 冲突优先级conflict_priority(03560426)

**依赖链**：连线的路径决定了哪些颜色"穿过"哪些封闭区域——没有连线，区域没有颜色来源；没有封闭区域，连线只是视觉连接。当多条不同色连线穿过同一区域时，"区域内最长线段"这一规则引入了隐蔽的信息——必须对比多个示例才能排除"第一条线优先"或"颜色编号小的优先"等替代假设。

在含有灰(5)围栏封闭区域的网格上，同色对齐标记之间画连线；每个被连线穿过的封闭区域被灌注该连线的颜色，多线穿越时取区域内线段最长者的颜色。

**输入结构**：
- 网格约 18x18，背景黑(0)。
- 3-5 个封闭区域，由灰(5)像素围成闭合边界（每个区域的边界为单像素厚的简单矩形或 L 形围栏，内部包含 6-15 个黑(0)背景像素），区域之间互不相邻。
- 6-10 个标记像素，颜色为红(2)、绿(3)、蓝(1)、黄(4)，放置在所有封闭区域的**外部**。每一行恰好有 0 或 2 个同色标记，每一列恰好有 0 或 2 个同色标记（保证配对唯一）。
- 至少 2 条连线会穿过封闭区域；至少 1 个区域会被 2 条不同色连线穿过。
- 生成约束：穿越同一区域的不同色线段在该区域内部的长度（像素数）不相等，保证无平局。

**规则**：
1. 对每一行，若恰好有两个同色标记像素，在二者之间的所有背景黑(0)像素上画一条该颜色的水平线段（不覆盖灰(5)边界，不覆盖已有连线像素）。
2. 对每一列，若恰好有两个同色标记像素，在二者之间的所有背景黑(0)像素上画一条该颜色的垂直线段（不覆盖灰(5)边界，不覆盖已有连线像素）。
3. 连线按行优先、列其次的顺序绘制（即先处理所有行连线，再处理所有列连线）。若两条线在同一像素交叉，先绘制的保留。
4. 对每个灰(5)封闭区域，统计其内部各种连线颜色的像素数量。若有连线穿过该区域，将该区域内部所有黑(0)背景像素（不包括连线像素本身和灰(5)边界）灌注为区域内线段最长的那种颜色。
5. 没有连线穿过的封闭区域保持原样（内部为黑(0)背景）。
6. 保留所有标记像素、连线像素和灰(5)边界。

**关键洞察**：连线同时充当"颜色传输管道"和"投票权重"——穿过区域的线段越长，该颜色越有可能赢得区域。求解者不能仅看"是否穿过"，还需比较穿越长度，这一隐蔽规则需要对比多个示例才能归纳。
