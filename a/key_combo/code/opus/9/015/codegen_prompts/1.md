## 新题 1：对角射线分区内的最近邻重涂色

**组合逻辑**：[射线延伸ray_extend](已有) → [射线遮挡分区ray_partition](创新：用对角射线而非逐像素射线来划分扇区) → [重涂色recolor + 最近邻选择nearest_neighbor_selection](创新：最近邻匹配被限制在同一扇区内，而非全局)

**来源原语**：射线延伸ray_extend(ea786f4a), 对角放射diagonal_radiation(ea786f4a), 重涂色recolor(6df30ad6), 最近邻选择nearest_neighbor_selection(6df30ad6), 欧氏距离最小minimum_euclidean_distance(6df30ad6), 射线遮挡分区ray_partition(1190bc91), 擦除erase(6df30ad6), 标记像素marker_pixel(6df30ad6), 孤立像素isolated_pixel(ea786f4a)

**依赖链**：对角射线产生的四个扇区边界限定了"哪些标记像素可以为哪些前景对象投票"——没有射线分区，最近邻匹配会跨区选中错误的标记；没有最近邻重涂色，射线分区只是装饰性线条。射线构造了一个局部化的约束空间，重涂色在这个空间内执行，两者通过"空间可达性"紧耦合。

从一个锚点发射四条对角线将画布切成四个扇区，每个灰(5)前景对象被重涂为其所在扇区内距它最近的标记像素的颜色。

**输入结构**：
- 网格约 15x15，背景蓝(1)。
- 恰好一个黑(0)像素，位于网格内部（不在边缘行/列上），作为射线锚点。
- 3-5 个小型单色灰(5)前景对象，每个是 4-连通的不规则图形（3-6 像素），分散在不同扇区中，不与锚点同行同列，互不相邻。
- 若干孤立标记像素，颜色为红(2)、绿(3)、黄(4)、橙(7)等（每种颜色只出现一次），每个含有灰(5)对象的扇区内至少有一个标记像素。标记像素不在对角射线路径上，不与灰(5)对象相邻。
- 生成约束：每个灰(5)对象在其所在扇区内有唯一最近标记像素（不会出现等距平局）。

**规则**：
1. 定位唯一的黑(0)像素。从该像素向四个对角方向（左上、右上、左下、右下）画射线，射线延伸至网格边界，沿途所有像素涂为黑(0)。
2. 四条射线将网格划分为四个扇区：上方（锚点正上方的三角区域）、下方、左方、右方。射线上的像素不属于任何扇区。对于每个非射线、非锚点的像素 (r, c)，若锚点在 (R, C)：若 |r-R| < |c-C| 且 c > C 则属于右扇区；若 |r-R| < |c-C| 且 c < C 则属于左扇区；若 |r-R| > |c-C| 且 r < R 则属于上扇区；若 |r-R| > |c-C| 且 r > R 则属于下扇区。
3. 对每个灰(5)对象，找到与该对象在同一扇区内的所有标记像素。计算该对象的每个像素到每个候选标记像素的欧氏距离平方，取最小值。将整个灰(5)对象重涂为距离最近的那个标记像素的颜色。
4. 擦除所有标记像素（替换为背景蓝(1)）。
5. 保留黑(0)锚点和四条对角射线。

**关键洞察**：对角射线是隐形的"防火墙"——两个灰(5)对象即使全局距离最近的标记颜色相同，也可能因为分属不同扇区而被涂成不同颜色。求解者必须先发现扇区边界的存在，才能正确预测重涂色结果。
