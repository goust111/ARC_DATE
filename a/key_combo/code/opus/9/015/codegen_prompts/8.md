## 新题 8：控制条引导平铺并镂空模板图案

**组合逻辑**：[平铺tiling + 沿控制条重复repeat_along_bar + 跨度对齐span_alignment](已有) → [挖孔punch_holes + 同色匹配same_color_matching](已有) → [擦除erase](已有：擦除控制条和模板原件) → 三者在同一组像素上交互：平铺决定"什么被复制"，镂空决定"什么被删去"，控制条决定"复制到哪里"

**来源原语**：平铺tiling(c62e2108), 沿控制条重复repeat_along_bar(c62e2108), 跨度对齐span_alignment(c62e2108), 控制条control_bar(c62e2108), 精灵体sprite(c62e2108), 擦除erase(c62e2108), 挖孔punch_holes(58f5dbd5), 模板图案motif_stencil(58f5dbd5), 同色匹配same_color_matching(58f5dbd5)

**依赖链**：控制条确定平铺方向和范围 → 平铺产生多个精灵体副本 → 每个副本被同色模板图案镂空。镂空的效果只在副本存在时才有意义（无平铺则只有一份原件），而平铺的可视结果被镂空改变（镂空使副本从实心变为镂空图案）。控制条决定有多少副本，模板决定每个副本长什么样——两者共同决定最终输出。

擦除控制条后，将匹配的精灵体沿控制条方向周期平铺，每个副本内部用同色模板图案镂空。

**输入结构**：
- 网格约 18x18，背景黑(0)。
- 2-3 个实心矩形精灵体（solid_rectangle），颜色分别为红(2)、蓝(1)、绿(3)，每个约 4x4 到 5x5 像素。
- 每个精灵体有一根同色的控制条（1 像素厚），水平或垂直放置。水平控制条与精灵体的列跨度相同；垂直控制条与精灵体的行跨度相同。控制条与精灵体之间有 2-6 像素的间距。
- 每种精灵体颜色对应一个同色的小型模板图案（motif，2-4 像素，不规则形状），放置在网格中远离精灵体和控制条的位置。
- 生成约束：平铺后的副本不会超出网格边界，不同精灵体的平铺区域互不重叠。

**规则**：
1. 对每根控制条，通过颜色和跨度对齐找到其匹配的精灵体：控制条颜色 = 精灵体颜色，且（水平控制条的列跨度 = 精灵体的列跨度，或垂直控制条的行跨度 = 精灵体的行跨度）。
2. 擦除所有控制条（替换为背景黑(0)）。
3. 从精灵体原始位置开始，沿朝向其控制条的方向（控制条在精灵体的哪一侧，就向哪个方向平铺），以精灵体的高度（向上/下平铺时）或宽度（向左/右平铺时）为周期，重复放置精灵体副本，直到到达控制条原始位置或网格边界。副本只绘制精灵体的非背景像素。
4. 对每个精灵体颜色，找到同色的模板图案。在每个副本（包括原件）的边界框内，将模板图案居中放置（若无法完美居中，向控制条方向偏移 1 像素）。模板覆盖的位置从该副本中移除（设为背景黑(0)）。
5. 擦除所有模板图案的原始位置（替换为背景黑(0)）。

**关键洞察**：平铺产生了视觉上的"墙纸"效果，但镂空在每个平铺单元中打出相同的洞，打破了重复的单调性。求解者必须分别识别三个要素（控制条的方向、平铺的周期、镂空的图案），才能重建完整的变换链。
