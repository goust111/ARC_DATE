## 新题 1：镜像补全母题充当射线障碍

**组合逻辑**：[镜像/mirror](宽高比决定轴向) + [射线延伸/ray_extend](从边缘标记向内投射) + [重涂色/recolor](创新：射线终止于镜像像素时吸收射线颜色)

**来源原语**：镜像(18419cfa) + 宽高比决定镜像轴(18419cfa) + 射线延伸(1f0c79e5/891232d6) + 边缘标记(891232d6) + 矩形框架(18419cfa) + 内部母题(18419cfa) + 重涂色(09c534e7)

**依赖链**：镜像补全在框架内生成新的前景像素 → 这些新像素改变了射线的行进路径和终止位置 → 射线终止于镜像像素时触发特殊重涂色规则（原始母题像素则正常阻挡射线）。删除镜像步骤，射线路径完全不同；删除射线步骤，镜像像素与原始像素无法区分。

将矩形框架内的不对称母题按框架宽高比镜像补全，然后从网格边缘标记发射射线，射线遇到镜像生成的像素时将其吸收为射线颜色，遇到原始母题像素时正常停止。

**输入结构**：约 15x20 的黑(0)背景网格。网格中散布 2~4 个灰(5)矩形框架（边框宽 1 像素，内部尺寸 3x5 至 5x7 不等，部分宽大于高、部分高大于宽）。每个框架内部有一个红(2)不对称小图形（3~5 像素，4-连通，位于框架内的一侧——宽框架中偏左或偏右，高框架中偏上或偏下）。网格的四条外边缘上（不在任何框架内）散布 3~6 个单像素标记，颜色取自蓝(1)、绿(3)、黄(4)，每个标记位于某条边缘的不同位置。生成约束：各框架互不相邻（边界框间距至少 2 格）；每个边缘标记沿其投射方向至少能到达一个框架。

**规则**：
1. 对每个灰(5)矩形框架，判断其内部区域的宽高比：宽 > 高则以垂直中轴做左右镜像，高 > 宽则以水平中轴做上下镜像，宽 = 高则以垂直中轴做左右镜像。将框架内原有红(2)母题像素关于该轴镜像，镜像副本涂为橙(7)。原始红(2)像素保留不变。
2. 从每个边缘标记出发，沿垂直于该边缘的方向向网格内部逐格投射一条射线，射线颜色与标记颜色相同。射线经过的每个空白（黑(0)）格涂为该标记颜色。
3. 射线前进时遇到的第一个非黑(0)像素为终止像素。射线在终止像素前一格停止（不覆盖终止像素），但有一个例外：若终止像素为橙(7)（镜像生成的像素），则该橙(7)像素被重涂为射线的标记颜色，射线仍在其前一格停止。若终止像素为灰(5)框架边框或红(2)原始母题像素，则不做任何重涂。
4. 若射线在到达对面边缘前未遇到任何非黑像素，则整条路径正常涂色直到边缘。
5. 多条射线可能经过同一个空白格或击中同一个橙(7)像素。空白格：后投射的射线覆盖先投射的颜色（处理顺序：先处理上边缘的标记从左到右，再右边缘从上到下，再下边缘从右到左，再左边缘从下到上）。橙(7)像素：第一条命中的射线将其重涂，之后该像素视为已重涂的非橙颜色，后续射线正常停止于其前一格。

**关键洞察**：镜像生成的橙(7)像素和原始红(2)像素对射线的阻挡行为不同——橙像素会被射线"吸收"并变色，而红像素只是静默阻挡；这使得框架的宽高比（决定镜像轴）间接控制了射线在哪些位置发生颜色覆写。
