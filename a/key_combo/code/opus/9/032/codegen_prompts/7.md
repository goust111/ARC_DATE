## 新题 7：对称恢复揭示隐藏种子的射线方向

**组合逻辑**：[补全/completion](平移对称恢复被遮挡区域) → [射线延伸/ray_extend](创新：恢复后才能看到完整的种子块及其红角方向) + [裁剪/crop](输出仅为原遮挡区域)

**来源原语**：补全+平移对称图案+遮挡矩形+对称轨道+对称恢复遮挡(f9012d9b) + 射线延伸+种子块+角位控制射线+对角方向(1f0c79e5) + 裁剪(f9012d9b/2d0172a1)

**依赖链**：对称恢复填补被遮挡的像素 → 恢复出的像素中包含部分或完整的 2x2 种子块（含红角方向信息）→ 从这些种子块发射对角射线 → 射线仅在原遮挡区域内绘制（裁剪到遮挡范围）。删除对称恢复则种子块不完整、方向不可知；删除射线则恢复后无额外变换；删除裁剪则输出包含无关区域。

在平移对称图案中，黑色遮挡矩形覆盖了部分种子块；先用对称性恢复被遮挡的图案（包括隐藏的种子），再从完整种子发射对角射线，最后裁剪输出为遮挡区域。

**输入结构**：约 16x16 的网格，无真正背景色，由 3~4 种颜色（取自蓝(1)、绿(3)、黄(4)、灰(5)）构成的平移重复图案填充整个网格。图案的最小平移周期约 4x4 至 6x6。在图案的特定重复位置上嵌入 2x2 种子块：种子块的 3 个像素融入图案颜色（与周围图案像素一致），1 个像素为红(2)，位于四角之一。整个网格中有 2~4 个这样的种子块（在不同的重复单元中）。一个黑(0)矩形（约 5x5 至 8x8）遮挡了网格的某个区域，该矩形覆盖了至少一个种子块的部分或全部。生成约束：至少一个种子块被完全遮挡或其红角被遮挡（使得不恢复就无法确定方向）；遮挡区域外至少有一个完整可见的种子块（提供种子的存在线索）；平移对称周期与种子位置兼容。

**规则**：
1. 将黑(0)像素视为遮挡掩膜。忽略黑像素，检测剩余像素的平移对称性（最小平移向量）。
2. 对每个黑(0)像素，从其对称轨道中找到一个非黑的等价像素，用该像素的颜色填充。
3. 恢复完成后，在整个网格中扫描所有 2x2 区域，找出恰好包含 1 个红(2)像素和 3 个非红同色像素的块，这些是种子块。
4. 对每个种子块，根据红角位置确定对角射线方向（同新题 4 规则 1），将红像素替换为种子的非红颜色，然后沿对角方向逐步绘制 2x2 同色方块直到超出网格边界。射线像素覆盖原有图案像素。
5. 裁剪输出：仅保留原始黑色遮挡矩形所覆盖区域的内容（恢复 + 射线叠加后的结果）。

**关键洞察**：遮挡不仅隐藏了图案，还隐藏了种子块的存在和方向信息；只有先完成对称恢复，才能发现哪些 2x2 块是种子以及射线应该朝哪个方向发射——恢复步骤是射线步骤的信息前提而非简单的数据传递。
