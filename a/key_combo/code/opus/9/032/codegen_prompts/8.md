## 新题 8：空心框架过滤后按边长填色再排序拼接

**组合逻辑**：[擦除/erase](忽略实心干扰项) + [填充/fill](创新：按边长映射内部填充色) + [排序/sorting + 拼接/concatenate](按边长排列)

**来源原语**：擦除+空心矩形+实心方块+仅保留空心对象+忽略干扰项(a680ac02) + 填充+按边长映射颜色+标记在框内居中(00dbd492) + 排序+拼接+沿主轴排列(a680ac02)

**依赖链**：干扰项过滤确定哪些框架参与后续处理 → 框架边长同时决定填充颜色和排序位置（双输出属性）→ 填充后的框架按边长排序拼接为条带。删除过滤则干扰项混入；删除填充则排序后的框架无内部色彩区分；删除排序则布局无序。

从混合的空心框架和实心方块中过滤出空心框架，根据边长映射颜色填充内部，保留居中标记，然后按边长从小到大排列为水平条带。

**输入结构**：约 20x15 的黑(0)背景网格。散布 5~8 个单色正方形物体（边长 4~8 像素），颜色均为灰(5)。其中部分是空心正方形框架（边框宽 1 像素，内部为黑），部分是实心正方形（全部填满）。每个空心框架的几何中心位置有一个红(2)标记像素（若边长为偶数，标记在中心偏左上的位置）。实心方块内无标记。物体间互不接触，边界框不重叠。生成约束：空心框架至少 3 个，边长至少有两种不同值；实心方块至少 2 个；不同边长的空心框架数量不超过 5 种。

**规则**：
1. 检测所有灰(5) 4-连通分量。判断每个分量是空心框架（内部有黑像素洞且包含红(2)标记）还是实心方块（无内部洞且无红标记）。
2. 丢弃所有实心方块（不出现在输出中）。
3. 对每个空心框架，测量其外边长 S，根据 S 填充内部空白区域（边框内的非红非灰像素位置）：S=4 → 蓝(1)，S=5 → 青(8)，S=6 → 黄(4)，S=7 → 橙(7)，S=8 → 品红(6)。灰(5)边框和红(2)标记保持不变。
4. 将所有填充后的空心框架按外边长从小到大排序。边长相同时，按原始位置列坐标从小到大排序（列坐标指边界框左上角的列号）。
5. 将排序后的框架从左到右紧密拼接为一行水平条带（相邻框架边框共用），输出网格的高度等于最大框架的边长，较小框架顶部对齐，底部以黑(0)填充至等高。

**关键洞察**：实心方块是形状匹配的干扰项，必须通过内部洞检测（而非颜色或大小）来区分；空心框架的边长是唯一的关键属性，同时决定了内部填充色和排列顺序——两个本质不同的输出维度由同一个输入特征驱动。
