## 新题 2：嵌套深度驱动剪切与重涂色

**组合逻辑**：[规范化/canonicalize → 包含树/containment_tree](提取嵌套深度) + [剪切变换/shear_transform](创新：剪切量由嵌套深度决定) + [重涂色/recolor](深度映射颜色) + [擦除/erase](移除框架)

**来源原语**：规范化+包含树(2d0172a1) + 剪切变换+偏移随行距增(423a55dc) + 重涂色+尺寸分类(aedd82e4) + 擦除(edcc2ff0)

**依赖链**：包含树确定每个精灵体的嵌套深度 → 深度同时决定剪切量和输出颜色（双输出属性）→ 框架在剪切过程中充当裁剪边界，剪切完成后被擦除。删除包含树分析则无法确定剪切量和颜色；删除剪切则深度信息无几何表达；删除框架擦除则输出包含多余结构。

根据嵌套框架层次确定每个内部精灵体的深度，对精灵体施加深度倍数的剪切变换并按深度重涂色，最后移除所有框架只留精灵体。

**输入结构**：约 20x20 的黑(0)背景网格。2~3 层嵌套的灰(5)矩形框架（边框宽 1 像素），最外层框架约 16x16，中层约 10x10，最内层约 6x6。每层框架内（在该层与下一层之间的空间）放置 1~2 个小型单色精灵体（4-连通，3~6 像素，形状各异——有的像不规则团块，有的像弯折线段）。每个精灵体使用不同颜色（取自红(2)、绿(3)、黄(4)、橙(7)、品红(6)），各精灵体间互不接触。生成约束：最深层不超过 3 层；每个精灵体的边界框完全在其直接所属层内；嵌套框架严格居中或近似居中。

**规则**：
1. 构建包含树：最外层框架深度为 1，被深度 d 框架直接包围的框架或精灵体深度为 d+1。
2. 对每个精灵体，以其最底行为锚点行，对其每个像素 (r, c) 施加剪切变换：新位置为 (r, c - depth * (bottom - r))，其中 depth 是该精灵体的嵌套深度，bottom 是该精灵体最底行的行号。
3. 若剪切后的像素位置超出该精灵体直接所属框架的内部区域，则裁剪掉（不绘制）。
4. 将剪切后的精灵体重涂色：深度 2 → 蓝(1)，深度 3 → 红(2)，深度 4 → 绿(3)。深度 1 的精灵体（在最外层框架内但不在任何子框架内）保持原色。
5. 擦除所有灰(5)框架边框像素（设为黑(0)），输出仅保留剪切并重涂色后的精灵体。

**关键洞察**：嵌套深度是一个不可直接观测的拓扑属性，它同时控制两个独立的输出维度——几何形变（剪切倍数）和颜色映射；框架在剪切过程中是必要的裁剪边界，但最终被擦除，属于"用后即弃"的辅助结构。

Remove blank separator columns and slide each vertical object group so adjacent connector endpoints touch.

Input structure
A short strip contains monochrome path-like object groups, each occupying a contiguous run of non-background columns; runs are separated by all-background columns. Each group has a unique degree-1 foreground endpoint on both its left and right outer edge.

Rule
Delete the all-background separator columns. Keep the first group in its original vertical position, then process the remaining groups from left to right: shift each group vertically, without rotation or recoloring, so its left endpoint is on the same row as the previous placed group's right endpoint, and paste it immediately to the right.

Key insight
The intended contacts are the degree-1 edge endpoints, not every possible foreground edge overlap, which makes the packed strip a single connected chain.
