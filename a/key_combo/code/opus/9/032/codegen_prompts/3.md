## 新题 3：指示条匹配计数筛选点对称反射

**组合逻辑**：[计数/counting](统计各色物体数) ↔ [条长等于物体计数/bar_equals_count](创新：反转为"条长作为期望值，计数作为实际值"进行匹配筛选) → [擦除/erase](移除未通过的物体) → [点对称补全/point_symmetry](仅对通过物体执行)

**来源原语**：计数+指示条+标记色筛选(edcc2ff0) + 点对称+中心标记(e729b7be) + 擦除(edcc2ff0/a680ac02)

**依赖链**：计数得到各色物体实际数量 → 与指示条长度比较筛选"合格色" → 合格色的物体被保留并做点对称反射，不合格色的物体被擦除 → 指示条本身也根据筛选结果更新。删除计数则无法确定哪些颜色通过筛选；删除点对称则通过筛选的物体无变换输出；删除擦除则不合格物体仍存在干扰输出。

统计左半区各色物体数量，只有数量与顶部指示条长度匹配的颜色通过筛选，通过的物体绕中心标记做 180 度旋转映射到右半区，其余物体被擦除。

**输入结构**：约 15x17 的黑(0)背景网格。第 0 行为指示条区域：从第 0 列开始有 2~4 条水平色条，每条占一行（若多条则占第 0~3 行），颜色各不相同（取自蓝(1)、绿(3)、黄(4)、橙(7)），每条长度 1~4 格。指示条下方为主区域。主区域中央有一条黄(4)垂直分隔线从第一个非指示条行延伸到底部。分隔线正中位置有一个红(2)中心标记像素（替换该位置的黄像素）。分隔线左侧散布 4~8 个小型 4-连通物体（每个 2~5 像素），颜色与指示条颜色对应，每种颜色 1~4 个物体。分隔线右侧为空（全黑）。生成约束：至少有一种颜色的物体数量与其指示条长度相等，至少有一种不相等；各物体互不接触且不接触分隔线。

**规则**：
1. 对每种出现在指示条中的颜色，统计分隔线左侧该颜色的 4-连通物体数量。
2. 若该颜色的物体数量恰好等于其指示条的长度（像素数），则该颜色"通过筛选"。
3. 将所有未通过筛选的颜色的物体像素设为黑(0)（擦除）。
4. 对每个通过筛选的物体中的每个像素 (r, c)，计算其关于红(2)中心标记 (cr, cc) 的 180 度旋转位置 (2*cr - r, 2*cc - c)，在该位置涂上与原物体相同的颜色。原物体像素保留不变。
5. 在指示条区域中，将未通过筛选的颜色对应的条擦除（设为黑(0)）。通过筛选的条保持不变。
6. 分隔线和中心标记保持不变。

**关键洞察**：指示条不是对物体数量的描述（如参考题 edcc2ff0 中的计数摘要），而是反转为"期望值"——只有实际物体数量恰好匹配条长的颜色才通过筛选参与反射；这层比较逻辑需要对比多个示例才能归纳。
