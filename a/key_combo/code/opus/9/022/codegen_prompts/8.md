## 新题 8：螺旋拐角印章与标记触发交替镜像

**组合逻辑**：[螺旋绘制/spiral_draw](创新：螺旋路径不画线，而是生成印章坐标序列) + [镜像/mirror](已有) + [印章覆盖/stamp_overlay](已有) + [标记像素/marker_pixel + 特定标记触发镜像/marker_triggers_mirror](已有原语新组合：镜像在交替拐角处触发而非所有位置)

**来源原语**：螺旋绘制、遇障碍停止 ← e5c44e8f；镜像、印章覆盖、标记像素、特定标记触发镜像 ← 3e980e27；碰撞阻挡 ← 1a07d186

**依赖链**：螺旋路径的拐角序列提供印章坐标 → 精灵体中标记像素的颜色（红/绿）决定是否在交替拐角镜像 → 障碍像素决定某个拐角的印章是否被跳过。螺旋的几何性质决定拐角位置和间距，标记颜色决定镜像模式，障碍决定有效印章集——三者交织。

沿螺旋路径的每个转向拐角位置印章一个精灵体副本，标记颜色为红时在偶数拐角处镜像，遇障碍则跳过该拐角。

**输入结构**：约 18×18 的黑(0)背景网格。一个小型多色精灵体（3×3 至 4×3 像素，由 2~3 种前景色组成，如蓝(1)、绿(3)、黄(4)），精灵体不具备左右对称性。精灵体内部恰好有一个红(2)或绿(3)标记像素（若精灵体本身使用绿(3)则标记为红(2)，反之亦然）。精灵体位于网格的某个角落区域。一个品红(6)种子像素位于网格中部。0~2 个灰(5)障碍像素散布于网格中。生成约束：种子像素周围有足够空间使得螺旋至少能产生 4 个拐角后才越界或遇障碍；精灵体在各拐角位置印章后互不重叠（需要螺旋步长足够大，或精灵体足够小）。

**规则**：
1. 识别精灵体：找到最大的多色连通前景区域（含标记像素），提取其边界框内的图案。记录标记像素的颜色（红(2)或绿(3)）。
2. 从品红(6)种子像素出发，按方向序列"上→右→下→左"循环，步长序列 2, 2, 4, 4, 6, 6, ...，追踪螺旋路径。记录每个方向切换的位置为"拐角"，拐角从 1 开始编号。
3. 对每个拐角位置（编号 n）：
   - 若该拐角位置处于网格边界之外，跳过但编号继续递增。
   - 若以拐角位置为精灵体中心放置精灵体时，任何精灵体像素会落在灰(5)障碍像素上，则跳过该拐角（不印章），编号继续递增。
   - 否则，在该拐角位置印章精灵体（精灵体中心像素对齐拐角坐标）。
4. 镜像规则取决于标记颜色：
   - 若标记为红(2)：在偶数编号拐角（2, 4, 6, ...）处，先将精灵体水平镜像（左右翻转），再印章。奇数编号拐角不镜像。
   - 若标记为绿(3)：所有拐角均不镜像，直接印章。
5. 当螺旋路径连续 2 个拐角均因越界而跳过时，停止生成更多拐角（螺旋终止）。
6. 种子像素在输出中保持品红(6)。精灵体原始位置保持不变。多个印章若有像素重叠，后印的覆盖先印的。

**关键洞察**：螺旋不绘制线条——它生成一系列拐角坐标作为印章位置，使输出呈现出围绕种子的旋转展开形态。标记颜色是一个全局开关，决定是否启用交替镜像模式——求解者需要对比标记为红和标记为绿的不同示例，才能发现镜像与标记颜色之间的因果关系，而非误认为镜像取决于位置或方向。
