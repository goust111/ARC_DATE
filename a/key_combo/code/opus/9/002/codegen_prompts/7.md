## 新题 7：符号解码距离驱动射线延伸长度

**组合逻辑**：[符号解码/symbol_decoding](创新：解码输出不是颜色而是距离参数) + [延伸/extend](创新：延伸长度由解码值参数化，而非固定 1 格) + [射线延伸/ray_cast](已有) ← 搭配 [边缘条] + [控制像素] + [符号掩码] + [标记在两边之间]

**来源原语**：符号解码/符号掩码（17cae0c1）、延伸/边缘条/控制像素/标记在两边之间（642248e4）、射线延伸（673ef223）

**依赖链**：符号解码产生的距离值直接参数化了射线延伸的长度——延伸操作无法独立确定自己该延伸多远。同时，每个控制像素必须找到"最近"的符号面板，而"最近"的定义取决于控制像素和面板的空间关系。删除符号解码，延伸长度无从确定；删除延伸规则，解码结果无处使用。

每个控制像素读取最近的 3x3 符号面板，解码得到一个距离值，然后向其较近的边缘条方向发射该长度的射线。

**输入结构**：黑(0)背景网格，约 18x20。网格顶行和底行各有一条完整的彩色边缘条——顶行为红(2)，底行为绿(3)。在两条边缘条之间的区域内，散布着 3~5 个橙(7)的控制像素（孤立单像素）。此外，在该区域内还嵌入了 3~5 个 3x3 的符号面板，每个面板由灰(5)和黑(0)像素组成二值图案。符号面板之间互不重叠，与控制像素不重叠，且面板边界与控制像素的最小曼哈顿距离不小于 2。每个符号面板中灰(5)像素的数量在 1~7 之间（不为 0 也不为 9）。生成约束：每个控制像素有唯一最近的符号面板（以控制像素到面板中心的曼哈顿距离度量，不存在平局）。

**规则**：
1. 识别顶行红(2)边缘条和底行绿(3)边缘条。
2. 对每个 3x3 符号面板，计算其中灰(5)像素的数量 d（1 <= d <= 7），此为该面板编码的"距离值"。
3. 对每个橙(7)控制像素 P：
   a. 找到距离 P 曼哈顿距离最近的符号面板（以面板中心像素为参考点），读取其距离值 d。
   b. 计算 P 到顶行边缘条的距离 d_top = P.row - 0 和到底行边缘条的距离 d_bot = (max_row) - P.row。
   c. 若 d_top <= d_bot，P 朝上方发射射线：从 P 的上方相邻像素开始，沿列方向向上连续填充 d 个黑(0)像素为红(2)（较近边缘条的颜色）。若射线在到达 d 个像素之前遇到非黑(0)像素（包括边缘条或符号面板像素），则射线在该像素之前停止，不覆盖已有像素。
   d. 若 d_top > d_bot，P 朝下方发射射线：从 P 的下方相邻像素开始，沿列方向向下连续填充 d 个黑(0)像素为绿(3)。遇到非黑(0)像素时提前停止。
   e. d_top = d_bot 时（P 在正中间），朝上方发射（红(2)）。
4. 控制像素 P 本身保持橙(7)不变。符号面板保持原样。边缘条保持原样。

**关键洞察**：源题 642248e4 的延伸固定为 1 格，方向由距离决定；本题中距离值来自符号解码——一个空间参数由另一种视觉编码提供，形成跨模态耦合。符号面板的灰(5)像素计数规则（而非图案形状映射到颜色）需要多个示例对比才能归纳出。
