## 新题 7：碎片帧排序重建同心环，紧凑对象像素数编码环间距

**组合逻辑**：[排序/sorting + 按边长降序排列/descending_side_order](已有) → [同心层填充/concentric_fill](创新：环间不再紧邻，间距由另一对象的像素数参数化) + [像素数决定长度/pixel_count_length](创新：从决定线段长度改为决定环间距)

**来源原语**：排序/sorting(#c658a4bd), 同心层填充/concentric_fill(#c658a4bd), 碎片帧/fragmented_frame(#c658a4bd), 嵌套层次/nesting_hierarchy(#c658a4bd), 按边长降序排列/descending_side_order(#c658a4bd), 计数/counting(#e3fe1151), 压缩/compress(#c61be7dc), 像素数决定长度/pixel_count_length(#c61be7dc), 内部对象/inner_object(#c61be7dc)

**依赖链**：碎片帧的边界框最大维度决定各层预期边长 → 按边长降序排列确定嵌套层次 → 独立的紧凑对象的像素计数 G 决定相邻环之间的间隙宽度 → 同心环组装时，第 k 层环的边长 = 最外环边长 - 2kG。两条独立信息源（帧排序 + 像素计数）在组装步骤中合流。

将散乱的碎片帧按预期边长排序后重建同心方环，环与环之间的间隙宽度等于另一个紧凑对象的像素数。

**输入结构**：约 15x15 网格，黑(0)背景。网格中散布 3-5 个不同颜色的碎片方环，每个碎片方环是一个完整方环的部分可见片段（因相互遮挡或边界裁剪而缺失部分像素）。每个碎片方环的所有可见像素为同一颜色，颜色示例：红(2)、绿(3)、蓝(1)、黄(4)。此外，网格中另有一个与所有帧颜色不同的小型紧凑单色对象（如灰(5)，面积 1-4 像素的 4-连通图形），该对象不与任何碎片帧重叠。每个碎片帧的预期完整边长可从其所有可见像素的边界框的较大维度推断。生成约束：各帧预期边长互不相同；紧凑对象的像素数 G 满足最外环边长 - 2(N-1)G >= 1（N 为帧数），保证最内环至少有 1 像素。

**规则**：
1. 对每种碎片帧颜色，计算其所有可见像素的边界框，取较大维度作为该颜色的预期边长 S。
2. 按 S 从大到小排序所有帧颜色，确定嵌套层次：S 最大的在最外层。
3. 计算紧凑灰(5)对象的像素总数 G。
4. 构建输出：正方形画布，边长 = 最大 S。从外到内绘制同心方环：第 0 层（最外）为边长 S_0 的方环，使用排序第一的颜色；第 k 层的边长 = S_0 - 2kG，使用排序第 k 的颜色。每层环是 1 像素宽的方形边框。各层居中。
5. 若计算出的某层边长 <= 0，则该层不绘制（但在生成约束下不会发生）。

**关键洞察**：紧凑灰对象与碎片帧在视觉上毫无关联——一个是小斑点，一个是方环碎片。但小斑点的像素数精确编码了环间距参数。仅靠帧排序无法确定间距（间距不是帧自身属性），仅靠像素计数无法确定哪些颜色放在哪一层。两个独立信息源在组装步骤中交汇，缺一不可。
