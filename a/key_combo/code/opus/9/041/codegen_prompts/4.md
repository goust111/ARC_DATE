## 新题 4：角落码对称展开同心环后按环序交替打孔

**组合逻辑**：[对称补全/symmetry_completion](已有) → [擦除/erase](创新：擦除位置由环的嵌套序号决定相位) + [交替/alternating](创新：从单一矩形中心线的固定交替推广为多环间的相位交错)

**来源原语**：对称补全/symmetry_completion(#9d9215db), 镜像/reflect(#9d9215db), 角落编码/corner_code(#9d9215db), 对称展开/symmetric_unfolding(#9d9215db), 同心正方形层/concentric_square_ring(#9d9215db), 擦除/erase(#3bdb4ada), 交替/alternating(#3bdb4ada), 中心线/center_line(#3bdb4ada), 中线交替打孔/alternating_holes_on_center(#3bdb4ada)

**依赖链**：角落码决定有多少层同心环及各环颜色 → 对称展开生成完整环 → 环的嵌套序号（从外到内编号 0,1,2,...）决定打孔相位：偶数环从侧边第 1 个像素（0-indexed）开始打孔，奇数环从第 2 个像素开始 → 相邻环的孔洞互相错开形成视觉棋盘效果。环数和环色只有完成对称展开后才确定；打孔相位只有知道环序号后才确定。

将角落编码的稀疏像素展开为完整同心方环，然后在每层环的各侧边上按环序号的奇偶交替打孔。

**输入结构**：奇数边长（11-15）的正方形网格，黑(0)背景。前景像素仅出现在奇坐标格点上（行、列索引均为奇数），且集中在网格的某一个角落附近（例如左上角）。前景像素编码 3-5 层同心方环的信息：位于对角线上的像素指定该层环四角的颜色；位于水平或垂直轴上的像素指定该层环对应两侧边的颜色。各层环使用不同颜色，如红(2)、绿(3)、蓝(1)、黄(4)、橙(7)。生成约束：至少 3 层环。

**规则**：
1. 找到距所有前景像素最近的角落，将每个前景像素解释为相对于该角落的局部坐标，确定其描述的是哪一层环的哪个部分（对角线像素 → 四角色；轴向像素 → 对侧边色）。
2. 通过双边对称将角落码展开为完整的同心方环。环从外到内编号为 0, 1, 2, ...。
3. 对每层环的每条侧边（上、右、下、左各一条），沿侧边方向对非角落像素执行交替擦除：
   - 偶数环（序号 0, 2, 4, ...）：擦除侧边上偏移量为奇数的像素（偏移量从该侧边的起始角落像素之后开始计数，0-indexed，起始角落本身不计入）。
   - 奇数环（序号 1, 3, 5, ...）：擦除侧边上偏移量为偶数的像素。
4. 环的四个角落像素永远不被擦除。
5. 擦除的像素设为黑(0)。

**关键洞察**：相邻环的打孔相位相反——外环在偏移 1,3,5 处打孔，内环在偏移 0,2,4 处打孔。这形成一种"棋盘嵌套"视觉效果，是两道源题均不存在的涌现结构。仅看单层环无法判断相位规则，必须对比相邻环才能归纳出序号奇偶决定相位的规律。

    separation: Chebyshev distance >= 2 between any two objects (required for 8-connected distinctness)
    the two shapes must be visually distinct (not rotations/reflections of each other)
  output:
    same grid dimensions, background unchanged
    singleton object pixels -> color 2 (red)
    repeated object pixels -> color 1 (blue)

generation_strategy:
  approach: direct construction
  steps:
    1. Create 10x10 grid of background (0).
    2. Generate shape_A (the repeated shape) as a random 8-connected polyomino, 4-10 pixels, bbox 2-4 x 2-5.
    3. Generate shape_B (the singleton shape) as a different 8-connected polyomino, 4-10 pixels, bbox 2-4 x 2-5. Reject if normalized shape equals shape_A.
    4. Place 2 copies of shape_A and 1 copy of shape_B on the grid at random positions, ensuring Chebyshev distance >= 2 between all pairs and all cells within bounds.
    5. Fill placed pixels with a single foreground color (e.g. 8).
    6. Build output by recoloring singleton pixels to 2 and repeated pixels to 1.
