## 新题 6：印章形状驱动的递减外扩

**组合逻辑**：[印章覆盖(stamp_overlay) + 标记锚定精灵(marker_anchors_sprite)](已有) → [递减填充(shrinking_fill) + 边缘行程(side_run) + 四方外扩(four_way_expansion)](创新：递减填充的参数由被印章的精灵体形状决定，形状信息在操作间传递)

**来源原语**：印章覆盖+标记锚定精灵+标记模式匹配+精灵体 ← e6721834; 递减填充+边缘行程+四方外扩+逐步缩短行程 ← 9772c176; 外推 ← 9772c176

**依赖链**：印章操作将精灵体复制到多个位置（操作A），每个副本的边缘行程由精灵体的形状决定。递减外扩（操作B）的几何参数（条纹的初始长度和缩减速率）完全取决于边缘行程——即操作A传递给操作B的不仅是位置信息，还有形状信息。改变精灵体的形状会改变所有副本的外扩效果。

将精灵体按内部标记像素的相对位置印章到所有匹配的标记组位置，然后每个副本的四边向外发射递减条纹，条纹的初始长度等于该边的边缘行程长度。

**输入结构**：约 18x18 黑(0)背景网格。网格中有一个蓝(1)4-连通精灵体（边界框约 4x4 到 6x6，不规则形状，至少在上、下、左、右四边各有长度不小于 3 像素的连续边缘行程），精灵体内含 2-3 个红(2)标记像素。网格其他区域散布 2-3 组红(2)标记像素，每组的红标记相对位置与精灵体内红标记的相对位置完全匹配。生成约束：各标记组间距足够大（边界框间至少间隔 8 格），使得印章后的递减外扩不会越过其他精灵体副本的边界框；精灵体的四边边缘行程长度不全相同（至少有两边长度不同）。

**规则**：
1. 找到蓝(1)精灵体内所有红(2)标记像素，记录其相对于精灵体边界框左上角的坐标偏移集合 M。
2. 在网格中搜索所有红(2)标记像素组，使得某组标记的相对坐标偏移集合与 M 完全匹配。
3. 对每个匹配的标记组：以标记对齐的方式将蓝(1)精灵体印章到该位置——精灵体的蓝(1)像素绘制到目标位置，精灵体边界框内的黑(0)像素不绘制（即背景透明）。
4. 对每个已印章的精灵体副本（包含原始精灵体），检测其四边（上、下、左、右）的边缘行程：上边行程 = 精灵体最上行中连续蓝(1)像素的最长段长度；下边行程 = 最下行中同理；左边行程 = 最左列中连续蓝(1)像素的最长段长度；右边行程 = 最右列中同理。
5. 从每条边向外发射递减条纹（颜色黄(4)）：以该边行程为初始长度，每向外多一行/列，条纹长度减少 2 像素（两端各缩进 1 像素，保持居中），条纹在长度减至 0 时停止。具体地：上边向上延伸，第 k 层（k=1,2,...）的条纹长度为 max(0, 上边行程 - 2k)，条纹居中于上边行程的中心列位置；其余三边类似。
6. 递减条纹只绘制在黑(0)背景像素上，不覆盖已有的蓝(1)或红(2)像素。

**关键洞察**：递减外扩的几何形状不是固定的——它完全由精灵体的边缘轮廓决定。精灵体的不规则形状导致四边行程不同，从而四个方向的递减条纹高度各异。印章复制了形状，形状编码了递减参数，这种"形状即指令"的关系是两个操作的核心耦合。
