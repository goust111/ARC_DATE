## 新题 9：自色簇裁剪后周期平铺

**组合逻辑**：[角标记(corner_marker) + 包围关系(enclosure) + 标记色与对象同色(marker_obj_same_color)](已有) → [裁剪(crop)](已有) → [平铺(tiling) + 周期(period)](创新：裁剪的结果不是最终输出而是平铺的瓦片，对象选择条件与空间生成紧耦合)

**来源原语**：角标记+包围关系+中心对象+标记色与对象同色 ← da6e95e5; 裁剪 ← da6e95e5/963e52fc; 平铺+周期 ← 963e52fc/15696249

**依赖链**：选择规则（自色条件判断）决定裁剪哪个对象（操作A），裁剪结果的尺寸和内容直接成为平铺操作（操作B）的瓦片。如果选错了对象（非自色簇），平铺出的图案完全不同。选择条件→裁剪→平铺三步中，每一步的输出都是下一步的必要输入，且选择条件需对比多个簇才能归纳。

从多个角标记围成的簇中选择自色簇（标记颜色等于中心对象颜色），裁剪其中心对象，然后以此为瓦片向右向下平铺填满输出画布。

**输入结构**：约 16x16 黑(0)背景网格。2-3 个"簇"散布在网格中，每个簇由四个同色角标记像素（单像素，位于某矩形的四角）围成一个矩形区域，区域中心有一个 4-连通单色对象（3-8 像素，形状不规则）。不同簇的角标记颜色各不相同（如蓝(1)、红(2)、绿(3)）。恰好一个簇的角标记颜色与其中心对象颜色相同（自色簇）；其他簇的角标记颜色与中心对象颜色不同。生成约束：自色簇的中心对象边界框尺寸为 h x w（h, w 各在 2-4 之间）；各簇互不重叠。

**规则**：
1. 找到所有簇：四个同色像素构成矩形四角，矩形内部有一个不同于背景色的 4-连通对象。
2. 在所有簇中选择自色簇——角标记颜色等于中心对象颜色的那一个。
3. 裁剪自色簇的中心对象：以对象的边界框为范围，提取该矩形区域（包含对象像素和边界框内的黑(0)背景像素），得到一个 h x w 的瓦片。
4. 输出画布尺寸与输入相同。从画布左上角 (0,0) 开始，以瓦片的 h x w 为周期，向右向下重复平铺该瓦片，直到填满整个画布。
5. 超出画布右边界或下边界的瓦片截断（只绘制画布内的部分）。

**关键洞察**：选择哪个对象来平铺不是基于大小、位置或出现频率，而是基于"自色"条件——角标记与中心对象同色。这个选择规则必须对比多个簇才能归纳出：非自色簇的存在是干扰项。裁剪结果的形状直接决定平铺的周期，因此对象选择和空间生成紧密耦合。

1. `main(grid)` 必须实现新题描述中的确定性转换规则，不能只识别 `generate_input()` 的固定模板。禁止不同的input网格输出相同的output网格。
2. `generate_input()` 必须随机生成多样样例，不能固定死。随机维度应覆盖：网格大小、对象数量、位置、颜色、方向、形状参数或关键分支。注意若描述中存在若干，需实现而不是只有单个，包括object或者对应关系等等。且若涉及到最短路径，则输入网格中必涉及到多条路径，对选择造成干扰。
