## 新题 3：跨面板周期种子扩展

**组合逻辑**：[双面板(dual_panel) + 标记模式匹配(marker_pattern_match)](创新：匹配关系从精灵体标记变为周期图案的颜色匹配) → [周期(period) + 平铺(tiling)](创新：周期参数从源面板读取但相位由目标面板种子位置决定)

**来源原语**：双面板+标记模式匹配 ← e6721834; 种子像素 ← 8403a5d5; 周期+平铺 ← 963e52fc; 周期间隔 ← 8403a5d5

**依赖链**：源面板提供周期图案（参数来源），目标面板的种子提供颜色匹配键（配对依据）和列位置（相位编码）。颜色匹配确定"用哪个图案"，种子列位置确定"从周期的哪个相位开始"——两个信息缺一不可，且来自不同面板。

参照源面板中完整周期图案的周期和颜色，将目标面板中的种子像素扩展为对应颜色的周期条纹，种子的列位置决定条纹的相位偏移。

**输入结构**：约 10x21 网格。中间第 10 列为灰(5)分隔列，将网格分为左面板（列 0-9，10 列宽）和右面板（列 11-20，10 列宽），两面板等宽。左面板（源）：黑(0)背景上有 3 个完整的水平周期条纹，每个条纹占据一行，使用不同颜色（蓝(1)、红(2)、绿(3)），每个条纹由该颜色像素按固定周期 T（T 在 2-4 之间，各条纹周期可不同）排列，周期内非该颜色的位置为黑(0)。右面板（目标）：黑(0)背景上仅有 3 个孤立种子像素，颜色分别为蓝(1)、红(2)、绿(3)，每种颜色恰好一个种子，种子所在行位置与源面板中同色条纹的行位置不同。生成约束：三种颜色在源面板中各出现在恰好一个条纹行中；种子的列位置各不相同。

**规则**：
1. 保留左面板和灰(5)分隔列不变。
2. 对右面板中的每个种子像素（颜色为 C，位于行 r、列 c）：
   a. 在左面板中找到使用颜色 C 的条纹行。
   b. 读取该条纹行的最短水平周期 T 和周期内的颜色序列 P（长度为 T 的序列，由颜色 C 和黑(0)组成）。
   c. 计算种子在右面板内的本地列号 lc = c - 11（面板内偏移）。
   d. 在右面板的行 r 上，对每个列位置 j（j 从 11 到 20）：绘制颜色 P[(j - c) mod T]，即以种子列 c 为相位零点，向左右延伸周期序列 P。
3. 种子像素本身属于其条纹的一部分（P[0] 必为颜色 C）。

**关键洞察**：种子像素同时编码了三个信息——颜色（选择哪个源图案）、行（条纹输出在哪行）、列（周期的相位起点）。其中颜色→图案选择通过对比多个示例容易归纳，但列位置→相位偏移是隐蔽规则：如果只看一个示例，无法区分"种子列决定相位"和"条纹总是从面板左端开始"。
