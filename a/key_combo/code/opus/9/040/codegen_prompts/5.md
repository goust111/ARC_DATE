## 新题 5：频率角色驱动的分裂与重涂

**组合逻辑**：[角色分配(role_assignment) + 按频率分配(freq_role_assignment)](创新：频率排序不决定图案布局而决定操作类型分派) → [擦除(erase) + 滑动(slide) + 沿短轴分裂(split_along_short)](条件性触发) + [重涂色(recolor)](条件性触发)

**来源原语**：角色分配+按频率分配 ← 3979b1a8; 擦除+滑动+沿短轴分裂+裂缝标记线 ← 2faf500b; 重涂色 ← d6e50e54/0becf7df

**依赖链**：全局统计（像素频率排序）决定每种颜色在变换中的角色——哪种颜色的像素被擦除、哪种颜色的对象被分裂、哪种颜色的对象被重涂。这不是线性流水线，而是一个条件分支结构：先做全局分析（频率排序），然后根据分析结果将不同的操作分派给不同的颜色。操作 A（擦除裂缝标记）的执行使操作 B（分裂滑动）成为可能——裂缝线消失后才能沿切口推开两半。

按全局像素频率给三种前景色分配角色：最稀有色标记裂缝线并被擦除，中间频率色的对象沿裂缝分裂两半各推开一格，最常见前景色的对象整体重涂为最稀有色。

**输入结构**：约 14x14 黑(0)背景网格。三种非背景前景色（如蓝(1)、红(2)、绿(3)）的像素分布如下：中间频率色构成 2-3 个 4-连通单色对象（每个 8-14 像素），每个对象的边界框为非正方形矩形，对象内部含有最稀有颜色的像素，这些最稀有色像素在每个对象内构成一条沿对象短轴的完整横切线（即裂缝线——若对象边界框宽>高则为一完整垂直列，若高>宽则为一完整水平行）。最常见前景色构成 2-3 个 4-连通单色对象（每个 10-18 像素），这些对象内部不含其他颜色。最稀有色仅以裂缝线形式出现在中间频率色对象内部，不单独成对象。生成约束：三种颜色的总像素数互不相等且差距不小于 5 像素；各对象互不相邻。

**规则**：
1. 统计三种前景色在整个网格中的总像素数，确定最稀有色 Cr（总数最少）、中间频率色 Cm（总数居中）、最常见前景色 Cf（总数最多）。
2. 擦除所有 Cr 像素——将它们改为黑(0)背景。
3. 对每个 Cm 色对象：该对象现在有一条沿短轴的空缺带（原裂缝线位置已被擦除）。将空缺带一侧的 Cm 像素沿垂直于空缺带的方向外移一格，另一侧同样外移一格（两半分离）。具体地：若空缺带为垂直列，左侧像素整体左移一格，右侧整体右移一格；若空缺带为水平行，上侧像素整体上移一格，下侧整体下移一格。
4. 对每个 Cf 色对象：将其所有像素重涂为 Cr 色。
5. 背景像素不变。位移超出网格边界的像素丢弃。

**关键洞察**：颜色的全局统计频率决定了每种颜色在变换中的角色分派——同样的三种颜色在不同示例中可能因像素数量不同而扮演不同角色。单看一个示例只能观察到操作结果，必须对比多个示例中颜色角色的变化才能归纳出"按频率排序分配角色"这一隐蔽规则。
