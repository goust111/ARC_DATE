## 新题 2：反转镜像补全

**组合逻辑**：[对称补全](创新：补全规则从同色复制变为反转映射) + [反转填充](创新：反转范围从固定瓷砖扩展到由对称轨道推导的镜像位置) + [面板对齐·分隔列](已有，定义左右面板)

**来源原语**：对称补全(af22c60d)、双轴镜像轨道(af22c60d)、反转填充/occupancy_inversion(1c0d0a4b)、分隔列(34b99a2b)、面板对齐(34b99a2b)

**依赖链**：分隔列将网格分为左右面板 → 右面板是左面板的水平镜像但占据关系反转（左侧前景对应右侧背景，左侧背景对应右侧前景色）→ 右面板中品红色损坏标记处需同时运用镜像位置对应和反转规则来恢复正确值。缺少对称分析则不知道位置对应关系，缺少反转规则则填错颜色。

右面板是左面板的"负片镜像"——镜像决定位置对应，反转决定颜色翻转；修复被损坏标记覆盖的像素。

**输入结构**：约 15x13 网格（奇数列宽），背景黑(0)。中间一列为黄(4)分隔线。左半区包含红(2)色像素构成的不规则图案（一个 4-连通形状，占据半区 30%~50% 的格子），其余为黑(0)。右半区大部分已正确填充：左半为红(2)的镜像位置在右半为黑(0)，左半为黑(0)的镜像位置在右半为蓝(1)。右半中有 4~6 个像素被替换为品红(6)（"损坏标记"），这些位置的正确值可能是黑(0)也可能是蓝(1)。生成约束：损坏标记中至少各有 1 个正确值应为黑(0)和应为蓝(1)的情况，使求解者必须同时理解镜像和反转两条规则。

**规则**：
1. 识别黄(4)分隔列，将网格分为宽度 W 的左半 L 和右半 R（不含分隔列）。
2. 左半 L 和右半 R 通过水平镜像对应：R 的第 j 列对应 L 的第 W-1-j 列。
3. 反转镜像规则：L[r, W-1-j] 为红(2) 时，R[r, j] 应为黑(0)；L[r, W-1-j] 为黑(0) 时，R[r, j] 应为蓝(1)。
4. 将右半所有品红(6)像素按上述规则替换为正确颜色。
5. 分隔列、左半、右半中非品红像素均不变。

**关键洞察**：右面板不是左面板的简单镜像复制，而是镜像加占据反转加颜色变换的三重叠加。蓝色图案恰好是红色图案的"负片"——必须同时把握镜像轴和反转关系才能修复损坏像素。仅从右面板自身的蓝色分布无法推断损坏像素的值，必须参照左面板。
