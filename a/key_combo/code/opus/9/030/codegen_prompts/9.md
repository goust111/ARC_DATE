## 新题 9：格网中颜色编码方向与空间距离编码幅度的双因子印章

**组合逻辑**：[印章覆盖/分隔线划分](创新：印章放置位置由双因子位移决定) + [颜色编码位移](创新：颜色仅编码方向，不再同时编码幅度) + [压缩](创新：格网距离编码位移幅度) + [位置索引](创新：将格网坐标差转化为位移量)

**来源原语**：印章覆盖/分隔线划分/标记单元格/格网(39e1d7f9), 颜色编码位移/颜色决定偏移(342dd610), 压缩/包含于(ac6f9922), 位置索引(09629e4f)

**依赖链**：格网压缩确定每个单元的内容和坐标→单色标记像素的颜色编码位移方向→标记像素与模板精灵的格网距离编码位移幅度→方向 x 幅度 = 完整位移向量→按此向量在标记所在单元放置偏移后的模板印章。四个因素缺一不可。

在分隔格网中，一个单元包含多像素模板精灵，其余单元包含单色标记。标记颜色编码位移方向，标记与模板的格网距离编码位移幅度，两者共同决定模板印章在标记单元内的偏移放置位置。

**输入结构**：约 17x17 的网格。灰(5)分隔线（宽 1 像素的完整水平线和垂直线）将网格划分为 4x4 或 5x5 的等大方形单元格阵列（每个单元格内部约 3x3 像素）。所有单元格内部背景为黑(0)。恰好一个单元格包含一个多像素彩色精灵体（模板，2~4 像素，4-连通，使用品红(6)），占据单元格内部的特定位置。若干其他单元格各包含一个单像素标记，颜色为以下四种之一：红(2)表示左、蓝(1)表示右、橙(7)表示上、绿(3)表示下。其余单元格为空（纯黑内部）。生成约束：标记单元格与模板单元格的格网曼哈顿距离（行差绝对值+列差绝对值，以单元格为单位）为 1~3；将模板按编码位移偏移后放置在标记单元格内时，不超出单元格内部边界；至少有 3 个标记单元格，且至少使用 2 种不同的方向颜色。

**规则**：
1. 将格网压缩为单元格阵列：识别灰(5)分隔线，确定每个单元格的内部区域和在阵列中的坐标 (gr, gc)。
2. 找到包含多像素精灵体的单元格，记录其阵列坐标 (Tr, Tc) 和精灵体的内部偏移图案（各像素相对于单元格内部左上角的偏移）。
3. 对每个包含单像素标记的单元格，设其阵列坐标为 (Mr, Mc)，标记颜色为 C：
   a. 方向解码：红(2)→左(0, -1)，蓝(1)→右(0, +1)，橙(7)→上(-1, 0)，绿(3)→下(+1, 0)。记方向单位向量为 (dr, dc)。
   b. 幅度计算：格网曼哈顿距离 D = |Mr - Tr| + |Mc - Tc|。
   c. 位移向量 = (dr * D, dc * D)，单位为单元格内部像素格。
   d. 将模板精灵体的每个像素偏移加上位移向量，放置在该标记单元格的内部。超出单元格内部范围的像素丢弃。
4. 标记像素本身被模板印章覆盖（若模板偏移后覆盖了标记位置）或清除为黑(0)（若未被覆盖）。
5. 模板所在的原始单元格保持不变。空单元格保持不变。灰(5)分隔线保持不变。
6. 输出整个网格。

**关键洞察**：位移信息被拆分编码在两个独立维度上——颜色负责方向，空间距离负责幅度。求解者必须同时破解两层编码并将它们乘积组合，才能确定每个标记位置的印章偏移。这是一种"双因子乘积编码"，在任何单个参考题中都不存在。
