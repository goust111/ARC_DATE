## 新题 2：重力沉降后按连通面积分类处理

**组合逻辑**：[重力下落](已有) + [连通性/尺寸分类](创新：面积三分类决定保留/描边/擦除) + [描边](创新：仅对特定面积类别执行)

**来源原语**：重力下落/沿路径滑动/碰撞停止(28a6681f), 连通性/连通分量(e0fb7511), 尺寸分类(b27ca6d3), 描边(b27ca6d3), 擦除(e39e9282)

**依赖链**：彩色像素经重力沉降后的最终位置决定了连通分量的形成；连通分量的面积决定了该分量的命运（保留/描边/擦除）。删除重力步骤则连通结构完全不同；删除分类规则则无法确定输出。

彩色像素在障碍物间做重力沉降，落定后按 4-连通分量面积决定命运：孤点保留、双联体描边、大团簇擦除。

**输入结构**：约 14x12 的网格。黑(0)背景。上半区散布若干彩色像素（颜色各异，均非黑非灰），它们之间互不 4-连通。下半区有灰(5)像素构成的静态障碍物结构，形成若干水平台面和凹槽（障碍物像素之间 4-连通，形成固定的地形）。生成约束：经重力沉降后，彩色像素之间恰好形成至少一个面积为 1 的分量、至少一个面积为 2 的分量、至少一个面积 >= 3 的分量。同一位置不会有两个像素同时沉降到达。

**规则**：
1. 逐个处理彩色像素（按原始位置从上到下、同行从左到右的顺序）。每个像素从当前位置向下逐格移动，穿过黑(0)空格。当正下方被阻挡（障碍物或已沉降的像素或网格底边）时停止。若停止位置的正下方被挡但左下或右下有空位，像素滑向有空位的一侧（仅左下开放则滑向左下，仅右下开放则滑向右下，两侧均开放则滑向左下）。滑动后继续尝试下落，重复此过程直到像素无法再移动。
2. 所有像素沉降完毕后，在彩色像素（不含灰色障碍物）之间计算 4-连通分量。
3. 面积 = 1 的分量：保持原色不变。
4. 面积 = 2 的分量：保留分量本身的像素，并绘制绿(3)描边——将该分量的边界框向四个方向各扩展 1 格（裁剪到网格范围内），在扩展后边界框的周边像素中，仅将当前为黑(0)的像素涂为绿(3)。
5. 面积 >= 3 的分量：擦除该分量的所有像素（设为黑(0)）。
6. 灰(5)障碍物在全过程中始终保持不变。

**关键洞察**：大团簇反而不稳定会被清除，只有恰好成对的像素获得描边强调——重力沉降的最终格局决定了哪些像素能"存活"，面积既非越大越好也非越小越好。
