## 新题 4：异常值象限反选为全局印章模板

**组合逻辑**：[相等比较/异常值选择](创新：异常值不是输出而是模板来源) + [重涂色](创新：模板颜色依目标单元格的原有颜色重新着色) + [印章覆盖](创新：模板来自动态检测而非预设)

**来源原语**：相等比较/异常值选择/输出唯一象限(88a62173), 重涂色(09629e4f/e0fb7511), 印章覆盖/分隔线划分(39e1d7f9), 位置索引(09629e4f)

**依赖链**：先通过象限比较找到异常值——这不是最终输出，而是确定模板；然后对每个非异常象限，提取其主色来为模板重新着色；最后将重着色的模板印章到各象限。异常值检测→模板确定→颜色适配→印章覆盖形成不可跳过的链。

在分隔栅格的多个单元中找出图案唯一的异常单元，将其图案作为模板，用每个其他单元的主色重新着色后印章覆盖到所有非异常单元。

**输入结构**：约 15x15 的网格。灰(5)分隔线将网格划分为 3x3 的单元格阵列（分隔线为完整的水平线和垂直线，宽度 1 像素）。每个单元格内部为黑(0)背景上的一个小型彩色图案（4-连通的单色像素组，3~6 像素，形状不规则）。9 个单元格中，有 4 个使用图案 A（形状和位置相同，颜色相同），4 个使用图案 B（形状和位置相同，颜色相同，但 A 和 B 的形状不同），恰好 1 个使用独特的图案 C（形状与 A、B 均不同）。A 和 B 使用不同的非黑非灰颜色，C 使用第三种非黑非灰颜色。生成约束：图案 A、B、C 的像素数在 3~6 范围内且互不相同；每个图案在其单元格内的位置（相对于单元格左上角的偏移）固定。

**规则**：
1. 将每个单元格的内容（排除分隔线）作为一个图案数组。逐对比较所有 9 个单元格的图案，找到仅出现一次的图案 C 所在的单元格，即异常单元格。
2. 提取图案 C 作为"主模板"——记录其中每个非黑像素相对于单元格左上角的偏移位置。
3. 对每个非异常单元格：找到该单元格内图案使用的非黑颜色（即该图案的唯一颜色）。将主模板中所有非黑像素替换为该颜色，生成该单元格专属的重着色模板。
4. 将重着色模板印章到对应单元格中（按偏移位置放置像素），替换原有图案。单元格中主模板未覆盖的位置设为黑(0)。
5. 异常单元格本身保持图案 C 不变。灰(5)分隔线保持不变。
6. 输出整个网格。

**关键洞察**：异常值不是被抛弃或被输出的对象——它反而成为了统治全局的模板。每个非异常单元格贡献自己的颜色但丧失自己的形状，接受异常值的形状支配。
