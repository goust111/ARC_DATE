## 新题 1：桥接网络决定同心填充模式

**组合逻辑**：[连通判定](创新：从二元连通测试扩展为连通分量大小分析) → [同心层填充](创新：填充模式由外部图结构决定而非固有属性) / [纯色填充](孤立帧的替代输出)

**来源原语**：连通判定(connectivity_test, #239be575), 桥接路径(bridge_path, #239be575), 同心层填充(concentric_fill, #a3f84088), 按距离循环配色(distance_color_cycling, #a3f84088), 空心矩形(hollow_rectangle, #917bccba / #a3f84088 / #c0f76784), 连通性(connectivity, #239be575)

**依赖链**：桥接路径决定帧之间的连通关系 → 连通分量大小决定每个帧的填充模式（同心循环 vs 纯色）→ 同心填充在被激活的帧内部按距离着色。删除连通判定则无法区分两种填充模式；删除同心填充则被激活帧的输出无法确定。

将散布于网格上的空心矩形帧按桥接路径分组，连通分量内帧数 >= 2 的帧做同心层填充，孤立帧做纯色填充，桥接路径本身在输出中被擦除。

**输入结构**：约 22x22 的黑(0)背景网格。网格上散布 4-6 个灰(5)一像素厚的空心正方形帧，边长各不相同（范围 5-11 像素），帧之间无重叠，彼此间距至少 2 像素。部分帧对之间由 1 像素宽的青(8)桥接路径连接——桥接路径是从一个帧外壁的某像素出发，沿水平或垂直方向延伸到另一个帧外壁的像素的直线段。每个帧最多参与 2 条桥接路径。生成约束：至少存在一个包含 2 个以上帧的连通分量，且至少存在一个孤立帧（不参与任何桥接路径）。

**规则**：
1. 以灰(5)帧为节点、青(8)桥接路径为边，构建无向连通图。计算每个连通分量包含的帧数。
2. 对于所在连通分量帧数 >= 2 的帧：保留灰(5)外框不变，在其严格内部区域按曼哈顿距离（从内壁向内计算，最外一层内部像素距离为 0）循环填充颜色序列 [红(2), 蓝(1)]——距离 0 填红(2)，距离 1 填蓝(1)，距离 2 填红(2)，依此类推，直到中心。
3. 对于孤立帧（所在连通分量帧数 = 1）：保留灰(5)外框不变，内部全部填充黄(4)。
4. 擦除所有青(8)桥接路径像素（置为黑(0)）。
5. 其余黑(0)背景像素不变。

**关键洞察**：桥接路径在输出中完全消失——它们的唯一功能是编码帧之间的连通关系。求解者必须先识别桥接网络的拓扑结构，才能确定每个帧该用哪种填充模式。仅看单个示例时，可能误以为填充模式由帧的大小或位置决定，必须对比多个示例才能归纳出"连通分量大小"这一真正的判断条件。
