## 新题 8：像素放大后涌现封闭区域并按计数着色

**组合逻辑**：[像素放大](创新：放大不是最终变换，而是为后续检测创造条件) → [连通检测](创新：检测的是放大涌现出的封闭区域) → [计数](创新：封闭区域总数决定填充规则的选择) → [填充](创新：填充规则本身由计数结果参数化)

**来源原语**：像素放大(pixel_upscale, #9172f3a0), 每像素扩展为色块(each_pixel_expanded_to_block, #9172f3a0), 填充(fill, #44d8ac46 / #c0f76784), 封闭区域(enclosed_region, #44d8ac46 / #c0f76784), 面积决定填充色(area_determines_fill_color, #c0f76784), 连通检测(connected_component_detection, #3194b014), 内部包含(containment, #44d8ac46)

**依赖链**：像素放大将每个像素扩展为 3x3 色块 → 在放大后的网格中，原本不相邻的有色像素可能形成连续边界，涌现出放大前不存在的封闭区域 → 检测并计数这些封闭区域 → 区域总数 E 决定采用哪套填充颜色规则 → 按规则填充每个封闭区域。放大是检测的前提，计数是规则选择的前提，三层依赖不可跳步。

将小网格像素放大 3 倍，检测放大后涌现的封闭黑色区域，按区域总数选择填充规则，按面积着色。

**输入结构**：一个 4x4 或 5x5 的网格，包含黑(0)背景和 2-3 种非黑色前景色的像素。前景像素在原始分辨率下不一定形成封闭边界，但在 3 倍放大后（每个像素变为 3x3 同色块），扩展后的色块之间可以形成完整的封闭围栏，将部分黑(0)区域完全包围。生成约束：放大后至少存在 1 个、至多 4 个被前景色块完全包围的黑(0) 4-连通区域（不接触放大后网格的边界）。

**规则**：
1. 将输入网格进行 3 倍最近邻放大：输入位置 (r, c) 的颜色复制到输出的 (3r..3r+2, 3c..3c+2) 区域，形成一个 (3H)x(3W) 的网格。
2. 在放大后的网格中，找到所有由黑(0)像素构成的 4-连通区域。将不接触网格边界的区域标记为"封闭区域"。
3. 计算封闭区域的总数 E。
4. 按 E 选择填充规则：
   - E = 1：将该唯一封闭区域填充为红(2)。
   - E = 2：面积较大的封闭区域填红(2)，较小的填蓝(1)。面积相同时，边界框左上角行号较小的填红(2)。
   - E >= 3：所有封闭区域统一填充为绿(3)。
5. 接触网格边界的黑(0)区域和所有前景色块保持不变。

**关键洞察**：原始小网格中的像素排列看似简单，但 3 倍放大后几何关系质变——不相邻的像素变为相邻的色块，可能围出新的封闭区域。求解者必须先在脑中执行放大，才能看到这些涌现的封闭结构。此外，填充规则不是固定的——它由封闭区域的总数参数化，需要对比包含不同 E 值的示例才能完整归纳。

    each loop's boundary is entirely one frame_color; the line_color pixels touch the loop's OUTER edges (8-adjacent) without bordering the cavity directly

  connectivity:
    loops attached to the seed's line (8-connected via line_color) get their cavity filled with seed_color
    filled: 1-8 per example; unfilled (distractor): 0-5
    at least 1 unfilled cavity exists in 5/6 examples [observed]
  distractors:
    0-1 disconnected 8-connected non-bg components with no seed; may contain line+frame structure or be a single frame loop
  output: same grid with each connected cavity flood-filled by its seed's color

generation_strategy:
  approach: output-first
  steps:
    1. Choose grid size, bg color, 1-2 seeds with unique colors, and per-seed line_color
    2. For each seed, draw a meandering 8-connected line path from the seed's border position inward, using diagonal and orthogonal steps
    3. Along each line, attach 2-5 frame loops (closed rings of a frame_color enclosing a 2x2 bg cavity); the line touches the loop at 1-2 outer edge positions (8-adjacent to the frame ring)
    4. Place 0-3 additional distractor loops (same frame_color or different) NOT 8-connected to any line
    5. Optionally add 0-1 disconnected non-bg component as a distractor network
    6. Verify: each cavity has single-color boundary; cavities connected to a line are fillable; at least 1 unfilled cavity exists
    7. Output is derived by flood-filling each connected cavity with its seed_color
