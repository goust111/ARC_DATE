## 新题 4：镜像错切对与楔形间隙填充

**组合逻辑**：[镜像](创建对称副本) + [错切](两份反向行偏移) → [填充 + 两体之间](创新：间隙形状由错切与原始图案共同决定)

**来源原语**：错切(shear, 3cd86f4f), 行偏移递变(row_offset_progress, 3cd86f4f), 行内容保持(row_content_preserved, 3cd86f4f), 镜像(mirror, 93c31fbe), 填充(fill, d6ad076f), 间隙区域(gap_region, d6ad076f), 两体之间(between_two_objects, d6ad076f), 间隙区域涂色(gap_region_recolor, d6ad076f)

**依赖链**：原始图案→镜像产生对称副本→两份分别做反向错切→错切后两份向彼此倾斜，各行的边缘位置不同→每行的间隙宽度 = 两份在该行的最近像素之间的距离，由原始图案的行宽和错切偏移共同决定→间隙填充。间隙的形状既不是矩形也不是简单的三角形，而是由图案轮廓和错切量共同决定的不规则楔形。

用一句话概括：将一个小图案及其水平镜像分别向内做反方向错切，然后用青色填充两个倾斜副本之间逐行变化的楔形间隙。

**输入结构**：
- 黑(0)背景网格，约 6x15（高 6、宽 15）。
- 网格中央偏左有一个彩色矩形图案（H 行 x W 列，如 4x3），不含黑色像素，使用 2-3 种前景色（如蓝(1)、红(2)、绿(3)）。图案的各行宽度相同（矩形），但行内的颜色分布不对称（使镜像后可区分方向）。
- 生成约束：H >= 3, W >= 2；画布宽度 >= 2W + 2H - 1（足够放置两个错切副本和间隙）；图案左右两侧有足够黑色空间。

**规则**：
1. 将原始图案记为 P（H x W 矩阵）。创建其水平镜像 P'（每行像素左右翻转）。
2. 在输出画布上放置 P 的错切版：P 的第 r 行（r = 0 为顶行）起始列为 c_left + r，其中 c_left 为画布最左可用位置。即逐行向右偏移 1 列（下行右移的错切）。
3. 在输出画布上放置 P' 的错切版：P' 的第 r 行起始列为 c_right - r，其中 c_right 确保顶行时 P' 最左像素与 P 最右像素之间恰好有 H-1 列的间隔。即逐行向左偏移 1 列（下行左移的错切）。
4. 两个错切副本向彼此倾斜。对每一行 r，找到左副本在该行的最右像素列 R_L(r) 和右副本在该行的最左像素列 L_R(r)。将 R_L(r)+1 到 L_R(r)-1 之间的所有黑色像素填充为青(8)。
5. 若某行左副本与右副本之间没有黑色间隙（已紧邻或重叠），则该行不填充。
6. 输出画布。

**关键洞察**：间隙区域不是固定形状，而是由错切偏移和原始图案的逐行宽度共同雕刻而成。顶行间隙最宽（H-1 列），底行间隙最窄甚至消失——这个楔形渐变是错切操作的涌现效应，源题中的间隙填充（两个静态矩形之间的固定间隙）和错切（单个对象的行偏移）都无法单独产生这种效果。

    objects sharing same target edge must occupy non-overlapping row/col bands (no collision after move)
  rule:
    move_direction: away from marker side to opposite grid edge (left->right, right->left, top->bottom, bottom->top)
    cross_rotation: rotate 3x3 cross block 180 degrees within the composite
    marker_block: unchanged
    final_position: object bbox flush against target grid edge, same row (horizontal) or column (vertical)

generation_strategy:
  approach: output-first
  steps:
    1. Choose grid H x W (5-18 each), object count N (1-4), and marker color (use 1).
    2. For each object, pick direction (left/right/top/bottom) and assign a row/col band at the target edge for the output. Ensure non-overlapping 3-row (horizontal) or 3-col (vertical) bands at each edge.
    3. Build each output object at its target-edge position: construct a random 5-color cross (center=4, arms from remaining non-bg non-marker colors), attach the direction-appropriate marker block.
    4. Derive input by inverting the transformation: rotate the cross block 180 degrees back, then place the composite at a random interior position along its movement axis (>= 2 cells from target edge). Verify no overlap with other input objects.

## 实现要求

1. `main(grid)` 必须实现新题描述中的确定性转换规则，不能只识别 `generate_input()` 的固定模板。禁止不同的input网格输出相同的output网格。
2. `generate_input()` 必须随机生成多样样例，不能固定死。随机维度应覆盖：网格大小、对象数量、位置、颜色、方向、形状参数或关键分支。注意若描述中存在若干，需实现而不是只有单个，包括object或者对应关系等等。且若涉及到最短路径，则输入网格中必涉及到多条路径，对选择造成干扰。
3. 生成器必须保证输入满足 `main()` 的隐式假设：对象不重叠、不越界、特殊标记唯一或可区分、匹配关系无歧义、关键分支出现概率相同。
4. 禁止把 ARC 颜色 id 、亮度、拼写等当作人类不可见的数值语义参与排序、大小比较或隐藏映射。颜色变化必须有可见结构线索。注意颜色亮度、拼写等也是不可见信息，若描述中出现违规的颜色id或者亮度，可自行使用少量的固定颜色替代，但注意生成时要在三个以内输入输出网格中对所有变换100%覆盖度。
5. 输出样例要视觉清晰，人类必须能从输入输出对中肉眼辨认出规律。具体要求：避免对象粘连、覆盖关系混乱、同一像素多重语义；不同逻辑步骤产生的结果不要大面积层叠在一起导致无法分辨哪个颜色属于哪个步骤；输入中各元素之间保持足够间距，输出中新增的标记/填充/路径等应与背景和已有元素在颜色上有明显区分；若规则涉及多层叠加，生成时控制对象密度和尺寸，确保叠加区域只占少数像素而非铺满整个网格。
6. 若规则有多个分支，生成器不能长期固定成一个分支；应让分支在随机样例中合理出现。分支概率不必平均——难以发现的隐蔽分支（如少数情况下才触发的特殊规则）应适当提高出现概率，确保在 3 个训练示例中至少出现一次，否则求解者无法归纳该规则。对于颜色映射类规则，确保 2 个左右的示例即可覆盖所有映射关系（每种颜色→颜色的映射至少在某个示例中出现过）。
