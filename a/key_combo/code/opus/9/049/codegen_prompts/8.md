## 新题 8：平铺后重力沉降与对角邻接装饰

**组合逻辑**：[平铺](复制空间结构) → [重力下落 + 碰撞停止](重新排列) → [描边 + 对角邻接](装饰沉降后的新布局)

**来源原语**：平铺(tiling, 10fcaaa3), 种子像素(seed_pixel, 10fcaaa3), 描边(mark_neighbors, 10fcaaa3), 对角邻接(diagonal_adjacency, 10fcaaa3), 平铺后对角涂色(diagonal_marked_after_tiling, 10fcaaa3), 重力下落(gravity_drop, 2b83f449), 碰撞停止(collision_stop, 2b83f449)

**依赖链**：小网格平铺为 2x2→种子像素在四个象限中各有一份副本→重力使所有种子在各列中下落并堆叠→不同象限的种子副本可能落入同一列形成紧密堆叠→对角邻接装饰在沉降后的新布局上执行，堆叠导致种子间产生源网格中不存在的新对角邻接关系。三步操作串联，每步的输出实质改变下一步的输入。

用一句话概括：将含种子和墙的小网格 2x2 平铺后，所有种子像素在平铺网格中做重力沉降，最后在沉降后的位置对黑色对角邻居涂青色。

**输入结构**：
- 一个小黑(0)背景网格（3 行 x 4 列）。
- 网格中有 2-3 个彩色种子像素（颜色各不相同，如红(2)、绿(3)、蓝(1)），分布在网格的中上部。
- 网格底行有 1-2 个灰(5)墙像素，作为种子下落的固定阻挡。
- 生成约束：种子不在底行（留出下落空间）；种子不与墙相邻（初始状态下无接触）。

**规则**：
1. 将 3x4 的输入网格 2x2 平铺，生成 6x8 的网格。所有像素（种子、墙、黑色背景）均复制到四个象限。
2. 在平铺后的 6x8 网格中执行重力下落：所有种子像素（非黑、非灰、非青的彩色像素）在各自所在列中向下移动。灰(5)墙像素不移动。种子遇到墙像素、已落定的种子或网格底边时停止。同一列中从底部开始依次处理（最低的种子先落定）。
3. 种子的原始位置恢复为黑(0)。
4. 对平铺网格中每个已落定的种子像素，检查其四个对角邻居（左上、右上、左下、右下）。若对角邻居为黑(0)，则将其涂为青(8)。若对角邻居为非黑色（种子、墙或已有的青色），则不覆盖。
5. 输出 6x8 网格。

**关键洞察**：平铺创造了原始网格中不存在的种子-种子空间关系（不同象限的同一种子副本出现在新的列中）。重力将这些副本压缩到列底部，导致不同颜色的种子可能紧密堆叠，产生新的对角邻接对。对角装饰揭示了这种堆叠结构——装饰图案的形状是平铺和重力共同作用的涌现结果。

    size: 4-6 rows x 4-6 cols (interior >= 2x2 so 4 corners are distinct)
    color: any non-bg color
    placement: >=1 cell from every grid edge (exterior corners need bg space)
  markers:
    count: exactly 4, one at each interior corner of the frame
    interior_corners: (r0+1,c0+1), (r0+1,c1-1), (r1-1,c0+1), (r1-1,c1-1)
    colors: 4 distinct colors, each != bg and != frame_color
    rest_of_interior: all bg (no other foreground besides frame + markers)
  no_other_foreground: only frame pixels and 4 marker pixels are non-bg
  transform:
    each marker at interior corner moves to diagonally opposite exterior corner
    TL_interior(r0+1,c0+1) -> BR_exterior(r1+1,c1+1)
    TR_interior(r0+1,c1-1) -> BL_exterior(r1+1,c0-1)
    BL_interior(r1-1,c0+1) -> TR_exterior(r0-1,c1+1)
    BR_interior(r1-1,c1-1) -> TL_exterior(r0-1,c0-1)
    frame stays unchanged; source pixels cleared to bg

generation_strategy:
  approach: output-first
  steps:
    1. Pick grid 10x10, bg=0.
    2. Pick frame_color (non-bg). Pick frame bbox (r0,c0)-(r1,c1) with h,w in 4-6 each, ensuring >=1 gap to all grid edges.
    3. Pick 4 distinct marker colors (all != bg, != frame_color).
    4. Place frame border pixels. Place markers at interior corners.
    5. Verify exterior destination cells (r0-1,c0-1), (r0-1,c1+1), (r1+1,c0-1), (r1+1,c1+1) are within grid and bg.
    6. This directly produces a valid input; output is derived by moving markers to opposite exterior corners.

## 实现要求

1. `main(grid)` 必须实现新题描述中的确定性转换规则，不能只识别 `generate_input()` 的固定模板。禁止不同的input网格输出相同的output网格。
2. `generate_input()` 必须随机生成多样样例，不能固定死。随机维度应覆盖：网格大小、对象数量、位置、颜色、方向、形状参数或关键分支。注意若描述中存在若干，需实现而不是只有单个，包括object或者对应关系等等。且若涉及到最短路径，则输入网格中必涉及到多条路径，对选择造成干扰。

6. 若规则有多个分支，生成器不能长期固定成一个分支；应让分支在随机样例中合理出现。分支概率不必平均——难以发现的隐蔽分支（如少数情况下才触发的特殊规则）应适当提高出现概率，确保在 3 个训练示例中至少出现一次，否则求解者无法归纳该规则。对于颜色映射类规则，确保 2 个左右的示例即可覆盖所有映射关系（每种颜色→颜色的映射至少在某个示例中出现过）。
