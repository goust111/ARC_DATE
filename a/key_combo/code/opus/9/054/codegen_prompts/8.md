## 新题 8：同心环层数编码输出尺寸，环色序列异或填充输出

**组合逻辑**：[计数](从分区计数创新为环层计数编码维度) + [异或](已有，但作用于抽象颜色序列而非空间掩码) + [嵌套层序](已有) + [分隔行](已有) + [同心环](已有)

**来源原语**：计数/分隔栅格/分区数定输出尺寸(1190e5a7), 异或/分隔行/掩码/对齐/逐像素异或输出(3428a4f5), 同心环/嵌套层序/色沿层序循环移(bda2d7a6)

**依赖链**：上下两半各含同心环——上半环层数 R 和下半环层数 C 编码输出网格的行数和列数——上半各环颜色映射到输出的各行、下半各环颜色映射到输出的各列——每个输出格 (r,c) 由第 r 个上半环色和第 c 个下半环色的"异同"决定颜色。环的几何结构同时编码了维度信息和内容信息。

上下两组同心环的层数决定输出尺寸，环色序列逐对比较——相同为黑(0)、不同为绿(3)——生成输出矩阵。

**输入结构**：黑(0)背景网格，约 16x16（保证上下两半各 7-8 行）。一条黄(4)水平满行将网格分为上下两半，上下两半行数相同。上半部分由同心矩形环填满（每环恰好一格厚、单色，从最外层到最内层可使用红(2)、蓝(1)、绿(3)、灰(5)等颜色，颜色可重复）。下半部分同样由同心矩形环填满（结构类似但环层数和颜色可不同）。生成约束：上半和下半的同心环均为完整的矩形环（最内层可以是单格或一条线段）；环层数各自在 2-5 之间。

**规则**：
1. 定位黄(4)分隔行。将网格分为上半和下半。
2. 在上半中，从最外层到最内层依次读取每个同心矩形环的颜色，得到颜色序列 T = [t1, t2, ..., tR]，共 R 层。
3. 在下半中，同样从最外层到最内层读取颜色序列 B = [b1, b2, ..., bC]，共 C 层。
4. 创建一个 R 行 C 列的输出网格。
5. 对输出的每个格子 (r, c)（r 从 1 到 R，c 从 1 到 C）：若 T[r] 与 B[c] 颜色不同，则该格输出绿(3)；若相同，则输出黑(0)。
6. 输出仅为该 R x C 小网格，不包含分隔行或原始环结构。

**关键洞察**：同心环的几何结构承担了双重编码角色——环的层数决定输出的维度（这在 1190e5a7 中由栅格分区完成），环的颜色序列决定输出的内容（这在 3428a4f5 中由空间掩码完成）。求解者必须同时理解"层数→尺寸"和"颜色异同→输出值"两条规则，且两者均依赖正确识别嵌套层序。仅看单个示例无法区分"颜色异同→绿/黑"和"颜色相同→绿"等替代规则。
