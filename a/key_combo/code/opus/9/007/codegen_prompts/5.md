## 新题 5：遮挡层序编码周期色彩表的循环序列

**组合逻辑**：[补全/reconstruct + 遮挡层序/occlusion_order](已有，创新用途：层序 = 色彩循环顺序) + [周期推断/periodic_inference + 间隙填充/gap_fill](已有，创新用途：循环顺序来自外部编码)

**来源原语**：补全/reconstruct、遮挡层序/occlusion_order、遮挡碎片/occluded_fragment、可见像素定边框/visible_defines_bbox、忽略干扰项/ignore_distractors（参考题 652646ff）；周期推断/periodic_inference、间隙填充/gap_fill、表格/table、空白单元格/blank_cell、对角线相位偏移/diagonal_phase_shift、按列周期取色/column_modular_phase（参考题 1e97544e）

**依赖链**：左侧区域的重叠菱形片段 → 根据遮挡关系推断从上到下的层序 → 层序定义颜色循环的排列顺序（最上层颜色 = 循环位置 0） → 右侧区域的周期表使用该循环 + 对角相位偏移填充空白格。两个子问题单独均不可解：表格中的空白太多使得仅凭可见格无法唯一确定循环顺序；菱形的遮挡排名本身只是一个列表，没有应用场景。

从重叠的彩色菱形碎片推断遮挡层序，将层序作为色彩循环的顺序，填充右侧周期表中的空白单元格。

**输入结构**：
- 网格大小约 15x20。
- 背景：黑(0)。
- **左侧区域**（约 15 行 x 8 列）：3~4 个菱形（旋转 45 度的正方形轮廓，每个约 4x4 边界框，8~12 像素，共享同一几何模板，仅做平移）部分重叠。每个菱形使用不同单色（如蓝(1)、绿(3)、红(2)、黄(4)）。重叠区域只显示上层菱形的颜色，下层像素被遮挡。另有少量孤立单体像素（与任何菱形模板平移副本不吻合）为噪声，应忽略。
- **右侧区域**（约 15 行 x 12 列）：一个 S x S 方形子网格充当周期表（S 约 8~12）。部分单元格填有与菱形相同的颜色（蓝(1)、绿(3)、红(2)、黄(4)），遵循带对角相位偏移的周期模式；其余单元格为灰(5)表示空白。
- 两个区域之间无显式分隔线，但互不重叠。
- 生成约束：菱形间的遮挡关系构成全序（无环、无并列）。周期表中至少 40% 的单元格为空白。仅凭可见（非灰）单元格能验证循环但无法唯一确定循环顺序（至少存在两种循环排列与可见格兼容），必须依赖遮挡层序来消歧。

**规则**：
1. **识别菱形**：在左侧区域，找出所有非背景、非噪声颜色。菱形模板是某个固定形状（旋转正方形轮廓），各颜色的像素必须完全落在该模板的某个平移副本上。不符合任何平移副本的孤立像素为噪声，忽略。
2. **推断遮挡层序**：对每个菱形颜色 C，检查其模板副本中缺失的像素位置——该位置当前被另一颜色 D 占据，说明 D 在 C 之上。收集所有这样的"D 在 C 之上"关系，拓扑排序得到从上到下的全序。
3. **读取色彩循环**：将遮挡全序从上到下映射为循环位置：最上层颜色 = 位置 0，第二层 = 位置 1，依此类推。设共 N 个菱形颜色，循环周期为 N。
4. **填充周期表**：在右侧区域的 S x S 方形子网格中（以子网格左上角为原点，行索引 r、列索引 c 从 0 开始）：若 r <= c（在主对角线上方或上），该单元格的颜色 = cycle[c mod N]；若 r > c（在主对角线下方），该单元格的颜色 = cycle[(c+1) mod N]。
5. 仅将灰(5)空白单元格替换为上述规则计算出的颜色。已有颜色的单元格和左侧区域的所有像素保持不变。

**关键洞察**：左侧的重叠菱形不是装饰或独立子题——它们的遮挡关系是右侧表格唯一的"图例"。表格中的可见格故意设计得太稀疏，使得多种循环排列均兼容，只有菱形的层序能消除歧义。求解者必须跨越网格的两个视觉区域建立联系：一侧编码顺序，另一侧使用顺序。
