## 新题 5：路径端点拼接后恢复周期缺损

**组合逻辑**：[滑动/sliding + 端点对齐/endpoint_align + 端点匹配拼接/endpoint_match_concat](已有) → [几何重排改变周期结构](创新：拼接后的垂直对齐产生新的像素排列) → [补全/completion + 周期重复/periodic_repeat + 前景残留推断周期/residue_infers_period](已有)

**来源原语**：滑动/sliding、路径片段/path_segment、端点/endpoint、端点对齐/endpoint_align、端点匹配拼接/endpoint_match_concat（参考题 d017b73f）；补全/completion、周期瓦片/periodic_tile、缺损像素/erased_pixel、周期重复/periodic_repeat、前景残留推断周期/residue_infers_period（参考题 ea959feb）

**依赖链**：路径片段的端点拼接改变了各片段的垂直位置，这直接影响拼接后图案的周期结构。正确推断周期需要正确的拼接对齐，而正确的拼接需要识别端点——两个操作通过几何对齐关系耦合，而非数据的顺序传递。

将分隔的路径片段按端点对齐拼接成连续链，拼接后的图案呈现带缺损的周期结构，推断最小周期并补全缺损像素。

**输入结构**：约 8x20 的黑(0)背景网格（矮而宽）。包含 3-4 组路径片段，每组占据连续的若干非背景列，组间由全背景列分隔。每组使用多种前景色（如蓝(1)、红(2)、绿(3)），形成类似路径的图案。每组在其左边缘和右边缘各有一个度为 1 的前景端点像素（即仅有一个前景邻居的前景像素）。拼接后的完整图案应具有行列周期性，但部分前景像素被擦除为黑(0)。生成约束：拼接后的图案的最小行周期和最小列周期均不超过 4；被擦除的像素数不超过拼接后前景总像素数的 30%。

**规则**：
1. 识别由全背景列分隔的路径片段组。
2. 删除全背景分隔列。保持第一组的垂直位置不变。
3. 从左到右逐组拼接：将当前组垂直平移，使其左端点与前一组的右端点位于同一行，然后紧贴前一组右侧放置。
4. 拼接完成后，忽略黑(0)像素，从剩余前景像素中推断最小行周期 pr 和最小列周期 pc，使得每个前景像素的颜色与同一残差类 (r mod pr, c mod pc) 中其他前景像素颜色一致。
5. 对每个残差类，若该类中有前景像素，则将该类中所有黑(0)像素补全为该类的前景颜色。无前景证据的残差类保持黑(0)。

**关键洞察**：拼接时的垂直偏移量改变了各像素的行坐标，从而改变了 r mod pr 的值——错误的拼接导致错误的周期推断。需要对比示例才能确认拼接规则（端点对齐而非简单平移）。

1. `main(grid)` 必须实现新题描述中的确定性转换规则，不能只识别 `generate_input()` 的固定模板。禁止不同的input网格输出相同的output网格。

6. 若规则有多个分支，生成器不能长期固定成一个分支；应让分支在随机样例中合理出现。分支概率不必平均——难以发现的隐蔽分支（如少数情况下才触发的特殊规则）应适当提高出现概率，确保在 3 个训练示例中至少出现一次，否则求解者无法归纳该规则。对于颜色映射类规则，确保 2 个左右的示例即可覆盖所有映射关系（每种颜色→颜色的映射至少在某个示例中出现过）。
