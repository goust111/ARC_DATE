## 新题 1：同心方框生长与交叉遮挡分层

**组合逻辑**：[生长/grow + 同心方框层/concentric_layer](已有) → [遮挡层次/occlusion_order + 排序/sort](已有，创新：遮挡序由种子的跨组空间侵入关系决定) → [重涂色/recolor](已有，创新：重叠区按分层序上色)

**来源原语**：生长/grow、同心方框层/concentric_layer、种子像素/seed_pixel、等距对角排列/equi_diag_array（参考题 5c2c9af4）；排序/sort、层序推断/layer_infer、遮挡层次/occlusion_order、交叉点/crossing_point、唯一序链/unique_chain（参考题 22425bda）

**依赖链**：每组种子生长出的同心方框面积取决于种子间距，而某组方框是否覆盖另一组的种子像素位置决定了遮挡的上下关系——种子同时充当生长参数和遮挡判据，两个操作通过种子位置的双重角色紧耦合。

从多组等距对角种子分别生长同心方框，再根据方框对他组种子的空间侵入关系确定分层顺序，渲染重叠区的可见颜色。

**输入结构**：约 20x20 的黑(0)背景网格。其上散布 3-4 组种子像素，每组由 3 个同色像素组成，三点位于同一条 45 度对角线上且间距相等（不同组间距可不同）。不同组使用不同颜色，可选蓝(1)、红(2)、绿(3)、黄(4)等。各组的对角线方向和间距在不同示例中有所变化。生成约束：不同组的中心种子像素之间的曼哈顿距离至少为 4，保证方框有交叠但种子本身不重合。

**规则**：
1. 对每组 3 个同色种子像素，找到中间点（中心种子）和两端点之间的间距 d。
2. 以中心种子为中心，在间距 d 的整数倍处画同心空心方框边框（与参考题 5c2c9af4 相同），直到方框完全超出网格边界。方框使用该组颜色绘制。
3. 判定遮挡顺序：若 A 组的任意方框边框覆盖了 B 组的某个种子像素的位置（以初始种子位置为准，非生长后），则 A 在 B 之下（B 遮挡 A）。沿此关系传递排序，构成一条从底到顶的唯一序链。生成约束保证此关系无环且形成唯一全序。
4. 按从底到顶的顺序依次渲染各组方框：后渲染的覆盖先渲染的。非重叠区域保留各组颜色，重叠区域显示层次更高组的颜色。
5. 种子像素本身保留在输出中，颜色不变。

**关键洞察**：种子像素的位置同时决定了方框的生长中心/尺寸和跨组遮挡顺序——删掉遮挡逻辑则重叠区颜色不确定，删掉生长逻辑则无方框可供分层。遮挡方向需要对比多个示例才能归纳（侵入 vs 被侵入的上下关系不靠直觉可判断）。
