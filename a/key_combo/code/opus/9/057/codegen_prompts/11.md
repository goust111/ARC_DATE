## 新题 11：连线路径交叉颜色编码驱动层序排列

**组合逻辑**：[连线/draw_line + 两点直线路径/straight_two_point + 按原色区分涂色/recolor_by_origin](已有，创新：多组标记对产生多条交叉线) → [交叉颜色产生遮挡约束](创新：连线相交处的可见色与被覆盖色给出上下关系) → [排序/sort + 层序推断/layer_infer + 唯一序链/unique_chain](已有，创新：排序对象不是预存在的线而是刚画出的线)

**来源原语**：连线/draw_line、标记像素/marker_pixel、线段/line_segment、两点直线路径/straight_two_point、按原色区分涂色/recolor_by_origin（参考题 bcb3040b）；排序/sort、层序推断/layer_infer、直线/straight_line、交叉点/crossing_point、遮挡层次/occlusion_order、唯一序链/unique_chain（参考题 22425bda）

**依赖链**：连线操作生成了线段实体，这些线段的交叉产生了遮挡信息，遮挡信息驱动层序排序。连线的"按原色区分涂色"规则在交叉处产生了双色冲突，冲突解决方式（后画的覆盖先画的）本身编码了绘制顺序——但输出要求的是与绘制顺序无关的、由空间关系决定的层序。两个逻辑形成对抗性耦合。

多对同色标记画出直线段，线段在交叉处产生颜色覆盖，从覆盖关系推断唯一的层序链并输出颜色序列。

**输入结构**：约 15x15 的黑(0)背景网格。包含 3-4 对标记像素，每对同色，可用蓝(1)、红(2)、绿(3)、黄(4)等颜色。每对标记位于同一水平线、垂直线或 45 度对角线上。另有少量灰(5)色前景像素散布在网格中（作为"原有前景"）。各对标记之间的连线路径至少两两有一个交叉点。生成约束：所有交叉点处的遮挡关系构成一条无矛盾的唯一全序链（即不存在 A 在 B 上方且 B 在 A 上方的环）；每条线至少与另一条线交叉一次。

**规则**：
1. 对每对同色标记，画出包含两端点的直线路径。路径上每个像素：若原为灰(5)则变为橙(7)，若原为黑(0)或为标记色则变为该对标记的颜色。
2. 当多条线的路径经过同一个像素时，该像素显示最后一条线的颜色（按线的颜色在输入中标记像素从左上到右下的扫描顺序决定先后，靠后的覆盖靠前的）。
3. 从交叉处的可见颜色推断遮挡关系：在交叉像素处，可见颜色的线在被覆盖颜色的线之上。
4. 将所有线的颜色排成一条从底到顶的唯一序链，要求相邻颜色在序链中对应的线几何上有交叉。
5. 输出为一行 1xK 的网格（K 为线的数量），从左到右排列层序链中从底到顶的颜色。

**关键洞察**：连线操作不仅生成了视觉线段，还通过覆盖规则隐式编码了绘制顺序，而绘制顺序正是遮挡关系的来源。需要对比多个示例才能归纳绘制顺序规则（扫描序而非其他顺序）以及层序链的输出方向（底到顶从左到右）。
