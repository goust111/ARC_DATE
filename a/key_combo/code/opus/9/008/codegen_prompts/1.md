## 新题 1：路径追踪选取对称填充目标

**组合逻辑**：[路径追踪/path_follow] → [对称图案选取/symmetric_selected](创新：对称性不再是选取输出对象，而是决定是否对路径源区域执行填充) → [填充/fill]

**来源原语**：路径追踪、引导像素、路径连接（来自 9ba4a9aa）；镜像、对称、对称图案选取（来自 d56f2372）；填充、封闭区域（来自 d4f3cd78）

**依赖链**：路径追踪确定每个封闭区域与哪个远端图形关联 → 对称性检测作为布尔门控：只有远端图形通过垂直镜像对称测试时，对应的封闭区域才被填充 → 填充颜色由远端图形的颜色决定。三步缺一不可：无路径则不知道谁关联谁，无对称检测则所有区域都会被填充（错误），无填充则无输出变化。

从封闭区域出发沿引导路径找到远端图形，仅当远端图形垂直对称时，用其颜色填充源区域。

**输入结构**：约 20x20 的黑(0)背景网格。包含 3~4 个灰(5)像素构成的封闭矩形轮廓（每个约 4x4 至 6x6，4-连通闭合，内部全黑），彼此相距至少 3 格。每个封闭轮廓的外侧恰好有一个相邻像素作为引导路径的起点，引导像素沿水平/垂直方向以间隔 2 格的栅格排列（与 9ba4a9aa 一致），每条路径使用与其他路径不同的非黑非灰颜色（如蓝(1)、红(2)、绿(3)、黄(4)）。每条引导路径的末端相邻一个由该路径颜色构成的小型单色图形（3~6 像素的 4-连通区域）。这些远端图形中，恰好部分的包围框裁剪是左右镜像对称的，其余不对称。生成约束：每条路径颜色唯一且路径之间不交叉；每个远端图形仅与一条路径关联。

**规则**：
1. 识别所有灰(5)封闭矩形轮廓及其内部黑色区域。
2. 对每个轮廓，找到其外侧唯一相邻的非黑非灰引导像素，确定引导颜色。
3. 沿该颜色的引导像素链（每步水平或垂直跳 2 格到下一个同色像素）追踪路径，直至路径末端。
4. 找到路径末端相邻的同色远端图形，裁剪其包围框。
5. 测试该裁剪是否等于其左右镜像翻转。若对称：用该颜色填充对应封闭轮廓的全部内部黑色像素。若不对称：该轮廓内部保持黑色不变。
6. 灰色轮廓、引导路径、远端图形在输出中保持原样不变。

**关键洞察**：引导路径不是装饰，它建立了封闭区域与远端图形之间的一一映射；远端图形的几何对称性是一个隐式布尔开关，决定对应区域是否被着色。仅看单个示例可能误以为"所有区域都填充"或"特定颜色才填充"，必须对比多个示例才能归纳出对称性才是真正的门控条件。

## 实现要求

1. `main(grid)` 必须实现新题描述中的确定性转换规则，不能只识别 `generate_input()` 的固定模板。禁止不同的input网格输出相同的output网格。
2. `generate_input()` 必须随机生成多样样例，不能固定死。随机维度应覆盖：网格大小、对象数量、位置、颜色、方向、形状参数或关键分支。注意若描述中存在若干，需实现而不是只有单个，包括object或者对应关系等等。且若涉及到最短路径，则输入网格中必涉及到多条路径，对选择造成干扰。
3. 生成器必须保证输入满足 `main()` 的隐式假设：对象不重叠、不越界、特殊标记唯一或可区分、匹配关系无歧义、关键分支出现概率相同。
4. 禁止把 ARC 颜色 id 、亮度、拼写等当作人类不可见的数值语义参与排序、大小比较或隐藏映射。颜色变化必须有可见结构线索。注意颜色亮度、拼写等也是不可见信息，若描述中出现违规的颜色id或者亮度，可自行使用少量的固定颜色替代，但注意生成时要在三个以内输入输出网格中对所有变换100%覆盖度。
5. 输出样例要视觉清晰，人类必须能从输入输出对中肉眼辨认出规律。具体要求：避免对象粘连、覆盖关系混乱、同一像素多重语义；不同逻辑步骤产生的结果不要大面积层叠在一起导致无法分辨哪个颜色属于哪个步骤；输入中各元素之间保持足够间距，输出中新增的标记/填充/路径等应与背景和已有元素在颜色上有明显区分；若规则涉及多层叠加，生成时控制对象密度和尺寸，确保叠加区域只占少数像素而非铺满整个网格。
6. 若规则有多个分支，生成器不能长期固定成一个分支；应让分支在随机样例中合理出现。分支概率不必平均——难以发现的隐蔽分支（如少数情况下才触发的特殊规则）应适当提高出现概率，确保在 3 个训练示例中至少出现一次，否则求解者无法归纳该规则。对于颜色映射类规则，确保 2 个左右的示例即可覆盖所有映射关系（每种颜色→颜色的映射至少在某个示例中出现过）。
