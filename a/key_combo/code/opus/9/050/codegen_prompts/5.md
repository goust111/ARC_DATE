## 新题 5：引导线穿过空心框架则填充内部

**组合逻辑**：[连线(draw_line)](创新：引导线的判定对象从实心物体变为空心框架的内部空间) + [填充(fill)](创新：填充由线-框穿越关系驱动) + [接触判定(contact_detection)](创新：从表面接触改为穿透内部)

**来源原语**：边界标记对(border_marker_pair) ← 0d87d2a6；引导线(guide_line) ← 0d87d2a6；连线(draw_line) ← 0d87d2a6/29c11459；空心矩形(hollow_rectangle) ← e73095fd；封闭孔洞(enclosed_hole) ← e73095fd；仅填矩形内部(fill_interior_only) ← e73095fd；接触判定(contact_detection) ← 0d87d2a6

**依赖链**：边界标记对确定引导线方位 → 引导线在网格上绘制 → 引导线是否穿过框架内部空间（而非仅接触外壁）决定填充与否。判定标准是"穿透"而非"邻接"——引导线必须有像素落在框架轮廓围住的内部区域中，而非仅与轮廓 4-邻接。

边界标记对定义的引导线穿透空心框架内部时，该框架被填充。

**输入结构**：约 18x18 的网格，黑(0)为背景。网格的左右边缘或上下边缘上有若干蓝(1)标记像素，成对出现——每对标记分布在相对的两条边上，且共享同一行（左右对）或同一列（上下对）。网格内部散布 3~4 个黄(4)色空心矩形框架，每个框架是单像素厚的矩形轮廓（宽和高均至少 4），内部为黑(0)。框架彼此不重叠。标记对数量为 2~3 对。生成约束：至少 1 条引导线穿过某框架的内部空间（即引导线上至少有一个像素落在框架轮廓严格围住的内部区域内），至少 1 个框架不被任何引导线穿过（引导线可能从框架外侧经过或不经过该区域）。

**规则**：
1. 识别所有蓝(1)边界标记对：在网格左边缘和右边缘同一行上各有一个蓝像素，则构成一个水平对；在上边缘和下边缘同一列上各有一个蓝像素，则构成一个垂直对。
2. 对每个标记对，在其共享的行（水平对）或列（垂直对）上画一条贯穿整行/整列的蓝(1)引导线。引导线覆盖该行/列的所有像素，但不覆盖黄(4)框架轮廓像素（黄色优先于蓝色）。
3. 对每个黄(4)框架，检查其内部区域（轮廓严格围住的黑色矩形区域）中是否包含至少一个蓝(1)引导线像素。"内部"指轮廓向内缩进一圈后的矩形区域。
4. 若框架内部包含引导线像素，将该框架的整个内部区域填充为绿(3)（覆盖内部的蓝色引导线像素和黑色像素）。
5. 未被引导线穿过的框架保持内部为黑(0)不变。
6. 输出为与输入同尺寸的网格，包含蓝引导线（在背景区域可见）、黄框架轮廓和条件填充结果。

**关键洞察**：引导线与框架的关系不是表面接触，而是空间穿透——引导线必须有像素落入框架内部才触发填充。一条从框架外侧擦过（仅与轮廓邻接但不穿过内部）的引导线不会触发填充，求解者需对比"被穿过但被填充"和"被擦过但未填充"的示例才能区分。
