## 新题 7：分割线编码缩放因子驱动配对精灵放大

**组合逻辑**：[连线(draw_line)/分裂(split)](创新：分割线的数量被重新解读为数值编码) + [像素放大(pixel_scaling)](创新：放大倍率由外部编码结构决定) + [裁剪(crop)] + [排序(sort)]

**来源原语**：标记像素(marker_pixel) ← 855e0971/6d1d5c90；标记沿短轴展分割(marker_short_axis_div) ← 855e0971；矩形区域(rect_region) ← 855e0971；像素放大(pixel_scaling) ← f25fbde4；含间隙等比放大(scale_with_gaps) ← f25fbde4；裁剪(crop) ← f25fbde4/67636eac；连通精灵(connected_sprite) ← 67636eac；编码映射(encoding_map) ← 65b59efc

**依赖链**：矩形中的标记像素展开为分割线 → 分割线数量确定该矩形的段数 → 段数作为缩放因子传递给配对精灵 → 精灵按该因子像素放大。分割线的空间意义（切割矩形）与数值意义（编码倍率）被同时使用——空间效果可见于输出左半部，数值效果体现在输出右半部。

矩形中的标记分割线数量编码了配对精灵的像素放大倍率。

**输入结构**：约 20x15 的网格，黑(0)为背景。网格左半区包含 3 个灰(5)色实心矩形区域（每个宽 4~6、高 3~5 像素），沿纵向排列（由上到下分别为第 1、2、3 个矩形，互不重叠）。每个矩形内部有 0~2 个红(2)色标记像素，位于矩形内部（非边缘行列上的位置）。网格右半区包含 3 个小型单色精灵体（每个使用不同颜色，从蓝(1)、绿(3)、黄(4)中选取），每个精灵体 3~5 像素，4-连通，具体形状在不同示例中不同。精灵体也沿纵向排列，由上到下的垂直顺序与左半区矩形一一对应（第 1 个精灵对应第 1 个矩形，以此类推）。生成约束：3 个矩形的标记像素数互不相同（分别为 0、1、2 个），对应缩放因子分别为 1、2、3。

**规则**：
1. 在左半区每个灰色矩形中，将每个红(2)标记像素沿矩形的短轴方向展开为一条贯穿矩形该维度的分割线：若矩形宽 > 高，则沿整列（垂直方向）画分割线；若高 > 宽，则沿整行（水平方向）画分割线；若宽 = 高，则沿整列画线。分割线颜色为红(2)，覆盖该行/列中矩形内的所有像素。
2. 统计每个矩形中的分割线数量 d（等于该矩形中红色标记像素的数量）。缩放因子 f = d + 1。
3. 按纵向位置（包围框上边缘行索引从小到大），将左半区第 k 个矩形与右半区第 k 个精灵体配对。
4. 将每个精灵体裁剪至紧凑包围框，然后进行 f 倍像素放大：将裁剪后的每个像素替换为 f x f 的同色像素块。
5. 输出仅包含放大后的精灵体：按配对顺序从上到下垂直排列，顶部对齐于输出网格左上角，相邻放大精灵之间有 1 行黑(0)间隔。输出网格宽度等于所有放大精灵中的最大宽度（较窄的精灵右侧补黑），高度等于所有放大精灵高度之和加上间隔行。

**关键洞察**：分割线在矩形内的空间作用（将矩形切为若干段）与其在精灵处的数值作用（编码放大倍率）完全不同——标记数量被从一种语义（空间分区工具）转化为另一种语义（数值参数），求解者需要发现这种跨结构的编码关系。
