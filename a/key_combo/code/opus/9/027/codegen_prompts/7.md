## 新题 7：遮挡序推断与排名边界着色

**组合逻辑**：[透明叠加 · 逆向推断](从重叠可见色推断前后遮挡序) → [排序](全序排列) → [重涂色](按深度排名涂矩形边界)（创新：遮挡序是隐变量，必须从重叠区域的可见色反推）

**来源原语**：透明叠加(ea9794b1), 图层优先级(ea9794b1), 面板位决定层序(ea9794b1), 排序(f8ff0b80), 面积排序(f8ff0b80), 重涂色(ef26cbf6), 实心矩形(ec883f72), 忽略干扰项(d90796e8)

**依赖链**：重叠区域可见色 → 推断成对遮挡关系（A盖住B） → 拓扑排序得到全局前后序 → 深度排名 → 排名映射到边界颜色 → 边界重叠处使用同一遮挡序解决覆盖冲突

从多个重叠矩形的可见颜色逆推遮挡顺序，按深度排名为每个矩形的边界环着色。

**输入结构**：约 14x14 的网格，黑(0) 背景。4 个轴对齐的实心矩形部分重叠，每个矩形使用唯一的前景色，取自 {蓝(1), 红(2), 绿(3), 黄(4)}。矩形尺寸各异（3x3 到 6x5），放置位置使得每对矩形至少有 1 行 1 列的重叠区域。在重叠区域中，只有"最前方"矩形的颜色可见，被遮挡矩形的颜色不可见。生成约束：遮挡关系构成全序（不存在循环遮挡，如 A 盖 B、B 盖 C、C 盖 A 的情况），且仅通过观察两两重叠区域的可见色即可唯一确定该全序。每个矩形的完整范围（包括被遮挡部分）是一个轴对齐实心矩形。

**规则**：
1. 对每对重叠的矩形 (X, Y)，检查重叠区域的可见颜色：若可见色为 X 的颜色，则 X 在 Y 前方。据此建立所有成对遮挡关系。
2. 对成对关系进行拓扑排序，得到从前到后的全序。分配深度排名：最前方 = 排名 1，其次 = 排名 2，以此类推至排名 4。
3. 确定每个矩形的完整范围（包括被遮挡部分）：最前方矩形的范围即为其可见像素的包围框；对于被部分遮挡的矩形，其完整范围需从可见部分推断——沿被遮挡边界方向，矩形的实际边界在遮挡矩形的对侧（即被盖住的角落在遮挡矩形下方延伸，直到形成完整矩形，由多个示例共同约束确定推断方法）。
4. 对每个矩形，计算其边界环（矩形最外一圈像素）。按深度排名重涂边界环颜色：排名 1→青(8), 排名 2→橙(7), 排名 3→品红(6), 排名 4→灰(5)。矩形内部（非边界）保持原色不变。
5. 边界环之间可能重叠（两个矩形边界交叉处）。重叠位置由遮挡序决定：前方矩形的边界色覆盖后方矩形的边界色。
6. 被遮挡的内部像素（前方矩形覆盖下方矩形的非边界区域）恢复为后方矩形的原色（即"揭开"遮挡，在输出中所有矩形的内部均可见原色，仅边界环颜色改变）。

**关键洞察**：遮挡顺序是必须从重叠证据反推的隐变量——输入中没有任何显式标注前后关系，求解者需通过"哪个颜色盖住了哪个颜色"的逻辑推断全序，然后将该序应用于一个完全不同的视觉特征（边界环着色）。
