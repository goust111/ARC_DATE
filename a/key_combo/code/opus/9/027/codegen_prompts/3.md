## 新题 3：角落收缩涌现连接线

**组合逻辑**：[裁剪 + 拼接](角落模式提取并缩合到最小画布) → [连线](收缩后同行同列的标记像素之间画线)（创新：连线目标由空间收缩涌现，原图中不可见）

**来源原语**：裁剪(bc1d5164), 拼接(bc1d5164), 角落图案(bc1d5164), 角落对应(bc1d5164), 最小包围框收缩(bc1d5164), 连线(cbded52d), 标记像素(cbded52d), 同行列对齐(cbded52d), 局部偏移保持(cbded52d)

**依赖链**：角落裁剪+拼接将四个角落图案压缩到紧凑画布 → 画布收缩改变了标记像素之间的距离关系 → 原本隔着大片空白的标记像素在收缩后落入同一行或同一列 → 同行/列标记之间的空白区域被连线填充 → 连线的存在本身是收缩操作的涌现结果

提取四角图案缩合画布后，原本不可见的同行列标记对齐关系浮现，沿缩合后的行列画连接线。

**输入结构**：约 20x20 的网格，黑(0) 背景。四角各有一个不超过 5x5 的图案区域，图案使用蓝(1) 和绿(3) 像素（每个角落图案是一个由 4-8 个像素构成的 4-连通不规则形状）。在某些角落图案中，存在橙(7) 标记像素（每个角落 0-2 个橙色像素，嵌在图案内部或边缘）。网格中央 10x10 区域全为黑(0)。生成约束：四个角落的图案缩合后（见下文规则），恰好存在 2-3 对橙(7) 像素落在同一行或同一列上，且这些对齐关系在原 20x20 网格中不成立（因为距离太远中间全是空白）；橙(7) 像素仅出现在不同角落的图案中（同一角落内的橙色像素不与同角落的其他橙色像素在缩合后对齐）。

**规则**：
1. 确定每个角落图案的最小包围框尺寸。取四个包围框中最大的边长 s（若宽和高不同，分别取最大宽 w 和最大高 h）。
2. 创建 (2w+1) x (2h+1) 的输出网格，黑(0) 填充。中央的第 w+1 列和第 h+1 行构成十字分隔带（保持黑色）。
3. 将左上角图案复制到输出的左上 w x h 区域（保持角落相对偏移），右上角图案复制到右上 w x h 区域，左下角复制到左下区域，右下角复制到右下区域。每个图案在其 w x h 区域内的位置与其在原网格角落中的局部偏移一致。
4. 在输出网格中，查找所有橙(7) 像素对：若两个橙(7) 像素位于同一行，将它们之间所有黑(0) 像素涂为橙(7)；若位于同一列，同理。多条连线可能交叉，交叉处保持橙(7)。
5. 蓝(1)、绿(3) 图案像素和橙(7) 标记像素保持不变，连线不覆盖已有的非黑色像素。

**关键洞察**：在 20x20 原图中，分属不同角落的橙色标记看起来完全无关——只有将画布收缩到最小尺寸后，它们才意外落入同行/列而触发连线规则，连线是空间收缩的涌现效果。

  output_colors: black + red + green; green only appears on expanded domino borders

generation_strategy:
  approach: direct random placement (input-first); transform is additive and non-destructive
  steps:
    1. pick grid size uniformly in 15-17 rows x 16-18 cols
