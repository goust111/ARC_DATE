## 新题 4：弹性模板对照缺陷检测与光环标记

**组合逻辑**：[弹性拉伸 + 模板填充](计算目标矩形的正确内容) → [连通检测](逐像素对比，找到不匹配点) → [标记环绕](对缺陷像素画 8-邻域光环)（创新：缺陷定义依赖弹性拉伸结果，不在输入中直接可见）

**来源原语**：弹性拉伸(40f6cd08), 模板填充(40f6cd08), 内部行程(40f6cd08), 按目标尺寸调整(40f6cd08), 标记环绕(71e489b6), 缺陷像素(71e489b6), 邻域包围(71e489b6), 异常值选择(71e489b6), 多色范例矩形(40f6cd08)

**依赖链**：弹性拉伸计算每个目标矩形的预期内容 → 与实际内容逐像素对比，差异位置即为缺陷 → 缺陷位置决定光环绘制区域 → 缺陷像素本身被修正为预期颜色

根据范例矩形的弹性拉伸结果判断目标矩形中的异常像素，修正异常并为其添加橙色光环。

**输入结构**：约 20x18 的网格，黑(0) 背景。左上角有一个多色"范例矩形"（约 4x3），由黄(4) 外框包围内部的水平色带（例如上带蓝(1)、下带红(2)），外框和色带各一像素厚。网格其他区域分布着 3-4 个矩形，每个矩形的尺寸不同（宽度 4-8，高度 3-6），矩形内部已填入了与范例弹性拉伸后相近的色带图案（外框固定为黄(4)，内部色带在宽度方向被拉伸以适应该矩形的宽度）。其中 1-2 个矩形内部有 1-2 个像素的颜色与正确拉伸结果不同（即"缺陷像素"，例如本应为蓝(1) 的位置被绿(3) 替代）。没有缺陷的矩形内容与正确拉伸完全一致。生成约束：缺陷像素不出现在矩形外框上，仅出现在内部色带区域；每个缺陷像素的颜色与其正确值不同且不是黑(0)。

**规则**：
1. 识别范例矩形：含有多种内部颜色且最小的矩形，记录其外框色和内部色带的行程编码（逐行的颜色序列）。
2. 对每个非范例矩形，根据其尺寸计算弹性拉伸结果：保持外框厚度不变（1 像素），将内部色带在宽度方向拉伸以填满矩形内部。拉伸方式为：识别范例内部各列中颜色种类最多的那一列为"可变列"，仅拉伸该列对应的行程以适配目标宽度，其余列保持原宽度。高度方向同理处理。
3. 逐像素对比每个非范例矩形的实际内容与计算出的预期内容。颜色不匹配的位置标记为"缺陷"。
4. 将每个缺陷像素修正为预期颜色。
5. 对每个缺陷位置，在其 8-邻域（上下左右及四个对角方向）的黑(0) 背景像素上涂橙(7)，形成光环。若 8-邻域的某个位置不是黑(0)（已被矩形内容或其他光环占据），则该位置不涂橙色。

**关键洞察**：缺陷不是通过颜色异常直接识别（缺陷像素的颜色本身是合法的 ARC 颜色），而是相对于弹性拉伸计算结果而言的"错误"——必须先正确完成拉伸计算才能定位缺陷。
