## 新题 8：镜像开关控制对角射线激活

**组合逻辑**：[镜像](根据边色匹配决定图案块朝向) → [模板填充](将图案块放入矩形框内) → [射线延伸](从内部实心矩形角沿对角线向外) → [条件激活](框角处的图案像素颜色决定射线是否发射)（创新：镜像决策通过改变框角处的像素颜色间接控制射线发射模式）

**来源原语**：镜像(846bdb03), 边色不符则翻转(846bdb03), 图案块(846bdb03), 矩形框(846bdb03), 颜色匹配(846bdb03), 射线延伸(ec883f72), 实心矩形(ec883f72), 空心矩形(ec883f72), 角对角对齐(ec883f72), 经过框角才延伸(ec883f72)

**依赖链**：图案块左右边色与框侧色对比 → 决定是否镜像 → 镜像后的图案像素覆盖框内部，改变框角处的颜色分布 → 内部实心矩形的角沿对角线向外追踪 → 射线经过框角时，检查该框角内侧的图案像素颜色 → 只有特定颜色才"放行"射线继续延伸 → 最终哪些对角射线存在取决于镜像决策

图案块放入框中前可能被镜像，镜像与否改变框角处的像素颜色，从而决定哪些对角射线被激活。

**输入结构**：约 15x15 的网格，黑(0) 背景。网格中央偏左有一个一像素厚的灰(5) 矩形空心框（外尺寸约 9x9，内部 7x7 可用空间）。框的左侧竖边的内侧一列全为蓝(1)，右侧竖边的内侧一列全为红(2)（这两列是框的"侧色标记"，各一像素宽，紧贴框内壁）。框外右侧放置一个 7x5 的双色图案块，图案块左半为一种颜色、右半为另一种颜色（使用蓝(1) 和红(2)），图案块高度与框内部高度相同。框内部中央有一个 2x2 的绿(3) 实心小矩形，其四个角分别与框的四个内角构成对角线对齐关系。生成约束：图案块宽度等于框内部宽度减去左右侧色标记列的宽度（即 7-2=5）；图案块的左右边色要么恰好与框的左右侧色一致（蓝左红右），要么恰好相反（红左蓝右）。

**规则**：
1. 比较图案块最左列的颜色与框左侧色标记的颜色（蓝(1)）。若一致，图案块保持原样；若不一致，将图案块水平镜像翻转。
2. 将（可能已翻转的）图案块填入框内部，放置在左右侧色标记列之间的区域。图案块像素不覆盖侧色标记和绿(3) 实心矩形——绿色矩形优先保留。
3. 从绿(3) 实心矩形的每个外角向外追踪对角线射线（共 4 条：左上、右上、左下、右下方向）。每条射线向外逐像素前进。
4. 当射线到达灰(5) 框角像素时，检查该框角内侧对角方向的紧邻像素（即框角内侧 45 度位置的图案像素）。若该像素的颜色为蓝(1)，射线被激活：继续穿过框角向网格外延伸，沿同一对角线方向将沿途所有黑(0) 像素涂为绿(3)，直到到达网格边界。若该像素颜色为红(2)，射线被阻断：不延伸到框外。
5. 框角像素本身保持灰(5) 不变。框内的侧色标记、图案块和绿色矩形均保留在输出中。

**关键洞察**：镜像翻转是一个"远程开关"——它改变的是图案块内部的颜色排布，但效果传导到框角处的像素颜色，进而控制哪些对角射线从框中射出。不同示例中图案块朝向不同，激活的射线组合也不同，求解者必须理解这条因果链才能预测输出。

Move each marked cross object away from its marker to the grid edge while rotating the colored cross 180 degrees.

Input structure:
- The background is the dominant color.
- Each 8-connected foreground object has nine pixels: a 4-pixel marker-color
  sprite attached to a 5-pixel non-marker colored cross.
- Each object bbox is either 3x6 or 6x3, so the marker sprite is on exactly
  one side of the cross.

Rule:
- Move the whole object straight away from its marker side until the object
  bbox touches the corresponding grid edge.
- Keep the marker sprite unchanged within the object.
- Rotate the 3x3 colored cross block by 180 degrees before placing it.

Key insight:
The marker sprite is a directional tail; the cross is the leading payload,
and only that payload turns around during the slide to the edge.

Paint the maze corridor and framed rooms lying on shortest paths between the two colored endpoint components.

Input structure
- The grid has a dominant background, one wall color forming thin orthogonal frames, and one endpoint/fill color.
- The endpoint/fill color forms exactly two 4-connected solid rectangular components; their larger side lengths define the framed room sizes.

Rule
- Treat wall pixels as blocked and every other pixel as passable.
- Find every passable pixel that lies on a shortest 4-connected path between the two endpoint components.
- Also fill any framed square room of an endpoint-derived size that intersects that shortest-path mask.

Key insight
- Shortest paths identify the route through open connector corridors, while the wall-bordered square rooms need to be expanded from the route centerline to their full interior.
