## 新题 6：形状等价路由与重力堆叠

**组合逻辑**：[形状匹配 · 旋转翻转等价](将可移动对象与括号框内参考形状配对) → [平移](水平对齐到匹配括号的通道) → [重力下落](垂直下落到底部堆叠) → [擦除](移除参考形状)

**来源原语**：形状匹配(6165ea8f), 旋转翻转等价(6165ea8f), 归一化掩码(6165ea8f), 重力下落(df9fd884), 括号框(df9fd884), 通道对齐(df9fd884), 目标底边对齐(df9fd884), 可移动对象(df9fd884), 擦除(fe45cba4)

**依赖链**：归一化掩码+旋转翻转比较确定每个对象的目标括号 → 括号的水平位置确定对象的横向对齐 → 处理顺序（按括号从左到右）确定堆叠顺序 → 先到达底部的对象影响后续对象的着陆高度 → 参考形状擦除还原括号内部

可移动对象通过形状等价（而非颜色）匹配目标括号，水平对齐后逐个下落堆叠。

**输入结构**：约 15x20 的网格，黑(0) 背景。沿顶行排列 3 个灰(5) 括号框，每个括号开口朝下，内部宽度各不相同（3-5 列宽）。每个括号的顶部横杆内侧附着一个小参考形状（3-5 像素，4-连通），分别用蓝(1)、红(2)、绿(3) 三种颜色。在括号区域下方（隔 3-5 行黑色空白），散布 3 个可移动对象，颜色分别为黄(4)、品红(6)、橙(7)，每个对象也是 4-连通的 3-5 像素小形状。生成约束：每个可移动对象的归一化掩码恰好与某个括号内参考形状的归一化掩码在旋转翻转等价意义下匹配，且该匹配是一一对应的（3 个对象恰好匹配 3 个括号，无歧义）。可移动对象之间互不接触，括号之间互不重叠。

**规则**：
1. 将每个可移动对象和每个括号内参考形状裁剪到紧包围框，得到归一化掩码（仅保留形状的布尔占用图）。
2. 对每个可移动对象，找到归一化掩码在旋转翻转等价意义下匹配的那个括号（即该对象的掩码可通过 0/90/180/270 度旋转和/或镜像翻转变为参考形状的掩码）。
3. 从原始位置擦除每个可移动对象（恢复为黑(0)）。
4. 按匹配括号的从左到右顺序依次处理每个对象：将对象水平平移，使其包围框在水平方向居中于匹配括号的内部列跨度内。然后将对象向下平移（重力下落），直到对象的最底行像素恰好位于网格最底行，或恰好位于已放置对象的最顶行像素的上方一行（即堆叠在先前对象之上）。对象形状和颜色在移动过程中保持不变。
5. 擦除所有括号内的参考形状（将参考形状像素恢复为黑(0)），括号框本身保持灰(5) 不变。

**关键洞察**：括号的参考形状是几何"地址标签"——对象的路由不靠颜色（三个对象和三个参考形状颜色完全不同）而靠形状等价关系，求解者必须在心中完成归一化和旋转翻转比较才能确定正确的配对。
