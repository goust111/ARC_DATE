## 新题 3：图元分解后按奇偶格点过滤保留

**组合逻辑**：[分解](拆分为基本图元) → [坐标奇偶匹配](创新：作为图元级过滤器而非像素级涂色) → [擦除](不匹配的图元整体移除)

**来源原语**：分解/decompose（来自 150deff5）、基本图元/primitive_shape（来自 150deff5）、坐标奇偶匹配/coord_parity_match（来自 d492a647）、标记像素/marker_pixel（来自 d492a647）、擦除/erase（来自 d93c6891）

**依赖链**：分解确定图元边界，奇偶匹配判断每个图元是否存活，擦除执行移除。分解不可跳过（否则无法知道哪些像素组成一个图元单位），奇偶过滤不可跳过（否则无法知道保留哪些），擦除不可跳过（否则输出与输入无差异）。创新点在于：源题 150deff5 中分解后按形状类型涂色，源题 d492a647 中按奇偶格点逐像素涂色——新题将两者交叉，变成按奇偶格点逐图元过滤。

将灰色复合形状分解为基本图元，然后根据外部标记的坐标奇偶仅保留顶角落在正确格点上的图元，擦除其余图元。

**输入结构**：约 14x14 的网格。背景为黑(0)。2~4 个灰(5) 复合前景形状散布在网格上，彼此不相连。每个复合形状由 2x2 方块和/或 1x3 或 3x1 矩形图元无重叠拼合而成（拼合后可能形成 L 形、T 形或其他不规则外观，但始终可被唯一分解为上述两种图元）。此外有一个绿(3) 标记像素位于网格中不与任何灰色形状相邻的位置。生成约束：每个复合形状的分解方式唯一（不存在两种不同的合法分解），且分解后的图元中恰好约一半的顶角落在标记的奇偶格点上、约一半不在，以确保过滤效果可见。

**规则**：
1. 将所有灰(5) 复合形状分解为不重叠的基本图元，允许的图元尺寸为 2x2 方块和 1x3/3x1 矩形。
2. 读取绿(3) 标记像素的坐标 (r_m, c_m)，计算其奇偶对 (r_m%2, c_m%2)。
3. 对每个图元，取其最小行号和最小列号构成的顶角 (r_t, c_t)，计算奇偶对 (r_t%2, c_t%2)。
4. 若图元的顶角奇偶对与标记的奇偶对相同：将该图元从灰(5) 重涂为蓝(1)，保留在原位。
5. 若奇偶对不同：将该图元的所有像素擦除为黑(0) 背景。
6. 绿(3) 标记像素在输出中擦除为黑(0)。

**关键洞察**：肉眼看到的是一块连续的灰色区域，但分解边界决定了哪些像素作为一个整体被保留或被擦除——即使两个相邻像素都是灰色，它们可能属于不同图元而命运不同。同一复合形状在不同标记位置下会产生不同的存活图元集合。

1. `main(grid)` 必须实现新题描述中的确定性转换规则，不能只识别 `generate_input()` 的固定模板。禁止不同的input网格输出相同的output网格。
2. `generate_input()` 必须随机生成多样样例，不能固定死。随机维度应覆盖：网格大小、对象数量、位置、颜色、方向、形状参数或关键分支。注意若描述中存在若干，需实现而不是只有单个，包括object或者对应关系等等。且若涉及到最短路径，则输入网格中必涉及到多条路径，对选择造成干扰。

6. 若规则有多个分支，生成器不能长期固定成一个分支；应让分支在随机样例中合理出现。分支概率不必平均——难以发现的隐蔽分支（如少数情况下才触发的特殊规则）应适当提高出现概率，确保在 3 个训练示例中至少出现一次，否则求解者无法归纳该规则。对于颜色映射类规则，确保 2 个左右的示例即可覆盖所有映射关系（每种颜色→颜色的映射至少在某个示例中出现过）。
