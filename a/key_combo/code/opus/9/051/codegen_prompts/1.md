## 新题 1：奇偶门控腔室填充

**组合逻辑**：[洪泛填充](创新：填充模式由坐标奇偶决定) + [坐标奇偶匹配](创新：作为分支判据选择操作模式) → 条件分支结构

**来源原语**：洪泛填充/flood_fill（来自 9edfc990, e69241bd）、坐标奇偶匹配/coord_parity_match（来自 d492a647）、墙壁/wall（来自 e69241bd）、封闭区域/enclosed_region（来自 e69241bd）、标记像素/marker_pixel（来自 d492a647）、标记在区域内/marker_inside（来自 e69241bd）、标记色填充区域/marker_color_fills（来自 e69241bd）

**依赖链**：标记像素的坐标奇偶值决定该腔室执行哪种填充模式——全填、棋盘填还是不填。洪泛填充的范围由墙壁确定，但填充的行为模式由奇偶判断分支选择。删除奇偶判断则无法确定填充模式；删除洪泛填充则无法确定填充范围。

根据标记像素的坐标奇偶对，将其所在的墙壁封闭腔室按三种模式之一进行填充。

**输入结构**：约 15x15 的网格。背景为黑(0)。灰(5) 像素构成单像素宽的连通墙壁，将网格分隔成 4~6 个封闭腔室（每个腔室面积约 8~20 个像素）。每个腔室内部恰好有一个单色标记像素（使用红(2)、蓝(1)、绿(3)、黄(4) 等互不相同的颜色）。标记像素位于腔室内部的黑(0) 背景上，不与墙壁相邻。不同腔室的几何形状可以不同（有矩形也有不规则形状）。生成约束：每个腔室至少 3x3 大小且标记不紧贴墙壁，保证奇偶棋盘模式可见。

**规则**：
1. 识别灰(5) 墙壁及其分隔出的封闭腔室。
2. 对每个腔室，定位其中唯一的标记像素，记其行号为 r、列号为 c，计算奇偶对 (r%2, c%2)。
3. 若 (r%2, c%2) = (0, 0)：将该腔室内所有黑(0) 像素洪泛填充为标记色（全填模式）。
4. 若 (r%2, c%2) = (1, 1)：仅将腔室内行列奇偶均与标记相同的黑(0) 像素涂为标记色（棋盘模式——在该腔室内形成间隔一格涂色的图案）。
5. 若 (r%2, c%2) 为 (0,1) 或 (1,0)：该腔室不做任何填充，仅保留原始的标记像素。
6. 所有墙壁像素保持灰(5) 不变。标记像素本身保持原色。

**关键洞察**：两个几何形状完全相同的腔室可以产生截然不同的输出——决定因素不是腔室形状，而是标记的行列坐标奇偶值。求解者必须对比多个示例中同类奇偶对产生同类输出才能归纳出三种模式。
