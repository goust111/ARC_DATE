## 新题 5：图元比例决定镜像轴向

**组合逻辑**：[分解](分析图元组成) → [计数](统计各类图元比例) → [镜像](创新：轴向由图元比例判断决定而非预设) + [重涂色](分解后按形状涂色)

**来源原语**：分解/decompose（来自 150deff5）、基本图元/primitive_shape（来自 150deff5）、图元形状决定涂色/shape_determines_color（来自 150deff5）、镜像/reflect（来自 538b439f）、跨轴对称/cross_axis_symmetry（来自 538b439f）、分隔线/separator_line（来自 538b439f）、计数/counting（来自 3b4c2228）

**依赖链**：分解确定图元类型分布，计数比较方块与矩形的数量，比较结果选择镜像轴——形成"分析→判断→执行"的条件分支。涂色依赖分解结果，镜像方向依赖计数比较。如果跳过分解，既无法涂色也无法确定镜像方向；如果跳过计数比较，无法选择正确的轴。

分解复合形状的图元组成以确定镜像轴向，同时按形状类型重涂色后连同镜像副本一起输出。

**输入结构**：约 15x15 的网格。背景为黑(0)。一条红(2) 全宽水平线和一条红(2) 全高垂直线交叉成十字，将网格分为 4 个象限。恰好一个象限内有一个灰(5) 复合前景形状（由 2x2 方块和 1x3/3x1 矩形无重叠拼合而成，总面积约 8~16 像素），其余三个象限为空（仅黑(0) 背景）。生成约束：复合形状的分解方式唯一；方块数 S 与矩形数 R 不可能在所有示例中都相等（至少有一个示例 S!=R），以确保求解者能归纳轴选择规则。

**规则**：
1. 将灰(5) 复合形状分解为不重叠的 2x2 方块和 1x3/3x1 矩形图元。
2. 统计方块数 S 和矩形数 R。
3. 涂色：所有 2x2 方块图元重涂为青(8)，所有 1x3/3x1 矩形图元重涂为黄(4)。
4. 镜像轴选择：
   - 若 S > R：选择水平红线为轴，将涂色后的形状垂直翻转到对面象限。
   - 若 R > S：选择垂直红线为轴，将涂色后的形状水平翻转到对面象限。
   - 若 S = R：同时选择两条轴，将涂色后的形状翻转到其余三个象限（水平翻转、垂直翻转、中心翻转各一份）。
5. 原象限中的形状保留涂色后的版本。红(2) 十字线保持不变。

**关键洞察**：同一外观的复合形状，如果内部图元组成不同（比如一种分解为 3 个方块+1 个矩形，另一种分解为 1 个方块+3 个矩形），会选择不同的镜像轴——求解者必须先分解图元才能预测镜像方向，而非直接观察形状的外部轮廓。

## 实现要求

1. `main(grid)` 必须实现新题描述中的确定性转换规则，不能只识别 `generate_input()` 的固定模板。禁止不同的input网格输出相同的output网格。
2. `generate_input()` 必须随机生成多样样例，不能固定死。随机维度应覆盖：网格大小、对象数量、位置、颜色、方向、形状参数或关键分支。注意若描述中存在若干，需实现而不是只有单个，包括object或者对应关系等等。且若涉及到最短路径，则输入网格中必涉及到多条路径，对选择造成干扰。
3. 生成器必须保证输入满足 `main()` 的隐式假设：对象不重叠、不越界、特殊标记唯一或可区分、匹配关系无歧义、关键分支出现概率相同。
4. 禁止把 ARC 颜色 id 、亮度、拼写等当作人类不可见的数值语义参与排序、大小比较或隐藏映射。颜色变化必须有可见结构线索。注意颜色亮度、拼写等也是不可见信息，若描述中出现违规的颜色id或者亮度，可自行使用少量的固定颜色替代，但注意生成时要在三个以内输入输出网格中对所有变换100%覆盖度。
5. 输出样例要视觉清晰，人类必须能从输入输出对中肉眼辨认出规律。具体要求：避免对象粘连、覆盖关系混乱、同一像素多重语义；不同逻辑步骤产生的结果不要大面积层叠在一起导致无法分辨哪个颜色属于哪个步骤；输入中各元素之间保持足够间距，输出中新增的标记/填充/路径等应与背景和已有元素在颜色上有明显区分；若规则涉及多层叠加，生成时控制对象密度和尺寸，确保叠加区域只占少数像素而非铺满整个网格。
6. 若规则有多个分支，生成器不能长期固定成一个分支；应让分支在随机样例中合理出现。分支概率不必平均——难以发现的隐蔽分支（如少数情况下才触发的特殊规则）应适当提高出现概率，确保在 3 个训练示例中至少出现一次，否则求解者无法归纳该规则。对于颜色映射类规则，确保 2 个左右的示例即可覆盖所有映射关系（每种颜色→颜色的映射至少在某个示例中出现过）。
7. 代码风格参考 `ARC_code`：使用 `numpy`，并把 `/home/lixinyu/snap/new/solvers/arc_utils.py` 作为公共参考工具箱，优先复用其中已经稳定的 bbox、连通域、裁剪、变换和颜色工具；目标文件必须能被 `SourceFileLoader` 直接加载。
