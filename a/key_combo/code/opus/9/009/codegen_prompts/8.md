## 新题 8：缺口分类后按类别分组重排为面积递增方阵

**组合逻辑**：[形状匹配 → 创新为"缺口检测作为二分类器"] + [压缩重排/repack] + [缺口决定方向/notch_determines_dir → 创新为"缺口决定分组"] + [面积递增排列/area_ascending_order] + [像素数定边长/pixel_count_determines_side]

**来源原语**：滑动、重涂色、边框缺口、靠边对齐、缺口决定方向（P8 320afe60）；排序、压缩重排、色块、正方形、面积递增排列、像素数定边长（P17 8abad3cf）

**依赖链**：检测每个对象边界框边框上是否有背景缺口 → 有缺口的对象归为 A 组，无缺口的归为 B 组 → 每组内部按像素数从小到大排列 → 每个对象转换为边长等于 sqrt(像素数) 的实心方块 → A 组方块底部对齐从左到右排列，B 组方块在 A 组右侧隔一列后同样排列。缺口检测为分组提供依据，分组结果决定重排的空间布局。

根据对象边框是否有缺口将其分为两组，每组内按面积递增重排为实心方块并列输出。

**输入结构**：约 16x16 的网格，背景为黄(4)。网格中有 5~7 个不同颜色（蓝(1)、红(2)、绿(3)、灰(5)、品红(6)、橙(7)等）的 4-连通单色前景对象，每个对象的像素数为完全平方数（4、9 或 16 像素），形状各异（不是实心方块，而是不规则的连通形状）。部分对象的边界框边框上存在至少一个背景缺口——即边界框的某条边上，该对象在边框位置有像素缺失，且缺失位置两侧的边框位置都有该对象的像素（与 P8 的缺口定义一致）。其余对象的边界框边框完整无缺口。生成约束：每种颜色只有一个对象；各对象像素数可以重复（如两个对象都是 9 像素），但同组内按像素数排序后再按颜色在输入中边界框左上角的行坐标从小到大打破平局。

**规则**：
1. 识别背景色黄(4)和所有非背景的 4-连通前景对象。
2. 对每个对象，计算其边界框。检查边界框的四条边上是否存在缺口：若边界框某条边上有该对象的像素，但该边上存在一个背景像素且该背景像素的左右（或上下，取决于边的方向）相邻的边框位置都有该对象的像素，则该对象"有缺口"。
3. 将有缺口的对象归入 A 组，无缺口的归入 B 组。
4. 每组内按对象像素数从小到大排序。像素数相同时，按该对象边界框左上角在输入网格中的行坐标从小到大排序。
5. 将每个对象转换为实心方块，边长 = sqrt(像素数)，颜色保持该对象的原色。
6. 输出网格：A 组的方块底部对齐从左到右排列，相邻方块间隔 1 列黄(4)背景；隔 1 列黄(4)背景后，B 组方块同样底部对齐从左到右排列。输出网格高度等于最大方块边长，宽度刚好容纳所有方块和间隔列。

**关键洞察**：缺口检测在源题 P8 中决定滑动方向；重排在源题 P17 中对所有对象统一处理。此题中缺口检测被重新定义为分类器——它不控制运动方向，而是将对象划分为两个独立的重排组，使得同一形状特征在不同上下文中扮演截然不同的结构角色。
