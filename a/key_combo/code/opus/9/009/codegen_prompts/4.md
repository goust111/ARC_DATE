## 新题 4：射线覆盖后的双面板占用补集

**组合逻辑**：[射线延伸/ray_extend + 重涂色/toggle_recolor]（创新：射线不在单一网格操作，而是分别修改两个面板的占用状态） + [透明叠加/transparent_overlay] + [标记/mark] + [占用补集/occupancy_complement]

**来源原语**：射线延伸、重涂色、控制像素、同列对齐、颜色匹配（P5 981add89）；透明叠加、标记、二值掩码、双侧对齐、占用补集（P7 66f2d22f）

**依赖链**：顶行控制像素在各自面板内发射向下的切换射线 → 射线改变每个面板的占用分布 → 叠加两个面板 → 在两个面板中都为背景的位置标记灰色。射线修改了占用分布，从而改变了哪些位置属于"双空"补集——射线和补集检测在空间上相互约束。

在左右两个面板中分别执行射线切换，然后叠加判定双面板占用补集并标记。

**输入结构**：约 12x24 的网格（高 12、宽 24），背景为黑(0)。网格沿宽度中线分为左右两个 12x12 的面板。左面板包含若干蓝(1)前景像素构成的散布图案（约 8~15 个像素，不构成规则形状）；右面板包含若干红(2)前景像素构成的散布图案（约 8~15 个像素）。左面板的第 0 行（顶行）有 2~3 个绿(3)控制像素；右面板的第 0 行有 2~3 个黄(4)控制像素。控制像素的位置在两个面板中不相同。生成约束：射线操作后，至少存在 3 个"双空"位置。

**规则**：
1. 将网格分为左面板（列 0~11）和右面板（列 12~23），按列对齐（右面板的列 12 对应左面板的列 0，依此类推）。
2. 对左面板：每个绿(3)控制像素向下发射射线至面板底部。射线沿该列逐格处理——若遇到蓝(1)像素则擦除为黑(0)背景，若遇到黑(0)背景则涂为蓝(1)。绿(3)控制像素本身保持不变。
3. 对右面板：每个黄(4)控制像素向下发射射线至面板底部。射线沿该列逐格处理——若遇到红(2)像素则擦除为黑(0)背景，若遇到黑(0)背景则涂为红(2)。黄(4)控制像素本身保持不变。
4. 射线处理完成后，将两个面板按行列对齐叠加。输出为单个 12x12 网格（不含顶行控制像素行，即输出为第 1~11 行对齐后的 11x12 网格）：
   - 对齐后某位置在左面板和右面板中都是背景黑(0) → 输出灰(5)。
   - 其他所有位置 → 输出黑(0)背景。

**关键洞察**：控制像素发射的射线以"切换"方式改变各面板的前景分布——一个原本被占用的位置可能被射线擦空，一个原本空白的位置可能被射线填满。因此"双空"补集的结果无法仅从原始面板读出，必须先完成射线切换才能判断。射线位置和面板图案共同约束最终的补集结果。
