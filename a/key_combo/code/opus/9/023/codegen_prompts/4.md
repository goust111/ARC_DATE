## 新题 4：中位对齐后的遮蔽循环填充

**组合逻辑**：[对齐(align) + 裁剪(trim)]（创新：对齐改变的不是最终输出的位置，而是后续循环填充的"原料配方"） → [列遮挡(column_coverage) 判断] → [循环填充(cycle_fill)]（创新：循环序列来自对齐后的纵向颜色栈，而非预设序列）

**来源原语**：对齐(align) + 裁剪(trim) + 线段(line_segment) + 平行共向(parallel_codirectional) + 中位线为参考(median_as_reference) ← e376de54；射线延伸(ray_cast) + 列遮挡(column_coverage) + 遮挡列延伸至边(covered_col_to_edge) ← 6d58a25d；循环填充(cycle_fill) + 色彩循环(color_cycle) ← 72207abc

**依赖链**：多根平行线段的位置各不相同 → 以中位线为基准对齐并裁剪到统一长度 → 对齐后各线段在同一列区间纵向叠加形成颜色栈 → 灰色人字形遮蔽物决定哪些列被激活 → 激活列用其颜色栈作循环序列向下填充。对齐步骤改变了每列的颜色组成；遮蔽判断决定了哪些列有填充；循环规则决定了填充内容。三者缺一不可。

多根平行水平线段先对齐到中位线的起止位置，对齐后线段的纵向颜色叠加构成循环序列，再由下方的人字形遮蔽物决定哪些列激活循环填充。

**输入结构**：约 20x20 的黑(0)背景网格。上半区域有 4~6 根水平线段（1 像素厚），各自颜色不同（从红(2)、蓝(1)、绿(3)、黄(4)、栗(9)中选），分布在不同行，起始列和长度各异。下半区域有一个灰(5)人字形（V 形或倒 V 形，开口朝上或朝下，宽度 8~14 像素，由 1 像素厚的对角线段构成）。线段与人字形之间至少隔 2 行空白。生成约束：线段数量为奇数（使中位线唯一）；各线段长度不全相同（使对齐裁剪可见）；人字形跨越的列范围与对齐后线段跨越的列范围有部分重叠但不完全相同。

**规则**：
1. 识别所有水平线段。按行位置排序，取中位线（按行号排序后的中间那根）作为参考线段。
2. 将每根线段水平平移，使其起始列与参考线段的起始列对齐。若线段比参考线段长，从右侧裁剪到参考线段长度；若比参考线段短，从右侧用该线段自身颜色延长到参考线段长度。线段保持在各自的行上，仅水平移动。
3. 对齐后，所有线段覆盖同一列区间 [c_start, c_end]。对该区间内的每一列 c，从上到下读取该列上所有线段的颜色（按行号从小到大），形成该列的颜色序列 S_c。由于所有列的线段集合相同（只是颜色被对齐了），S_c 对所有列相同，记为 S。
4. 对于列区间 [c_start, c_end] 中的每一列 c：从该列最底部的行开始向上搜索灰(5)像素。若在人字形中找到灰(5)像素，则该列被"遮蔽"（激活）；否则不激活。
5. 对每个被激活的列 c：找到该列中灰(5)人字形最下方像素所在的行 r_bottom。从 r_bottom + 1 行开始到网格最后一行，用颜色序列 S 循环填充：第 r_bottom + 1 行涂 S[0]，第 r_bottom + 2 行涂 S[1]，……，序列用完后从头循环。
6. 未被激活的列不做任何修改。人字形本身的灰(5)像素保持不变。线段像素保持对齐后的位置和颜色。

**关键洞察**：对齐步骤不只是几何整理——它将原本散落在不同列区间的线段汇聚到同一列区间，从而改变了每列的颜色"配方"。若不对齐，有些列可能只有 1~2 条线段经过，颜色序列不完整。中位线的选取规则（而非最长或最上的线段）需要对比多个示例才能确认。
