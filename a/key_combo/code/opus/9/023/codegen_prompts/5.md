## 新题 5：镜像平铺涌现矩形的跨界掏空

**组合逻辑**：[平铺(tiling) + 镜像(mirror)]（创新：平铺后的结果不是最终输出，而是产生新几何特征的中间步骤） → [掏空(hollowing)]（创新：掏空的对象不是输入中的原有矩形，而是平铺涌现的跨界矩形）

**来源原语**：平铺(tiling) + 镜像(mirror) + 瓦片(tile) + 阵列排布(array_layout) + 相邻槽位翻转(adjacent_slot_flip) ← c48954c1；掏空(hollowing) + 实心矩形(solid_rectangle) + 边框(frame) + 保留边擦除内部(keep_border_erase_interior) ← 4347f46a

**依赖链**：小网格经镜像规则铺成 3x3 马赛克 → 相邻瓦片的翻转使得边界处的色块拼合成更大的矩形（这些矩形在单个瓦片中不存在） → 检测所有跨越瓦片边界的实心矩形 → 仅掏空跨界矩形，单瓦片内的矩形保持实心。去掉镜像规则，跨界矩形不会出现；去掉跨界判断，无法区分哪些掏空哪些保留。

将小网格按镜像规则铺成 3x3 马赛克，在瓦片边界处涌现出新的大矩形，仅对跨越瓦片边界的矩形执行掏空操作。

**输入结构**：一个 4x4 或 5x5 的彩色网格，包含黑(0)背景和若干有色像素。有色像素形成 1~3 个小型实心矩形区域（2x2 或 2x3 或 1x3 等），各矩形颜色不同（如蓝(1)、红(2)、黄(4)）。设计时确保：至少一个矩形的某条边紧贴网格边缘，使得镜像平铺后该矩形与相邻瓦片中的镜像副本拼合成更大的矩形；至少一个矩形不贴边，使其镜像后不与邻居拼合。

**规则**：
1. 以输入网格为中心瓦片，构建 3x3 的镜像马赛克，输出尺寸为 (3*H) x (3*W)，其中 H、W 为输入的高和宽。9 个槽位编号如下（行,列从 0 开始）：
   - (0,0) 左上、(0,1) 上、(0,2) 右上
   - (1,0) 左、(1,1) 中心、(1,2) 右
   - (2,0) 左下、(2,1) 下、(2,2) 右下
2. 中心槽 (1,1) 放置原始瓦片。与中心在行方向相邻的槽 (0,1) 和 (2,1) 将瓦片行顺序翻转。与中心在列方向相邻的槽 (1,0) 和 (1,2) 将瓦片列顺序翻转。四个角槽 (0,0)(0,2)(2,0)(2,2) 同时翻转行和列。
3. 在马赛克中检测所有最大单色实心轴对齐矩形（贪心扩展：对每个非背景像素，找到包含它的最大同色矩形；去重后保留不被其他同色矩形严格包含的）。只考虑短边至少 3 像素的矩形（确保有内腔可掏空）。
4. 对每个检测到的矩形，判断其是否"跨越瓦片边界"：矩形的外接框是否跨越任何瓦片槽之间的分界线（行分界线在第 H 行和第 2H 行，列分界线在第 W 列和第 2W 列）。
5. 跨界矩形：掏空，保留 1 像素宽边框，内腔全部设为黑(0)。
6. 未跨界矩形（完全在单个瓦片槽内）：保持实心，不修改。
7. 若掏空操作使某个矩形的内腔像素恰好也是另一个矩形的边框像素，后者的边框保留（掏空不影响其他矩形的边框）。处理顺序：按矩形面积从大到小掏空。

**关键洞察**：镜像平铺在瓦片边界处"制造"了输入中不存在的大矩形——两个贴边的小矩形与它们的镜像副本拼合成更大的整体。是否掏空取决于矩形是否跨界，而跨界与否是由输入小矩形的位置（是否贴边）间接决定的。求解者需要理解镜像规则如何在边界处合并色块，这需要对比多个示例中不同的贴边情况。
