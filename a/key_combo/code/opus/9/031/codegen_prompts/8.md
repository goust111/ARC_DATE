## 新题 8：互补形状配对确定嵌套层序与层厚

**组合逻辑**：[形状匹配·互补](已有，创新：匹配结果决定嵌套分配而非填充) → [嵌套包裹·逐层构建](已有，创新：层厚由匹配到的源形状像素数决定) ← [计数](已有，提供层厚数值)

**来源原语**：形状匹配/模板缺口/源形状/互补形状/缺口形状唯一配对(18447a8d)，嵌套包裹/同心正方形层/逐层构建/色条/条高决定框厚(45a5af55)，计数(6455b5f5)

**依赖链**：模板缺口形状与源形状一一配对 → 配对确定每个源形状的颜色分配到哪一嵌套层（由模板从上到下的顺序决定） → 每个源形状的像素数决定其对应层的厚度 → 逐层从内到外构建同心方框。不配对则不知颜色-层映射；不计数则不知层厚；不构建则无输出。

模板缺口与源形状互补配对，模板的排列顺序决定嵌套层序，匹配到的源形状像素数决定每层厚度，最终构建同心方框。

**输入结构**：约 18x12 的网格，背景为黑(0)。左半区自上而下排列 3-4 个灰(5)填充的矩形模板（每个约 5x5），模板之间由至少 1 行背景分隔。每个模板内部有一个独特形状的黑(0)缺口（3-6 像素的 4-连通区域，形状各不相同，如 L 形缺口、线形缺口、角形缺口等）。右半区散布同样数量的彩色小图形（源形状），每个源形状为单一颜色的 4-连通区域（3-6 像素），颜色取自红(2)、蓝(1)、绿(3)、橙(7)，各源形状颜色互不相同，像素数也互不相同。每个源形状的归一化形状恰好与某个模板缺口的归一化形状完全一致（一一对应）。生成约束：源形状在右半区的垂直排列顺序与模板在左半区的顺序不同（打乱），以确保求解者必须通过形状匹配而非位置对应来配对。

**规则**：
1. 对每个模板，提取其缺口形状：模板边界框内所有黑(0)像素的坐标，归一化为相对于缺口边界框左上角的局部坐标集合。
2. 对每个源形状，提取其形状：所有该颜色像素的坐标，归一化为相对于边界框左上角的局部坐标集合。
3. 将每个源形状与归一化形状完全相同的唯一模板缺口配对。
4. 按模板在左半区从上到下的顺序（以模板边界框顶行从小到大排序），将配对的源形状排成序列。序列中第一个（最上方模板对应的源形状）为最内层，最后一个为最外层。
5. 最内层源形状的像素数 N1 决定中心实心正方形的边长为 N1（用该源形状的颜色填充）。
6. 后续每个源形状的像素数 Nk 决定该层同心方框的厚度为 Nk（用该源形状的颜色绘制）。每层方框紧贴包裹在前一层外部。
7. 输出仅包含构建好的同心方框结构，背景为黑(0)，尺寸由各层厚度之和决定（总边长 = N1 + 2*(N2 + N3 + ...)）。

**关键洞察**：源形状的像素数承担双重角色——几何形状决定它匹配哪个模板（从而确定嵌套层序），像素数量决定该层的厚度。一个 5 像素的 L 形和一个 5 像素的线形会产生不同的层分配但相同的层厚。
