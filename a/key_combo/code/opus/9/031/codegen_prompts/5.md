## 新题 5：泛洪填充分区提取图案，面积优先级透明叠加

**组合逻辑**：[泛洪填充](已有，创新：用于分区提取而非描边) + [透明叠加](已有，创新：叠加优先级由区域面积决定) ← [面积比较](已有，提供优先级判据)

**来源原语**：泛洪填充/墙壁障碍/封闭区域/可达性(8f3a5a89)，透明叠加/标记像素/同尺寸对齐/标记无冲突合并/共享底色(25e02866)，面积比较/计数(6455b5f5)

**依赖链**：墙壁将网格分为若干封闭区域 → 泛洪填充识别各区域边界并提取内部图案 → 计算各区域面积确定叠加优先级 → 将所有图案按相对坐标对齐后透明叠加，冲突时面积大者胜。不分区则无法提取独立图案；不计面积则冲突无法解决；不叠加则图案分散无输出。

墙壁分隔的多个封闭区域各含一个小图案，将它们按区域面积决定的优先级透明叠加为单一输出图案。

**输入结构**：约 16x16 的网格，背景为黑(0)。灰(5)墙壁线段将网格分为 3-4 个矩形封闭区域，区域大小各不相同。每个区域内部有一个由彩色像素构成的小图案（3x3 至 5x5 的边界框），图案由若干非黑(0)、非灰(5)像素构成，颜色取自红(2)、蓝(1)、绿(3)、黄(4)、橙(7)。所有图案的边界框尺寸相同（如都是 4x4）。每个图案在其所在区域内的相对位置（图案左上角到区域左上角的偏移）相同。图案之间有部分像素位置重叠（同一相对坐标处，不同图案有不同颜色的非背景像素）也有部分互补（某图案有颜色而另一图案在该位置为背景）。生成约束：不存在三个或更多图案在同一相对坐标处都有非背景像素的情况（即冲突仅发生在两两之间）。

**规则**：
1. 识别灰(5)墙壁，通过 4-连通泛洪填充从每个区域的任意黑(0)像素出发，找到该区域内所有黑(0)连通像素，从而确定各封闭区域的范围。
2. 计算每个区域的面积（该区域内黑(0)像素总数，不含墙壁和图案像素；或等价地，该连通分量的像素数）。
3. 从每个区域中提取图案：找到区域内所有非黑(0)、非灰(5)像素，将它们的坐标归一化为相对于图案边界框左上角的局部坐标。
4. 创建一个与图案边界框同尺寸的纯黑(0)输出网格。
5. 按区域面积从小到大的顺序，依次将每个区域的图案绘制到输出网格上：将该图案的每个非背景像素写入输出网格的对应局部坐标，覆盖该位置的已有颜色。
6. 最终输出即为叠加完成的小网格。

**关键洞察**：面积最大的区域的图案拥有最高绘制优先级（因为最后绘制，覆盖先前的），但这一优先级规则隐含在区域几何中，不在图案本身。改变墙壁位置会改变区域面积比，从而翻转冲突像素的胜负——必须对比不同墙壁布局的示例才能归纳出面积优先规则。
