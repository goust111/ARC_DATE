## 新题 3：孔洞拓扑分流滑动，滑动距离编码重涂长度

**组合逻辑**：[滑动·拓扑分流](已有) + [重涂色](已有，创新：重涂长度由滑动距离决定) ← [有孔者升无孔者降](已有，提供分流条件) + [碰撞停止](已有)

**来源原语**：滑动/堆叠/封闭对象/开放对象/封闭孔洞/有孔者升无孔者降/碰撞停止/分离(ac2e8ecf)，重涂色/间距编码尾长(696d4842)，路径对象(696d4842)

**依赖链**：孔洞拓扑判定分流方向（上/下） → 滑动并碰撞停止确定最终位置 → 原位置与终位置的行差即滑动距离 → 从每个对象的尾端（滑动方向的反向端）起重涂该距离数量的像素为黄(4)。不做拓扑分类则不知方向；不滑动则无距离；无距离则不知重涂范围。

按孔洞拓扑将对象分流向上或向下滑动，再以每个对象的滑动行距决定从其尾端重涂多少像素。

**输入结构**：约 15x15 的网格，背景为黑(0)。散布 4-6 个单色 4-连通前景对象，每个对象 4-8 像素，颜色取自红(2)、蓝(1)、绿(3)、橙(7)、灰(5)，各对象颜色互不相同。部分对象为封闭框形（边界框内至少存在一个被该对象像素完全包围的黑(0)孔洞），其余为开放线形（无孔洞）。各对象互不相邻（任意两个对象的像素之间至少有 1 格黑(0)间隔）。生成约束：各对象在水平投影上至少有部分重叠，保证滑动时会发生至少一次堆叠碰撞；每个对象距其滑动方向的边界至少 2 行，保证都会产生非零滑动距离。

**规则**：
1. 判定每个对象的拓扑类型：若对象的边界框内存在被该对象像素完全 4-连通包围的黑(0)连通区域，则为"封闭"型；否则为"开放"型。
2. 封闭型对象向上滑动，开放型对象向下滑动。滑动时保持每个对象的形状、颜色和水平位置不变。
3. 在同一滑动方向内，按对象在原始输入中距目标边界的距离从近到远依次处理（即向上滑动的对象中，原始位置最靠上的先滑动）。每个对象沿其方向逐行移动，直至其任意像素接触网格边缘或已固定的其他对象像素的相邻行（碰撞停止，对象不重叠）。
4. 计算每个对象的滑动距离 D = 该对象边界框顶行在滑动前后的行号之差的绝对值。
5. 对每个对象，从其"尾端"开始重涂像素为黄(4)。尾端定义：向上滑动的对象的尾端为其最底行，向下滑动的对象的尾端为其最顶行。从尾端逐行向对象内部推进，将遇到的对象像素涂为黄(4)，直至已涂黄的像素总数达到 D 或该对象所有像素已全部涂黄。
6. 输出最终网格（背景保持黑(0)）。

**关键洞察**：重涂范围不是输入中显式标注的，而是从滑动距离涌现——滑动距离本身取决于所有对象的拓扑分类和空间排列，因此单个对象的重涂结果依赖于全局布局。需要对比多个示例才能发现"滑动行距 = 重涂像素数"的隐藏映射。
