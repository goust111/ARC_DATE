## 新题 1：可达性门控的对角射线

**组合逻辑**：[泛洪填充](已有) + [射线延伸·对角](已有，创新：由可达性决定是否激活) + [擦除](已有，创新：擦除不可达标记) → 可达性判定充当射线激活的逻辑门

**来源原语**：泛洪填充/可达性/墙壁障碍/角落标记/边界连通区分结构(8f3a5a89)，射线延伸/对角邻接/对角标记(7ddcd7ec/d07ae81c)，擦除(252143c9/8f3a5a89)

**依赖链**：泛洪填充确定哪些区域可达 → 可达性判定筛选哪些标记像素被激活 → 被激活的标记根据对角方向指示像素发射射线 → 不可达标记被擦除。删除可达性判定则不知道哪些标记发射射线；删除射线延伸则可达性判定无处输出；删除对角指示则射线无方向。

从角落出发泛洪填充判定区域可达性，仅对可达区域内的标记像素按对角方向发射射线至网格边缘，擦除不可达区域的标记。

**输入结构**：约 15x15 的网格，背景为黑(0)。蓝(1)墙壁线段将网格分隔为若干不规则区域（墙壁为单像素宽的 4-连通线段，部分连接网格边界形成封闭或半封闭分隔）。网格某一角落有一个品红(6)单像素（起始标记）。在不同区域内各有一个彩色标记像素（取自红(2)、绿(3)、黄(4)中的不同颜色，每区域至多一个标记），每个标记像素恰好有一个同色的对角邻居像素（位于标记的四个对角方向之一），作为方向指示。生成约束：每个标记的方向指示像素也在同一区域内；不同区域的标记颜色互不相同；至少有一个区域被墙壁完全隔开（从角落不可达）。

**规则**：
1. 从品红(6)角落标记出发，对黑(0)背景像素做 4-连通泛洪填充，蓝(1)墙壁阻止扩散。标记所有可达的背景像素。
2. 判定每个彩色标记像素的可达性：若该标记的某个 4-邻居是可达背景像素，则该标记为"活跃"；否则为"不活跃"。
3. 对每个活跃标记，从标记位置沿其方向指示像素所指的对角方向（标记→方向指示像素的偏移方向继续延伸），逐像素绘制射线，将路径上的黑(0)像素涂为该标记的颜色，直至射线离开网格边界或遇到非黑(0)像素（遇到时停止，不涂该终点像素）。
4. 擦除所有不活跃标记及其方向指示像素（设为黑(0)）。
5. 擦除品红(6)角落标记（设为黑(0)）。活跃标记的方向指示像素保留。

**关键洞察**：墙壁同时承担两个角色——既定义泛洪填充的可达边界（决定哪些标记被激活），又充当射线的终止障碍。一个隐藏在墙壁后面的标记既不可达也不会发射射线，必须对比多个示例才能确认"不可达则擦除"这条规则。
