## 新题 3：格子单元拓扑回传染色

**组合逻辑**：[擦除](已有：清除噪声) → [检测/拓扑分类](创新：分析每个格子单元内形状的拓扑属性) → [重涂色](创新：拓扑分类结果回传到格子交叉点的颜色，信息从单元内部流向分隔结构)

**来源原语**：分隔行列/separator_row_col（95a58926）、格点交叉/lattice_intersection（95a58926）、噪声像素/noise_pixel（95a58926）、完整行列为分隔线/full_rows_cols_separators（95a58926）、行列交叉/row_col_intersection（95a58926）、擦除/erase（95a58926）、封闭区域/enclosed_region（b2862040）、内部包含/interior_containment（b2862040）、含空洞对象重涂/objects_with_holes_recolored（b2862040）、连通分量/connected_component（b2862040）、重涂色/recolor（ad38a9d0）

**依赖链**：格子结构定义单元边界 → 清除噪声后分析每个单元内形状的拓扑类别（有洞/无洞）→ 拓扑分类结果反向传播到格子交叉点的颜色。信息流形成回路：格子结构 → 单元内容 → 格子结构。没有格子就不知道单元边界；没有拓扑分析就无法分类；没有交叉点重涂就缺少输出信号。

识别格子分隔线，在每个单元内检测形状的拓扑类别（实心或空心），然后将分类结果映射回格子交叉点的颜色。

**输入结构**：约 16x16 的网格，黑(0)背景。蓝(1)像素填满若干完整行和完整列，形成正交格子（至少 3 条水平线和 3 条垂直线，产生至少 2x2 = 4 个内部单元）。每个单元的内部空间为 3x3 到 5x5 的黑色区域。每个单元内包含一个由单一颜色构成的 4-连通小形状（颜色从黄(4)、绿(3)、橙(7)、品红(6)中选取，不同单元可同色可异色；形状为 3-8 像素的不规则图案，不同单元的具体形状不同）。部分单元的形状是实心的（无封闭背景孔洞），部分形状在其像素包围的区域内有一个 4-连通的封闭背景孔洞。网格中散布若干红(2)噪声像素（有的在单元内部，有的在蓝色格子线上）。生成约束：(a) 每个格子线完整跨越网格全宽或全高；(b) 每个单元恰好包含一个形状；(c) 至少存在一个交叉点其所有相邻单元全为空心、一个全为实心、一个为混合。

**规则**：
1. 识别格子结构：找出所有完全由蓝(1)或红(2)填充的行和列（红(2)噪声可能覆盖了部分蓝(1)像素，但该行/列的所有像素均为蓝(1)或红(2)，不含黑(0)）。这些行/列即为分隔线。
2. 清除所有红(2)噪声像素：位于分隔线上的红(2)像素恢复为蓝(1)；位于单元内部的红(2)像素恢复为黑(0)。
3. 对每个单元，分析其中形状的拓扑类别：若形状包含至少一个封闭背景孔洞，分类为"空心"；否则分类为"实心"。
4. 对每个格子交叉点（水平分隔线与垂直分隔线的交叉像素），检查与其相邻的所有单元（内部交叉点有 4 个相邻单元，边缘交叉点有 2 个，角落交叉点有 1 个）：
   - 若所有相邻单元均为空心：将该交叉点像素涂为绿(3)。
   - 若所有相邻单元均为实心：将该交叉点像素涂为黄(4)。
   - 若相邻单元混合（既有空心又有实心）：该交叉点保持蓝(1)不变。
5. 非交叉点的分隔线像素保持蓝(1)。单元内的形状保持原色不变。

**关键洞察**：交叉点颜色取决于周围单元形状的拓扑属性（有洞/无洞），而非形状的颜色或大小。需要对比同色但不同拓扑的形状所对应的交叉点颜色，才能排除"颜色决定交叉点"的错误假设。
