## 新题 4：模板框架的双重传递——边框色与内部环形

**组合逻辑**：[尺寸匹配](已有) → [重涂色/框架色传递](已有：模板边框色传递到匹配框架) + [同心层填充](创新：模板框架的内部环形图案作为填充规则示范，同时应用于所有匹配框架)

**来源原语**：空心矩形/rectangular_frame（890034e9）、模板/template（890034e9）、尺寸匹配/size_matching（890034e9）、框架色传递同形/frame_color_transferred_to_matching_empty（890034e9）、重涂色/recolor（890034e9）、同心层填充/concentric_fill（b7fb29bc）、控制像素/control_pixel（b7fb29bc）、以控制点为中心/centered_on_control（b7fb29bc）、奇偶距离决定颜色/parity_distance_color（b7fb29bc）、同心正方形层/concentric_layer（b7fb29bc）

**依赖链**：尺寸匹配找到源框架和目标框架 → 源框架的边框颜色作为重涂色模板 → 源框架的内部同心环图案作为填充规则示范 → 目标框架同时接受边框重涂和内部填充。源框架承担双重角色（颜色模板 + 规则示范），两个操作共享同一个匹配结果但各自独立作用于边框和内部——不是先做 A 再做 B 的流水线，而是从同一个匹配结果分叉出两条并行变换。

通过尺寸匹配找到源框架与目标框架，将源框架的边框色传递给目标框架，同时将源框架内部展示的同心环填充规则应用于所有目标框架的内部。

**输入结构**：约 16x16 的网格，黑(0)背景。网格中包含：
- 一个"源框架"：蓝(1)的 1 像素厚矩形边框（如 6x6 外框，内部 4x4），内部已经填好同心 Chebyshev 环——以一个红(2)控制像素为中心，奇数距离为黄(4)，偶数距离（> 0）为橙(7)，红(2)控制像素保留在原位。
- 1-2 个"目标框架"：灰(5)的 1 像素厚矩形边框，与源框架尺寸完全相同。内部为纯黑(0)，其中各有一个红(2)控制像素（位置与源框架的控制像素位置不同）。
- 各框架之间互不重叠、互不相邻。
- 生成约束：(a) 源框架有且仅有一个，以蓝(1)边框为唯一标识；(b) 所有目标框架与源框架的外框尺寸严格一致；(c) 每个框架内部恰好一个红(2)控制像素。

**规则**：
1. 识别源框架：边框颜色为蓝(1)的矩形框架（其内部已有同心环图案）。
2. 识别所有目标框架：与源框架外框尺寸相同、边框颜色为灰(5)的矩形框架。
3. 将每个目标框架的边框从灰(5)重涂为蓝(1)。
4. 对每个目标框架的内部：以其红(2)控制像素为中心，对每个黑(0)像素计算 Chebyshev 距离，按源框架展示的规则填色——奇数距离涂黄(4)，偶数距离（> 0）涂橙(7)。
5. 红(2)控制像素保持不变。源框架本身不做任何修改。

**关键洞察**：源框架是"活的示范"——它同时展示了边框应为什么颜色以及内部应按什么规则填充。求解者必须从源框架的完成态中逆向推断出两条规则（边框色 + 同心填充），然后将两者同时施加于目标框架。仅看目标框架无法推断规则；仅做边框传递而忽略填充、或仅做填充而忽略边框传递，都会产生不完整的输出。
