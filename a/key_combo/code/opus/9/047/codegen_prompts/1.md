## 新题 1：拓扑门控的同心环配色

**组合逻辑**：[内部包含/拓扑检测](创新：孔洞数量分类对象) → [计数](创新：孔洞计数决定配色方案而非输出尺寸) → [同心层填充](已有) → [擦除](已有：无孔对象擦除)

**来源原语**：内部包含/interior_containment（b2862040）、封闭区域/enclosed_region（b2862040）、含空洞对象重涂/objects_with_holes_recolored（b2862040）、计数/counting（d0f5fe59、fcc82909）、同心层填充/concentric_fill（b7fb29bc）、控制像素/control_pixel（b7fb29bc）、以控制点为中心/centered_on_control（b7fb29bc）、奇偶距离决定颜色/parity_distance_color（b7fb29bc）、擦除/erase（d59b0160）、连通分量/connected_component（b2862040）

**依赖链**：拓扑检测（有无孔洞）决定对象的保留或擦除；孔洞计数决定保留对象内部的环形配色方案；配色方案再驱动同心层填充的具体颜色。三步环环相扣：没有拓扑检测就不知道哪些对象保留；没有孔洞计数就不知道用哪套配色；没有同心填充就无法产生最终图案。

对于每个含孔灰色对象，先数其孔洞总数，再按该总数选配色方案，最后在每个孔洞内以其控制像素为中心画同心 Chebyshev 环。

**输入结构**：约 14x14 的网格，黑(0)背景。灰(5)前景像素构成若干分离的 4-连通对象（每个对象 10-30 像素，形状各异——有的紧凑近似矩形、有的蜿蜒不规则、有的近似环形）。部分对象是实心的（无封闭背景孔洞），部分对象包含 1 个封闭背景孔洞，部分对象包含 2 个或更多封闭背景孔洞。每个孔洞内部恰好有一个红(2)控制像素。生成约束：(a) 每个孔洞的内部空间足够大（至少 3x3 背景区域），保证控制像素周围至少存在 2 层 Chebyshev 环；(b) 不同对象互不相邻；(c) 至少存在一个无孔对象、一个单孔对象和一个多孔对象。

**规则**：
1. 识别所有灰(5)的 4-连通对象。
2. 对每个对象，检测其包围盒内被灰像素完全包围的 4-连通背景区域（即封闭孔洞）。统计每个对象的孔洞总数 H。
3. H = 0（无孔洞）的对象：将其所有灰(5)像素擦除为黑(0)。
4. H >= 1 的对象：保留灰(5)边界不变。根据 H 选择配色方案：
   - H = 1：奇数 Chebyshev 距离 → 黄(4)，偶数距离（> 0）→ 蓝(1)。
   - H >= 2：奇数 Chebyshev 距离 → 橙(7)，偶数距离（> 0）→ 绿(3)。
5. 对每个保留对象的每个孔洞：以该孔洞内的红(2)控制像素为中心，计算孔洞内每个黑(0)背景像素到控制像素的 Chebyshev 距离，按第 4 步的配色方案填色。
6. 红(2)控制像素保持不变（距离 0 不填色）。

**关键洞察**：孔洞数量决定配色方案——这是单个示例中无法确定的隐蔽规则。仅看一个单孔对象的蓝黄环形，可能误以为所有对象都用蓝黄；必须对比含不同孔洞数的对象后才能归纳出数量-配色映射。
