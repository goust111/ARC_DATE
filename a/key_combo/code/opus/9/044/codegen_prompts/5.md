## 新题 5：字形路径解码划分区域后种子染色

**组合逻辑**：[解码(decode)]（字形 → 路径边界）→ [填充(fill)]（种子像素决定区域颜色），路径拓扑决定区域划分，种子位置决定颜色归属，颜色映射增加隐蔽规则层。

**来源原语**：解码、字形、起点标记、弯头决定偏移 ← e6de6e8f；填充、画布、最高频色覆盖全图 ← 5582e5ca（填充概念）；标记色决定描边色（颜色配对映射）← 913fb3ed

**依赖链**：字形序列 → 解码为红色路径线 → 路径将网格划分为若干 4-连通背景区域 → 种子像素落在特定区域内 → 种子颜色经配对映射后确定该区域的填充色。删除解码则区域未定义；删除种子则颜色未定义；删除颜色映射则输出颜色错误。

将两行红色字形条解码为一条折线路径，该路径把输出网格分割成若干区域，再由散布的种子像素经颜色配对映射为各区域染色。

**输入结构**：网格分为上下两个区域，中间隔 2 行黑(0)。
- 上区域（2 行）：红(2)字形编码条。字形从左到右排列，每个字形占据两行。竖直字形：上下两格均为红(2)，位于同一列。弯头字形：占据 2×2 区域中的 3 格，缺失的那个上行格指示弯转方向（缺左上则右转，缺右上则左转）。字形数量 4~7 个。
- 下区域（约 8 列宽）：一列黑(0)空白网格，高度等于字形数量加 2。在这片空白的第一行正中放置一个绿(3)起点标记。另外在此区域的空白处散布 2~3 个单像素种子，颜色为蓝(1)、黄(4)或灰(5)。种子位于路径解码后会形成的不同区域内（生成时确保）。
- 生成约束：路径解码后恰好将下区域分割为种子数 +1 个 4-连通背景区域（其中一个区域无种子），每个有种子的区域恰好包含一个种子。

**规则**：
1. 解码字形条：创建一个宽度为字形条宽度一半加一、高度为字形数量加 2 的黑(0)输出网格。在第一行的中间列放置绿(3)起点标记。
2. 从起点标记正下方开始，逐字形向下追踪路径：竖直字形在当前列画两个红(2)像素（向下两行）；弯头字形画一个红(2)像素后水平移动一格（左或右取决于弯头方向），再画一个红(2)像素。
3. 路径画完后，识别输出网格中所有 4-连通黑(0)背景区域（不含路径像素和起点标记）。
4. 将种子像素放置到输出网格中对应的位置（根据输入下区域中种子的相对坐标映射到输出网格）。
5. 对每个包含种子的区域，将该区域所有黑(0)像素填充为种子颜色的配对色：蓝(1) → 红(2)，黄(4) → 品红(6)，灰(5) → 栗(9)。种子像素本身保持原色。
6. 不含种子的区域保持黑(0)。路径像素（红(2)）和起点标记（绿(3)）保持不变。

**关键洞察**：字形编码的是分隔边界而非填充区域——求解者需要理解字形是"墙壁指令"。而种子的颜色不直接出现在填充中，必须经过一层颜色配对映射，这只有对比多个示例后才能归纳。
