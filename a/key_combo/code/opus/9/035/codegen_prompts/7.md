## 新题 7：粗粒度块内标记边缘方位编码印章旋转

**组合逻辑**：[压缩(compress) + 含标记涂标记色(marker_presence_color)](创新：标记不仅标注"是否有"，其在块内的位置编码旋转信息) → [裁剪(crop)](保留) + [印章覆盖(stamp_overlay)](保留) + [旋转(rotate)](创新：旋转由标记在块内的边缘邻近度决定)

**来源原语**：压缩、粗粒度块、含标记涂标记色、阵列排布（e57337a4）；印章覆盖、瓦片（48f8583b）；旋转（2697da3f）；裁剪（d10ecb37）

**依赖链**：粗粒度块划分确定区域网格 → 识别含多色瓦片模板的块（提取模板）和含标记的块（确定印章位置）→ 标记在块内的边缘方位决定旋转角 → 旋转模板后粘贴到对应位置。单个标记像素同时承载位置信息（哪个块）和方位信息（块内哪条边），信息密度高于普通布尔标记。

将大网格分为粗粒度块阵列，其中一块含多色瓦片模板，其余块中的标记像素靠近块的哪条边就决定模板以何种旋转印入该块。

**输入结构**：15x15 网格（3x3 阵列，每块 5x5），背景黑(0)。中心块包含一个 3x3 的非对称多色瓦片模板（使用蓝(1)和红(2)像素的组合，使 0/90/180/270 度旋转均可区分），模板居中放置（周围一圈黑边距）。其余 8 个块中，2~4 个块各含恰好一个绿(3)单像素标记，其余块为全黑。每个标记像素位于其所在块的某条边附近（距该边 0~1 格，且距其他三条边 >=2 格，使"最近边"唯一确定）。

**规则**：
1. 将网格划分为 3x3 的 5x5 块阵列。
2. 识别中心块中的多色瓦片模板，提取其 3x3 边界框内容。
3. 对每个含绿(3)标记的块，确定标记像素距块四条边的曼哈顿距离，取最近的边：
   - 最近为上边 → 旋转 0 度（原始方向）
   - 最近为右边 → 顺时针旋转 90 度
   - 最近为下边 → 旋转 180 度
   - 最近为左边 → 顺时针旋转 270 度
4. 创建 9x9 输出网格（3x3 阵列，每个子块 3x3）。对每个输入块：
   - 若含绿标记：放置对应旋转的模板瓦片
   - 若为中心块或空块：填充黑(0)
5. 绿色标记像素不出现在输出中（被模板覆盖或被黑色替代）。

**关键洞察**：一个标记像素通过其在粗粒度块内的亚位置（哪条边最近）编码了旋转参数——这不是一个独立的旋转标志位，而是从空间位置中隐式提取的。求解者需对比多个示例发现"块内位置→旋转角"的映射关系。

## 实现要求

1. `main(grid)` 必须实现新题描述中的确定性转换规则，不能只识别 `generate_input()` 的固定模板。禁止不同的input网格输出相同的output网格。
2. `generate_input()` 必须随机生成多样样例，不能固定死。随机维度应覆盖：网格大小、对象数量、位置、颜色、方向、形状参数或关键分支。注意若描述中存在若干，需实现而不是只有单个，包括object或者对应关系等等。且若涉及到最短路径，则输入网格中必涉及到多条路径，对选择造成干扰。
3. 生成器必须保证输入满足 `main()` 的隐式假设：对象不重叠、不越界、特殊标记唯一或可区分、匹配关系无歧义、关键分支出现概率相同。
4. 禁止把 ARC 颜色 id 、亮度、拼写等当作人类不可见的数值语义参与排序、大小比较或隐藏映射。颜色变化必须有可见结构线索。注意颜色亮度、拼写等也是不可见信息，若描述中出现违规的颜色id或者亮度，可自行使用少量的固定颜色替代，但注意生成时要在三个以内输入输出网格中对所有变换100%覆盖度。
5. 输出样例要视觉清晰，人类必须能从输入输出对中肉眼辨认出规律。具体要求：避免对象粘连、覆盖关系混乱、同一像素多重语义；不同逻辑步骤产生的结果不要大面积层叠在一起导致无法分辨哪个颜色属于哪个步骤；输入中各元素之间保持足够间距，输出中新增的标记/填充/路径等应与背景和已有元素在颜色上有明显区分；若规则涉及多层叠加，生成时控制对象密度和尺寸，确保叠加区域只占少数像素而非铺满整个网格。
6. 若规则有多个分支，生成器不能长期固定成一个分支；应让分支在随机样例中合理出现。分支概率不必平均——难以发现的隐蔽分支（如少数情况下才触发的特殊规则）应适当提高出现概率，确保在 3 个训练示例中至少出现一次，否则求解者无法归纳该规则。对于颜色映射类规则，确保 2 个左右的示例即可覆盖所有映射关系（每种颜色→颜色的映射至少在某个示例中出现过）。
