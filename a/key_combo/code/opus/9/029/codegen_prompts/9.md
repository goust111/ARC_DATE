## 新题 9：车道标记驱动的精灵体转移与楔形展开

**组合逻辑**：[移动/transfer](红色车道精灵体转移到绿色车道) + [展开](创新：转移后的精灵体不做简单堆叠，而是以车道中心为轴做楔形展开) + [交替填色](创新：展开的每一层按距中心距离交替涂色) + [数量守恒]

**来源原语**：移动、车道、标记条、数量守恒、最近配对（参考题 9aaea919）；展开、中心对称展开（参考题 db3e9e38）；交替填色、奇偶决定颜色（参考题 db3e9e38）；擦除（参考题 bae5c565）

**依赖链**：转移数量决定展开高度（因为每个转移的精灵体对应展开中的一行），而展开的颜色模式又由精灵体在源车道中的垂直排列顺序决定（从下到上依次填入展开的从中心到两侧各行）。转移操作和展开操作共享同一个"数量"参数并交叉引用空间信息，形成紧耦合。

将红色标记车道中的精灵体转移到最近的绿色标记车道，转移后的精灵体以车道中心列为轴做楔形展开排列，展开宽度逐行递增且颜色交替。

**输入结构**：约 15x15 的黑(0)背景网格。网格中有 3~5 条垂直车道，每条车道由一条位于顶行或底行的标记像素标识：红(2)标记表示源车道，绿(3)标记表示目标车道。每条车道宽 1 列。红色车道中，从底部开始等间距（间距 2~3 行）排列着 2~4 个相同的单色精灵体（颜色为蓝(1)，每个精灵体是一个宽 1 列、高 1 像素的单像素——即蓝色像素点）。绿色车道初始为空（除标记像素外无前景像素）。生成约束：恰好有一条红色车道和一条绿色车道；红色车道的精灵体数量 n 满足 2 <= n <= 4；绿色车道左右两侧各有至少 n-1 列空间（保证楔形展开不超出网格边界）。

**规则**：
1. 识别红(2)标记的源车道列号 cs 和绿(3)标记的目标车道列号 ct。
2. 收集源车道中所有蓝(1)像素（精灵体），按行号从下到上排列，记为序列 S = [s1, s2, ..., sn]，其中 s1 是最底部的。
3. 将源车道中的所有蓝(1)精灵体擦除为黑(0)，同时将红(2)和绿(3)标记像素也擦除为黑(0)。
4. 在目标车道列 ct 处，从底部可用行开始向上构建楔形展开：
   - 第 1 行（最底部）：仅在列 ct 处涂蓝(1)，宽度 1。
   - 第 2 行（上一行）：在列 ct-1 到 ct+1 处涂色，宽度 3。中心列 ct 涂蓝(1)，两侧各涂橙(7)。
   - 第 k 行（k <= n）：在列 ct-(k-1) 到 ct+(k-1) 处涂色，宽度 2k-1。距中心列距离为偶数的位置涂蓝(1)，距离为奇数的位置涂橙(7)。
   - 共展开 n 行（等于源车道精灵体数量），相邻展开行之间间距为 1（紧邻排列），从底部向上生长。"底部可用行"定义为网格最底行减去 1（即倒数第二行，因为最底行原为标记行已擦除）。
5. 输出网格尺寸与输入相同。

**关键洞察**：展开的行数恰好等于转移的精灵体数量（数量守恒的变形应用），而交替涂色的规则基于距中心列的距离奇偶——需要对比不同精灵体数量的示例才能同时发现"行数=精灵数"和"奇偶决定颜色"这两条隐蔽规则。
