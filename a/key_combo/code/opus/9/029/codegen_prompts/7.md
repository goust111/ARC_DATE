## 新题 7：前缀行解码映射驱动跨区域连通分量重涂

**组合逻辑**：[补全](创新：前缀色映射不用于补全同行，而是生成颜色查找表) → [重涂色](创新：查找表驱动另一区域的连通分量颜色替换) + [筛选](创新：查找表中无对应条目的连通分量被擦除)

**来源原语**：补全、模板行、前缀片段、列对齐、前缀色映射补全行、编码映射（参考题 82819916）；重涂色、连通分量、归一化形状比对（参考题 4ff4c9da）；筛选、忽略干扰项（参考题 0a1d4ef5）；擦除（参考题 bae5c565）

**依赖链**：模板行和前缀行构成的解码结构产出一个颜色映射表（源色→目标色），但该映射不应用于补全前缀行自身，而是传递到网格的另一个区域，驱动那里的连通分量重涂。同时，映射表隐含了一个筛选功能——只有颜色出现在映射表"源色"中的连通分量才被保留和重涂，其余被擦除。解码和重涂两个逻辑作用于不同区域的不同对象，但通过映射表紧密耦合。

从网格上部的模板行和前缀行中解码出颜色映射表，用该映射表重涂网格下部散布的连通分量，并擦除映射表中无对应条目的分量。

**输入结构**：约 15x12 的黑(0)背景网格。网格由一条灰(5)水平分隔行分为上区域（约 4~5 行）和下区域（约 9~10 行）。上区域结构：最上面一行是完整的模板行，由两种颜色（如蓝(1)和红(2)）交替填满整行（无背景色间隔）。模板行下方有 1~3 行前缀行，每行从列 0 开始有一段连续的非背景前缀（2~4 个像素），前缀后为黑(0)背景。每个前缀行的前缀颜色与模板行对应列的颜色配对，定义一个颜色映射：前缀色 X 在列 c 处 → 模板色 Y 在列 c 处，则 X→Y 是映射的一条规则。每个前缀行恰好定义一条映射规则（一种前缀色映射到一种模板色）。下区域包含 4~6 个互不接触的 4-连通单色前景连通分量（每个 3~8 像素，形状不规则），颜色从蓝(1)、红(2)、绿(3)、黄(4)、品红(6)中选取。生成约束：前缀行定义的映射规则中，"源色"集合恰好覆盖下区域部分（非全部）连通分量的颜色；至少有一个下区域连通分量的颜色不在映射源色中。

**规则**：
1. 解析上区域的模板行和前缀行。对每个前缀行，将其每个前缀像素的颜色与同列的模板像素颜色配对。一个前缀行中所有配对应一致地给出一条映射 X→Y（生成保证无歧义）。汇总所有前缀行的映射，得到颜色查找表 M = {X1→Y1, X2→Y2, ...}。
2. 在下区域中，识别所有 4-连通的单色前景连通分量。
3. 对每个连通分量，检查其颜色 C 是否存在于查找表 M 的源色集合中：
   - 若 C 在 M 中（C = Xi），将该分量的所有像素重涂为 M[C]（即 Yi）。
   - 若 C 不在 M 中，将该分量的所有像素擦除为黑(0)背景。
4. 灰(5)分隔行在输出中保留。上区域（模板行和前缀行）在输出中保持不变。
5. 输出网格尺寸与输入相同。

**关键洞察**：前缀行的功能从"补全自身后续列"变成了"为另一区域提供重涂指令"——需要对比多个示例才能发现上区域的映射表与下区域重涂之间的对应关系，尤其是"映射表外的颜色被擦除"这一筛选规则。
