## 新题 3：形状匹配筛选后的锚点对齐叠加

**组合逻辑**：[归一化形状比对](识别哪些精灵体与模板形状匹配) → [筛选](创新：仅保留匹配的精灵体参与后续操作) → [透明叠加](创新：通过锚点对齐将筛选后的精灵体叠加) + [裁剪](裁剪至最小包围盒)

**来源原语**：归一化形状比对、模板对象、匹配模板则重涂（参考题 4ff4c9da）；透明叠加、锚点像素、锚点重合叠加（参考题 137eaa0f）；筛选、忽略干扰项（参考题 0a1d4ef5）；裁剪（参考题 6cbe9eb8）；精灵体（参考题 4290ef0e, 137eaa0f）

**依赖链**：形状匹配决定了哪些精灵体参与叠加（筛选条件），而叠加结果取决于参与者的颜色和锚点相对位置。两个逻辑缺一不可：不做形状匹配则不知道保留谁，不做锚点叠加则无法生成合成图案。且匹配判断和叠加操作的对象类型相同（精灵体），形成"同对象上的两步判定-执行"耦合。

在散布着多个带锚点的精灵体和一个模板精灵体的网格中，筛选出与模板形状匹配的精灵体，通过对齐它们的锚点进行透明叠加，裁剪输出。

**输入结构**：约 20x20 的黑(0)背景网格。网格中散布 5~7 个互不接触的精灵体，每个精灵体由一种前景颜色（蓝(1)、红(2)、绿(3)、品红(6)中的某一种）加上恰好一个灰(5)锚点像素组成。每个精灵体是一个 4-连通的单色小图形（3~7 个非灰像素），灰像素与该图形 4-连通相邻。此外，网格中有一个由青(8)色像素构成的模板精灵体（同样 4-连通，3~7 像素，无灰锚点）。生成约束：恰好有 2~3 个精灵体的非灰像素部分在平移归一化后与青(8)模板的形状完全一致；其余精灵体形状与模板不同；所有精灵体的包围盒互不重叠且与模板的包围盒也不重叠。

**规则**：
1. 提取青(8)模板精灵体的形状掩码（将其裁剪到最小包围盒，记录各像素相对于左上角的偏移集合）。
2. 对每个非模板精灵体，提取其非灰像素的形状掩码（同样平移归一化到左上角）。若该掩码与模板掩码完全一致，则标记为"匹配"。
3. 忽略所有不匹配的精灵体和青(8)模板（它们在输出中不出现）。
4. 将所有匹配的精灵体裁剪为各自的最小包围盒精灵图（保留灰锚点和彩色像素）。
5. 以第一个匹配精灵体（按其包围盒左上角从左到右、从上到下排序取首个）的灰锚点为画布原点，将其他匹配精灵体的灰锚点对齐到同一位置，透明叠加（黑(0)视为透明，非黑像素直接放置；若两个非黑像素重叠于同一位置，后叠加的精灵体按排序在后，其像素覆盖在先的）。
6. 灰(5)锚点在叠加完成后被擦除为黑(0)。
7. 将叠加结果裁剪到包含所有非黑像素的最小包围盒，作为输出。

**关键洞察**：模板精灵体本身不出现在输出中，它仅充当形状筛选器——必须对比多个示例才能发现"与模板不匹配的精灵体被丢弃"这一规则，因为在单个示例中可能误以为是按颜色或位置筛选。
