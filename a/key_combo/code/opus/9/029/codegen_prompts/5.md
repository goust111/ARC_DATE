## 新题 5：面板背景交集生成吸附锚点

**组合逻辑**：[透明叠加](创新：双面板背景交集不直接输出，而是生成锚点位置图) → [吸附](创新：孤立像素按最近距离吸附到交集位置) + [冲突优先级](多个像素争抢同一锚点时按距离优先)

**来源原语**：透明叠加、面板、分隔行、位置对齐、双面板背景交集（参考题 0c9aba6e）；吸附、孤立像素、最近距离、最短距离分配、冲突优先级（参考题 1b8318e3）；擦除（参考题 bae5c565）

**依赖链**：面板交集产生的标记位置集合是吸附操作的目标——交集结果决定了哪些位置可以接收像素，而吸附规则决定了每个孤立像素落到哪个目标位置。两个逻辑同时约束最终输出，缺一不可：不做交集则吸附目标不存在，不做吸附则交集结果无物理意义。这是一个"生成目标→分配资源"的双阶段结构，非线性流水线。

将双面板的背景交集位置作为磁性锚点，再将散布在网格第三区域的孤立彩色像素按最近距离吸附到这些锚点上。

**输入结构**：约 18x9 的黑(0)背景网格（高 18，宽 9），被两条灰(5)水平分隔行分为三个等高区域（每区域 5 行，两条分隔行各占 1 行，加上可能的边距行，具体行数可变但三区域等高）。上区域和中区域各包含一些前景像素（上区域用蓝(1)，中区域用红(2)），每种颜色的像素散布形成不规则图案（每个区域 6~12 个前景像素，均为单像素散布，不构成连通块）。下区域包含 3~5 个孤立的彩色像素（颜色从绿(3)、黄(4)、品红(6)中选取，每个像素颜色可不同）。生成约束：上区域和中区域的尺寸相同（去掉分隔行后行列数一致）；两个区域的背景(黑)交集位置数量 >= 下区域的孤立像素数量；下区域的孤立像素之间互不相邻。

**规则**：
1. 移除两条灰(5)分隔行。将上区域和中区域按位置对齐（逐像素对应）。
2. 找出两个区域中对应位置都是黑(0)背景的单元格集合——即双面板背景交集位置。这些位置标记为锚点。
3. 在输出网格中，输出尺寸等于单个区域的尺寸（行数 = 区域高度，列数 = 区域宽度）。初始化为全黑(0)。
4. 对下区域的每个孤立彩色像素，计算它到每个锚点的曼哈顿距离（下区域像素的行坐标需映射到区域本地坐标：减去下区域的起始行号）。将该像素分配给距离最近的锚点。若存在距离相同的多个锚点，选择列号较小的；若列号也相同，选择行号较小的。
5. 若多个孤立像素被分配到同一锚点，仅保留距离最近的那个像素（若距离也相同，保留在下区域中行号较小的像素，行号也相同则保留列号较小的）。被挤出的像素不重新分配，直接丢弃。
6. 在输出网格的锚点位置，涂上被分配到该锚点的孤立像素的颜色。未被分配任何像素的锚点保持黑(0)。

**关键洞察**：上区域和中区域本身的前景像素在输出中完全消失——它们的唯一作用是通过"取反交集"划定吸附目标的位置。必须对比多个示例才能发现面板交集不是最终输出，而是中间步骤。
