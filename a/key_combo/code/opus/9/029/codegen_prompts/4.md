## 新题 4：频率过滤重连后的周期色带倍增延伸

**组合逻辑**：[筛选](频率排序识别少数色) + [擦除](创新：清除少数色像素以重连断裂的色带) → [射线延伸](创新：沿对角方向按周期规律将色带延伸到倍增画布) + [画布倍增]

**来源原语**：筛选、频率排序、少数色替换（参考题 9caf5b84）；射线延伸、对角色带、周期重复、画布倍增（参考题 cad67732）；擦除（参考题 bae5c565）；对角方向（参考题 69889d6e）

**依赖链**：少数色像素嵌入在对角色带的路径中，将连续的色带截断为不连续的片段。频率过滤清除少数色后，被截断的色带片段重新连成完整的周期色带。只有在色带恢复连续性之后，才能正确提取其周期参数（行周期、颜色序列、对角偏移方向），用于在倍增画布上延伸。两步操作紧密耦合：不做过滤则色带不连续、周期无法提取；不做延伸则过滤无意义。

清除网格中像素数最少的颜色以修复被中断的对角色带，然后将修复后的周期色带延伸到双倍尺寸的画布上。

**输入结构**：约 10x10 的黑(0)背景网格。网格中有一条沿左上→右下方向的窄色带（宽度 1 像素），由两种前景颜色交替组成（如蓝(1)和红(2)交替，行周期为 2），即第 r 行的色带像素在列 c=r+offset 处，颜色按 r 的奇偶交替。色带中有 2~3 个像素被第三种颜色（如绿(3)）替换，使得色带在视觉上出现"断点"（该位置不是蓝也不是红）。绿(3)像素的总数严格少于蓝(1)和红(2)中任一种的像素数。除色带外无其他前景像素。生成约束：绿(3)像素仅出现在色带路径上（替换原有色带像素），不出现在色带外；绿(3)的像素数严格最少且与第二少的颜色无平局。

**规则**：
1. 统计输入中每种非背景颜色的像素总数。找到像素数严格最少的颜色（即绿(3)），将其所有像素清除为黑(0)背景。
2. 在清除后的网格中，剩余的非背景像素构成一条对角色带（可能有间断，但间断处恰好是刚清除的位置）。将这些间断处视为色带路径的一部分，根据色带上相邻已知像素的周期模式推断间断处应有的颜色，从而恢复完整的连续色带。具体推断方法：色带路径上每个位置的行号 r 决定颜色，取色带上任意已知像素的 (行号, 颜色) 对，按行周期推算所有位置的颜色。行周期 = 色带上同色相邻像素的最小行间距。
3. 创建一个 2H x 2W 的黑(0)画布（H 和 W 为输入网格的行数和列数）。将恢复后的色带规则（对角偏移、行周期、颜色序列）推广到整个大画布：对大画布的每一行 r，在列 c = (r + offset) mod 2W 处（若 c 在画布范围内）涂上由行周期决定的颜色。
4. 输出该 2H x 2W 画布。

**关键洞察**：少数色不是无关噪声，而是精确嵌入色带路径中的干扰——清除它后色带才可提取周期参数。需要对比多个示例才能发现"最少的颜色总是嵌在色带上"以及"清除后按周期补回再延伸"这一组合规则。
