## 新题 2：指示方向延伸至视线遮挡处

**组合逻辑**：[方向指示解码](保留) → [视线遮挡判断](创新：从遍历寻路变为延伸终止条件) → [延伸/extend](创新：终点由视线中第一个遮挡物决定，而非画布边界)

**来源原语**：延伸/extend（参考题 b527c5c6）、指示像素/indicator_pixel（参考题 b527c5c6）、方向指示/direction_indication（参考题 b527c5c6）、视线遮挡判断/line_of_sight_blocked（参考题 3490cc26）、矩形/rectangle（参考题 b527c5c6）、同行同列对齐/row_or_column_aligned（参考题 3490cc26）

**依赖链**：指示像素确定每个矩形的延伸方向 → 延伸射线沿该方向前进 → 视线遮挡判断确定射线在哪里停止（碰到第一个其他矩形的边缘即停止） → 延伸带的长度由遮挡距离决定。删除方向指示，不知道往哪个方向延伸；删除视线遮挡，延伸全部到达画布边界，输出不同。

每个带指示像素的绿色矩形沿指示方向延伸，直到撞上另一个矩形或画布边界。

**输入结构**：黑(0)背景，约 15x15 网格。网格中有 3~5 个绿(3)实心矩形（宽 2~4 像素、高 2~4 像素），彼此不重叠且不相邻。每个矩形的某一条边（上、下、左或右）的中间位置有一个红(2)像素，替换了该位置原本的绿(3)像素，标示延伸方向。矩形的排布保证：部分矩形在某个方向上与另一个矩形共享行带或列带（即延伸射线会碰到另一个矩形），部分矩形在指示方向上无遮挡（射线直达画布边界）。生成约束：不同矩形的延伸射线不会在延伸过程中互相交叉（各矩形的延伸带互不重叠）。

**规则**：
1. 对每个绿(3)矩形，定位其红(2)指示像素。指示像素所在的边决定延伸方向：位于上边 → 向上延伸；位于下边 → 向下延伸；位于左边 → 向左延伸；位于右边 → 向右延伸。
2. 从矩形的指示边出发，沿延伸方向逐像素扫描。延伸带的宽度等于矩形在垂直于延伸方向上的尺寸（例如向上延伸时，带宽等于矩形的列跨度）。
3. 延伸带遇到以下情况之一时停止：(a) 到达画布边界；(b) 延伸带的任一像素的下一步将进入另一个绿(3)矩形的像素位置。停止时不覆盖该阻挡矩形。
4. 将延伸带填充为绿(3)。同时，从红(2)指示像素出发，沿延伸方向画一条红(2)线，长度与延伸带相同（即红线从指示像素延伸到延伸带的末端）。
5. 各矩形的延伸独立处理，处理顺序不影响结果（因为生成约束保证延伸带互不重叠）。

**关键洞察**：延伸的终止条件不再是固定的画布边界，而是动态的——取决于其他矩形是否恰好挡在延伸路径上。求解者需要同时运用方向解码和视线扫描两套逻辑，仅靠其中任何一套都无法确定正确的延伸长度。
