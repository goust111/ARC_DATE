## 新题 1：重力沉降后的对角链判色

**组合逻辑**：[滑动/gravity_settling](保留) → [对角链式连接判定](创新：从静态拓扑分类变为对重力后构型的拓扑分类) → [重涂色](创新：由拓扑分类结果决定目标颜色)

**来源原语**：滑动/sliding（参考题 1e0a9b12、3618c87e）、对角链式连接/diagonal_chain（参考题 ecb67b6d）、重涂色/recolor（参考题 ecb67b6d）、列内独立/column_independent（参考题 1e0a9b12）、仅对角接触变色/diagonal_touch_recolor（参考题 ecb67b6d）

**依赖链**：重力沉降改变像素的空间位置 → 新位置产生了原始输入中不存在的 8-连通但非 4-连通邻接关系 → 对角链判定必须作用于沉降后的构型 → 判定结果决定哪些像素被重涂色。删除重力步骤，沉降后构型不存在；删除对角链判定，无法区分应重涂色的像素组。

给定散落的彩色像素，先按列独立重力沉降至底部，再将沉降后仅通过对角接触相连的同色像素组重涂为灰(5)。

**输入结构**：黑(0)背景，约 12x12 网格。网格中散布着多种前景颜色的单像素（每种前景颜色出现 4~8 个像素），像素之间互不相邻（4-连通意义下）。前景颜色使用红(2)、绿(3)、蓝(1)中的 2~3 种。像素分布保证：在列独立重力沉降后，某些同色像素会在底部堆叠时形成仅通过对角接触（8-连通但非 4-连通）相连的组，而另一些同色像素会形成 4-连通相连的组或保持孤立。生成约束：沉降后至少存在一个由 3 个以上同色像素组成的对角链组，且至少存在一个 4-连通的同色组，以确保两类结果都出现。

**规则**：
1. 对每一列，读取该列中所有非黑(0)像素，从上到下记录其颜色序列。
2. 将该列清空为黑(0)，然后将记录的颜色序列从该列最底行开始向上依次填入，保持读取顺序。（即列内重力沉降，各列独立处理。）
3. 沉降完成后，对每种前景颜色分别执行：将该颜色的所有像素按 8-连通分组。
4. 对每个 8-连通组，检查其内部是否存在任意两个像素是 4-连通邻居。若该组中**没有任何** 4-连通邻居对（即组内所有相邻关系均为纯对角接触），则将该组所有像素重涂为灰(5)。
5. 4-连通组和孤立像素保持原色不变。

**关键洞察**：对角链的判定对象不是原始输入，而是重力沉降后的构型——同一列中不同颜色像素的堆叠顺序决定了它们在底部的相对位置，从而决定了哪些同色像素恰好形成纯对角接触链。求解者必须先在脑中模拟重力，再判断沉降结果的连通拓扑。

Recolor the grey diagonal-chain regions in an orange field to teal.

Input structure
The input contains only grey pixels and orange pixels.  Grey pixels form
several 8-connected regions embedded in the orange field.

Rule
Decompose each grey 8-connected region into 4-connected lobes.  Recolor the
whole region teal only when it contains a straight diagonal run of at least
three pixels and those lobes meet only by diagonal corner contacts in a
non-branching diagonal chain or cycle; a single 4-connected region is
recolored only when it is a square diagonal staircase.

Key insight
The teal regions are not selected by size or position; they are the grey
regions whose internal connectivity depends on diagonal corner joins, while
same-edge cracks, rectangles, bars, and branching/noisy regions remain grey.

Compact every non-background pixel downward within its own column.

Input structure:
- A rectangular 2D grid has one dominant background color.
- Foreground pixels are sparse cells whose columns are independent.

Rule:
- For each column, read the non-background pixels from top to bottom.
- Clear the column to background, then write those pixels into the bottom

Key insight:
- This is stable vertical gravity: pixels fall straight down without changing

## 实现要求

1. `main(grid)` 必须实现新题描述中的确定性转换规则，不能只识别 `generate_input()` 的固定模板。禁止不同的input网格输出相同的output网格。
2. `generate_input()` 必须随机生成多样样例，不能固定死。随机维度应覆盖：网格大小、对象数量、位置、颜色、方向、形状参数或关键分支。注意若描述中存在若干，需实现而不是只有单个，包括object或者对应关系等等。且若涉及到最短路径，则输入网格中必涉及到多条路径，对选择造成干扰。
3. 生成器必须保证输入满足 `main()` 的隐式假设：对象不重叠、不越界、特殊标记唯一或可区分、匹配关系无歧义、关键分支出现概率相同。
4. 禁止把 ARC 颜色 id 、亮度、拼写等当作人类不可见的数值语义参与排序、大小比较或隐藏映射。颜色变化必须有可见结构线索。注意颜色亮度、拼写等也是不可见信息，若描述中出现违规的颜色id或者亮度，可自行使用少量的固定颜色替代，但注意生成时要在三个以内输入输出网格中对所有变换100%覆盖度。
5. 输出样例要视觉清晰，人类必须能从输入输出对中肉眼辨认出规律。具体要求：避免对象粘连、覆盖关系混乱、同一像素多重语义；不同逻辑步骤产生的结果不要大面积层叠在一起导致无法分辨哪个颜色属于哪个步骤；输入中各元素之间保持足够间距，输出中新增的标记/填充/路径等应与背景和已有元素在颜色上有明显区分；若规则涉及多层叠加，生成时控制对象密度和尺寸，确保叠加区域只占少数像素而非铺满整个网格。
6. 若规则有多个分支，生成器不能长期固定成一个分支；应让分支在随机样例中合理出现。分支概率不必平均——难以发现的隐蔽分支（如少数情况下才触发的特殊规则）应适当提高出现概率，确保在 3 个训练示例中至少出现一次，否则求解者无法归纳该规则。对于颜色映射类规则，确保 2 个左右的示例即可覆盖所有映射关系（每种颜色→颜色的映射至少在某个示例中出现过）。
7. 代码风格参考 `ARC_code`：使用 `numpy`，并把 `/home/lixinyu/snap/new/solvers/arc_utils.py` 作为公共参考工具箱，优先复用其中已经稳定的 bbox、连通域、裁剪、变换和颜色工具；目标文件必须能被 `SourceFileLoader` 直接加载。
8. 可以在目标目录放公共 helper 文件，或从 `arc_utils.py` 摘取少量必要函数；若只实现一道题，优先保持目标文件自包含，减少额外依赖。
9. `main(grid)` 必须带一段 docstring，按 `ARC_code` 参考题的格式分四部分书写：首行用一句话概述转换目标；随后 `Input structure:` 描述输入网格中的对象/背景/标记/边界/组件；`Rule:` 给出从输入到输出的确定性变换规则；`Key insight:` 点明解题核心洞见。该 docstring 供下游相似度/索引流程（按 `main` 的 docstring 抽取机制标签）使用，缺失会导致此题无法被收录为参考题。
