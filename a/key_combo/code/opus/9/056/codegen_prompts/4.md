## 新题 4：面积异常值筛选定位遮挡物后对称修复

**组合逻辑**：[筛选/filter + 异常值选择/outlier_selection](创新：从颜色多样性异常值变为面积异常值) → [擦除/erase](保留) → [对称补全/symmetry_completion](保留)

**来源原语**：筛选/filter（参考题 9a4bb226）、异常值选择/outlier_selection（参考题 9a4bb226）、擦除/erase（参考题 3345333e）、遮挡/occlusion（参考题 3345333e）、对称补全/symmetry_completion（参考题 3345333e）、镜像/mirror（参考题 3345333e）、填充矩形/filled_rectangle（参考题 3345333e）

**依赖链**：输入中多个实心矩形看起来都可能是遮挡物 → 需要通过面积比较找到面积异常值（与其他矩形面积显著不同的那个） → 将该异常矩形识别为遮挡物并擦除 → 暴露出被遮挡的对称对象碎片 → 用镜像对称补全还原完整对象。删除面积筛选，不知道擦除哪个矩形；删除对称补全，擦除后的碎片无法还原。

在多个实心矩形中找出面积异常者作为遮挡物擦除，然后镜像对称补全被遮挡的图案。

**输入结构**：黑(0)背景，约 14x14 网格。网格中有一个用蓝(1)像素构成的单色对象，该对象具有左右镜像对称性（完整时）。此外有 3~4 个不同颜色的实心填充矩形（颜色从红(2)、绿(3)、黄(4)、品红(6)中选取，各不相同）。其中恰好一个矩形与蓝色对象重叠，遮挡了对象的一部分（重叠区域显示矩形颜色而非蓝色）。其他矩形不与蓝色对象重叠，它们是独立的前景元素。面积约束：作为遮挡物的那个矩形的面积与其他矩形的面积相差明显——要么它的面积是唯一最大的（比其余所有矩形都大至少 50%），要么是唯一最小的（比其余所有矩形都小至少 50%）。其他矩形之间的面积差异较小（互相在 30% 以内）。不同示例中异常值的方向（偏大或偏小）可能不同，需对比多个示例归纳"异常值"含义。

**规则**：
1. 识别输入中所有实心填充矩形（每个矩形是一种非黑、非蓝的纯色 4-连通区域，且边界框内全部填满该色或被蓝色对象遮挡处除外——但因为我们是在原图上识别矩形颜色的连通区域，遮挡物矩形本身是完整可见的，因为它画在蓝色对象之上）。
2. 计算每个矩形的面积（像素数）。找到面积异常值：该矩形的面积与所有矩形面积的中位数之差的绝对值在所有矩形中最大，且明显偏离（生成时保证唯一）。
3. 将异常值矩形的所有像素擦除为黑(0)。
4. 此时被遮挡的蓝(1)对象露出不完整的部分。检测蓝色像素集合的竖直对称轴（通过现有蓝色像素的边界框中线确定）。
5. 将每个蓝(1)像素关于对称轴镜像到对侧——若对侧位置为黑(0)，则填入蓝(1)；若对侧已有蓝(1)，保持不变。
6. 非异常值的矩形保持原样不动。

**关键洞察**：难点在于遮挡物的识别——所有矩形在视觉上同为实心色块，没有标记指示哪个是遮挡物。面积异常值是唯一的线索，且异常方向（偏大或偏小）需要对比多个示例才能归纳出"离中位数最远"这个规则，而非简单的"最大"或"最小"。
