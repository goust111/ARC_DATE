## 新题 6：射线网格分区的边界可达性着色

**组合逻辑**：[射线延伸](创新：射线构造网格线而非信号传播) + [行列交叉](创新：交叉点标红后射线成为分区边界) + [连通分量检测](创新：在射线网格的间隙中检测区域) + [拓扑分类](创新：按边界可达性分类着色)

**来源原语**：射线延伸(45bbe264), 行列交叉(45bbe264), 标记像素(45bbe264), 异源交叉特殊着色(45bbe264), 边界可达性(84db8fc4), 拓扑分类(84db8fc4), 重涂色(84db8fc4), 连通分量检测(84db8fc4), 连通区域(84db8fc4), 网格边界(84db8fc4)

**依赖链**：标记像素的位置决定射线的行列 → 射线交叉点被标红 → 射线 + 交叉点将网格分割为若干矩形背景区域 → 区域是否接触网格外边界决定其分类 → 分类结果决定重涂颜色。标记像素的数量和位置同时影响分区数量和各区域的边界可达性——增减一个标记会同时改变两个层面。

将散布的彩色标记像素的整行整列涂为引导线，交叉点涂红，然后将被引导线分割出的背景矩形区域按是否触碰网格外边界分别涂为绿色或灰色。

**输入结构**：约 14x14 网格，黑(0)背景。3-5 个孤立的彩色标记像素（每个标记颜色不同，颜色从蓝(1)、黄(4)、橙(7)、青(8)、品红(6)中选取，不使用红(2)、绿(3)、灰(5)）。任意两个标记不在同一行也不在同一列。标记不在网格边界行/列上（即行号和列号都不为 0 或最大值）。

**规则**：
1. 对每个标记像素，将其所在整行和整列的所有背景像素涂为该标记的颜色。
2. 保留原始标记像素的颜色不变。
3. 当某个位置同时处于两个不同标记的行线和列线交叉处时，将该位置涂为红(2)。注意：标记像素本身虽处于自己的行列交叉处，但保持原色不变。
4. 步骤 1-3 完成后，网格中的彩色线条和红色交叉点将黑(0)背景分割成若干 4-连通的矩形区域。
5. 对每个背景矩形区域进行分类：若该区域中任何像素位于网格第 0 行、最后一行、第 0 列或最后一列，则标记为"外部区域"；否则标记为"内部区域"。
6. 将所有"外部区域"的背景像素涂为绿(3)。将所有"内部区域"的背景像素涂为灰(5)。

**关键洞察**：标记像素的行列位置决定了网格被切割的方式。N 个标记（行列均不同）将网格切割成 (N+1)x(N+1) 个矩形区域。其中，位于最外一圈的 4N 个区域触碰边界（外部），内部的 (N-1)x(N-1) 个区域不触碰边界（内部）。但求解者需要从具体示例中验证这个规律，而不能仅靠公式——因为标记恰好在极端位置时可能改变计数。
