## 新题 5：完整方块角标驱动对角印章

**组合逻辑**：[标记](创新：标记结果改变印章精灵体的边界框尺寸) + [完整方块才标记](已有) + [印章覆盖](创新：印章精灵体包含标记像素) + [对角偏移重复](已有) + [裁剪](已有)

**来源原语**：标记(14b8e18c), 完整方块(14b8e18c), 角外像素(14b8e18c), 角点邻接(14b8e18c), 完整方块才标记(14b8e18c), 印章覆盖(e619ca6e), 对角偏移重复(e619ca6e), 裁剪(e619ca6e)

**依赖链**：完整方块检测确定哪些对象参与后续操作 → 角标标记扩大了对象的有效边界框 → 扩大后的边界框尺寸(h', w')成为对角印章的步幅 → 步幅改变导致印章间距与原始方块尺寸不同。标记操作不是装饰性的，它实质性地修改了后续印章操作的参数。

检测前景中的完整方块并标记其角外像素，再将"方块+角标"作为整体精灵体沿两条对角线方向反复印章，非完整形状不参与印章。

**输入结构**：约 16x16 网格，黑(0)背景。分布 3-5 个绿(3)前景对象（4-连通单色）：其中 1-3 个是完整方块（边界框为正方形，且边界框边缘所有位置都有绿色像素，即填满的正方形或正方形框），其余为非方形条状或不规则碎片。各对象互不接触，周围至少有 2 行/列的空白间距。完整方块的尺寸在 2x2 到 4x4 之间。生成约束：完整方块的位置保证沿对角方向至少能放下 2 个完整副本再超出网格。

**规则**：
1. 保留所有输入对象不变（包括非完整形状）。
2. 识别每个完整方块：4-连通绿(3)对象，其边界框为正方形且边界框一像素宽的边框上所有位置均为绿色。
3. 对每个完整方块，在其四个角的正外侧各标记 2 个红(2)像素——即角像素正交方向（上下或左右）相邻的两个背景位置。具体地：对于方块左上角像素(r,c)，标记(r-1,c)和(r,c-1)；右上角像素(r,c')，标记(r-1,c')和(r,c'+1)；左下角像素(r',c)，标记(r'+1,c)和(r',c-1)；右下角像素(r',c')，标记(r'+1,c')和(r',c'+1)。若标记位置超出网格则跳过。
4. 将每个完整方块及其 8 个红色角标作为一个复合精灵体，计算该复合体的边界框高度 h' 和宽度 w'（方块本身为 s x s 则 h' = s+2, w' = s+2）。
5. 沿两条对角线方向反复印章：从方块原始位置出发，在偏移量 (+h', +w'), (+2h', +2w'), ... 和 (+h', -w'), (+2h', -2w'), ... 处放置复合精灵体的副本，直到副本完全超出网格。超出网格边界的部分裁剪丢弃。
6. 印章副本不覆盖已有的非背景像素（包括原始的绿色对象和其他方块的印章）。若副本的某个像素位置已被占据，该像素跳过不绘制。

**关键洞察**：角标使复合精灵体的边界框比方块本身每边大 1 像素，因此对角印章的步幅为 (s+2, s+2) 而非 (s, s)。不同大小的方块产生不同的步幅，它们的印章轨迹在网格上可能交错。如果忽略角标直接用方块做印章，结果会明显不同——这迫使求解者理解标记操作对后续步幅的影响。
