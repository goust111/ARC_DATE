## 新题 8：掩码与对角印章格子的交集过滤

**组合逻辑**：[印章覆盖](创新：生成规则的对角格子图案) + [掩码决定保留](创新：不规则掩码截取格子图案的局部) + [擦除](创新：掩码和未命中像素同时清除) + [颜色替换](创新：幸存像素统一变色标记)

**来源原语**：印章覆盖(e619ca6e), 对角偏移重复(e619ca6e), 实心矩形(e619ca6e), 裁剪(e619ca6e), 掩码像素(f76d97a5), 掩码决定保留(f76d97a5), 擦除(f76d97a5), 颜色替换(f76d97a5)

**依赖链**：小矩形的尺寸决定对角印章格子的间距和覆盖位置 → 掩码形状决定哪些格子位置的像素被保留 → 两者的空间交集才是最终输出 → 颜色替换标记哪些像素通过了双重过滤。印章图案和掩码形状是两个独立输入，必须同时正确推断才能得到输出——单独理解任一个都无法预测结果。

将蓝色小矩形沿四个对角方向反复印章形成规则格子，然后仅保留与灰色掩码区域重合的印章像素并变色为红色，其余全部清除。

**输入结构**：约 15x15 网格，黑(0)背景。一个蓝(1)实心小矩形（2-3 行，2-4 列），位于网格上半部分。一个灰(5)不规则连通区域（4-连通，8-15 像素，形状不对称），位于网格中部偏下。蓝矩形与灰区域不重叠，且间隔至少 2 个像素。生成约束：蓝矩形的对角印章轨迹中至少有 3 个副本与灰掩码区域存在像素重合。

**规则**：
1. 以蓝(1)矩形为原型，设其高度为 h、宽度为 w。从矩形左上角位置出发，在四个对角方向 (+h,+w), (+h,-w), (-h,+w), (-h,-w) 及其整数倍偏移处放置矩形副本。保留原始矩形本身。
2. 超出网格边界的副本部分裁剪丢弃；完全超出的副本不绘制。
3. 所有印章副本均为蓝(1)色，形成一个规则的对角格子图案。
4. 将灰(5)掩码区域视为过滤器：遍历网格每个像素，仅当该位置同时是蓝(1)印章像素且原始输入中为灰(5)掩码像素时，该像素保留。
5. 保留的像素从蓝(1)重涂为红(2)。
6. 清除所有其他非背景像素：未保留的蓝印章像素、剩余的灰掩码像素，均设为黑(0)背景。
7. 输出：仅有红(2)像素留在黑(0)背景上。

**关键洞察**：输出是两个独立空间模式的交集——一个是由小矩形尺寸决定的严格规则对角网格，一个是输入中给定的不规则掩码形状。求解者必须先在脑中展开完整的对角格子（这需要正确提取矩形的 h 和 w 作为步幅），再将格子与掩码叠加，才能定位存活像素。单独看掩码或单独看矩形都无法预测哪些位置变红。
