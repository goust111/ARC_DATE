## 新题 4：重建框架计数房间排序同心重绘

**组合逻辑**：[重建](已有) + [计数](创新：统计重建后的封闭房间数) + [排序](创新：按房间数排列) + [重绘](创新：以同心方框形式输出排序结果) + [忽略干扰项](已有)

**来源原语**：重建(89565ca0), 分隔框架(89565ca0), 封闭区域(89565ca0), 忽略干扰项(89565ca0, e3721c99), 区域数映射长度(89565ca0), 排序(89565ca0, c920a713), 同心方框(c920a713), 重绘(c920a713)

**依赖链**：噪声干扰 → 需要重建墙壁才能正确计数 → 房间数量决定排序 → 排序结果决定同心嵌套顺序 → 同心框的几何结构由排序后的颜色数决定。每个阶段的输出是下一阶段不可替代的输入：不重建则计数错误，不计数则无排序依据，不排序则无嵌套顺序。

将被噪声损坏的多色分隔框架重建后，按各框架封闭房间数从少到多排序，输出为同心嵌套方框（最外层为房间最少者，最内层为房间最多者）。

**输入结构**：约 20x20 网格，黑(0)背景。3-5 种非黑颜色各绘制一个轴对齐的矩形分隔框架（1 像素宽的矩形外框加若干水平或竖直内部隔墙，将框内分为 1-4 个背景房间）。各框架可部分重叠。另有一种散布的噪声颜色（非黑，与所有框架颜色不同），其像素随机散落在网格各处，覆盖部分框架像素造成损坏。生成约束：每个真实框架颜色在其完整矩形边框和隔墙上至少有 60% 的像素存活（未被噪声覆盖）；不同框架的房间数互不相等；噪声颜色的像素在做直线段重建后不封闭任何背景区域。

**规则**：
1. 识别噪声颜色：对每种非背景颜色，尝试用密集行/列证据进行直线墙壁重建（若某行或某列中该颜色像素数量占该行/列在其边界框范围内长度的 50% 以上，则该行/列段为一面墙）。重建后不封闭任何背景区域的颜色即为噪声色。
2. 擦除所有噪声颜色像素。
3. 对每种非噪声颜色，用上述重建规则恢复完整的矩形外框和内部隔墙。
4. 在每种颜色的重建框架中，统计被墙壁完全封闭的 4-连通背景区域数量（即房间数）。
5. 按房间数从小到大排序各颜色。若房间数相等（生成约束保证不会发生），以重建边界框面积较小者排前。
6. 生成输出网格：尺寸为 (2N-1) x (2N-1)，其中 N 为非噪声框架颜色数。以排序后第 1 种颜色（房间最少）画最外层 1 像素宽方框，第 2 种颜色画次外层，以此类推，最内层为房间最多的颜色。各层同心嵌套，中心为单像素。

**关键洞察**：噪声不仅遮盖了颜色像素，还可能伪造出看似合理的墙壁段——求解者必须通过密度阈值判断哪些线段是真实墙壁的残留、哪些是噪声恰好排成的直线。房间数这一拓扑特征对噪声具有鲁棒性（重建后稳定），因此是可靠的排序依据。
