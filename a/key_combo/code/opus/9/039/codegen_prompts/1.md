## 新题 1：重力落种同心扩展

**组合逻辑**：[重力下落](创新：落点决定扩展中心) + [同心层填充](创新：多源扩展竞争) + [冲突优先级](创新：切比雪夫距离最近者胜)

**来源原语**：重力下落(963c33f8), 障碍物(963c33f8), 同心层填充(9356391f), 种子像素(9356391f), 切比雪夫距离索引(9356391f), 色板行(9356391f), 分隔行(9356391f), 冲突优先级(c92b942c)

**依赖链**：障碍物的空间分布决定种子像素的落点位置 → 落点位置决定同心扩展的中心坐标 → 多个扩展中心同时生长时，切比雪夫距离提供冲突仲裁 → 色板行提供距离到颜色的映射。重力模拟与同心填充之间存在不可跳过的位置传递：不完成重力计算就无法确定环心，不确定环心就无法判断距离冲突。

将悬浮的彩色种子像素在障碍物约束下自由下落，以各自落点为圆心用色板行进行切比雪夫距离同心环扩展，多环碰撞时距离更近的种子获得该像素。

**输入结构**：约 16x16 网格，黑(0)背景。第 0 行为色板行：从左边缘起连续排列若干非黑像素，颜色各异，作为距离 d=0,1,2,...的调色板（色板内可包含黑(0)像素表示该距离环为背景色）。第 1 行为灰(5)分隔行（整行灰色）。第 2 行至最后一行为工作区域：散布若干灰(5)障碍像素（单独散落，不形成连通大块），以及 2-4 个彩色种子像素（颜色均与色板行第 0 项 palette[0] 相同），种子像素悬浮在空中（其正下方至少有一行为空或有障碍物）。生成约束：任意两个种子不在同一列；每个种子正下方至少存在一个灰障碍像素或底边。

**规则**：
1. 保留色板行、分隔行和所有灰(5)障碍像素不变。
2. 每个种子像素从其初始位置竖直下落：逐行向下移动，在遇到的第一个灰障碍像素的正上方一格停止；若该列无障碍像素，则落在工作区域最底行。种子原始位置清除为背景。
3. 读取色板行：从第 0 行左边缘开始，依次读取像素颜色，直到遇到第一个处于色板最右侧非黑项之后的位置为止，得到调色板序列 palette[0], palette[1], ...。
4. 以每个落定种子为中心，对工作区域中的每个背景像素计算到该种子的切比雪夫距离 d。若 d < len(palette)，该像素候选颜色为 palette[d]。
5. 多源冲突解决：若某像素处于多个种子的扩展范围内，取切比雪夫距离最小的种子的候选颜色。距离相等时，取种子所在列号较小的种子的颜色。
6. 同心环不覆盖灰障碍像素和分隔行。距离 d 处若 palette[d] 为黑(0)，该环位置保持背景不变。

**关键洞察**：种子的最终位置完全由其下方障碍物的分布决定，而非由其初始位置决定。同一组障碍物在不同列有不同的"地形高度"，导致种子落在不同高度，进而使同心环图案在竖直方向错位、在水平方向交错。求解者必须先完成重力模拟才能确定环心，再处理多源环的空间竞争。
