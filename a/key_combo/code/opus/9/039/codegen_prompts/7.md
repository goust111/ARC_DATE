## 新题 7：平铺涌现孔洞的分级填充

**组合逻辑**：[平铺](创新：无孔形状平铺后在间隙处涌现孔洞) + [描边](创新：对平铺后的形状做外轮廓以定义边界) + [洪泛填充](创新：在描边后的封闭区域中执行) + [计数](创新：按孔洞面积分级着色)

**来源原语**：平铺(c92b942c), 描边(543a7ed5), 洪泛填充(543a7ed5), 封闭区域(543a7ed5), 外部邻接区域(543a7ed5), 孔洞填色轮廓描色(543a7ed5), 计数(878187ab), 计数映射尺寸(878187ab)

**依赖链**：原始小形状无封闭孔洞 → 3x3 平铺后副本之间的间隙可能形成封闭区域 → 描边操作区分了外部轮廓与内部空隙 → 孔洞面积计数将封闭区域分为两类 → 不同面积类别对应不同填充颜色。涌现效应：单个形状不具备的拓扑特征（孔洞），在平铺后由多个副本之间的空间关系产生。

将一个无孔洞的小前景形状 3x3 平铺，在平铺画布上为前景像素描绿色外轮廓，然后将平铺间隙中涌现的封闭区域按面积分为两级，最小面积级填黄色，其余填红色。

**输入结构**：约 5x5 至 7x7 的小网格，黑(0)背景。恰有一种非黑前景颜色（如橙(7)），前景像素形成一个 4-连通的单色形状（3-6 像素），该形状无封闭孔洞（即形状的背景补集通过 4-连通可完全到达网格边界）。形状不完全填满网格（至少有 40% 的像素为背景）。生成约束：形状的设计使得 3x3 平铺后，相邻副本之间的间隙中至少存在两种不同面积的封闭背景区域（例如角落间隙较小、边缘间隙较大）。

**规则**：
1. 将输入网格在水平和竖直方向各重复 3 次，生成一个 3 倍宽、3 倍高的平铺画布（若原始网格为 H x W，画布为 3H x 3W）。
2. 在平铺画布上，识别所有橙(7)前景像素。
3. 描绿色外轮廓：将画布上每个与任意橙(7)像素 8-邻接（含对角）的背景像素标记为绿(3)。
4. 识别封闭背景区域：在画布上，从网格四边出发，对所有未被橙(7)或绿(3)占据的背景像素做 4-连通洪泛填充，标记为"可达边界"。剩余未标记的背景像素（既非前景、非轮廓、又不可达边界）形成若干 4-连通封闭区域。
5. 统计每个封闭区域的面积（像素数）。找出所有封闭区域中的最小面积值 A_min。
6. 将面积等于 A_min 的封闭区域填充为黄(4)。
7. 将面积大于 A_min 的封闭区域填充为红(2)。
8. 将步骤 4 中标记为"可达边界"的背景像素保持黑(0)不变。

**关键洞察**：原始小形状完全没有封闭孔洞，但平铺后多个副本在空间上彼此靠近，它们之间的背景间隙被四周的前景像素和轮廓围合形成新的封闭区域。不同位置的间隙（角落处四个副本汇合 vs 边缘处两个副本相邻）面积不同，由此产生分级着色。求解者必须先在脑中完成平铺，再识别涌现的封闭区域，最后按面积分级。
