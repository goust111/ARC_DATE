## 新题 2：镜像拓扑变色

**组合逻辑**：[镜像](创新：镜像合并改变拓扑) + [洪泛填充/连通分量检测](创新：在合并形状上检测孔洞) + [孔洞数映射颜色](创新：拓扑属性而非几何属性决定重涂色)

**来源原语**：镜像(ad3b40cf), 对称轴(ad3b40cf), 沿轴反射(ad3b40cf), 洪泛填充(543a7ed5), 封闭区域(543a7ed5, e3721c99), 孔洞数映射颜色(e3721c99), 颜色图例(e3721c99), 连通分量检测(84db8fc4)

**依赖链**：镜像操作改变了形状的拓扑结构（原始形状无孔洞或少孔洞，合并后可能产生新孔洞） → 孔洞数量需要在合并后的形状上重新计算 → 孔洞数映射到图例颜色完成重涂色。关键耦合在于：镜像不只是几何复制，它与原始形状的并集创造了新的拓扑属性，而这个新属性才是决定颜色的依据。

将灰色精灵体沿蓝色轴线镜像后，统计原始与镜像合并体的封闭孔洞数，按图例将合并体整体重涂为对应颜色。

**输入结构**：约 15x15 网格，黑(0)背景。一条竖直的蓝(1)像素线贯穿网格中央列（从第 0 行到最后一行，整列为蓝色），作为反射轴。轴线左侧分布 2-4 个灰(5)精灵体（4-连通，各 4-8 像素，形状不规则且不对称，各精灵体互不接触，不触碰轴线，且与轴线之间至少间隔 1 列背景）。精灵体的设计使得部分精灵体镜像合并后会产生新的封闭孔洞（如 C 形镜像后闭合成 O 形），部分则不会（如线性形状镜像后仍无孔洞）。网格右下角区域放置 2-3 个小型彩色图例形状（非灰、非蓝、非黑的颜色，各图例颜色不同，如红(2)、绿(3)、黄(4)），每个图例形状自身具有不同数量的封闭孔洞（分别为 0、1、2 个孔洞），且图例形状互不接触、不触碰网格外边界。生成约束：灰精灵体的镜像位置不与图例形状重叠；各灰精灵体合并后的孔洞数均能在图例中找到对应。

**规则**：
1. 保留蓝(1)轴线和所有图例形状不变。
2. 将每个灰(5)精灵体沿蓝色轴线做左右镜像反射，在轴线右侧对应位置绘制灰(5)镜像副本。
3. 对每个灰精灵体，取其原始像素与镜像像素的并集，作为一个合并形状。
4. 在合并形状上检测封闭孔洞：以 4-连通方式从网格边界对背景像素做洪泛填充，合并形状内部无法被该洪泛到达的背景连通区域即为孔洞。统计每个合并形状的孔洞数。
5. 查阅图例映射：找到孔洞数与该合并形状相同的图例形状，读取其颜色。
6. 将合并形状的所有像素（原始 + 镜像）重涂为对应图例颜色。

**关键洞察**：单独看左侧的灰精灵体可能没有孔洞，但镜像后与自身合并会"闭合"出新的封闭空间。求解者必须先在脑中完成镜像操作并构建合并体，然后才能判断拓扑变化（孔洞数增减），最后才能确定颜色。仅看原始形状的几何外观无法直接得出答案。
