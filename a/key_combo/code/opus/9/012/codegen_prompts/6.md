## 新题 6：图例指导半区条件重涂

**组合逻辑**：[微型图例→颜色替换映射](来自e9b4f6fc，保留图例读取逻辑) + [裁剪](来自e9b4f6fc) → [半区+重涂色](来自e7dd8335，创新：重涂不是统一变红，而是按图例映射变色，且仅作用于下半区)

**来源原语**：微型图例/颜色替换映射/裁剪(e9b4f6fc)、半区/重涂色/包围盒(e7dd8335)

**依赖链**：图例提供颜色映射规则但不指定作用区域；半区规则限定映射仅在下半区生效。不读取图例则不知道怎么重涂；不应用半区约束则整个对象都会被重涂（与原题 e9b4f6fc 无法区分）。求解者必须对比多个示例发现上半区不变、下半区才应用图例替换。

裁剪多色目标对象，按图例的颜色映射仅对下半区执行颜色替换，上半区保持原色不变。

**输入结构**：约 14x14 的黑(0)背景网格。一个多色矩形目标对象（由 2~3 种非背景色构成，如蓝(1)和绿(3)，包围盒高度为偶数，宽 4~7、高 4~8），位于网格中央偏左。1~2 个水平二像素图例色块（domino）散布在目标对象的右侧或下方，与目标对象不相邻（至少间隔2格）。每个图例 domino 的右像素颜色出现在目标对象中，左像素颜色不出现在未替换的目标对象中。生成约束：各图例 domino 的右像素颜色互不相同；图例映射关系在上半区和下半区都有可替换像素（以使半区限制效果可观测）。

**规则**：
1. 找到多色矩形目标对象，裁剪其包围盒区域作为输出基底。
2. 读取每个图例 domino：左像素为替换色 R，右像素为源色 S，构成映射 S→R。
3. 计算裁剪区域包围盒的水平中线：中线位于第 H/2 行（H为包围盒高度，0-indexed，即中线以上为行 0 到 H/2-1，中线及以下为行 H/2 到 H-1）。
4. 对裁剪区域的下半区（行 H/2 到 H-1）中的每个像素：若其颜色为某映射的源色 S，则替换为对应的 R。
5. 上半区（行 0 到 H/2-1）的所有像素保持原样。

**关键洞察**：图例映射在全对象范围内都是合法的，但变换只在下半区生效——这一空间限制在单个示例中可能被误解为"只有下半区碰巧有该颜色"，需要对比多个示例（上半区也有该颜色但未被替换）才能确认规则。
