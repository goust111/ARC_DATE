## 新题 7：格子结构中对角周期填色与边缘覆写

**组合逻辑**：[格子结构→单元格阵列位置](来自8a371977) + [对角线同余→周期填色](来自c3f564a4，创新：周期填色的单位不是像素而是格子单元格) → [边缘与内部区分→边缘覆写](来自8a371977，创新：边缘单元格不是简单变红，而是覆写为特定颜色，与对角周期色不同)

**来源原语**：格子结构/单元格区域/行列阵列位置/边缘与内部区分(8a371977)、对角周期图案/对角线同余/补全(c3f564a4)、重涂色(c8f0f002)

**依赖链**：格子结构确定单元格的行列阵列坐标；对角线同余规则（行索引+列索引）mod K 为每个内部单元格指定颜色；边缘/内部区分决定哪些单元格按对角周期涂色、哪些按边缘规则覆写。三个环节各自提供不可替代的信息。

在格子结构划分的单元格阵列中，内部单元格按对角线同余规则循环涂色，边缘单元格统一涂为灰色。

**输入结构**：约 17x17 的网格。栗(9)像素构成格子结构（lattice）：栗色填满外边框的一行/一列，并在内部形成等间距的行条和列条（每条宽1像素），将网格分割为至少 4x4 的单元格矩形阵列（每个单元格为 2x2 或 3x3 的等大矩形区域）。部分单元格已被填充为非背景色（从蓝(1)、红(2)、绿(3)、黄(4)中选取），部分单元格仍为黑(0)。已填充的单元格均位于阵列的内部位置（非边缘行/列），且其颜色符合对角线同余规则：设单元格在阵列中的行索引为 r、列索引为 c（均从 0 开始），令 K 为使用的前景色种数（K=3 或 4），颜色按 (r+c) mod K 映射到一个固定的颜色序列。部分内部单元格的颜色被替换为黑(0)（作为需要补全的"空洞"）。所有边缘单元格（阵列第一行/最后一行/第一列/最后一列的单元格）均为黑(0)。

**规则**：
1. 识别栗(9)格子结构，确定单元格阵列的行数 R 和列数 C，以及每个单元格的阵列坐标 (r, c)。
2. 从已着色的内部单元格推断对角线同余映射：确定颜色种数 K 和 (r+c) mod K 到颜色的映射表。
3. 对每个内部单元格（1 <= r <= R-2, 1 <= c <= C-2）：若为黑(0)，则根据 (r+c) mod K 查表填充对应颜色。若已有颜色，保持不变。
4. 对每个边缘单元格（r=0 或 r=R-1 或 c=0 或 c=C-1）：统一填充为灰(5)。
5. 栗(9)格子像素保持不变。

**关键洞察**：内部单元格的涂色规则是对角线同余（而非行列独立），但边缘单元格被统一覆写为灰色，打破了对角周期——求解者需对比多个示例，分离"边缘覆写"和"对角周期"两条并行规则。
