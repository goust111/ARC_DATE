## 新题 8：精灵体旋转匹配嵌入后按面积排序输出

**组合逻辑**：[精灵体+孔洞+形状匹配+旋转→拼合](来自97a05b5b，保留旋转匹配嵌入逻辑) → [计数各孔洞面积+排序](来自81c0276b，创新：排序的不是颜色频率而是嵌入后各孔洞区域的面积) → [裁剪+生成网格](来自7039b2d7，创新：输出不是均匀色网格而是按面积排序的精灵体裁剪行)

**来源原语**：精灵体/孔洞/形状匹配/旋转/拼合/裁剪(97a05b5b)、计数/排序/频率统计(81c0276b)、生成网格(7039b2d7)

**依赖链**：必须先完成形状匹配和旋转才能确定每块精灵体嵌入哪个孔洞；嵌入后每个孔洞区域的面积（=精灵体像素数）决定排序顺序；裁剪和排列依赖排序结果。三个阶段层层依赖。

将多色精灵体旋转匹配嵌入红色对象的孔洞中，然后按各精灵体的像素面积从小到大裁剪输出为纵向排列的行。

**输入结构**：约 20x20 的黑(0)背景网格。一个红(2)大对象位于网格左侧或中央（4-连通，约 40~60 像素），内部有 2~4 个黑(0)孔洞（每个孔洞为一个 4-连通的黑色连通域，面积 3~8 像素，完全被红色像素包围，各孔洞形状互不相同且面积互不相同）。网格右侧或下方散布 2~4 个多色精灵体（每个精灵体由 1~2 种非红非黑颜色构成，如蓝(1)、绿(3)、黄(4)、橙(7)；精灵体之间互不相邻，且与红色对象不相邻）。每个精灵体的形状经过 0/90/180/270 度旋转后恰好与某一个孔洞形状匹配（像素位置一一对应），精灵体与孔洞之间一一对应。

**规则**：
1. 找到红(2)对象中的所有黑(0)孔洞，记录每个孔洞的形状（相对像素坐标集合）和面积（像素数）。
2. 找到所有散布在外的多色精灵体。对每个精灵体，尝试 0/90/180/270 度旋转，找到与某孔洞形状匹配的旋转方式和对应孔洞。
3. 将每个精灵体按匹配的旋转方式旋转后，记录其颜色像素。
4. 按孔洞面积从小到大排序所有已匹配的精灵体。
5. 输出网格：计算所有精灵体包围盒的最大宽度 W；输出高度为所有精灵体包围盒高度之和，宽度为 W。从上到下依次放置每个精灵体（已旋转）的裁剪包围盒，左对齐，右侧空余部分填充黑(0)。精灵体之间无间隔行。

**关键洞察**：输出的排列顺序不由精灵体在输入中的空间位置决定，也不由精灵体自身颜色决定，而由其匹配孔洞的面积决定——求解者必须先完成形状匹配才能确定排序键。

Input structure
- The background is the dominant color.

- Each block has four non-background, non-block corner pixels diagonally adjacent to it.

Rule

Key insight
- The 2x2 blocks are color rotators and ray blockers; the corner pixels are not independent dots but the four ports of each block.
