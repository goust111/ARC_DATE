## 新题 5：图层合成后按频率排序输出色条

**组合逻辑**：[透明叠加+图层优先级](来自6a11f6da，保留三层合成逻辑) → [计数+频率统计+排序](来自81c0276b，创新：频率统计的对象不是预设表格中的色块，而是合成后的像素)

**来源原语**：透明叠加/等高面板/图层优先级/底层最优先(6a11f6da)、计数/排序/频率统计/按计数升序(81c0276b)

**依赖链**：三面板合成决定每个位置的最终颜色（图层冲突由优先级规则解决），合成结果改变了各颜色的像素频率分布，频率统计和排序必须基于合成后的结果。不做合成则频率分布不确定；不做排序则输出格式不确定。

将三个等高面板按图层优先级合成为一个面板，统计合成结果中每种非背景色的像素数量，输出按数量升序排列的左对齐色条。

**输入结构**：约 15x9 的网格（宽15、高9）。黑(0)背景上纵向排列三个等高面板（每个面板高3行、宽与网格同宽），面板之间无间隔。每个面板内包含若干非背景色像素（每个面板使用 1~2 种前景色，从红(2)、绿(3)、蓝(1)、黄(4)、橙(7)中选取；不同面板可使用相同颜色）。三个面板中各颜色的像素位置存在部分重叠（即同一列同一相对行位置在多个面板中都有非背景像素）。生成约束：合成后至少出现 3 种不同的非背景色，且各颜色的像素计数互不相同（避免排序歧义）。

**规则**：
1. 将三个面板视为从上到下分别为顶层面板、中层面板、底层面板，每个面板高 3 行。
2. 合成规则：从中层面板开始作为基底，将顶层面板的每个非黑像素覆盖到相同相对位置上，再将底层面板的每个非黑像素覆盖到相同相对位置上（底层优先级最高，最后覆盖）。合成结果为一个 3 行 x 宽的面板。
3. 统计合成面板中每种非黑(0)颜色的像素总数。
4. 按像素总数从小到大排序。输出网格的行数等于颜色种数，列数等于最大像素计数。第 i 行（从上到下，i=0 为最少的颜色）为第 i 种颜色的左对齐色条（前 count 列为该颜色，其余列为黑(0)）。

**关键洞察**：频率统计的输入不是直接可见的——三个面板中同一位置可能有不同颜色的像素相互覆盖，合成优先级改变了最终的颜色分布，求解者不能简单地数每种颜色在输入中出现了多少次。
