## 新题 3：字形解码驱动空心矩形定向拉伸

**组合逻辑**：[字形图案→解码](来自995c5fa3，创新：解码结果不映射为颜色行，而映射为拉伸方向) + [位置映射](来自995c5fa3，创新：字形相对于矩形的方位决定拉伸作用的边) → [拉伸+重绘](来自b548a754/baf41dbf，创新：拉伸量由解码值决定而非由标记点位置决定)

**来源原语**：字形图案/解码/位置映射(995c5fa3)、拉伸/重绘/空心矩形(b548a754/baf41dbf)、包围盒(e74e1818)

**依赖链**：字形解码得到拉伸量（1~4格），字形相对于矩形的方位（上/下/左/右）决定拉伸的边，两者共同确定拉伸参数。不解码则不知拉伸多远；不判断方位则不知拉伸哪条边。

解码空心矩形四周的灰色字形块，获得拉伸量，再根据字形相对于矩形的方位确定拉伸方向，将矩形的对应边向外推移相应格数并重绘。

**输入结构**：约 18x18 的黑(0)背景网格。中心区域有一个红(2)边框、黄(4)内部的空心矩形（边框宽1像素，内部至少 3x3）。矩形的上方、下方、左方、右方各有 0 或 1 个灰(5)/黑(0)组成的 3x3 字形块（灰为底色，黑像素构成掩码图案）。共出现 2~4 个字形块。每个字形块的掩码图案是四种预定义图案之一，分别编码拉伸量 1、2、3、4（图案定义：全灰无黑=1；中心一个黑像素=2；中心行三个黑像素=3；四角各一个黑像素=4）。每个字形块与矩形的最短轴向距离为 1~2 格，且其中心与矩形的对应边中点在该边的垂直方向上对齐（允许+-1像素偏移）。不存在两个字形块位于矩形同一侧的情况。

**规则**：
1. 找到红(2)边框的空心矩形，记录其上、下、左、右四条边的位置。
2. 找到所有 3x3 灰(5)字形块。对每个字形块，根据其黑色掩码图案解码得到拉伸量 D（全灰=1，中心黑=2，中心行三黑=3，四角黑=4）。
3. 判断每个字形块相对于矩形的方位：字形块中心在矩形包围盒上方→控制上边；下方→控制下边；左方→控制左边；右方→控制右边。
4. 对每条被控制的边，向外移动 D 格（上边向上、下边向下、左边向左、右边向右）。未被任何字形块控制的边保持原位。
5. 用红(2)重绘扩展后矩形的边框（宽度仍为1像素），内部填充黄(4），矩形外部为黑(0)背景。字形块在输出中被擦除（变为黑(0)背景）。

**关键洞察**：字形块既是方向指示器（通过空间位置）又是数值编码器（通过掩码图案），两层信息缺一不可；求解者必须对比多个示例中不同掩码与不同拉伸量的对应关系，才能归纳出编码规则。
