## 新题 2：角括号选色定向周期图案恢复

**组合逻辑**：[角括号+标记像素→选色](来自1e81d6f9，创新：选出的颜色不用于擦除，而是指定要恢复的遮挡物颜色) → [周期平铺图案恢复](来自abbfd121，创新：仅对被选中颜色的遮挡物执行恢复，其余遮挡物保留)

**来源原语**：角括号/标记像素/按标记色选择同色(1e81d6f9)、周期平铺图案/矩形遮挡物/被遮挡(abbfd121)、擦除(1e81d6f9/abbfd121)

**依赖链**：角括号内的标记像素颜色决定哪些矩形遮挡物需要被移除并恢复底层周期图案；未被选中颜色的遮挡物必须原样保留。不读取标记颜色就不知道恢复哪些遮挡物；不执行周期图案推断就无法恢复被遮挡区域的内容。

读取角括号内标记像素的颜色，仅移除该颜色的矩形遮挡物并用推断出的周期平铺图案填补，其余遮挡物和角括号本身均保留。

**输入结构**：约 15x15 的网格。背景是一个行列周期为 2~3 的小图案平铺（使用蓝(1)和青(8)两色交替）。网格上散布 3~5 个不同颜色的实心矩形遮挡物（每个遮挡物为单色，颜色各不相同，使用红(2)、绿(3)、黄(4)、橙(7)中的若干种；每个遮挡物宽高均>=2，互不重叠，完全覆盖其下的周期图案）。网格中有一个灰(5)像素构成的单色 4-连通角括号对象（L形，3~4像素，开口朝向不定），角括号的包围盒内部（不含角括号自身像素）恰好有一个前景标记像素，该标记像素的颜色与某一种遮挡物颜色相同。角括号位于不被任何遮挡物覆盖的区域。

**规则**：
1. 找到灰(5)角括号对象，读取其包围盒内部非灰非背景图案色的那一个标记像素的颜色，记为 C。
2. 从网格中所有未被遮挡的区域（不含遮挡物和角括号区域）推断周期平铺图案的最小重复单元。
3. 找到所有颜色为 C 的矩形遮挡物，将其每个像素替换为该位置对应的周期图案颜色。
4. 颜色不为 C 的遮挡物像素保持原样不变。
5. 角括号和标记像素保持原样不变。

**关键洞察**：角括号不再是"擦除指令"而是"恢复指令"——它指定的颜色不是要从全局删除的颜色，而是要揭开的遮挡层；求解者必须对比多个示例才能发现标记颜色与被恢复遮挡物颜色的对应关系，因为仅凭单个示例可能误以为是按位置或面积选择遮挡物。
