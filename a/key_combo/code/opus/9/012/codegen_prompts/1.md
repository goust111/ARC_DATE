## 新题 1：四象限镜像涌现封闭区域填充

**组合逻辑**：[镜像+拼接](来自0c786b71，保留四象限镜像) → [洪泛填充](来自00d62c1b，创新：作用于镜像后涌现的封闭区域而非输入中已有的封闭区域)

**来源原语**：镜像/拼接/四象限对称(0c786b71)、洪泛填充/封闭区域/拓扑内外(00d62c1b)

**依赖链**：输入中的绿(3)曲线并不自封闭，无法独立产生封闭区域；四象限镜像拼接后，曲线在对称轴处对接形成闭合边界，洪泛填充才有可操作的拓扑内部。删除镜像步骤则无封闭区域可填；删除填充步骤则输出与单纯镜像无法区分。

从一组不封闭的绿色曲线出发，通过四象限镜像使曲线在对称轴拼合成闭合边界，再将涌现出的封闭黑色内部填充为黄色。

**输入结构**：约 7x9 的黑(0)背景网格。绿(3)像素构成 1~3 条不自封闭的曲线段（4-连通，每条 4~10 像素），每条曲线至少有一个端点位于网格的边缘行或边缘列上。曲线之间互不相邻。生成约束：将网格进行四象限镜像拼接后（原始位于右下象限，左右翻转位于左下，上下翻转位于右上，180度旋转位于左上），至少存在一个被绿色边界完全4-连通封闭的黑色连通域，且该连通域不与拼接后网格的外部黑色区域4-连通相通。

**规则**：
1. 构造一个高度为原始行数x2、宽度为原始列数x2 的输出网格。
2. 将原始网格放入右下象限。
3. 将原始网格左右翻转后放入左下象限。
4. 将原始网格上下翻转后放入右上象限。
5. 将原始网格旋转180度后放入左上象限。
6. 在拼接结果中，从输出网格的四条外边界向内做洪泛标记（4-连通），标记所有与外边界4-连通相通的黑(0)像素为"外部"。
7. 将所有未被标记为"外部"的黑(0)像素重涂为黄(4)。绿(3)像素保持不变。

**关键洞察**：封闭区域在输入中并不存在——它们是镜像拼接的涌现结果；求解者必须先在心中完成镜像，才能判断哪些区域会被封闭。

    each corner must be in bounds (block row >= 1 from top, etc., but corners on grid edge are allowed — margin 0 OK)
  input_content: only bg, block cells, and corner pixels; no other colored cells
  transform:
    rotate each block's 4 corner colors clockwise (NW<-SW, NE<-NW, SE<-NE, SW<-SE)
    from each rotated corner, paint outward along its diagonal until grid edge or another block's 2x2 body
    if a ray cell is 4-adjacent to another ray start of same color with path len > 1, truncate there
    blocks themselves are unchanged
  ray_lengths: 1-8 observed; at least some rays per example have length >= 2

generation_strategy:
  approach: direct construction (input is simple enough)
  steps:
    1. Pick grid size N in [8..12].
    2. Pick block count K in [1..3]. Place K non-overlapping 2x2 blocks such that each block's 4x4 corner-inclusive bbox is in bounds and no two 4x4 bboxes overlap. Ensure at least one block has margin >= 2 on some diagonal so rays are non-trivial.
    3. For each block, assign a random permutation of {3,6,7,8} to its 4 corners.
    4. Fill everything else with bg=0.
    5. Validate by running solver — reject if solver raises (conflicting rays) or all rays have length 1.

## 实现要求

1. `main(grid)` 必须实现新题描述中的确定性转换规则，不能只识别 `generate_input()` 的固定模板。禁止不同的input网格输出相同的output网格。
2. `generate_input()` 必须随机生成多样样例，不能固定死。随机维度应覆盖：网格大小、对象数量、位置、颜色、方向、形状参数或关键分支。注意若描述中存在若干，需实现而不是只有单个，包括object或者对应关系等等。且若涉及到最短路径，则输入网格中必涉及到多条路径，对选择造成干扰。

6. 若规则有多个分支，生成器不能长期固定成一个分支；应让分支在随机样例中合理出现。分支概率不必平均——难以发现的隐蔽分支（如少数情况下才触发的特殊规则）应适当提高出现概率，确保在 3 个训练示例中至少出现一次，否则求解者无法归纳该规则。对于颜色映射类规则，确保 2 个左右的示例即可覆盖所有映射关系（每种颜色→颜色的映射至少在某个示例中出现过）。
