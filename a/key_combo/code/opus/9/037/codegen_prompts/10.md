## 新题 10：围墙内的种子周期生长遇壁反射

**组合逻辑**：[种子周期生长](已有) + [区域封闭/墙壁线段](创新：墙壁不再用于洪泛填充判定，而是作为生长射线的反射面) + [镜像](创新：从整体图案翻转改为单条生长射线的方向反射) + [对角偏移](已有) + [填充](已有)

**来源原语**：种子周期生长/对角偏移/孤立像素(3ac3eb23), 区域封闭/墙壁线段/封闭区域(a5313dff), 镜像(67e8384a, dc0a314f), 填充(3eda0437)

**依赖链**：红墙界定一个封闭区域 → 区域内有彩色种子像素 → 种子发射对角周期生长射线 → 射线遇到红墙时反射（镜像反弹）继续生长 → 射线最终形成的轨迹图案覆盖区域内部 → 未被轨迹覆盖的最大黑色矩形被填充为灰色

种子在红墙围成的封闭区域内进行对角周期生长，射线遇墙反射继续延伸，最终剩余的最大空白矩形被填充为灰色。

**输入结构**：
- 网格约 13x13，黑(0)背景。
- 红(2)像素构成一个封闭的单像素宽多边形墙壁（矩形或 L 形），围成一个面积约 8x8 至 10x10 的内部区域。墙壁完全封闭，内部与外部不四连通。
- 封闭区域内有 1~2 个孤立的彩色种子像素，颜色各不相同，取自 {蓝(1), 绿(3), 黄(4), 橙(7)}。种子与墙壁不相邻（距红墙至少 2 像素）。
- 封闭区域外为黑(0)背景，无其他前景像素。
- 生成约束：封闭区域足够大，使种子的反射生长至少能发生 2 次反射后才停止。区域内在生长完成后存在至少一个 2x2 的全黑矩形区域。

**规则**：
1. 识别红(2)墙壁围成的封闭区域（红墙内侧的四连通黑色区域）。
2. 找到封闭区域内的孤立彩色种子像素。按行号升序、列号升序处理种子。
3. 对每个种子，从种子位置开始向四个对角方向（左上、右上、左下、右下）各发射一条周期生长射线。射线每步移动 1 像素（沿对角方向），每隔 1 步绘制一个像素（即步数为奇数时绘制，偶数时跳过——与种子位置的曼哈顿距离奇偶性匹配时绘制）。
4. 当射线的下一步将进入红(2)墙壁像素或离开封闭区域时，射线发生反射：
   - 若碰到水平方向的墙壁（上方或下方为红像素），行方向取反，列方向不变。
   - 若碰到垂直方向的墙壁（左方或右方为红像素），列方向取反，行方向不变。
   - 若碰到墙壁角落（对角方向的下一步为红像素，且相邻的水平和垂直方向也有红像素），行列方向同时取反（原路反弹）。
   射线从反射点继续按新方向生长，保持周期-2 的绘制间隔不重置。
5. 射线在以下情况停止：a) 反射后的下一步仍为墙壁（被困在角落）；b) 下一步的像素已被当前种子的射线绘制过（形成闭环）；c) 总步数超过封闭区域面积的 2 倍（防止无限循环）。
6. 所有种子的生长完成后，在封闭区域内寻找最大面积的全黑(0)矩形（宽和高均至少为 2）。将其填充为灰(5)。若面积最大的矩形不唯一，取左上角行号最小的，再取列号最小的。
7. 红(2)墙壁和封闭区域外部保持不变。

**关键洞察**：种子的周期生长不是在开放空间中无限扩展，而是被墙壁约束并通过反射改变方向——生长轨迹的最终形态取决于墙壁的几何形状。最后的灰色填充找到的是"生长盲区"，即射线反射模式恰好覆盖不到的最大矩形空白区。

```yaml
    outline: outermost layer = largest fg pixel count, single 8-connected component
    fill: 0-1 middle layers between outline and marker [observed]
    marker: innermost layer = smallest non-outline fg pixel count, 1-3 pixels, never 4-adjacent to background
  transform:
    rule: erase all foreground; paint every background pixel 4-adjacent to any outline pixel with marker color
    output: only marker-colored contour pixels on background; grid shape unchanged

generation_strategy:
  approach: output-first
  steps:
    1. Choose grid size (5-16 square or rectangular) and background color.
    2. Define a wedge/diamond shape via per-row left/right boundaries (each boundary changes by 0 or 1 per row, overall height 5-7, max width 3-5). Position it touching exactly 2 grid edges.
    3. The outline = border pixels of this filled shape. Compute outer contour = bg pixels 4-adjacent to outline. This is the output.
    4. Assign colors - pick outline color, optionally one fill color, and a marker color, all with distinct pixel counts. Fill shape concentrically (outline on border, fill inside, marker innermost).
    5. Verify outline is single 8-connected component, marker count < any other fg count, and outer contour is non-empty. This is the input.
```
</generation_spec>
</reference_puzzle>
