## 新题 14：遮挡方块定位后以象限对称恢复并裁剪为棋盘式输出

**组合逻辑**：[反射恢复遮挡](已有) + [象限排布](创新：从平铺结构改为确定反射来源的象限) + [裁剪](创新：裁剪区域不由边界框决定而由恢复内容的象限数决定) + [缩放](创新：恢复后的区域缩放为标准尺寸以形成棋盘排列)

**来源原语**：反射恢复遮挡/遮挡块/被遮区域/镜像对称(dc0a314f), 象限排布(67e8384a), 裁剪(a740d043, a6953f00), 缩放(b99e7126)

**依赖链**：识别场景中的遮挡方块 → 将场景分为四个象限 → 遮挡方块所在象限为"损坏象限"→ 从其他象限中找到可用的镜像对称源 → 恢复损坏象限的内容 → 将四个象限按 2x2 排列裁剪输出 → 输出中损坏象限的位置放置恢复后的内容，其他象限放置原内容

在四象限对称的场景中定位遮挡方块所在象限，用对称象限的内容恢复后按 2x2 排列输出四个象限。

**输入结构**：
- 网格为偶数边长的正方形（如 14x14），以中心分为四个等大象限。
- 场景具有双轴镜像对称性（关于水平和垂直中心线对称），但其中一个象限被一个 3x3 至 4x4 的品红(6)单色遮挡方块部分破坏。
- 场景使用 2~3 种颜色（如蓝(1)、红(2)、灰(5)）在黑(0)背景上绘制。品红(6)不出现在正常场景中。
- 遮挡方块完全落在一个象限内部，不跨越中心线。
- 生成约束：遮挡方块不覆盖中心线上的像素；三个未损坏象限至少有一个与损坏象限关于某轴对称且自身无遮挡。

**规则**：
1. 以网格的水平和垂直中心线将网格分为四个象限：左上(TL)、右上(TR)、左下(BL)、右下(BR)。
2. 找到品红(6)遮挡方块的位置，确定其所在象限（损坏象限）。
3. 确定恢复来源：优先使用关于垂直中心线对称的象限（左↔右）。若该象限也被遮挡（本题保证不会），则使用关于水平中心线对称的象限。
4. 将来源象限的内容关于对应的对称轴做镜像翻转。
5. 用翻转后的内容替换损坏象限中品红(6)遮挡方块覆盖的像素，恢复原始场景。
6. 输出为一个 2x2 排列的网格：每个象限缩放为 (原象限宽/2) x (原象限高/2)（缩小到一半，最近邻采样），按原始位置排列。即输出网格大小为原网格的 1/2 x 1/2 = 1/4 面积。
7. 缩放规则：每 2x2 的像素块取左上角像素的颜色作为缩放后的像素。

**关键洞察**：遮挡恢复不是最终输出——恢复只是中间步骤，最终输出是整个场景（含恢复部分）的缩小版。需要同时理解对称恢复逻辑和缩放输出格式，仅看对称性或仅看缩放都无法得到正确答案。
