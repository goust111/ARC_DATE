## 新题 12：双色矩形内叶片标记行列交叉处的最大空白填充

**组合逻辑**：[叶状突起/突起定行列](已有) + [双色矩形](已有) + [搜索/最大矩形填充/最小边长约束](创新：搜索范围不是整个网格而是叶片行列交叉切割后的子区域) + [填充](已有) + [重涂色/内外色互换延伸](创新：互换范围限定在交叉格内)

**来源原语**：叶状突起/突起定行列/双色矩形/内外色互换延伸(f1cefba8), 搜索/最大矩形填充/最小边长约束(3eda0437), 填充(3eda0437)

**依赖链**：叶状突起标记若干行和列 → 标记行列将双色矩形内部切割为一个网格状分区 → 在标记行列的交叉处，内外色互换 → 互换后寻找矩形内部最大的全内色矩形子区域 → 将其填充为第三种颜色

叶状突起标记行列，将矩形内部切割成棋盘式的内外色分区，交叉格互换颜色后，最大的纯色矩形区域被填充为新颜色。

**输入结构**：
- 网格约 14x14，黑(0)背景。
- 一个大矩形前景区域（约 10x12）由外色 A（如红(2)）的单像素宽边框和内色 B（如蓝(1)）的实心内部组成。
- 矩形的上/下边缘有 2~3 个内色 B 的单像素叶状突起（标记列），左/右边缘有 1~2 个内色 B 的单像素叶状突起（标记行）。
- 矩形内部除了纯色 B 外无其他元素。
- 生成约束：标记行列将矩形内部分割为至少 3x3 个子区域；存在一个面积最大（宽高均 >= 2）的"交叉格"（行列均被标记的子区域），使得互换后的最大纯色搜索有唯一解。

**规则**：
1. 识别矩形前景区域。外色 A = 矩形四角的颜色，内色 B = 矩形内部主色。
2. 识别叶状突起：上/下边缘外的内色 B 像素标记其所在列；左/右边缘外的内色 B 像素标记其所在行。
3. 标记行和标记列将矩形内部（不含 A 色边框）分割为一个行列网格。将子区域分为两类：
   - "交叉格"：行索引（从上到下，0-indexed）和列索引（从左到右，0-indexed）奇偶性相同的子区域。
   - "非交叉格"：行列索引奇偶性不同的子区域。
   其中行列索引的计算以标记行列为分隔线：第一条标记行/列之前的区域索引为 0，之间为 1，以此类推。
4. 在矩形内部，将所有交叉格的像素从内色 B 重涂为外色 A，同时将标记行和标记列上的像素（在矩形内部的部分）从内色 B 重涂为外色 A。非交叉格保持内色 B。
5. 重涂后，在矩形内部（含边框内侧）搜索最大面积的全内色 B 矩形区域（宽和高均 >= 2）。
6. 将该最大区域填充为绿(3)（若 A 或 B 已经是绿(3)，则填充为黄(4)）。
7. 叶状突起像素在输出中擦除为黑(0)。外色 A 边框保持不变。

**关键洞察**：叶状突起不是直接生成射线或切割线（如参考题 f1cefba8 的外延），而是将矩形内部划分为棋盘格式的交叉分区——交叉格的颜色互换改变了内部的颜色分布，使得"最大矩形搜索"的结果完全取决于叶片位置。两个操作（互换 + 搜索）在同一空间域上交织，缺一不可。
