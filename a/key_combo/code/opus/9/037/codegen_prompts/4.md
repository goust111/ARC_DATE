## 新题 4：重力下沉竖条形成封闭区域并继承填充色

**组合逻辑**：[滑动/碰撞阻挡](已有) + [洪泛填充/区域封闭](创新：封闭边界由动态滑动结果生成而非静态存在) + [墙壁线段](已有) + [频率比较](创新：从选取角落改为决定填充色继承逻辑)

**来源原语**：滑动/碰撞阻挡/滑动至目标旁(3906de3d), 洪泛填充/区域封闭/孤立背景区域填充(a5313dff), 墙壁线段(a5313dff), 频率比较(a6953f00)

**依赖链**：彩色竖条在重力作用下向下滑动 → 滑动遇到灰墙或网格底部停止 → 停止后的竖条与灰墙共同构成新的边界结构 → 检测边界结构中的封闭黑色区域 → 每个封闭区域的填充色取决于其边界上出现频率最高的竖条颜色

彩色竖条向下滑动直到撞上灰墙或底部，然后与灰墙共同围成的封闭区域被填充为边界上出现最多的竖条颜色。

**输入结构**：
- 网格约 14x16（略高），黑(0)背景。
- 灰(5)像素构成若干水平和垂直的单像素宽静态墙壁线段，分布在网格中下部。墙壁不完全封闭任何区域（初始状态下不存在封闭黑色区域）。
- 网格上部有 4~6 根彩色竖条，每根竖条为 1 像素宽、2~4 像素高的垂直连通块，颜色各不相同，取自 {蓝(1), 红(2), 绿(3), 黄(4), 品红(6), 橙(7)}。
- 每根竖条正下方的路径上没有其他竖条（竖条列号互不相同，或同列竖条间保持足够间距不会碰撞）。
- 生成约束：竖条下落并停止后，灰墙与停止后的竖条恰好形成 2~3 个四连通封闭黑色区域；每个封闭区域的边界上至少有 2 根不同颜色的竖条参与（使频率比较有意义）。

**规则**：
1. 将灰(5)墙壁视为固定障碍。将网格底边也视为障碍。
2. 对每根彩色竖条，在其所在列中将整根竖条向下平移，直到竖条的最底部像素的下一行是灰(5)墙壁像素或网格底边。清除竖条原始位置的颜色（置为黑(0)）。
3. 竖条按列号从左到右依次处理。若同列有多根竖条，从下方的先处理（先落位的成为后续竖条的障碍）。
4. 所有竖条落位后，将灰(5)像素和所有竖条像素均视为墙壁，识别所有无法通过四连通路径到达网格边界的黑(0)区域（封闭区域）。
5. 对每个封闭区域，检查其四连通边界上所有非黑非灰像素（即竖条像素）。统计各颜色出现的像素数量，出现最多的颜色作为该区域的填充色。若数量并列，取在网格中列号最小的那根竖条的颜色。
6. 用该填充色填充封闭区域内的所有黑(0)像素。
7. 灰(5)墙壁和竖条像素保持不变。

**关键洞察**：初始网格中没有封闭区域——封闭区域只有在竖条下落并与灰墙拼合后才出现；而填充颜色又由参与围合的竖条之间的数量竞争决定。这形成了一条三步依赖链：滑动 → 封闭检测 → 频率决策。
