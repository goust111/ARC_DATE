## 新题 5：射线交叉动态围合与来源染色

**组合逻辑**：[射线延伸](创新：射线从标记像素出发沿基数方向而非对角方向) + [封闭区域/区域封闭](创新：封闭边界由射线动态生成) + [洪泛填充](已有) + [擦除](已有) + [标记像素](已有)

**来源原语**：射线延伸(5c0a986e, f1cefba8), 封闭区域/区域封闭(a5313dff), 洪泛填充(a5313dff), 擦除(494ef9d7, 17b866bd), 标记像素(17b866bd)

**依赖链**：标记像素向四基数方向发射射线直到遇到灰墙或网格边界 → 射线本身成为新的墙壁 → 射线与灰墙共同界定出新的封闭区域 → 每个封闭区域的填充色由贡献了其最长边界射线的标记像素决定 → 未参与围合任何区域的标记像素被擦除

标记像素向四方发射射线形成新边界，由此围成的封闭区域被填充为贡献最长边界的标记颜色，无贡献的标记被擦除。

**输入结构**：
- 网格约 13x13，黑(0)背景。
- 灰(5)像素构成若干不完整的单像素宽墙壁线段（水平或垂直），留有缺口。
- 3~5 个彩色标记像素，分布在墙壁的缺口附近或开放区域内，颜色各不相同，取自 {蓝(1), 红(2), 绿(3), 黄(4), 橙(7)}。
- 标记像素不与灰墙直接相邻（四连通距离至少 2）。
- 生成约束：每个标记的射线至少有一条能连接到灰墙（不只是到达边界），使得射线能够与灰墙共同形成至少一个封闭区域。至少有一个标记的所有射线都不参与任何封闭（该标记将被擦除）。整体恰好形成 2~3 个封闭区域。

**规则**：
1. 从每个标记像素向上、下、左、右四个方向各发射一条射线。射线颜色与标记像素相同。
2. 每条射线逐像素延伸，遇到灰(5)墙壁像素或网格边界时停止（不覆盖灰墙像素；到达边界时最后一个像素在边界行/列上）。射线遇到另一条射线时不停止，后绘制的覆盖先绘制的颜色。
3. 射线的绘制顺序：按标记像素的行号升序处理，行号相同按列号升序，每个标记按上、右、下、左的顺序绘制四条射线。
4. 所有射线绘制完成后，将灰(5)像素和所有射线像素均视为墙壁。识别所有无法通过四连通路径到达网格边界的黑(0)区域（封闭区域）。
5. 对每个封闭区域，检查其四连通边界上的所有射线像素。对于边界上的每个标记来源（可通过颜色追溯），统计该标记的射线在此封闭区域边界上贡献的像素总数。贡献最多的标记的颜色作为填充色。若并列，取行号更小的标记的颜色。
6. 用填充色填充该封闭区域内的所有黑(0)像素。
7. 检查每个标记像素：若其四条射线中没有任何一条参与了某个封闭区域的边界，则将该标记像素及其所有射线像素擦除为黑(0)。
8. 灰(5)墙壁保持不变。标记像素（未被擦除的）保持原色。

**关键洞察**：射线不是最终输出的一部分装饰，而是构建封闭边界的建筑材料——封闭区域在输入中不存在，完全由射线的交叉与灰墙的拼合动态生成。需要同时理解射线延伸规则和封闭判定逻辑才能解题。
