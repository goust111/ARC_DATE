## 新题 7：频率稀有角落种子的象限约束周期生长

**组合逻辑**：[频率比较/重复色或稀有色](创新：从选取角落裁剪改为选取周期生长的种子) + [种子周期生长/对角偏移](已有) + [象限排布](创新：从平铺反射改为生长范围限制) + [裁剪](已有)

**来源原语**：频率比较/重复色或稀有色(a6953f00), 种子周期生长/对角偏移(3ac3eb23), 象限排布(67e8384a), 裁剪(a6953f00, a740d043)

**依赖链**：统计四个角像素的颜色在全网格中的出现频率 → 最稀有的角像素成为生长种子 → 种子所在角确定其所属象限 → 周期生长仅在该象限范围内进行 → 输出裁剪至该象限

四个角像素中颜色最稀有的成为周期对角生长的种子，生长被限制在种子所属的象限内，输出为该象限的裁剪。

**输入结构**：
- 网格为偶数边长的正方形（如 12x12 或 14x14），便于等分象限。
- 四个角像素各有一种颜色，颜色取自 {蓝(1), 红(2), 绿(3), 黄(4)}，四角颜色互不相同。
- 网格内部散布着一些彩色像素作为"频率填充"：大多数像素使用某 2~3 种角颜色，使得各角颜色的全网格频率明显不同。
- 生成约束：恰好有一种角颜色的全网格频率严格最低（无并列）。频率填充像素不出现在种子象限内（种子象限在输入时仅含种子角像素和黑(0)背景）。

**规则**：
1. 读取四个角的像素颜色。统计每种角颜色在整个网格中出现的总次数（含角像素本身和内部填充像素）。
2. 频率最低的角颜色所在的角像素成为种子。
3. 以网格中心为原点将网格分为四个等大象限（左上、右上、左下、右下），种子位于其中一个象限的角上。
4. 从种子位置开始进行周期-2 对角生长：初始发射点为种子位置及其四个对角邻居共 5 个起点。从每个起点开始，每隔 2 行向下（远离种子所在边界的方向）放置一个同色像素。同时每隔 2 列向内（远离种子所在角的侧方向）也放置像素。即生长方向始终从角向象限内部扩展。
5. 所有生长像素必须严格落在种子所属的象限范围内（含边界行/列），超出象限的像素不绘制。
6. 输出为种子所属象限的裁剪（网格宽高各取一半）。

**关键洞察**：角像素的颜色频率决定了哪个角是种子，进而决定了生长发生在哪个象限——必须对比多个示例才能发现"频率最低"这个选取标准，因为单个示例无法排除按位置或颜色名选取的假说。

<description>
Move each gray marker along its green path until it reaches the cell next to a black-green-black gate, erasing the path behind it.

Input structure:
- The background is the dominant color.
- Foreground components are made from a path color, a paired gate-end color, and single marker pixels.
- A gate is a straight end-center-end motif whose center has the path color and whose two ends share the gate-end color.

Rule:
- In every 4-connected foreground component with exactly one marker and one gate, erase the marker and all path-color pixels except the gate center.
- Place the marker on the unique path-color pixel adjacent to the gate center but not between the two gate ends.
- Components without both a marker and a gate stay unchanged.

Key insight: The black-green-black motif marks the stopping gate; the gray marker consumes the connected green path until it rests on the path cell immediately beside that gate.
