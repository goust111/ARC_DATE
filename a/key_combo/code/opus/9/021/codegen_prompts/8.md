## 新题 8：格子路由的标记滑动与多源投票填充

**组合逻辑**：[滑动 + 碰撞停止](创新：滑动路径不是朝向自由空间中的锚点，而是沿格子框架的线路) → [标记归属区域](创新：归属由滑动终点与格子单元的空间关系决定，而非由标记的原始位置决定) → [投票 + 洪泛填充](创新：同一单元可收到多个不同颜色标记，需多数投票决定填充色)

**来源原语**：滑动(a48eeaf7)、碰撞停止(a48eeaf7)、射线对齐(a48eeaf7)、格子框架(83302e8f)、封闭背景区域(83302e8f)、投票(de1cd16c)、标记归属区域(de1cd16c)、最多标记区胜出(de1cd16c)、洪泛填充(83302e8f)、标记像素(a48eeaf7/de1cd16c)、填充块(a48eeaf7)

**依赖链**：格子框架提供路由线路 → 标记沿格子线滑向锚点 → 碰撞停止于锚点邻环 → 停靠位置关联特定格子单元 → 同一单元的多标记投票 → 投票结果决定填充颜色。标记的原始位置、格子结构、锚点位置三者共同决定标记的终点和归属。

将格子线上的彩色标记像素沿格子路由滑向中央锚点，停在锚点邻环后归属到相邻格子单元，每个单元按收到标记的多数颜色洪泛填充。

**输入结构**：约 14x14 黑(0)背景网格。
- 灰(5)格子框架将网格分为规则的矩形单元（如 4x4 单元，每单元约 3x3 像素大小），格子线宽 1 像素。
- 蓝(1)的 2x2 锚点块放置在格子的某个十字交叉点上（覆盖四个单元共享的角区域）。
- 若干彩色标记像素（红(2)、绿(3)、黄(4)），每个放置在格子线上（即灰(5)像素位置，标记颜色覆盖灰色）。每个标记与锚点块中心处于同行或同列。
- 生成约束：每个标记沿格子线到锚点的路径是连续灰(5)像素（无中断）；至少有一个单元接收到 2 个以上不同颜色的标记；各标记颜色总数不完全相同，确保投票有结果差异。

**规则**：
1. 每个标记像素沿其所在行或列的格子线朝蓝(1)锚点滑动。标记沿灰(5)格子像素逐步移动，到达与锚点块任一像素 4-相邻的格子像素时停止。标记滑过的原位置恢复为灰(5)。
2. 每个标记的停靠位置恰好与锚点块的一侧相邻，同时也与恰好一个格子单元（停靠位置与锚点之间的那个单元）相邻。将该标记关联到这个单元。
3. 对每个关联了标记的单元：统计其收到的各颜色标记数量。颜色数最多的为"赢色"，将该单元的黑(0)背景区域洪泛填充为赢色。若出现平局，选择从更远处滑来的标记（即原始位置距锚点曼哈顿距离最大的那个标记）的颜色。
4. 未收到任何标记的单元保持黑(0)。锚点块保持蓝(1)。格子框架保持灰(5)（含标记滑过后恢复的灰色）。

**关键洞察**：格子框架不仅是空间分隔，更是标记的"铁轨"——标记只能沿格子线移动。锚点是所有标记的目的地，但格子结构将来自不同方向的标记路由到锚点的不同侧面，从而分配到不同的单元。两个从不同方向到达同一侧的标记会竞争同一个单元的填充权。
