## 新题 2：路径色序反转驱动封闭区域填充

**组合逻辑**：[颜色序列反转(reverse_color_seq)] + [洪泛填充(flood_fill)] + [擦除(erase)]。创新点：路径色序反转不是自身目的，而是改变路径各段在不同封闭区域内的颜色分布，从而改变各区域的填充色。反转操作通过重新分配颜色浓度来间接控制填充结果。

**来源原语**：颜色序列反转、单像素宽路径、端点像素、端到端遍历、形状不变仅反色序 (5792cb4d)；洪泛填充、轮廓框、封闭区域、标记在封闭区域内、多数色决定填充 (4b6b68e5)；擦除 (e7b06bea)

**依赖链**：路径色序反转改变了路径上各段的颜色分布 → 反转后路径在每个封闭区域内的多数色可能发生变化（反转将路径一端的颜色浓度搬到另一端）→ 洪泛填充使用反转后的路径段多数色 → 擦除路径。四个操作形成信息变换链：反转改变分布，分布改变多数色，多数色决定填充。

将穿越多个封闭区域的彩色路径进行端到端颜色反转，再用反转后各区域内路径段的主色填充对应区域，最后擦除路径。

**输入结构**：约 18x18 的黑(0)背景网格。3~4 个不同颜色的矩形轮廓框（每个轮廓框用不同的非黑、非路径色的颜色绘制，如橙(7)、品红(6)、栗(9)），每个轮廓框有一个 1 像素的缺口（开口位于某条边的中部）。一条 4-连通的单像素宽多色路径从网格的一个边缘出发，依次穿过每个轮廓框的缺口，进入并穿越框内部（路径在框内弯折数次以积累足够像素），再从缺口离开前往下一个框，最终在网格另一边缘终止。路径使用红(2)、蓝(1)、绿(3) 三种颜色的像素。路径有恰好两个端点，无分支。生成约束：路径在每个框内的段至少有 5 个像素；在不同框内路径段的颜色分布不同（如框 A 内红多蓝少，框 B 内蓝多绿少），确保反转后各框内多数色会发生至少一次变化。

**规则**：
1. 找到路径的两个端点（仅有一个 4-连通路径邻居的非黑像素）。从其中一个端点开始，沿 4-连通方向遍历整条路径至另一端点，记录像素颜色序列 S = [s_1, s_2, ..., s_n]。选择起始端点的规则：优先选行号更小的端点；若行号相同，选列号更小的。
2. 将颜色序列 S 反转为 S' = [s_n, s_{n-1}, ..., s_1]，并将反转后的颜色写回路径的原位置（第 i 个路径像素的颜色变为 s'_i）。路径几何形状不变。
3. 对每个轮廓框，找出其封闭内部区域中路径像素的颜色（使用反转后的颜色）。统计该段路径中出现最多的颜色作为该区域的填充色。若出现平局，选路径遍历方向上最先出现的颜色。
4. 用步骤 3 确定的颜色洪泛填充每个轮廓框的封闭内部（路径像素位置也被填充色覆盖）。轮廓框边界和框外路径段全部擦除为黑(0)。轮廓框边界保留原色。

**关键洞察**：反转路径色序相当于将路径前端的颜色浓度搬到后端——如果框 A 位于路径前端且原本以红为主，反转后红色被搬到路径后端的框 C 中，导致框 A 和框 C 的填充色互换。需要对比多个示例才能区分"直接用路径主色填充"和"反转后用路径主色填充"。
