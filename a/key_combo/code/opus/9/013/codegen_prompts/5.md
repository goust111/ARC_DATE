## 新题 5：印章覆盖配合色互换筛选唯一模板

**组合逻辑**：[印章覆盖(stamp_overlay)] + [颜色互换(color_swap)] + [提取(extract) / 去重筛选(uniqueness_filter)]。创新点：印章覆盖创造了多个副本，色互换使副本与原件产生系统性差异，去重筛选在"原件 vs. 互换副本"的混合集中找出唯一不同者。三个操作链式紧耦合：没有印章就没有副本集，没有色互换副本与原件无法区分，没有去重筛选无法确定输出。

**来源原语**：印章覆盖、多色模板、纯色矩形、尺寸匹配、同尺寸替换 (e76a88a6)；颜色互换、前景对象、对象内双色配对、同对象内互换 (45737921)；提取、去重筛选、带框精灵体、图案仅出现一次、异常值选择 (aee291af)

**依赖链**：印章覆盖将模板复制到所有灰色目标区域 → 色互换对所有副本（不含原件）执行双色互换 → 此时网格上存在 1 个原件和 N 个互换副本。同时还存在 1 个预设的"干扰矩形"，它要么与原件相同、要么与副本相同。去重筛选在所有矩形（原件 + 副本 + 干扰矩形）中找到图案仅出现一次的那个，裁剪输出。

在印章覆盖产生的多个副本上执行色互换使副本与原件系统性不同，然后从包含原件、副本和干扰项的混合集中提取唯一图案。

**输入结构**：约 18x18 的黑(0)背景网格。一个多色模板矩形（约 3x3 到 4x4），包含恰好两种非黑颜色（如红(2)和蓝(1)），形成某种不对称图案（互换后图案不同于原件）。2~3 个灰(5)纯色矩形，尺寸与模板相同，散布在网格中。另有 1 个非灰的预着色矩形，同样尺寸，其图案要么与模板完全相同（两色排布一致），要么与模板的两色互换版完全相同。所有矩形互不重叠，与模板不重叠。生成约束：模板图案在两色互换后必须产生不同图案（即图案不是两色对称的）；预着色矩形的图案使得最终集合中恰好有一个图案只出现一次。

**规则**：
1. 找到多色模板（网格中唯一一个包含恰好两种非黑、非灰颜色且完全填满的矩形区域）。记录其两种颜色 A 和 B 以及图案。
2. 将模板图案复制到每个灰(5)矩形区域（印章覆盖），替换灰色像素。
3. 对每个通过印章覆盖创建的副本（不包括原始模板位置），在其内部将颜色 A 和 B 互换（A→B, B→A）。
4. 现在网格上有：原始模板（颜色 A/B）、若干互换副本（颜色 B/A）、一个预着色矩形（其图案为 A/B 或 B/A）。统计每种图案出现的次数（忽略位置，只比较像素图案）。
5. 提取出现恰好一次的图案，裁剪为输出。若原始模板 + 预着色矩形图案相同，则唯一的是互换副本中的某一个（但所有互换副本图案相同，所以实际上唯一的是原件那个图案，因为只有 1 个原件 vs. 多个副本+1 个预着色=都是互换版）；若预着色矩形与互换副本相同，则所有副本+预着色都是互换版，原件是唯一的。反之亦然。输出该唯一图案。

**关键洞察**：印章覆盖和色互换共同制造了两个阵营（原件阵营 vs. 互换阵营），预着色矩形的阵营归属决定了哪个阵营是少数派。需要对比多个示例才能发现"副本被互换"这一隐藏步骤——仅看一个示例可能误以为是简单的异常值检测。

## 实现要求

1. `main(grid)` 必须实现新题描述中的确定性转换规则，不能只识别 `generate_input()` 的固定模板。禁止不同的input网格输出相同的output网格。
2. `generate_input()` 必须随机生成多样样例，不能固定死。随机维度应覆盖：网格大小、对象数量、位置、颜色、方向、形状参数或关键分支。注意若描述中存在若干，需实现而不是只有单个，包括object或者对应关系等等。且若涉及到最短路径，则输入网格中必涉及到多条路径，对选择造成干扰。
3. 生成器必须保证输入满足 `main()` 的隐式假设：对象不重叠、不越界、特殊标记唯一或可区分、匹配关系无歧义、关键分支出现概率相同。
4. 禁止把 ARC 颜色 id 、亮度、拼写等当作人类不可见的数值语义参与排序、大小比较或隐藏映射。颜色变化必须有可见结构线索。注意颜色亮度、拼写等也是不可见信息，若描述中出现违规的颜色id或者亮度，可自行使用少量的固定颜色替代，但注意生成时要在三个以内输入输出网格中对所有变换100%覆盖度。
5. 输出样例要视觉清晰，人类必须能从输入输出对中肉眼辨认出规律。具体要求：避免对象粘连、覆盖关系混乱、同一像素多重语义；不同逻辑步骤产生的结果不要大面积层叠在一起导致无法分辨哪个颜色属于哪个步骤；输入中各元素之间保持足够间距，输出中新增的标记/填充/路径等应与背景和已有元素在颜色上有明显区分；若规则涉及多层叠加，生成时控制对象密度和尺寸，确保叠加区域只占少数像素而非铺满整个网格。
6. 若规则有多个分支，生成器不能长期固定成一个分支；应让分支在随机样例中合理出现。分支概率不必平均——难以发现的隐蔽分支（如少数情况下才触发的特殊规则）应适当提高出现概率，确保在 3 个训练示例中至少出现一次，否则求解者无法归纳该规则。对于颜色映射类规则，确保 2 个左右的示例即可覆盖所有映射关系（每种颜色→颜色的映射至少在某个示例中出现过）。
