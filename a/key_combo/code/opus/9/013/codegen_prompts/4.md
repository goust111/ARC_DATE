## 新题 4：嵌套框颜色继承重组标记分组与排序输出

**组合逻辑**：[重涂色(recolor, 最外层继承)] + [计数(counting)] + [排序(sorting)]。创新点：颜色继承不是视觉美化，而是通过将嵌套内框颜色统一为最外层框色，重新定义了标记像素的分组归属——原本分散在不同嵌套层级的标记被合并为同一组，改变了计数和排序结果。

**来源原语**：重涂色、矩形边框、严格包含、最外层颜色继承 (7d1f7ee8)；计数、标记像素、包含、按计数升序排列、标记数决定行长 (d4c90558)；排序、面积比较 (694f12f3)

**依赖链**：颜色继承将内层框的颜色统一为外层框色 → 标记像素原本在颜色不同的框内，继承后同属一个颜色组 → 计数基于重涂后的颜色分组，而非原始框色 → 排序基于新的分组计数。删除颜色继承步骤，分组方式改变，计数和排序结果全部不同。

先对嵌套矩形框执行最外层颜色继承使同一嵌套树的框统一颜色，再按统一后的颜色对框内标记进行分组计数和升序排序，输出计数表。

**输入结构**：约 18x18 的黑(0)背景网格。2~3 组相互独立的嵌套矩形边框结构。每组包含 1~2 层嵌套（即一个外框包含 0~1 个内框），各框用不同颜色（如红(2)、蓝(1)、绿(3)、品红(6)）。内框严格位于外框内部，边框宽度均为 1 像素。各个嵌套组之间不重叠、不接触。每个矩形框（包括最内层框）内部散布若干灰(5)标记像素（1~5 个），不在任何边框像素上。生成约束：至少有一组嵌套包含内框（使得颜色继承改变至少一些标记的归属组）；不同最外层框的灰标记总数（含其嵌套子框内标记）互不相同。

**规则**：
1. 识别所有矩形边框及其嵌套关系。找到每个最外层框（不被任何其他框严格包含的框）。
2. 对每个最外层框，将其内部所有嵌套框的边框像素重涂为该最外层框的颜色。最外层框自身颜色不变。背景和灰(5)标记不受影响。
3. 重涂完成后，按最外层框的颜色对标记像素进行分组：位于某最外层框的边界框(bounding box)内部（含嵌套层）的所有灰(5)标记归为一组，该组颜色为最外层框的颜色。
4. 对各组按标记数升序排序。标记数相同时，按最外层框的边界框左上角位置排序（先比较行号，行号相同比较列号，靠左上的排前面）。
5. 输出一个新网格：每组一行，行内用该组颜色重复填充该组标记数个像素，右侧用黑(0)填充至最大标记数。行从上到下按排序顺序排列。输出网格宽度等于最大标记数，高度等于组数。

**关键洞察**：颜色继承的真正作用是合并分组——一个蓝(1)外框内嵌套的绿(3)内框中的标记，在继承后归入蓝(1)组而非绿(3)组。如果不执行继承而直接按框色分组，结果会完全不同。需要对比包含嵌套和不含嵌套的示例才能确认这一规则。
