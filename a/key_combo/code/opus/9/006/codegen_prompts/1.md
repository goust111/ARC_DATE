## 新题 1：视线争夺与奇偶仲裁

**组合逻辑**：[射线投射](创新：从单侧可见性判断改为双源四方向可见性分区) + [重涂色](已有) + [奇偶性选色](创新：从棋盘运动方向选择器改为双源领地争夺的仲裁机制)

**来源原语**：射线投射/ray_cast(参考题 3d588dc9), 重涂色/recolor(参考题 3d588dc9 等), 奇偶性选色/parity_selects_color(参考题 5e6bbc0b), 种子区域/seed_region(参考题 800d221b)

**依赖链**：射线投射从两个种子区域出发，为每个背景像素建立可见性归属——这是重涂色的前提。但当两个种子的可见区域在空间上重叠时，可见性判断无法唯一指定颜色，此时奇偶性规则作为仲裁层介入。奇偶性规则本身不决定哪些像素需要仲裁——这完全由射线投射的空间结果决定。三层逻辑缺一不可。

通过射线投射划分两个种子的可见性领地，将可见区域涂为对应种子颜色；对双方均可见的争夺像素，以棋盘奇偶性仲裁归属。

**输入结构**：黑(0)背景网格，约 15x15。网格中有两个单色种子区域，每个种子为 3~5 像素的 4-连通单色图形，两个种子颜色不同，从红(2)、蓝(1)、黄(4)、橙(7)中选取两种。网格中另有若干灰(5)遮挡体（每个遮挡体为 1~3 像素的 4-连通块，共 3~6 个，散布在网格中）。种子区域与遮挡体互不相邻、互不重叠。生成约束：两个种子的可见区域必须存在非空重叠（至少有一个背景像素同时可被两个种子看到），否则奇偶性规则无法体现。

**规则**：
1. 对每个黑(0)背景像素，分别向上、下、左、右四个方向投射射线。射线沿该方向逐格前进，遇到灰(5)遮挡体像素或网格边界时停止（不含遮挡体本身）。若射线在停止前经过了某个种子区域的任意像素，则该背景像素对该种子"可见"。
2. 若该像素仅对种子 A 可见，重涂为种子 A 的颜色。
3. 若该像素仅对种子 B 可见，重涂为种子 B 的颜色。
4. 若该像素同时对两个种子可见（争夺区），计算棋盘奇偶性：(行号 + 列号) 为偶数时涂为种子 A 的颜色，为奇数时涂为种子 B 的颜色。种子 A 定义为边界框左上角行号较小者；行号相同则列号较小者为 A。
5. 若对两个种子均不可见，保持黑(0)。
6. 种子区域和遮挡体像素保持原色不变。

**关键洞察**：奇偶性仲裁仅在双方视线重叠处生效——只看单个示例容易误判为"可见区域直接涂色"，必须对比含有不同重叠分布的多个示例才能发现棋盘交替规则。
