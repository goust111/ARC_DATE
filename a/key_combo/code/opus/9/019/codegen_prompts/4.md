## 新题 4：压缩色带序列为瓦片调色板

**组合逻辑**：[压缩](已有) → [编码映射](创新：压缩产生的颜色序列成为像素放大的调色板) ← [像素放大](创新：每个掩码像素的颜色由序列位置决定)

**来源原语**：压缩(compress) ← 4be741c5；色带(color_band) ← 4be741c5；空间排列顺序(spatial_order) ← 4be741c5；行主色压缩单像素(row_majority_to_pixel) ← 4be741c5；像素放大(pixel_upscale) ← bf45cf4b；控制精灵(control_sprite) ← bf45cf4b；掩码映射(mask_mapping) ← bf45cf4b；编码映射(encoding_map) ← dfadab01

**依赖链**：色带压缩生成有序颜色序列 → 序列中第 k 个颜色赋给控制精灵中第 k 个填充像素（按阅读顺序） → 每个填充像素展开为以其赋色填充的方块。压缩结果是放大操作的输入参数（调色板），而非操作的数据对象——这构成参数级耦合。

将输入中色带区域压缩为颜色序列，用该序列依次为控制精灵的填充像素着色，然后将着色后的精灵像素放大为实心方块拼接输出。

**输入结构**：约 12x20 的黑(0)背景网格，被一条灰(5)垂直分隔线分为左右两半。左半部分被 3~5 种非背景色的水平色带完全覆盖（每种颜色占若干连续行，边界参差不齐但行主色明确）。右半部分包含一个灰(5)边框围成的小区域（约 5x5），内部有一个由白(未使用，此处用栗(9))单色绘制的控制精灵（3~5 个像素，4-连通，形状不规则），其余为黑(0)背景。生成约束：左半色带的颜色种类数恰好等于右半控制精灵中栗(9)填充像素的数量。

**规则**：
1. 识别灰(5)垂直分隔线，将网格分为左区（色带区）和右区（精灵区）。
2. 对左区逐行计算行主色（该行出现次数最多的颜色，忽略灰(5)），按从上到下顺序提取连续行主色变化点，得到有序颜色序列 C = [c1, c2, ..., ck]。
3. 在右区中找到栗(9)像素构成的控制精灵。按阅读顺序（从上到下、从左到右）对精灵的填充像素编号 1, 2, ..., k。
4. 将第 i 个填充像素的颜色从栗(9)替换为 C[i]。
5. 以精灵的边界框为掩码进行像素放大：每个填充像素展开为一个 3x3 的实心方块，颜色为该像素在步骤 4 中被赋予的颜色；每个黑(0)像素展开为 3x3 的黑(0)方块。
6. 输出仅包含展开结果（尺寸为精灵边界框行数 x 3, 精灵边界框列数 x 3），丢弃原始网格的其余部分。

**关键洞察**：色带压缩本身不产生视觉输出——它生成的颜色序列作为隐式参数注入像素放大操作，决定了每个展开方块的颜色。不执行压缩就无法确定放大后的配色。
