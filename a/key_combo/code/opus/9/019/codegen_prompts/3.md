## 新题 3：角落对象掩码展开瓦片到对角

**组合逻辑**：[接触两边缘检测](已有) → [像素放大](创新：掩码来自角落对象而非独立精灵) → [平移到对角](创新：展开结果放置在对角线对侧角落)

**来源原语**：复制(copy) ← bc93ec48；角落对象(corner_object) ← bc93ec48；接触两边缘(touching_two_edges) ← bc93ec48；忽略干扰项(ignore_distractors) ← bc93ec48；像素放大(pixel_upscale) ← bf45cf4b；平铺(tile) ← bf45cf4b；控制精灵(control_sprite) ← bf45cf4b；多色瓦片(polychrome_tile) ← bf45cf4b；掩码映射(mask_mapping) ← bf45cf4b

**依赖链**：角落检测筛选出掩码对象（而非源题中直接给定的精灵）→ 每个角落对象作为二值掩码，其每个填充像素展开为瓦片副本 → 展开结果放置到对角线对侧的角落位置。角落身份同时决定了"用什么掩码"和"放到哪里"。

将每个锚定在网格角落的前景对象当作二值掩码，用中央瓦片模板展开放大，并将结果放置到对角线对侧的角落。

**输入结构**：约 20x20 的黑(0)背景网格。在网格中央偏上区域有一个 3x3 的多色瓦片（由 2~3 种非背景色组成，内部有固定图案）。在网格的 2~4 个角落各有一个单色前景对象（3~6 像素，4-连通），其边界框紧贴该角落的两条边缘。不同角落的对象颜色各异。网格边缘和内部可能散布少量孤立干扰像素（不接触任何角落的两条边缘）。生成约束：每个角落对象的边界框不超过 4x4，且展开后的结果（对象边界框高 x 瓦片高, 对象边界框宽 x 瓦片宽）不超过对角角落的可用空间。存在角落对象的角落恰好成对角分布（即若左上有则右下也有，若右上有则左下也有），保证对角放置不冲突。

**规则**：
1. 识别中央区域的 3x3 多色瓦片（唯一的多色 8-连通分量，与任何网格边缘距离 >= 3）。
2. 对每个前景 4-连通分量，判断其边界框是否同时接触网格的两条相邻边缘（即锚定在某个角落）。只有锚定在角落的对象参与后续步骤；其余为干扰项，保留不动。
3. 对每个角落对象，将其边界框内的像素视为二值掩码（非黑 = 1，黑 = 0）。
4. 按掩码展开：掩码中值为 1 的位置放置一份完整的 3x3 瓦片副本，值为 0 的位置放置 3x3 的黑(0)块。展开结果尺寸为（边界框行数 x 3）行 x（边界框列数 x 3）列。
5. 确定对角角落：左上 ↔ 右下，右上 ↔ 左下。将展开结果的边界框对齐到对角角落（例如左上角落对象的展开结果对齐到右下角落，使展开结果的右下像素与网格的右下像素重合）。
6. 展开结果覆盖目标区域的已有像素（包括该角落原有的对象像素）。原角落的对象像素不擦除（保留在原位）。中央瓦片在输出中移除（替换为黑(0)）。

**关键洞察**：角落检测既决定了哪个对象充当掩码（来自源题 bc93ec48 的筛选逻辑），又决定了展开结果的放置位置（对角映射），同一属性驱动两个不同决策——这种一属性双用途的结构在源题中不存在。
