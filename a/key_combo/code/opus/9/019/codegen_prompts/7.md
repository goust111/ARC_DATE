## 新题 7：归一化圆角精灵后按内部密度排序堆叠

**组合逻辑**：[裁剪+缩放/归一化](已有) → [计数](创新：对归一化后的固定尺寸内部计数) → [排序+堆叠](已有：按密度而非类型排列)

**来源原语**：裁剪(crop) ← db118e2a；缩放(resize) ← db118e2a；圆角边框(rounded_frame) ← db118e2a；内部图案(inner_pattern) ← db118e2a；归一化到固定尺寸(normalize_size) ← db118e2a；计数(counting) ← 29623171/358ba94e；排序(sort) ← 2ba387bc；堆叠(stack) ← 2ba387bc

**依赖链**：先将不同尺寸的圆角精灵归一化到统一 5x5（3x3 内部），然后在归一化后的 3x3 内部统计非背景像素数量，最后按该数量从多到少排序并垂直堆叠。归一化是为了让计数可比——原始尺寸不同的精灵直接比较内部像素数无意义。

将散布的不同尺寸圆角边框精灵统一缩放到 5x5，统计每个精灵归一化后 3x3 内部的前景像素数，按此数量从多到少垂直堆叠输出。

**输入结构**：约 20x20 的黑(0)背景网格。包含 4~6 个大小不同的圆角矩形边框精灵，互不重叠。每个精灵由同一种非背景色的边框构成（四角为黑(0)，其余外边界为边框色），尺寸在 5x5 到 9x9 之间变化（均为奇数边长），内部包含若干非背景色像素形成的图案（内部颜色与边框颜色相同或不同均可）。不同精灵的边框颜色各异。生成约束：每个精灵归一化到 5x5 后，其 3x3 内部的非背景像素数量互不相同（无并列），取值范围为 1~9。

**规则**：
1. 识别所有圆角矩形边框精灵：外边界上四角为黑(0)，其余边界像素为同一非背景色的矩形区域。
2. 对每个精灵执行归一化：
   a. 裁剪出精灵的边界框。
   b. 提取内部图案（去除外边界一圈后的区域）。
   c. 将内部图案的边界框居中放入 3x3 区域（若图案边界框小于 3x3，居中填充；若恰好 3x3，直接使用）。
   d. 在 3x3 内容外加一圈圆角边框（四角黑(0)，上下左右边界用原边框色），得到 5x5 归一化图标。归一化图标的边框色保持为原精灵的边框色。
3. 统计每个 5x5 图标中 3x3 内部区域的非黑(0)像素数量。
4. 按内部非黑像素数量从大到小排列（最密的在最上方）。
5. 将排序后的 5x5 图标垂直堆叠，图标之间无间隔，输出网格宽度为 5，高度为图标数 x 5。

**关键洞察**：不同精灵原始尺寸各异，直接比较内部像素数量没有意义——必须先归一化到统一尺寸，使计数在同一基准下可比；归一化步骤为排序提供了可比较的度量，而不只是格式转换。
