## 新题 4：柱高算术决定周期瓦片修复的相位偏移

**组合逻辑**：[计数·高度算术](已有) + [周期推断·补全](创新：修复时使用相位偏移后的瓦片) — 两个独立推理源（算术与周期推断）在修复步骤汇聚，缺任一则结果不确定

**来源原语**：计数(37ce87bb)、填充(37ce87bb)、柱状条(37ce87bb)、颜色编码正负(37ce87bb)、高度加减运算(37ce87bb)、补全(29ec7d0e)、周期瓦片(29ec7d0e)、缺失单元(29ec7d0e)、最小周期推断填补(29ec7d0e)、周期相位对应(c663677b)

**依赖链**：（分支 A）统计青(8)柱高之和减红(2)柱高之和得到偏移量 S → （分支 B）从含缺损的网格推断最小周期瓦片 T → 将 T 循环下移 S 行得到 T' → 用 T' 按相位填充所有缺损单元。删除算术则不知偏移量；删除周期推断则无基础瓦片；删除相位偏移则修复结果与标准修复不同。

输入分为两个区域：左边是带有黑色缺损的周期网格，右边是柱状算术区；输出仅为左边区域的修复结果，但修复使用的瓦片经过了由算术结果决定的行偏移。

**输入结构**：约 12x20 的网格。左侧区域约 12x12，背景色黑(0)，包含一个行周期 p、列周期 q 的周期色彩表（p, q 约 2~4），使用绿(3)、黄(4)、品红(6)、橙(7) 中的 2~3 种颜色填充。其中若干单元格被替换为黑(0)（缺损），每个周期相位至少在某个非缺损位置可见。右侧区域约 12x7，与左侧被 1 列灰(5) 分隔线隔开。右侧底部对齐放置若干 1 像素宽的垂直柱状条：青(8) 柱为正操作数，红(2) 柱为负操作数，柱间至少间隔 1 列背景。生成约束：算术结果 S = sum(青柱高) - sum(红柱高) 满足 0 < S < p（即结果为正且小于行周期，保证偏移有意义）。

**规则**：
1. 在右侧区域，计算所有青(8) 柱的高度之和减去所有红(2) 柱的高度之和，得到整数 S。
2. 在左侧区域，推断最小行周期 p 和列周期 q：找到最小的 (p, q) 使得所有非黑(0) 单元格在 (row mod p, col mod q) 相位上一致，构建 p x q 的基础瓦片 T。
3. 将瓦片 T 循环下移 S 行：新瓦片 T' 满足 T'[r][c] = T[(r - S) mod p][c]。
4. 用 T' 修复左侧区域：每个单元格 (i, j) 的输出颜色 = T'[i mod p][j mod q]。
5. 输出仅包含左侧区域（不含分隔线和右侧区域），大小与左侧区域相同。

**关键洞察**：标准周期修复只需推断瓦片并按相位填充，但此题中修复使用的瓦片被偏移了——偏移量来自完全独立的算术计算，两条推理线在最终修复步骤交汇，缺一不可。
