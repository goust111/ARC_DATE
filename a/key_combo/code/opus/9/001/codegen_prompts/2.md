## 新题 2：绕障碍重路由的空心矩形走廊网络

**组合逻辑**：[连线·最小生成树](创新：边权包含绕障代价) + [绕障重绘](创新：作用对象从线段变为走廊) + [擦除](已有) — 障碍改变有效边权，MST 选边与走廊路径相互约束

**来源原语**：连线(b9630600)、擦除(b9630600)、空心矩形(b9630600)、走廊(b9630600)、最短可见间距(b9630600)、最小生成树连接(b9630600)、重叠决定走廊宽度(b9630600)、绕障重绘(88bcf3b4)、障碍精灵体(88bcf3b4)、边界贴合(88bcf3b4)、像素数守恒(88bcf3b4)

**依赖链**：候选间距的有效长度 = 直线距离 + 绕障附加长度 → 以有效长度为权重构建 MST → 被选中的边按绕障路径绘制走廊 → 走廊宽度由框内部重叠范围决定。删除绕障则有效长度错误、MST 可能选错边；删除 MST 则不知道连哪些框；删除走廊宽度规则则输出形状不确定。

输入包含若干空心矩形框和障碍精灵体；输出是将所有框通过最短有效走廊网络连接起来，走廊在遇到障碍时沿障碍边界绕行。

**输入结构**：约 25x25 的网格，背景色黑(0)。网格中包含 3~5 个蓝(1) 空心矩形框（壁厚 1 像素，内部为黑(0)背景，边界框尺寸各异，约 4x4~7x7），互不接触且互不重叠。在部分相邻框对之间的空隙中，放置 1~3 个红(2) 障碍精灵体（4-连通不规则形状，3~6 像素，不接触任何框壁）。每个障碍精灵体最多阻挡一个候选间距。候选间距定义为：两框之间沿水平或垂直方向、其内部行/列范围有重叠、且路径上仅经过背景和障碍像素（不经过其他框壁）的直线通道。生成约束：所有框通过候选间距构成连通图；每个候选间距上最多有一个障碍。

**规则**：
1. 枚举所有候选间距。对每个候选间距，若路径上无障碍，有效长度 = 两框壁之间的像素距离。若路径上有障碍，有效长度 = 直线距离 + 绕行障碍边界所需的额外像素数（绕行方式：走廊到达障碍时选择上/下或左/右中绕行路径较短的一侧，沿障碍外边界贴合行进，直至越过障碍后回到原直线方向）。
2. 以框为节点、有效长度为边权构建最小生成树（若有效长度相同，选择直线距离更短的；仍相同则选涉及更靠左上角框的边）。
3. 对 MST 中每条选中的边，绘制蓝(1) 走廊：走廊宽度 = 两框内部行/列范围重叠的像素数（取重叠范围的两条边界线），走廊沿直线路径前进，遇到障碍时沿障碍外轮廓绕行（贴合像素），绕过后回到直线。绘制走廊时，擦除两框面对走廊方向的壁上、走廊边界线之间的像素（打开通道口）。
4. 障碍精灵体保持红(2) 不变；走廊像素不覆盖障碍像素。

**关键洞察**：障碍不仅改变走廊的几何路径，还改变间距的有效权重，从而可能导致 MST 选择完全不同的连接方案——必须先计算所有绕障代价才能确定网络拓扑。
