## 新题 7：压缩空间路由的跨尺度还原

**组合逻辑**：[压缩](创新：压缩将瓦片网格简化为单像素表示以暴露路由拓扑) + [连线](创新：在压缩空间中执行先横后纵路由) + [像素放大](创新：将压缩空间的路由结果还原为瓦片尺度的粗线段)

**来源原语**：压缩/compress（5ad4f10b）、连线/line_drawing（0e671a1a）、像素放大/pixel_upscale（6aa20dc0）、瓦片/tile（5ad4f10b）、网格分块/grid_partitioning（5ad4f10b）、标记像素/marker_pixel（5ad4f10b, 0e671a1a）、经由中间点路由/routed_via_waypoint（0e671a1a）、先横后纵路由/horizontal_then_vertical（0e671a1a）、填充位出标记色/filled_gets_marker（5ad4f10b）

**依赖链**：瓦片网格的填充状态被压缩为 NxN 摘要 → 标记像素在压缩空间中的位置确定路由端点 → 先横后纵路由连接端点 → 压缩空间的路由结果被像素放大还原为瓦片尺度。压缩阶段决定了路由的拓扑结构，路由阶段在压缩空间完成以避免处理瓦片内部细节，放大阶段将结果映射回原始尺度。

将瓦片网格压缩为每瓦片一像素的摘要，在摘要中按读序连接标记像素进行先横后纵路由，再将摘要放大回原始瓦片尺度，路由线段变为整个瓦片宽度的粗通道。

**输入结构**：
- 网格约 18x18，背景黑(0)。
- 网格被均匀划分为 3x3 的瓦片阵列，每个瓦片为 6x6 像素。
- 每个瓦片要么整体填充为某种单色（从蓝(1)、红(2)、绿(3)中取用），要么整体为黑(0)背景。
- 其中 2~3 个已填充的瓦片各包含一个单像素标记点，颜色为黄(4)，位于瓦片中心位置（第 3 行第 3 列，0-索引下为 (2,2)）。
- 生成约束：标记点所在的瓦片一定是已填充瓦片；不同示例中瓦片的填充颜色分布和标记点位置不同；标记点数量至少 2 个。

**规则**：
1. 将 3x3 瓦片阵列压缩为 3x3 摘要网格：已填充瓦片的像素取其填充色，含标记点的瓦片像素取标记色黄(4)，纯背景瓦片取黑(0)。
2. 在摘要网格中找到所有黄(4)像素，按读序排列：从左到右、从上到下，编号为 W1, W2, ..., Wk。
3. 对每对连续的标记 (Wi, Wi+1)，绘制灰(5)正交路径：从 Wi 出发先水平移动到 Wi+1 所在列，再垂直移动到 Wi+1 所在行。仅覆盖黑(0)背景像素；非黑像素不被覆盖，路径在其位置中断但继续在另一侧延伸。黄(4)标记像素也不被覆盖。
4. 将完成路由的 3x3 摘要网格放大回 18x18：每个摘要像素扩展为 6x6 的同色块。
5. 在放大后的网格中，原始标记点（黄(4)）仅保留为瓦片中心的单像素；其所在瓦片的其余像素恢复为该瓦片的原始填充色。

**关键洞察**：路由在压缩空间中执行，单像素宽的路径在还原后变成整个瓦片宽度的粗通道。求解者必须识别出压缩/还原的尺度对偶关系——在压缩空间中看似简单的一步移动，在原始尺度上是一个完整瓦片大小的色块。
