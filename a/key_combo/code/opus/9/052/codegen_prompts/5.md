## 新题 5：射线编码的双重语义平移

**组合逻辑**：[射线延伸](创新：射线同时编码目的地位置和传播模板) + [平移](创新：平移距离由射线长度决定而非边界框) + [变换传播](创新：模板来源的射线在平移后沿二面体对应传播到所有精灵体)

**来源原语**：射线延伸/ray_extension（64efde09）、平移/translate（54dc2872）、擦除/erase（f5c89df1）、矩形精灵体/rectangular_sprite（64efde09）、控制标记/control_marker（64efde09）、模板单元映射/template_cell_mapping（64efde09）、颜色匹配配对/color_match_pairing（271d71e2, 54dc2872）、锚点像素/anchor_pixel（f5c89df1）、二面体变换对应/dihedral_correspondence（64efde09）

**依赖链**：模板精灵体上的射线颜色与其他精灵体上的嵌入像素颜色配对 → 射线长度决定平移步数 → 精灵体平移到射线尖端位置 → 平移后需判定每个精灵体相对于模板的二面体变换 → 根据模板射线的模板单元位置和方向，在每个变换后的精灵体上传播射线。前半段（配对+平移）和后半段（二面体+传播）通过射线的双重语义耦合。

模板精灵体上的彩色射线既标识目标精灵体（通过颜色配对），又编码了射线传播的模板单元位置；目标精灵体平移到射线尖端后，根据自身的二面体朝向从对应单元位置发射传播射线。

**输入结构**：
- 网格约 18x18，背景黑(0)。
- 3~4 个小型密实矩形精灵体（约 2x3 或 3x2 像素），每个由单一体色蓝(1)构成。
- 其中一个精灵体为"模板"：其长边外侧有 2~3 个单像素控制标记，沿垂直于长边的方向向外延伸形成短射线（长度 2~5 格），每条射线颜色各不相同（从红(2)、绿(3)、黄(4)、橙(7)中取用）。射线像素覆盖的是黑(0)背景格。
- 其他精灵体（非模板）各有一个嵌入像素，颜色与某条射线颜色匹配。嵌入像素位于精灵体的一个体色像素位置上（替代蓝(1)）。
- 非模板精灵体的形状与模板相同但可能处于不同的二面体朝向（0/90/180/270 度旋转，可能含水平翻转）。
- 生成约束：每条射线颜色恰好对应一个非模板精灵体的嵌入像素颜色；射线尖端位置与对应精灵体当前位置不同；平移后精灵体不会超出网格边界且不会彼此重叠。

**规则**：
1. 识别模板精灵体：拥有外侧射线的那个（其 4-邻域外存在沿同一直线延伸的同色像素序列）。
2. 对模板的每条射线，记录：(a) 射线起始于模板长边的第几个单元（模板单元位置），(b) 射线颜色，(c) 射线方向（相对于模板的朝向），(d) 射线尖端坐标。
3. 颜色配对：将每个非模板精灵体的嵌入像素颜色与射线颜色匹配。
4. 平移每个非模板精灵体，使其嵌入像素落在对应射线的尖端像素位置上。擦除精灵体的旧位置（恢复为黑(0)）。
5. 平移后，确定每个非模板精灵体相对于模板的二面体变换（通过比较体色像素的相对位置排列）。
6. 射线传播：对模板上的每条射线（模板单元位置 P，方向 D），在每个非模板精灵体上找到位置 P 经二面体变换后对应的单元，从该单元沿 D 经同一二面体变换后的方向向外延伸，绘制灰(5)像素，直到遇到非黑(0)像素或网格边缘（不含终点）。
7. 模板精灵体及其原始射线保持不变。

**关键洞察**：射线具有双重语义——其颜色和长度编码"把谁移到哪"，其模板单元位置编码"移到后从哪里发射新射线"。求解者必须同时解读这两层信息；仅理解配对平移而忽略射线传播，或仅理解传播而忽略平移目的地，都无法完成题目。
