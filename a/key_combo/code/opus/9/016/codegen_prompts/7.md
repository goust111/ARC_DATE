## 新题 7：线路传输模板图案并在端点重涂色印章

**组合逻辑**：[传输/transmit + 端点配对/endpoint_pairing](创新：传输的对象是模板图案而非令牌形状) + [印章放置/stamp + 颜色替换/color_substitution] + [擦除/erase]

**来源原语**：传输/transmit、线路网络/wire_network、端点配对/endpoint_pairing（来自 a47bf94d）；印章放置/stamp、模板图案/stencil_pattern、规则示例/rule_example、颜色替换/color_substitution、示例定义规则/example_defines_rule、擦除/erase（来自 abc82100）

**依赖链**：线路网络的拓扑决定模板图案的传输路径（哪个端点的图案传到哪里），端点处的本地颜色像素决定重涂色映射（青色图案被替换为什么颜色）。传输目的地由线路决定，印章颜色由目的地的本地上下文决定——两个信息流在"将图案印章到远端"这一步汇聚。

沿线路网络将源端的青色模板图案传输到远端，在远端以远端本地像素的颜色替代青色进行印章，擦除所有源端组件。

**输入结构**：约 20x20 的黑(0)背景网格。包含 2~3 条独立的线路网络，每条线路由灰(5)像素构成单像素宽的 4-连通路径（可弯折），连接两个端点。在每条线路的一个端点（源端）旁，有一个 3x3~4x4 的青(8)模板图案（非对称的连通图形，不占据全部方格，与端点相邻但不重叠线路）。在青(8)图案与线路端点之间有一个单独的彩色像素（取自蓝(1)、红(2)、绿(3)、黄(4)），这是源端的颜色标记。在线路的另一端点（远端）旁，有另一个单独的彩色像素作为远端的颜色标记。生成约束：各线路互不交叉；每条线路恰好一端有青色模板图案；源端与远端的颜色标记颜色不同；青色模板图案在传输到远端后不超出网格边界。

**规则**：
1. 识别每条灰(5)线路网络及其两个端点。
2. 确定线路的源端：有青(8)模板图案相邻的端点为源端，另一端为远端。
3. 将源端的青(8)模板图案沿线路传输到远端：以源端端点为参考锚点，以远端端点为放置锚点，保持图案相对于锚点的偏移不变，将图案印章到远端位置。
4. 印章时，将青(8)替换为远端本地颜色标记像素的颜色（颜色替换）。
5. 擦除所有源端的组件：源端的青(8)模板图案、源端的颜色标记像素。保留远端的颜色标记像素。
6. 灰(5)线路网络保持不变。
7. 若印章后的图案与已有的非黑像素重叠，印章像素覆盖黑(0)背景但不覆盖灰(5)线路和已有的彩色标记像素。

**关键洞察**：线路的作用不是传输颜色信息或变换形状，而是传输空间图案本身——图案从一端被"搬运"到另一端，同时在新位置获得新颜色。这将"路由"和"模板印章"两种原本无关的机制紧耦合：路由决定去哪里，本地颜色决定印什么色，模板决定印什么形状。

    sides (T,R,B,L): cycle values CW by 1 step (T->R->B->L->T)
    background unchanged

generation_strategy:
  approach: direct input construction (task is simple transform-in-place)
  steps:
    1. Pick grid size (7x7 [observed], or allow 6-10 for variety) and background color
    2. Choose ring count 1-2; place each ring's top-left corner ensuring 3x3 fits in grid and no two rings' 3x3 bboxes overlap or are 4-adjacent (gap >= 1 on at least one axis)
    3. For each ring, fill 8 surround cells with random non-background colors (allow repeats); set center to background
    4. Fill remaining cells with background
    5. Compute output by applying the corner-CCW / side-CW rotation to each ring
