## 新题 2：最近边引力堆叠与边色重涂

**组合逻辑**：[最近边归属/nearest_side_assignment](创新：决定引力方向而非仅决定颜色) → [滑动/slide + 碰撞停止/collision_stop + 近墙优先结算/nearest_first_settling] → [重涂色/recolor] + [裁剪/crop]

**来源原语**：最近边归属/nearest_side_assignment、空心矩形/rectangular_frame、重涂色/recolor、裁剪/crop（来自 9aec4887）；滑动/slide、重力下落/gravity_drop、碰撞停止/collision_stop、近墙优先结算/nearest_first_settling（来自 6ad5bdfd）；边框/frame（来自 d687bc17）

**依赖链**：每个物体的最近边归属同时决定两件事——引力方向和最终颜色。引力方向又影响结算顺序（近墙优先），而结算顺序影响碰撞位置，碰撞位置反过来影响后续物体的可落位空间。这形成了一个"归属→方向→结算序→碰撞位→最终布局→重涂色"的紧耦合链。

将框内散布的小图形按各自最近边的方向滑动堆叠，然后用对应边的颜色重涂每个图形，输出裁剪后的紧凑框。

**输入结构**：约 20x20 的黑(0)背景网格。中央区域有一个由四条同长度色条构成的矩形框（无角像素），四条边分别为蓝(1)、红(2)、绿(3)、黄(4)——上、下、左、右各一色。框内部散布 4~7 个灰(5)的 4-连通单色小图形，每个图形 3~5 像素，形状各异（不限于特定几何形状），图形之间互不相邻。生成约束：每个图形的边界框中心到四条边的距离中，最小距离唯一（无并列最近边）；框的内部尺寸至少 10x10 以保证图形有足够散布空间；各图形滑动路径上不存在循环依赖（即不存在 A 需要等 B 先结算但 B 又需要等 A 的情况）。

**规则**：
1. 识别矩形框及其四条边的颜色。
2. 对每个灰(5)图形，计算其边界框中心到框的上、下、左、右内侧边缘的曼哈顿距离，选距离最短的边作为该图形的"吸引边"。
3. 按每个图形到其吸引边的距离从小到大排序（最近的先结算）。按此顺序，将每个图形作为刚体沿吸引边方向滑动，直到图形的前沿碰到框的该边内壁或碰到已结算的其他图形为止。
4. 所有图形结算后，将每个图形重涂为其吸引边的颜色。
5. 输出裁剪为框的边界框（含框边本身）。

**关键洞察**：与单一方向的引力不同，每个物体有独立的引力方向，由其空间位置（最近边）决定——同一网格中的物体可能朝四个不同方向滑动。需要对比多个示例才能确认"吸引方向=最近边方向"而非某种固定方向。
