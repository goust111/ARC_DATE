## 新题 5：引力结算后凸耳触发轴向镜像

**组合逻辑**：[墙面确定方向/wall_determines_direction + 滑动/slide + 碰撞停止/collision_stop] → [凸耳决定镜像轴/tab_determines_axis + 镜像/mirror](创新：镜像发生在结算后的位置而非原始位置) + [颜色按方位定/color_by_orient]

**来源原语**：滑动/slide、重力下落/gravity_drop、边墙/edge_wall、墙面确定方向/wall_determines_direction、碰撞停止/collision_stop、近墙优先结算/nearest_first_settling（来自 6ad5bdfd）；镜像/mirror、凸耳/tab、轮廓/outline、对侧放置/opposite_place、凸耳决定镜像轴/tab_determines_axis、颜色按方位定/color_by_orient、擦除/erase（来自 dc2e9a9d）

**依赖链**：引力方向由边墙决定，结算顺序影响各物体最终停靠位置。镜像操作在结算后执行，镜像轴由凸耳决定，镜像副本的放置位置依赖结算后的边界框（不是原始位置的边界框）。因此引力结算的结果实质性地改变了镜像副本的空间位置。

带凸耳的轮廓物体在引力作用下滑向边墙并堆叠，结算完成后每个物体根据凸耳方位在结算位置的对侧生成彩色镜像副本。

**输入结构**：约 18x18 的黑(0)背景网格。一条完整的红(2)单像素厚边墙占据网格的某一条边（上、下、左或右），红(2)不出现在其他位置。网格中散布 2~4 个绿(3)的 4-连通单像素宽轮廓物体，每个物体有一个明确的边界框（约 3x3 到 5x5），边界框的恰好一条边上有一个单像素的绿(3)凸耳（凸耳是边界框某边向外突出的一个像素）。各物体互不相邻，且不与边墙相邻。生成约束：所有物体沿引力方向滑动后不会旋转或变形（纯平移）；各物体的滑动路径互不交叉；结算后的镜像副本不超出网格边界且副本之间互不重叠。

**规则**：
1. 识别边墙所在边，确定引力方向（指向边墙）。
2. 按每个轮廓物体到边墙的距离从小到大排序。依次将每个物体作为刚体沿引力方向滑动，直到前沿接触边墙或已结算物体为止（碰撞停止）。
3. 所有物体结算后，原始位置擦除（变为黑(0)），物体出现在新位置，保持绿(3)。
4. 对每个结算后的物体，找到其凸耳。凸耳在物体边界框的左或右边→水平镜像轴；凸耳在上或下边→垂直镜像轴。
5. 在物体结算后的边界框的凸耳对侧，间隔 1 个像素的位置，放置该物体的镜像副本。副本颜色由镜像轴决定：水平镜像→蓝(1)，垂直镜像→青(8)。
6. 镜像副本仅绘制在黑(0)背景上，不覆盖已有的绿(3)物体、红(2)边墙或其他副本。若两个副本冲突（占据同一单元格），保留结算位置离边墙更近的那个物体的副本。

**关键洞察**：镜像操作的空间参照系不是物体的原始位置而是引力结算后的位置——如果忽略引力步骤直接在原位镜像，副本的位置将完全错误。这个两阶段依赖（先运动、后镜像、镜像位置取决于运动结果）需要对比示例中物体的初始和最终位置才能看出。
