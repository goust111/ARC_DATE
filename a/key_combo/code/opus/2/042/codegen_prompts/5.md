## 新题 5：标记色多重角色——选择、镜像触发、位置印章

**组合逻辑**：[裁剪/crop + 标记色最多者选中/max_marker_count_selected](按标记密度选取精灵体) → [镜像/mirror + 特定标记触发镜像/marker_triggers_mirror](创新：标记分布对称性决定是否镜像) → [印章覆盖/stamp + 标记色匹配目标位/marker_color_matches_dest](在孤立标记位置印章)

**来源原语**：裁剪/crop、标记色像素/marker_color_pixel、标记色最多者选中/max_marker_count_selected、形状内色频/color_frequency_within_shape（ae4f1146）；镜像/mirror、特定标记触发镜像/marker_triggers_mirror、标记色匹配目标位/marker_color_matches_dest（3e980e27）；印章覆盖/stamp（3e980e27）

**依赖链**：全局最稀有色被识别为标记色 → 标记色计数决定选中哪个精灵体 → 选中精灵体内标记像素的空间对称性决定是否水平镜像 → 网格中孤立标记像素的位置决定印章放置处。同一"标记"概念在四个不同的结构层次发挥作用，删除任一层次都会导致输出不确定。

选出标记色像素最多的精灵体，根据其标记像素的对称性决定是否镜像，然后将清理后的精灵体印章到所有孤立标记位置。

**输入结构**：
- 网格约 15x15，黑(0)背景。
- 3-4 个实心矩形精灵体（各 4x4 像素），各以一种非背景主色填充（如蓝(1)、绿(3)、黄(4)），不同精灵体主色不同。
- 在每个精灵体内部，部分像素被替换为全局最稀有的前景色——标记色（如红(2)）。不同精灵体含有不同数量的标记色像素（如分别含 1、2、3 个），恰好一个精灵体的标记色像素数量唯一最多。
- 网格其他位置散布 2-3 个孤立的标记色单像素，不与任何精灵体相邻。
- 生成约束：标记色在整个网格中的总像素数（含精灵体内和孤立的）明确少于任何其他非背景色；标记数最多的精灵体内的标记像素要么明确关于精灵体垂直中心轴对称，要么明确不对称。

**规则**：
1. 识别标记色：整个网格中像素总数最少的非背景色。
2. 识别每个精灵体（像素数 > 1 的非背景 4-连通区域，排除孤立单像素标记）。统计每个精灵体内标记色像素的数量。
3. 选中标记色像素数量最多的精灵体。
4. 生成"洁净版"：将选中精灵体内所有标记色像素替换为该精灵体的主色（精灵体内出现次数最多的非标记颜色）。
5. 检查选中精灵体内标记色像素在精灵体局部坐标系下的位置，判断是否关于精灵体垂直中心轴左右对称。若不对称，将洁净版精灵体水平镜像翻转；若对称，保持不变。
6. 将结果精灵体（洁净、可能已镜像）以每个孤立标记色像素为中心进行印章放置。超出网格边界的部分裁去。
7. 擦除所有未被选中的精灵体（替换为背景）。选中精灵体的原始位置也清除（仅保留印章副本）。

**关键洞察**：标记色同时承担四种结构角色——(a) 选择判据（精灵体内的标记计数）、(b) 变换触发器（标记的空间对称性）、(c) 清理对象（被主色替换）、(d) 位置指南（孤立标记决定印章坐标）。理解同一颜色的四重身份是解题的核心。
