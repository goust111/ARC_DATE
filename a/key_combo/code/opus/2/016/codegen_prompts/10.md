## 新题 10：表格颜色摘要展开为同心环

**组合逻辑**：[提取摘要/压缩](从表格封闭单元中读取颜色序列) → [对称补全](创新为将颜色序列映射到同心正方形环层，并从角落编码展开为完整环)

**来源原语**：提取摘要(extract_summary)/压缩(compress)/封闭区域(enclosed_region)/网格表格(grid_table)/包含于(contained_in)/不接触边缘(not_touching_edge) ← ac6f9922；对称补全(symmetry_completion)/同心正方形层(concentric_square_ring)/角落编码(corner_code)/对称展开(symmetric_unfolding)/角落码展开同心(corner_code_unfolds_concentric) ← 9d9215db

**依赖链**：表格封闭单元按行主序排列提供颜色序列 [c1, c2, ..., cN] → 角落编码区域的对角距离层数 = N（验证一致性）→ 第 i 层环使用颜色 ci → 从角落编码几何展开为完整的 N 层同心正方形环 → 表格提供"画什么色"，角落编码提供"画什么形状"

从表格中读取颜色序列，然后用该序列为角落编码定义的同心环模板上色，展开为完整的多层同心正方形环图案。

**输入结构**：约 15x15 的网格，分为两个非重叠区域。区域 A（左侧或上侧，约 5 列宽或 5 行高）：灰(5)背景，内部有 N 个封闭小格子（灰(5)不接触网格边缘的 4-连通区域），排成一列或一行，每个格子约 3x3，内含一个单像素前景色（颜色取自红(2)、蓝(1)、绿(3)、黄(4)、品红(6)等，各不相同）。区域 B（右下部分，约 11x11 的奇数边长正方形区域）：黑(0)背景，在右下角的奇数坐标格点上有若干前景像素，全部为橙(7)色，构成一个角落编码图案——像素分布在从角落起 1, 2, ..., N 条对角线上，每条对角线上有 1 个或多个像素（描述对应环的角和边）。生成约束：N 介于 3 到 5 之间；角落编码的对角距离层数恰好等于区域 A 中的单元格数 N；区域 A 和区域 B 之间用灰(5)分隔线隔开。

**规则**：
1. 在区域 A 中，找到所有不接触网格边缘的 4-连通灰(5)封闭区域，按边界框位置从上到下（或从左到右）排序。从每个封闭区域中提取唯一的非灰前景颜色，得到有序颜色序列 [c1, c2, ..., cN]。
2. 在区域 B 中，读取角落编码：以右下角为原点，计算每个橙(7)像素到该角的切比雪夫距离（奇数坐标格点上的对角层索引 d = max(|row_offset|, |col_offset|) / 2，其中偏移量从角落起算）。确认共有 N 个不同的距离层。
3. 将颜色序列映射到距离层：距离层 1（最靠近角落）→ cN（序列末尾颜色），距离层 2 → c(N-1)，...，距离层 N（最外层）→ c1。即表格第一个颜色对应最外环，最后一个颜色对应最内环。
4. 按 9d9215db 的对称展开规则，将每个橙(7)像素替换为其对应层的颜色，然后对每一层执行四向对称展开：对角位置像素展开为四个角，水平/垂直侧边像素展开为两对相对边。
5. 输出为区域 B 尺寸的完整同心环图案（区域 A 和分隔线不包含在输出中）。

**关键洞察**：输入的两个区域编码了输出的两个正交属性——区域 A（表格）编码颜色，区域 B（角落编码）编码几何形状。任何一个区域单独都不能确定输出：缺少表格则不知道每层涂什么颜色，缺少角落编码则不知道环的几何结构。更隐蔽的是颜色映射方向（c1→最外层而非最内层），必须通过多个示例对比才能确认。
