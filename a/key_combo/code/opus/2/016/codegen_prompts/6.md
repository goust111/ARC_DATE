## 新题 6：引导路径选定旋转角度裁剪面板

**组合逻辑**：[路径追踪](沿引导像素从棋盘格走到目标环形物体) → [旋转](创新为目标环形物体相对面板的方位编码旋转角度) → [裁剪](提取面板内部并旋转输出)

**来源原语**：路径追踪(path_follow)/棋盘格(checkerboard)/环形物体(ring_object)/引导像素(guide_pixel)/路径连接(path_connected)/终点相邻(endpoint_adjacent) ← 9ba4a9aa；旋转(rotate)/整体半周旋转(half_turn_rotation) ← 3c9b0459；裁剪(crop) ← 9ba4a9aa；面板区域(panel_region)/包含于(contained_in) ← c3fa4749

**依赖链**：棋盘格是路径追踪的起点 → 沿引导像素路径到达目标环形物体 → 环形物体位于面板的某个方位（上/右/下/左）→ 方位编码旋转角度（上=0°，右=90°，下=180°，左=270°）→ 裁剪面板内部图案并按该角度顺时针旋转 → 输出为旋转后的裁剪结果

沿引导像素路径从棋盘格到达目标环形物体，再根据该环形物体相对于中央面板的方位决定面板内容的旋转角度，裁剪并旋转输出。

**输入结构**：约 17x17 的黑(0)背景网格。中央有一个约 7x7 的面板区域，由灰(5)边框围成正方形，内部包含一个非对称的多色图案（使用红(2)、蓝(1)、绿(3)等颜色，确保旋转后可区分方向）。面板外有 4 个 3x3 环形物体（中心为黑(0)，8 个边缘像素为同一颜色），分别位于面板的正上方、正右方、正下方、正左方，各自颜色不同（如红(2)、蓝(1)、绿(3)、黄(4)）。一个 3x3 棋盘格（黑白交替，使用橙(7)和黑(0)）位于网格某个角落。从棋盘格的某个相邻像素开始，一条由某种颜色的引导像素组成的路径以两格间隔的水平/垂直步进连接到 4 个环形物体中的某一个。生成约束：引导路径只连接到一个环形物体，路径不经过其他环形物体或面板边框；面板内部图案在 0°、90°、180°、270° 旋转下各不相同。

**规则**：
1. 找到 3x3 棋盘格及其唯一相邻的引导像素。
2. 沿引导像素以两格水平/垂直步进追踪路径，直到路径终点相邻于某个 3x3 环形物体。该环形物体为目标。
3. 判断目标环形物体相对面板中心的方位：若环形物体中心行低于面板中心行（在面板下方），方位 = 下；若在上方，方位 = 上；若中心列在面板右侧，方位 = 右；若在左侧，方位 = 左。
4. 将方位映射为旋转角度：上 = 0°（不旋转），右 = 90°顺时针，下 = 180°，左 = 270°顺时针。
5. 裁剪面板的严格内部（不包含灰(5)边框），将裁剪结果按上述角度顺时针旋转。
6. 输出为旋转后的裁剪图案。

**关键洞察**：引导路径是一个"查询机制"——它不改变任何像素，只是选择目标。但目标的价值不在于自身（环形物体的颜色和形状是无关的），而在于它的空间位置编码了一个变换参数。求解者必须同时理解路径追踪（选择）和方位→旋转映射（参数化变换）这两层逻辑。单个示例可能让求解者误以为输出只是简单裁剪，需要多个示例（旋转角度不同）才能发现旋转规则。
