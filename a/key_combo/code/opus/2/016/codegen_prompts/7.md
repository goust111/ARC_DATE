## 新题 7：矩形自高平移后转折射线标记

**组合逻辑**：[平移](每个矩形上移自身高度) → [射线延伸](创新为从移后矩形的右下角出发，画出转折射线至下一矩形行)

**来源原语**：平移(translate)/实心矩形(solid_rectangle)/无重叠间距(non_overlap_spacing)/移动自身高度(shift_own_height) ← 5521c0d9；射线延伸(ray_extend)/画布边界(canvas_boundary)/行列对齐(row_column_alignment)/转折至下一标记行(turning_path_to_next_marker_row) ← 99fa7670

**依赖链**：每个矩形的高度决定其上移量 → 移后各矩形的底边行位置互不相同（因高度不同）→ 矩形右下角成为射线标记点 → 从每个标记点向右延伸水平射线至右边缘，再沿右边缘向下延伸至下一标记点所在行的上一行 → 射线颜色与对应矩形颜色一致 → 射线间距完全由矩形高度决定

先将每个实心矩形上移其自身高度，再从移后矩形的右下角发射向右转折向下的 L 形射线，射线止于下一个矩形的行。

**输入结构**：约 15x20 的黑(0)背景网格（高大于宽）。包含 3-4 个单色实心矩形，颜色互不相同（如红(2)、蓝(1)、绿(3)、黄(4)），高度各异（2-5 像素），宽度 2-4 像素。每个矩形正上方有等于自身高度的空黑区域（确保上移后不越界）。矩形水平位置各异，垂直排列使得上移后的矩形底边行从上到下递增。生成约束：矩形间垂直间距足够大，确保上移后互不重叠；上移后各矩形的底边行互不相同；所有矩形的右下角列坐标小于网格宽度减 1（确保水平射线至少有 1 格长度）。

**规则**：
1. 对每个矩形，清除其原始位置，将矩形整体上移自身高度个格子（新底边行 = 旧顶边行 - 1）。
2. 上移完成后，找到每个矩形的右下角像素，作为射线标记点。
3. 按标记点的行索引从小到大排序。
4. 对每个标记点，用该矩形的颜色画一条水平线从标记点所在列向右延伸至网格右边缘（包含标记点本身所在列到右边缘的所有格子）。
5. 再从该水平线的右端（网格最右列）向下画垂直线，直到下一个标记点的行减 1 为止；最后一个标记点的垂直线延伸至网格底边。垂直线也使用该矩形的颜色。
6. 矩形本体（移后位置）保持不变，射线不覆盖已有矩形像素。

**关键洞察**：射线的垂直间距不是固定的，而是由各矩形的高度间接决定——高度决定上移量，上移量决定移后位置，位置差决定射线间距。一个高 5 像素的矩形比高 2 像素的矩形移得更远，导致对应射线段更长或更短。求解者必须先发现"上移自身高度"规则，然后才能预测射线的分布。
