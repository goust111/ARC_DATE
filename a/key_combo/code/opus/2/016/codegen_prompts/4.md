## 新题 4：对称补全后局部边框擦除

**组合逻辑**：[对称补全](由控制标记确定可信半侧，跨轴镜像补全缺失半侧) → [擦除](创新为擦除补全后对象局部边界框的最外一圈像素)

**来源原语**：对称补全(symmetry_completion)/对称轴(symmetry_axis)/控制标记(control_marker)/控制标记指示源侧(control_marker_indicates_source)/轴对称反射(axial_mirror_reflection) ← 5b692c0f；擦除(erase)/局部边界列(local_bounding_col)/相对自身定位(self_relative_pos)/按对象局部裁切(local_bbox_crop) ← 52364a65

**依赖链**：每个对象包含一条黄色对称轴和一个偏离轴的黄色控制标记 → 控制标记所在半侧为可信源 → 将源侧非黄像素跨轴反射到对侧，完成对称补全 → 补全后重新计算每个对象的局部边界框（因新增像素而扩大）→ 擦除边界框最外一圈像素 → 擦除量由补全后的边界框决定，而边界框依赖补全结果，形成紧耦合

先用控制标记确定可信侧并跨轴镜像补全每个对象，然后擦除补全后各对象局部边界框最外一圈的全部像素。

**输入结构**：约 14x14 的黑(0)背景网格。包含 2-3 个互不接触的前景对象。每个对象由以下部分组成：(a) 一条黄(4)色的连续直线段（水平或垂直），贯穿对象中部，作为对称轴；(b) 轴的一侧有若干非黄前景像素（如红(2)或蓝(1)），形成 4-连通图形（3-8 像素），构成"可信半侧"；(c) 轴的另一侧基本为空（黑色背景），是待补全的"缺失半侧"；(d) 在可信半侧有一个额外的黄(4)像素不在轴线上，标记源侧。每个对象的可信半侧在轴两侧至少跨越 3 行/列，使得补全后的边界框比补全前至少扩大 2 行/列。生成约束：不同对象的边界框（补全后）互不重叠且间距至少 2 格；黄色轴线像素和控制标记不参与擦除判定。

**规则**：
1. 对每个包含黄(4)轴线的对象，定位其对称轴（连续水平或垂直黄色线段）和偏离轴的黄色控制像素。
2. 控制像素所在的半侧为源侧。将源侧所有非黄前景像素跨轴反射到对侧对应位置，覆盖目标位置的背景像素。轴线像素和控制像素保持不变。
3. 全部对象补全完毕后，对每个对象重新计算其局部边界框（包含该对象所有非背景像素的最小矩形）。
4. 对每个对象，将其局部边界框最外一圈（顶行、底行、最左列、最右列）上的所有像素设为黑(0)背景。注意：黄色轴线像素和控制像素若位于最外一圈也会被擦除。
5. 不属于任何对象边界框的像素保持不变。

**关键洞察**：对称补全和边框擦除通过边界框尺寸紧耦合——补全步骤新增的像素扩大了边界框，而擦除步骤恰好作用于这个扩大后的边界框外圈。如果跳过补全直接擦除，边界框更小，擦除的像素集完全不同；如果跳过擦除，输出保留了完整的补全结果。两步操作对最终输出的贡献不可拆分。
