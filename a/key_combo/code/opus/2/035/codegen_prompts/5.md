## 新题 5：十字扩展与射线延伸的方向依赖冲突

**组合逻辑**：[扩展/expand] + [射线延伸/ray_extend] + 方向依赖冲突解决(创新：两种空间操作同时产出，冲突优先级由射线朝向决定)

**来源原语**：expand(0962bcdd), ray_extend(9344f635), cross_pattern(0962bcdd), micro_marker(9344f635), row_column_bar(9344f635), ortho_diag_role_split(0962bcdd), orientation_determines_direction(9344f635), arm_center_split_growth(0962bcdd), row_overrides_column(9344f635), conflict_priority(9344f635)

**依赖链**：扩展和射线延伸各自独立产生像素覆盖 → 在重叠区域，冲突解决规则依赖射线朝向（行条 vs 列条）。删除扩展，没有十字足迹参与冲突；删除射线延伸，没有条纹参与冲突；删除方向依赖的冲突规则，重叠区域颜色不确定。

同时扩展十字和延伸骨牌射线；行条切穿十字，但列条被十字遮挡。

**输入结构**：
- 约14x14网格，黑(0)背景。
- 前景元素分两类：
  - **3x3两色十字**：臂色（N/S/E/W四像素）和中心色（1像素）各为一种非黑颜色，两色不同。约2-3个十字。
  - **2像素同色多米诺骨牌**：水平排列（1x2，两像素同行相邻）或垂直排列（2x1，两像素同列相邻），颜色非黑且与十字的臂色和中心色均不同。约2-4个骨牌，其中至少1个水平、至少1个垂直。
- 十字与骨牌的边界框互不重叠且不4-相邻。
- 生成约束：至少一个水平骨牌的所在行穿过某个十字的5x5扩展范围；至少一个垂直骨牌的所在列穿过某个十字的5x5扩展范围。不同十字可使用不同的臂色/中心色。

**规则**：
1. 扩展每个3x3十字：臂色沿正交方向各延伸1像素（5x5足迹的上/下/左/右端点）；中心色填充5x5足迹的四个对角位置。扩展后每个十字在5x5区域内占13个非背景像素。
2. 延伸每个骨牌为射线：水平骨牌 → 将骨牌颜色沿骨牌所在行绘制整行（行条）；垂直骨牌 → 将骨牌颜色沿骨牌所在列绘制整列（列条）。
3. 同一像素被多种操作覆盖时的冲突解决：
   a. 行条 vs 扩展十字：行条颜色覆盖十字颜色（行条优先级更高）。
   b. 列条 vs 扩展十字：十字颜色保留，列条被遮挡（十字优先级更高）。
   c. 行条 vs 列条（无十字参与）：行条覆盖列条。
4. 等效绘制顺序理解：先绘制所有列条 → 再绘制所有扩展十字 → 最后绘制所有行条。每层覆盖前一层在同位置的颜色。
5. 未被任何操作覆盖的像素保持黑(0)背景。

**关键洞察**：冲突优先级不是简单的"后画覆盖先画"全局规则，而是依赖射线的朝向：水平行条能穿透十字（行条 > 十字），但垂直列条被十字遮挡（十字 > 列条）。求解者需要在示例中分别观察水平射线穿过十字区域和垂直射线被十字阻断的现象，才能推断出这条方向不对称的分层规则。仅看一个示例可能误判为统一优先级。
