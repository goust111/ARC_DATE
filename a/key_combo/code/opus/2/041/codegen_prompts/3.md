## 新题 3：L 标记朝向编码重力方向

**组合逻辑**：[标记朝向编码颜色 marker_orientation_encodes_color](创新：朝向编码改为方向编码) + [重力下落 gravity_drop](创新：方向由标记动态决定) + [容器 container] + [填充 fill] + [擦除 erase]

**来源原语**：marker / marker_orientation_encodes_color 来自 604001fa；gravity_drop / container / fill / column_fall_in / no_container_floor 来自 db7260a4；erase 来自 182e5d0f

**依赖链**：必须解读 L 标记的缺角方位才能确定坠落方向；必须确定方向才能判断彩色像素是否会进入某个容器；必须知道容器开口方向才能判断是否"接住"了坠落像素。三层判断环环相扣。

L 三联骨牌标记的缺角不编码颜色，而是编码重力方向；标记旁的彩色像素沿该方向坠落，落入开口方向匹配的 U 形容器。

**输入结构**：约 14x14 网格。背景黑(0)。网格中散布 3-4 个橙(7)色 L 三联骨牌标记（每个占据 2x2 区域中的 3 个像素，缺失一个角像素）。每个标记紧邻（共享一条边）1 个彩色单像素（颜色各异，从红(2)、蓝(1)、绿(3)、黄(4)中选取），该彩色像素位于标记 2x2 包围盒的某条边外侧的中间位置。网格中另有 3-4 个栗(9)色 U 形容器（两条平行边 + 一条底边，内部为空矩形区域，每个容器的开口朝某个基数方向——上/下/左/右），容器开口方向不全相同。生成约束：每个标记的坠落方向上恰好有一个开口方向与之相对的容器（向下坠落对应朝上开口、向左坠落对应朝右开口，以此类推），且不同标记指向不同容器，保证无冲突。

**规则**：
1. 擦除所有橙(7)标记像素（变为黑色）。
2. 对每个原标记，根据其 2x2 包围盒中缺失角的位置确定重力方向：缺左上角 → 向下，缺右上角 → 向右，缺右下角 → 向上，缺左下角 → 向左。
3. 将每个标记紧邻的彩色像素沿对应方向移动。像素沿该方向逐格移动直到遇到一个 U 形容器的开口。容器"接住"像素的条件：容器的开口方向与坠落方向相对（即容器朝上开口接住向下坠落、容器朝右开口接住向左坠落，以此类推），且像素的移动轨迹经过容器开口的行或列范围。
4. 当像素被容器接住时，用该彩色填满容器的整个内部空间。
5. 若像素到达网格边界仍未遇到匹配容器，则沿移动方向在边界行或列铺满该色（从像素起始位置到边界的整行或整列）。
6. 容器壁（栗色）保持不变。彩色像素的原始位置变为黑色。

**关键洞察**：L 标记的几何朝向编码的不是颜色而是物理方向，且容器的开口方向必须与坠落方向"相对"才能接住填充。需要同时解读标记的几何编码和容器的结构朝向。缺角位置到方向的映射是隐蔽规则，需对比多个示例才能归纳。
