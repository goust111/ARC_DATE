## 新题 10：压缩颜色网格后中心分隔列翻转

**组合逻辑**：[压缩 compress] + [包围盒行列分组 bbox_row_column_grouping] + [忽略干扰项 ignore_distractors] → 颜色网格生成 → [局部翻转 local_reverse] + [中心分隔像素 center_separator](创新：翻转作用于压缩后的动态网格而非固定结构) + [各侧独立翻转 independent_side_reverse]

**来源原语**：compress / bbox_row_column_grouping / filled_rectangle / ignore_distractors / color_grid 来自 0a1d4ef5；local_reverse / center_separator / center_symmetry / independent_side_reverse / pixel_segment 来自 833966f4；min_side_filter / minimum_size_filtering 来自 25094a63

**依赖链**：必须先筛选出大矩形并压缩成颜色网格才能确定每列有哪些颜色以及中心分隔像素是什么；必须识别中心分隔像素才能确定翻转的轴和范围；压缩结果的尺寸（行数）决定了翻转是否发生（行数为奇数时有唯一中心行，偶数时无中心行则不翻转该列）。两个操作通过网格尺寸和颜色内容紧耦合。

大网格中散布的填充矩形先压缩成紧凑颜色网格，再对网格每列以中心行像素为轴独立翻转上下两段颜色顺序。

**输入结构**：约 20x20 网格。背景黑(0)，散布少量干扰色单像素。包含 15 个单色填充矩形（5 行 x 3 列排列），每个矩形至少 3x3，颜色从 10 种 ARC 颜色中选取（可有重复）。同行矩形的垂直包围盒范围重叠，同列矩形的水平包围盒范围重叠，形成 5x3 的格点结构。干扰像素不构成边长 >= 3 的矩形。

**规则**：
1. 筛选出所有边长均 >= 3 的纯色 4-连通填充矩形（恰好填满其包围盒），忽略干扰像素。
2. 按矩形包围盒的行位置和列位置分组，压缩为 5x3 颜色网格（5 行 3 列，每格填入对应矩形的颜色）。
3. 对压缩后的 5x3 网格，将每一列（5 个像素的竖直序列）视为独立单元进行局部翻转：
   - 第 3 行（中间行，从 1 开始计数）的像素为中心分隔像素，保持不动。
   - 第 1-2 行的两个像素顺序翻转（第 1 行和第 2 行交换）。
   - 第 4-5 行的两个像素顺序翻转（第 4 行和第 5 行交换）。
4. 输出翻转后的 5x3 颜色网格。

**关键洞察**：压缩步骤决定了颜色网格的内容——哪些颜色在哪些位置——而翻转步骤重排了每列内的颜色布局。不先压缩就不知道颜色排列，不翻转就无法匹配输出。中心分隔行的颜色不变，但它隐式锚定了翻转的对称轴。
