## 新题 8：噪声中检测隐藏矩形作为射线偏转障碍

**组合逻辑**：[最大矩形检测 max_rect_detection] + [最小边长过滤 min_side_filter] + [噪声背景 noisy_background] → 障碍识别(创新：检测结果不重涂色而作为障碍) → [射线延伸 ray_extend] + [障碍偏转绕行 obstacle_deflection] + [对角方向 diagonal_direction] + [擦除 erase]

**来源原语**：max_rect_detection / min_side_filter / noisy_background / solid_mono_rect 来自 25094a63；ray_extend / source_pixel / obstacle_deflection / blocker / diagonal_direction 来自 69889d6e；erase 来自 182e5d0f

**依赖链**：必须先从噪声中检测出隐藏的大矩形才能确定障碍位置；必须知道障碍位置才能计算射线的偏转轨迹。检测和偏转构成不可分割的推理链——不先解决感知问题（哪些是真正的矩形）就无法执行物理模拟（射线怎么绕行）。

噪声网格中隐藏的大型同色矩形不被标记，而是作为射线偏转的障碍，射线的弯折轨迹间接揭示矩形的存在。

**输入结构**：约 16x16 网格。网格被随机多色噪声像素填满（颜色 0-9 随机分布，无大面积同色区域）。其中隐藏 2 个纯色实心矩形（如一个 4x5 的红(2)矩形和一个 5x4 的蓝(1)矩形），它们的颜色在噪声中也零散出现，但这两个矩形是唯一边长均 >= 4 的最大同色矩形区域。网格底行最左侧有一个黄(4)色源像素（该位置的噪声被显式替换为黄色）。网格中不存在其他黄(4)像素。生成约束：两个隐藏矩形不相邻也不重叠；源像素的对角射线路径上至少遇到一个矩形障碍。

**规则**：
1. 检测网格中所有边长均 >= 4 的最大同色实心矩形。"最大"指不存在一个更大的同色矩形严格包含它。忽略噪声中的小色块和短色条。
2. 将检测到的矩形标记为障碍块，保留其原色。
3. 从底行的黄色源像素出发，向右上方（对角方向，每步行-1 列+1）发射一个两像素宽的水平带。第一步在源像素上方一行放置两个黄色像素（源像素列和列+1）。
4. 每向上一行，带的两个像素都向右移一列（对角前进）。若带在新行的位置与障碍块碰撞（任一像素落在障碍块内），则将带继续向右平移直到两个像素都避开障碍块。
5. 若偏移导致当前行的带与上一行的带在列方向上产生间隙（当前行最左像素的列 > 上一行最右像素的列 + 1），则在上一行从其带的右端向右补充黄色像素直到列间隙消除（保持轨迹连通）。
6. 带移出网格右边界时停止。
7. 将所有非障碍块且非射线轨迹的像素替换为黑(0)。输出保留：检测到的矩形（原色不变）、黄色射线轨迹、黑色背景。

**关键洞察**：射线的弯折位置是矩形检测正确性的间接验证——不先从噪声中识别出真正的大矩形，就无法确定射线该在哪里偏转。感知和模拟必须同时正确才能得到正确输出。

import hashlib
import numpy as np

p = Path("/home/lixinyu/snap/a/key_combo/code/opus/2/041/8.py")
mod = SourceFileLoader("new_arc_task", str(p)).load_module()
sigs = set()
for i in range(100):
    inp = mod.generate_input()
    out = mod.main(inp)
    assert isinstance(inp, np.ndarray)
    assert isinstance(out, np.ndarray)
    assert inp.ndim == 2 and max(inp.shape) <= 30, f"input grid exceeds 30x30: {inp.shape}"
    assert out.ndim == 2 and max(out.shape) <= 30, f"output grid exceeds 30x30: {out.shape}"
    sigs.add(hashlib.md5(inp.tobytes() + str(inp.shape).encode()).hexdigest())
print("variants", len(sigs))
assert len(sigs) >= 20
