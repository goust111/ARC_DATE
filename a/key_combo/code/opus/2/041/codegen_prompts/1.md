## 新题 1：门结构划界的分段周期修复

**组合逻辑**：[门结构 gate_motif](创新：从滑动终点改为周期域分界标记) + [四邻接连通 four_neighbor_connect] → [周期推断 periodic_inference](分段独立执行) → [间隙填充 gap_filling](在各段内修复)

**来源原语**：gate_motif / stop_at_gate / path / four_neighbor_connect 来自 182e5d0f；periodic_inference / gap_filling / ignore_missing_to_infer / repeating_tile 来自 1d0a4b61

**依赖链**：必须先识别门结构才能确定周期域的边界；必须划定域边界才能对每段独立推断周期；必须推断出周期才能修复缺损像素。删除门识别环节则所有段被混为一个域、周期冲突无法求解；删除周期推断环节则门结构失去意义。

在一条绿色通道上，门结构将通道切分为独立周期段，每段有自己的彩色周期图案和黑色缺损，需分段推断并修复。

**输入结构**：约 12x18 网格。背景黑(0)。绿(3)色像素构成一条 4-连通的水平或垂直通道（宽 1 像素，长度跨越网格大部分范围）。通道上嵌有 2-3 个门结构，每个门是与通道方向垂直的"栗(9)-绿(3)-栗(9)"三像素直线段（中心像素与通道重合，两端栗色像素在通道两侧各延伸 1 像素）。门结构将通道分为 3-4 段。每段内，部分绿色通道像素被替换为其他颜色（如红(2)、蓝(1)、黄(4)等），构成该段特有周期图案的可见样本；另有部分像素被替换为黑(0)表示缺损。不同段的周期长度和颜色组合互不相同。生成约束：每段内至少有一个完整周期的非黑像素可见，确保周期可唯一推断。

**规则**：
1. 识别通道中所有门结构：与通道垂直的栗(9)-绿(3)-栗(9)三像素直线段。门结构保持不变。
2. 门的绿色中心像素将通道分段。每段的范围是两个相邻门中心之间的通道像素（不含门中心本身），或从通道端点到最近门中心之间的通道像素。
3. 对每段独立执行：忽略黑(0)像素，从该段内可见的彩色像素（含绿色）推断沿通道方向的最小重复周期。
4. 用推断出的周期瓦片填充该段内所有黑(0)位置，保持与可见像素的相位一致。
5. 通道外的所有像素（包括背景和栗色门端）不变。

**关键洞察**：门结构不再是运动的终点，而是周期性的边界——同一条通道上不同段拥有完全不同的周期规律，必须先用门分段才能正确推断各段的独立周期。
