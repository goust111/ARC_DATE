## 新题 4：差异掩码编码射线方向集

**组合逻辑**：[差异提取 difference_extraction] + [对齐比较 aligned_comparison] → 方向编码(创新：掩码几何形状编码射线方向) → [射线延伸 ray_extend] + [障碍块 blocker] + [碰撞停止 collision_stop]

**来源原语**：difference_extraction / aligned_comparison / foreground_motif / damaged_copy / missing_cell_mask 来自 2037f2c7；ray_extend / source_pixel / blocker / collision_stop 来自 69889d6e；erase 来自 182e5d0f

**依赖链**：必须比较两个图案才能提取差异掩码；必须分析掩码像素的空间分布才能确定射线方向集合；必须发射射线才能生成输出。差异提取的结果不是终态输出而是中间编码，射线延伸的方向参数不是固定的而是由差异动态决定。

上区两个对齐图案的缺失像素分布编码了射线方向，下区的源像素沿这些方向发射射线直到撞上障碍。

**输入结构**：约 15x15 网格。背景黑(0)。网格被一行灰(5)色水平分隔线分为上下两区。上区包含两个 4-连通多色前景图案（每个的包围盒约 4x4 到 5x5，互相水平间隔若干列），它们的包围盒大小相同。一个是完整图案，另一个是缺损副本（有 2-4 个像素被替换为黑色）。下区中央有一个红(2)色源像素，下区另有若干蓝(1)色障碍块（每个为 2x2 方块，共 2-4 个）。生成约束：缺损像素相对于掩码几何中心的方向集合中，每个归一化方向互不相同（不会有两个缺损像素映射到同一射线方向）。

**规则**：
1. 裁剪上区两个图案到各自包围盒，按左上角对齐逐像素比较。
2. 提取缺损副本中缺失的像素位置（完整中有前景色、缺损中为黑色的格子），得到差异掩码（一组相对于包围盒的坐标）。
3. 计算差异掩码的几何中心：所有缺失像素坐标的平均值（行和列分别平均，四舍五入取整）。
4. 每个缺失像素相对于几何中心的偏移 (dr, dc) 定义一个射线方向。方向归一化规则：若 |dr| > |dc| 则步长为 (sign(dr), 0)；若 |dc| > |dr| 则步长为 (0, sign(dc))；若 |dr| == |dc| 且均非零则步长为 (sign(dr), sign(dc))。偏移为 (0,0) 的像素不产生射线。
5. 从下区的红色源像素出发，沿每个归一化方向发射射线。射线逐格绘制红(2)色像素，遇到蓝色障碍块或网格边界时停止（不覆盖障碍块，不覆盖灰色分隔线）。
6. 擦除灰色分隔线和上区所有内容（变为黑色）。输出仅保留下区：红色射线、红色源像素、蓝色障碍块、黑色背景。

**关键洞察**：上区的"找不同"不是目的而是编码——缺失像素的空间分布决定了下区射线的发射方向集合。差异提取是中间推理步骤，其几何属性成为后续操作的参数。
