## 新题 7：框架缺口方向编码条纹平铺轴

**组合逻辑**：[缺口不对称/方向帽](创新：不再决定射线溢出方向，而是编码平铺轴方向) + [平铺/种子像素/条纹](创新：种子不在网格边缘而在框架内部，周期不由种子间距而由框架尺寸决定) + [填充](已有)

**来源原语**：开顶矩形框/方向帽/缺口不对称(4e469f39)、平铺/种子像素/条纹/种子定条纹周期(0a938d79)、填充(694f12f3, 0a938d79)

**依赖链**：框架的缺口位置和方向帽朝向 → 确定条纹平铺沿水平还是垂直方向 → 框架内的两个种子像素定义条纹颜色和初始间距 → 按确定方向在框架内部平铺条纹。删掉缺口方向分析则不知沿哪个轴平铺；删掉种子像素则不知条纹颜色和间距。

框架结构的几何不对称性（缺口位置与帽方向）编码了条纹平铺的轴方向，内部种子像素提供颜色和间距参数。

**输入结构**：约 18x18 的网格，背景黑(0)。网格中有 2~3 个由灰(5)像素构成的矩形框架（1 像素厚，最小内部尺寸 4x4，最大 8x8），框架之间互不重叠且间距至少 2 像素。每个框架在其四条边之一上有一个 1 像素宽的缺口（该边上缺少一个灰像素），缺口一侧有连续 2 个灰像素帽（即缺口不居中，一侧比另一侧多出 1~2 个灰像素）。不同框架的缺口可以在不同边上（上/下/左/右）。每个框架内部恰有两个不同颜色的单像素标记（种子像素），颜色从蓝(1)、红(2)、绿(3)、黄(4)、品红(6)、橙(7)中选取。两个种子像素位于同一行或同一列，间距为 1~3 像素。生成约束：帽方向与缺口方向的关系在所有框架中一致（即帽总是指向同一侧，如总是指向缺口的顺时针方向），但这一规则需要对比多个示例才能归纳。

**规则**：
1. 对每个框架，识别其缺口所在的边（上/下/左/右）。
2. 确定平铺轴：缺口在上边或下边 → 条纹沿垂直方向平铺（竖条纹）；缺口在左边或右边 → 条纹沿水平方向平铺（横条纹）。
3. 帽方向决定条纹起始色：帽指向缺口的顺时针方向时，距离帽较近的种子像素颜色作为第一条纹色；另一个种子颜色作为第二条纹色。
4. 两个种子像素之间的间距 d（沿平铺轴方向的距离）确定条纹宽度：每条纹宽 d 像素。
5. 从框架内部靠近帽的一侧开始，按条纹宽 d 交替填充第一色和第二色，直到填满框架内部。超出整数倍的剩余空间用最后一条纹的颜色填充。
6. 种子像素被条纹覆盖。灰色框架边框和缺口保持不变（缺口处仍为黑色背景）。

**关键洞察**：框架的结构不对称性（哪条边有缺口、帽指向哪侧）本身就是变换指令，而非需要被变换的对象——几何结构编码了算法参数。
