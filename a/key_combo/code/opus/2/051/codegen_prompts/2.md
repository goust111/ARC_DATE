## 新题 2：模式匹配定位逻辑运算操作数

**组合逻辑**：[模式匹配/形状相同](已有) + [逻辑运算/NOR](创新：操作数不再由分隔条预先分割，而是通过模式匹配从散布的候选中选出) → [描框](创新：框选的是运算结果而非匹配副本)

**来源原语**：模式匹配/形状相同/标记模板/样本区域(e2092e0c)、逻辑运算/逻辑或非合并/二值掩模(1b2d62fb)、描框(e2092e0c)

**依赖链**：L-stencil 标识参考样本的轮廓形状 → 在网格中找到恰好两个与参考轮廓相同的二值图案 → 将两图案对齐后做逐像素 NOR → 在 NOR 结果所在位置描灰色框。删掉模式匹配则不知道选哪两个图案做 NOR；删掉 NOR 则匹配结果无用；删掉描框则输出缺少定位信息。

通过轮廓匹配从多个候选中选出两个图案作为逻辑 NOR 的操作数，NOR 结果被框选标记。

**输入结构**：约 18x18 的网格，背景黑(0)。网格内散布着 4~6 个由栗(9)像素构成的小图案（每个 3x4 至 5x5 大小，4-连通，形状各不相同，像素数 5~10）。其中一个图案的右侧紧邻一列灰(5)像素、下方紧邻一行灰(5)像素，形成 L 形标记（灰像素不与图案像素重合，仅紧邻）。在其余图案中，恰好有两个的外轮廓（边界框内的前景/背景二值掩模）与被 L 标记的图案完全相同。这两个匹配图案各自的边界框尺寸相同。生成约束：两个匹配图案互不重叠且各自周围有至少 1 像素的空白边距；被 L 标记的图案本身不参与 NOR 运算。

**规则**：
1. 找到被灰(5) L-stencil 标记的参考图案，提取其边界框内的二值掩模（栗=1，背景=0）。
2. 在所有其他栗色图案中，找出恰好两个与参考掩模完全相同的匹配图案（逐像素比较边界框内二值掩模）。
3. 将两个匹配图案的二值掩模按像素位置对齐（以各自边界框左上角为原点对齐）。执行逐像素 NOR 运算：两个掩模在该位置都为 0 时输出青(8)，否则输出黑(0)。
4. 将 NOR 结果放置在两个匹配图案的边界框质心连线的中点处（中点取整，结果图案的中心对齐该中点）。若放置位置与已有前景像素冲突，则向下逐行偏移直到无冲突。
5. 在 NOR 结果的外围描一圈灰(5)像素框（1 像素厚），框内保留 NOR 结果不变。
6. 其余所有已有像素保持不变。

**关键洞察**：逻辑运算的操作数不由空间分隔预先给定，而需要通过模式匹配从多个外观相似但不完全相同的候选中筛选出来——匹配失败的图案是干扰项。
