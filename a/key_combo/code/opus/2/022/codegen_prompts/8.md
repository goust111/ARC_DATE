## 新题 8：对称性筛选精灵体与位置编码面板汇聚决定放置

**组合逻辑**：[筛选/filter](对称性选择目标) ⊕ [裁剪/crop](提取精灵体) ⊕ [放置/place](位置编码面板决定坐标) — 三个独立信息源（多个精灵体中哪个对称、对称精灵体的形状、编码面板的位置信号）汇聚到一个输出决策；不是流水线而是多源收敛结构

**来源原语**：筛选/filter、对称性筛选目标/symmetry_filter、精灵体/sprite、干扰体/distractor、裁剪/crop（参考题 72ca375d）；放置/place、标记编码位置/marker_encodes_position、锚点对齐/anchor_alignment（参考题 a32d8b75）；标记像素/marker_pixel（参考题 d687bc17）

**依赖链**：网格中有多个精灵体和一个位置编码面板。求解者需要同时解决两个子问题：(1) 哪个精灵体是目标？——通过对称性测试筛选；(2) 目标放在哪里？——通过编码面板中标记像素的位置解码。两个子问题的答案在放置操作中汇合。删除对称性筛选则不知道放什么；删除位置编码则不知道放哪里。

在多个精灵体中找到唯一对称的那个，裁剪后放置到位置编码面板指定的网格坐标处。

**输入结构**：约 15x15 网格，黑(0) 背景。网格主区域（约 12x12）散布 3-5 个单色精灵体，每个精灵体 4-8 像素、4-连通，颜色各不相同（从红(2)、蓝(1)、绿(3)、橙(7)、品红(6) 中取）。恰好一个精灵体关于其边界框具有某种对称性（垂直反射、水平反射或 180 度旋转），其余均为不对称的干扰体。网格右下角（或右上角等固定位置）有一个 5x5 的灰(5) 边框面板（外圈 1 像素宽灰色边框，内部 3x3 区域为黑(0) 背景）。该 3x3 内部恰有一个像素为栗(9)，其在 3x3 格中的位置编码了放置对齐方式。生成约束：精灵体互不相邻且不与面板相邻；对称精灵体的边界框不超过 4x4；面板位置固定（所有示例中面板都在同一角落）。

**规则**：
1. 识别所有精灵体（4-连通非黑非灰前景连通分量），裁剪到最小边界框。
2. 对每个精灵体测试对称性（垂直反射、水平反射、180 度旋转），选出唯一通过测试的精灵体作为目标。
3. 读取 5x5 面板内部 3x3 格中栗(9) 标记像素的位置 (pr, pc)，其中 pr 属于 {0, 1, 2}（上/中/下），pc 属于 {0, 1, 2}（左/中/右）。
4. 清除整个网格（所有精灵体和面板均清除为黑(0)）。
5. 将目标精灵体放置到清空后的网格上，对齐方式由 (pr, pc) 决定：
   - pr=0：精灵体边界框上边缘对齐网格第 0 行；pr=1：精灵体边界框垂直居中于网格；pr=2：精灵体边界框下边缘对齐网格最后一行。
   - pc=0：精灵体边界框左边缘对齐网格第 0 列；pc=1：精灵体边界框水平居中于网格；pc=2：精灵体边界框右边缘对齐网格最后一列。
   - 居中时若无法恰好居中（网格尺寸与精灵体尺寸奇偶不同），向上/向左取整（即 floor）。
6. 输出仅含黑(0) 背景和放置后的目标精灵体。

**关键洞察**：这道题不是流水线——对称性筛选和位置解码是两个独立的推理任务，它们的结果在放置操作中汇聚。求解者不能先做完一个再做另一个（两者无先后依赖），但必须同时解对才能产生正确输出。面板中标记的行列位置联合编码了两个独立的空间参数（垂直对齐和水平对齐），与精灵体的内容无关。
