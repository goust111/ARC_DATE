## 新题 9：标记间距隐式编码平铺缩放因子

**组合逻辑**：[扩展 + 中点划分归属 + 按行排序 + 边框绘制](从参考题4) ⊗ [平铺 + 像素放大 + 逐级展开](从参考题2，创新：缩放因子不再是固定的 2 的幂次，而是由带高度与图案高度之比决定)

**来源原语**：扩展(0f63c0b9)、中点划分归属(0f63c0b9)、按行排序(0f63c0b9)、边框绘制(0f63c0b9)、单像素标记(0f63c0b9)、横带(0f63c0b9)、平铺(762cd429)、像素放大(762cd429)、基元图案(762cd429)、逐级展开(762cd429)

**依赖链**：标记的行坐标决定带的划分（中点归属），带高度 = 带的行数。缩放因子 = floor(带高度 / 图案高度)。缩放因子 < 1 的带不放置图案。因此标记的不规则间距直接编码了图案在各带中的不同缩放大小——间距大的带产生大副本，间距小的带产生小副本或不产生副本。这种编码关系在源题中不存在。

标记点沿行方向不等距分布，将网格分为不等高的横带；在每带中以带高度与图案高度之比为缩放因子放置缩放后的图案，标记色作为边框色。

**输入结构**：约 20x10 的网格（20 行 10 列），背景为黑(0)。网格第 0 行、第 0~2 列有一个 3x3 的基元图案（仅占据行 0~2、列 0~2），使用蓝(1)和红(2)两色。在列 5 位置（或网格中部某固定列），有 3~4 个单像素标记，颜色各不相同（如绿(3)、黄(4)、灰(5)、品红(6)），行坐标互不相同且互不连续。生成约束：相邻标记之间的行间距不全相同（至少有两对间距不同）；最大间距不超过 9 行；最小间距 >= 3 行（即图案高度，保证至少缩放因子为 1）。

**规则**：
1. 将所有标记按行坐标从小到大排序。在相邻标记行坐标的中点（向下取整）处划分网格为水平带。第一个带从行 0 到第一个中点行（含），最后一个带从最后一个中点行+1 到网格底部行（含）。
2. 对每个带，计算带高度 H（带包含的行数）。计算缩放因子 s = floor(H / 3)，其中 3 为图案高度。
3. 若 s >= 1，将基元图案的每个像素放大为 s x s 的同色方块，得到 (3s) x (3s) 的缩放副本。将该副本放置在带内：水平居中于网格宽度，垂直方向顶端对齐带的顶行。若缩放副本超出带的底行则裁剪掉超出部分。若缩放副本超出网格右边缘则裁剪掉超出部分。
4. 若 s = 0（带高度 < 3），该带内不放置图案，保持黑(0)。
5. 对每个带，用该带对应标记的颜色绘制带的边框：带的顶行和底行全部填充为标记色，带的左列（列 0）和右列（最后一列）在带范围内填充为标记色。边框覆盖缩放副本的对应像素。
6. 基元图案原始位置（行 0~2、列 0~2）被纳入第一个带的正常处理流程中，不做特殊保留。标记像素保持其原色。

**关键洞察**：标记点的不等距分布看似只是划分边界，实则隐式编码了每个带内图案的缩放因子——相距远的标记产生大缩放，相距近的标记产生小缩放。求解者必须发现"带高度决定缩放因子"这一隐藏规则，仅看输出中图案大小的变化无法直接推断，需结合标记位置归纳。

p = Path("/home/lixinyu/snap/a/key_combo/code/opus/2/025/9.py")
mod = SourceFileLoader("new_arc_task", str(p)).load_module()
sigs = set()
for i in range(100):
    inp = mod.generate_input()
    out = mod.main(inp)
    assert isinstance(inp, np.ndarray)
    assert isinstance(out, np.ndarray)
    assert inp.ndim == 2 and max(inp.shape) <= 30, f"input grid exceeds 30x30: {inp.shape}"
    assert out.ndim == 2 and max(out.shape) <= 30, f"output grid exceeds 30x30: {out.shape}"
    sigs.add(hashlib.md5(inp.tobytes() + str(inp.shape).encode()).hexdigest())
print("variants", len(sigs))
assert len(sigs) >= 20
