## 新题 5：平行四边形对顶点射线与交叉着色

**组合逻辑**：[连线 + 对角分解 + 标记为对顶点](从参考题13) × 2（两组标记画两个平行四边形）→ [射线延伸](从参考题1/9，创新：射线方向由平行四边形边的法线决定) → [重涂色](从参考题1，创新：射线撞击另一个平行四边形边框时，将命中点重涂为射线颜色)

**来源原语**：连线(cb227835)、对角分解(cb227835)、标记为对顶点(cb227835)、标记像素(cb227835)、射线延伸(696d4842/551d5bf1)、重涂色(696d4842)、冲突优先级(03560426)

**依赖链**：必须先用对角分解画出两个平行四边形，才能确定各顶点处射线的发射方向（垂直于该顶点所在的较短边）。两个四边形的相对位置决定射线是否命中对方边框。命中时的重涂色创造了两个四边形之间的信息交换——单独看一个四边形无法确定其哪些边框像素会被改色。

用两对不同颜色的标记像素分别画出两个绿色平行四边形轮廓，从每个顶点沿所在边法线发射该顶点标记色的射线，射线撞到另一个四边形时将命中点染为射线颜色。

**输入结构**：约 18x18 的网格，背景为黑(0)。网格中有四个前景像素形成两对标记：一对为蓝(1)（2 个像素），一对为红(2)（2 个像素）。每对标记像素之间的行偏移和列偏移均非零且不相等（保证对角分解可行）。两对标记所构成的平行四边形不重叠但相距不远（边界框间距 2~5 格），使得至少一条射线能命中另一个四边形。生成约束：每对标记的对角分解方式唯一（取 45 度对角向量加剩余正交向量的分解）；两个平行四边形的边框互不相交；每个四边形至少有一个顶点的射线能到达另一个四边形。

**规则**：
1. 对每对同色标记（蓝(1)对和红(2)对），将两标记视为平行四边形的一对对角顶点。
2. 对每对标记，将标记间的位移向量分解为一个 45 度对角向量（行列分量绝对值相等，等于两个分量绝对值中的较小者）和一个剩余正交向量（纯水平或纯垂直）。这两个向量定义平行四边形的两条相邻边。
3. 计算四个顶点坐标，用绿(3)绘制四边形的四条边（含顶点）。四个标记像素保持原色（蓝(1)或红(2)），不被绿(3)覆盖。
4. 先绘制蓝(1)对的平行四边形，再绘制红(2)对的平行四边形。若两者有重叠像素，红(2)对的绿(3)覆盖蓝(1)对的绿(3)。
5. 从每个标记像素（四个标记各一条射线）出发，确定该标记所在的平行四边形中与该标记相连的较短边的外法线方向（指向四边形外部的那个正交方向）。沿该方向逐格发射射线，颜色为该标记的原色。
6. 射线在遇到第一个非黑(0)像素时停止。若该像素属于另一个平行四边形的绿(3)边框，则将该像素重涂为射线的颜色（蓝(1)或红(2)）。若该像素属于自身四边形边框或标记像素，射线不改变该像素。若射线到达网格边缘仍未命中，则射线止于边缘。
7. 射线本身（不含起点标记、不含终点命中像素）绘制为该标记的原色。

**关键洞察**：两个平行四边形通过射线产生单向信息传递——一个四边形的标记色可以"染"到另一个四边形的边框上，但这仅在几何关系允许射线到达时发生。哪些边框像素被改色完全取决于两个四边形的相对位置和朝向，无法从单个四边形独立推断。
