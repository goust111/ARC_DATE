## 新题 4：同色计数驱动的同心生长与碰撞裁决

**组合逻辑**：[计数/counting](创新：计数结果不再用于排序输出，而是作为生长层数的参数) + [生长/grow](创新：生长层数由外部统计量决定而非固定) + [碰撞阻挡/collision_blocking](创新：碰撞裁决规则引入原始边长作为优先级)

**来源原语**：计数/按数量排序(b1986d4b)、忽略非正方形(b1986d4b)、生长/同心正方形层(3befdf3e)、碰撞阻挡(4093f84a)、忽略干扰项(b1986d4b)

**依赖链**：识别正方形并按颜色计数 → 计数值决定每个正方形的生长层数 → 生长过程中不同正方形的扩展区域可能冲突 → 碰撞裁决根据原始边长确定优先级。删除计数则无法确定生长量；删除碰撞裁决则重叠区域颜色不确定。

每个彩色实心正方形按同色兄弟数量向外生长同心边框层，扩展重叠时大正方形优先覆盖。

**输入结构**：
- 黑(0)背景，网格约 18x18。
- 4-8 个实心单色正方形，使用 3-4 种颜色，选自蓝(1)、红(2)、绿(3)、黄(4)、橙(7)。每种颜色出现 1-3 次。正方形边长 2-3 像素。正方形之间互不相邻（初始状态下最近正方形之间至少隔 3 像素）。
- 2-3 个非正方形干扰体：不规则 4-连通单色小图形（2-5 像素），颜色选自品红(6)或栗(9)，散布于网格中。
- 生成约束：每种正方形颜色至少出现 1 次；至少有一种颜色出现 2 次以上（确保存在生长行为）；正方形之间留足空间使生长层有可展开的余地，但至少有一对正方形的生长区域会发生重叠。

**规则**：
1. 擦除所有非正方形干扰体（品红(6)或栗(9)的不规则图形 → 替换为黑(0)）。判断标准：4-连通分量的边界框不是正方形，或边界框内有黑(0)空洞。
2. 对每种颜色 C，计算颜色为 C 的正方形个数，记为 N(C)。
3. 对每个颜色为 C 的正方形，向外生长 (N(C) - 1) 层同心一像素宽边框。边框颜色按层交替：第 1 层（紧贴原正方形）= 颜色 C，第 2 层 = 灰(5)，第 3 层 = 颜色 C，第 4 层 = 灰(5)，依此交替。若 N(C) = 1，则不生长（0 层边框）。
4. 碰撞裁决：若两个正方形的生长区域（含原始正方形本身）重叠于某像素，该像素归属原始边长较大的正方形。若原始边长相同，归属中心点距网格中心（行列各取中值）曼哈顿距离较小的正方形。
5. 生长层超出网格边缘的部分裁剪丢弃。
6. 黑(0)背景中未被生长覆盖的区域保持不变。

**关键洞察**：正方形的生长幅度取决于全局统计量（同色兄弟总数），而非自身属性——孤立颜色的正方形完全不生长，而同色兄弟多的正方形大幅扩展。碰撞区域的归属由原始尺寸决定，需同时掌握计数规则和碰撞规则才能确定每个像素的最终颜色。
