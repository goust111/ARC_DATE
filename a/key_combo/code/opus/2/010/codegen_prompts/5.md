## 新题 5：周期平铺的同源合流与异源冲突

**组合逻辑**：[周期平铺/periodic_tiling](已有) + [邻接侧决定方向/adjacency_side_determines_dir](已有) + [碰撞阻挡/collision_blocking](创新：十字体本身充当阻断墙) + [异源交叉特殊着色/cross_source_special_color](创新：同源重叠与异源重叠产生截然不同的颜色)

**来源原语**：周期平铺/十字图案/标记块(53fb4810)、邻接侧决定方向(53fb4810)、不覆盖源对象(53fb4810)、碰撞阻挡(4093f84a)、异源交叉特殊着色(45bbe264)、行列交叉(45bbe264)

**依赖链**：标记块邻接位置确定平铺方向 → 平铺向网格边缘或遇其他十字体时停止（碰撞阻挡） → 多条平铺带在远处交叉时根据是否同源产生不同颜色（同源合流 vs. 异源冲突）。所有平铺带必须同时计算才能判定交叉类型。

十字体臂端的彩色标记块沿臂方向周期平铺至边缘，同源重叠合为灰色、异源重叠变为红色。

**输入结构**：
- 黑(0)背景，网格约 20x20。
- 2-3 个灰(5)十字(+)形锚点，每个由 5 像素组成（中心 + 上下左右各 1 像素），十字体之间距离至少 6 像素。
- 每个十字体的 2-4 个臂端（非全部 4 个臂都必须有标记）各紧邻一个 1x1 单像素彩色标记块。标记块颜色选自蓝(1)、绿(3)、黄(4)、橙(7)，同一十字体的不同臂端标记颜色可相同或不同，不同十字体的标记颜色可相同或不同。标记块与臂端 4-邻接，且位于臂的延伸方向上（即标记在十字体外侧，而非内侧）。
- 生成约束：至少存在一对来自不同十字体的标记，其平铺方向互相垂直且路径会相交；至少存在一对来自同一十字体的标记，其平铺带会在远处某像素重叠。

**规则**：
1. 对每个标记块，确定其所属十字体及所邻接的臂（北/南/东/西臂）。标记的平铺方向 = 该臂从十字中心指向外侧的方向（即标记远离十字体的方向）。
2. 从标记块的位置开始，沿平铺方向逐像素推进，每隔 2 像素放置一个标记颜色像素（即标记本身为第 1 个，跳过 1 个像素后放置第 2 个，再跳过 1 个放第 3 个......周期为 2）。放置持续至以下任一条件终止：
   - 到达网格边缘（最后一个网格内像素仍可放置）。
   - 下一个放置位置落在某个十字体(灰(5))像素上：不放置，在该像素前一个周期位置停止。
3. 十字体像素永远不被覆盖。
4. 重叠裁决——若某像素被多条平铺带同时要求放置：
   - 所有相关标记块属于同一个十字体 → 该像素涂为灰(5)（同源合流）。
   - 相关标记块分属不同十字体 → 该像素涂为红(2)（异源冲突）。
   - 若同时存在同源和异源 → 红(2)优先（异源冲突覆盖同源合流）。
5. 标记块本身保留其原始颜色（即使处于"第 1 个放置位置"，也不被同源/异源规则覆盖）。

**关键洞察**：同一十字体两条臂的平铺带在远处交汇时融合为灰色（表示"同源汇合"），而不同十字体的平铺带交汇时变为红色（表示"冲突"）。求解者必须追踪每条平铺带的归属才能确定交叉点颜色，仅靠局部信息无法判定。

p = Path("/home/lixinyu/snap/a/key_combo/code/opus/2/010/5.py")
mod = SourceFileLoader("new_arc_task", str(p)).load_module()
sigs = set()
for i in range(100):
    inp = mod.generate_input()
    out = mod.main(inp)
    assert isinstance(inp, np.ndarray)
    assert isinstance(out, np.ndarray)
    assert inp.ndim == 2 and max(inp.shape) <= 30, f"input grid exceeds 30x30: {inp.shape}"
    assert out.ndim == 2 and max(out.shape) <= 30, f"output grid exceeds 30x30: {out.shape}"
    sigs.add(hashlib.md5(inp.tobytes() + str(inp.shape).encode()).hexdigest())
print("variants", len(sigs))
assert len(sigs) >= 20
