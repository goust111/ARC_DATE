## 新题 2：射线封闭域的边界归属填色

**组合逻辑**：[射线延伸/ray_extend](创新：射线不再只是标记行列，而是与已有线段共同构成封闭边界) + [洪泛填充/flood_fill](创新：填充域由射线动态创建而非预设) + [异源交叉特殊着色/cross_source_special_color](已有：多色边界→冲突色)

**来源原语**：射线延伸/十字引导线(45bbe264)、洪泛填充/封闭区域(c0f76784)、异源交叉特殊着色(45bbe264)、包围/enclosure(c0f76784)、标记像素(e1d2900e)

**依赖链**：标记像素沿行列延伸射线 → 射线遇到灰线段停止，与灰线段共同构成新的闭合边界 → 新闭合域被填充，颜色取决于边界上射线的颜色构成。射线步骤和填充步骤同时约束：未画射线无法知道哪些域被封闭；不知封闭域就无法确定填色。

彩色标记像素向四方射出射线直至触及灰色线段或网格边缘，射线与灰线段围成的新封闭区域按边界射线颜色填色。

**输入结构**：
- 黑(0)背景，网格约 15x15。
- 若干灰(5)一像素宽直线段（水平或垂直），散布于网格中，线段之间不完全围合——即仅靠灰线段本身不构成任何封闭背景区域。
- 2-4 个单像素标记，颜色各不相同，选自蓝(1)、绿(3)、黄(4)、橙(7)中的不同颜色。标记不在灰线段上。
- 标记位置经选择，使得从标记射出的射线遇灰线段停止后，能与灰线段共同围合出至少一个封闭背景区域。
- 生成约束：任意两个标记不在同一行且不在同一列；射线延伸后，至少存在 2 个新围合的封闭区域；每个封闭区域的边界至少包含一段彩色射线。

**规则**：
1. 对每个标记像素，沿上、下、左、右四个方向各射出一条射线。射线逐像素推进，遇到灰(5)线段像素或网格边缘时停止（停止位置的灰像素不被着色；到达网格边缘时最后一个网格内像素被着色）。射线路径上的每个黑(0)像素被涂为该标记的颜色。
2. 标记像素本身保留原色。灰(5)线段像素保持不变。
3. 若某像素同时处于两条不同颜色标记的射线路径上（两条射线交叉），该像素涂为红(2)。
4. 射线绘制完成后，在由灰(5)线段 + 彩色射线 + 红(2)交叉点 + 网格边缘共同构成的边界中，识别所有完全封闭的 4-连通黑(0)背景区域（不与网格外连通、不含任何非黑像素的连通分量）。
5. 对每个封闭区域，检查其边界上的非灰像素：
   - 若边界射线全部来自同一标记颜色（可含灰段，但非灰射线仅一种颜色）→ 用该标记颜色填充该区域。
   - 若边界射线来自两个或以上不同标记颜色 → 用红(2)填充该区域。
6. 未被封闭的黑(0)背景区域保持不变。

**关键洞察**：射线不是终态装饰，而是结构建材——它们与灰线段共同围合出输入中原本不存在的封闭域。封闭域的填色取决于"哪些标记的射线参与了围合"，需同时理解射线扩展规则和封闭判定规则才能求解。

p = Path("/home/lixinyu/snap/a/key_combo/code/opus/2/010/2.py")
mod = SourceFileLoader("new_arc_task", str(p)).load_module()
sigs = set()
for i in range(100):
    inp = mod.generate_input()
    out = mod.main(inp)
    assert isinstance(inp, np.ndarray)
    assert isinstance(out, np.ndarray)
    assert inp.ndim == 2 and max(inp.shape) <= 30, f"input grid exceeds 30x30: {inp.shape}"
    assert out.ndim == 2 and max(out.shape) <= 30, f"output grid exceeds 30x30: {out.shape}"
    sigs.add(hashlib.md5(inp.tobytes() + str(inp.shape).encode()).hexdigest())
print("variants", len(sigs))
assert len(sigs) >= 20
