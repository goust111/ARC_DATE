## 新题 2：封闭面积排名决定轮廓重涂色

**组合逻辑**：[counting](已有) + [outline_trace](创新：从单轮廓擦除改为多轮廓独立描边) + [recolor](创新：颜色不由标记色决定而由面积排名映射调色板)

**来源原语**：counting、enclosed_bg_region、ordered_arrangement（8ba14f53）；outline_trace、outer_adjacent、erase（aa62e3f4）；recolor（6ffe8f07）

**依赖链**：封闭面积计数 → 产生排名序 → 排名序映射调色板行颜色 → 外轮廓描边提供涂色几何位置 → 两者汇合才能确定最终输出。计数与描边分别提供"涂什么色"和"涂在哪"，缺一不可。

统计多个闭合轮廓各自围住的背景像素数量，按面积升序排名后，擦除原轮廓，用调色板行中对应位次的颜色描绘每个轮廓的外侧等距线。

**输入结构**：约 20x20 网格，黑(0)背景。第 0 行为调色板行，包含 N 个不同颜色的像素从左到右排列（如红(2)、绿(3)、黄(4)、橙(7)），中间用黑(0)分隔，N 等于网格中闭合轮廓的数量。第 1 行起为主区域，包含 N 个蓝(1)闭合轮廓，每个轮廓是一圈一像素宽的封闭环（4-连通闭合曲线），各轮廓互不接触且不接触调色板行，每个轮廓围住的黑色内部面积互不相同（如分别围住 2、5、9 个黑像素）。轮廓形状为不规则多边形（非全为矩形），不同示例中轮廓形状和位置不同。

**规则**：
1. 对每个蓝(1)闭合轮廓，计算其围住的黑(0)像素数量——即轮廓内部不经过轮廓像素就无法 4-连通到达网格边界的黑像素集合的大小。
2. 按围住面积从小到大排列轮廓，产生排名 1、2、...、N。
3. 擦除所有蓝(1)轮廓像素为黑(0)。
4. 对于排名为 k 的原轮廓位置，找到所有原来与该轮廓外侧 4-相邻的黑(0)像素（即轮廓外一圈的背景像素，不包含轮廓内部像素），将这些像素涂为调色板行第 k 个颜色（从左数第 k 个非黑像素）。
5. 调色板行保持不变。网格尺寸不变。

**关键洞察**：调色板颜色的分配不是按轮廓的空间位置（如从左到右）决定的，而是按各轮廓围住的内部面积升序排名决定的；求解者必须对比多个示例才能排除"按位置分配"的错误假设。
