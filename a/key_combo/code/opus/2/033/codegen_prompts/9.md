## 新题 9：障碍截断的轮廓跟随滑动

**组合逻辑**：[slide + contour_adjacency + longest_adjacent_path](创新：在轮廓路径上增加障碍截断条件) + [stop_at_barrier](创新：从行内阻停改为沿轮廓阻停)

**来源原语**：slide、contour_adjacency、longest_adjacent_path、marker_pixel、obstacle_contour（97c75046）；fixed_barrier、stop_at_barrier（9c56f360）

**依赖链**：标记像素沿视线滑向障碍物 → 在着陆点选择两个对角方向 → 沿轮廓行走但遇蓝色障碍像素则截断 → 障碍截断改变了哪个方向是"最长路径" → 标记移至截断后的最长路径终点。障碍像素引入了对基础轮廓跟随规则的修改，可能反转最优方向。

将标记像素沿视线滑向障碍物体后沿外轮廓行走，但轮廓路径上放置的截断障碍可能缩短某方向的有效路径，从而改变标记的最终落点。

**输入结构**：约 15x15 网格，黑(0)背景。一个绿(3) 4-连通障碍区域（约 15-25 像素的不规则形状，非凸）。一个红(2)单像素标记，不与障碍区域接触，但沿水平或垂直方向恰好有一条到障碍区域的直线视线（视线上全为黑(0)背景）。1-2 个蓝(1)单像素截断障碍，放置在绿色障碍区域外轮廓的 4-邻接位置上（即蓝像素与绿区域 4-相邻且蓝像素本身在黑背景上）。不同示例中障碍区域形状、标记位置、蓝色截断像素位置均不同。

**规则**：
1. 找到红(2)标记像素到绿(3)障碍区域的唯一水平或垂直视线方向。
2. 沿该视线方向将标记滑动到障碍区域前最后一个黑(0)像素位置（即视线方向上紧邻绿色区域的黑像素）。
3. 从着陆位置出发，考虑两个沿障碍外轮廓行走的对角方向（保持行走路径上每个像素都与绿色区域 4-相邻，且路径自身在黑背景上）。
4. 沿每个方向行走，逐像素前进。若下一个位置是蓝(1)截断像素或不再与绿色区域 4-相邻或到达网格边缘，则该方向的行走终止。蓝像素本身不算有效路径位置。
5. 比较两个方向的有效行走长度（经过的像素数），选择更长的方向。若等长，选择首步行方向为向上或向左的方向。
6. 将红(2)标记移至选定方向的行走终点。擦除原位置标记。蓝色截断像素保留在输出中。

**关键洞察**：没有蓝色截断障碍时，最长轮廓路径纯粹由障碍物几何决定；但截断障碍可能恰好阻断原本更长的方向，使原本较短的方向反而胜出——求解者必须同时考虑几何轮廓和截断约束。
