## 新题 8：坐标轴距离排序驱动双朝向归一化排列

**组合逻辑**：[sort / distance_ordering](按到坐标轴距离排序) + [normalize_orient + arrange / each_rect_doubled](排序后每个矩形产生水平和垂直两份排列)

**来源原语**：sort / stack / coordinate_axis_line / distance_ordering / axis_color_determines_rotation（来自 291dc1e1）；normalize_orient / arrange / rectangle / width_height_swap / each_rect_doubled（来自 d749d46f）

**依赖链**：坐标轴线的距离度量决定了矩形的排列顺序，而轴线的朝向（蓝线水平还是垂直）决定了双份排列中水平版和垂直版哪个在上、哪个在下。排序和朝向判断都依赖同一对轴线，但提取的信息不同——一个是距离，一个是方向。归一化排列的结果完全取决于排序顺序和上下分配规则，三者不可跳步。

按矩形到两条坐标轴线的距离排序，排序后将每个矩形以水平和垂直两种朝向归一化排列，蓝轴朝向决定哪种朝向排在上半区。

**输入结构**：
- 背景为黑(0)，网格约 15x15
- 两条彩色边线在网格一角相交：一条沿某条边的完整水平线，一条沿垂直边的完整垂直线，相交角的像素为栗(9)。两条线分别为蓝(1)和红(2)，具体哪条是蓝、哪条是红在不同示例中可能不同
- 内部散布 3-5 个实心单色矩形（颜色取自绿(3)、黄(4)、灰(5)、橙(7)、青(8)），各矩形尺寸不同（没有两个矩形的 {宽, 高} 多重集相同）
- 矩形不接触边线，不互相重叠
- 生成约束：矩形到蓝线和红线的距离组合互不相同（不需要 tie-break）；矩形总数和尺寸保证输出不超过 20 列宽

**规则**：
1. 对每个矩形，计算其到蓝(1)线的最短 Manhattan 距离（矩形任意像素到蓝线任意像素的最小 Manhattan 距离）作为主排序键，到红(2)线的最短 Manhattan 距离作为次排序键
2. 按（主键升序，次键升序）排序所有矩形
3. 构建一个 10 行高的输出画布：
   - 若蓝(1)线为水平线：上半区排水平版，下半区排垂直版
   - 若蓝(1)线为垂直线：上半区排垂直版，下半区排水平版
4. 上半区排列：按排序顺序，对每个矩形取水平朝向（min(h,w) 行 x max(h,w) 列），顶部对齐排列，相邻矩形间隔 1 列黑像素
5. 下半区排列：按排序顺序，对每个矩形取垂直朝向（max(h,w) 行 x min(h,w) 列），底部对齐排列，相邻矩形间隔 1 列黑像素
6. 输出宽度为上半区总宽和下半区总宽中的较大值；较窄的半区左对齐
7. 边线、交点像素和原始矩形位置不出现在输出中；每个矩形保持其原色

**关键洞察**：同一对坐标轴线同时提供两种完全不同的信息——距离值（用于排序）和轴朝向（用于决定上下分区的内容）。蓝线从水平变为垂直时，排序键值可能不变（取决于矩形位置），但上下半区的朝向会交换，导致输出结构性地不同。求解者需要跨多个示例才能分离出"距离决定顺序"和"朝向决定分区"这两条独立规则。
