## 新题 6：槽位插入构建封闭体后径向泛洪填充

**组合逻辑**：[insert / rotate](尺寸匹配槽位插入) → [flood_fill + radiate](插入后形成的封闭体内泛洪填充并沿开口辐射)

**来源原语**：insert / rotate / rectangular_block / platform_slot / size_matches_slot / aligned_and_width_matched（来自 67c52801）；flood_fill / radiate / partial_enclosure / obstacle / fill_seed / opening_direction / obstacle_casts_shadow（来自 b9e38dc0）

**依赖链**：浮动矩形块插入平台槽位后，与已有的 U 形墙壁和平台共同围成半封闭区域。这些封闭区域在插入前不存在（墙壁+平台不够封闭）。泛洪填充从封闭区域内的种子像素出发，填满封闭区域并通过开口向外辐射。插入决定了封闭几何体的形状和开口方向，从而决定了填充的范围。

将浮动块按宽度匹配插入平台槽位，插入后与墙壁和平台围成半封闭区域，从种子像素出发泛洪填充并沿开口辐射，障碍物投射阴影阻断辐射。

**输入结构**：
- 背景为黑(0)，网格约 15x18
- 网格底行为灰(5)实心平台（贯穿整行）
- 平台上方一行由灰(5)段和黑(0)间隙交替组成，间隙即为槽位（宽 2-4 像素）；共 2-3 个槽位
- 每个槽位的上方或侧方有绿(3)像素构成的 U 形或 L 形部分墙壁，墙壁一端连接平台或槽位边缘的灰段，另一端悬空形成开口（开口方向为上、左或右之一，不向下因平台已封闭底部）
- 网格上部散布 2-3 个实心单色矩形块（颜色取自蓝(1)、黄(4)、青(8)），每块有一条边长度为 2，另一条边长度等于某个槽位宽度
- 每个槽位旁（在插入后会被封闭的区域内）有一个橙(7)种子像素
- 墙壁开口附近可能有 1-2 个栗(9)障碍像素
- 生成约束：每个块恰好匹配一个槽位（按较短边=2、较长边=槽位宽度匹配）；插入后每个墙壁+插入块+平台恰好形成一个有唯一开口的半封闭区域；种子像素位于封闭区域内部

**规则**：
1. 将每个浮动块与槽位匹配：块的较短边（若非 2 则旋转 90 度使之为 2）对应行数，较长边对应槽位宽度。每个块唯一匹配一个槽位
2. 从原位置擦除块，将旋转后的块（2 行高、槽位宽度宽）底部对齐放入槽位（底边紧贴平台）
3. 插入后：绿墙壁 + 插入的块 + 灰平台共同形成半封闭区域。确定每个封闭区域的开口方向（墙壁未封闭的那一侧）
4. 从每个橙(7)种子像素出发，在封闭区域内做 4-连通泛洪填充，将所有可达的黑像素涂为橙(7)。填充不穿越绿墙壁、灰平台、插入块或栗(9)障碍
5. 填充完封闭区域后，从开口处向外沿开口方向做直线辐射：以开口宽度为带宽，沿开口方向逐行/列扩展橙(7)像素，直到遇到网格边界
6. 栗(9)障碍像素在辐射路径上投射阴影：沿辐射方向，障碍像素正后方 1 像素宽的条带不被填充（阴影从障碍像素背面延伸到辐射终点）
7. 种子像素变为橙色；障碍、墙壁、平台、插入块保持原色不变

**关键洞察**：插入操作不是装饰性的空间移动——它直接创造了泛洪填充所需的拓扑封闭条件。若块插入了错误的槽位，形成的封闭体几何不同，填充范围和辐射方向都会改变。求解者必须理解"插入构建封闭体"这一因果关系，而非将插入和填充视为独立步骤。

## 实现要求

1. `main(grid)` 必须实现新题描述中的确定性转换规则，不能只识别 `generate_input()` 的固定模板。禁止不同的input网格输出相同的output网格。
2. `generate_input()` 必须随机生成多样样例，不能固定死。随机维度应覆盖：网格大小、对象数量、位置、颜色、方向、形状参数或关键分支。注意若描述中存在若干，需实现而不是只有单个，包括object或者对应关系等等。
3. 生成器必须保证输入满足 `main()` 的隐式假设：对象不重叠、不越界、特殊标记唯一或可区分、匹配关系无歧义、关键分支出现概率相同。
4. 禁止把 ARC 颜色 id 、亮度、拼写等当作人类不可见的数值语义参与排序、大小比较或隐藏映射。颜色变化必须有可见结构线索。注意颜色亮度、拼写等也是不可见信息，若描述中出现违规的颜色id或者亮度，可自行使用少量的固定颜色替代，但注意生成时要在三个以内输入输出网格中对所有变换100%覆盖度。
5. 输出样例要视觉清晰，人类必须能从输入输出对中肉眼辨认出规律。具体要求：避免对象粘连、覆盖关系混乱、同一像素多重语义；不同逻辑步骤产生的结果不要大面积层叠在一起导致无法分辨哪个颜色属于哪个步骤；输入中各元素之间保持足够间距，输出中新增的标记/填充/路径等应与背景和已有元素在颜色上有明显区分；若规则涉及多层叠加，生成时控制对象密度和尺寸，确保叠加区域只占少数像素而非铺满整个网格。
6. 若规则有多个分支，生成器不能长期固定成一个分支；应让分支在随机样例中合理出现。分支概率不必平均——难以发现的隐蔽分支（如少数情况下才触发的特殊规则）应适当提高出现概率，确保在 3 个训练示例中至少出现一次，否则求解者无法归纳该规则。对于颜色映射类规则，确保 2 个左右的示例即可覆盖所有映射关系（每种颜色→颜色的映射至少在某个示例中出现过）。
