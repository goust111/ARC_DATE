## 新题 1：拓扑封闭门控象限涂色

**组合逻辑**：[flood_fill](创新：用于拓扑封闭性检测而非直接涂色) + [split](象限划分) + [recolor](角标驱动涂色)

**来源原语**：flood_fill / enclosed_region / topological_in_out（来自 00d62c1b）；split / quadrant / diag_marker / corner_correspond（来自 e9ac8c9e）；recolor（来自 e9ac8c9e, 8dae5dfc）

**依赖链**：泛洪填充从网格边界向内标记所有可达的黑(0)像素，未被标记的黑像素即为被绿(3)边界拓扑封闭的区域——这一步决定了哪些区域参与后续处理。只有被封闭的矩形区域才被四等分并用对角标记像素指定的颜色涂色；未封闭的绿形状是干扰项，不处理。封闭检测的结果直接过滤了象限涂色的作用域。

将被绿色边界拓扑封闭的矩形黑区识别出来，四等分后用其外侧四角的标记像素颜色分别涂色。

**输入结构**：
- 背景为黑(0)，网格约 20x20
- 网格中有 2-4 个由绿(3)像素构成的闭合或非闭合形状。闭合形状为绿像素沿 4-连通路径围成的封闭环，内部围出一个矩形黑区域（宽、高均为偶数，至少 4x4）。非闭合形状为绿像素构成的开放曲线或断裂环（有至少一个缺口），不围出封闭区域
- 每个闭合绿边界的外接矩形（bounding box）的四个对角位置各有一个标记像素，位于对角外侧 1 格处（即 bounding box 左上角的左上方、右上角的右上方、左下角的左下方、右下角的右下方各 1 像素）。四个标记像素颜色互不相同，取自蓝(1)、红(2)、黄(4)、灰(5)、品红(6)、橙(7)、青(8)
- 非闭合形状没有标记像素
- 生成约束：各绿形状及其标记像素互不重叠；闭合区域的内部矩形宽高为偶数以确保四等分无余数；标记像素不与任何绿像素或其他标记像素相邻

**规则**：
1. 从网格四条边上所有黑(0)像素出发做泛洪填充（4-连通），标记所有可达的黑像素为"外部"
2. 未被标记的黑像素即为"封闭内部"像素。将每个 4-连通的封闭内部区域识别为一个封闭矩形区域
3. 对每个封闭区域，找到包围它的绿边界的 bounding box（绿边界像素的最小外接矩形），在该 bounding box 四对角外侧 1 格处读取标记像素颜色
4. 将封闭内部矩形沿水平和垂直中线四等分为左上、右上、左下、右下四个象限
5. 用左上对角标记色填充左上象限，右上标记色填充右上象限，左下标记色填充左下象限，右下标记色填充右下象限
6. 绿边界像素保持不变；标记像素设为黑(0)（移除）；非闭合绿形状及其周围区域不做任何修改
7. 多个封闭区域的处理顺序不影响结果（它们互不重叠）

**关键洞察**：绿色边界同时承担两个角色——判断封闭性（拓扑检测的材料）和定位标记像素（提供 bounding box 以定位对角标记）。非闭合绿形状是专门设计的干扰项：它们在视觉上与闭合形状相似，但因缺口的存在，其内部黑像素可从外部泛洪到达，因此不参与涂色。求解者必须先正确实现拓扑封闭检测，才能知道哪些区域该被处理。
