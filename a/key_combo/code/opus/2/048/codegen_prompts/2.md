## 新题 2：降噪压缩揭示隐藏分隔墙与极值区域涂色

**组合逻辑**：[降噪+压缩](已有原语组合使用，但创新在于压缩结果中涌现出原图中不可见的分隔墙结构) → [墙分隔区域](创新：分隔墙不是显式给出的，而是压缩后涌现的) → [极值面积重涂色](已有原语，但作用在压缩后的涌现结构上)

**来源原语**：压缩/compress(参考题 5614dbcf)、降噪/denoise(参考题 5614dbcf)、忽略标记取主色/ignore_marker_dominant(参考题 5614dbcf)、网格分块/grid_partitioning(参考题 5614dbcf)、分隔墙/partition_wall(参考题 62ab2642)、连通区域/connected_region(参考题 62ab2642)、墙分隔区域/wall_partitions_regions(参考题 62ab2642)、极值面积决定颜色/extreme_area_determines_color(参考题 62ab2642)、重涂色/recolor(参考题 62ab2642)

**依赖链**：原图是一个大网格，由 3x3 块构成，每块含灰噪声像素。压缩时，纯灰+背景块变为灰像素，带主色块变为主色像素。压缩后灰像素恰好形成一像素宽的分隔墙，将非灰像素分割成若干连通区域。只有在正确压缩之后才能看到分隔墙结构；只有正确分区后才能比较面积并涂色。

将含噪声的大网格压缩为小网格后，灰色压缩块涌现为分隔墙，将非灰区域分隔成多个连通区域，再对最小和最大区域分别涂色。

**输入结构**：黑(0)背景，约 18x18 网格（行列数均为 3 的倍数，形成 6x6 的 3x3 块阵列）。每个 3x3 块要么是"结构灰块"（9 格全为灰(5)或黑(0)+灰(5)混合，无其他前景色），要么是"彩色块"（包含一种非黑非灰的主色占至少 7 格，其余 1~2 格为灰(5)噪声）。彩色块的主色从蓝(1)、红(2)、绿(3)中选取。结构灰块在压缩后形成连通的一像素宽的墙网络（无死端、无孤立灰像素），将彩色压缩像素分成 3~5 个 4-连通区域。生成约束：最小区域和最大区域各唯一（面积无并列）。

**规则**：
1. 对每个 3x3 块取主色：若块中存在非黑(0)、非灰(5)的颜色，则该块压缩为该颜色的单像素；否则该块压缩为灰(5)单像素。
2. 在压缩后的 6x6 网格中，灰(5)像素构成分隔墙。找出所有被灰墙分隔的 4-连通非灰区域。
3. 将面积最小的非灰区域中所有像素重涂为橙(7)。
4. 将面积最大的非灰区域中所有像素重涂为青(8)。
5. 其余非灰区域保持各自压缩后的原色。灰墙像素不变。
6. 输出即为该 6x6 网格。

**关键洞察**：分隔墙在原始 18x18 网格中并不可见——它们是分散的灰色噪声块，只有压缩后才涌现为连贯的墙结构。求解者必须先理解压缩规则，才能"看到"分隔墙，进而才能分区并找极值。
