## 新题 4：跨分隔线计数比较决定是否逐对象颜色互换

**组合逻辑**：[计数/counting + 两区域比较/region_comparison](已有) → [颜色互换/color_swap](创新：互换不再对所有对象统一执行，而是由跨区域计数比较的结果逐对象有条件触发)

**来源原语**：计数、选择、两区域比较、最大增长差、横分隔线（8597cfd7）；颜色互换、对象内双色配对、同对象内互换（45737921）

**依赖链**：灰线划分上下区域 → 对应对象配对 → 逐对象统计上下区域中两种颜色的像素比例 → 比例是否翻转决定下方对象是否执行颜色互换 → 输出仅包含（可能被互换的）下方对象。配对需要空间定位；互换判断需要跨区域计数；最终输出需要互换操作。三步不可分离。

比较分隔线上下对应对象中的双色比例，比例翻转的对象执行颜色互换，输出下半区。

**输入结构**：约 13x10 的黑(0)背景网格。一条全宽灰(5)水平分隔行位于网格正中。上半区和下半区各包含相同数量（2~4 个）的 4-连通矩形对象，每个对象为 3x3，由恰好两种非背景非灰前景色构成（例如蓝(1)和绿(3)）。上下对应对象的位置在各自半区中相同（即上半区第 r 行第 c 列的对象与下半区第 r 行第 c 列的对象对应）。对应对象使用相同的两种颜色，但两种颜色的像素数分配可能不同。例如上方对象中蓝(1)占 6 像素、绿(3)占 3 像素，而下方对应对象中蓝(1)占 4 像素、绿(3)占 5 像素（比例翻转了）。生成约束：至少一个对应对出现比例翻转，至少一个对应对不翻转；每个对象内两种颜色像素数均 >= 1 且不相等。

**规则**：
1. 识别灰(5)水平分隔行，将网格分为上半区和下半区。
2. 在上半区和下半区分别检测所有 3x3 的双色对象，按对象中心在半区内的 (行, 列) 坐标配对。
3. 对每对对应对象：设上方对象中颜色 A 的像素数为 U_A、颜色 B 的像素数为 U_B；下方对象中颜色 A 的像素数为 D_A、颜色 B 的像素数为 D_B。若上方多数色与下方多数色不同（即 U_A > U_B 但 D_A < D_B，或反之），则标记该对象为"翻转"。
4. 对标记为"翻转"的下方对象，将其内的颜色 A 像素全部替换为颜色 B、颜色 B 像素全部替换为颜色 A。未标记的下方对象保持不变。
5. 输出仅包含下半区（裁剪掉灰线和上半区），尺寸为原网格高度的一半 x 原网格宽度。

**关键洞察**：颜色互换不是全局的——每个对象是否互换由该对象自身的跨区域计数比较独立决定。上半区不出现在输出中，它纯粹作为比较基准存在。仅看下半区无法判断哪些对象被互换了，必须参照上半区。

6. 若规则有多个分支，生成器不能长期固定成一个分支；应让分支在随机样例中合理出现。分支概率不必平均——难以发现的隐蔽分支（如少数情况下才触发的特殊规则）应适当提高出现概率，确保在 3 个训练示例中至少出现一次，否则求解者无法归纳该规则。对于颜色映射类规则，确保 2 个左右的示例即可覆盖所有映射关系（每种颜色→颜色的映射至少在某个示例中出现过）。
