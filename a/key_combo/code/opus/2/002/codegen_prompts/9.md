## 新题 9：按封闭孔洞数排序裁剪后拼接精灵体

**组合逻辑**：[裁剪/crop + 重涂色/recolor + 最近邻匹配/nearest_neighbor_matching](已有) → [计数/counting](创新：计数对象不是像素而是封闭的拓扑孔洞) → [排序/sorting](创新：排序依据不是包围盒高度或空间位置，而是拓扑属性) → [拼接/pack](已有)

**来源原语**：裁剪、重涂色、最近邻匹配、重复精灵体、标记像素、拼接、标记主轴方向排列（50aad11f）；封闭区域（6e453dd6）；排序、计数、按高度排列（b7999b51）

**依赖链**：检测封闭孔洞（需要理解拓扑连通性）→ 每个精灵体的孔洞数作为排序键 → 排序决定拼接顺序 → 标记颜色决定重涂色 → 裁剪后按排序顺序拼接输出。孔洞计数 → 排序 → 拼接构成主链；标记匹配 → 重涂色为并行信息流，两者在最终拼接处汇合。

将每个精灵体按其封闭孔洞数从少到多排序，重涂为最近标记色后拼接输出。

**输入结构**：约 15x15 的黑(0)背景网格。3~5 个同色（如橙(7)）的 4-连通精灵体散布在网格上，互不相邻。每个精灵体的像素数在 8~20 之间，形状各异——关键区别在于：有的精灵体没有封闭的黑(0)孔洞（如实心块），有的有 1 个孔洞（如环形），有的有 2 个孔洞（如"8"字形或双环）。每个精灵体附近（曼哈顿距离最近）有一个单像素标记，标记颜色各不相同（从蓝(1)、红(2)、绿(3)、黄(4)中选取）。生成约束：每个精灵体的封闭孔洞数互不相同（如 0, 1, 2）；标记与最近精灵体的配对无歧义（每个标记离恰好一个精灵体最近）。

**规则**：
1. 识别所有橙(7)的 4-连通精灵体。对每个精灵体，计算其包围盒内被该精灵体完全 4-连通包围的黑(0)封闭区域数（孔洞数）。判断标准：一个黑(0)的 4-连通分量如果不与包围盒外部的黑(0)像素相连，则为封闭孔洞。
2. 将每个标记像素匹配到曼哈顿距离最近的精灵体。
3. 裁剪每个精灵体至其包围盒。将裁剪后精灵体中所有橙(7)像素替换为其匹配标记的颜色。孔洞内的黑(0)像素保持黑色。
4. 按封闭孔洞数从小到大排序（0 孔洞的排最前，1 孔洞的次之，依此类推）。
5. 将排序后的裁剪精灵体从左到右水平拼接，相邻精灵体之间间隔 1 列黑(0)。垂直方向顶部对齐，不足部分用黑(0)填充。

**关键洞察**：在 50aad11f 中拼接顺序由标记的空间位置主轴决定；在 b7999b51 中排序依据是包围盒高度。这里排序依据是拓扑属性——封闭孔洞数，这需要对每个精灵体进行连通性分析，而非简单的几何测量。拓扑分析结果决定了空间排列顺序，两种截然不同层次的分析（拓扑 vs. 空间布局）被耦合在一起。
