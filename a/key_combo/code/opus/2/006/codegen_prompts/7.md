## 新题 7：面积分级的自相似展开

**组合逻辑**：[counting/area_filtering](已有) → [crop](已有) → [recursive_expand/self_similar_sub](创新：种子掩码和间隔填充色不来自边界图例，而由面积排名前两位的物体分别提供)

**来源原语**：counting、area_filtering、connected_component、ignore_distractors（a3325580）；recursive_expand、seed_mask、self_similar_sub、fg_bg_separate（58c02a16）；crop（2d0172a1）

**依赖链**：不计算面积就无法确定哪个物体充当种子、哪个提供间隔色；不裁剪最大物体就得不到种子掩码；不展开就缺少输出结构。第三名及更小的物体是干扰项，但必须计算它们的面积才能确认前两名的排名。

从多个不同大小的物体中，按面积选出最大者作为自相似种子掩码、次大者提供间隔填充色，执行一轮分形展开。

**输入结构**：黑(0)背景，约14x14网格。3~5个不同颜色的4-连通单色前景物体，面积（像素数）各不相同，取值范围3~12像素。每个物体颜色唯一，取自蓝(1)、红(2)、绿(3)、黄(4)、橙(7)等。物体之间互不接触、互不嵌套。生成约束：面积最大物体的边界框尺寸不超过5x5（保证展开后输出不超过25x25）；所有物体面积两两不同。

**规则**：
1. 计算每个前景4-连通单色物体的面积（像素数）。
2. 面积最大的物体：裁剪其边界框得到种子掩码M（尺寸HxW），其中该物体颜色C1的像素为前景，黑(0)为背景。
3. 面积第二大的物体：记录其颜色C2。
4. 执行一轮自相似替换：创建(H*H)行 x (W*W)列的输出网格。对种子掩码M中第r行第c列的格子（0起始）：若为前景(C1)，在输出的第(r*H)至第((r+1)*H-1)行、第(c*W)至第((c+1)*W-1)列放置种子掩码M的一个副本（前景像素用C1，背景像素用黑(0)）；若为背景(黑(0))，在对应区域填充纯色C2。
5. 其余物体（第三名及以下）全部丢弃，不出现在输出中。

**关键洞察**：两个面积排名不同的物体承担完全不同的角色——大者贡献"形状基因"（种子掩码），次大者仅贡献"颜色基因"（间隔填充色）。第三名及以下虽不参与输出，但必须被识别和排除才能确认前两名。
