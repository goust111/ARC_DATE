## 新题 11：颜色查表替换与滑动定位的组合放置

**组合逻辑**：[查表替换/颜色决定输出](创新：查表结果不是最终输出，而是需要放置到指定位置) + [滑动/移动并变色](创新：滑动方向由输入空间关系决定，滑动距离由面积匹配决定) + [擦除](已有)

**来源原语**：查表替换/前景颜色编码/固定符号/颜色映射符号/颜色决定输出/忽略干扰项(d4469b4b)、滑动/移动并变色/前景对象(a79310a0)、面积匹配(7acdf6d3)、擦除(7acdf6d3)、孤立像素/指示像素(b775ac94/1bfc4729)

**依赖链**：每个色块的颜色查表得到对应符号→色块旁的指示像素确定滑动方向→色块到目标框的距离由面积匹配间接确定（符号面积等于框面积时即为目标框）→将符号放入匹配框后擦除原始色块和指示像素。查表、方向判断和面积匹配三条线汇聚在最终放置操作上。

每个色块通过颜色查表变为对应符号，再按指示像素方向滑动到面积匹配的目标空框中。

**输入结构**：黑(0)背景，约 16x16。网格中有 2-3 个单色矩形色块（3x3 至 4x4 不等），颜色分别为红(2)、蓝(1)、绿(3)中的不同颜色。每个色块有一个与该色块同色的单像素指示像素，位于色块外部、与色块某一边 4-邻接（上、下、左或右之一），标示滑动方向（指示像素所在方向即为滑动方向）。网格中另有 2-3 个灰(5)空心矩形框（1 像素宽边框围成的矩形，内部为黑色），各框内部面积（被围合的黑像素数）各不相同。颜色到符号的映射：红(2)→十字形（3x3，中心行和中心列全填，角像素空）、蓝(1)→X 形（3x3，四角和中心填，边中空）、绿(3)→口字形（3x3，外圈全填，中心空）。每个符号占据的像素数分别为：十字 = 5，X = 5，口 = 8。生成约束：每个灰框的内部面积恰好等于某一种符号的像素数（5 或 8），且匹配是唯一的一一对应；指示像素方向指向的方向上该色块与其匹配框之间无障碍物；色块与灰框不重叠。

**规则**：
1. 对每个色块，根据颜色查表获取对应符号（红→十字，蓝→X，绿→口）。符号像素颜色使用灰(5)。
2. 计算每个符号的像素数。计算每个灰框的内部面积。将每个符号与内部面积等于该符号像素数的唯一灰框配对。
3. 确定每个色块的指示像素方向（指示像素在色块的上/下/左/右）。
4. 擦除原始色块和指示像素（变为黑(0)）。
5. 将查表得到的符号放置在配对灰框的中心位置（符号中心与框内部区域中心对齐）。符号像素涂灰(5)。灰框边框保持灰(5)不变。
6. 若符号比框的内部小，剩余内部保持黑(0)。

**关键洞察**：颜色同时编码了两件事——"变成什么形状"和"放到哪个框里"（通过形状像素数与框面积匹配）。指示像素提供方向信息但实际放置位置由面积匹配决定，形成"方向线索+数值匹配"的双重确认。

import numpy as np

p = Path("/home/lixinyu/snap/a/key_combo/code/opus/2/027/11.py")
mod = SourceFileLoader("new_arc_task", str(p)).load_module()
sigs = set()
for i in range(100):
    inp = mod.generate_input()
    out = mod.main(inp)
    assert isinstance(inp, np.ndarray)
    assert isinstance(out, np.ndarray)
    assert inp.ndim == 2 and max(inp.shape) <= 30, f"input grid exceeds 30x30: {inp.shape}"
    assert out.ndim == 2 and max(out.shape) <= 30, f"output grid exceeds 30x30: {out.shape}"
    sigs.add(hashlib.md5(inp.tobytes() + str(inp.shape).encode()).hexdigest())
print("variants", len(sigs))
assert len(sigs) >= 20
