## 新题 9：轮廓内腔面积与虚线间隙计数互验激活双向填充

**组合逻辑**：[面积匹配/像素数等于腔面积](创新：匹配对象从源像素变为间隙计数) + [单像素间隙补填](创新：补填条件不再是局部判断，而由远端面积匹配触发) + [填充](创新：轮廓填充与间隙补填双向联动)

**来源原语**：轮廓对象/行内腔/面积匹配/像素数等于腔面积(7acdf6d3)、填充(7acdf6d3)、虚线段/单像素间隙补填/邻接(a699fb00)、计数(e681b708/7acdf6d3)、擦除(7acdf6d3)、重涂色(多源)

**依赖链**：统计每条虚线段的间隙数→计算每个轮廓的内腔面积→匹配间隙数等于内腔面积的"虚线-轮廓"配对→匹配成功则双向操作：补填该虚线的间隙 + 填充该轮廓的内腔。匹配是双向的桥梁，缺少任何一侧的计数都无法确定配对关系。

统计虚线间隙数与轮廓内腔面积，匹配相等的配对后同时补填间隙和填充内腔。

**输入结构**：黑(0)背景，约 16x16。网格中有 3-4 个灰(5)轮廓对象（8-连通闭合环形，由灰色像素围成，内部为黑色空腔），各轮廓大小不同（内腔面积分别为不同的值，如 3、5、7 等）。轮廓之间的空白区域中有 3-4 段水平蓝(1)虚线段（蓝像素以 1 个黑像素间隔排列），每段长度不同，使得各段的间隙数（黑色间隔数）各不相同。生成约束：轮廓和虚线段不重叠、不邻接；恰好存在若干对"间隙数 = 内腔面积"的匹配（至少 2 对），且至少有 1 个轮廓和 1 段虚线段无法匹配（保证不是全匹配）；每个轮廓至多匹配一段虚线，每段虚线至多匹配一个轮廓（一一匹配）。

**规则**：
1. 对每个灰(5)轮廓对象，计算其行内腔面积：对轮廓占据的每一行，统计该行上严格位于最左灰像素和最右灰像素之间的黑(0)像素数，所有行求和即为内腔面积 A。
2. 对每段蓝(1)虚线段，统计其间隙数 G：该段中左右邻居均为蓝(1)的黑(0)像素总数。
3. 建立匹配：若某轮廓的 A 等于某虚线段的 G，则它们配对。按从上到下、从左到右的顺序处理轮廓，每个轮廓匹配尚未被匹配的、G 值相等的虚线段中最上方的一段。
4. 对每个已匹配的轮廓：将其内腔所有黑(0)像素填充为蓝(1)。
5. 对每段已匹配的虚线段：将其间隙（左右邻蓝的黑像素）填充为灰(5)。
6. 未匹配的轮廓和虚线段保持不变。灰色轮廓像素和蓝色虚线像素本身不变。

**关键洞察**：间隙数和内腔面积是两种看似无关的几何量，它们的数值相等建立了跨类型的配对关系。补填和填充互为对方激活的结果，体现了"锁与钥匙"的双向验证。

p = Path("/home/lixinyu/snap/a/key_combo/code/opus/2/027/9.py")
mod = SourceFileLoader("new_arc_task", str(p)).load_module()
sigs = set()
for i in range(100):
    inp = mod.generate_input()
    out = mod.main(inp)
    assert isinstance(inp, np.ndarray)
    assert isinstance(out, np.ndarray)
    assert inp.ndim == 2 and max(inp.shape) <= 30, f"input grid exceeds 30x30: {inp.shape}"
    assert out.ndim == 2 and max(out.shape) <= 30, f"output grid exceeds 30x30: {out.shape}"
    sigs.add(hashlib.md5(inp.tobytes() + str(inp.shape).encode()).hexdigest())
print("variants", len(sigs))
assert len(sigs) >= 20
