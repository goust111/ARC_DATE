## 新题 1：旋转重划区后按标记多数色填充

**组合逻辑**：[旋转](创新：旋转改变区域划分而非单纯变换形状) + [洪泛填充](已有) + [计数→多数标记色涂色](创新：从墙壁邻接场景移植到旋转后区域场景)

**来源原语**：旋转/中心点不变/朝向交换长度保持(f0f8a26d)、洪泛填充/区域邻接(e681b708)、计数/多数标记色涂色(e681b708)、标记像素(e681b708)、重涂色(多源)

**依赖链**：旋转改变了条状障碍物的朝向，从而改变了背景被分割成的区域形状和数量；洪泛填充依赖旋转后的新区域边界；每个区域内的标记像素数量决定填充色，而哪些标记落入哪个区域又取决于旋转后的边界位置。三步环环相扣。

将灰色薄条旋转 90 度后重新划分背景区域，再按各区域内彩色标记的多数色填充该区域。

**输入结构**：黑(0)背景，约 15x15。网格中散布 4-6 根灰(5)单像素宽条（1-cell-thick），长度为奇数（3-7 像素），有的水平有的竖直，彼此不相交、不相邻。网格中另有 8-14 个孤立单像素标记，颜色为红(2)、蓝(1)或绿(3)，每种颜色至少 2 个，分布在条之间的空白区域中，不与任何条 4-邻接。生成约束：旋转后所有条仍在网格范围内且彼此不重叠、不相邻；旋转后形成的 4-连通背景区域至少 3 个；每个含标记的区域中存在唯一多数色（无平局）。

**规则**：
1. 将每根灰(5)条绕其中心像素旋转 90 度（水平变竖直、竖直变水平），长度和颜色不变。超出网格边界的部分舍弃（生成时保证不会发生）。
2. 将旋转后的灰条视为障碍物，对剩余黑(0)像素做 4-连通洪泛填充，划分出若干独立的背景区域。标记像素不作为障碍物，归入其所在的背景区域。
3. 对每个区域，统计其中各颜色标记像素的数量。若某区域包含标记像素，将该区域所有背景像素填充为该区域中数量最多的标记颜色。标记像素本身保持原色不变。
4. 不含任何标记的区域保持黑(0)不变。
5. 灰(5)条保持旋转后的位置和颜色。

**关键洞察**：必须先完成旋转才能确定区域边界，而标记像素的归属完全由旋转后的边界决定——同一标记在旋转前后可能属于不同区域，因此不能跳过旋转步骤直接计数。
