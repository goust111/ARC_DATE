## 新题 6：拉丁方补全与邻接桥接双约束

**组合逻辑**：[补全/completion + 拉丁方约束/latin_square_constraint](已有) ⊗ [连线/bridge_drawing + 访问顺序编码/visitation_order_encoding](创新：控制序列不再编码访问路径，而是编码邻接约束用于消歧) —— 注意 ⊗ 表示同时约束满足，非顺序执行

**来源原语**：补全+拉丁方约束+行列唯一约束+色表+空白单元(4cd1b7b2), 桥接连线+带框方块+控制序列+访问顺序编码+行列对齐+最近优先(3e6067c3)

**依赖链**：拉丁方行列唯一性提供必要约束但不充分消歧（多个合法补全）；控制序列编码的邻接要求提供额外约束，将合法解收窄为唯一解（删除控制序列则解不唯一）；桥接线的绘制依赖补全后的颜色分布（删除补全则无法确定哪些方块同色相邻）。两个约束系统同时作用才能确定唯一输出。

在 NxN 带框方块阵列中，部分方块内色缺失。仅靠拉丁方约束存在多解；底部控制序列编码了一条颜色邻接路径，额外约束使补全唯一确定。补全后沿控制路径在相邻方块间画桥。

**输入结构**：
- 网格约 22x22，背景黑(0)。
- 上方主区域：NxN（N=4 或 5）个带框方块排列成规则阵列。每个方块由灰(5)边框（1 像素宽）围成，内部为 3x3 至 4x4 的区域。方块之间间隔 1 像素黑色间隙。
- 部分方块的内部填充了一种前景色（取自 N 色调色板，例如 N=4 时为蓝(1)、红(2)、绿(3)、黄(4)）；其余方块内部全为黑(0)（空白）。
- 已填充的方块满足拉丁方行列约束（每种颜色在每行每列至多出现一次），但空白方块有 2-4 个，且仅靠拉丁方约束至少存在两种合法补全。
- 下方控制行（在主阵列下方，间隔 2 行黑色）：一行 N 个彩色像素，从左到右依次为 c1, c2, ..., cN，颜色取自同一调色板，恰好是 N 种颜色的一个排列。
- 生成约束：恰好有一种补全方案同时满足拉丁方约束和控制序列邻接约束（下述规则 2）。

**规则**：
1. 将 NxN 方块阵列视为一个 NxN 颜色矩阵。保持所有已填充方块不变，将黑色空白方块填充为某种调色板颜色，使得每一行和每一列恰好包含 N 种颜色各一次（拉丁方约束）。
2. 额外约束：读取控制序列 c1, c2, ..., cN。对每对相邻颜色 (ci, ci+1)（i=1..N-1），在 NxN 矩阵中，颜色为 ci 的方块与颜色为 ci+1 的方块必须在阵列中正交相邻（上下或左右紧邻，即矩阵坐标的曼哈顿距离为 1）。
3. 找到同时满足以上两条约束的唯一补全方案，填充所有空白方块。
4. 对每对控制序列相邻颜色 (ci, ci+1)，在 NxN 阵列中找到对应的两个正交相邻方块，用颜色 ci 填充两方块灰色边框之间的 1 像素间隙（绘制桥接线）。
5. 输出整个网格（含方块阵列、桥接线和控制序列行）。

**关键洞察**：这是同时约束满足结构，非线性流水线。拉丁方约束（来自 4cd1b7b2）和邻接路径约束（来自 3e6067c3 的控制序列）必须同时被满足才能消歧。单独使用任一约束都无法确定唯一解。桥接线的绘制是约束满足的可视化结果，而非独立步骤。
