## 新题 1：标记色链式对接装配

**组合逻辑**：[颜色配对/color_pairing](创新：从"标记色→孤立控制点"改为"标记色→另一精灵体色"的跨精灵配对) → [链式连接排序/chaining_by_edge_contact](创新：链接依据从边缘像素位置匹配改为跨精灵颜色匹配) → [对接拼合/docking](已有) → [重涂色/recolor](已有：连接点融入体色)

**来源原语**：颜色配对(54dc2872), 链式连接排序(78332cb0), 对接拼合+连接点颜色匹配(20270e3b), 重涂色(1d61978c)

**依赖链**：跨精灵标记色→体色配对决定链接顺序（无此配对则无法排序）；链接顺序决定对接方向和平移量（无顺序则无法组装）；连接点位置对齐决定物理拼合点（无连接点则无法对齐）；拼合后连接点重涂为体色完成融合。四者缺一不可。

将散布的多色精灵体按"前一精灵的嵌入标记色 = 后一精灵的体色"规则链式排序，然后沿连接点对齐方向依次对接拼合为一条完整条带，连接点融入体色。

**输入结构**：
- 网格约 20x20，背景黑(0)。
- 网格中散布 4-5 个 4-连通多色精灵体，每个精灵体由 5-8 个像素构成，形状各异（不规则，非特定几何形状）。
- 每个精灵体包含三种像素：(a) 体色像素（占多数，如蓝(1)、红(2)、绿(3)、黄(4)中的一种，每个精灵体体色不同）；(b) 一个嵌入标记像素（颜色与体色不同，等于另一个精灵体的体色）；(c) 一个品红(6)连接点像素，位于精灵体边界框的左边缘或右边缘上。
- 恰好有一个精灵体的体色不被任何其他精灵体的标记色引用（链头），恰好有一个精灵体的标记色不等于任何其他精灵体的体色（链尾），形成唯一线性链。
- 各精灵体之间互不接触，至少间隔 2 个像素。
- 生成约束：每个精灵体的连接点像素在其边界框的左边缘或右边缘上各恰好一个；链中相邻两个精灵体的连接点像素在各自边界框内的行偏移量（相对于边界框顶部的行距）相同，以保证对接时能水平对齐。

**规则**：
1. 识别每个精灵体的体色（该精灵体中出现次数最多的非黑(0)、非品红(6)颜色）和嵌入标记色（精灵体内唯一的非体色、非品红(6)、非黑(0)像素的颜色）。
2. 建立链序：找到体色不被任何其他精灵体标记色引用的精灵体作为链头。从链头开始，下一个精灵体是体色等于当前精灵体标记色的那一个。依此递推直至所有精灵体排入链中。
3. 水平组装：将链头精灵体裁剪为其边界框，放置在输出的最左侧。对链中的下一个精灵体，裁剪为其边界框，将其左边缘连接点像素对齐到前一精灵体右边缘连接点像素的右侧紧邻位置（同一行），使两个连接点像素水平相邻。依次拼接所有精灵体。
4. 拼合完成后，将所有品红(6)连接点像素重涂为其所属精灵体的体色。
5. 输出为包含拼合条带的最小边界框裁剪。

**关键洞察**：链的排列顺序既非空间位置决定，也非边缘像素几何匹配决定，而是由跨精灵体的"标记色 = 另一精灵体体色"这一颜色配对关系唯一确定——这是源题中不存在的结构关系。

p = Path("/home/lixinyu/snap/a/key_combo/code/opus/2/032/1.py")
mod = SourceFileLoader("new_arc_task", str(p)).load_module()
sigs = set()
for i in range(100):
    inp = mod.generate_input()
    out = mod.main(inp)
    assert isinstance(inp, np.ndarray)
    assert isinstance(out, np.ndarray)
    assert inp.ndim == 2 and max(inp.shape) <= 30, f"input grid exceeds 30x30: {inp.shape}"
    assert out.ndim == 2 and max(out.shape) <= 30, f"output grid exceeds 30x30: {out.shape}"
    sigs.add(hashlib.md5(inp.tobytes() + str(inp.shape).encode()).hexdigest())
print("variants", len(sigs))
assert len(sigs) >= 20
