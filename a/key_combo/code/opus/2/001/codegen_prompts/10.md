## 新题 10：旋转匹配定向链式延伸

**组合逻辑**：[模板匹配+旋转](碎片与模板的旋转匹配确定匹配角度) + [链式填充](匹配角度编码链延伸方向) + [重建](先补全碎片再延伸)（创新：旋转角度不仅用于几何校正，同时编码链式填充的方向指令——同一参数的双重语义）

**来源原语**：旋转(rotate) ← 6aa20dc0/1b60fb0c；模板匹配(template_match) ← 6aa20dc0；缩放旋转对齐碎片(scale_rotate_align_frag) ← 6aa20dc0；碎片(fragment) ← 6aa20dc0；链式填充(chain_fill) ← 16b78196；重建(rebuild) ← c61be7dc

**依赖链**：碎片匹配确定旋转角度 -> 旋转角度同时用于补全碎片形状和确定链延伸方向 -> 链式填充沿确定方向放置旋转后模板副本。旋转角度承担双重职责，跳过匹配则既无法补全碎片也无法确定方向。

识别每个碎片是多色模板哪个旋转版本的部分残片，补全碎片后沿旋转角度编码的方向链式延伸模板副本直至网格边界。

**输入结构**：网格约 18x18，背景黑(0)。网格一角有一个完整的多色模板（约 3x4 至 4x3，包含 2-3 种非黑颜色，非对称以确保旋转版本可区分）。网格中散布 2-4 个碎片，每个碎片是模板某个旋转版本（0/90/180/270 度）的部分像素子集（保留 40%-70% 的非黑像素，颜色与旋转后模板一致）。碎片之间互不重叠，且与模板不重叠。生成约束：每个碎片仅匹配一个旋转角度（碎片的非黑像素是且仅是该旋转版本的子集）；从每个碎片位置沿编码方向延伸至少能放置 1 个完整副本才到达网格边界。

**规则**：
1. 识别完整模板：包含最多不同颜色的非黑 4-连通对象。
2. 对每个碎片（其余非黑 4-连通对象），尝试模板的 4 个旋转版本（0/90/180/270 度顺时针），找到使碎片的所有非黑像素位置和颜色均为旋转模板对应位置子集的唯一旋转角度。碎片的边界框左上角与旋转模板的边界框左上角对齐进行比较。
3. 旋转角度编码链延伸方向：0 度 -> 向右延伸，90 度 -> 向下延伸，180 度 -> 向左延伸，270 度 -> 向上延伸。
4. 先补全碎片：将碎片位置处的旋转模板完整绘制（补上碎片缺失的像素）。
5. 从补全后的碎片位置开始，沿编码方向链式放置旋转模板的完整副本：下一个副本的边界框紧接前一个副本的边界框（在延伸方向上无间隙相邻）。持续放置直到下一个副本的边界框会超出网格边界时停止。
6. 保持原始模板不变。不同碎片的链互相独立，若链与链之间有重叠，后处理的碎片（按碎片边界框左上角行优先排序，较大者后处理）覆盖先处理的。

**关键洞察**：旋转角度具有双重语义——它既是几何校正参数（用于补全碎片），又是方向指令（决定链延伸方向）。求解者需要意识到这一参数的双重用途，并从多个碎片的不同旋转角度和不同延伸方向中归纳出角度-方向的对应规则。
