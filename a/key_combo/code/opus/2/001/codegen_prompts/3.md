## 新题 3：整数降采样揭示隐藏旋转对称

**组合逻辑**：[降采样](揭示块状图案的小尺度结构) + [对称补全](在降采样层面检测并补全旋转对称缺失) + [像素放大+重涂色](将缺失块映射回原尺度并标记新色)（创新：对称性隐藏在整数缩放之下，须跨尺度推理）

**来源原语**：降采样(downsample) ← 6ecd11f4；整数缩放对应(int_scale_correspond) ← 6ecd11f4；对称补全(symmetry_completion) ← 1b60fb0c；旋转对称(rotational_symmetry) ← 1b60fb0c；缺失部分标记新色(missing_marked_new_color) ← 1b60fb0c；像素放大(pixel_upscale) ← 6aa20dc0

**依赖链**：原始网格中的图案由均匀块构成，肉眼难以直接识别旋转对称性；降采样后对称结构清晰可见，才能执行补全；补全结果须映射回原始尺度着色。三步环环相扣，跳过任何一步都无法求解。

大尺度块状图案隐藏着一个小尺度的近旋转对称结构；降采样后补全对称缺失，再将缺失块以新色标记回原始网格。

**输入结构**：网格约 12x12 或 15x15，背景黑(0)。网格上有一个绿(3)图案，由若干 3x3（或其他固定边长 k，k 在 2-4 之间）的均匀绑定块组成——每个块内所有像素同色（绿(3)或黑(0)）。将每个块视为一个"超级像素"后，绿块构成一个约 4x4 至 5x5 的二值图案。该二值图案几乎具有 180 度旋转对称性，但缺失 1-2 个绿块（对应位置为黑块）。生成约束：缺失块数不超过 2；旋转中心为二值图案的几何中心；缩放因子 k 在所有示例中固定。

**规则**：
1. 检测缩放因子 k：找到绿(3)像素构成的最小均匀块边长（所有绿色连通区域都是 k x k 的正方形，且左上角坐标是 k 的倍数）。
2. 将网格按 k x k 块降采样：每个块若包含绿(3)像素则记为 1，否则记为 0，得到一个小的二值矩阵。
3. 在二值矩阵中检测 180 度旋转对称：对每个值为 1 的位置 (r, c)，检查其关于矩阵中心的 180 度对称位置 (H-1-r, W-1-c)。若对称位置为 0，则该位置为"缺失块"。
4. 对每个缺失块，在原始网格中将对应的 k x k 区域全部涂为红(2)。
5. 保持所有原始绿(3)像素不变。

**关键洞察**：旋转对称性被整数缩放隐藏——在原始尺度上图案显得庞大而杂乱，只有先识别出块结构并降采样，对称性才变得可辨。求解者需要跨尺度推理：在小尺度检测对称、在大尺度执行着色。
