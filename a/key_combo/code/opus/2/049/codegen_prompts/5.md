## 新题 5：路径编码位移与种子计数联合决定环-框交叉图案

**组合逻辑**：[端点编码位移/endpoints_encode_disp → 平移/translate](保留) + [计数/counting → 生长/grow](创新：生长环数由种子计数决定，而非种子间距) → 几何交叉分类涂色（创新：环与平移后框架的空间交叠产生第三种颜色，这种交叉涂色在源题中不存在）

**来源原语**：平移/translate、空心框/hollow_frame、路径端点/path_endpoint、端点编码位移/endpoints_encode_disp（来自 2b9ef948）；生长/grow、种子像素/seed_pixel、同心方框层/concentric_layer、等距对角排列/equi_diag_array（来自 5c2c9af4）；计数/counting（来自 b0c4d837/91413438）；按原色区分涂色/recolor_by_origin（来自 bcb3040b，创新改造为"按空间归属区分涂色"）

**依赖链**：灰色路径的两个彩色端点编码位移向量 → 框架按该向量平移到新位置 → 种子像素计数决定同心环层数 → 环在生长过程中与平移后框架产生空间交叠 → 交叠像素变为第三种颜色。位移决定框架落点，计数决定环的规模，两者共同决定交叠图案——是一个扇入结构而非线性流水线。

解码路径端点获得位移向量平移框架，同时从种子计数获得环层数生长同心环，环与框架交叠处变色。

**输入结构**：黑(0)背景，约 15x15 网格。
- 一个 3x3 黄(4)空心框（8 个黄色像素围成正方形边框），中心为红(2)像素。
- 在网格其他位置有第二个红(2)像素，通过一串灰(5)像素连接到一个孤立的黄(4)像素。灰色路径可以有转弯，但连通的两个彩色端点（红与黄）的相对位置编码了位移向量。
- 2~4 个蓝(1)种子像素散布在网格中，互不相邻，且不在灰色路径上，不与框架重叠。
- 生成约束：位移向量使框架平移后仍完全在网格内。种子像素的数量 S 满足 S >= 2。框架平移后的位置至少与一个种子的第 S 层同心环有重叠。

**规则**：
1. 找到第二个红(2)像素（不在 3x3 框架中心的那个）和孤立黄(4)像素（不属于 3x3 框架的那个）。计算位移向量 D =（孤立黄的行 - 第二红的行，孤立黄的列 - 第二红的列）。
2. 擦除灰(5)路径像素、第二个红(2)像素和孤立黄(4)像素（设为黑(0)）。
3. 将 3x3 黄(4)框架（含红色中心）整体平移向量 D。原位置擦除为黑(0)，新位置绘制。若新位置与种子像素重叠，框架像素覆盖种子像素。
4. 统计蓝(1)种子像素数量 S。
5. 从每个蓝(1)种子像素出发，绘制 S 层同心正方形环边框。第 k 层环（k = 1, 2, ..., S）是以该种子为中心、Chebyshev 距离恰好为 k 的所有像素构成的正方形边框，颜色为蓝(1)。
6. 若某个蓝色环像素与平移后的黄(4)框架边框像素位置重合，该像素涂为绿(3)。
7. 若不同种子的环相互重叠，重叠像素仍为蓝(1)（不变色）。仅环与框架的交叠产生绿色。
8. 框架的红(2)中心像素不参与交叠判定，保持红色。

**关键洞察**：位移向量和种子计数是两个独立信息源，分别控制框架落点和环的规模，但最终输出图案取决于两者的几何交叉——这是一个扇入汇合结构。仅看输出的绿色像素位置，需要同时逆推位移和环层数才能理解规则。
