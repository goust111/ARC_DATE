## 新题 3：去重还原精灵体后计数驱动平铺

**组合逻辑**：[压缩/compress + 去重/deduplicate](保留) → 还原隐藏精灵体 → [计数/counting](创新：计数对象不是输入像素，而是压缩后才可见的精灵体像素) → [平铺/tile](创新：平铺内容和参数均由压缩结果决定，而非直接从输入读取)

**来源原语**：压缩/compress、去重/deduplicate、相邻重复/adjacent_repeat、合并相同行列/merge_identical_row_col（来自 e1baa8a4）；计数/counting、平铺/tile、精灵体/sprite、阵列排布/array_layout、像素数定尺寸数/pixel_count_sets_size_copies（来自 91413438）

**依赖链**：输入是拉伸膨胀的网格 → 去重还原真实精灵体 → 精灵体的前景/背景像素数分别控制平铺副本数和画布槽位数 → 不压缩就无法得知精灵体的真实形状和像素统计，三步逻辑环环相扣。

输入是一个被行列重复膨胀的网格；去重压缩还原出真实精灵体，再用精灵体自身的像素统计决定平铺布局。

**输入结构**：一个约 9x9 至 15x15 的全彩网格（无黑色背景可见），由 2~4 种颜色构成。
- 该网格是一个更小的隐藏精灵体（3x3 或 4x4）经行列不等量重复膨胀而成：隐藏精灵体的每一行被复制了 k_i 次（k_i 在 1~4 之间，不同行可以不同），每一列被复制了 l_j 次（l_j 在 1~4 之间，不同列可以不同）。
- 隐藏精灵体包含黑(0)背景像素和恰好一种非黑前景色像素。
- 生成约束：隐藏精灵体中前景像素数 F 和背景像素数 B 满足 F >= 2，B >= 4（保证画布足够大且至少放 2 份副本）。精灵体为正方形（行列数相同）。

**规则**：
1. 对输入网格执行行列去重：将所有最大相同相邻行段合并为单行，将所有最大相同相邻列段合并为单列。结果即为隐藏精灵体。
2. 统计精灵体中非黑前景像素数 F 和黑(0)像素数 B。
3. 构建一个黑(0)输出画布，大小为 (B x 精灵体行数) x (B x 精灵体列数) 像素。画布被逻辑划分为 B x B 个槽位，每个槽位大小等于精灵体尺寸。
4. 按行优先顺序（从左上到右下），将精灵体原样复制到前 F 个槽位中。剩余槽位保持全黑。

**关键洞察**：精灵体隐藏在膨胀网格中，不执行去重就无法获得精灵体的真实形状和像素计数。压缩结果同时提供了平铺的内容（精灵体本身）、画布尺寸（B）和副本数量（F），三者缺一不可。
