**组合逻辑**：[对称检测](创新：结果不再输出颜色指示像素，而是决定后续路径生长的方向参数) → [生长](已有) + [遇障碍则绕行](已有，绕行方向由主方向间接决定)

- 遇障碍则绕行 detour_on_obstacle ← d9f24cd1

**依赖链**：对称检测的布尔结果直接决定路径生长的主方向（上/右），主方向不同导致路径遭遇的障碍集合不同，绕行行为因此产生不同的路径形态。删除对称检测则方向未知；删除生长规则则无路径输出。

以单色小图案的水平对称性为条件，从相邻种子像素出发在对应方向上逐步生长路径，遇灰(5)障碍时向垂直于主方向的一侧绕行。

**输入结构**：
- 网格约 15x20，背景黑(0)。
- 3~4 个互不相邻的 3x3 单色图案（颜色为红(2)），由红(2)像素在黑(0)背景上构成；不同示例中同一题的图案形状不同，但尺寸固定为 3x3。
- 每个图案正下方紧邻一个种子像素，颜色为蓝(1)或绿(3)（同一输入中可有不同颜色的种子）。
- 灰(5)障碍像素散布于网格中，不接触网格外边缘，不与图案或种子重叠。
- 生成约束：图案之间至少间隔 4 个像素；不同图案生长出的路径不会交叉（障碍分布保证各路径的可达区域不重叠）。

**规则**：
1. 对每个 3x3 红(2)图案进行水平镜像对称检测：比较第 0 行与第 2 行的左右翻转，若相同则判定为对称，否则为非对称。
2. 若对称：从该图案下方的种子像素出发，主方向为**向上**（行号递减）；若非对称：主方向为**向右**（列号递增）。
3. 路径生长：从种子像素开始，每步尝试沿主方向前进一格。若目标格为灰(5)像素，则改为向**垂直于主方向的正方向**前进一格（主方向为上时绕行方向为右；主方向为右时绕行方向为下）。路径像素的颜色与种子像素相同。
4. 路径在到达网格边界时停止。若绕行方向也被阻挡（目标格为灰(5)或超出边界），路径同样停止。
5. 原始图案和种子像素保留在输出中；灰(5)障碍保留。

**关键洞察**：对称性检测在源题中输出一个颜色指示像素，此处它不产生直接可见输出，而是作为路径生长方向的隐式开关——求解者必须先推断"对称→向上、非对称→向右"的映射关系，才能预测路径走向。
