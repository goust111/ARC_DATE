## 新题 8：空心矩形拉伸后象限旋转拼接

**组合逻辑**：[拉伸(stretch)](标记像素指定空心矩形在某方向上拉伸到的终点) → [旋转(rotate) + 拼接(concatenate)](拉伸后的矩形作为基础瓦片，生成四个旋转变体并拼成 2x2 阵列)（非线性耦合：拉伸造成的非正方形比例使得旋转后各象限尺寸不一致，需要补齐）

**来源原语**：拉伸/空心矩形/标记点/行列对齐/标记决定拉伸终点(b548a754)，旋转/拼接/象限/阵列排布/四旋转变体组拼图(46442a0e)

**依赖链**：标记像素决定空心矩形的拉伸方向和幅度，拉伸后得到一个可能非正方形的空心矩形；将其四个旋转变体拼成 2x2 阵列时，由于非正方形，90° 和 270° 旋转变体的宽高与 0° 和 180° 不同，需要用背景填充使各象限尺寸一致。删除拉伸则矩形保持原状、四旋转拼接的结果固定；删除旋转拼接则拉伸只是简单的矩形放大。拉伸的非对称性创造了拼接时的尺寸协调问题，这是耦合点。

依据标记像素拉伸空心矩形后，将拉伸结果的四个 90° 旋转变体拼成 2x2 输出阵列。

**输入结构**：黑(0)背景，约 12x12。网格中有一个红(2)边框、黄(4)内部填充的空心矩形（边框 1 像素宽，内部约 2x2 ~ 3x3，整体约 4x4 ~ 5x5）。网格中有一个蓝(1)孤立标记像素，位于矩形外部，且与矩形的某条边在行或列上对齐（标记的行在矩形行范围内则为水平拉伸，标记的列在矩形列范围内则为垂直拉伸）。生成约束：标记像素距矩形对应边至少 2 格，至多 5 格，以保证拉伸后矩形明显非正方形但不超出原网格尺寸。

**规则**：
1. 识别红(2)/黄(4)空心矩形：红(2)像素形成 1 像素宽的矩形边框，内部被黄(4)填充。记录矩形边界框 (r1, c1, r2, c2)。
2. 识别蓝(1)标记像素 (rm, cm)。判断拉伸方向：
   - 若 r1 <= rm <= r2（标记行在矩形行范围内）：水平拉伸。若 cm > c2，将矩形右边界拉伸到 cm 列；若 cm < c1，将矩形左边界拉伸到 cm 列。
   - 若 c1 <= cm <= c2（标记列在矩形列范围内）：垂直拉伸。若 rm > r2，将矩形下边界拉伸到 rm 行；若 rm < r1，将矩形上边界拉伸到 rm 行。
3. 重新绘制拉伸后的空心矩形 R：新边界框为 (r1', c1', r2', c2')，红(2)边框 1 像素宽，黄(4)填充内部。得到一个高 H = r2'-r1'+1、宽 W = c2'-c1'+1 的瓦片 T0。
4. 生成 T0 的三个旋转变体：T90（顺时针 90°，尺寸变为 W x H）、T180（180°，H x W）、T270（顺时针 270°，W x H）。
5. 构建 2x2 拼接阵列：各象限的尺寸取统一值 Hmax = max(H, W)，Wmax = max(H, W)。每个瓦片在其象限内居中放置（上下左右用黑(0)填充使其达到 Hmax x Wmax 尺寸）。左上 = T0，右上 = T90，左下 = T270，右下 = T180。
6. 输出为 (2*Hmax) x (2*Wmax) 的网格。蓝(1)标记像素不出现在输出中。

**关键洞察**：如果矩形拉伸后恰好仍为正方形，则四个旋转变体尺寸相同，拼接直接无缝；但标记像素的距离通常导致非正方形拉伸，使 90°/270° 旋转变体的宽高对换，拼接时出现尺寸不匹配——求解者需要推断出居中填充的对齐策略。拉伸量与拼接的填充量直接数值关联。
