## 新题 7：平移产生新重叠与面积优先遮挡解析

**组合逻辑**：[平移/固定步长平移](创新：多个不同颜色对象各自平移而非全体同方向) + [遮挡层序](创新：遮挡优先级不来自输入中的堆叠，而来自对象面积比较) + [背景替换](已有) + [计数](创新：面积计数用于遮挡裁决而非阈值判断)

**来源原语**：平移/固定步长平移(32e9702f) + 遮挡层序/重叠定先后(68bc2e87) + 背景替换(32e9702f) + 计数(ae58858e/d5c634a2)

**依赖链**：所有前景对象按统一方向平移 → 平移后原本不重叠的对象可能产生新的空间冲突 → 面积计数确定每个对象的优先级 → 冲突格子上面积更大的对象可见。删除平移则无重叠产生，删除面积计数则冲突无法解决，删除背景替换则背景不正确。

将所有前景对象按统一方向平移，用灰色替换旧背景，对平移后产生的新重叠区域按对象面积从大到小决定可见颜色。

**输入结构**：黑(0)背景网格，约 14x16。网格中有 4~6 个 4-连通前景对象，每个对象使用不同的非黑颜色（从蓝(1)、红(2)、绿(3)、黄(4)、橙(7)、栗(9)中选取），每个对象包含 3~10 个像素，形状为不规则的 4-连通区域（非矩形）。在输入中，所有对象互不接触（任意两个对象之间至少间隔 1 格黑色），不存在任何重叠。网格左下角有一个方向指示符：一个品红(6)的 1x3 水平箭头形状（三个品红像素从左到右排列，最右侧像素的上方和下方各有一个品红像素构成箭头头部），表示平移方向为"向右 2 格"。生成约束：所有对象的面积（像素数）互不相同。平移 2 格后，至少有两对对象产生空间重叠，且无对象完全移出网格右边界。

**规则**：
1. 识别方向指示符：品红(6)箭头形状指示平移方向和步长。箭头朝右表示所有前景对象向右平移，步长为箭头主干长度（此处为 3 个像素对应 2 格位移，即主干像素数 - 1 = 步长）。
2. 创建与输入同尺寸的输出网格，全部填充灰(5)。
3. 计算每个前景对象的面积（像素数量）。
4. 将每个前景对象的所有像素坐标向右平移 2 列。超出网格右边界的像素被裁剪丢弃。
5. 在输出网格上绘制平移后的对象。按面积从小到大的顺序依次绘制（面积小的先画，面积大的后画覆盖），这样面积大的对象在冲突区域总是可见（后绘制覆盖先绘制）。
6. 方向指示符（品红箭头）不参与平移，在输出中被灰色背景覆盖（即不保留）。

**关键洞察**：输入中所有对象互不重叠，遮挡问题只在平移后才涌现——这意味着求解者无法从输入直接观察到遮挡关系，必须先执行平移再解决冲突。面积优先规则（非颜色编号、非位置）需要对比多个示例中不同面积对象在冲突区域的表现才能归纳。

import numpy as np

p = Path("/home/lixinyu/snap/a/key_combo/code/opus/2/003/7.py")
mod = SourceFileLoader("new_arc_task", str(p)).load_module()
sigs = set()
for i in range(100):
    inp = mod.generate_input()
    out = mod.main(inp)
    assert isinstance(inp, np.ndarray)
    assert isinstance(out, np.ndarray)
    assert inp.ndim == 2 and max(inp.shape) <= 30, f"input grid exceeds 30x30: {inp.shape}"
    assert out.ndim == 2 and max(out.shape) <= 30, f"output grid exceeds 30x30: {out.shape}"
    sigs.add(hashlib.md5(inp.tobytes() + str(inp.shape).encode()).hexdigest())
print("variants", len(sigs))
assert len(sigs) >= 20
