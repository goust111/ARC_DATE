## 新题 1：遮挡层序决定角点邻域几何

**组合逻辑**：[遮挡层序/排序](已有) → [计数/奇偶分类](创新：层序rank的奇偶性作为分类依据) → [描边/mark_neighbors + 对角邻接/正交邻接](创新：rank奇偶替代颜色来选择邻域几何)

**来源原语**：遮挡层序/排序(68bc2e87) + 描边/mark_neighbors(0ca9ddb6) + 对角邻接/正交邻接(0ca9ddb6) + 计数(d5c634a2)

**依赖链**：遮挡分析产出各框架的层序rank → rank的奇偶性对框架进行二分类 → 分类结果决定在每个框架的四角施加对角扩展还是正交扩展。删除遮挡分析则无法确定rank，删除奇偶判断则无法选择几何类型，删除邻域扩展则输出无变化。

从重叠的空心矩形框中推断层叠顺序，再按层序rank的奇偶性为每个框架的四角选择对角或正交邻域扩展标记。

**输入结构**：黑(0)背景网格，约 15x15。网格中有 4~6 个单像素厚的空心矩形框，每个框使用不同的非黑非黄非橙颜色（如蓝(1)、红(2)、绿(3)、灰(5)、品红(6)等）。各框架的矩形区域部分重叠，重叠处仅显示最顶层框架的颜色。每个框架的可见像素至少足以确定其完整矩形边界框（即四个极值行列均有可见像素）。框架之间的重叠关系构成一个完整的线性顺序（不存在循环遮挡）。所有框架的四个角点的对角/正交邻居位置中至少有 2 个位于网格内且为黑(0)。

**规则**：
1. 对每种框架颜色，收集该颜色的所有可见像素，计算其行列极值，从而还原该框架的完整矩形边框（即极值行列围成的一像素厚矩形环）。
2. 在所有还原后的框架存在空间重叠的格子上，实际可见的颜色表示该位置的最上层框架。通过这些重叠证据推断所有框架的从底到顶的唯一线性堆叠顺序，记底层为 rank=1，依次递增。
3. 对每个框架，定位其矩形边框的四个角点像素（左上、右上、左下、右下）。
4. rank 为奇数的框架：对其每个角点，将该角点的四个对角邻居（左上、右上、左下、右下方向各偏移一格）中位于网格内且当前为黑(0)的格子涂为黄(4)。
5. rank 为偶数的框架：对其每个角点，将该角点的四个正交邻居（上、下、左、右方向各偏移一格）中位于网格内且当前为黑(0)的格子涂为橙(7)。
6. 扩展标记仅涂在当前为黑(0)的格子上；已有任何非黑颜色的格子不被覆盖。
7. 按 rank 从低到高的顺序依次处理各框架的角点标记（低层先画，高层后画），若多个框架的标记目标位置重叠，后处理的框架标记不覆盖先前已涂的标记像素（因为先涂的已非黑色）。
8. 所有原始框架像素和背景保持不变。

**关键洞察**：框架的深度rank奇偶性决定了邻域扩展的几何类型——这一决策必须通过遮挡分析获得，而非从任何可见颜色直接读取。源题 0ca9ddb6 中是标记颜色选择几何类型，这里替换为遮挡层序分析得出的rank属性。
