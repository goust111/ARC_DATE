## 新题 5：长宽比分类驱动的双轨调色板内部填色

**组合逻辑**：[分类/朝向分组](创新：以长宽比替代图形朝向作为分类依据) → [计数/计数映射槽位](创新：类内排序索引替代全局计数) + [内部与边框/仅内部像素变色](已有) + [编码映射](创新：分类结果同时决定调色板和排序轴)

**来源原语**：分类/朝向分组(d5c634a2) + 计数/计数映射槽位(d5c634a2) + 内部与边框/仅内部像素变色(bb43febb) + 编码映射(edb79dae) + 面板(d5c634a2)

**依赖链**：矩形长宽比分类（"高"vs"宽"）→ 分类结果同时选择调色板（颜色序列）和类内排序轴（空间方向）→ 按排序轴对类内矩形排序获得索引 → 索引对应调色板中的颜色 → 该颜色填入矩形内部。删除分类则不知使用哪个调色板和哪个排序轴，删除排序则无法确定颜色索引，删除内部识别则不知修改哪些像素。

将矩形按长宽比分为"高型"和"宽型"两类，每类有专属调色板和排序方向，按类内位置顺序从调色板取色填充各矩形内部。

**输入结构**：黑(0)背景网格，约 16x20。网格中有 5~7 个实心灰(5)矩形，互不接触（任意两个矩形之间至少隔 1 格黑色）。每个矩形高宽均 >= 3，且高 != 宽（不存在正方形）。其中一部分矩形高 > 宽（"高型"），另一部分宽 > 高（"宽型"），每类至少 2 个。网格的最底行（或最右列）有两个小的调色板条：
- "高型调色板"：一行连续色块，从左到右排列，颜色各不相同（如红(2)、绿(3)、蓝(1)），色块数量恰等于高型矩形的数量。调色板条的左侧有一个纵向排列的双像素标记（两个上下相邻的品红(6)像素），表示"高型"。
- "宽型调色板"：一行连续色块，从左到右排列，颜色各不相同（如黄(4)、橙(7)、栗(9)），色块数量恰等于宽型矩形的数量。调色板条的左侧有一个横向排列的双像素标记（两个左右相邻的品红(6)像素），表示"宽型"。
两个调色板条之间用黑色分隔，且都位于网格底部，不与任何灰色矩形重叠。生成约束：高型矩形数量等于高型调色板长度，宽型矩形数量等于宽型调色板长度。

**规则**：
1. 对每个灰(5)矩形，计算其高（行数）和宽（列数）。高 > 宽者归为"高型"，宽 > 高者归为"宽型"。
2. 识别两个调色板：品红(6)标记为纵向双像素（上下相邻）的调色板是高型调色板，品红(6)标记为横向双像素（左右相邻）的调色板是宽型调色板。
3. 高型矩形按其边界框左上角的列坐标从小到大排序（列坐标相同时按行坐标从小到大），得到顺序索引 k=1,2,3,...。第 k 个高型矩形的填充色为高型调色板从左到右的第 k 个颜色。
4. 宽型矩形按其边界框左上角的行坐标从小到大排序（行坐标相同时按列坐标从小到大），得到顺序索引 k=1,2,3,...。第 k 个宽型矩形的填充色为宽型调色板从左到右的第 k 个颜色。
5. 对每个矩形，保留其一像素厚的灰(5)边框不变，将边框严格内部的所有灰色格子重涂为步骤 3 或步骤 4 确定的颜色。
6. 调色板区域、品红标记、黑色背景均保持不变。

**关键洞察**：矩形的长宽比属性同时编码了两个独立决策——选择哪个调色板（颜色来源），以及按哪个空间轴排序（列优先=高型 vs 行优先=宽型）。这一双重编码在任何单一源题中都不存在，需要对比多个示例中不同长宽比矩形的处理差异才能推断。

import hashlib

p = Path("/home/lixinyu/snap/a/key_combo/code/opus/2/003/5.py")

    assert out.ndim == 2 and max(out.shape) <= 30, f"output grid exceeds 30x30: {out.shape}"
    sigs.add(hashlib.md5(inp.tobytes() + str(inp.shape).encode()).hexdigest())
print("variants", len(sigs))
assert len(sigs) >= 20
PY
python -m py_compile "/home/lixinyu/snap/a/key_combo/code/opus/2/003/5.py"
