## 新题 8：标记位置编码选择周期瓦片填充框架内部

**组合逻辑**：[极值内缩定边框/描边](已有，识别框架) + [标记像素/方位决定象限分配](创新：标记的粗略方位编码为候选瓦片的选择索引) → [平铺/周期重复](创新：所选瓦片周期性铺满框架内部) + [内部与边框](已有，仅填充内部)

**来源原语**：框架/内部与边框(bb43febb/edb79dae) + 标记像素/方位决定象限分配(94414823) + 平铺/周期重复(135a2760) + 编码映射(edb79dae)

**依赖链**：识别框架和框架内部区域 → 标记像素的粗略空间方位编码为二进制选择信号 → 选择信号索引到候选瓦片集合中的某一个 → 所选瓦片周期性铺满框架内部。删除框架识别则不知填充区域，删除标记方位解读则无法选择瓦片，删除周期铺设则内部为空。

框架外的标记像素通过其相对于框架中心的方位编码一个选择索引，从候选瓦片中选出一个，用于周期性铺满框架内部。

**输入结构**：黑(0)背景网格，约 18x18。一个灰(5)单像素厚的矩形框架，框架内部为黑色空区域（内部高宽均 >= 6）。框架外部散布着 3~4 个小瓦片图案，每个瓦片是一个 2x2 或 2x3 或 3x2 的紧凑色块区域，使用各自不同的颜色组合（如一个瓦片由红(2)和蓝(1)组成，另一个由绿(3)和黄(4)组成，等等）。瓦片图案互不接触，且不与框架接触。瓦片图案在框架外按特定空间布局排列：相对于框架中心，它们大致分布在不同的方位区域（左上区、右上区、左下区、右下区）。恰好两个栗(9)标记像素放置在框架外部（不在任何瓦片图案内），一个位于框架中心的左侧或右侧，另一个位于框架中心的上方或下方。生成约束：候选瓦片数量恰为 4，且能被框架内部的尺寸整除地铺满（或至少能周期重复覆盖内部，边缘处允许截断）。

**规则**：
1. 识别灰(5)矩形框架及其内部区域（框架边框内侧的所有黑色格子）。
2. 计算框架的几何中心（框架边界框的中心坐标，行和列取平均值）。
3. 识别两个栗(9)标记像素的位置。对每个标记，判断其相对于框架中心的粗略方位：
   - 标记 A：若其列坐标 < 框架中心列，则水平分量 = 0（左）；否则水平分量 = 1（右）。
   - 标记 B：若其行坐标 < 框架中心行，则垂直分量 = 0（上）；否则垂直分量 = 1（下）。
   - 两个标记合成一个二维索引 (垂直分量, 水平分量)，取值为 (0,0)、(0,1)、(1,0)、(1,1) 之一。
4. 识别框架外的 4 个候选瓦片图案，按其中心位置相对于框架中心的方位排列：左上方位=(0,0)，右上方位=(0,1)，左下方位=(1,0)，右下方位=(1,1)。
5. 选择方位索引与步骤 3 计算的 (垂直, 水平) 索引匹配的那个候选瓦片。
6. 将所选瓦片周期性地铺满框架内部：以框架内部区域的左上角为起始对齐点，将瓦片沿行和列方向重复平铺。若内部尺寸不是瓦片尺寸的整数倍，在右边缘和下边缘截断多余部分。
7. 灰色框架边框保持不变。框架外的所有内容（瓦片图案、标记像素、黑色背景）保持不变。

**关键洞察**：两个标记像素各自只编码一个比特的信息（左/右 或 上/下），联合起来才能编码一个 2-bit 索引来从四个候选瓦片中选择一个。标记的精确位置无关紧要，只有其相对于框架中心的粗略方位有意义——这一编码机制需要对比多个示例（不同标记方位选择不同瓦片）才能归纳。
