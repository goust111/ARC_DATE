## 新题 3：锚点对齐方向同时控制射线与精灵体镜像方式

**组合逻辑**：[射线延伸](已有) + [镜像](已有，创新：镜像轴由射线的方向属性隐式决定，而非由独立标记编码) + [印章覆盖](已有，创新：印章位置由标记而非孤立像素决定)

**来源原语**：射线延伸、锚定方块、行列对齐、标记像素、对齐标记连向锚点（参考题 d43fd935）；镜像、相邻拼接（参考题 9bebae7a）；印章覆盖、中心展开（参考题 b60334d2）；精灵体（参考题 4290ef0e）

**依赖链**：每个标记像素与锚定方块的行列对齐关系同时决定两件事：(1) 射线从标记延伸到锚点的方向（行对齐→水平射线，列对齐→垂直射线）；(2) 在标记位置放置精灵体副本时的镜像方式（行对齐→水平翻转，列对齐→垂直翻转）。同一个几何属性驱动两个不同操作——这在源题中不存在。

利用"对齐方向"这一单一几何属性同时编码射线方向和镜像轴，在标记位置生成射线连接和方向感知的精灵体副本。

**输入结构**：约 16x16 的网格。背景为黑(0)。包含一个 2x2 蓝(1)锚定方块。一个不对称的小型 4-连通精灵体（3~6 个像素，绿(3)），位于远离锚定方块的位置（与锚定方块不行列对齐）。另有 3~4 个单像素标记，颜色各不相同（从红(2)、黄(4)、品红(6)、橙(7)中选取），每个标记恰好与锚定方块的某一行或某一列对齐（即标记的行号等于锚定方块占据的两行之一，或标记的列号等于锚定方块占据的两列之一）。生成约束：标记不紧贴锚定方块（至少间隔 4 个像素），使射线可见；标记中至少有一个行对齐和一个列对齐，使两种镜像方式都出现；各标记的精灵体副本的边界框互不重叠。

**规则**：
1. 对每个标记像素，判断它与锚定方块的对齐类型：
   - 行对齐：标记的行号等于锚定方块占据的两行之一。
   - 列对齐：标记的列号等于锚定方块占据的两列之一。
2. 对行对齐的标记：从标记位置向锚定方块方向水平绘制射线（涂为标记的颜色），直到锚定方块的边缘（不覆盖锚定方块像素），仅涂背景像素。
3. 对列对齐的标记：从标记位置向锚定方块方向垂直绘制射线（涂为标记的颜色），直到锚定方块的边缘，仅涂背景像素。
4. 在每个标记的位置，以标记为中心放置精灵体的一个副本：
   - 行对齐的标记：精灵体水平翻转（左右镜像）后放置。
   - 列对齐的标记：精灵体垂直翻转（上下镜像）后放置。
   - 副本颜色保持绿(3)不变，仅覆盖背景像素。
5. 锚定方块（蓝）、原始精灵体（绿）、所有标记像素和射线均保留。处理顺序：按标记在网格中的光栅顺序（从左上到右下）依次处理，先画射线再放精灵体副本。

**关键洞察**：标记与锚定方块的行列对齐类型是一个隐藏变量，同时编码射线方向和精灵体镜像轴。仅看单个示例可能以为镜像方向由标记相对于锚点的左右上下位置决定，需要对比多个示例（例如同在左侧但一个行对齐一个列对齐的标记产生不同镜像）才能归纳出真正的规则。
