## 新题 9：射线着色与二部图区域着色的同时约束

**组合逻辑**：[射线延伸/ray_extend] + [交替着色/alternating_coloring] → [重涂色/recolor](创新：每个背景像素的最终颜色由射线覆盖状态和所在区域的交替色共同决定，非流水线而是同时约束)

**来源原语**：射线延伸、控制像素、整行整列射线、像素为射线中心 ← 140c817e；交替着色、二部图结构、四邻接连通、分隔墙线 ← 3bd292e8；重涂色 ← 6c434453

**依赖链**：墙线结构同时是区域着色和射线传播的输入。区域着色和射线覆盖各自独立计算，但它们在每个像素处交汇决定最终颜色——射线覆盖的区域内像素获得混合色，未被射线覆盖的获得纯交替色。这是一个同时约束满足结构，不存在固定的先后顺序。

红色墙线将网格分为交替着色的区域，蓝色控制像素发射全行全列射线；每个背景像素的最终颜色由其所在区域的交替色和是否被射线覆盖共同决定。

**输入结构**：黑(0)背景网格，约 15x15。网格中有红(2)墙线（单像素宽的 4-连通线段），将黑(0)背景分隔为若干 4-连通区域（4~7 个区域）。部分区域中含有蓝(1)控制像素（共 2~3 个，每个区域至多 1 个），位于该区域的某个黑(0)位置上。生成约束：墙线结构保证区域邻接图为二部图（单像素宽墙线天然满足）；控制像素的射线至少穿过 2 个不同区域。

**规则**：
1. 红(2)墙线像素在输出中保持不变。
2. 计算二部图交替着色：将包含网格左下角像素的区域标记为灰(5)侧，通过墙线邻接交替标记为灰(5)和绿(3)。
3. 计算射线覆盖：对每个蓝(1)控制像素，标记其所在整行和整列的所有非墙线位置为"被射线覆盖"。
4. 对每个黑(0)背景像素，根据以下规则确定输出颜色：
   - 若该像素不被任何射线覆盖：涂为其所在区域的交替色（灰(5)或绿(3)）。
   - 若该像素被射线覆盖且所在区域为灰(5)侧：涂为橙(7)。
   - 若该像素被射线覆盖且所在区域为绿(3)侧：涂为品红(6)。
5. 蓝(1)控制像素本身在输出中涂为黄(4)（既非交替色也非射线色，作为标记保留）。

**关键洞察**：输出中每个像素的颜色是两个独立属性（区域归属、射线覆盖）的联合函数——不存在"先做 A 再做 B"的线性顺序，求解者必须同时理解两套规则并在每个像素处执行二维查表。橙(7)和品红(6)的出现条件（射线 + 特定区域侧）需对比多个示例中不同区域的射线覆盖情况才能归纳。
