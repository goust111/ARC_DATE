## 新题 6：最小生成树遍历序驱动的对角格点相位

**组合逻辑**：[连接 connect](已有) + [循环填充 periodic_fill](创新：周期相位由遍历序而非固定参数决定) + [填充 fill](已有) —— 创新点在于：MST 的拓扑遍历顺序编码了每个房间内对角格点图案的相位偏移，使得物理连通性与视觉图案产生结构性关联

**来源原语**：connect / hollow_rectangle / corridor / shortest_gap / min_spanning_tree / overlap_corridor_width（参考题 b9630600）；periodic_fill / diagonal_lattice / periodic_phase_align（参考题 c1990cce）；fill / marker_pixel（参考题 4b6b68e5 / e9c9d9a1）

**依赖链**：识别所有空心矩形框 → 计算可见间距并构建 MST → 画走廊连接 → 从最大框 BFS 遍历 MST 确定每框的访问序号 → 每框内部绘制对角格点，相位 = 访问序号 mod 4 → 格点颜色取该框内部标记像素的颜色。删除 MST 构建则无法确定遍历序，进而无法确定相位；删除格点填充则无视觉输出；删除标记色则格点无颜色。

将通过走廊连接的空心矩形房间内部填充对角格点图案，格点的相位偏移由房间在最小生成树中的广度优先遍历顺序决定，格点颜色由房间内标记像素指定。

**输入结构**：黑(0)背景，约 22x22。网格中有 4-6 个绿(3)单像素宽空心矩形框，大小各异（内部面积从 3x3 到 7x7 不等），边界框互不重叠。每个矩形内部恰有 1 个孤立标记像素（颜色取自红(2)、蓝(1)、黄(4)、品红(6)、橙(7)，各框标记色互不相同）。矩形之间存在可见的水平或垂直间距（两框之间无障碍的背景通道，且两框的内部在垂直或水平方向有重叠范围）。生成约束：任意两个矩形之间至多有一条可见间距路径；所有矩形通过可见间距形成连通图；最大内部面积的矩形唯一。

**规则**：
1. 对所有绿(3)空心矩形框，计算每对之间的可见间距长度（两框面对的壁之间的背景像素列数或行数）。仅考虑水平或垂直方向、且两框内部在垂直或水平方向有重叠范围的框对。
2. 选择最小生成树（MST）：在所有可见间距中选择总长度最小的子集，使所有框连通。若总长度相同，选择包含最短单条间距的那棵。
3. 画走廊：对 MST 中每条选中的间距，在两框重叠的内部范围的边界两行（或两列）之间画绿(3)走廊壁，并擦除两框面对的壁上严格位于走廊壁之间的像素（设为黑(0)），形成通道。
4. 以内部面积最大的矩形为根节点，在 MST 上做广度优先遍历（BFS），相同层级内按间距长度升序访问（短间距优先）。根节点的访问序号 = 0，其第一个邻居 = 1，依次递增。
5. 对每个矩形框的内部区域（不含框壁），绘制 NW-SE 方向对角格点：将内部像素 (r, c)（r 为行号、c 为列号）中满足 (r + c) mod 4 == (该框访问序号 mod 4) 的像素涂为该框内部标记像素的颜色。
6. 擦除所有标记像素（被格点颜色覆盖或保持为背景）。走廊内部保持黑(0)。

**关键洞察**：走廊网络不仅是视觉连接——其最小生成树的 BFS 遍历序号直接编码了每个房间内对角格点的相位偏移（mod 4）。改变任何一条走廊的长度可能改变 MST 结构，进而改变所有下游房间的格点相位。这一"拓扑顺序→视觉图案"的映射在任何单一源题中都不存在。
