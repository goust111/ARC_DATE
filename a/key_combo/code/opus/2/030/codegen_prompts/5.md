## 新题 5：标记围定矩形的缺色补全 + 补全色反涂边框

**组合逻辑**：[颜色多重集相同 + 各区域缺像素](已有，创新改造：操作对象从分隔线划分的区域改为标记围定的矩形) → [重涂色](创新：补全的颜色反过来成为该矩形红色边框标记的新颜色，使补全结果编码在边框上可见)

**来源原语**：填充/fill、计数/counting、颜色多重集相同/same_color_multiset、各区域缺像素/region_miss_pixel（e3fe1151）；重涂色/recolor、标记像素/marker_pixel、标记围定区域重涂/marker_bounded_rect_recolor、填充矩形/filled_rectangle、包围框内部/inside_bbox（36fdfd69）

**依赖链**：多重集比较确定每个矩形的缺失颜色 → 缺失颜色填入空位 → 同一颜色替换该矩形的所有红色边框标记。删除多重集比较则不知道缺什么颜色；删除边框重涂则补全结果只在内部可见，边框信息丢失。补全颜色同时充当"填充值"和"边框新色"——同一个值被两种不同操作消费，这在源题中不存在。

比较四个红色标记围定矩形的内部颜色多重集，找出各自缺失的颜色并填入空位，然后用该缺失颜色替换该矩形的所有红色边框标记。

**输入结构**：约 14x14 网格，背景黑(0)。网格中分布 4 个不重叠的矩形区域（各约 4x4 至 5x5），每个矩形的边缘由红(2)标记像素勾勒（红像素位于矩形的四条边上，不必铺满每个边缘位置，但四条边上各至少有 1 个红像素）。矩形内部（不含红边框）填有若干非黑非红前景像素（使用蓝(1)、绿(3)、黄(4)、品红(6)等），其中恰好一个位置是黑(0)空位。四个矩形的非黑非红内部像素构成的颜色多重集在补全后应完全相同（即它们拥有相同的完整多重集，但各缺少不同的一个颜色实例）。生成约束：四个矩形内部大小相同；每个矩形恰好缺少一个不同的颜色实例；补全后多重集完全一致。

**规则**：
1. 识别每个矩形：找到红(2)标记像素围定的最小轴对齐矩形，将其边框内部（不含红标记行列上的像素）视为该矩形的内容区域。
2. 对每个矩形的内容区域，收集所有非黑像素的颜色，构建该矩形的当前颜色多重集。
3. 取四个矩形中每种颜色的最大出现次数，构建完整多重集。
4. 对每个矩形，其缺失颜色 = 完整多重集减去当前多重集后剩余的唯一颜色。将该矩形内容区域中的黑(0)空位像素填为该缺失颜色。
5. 将该矩形边缘上所有红(2)标记像素替换为该矩形的缺失颜色。
6. 背景和其他非矩形区域的像素保持不变。

**关键洞察**：每个矩形的缺失颜色承担双重角色——它既是内容补全的填充值，又是边框标记的替换色。输出中边框颜色的差异直接暴露了各矩形原来缺失的是哪种颜色，使补全分析的结论编码在结构的外部可见属性上。
