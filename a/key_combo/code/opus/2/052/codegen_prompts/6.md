## 新题 6：最小间距连线与距离参数化径向涂色

**组合逻辑**：[connect/连线 + min_gap_triggered/最小间距触发](连接最近标记对) → [counting/计数](量化间距 G) → [recolor/重涂色](G 作为其余标记的涂色半径) + [erase/擦除](引导像素转色后消失)

**来源原语**：connect, mirrored_marker_pair, gap_segment, center_axis_symmetry, min_gap_triggered ← 5ad8a7c0；counting ← 27a77e38；recolor, erase ← aabf363d, e4941b18；guide_pixel, corner_positioning, corner_color_transfer_vanish ← aabf363d

**依赖链**：最小间距识别→连线填充 + 间距值 G 提取→G 作为其余标记对的涂色半径参数→角落引导像素决定涂色目标色并自身消失。间距值同时充当连线触发条件和径向涂色的范围参数——这是跨操作的数值传递。

连接间距最小的镜像标记对，然后用该间距值作为半径，将其余标记对周围的背景像素涂成角落引导像素指定的颜色。

**输入结构**：
- 约 13x13 的网格，背景为黑(0)，前景标记颜色为蓝(1)。
- 4~6 行各含两个蓝(1)像素，关于网格垂直中轴对称。各行的两个标记之间的水平间距（两标记之间的背景像素数）各不相同，且恰好有唯一一对间距最小。
- 网格左下角（最后一行第一列）有一个单独的引导像素，颜色为红(2)。
- 生成约束：最小间距 G 在 1~3 之间；各对间距互不相同；引导像素不在任何标记对所在行上；标记对所在行互不相邻（行间至少间隔一行）。

**规则**：
1. 在所有含对称标记对的行中，找到水平间距最小的那对。设其间距为 G（两标记之间有 G 个背景像素）。
2. 将该最小间距对之间的 G 个背景像素填充为蓝(1)，形成水平连线。
3. 读取左下角引导像素的颜色 C（本题为红(2)），然后将引导像素擦除为黑(0)。
4. 对其余每对未连线的对称标记：以每个标记像素为中心，将曼哈顿距离 <= G 范围内的所有黑(0)背景像素涂为颜色 C。
5. 涂色不覆盖蓝(1)前景像素和连线像素。不同标记的涂色范围若重叠，颜色相同，无冲突。
6. 被连线行的两个标记保持蓝(1)不变。其余行的标记像素也保持蓝(1)不变。

**关键洞察**：最小间距值 G 同时充当连线的触发条件和其余标记涂色范围的半径参数——这是一个跨操作的数值传递；需要对比多个示例中不同 G 值产生的不同涂色范围才能归纳出半径等于间距这一关系。
