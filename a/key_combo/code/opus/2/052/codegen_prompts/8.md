## 新题 8：封闭区域总数编码区内螺旋臂数

**组合逻辑**：[flood_fill/洪泛填充](识别封闭区域集合) → [counting/计数](统计封闭区域总数 N，创新：全局计数参数化局部操作) → [spiral_drawing/螺旋绘制](每个封闭区域中心画螺旋，臂数 = 2N) + [boundary_clipping/边界裁剪](螺旋被裁剪在各自封闭区域内)

**来源原语**：flood_fill, enclosed_region, wall_segment, region_enclosure, unreachable_background_filled ← a5313dff；spiral_drawing, origin_positioning, boundary_clipping ← 8b28cd80；counting, partition_sets_size ← 1190e5a7

**依赖链**：洪泛填充确定封闭区域集合→区域数量 N 决定每个螺旋的臂数 2N（全局→局部参数传递）→每个区域中心起画螺旋→螺旋被裁剪在各自区域内。增减一个封闭区域会改变所有螺旋的长度——各区域通过全局计数隐式耦合。

识别被红色墙壁围成的封闭区域，在每个区域的质心处画正方形螺旋，螺旋的展开臂数由封闭区域的总数决定，超出区域边界的部分被裁剪。

**输入结构**：
- 约 21x21 的网格，背景为黑(0)。
- 红(2)色像素形成单像素厚的墙壁线段。墙壁之间或墙壁与网格边界围成若干封闭区域和非封闭区域。
- 封闭区域：4-连通的黑(0)背景像素集合，不能通过黑(0)像素路径到达网格边界。
- 封闭区域形状大致为矩形或不规则多边形，面积在 9~50 像素之间。
- 存在若干非封闭的背景区域（可达网格边界），不参与变换。
- 生成约束：封闭区域数量在 2~5 个之间；每个封闭区域的最短内径（内部最窄处的连续背景像素数）至少 3 像素；不同封闭区域之间至少隔 1 个墙壁像素。

**规则**：
1. 从网格四周边界出发，对黑(0)像素做 4-邻域洪泛填充，标记所有从边界可达的背景像素为"外部"。红(2)像素视为墙壁，不可通过。
2. 未被标记的黑(0)像素按 4-连通性分组，每组构成一个封闭区域。统计封闭区域总数 N。
3. 对每个封闭区域，计算其质心：所有区域内像素的行坐标平均值（四舍五入到最近整数）和列坐标平均值（四舍五入到最近整数）。若质心位置落在墙壁上或区域外部，将其调整为区域内曼哈顿距离最近的像素（若有多个等距的，取扫描序最先的）。
4. 从质心出发，按上→右→下→左的方向顺序绘制正方形螺旋。臂长序列为 1, 1, 2, 2, 3, 3, ...（第 k 条臂长度为 ceil(k/2)）。螺旋共绘制 2N 条臂。
5. 螺旋像素涂为蓝(1)色，但仅绘制落在该封闭区域内部的黑(0)像素上。落在墙壁上、其他区域内或外部背景中的螺旋像素不绘制（裁剪）。
6. 红(2)墙壁像素和外部背景在输出中保持不变。质心位置也涂为蓝(1)。

**关键洞察**：每个封闭区域的螺旋展开程度取决于所有封闭区域的总数 N——增加或减少一个封闭区域会改变全部螺旋的长度；这个全局参数到局部操作的隐式传递需要对比不同示例（封闭区域数量不同的情况）才能发现。
