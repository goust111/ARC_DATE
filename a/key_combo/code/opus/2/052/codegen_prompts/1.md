## 新题 1：环缝洪泛门控色循环

**组合逻辑**：[flood_fill/洪泛填充](检测缝隙可达性，创新：穿透环缝而非填充封闭区域) → [counting/计数](统计被突破环数 N) → [recolor/重涂色 + colors_cycle_by_nesting/色循环](仅对被突破环执行，方向由 N 奇偶决定)

**来源原语**：flood_fill, enclosed_region, unreachable_background_filled ← a5313dff；recolor, concentric_ring, nesting_order, colors_cycle_by_nesting ← bda2d7a6；counting ← 1190e5a7

**依赖链**：洪泛可达性判定筛选出参与循环的环子集；被突破环的数量奇偶性反转循环方向；两层依赖缺一不可——删掉洪泛则无法确定哪些环参与，删掉奇偶判定则无法确定方向。

从网格边界洪泛，只有水流能穿透缝隙到达的同心环才参与颜色轮转，轮转方向由被突破环的数量奇偶性决定。

**输入结构**：
- 约 15x15 的网格，背景为黑(0)。
- 4~6 层单像素厚的同心矩形环，每层一种颜色（从外到内依次使用蓝(1)、红(2)、绿(3)、黄(4)、灰(5)等，各层颜色不重复）。
- 部分环上恰好有一个像素为黑(0)，形成 1 像素宽的缝隙，缝隙位置不规律。
- 最内层环内部区域为黑(0)背景。
- 生成约束：每条环最多一个缝隙；至少有一条环没有缝隙（确保不是所有环都被突破）；缝隙不出现在环的四个角上。

**规则**：
1. 从网格四周边界出发，对黑(0)像素执行 4-邻域洪泛填充，标记所有从边界可达的背景像素为"外部"。环的像素视为墙壁，环上的黑色缝隙视为通道。
2. 洪泛穿过一条环的缝隙后继续向内扩散。没有缝隙的环阻断洪泛，该环及其所有内侧环不会被到达。
3. 一条环被"突破"当且仅当洪泛标记到达了该环内侧紧邻的背景像素（即该环内侧第一个黑色像素被标记为"外部"）。
4. 收集所有被突破的环，按从外到内的嵌套顺序排列其颜色序列 [c_1, c_2, ..., c_N]。
5. 统计被突破环的数量 N。若 N 为奇数，颜色序列向外循环一位：c_1 -> c_N 的环涂 c_1 色，c_2 -> c_1 的环涂 c_2 色，...，c_N -> c_{N-1} 的环涂 c_N 色（即最外层颜色移到最内层被突破环，其余各向外移一位）。若 N 为偶数，颜色序列向内循环一位：c_1 的环涂 c_2 色，c_2 的环涂 c_3 色，...，c_N 的环涂 c_1 色（即最内层被突破环的颜色移到最外层，其余各向内移一位）。
6. 未被突破的环保持原色不变。
7. 缝隙位置保持黑(0)背景不变。洪泛标记仅用于判断，不改变输出中的背景颜色。

**关键洞察**：洪泛的可达性和环的完整性共同决定了哪些环进入颜色轮转池；被突破环的数量奇偶性是一个隐蔽规则，需要对比多个示例才能发现循环方向会反转——单个示例无法区分"总是向外"和"奇数时向外"。
