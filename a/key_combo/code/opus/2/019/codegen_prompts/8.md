## 新题 8：中位对齐线段界定编织区域

**组合逻辑**：[对齐/align](已有) → [编织填充/weave_fill](创新改造：编织区域的边界不由标记对决定，而由对齐后线段的共享跨度决定)；[中位线为参考/median_as_reference](已有) 决定对齐目标，[奇偶交替颜色/parity_alt_color](已有) 决定编织着色；交叉条提供编织的两种颜色

**来源原语**：对齐、线段、平行共向、中位线为参考（e376de54）；编织填充、交叉条、奇偶交替颜色（f3e14006）；裁剪/trim（e376de54）

**依赖链**：若干平行短线段按中位线对齐（改变各线段的起止列和长度） → 对齐后的线段共享一个列跨度 [c_left, c_right]，行跨度由最上和最下对齐线段的行坐标界定 → 该矩形区域内用两根交叉长条的颜色进行奇偶编织填充。删除对齐步骤则列跨度未统一，编织区域无法确定；删除编织步骤则仅完成对齐未产出网格纹。

将一组平行短线段按中位线的起止位置对齐，对齐后的公共跨度矩形区域用十字交叉条的两种颜色做奇偶编织填充。

**输入结构**：黑(0)背景，约 14x14 网格。一根蓝(1)色水平长条横贯网格某行（全宽或近全宽）。一根红(2)色垂直长条纵贯网格某列（全高或近全高）。二者交叉于一个像素。另有 3-5 根短水平线段（每段 3-6 像素长，颜色各异但不是蓝(1)或红(2)），位于不同行，起始列和长度各不相同，但方向一致（均水平）。短线段的行坐标各不相同，使中位线段唯一确定。生成约束：按行坐标取中位的那根短线段的列跨度与蓝/红交叉条均有重叠（即编织区域包含交叉条的部分区段）。

**规则**：
1. 在所有短水平线段中，按行坐标排序取中位线段（线段数为奇数时取正中，偶数时取靠上者）作为参考。
2. 对齐：将每根短线段水平平移使其左端与参考线段的左端对齐，然后截断或延伸使其长度与参考相同（延伸时新像素取该线段自身颜色；截断时丢弃超出部分）。
3. 对齐完成后，所有短线段共享列跨度 [c_left, c_right]（等于参考线段的列跨度）。行跨度为 [r_top, r_bottom]，其中 r_top 为最上方对齐线段的行坐标，r_bottom 为最下方对齐线段的行坐标。
4. 在矩形 [r_top..r_bottom] x [c_left..c_right] 内执行编织填充：位置 (r,c) 若 (r+c) 为偶数则涂蓝(1)，若为奇数则涂红(2)。此填充覆盖该矩形内的所有像素（包括背景、短线段、以及蓝/红长条落在此区域内的部分）。
5. 落在编织矩形内的对齐短线段保留原色绘制在编织之上（短线段像素覆盖编织像素）。
6. 编织矩形之外的蓝色水平长条和红色垂直长条保持不变。编织矩形之外的背景保持黑(0)。

**关键洞察**：编织区域的边界完全由中位对齐的结果决定——更换中位线段（因线段集合不同）会改变列跨度和行跨度，从而改变编织区域的大小和位置。对齐和编织通过共享边界紧密耦合。需要对比不同示例中线段数量和位置的变化来确认"中位线段"而非"最长线段"或"最短线段"是参考。
