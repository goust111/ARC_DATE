## 新题 2：遮罩恢复后对角折叠

**组合逻辑**：[对称补全/symmetry_completion](创新：作用于对角线 X 图案的遮罩恢复，利用八重轨道中旋转分量恢复同一对角线上被遮住的颜色) → [折叠/folding](已有：对角到边映射)

**来源原语**：对称补全、遮罩像素、正方形网格、八重对称轨道、轨道内唯一可见色（929ab4e9）；折叠、压缩、对角线像素、正方形边框、对角到边映射（ca8de6ea）

**依赖链**：遮罩隐藏了对角线上部分像素的真实颜色 → 八重对称恢复补全颜色（必须利用旋转分量，因为同一对角线上的反射伙伴也可能被遮罩） → 恢复后才能执行对角到边的折叠得到正确 3x3 输出。删除恢复步骤则折叠缺失颜色信息；删除折叠步骤则得到 5x5 而非所求的 3x3。

先用八重对称轨道恢复 5x5 X 形图案中被灰色遮罩覆盖的像素颜色，再将完整 X 折叠为 3x3 边框加中心。

**输入结构**：黑(0)背景上一个独立的 5x5 正方形区域。该区域内，两条对角线上的 9 个位置（含中心共享点）均有像素：其中 5-7 个为彩色前景像素（使用蓝(1)、红(2)、绿(3)、黄(4)等，每个位置颜色可不同），其余 2-4 个位置被灰(5)遮罩替换。遮罩分布约束：在每个八重对称轨道（4 个位置一组，中心单独一组）中，至少有一个位置未被遮罩，保证每个轨道有可见的参考颜色。同一轨道内所有未被遮罩的位置颜色相同。网格可以恰好 5x5，也可以更大（遮罩图案居于网格中央的 5x5 区域）。

**规则**：
1. 识别灰(5)为遮罩色。
2. 对 5x5 区域内每个灰(5)像素，计算其八重对称轨道——包括关于两条对角线、水平中线、垂直中线的反射以及 90°/180°/270° 旋转，共至多 8 个位置（在 5x5 中，非中心对角线位置的轨道大小为 4）。
3. 从该轨道中找到唯一的非灰色可见颜色，用此颜色替换遮罩。中心位置若被遮罩，其轨道仅含自身，此情况不会出现（生成约束保证中心不被遮罩）。
4. 恢复全部颜色后，执行对角到边折叠，将 5x5 X 折叠为 3x3：
   - 中心像素 (2,2) → 输出 (1,1)。
   - 西北臂：(1,1) → 输出 (0,0)，(0,0) → 输出 (0,1)。（从中心向外的像素依次映射到顶边从左到中）
   - 东北臂：(1,3) → 输出 (0,2)，(0,4) → 输出 (1,2)。（映射到右边从上到中）
   - 西南臂：(3,1) → 输出 (2,0)，(4,0) → 输出 (1,0)。（映射到左边从中到下）
   - 东南臂：(3,3) → 输出 (2,1)，(4,4) → 输出 (2,2)。（映射到底边从中到右）
5. 输出为 3x3 网格。

**关键洞察**：对角线上的像素被遮罩后，沿同一条对角线做反射得到的伙伴仍在该对角线上，也可能被遮罩。恢复必须依赖轨道中的旋转分量（90° 旋转将主对角线位置映射到副对角线位置），这是纯反射无法完成的。只有完成恢复后，折叠才能产出正确的 3x3 颜色布局。

1. `main(grid)` 必须实现新题描述中的确定性转换规则，不能只识别 `generate_input()` 的固定模板。禁止不同的input网格输出相同的output网格。

3. 生成器必须保证输入满足 `main()` 的隐式假设：对象不重叠、不越界、特殊标记唯一或可区分、匹配关系无歧义、关键分支出现概率相同。
4. 禁止把 ARC 颜色 id 、亮度、拼写等当作人类不可见的数值语义参与排序、大小比较或隐藏映射。颜色变化必须有可见结构线索。注意颜色亮度、拼写等也是不可见信息，若描述中出现违规的颜色id或者亮度，可自行使用少量的固定颜色替代，但注意生成时要在三个以内输入输出网格中对所有变换100%覆盖度。
