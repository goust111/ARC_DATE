## 新题 7：异或掩码指引滑块路径选择

**组合逻辑**：[异或合成/xor_compositing](已有原语，但产出物从最终输出变为路径标记) → [滑动/slide + 路径搜索/pathfinding](已有原语，但目标由异或结果动态确定) → [碰撞停止/collision_stop + 尺寸约束通行/size_constrains_passage](已有原语)

**来源原语**：异或合成/xor_compositing、半区掩码/half_mask、恰一为前景/exactly_one_foreground（来自 31d5ba1a）；滑动/slide、路径搜索/pathfinding、实心方块/solid_square、蜿蜒通道/winding_channel、尺寸约束通行/size_constrains_passage、碰撞停止/collision_stop（来自 332f06d7）

**依赖链**：两个掩码的异或产生目标标记 → 目标标记的位置决定滑块的移动方向和终点 → 通道宽度约束决定滑块能否到达。删去异或则目标未知；删去滑动则异或结果无用途。这是一种"解码-执行"双阶段结构，解码阶段的输出直接参数化了执行阶段。

先对两个掩码做异或得出目标位置，再让通道中的实心方块沿通道滑向该目标，途中受通道宽度约束。

**输入结构**：约 20x10 网格（高 20，宽 10），黑(0)背景。分为上下两大区域：
- 上半区（第 0-9 行）：等高分为两个子面板，各 5 行。上子面板有绿(3)前景掩码（若干散布像素），下子面板有灰(5)前景掩码（若干散布像素），其余为黑(0)背景。两个掩码的尺寸相同（5 行 x 10 列），可按位置对齐比较。
- 下半区（第 10-19 行）：一条蓝(1)蜿蜒通道（宽度 2~4 像素），从左侧延伸至右侧，至少有两个弯道。通道内有一个红(2) 2x2 实心方块（滑块），位于通道的一端。
- 输入保证：上半区异或后恰好有 1 个前景像素，该像素在下半区对应位置（行号减 10 映射）落在通道上。

**规则**：
1. 对上半区的两个子面板按位置对齐做异或：保留恰好一个子面板有前景的位置，标记为黄(4)。两个都有或都没有的位置保持黑(0)。
2. 将异或结果中的黄(4)像素位置映射到下半区：目标行 = 异或行 + 10，目标列不变。在下半区对应位置放置一个黄(4)目标标记。
3. 红(2)滑块沿蓝(1)通道向黄(4)目标滑动。滑块在通道中沿基数方向移动（每步选择能缩短与目标曼哈顿距离的方向；若有弯道则沿通道走向转弯）。
4. 滑块只能经过通道中完整容纳 2x2 的区段。若某段通道宽度不足 2，滑块无法通过，停在最远可达位置。
5. 若滑块到达目标位置，滑块覆盖黄(4)标记；若被阻挡则停在阻挡点前最后的合法位置。
6. 滑块原始位置填充为蓝(1)（通道色）。
7. 上半区的异或结果（黄色像素替换后的掩码区域）保持输出中显示；下半区显示滑动后的最终状态。

**关键洞察**：滑块的目的地不是直接给定的，而是必须通过两个掩码的对称差异来推断——空间推理和逻辑运算的结果共同确定了物理运动的终点。

## 实现要求

1. `main(grid)` 必须实现新题描述中的确定性转换规则，不能只识别 `generate_input()` 的固定模板。禁止不同的input网格输出相同的output网格。
2. `generate_input()` 必须随机生成多样样例，不能固定死。随机维度应覆盖：网格大小、对象数量、位置、颜色、方向、形状参数或关键分支。注意若描述中存在若干，需实现而不是只有单个，包括object或者对应关系等等。
3. 生成器必须保证输入满足 `main()` 的隐式假设：对象不重叠、不越界、特殊标记唯一或可区分、匹配关系无歧义、关键分支出现概率相同。
4. 禁止把 ARC 颜色 id 、亮度、拼写等当作人类不可见的数值语义参与排序、大小比较或隐藏映射。颜色变化必须有可见结构线索。注意颜色亮度、拼写等也是不可见信息，若描述中出现违规的颜色id或者亮度，可自行使用少量的固定颜色替代，但注意生成时要在三个以内输入输出网格中对所有变换100%覆盖度。

6. 若规则有多个分支，生成器不能长期固定成一个分支；应让分支在随机样例中合理出现。分支概率不必平均——难以发现的隐蔽分支（如少数情况下才触发的特殊规则）应适当提高出现概率，确保在 3 个训练示例中至少出现一次，否则求解者无法归纳该规则。对于颜色映射类规则，确保 2 个左右的示例即可覆盖所有映射关系（每种颜色→颜色的映射至少在某个示例中出现过）。
