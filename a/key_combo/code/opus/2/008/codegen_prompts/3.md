## 新题 3：角标裁剪区域内的同心距离色带

**组合逻辑**：[角标记像素/corner_marker + 裁剪/crop](已有) → [距离决定调色板/distance_determines_palette + 循环色带/cyclic_color_bands](创新：裁剪边界同时定义距离原点，标记像素深度编码调色板顺序，角标色本身成为调色板首色)

**来源原语**：角标记像素(3de23699), 裁剪/crop(3de23699), 内部包含/containment(3de23699), 同心正方形层(13e47133), 距离决定调色板(13e47133), 标记像素(13e47133), 循环色带(13e47133)

**依赖链**：角标记定义裁剪边界 → 裁剪边界即为同心距离的零号边界 → 角标色成为调色板首位 → 内部标记深度确定后续调色板位 → 循环色带向内辐射。删除角标则无法裁剪也无法确定首色；删除内部标记则调色板不完整；删除距离填充则无输出图案。

用角标记定义裁剪区域并提取内部图案，然后以裁剪边界为零距面、角标色为首色，结合内部标记像素的深度顺序构建循环调色板，向内辐射同心矩形色带。

**输入结构**：约 18x18 网格，黑(0)背景。一个灰(5)为主色的非黑像素簇占据网格中部。簇的四角各有一个红(2)像素作为角标记，它们恰好标出一个矩形边框（角标位于边框的四个角上）。边框内部（不含边框本身）是一块以灰(5)为底色的区域（约 8x10），其中散布 2~3 个孤立标记像素，颜色各不相同（从绿(3)、蓝(1)、黄(4)中选取），每个标记像素到裁剪边界的切比雪夫距离互不相同。簇外部可能有少量黑(0)背景上的干扰像素（随机颜色，不超过 3 个）。生成约束：(a) 角标恰好 4 个且同色；(b) 内部标记的切比雪夫距离两两不同且均 >= 1；(c) 内部无重复颜色的标记。

**规则**：
1. 定位四个红(2)角标记像素，确定它们围成的矩形区域。
2. 去除外层一圈边框（角标所在行列），提取内部矩形作为工作区（大小为原矩形减去上下左右各一行/列）。
3. 构建调色板：首位为角标色红(2)（切比雪夫距离 0，即紧贴裁剪边界的那一层）。然后按内部各标记像素到工作区边界的切比雪夫距离从小到大排序，依次将其颜色追加到调色板。
4. 对工作区内每个单元格，计算其到工作区边界的切比雪夫距离 d，将颜色设为 palette[d mod len(palette)]。
5. 忽略所有干扰像素。输出仅为重新着色后的工作区（裁剪后的矩形）。

**关键洞察**：角标记同时承担两个角色——标定裁剪范围和提供调色板首色。内部的孤立标记像素不是需要保留的对象，而是通过自身深度位置编码调色板顺序的指令。
