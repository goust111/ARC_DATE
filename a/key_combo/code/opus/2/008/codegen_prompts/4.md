## 新题 4：旋转绿色层后格子追踪与交叉混色

**组合逻辑**：[旋转/rotate](创新：仅对一种颜色的标记位置做格子坐标系内旋转，不旋转整个画布) + [连线/trace](已有) + [双色交叉混合色/intersect_blend_color](创新：交叉发生在原始红布局与旋转后绿布局之间)

**来源原语**：格子单元(e760a62e), 共行或共列(e760a62e), 连线/trace(e760a62e), 双色交叉混合色(e760a62e), 旋转/rotate(ed36ccf7), 标记像素(e760a62e), 网格线(e760a62e)

**依赖链**：绿色标记在格子坐标中旋转90度 → 旋转后的绿色位置参与追踪 → 红色原位追踪 → 两色追踪区域交叉处涂混合色。删除旋转则绿色追踪走向错误；删除追踪则无填充；删除混色规则则交叉区颜色不确定。

在格子坐标系中将绿色标记旋转90度后再做行列追踪，红色标记原位追踪，两色追踪区域交叉处涂黄色混合色。

**输入结构**：15x15 网格，黑(0)背景。青(8)线条将画布划分为 4x4 的正方形格子阵列（每个格子内部为 3x3 的黑(0)区域，格子间由 1 像素宽的青(8)网格线分隔；网格总尺寸 = 4*3 + 3*1 = 15）。若干格子内部中心放置红(2)标记像素（2~3 个），另有若干格子内部中心放置绿(3)标记像素（2~3 个）。无格子同时含两种标记。生成约束：(a) 格子阵列严格正方形（4x4）；(b) 红色标记至少有一对共享同一格子行或同一格子列；(c) 绿色标记在旋转后至少有一对共享同一格子行或同一格子列；(d) 旋转后的绿色标记不与红色标记占据相同格子。

**规则**：
1. 将格子阵列视为 4x4 的抽象坐标系，行列编号 0~3。
2. 红(2)标记保持原始格子坐标不变。对同一格子行中至少有两个红色标记的行，在该行最左和最右红色标记之间（含端点）的所有格子内部填充红(2)。对同一格子列中至少有两个红色标记的列，同理纵向填充。
3. 将每个绿(3)标记的格子坐标 (r, c) 变换为 (c, 3-r)（即在 4x4 坐标系中顺时针旋转 90 度）。以旋转后的坐标为准，按与红色相同的规则追踪并填充绿(3)。
4. 若某格子同时被红色追踪和绿色追踪覆盖，该格子内部改填黄(4)。
5. 所有填充仅作用于格子内部（3x3 区域），青(8)网格线始终保留不变。输出完整网格。

**关键洞察**：绿色标记的追踪路径不是从其输入位置出发，而是从旋转后的位置出发。求解者必须先在格子坐标系中完成旋转，才能正确预测绿色追踪走向和交叉位置。仅看单个示例可能误以为绿色也原位追踪。
