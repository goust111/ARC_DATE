## 新题 7：最小矩形颜色填补调色板缺口 + 楔形展开

**组合逻辑**：[筛选/filtering + 最小面积矩形保留/smallest_rect_retained](创新：最小矩形不是直接输出，而是为另一个操作提供参数) → [调色板行/palette_row + 以缺口为中心/centered_on_gap + 逐行扩展楔形/row_expand_wedge](创新：缺口颜色由筛选结果决定而非由标记竖条给出)

**依赖链**：筛选最小实心矩形 → 提取其颜色 → 填入调色板行缺口 → 以缺口为中心做楔形展开。删除筛选则缺口颜色未知；删除调色板行则展开内容未知；删除楔形展开则无输出图案。

找到面积最小的实心矩形，用其颜色填补调色板行唯一缺口，然后以缺口列为中心向下做逐行加宽的楔形展开。

**输入结构**：约 12x15 网格，黑(0)背景。第 0 行为调色板行：每个单元格填有不同颜色（从蓝(1)、红(2)、绿(3)、黄(4)、橙(7)中选取），恰好有一个单元格为黑(0)（即缺口）。第 1 行及以下：散布 3~5 个实心单色矩形（每个矩形的所有像素恰好填满其边界框，宽高均 >= 2），颜色和面积各不相同。其中至少一个矩形的颜色不出现在调色板行中（该颜色就是缺口应填的颜色）。另有 1~2 个非矩形干扰对象（像素不完全填满边界框的连通体）。生成约束：(a) 面积最小的实心矩形是唯一的；(b) 该最小矩形的颜色恰好是调色板行缺口应填的颜色；(c) 不同示例中最小矩形的颜色、位置、面积均不同。

**规则**：
1. 识别第 0 行调色板行及其缺口位置（黑(0)单元格所在列 g）。
2. 在第 1 行及以下找到所有单色非黑 4-连通对象。筛选出"实心矩形"——其像素恰好填满自身边界框的对象。忽略所有非矩形干扰体。
3. 在所有实心矩形中选取面积（像素数）最小的唯一者，读取其颜色 C_fill。
4. 将 C_fill 填入调色板行第 g 列，完成调色板。
5. 擦除第 1 行及以下所有内容（设为黑(0)）。
6. 以第 g 列为中心，从第 1 行开始逐行向下展开调色板行内容：第 1 行仅复制第 g 列的颜色（C_fill）；第 2 行复制第 g-1 至 g+1 列的颜色（3 列）；第 k 行复制第 g-k+1 至 g+k-1 列的颜色（2k-1 列）。若复制范围超出调色板行的有效宽度（0 至 W-1），则超出部分保持黑(0)。展开持续到某行的复制宽度达到或超过调色板行总宽度为止。
7. 输出完整网格。

**关键洞察**：最小矩形不出现在输出中——它是为调色板行提供缺失颜色的"信息源"。求解者必须先做面积筛选找到缺口颜色，再做楔形展开；两步之间通过颜色传递信息。
