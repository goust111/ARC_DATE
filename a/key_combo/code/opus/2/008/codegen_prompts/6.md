## 新题 6：引导掩码选精灵 + 图例互换决定输出色

**组合逻辑**：[引导掩码/guide_mask + 包围框包含/bbox_containment](已有) → [图例行内配对/legend_row_pairing + 同行颜色互换/same_row_bidirectional_swap](创新：互换不作用于整幅画面，而仅决定被选中精灵体的输出颜色) → [裁剪/crop](已有)

**来源原语**：引导掩码(bf699163), 包围框包含(bf699163), 空心精灵体(bf699163), 唯一被框选对象(bf699163), 图例(0becf7df), 图例行内配对(0becf7df), 同行颜色互换(0becf7df), 重涂色/recolor(0becf7df/3de23699), 裁剪/crop(bf699163)

**依赖链**：引导掩码框选出唯一精灵体 → 读取其颜色 → 在图例中查找该颜色的行配对色 → 将精灵体重涂为配对色 → 裁剪输出。删除引导掩码则不知选哪个精灵体；删除图例则不知输出颜色；仅看单个示例可能误以为输出色就是精灵体原色。

引导掩码选中一个空心精灵体后，不直接输出其原色，而是查找图例中该色的配对色进行重涂后再裁剪输出。

**输入结构**：约 14x14 网格，黑(0)背景。左上角 2x2 区域为图例，包含四种颜色按行配对：第 0 行 = [蓝(1), 红(2)]，第 1 行 = [绿(3), 黄(4)]（含义：蓝↔红互换，绿↔黄互换）。网格其余区域散布 3~4 个单色 3x3 空心正方形精灵体（仅外圈 8 像素着色，中心 1 像素为黑(0)），每个精灵体颜色不同，均取自图例中的四种颜色。另有一组灰(5)像素构成稀疏引导掩码，其边界框恰好框住其中一个精灵体。生成约束：(a) 精灵体之间互不重叠，与图例不重叠；(b) 引导掩码边界框内恰好完整包含一个精灵体；(c) 被框选精灵体的颜色属于图例四色之一。

**规则**：
1. 识别所有 3x3 空心正方形精灵体。
2. 收集所有非黑、非精灵体组成部分、非图例的前景像素，构成引导掩码。
3. 计算引导掩码的边界框，找到被该边界框完整包含的唯一精灵体。
4. 读取被选精灵体的颜色 C。
5. 在图例中找到 C 所在行的另一种颜色 C'（即 C 的配对色）。
6. 将被选精灵体的所有着色像素重涂为 C'。
7. 输出该精灵体的紧致 3x3 裁剪（重涂后）。

**关键洞察**：引导掩码决定"选哪个"，图例决定"变什么色"——两者缺一不可。仅凭单个示例可能误以为输出就是框选精灵体的原色；必须对比多个示例才能发现颜色发生了配对互换。
