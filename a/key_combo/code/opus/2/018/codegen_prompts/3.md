## 新题 3：寻路方向决定模板印章朝向

**组合逻辑**：[寻路](BFS 搜索障碍触发转向路径) → [模板提取](从网格角落提取印章模板) → [旋转+印章覆盖](在路径上每个标记点处，按路径行进方向旋转模板后覆盖印章)

**来源原语**：寻路/障碍像素/起止标记/路径/障碍触发转向(#4 2dd70a9a), 印章覆盖/模板图块/标记像素/标记指定放置位置/仅标记格被覆盖(#5 e734a0e8), 旋转(#3 2b83f449/#13 2697da3f)

**依赖链**：障碍布局唯一确定路径走向 → 路径上每个标记点处的行进方向唯一确定模板旋转角度 → 旋转后的模板覆盖在标记点上。没有路径就不知道在哪里印章也不知道旋转多少度；没有模板就没有可印的内容；没有旋转则印章朝向错误。

沿障碍触发转向路径前进，在路径经过的每个标记点处，按当前行进方向旋转模板后印章覆盖。

**输入结构**：约 18x18 网格，背景黑(0)。青(8)障碍像素散布于网格中部区域。一段 2-3 像素长的绿(3)水平或竖直线段标记起点及初始行进方向；一段同长的红(2)线段标记终点。网格的一个角落（如左上角 4x4 区域）包含一个由黄(4)像素组成的小型非对称模板图块（约 3x3 边界框，4-6 个黄像素，非旋转对称），模板区域与路径区域不重叠。路径可达区域中放置有 2-4 个品红(6)标记像素，这些像素位于路径将经过的黑(0)格子上。生成约束：从起点到终点存在唯一的障碍触发转向路径；每个品红标记都恰好位于该路径上；路径上各标记点处的行进方向不全相同（至少出现 2 种方向）。

**规则**：
1. 从绿(3)起点出发，沿初始方向做 BFS：在黑(0)格子上直行，仅当前方下一格为青(8)障碍时触发转向（尝试左转或右转，选择可行方向继续；生成约束保证每个转向点只有一个可行方向）。到达红(2)终点前一格时停止。记录完整路径及路径上每个格子的行进方向。
2. 提取黄(4)模板图块：取所有黄(4)像素的边界框作为模板。
3. 路径上每个品红(6)标记点触发印章操作。按路径顺序（从起点到终点）依次处理各标记点：
   - 行进方向为右 → 模板保持原始朝向（0 度）
   - 行进方向为下 → 模板顺时针旋转 90 度
   - 行进方向为左 → 模板旋转 180 度
   - 行进方向为上 → 模板顺时针旋转 270 度
4. 印章以标记点为中心放置（模板边界框中心对齐到标记点坐标）。超出网格边界的部分裁掉。后处理的印章覆盖先处理的（沿路径方向越靠后的印章优先级越高）。
5. 输出保留绿(3)起点、红(2)终点、青(8)障碍、模板角落原样不变。路径本身不涂色（路径格子保持黑(0)，除非被印章覆盖）。品红(6)标记像素被印章覆盖。

**关键洞察**：模板在每个标记点的朝向不是固定的，而是由路径在该点的行进方向唯一决定；而行进方向又由障碍布局唯一决定。改变任意一个障碍像素的位置都可能改变路径走向，从而改变所有下游标记点的印章朝向。
