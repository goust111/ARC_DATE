## 新题 2：环路弯折分类门控内部填充

**组合逻辑**：[环路追踪+分类涂色](追踪每条闭合环路，将弯折像素分为凸/凹) → [计数](统计各环路的凸弯折数，计算全局中位数阈值) → [填充](仅对凸弯折数达到中位数阈值且内部孔洞为正方形的环路进行填充，填充颜色由有无凹弯折决定)

**来源原语**：环路追踪/分类涂色/弯折像素/多数转向为凸/少数转向为凹(#7 15663ba9), 填充/封闭区域/孔洞/孔洞几何决定填充/仅正方形孔洞填充(#6 44d8ac46), 计数(#10 e872b94a), 内部包含(#6 44d8ac46)

**依赖链**：弯折分类（凸/凹）需要追踪完整环路 → 凸弯折计数需要在所有环路上完成后才能算出中位数 → 中位数门控 + 孔洞几何门控同时决定是否填充 → 填充颜色由该环路自身的凹弯折有无决定。全局阈值导致任何单个环路的结果都依赖于其余所有环路。

追踪所有闭合正交环路并分类弯折，以全局凸弯折中位数为门槛，对达标且内含正方形孔洞的环路按有无凹弯折分色填充。

**输入结构**：约 20x20 网格，背景黑(0)。3-4 条互不接触的蓝(1)闭合正交环路，每条环路为 1 像素宽的直角折线闭合曲线（每个前景像素恰好有 2 个 4-连通前景邻居）。每条环路围出一块黑(0)内部区域（孔洞）。部分孔洞的边界框为正方形且被黑像素完全填满（"正方形孔洞"），其余孔洞为长方形或 L 形等不规则形状。环路之间至少间隔 2 个像素，且不接触网格边界。生成约束：至少一个环路有凹弯折，至少一个环路仅有凸弯折；各环路的凸弯折数互不相同。

**规则**：
1. 追踪每条蓝(1)闭合环路。对每个环路像素，检查其两个 4-连通前景邻居的走向：若走向发生方向改变，该像素为弯折像素；否则为直行像素。
2. 对每个弯折像素，判断其转向方向。在该环路中统计两种转向方向的出现次数，出现次数更多的为凸弯折，更少的为凹弯折（依据：简单直角闭合曲线的凸弯折总比凹弯折多恰好 4 个）。
3. 统计每条环路的凸弯折总数。将所有环路的凸弯折数排序，取中位数（环路数为偶数时取较小的中间值）。
4. 一条环路被"激活"当且仅当其凸弯折数 >= 中位数。
5. 对每条激活的环路，计算其内部封闭区域（4-连通黑(0)像素且被该环路完全包围）。若该封闭区域的边界框是正方形且被黑像素完全填满，则执行填充：
   - 若该环路不含任何凹弯折 → 填充为黄(4)。
   - 若该环路含有至少一个凹弯折 → 填充为红(2)。
6. 未被激活的环路、以及激活但孔洞非正方形的环路保持原样不变。直行像素和弯折像素的颜色保持蓝(1)不变（不做源题 #7 中的弯折像素重涂色）。

**关键洞察**：某条环路的孔洞是否被填充不仅取决于自身的孔洞形状，还取决于所有环路的凸弯折数分布——全局中位数阈值使得增减任何一条环路都可能改变其他环路的激活状态。必须分析完所有环路后才能做出任何一条环路的填充判断。

p = Path("/home/lixinyu/snap/a/key_combo/code/opus/2/018/2.py")
mod = SourceFileLoader("new_arc_task", str(p)).load_module()
sigs = set()
for i in range(100):
    inp = mod.generate_input()
    out = mod.main(inp)
    assert isinstance(inp, np.ndarray)
    assert isinstance(out, np.ndarray)
    assert inp.ndim == 2 and max(inp.shape) <= 30, f"input grid exceeds 30x30: {inp.shape}"
    assert out.ndim == 2 and max(out.shape) <= 30, f"output grid exceeds 30x30: {out.shape}"
    sigs.add(hashlib.md5(inp.tobytes() + str(inp.shape).encode()).hexdigest())
print("variants", len(sigs))
assert len(sigs) >= 20
