## 新题 5：象限定位决定模板旋转角度的补全

**组合逻辑**：[模板提取](从完整象限提取源模板) + [象限对应](锚定块中心定义象限轴，各象限位置编码旋转角度——创新：象限不再映射颜色到 2x2 格子，而是映射旋转角度到精灵体补全操作) → [旋转+补全](对每个不完整象限，按象限编码的旋转角度旋转模板，填补缺失像素)

**来源原语**：模板提取/补全/变换副本/对齐签名匹配/旋转反射等价(#12 79369cc6), 旋转(#3/#13), 象限对应/锚定方块/象限决定目标格(#11 d89b689b)

**依赖链**：需要先找到锚定块确定象限轴 → 再判断哪个象限有完整模板 → 源象限的位置决定其余三个象限各自的旋转角度 → 旋转后的模板与已有部分像素对比才能确定缺失位置。四步紧密串联，缺任何一步都无法正确补全。

以 2x2 锚定块为中心划分四象限，从唯一完整象限提取模板，按象限位置关系确定旋转角度，补全其余三个象限中的缺失像素。

**输入结构**：约 16x16 网格，背景黑(0)。网格中偏中心位置有一个 2x2 的灰(5)实心锚定方块。四个象限（以锚定块中心为原点划分的左上、右上、右下、左下区域）中，恰好一个象限包含一个完整的小型多色精灵体（边界框约 3x4 或 4x4，使用 2 种颜色如红(2)和蓝(1)，形状非旋转对称，边界框内无背景空洞——即所有格子都被红或蓝填满）。其余三个象限各包含该精灵体某个旋转版本的不完整副本（保留约 60%-80% 的像素，其余像素为黑(0)背景）。生成约束：完整象限随机选取（不固定在左上）；三个不完整副本中缺失的像素位置互不相同；每个副本保留的像素足以唯一确定其旋转角度。

**规则**：
1. 找到灰(5) 2x2 锚定方块，以其中心（四格交点）为原点，划分上/下、左/右四个象限。
2. 识别包含完整精灵体的象限（该象限中存在一个矩形区域，区域内无黑(0)背景像素）。提取该精灵体作为源模板。记录源象限的编号（左上=0，右上=1，右下=2，左下=3）。
3. 对其余三个象限，计算其旋转角度：旋转度数 = ((目标象限编号 - 源象限编号) mod 4) x 90 度（顺时针）。
4. 对每个目标象限，将源模板顺时针旋转相应角度得到期望图案。将该象限中缺失的像素（当前为黑(0)但期望图案中为非背景色的位置）填补为期望颜色。已有的非背景像素保持不变。
5. 输出：锚定块保持灰(5)不变，源象限保持不变，三个目标象限的精灵体被补全。

**关键洞察**：源象限不是固定的——必须通过完整性检测确定哪个象限是源，这一判断直接改变其余三个象限的旋转角度。如果误判源象限，所有旋转角度都会错误。此外，补全操作需要将旋转后的模板与已有像素精确对齐，已有像素既是对齐线索也是正确性校验。
