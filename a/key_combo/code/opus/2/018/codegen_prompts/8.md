## 新题 8：格栅异常值提取后借轴对称修复

**组合逻辑**：[逐行比较+异常值选择](每行格栅单元中找出唯一不同的异常图案) → [提取](将异常单元组成单列格栅) → [对称轴借用+对称补全](从该行的多数图案中提取对称轴，将其应用于异常图案进行对称修复——创新：对称轴不来自异常图案自身，也不来自一个独立的对称标记物，而是从被丢弃的多数图案中"借"来)

**来源原语**：提取/裁剪/网格单元/逐行比较/异常值选择(#8 38007db0), 对称补全/对称体/非对称体/对称轴借用(#19 4c5c2cf0), 精灵体(#8/#13)

**依赖链**：逐行比较 → 找到异常单元 → 提取异常单元的同时必须记住多数单元的对称结构 → 用多数单元的对称轴修复异常单元。提取和修复不能分离执行——修复所需的信息（对称轴）存在于被丢弃的多数单元中，若先丢弃再修复就丢失了修复依据。

从格栅的每行中提取唯一异常图案，再借用同行多数图案的对称轴将异常图案修复为对称形式。

**输入结构**：约 23x17 网格。灰(5)全行/全列分隔线将网格划分为等大的矩形格栅单元（如 4 列 x 3 行，每个单元 5x5 像素）。每个单元内部有一个由蓝(1)像素构成的精灵图案（3-8 像素的 4-连通形状）。同一行中，除一个异常单元外的所有单元都包含完全相同的图案，且该图案具有水平或竖直双边镜像对称性（具体是哪种对称性可能每行不同）。异常单元的图案是多数图案的"破损版"——有 1-2 个像素偏移了位置，导致对称性被破坏。生成约束：每行至少 3 个单元（保证多数图案可以可靠识别）；每行的异常单元位于不同列；异常图案与多数图案的差异不超过 2 个像素位置。

**规则**：
1. 对每行格栅单元，逐对比较单元内部图案（忽略灰分隔线），找出唯一不同的异常单元（与其余所有单元的图案不一致的那个）。
2. 对每行的多数图案（非异常单元共享的图案），检测其对称轴：若图案关于竖直中轴对称，轴为竖直轴；若关于水平中轴对称，轴为水平轴。若两个轴都对称，优先使用竖直轴。记录轴类型和轴位置（相对于单元内部坐标）。
3. 提取各行的异常单元，按原行顺序排列成单列格栅（保留灰分隔线，单元尺寸不变）。
4. 对每个提取出的异常单元图案，将多数图案的对称轴应用于它：对异常图案中的每个蓝(1)像素，计算其关于该轴的镜像位置；若镜像位置当前为背景，则填充为蓝(1)。若异常图案中存在不在多数图案对应位置上的多余像素（即多数图案在该位置为背景），则擦除该像素为背景。
5. 输出为修复后的单列格栅。

**关键洞察**：异常图案自身没有可靠的对称性信息（它本身就是不对称的），修复它所需的对称轴隐藏在被丢弃的多数图案中。这意味着"丢弃"和"利用"是同一批数据的两种用途——提取操作必须同时保存被过滤掉的多数模式的结构信息供后续修复使用。
