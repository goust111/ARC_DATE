## 新题 8：双轴反射平铺后涌现连通分量的奇偶重涂

**组合逻辑**：[mirror, tiling, both_axes_four_quadrants](已有，来自 3af2c5a8) → [counting, connected_component](已有，来自 08ed6ac7，创新：连通分量不是在原始输入上识别，而是在平铺后的图像上识别——反射接合处可能令原本独立的分量融合，产生涌现拓扑) → [recolor, alternating_parity_selection](已有，来自 817e6c09，创新：奇偶选择基于后续面积排名而非水平位置排名)

**来源原语**：mirror, tiling, both_axes_four_quadrants (3af2c5a8); counting, connected_component (08ed6ac7); recolor, alternating_parity_selection (817e6c09)

**依赖链**：双轴反射生成 2x2 平铺 → 在平铺结果上识别 4-连通分量（部分在边界处融合）→ 按面积降序排名 → 偶数排名分量重涂色。平铺改变了拓扑（涌现效应），排名基于融合后面积，奇偶选择基于排名——三步紧耦合。

将小网格双轴镜像平铺为四象限，在平铺后图像上按面积对连通分量排名，将偶数排名的分量重涂为另一色。

**输入结构**：一个约 5x4 的小网格，黑(0)背景上有 3-5 个蓝(1)前景像素，形成 2-3 个独立的 4-连通分量。至少一个分量有像素紧邻网格边缘（这样反射后该分量的副本会与原件在接合线处融合为一个更大的分量）。生成约束：平铺后所有蓝色分量的面积两两不同（保证排名无歧义）。

**规则**：
1. 构建 (2H)x(2W) 的输出网格：左上放原图，右上放水平镜像，左下放垂直镜像，右下放 180 度旋转。
2. 在输出网格上识别所有蓝(1)像素的 4-连通分量（跨越象限接合线的像素视为连通）。
3. 按面积（像素数）降序排列分量。若面积相同，以分量中行主序最靠前（行号小优先，行号同则列号小优先）的像素为代表，代表靠前者排名在前。
4. 将排名为偶数（0, 2, 4, ...）的分量重涂为红(2)。
5. 排名为奇数的分量保持蓝(1)。
6. 背景保持黑(0)。

**关键洞察**：平铺不只是空间扩展——反射边界处的拓扑融合改变了分量数目和面积排名。一个在原图中面积较小的分量可能因四份副本在角上融合而成为平铺后面积最大的分量，导致奇偶着色结果与直觉相反。
