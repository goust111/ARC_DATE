## 新题 8：碎片质心排序与边框区域图例填充的交叉约束

**组合逻辑**：[排序/质心方向分类](已有) + [填充/固定图例补色](已有) → 交叉约束：排序结果改变填充目标集合，两者在共享插槽上互相影响

**来源原语**：排序(sorting)、瓦片碎片(tile_fragment)、分隔插槽阵列(separated_slot_array)、质心偏移定位(centroid_offset_positioning)、质心方向映射插槽(centroid_direction_maps_to_slot) 来自 4e45f183；填充(fill)、边框区域(bordered_region)、固定图例(fixed_legend)、位置对应颜色(position_to_color)、缺失位补色(fill_missing) 来自 a834deea

**依赖链**：瓦片碎片的质心方向决定目标插槽 → 部分插槽是边框区域（内部有缺失位）→ 碎片放入边框区域后占据了部分内部位置 → 剩余缺失位用固定图例补色。排序和填充互相影响：不知道碎片去哪就不知道哪些位置需要补色，碎片占据的位置不参与补色。

将标记碎片按质心方向分入 3x3 插槽阵列，然后对阵列中的边框区域用固定位置图例补全缺失像素，碎片占据的位置不再补色。

**输入结构**：
- 19x19 黑(0)网格，被黑(0)分隔行和分隔列分为 3x3 共 9 个 5x5 瓦片插槽（分隔线位于第 6、12 行和第 6、12 列，宽度 1 像素）。
- 9 个插槽中 4~6 个非空，其余全黑。非空插槽分两类：
  - 碎片插槽（3~4 个）：包含青(8)频繁填充色和红(2)少见标记色。标记色像素形成一个小碎片（2~4 个红(2)像素），碎片相对于 5x5 中心 (2,2) 的质心行偏移和列偏移的符号组合决定目标方向（如行负列负→左上插槽，行零列正→右中插槽）。
  - 边框插槽（1~2 个）：一像素厚黑(0)边框围成的 5x5 区域，3x3 内部中部分位置已填有青(8)像素，其余内部位置为黑(0)（缺失位）。
- 生成约束：碎片的目标插槽可以是当前为空的插槽或边框插槽，但不会是另一个碎片插槽；至少一个碎片的目标是边框插槽；碎片放入目标插槽后至少留有 1 个缺失位待补色。

**规则**：
1. 对每个碎片插槽，提取红(2)标记像素的坐标集合，计算集合质心相对于 5x5 中心 (2,2) 的行偏移 dr 和列偏移 dc。根据 (sign(dr), sign(dc)) 确定目标插槽在 3x3 阵列中的位置：(-1,-1)→左上, (-1,0)→上中, (-1,+1)→右上, (0,-1)→左中, (0,0)→中心, (0,+1)→右中, (+1,-1)→左下, (+1,0)→下中, (+1,+1)→右下。
2. 将碎片的红(2)标记像素移动到目标插槽的对应 5x5 内部坐标位置（保持相对于 5x5 中心的相同偏移）。原碎片插槽中的红(2)像素位置变为黑(0)，其余青(8)填充保留。
3. 对每个边框插槽的 3x3 内部（第 2~4 行、第 2~4 列），应用固定位置颜色图例：
   ```
   蓝(1)  橙(7)  品红(6)
   黄(4)  灰(5)  灰(5)
   红(2)  栗(9)  绿(3)
   ```
   内部 3x3 中已有青(8)像素的位置保持不变；已有红(2)碎片像素（由步骤 2 放入）的位置保持不变；剩余的黑(0)缺失位填充为图例中对应位置的颜色。
4. 目标为空插槽（非边框）的碎片直接放入，该插槽不做图例填充。

**关键洞察**：碎片和边框不是独立处理的两类对象——当碎片的目标恰好是边框插槽时，碎片像素"占位"使得该位置不被图例颜色覆盖，从而改变了边框区域最终呈现的颜色图案。必须先解决排序（碎片去哪），才能确定填充（补哪些色），形成不可跳步的交叉约束。
