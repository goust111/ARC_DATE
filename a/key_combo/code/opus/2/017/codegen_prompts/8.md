## 新题 8：远程帧面积控制局部延伸高度

**组合逻辑**：[颜色匹配/color_matching](创新：匹配不是用于印章放置，而是建立种子像素与远程帧的对应关系) + [内部面积/interior_area 测量](已有) → [延伸填充/extension_fill](创新：延伸高度由远程帧面积决定，而非本地距离)

**来源原语**：矩形边框/rectangular_frame + 封闭内部/enclosed_interior + 内部面积/interior_area + 面积阈值决定颜色/area_threshold_determines_color(84f2aca1), 延伸填充/extension_fill + 距离控制高度/distance_controls_height(5207a7b5), 颜色匹配/color_matching(a251c730)

**依赖链**：按颜色将种子像素与远程帧配对 → 测量帧内部面积 A → A 决定种子像素的纵向延伸高度 → 执行延伸。删除颜色匹配则种子不知道参考哪个帧；删除面积测量则延伸高度不确定；删除延伸则无输出变化。

网格上半部有若干不同颜色的空心矩形帧，下方有一行彩色种子像素；每个种子按颜色匹配到对应帧，该帧的内部面积即为种子向上延伸的高度。

**输入结构**：约 15x18 网格，黑(0) 背景。上部区域（约行 1-10）：3-4 个一像素厚的空心矩形帧，每个帧的边框使用一种独特颜色（如红(2)、蓝(1)、绿(3)、黄(4)），各帧大小不同从而内部面积各异，互不重叠。下方有一行空白分隔（全黑）。底部种子行（约倒数第 2 行）：3-4 个单像素种子，颜色分别与上方某个帧的边框色对应，一一配对。种子在行内的水平位置各不相同，但不一定与对应帧水平对齐。生成约束：每个帧的内部面积（帧内黑像素数）互不相同，且均 <= 种子行到分隔行之间的可用行数，确保延伸不超出上部区域。

**规则**：
1. 对种子行中的每个彩色像素，按颜色找到上部区域中同色边框的矩形帧。
2. 计算该帧的内部面积 A（帧边框严格内部的黑(0) 像素总数）。
3. 从种子像素的位置向上延伸 A 个像素（包含种子自身则共 A+1 个像素；或不含种子则从种子上方一格起共 A 个像素——此处精确定义：从种子所在位置向上连续绘制 A 格，包含种子位置本身），颜色与种子相同。
4. 若延伸柱超出网格顶部，截断至顶部边界。
5. 上部区域的帧保持不变。
6. 若两根延伸柱在同一行列位置冲突（由生成约束保证不发生），则列号较小的优先。

**关键洞察**：种子像素的延伸高度不由自身的局部属性（如离某条线的距离）决定，而由网格另一区域中同色帧的内部面积这一远程几何属性控制。求解者必须建立"种子 ↔ 帧"的跨区域颜色对应，然后在帧上执行面积测量，最后将测量结果用作延伸参数——三个不同位置的操作通过颜色链接在一起。
