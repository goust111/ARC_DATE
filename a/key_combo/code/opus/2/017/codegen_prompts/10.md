## 新题 10：连线激活决定模板展开

**组合逻辑**：[连线/connect](创新：连线不仅是视觉操作，还是单元激活的判定机制) → [颜色到模板映射/color_stencil_map](已有) + [像素放大/pixel_expand](创新：展开不作用于索引网格的每个像素，而只作用于被连线激活的格阵单元)

**来源原语**：分隔线格阵/separated_tile_lattice + 标记像素/marker_pixel + 同行列对齐/same_row_col_align + 连线/connect + 局部偏移保持/local_offset_preserved(cbded52d), 色卡/color_swatch + 模板遮罩/stencil_mask + 颜色到模板映射/color_stencil_map + 像素放大/pixel_expand + 顺序配对/ordered_pairing(42f83767), 忽略干扰项/ignore_distractors(458e3a53)

**依赖链**：跨格阵单元连线标记 → 连线使原本无标记的中间单元获得颜色（被激活） → 检测每个单元是否被激活为单一非底色颜色 → 激活色查图例找模板 → 用模板图案替换激活单元内容。删除连线则中间单元不被激活、模板展开范围缩小；删除激活判定则无法区分应展开和不应展开的单元；删除模板展开则激活无视觉效果。

格阵中标记像素跨单元连线后，中间被连线穿过的单元获得颜色从而被"激活"；每个激活单元按其颜色查图例找到配对模板，用该模板图案替换单元内容。

**输入结构**：约 21x21 网格。顶部 4 行为图例区：3 个色卡像素（各 1x1，如红(2)、蓝(1)、绿(3)）在左侧，右侧对应 3 个 4x4 的灰(5)/黑(0) 二值模板图案，色卡与模板按从左到右顺序一一配对。图例下方 1 行全黑分隔。主区域：一个 3x3 格阵（9 个等大矩形单元，每个约 5x5），由灰(5) 全宽/全高分隔线划分。每个单元有统一的底色（如栗(9)）。部分单元在固定局部偏移位置有 0-2 个标记像素（使用红(2)、蓝(1)、绿(3) 之一）。其余单元无标记。生成约束：存在若干对标记，它们处于同一格阵行或同一格阵列、使用相同颜色、占据相同的局部偏移位置，满足跨格阵连线条件；连线穿过的中间单元在连线前在该局部偏移位置无标记；连线完成后，部分原本无标记的单元在某个偏移位置获得了颜色，从而被激活；每个被激活的单元最终只含一种非底色颜色（连线不会导致同一单元出现两种激活色）。

**规则**：
1. 在格阵中执行标记连线：对每种颜色和每个局部偏移位置，若某格阵行（或格阵列）中有两个单元在该偏移位置有该颜色的标记，则将它们之间所有中间单元的相同偏移位置也填充为该颜色（覆盖底色）。
2. 连线后检测每个单元：若该单元内存在至少一个非底色像素，且所有非底色像素为同一颜色 C，则该单元被"激活"，激活色为 C。
3. 对每个激活单元：在图例中按颜色匹配找到 C 对应的模板图案。将该单元的内容替换为模板图案——模板中灰(5) 位置涂为 C，模板中黑(0) 位置涂为底色栗(9)。模板与单元左上角对齐（若模板小于单元，剩余区域保持底色；若模板大于单元，截断至单元边界）。
4. 未激活的单元保持原样（底色 + 可能的原始标记）。
5. 图例区和分隔线保持不变。

**关键洞察**：连线不只是视觉上在格阵中画线——它是一个激活机制。原本空白的中间单元因为被连线穿过而获得了颜色，这个颜色又成为模板查找的索引键。一个单元是否被模板展开取决于它是否恰好位于两个同色标记之间的连线路径上——连线的发生与否决定了模板展开的范围。求解者若只看最终输出，可能误以为"有颜色的单元就用模板"，但需对比多个示例才能发现"中间单元的颜色是连线产生的，不是预设的"。

import hashlib
import numpy as np

p = Path("/home/lixinyu/snap/a/key_combo/code/opus/2/017/10.py")
mod = SourceFileLoader("new_arc_task", str(p)).load_module()
sigs = set()
for i in range(100):
    inp = mod.generate_input()
    out = mod.main(inp)
    assert isinstance(inp, np.ndarray)
    assert isinstance(out, np.ndarray)
    assert inp.ndim == 2 and max(inp.shape) <= 30, f"input grid exceeds 30x30: {inp.shape}"
    assert out.ndim == 2 and max(out.shape) <= 30, f"output grid exceeds 30x30: {out.shape}"
    sigs.add(hashlib.md5(inp.tobytes() + str(inp.shape).encode()).hexdigest())
print("variants", len(sigs))
assert len(sigs) >= 20
