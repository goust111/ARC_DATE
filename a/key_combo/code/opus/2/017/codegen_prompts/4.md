## 新题 4：连线完成度作为格阵单元有效性判定

**组合逻辑**：[连线/connect](创新：连线不是最终视觉操作，而是拓扑诊断的手段) → [格内判定/cell_interior_test](创新：判定准则从"纯色"变为"连线后形成闭合矩形框") → [擦除/erase + 填充/fill](创新：擦除的是连线产生的框而非原始结构，填充的是诊断通过的单元内部)

**来源原语**：分隔线格阵/separated_tile_lattice + 标记像素/marker_pixel + 同行列对齐/same_row_col_align + 连线/connect + 局部偏移保持/local_offset_preserved(cbded52d), 分隔线网格/separator_lattice + 格内判定/cell_interior_test + 纯色即有效/solid_is_valid(458e3a53), 空心矩形/hollow_rectangle + 擦除/erase + 填充/fill + 空心内部变色/interior_recolor(d5d6de2d)

**依赖链**：在每个格阵单元内连接同行列标记 → 判断连线结果是否形成闭合矩形框 → 闭合的单元为"有效" → 有效单元擦除框线并填充内部 → 裁剪至有效单元的包围矩形。删除连线则无法形成框、判定无依据；删除判定则无法区分有效/无效；删除填充则有效单元无输出内容。

格阵中每个单元含若干标记像素，将同行同列标记连线后，判断结果是否闭合成矩形框；闭合者为有效单元，擦除框线并填充内部为指定颜色，无效单元清空，最后裁剪至有效区域。

**输入结构**：约 19x19 网格，由全宽和全高的灰(5) 分隔线划分为 3x3 共 9 个等大矩形单元（每个约 5x5）。每个单元内部为黑(0) 底色，散布 2-4 个红(2) 标记像素。部分单元中的标记恰好位于某个矩形的四角或四边上，使得将同行/同列的标记对连线后能形成一个完整的一像素厚闭合矩形框；其余单元的标记连线后产生不完整形状（L 形、T 形、零散线段等，不闭合）。生成约束：9 个单元中恰好 3-5 个为有效单元（连线后闭合），且这些有效单元在 3x3 格阵中构成一个连通的矩形子块（如 2x2 或 1x3）。每个单元内的标记位置互不相同，避免外观上的简单模式。

**规则**：
1. 在每个单元内部，对所有红(2) 标记执行连线：若两个标记在同一行（单元内部行号相同），用红(2) 填充它们之间的所有像素；若两个标记在同一列，同理。
2. 连线后，检测每个单元：如果单元内所有红(2) 像素（原始标记 + 新连线像素）恰好构成一个闭合的一像素厚空心矩形框（即存在一个矩形区域，其四边全为红(2)，内部全为黑(0)，无缺口），则该单元为"有效"；否则为"无效"。
3. 对每个有效单元：擦除所有红(2) 像素（置为黑(0)），然后将该矩形框的严格内部区域填充为绿(3)。
4. 对每个无效单元：擦除所有红(2) 像素，整个单元变为纯黑(0)。
5. 输出网格保留灰(5) 分隔线，裁剪至有效单元在格阵坐标中的紧边界矩形（包含对应的分隔线）。

**关键洞察**：连线操作不是为了视觉展示，而是一个诊断步骤——它生成的形状被检测拓扑闭合性，闭合与否决定单元的命运。求解者需要理解三步耦合：(a) 标记被连线成形状，(b) 形状被测试是否为闭合矩形，(c) 测试结果决定填充还是清空。仅看单个示例可能误以为"有标记的单元就是有效的"，需对比多个示例才能发现闭合性才是关键。
