## 新题 7：方向标记控制印章反射模式的分块展开

**组合逻辑**：[印章覆盖(stamp)](已有：将源像素展开为模板副本) + [镜像(mirror)](创新：不再由外部标记指示固定方向，而是每个源像素自带方向标记，控制该位置的模板是否翻转及翻转方式) + [重涂色(recolor)](已有：模板颜色替换为源像素颜色)

**来源原语**：印章覆盖/模板面板/前景像素/分块对应/源色决定模板涂色(来自 b190f7f5)；镜像/精灵体/标记像素/方向指示/标记指示放置侧(来自 760b3cac)；重涂色(来自 97d7923e)；分隔列(来自 195ba7dc)

**依赖链**：印章操作需要知道模板形状（来自模板面板）和放置位置+颜色（来自源像素），但还需要知道每个印章的朝向（来自方向标记）。如果没有方向标记，所有印章朝向相同——对于非对称模板，输出将会错误。三种信息（模板形状、源颜色/位置、翻转方向）共同决定每个输出块的内容，缺一不可。每个源像素同时编码了三个通道的信息：位置决定哪个块、颜色决定涂色、邻接的灰标记决定翻转方式。

左右两面板以灰色列分隔：左面板是一个非对称模板，右面板的彩色像素各带一个灰色方向标记；将每个源像素展开为模板的着色副本时，方向标记决定该副本是否水平/垂直翻转。

**输入结构**：网格约 (2N+1) x N，被一条灰(5)分隔列分成左右两个 N x N 面板（N 在 4-7 之间）。左面板：黑(0)背景上有一个蓝(1)模板掩码，由 3-6 个 4-连通像素组成，形状不对称（水平翻转后与原始形状不同，垂直翻转后也不同）。右面板：黑(0)背景上有 2-4 个彩色前景像素（每个像素颜色互不相同，颜色从红(2)、绿(3)、黄(4)、橙(7)、品红(6)中选取，不使用蓝(1)和灰(5)以避免与模板色和标记色混淆）。每个彩色像素恰好有一个灰(5)像素与之 4-邻接（上、下、左、右之一），作为方向标记。生成约束：不同彩色像素的方向标记指向不同方位（保证示例中能观察到至少两种不同的翻转方式）。

**规则**：
1. 以灰(5)分隔列为界，分离出左面板（模板 T）和右面板（源区域 S），两者均为 N x N。
2. 创建 N^2 x N^2 的输出网格，初始化为黑(0)。
3. 对右面板中每个非黑非灰的源像素 P（位置 (r, c)，颜色 K）：
   a. 找到与 P 4-邻接的灰(5)方向标记的方位：
      - 标记在 P 的左边 → 使用模板 T 原样（不翻转）。
      - 标记在 P 的右边 → 将 T 水平翻转（左右镜像）。
      - 标记在 P 的上方 → 将 T 垂直翻转（上下镜像）。
      - 标记在 P 的下方 → 将 T 水平 + 垂直翻转（等价于 180 度旋转）。
   b. 将翻转后的模板中蓝(1)像素替换为颜色 K，得到着色后的模板 T'。
   c. 将 T' 印入输出网格中以 (r, c) 为索引的 N x N 子块：子块的行范围为 [r*N, (r+1)*N)，列范围为 [c*N, (c+1)*N)。T' 中的非黑像素覆盖子块对应位置，黑像素不覆盖（保持子块原有值）。
4. 若两个印章子块存在空间重叠（不同源像素映射到相邻的块且模板像素延伸到块边界外时不会发生——每个印章严格限制在自己的 N x N 子块内），则不存在冲突。未被任何印章覆盖的格子保持黑(0)。

**关键洞察**：每个源像素不仅编码了"在哪个块放置什么颜色的模板"，还通过相邻的灰色标记编码了"模板朝哪个方向"。模板是非对称的，因此四种翻转方式产生四种不同的输出图案。要发现方向标记与翻转方式的对应关系，必须对比多个示例中不同标记方位产生的不同印章形状。
