## 新题 2：角标记矩形的条纹间距由外部精灵计数决定

**组合逻辑**：[角标记→矩形识别] + [计数](创新：从"点数表示"改为"决定填充疏密") + [填充](创新：从"整体红色填充"改为"条纹化填充，间距由外部信息决定") + [擦除]

**来源原语**：角标记/corner_marker (af902bf9), 四角标记围定内部/four_corners_define_interior (af902bf9), 填充/fill (af902bf9), 计数/counting (8f215267), 同色匹配/same_color_matching (8f215267), 图案精灵体/pattern_sprite (8f215267), 擦除/erase (8f215267)

**依赖链**：角标记 → 确定矩形几何区域；矩形内标签像素 → 确定填充颜色；外部同色精灵计数 → 确定条纹间距。三个独立信息源（几何、颜色、疏密）汇聚到一个填充操作上，删掉任何一个来源都无法确定输出。

角标记在参考题中直接触发整体填充；计数在参考题中映射为框内的点数。这里计数不画点，而是调制填充的空间频率——计数结果转化为几何参数，这种"数量→周期"的映射在参考题中不存在。

**输入结构**：约 15x15 网格，黑(0)背景。2-3 组黄(4)像素，每组恰好 4 个黄像素，构成一个轴对齐矩形的四个角（四个黄像素共享恰好两个行坐标和两个列坐标）。每个矩形内部（不含角）有恰好 1 个非黑非黄的"标签像素"，不同矩形的标签像素颜色互不相同（使用蓝(1)、红(2)、绿(3)等）。矩形之间不重叠（包括角），矩形内部高度至少 5 行（不含角行）。在所有矩形外部，散布若干小型 4-连通单色精灵体（每个 2-4 像素，非矩形形状），颜色从标签像素颜色集合中选取。每种标签颜色对应的外部精灵数量为 1-4 个。生成约束：每种标签颜色至少有 1 个外部精灵。

**规则**：
1. 识别每组 4 个黄(4)像素构成的矩形。矩形按左上角位置从左到右、从上到下排序处理。
2. 读取每个矩形内部的标签像素颜色 C。
3. 统计网格中所有矩形外部颜色为 C 的精灵体数量，记为 K。
4. 在矩形内部（不含四个角像素所在的行和列），从内部第 1 行开始，每隔 K 行涂一整行标签颜色 C 的水平条纹。具体地：内部行编号从 0 开始，行号对 (K+1) 取模为 0 的行涂 C 色，其余内部行保持黑(0)。
5. 擦除所有外部精灵体（恢复为黑(0)）。
6. 黄(4)角像素和标签像素保持不变。

**关键洞察**：矩形几何来自角标记，颜色来自内部标签，但条纹疏密来自外部精灵的数量——三个独立信息源决定一个输出。仅看一个示例可能误判条纹间距是固定值或由矩形尺寸决定，需要多个示例（同一矩形大小但不同精灵数量导致不同间距）才能发现计数与间距的关联。
