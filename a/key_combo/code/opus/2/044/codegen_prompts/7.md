## 新题 7：多源射线交叉构成封闭区域后填充

**组合逻辑**：[射线延伸](创新：从"单方向"改为"四方向十字射线") + [边界包围内部](创新：从"行段内部"改为"射线网格围成的矩形区域") + [填充](创新：不是填充预定义轮廓，而是填充由射线涌现出的封闭区域)

**来源原语**：射线延伸/ray_extend (97999447), 孤立像素/isolated_pixel (97999447), 画布边界/canvas_boundary (97999447), 填充/fill (af902bf9, bf32578f), 边界包围内部/boundary_encloses_interior (62b74c02)

**依赖链**：每个孤立像素独立发射十字射线 → 多组射线在网格上交叉形成格子状图案 → 格子中完全被射线包围的矩形区域（即不能沿黑(0)像素 4-连通到达网格边界的连通分量）被识别并填充。填充目标不是预先给定的，而是从射线组合中涌现出来的——单个像素无法围成区域，必须至少两个像素的射线交叉才能产生封闭空间。

在参考题中，射线仅向右延伸且不涉及封闭；填充操作作用于已知的角标记围定矩形或半轮廓定义的内部。这里封闭区域是射线交叉的涌现结果——没有任何单一像素"拥有"被填充的区域。

**输入结构**：约 13x13 网格，黑(0)背景。2-4 个蓝(1)孤立像素（每个像素上下左右相邻像素均为黑(0)），无两个像素在同一行或同一列。生成约束：所有蓝像素不在网格最外圈（至少距边界 1 像素），以保证所有四个方向的射线至少有 1 像素长。蓝像素的数量和位置保证至少产生 1 个封闭区域。

**规则**：
1. 对每个蓝(1)像素，向上、下、左、右四个方向发射射线至网格边界，射线颜色为蓝(1)。射线包含起始像素本身。
2. 射线在同一像素交叉时保持蓝(1)（颜色一致，无冲突）。
3. 所有射线绘制完毕后，识别黑(0)像素的 4-连通分量。每个分量若不包含任何位于网格最外圈（第 0 行、最后一行、第 0 列、最后一列）的像素，则视为封闭区域。
4. 将所有封闭区域的像素填充为红(2)。
5. 蓝(1)射线像素和非封闭的黑(0)区域保持不变。

**关键洞察**：每个像素单独只画一个十字，无封闭区域可言。封闭区域是多个十字的射线相互"围栏"的结果——这是组合涌现效应。像素数量和相对位置决定了封闭区域的数量和大小。仅看一个示例可能误以为"所有黑色矩形都填红"，需要看到不同像素配置（有的产生多个封闭区域、有的只产生一个）才能发现"封闭性"是填充的真正条件。
