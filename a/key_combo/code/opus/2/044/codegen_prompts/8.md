## 新题 8：同心正方形缩放后按图例重涂色并解决重叠

**组合逻辑**：[缩放/边长循环](已有) + [图例映射](创新：从"映射光晕色"改为"映射缩放后的正方形颜色") + [重涂色] + 重叠优先级（涌现：缩放改变大小关系后原本不重叠的正方形可能重叠）

**来源原语**：缩放/scaling (522fdd07), 边长循环变换/side_length_cycle (522fdd07), 同心定位/concentric_position (522fdd07), 奇数边正方形/odd_side_square (522fdd07), 图例映射/legend_mapping (5adee1b2), 颜色图例/color_legend (5adee1b2), 重涂色/recolor (5adee1b2)

**依赖链**：边长循环改变正方形大小 → 大小变化导致原本不重叠的正方形可能重叠 → 重叠需要优先级规则 → 同时图例映射改变颜色 → 颜色变化意味着优先级不能简单地"看颜色"，必须追踪原始颜色。两条独立的变换（尺寸和颜色）通过重叠问题产生交互。

在参考题中，正方形缩放后不会重叠（各自保持中心），且颜色不变。图例在参考题中用于膨胀光晕。这里缩放可以使小正方形变大（1→7），与相邻正方形发生重叠；同时颜色通过图例重映射，使得追踪"谁覆盖谁"需要同时理解两条变换链。

**输入结构**：约 15x15 网格，黑(0)背景。左侧两列为图例区：每行的第 0 列为原始颜色，第 1 列为映射后颜色，不同行的条目用黑(0)行分隔。图例条目覆盖所有出现的正方形颜色。主区域（第 3 列起）包含 3-4 个实心单色正方形，边长为奇数且属于集合 {1, 3, 5, 7}，颜色互不相同（使用蓝(1)、红(2)、绿(3)、橙(7)等）。生成约束：正方形中心之间的曼哈顿距离足够小，使得某些正方形在边长循环后会发生重叠。至少有一个边长为 1 的正方形（会变为 7）。所有正方形缩放后仍在网格边界内。

**规则**：
1. 读取图例区的颜色映射：原始颜色 → 新颜色。
2. 对每个正方形，保持中心不变，将边长 n 循环为：n > 1 时变为 n - 2；n = 1 时变为 7。
3. 按新边长从大到小的顺序绘制正方形（即大正方形先绘制，小正方形后绘制覆盖在上层）。新边长相同时，中心行坐标较小的先绘制。
4. 每个正方形绘制时使用图例映射后的新颜色。
5. 图例区保持不变。

**关键洞察**：边长为 1 的像素点会膨胀为 7x7 大方块，可能吞没周围原本较大的正方形。但绘制顺序是"大先小后"，所以虽然变大的原小正方形面积最大，它可能被更晚绘制的小正方形（原本较大但缩小了的）部分覆盖。同时颜色经过图例重映射，使得视觉上需要逆向追踪：看到的新颜色→查图例反推原始颜色→推断原始边长→推断缩放行为。
