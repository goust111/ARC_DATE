## 新题 5：宽高比决定镜像轴的标记对齐印章

**组合逻辑**：[印章放置/标记对齐](已有) + [镜像/宽高比决定镜像轴](创新：宽高比不再应用于角标记框而是应用于源精灵本身，在印章前先做镜像变换) + [面积排序叠加](已有) + [裁剪](已有)

**来源原语**：印章放置、标记对齐、面积排序叠加(83eb0a57)；目标对象、源精灵、共享标记(83eb0a57)；镜像、宽高比决定镜像轴(93c31fbe)；裁剪(83eb0a57)

**依赖链**：每个源精灵的边界框宽高比决定其镜像轴（宽→左右翻转，高→上下翻转），镜像后的精灵再通过共享标记对齐到目标对象上。镜像改变了精灵的几何形状，进而改变对齐后精灵覆盖的区域。去掉镜像则对齐位置产生的叠加图案不同；去掉标记对齐则不知道放在哪里；去掉面积排序则重叠区域的颜色不确定。

根据每个源精灵的宽高比翻转后，按共享标记对齐印在目标对象上，面积大的先印。

**输入结构**：约 20x20 的黑(0)背景网格。包含一个最大的多色目标对象（约 8x8 边界框，包含红(2)和黄(4)像素，形状不规则但 4-连通）以及 2~3 个较小的单色源精灵（每个约 3x5 至 5x3 边界框，像素数 5~10，4-连通，形状不规则）。每个源精灵使用蓝(1)、绿(3)或品红(6)中的一种颜色。每个源精灵恰好包含一种与目标对象共享的标记颜色——即精灵中有若干像素颜色为红(2)或黄(4)，与目标对象中的某些同色连通分量在形状上完全一致（作为对齐锚点）。不同示例中精灵数量、形状、宽高比和标记颜色不同。生成约束：各精灵的共享标记连通分量与目标对象中的对应分量形状完全匹配；各精灵的边界框宽高比严格非正方形（宽 != 高）。

**规则**：
1. 裁剪目标对象的紧凑边界框作为输出画布。
2. 对每个源精灵，计算其裁剪后边界框的宽高比。宽 > 高（横向精灵）→ 对该精灵做左右镜像翻转；高 > 宽（纵向精灵）→ 对该精灵做上下镜像翻转。
3. 对翻转后的精灵，将其共享标记颜色的连通分量与目标对象中相同颜色的连通分量对齐（平移使标记完全重合）。
4. 按精灵面积从大到小的顺序依次将精灵印到输出画布上。后印的精灵中非黑(0)像素覆盖先印的内容。
5. 超出输出画布边界的精灵像素被裁剪丢弃。

**关键洞察**：源精灵在印章前需先翻转，翻转轴取决于精灵自身的宽高比而非目标对象的属性。翻转改变了精灵中非标记像素的相对位置，因此同一精灵在宽版和高版输入中会在目标对象上产生不同的覆盖图案。需对比多个示例才能确认翻转的触发条件是宽高比而非其他属性。
