## 新题 4：轨迹反向射线的级联障碍擦除

**组合逻辑**：[射线投射/轨迹/反向投射](已有) + [碰撞停止](已有) + [按距离循环配色](创新：射线沿途像素不再统一着色而是按离发射源的距离循环配色) + [擦除](创新：射线命中障碍后擦除障碍，可能为其他射线开路) + [首个障碍](已有)

**来源原语**：射线投射、轨迹、反向投射、首个障碍(9f8de559)；标记像素(9f8de559)；碰撞停止(e87109e9)；按距离循环配色(a3f84088)；擦除(93c31fbe)

**依赖链**：轨迹方向决定射线方向（反向投射），射线着色依赖射线长度（距离循环配色），射线终点的障碍被擦除后可能使另一个标记的射线路径延长并命中新目标。处理顺序制造了级联效应——先处理的标记擦除的障碍影响后处理标记的射线路径。去掉轨迹则无法确定射线方向，去掉距离配色则射线着色不确定，去掉障碍擦除则无级联效应。

每个带轨迹的标记向轨迹反方向发射距离着色射线，射线命中障碍后擦除该障碍，可能为后续射线开路。

**输入结构**：约 18x18 的黑(0)背景网格。网格中散布 2~4 个标记像素，每个标记为红(2)单像素。每个标记恰好有一条由 3 个灰(5)像素组成的直线轨迹，轨迹从标记的某个正交方向延伸（上/下/左/右）。网格中另有 2~5 个橙(7)障碍像素（均为单像素）。标记、轨迹和障碍互不重叠。不同示例中标记数量（2~4）、轨迹方向和障碍位置均不同。生成约束：每个标记的射线方向（轨迹反方向）上至少有一个障碍或网格边界；至少有一个障碍位于两个标记的射线路径上，使得先发射的标记擦除该障碍后能改变后发射标记的射程。

**规则**：
1. 按标记像素在网格中的位置从上到下、从左到右的顺序依次处理每个标记。
2. 对当前标记，确定其轨迹方向（灰(5)像素相对于标记的方向），射线方向为轨迹的反方向。
3. 从标记位置沿射线方向逐格前进。对经过的每个黑(0)像素，按其与标记的曼哈顿距离 d 循环配色：d mod 3 == 1 时涂蓝(1)，d mod 3 == 2 时涂绿(3)，d mod 3 == 0 时涂黄(4)。
4. 射线在遇到第一个非黑(0)像素或网格边界时停止。
5. 若射线命中一个橙(7)障碍像素，将该障碍擦除为黑(0)。射线本身不延伸到障碍位置（障碍被擦除但该格不着射线色）。
6. 若射线命中非障碍的非黑(0)像素（如另一个标记、轨迹或已有射线着色），射线在该像素前一格停止，不修改该像素。
7. 所有标记处理完毕后，标记像素保留红(2)，轨迹像素保留灰(5)。

**关键洞察**：处理顺序（从上到下、从左到右）产生级联效应：先处理的标记擦除的障碍可能恰好挡在后处理标记的射线路径上，使后者的射线延伸更远并可能命中另一个障碍。仅凭单个示例无法确定是否存在级联效应；需要对比多个示例中不同标记排列与射线长度的关系才能归纳出处理顺序规则。

## 实现要求

1. `main(grid)` 必须实现新题描述中的确定性转换规则，不能只识别 `generate_input()` 的固定模板。禁止不同的input网格输出相同的output网格。
2. `generate_input()` 必须随机生成多样样例，不能固定死。随机维度应覆盖：网格大小、对象数量、位置、颜色、方向、形状参数或关键分支。注意若描述中存在若干，需实现而不是只有单个，包括object或者对应关系等等。
3. 生成器必须保证输入满足 `main()` 的隐式假设：对象不重叠、不越界、特殊标记唯一或可区分、匹配关系无歧义、关键分支出现概率相同。
4. 禁止把 ARC 颜色 id 、亮度、拼写等当作人类不可见的数值语义参与排序、大小比较或隐藏映射。颜色变化必须有可见结构线索。注意颜色亮度、拼写等也是不可见信息，若描述中出现违规的颜色id或者亮度，可自行使用少量的固定颜色替代，但注意生成时要在三个以内输入输出网格中对所有变换100%覆盖度。
5. 输出样例要视觉清晰，人类必须能从输入输出对中肉眼辨认出规律。具体要求：避免对象粘连、覆盖关系混乱、同一像素多重语义；不同逻辑步骤产生的结果不要大面积层叠在一起导致无法分辨哪个颜色属于哪个步骤；输入中各元素之间保持足够间距，输出中新增的标记/填充/路径等应与背景和已有元素在颜色上有明显区分；若规则涉及多层叠加，生成时控制对象密度和尺寸，确保叠加区域只占少数像素而非铺满整个网格。
6. 若规则有多个分支，生成器不能长期固定成一个分支；应让分支在随机样例中合理出现。分支概率不必平均——难以发现的隐蔽分支（如少数情况下才触发的特殊规则）应适当提高出现概率，确保在 3 个训练示例中至少出现一次，否则求解者无法归纳该规则。对于颜色映射类规则，确保 2 个左右的示例即可覆盖所有映射关系（每种颜色→颜色的映射至少在某个示例中出现过）。
