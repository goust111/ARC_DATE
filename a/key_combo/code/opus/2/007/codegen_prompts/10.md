## 新题 10：瓦片精确覆盖计数驱动底部矩形及对角线绘制

**组合逻辑**：[平铺/精确覆盖按形着色](已有) + [计数映射尺寸](创新：计数对象从散布标记像素变为瓦片分类统计) + [对角线](已有) + [矩形](创新：矩形不是输入中的对象，而是从计数结果生成的输出)

**依赖链**：前景掩码精确覆盖分瓦片 → 统计各类瓦片数量 → 最多/最少瓦片数量确定矩形宽/高 → 矩形着色取最多类颜色 → 矩形两底角画对角线。空间分解（几何推理）→ 计数（离散化）→ 尺寸编码（逆几何化）→ 对角线装饰，每步的输出类型都不同于输入类型，构成跨域信息转换链。

将上半区前景掩码精确分为四类 2x2 瓦片并着色，统计各类数量后在下半区绘制以最多/最少瓦片数为宽/高的彩色矩形及角对角线。

**输入结构**：约 16x16 网格，分为上下两个 8x16 区域。上半区：黑(0)背景上有一片灰(5)前景掩码（4-连通，30~48 像素），可被四类 2x2 瓦片精确覆盖——实心 2x2 方块、缺左上角的 L 型三连块、缺左下角的 L 型三连块、缺右上角的 L 型三连块（与参考题 626c0bcc 相同）。下半区：全为黑(0)背景。不同示例中掩码形状不同，各类瓦片的数量分布也不同。生成约束：四类瓦片中恰好有一个数量最多和一个数量最少的（均唯一）；最多的数量不超过 16，最少的不超过 8（保证矩形在下半区内）。

**规则**：
1. 对上半区的灰(5)前景掩码，用四类 2x2 瓦片精确覆盖（每个前景像素恰好属于一个瓦片）。瓦片类型着色：实心 2x2 → 蓝(1)，缺左上角 L → 红(2)，缺左下角 L → 绿(3)，缺右上角 L → 黄(4)。覆盖后上半区的灰色像素被替换为对应瓦片颜色，背景不变。
2. 统计四类瓦片各自的数量。
3. 取数量最多的瓦片类型，记其数量为 W、颜色为 C_max；取数量最少的类型，记其数量为 H。
4. 在下半区绘制一个底边左对齐于列 0、底边位于下半区最底行的实心矩形，宽度为 W 列，高度为 H 行，颜色为 C_max。
5. 从矩形左下角像素出发，向右上方画一条 45 度上升的黄(4)对角线，直到离开矩形范围为止（对角线仅在矩形内部绘制，覆盖矩形像素）。
6. 从矩形右下角像素出发，向左上方画一条 45 度上升的黄(4)对角线，同样限制在矩形内部。
7. 两条对角线若有交点，交点为黄(4)（后画覆盖先画）。
8. 下半区矩形外的区域保持黑(0)。

**关键洞察**：上半区的几何分解（瓦片覆盖）产生的信息不是留在原地（仅着色），而是被抽象为数量后传递到下半区构建一个全新的几何对象。求解者需要意识到上半区和下半区之间存在跨区信息传递，而不是独立的两道题。
