## 新题 8：双面板去干扰后按内部色锚定印章并分析象限覆盖

**组合逻辑**：[干扰项忽略](已有) + [印章覆盖/标记锚定精灵](创新：锚定不是靠标记像素的排列模式，而是靠标记颜色对应精灵内部的特定像素位置) + [所属象限/区域填充](创新：象限判据不是单像素位置，而是印章后覆盖最多像素的象限)

**来源原语**：擦除/erase（87ab05b8）、干扰项忽略/distractor_ignored（87ab05b8）、所属象限/containing_quadrant（87ab05b8）、区域填充/region_fill（87ab05b8）、印章覆盖/stamp_overlay（e6721834）、标记锚定精灵/marker_anchors_sprite（e6721834）、精灵体/sprite（e6721834）、双面板/dual_panel（e6721834）

**依赖链**：去干扰（两面板同时）→ 提取精灵模板 + 识别锚定标记 → 标记颜色在精灵内部找到对应像素 → 对齐印章 → 汇总所有印章覆盖 → 统计每象限覆盖量 → 最大象限做背景填充。去干扰是精灵提取和标记识别的共同前提；精灵内部结构决定对齐偏移；所有印章的叠加结果才能决定象限填充。

在双面板中去除两侧干扰像素后，用右面板标记像素的颜色在左面板精灵中找到同色像素作为锚点，将精灵印章到右面板各标记处；印章完成后，覆盖最多前景像素的象限背景被填充为灰色。

**输入结构**：约 10x21 网格，由一条 1 像素宽的灰(5)分隔列将网格分为左右两个 10x10 面板。左面板：黑(0)背景上有一个多色 4-连通精灵体（3~5 种颜色，8~15 像素），另有 2~3 个孤立的栗(9)干扰像素（不与精灵相邻）。右面板：黑(0)背景上有 2~3 个单像素标记，每个标记的颜色是精灵内部某种颜色（且该颜色在精灵中恰好出现 1 次），另有 1~2 个孤立的栗(9)干扰像素。不同示例中精灵形状和颜色分布不同，标记颜色和位置也不同。生成约束：每个标记颜色在精灵中唯一出现 1 次；各印章完全落在右面板范围内；不同印章可以重叠（后印覆盖先印）。

**规则**：
1. 忽略两个面板中所有栗(9)像素（将其视为背景）。
2. 左面板中剩余的非黑像素构成精灵模板。记录精灵中每种颜色每个像素的相对位置（相对于精灵任一固定参考点，如包围盒左上角）。
3. 右面板中剩余的非黑像素为标记像素。对每个标记像素，在精灵模板中找到与该标记同色的唯一像素，记其在精灵中的相对位置为 (dr, dc)。
4. 将精灵平移，使精灵中 (dr, dc) 处的像素对齐到该标记像素的位置，然后将整个精灵印章到右面板上（黑色背景透明，非黑像素覆盖目标位置）。按标记从左到右、从上到下的顺序依次印章，后印章覆盖先印章的重叠像素。
5. 所有印章完成后，将右面板分为四个象限（以面板行数和列数各自的中点为分界，中点行归上半，中点列归左半）。统计每个象限中非黑前景像素（即印章产生的像素）的数量。
6. 找到前景像素最多的象限（生成约束保证唯一），将该象限中所有仍为黑(0)的背景像素填充为灰(5)。
7. 灰(5)分隔列保持不变。左面板保持不变（含干扰像素被忽略后的状态——即干扰像素仍然显示为栗(9)，不被擦除）。

**关键洞察**：标记像素的颜色不是随意的，它指向精灵内部的一个特定像素位置来定义对齐锚点。这意味着同一个精灵在不同标记处会以不同的偏移量印章，而不是简单地以精灵中心对齐。这一锚定规则需要对比多个示例才能归纳出来。
