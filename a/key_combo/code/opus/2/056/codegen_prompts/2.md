## 新题 2：计数即层厚的同心框构建与图例重涂

**组合逻辑**：[计数](对象数量 → 几何参数) + [嵌套包裹](层厚由计数而非条纹高度决定) + [颜色替换映射](图例将输入色映射为输出色，独立于几何参数)

**来源原语**：计数/counting(ff28f65a)、数量映射/count_mapping(ff28f65a)、嵌套包裹/nested_wrapping(45a5af55)、逐层构建/layer_by_layer_build(45a5af55)、颜色替换映射/color_sub_map(e9b4f6fc)、微型图例/micro_legend(e9b4f6fc)、实心正方形/solid_square(22806e14)

**依赖链**：计数各色方块数量 → 数量决定同心框的层厚（不同于 45a5af55 中由条纹高度直接给出层厚）→ 数量大小排序决定从内到外的层序 → 图例将每种输入色映射为输出层色（不同于 e9b4f6fc 中对已有目标的局部替换，这里是对即将构建的结构指定颜色）。三条信息通路——计数→厚度、排序→层序、图例→颜色——分别来自不同的输入元素，缺任一通路都无法确定输出。

用一句话概括：数各色方块的个数作为层厚，按数量从少到多逐层包裹构建同心正方形框，每层颜色由微型图例指定。

**输入结构**：约 14x14 的网格。黑(0)为背景色。网格上散布着 3-4 种颜色的实心正方形（每个方块 2x2，同色方块互不相邻）。网格底部一行紧贴下边界放置一个 2xN 的微型图例条（N = 颜色种数），图例的上行像素为各方块颜色（如红(2)、蓝(1)、绿(3)），下行像素为对应的输出层颜色（如黄(4)、品红(6)、橙(7)）。图例上行的颜色集合与方块颜色集合完全一致。生成约束：不同颜色的方块数量互不相同（确保排序无歧义），每种颜色的方块数量在 1-4 之间。

**规则**：
1. 识别底部的 2xN 图例条：上行 → 输入色，下行 → 输出色，逐列对应。
2. 统计网格中（不含图例区域）每种颜色的 2x2 实心方块数量。记为 count(C) 对于每种颜色 C。
3. 将所有颜色按 count 值从小到大排列。若 count 相同（生成约束排除此情况，但作为保险），按颜色在图例中从左到右的出现顺序作为次序。
4. 构建同心正方形输出（黑(0)背景画布上）：
   - 取排序后第一种颜色（count 最小，设为 k_1），在画布中心放置一个 k_1 x k_1 的实心正方形，颜色为该色的图例映射输出色。
   - 取第二种颜色（count 为 k_2），在当前结构外围包裹一圈厚度为 k_2 像素的正方形框，颜色为该色的图例映射输出色。新结构边长 = 原边长 + 2 * k_2。
   - 依次对后续颜色重复包裹。
5. 输出仅包含该同心正方形结构，画布大小恰好包围最外层框。

**关键洞察**：方块的数量在源题(ff28f65a)中编码到固定位模式，在源题(45a5af55)中层厚由可视条纹高度直接给出；此题中数量从离散对象的计数中产生，再被用作几何参数，同时图例独立地决定了颜色——必须对比多个示例才能发现计数→厚度的映射规则（而非按颜色编号或其他属性）。

## 实现要求

1. `main(grid)` 必须实现新题描述中的确定性转换规则，不能只识别 `generate_input()` 的固定模板。禁止不同的input网格输出相同的output网格。

3. 生成器必须保证输入满足 `main()` 的隐式假设：对象不重叠、不越界、特殊标记唯一或可区分、匹配关系无歧义、关键分支出现概率相同。
4. 禁止把 ARC 颜色 id 、亮度、拼写等当作人类不可见的数值语义参与排序、大小比较或隐藏映射。颜色变化必须有可见结构线索。注意颜色亮度、拼写等也是不可见信息，若描述中出现违规的颜色id或者亮度，可自行使用少量的固定颜色替代，但注意生成时要在三个以内输入输出网格中对所有变换100%覆盖度。
5. 输出样例要视觉清晰，人类必须能从输入输出对中肉眼辨认出规律。具体要求：避免对象粘连、覆盖关系混乱、同一像素多重语义；不同逻辑步骤产生的结果不要大面积层叠在一起导致无法分辨哪个颜色属于哪个步骤；输入中各元素之间保持足够间距，输出中新增的标记/填充/路径等应与背景和已有元素在颜色上有明显区分；若规则涉及多层叠加，生成时控制对象密度和尺寸，确保叠加区域只占少数像素而非铺满整个网格。
6. 若规则有多个分支，生成器不能长期固定成一个分支；应让分支在随机样例中合理出现。分支概率不必平均——难以发现的隐蔽分支（如少数情况下才触发的特殊规则）应适当提高出现概率，确保在 3 个训练示例中至少出现一次，否则求解者无法归纳该规则。对于颜色映射类规则，确保 2 个左右的示例即可覆盖所有映射关系（每种颜色→颜色的映射至少在某个示例中出现过）。
