## 新题 7：最相似象限对的布尔交集

**组合逻辑**：[裁剪/crop + 相等比较/equality_comparison](创新：不是寻找异常值象限，而是寻找差异最小的象限对) → [布尔运算/boolean_op + 对齐/alignment](创新：不是两个预定义掩码的交集，而是动态选出的最佳象限对的交集)

**来源原语**：象限(quadrant)、分隔十字(separator_cross)、相等比较(equality_comparison)、异常值选择(outlier_selection) 来自参考题 88a62173；布尔运算(boolean_op)、掩码区域(mask_region)、对齐(alignment)、双掩码交集输出(bg_intersection_out) 来自参考题 6430c8c4

**依赖链**：四象限两两比较差异像素数 → 选出差异最小的象限对 → 将该对逐像素对齐做布尔交集 → 输出交集结果。象限选择决定布尔输入，布尔运算产生输出——去掉选择则不知道用哪两个象限，去掉布尔则选择结果无处使用。

在被十字线分成的四个象限中，找出图案差异最小的一对，输出该对象限前景的逐像素交集。

**输入结构**：约 13x13 的网格（奇数边长）。包含以下元素：
- 中间行和中间列被灰(5)填满，形成分隔十字，将网格分为四个大小相等的矩形象限（左上、右上、左下、右下）。
- 四个象限各含一个由单种前景色组成的图案（不同象限的前景色可相同或不同，取自 {蓝(1), 红(2), 绿(3)}）。每个象限的背景为黑(0)。
- 四个象限的图案两两不完全相同：任意两个象限至少有 1 个像素不同。
- 生成约束：恰好存在唯一一对象限，其差异像素数（对齐后颜色不同的位置数）严格小于其他所有 5 对。这对象限的前景色相同（否则交集无意义）。差异像素数 >= 1（两个象限不完全相同）。

**规则**：
1. 去掉灰(5)分隔十字，提取四个象限 Q_TL, Q_TR, Q_BL, Q_BR，每个象限为 (H x W) 的矩阵。
2. 对所有 6 对象限组合 (Q_i, Q_j)，逐像素比较，统计颜色不同的位置数 D(i,j)。
3. 选择 D 值最小的唯一一对象限（由生成约束保证唯一）。
4. 对选出的象限对，逐像素做交集：若两个象限在同一位置均为前景色（非黑(0)），输出该位置为绿(3)；否则输出黑(0)。
5. 输出为一个 (H x W) 的网格（单象限大小），不含分隔线。

**关键洞察**：这不是"找异常值"——没有三个相同加一个不同的结构。四个象限全部不同，求解者必须做全部六次两两比较，找出最接近的一对，再对该对做交集。选择标准（最少差异）只能通过对比多个示例才能确认。
