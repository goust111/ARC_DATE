## 新题 3：格子位置决定替换方向

**组合逻辑**：[格子结构/lattice + 行列阵列位置/row_column_position + 边缘与内部区分/perimeter_interior_distinction](已有原语) ⊗ [重涂色/recolor + 逐行顺序链式替换/chain_replace + 图例行序决定替换/legend_row_order](已有原语) → 创新：同一张图例对边缘单元格做正向替换，对内部单元格做逆向替换

**来源原语**：格子结构(lattice)、单元格区域(cell_region)、行列阵列位置(row_column_position)、边缘与内部区分(perimeter_interior_distinction) 来自参考题 8a371977；重涂色(recolor)、双列图例(two_col_legend)、逐行顺序链式替换(chain_replace)、图例行序决定替换(legend_row_order) 来自参考题 e4888269

**依赖链**：格子拓扑决定哪些单元格属于边缘、哪些属于内部 → 同一张双列图例对两类单元格施加方向相反的链式替换 → 最终颜色由位置类别和替换方向共同决定。去掉位置分类则无法确定替换方向；去掉图例则无法确定替换内容。

对格子网格中的每个单元格区域，根据其在单元格阵列中处于边缘还是内部，分别使用图例的正向或逆向链式颜色替换。

**输入结构**：约 13x13 的网格。包含以下元素：
- 灰(5)格子线构成完整的网格骨架：灰(5)填满外边框一圈，并以等间距的水平线和竖直线将内部分割为至少 3 行 3 列的矩形单元格阵列。每个单元格区域为 2x2 或 3x3 的同色方块。
- 单元格区域的颜色取自 {红(2), 蓝(1), 绿(3), 黄(4)}，分布不均匀但保证每种颜色至少出现一次。
- 在网格右侧或下方（与格子主体不相连），放置一个 2 列 N 行的双列图例（N 为 2~3 行）。图例每行由左列一个颜色和右列一个颜色组成，每个颜色占一个像素，两列紧邻。图例使用的颜色均来自上述四种单元格颜色。
- 生成约束：图例行数 >= 2。图例中不出现同色映射（左列颜色 != 右列颜色）。正向替换和逆向替换对至少一种初始颜色产生不同结果（否则位置分类无法被观察到）。

**规则**：
1. 识别灰(5)格子线，将非格子区域划分为矩形单元格阵列。记每个单元格在阵列中的行号 i（从 0 开始）和列号 j（从 0 开始），阵列共 R 行 C 列。
2. 将单元格分为两类：
   - 边缘单元格：i = 0 或 i = R-1 或 j = 0 或 j = C-1。
   - 内部单元格：其余。
3. 读取双列图例，从上到下记为替换序列 S_1, S_2, ..., S_N，其中 S_k = (左色_k, 右色_k)。
4. 对每个边缘单元格，执行正向链式替换：取该单元格当前颜色 c，从 S_1 到 S_N 依次扫描，若 c == 左色_k 则 c := 右色_k（继续扫描后续行，可能被多次替换）。最终 c 为该单元格的输出颜色。
5. 对每个内部单元格，执行逆向链式替换：取该单元格当前颜色 c，从 S_1 到 S_N 依次扫描，若 c == 右色_k 则 c := 左色_k（继续扫描后续行，以逆向规则处理）。最终 c 为该单元格的输出颜色。
6. 格子线保持灰(5)不变。图例区域保持不变。

**关键洞察**：图例并非全局统一地应用——同一张图例在边缘和内部扮演正反两个角色。仅观察边缘单元格会以为图例是正向映射，仅观察内部单元格会以为图例是逆向映射；必须同时对比两类区域才能归纳出完整规则。
