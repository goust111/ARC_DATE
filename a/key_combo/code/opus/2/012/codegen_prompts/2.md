## 新题 2：近邻标记决定补全色

**组合逻辑**：[补全/completion + 包围框内部/inside_bbox](已有原语) × [最近邻选择/nearest_neighbor_selection + 欧氏距离最小/minimum_euclidean_distance](已有原语) → [重涂色/recolor + 擦除/erase](创新：每个缺角的填充色不固定，由最近标记像素的颜色决定)

**来源原语**：补全(completion)、前景对象(foreground_object)、包围框内部(inside_bbox)、缺角补全正方形(missing_corner_completes_square) 来自参考题 3aa6fb7a；最近邻选择(nearest_neighbor_selection)、标记像素(marker_pixel)、欧氏距离最小(minimum_euclidean_distance)、擦除(erase) 来自参考题 6df30ad6；重涂色(recolor) 来自多题

**依赖链**：识别每个前景 L 形区域的缺角位置 → 以缺角坐标为基准计算到各标记像素的欧氏距离 → 距离最小的标记像素颜色成为该缺角的填充色。每个缺角独立查询最近邻，不同缺角可能获得不同颜色。

找到每个三像素前景簇的缺角位置，用距该缺角最近的彩色标记像素的颜色填充缺角，最后擦除所有标记像素。

**输入结构**：约 12x12 的黑(0)背景网格。包含以下元素：
- 3~5 个青(8)前景簇，每个簇由 3 个四邻接像素组成，恰好占据某个 2x2 区域的三个格子（即第四个格子为黑(0)背景），形成不同朝向的三像素弯折。不同簇的 2x2 边界框互不重叠，且任意两簇之间至少间隔 2 个像素。
- 3~4 个孤立的标记像素，颜色各不相同，取自 {红(2), 绿(3), 黄(4), 蓝(1)}，散布在网格各处。标记像素不与任何青(8)簇四邻接。
- 生成约束：对每个青(8)簇的缺角位置，存在唯一的最近标记像素（无距离平局）。不同簇的最近标记像素可以相同也可以不同。

**规则**：
1. 对每个青(8)前景簇，找到其 2x2 边界框中唯一的黑(0)像素——即缺角位置。
2. 对每个缺角位置 (r, c)，计算到每个标记像素 (r_m, c_m) 的平方欧氏距离 (r - r_m)^2 + (c - c_m)^2。
3. 取距离最小的标记像素，将缺角位置涂为该标记像素的颜色。
4. 擦除所有标记像素：将标记像素所在位置恢复为黑(0)。
5. 其余像素（青(8)前景、黑(0)背景）保持不变。

**关键洞察**：不同缺角可能被不同颜色的标记"认领"——补全色并非全局统一，而是由每个缺角自身的空间位置与标记像素的距离关系独立决定。求解者不能仅凭一个示例判定补全色是固定的。
