## 新题 4：框内标记计数决定叠放深度

**组合逻辑**：[计数/counting + 框内包含/inside_frame + 忽略干扰项/ignore_distractors](已有原语) → [堆叠/stack](创新：计数结果不渲染为计数图，而是编码矩形框的绘制优先级，决定重叠区域的可见颜色)

**来源原语**：计数(counting)、矩形框(rectangular_frame)、标记像素(marker_pixel)、框内包含(inside_frame)、忽略干扰项(ignore_distractors) 来自参考题 c8b7cc0f；堆叠(stack)、碰撞停止(collision_stop) 来自参考题 ac2e8ecf；重涂色(recolor) 来自多题

**依赖链**：统计每个矩形框内部的标记像素数量 → 数量决定该框的绘制优先级（计数越大，绘制越晚，越在上层）→ 重叠区域显示优先级最高的框的颜色。去掉计数则无法确定叠放顺序；去掉叠放渲染则计数结果无处使用。

多个部分重叠的彩色矩形框各含若干标记像素；按框内标记数从少到多依次绘制，标记数多的框覆盖标记数少的框，最终擦除标记。

**输入结构**：约 14x14 的黑(0)背景网格。包含以下元素：
- 3~4 个单像素厚的矩形框，每个框的边框颜色各不相同，取自 {蓝(1), 红(2), 绿(3), 橙(7)}。每个框为 4x4 到 7x7 的中空矩形（边框 1 像素厚，内部为黑(0)背景或标记像素）。
- 矩形框之间存在部分重叠：至少两对框的边框区域有像素位置冲突。重叠区域在输入中显示为任意一个框的颜色（输入中的重叠表现不确定，求解者不应依赖输入中重叠区域的颜色）。
- 黄(4)标记像素散布在网格各处：部分位于某些框的严格内部（不在边框上），部分位于所有框的外部。框外的黄(4)标记是干扰项。
- 生成约束：每个框内部的黄(4)标记数互不相同（保证排序唯一）。框的严格内部指边框围成的矩形区域去掉边框本身。

**规则**：
1. 对每个矩形框，统计其严格内部（边框围成区域减去边框像素本身）中黄(4)标记像素的数量。框外的黄(4)标记忽略不计。
2. 按标记数从小到大为矩形框排序，得到绘制顺序。
3. 在一个全黑(0)的空白画布上，按排序顺序依次绘制每个矩形框的边框（仅边框，不填充内部）。后绘制的框覆盖先绘制的框——即重叠区域显示后绘制的框的颜色。
4. 擦除所有黄(4)标记像素：输出中不出现任何黄(4)像素。
5. 输出画布尺寸与输入相同。

**关键洞察**：黄色标记像素是排序指令而非装饰——它们的空间分布（在哪个框内部）编码了框的深度层级。框外的黄色标记是故意设置的干扰，迫使求解者精确区分"框内"与"框外"。
