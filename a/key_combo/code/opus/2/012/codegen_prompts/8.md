## 新题 8：封闭拓扑决定镜像方向

**组合逻辑**：[封闭对象/closed_object + 开放对象/open_object + 封闭孔洞/enclosed_hole + 分离/separation](已有原语) → [镜像/mirror](创新：镜像轴不由几何结构给定，而由对象拓扑类别的多数决投票决定) + [擦除/erase](创新：少数类对象被删除而非移动)

**来源原语**：封闭对象(closed_object)、开放对象(open_object)、封闭孔洞(enclosed_hole)、分离(separation)、有孔者升无孔者降(hole_up_holeless_down) 来自参考题 ac2e8ecf；镜像(mirror)、拼接(concatenation)、四象限对称(four_quadrant_symmetry) 来自参考题 0c786b71

**依赖链**：将对象分为有孔（封闭）和无孔（开放）两类 → 多数类决定镜像轴方向（封闭多则左右镜像，开放多则上下镜像）→ 少数类对象被擦除 → 仅保留多数类对象，执行对应方向的镜像拼接。拓扑分类同时决定了"怎么镜像"和"保留什么"，二者不可分离。

统计网格中有孔对象和无孔对象的数量；多数类决定镜像轴方向，少数类被擦除，对保留对象所在的网格执行相应方向的镜像拼接。

**输入结构**：约 10x8 的黑(0)背景网格。包含以下元素：
- 4~6 个单色 4-连通前景对象，颜色取自 {蓝(1), 红(2), 绿(3), 黄(4), 橙(7)}，每个对象 4~12 像素，形状各异。对象之间互不四邻接。
- 部分对象为封闭型：其边界框内部存在至少一个被该对象像素完全包围（4-连通意义下与边界框外部不连通）的背景孔洞。
- 其余对象为开放型：边界框内部的所有背景像素均与边界框外部的背景四邻接连通（即无封闭孔洞）。
- 生成约束：封闭对象数与开放对象数不相等（保证有唯一多数类）。两类数量差恰好为 1（如 3:2 或 2:3，使判断不那么显然）。

**规则**：
1. 对每个前景对象，判断其是否为封闭型：在该对象的最小边界框内，检查是否存在黑(0)背景像素不与边界框外部背景四邻接连通。若存在则为封闭型，否则为开放型。
2. 统计封闭型对象数 N_closed 和开放型对象数 N_open。
3. 若 N_closed > N_open：
   - 擦除所有开放型对象（恢复为黑(0)）。
   - 对剩余网格执行左右镜像拼接：输出宽度加倍，左半为原图（含封闭对象），右半为左半的左右镜像。
4. 若 N_open > N_closed：
   - 擦除所有封闭型对象（恢复为黑(0)）。
   - 对剩余网格执行上下镜像拼接：输出高度加倍，上半为原图（含开放对象），下半为上半的上下镜像。
5. 输出尺寸为：镜像方向加倍，另一方向不变。

**关键洞察**：镜像的轴方向本身就是需要推断的隐藏规则——它不由任何几何标记指示，而由对象拓扑类别的统计多数决定。求解者需要同时发现三件事：如何分类对象、多数类如何决定轴、少数类被擦除。
