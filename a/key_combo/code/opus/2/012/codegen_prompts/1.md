## 新题 1：周期栅栏迷宫寻路

**组合逻辑**：[连线/draw_line + 周期间隔/periodic_space](创新：种子像素生成的周期竖线不作为纯视觉输出，而同时充当寻路障碍) → [寻路/pathfinding + 四邻接连通/four_neighbor_connect](已有原语) → [重涂色/recolor](已有原语)

**来源原语**：连线(draw_line)、种子像素(seed_pixel)、周期间隔(periodic_space)、竖线段(vertical_bar) 来自参考题 8403a5d5；寻路(pathfinding)、端点像素(endpoint_pixel)、障碍像素(blocker_pixel)、最短路径(shortest_path)、四邻接连通(four_neighbor_connect)、最短路径唯一(unique_shortest_path) 来自参考题 b15fca0b；重涂色(recolor) 来自多题

**依赖链**：种子像素的列坐标决定周期竖线的相位 → 竖线构成迷宫墙壁 → 墙壁拓扑决定两个端点之间的唯一最短路径 → 路径被涂色。改变种子位置即改变栅栏相位，进而彻底改变路径走向。

从种子像素生成周期竖线栅栏，同时在两个红色端点之间穿越栅栏间隙找到最短四邻接路径，输出栅栏与路径共存的网格。

**输入结构**：约 15x15 的黑(0)背景网格。包含以下元素：
- 一个绿(3)种子像素，位于网格内部（不在第 0 行、最后一行、第 0 列或最后一列）。
- 两个红(2)端点像素，分别位于网格的左侧区域（列索引 < 种子列索引）和右侧区域（列索引 > 种子列索引 + 4），保证两端点不在同一行。
- 输入中仅包含上述三个非背景像素，其余均为黑(0)。
- 生成约束：种子列坐标为偶数；两端点之间在生成的栅栏迷宫中存在唯一最短四邻接路径（栅栏间隙足够使路径连通但唯一）。

**规则**：
1. 从绿(3)种子像素所在列开始，向右每隔 2 列生成一条绿(3)竖线，每条竖线贯穿网格全高（从第 0 行到最后一行），直到超出网格右边界为止。种子所在列本身即第一条竖线。
2. 在种子像素所在行，每条竖线开一个 1 像素宽的缺口：即该行该列保持黑(0)不画绿线。这些缺口是栅栏的唯一通道。
3. 将所有绿(3)竖线像素视为不可通行障碍，红(2)端点像素视为可到达的起点和终点，其余黑(0)像素可通行。
4. 找到从一个红(2)端点到另一个红(2)端点的唯一最短四邻接路径。
5. 将该路径上所有中间黑(0)像素涂为黄(4)。端点保持红(2)。
6. 输出网格包含：绿(3)竖线栅栏（含缺口）、红(2)端点、黄(4)路径。未涉及像素保持黑(0)。

**关键洞察**：栅栏缺口全部位于种子像素所在行——求解者必须发现这一隐含规律，才能理解路径为何在特定行高度穿越每道栅栏。仅看路径本身无法推断缺口规则，必须对比多个示例中种子行与缺口行的对应关系。
