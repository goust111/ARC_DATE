## 新题 7：嵌套框深度编码迭代次数的裁剪重涂

**组合逻辑**：[外框绘制/嵌套检测](计数嵌套层数N) → [裁剪](提取最内层图案) → [重涂色](将图例映射迭代应用N次)

**来源原语**：外框绘制(frame_draw, 参考题18), 裁剪(crop, 参考题17), 重涂色(recolor, 参考题17), 空心矩形(hollow_rect, 参考题2/16), 微型图例(micro_legend, 参考题17), 尺寸倍增嵌套(size_doubled_nesting, 参考题18), 颜色替换映射(color_sub_map, 参考题17), 图例色替换(legend_color_replace, 参考题17), 内部区域(interior_region, 参考题16)

**依赖链**：检测嵌套空心矩形的层数N → N决定颜色映射的迭代次数 → 裁剪最内层获得操作对象 → 图例定义单步映射 → 迭代N次后得到最终颜色（可能产生循环或回到原色）。删除嵌套检测则不知迭代次数；删除裁剪则不知操作对象；删除图例则不知映射规则。

嵌套空心框的层数决定颜色映射的迭代深度，对最内层图案执行相应次数的颜色替换。

**输入结构**：黑(0)背景上约17x17网格。中心区域有2~3层同心嵌套的单像素宽空心矩形框，每层框颜色相同为灰(5)，相邻框间距1像素（内层框的外边界与外层框的内边界间隔1像素背景）。最内层框内部有一个3x3~5x5的多色图案（使用红(2)、蓝(1)、绿(3)中的2~3种颜色）。网格左下角或右下角放置1~2个水平微型图例（2像素宽1像素高的颜色对）：左像素为替换色，右像素为被替换色。生成约束：嵌套层数在不同示例中不同（2或3层）；图例定义的映射可以形成循环（如红→蓝、蓝→红）；最内层图案不含灰(5)和黑(0)。

**规则**：
1. 检测所有灰(5)色单像素宽空心矩形框，计算嵌套层数N（从外到内依次编号，最外层为第1层）。
2. 读取所有微型图例：每个图例的右像素为源色S，左像素为目标色T，表示映射S→T。将所有图例合并为一个颜色替换函数f（每种源色映射到一个目标色）。
3. 裁剪最内层框的内部区域，得到核心图案P（不含框本身）。
4. 对P中每个像素的颜色，迭代应用映射f共N次：第1次将颜色C替换为f(C)，第2次将f(C)替换为f(f(C))，以此类推。若某颜色不在映射中（f未定义该色），则该颜色在该次迭代中保持不变。
5. 输出为经过N次迭代后的图案P（尺寸与最内层框内部相同），不含任何框和图例。

**关键洞察**：嵌套框的几何结构不参与最终输出的图形内容，而是编码了一个数值参数（迭代次数）；当映射形成循环（如2色互换）时，偶数层和奇数层产生不同结果——需要多个不同嵌套深度的示例才能归纳此规则。
