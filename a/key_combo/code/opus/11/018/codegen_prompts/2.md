## 新题 2：象限归属决定延伸着色而非最近边

**组合逻辑**：[延伸 + 朝近端扩展](保留方向判定) + [象限对应](创新：象限归属决定延伸颜色而非方向)

**来源原语**：延伸、朝近端扩展、边缘条、控制像素（642248e4）；象限对应、象限决定目标格（d89b689b）；重涂色（48634b99）

**依赖链**：延伸方向取决于距离最近的边缘条（距离判断），但延伸颜色取决于控制像素所在的象限对应的边缘条颜色（象限判断）。两种独立的空间推理交织于同一操作的不同参数。

每个控制像素向距离最近的边缘条方向延伸一格，但延伸格的颜色由该控制像素所在象限对应的边缘条颜色决定。

**输入结构**：约 15x15 的黑(0)背景网格。四条完整边缘条分别位于网格的上、下、左、右边界（各占一整行/列），颜色各不相同——上=蓝(1)、右=红(2)、下=绿(3)、左=黄(4)。网格内部散布 5~7 个灰(5)控制像素，各自远离边界（与四边缘条的距离均 >= 2）。以网格中心为原点划分四象限：左上、右上、右下、左下。生成约束：每个控制像素的最近边缘条方向和其象限归属不完全一致（即存在至少一个像素距上边最近但位于右下象限等情况）。

**规则**：
1. 对每个灰(5)控制像素，沿行轴和列轴分别计算到四条边缘条的曼哈顿距离，确定距离最近的那条边缘条所在方向。
2. 在该方向上紧邻控制像素的下一格绘制一个新像素（延伸一格）。
3. 新像素的颜色不取决于最近边缘条，而取决于控制像素所在象限：左上象限 → 用上边缘条颜色蓝(1)，右上象限 → 用右边缘条颜色红(2)，右下象限 → 用下边缘条颜色绿(3)，左下象限 → 用左边缘条颜色黄(4)。
4. 控制像素本身保持灰(5)不变，四条边缘条不变。
5. 若延伸目标格已被边缘条占据，则该控制像素不做延伸（跳过）。

**关键洞察**：方向和颜色由两套独立的空间逻辑分别决定——必须同时正确推断"向哪延伸"（距离最近）和"用什么色"（象限归属）才能得出正确输出。仅看单个示例可能混淆这两个来源。
