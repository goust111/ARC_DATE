## 新题 7：半段标记推进 + 推进目标由边缘像素链决定

**组合逻辑**：[重涂色 + 半段位置保持](保留标记推进和半段逻辑) + [边缘像素匹配 + 链式连接排序](创新：推进目标不由尺寸+2决定，而由边缘接触链的下一个节点决定)

**来源原语**：重涂色、平移、竖条、标记段、尺寸排序、半段位置保持（48634b99）；边缘像素匹配、链式连接排序（78332cb0）

**依赖链**：必须通过边缘像素匹配建立竖条之间的链式顺序，才能确定标记应推进到哪根竖条；同时必须识别当前标记占据的是上半段还是下半段，以在目标竖条保持相同位置。链序和半段判断缺一不可。

将标记从当前竖条推进到边缘接触链中的下一根竖条，保持标记在上半段或下半段的位置不变。

**输入结构**：约 14x20 的黑(0)背景网格。包含 5~6 根绿(3)竖条（宽 1 像素，高度各不相同且均为偶数，范围 4~12 像素），分散在网格各列。其中恰好一根竖条的上半段或下半段被重涂为红(2)（标记段），其余部分仍为绿(3)。每根竖条的顶端或底端像素旁（水平相邻格）有 0~2 个橙(7)连接像素。生成约束：通过橙(7)连接像素的行对齐关系，所有竖条可被串成唯一无分叉链（若竖条 A 的底端连接像素与竖条 B 的顶端连接像素在同一行，则 A→B 相连）。

**规则**：
1. 识别所有绿(3)竖条及其顶端/底端的橙(7)连接像素。
2. 建立链：若竖条 A 的某个连接像素与竖条 B 的某个连接像素在同一行（水平对齐），则 A 与 B 相邻。按此关系将所有竖条串成有向链（从链头到链尾）。
3. 找到当前含红(2)标记段的竖条，确定标记占据其上半段还是下半段。
4. 将标记段恢复为绿(3)。
5. 在链中找到该竖条的下一个节点（下一根竖条），将其相同半段（上半或下半）重涂为红(2)。
6. 若当前标记在链尾，则推进到链头（环形）。
7. 所有橙(7)连接像素保持不变。

**关键洞察**：推进目标不是按高度排序的"下一根更高的竖条"（源题逻辑），而是由连接像素的行对齐形成的拓扑链决定——物理位置远近和高度大小都无法预测推进方向，只有破解链式连接规则才能求解。

6. 若规则有多个分支，生成器不能长期固定成一个分支；应让分支在随机样例中合理出现。分支概率不必平均——难以发现的隐蔽分支（如少数情况下才触发的特殊规则）应适当提高出现概率，确保在 3 个训练示例中至少出现一次，否则求解者无法归纳该规则。对于颜色映射类规则，确保 2 个左右的示例即可覆盖所有映射关系（每种颜色→颜色的映射至少在某个示例中出现过）。
