## 新题 4：色带压缩序列作为空腔平铺种子

**组合逻辑**：[压缩 + 行主色压缩单像素](提取色带序列) → [平铺 + 保持种子相位](创新：压缩产物本身成为平铺种子而非预设在空腔中)

**来源原语**：压缩、色带、空间排列顺序、行主色压缩单像素（4be741c5）；平铺、种子图案、矩形空腔、墙壁、图案填满空腔、保持种子相位（a57f2f04）

**依赖链**：色带区域的压缩输出一个短颜色向量，该向量直接成为空腔区域的平铺种子。没有压缩就没有种子；没有空腔就无处平铺。两步操作通过"压缩产物即种子"这一共享数据结构紧耦合。

将网格上半区的宽色带压缩为一列颜色序列，再将该序列作为种子图案平铺到下半区的矩形空腔中。

**输入结构**：约 20x12 的黑(0)背景网格，被一条水平灰(5)分隔线（完整行）分为上下两区。上区（约 8 行）：被 3~4 种非黑非灰颜色的宽色带完全覆盖（无黑(0)背景），各行的主色形成从上到下的连续带，带边界参差不齐（同一行可能有少量非主色噪声像素）。下区（约 10 行）：灰(5)墙壁围成一个矩形空腔，空腔内部全为黑(0)，空腔高度等于上区色带数量，宽度 >= 色带数量的 2 倍。生成约束：上区每行恰好有一个出现次数严格超过半数的主色；色带数量等于空腔高度。

**规则**：
1. 对上区逐行取主色（该行出现次数最多的颜色），将相邻同色行归为一个色带，按从上到下顺序得到颜色序列（如 [红(2), 蓝(1), 绿(3)]）。
2. 将该序列视为一列（Nx1）的种子瓦片。
3. 在下区空腔中，以空腔左上角为相位起点，将种子瓦片沿水平方向周期性重复，直至铺满整个空腔。即空腔第 i 行第 j 列的颜色 = 序列第 i 项（行索引从 0 开始对应序列第 0 项）。
4. 灰(5)分隔线和墙壁不变，上区保持原样不变。

**关键洞察**：上区的色带顺序直接编码了下区的平铺图案——求解者必须先完成压缩识别色带序列，才能知道空腔该如何填充。色带的数量恰好等于空腔高度这一隐含对应关系需要跨示例对比才能确认。
