## 新题 7：修补缺陷后对称补全，补全区域由孔洞面积编码颜色

**组合逻辑**：[修补](消除噪声标记) → [对称补全](利用修补后的干净形状) + [孔洞面积区分角色](孔洞面积→颜色) → [填充](补全区域的颜色由孔洞面积决定)

**来源原语**：修补(8886d717)、嵌入与孤立(8886d717)、对称补全(14754a24)、部分标记(14754a24)、孔洞(3a25b0d8)、孔洞面积区分角色(3a25b0d8)、填充(3a25b0d8)

**依赖链**：先修补嵌入缺陷恢复对象真实形状 → 检测修补后对象的对称性以确定补全模式 → 执行镜像补全 → 补全产生的新封闭孔洞按面积大小分配不同填充颜色

一句话总结：含有噪声标记的部分对称对象先被修补还原，再沿对称轴补全为完整形状，补全后产生的封闭孔洞按面积从小到大依次填入不同颜色。

**输入结构**：约 15x15 的网格，黑(0)为背景。网格中有 1~2 个蓝(1)的大型 4-连通对象（每个 20~40 像素）。每个对象大致呈现某条轴（水平或垂直）的半边形状——即对象主体位于对称轴的一侧，另一侧仅有少量像素暗示对称延伸方向。对象内部嵌入了 2~4 个红(2)噪声像素（嵌入定义：该红像素的 4 个邻居中至少 3 个是蓝(1)）。对象外部的黑色区域中还有 1~2 个孤立的红(2)像素（4-邻域全为黑色）。修补后的干净对象保证：以其边界框某条中线为轴，前景掩码的一半是另一半的子集（即一半完整，另一半是该半的部分残缺）。生成约束：补全后的完整形状保证产生 2~3 个大小不同的封闭孔洞（4-连通黑色区域被蓝像素完全围合）。

**规则**：
1. **修补**：将所有嵌入的红(2)像素（4-邻域中至少 3 个为蓝(1)）重涂为蓝(1)。孤立的红(2)像素（4-邻域全为黑(0)）保留不变。
2. **确定对称轴**：对修补后的蓝(1)对象，测试其边界框的水平中线和垂直中线，选择使一侧前景完全包含于另一侧镜像的那条轴。
3. **对称补全**：将较完整一侧的前景掩码镜像到较残缺一侧，填充缺失像素为蓝(1)。
4. **识别孔洞**：在补全后的蓝(1)对象内部，找到所有被蓝像素完全 4-连通围合的黑(0)区域（不与网格边界连通的黑色连通分量）。
5. **按面积填色**：将孔洞按面积（像素数）从小到大排序。最小孔洞填黄(4)，次小填绿(3)，第三小填橙(7)。面积相同时按孔洞左上角位置从左到右再从上到下排序。
6. 孤立红(2)像素、蓝(1)对象轮廓及其补全部分均保留。

**关键洞察**：修补和对称补全必须按严格顺序执行——若不先修补噪声，对称轴判断和补全方向都会出错；而孔洞只有在补全完成后才出现完整闭合形态，面积才能正确计算。三步之间存在严格的信息依赖。
