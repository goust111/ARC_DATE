## 新题 4：占位符形状归一化后旋转匹配决定填充方向

**组合逻辑**：[平移归一化 + 形状相同](形状分组) → [旋转匹配](确定每个实例相对模板的变换) → [射线延伸 + 边缘指示方向](变换决定射线朝向)

**来源原语**：占位符对象(ad38a9d0)、平移归一化(ad38a9d0)、形状相同(ad38a9d0)、旋转匹配(3a25b0d8)、二面体变换对应(64efde09)、射线延伸(97999447)、边缘指示方向(8886d717)、边缘线(8886d717)

**依赖链**：平移归一化识别同形状组 → 旋转匹配确定每个实例相对规范朝向的旋转角 → 旋转角决定射线发射方向 → 射线从对象边缘向外延伸至网格边界

一句话总结：同形状的占位符对象被分组，每个实例相对规范朝向的旋转量（0/90/180/270度）决定其向外射线的方向，射线颜色由对象所属形状组的颜色决定。

**输入结构**：约 20x20 的网格，黑(0)为背景。网格中散布 6~9 个灰(5)的 4-连通小对象（每个 4~7 像素，非矩形，非对称），它们属于 2~3 个形状组（同组对象平移归一化后为同一掩码的旋转变体）。每个形状组有一个"规范实例"：该实例的某一边（上/下/左/右）紧邻一个单独的彩色像素（红(2)、蓝(1)或绿(3)），该像素既标注了组颜色也标注了规范朝向（彩色像素相对对象的方位定义为"正前方"）。其余实例没有彩色邻接像素。生成约束：同组内各实例的旋转角度互不相同（从 0、90、180、270 中取）；不同组的规范朝向标记颜色不同；对象间距至少 3 格。

**规则**：
1. 对所有灰(5)对象做平移归一化，将其分为形状组（归一化掩码在 4 个旋转下匹配视为同组）。
2. 对每个组，找到具有彩色邻接像素的规范实例，记录其颜色 C 和规范朝向（彩色像素在对象的哪一侧 = "正前方"方向）。
3. 对组内每个非规范实例，确定其相对规范实例的旋转角 theta（0/90/180/270顺时针）。将规范朝向旋转 theta 度得到该实例的"正前方"方向。
4. 从每个非规范实例的边界框的"正前方"边中线位置起，沿"正前方"方向射出一条单像素宽的射线，颜色为 C，直至网格边界。
5. 规范实例本身不射出射线。彩色标记像素保留。灰(5)对象保留。射线不覆盖已有的非黑像素。

**关键洞察**：射线方向并非由对象自身的绝对位置决定，而是由对象相对其规范实例的旋转差异推导而出；必须同时完成形状分组、规范实例识别和旋转角计算三步才能确定射线朝向。
