## 新题 6：行均匀性检测驱动括号提取范围的选择性堆叠

**组合逻辑**：[检测/单色行标记](行分类) → [括号界定提取](仅对标记行提取) → [堆叠](提取结果堆叠) + [重涂色](按原行色重涂)

**来源原语**：检测(25d8a9c8)、单色行标记否则黑(25d8a9c8)、括号界定提取范围(505fff84)、控制像素对(505fff84)、堆叠(505fff84)、行段(505fff84)、重涂色(ad38a9d0)

**依赖链**：行均匀性检测标记哪些行"活跃" → 仅在活跃行中寻找括号控制像素对 → 提取括号间内容 → 按原行单色颜色重涂提取段 → 堆叠输出

一句话总结：仅从满足单色条件的行中识别括号标记并提取段落，提取的段被重涂为该行原本的单一颜色后依次堆叠为输出。

**输入结构**：约 12x18 的网格，黑(0)为背景。网格包含 10~14 行，其中约半数行是"单色行"（该行除两个特殊标记像素外所有像素为同一非黑颜色），其余行包含混杂的多种颜色。每个单色行中恰好有一个品红(6)像素和一个青(8)像素作为左右括号标记（品红在青的左侧），其余像素为该行的单一颜色（红(2)、蓝(1)、黄(4)或绿(3)之一）。非单色行中也可能偶然出现品红或青像素，但这些是干扰。生成约束：单色行的单一颜色各行可能不同；品红和青标记之间至少有 2 个像素的间距；非单色行中品红/青像素不成对出现（至多出现一个）。

**规则**：
1. 逐行检测：若该行中除品红(6)和青(8)以外的所有像素颜色相同且非黑，则标记为"活跃行"，记录其单一颜色 C_row。
2. 对每个活跃行，找到品红(6)和青(8)的位置，提取两者之间（不含标记本身）的像素序列作为一个行段。
3. 将提取的行段中所有非黑像素重涂为 C_row（该活跃行的单一颜色）。黑(0)像素保持黑色。
4. 忽略所有非活跃行（不提取任何内容）。
5. 将所有提取并重涂后的行段按原始行号从上到下依次堆叠，组成输出网格。输出宽度等于最长段的长度，短段右侧补黑(0)。

**关键洞察**：非单色行中出现的品红/青像素是干扰项——只有先通过均匀性检测确认哪些行是活跃的，才能正确忽略干扰括号；提取后的重涂颜色也依赖于均匀性检测得到的行色信息，两个机制在同一步检测中同时获取。
