## 新题 1：区域封闭射线与周期步长由邻域投票决定

**组合逻辑**：[洪泛填充](区域划分) + [区域邻接](构建邻接图) → [多数标记色涂色](跨区域投票) → [射线延伸 + 周期步长](投票结果决定射线周期)

**来源原语**：洪泛填充(e681b708)、区域邻接(e681b708)、多数标记色涂色(e681b708)、射线延伸(16de56c4/97999447)、周期步长(16de56c4)、孤立像素(e681b708/97999447)

**依赖链**：洪泛填充确定区域边界 → 区域邻接图确定哪些标记参与投票 → 投票结果决定射线颜色 → 同区域内孤立像素数量决定射线周期 → 射线在区域边界处截止

一句话总结：墙壁划分出封闭区域，每个区域中的孤立像素向四方射出周期条纹，条纹颜色由相邻区域的多数标记色决定，周期等于本区域孤立像素总数，射线在区域边界处停止。

**输入结构**：约 18x18 的网格，黑(0)为背景。蓝(1)像素组成多段水平/垂直墙壁线段（每段 3~7 像素长），将网格划分为 4~6 个不规则的 4-连通开放区域。每个区域内散布 1~4 个孤立的绿(3)像素（与墙壁和其他绿像素均不相邻）。在墙壁线段的端点或拐角处，有红(2)、黄(4)、橙(7)三种颜色的标记像素各若干个（每个标记恰好 8-邻域接触两个不同区域的边界）。生成约束：每个区域至少有 2 个相邻区域的标记可见；每个区域内的孤立像素数互不相同（取值 1~4）；标记颜色分布保证每个区域的邻域投票有唯一多数色。

**规则**：
1. 将蓝(1)墙壁和所有标记像素视为障碍，对剩余黑(0)+绿(3)像素做 4-连通洪泛填充，划分为若干封闭区域。
2. 对每个区域 R，找到所有 8-邻域同时接触 R 和另一区域的标记像素，统计这些标记中出现次数最多的颜色 C_R（唯一多数，无平局）。
3. 对区域 R 内每个孤立绿(3)像素 P，令 step = R 内孤立绿像素总数。从 P 向上/下/左/右四个方向逐格延伸：偏移量 d（从 1 开始）若 d mod step == 0 则涂 C_R，否则保持黑(0)。射线遇到蓝(1)墙壁、标记像素或网格边界时停止（不涂终点）。
4. 原有的绿(3)像素保留不变；墙壁和标记像素保留不变。

**关键洞察**：射线的颜色不由本区域内的任何元素决定，而由跨区域的邻域标记投票决定；同时射线的疏密由同区域内像素数量控制，两个机制耦合后使得每个区域的输出图案既依赖自身结构又依赖邻域信息。
