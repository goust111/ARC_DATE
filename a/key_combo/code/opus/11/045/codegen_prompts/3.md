## 新题 3：嵌套括号提取与深度驱动的字形印章

**组合逻辑**：[括号界定提取](识别嵌套层级) + [计数](嵌套深度) → [编码映射](深度→字形) → [图案印章](在提取位置印章)

**来源原语**：括号界定提取范围(505fff84)、堆叠(505fff84)、控制像素对(505fff84)、嵌套层(bd5af378)、计数(3b4c2228)、编码映射(dfadab01)、图案印章(dfadab01)、字形字典(dfadab01)

**依赖链**：括号对的嵌套关系决定每段的深度 → 深度值通过字形字典映射到特定 3x3 图案 → 提取的段被替换为对应深度的字形印章 → 堆叠时按深度从浅到深排列

一句话总结：从嵌套的彩色括号对中提取行段，按嵌套深度查字形字典印章到段的起始位置，然后按深度顺序从上到下堆叠输出。

**输入结构**：约 16x20 的网格，黑(0)为背景。网格分为两个区域：左侧 3x12 的字形字典区和右侧的主区域。字形字典区包含 3 个纵向排列的 3x3 图案（互不相同的非黑单色图案），从上到下分别对应深度 1、2、3，每个图案右侧紧邻一个灰(5)像素标注序号位置。主区域中有 6~8 行包含括号对：每行有一对同色像素作为左右括号（蓝(1)、红(2)、绿(3)三种颜色分别代表深度 1、2、3 的括号）。括号可嵌套：深度 2 的括号对完全位于某个深度 1 括号对的内部行范围中，深度 3 完全位于深度 2 内部。每对括号之间有 3~5 个黑(0)单元作为内容段。生成约束：同一深度的括号对不超过 2 对；括号颜色与深度的对应关系在所有示例中一致但需对比多个示例归纳（单个示例中可能只出现部分深度）。

**规则**：
1. 识别所有括号对：同一行中同色的两个非黑像素构成一对括号，括号颜色决定其深度（需从字典区旁的示例或多示例对比确定颜色→深度映射）。
2. 计算每对括号的嵌套深度 d（1/2/3）。
3. 从字形字典区读取深度 d 对应的 3x3 图案 G_d。
4. 对每对括号，提取其内部行段（括号之间的像素），将段的前 3 个单元替换为 G_d 的第一行，保留段的其余单元不变（若段长度 < 3 则裁剪图案）。
5. 将所有处理后的段按深度从小到大排序，同深度内按原始行号从上到下排序，依次堆叠为输出行。
6. 输出宽度等于最长段的长度，短段右侧补黑(0)。

**关键洞察**：括号的颜色并非直接标注深度数字，而是需要通过观察嵌套结构（哪种颜色被哪种颜色包含）来反推颜色-深度映射；这个映射又决定了选用哪个字形印章，形成两层间接推理。
