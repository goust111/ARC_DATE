## 新题 1：折叠探测定印章位

**组合逻辑**：[折叠fold](创新：折叠不作为最终输出而作为中间探测步骤) + [印章覆盖stamp] + [源色决定模板涂色](已有) + [对称互补symmetric_complement](已有，但从判定互补变为定位命中)

**来源原语**：折叠(e3497940)、印章覆盖(b190f7f5)、源色决定模板涂色(b190f7f5)、对称互补(e3497940)、分隔线(e3497940)

**依赖链**：折叠操作确定哪些散点"命中"了模板位置 → 命中位置决定印章目标坐标 → 散点颜色决定印章着色 → 印章在散点原始坐标处展开

用一句话概括：将右侧散点折叠到左侧模板上以发现命中关系，然后在每个命中散点的原始位置印章出以该散点颜色着色的模板副本。

**输入结构**：约 15x31 的网格，背景为黑(0)。中央有一条灰(5)竖直分隔列贯穿全高。左半区(15x15)包含一个由蓝(1)像素组成的4-连通精灵体（约5~8像素，形状不规则，非对称），位于左半区中部。右半区(15x15)包含3~5个散落的单像素前景点，颜色各不相同（从红(2)、绿(3)、黄(4)、品红(6)中取），各点之间至少间隔3格。生成约束：将右半区各点水平镜像到左半区坐标后，其中至少2个点落在蓝色精灵体的像素上（"命中"），至少1个点不落在精灵体上（"未命中"）。

**规则**：
1. 将右半区水平镜像（以分隔列为轴），叠加到左半区坐标系。
2. 检查每个镜像后的散点是否落在蓝色精灵体的像素位置上。
3. 对每个"命中"的散点：以其在右半区的原始坐标为锚点（锚点对应精灵体中该像素的局部偏移），将蓝色精灵体的完整形状以该散点的颜色印章到输出网格中。
4. "未命中"散点不产生任何输出。
5. 分隔列和左半区不出现在输出中；输出尺寸为15x15（即右半区大小），背景为黑(0)。
6. 多个印章重叠时，按散点在右半区中从上到下、从左到右的顺序绘制，后绘制覆盖先绘制。

**关键洞察**：折叠不是最终变换，而是一个探测机制——它揭示哪些散点与模板有空间对应关系；真正的输出变换（印章）发生在折叠之前的坐标空间中。

1. `main(grid)` 必须实现新题描述中的确定性转换规则，不能只识别 `generate_input()` 的固定模板。禁止不同的input网格输出相同的output网格。
2. `generate_input()` 必须随机生成多样样例，不能固定死。随机维度应覆盖：网格大小、对象数量、位置、颜色、方向、形状参数或关键分支。注意若描述中存在若干，需实现而不是只有单个，包括object或者对应关系等等。且若涉及到最短路径，则输入网格中必涉及到多条路径，对选择造成干扰。

6. 若规则有多个分支，生成器不能长期固定成一个分支；应让分支在随机样例中合理出现。分支概率不必平均——难以发现的隐蔽分支（如少数情况下才触发的特殊规则）应适当提高出现概率，确保在 3 个训练示例中至少出现一次，否则求解者无法归纳该规则。对于颜色映射类规则，确保 2 个左右的示例即可覆盖所有映射关系（每种颜色→颜色的映射至少在某个示例中出现过）。
