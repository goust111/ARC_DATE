## 新题 7：十字线切割生成区域后循环着色

**组合逻辑**：[连线(draw_line) + 画布全长十字线(canvas_spanning_cross)] 创新为多标记十字线产生网格分割 → [包围(enclosure)] 涌现出封闭区域 → [补全(completion) + 循环对称(cyclic_symmetry)] 创新为位置索引驱动循环着色

**来源原语**：连线/画布全长十字线/中心对齐(41e4d17e), 包围/封闭区域(b9b7f026), 补全/循环对称(73251a56)

**依赖链**：标记位置决定十字线位置；十字线相交切割出若干封闭矩形区域（涌现结构）；每个区域按其行列索引进行循环着色。不画十字线则无区域可着色；区域的行列索引由十字线位置决定，改变任一标记位置都会改变所有区域的着色结果。

多个彩色标记各生成一条全宽行线和一条全高列线，交叉的线网将画布切割为矩形区域，每个区域按行列位置进行循环着色。

**输入结构**：约 15x15 的灰(5)背景网格。网格中有 3~4 个不同颜色的标记像素（如蓝(1)、红(2)、绿(3)），它们不共享行也不共享列。网格中无其他前景像素。生成约束：标记不在网格边界行/列上（确保切割产生的最外圈区域非退化）；标记数量确保产生的区域 >= 6 个。

**规则**：
1. 对每个彩色标记，绘制一条该颜色的全宽水平线（覆盖标记所在行的所有列）和一条该颜色的全高垂直线（覆盖标记所在列的所有行）。线的交叉点保持后绘制的颜色（按标记的列坐标从左到右的顺序依次绘制，后画覆盖先画）。
2. 十字线网将网格切割为若干矩形区域。对这些区域按行列索引编号：行索引 r 从上到下为 0, 1, 2, ...，列索引 c 从左到右为 0, 1, 2, ...。
3. 收集所有标记颜色，按标记的列坐标从左到右排序，形成调色板序列 P。
4. 每个区域的填充颜色为 P[(r + c) mod len(P)]。用该颜色填充区域内部所有背景像素（线本身不被覆盖）。

**关键洞察**：十字线在源题中是装饰性叠加层，此处却是空间分割工具——线的绘制涌现出了源题中不存在的区域结构，而这些区域的着色规则借用了循环对称的索引逻辑，将一维循环扩展到了二维网格坐标上。
