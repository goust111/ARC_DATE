## 新题 3：对角朝向分类驱动滑动方向

**组合逻辑**：[分类(classify) + 对角朝向(diagonal_orientation)] → [计数(counting) 创新为计数决定距离] → [滑动(sliding) 创新为方向由分类决定] → [擦除(erase)]

**来源原语**：分类/对角朝向/多数朝向决定色(1d61978c), 计数/像素数转为条纹(d93c6891), 滑动/碰撞停止(a48eeaf7), 擦除(e4941b18)

**依赖链**：分类决定滑动方向（NW-SE 类→水平滑动，NE-SW 类→垂直滑动）；标记像素计数决定滑动距离；滑动执行后擦除原始标记。分类和计数共同约束滑动参数，两者缺一则滑动不确定。

将对角线段按朝向分为两组，每组的附属标记像素数决定该组整体滑动的距离，滑动方向由朝向类别决定。

**输入结构**：约 15x15 的黑(0)背景网格。前景有两种颜色：橙(7)像素构成若干 1 像素宽的对角线段（每段 3~6 像素，分为 NW-SE 朝向和 NE-SW 朝向两类，每类 2~3 段）；红(2)标记像素散布在网格中，每个红像素恰好与某一根橙色对角线段在 8-邻域相邻（即紧贴对角线段端点或侧面）。不同对角线段互不接触，红像素不互相相邻。生成约束：两类朝向的对角线段均至少 2 根；每类附属的红标记总数不同且均在 1~4 之间；滑动后不超出网格边界且对角线段之间不重叠。

**规则**：
1. 识别所有橙(7) 4-连通对角线段，判断每根的朝向：若像素沿左上→右下排列则为 NW-SE 类，沿右上→左下排列则为 NE-SW 类。
2. 对每根对角线段，计数其 8-邻域内的红(2)标记像素数。同一朝向类别的所有对角线段的标记数求和，得到该类的滑动距离 d。
3. NW-SE 类的所有对角线段整体向右平移 d 格（d 为该类的标记总数）。NE-SW 类的所有对角线段整体向下平移 d 格（d 为该类的标记总数）。
4. 擦除所有红(2)标记像素（置为黑(0)）。
5. 平移后的对角线段保持橙(7)色。原位置上的橙色像素被清除（如果新位置与原位置不重叠）。

**关键洞察**：分类在源题中仅决定重涂色，此处决定运动方向；标记像素计数在源题中转为条纹宽度，此处转为位移量——两个独立来源的机制交叉耦合在同一个滑动操作上。
