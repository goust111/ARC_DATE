## 新题 7：间隙补填完成分区线 + 带内对称检测重涂色

**组合逻辑**：[填充(间隙补填)](创新：补填不是最终操作而是构建分区边界的前置步骤) → [洪泛填充(隐式分区)](创新：完成的线段定义封闭区域) → [镜像对称检测+重涂色](创新：对称性判断的作用域由动态生成的分区决定)

**来源原语**：填充+单像素间隙补填+虚线段+邻接(a699fb00), 洪泛填充+封闭区域+区域排列顺序(7447852a), 镜像对称+重涂色+镜像配对则涂色(ce039d91)

**依赖链**：虚线间隙补填 → 连续线段形成水平隔板 → 隔板划分出若干水平带 → 每带内独立判断灰色像素是否水平镜像对称 → 对称带内灰色重涂为绿色；间隙不补则隔板不完整导致带合并、对称判断域改变、输出错误

补填蓝色虚线的单像素间隙形成完整水平隔板，隔板将网格分为若干水平带，检测每带内灰色前景像素的水平镜像对称性：对称则重涂为绿色，不对称则保持灰色。

**输入结构**：约 13x13 的网格，黑(0)背景。2~3 条水平虚线由蓝(1)像素组成，横贯网格（从第 0 列到最后一列），虚线中蓝像素之间有单像素黑间隙（即蓝-黑-蓝-黑-蓝……的模式），不同虚线位于不同行。虚线之间（以及虚线与网格上下边界之间）形成水平带区域，每个带内散布若干灰(5)前景像素（每带 3~7 个像素），构成小型不规则图案。生成约束：每条虚线横贯整行（若间隙补满则成为完整横线）；至少一个带的灰色像素关于该带水平中线（即 (带最左列 + 带最右列) / 2 对应的垂直轴）构成镜像对称，至少一个带不对称。

**规则**：
1. 扫描每一行：对于任何黑(0)像素，若其左邻和右邻均为蓝(1)像素，则将该黑像素涂为红(2)。这一步将所有虚线的单像素间隙补填，使虚线成为连续的水平线段。
2. 补填后的完整蓝+红水平线将网格分为若干水平带（被线段隔开的连通黑色区域）。自上而下编号。顶部边界到第一条完整线之间为第一带，两条线之间为中间带，最后一条线到底部边界为最后一带。
3. 对每个水平带，提取该带内所有灰(5)像素的位置集合。计算该带的垂直对称轴：轴位于网格列范围 [0, W-1] 的中线处（即列 (W-1)/2.0，W 为网格宽度）。
4. 检验灰色像素集合是否关于该垂直轴呈镜像对称——即对每个灰像素 (r,c)，镜像位置 (r, W-1-c) 也必须是灰像素。
5. 若某带的灰色像素完全镜像对称：将该带内所有灰(5)像素重涂为绿(3)。
6. 若某带的灰色像素不对称：保持灰(5)不变。
7. 蓝(1)线段像素和红(2)补填像素保持不变。

**关键洞察**：虚线间隙看似只是视觉噪声，实际上它们是"未完成的分区边界"。如果不补填间隙，相邻的带会通过间隙连通，合并为一个更大的区域，导致对称判断的作用域错误。间隙补填是分区正确性的先决条件，分区正确性是对称判断的先决条件。三层操作通过"作用域"紧密耦合。

    erased: 5 (grey) -- wildcards overlaid on blocks and separators
    payload: exactly 2 distinct non-{0,5} colors; one is foreground (majority in sprite), other is blank_color (minority)

  output: same grid size; separator lines become all-black; sprite blocks become solid foreground; blank blocks become the sprite tile; no grey remains

generation_strategy:
  approach: output-first
  steps:
    1. Pick N (2-4) and block_size (2-4). Compute grid side = N*block_size + (N-1).
    2. Pick two payload colors (not 0 or 5).
    3. Generate a random block_size x block_size sprite using both colors, foreground filling 67-75% of cells, counts distinct, no all-one-color rows/cols [observed].
    4. Build the NxN block state map (sprite or blank for each macro-cell). Ensure >= 1 sprite and >= 1 blank.
    5. Construct the output grid: sprite blocks -> solid foreground, blank blocks -> sprite tile, separators -> black.
    6. Construct the clean input grid (before grey): sprite blocks -> sprite tile, blank blocks -> solid blank_color, separators -> black.
    7. Generate a grey blob: pick a random seed cell, grow via BFS/random-walk across the grid (crossing separators), replacing cells with grey (5). Ensure each block keeps >= 1 non-grey cell and remains unambiguous. Ensure >= 1 block stays fully clean with 2 colors (a sprite block). Grey covers 5-25% of grid.
