## 新题 4：滑动矩形体到交叉位置后编织填充重叠区

**组合逻辑**：[滑动/slide] + [碰撞阻挡/collision_blocking](创新：两个矩形体同时滑动到交叉位置) + [编织填充/weave_fill](创新：编织范围由两个矩形体的重叠区域决定)

**来源原语**：滑动、矩形体、连接杆、锚定物、碰撞阻挡、沿杆滑至锚定物（98cf29f8）；编织填充、交叉条、奇偶交替颜色（f3e14006）；行列对齐（b7249182）

**依赖链**：两个矩形体各自沿连接杆方向滑动 → 滑动距离等于连接杆长度 → 滑动后两矩形体在某矩形区域重叠 → 重叠区域内按行列奇偶性交替填充两个矩形体的颜色 → 非重叠部分保持各自原色

一句话总结：两个不同颜色的矩形体各自沿连接杆滑动到目标位置，在重叠区域用两者颜色交替编织填充。

**输入结构**：约 18x18 的黑(0)背景网格。包含两个前景对象，颜色分别为蓝(1)和红(2)：一个是水平长条形（如 2x6），左端或右端连有一条单像素宽的水平连接杆（同色，长度 3~5 格）；另一个是垂直长条形（如 6x2），上端或下端连有一条单像素宽的垂直连接杆（同色，长度 3~5 格）。两根连接杆的延伸方向指向网格中心区域。生成约束：当两个矩形体各自沿连接杆方向滑动连接杆长度后，它们的新位置会产生一个非空矩形重叠区域（至少 2x2）；滑动后矩形体不超出网格边界。

**规则**：
1. 识别两个前景对象。每个对象由一个最大实心矩形体和一条单像素宽的直线连接杆组成。
2. 擦除两个完整对象（矩形体 + 连接杆均设为黑(0)）。
3. 将每个矩形体沿其连接杆指向的方向平移，平移距离等于该连接杆的长度（像素数）。在新位置绘制矩形体。
4. 计算两个滑动后矩形体的重叠矩形区域。
5. 在重叠区域内，对每个像素 (r, c)：若 (r + c) 为偶数，填充水平矩形体（原水平长条）的颜色；若 (r + c) 为奇数，填充垂直矩形体（原垂直长条）的颜色。
6. 重叠区域外的矩形体部分保持各自原色不变。

**关键洞察**：连接杆不仅指示滑动方向和距离（这与参考题 98cf29f8 类似），还隐式定义了重叠区域的位置和大小——重叠区域的编织填充规则（行列奇偶性）需通过多个示例对比才能发现。
