## 新题 7：同色框补全后按框内面积排序生成竖条摘要

**组合逻辑**：[对称补全/pattern_union_completion] + [计数/counting](创新：统计补全后的内部填充面积) + [排序/sorting] + [竖条生成](创新：输出形式为竖条长度编码)

**来源原语**：对称补全、同色框共享图案、按边框颜色分组、彩色边框、内部图案（42918530）；计数、排序、按计数升序排列（d4c90558）；竖条、长度排名（97d7923e）；重涂色（多源）

**依赖链**：同色边框之间共享内部图案并补全 → 补全后统计每种颜色框内的填充像素总数 → 按填充数排序 → 输出为竖条摘要，每种颜色一列竖条，高度等于填充数，列序按填充数从左到右递增

一句话总结：先补全同色框的共享内部图案，再统计各色填充量，最后按填充量排序输出为竖条柱状图。

**输入结构**：约 16x16 的黑(0)背景网格。包含一个 M 行 N 列（M, N 各 2~3）的矩形阵列，由等尺寸的彩色边框组成（每框约 5x5），框间间隔 1 列/行黑(0)像素。边框颜色从蓝(1)、红(2)、绿(3)、黄(4)中取，每种颜色恰好出现 2~3 个框。每个框有一像素宽的单色边框，内部 3x3 区域中部分格子填为边框同色像素，部分为黑(0)。同色框的内部图案互有差异但互为补集子集（即它们的并集形成完整图案，单个不完整）。生成约束：同色框补全后的填充像素总数互不相同（不同颜色之间）；填充总数不超过 9（使输出竖条高度可控）。

**规则**：
1. 按边框颜色对所有框分组。
2. 对每个颜色组，收集该组所有框内部图案的相对位置并集。将此并集写回该组每个框中（补全操作）。
3. 对每种颜色，统计补全后单个框内填充像素的数量（由于同组框补全后一致，取任一即可），记为 f。
4. 按 f 从小到大对颜色排序。
5. 输出一个 f_max 行 x 颜色数列的网格（f_max 为最大填充数）。每列对应一种颜色（从左到右按 f 递增）。每列从底部起填充 f 个该颜色的像素，其余为黑(0)。

**关键洞察**：补全操作改变了内部填充数量——未补全前各框的像素数各不相同，补全后同色框一致但不同颜色间仍有差异——排序的对象是补全后的数量而非原始数量，这一点仅看单个示例中的原始框无法确定。
