## 新题 3：十字擦除后对存活连通分量做锚点叠加

**组合逻辑**：[十字擦除/cross_erasure](提供结构筛选) + [分组/grouping](创新：按存活连通分量的颜色分组) + [透明叠加/transparent_overlay](创新：叠加对象由擦除结果动态确定)

**来源原语**：十字擦除、标记块、保护像素、特定色像素豁免（319f2597）；分组、按边框颜色分组（42918530）；透明叠加、锚点像素、锚点对齐、锚点重合叠加（137eaa0f）；裁剪（f5aa3634）

**依赖链**：2x2 黑色标记块的位置决定哪些行列被擦除 → 灰(5)保护像素在擦除中存活 → 存活的非保护彩色像素形成若干连通分量 → 每个连通分量恰好包含一个灰(5)锚点像素 → 按连通分量颜色分组 → 同色组内的分量以灰像素为锚点叠加 → 裁剪叠加结果输出

一句话总结：用 2x2 黑块的十字擦除清理网格后，以存活的灰像素为锚点将同色连通区域叠加合并，输出裁剪后的合成图案。

**输入结构**：约 14x14 的网格，大部分格子填有彩色像素（蓝(1)、红(2)、绿(3)等），形成若干不规则的同色区域。每个区域内含恰好一个灰(5)像素。网格中有一个 2x2 的黑(0)标记块。部分彩色像素恰好位于标记块所在行列的交叉位置。生成约束：擦除后，每种出现的前景色恰好剩余 2~3 个连通分量；每个存活连通分量内恰好有 1 个灰(5)像素；同色连通分量的形状互不完全相同（有部分差异，叠加后互补）；擦除不会消灭任何连通分量中的全部像素（每个分量至少有部分像素不在擦除行列上）。

**规则**：
1. 找到唯一的 2x2 黑(0)标记块，选中它覆盖的 2 行和 2 列。
2. 将这些行列上的所有非灰(5)像素重涂为黑(0)。灰(5)像素不受影响。
3. 在擦除后的网格中，提取所有非黑、非灰的 4-连通连通分量。每个连通分量的边界框内恰含一个灰(5)像素。
4. 按颜色对连通分量分组。对每个颜色组，将该组所有连通分量裁剪为各自的最小边界框（灰像素包含在裁剪中）。
5. 将同组的所有裁剪精灵体以灰(5)像素为锚点对齐叠加（灰像素重合于同一位置，彩色像素取并集，重叠处保持该组颜色）。
6. 如果只有一个颜色组，输出该组叠加结果的最小边界框裁剪。如果有多个颜色组，将各组叠加结果按组中连通分量数量从多到少、从上到下排列在输出网格中，组间间隔 1 行黑(0)像素。

**关键洞察**：灰像素同时扮演两个角色——在擦除阶段作为保护像素存活，在叠加阶段作为对齐锚点——这种双重身份需对比擦除前后才能理解。
