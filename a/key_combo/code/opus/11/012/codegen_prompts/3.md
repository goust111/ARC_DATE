## 新题 3：指示方向平铺与支撑匹配印章的遮挡叠加

**组合逻辑**：[平铺tiling](创新：方向由指示像素决定而非固定四方向) + [印章覆盖stamp_overlay] + [处理顺序决定遮挡order_determines_block](创新：平铺副本按距离排序决定遮挡优先级)

**来源原语**：平铺(e8dc4411), 指示像素/指示决定方向色(e8dc4411), 印章覆盖(e5062a87), 支撑签名匹配(e5062a87), 处理顺序决定遮挡(1190bc91), 邻接触碰(e8dc4411)

**依赖链**：指示像素同时编码平铺方向和印章颜色 → 模板沿指示方向重复平铺 → 当两个不同方向的平铺路径在同一像素重叠时，距各自源模板更近的副本优先（遮挡规则）。方向决定路径，路径决定重叠区域，距离决定遮挡胜负——三层逻辑紧密耦合。

一句话总结：根据多个指示像素的方向将同一模板分别沿不同方向重复平铺，重叠处由距源模板的曼哈顿距离决定哪条路径的颜色胜出。

**输入结构**：约 15x15 的灰(5)背景网格。中央有一个黑(0)色模板对象（4-连通，约 3x3 边界框，像素数 4~7）。模板外围有 2~3 个单像素指示物，每个指示物颜色不同（从红(2)、蓝(1)、绿(3)中选取），且各自位于模板的不同侧（上、下、左、右中的不同方位）。生成约束：至少有两个指示物的平铺路径会在某些像素上重叠；指示物与模板曼哈顿距离为 1（即 4-邻接）。

**规则**：
1. 识别背景色灰(5)、黑(0)模板和各彩色单像素指示物。
2. 对每个指示物，计算其相对于模板质心的方向（上/下/左/右取最接近的正方向）。该方向即为该指示物对应的平铺方向。
3. 对每个指示物：将模板形状以该指示物的颜色沿平铺方向重复绘制，每次平移量等于模板边界框在该方向上的尺寸，直到超出网格边界。第 k 个副本的距离编号为 k（k=1 为紧邻原模板的第一个副本）。
4. 原模板位置保持黑(0)不变。
5. 遮挡规则：若某像素被多条平铺路径覆盖，保留距离编号最小的那条路径的颜色；若距离编号相同，保留平铺方向为水平方向（左或右）的路径颜色。
6. 背景中未被任何平铺覆盖的像素保持灰(5)。

**关键洞察**：遮挡规则（距离近者优先、水平方向 tie-break）需要对比多个重叠区域的示例才能归纳，单个示例无法区分"近者优先"和"某颜色固定优先"。
