## 新题 5：面积排序精灵体的颜色循环传递与对角装饰

**组合逻辑**：[排序sort + 面积排序area_ordering] + [重涂色recolor](创新：颜色不由面积直接映射，而是循环位移传递) + [描边decorate + 对角邻接diagonal_adjacency](创新：装饰色来自排序链中的下一个精灵体)

**来源原语**：排序(4df5b0ae), 面积排序(4df5b0ae), 描边/对角邻接(95990924), 角标记(95990924), 重涂色(d2abd087), 面积分类(d2abd087), 精灵体(4df5b0ae/a87f7484)

**依赖链**：面积排序建立精灵体的有序序列 → 有序序列决定颜色循环传递方向（每个精灵体获得排序中前一位的颜色）→ 装饰色取排序中后一位的原始颜色。排序同时驱动两个不同的颜色映射（重涂和装饰），且两个映射方向相反（前一位 vs 后一位），必须同时正确推断才能得到完整输出。

一句话总结：将精灵体按面积排序后，每个精灵体被重涂为序列中前一位的颜色，同时在四个对角位置用序列中后一位的颜色画角标记。

**输入结构**：约 12x12 的黑(0)背景网格。散布 4 个不同颜色的单色4-连通精灵体（颜色分别为红(2)、蓝(1)、绿(3)、黄(4)），像素面积各不相同（分别约 3、5、7、9 像素）。每个精灵体形状不规则但边界框不超过 4x4。精灵体之间至少间隔 2 像素（保证对角装饰不重叠）。生成约束：四个精灵体面积严格不等。

**规则**：
1. 按像素面积从小到大排序四个精灵体，记为 S1(最小)、S2、S3、S4(最大)，记各自原始颜色为 C1、C2、C3、C4。
2. 颜色循环传递重涂：S1 重涂为 C4（最大的颜色），S2 重涂为 C1，S3 重涂为 C2，S4 重涂为 C3。即每个精灵体获得排序序列中前一位的颜色（循环：S1 的前一位是 S4）。
3. 对角装饰：对每个精灵体的边界框，在其四个外角对角位置各画一个单像素标记。装饰色为排序序列中后一位的原始颜色：S1 的装饰色为 C2，S2 的装饰色为 C3，S3 的装饰色为 C4，S4 的装饰色为 C1（循环）。
4. 精灵体保持原位不移动。边界框的四个外角定义为：(top-1, left-1)、(top-1, right+1)、(bottom+1, left-1)、(bottom+1, right+1)。若外角超出网格边界则不绘制。

**关键洞察**：重涂色和装饰色都依赖面积排序，但方向相反（重涂取前一位，装饰取后一位），仅看单个精灵体无法推断循环方向。需要对比多个示例中所有精灵体的颜色变化才能确认循环规则。
