## 新题 8：形状编码方向的射线延伸与障碍停止压缩

**组合逻辑**：[形状编码颜色shape_encodes_color](创新改造：形状不编码颜色而是编码射线方向) + [射线延伸ray_extend] + [靠近障碍停止stop_at_barrier] + [压缩compress](创新：压缩射线长度为数值编码的颜色输出)

**来源原语**：形状编码颜色(009d5c81), 标记字形(009d5c81), 射线延伸(1190bc91), 固定障碍(9c56f360), 靠近障碍停止(9c56f360), 压缩(7837ac64), 同行阻挡(9c56f360)

**依赖链**：字形形状 → 解码为射线方向 → 射线从字形位置发出直到碰到障碍停止 → 测量射线长度 → 长度映射为输出颜色。形状决定方向（解码），障碍位置决定长度（空间约束），长度决定输出色（数值映射）——多层间接编码构成推理链。

一句话总结：每个小字形的形状编码一个射线方向，从字形位置发射射线直到碰到障碍，射线长度映射为输出中对应位置的颜色。

**输入结构**：约 11x11 的黑(0)背景网格。散布 3~5 个 3x3 的灰(5)色字形图案（每个字形是不同形状：十字形、竖条形、横条形、L形等，均由灰(5)像素构成）。网格中还有若干红(2)色固定障碍像素（单像素或短线段），分布在不同位置。字形之间、字形与障碍之间互不重叠。生成约束：每个字形在其编码方向上至少有一个障碍物可以终止射线；射线长度在 1~5 之间。

**规则**：
1. 识别所有 3x3 字形及其形状。形状到方向的解码规则：十字形（5像素）→ 向上，竖条形（3像素垂直排列）→ 向下，横条形（3像素水平排列）→ 向右，L形（3像素成直角）→ 向左。
2. 从每个字形的中心像素出发，沿解码方向发射射线（逐像素延伸），直到碰到红(2)障碍像素或网格边界时停止（不包含障碍像素本身）。记录射线长度 L（不含起点像素）。
3. 将所有字形按其中心位置从上到下、从左到右排序。
4. 输出为 1xN 的单行网格（N = 字形数量），每格颜色由对应字形的射线长度决定：L=1 → 蓝(1)，L=2 → 绿(3)，L=3 → 黄(4)，L=4 → 品红(6)，L=5 → 橙(7)。

**关键洞察**：形状到方向的解码规则（十字→上, 竖条→下等）和长度到颜色的映射都需要对比多个示例归纳。两层编码叠加使得仅看单个示例无法确定完整规则。
