## 新题 9：双轴镜像四象限中按区域面积选择性保留

**组合逻辑**：[镜像mirror + 双轴反射四象限both_axes_four_quadrants] + [面积排名area_ranking + 裁剪crop](创新：镜像后不完整保留四象限，而是按各象限中连通区域的面积排名选择性擦除)

**来源原语**：镜像(3af2c5a8), 双轴反射四象限(3af2c5a8), 面积排名(a87f7484), 裁剪(a87f7484/5bd6f4ac), 连通分量(d2abd087), 擦除(f45f5ca7), 前景最多者选出(a87f7484)

**依赖链**：输入图案先做双轴镜像生成四象限 → 在每个象限中独立计算前景连通分量的面积 → 仅保留每个象限中面积最大的连通分量，擦除其余。镜像改变了各象限中连通分量的形状和面积（因为不规则图案镜像后与邻接区域形成不同的连通性），面积比较的结果因象限不同而不同——两步操作通过连通性产生涌现效应。

一句话总结：将输入图案做双轴镜像填满四象限，再在每个象限中仅保留面积最大的前景连通分量。

**输入结构**：一个 4x5 的网格，黑(0)背景上有若干红(2)前景像素构成一个不规则的4-连通图形（像素数约 6~10）。图形不具有水平或垂直对称性。生成约束：做双轴镜像生成 8x10 输出后，至少有一个象限中因边界处像素对齐而使两个原本独立的区域连通为一个更大的分量。

**规则**：
1. 将 4x5 输入做双轴镜像生成 8x10 输出：左上 = 原图，右上 = 水平翻转，左下 = 垂直翻转，右下 = 180度旋转。
2. 将 8x10 输出划分为四个 4x5 象限（左上、右上、左下、右下）。
3. 在每个象限中独立执行：找出所有红(2)前景像素的4-连通分量，保留像素面积最大的分量（若存在唯一最大），将其余分量像素擦除为黑(0)。
4. 若某象限中最大面积不唯一（存在并列），则该象限保留所有并列最大的分量。
5. 将四个象限重新组合为 8x10 输出。

**关键洞察**：镜像本身是确定性的简单操作，但镜像后各象限在边界处的连通性可能不同于输入中的连通性（因为相邻像素在翻转后可能恰好对齐），这导致各象限"最大分量"的判定结果不同。求解者必须先正确执行镜像，再独立分析每个象限的连通性。

    4. Fill everything else with bg=0.
    5. Validate by running solver — reject if solver raises (conflicting rays) or all rays have length 1.

1. `main(grid)` 必须实现新题描述中的确定性转换规则，不能只识别 `generate_input()` 的固定模板。禁止不同的input网格输出相同的output网格。
2. `generate_input()` 必须随机生成多样样例，不能固定死。随机维度应覆盖：网格大小、对象数量、位置、颜色、方向、形状参数或关键分支。注意若描述中存在若干，需实现而不是只有单个，包括object或者对应关系等等。且若涉及到最短路径，则输入网格中必涉及到多条路径，对选择造成干扰。
