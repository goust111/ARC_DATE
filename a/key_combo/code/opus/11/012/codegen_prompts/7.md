## 新题 7：颜色编码滑动后按着陆列计数驱动区域填充

**组合逻辑**：[滑动slide + 颜色编码列color_coded_col](创新：滑动结果不是最终输出而是中间状态) + [计数counting](创新：计数同列着陆像素数) + [区域填充flood_fill](创新：填充色由着陆计数决定)

**来源原语**：滑动(f45f5ca7/9c56f360), 颜色编码列(f45f5ca7), 颜色决定目标列(f45f5ca7), 计数(a87f7484), 区域填充(1190bc91), 连通分量(d2abd087), 封闭区域(44d8ac46)

**依赖链**：左边缘彩色像素按颜色滑到对应列 → 统计每列的着陆像素总数 → 该计数决定该列中封闭区域的填充颜色。滑动产生空间分布（中间态），计数将空间分布压缩为数值，数值驱动颜色选择——三步信息逐渐抽象化，不可跳步。

一句话总结：左边缘像素按颜色规则滑入指定列，每列累积的着陆数决定该列中预设封闭区域的填充颜色。

**输入结构**：约 10x12 的黑(0)背景网格。最左列有若干彩色像素（红(2)、蓝(1)、绿(3)），分布在不同行，颜色可重复。网格中部（第3~6列）有灰(5)色线条构成的 2~3 个独立封闭区域（每个区域为灰色边框围成的矩形空腔，内部为黑(0)，面积约 2x2 至 3x3）。封闭区域分布在不同列范围内。生成约束：颜色到列的固定映射为红(2)→第3列、蓝(1)→第4列、绿(3)→第5列；每个目标列至少有1个对应颜色的左边缘像素；至少有一个封闭区域跨越的列范围内有多个着陆像素。

**规则**：
1. 将最左列的每个彩色像素滑动到其颜色对应的列（红→列3，蓝→列4，绿→列5），保持原行号不变。滑动后的像素在输出中不绘制（仅作逻辑中间步骤）。
2. 统计每个目标列（3、4、5）上的着陆像素总数，记为 count(col)。
3. 对每个灰(5)封闭区域，确定其内部空腔占据的列集合。取这些列的着陆计数之和 S。
4. 按 S 决定填充色：S=1 → 填黄(4)，S=2 → 填橙(7)，S=3 → 填品红(6)，S>=4 → 填青(8)。
5. 将每个封闭区域的内部黑(0)像素替换为对应的填充色。灰(5)边框和其余黑(0)背景不变。最左列的彩色像素在输出中被擦除（变为黑(0)）。

**关键洞察**：从颜色到列的映射（红→3，蓝→4，绿→5）需要对比多个示例才能归纳。填充色不由区域自身属性决定，而由其所在列的"流量"（着陆计数）决定——这是滑动操作与填充操作之间的间接耦合。
