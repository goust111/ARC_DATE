## 新题 2：射线分区内的散布标记蛇形压缩

**组合逻辑**：[射线延伸ray_extend](创新：射线从固定源点发出建立分区边界) + [蛇形填充boustrophedon_fill](创新：蛇形读取顺序限定在射线分区内) + [压缩compress]

**来源原语**：射线延伸(1190bc91), 射线遮挡分区(1190bc91), 散布标记(cdecee7f), 蛇形填充(cdecee7f), 列序排列(cdecee7f), 压缩(7837ac64)

**依赖链**：射线从源像素出发向四方向延伸建立空间分区 → 每个分区内的散布标记按蛇形顺序收集 → 分区按源像素在输入中从左到右的顺序排列，各分区的蛇形序列拼接输出。射线分区决定了哪些标记属于同组（分组），蛇形顺序决定了组内排列（排序），两步信息不可互换。

一句话总结：从顶行彩色源点向下发射射线将网格分为竖条区域，收集每个区域内散布标记的颜色并按蛇形顺序压缩为紧凑输出。

**输入结构**：约 12x12 的黑(0)背景网格。顶行（第0行）有 2~4 个不同颜色的像素作为射线源（颜色各不相同，从红(2)、蓝(1)、绿(3)、黄(4)中选取，位于不同列）。网格内散布 6~9 个单像素前景标记（颜色各异或部分重复，颜色来自品红(6)、橙(7)、青(8)、栗(9)），每个标记占一个独立位置，互不相邻。生成约束：每个射线分区内至少有2个散布标记；散布标记不在第0行；射线源像素之间至少间隔2列。

**规则**：
1. 每个顶行源像素向下发射一条垂直射线（即该列从第1行到底部全部标记为该射线的边界）。射线本身不绘制在输出中，仅用于逻辑分区。
2. 射线将网格分为若干竖条区域（最左射线左侧为第一区、相邻射线之间为中间区、最右射线右侧为最后区）。按区域从左到右编号。
3. 对每个区域内的散布标记，建立 3 列的虚拟子网格（列数 = 区域宽度对 3 取整，行数由标记的行范围决定），按蛇形顺序读取标记：偶数行从左到右，奇数行从右到左。蛇形行以标记实际所在行的相对行号（在该区域内从上到下编号，从 0 起）为准。
4. 将所有区域的蛇形序列按区域编号顺序拼接，输出为一行 Nx1 的紧凑网格（N = 散布标记总数），每格为对应标记的颜色。

**关键洞察**：射线位置决定分区宽度，分区宽度改变了蛇形读取中"换行"的位置，从而改变同一组标记的输出顺序。移动一个射线源的列位置会导致多个标记的输出顺序发生非局部变化。
