## 新题 4：旋转对齐印章与旋转角度编码重涂

**组合逻辑**：[图案识别](识别模板中标记像素的空间模式) → [旋转](确定每个目标标记组需要何种旋转才能与模板对齐) → [印章覆盖](将旋转后的完整模板印到目标位置) + [重涂色](根据所需旋转角度将印章的非标记像素重涂为特定颜色)（旋转推断同时决定印章朝向和重涂颜色，两个输出通过同一推理步骤耦合）

**来源原语**：印章覆盖(stamp_overlay)←e6721834, 旋转(rotate)←a25697e4, 重涂色(recolor)←67385a82, 图案识别(pattern_recognition)←642d658d, 标记锚定精灵(marker_anchors_sprite)←e6721834, 标记模式匹配(marker_pattern_match)←e6721834, 模板精灵体(template_sprite)←bb52a14b

**依赖链**：模板的标记像素布局定义了匹配模式；目标区域的标记像素与模板的某个旋转版本匹配，确定旋转角度；该角度既用于正确旋转完整模板以进行印章覆盖，又决定了非标记像素的输出颜色。旋转推断是两条输出路径的共享瓶颈。

在双面板网格中，根据目标面板上标记像素与模板标记模式的旋转匹配关系，将完整模板旋转后印到目标位置，同时按旋转角度将非标记像素重涂为对应颜色。

**输入结构**：黑(0)背景网格，约 12x20，被一条灰(5)竖线分为左右两个等宽面板。左面板（源面板）包含一个完整的 4x4 模板精灵体：模板由黄(4)标记像素和红(2)非标记像素组成，模板内黄(4)像素构成一个非对称的 4-连通图案（保证 0°、90°、180°、270° 四种旋转下标记模式互不相同）。右面板（目标面板）包含 2~4 组黄(4)标记像素，每组标记像素的相对位置恰好对应模板标记模式的某个旋转版本。各组标记之间至少间隔 2 行 2 列。生成约束：右面板中每组标记周围有足够的黑色空间容纳 4x4 模板印章且印章之间互不重叠；四种旋转角度中至少出现两种不同的角度。

**规则**：
1. 在左面板中定位模板精灵体：提取其边界框内的 4x4 图案，记录黄(4)像素的相对坐标集合 M0（0° 版本）。
2. 计算 M0 的 90°、180°、270° 顺时针旋转版本 M90、M180、M270。
3. 对右面板中每组黄(4)标记像素，计算其相对坐标集合 T。将 T 与 M0、M90、M180、M270 逐一比较（允许平移对齐），找到唯一匹配的旋转角度 theta。
4. 将完整模板旋转 theta 度，然后以标记像素对齐的方式印章覆盖到右面板上。印章时黑(0)像素透明（不覆盖目标面板的已有内容）。
5. 印章中的非标记像素（模板中原为红(2)的像素）根据 theta 重涂：
   - theta = 0°：保持红(2)
   - theta = 90°：重涂为蓝(1)
   - theta = 180°：重涂为绿(3)
   - theta = 270°：重涂为橙(7)
6. 黄(4)标记像素保持不变。左面板和灰(5)分隔线在输出中保留。

**关键洞察**：旋转角度到颜色的映射（0°→红、90°→蓝、180°→绿、270°→橙）是隐蔽规则，仅凭单个示例中若所有目标恰好使用同一旋转角度则完全不可见，必须对比包含不同旋转角度的多个示例才能归纳。
