## 新题 6：描边扩容后面积匹配嵌套入腔

**组合逻辑**：[描边](对小型连通分量绘制外扩边框，改变其有效面积) → [面积匹配](描边后的有效面积与框架空腔面积配对) → [嵌套/dock](将描边后的整体平移嵌入匹配的空腔)（描边不是最终视觉效果，而是改变面积匹配的中间计算步骤——这是源题中不存在的结构关系）

**来源原语**：描边(outline)←b27ca6d3, 嵌套(dock)←a25697e4, 面积匹配(area_matching)←a25697e4, 空腔(cavity)←a25697e4, 边框框架(border_frame)←a25697e4, 连通分量(connected_component)←67385a82, 尺寸分类(size_classification)←b27ca6d3, 微型对象描边(micro_obj_outlined)←b27ca6d3

**依赖链**：描边操作将 2 像素的红色对象扩展为带绿色边框的更大图形，其总占用面积（红+绿像素数）成为匹配空腔的关键；不同朝向的 2 像素对象（水平 vs 垂直）描边后形状不同、面积相同但边界框不同，需要匹配边界框形状而非仅面积；单像素对象不描边，因此也不参与嵌套。

对每个两像素红色对象绘制绿色描边边框，然后将描边后的完整图形（红色核心+绿色边框）嵌入边界框形状匹配的框架空腔中。

**输入结构**：黑(0)背景网格，约 16x16。网格边缘附近有 2~4 个蓝(1)一像素厚矩形框架，每个框架的内部是一个黑(0)矩形空腔（空腔尺寸各不相同，但都是 3x4 或 4x3 或 4x4 等小矩形）。网格中央区域散布着若干红(2)前景对象：部分是单像素（孤立点），部分是两像素的水平或垂直相邻对（即"多米诺骨牌"形态）。生成约束：每个多米诺描边后的边界框（4x3 或 3x4）恰好与某一个空腔的尺寸一致，形成一一对应；空腔尺寸互不相同以保证匹配唯一；单像素红色对象的数量可以为 0 或多个，它们是干扰项。

**规则**：
1. 识别所有红(2) 4-连通分量并按面积分类：
   - 面积 = 1（孤立像素）：保留在原位，不做任何操作。
   - 面积 = 2（多米诺）：进入描边和嵌套流程。
2. 对每个红色多米诺，计算其边界框，将边界框向四个方向各扩展 1 格。在扩展后的矩形边框位置，将黑(0)像素涂为绿(3)，形成一像素宽的绿色描边。此时该多米诺的"完整图形"包含原始 2 个红色像素和新增的绿色边框像素。
3. 计算每个完整图形的边界框尺寸（行数 x 列数）。
4. 对每个蓝(1)框架，计算其内部空腔的尺寸（行数 x 列数）。
5. 将完整图形与空腔按边界框尺寸进行匹配：尺寸完全相等（行数对行数、列数对列数）即为匹配。
6. 将每个匹配的完整图形从原位置擦除（红色和绿色像素均填回黑(0)），然后平移至匹配空腔的位置，使完整图形的边界框与空腔边界框完全重合。绿色像素填入空腔内的对应位置，红色像素同样填入。
7. 蓝(1)框架在输出中保留。

**关键洞察**：描边不仅仅是装饰——它改变了对象的有效边界框尺寸，而这个新尺寸才是空腔匹配的依据。求解者必须意识到"先描边、再匹配"的顺序，而非直接用红色多米诺的原始尺寸去匹配空腔（原始 2 像素的 1x2 或 2x1 显然无法匹配任何 3x4 空腔）。
