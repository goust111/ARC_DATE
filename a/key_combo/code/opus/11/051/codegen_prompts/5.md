## 新题 5：周期推断定位异常区域与洪泛分流修复

**组合逻辑**：[周期推断](从完好区域推断重复瓦片) → [分类](识别异常像素——颜色与瓦片相位不一致的像素) → [洪泛填充](从种子像素沿异常像素 4-连通扩散，划分异常区域) → [重涂色](种子可达的异常区域涂种子色，不可达的异常区域修复为正确瓦片色)（四步串联但信息在每步发生实质变换：周期→异常检测→连通分区→差异化修复）

**来源原语**：周期推断(period_inference)←c663677b, 洪泛填充(flood_fill)←9edfc990, 重涂色(recolor)←67385a82, 种子像素(seed_pixel)←9edfc990, 缺损像素(corrupted_pixel)←c663677b, 周期相位对应(periodic_phase_match)←c663677b, 非缺损像素一致性(non_corrupted_consistency)←c663677b, 种子沿连通域扩散(spread_from_seed_through_connected)←9edfc990

**依赖链**：周期推断提供"正确颜色"基准；与基准不一致的像素被标记为异常；种子像素的洪泛沿异常像素连通域扩散，将异常像素分为"种子可达"和"种子不可达"两组；两组的修复策略不同。若周期推断错误，异常检测全部失效；若洪泛划分错误，修复策略混淆。

推断网格的周期性瓦片，找出颜色与瓦片相位不一致的异常像素，然后以种子像素为起点洪泛扩散标记可达异常区域：可达区域统一涂为种子颜色，不可达区域修复为正确瓦片颜色。

**输入结构**：网格约 14x14，由一个 3x3 或 4x4 的彩色瓦片周期性平铺而成，瓦片使用 {红(2), 蓝(1), 绿(3), 黄(4)} 中的 2~3 种颜色加上黑(0)。网格中有若干"异常像素"——其颜色被篡改为与正确瓦片相位不同的颜色（篡改后的颜色仍在瓦片使用的颜色集合内，因此无法仅靠"出现了瓦片中不存在的颜色"来检测）。异常像素形成 1~3 个 4-连通的簇。网格中恰好有一个品红(6)种子像素，位于某个异常簇内部或与之 4-邻接。生成约束：品红(6)不出现在正确瓦片中；种子像素恰好与一个异常簇 4-连通可达（可经由异常像素逐步到达）；至少有一个异常簇与种子像素不连通。

**规则**：
1. 推断最小行周期 pr 和列周期 pc，使得所有非品红(6)像素中，颜色一致的像素在模 (pr, pc) 的相位下彼此吻合。忽略品红(6)像素和异常像素（少数派）时，多数像素在同一相位下颜色相同。以多数投票确定每个相位的正确颜色，记为 tile[r % pr][c % pc]。
2. 标记异常像素：若网格中 (r, c) 处的颜色既不是品红(6)也不等于 tile[r % pr][c % pc]，则 (r, c) 为异常像素。
3. 从品红(6)种子像素出发，沿 4-邻接异常像素进行洪泛填充，标记所有可达的异常像素为"种子连通"。
4. 对所有"种子连通"的异常像素，将其颜色重涂为品红(6)。
5. 对所有不与种子连通的异常像素，将其颜色修复为 tile[r % pr][c % pc]（正确瓦片颜色）。
6. 品红(6)种子像素本身在输出中保留。

**关键洞察**：异常像素的颜色并非全部被替换为同一种颜色——种子可达与否决定了两种截然不同的修复策略。这一分流规则在单个示例中如果所有异常簇恰好都与种子连通（或都不连通），将完全不可见，需要对比包含两种情况的示例才能归纳。
