## 新题 3：旋转等价分组后按组内计数确定印章位置

**组合逻辑**：[形状匹配 + 旋转翻转等价](将精灵体分组) → [计数](组内成员数) → [印章覆盖 + 非重叠约束](组代表印章到计数决定的位置，大组优先)

**来源原语**：形状匹配/旋转翻转等价(6165ea8f)、计数(de1cd16c/e48d4e1a)、印章覆盖/最大重叠确定位置(d6542281)、非重叠约束/从大到小优先(31adaf00)

**依赖链**：等价分组决定哪些精灵体归为一类；组内成员数决定该组代表被印章到输出区的哪一列；大组优先的贪心顺序解决位置冲突。三者缺一则输出无法确定。

一句话总结：将散落的小精灵体按旋转/翻转等价分组，每组的成员数量决定其代表图案在输出区的水平放置列，组大者优先占位。

**输入结构**：约 18x18 黑(0)背景网格，分为上下两区。上区（行 0~11）散布 6~8 个 4-连通单色小图形（3~5 像素），每个图形颜色各异（使用蓝(1)、红(2)、绿(3)、黄(4)、灰(5)、品红(6)等），形状不规则但紧凑。下区（行 13~17）为 5 行高的空白输出区，行 12 为灰(5)水平分隔线。生成约束：上区图形按旋转/翻转等价关系恰好分为 2~3 组，每组 2~3 个成员；各图形的包围框不超过 3x3，互不重叠且间隔至少 1 像素。

**规则**：
1. 提取上区所有 4-连通前景图形，将每个图形归一化为其紧凑掩码（最小包围框内的二值模式）。
2. 比较所有图形对：若两个图形的归一化掩码在旋转 0/90/180/270 度或水平/垂直翻转后能完全重合，则它们属于同一等价组。
3. 对每个等价组，统计成员数量 K。
4. 每组选取一个代表（成员中包围框左上角行最小的那个；若行相同取列最小的），保留其原始颜色和形状。
5. 在下区放置代表图案：代表的包围框左上角行固定为 14（下区第二行），列位置 = (K-1) * 5（即成员数为 2 的组放在列 5，成员数为 3 的组放在列 10，成员数为 1 的放在列 0）。
6. 放置顺序：成员数多的组优先。若两组成员数相同，代表包围框面积大的优先。若后放置的代表与已放置的发生像素重叠，后者向右平移 1 列直到无冲突。
7. 上区所有原始图形在输出中擦除为背景色，灰分隔线保留。

**关键洞察**：等价判断必须穷举八种 dihedral 变换；成员数到列位置的映射规则（K*5 偏移）需要对比多示例才能确认，因为单示例中无法区分"按成员数"还是"按其他属性"排列。
