## 新题 5：频率计数双重编码：排序行序 + 周期瓦片间距

**组合逻辑**：[计数(counting)+排序(sorting)](确定输出行顺序) + [平铺(tiling)](以计数值为周期参数生成行内图案) + [频率统计(frequency_statistic)](同一测量值服务于两个不同用途)

**来源原语**：计数+排序 ← 81c0276b; 平铺 ← e95e3d8e/135a2760; 频率统计 ← 81c0276b; 按计数升序 ← 81c0276b; 周期瓦片 ← e95e3d8e

**依赖链**：颜色频率同时决定两件事——行排列顺序（升序）和行内瓦片周期（频率值即间距）。计数是共享的信息源，它的输出分叉到两个独立用途，任何一个用途缺失都会导致输出不唯一。

统计前景色频率，按频率升序各生成一行，行内以"1个色像素 + (频率-1)个背景像素"为瓦片周期左对齐平铺。

**输入结构**：约 10x10 的黑(0)背景网格。散布着 3~5 种非背景颜色的前景像素（如红(2)、绿(3)、蓝(1)、黄(4)），每种颜色出现 2~6 次不等，位置随机。网格中无任何结构（无线条、无分隔、无分组），纯粹是散点。生成约束：各颜色频率互不相同；最大频率不超过输出宽度的一半（保证瓦片至少能重复两次）。

**规则**：
1. 统计每种非黑(0)颜色在输入网格中出现的像素数，记为 freq(c)。
2. 将颜色按 freq 升序排列。freq 最小的颜色排第 0 行，依此类推。
3. 输出宽度等于输入宽度 W，输出高度等于颜色种数。
4. 对排在第 r 行的颜色 c（其频率为 f = freq(c)）：构造长度为 f 的瓦片单元 = [c, 黑(0), 黑(0), ..., 黑(0)]（1 个 c 像素后跟 f-1 个黑像素）。将该瓦片从第 0 列开始向右重复平铺直到填满 W 列（末尾不足一个完整瓦片则截断）。
5. 输出仅包含上述行矩阵。

**关键洞察**：同一个数值（频率）在两个维度上发挥作用——纵向决定行排列的优先级，横向决定行内图案的疏密节奏。仅看单个示例无法区分"频率决定排序"和"频率决定间距"哪个是巧合哪个是规则，必须对比多个示例。
