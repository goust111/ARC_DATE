## 新题 10：图例位置映射 + 射线遮挡选择性印章

**组合逻辑**：[位置对应(positional_mapping)](图例精灵与标记色的对应关系) + [射线延伸(ray_cast)](从标记向上发射射线判断可达性) + [印章覆盖(stamp)](将图例精灵印在通过射线测试的标记位置) + [列遮挡(column_coverage)](遮挡物阻断射线则标记不被印章)

**来源原语**：位置对应+图例精灵 ← 20fb2937; 射线延伸+列遮挡 ← 6d58a25d; 印章覆盖 ← 363442ee; 分隔行 ← 20fb2937; 标记像素 ← 20fb2937/363442ee

**依赖链**：图例建立颜色→精灵体的映射（查表）；射线测试筛选哪些标记有资格被印章（空间过滤）；印章操作将精灵体放置到通过筛选的位置（绘制）。三步链式依赖：没有图例无法知道印什么，没有射线无法知道在哪印，没有印章则无最终输出。

下方标记像素向上发射射线，只有射线能无阻碍到达分隔行的标记才获得图例精灵体的印章替换；被中间障碍物遮挡的标记保持不变。

**输入结构**：约 14x12 的网格，黑(0)背景。结构从上到下分三段：(1) 图例区（约 3 行）：包含 2~3 个等尺寸的小正方形精灵体（3x3，各不同色，如红(2)、绿(3)、蓝(1)），每个精灵体正下方一行有一个对应标记色像素（如精灵体下方为黄(4)表示"黄标记→该精灵"）。(2) 一行灰(5)满宽分隔行。(3) 下方工作区（约 8 行）：散布着与图例标记色相同的彩色像素（如黄(4)、橙(7)等），作为待印章的目标标记。工作区中还有若干栗(9)色障碍物像素散布其中。生成约束：部分标记像素正上方至分隔行的路径无障碍（射线畅通），部分被栗(9)像素阻断；每种标记色至少有一个畅通和一个被阻断的实例。

**规则**：
1. 识别灰(5)分隔行，将其上方划为图例区，下方划为工作区。
2. 在图例区中，按从左到右顺序，将每个精灵体与其正下方的标记色像素配对，建立映射表：标记色 → 精灵体图案。
3. 对工作区中每个标记色像素 M：从 M 位置向上逐行扫描，检查其所在列中 M 与分隔行之间是否存在任何非黑(0)像素（栗(9)障碍物）。若存在障碍物，该标记"被遮挡"，在输出中保持为原标记色像素不变。
4. 若无障碍物（射线畅通），查映射表找到对应精灵体，以 M 的位置为精灵体中心对齐点，将精灵体印章到输出中。印章覆盖 M 本身及周围像素。
5. 输出仅包含工作区（分隔行及以上被裁剪掉）。栗(9)障碍物在输出中被擦除为黑(0)。印章按标记从上到下、同行从左到右顺序绘制，后绘制的覆盖先绘制的。

**关键洞察**：图例提供"印什么"的信息，但并非所有标记都有资格接收印章——射线遮挡测试作为空间过滤器，使得同一颜色的标记在不同位置有截然不同的命运。求解者需同时理解查表映射和几何遮挡两套独立逻辑。
