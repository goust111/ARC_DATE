## 新题 6：框架擦除后内部区域按角度循环换色

**组合逻辑**：[擦除(erase)](去除框架边界) + [循环轮换(cyclic_shift)](颜色沿角度序列移位) + [环绕角度排序(angular_order_around_center)](确定轮换顺序) + [洪泛填充(flood_fill)](识别并填色内部区域)

**来源原语**：擦除 ← d5d6de2d; 循环轮换 ← 880c1354; 环绕角度排序 ← 880c1354; 空心矩形 ← d5d6de2d/445eab21; 封闭区域 ← d5d6de2d/543a7ed5; 洪泛填充 ← 543a7ed5

**依赖链**：框架颜色提供调色板→擦除框架后内部区域需重新着色→角度排序确定区域间的循环顺序→循环移位将每个区域的颜色替换为角度序列中前一个区域的原始框架色。框架同时是"要移除的结构"和"颜色信息的来源"，这种双重角色制造了紧耦合。

多个彩色空心矩形的边框被擦除，其原本的封闭内部按照质心角度排序后循环继承相邻框架的颜色。

**输入结构**：约 14x14 的黑(0)背景网格。包含 3~5 个不同颜色的单像素厚空心矩形框（如红(2)、蓝(1)、绿(3)、黄(4)），各框互不重叠也不嵌套，各框内部均为黑(0)。框的尺寸在 3x3 到 6x6 之间不等。各框的质心分布在网格的不同方位（不共线）。生成约束：各框颜色互不相同；框的质心相对于网格中心点的角度（以正上方为 0 度顺时针度量）互不相同。

**规则**：
1. 识别所有单像素厚空心矩形框，记录每个框的颜色 c_i 和其边界框严格内部区域的像素坐标集 R_i。
2. 计算每个框 i 的内部区域质心（内部像素坐标的算术平均）。
3. 计算网格中心点 G =（(行数-1)/2, (列数-1)/2）。
4. 对每个区域质心，计算其相对于 G 的角度：以 G 正上方为 0 度，顺时针增长。按角度升序排列区域，得到序列 R_0, R_1, ..., R_{n-1}，其原始框架颜色序列为 c_0, c_1, ..., c_{n-1}。
5. 擦除所有矩形框像素为黑(0)。
6. 对每个区域 R_i，将其所有像素填充为 c_{(i-1+n) mod n}，即角度序列中前一个区域的框架颜色。
7. 输出保持原网格尺寸，仅有填充后的内部区域为非黑色。

**关键洞察**：框架的颜色在被擦除前必须先被记录，因为擦除后这些颜色信息就丢失了；而这些颜色恰恰是后续填充的来源——且不是填回自己的区域，而是循环移位后填入邻居的区域。角度排序作为隐含的"邻居"定义需要对比多个示例才能归纳。
