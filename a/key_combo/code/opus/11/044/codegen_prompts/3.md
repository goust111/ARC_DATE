## 新题 3：滑动镜像围合后按面积选择性填充

**组合逻辑**：[滑动(slide)+镜像(mirror)](产生几何围合的涌现效应) + [洪泛填充(flood_fill)](识别封闭区域) + [面积比较(area_comparison)](决定哪些区域被填色)

**来源原语**：滑动+镜像 ← 11dc524f; 洪泛填充 ← 543a7ed5; 封闭区域 ← 543a7ed5/445eab21; 面积比较 ← 445eab21; 方块锚点 ← 11dc524f

**依赖链**：滑动+镜像改变几何形态→新几何可能产生封闭区域（涌现）→洪泛填充检测封闭性→面积比较筛选填充目标。不执行滑动镜像则无封闭区域产生；不做洪泛填充则无法知道哪些区域封闭；不做面积比较则无法决定填哪个。

多组精灵体滑向各自锚点并镜像，镜像对拼可能围合出封闭区域；仅面积最大的封闭区域被填色输出。

**输入结构**：约 15x15 的黑(0)背景网格。包含 2~3 组"精灵体+方块锚点"配对。每个精灵体为单色 4-连通图形（4~7 像素，形状不规则且非对称），颜色各不相同（如蓝(1)、红(2)、绿(3)）。每组对应一个同色的 2x2 实心方块锚点。精灵体与其同色锚点在同一行或同一列上，且之间仅有黑(0)背景（无阻挡）。生成约束：至少一组精灵体在滑动并镜像后，原件与镜像件共同形成一个 4-连通封闭边界（内部至少有 1 个黑像素被完全包围）；各组的滑动路径互不交叉。

**规则**：
1. 对每组精灵体-锚点配对：沿它们的基数方向连线将精灵体直线滑动，直至精灵体的前缘触碰方块锚点的近边。
2. 以锚点近边为镜像轴，生成精灵体的镜像副本，绘制在轴的另一侧，使用锚点颜色。移除原锚点像素。
3. 对所有组完成上述操作后，在结果网格上执行背景连通性分析：从网格四边出发洪泛标记所有 4-连通可达的黑(0)像素为"外部"。
4. 未被标记的黑(0)像素即为封闭区域。计算每个封闭连通分量的像素面积。
5. 选择面积最大的封闭区域，将其所有像素填充为黄(4)。若存在面积相同的多个最大区域，选择左上角像素行号更小的那个；行号也相同则选列号更小的。
6. 其余封闭区域保持黑(0)不变。

**关键洞察**：滑动镜像本身不以"围合"为目的，但特定的非对称形状在对拼后会涌现出封闭边界——求解者需先预判镜像结果的几何形态，再从多个候选围合中比较面积。
