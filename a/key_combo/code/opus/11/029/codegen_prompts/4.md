## 新题 4：图例驱动的精灵体半区重涂与膨胀

**组合逻辑**：[图例映射/legend_mapping](读取颜色映射) → [半区/half_region](创新：按图例指示确定哪个半区变色) → [重涂色/recolor] → [膨胀/dilate](创新：仅对变色后的半区膨胀)

**来源原语**：图例映射(5adee1b2), 颜色图例(5adee1b2), 膨胀(5adee1b2), 半区(e7dd8335), 重涂色(e7dd8335, 5adee1b2), 包围盒(e7dd8335), 连通分量(5adee1b2)

**依赖链**：图例提供两层信息——目标颜色的映射和半区选择的编码；半区分割依赖包围盒的计算；膨胀仅作用于重涂后的半区，因此膨胀的范围依赖重涂结果。删除图例则不知涂什么色、选哪半区；删除半区分割则整体膨胀得到不同结果。

根据左侧图例的编码，对每个精灵体的指定半区重涂色，再仅对重涂半区向外膨胀一层。

**输入结构**：约 15x15 的黑(0)背景网格。左侧边缘有 1~2 个图例标记，每个图例是一个 2x3 的小块：左列 2 像素为某前景色 C，右上 1 像素为映射目标色 T，右下 1 像素为灰(5)或白——灰(5)表示"上半区"，栗(9)表示"下半区"。网格右侧散布 2~3 个 4-连通单色精灵体（每个 6~12 像素，形状不规则但连通），颜色与图例左列颜色之一对应。每个精灵体的包围盒高度为偶数（保证可精确二等分）。精灵体之间间距至少 3 格，与图例间距至少 4 列。生成约束：膨胀后的像素不会触碰其他精灵体或图例。

**规则**：
1. 识别左侧边缘的图例标记：每个 2x3 块的左列颜色 C 为源色，右上颜色 T 为目标色，右下颜色指示半区（灰(5)=上半区，栗(9)=下半区）。
2. 对每个颜色为 C 的精灵体，计算其包围盒，将包围盒沿水平中线分为上半区和下半区。
3. 根据图例的半区指示，将该精灵体在指定半区内的所有像素重涂为目标色 T。另一半区保持原色 C。
4. 对每个精灵体中被重涂为 T 的像素集合，向外膨胀 1 层：将与该像素集合 4-邻接的所有背景像素涂为 T。膨胀不侵入该精灵体未重涂的半区像素。
5. 保留图例标记和未重涂半区的像素不变。

**关键洞察**：图例的右下像素不是装饰——它编码了半区选择信息，这需要对比包含不同半区指示的多个示例才能归纳出来。膨胀仅限于重涂半区而非整体，这进一步耦合了半区分割与膨胀范围。
