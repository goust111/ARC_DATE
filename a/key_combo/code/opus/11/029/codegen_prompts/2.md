## 新题 2：瓦片周期缺陷定位与对称轴修复

**组合逻辑**：[平铺/tile](识别周期结构) → [差异提取/difference_extraction](创新：对比各周期副本找出缺陷瓦片) → [对称补全/symmetry_completion](创新：利用瓦片自身的对称性修复缺陷像素)

**来源原语**：平铺(9b30e358), 差异提取(2037f2c7), 对称补全(3631a71a), 对称轨道(3631a71a), 周期重复(9b30e358), 对齐比较(2037f2c7)

**依赖链**：周期结构的识别决定了对齐比较的单元划分；差异提取定位了哪些像素被损坏；损坏像素的修复依赖瓦片内部的对称结构（而非其他副本的直接拷贝）。三步互相依赖——不知道周期就无法对齐比较，不做差异提取就不知道哪些像素需要修复，不利用对称性就无法确定修复值（因为所有副本中该位置都可能被损坏）。

在一个近似周期铺排的网格中，定位被篡改的瓦片位置，再利用该瓦片自身的对称性恢复正确颜色。

**输入结构**：约 12x12 的黑(0)背景网格。网格可以被精确划分为 3x3 或 4x3 的等大瓦片（每个瓦片约 3x4 或 4x4 像素）。每个瓦片本应是同一个多色图案的精确副本，该图案具有某种对称性（水平镜像对称或垂直镜像对称，但不同时具备两种）。其中恰好一个瓦片有 1~2 个像素被替换为品红(6)（品红在正常瓦片中不出现）。生成约束：正常瓦片图案至少使用 2 种非黑颜色；被损坏的像素位置不在对称轴上（确保可通过对称性唯一确定正确值）。

**规则**：
1. 识别网格的周期瓦片大小：找到最小的矩形尺寸使得网格可被无缝划分为该尺寸的瓦片矩阵。
2. 对比所有瓦片，找到包含品红(6)像素的那个瓦片——品红标记了被损坏的位置。
3. 确定正常瓦片（不含品红的任一瓦片）的对称类型：检测它是水平镜像对称（左右对称）还是垂直镜像对称（上下对称）。
4. 在损坏瓦片中，对每个品红像素，利用步骤 3 确定的对称轴，找到该像素在瓦片内的对称伙伴位置的颜色，将品红替换为该颜色。
5. 输出修复后的完整网格（所有瓦片保持原位，仅品红像素被替换）。

**关键洞察**：不能简单地用其他正常瓦片的对应位置来修复（那样就是直接拷贝，无需对称性）——需要对比多个示例才能发现修复策略是用瓦片自身的对称伙伴而非其他副本的同位像素。

## 实现要求

1. `main(grid)` 必须实现新题描述中的确定性转换规则，不能只识别 `generate_input()` 的固定模板。禁止不同的input网格输出相同的output网格。
2. `generate_input()` 必须随机生成多样样例，不能固定死。随机维度应覆盖：网格大小、对象数量、位置、颜色、方向、形状参数或关键分支。注意若描述中存在若干，需实现而不是只有单个，包括object或者对应关系等等。且若涉及到最短路径，则输入网格中必涉及到多条路径，对选择造成干扰。

4. 禁止把 ARC 颜色 id 、亮度、拼写等当作人类不可见的数值语义参与排序、大小比较或隐藏映射。颜色变化必须有可见结构线索。注意颜色亮度、拼写等也是不可见信息，若描述中出现违规的颜色id或者亮度，可自行使用少量的固定颜色替代，但注意生成时要在三个以内输入输出网格中对所有变换100%覆盖度。

6. 若规则有多个分支，生成器不能长期固定成一个分支；应让分支在随机样例中合理出现。分支概率不必平均——难以发现的隐蔽分支（如少数情况下才触发的特殊规则）应适当提高出现概率，确保在 3 个训练示例中至少出现一次，否则求解者无法归纳该规则。对于颜色映射类规则，确保 2 个左右的示例即可覆盖所有映射关系（每种颜色→颜色的映射至少在某个示例中出现过）。
