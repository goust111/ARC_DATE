## 新题 3：内部面积奇偶性决定矩形内填充方式

**组合逻辑**：[计数/counting] → 奇偶判定 → {奇：[填充/fill 收缩楔形]，偶：[填充/fill 棋盘格]}（创新：同一类对象根据派生数值属性走不同的填充分支，两种填充算法完全不同）

**来源原语**：计数/counting（2a28add5）、填充/fill（b5bb5719/ba9d41b8）、边框与内部分离/border_interior_split（ba9d41b8）、实心矩形/solid_rectangle（ba9d41b8）、矩形内部/rectangle_interior（ba9d41b8）、棋盘格图案/checkerboard（ba9d41b8）、收缩楔形/shrinking_wedge（b5bb5719）、行列奇偶决定填充/parity_fill（ba9d41b8）

**依赖链**：边框与内部分离 → 内部面积计数 → 奇偶判定产生分支 → 奇分支执行收缩楔形填充 / 偶分支执行棋盘格镂空。删除面积计数则无法确定分支；删除任一分支操作则对应矩形无法求解。

将每个实心矩形的内部按面积奇偶性分别施加收缩楔形或棋盘格镂空。

**输入结构**：约 16x16 的网格，灰(5)背景。网格中有 3-5 个单色实心矩形，每个至少 3x3，每个矩形使用不同颜色（从蓝(1)、红(2)、绿(3)、黄(4)、品红(6)中选取），矩形之间互不重叠且不相邻（间隔至少 1 像素）。矩形的宽高组合确保既有内部面积为奇数的（如 3x4 内部面积 1x2=2 为偶，3x5 内部面积 1x3=3 为奇，5x4 内部面积 3x2=6 为偶，5x5 内部面积 3x3=9 为奇），也有偶数的。生成约束：至少一个矩形内部面积为奇、至少一个为偶。

**规则**：
1. 对每个矩形，分离出 1 像素厚的边框和内部区域。边框在所有操作中保持原色不变。
2. 计算内部区域的像素数（即 (宽-2)x(高-2)），判断奇偶性。
3. 内部面积为奇数的矩形：从内部区域的顶行开始，逐行填充收缩楔形——第 0 行（内部最顶行）填满矩形原色，第 r 行填充列范围 [r, 内部宽度-1-r]，即每行左右各收缩 1 列；超出范围（左右两端被收缩掉的位置）填为背景色灰(5)。当 r 使得剩余宽度 <= 0 时，之后各行全部填背景色。
4. 内部面积为偶数的矩形：对内部区域施加棋盘格镂空——以内部左上角为锚点，将 (local_row + local_col) 为偶数的像素替换为背景色灰(5)，其余像素保持矩形原色。
5. 背景像素和非矩形区域不变。

**关键洞察**：矩形的视觉外观（颜色、位置、大小）不直接决定变换方式——必须剥离边框后计算内部面积，再通过奇偶判定选择完全不同的填充算法。3x5 红矩形和 5x5 红矩形虽然同色，但因内部面积奇偶不同而产生截然不同的内部图案。
