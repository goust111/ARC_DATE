## 新题 1：对称筛选决定封闭区域处理方式

**组合逻辑**：[洪泛填充/flood_fill] + [擦除/erase]，由 [对称性筛选/symmetry_filter] 作为决策门控（创新：对称性检测不用于选取单一输出对象，而是作为每个封闭区域的二元判定条件，分流到不同操作）

**来源原语**：洪泛填充/flood_fill（e69241bd）、对称性筛选/symmetry_filter（72ca375d）、擦除/erase（2f767503）、墙壁/wall（e69241bd）、封闭区域/enclosed_region（e69241bd）、精灵体/sprite（72ca375d）

**依赖链**：墙壁分割出封闭区域 → 每区域裁剪出内部小图形 → 对称性检测产生布尔结果 → 布尔结果决定该区域执行洪泛填充还是擦除。删除对称性检测则无法区分两种操作的适用对象；删除洪泛填充或擦除则对称性检测的结果没有下游效果。

将散落在墙壁迷宫各腔室内的小图形按对称性分类：对称者以其颜色灌满所在腔室，非对称者被清除。

**输入结构**：约 15x15 的网格，黑(0)背景。灰(5)像素构成 1 像素厚的直线段墙壁，将网格分隔为 4-6 个封闭腔室（每个腔室内部面积约 9-25 个像素）。每个腔室内有一个 4-连通单色小图形（3-6 像素），每个小图形使用不同颜色（从红(2)、蓝(1)、绿(3)、黄(4)、品红(6)中选取）。部分小图形具有某种对称性（水平镜像、垂直镜像或 180 度旋转对称），部分不具有任何对称性。生成约束：每个腔室恰好一个小图形；小图形不接触墙壁；至少有一个对称图形和一个非对称图形。

**规则**：
1. 识别灰(5)墙壁并将网格分割为若干 4-连通的非墙壁区域（封闭腔室）。
2. 对每个腔室，定位其中唯一的非背景、非墙壁色的小图形，将其裁剪为最小边界框。
3. 对裁剪后的图形进行对称性测试：检查水平镜像、垂直镜像和 180 度旋转对称。只要满足其中任一种即判定为"对称"。
4. 对称的腔室：将腔室内所有背景像素替换为该图形的颜色（洪泛填充整个腔室），墙壁不变。
5. 非对称的腔室：将该图形的所有像素替换为背景色黑(0)（擦除图形），腔室变为空腔。
6. 墙壁像素在所有操作中保持不变。

**关键洞察**：对称性不是用来选一个最终输出对象，而是对每个独立区域做就地判定——同一张图中同时发生填充和擦除两种操作，且哪个区域做哪种操作完全由几何对称性决定，必须逐区域裁剪后检验才能确定。
