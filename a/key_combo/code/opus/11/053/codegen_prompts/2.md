## 新题 2：射线穿越计数驱动精灵体平铺数量

**组合逻辑**：[射线延伸/ray_extend] → [计数/counting] → [平铺/tile]（创新：射线不用于擦除目标，而是充当计数探针；计数结果不编码尺寸而是编码平铺副本数）

**来源原语**：射线延伸/ray_extend（2f767503）、射线命中/ray_intersection（2f767503）、计数/counting（2a28add5）、平铺/tile（91413438）、标记条/marker_bar（2f767503）、控制像素/control_pixel（2f767503）、目标对象/target_object（2f767503）、精灵体/sprite（91413438）、阵列排布/array_layout（91413438）

**依赖链**：标记条+控制像素确定射线方向 → 射线穿越目标对象产生命中计数 → 计数值 N 决定精灵体的平铺副本数 → 精灵体按 1xN 阵列排布。删除射线则无法获得 N；删除计数则射线无用途；删除平铺则 N 无下游效果。

从标记条发射射线，统计射线穿越的散落对象数量 N，然后将一个孤立小精灵体复制 N 份排成一行。

**输入结构**：约 12x15 的网格，黑(0)背景。左侧边缘中部有一个 3 像素水平标记条（红(2)），标记条正下方紧邻 1 个橙(7)控制像素。网格中央区域散布 3-5 个蓝(1) 4-连通小对象（每个 2-4 像素，形状各异），它们分布在不同行上，部分与标记条同行，部分不在同行。网格右下角有一个 3x3 的绿(3)精灵体（含黑(0)背景像素的非全填充图案）。生成约束：标记条位于左侧边缘（列 0-2 某一行）；控制像素紧邻标记条中心像素正下方；蓝色对象互不相邻；精灵体与所有蓝色对象不重叠；射线方向固定为水平向右（远离左边缘）。

**规则**：
1. 从红(2)标记条的中心像素出发，沿远离橙(7)控制像素的方向（即水平向右）发射 1 像素宽的射线，射线延伸至网格右边缘。
2. 统计射线经过的所有蓝(1)像素所属的不同 4-连通对象数量，记为 N。同一个对象即使被射线命中多个像素也只计数 1 次。
3. 以绿(3)精灵体的原始位置为起点，将精灵体沿水平方向平铺 N 份，每份 3x3，紧密排列（第 k 份占据列 [原始列 + 3*(k-1), 原始列 + 3*k - 1]）。超出网格右边界的部分裁剪丢弃。
4. 输出中擦除所有蓝(1)对象、红(2)标记条和橙(7)控制像素（替换为黑(0)背景）。
5. 精灵体区域如与被擦除对象重叠，平铺的精灵体覆盖在上层（精灵体优先）。

**关键洞察**：蓝色对象的形状和大小无关紧要，只有"是否被水平射线穿过"这一空间关系决定计数。射线行上方或下方的蓝色对象即使距离很近也不被计入——必须精确判断射线行与对象像素的行坐标是否重合。
