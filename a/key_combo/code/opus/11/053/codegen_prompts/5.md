## 新题 5：印章放置位置由同心距离决定，重叠优先级由深度编码

**组合逻辑**：[印章放置/stamp] + [重涂色/recolor]，由 [距离决定调色板/distance_determines_palette] 中的距离概念转用为重叠优先级（创新：同心结构不产生填充色带，而是充当空间坐标系为印章冲突仲裁）

**来源原语**：印章放置/stamp（abc82100）、重涂色/recolor（abc82100）、颜色替换/color_substitution（abc82100）、距离决定调色板/distance_determines_palette（13e47133）、同心正方形层/concentric_square_layers（13e47133）、标记像素/marker_pixel（13e47133）、模板图案/stencil_pattern（abc82100）

**依赖链**：同心结构为标记像素分配深度值 → 每个标记像素处印章放置模板图案并重涂为标记色 → 印章重叠时深度值更大（更靠内）的标记优先。删除同心结构则无法确定深度和优先级；删除印章操作则标记和模板无意义；删除重涂色则所有印章同色无法区分。

在同心环结构中，每个标记像素获得一个深度值；将模板图案以标记色印章到标记位置，重叠冲突时更深层的标记覆盖外层。

**输入结构**：约 15x15 的网格，黑(0)背景。网格中央有 3-4 层灰(5)同心正方形框（每层 1 像素厚，层间间隔 1 像素背景）。在同心结构的各层之间和内部，分布 3-5 个标记像素，每个标记像素使用不同颜色（从红(2)、蓝(1)、绿(3)、黄(4)、品红(6)中选取）。标记像素位于同心结构覆盖范围内但不在灰色框像素上（位于层间的背景像素位置）。网格的某个角落（不与同心结构重叠）有一个 3x3 的模板图案，由橙(7)像素构成（含部分黑(0)背景像素的非全填充图案）。生成约束：不同标记像素可位于不同深度层；部分标记之间的距离小于 3（使得印章会重叠）。

**规则**：
1. 计算每个标记像素相对于同心结构中心的 Chebyshev 距离，将其归入最近的同心层，得到深度值 d（最外层 d=0，向内依次递增）。
2. 对每个标记像素，将 3x3 模板图案以标记像素为中心放置（印章放置），将模板中所有橙(7)像素替换为该标记像素的颜色（重涂色），黑(0)像素保持为黑(0)。
3. 若多个印章在同一像素位置重叠，深度值 d 更大（更靠近中心）的标记颜色覆盖深度值更小的。相同深度按标记像素在网格中从上到下、从左到右的扫描顺序，后扫描到的覆盖先扫描到的。
4. 输出中移除所有灰(5)同心框像素（替换为黑(0)背景）和原始模板图案。仅保留印章结果。
5. 印章超出网格边界的部分裁剪丢弃。

**关键洞察**：同心框结构在输出中完全消失——它唯一的作用是为每个标记像素分配深度等级，而该等级决定了重叠冲突的仲裁结果。必须先从几何结构中推断出深度分配规则，才能确定最终哪个颜色"赢"在每个重叠位置。
