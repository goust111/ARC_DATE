## 新题 2：对象计数驱动母题循环填充次数

**组合逻辑**：[计数](保留颜色索引机制) → [循环填充](创新：循环次数由计数结果决定，非无限填满)

**来源原语**：计数/counting(58490d8a), 颜色索引行/color_keyed_row(58490d8a), 图例框/legend_box(58490d8a), 循环填充/cyclic_fill(12422b43), 母题行/motif_rows(12422b43), 标记界定母题/marker_delimits_motif(12422b43), 擦除/erase(12422b43)

**依赖链**：图例框提供颜色-母题映射 → 计数确定每个颜色的重复次数 → 循环填充按次数堆叠母题。删除计数则不知填多少次；删除图例则不知填什么图案。

统计网格中各颜色对象的数量，以此决定图例框中对应母题向下循环重复的完整次数。

**输入结构**：黑(0)背景，约 18x18 网格。左侧有一个灰(5)边框包围的图例区域（约 4 列宽、覆盖网格全部行高），图例区域内部为黑色背景，其中最左列非灰的像素为 2~4 个颜色键（如红(2)、蓝(1)、绿(3)），每个颜色键的右侧同行有 2~3 个像素组成的小母题图案。图例区域外的网格散布着若干 4-连通单色小对象（3~6 像素），颜色与图例键颜色对应，每种颜色有 1~4 个独立对象。生成约束：图例中各颜色键所在行互不相邻（至少间隔 1 行黑色），且母题图案高度均为 1 行。

**规则**：
1. 识别灰(5)边框围成的图例区域，提取其中各颜色键及其同行的母题图案（键像素右侧到灰边框之间的非黑像素序列）。
2. 对每个颜色键 C，计数图例区域外颜色为 C 的独立 4-连通对象数量，记为 N_C。
3. 输出网格仅保留图例区域（含灰边框）。在图例区域右侧的空白画布中，从顶行开始，按图例中颜色键从上到下的顺序，依次将各母题垂直堆叠：颜色 C 的母题连续重复 N_C 行，然后紧接下一个颜色的母题重复其对应次数，直到所有颜色处理完毕。
4. 擦除图例外原有的所有散布对象。若堆叠超出网格底部则截断。

**关键洞察**：循环填充的次数不来自网格的空间容量，而来自对象计数——必须先正确分割并计数外部对象才能确定每段母题重复多少次。
