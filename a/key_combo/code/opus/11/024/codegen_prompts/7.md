## 新题 7：精灵拼合孔洞同时满足边缘颜色匹配约束

**组合逻辑**：[拼合填充](保留精确面积覆盖约束) + [平移拼合/边缘匹配](创新：将边缘匹配从矩形组装引入孔洞填充，形成双重约束)

**来源原语**：拼合填充/tiling_fill(184a9768), 源精灵体/source_sprite(184a9768), 封闭孔洞/enclosed_hole(184a9768), 大型单色对象/large_monochrome_object(184a9768), 精灵精确拼合孔洞/sprites_exactly_tile_holes(184a9768), 边缘匹配/edge_matching(446ef5d2), 通配色/wildcard_color(446ef5d2), 擦除/erase(184a9768)

**依赖链**：识别孔洞和精灵 → 面积匹配筛选可行精灵子集 → 尝试放置时检查边缘颜色匹配 → 通配色简化匹配但不消除约束。仅靠面积匹配有多解，加入边缘匹配后解唯一。删除面积约束则无法确定放置区域；删除边缘匹配则有多个合法拼合方案。

将多色精灵无旋转地平移嵌入大型对象的孔洞中，要求精灵精确覆盖孔洞面积且相邻精灵的接触边颜色一致。

**输入结构**：黑(0)背景，约 18x18 网格。一个蓝(1)大型单色对象（不规则形状，约占网格 40% 面积）内部有 1~2 个封闭背景孔洞（每个孔洞为 4-连通黑色区域，面积 6~12 像素，形状不规则）。网格其余区域散布着 2~4 个源精灵体，每个精灵为多色（含 2~3 种颜色，从红(2)、绿(3)、黄(4)、橙(7)中选取），像素数为 3~6，形状不规则。蓝(1)为通配色。生成约束：精灵的总像素数恰好等于所有孔洞的总面积；存在唯一的放置方案使得精灵精确覆盖所有孔洞且相邻精灵接触像素颜色一致或至少一方为蓝(1)。

**规则**：
1. 识别蓝(1)大型对象内部的所有封闭黑色孔洞。
2. 识别蓝(1)对象外部的所有源精灵体（多色 4-连通前景分量）。
3. 将每个精灵无旋转平移到孔洞内的某个位置，使得：(a) 所有精灵像素恰好覆盖所有孔洞像素（精确拼合），(b) 任意两个精灵若有像素 4-邻接，则接触处两像素须颜色相同或至少一个为蓝(1)（蓝色为通配色，与任何颜色兼容）。
4. 擦除精灵的原始位置。输出中孔洞被精灵填满，大型蓝色对象和背景不变。

**关键洞察**：面积精确覆盖产生有限候选方案，但仅凭面积可能有多解——边缘颜色匹配（以蓝为通配）作为第二层约束将解缩减为唯一。求解者必须同时考虑几何拼合和颜色兼容性两个维度。
