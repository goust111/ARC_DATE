## 新题 6：外部对象空间分布统计决定矩形象限着色

**组合逻辑**：[分割/象限](保留四等分机制) + [计数](创新：计数对象的空间方位而非仅数量) → [重涂色](创新：颜色由方位计数结果决定而非由标记像素指定)

**来源原语**：分割/split(e9ac8c9e), 实心矩形/solid_rect(e9ac8c9e), 象限/quadrant(e9ac8c9e), 重涂色/recolor(e9ac8c9e), 计数/counting(58490d8a), 前景对象/foreground_object(58490d8a), 最近距离/nearest_distance(d6e50e54), 角落对应/corner_correspond(e9ac8c9e)

**依赖链**：识别灰色矩形并四等分 → 统计矩形外部各象限方向的对象数量 → 数量最多的方向对应的颜色填充该象限。删除分割则无象限目标；删除计数则颜色来源未知；删除空间方位判定则计数无法对应到象限。

将灰色矩形四等分后，每个象限被涂为其对角外侧区域中数量最多的那种颜色对象的颜色。

**输入结构**：黑(0)背景，约 17x17 网格。中央有一个灰(5)实心矩形（宽高均为偶数，约 6x6 或 8x8）。矩形外的四个对角方向区域（左上、右上、左下、右下）各散布着若干小型 4-连通单色对象（2~4 像素），颜色从红(2)、蓝(1)、绿(3)、黄(4)中选取。每个对角区域包含 2~4 种颜色的对象，每种颜色 1~3 个对象，且每个区域中数量最多的颜色唯一（无并列）。生成约束：四个区域中数量最多的颜色互不相同。

**规则**：
1. 找到灰(5)实心矩形，计算其中心点坐标。
2. 将矩形水平和垂直各等分为四个象限：左上、右上、左下、右下。
3. 对矩形外的每个前景对象，根据其质心相对于矩形中心的位置归入四个对角区域之一（左上区域：质心在矩形中心的左方且上方，依此类推）。
4. 对每个对角区域，统计各颜色的独立对象数量，确定该区域中数量最多的颜色 C_max。
5. 将矩形对应象限（与区域同侧）整体涂为 C_max：左上区域的 C_max 涂左上象限，依此类推。
6. 输出中保留矩形外的所有前景对象不变。

**关键洞察**：象限颜色不来自紧邻的标记像素（如参考题中的对角标记），而来自对整个对角区域的统计分析——必须正确划分空间区域、归类对象、计数并比较才能确定每个象限的颜色。
