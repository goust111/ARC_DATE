## 新题 3：坠落路径塑形后的最大空腔填充

**组合逻辑**：[重力下落(gravity_drop)] + [绕行(detour)](已有原语) → [搜索(search)](创新：搜索目标是坠落路径围成的空腔) + [填充(fill)](创新：填充的区域由坠落路径的拓扑决定)

**来源原语**：重力下落/绕行/遇障碍绕最近侧/源列/障碍线段(c87289bb), 搜索/填充/最大矩形填充/最小边长约束/空心矩形区域(3eda0437)

**依赖链**：源像素坠落路径遇到障碍后绕行 → 绕行方向改变路径走向 → 路径将背景切割为不同区域 → 在剩余背景中找到最大全黑矩形 → 对该矩形填色。障碍线段的位置和长度直接决定了绕行方向，进而决定了路径形状，最终决定了可填充的最大矩形在哪里。移动障碍会同时改变路径和填充目标。

将顶部色块下落并绕过障碍后，在剩余背景空间中找到最大的空矩形并填充。

**输入结构**：约 16x16 的黑(0)背景网格。第 0 行有 3~5 个青(8)像素作为源列（互不相邻）。网格中部有 2~3 条红(2)水平障碍线段（每条占连续 3~6 个像素，位于同一行，各线段不在同一行，不与源列正上方对齐的列重叠超过一个像素）。生成约束：所有源列从上向下坠落并完成绕行后，剩余背景中存在至少一个高和宽均不小于 2 的全黑矩形；各源列的绕行路径互不冲突（不会有两条路径需要占用同一个像素）。

**规则**：
1. 复制输入网格。
2. 从每个源列像素开始，向下延伸一条青(8)竖直线，逐行绘制，直到碰到障碍线段或到达底边。
3. 若竖直线碰到障碍线段：在障碍线段正上方一行，从源列位置向障碍线段的最近外侧端画一段青(8)水平线，然后从该外侧端继续向下延伸竖直线直到底边或下一个障碍。若源列恰好位于障碍线段的正中央（到两端距离相等），则绕向右侧。
4. 所有路径绘制完成后，在网格中搜索所有高和宽均不小于 2 的全黑(0)矩形区域。
5. 将面积最大的全黑矩形填充为灰(5)。若最大面积有多个矩形并列，选择左上角行号最小的；仍并列则选左上角列号最小的。
6. 红(2)障碍线段在输出中保持不变。

**关键洞察**：填充目标不是预设的固定区域，而是由坠落路径的绕行拓扑间接塑造出来的——改变任一障碍的位置会同时改变路径走向和可用空腔的形状与位置。需要对比多个示例才能确认"填充最大矩形"而非"填充路径围成的封闭区域"。
