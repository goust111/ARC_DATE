## 新题 2：轴标引导的镜像补全与孔洞填色

**组合逻辑**：[镜像(mirror)](创新：镜像轴由外部标记位置编码而非引导线) + [填充(fill)](创新：填充目标是镜像后涌现的封闭孔洞) + [重涂色/擦除(recolor/erase)](创新：由孔洞存在性决定)

**来源原语**：镜像/轴线决定变换(4e7e0eb9), 填充/封闭孔洞/有孔触发重涂(aa4ec2a5), 标记像素(0ca9ddb6, 6df30ad6), 擦除(6df30ad6)

**依赖链**：轴标像素的位置编码镜像方向 → 镜像操作创造了新的形状 → 新形状可能产生封闭孔洞 → 孔洞存在时用轴标颜色填充，不存在时擦除轴标。镜像方向决定了孔洞是否涌现，而孔洞是否涌现反过来决定了轴标的命运（保留颜色还是被擦除）。

根据轴标像素的位置对每个前景对象做镜像补全；若补全后产生封闭孔洞，则用轴标颜色填充孔洞并保留轴标；否则擦除轴标。

**输入结构**：约 18x18 的黑(0)背景网格。网格中有 3~4 个互不相邻的 4-连通单色前景对象（每个对象一种颜色，从蓝(1)、绿(3)、灰(5)、青(8)中选取），每个对象占 6~15 像素，形状不规则但具有可沿某轴镜像补全的半对称结构。每个对象恰好有一个与之相邻（8-邻接）的"轴标像素"，颜色与该对象不同（从红(2)、黄(4)、橙(7)、品红(6)中选取）。轴标像素位于该对象边界框的某条边的中点位置：若在上边或下边中点 → 表示水平轴（上下镜像）；若在左边或右边中点 → 表示垂直轴（左右镜像）。生成约束：镜像补全后至少一个对象产生封闭孔洞、至少一个对象不产生封闭孔洞；各对象镜像补全后的区域互不重叠。

**规则**：
1. 对每个前景对象，找到与其 8-邻接的唯一轴标像素。
2. 根据轴标位置确定镜像轴：轴标在对象边界框上边或下边中点 → 以对象边界框水平中线为轴做上下镜像；轴标在左边或右边中点 → 以对象边界框垂直中线为轴做左右镜像。
3. 将镜像产生的新像素绘制到网格上（与原对象同色），形成补全后的完整对象。
4. 检查补全后的对象是否包含 4-连通的封闭黑(0)孔洞（完全被该对象像素包围的黑色连通区域）。
5. 若存在孔洞：用该对象的轴标颜色填充所有孔洞像素，轴标像素保留。
6. 若不存在孔洞：擦除该对象的轴标像素（变为黑(0)）。

**关键洞察**：轴标像素承担三重角色——编码镜像方向、提供孔洞填充颜色、自身根据孔洞是否涌现而保留或消失。仅看单个示例无法区分"轴标总是保留"和"轴标根据孔洞条件保留"，需要对比有孔和无孔的案例。

Recolor the grey object with the color of the marker set closest to it, erasing all markers.

Input structure
- The grid has a black background with one 4-connected grey object.
- Every other foreground color appears as one or more isolated marker pixels.

Rule
- For each marker color, measure the smallest squared Euclidean distance from any marker pixel of that color to any grey-object pixel.
- The unique marker color with the smallest such distance becomes the output color.
- Return a blank background grid with the grey object's mask painted in that selected color.

Key insight
- The scattered pixels are competing color labels; only the label with the closest approach to the grey object survives.
</description>

1. `main(grid)` 必须实现新题描述中的确定性转换规则，不能只识别 `generate_input()` 的固定模板。禁止不同的input网格输出相同的output网格。
2. `generate_input()` 必须随机生成多样样例，不能固定死。随机维度应覆盖：网格大小、对象数量、位置、颜色、方向、形状参数或关键分支。注意若描述中存在若干，需实现而不是只有单个，包括object或者对应关系等等。且若涉及到最短路径，则输入网格中必涉及到多条路径，对选择造成干扰。

6. 若规则有多个分支，生成器不能长期固定成一个分支；应让分支在随机样例中合理出现。分支概率不必平均——难以发现的隐蔽分支（如少数情况下才触发的特殊规则）应适当提高出现概率，确保在 3 个训练示例中至少出现一次，否则求解者无法归纳该规则。对于颜色映射类规则，确保 2 个左右的示例即可覆盖所有映射关系（每种颜色→颜色的映射至少在某个示例中出现过）。
