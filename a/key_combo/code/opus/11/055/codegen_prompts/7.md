## 新题 7：边框裁剪后按标记方向镜像拼接

**组合逻辑**：[裁剪(crop)](已有原语) + [镜像(mirror)](创新：镜像轴由外部标记位置编码) + [拼接(concatenate)](创新：拼接方向与镜像轴耦合) + [重涂色(recolor)](创新：边框重涂为标记颜色)

**来源原语**：裁剪/空心矩形/单色边框/唯一完整边框/包含内部(c909285e), 镜像/拼接/整幅画布(6d0aefbc), 标记像素(0ca9ddb6), 重涂色(aa4ec2a5)

**依赖链**：唯一完整边框 → 裁剪出边框及内部内容 → 标记像素相对边框中心的方位决定镜像轴 → 镜像轴同时决定拼接方向 → 拼接前将边框像素重涂为标记颜色。边框检测、标记定位、镜像、拼接四步串联且每步输出被下一步使用。

找到唯一的完整矩形边框并裁剪，根据外部标记像素的位置做镜像拼接，并将边框重涂为标记颜色。

**输入结构**：约 15x15 的黑(0)背景网格，其上有各种散布的杂色前景像素。网格中恰好有一种颜色（如蓝(1)）的像素组成了一个完整的矩形边框（一像素宽的矩形周长，无断裂），该颜色不出现在边框之外。边框内部含有 2~3 种其他颜色的像素组成的非对称小图案。网格上还有恰好一个孤立标记像素（颜色为红(2)、绿(3)、黄(4)或橙(7)之一），位于边框外部。生成约束：标记像素不在边框的水平中线或垂直中线的延长线上（即标记相对于边框中心明确偏向某一侧）。

**规则**：
1. 找到唯一形成完整矩形边框的颜色，裁剪出该边框及其内部内容（包含边框本身），得到子网格 A。
2. 确定标记像素相对于边框中心的位置：
   - 若标记在边框中心的左方或右方（|列差| > |行差|）→ 镜像轴为垂直轴，拼接方向为水平。
   - 若标记在边框中心的上方或下方（|行差| > |列差|）→ 镜像轴为水平轴，拼接方向为垂直。
   - |行差| = |列差| 时，按垂直轴处理（水平拼接）。
3. 生成子网格 A 的镜像副本 B（按确定的轴做翻转）。
4. 将 A 的边框像素全部重涂为标记像素的颜色。B 的边框像素同样重涂为标记像素的颜色。
5. 将 A 和 B 沿拼接方向拼合：若水平拼接，A 在左 B 在右，共享边框的接合边（重叠的一列边框合并为一列）；若垂直拼接，A 在上 B 在下，共享接合行。
6. 输出为拼合后的网格（不含原输入中的其他杂色像素和标记像素）。

**关键洞察**：标记像素同时编码了两个信息：镜像/拼接方向（由其相对边框的方位决定）和边框的新颜色。裁剪步骤消除了输入中的干扰噪声，而拼接时的边框合并规则需要对比多个示例才能确认（单个示例可能误以为边框被保留两份）。

## 实现要求

1. `main(grid)` 必须实现新题描述中的确定性转换规则，不能只识别 `generate_input()` 的固定模板。禁止不同的input网格输出相同的output网格。
2. `generate_input()` 必须随机生成多样样例，不能固定死。随机维度应覆盖：网格大小、对象数量、位置、颜色、方向、形状参数或关键分支。注意若描述中存在若干，需实现而不是只有单个，包括object或者对应关系等等。且若涉及到最短路径，则输入网格中必涉及到多条路径，对选择造成干扰。
3. 生成器必须保证输入满足 `main()` 的隐式假设：对象不重叠、不越界、特殊标记唯一或可区分、匹配关系无歧义、关键分支出现概率相同。
4. 禁止把 ARC 颜色 id 、亮度、拼写等当作人类不可见的数值语义参与排序、大小比较或隐藏映射。颜色变化必须有可见结构线索。注意颜色亮度、拼写等也是不可见信息，若描述中出现违规的颜色id或者亮度，可自行使用少量的固定颜色替代，但注意生成时要在三个以内输入输出网格中对所有变换100%覆盖度。
5. 输出样例要视觉清晰，人类必须能从输入输出对中肉眼辨认出规律。具体要求：避免对象粘连、覆盖关系混乱、同一像素多重语义；不同逻辑步骤产生的结果不要大面积层叠在一起导致无法分辨哪个颜色属于哪个步骤；输入中各元素之间保持足够间距，输出中新增的标记/填充/路径等应与背景和已有元素在颜色上有明显区分；若规则涉及多层叠加，生成时控制对象密度和尺寸，确保叠加区域只占少数像素而非铺满整个网格。
