## 新题 4：面板差异图的形状频率着色

**组合逻辑**：[逐像素比较(pixel_comparison)](已有原语) → [形状匹配(shape_matching)](创新：匹配对象是比较后涌现的差异分量) + [重涂色(recolor)](创新：涂色依据是差异分量的形状频率而非来源面板)

**来源原语**：逐像素比较/面板/分隔列/差异分类着色(d47aa2ff), 形状匹配/唯一重复形分涂/连通分量/精灵体(b230c067)

**依赖链**：两面板逐像素比较 → 差异像素形成连通分量 → 将分量按归一化形状分组 → 形状出现次数决定该分量的最终颜色。比较步骤不可跳过（差异分量只存在于比较之后），形状分组也不可跳过（颜色由频率而非位置决定）。

比较两个面板，将差异像素按形状频率着色：形状唯一的差异分量涂红，形状重复的涂蓝。

**输入结构**：约 12x25（或 25x12）的网格，由一列（或一行）灰(5)分隔线分为左右（或上下）两个等大面板，每个面板约 12x12。两个面板的背景为黑(0)，各含若干绿(3)前景像素构成的图案。两面板的图案大部分重合，但各有若干 4-连通小区域（3~8 像素）不在对方面板中出现。生成约束：差异产生的 8-连通分量共 4~6 个，其中至少两个分量的归一化边界框形状相同（平移等价），至少一个分量的形状是唯一的；各差异分量互不 8-邻接。

**规则**：
1. 移除分隔线，将左右面板逐像素对齐比较。
2. 两面板同位置均为绿(3)的像素 → 输出为绿(3)。
3. 两面板同位置均为黑(0)的像素 → 输出为黑(0)。
4. 仅一侧为绿(3)的像素 → 标记为"差异像素"。
5. 将所有差异像素按 8-连通分量分组。
6. 对每个分量，裁剪到其边界框并提取二值掩码（差异像素为1，其余为0）作为归一化形状。
7. 将所有分量按归一化形状分组：形状相同（掩码完全一致）的分量归为一组。
8. 若某组只含一个分量（形状唯一），将该分量的所有像素涂为红(2)。
9. 若某组含多个分量（形状重复），将该组所有分量的所有像素涂为蓝(1)。
10. 输出为一个面板大小的网格（宽度和高度与单个面板相同）。

**关键洞察**：差异分量本身并不存在于任何一个面板中——它们只在比较后涌现。着色不是按"来自左面板/右面板"区分（那是原题的做法），而是按差异分量的几何形状频率区分，这要求求解者先完成比较、再做形状匹配、再做频率统计，三步环环相扣。
