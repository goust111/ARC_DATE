## 新题 7：选择器四象限颜色映射转写

**组合逻辑**：[颜色索引匹配/图例位置映射](已有) → [颜色映射](创新：选择器的象限颜色对定义映射规则) → [重涂色](创新：用推导出的映射转写目标区域)

**来源原语**：颜色索引匹配color_index_matching(7d18a6fb), 图例位置映射legend_position_mapping(7d18a6fb), 选择器块selector_block(7d18a6fb), 象限quadrant(7d18a6fb), 颜色映射color_mapping(b0722778), 匹配对推导映射pair_defines_mapping(b0722778), 重涂色recolor(82819916)

**依赖链**：选择器块的象限标记不再指向外部精灵体，而是成对定义颜色映射规则（左半象限色→右半象限色）；该映射规则反过来应用于网格中的目标区域。选择器的结构语义完全改变——从"索引"变为"映射定义器"。

网格中有一个 5x5 选择器块，其四个 2x2 象限各填一种颜色，左列两象限的颜色作为映射源色，右列两象限的颜色作为映射目标色（上左→上右，下左→下右定义两对映射）。网格其余位置有一个由这些源色构成的图案，将该图案按映射规则转写为目标色。

**输入结构**：约 15x15 的网格，黑(0)背景。左上角有一个 5x5 的选择器块：灰(5)构成十字分隔（第 3 行和第 3 列为灰(5)），将内部分为四个 2x2 象限。左上象限填颜色 A（如蓝(1)），右上象限填颜色 B（如红(2)），左下象限填颜色 C（如黄(4)），右下象限填颜色 D（如橙(7)）。网格右下区域（与选择器不重叠，间隔至少 2 行 2 列）有一个由颜色 A 和 C 构成的 4-连通图案（5~10 像素，形状不规则）。生成约束：A, B, C, D 四色互不相同且均非黑非灰；目标图案仅使用 A 和 C 两种颜色。

**规则**：
1. 识别 5x5 选择器块（由灰(5)十字分隔的 4 个 2x2 纯色象限）。
2. 读取颜色映射：左上象限色 A 映射到右上象限色 B；左下象限色 C 映射到右下象限色 D。
3. 在网格中定位由颜色 A 和 C 构成的目标图案区域。
4. 对目标图案执行颜色映射：A→B，C→D。
5. 输出仅包含转写后的图案的最小边界框裁剪（黑(0)背景处保留黑(0)）。

**关键洞察**：选择器块不是索引图例而是映射定义器——其空间布局（左列=源，右列=目标，行=对应关系）隐式编码了颜色替换规则，求解者需从位置语义中推导映射而非从颜色匹配中查找。
