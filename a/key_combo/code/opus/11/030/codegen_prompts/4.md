## 新题 4：对角邻接传染与镜像边界截断

**组合逻辑**：[仅对角邻接着色](创新：迭代传染而非单次) → [镜像](创新：传染结果关于中轴镜像) → [裁剪](创新：仅保留镜像后与原图重合的区域)

**来源原语**：仅对角邻接diagonal_only_adj(396d80d7), 对角邻接背景着色diagonal_bg_color(396d80d7), 镜像mirror(62c24649), 裁剪crop(7bb29440)

**依赖链**：对角传染的迭代次数决定了着色区域的大小；镜像操作将传染图案翻转后与原始前景叠加；最终裁剪区域由叠加后的非背景像素边界框决定。传染范围影响镜像后的对齐结果，三步紧密耦合。

从封闭框的对角邻接背景像素开始，迭代传染（每次将新着色像素的对角邻接背景像素也着色），传染固定 2 轮后停止。将传染结果关于网格垂直中轴做左右镜像，镜像后的着色像素与原始前景像素取并集，最后裁剪到该并集的最小边界框。

**输入结构**：约 15x15 的网格，黑(0)背景。网格中有一个由红(2)像素构成的单像素宽封闭矩形框（边长 5~7），框内全为黑(0)，框外也全为黑(0)。框不居中——偏向网格左半侧（框的垂直中线在网格垂直中线的左侧）。生成约束：框离左边界至少 1 像素，离右边界足够远使传染和镜像后不超出网格；框为轴对称矩形。

**规则**：
1. 识别红(2)封闭矩形框。
2. 第 1 轮传染：找到所有与红(2)像素仅有对角邻接（无正交邻接）的黑(0)像素，将它们涂为绿(3)。
3. 第 2 轮传染：找到所有与绿(3)像素仅有对角邻接（无正交邻接于任何非黑像素）的黑(0)像素，将它们也涂为绿(3)。
4. 将整个网格关于垂直中轴做左右镜像，得到镜像网格。
5. 合并：对每个像素位置，若原始网格或镜像网格中任一为非黑色，则输出该颜色；若两者都非黑且颜色不同，以原始网格颜色优先。
6. 裁剪合并结果到所有非黑像素的最小边界框。

**关键洞察**：传染的迭代轮数是固定的（2轮），但传染区域的几何形状取决于封闭框的角点位置；镜像后的叠加创造了原本不存在的对称图案，裁剪边界由这个涌现的对称图案决定。

## 实现要求

1. `main(grid)` 必须实现新题描述中的确定性转换规则，不能只识别 `generate_input()` 的固定模板。禁止不同的input网格输出相同的output网格。
2. `generate_input()` 必须随机生成多样样例，不能固定死。随机维度应覆盖：网格大小、对象数量、位置、颜色、方向、形状参数或关键分支。注意若描述中存在若干，需实现而不是只有单个，包括object或者对应关系等等。且若涉及到最短路径，则输入网格中必涉及到多条路径，对选择造成干扰。
3. 生成器必须保证输入满足 `main()` 的隐式假设：对象不重叠、不越界、特殊标记唯一或可区分、匹配关系无歧义、关键分支出现概率相同。
4. 禁止把 ARC 颜色 id 、亮度、拼写等当作人类不可见的数值语义参与排序、大小比较或隐藏映射。颜色变化必须有可见结构线索。注意颜色亮度、拼写等也是不可见信息，若描述中出现违规的颜色id或者亮度，可自行使用少量的固定颜色替代，但注意生成时要在三个以内输入输出网格中对所有变换100%覆盖度。
5. 输出样例要视觉清晰，人类必须能从输入输出对中肉眼辨认出规律。具体要求：避免对象粘连、覆盖关系混乱、同一像素多重语义；不同逻辑步骤产生的结果不要大面积层叠在一起导致无法分辨哪个颜色属于哪个步骤；输入中各元素之间保持足够间距，输出中新增的标记/填充/路径等应与背景和已有元素在颜色上有明显区分；若规则涉及多层叠加，生成时控制对象密度和尺寸，确保叠加区域只占少数像素而非铺满整个网格。
6. 若规则有多个分支，生成器不能长期固定成一个分支；应让分支在随机样例中合理出现。分支概率不必平均——难以发现的隐蔽分支（如少数情况下才触发的特殊规则）应适当提高出现概率，确保在 3 个训练示例中至少出现一次，否则求解者无法归纳该规则。对于颜色映射类规则，确保 2 个左右的示例即可覆盖所有映射关系（每种颜色→颜色的映射至少在某个示例中出现过）。
