## 新题 7：格网分区内的重力沉降与跨区透明叠加

**组合逻辑**：[重力沉降gravity_settling](创新：在格网的每个分区内独立执行) + [透明叠加transparent_overlay](创新：叠加的对象是各分区沉降后的结果) + [分隔线划分separator_partition] + [中心对齐center_alignment]

**来源原语**：重力沉降(#17 1e0a9b12), 透明叠加(#1 c8cbb738, #20 6a11f6da), 分隔线划分(#16 39e1d7f9), 中心对齐(#1 c8cbb738)

**依赖链**：分隔线将输入划分为多个等大分区 → 每个分区内独立执行重力沉降 → 沉降后将所有分区中心对齐叠加为一个输出 → 叠加时非背景像素覆盖背景像素，多个非背景像素重叠时按分区从左到右的顺序决定优先级（右侧分区覆盖左侧）。

多个格网分区各自重力沉降后，中心对齐透明叠加为一幅输出，右侧分区优先。

**输入结构**：约 5x17 网格（5 行 17 列），背景黑(0)。2 条灰(5)竖直分隔线将网格等分为 3 个 5x5 的分区（分隔线各占 1 列，分区间距 = 分隔线宽 1）。每个分区内有 2~4 个散布的彩色像素（使用蓝(1)、红(2)、绿(3)、黄(4)中的若干色），各分区的颜色可能有重叠也可能不同。

**规则**：
1. 识别灰(5)竖直分隔线，将网格分为 3 个等大分区（不含分隔线列）。
2. 在每个 5x5 分区内，独立执行列内重力沉降：每列的非背景像素下落至底部，保持列内从上到下的相对顺序。
3. 生成 5x5 的输出画布，初始为全黑(0)。
4. 按从左到右的分区顺序（分区1、分区2、分区3），依次将每个沉降后的分区叠加到输出画布上：若分区像素为非背景色，则覆盖输出画布对应位置的值（无论之前是什么）。
5. 输出即为最终叠加结果。

**关键洞察**：分区内的重力沉降改变了像素的垂直分布，因此叠加时的遮挡关系不能直接从输入位置推断——必须先完成沉降再判断谁遮挡谁。同时，叠加优先级是空间序（左到右）而非颜色值。

Copy the colored neighborhood around the one decorated marker to every matching marker in the lattice.

Input structure
- A square-cell lattice is separated by full horizontal and vertical separator lines.
- Each lattice cell is uniformly colored; most cells are background.
- One marker cell is surrounded by a colored 3x3-neighborhood template, and the same marker color appears elsewhere as isolated cells.

Rule
- Compress the lattice to one value per cell.
- Use the decorated marker's non-background neighbors as relative colored offsets.
- Stamp those offsets around every cell of the marker color, clipping offsets that fall outside the lattice.

Key insight
The separator grid is only scale: the real rule is copying a small colored mask from the exemplar marker to all same-color marker cells.
</description>

6. 若规则有多个分支，生成器不能长期固定成一个分支；应让分支在随机样例中合理出现。分支概率不必平均——难以发现的隐蔽分支（如少数情况下才触发的特殊规则）应适当提高出现概率，确保在 3 个训练示例中至少出现一次，否则求解者无法归纳该规则。对于颜色映射类规则，确保 2 个左右的示例即可覆盖所有映射关系（每种颜色→颜色的映射至少在某个示例中出现过）。
