## 新题 3：射线交叉填充与图层优先级仲裁

**组合逻辑**：[射线延伸ray_extend] + [行列交叉row_column_crossing] + [洪泛填充flood_fill](创新：填充区域由射线围合而成) + [图层优先级layer_priority](创新：由射线源像素的空间位置决定)

**来源原语**：射线延伸(#18 45bbe264), 行列交叉(#18 45bbe264), 洪泛填充(#9 4e469f39), 图层优先级(#20 6a11f6da)

**依赖链**：标记像素发出十字射线 → 射线相交形成封闭区域 → 洪泛填充每个封闭区域 → 区域被多条射线围合时，用图层优先级（由射线源的行号决定）仲裁颜色。射线必须先画出才能形成围合；围合不存在则无区域可填；优先级规则需对比多个示例才能归纳。

多个彩色标记发出十字射线，射线围合形成的封闭区域按"行号最大的射线源优先"规则着色。

**输入结构**：约 11x11 网格，背景黑(0)。3 个非背景标记像素位于不同行和不同列，颜色各异（如蓝(1)、绿(3)、黄(4)）。标记像素不在网格边缘行/列上。

**规则**：
1. 每个标记像素向上、下、左、右四个方向发出射线，射线颜色与标记相同，延伸至网格边界。
2. 标记像素本身保留原色不变。
3. 两条不同来源的射线相交的像素涂红(2)。
4. 射线将网格分割为若干矩形区域。对每个完全被射线和/或网格边界围合的矩形区域，执行洪泛填充。
5. 填充颜色的选择规则：该区域的边界由哪些标记的射线构成，取这些标记中**行号最大者**的颜色作为填充色。若区域仅由一个标记的射线和网格边界围合，则用该标记的颜色。
6. 射线像素和交叉点像素不被填充覆盖（它们保持射线色或红色）。

**关键洞察**：表面上看每个区域被多条射线包围、颜色选择似乎任意，但规则是由射线源的行坐标仲裁——行号越大优先级越高。这个规则需对比多个区域的着色才能归纳。
