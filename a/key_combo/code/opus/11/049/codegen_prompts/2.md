## 新题 2：印章覆盖的颜色随距离循环移位

**组合逻辑**：[印章覆盖stamp] + [循环移位cyclic_shift](创新：移位量由目标与范例的曼哈顿距离决定) + [最近距离nearest_distance](创新：作为移位量的编码来源)

**来源原语**：印章覆盖(#16 39e1d7f9), 循环移位(#11 2601afb7), 最近距离(#19 2204b7a8)

**依赖链**：范例标记的邻域模板提供印章形状和基础颜色 → 每个目标标记相对范例的曼哈顿距离决定颜色循环偏移量 → 最终每个目标标记处的印章具有距离相关的颜色变体。距离计算依赖位置，印章形状依赖范例，颜色偏移依赖距离——三者环环相扣。

将范例标记周围的多色邻域模板复制到同色标记处，但模板中的颜色按目标与范例的曼哈顿距离做循环移位。

**输入结构**：约 15x15 网格，背景黑(0)，有灰(5)分隔线将网格划分为 5x5 的格网（每个格子 3x3，分隔线宽 1 像素，非必须均匀但保证对齐）。格网中大部分格子为黑(0)。恰好一个格子为红(2)且其 8-邻域格子中有 2~4 个被涂上了不同的非背景非红色（如蓝(1)、绿(3)、黄(4)），这些构成邻域模板。另有 3~4 个格子也为红(2)但邻域为空（孤立标记）。

**规则**：
1. 识别唯一被装饰的红(2)格子（其邻域有非背景色）为范例。
2. 提取范例的邻域模板：记录每个非背景邻居相对于范例的方向偏移及其颜色。设模板中出现了 C 种不同颜色，按这些颜色在模板中从左上到右下首次出现的顺序排列为颜色序列 S。
3. 对每个孤立红(2)标记，计算其到范例的棋盘格距离 D（格网坐标的切比雪夫距离，即 max(|row差|, |col差|)）。
4. 将颜色序列 S 循环右移 D 位。用移位后的序列替换模板中对应位置的颜色，然后将修改后的模板印章到该标记的邻域。
5. 印章超出网格边界的部分裁剪。模板位置与分隔线重叠时，分隔线颜色不变（印章不覆盖分隔线）。

**关键洞察**：同一个印章形状在不同位置呈现不同颜色组合，求解者必须发现颜色变化的规律是距离驱动的循环移位，而非独立的颜色映射。
