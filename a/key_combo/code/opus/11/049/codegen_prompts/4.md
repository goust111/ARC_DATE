## 新题 4：对称补全后的缺陷检测与环绕标记

**组合逻辑**：[对称补全symmetry_complete] + [模式匹配pattern_match](创新：匹配对称后应有的模式以检测缺陷) + [标记环绕surround_marking](创新：环绕标记的目标是对称性破坏点)

**来源原语**：对称补全(#10 60d73be6), 模式匹配(#5 d94c3b52), 标记环绕(#15 71e489b6), 异常值选择(#15 71e489b6)

**依赖链**：输入本应具有双轴对称但有若干像素被故意移除或改色 → 需通过对称补全推断"正确"图案 → 将推断结果与实际输入对比，找出不匹配的像素（缺陷） → 对缺陷像素执行 8-邻域环绕标记。对称补全提供预期基准，缺陷检测依赖该基准与实际的差异，环绕标记作用于检测结果。

检测并标记一个近似双轴对称图案中的对称性破坏点。

**输入结构**：约 13x13 网格，背景黑(0)。一条完整的灰(5)横行和一条完整的灰(5)竖列构成十字轴线（行列交叉处也为灰）。在四个象限中，蓝(1)像素构成一个近似关于十字轴双轴对称的图案（每个象限约 4~7 个蓝像素）。但其中 2~3 个蓝像素被故意替换为黑(0)（即被删除），另有 1~2 个黑(0)位置被替换为蓝(1)（即被添加）。生成约束：扰动不位于轴线上；理想对称图案（无扰动版本）确实是严格双轴对称的。

**规则**：
1. 识别十字轴线（完整灰行与完整灰列）。
2. 对于每个非轴线非背景像素，计算其关于水平轴、垂直轴、以及双轴的三个镜像位置。一个像素若在四个对称位置（含自身）中，蓝(1)的出现次数 >= 3，则该位置"应当"为蓝；若出现次数 <= 1，则"应当"为黑。
3. 缺陷像素 = 实际颜色与"应当"颜色不同的像素。
4. 输出 = 输入的副本，但在每个缺陷像素的 8-邻域中，所有背景(0)像素被涂为橙(7)。缺陷像素本身保持其实际颜色不变。轴线像素不受影响。

**关键洞察**：必须先利用多数投票原则从有噪声的对称图案中重建理想对称，然后才能识别哪些是缺陷——直接观察单个像素是否"对称"不够，因为可能有对称位置上的像素本身就是被扰动的。
