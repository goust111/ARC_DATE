## 新题 5：双列图例编码平铺镜像序列

**组合逻辑**：[平铺tiling] + [镜像mirror] + [双列图例two_col_legend](创新：图例编码的不是颜色替换而是平铺方向指令) + [编码映射encoding_map]

**依赖链**：图例中的颜色对编码翻转指令（左列色=该位置用原瓦片，右列色=该位置用镜像瓦片） → 输出网格中每个瓦片位置的颜色由瓦片边缘的标记色确定属于"原/镜"哪一类 → 按类别放置原瓦片或镜像瓦片。图例解读依赖颜色映射，瓦片选择依赖图例，最终布局依赖瓦片选择。

根据双列图例的颜色指令决定平铺序列中每个位置使用原瓦片还是左右镜像瓦片。

**输入结构**：约 14x7 网格，背景黑(0)。左半部分为一个 4x4 的瓦片区域（含多色图案，至少 3 种前景色），瓦片与其余部分之间有 1 列黑色间隔。右上角有一个 2 列 N 行（N=3~5）的双列图例块，图例完全填满无背景间隔。图例下方有一行 N 个单独的彩色标记像素，从左到右排列，每个标记像素的颜色恰好是图例中某一行的左列色或右列色。

**规则**：
1. 识别左侧瓦片（4x4 区域）和右侧双列图例。
2. 图例编码规则：每行的左列颜色代表"使用原瓦片"，右列颜色代表"使用左右镜像瓦片"。
3. 读取图例下方的标记像素行，从左到右共 N 个标记。
4. 对于第 i 个标记：在图例中找到包含该标记颜色的行。若标记颜色 = 该行左列色，则第 i 个平铺位置使用原瓦片；若 = 右列色，则使用镜像瓦片。
5. 输出：将 N 个瓦片（原或镜像）从左到右水平拼接，形成 4 x (4N) 的输出网格。

**关键洞察**：图例的两列不是传统的颜色替换映射，而是编码了二元选择指令；标记行中每个像素的颜色是对图例的查询键，决定瓦片朝向。
