## 新题 1：射线穿越嵌套层变色

**组合逻辑**：[射线延伸](从缺口发射) → [嵌套矩形](射线穿越边界时变色) → [重涂色](射线颜色由穿越层数决定)

**来源原语**：射线延伸(e12f9a14)、嵌套矩形(5751f35e)、重涂色(25094a63)、由外到内嵌套(5751f35e)、框架缺口(e12f9a14)

**依赖链**：射线的发射方向由缺口位置决定；射线每穿过一层嵌套矩形的边界，其颜色按固定映射切换一次；最终射线在画布上留下的是分段变色的线条，每段颜色编码了该段所处的嵌套深度。

输入中存在同心嵌套的矩形框和发射源，输出是从发射源出发的分段变色射线，每段颜色反映穿越了几层边界。

**输入结构**：约 18x18 网格，黑(0)背景。3~4 层同心嵌套的单像素宽矩形框，每层框颜色不同（外到内依次为绿(3)、蓝(1)、红(2)、黄(4)之一）。最外层框的某一边有一个 1 像素宽的缺口，缺口处放置一个灰(5)像素作为发射源。嵌套框之间间距 2~3 像素，框的边界框尺寸依次递减。每层框仅有完整四边，无其他缺口。生成约束：发射源所在边与缺口方向保证射线沿水平或垂直方向能依次穿过所有层。

**规则**：
1. 从灰(5)发射源出发，沿缺口朝内的基数方向（上/下/左/右）发射一条射线，射线延伸至网格边界。
2. 射线初始颜色为灰(5)。
3. 射线每穿过一层矩形框的边界像素时，从该边界像素的下一个像素开始，射线颜色切换为该层框的颜色。框边界像素本身不被射线覆盖（保持框原色）。
4. 射线穿出最内层后，颜色保持为最内层框的颜色直到网格边界。
5. 发射源像素保持灰(5)不变。
6. 输出仅改变射线路径上的背景像素，其余像素（框、发射源）保持不变。

**关键洞察**：射线的分段颜色不是预设的，而是由它实际穿越的每一层框的颜色动态决定——必须对比多个示例才能发现"射线颜色 = 最近穿越的框的颜色"这一规则，而非基于嵌套深度的固定映射。
