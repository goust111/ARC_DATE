## 新题 4：裂缝分离后两半各按自身宽度平移

**组合逻辑**：[擦除](裂缝标记线) → [沿短轴分裂](分为两半) → [平移](每半按自身边界框宽度向外平移)

**来源原语**：擦除(2faf500b)、裂缝标记线(2faf500b)、沿短轴分裂(2faf500b)、平移(64a7c07e)、按自身宽度平移(64a7c07e)、两侧等距分离(2faf500b)

**依赖链**：裂缝的方向决定了分裂轴向（短轴分裂）；分裂后每一半成为独立对象，其边界框宽度决定了该半的平移距离。与参考题 2faf500b（固定分离1像素）和 64a7c07e（整体对象按自身宽度右移）都不同——这里是分裂产生的碎片各自按各自的宽度向外分离。

擦除裂缝后将对象分为两半，每半按自己的边界框宽度向外平移远离裂缝。

**输入结构**：约 16x20 网格，黑(0)背景。包含 2~3 个互不接触的 8-连通前景对象，每个对象由主体色（蓝(1)或绿(3)）和裂缝标记色红(2)组成。每个对象的边界框为非正方形（宽>高 或 高>宽）。裂缝标记像素沿对象短轴方向形成一条完整切割线（如宽对象中有一列红像素从上到下贯穿对象）。裂缝将对象分为左右两半（或上下两半），两半的宽度可能不同。生成约束：每个对象的两半在各自平移后不与其他对象重叠，网格有足够空间容纳平移后的结果。

**规则**：
1. 对每个对象，擦除所有红(2)裂缝标记像素（替换为黑(0)背景）。
2. 裂缝方向沿对象边界框的短轴：宽对象的裂缝为垂直线，高对象的裂缝为水平线。
3. 擦除裂缝后，对象被分为两个独立的 8-连通分量（左半和右半，或上半和下半）。
4. 计算每个分量自身的边界框宽度 W（对于垂直裂缝的情况）或高度 H（对于水平裂缝的情况）。
5. 垂直裂缝：左半向左平移其自身宽度 W_left 个像素，右半向右平移其自身宽度 W_right 个像素。水平裂缝：上半向上平移其自身高度 H_top 个像素，下半向下平移其自身高度 H_bottom 个像素。
6. 超出网格边界的像素直接丢弃。

**关键洞察**：分离距离不是固定的，而是取决于每个碎片自身的尺寸——两半如果宽度不同则移动距离不同，必须对比多个示例中不对称对象的行为才能归纳出"按自身宽度平移"而非"按固定量分离"。
