## 新题 11：标记方向观察后连通分量按距离重力堆叠

**组合逻辑**：[标记指定观察方向](边界标记确定重力方向) → [平移/重力下落](连通分量按该方向堆叠) → [碰撞阻挡+按自身宽度间距](堆叠间距等于各自宽度)

**来源原语**：标记指定观察方向(f341894c)、边界标记(f341894c)、重力下落(afe3afe9)、连通分量(64a7c07e)、碰撞阻挡(05f2a901)、按自身宽度平移(64a7c07e)

**依赖链**：边界标记确定"重力"方向（标记在哪一边，重力就指向哪一边）；所有连通分量沿该方向下落；但堆叠时相邻两个对象之间的间距不是 0（紧贴），而是等于后到者自身的边界框在垂直于重力方向上的宽度。这意味着宽的对象距离前一个对象更远，窄的对象更近。

边界标记定义重力方向，连通分量沿该方向下落，相邻对象间距等于后方对象的横向宽度。

**输入结构**：约 14x18 网格，黑(0)背景。某一边（上/下/左/右之一）有一整行或整列的栗(9)像素作为边界标记。网格内散布 4~6 个互不接触的 8-连通单色对象，颜色从蓝(1)、红(2)、绿(3)中选取，每个对象 3~8 像素，形状不规则。对象之间有充足的空间。生成约束：对象在重力方向堆叠后（含间距）不超出网格边界。

**规则**：
1. 边界标记在顶边→重力方向向上；在底边→向下；在左边→向左；在右边→向右。
2. 所有前景连通分量沿重力方向移动。按其在重力方向上的原始坐标排序（靠近目标边的先处理）。
3. 第一个（最靠近目标边的）对象移动到紧贴边界标记（间距0，即对象边缘在标记旁边一行/列）。
4. 后续每个对象依次堆叠：该对象与前一个已放置对象之间的间距（空行/列数）= 该对象自身在垂直于重力方向上的边界框尺寸。例如重力向下时，间距 = 该对象的边界框宽度。
5. 对象水平（或垂直，取决于重力方向）位置保持不变。
6. 边界标记保留在输出中。

**关键洞察**：间距不是固定值，而是依赖于每个对象自身的"横向"尺寸——宽对象间距大，窄对象间距小。需要对比不同宽度对象的堆叠结果才能归纳出此规则，仅看紧贴型堆叠会得出错误答案。
</new_puzzle>
