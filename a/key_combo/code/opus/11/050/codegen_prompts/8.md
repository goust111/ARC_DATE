## 新题 8：杯形方向弹射后射线连线

**组合逻辑**：[弹射](内容像素沿尾刺方向射出) + [像素数守恒](弹射线段长度=内容像素数) + [连线](创新：同色弹射线段端点之间画连接线) + [遇前景终止](创新：连接线遇到其他弹射线段时终止)

**来源原语**：弹射/杯形框架/尾刺/内容像素/尾部朝向决定射出/像素数守恒(3dc255db), 射线延伸/遇前景终止(f8be4b64), 连线/共行或共列(e760a62e)

**依赖链**：杯形框架的尾刺方向决定弹射方向→内容像素数决定弹射线段长度→弹射完成后产生的线段端点位置取决于前两步→同色端点之间的连线需判断是否共行或共列→连线向对方延伸但遇到任何非背景像素（包括其他弹射线段）时终止。弹射结果改变了网格的前景分布，进而改变了连线可达的范围。

从杯形框架中弹射内容像素形成线段，然后在同色弹射线段的末端之间沿共享行或列画连接线，连接线遇阻停止。

**输入结构**：约 17x17 黑(0)背景网格。2~3 个杯形框架（空心框体，各用不同的边框色如灰(5)、青(8)），每个杯有一个尾刺（从杯体延伸出的 1~2 像素突起指示方向）和一个开口方向（与尾刺方向相反）。杯内有 2~4 个同色内容像素（颜色与边框色不同；同色框对应同色内容）。设计中同色内容出现在恰好两个杯中（如两个灰框杯各含蓝(1)内容，一个青框杯含绿(3)内容）。两个同色杯的尾刺方向使得弹射线段的末端恰好在同一行或同一列上。生成约束：同色弹射线段末端共享一行或一列，且之间存在至少一段空白可供连线。

**规则**：
1. 对每个杯形框架，识别其尾刺方向（尾刺所指基方向）。
2. 擦除杯内所有内容像素。
3. 从尾刺尖端向外（沿尾刺方向），画一条长度等于该杯内原内容像素数的同色线段。
4. 杯形框架本身（含尾刺）保留原色。
5. 弹射完成后，对每种内容颜色：若存在两条同色弹射线段，找到它们各自离对方更近的末端像素。
6. 若这两个末端像素共行，从各自末端向对方方向逐像素延伸同色像素，直到遇到任何非黑(0)像素或到达对方末端，不覆盖终点障碍物。若共列同理。若既不共行也不共列则不连线。
7. 连接线使用与弹射线段相同的颜色。

**关键洞察**：弹射线段的长度（由内容像素数决定）间接控制了末端位置，进而决定了连接线是否能画（是否共行/列）以及画多长（中间是否有其他弹射线段阻挡）。整道题的输出形态由杯内像素数、尾刺方向、杯的空间分布三者共同约束。
