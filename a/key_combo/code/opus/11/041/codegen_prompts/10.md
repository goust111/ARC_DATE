## 新题 10：折线连接路径上印章精灵体并按封闭区域计数裁剪

**组合逻辑**：[折线连接/曼哈顿路径](绘制 L 形路径) → [印章覆盖](沿路径等距放置精灵体) → [计数/封闭区域](统计路径形成的封闭区域数) → [裁剪](按封闭数裁剪输出边界)

**来源原语**：折线连接/曼哈顿路径/起点终点标记(a2fd1cf0), 印章覆盖/精灵体/锚点(36d67576/1b59e163), 计数/封闭区域(e3721c99), 裁剪(80214e03/458e3a53)

**依赖链**：起点终点确定 L 形路径几何 → 沿路径等距印章放置精灵体 → 精灵体与路径共同构成的图形可能围出封闭区域 → 封闭区域数决定输出的裁剪边距。整条链中，路径形状决定精灵体位置，精灵体位置决定封闭拓扑，封闭拓扑决定裁剪参数。

绘制 L 形路径并沿路径放置精灵体，根据形成的封闭区域数确定输出裁剪量。

**输入结构**：约 20x20 黑(0)背景网格。包含 1 个红(2)起点像素和 1 个绿(3)终点像素，分别位于不同行不同列。网格某角落有一个蓝(1)小精灵体模板（3x3 以内，4-连通，约 4~6 像素，中心有 1 个黄(4)锚点像素）。生成约束：红绿像素间曼哈顿距离 >= 8；L 路径（水平优先）上每隔 3 格放置一个精灵体时，精灵体不超出网格边界；路径加精灵体的组合至少形成 1 个封闭区域。

**规则**：
1. 从红(2)像素出发，沿其所在行水平移动到绿(3)像素所在列，再从该拐点垂直移动到绿(3)像素所在行（不含绿像素本身），用灰(5)绘制 L 形路径像素。
2. 沿 L 路径从起点开始，每隔 3 个路径像素（即第 1、4、7...个路径格），以该格为锚点位置印章放置蓝(1)精灵体副本（锚点对齐路径格，覆盖已有像素）。
3. 统计当前网格中由非黑像素完全围合的黑(0)封闭区域数量 N（封闭 = 该连通黑区域不触及网格边界）。
4. 输出为以 L 路径拐点为中心、向四周各扩展 N 格的正方形裁剪区域（边长 = 2N+1）。若裁剪框超出网格则取网格边界内的部分。
5. 输出内容包含裁剪区域内的所有像素（路径、精灵体、背景均保留原样）。

**关键洞察**：裁剪范围不是预先给定的，而是由路径上精灵体的放置结果"涌现"出的封闭区域数量动态决定的——同样的起止点配上不同形状的精灵体会产生不同数量的封闭区域，从而输出不同大小的裁剪结果。
