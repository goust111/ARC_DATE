## 新题 4：镜像差异提取为挖孔模板

**组合逻辑**：[镜像](精灵体水平翻转) → [差异提取](原始与镜像的不一致像素集合) → [挖孔](差异集作为模板挖孔于同色块) + [同色匹配]

**来源原语**：镜像(80214e03/c9680e90), 挖孔/模板图案(58f5dbd5), 单色块(58f5dbd5), 同色匹配(58f5dbd5)

**依赖链**：必须先对精灵体做镜像变换得到镜像版，然后将原版与镜像版逐像素比较提取差异区域，该差异区域才是挖孔的模板——差异像素的空间模式取决于精灵体的不对称程度，无法跳过镜像步骤直接确定。

通过精灵体与其镜像的像素差异生成挖孔模板，再将该模板应用于同色单色块。

**输入结构**：约 18x18 黑(0)背景网格。包含 3 个 5x5 单色实心方块（颜色分别为蓝(1)、红(2)、绿(3)），位于网格下半区，互不相邻。网格上半区有 3 个不规则精灵体（4-连通，约 6~10 像素），颜色分别与三个方块同色（蓝(1)、红(2)、绿(3)各一个）。每个精灵体在水平方向上不完全对称（即左右翻转后至少有 2 个像素位置不同）。精灵体的边界框不超过 5x5（与方块尺寸匹配）。生成约束：每个精灵体的边界框与其对应方块的尺寸兼容（精灵体边界框 <= 5x5）；差异像素集合居中放置于 5x5 方块时不超出方块范围。

**规则**：
1. 对每个彩色精灵体，以其边界框为参考做水平镜像翻转（左右翻转）。
2. 将翻转结果与原始精灵体在同一边界框坐标内逐像素比较：原始有色但镜像为空的位置标记为"差异像素"。
3. 将差异像素集合的模式居中对齐到同色的 5x5 方块上。
4. 在方块中，差异像素对应位置的颜色设为黑(0)（挖孔），其余方块像素保持原色。
5. 精灵体在输出中被擦除（设为黑(0)）。
6. 若差异像素集合为空（完全对称，不应出现，生成时保证不对称），该方块保持不变。

**关键洞察**：挖孔模板不是直接给出的图案，而是通过精灵体与其自身镜像的"不对称度"隐式编码的——对称性越低的精灵体产生越多的孔洞，求解者必须自行执行镜像比较才能推导出模板。
