## 新题 2：碎片补全后按孔洞数查表重涂色

**组合逻辑**：[补全](碎片锚定补全为完整模板) → [计数](统计每个补全体的封闭孔洞数) → [查表映射](孔洞数→颜色图例) + [重涂色]

**来源原语**：补全/碎片/碎片锚定放置位(fd096ab6), 模板精灵体(fd096ab6), 计数(e3721c99/7039b2d7), 封闭区域(e3721c99), 颜色图例/孔洞数映射颜色(e3721c99), 重涂色(9caf5b84)

**依赖链**：碎片必须先补全为完整模板才能计算孔洞数（碎片本身无封闭区域）；孔洞数决定查表结果；查表结果决定重涂色的目标颜色。三步之间有严格的信息依赖。

将散落碎片补全为完整模板，再根据每个完整体的孔洞拓扑结构查表重涂色。

**输入结构**：约 25x25 黑(0)背景网格。左下角有一个灰(5)的完整模板形状（8-连通、约 12~18 像素，内部含 1~3 个由黑(0)构成的封闭孔洞，模板本身不规则但连通）。网格右上区域有一个颜色图例区：2~3 个小型彩色形状（如红(2)、蓝(1)、绿(3)），每个形状为 2x2 至 3x3 的连通区域，分别含有不同数量的 1 像素封闭孔洞（0 个、1 个、2 个），作为"孔洞数→颜色"的映射表。网格中央散布着 4~6 组碎片，每组碎片用同一种非灰非图例的颜色（如黄(4)、橙(7)、栗(9)、品红(6)等），每组含 2~4 个像素，这些像素是灰(5)模板在某个平移位置下的子集。不同组碎片对应的平移位置互不重叠。生成约束：每组碎片唯一确定一个模板平移位置；补全后各模板副本互不重叠且不与图例、原始模板重叠。

**规则**：
1. 识别灰(5)的连通区域为模板 mask。
2. 对每组同色碎片，找到唯一的平移位置使得模板 mask 平移后覆盖该组所有碎片像素。
3. 在该平移位置绘制完整模板副本（用该组碎片的颜色）。
4. 对每个补全后的模板副本，计算其内部封闭孔洞数（被该颜色像素完全包围的黑(0)连通区域，不触及该副本边界框外部）。
5. 在图例区中找到孔洞数相同的图例形状，读取其颜色。
6. 将该模板副本的所有像素重涂为图例指示的颜色。
7. 灰(5)原始模板保持不变；图例保持不变。

**关键洞察**：碎片本身没有封闭区域（像素太少无法围合），只有补全后才能形成孔洞——但不同平移位置可能因为与网格边界的距离关系导致"看似封闭"的区域实际连通到外部，因此孔洞计数必须基于补全后的实际几何形状而非模板本身的固有孔洞数。
