## 新题 7：分区计数生成画布后按频率排序铺色

**组合逻辑**：[计数/分区数决定尺寸](统计分区数确定输出尺寸) → [生成网格](创建空白画布) → [频率排序 + 重涂色](按输入中各色频率从高到低依次填充输出行)

**来源原语**：计数/生成网格/分区数决定尺寸(7039b2d7), 分隔线(780d0b14/7039b2d7), 频率排序(9caf5b84), 重涂色(9caf5b84)

**依赖链**：必须先数清分隔线划分出的行区域数和列区域数才能确定输出网格尺寸；然后统计输入中各非分隔色的频率排名；输出网格的行数恰好等于非分隔色的种类数（由分区数保证），每行填一种颜色按频率从高到低排列。分区计数同时决定了画布尺寸和需要排列多少种颜色。

统计分隔线划分的分区数作为输出尺寸，然后按输入各色出现频率从高到低逐行填充纯色。

**输入结构**：约 15x15 网格。灰(5)完整行和完整列将网格分割为若干矩形区域（行分区数 R，列分区数 C，R 和 C 在 3~5 之间）。每个矩形区域内散布着单一颜色的非黑非灰像素（颜色从蓝(1)、红(2)、绿(3)、黄(4)、橙(7)中选取），不同区域可能使用相同颜色。共有 R 种不同颜色出现在输入中（生成约束保证）。背景为黑(0)。生成约束：恰好有 R 种不同的非黑非灰颜色出现；各颜色的总像素数互不相同（保证频率排名无平局）。

**规则**：
1. 找到所有灰(5)的完整行和完整列，计算行分区数 R（灰行之间及边界间的间隔数）和列分区数 C。
2. 输出网格尺寸为 R 行 x C 列。
3. 统计输入中所有非黑(0)非灰(5)像素的颜色及各色的总像素数。
4. 按像素数从多到少排列颜色，得到颜色序列 [c1, c2, ..., cR]。
5. 输出网格的第 i 行（从上到下，i=1 为最上行）全部填充颜色 ci。

**关键洞察**：分区的空间结构（哪个区域用什么颜色、区域大小差异）只是频率信息的载体——输出完全抛弃了空间布局，仅保留颜色的全局统计排名。列分区数 C 决定输出宽度但不携带颜色信息，是一个纯几何参数。
