## 新题 5：标记滑动轨迹形成条纹种子，条纹周期由滑动距离决定

**组合逻辑**：[滑动](创新：滑动不只是移动一步，而是移动到目标位置，沿途留下轨迹) → [平铺/条纹填充](创新：轨迹的方向和长度成为条纹的方向和周期参数)

**来源原语**：滑动(slide) + 标记像素(marker_pixel) + 目标像素(target_pixel) + 共线对齐(collinear_aligned) + 趋近目标(approach_target) 来自 dc433765；平铺(tiling) + 填充(fill) + 种子像素(seed_pixel) + 条纹(stripe) + 种子定条纹周期(seed_sets_stripe_period) + 阵列排布(array_layout) 来自 0a938d79

**依赖链**：标记像素沿共线方向滑动到目标像素 → 滑动路径成为一条有色线段（轨迹种子） → 轨迹方向决定条纹方向（正交于轨迹） → 轨迹长度（滑动距离）决定条纹重复周期 → 用标记色和目标色交替填充条纹。删除滑动步骤则条纹参数未知；删除条纹步骤则滑动无后续效果。

每对标记-目标像素产生一条滑动轨迹，轨迹方向的正交方向上按滑动距离为周期绘制双色交替条纹，覆盖整个网格对应区域。

**输入结构**：约 16x16 的网格，背景为黑(0)。网格中有 2 对标记-目标像素对。第一对：绿(3)标记和黄(4)目标，位于同一行（水平共线），间隔 3~5 个像素。第二对：蓝(1)标记和红(2)目标，位于同一列（垂直共线），间隔 3~5 个像素。两对像素的行列范围不重叠（第一对占据网格上半部分，第二对占据网格下半部分），由一条灰(5)水平分隔线（贯穿整行）隔开。生成约束：两对像素分别在分隔线上方和下方；每对的标记和目标间隔不同（确保两组条纹周期不同）。

**规则**：
1. 对每一对标记-目标像素，将标记像素沿共线方向滑动到目标像素的相邻位置（距目标 1 格处停止），沿途所有经过的背景像素涂为标记颜色，形成轨迹线段。原标记位置也保留标记颜色。
2. 计算滑动距离 D（标记原位置到停止位置的像素数，含端点）。
3. 在该对所属的半区（分隔线上方或下方的所有行/列）中，沿垂直于轨迹方向每隔 D 个像素绘制一条贯穿该半区的完整条纹。条纹交替使用标记颜色和目标颜色：第一条（轨迹所在行/列）为标记颜色，距离 D 的下一条为目标颜色，再距离 D 为标记颜色，依此交替。
4. 条纹覆盖对应半区内的所有黑(0)背景像素。若条纹与轨迹线段重叠，保留轨迹线段颜色（标记颜色优先）。
5. 灰(5)分隔线、目标像素保持原色不变。

**关键洞察**：条纹的周期不是由两个种子的空间间距直接给出的（源题做法），而是由标记滑向目标后实际走过的步数决定——必须先模拟滑动才能知道周期。
