## 新题 1：射线铸造开门与最短走廊连通

**组合逻辑**：[射线延伸](创新：射线命中处不是印标记，而是擦除墙壁形成门洞) → [擦除](创新：擦除对象由射线命中位置动态决定) → [连线/最小生成树](已有原语，但连通路径受限于动态生成的门洞)

**来源原语**：射线延伸(ray_extend) + 命中处印标记(stamp_at_hit) 来自 ecdecbb3；擦除(erase) + 空心矩形(hollow_rectangle) + 走廊(corridor) + 最小生成树连接(min_spanning_tree) 来自 b9630600；控制像素(control_pixel) + 投射(perpendicular_cast) 来自 ecdecbb3

**依赖链**：控制像素的射线投射决定了门洞在哪面墙上打开 → 门洞的存在约束了走廊的可用连接点 → 最小生成树在受限门洞上规划连通网络。删除射线步骤则门洞位置未知；删除连通步骤则门洞无意义。

从控制像素出发铸造射线，在命中的空心矩形墙壁上开出门洞，再通过这些门洞用最短走廊将所有矩形连成一棵生成树。

**输入结构**：约 22x22 的网格，背景为黑(0)。网格中有 4~5 个蓝(1) 一像素厚的空心矩形框，每个框的外边长在 4~7 像素之间，框与框之间至少间隔 3 个背景像素，互不接触。每个矩形框的某一条外壁的外侧（紧邻墙壁外一格）有恰好一个红(2)控制像素。每个控制像素仅紧邻一条墙壁（位于该墙壁的正交外侧）。生成约束：每个控制像素沿其朝外方向（垂直于所邻墙壁、远离所属框的方向）投射射线时，必定命中另一个矩形框的墙壁（不会射到网格边缘外或自身框体）。

**规则**：
1. 对每个红(2)控制像素，确定其紧邻的蓝(1)墙壁段及朝外方向（垂直于该墙壁、背离所属框的方向）。
2. 沿朝外方向逐格投射射线，直到命中另一个蓝(1)矩形框的墙壁像素。射线经过的背景像素暂不改变。
3. 在命中墙壁上，以命中点为中心擦除连续 3 个墙壁像素（将其变为黑(0)背景），形成一个 3 像素宽的门洞。若命中点距墙壁端点不足 1 格导致无法居中放置 3 像素门洞，则门洞向墙壁内侧偏移至刚好放下 3 像素。
4. 擦除该红(2)控制像素（变为黑(0)）。
5. 所有门洞开完后，将所有矩形框视为节点，两框之间的距离定义为"经由它们之间的门洞所需走廊长度"（门洞中心到门洞中心的曼哈顿距离）。仅当两框之间存在直接门洞对（一个框被射线开门、该射线来自另一个框的控制像素）时，才算有直接连边。
6. 在这些直接连边上选择最小生成树（若权重相同则优先选择连边中门洞中心行坐标较小的，仍相同则选列坐标较小的）。
7. 对最小生成树的每条边，沿两个门洞中心之间的正交路径绘制绿(3)走廊像素（先水平后垂直），走廊经过门洞本身时也涂绿(3)。走廊不覆盖蓝(1)墙壁像素。

**关键洞察**：门洞不是预设的，而是由射线动态铸造在其他框的墙壁上；走廊的可行拓扑完全由射线几何决定，必须先完成射线计算才能规划连通。
