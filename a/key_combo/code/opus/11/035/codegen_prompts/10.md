## 新题 10：周期瓦片补全后残留标记定位碎片锚点，碎片滑入锚点拼合矩形

**组合逻辑**：[补全](已有原语) → [标记识别](创新：补全操作的副产品——无法被周期解释的像素——成为下一步操作的锚点) → [滑动/移动 + 互补拼合](已有原语，但目标位置由补全残留决定)

**来源原语**：补全(completion) + 周期瓦片(periodic_tile) + 行列周期(row_col_period) + 标记为缺失值(markers_missing_val) 来自 f823c43c；移动(move) + 互补拼合(complement_fit) + 碎片(fragment) + 锚定物体(anchor_object) + 同色碎片拼成矩形(same_color_join) 来自 fe45cba4；滑动(slide) + 共线对齐(collinear_aligned) 来自 dc433765

**依赖链**：品红像素既可能是周期瓦片的缺失值也可能是碎片锚点标记 → 先推断周期瓦片并补全所有可被周期解释的品红像素 → 补全后仍为品红的像素就是锚点标记 → 锚点标记的位置指示碎片应滑入的目标位置 → 碎片沿共线方向滑动到锚点处与同色锚定物体互补拼合成矩形。删除补全步骤则无法区分缺失值和锚点；删除滑动拼合步骤则锚点无意义。

补全周期瓦片后，无法被周期解释的品红像素暴露为碎片锚点，碎片沿共线方向滑入锚点位置与同色物体拼合成完整矩形。

**输入结构**：约 18x18 的网格。网格大部分区域由两种颜色（蓝(1)和灰(5)）构成的周期性棋盘状图案覆盖（最小周期瓦片为 2x2 或 3x2）。若干品红(6)像素散布在网格中，其中大部分替换了本应是蓝(1)或灰(5)的周期位置（即周期缺失值）。此外，网格中有 2 对红(2)色的 4-连通物体：每对中一个物体触及网格底边（碎片），另一个不触底边（锚定物体）。每对的碎片和锚定物体在同一列范围内（垂直共线），可通过垂直平移互补拼合成一个 3x3 或 4x3 的实心红(2)矩形。在每个碎片与其配对锚定物体之间的垂直路径上，恰好有 1~2 个品红(6)像素不在任何合法的周期位置上（即使推断出周期后这些像素也无法被周期颜色解释）——这些就是锚点标记。生成约束：锚点标记像素所在的行坐标恰好标示了碎片滑入后的目标行（碎片顶边对齐到该标记行时，碎片与锚定物体恰好互补拼合）；所有周期缺失值品红像素都可被最小周期瓦片唯一恢复；两对红(2)物体互不干扰。

**规则**：
1. 忽略红(2)像素和品红(6)像素，从剩余的蓝(1)和灰(5)像素推断最小面积的行列周期瓦片。
2. 对每个品红(6)像素，检查其网格坐标在周期瓦片中对应的颜色：若该坐标对应蓝(1)或灰(5)，则该品红像素是缺失值，用对应颜色替换之。
3. 补全后仍为品红(6)的像素即为锚点标记。
4. 对每对红(2)碎片和锚定物体（同一列范围内、碎片触底边、锚定物体不触底边）：
   - 找到该对之间路径上的锚点标记（品红(6)像素，位于碎片和锚定物体之间的列范围内）。
   - 将碎片从底边向上垂直滑动，使碎片顶边行对齐到锚点标记所在行。
   - 清除碎片原位置像素为该位置补全后的周期颜色（即恢复为周期瓦片应有的颜色）。
   - 在新位置绘制碎片的红(2)像素。此时碎片与锚定物体恰好互补拼合成一个实心红(2)矩形。
5. 擦除所有锚点标记像素（品红(6)），替换为该位置周期瓦片的应有颜色。

**关键洞察**：品红像素身兼两职——大部分是周期瓦片的遮蔽噪声，少数是碎片操作的定位信号——求解者必须先完成周期推断才能将两种品红像素区分开来，进而找到正确的滑动目标。
