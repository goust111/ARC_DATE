## 新题 3：碎片互补拼合生成模板，变换匹配后印章覆盖

**组合逻辑**：[移动/互补拼合](已有原语) → [旋转/镜像 + 模式匹配](创新：匹配对象不是预设的源精灵体标记掩码，而是拼合后才出现的完整图案) → [印章覆盖](创新：印章内容由拼合结果动态生成)

**来源原语**：移动(move) + 互补拼合(complement_fit) + 碎片(fragment) + 锚定物体(anchor_object) + 碎片触边锚不触边(frag_edge_anchor) 来自 fe45cba4；旋转(rotate) + 镜像(mirror) + 模式匹配(pattern_match) + 掩码变换匹配则补(transform_match_fill) 来自 7df24a62；印章覆盖(stamp_overlay) 来自 f21745ec/ecdecbb3

**依赖链**：两个同色碎片必须先拼合成完整矩形 → 拼合后的矩形图案成为印章模板 → 网格其他位置的标记像素群如果与模板的某个旋转/镜像变换的非背景像素位置完全吻合，则在该位置盖章（用模板的填充色填充对应的背景位置）。删除拼合步骤则模板未知；删除匹配步骤则不知道往哪里盖章。

从左边缘碎片移动到锚定碎片处完成矩形拼合，拼合后的矩形图案作为印章模板，在网格中寻找与模板某个刚体变换的标记掩码匹配的位置并盖章填充。

**输入结构**：约 20x20 的网格，背景为黑(0)。网格中有一组蓝(1)像素分成两个 4-连通物体：一个触及左边缘（碎片），一个不触左边缘（锚定物体），二者可通过平移互补拼合成一个实心矩形（约 3x4 至 4x5 大小）。该矩形内部分布着若干红(2)标记像素（嵌在蓝(1)填充色中，占矩形面积的 20%~40%），这些标记像素构成一个不对称图案（在 8 种刚体变换下互不相同）。此外，网格其他区域（远离碎片和锚定物体）散布着 2~3 组红(2)像素群，每组恰好是矩形模板中红(2)标记掩码的某个刚体变换副本（旋转 0/90/180/270 度或镜像后的某一种），且对应矩形范围内的其余位置全为黑(0)背景。还有 1~2 个孤立的红(2)干扰像素不构成任何完整的变换匹配。生成约束：各标记群互不重叠，且与碎片/锚定物体不重叠。

**规则**：
1. 找到蓝(1)颜色的两个 4-连通物体，其中触左边缘的为碎片，不触左边缘的为锚定物体。
2. 将碎片水平平移至与锚定物体互补拼合形成一个填满蓝(1)的实心矩形。清除碎片原位置像素为黑(0)。
3. 记录拼合后矩形中红(2)标记像素的相对位置，作为模板标记掩码。
4. 枚举模板标记掩码的全部 8 种刚体变换（4 种旋转 x 是否水平镜像）。
5. 在网格中搜索所有候选位置：某个变换后的标记掩码恰好覆盖一组红(2)像素，且对应矩形范围内的其余位置全为黑(0)背景。
6. 对每个匹配位置，将对应矩形范围内的黑(0)背景像素涂为蓝(1)（即用填充色补齐矩形），保留红(2)标记像素不变。
7. 不匹配任何变换的孤立红(2)像素保持不变。

**关键洞察**：印章的模板不是直接给出的，而是通过碎片互补拼合才"合成"出来的——求解者必须先完成空间拼合才能获得匹配模式。
