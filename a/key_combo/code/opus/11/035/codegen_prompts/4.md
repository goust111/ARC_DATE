## 新题 4：颜色计数控制射线长度，射线轨迹形成轮廓围合

**组合逻辑**：[计数](已有原语) → [射线延伸](创新：射线不延伸到命中障碍物为止，而是延伸固定步数，步数由计数结果决定) → [洪水填充](创新：填充区域由射线轨迹围合而成，非预设轮廓)

**来源原语**：计数(counting) + 多色方块(multicolor_square) + 颜色数决定高度(color_count_height) 来自 fcc82909；射线延伸(ray_extend) + 控制像素(control_pixel) + 投射(perpendicular_cast) 来自 ecdecbb3；洪水填充(flood_fill) + 封闭背景区域(enclosed_bg_region) + 轮廓围合(contour_enclosure) + 小区域被填充(small_regions_filled) 来自 753ea09b

**依赖链**：多色方块中不同颜色的数量 → 决定从相邻控制像素射出的射线长度 → 射线轨迹在网格上绘制线段 → 多条线段围合出封闭区域 → 封闭区域被填充。删除计数步骤则射线长度未知；删除射线步骤则无围合轮廓；删除填充步骤则射线无用途。

从多色方块中计数不同颜色得到数值，该数值控制从相邻控制像素射出的十字射线长度，射线轨迹围合出的封闭区域被填充为方块中面积最大的颜色。

**输入结构**：约 20x20 的网格，背景为黑(0)。网格中有 3~4 个 2x2 的多色方块，每个方块由 2~4 种非黑颜色填充（颜色取自蓝(1)、红(2)、绿(3)、黄(4)中的若干种）。每个方块的 4-邻域外侧（上下左右各一格）恰好有一个灰(5)控制像素，且该控制像素不与其他方块或控制像素相邻。多色方块之间间距至少 6 个像素。生成约束：每个控制像素沿其四个正交方向中远离所属方块的那个方向，按计数结果的步数延伸射线后，至少有两个不同方块的射线轨迹会在某处构成闭合区域（多段射线首尾相连或交叉围合）。

**规则**：
1. 对每个 2x2 多色方块，计数其中不同非黑颜色的种数 K（K 在 2~4 之间）。
2. 找到该方块 4-邻域外的灰(5)控制像素，确定其远离方块的方向 D。
3. 从控制像素出发，沿方向 D 绘制恰好 K 个像素长的橙(7)射线段（包括控制像素位置本身变为橙(7)，再沿 D 方向延伸 K-1 格，共 K 格橙色）。若射线超出网格则在边缘截断。
4. 所有射线绘制完成后，将橙(7)射线像素视为障碍，对黑(0)背景做 4-连通区域划分。
5. 对每个不接触网格边缘的封闭背景区域：该区域被填充为品红(6)。
6. 多色方块、橙(7)射线段均保持不变。接触网格边缘的背景区域保持黑(0)。

**关键洞察**：射线长度不是固定的也不是延伸到碰撞，而是由关联方块的颜色多样性编码——颜色越多射线越长，围合面积越大。求解者必须先完成计数才能确定几何形状。
