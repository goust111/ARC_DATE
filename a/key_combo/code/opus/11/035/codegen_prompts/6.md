## 新题 6：十字周期延伸构建栅栏墙，墙中缺口由尺寸匹配的空心框标定

**组合逻辑**：[平铺/周期延伸](已有原语，但创新：延伸结果形成功能性墙壁) + [尺寸匹配](创新：匹配对象从矩形框变为墙壁间距) → [路径绘制](已有原语，但路径受动态生成的墙壁和缺口约束)

**来源原语**：平铺(tile) + 十字图案(cross_pattern) + 周期序列(periodic_sequence) + 中心行列种子(center_seed) + 周期性延伸(periodic_extension) 来自 e21d9049；尺寸匹配(size_match) + 空心矩形(hollow_rect) 来自 f21745ec；寻路(pathfinding) + 路径绘制(path_drawing) + 门段(door_segment) + 穿越门中心(through_door_center) + 走廊正交路径(corridor_ortho_path) 来自 7e576d6e

**依赖链**：十字图案周期延伸后，其中心行和中心列的重复形成平行的水平和垂直色带（即栅栏墙壁） → 散布的空心矩形框的内部宽度或高度恰好与相邻两面墙壁间距匹配 → 匹配墙壁上框所在的列/行位置出现缺口（门洞） → 从起点到终点的正交路径必须穿过这些门洞。删除周期延伸则墙壁不存在；删除尺寸匹配则不知道哪些框标定门洞；删除寻路则结构无意义。

十字图案周期延伸形成平行栅栏墙壁，空心矩形框按尺寸匹配标定墙壁上的门洞位置，然后绘制从起点到终点穿越所有门洞的正交路径。

**输入结构**：约 21x21 的网格，背景为黑(0)。网格中央有一个由多色像素（蓝(1)和红(2)交替）组成的十字图案（约 5x5 像素，中心行全蓝(1)、中心列全红(2)、交叉中心为蓝(1)），其中心行和中心列各有一个明确的颜色序列。网格中另有 3~4 个黄(4)一像素厚空心矩形框（内部宽度或高度各不相同，范围 2~5 像素）。网格左上角有一个绿(3)起点像素，右下角有一个绿(3)终点像素。生成约束：十字图案周期延伸后形成的蓝(1)水平色带和红(2)垂直色带恰好产生若干平行墙壁段；空心矩形框中内部高度与相邻水平墙壁间距相等的框标定垂直墙壁门洞位置，内部宽度与相邻垂直墙壁间距相等的框标定水平墙壁门洞位置；至少存在一条从起点到终点穿越所有必要门洞的正交路径。

**规则**：
1. 裁剪十字图案，找到其中心行序列和中心列序列。
2. 将中心行序列沿水平方向周期重复、沿垂直方向在中心行的周期位置复制，形成水平色带（蓝(1)全行条纹）。同理将中心列序列形成垂直色带（红(2)全列条纹）。这些色带叠加到输出网格上（交叉处蓝(1)覆盖红(2)）。
3. 对每个黄(4)空心矩形框：计算其内部高度 H 和内部宽度 W。
   - 若 H 等于某对相邻水平色带之间的间距，则该框标定一个垂直色带上的门洞：在距框的列坐标中心最近的垂直色带上，擦除与该框同行范围的色带像素（形成 H 像素高的门洞）。
   - 若 W 等于某对相邻垂直色带之间的间距，则该框标定一个水平色带上的门洞：在距框的行坐标中心最近的水平色带上，擦除与该框同列范围的色带像素（形成 W 像素宽的门洞）。
4. 擦除所有黄(4)框像素（变为黑(0)）。
5. 从绿(3)起点到绿(3)终点，沿正交方向（先水平再垂直交替转弯）穿过每面墙壁的门洞中心，绘制橙(7)路径像素。路径在每个走廊（两面墙壁之间的区域）中走直线到下一面墙的门洞中心。起点和终点保持绿(3)。

**关键洞察**：墙壁是由十字图案的周期延伸"生长"出来的，而门洞位置则由空心框的内部尺寸与墙壁间距的匹配关系编码——求解者必须同时理解周期结构和尺寸匹配才能定位门洞。
