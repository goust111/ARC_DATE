## 新题 9：控制标记重涂区域后形成平行墙壁，种子像素在墙间生成条纹

**组合逻辑**：[重涂色](已有原语) + [擦除](已有原语) → [填充/条纹生成](创新：条纹范围和方向由重涂后形成的墙壁几何决定) ← [标记形状决定操作](已有原语，决定重涂方向) + [种子定条纹周期](已有原语，但种子位置受重涂结果约束)

**来源原语**：重涂色(recolor) + 擦除(erase) + 控制标记(control_marker) + 单色区域(monochrome_region) + 标记指向目标(marker_points_to_target) + 标记形状决定操作(marker_shape_determines_operation) 来自 21897d95；填充(fill) + 种子像素(seed_pixel) + 条纹(stripe) + 种子定条纹周期(seed_sets_stripe_period) + 阵列排布(array_layout) 来自 0a938d79

**依赖链**：T 形控制标记的茎指向目标区域 → 目标区域被重涂为源区域颜色（形成新的单色条带/墙壁） → 重涂后的墙壁将网格分割成走廊 → 走廊内的种子像素对定义条纹方向和周期 → 条纹填充走廊空间。删除重涂步骤则墙壁拓扑不确定，种子不知在哪个走廊中；删除条纹步骤则重涂只是换色无几何后果。

T 形控制标记驱动区域重涂，重涂后的区域扩展为平行墙壁，墙壁间走廊中的种子像素对产生交替条纹填充。

**输入结构**：约 18x18 的网格。网格由 4~5 个大型单色矩形区域镶嵌而成（颜色取自蓝(1)、红(2)、灰(5)、青(8)），区域之间以 1 像素缝隙或直接邻接。其中 2 个区域边界上有栗(9)色的 T 形控制标记（3 像素的横杆 + 1 像素的茎），茎指向相邻的目标区域。在网格中另有 2 对非黑非区域色的种子像素：每对由绿(3)和黄(4)各一个像素组成，位于同一行或同一列，位于某个大型区域内部（非边界），两个种子之间间隔 2~4 像素。生成约束：T 形标记的重涂操作会使被重涂的区域与某个已有同色区域融合，形成贯穿若干行或列的连续色带（即墙壁效果）；重涂完成后，种子像素对所在的走廊（两面墙壁之间的条形空间）是明确的矩形区域。

**规则**：
1. 对每个栗(9)色 T 形控制标记：茎的方向指向一个目标区域。标记横杆背后（茎的反方向）两个对角位置落在源区域中。
2. 将目标区域的所有像素重涂为源区域的原始颜色。
3. 将控制标记的所有栗(9)像素重涂为源区域的颜色（标记融入源区域）。
4. 重涂完成后，识别由同色连续区域形成的平行墙壁结构（贯穿网格大部分行或列的连续色带，宽度至少 2 像素）。
5. 两面平行墙壁之间的背景区域为走廊。对走廊内的每对种子像素（绿(3)和黄(4)）：
   - 若走廊是水平走廊（上下被墙壁夹），则以两种子的列间距为周期，在走廊范围内绘制垂直条纹：经过绿(3)种子列的条纹为绿(3)，经过黄(4)种子列的条纹为黄(4)，以此周期交替覆盖走廊内所有像素。
   - 若走廊是垂直走廊（左右被墙壁夹），则以两种子的行间距为周期，在走廊范围内绘制水平条纹，同理交替。
6. 种子像素被条纹覆盖。墙壁和非走廊区域保持重涂后的颜色不变。

**关键洞察**：墙壁不是输入中预设的，而是控制标记驱动的重涂操作"焊接"出的——求解者必须先模拟标记操作才能知道走廊在哪里，然后才能在正确的走廊中生成正确方向的条纹。
