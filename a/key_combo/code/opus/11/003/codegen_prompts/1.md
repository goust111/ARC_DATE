## 新题 1：对称性筛选决定滑动方向与重涂色

**组合逻辑**：[对称/symmetry](创新：从选择输出物变为决定是否重涂色) + [重涂色/recolor](创新：对称性判断结果驱动颜色翻转) + [滑动/slide](已有) + [碰撞停止/collision_stop](已有)

**来源原语**：对称/symmetry、对称图案选取/symmetric_selected（P17 d56f2372）；滑动/translate、墙壁列/wall_column、同色物体朝同色墙/same_color_wall、碰撞停止/collision_stop、近者优先不重叠/nearest_first（P10 f0100645）；重涂色/recolor（P7 b94a9452、P13 7d1f7ee8）；精灵体/sprite（P12 39a8645d）

**依赖链**：对称性测试决定每个精灵体是否被重涂色 → 重涂色改变精灵体颜色 → 颜色决定滑动方向（匹配哪面墙） → 滑动顺序和碰撞决定最终位置。删除对称测试则无法确定哪些精灵体要变色；删除重涂色则所有精灵体保持原色、仅有一面墙有目标；删除滑动则无空间变换。

在一个有双色墙壁列的网格中，对每个小精灵体做对称性判断：对称者保持原色滑向同色墙，不对称者互换为另一面墙的颜色后滑向该墙。

**输入结构**：约 18x18 的黑(0)背景网格。左列全为蓝(1)，右列全为红(2)，作为两面墙壁列。网格内部散布 4~6 个单色小精灵体（每个为 4-连通、3~6 像素、边界框不超过 3x3 的不规则图形），颜色为蓝(1)或红(2)。每个精灵体互不相邻（边界框间至少间隔 1 列背景）。生成约束：蓝精灵体和红精灵体各至少 2 个；其中至少各有一个具有垂直镜像对称性、至少各有一个不具有垂直镜像对称性。

**规则**：
1. 识别左列蓝(1)墙和右列红(2)墙。
2. 对每个精灵体，裁剪到其边界框，判断该裁剪图案是否关于垂直中轴左右镜像对称。
3. 对称的精灵体保持原色不变。不对称的精灵体做双色互换：蓝(1)像素全部变为红(2)，红(2)像素全部变为蓝(1)。
4. 互换后，所有精灵体按照距离其目标墙的远近排序（近者优先）。目标墙 = 与精灵体当前颜色相同的墙（蓝精灵体目标为左墙，红精灵体目标为右墙）。
5. 按上述顺序依次将每个精灵体水平滑向其目标墙，保持行位置不变，直到精灵体的最近像素紧贴墙壁列或紧贴已经抵达的另一个精灵体，不可重叠。
6. 两面墙壁列保持不变。

**关键洞察**：对称性不是用来选择"输出哪个精灵体"，而是用来反转精灵体颜色——这改变了它的滑动方向，使得原本应该向左滑的精灵体在不对称时反而向右滑。需要对比多个示例才能发现"不对称 → 互换颜色"这一隐蔽规则。
