## 新题 4：镜像恢复遮挡区域后将恢复图案作为印章模板

**组合逻辑**：[镜像/mirror](已有) + [反射恢复遮挡/reflection_recovers](创新：恢复结果不是最终输出，而是中间模板) → [印章覆盖/stamp](已有) + [特定标记触发镜像/marker_triggers_mirror](已有，但作用于恢复出的模板)

**来源原语**：镜像/mirror、遮挡块/occluder、被遮区域/occluded_region、镜像对称/mirror_symmetry、反射恢复遮挡/reflection_recovers（P18 dc0a314f）；印章覆盖/stamp、标记像素/marker_pixel、颜色配对/color_pairing、标记色匹配目标位/marker_color_matches_dest、特定标记触发镜像/marker_triggers_mirror（P6 3e980e27）

**依赖链**：镜像对称恢复被遮挡的图案 → 恢复出的图案成为印章模板（这在 P18 中不存在——P18 的恢复结果就是最终输出） → 散落的绿(3)/红(2)标记像素指定印章目的地 → 绿(3)标记处原样印章、红(2)标记处左右镜像后印章。删除恢复步骤则无模板可印章；删除印章则恢复结果仅是一个局部碎片、无法生成完整输出；删除颜色触发镜像则无法区分两种印章方式。

利用场景的镜像对称性恢复被遮挡的图案，然后将该恢复图案作为印章模板，根据标记像素颜色决定是否镜像后印章到各个标记位置。

**输入结构**：约 20x20 的黑(0)背景网格。网格中存在一个关于垂直中轴镜像对称的多色图案（使用蓝(1)、黄(4)、灰(5)等颜色，占据网格中央约 10x10 区域）。图案内有一个 3x3 至 4x4 的实心栗(9)色正方形遮挡块，覆盖了部分图案。遮挡块不跨越对称轴（即其镜像位置处的图案完好可见）。在图案外部（距离图案边界至少 2 像素），散布 2~4 个孤立的单像素标记，颜色为绿(3)或红(2)。生成约束：绿(3)和红(2)标记各至少 1 个；标记之间间距足够大，使得以标记为中心放置恢复图案后各副本不重叠；遮挡块下方的图案至少包含 2 种颜色的像素。

**规则**：
1. 识别栗(9)色实心正方形为遮挡块。
2. 找到遮挡块边界框关于场景垂直中轴的镜像区域。将镜像区域的内容反射回遮挡块位置，恢复被遮挡的图案碎片。恢复出的碎片即为"印章模板"，尺寸等于遮挡块尺寸。
3. 清除整个对称图案和遮挡块，保留黑(0)背景和所有标记像素。
4. 对每个绿(3)标记像素：以该标记所在位置为模板的左上角，将印章模板原样绘制到画布上。
5. 对每个红(2)标记像素：将印章模板做左右镜像后，以该标记所在位置为模板的左上角绘制到画布上。
6. 标记像素本身被印章内容覆盖（若印章范围覆盖了标记位置）。若多个印章范围重叠（不应出现，由生成约束保证），后绘制的覆盖先绘制的。

**关键洞察**：遮挡恢复的目的不是修复画面——恢复出的碎片被从原场景中"取出"，变成了一个可复用的印章模板。需要对比多个示例才能发现"绿=原样、红=镜像"的颜色-操作映射。

    split_type: horizontal (top/bottom) or vertical (left/right), roughly equal mix
    colors: one region is blue(1), the other is teal(8); each fills its half completely
    ratio: each half gets 30-70% of the grid extent along the split axis
  red_objects:
    count: 4-5 per grid; at least 2 per carrier color
    shape: solid rectangles (no holes), bbox 1x1 to 4x2; typical sizes 1x1,1x2,2x1,2x2,2x3,2x4
    carrier: each red object is fully embedded in exactly one carrier region (blue or teal)
    adjacency: all 4-neighbors of every red pixel are either red or the carrier color (never the other color)
    no_row_overlap: red objects within the same carrier region never share rows [observed]
    gap: each object has gap>=1 to destination edge (never starts already flush)
  rule:
    blue carrier -> slide red object right until flush with right edge of blue region
    teal carrier -> slide red object left until flush with left edge of teal region
    shape and rows preserved; simultaneous moves; moved objects must not overlap
  slide_distance: 1-10 cells; gap_before equals slide distance

generation_strategy:
  approach: output-first
  steps:
    1. Choose grid size H,W in [9,15]. Pick split type (horiz or vert) and split position (30-70%).
    2. Fill the grid: one half blue, other half teal. Assign which color is which.
    3. For each carrier region, place 2-3 red rectangles at the destination (flush) position.
       Choose rectangle sizes from observed set. Ensure no row overlap within same carrier.
    4. Verify no overlap between placed red objects.
    5. To derive input: for each red object, slide it away from the flush edge by a random
       gap (1 to max available space), moving it in the opposite direction of the rule.
       Blue objects move left (away from right edge); teal objects move right (away from left edge).
    6. Validate all red objects remain within their carrier region after displacement.
