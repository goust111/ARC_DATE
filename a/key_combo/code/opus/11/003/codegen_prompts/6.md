## 新题 6：射线存活性生成外层掩码驱动克罗内克积

**组合逻辑**：[射线延伸/ray_extend](创新：射线是否到达对侧边缘编码为二值信号) → [克罗内克积/kronecker_product](创新：外层掩码由射线存活性动态生成而非直接给定) + [面板提供调色板/panel_as_palette](已有)

**来源原语**：射线延伸/ray_extend、障碍块/blocker、源像素/source_pixel、边缘起始/edge_origin（P11 69889d6e）；克罗内克积/kronecker_product、二值掩码/binary_mask、色块面板/color_panel、面板提供调色板/panel_as_palette（P5 c803e39c）；分隔列/separator_column（P4 5545f144、P5 c803e39c）

**依赖链**：左边缘的源像素发射水平射线 → 障碍块阻挡部分射线 → 到达右侧分隔列的射线标记为"存活"，形成一个 Nx1 的二值列向量（存活=前景、被挡=背景） → 该列向量作为克罗内克积的外层掩码 → 与右侧面板中的内层二值掩码做克罗内克积 → 两个色块面板提供调色板。删除射线则外层掩码未知；删除克罗内克积则存活列表无法扩展为二维图案。

左边缘源像素的射线被障碍块选择性阻挡，存活射线形成的二值向量与面板中的内层掩码做克罗内克积，生成最终图案。

**输入结构**：约 Nx(M+1+K) 的黑(0)背景网格，被一条灰(5)满高分隔列分为左右两区。左区约 Nx M（N 约 5~8 行，M 约 8~12 列）：左列（第 0 列）的每个像素为红(2)色源像素；左区内部散布若干蓝(1)色障碍块（单像素或 1x2/2x1 小块），每行至多一个障碍块。右区约 Nx K（K 约 6~8 列）：紧贴分隔列右侧放置一个 P x Q 的二值掩码面板（前景绿(3)、背景黑(0)，P,Q 约 3~4），以及两个 1x1 色块——一个橙(7)色方块和一个品红(6)色方块。生成约束：N >= P，使克罗内克积有意义；左区中至少有 2 行的射线能到达分隔列、至少有 1 行的射线被障碍块完全阻挡；障碍块不在第 0 列（不遮挡源像素本身）。

**规则**：
1. 识别灰(5)分隔列，将网格分为左区和右区。
2. 左区：每个源像素（左列红(2)像素）向右发射水平射线，射线沿行前进直到碰到障碍块（蓝(1)像素）或到达分隔列。若射线到达分隔列（中途未被任何障碍块阻挡），记该行为"存活"（前景=1）；否则记为"阻挡"（背景=0）。
3. 将 N 行的存活/阻挡状态排列为一个 Nx1 的二值列向量 V。
4. 从右区提取 PxQ 的二值掩码 M_inner 和两个调色板颜色 C_fg=橙(7)、C_bg=品红(6)。
5. 计算克罗内克积 V (x) M_inner：对 V 中每个前景元素，放置一个 PxQ 的 M_inner 副本（前景像素涂 C_fg、背景像素涂 C_bg）；对 V 中每个背景元素，放置一个 PxQ 的全 C_bg 块。
6. 输出仅为克罗内克积结果（尺寸 (N*P) x Q），不包含原始左区、分隔列或右区面板。

**关键洞察**：克罗内克积的外层掩码不是直接给定的（与 P5 不同），而是由射线-障碍块交互动态生成的——改变障碍块位置就改变了外层掩码，从而改变整个输出图案。需要对比多个示例才能发现外层掩码来自射线存活性而非某个显式面板。
