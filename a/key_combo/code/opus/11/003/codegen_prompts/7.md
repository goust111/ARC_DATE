## 新题 7：对称掩码裁剪为地形图，非对称物体在地形上做重力下落

**组合逻辑**：[对称图案选取/symmetric_selected](创新：对称掩码不作为输出，而是定义输出画布的"地形") + [裁剪/crop](已有) → [重力下落/gravity_drop](创新：下落地形由另一个操作的中间结果提供) + [碰撞停止/collision_stop](已有)

**来源原语**：对称/symmetry、对称图案选取/symmetric_selected、颜色掩码/color_mask、裁剪/crop（P17 d56f2372）；重力下落/gravity_drop、碰撞停止/collision_stop（P10 f0100645）；前景物体/foreground_object（P10 f0100645）

**依赖链**：多个颜色掩码中选出对称掩码 → 裁剪对称掩码得到一个二值地形图（前景=地面，背景=空气） → 非对称掩码中的连通分量作为下落物体 → 物体从地形顶部下落，在地面或其他已停稳物体上停止。删除对称选择则无法区分地形和物体；删除裁剪则地形尺寸未定；删除重力下落则物体无放置规则。这是一个同时约束满足结构：对称掩码同时编码了"输出画布是什么"和"地面在哪里"。

从多个颜色掩码中识别出对称掩码作为地形，将剩余掩码的连通分量在该地形中做重力下落。

**输入结构**：约 14x14 的黑(0)背景网格。网格内有 3~4 种非背景颜色的掩码（每种颜色的所有像素构成一个掩码）。恰好一种颜色的掩码（裁剪到边界框后）关于垂直中轴左右对称，其颜色取自灰(5)或栗(9)。其余颜色的掩码不对称，每种颜色可能含 1~2 个 4-连通分量，每个分量 2~5 像素。生成约束：对称掩码裁剪后的边界框高度 >= 6、宽度 >= 5；对称掩码中前景像素不全集中在底部（即"地形"中存在空洞或悬空平台，使重力下落路径不平凡）；非对称物体的总数 >= 3；非对称物体的最大宽度不超过对称掩码裁剪宽度。

**规则**：
1. 对每种非背景颜色，将该颜色的所有像素裁剪到其边界框，判断是否左右镜像对称。
2. 恰好一种颜色 T 的掩码是对称的。将该掩码裁剪到其边界框，得到一个 HxW 的地形图：颜色 T 的像素 = 地面（固态），背景像素 = 空气。
3. 创建一个 HxW 的黑(0)输出画布。将地形图的地面像素涂为颜色 T。
4. 收集所有非对称颜色掩码的 4-连通分量，每个分量裁剪到其边界框，保留其原色和内部形状。
5. 按分量原始位置的列坐标从左到右排序（列坐标相同则行坐标小的优先）。依次将每个分量放入输出画布：
   - 分量的水平位置（左边界列号）= 该分量在原始网格中的列坐标减去对称掩码边界框的左列坐标（即对齐到地形坐标系），若超出画布宽度则右截断。
   - 分量从画布顶部（行 0）开始逐行下落，直到分量的任一像素的正下方一行是地面像素或已停稳的物体像素，此时停止。
   - 若分量在顶行就已碰到地面，则分量放置在顶行。
6. 后放置的物体像素覆盖先放置的物体像素（但不覆盖地面像素——物体停在地面之上）。

**关键洞察**：对称掩码在 P17 中是被选出直接输出的目标，但这里它的角色完全不同——它定义了一个"物理世界"的地形，其他物体在这个地形中受重力约束。需要对比多个示例才能发现对称掩码不是输出主体，而是输出中的地面结构。
