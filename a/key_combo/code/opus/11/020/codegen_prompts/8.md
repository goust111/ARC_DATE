## 新题 8：滑动碰撞后间隙区域按遮挡层填充

**组合逻辑**：[滑动](矩形块沿指定方向滑动直到碰撞停止) → [间隙区域 + 行列跨度重叠](识别停止后相邻矩形间的水平间隙) → [填充 + 无遮挡才填充 + 深度排序](用优先级规则决定间隙填充颜色)

**来源原语**：滑动(834ec97d)、前景矩形/间隙区域/行列跨度重叠/无遮挡才填充(ef135b50)、深度排序(85c4e7cd)、填充(ef135b50)、标记像素(834ec97d)

**依赖链**：滑动后的停止位置决定了间隙区域的形状和大小；间隙两侧矩形的颜色信息决定了填充颜色（取面积较大者的颜色）；是否有第三个矩形遮挡间隙路径决定了是否执行填充。三个阶段的输出环环相扣。

一句话总结：矩形块向中心滑动停靠后，用面积较大者的颜色填充未被遮挡的相邻间隙。

**输入结构**：约 12x15 的黑(0)背景网格。包含 4-6 个不同颜色的实心矩形块（边长 2-4，颜色互不相同，使用蓝(1)、红(2)、绿(3)、黄(4)、品红(6)）。每个矩形块内部有一个灰(5)标记像素指示滑动方向：灰像素位于矩形的上/下/左/右边中点，指示该矩形将朝灰像素所在边的方向滑动。矩形初始位置分散在网格四周。生成约束：所有矩形滑动后不会重叠（先滑动的不阻挡后滑动的路径；处理顺序为按矩形面积从大到小依次滑动）。

**规则**：
1. 按矩形面积从大到小排序。依次处理每个矩形：沿灰(5)标记像素指示的方向滑动，直到碰到网格边界或已停止的其他矩形时停止（停在相邻格，不重叠）。
2. 所有矩形滑动完成后，识别所有水平相邻矩形对（两个矩形的行跨度有重叠，列跨度之间存在间隙）。
3. 对每对相邻矩形的间隙区域（行跨度取交集，列跨度取两者之间的空列），检查是否有第三个矩形的边界框与该间隙区域在行列上均有交集——若有则不填充（遮挡）。
4. 对未被遮挡的间隙区域，填充颜色 = 两侧矩形中面积较大者的颜色。
5. 灰(5)标记像素在滑动后保留在矩形内（随矩形一起移动）。

**关键洞察**：填充规则依赖滑动后的最终布局而非初始布局——求解者必须先正确模拟所有滑动（含碰撞停止），才能识别哪些间隙存在、哪些被遮挡、填什么颜色。
