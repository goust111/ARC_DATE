## 新题 7：墙线弹射路径编码嵌套框色序

**组合逻辑**：[射线延伸 + 反射弹回](射线在矩形边界和墙线间弹射) → [计数](记录射线穿越不同颜色墙线的顺序) → [嵌套包裹 + 层色序](按穿越顺序确定同心方框的颜色层序)

**来源原语**：射线延伸/反射弹回/对角遇边反射(a3df8b1e)、分隔墙线(3bd292e8)、计数(e048c9ed)、嵌套包裹/同心正方形层/逐层构建(45a5af55)、深度排序/层色序内外翻转(85c4e7cd)

**依赖链**：射线弹射路径由墙线位置决定；路径穿越彩色墙线的先后顺序编码了颜色序列；该序列直接成为同心方框从外到内的色序。墙线位置改变→路径改变→穿越顺序改变→输出色序改变，形成完整因果链。

一句话总结：射线在网格中弹射，依次穿越不同颜色的墙线，穿越顺序决定输出同心方框从外到内的颜色层序。

**输入结构**：约 11x11 至 13x13 的黑(0)背景网格。网格中有 3-4 条单像素宽的直线段（水平或垂直），每条线段颜色不同（使用蓝(1)、红(2)、绿(3)、黄(4)中的 3-4 种）。线段不贯穿整个网格（长度约 3-7 格），彼此不相交。网格左下角有一个橙(7)标记像素作为射线起点。生成约束：从起点沿 45 度右上方向弹射时，射线在到达网格边界前或到达特定弹射次数（不超过 15 步）内会依次穿过每条彩色线段恰好一次。

**规则**：
1. 从橙(7)像素出发，沿 45 度右上方向逐格前进。遇到网格左右边界时水平方向反转，遇到上下边界时垂直方向反转。
2. 射线穿过彩色线段时不停止，继续前进，但记录穿越的线段颜色（按穿越先后排序）。若射线回到起点则停止；若弹射 20 步未回到起点也停止。
3. 得到颜色序列，例如 [蓝, 绿, 红]（按穿越先后）。
4. 构建同心正方形框：层数 = 颜色序列长度 + 1（额外一层为橙(7)中心）。最外层颜色 = 序列第一个（最先穿越的），次外层 = 第二个，依此类推，最内层中心 1x1 方块为橙(7)。每层框厚度统一为 1 格。
5. 输出仅为同心方框图案，紧凑无多余背景。

**关键洞察**：输入中的线段位置看似随意，但它们与射线弹射路径的交叉顺序才是真正的信息——求解者需要模拟弹射过程并观察穿越顺序，而非直接读取线段的空间排列。
