## 新题 5：射线计数决定象限着色

**组合逻辑**：[射线延伸](从标记像素向四个轴方向发射射线) → [计数](统计每条射线到达边界前经过的像素数) → [相对位置决定颜色 + 象限分层](根据四条射线长度的相对大小，对标记像素周围四个象限区域着色)

**来源原语**：射线延伸/画布边界(a3df8b1e)、计数(e048c9ed)、标记像素(834ec97d/1478ab18)、相对位置决定颜色/象限与边距分层(639f5a19)、固定编码表/编码映射(e048c9ed/52fd389e)

**依赖链**：标记像素位置决定四条射线的长度；射线长度的排序结果决定哪个象限获得哪种颜色；若标记像素移动，所有四个象限的着色都会改变。计数、排序、着色三个环节形成不可分割的推理链。

一句话总结：从标记像素向上下左右发射射线，按射线长度从长到短为四个象限分配固定颜色。

**输入结构**：约 9x9 至 13x13 的黑(0)背景网格（奇数边长）。网格中有唯一一个橙(7)标记像素，不在边缘且不在正中心（保证四条射线长度互不相等）。网格中还有若干灰(5)像素作为障碍物散布在网格各处（每个方向 0-2 个），射线遇到障碍物时停止。生成约束：标记像素到四个方向遇到障碍物或边界的距离互不相同。

**规则**：
1. 从橙(7)标记像素出发，分别向上、下、左、右四个方向发射射线，射线前进直到遇到灰(5)障碍物或网格边界时停止（不包含障碍物本身，不包含起点）。
2. 记录四条射线的长度（经过的空格数）：L_up、L_down、L_left、L_right。
3. 将四个长度从大到小排序。最长射线对应的方向获得蓝(1)，第二长获得红(2)，第三长获得绿(3)，最短获得黄(4)。
4. 以标记像素为中心，将网格划分为四个象限（不含中心行和中心列）：左上、右上、左下、右下。每个象限的着色由与之相邻的两条射线决定——取两条相邻射线中较长者的颜色。具体：左上象限 = max(L_up, L_left) 对应的颜色；右上 = max(L_up, L_right) 的颜色；左下 = max(L_down, L_left) 的颜色；右下 = max(L_down, L_right) 的颜色。
5. 用该颜色填充对应象限中所有黑(0)像素。标记像素、灰障碍物、中心行和中心列保持不变。

**关键洞察**：象限颜色不是由象限自身位置直接映射，而是由射线长度的相对排序间接决定——需要先完成射线模拟和计数，再通过比较运算确定每个象限取哪条射线的颜色。

## 实现要求

1. `main(grid)` 必须实现新题描述中的确定性转换规则，不能只识别 `generate_input()` 的固定模板。禁止不同的input网格输出相同的output网格。
2. `generate_input()` 必须随机生成多样样例，不能固定死。随机维度应覆盖：网格大小、对象数量、位置、颜色、方向、形状参数或关键分支。注意若描述中存在若干，需实现而不是只有单个，包括object或者对应关系等等。且若涉及到最短路径，则输入网格中必涉及到多条路径，对选择造成干扰。

6. 若规则有多个分支，生成器不能长期固定成一个分支；应让分支在随机样例中合理出现。分支概率不必平均——难以发现的隐蔽分支（如少数情况下才触发的特殊规则）应适当提高出现概率，确保在 3 个训练示例中至少出现一次，否则求解者无法归纳该规则。对于颜色映射类规则，确保 2 个左右的示例即可覆盖所有映射关系（每种颜色→颜色的映射至少在某个示例中出现过）。
