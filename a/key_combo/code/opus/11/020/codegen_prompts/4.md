## 新题 4：连通区域面积编码条纹宽度

**组合逻辑**：[四邻接连通](识别分离的前景区域) → [计数](统计每个区域面积) → [堆叠 + 逐行递增](按面积大小依次生成对应宽度的水平条纹并垂直堆叠)

**来源原语**：四邻接连通/背景区域(3bd292e8)、计数(e048c9ed)、堆叠(bbc9ae5d/291dc1e1)、逐行递增(bbc9ae5d)、色段(bbc9ae5d)、长度映射颜色(e048c9ed)

**依赖链**：连通区域的划分决定了有多少个独立面积值需要处理；面积值决定条纹的行数（高度）；区域颜色决定条纹颜色；区域在输入中的空间位置（按边界框左上角从上到下）决定条纹堆叠顺序。任一环节缺失都无法确定最终输出。

一句话总结：将输入中散布的彩色连通区域按从上到下的位置排序，每个区域转化为一条水平色带堆叠输出，色带高度等于区域面积。

**输入结构**：约 10x10 至 14x14 的黑(0)背景网格。包含 3-5 个互不相邻的单色 4-连通前景区域，每个区域颜色不同（如蓝(1)、红(2)、绿(3)、黄(4)），每个区域由 1-4 个像素组成，形状不规则。生成约束：各区域面积互不相同；各区域边界框在垂直方向上无重叠（即可以明确按"从上到下"排序）。

**规则**：
1. 识别所有非黑 4-连通区域，记录每个区域的颜色和像素面积。
2. 按每个区域边界框的最上行坐标从小到大排序（最靠近顶部的区域排第一）。
3. 输出宽度 = 输入网格宽度。输出高度 = 所有区域面积之和。
4. 从输出顶部开始，按排序顺序依次绘制全宽水平色带：第一个区域的颜色填满前 k1 行（k1 = 该区域面积），第二个区域颜色填满接下来 k2 行，依此类推。
5. 每条色带完全填满整行（从第 0 列到最后一列）。

**关键洞察**：输入中区域的形状和具体位置无关紧要，唯一重要的是面积（决定条纹高度）和垂直位置（决定堆叠顺序）——求解者必须对比多个示例才能排除形状和水平位置的干扰。
