## 新题 3：掩码旋转选择性保留

**组合逻辑**：[旋转](对输入图案施加 90 度旋转生成四个朝向) → [掩码决定保留](用掩码层决定四个旋转版本中哪些像素最终出现) → [深度排序 + 重涂色](多个旋转版本重叠时按旋转角度决定优先级)

**来源原语**：旋转/四旋转组成风车(7fe24cdd)、掩码决定保留/掩码像素(f76d97a5)、深度排序(85c4e7cd)、重涂色(85c4e7cd)

**依赖链**：旋转产生的四个版本在空间上必然重叠；掩码决定哪些位置有内容（过滤掉大部分区域）；重叠位置的冲突需要深度规则解决。掩码本身不包含旋转信息，旋转结果不包含过滤信息，两者必须结合才能生成输出。

一句话总结：将输入图案旋转四次叠放到同一画布上，仅保留掩码层标记的位置，重叠处按旋转角度优先级取色。

**输入结构**：约 9x9 的网格（奇数边长正方形）。网格分为两个逻辑层叠放在同一画布上：(a) 图案层——由红(2)像素组成的不对称连通图形（约 5-10 像素），放置在网格某个象限区域，其余位置为黑(0)；(b) 掩码层——由灰(5)像素标记的散布位置（约占网格总面积的 30-40%），分布跨越所有四个象限。图案层像素和掩码层像素不重叠（同一格不会既是红又是灰）。生成约束：图案经四次旋转后，在掩码标记位置处至少存在部分有效像素（不会全部落空）。

**规则**：
1. 提取图案层（所有红(2)像素）和掩码层（所有灰(5)像素的坐标集合）。
2. 以网格中心为旋转中心，生成图案的 0度、90度顺时针、180度、270度顺时针 四个旋转副本。
3. 创建与输入同尺寸的黑(0)输出网格。
4. 按优先级从低到高依次绘制：0度版本 → 90度 → 180度 → 270度（即 270度优先级最高，后绘制覆盖先绘制）。
5. 绘制规则：对于每个旋转版本中非黑像素的位置，仅当该位置属于掩码集合时才绘制。绘制颜色按旋转角度不同：0度保持红(2)、90度涂为蓝(1)、180度涂为绿(3)、270度涂为黄(4)。
6. 掩码层像素本身不出现在输出中（灰色不保留）；未被任何旋转版本覆盖的掩码位置保持黑(0)。

**关键洞察**：掩码并非简单的"保留/擦除"开关——它与旋转后的图案位置做交集运算，因此同一掩码在不同旋转版本下筛选出不同的像素子集，求解者需要心算旋转后的图案落点。
