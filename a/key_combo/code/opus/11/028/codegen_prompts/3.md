## 新题 3：面积排名决定镜像轴

**组合逻辑**：[计数(counting)](已有) + [排序(sorting)](已有) → 排名 → [镜像(mirror)](创新：镜像轴由排名决定而非固定)

**来源原语**：计数/排序/面积排序/按像素数降序(f8ff0b80), 镜像/镜像对应(74dd1130, 9bebae7a), 精灵体(9bebae7a), 前景色掩码(f8ff0b80)

**依赖链**：计数产生面积值，排序产生排名，排名决定每个精灵的镜像方式。三步紧耦合——不计数则无法排序，不排序则无法分配镜像轴，不镜像则无法生成输出。

统计每个前景精灵的像素数并排序，排名决定该精灵的反射轴类型，输出所有精灵经各自轴反射后的结果。

**输入结构**：约 12x12 网格，黑(0)背景。恰好 3 个互不相邻的单色 4-连通前景精灵，颜色分别为蓝(1)、红(2)、绿(3)，每个精灵 3~7 像素且三者像素数互不相同。每个精灵非对称（不具备水平/垂直/对角对称性）。生成约束：三个精灵的 bbox 之间至少间隔 2 格；每个精灵的 bbox 距离网格边界有足够空间容纳其镜像副本。

**规则**：
1. 统计每个精灵的像素数，按像素数从大到小排列为排名 1、2、3。
2. 排名 1 的精灵：以其 bbox 的水平中轴为轴做上下镜像，镜像副本紧贴在原件下方（若原件在下则副本在上），保持原色。
3. 排名 2 的精灵：以其 bbox 的垂直中轴为轴做左右镜像，镜像副本紧贴在原件右侧（若原件在右则副本在左），保持原色。
4. 排名 3 的精灵：以其 bbox 的主对角线为轴做转置反射（行列互换），镜像副本放置在原件的右下方，与原件共享 bbox 左上角，保持原色。
5. 输出保留原始精灵并添加各自的镜像副本。背景保持黑(0)。

**关键洞察**：镜像轴不是由位置或颜色决定的——必须先数像素、排名次，才能知道每个精灵该怎么反射。单个示例中可能误以为"蓝色=水平镜像"，需要对比多个示例（颜色与排名关系变化）才能归纳出正确规则。
