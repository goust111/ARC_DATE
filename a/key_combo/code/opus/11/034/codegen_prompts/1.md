## 新题 1：嵌套环指向射线

**组合逻辑**：[嵌套层序](已有) + [指示像素→罗盘方向](创新：指示像素的位置不再指示延伸侧，而是编码射线方向) → [射线延伸](已有，但从公共中心而非各自中心出发) → [重涂色](已有，但颜色由环层而非标记本身决定) + [嵌套层序决定绘制优先级](创新：外层先画、内层后画，交叉处内层覆盖外层)

**来源原语**：嵌套层序、色沿层序循环移(bda2d7a6)；指示像素、方向指示(b527c5c6)；射线延伸、罗盘方向、中心向外辐射(1d398264)；重涂色(673ef223)

**依赖链**：环的嵌套层序决定指示像素的读取顺序和射线绘制优先级；指示像素在其所在环上的位置编码射线方向；环的颜色决定射线颜色；射线之间的交叉由嵌套层序决定覆盖关系——三者互相依赖，缺一不可。

从同心环的指示像素读取方向，以最内环中心为起点射出彩色射线，外层环的射线先画、内层后画以决定交叉覆盖。

**输入结构**：黑(0)背景上有 3~5 层同心矩形环（约 15x15 网格），每层环一像素厚、各不同色（从蓝(1)、红(2)、绿(3)、黄(4)、灰(5)中取）。每层环的某一侧边（上/下/左/右）上恰好有一个像素被替换为橙(7)，作为该层的指示像素。各层指示像素所在的侧边互不相同或可重复（需从示例中归纳覆盖规则）。最内层环围出的中心区域为 1x1 或 2x2 的黑(0)空间。生成约束：各环颜色互不相同；每层恰好一个橙(7)指示像素。

**规则**：
1. 找到所有同心环并确定嵌套层序（最外层为第 1 层，最内层为第 N 层）。
2. 对每层环，找到其橙(7)指示像素。该像素在环的哪一侧决定射线方向：上侧→向上、下侧→向下、左侧→向左、右侧→向右。
3. 以最内层环围出的中心区域的中心像素为射线起点（若中心区域为 2x2，取左上角像素）。
4. 按**从外到内**的顺序依次绘制射线：从起点沿该层指示的方向画直线至网格边界，颜色为该层环的原色（非橙色）。后绘制的射线覆盖先绘制的射线（即内层射线优先）。
5. 擦除所有原始同心环和指示像素（置为黑(0)），只保留射线和起点。起点像素涂为橙(7)。

**关键洞察**：射线的绘制顺序由环的嵌套层序决定（外先内后），因此在同一方向上若多层环都指向该方向，最终可见的是最内层的颜色——必须对比多个示例才能确认"内层覆盖外层"而非相反。
