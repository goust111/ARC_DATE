## 新题 3：梳状编码模板缩放

**组合逻辑**：[高度编码数量](已有) → [像素放大](创新：缩放因子不由全局色数决定，而由每个梳状结构独立编码) → [印章放置](创新：模板的放置位置由梳状结构的水平位置决定，而非由单像素布局决定) + [重涂色](已有，颜色来自梳状结构)

**来源原语**：高度编码数量、梳状结构、压缩(a1aa0c1e)；像素放大、色数决定缩放(469497ad)；印章放置、模板(a395ee82)；重涂色(221dfab4)

**依赖链**：梳状结构的实心行数编码缩放因子→缩放因子决定模板复制品的大小→梳状结构的水平位置决定放置列→梳状结构的颜色决定复制品的颜色。解码、缩放、定位、涂色四步全部依赖梳状结构的不同属性。

读取梳状结构的高度作为缩放因子，将模板精灵按此因子放大后放置在梳状结构的水平位置上，并涂为梳状结构的颜色。

**输入结构**：黑(0)背景约 20x20 网格。网格底部有一条完整宽度的灰(5)水平分隔条（1 像素厚）。分隔条上方有 2~4 个梳状结构，每个梳状结构占 3 列宽，由交替的"两侧像素行"和"实心三像素行"垂直堆叠而成，颜色各异（从红(2)、绿(3)、蓝(1)、黄(4)中取），底部对齐到分隔条。每个梳状结构的实心行数为 1~4，编码一个数值。梳状结构之间水平间距不等。分隔条下方左侧有一个小型单色模板精灵（品红(6)，约 2x2~3x3 像素，形状为 4-连通不规则图形）。生成约束：各梳状结构的实心行数互不相同；模板精灵的宽高均不超过 3 像素。

**规则**：
1. 识别灰(5)分隔条上方的每个梳状结构。每个梳状结构的"实心三像素行"数量即为该梳的编码数值 K。
2. 在分隔条下方找到品红(6)模板精灵，裁剪其最小边界框。
3. 对每个梳状结构：将模板精灵按因子 K 做像素级放大（每个像素变为 KxK 方块），得到放大后的模板。
4. 将放大后的模板涂为该梳状结构的颜色，放置到输出网格中：模板的水平中心与梳状结构的中心列对齐，模板的顶边紧贴分隔条下方。
5. 擦除原始梳状结构和原始模板精灵（置为黑(0)）。保留灰(5)分隔条。若多个放大模板在水平方向重叠，后处理的（即编码数值更大的）覆盖先处理的。

**关键洞察**：缩放因子不是一个全局常数，而是每个梳状结构独立编码的局部值——必须对比多个梳状结构在同一示例中产生的不同大小模板，才能确认"高度=缩放因子"的对应关系。
