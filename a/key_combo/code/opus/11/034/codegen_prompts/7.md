## 新题 7：边缘字形路径描绘

**组合逻辑**：[解码 + 字形 + 顺序排列](已有，但字形不再编码管道方向，而是编码平移向量) → [平移](创新：平移对象从边缘带变为网格内精灵体，且为累积平移) → [连线](创新：轨迹不是射线而是逐步位移的路径，每段颜色由对应字形决定) + [擦除](已有)

**来源原语**：解码、字形、顺序排列、弯头决定偏移(e6de6e8f)；平移、边缘带、擦除(d255d7a7)；连线(b527c5c6)；重涂色(673ef223)

**依赖链**：字形的像素形状编码移动方向→字形的左右顺序决定执行序列→精灵体从当前位置按指令平移→每步留下该字形颜色的轨迹→前一步的终点位置是后一步的起点。路径是累积的，任何一步的解码错误都会导致后续所有步骤位置偏移。

将边缘字形条中的字形按序解码为移动指令，驱动网格内精灵体逐步平移并留下彩色轨迹。

**输入结构**：黑(0)背景约 15x15 网格。网格最左列为一列宽的灰(5)分隔条。分隔条左侧无内容（分隔条在第 0 列）。网格顶部两行（第 0~1 行）为字形条：包含 3~5 个字形，每个字形占 2 行 x 2 列，字形之间紧邻排列（无间隔），从左到右依次排列。每个字形由单色像素在 2x2 区域内构成 L 形图案（3 个像素亮、1 个像素黑(0)），每个字形颜色不同（从红(2)、蓝(1)、绿(3)、黄(4)、品红(6)中取）。L 形中缺失像素的位置编码移动方向：左上缺→向右下移动、右上缺→向左下移动、左下缺→向右上移动、右下缺→向左上移动（缺失角的对角方向）。在网格中部偏下位置有一个橙(7)起点标记（单像素）。生成约束：按字形序列移动后，精灵体始终不会离开网格边界；每步移动距离为 2 像素（对角方向即行列各移动 2）。

**规则**：
1. 在顶部两行中，按从左到右的顺序识别每个 2x2 字形及其颜色。
2. 对每个字形，检查其 2x2 区域中黑(0)像素的位置（左上/右上/左下/右下），确定移动方向为该位置的对角方向。
3. 从橙(7)起点标记开始，按字形顺序依次执行移动：每步沿指定对角方向移动 2 像素（行 +/-2，列 +/-2）。
4. 每步移动的路径（起点到终点之间的 2 个像素，包括终点但不包括起点）涂为该字形的颜色。若路径像素已有颜色，后画的覆盖先画的。
5. 擦除顶部两行的字形条（置为黑(0)）。起点标记橙(7)保留。

**关键洞察**：字形中缺失像素的位置与移动方向之间的映射关系（缺失角→对角方向移动）是隐蔽规则，单个字形的效果可能恰好与其他假设（如"朝缺失方向移动"）吻合，必须对比多个字形的效果才能排除错误假设。
