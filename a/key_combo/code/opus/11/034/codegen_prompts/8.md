## 新题 8：射线碰撞计数涂色

**组合逻辑**：[射线延伸](已有) + [计数](创新：计数对象不是颜色频率，而是"射线到达边界的方向数") → [重涂色 + 颜色循环](创新：颜色循环的索引不由嵌套层序决定，而由射线碰撞计数决定)

**来源原语**：射线延伸、中心向外辐射、罗盘方向(1d398264)；计数(27a77e38, 469497ad)；重涂色、颜色循环(221dfab4, bda2d7a6)

**依赖链**：每个方块的四方向射线是否被其他方块阻挡取决于所有方块的全局布局→阻挡统计产生每个方块的"自由度"计数→计数索引到颜色循环表决定输出色。任何一个方块的移除或增加都会改变其他方块的射线结果，形成全局耦合。

从每个色块中心向四个基本方向射出射线，统计未被其他色块阻挡而到达网格边界的方向数，按此计数通过颜色循环表重涂每个色块。

**输入结构**：黑(0)背景约 13x13 网格。散布 4~7 个单色实心方块，每个方块为 2x2 像素，全部为灰(5)。方块之间不相邻（任意两个方块之间至少间隔 1 像素）。方块分布使得不同方块有不同的"自由方向数"（0~4 的某个子集）。生成约束：至少存在 3 种不同的自由方向数值，以便求解者归纳颜色映射。

**规则**：
1. 对每个 2x2 灰(5)方块，从其中心（四格交汇点）向上、下、左、右四个方向各射一条虚拟射线。
2. 每条射线沿该方向检查：若到达网格边界前未碰到任何其他方块的像素，则该方向计为"自由"；若碰到其他方块的像素（包括仅触碰角），则该方向计为"阻挡"。
3. 统计每个方块的自由方向数 F（0~4）。
4. 按以下颜色映射重涂该方块：F=0→红(2)，F=1→蓝(1)，F=2→绿(3)，F=3→黄(4)，F=4→品红(6)。此映射为隐蔽规则，需从示例中归纳。
5. 方块形状和位置不变，仅颜色改变。背景保持黑(0)。

**关键洞察**：每个方块的输出颜色取决于全局布局中其他方块对它的遮挡关系，而非方块自身的任何局部属性——必须分析多个不同布局的示例才能确认"自由方向数→颜色"的映射表，且在同一示例内各方块的结果互相印证。
