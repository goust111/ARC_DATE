## 新题 6：拉丁方对角约束补全

**组合逻辑**：[补全 + 拉丁方约束](已有) × [对角映射 + 标记块](创新：标记块不再直接提供填充色，而是为对角象限的拉丁方补全提供锚定约束——标记色指定哪个颜色在对角象限中已正确放置) → [行列唯一约束](已有，但作用范围从全局变为象限内)

**来源原语**：补全、拉丁方约束、行列唯一约束、色表(4cd1b7b2)；对角映射、标记块、象限区域、标记色填对角区(93b581b8)

**依赖链**：标记块的每个单元格颜色→通过对角映射指向对面象限→该颜色在对面象限中的已有位置不可移动（锚定）→象限内拉丁方补全必须在锚定约束下进行。标记块、对角映射、拉丁方补全三者形成不可分割的约束网络。

中央标记块通过对角映射为每个象限的拉丁方补全提供锚定色约束，补全时须同时满足行列唯一和锚定不可移动。

**输入结构**：约 11x11 网格（奇数边长）。网格正中央有一个 2x2 标记块，四格颜色各异，取自红(2)、蓝(1)、绿(3)、黄(4)。以标记块为中心，网格被分为四个象限（左上、右上、左下、右下），每个象限为一个 (n-1)/2 边长的正方形区域（约 4x4 或 5x5）。每个象限是一个部分填充的颜色网格：使用恰好 n 种颜色（等于象限边长，4 或 5 种），部分格子已填色，部分为黑(0)（表示空白待补全）。已填色格子满足行列无重复约束。生成约束：每个象限的拉丁方补全在锚定约束下有唯一解。

**规则**：
1. 识别中央 2x2 标记块及其四个单元格的颜色。
2. 对角映射：标记块左上格颜色 → 约束右下象限；标记块右上格颜色 → 约束左下象限；标记块左下格颜色 → 约束右上象限；标记块右下格颜色 → 约束左上象限。
3. 每个象限收到一个"锚定色"。在该象限中，所有已填入该锚定色的格子位置不可更改（这些位置是确定正确的参考点）。
4. 对每个象限，在锚定约束下完成拉丁方补全：每行每列恰好包含所有使用颜色各一次，黑(0)空白格被唯一确定地填入正确颜色。
5. 标记块本身保持不变。

**关键洞察**：标记块不是颜色图例（不直接告诉填什么色），而是通过对角映射远程指定哪些已有信息是可信锚点——必须对比多个象限的补全结果才能发现"对角映射锚定"这一隐蔽约束，否则可能误以为所有已填色格子都是锚点（实际上非锚定色的已填格子在某些示例中可能有多种补全方式，但锚定约束排除了歧义）。
