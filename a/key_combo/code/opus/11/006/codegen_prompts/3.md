## 新题 3：杯体填充奇偶溢出生长

**组合逻辑**：[fill](已有：杯体内标记色填充) + [counting](创新：计数对象从"空心矩形面积"变为"已填充像素数") + [parity_sets_fill → parity_triggers_growth](创新：奇偶不再决定填充色，而决定是否触发生长) + [grow](创新：生长起点从"种子行"变为"杯底边缘"，生长形态从平行行变为逐行缩窄三角滴落)

**来源原语**：fill + cup_outline + marker_color_sets_fill + cap_layer_added (444801d8), counting + parity_sets_fill (868de0fa), grow + alternating_color (af726779)

**依赖链**：标记色填充杯体 → 计数填充像素 → 奇偶判断 → 偶数则停止（只保留填充和封盖），奇数则从杯底向下生长交替色三角滴落。计数结果决定是否触发生长——不填充就无法计数，不计数就不知道是否生长。

用标记色填充蓝色杯体并加封盖层，然后统计各杯体填充面积：偶数面积的杯体到此为止，奇数面积的杯体从底部向下生长逐行缩窄的交替色三角滴。

**输入结构**：黑(0)背景网格，约 16x20。网格中有 2-4 个蓝(1)像素组成的杯状轮廓：每个杯由一条 U 形蓝(1)连通曲线构成，开口朝上，内部为黑(0)空腔。各杯大小不同（宽 3-6 像素，高 3-5 像素），水平排列且互不接触。每个杯内部恰好有一个非黑、非蓝的单色标记像素（使用 {红(2), 绿(3), 黄(4), 灰(5)} 中不重复的颜色）。杯与网格底边之间留有足够空间（至少 5 行）。生成约束：各杯的内部像素数（不含蓝边框像素）各不相同，且至少一个为偶数、至少一个为奇数。

**规则**：
1. 对每个蓝(1)杯状轮廓，找到其内部的标记像素颜色 C。
2. 用颜色 C 填充杯体内部所有黑(0)像素（标记像素本身已经是 C，保持不变）。
3. 在杯口正上方一行，将与杯口等宽的像素段涂为颜色 C（封盖层）。
4. 计算该杯体内部被填充为 C 的像素总数（不含封盖层、不含蓝边框）。
5. 若总数为偶数：该杯体处理完毕，无额外操作。
6. 若总数为奇数：从杯体蓝(1)底边正下方一行开始，向下生长交替色行。第一行用品红(6)，第二行用橙(7)，依次交替。每一行比上一行左右各缩进 1 像素。当行宽缩至 0 像素或下一行超出网格底边时停止。
7. 各杯体独立处理。蓝色轮廓保持不变。

**关键洞察**：封盖层的生成是无条件的（所有杯都加），但滴落生长是有条件的（仅奇数面积触发）。需要对比偶数面积杯（无滴落）和奇数面积杯（有滴落）的示例才能发现奇偶这条隐蔽规则。
