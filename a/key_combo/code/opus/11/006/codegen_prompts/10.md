## 新题 10：色匹配区域面积驱动循环位移

**组合逻辑**：[cyclic_roll](创新：位移量不来自控制行/列标记位置，而来自一个区域的面积值) + [counting](创新：计数对象从"奇偶判定"变为"位移参数提取") + [color_matches_side → color_matches_region](创新："颜色匹配"从匹配边框侧扩展为匹配任意区域，标记色选定参数源区域)

**来源原语**：cyclic_roll + marker_is_shift (79cce52d), counting + parity_sets_fill (868de0fa, 概念层面：面积计算), color_matches_side (d687bc17, 概念层面：颜色匹配选择), enclosed_region (868de0fa)

**依赖链**：标记像素颜色匹配某个封闭区域 → 计算该区域面积 → 面积值取模后成为循环位移量 → 对整个网格执行位移。颜色匹配回答"哪个区域的面积？"，计数回答"面积是多少？"，位移将面积转化为空间变换——三步形成信息提取链。

找到颜色与背景标记匹配的封闭区域，用其面积对网格尺寸取模得到循环位移量，据此位移全网格。

**输入结构**：黑(0)背景网格，约 11x11。网格中有 3-4 个由不同颜色（从 {蓝(1), 红(2), 绿(3), 黄(4)} 中选取）绘制的实心封闭区域（4-连通单色连通分量，每个 4-12 像素，形状不规则，各示例中同类区域形状不同）。区域间互不接触（间隔至少 1 像素）。网格最底行的最右侧有一个品红(6)的单像素标记。该标记的左侧紧邻一个像素，其颜色与网格中某个封闭区域的颜色相同（如该像素为红(2)，则网格中存在一个红(2)区域）。生成约束：被指定区域的面积对网格宽度取模后不为 0，对网格高度取模后也不为 0；各区域面积互不相同。

**规则**：
1. 在网格最底行找到品红(6)标记像素。读取标记左侧紧邻像素的颜色 C。
2. 在网格中找到颜色为 C 的 4-连通封闭区域，计算其面积 A（像素数）。
3. 设网格宽度为 W、高度为 H。
4. 将网格所有像素（包括所有区域和背景，但不包括最底行的标记结构）整体循环右移 A mod W 列。
5. 再将结果整体循环下移 A mod H 行。
6. 移除最底行中的品红(6)标记像素及其左邻的颜色指示像素（均变为黑(0)）。
7. 输出循环位移后的网格。

**关键洞察**：位移量不是直接读取的标记位置，而是通过"颜色匹配→面积计算→取模"的间接推理链得到的。标记像素本身不携带位移信息——它只是一个指针，指向某个区域，而那个区域的几何属性才编码了变换参数。需要多个示例才能归纳出面积→位移量的映射规则。
