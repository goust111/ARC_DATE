## 新题 4：双面板空交集生成定向生长种子

**组合逻辑**：[logical_operation](已有：双面板逐格比较) + [intersect_empty → seed_generation](创新："双空交集"从最终输出变为生长的种子来源) + [grow](创新：生长方向由控制行标记编码，而非固有的向下生长) + [crop](已有：裁去分隔和控制结构)

**来源原语**：logical_operation + cell_comparison + separator_column + equal_width_panel + intersect_empty_fill (f2829549), grow + alternating_color (af726779), crop + control_row + marker_is_shift (79cce52d)

**依赖链**：控制行提供方向参数 → 裁去控制行和分隔列 → 双面板逐格比较找到双空像素 → 双空像素成为生长种子 → 种子沿控制行指定方向生长至遇到前景像素。控制行参数决定生长行为，面板交集决定生长起点，两者汇聚于生长操作。

裁去控制行和分隔列，在左右面板的空白交集位置放置种子，种子沿控制行标记编码的方向生长至碰到前景像素。

**输入结构**：黑(0)背景网格，约 13x15（奇数列宽以容纳分隔列）。最顶行为控制行：整行为灰(5)底色，其中一个像素为红(2)标记。红(2)标记的列位置编码生长方向——位于控制行左四分之一区域表示向左生长，右四分之一表示向右，中左四分之一表示向上，中右四分之一表示向下。第 2 行起，网格正中列为 1 像素宽的灰(5)分隔列，将剩余区域分为等宽的左面板和右面板。两面板各自包含若干非黑前景像素（左面板用蓝(1)，右面板用黄(4)），形成不同的稀疏图案。生成约束：两面板的共同空白像素（双空交集）至少 3 个且不超过 8 个；沿指定方向生长时各种子的生长路径互不冲突（不交叉也不重叠）。

**规则**：
1. 读取控制行中红(2)标记的列位置 c。设控制行总宽为 W。若 c < W/4，生长方向为向左；若 W/4 <= c < W/2，方向为向上；若 W/2 <= c < 3W/4，方向为向下；若 c >= 3W/4，方向为向右。
2. 移除控制行（第 0 行）和分隔列，得到左面板和右面板。
3. 将左面板和右面板按相同坐标逐格比较：若某位置在两个面板中均为黑(0)（背景），则在输出网格对应位置标记为绿(3)种子像素。
4. 保留两个面板中所有非黑前景像素（蓝(1)和黄(4)保留在原位）。
5. 从每个绿(3)种子像素出发，沿步骤 1 确定的方向逐像素延伸，将路径上的黑(0)背景像素涂为绿(3)，直到碰到非黑像素（蓝(1)、黄(4)或另一条绿(3)生长路径的像素）或到达网格边缘时停止（不覆盖终点处的非黑像素）。
6. 输出网格尺寸 = 去掉控制行和分隔列后的面板并排尺寸（高度 = 原高度 - 1，宽度 = 原宽度 - 1）。

**关键洞察**：控制行标记不是偏移量（不像 79cce52d 那样编码位移），而是方向编码器——其位置落在四个区间中的哪一个决定了生长方向。双空交集也不是最终输出（不像 f2829549），而是中间产物——生长的起点。两个独立来源（控制行 + 面板交集）的信息汇聚在生长操作上。
