## 新题 7：反转掩码印章叠加于色对锚点

**组合逻辑**：[invert + paired_color_mapping](创新：反转结果不是最终输出，而是生成印章模板) + [diagonal_pairing + pair_defines_rect](创新：色对不仅定义矩形填充区，还提供印章放置锚点) + [stamp_overlay](创新：印章内容来自反转运算而非目录区域) + 层叠冲突解决

**来源原语**：invert + paired_color_mapping (6ea4a07e), fill + diagonal_pairing + pair_defines_rect (56ff96f3), stamp_overlay + template_matching (3ed85e70)

**依赖链**：小掩码区域经反转+配对色映射生成印章模板 → 同色像素对定义矩形并计算中心点 → 印章在中心点处盖印 → 矩形填充在印章下方作为底色。反转生成内容（印章模板），色对生成位置（锚点）和底色（矩形填充），三者汇聚为最终分层输出。

用反转和配对色映射将小掩码变为印章模板，在各同色对矩形的中心叠印该模板，矩形自身填充为底层。

**输入结构**：黑(0)背景网格，约 14x14。左上角有一个 3x3 的子区域，用栗(9)单像素边框圈出：框内为 3x3 的单色掩码（使用灰(5)、绿(3)或青(8)中的一种作为前景色，黑(0)为背景），掩码中前景像素 2-4 个，形成简单图案。栗(9)框外、网格其余区域中有 2-3 种颜色（从 {蓝(1), 红(2), 黄(4)} 中选取），每种颜色恰好出现 2 个孤立像素。各色对定义的矩形互不重叠，且不与左上角掩码框重叠。掩码框占据网格第 0-4 行、第 0-4 列（含框线）。

**规则**：
1. 提取栗(9)框内的 3x3 掩码。对掩码进行反转：前景像素变为黑(0)，黑(0)背景像素变为配对色。配对色映射规则：灰(5)→黄(4)，绿(3)→蓝(1)，青(8)→红(2)。反转后的 3x3 图案即为印章模板。
2. 擦除栗(9)框及其内容（框区域全部变为黑(0)）。
3. 对每种出现恰好 2 次的颜色 C（在框外区域），取两个像素的轴对齐矩形。填充该矩形为颜色 C。
4. 计算每个矩形的中心位置（行中心 = (r1+r2)/2 向下取整，列中心 = (c1+c2)/2 向下取整）。
5. 将印章模板以中心对齐方式盖印在每个矩形中心：印章的中心像素 (1,1) 对齐到矩形中心。印章中的黑(0)像素为透明（不覆盖），非黑像素覆盖底层。
6. 印章叠印顺序：按矩形面积从大到小处理。面积相同时，按矩形左上角从上到下、从左到右处理。后印的覆盖先印的。
7. 超出网格的印章像素舍弃。

**关键洞察**：配对色映射（灰→黄、绿→蓝、青→红）是一条需要对比多个示例才能归纳的隐蔽规则，它决定了印章的颜色。同色像素对既提供了矩形底色又提供了印章锚点，这两个角色在任何参考题中都不同时出现。
