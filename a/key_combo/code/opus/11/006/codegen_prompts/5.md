## 新题 5：端点定侧的半字形镜像补全

**组合逻辑**：[erase](已有) + [reconstruct](创新：模板是半字形而非完整字形) + [mirror](创新：镜像不是独立操作，而是补全不完整重建的必要步骤) + [endpoint_marker](创新：标记所在列决定半字形放置侧和镜像方向)

**来源原语**：erase + reconstruct + frame_bar + endpoint_marker + glyph_template + color_to_shape + anchor_position (98c475bf), mirror + mirror_toward_marker_recolor (2bcee788)

**依赖链**：参考半字形定义模板 → 擦除参考字形 → 端点标记对的列位置（左列 / 右列 / 两列都有）决定三件事：（a）用哪一半作为模板，（b）放置在哪一侧，（c）是否需要镜像补全。重建和镜像不是独立步骤，而是由标记位置统一控制的一体化补全流程。

擦除参考半字形，根据各端点标记对所在的列位置，在锚定行重建半字形并镜像补全为完整对称字形。

**输入结构**：网格为 20 行高、约 12 列宽。最左列和最右列为同色（栗(9)）的满高竖条边框。边框之间为黑(0)背景的内部区域，内部区域列宽为 W（偶数，约 10）。内部区域包含：一个由颜色 A（如蓝(1)）绘制的半字形参考模板——该字形仅占据内部左半侧（第 0 列到第 W/2-1 列）或仅占据右半侧（第 W/2 列到第 W-1 列），关于内部垂直中轴不对称。另有 1-2 种其他颜色（如红(2)、绿(3)）的端点标记对：每个标记对由两个同色像素组成，位于同一行，分别处于内部区域的第一列和/或最后一列。标记对有三种配置：（i）两个标记均在内部左侧第一列；（ii）两个标记均在内部右侧最后一列；（iii）一个在第一列、一个在最后一列。生成约束：不同颜色的标记对所在行互不重叠；重建后的字形互不重叠。

**规则**：
1. 记录参考半字形（颜色 A）的形状和它占据的侧（左半或右半）。
2. 擦除参考半字形（所有颜色 A 的像素变为黑(0)）。
3. 对每个端点标记对（颜色 B），检查其两个像素的列位置：
   - 若两个标记均在内部第一列（左侧）：在标记所在行为锚点，将参考半字形绘制在左半侧（使用颜色 B），然后将其沿内部垂直中轴向右镜像，得到完整对称字形（镜像部分也使用颜色 B）。
   - 若两个标记均在内部最后一列（右侧）：在标记所在行为锚点，将参考半字形绘制在右半侧（使用颜色 B），然后向左镜像补全。
   - 若标记分处两侧（一个在第一列、一个在最后一列）：在标记所在行为锚点，直接绘制参考半字形在其原始侧（使用颜色 B），再镜像到另一侧（也用颜色 B），等价于对称放置。
4. 锚点定位规则：将参考半字形的横向中心行对齐到标记像素所在行。
5. 保留栗(9)边框不变。端点标记像素被重建的字形覆盖。

**关键洞察**：标记对的列配置（双左 / 双右 / 一左一右）不只是位置信息，而是隐式地编码了"从哪侧开始重建"和"向哪侧镜像"。必须对比三种不同配置的示例才能完整归纳规则。模板本身是不完整的半字形——这一点只有在看到输出总是对称的之后才能推断。
