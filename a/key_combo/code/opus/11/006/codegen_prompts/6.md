## 新题 6：对角色对矩形作为生长屏障

**组合逻辑**：[pair_defines_rect + fill](已有：同色对定义矩形并填充) + [grow](创新：生长被已填充矩形的边界阻挡) + [alternating_color](已有：交替色) + [containment → barrier](创新："包含"关系反转为"排斥/阻挡"——矩形不是被填充的目标，而是阻止其他操作进入的墙)

**来源原语**：fill + diagonal_pairing + pair_defines_rect (56ff96f3), grow + alternating_color + adjacent_gap (af726779), containment (868de0fa)

**依赖链**：同色像素对定义矩形 → 矩形被填充为该色 → 绿色种子开始四方向生长 → 生长在矩形边界处被阻挡。两个操作（填充矩形、种子生长）同时作用于同一网格，矩形的空间位置直接塑造了生长区域的形状——去掉矩形则生长无界，去掉生长则只有矩形。

同色像素对标记矩形对角并填充为该色，同时绿色种子向四方向交替色生长，生长在矩形边界处停止。

**输入结构**：黑(0)背景网格，约 14x14。网格中有 2-3 种颜色（从 {蓝(1), 红(2), 黄(4)} 中选取），每种颜色恰好出现 2 个孤立像素，位于不同行不同列。另有 1-2 个绿(3)的孤立种子像素。所有像素互不相邻（曼哈顿距离 >= 2）。生成约束：各色对定义的矩形互不重叠；种子像素不在任何矩形区域内；矩形不紧贴网格边缘（至少留 1 像素间距）。

**规则**：
1. 对每种出现恰好 2 次的颜色 C，取其两个像素为对角，填充以它们为对角的轴对齐矩形（包含边界）为颜色 C。
2. 对每个绿(3)种子像素，同时向上、下、左、右四个方向逐步生长。第 1 步涂品红(6)，第 2 步涂橙(7)，第 3 步涂品红(6)，以此类推交替。
3. 生长在某方向上遇到以下情况时，该方向停止（其他方向可继续）：遇到已填充矩形的边界像素（颜色为某个 C），或到达网格边缘。停止时不覆盖终点处的矩形像素或超出网格。
4. 若两个种子的生长路径在某像素相遇，先到达的保留（按步数，步数相同则按种子从左到右、从上到下的顺序优先）。
5. 完成后，擦除绿(3)种子像素本身（变为黑(0)）。

**关键洞察**：同色像素对构建的填充矩形不是谜题的输出重点——它们充当生长的物理屏障，使得每个种子的生长区域呈现被矩形切割后的不规则形状。矩形的位置和种子的位置共同决定了最终图案，两者缺一不可。
