## 新题 7：环形连接给出轮换方向，交叉遮挡深度决定轮换步数

**组合逻辑**：[环形连接](已有：确定框体顺时针序) × [遮挡顺序](创新：遮挡深度作为轮换步数，非固定 1 步) → [重涂色](创新：每个框体的掩码色独立轮换不同步数)

**来源原语**：环形连接(ring_connection)、顺时针轮换(clockwise_rotation)、空心方框(hollow_square)、连接线(connector_line)、内部遮罩(interior_mask) 来自 ad173014；遮挡顺序(occlusion_order)、交叉处可见性(crossing_visibility)、排序(sort) 来自 c920a713；重涂色(recolor) 来自 c920a713 / c7d4e6ad

**依赖链**：蓝色连接线将红色框体串成一个环，环的顺时针方向建立了颜色轮换的候选序列（哪个颜色排在哪个颜色之后）。同时，框体之间的边框交叉产生遮挡关系——框 F 被其他 D(F) 个框遮挡。D(F) 决定框 F 的内部掩码颜色向顺时针方向轮换多少步。环提供方向，遮挡提供步数——两个独立的图结构（无向环 + 有向遮挡图）作用于同一组节点，产生源题中都不存在的"变步长轮换"效果。

在环形连接的框体中，每个框的内部掩码颜色沿环的顺时针方向轮换，但轮换步数不固定——由该框被其他框遮挡的次数决定。

**输入结构**：黑(0)背景，约 22x22 网格。4 个空心红(2)正方形框（1 像素厚边框，每个约 6x6），通过蓝(1)线段两两连接成一个环（每个框恰好接触 2 条蓝连接线）。框体的位置使得部分框的边框线互相穿过（至少 2 对框存在交叉，但并非所有框都两两交叉）。每个框内部（除黑背景外）有一个小型彩色掩码图案，4 个框的内部掩码颜色互不相同，取自绿(3)、黄(4)、灰(5)、橙(7)。生成约束：蓝连接线不穿过任何框的内部区域，仅连接框的外边框像素；框体交叉处恰好一种颜色可见，产生明确的遮挡方向；每个框的遮挡深度 D（被多少个其他框遮挡）在 0-3 范围内，且至少两个框的 D 值不同。

**规则**：
1. 确定 4 个红色框的顺时针顺序：以 4 个框中心的几何重心为参考点，按各框中心相对于重心的极角从 0 度（正右方）顺时针排列，得到顺时针序列如 [F_a, F_b, F_c, F_d]。
2. 建立轮换色表 C = [F_a 的掩码色, F_b 的掩码色, F_c 的掩码色, F_d 的掩码色]。
3. 对每个框 F_i，统计遮挡深度 D(F_i)：在 F_i 的边框与其他框的边框交叉处，若他框颜色可见（即 F_i 被遮挡），则该他框对 F_i 贡献 1 点深度。D(F_i) = 遮挡 F_i 的不同框的数量（0-3）。
4. 对每个框 F_i，其掩码图案的形状和位置保持不变，但颜色更换为：在轮换色表 C 中，从 F_i 当前位置向顺时针方向数 D(F_i) 步，到达的颜色即为新颜色。若 D(F_i)=0，颜色不变。例如若 F_a 的 D=2 且 C=[绿, 黄, 灰, 橙]，则 F_a 的掩码从绿变为灰（顺时针跳 2 步）。
5. 红色框边框、蓝色连接线、背景和掩码内的背景孔洞保持不变。

**关键洞察**：源题 ad173014 中所有框的轮换步数都是 1（固定），而源题 c920a713 中遮挡顺序用于决定空间嵌套。本题中两个图结构（环形连接的循环图 + 遮挡关系的有向图）在框体节点上交叉——环提供"沿哪个方向找替换色"，遮挡提供"跳多远去取"。同一个框在环上的位置和在遮挡图中的深度完全独立，必须同时推断两者才能确定输出。
