## 新题 8：左面板滑动生孔洞射线，射线行选择右面板的逐行重涂色

**组合逻辑**：[滑动至分隔列](已有) → [孔洞触发射线](创新：射线不直接绘制到输出，而是生成行选择掩码) → [逐行重涂色](创新：射线行选择与行控制色配合，决定右面板哪些行的前景被重涂)

**来源原语**：滑动(sliding)、边缘对齐(flush_with_separator)、孔洞触发射线(hole_triggers_ray)、封闭区域(enclosed_region) 来自 6e453dd6；分隔列(separator_column)、面板(panel)、面板对应(panel_correspondence)、前景掩码(foreground_mask) 来自 bbb1b8b6；重涂色(recolor)、占位像素(placeholder_pixel)、行控制色(row_control_color)、每行独立取色(per_row_color)、同行对齐(same_row_align) 来自 c7d4e6ad

**依赖链**：左面板的黑色形状滑动至分隔列后产生封闭孔洞，孔洞所在的行被标记为"射线行"。这些射线行信息跨越分隔列作用于右面板：只有射线行上的蓝色前景像素会被重涂色，非射线行的蓝色像素保持不变。重涂使用的颜色来自右面板边缘的行控制色标记列——每个射线行有自己的控制色。左面板的几何结构（黑色形状 → 滑动后的孔洞位置）通过行选择机制，远程控制了右面板的颜色分布。

左面板中黑色形状滑向分隔列后形成的孔洞确定哪些行是"活跃行"，右面板中仅活跃行上的前景像素被替换为该行标记列指定的颜色。

**输入结构**：青(8)背景，约 15x25 网格。中央一条灰(5)竖直分隔列将网格分为左右两个等宽面板。左面板：2-3 个黑(0) 4-连通形状（各 6-12 像素，不规则但紧凑）位于面板左侧区域，与分隔列之间有若干列间距。这些形状内部可能包含青(8)背景像素形成的小孔洞（1-3 像素），但只有在形状滑动至分隔列后、与分隔列相邻的封闭青色区域才算"有效孔洞"。右面板：蓝(1)前景色的不规则掩码图案（4-连通，覆盖面板约 30-50% 的面积）。右面板最右侧一列为标记列：在此列中，部分行有一个红(2)或绿(3)像素作为该行的控制色标记，其余行为背景色。生成约束：左面板形状滑动后产生的有效孔洞行集合与右面板标记列中有控制色标记的行集合完全一致（即每个射线行恰好有一个控制色，无多余无遗漏）；右面板蓝色掩码在每个射线行上都至少有 1 个蓝色像素。

**规则**：
1. 将左面板每个黑(0)连通分量向右平移，直到其最右列像素与分隔列紧邻（即右边缘列 = 分隔列左侧一列）。平移保持形状不变，仅改变水平位置。
2. 滑动完成后，在左面板中识别封闭的青(8)区域：被黑色像素和分隔列共同包围、且至少有一个像素紧邻分隔列左侧一列的青色 4-连通分量。记录这些封闭区域覆盖的所有行号，称为"射线行"集合。
3. 在右面板中，对每个射线行 r：读取该行标记列中的控制色像素颜色 c_r（红(2)或绿(3)）。将右面板中第 r 行的所有蓝(1)前景像素重涂为 c_r。
4. 非射线行上的蓝(1)前景像素不变。标记列像素保留在原位。分隔列保留。左面板保持滑动后的状态（黑色形状已移至分隔列旁）。背景色青(8)不变。

**关键洞察**：左面板是"选择器"——它的几何形状通过滑动和孔洞机制生成行选择信号。右面板是"被操作对象"——它的蓝色掩码根据选择信号被逐行重涂。两个面板的信息在分隔列处耦合：左面板决定"哪些行参与变换"，右面板的标记列决定"变换成什么颜色"。改变左面板某个黑色形状的内部孔洞结构，会改变右面板中完全不同位置的像素颜色。
