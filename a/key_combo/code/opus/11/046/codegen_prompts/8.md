## 新题 8：反对角线色场由碎片合并仲裁冲突

**组合逻辑**：[填充/反对角线等值](用反对角线规律填充色场) ← [补全/合并对齐碎片](碎片合并组确定各反对角线的权威颜色)（反对角线规律不再从可见多数中恢复，而需要外部碎片信息仲裁冲突——两个源题的信息流方向完全重构）

**来源原语**：填充(4aab4007)、补全(8fbca751)、反对角线等值(4aab4007)、残缺矩形(8fbca751)、行列跨度重叠(8fbca751)、合并对齐碎片(8fbca751)

**依赖链**：色场中存在颜色冲突的反对角线（两种颜色各占一半），无法仅靠多数投票解决；碎片合并组的颜色提供权威答案。不合并碎片则冲突无法裁定，不填充色场则碎片信息无处使用。

在存在颜色歧义的反对角线色场中，利用散落碎片合并后的颜色信息裁定每条反对角线的正确颜色。

**输入结构**：约 14x14 网格。主体是一个反对角线色场：反对角线 d（定义为 row+col=d）上的像素本应全部同色，使用的颜色从蓝(1)、红(2)、绿(3)、黄(4)中循环。但有 2~4 条反对角线存在"冲突"——该对角线上恰好一半像素是一种颜色，另一半是另一种颜色（两种颜色各占约 50%，无法通过多数判定）。另外，网格中散布 3~5 个灰(5) 4-连通碎片（每个 2~4 像素）。生成约束：冲突的反对角线上，正确颜色恰好是其跨度范围内某个碎片合并组所使用的前景色（非灰非背景）；非冲突反对角线颜色唯一确定。

**规则**：
1. 识别色场中所有反对角线。对于无冲突的反对角线（所有像素同色），颜色已确定。
2. 对于有冲突的反对角线 d（两种颜色 A 和 B 各占约一半），需要外部信息裁定。
3. 找到所有灰(5) 4-连通碎片，按行跨度或列跨度重叠传递合并为组。
4. 对每个合并组，计算其边界框覆盖的反对角线范围 [d_min, d_max]（即 row+col 的最小值到最大值）。
5. 对于冲突反对角线 d，找到边界框覆盖该 d 值的碎片合并组。该组中碎片像素的非灰邻居中出现的颜色（在色场中与碎片像素 4-邻接的非灰像素的颜色）即为该反对角线的正确颜色。
6. 输出：将所有冲突反对角线上的错误颜色像素替换为正确颜色，灰(5)碎片像素本身也替换为其所在反对角线的正确颜色。

**关键洞察**：反对角线色场的"遮挡空洞"不再是黑色缺失值（可从同对角线可见像素恢复），而是颜色冲突（50-50 分裂）——必须借助外部碎片的空间位置信息来仲裁，碎片合并的跨度划定了仲裁管辖范围。
