## 新题 7：角 L 扩展画布后旋转闭合遇障碍截断

**组合逻辑**：[放大画布](角 L 确定扩展尺寸) + [旋转/四次旋转闭合](L 绕中心旋转四次) + [路径绘制/障碍截断](障碍像素截断旋转副本的臂)（源题中 L 变三角轮廓，这里 L 变旋转对称图形；障碍从路径转向机制变为几何截断机制——两个源题的核心操作在新的几何语境中交互）

**来源原语**：放大画布(e3f79277)、旋转(e40b9e2f)、角位边角(e3f79277)、旋转对称(e40b9e2f)、四次旋转闭合(e40b9e2f)、障碍像素(891232d6)、障碍决定转向(891232d6)、角位置对应(e3f79277)

**依赖链**：角 L 确定画布尺寸和旋转种子，旋转闭合生成四个臂，障碍截断修剪各臂长度。不扩展画布则无空间旋转，不旋转则无四臂结构，不处理障碍则输出错误。三步串联且障碍截断依赖旋转后的具体像素位置。

将输入角 L 扩展到更大画布并旋转四次形成十字对称图形，但障碍像素截断部分臂。

**输入结构**：约 7x7 正方形网格，背景黑(0)。蓝(1)像素形成一个一像素宽的 L 形，L 的两条臂紧贴网格的一个角（如左上角的第 0 行和第 0 列）。L 的每条臂长 3~5 像素。网格中另有 1~3 个红(2)障碍像素，不在 L 上，不在网格角点。生成约束：L 的两臂等长；障碍像素的位置在扩展画布后会落在某条旋转臂的路径上。

**规则**：
1. 识别蓝(1) L 形的角位置和臂长 k。
2. 创建边长 2k-1 的正方形输出画布（背景黑(0)）。画布中心为 (k-1, k-1)。
3. 将输入的 L 重新定位到输出画布的对应角（保持相对于角的位置不变）。
4. 将该 L 绕画布中心分别旋转 90、180、270 度，生成另外三条 L，均以蓝(1)绘制。四个 L 组合形成一个具有四重旋转对称的风车图形。
5. 将输入中的红(2)障碍像素按相同的画布坐标映射放置到输出画布（若输入为 7x7 而输出为 2k-1，则障碍坐标按比例 (2k-2)/(输入边长-1) 缩放取整后放置）。
6. 对每条 L 臂（从角点向中心方向逐像素遍历），若途中遇到红(2)障碍，则从障碍位置（含）开始截断该臂其余部分（涂回背景）。
7. 障碍像素本身保留红(2)在输出中。

**关键洞察**：L 不再生成三角形而是生成旋转对称风车，但该对称性被障碍破坏——求解者须同时推断旋转规则（对比无障碍示例）和截断规则（对比有障碍示例），两条规则共用同一几何框架却需独立归纳。
