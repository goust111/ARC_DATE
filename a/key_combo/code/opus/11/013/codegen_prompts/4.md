## 新题 4：周期推断与象限镜像扩展

**组合逻辑**：[补全/periodic_translation + 周期偏移延续行]（推断并补全缺失行） → [镜像/四向对称扩展/four_way_symmetric_expansion]（创新：先补全再镜像，补全错误会被镜像放大四倍）

**来源原语**：补全/周期平移/周期偏移延续行(参考题20 53b68214)、镜像/四向对称扩展(参考题3 833dafe3)

**依赖链**：输入只给出不完整的周期行图案（缺失下半部分）；必须先推断周期和水平偏移量并补全，才能得到完整的矩形图案；然后将完整图案作为右下象限进行四向镜像扩展。补全的正确性直接决定最终四倍面积输出的正确性。

将一个不完整的周期行图案先补全为完整方块，再以该方块为基础进行四向镜像扩展。

**输入结构**：约 5x10 的黑(0)背景网格（宽 10，高 5）。前景为黄(4)像素，分布在前 3~4 行中形成水平行图案，每行的黄色像素位置相对上一行有固定水平偏移（周期 = 2~3 行，每周期水平偏移 1~2 列）。最底部 1~2 行为纯黑（这是需要补全的缺失行）。生成约束：补全后的图案恰好形成 5x10 的完整矩形；水平偏移量和垂直周期可从已有行唯一确定。

**规则**：
1. 从已有的前景行中推断垂直周期 P 和每周期的水平偏移量 S：找到最小的 P 使得第 r 行的图案等于第 r-P 行的图案向右平移 S 列（超出右边界的像素从左侧环绕）。
2. 对每个缺失行 r（纯黑行），用第 r-P 行的图案向右平移 S 列生成，超出边界的像素环绕到另一侧。
3. 得到补全后的 5x10 矩形图案，将其视为右下象限。
4. 生成左下象限：对右下象限做左右镜像。
5. 生成右上象限：对右下象限做上下镜像。
6. 生成左上象限：对右下象限做上下+左右双镜像。
7. 输出为 10x20 的网格，四个象限拼合。

**关键洞察**：周期偏移的环绕特性使得镜像后在拼接边界处图案可能不连续——求解者必须正确处理环绕才能得到看起来"对"的四向对称结果。

  5. Derive input:
     a. Copy output canvas into input grid at chosen frame bbox position; replace each hole cell (non-frame_col) with bg to get the "hole appears as bg" input frame.
     b. Fill rest of input grid with bg.
     c. For each hole-shape with assigned color C_h and multiplicity m_h: scatter N_sprites (N_sprites = m_h + random extras, so chosen C_h is the plurality) sprite instances with that shape (optionally rotated/flipped) in color C_h; also scatter some other-color sprite instances of the same shape (in non-winning colors) so C_h is the MOST FREQUENT color for this shape.
     d. Optionally add 0-1 distractor sprites of a shape not matching any hole.
     e. Place all sprites outside the frame bbox, each with >=1 bg-cell separation from each other and from the frame bbox (Chebyshev). Reject-and-retry on collision.
