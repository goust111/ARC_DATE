## 新题 5：并集识别驱动的弹性拉伸目标选择

**组合逻辑**：[像素并集/pixel_union + 双掩码并集等三/two_union_eq_third]（识别哪个精灵体是并集结果） → [弹性拉伸/elastic_stretching + 按目标尺寸调整/resize_to_target]（创新：并集结果作为模板被拉伸填入目标矩形）

**来源原语**：像素并集/双掩码并集等三(参考题14 fea12743)、弹性拉伸/模板填充/按目标尺寸调整(参考题4 40f6cd08)

**依赖链**：必须先通过穷举配对找到哪两个精灵体的并集等于第三个，才能确定哪个精灵体是"模板"；模板确定后才能执行弹性拉伸填入目标矩形。并集关系的识别是拉伸操作的前提。

从多个等尺寸小精灵体中找出像素并集关系确定模板，然后将该模板弹性拉伸填入网格中的大矩形目标区域。

**输入结构**：约 18x18 的黑(0)背景网格。上半区包含 6 个红(2)色 4x4 精灵体区域，排列为 2 行 3 列，间隔 1 列/行的黑色间距。每个精灵体区域内有不同的红色掩码图案（2~8 个像素）。其中恰好存在两个精灵体 A、B，其掩码的像素并集恰好等于第三个精灵体 C 的掩码。下半区有一个较大的纯红(2)实心矩形（约 6x8 至 8x12 大小）。生成约束：并集关系唯一（不存在多组满足条件的三元组）；目标矩形的行数和列数均大于 4（保证拉伸有意义）。

**规则**：
1. 在上半区的 6 个 4x4 精灵体中，穷举所有三元组 (A, B, C)，找到唯一满足 mask(A) OR mask(B) = mask(C) 的组合，且 A 和 B 各自至少贡献一个 C 中没有的独占像素（即 A 不是 B 的子集，反之亦然）。当存在相同掩码的精灵体时，按行优先位置选择靠前的。
2. 将精灵体 C 的 4x4 掩码视为多色模板：A 独占的像素涂蓝(1)，B 独占的像素涂绿(3)，A 和 B 共有的像素涂黄(4)，空白保持黑(0)。
3. 对模板执行弹性拉伸以匹配目标矩形的尺寸：对行和列分别进行拉伸，边界行/列（第一行、最后一行、第一列、最后一列）保持 1 像素宽度不变，内部行/列均匀拉伸以填满目标尺寸。
4. 将拉伸后的多色图案写入目标矩形的位置，替换原有的纯红像素。
5. 上半区所有精灵体保持原样不变。

**关键洞察**：并集关系不仅决定了哪个精灵体被选为模板，还隐含了模板内部的颜色分区——A 独占区、B 独占区和重叠区形成三色分区，这个分区信息在拉伸后被保留到大矩形中。
