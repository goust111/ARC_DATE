## 新题 3：逐色自身镜像不对称标记

**组合逻辑**：[镜像/逐色独立变换](已有) + [逐像素比较](创新：比较对象从两个面板变为同一掩码的原始与镜像版本) → [差异标记](创新：方向性标记，区分上半多余和下半多余)

**来源原语**：镜像、单色掩码、包围盒、逐色独立变换、包围盒内翻转(e74e1818)；逐像素比较、差异标记、异或差异判定(34b99a2b)

**依赖链**：镜像变换生成参照基线 → 原始与镜像的逐像素比较产生三种状态（对称/上多余/下多余） → 每种状态映射到不同颜色。镜像定义了对称基准，若无镜像则无法判断"什么是对称的"；比较产出方向性差异，若无比较则输出仅为镜像结果（与参考题 e74e1818 相同）。

对每种前景色的掩码独立执行包围盒内垂直镜像，然后与原始掩码比较，输出一张不对称地图：对称部分保留原色，不对称部分按方向标记。

**输入结构**：黑(0)背景网格，约 12x12。包含 2~3 组前景色掩码，颜色取自 {红(2)、蓝(1)、绿(3)}。每组掩码由同色像素构成（可以 4-连通也可以分为多个连通体，但同色像素作为一个整体处理），每组约 8~15 个像素，散布在一个约 4x4 到 6x6 的包围盒内。各色掩码的包围盒互不重叠。每组掩码必须存在垂直不对称性（上下翻转后与原始不完全一致），即非完美垂直对称。生成约束：每组掩码至少有 2 个像素属于"对称部分"（原始与镜像重叠）、至少有 1 个像素属于"上半多余"（原始有镜像无）、至少有 1 个像素属于"下半多余"（镜像有原始无）。

**规则**：
1. 对每种非背景颜色 C，找到该颜色所有像素的包围盒（顶行 r0，底行 r1）。
2. 在包围盒内计算 C 的垂直镜像掩码：原始掩码中位于 (r, c) 的 C 像素，在镜像掩码中映射到 (r0 + r1 - r, c)。
3. 逐像素比较原始掩码与镜像掩码（仅在该色包围盒范围内）：
   - 位置同时在原始和镜像中有 C → 输出保持颜色 C（对称像素）。
   - 位置仅在原始中有 C、镜像中无 → 输出该位置为橙(7)（上半多余标记）。
   - 位置仅在镜像中有 C、原始中无 → 输出该位置为青(8)（下半多余标记）。
   - 位置在原始和镜像中都无 C → 保持黑(0)。
4. 所有颜色的包围盒之外的像素保持黑(0)。

**关键洞察**：输出不是简单的镜像结果，而是原始与镜像之间的"不对称地图"。对称部分保留原色证明对称性存在；橙(7)和青(8)的方向性标记揭示了不对称的具体位置和方向。求解者需要同时理解逐色包围盒镜像和方向性比较两个机制。

Reflect each foreground color mask vertically inside its own bounding box.

- Each foreground color is a glyph-like mask; it may be split under

Rule
- For each non-background color independently, find the mask's bounding box.

- The scene is not globally flipped; each colored mask is mirrored within its

## 实现要求

1. `main(grid)` 必须实现新题描述中的确定性转换规则，不能只识别 `generate_input()` 的固定模板。禁止不同的input网格输出相同的output网格。
2. `generate_input()` 必须随机生成多样样例，不能固定死。随机维度应覆盖：网格大小、对象数量、位置、颜色、方向、形状参数或关键分支。注意若描述中存在若干，需实现而不是只有单个，包括object或者对应关系等等。且若涉及到最短路径，则输入网格中必涉及到多条路径，对选择造成干扰。
3. 生成器必须保证输入满足 `main()` 的隐式假设：对象不重叠、不越界、特殊标记唯一或可区分、匹配关系无歧义、关键分支出现概率相同。
4. 禁止把 ARC 颜色 id 、亮度、拼写等当作人类不可见的数值语义参与排序、大小比较或隐藏映射。颜色变化必须有可见结构线索。注意颜色亮度、拼写等也是不可见信息，若描述中出现违规的颜色id或者亮度，可自行使用少量的固定颜色替代，但注意生成时要在三个以内输入输出网格中对所有变换100%覆盖度。
5. 输出样例要视觉清晰，人类必须能从输入输出对中肉眼辨认出规律。具体要求：避免对象粘连、覆盖关系混乱、同一像素多重语义；不同逻辑步骤产生的结果不要大面积层叠在一起导致无法分辨哪个颜色属于哪个步骤；输入中各元素之间保持足够间距，输出中新增的标记/填充/路径等应与背景和已有元素在颜色上有明显区分；若规则涉及多层叠加，生成时控制对象密度和尺寸，确保叠加区域只占少数像素而非铺满整个网格。
