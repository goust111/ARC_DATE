## 新题 4：导线长度调制令牌形状周期后填入腔室

**组合逻辑**：[传输](令牌经导线到达远端腔室) + [形状变换](创新：导线像素数对 3 取模推进形状周期) → [填充](变换后的形状图案填入目标腔室)

**来源原语**：传输、形状变换、线路网络、令牌、端点配对、形状循环映射 ← a47bf94d；填充、封闭腔室、格点骨架、标记指定腔室 ← 17b866bd

**依赖链**：导线的空间路由决定其像素数 L → L mod 3 推进形状周期 → 推进后的形状填入目标腔室。同一个令牌经不同长度的导线传输会产生不同形状，导线的几何布局隐式编码了变换参数。

将格点骨架腔室中的令牌图案通过导线传输到远端空腔室，导线长度（像素数）对 3 取模推进形状周期（实心→X→菱形→实心...），变换后的图案以令牌颜色填入目标腔室。

**输入结构**：约 20x20 黑(0)网格。青(8)格点骨架将网格划分为若干 3x3 的黑(0)封闭腔室（每个腔室被青色边框完全围合）。部分腔室内含有 3x3 令牌图案，共三种形态：实心块（9 像素全填）、X 形（4 角 + 中心共 5 像素）、菱形（中心 + 上下左右 4 个共 5 像素）。令牌颜色各异（红(2)、蓝(1)、绿(3)、黄(4)等），每个令牌颜色唯一。部分腔室为空（全黑）。青(8)单像素宽的导线路径（4-连通，沿骨架外侧或利用骨架自身通道）连接某些有令牌的腔室与空腔室，每条导线恰好两端各连接一个腔室。不同导线像素数不同（范围约 3-15 像素）。生成约束：每条导线恰连接一个有令牌腔室和一个空腔室；导线之间不共用像素；所有导线长度 mod 3 的值在示例间有变化。

**规则**：
1. 识别每条导线：从有令牌腔室边框出发，沿 4-连通青(8)像素（不属于任何腔室边框的青色像素）追踪到另一个腔室边框为止。统计导线本身的青色像素数（不含两端腔室边框像素），记为 L。
2. 形状周期定义为：实心 → X → 菱形 → 实心（步长为 3 的循环）。从源令牌当前形状出发，前进 (L mod 3) 步，得到目标形状。
3. 在导线远端的空腔室中，以源令牌的颜色绘制目标形状。
4. 源令牌保持原位不变。

**关键洞察**：导线不只是路由通道——它的物理长度隐式编码了形状变换量。同一个实心令牌经长度 4 的导线变成 X 形（前进 1 步），经长度 6 的导线仍是实心（前进 0 步）。求解者必须同时发现导线路由规则和长度取模规则，且只有对比不同长度导线的输出才能归纳出周期关系。

Paint yellow the background cells on the unobstructed shortest monotone corridor between two doorway frames.

Input structure
- The grid has a background, two small frame objects in one foreground color, and one center marker in each frame.
- Each marker has exactly one background 4-neighbor, the doorway gap; the next cell outward is the exterior doorway cell.

Rule
- Treat all existing foreground cells as blockers.
- Between the two exterior doorway cells, allow only row/column steps that move toward the other exterior cell.
- Paint every background cell that lies on some such path from one exterior cell to the other, plus the two doorway gaps, yellow.

Key insight
- The output is not a single chosen route: it is the union of all shortest monotone paths that can pass between the two frames.

Recolor each closed orthogonal line loop so convex bend pixels are yellow and concave bend pixels are red.

Input structure
- The grid has a dominant background and exactly one foreground color.

Rule
- Trace each cycle and inspect the turn at each foreground pixel.
