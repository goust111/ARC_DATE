## 新题 3：短轴分割线延伸切割背景后锚点洪泛

**组合逻辑**：[连线/draw_line](标记沿矩形短轴展开为分割线) → [连线延伸](创新：分割线穿出矩形进入背景通道) → [洪泛填充](被分割线切割后的背景区域中，含锚点的区域被洪泛)

**来源原语**：连线、标记像素、矩形区域、标记沿短轴展分割、包含 ← 855e0971；洪泛填充、分隔墙、四连通分区、角落锚定 ← 782b5218；背景通道 ← b7f8a4d8

**依赖链**：矩形短轴决定分割线方向 → 分割线延伸穿过背景通道 → 延伸后的分割线将背景切割为多个 4-连通区域 → 锚点所在的区域被洪泛填充。分割线的全局效果无法从其局部规则（短轴方向）直接预测，因为延伸路径取决于矩形外的背景布局。

将矩形内的标记像素沿矩形短轴展开为分割线，该分割线穿出矩形延伸到背景中，将背景切割为多个区域，包含锚点像素的区域被洪泛填充为锚点颜色。

**输入结构**：约 16x16 黑(0)背景。3-4 个互不重叠的单色实心矩形（蓝(1)、红(2)、绿(3)、黄(4)，每个至少 4x3 或 3x4 像素），散布在网格中，矩形之间有黑色背景间隙。其中 1-2 个矩形内各含一个灰(5)标记像素。网格的一个角落（如左下角）放置一个橙(7)单像素锚点，位于黑色背景中而非任何矩形内部。生成约束：各矩形之间的背景间隙宽度至少 2 像素；标记像素不在矩形边缘行/列上（以确保分割产生两个非空子区域）；灰色分割线延伸后确实将背景分为多个 4-连通区域（至少 2 个）。

**规则**：
1. 对每个含灰(5)标记像素的矩形：若矩形宽度 > 高度，过标记所在列画一条灰(5)竖线，跨矩形全高；若高度 > 宽度，过标记所在行画一条灰(5)横线，跨矩形全宽；若宽高相等，画竖线。灰线覆盖矩形内原有像素。
2. 每条灰色分割线从矩形边界处向两个方向延伸进入黑色背景，沿同方向（竖线向上和向下、横线向左和向右）逐像素前进，直到碰到非黑(0)像素或网格边缘时停止（不覆盖非黑像素）。延伸段也设为灰(5)。
3. 所有分割线绘制完毕后，将网格中剩余的黑(0)像素按 4-连通性分为若干区域。
4. 找到包含橙(7)锚点的那个 4-连通黑色区域，将该区域所有黑(0)像素填充为橙(7)（锚点本身已经是橙(7)，保持不变）。
5. 其余黑色区域、所有矩形、灰色分割线均保持不变。

**关键洞察**：分割线在矩形内的朝向由局部短轴规则决定，但延伸进背景后的切割效果取决于矩形相对于网格边缘和其他矩形的全局布局。一条看似水平的短分割线延伸后可能恰好封堵两个矩形之间的窄通道，彻底改变背景的连通性。需要多个示例才能分别发现短轴方向规则和延伸后的洪泛规则。
