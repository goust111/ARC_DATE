## 新题 10：双尺度网格叠加生成复合腔室后标记选填

**组合逻辑**：[生成网格](两个不同边长的实心方块各自生成一套网格线) → [透明叠加](创新：两套网格线叠加，交叉处细网格色优先) → [填充](标记像素指定腔室，洪泛填充所在腔室)

**来源原语**：生成网格、实心方块、网格线、边长决定间距、等距参数化 ← 695367ec；透明叠加、同尺寸对齐 ← 25e02866（改造：从矩形叠加变为网格线叠加）；填充、封闭腔室、标记像素、标记指定腔室 ← 17b866bd

**依赖链**：两个方块的边长决定两套网格线的间距 → 两套网格叠加时产生的交叉点改变了腔室的边界 → 标记所在的腔室形状取决于双网格的叠加结果。粗网格的大腔室被细网格的线切割为更小的子腔室，标记可能落在某个子腔室中——填充范围取决于两套网格的共同作用。

输入中两个不同尺寸和颜色的实心方块各自参数化生成一套等距网格线，两套网格叠加在同一画布上形成复合分区，然后将标记像素所在的封闭腔室洪泛填充为标记颜色。

**输入结构**：约 15x15 黑(0)背景。画布左上角区域放置两个不重叠的实心方块：一个蓝(1)方块（边长 s1，如 2）、一个红(2)方块（边长 s2，如 3），s1 < s2。两个方块在同一行或相邻行水平排列。此外，网格中散布 2-3 个绿(3)单像素标记，位于将要生成的双网格的腔室内部（不在任何即将生成的网格线上）。生成约束：s1 和 s2 互不整除（如 2 和 3），以确保两套网格不完全重合；绿色标记不位于任何网格线将经过的行或列上。

**规则**：
1. 对蓝(1)方块（边长 s1）：从行 s1 开始，每隔 s1+1 行画一条贯穿全宽的蓝(1)水平线；从列 s1 开始，每隔 s1+1 列画一条贯穿全高的蓝(1)垂直线。
2. 对红(2)方块（边长 s2）：同理，从行 s2 开始，每隔 s2+1 行/列画红(2)线。
3. 两套网格线叠加在同一 15x15 画布上。若某像素同时被两条线覆盖，使用边长较小的方块（细网格）的颜色（蓝(1)优先于红(2)）。
4. 擦除两个实心方块的原始像素（置为黑(0)），但若方块位置恰在网格线上，则保留网格线色。
5. 网格线将画布划分为若干封闭的矩形腔室（全黑区域，被网格线四面围合）。对每个绿(3)标记像素，找到包含它的腔室（该标记与腔室内其他黑像素 4-连通），将整个腔室（含标记本身）填充为绿(3)。
6. 不含标记的腔室保持黑(0)。

**关键洞察**：两套网格的间距互不整除时，叠加产生的腔室尺寸不均匀——粗网格的大腔室在某些位置被细网格线切割为更小的子腔室，在其他位置则保持完整。标记落在哪种腔室中（大的还是被切割后的小的）决定了填充面积，但这只有在理解双网格叠加机制后才能预测。
