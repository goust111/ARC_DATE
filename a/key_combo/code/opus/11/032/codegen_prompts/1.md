## 新题 1：轮廓滑行距离决定印章缩放

**组合逻辑**：[滑动](沿视线到达障碍后转为轮廓追踪) → [像素放大](追踪距离作为缩放因子) → [印章覆盖](缩放后的模板印在落点) + [擦除](清除原模板)

**来源原语**：滑动、轮廓邻接、最长贴边路径 ← 97c75046；像素放大、缩放对应、边长定缩放因子、模板 ← 447fd412；擦除 ← 17b866bd；标记像素 ← 多题共有

**依赖链**：标记的滑动落点由障碍形状决定 → 落点处的局部轮廓长度编码了缩放因子 → 缩放因子决定印章大小和印章位置的覆盖范围。障碍体同时充当运动屏障和缩放参数表，三者经由同一几何体紧耦合。

将彩色标记沿视线滑向障碍体，在落点处沿障碍外轮廓追踪，追踪距离决定模板的缩放倍率，最后将缩放后的模板印在落点位置。

**输入结构**：约 18x18 黑(0)背景。网格中有一个不规则的 4-连通灰(5)障碍区域（15-25 像素，非凸，含至少两处凹弯）。网格某角落放置一个小型蓝(1)模板图案（4-连通，3-6 像素，包围盒不超过 3x3）。2-3 个单像素彩色标记（分别为红(2)、绿(3)、黄(4)），每个标记恰好有唯一一个基数方向（上/下/左/右之一）到障碍边界的无阻挡视线。各标记互不同行同列。生成约束：每个标记的两个轮廓追踪方向产生的长度不相等，以避免平局；各标记落点互相间距至少为最大缩放倍率乘以 3。

**规则**：
1. 每个彩色标记沿其唯一的基数视线方向滑向障碍体，停在障碍体前最后一个黑(0)像素（即落点）。
2. 从落点出发，沿障碍体的外 4-邻接边界向两个方向（顺时针和逆时针）追踪。追踪时每步移动到下一个与障碍体保持 4-邻接的背景像素，直到无法继续（没有既是背景又与障碍 4-邻接的未访问邻居）。分别记两个方向的追踪步数为 L1 和 L2，取 k = max(L1, L2)。
3. 将蓝(1)模板中的每个像素放大为 k x k 的色块，以落点为放大后图案的左上角绘制，颜色使用该标记的原色。超出网格边界的部分裁掉。
4. 所有标记处理完毕后，擦除蓝(1)模板原始位置（置为黑(0)）。
5. 若两个缩放印章的像素重叠，k 值较大的覆盖 k 值较小的。k 值相同时，按标记距网格左上角的曼哈顿距离升序排优先级，距离近的在上。

**关键洞察**：障碍体的局部曲率在不同入射点产生不同的顺/逆时针轮廓段长度差异，使同一障碍体为每个标记编码不同的缩放因子——障碍体既是空间屏障，又是逐标记的缩放查找表。需要多个示例才能将轮廓追踪规则与缩放规则分别归纳。
