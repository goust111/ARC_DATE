## 新题 5：按标记数排序叠合后冲突像素挖洞

**组合逻辑**：[排序](按标记像素数决定叠合层序) → [透明叠加](灰底透明，标记不透明) → [擦除](创新：不同色标记冲突的位置挖为黑洞)

**来源原语**：排序、排列顺序、整块移动保持内容 ← f18ec8cc；透明叠加、填充矩形、共享底色、标记像素、同尺寸对齐、标记无冲突合并 ← 25e02866；擦除 ← 17b866bd

**依赖链**：标记数量决定排序 → 排序决定叠合顺序 → 叠合顺序决定哪些位置出现多色冲突 → 冲突位置被挖成黑洞。改变排序标准会改变冲突位置分布，从而改变最终图案——排序和冲突擦除通过叠合层序紧密耦合。

将多个同尺寸的灰底矩形按其标记像素数量升序排列后逐层叠合，标记像素覆盖下层，但任何位置如果被两种不同颜色的标记争夺过则挖为黑洞。

**输入结构**：约 12x18 黑(0)背景。3-4 个相同尺寸的矩形（如都是 5x4），每个矩形以灰(5)为底色，内含 2-4 个非灰标记像素（颜色从红(2)、蓝(1)、绿(3)、黄(4)中取，同一矩形内标记颜色可重复也可不同）。各矩形竖向排列，间隔至少 1 行黑色。每个矩形的标记总数互不相同。生成约束：至少存在 2 个位置（相对矩形左上角的坐标相同）在不同矩形中被不同颜色的标记占据，以产生冲突。

**规则**：
1. 统计每个矩形中非灰像素的总数。按总数升序排列矩形（最少的在底层，最多的在顶层）。若总数相同，按矩形左上角到网格左上角的曼哈顿距离升序排（距离近的在底层）。
2. 创建一个与矩形同尺寸的输出画布，初始填满灰(5)。
3. 按排序顺序从底层到顶层逐层叠合：每层中，非灰标记像素覆盖画布对应位置的当前内容。灰色像素透明（不改变画布）。同时记录每个位置被写入过的所有不同标记颜色。
4. 叠合完毕后，检查每个位置的颜色写入历史：若某位置被 2 种及以上不同颜色的标记写入过（无论最终显示哪种），将该位置置为黑(0)。
5. 输出仅为该合成矩形，原始多个矩形不保留。

**关键洞察**：排序将标记少的矩形放在底层，标记多的在顶层，这意味着顶层更容易覆盖底层——但覆盖不等于安全，被覆盖的冲突位置同样会被挖洞。求解者容易误以为顶层颜色总是最终结果，实际上冲突检测贯穿所有层。需要对比不同标记分布的示例才能发现冲突擦除规则独立于叠合优先级。
