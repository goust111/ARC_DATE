## 新题 4：异常象限叠加投射阴影

**组合逻辑**：[裁剪+异常值选择](从四象限中提取唯一图案) → [叠加](将提取图案放置到画布) → [偏移阴影+列环绕](前景像素产生带环绕的偏移阴影) + [处理顺序保护](原前景覆盖阴影)

**来源原语**：裁剪(88a62173)、异常值选择(88a62173)、输出唯一象限(88a62173)、叠加(337b420f)、偏移阴影(310f3251)、列环绕(310f3251)、处理顺序保护(9385bd28)

**依赖链**：异常象限选择确定图案内容 → 图案的具体像素位置决定阴影投射方向和环绕 → 阴影与原图案共存时需处理顺序保护。删除异常选择则无图案可投射；删除阴影规则则输出仅为裁剪结果（单逻辑）；环绕规则必须与阴影结合才能产生非平凡输出。

从四象限中找出唯一不同的图案，为其每个前景像素生成带列环绕的对角偏移阴影，原图案像素优先于阴影。

**输入结构**：约 11x11 的网格（奇数行列），中间行和中间列为黑(0)背景形成分隔十字，将网格分为四个 5x5 象限。三个象限包含相同的蓝(1)图案（3~7 个前景像素组成的 4-连通小图形），一个象限包含不同的蓝(1)图案（形状、像素数或位置不同）。生成约束：唯一象限的图案中至少有一个像素位于所在象限的最左列（以触发列环绕）。

**规则**：
1. 识别四个 5x5 象限，找出图案唯一（像素阵列不同于其他三个）的那个象限。
2. 裁剪出该唯一象限的 5x5 内容作为工作画布。
3. 对画布中每个蓝(1)前景像素在位置 (r, c)，在位置 (r-1, (c-1) mod 5) 生成一个红(2)阴影像素。即向上一行、向左一列，列方向在 5 格宽度内环绕（c=0 时环绕到 c=4）。
4. 若阴影位置的行号为负（r-1 < 0），则该阴影舍弃（不进行行环绕）。
5. 处理顺序保护：蓝(1)前景像素始终覆盖红(2)阴影。即若某位置同时是前景和阴影目标，保持蓝(1)。
6. 输出为 5x5 画布。

**关键洞察**：列环绕使得左边缘的像素阴影出现在右边缘，形成视觉上不连续的映射；必须理解环绕机制才能正确预测阴影位置。阴影方向（左上）和环绕规则需要对比多个示例才能确定。

## 实现要求

1. `main(grid)` 必须实现新题描述中的确定性转换规则，不能只识别 `generate_input()` 的固定模板。禁止不同的input网格输出相同的output网格。
2. `generate_input()` 必须随机生成多样样例，不能固定死。随机维度应覆盖：网格大小、对象数量、位置、颜色、方向、形状参数或关键分支。注意若描述中存在若干，需实现而不是只有单个，包括object或者对应关系等等。且若涉及到最短路径，则输入网格中必涉及到多条路径，对选择造成干扰。
3. 生成器必须保证输入满足 `main()` 的隐式假设：对象不重叠、不越界、特殊标记唯一或可区分、匹配关系无歧义、关键分支出现概率相同。
4. 禁止把 ARC 颜色 id 、亮度、拼写等当作人类不可见的数值语义参与排序、大小比较或隐藏映射。颜色变化必须有可见结构线索。注意颜色亮度、拼写等也是不可见信息，若描述中出现违规的颜色id或者亮度，可自行使用少量的固定颜色替代，但注意生成时要在三个以内输入输出网格中对所有变换100%覆盖度。
5. 输出样例要视觉清晰，人类必须能从输入输出对中肉眼辨认出规律。具体要求：避免对象粘连、覆盖关系混乱、同一像素多重语义；不同逻辑步骤产生的结果不要大面积层叠在一起导致无法分辨哪个颜色属于哪个步骤；输入中各元素之间保持足够间距，输出中新增的标记/填充/路径等应与背景和已有元素在颜色上有明显区分；若规则涉及多层叠加，生成时控制对象密度和尺寸，确保叠加区域只占少数像素而非铺满整个网格。
6. 若规则有多个分支，生成器不能长期固定成一个分支；应让分支在随机样例中合理出现。分支概率不必平均——难以发现的隐蔽分支（如少数情况下才触发的特殊规则）应适当提高出现概率，确保在 3 个训练示例中至少出现一次，否则求解者无法归纳该规则。对于颜色映射类规则，确保 2 个左右的示例即可覆盖所有映射关系（每种颜色→颜色的映射至少在某个示例中出现过）。
