## 新题 5：等差矩形补全与桥接连线

**组合逻辑**：[等差递推/补全](推断缺失矩形位置) + [同色配对/对向间隙](识别可桥接的矩形对) + [连线/最短间隙优先连](绘制桥接) + [画布裁切可见](边界截断)

**来源原语**：等差递推/补全/矩形边框笔画(f8c80d96), 同色配对/对向间隙/最短间隙优先连(f3b10344), 连线/桥接条(f3b10344), 画布裁切可见(f8c80d96)

**依赖链**：可见的实心矩形按等差序列排列但有缺失；补全逻辑推断出完整序列中所有矩形的位置和尺寸；补全后的矩形与原有矩形一起参与桥接配对判断；同色且对向间隙最短的矩形对之间绘制桥接线。补全的矩形可能被画布裁切。

先补全等差序列中缺失的矩形，再在所有同色矩形间用最短间隙桥接连线。

**输入结构**：约 20x20 的黑(0)背景网格。存在两种前景色（如蓝(1)和绿(3)）的实心矩形，每种颜色 2~4 个矩形（尺寸均为 2x3 或 3x2）。同色矩形的中心坐标沿某个方向构成等差数列（公差相同），但序列中有 1~2 个位置的矩形缺失。所有可见矩形互不重叠，且与网格边界之间至少有 1 像素间距。生成约束：补全后的矩形可能部分超出画布边界（此时只显示画布内的部分）；补全后同色矩形中至少存在一对在行跨度或列跨度上有至少 3 像素重叠且间隙全为背景的配对。

**规则**：
1. 对每种前景色，提取其所有矩形的中心坐标，推断等差数列的公差（行方向公差和列方向公差）。
2. 根据公差补全缺失位置的矩形（尺寸与同色可见矩形相同）。若补全矩形部分超出网格边界，只绘制画布内可见的部分。补全矩形颜色与同色组一致。
3. 在所有矩形（包括原有和补全的）中，对每种颜色独立进行桥接判断：找到同色矩形对中行跨度或列跨度重叠至少 3 像素且间隙内全为背景像素的配对。
4. 对每组同色矩形，从所有候选配对中选择间隙最短的那对进行桥接。桥接线用青(8)绘制，宽度为 1 像素，位于重叠跨度的中央行或中央列，长度恰好填满两矩形之间的间隙。
5. 若存在环路（三个矩形两两可桥接），只保留使总桥接长度最小的两条桥。
6. 保留所有矩形（含补全）和背景不变，仅在间隙中添加青色桥接线。

**关键洞察**：桥接的候选对象不仅包括输入中可见的矩形，还包括通过等差推断补全的矩形——如果只看可见矩形可能找不到合法配对，必须先完成补全才能确定哪些矩形可以桥接。
