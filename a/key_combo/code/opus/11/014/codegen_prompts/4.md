## 新题 4：旋转态编码平移方向

**组合逻辑**：[形状匹配/shape_match + 含旋转反射变换/includes_rotation_reflection](识别形状及其变换态) + [平移/translate + 颜色编码位移/color_encoded_disp](将位移编码方式从颜色改为旋转态，创新) → 匹配结果的旋转态作为平移指令

**来源原语**：形状匹配(898e7135/50f325b5), 含旋转反射变换(50f325b5), 平移(342dd610), 颜色编码位移(342dd610), 八方向匹配(898e7135)

**依赖链**：识别网格中与模板匹配的对象 → 确定每个对象相对于模板的旋转角度 → 旋转角度编码平移方向 → 每个对象按其旋转态指定的方向平移固定距离

[一句话总结：网格中散布同一图形的旋转副本，每个副本相对模板的旋转角度决定它的移动方向，所有副本同时平移]

**输入结构**：约 14x14 的黑(0)背景网格。左上角有一个由青(8)像素组成的不对称小图形作为模板（4~6 像素，4-连通，无旋转对称性）。网格其余区域散布 3~5 个红(2)像素组成的图形，每个都是该模板在 0/90/180/270 度旋转下的精确副本（仅旋转，不含反射）。各副本互不接触，与模板也不接触。生成约束：所有副本平移后仍在网格内且互不重叠；模板图形无旋转对称性（确保旋转态唯一可判）。

**规则**：
1. 识别左上角的青(8)模板图形（最小包围框内的形状）。
2. 对网格中每个红(2)连通图形，确定它是模板的哪个旋转态：0度（原始方向）、90度顺时针、180度、270度顺时针。
3. 按旋转态确定平移方向和距离：0度 → 向右平移 2 格；90度 → 向下平移 2 格；180度 → 向左平移 2 格；270度 → 向上平移 2 格。
4. 擦除每个红色图形的原始位置（恢复为黑色），在新位置绘制该图形（保持红色和旋转态不变）。
5. 青(8)模板保持原位不动。所有红色图形同时移动（不存在移动顺序依赖）。

**关键洞察**：位移指令不来自颜色（所有可动对象同色），而是隐藏在对象相对于模板的旋转角度中——求解者必须先识别模板、再判断旋转态、最后推断旋转-方向映射，三层推理缺一不可。
