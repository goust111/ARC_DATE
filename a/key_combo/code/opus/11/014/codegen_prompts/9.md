## 新题 9：重复色矩形射线相遇间隙分割

**组合逻辑**：[重复色才移动/repeated_color_moves](从识别移动对象改为识别射线发射者，创新) + [射线延伸/ray_extend](矩形向内射线) + [间隙对半分/gap_bisect + 奇数间隙留中线/odd_gap_midline](对射线间隙进行分割) + [贴边定位/border_aligned](保留边界矩形定位)

**来源原语**：重复色才移动(22208ba4), 贴边定位(22208ba4), 边界矩形(22208ba4), 射线延伸(d968ffd4), 间隙对半分(d968ffd4), 奇数间隙留中线(d968ffd4)

**依赖链**：识别哪种前景色出现多次（重复色） → 重复色矩形从各自贴边位置向网格内部射出射线 → 同轴相对的两条射线之间的间隙被对半分割各涂对应射线色 → 单例色矩形作为射线阻挡物

[一句话总结：贴边的重复色矩形各向内射出射线，两条相对射线之间的空隙对半分割并各涂半边，单例色矩形阻挡射线]

**输入结构**：约 13x13 的黑(0)背景网格。包含 4~5 个单色实心矩形（约 2x2 到 2x3），每个紧贴网格的某一边（上/下/左/右边缘）。其中一种颜色出现 2~3 次（重复色，如红(2)），其余颜色各出现一次（单例色，如蓝(1)、绿(3)）。生成约束：至少存在一对重复色矩形分别贴在相对的两边（如一个贴左边一个贴右边），且它们的行跨度有重叠；单例色矩形位于某对重复色矩形的射线路径上。

**规则**：
1. 统计各前景色的 4-连通对象数量，出现次数 >1 的颜色为重复色，出现次数 =1 的为单例色。
2. 每个重复色矩形从其不贴边的朝内面发射射线（与贴边方向相反），射线宽度等于矩形在垂直于射线方向上的跨度，颜色为该矩形颜色。
3. 射线逐格向内延伸，遇到以下情况停止：碰到任意非背景像素（包括单例色矩形或另一重复色矩形的射线），或到达网格对边。射线不含终止格。
4. 对于同一行带或列带上相向而行的两条重复色射线（来自贴相对边的同色矩形），它们之间的背景间隙进行对半分割：靠近左/上射线的一半涂为该射线颜色，靠近右/下射线的一半涂为另一射线颜色。若间隙像素数为奇数，正中间一行/列保持黑(0)背景。
5. 单例色矩形保持原位不变，其阻挡射线但不参与间隙分割。

**关键洞察**：重复色的身份判定（统计出现次数）是触发射线操作的前提，而单例色的功能从"不移动"变成了"射线障碍"——三层逻辑（身份判定 → 射线发射 → 间隙分割）严格顺序依赖，且奇偶间隙规则需要对比多示例才能确认。
