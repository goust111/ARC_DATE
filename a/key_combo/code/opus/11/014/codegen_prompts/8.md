## 新题 8：角落裁剪分象限翻转平铺

**组合逻辑**：[角落图案/corner_pattern + 裁剪/crop + 角落对应/corner_correspondence](保留角落提取) + [交替翻转平铺/alternating_reflections_tiling](从单一精灵平铺改为四个不同角落各自平铺，创新) + [画布加倍/canvas_doubling](输出尺寸约束)

**来源原语**：角落图案(bc1d5164), 裁剪(bc1d5164), 角落对应(bc1d5164), 交替翻转平铺(8d5021e8), 画布加倍(d13f3404), 镜像(8d5021e8)

**依赖链**：从输入四角裁剪出四个不同图案 → 输出画布为输入的两倍大小并分为四象限 → 每个角落图案在其对应象限内做交替镜像平铺填满该象限

[一句话总结：输入四角各有一个不同的小图案，输出是加倍画布，每个象限由对应角落图案通过交替镜像平铺填满]

**输入结构**：约 8x8 的黑(0)背景网格（高宽均为偶数）。四个角落各有一个由不同颜色构成的小图案（每个占据 2x2 的角落区域）：左上角用红(2)，右上角用蓝(1)，左下角用绿(3)，右下角用黄(4)。每个 2x2 区域内至少有 1 个像素为该颜色、其余为黑(0)（即图案是稀疏的，不一定填满 2x2）。四个角落图案形状互不相同。网格中央区域全为黑色。

**规则**：
1. 裁剪输入四角的 2x2 区域作为四个图案块：左上(TL)、右上(TR)、左下(BL)、右下(BR)。
2. 创建输出画布，尺寸为输入的 2 倍（16x16），分为四个等大象限（各 8x8）。
3. 对每个象限，用其对应角落图案进行 2x2 交替镜像平铺填满：
   - 将象限划分为 2x2 的子块网格（4x4 个子块）。
   - 子块行列坐标 (i,j)：i 为偶数且 j 为偶数时放原图案；i 为偶数且 j 为奇数时放左右镜像；i 为奇数且 j 为偶数时放上下镜像；i 为奇数且 j 为奇数时放 180 度旋转。
4. 左上象限用 TL 图案平铺，右上象限用 TR 图案平铺，左下象限用 BL 图案平铺，右下象限用 BR 图案平铺。

**关键洞察**：与单精灵平铺不同，四个角落各有独立图案且平铺规则相同但素材不同——求解者需同时推断"角落对应象限"的映射关系和"交替镜像"的平铺规则，单看一个象限无法确定规则是平铺还是其他变换。
