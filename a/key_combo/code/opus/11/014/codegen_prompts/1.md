## 新题 1：膨胀光晕阻断射线

**组合逻辑**：[膨胀/dilation](作用对象从单色标记变为多色标记，光晕色由标记色决定) + [射线延伸/ray_extend](射线方向由标记色编码) + [颜色决定方向/color_determines_direction](复用) → 光晕作为射线终止条件（创新：膨胀产物成为另一操作的空间约束）

**来源原语**：膨胀(4258a5f9), 射线延伸(d968ffd4), 颜色决定方向(9b4c17c4), 标记像素(4258a5f9), 光晕(4258a5f9)

**依赖链**：膨胀为每个标记生成光晕边界 → 光晕边界成为其他标记射线的终止墙 → 射线方向由标记颜色编码 → 最终输出是光晕 + 射线的叠加图，射线长度取决于标记间的空间关系

[一句话总结：每个彩色标记先膨胀出光晕，再沿颜色指定的方向射出射线，射线遇到任意其他标记的光晕边界即停止]

**输入结构**：约 15x15 的黑(0)背景网格。散布 3~5 个孤立的单像素标记，颜色为红(2)、蓝(1)、绿(3)、黄(4)中的若干种（每个标记恰好一个像素）。标记之间的曼哈顿距离至少为 5（保证光晕互不重叠）。生成约束：每个标记沿其颜色指定方向的路径上，至少存在一个其他标记的光晕可达范围内（保证射线不会全部飞出网格）。

**规则**：
1. 对每个标记像素，将其 3x3 邻域（裁剪到网格边界内）涂为灰(5)，标记自身保持原色不变。
2. 确定每个标记的射线方向：红(2)向右，蓝(1)向上，绿(3)向下，黄(4)向左。
3. 从每个标记中心出发，沿该方向逐格延伸射线，将路径上的黑(0)背景像素涂为该标记的原色。
4. 射线在以下任一条件下停止（不含终止格）：遇到灰(5)像素（即另一标记的光晕）、遇到非黑非灰像素、到达网格边界。
5. 所有标记的光晕先绘制完毕，再同时绘制所有射线。射线之间若交叉（同一像素被两条射线覆盖），按标记在网格中从左上到右下的扫描顺序，先扫描到的标记的射线优先。

**关键洞察**：膨胀不仅是视觉装饰，它产生的灰色光晕充当了射线的物理障碍——标记的间距和方位共同决定每条射线的长度，需要对比多个示例才能确认"射线遇光晕即停"这一规则。

Slide multi-color sprites to align their marker pixels with matching isolated border anchors.

Input structure:
