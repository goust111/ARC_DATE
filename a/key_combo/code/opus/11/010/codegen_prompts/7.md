## 新题 7：双印章叠加、控制矩阵裁决冲突

**组合逻辑**：[印章覆盖 stamping / 周期排布 periodic_layout]（创新：两个不同精灵体同时进行周期印章）+ [透明叠加 transparent_overlay / 逐像素对齐 cell_align]（创新：叠加两层印章结果）+ [索引映射 index_mapping / 控制矩阵 control_matrix / 按控制色重涂 recolor_by_control]（创新：控制矩阵不重涂既有对象，而是裁决两层叠加的冲突像素取哪一层的颜色）

**来源原语**：印章覆盖 stamping / 精灵体 sprite / 周期排布 periodic_layout（d304284e）；透明叠加 transparent_overlay / 逐像素对齐 cell_align / 并集取前景 union_foreground（d19f7514）；索引映射 index_mapping / 控制矩阵 control_matrix / 行列位置对应 row_column_correspondence / 按控制色重涂 recolor_by_control（33b52de3）

**依赖链**：两个精灵体各自周期印章生成两层前景图案，两层叠加产生冲突区域（均为前景的位置）。控制矩阵以周期格点的行列坐标为索引，指定冲突位置保留哪一层。三步缺一不可：不印章则无图案；不叠加则只有单层无冲突；无控制矩阵则冲突区域颜色不确定。

两个精灵体分别在网格上周期印章，叠加两层印章图案，在冲突位置（两层均有前景像素）用控制矩阵查表决定保留哪一层的颜色。

**输入结构**：约 16x16 的黑(0)背景网格。左上角紧贴的 2~3 行 x 2~3 列区域放置精灵体 A（蓝(1)色前景，含 3~5 个像素的不规则 4-连通形状）。紧邻精灵体 A 右侧（隔 1 列背景）放置精灵体 B（红(2)色前景，与 A 尺寸相同的边界框但形状不同）。网格右下角放置一个 PxQ 的控制矩阵（P = 纵向印章周期数, Q = 横向印章周期数），矩阵中每个像素为蓝(1)或红(2)，表示该格点位置冲突时保留哪个精灵体的颜色。生成约束：两个精灵体的边界框尺寸相同（如均为 3x3）；周期间距 = 边界框宽度 + 1（水平）和 边界框高度 + 1（垂直）；至少存在 3 个周期格点位置两层均有前景像素（即存在冲突）；控制矩阵中蓝和红均至少出现一次。

**规则**：
1. 以精灵体 A 的边界框左上角为起点，按水平间距（bbox 宽 + 1）和垂直间距（bbox 高 + 1）在整个网格上周期印章精灵体 A 的掩码，所有前景像素着蓝(1)色。超出网格部分裁剪。得到图层 L_A。
2. 以精灵体 B 的边界框左上角为起点，使用相同的水平和垂直间距周期印章精灵体 B 的掩码，所有前景像素着红(2)色。得到图层 L_B。
3. 初始化输出为黑(0)背景。对每个像素位置 (r,c)：
   - 若仅 L_A 有前景 → 输出蓝(1)
   - 若仅 L_B 有前景 → 输出红(2)
   - 若两层均有前景（冲突）→ 计算该位置属于哪个周期格点 (gi, gj)（gi = 行偏移 / 垂直间距，gj = 列偏移 / 水平间距，两个精灵体共享同一格点坐标系），查控制矩阵 (gi, gj) 处的颜色：蓝则保留 L_A，红则保留 L_B
   - 若两层均无前景 → 输出黑(0)
4. 擦除控制矩阵区域（替换为背景色）和原始精灵体区域中未被周期印章覆盖的部分。

**关键洞察**：冲突解决规则不是固定优先级（如"后画的覆盖先画的"），而是逐格点由外部控制矩阵指定——同一对精灵体在不同格点位置可以有不同的冲突裁决结果，这使得叠加输出呈现非均匀的图案。
