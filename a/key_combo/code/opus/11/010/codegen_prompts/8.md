## 新题 8：周期约束下的断线修复与噪声擦除

**组合逻辑**：[擦除 erase]（创新：擦除对象不仅是对角噪声，还包括不符合周期约束的孤立前景像素）+ [补线 line_completion / 间隙长度限制 gap_length_constraint]（创新：间隙填充不仅由局部连续性判断，还需全局周期一致性验证）+ [补全 complete / 周期平铺图案 periodic_tile / 被遮挡 occluded]（创新：周期性不用于填充被遮挡区域，而是作为线条修复的验证约束）

**来源原语**：擦除 erase / 对角噪声 diagonal_noise / 忽略干扰项 ignore_distractors / 间隙长度限制 gap_length_constraint（7b80bb43）；补线 line_completion / 直线段 straight_line_segment（7b80bb43）；补全 complete / 周期平铺图案 periodic_tile / 被遮挡 occluded（abbfd121）

**依赖链**：输入是一个由水平和垂直线条构成的周期网格图案，但被两种损坏破坏：(a) 对角线噪声像素添加在线条附近；(b) 部分线条段被擦除形成断口。修复过程中，擦除噪声依赖区分"属于周期线条图案的像素"和"不属于的噪声像素"；补线需要知道周期间距以确定哪些间隙应填充、填充到什么位置。周期性分析为两个操作提供共同约束：噪声判定和间隙填充都不能独立于周期结构完成。

擦除不属于底层周期线条图案的对角噪声像素，并依据周期间距修复线条中的断口。

**输入结构**：约 15x15 的黑(0)背景网格。底层结构是由蓝(1)色水平线和蓝(1)色垂直线构成的周期网格，水平线间距 h（3~5 行），垂直线间距 w（3~5 列），线条宽度 1 像素。该周期网格被两种损坏破坏：(a) 每条线上有 1~3 个断口，每个断口长度 1~3 像素（断口处像素被替换为黑色背景）；(b) 在断口附近及其他随机位置，添加了若干蓝(1)色对角噪声像素——这些像素不与任何蓝色线条正交相邻（4-连通），仅与其他蓝色像素对角相邻（8-连通但非 4-连通）。此外，还有 2~4 个蓝(1)色干扰像素，它们虽然与某条线 4-连通相邻，但出现在不符合周期间距的位置上。生成约束：断口不出现在线条交叉点；周期间距从未损坏的线条段可推断（至少有两条完整的水平线和两条完整的垂直线未被完全中断）；对角噪声像素总数 >= 3 以确保非空。

**规则**：
1. 从输入中识别所有蓝(1)像素的正交连通分量。长度 >= 3 且为纯水平或纯垂直的分量是可靠线段。
2. 从可靠线段推断周期间距：水平线的行坐标之间的最大公约数模式确定 h，垂直线的列坐标确定 w。
3. 擦除对角噪声：删除所有与线条仅对角相邻（无 4-连通蓝色邻居）的蓝色像素。
4. 擦除周期外干扰：删除所有位于不符合周期行坐标（对水平线）或周期列坐标（对垂直线）的蓝色像素。一个蓝色像素"符合周期"当且仅当它所在的行是某条水平周期线的行，或它所在的列是某条垂直周期线的列。
5. 补线：对每条周期线（由周期间距确定的所有应存在线条的行和列），扫描该行/列上的间隙（连续背景像素段）。若间隙长度 <= 3 且间隙两侧在该行/列上有蓝色像素，则用蓝(1)色填充该间隙。
6. 保留所有线条交叉点。

**关键洞察**：对角噪声和周期外干扰像素颜色与线条相同，仅凭局部连通性无法可靠区分——必须先推断全局周期间距作为判据，而周期间距的推断又需要先忽略噪声找到可靠线段。两步互为前提，形成引导式迭代而非简单的线性流水线。
