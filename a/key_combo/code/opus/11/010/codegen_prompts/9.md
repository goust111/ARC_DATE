## 新题 9：位移路径引导射线方向与端点裁剪

**组合逻辑**：[平移 translate / 端点编码位移 endpoints_encode_disp]（创新：位移向量不平移对象，而是编码射线方向）+ [射线延伸 ray_extend / 延伸至边界 extend_to_edge]（创新：射线起点和方向由位移路径决定而非固定为对角方向）+ [裁剪 crop / 包含 containment]

**来源原语**：平移 translate / 路径端点 path_endpoint / 端点编码位移 endpoints_encode_disp（2b9ef948）；射线延伸 ray_extend / 对角放射 diagonal_radiation / 延伸至边界 extend_to_edge / 孤立像素 isolated_pixel（ea786f4a, 2b9ef948）；裁剪 crop / 包含 containment（42f14c03, 890034e9）

**依赖链**：位移路径的两个彩色端点编码一个方向向量；从路径起始端点出发，沿该方向绘制射线至网格边界。多条路径产生多条射线。所有射线和端点的联合边界框裁剪为输出。若不解码路径位移，射线方向未知；若不画射线，裁剪区域无法确定（裁剪框由射线端点极值决定）。

解码每条灰色路径两端彩色端点的位移向量作为射线方向，从起始端点沿该方向画射线至网格边界，裁剪所有射线和端点的最小边界框。

**输入结构**：约 15x15 的黑(0)背景网格。网格中有 2~4 条独立的灰(5)色路径（每条路径是 4-连通的灰色像素链，宽度 1 像素，可弯折），每条路径的两个末端各连接一个彩色端点像素。每条路径的起始端点为绿(3)色，终止端点为黄(4)色（或统一地：每条路径两端颜色相同但不同路径颜色不同，从蓝(1)、红(2)、绿(3)、橙(7)中选取）。生成约束：每条路径的位移向量（从绿端点到黄端点的行列差）归一化后为 8 个罗盘方向之一（上、下、左、右、四个对角）；不同路径的归一化方向互不相同；从绿端点沿该方向画射线不会经过其他路径的像素；各路径互不相邻。

**规则**：
1. 识别每条灰(5)色 4-连通路径及其两个非灰端点。将颜色编号较小的端点定为起始端点，颜色编号较大的定为终止端点。（生成时保证每条路径两端颜色编号不同。）
2. 计算位移向量：从起始端点到终止端点的 (delta_row, delta_col)。将其归一化为单位步长方向 (sign(delta_row), sign(delta_col))，得到射线方向。
3. 从起始端点位置出发（包含起始端点自身），沿归一化方向每步走 1 格，用起始端点的颜色绘制射线像素，直到到达网格边界（最后一个仍在网格内的位置）。
4. 擦除所有灰色路径像素和终止端点像素。
5. 计算所有保留的非背景像素（射线像素 + 起始端点）的最小边界框，裁剪该区域作为输出。

**关键洞察**：灰色路径的弯折走向是干扰信息——真正有用的只有两个端点的相对位置差；路径的存在是为了在视觉上混淆方向判断，迫使求解者提取端点坐标而非追踪路径形状。
