## 新题 2：旋转对称补全像素作为射线源点

**组合逻辑**：[对称补全(symmetry_completion)](检测缺失臂并填充) → [射线延伸(ray_extend)](创新：补全像素成为射线起点，方向由对称中心决定)

**来源原语**：对称补全(symmetry_completion) ← 1b60fb0c；射线延伸(ray_extend) ← 13713586/25d487eb；旋转对称(rotational_symmetry) ← 1b60fb0c；方向指示(direction_indication) ← 25d487eb

**依赖链**：旋转对称分析确定哪些像素缺失 → 补全像素的位置决定射线的起点 → 补全像素相对于对称中心的方位决定射线方向。不完成对称分析就无法知道射线从哪里出发、往哪里延伸。

识别旋转对称缺失臂，补全后的新像素自动成为向外辐射射线的发射点。

**输入结构**：约 13x13 黑(0)背景网格。中心区域有一个蓝(1)像素组成的图案，该图案具有 4 重旋转对称性（绕中心旋转 90 度自重合），但恰好缺少一个方位的"臂"（约 3-5 个像素的连通区域）。完整的三个臂从中心向外延伸 3-4 格，呈辐射状。缺失臂对应的位置为黑(0)背景。整个蓝图案约 12-20 像素，对称中心在网格的大致中心。对称中心到网格边缘的距离至少为 5 格（确保射线有足够延伸空间）。

**规则**：
1. 确定蓝(1)图案的旋转对称中心（所有蓝像素集合在 90 度旋转下与自身最大重合的中心点）。
2. 将现有蓝像素顺时针旋转 90 度；旋转后落在黑(0)位置的像素即为缺失的补全像素，将这些位置标记为红(2)。
3. 对每个红(2)补全像素，计算它相对于对称中心的方向向量（行偏移 dr, 列偏移 dc）。
4. 将方向向量归一化为单位步长（dr 和 dc 各自取符号值 -1/0/+1），得到射线方向。
5. 从每个红像素出发，沿该方向逐格延伸射线，将路径上的黑(0)像素涂为红(2)，直到到达网格边界（最后一个涂色像素为边界行/列上的像素）。
6. 射线遇到非黑像素（蓝(1)或已有红(2)）时停止，不覆盖该像素。
7. 原始蓝(1)像素保持不变。

**关键洞察**：补全像素承担双重角色——它既是对称修复的结果，又是射线延伸的源头。射线方向无需额外标记指示，而是由补全像素自身在对称结构中的径向位置隐式编码。
