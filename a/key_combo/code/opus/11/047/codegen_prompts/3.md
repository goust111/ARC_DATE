## 新题 3：分区数决定外推步数后嵌套放置

**组合逻辑**：[计数(counting)](统计框架内部分区数) → [序列外推(sequence_extrapolation)](创新：分区数作为外推步数参数) → [嵌套放置(nest_inside)](将外推结果放入对应框架)

**来源原语**：计数(counting) ← 1190e5a7；序列外推(sequence_extrapolation) ← 351d6448；嵌套放置(nest_inside) ← 8698868d；分隔栅格(divider_grid) ← 1190e5a7；面板帧(panel_frame) ← 351d6448；空心框架(hollow_frame) ← 8698868d；恒定偏移平移(constant_offset_translation) ← 351d6448

**依赖链**：框架内部的分隔栏数量决定要外推多少步 → 动画序列被外推到第 N 帧 → 第 N 帧的精灵图案被放入提供 N 值的那个框架内部。三步操作形成参数化循环：结构属性→运算参数→结果放回同一结构。

每个空心框架内部的横隔栏数量告诉你动画要往前推几帧，推出的那帧精灵放回该框架。

**输入结构**：约 20x14 黑(0)背景网格，由一条灰(5)竖直满列分隔为左右两区。左区（约 20x5）：4 个等高小面板纵向堆叠，面板间由灰(5)满行分隔；每个面板约 4x5，内含一个绿(3)小精灵（3-4 像素的 4-连通形状），精灵在各面板中沿固定方向逐帧平移 1 格（如每帧右移 1 列），背景为黑(0)。右区（约 20x8）：2-3 个蓝(1)空心正方形框架（外框尺寸 6x6，边框 1 像素厚，内部 4x4），框架竖直排列互不重叠。每个框架内部有 0-3 条橙(7)满宽横隔栏（宽 1 像素，横跨框架内部 4 列）。不同框架的横隔栏数量互不相同。生成约束：动画序列的外推方向和步长保证在最大所需步数内精灵不会超出面板尺寸。

**规则**：
1. 识别左区的动画序列：从上到下 4 帧，推断绿精灵的逐帧平移向量（行偏移, 列偏移）。
2. 对右区每个蓝框架，统计其内部橙(7)横隔栏的数量 N。
3. 将动画序列从第 4 帧继续外推 N 步，得到第 (4+N) 帧的精灵位置和形状。
4. 将外推得到的精灵（保持绿(3)色和原始形状）放置到对应框架的内部区域中心（精灵 bounding box 中心对齐框架内部区域中心，若无法精确居中则偏左上）。
5. 放置精灵时，擦除该框架内部的所有橙(7)横隔栏（变为黑(0)）。
6. 灰分隔线、蓝框架边框、左区内容保持不变。

**关键洞察**：框架的内部结构（隔栏数量）不是装饰性特征，而是编码了一个运算参数——它决定了动画要向未来推演多远。这使得同一个动画序列对不同框架产生不同的嵌套结果。
