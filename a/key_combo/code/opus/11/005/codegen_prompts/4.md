## 新题 4：标记连线构建瓦片驱动像素放大

**组合逻辑**：[连线](同行列标记对之间填充连线) → [像素放大](连线结果作为多色瓦片，放大控制精灵)

**来源原语**：连线、标记像素、线段、同行列对齐、相邻标记间填充（dbc1a6ce）；像素放大、控制精灵、多色瓦片、掩码映射、像素展开为瓦片（bf45cf4b）

**依赖链**：像素放大所需的多色瓦片在连线完成前不存在——连线的拓扑结构（标记的位置与对齐关系）完全决定了瓦片的图案；跳过连线则无瓦片可用，跳过放大则连线无用武之地。

将对齐的蓝色标记用青色线段连接形成多色瓦片，再用该瓦片对一个单色控制精灵进行像素放大。

**输入结构**：约 18x18 至 25x25 的黑(0)背景网格，分为两个不重叠区域。区域一（如左上角）：3~5 个蓝(1)标记像素，部分标记在同一行或同一列上形成可连接的对（至少 2 对）。标记的最小包围框为正方形，边长 S 在 3~5 之间。区域二（如右下角）：一个单色矩形控制精灵（如红(2)），带有若干黑(0)背景孔洞，高度和宽度各在 3~6 之间。两个区域之间至少间隔 2 行 2 列的背景。生成约束：标记包围框内的连线结果不会填满整个包围框（至少有一半像素保持黑(0)背景）。

**规则**：
1. 在同一行中，将所有蓝(1)标记按列坐标排序，相邻标记之间的背景像素涂为青(8)。在同一列中，将所有蓝(1)标记按行坐标排序，相邻标记之间的背景像素涂为青(8)。若某位置同时被行连线和列连线涂色，保持青(8)。
2. 提取蓝(1)标记的最小包围框（S x S），该包围框内的图案（蓝标记 + 青连线 + 黑背景）即为多色瓦片 T。
3. 提取控制精灵的最小包围框，记为 H x W。
4. 构建输出网格，尺寸为 (H x S) 行 x (W x S) 列。
5. 遍历控制精灵每个像素位置 (r, c)：若该位置为前景色（非黑(0)），将瓦片 T 的完整副本写入输出中对应的第 (r, c) 块（每块大小 S x S）；若该位置为黑(0)背景，则对应块全部填黑(0)。
6. 输出中不保留原始标记区域和控制精灵的未放大版本。

**关键洞察**：瓦片不是预先给定的固定图案，而是由标记的空间对齐关系"构造"出来的——改变标记的相对位置就完全改变瓦片图案，进而改变放大结果的每一个细节。
