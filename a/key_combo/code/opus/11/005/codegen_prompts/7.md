## 新题 7：同色精灵计数决定连通分量重涂色与印章内容

**组合逻辑**：[计数 + 同色匹配](统计各色精灵数量) + [排序](灰色连通分量按面积降序) → [重涂色](按排名与计数排名交叉映射分配颜色) + [印章覆盖](对应色精灵印入分量包围框)

**来源原语**：计数、同色匹配、图案精灵体（8f215267）；排序、连通分量、重涂色、高度排名映射颜色（08ed6ac7）；印章覆盖、像素到块映射（5b6cbef5）

**依赖链**：重涂色需要面积排序结果和计数排序结果的交叉对应（面积排名第 k 的分量获得计数排名第 k 的颜色）；印章内容取决于重涂后分配的颜色（该色对应的精灵图案）；若跳过计数则无颜色分配依据，跳过排序则无分量排名，跳过印章则重涂色后的分量内部无图案。三个来源的信息汇聚为最终输出。

统计散落精灵的颜色分组数量，按数量排名与灰色分量的面积排名对应，将精灵印入对应分量。

**输入结构**：约 20x20 至 25x25 的黑(0)背景网格。包含 3~4 个灰(5)连通分量（4-连通），形状不规则（非矩形），面积互不相同，各在 8~25 像素之间，分量之间互不相邻。另散布若干小型单色精灵（4-连通，3~5 像素，形状不规则），共使用 3~4 种非灰非黑颜色（如蓝(1)、红(2)、绿(3)、黄(4)），每种颜色的精灵数量互不相同且至少为 1。同色精灵形状完全相同。不同色精灵形状不同。精灵不与灰色分量相邻。灰色分量数量等于精灵颜色种类数量。

**规则**：
1. 识别所有灰(5)连通分量（4-连通），按像素数降序排列，得到分量序列 C1, C2, ..., Ck（C1 最大）。
2. 识别所有非灰非黑的小型精灵，按颜色分组。统计每种颜色的精灵数量，按数量降序排列颜色，得到颜色序列 color1, color2, ..., colork（color1 对应数量最多的颜色）。
3. 面积排名第 i 的分量 Ci 被分配颜色 colori：将 Ci 的所有灰(5)像素重涂为 colori。
4. 对每个重涂后的分量 Ci：取该颜色 colori 对应的精灵图案（任一同色精灵的形状），将精灵图案印入 Ci 的包围框左上角对齐位置。精灵图案中前景像素涂为黑(0)（在重涂色背景上形成"镂空"标记），背景像素不改变分量颜色。若精灵图案超出分量包围框则裁剪。
5. 从网格中擦除所有原始小型精灵（恢复为黑(0)背景）。
6. 保留所有其他像素不变。

**关键洞察**：精灵数量不是直接用于"在框内画点"（与参考题 8f215267 不同），而是作为排名依据与面积排名交叉映射——数量最多的颜色被分配给面积最大的分量，形成双排序对应关系，这在任何单道参考题中都不存在。

## 实现要求

1. `main(grid)` 必须实现新题描述中的确定性转换规则，不能只识别 `generate_input()` 的固定模板。禁止不同的input网格输出相同的output网格。
2. `generate_input()` 必须随机生成多样样例，不能固定死。随机维度应覆盖：网格大小、对象数量、位置、颜色、方向、形状参数或关键分支。注意若描述中存在若干，需实现而不是只有单个，包括object或者对应关系等等。且若涉及到最短路径，则输入网格中必涉及到多条路径，对选择造成干扰。
3. 生成器必须保证输入满足 `main()` 的隐式假设：对象不重叠、不越界、特殊标记唯一或可区分、匹配关系无歧义、关键分支出现概率相同。
4. 禁止把 ARC 颜色 id 、亮度、拼写等当作人类不可见的数值语义参与排序、大小比较或隐藏映射。颜色变化必须有可见结构线索。注意颜色亮度、拼写等也是不可见信息，若描述中出现违规的颜色id或者亮度，可自行使用少量的固定颜色替代，但注意生成时要在三个以内输入输出网格中对所有变换100%覆盖度。
