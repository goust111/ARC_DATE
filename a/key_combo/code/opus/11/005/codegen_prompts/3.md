## 新题 3：转向路径分段按长度排名重涂色

**组合逻辑**：[射线延伸 + 转向](沿控制点转弯描绘路径) → [排序](路径分段按像素长度降序) → [重涂色](按排名分配颜色)

**来源原语**：射线延伸、转向、路径、起点像素、转向控制点、视线方向、颜色决定转向（e5790162）；重涂色、排序、连通分量、高度排名映射颜色（08ed6ac7）

**依赖链**：分段只有在路径完全追踪后才能确定长度；长度排名决定颜色分配；若跳过路径追踪则无分段可排，若跳过排序则无法确定颜色。路径的转弯方向由控制点颜色决定，改变一个控制点颜色就改变所有后续段的长度和数量。

追踪一条在控制点处转弯的路径，然后按各段长度排名分配不同颜色。

**输入结构**：约 15x15 至 20x20 的黑(0)背景网格。恰好一个绿(3)起点像素。散布 3~6 个转向控制点像素：品红(6)表示右转，青(8)表示左转。起点像素沿恰好一个基本方向（上/下/左/右）的视线内可见一个控制点（即该方向上第一个非背景像素是一个控制点）。控制点的摆放保证路径在出网格前至少转弯 3 次，产生至少 4 个段。各段长度互不相等。生成约束：路径不会经过任何控制点所在的像素（路径在到达控制点前一格转弯）。

**规则**：
1. 从绿(3)起点出发，沿其唯一可见控制点的方向开始移动。将起点本身计为第一段的第一个像素。
2. 沿当前方向逐像素前进，将经过的背景像素涂为当前段的颜色（初始为绿(3)，后续会被重涂）。
3. 当下一个像素是品红(6)控制点时，不覆盖该控制点，方向顺时针旋转 90 度，开始新的一段。当下一个像素是青(8)控制点时，不覆盖该控制点，方向逆时针旋转 90 度，开始新的一段。
4. 当下一步超出网格边界时路径终止。
5. 统计每段的像素数（含起始位置像素，不含控制点）。按像素数降序排列。
6. 按排名重涂色：最长段涂蓝(1)，第二长涂红(2)，第三长涂绿(3)，第四长涂黄(4)，若有更多段依次涂灰(5)、品红(6)（跳过已被控制点使用的品红(6)和青(8)——若排名对应的颜色恰好是品红(6)或青(8)，则跳过该颜色继续取下一个）。
7. 所有控制点像素保持原色不变。起点像素随其所在段一起重涂。

**关键洞察**：重涂色调色板必须跳过控制点使用的品红(6)和青(8)以避免歧义——这条规则不显然，需要在多个示例中观察到排名颜色"跳跃"才能归纳。
