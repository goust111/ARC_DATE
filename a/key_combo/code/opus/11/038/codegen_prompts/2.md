## 新题 2：射线探测互补形状并填充缺口

**组合逻辑**：[ray_extend](从源形状的发射器向左延伸探测射线，原用于绘制可见线条，此处用作空间搜索探针，不留痕迹) + [shape_match/complementary_shape](射线碰到模板时执行形状互补测试，原为静态配对，此处由射线动态触发) -> [fill](互补匹配成功时将源形状颜色填入模板缺口)

**来源原语**：ray_extend(参考题2 ac3e2b04, 参考题17 bdad9b1f), shape_match/complementary_shape/unique_complement(参考题12 18447a8d), template_gap/source_shape(参考题12), fill(参考题12), marker_pixel(参考题3, 13, 15)

**依赖链**：发射器的位置和方向决定射线扫过哪些模板 -> 射线在每个模板处触发互补形状测试 -> 测试结果决定射线是停止并填充还是穿透继续 -> 填充操作将源颜色写入匹配的模板缺口。射线提供搜索路径，互补测试提供匹配判据，填充完成变换——三者在"射线碰撞时测试、通过则停止"这一决策点紧密耦合。

从源形状发出的探测射线沿途检查模板的缺口形状，仅在互补匹配时停止并将源颜色填入缺口。

**输入结构**：约 18x18 的网格。黑(0)背景。左侧区域（约前 5 列）放置 2~3 个模板块，每个模板块是一个单色矩形区域（如蓝(1)、灰(5)、品红(6)，每个模板颜色不同），内部包含一个 3~5 像素的不规则 4-连通背景色(黑(0))缺口（即模板矩形中被扣除的部分）。右侧区域（约后 5 列）放置等数量的源形状，每个源形状是 3~5 像素的 4-连通单色图形（如红(2)、绿(3)、黄(4），每个源形状颜色不同），且每个源形状的最左列有一个紧邻的橙(7)发射器像素（与源形状在同一行、位于源形状左侧一列）。中间区域为空白黑(0)走廊。生成约束：每个源形状（平移归一化后）恰好与一个模板缺口（平移归一化后）形状相同，形成唯一配对；不同模板的缺口形状互不相同。

**规则**：
1. 对每个橙(7)发射器像素，从其位置向左逐列延伸一条不可见射线（不绘制任何像素）。
2. 当射线进入某个模板块所占的列范围时，将该发射器对应的源形状与该模板的缺口进行互补测试：将源形状和缺口分别平移使其最小边界框左上角对齐原点，比较二者像素集合是否完全相同。
3. 若匹配成功：将模板缺口内的黑(0)像素重涂为该源形状的颜色；擦除原位置的源形状和发射器像素（置为黑(0)）；该射线终止。
4. 若匹配失败：射线穿过该模板继续向左搜索下一个模板。
5. 若射线到达网格左边界仍未找到匹配，源形状和发射器保持不变。
6. 多条射线之间互不干扰。处理顺序为从上到下（按发射器像素的行号），行号相同时从左到右。

**关键洞察**：射线不仅仅是连接线，而是逐模板扫描的空间搜索器——源形状可能跳过不匹配的模板，继续向左寻找真正互补的目标。射线碰撞只是候选，互补测试才是决策点。
