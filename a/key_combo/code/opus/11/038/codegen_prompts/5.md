## 新题 5：对称补全揭示隐藏连接端点

**组合逻辑**：[symmetry_completion/infer_missing_from_three](在 2x2 格元块中从三个已知精灵推断第四个，原为最终输出，此处推断结果仅为中间步骤) + [connect/same_row_col_align](在所有标记像素之间按同行同列规则连线，原为已知标记间的操作，此处连接对象包含推断出的新标记) -> [recolor/crossing_cell_marked_new_color](两条不同偏移的连接线交叉时将交叉像素重涂为特殊颜色)

**来源原语**：symmetry_completion/block_symmetry/infer_missing_from_three(参考题14 2546ccf6), lattice_cell/divider_line/sprite(参考题14), connect/same_row_col_align/local_offset_preserved(参考题20 cbded52d), separated_tile_lattice(参考题20), crossing/crossing_cell_marked_new_color(参考题17 bdad9b1f), recolor(参考题17)

**依赖链**：对称补全推断出缺失格元中的精灵，其中包含此前不可见的标记像素 -> 这些新标记与已有标记一起参与同行/同列连接规则 -> 连接线在某些格元内产生交叉 -> 交叉像素被标记为特殊颜色。对称补全是信息生成步骤（揭示隐藏标记），连接是信息传播步骤（基于完整标记集拓展结构），交叉标色是最终判定——跳过补全则标记集不完整、连接图案错误。

通过对称推断补全缺失格元中的精灵（含隐藏标记），然后用完整的标记集在格阵中建立同偏移连接线，交叉点标为特殊颜色。

**输入结构**：约 15x15 的网格。灰(5)色分隔线组成的网格将画布分为 3x3 阵列的等大矩形格元（每个格元内部约 4x4）。每个格元要么为空（全黑(0)），要么包含一个小精灵（2~4 像素的单色 4-连通图形）。精灵使用的颜色：蓝(1)、红(2)、绿(3)，每种颜色对应一个 2x2 格元块中的同色精灵组。在每个 2x2 格元块中，恰好 3 个格元有精灵、1 个为空；三个已知精灵是同一图案按其在 2x2 块中的位置做水平/垂直翻转后的变体。部分精灵的内部包含一个额外的橙(7)标记像素，位于格元内的特定局部偏移位置。生成约束：每个 2x2 块的对角精灵翻转后一致；推断出的第四个精灵也会在对应翻转位置包含橙(7)标记（如果对角精灵有标记的话）；至少存在两对同局部偏移的标记分布在同一格元行或列中，且至少一对包含推断出的标记。

**规则**：
1. 对每个 2x2 格元块，找到空格元。取对角位置的精灵，对其同时做水平和垂直翻转，将结果绘制到空格元中，颜色与对角精灵相同（包括其中的橙(7)标记像素也一并翻转放置）。
2. 补全所有空格元后，收集网格中所有橙(7)标记像素（含原有的和新推断出的）。对每个标记，记录其所在的格元行号、格元列号、以及在格元内的局部偏移 (lr, lc)。
3. 对于共享相同局部偏移 (lr, lc) 的标记组：若组内存在两个标记位于同一格元行（格元行号相同），则在它们之间的所有中间格元中，在相同局部偏移 (lr, lc) 处绘制橙(7)像素，形成水平连接线。同理处理同一格元列的标记对，形成垂直连接线。连接线仅绘制在格元内部的对应偏移位置，不覆盖分隔线。
4. 若在某个格元内，两条不同局部偏移的连接线都经过该格元（即该格元内有两个不同偏移位置都被连接线绘制了橙(7)像素），则将这两个像素中后绘制的那个（垂直连接线的像素）重涂为黄(4)。若同一格元内有超过两条线经过，所有交叉偏移位置的像素均重涂为黄(4)。

**关键洞察**：对称补全不是最终答案——它揭示了隐藏在空格元中的标记像素。这些推断出的标记参与后续的连接步骤，因此跳过补全会导致连接图案不完整。求解者必须先完成拓扑推断，才能看到完整的连接端点集合。

Complete each 2-by-2 lattice-cell quartet by adding its missing reflected sprite.

Input structure:
- The background is the most common color.
- One non-background color forms complete horizontal and vertical divider
  lines, partitioning the grid into rectangular cells.
- Every occupied cell away from the dividers contains pixels of exactly one

  inside a 2-by-2 block of equal-sized cells.

Rule:
- Split the grid at the divider rows and columns.
- For each three-cell monochrome group in a 2-by-2 cell block, find the one
  empty cell in that block.
- Reflect each of the three present cell-local sprites vertically and/or
  horizontally according to its relative position to the missing cell; all
  three reflections must produce the same mask.
- Paint that agreed reflected sprite into the missing cell, leaving dividers
  and all existing cells unchanged.

Key insight:
- The sprites are mirror variants around the center of a 2-by-2 block of
  lattice cells, so any three visible variants uniquely determine the fourth.
</description>

6. 若规则有多个分支，生成器不能长期固定成一个分支；应让分支在随机样例中合理出现。分支概率不必平均——难以发现的隐蔽分支（如少数情况下才触发的特殊规则）应适当提高出现概率，确保在 3 个训练示例中至少出现一次，否则求解者无法归纳该规则。对于颜色映射类规则，确保 2 个左右的示例即可覆盖所有映射关系（每种颜色→颜色的映射至少在某个示例中出现过）。
