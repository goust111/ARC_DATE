## 新题 3：标记数控制放大倍率后印章

**组合逻辑**：[计数](统计标记数) → [像素放大](创新：倍率由标记数决定而非色数) → [印章覆盖](创新：放大后的图案印到指定插槽)

**来源原语**：计数(counting) ← 4852f2fa；像素放大(pixel_upscale) ← d4b1c2b1；印章覆盖(stamp) ← 92e50de0；标记数等于副本数(marker_count_equals_copy_count) ← 4852f2fa；色数决定倍率(color_count_scale) ← d4b1c2b1；目标插槽(target_slot) ← 9f27f097

**依赖链**：标记像素的数量决定精灵体的放大倍率，放大后的精灵体尺寸必须恰好匹配目标插槽的尺寸才能正确印入。三个操作环环相扣：删除计数则不知倍率，删除放大则尺寸不匹配目标，删除印章则无最终输出。

统计散落标记的数量作为放大倍率，将精灵体放大后填入尺寸匹配的目标插槽。

**输入结构**：约 12x12 的网格，黑(0)背景上有三类元素：(a) 一个 2x2 或 3x3 的多色精灵体（由 2~3 种非背景色组成，颜色从蓝(1)、红(2)、绿(3)中选取），位于网格左上区域；(b) 若干个橙(7)单像素标记，散布在网格各处，数量为 2 或 3（即放大倍率为 2 或 3）；(c) 一个全黄(4)填充的矩形目标插槽，其尺寸恰好等于精灵体尺寸乘以标记数量（如精灵体 2x2 且标记数为 3，则插槽为 6x6），位于网格右下区域。生成约束：标记数量乘以精灵体边长恰等于目标插槽边长。

**规则**：
1. 识别精灵体（由非黑、非橙、非黄颜色组成的连通多色小图形）并裁剪其最小边界框。
2. 统计网格中橙(7)单像素标记的数量 N。
3. 将精灵体进行 N 倍像素放大：每个像素替换为 NxN 的同色方块。
4. 识别黄(4)填充的矩形目标插槽。
5. 将放大后的精灵体覆盖到目标插槽的位置（左上角对齐），替换掉黄色像素。
6. 橙(7)标记像素在输出中擦除为黑(0)背景。原始精灵体位置保持不变。

**关键洞察**：放大倍率既不由精灵体自身属性决定，也不由目标插槽直接标注，而由散落在网格各处的标记像素数量隐式编码——需要对比不同示例中标记数与输出尺寸的关系才能归纳。

<description>
Decode a block-grid image by swapping each sprite-coded cell with a solid cell and each blank cell with the sprite.

Input structure
The grid is partitioned by black separator rows and columns into equal-size
square blocks. Each block is either a copy of one two-color sprite or a
uniform blank block of the sprite's minority color; grey pixels are erased
cells that act as wildcards.

Rule
Infer the repeated sprite from fully visible mixed-color blocks. Replace a
block matching that sprite, ignoring grey erasures, with a solid block of
the sprite's majority color. Replace a uniform blank block with the sprite.
Separator rows and columns, including grey erasures on them, become black.

Key insight
The small sprite is a block-level code for one macro-cell state, and the
uniform minority-color block is the other state; the output renders the
opposite code in each macro-cell while cleaning erased pixels.
