## 新题 6：转向射线构筑墙壁后按封闭区域面积排序填色

**组合逻辑**：[射线延伸/ray_extend](已有) + [转向/turn](已有) ← [图例编码转向/legend_encodes_turn](已有) → 射线路径形成墙壁 → [洪泛填充/flood_fill](创新：填充目标不是预存区域而是射线动态构筑的新区域) ← [计数/counting](已有，创新：计数对象从封闭区域数变为面积值) + [排序/sort](已有，创新：排序依据从区域数变为面积，排序结果映射到固定色阶)

**来源原语**：射线延伸/ray_extend(e87109e9), 转向/turn(e87109e9), 图例编码转向/legend_encodes_turn(e87109e9), 发射源方块/emitter_square(e87109e9), 障碍块/obstacle_block(e87109e9), 碰撞停止/collision_stop(e87109e9), 计数/counting(89565ca0), 排序/sort(89565ca0), 洪泛填充/flood_fill(00d62c1b), 封闭区域/enclosed_region(00d62c1b/89565ca0), 仅填封闭内部/fill_enclosed_only(00d62c1b)

**依赖链**：图例编码转向规则 → 射线从发射源出发遇障碍转向 → 射线路径与障碍共同形成墙壁网络 → 检测被墙壁围合的封闭背景区域 → 计算每个封闭区域的面积（像素数） → 按面积升序排列 → 面积最小的区域填第一种色、次小填第二种色、依此类推。射线路径决定区域形状，面积排序决定填色，两者不可分离。

发射源发出的射线在障碍处转向后形成墙壁网络，将背景分割为若干封闭区域，再按区域面积从小到大依次填入固定色序。

**输入结构**：
- 网格约 18x18，背景黑(0)。
- 顶部 2 行为图例区，背景灰(5)：图例中有 2~3 个彩色竖条（各 1 像素宽、2 像素高），颜色与主网格中的障碍块颜色对应。每个竖条在其所占 1x2 列区域内的水平位置编码转向方向——竖条偏左（在左半列）→ 遇此色障碍时逆时针转 90 度；竖条偏右（在右半列）→ 顺时针转 90 度。
- 顶部图例下方为主网格，背景黑(0)。主网格中央有一个青(8)实心正方形（3x3），为发射源。
- 主网格中散布 3~5 个矩形障碍块（每个为 1x2 或 2x1 的单色色块），颜色取自红(2)、绿(3)、黄(4)中的 2~3 种。
- 生成约束：发射源的四条射线在有限次转向后均到达网格边缘或回到已有路径上终止（不产生无限循环）。射线路径与障碍至少围合出 2 个、至多 5 个互不相连的封闭背景区域。不同封闭区域的面积互不相等。

**规则**：
1. 读取图例：对每种障碍颜色，确定其竖条在图例中的水平偏向——偏左 → 逆时针 90 度，偏右 → 顺时针 90 度。
2. 从青(8)正方形的四条边各发出一条射线，初始方向分别为上、下、左、右。射线宽度为 1 像素，沿发射方向逐像素前进，将经过的黑(0)像素涂为青(8)。
3. 射线碰到非黑像素（障碍块、已有射线路径或网格边缘）时停止当前方向的前进。若碰到的是某颜色的障碍块像素，射线在碰撞点前一格停止，然后按该颜色在图例中的转向规则改变方向，从碰撞点前一格沿新方向继续前进。若碰到的是网格边缘或已有的青(8)射线像素，射线完全终止。
4. 所有射线终止后，找出被青(8)射线路径、障碍块和网格边缘共同围合的 4-连通黑(0)封闭区域（该区域的黑(0)像素无法通过 4-连通路径到达网格边缘而不穿过非黑像素）。
5. 计算每个封闭区域的面积（黑(0)像素数），按面积升序排序。
6. 按排序顺序依次填色：面积最小的区域填蓝(1)，次小的填红(2)，第三小的填绿(3)，第四小的填黄(4)，第五小的填品红(6)。（即使用固定色序 [1, 2, 3, 4, 6]。）
7. 输出中移除顶部图例区（输出网格高度比输入少 2 行）。所有青(8)射线路径和障碍块保留。

**关键洞察**：射线路径是由转向规则动态构筑的，而转向规则编码在图例中——图例改变意味着射线路径完全不同，从而封闭区域的形状和面积全部改变，填色也随之变化；整条推理链从图例解码开始，到面积排序结束，任何中间环节的错误都会传递到最终填色。
