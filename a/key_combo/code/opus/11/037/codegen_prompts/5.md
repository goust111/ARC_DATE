## 新题 5：帧序列双重外推——位置外推与标记色循环外推联动内部重涂

**组合逻辑**：[外推/extrapolate](已有) ×2（创新：同时外推空间位移和颜色循环两个独立序列） + [重涂色/recolor](已有，创新：重涂范围由邻域全包含条件确定，重涂颜色由外推的标记色决定）← [邻域全包含/full_neighborhood_inside_component](已有)

**来源原语**：外推/extrapolate(ba1aa698), 帧序列/frame_sequence(ba1aa698), 内部精灵/inner_sprite(ba1aa698), 匀速运动延续/constant_motion(ba1aa698), 等间距排列/equal_spacing(ba1aa698), 重涂色/recolor(09c534e7), 单点标记/singleton_marker(09c534e7), 邻域全包含/full_neighborhood_inside_component(09c534e7), 标记在分量内/marker_inside_component(09c534e7)

**依赖链**：帧序列中精灵的空间位移形成等差数列 → 外推位移得到下一帧精灵位置。同时标记像素的颜色在各帧间形成固定循环（如红→绿→蓝→红…） → 外推循环得到下一帧标记色。在输出帧中，精灵内部（3x3 邻域全在精灵内的像素）被重涂为外推所得的标记色。位置外推错误 → 精灵放错位置 → 内部像素判断错误。颜色外推错误 → 内部涂错色。两条外推链独立但共同决定最终输出。

在帧序列中同时外推精灵的运动轨迹和其内部标记颜色的循环模式，将两个预测结果合成到新帧中，并用预测的标记色重涂精灵内部。

**输入结构**：
- 网格约 10x30（宽远大于高），背景黑(0)。
- 灰(5)线条将网格分为 4~5 个等宽的竖直面板（面板共享灰(5)竖直边框线，每个面板内部宽约 5~6 列、高约 8~9 行，内部填充黑(0)背景）。
- 每个面板内有一个相同形状的小精灵（4-连通单色小图形，约 5~8 像素，颜色为蓝(1)）。精灵在各面板中的局部列位置相同，但局部行位置随面板从左到右呈等差变化（如每个面板比前一个下移 1 行），模拟匀速对角运动。
- 每个精灵内部恰好有一个像素位置满足其 3x3 邻域全在精灵占据的像素范围内。该位置上放置一个单点标记，颜色在面板间按固定循环变化，循环使用红(2)、绿(3)、黄(4)三色（如面板 1 为红(2)，面板 2 为绿(3)，面板 3 为黄(4)，面板 4 回到红(2)）。
- 生成约束：精灵形状保证恰好有一个内部像素（满足 3x3 全包含条件）。运动轨迹外推一帧后精灵不超出面板边界。循环长度为 3（固定使用红绿黄三色）。

**规则**：
1. 识别帧序列：各面板从左到右依次为第 1、2、3、…帧。
2. 测量精灵的垂直位移：记录每帧精灵边界框的顶行在面板局部坐标中的位置，得到等差数列 {y1, y2, …}，公差 dy = y2 - y1。
3. 记录每帧标记像素的颜色序列 {c1, c2, c3, …}，确定循环周期和下一帧应出现的颜色 c_next。
4. 输出为一个独立面板（与输入面板同高同宽，灰(5)边框，黑(0)填充），其中：
   - 精灵绘制在局部行位置 y_last + dy 处（列位置不变），颜色仍为蓝(1)。
   - 精灵中满足 3x3 邻域全包含条件的像素重涂为 c_next。
   - 其余精灵像素保持蓝(1)。

**关键洞察**：本题要求同时推断两个独立的外推序列（空间位移的等差数列和颜色的循环序列），并将两个预测结果交叉应用到同一输出中——仅正确外推位置或仅正确外推颜色都不能生成正确输出。
