## 新题 1：投票恢复残缺精灵后以对称轴补全剩余空位

**组合逻辑**：[投票恢复/majority_vote_recovery](已有) → [对称补全/symmetry_completion](已有，创新：作用于投票无法决定的残余空位，而非直接作用于原始缺失) ← [密集带检测/dense_band_detection](已有) + [双轴镜像轨道/two_axis_orbit](已有，创新：对称轴从投票恢复的部分结果中推断，而非从完整图案推断)

**来源原语**：投票恢复/majority_vote_recovery(0607ce86), 对称补全/symmetry_completion(af22c60d), 密集带检测/dense_band_detection(0607ce86), 双轴镜像轨道/two_axis_orbit(af22c60d), 插槽阵列/slot_array(0607ce86), 缺失像素/missing_pixel(484b58aa/af22c60d), 忽略干扰项/ignore_distractors(0607ce86)

**依赖链**：密集带检测定位插槽阵列 → 投票恢复在各槽位间取逐像素多数色，但部分像素因腐蚀严重无法得到唯一多数色（平票） → 平票位置标记为未知 → 已恢复的像素揭示精灵具有单轴镜像对称性 → 用该对称轴的镜像轨道为每个未知像素找到已知的镜像伙伴 → 填入伙伴颜色完成恢复。投票与对称是两种独立的信息来源，在各自适用范围内互补，缺一不可。

用投票聚合多份噪声副本得到部分精灵，再用恢复出的对称性补全投票无法决定的残余空位，最后将干净精灵回写所有槽位并擦除槽外噪声。

**输入结构**：
- 网格约 20x25，背景黑(0)。
- 非背景像素形成密集的行带和列带，交叉处为矩形插槽（如 4 行 x 5 列的 4x4 插槽，槽间隔 1 像素背景）。每个插槽包含同一精灵的一份腐蚀副本。
- 精灵使用蓝(1)和红(2)两色在黑(0)背景上绘制，是一个 4-连通的不规则图形（约 8~12 像素）。精灵本身具有左右镜像对称性（以其边界框的垂直中轴为对称轴），但这一对称性在单份腐蚀副本中无法识别。
- 腐蚀方式：每个副本中 1~3 个像素被随机翻转（前景 → 背景或背景 → 前景、前景色互换）。在精灵的某些对称像素对上，腐蚀恰好使所有副本中该位置无唯一多数色（例如 10 个副本中 5 份为蓝(1)、5 份为红(2)）。
- 槽外散布少量噪声像素（蓝(1)或红(2)），密度远低于槽内密集带。
- 生成约束：精灵的对称轴将像素分为若干镜像轨道，每条轨道中至少有一个位置在投票中能确定唯一多数色；平票位置不超过精灵总像素数的 1/3。

**规则**：
1. 找到密集行带和密集列带的交集，确定插槽阵列的行列结构与每个槽的边界。
2. 对精灵的每个相对位置，统计所有槽内该位置出现的各颜色次数。若某颜色严格超过半数，则该位置恢复为此颜色；若无严格多数（含平票），标记为"未知"。
3. 从已恢复（非未知）像素中确定精灵边界框内的垂直镜像对称轴：找到列偏移量 c 使得所有已知像素对 (r, c-d) 与 (r, c+d) 颜色一致且支持数最多、无矛盾。
4. 对每个未知位置，取其关于对称轴的镜像位置。若镜像位置已知，则将未知位置填入镜像位置的颜色。若镜像位置也未知，则该对称对中必有第三步骤遗漏的间接证据——通过所有槽的颜色计数中取出现次数更多的颜色（非严格多数但相对最多）填入两个位置。
5. 将恢复完整的精灵回写到每个插槽。将所有不属于任何插槽的非背景像素设为黑(0)背景。

**关键洞察**：投票恢复和对称补全各自只能解决部分像素——投票处理随机噪声，对称处理系统性歧义——两者交汇才能完整重建精灵；对称轴本身也必须从投票的局部结果中推断，而非预先已知。
