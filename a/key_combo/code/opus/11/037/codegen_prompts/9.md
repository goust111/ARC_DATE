## 新题 9：三角朝向决定投射方向后在落点印章模板

**组合逻辑**：[投射发射/projectile_fire](已有，创新：投射物不产生碰撞变色，而是在落点触发印章操作) ← [朝向编码方向/orientation_encodes_direction](已有) → [印章覆盖/stamp_overlay](已有，创新：印章位置不是预设格子而是由投射物动态确定) + [擦除/erase](已有)

**来源原语**：投射发射/projectile_fire(409aa875), 三角精灵体/triangle_sprite(409aa875), 朝向编码方向/orientation_encodes_direction(409aa875), 碰撞变色规则/collision_recolor_rule(409aa875), 印章覆盖/stamp_overlay(5a5a2103), 模板掩码/template_mask(5a5a2103), 擦除/erase(d35bdbdc/0607ce86), 碰撞停止/collision_stop(e87109e9/36a08778)

**依赖链**：三角精灵的几何朝向编码发射方向 → 从三角顶点沿该方向发射投射物 → 投射物在碰到非背景像素或网格边缘前一格停止 → 在落点位置以三角的颜色印章模板掩码 → 多个印章重叠时近距离发射优先 → 擦除所有原始三角。朝向决定路径，路径决定落点，落点决定印章位置，颜色决定印章颜色。

读取三角精灵的朝向以确定发射方向，沿该方向发射投射物至碰撞停止，在落点处以该三角的颜色印章一个公共模板，最后擦除所有三角。

**输入结构**：
- 网格约 20x20，背景黑(0)。
- 3~5 个三角精灵分散在网格中。每个三角由 3 个同色像素组成，排列为直角 L 形：2 个像素沿某基本方向相邻排成一排，第 3 个像素在排头垂直方向偏移 1 格，三像素形成一个直角。每个三角颜色互不相同，取自红(2)、绿(3)、黄(4)、橙(7)、品红(6)。
- 直角的开口方向（缺失像素方向）就是该三角的发射方向：若 3 像素占据了 2x2 区域的三个角，缺失的那个角所在的方向即为发射方向。
- 网格某个角落（如左下角的 4x4 区域内）放置一个灰(5)模板掩码，由 3~5 个灰(5)像素组成的 4-连通小图形，形状不规则。
- 生成约束：每个三角的投射路径上在到达网格边缘之前不会碰到另一个三角（路径不穿越其他三角）；模板掩码位于角落，不在任何三角的投射路径上。所有落点位置使得印章的模板掩码（以落点为模板边界框的中心）完全在网格范围内。

**规则**：
1. 确定模板掩码：灰(5)像素构成的连通图形。记录其相对于自身边界框中心的像素偏移集合 S。
2. 对每个三角精灵，确定其发射方向：将三角的 3 个像素放入最小 2x2 边界框中，缺少的那个角的方向即为发射方向（上、下、左、右之一）。确定发射起点为三角直角顶点（离缺角最远的那个像素）。
3. 从发射起点沿发射方向逐像素前进。忽略模板掩码位置（灰(5)像素视为可穿越）。在碰到其他非背景非灰(5)像素或下一步超出网格边界时停止。落点 = 停止时的最后一个背景像素位置（即碰撞前一格；若到达网格边缘，落点为最后一个网格内像素）。
4. 在落点处印章模板：以落点坐标为中心，将偏移集合 S 中的每个偏移位置涂为该三角的颜色（覆盖黑(0)背景）。若某偏移位置超出网格范围，忽略该像素。
5. 若两个印章在某像素重叠（两个三角的落点使得模板覆盖了同一像素），该像素取发射距离更短（起点到落点的曼哈顿距离更小）的三角颜色。若距离相等，取发射起点行号更小的三角颜色；行号仍相等则取列号更小的。
6. 擦除所有原始三角精灵（将其 3 个像素设为黑(0)）。保留灰(5)模板掩码不变。

**关键洞察**：三角的几何结构（哪个角缺失）隐式编码了发射方向，而落点位置取决于路径上的障碍物分布——方向编码和空间布局共同决定模板印章的位置，使得同一模板以不同颜色出现在不同位置。
