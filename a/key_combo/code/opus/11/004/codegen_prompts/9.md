## 新题 9：轨迹定向射线擦除与拓扑裂变重涂色

**组合逻辑**：[射线延伸/反向投射](已有原语) + [擦除/首个障碍](已有原语) → [计数/连通分量](创新：擦除导致对象拓扑裂变后重新计数) → [重涂色/像素数映射颜色](创新：按裂变后的组件尺寸着色)

**来源原语**：射线延伸/反向投射/轨迹/擦除/首个障碍/标记像素(9f8de559)、计数/连通分量(aaecdb9a)、重涂色/像素数映射颜色(6e82a1ae)

**依赖链**：粉色轨迹指示红色标记的来源方向 → 沿反方向射线命中第一个灰色像素并擦除 → 擦除可能将一个 4-连通对象断裂为多个组件 → 所有擦除完成后重新识别灰色组件 → 按组件像素数重涂色。射线定向和命中决定擦除位置，擦除改变拓扑，拓扑决定组件尺寸，尺寸决定颜色——四步紧耦合。

按轨迹反方向射线擦除障碍像素，裂变后的组件按像素数重涂色。

**输入结构**：约 15x15 的黑(0)背景网格。含 2~4 个灰(5)的 4-连通前景对象，每个对象 4~10 像素，形态不限但须为 4-连通。含 2~3 个红(2)单像素标记，每个标记旁有恰好 3 个品红(6)像素沿某方向（水平/垂直/45 度对角之一）形成直线轨迹，轨迹从标记向外延伸。生成约束：每个红标记沿轨迹反方向的射线上恰好命中一个灰(5)像素作为第一个非背景障碍；每条射线命中不同的灰像素；至少一次擦除导致某灰对象断裂为两个 4-连通组件；标记和轨迹不遮挡彼此的射线路径。

**规则**：
1. 对每个红(2)标记，确定其品红(6)轨迹的方向（从标记到最近品红像素的 8-连通方向向量）。
2. 从红标记出发，沿轨迹的正反方向（即方向向量取反）逐格前进，找到第一个非背景像素（必为灰(5)）。
3. 将该灰像素擦除为黑(0)。红标记和品红轨迹保留不变。
4. 所有标记的射线擦除全部执行完毕后，识别网格上所有 4-连通灰(5)组件，统计每个组件的像素数 S。
5. 按 S 重涂色：S = 1 或 2 → 绿(3)；S = 3 或 4 → 蓝(1)；S >= 5 → 黄(4)。

**关键洞察**：每条射线精确移除一个像素，但因被移除的像素可能是对象的拓扑关节点（articulation point），该移除能将一个对象断裂为多个独立组件。最终颜色取决于断裂后的组件尺寸而非原始对象尺寸，因此射线的命中位置间接但决定性地影响着色结果。像素数到颜色的映射阈值需要从多个示例中归纳。
