## 新题 4：贪心路径中标记朝向决定走廊颜色

**组合逻辑**：[贪心遍历](已有原语) + [路径绘制](已有原语) + [标记朝向编码颜色](创新：朝向不再编码对象自身的重涂色，而是编码通向该对象的走廊颜色) + [擦除](已有原语)

**来源原语**：贪心遍历/路径绘制/视线可见/同行同列对齐/最近未访问优先/视线遮挡判断(3490cc26)、标记朝向编码颜色/擦除(604001fa)

**依赖链**：从起始块出发按最近可见优先贪心访问目标块 → 每到一个目标块，读取其旁边 L 形标记的朝向 → 朝向编码出一种颜色 → 用该颜色绘制从前一站到当前站的走廊 → 擦除已读取的标记。遍历顺序决定走廊存在性，标记朝向决定走廊颜色，两者在每一步交织。

沿贪心最近可见路径逐站行走，每段走廊的颜色由目的站的 L 标记朝向编码决定。

**输入结构**：约 20x20 的黑(0)背景网格。一个红(2) 2x2 方块为起点。4~6 个青(8) 2x2 方块为目标站。每个青方块的正上方紧邻一个橙(7) L 形三联体（占据一个 2x2 框内的三个像素，缺失一角），L 的 2x2 框的列范围与其所属青方块的列范围重叠。各方块之间部分对共享同一双行或双列带（使视线可达），部分不共享。生成约束：从起点出发的贪心遍历至少访问 3 个目标站后才无可见未访问目标；每一步的最近可见目标唯一（无平局）；四种 L 朝向至少出现两种。

**规则**：
1. 从红(2)起始块出发。
2. 在所有未访问的青(8)目标块中，找与当前块共享双行或双列带（即两块在水平或垂直方向上有两行或两列重叠）且带内间隙中无非背景像素阻挡的目标块。从中选间隙像素数最少的那个（最近者）。
3. 读取该目标块上方橙(7) L 三联体的朝向——确定其 2x2 框中缺失角的位置。缺失角位置与走廊颜色的映射为：左上缺失 → 绿(3)；右上缺失 → 黄(4)；左下缺失 → 品红(6)；右下缺失 → 栗(9)。
4. 将当前块与该目标块之间的背景间隙像素全部涂为步骤 3 确定的颜色。
5. 将该目标块的橙(7) L 三联体擦除为黑(0)。
6. 以该目标块为当前块，重复步骤 2-5，直到无可见未访问目标块为止。

**关键洞察**：空间布局控制哪些站可达（视线 + 最近优先），而每个站旁微小的 L 标记几何细节控制到达该站的走廊被涂什么颜色。遍历结构和局部标记几何缺一不可——不走到某站就不知道该走廊颜色，不知道 L 朝向映射就无法着色。四种朝向到四种颜色的映射需要至少两个示例交叉验证。
