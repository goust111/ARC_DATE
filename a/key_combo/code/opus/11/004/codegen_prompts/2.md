## 新题 2：分隔面板叠加与合并后组件重涂色

**组合逻辑**：[计数/连通分量](已有原语) → [透明叠加](创新：叠加优先级由组件计数决定) → [计数+重涂色](创新：在叠加合并后的新拓扑上二次计数并按合并尺寸着色)

**来源原语**：分隔行/等高面板/透明叠加(e98196ab)、连通分量/计数(aaecdb9a)、重涂色/像素数映射颜色(6e82a1ae)

**依赖链**：分隔行将网格切分为等高面板 → 统计每个面板内 4-连通前景组件数量 → 组件数决定面板的叠加层序（少在下多在上）→ 叠加合并前景像素 → 合并可能使不同面板的对象连接为更大组件 → 在合并后的拓扑上重新计数每个组件的像素数 → 按合并后的尺寸重涂色。两次计数作用于不同几何状态（叠加前 vs 叠加后），使逻辑不可跳步。

删除分隔行，按各面板前景组件数从少到多叠加，合并后按新组件像素数重涂色。

**输入结构**：约 17x10 的黑(0)背景网格。两条灰(5)实心水平行横贯全宽，将网格分为三个等高面板（每个面板约 5 行）。每个面板内有 1~4 个红(2)的 4-连通单色前景对象，每个对象 2~6 像素，形态不限（须为 4-连通，像素数在该范围内）。不同面板中的对象在列坐标上可能有重叠。生成约束：三个面板的组件数两两不同；至少一组来自不同面板的对象在叠加后同一局部坐标处有前景像素（产生冲突）；至少一次叠加合并导致两个原本独立的对象连为一个组件。

**规则**：
1. 删除两条灰(5)分隔行。
2. 统计每个面板内 4-连通红(2)组件的数量。
3. 将三个面板叠加到一个面板高度的画布上：组件数最少的面板作为底层，最多的在顶层。同一局部坐标 (r, c) 上若多个面板都有前景像素，保留最上层面板的像素。
4. 在叠加结果中，重新识别所有 4-连通前景组件，统计每个组件的像素数 S。
5. 按像素数重涂色：S <= 2 → 绿(3)；3 <= S <= 5 → 蓝(1)；S >= 6 → 黄(4)。

**关键洞察**：叠加优先级取决于叠加前各面板的组件计数，但最终颜色取决于叠加后合并组件的像素数——叠加改变了拓扑结构，使第二次计数的结果与第一次无直接对应关系，两步计数不可省略任一步。
