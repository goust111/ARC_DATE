## 新题 4：泛洪边界描边与对角线相位涂色

**组合逻辑**：[flood_fill] + [draw_inner_border](创新：描边宽度由区域面积决定) + [recolor/diagonal_phase_shift](创新：描边颜色沿对角线方向周期变化)

**来源原语**：flood_fill/reachability(8f3a5a89)、draw_inner_border(8f3a5a89)、diagonal_phase_shift/column_modular_phase(1e97544e)、recolor(a5f85a15)

**依赖链**：墙壁将网格划分为多个封闭区域；每个区域的面积决定其内边界的描边宽度（面积大则边框厚）；描边的颜色不是固定的，而是由该区域左上角在全局网格中的对角线坐标（row+col）模 3 决定从一个三色循环中取哪种颜色。面积决定宽度，位置决定颜色，两者独立作用于同一描边操作。

墙壁分割出的各区域被描上内边框，边框宽度取决于区域面积，边框颜色取决于区域左上角的对角线坐标模 3。

**输入结构**：约 15x15 的黑(0)背景网格。灰(5)像素形成连通的墙壁结构（所有灰像素 4-连通为一个分量），将网格划分为 4~6 个黑色封闭区域（每个区域面积在 6~30 像素之间）。墙壁与网格边界相连，确保所有区域完全封闭。生成约束：每个区域面积互不相等；区域面积分布在小（6~12）、中（13~20）、大（21~30）三档至少各有一个。

**规则**：
1. 识别所有被灰墙壁完全包围的黑色 4-连通区域。
2. 对每个区域计算面积（像素数）。描边宽度 = 1 + floor(面积 / 12)。即面积 6~11 描边 1 像素宽，12~23 描边 2 像素宽，24~35 描边 3 像素宽。
3. 描边位置：区域内与灰墙壁的切比雪夫距离 <= 描边宽度的所有像素。
4. 描边颜色由该区域边界框左上角坐标 (r,c) 决定：计算 (r+c) mod 3，结果为 0 涂红(2)、1 涂绿(3)、2 涂蓝(1)。
5. 区域内不属于描边的像素保持黑(0)。灰墙壁保持不变。

**关键洞察**：描边宽度的阶梯函数和颜色的对角线相位规律需要对比多个区域才能分别归纳；单看一个区域无法同时确定宽度公式和颜色周期。
