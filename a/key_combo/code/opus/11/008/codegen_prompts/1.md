## 新题 1：嵌套框缺口渗透与穿墙着色

**组合逻辑**：[泛洪填充](创新：穿越有缺口的框架墙) + [重涂色](创新：填充色由最后穿越的墙色决定) ← 约束于 [嵌套层次] + [可达性]

**来源原语**：泛洪填充/flood_fill（b9e38dc0）、重涂色/recolor（8dae5dfc）、嵌套矩形层/nested_rect_layer（8dae5dfc）、封闭区域/enclosed_region（ac6f9922）、可达性/reachability（dd6b8c4b）、填充种子/fill_seed（b9e38dc0）

**依赖链**：泛洪填充确定每个封闭环形区域是否可达；可达区域的填充颜色取决于洪水最后穿越了哪层框架墙的颜色，两者缺一不可——没有泛洪则无法判断可达性，没有穿墙着色规则则无法确定颜色。

从种子像素出发泛洪穿越嵌套框架墙的缺口，每个被洪水抵达的环形区域用最后穿越的墙色填充。

**输入结构**：约 14x14 的黑(0)背景网格。中央有三层同心矩形框架，每层 1 像素厚，颜色各不相同（外层红(2)、中层绿(3)、内层蓝(1)）。每层框架恰有一个 1 像素的缺口（开口），三个缺口分布在不同的边上（例如外层缺口在顶边、中层缺口在左边、内层缺口在底边）。在最外层框架之外的黑色区域中放置一个黄(4)种子像素。生成约束：三层框架严格嵌套不相交；每层缺口位置保证从种子出发存在至少一条连通路径可达最内层。

**规则**：
1. 从黄(4)种子像素出发，对黑(0)背景像素执行 4-连通泛洪填充。洪水可以穿过框架墙上的 1 像素缺口进入内部区域，但不能穿过框架墙本身（非缺口的框架像素视为不可通行）。
2. 对每个被洪水抵达的封闭环形区域（两层相邻框架之间的黑色空间），将该区域的所有黑(0)像素重涂为洪水最后穿越的那层框架墙的颜色。"最后穿越"指：从种子到该区域的任意 4-连通最短路径上，最后经过的那个缺口所属框架的颜色。若最短路径不唯一但最后穿越的框架层相同，则颜色唯一确定（生成时保证此条件成立）。
3. 最内层框架围成的核心区域若被洪水抵达，同样使用最后穿越的框架墙（即内层蓝(1)框架）的颜色填充。
4. 框架墙像素本身保持不变。黄(4)种子像素保持不变。不可达的区域保持黑(0)。

**关键洞察**：洪水从外向内逐层渗透时，缺口在不同边上意味着洪水可能沿不同路径穿越不同数量的墙——有时外层和中层缺口在同侧导致洪水直接穿透两层，此时中间环形区域的"最后穿越墙"仍是外层墙（洪水是沿缺口直线进入的），而非中层墙。必须对比多个示例中缺口的不同排布才能归纳出"最后穿越"规则，而非简单的"第 N 层区域用第 N 层颜色"。
