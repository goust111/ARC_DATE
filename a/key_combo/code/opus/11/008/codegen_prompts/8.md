## 新题 8：角落码对称展开与印章颜色调制

**组合逻辑**：[对称补全](已有：角落码展开同心框) + [印章覆盖](已有：对角重复) → [重涂色](创新：印章与展开后框架的空间交集决定印章像素颜色) ← 约束于 [对称展开] + [对角偏移重复] + [尺寸决定步幅]

**来源原语**：对称补全/symmetry_completion（9d9215db）、印章覆盖/stamp（e619ca6e）、重涂色/recolor（8dae5dfc）、角落编码/corner_code（9d9215db）、同心正方形层/concentric_square_ring（9d9215db）、实心矩形/solid_rect（e619ca6e）、对称展开/symmetric_unfolding（9d9215db）、对角偏移重复/diag_offset_repeat（e619ca6e）、尺寸决定步幅/size_determines_stride（e619ca6e）、角落码展开同心/corner_code_unfolds_concentric（9d9215db）

**依赖链**：角落码对称展开生成同心方形框架几何结构 → 实心矩形沿对角线印章生成重复图案 → 印章像素的最终颜色由其所在位置是否与同心框架像素重合决定（重合则吸收框架颜色，否则保持原色）。两个独立的图案生成过程通过空间交集产生耦合——单独看任一过程都无法预测最终输出。

角落码展开为同心方形框架，同时一个小矩形沿对角线印章重复；印章像素落在框架上时吸收框架颜色，产生颜色调制的重复图案。

**输入结构**：约 15x15 的奇数尺寸黑(0)背景网格。网格的一个角落区域（例如左上角）在奇数坐标格点上有稀疏的彩色前景像素（2-4 个像素，颜色各不相同，例如红(2)、绿(3)、蓝(1)），构成角落码（与 9d9215db 相同的编码方式）。另外，在远离角落码的位置（例如右下区域）有一个小的黄(4)实心矩形（约 2x2 或 2x3）。生成约束：角落码和实心矩形不重叠；角落码定义的同心框架数量为 2-3 层；矩形的对角印章轨迹与至少一层展开后的同心框架有空间交集。

**规则**：
1. 对称展开：按 9d9215db 的规则，从角落码的稀疏像素推断同心方形框架的颜色分配。对角线位置的像素定义该层四个角的颜色；水平/垂直方向的像素定义对应边的颜色。将角落码展开为完整的同心方形框架，框架像素绘制到网格上。
2. 对角印章：对黄(4)实心矩形执行对角印章——以矩形高度 h 和宽度 w 为步幅，在偏移 (kh, kw) 和 (kh, -kw)（k=1,2,...）处复制，超出网格裁剪，完全出界后停止。原始矩形保留。
3. 颜色调制：逐像素检查每个印章副本（含原始矩形）的每个像素位置。若该位置同时是步骤 1 中绘制的同心框架像素，则该印章像素的颜色替换为该框架像素的颜色（吸收框架色）。若该位置不是框架像素（为黑色背景或其他），则保持黄(4)不变。
4. 框架像素本身的显示规则：若某框架像素位置未被任何印章覆盖，则正常显示框架颜色。若被印章覆盖，则按步骤 3 规则显示（即该位置显示框架颜色——因为印章吸收了框架色，两者一致）。
5. 角落码的原始稀疏像素保持不变（它们同时也是展开后框架的一部分）。

**关键洞察**：同心框架和对角印章是两个独立的空间图案生成过程——框架从中心向外环形分布，印章沿对角线格点分布。它们的空间交集创造了颜色调制效果：重复的黄色印章在经过不同框架层时"染上"不同颜色，形成一种非均匀的周期图案。这个最终图案无法通过单独理解任一过程得出，必须同时理解两者并计算它们的空间叠加。
