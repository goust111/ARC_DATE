## 新题 6：堆叠掩码交集计数驱动模板像素放大

**组合逻辑**：[压缩/逐格比较](保留) + [像素放大/pixel_scale](创新：放大倍率不再预设，而由掩码交集像素数决定) + [种子选择模板](创新：种子不再是框内已有像素，而是交集图案本身匹配模板)

**来源原语**：压缩/compress (fafffa47), 堆叠掩码/stacked_mask (fafffa47), 逐格比较/cell_comparison (fafffa47), 双背景标记输出/both_bg_marks (fafffa47), 像素放大/pixel_scale (8a6d367c), 模板/template (8a6d367c), 种子选择模板/seed_selects_template (8a6d367c), 框内匹配/frame_interior_match (8a6d367c)

**依赖链**：两个掩码逐格比较产生交集标记 -> 交集标记的空间图案用于匹配模板（图案选择） -> 交集标记的像素数量用于决定放大倍率（数量编码） -> 被选中的模板以该倍率放大后作为输出。同一个交集结果被同时读取了两种信息（图案和数量），分别决定了两个不同参数。

一句话：将两个堆叠掩码逐格比较得到交集标记，交集的形状匹配某个模板，交集的像素数量决定该模板的放大倍率，输出放大后的模板。

**输入结构**：约 12x20 网格，纵向分三个区域。上区（约 5 行）：2~4 个小模板，每个模板为单色 4-连通图形（2~4 像素），颜色各异（从蓝(1)、红(2)、绿(3)、黄(4)中选取），模板之间水平排列，间隔至少 2 列。中区和下区各为一个 5xW 的掩码（W = 网格宽度），两个掩码之间用一行栗(9)色分隔条隔开。每个掩码以黑(0)为底色，分别包含一种前景色的像素图案（中区用品红(6)，下区用橙(7)）。生成约束：两个掩码逐格比较后，"双底色"位置（即中区该格为黑(0)且下区同位置也为黑(0)）的集合形成的形状，经平移后恰好匹配上区某一个模板的形状；该匹配是唯一的（其他模板形状不匹配）；交集像素数量为 2、3 或 4（即放大倍率为 2x、3x 或 4x）。

**规则**：
1. 以栗(9)分隔条为界，提取中区掩码和下区掩码（大小相同）。
2. 逐格比较：同一位置 (r, c) 在中区和下区都是黑(0)背景时，标记为红(2)交集像素；否则标记为黑(0)。得到一个交集掩码。
3. 将交集掩码中所有红(2)像素的坐标集合，平移使其边界框左上角对齐 (0,0)，得到归一化形状。
4. 在上区的模板中，找到形状与归一化交集完全匹配的模板（像素集合平移后全等）。
5. 令 n = 交集红(2)像素的数量。将匹配到的模板做 n 倍像素放大（每个模板像素变为 nxn 的同色方块）。
6. 输出仅包含放大后的模板，背景为黑(0)。输出网格大小 = 模板边界框高 * n 行 x 模板边界框宽 * n 列。

**关键洞察**：交集结果被双重利用——形状选模板、数量定倍率。求解者如果只关注形状匹配或只关注计数，都无法独立确定输出。必须对比多个示例才能发现计数与倍率的映射关系，以及形状匹配的选择逻辑。
