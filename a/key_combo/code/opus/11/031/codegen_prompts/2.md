## 新题 2：反射重叠的距离优先涂色

**组合逻辑**：[镜像/跨轴反射](保留) + [重涂色](创新：涂色由标记像素指定，但重叠区域按原始距轴距离解决冲突) + [逐格比较](创新：比较反射后的落点是否重叠，而非比较两个掩码)

**来源原语**：镜像/mirror (88207623), 重涂色/recolor (12997ef3), 跨轴反射/reflection_across_axis (88207623), 标记色指定涂色/marker_color_paint (88207623), 逐格比较/cell_comparison (fafffa47), 标记像素/marker_pixel (581f7754)

**依赖链**：反射产生镜像位置 -> 多个镜像可能重叠 -> 重叠必须按源图形距轴的远近分优先级 -> 标记像素为非重叠区域提供涂色。反射结果决定了哪些格子需要冲突解决，而冲突解决依赖反射前的空间距离信息。

一句话：将轴一侧的多个图形反射到另一侧，非重叠区域由对侧标记像素指定颜色，重叠区域由距轴更近的原始图形获得涂色优先权。

**输入结构**：黑(0)背景，约 15x20 网格。一条灰(5)像素组成的垂直线段位于网格中部（贯穿所有行或大部分行），作为反射轴。轴左侧有 2~4 个互不相邻的单色 4-连通前景图形（每个 3~8 像素，形状不规则，颜色从蓝(1)、红(2)、绿(3)中选取，颜色可重复）。轴右侧有若干孤立标记像素（每个 1 像素，颜色从黄(4)、橙(7)、品红(6)中选取），每个标记像素位于恰好一个左侧图形反射后的覆盖区域内（不在重叠区域内）。生成约束：至少有一对图形反射后存在 2 像素以上的重叠区域；每个非重叠反射区域内恰好有一个标记像素；不同图形反射后的重叠区域内不放置标记像素。

**规则**：
1. 保留灰(5)反射轴和所有左侧原始图形不变。
2. 将每个左侧图形关于灰色轴列做水平镜像反射，计算每个反射像素的目标位置 (r, 2*axis_col - c)。
3. 对于仅被一个反射图形覆盖的目标格子（非重叠）：查找该反射区域内的标记像素，用标记像素的颜色涂该反射图形的所有非重叠格子。
4. 对于被多个反射图形同时覆盖的目标格子（重叠）：计算每个竞争图形的最近边框像素到轴的水平距离（像素数），距轴更近的图形优先——该格子涂为该优先图形对应的标记颜色。距离相同时，边界框上边缘行号更小的图形优先。
5. 移除所有标记像素（标记像素仅用于指示颜色，不出现在输出中）。

**关键洞察**：反射本身制造了空间冲突（重叠），而解决冲突需要回溯到反射前的距离信息——镜像操作和冲突解决之间存在因果环路：不做反射不知道哪里重叠，不知道原始距离不能解决重叠。需要对比多个示例才能归纳距离优先规则。
