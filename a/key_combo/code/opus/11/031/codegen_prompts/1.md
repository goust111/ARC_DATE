## 新题 1：重力穿越门控框架

**组合逻辑**：[重力下落](创新：遇框时判断颜色匹配决定通过/停靠) + [洪泛填充](创新：通过缺口后沿缺口方向改变下落轴) + [边框缺口](创新：缺口不再触发射线，而是重定向重力轴)

**来源原语**：重力下落/gravity_drop (963c33f8), 洪泛填充/flood_fill (551d5bf1), 空心矩形/rectangular_frame (551d5bf1), 边框缺口/border_gap (551d5bf1), 控制色定行为/control_color_determines_behavior (963c33f8), 碰撞停止/collision_stop (332f06d7)

**依赖链**：颜色匹配决定像素能否穿越框架 -> 缺口位置决定穿越后的运动方向 -> 运动方向改变后遇到下一个框架又触发新一轮匹配判断。三者形成循环依赖：每次穿越改变方向，方向改变后遇到的框架颜色不同，又触发不同的匹配结果。

一句话：彩色像素在重力作用下穿越多层带缺口的矩形框架，同色框架可穿过且缺口方向重定向运动轴，异色框架则阻挡停靠。

**输入结构**：黑(0)背景，约 18x18 网格。顶部有 2~4 个单色前景像素（每个 1 像素，颜色各异，从蓝(1)、红(2)、绿(3)、黄(4)中选取），分布在不同列。网格中散布 3~5 个空心矩形框架（4-连通单像素宽边框，内部 3x3 至 5x5 的空腔），每个框架用上述四色之一绘制。每个框架恰好有一个非角落边框像素缺失（缺口），缺口可在上、下、左、右任一侧。框架之间互不重叠，且在水平和垂直方向上至少间隔 2 像素。生成约束：每个下落像素的运动路径上至少经过 2 个框架，路径之间互不交叉。

**规则**：
1. 每个顶部前景像素初始向下运动（重力方向 = 下）。
2. 像素沿当前运动方向逐格移动。遇到框架边框像素时进行颜色匹配判断：
   - 若像素颜色与框架颜色相同：像素穿过框架，从缺口位置离开。离开后运动方向变为缺口朝外的方向（上侧缺口 -> 向上，右侧缺口 -> 向右，依此类推）。
   - 若像素颜色与框架颜色不同：像素停在碰撞前一格（即框架外侧紧邻的背景像素位置），保留像素原色。
3. 像素运动直到停靠（碰撞异色框架或到达网格边界）。到达网格边界时像素停在边界最后一个格子。
4. 多个像素独立运动，互不影响。若两个像素最终落在同一格，后停靠的覆盖先停靠的（按初始列从左到右的顺序依次处理）。
5. 输出保留所有框架（含缺口），背景不变，仅改变像素的最终位置。

**关键洞察**：缺口不是装饰性缺陷，而是运动方向的转向阀；同一个像素可能先向下、穿过一个框架后转向右、再穿过另一个框架后转向上，轨迹呈折线形。颜色匹配和缺口方向两个判断交替作用，缺一不可。
