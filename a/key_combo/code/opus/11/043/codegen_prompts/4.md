## 新题 4：粒子终点匹配占位块重涂色

**组合逻辑**：[路径追踪]+[碰撞停止] → [相对位置对应](创新：对应关系由粒子的起止位置映射建立) → [重涂色]

**来源原语**：路径追踪(path_trace)+粒子(particle)+碰撞停止(collision_stop)来自9bbf930d；重涂色(recolor)+相对位置对应(relative_position_correspondence)+占位块(placeholder_object)+最小距离匹配(minimum_distance_matching)来自1da012fc

**依赖链**：彩色粒子沿走廊移动直到碰撞停止 → 粒子停止位置相对于"停止区"的布局 ≈ 占位块相对于输出区的布局 → 建立位置对应 → 每个占位块重涂为对应粒子的起始颜色

粒子携带颜色信息穿越迷宫，最终停止位置的空间分布与占位块的分布构成位置映射，决定重涂色方案。

**输入结构**：约 16x16 网格，背景黑(0)，分为上下两半（无显式分隔线）。上半区：3-4 个彩色单像素粒子（如蓝(1)、绿(3)、黄(4)、品红(6)）分布在左侧列，每个粒子右侧有一条由橙(7)色条围成的水平走廊（宽 1 格），走廊末端被一个栗(9)像素封堵（碰撞墙）。走廊长度各不相同，导致粒子停在不同的列位置。下半区：与粒子数量相同的灰(5)占位块（各为 3-5 像素的 4-连通不规则图形），散布在不同位置。生成约束：粒子停止后的各终点位置相对于上半区包围框的归一化坐标，与各占位块中心相对于下半区包围框的归一化坐标可通过最小总距离唯一配对；各粒子走廊长度互不相同。

**规则**：
1. 每个粒子从起始位置向右直行，遇到栗(9)封堵墙时停止（停在墙的前一格）。
2. 计算所有粒子终点位置相对于上半区包围框（所有走廊占据的最小矩形）的归一化相对坐标 (row_ratio, col_ratio)。
3. 计算所有占位块的质心相对于下半区包围框（所有占位块占据的最小矩形）的归一化相对坐标。
4. 对粒子终点和占位块质心进行最小总欧氏距离的一对一匹配。
5. 将每个占位块的所有像素重涂为其匹配粒子的原始颜色（即粒子起始时的颜色）。
6. 输出时，上半区的走廊、粒子、墙壁全部清除为黑(0)，仅保留下半区的重涂色后的占位块。

**关键洞察**：走廊长度差异使粒子停在不同列，这些终点的相对空间布局是连接上下两区的隐式编码——求解者必须先模拟路径确定终点，再用终点布局匹配占位块。
