## 新题 4：嵌套框架深度计数决定框架重涂色

**组合逻辑**：[包含树遍历](已有) → [计数](已有，创新：计数范围由包含层级严格限定) → [重涂色](创新：计数结果映射到标记颜色而非固定色表)

**来源原语**：嵌套框架、封闭区域、包含树、拓扑决定布局(2d0172a1)；计数、内部标记计数、稀疏标记(54db823b)；重涂色(0becf7df)

**依赖链**：包含树确定每个框架的直接子区域 → 在直接子区域中（排除更内层框架内部）计数标记像素 → 计数结果决定该框架的重涂颜色。删去包含树则无法正确划定计数区域（会把内层框架内的标记误算）；删去计数则无法选择颜色；删去重涂色则无输出变化。

**输入结构**：约 15x15 的黑(0)背景网格。包含 2-3 组相互独立的嵌套矩形框架结构（各组之间不嵌套）。每组有 2-3 层嵌套，每个框架都是灰(5)的单像素厚矩形边框。在各层之间的间隙区域中散布着小的单色标记像素（可能为红(2)、蓝(1)、绿(3)），每层间隙中的标记数量从 0 到 3 不等。标记只在框架之间的间隙中出现，不在框架边框像素上。生成约束：每个框架的直接内部区域（不含更内层框架内部）中的标记数量各不相同（0, 1, 2, 3 中的不同值）。

**规则**：
1. 构建包含树：确定哪些框架包含哪些更小的框架，以及每个标记像素被哪个最内层框架直接包含。
2. 对每个框架，统计其"直接内部"中的标记像素数——直接内部定义为该框架内部、但不在任何子框架内部的区域。
3. 重涂色规则：
   - 直接内部标记数为 0 → 框架保持灰(5)
   - 直接内部标记数为 1 → 框架涂为该唯一标记的颜色
   - 直接内部标记数 >= 2 → 框架涂为其直接内部中距框架左上角（框架边框左上角像素）最近的那个标记的颜色（使用曼哈顿距离，若相等则取行号更小者，行号也相同则取列号更小者）
4. 所有标记像素从输出中擦除（变为黑(0)背景）。

**关键洞察**："直接内部"的定义是解题关键——一个标记虽然在外层框架的包围盒之内，但如果它在更内层框架的包围盒之内，则不计入外层框架。必须正确构建包含树才能得到正确的计数。
