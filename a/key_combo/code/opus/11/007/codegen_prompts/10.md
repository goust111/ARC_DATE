## 新题 10：自色匹配集群选择后拉伸入框

**组合逻辑**：[包围选择](已有，自色匹配条件) → [裁剪](已有) → [拉伸](已有，创新：被拉伸的对象由集群选择规则决定)

**来源原语**：角标记、中心对象、包围关系、标记色与对象同色、裁剪(da6e95e5)；拉伸、精灵体、空心矩形、包围盒映射、线段连接再填充(465b7d93)；擦除(54db823b)

**依赖链**：自色匹配规则在多个集群中选出目标 → 裁剪出目标中心对象 → 将其拉伸入框架内部。选错集群则拉伸结果完全不同；不拉伸则输出只是裁剪而非变形；不擦除集群则输出包含无关元素。

**输入结构**：约 17x17 的黑(0)背景网格。包含 3 个互不重叠的"集群"，每个集群由四个相同颜色的小标记对象（每个标记为 1x2 或 2x1 矩形，4-连通）围绕一个中心小精灵体（3-6 像素，4-连通，单色）组成。四个标记分别位于中心精灵体包围盒的左上、右上、左下、右下外侧，与中心精灵体不相邻但在同一局部区域内。三个集群的标记颜色各不相同（如红(2)、蓝(1)、绿(3)），中心精灵体颜色也各不相同。恰好有一个集群的中心精灵体颜色与其四个角标记颜色相同（自色匹配集群）。网格中另有一个独立的灰(5)单像素厚空心矩形框架，内部约 6x6，不与任何集群重叠。生成约束：自色匹配集群的中心精灵体形状不对称，拉伸后视觉上有明确的方向性。

**规则**：
1. 识别自色匹配集群：找到唯一的集群，其中心精灵体颜色等于其四个角标记颜色。
2. 提取该集群的中心精灵体，裁剪至其包围盒。
3. 将精灵体拉伸入灰色空心框架的内部区域：将精灵体包围盒的四角映射到框架内部的四角，精灵体中相邻像素的映射位置之间用水平或垂直直线段连接，再填充线段围成的封闭背景区域（使用精灵体颜色）。
4. 擦除所有集群（三个集群的所有标记和中心精灵体全部变为黑(0)背景）。
5. 保留灰色框架和框架内的拉伸结果。

**关键洞察**：三个集群外观相似，选择错误的集群会产生完全不同的拉伸形状。自色匹配是唯一的选择依据——不是最大、最亮或最居中的集群，而是标记色与中心色一致的那个。
