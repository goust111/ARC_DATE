## 新题 3：角落环带配合图例交替换色

**组合逻辑**：[填充](创新：奇偶环带不再是"涂/不涂"，而是"涂原色/涂换色") + [重涂色](已有，图例行配对互换)

**来源原语**：角标记像素、同心环、最近归属、奇偶距离决定填色(d22278a0)；图例、图例行内配对、同行颜色互换、重涂色(0becf7df)

**依赖链**：角标记确定归属区域 → Chebyshev 距离奇偶性决定每个像素是"原色环"还是"换色环" → 图例提供配对换色表 → 奇数环像素查找图例得到替代色。删去角标记则无归属划分；删去奇偶判断则无法区分两类环；删去图例则奇数环颜色不确定。

**输入结构**：约 13x13 的黑(0)背景方形网格。2-3 个角落各有一个单像素标记，颜色各不相同（如红(2)在左上角、蓝(1)在右下角、绿(3)在左下角）。网格中央偏某侧放置一个 2 行 2 列的图例块，图例不在任何角落附近。图例每行包含两种颜色，构成一个配对：例如第一行为红(2)和黄(4)，第二行为蓝(1)和橙(7)。每个角标记的颜色恰好出现在图例的某一行中。生成约束：图例位置不与任何角标记的 Chebyshev 距离为 0 或 1 的区域重叠；至少有两个角标记的归属区域相邻（存在归属边界）。

**规则**：
1. 对每个非图例、非角标记的背景像素，计算其到每个角标记的平方欧氏距离，将其归属给距离最近的角标记。若到两个或以上角标记距离相等，则该像素保持黑(0)背景。
2. 对每个被归属的像素，计算其到归属角标记的 Chebyshev 距离 d。
3. 若 d 为偶数：该像素涂为归属角标记的原始颜色。
4. 若 d 为奇数：在图例中找到包含该角标记颜色的那一行，将该像素涂为同行的另一种颜色（即配对色）。
5. 图例块本身保持不变，覆盖在环带图案之上。

**关键洞察**：偶数环显示角标记本色，奇数环显示图例配对色，形成交替色带。图例不是装饰，而是控制交替色的指令表。仅看一个示例可能误以为所有环都是同一颜色或所有环都换色，必须对比多个角落的环带模式和图例内容才能归纳出奇偶分流规则。
