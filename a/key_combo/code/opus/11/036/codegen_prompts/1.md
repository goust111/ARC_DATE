## 新题 1：条件旋转与跨度连线

**组合逻辑**：[旋转/rotate](条件化：仅特定颜色的条旋转，创新) → [连线/connect + 首尾跨度填充/span_fill_between](作用于旋转后新涌现的行列对齐关系) → [重涂色/recolor](连接段使用第三色，已有)

**来源原语**：旋转+中心点不变+单像素宽条(#14 f0f8a26d), 连线+标记像素+同行列对齐+首尾跨度填充(#1 ded97339), 重涂色(#2 ce9e57f2)

**依赖链**：旋转改变条的朝向，从而创造出输入中不存在的行列对齐关系；连线操作依赖这些新对齐关系来确定连接位置。哪种颜色参与旋转是隐蔽规则，必须对比多个示例才能归纳。不旋转则无新对齐、无法产生正确连接；不连线则只有散落的旋转条。

将特定颜色的细条绕中心旋转 90 度，然后在旋转后同色且同行或同列的条端点之间画连接跨度。

**输入结构**：
- 约 12x12 的黑(0)背景网格。
- 散布着若干单像素宽的奇数长度直线段（3~7 像素），每段为 4-连通的水平或竖直细条。
- 细条有两种颜色：红(2)和蓝(1)，每种颜色至少 3 条。
- 任意两条的边界框互不相邻（至少间隔 1 格空行/列）。
- 生成约束：红(2)条旋转 90 度后，至少存在两对同色条共享同一行或同一列；这些对齐关系在旋转前不存在。蓝(1)条在原始位置也存在至少一对同行或同列对齐。

**规则**：
1. 识别所有单像素宽的直线段及其颜色。
2. 将所有红(2)条绕各自中心像素旋转 90 度（水平变竖直、竖直变水平），长度和中心位置不变。蓝(1)条保持原位不动。
3. 旋转后，对每一行：若该行包含至少两个同色条的像素，取同色像素中最左与最右之间的全部空白格（不含已有条像素的格），涂为绿(3)。对每种颜色分别独立执行此操作。
4. 对每一列执行相同逻辑：若该列包含至少两个同色条的像素，取同色像素中最上与最下之间的全部空白格，涂为绿(3)。
5. 若连接路径穿过另一种颜色的条，该条的像素保持原色不被覆盖。
6. 行连接和列连接的交叉点若均为空白格，涂为绿(3)。

**关键洞察**：只有红(2)条旋转而蓝(1)条不动——这一颜色条件在单个示例中无法唯一确定（可能恰好看似两色都旋转或都不旋转），必须对比多个示例中不同颜色条的行为差异才能归纳。旋转本身不是目的，而是为后续连线操作"制造"出新的对齐关系。
