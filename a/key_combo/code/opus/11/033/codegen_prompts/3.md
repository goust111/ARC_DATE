## 新题 3：镜像马赛克与标记编码槽位提取

**组合逻辑**：[镜像 mirror / 相邻槽位翻转 adjacent_slot_flip](概念性构建镜像马赛克) ⊗ [标记坐标编码槽位 marker_encodes_slot](标记位置选择输出槽位) → [擦除 erase](标记被消费)

**来源原语**：镜像(mirror)、平铺(tiling)、瓦片(tile)、阵列排布(array_layout)、相邻槽位翻转(adjacent_slot_flip) 来自 c48954c1；标记坐标编码槽位(marker_encodes_slot)、标记像素(marker_pixel)、复制(copy) 来自 6d0160f0；擦除(erase) 来自 a416fc5b

**依赖链**：镜像逻辑决定每个槽位的瓦片内容；标记位置解码出目标槽位；擦除移除标记。三者非线性依赖：镜像变换和标记解码各自独立贡献信息，合流确定唯一输出。去掉镜像则不知道槽位内容，去掉标记则不知道选哪个槽位。

从一个含标记的小瓦片出发，概念性构建 3x3 镜像马赛克，仅提取标记本地坐标所指示的那个槽位作为输出，并从结果中擦除标记。

**输入结构**：
- 一个 3x3 彩色网格。每个格子都有颜色填充，无黑(0) 背景。
- 恰好一个格子为黄(4)，作为标记像素。其余 8 个格子使用 2~3 种其他颜色（如蓝(1)、红(2)、绿(3)），颜色分布在不同示例中变化。
- 瓦片在行列翻转组合下不对称（即不存在非恒等的行/列翻转组合使瓦片映射到自身），保证 9 个马赛克槽位产生不同的视觉结果。
- 生成约束：黄(4) 标记不在中心位置 (1,1)，保证输出是某种翻转版本而非原始瓦片。

**规则**：
1. 概念性构建 3x3 镜像马赛克（9 个 3x3 槽位）：
   - 中心槽位（宏行 1、宏列 1）：原始瓦片不变。
   - 上方或下方槽位（宏行 0 或 2、宏列 1）：将原始瓦片的行顺序翻转（第 0 行与第 2 行互换）。
   - 左方或右方槽位（宏行 1、宏列 0 或 2）：将原始瓦片的列顺序翻转（第 0 列与第 2 列互换）。
   - 四角槽位（宏行 ∈ {0,2}，宏列 ∈ {0,2}）：同时翻转行和列。
2. 读取黄(4) 标记在瓦片内的本地坐标 (r, c)，其中 r, c ∈ {0, 1, 2}。
3. 选取马赛克中宏位置 (r, c) 处的槽位。
4. 在选取的 3x3 槽位中，找到黄(4) 标记经过翻转后所在的位置，将其替换为黑(0)。
5. 输出仅为该 3x3 槽位。

**关键洞察**：黄色标记具有双重角色——它既是瓦片的视觉内容的一部分（参与镜像变换），又编码了目标槽位的元数据（通过其位置坐标）。马赛克从不被完整构建，只有标记指示的那个槽位出现在输出中。标记在输出中被"消费"（擦除），防止循环推理。求解者必须理解坐标即指令这一隐含编码。
