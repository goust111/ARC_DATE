## 新题 4：地形高度匹配散落标记数以选定框架填充色

**组合逻辑**：[列高度极值](创新：高度值不再用于标记最深/最浅列，而是作为匹配键) → [计数](创新：统计散落标记的数量，用于与地形高度匹配) → [填充](创新：填充目标由两个独立信息源的匹配关系决定)

**来源原语**：地形轮廓、列高度极值(e45ef808)；计数、填充、空心矩形、标记像素、像素数匹配格数(df8cc377)

**依赖链**：本题的核心创新在于三个独立信息源的汇聚：框架提供"在哪填"、地形高度提供"匹配什么数值"、标记像素数量提供"选什么颜色"。地形高度不再是标记极值（参考题 e45ef808 的用法），而是作为匹配键与标记数量对接（参考题 df8cc377 中棋盘格格数的角色被地形高度替代）。三者缺一不可：没有地形无法确定匹配键，没有标记无法确定颜色，没有框架无法确定填充位置。

测量每个框架正下方的地形高度，将其与散落标记的逐色像素数匹配，用匹配到的颜色填充框架内部。

**输入结构**：约 20x20 的黑(0)背景网格。分为三个垂直区域：(a) 顶部区域（约 row 0-7）：3-4 个灰(5)单像素厚空心矩形框架，内部尺寸统一为 3x3，水平均匀分布且互不重叠，内部初始为背景色。每个框架的水平中心列位置各不相同。(b) 中间区域（约 row 8-11）：散落的单像素标记，使用 3-4 种不同的前景色（如红(2)、蓝(1)、绿(3)、黄(4)），每种颜色的像素总数各不相同（例如红 3 个、蓝 5 个、绿 4 个、黄 7 个），标记位置随机分布在此区域。(c) 底部区域（约 row 13-19）：灰(5)地形轮廓，每列从网格底行向上有一段连续的灰色像素，不同列高度不同（范围约 2-8 像素），形成高低起伏的地形剖面。生成约束：每个框架水平中心列处的地形高度恰好等于某一种标记颜色的像素总数，且该对应关系是一一映射（不同框架对应不同颜色）；框架数量等于标记颜色种类数。

**规则**：
1. 对每个框架，确定其水平中心列（左右边框列的中间列；若内部宽度为偶数，取左侧中心列）。
2. 测量该中心列的地形高度：从网格最底行向上连续灰(5)像素的数量。
3. 统计中间区域每种标记颜色的像素总数。
4. 将每个框架的地形高度值与标记颜色像素数匹配：找到像素总数等于该地形高度的唯一标记颜色。
5. 用匹配到的颜色实心填充该框架的 3x3 内部区域。
6. 擦除中间区域的所有标记像素（设为背景色）。
7. 框架边框和底部地形保持不变。

**关键洞察**：框架正下方的地形高度是一个隐式数值键，它不直接出现在框架内部，而是通过垂直空间对应关系从远处的地形剖面中读取。求解者必须发现"中心列地形高度 = 标记像素数"这一跨区域的匹配规则。
