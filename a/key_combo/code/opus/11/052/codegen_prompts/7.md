## 新题 7：按框架尺寸比缩放母题并由共享标记锚定印章位置

**组合逻辑**：[尺寸比编码缩放](创新：缩放比不由锚点方块大小决定，而由容器内部空间与母题的尺寸比直接编码) → [缩放](已有) → [标记对齐](创新：标记从面积块变为单像素，对齐粒度更细) → [印章放置](创新：印章范围受限于框架内部，仅填充背景格)

**来源原语**：缩放、图案母题、锚点方块、尺寸比编码缩放(b10624e5)；印章放置(b10624e5)；共享标记、标记对齐(83eb0a57)；空心矩形(df8cc377)；仅填背景格(f0df5ff0)

**依赖链**：框架的内部尺寸与母题尺寸的比值隐式编码了缩放倍率（参考题 b10624e5 中由锚点方块大小编码，本题改为由容器空间编码）。红色标记像素同时出现在母题和框架内部，提供亚像素级精确对齐锚点（参考题 83eb0a57 的共享标记思路，但从多连通分量对齐简化为单像素锚定）。两者耦合：不知道缩放倍率就无法生成正确大小的母题副本，不知道标记位置就无法正确放置副本。

将母题按各框架内部与母题的尺寸比进行整数倍放大，以共享红色标记像素为锚点印章到框架内部。

**输入结构**：约 22x22 的黑(0)背景网格。左上角区域（约 row 0-4, col 0-4）放置一个橙(7)像素构成的小型图案母题，边界框约 4x4 至 5x5，为不规则的 4-连通图形（约 8-15 像素），内部含有恰好 1 个红(2)标记像素，其余填充像素均为橙(7)。网格其余区域散布 2-4 个灰(5)单像素厚空心矩形框架，框架互不重叠且不与母题重叠。每个框架的内部尺寸为母题边界框尺寸的正整数倍（水平和垂直方向倍率相同，即等比缩放，倍率为 2 或 3），且不同框架的倍率可以不同。每个框架内部恰好有 1 个红(2)标记像素，位于框架内部的某个位置，其余内部像素均为背景色。标记像素的位置经过设计，使得缩放后的母题以该标记为锚点放入框架时，整个缩放母题不超出框架内部边界。生成约束：缩放倍率为正整数且水平垂直相同；缩放后的母题完全落在框架内部范围内；红色标记在母题中的相对位置（行偏移、列偏移相对于母题边界框左上角）乘以缩放倍率后，所得的缩放标记块能覆盖框架内红色标记像素。

**规则**：
1. 提取母题的边界框尺寸 (mh, mw) 和母题内红(2)标记相对于边界框左上角的偏移 (mr, mc)。
2. 对每个框架，计算其内部尺寸 (fh, fw)，缩放倍率 k = fh / mh（保证 fh / mh = fw / mw 且为正整数）。
3. 将母题以最近邻方式放大 k 倍：母题中每个像素变为 k x k 的同色块。放大后的红色标记块大小为 k x k，位于放大母题内偏移 (mr*k, mc*k) 处。
4. 将放大后的母题对齐到框架内部：平移放大母题，使其红色标记块的左上角与框架内部红(2)标记像素重合（即框架内的红色标记像素位于放大标记块的左上角位置）。
5. 在框架内部执行印章放置：仅将放大母题中非背景色的像素写入框架内部对应位置的背景色像素上。已存在的红(2)标记像素和灰(5)框架边框不被覆盖。
6. 擦除左上角的原始母题区域（设为背景色）。

**关键洞察**：框架的内部空间并非空白画布——其尺寸本身就是缩放指令，而内部的单个红色标记像素是定位锚点。缩放倍率和放置位置分别由两种几何属性（面积比和标记坐标）独立编码，必须同时解读才能正确完成印章。
