## 新题 5：自相似晶格恢复后按形状匹配为孔洞着色

**组合逻辑**：[自相似晶格映射 + 缩略图复原](已有) → [补全](创新：恢复的不只是精灵位置，还连带恢复了待填充的孔洞) → [形状匹配](创新：匹配对象从面板间的独立图形变为精灵内部孔洞与外部钥匙图形) → [填充](创新：每个恢复的精灵副本中的每个孔洞都被独立着色)

**来源原语**：自相似晶格映射、缩略图复原、精灵体、插槽阵列、遮挡条、掩码定插槽占位(456873bc)；形状匹配、模板、封闭孔洞、单色对象、形状对应、匹配形状决定填色(93b4f4b3)

**依赖链**：遮挡条隐藏了部分插槽，自相似规则恢复缺失的精灵副本（含其内部孔洞）。恢复后，每个精灵副本中的孔洞需要通过形状匹配从外部钥匙区获取颜色。两步紧耦合：不恢复就缺少部分孔洞需要填充，不做形状匹配就无法确定孔洞颜色。参考题 456873bc 恢复后仅做单像素标记，参考题 93b4f4b3 的匹配发生在两个面板之间——本题将两者的核心机制交织在同一个晶格结构中。

恢复被遮挡条隐藏的精灵副本，再用外部钥匙图形按形状匹配为所有精灵副本的内部孔洞着色。

**输入结构**：约 21x21 的网格。网格被划分为 3x3 的插槽晶格，每个插槽为 5x5 像素，插槽之间由单像素宽的黑(0)分隔线隔开（总计 5x3+2=17 或类似尺寸，实际为 17x17 主晶格区域）。晶格中的精灵副本使用红(2)绘制，每个精灵为相同的 5x5 图案，内部含有 2-3 个形状各异的封闭孔洞（由背景色像素构成的、被红色像素完全包围的连通区域），例如一个 1x1 单像素孔、一个 1x2 竖条孔、一个由 2 个像素组成的 L 形孔。精灵自身的填充掩码（5x5 中哪些位置是红色、哪些是背景）同时作为晶格的粗粒度地图：当且仅当精灵掩码中对应位置是红色时，晶格中该插槽才包含精灵副本。一整行或一整列插槽被蓝(1)实心矩形（遮挡条）覆盖，隐藏了其中的内容。在晶格下方（约 row 18-20），黑(0)背景上放置 2-3 个小型单色图形（钥匙），每个钥匙使用不同颜色（如绿(3)、黄(4)、品红(6)），每个钥匙归一化到其边界框后的形状恰好匹配精灵内部某一个孔洞的形状，且映射关系一一对应。生成约束：所有孔洞形状两两不同；钥匙数量等于孔洞数量；精灵掩码足以唯一确定所有隐藏插槽的内容。

**规则**：
1. 从可见的精灵副本中提取 5x5 精灵掩码（红色位置为填充，背景位置为空）。
2. 将精灵掩码作为粗粒度晶格地图：掩码第 (r,c) 格为填充意味着晶格第 (r,c) 插槽应包含精灵副本。据此确定遮挡条下方被隐藏的插槽是否应含精灵。
3. 擦除遮挡条，在所有应含精灵的插槽中绘制红(2)精灵副本（包括恢复被隐藏的副本）。
4. 对精灵内部的每个孔洞形状，将其归一化到边界框，与下方每个钥匙图形的归一化掩码逐一比较，找到唯一匹配的钥匙。
5. 在晶格中每一个精灵副本内，将每个孔洞的所有像素填充为其匹配钥匙的颜色。
6. 擦除下方钥匙区域的所有图形（设为背景色）。

**关键洞察**：自相似结构回答"哪些位置有精灵"，形状匹配回答"孔洞用什么颜色填"。两个独立的推理机制共同作用于同一组精灵副本：前者决定副本的存在性，后者决定副本内部的着色方案。
