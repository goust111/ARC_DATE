## 新题 7：图例颜色排除异常值后按序补全

**组合逻辑**：[异常值选择(outlier_selection) + 唯一图案选取(unique_pattern_selected)]（检测异常精灵体） → [擦除(erase)]（擦除异常值） → [色条图例(color_bar_legend) + 图例顺序对应插槽(legend_order_to_slot) + 缺失色补入对应位(missing_color_fill_slot)]（创新：异常值的擦除改变了"缺失色"的判定，耦合了两个独立逻辑）

**来源原语**：异常值选择(outlier_selection, cd3c21df)、唯一图案选取(unique_pattern_selected, cd3c21df)、图案匹配(pattern_match, cd3c21df)、忽略干扰项(ignore_distractors, cd3c21df)、精灵体(sprite, 94be5b80)、色条图例(color_bar_legend, 94be5b80)、图例顺序对应插槽(legend_order_to_slot, 94be5b80)、缺失色补入对应位(missing_color_fill_slot, 94be5b80)、擦除(erase, 94be5b80)、印章覆盖(stamp_overlay, 94be5b80)

**依赖链**：在所有精灵体中找出形状唯一的异常值 → 异常值被擦除且其颜色从"已使用颜色"中移除 → 重新对比图例颜色和剩余精灵体颜色，确定缺失色 → 按图例顺序将缺失色的精灵体补入对应插槽

识别形状独特的异常精灵体并擦除，然后按图例顺序用共享形状补入缺失颜色的精灵体。

**输入结构**：黑(0)背景，约 16x16 网格。左侧有一个垂直色条图例，由 4~5 种颜色从上到下排列（每色 1 行 x 2 列的色块紧密堆叠），颜色取自蓝(1)、红(2)、绿(3)、黄(4)、品红(6)。网格右侧区域有若干精灵体（3~6 像素的 4-连通小图形），其中大部分精灵体共享同一种形状（裁剪为边界框后图案相同）但颜色各不相同，对应图例中的部分颜色。有一个精灵体的形状与其他精灵体不同（异常值），其颜色也是图例中的某种颜色。图例中有 1~2 种颜色在右侧区域没有对应的正常（非异常）精灵体。生成约束：异常精灵体的颜色恰好是某种图例颜色，擦除它后该颜色变为"缺失色"之一；正常精灵体在右侧按照固定行间距的垂直插槽排列，左对齐，插槽数量等于图例颜色数量。

**规则**：
1. 裁剪每个精灵体到其边界框，比较各精灵体的形状掩码（忽略具体颜色，只看非黑像素的位置模式）。
2. 找出形状掩码唯一（仅出现一次）的精灵体作为异常值。将其从网格中擦除（变为黑(0)）。
3. 读取色条图例中从上到下的颜色序列，作为插槽顺序（第 1 种颜色对应最上方插槽，第 2 种对应次上方插槽，依此类推）。
4. 将剩余正常精灵体的颜色与图例颜色对比，找出图例中存在但在正常精灵体中不存在的缺失颜色。
5. 对每种缺失颜色，在其对应的插槽位置（与最近的已有正常精灵体左对齐、按行间距定位），用共享的正常形状掩码印章一个新精灵体，颜色为该缺失颜色。
6. 擦除色条图例（图例区域变为黑(0)）。

**关键洞察**：异常值不是最终答案（与源题 cd3c21df 相反），而是干扰项——必须先将其识别并移除，才能正确判定哪些图例颜色是"缺失"的；如果不排除异常值，其颜色会被误认为"已存在"，导致补全遗漏。
