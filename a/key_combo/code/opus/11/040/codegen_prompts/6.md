## 新题 6：面积驱动平移与引导条间隙过滤着陆

**组合逻辑**：[平移(translate) + 位移等于面积(shift_equals_area)] → [引导条(guide_bar) + 投射落间隙则擦(erase_if_gap)]（创新：间隙过滤不是在投射时发生，而是在着陆时——平移到达位置后，检查着陆列是否对齐引导条间隙）

**来源原语**：平移(translate, b2bc3ffd)、计数(counting, b2bc3ffd)、位移等于面积(shift_equals_area, b2bc3ffd)、引导条(guide_bar, f83cb3f6)、投射落间隙则擦(erase_if_gap, f83cb3f6)、擦除(erase, f83cb3f6)、全宽条纹(full_width_stripe, b2bc3ffd)

**依赖链**：每个对象的面积决定其下移距离 → 对象下移后着陆在引导条附近 → 着陆后逐像素检查：若该像素所在列的引导条位置有间隙则擦除该像素，否则保留并重涂为引导条颜色

对象按自身面积大小向下平移，着陆后根据引导条的间隙模式逐列过滤像素。

**输入结构**：黑(0)背景，约 12x18 网格（高大于宽）。网格中下部有一行水平红(2)引导条（仅 1 像素厚），跨越全宽但有 2~4 个 1 格宽的间隙（间隙处为黑(0)）。引导条上方（距引导条至少 4 行）分布 2~4 个单色 4-连通小对象（每个 2~5 像素），颜色各不相同，取自蓝(1)、绿(3)、黄(4)、品红(6)。各对象水平位置不同，互不重叠。生成约束：每个对象向下平移其面积对应的行数后，其最低行恰好落在引导条所在行或引导条上方一行（即平移后对象"停靠"在引导条上方紧邻位置）；平移后各对象互不重叠。

**规则**：
1. 识别引导条上方的每个 4-连通单色对象，计算其像素数（面积）。
2. 将每个对象从原位置擦除（原位置变为黑(0)），然后整体向下平移，行数等于该对象的像素面积。
3. 平移后，逐像素检查：对于对象中的每个像素，查看该像素所在列在引导条行的颜色——若为红(2)（引导条实体），则该像素保留并重涂为红(2)；若为黑(0)（间隙），则该像素被擦除为黑(0)。
4. 引导条本身保持不变。

**关键洞察**：对象的面积同时决定两件事——移动多远（位移量）以及移动后保留多少（因为不同面积导致不同着陆位置，从而对齐引导条的不同列段）；引导条的间隙模式充当着陆区的空间滤波器。
