## 新题 10：形状匹配决定链式填充方向与拉伸量

**组合逻辑**：[形状匹配(shape_matching)] → [链式填充(chain_fill)]（创新：链式填充的方向由匹配到的凹槽朝向决定） + [拉伸(stretch) + 压缩与展开(compress_expand)]（创新：每个链环的尺寸沿链方向递增拉伸）

**来源原语**：形状匹配(shape_matching, 16b78196)、凹槽(notch, 16b78196)、中心条(central_bar, 16b78196)、链式填充(chain_fill, 16b78196)、精灵体(sprite, 16b78196)、拉伸(stretch, 9841fdad)、压缩与展开(compress_expand, 9841fdad)、固定条带宽度(fixed_strip_width, 16b78196)

**依赖链**：中心条的凹槽形状决定哪个精灵体作为根 → 根精灵体填入凹槽后定义链的方向（凹槽开口朝向） → 后续链环沿该方向生长，但每个链环在链方向上比前一个多拉伸 1 行/列 → 拉伸量依赖链环的序号，序号来自链式填充的递推

将精灵体匹配到中心条凹槽后，沿凹槽朝向做链式填充，每个后续链环在生长方向上递增拉伸。

**输入结构**：黑(0)背景，约 15x20 网格。网格中部有一个灰(5)中心条（实心矩形，约 3 行 x 10 列或 10 行 x 3 列），中心条的一侧或两侧有 1~2 个凹槽（凹槽为中心条边界上的矩形缺口，宽/高 2~3 像素，深 1~2 像素，缺口处为黑(0)）。网格中散布 2~4 个单色精灵体（各 4~8 像素的 4-连通图形），颜色取自蓝(1)、红(2)、绿(3)、黄(4)。每个凹槽恰好有一个精灵体的边界框形状与凹槽尺寸匹配（旋转 0/90/180/270 度后与凹槽形状吻合）。不匹配任何凹槽的精灵体是干扰项。生成约束：凹槽开口方向有足够空间（至少 6 格）容纳 3 个递增拉伸的链环。

**规则**：
1. 对每个凹槽，找到边界框尺寸与凹槽吻合的精灵体（可旋转 90 度倍数匹配）。将该精灵体的像素填入凹槽位置（保持精灵体原色），作为链的第 0 环。
2. 确定凹槽的开口方向（上/下/左/右），这就是链的生长方向。
3. 生成第 k 环（k = 1, 2, 3, ...）：取第 0 环的形状，在链生长方向上拉伸 k 行（或列）。即若生长方向为向下，则第 k 环的高度 = 第 0 环高度 + k，宽度不变；像素拉伸方式为最后一行重复 k 次。
4. 将第 k 环紧接在第 k-1 环的外侧放置，颜色与第 0 环相同。
5. 重复直到第 k 环放置后超出网格边界（超出部分裁剪）。
6. 未匹配任何凹槽的干扰精灵体从网格中擦除（变为黑(0)）。
7. 中心条保持灰(5)不变。

**关键洞察**：形状匹配不仅决定"谁填入凹槽"，还隐式决定了链的生长方向和宽度约束；拉伸的递增量使链环不是简单重复而是逐级膨胀，求解者需要从示例中归纳出"第 k 环比根多 k 行"的递增规律。
