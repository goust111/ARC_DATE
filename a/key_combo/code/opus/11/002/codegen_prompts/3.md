## 新题 3：周期与对称联合消歧的图案补全

**组合逻辑**：[补全/周期推断](已有) + [镜像对称](创新：对称性不再是独立变换，而是作为消歧判据筛选唯一合法周期) → 两者互为约束而非串行

**来源原语**：补全/completion、周期瓦片/periodic_tile、缺损像素/erased_pixel、前景残留推断周期/residue_infers_period、周期重复/periodic_repeat (ea959feb) ；镜像/mirror、整幅画布/full_canvas、翻转列序/column_reversal (67a3c6ac) ；镜像对称/mirror_symmetry (e8686506)

**依赖链**：可见前景像素同时兼容多个周期假设——仅靠周期规则无法唯一确定输出；引入左右镜像对称约束后，多个候选周期中恰好只有一个能产生对称结果，从而消歧。周期推断和对称检验并行约束同一个输出，不存在先后顺序。

在部分像素被擦除的网格中恢复完整图案，可见像素同时兼容多种周期，但只有一种周期的补全结果满足左右镜像对称。

**输入结构**：
- 约 12x12 的黑(0)背景网格，列数为偶数。
- 网格上散布着若干彩色前景像素（使用 2~3 种非黑颜色，如红(2)、蓝(1)、绿(3)），其余为黑(0)。
- 这些前景像素是某个同时具有行周期 P 和列周期 Q 且左右对称的完整图案被部分擦除（将部分前景像素改为黑(0)）后的残留。
- 擦除方式经过精心设计：残留像素同时兼容至少两组不同的 (P, Q) 周期假设——即对于每组候选周期，所有残留像素的颜色都满足该周期的残差类一致性。
- 生成约束：在所有兼容的候选周期中，恰好只有一组 (P, Q) 的补全结果同时满足以网格垂直中线为轴的左右镜像对称。其他候选周期的补全结果均不对称。

**规则**：
1. 枚举所有可能的行周期 P（1 至行数）和列周期 Q（1 至列数），找出所有使残留前景像素满足残差类一致性的候选 (P, Q) 对：即对于同一 (row mod P, col mod Q) 残差类中的所有可见前景像素，颜色相同。
2. 对每个候选 (P, Q)，执行周期补全：对于每个包含至少一个可见前景像素的残差类，将该类的所有网格位置填为该颜色；无前景证据的残差类保持黑(0)。
3. 检查每个候选补全结果是否关于网格垂直中线严格左右对称（即 grid[r][c] == grid[r][W-1-c] 对所有 r, c 成立）。
4. 输出唯一通过对称检验的补全结果。

**关键洞察**：残留像素的稀疏分布使得多种周期假设在数据层面均自洽，求解者不能仅靠"最小周期"或"多数投票"来选择——必须引入对称性作为第二约束来消歧。这是一个同时约束满足问题而非线性流水线。

6. 若规则有多个分支，生成器不能长期固定成一个分支；应让分支在随机样例中合理出现。分支概率不必平均——难以发现的隐蔽分支（如少数情况下才触发的特殊规则）应适当提高出现概率，确保在 3 个训练示例中至少出现一次，否则求解者无法归纳该规则。对于颜色映射类规则，确保 2 个左右的示例即可覆盖所有映射关系（每种颜色→颜色的映射至少在某个示例中出现过）。
