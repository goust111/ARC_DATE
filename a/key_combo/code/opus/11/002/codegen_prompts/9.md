## 新题 9：缩放放置受轮廓边界约束

**组合逻辑**：[像素放大 + 对齐放置 + 着色约束](已有) + [描边连线 + 极角排序](创新：轮廓不作为独立图形输出，而是定义放置区域的非矩形边界) + [裁剪](创新：裁剪区域由轮廓而非角标记决定)

**来源原语**：像素放大/scale_up、对齐放置/align_and_place、角标记/corner_marker、着色约束对齐缩放/color_evidence_constrains_scaled_placement (8a004b2b) ；描边连线/outline_tracing、轮廓顶点/outline_vertex、极角排序/polar_angle_ordering、路径需通畅/path_clearance (35ab12c3) ；裁剪/crop (8efcae92)

**依赖链**：轮廓顶点定义一个多边形区域的边界 → 该边界取代角标记成为缩放放置的目标区域 → 精灵体缩放后必须完全落在多边形内部 → 内部的着色证据约束放置位置和缩放因子。轮廓描边和缩放放置共用同一空间域，轮廓决定"在哪放"，证据决定"怎么对齐"。

将小精灵体缩放后放入由顶点轮廓围成的多边形区域内部，利用区域内已有的着色证据约束对齐位置，输出为裁剪到轮廓边界框的结果。

**输入结构**：
- 约 20x20 的黑(0)背景网格。
- 网格上有 4~6 个黄(4)单像素作为轮廓顶点，围成一个凸多边形（相邻顶点可连水平、垂直或 45 度对角线段，段内像素均为黑(0)）。
- 多边形内部散布 2~4 个着色证据像素（非黑非黄颜色），这些像素的颜色和相对位置与某个缩放因子下的精灵体对应位置一致。
- 多边形外部的网格角落有一个小型多色精灵体（约 3x3~4x4，使用蓝(1)、红(2)、绿(3)等颜色），不含黄(4)色。
- 生成约束：恰好存在唯一的整数缩放因子 k 和唯一的放置偏移使得：(a) 缩放后的精灵体完全落在多边形内部（所有像素严格在多边形边内侧），(b) 缩放后精灵体在证据像素位置的颜色与证据一致。

**规则**：
1. 按极角排序连接黄(4)顶点，绘制多边形轮廓线段（用黄(4)色填充中间像素）。确定多边形内部区域（用射线法或奇偶规则判断）。
2. 尝试整数缩放因子 k = 2, 3, 4, ...，对精灵体进行 k 倍像素放大（每个原始像素变为 kxk 块）。
3. 对每个 k，尝试所有可能的放置偏移，找到满足以下条件的 (k, offset) 组合：缩放后精灵体的每个像素都位于多边形内部（不在轮廓线上、不在外部），且所有着色证据像素被缩放精灵体正确覆盖（颜色匹配）。
4. 将缩放后的精灵体绘制在找到的位置上。多边形轮廓线保留。
5. 输出为多边形边界框的裁剪：以所有黄(4)顶点的最小外接矩形裁剪网格。

**关键洞察**：传统的缩放放置题（8a004b2b）使用四个角标记定义矩形区域，而本题用轮廓顶点定义非矩形多边形区域——这使得"放得下"成为一个非平凡的几何判断，缩放因子不再由矩形尺寸直接推出，必须同时满足多边形内部约束和着色证据约束。
