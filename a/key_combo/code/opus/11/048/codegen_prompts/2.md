## 新题 2：计数门控级联激活

**组合逻辑**：[级联激活/cascade_activation] + [计数/counting](创新：计数结果成为传播条件的判据) → [指示条/indicator_bar](创新：条长决定射线是否能到达下一节点) → [射线延伸/ray_extension]

**来源原语**：级联激活(5961cc34), 计数(edcc2ff0), 指示条(edcc2ff0), 射线延伸(5961cc34), 端口/port(5961cc34), 四连通物体(edcc2ff0), 链式反应传播(5961cc34), 条长等于物体计数(edcc2ff0)

**依赖链**：激活一个节点后，必须计数其邻域物体才能确定指示条长度；指示条长度决定射线能延伸多远；射线是否触及下一节点决定级联能否继续。计数→条长→射线长度→是否激活，形成一条依赖链中的反馈约束。

从起始点发射射线激活节点，每个被激活节点生成长度等于其邻域物体计数的指示条，指示条即为射向下一节点的限长射线。

**输入结构**：约 20x20 的黑(0)背景网格。网格中有 4~6 个蓝(1)圆团（各 5~12 像素的紧凑 4-连通区域，无孔洞）。每个蓝圆团的某一侧有 1 个绿(3)像素紧贴其边缘（即端口，指示射线方向：绿像素相对于蓝圆团中心的方位即射线出射方向——上、下、左、右之一）。网格中还散布若干灰(5)小物体（各 1~3 像素的 4-连通区域），不与蓝圆团重叠。网格底部有一个黄(4)像素紧贴一段红(2)短竖线（2~3 像素），作为起始标记。生成约束：蓝圆团沿着射线路径大致串联（但间距不等），使得存在一条从起始点出发依次激活所有蓝圆团的潜在路径；每个蓝圆团的 4-邻域内（包括距蓝圆团边界 1 像素范围内）恰好有 1~5 个灰(5)物体。

**规则**：
1. 从起始标记（黄(4)像素）向上发射一条红(2)射线（宽 1 像素），射线向上延伸直至碰到第一个蓝(1)圆团的边缘像素为止（射线终点为蓝圆团的边缘，不穿入）。
2. 被射线触及的蓝圆团被"激活"：将其所有蓝(1)像素重涂为红(2)。
3. 对刚激活的圆团，计数其 4-邻域范围内（与圆团边缘曼哈顿距离 <= 1 的所有格子中）灰(5)物体的个数 N。
4. 从该圆团的绿(3)端口出发，沿端口指示方向延伸一条红(2)射线，长度恰好为 N 个像素（不多不少）。若射线在 N 像素内碰到另一个蓝圆团，则该圆团被激活，回到步骤 2 继续级联。若 N 像素长的射线未触及任何蓝圆团，级联在此终止。
5. 所有未被激活的蓝圆团保持蓝(1)不变。灰(5)物体、绿(3)端口均保持不变。

**关键洞察**：级联能否传播到下一节点完全取决于当前节点邻域的灰色物体计数——计数过少则射线太短够不到下一节点，级联中断。需要对比多个示例才能发现"射线长度 = 邻域灰物体数"这一隐蔽规则。
