## 新题 6：完整性筛选·缩放打包

**组合逻辑**：[完整方块才标记](创新：完整性作为筛选条件而非标记触发) + [缩放/scaling](保留) + [紧凑排列/compact_packing](保留) + [空间位置排序](保留)

**来源原语**：完整方块才标记(14b8e18c)、完整方块(14b8e18c)、缩放(539a4f51)、紧凑排列(1990f7a8)、空间位置排序(1990f7a8)、裁剪(1990f7a8)

**依赖链**：完整性判断筛选出目标对象→被筛选的对象按空间位置排序→排序结果决定紧凑排列中的放置顺序。筛选条件不确定，后续排列就无法执行。

一句话总结：从网格中筛选出边界框为完整填充正方形的对象，按空间位置排序后缩放至统一尺寸紧凑排列。

**输入结构**：约 20x20 的黑(0)背景网格。包含 5~7 个互不相邻的单色前景对象，每个对象使用不同颜色（从蓝(1)、红(2)、绿(3)、黄(4)、灰(5)、品红(6)、橙(7)中选取）。其中 3~4 个对象是完整的实心正方形（边长 2~4 像素，边界框内所有像素均为该对象颜色）。其余对象是非正方形的图形（L形片段、线段、或矩形但非正方形）。生成约束：完整正方形对象的边长不全相同。

**规则**：
1. 对每个前景对象检测：其边界框是否为正方形，且边界框内所有像素均为该对象颜色（完整正方形判据）。
2. 仅保留通过完整正方形判据的对象，忽略其余对象。
3. 将保留的对象按原始位置排序：按边界框左上角坐标，先行后列（上面的排前面，同行则左边的排前面）。
4. 将每个保留对象缩放为 2x2 像素的色块（保持其颜色）。
5. 将缩放后的 2x2 色块紧凑排列为一行，相邻色块之间间隔 1 列黑(0)像素。输出网格高度为 2，宽度为 (对象数 x 3 - 1)。

**关键洞察**：筛选标准不是颜色或面积，而是"形状完整性"——非正方形对象和不完整填充的正方形都被排除。必须对比输入中被保留和被忽略的对象才能归纳出"完整正方形"这一结构判据。
