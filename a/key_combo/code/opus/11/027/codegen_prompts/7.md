## 新题 7：十字扩展·层叠遮蔽

**组合逻辑**：[扩展/expand](保留) + [透明叠加/transparent_overlay](创新：扩展后的十字图案相互叠加) + [正交对角分工](保留) + [层级优先](创新：优先级由原始十字的面积决定)

**来源原语**：扩展(0962bcdd)、正交对角分工(0962bcdd)、臂色中心色分延(0962bcdd)、十字图案(0962bcdd)、透明叠加(ce4f8723/a68b268e)、层级优先(a68b268e)

**依赖链**：每个十字图案先扩展（臂色正交延伸、中心色对角延伸）→扩展后的图案可能重叠→重叠冲突通过层级优先级解决→优先级由扩展前的原始十字臂长决定。扩展必须先完成才能发现重叠，优先级又需回溯原始尺寸。

一句话总结：将多个双色十字同时扩展（臂色向四个正交方向延伸一步、中心色向四个对角延伸一步），重叠区域由原始臂长较长的十字优先显示。

**输入结构**：约 15x15 的黑(0)背景网格。包含 2~3 个十字图案，每个十字由臂色和中心色两种颜色构成。每个十字的中心为 1 像素的中心色，四条臂为臂色，臂长 1~3 像素（同一十字的四臂等长）。不同十字使用不同的颜色对（例如十字 A：臂色蓝(1)中心色红(2)；十字 B：臂色绿(3)中心色黄(4)）。十字之间相距 2~4 像素，使得扩展后恰好部分区域重叠。生成约束：不同十字的臂长不完全相同（以确保优先级无歧义）。

**规则**：
1. 对每个十字图案执行扩展：
   - 臂色沿上下左右四个正交方向，从当前臂端再延伸 1 像素。
   - 中心色从中心出发，沿四个对角方向各绘制 1 像素。
2. 扩展后若多个十字的像素位置重叠，按优先级规则决定显示哪个：
   - 优先级 = 原始十字的臂长（像素数），臂长更长的十字优先级更高。
   - 高优先级十字的像素覆盖低优先级十字的像素。
3. 非重叠区域正常显示各自颜色。
4. 输出网格尺寸与输入相同。

**关键洞察**：重叠的解决规则并非简单的"后画覆盖前画"或按颜色编号排序，而是回溯到扩展前的几何属性（臂长）——这一优先级来源在输出中不可见，需要对比不同示例中哪个十字"赢得"重叠区域来推断。
