## 新题 11：行列条交织·并集掩码提取

**组合逻辑**：[射线延伸/ray_extend](创新：domino 延伸为行/列条) + [透明叠加/transparent_overlay](创新：行列条交叉形成掩码) + [裁剪/crop](保留) + [行覆盖列](保留) + [并集合并](创新：从掩码并集迁移为行列条交叉区域提取)

**来源原语**：射线延伸(9344f635)、微型标记(9344f635)、行列条(9344f635)、行覆盖列(9344f635)、冲突优先级(9344f635)、透明叠加(ce4f8723)、并集合并(ce4f8723)、裁剪(a644e277)

**依赖链**：domino 标记延伸为行/列条→行条与列条形成交叉网格→交叉点区域（行条与列条重叠处）构成需要提取的掩码→裁剪该掩码的边界框为输出。行列条的绘制规则（行覆盖列）决定了交叉点的颜色，进而影响最终裁剪内容。

一句话总结：将 domino 标记延伸为行条和列条，提取所有行条与列条交叉点构成的最小矩形区域作为输出。

**输入结构**：约 14x14 的黑(0)背景网格。包含 2~3 个水平 domino（同色两像素水平相邻）和 2~3 个垂直 domino（同色两像素垂直相邻）。水平 domino 的颜色彼此不同（从红(2)、绿(3)、黄(4)中选取），垂直 domino 的颜色也彼此不同（从蓝(1)、品红(6)、橙(7)中选取）。水平 domino 与垂直 domino 不在同一行同一列。生成约束：任意一个水平 domino 所在行与任意一个垂直 domino 所在列的交叉点落在网格内。

**规则**：
1. 识别所有水平 domino 和垂直 domino。
2. 将每个垂直 domino 延伸为覆盖该列所有行的列条（该列所有像素染为 domino 颜色）。
3. 将每个水平 domino 延伸为覆盖该行所有列的行条（该行所有像素染为 domino 颜色）。行条绘制在列条之后，交叉点处行条颜色覆盖列条颜色。
4. 找出所有交叉点的位置（行条所在行与列条所在列的交集像素）。
5. 计算所有交叉点的最小边界框，裁剪该区域为输出。输出中交叉点像素为行条颜色（因行覆盖列），非交叉点像素为列条颜色或黑(0)背景。

**关键洞察**：输出不是完整的行列条网格，而是仅裁剪交叉点区域——交叉点的颜色由"行覆盖列"规则决定，使得输出中每个格点都显示对应行条的颜色，需要同时理解覆盖优先级和裁剪范围两条规则。
