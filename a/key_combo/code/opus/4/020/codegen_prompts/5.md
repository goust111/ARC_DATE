## 新题 5：双掩码差异区按连通尺寸分类重涂

**组合逻辑**：[压缩/compress + 逐格比较/cell_comparison](已有：双掩码比较) → [重涂色/recolor + 尺寸分类/size_classification](创新：差异像素合并后按连通分量尺寸分类重涂不同颜色)

**来源原语**：
- 压缩/compress, 堆叠掩码/stacked_mask, 逐格比较/cell_comparison, 背景交集/bg_intersection, 双背景标记输出/both_bg_marks ← fafffa47
- 重涂色/recolor, 连通分量/connected_component, 尺寸分类/size_classification, 单像素分量重涂/single_pixel_component_recolored ← aedd82e4

**依赖链**：逐格比较两个堆叠掩码产出三类区域（仅上层前景、仅下层前景、双背景）→ 将仅上和仅下区域合并为"差异区"→ 差异区像素按 4-连通性分割为连通分量 → 单像素分量和多像素分量分别涂为不同颜色。比较结果定义了差异区的形态，差异区的拓扑结构（连通性）决定了重涂颜色。删除比较则无差异区；删除连通分类则差异区着色未定。

比较上下两个堆叠掩码，将差异区域按 4-连通分量大小分类重涂为不同颜色，双背景区域另色标注。

**输入结构**：
- 黑(0)背景网格，高度为偶数（如 12 行），宽度约 8~10。
- 上半区（前 H/2 行）和下半区（后 H/2 行）各为一个同尺寸的二值掩码。背景色相同为黑(0)；上半区前景色为绿(3)，下半区前景色为橙(7)。
- 每个掩码中前景像素形成若干 4-连通分量，每个分量大小从 1 像素到 5 像素不等。
- 两个掩码的前景区域有部分位置重叠（对应位置都有前景）、部分仅上有、部分仅下有。
- 生成约束：合并后的差异区中，至少包含一个 4-连通大小为 1 的分量和一个大小 >= 2 的分量。

**规则**：
1. 将网格沿行等分为上下两半，各 H/2 行。
2. 逐格比较上下半对应位置 (r, c) 和 (r + H/2, c) 的像素，生成一个 H/2 行 x W 列的输出网格：
   - 若上格为黑(0)且下格为黑(0)（双背景）：输出灰(5)。
   - 若上格为绿(3)且下格为橙(7)（双前景）：输出黑(0)。
   - 若仅上格为绿(3)、下格为黑(0)：标记该格为"差异格"。
   - 若仅下格为橙(7)、上格为黑(0)：标记该格为"差异格"。
3. 将所有差异格按 4-连通性划分连通分量。
4. 大小为 1 的连通分量（边界框 1x1）涂蓝(1)。
5. 大小 >= 2 的连通分量涂红(2)。
6. 输出网格尺寸为 H/2 行 x W 列。

**关键洞察**：前景重叠区域在输出中消失（变为背景黑(0)），而差异区域的着色不取决于差异来自上层还是下层，而取决于差异像素合并后形成的 4-连通分量大小——这种"先做集合差运算、再按拓扑属性分类"的两步逻辑需要对比多个示例才能区分于简单的"上层→一种色、下层→另一种色"的朴素映射。
