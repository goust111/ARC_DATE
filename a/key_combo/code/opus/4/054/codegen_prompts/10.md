## 新题 10：像素放大倍率由对象面积决定的分区缩放

**组合逻辑**：[像素放大/均匀倍率缩放](创新：倍率不是全局统一的，而是逐区域由面积计数决定) + [计数/像素数决定尺寸] + [分类](创新：分类依据是面积而非朝向) + [拼接] → 计数结果参数化了缩放操作

**来源原语**：像素放大/均匀倍率缩放(c59eb873)、计数/像素数决定尺寸(f931b4a8)、分类(d5c634a2)、拼接(a8c38be5)、精灵体(a8c38be5)、边界框(c8cbb738)

**依赖链**：统计每个连通对象的像素面积 → 面积值即为该对象的放大倍率 → 对每个对象的最小外接矩形区域执行对应倍率的像素放大 → 将放大后的各对象按原始位置关系（左到右排序）水平拼接，间隔 1 列黑背景。面积计数直接转化为缩放参数——少一个像素意味着完全不同的输出尺寸。

统计每个前景连通体的像素面积，面积值即为其像素放大倍率，放大后按水平位置拼接。

**输入结构**：约 5x15 的黑(0)背景网格。水平排列 2~4 个互不接触的小型单色连通体（4-连通），每个连通体颜色互不相同（如红(2)、蓝(1)、绿(3)），像素面积在 2~4 之间。各连通体的最小外接矩形不超过 3x3。连通体之间至少间隔 2 列。每个连通体形状不对称（不是简单的矩形或正方形），使得放大后的外观变化清晰可辨。生成约束：各连通体面积互不相同；放大后所有对象水平拼接（含间隔）的总宽度不超过 30。

**规则**：
1. 检测所有非黑的 4-连通连通体，记录每个连通体的颜色、像素面积 a、最小外接矩形内容。
2. 对每个连通体，以其像素面积 a 为倍率，对其最小外接矩形区域执行像素放大：矩形中每个像素（含黑色背景像素）替换为 a x a 的同色块。放大后该对象区域尺寸为 (原高 x a) x (原宽 x a)。
3. 按各连通体在输入中的水平位置从左到右排序（以最小外接矩形左列坐标为键）。
4. 输出网格高度 = 所有放大后区域中的最大高度。宽度 = 所有放大后区域宽度之和 + (连通体数量 - 1) 作为间隔列数。
5. 从左到右将放大后的各对象区域放置到输出中，相邻对象间间隔 1 列黑(0)背景。每个对象顶部与输出顶部对齐，下方不足部分填黑(0)。

**关键洞察**：对象的面积既是被测量的属性又是控制后续操作的参数——面积为 2 的对象放大 2 倍而面积为 4 的放大 4 倍，这种"自引用"关系（对象自身的几何属性决定对自身施加的变换强度）需要求解者跨过"属性→参数"的概念桥梁。
