## 新题 3：碰撞距离编码平铺周期

**组合逻辑**：[射线延伸/碰撞产生侧翼](创新：碰撞不产生侧翼，而是记录碰撞距离) + [平铺/模板瓦片](创新：平铺周期由碰撞距离参数化) + [计数](创新：碰撞次数决定平铺层数) → 射线物理模拟的输出参数化了平铺操作

**来源原语**：射线延伸/行传播(79fb03f4)、碰撞产生侧翼(79fb03f4)、种子像素/障碍像素(79fb03f4)、平铺/模板瓦片(f931b4a8)、计数(d5c634a2/1fad071e)、像素数决定尺寸(f931b4a8)

**依赖链**：种子像素发射射线并撞击障碍像素 → 第一次碰撞的距离决定模板瓦片的水平重复周期 → 总碰撞次数决定模板瓦片的垂直重复层数 → 三个数值（射线颜色、碰撞距离、碰撞次数）分别控制平铺的颜色、宽度、高度，缺少任一都无法确定输出尺寸。

种子像素向右发射射线，第一次碰撞障碍的距离决定输出瓦片的宽度周期，总碰撞次数决定输出的行数。

**输入结构**：约 5x20 的黑(0)背景网格，分为上下两个区域。上方区域（前 2~3 行）：最左列有一个彩色种子像素（如蓝(1)），同一行中散布 2~4 个橙(7)障碍像素，每两个障碍像素之间至少间隔 2 格。下方区域（底部 2~3 行）：一个小型矩形模板瓦片（如 2x3 或 3x2），由 2~3 种非黑非橙颜色构成，左上角与网格左下区域对齐。两个区域之间有至少 1 行全黑分隔。生成约束：种子像素与第一个障碍像素的距离在 2~5 之间；障碍像素均在种子像素同一行；模板瓦片的宽度不超过种子到第一个障碍的距离。

**规则**：
1. 从种子像素向右发射射线（沿同一行），射线遇到障碍像素时停止该段，跳过障碍像素后继续向右发射，直到射线离开网格右边界或没有更多路径。记录：(a) 种子像素到第一个障碍像素的距离 d（不含种子和障碍本身，即中间的空格数）；(b) 射线撞击障碍像素的总次数 n。
2. 输出为一个新网格，尺寸为 n 行 x d 列。
3. 将下方区域的模板瓦片在这个 n x d 网格中进行平铺：模板从左上角开始，水平方向每隔模板宽度重复一次直到填满 d 列（右侧多余部分裁剪），垂直方向每隔模板高度重复一次直到填满 n 行（底部多余部分裁剪）。
4. 上方区域的射线、障碍、种子均不出现在输出中——输出仅为平铺后的新网格。

**关键洞察**：射线碰撞模拟是一个"参数提取器"而非视觉操作——它不改变画面，而是从空间布局中提取两个数值（首次碰撞距离和碰撞总数），这两个数值随后控制一个完全不同的几何操作（瓦片平铺）的尺寸参数。
