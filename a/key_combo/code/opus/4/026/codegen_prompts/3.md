## 新题 3：镜像足迹解码滑动方向与涂色

**组合逻辑**：[镜像 mirror]（创新：镜像不产生可见输出，而是构建坐标系用于解码标记位置）→ [滑动 slide]（创新：滑动方向由标记在镜像足迹中的相对位置编码）→ [重涂色 recolor]（已有原语）

**来源原语**：镜像(mirror) ← 88207623；轴线段(axis_segment) ← 88207623；标记像素(marker_pixel) ← 88207623；跨轴反射(reflection_across_axis) ← 88207623；标记色指定涂色(marker_color_paint) ← 88207623；滑动(slide) ← 320afe60；靠边对齐(edge_aligned) ← 320afe60；重涂色(recolor) ← 320afe60

**依赖链**：必须先计算镜像足迹（反射后的包围盒），才能判断标记像素在足迹中的相对位置；相对位置编码了滑动方向；标记的颜色同时指定重涂色。镜像操作本身不出现在输出中，它仅作为几何解码工具。

利用红色轴段的镜像足迹作为坐标参考系，从足迹内标记像素的方位读取滑动方向，再以标记颜色重涂滑动后的对象。

**输入结构**：约 15x15 黑(0)背景网格。3-4 条红(2)垂直线段（每条 3-5 像素高），不接触网格边缘。每条红线段的左侧或右侧恰好 8-相邻一个黄(4) 4-连通对象（3-7 像素，不对称形状）。在红线段的另一侧，位于该黄色对象镜像足迹（反射后包围盒）内的某个位置，恰好有一个单像素标记，颜色从蓝(1)、绿(3)、橙(7)、品红(6)中取（不与其他标记重复）。生成约束：每个标记在足迹包围盒内的位置明确落在上半区、下半区、左半区或右半区之一（不处于正中线上）；4 个方向（上/下/左/右）在所有对象中至多各出现一次；各对象滑动后互不重叠。

**规则**：
1. 对每条红(2)轴线段，找到与之 8-相邻的黄(4)对象。
2. 将该黄色对象的每个像素关于红线段所在列做水平反射，得到镜像像素集合；计算镜像像素集合的包围盒，即为"镜像足迹"。
3. 在镜像足迹的包围盒内找到唯一的标记像素。
4. 计算标记在足迹包围盒内的归一化坐标：row_frac = (标记行 - 包围盒顶行) / (包围盒高 - 1)，col_frac = (标记列 - 包围盒左列) / (包围盒宽 - 1)。
5. 判断方向：若 |row_frac - 0.5| >= |col_frac - 0.5|，则 row_frac < 0.5 → 向上滑动，row_frac >= 0.5 → 向下滑动；否则 col_frac < 0.5 → 向左滑动，col_frac >= 0.5 → 向右滑动。
6. 将原始黄色对象沿确定的方向平移，直到其前导边缘抵达网格边界（对象整体贴边，不超出）。
7. 将平移后的对象重涂为标记像素的颜色。
8. 从输出中移除所有红线段和标记像素，只保留背景和重涂后的滑动对象。

**关键洞察**：镜像操作从不在输出中留下痕迹——它仅作为几何坐标系存在，将标记像素的绝对位置转换为相对于对象形状的方位信号，从而编码了滑动方向。标记同时承载了方向信息（位置）和颜色信息（颜色值），实现了双重编码。
