## 新题 8：缺口方向驱动的计数次平铺与像素数分层遮挡

**组合逻辑**：[平铺 tile]（已有原语）+ [计数 count]（创新：像素计数同时决定平铺重复次数和遮挡优先级，单一属性的双重角色）+ [缺口决定方向 notch_determines_dir]（创新：缺口不再决定滑动方向，而是决定平铺方向）+ [遮挡覆盖 occlusion_overwrite]（已有原语）

**来源原语**：平铺(tile) ← 34cfa167/b99e7126；计数(count) ← 878187ab；计数映射尺寸(count_maps_to_size) ← 878187ab；边框缺口(border_notch) ← 320afe60；缺口决定方向(notch_determines_dir) ← 320afe60；遮挡覆盖(occlusion_overwrite) ← 13713586；按距离排序绘制(draw_ordered_by_distance) ← 13713586

**依赖链**：缺口方位决定平铺方向（四向之一）；像素计数决定平铺重复次数；当不同对象的平铺区域重叠时，像素计数再次作为遮挡优先级裁判（像素少的对象在上层）。三个属性（缺口位置、像素数量、重叠区域）形成紧耦合：改变任一对象的缺口位置会改变其铺展方向从而改变重叠格局，改变像素数会同时改变铺展长度和遮挡优先级。

每个前景对象按其缺口朝向的方向平铺，重复次数等于其像素数，重叠区域由像素数更少的对象覆盖更多的对象。

**输入结构**：约 20x20 黑(0)背景网格。3-4 个单色 4-连通前景对象，各使用不同颜色（红(2)、绿(3)、蓝(1)、黄(4)），每个对象有 4-8 个前景像素，包围盒至少 3x3。每个对象的包围盒边界上恰好有一处"缺口"：该侧边界行（或列）上存在一个被两个同色前景像素夹着的黑(0)背景像素。不同对象的缺口分布在不同侧（上/右/下/左各至多一个对象）。对象之间有足够间距使得原始位置不重叠。生成约束：至少两个对象的平铺区域存在部分重叠；所有对象像素数互不相同。

**规则**：
1. 对每个对象，识别其缺口侧：检查包围盒四侧的边界像素行/列，找到存在"被同色像素夹着的背景间隙"的那一侧。
2. 缺口侧决定平铺方向：缺口在上侧 → 向上平铺，缺口在右侧 → 向右平铺，缺口在下侧 → 向下平铺，缺口在左侧 → 向左平铺。
3. 计数该对象的前景像素数 C，平铺 C 次（含原始位置，故新增 C-1 个副本）。
4. 将对象裁剪到包围盒后，沿平铺方向依次紧贴排列副本（每个副本的前导边紧接前一个副本的尾随边，无间隔）。
5. 超出网格边界的副本像素被裁剪丢弃。
6. 绘制顺序：按像素数 C 降序绘制各对象的平铺区域（像素最多的对象先画，最少的后画），后画的覆盖先画的。即像素数最少的对象在最顶层。
7. 若两个对象像素数相同（生成约束中已排除此情况，此条为防御性规则），以包围盒左上角扫描序靠前的优先在上层。

**关键洞察**：像素计数承担了双重角色——它既是"铺多少次"的计量器，又是"谁覆盖谁"的优先级排序依据。一个像素少的对象铺展范围小但在重叠处总能显现；一个像素多的对象铺展广阔但在任何冲突中都被压在下面。缺口方向则将这种铺展-遮挡博弈投射到特定的空间轴上。
