## 新题 3：面积决定角色的镜像-射线分叉

**组合逻辑**：[面积区分角色](创新：面积不再区分"动/静"，而是区分"镜像目标"与"射线源") → [镜像](已有：围绕红标记点反射) ∥ [射线延伸](创新：射线方向由标记点→小分量的矢量决定，且使用交替色) → [遮挡判定](创新：镜像产物可阻断射线)

**来源原语**：面积区分角色(area_determines_role, 6ca952ad)、镜像(mirror, 7ed72f31)、反射轴标记(reflection_axis_marker, 7ed72f31)、透明叠加(transparent_overlay, 7ed72f31)、射线延伸(ray_extend, 97999447)、奇偶交替(parity_alternation, 97999447)、精灵体(sprite, 7ed72f31)

**依赖链**：每个红标记点的邻域内有多个不同大小的分量 → 面积最大者被选为镜像载荷，其余为射线源 → 镜像操作先执行，产物叠加到网格上 → 射线从小分量出发沿径向延伸，但镜像产物占据的像素会阻断射线 → 因此镜像的几何形状直接影响射线的长度

将每个红标记点附近面积最大的分量点反射到对侧，同时从较小分量沿离开标记点的方向发射交替色射线，射线被镜像产物阻断。

**输入结构**：约 18x18 的网格，黑(0)背景。包含 2~3 个红(2)单像素标记，彼此间距至少 8 像素。每个红标记的 8-连通邻域（半径约 3~4 像素内）有 2~3 个不同颜色的 4-连通单色分量（每个分量 2~7 像素，颜色从绿(3)、蓝(1)、橙(7)、栗(9)中选取，每个标记邻域内各分量颜色不同）。每个标记邻域内恰好有一个分量面积严格最大。生成约束：面积最大分量关于红标记点反射后落在网格内，且不与其他标记的邻域重叠；各标记邻域的分量不互相接触。

**规则**：
1. 对每个红(2)标记像素，找出与其 8-连通距离不超过 4 的所有非红、非黑 4-连通分量。
2. 在这些分量中，面积（像素数）最大的标记为"载荷"，其余标记为"射线源"。
3. 将载荷关于红标记做 180 度点反射（每个载荷像素 (r,c) 映射到 (2*mr-r, 2*mc-c)，其中 (mr,mc) 为红标记坐标），反射像素以载荷的原色绘制在网格上，仅覆盖黑(0)像素（非黑像素不被覆盖）。
4. 对每个射线源分量，计算从红标记指向该分量质心的方向矢量，取最近的正交方向（上/下/左/右）作为射线方向。若与两个正交方向等距，取行方向（水平）优先。
5. 从该射线源分量在射线方向上最远的像素开始，沿射线方向逐像素延伸：偏移量为偶数的像素涂该分量的颜色，偏移量为奇数的像素涂灰(5)。射线遇到非黑像素（包括步骤 3 的镜像产物、其他分量、其他射线已绘制的像素）时停止，不包含终止像素。射线超出网格边界时也停止。
6. 红(2)标记像素保持不变。各射线源和载荷的原始像素保持不变。

**关键洞察**：面积在源题中区分"动态精灵"与"静态标记"，但在本题中区分"被镜像的对象"与"发射射线的对象"——两种完全不同的变换操作由同一属性分配。镜像产物不是装饰性叠加，而是在空间中构筑了阻断射线的实体屏障。需要先完成镜像才能确定射线长度，射线长度对于不同标记点因其载荷形状不同而各异。
