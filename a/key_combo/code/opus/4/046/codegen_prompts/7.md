## 新题 7：锚点平移作为选择性图案补全

**组合逻辑**：[平移复制·锚点对齐](已有) × [补全·完整图案推断缺失](已有) → [选择性绘制](创新：平移不再是盲目复制整个精灵体，而是仅填充目标位置的缺失像素，使每次"复制"都是不同的补全操作)

**来源原语**：平移复制/锚点对齐/锚点偏移对应/源锚点/目标锚点(2c737e39), 补全/形状匹配/完整图案推断缺失/模板精灵体(72322fa7)

**依赖链**：源精灵体提供完整模板（什么该存在），目标位置的现有像素提供局部约束（什么已存在），两者的差集决定实际绘制内容。没有源模板则不知道完整图案；没有目标现状则无法判断缺失部分。平移对齐将源的坐标系映射到目标的坐标系，使补全成为可能。

将完整精灵体的形状通过锚点对齐平移到每个目标标记处，但只绘制目标位置上缺失的像素，保留已有像素不变。

**输入结构**：
- 黑(0)背景，约 14x14。
- 一个源精灵体区域：包含一个小型 4-连通多色图案（4~8 像素，使用 1~2 种非黑非灰颜色，如蓝(1)和红(2)），加上一个紧邻该图案的灰(5)像素作为源锚点。
- 2~4 个目标区域，每个包含：
  - 一个灰(5)目标标记像素。
  - 源精灵体图案的一个局部副本：精灵体中的部分像素已按正确的相对位置（以目标标记为锚点）出现，其余缺失（为黑色）。不同目标可能缺失不同的像素子集。
- 生成约束：所有目标区域（含完整补全后的范围）互不重叠，也不与源区域重叠。每个目标至少有一个像素已存在、至少有一个像素缺失。已存在的像素颜色与源模板对应位置一致。

**规则**：
1. 识别源精灵体：以灰色源锚点为参照，记录所有相邻的非黑非灰像素及其相对于锚点的偏移 (dr, dc) 和颜色。
2. 对每个灰色目标标记位置 (r_t, c_t)：
   a. 对源精灵体的每个像素偏移 (dr, dc) 及颜色 C：
      - 检查目标位置 (r_t + dr, c_t + dc)。
      - 若该位置为黑(0)（缺失）→ 涂为颜色 C。
      - 若该位置已有非黑像素 → 不改动（该像素应已与 C 一致）。
   b. 将目标标记灰色像素擦除为黑(0)。
3. 将源锚点灰色像素擦除为黑(0)。源精灵体的其余非灰像素保持不变。

**关键洞察**：参考题 2c737e39 中的平移复制是无条件的——整个精灵体被复制到目标位置。本题将平移复制重新解释为条件补全：每个目标位置已有部分信息，平移只填补空缺。这使得同一个精灵体在不同目标处产生不同的绘制结果，求解者必须识别出部分副本是同一完整模板的不同子集，而非不同的图案。
