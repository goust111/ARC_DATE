## 新题 5：连通分量面积筛选出候选体与凹槽并按旋转匹配执行颜色互换

**组合逻辑**：[连通分量检测 + 面积阈值筛选](创新：同一次检测中按面积阈值将分量分为"候选体"和"凹槽主体") → [洪泛填充](识别凹槽主体内部的凹槽区域) → [旋转平移嵌入 + 形状匹配](候选体旋转后尝试嵌入凹槽) → [颜色角色互换](创新：成功匹配后，候选体和凹槽的颜色互换而非简单填充)

**来源原语**：连通分量检测、面积阈值筛选、单色连通体(12eac192)；洪泛填充、封闭背景区域(83302e8f)；形状匹配、凹槽、候选块、旋转平移嵌入、完全覆盖、无重叠(1acc24af)；颜色角色互换(c6141b15)；重涂色(1acc24af/12eac192)

**依赖链**：连通分量检测将所有前景分量按面积分为两组 → 大分量（面积 >= 阈值）是"凹槽主体"，其内部的背景连通区域即凹槽 → 小分量（面积 < 阈值）是"候选体" → 每个候选体尝试四种旋转与每个凹槽做形状匹配 → 匹配成功时执行颜色互换：候选体像素变为凹槽主体颜色，凹槽像素变为候选体原色 → 面积阈值决定了角色分配，而不是位置

连通分量的面积决定其角色（候选体 vs. 凹槽主体）；候选体旋转匹配凹槽后，双方颜色互换。

**输入结构**：约 18x18 的黑(0)背景网格。网格中有 2 个较大的单色 4-连通前景对象（"凹槽主体"），颜色分别为蓝(1)和绿(3)，每个面积在 15~25 像素之间，形状不规则但内部各含有 1 个由黑(0)背景构成的封闭凹槽（凹槽面积 3~5 像素，形状不规则）。网格中另有 3~4 个较小的单色 4-连通前景对象（"候选体"），颜色各异取自 {红(2), 黄(4), 灰(5), 品红(6)}，每个面积在 3~5 像素之间。候选体散布在凹槽主体周围，与凹槽主体不相邻。生成约束：恰好有 2 个候选体能在某个旋转（0/90/180/270 度）下与某个凹槽完全形状匹配（面积相等且形状吻合），其余候选体与所有凹槽均不匹配；每个凹槽最多被一个候选体匹配；所有前景分量的面积要么 >= 12（大），要么 <= 6（小），中间无歧义。

**规则**：
1. 检测网格中所有非背景的 4-连通单色分量，计算每个分量的面积。
2. 面积 >= 12 的分量为"凹槽主体"；面积 <= 6 的分量为"候选体"。
3. 对每个凹槽主体，找到其边界框内被该主体颜色完全包围的黑(0) 4-连通区域，即"凹槽"。凹槽不触及网格边界且不触及主体边界框外部。
4. 对每个候选体，尝试 0/90/180/270 四种旋转。对每种旋转后的形状，检查是否与某个凹槽面积相同且形状完全一致（像素逐一对应）。
5. 若候选体在某个旋转下与某个凹槽匹配，执行颜色互换：(a) 将该候选体在输入中的所有像素（原始位置、原始未旋转形态）重涂为其匹配的凹槽主体的颜色；(b) 将该凹槽的所有像素重涂为该候选体的原始颜色。
6. 不匹配的候选体保持原色不变。凹槽主体的非凹槽像素保持原色不变。
7. 若一个候选体的旋转能匹配多个凹槽（生成约束保证不会发生），优先匹配按凹槽主体边界框左上角阅读序靠前的。

**关键洞察**：面积阈值同时完成了"角色分配"和"干扰排除"——求解者无法通过位置或颜色判断谁是候选体谁是凹槽主体，只能通过面积。而匹配成功后不是简单地把候选体塞入凹槽，而是执行颜色互换，使得输入中的候选体和凹槽都发生颜色变化。需要对比多个示例才能归纳出"互换"而非"单向填充"的规则。
