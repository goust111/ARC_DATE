## 新题 3：矩形堆叠揭示隐藏标记驱动水平重复

**组合逻辑**：[排序 + 堆叠](按面积从大到小堆叠矩形) → [前景遮挡](堆叠产生遮挡关系，决定哪些标记可见) → [计数](统计可见标记数) → [重复](按标记数水平重复堆叠结果)

**来源原语**：排序、堆叠、填充矩形、角对齐、按面积降序(20818e16)；前景遮挡(52df9849)；计数、重复、单像素标记、标记数等于副本数(4852f2fa)；标记计数驱动重复(4852f2fa)

**依赖链**：各矩形按面积降序堆叠于左上角 → 堆叠顺序决定遮挡关系：小矩形在上层可见，大矩形被部分遮挡 → 某些矩形内部嵌有栗(9)标记像素，被更大矩形遮挡的标记不可见，只有最终可见的标记参与计数 → 可见标记总数 N 决定输出宽度：将堆叠结果水平拼接 N 份

矩形按面积堆叠后，仅未被遮挡的标记像素可见；可见标记数决定堆叠图像的水平重复次数。

**输入结构**：约 18x18 的黑(0)背景网格。散布 4~5 个不同颜色的实心矩形（颜色取自 {蓝(1), 红(2), 绿(3), 黄(4), 灰(5)}），每个矩形的宽和高在 3~8 像素之间，面积互不相同。矩形在输入中的位置互相分离（不重叠），每个矩形的完整尺寸可由其可见像素的边界框恢复。其中 2~3 个矩形内部各含有 1~2 个栗(9)标记像素（替换了该矩形颜色的像素）。标记像素的位置经过设计：当矩形按面积降序堆叠于左上角后，部分标记被更上层的小矩形完全覆盖而不可见，剩余标记仍然可见。生成约束：最终可见标记数 N 在 2~4 之间；堆叠结果的宽度乘以 N 不超过 30 像素；至少有 1 个标记在堆叠后被遮挡（否则遮挡逻辑无法验证）。

**规则**：
1. 对每种非背景、非栗(9)的前景颜色，用该颜色所有像素（包括被栗(9)标记替换的原始位置）的边界框宽高恢复其完整矩形。标记像素视为其所在矩形颜色的一部分来确定边界框，但标记像素本身保持栗(9)。
2. 按矩形面积从大到小排序。以输出画布左上角 (0,0) 为所有矩形的左上角对齐点，依次绘制矩形（大的先画，小的后画覆盖大的）。每个矩形内部的栗(9)标记像素在对应相对位置保持为栗(9)。
3. 堆叠完成后，统计画布上所有可见的栗(9)像素数量，记为 N。（被后绘制的矩形覆盖的标记不计入。）
4. 输出为堆叠图像在水平方向拼接 N 份。输出高度等于最大矩形的高度，输出宽度等于最大矩形的宽度乘以 N。各份之间无间隔，直接相邻。

**关键洞察**：堆叠顺序（由面积决定）不仅决定视觉结果，还过滤了哪些标记像素可见——这是一个信息揭露步骤而非简单的渲染步骤。求解者必须先正确堆叠才能正确计数，而计数结果又驱动输出的整体结构。单个示例中可能无法区分"统计所有标记"和"统计可见标记"，必须对比多个示例（不同遮挡情况）才能发现遮挡过滤规则。
