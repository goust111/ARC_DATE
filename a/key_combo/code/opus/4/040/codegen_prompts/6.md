## 新题 6：标记对定义裁剪跨度后按面积分配平铺角色

**组合逻辑**：[标记对定义跨度](每个矩形框上的标记对定义裁剪窗口) → [裁剪](从每个框中裁出标记跨度内的子区域) → [尺寸排序](按裁剪结果面积排序) → [周期平铺](创新：面积最小的裁剪结果作为图案模板，周期平铺到所有较大裁剪结果的区域内)

**来源原语**：标记对定义跨度、标记像素(f3e14006)；裁剪、矩形框、内部区域(1c786137/1a6449f1)；尺寸排序(48634b99)；周期平铺(53fb4810)；边框包围内容(1a6449f1)；包含(1c786137)

**依赖链**：每个矩形框的边框上有两个同色标记像素，它们定义了一个行跨度或列跨度 → 该跨度限定了从框内部裁出的子区域范围 → 所有裁出的子区域按面积排序 → 面积最小的子区域成为"图案模板" → 其余子区域在输出中被该模板周期平铺填充 → 标记位置决定裁剪范围，裁剪范围的相对大小决定谁是模板谁是画布

矩形框上的标记对定义裁剪跨度；裁剪出的最小子区域成为模板，周期平铺到其余裁剪区域中。

**输入结构**：约 22x22 的黑(0)背景网格。网格中有 3 个互不重叠的单像素厚单色矩形框（空心矩形），颜色分别为蓝(1)、红(2)、绿(3)，大小不同（内部区域约 4x4 到 8x8）。每个矩形框的边框上恰好有 2 个黄(4)标记像素，替换了边框原色。这两个标记像素位于同一条边框边上（同在顶边、底边、左边或右边），定义了一个跨度：若在水平边上则定义列跨度（两标记之间的列范围），若在垂直边上则定义行跨度（两标记之间的行范围）。每个矩形框的内部包含一些由灰(5)像素组成的小图案（1~6 个灰像素，位置各异）。生成约束：三个框的标记跨度裁剪出的子区域面积互不相同；最小裁剪区域的宽和高都能整除其余每个裁剪区域的对应维度（保证周期平铺无余数）；框内灰(5)图案不触及边框。

**规则**：
1. 找到每个矩形框边框上的两个黄(4)标记像素。确定它们所在的边（上/下/左/右）。
2. 若标记在水平边上，裁剪窗口的列范围为两标记像素之间（不含标记所在列），行范围为框内部的全部行。若标记在垂直边上，裁剪窗口的行范围为两标记像素之间（不含标记所在行），列范围为框内部的全部列。
3. 从每个框内部裁出对应窗口内的子网格（包含其中的灰(5)图案像素和黑(0)背景像素）。
4. 按裁剪子网格的面积（行数 x 列数）从小到大排序。面积最小的子网格记为 T（模板）。
5. 对其余每个裁剪子网格 C，将 T 从 C 的左上角开始周期平铺（水平和垂直方向均重复），直到完全覆盖 C 的范围。平铺时 T 中的灰(5)像素覆盖 C 中对应位置的像素，T 中的黑(0)像素不覆盖（保持 C 原有内容）。
6. 将平铺结果写回每个非模板框的对应内部区域。模板所在框的内部保持不变。矩形框边框保持不变（黄(4)标记也保留）。框外区域保持黑(0)。

**关键洞察**：标记像素的位置在每个框上独立定义了不同的裁剪窗口，导致同样大的框可能裁出不同大小的子区域。谁是"模板"谁是"画布"不由框的大小决定，而由标记位置决定的裁剪结果的相对面积决定——这个角色分配是间接的，必须先完成裁剪才能确定。
