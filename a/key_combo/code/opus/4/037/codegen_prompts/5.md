## 新题 5：嵌入/孤立分类控制镜像轴与修复

**组合逻辑**：[嵌入与孤立分类](已有) → [修补](已有，嵌入标记→修复) + [计数→奇偶判定](创新：孤立标记的数量编码镜像方向) → [镜像 + 对侧放置 + 颜色按方位定](已有，但轴选择由计数决定而非凸耳位置)

**来源原语**：embedded_vs_isolated / repair / edge_line / edge_indicates_direction（8886d717）、mirror / opposite_place / tab_determines_axis / color_by_orient（dc2e9a9d）、outline（dc2e9a9d）

**依赖链**：分类嵌入/孤立标记 → 嵌入标记修复为轮廓色 → 孤立标记计数 → 奇偶性决定镜像轴 → 按轴镜像并按方位涂色

修复轮廓中的嵌入缺陷，然后统计内部孤立标记数量，奇数时水平镜像（涂蓝），偶数时垂直镜像（涂青），在对侧生成副本。

**输入结构**：约 16x16 的黑(0) 背景网格。含 2~3 个绿(3) 轮廓对象（每个为 4-连通的单像素厚空心环形，围成的内部区域约 3x3~5x5，形状各异——可以是矩形环、不规则多边形环等）。每个轮廓内部和轮廓像素上散布若干红(2) 标记像素：嵌入标记位于轮廓像素位置（该位置本应为绿(3)，被替换为红(2)，其 4-邻域中有 >= 2 个绿(3) 像素），孤立标记位于轮廓内部的黑(0) 区域中（4-邻域中绿(3) 像素 <= 1 个）。每个轮廓内部的孤立标记数量为 1~4 个。生成约束：不同轮廓的孤立标记数量奇偶性不全相同（至少一个奇数、一个偶数），以确保两种镜像方向都出现。各轮廓之间间距 >= 3，镜像副本不会与任何原有对象重叠。

**规则**：
1. 对每个绿(3) 轮廓对象，识别其中所有红(2) 标记像素，分类为嵌入或孤立：
   - 嵌入：该红(2) 像素的 4-邻域中绿(3) 像素 >= 2 个。
   - 孤立：该红(2) 像素的 4-邻域中绿(3) 像素 <= 1 个。
2. 将所有嵌入标记重涂为绿(3)（修复轮廓缺陷）。孤立标记保留红(2) 不变。
3. 统计每个轮廓内部的孤立标记数量 N。
4. 若 N 为奇数：将修复后的轮廓（含内部孤立标记）水平镜像，副本放置在原轮廓 bbox 左侧（若原轮廓偏右）或右侧（若原轮廓偏左），间隔 1 列，副本涂蓝(1)（副本中孤立标记也变蓝）。
5. 若 N 为偶数：将修复后的轮廓垂直镜像，副本放置在原轮廓 bbox 上方（若原轮廓偏下）或下方（若原轮廓偏上），间隔 1 行，副本涂青(8)（副本中孤立标记也变青）。
6. "偏左/偏右/偏上/偏下"以轮廓 bbox 中心与网格中心的相对位置判定。
7. 镜像副本超出网格边界的部分裁剪丢弃。

**关键洞察**：嵌入/孤立分类在源题中只决定"修复还是延伸"，这里孤立标记的数量进一步编码了镜像方向——必须先完成分类和修复，才能正确计数，计数结果又决定了完全不同的空间变换。仅看单个示例可能无法区分奇偶规则，需要对比多个轮廓的不同行为才能归纳。

p = Path("/home/lixinyu/snap/a/key_combo/code/opus/4/037/5.py")
mod = SourceFileLoader("new_arc_task", str(p)).load_module()
sigs = set()
for i in range(100):
    inp = mod.generate_input()
    out = mod.main(inp)
    assert isinstance(inp, np.ndarray)
    assert isinstance(out, np.ndarray)
    assert inp.ndim == 2 and max(inp.shape) <= 30, f"input grid exceeds 30x30: {inp.shape}"
    assert out.ndim == 2 and max(out.shape) <= 30, f"output grid exceeds 30x30: {out.shape}"
    sigs.add(hashlib.md5(inp.tobytes() + str(inp.shape).encode()).hexdigest())
print("variants", len(sigs))
assert len(sigs) >= 20
