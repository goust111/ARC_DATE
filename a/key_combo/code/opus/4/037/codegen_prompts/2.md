## 新题 2：裂缝分离后的重力堆叠与重合判定

**组合逻辑**：[裂缝标记线 + 沿短轴分裂](已有) → [擦除](已有) → [重力下落 + 碰撞阻挡 + 重力远近序处理](已有，但作用对象变为裂缝产生的碎片) → [重涂色](已有，触发条件为碎片重合判定——创新)

**来源原语**：fracture_line / split_along_short / halves_separate / erase（2faf500b）、gravity_drop / collision_blocking / gravity_far_to_near（5ffb2104）、recolor（dc2e9a9d）

**依赖链**：裂缝分裂产出碎片集 → 碎片加入全局重力场 → 碰撞阻挡决定最终位置 → 同色碎片是否垂直相邻决定是否重涂色

将每个含裂缝的对象沿裂缝分离为两半，所有碎片与未裂对象一起向下做重力堆叠，堆叠后同源两半若垂直相邻则合并并变色。

**输入结构**：约 18x12 的黑(0) 背景网格。含 3~4 个 8-连通前景对象，每个对象使用一种独有的体色（从蓝(1)、绿(3)、黄(4)、橙(7) 中选取，各对象颜色互不相同）。对象为 4~8 像素的不规则连通图形（非矩形、非对称均可），bbox 为非正方形。其中 2~3 个对象内部有一条由栗(9) 像素组成的裂缝线，沿 bbox 较短轴完整贯穿（宽对象为竖线，高对象为横线）。其余对象无裂缝线。各对象在网格中垂直位置不同、互不接触，底部留有足够下落空间。生成约束：裂缝分离后产生的碎片形状保证在重力下落后，恰好有一对同源碎片能够垂直相邻（相邻指两碎片的 bbox 在垂直方向仅隔 0 行），而至少一对同源碎片因为中间夹有其他对象而无法相邻。

**规则**：
1. 对每个含栗(9) 裂缝线的对象：擦除裂缝线像素，将对象沿裂缝方向分离——裂缝左侧的体色像素向左移 1 格，右侧向右移 1 格（若裂缝为竖线）；上半向上移 1 格，下半向下移 1 格（若裂缝为横线）。无裂缝对象保持不变。
2. 对所有碎片和完整对象施加向下重力：按原始位置从下到上的顺序依次处理，每个碎片/对象保持形状和颜色向下滑动，直到触及网格底边或已就位的其他碎片/对象。
3. 重力就位后，检查每对同源碎片（同体色、来自同一原始对象的两半）：若它们的像素在垂直方向直接相邻（上半最低行紧邻下半最高行，且水平投影有重叠），则将这两个碎片的所有像素重涂为青(8)。
4. 不满足相邻条件的碎片保留原体色。

**关键洞察**：裂缝分离产出的碎片数量直接改变了重力场中的参与者集合，而重力堆叠的碰撞结果又反过来决定了哪些同源碎片能够重合——中间插入的无关对象充当阻隔，使得重合判定不可预知，必须模拟完整重力过程才能确定最终颜色。
