**组合逻辑**：[分隔线 + 阵列排布 + 模板](已有) + [行标签 + 列标签 + 标签同色时填充](已有，从等式表场景迁移到模板修复的条件判断) → [补全](已有，但修复方式由标签匹配结果分支决定——创新) + [重涂色](已有)

**依赖链**：格栅解析 + 标签读取同步进行 → 标签配对判断每个单元的修复模式 → 匹配时用模板图案修复并重涂为标签色，不匹配时填充分隔色

将被局部擦除的模板阵列按行列标签是否同色分两种方式修复：同色时恢复模板图案并染为标签色，异色时以分隔色填平。

**输入结构**：约 17x17 的网格，灰(5) 分隔线（完整行和完整列）将其切分为 3x3 的方形单元阵列，每个单元约 5x5。网格右侧紧邻一列标签列（3 个像素，每个对应一个单元行，颜色从红(2)、蓝(1)、绿(3) 中选取），网格底部紧邻一行标签行（3 个像素，每个对应一个单元列，颜色同样从上述三色中选取）。左上角单元包含完整的模板图案（由黑(0) 背景和一种前景色黄(4) 构成的 3~5 像素 4-连通图形）。其余 8 个单元中，部分像素被替换为黑(0)（模拟缺失），但至少保留 1 个黄(4) 像素以暗示原始图案存在。生成约束：标签行和标签列中至少有一对同色匹配和一对异色匹配，以确保两种修复模式都出现。

**规则**：
1. 识别灰(5) 分隔线，切分出 3x3 单元阵列和边缘标签。
2. 以左上角单元为模板。对于阵列中 (r, c) 位置的每个非模板单元：
   a. 读取行标签（右侧列第 r 个像素的颜色）和列标签（底部行第 c 个像素的颜色）。
   b. 若行标签与列标签颜色相同：将该单元中所有缺失位置（当前为黑(0) 但模板对应位置为黄(4) 的格子）恢复为前景，但颜色不用黄(4)，而用该匹配的标签颜色重涂。已有的黄(4) 像素也重涂为标签色。
   c. 若行标签与列标签颜色不同：将该单元中所有缺失位置填充为灰(5)（分隔色），已有的黄(4) 像素保持不变。
3. 模板单元本身不做任何改动。标签行列不做改动。

**关键洞察**：模板补全在源题中是无条件的（所有单元统一用分隔色填充缺失），这里引入行列标签匹配作为分支条件——同一个模板在不同单元中以不同颜色或不同方式修复。仅看单个示例无法确定标签匹配规则，必须对比多个示例中同位置单元在不同标签配色下的表现才能归纳出分支逻辑。
