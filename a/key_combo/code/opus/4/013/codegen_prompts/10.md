## 新题 10：控制像素方位循环置换精灵嵌入方案

**组合逻辑**：[嵌入/形状匹配](已有，产生"自然匹配") → [定位/相对方位](创新：控制像素的方位不再选择 3x3 内的槽位，而产生一个置换偏移量) → 置换偏移循环重映射精灵-孔洞配对

**来源原语**：嵌入/embed(228f6490), 形状匹配/shape_matching(228f6490), 精灵体/sprite(228f6490), 孔洞/hole(228f6490), 拼图块嵌入孔洞/piece_fits_hole(228f6490), 定位/locate(18286ef8), 控制像素/control_pixel(18286ef8), 相对方位/relative_position(18286ef8), 方位决定槽位/position_selects_slot(18286ef8)

**依赖链**：形状匹配建立精灵与孔洞的"自然配对"（形状一致），但控制像素的方位计算出一个循环偏移量，将自然配对重新打乱。最终每个精灵不一定嵌入与其形状匹配的孔洞，而是嵌入偏移后的孔洞。删除形状匹配则无法建立自然序；删除控制像素定位则无偏移量，退化为简单嵌入。

先用形状相等为精灵和孔洞建立自然配对顺序，再用控制像素相对于灰色矩形群的方位计算循环偏移量，对配对方案做循环置换后执行嵌入。

**输入结构**：
- 约 14x14 的网格，背景为黑(0)。
- 网格中有 N 个灰(5)矩形对象（N = 3 或 4），每个矩形内有一个形状各异的黑(0)孔洞（4-连通，3~6 像素，不规则形状）。各矩形不相邻，按边界框左上角从左到右、从上到下排列可得到确定顺序。
- 网格中另有 N 个彩色精灵体（颜色两两不同，使用蓝(1)、红(2)、黄(4)、绿(3)中的 N 种），每个精灵的二值形状恰好与某个孔洞的形状全等（一一对应）。精灵位于灰色矩形的外部。
- 网格中有一个品红(6)控制像素，位于所有灰色矩形和精灵体之外。
- 生成约束：N 个孔洞的形状两两不同，确保形状匹配唯一。控制像素不在任何矩形或精灵的边界框内。

**规则**：
1. 提取所有灰(5)矩形及其内部黑色孔洞掩码，按矩形边界框左上角坐标从上到下、同行从左到右排序，编号为 H_0, H_1, ..., H_{N-1}。
2. 提取所有彩色精灵及其掩码。对每个精灵，找到形状全等（二值掩码相同）的孔洞，建立自然匹配：精灵 S_j 自然匹配孔洞 H_{m(j)}。
3. 按自然匹配的孔洞编号对精灵排序：令精灵序列为 [S_{a0}, S_{a1}, ..., S_{a(N-1)}]，其中 S_{ai} 自然匹配 H_i。
4. 计算控制像素相对于所有灰色矩形群的总边界框的方位：
   - 垂直：控制像素在总边界框上方 → 行区 = 0；与总边界框同行带 → 行区 = 1；在总边界框下方 → 行区 = 2。
   - 水平：控制像素在总边界框左方 → 列区 = 0；与总边界框同列带 → 列区 = 1；在总边界框右方 → 列区 = 2。
   - 方位槽号 p = 行区 x 3 + 列区（取值 0~8）。
5. 循环偏移量 d = p mod N。
6. 对精灵序列做循环右移 d 位：新的配对方案为精灵 S_{ai} 嵌入孔洞 H_{(i + d) mod N}。
7. 按新配对方案将每个精灵粘贴到对应孔洞中（精灵像素替换孔洞中的黑色像素，保持精灵原色）。
8. 移除控制像素（品红像素变为黑(0)）。擦除所有精灵原位置（精灵原位像素变为黑(0)）。
9. 输出完整网格。

**关键洞察**：形状匹配给出的"自然"配对不一定是最终配对。控制像素的方位编码了一个循环偏移量，使精灵被重新分配到不同的孔洞中。同一组精灵和孔洞在不同控制像素位置下会产生完全不同的嵌入结果。

p = Path("/home/lixinyu/snap/a/key_combo/code/opus/4/013/10.py")
mod = SourceFileLoader("new_arc_task", str(p)).load_module()
sigs = set()
for i in range(100):
    inp = mod.generate_input()
    out = mod.main(inp)
    assert isinstance(inp, np.ndarray)
    assert isinstance(out, np.ndarray)
    assert inp.ndim == 2 and max(inp.shape) <= 30, f"input grid exceeds 30x30: {inp.shape}"
    assert out.ndim == 2 and max(out.shape) <= 30, f"output grid exceeds 30x30: {out.shape}"
    sigs.add(hashlib.md5(inp.tobytes() + str(inp.shape).encode()).hexdigest())
print("variants", len(sigs))
assert len(sigs) >= 20
