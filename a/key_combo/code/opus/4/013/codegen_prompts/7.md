## 新题 7：梳状计数排序后镜像填入格子

**组合逻辑**：[压缩/高度编码数量](已有) → [排序](已有) → [镜像](创新：不作用于格子原始内容，而作用于排序后的填充结果) + [格子结构](创新：格子不从输入直接读取颜色，而由排序结果填充)

**来源原语**：压缩/compress(a1aa0c1e), 计数/count(a1aa0c1e), 排序/sort(a1aa0c1e), 色条/color_bar(a1aa0c1e), 梳状结构/comb_motif(a1aa0c1e), 高度编码数量/height_encodes_count(a1aa0c1e), 镜像/mirror(80214e03), 格子结构/lattice(80214e03), 行列交叉/row_column_intersection(80214e03)

**依赖链**：必须先从梳状结构解码计数值，才能排序；排序结果决定颜色在格子中的列位置和填充深度；镜像作为最终变换作用于已填充的格子。删除计数解码，排序无依据；删除格子填充，排序和镜像无输出载体；删除镜像，无法得到正确输出。

解码每条色条底部梳状结构的高度计数，按计数从小到大排列色条颜色填入格子的对应列，填充行数等于计数值，最后将整个格子水平镜像输出。

**输入结构**：
- 约 15x18 的网格，背景为黑(0)。
- 网格上半部分有一个格子框架：由灰(5)横线和灰(5)竖线交叉形成 R 行 x C 列的矩形格子（R 约 4~5，C = 色条数量，约 3~5）。格子内每个单元格约 2x2 像素，初始全为黑(0)。
- 网格下半部分有 C 条垂直色条，从左到右排列，每条颜色各不相同（使用蓝(1)、红(2)、黄(4)、品红(6)、橙(7)中的 C 种）。每条色条宽 1 像素，高度约 2~3 像素。
- 每条色条底部紧接一个梳状结构：由交替的 3 像素宽实心行和 1 像素宽侧对行组成。实心行数量即为该色条编码的计数值 k（1 <= k <= R）。梳状结构使用与色条相同的颜色。
- 生成约束：C 条色条的计数值两两不等。

**规则**：
1. 对每条色条，解码其梳状结构中的实心 3 像素行数量，得到计数值 k。
2. 按计数值从小到大排列所有色条。排列结果定义一个颜色序列 [颜色_1, 颜色_2, ..., 颜色_C]（颜色_1 的计数最小）。
3. 在格子中填充：颜色_i 填入格子的第 i 列（i 从 0 开始，即计数最小的颜色填最左列）。在该列中从顶部向下填充 k_i 行（k_i 为该颜色的计数值），每个单元格填为该颜色。未被填充的单元格保持黑(0)。
4. 将填充完毕的格子（含灰色框线）水平镜像（左右翻转列顺序）。
5. 输出镜像后的格子区域（不含色条和梳状结构）。

**关键洞察**：梳状高度具有双重角色——既是排序键（决定哪种颜色进入哪一列），又是填充深度（决定该列填多少行）。镜像翻转使得最终输出中计数最小的颜色反而出现在最右列，增加了从输出反推规则的难度。
