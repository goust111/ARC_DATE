## 新题 1：偏转射线印章链

**组合逻辑**：[射线延伸 + 障碍偏转绕行](创新：射线不画线而是在路径上逐格印章) → [印章覆盖 + 仅填背景格](创新：印章沿动态路径展开而非固定标记位置) → 路径长度决定覆盖优先级(创新)

**来源原语**：射线延伸/ray_extension + 障碍偏转绕行/obstacle_deflection（来自 69889d6e）；印章覆盖/stamp_overlay + 仅填背景格/only_bg_filled + 中心邻域/center_neighborhood（来自 f0df5ff0）

**依赖链**：障碍物的位置决定射线路径的形状 → 路径形状决定印章落点的空间分布 → 多条路径的交叉区域中，路径长度决定最终颜色归属。三者缺一则输出不确定。

将底部边缘的源像素沿对角线向上发射，遇障碍右移绕行，在射线经过的每个格子盖一个 3x3 色块，重叠处由后处理的源覆盖。

**输入结构**：
- 约 15x15 的网格，背景为黑(0)。
- 底部边缘（最后一行）有 2~3 个不同颜色的源像素（如蓝(1)、红(2)、绿(3)），彼此间隔至少 3 列。
- 网格内部散布 4~7 个灰(5) 单像素障碍物。障碍物不在底部边缘行，不在最左列或最右列，彼此不 4-相邻。
- 生成约束：每个源像素的射线路径（含偏转）至少经过 4 个格子后才离开网格顶部或右侧边缘；至少有一对源像素的射线路径产生印章重叠区域。

**规则**：
1. 对每个源像素，从其正上方一格开始，逐步沿"上一行、右一列"的对角方向前进。
2. 若下一步目标格被灰(5) 障碍物占据，则在当前行向右平移一列（不上移），再继续对角前进。若平移后的格仍被障碍物占据，继续右移直到找到空格或超出右边界。
3. 射线在超出网格顶部边缘或右侧边缘时终止。记录射线经过的所有格子坐标序列，即为该源的"路径"。
4. 计算每个源的路径长度（格子数）。按路径长度从短到长排列源像素的处理顺序；长度相同则按源像素在底部边缘从左到右的顺序。
5. 按此顺序依次处理每个源：对其路径上的每个格子，以该格为中心画 3x3 正方形区域。区域内每个格子若当前为黑(0) 背景或为先前源印章所涂的颜色，则涂为当前源的颜色。灰(5) 障碍物格子永不被覆盖。超出网格边界的部分忽略。
6. 输出即为处理完所有源后的网格。底部边缘的源像素保留原色，障碍物保留灰(5)。

**关键洞察**：障碍物不仅阻挡射线使路径弯折，还保护自身周围的像素不被印章覆盖，在印章密集区域形成"阴影孔洞"。路径较长的源后处理，其颜色在重叠区占优——但路径长恰恰说明它被障碍物偏转得更多，因此"被干扰最多的源反而在视觉上最显著"。这条优先级规则需对比多个示例才能归纳。
