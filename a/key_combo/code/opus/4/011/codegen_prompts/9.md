## 新题 9：面板重叠统计螺旋仪表阵列

**组合逻辑**：[透明叠加 + 位置对齐](创新：叠加不生成交集掩码，而是计算每种颜色的逐色重叠统计量) → [计数 + 面积排序](创新：计数对象是逐色重叠像素数) → [螺旋填充](创新：填充量编码重叠统计而非液位高度)

**来源原语**：透明叠加/transparent_overlay + 面板/panel + 分隔行/separator_row + 位置对齐/positional_alignment + 双面板背景交集/both_panels_background_intersection（来自 0c9aba6e）；计数/counting + 螺旋填充/spiral_fill + U形框架/u_shaped_frame + 仪表盘/gauge_output + 空行数映射填充量/empty_rows_map_to_fill_amount（来自 b0c4d837）；排序/sort + 面积排序/area_ordering（来自 4df5b0ae）

**依赖链**：分隔行将网格分为两个面板 → 面板对齐后逐色计算重叠像素数 → 重叠数决定螺旋仪表的填充量 → 各色区域的总面积决定仪表的排列顺序。叠加提供统计输入，计数转化为编码量，排序决定空间布局。

将两个面板位置对齐，统计上面板每种颜色区域与下面板前景区域的重叠像素数，按上面板各色总面积从小到大排列 3x3 螺旋仪表。

**输入结构**：
- 约 7x13（宽大于高）的网格，背景为黑(0)。
- 正中间一行为品红(6) 分隔行，将网格分为上下两个等大的面板（如各 3x13）。
- 上面板包含 2~4 个单色 4-连通前景区域，颜色各不相同（可选蓝(1)、红(2)、绿(3)、黄(4)），每个区域 3~8 像素，不触碰分隔行。
- 下面板包含 2~3 个单色 4-连通前景区域，颜色为灰(5) 或青(8)（不与上面板颜色重复），每个区域 4~10 像素。
- 上下面板的前景区域在位置上有部分重叠（若去掉分隔行将两面板叠合，某些上面板前景像素的位置对应下面板的前景像素位置）。
- 生成约束：上面板至少有 2 种颜色的区域与下面板前景有重叠。每种颜色的重叠像素数在 1~7 之间（适合 3x3 仪表显示）。不同颜色的总像素面积互不相同。

**规则**：
1. 移除品红(6) 分隔行，将上下面板按位置对齐（上面板第 i 行第 j 列 对应 下面板第 i 行第 j 列）。
2. 对上面板中的每种前景色 C，计算重叠数 O(C)：在对齐后的位置中，上面板像素为 C 且下面板像素为任意非黑(0) 前景色的位置数量。
3. 对上面板中的每种前景色 C，计算总面积 A(C)：上面板中颜色为 C 的像素总数。
4. 将上面板的所有前景色按 A(C) 从小到大排序。A(C) 相同则按颜色编号从小到大排序。
5. 输出一个 3 行宽的网格，包含排序后的 3x3 仪表方块从左到右排列，相邻仪表间隔 1 列黑(0)：
   - 每个仪表为 3x3 网格，背景为黑(0)。
   - 从左上角开始，沿顺时针螺旋方向（右→下→左→上→...）依次填充 O(C) 个像素为颜色 C。螺旋顺序为：(0,0), (0,1), (0,2), (1,2), (2,2), (2,1), (2,0), (1,0)，最多 8 格。中心 (1,1) 不在螺旋路径上。
   - 若 O(C)=0，仪表为全黑 3x3。
6. 输出网格高度为 3，宽度为 (仪表数 x 3) + (仪表数 - 1)。

**关键洞察**：面板叠加在参考题 0c9aba6e 中产生交集掩码（布尔结果），而这里叠加产生逐色计数（数值结果），编码到螺旋仪表中。仪表的排列顺序由总面积决定而非重叠量——面积最小的色排最左但其仪表填充量未必最少。需要多个示例才能区分排列键（总面积）和填充量（重叠数）是两个独立的度量。
