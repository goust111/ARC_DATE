## 新题 6：擦除内部描外轮廓按围合面积排列

**组合逻辑**：[擦除 + 轮廓描边 + 最小色为画笔](创新：对多个独立物体分别执行轮廓描边，每个物体的画笔色由其内部标记决定) → [裁剪 + 排序 + 拼接 + 基线对齐排列](创新：排序键为轮廓围合面积而非像素面积或边界框面积)

**来源原语**：擦除/erase + 轮廓描边/outline_trace + 外侧相邻/outer_adjacent + 标记色/marker_color + 最小色为画笔/smallest_as_paint（来自 aa62e3f4）；排序/sort + 裁剪/crop + 拼接/concatenate + 面积排序/area_ordering + 基线对齐排列/baseline_aligned_pack（来自 4df5b0ae）

**依赖链**：物体内部标记色决定轮廓的绘制颜色 → 擦除+描边改变了每个物体的几何形态（实心变空心） → 轮廓围合的内部面积（非像素数）成为排序键 → 排序后按基线对齐拼接。形态变换、颜色来源、排序键三者各自依赖前一步的结果。

将每个填充物体替换为用其内部标记颜色绘制的外轮廓，裁剪后按轮廓围合的内部面积从小到大底部对齐排列。

**输入结构**：
- 约 20x20 的网格，背景为黑(0)。
- 网格中有 3~5 个互不相邻的单色 4-连通填充前景物体（每个物体 6~20 像素，形状不规则但无孔洞，颜色各不相同，可选蓝(1)、红(2)、绿(3)、灰(5)、品红(6)、橙(7)）。
- 每个物体内部恰好包含 1 个不同颜色的标记像素（如物体为蓝(1) 而标记为黄(4)）。标记像素被物体像素 4-邻域包围（不在物体边缘）。
- 生成约束：各物体的轮廓围合内部面积（轮廓内部黑像素数 = 物体像素数 - 轮廓像素数）互不相同。各物体的总像素面积排序与围合内部面积排序不同（至少有一对物体的两种排序逆序），以确保排序键的选择是非显然的。

**规则**：
1. 对每个前景物体，记录其填充颜色和内部标记像素的颜色。
2. 擦除物体的所有原色像素为黑(0)。
3. 在原物体占据的每个像素位置，检查其 4-邻域中是否有至少一个黑(0) 背景格（即该像素是否在物体的外边界上）。若是，该位置为轮廓像素；若否（即被物体完全包围），则不是轮廓像素。
4. 将所有轮廓像素涂为该物体的标记颜色。非轮廓位置保持黑(0)。标记像素本身若在轮廓上则涂标记色，否则保持黑(0)。
5. 裁剪每个轮廓图形到其最小边界框。
6. 计算每个轮廓的围合内部面积：边界框内被轮廓完全 4-连通包围的黑(0) 像素数（即无法从该黑像素通过 4-连通路径到达边界框外部的黑像素的数量）。
7. 按围合内部面积从小到大排序。
8. 将排序后的轮廓图形从左到右排列在一个新网格中：每个图形的边界框底边对齐于输出网格的最底行，相邻图形的边界框之间间隔 1 列黑(0)。输出网格的高度为最高边界框的高度，宽度为所有边界框宽度之和加间隔。

**关键洞察**：排序键是轮廓围合的空心面积，而非物体的像素总数或边界框面积。一个像素多但形状细长的物体可能围合面积很小，而一个像素少但形状紧凑的物体围合面积反而大。需要对比多个示例中不同物体的排列位置，才能区分出排序键是围合面积而非其他度量。
