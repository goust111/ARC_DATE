## 新题 5：参照条对齐后围合填充

**组合逻辑**：[对齐 + 同色对齐 + 首行为参照](来自参考题但作用对象改变) → [填充 + 内部包含](创新：对齐操作改变拓扑连通性，产生新围合区域，填充色由预置标记决定)

**来源原语**：滑动/shift + 对齐/align + 同色对齐/same_color_align + 双色条/two_color_bar + 参考条/reference_bar + 首行为参照/top_row_reference（来自 9968a131）；填充/fill + 内部包含/interior_containment（来自 b0c4d837）；标记像素/marker_pixel（来自 f0df5ff0/e3fe1151）

**依赖链**：参考条定义了每种颜色的目标列 → 反转条的平移改变了条的水平位置 → 位置改变后，条与条、条与标记、条与网格边缘共同围成新的封闭背景区域 → 封闭区域用标记颜色填充。对齐步骤本身不知道会产生什么封闭区域，封闭区域的出现是对齐的涌现效应。

将散布的双色条按顶行参考条对齐，对齐后新出现的被围合背景区域用预置标记的颜色填充。

**输入结构**：
- 约 12x10 的网格，背景为黑(0)。
- 最顶行是参考条：蓝(1) 和红(2) 各占一半列，呈固定的左右分布（如偶数列蓝、奇数列红，或左半蓝右半红）。参考条覆盖整行。
- 参考条下方有 4~7 行各包含一个水平双色条（2 像素宽：一格蓝(1)、一格红(2)，相邻），其余格为黑(0) 背景。部分条的蓝-红顺序与参考条一致（正向），部分反转（红在左、蓝在右）。
- 网格中还散布 1~3 个绿(3) 单像素标记，位于双色条之间的背景区域中。标记不与任何条 4-相邻。
- 生成约束：反转条的对齐移动后，至少有一个由参考条、若干对齐后的条、绿标记和/或网格左右边缘共同围成的 4-连通封闭黑(0) 背景区域。对齐前该区域不封闭。

**规则**：
1. 对每个双色条检查其蓝(1) 像素是否在参考条中蓝(1) 所在的列上。若是，该条已对齐，不移动。
2. 若该条反转（蓝像素不在参考条蓝列上），将整个双色条水平平移，使蓝(1) 像素落在参考条中距其当前位置最近的蓝(1) 列上，红(2) 像素落在相邻的红(2) 列上。条移动后原位置变为黑(0)。
3. 对齐完成后，识别所有 4-连通的黑(0) 背景区域。
4. 对每个不与网格边缘 4-连通的封闭背景区域，将区域内所有黑(0) 像素填充为绿(3)（与预置标记同色）。
5. 绿(3) 标记像素本身保留。输出最终网格。

**关键洞察**：对齐操作是纯水平移动，看似只改变条的 x 坐标，但条的新位置可能恰好封堵了原本通向网格边缘的背景通道，使一片背景变为封闭区域。填充色固定为绿(3)（与已有标记同色），但这一映射关系必须通过对比多个示例确认，因为标记的作用不是"指向"而是"定义颜色"。
