## 新题 8：连线计数驱动错切方向

**组合逻辑**：[连线 + 行列对齐 + 碰撞停止](创新：连线不只是视觉效果，其方向分布编码了几何变换参数) → [平移 + 贴墙移动](创新：移动方向由连线已确定) → [错切 + 逐行偏移](创新：错切方向和幅度由连线的方向统计决定)

**来源原语**：连线/draw_line + 行列对齐/row_col_align + 碰撞停止/collision_stop + 矩形/rectangle + 孤立像素/isolated_pixel + 对齐像素投射矩形/aligned_pixel_to_rect（来自 2c608aff）；错切/shear + 平移/translate + 贴墙移动/move_to_wall + 逐行偏移/row_offset_incr + 网格边缘/grid_edge + 前景物体/foreground_object（来自 9f41bd9c）

**依赖链**：行列对齐的孤立像素向矩形投射连线 → 连线从上方和下方到达矩形的数量对比确定错切方向 → 矩形移到对面墙后，按该方向逐行偏移。连线数统计是一个中间信息变换步骤——它将空间分布转换为单一方向信号。

将与矩形行列对齐的孤立像素连线至矩形，统计从上方和下方到达的线数之差确定错切方向，然后将矩形移到对面墙并按此方向错切。

**输入结构**：
- 约 15x12 的网格，背景为橙(7)（非黑色背景）。
- 一个蓝(1) 填充矩形（约 3x4~4x5 像素）紧贴网格的左侧或右侧边缘。矩形不跨越网格半高。
- 4~6 个不同颜色的单像素（可选红(2)、绿(3)、黄(4)、品红(6)、青(8)），散布在网格中远离矩形的位置。其中部分像素与矩形共享同一行或同一列（行列对齐），部分不对齐。
- 生成约束：至少 1 个像素从上方对齐（与矩形共享某列，且行号小于矩形顶部行）、至少 1 个从下方对齐（行号大于矩形底部行）、至少 1 个从侧方对齐（与矩形共享某行）。从上方到达的对齐像素数与从下方到达的不相等。

**规则**：
1. 识别背景色（像素数最多的颜色，即橙(7)）、最大前景矩形（蓝(1)）、以及所有其他单像素。
2. 对每个单像素，检查它是否与蓝矩形共享某一行或某一列。若是，沿该行或列方向朝矩形画一条同色直线，直到线的下一个像素将进入矩形区域时停止（线不覆盖矩形）。不对齐的像素不画线。
3. 统计到达矩形各侧的线数：上方线数 U（线从矩形上方向下到达）、下方线数 D（线从矩形下方向上到达）。侧方线不参与此统计。
4. 将蓝矩形从当前贴靠的墙移到对面墙（若原在左墙则移到右墙，反之亦然），保持行位置不变。原位置变为背景色。
5. 对移动后的矩形施加错切：
   - 若 U > D：矩形的每一行相对于最顶行向右偏移，偏移量 = (该行在矩形内的行索引) x 1 像素。即最顶行不动，第二行右移 1，第三行右移 2，以此类推。
   - 若 D > U：矩形的每一行相对于最顶行向左偏移，偏移量同上。
   - 偏移后超出网格边界的像素被裁剪（不显示）。
6. 连线保留在输出中。输出最终网格。

**关键洞察**：连线步骤有双重用途——它既在网格上画出可见的线条，又隐含地对矩形的后续变换投票。上方线和下方线的数量对比决定错切方向，但解题者在第一个示例中可能误以为错切方向由矩形所贴的墙决定。需要对比线数分布不同的多个示例，才能发现真正的驱动因素是线的方向统计。
