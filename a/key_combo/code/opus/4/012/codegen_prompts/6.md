## 新题 6：旋转对齐后平铺加阴影

**组合逻辑**：[旋转] + [颜色一致对齐](保留匹配逻辑) + [印章覆盖](保留) → [偏移阴影](创新：阴影不是加在原始输入上，而是加在旋转对齐结果上) → [平铺](创新：带阴影的合成瓦片进行 2x2 平铺)

**来源原语**：旋转/rotate + 印章覆盖/stamp_overlay + 颜色一致对齐/color_consistent_align + 稀疏像素引导放置/sparse_pixels_guide_placement + 精灵体/sprite + 锚点像素/anchor_pixel (0e206a2e)；平铺/tiling + 偏移阴影/offset_shadow + 列环绕/column_wrapping + 瓦片/tile (310f3251)

**依赖链**：锚点像素的颜色和位置约束旋转角度与放置位置 → 对齐后的合成图确定瓦片内容 → 瓦片内容决定阴影位置（阴影取决于非黑像素的坐标） → 带阴影的瓦片作为单元进行平铺。旋转角度的选择影响瓦片中像素的空间布局，进而影响阴影图案和最终的平铺结果。

将多色精灵体旋转对齐到锚点像素上，对合成结果添加偏移阴影后作为瓦片进行 2x2 平铺。

**输入结构**：约 10x10 的黑(0)背景网格，由一行灰(5)像素（位于网格中部某行，横跨全宽）分隔为上半区和下半区。上半区包含一个多色精灵体（使用 2 种前景色如蓝(1)和黄(4)，3~7 个像素组成的 4-连通图形）。下半区包含一个与上半区等大的区域，其中散布 2~3 个锚点像素（颜色与精灵体中对应像素的颜色相同）。精灵体经过 0/90/180/270 度中恰好一种旋转后，其有色像素能与下半区锚点像素的颜色和相对位置完全吻合。红(2)在输入中不出现。不同示例中精灵体形状、旋转角度和锚点位置不同。

**规则**：
1. 分离上半区精灵体和下半区锚点像素。将下半区（不含灰分隔行）作为瓦片画布（大小记为 Rxt x Cxt）。
2. 对精灵体尝试 4 种旋转（0/90/180/270 度），对每种旋转在瓦片画布上尝试所有合法平移位置，寻找使旋转后精灵体的有色像素完全覆盖所有锚点像素且颜色逐像素一致的唯一组合（旋转角度 + 平移偏移）。
3. 在瓦片画布上放置旋转后的精灵体（覆盖锚点像素位置，其余位置保持黑(0)），得到合成瓦片。
4. 在合成瓦片中，对每个非黑像素 (r, c)，在位置 (r-1, (c-1+Cxt) mod Cxt) 处添加红(2)阴影像素。列索引到达左边界时环绕到右侧。若该位置已有非黑像素则不覆盖（原始前景像素优先）。
5. 以带阴影的合成瓦片为单元，进行 2x2 平铺（水平复制 2 份，垂直复制 2 份），生成大小为 (2xRxt) x (2xCxt) 的输出网格。灰分隔行不出现在输出中。

**关键洞察**：锚点像素同时充当两个角色——确定旋转角度的约束条件，以及合成瓦片中的组成像素。阴影位置取决于旋转对齐后的像素布局，因此不同的旋转角度会产生不同的阴影图案。求解者必须先完成旋转匹配，才能得到正确的瓦片内容用于后续的阴影计算和平铺。
