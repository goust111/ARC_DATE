## 新题 9：标记定义矩形区域内恢复周期图案

**组合逻辑**：[连线] + [对角标记定矩形](保留标记定义矩形) → [补全] + [周期平铺图案](创新：周期图案不是从被遮挡的已知输入恢复，而是从矩形外部可见区域推断后填入标记定义的矩形) + [行列分割线](保留，但分割线打断恢复的图案)

**来源原语**：连线/draw_line + 标记像素/marker_pixel + 矩形/rectangle + 对角标记定矩形/markers_define_rect + 行列分割线/row_col_divider (21f83797)；补全/complete + 周期平铺图案/periodic_tile + 被遮挡/occluded + 最大矩形区域/max_rect_region (abbfd121)

**依赖链**：标记像素确定矩形边界和分割线位置 → 矩形外部可见像素确定周期瓦片 → 周期瓦片用于填充矩形内部 → 分割线覆盖部分填充结果。标记像素同时编码了"哪里需要恢复"和"哪里会被分割线打断"。

两个标记像素定义一个矩形，矩形外的网格可见像素暗含一个周期图案，将该图案填入矩形内部并保留标记行列分割线。

**输入结构**：约 14x14 的网格，大部分区域由一个小周期图案铺满（周期为 2x2 或 3x3，使用 2~3 种颜色如蓝(1)和绿(3)交替，或红(2)、黄(4)、黑(0)的 3x3 周期）。网格内有一个矩形区域（约 4x4 至 6x6）被灰(5)像素覆盖，打断了周期图案。灰色矩形的两个对角位置各有一个品红(6)标记像素，取代了该位置的灰(5)像素。灰色矩形外的所有像素保持完整的周期图案。不同示例中周期图案的类型、矩形位置和大小不同。

**规则**：
1. 识别两个品红(6)标记像素的坐标 (r1,c1) 和 (r2,c2)，确定它们定义的矩形范围：行范围 [min(r1,r2), max(r1,r2)]，列范围 [min(c1,c2), max(c1,c2)]。
2. 将两个标记像素所在的完整行和完整列全部涂为品红(6)，形成十字分割线。
3. 从灰色矩形外部的可见像素推断最小周期瓦片：依次尝试从 1x1 到 5x5 的候选瓦片尺寸，选择使瓦片在全网格平铺后与所有非灰、非品红的可见像素一致的最小尺寸瓦片。
4. 用推断出的周期图案填充灰(5)矩形内部的所有灰(5)像素：对矩形内每个灰色像素 (r, c)，赋值为 tile[r mod Tr][c mod Tc]，其中 Tr x Tc 为瓦片尺寸。
5. 品红(6)分割线像素不被周期图案覆盖，保持品红(6)。灰色矩形外部像素保持不变。

**关键洞察**：标记像素同时承担两个角色——作为对角顶点定义需要恢复的灰色矩形区域，以及作为全行全列分割线打断恢复后的图案。恢复区域内并非完整的周期图案，而是被品红十字线分割的版本。求解者必须分别理解标记的两种功能才能正确生成输出。
