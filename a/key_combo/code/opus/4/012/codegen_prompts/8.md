## 新题 8：射线穿框后分割区域按面积极值着色

**组合逻辑**：[射线延伸] + [经过框角才延伸](保留选择性激活条件) + [角对角对齐](保留) → [封闭区域](创新：射线与框边联合分割出新区域) → [面积比较] + [极值区域分别涂色](创新：着色对象是射线与框联合围合的区域)

**来源原语**：射线延伸/ray_extend + 实心矩形/solid_rectangle + 空心矩形/hollow_frame + 角对角对齐/corner_diagonal_align + 经过框角才延伸/extend_past_corner (ec883f72)；面积比较/area_comparison + 极值区域分别涂色/extreme_regions_recolor + 封闭区域/enclosed_region (6455b5f5)；内外分离/interior_exterior_sep + 保留边框涂内部/keep_border_fill_inside (50cb2852)

**依赖链**：实心矩形角与空心框角的对角对齐关系决定哪些射线被激活 → 激活的射线改变框外空间的拓扑分割 → 分割后各区域的面积排名决定填充颜色。矩形的偏心位置同时决定了哪些射线存在和射线如何切分空间。

从实心矩形角沿对角线穿过空心框角后延伸射线，射线和框边围合出多个区域，按面积着不同填充色。

**输入结构**：约 15x15 的黑(0)背景网格。一个蓝(1)实心矩形（3x3 至 4x4），位于网格偏某个方向的位置（非正中央）。一个红(2)空心矩形框（1 像素厚，约 9x9 至 11x11），中心大致在网格中央。实心矩形完全位于空心框的内部。生成约束：实心矩形至少有 2 个角的外延对角线恰好穿过空心框的某个角（即实心矩形角的对角延伸方向上遇到的第一个非黑像素是框的角像素），但不一定所有 4 个角都满足此条件。不同示例中实心矩形的位置不同，导致不同的角被激活。

**规则**：
1. 从实心矩形的每个角出发，沿该角的外延对角线方向（左上角向左上、右下角向右下、左下角向左下、右上角向右上）逐像素检查。
2. 若该对角线上遇到的第一个非黑(0)像素恰好是空心框的一个角像素，则该射线被"激活"：从框角像素的下一个位置起，继续沿同方向逐像素延伸到网格边界，将路径上所有黑(0)像素涂蓝(1)。若遇到的第一个非黑像素不是框角（例如是框边），则该射线不激活。
3. 激活射线的像素、空心框的像素和实心矩形的像素共同将网格空间分割为若干封闭区域。仅考虑空心框外部的区域（框内部不参与面积比较）。
4. 计算每个框外封闭区域的面积（黑(0)像素数）。面积最小的区域（可能并列）填绿(3)。面积最大的区域（可能并列）填黄(4)。其余区域保持黑(0)。
5. 空心框、实心矩形和射线像素保持各自颜色不变。

**关键洞察**：射线能否激活取决于实心矩形与空心框之间精确的对角对齐关系，而激活的射线数量和方向直接决定框外空间被切分为几个区域以及各区域的面积比例。实心矩形的位置是唯一的自变量，同时控制射线的存在性和分区的几何形状。
