## 新题 7：洪泛可达性决定嵌套层序反转

**组合逻辑**：[洪泛填充 flood_fill](创新：洪泛结果不保留在输出中，仅作为分类判据) + [层序反转 layer_order_reversal](创新：反转操作仅对被洪泛触及的矩形执行) + [重涂色 recolor](已有) + [擦除 erase](已有，洪泛痕迹擦除)

**来源原语**：洪泛填充/种子像素/障碍物/四邻连通/种子沿连通域扩散(9edfc990)；重涂色/层序反转/嵌套矩形层/实心矩形/嵌套层次/颜色序列逆转(8dae5dfc)

**依赖链**：种子像素洪泛扩散 → 扩散被墙壁阻挡形成到达域 → 嵌套矩形是否与到达域 4-相邻决定了是否反转层序 → 反转后洪泛痕迹被擦除。洪泛是临时计算——它在输出中完全不可见，仅留下反转/不反转的分类结果。

种子洪泛填充后随即擦除，其唯一作用是决定哪些嵌套矩形需要反转颜色层序。

**输入结构**：约 18x18 的网格，背景为黑(0)。网格中有 2~3 个实心矩形（各约 5x5 至 7x7），每个矩形由 2~3 层嵌套的矩形色环构成（颜色各不相同，取自红(2)、黄(4)、橙(7)、栗(9)等，最外层均匀包裹第二层，第二层均匀包裹最内层实心核心）。矩形之间以黑(0)背景分隔，其中散布若干灰(5)墙段（1 像素宽、2~5 像素长的短线段），将背景分割为若干 4-连通黑色区域。1~2 个蓝(1)种子像素位于某个黑色区域中。生成约束：部分矩形与种子可达的黑色区域 4-相邻，部分不相邻（被墙阻隔）；每个矩形至少有两层颜色以使反转可观察。

**规则**：
1. 从每个蓝(1)种子像素出发，沿 4-连通黑(0)像素扩散，将到达的黑(0)像素临时标记为蓝(1)。灰(5)墙段和矩形像素阻挡扩散。
2. 对每个嵌套矩形，检查其最外层的任意像素是否与某个蓝(1)像素（含临时标记的）4-相邻。
3. 若 4-相邻（被洪泛"触及"）：对该矩形执行层序反转——按从最外层到最内层的顺序读取各层颜色，然后将层颜色以相反顺序重新赋回各层（最外层获得原最内层颜色，反之亦然，中间层若有则也对称交换）。
4. 若不 4-相邻（未被触及）：该矩形保持原样。
5. 将所有蓝(1)像素（含种子和洪泛标记的）全部擦除为黑(0)背景。

**关键洞察**：洪泛填充在输出中完全不可见——它是一个纯粹的中间计算步骤。求解者必须从输入中矩形的颜色层序与输出中的差异，反推出存在一个不可见的洪泛分类过程。需对比多个示例中不同墙壁配置导致不同矩形被反转/保留，才能归纳出洪泛可达性这一隐藏机制。
