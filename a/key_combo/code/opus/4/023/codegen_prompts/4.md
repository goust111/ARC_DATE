## 新题 4：射线碰撞计数索引图例——几何探测映射符号颜色

**组合逻辑**：[射线延伸](来自 508bd3b6) + [碰撞检测](创新：从反弹改为计数碰撞次数) + [色条图例 + 图例顺序对应](创新：用碰撞计数作为图例索引)

**来源原语**：射线延伸(ray_cast, 508bd3b6)；对角射线(diagonal_ray, 2b9ef948)；碰撞反弹(collision_bounce, 508bd3b6) → 创新为碰撞计数；矩形障碍(rect_obstacle, 508bd3b6)；色条图例(color_bar_legend, 94be5b80)；图例顺序对应插槽(legend_order_to_slot, 94be5b80)；重涂色(recolor, 多题)；擦除(erase, 94be5b80)

**依赖链**：种子像素发射射线 → 射线与障碍的碰撞次数 → 碰撞数索引图例颜色 → 重涂种子像素。射线几何决定碰撞数；图例提供颜色映射；两者在碰撞计数处耦合。去掉射线则无碰撞数；去掉图例则无颜色映射；去掉障碍则所有种子相同。

从种子像素向四个对角方向发射射线，以各射线碰撞障碍的总次数索引色条图例，将种子重涂为对应颜色。

**输入结构**：约 15x18 的网格，黑(0)背景。网格顶部一行包含一个水平色条图例：3-4 个相邻单元格，从左到右分别为蓝(1)、红(2)、绿(3)、黄(4)（图例长度在不同示例中可为 3 或 4）。网格中散布 3-5 个灰(5)矩形障碍（每个为 2x2 至 3x4 的实心矩形），位置各异。另有 3-5 个青(8)种子像素分散于网格中，不与障碍或图例重叠。生成约束：每个种子像素在四条对角射线中至少有一条能碰到某个灰障碍；每个种子的碰撞总数在 1 到图例长度之间（没有碰撞数为 0 或超出图例长度的种子）；不同种子的碰撞总数至少有两种不同值。

**规则**：
1. 对每个青(8)种子像素，从该像素出发沿四个对角方向（左上、右上、左下、右下）各发射一条射线。每条射线逐像素延伸，遇到灰(5)障碍像素或网格边界时停止（不穿透、不反弹）。若射线停止是因为碰到灰障碍（而非网格边界），则计为一次碰撞。
2. 统计每个种子的四条射线的碰撞总数 C（0 <= C <= 4）。
3. 以碰撞数 C 作为图例索引（从左起第 C 个颜色，1-indexed）：C=1 → 图例第 1 色，C=2 → 图例第 2 色，以此类推。
4. 将种子像素从青(8)重涂为对应的图例颜色。射线路径不绘制（不在输出中出现）。
5. 擦除图例（图例区域变为黑(0)）。灰障碍保持不变。

**关键洞察**：在源题 508bd3b6 中射线碰撞导致方向反弹（物理模拟），在源题 94be5b80 中图例位置对应插槽顺序（符号映射）。本题用碰撞计数作为桥梁连接几何探测与符号编码——空间中障碍的分布决定了一个拓扑量（碰撞数），该量再映射到离散的颜色标签。求解者必须先理解射线几何，再发现碰撞数与图例索引的对应关系。
