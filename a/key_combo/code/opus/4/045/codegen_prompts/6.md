## 新题 6：行列压缩提取核心后递归印章

**组合逻辑**：[压缩/compression](已有) → [递归印章/recursive_stamp](创新：印章模板不是直接给定而是从压缩中提取) + [像素放大/pixel_scaling](已有，但放大倍率由压缩比隐式决定)

**来源原语**：压缩(ce8d95cc), 相邻相同(ce8d95cc), 相同行列合并(ce8d95cc), 重复行(ce8d95cc), 重复列(ce8d95cc), 像素放大(cce03e0d), 递归印章(cce03e0d), 控制像素(cce03e0d), 格位映射(cce03e0d), 输入图案(cce03e0d)

**依赖链**：输入是一个"拉伸"过的图案，压缩操作提取出隐藏的小核心图案。核心图案中的红色像素标记递归印章位置，核心图案本身就是印章模板。像素放大的倍率等于核心图案的边长。压缩比、印章模板、印章位置全部编码在同一个输入中，三者相互纠缠——改变输入的重复结构会同时改变核心图案的内容和放大倍率。

输入是一个被行列重复拉伸的小图案；压缩还原出核心后，以核心中的红色像素为控制点进行递归印章式放大。

**输入结构**：黑(0)背景，约 15x15 或 16x16 的网格。网格内容实际上是一个小图案（约 4x4 或 5x5）经行列重复拉伸而成——每行被重复 3~4 次、每列也被重复 3~4 次。小图案包含：黑(0)背景像素、若干红(2)像素（控制像素，1~3 个）、以及其他颜色像素（蓝(1)、绿(3)等，构成图案主体）。拉伸后的网格中，相邻的同内容行和同内容列清晰可见。生成约束：拉伸倍率在行方向和列方向上各自一致（但行列倍率可以不同）；小图案中红(2)像素不相邻。

**规则**：
1. 从上到下扫描，保留每组连续相同行的第一行；从左到右扫描，保留每组连续相同列的第一列。取保留行与保留列的交集，得到核心图案 P（大小 R x C）。
2. 创建输出网格，大小为 (R*R) x (C*C)。输出网格被划分为 R x C 个块，每块大小 R x C。
3. 对于核心图案 P 中的每个红(2)像素 (r, c)，在输出网格的第 (r, c) 块中填入核心图案 P 的完整副本（逐像素复制）。
4. 对于核心图案 P 中的每个非红像素 (r, c)，在输出网格的第 (r, c) 块中填入该像素颜色的均匀色块（整个块统一为该颜色）。
5. 在每个被印章的块内部，红(2)像素保持为红(2)——不进行第二层递归。

**关键洞察**：核心图案隐藏在重复拉伸的输入中，需要先识别重复结构并压缩才能获得。核心图案同时扮演"印章模板"和"印章位置图"两个角色，而压缩比隐式决定了输出的尺度。这三个信息（模板、位置、尺度）全部编码在输入的重复结构中，不可分离提取。
