## 新题 4：分隔栅格内的对称补全与间隙连通

**组合逻辑**：[对称补全/symmetry_completion](创新：镜像中心由分隔栅格中的标记方块定义) + [间隙填充/gap_fill](创新：间隙出现在对称补全创建的新内容与原有内容之间) + [网格分区/grid_partition]

**来源原语**：对称补全(4938f0c2), 镜像(4938f0c2), 标记方块(4938f0c2), 对称中心(4938f0c2), 间隙填充(faa9f03d), 端点朝向(faa9f03d), 网格分区(6773b310), 分隔线(6773b310), 分隔栅格(06df4c85), 沿行列填充间隙(06df4c85)

**依赖链**：分隔栅格划定了单元格边界，标记方块在栅格中的位置定义了对称中心。对称补全在空单元格中生成新前景内容——这些新内容与原有内容之间如果在同一行或列上存在朝向彼此的端点，就触发间隙填充。间隙填充的前提（面对的端点对）只在对称补全之后才存在；而对称补全的中心又由分隔栅格中标记方块的格位决定。三个逻辑环环嵌套。

在分隔栅格的格局下，以标记方块为中心做四向对称补全，再将对称后产生的面对端点之间的间隙连通。

**输入结构**：黑(0)背景，约 15x15 的网格。灰(5)全行和全列构成分隔栅格，将画布分成 3x3 或 4x4 的矩形单元格（每个单元格约 3x3~4x4 像素）。部分单元格内有红(2)前景像素，构成单像素宽的水平或垂直线段片段（每个片段 1~3 像素长）。恰好一个单元格内填有一个 2x2 的绿(3)方块（标记方块），该单元格位于栅格的中心或近中心位置。其余有内容的单元格分布在标记方块的一侧或两侧（但不对称——至少有一个方向缺少镜像对应内容）。生成约束：分隔线颜色与前景色和标记色都不同；标记方块恰好占据其所在单元格的中央 2x2 区域；前景线段的端点朝向单元格边缘。

**规则**：
1. 识别灰(5)全行全列为分隔线，将网格划分为矩形单元格，建立单元格坐标系 (cr, cc)。
2. 找到包含 2x2 绿(3)方块的单元格 (mr, mc)，以该单元格的中心为对称中心。
3. 对于每个包含红(2)前景内容的单元格 (cr, cc)，计算它关于 (mr, mc) 的三个镜像单元格：水平镜像 (cr, 2*mc - cc)、垂直镜像 (2*mr - cr, cc)、中心对称 (2*mr - cr, 2*mc - cc)。
4. 将 (cr, cc) 内的红(2)前景图案复制到每个镜像单元格中（在单元格内部做相应的水平/垂直/180度翻转），但不覆盖已有的非背景像素。若镜像单元格超出栅格范围，忽略。
5. 对称补全完成后，扫描所有同一行或同一列的单元格对：若两个单元格内各有一个红(2)线段端点面向彼此（即端点位于单元格靠近对方的边缘，中间单元格全为空），则在中间的空单元格中沿该行或列画一条红(2)直线段，连接两个端点的投影位置。
6. 间隙填充的直线段穿过分隔线时不中断（分隔线像素被红(2)覆盖）。
7. 绿(3)标记方块在输出中保留不变。

**关键洞察**：间隙填充操作在对称补全之前无法执行——面对的端点对只有在镜像内容出现后才形成。单个示例可能只看到一侧有原始内容、另一侧有镜像内容并已连通，需要对比多个示例（不同的原始内容分布和标记方块位置）才能分离出"先对称再填充"的两步逻辑。

## 实现要求

1. `main(grid)` 必须实现新题描述中的确定性转换规则，不能只识别 `generate_input()` 的固定模板。禁止不同的input网格输出相同的output网格。
2. `generate_input()` 必须随机生成多样样例，不能固定死。随机维度应覆盖：网格大小、对象数量、位置、颜色、方向、形状参数或关键分支。注意若描述中存在若干，需实现而不是只有单个，包括object或者对应关系等等。
3. 生成器必须保证输入满足 `main()` 的隐式假设：对象不重叠、不越界、特殊标记唯一或可区分、匹配关系无歧义、关键分支出现概率相同。
4. 禁止把 ARC 颜色 id 、亮度、拼写等当作人类不可见的数值语义参与排序、大小比较或隐藏映射。颜色变化必须有可见结构线索。注意颜色亮度、拼写等也是不可见信息，若描述中出现违规的颜色id或者亮度，可自行使用少量的固定颜色替代，但注意生成时要在三个以内输入输出网格中对所有变换100%覆盖度。
5. 输出样例要视觉清晰，人类必须能从输入输出对中肉眼辨认出规律。具体要求：避免对象粘连、覆盖关系混乱、同一像素多重语义；不同逻辑步骤产生的结果不要大面积层叠在一起导致无法分辨哪个颜色属于哪个步骤；输入中各元素之间保持足够间距，输出中新增的标记/填充/路径等应与背景和已有元素在颜色上有明显区分；若规则涉及多层叠加，生成时控制对象密度和尺寸，确保叠加区域只占少数像素而非铺满整个网格。
6. 若规则有多个分支，生成器不能长期固定成一个分支；应让分支在随机样例中合理出现。分支概率不必平均——难以发现的隐蔽分支（如少数情况下才触发的特殊规则）应适当提高出现概率，确保在 3 个训练示例中至少出现一次，否则求解者无法归纳该规则。对于颜色映射类规则，确保 2 个左右的示例即可覆盖所有映射关系（每种颜色→颜色的映射至少在某个示例中出现过）。
