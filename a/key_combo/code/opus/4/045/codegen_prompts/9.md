## 新题 9：三角楔形区域约束下的同色端点连线

**组合逻辑**：[填充/fill](创新：楔形填充创建"许可区域") + [连线/connect](创新：连线仅在许可区域内有效) + [标记定义楔形范围/marker_define_wedge] + [同色配对/same_color_pairing]

**来源原语**：填充(896d5239), 三角楔形区域(896d5239), 对角线边界(896d5239), 标记定义楔形范围(896d5239), 标记像素(896d5239), 连线(06df4c85), 同色配对(06df4c85), 沿行列填充间隙(06df4c85), 轴对齐(06df4c85)

**依赖链**：绿色标记像素定义三角楔形区域，楔形内部被填充为"许可区"。同色配对的线段端点只有当连线路径完全位于许可区内时才被连接。楔形的几何范围（由标记位置决定）充当连线的空间过滤器——同一对端点在不同的楔形配置下可能被连接或不被连接。标记像素同时服务于两个操作：定义楔形（几何角色）和作为空间过滤器的边界（逻辑角色）。

绿色标记定义的三角楔形区域是"许可区"，只有完全位于许可区内的同色端点对才会被连线。

**输入结构**：黑(0)背景，约 16x16 的网格。绿(3)标记像素 4~8 个，排列在 1~2 个 45 度三角楔形的对角线边上（每个楔形由一个尖端和两条对角侧线定义，侧线上各有 2~3 个绿色标记作为线索）。此外，网格中散布若干成对的同色小线段端点：红(2)、蓝(1)、黄(4)各 1~2 对，每对中两个端点在同一行或同一列上，间距 3~8 像素，中间为黑(0)。部分端点对完全位于楔形内部，部分端点对跨越楔形边界（一端在内一端在外，或连线路径穿过楔形外部）。生成约束：楔形内部无端点对之间的路径冲突；每个端点恰属于一对配对。

**规则**：
1. 从绿(3)标记像素识别三角楔形：找到每个楔形的尖端（两条 45 度对角线的交点处的绿色标记），确定两条侧线方向，楔形高度为侧线上距尖端最远的绿色标记的距离。
2. 将每个楔形内部（由两条对角侧线和底边围成的三角区域）的黑(0)像素标记为"许可区"。绿色标记像素本身也属于许可区。
3. 对每种非绿、非背景颜色，在同一行或同一列中寻找该颜色的像素对。
4. 对每对同色端点，检查它们之间的直线路径（沿行或列的所有中间像素）是否全部位于许可区内（含两个端点本身也必须在许可区内）。
5. 若路径完全在许可区内，用该对端点的颜色填充中间的黑(0)像素，完成连线。
6. 若路径中任何一个像素不在许可区内，不连线，保持原状。
7. 楔形内部未被连线占用的许可区像素涂为青(8)。
8. 绿(3)标记像素在输出中保持绿(3)。

**关键洞察**：连线是否发生不仅取决于端点是否同色同行/列，还取决于连线路径与楔形区域的空间关系。两对看似相同的端点（同色、同间距）可能一对被连接而另一对不被连接，完全由楔形位置决定。这一空间过滤规则需要对比多个示例才能区分"距离太远连不上"和"路径不在许可区内连不上"。

## 实现要求

1. `main(grid)` 必须实现新题描述中的确定性转换规则，不能只识别 `generate_input()` 的固定模板。禁止不同的input网格输出相同的output网格。
2. `generate_input()` 必须随机生成多样样例，不能固定死。随机维度应覆盖：网格大小、对象数量、位置、颜色、方向、形状参数或关键分支。注意若描述中存在若干，需实现而不是只有单个，包括object或者对应关系等等。
3. 生成器必须保证输入满足 `main()` 的隐式假设：对象不重叠、不越界、特殊标记唯一或可区分、匹配关系无歧义、关键分支出现概率相同。
4. 禁止把 ARC 颜色 id 、亮度、拼写等当作人类不可见的数值语义参与排序、大小比较或隐藏映射。颜色变化必须有可见结构线索。注意颜色亮度、拼写等也是不可见信息，若描述中出现违规的颜色id或者亮度，可自行使用少量的固定颜色替代，但注意生成时要在三个以内输入输出网格中对所有变换100%覆盖度。
5. 输出样例要视觉清晰，人类必须能从输入输出对中肉眼辨认出规律。具体要求：避免对象粘连、覆盖关系混乱、同一像素多重语义；不同逻辑步骤产生的结果不要大面积层叠在一起导致无法分辨哪个颜色属于哪个步骤；输入中各元素之间保持足够间距，输出中新增的标记/填充/路径等应与背景和已有元素在颜色上有明显区分；若规则涉及多层叠加，生成时控制对象密度和尺寸，确保叠加区域只占少数像素而非铺满整个网格。
6. 若规则有多个分支，生成器不能长期固定成一个分支；应让分支在随机样例中合理出现。分支概率不必平均——难以发现的隐蔽分支（如少数情况下才触发的特殊规则）应适当提高出现概率，确保在 3 个训练示例中至少出现一次，否则求解者无法归纳该规则。对于颜色映射类规则，确保 2 个左右的示例即可覆盖所有映射关系（每种颜色→颜色的映射至少在某个示例中出现过）。
