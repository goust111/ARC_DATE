## 新题 3：分隔线劈裂对象与逐带密度竞争

**组合逻辑**：[重力下落](创新：对象被分隔线劈裂为碎片后各自下落) + [计数/counting] + [洪泛填充/flood_fill] + [筛选/filtering](创新：按带状区域的密度筛选)

**来源原语**：重力下落/gravity_drop(b2bc3ffd), 计数/counting(29623171), 洪泛填充/flood_fill(29623171), 筛选/filtering(29623171), 分隔线/separator_line(29623171, 7c9b52a0), 分区区域/partitioned_region(29623171), 前景对象/foreground_object(423a55dc), 最密区域保留填充/densest_region_kept_filled(29623171)

**依赖链**：水平分隔线将跨区对象劈裂为碎片 → 碎片在各自所属带内独立下落 → 下落后统计每个带的前景像素总数 → 像素最多的带保留并洪泛填充，其余带清空。删除劈裂则碎片归属不确定；删除重力则密度分布错误；删除计数则无法选出优胜带。

跨越分隔线的对象被劈裂为独立碎片，各自在所属区域内下落后，按区域像素密度竞争决定存亡。

**输入结构**：约 15x15 网格，黑(0) 背景。2 条全宽红(2) 水平分隔行将网格分为 3 个水平带（上带、中带、下带），每带高度至少 4 行。网格中有 3~4 个单色 4-连通对象（颜色取自 {蓝(1), 绿(3), 橙(7), 青(8)}），每个对象 4~8 像素。其中至少 2 个对象跨越某条分隔行（即该对象的像素同时出现在分隔行的上方带和下方带中；分隔行本身不含对象像素）。其余对象完全位于某一个带内。生成约束：各对象颜色互不相同；每个带在劈裂和下落后至少包含 1 个像素；三个带在下落后的像素总数互不相等（避免平局）。

**规则**：
1. 沿每条红(2) 分隔行切割：跨越分隔行的对象被劈裂为独立碎片，每个碎片包含原对象在该带内的所有像素，保留原色和相对位置。不跨越分隔行的对象保持不变。
2. 在每个带内，对所有碎片和完整对象执行重力下落：每个像素在其所在列内向下移动，直到碰到该带的底边（分隔行或网格底边）或已落定的像素为止。处理顺序：从每带的最低行向上逐行处理。
3. 下落完成后，统计每个带内所有前景（非黑、非红）像素的总数。
4. 像素总数最多的带为优胜带：将该带内所有前景像素保留，并将该带内剩余的黑(0) 背景像素全部洪泛填充为灰(5)。其余带的所有前景像素清除为黑(0)（背景不变）。
5. 所有红(2) 分隔行保持不变。

**关键洞察**：对象跨带劈裂改变了各带的像素分配——一个大对象劈裂后可能在某带只留下少量碎片，使该带在密度竞争中落败。重力下落本身不改变像素总数，但它改变了像素的空间分布（这影响视觉识别但不影响计数——此处重力的作用是让碎片"归位"到带底部，使密度视觉上可读）。真正决定胜负的是劈裂后的像素分配。

    sigs.add(hashlib.md5(inp.tobytes() + str(inp.shape).encode()).hexdigest())
print("variants", len(sigs))
assert len(sigs) >= 20
