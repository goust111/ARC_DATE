## 新题 6：形状频率门控轮廓描绘与孔洞填充的分支操作

**组合逻辑**：[counting + shape_matching](创新：频率分析不直接映射颜色，而是决定对每个对象施加哪种操作) + [outline | flood_fill/fill](创新：同一场景中两种不同的视觉操作由全局属性——形状频率——来门控选择)

**来源原语**：counting/shape_matching/connected_component/unique_vs_repeated_recolor(b230c067), outline/flood_fill/enclosed_region/exterior_adj_region/holes_fill_outline/region_reachability(543a7ed5)

**依赖链**：形状归一化比较 → 频率分类（唯一 vs 重复） → 分支：唯一形状执行孔洞填充，重复形状执行外部轮廓描绘。删除形状比较则不知道哪些对象走哪个分支；删除任一分支操作则部分对象无法处理。分支选择依赖全局信息（需遍历所有对象才能确定频率）。

根据前景对象的形状是否在其他对象中重复出现，对唯一形状的对象填充其内部孔洞，对重复形状的对象描绘外部轮廓。

**输入结构**：黑(0)背景网格，约 16x18。包含 5~7 个灰(5)8-连通前景对象，每个对象 6~14 像素。对象之间互不相邻（两两之间至少 2 像素间隔）。对象形状多样（按连通性、像素数、边界框内的占据模式定义），无需命名具体外形。其中：
- 恰好一种形状只出现一次（唯一形状），该对象内部包含至少一个封闭孔洞（被对象像素完全包围的黑色背景区域，4-连通不可达网格边界）。
- 恰好另一种形状出现 2~3 次（重复形状），这些对象不必有孔洞。
- 输入中不含绿(3)和黄(4)，这两色保留给输出。
- 生成约束：唯一形状和重复形状在像素数和边界框尺寸上有一定重叠（不能仅靠大小区分），迫使求解者进行形状比较。

**规则**：
1. 检测所有灰(5)的 8-连通前景对象。
2. 对每个对象提取其在最小边界框内的掩码（相对于边界框左上角归一化），按掩码比较形状。
3. 形状只出现一次的对象为"唯一"类，出现多次的为"重复"类。
4. 对每个"唯一"类对象：找出其内部封闭孔洞（4-连通不可达网格边界的黑色区域），将孔洞中所有像素重涂为黄(4)。若无孔洞则不做改变。
5. 对每个"重复"类对象：找出其外部轮廓——所有 8-邻域接触该对象的非对象背景像素（且该背景像素能 4-连通达到网格边界），将这些像素重涂为绿(3)。
6. 若不同对象的绿色轮廓在同一像素重叠（两个重复类对象相邻到共享外部邻域像素），该像素仍涂绿(3)（幂等操作）。
7. 所有原始灰色对象像素保持灰色不变。

**关键洞察**：两种视觉上完全不同的变换（向内填充 vs 向外描边）施加于颜色完全相同的对象上。区分标准是全局的形状频率属性，不能仅看单个对象——必须扫描所有对象后才能做出决定。单个示例可能无法暴露这个分支逻辑（若示例中唯一形状恰好也是最大的，求解者可能误以为规则是按大小分支）。

import hashlib
import numpy as np

p = Path("/home/lixinyu/snap/a/key_combo/code/opus/4/042/6.py")
mod = SourceFileLoader("new_arc_task", str(p)).load_module()
sigs = set()
for i in range(100):
    inp = mod.generate_input()
    out = mod.main(inp)
    assert isinstance(inp, np.ndarray)
    assert isinstance(out, np.ndarray)
    assert inp.ndim == 2 and max(inp.shape) <= 30, f"input grid exceeds 30x30: {inp.shape}"
    assert out.ndim == 2 and max(out.shape) <= 30, f"output grid exceeds 30x30: {out.shape}"
    sigs.add(hashlib.md5(inp.tobytes() + str(inp.shape).encode()).hexdigest())
print("variants", len(sigs))
assert len(sigs) >= 20
