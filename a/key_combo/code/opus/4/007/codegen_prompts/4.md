## 新题 4：标记定位矩形的面积驱动缩放印章

**组合逻辑**：[角标记/corner_marker + 标记定位矩形/markers_locate_rectangle](已有) → [计数/counting](创新：计算矩形面积而非像素数) → [像素放大/pixel_scaling + 印章覆盖/stamp](创新：缩放因子由目标矩形面积与模板面积之比决定)

**来源原语**：角标记/corner_marker、标记定位矩形/markers_locate_rectangle、遮罩矩形/mask_rectangle、按标记色分组/group_by_marker_color、包围框修剪定位/bounding_box_trim_to_locate（参考题 1c02dbbe）；像素放大/pixel_scaling、印章覆盖/stamp、模板/template、缩放对应/scale_correspond、边长定缩放因子/side_sets_scale（参考题 447fd412）；擦除/erase（参考题 3d588dc9）

**依赖链**：标记定位确定矩形的几何尺寸→矩形面积除以模板面积得到缩放因子→缩放因子决定模板的放大倍率→放大后的模板印入矩形区域。标记颜色同时承担定位和着色双重角色。

用三点同色角标记定位灰色遮罩中的子矩形，每个子矩形的面积与固定模板的面积之比确定缩放倍率，将模板按该倍率放大后印入矩形，模板颜色替换为标记颜色。

**输入结构**：约 18x18 的黑(0)背景网格。网格中央有一个较大的灰(5)实心矩形遮罩（约 12x14）。遮罩外部散布若干彩色标记像素，按颜色分组，每组恰好 3 个同色像素，颜色选自红(2)、绿(3)、蓝(1)，共 2~3 组。每组 3 个标记的轴对齐包围框经过修剪后恰好框定遮罩内部一个全灰子矩形（修剪规则：四种单边裁切中，取内部全为灰(5)加标记色且恰含 1 个标记的那种）。网格左上角（遮罩外）有一个 2x2 的单色模板图案，颜色为黄(4)，其中恰好 3 个像素为黄(4)、1 个像素为黑(0)。生成约束：每个定位出的子矩形面积恰好是模板面积（3 像素）的完全平方倍（即 3, 12, 27, ...），使得缩放因子 k 为整数（k=1, 2, 3, ...）；子矩形的宽和高分别是模板宽和高的 k 倍；不同组定位的子矩形互不重叠。

**规则**：
1. 按颜色对标记像素分组。对每组 3 个同色标记，计算其轴对齐包围框。
2. 对包围框的四种单边修剪（去掉上边一行、去掉下边一行、去掉左边一列、去掉右边一列），选择使修剪后矩形内只含灰(5)和该标记色、且恰好包含该组 3 个标记中的 1 个的那种修剪方式，得到目标子矩形。
3. 将所有标记像素擦除为黑(0)。
4. 计算目标子矩形的面积 A_rect 和模板的非背景像素数 A_tmpl。缩放因子 k = sqrt(A_rect / A_tmpl)（由生成约束保证为整数）。
5. 将 2x2 模板中的每个像素放大为 k x k 的块，得到 2k x 2k 的放大模板。将放大模板中的黄(4)替换为该组标记的颜色。
6. 将放大后的模板印入目标子矩形，对齐子矩形的左上角。模板中黑(0)像素对应的位置保留灰(5)。
7. 各组按标记颜色的编号从小到大依次处理；实际上各组子矩形不重叠，顺序不影响结果。

**关键洞察**：标记的角色从源题中的"定位后直接重涂色"扩展为"定位后提取几何参数（面积）来驱动另一个操作（缩放印章）"——矩形不是被填色的目标，而是承载缩放信息的容器。
