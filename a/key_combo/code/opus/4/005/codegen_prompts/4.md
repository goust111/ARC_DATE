## 新题 4：周期平铺后由定向标记引发局部相移

**组合逻辑**：[tile + periodic_repeat + seed_motif](已有) → [orientation_determines_direction + micro_marker](创新：原用于决定 bar 延伸的行/列，此处 domino 朝向编码平铺图案的相移方向——水平 domino 触发其所在行的水平相移，垂直 domino 触发其所在列的垂直相移)

**来源原语**：tile, periodic_repeat, seed_motif, fill_grid（来自 9b30e358）；orientation_determines_direction, micro_marker, row_column_bar（来自 9344f635）

**依赖链**：底部种子图案确定平铺周期 → 先用种子图案填满整个网格 → domino 标记的朝向决定相移方向（行移 vs 列移） → 相移改变局部平铺相位。若不先识别平铺周期，相移量无法定义；若不解读 domino 朝向，不知道对哪些行/列执行何种移位。

一句话总结：底部种子图案向上周期平铺填满网格，然后品红色 domino 标记在其所在行或列触发 1 像素的循环相移，朝向决定移位方向。

**输入结构**：
- 黑(0)背景，约 15x15 网格。
- 网格底部若干连续行（例如 3-5 行）包含非黑前景色像素，构成种子图案（motif）。种子图案的行高度为 H。
- 种子图案上方是空白的黑色区域（网格总高度是 H 的整数倍，保证平铺无余）。
- 空白区域中散布 1-3 个品红(6) domino 标记（每个 domino 是 2 个 4-连通的品红像素）。domino 要么水平（同一行相邻两列），要么垂直（同一列相邻两行）。
- 生成约束：不同 domino 不在同一行或同一列上（保证相移不冲突）。domino 所在位置不在种子图案所在的行内。

**规则**：
1. 识别底部种子图案块（最下方连续的非空行组成的矩形区域，高度 H，宽度=网格宽度），包含其中的黑色像素。
2. 将种子图案以周期 H 向上重复平铺，填满整个网格。此时得到基础平铺结果。
3. 对每个品红 domino：
   - 若 domino 为水平方向：将其所在行的所有像素向右循环移动 1 格（最右侧像素回到最左侧）。
   - 若 domino 为垂直方向：将其所在列的所有像素向下循环移动 1 格（最底部像素回到最顶部）。
4. 移位操作按 domino 从左上到右下的阅读顺序依次执行。
5. 最终将所有品红 domino 像素替换为该位置在移位后的平铺颜色值（即 domino 标记不出现在输出中）。

**关键洞察**：平铺图案本身是全局规律性的，domino 引入的局部相移打破了周期性。仅看一个示例可能将相移行/列误解为平铺错误或特殊边界处理，必须对比多个示例中 domino 位置、朝向与相移方向的对应关系才能归纳规则。

Rule
Find the nonzero translation vector whose overlapping visible cells have the

the visible pixels identifies exactly how to copy colors through the gaps.
