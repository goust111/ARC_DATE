## 新题 8：障碍物过滤射线，成功射线数汇总为计数条

**组合逻辑**：[ray_cast + toward_and_away + color_determines_ray_direction + divider_line](已有) → 障碍物截断判定（创新：源题中射线无障碍传播，此处引入橙色障碍物阻断射线） → [counting + summary_generation + categorical_count + row_major_fill](创新：源题中直接计数条/横条数量，此处计数的是成功穿越的射线数量)

**来源原语**：ray_cast, toward_and_away, color_determines_ray_direction, divider_line, isolated_pixel, canvas_boundary（来自 8d510a79）；counting, summary_generation, categorical_count, row_major_fill, horizontal_bar（来自 5289ad53）；boundary 作为障碍（来自 00d62c1b）

**依赖链**：红/蓝像素各自射出朝向/背离分隔线的射线 → 橙色障碍物可能截断射线 → 仅未被截断的射线计为"成功" → 成功射线按颜色分类计数 → 计数结果编码到输出区域的摘要条中。射线方向规则、障碍物判定、计数汇总三步环环相扣。

一句话总结：红蓝像素各自向/背离灰色分隔线射出射线，橙色障碍物可阻断射线，统计未被阻断的红蓝射线各有多少条，将计数写入角落的摘要格。

**输入结构**：
- 黑(0)背景，约 13x15 网格。
- 一条完整的水平灰(5)分隔线将网格分为上下两区。
- 上下两区各散布若干红(2)和蓝(1)孤立像素（每区 2-4 个，总共 5-8 个）。红蓝像素不在分隔线上，不在同一行或同一列上（保证射线不互相干扰）。
- 若干橙(7)孤立像素散布在网格中（不在分隔线上），位于某些红/蓝像素与其射线目标之间的路径上。
- 网格右下角预留一个 2x3 的黑色区域作为输出摘要槽（该区域内无其他像素）。
- 生成约束：至少一条红射线和一条蓝射线被橙色障碍物阻断，至少一条红射线和一条蓝射线未被阻断（保证摘要非空且体现过滤效果）。

**规则**：
1. 分隔线为水平方向。红(2)像素向分隔线方向射出垂直射线（若在上方则向下，若在下方则向上）。蓝(1)像素向远离分隔线的方向射出垂直射线（若在上方则向上朝网格顶部，若在下方则向下朝网格底部）。
2. 射线逐像素前进。若下一个像素是黑(0)，继续前进。若下一个像素是橙(7)障碍物，射线被阻断——停止前进，该射线标记为"失败"。若射线到达分隔线（红射线的目标）或网格边缘（蓝射线的目标），该射线标记为"成功"。
3. 在网格上绘制所有成功的射线路径：红色成功射线路径涂红(2)，蓝色成功射线路径涂蓝(1)。失败射线不绘制任何内容。射线路径不包含起始像素本身（起始像素已有颜色）也不包含终点（分隔线保持灰色，边缘像素保持黑色）。
4. 统计成功的红射线数量 R 和成功的蓝射线数量 B。
5. 在右下角 2x3 摘要槽中，按行主序（从左到右、从上到下）依次填入 R 个红(2)像素，然后填入 B 个蓝(1)像素。剩余格子保持黑(0)。若 R + B > 6，仅填前 6 格。
6. 所有灰色分隔线像素、橙色障碍物像素、红/蓝起始像素保持原色不变。

**关键洞察**：射线不是最终输出的全部——它们同时是中间计算步骤（决定摘要内容）和可视化输出。求解者必须理解三层逻辑：方向规则（颜色→朝向/背离）、障碍物过滤（橙色像素阻断射线）、摘要编码（成功数量→紧凑条带），且三层之间存在信息流动。

    sigs.add(hashlib.md5(inp.tobytes() + str(inp.shape).encode()).hexdigest())
print("variants", len(sigs))
assert len(sigs) >= 20
