## 新题 6：标记数量奇偶性分支决定同心方块的变换类型

**组合逻辑**：[counting + embedded_marker_count](已有) → 奇偶分支判断（创新：源题中 swap 和 grow 总是同时执行，此处由标记计数的奇偶性决定执行哪一个） → [inner_outer_swap](条件触发) / [grow](条件触发)

**来源原语**：inner_outer_swap, concentric_layer, outward_rect, grow, border_core_swap_extend（来自 3befdf3e）；counting, embedded_marker_count, control_pixel, count_determines_expansion（来自 52fd389e）

**依赖链**：灰色标记数量 → 奇数触发颜色互换（不生长）；偶数（且>0）触发向外生长（不互换），生长距离=数量/2 → 变换类型和变换参数都由同一组标记编码，缺少计数则无法选择分支。

一句话总结：每个同心方块图案内的灰色标记数量决定对该图案执行颜色互换还是向外生长，且生长距离也由数量编码。

**输入结构**：
- 黑(0)背景，约 18x18 网格。
- 2-4 个互相分离的方块图案。每个图案由一个 3x3 的实心内核（颜色 A）和一圈 1 像素宽的外框（颜色 B）组成，整体为 5x5。A 和 B 都不是黑(0)或灰(5)，且不同图案的 (A, B) 颜色对互不相同。
- 每个图案的内核（3x3 区域）中有 0-4 个像素被替换为灰(5)标记像素（其余内核像素保持颜色 A）。
- 生成约束：图案之间留有足够间距（至少 4 像素），确保生长后不重叠、不超出网格边界。标记数量在不同图案之间不全相同，且至少包含一个奇数和一个偶数（>0）。

**规则**：
1. 对每个方块图案，计算其内核中灰(5)标记像素的数量 n。
2. 若 n = 0：图案保持不变。
3. 若 n 为奇数：执行颜色互换——将内核颜色 A 改为 B，外框颜色 B 改为 A。不向外生长。灰色标记像素被替换为互换后的内核颜色（即颜色 B）。
4. 若 n 为偶数且 n > 0：不执行颜色互换——保持原色。从外框的四条边各向外延伸 n/2 个像素的矩形条，延伸区域涂为外框颜色 B。灰色标记像素被替换为内核颜色 A。
5. 处理顺序不影响结果（生成约束保证无重叠）。

**关键洞察**：源题（3befdf3e）中颜色互换和向外生长始终绑定执行。本题将二者拆解为互斥分支，由标记计数的奇偶性决定走哪条分支。仅凭一个示例看到的某个图案变换无法判断分支规则，必须同时观察奇数和偶数标记的图案才能归纳出奇偶判据。
