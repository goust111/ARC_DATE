## 新题 5：十字轴对称展开标记后按切比雪夫距离填充方块

**组合逻辑**：[对称补全/symmetry_complete + 双轴对称/biaxial_symmetry + 四象限镜像填充/quadrant_mirror](已有) → [填充/fill + 切比雪夫距离/chebyshev_dist + 近阻挡距定尺寸/blocker_dist_size](已有，但填充目标由对称补全产生) + [碰撞停止/collision_stop](已有，阻挡像素阻止填充扩展)

**来源原语**：对称补全/symmetry_complete、十字轴线/cross_axis、稀疏标记/sparse_marker、双轴对称/biaxial_symmetry、四象限镜像填充/quadrant_mirror（60d73be6）；填充/fill、标记像素/marker_pixel、阻挡像素/blocker_pixel、正方形区域/square_region、切比雪夫距离/chebyshev_dist、近阻挡距定尺寸/blocker_dist_size（ff72ca3e）

**依赖链**：黄色标记仅存在于一个象限，必须先通过十字轴双轴对称补全到其余三个象限，才能获得完整的填充中心集合。每个中心（无论原始还是反射产生的）根据其到最近灰色阻挡像素的切比雪夫距离来确定红色方块的边长。反射产生的标记与不同象限的阻挡像素交互，因此同一原始标记的四个副本可能产生不同大小的方块。没有对称补全→只有四分之一的填充中心；没有阻挡距离规则→方块大小不确定。

将单象限的黄色标记通过十字轴反射补全到所有象限，然后以每个标记为中心、按最近灰色阻挡像素的切比雪夫距离画红色方块。

**输入结构**：黑(0)背景，约 17x17（奇数行列以确保十字轴居中）。一条绿(3)的完整行（正中行）和一条绿(3)的完整列（正中列）构成十字轴。黄(4)标记像素仅出现在左上象限（十字轴以外区域），共 2~4 个，互不相邻。灰(5)阻挡像素散布在所有四个象限中（每个象限 2~5 个），互不相邻，且不与黄色标记相邻。生成约束：每个黄色标记反射到其余三个象限后，落点均为黑色背景（不与阻挡像素或十字轴重合）；每个标记（含反射副本）到最近阻挡像素的切比雪夫距离至少为 2（保证至少生成 1x1 的方块）；不同标记产生的红色方块互不重叠。

**规则**：
1. 识别绿(3)十字轴：满行的行号为 axis_row，满列的列号为 axis_col。
2. 收集所有黄(4)像素的坐标作为原始标记集合 M。
3. 对每个标记 (r, c) in M，计算其三个反射位置：
   - 跨行轴反射：(2*axis_row - r, c)
   - 跨列轴反射：(r, 2*axis_col - c)
   - 双轴反射：(2*axis_row - r, 2*axis_col - c)
   将反射位置加入标记集合。在这些位置放置黄(4)像素。若反射位置超出网格边界则丢弃。
4. 对完整标记集合中的每个标记 (r, c)（按行优先、列次优先从左上到右下处理）：
   - 计算 d = 到所有灰(5)阻挡像素的切比雪夫距离的最小值。
   - 半径 R = d - 1。
   - 以 (r, c) 为中心，绘制边长为 (2R+1) 的红(2)正方形：将所有满足 |r'-r| <= R 且 |c'-c| <= R 的格子 (r', c') 涂为红(2)，但仅覆盖黑(0)背景像素，不覆盖黄(4)、灰(5)、绿(3)或先前已绘制的红(2)像素。
5. 十字轴、黄色标记、灰色阻挡像素保持不变。

**关键洞察**：填充中心的完整集合必须通过对称补全才能获得，而每个反射副本的方块大小取决于目标象限中阻挡像素的局部分布——同一源标记在不同象限可能产生不同大小的方块，使得对称补全与局部距离分析形成非平凡交互。
