## 新题 5：像素计数配对与边框完整性决定填充模式

**组合逻辑**：[计数(框内面积) + 计数(标记数量)](已有) → [相等比较 → 配对](创新：将两种不同计数结果做匹配) → [边框完整性检测](创新：框的拓扑属性决定操作的具体形式) → [条件填充(实心 / 棋盘格)](创新：同一操作的两种模式由拓扑条件切换)

**来源原语**：计数、空心矩形、棋盘格图案、像素数匹配格数(df8cc377)；填充(00dbd492)；有空洞则重涂(810b9b61) → 创新为边框完整性检测；擦除(184a9768)

**依赖链**：框内面积计数与标记计数的相等关系建立颜色配对 → 框的边框是否完整决定填充模式（实心或棋盘格） → 配对和模式共同确定每个框的最终外观。计数提供"哪个颜色填哪个框"，拓扑提供"用什么方式填"。

统计散布标记数量与框内面积做匹配，按匹配颜色填充对应框，边框完整的框做实心填充，有缺口的框做棋盘格填充。

**输入结构**：约 15x15 网格，黑(0)背景。包含 2-4 个灰(5)空心矩形框，一像素宽边框，框的大小不同（内部面积互不相同）。部分框的边框是完整的（四条边无缺失像素），部分框的边框有 1-3 个缺口（边上缺失像素，但缺口不影响内部面积的定义——内部面积仍按边界框内部计算）。框之间互不接触、互不嵌套。网格上另散布有单独的标记像素，每种标记颜色（非黑(0)非灰(5)，如蓝(1)、红(2)、绿(3)、黄(4)等）的总数各不相同，且每种颜色的标记总数恰好等于某一个框的内部面积（内部行数 x 内部列数）。标记像素不在任何框的内部或边框上。生成约束：每个框恰好匹配一种标记颜色（一一对应）；至少 1 个框边框完整，至少 1 个框有缺口。

**规则**：
1. 对每个灰(5)框，计算其内部面积：边界框内部的行数乘以列数（不含边框像素本身）。
2. 对每种标记颜色，统计该颜色在网格上的标记像素总数。
3. 将每种标记颜色与内部面积等于该颜色标记数量的框配对。
4. 对每个配对的框，检查其灰(5)边框是否完整（边界框的四条边上是否全部为灰色像素，无缺失）。
5. 边框完整的框：将其全部内部像素用配对颜色实心填充。
6. 边框有缺口的框：将其内部像素用配对颜色做棋盘格填充——从内部左上角格子开始上色，按行列奇偶性交替填色与留黑（内部坐标 (r, c) 满足 (r+c) 为偶数的格子填色，奇数的留黑(0)）。
7. 擦除所有标记像素。框的灰(5)边框保持不变（含缺口的仍有缺口）。

**关键洞察**：同一种填充操作在不同条件下表现为两种模式（实心与棋盘格），而模式的切换由框本身的拓扑属性（边框是否完整）决定，而非由所配对的颜色或其他外部标记决定；需对比多个示例才能排除"按框大小决定模式"等替代假设。

p = Path("/home/lixinyu/snap/a/key_combo/code/opus/4/055/5.py")
mod = SourceFileLoader("new_arc_task", str(p)).load_module()
sigs = set()
for i in range(100):
    inp = mod.generate_input()
    out = mod.main(inp)
    assert isinstance(inp, np.ndarray)
    assert isinstance(out, np.ndarray)
    assert inp.ndim == 2 and max(inp.shape) <= 30, f"input grid exceeds 30x30: {inp.shape}"
    assert out.ndim == 2 and max(out.shape) <= 30, f"output grid exceeds 30x30: {out.shape}"
    sigs.add(hashlib.md5(inp.tobytes() + str(inp.shape).encode()).hexdigest())
print("variants", len(sigs))
assert len(sigs) >= 20
