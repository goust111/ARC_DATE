## 新题 9：射线分割产生区域，精灵体形状匹配精确拼合

**组合逻辑**：[射线延伸](已有) → [区域分割(涌现)](创新：射线与锚点共同划分出输入中不存在的矩形区域) → [精灵体形状匹配 → 拼合填充](已有原语的创新组合：精灵体不是填入预有孔洞，而是填入射线产生的新区域)

**来源原语**：射线延伸、锚定方块、标记像素、行列对齐、对齐标记连向锚点(d43fd935)；拼合填充、源精灵体、精灵填入孔洞、精灵精确拼合孔洞(184a9768)；计数(df8cc377)；擦除(184a9768)

**依赖链**：标记到锚点的射线延伸在空间中画出分割线 → 分割线与锚点和网格边界共同围成矩形区域（这些区域在输入中不存在） → 每个区域的形状和面积成为精灵体匹配的目标 → 精灵体必须恰好无旋转无翻转地平铺满区域 → 匹配结果决定哪个精灵体放入哪个区域。射线创造了容器，精灵体选择容器。

用锚点对齐的标记像素延伸射线分割画布，然后将散布的精灵体按形状精确拼合到射线围成的各个区域中。

**输入结构**：约 18x18 网格，黑(0)背景。网格中部偏位置有一个 3x3 灰(5)锚定方块。散布若干灰(5)标记像素，部分与锚定方块共享行或列（行列对齐），部分不对齐。另有 2-3 个小型单色精灵体（各 3-8 像素，4-连通，颜色各不相同，如蓝(1)、红(2)、绿(3)等），位于远离锚点的区域。生成约束：对齐的标记像素分布在锚点的不同方向（至少有来自两个方向的射线）；射线延伸后与锚点和网格边界共同围出的矩形区域数量等于精灵体数量；每个精灵体恰好可以通过纯平移（不旋转不翻转）重复铺满恰好一个区域（精灵体面积整除区域面积，且形状可无间隙无重叠地铺满该矩形）；每个精灵体与区域的配对是唯一的。

**规则**：
1. 识别所有与锚定方块行列对齐的灰(5)标记像素（与锚定方块的边界框共享至少一行或一列）。
2. 从每个对齐标记沿其对齐方向（同行则水平、同列则垂直）向锚定方块延伸灰(5)射线，直到碰到锚定方块边界外侧相邻格子。射线像素绘制为灰(5)。
3. 不对齐的标记像素直接擦除。
4. 射线、锚定方块、网格边界共同将背景划分为若干矩形区域。识别所有完全由灰(5)像素和/或网格边界围成的矩形背景区域（不含灰色像素本身，仅统计区域内的黑色背景格子）。
5. 对每个精灵体，检查它能否通过纯平移重复铺满某个矩形区域（精灵体的边界框尺寸必须整除区域尺寸，且铺满后无间隙无重叠）。将每个精灵体与它能唯一铺满的区域配对。
6. 将每个精灵体按平铺方式填入其配对区域：从区域左上角开始，逐行逐列重复精灵体图案。
7. 擦除精灵体原始位置的像素和所有原始标记像素。灰(5)射线和锚定方块保留。

**关键洞察**：待填充的区域在输入中并不存在——它们是射线延伸这一几何操作的副产物；精灵体与区域的配对不靠颜色或位置，而靠几何形状的铺满兼容性，这需要同时理解区域形状和精灵体形状。
