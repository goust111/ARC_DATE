## 新题 1：标记定向印章

**组合逻辑**：[标记坐标编码槽位](创新：从离散槽位改为连续方向向量编码) + [尺寸决定步幅] + [印章覆盖] + [擦除]（标记坐标编码槽位、尺寸决定步幅为已有原语；方向向量编码为创新用法）

**来源原语**：标记坐标编码槽位(marker_encodes_slot) ← 6d0160f0；尺寸决定步幅(size_determines_stride) ← e619ca6e；印章覆盖(stamp) ← e619ca6e；擦除(erase) ← e39e9282

**依赖链**：标记像素在矩形内的局部位置编码出方向向量（不再是离散的格子槽位，而是连续的八方向之一），矩形的宽高同时决定水平/垂直步幅。方向与步幅共同决定印章轨迹，两者缺一不可——改变标记位置则整条轨迹方向改变，改变矩形尺寸则步幅改变。

将每个彩色矩形沿其内部黄(4)标记像素所编码的方向反复印章，步幅由矩形自身尺寸决定，印章副本中的标记被擦除。

**输入结构**：约 20×20 的黑(0)背景网格。散布 3-5 个互不相邻的实心矩形（每个宽 3-6 像素、高 3-6 像素），各为不同颜色（从蓝(1)、红(2)、绿(3)、灰(5)、品红(6)、橙(7)、青(8)中选取）。每个矩形内部恰好有一个黄(4)像素（标记像素），占据矩形的某个位置区域。生成约束：各矩形间距足够大，使得沿任意方向印章时各矩形的轨迹互不重叠；每个矩形的宽和高均为 3 的倍数（便于三等分）。

**规则**：
1. 对每个矩形，将其边界框沿宽度和高度各三等分，形成 3×3 的九宫格区域。黄(4)标记像素落入的区域决定方向向量：左上→(-1,-1)、上中→(-1,0)、右上→(-1,+1)、左中→(0,-1)、正中→无印章、右中→(0,+1)、左下→(+1,-1)、下中→(+1,0)、右下→(+1,+1)。
2. 以矩形高度为垂直步幅 sv、宽度为水平步幅 sh。从矩形当前位置出发，沿方向向量每步偏移 (sv × 方向行分量, sh × 方向列分量)，在新位置放置矩形的完整副本。
3. 副本中的黄(4)标记像素替换为该矩形的主体颜色。
4. 超出网格边界的部分裁剪丢弃；当某次印章完全超出网格时停止该矩形的轨迹。
5. 保留原始矩形，但将其中的黄(4)标记像素也替换为矩形主体颜色。
6. 处理顺序：按矩形边界框左上角从上到下、从左到右依次处理。后处理的印章覆盖先处理的。

**关键洞察**：黄色标记像素不是装饰——它在矩形内的九宫格位置编码了八个可能的印章方向之一，而矩形的宽和高则各自独立地控制水平和垂直步幅，因此同一个对象同时提供了精灵图、方向和步幅三个参数。
