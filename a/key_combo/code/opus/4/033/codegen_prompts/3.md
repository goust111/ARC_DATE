## 新题 3：嵌套深度决定投影距离

**组合逻辑**：[包含](计算嵌套层数) → [计数](深度数值化) → [投影](距离 = 深度) + [重涂色](颜色 = 最内层框架色) + [擦除]（包含、投影、计数均为已有原语；嵌套深度作为投影距离的数值参数为创新结构关系）

**来源原语**：包含(containment) ← 8efcae92；投影(project) ← e39e9282；计数(counting) ← 642d658d；重涂色(recolor) ← 多源；擦除(erase) ← e39e9282

**依赖链**：嵌套矩形框架构成包含层级，标记像素的嵌套深度（被几层框架包围）直接成为投影的位移量——深度不再只是分类标签而是连续的几何参数。同时，最内层框架的颜色决定投影像素的颜色。移动任何一层框架会同时改变多个标记的深度和颜色归属，形成结构→数值→空间的三层耦合。

在嵌套矩形框架中，将栗(9)标记像素沿其所在侧向内投影，投影距离等于该标记被框架包围的层数，投影颜色取自最内层框架。

**输入结构**：约 17×17 的黑(0)背景网格。3-4 层嵌套的空心矩形框架（仅边框像素着色，内部为黑色），每层框架颜色不同（从蓝(1)、红(2)、绿(3)、橙(7)、青(8)中选取）。框架之间留有 2-3 像素的黑色间隙。在间隙中散布 4-6 个栗(9)标记像素，分布在不同嵌套深度的位置。生成约束：每个标记像素严格靠近其最内层框架的某一侧（与该侧边框的距离严格小于与其他三侧的距离）；不同标记的嵌套深度不全相同（至少出现 2 种不同深度）；投影后的目标位置不会落在框架像素上也不会超出最内层框架的内部区域。

**规则**：
1. 对每个栗(9)标记像素，计算其嵌套深度 D = 完全包围该像素的矩形框架数（一个框架"完全包围"某像素，当且仅当该像素在框架矩形的内部区域内，不在框架边框上）。
2. 确定该标记像素相对于其最内层包围框架的方位：计算标记到最内层框架内部区域四条边的距离，取距离最小的边作为"所在侧"。左侧→向右投影，右侧→向左投影，上侧→向下投影，下侧→向上投影。
3. 沿确定的方向移动 D 个像素，在目标位置放置一个新像素，颜色 = 最内层包围框架的颜色。
4. 擦除原始栗(9)标记像素（设为黑(0)）。
5. 框架本身不变。
6. 处理顺序：按标记像素位置从上到下、从左到右依次处理；若多个投影落在同一位置，后处理的覆盖先处理的。

**关键洞察**：嵌套深度在这里不是离散类别而是一个数值参数——它直接等于投影位移的像素数。求解者必须同时推断"投影方向由方位决定"和"投影距离由嵌套深度决定"两条规则，且两条规则必须配合才能确定输出。
