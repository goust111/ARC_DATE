## 新题 1：同心深度门控邻域扩展

**组合逻辑**：[循环填充/边距深度](创新：深度用于条件判断而非着色) → [描边/mark_neighbors](创新：扩展类型由深度奇偶决定，而非由标记颜色决定)

**来源原语**：循环填充(concentric_fill)、边距深度(edge_distance_depth) 来自 516b51b7；描边(mark_neighbors)、对角邻接(diagonal_adjacency)、正交邻接(orthogonal_adjacency)、标记色选邻域几何(marker_color_selects_neighborhood) 来自 0ca9ddb6；标记像素(marker_pixel) 为共享原语

**依赖链**：必须先从矩形几何计算每个标记像素的同心层深度，才能确定该标记应执行对角扩展还是正交扩展；深度是不可见的中间量，删去深度计算则无法选择扩展类型，删去扩展操作则深度无用

从矩形内标记像素的同心层深度推断扩展方式，对奇数深度标记做对角邻域标注，对偶数正深度标记做正交邻域标注，边缘标记不扩展。

**输入结构**：约 15x15 的黑(0)背景网格。网格中有 2~3 个互不相邻的实心绿(3)填充矩形，尺寸各不相同（最小约 5x5，最大约 9x7）。每个矩形内部散布 2~4 个孤立的红(2)标记像素，标记之间互不相邻（曼哈顿距离 >= 3），且分布在不同的同心层深度上（有的紧邻矩形边缘，有的深入矩形内部）。生成约束：每个矩形至少包含一个奇数深度标记和一个偶数深度（含深度 0）标记，以确保两种扩展方式都可被观察到。

**规则**：
1. 对每个红(2)标记像素，计算其在所属矩形内的同心层深度：标记到该矩形最近边缘的切比雪夫距离（即 min(到上边距离, 到下边距离, 到左边距离, 到右边距离)）。矩形最外圈像素深度为 0，向内一层为 1，依此类推。
2. 深度为 0 的标记（位于矩形边缘）：不执行任何扩展，将该标记像素从红(2)改涂为灰(5)作为标识。
3. 深度为奇数（1, 3, ...）的标记：在该标记的 4 个对角邻居位置放置黄(4)像素。
4. 深度为正偶数（2, 4, ...）的标记：在该标记的 4 个正交邻居位置放置橙(7)像素。
5. 扩展像素仅在网格范围内放置，不覆盖任何红(2)标记像素，也不覆盖已有的扩展像素（黄或橙）。当存在冲突时，按标记的处理顺序保留先生成的扩展像素。标记按行优先顺序处理（从上到下，同行从左到右）。
6. 绿(3)矩形像素保持不变，红(2)标记像素保持不变（深度 0 的除外，它们变灰(5)）。扩展像素覆盖在绿(3)之上。

**关键洞察**：同心层深度是一个必须从矩形几何推算的不可见属性，它作为隐式开关决定了邻域扩展的几何类型——这一条件映射关系在单个示例中无法与其他假设区分（如"上半区对角、下半区正交"），必须对比多个不同矩形和标记位置的示例才能归纳。
