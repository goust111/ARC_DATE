## 新题 1：拓扑门控的颜色位移印章

**组合逻辑**：[interior_containment](创新：空洞检测从"重涂色标准"变为"激活门控") → [color_encoded_disp](创新：颜色不再移动自身像素，而是编码印章目标偏移) → [stamp](创新：印章目标由颜色位移动态计算，而非固定占位对象)

**来源原语**：interior_containment, enclosed_region, objects_with_holes_recolored ← b2862040 | color_encoded_disp, foreground_pixel, color_determines_offset ← 342dd610 | stamp, mask_matching, source_colors_onto_placeholders ← 321b1fc6

**依赖链**：拓扑空洞检测筛选出"有效位移标记"（没有空洞的对象被淘汰）→ 有效标记的颜色被解码为位移方向与距离 → 源精灵体被印章到每个有效标记的位置加位移偏移处。三个环节紧耦合：删除门控则所有对象都触发印章（输出错误），删除颜色解码则无法确定印章位置，删除印章则前两步的筛选和解码毫无意义。

识别含空洞的前景对象作为有效位移标记，将其颜色解码为方向，在偏移位置印章源精灵体。

**输入结构**：
- 网格约 15x15，背景为黑(0)
- 网格左上区域有一个约 3x4 的多色源精灵体，由 2~3 种非黑颜色（如红(2)、绿(3)、黄(4)）构成不规则图案，每种颜色至少占 2 个像素
- 网格其余区域散布 4~6 个单色 4-连通小图形（每个 3~8 像素），每个图形仅使用橙(7)、蓝(1)、栗(9)、品红(6)四色之一
- 部分小图形的像素完全包围了一个或多个黑(0)背景像素（即存在 4-连通的内部空洞），部分小图形无空洞
- 不同示例中，哪些颜色的图形有空洞、哪些无空洞是变化的
- 生成约束：所有印章目标位置（有空洞图形的边界框左上角 + 位移向量）不超出网格边界；印章副本之间、印章副本与源精灵体之间不重叠；每种颜色的图形至少出现 1 个

**规则**：
1. 对每个非源精灵体的单色 4-连通前景图形，检测其是否包含 4-连通的内部背景空洞（被该图形像素完全包围的黑色连通区域）
2. 有空洞的图形标记为"有效标记"；无空洞的图形擦除为背景色
3. 颜色-位移映射表：橙(7) = 上移 3 格，蓝(1) = 右移 3 格，栗(9) = 下移 3 格，品红(6) = 左移 3 格
4. 对每个有效标记，计算印章目标位置 = 该标记边界框左上角坐标 + 对应颜色的位移向量
5. 在每个目标位置绘制源精灵体的完整副本，保留源精灵体的所有颜色
6. 擦除原始源精灵体和所有有效标记的像素（替换为背景色）
7. 绘制顺序：按目标位置行优先、列其次（从上到下、从左到右）；后绘制的覆盖先绘制的（生成时保证不重叠）

**关键洞察**：拓扑属性（空洞）和颜色语义（位移编码）是两层独立的筛选/解码机制，必须依次通过才能确定一个印章位置。仅看单个示例可能误以为"所有对象都触发印章"或"所有蓝色对象都印章到右侧"，只有对比多个示例中不同空洞状态才能归纳出门控规则。
