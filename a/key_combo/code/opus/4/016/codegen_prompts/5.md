## 新题 5：对角连线的图例排名重涂色

**组合逻辑**：[connect/diagonal_alignment](保留对角连线) → [sort/length_ranking](创新：排名对象从竖条变为对角线段) → [recolor via color_legend](创新：图例不再选竖条而选对角线段，高度仍是排名索引)

**来源原语**：connect, diagonal_pixel_pair, diagonal_alignment ← db695cfb | sort, length_ranking, color_legend, legend_height_as_rank_index ← 97d7923e | recolor ← 多题共有

**依赖链**：连接同色对角像素对形成对角线段 → 测量各线段长度并排名 → 图例方块高度作为排名索引选中对应线段 → 被选中线段重涂为图例方块颜色。线段必须先画出才能测量排名，图例的双重语义（颜色 + 排名索引）是推理核心。

先连接对角像素对生成线段，再按线段长度排名，用图例高度作为排名索引重新着色各线段。

**输入结构**：
- 网格约 15x18，背景为黑(0)
- 网格左侧 3 列为图例区：包含 3~4 个单色小方块，各方块宽 1 格、高度各异（1~4 格），颜色互不相同（如红(2)、绿(3)、黄(4)、品红(6)），从上到下排列，方块之间有至少 1 行黑色间隔
- 网格右侧为主区域：包含 3~4 对蓝(1)像素，每对位于同一条对角线上（行差绝对值 = 列差绝对值），不同对的对角线互不交叉
- 每对蓝像素之间的对角距离（沿对角线的像素数）互不相同
- 生成约束：图例方块数量 = 像素对数量；图例高度值互不相同且取值为 1 到像素对数量的连续整数；各对角线段不共享任何像素

**规则**：
1. 在主区域中，连接每对蓝(1)像素：沿共享对角线方向（左上-右下或左下-右上）绘制蓝色对角线段，包含两端点及之间所有对角像素
2. 按对角线段长度（像素数）从长到短排名（最长 = 排名 1）
3. 对每个图例方块（颜色 K，高度 k）：找到排名为 k 的对角线段，将该线段所有像素重涂为颜色 K
4. 将图例区所有像素替换为背景色（擦除图例）
5. 保留主区域中未被任何图例选中的线段为蓝(1)不变（当图例数量 < 线段数量时生效；生成时保证图例数量 = 线段数量）

**关键洞察**：蓝(1)像素的颜色仅用于标识像素配对关系，不是最终输出颜色。线段必须先连接才能测量长度，然后图例的高度值作为排名索引（而非字面尺寸）选中对应线段并赋予新颜色。仅看单个示例容易误以为图例高度表示线段的目标长度，必须对比多个示例中高度值与实际线段长度的不匹配才能发现"高度 = 排名"的隐蔽规则。
