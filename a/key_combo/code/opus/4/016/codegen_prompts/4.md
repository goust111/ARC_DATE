## 新题 4：压缩前置的引导掩码裁剪

**组合逻辑**：[compress/deduplicate](保留重复行列去重) → [guide_mask/bbox_containment](创新：引导掩码的有效框选范围在压缩后才成立) → [crop](保留裁剪)

**来源原语**：compress, deduplicate, adjacent_repeat, merge_identical_row_col ← e1baa8a4 | crop, guide_mask, hollow_sprite, bbox_containment, uniquely_enclosed ← bf699163

**依赖链**：识别重复行列并压缩 → 压缩同步改变引导掩码像素的相对位置 → 压缩后引导掩码的边界框恰好唯一框选一个目标图案 → 裁剪出该图案。压缩是选择的前提条件——不压缩则掩码框选范围错误。

先压缩含重复行列的膨胀网格，使引导掩码收拢到正确框选范围，再裁剪出唯一被框选的图案。

**输入结构**：
- 网格约 16x20，背景为黑(0)
- 网格实际上是一个约 8x8 的原始彩色图案经行列不均匀膨胀生成（不同行组重复 1~3 次，不同列组重复 1~3 次），使得图案中的对象在膨胀后被拉伸变形
- 原始图案中包含 3~4 个小型单色空心方形（3x3，由不同颜色如红(2)、蓝(1)、绿(3)构成，中心为背景色），分布在原始网格的不同位置
- 膨胀网格中散布若干品红(6)像素作为引导掩码，这些像素不落在空心方形的像素上，仅落在背景区域
- 生成约束：在膨胀网格中，品红像素的边界框包含 2 个或以上空心方形（因膨胀使空间被拉伸）；压缩回原始尺寸后，品红像素的边界框恰好仅完全包含 1 个空心方形

**规则**：
1. 识别所有最大重复行段（相邻完全相同的行，逐像素比较）和最大重复列段（相邻完全相同的列），每段保留第一行/列，删除其余重复行/列
2. 品红(6)引导掩码像素与网格内容同步经历压缩（其所在行/列若被删除则该掩码像素也被删除，若保留则保留）
3. 在压缩后的网格中，计算所有剩余品红(6)像素的边界框
4. 在压缩后的网格中，找到所有 3x3 空心方形（外圈为同一非黑非品红颜色、中心为黑色的 3x3 区域）
5. 确定唯一一个完全包含在品红边界框内的空心方形
6. 输出该空心方形的 3x3 紧凑裁剪（不含品红像素；品红像素若在裁剪区域内则替换为黑(0)）

**关键洞察**：在膨胀网格中，引导掩码的边界框因行列重复而被拉伸，看起来包含多个候选空心方形；只有先压缩去重，掩码才收拢到正确的唯一框选范围。求解者必须意识到压缩是选择的前提——在膨胀网格上直接裁剪会得到错误结果。
