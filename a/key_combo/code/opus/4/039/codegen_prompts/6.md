## 新题 6：唯一精灵体经波浪弯折后保留

**组合逻辑**：[去重筛选/异常值选择](已有) → [移位/逐行交替方向](创新：波浪弯折不再应用于整个前景格子体，而是仅应用于通过唯一性筛选后的单个精灵体) → [擦除](已有，擦除重复精灵体)

**来源原语**：去重筛选/uniqueness_filter + 异常值选择/outlier_selection + 图案仅出现一次/pattern_once（aee291af）、移位/shift + 逐行交替方向/alternating_direction_per_row + 底行锚定/bottom_row_anchored（1c56ad9f）、擦除/erase（ae3edfdc）、连通分量检测/connected_component_detection（84db8fc4）

**依赖链**：在多个前景精灵体中识别哪个是唯一的（形状不重复） → 仅对该精灵体执行波浪弯折 → 擦除所有重复的精灵体。删除唯一性检测，不知道哪个精灵体做弯折；删除弯折，输出退化为简单的异常值提取。

在多个精灵体中找出形状唯一的那个，对其做逐行交替偏移的波浪弯折，擦除其余所有重复精灵体。

**输入结构**：约 15x20 的网格，背景为黑(0)。网格中有 5~7 个灰(5) 的 4-连通精灵体，彼此不相邻（8-连通距离至少 2）。精灵体均为小型图案（占据 3x3 到 5x5 的边界框，像素数 4~12）。其中存在若干组"重复"精灵体：同组内各精灵体归一化后形状完全相同（将精灵体平移到边界框左上角后像素图案一致），每组至少 2 个。恰好有一个精灵体的归一化形状在所有精灵体中仅出现一次（唯一精灵体）。该唯一精灵体的边界框每行都有至少一个灰色像素（保证波浪弯折有意义）。生成约束：(a) 重复组至少 2 组，每组 2~3 个；(b) 唯一精灵体的边界框高度至少 4 行，使弯折效果可见。

**规则**：
1. 找出所有灰(5) 的 4-连通精灵体。对每个精灵体提取其归一化形状（平移到左上角为原点后的像素坐标集合）。
2. 比较所有精灵体的归一化形状，找到仅出现一次的形状对应的精灵体（唯一精灵体）。
3. 对唯一精灵体执行波浪弯折：以其边界框最底行为锚定行（不偏移），从底行向上每隔一行交替偏移——第一个偏移行向右移 1 像素，第二个偏移行向左移 1 像素，依此交替。偏移在网格坐标系中执行，超出网格边界的像素舍弃。
4. 擦除所有非唯一精灵体（将其像素改为黑(0)）。
5. 输出中仅保留弯折后的唯一精灵体和黑色背景。

**关键洞察**：这不是简单的"找不同后提取"——唯一精灵体被找到后还要经历波浪变形，而变形参数（锚定行、偏移方向）隐含在弯折规则中，需要对比多个示例才能确定偏移模式（先右后左还是先左后右、锚定在底行而非顶行）。
