## 新题 5：边框边长编码目标面积匹配填充

**组合逻辑**：[计数](创新：计数对象从"4-连通物体个数"变为"矩形边框每条边的像素数") → [面积匹配/像素数等于腔面积](创新：匹配的不再是源像素集与腔面积，而是边框边长与轮廓内腔面积) → [填充](已有) + [朝向对应边色](创新：边色不再填入缺口，而是填入面积匹配的轮廓内腔)

**来源原语**：计数/counting（edcc2ff0/7acdf6d3）、面积匹配/area_matching + 像素数等于腔面积/count_equals_cavity（7acdf6d3）、填充/fill（7acdf6d3）、矩形边框/rectangular_frame + 朝向对应边色/facing_side_color（5b37cb25）、轮廓对象/outline_object + 行内腔/row_interior（7acdf6d3）、连通分量检测/connected_component_detection（84db8fc4）

**依赖链**：测量矩形边框四条边各自的像素长度 → 在边框内部找到多个灰色轮廓对象并计算每个轮廓的内腔面积 → 将每条边的长度与某个轮廓内腔面积做匹配（长度 = 面积） → 用匹配到的边的颜色填充对应轮廓的内腔。删除边长测量，不知道目标面积；删除面积匹配，不知道哪个轮廓对应哪个颜色。

测量矩形边框每条边的像素数，找到边框内部与该数值面积相同的轮廓内腔，用该边的颜色填充。

**输入结构**：约 16x16 的网格，背景为黑(0)。网格最外圈为一像素宽的矩形边框，四条边各自为不同的纯色：上边为蓝(1)、右边为红(2)、下边为绿(3)、左边为黄(4)（四个角像素为黑色，不属于任何边）。边框内部为黑色背景，其中有 4 个灰(5) 轮廓对象，每个轮廓对象是一个封闭的单像素宽灰色环（8-连通闭合曲线），内部为黑色空腔。四个轮廓的内腔面积（内腔中黑色像素总数）互不相同，且分别等于矩形边框四条边中某一条的像素长度（不含角，即纯色段的像素数）。轮廓对象之间不重叠、不相邻。生成约束：(a) 网格为矩形但不一定是正方形，使得四条边像素数可以不同（如 16x14 时上下边各 14 像素，左右边各 14 像素——需要非正方形才有不同长度的边）；(b) 实际使用非正方形网格如 14x18 使上边/下边为 12 像素（去掉两角），左边/右边为 16 像素（去掉两角），从而产生两种不同长度；为获得四种不同长度，将上边和下边各减去若干角落相邻像素或使用不对称设计——简化方案：允许上边和下边长度不同、左边和右边长度不同，通过在某些边上留出额外黑色间断来实现不同有效长度。(c) 每个轮廓内腔面积恰好匹配一条边，一一对应，无歧义。

**规则**：
1. 识别矩形边框的四条边。边框占据网格第 0 行、最后一行、第 0 列、最后一列。四个角(0,0)、(0,W-1)、(H-1,0)、(H-1,W-1)为黑色。上边 = 第 0 行中连续的非黑像素段，记录其颜色和像素数 L_top；同理得到 L_right、L_bottom、L_left 及各自颜色。
2. 在边框内部（去掉最外圈一行一列后的矩形区域），找到所有灰(5) 的 8-连通区域，每个即为一个轮廓对象。
3. 对每个轮廓对象，计算其内腔面积：轮廓边界框内、被灰色像素完全包围的黑色 4-连通区域的像素总数。
4. 对四条边中的每条，找到内腔面积等于该边像素数的唯一轮廓对象。用该边的颜色填充该轮廓的内腔。
5. 灰色轮廓本身保持不变。边框保持不变。其余黑色背景保持不变。

**关键洞察**：边框不是纯粹的装饰边界——每条边的像素长度是一条隐式编码的数值指令，它指定了哪个轮廓内腔是该颜色的目标。求解者需要同时"测量"边框和轮廓，然后通过数值等式建立对应关系。
