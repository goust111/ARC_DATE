## 新题 4：图例定序同心环与最近种子分区

**组合逻辑**：[查表替换](创新：图例面板不再做颜色-形状翻译，而是提供有序调色板) + [同心层填充](已有，但调色板来源从色板行改为图例面板) + [最近邻分区](创新：多种子的切比雪夫最近分配，源题中不存在)

**来源原语**：查表替换/lookup_replace + 图例面板/legend_panel（b20f7c8b）、同心层填充/concentric_fill + 切比雪夫距离索引/chebyshev_index + 种子像素/seed_pixel（9356391f）、色板按距离配色/palette_color_by_distance（9356391f）、最近邻匹配/nearest_neighbor_matching（50aad11f）

**依赖链**：图例面板的垂直排列顺序决定调色板；种子像素提供扩展中心；切比雪夫距离索引将调色板映射到空间；当多种子环形重叠时最近邻规则解决冲突——四个逻辑交织成空间分区着色。

从图例面板中自上而下读取调色板，以多个种子像素为中心画同心方环，重叠区域归属切比雪夫距离最近的种子。

**输入结构**：约 20×20 的网格。左侧 5 列为青(8)边框的图例面板，面板内从上到下排列 3~5 个小图形（每个为不同颜色的 4-连通形状，约 2~4 像素），图形之间用青(8)行分隔。面板右侧为黑(0)背景画布，画布上散布 2~3 个孤立的白色单像素种子（因白色不在 0-9 标准色中——修正：使用栗(9)色单像素作为种子标记）。生成约束：种子之间的切比雪夫距离至少为 6，以确保最近环之间有足够空间区分；调色板长度（图例中图形数量）不超过种子间最小半距离。

**规则**：
1. 读取图例面板：从上到下依次记录每个图形的颜色，形成有序调色板 P[0], P[1], ..., P[N-1]。图形的具体形状不影响规则，仅颜色和垂直位序有意义。
2. 画布上每个非种子单元格 (r, c)，计算其到所有种子像素的切比雪夫距离（max(|r-sr|, |c-sc|)），取最小值及对应种子。若到两个种子的最小切比雪夫距离相同，归属行坐标更小的种子；若行坐标也相同，归属列坐标更小的种子。
3. 设该单元格到其归属种子的切比雪夫距离为 d。若 d ≤ N-1，将该单元格着色为 P[d]；若 d > N-1，保持黑(0)。
4. 种子像素本身着色为 P[0]（调色板第一色取代种子标记色）。
5. 图例面板原样保留在输出中。

**关键洞察**：图例面板在参考题 b20f7c8b 中是颜色-形状双向字典，此题中仅用其垂直排列顺序编码距离调色板——形状本身无意义，这一点只有对比不同示例（相同颜色出现在形状不同的图例中但输出不变）才能确认。多种子的切比雪夫最近分区产生类似 Voronoi 的方形边界，是源题中不存在的涌现结构。
