## 新题 9：楔形对角传播中墙壁注入替换色

**组合逻辑**：[填充+沿对角线传播+收缩楔形+逐行交换双色](保留楔形传播机制) ×交织× [反弹/墙壁交互+颜色继承](创新：墙壁不引起方向反弹而是沿对角线注入替换色，将双色交替中的一色永久替换)

**来源原语**：填充+顶行色带+收缩楔形+沿对角线传播+逐行交换双色(b5bb5719)、墙壁像素+颜色继承+碰撞停止(142ca369)、反弹(142ca369)

**依赖链**：楔形传播决定了哪些位置需要填色以及基础的双色交替图案；墙壁像素在传播路径中注入第三种颜色，改变其所在对角线上所有后续格子的颜色——传播机制与颜色注入在同一空间中逐行交织，无法分步执行。

顶行双色色带向下传播为收缩楔形，遇到墙壁像素时该对角线上的一种交替色被墙壁色永久替换。

**输入结构**：约 13x13 的橙(7)背景网格。包含以下元素：
- **顶行色带**：顶行的一个连续奇数宽度区间（5~9 像素），由红(2)和灰(5)严格交替填充（第一个像素为红(2)或灰(5)，依次交替）。区间外为橙(7)背景。
- 1~2 个**墙壁像素**：颜色各异（例如蓝(1)、绿(3)），位于色带区间下方、楔形未来覆盖区域内（即第 rw 行的列坐标在 span_left+rw 到 span_right-rw 之间）。
- 生成约束：墙壁像素互不在同一对角线上（每条从顶行出发的对角线最多一个墙壁）。楔形在到达网格底部之前因收缩而自然结束（即 span_width/2 < grid_height）。

**规则**：
1. 楔形传播基础规则（同 b5bb5719）：从顶行色带出发，第 r 行（r=0 为顶行）填充列范围 [span_left+r, span_right-r]。每个填充格 (r, c) 的颜色取自顶行第 c-r 列的颜色，再做 r 次红(2)↔灰(5)翻转（等效：r 为偶数保持原色，r 为奇数翻转）。
2. 墙壁交互规则：当楔形传播到达墙壁像素 (rw, cw) 时：
   - 墙壁像素本身保留不变（不被楔形覆盖）。
   - 确定该墙壁位置在无墙情况下本应获得的颜色 X（红(2)或灰(5)之一）。
   - 在同一条对角线上（从 (rw, cw) 沿对角线方向 (r+1, c+1) 或 (r+1, c-1)，取决于该格位于楔形中心的哪一侧：若 cw <= 楔形中心列则沿 (r+1, c+1)，若 cw > 中心列则沿 (r+1, c-1)），所有后续楔形格中本应为颜色 X 的格子改为墙壁像素的颜色。另一种交替色保持不变。
3. 若一个格子同时受多个墙壁影响（生成时已排除），后遇到的墙壁覆盖先前的替换色。
4. 楔形区域外的格子保持橙(7)背景。

**关键洞察**：楔形的双色交替图案是全局规律，但墙壁像素在局部注入第三种颜色，沿一条对角线"污染"后续所有格子。这种污染不是简单地覆盖一个点，而是替换交替序列中的一个颜色通道——视觉上表现为楔形中出现一条斜向的异色条带，条带的起点和颜色由墙壁决定。
