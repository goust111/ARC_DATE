## 新题 7：多色叶突坐标交叉印章

**组合逻辑**：[叶状突起选行列](已有，创新：突起多色化，颜色承载匹配信息) + [印章覆盖](已有，创新：印章位置由行列交叉点确定) + [颜色匹配](创新：行叶与列叶同色时才触发印章) + [擦除](已有)

**来源原语**：叶状突起/leaf_protrusion、突起定行列/leaf_selects_row_col（来自 f1cefba8）；印章覆盖/stamp_overlay、精灵体/sprite（来自 e5062a87、48f8583b）；颜色匹配/color_match（来自 981add89）；擦除/erase（来自 54db823b）

**依赖链**：叶突位置 → 确定选中的行和列 → 叶突颜色 → 在行列交叉点执行同色匹配过滤 → 匹配成功的交叉点放置对应颜色的模板印章。移除叶突位置则无坐标；移除颜色匹配则所有交叉点都印章（过多/错误）；移除模板则无印章内容。

矩形边框上的多色叶突标记选中行和列；只有颜色相同的行叶与列叶所确定的交叉点才会被印上对应颜色的模板精灵。

**输入结构**：
- 约 16x16 网格，黑(0)背景
- 一个灰(5)单像素厚矩形边框（约 10x10），内部填充黄(4)
- 矩形边框外侧有 4-6 个单像素叶突，每个叶突紧邻边框灰像素并向外延伸 1 格到黑(0)背景上：
  - 位于边框上边或下边的叶突：该叶突选中其所在列
  - 位于边框左边或右边的叶突：该叶突选中其所在行
  - 叶突颜色为红(2)、蓝(1)或绿(3)（不同叶突可同色可异色）
- 矩形外部、远离边框的位置有 2-3 个模板精灵，颜色分别为红(2)、蓝(1)、绿(3)，与叶突颜色一一对应。每个模板为 4-连通、3-5 像素的不规则小形状，不同颜色的模板形状不同
- 生成约束：至少存在一对同色的行叶与列叶；模板印章在有效交叉点处不会超出矩形内部区域；各印章之间不重叠

**规则**：
1. 识别每个叶突的颜色和类型（行选择 or 列选择）：
   - 叶突与灰(5)边框像素的相邻方向为上下（即叶突在边框正上方或正下方）→ 列选择叶突，选中该列
   - 叶突与灰(5)边框像素的相邻方向为左右（即叶突在边框正左方或正右方）→ 行选择叶突，选中该行
2. 枚举所有（行选择叶突 R，列选择叶突 C）配对：
   - 若 R 的颜色 == C 的颜色 → 该交叉点（R 选中的行，C 选中的列）被标记为"有效印章点"，印章颜色为该共同颜色
   - 若 R 的颜色 != C 的颜色 → 不标记
3. 对每个有效印章点，取对应颜色的模板精灵，将模板的包围框左上角对齐到该交叉点所在格，将模板像素印章到矩形内部：仅覆盖黄(4)的格（涂为模板颜色），不覆盖灰(5)边框或已印章的格
4. 处理顺序：按交叉点的行优先、列次优先顺序处理
5. 矩形外部的模板精灵在输出中擦除为黑(0)

**关键洞察**：叶突的功能被从"选行列后延伸射线"改造为"选行列后在交叉点印章"，且加入了颜色一致性门控——只有行叶和列叶颜色匹配时才产生印章。这意味着同一行被多个列叶交叉时，只有同色列叶的交叉点有效。求解者需通过多个示例区分"所有交叉点印章"与"同色交叉点印章"两种假说。

## 实现要求

1. `main(grid)` 必须实现新题描述中的确定性转换规则，不能只识别 `generate_input()` 的固定模板。禁止不同的input网格输出相同的output网格。
2. `generate_input()` 必须随机生成多样样例，不能固定死。随机维度应覆盖：网格大小、对象数量、位置、颜色、方向、形状参数或关键分支。注意若描述中存在若干，需实现而不是只有单个，包括object或者对应关系等等。
3. 生成器必须保证输入满足 `main()` 的隐式假设：对象不重叠、不越界、特殊标记唯一或可区分、匹配关系无歧义、关键分支出现概率相同。
4. 禁止把 ARC 颜色 id 、亮度、拼写等当作人类不可见的数值语义参与排序、大小比较或隐藏映射。颜色变化必须有可见结构线索。注意颜色亮度、拼写等也是不可见信息，若描述中出现违规的颜色id或者亮度，可自行使用少量的固定颜色替代，但注意生成时要在三个以内输入输出网格中对所有变换100%覆盖度。
5. 输出样例要视觉清晰，人类必须能从输入输出对中肉眼辨认出规律。具体要求：避免对象粘连、覆盖关系混乱、同一像素多重语义；不同逻辑步骤产生的结果不要大面积层叠在一起导致无法分辨哪个颜色属于哪个步骤；输入中各元素之间保持足够间距，输出中新增的标记/填充/路径等应与背景和已有元素在颜色上有明显区分；若规则涉及多层叠加，生成时控制对象密度和尺寸，确保叠加区域只占少数像素而非铺满整个网格。
6. 若规则有多个分支，生成器不能长期固定成一个分支；应让分支在随机样例中合理出现。分支概率不必平均——难以发现的隐蔽分支（如少数情况下才触发的特殊规则）应适当提高出现概率，确保在 3 个训练示例中至少出现一次，否则求解者无法归纳该规则。对于颜色映射类规则，确保 2 个左右的示例即可覆盖所有映射关系（每种颜色→颜色的映射至少在某个示例中出现过）。
