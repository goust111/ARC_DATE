## 新题 1：同心环迷宫寻路

**组合逻辑**：[同心层填充](已有，从b7fb29bc) + [奇偶距离决定颜色→迷宫墙壁](创新：奇偶分色从装饰变为通行性判据) + [寻路](已有，从b15fca0b) + [重涂色](已有)

**来源原语**：同心层填充、控制像素、同心正方形层、奇偶距离决定颜色 → b7fb29bc；寻路、端点像素、障碍像素、最短路径、四邻接连通 → b15fca0b；重涂色 → b15fca0b

**依赖链**：控制像素的偏心位置决定同心环布局 → 奇偶距离规则将环分为通行层与阻挡层 → 路径搜索受限于通行层拓扑 → 路径像素重涂色。删除同心填充则无迷宫；删除寻路则无路径输出；删除奇偶规则则无墙壁约束。

在矩形边框内部，以偏心控制像素为中心生成同心方环，奇距离层为通道、偶距离层为墙壁，然后在通道层中找出两端点之间的最短路径并标记。

**输入结构**：约15x15黑(0)背景网格。一个灰(5)像素构成的矩形单像素边框。边框内部有一个绿(3)控制像素，位置偏离中心（不在边框内部的几何中心上）。边框内部另有两个红(2)端点像素，分布在控制像素的不同方位、位于不同切比雪夫距离层上。所有其他内部像素为黑(0)背景。生成约束：两个红(2)端点之间存在至少一条仅经过奇切比雪夫距离层的4-连通路径，且该路径唯一最短。

**规则**：
1. 保持灰(5)边框、绿(3)控制像素和红(2)端点像素不变。
2. 对边框内部每个黑(0)背景像素，计算其到绿(3)控制像素的切比雪夫距离 d。
3. d 为偶数的像素涂为红(2)（墙壁层）；d 为奇数的像素涂为黄(4)（通道层）。
4. 以黄(4)像素和红(2)端点像素为可通行区域，红(2)墙壁层像素为不可通行区域，找到两个红(2)端点之间的唯一最短4-连通路径。
5. 将路径上的黄(4)内部像素（不含两个端点本身）重涂为蓝(1)。

**关键洞察**：同心环的奇偶分色不是视觉装饰，而是迷宫墙壁的生成机制——控制像素的偏心位置导致各方向的通道层宽度不均匀，某些方向的通道仅一像素宽而另一些方向的通道宽达数像素，间接约束了路径走向。必须对比多个示例才能归纳出"偶距离=墙壁、奇距离=通道"的规则。
