## 新题 10：精灵对接拼合与封闭空腔洪泛填色

**组合逻辑**：[对接拼合/docking](已有) → [裁剪/crop](已有) → [洪泛填充/flood_fill](已有，但作用于对接后才出现的封闭区域) + [连接点颜色匹配/connector_color_match](已有，连接点颜色额外用作填充色)

**来源原语**：对接拼合、精灵体、连接点、对接对齐、连接点颜色匹配(来自 20270e3b)；裁剪(来自 fcb5c309)；洪泛填充、封闭区域、区域封闭、孤立背景区域填充(来自 a5313dff)

**依赖链**：连接点颜色匹配确定对接对 → 平移对接改变空间布局 → 拼合后的形状可能围出封闭空腔 → 洪泛填充检测这些空腔 → 空腔用连接点的颜色填充 → 紧凑裁剪。对接决定最终形状（拓扑），拓扑决定是否有封闭区域，封闭区域的颜色来自对接时用过的连接点。

将两个带有同色连接点的精灵对接拼合，拼合后形状围出的封闭背景空腔用连接点颜色填充，最后紧凑裁剪。

**输入结构**：
- 黑(0)背景，约 16x16 网格。
- 两个独立的灰(5)精灵体（各 8~15 像素，4-连通，不规则形状），放置在网格不同区域，互不接触。
- 每个精灵各有恰好一个红(2)像素作为连接点，该连接点位于精灵的边界（与至少一个背景像素 4-邻接）。
- 生成约束：基座精灵（包围框左上角在阅读顺序中更靠前的那个）的连接点位于其下边界；插入精灵的连接点位于其上边界。对接后（插入精灵的连接点移至基座连接点正上方一格），两个精灵合并后的 4-连通灰色+红色像素集合围出至少一个封闭的黑(0)背景区域（该区域无法通过 4-邻接背景路径到达合并体外部）。

**规则**：
1. 确定基座精灵：两个精灵中，包围框左上角按阅读顺序（先比行、行同比列）更靠前的为基座。另一个为插入体。
2. 平移插入体，使其红(2)连接点恰好位于基座红(2)连接点正上方一格。
3. 将两个连接点的红(2)像素重涂为灰(5)，使其融入精灵体。
4. 对合并后的形体执行紧凑裁剪：取所有非黑像素的最小包围框。
5. 在裁剪区域内，以灰(5)像素为墙壁，从裁剪区域的四条边出发做 4-邻接洪泛标记所有可达的黑(0)像素为"外部"。
6. 裁剪区域内剩余的未标记黑(0)像素为封闭空腔，将其全部填充为红(2)（连接点的原始颜色）。
7. 输出裁剪后的结果。

**关键洞察**：两个精灵单独存在时没有任何封闭区域，对接拼合后其几何形状产生了输入中不存在的空腔——这是典型的涌现效应。连接点的颜色从"匹配标识"变为"空腔填充色"，一色三用（匹配、定位、填色）。
