## 新题 6：对角射线延伸与端点桥接连线

**组合逻辑**：[射线延伸/ray_cast](已有，方向和种子不变) → [连线/line_drawing](创新：端点不再是预置的标记对，而是射线到达网格边界前的最后一个像素) + [纵线覆盖横线/vertical_over_horizontal_priority](已有，应用于射线与连线的交叉)

**来源原语**：射线延伸、实心正方形、对角标记、画布边界、对角邻接、锚角对角射线至边(来自 7ddcd7ec)；连线、轴对齐线段、共行或共列(来自 070dd51e)

**依赖链**：2x2 正方形的角落位置 + 对角标记位置确定射线方向 → 射线沿对角线延伸到网格边界 → 两条射线的终点（最后一个网格内像素）成为连线端点 → 端点之间画轴对齐线段 → 线段与射线交叉时，后绘制者覆盖先绘制者。射线方向决定终点位置，终点位置决定连线几何，几何决定交叉。

从两个 2x2 正方形的对角标记分别射出对角线到网格边界，再在两条射线的终点之间画一条轴对齐连线，交叉处连线覆盖射线。

**输入结构**：
- 黑(0)背景，约 14x14 网格。
- 两个红(2) 2x2 实心正方形，位于网格不同区域（包围框不重叠），彼此距离至少 4。
- 每个正方形恰有一个黄(4)对角标记像素：该像素位于该正方形某一角的对角外侧（与角共对角线的相邻背景像素），且该方向的对角线可以延伸至少 3 格才到达网格边界。
- 生成约束：两条对角射线的终点（到达网格边界前的最后一个网格内像素）恰好位于同一行或同一列，保证可以用一条水平或垂直线段连接。

**规则**：
1. 保留输入中的所有红(2) 2x2 正方形及黄(4)对角标记。
2. 对每个对角标记，沿其远离正方形的对角方向，逐格绘制黄(4)像素，直到下一个像素超出网格边界为止。记录每条射线的最后一个像素位置（"终点"）。
3. 在两个终点之间绘制一条绿(3)直线段（含两端点），连接它们共享的行或列。
4. 若绿(3)线段经过已有黄(4)射线像素的位置，绿(3)覆盖黄(4)。
5. 红(2)正方形像素不被任何射线或线段覆盖。

**关键洞察**：对角标记不仅发射射线——射线的落点（打在网格边界上的位置）成为一条桥接线的锚点。求解者必须先追踪两条发散的对角射线到达边界的位置，才能知道桥接线画在哪里。
