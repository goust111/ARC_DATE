## 新题 9：模板精灵沿延伸条纹平铺并按间距保持着色

**组合逻辑**：[射线延伸/ray_extend + 标记排除对应行列/marker_excludes_row_col + 延伸条纹/extension_stripe](来自9def23fe) → [平铺/tile + 控制像素对应副本/control_pixel_to_copy + 间距保持一致/gaps_preserved](来自9b2a60aa，创新：平铺轨道不是直线而是延伸条纹的形状，间距由条纹间的排除区决定) → [标记色传递给模板/marker_color_pass](来自fd02da9e，创新：颜色源从角落标记变为条纹方向上的控制像素)

**来源原语**：ray_extend、marker_excludes_row_col、extension_stripe、solid_rectangle、control_pixel、side_strip_align（9def23fe）；tile、control_pixel_to_copy、gaps_preserved、template_sprite、control_pixel_line（9b2a60aa）；marker_color_pass、erase（fd02da9e）

**依赖链**：控制像素排除某些行/列 → 产生不连续的延伸条纹 → 模板精灵沿每段条纹平铺 → 条纹间的断裂间距成为副本间的间距 → 每段条纹最近的控制像素的颜色传递给该段上的副本。排除模式同时控制了平铺轨道的形状和副本的着色——同一信息源驱动两个不同的下游效果。

矩形沿未被标记行列的延伸条纹平铺模板精灵，断裂间距决定副本间隔，最近控制像素传递颜色。

**输入结构**：黑(0)背景上有一个青(8)实心矩形（约 4x6），矩形四周的侧边带中有若干控制像素（颜色各不相同，选自红(2)、绿(3)、蓝(1)、橙(7)），每个控制像素与矩形共行或共列。另有一个小型模板精灵体（约 3x2 像素的不规则形状，使用灰(5)），位于网格角落。网格约 22x22。生成约束：每侧至少有一个行/列未被控制像素排除；模板精灵的包围盒不超过矩形在对应方向的尺寸。

**规则**：
1. 按 9def23fe 的规则确定延伸条纹：矩形的上方，每列若无控制像素则向上延伸至网格边界，否则不延伸；下方、左方、右方同理。延伸区域由离散的条纹段组成（被排除行/列打断）。
2. 对上方和下方的延伸区域：沿列方向（垂直方向），在每段连续条纹上从靠近矩形的端开始，逐个放置模板精灵的副本。相邻副本之间的间距等于该段条纹与前一段条纹之间被排除的行数。若条纹段长度不足以放下完整副本，跳过该段。
3. 对左方和右方的延伸区域：沿行方向（水平方向），同理放置。
4. 每个副本的颜色由其所在条纹段最近的控制像素决定：在排除该条纹的方向上，找到与该段相邻的控制像素（即导致相邻条纹断裂的那个控制像素），副本使用该控制像素的颜色。若条纹段两侧都有控制像素，取距矩形更近的那个。若条纹段紧邻矩形边且旁边无控制像素，使用矩形的颜色青(8)。
5. 原始矩形、控制像素和模板精灵保持不变。副本与任何已有像素重叠时，已有像素保持不变（副本不覆盖）。

**关键洞察**：控制像素一箭双雕——它们既定义了条纹断裂的位置（决定平铺轨道和间距），又为断裂处旁边的条纹段提供颜色（决定副本外观），同一个控制像素的空间位置同时编码了几何信息和颜色信息。
