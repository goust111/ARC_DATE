## 新题 6：双面板异或差异揭示隐藏周期结构

**组合逻辑**：[逐像素比较 + 异或差异判定](来自 #18 34b99a2b，创新：XOR 结果不是最终输出的红色标记，而是周期推断的输入数据) → [平铺 + 最小周期修复缺口](来自 #9 e95e3d8e，创新：周期结构不存在于输入网格中，而是两面板差异的涌现属性)

**来源原语**：逐像素比较(cell_by_cell_comparison)、差异标记(mark_differences)、二值掩码(binary_mask)、分隔列(separator_column)、面板对齐(panel_alignment)、异或差异判定(xor_difference) ← #18 34b99a2b；平铺(tiling)、周期瓦片(periodic_tile)、周期对齐(periodic_align)、最小周期修复缺口(min_period_repair_gap) ← #9 e95e3d8e

**依赖链**：XOR 比较产生一个不完整的二值掩码 → 该掩码隐含周期结构 → 最小周期推断填补缺失位置。单个面板无周期性；XOR 产生的掩码中也有蓄意隐藏的位置（两面板在此一致导致该位置不出现在 XOR 中）。三步链路中每步都对下一步执行了不可逆的信息变换。

对齐左右面板并计算逐像素异或差异，差异位置构成一个有缺失的周期图案，推断最小周期并填补缺失位置后输出。

**输入结构**：
- 网格约 11 行 x 23 列，正中央一列为黑(0)分隔列（列索引 11）。
- 左面板（列 0~10）和右面板（列 12~22），均为 11 行 x 11 列。
- 两面板背景为灰(5)，前景像素使用蓝(1)和红(2)散布其中。
- 每个面板的前景图案看起来无规律、不具周期性。
- 生成约束：两面板的 XOR（恰好一个面板该位置有前景、另一个为背景的格子集合）必须构成一个矩形周期图案（周期尺寸在 2x2 到 4x4 之间），但该周期图案有 10%~30% 的位置被蓄意隐藏（这些位置两面板一致，不出现在 XOR 中）。

**规则**：
1. 将左右面板按行列对齐（忽略分隔列），得到 11x11 对齐网格。
2. 计算 XOR 掩码：某位置 (r, c) 为"激活"当且仅当对齐的两个格子中恰有一个为非背景色（蓝或红），另一个为背景(5)。
3. 激活位置构成一个有缺失的周期图案。推断最小矩形周期（最小的周期高度 pH 和宽度 pW，使所有激活位置与其 (r mod pH, c mod pW) 余类一致，且每个余类至少有一个激活位置作为证据）。
4. 填补缺失：对每个非激活位置，若其 (r mod pH, c mod pW) 对应的余类中存在激活位置，则将该位置也标记为激活。
5. 输出 11x11 网格：激活位置为红(2)，其余为黑(0)。

**关键洞察**：任一面板单独观察都不具有周期性——周期结构是两面板差异的涌现属性，只在 XOR 之后才可见。部分周期位置被蓄意隐藏（两面板在此一致），因此 XOR 掩码本身也不完整，必须通过最小周期推断来恢复完整图案。
