## 新题 8：帧边标记兼任射线转向触发器与印章坐标

**组合逻辑**：[射线延伸 + 转向](来自 #3 e5790162，创新：转向不由独立的粉/青控制点触发，而由帧边标记的行列对齐触发——标记同时扮演两个角色) ↔ [复制放置 + 标记交叉定位](来自 #1 247ef758，创新：不是在所有交叉点放置精灵，而是仅在射线经过的交叉点放置)——标记的双重角色使两个操作通过同一结构紧密耦合

**来源原语**：射线延伸(ray_extend)、转向(turn)、起点像素(start_pixel)、路径(path)、视线方向(line_of_sight) ← #3 e5790162；复制放置(replicate_stamp)、精灵体(sprite)、框架标记(frame_marker)、标记交叉定位(marker_intersection_positioning)、颜色匹配配对(color_match_pairing) ← #1 247ef758；擦除(erase) ← #1/#7

**依赖链**：帧边标记的位置同时定义了(a)射线的转向行/列和(b)候选印章坐标的行列网格。射线轨迹由标记的转向效应决定；印章仅放置在射线经过的交叉点。改变一个标记的位置同时改变射线路径和候选位置集合——这种双重角色使"路径选择"与"位置定义"不可分割。

一条射线在矩形帧内部行进，帧边标记既作为转向触发器控制射线方向，又作为坐标标记定义候选印章位置；仅在射线经过的标记交叉点处放置精灵。

**输入结构**：
- 黑(0)背景网格，约 16 行 x 16 列。
- 一个灰(5)空心矩形帧（1 像素宽边框），占据网格右侧约 12 列 x 10 行区域。
- 帧的上下边缘上有 2~3 个彩色标记像素（替换灰像素），标记颜色从蓝(1)、红(2)、绿(3)中选取；帧的左右边缘上也有 2~3 个彩色标记像素。
- 一个小精灵（3x3 区域，含 3~5 个非背景像素，背景为黑(0)）显示在网格左上角的 3x3 调色板区域内，与帧不重叠。
- 一个绿(3)起点像素位于帧内部，紧贴帧左内边缘（帧左边框右侧一格）。
- 生成约束：标记位置必须使绿色射线至少转向 2 次且经过至少 2 个标记交叉点；射线路径不能在第一次转向前就撞墙。

**规则**：
1. 从绿(3)起点像素开始，初始方向为向右。射线逐格移动，将每个背景(0)格涂为绿(3)：
   - 当射线进入某一行 r，且该行在帧的左边缘或右边缘上有一个彩色标记时，射线在当前格顺时针转 90 度（右转）。
   - 当射线进入某一列 c，且该列在帧的上边缘或下边缘上有一个彩色标记时，射线在当前格逆时针转 90 度（左转）。
   - 若同一格同时满足两个条件（既在标记行又在标记列），右转优先。
   - 当射线下一格为帧壁（灰色像素）、已有颜色的像素或越出帧时，停止。
2. 确定标记交叉点：帧内部位置 (r, c)，其中行 r 在帧的左/右边缘有标记，且列 c 在帧的上/下边缘有标记。
3. 在所有标记交叉点中，仅在绿色射线经过的格子及其曼哈顿距离 <= 1 的格子所涵盖的交叉点处放置精灵（精灵以该交叉点为中心放置，超出帧的部分裁去）。
4. 擦除绿色路径（涂回黑(0)）、擦除调色板精灵区域（涂回黑(0)）、擦除起点像素。输出帧及其标记、放置的精灵和黑色背景。

**关键洞察**：帧边标记扮演双重角色——它们既是定义候选放置位置的坐标网格节点，又是操纵选择射线的转向指令。移动一个标记同时改变了"哪些位置可以放精灵"和"射线会经过哪些位置"。这种结构性纠缠使路径规划和位置定义不可分离。

    sigs.add(hashlib.md5(inp.tobytes() + str(inp.shape).encode()).hexdigest())
print("variants", len(sigs))
