## 新题 4：同色标记对编码色层对称轴以执行逐色去噪

**组合逻辑**：[同色配对](来自 #10 1f876c06，创新：配对不用于画连线，而是计算中点列作为对称轴) → [逐色处理 + 对称补全/去噪](来自 #16 8e5c0c38，创新：对称轴不再通过最佳拟合推断，而由标记对的几何位置显式编码) → [擦除](来自 #1/#7)

**来源原语**：同色配对(same_color_pairing)、端点对(endpoint_pair) ← #10 1f876c06；对称补全(symmetry_completion)、色层(color_layer)、对称轴(symmetry_axis)、逐色处理(per_color_processing)、忽略干扰项(ignore_distractors) ← #16 8e5c0c38；擦除(erase) ← #1/#7

**依赖链**：标记像素对的中点列确定对称轴；对称轴决定每个色层的去噪结果。误判标记对为噪声则得到错误对称轴，输出完全错误。三个环节（标记识别 → 轴计算 → 镜像去噪）缺一不可。

每种颜色有一对孤立标记像素，其中点列即该颜色聚类的垂直对称轴；以此轴为基准移除每个色层中无镜像对应的噪声像素。

**输入结构**：
- 黑(0)背景网格，约 16 行 x 16 列。
- 3~4 种非背景颜色（如蓝(1)、红(2)、绿(3)、黄(4)），每种颜色形成一个空间上分离的像素聚类，每个聚类包含 8~15 个同色像素、呈 4-连通结构。
- 每个聚类近似关于某一垂直列对称，但有 1~3 个"噪声"像素打破对称（噪声像素只出现在对称轴的一侧，且该行对称位置为背景(0)）。
- 对每种颜色 C，另有恰好 2 个孤立的 C 色像素远离聚类（与聚类中任何像素的切比雪夫距离 >= 3），这两个孤立像素的列坐标中点 M = (col1 + col2) / 2 即为 C 色聚类的垂直对称轴。
- 生成约束：不同颜色的标记对中点必须互不相同；中点必须为整数或半整数（若为半整数则对称轴在两列之间）；聚类之间不重叠、不相邻。

**规则**：
1. 对每种非背景颜色 C，识别该颜色的所有像素，将它们分为"聚类像素"（属于 5 个及以上同色像素的 4-连通分量）和"标记像素"（属于 1~2 个像素的孤立组）。
2. 每种颜色恰有 2 个标记像素。计算它们的中点列 M = (col1 + col2) / 2，此即颜色 C 的垂直对称轴。
3. 对颜色 C 的每个聚类像素 (r, c)：计算镜像位置 (r, 2M - c)。若镜像位置在网格内且包含颜色 C 的像素，保留该像素。否则该像素为噪声，替换为黑(0)。
4. 擦除每种颜色的两个标记像素（替换为黑(0)）。
5. 输出去噪后的网格。

**关键洞察**：每种颜色的两个孤立像素看起来像噪声，实际上它们编码了该颜色聚类的对称轴。将它们误判为噪声（而非轴标记）会导致对称轴无法确定或被错误推断。标记对的空间位置——而非颜色本身——承载了关键信息。
