## 新题 4：箭头几何属性双重编码——方向与周期射线

**组合逻辑**：[横杆偏移定方向](已有) + [箭头杆长度作为周期步长](创新：杆长从静态形态属性重新解释为动态参数) → [射线延伸/ray_extend](已有，但从连续变为周期性) → [周期填充/periodic_fill](已有，但步长来自几何属性而非两个标记点的间距)

**来源原语**：箭头精灵/arrow_sprite、矩形边框/rectangular_frame、边框端点/frame_endpoint、朝向对齐/orientation_aligned、横杆偏移定方向/crossbar_determines（来自 689c358e）；射线延伸/ray_cast、周期步长/periodic_step、周期填充/periodic_fill、同余对齐/modular_alignment（来自 16de56c4）；计数/counting（来自 c3e719e8 / 9af7a82c）

**依赖链**：箭头精灵的横杆偏移决定方向（从 689c358e 继承），箭头杆的像素长度被重新解释为周期步长（全新结构关系），两者共同控制从边框端点向外发射的周期性射线。没有方向信息不知道射向哪，没有杆长信息不知道间隔多少像素打一个点。

从箭头精灵的横杆偏移读取方向、从杆长读取周期步长，在矩形边框外沿该方向每隔该步长打一个点。

**输入结构**：约 15x15 的黑(0)背景网格。
- 一个一像素宽的灰(5)矩形边框，约 7x7 至 9x9，位于网格中央偏置，保证边框到网格边缘在四个方向上均有至少 3 像素的空间。
- 边框内部为黑(0)背景，其中有 2~3 个单色 T 形箭头精灵（每个精灵由 6 个像素组成：一条长度为 3 或 4 的直线杆 + 一条长度为 3 的横杆，横杆在杆上偏向一端，偏向的那一端即为箭头指向的方向）。每个精灵颜色不同（从红(2)、蓝(1)、绿(3)、橙(7)、品红(6)中选取），精灵之间互不接触，且不接触边框。
- 边框外部全为黑(0)。
- 生成约束：每个箭头指向的方向上，从其杆的指向端出发沿该方向到达边框的路径上无其他精灵像素阻挡。不同箭头指向不同的边框边（不会有两个箭头射向同一段边框边）。

**规则**：
1. 对每个箭头精灵，通过横杆偏移确定指向方向（上/下/左/右）：横杆在杆上靠近哪一端，那一端就是箭头尖端方向（同 689c358e）。
2. 沿指向方向从箭头尖端出发，直线前进到边框，确定射中的边框像素位置 P。将 P 涂为该精灵的颜色（覆盖灰(5)）。
3. 计算该箭头杆的像素长度 k（杆是精灵中那条较长直线的像素数量，不含横杆独有像素）。
4. 从 P 出发沿同一方向向边框外部延伸。在距 P 为 k、2k、3k、... 的每个位置涂上该精灵的颜色，直到超出网格边界为止。中间位置保持黑(0)。
5. 同时，在边框上与 P 对边对称的位置（同行或同列的另一端边框像素）涂黑(0)（覆盖灰(5)）。
6. 不同精灵的射线互不交叉（由生成约束保证），边框上未被射中的像素保持灰(5)。

**关键洞察**：箭头精灵在源题 689c358e 中仅用于标记边框端点（方向信息），杆长从未被利用。这里杆长被赋予全新的语义——周期步长——使得同一个几何对象同时编码了方向和周期两个独立参数。求解者需要意识到"杆长 3 的箭头每隔 3 格打点，杆长 4 的箭头每隔 4 格打点"这一隐含规则，而非简单地画连续射线。

p = Path("/home/lixinyu/snap/a/key_combo/code/opus/4/030/4.py")
mod = SourceFileLoader("new_arc_task", str(p)).load_module()
sigs = set()
for i in range(100):
    inp = mod.generate_input()
    out = mod.main(inp)
    assert isinstance(inp, np.ndarray)
    assert isinstance(out, np.ndarray)
    assert inp.ndim == 2 and max(inp.shape) <= 30, f"input grid exceeds 30x30: {inp.shape}"
    assert out.ndim == 2 and max(out.shape) <= 30, f"output grid exceeds 30x30: {out.shape}"
    sigs.add(hashlib.md5(inp.tobytes() + str(inp.shape).encode()).hexdigest())
print("variants", len(sigs))
assert len(sigs) >= 20
