## 新题 6：均匀行检测生成隐式障碍，标记跨障碍对称交换

**组合逻辑**：[detection + row + uniform_row_marked_else_black](来自 25d8a9c8)（创新：源题中均匀行被标记为灰色输出，此处均匀行被识别为障碍而非直接标记） → [swap + erase + barrier_segment + cross_barrier_pair + one_each_side](来自 1efba499)

**来源原语**：detection / row / uniform_row_marked_else_black（25d8a9c8）；swap / erase / marker_pixel / barrier_segment / cross_barrier_pair / one_each_side（1efba499）

**依赖链**：均匀行检测确定障碍位置（输入中并无显式障碍标记）→ 标记像素的跨障碍配对依赖于已识别的障碍行 → 配对后执行位置交换。删除检测则障碍位置不可知；删除交换则标记不移动。

先检测哪些行是单色均匀行（这些行充当隐式障碍），然后将位于障碍两侧同列的标记像素对称交换到障碍另一侧的紧邻位置。

**输入结构**：一个约 12x10 的网格。网格由若干行组成，部分行内所有像素颜色相同（均匀行，颜色不限，可以是蓝(1)、红(2)、绿(3)等任意非黑色），其余行包含多种颜色的混合像素。在非均匀行中，散布着若干黑(0)标记像素（与多彩背景形成对比）。生成约束：标记像素成对出现——每一对在同一列上，分别位于同一条均匀行的上方和下方（即一个在均匀行上方的某非均匀行，另一个在均匀行下方的某非均匀行），且两者之间恰好只隔着一条均匀行（它们之间可以有其他非均匀行，但有且仅有一条均匀行）；不存在落单的标记。

**规则**：
1. 逐行检测：若某行所有像素颜色完全相同，则该行为"障碍行"。
2. 对每一列，扫描该列中的黑(0)标记像素。对于同一列中被恰好一条障碍行分隔的一对标记（一个在障碍行上方，一个在下方），执行交换操作。
3. 交换规则：擦除两个标记像素的原位置（恢复为该位置在输入中被标记替换前的颜色——由于标记为黑(0)而非均匀行的颜色，交换后原位置恢复为黑(0)以外的值需要另行处理）。修正：由于输入中标记像素就是黑(0)，而这些行是非均匀行（包含多种颜色），标记像素的"原始颜色"未知。因此规则改为：将上方标记移动到障碍行下方的紧邻行（障碍行行号+1）的同一列，将下方标记移动到障碍行上方的紧邻行（障碍行行号-1）的同一列。两个新位置都涂黑(0)。两个原始位置恢复为所在行中最常见的非黑颜色。
4. 障碍行本身保持不变。无配对的标记保持不变。

**关键洞察**：障碍不是由特殊颜色或符号标出的——求解者必须从行的均匀性推断出哪些行充当障碍，这一隐式检测规则在单个示例中可能有多种解释（例如特定颜色的行是障碍），只有对比多个示例（均匀行颜色各不相同）才能归纳出"均匀性"才是判据。
