## 新题 4：对称补全重塑障碍景观影响射线路径

**组合逻辑**：[对称补全/symmetry_completion](创新：补全结果不是最终输出，而是改变后续操作的障碍环境) + [射线延伸/ray_extend](创新：射线的终点由补全后的障碍决定，而非原始输入) + [障碍像素/obstacle_pixel](双重角色：原始障碍 + 补全产生的新障碍)

**来源原语**：对称补全(symmetry_completion)/镜像(mirror)/缺失区域(missing_patch) ← 参考题 9ecd008a/4c5c2cf0；射线延伸(ray_extend)/障碍像素(obstacle_pixel) ← 参考题 891232d6/13713586；绘制(drawing) ← 参考题 13f06aa5

**依赖链**：蓝像素模式含缺口 → 对称补全填充缺口（产生新蓝像素）→ 新蓝像素成为射线障碍 → 射线终点由补全后的完整障碍集决定。删除对称补全步骤，射线会穿过缺口到达不同高度；删除射线步骤则无法产生黄色输出。

先将一个有缺口的蓝色图案做左右镜像补全，然后从底部种子向上投射射线，射线遇到补全后的障碍即停止。

**输入结构**：约 12x14 的网格，宽度为偶数。黑(0)背景。蓝(1)像素在网格上半部分形成一个大致关于垂直中心线左右对称的图案（如散布的水平短线段、小方块等），但有 2~3 处缺口：某些位置左侧有蓝像素而右侧对称位置为黑(0)，或反之。红(2)像素形成 1~2 个孤立的单像素障碍，位于网格中部。绿(3)种子像素沿底部边缘放置（2~3 个，不在最底行的墙上而在倒数第二行），每个种子占一个像素。生成约束：至少有一个绿种子的正上方路径上存在因对称补全而新增的蓝像素（即该路径上有一个缺口位置会被补全填充），使得补全步骤对射线结果产生实质影响。

**规则**：
1. 对蓝(1)像素图案做左右镜像补全：以网格垂直中心线为对称轴（中心列索引 = (宽度-1)/2.0），对于每对对称列 (c, 宽度-1-c) 的每一行，若一侧为蓝而另一侧为黑，则将黑侧填充为蓝(1)。若两侧都已为蓝或都为黑，则不改变。红(2)像素不参与对称补全（不会被覆盖，也不作为对称源）。
2. 补全完成后，从每个绿(3)种子出发向上投射射线（逐行上移，列不变）。射线经过的每个黑(0)像素涂为黄(4)。
3. 射线遇到第一个非黑像素（蓝(1)——包括补全新增的、红(2)或网格顶部边界）时停止。终止像素本身不涂黄。
4. 绿种子保持绿(3)。所有蓝像素（原始+补全）保持蓝(1)。红像素保持红(2)。

**关键洞察**：射线的高度取决于补全后的障碍布局，而非原始输入。在原始输入中看到缺口处射线本应穿过，但补全后该缺口被填充，射线提前终止。需要多个示例才能发现"先补全后投射"的两步关系，而非"射线对原始输入投射"。
