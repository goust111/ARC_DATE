## 新题 2：重力沉降后反射对称分色

**组合逻辑**：[重力下落/gravity_drop](已有) + [反射对称/reflection_symmetry + 交集差集分别着色/intersection_diff_colored](创新：对称分析的对象从原始输入变为重力沉降后的构型)

**来源原语**：重力下落(gravity_drop)/碰撞停止(collision_stop)/近墙优先结算(nearest_first_settling) ← 参考题 6ad5bdfd；反射对称(reflection_symmetry)/交集差集分别着色(intersection_diff_colored)/重涂色(recolor) ← 参考题 a8610ef7；边墙(edge_wall) ← 参考题 6ad5bdfd

**依赖链**：边墙确定重力方向 → 重力沉降改变形状空间分布 → 沉降后构型决定反射对称分析结果 → 对称交集/差集分别着色。重力沉降是对称分析的前置条件，同一批形状在不同起始位置会产生不同的沉降构型，进而产生不同的对称着色结果。

将散落的小形状按重力堆积到边墙侧，然后对堆积后的形状掩码做左右镜像对称分析：对称交集像素涂一种颜色，差集像素涂另一种颜色。

**输入结构**：约 10x12 的网格。黑(0)背景。底部边缘为一整行红(2)边墙（固定不动）。红墙上方散布 3~5 个蓝(1)小形状，每个形状为 4-连通单色体，3~5 像素，形状各异（非全为矩形）。各形状互不接触，且不接触红墙。生成约束：所有形状的总宽度不超过网格宽度的 80%，保证沉降后不会溢出；网格宽度为偶数，以便定义明确的垂直中心线。

**规则**：
1. 红(2)底边墙固定不动。所有蓝(1)形状以刚体方式向下滑动（重力方向朝红墙）。
2. 沉降顺序：距红墙最近的形状先沉降。每个形状向下逐行移动，直到其任一像素的下一行位置会碰到红墙、网格底边或另一个已沉降的形状，则停止。
3. 沉降完成后，考察所有蓝像素的位置集合 S。定义垂直中心线为列索引 c = (网格宽度 - 1) / 2.0。对于 S 中的每个像素 (r, col)，计算其镜像位置 (r, 网格宽度 - 1 - col)。
4. 若像素 (r, col) 在 S 中，且其镜像 (r, 网格宽度 - 1 - col) 也在 S 中 → 将该像素重涂为绿(3)。
5. 若像素 (r, col) 在 S 中，但其镜像不在 S 中 → 将该像素重涂为橙(7)。
6. 红墙保持红(2)，背景保持黑(0)。

**关键洞察**：绿/橙着色取决于沉降后的构型而非原始位置。若跳过重力步骤直接对原始位置做对称分析，会得到完全不同的结果。需要对比多个示例才能确认"先沉降后分析"的顺序。
