## 新题 1：分区计数驱动同心生长深度

**组合逻辑**：[计数/counting](创新：计数对象从分隔条变为墙围区域) + [同心层填充/concentric_fill](创新：层数由全局区域计数而非固定模式决定) + [分隔墙/partition_wall](双重角色：既定义区域又约束生长边界)

**来源原语**：计数(counting) ← 参考题 1190e5a7/27a28665；同心层填充(concentric_fill)/生长(grow) ← 参考题 a3f84088/5c2c9af4；分隔墙(partition_wall) ← 参考题 62ab2642；种子像素(seed_pixel) ← 参考题 5c2c9af4

**依赖链**：分隔墙定义区域 → 区域计数产生全局参数 N → N 决定每个种子的同心层数 → 分隔墙同时约束同心层的空间生长范围。分隔墙在"定义区域"和"约束生长"中承担双重角色，使得全局结构和局部操作不可分离。

给定分隔墙围出的若干区域，每个区域含一个种子像素；以全部区域数量作为同心壳层数，从每个种子向外生长同心方框，壳层遇墙或边界截断。

**输入结构**：约 13x13 的网格。黑(0)背景。灰(5)一像素宽墙将网格分割为 3~5 个不规则矩形区域（墙为完整的横贯行或纵贯列，或 T 形/十字形交叉）。每个区域内恰好有一个种子像素，种子颜色互不相同，从红(2)、蓝(1)、绿(3)、黄(4)、品红(6)中选取。种子不紧贴墙壁（与最近墙壁至少间隔 1 个像素）。生成约束：每个区域至少 4x4 大小以容纳多层同心壳。

**规则**：
1. 识别灰(5)墙并确定它们分割出的所有区域，计算区域总数 N。
2. 从每个种子像素出发，以种子为中心，向外依次绘制同心方框壳层。种子自身为第 0 层（保留种子颜色），第 1 层为 Chebyshev 距离 1 的 8 个位置，第 2 层为距离 2 的 16 个位置，以此类推。共绘制 N 层壳层（第 0 层到第 N-1 层）。
3. 壳层颜色交替：偶数层（0, 2, 4...）使用种子颜色，奇数层（1, 3, 5...）使用橙(7)。
4. 若壳层中某像素落在灰(5)墙上或网格外，则该像素不绘制（墙保持灰色，网格外丢弃）。若落在另一个种子已绘制的壳层上，同样不绘制（先绘制的保留；绘制顺序为种子按其所在区域面积从小到大，面积相同则按种子行号从上到下、列号从左到右）。
5. 所有灰墙保持不变。

**关键洞察**：壳层数量是一个全局属性（区域总数），而非由种子本身的颜色或位置决定。仅看单个区域无法确定应画多少层——必须知道整张网格被分成了几块。同时，墙既是"计数的依据"又是"生长的边界"，移除任何一个角色都会改变输出。
