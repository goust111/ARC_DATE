## 新题 10：可见像素推断瓦片与内外分区选择性修复

**组合逻辑**：[tiling + infer_from_visible](已有：从可见像素推断最小重复瓦片) + [flood_fill + inside_outside_partition](创新：瓦片修复的范围不是全局的，而是由拓扑分区限定为封闭区域内部)

**来源原语**：tiling + repeating_tile + completion + infer_from_visible(ca8f78db)、occluded_region(ca8f78db)、flood_fill + inside_outside_partition(7491f3cf)、wall_boundary(7491f3cf)、mask_selects_source_panel(7491f3cf)

**依赖链**：可见像素推断出最小重复瓦片 -> flood_fill 区分封闭/开放区域 -> 仅封闭区域内的遮挡（黑色像素）被推断瓦片修复，开放区域的遮挡保持不变。去掉瓦片推断则无修复材料；去掉内外分区则无法确定修复范围。

从部分被黑色矩形遮挡的重复图案中推断最小瓦片，但只修复被灰色围栏封闭的区域内的遮挡，开放区域中的遮挡保持黑色。

**输入结构**：
- 约 12x12 的网格，本底为一个规则的二维重复色彩图案（周期约 3x3 或 4x4，使用红(2)、蓝(1)、黄(4)等 2~3 种颜色）。
- 若干矩形区域被黑(0)遮挡覆盖（原图案内容被替换为黑(0)）。
- 灰(5)像素构成一个或多个 4-连通闭合围栏，围栏穿越图案但不破坏图案的周期性（围栏位置不影响瓦片推断）。
- 部分遮挡矩形在围栏内部，部分在围栏外部。
- 生成约束：围栏外部的可见（非黑非灰）像素足以唯一确定最小重复瓦片；至少一个遮挡矩形完全位于围栏内部，至少一个完全位于围栏外部；灰(5)不出现在重复图案中。

**规则**：
1. 将灰(5)像素和黑(0)像素均视为"未知"，利用其余可见像素推断最小矩形重复瓦片 T（找到与所有可见像素一致的最小周期矩形）。
2. 从网格四条边缘向内 4-连通 flood fill（不穿越灰(5)像素），标记可达区域为"外部"，不可达区域为"内部"。
3. 对网格中每个黑(0)像素：
   - 若该像素位于"内部"区域：用推断瓦片 T 的对应位置颜色替换（即 T[r mod Tr][c mod Tc]，其中 Tr、Tc 为瓦片行列周期）。
   - 若该像素位于"外部"区域：保持黑(0)不变。
4. 灰(5)围栏像素保持不变。
5. 所有原本可见的非黑非灰像素保持不变。

**关键洞察**：同样的黑色遮挡在围栏内外有不同命运——围栏内部的遮挡被推断瓦片修复，外部的保持黑色。求解者必须同时理解瓦片推断规则和拓扑分区规则，两者交叉决定每个黑色像素的最终状态。单个示例可能让人误以为"所有遮挡都被修复"或"所有遮挡都保留"，需要对比不同拓扑位置的遮挡行为才能归纳出分区规则。
