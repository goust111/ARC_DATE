## 新题 1：角落指示镜像印章

**组合逻辑**：[mirror](创新：反射方式由帧内角落指示像素的空间位置动态编码，而非全局固定或由阵列坐标决定) x [stamp_overlay](已有：将变换后的精灵体印入空槽位) <-- [support_match](创新：支撑签名从"形状匹配"改为"角落位置编码反射类型")

**来源原语**：mirror/reflect(c48954c1, 8be77c9e, 9dfd6313)、stamp_overlay + shape_matching + support_match(e5062a87)

**依赖链**：每个空帧内部的角落指示像素位置决定了对精灵体施加哪种镜像反射 -> 反射结果决定了印入帧内的具体图案。去掉指示像素解读，反射类型不确定；去掉印章逻辑，反射结果无处放置。两者通过"角落位置 = 反射编码"这一结构关系紧密耦合。

从角落指示像素的位置推断反射类型，将精灵体的对应镜像印入每个空帧。

**输入结构**：
- 网格约 15x15，背景黑(0)。
- 左上角区域放置一个非对称精灵体（由红(2)像素组成的 4-连通单色图形，3~6 像素，关于水平轴和垂直轴均不对称，使四种反射产生四种不同图案）。精灵体的包围框为 RxC（R 行 C 列）。
- 网格其余位置散布 4~6 个矩形空帧，每个帧由灰(5)像素构成的 1 像素宽边框围成，内部大小恰好为 RxC（与精灵体包围框相同）。帧之间互不重叠，且不与精灵体重叠。
- 每个帧的内部恰好有一个蓝(1)像素，位于内部四角之一（左上、右上、左下、右下）。不同帧的蓝像素角落位置可能不同。
- 生成约束：精灵体在水平和垂直方向上都不对称（保证四种反射各不相同）。

**规则**：
1. 将精灵体包围框内的红(2)像素提取为印章掩码。
2. 对每个帧，识别其内部蓝(1)像素所在的角落位置：
   - 左上角 -> 对印章掩码不做变换（原始方向）。
   - 右上角 -> 水平翻转（左右列倒序）。
   - 左下角 -> 垂直翻转（上下行倒序）。
   - 右下角 -> 水平 + 垂直翻转（行列均倒序）。
3. 将变换后的印章掩码印入帧的内部区域，掩码的 (0,0) 对齐帧内部的左上角。掩码中红(2)位置覆盖帧内部对应单元（无论该单元原来是黑还是蓝）。掩码中非红位置不改变帧内部对应单元。
4. 各帧独立处理，处理顺序不影响结果。
5. 灰(5)帧边框和原始精灵体像素保持不变。

**关键洞察**：蓝色角落像素不是装饰——它编码了四种镜像中的哪一种应该填充该帧。精灵体的非对称性保证每种反射视觉上截然不同，需要对比多个示例中不同角落位置对应的不同印章方向才能归纳出编码规则。
