## 新题 3：对称补全后按内部标记多数色填充

**组合逻辑**：[mirror/symmetry_completion](来自 bf32578f，创新：补全建立几何边界而非直接产出) + [counting](来自 f8b3ba0a/54db823b，创新：计数范围由补全后的边界决定) + [fill](来自 bf32578f，创新：填充色由标记分布投票决定)

**来源原语**：mirror (bf32578f), counting (f8b3ba0a), fill (bf32578f), half_outline (bf32578f), marker_pixel (48d8fb45), symmetry (bf32578f), interior_marker_count (54db823b)

**依赖链**：半侧轮廓镜像补全 -> 定义闭合内部区域 -> 统计落入内部的各色标记数量 -> 多数色确定填充颜色。去掉补全则内部边界未知；去掉计数则填充色不确定；去掉填充则无输出变换。三者形成几何-统计-渲染的推理链。

将半侧轮廓镜像补全为完整闭合形状，统计落入闭合区域内部的各色标记像素，用数量最多的标记颜色填充内部。

**输入结构**：
- 黑(0)背景，约 14x14 网格。
- 一组绿(3)前景像素形成一个左半轮廓：沿垂直方向上下延伸，最右侧的前景像素紧贴形状的垂直中线。该轮廓呈不规则的半封闭形状（如半个花瓶轮廓，3-5 像素宽，8-12 像素高）。
- 散布在网格各处的 6-10 个单像素标记，分属 2-3 种颜色（如蓝(1)、红(2)、黄(4)），部分标记位于轮廓镜像补全后的内部区域，部分位于外部。
- 生成约束：补全后的内部区域中至少有 2 个标记；内部标记中恰好有一种颜色数量严格最多（无并列）。

**规则**：
1. 找到绿(3)半轮廓最右列的列号 c_max。镜像轴位于 c_max + 0.5 处（即 c_max 与 c_max+1 之间）。
2. 将每个绿(3)像素 (r, c) 关于镜像轴水平翻转，得到镜像像素 (r, 2*c_max + 1 - c)。若镜像位置无前景像素，则绘制绿(3)像素，形成完整的闭合轮廓。
3. 对于每一行，确定该行上最左和最右绿(3)像素的列号，二者之间（不含轮廓像素本身）即为该行的内部区间。所有行的内部区间的并集构成闭合内部区域。
4. 统计所有落在内部区域中的标记像素，按颜色分组计数。
5. 用数量最多的标记颜色填充整个内部区域。
6. 位于内部区域的标记像素保留（绘制在填充色之上）。位于外部的标记像素擦除（设为黑(0)）。轮廓像素（原始和镜像）保持绿(3)。

**关键洞察**：填充颜色并非轮廓本身的属性，而由标记像素与镜像边界的空间交互决定——移动一个标记跨过对称边界就可能改变整个区域的填充色。求解者必须先完成几何补全才能判定哪些标记"算数"。
