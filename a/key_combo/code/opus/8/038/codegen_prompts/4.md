## 新题 4：矩形内部提取为印章模板，标记计数定调色

**组合逻辑**：[内外分离·保留边框涂内部/interior_exterior_sep](创新：内部不是涂色目标而是模板提取源) + [印章覆盖/stamp_overlay](已有) + [计数·标记最多者选取/counting + rectangle_with_most_markers_selected](创新：计数选模板而非选裁剪对象)

**来源原语**：重涂色·前景矩形·矩形内部·内外分离·保留边框涂内部（参考题 50cb2852）、印章覆盖·同形精灵体·格点对齐（参考题 5b526a93）、计数·实心矩形·标记像素·包含·标记最多者选取（参考题 8efcae92）

**依赖链**：标记计数在多个矩形之间选出"模板源"→内部提取从该矩形获得印章模板→印章覆盖将模板复制到格点位置。计数结果决定提取哪个矩形的内部；提取内容决定印章图案；三者缺一不可。

多个有边框的矩形中，标记像素最多的矩形被选为模板源——提取其一像素内缩的内部图案，将该图案印章覆盖到网格中散布的精灵体位置上，替换原有精灵体。

**输入结构**：约 15x15 网格，黑(0)背景。网格中有 3-4 个实心矩形（每个至少 5x5），每个矩形由单一颜色的像素填充（颜色各不相同，例如蓝(1)、绿(3)、黄(4)、橙(7)），矩形之间不相邻。部分矩形的内部（去掉一像素宽边框后的区域）有若干红(2)标记像素替换了原色像素，形成不同的内部图案。各矩形内的红(2)标记数量不同（例如 1 个、3 个、2 个），且恰好有一个矩形的标记最多（无并列）。此外，网格中散布 2-4 个相同的小型青(8)精灵体（3-5 像素的 4-连通小图形，每个形状相同），它们的边界框尺寸与最多标记矩形的内部尺寸一致（即矩形宽-2 x 矩形高-2）。精灵体之间和与矩形之间互不相邻。生成约束：最多标记的矩形是唯一的；精灵体边界框尺寸与该矩形内部尺寸完全匹配；精灵体放置位置保证印章不超出网格边界。

**规则**：
1. 对每个矩形，计算其内部（去掉一像素宽度边框后的区域）中红(2)标记像素的数量。
2. 选择标记数量最多的矩形作为模板源矩形。
3. 提取模板源矩形的内部图案：将内部区域中的原色像素记为前景(用栗(9)表示)、红(2)标记像素记为红(2)、背景(若有)保持黑(0)。该内部图案即为印章模板。
4. 对网格中每个青(8)精灵体，将其边界框区域替换为印章模板——模板左上角对齐精灵体边界框左上角，逐像素覆盖。
5. 非模板源的矩形保持不变；模板源矩形本身也保持不变（仅提取内部图案，不修改）。

**关键洞察**：矩形的边框不是装饰——它是将矩形标识为"容器"的结构信号。标记像素在源题中用于选裁剪对象，在此处它们选择"哪个容器的内容值得复制"，将计数竞争与模板提取耦合成一个选拔机制。

Sort objects to top or bottom edge by whether their shape (up to rotation/flip) is shared.

Input structure:
- bg = most common color.
- Several multicolor connected components (8-connected) scattered across the grid.

Rule:

- Objects whose shape appears in two or more components → translate to TOP edge (row 0).
- Objects whose shape is unique → translate to BOTTOM edge (row H−h).

Key insight: The sorting criterion is shape frequency (rotation-invariant), not area — duplicated shapes go up, unique shapes go down.
