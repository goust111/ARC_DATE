## 新题 6：括号定靶标的可达性筛选聚集

**组合逻辑**：[按标记色选择同色/select_same_color_by_marker](创新：标记色不选擦除目标而是选聚集的目的地) + [可达性/reachability](已有) + [聚集·距离排序填充/gather + distance_ranked_fill](已有) + [计数/counting](创新：计数确定聚集容量)

**来源原语**：角括号·标记像素·标记在括号内部·按标记色选择同色（参考题 1e81d6f9）、聚集·墙壁障碍·可达性·距离排序填充·目标块（参考题 dd6b8c4b）、计数·实心矩形·标记像素·包含（参考题 8efcae92）

**依赖链**：括号标记色匹配到某个矩形→该矩形成为聚集目的地→墙壁限制可达性筛选候选栗色像素→矩形内部面积决定聚集容量→距离排序决定哪些候选像素被选中。五个环节形成决策链，删除任一环节则输出无法确定。

角括号内标记像素的颜色指向一个矩形作为聚集目的地，网格中散布的栗色像素通过墙壁限定的可达性筛选后，按距离排序向该矩形聚集，聚集数量由矩形内部可用面积决定。

**输入结构**：约 14x14 网格，橙(7)背景。网格中有 2-3 个不同颜色的实心矩形（每个至少 4x4，颜色例如蓝(1)、绿(3)、黄(4)），矩形内部全为该矩形颜色（无孔洞）。品红(6)墙壁像素组成若干不连续的墙段（每段 3-6 像素，水平或垂直），将网格划分为互有通道连接的区域，但部分区域之间的通道被完全封锁。栗(9)像素散布在各区域中（共 8-15 个），不在矩形内部也不在墙壁上。网格某角有一个红(2)角括号（3x3 直角形），括号内部有一个标记像素，颜色与某个矩形颜色相同。生成约束：至少有部分栗(9)像素与目标矩形不在同一可达区域（被墙壁隔断）；目标矩形的内部面积（去掉一像素边框）小于可达栗色像素总数，使容量限制生效。

**规则**：
1. 读取角括号内标记像素的颜色 C，找到颜色为 C 的矩形——该矩形即为聚集目的地。
2. 计算目的地矩形去掉一像素宽边框后的内部面积，记为 N（即可容纳的像素数）。
3. 从目的地矩形的任一边框像素出发，通过橙(7)背景像素和栗(9)像素（不穿越品红(6)墙壁和其他矩形像素）做 4-连通泛洪填充，标记所有可达的栗(9)像素为候选。
4. 计算每个候选栗(9)像素到目的地矩形中心的曼哈顿距离，按距离从小到大排序。距离相同时，行号小的优先；行号也相同时，列号小的优先。
5. 取排序后前 N 个候选像素（若候选总数不足 N，则取全部），将它们移动到目的地矩形内部，按行优先序（内部左上角开始，从左到右、从上到下）逐格放置，颜色保持栗(9)。
6. 被移动的栗(9)像素原位置替换为橙(7)背景。未被选中的候选像素和不可达的栗(9)像素保持原位不变。
7. 角括号、标记像素、墙壁和非目的地矩形保持不变。

**关键洞察**：括号在源题中选择"擦除什么"，在此处它选择"向哪里聚集"——同一个选色机制被重新诠释为目的地定位器。墙壁不仅限制聚集路径，还将部分候选像素彻底排除在外，使得空间布局和容量限制共同决定最终结果。
