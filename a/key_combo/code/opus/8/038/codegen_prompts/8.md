## 新题 8：选色镜像中的擦除与递增填补

**组合逻辑**：[镜像/mirror](已有) + [擦除/erase](创新：仅擦除镜像副本中的标记色，保留原件) + [堆叠·逐行递增/stack + row_by_row_increment](创新：递增填补不从单行开始，而是从擦除空洞的每列顶端开始)

**来源原语**：镜像（参考题 0e206a2e / 2dee498d / cad67732）、擦除·角括号·标记像素·按标记色选择同色·保留标记本身（参考题 1e81d6f9）、堆叠·色段·逐行递增·每行递增扩展（参考题 bbc9ae5d）

**依赖链**：镜像生成精灵体的副本→标记色指定擦除目标→擦除在副本中形成空洞→空洞的列形状决定递增填补的起止位置。镜像决定了副本的内容；选色决定了副本中哪些部分被擦除；擦除留下的空洞形状决定了填补生长的方向和范围——三者缺一不可。

将精灵体水平镜像生成副本，在副本中擦除与括号标记同色的像素形成空洞，然后从每个空洞列的顶端开始向下逐行递增地填入栗色像素。

**输入结构**：约 12x15 网格（宽大于高），黑(0)背景。网格左半部分有一个多色精灵体（占据 5-8 行、4-6 列的区域，由 2-3 种前景色组成，例如蓝(1)、绿(3)、黄(4)，精灵体形状不规则但 4-连通）。网格右半部分有足够的空间容纳精灵体的镜像副本。网格下方某处有一个红(2)角括号（3x3 直角形），括号内有一个标记像素，颜色与精灵体中某种颜色相同。生成约束：标记颜色在精灵体中的像素不全在同一行（即擦除后空洞分布在多行，使递增填补产生视觉效果）；精灵体镜像后与原件不重叠；精灵体中每种颜色至少有 3 个像素。

**规则**：
1. 将左半部分的精灵体水平镜像到右半部分：以精灵体边界框右边缘+2 列为镜像后边界框左边缘，逐像素水平翻转复制。
2. 读取角括号内标记像素颜色 C。
3. 在镜像副本中，将所有颜色为 C 的像素替换为黑(0)背景，形成空洞。原件中的颜色 C 像素保持不变。
4. 对镜像副本中每一列，从上到下扫描，找到该列中所有空洞像素（因步骤 3 被擦除的位置）。对该列中最顶端的空洞位置开始，向下逐格填入栗(9)像素，直到遇到非背景像素或该列空洞的最底端位置（取两者中较早到达的）。
5. 若某列有多段不连续的空洞（中间被非空洞像素隔开），每段独立处理：从每段顶端开始向下填入栗(9)直到段末。
6. 原件精灵体、角括号、标记像素保持不变。

**关键洞察**：擦除不是清理——它是雕刻。角括号选色后在镜像中挖出的空洞轮廓，决定了递增填补的生长区域。同一个精灵体换一种标记颜色，空洞形状完全不同，填补结果也截然不同。
