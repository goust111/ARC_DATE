## 新题 5：收缩楔形穿越障碍间隙的分支传播

**组合逻辑**：[填充·沿对角线传播/diagonal_propagate](创新：传播遇障碍不终止而是从间隙穿越并分裂) + [碰撞停止/collision_stop](创新：从完全阻断变为间隙过滤) + [逐行交换双色/row_swap_bicolor](已有，色带交替在分支间延续)

**来源原语**：填充·顶行色带·收缩楔形·沿对角线传播·逐行交换双色（参考题 b5bb5719）、重力下落·障碍物·碰撞停止（参考题 28a6681f）

**依赖链**：顶行色带启动楔形传播→障碍行的间隙位置决定楔形分裂方式→每个子楔形的宽度由间隙宽度决定→子楔形继续独立收缩并可能遇到下一行障碍再次分裂。障碍不消灭传播，而是过滤和分叉传播——这是源题中不存在的结构关系。

顶行色带向下传播为收缩楔形，遇到水平障碍条时不终止而是从障碍中的间隙穿过，在间隙下方生成更窄的子楔形，每个子楔形独立继续收缩，色带的红灰交替计数跨分支连续。

**输入结构**：约 15x15 网格，橙(7)背景。第 0 行有一段连续的交替红(2)/灰(5)像素（长度为奇数，5-11 像素），左右两端对称地位于行中央。第 0 行其余位置为橙(7)背景。在网格下方有 1-2 条水平障碍条（品红(6)像素组成的完整行，但每条障碍行中有 1-2 个间隙——即该行中有 1-2 段连续的橙(7)背景像素）。障碍条之间以及障碍条与顶行之间至少间隔 3 行。生成约束：每个间隙宽度至少 3 像素且为奇数；间隙水平范围完全在楔形到达该行时的有效宽度范围内；每个子楔形在到达下一障碍或网格底部前至少能收缩 2 行。

**规则**：
1. 初始楔形从第 0 行的红(2)/灰(5)色带开始。定义楔形的有效列范围为 [L, R]（色带首尾列），初始行计数器 r=0。
2. 对下方每一行 r+1：楔形有效列范围收缩为 [L+1, R-1]。在有效列范围内，每个像素取第 0 行中沿对角线上溯 r+1 步对应的颜色（即列 c 的颜色取第 0 行列 c-(r+1) 的颜色），然后每增加一行翻转一次红(2)<->灰(5)。
3. 若行 r+1 是障碍行：不在该行填充楔形像素。取该障碍行中与当前有效列范围重叠的每个间隙段 [G_L, G_R]，在障碍行下方一行为每个间隙段启动一个独立子楔形，初始有效列范围为 [G_L, G_R]。子楔形继承父楔形的行计数器（用于颜色交替），从父楔形中断处继续计数。
4. 每个子楔形按步骤 2-3 独立向下传播，可能遇到更下方的障碍行再次分裂。
5. 楔形或子楔形在有效列范围收缩至宽度 < 1 时自然终止，或在到达网格最底行时终止。
6. 障碍行的品红(6)像素保持不变。

**关键洞察**：障碍条不是楔形的终点——它是分束器。一个收缩楔形穿过障碍后变成多个独立的窄楔形，如同光束被狭缝衍射。颜色交替的行计数器跨越分裂保持连续，所以分支的色相取决于分裂发生在第几行。
