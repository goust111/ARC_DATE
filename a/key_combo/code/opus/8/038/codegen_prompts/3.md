## 新题 3：括号选色触发重力级联

**组合逻辑**：[擦除/erase](创新：擦除不是最终目标而是级联触发器) + [重力下落/gravity_drop](已有) + [碰撞停止/collision_stop](已有)

**来源原语**：擦除·角括号·标记像素·按标记色选择同色·保留标记本身（参考题 1e81d6f9）、重力下落·障碍物·碰撞停止·沿路径滑动（参考题 28a6681f）

**依赖链**：角括号内的标记色决定擦除目标→擦除移除了支撑结构→失去支撑的其他颜色像素在重力下落→障碍物决定最终停靠位置。擦除的对象选择与物理级联紧密耦合：擦除不同的颜色会产生完全不同的下落结果。

角括号内的标记像素指定一种颜色，该颜色的所有非标记像素被擦除；擦除导致原先被该颜色支撑的其他颜色像素失去支撑并在重力作用下坠落，直到碰到障碍物或网格底部。

**输入结构**：约 12x12 网格，黑(0)背景。网格中有若干像素簇，每簇由 3-6 个同色 4-连通像素组成，使用 2-3 种不同颜色（例如蓝(1)、绿(3)、黄(4)）。部分像素簇在垂直方向上相互堆叠（一个簇的像素直接在另一个簇的像素上方，形成支撑关系）。网格中有 2-4 个灰(5)像素作为固定障碍物（不受重力影响），分布在不同高度。网格右下角区域有一个由红(2)像素组成的 4-连通角括号（开口朝左上的直角形，宽高各 3 像素），括号内部（括号边界框内、非括号像素的位置）恰好有一个标记像素，其颜色与网格中某种像素簇颜色相同。生成约束：标记颜色的像素簇至少支撑着一个其他颜色的像素簇（即标记色像素的正上方有非标记色像素）；不同示例中标记颜色不同；擦除后下落的像素不会与角括号或障碍物的水平位置冲突。

**规则**：
1. 识别角括号（红(2)像素组成的直角形连通体）并定位其边界框内唯一的非括号、非背景标记像素，读取标记颜色 C。
2. 将网格中所有颜色为 C 的像素（标记像素本身除外）替换为黑(0)背景。
3. 擦除后，检查每个非背景、非障碍、非括号像素：若其正下方为背景且自身不在网格最底行，则该像素"悬空"。
4. 所有悬空像素同时开始下落：每个像素沿垂直方向逐格下移，直到正下方遇到非背景像素（另一个已稳定的像素、障碍物、括号像素）或到达网格底行时停止。处理顺序为从最底行的悬空像素开始向上逐行处理，确保下方像素先稳定。
5. 角括号、标记像素和灰(5)障碍物始终保持原位不变。

**关键洞察**：角括号不是在做颜色清理——它在选择性拆除支撑结构。被擦除的颜色本身不重要，重要的是它的移除如何改变其他颜色的物理平衡，触发一场由选色决定结果的重力级联。
