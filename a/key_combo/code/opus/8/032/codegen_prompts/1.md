## 新题 1：奇偶门控方位印章

**组合逻辑**：[印章覆盖](方向从固定十字改为奇偶分支的条形) → [方位决定颜色](保留方向-颜色映射但作用于选定轴) ← [行列奇偶](创新：从矩形内部填充改为控制印章朝向)

**来源原语**：印章覆盖stamp_overlay(#19 d364b489)、方位决定颜色direction_color(#19 d364b489)、行列奇偶决定填充parity_fill(#2 ba9d41b8)

**依赖链**：标记像素的网格坐标奇偶性决定印章是水平条还是垂直条（条件门控），条的两端颜色再由相对标记的方位决定（方位-颜色映射）。奇偶判断和方位着色缺一不可：没有奇偶就无法确定条的朝向，没有方位映射就无法确定端点颜色。

将每个蓝色标记根据其坐标奇偶性展开为水平或垂直三像素条，端点颜色由其相对于标记的方位决定。

**输入结构**：约 11x11 的黑(0)背景网格。网格上散布 4~6 个蓝(1)孤立像素作为标记。任意两个标记之间的切比雪夫距离至少为 3（确保印章互不重叠）。输入中不含橙(7)、品红(6)、红(2)、青(8)像素。生成约束：所有标记均不在网格最外一圈边缘行/列上（确保两端均在网格内）。

**规则**：
1. 对每个蓝(1)标记像素，设其位置为 (r, c)。计算 (r + c) mod 2。
2. 若结果为 0（偶数奇偶）：生成水平三像素条——在 (r, c-1) 涂橙(7)，(r, c) 保持蓝(1)，(r, c+1) 涂品红(6)。
3. 若结果为 1（奇数奇偶）：生成垂直三像素条——在 (r-1, c) 涂红(2)，(r, c) 保持蓝(1)，(r+1, c) 涂青(8)。
4. 其余黑(0)背景不变。
5. 冲突处理：由生成约束保证印章不重叠，无需额外冲突规则。

**关键洞察**：标记的网格坐标奇偶性是一个隐藏的二元开关，选择水平还是垂直印章；单看一个示例无法判断开关来源（可能是行号、列号、行列之和等），需要对比多个示例中标记位置与印章朝向的对应关系才能归纳出 (r+c) mod 2 规则。
