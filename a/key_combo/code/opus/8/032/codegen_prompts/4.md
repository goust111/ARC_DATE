## 新题 4：标记象限编码全局旋转

**组合逻辑**：[裁剪(象限)](从十字分隔网格中提取四个精灵体) → [旋转](创新：旋转角度不由两个标记的角落关系指定，而由单个标记所在象限编码) → [拼接](重新组装为紧凑蒙太奇)

**来源原语**：裁剪crop(#1 0bb8deee)、十字分隔线cross_divider(#1 0bb8deee)、象限quadrant(#1 0bb8deee)、象限位置对应quadrant_correspondence(#1 0bb8deee)、旋转rotate(#7 ecaa0ec1)、标记像素marker_pixel(#7 ecaa0ec1)

**依赖链**：十字分隔定义四个象限，每个象限内有一个精灵体（裁剪提取）。某个象限中额外的单像素标记编码了一个全局旋转角度（象限位置→角度映射），该角度统一施加于所有四个精灵体。去掉十字分隔无法定义象限；去掉标记无法确定旋转角；去掉旋转则输出与源题#1 的蒙太奇相同。

从十字分隔的四象限中裁剪精灵体，由标记所在象限编码的角度统一旋转后重新拼成蒙太奇。

**输入结构**：约 11x11（奇数行列）的网格。灰(5)像素组成一条完整横行和一条完整纵列（十字分隔线），将网格分为四个大小相等的象限（每象限约 5x5）。每个象限内有一个单色精灵体（4-连通，3~5 像素，边界框 3x3），四个精灵体形状完全相同但颜色各异（如蓝(1)、红(2)、绿(3)、黄(4)）。背景为黑(0)。恰好一个象限内额外有一个品红(6)单像素标记，位于该象限的某个角落单元格（即象限内距离网格角最近的那个单元格），且不与精灵体重叠。生成约束：四个精灵体的形状关于其各自象限中心放置时非旋转对称（即 90 度旋转后形状可区分）。

**规则**：
1. 移除灰(5)十字分隔线。
2. 将每个象限中的精灵体裁剪至其 3x3 紧凑边界框。
3. 找到品红(6)标记所在的象限，根据象限位置确定旋转角度：
   - 左上象限 → 0 度（不旋转）
   - 右上象限 → 顺时针 90 度
   - 右下象限 → 180 度
   - 左下象限 → 顺时针 270 度
4. 将四个裁剪后的精灵体各自绕其 3x3 边界框中心旋转上述角度。
5. 将旋转后的四个 3x3 块按象限顺序（左上、右上、左下、右下）拼成 6x6 的 2x2 蒙太奇。品红标记不出现在输出中。

**关键洞察**：品红标记像素的象限位置是对旋转角度的隐式编码。标记不直接参与几何变换，也不指示源/目标角落（与源题 #7 不同）——它的位置本身就是一个查找键。需要至少两个示例（标记在不同象限）才能确认象限-角度映射规则。
