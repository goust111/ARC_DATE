## 新题 3：周期修复揭示隐藏裁剪标记

**组合逻辑**：[补全](利用平移对称修复遮挡) → [异常值选择](修复后识别非周期的异常色) → [裁剪 + 标记对齐指定半区](以异常色像素为标记裁剪半区) → [擦除](清除标记)

**来源原语**：补全(inpaint, #18 0dfd9992), 平移对称(translational_symmetry, #18), 轨道可见色填缺失(orbit_color_restores_missing, #18), 裁剪(crop, #15 fbf15a0b), 标记对齐指定半区(marker_selects_half, #15), 擦除(erase, #15), 异常值选择(outlier_selection, #2 ad3b40cf)

**依赖链**：补全操作恢复被遮挡的像素，其中部分恢复出的像素呈现周期模式中不存在的异常颜色——这些是隐藏的裁剪标记。标记在补全前不可见（被黑色遮挡），补全后才暴露位置信息供裁剪使用。删除补全步骤则标记位置未知，删除裁剪步骤则补全无目的。

修复周期图案的黑色遮挡后，恢复出的像素中出现两个异常颜色像素（不属于周期色板），以它们为标记裁剪出所在半区并擦除标记。

**输入结构**：网格约 10x14 至 14x18。整体为一个具有平移周期性的彩色图案（使用 3~4 种颜色，如蓝(1)、绿(3)、黄(4)、橙(7)），周期为 3x3 至 5x5。图案中有 6~12 个格子被黑(0)遮挡。在这些被遮挡的位置中，恰好有 2 个格子的"真实值"不是周期图案的颜色，而是红(2)——一种在周期图案中完全不出现的颜色。这两个红(2)像素在同一行或同一列上，且都位于网格沿该方向的同一半区内。其余被遮挡位置的真实值均可由周期轨道唯一确定。

**规则**：
1. 检测输入中非黑(0)像素的平移对称性，确定最小平移向量。
2. 对每个黑(0)格子，收集其平移轨道上所有非黑色的可见值。
3. 若轨道上的可见值颜色唯一，用该颜色填充。若轨道上出现的颜色不在周期图案的色板中（即红(2)），同样填入该颜色。
4. 修复完成后，找到恰好 2 个红(2)像素。
5. 若两个红(2)像素共享同一行，检测它们在水平方向上位于左半区还是右半区，裁剪出该半区。若共享同一列，检测上下半区并裁剪。半区边界为网格中线（列数或行数的一半，向下取整）。
6. 在裁剪出的半区中，将两个红(2)像素恢复为黑(0)（擦除标记）。
7. 输出为裁剪后的半区网格。

**关键洞察**：标记在输入中被遮挡为黑色，与普通缺失像素完全无法区分——只有完成周期修复后，红(2)才会作为异常色浮现，而这个异常色恰恰是裁剪指令。需要对比多个示例才能发现红色不是周期图案的一部分而是功能性标记。
