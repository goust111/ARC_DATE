## 新题 1：射线交织差异图

**组合逻辑**：[射线延伸](每个标记向两个最近边界投射同色射线) → [逐像素比较](两色射线网格逐格比较) → [差异分类着色](创新：交叉点产生第三色)

**来源原语**：射线延伸(ray_extend, #20 705a3229), 逐像素比较(pixel_comparison, #1 d47aa2ff), 差异分类着色(diff_class_color, #1 d47aa2ff), 最近边界方向(nearest_boundary_direction, #20 705a3229)

**依赖链**：射线延伸为两组标记分别生成射线网格，网格的形状由标记位置和边界距离决定；逐像素比较以这两个动态生成的网格为输入（而非静态面板），在交叉处应用差异着色。射线延伸的输出完全决定了比较的空间范围和形状，删除任一步均无法求解。

将两种颜色的标记像素各自向最近边界投射射线，对两组射线网格逐格比较，仅一色占据保留原色，双色交叉的位置涂为第三色。

**输入结构**：黑(0)背景网格，约 12x12 至 16x16。网格中散布两种颜色的孤立像素：红(2)像素 2~4 个，蓝(1)像素 2~4 个。所有孤立像素互不在同一行或同一列上。每个像素到最近水平边界和最近垂直边界的距离均无平局（即不在行或列的正中央）。红像素与蓝像素之间的射线路径保证存在至少 2 处交叉。

**规则**：
1. 对每个红(2)像素，沿其所在列向最近的水平边界（顶/底）延伸一条红(2)射线，同时沿其所在行向最近的垂直边界（左/右）延伸一条红(2)射线，形成一个 L 形。像素本身保留。
2. 对每个蓝(1)像素做相同操作，生成蓝(1)射线。
3. 逐格比较两组射线占据的区域：
   - 仅红射线占据的格子保持红(2)。
   - 仅蓝射线占据的格子保持蓝(1)。
   - 红射线与蓝射线同时占据的格子涂为绿(3)。
4. 原始标记像素保持其原色不变（即使处于交叉位置，标记像素也保持原色）。
5. 所有其他格子保持黑(0)。
6. 处理顺序：先生成所有射线，再统一做逐格比较，不存在先后覆盖问题。

**关键洞察**：被比较的不是预设面板而是动态生成的射线网格——交叉格的颜色（绿(3)）需要对比多个示例才能确认不是来自某种位置规则，而是来自"双色共占"这一比较逻辑。
