## 新题 8：杯体标记高度驱动的互补填充与溢出射线

**组合逻辑**：[填充(fill)](创新：从完整填充改为标记高度控制的部分填充) + [射线延伸(ray_extend)](创新：从孤立像素出发改为从杯沿出发、长度由未填充高度决定) + [追加封盖层(cap_layer_added)](已有) — 守恒律耦合结构

**来源原语**：填充/杯状轮廓/标记像素/内部包含/标记色决定填充/追加封盖层 ← 444801d8；射线延伸/孤立像素/对角方向/画布边界 ← 623ea044；数量守恒 ← 9aaea919

**依赖链**：标记像素在杯内的垂直位置同时编码两个互补参数——填充高度和射线长度，二者之和恒等于杯内部高度（守恒律）。标记越深 → 填充越多、射线越短；标记越浅 → 填充越少、射线越长。填充和射线通过守恒约束形成此消彼长的紧耦合。

在每个杯状容器中，标记像素的高度位置决定从底部填充到该高度，未填充的剩余高度则转化为从杯沿向外发射的对角射线长度。

**输入结构**：约 16x16 的黑(0)背景网格。散布 2-3 个蓝(1)杯状轮廓——每个杯由蓝(1)像素组成 U 形（底边水平、两侧壁垂直、顶部开口），内部为黑(0)。每个杯的内部宽度为 3-5 列，内部高度为 4-7 行。每个杯内部恰好有一个标记像素，颜色各不相同（从红(2)、绿(3)、黄(4)、橙(7)中选取），标记像素位于杯内部的某一行（不在最底行也不在最顶行，保证填充和射线均非零）。各杯互不重叠，杯沿上方至少有 5 行空间供射线延伸。生成约束：不同杯的标记像素行位置不同（确保射线长度不同）。

**规则**：
1. 对每个蓝(1)杯，找到内部唯一的标记像素，记录其颜色 C 和其在杯内部的行位置（从杯底部内壁起计为第 0 行）。
2. 用颜色 C 填充杯内部从底部（第 0 行）到标记所在行（含标记行）的所有像素。标记像素本身被填充色覆盖。
3. 计算未填充高度 E = 杯内部总高度 - 已填充高度（即标记行上方的空行数）。
4. 从杯左侧壁顶端外侧一格的位置出发，沿左上方对角方向延伸 E 个像素，颜色为 C。从杯右侧壁顶端外侧一格的位置出发，沿右上方对角方向延伸 E 个像素，颜色为 C。射线若遇到非黑(0)像素或到达网格边界则提前停止。
5. 在杯顶部开口正上方一行、跨越杯的外部宽度（含两侧壁），绘制一条颜色为 C 的水平封盖层。
6. 蓝(1)杯轮廓保持不变。

**关键洞察**：每个杯内存在一个守恒量——填充高度 + 射线长度 = 杯内部高度。标记像素越靠近杯底，填充区域越大但溢出射线越长；越靠近杯顶则相反。求解者必须发现这一互补关系才能预测射线长度。单个示例中可能误以为射线长度是固定的或由杯宽度决定，需要对比多个杯（不同标记高度产生不同填充/射线比例但总和恒定）才能归纳守恒律。
