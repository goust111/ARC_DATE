## 新题 7：对角折叠后邻接驱动的角色轮换

**组合逻辑**：[折叠(folding)](创新：从单个 X 到 3x3 改为批量处理并改变空间邻接关系) + [旋转(rotation)](创新：从固定一步顺时针改为邻接计数驱动的可变步数轮换) + [计数(counting)](创新：从面积计算改为邻接关系计数) — 空间反馈结构

**来源原语**：折叠/压缩/对角线像素/对角到边映射 ← ca8de6ea；旋转/顺时针轮换/对角角点/对角邻接 ← 85fa5666；计数 ← a3325580, 5289ad53

**依赖链**：折叠将 5x5 X 压缩为 3x3 块并改变块间距 → 块的新位置决定邻接关系 → 邻接计数决定旋转步数 → 旋转改变 3x3 块的角色像素颜色。关键反馈：折叠前相距甚远的 X 可能折叠后变为相邻（因 5x5 缩小为 3x3），这一空间变化是旋转步数的决定因素。

将多个 5x5 X 形图案分别折叠为 3x3 块，再根据折叠后各块之间的邻接数量，对每个块的四个角像素进行对应步数的顺时针轮换。

**输入结构**：约 15x15 的黑(0)背景网格。散布 2-4 个不重叠的 5x5 X 形图案——每个 X 占据一个 5x5 区域，其两条对角线上的 9 个像素被着色（各像素颜色可能不同，使用蓝(1)、红(2)、绿(3)、黄(4)、橙(7)等），其余 16 个像素为黑(0)。不同 X 的 5x5 包围框之间至少间隔 1 格。生成约束：折叠后的 3x3 块放置于各 X 中心位置时，至少有一对块正交相邻（共享一条边）。

**规则**：
1. 对每个 5x5 X，按以下映射折叠为 3x3 块（行列从 0 起计）：
   - (0,0) → (0,0)，(1,1) → (0,1)，(0,4) → (0,2)：西北臂 → 顶边
   - (2,2) → (1,1)：中心不变
   - (3,1) → (1,0)，(1,3) → (1,2)：西南臂首像素 → 左边中，东北臂首像素 → 右边中
   - (4,0) → (2,0)，(3,3) → (2,1)，(4,4) → (2,2)：西南角 → 左下，东南臂 → 底边中，东南角 → 右下
2. 在新画布上，将每个 3x3 块放置于其原始 5x5 X 中心像素所在的位置（3x3 块的中心对齐原中心）。画布尺寸与输入相同，背景为黑(0)。
3. 对每个 3x3 块，计算与之正交相邻（上下左右共享边）的其他 3x3 块的数量，记为 N。
4. 对该 3x3 块的四个角像素执行 N 步顺时针轮换：每一步将 (0,0)→(0,2)、(0,2)→(2,2)、(2,2)→(2,0)、(2,0)→(0,0) 的颜色顺移。N=0 则不动，N=1 轮换一次，N=2 轮换两次（等价于对角互换），以此类推。边中和中心像素不参与轮换。
5. 输出画布。

**关键洞察**：折叠不仅是形态压缩，更改变了对象间的拓扑关系——原本相距甚远的 X 折叠后可能变为紧邻块，从而获得更多邻接计数、更多轮换步数。求解者必须先完成折叠才能判断邻接关系，而邻接关系又决定了颜色变换的程度。单个示例中旋转步数可能碰巧为 1，需多个示例确认"步数=邻接数"。
