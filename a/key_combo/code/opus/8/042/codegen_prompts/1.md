## 新题 1：邻接过滤后按尺寸排名重涂色

**组合逻辑**：[擦除](已有) + [邻接不足则删除](已有) → [计数](已有) + [尺寸分类](已有) → [排序](已有) + [重涂色](已有, 创新：排名对象变为过滤后残余分量而非原始对象)

**来源原语**：擦除/erase(7f4411dc), 邻接/adjacency(7f4411dc), 邻接不足则删除/delete_unsupported(7f4411dc), 计数/counting(08ed6ac7), 排序/sorting(08ed6ac7), 重涂色/recolor(08ed6ac7), 高度排名映射颜色/height_rank_to_color(08ed6ac7, 创新改造为尺寸排名映射颜色), 连通分量/connected_component(08ed6ac7)

**依赖链**：邻接过滤改变了分量的边界和数量（噪声移除可能将一个大分量拆分为多个小分量），过滤后的分量集合决定了尺寸排名，尺寸排名决定了每个分量的最终颜色。删除过滤环节→排名对象错误；删除排名环节→无法确定颜色映射。

将同色前景中的噪声像素按邻接支撑过滤掉，再将存活分量按像素数从大到小排列并依排名重涂色。

**输入结构**：黑(0)背景，约 15x15 网格。网格中有若干红(2)前景像素，它们形成 4-连通的分量。分量有两类：主体分量为紧密连通的区域（每个 5~15 像素，形态不规则，可以有分支或弯折，但每个像素至少有 2 个同色 4-邻居）；噪声像素为散落的红(2)孤立点或仅有 1 个同色 4-邻居的弱连接尾部像素（1~3 像素的小碎片）。不同示例中，主体分量数量为 3~5 个，噪声分布位置不固定。生成约束：所有红(2)像素来自同一颜色，噪声像素在过滤后不会与任何主体分量相连，且至少有一个噪声像素在过滤前将两个本应独立的主体分量桥接为一个大分量（以此制造过滤前后分量计数的变化）。各主体分量的过滤后像素数互不相等。

**规则**：
1. 遍历每个红(2)像素，计算其红(2)色 4-邻居数量。将邻居数小于 2 的像素设为黑(0)（擦除噪声）。
2. 在过滤后的网格上，以 4-连通检测所有剩余红(2)分量。
3. 按每个分量的像素数从大到小排序。像素数最多的分量排名 1，次多排名 2，依此类推。
4. 按排名重涂色：排名 1 → 蓝(1)，排名 2 → 绿(3)，排名 3 → 黄(4)，排名 4 → 橙(7)，排名 5 → 品红(6)。若分量数不足 5 个，仅使用前若干种颜色。
5. 所有被擦除的噪声像素保持黑(0)不变。

**关键洞察**：噪声像素可能在过滤前充当两个主体分量之间的桥梁，使它们在输入中表现为一个大分量；过滤后桥梁消失，一个大分量被拆分为两个小分量，排名因此完全改变。求解者必须先推断过滤规则，才能正确识别分量边界和尺寸排名。

```yaml
    From each endpoint of each outer segment, cast a diagonal ray in the outward direction
    (perpendicular to segment, away from diamond). Paint over bg cells with segment color
    until hitting grid edge. Each segment emits exactly 2 rays.
  ray_length: 0-19 pixels per endpoint; all rays reach grid boundary [observed]

generation_strategy:
  approach: output-first
  steps:
    1. Choose grid dimensions within range. Fill with checkerboard (top-left=1).
    2. Pick 1-3 diamond count and assign distinct non-bg colors (from 2-9).
    3. For each diamond, choose 2-4 edges (TR/TL/BL/BR) to receive outer segments.
    4. Assign a segment color per edge (non-bg, differs from diamond color).
    5. Build output-first -- place each diamond, then for each segment edge, compute the
       full ray pair (from both endpoints outward to grid edge) and paint them.
       Verify no ray collides with existing non-bg pixels; reject or retry placement if so.
    6. Derive input by removing all ray pixels (restoring bg checkerboard values at those cells),
       keeping only diamonds and outer segments.
```
</generation_spec>
</reference_puzzle>
