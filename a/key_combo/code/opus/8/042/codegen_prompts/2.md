## 新题 2：异常精灵体像素播种周期生长

**组合逻辑**：[裁剪](已有) + [图案匹配](已有) → [异常值选择](已有) → [擦除](已有) + [种子周期生长](创新：种子不再是单色孤立像素，而是精灵体内的多色像素阵列)

**来源原语**：裁剪/cropping(cd3c21df), 图案匹配/pattern_match(cd3c21df), 异常值选择/outlier_selection(cd3c21df), 精灵体/sprite(cd3c21df), 擦除/erase(多源), 种子周期生长/seed_periodic_growth(3ac3eb23), 对角偏移/diagonal_offset(3ac3eb23), 孤立像素/isolated_pixel(3ac3eb23, 创新改造为精灵体内的各像素)

**依赖链**：图案匹配确定哪些精灵体重复、哪个唯一；异常值选择保留唯一精灵体并擦除其余；被保留精灵体的每个非背景像素成为一颗种子，其坐标决定生长起点，其颜色决定轨迹颜色。删除图案匹配→无法找到异常精灵体；删除周期生长→输出仅为一个裁剪后的精灵体，退化为单逻辑。

在多个外形相同的精灵体中找到唯一不同的异常体，将其每个像素作为种子向下做周期-2 对角生长，不同颜色的种子产生交错的彩色轨迹。

**输入结构**：黑(0)背景，约 20x20 网格。网格上半区散布 5~7 个互不接触的小精灵体，每个精灵体为一个多色 4-连通区域（边界框约 3x3 至 4x4，使用 2~3 种非背景色，如蓝(1)、红(2)、绿(3)），精灵体形态由结构属性定义（4-连通、4~8 像素、非矩形）。其中恰好 1 个精灵体的裁剪后彩色图案与其余所有精灵体不同（异常体），其余精灵体两两图案完全相同（包含内部颜色布局）。异常体位于网格上方若干行处，确保其下方至少留有 10 行空间供生长。不同示例中异常体位置不固定、异常体的具体图案不同。生成约束：所有精灵体的边界框尺寸相同，仅内部颜色布局区分异常体与复制体；异常体位于网格上半部分（行索引 ≤ 网格高度的 1/3）。

**规则**：
1. 将每个精灵体裁剪至其边界框，得到包含背景像素的彩色小矩阵。
2. 逐对比较所有裁剪结果（含颜色），找到恰好只出现一次的图案——该精灵体为异常体。
3. 擦除所有非异常精灵体（设为黑(0)）。
4. 对异常精灵体的每个非黑(0)像素 P（坐标 (r, c)，颜色 C）：以 P 为中心，从 P 本身和其四个对角邻居 (r-1,c-1)、(r-1,c+1)、(r+1,c-1)、(r+1,c+1) 共五个位置出发，每个位置每隔 2 行向下重复绘制颜色 C 的像素，直到超出网格下边界为止。即对每个起始位置 (r0, c0)，绘制 (r0, c0)、(r0+2, c0)、(r0+4, c0)、... 。
5. 若多条轨迹在同一像素重叠，按种子像素在精灵体内从左上到右下的扫描顺序，后绘制的覆盖先绘制的。

**关键洞察**：异常精灵体不只是被"选中"——它的多色内部布局同时决定了种子的空间排列和每条生长轨迹的颜色，不同示例中异常体图案不同会导致完全不同的生长纹理。

Input structure
The grid is partitioned by black separator rows and columns into equal-size

Key insight
