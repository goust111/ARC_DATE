## 新题 8：压缩对角线展开与奇偶交替涂色

**组合逻辑**：[拉伸](已有, 创新：展开因子编码在水平条中而非直接空间复制) + [奇偶交替涂色](已有, 创新：交替对象从预存对角线变为展开后生成的对角线) + [压缩与展开](已有) + [参考面板](已有)

**来源原语**：拉伸/stretch(9841fdad), 压缩与展开/compress_expand(9841fdad), 参考面板/reference_panel(9841fdad), 分隔线/divider(9841fdad), 竖条/bar(08ed6ac7, 创新改造为水平条用作拉伸因子), 对角线段/diagonal_segment(a5f85a15), 奇偶交替涂色/alternating_parity_recolor(a5f85a15), 序列索引/sequential_index(a5f85a15)

**依赖链**：参考面板中每个对角线段附带的水平条长度编码了该对角线在工作区中的展开倍率。展开后的对角线长度决定了奇偶交替涂色产生多少个黄色像素。没有水平条→不知展开多少；没有展开→没有交替涂色的载体；没有交替涂色→输出仅为纯色对角线，退化为简单展开。

从参考面板中读取短对角线段及其附带的水平条长度，将对角线按条长倍率展开到工作区，并沿展开后的对角线做奇偶交替涂色。

**输入结构**：黑(0)背景，约 12x22 网格（窄高布局，左窄右宽）。灰(5)竖直分隔线（1 像素宽）将网格分为左侧参考面板（约 5 列宽）和右侧工作区（约 16 列宽）。参考面板中有 2~4 条短对角线段（沿主对角线方向即左上到右下，每段 2~3 像素长），颜色各不相同（从蓝(1)、红(2)、绿(3)、橙(7)中选取）。每条对角线段的右下端点向右延伸出一条同色水平条（1 像素高，长度 1~4 像素，不接触分隔线）。不同对角线段在纵向上不重叠。右侧工作区为空。生成约束：不同对角线段的水平条长度互不相等；展开后的对角线在工作区内不超出网格下边界和右边界（即每条对角线段的起始行 + 原始长度 x 水平条长度 ≤ 网格高度，起始列在分隔线右侧第 2 列 + 原始长度 x 水平条长度 ≤ 网格宽度）。

**规则**：
1. 在参考面板中识别每条对角线段 D（颜色 C、像素数 L）及其右下端点延伸的水平条（像素数 M）。
2. 在右侧工作区中，从与 D 的左上端点同行、分隔线右侧第 2 列的位置开始，沿主对角线方向（右下）绘制长度为 L x M 的对角线段。
3. 对该展开后的对角线段，按像素顺序从左上到右下编号 0, 1, 2, ...：偶数编号像素保持颜色 C，奇数编号像素重涂为黄(4)。
4. 若不同展开对角线在工作区内某像素重叠，按对角线在参考面板中从上到下的顺序，后出现的覆盖先出现的。
5. 参考面板、分隔线保持不变。

**关键洞察**：水平条是对角线展开倍率的压缩编码——一条 3 像素的水平条不是直接空间复制为 3 行，而是将 2 像素对角线展开为 6 像素对角线。交替涂色的节奏在压缩参考中不可见，只在展开后才涌现出黄色间隔图案。
