## 新题 7：尺寸决定沿路径运动距离与颜色归属

**组合逻辑**：[沿路径移动](已有, 创新：移动距离由分量尺寸决定而非固定全程) + [尺寸分类](已有) + [重涂色](已有, 创新：颜色改变方向由尺寸不对称决定) + [擦除](已有)

**来源原语**：沿路径移动/path_move(c9680e90), 轨迹路径/trace_path(c9680e90), 连通分量/connected_component(多源), 尺寸分类/size_classification(aedd82e4), 重涂色/recolor(aedd82e4), 单像素分量重涂/single_pixel_component_recolored(aedd82e4, 创新改造为小分量被大分量的颜色吸收), 擦除/erase(多源), 计数/counting(多源)

**依赖链**：尺寸分类同时决定三件事：(1) 运动方向——小分量沿路径向大分量移动；(2) 运动距离——小分量走全程（到达大分量位置），同尺寸类的分量各走半程；(3) 颜色归属——小分量到达后被重涂为大分量的颜色。三个输出属性全部由同一个判据（尺寸比较）派生。删除路径→无运动通道；删除尺寸比较→方向、距离、颜色全部不确定。

沿灰色路径连接的彩色分量对中，小分量向大分量全程移动并被吸色，同级分量各走半程保持原色。

**输入结构**：黑(0)背景，约 16x16 网格。网格中有 3~5 个不同颜色的 4-连通前景分量（颜色从蓝(1)、红(2)、绿(3)、黄(4)、橙(7)中选取），像素数各异（1~8 像素），形态不规则。灰(5)单像素宽的路径（4-连通曲线，不分支）将分量两两连接：每条路径的两端各有一个像素与一个分量 4-连通相邻。每个分量恰好连接一条路径（即分量按路径配对，若分量数为奇数则有一个分量无路径连接，该分量保持不变）。生成约束：路径不穿过任何分量内部；不同路径之间不交叉不接触；每条路径长度 ≥ 3 像素。

**规则**：
1. 检测所有非黑(0)非灰(5)的 4-连通前景分量，记录每个分量的像素数和颜色。
2. 检测所有灰(5) 4-连通路径，确定每条路径两端连接的两个分量 A 和 B。
3. 对每条路径连接的分量对 (A, B)，比较像素数：
   - 若 |A| < |B|：A 沿路径向 B 移动全程——将 A 的所有像素擦除（设为黑(0)），然后在 B 的最近路径端点旁、沿路径最后几步的方向重新绘制 A 的形状（平移 A 的精灵体使其 4-连通接触 B），颜色改为 B 的颜色。
   - 若 |A| > |B|：对称处理，B 向 A 移动并取 A 的颜色。
   - 若 |A| = |B|：双方各沿路径向对方移动路径长度的一半（向下取整）像素距离，各自保持原色不变。移动方式为将整个分量沿路径方向平移对应像素数。
4. 所有灰(5)路径像素在移动完成后擦除（设为黑(0)）。
5. 未连接路径的分量保持原位和原色不变。

**关键洞察**：尺寸是三重判据——它同时决定"谁动""动多远""变什么色"。小分量被大分量"引力吸收"的动态关系使得每对连接分量的行为模式不同，而同尺寸对的对称半程移动又是第三种行为，需要多个示例才能归纳出完整规则。

Input structure

Key insight
