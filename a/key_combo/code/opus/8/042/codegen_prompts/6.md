## 新题 6：块网格内形状尺寸到同心环排列

**组合逻辑**：[计数](已有) + [块网格](已有, 创新：块内容不作编码解码用途，而是提供待测量的对象) → [排序](已有) + [按边长降序排列](已有, 创新改造为按像素数降序) → [同心层填充](已有, 创新：环尺寸不取自碎片帧的 bbox 而是取自块内分量的像素数)

**来源原语**：块网格/block_grid(6350f1f4), 连通分量/connected_component(多源), 计数/counting(多源), 排序/sorting(c658a4bd), 按边长降序排列/descending_side_order(c658a4bd), 同心层填充/concentric_fill(c658a4bd), 同心正方形层/concentric_layer(c658a4bd), 嵌套层次/nesting_hierarchy(c658a4bd)

**依赖链**：块网格将空间划分为独立的测量单元，每个块内部的形状像素数是该块的"权重"。全局排序将各块的权重从大到小排列，该排名直接映射为同心正方形环的由外到内层次，每层的颜色取自对应块内形状的颜色。删除块网格→无法分离测量单元；删除计数→无法排序；删除同心填充→无输出几何。

读取块网格中每个块内形状的像素数，按数量从大到小排列，生成相应层数的同心正方形环，每层颜色对应最大到最小块内形状的颜色。

**输入结构**：黑(0)背景，约 15x15 网格。灰(5)分隔线（宽 1 像素）将网格划分为 2x2 或 3x3 的等大正方形块（每块内部约 4x4 至 6x6）。每个块内包含一个单色 4-连通前景形状（形状不规则，像素数 2~12，不同块的形状颜色各不相同，从蓝(1)、红(2)、绿(3)、黄(4)、橙(7)中选取），块内其余像素为黑(0)。不同示例中块的数量（4 或 9）和形状像素数不同。生成约束：所有块内形状像素数互不相等；块的数量 N 满足 N ≤ 5（以保证同心环可以区分且不过密）；输出正方形边长 = 2N - 1。

**规则**：
1. 识别块网格结构：灰(5)分隔行/列将网格分割为 N 个等大方形块。
2. 对每个块，检测其内部的非黑(0)非灰(5)前景 4-连通分量，记录其像素数和颜色。
3. 将所有块按其内部分量像素数从大到小排序。排名 1 = 像素最多的块。
4. 创建边长为 (2N - 1) 的输出正方形：
   - 排名 1 的颜色绘制最外层正方形环（边长 = 2N - 1 的边框，一像素厚）。
   - 排名 2 的颜色绘制次外层正方形环（边长 = 2N - 3 的边框）。
   - 依此类推，排名 k 的颜色绘制边长为 (2N - 2k + 1) 的正方形环。
   - 最内层排名 N 的颜色填充中心 1x1 像素。
5. 输出仅为该同心正方形，无多余背景。

**关键洞察**：输入的块网格是空间容器，输出的同心环是全新的几何结构——两者之间没有空间对应关系，只有数值对应（像素数→环层序号）。求解者必须理解块网格仅用于测量和分组，而非作为输出模板。

<description>
Paint yellow the background cells on the unobstructed shortest monotone corridor between two doorway frames.

Input structure
- The grid has a background, two small frame objects in one foreground color, and one center marker in each frame.
- Each marker has exactly one background 4-neighbor, the doorway gap; the next cell outward is the exterior doorway cell.

Rule
- Treat all existing foreground cells as blockers.
- Between the two exterior doorway cells, allow only row/column steps that move toward the other exterior cell.
- Paint every background cell that lies on some such path from one exterior cell to the other, plus the two doorway gaps, yellow.

Key insight
- The output is not a single chosen route: it is the union of all shortest monotone paths that can pass between the two frames.
</description>
