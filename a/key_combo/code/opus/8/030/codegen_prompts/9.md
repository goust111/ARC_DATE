## 新题 9：从框架中提取母题模板，在单像素位置盖章，单像素颜色编码盖章后的行为

**组合逻辑**：[裁剪 + 包含 + 模板](创新：模板不由重复检测获得，而由框架内部提取) → [印章放置 + 单像素布局](已有：单像素指示盖章位置) → [重涂色 / 擦除](创新：不按对称性或路径可达性，而按单像素颜色编码的"指令"决定后处理——同色于框架的单像素盖章后消失，异色的单像素保留并变为框架色)

**来源原语**：裁剪 crop、空心矩形 rectangular_frame、模板 template、包含 containment、框架色传递同形 frame_color_transferred_to_matching_empty（参考题 890034e9）；印章放置 stamp、单像素布局 singleton_layout、栅格偏移 lattice_offset（参考题 a395ee82）；重涂色 recolor、擦除 erase（参考题 a09f6c25）

**依赖链**：框架包含母题 → 裁剪提取母题为模板 → 单像素的位置提供盖章坐标 → 模板在各坐标处盖章 → 每个单像素的颜色编码该位置的"后处理指令"（同框架色→擦除该单像素，异框架色→保留并重涂为框架色）。模板提取、位置指定、后处理三步缺一不可。

从框架内提取母题作为印章模板，在散布的单像素位置盖章，盖章后按单像素颜色决定该标记点是消失还是变色保留。

**输入结构**：约 15x15 的黑(0)背景网格。一个完整的蓝(1)矩形边框（单像素厚，约 4x4 至 5x5）。框架内部有一个由红(2)像素构成的小母题（2-4 个像素，形状各异）。框架外散布 4-6 个孤立的单像素：其中一部分为蓝(1)（与框架同色），另一部分为绿(3)（与框架异色）。单像素之间及单像素与框架之间的间距 >= 框架边长（保证盖章区域不重叠、不与框架重叠）。生成约束：盖章区域完全在网格范围内。

**规则**：
1. 找到蓝(1)矩形边框，提取其内部的红(2)像素图案——记录每个红像素相对于框架内部左上角的偏移。这就是印章模板 S。
2. 对每个框架外的单像素 P（位于 (r, c)）：以 (r, c) 为左上角参考点，按模板 S 中各像素的偏移量放置红(2)像素。仅在黑(0)背景像素上着色。
3. 盖章完成后，处理每个单像素 P：
   - 若 P 的颜色 = 蓝(1)（与框架同色）：将 P 擦除（设为黑(0)背景）。该单像素是"一次性位置标记"。
   - 若 P 的颜色 = 绿(3)（与框架异色）：将 P 重涂为蓝(1)。该单像素是"永久锚点"。
4. 原始框架和框架内母题保持不变。

**关键洞察**：单像素的颜色不仅标记"在此处盖章"，还编码了盖章后的行为差异。同色于框架的单像素在完成使命后消失（"阅后即焚"），异色的单像素在完成使命后变色存留（"刻入框架色"）。这一颜色→行为的编码规则需要对比同一输出中两类标记点的不同命运才能归纳。
