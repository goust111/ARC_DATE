## 新题 7：擦除重复色遮挡物后推断并补全矩形边框笔画的等差序列

**组合逻辑**：[擦除 + 重复色才移动](创新：重复色物体不移动而是就地擦除，目的是揭露被遮挡的笔画碎片) → [等差递推 + 补全 + 画布裁切可见](已有：从可见笔画推断等差序列并补全) → [填充](已有：剩余背景涂灰)

**来源原语**：擦除 erase、重复色对象 repeated_color_obj、重复色才移动 repeated_color_moves（参考题 22208ba4）；等差递推 arithmetic_progression、补全 completion、矩形边框笔画 rect_side_stroke、画布裁切可见 canvas_clips_visible（参考题 f8c80d96）；填充 fill（参考题 f8c80d96）

**依赖链**：颜色出现次数统计 → 识别重复色 → 擦除所有重复色像素 → 露出被遮挡的笔画碎片 → 碎片 + 原本可见的笔画共同构成等差序列的部分成员 → 推断等差序列参数 → 补全缺失成员（含超出画布的裁切成员）→ 其余背景涂灰。

擦除重复色遮挡物以揭露隐藏的矩形笔画碎片，再与原有可见笔画一起推断等差序列，补全所有缺失成员并将背景涂灰。

**输入结构**：约 15x15 的黑(0)背景网格。绿(3)的矩形边框笔画（如每个笔画是矩形的顶边 + 右边，即 L 形笔画）构成等差序列的部分成员：2-3 个完整可见，1-2 个被遮挡（部分或完全隐藏在红色物体下方）。红(2)的实心 4-连通物体有 2 个以上（使红色成为重复色），它们覆盖在某些笔画位置上。可能还有 1 个其他颜色（如蓝(1)）的单例物体贴边放置（单例色不被擦除）。生成约束：等差序列的步长恒定（位置和尺寸的增量一致）；被遮挡的笔画在擦除红色后必须有足够碎片可与其他成员拼合以推断序列；序列至少有 4 个成员（含需补全的）。

**规则**：
1. 统计每种非背景色的 4-连通分量数量。分量数 >= 2 的颜色为重复色 R。
2. 将所有 R 色像素设为黑(0)背景。
3. 现在网格中只剩绿(3)笔画像素（含原本可见的 + 被遮挡后露出的碎片）和可能的单例色物体。
4. 将所有绿(3)像素归入各自的 4-连通分量，每个分量视为一段笔画碎片。重建每段碎片所属的矩形边框笔画（同一笔画的碎片具有共线的边段）。
5. 从已知的完整或可拼合的笔画中，推断等差序列参数：边界框的左上角坐标和尺寸分别构成等差数列。
6. 按等差序列向两个方向外推，直到新成员的可见部分（被画布裁切后）为空。
7. 绘制所有序列成员（包括已存在的和补全的）的绿(3)笔画。
8. 将网格中所有仍为黑(0)的像素（非绿(3)、非单例色物体）涂为灰(5)。
9. 单例色物体保持原色不变。

**关键洞察**：遮挡物不是装饰——它们系统性地隐藏了等差序列中的关键成员。擦除是推断的前提条件：不擦除就看不到完整的笔画集合，看不到就无法确定等差步长，无法确定步长就无法补全。这形成了一个严格的因果链，而非两个独立操作的串联。
