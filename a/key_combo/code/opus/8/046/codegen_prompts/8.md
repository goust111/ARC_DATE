## 新题 8：格子多数决生成调色带驱动蒙版重涂

**组合逻辑**：[压缩/majority_vote](创新：压缩结果不是最终输出，而是生成调色带) + [逐列对应重涂/column_correspondence recolor](已有) + [擦除/erase]

**来源原语**：压缩/compress(af24b4cc), 多数决/majority_vote(af24b4cc), 格子格局/lattice_layout(af24b4cc), 分隔行列/separator_row_col(af24b4cc), 填色块/filled_block(af24b4cc), 重涂色/recolor(278e5215), 单色蒙版/monochrome_mask(278e5215), 调色带/palette_strip(278e5215), 逐列对应/column_correspondence(278e5215), 擦除/erase(4b6b68e5), 标记像素/marker_pixel(4b6b68e5)

**依赖链**：格子中噪声块的多数色决定压缩后的颜色序列（多数决 -> 调色带生成），调色带逐列映射到蒙版上（调色带 -> 重涂色），蒙版内的标记像素被擦除。格子噪声直接影响最终蒙版颜色，三步紧密耦合。

网格上半区为被背景线分隔的彩色格子（含噪声），下半区为灰(5)蒙版；将格子按多数决压缩为一行颜色序列作为调色带，用该调色带逐列重涂蒙版，并擦除蒙版区域中的标记像素。

**输入结构**：约 16x20 的黑(0)背景网格。上半区（约前 8~10 行）被黑(0)完整行和完整列分隔为一行 N 列的格子（N 为 4~7），每个格子块宽 2~3 像素、高 2~3 像素。每个格子块中多数像素为一种非黑颜色（如红(2)、蓝(1)、绿(3)、黄(4)、橙(7)等），少数像素为其他颜色（噪声），保证多数色唯一。下半区（约后 8~10 行）包含一个灰(5)单色蒙版——一个 4-连通的不规则形状（宽度恰好覆盖 N 列范围，即与格子总列跨度对齐，含若干背景色孔洞），蒙版区域内散布有 1~3 个品红(6)单像素标记。不同示例中格子颜色分布和蒙版形状变化。生成约束：格子的列数与蒙版边界框宽度相等，一一对应。

**规则**：
1. 在上半区找到格子结构，确定分隔线并提取每个格子块。
2. 对每个格子块，取唯一多数色，形成一行长度为 N 的颜色序列（从左到右对应格子从左到右）。此序列即为调色带。
3. 裁剪到下半区蒙版的边界框。对边界框的每一列，将该列中所有灰(5)像素替换为调色带中对应位置的颜色。
4. 边界框内的背景(0)孔洞保持为黑(0)。
5. 边界框内的所有品红(6)标记像素擦除为黑(0)。
6. 输出为裁剪后的蒙版边界框区域。

**关键洞察**：调色带不在输入中直接给出，而是隐藏在格子的噪声中，必须通过多数决提取。格子的噪声模式直接影响最终蒙版的列颜色——如果一个格子块的多数色因噪声分布不同而改变，蒙版对应列的输出颜色随之改变。
