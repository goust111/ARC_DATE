## 新题 5：视线计数竞争筛选分区

**组合逻辑**：[射线延伸/ray_extend](创新：射线从标记出发，计数命中而非移动) + [计数/counting] + [筛选/filtering+洪泛填充/flood_fill](创新：视线命中总数决定分区存亡)

**来源原语**：射线延伸/ray_extend(e1d2900e), 视线对齐/sightline_align(e1d2900e), 计数/counting(1fad071e), 洪泛填充/flood_fill(29623171), 筛选/filtering(29623171), 实心方块/solid_block(e1d2900e), 标记像素/marker_pixel(e1d2900e), 分区区域/partitioned_region(29623171), 分隔线/separator_line(29623171), 最密区域保留填充/densest_region_kept_filled(29623171)

**依赖链**：标记与方块的相对位置决定视线命中数（空间布局 -> 计数结果），各分区的命中总数竞争（计数 -> 筛选），胜出分区被洪泛填充（筛选 -> 填充）。方块同时是视线目标和分区内容的一部分，移除任何一步都无法确定输出。

黑(0)背景被灰(5)分隔线划分为若干矩形区域；每区域内有蓝(1) 2x2 方块和红(2)标记像素；从标记投射四方向射线计数命中方块数，命中总数最多的区域被蓝色洪泛填充，其余区域清空。

**输入结构**：约 17x17 的黑(0)背景网格。灰(5)完整行和完整列将网格分为 2x2 或 2x3 共 4~6 个矩形分区（灰线包括外边框）。每个分区内包含 1~3 个蓝(1)实心 2x2 方块和 1~3 个红(2)单像素标记。方块和标记在分区内的位置各示例不同。不同示例中分区数量和尺寸比例可变，但每个分区内至少有一个方块和一个标记。生成约束：恰好一个分区的视线命中总数严格最大（不平局）。

**规则**：
1. 识别灰(5)分隔线，提取所有矩形分区。
2. 对每个分区内的每个红(2)标记像素，沿上、下、左、右四个方向投射射线，射线在碰到分区边界（灰线或网格边缘）时停止。若射线在停止前碰到蓝(1) 2x2 方块的任意像素，记为一次"命中"（每条射线至多计一次命中，即碰到的第一个方块）。
3. 对每个分区，求其所有标记的命中次数之和。
4. 命中总数最大的分区为胜出分区。将该分区内的所有非灰像素（包括背景(0)、蓝(1)方块、红(2)标记）全部涂为蓝(1)。
5. 所有非胜出分区的内部全部清为黑(0)。
6. 灰(5)分隔线在输出中保持不变。

**关键洞察**：方块在分区内既是"被计数的视线目标"又是"被填充或被清除的内容"。同一个方块因为遮挡了后方的视线，可能减少该分区的命中数从而导致自身所在分区被清除——方块的存在既帮助又妨碍了所在分区的存亡。

    structure: 8-connected meandering path from seed through the grid (1px wide, uses diagonal steps so NOT 4-connected)
    length: 6-45 line_color pixels per seed's component

  frame_loops:
    count: 1-9 total across the grid (single-color-boundary cavities)

  connectivity:
    loops attached to the seed's line (8-connected via line_color) get their cavity filled with seed_color
    filled: 1-8 per example; unfilled (distractor): 0-5
    at least 1 unfilled cavity exists in 5/6 examples [observed]
  distractors:
    0-1 disconnected 8-connected non-bg components with no seed; may contain line+frame structure or be a single frame loop
  output: same grid with each connected cavity flood-filled by its seed's color

generation_strategy:
  approach: output-first
  steps:
    1. Choose grid size, bg color, 1-2 seeds with unique colors, and per-seed line_color
    2. For each seed, draw a meandering 8-connected line path from the seed's border position inward, using diagonal and orthogonal steps
    3. Along each line, attach 2-5 frame loops (closed rings of a frame_color enclosing a 2x2 bg cavity); the line touches the loop at 1-2 outer edge positions (8-adjacent to the frame ring)
    4. Place 0-3 additional distractor loops (same frame_color or different) NOT 8-connected to any line
    5. Optionally add 0-1 disconnected non-bg component as a distractor network
    6. Verify: each cavity has single-color boundary; cavities connected to a line are fillable; at least 1 unfilled cavity exists
    7. Output is derived by flood-filling each connected cavity with its seed_color
