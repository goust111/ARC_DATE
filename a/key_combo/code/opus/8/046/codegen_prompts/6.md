## 新题 6：方块计数选择镜像轴向

**组合逻辑**：[计数/counting](已有) + [镜像/mirror](创新：计数结果决定镜像轴向而非编码为条形长度) + [忽略干扰项/ignore_distractors]

**来源原语**：计数/counting(1fad071e), 镜像/mirror(4c4377d9), 正方形块/square_block(1fad071e), 干扰体/distractor(1fad071e), 忽略干扰项/ignore_distractors(1fad071e), 翻转副本堆叠拼接/flip_copy_stacked(4c4377d9)

**依赖链**：计数结果直接决定镜像操作的类型（奇偶性 -> 轴向选择），而被计数的方块本身又是被镜像的视觉内容的一部分（计数 -> 镜像内容）。两步融合在同一组对象上，无法独立执行。

统计网格中蓝(1) 2x2 实心方块的数量（忽略单像素干扰），奇数则水平翻转后拼接到右侧，偶数则垂直翻转后拼接到下方。

**输入结构**：约 8x8 至 10x10 的黑(0)背景网格。包含 1~5 个蓝(1)实心 2x2 方块和 1~5 个红(2)实心 2x2 方块，散布在网格中互不重叠。另有若干（0~3 个）蓝(1)或红(2)的单像素点作为干扰体（与方块不相邻）。不同示例中蓝方块数量的奇偶性变化，使得镜像方向改变。生成约束：蓝 2x2 方块数量在 1~5 之间。

**规则**：
1. 扫描输入中所有 2x2 窗口，找到完全由蓝(1)填充的窗口——即蓝方块。忽略红(2) 2x2 方块和所有单像素干扰点。
2. 统计蓝方块总数 N。
3. 若 N 为奇数：构建一个宽度为原输入两倍、高度不变的输出。左半部为原输入不变，右半部为原输入的水平翻转副本（左右镜像）。
4. 若 N 为偶数：构建一个高度为原输入两倍、宽度不变的输出。上半部为原输入不变，下半部为原输入的垂直翻转副本（上下镜像）。

**关键洞察**：蓝方块同时扮演两个角色——它们是被计数的判定依据，也是被镜像复制的视觉内容。计数结果不编码为数字或条形，而是选择了一种完全不同的空间变换类型。仅看一个示例无法确定奇偶规则，必须对比多个示例中方块数与镜像方向的对应关系。
