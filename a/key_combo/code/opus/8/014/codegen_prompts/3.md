## 新题 3：象限异常值定位周期修复目标

**组合逻辑**：[相等比较(equality_comparison) + 异常值选择(outlier_selection)](定位操作对象) ↔ [补全(completion) + 周期瓦片推断(periodic_tile)](修复操作) — 两步互相依赖：异常值选择确定修复目标的位置，而多数象限提供修复所需的周期信息

**来源原语**：象限/quadrant、分隔十字/separator_cross、相等比较/equality_comparison、异常值选择/outlier_selection（来自 88a62173）；周期瓦片/periodic_tile、补全/completion、标记为缺失值/markers_missing_val、行列周期/row_col_period（来自 f823c43c）

**依赖链**：四象限比较产生两类输出——异常值象限（操作的目标区域）和多数象限组（修复信息的来源）。多数象限各自含有品红缺损，但同一位置不会在所有三个多数象限中同时缺损，因此交叉比对可还原完整周期瓦片。还原后的瓦片用于覆写异常值象限的内容。异常值检测和周期推断必须协同工作：检测不出异常值就不知道往哪里写，推断不出周期瓦片就不知道写什么。

找到四象限中的异常值，用其余三个象限交叉还原的周期瓦片替换异常值象限的内容。

**输入结构**：奇数行奇数列（如 13x13）的网格。中间行和中间列为黑(0)背景色，形成分隔十字，将网格分为四个大小相同的矩形象限。三个象限包含相同的底层双色周期图案（如红(2)和蓝(1)交替），但每个象限中有若干像素被替换为品红(6)（缺损标记），同一网格位置（相对于象限左上角）至多在两个多数象限中同时缺损（保证可修复）。第四个象限（异常值）包含完全不同的图案（如绿(3)和黄(4)组成的非周期图形）。生成约束：三个多数象限的底层周期图案完全一致；每个缺损位置至少有一个多数象限保留了原始颜色；异常值象限与多数象限的图案明显不同（不只是缺损差异）。

**规则**：
1. 将网格沿分隔十字分为四个象限区域（不含分隔十字本身的行列）。
2. 两两比较四个象限（比较时将品红(6)视为通配符，与任何颜色匹配）。找出三个互相兼容的象限（多数组）和一个与其余三个都不兼容的象限（异常值）。
3. 对多数组的三个象限，逐像素交叉比对：在每个位置，取非品红的颜色值作为该位置的真实值（若三个象限在该位置都非品红且一致，直接取值；若部分为品红，取非品红值）。由此还原出完整的无缺损象限图案。
4. 用还原的完整图案替换异常值象限的全部内容。
5. 输出完整网格（分隔十字、多数象限保持原样不变，仅异常值象限被替换）。

**关键洞察**：异常值检测和周期修复不是先后独立的两步——异常值检测的副产品（多数组的确定）恰好提供了修复所需的冗余信息源，两个操作共享同一次比较的结果。
