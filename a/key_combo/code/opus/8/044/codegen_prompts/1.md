## 新题 1：不对称标记连线

**组合逻辑**：[对称检测](选出不对称对象作为活跃标记) → [计数](统计活跃标记的像素数，映射连线颜色) → [连线/首尾跨度填充](对同行列的活跃标记做跨度连接)

**来源原语**：对称检测(#73ccf9c2)、计数(#6e02f1e3)、连线/首尾跨度填充(#ded97339)、前景对象(#73ccf9c2)、同行列对齐(#ded97339)

**依赖链**：对称检测筛选出哪些对象参与连线（未通过对称检测的对象被忽略）；活跃标记的像素总数决定连线使用的颜色；连线仅发生在活跃标记之间，非活跃对象既不参与也不阻挡。

将网格中不对称的前景对象视为活跃标记，统计其总像素数以确定连线颜色，然后在同行或同列的活跃标记之间画跨度连线。

**输入结构**：约 15x15 的黑(0)背景网格。网格上散布 5~8 个灰(5)的 4-连通单色小对象（3~7 像素），彼此不相邻、不共享行列上的像素。其中部分对象在其紧包围框内具有左右镜像对称性，其余不具有。生成约束：至少有 2 个不对称对象共享某一行或某一列；不同示例中对称/不对称对象的数量比例不同。

**规则**：
1. 将每个灰(5)的 4-连通前景对象裁剪到其紧包围框，判断其前景掩码是否等于自身的左右镜像。
2. 将所有不对称的对象标记为"活跃标记"，对称对象保持原样不参与后续操作。
3. 统计所有活跃标记的像素总数 N。若 N <= 8，连线颜色为蓝(1)；若 9 <= N <= 14，连线颜色为红(2)；若 N >= 15，连线颜色为绿(3)。
4. 对于每一行，若该行穿过至少两个活跃标记的包围框，则从最左侧活跃标记包围框的最左列到最右侧活跃标记包围框的最右列，将该行上所有黑(0)背景像素填充为连线颜色。活跃标记自身的灰(5)像素保留不变。
5. 对于每一列，执行相同的纵向跨度填充。
6. 对称对象、非活跃区域的背景保持不变。若水平连线和垂直连线在某像素交叉，该像素为连线颜色（无冲突，颜色相同）。

**关键洞察**：对称性检测不是输出的一部分，而是一个隐式门控——它决定哪些对象"存在"于连线逻辑中；像素总数到颜色的映射阈值需要对比多个示例才能归纳出。

    gap: each wall leaves a gap at one end, gaps alternate sides across successive walls to force a serpentine path
    density: 19-36% of grid cells are BLUE
  path:
    type: unique shortest 4-neighbor path between the two RED endpoints through non-BLUE cells
    uniqueness: solver asserts exactly one shortest path (no ties)
    length: 13-28 cells including endpoints
    turns: 4-10 direction changes
    path/manhattan ratio: 1.5-3.3 (walls force significant detour)
  output:
    same grid with interior path cells (BLACK on shortest path, excluding RED endpoints) recolored to YELLOW(4)
    all other cells unchanged

generation_strategy:
  approach: path-first
  steps:
    1. Choose grid size N x N in [5,10].
    2. Place two RED endpoints on grid border (prefer corners or border cells well separated).
    3. Build a serpentine corridor between them by placing BLUE wall segments that alternate gap sides.
       Each wall is a H or V line spanning 40-85% of the relevant dimension, anchored to a grid edge,
       with a 1-cell gap at the opposite end. Alternate gap side so the path snakes.
    4. Verify the unique shortest path exists by running BFS, and that backtracking yields exactly
       one predecessor at each step. Reject if path is non-unique or endpoints are disconnected.
    5. Return the grid with only BLACK, BLUE, and RED cells.
