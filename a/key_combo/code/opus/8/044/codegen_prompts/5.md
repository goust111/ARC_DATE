## 新题 5：象限异常值精灵平铺全域

**组合逻辑**：[裁剪/象限分割](四象限分离) → [异常值选择](找到与其他三象限精灵不同的那个) → [裁剪](紧包围框裁剪异常精灵) → [平铺](将异常精灵作为瓦片铺满整个网格)

**来源原语**：象限(#0b148d64)、分隔行列(#0b148d64)、异常值选择(#0b148d64)、裁剪(#0b148d64)、平铺(#ea959feb/#0a938d79)、周期重复(#ea959feb)、归一化形状匹配(#2a5f8217)

**依赖链**：象限分割是定位的前提；异常值选择依赖跨象限的形状比较（需要归一化形状匹配来判断"相同"与"不同"）；被选中的异常精灵成为平铺的种子瓦片——选错异常值就会铺错图案。

将网格分为四个象限，找到精灵形状与其他三个不同的象限，裁剪出该异常精灵，然后将其作为周期瓦片从左上角开始铺满整个输出网格。

**输入结构**：约 13x13 的黑(0)背景网格（奇数行列以保证有唯一中心分隔线）。正中间的一整行和一整列为灰(5)分隔线，将网格分为四个大小相等的象限。每个象限内有一个由单一非黑非灰颜色构成的 4-连通小精灵（3~6 像素），四个象限的精灵颜色各不相同，取自蓝(1)、红(2)、绿(3)、黄(4)。其中三个象限的精灵在归一化到包围框左上角后形状完全相同（但颜色不同），第四个象限的精灵形状不同（这是异常值）。精灵在象限内的位置各不相同。生成约束：异常精灵的包围框高度和宽度均不超过象限尺寸的一半（以保证平铺时至少能重复两次）。

**规则**：
1. 识别灰(5)分隔行和分隔列，将网格分为四个象限（不含分隔线）。
2. 提取每个象限中的非黑前景精灵，裁剪到紧包围框，得到归一化掩码（仅看形状，忽略颜色）。
3. 比较四个归一化掩码：三个相同的是"正常"精灵，一个不同的是"异常"精灵。
4. 将异常精灵的紧包围框裁剪保留（保留其原始颜色）。
5. 输出网格的尺寸等于输入网格去掉分隔行列后一个象限的尺寸。以异常精灵裁剪结果为瓦片，从输出网格左上角开始按行优先顺序周期平铺，超出输出网格边界的部分截断。瓦片之间无间隔，未被瓦片覆盖的像素（瓦片内的黑色背景部分）保持黑(0)。

**关键洞察**：异常值不是用颜色判定的（四个颜色都不同），而是用归一化形状判定的——必须对比四个象限的精灵形状才能确定哪个是异常值。异常值从"被排除者"变成唯一的输出种子，这一反转需要多个示例确认。

Input structure
- A black-background grid contains several 4-connected foreground objects.
- Blue objects are uncolored placeholders.

Rule

- For each blue object, find the unique non-blue template object with the same normalized mask.

Key insight
- Position is irrelevant: each placeholder is identified by shape equality with a colored template elsewhere in the grid.

Complete the erased cells of a periodic wallpaper by inferring its smallest repeating tile.

Input structure
A rectangular grid contains a multi-color repeating pattern. The background
color is also a valid tile color, and some non-background pattern pixels

Rule
Ignore background-colored cells and find the unique smallest row/column
period whose residue classes assign every visible foreground pixel one
consistent color. Repaint each foreground residue class across the whole
grid, leaving residue classes with no foreground evidence as background.

Key insight
The visible foreground pixels are enough to recover the wallpaper's period;
erased pixels are exactly the background cells in foreground residue classes.
</description>

- bg = most common color.
- Several multicolor connected components (8-connected) scattered across the grid.

Rule:

- Objects whose shape is unique → translate to BOTTOM edge (row H−h).

Key insight: The sorting criterion is shape frequency (rotation-invariant), not area — duplicated shapes go up, unique shapes go down.
