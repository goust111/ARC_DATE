## 新题 6：叠加深度热力重涂色

**组合逻辑**：[透明叠加/标记对齐](已有原语) → [计数](创新：计数的不是对象面积而是叠加后每个像素上的覆盖层数) → [重涂色](创新：由叠加深度映射颜色，产生热力图式的涌现效果)

**来源原语**：透明叠加/标记对齐/面积排序叠加(83eb0a57), 计数(d2abd087/c8b7cc0f), 重涂色(d2abd087/bda2d7a6), 标记像素(c8b7cc0f)

**依赖链**：必须先通过标记对齐确定各精灵体的叠加位置，才能计算每个像素的覆盖层数。覆盖层数（深度）是叠加操作产生的涌现信息——单个精灵体没有"深度"概念，深度仅在多体叠加后出现。深度数值再驱动重涂色映射。三步之间存在严格的信息依赖。

将多个灰色矩形精灵体按标记对齐叠加，然后将每个像素按其被覆盖的层数重涂色为不同颜色，形成类似等高线的热力图。

**输入结构**：约 15x15 的网格，黑(0)背景。3-4 个灰(5)实心矩形精灵体，大小各不相同（如 3x5、5x7、7x9、4x6）。每个精灵体中恰有一个像素为红(2)，作为对齐标记。红(2)标记在各精灵体内部的相对位置相同（如均位于精灵体左上角起第 2 行第 2 列）。精灵体在输入网格中互不重叠，水平排列，间距足够大。生成约束：叠加后所有精灵体的并集区域不超出网格边界；精灵体数量为 3 或 4 个，确保最大深度不超过 4。

**规则**：
1. 识别所有灰(5)矩形精灵体及其内部的红(2)标记像素。
2. 以最大面积精灵体的标记位置为基准点，将所有精灵体平移使其红(2)标记对齐到该基准点。
3. 对叠加后的每个网格像素，计算其被多少个精灵体覆盖（即覆盖深度 d）。标记像素所在位置也参与深度计算（该位置被所有精灵体覆盖）。
4. 按深度重涂色：d=0 → 黑(0)（背景），d=1 → 蓝(1)，d=2 → 绿(3)，d=3 → 黄(4)，d=4 → 橙(7)。
5. 所有红(2)标记像素叠加后的位置保留为红(2)，不受深度规则影响。
6. 输出网格大小与输入相同。叠加后未被任何精灵体覆盖的区域保持黑(0)。

**关键洞察**：输出中看不到任何单个精灵体的边界——可见的是若干颜色不同的嵌套区域，形似同心矩形环。这个环状结构是叠加产生的涌现效果，而非输入中的直接结构。求解者必须意识到输入中分散的矩形在叠加后的重合模式产生了输出的"等高线"图案。
