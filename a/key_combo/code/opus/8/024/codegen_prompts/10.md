## 新题 10：嵌套空心框按深度选择控制色填充

**组合逻辑**：[洪泛填充(flood_fill) + 封闭区域(enclosed_region)](已有) + [包围(enclosure)](创新：嵌套深度作为新的空间关系) → [列范围包含(column_span_contains) + 控制色决定填色(control_fill_color)](已有) → [图层优先级(layer_priority)](创新：嵌套深度决定填充优先级)

**来源原语**：洪泛填充/封闭区域/空心矩形/包围 ← c0f76784；列范围包含/控制像素/控制色决定填色 ← ddf7fa4f；图层优先级 ← 281123b4, e99362f0

**依赖链**：空心框检测 → 嵌套关系判定（哪个框包含哪个框） → 每个框的列范围匹配控制像素确定候选填充色 → 嵌套深度决定填充优先级（内层覆盖外层）。框的列范围可能包含多个控制像素（外层框范围宽），此时取嵌套深度最深的匹配作为该框的填充色。

**输入结构**：
- 约 15x15 的网格，背景为黑(0)。
- 3~5 个灰(5)空心矩形框（仅边框为灰，内部为黑）。部分框嵌套在其他框内部（内层框完全在外层框的内部空间中），嵌套深度最多 3 层。框的边框像素互不重叠。
- 顶行（第 0 行，不与任何框的边框重叠）有若干单像素控制标记，颜色互不相同，取自 {蓝(1), 红(2), 绿(3), 黄(4), 品红(6)}。
- 生成约束：每个空心框的列范围（左边框列到右边框列）恰好包含至少一个控制像素的列。最内层框的列范围恰好包含一个控制像素。外层框的列范围可能包含多个控制像素（因为它跨度更大，可能覆盖内层框对应的控制像素的列以及其他控制像素的列）。

**规则**：
1. 识别所有灰(5)空心矩形框（边框为灰的 4-连通矩形环，内部为黑或包含更小的框）。
2. 判定嵌套关系：若框 A 的边框完全在框 B 的内部空间中，则 A 是 B 的子框。建立嵌套树。根节点是最外层框（不被任何框包含）。
3. 对每个框，找到其列范围 [左边框列, 右边框列] 内所有控制像素。
4. 在匹配到的多个控制像素中，选择列坐标距该框中心列最近的那个控制像素（若距离相同，取列坐标较小的），该控制像素的颜色即为该框的填充色。
5. 从最外层框开始，由外向内逐层填充：将每个框的内部黑(0)像素填为其填充色。内层框的填充覆盖外层框的填充（内层优先）。
6. 灰(5)边框保持不变。控制像素保持不变。框外部的黑(0)背景保持不变。

**关键洞察**：外层框的列范围通常包含多个控制像素的列（因为它也覆盖了内层框对应的控制像素），因此不能简单取"范围内的唯一控制像素"——必须用最近距离规则选取。嵌套深度决定填充覆盖优先级：内层框的颜色总是覆盖外层框的颜色，使最终输出呈现出同心矩形环状的多色分层效果。
