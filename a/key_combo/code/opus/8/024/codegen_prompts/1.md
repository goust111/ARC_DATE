## 新题 1：行填充桥接改变连通分量存活

**组合逻辑**：[填充(fill)](创新：行填充充当结构桥梁) + [同色配对(same_color_pairing) / 两端同色整行填充(full_row_fill_endpoints_match)](已有) → [连通分量检测(connected_component_detection)](已有) → [面积阈值筛选(area_threshold_filter) / 重涂色(recolor)](创新：筛选在填充后的拓扑上执行)

**来源原语**：填充 ← 22eb0ac0；同色配对/两端同色整行填充 ← 22eb0ac0；连通分量检测/面积阈值筛选/重涂色 ← 12eac192

**依赖链**：行填充改变了像素的前景/背景属性 → 这改变了连通分量的拓扑结构（原本分离的小物体可能被填充色桥接为一个大连通体） → 面积阈值筛选在新拓扑上执行，决定哪些物体被重涂为绿(3)。填充步骤不仅是视觉变化，更是决定后续哪些物体"存活"的结构性操作。

行填充在两端同色行上涂色，可能将两个原本分离的小前景物体桥接为一个大连通体，使其面积超过阈值而避免被重涂为绿(3)；未被桥接的小物体则被重涂。

**输入结构**：
- 约 12x15 的网格，背景为黑(0)。
- 若干行的左右边界各有一个前景色标记像素（成对出现在同一行的第 0 列和最后一列）。每行的两个标记使用相同或不同的颜色，颜色取自 {蓝(1), 红(2), 黄(4)}。
- 网格内部散布着若干小型单色 4-连通前景物体（每个物体 1~4 像素），颜色取自 {蓝(1), 红(2), 黄(4), 橙(7)}。这些物体的颜色可能与某些标记颜色相同。
- 生成约束：至少存在两个小物体（各 1~2 像素），它们位于同一行或相邻行，且该行的左右标记颜色匹配。至少存在一个小物体不在任何匹配行附近。不同示例中物体的具体形态不同。

**规则**：
1. 复制输入网格。
2. 对每一行检查左右边界标记：若两端标记颜色相同，则将该行中所有黑(0)背景像素涂为该标记颜色（已有的前景像素保持不变）。若两端不同色或该行无标记，不做处理。
3. 在填充后的网格上，检测所有非黑(0)的 4-连通同色连通分量（将所有非黑像素视为前景，按颜色分别检测连通性）。
4. 对每个连通分量，计算其像素面积。面积为 1 或 2 的连通分量，将其所有像素重涂为绿(3)。面积 >= 3 的连通分量保持不变。
5. 边界标记像素本身参与连通分量检测——如果标记像素与填充行或其他前景像素同色且 4-连通，则属于同一连通分量。

**关键洞察**：行填充不只是装饰——它是拓扑桥梁。同色填充行将行内或相邻行的小物体合并为更大的连通体，使它们逃过面积阈值筛选。判断哪些物体被重涂绿色，需要先确定哪些行会被填充、填充如何改变连通结构。
