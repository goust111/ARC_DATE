## 新题 7：投票恢复精灵中的锚点驱动格内对角射线

**组合逻辑**：[投票恢复(majority_vote_recovery) + 密集带检测(dense_band_detection)](已有) → [实心正方形(solid_square) / 对角标记(diag_marker) 识别](创新：锚点从恢复结果中提取) → [射线延伸(ray_cast) + 对角邻接(diag_adjacency) + 锚角对角射线至边(anchor_diag_to_edge)](创新：射线限制在插槽内部) + [擦除(erase)](已有：清除槽外噪声)

**来源原语**：投票恢复/密集带检测/插槽阵列/精灵体/忽略干扰项 ← 0607ce86；射线延伸(ray_cast)/实心正方形/对角标记/对角邻接/锚角对角射线至边 ← 7ddcd7ec；擦除 ← 0607ce86

**依赖链**：密集带检测定位插槽 → 多插槽投票恢复标准精灵（含被噪声破坏的锚点） → 恢复的精灵中找到 2x2 锚和对角种子 → 在每个插槽内从锚点对角种子发射对角射线，射线止于插槽边界。噪声破坏了个别插槽的锚点，只有投票恢复才能可靠确定锚点位置。

**输入结构**：
- 约 23x23 的网格，背景为黑(0)。
- 蓝(1)前景像素构成一个 4x4 规则插槽阵列（共 16 个插槽）。每个插槽是一个 5x5 的矩形区域，插槽间由 1 像素宽的黑间隙分隔。
- 每个插槽包含同一精灵图案的一个副本（精灵使用蓝(1)像素，约 8~12 像素）。精灵内部包含一个 2x2 的实心蓝方块作为锚点，锚点的 1~2 个角有对角邻接的蓝像素（对角种子）。
- 约 2~4 个插槽中，精灵的 1~2 个像素被破坏（颜色错误或缺失），可能波及锚点或对角种子。
- 插槽外部有少量零星蓝(1)噪声像素。
- 生成约束：每个精灵像素位置，16 个插槽中至少 12 个是正确的（保证多数投票可靠）。

**规则**：
1. 通过行密度和列密度检测找到密集行带和密集列带，确定 4x4 插槽阵列的位置（密集带间的交叉区域为插槽）。
2. 对精灵边界框内的每个相对位置 (r, c)，统计 16 个插槽在该位置的颜色，取多数颜色作为标准值。得到标准精灵。
3. 在标准精灵中识别唯一的 2x2 实心蓝方块（锚点）。检查锚点四角的对角邻接位置：若该位置为蓝(1)，则标记为对角射线种子，射线方向为从锚点中心指向该对角的方向（如左上角有种子则方向为左上）。
4. 用标准精灵替换每个插槽内的内容。
5. 在每个插槽内，从每个对角种子出发，沿其方向逐像素延伸对角射线，涂为蓝(1)。射线遇到插槽边界时停止（不越过插槽间的间隙）。
6. 将所有插槽外的像素设为黑(0)，清除噪声。

**关键洞察**：个别插槽的噪声可能恰好破坏了锚点或对角种子，若直接在各插槽中识别锚点会得到错误结果。只有通过 16 个副本的多数投票恢复标准精灵，才能可靠确定锚点位置和对角种子方向，进而正确生成每个插槽内的对角射线。

print("variants", len(sigs))
