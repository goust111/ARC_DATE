## 新题 4：面板分层外推与重组

**组合逻辑**：[序列外推(sequence_extrapolation)](已有) + [透明叠加(transparent_overlay)](创新：每帧是两层叠加的合成结果) → [裁剪(crop)](已有) + [图层优先级(layer_priority)](创新：重叠色作为分层线索)

**来源原语**：序列外推/面板帧/分隔行/恒定偏移平移 ← 351d6448；透明叠加/图层优先级 ← 281123b4, e99362f0

**依赖链**：分帧 → 分层解码（黄色像素 = 两层重叠信号） → 每层独立追踪恒定平移 → 第 5 帧各层独立外推 → 按叠加规则重组合成帧。不分层则无法追踪各层独立运动；不外推则无法预测下一帧；不重组则输出不完整。

**输入结构**：
- 约 24x6 的网格。四个等大面板（每个约 5x6）纵向堆叠，相邻面板间由一整行灰(5)分隔行分开。
- 每个面板背景为黑(0)，包含蓝(1)和红(2)前景像素。部分像素为黄(4)。
- 蓝(1)像素构成一个 4-连通小图形（层 A），红(2)像素构成另一个 4-连通小图形（层 B）。黄(4)像素出现在层 A 和层 B 重叠的位置。
- 从第 1 帧到第 4 帧，层 A 以恒定偏移 (dr_A, dc_A) 平移，层 B 以恒定偏移 (dr_B, dc_B) 平移。两层的偏移通常不同。
- 生成约束：每帧中两层至少有 1 个像素重叠（产生黄色），以确保分层线索可见。每层的图形在所有 4 帧中均完整在面板内（不被截断）。第 5 帧外推后两层也完整在面板内。

**规则**：
1. 在灰(5)分隔行处将输入切分为 4 个面板。
2. 对每个面板进行分层解码：
   - 层 A 占据位置 = 蓝(1)像素位置 + 黄(4)像素位置（黄色表示两层重叠，层 A 在此存在）。
   - 层 B 占据位置 = 红(2)像素位置 + 黄(4)像素位置。
3. 对层 A，计算连续面板间的平移偏移 (dr_A, dc_A)。验证所有相邻帧间偏移一致。
4. 对层 B，同样计算恒定偏移 (dr_B, dc_B)。
5. 将层 A 和层 B 分别按各自偏移外推到第 5 帧位置。
6. 合成第 5 帧：仅层 A → 蓝(1)；仅层 B → 红(2)；两层均在 → 黄(4)；均不在 → 黑(0)。
7. 输出为单个面板大小的网格（不含分隔行）。

**关键洞察**：黄(4)不是独立物体，而是两层重叠的信号。必须将每帧分解为两层，才能独立追踪各层的运动规律并正确外推。直接对合成帧做整体外推会因重叠区的颜色变化而失败。
