## 新题 2：对称恢复揭示隐藏射线种子

**组合逻辑**：[对称补全(symmetry_completion)](已有) → [种子像素(seed_pixel) 发现](创新：种子藏在遮挡区域下) → [射线延伸(ray_extend)](已有，但种子来源为恢复结果) + [种子色决定延伸(seed_color_determines_extend)](创新：恢复的种子色决定射线方向)

**来源原语**：对称补全/二面体对称/遮挡矩形/可见副本恢复遮挡 ← f4081712；射线延伸/种子像素/种子色决定延伸 ← 178fcbfb

**依赖链**：对称恢复从遮挡区域中还原出种子像素的颜色 → 种子颜色决定射线延伸方向（红=垂直，蓝=水平） → 射线在完整恢复图上绘制。不执行恢复则缺少部分种子，射线图案不完整；不知道种子色与方向的映射则无法确定射线走向。

**输入结构**：
- 约 13x13 的正方形网格。整个图案在非遮挡区域具有正方形的二面体对称性（4 次旋转 + 4 次反射，共 8 个等价位置）。
- 前景图案使用灰(5)像素构成几何结构（4-连通边框或线段），背景为黑(0)。
- 图案中散布着少量红(2)和蓝(1)单像素，它们是射线种子。
- 一个绿(3)实心矩形（约 3x4 或 4x5 像素）遮挡了部分图案。被遮挡的区域下隐藏着灰(5)结构像素以及 1~2 个种子像素（红或蓝）。
- 生成约束：每个被遮挡的种子像素，其至少一个对称等价位置是可见的（未被遮挡），以保证可恢复。不同示例中遮挡矩形的位置不同，导致被隐藏的种子不同。

**规则**：
1. 对每个绿(3)像素，检查其在二面体对称群下的所有等价坐标。忽略等价坐标中同样被遮挡（绿色）的位置。剩余可见位置的颜色应一致，取该颜色作为恢复值。
2. 用恢复值替换所有绿(3)像素，得到完整的对称图案。
3. 在完整图案上，识别所有红(2)和蓝(1)单像素作为射线种子。
4. 对每个红(2)种子，沿垂直方向（上下）延伸射线：将该列上所有黑(0)背景像素涂为红(2)，遇到非黑像素时停止（不覆盖已有前景）。
5. 对每个蓝(1)种子，沿水平方向（左右）延伸射线：将该行上所有黑(0)背景像素涂为蓝(1)，遇到非黑像素时停止。
6. 若一个红射线和一个蓝射线交汇于同一个黑(0)像素，该像素涂为黄(4)。
7. 灰(5)结构像素和种子像素本身保持不变。

**关键洞察**：绿色遮挡不仅隐藏了图案结构，更隐藏了射线种子的存在和颜色。必须先通过对称恢复找到所有种子，才能正确生成射线图案；射线的交汇色（黄）又需要同时处理两种方向的射线。
