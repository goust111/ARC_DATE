## 新题 5：十字扩展后按列控制重涂色

**组合逻辑**：[射线延伸(ray_extend) → 十字图案(cross_pattern)](已有) + [交叉点重置背景(intersect_reset_bg)](已有) → [列范围包含(column_span_contains)](创新：用于十字而非矩形) + [控制色决定填色(control_fill_color)](创新：控制色作用于生成的十字臂)

**来源原语**：射线延伸/实心方块/十字图案/行列对齐/交叉点重置背景 ← e9bb6954；控制像素/列范围包含/控制色决定填色 ← ddf7fa4f

**依赖链**：3x3 方块 → 十字扩展（确定十字形状） → 交叉点重置（确定十字间的间隙） → 列范围匹配控制像素（确定每个十字的颜色）。十字必须先生成再着色，因为着色依据是原始方块的列位置而非扩展后的十字列位置。

**输入结构**：
- 约 15x15 的网格，背景为黑(0)。
- 2~4 个灰(5)实心 3x3 方块，各中心行互不相同且各中心列互不相同。方块间距至少 4 像素，保证十字交叉点在所有方块外部。
- 顶行（第 0 行）有若干单像素控制标记，颜色取自 {蓝(1), 红(2), 绿(3), 黄(4)}，每个控制像素颜色互不相同。
- 生成约束：每个 3x3 方块的列范围（中心列 -1 到中心列 +1）恰好包含一个控制像素的列坐标。控制像素不与任何方块在同一行。

**规则**：
1. 复制输入网格。
2. 对每个灰(5) 3x3 方块，将其中心行的所有像素（从列 0 到最右列）涂为灰(5)，将其中心列的所有像素（从行 0 到最底行）涂为灰(5)。方块本身已为灰色，保持不变。此步骤生成灰色十字臂。
3. 检查所有十字交叉点：若某像素同时在方块 X 的中心行和方块 Y 的中心列上（X != Y），将该像素重置为黑(0)背景。
4. 对每个 3x3 方块，找到列坐标落在其列范围 [中心列-1, 中心列+1] 内的那个顶行控制像素，取其颜色。
5. 将该方块及其生成的所有十字臂像素（不含已重置为背景的交叉点）重涂为步骤 4 确定的控制颜色。
6. 顶行控制像素本身保持不变。

**关键洞察**：十字的颜色不由方块自身决定，而由顶行控制像素的列位置决定——判断依据是控制像素的列是否落在原始 3x3 方块的列范围内（宽度仅 3 列），而非扩展后的全宽十字。交叉点重置创造的间隙使不同颜色的十字臂在视觉上分离。
