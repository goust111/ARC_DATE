## 新题 3：格元内射线可见性决定精灵重涂色

**组合逻辑**：[标记点阵(marker_lattice) / 格元(lattice_cell)](已有) → [射线延伸(ray_cast)](创新：射线限制在格元内部) + [障碍像素(obstacle_pixel)](已有) → [计数(counting)](已有) → [重涂色(recolor)](创新：命中数决定颜色)

**来源原语**：标记点阵/格元/格元内居中 ← 20981f0e；射线延伸/障碍像素/碰撞产生侧翼 ← 79fb03f4；计数 ← 6455b5f5；重涂色 ← ddf7fa4f

**依赖链**：点阵定义格元边界 → 格元边界限定射线传播范围 → 射线从精灵出发检测障碍可见性 → 可见障碍计数决定精灵新颜色。格元边界、精灵形状、障碍位置三者共同决定最终结果。

**输入结构**：
- 约 19x19 的网格，背景为黑(0)。
- 黄(4)单像素形成规则笛卡尔点阵，点阵间距相等（如每隔 5 列 5 行一个黄点），将网格划分为等大的矩形格元（约 4x4 或 5x5 内部空间）。
- 每个格元内部包含一个灰(5) 4-连通小精灵（3~6 像素，不同格元中形状可不同但颜色均为灰）。
- 部分格元内部还有 0~3 个红(2)单像素障碍，散布在精灵周围。
- 生成约束：每个格元内，精灵与障碍互不 4-连通。不同格元的障碍数量不同（含 0 个的情况）。精灵和障碍均不接触黄点阵标记。

**规则**：
1. 识别黄(4)点阵标记，确定格元边界。每个格元的内部区域是两个相邻黄标记之间的矩形空间（不含黄标记本身）。
2. 对每个格元，从灰(5)精灵的每个像素向四个基本方向（上、下、左、右）发射射线。射线在格元内部传播，逐像素前进，遇到以下情况停止：(a) 碰到红(2)障碍像素（记录该障碍为"被命中"），(b) 碰到黄(4)标记或格元边界，(c) 碰到灰(5)精灵自身的另一像素。
3. 统计该格元内被至少一条射线命中的**不同**红(2)障碍像素数量（同一障碍被多条射线命中只计 1 次）。
4. 根据命中数重涂精灵颜色：0 个 → 蓝(1)，1 个 → 绿(3)，2 个 → 橙(7)，3 个及以上 → 品红(6)。
5. 黄标记和红障碍保持不变。

**关键洞察**：精灵的颜色不仅取决于格元内有多少障碍，还取决于从精灵的具体形状能"看见"多少个障碍——一个障碍若被另一个障碍遮挡（从精灵所有像素出发的射线都先碰到前方障碍），则不被计入。精灵的几何形状直接影响可见性判定。
