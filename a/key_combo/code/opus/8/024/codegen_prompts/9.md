## 新题 9：长度排名着色与连接标记引导装配

**组合逻辑**：[排序(sorting) + 长度排名(length_ranking)](已有) → [重涂色(recolor) + 排名决定颜色(rank_determines_color)](已有) → [同色标记对齐对接(same_color_dock)](创新：对接目标的排列顺序独立于长度排名) + [裁剪(crop)](已有)

**来源原语**：排序/长度排名/细条/排名决定颜色/重涂色 ← ea32f347；同色标记对齐对接/连接标记/标记侧面决定方向/拼接/裁剪 ← e9fc42f2

**依赖链**：长度排名 → 条的颜色（排名决定视觉外观）。同时，每条的连接标记颜色与右侧对接列中的目标像素匹配 → 对接翻译确定条的空间位置。条的最终外观由排名决定，最终位置由对接决定——两个独立分类系统共同决定输出。

**输入结构**：
- 约 8x20 的网格，背景为黑(0)。
- 三条灰(5)水平细条（宽 1 像素），长度互不相同（如 3、5、7 像素），位于网格左半区的不同行。
- 每条细条的左端有一个彩色单像素连接标记，紧贴细条最左像素的左侧（即列坐标 = 细条最左列 - 1）。三个标记颜色互不相同，取自 {品红(6), 橙(7), 青(8)}。
- 网格最右列（最后一列）有三个彩色单像素，颜色与三个连接标记一一对应（同一组 {品红(6), 橙(7), 青(8)}），从上到下排列顺序任意（不同示例中排列不同）。
- 生成约束：三条细条的长度排名与连接标记颜色的排列无预设关系（最长条的标记不一定对应最上方的目标像素）。

**规则**：
1. 按长度排名重涂三条细条：最长 → 蓝(1)，中等 → 黄(4)，最短 → 红(2)。
2. 每条细条的连接标记颜色不变（品红/橙/青之一）。
3. 对每条细条，在最右列找到与其连接标记同色的目标像素。
4. 水平平移整条细条（含标记），使标记像素移到目标像素的左侧相邻位置（即标记列 = 目标列 - 1，标记行 = 目标行）。
5. 平移后，擦除最右列的目标像素和细条的连接标记像素（设为黑(0)）。
6. 输出为包含三条平移后细条的最小边界矩形，背景为黑(0)。

**关键洞察**：条的颜色由长度排名决定（最长=蓝，最短=红），但条的垂直位置由连接标记的对接决定——最右列目标像素的排列顺序独立于长度排名。因此颜色和位置由两套独立规则控制，输出中蓝/黄/红条的上下排列不可从长度排名直接推断，必须同时理解对接机制。
