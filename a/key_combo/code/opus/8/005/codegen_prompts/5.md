## 新题 5：控制列位移后按条纹方向修复十字遮罩

**组合逻辑**：[循环位移/cyclic_roll + 标记位定位移量](已有) → [擦除控制列](已有) → [填充修复/fill + 从平行行列推断](创新：修复依据是位移后的条纹位置，而非原始位置) + [条纹决定填充轴](创新：条纹方向决定修复时优先参考行还是列)

**来源原语**：循环位移+控制列+标记像素+行偏移编码+标记位定位移量(6d1d5c90)、十字遮罩+色块拼图+补全+从平行行列推断(b7955b3c)、条纹+顺序对应+条纹决定填充轴+排序(8e1813be)

**依赖链**：控制列中红色标记的行号 → 确定循环位移量 → 位移重排了条纹与遮罩的相对位置 → 修复遮罩时必须参考位移后而非原始的行列内容 → 条纹方向决定优先从同行还是同列的未遮罩像素推断。位移改变了修复的上下文，条纹方向改变了修复的策略。

读取控制列的位移量，循环移动主区域后，利用条纹方向决定按行或按列从未遮罩区域推断被遮罩像素的颜色。

**输入结构**：约 8x11 的网格。最左列为控制列：品红(6)背景中嵌有恰好一个红(2)标记像素。右侧 8x10 的主区域是一个由 2~4 种颜色构成的条纹拼图——若为水平条纹则每行一色，若为垂直条纹则每列一色，颜色从蓝(1)、绿(3)、黄(4)、橙(7)中选取。主区域中有 1~2 个灰(5)十字遮罩（3x3 的加号形状：中心像素 + 上下左右各一个像素，共 5 个灰像素），遮罩覆盖了底层条纹颜色。遮罩之间不重叠，且遮罩不接触主区域边缘（遮罩中心距边缘至少 2 像素）。生成约束：每条条纹在遮罩区域之外至少有一段连续的未遮罩像素可供推断。

**规则**：
1. 读取位移量：令 r = 控制列中红(2)像素的行号（0-indexed）。
2. 删除控制列：输出不含最左列，宽度减 1。
3. 循环位移：将主区域所有行整体向下循环位移 r 行（第 i 行内容移至第 (i+r) mod H 行）。
4. 判定条纹方向：在位移后的网格中，忽略灰(5)像素，检查非灰像素是否呈现水平条纹（同行非灰像素颜色相同）或垂直条纹（同列非灰像素颜色相同）。
5. 修复遮罩：将每个灰(5)像素替换为其应有的条纹颜色。若为水平条纹：每个灰像素取其同行中任一非灰像素的颜色。若为垂直条纹：每个灰像素取其同列中任一非灰像素的颜色。
6. 输出修复后的网格（不含控制列）。

**关键洞察**：同一个遮罩在位移前和位移后可能跨越不同的条纹，导致修复结果完全不同。求解者必须先理解位移机制（通过对比控制列标记位置与输出的条纹偏移），再理解条纹方向决定了修复策略，二者的顺序关系不可颠倒。
