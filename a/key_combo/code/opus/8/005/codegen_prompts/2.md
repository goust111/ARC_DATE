## 新题 2：字形解码驱动循环位移后的嵌套重涂色

**组合逻辑**：[解码/decode](已有) → [循环位移/cyclic_roll](创新：位移量由解码结果决定) → [重涂色/recolor + 最外层颜色继承/outermost_color_inheritance](创新：位移改变了包含关系，从而改变了继承源)

**来源原语**：解码+字形图案+位置映射(995c5fa3)、循环位移+控制列+标记位定位移量(6d1d5c90)、重涂色+矩形边框+严格包含+最外层颜色继承(7d1f7ee8)

**依赖链**：字形图案解码为数值 → 数值作为循环位移的偏移量 → 位移重排了嵌套矩形的相对位置 → 包含关系改变 → 内层矩形按新的最外层矩形颜色重涂。解码结果决定位移量，位移改变几何关系，几何关系决定涂色。三步环环相扣。

解码字形获得位移量，对嵌套矩形区域做循环位移，然后按位移后的包含关系将内层矩形重涂为其最外层容器的颜色。

**输入结构**：约 14x10 的黑(0)背景网格，水平分为左右两区。左区宽 4 列，包含一个 4x4 的字形图案：灰(5)底色中嵌有若干黑(0)像素形成特定掩码图案，共有四种可能的图案，分别编码数值 1、2、3、4（各图案中黑色像素的数量分别为 1、2、3、4 个，且位置固定可区分）。右区宽 10 列，包含 3~4 个不同颜色的单色矩形边框（仅绘制边框一圈像素，宽度为 1 像素），颜色从蓝(1)、红(2)、绿(3)、黄(4)中选取且互不相同。这些矩形在垂直方向上形成嵌套关系：最大的矩形跨越右区大部分高度，较小的矩形严格位于较大矩形的内部。所有矩形的左右边界相同（均贴合右区左右边缘），仅在上下边界位置上不同，从而形成纯垂直方向的嵌套。生成约束：最大矩形的高度等于右区总高度，各矩形的上下边框行互不重合。

**规则**：
1. 解码：识别左区 4x4 字形图案中黑色像素的数量和位置，映射到对应数值 r（1~4）。
2. 删除左区：输出仅包含右区内容（宽度减少 4 列）。
3. 循环位移：将右区内容整体向下循环位移 r 行。即原来第 i 行的内容移到第 (i+r) mod H 行，H 为右区高度。
4. 重建包含关系：在位移后的网格中，重新判定矩形边框的嵌套包含关系——若矩形 A 的边框完全位于矩形 B 的边框严格内部（不含边框重合），则 A 被 B 包含。注意：循环位移可能导致某些矩形边框被截断后出现在网格顶部和底部，此时该矩形不再构成完整边框，视为不参与包含关系的碎片，保持原色不变。
5. 重涂色：对每个仍然完整的被包含矩形，将其边框颜色改为包含它的最外层完整矩形的颜色。最外层矩形自身和碎片矩形保持原色。

**关键洞察**：循环位移的量由字形编码决定，而位移直接改变哪些矩形保持完整、哪些被截断成碎片，进而改变包含关系图。同样的嵌套矩形在不同位移量下会产生完全不同的重涂结果。求解者必须从多个示例中同时归纳出解码映射和位移对包含关系的影响。
