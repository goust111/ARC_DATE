## 新题 4：补全矩形的缺口由条纹颜色按轴向填充

**组合逻辑**：[补全/complete + 边界框推断 + 缺失像素补新色](创新：补全不是用固定新色，而是由条纹颜色决定) + [排序/sort + 条纹决定填充轴 + 顺序对应](创新：条纹颜色按位置顺序映射到补全区域的行或列)

**来源原语**：补全+不完整矩形+边界框推断+缺失像素补新色(6d75e8bb)、填充+排序+条纹+顺序对应+条纹决定填充轴(8e1813be)

**依赖链**：不完整矩形的边界框推断 → 确定需要补全的缺口区域 → 条纹方向决定缺口是按行填还是按列填 → 条纹按位置排序后的颜色序列决定每行/列的填充色。补全步骤定义了"哪些像素需要填"，条纹分析定义了"填什么颜色"和"按什么轴填"。二者共享同一区域，缺一不可。

检测不完整矩形的边界框，用条纹颜色按其方向和顺序填充缺口像素。

**输入结构**：约 12x12 的黑(0)背景网格。包含 1~2 个不完整的青(8)矩形轮廓（仅边框像素，边框宽度 1 像素），每个矩形的边框有若干像素缺失（被黑色替代），但剩余青色像素足以唯一确定该矩形的边界框。矩形之外的网格区域中存在 2~4 条完整的单色条纹——若为水平条纹则每条占满一整行，若为垂直条纹则占满一整列。同一网格中所有条纹方向一致（全水平或全垂直）。条纹颜色从红(2)、蓝(1)、绿(3)、黄(4)中选取，各条纹颜色不同。条纹不与矩形边框区域重叠。生成约束：每个矩形缺口区域的行数（水平条纹时）或列数（垂直条纹时）恰好等于条纹数量；多个矩形共享同一套条纹。

**规则**：
1. 边界框推断：对每个不完整矩形，找到所有青(8)像素的边界框，该框即为完整矩形的范围。
2. 识别缺口：在每个矩形的边界框范围内，边框位置上为黑(0)的像素即为缺口像素。
3. 条纹分析：找到所有条纹，判定方向（全为水平行或全为垂直列）。将条纹按位置排序——水平条纹按行号从小到大排，垂直条纹按列号从小到大排——得到有序颜色序列 C1, C2, ..., Ck。
4. 缺口填充：对每个矩形的缺口像素集合，按条纹方向分配颜色。若条纹为水平方向：将缺口像素按其所在行在矩形边界框中的相对行号（从上到下第 1、2、...行）分组，第 i 组中的所有缺口像素填充颜色 Ci。若条纹为垂直方向：将缺口像素按其所在列在矩形边界框中的相对列号（从左到右第 1、2、...列）分组，第 j 组填充颜色 Cj。此处相对行号/列号仅计算边框所在的行/列（即第 1 行 = 边框顶行，第 2 行 = 边框底行；对于高度 > 2 的矩形，左列和右列也计入，按从上到下/从左到右的顺序，仅统计边框像素所在的行或列）。
5. 保持原有青色像素和条纹不变，仅缺口像素被填充。

**关键洞察**：矩形的缺口位置分布在不同的行和列上，条纹的排列顺序决定了每个行/列的缺口获得什么颜色。求解者必须同时理解"边界框推断确定缺口在哪"和"条纹排序确定缺口填什么"，且条纹方向还隐式决定了分组维度（行 vs 列），需从不同方向的示例中归纳。
