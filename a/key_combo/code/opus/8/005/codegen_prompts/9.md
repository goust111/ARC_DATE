## 新题 9：边缘标记去噪后的对侧线段颜色互换

**组合逻辑**：[擦除/erase + 单像素分量移除 + 八连通判定](创新：去噪规则应用于网格边缘的标记像素而非内部像素) + [颜色互换/color_swap + 配对间像素互换 + 对边配对](已有，但配对集合依赖去噪结果)

**来源原语**：擦除+孤立像素+连通分量+单像素分量移除+八连通判定(42a50994)、颜色互换+标记像素+线段+网格边缘+对边配对+配对间像素互换(d2acf2cb)

**依赖链**：边缘上存在真标记和噪声标记 → 八连通去噪区分二者（真标记与同边其他标记八连通相邻，噪声标记孤立）→ 去噪后的标记集合决定哪些行/列被选中 → 被选行/列的内部像素执行颜色互换。噪声标记不去除则会选中错误的行/列，导致互换区域错误。

清除边缘上的孤立噪声标记后，将对侧标记对之间的线段像素做颜色互换。

**输入结构**：约 10x10 的网格，内部填充由黑(0)、青(8)、品红(6)、橙(7) 四种颜色构成的图案。网格四条边缘上分布若干黄(4)标记像素。标记分为两类：（a）"真标记"——同一条边上有至少一个其他黄色像素与其 8-连通相邻（即在边缘上形成 2~3 像素的小簇），且在对面的边缘上有对应的黄色像素簇（在同一行或同一列上）；（b）"噪声标记"——孤立的黄色像素，在同一条边上没有任何黄色 8-连通邻居。左右边缘上的成对标记簇选中对应的整行，上下边缘上的成对标记簇选中对应的整列。每条边缘上有 1~2 个真标记簇和 0~2 个噪声标记。生成约束：噪声标记所在的行/列在对面边缘上没有标记，因此即使不去噪也不会误配对——但去噪仍是必要的，因为噪声标记的存在会干扰簇的 8-连通判定（一个噪声标记若恰好与真标记相邻会改变簇的范围，进而改变选中的行/列范围）。

**规则**：
1. 边缘标记识别：提取网格四条边缘上所有黄(4)像素。
2. 八连通去噪：在每条边缘上，对黄色像素做 8-连通分量标记。删除大小为 1 的分量（将其恢复为该边缘位置在内部图案中应有的颜色，即若边缘像素原本就是图案的一部分，恢复为图案色；若原本是黑色背景则恢复为黑(0)）。保留大小 >= 2 的分量。
3. 配对：将左边缘上幸存的每个标记簇与右边缘上同行范围内的标记簇配对（簇占据的行范围有交集即配对）。将上边缘的标记簇与下边缘同列范围内的标记簇配对。
4. 选中区域：对每个配对的标记簇对，选中对应的行段（左右配对）或列段（上下配对）。行段 = 两个黄色端点之间的所有严格内部像素（不含端点本身）；列段同理。
5. 颜色互换：对每个选中区域内的严格内部像素，执行颜色互换：黑(0) ↔ 青(8)，品红(6) ↔ 橙(7)。
6. 黄色标记像素（包括去噪后保留的）保持不变，其余未被选中的像素保持不变。

**关键洞察**：噪声标记可能与真标记簇 8-连通相邻，导致簇的范围扩大（多选一行/列）。求解者必须在多个示例中观察到噪声标记有时紧邻真标记、有时远离真标记，才能归纳出"先去噪再配对"的正确顺序——而非"先配对再过滤"。
