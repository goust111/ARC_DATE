## 新题 6：接触侧与包含深度的双规则重涂

**组合逻辑**：[重涂色/recolor + 接触侧定色](创新：接触侧规则仅在接触条件满足时激活) ⊕ [重涂色/recolor + 最外层颜色继承](创新：继承规则仅在无接触时激活) + [填充/fill](创新：填充被重涂后矩形内的封闭空洞)

**来源原语**：重涂色+多色对象+侧边标记+面板区域+包含于+接触侧定色(c3fa4749)、重涂色+矩形边框+严格包含+最外层颜色继承(7d1f7ee8)、填充(c3fa4749/6d75e8bb)

**依赖链**：检测矩形的包含层级 → 对每个内层矩形判断是否接触外层容器的某一边 → 若接触：取接触边上的标记色重涂 → 若不接触：取最外层容器色重涂 → 重涂后矩形内部若有黑色空洞则填充为该矩形的新颜色。两条重涂规则由同一个几何条件（是否接触容器边）互斥激活，填充步骤依赖重涂结果。

在嵌套矩形中，接触容器边的矩形按接触标记色重涂，不接触的按最外层容器色重涂，最后填充内部空洞。

**输入结构**：约 15x15 的黑(0)背景网格。包含 1~2 个最外层矩形边框，每个最外层矩形的边框为单一颜色（从蓝(1)、红(2)中选取），边框宽度 1 像素。每个最外层矩形内部嵌套 2~3 个较小的单色矩形边框，颜色从绿(3)、黄(4)、品红(6)、橙(7)中选取且互不相同。内层矩形分为两类：（a）"接触型"——该矩形的某一条边恰好与其直接容器的某一条边完全重合（共享同一行或列的像素），且在该重合边上，容器的边框像素被替换为一种标记色（青(8)或灰(5)），标记色仅出现在这些重合位置；（b）"浮空型"——该矩形的四条边均不与容器的任何边重合，完全悬浮在容器内部。部分内层矩形的内部有若干黑(0)像素空洞（矩形内部并非全黑，而是边框围起的空区域）。生成约束：每个最外层矩形内至少有一个接触型和一个浮空型内层矩形；标记色在整个网格中仅出现在接触重合边上。

**规则**：
1. 包含分析：识别所有矩形边框，建立严格包含关系层级。最外层矩形 = 不被任何其他矩形严格包含的矩形。
2. 接触检测：对每个非最外层矩形，检查其四条边是否有某条边与其直接容器（包含它的最小矩形）的某条边完全重合。若重合边上存在标记色像素（颜色不同于容器边框原色和内层矩形原色），则该矩形为"接触型"，标记色即为该标记色。
3. 接触型重涂：将接触型矩形的所有边框像素重涂为其标记色。同时将重合边上容器的标记色像素也保持为该标记色。
4. 浮空型重涂：将浮空型矩形的所有边框像素重涂为包含它的最外层矩形的边框颜色。
5. 空洞填充：对每个被重涂的矩形，若其边框围起的内部区域存在黑(0)像素，将这些黑像素填充为该矩形重涂后的颜色。
6. 最外层矩形自身的边框和所有不属于任何矩形边框的像素保持不变。

**关键洞察**：同一个包含层级中的两个矩形，可能因为一个接触容器边而另一个不接触，从而被完全不同的规则重涂为不同颜色。求解者必须同时发现"接触→取标记色"和"不接触→取最外层色"这两条互斥规则，仅凭单一示例无法区分二者（可能所有内层矩形恰好都是同一类型）。
