## 新题 1：散落连线生成滑动障碍

**组合逻辑**：[连线/scatter_connect_side](创新：连线结果不直接输出，而是作为滑动障碍) + [裁剪/crop] + [滑动/slide] + [颜色决定方向/color_determines_direction]

**来源原语**：连线+散落像素+颜色对应边+矩形框(5daaa586)、滑动+可移动对象+载体区域+颜色决定方向(9b4c17c4)、裁剪(6cbe9eb8)

**依赖链**：散落像素的颜色决定它连接到矩形框的哪条边 → 连线产生从框边向内延伸的障碍线段 → 障碍线段限制内部可移动对象的滑动终点 → 载体颜色决定滑动方向。连线步骤的输出是滑动步骤的空间约束；载体颜色是滑动方向的编码。缺少连线则滑动终点不确定，缺少载体颜色则方向不确定。

从矩形框外的散落像素引出障碍线段，框内可移动对象沿载体颜色指定的方向滑动至障碍或框边停止。

**输入结构**：约 15x15 的黑(0)背景网格。中央有一个约 9x9 的矩形框，四条边各由一种颜色构成：上边蓝(1)、下边绿(3)、左边红(2)、右边黄(4)，四角像素颜色归属于水平边（即左上角和右上角为蓝(1)，左下角和右下角为绿(3)）。框外散落着 2~4 个孤立像素，每个像素的颜色与某条框边颜色相同，分布在该边的延长线方向上（即与该边在同一行或同一列）。框内部背景分为若干水平条带，每条带为蓝(1)或青(8)单色填充，条带之间无间隙地铺满框内区域。每条条带内嵌入恰好一个橙(7)色的 4-连通小图形（3~5 像素），该图形完全位于条带内部且不接触框边。生成约束：不同散落像素引出的障碍线段互不交叉；每个橙色图形在其滑动方向上至少有一条障碍线段或框边可以阻挡。

**规则**：
1. 裁剪：以矩形框的外边界为裁剪范围，仅保留框及框内内容，丢弃框外区域（散落像素的信息已通过下一步提取）。
2. 连线生障碍：对每个散落像素，从该像素位置沿垂直于其所属框边的方向向框内画一条单像素宽的线段，颜色为灰(5)，线段从框边内侧第一个像素开始，一直延伸到碰到第一个非条带背景色像素（即碰到橙色图形或另一条灰色障碍）前一格停止。若路径上无障碍，则延伸到对面框边内侧为止。
3. 滑动：对每个橙(7)色图形，根据其所在条带的颜色确定滑动方向——蓝(1)条带内的图形向右滑动，青(8)条带内的图形向左滑动。图形保持形状和所在行不变，整体水平平移，直到图形的边界框在滑动方向上碰到灰(5)障碍线段或框边内侧为止。所有图形同时移动（移动计算基于初始位置，不考虑其他图形移动后的位置）。
4. 擦除原位：图形滑动离开的原位置恢复为该条带的背景色。

**关键洞察**：散落像素的连线方向由框边决定，但连线的长度由框内容决定；滑动方向由条带颜色决定，但滑动距离由连线障碍决定。两组规则通过共享的框内空间紧密耦合，单独理解任一组都无法确定最终输出。
