## 新题 2：蛇径遍历顺序编号的分区着色

**组合逻辑**：[网格分区](已有) → [展直/遍历](已有，创新：遍历不输出序列，而是给穿越的区域赋予编号) → [计数](已有，创新：对编号做奇偶分类) → [重涂色](已有)

**来源原语**：蛇形路径(snake_path)、端点(endpoint)、遍历顺序(traversal_order) ← 7b5033c1；分隔线(separator_line)、网格分区(grid_partition) ← 6773b310；重涂色(recolor) ← 多源

**依赖链**：分隔线将网格划分为若干矩形区域。一条蛇形路径穿越部分区域，路径的拓扑遍历顺序为每个被穿越的区域赋予唯一编号。编号的奇偶性决定该区域的填充色——奇数区域涂红，偶数区域涂绿。遍历顺序依赖路径的空间走向而非区域的网格坐标。

蛇形路径穿过分隔网格的各区域，路径遍历的先后顺序决定区域编号，编号奇偶决定区域填充颜色。

**输入结构**：约16x18网格，背景为黑(0)。灰(5)色的完整行和完整列作为分隔线，将网格划分为3x3或4x3共9~12个矩形区域。一条蓝(1)色的4-连通蛇形路径在区域内部和分隔线间隙中穿行（分隔线上留有1像素宽的间隙供路径通过），路径有且仅有两个端点（仅一个路径邻居的像素）。每个区域内最多经过一段连续路径。生成约束：蛇径至少穿过6个不同区域；路径不分叉（严格单链）；两个端点不在同一区域内。

**规则**：
1. 识别灰(5)色完整行和完整列作为分隔线，将网格划分为矩形区域。
2. 找到蛇径的两个端点（仅有一个4-连通路径邻居的蓝色像素）。选择行号更小的端点作为起点；若行号相同则取列号更小的。
3. 从起点沿路径逐像素遍历。按遍历顺序记录路径依次进入的区域序列（同一区域仅在首次进入时记录），得到区域的访问编号（从1开始递增）。
4. 访问编号为奇数的区域：将该区域内所有背景像素（黑(0)）涂为红(2)。访问编号为偶数的区域：涂为绿(3)。
5. 未被蛇径穿过的区域保持黑(0)背景不变。蛇径像素保持蓝(1)不变。分隔线保持灰(5)不变。

**关键洞察**：区域的填充颜色不由其在网格中的空间坐标决定，而由蛇径穿越的拓扑顺序决定——即使空间上相邻的两个区域，如果蛇径的走向使它们的访问编号奇偶不同，颜色也不同。必须完整追踪蛇径才能确定每个区域的编号。
