## 新题 5：标记行分区后的像素计数蛇形压缩

**组合逻辑**：[稀疏标记线](已有，创新：用作分区边界而非镜像轴) → [计数](已有) → [排序](已有) → [蛇形填充](已有，创新：填充内容为区域主色而非单个标记色)

**来源原语**：稀疏标记线(sparse_marker_line) ← 66ac4c3b；计数(counting)、面积排序(area_ordering)、按像素数降序(descending_pixel_count) ← f8ff0b80；蛇形填充(boustrophedon_fill)、列序排列(column_order)、奇行反序(odd_row_reversed)、压缩(compress) ← cdecee7f

**依赖链**：含有灰色像素的稀疏行将网格分割为水平带状区域。计算每个区域内前景像素的总数并记录区域主色。按像素数降序排列各区域，将排序后的主色序列蛇形折叠填入紧凑矩阵。分区方式决定了区域划分，像素密度决定了排序，蛇形折叠决定了输出布局。

稀疏标记行将网格分为带状区域，按各区域前景像素数排序后蛇形折叠输出颜色序列。

**输入结构**：约16x14网格，背景为黑(0)。2~3条水平稀疏标记行（行内有若干灰(5)像素散布，其余为背景黑(0)，灰色像素数占该行宽度的30%~70%），将网格分为4~5个水平带状区域。每个带状区域包含一种主前景色（红(2)、蓝(1)、绿(3)、黄(4)、橙(7)中的一种）的若干散布像素，各区域主色互不相同。生成约束：各区域的前景像素总数互不相等；稀疏行的灰色像素位置随机分布，但同一行内至少有3个灰色像素以便识别为标记行。

**规则**：
1. 识别稀疏标记行：扫描所有行，若某行包含灰(5)像素且灰色像素数 >= 3，则该行为稀疏标记行。
2. 以标记行为边界，将网格划分为水平带状区域。标记行本身不属于任何区域。最顶部标记行之上为第一区域，相邻标记行之间为中间区域，最底部标记行之下为末尾区域。
3. 对每个区域，计算其中非背景(0)、非灰(5)的前景像素总数，并记录该区域中出现次数最多的前景色作为主色。
4. 按前景像素数从多到少排列各区域。
5. 将排序后的区域主色序列蛇形填充到一个 R x 3 矩阵中（R = ceil(区域数 / 3)）：第0行从左到右填入第1~3名的主色，第1行从右到左填入第4~6名的主色，依此交替。不足3个的行末尾填充黑(0)背景。输出该矩阵。

**关键洞察**：输出颜色的排列顺序既不反映区域在输入中的上下位置，也不对应颜色本身的任何固有属性——而是由各区域内像素的密度（前景像素总数）决定排名，再经蛇形折叠交替反转阅读方向。必须先正确识别稀疏标记行（它们不是完整分隔线，而是断续的灰色像素行）才能正确分区。
