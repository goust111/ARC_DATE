## 新题 4：图例计数反馈控制嵌套层反转深度

**组合逻辑**：[计数/counting + 填充图例/populate_legend](统计各色外层出现次数并填入图例) → [层序反转/layer_order_reversal](以计数值 T 为参数，仅反转外侧 T 层) — 统计结果回馈为变换深度参数，形成"频率越高则反转越深"的自激放大效应

**来源原语**：计数/counting(58490d8a), 填充图例/populate_legend(58490d8a), 层序反转/layer_order_reversal(8dae5dfc), 图例框/legend_box(58490d8a), 嵌套矩形层/nested_rect_layer(8dae5dfc), 颜色索引行/color_keyed_row(58490d8a), 计数映射点序列/count_to_dot_sequence(58490d8a), 嵌套层次/nesting_hierarchy(8dae5dfc), 颜色序列逆转/color_sequence_reversed(8dae5dfc)

**依赖链**：统计外层颜色出现频次 → 频次填入图例 → 频次数值作为每个嵌套矩形的反转深度参数 → 反转改变颜色分布。计数和反转之间存在信息闭环：同一颜色用于更多矩形的外层 → 产生更大的 T → 每个该色矩形被更深地反转。

统计各色作为嵌套矩形最外层的次数并记入图例，每个嵌套矩形根据其外层颜色的出现次数决定反转多少层。

**输入结构**：约 18x18 的网格，黑(0)背景。网格左侧或右侧有一个黑(0)边框围成的图例框（约 6 行高、8 列宽），框内左列有 2-3 个不同颜色的关键色像素，每个占一行，行间隔至少 1 行。网格其余区域散布 3-5 个嵌套矩形，每个由 2-4 层同心彩色矩形环组成（最外层是均匀单色矩形边框，向内逐层剥离可得到不同颜色的内层，最内层是实心矩形核心）。每个嵌套矩形的最外层颜色必须是图例中的某个关键色。生成约束：图例关键色不含黑(0)和橙(7)；不同嵌套矩形的最外层颜色可以相同；至少有一种关键色被 2 个以上嵌套矩形共用为最外层；每个嵌套矩形的层数至少为 2。

**规则**：
1. 对图例中的每个关键色，统计网格上有多少个嵌套矩形以该色为最外层。得到计数 T_c。
2. 在图例框中填写计数：每个关键色行上，从关键色像素右侧开始每隔一个单元格放置一个该色点像素，共放 T_c 个点。
3. 对每个嵌套矩形，查找其最外层颜色 c 对应的计数 T_c。将该矩形从外到内的前 min(T_c, L) 层颜色顺序反转，其中 L 为该矩形的总层数。第 min(T_c, L)+1 层及更深层颜色不变。
4. 处理顺序：按嵌套矩形的边界框面积从小到大依次处理。若面积相同，按边界框左上角从左到右、从上到下的顺序处理。

**关键洞察**：图例既是统计面板又是变换参数源——某种外层颜色越"流行"（被更多矩形使用），每个使用它的矩形就被更深地反转，形成"共享即不稳定"的反馈关系。仅看单个示例可能以为反转深度是固定的（如总是反转 2 层），必须对比不同计数的示例才能发现深度随计数变化。
