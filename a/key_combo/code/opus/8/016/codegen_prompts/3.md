## 新题 3：射线锁定竖直条的循环轮转

**组合逻辑**：[射线延伸/ray_extend](从框架缺口向上发射竖直射线，创新为竖直方向) + [循环移位/cyclic_shift](仅对未被射线命中的竖直条执行轮转) — 射线的空间到达性动态修改循环移位的参与集合

**来源原语**：射线延伸/ray_extend(e12f9a14, 创新：改为竖直方向而非对角线), 循环移位/cyclic_shift(2601afb7), 竖直条/vertical_bar(2601afb7), 带框块/framed_block(e12f9a14), 框架缺口/frame_gap(e12f9a14), 有序槽位/ordered_slots(2601afb7), 碰撞停止/collision_stop(e12f9a14), 色与高反向轮转/color_height_rotate(2601afb7)

**依赖链**：框架缺口位置 → 射线命中哪些竖直条 → 命中的条被锁定 → 循环移位仅在未锁定的条之间执行。射线的空间选择直接改变了轮转的参与者集合和映射关系，两步不可分离。

框架缺口向上发射射线命中的竖直条被冻结，剩余竖直条在它们自己的有序槽位中执行颜色右移、高度左移的循环轮转。

**输入结构**：约 14x20 的网格，黑(0)背景。上半区（约前 8 行）有 5-7 根底部对齐在同一基线行的竖直条，每根宽 1 像素、高 3-8 像素，各占不同列，颜色互不相同（从蓝(1)、绿(3)、黄(4)、品红(6)、橙(7)、青(8)、栗(9)中选取）。下半区（约后 6 行）有 1-3 个带框块：每个由一个 4x4 的灰(5)框围住一个 2x2 的单色内块组成，框的顶边有恰好一个缺口像素（缺口位置为该框顶边某一格的灰(5)被替换为黑(0)背景）。生成约束：每个缺口的列坐标恰好与某根竖直条的列对齐（正上方有条）；不同框架的缺口对齐不同的竖直条；至少有 2 根竖直条未被任何射线命中。

**规则**：
1. 每个框架的顶边缺口向正上方发射一条射线，颜色为该框架内 2x2 块的颜色。射线逐像素上行，遇到第一个非背景像素（即竖直条的最低像素）时停止（该像素不被射线覆盖）。射线经过的所有背景像素涂为内块颜色。
2. 被射线命中的竖直条（射线的终止点紧邻该条底部）标记为"锁定"。锁定条的颜色和高度不变。
3. 将所有未锁定的竖直条按从左到右的列顺序编入一个独立序列，编号 0, 1, 2, ...（共 n 根）。
4. 在该序列中执行循环移位：序列位置 i 的条获得位置 (i-1+n) mod n 的颜色，同时获得位置 (i+1) mod n 的高度。
5. 以新属性重新绘制所有竖直条（锁定条原样，未锁定条用轮转后的颜色和高度），底部对齐在原基线行。

**关键洞察**：射线是否命中竖直条取决于列对齐，而被命中的条退出循环移位池后，剩余条之间的映射关系完全改变——相同的初始配置在不同的锁定模式下产生截然不同的轮转结果。求解者必须先确定锁定集合，再在缩小的序列上执行双向轮转。
