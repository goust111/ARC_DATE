## 新题 2：杯形内部面积排序驱动调色 + 开口方向射线

**组合逻辑**：[洪泛填充](识别杯形内部区域) → [计数 + 排序](按内部面积排序) → [重涂色](排序结果映射色板) → [射线延伸](从开口方向向外发射已分配颜色的射线)

**来源原语**：杯形轮廓、开口、开口决定延伸向（d4f3cd78）；洪泛填充、封闭区域（7b6016b9）；计数、排序、按计数升序排列（d4c90558）；重涂色（b2862040）；射线延伸（981add89）

**依赖链**：洪泛填充产出各杯的内部面积 → 面积排序决定颜色分配 → 颜色分配决定射线颜色 → 开口方向决定射线走向。删掉计数/排序则无法确定颜色映射；删掉开口检测则射线无方向；删掉洪泛填充则无法获得面积。

按杯形内部面积从小到大排序后依次赋予色板颜色，并从各杯开口方向发射该颜色的射线。

**输入结构**：黑(0)背景网格，约 16x16。网格中有 3-4 个灰(5)杯形轮廓对象，每个由灰像素构成近封闭矩形框，框的某一侧有一个 1-2 像素宽的缺口（开口），不同杯的开口朝向不同（上、下、左、右均可能）。各杯的内部面积（被框围住的背景像素数）互不相同，范围约 4-20 像素。各杯互不相邻，距网格边缘至少 2 像素。网格最下方一行放置一排色板像素，从左到右依次为蓝(1)、红(2)、绿(3)、黄(4)（色板数量等于杯的数量），每个色板占 1 像素，彼此间隔 1 个黑像素。

**规则**：
1. 对每个灰(5)杯形轮廓，找到其边界框，将边界框内部通过杯壁封闭的黑(0)像素识别为该杯的内部区域（开口侧与外部连通的像素不算内部——如果开口被堵住则整个内部都算封闭，否则只有无法从开口逃逸的部分算封闭）。具体方法：将杯壁像素视为障碍，从开口向外做 4-连通洪泛，边界框内未被洪泛到达的黑像素即为内部。
2. 计算每个杯的内部像素数。
3. 按内部像素数从小到大排列所有杯。
4. 将排序后第 k 个杯（k 从 1 开始）的杯壁和内部像素全部重涂为最下方色板行的第 k 个颜色。
5. 对每个杯，检测其开口方向（上/下/左/右），从开口处沿该方向向网格边缘发射一条 1 像素宽的射线，颜色为该杯被分配的颜色。射线遇到其他杯的杯壁像素时停止（不覆盖该杯壁像素）。
6. 移除最下方色板行（输出中不包含色板）。

**关键洞察**：杯的颜色不由其空间位置或原始属性决定，而由所有杯的内部面积排名决定。求解者需同时推断面积→颜色映射规则和开口→射线方向规则，两者耦合在同一输出中——射线的颜色验证了面积排序，射线的方向验证了开口检测。
