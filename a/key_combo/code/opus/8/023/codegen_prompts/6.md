## 新题 6：双向控制像素射线交叉构墙 + 周期选区填充

**组合逻辑**：[射线延伸](从两条边的控制像素发射交叉射线) → [洪泛填充](射线交叉点形成墙，划分区域) → [排序 + 等间隔采样填充](区域排序后周期性选择着色)——动态分区结构

**来源原语**：射线延伸、控制像素、网格边缘（981add89）；洪泛填充、内外分区（7b6016b9）；排序、区域排列顺序、等间隔采样填充（7447852a）

**依赖链**：控制像素的位置决定射线走向 → 射线交叉形成网格状墙 → 墙的拓扑划分出若干背景区域 → 区域按位置排序后周期性选择填充。删掉射线则无墙、无分区；删掉周期选择则不知道填哪些区域。

从顶边和左边的控制像素发射交叉射线形成网格墙，然后对被墙划分出的区域做周期性着色。

**输入结构**：黑(0)背景网格，约 12x12。
- 顶边（第 0 行）有 2-4 个蓝(1)控制像素，分布在不同列。
- 左边（第 0 列）有 2-4 个红(2)控制像素，分布在不同行。
- 左上角 (0,0) 位置为黑(0)背景（不同时属于两组控制像素）。
- 网格其余位置为黑(0)背景。
- 生成约束：控制像素的行列不完全重叠，确保射线交叉产生至少 4 个封闭区域。

**规则**：
1. 每个顶边蓝(1)控制像素向下发射一条垂直射线，将该列从第 1 行到最后一行全部涂为蓝(1)。
2. 每个左边红(2)控制像素向右发射一条水平射线，将该行从第 1 列到最后一列全部涂为红(2)。
3. 蓝射线和红射线交叉的位置涂为绿(3)。
4. 射线像素（蓝、红、绿）视为墙。识别所有被墙和网格边界围住的 4-连通黑(0)背景区域。
5. 将这些区域按其边界框左上角坐标排序：先按行从上到下，行相同则按列从左到右。
6. 对排序后的区域列表，将索引为 0、2、4、6... 的区域（从 0 开始的偶数索引）洪泛填充为黄(4)，其余区域保持黑(0)。
7. 顶边和左边的控制像素自身保留原色。

**关键洞察**：射线不是输出的主角——它们动态构建了一张分区网格。增减一个控制像素会改变区域数量和排列，导致周期填充的结果发生非局部变化。求解者必须理解射线→分区→排序→周期选择的完整因果链。
