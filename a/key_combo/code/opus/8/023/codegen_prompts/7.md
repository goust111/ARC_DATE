## 新题 7：标记像素计数驱动同心正方形多步循环

**组合逻辑**：[计数](统计每个正方形内的标记像素数) → [缩放/边长循环变换](按标记数多次应用尺寸循环)——计数结果控制变换迭代次数

**来源原语**：缩放、边长循环变换、奇数边正方形、中心点、同心定位（522fdd07）；计数、标记像素、包含（d4c90558）

**依赖链**：标记像素数决定循环步数 → 循环步数决定最终边长 → 最终边长决定输出中正方形的大小。删掉计数则不知道循环几次；删掉循环规则则不知道如何变换尺寸。不同正方形的标记数不同，导致非均匀变换。

每个正方形内的灰色标记数决定其边长在奇数循环 (1-3-5-7-9) 中前进几步。

**输入结构**：黑(0)背景网格，约 21x21。网格中有 3-5 个互不重叠的单色实心正方形，每个边长为奇数（属于 {1, 3, 5, 7, 9}），颜色各不相同（使用蓝(1)、红(2)、绿(3)、黄(4)、品红(6)中的若干种）。部分正方形（边长 >= 3）的内部放置了若干灰(5)标记像素（占据正方形内部的背景色位置——即正方形本身为实心填充，灰标记像素覆盖在正方形像素之上）。标记像素数量为 1-4 个，不同正方形的标记数不同。边长为 1 的正方形不含标记（无空间放置），其标记数视为 0。
- 生成约束：每个正方形循环变换后不与其他正方形重叠（以各自中心和最终边长计算）。

**规则**：
1. 对每个彩色正方形，计算其内部（边界框范围内）的灰(5)标记像素数量 K。
2. 对该正方形的边长 S，应用 K 次缩小循环：每次将 S 替换为 S-2；若 S=1，则替换为 9（循环回卷）。即循环链为 9→7→5→3→1→9→7→...
3. 保持每个正方形的中心位置和颜色不变，仅将边长替换为循环后的新值。
4. 移除所有灰(5)标记像素（输出中不包含灰色）。

**关键洞察**：变换不是对所有正方形统一应用一次循环——每个正方形根据自身标记数循环不同步数。例如，一个 7x7 红正方形含 1 个标记 → 7→5（变为 5x5），而含 3 个标记 → 7→5→3→1（变为 1x1）。求解者需要同时发现循环规则和"标记数=步数"的隐蔽映射。
