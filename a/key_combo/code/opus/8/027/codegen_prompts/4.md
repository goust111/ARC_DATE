## 新题 4：障碍轮廓环上的竞争生长

**组合逻辑**：[轮廓描边/outline_trace](创新：轮廓不用于描边输出，而用作一维生长轨道) → [生长/grow + 交替变色/alternating_color](创新：沿轮廓环而非二维平面生长) → [面积分级/area_ranking](创新：面积不决定颜色，而决定碰撞优先级)

**来源原语**：轮廓描边 outline_trace + 外侧相邻 outer_adjacent (aa62e3f4), 生长 grow + 交替变色 alternating_color + 相邻间隔 adjacent_gap (af726779), 面积分级 area_ranking + 连通分量 connected_component (e8593010), 轮廓邻接 contour_adjacency + 障碍轮廓 obstacle_contour (97c75046)

**依赖链**：障碍的形状决定轮廓环的拓扑（一维闭合路径）；种子在轮廓环上的位置决定各方向上的可达空间；生长速度相同但碰撞优先级由种子面积排名决定——一个种子的面积排名影响的不只是它自己的边界，还会传递性地改变其他种子对的碰撞结果。

多个种子沿障碍外轮廓环向两个方向生长，碰撞时面积更大的种子吞并争议像素。

**输入结构**：
- 约 15x15 网格，黑(0) 背景。
- 一个大型不规则灰(5) 障碍（8-连通，约 20-40 像素）。障碍无孔洞，外轮廓形成单一闭合环路。
- 2-4 个"种子"分量：小型单色 4-连通分量（每个 1-3 像素），4-邻接于障碍边界。每个种子颜色不同，从 {红(2), 蓝(1), 绿(3), 黄(4)} 中选取。
- 各种子沿轮廓间隔放置，不相邻。
- 生成约束：所有种子的面积（像素数）两两不同。障碍外轮廓上的背景像素数量足够容纳所有种子的双向生长（即轮廓环长度 > 种子数 x 2）。

**规则**：
1. 计算障碍的外轮廓环：所有 4-邻接于至少一个灰(5) 障碍像素的黑(0) 背景像素的集合。按 4-连通顺序将其排列为一条闭合环路（从轮廓上最左上方的像素出发，沿顺时针方向排列）。
2. 每个种子"认领"轮廓环上与自身 4-邻接的所有像素，涂为该种子的颜色。若种子像素本身在轮廓环上，也计入。
3. 生长按离散轮回推进。每轮中，每个种子的领地沿轮廓环的两个方向各扩展一步（即领地边界的相邻未认领轮廓像素被涂为该种子颜色）。
4. 当两个种子的领地同时扩展到同一个轮廓像素时（碰撞），该像素归属于原始输入中 4-连通面积更大的种子。
5. 生长持续到轮廓环上所有像素均被认领。
6. 障碍像素（灰(5)）和不在轮廓环上的背景像素保持不变。种子的原始像素（若不在轮廓环上）保持原色。

**关键洞察**：生长并非在二维平面扩散，而是沿轮廓环的一维闭合路径推进——两个种子在欧氏距离上很近但在轮廓路径上很远时，碰撞位置与直觉相反。面积排名是需要对比多个示例才能归纳的隐蔽规则：单看一个示例，碰撞结果可能恰好与位置顺序一致。
