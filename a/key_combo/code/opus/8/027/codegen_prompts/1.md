## 新题 1：射线穿越序定义线段链式换色

**组合逻辑**：[连线/line_drawing] → [射线延伸/ray_extend](创新：射线穿越顺序本身生成置换规则) → [重涂色/recolor + 链式替换/chain_replace](创新：置换规则由射线交叉序动态产生，而非来自静态图例)

**来源原语**：连线 line_drawing (070dd51e), 射线延伸 ray_extend (2f767503), 同色配对 same_color_pairing (070dd51e), 标记条 marker_bar + 控制像素 control_pixel (2f767503), 链式替换 chain_replace (e4888269), 纵线覆盖横线 vertical_over_horizontal_priority (070dd51e)

**依赖链**：同色像素对的位置决定线段的走向和交叉结构；射线方向由控制像素确定，射线与线段的交叉顺序随线段拓扑变化；交叉顺序本身构成循环颜色置换规则，再回头作用于所有线段——线段拓扑→交叉序→置换规则→线段颜色，形成闭环依赖。

将同色像素对连成线段后，以标记条发出的射线穿越线段的先后顺序，生成一个循环颜色置换，应用于全部线段。

**输入结构**：
- 约 18x18 网格，黑(0) 背景。
- 4-6 对同色前景像素标记。每种颜色恰好出现 2 个像素，颜色从 {红(2), 蓝(1), 绿(3), 黄(4), 品红(6), 栗(9)} 中选取。每对像素共享同一行或同一列（不会对角放置）。
- 一根 3 像素长的灰(5) 直线标记条（水平或垂直放置）。一个橙(7) 像素 4-邻接于标记条的中心像素，位于标记条的某一端。
- 生成约束：当按规则步骤 1 画出所有线段后，射线（从标记条中心沿远离橙像素方向延伸至网格边界）至少穿越 2 条线段，但不穿越全部线段（即至少有一条线段不被射线穿越）。各对标记像素互不重叠、互不与标记条/控制像素重叠。

**规则**：
1. 对每一对同色像素，画出连接它们的轴对齐线段（含两端点）。若两条线段在某像素重叠，垂直方向的线段覆盖水平方向的线段（即交叉点显示垂直线段的颜色）。
2. 确定射线方向：从标记条中心像素出发，沿远离橙(7) 控制像素的方向延伸一条直线至网格边界。例如橙像素在标记条中心的左侧，则射线向右延伸。
3. 找出射线经过的所有像素位置。若某条线段至少有一个像素落在射线路径上，则该线段被射线"穿越"。
4. 按射线首次接触各线段的距离（距标记条中心的步数），从近到远排列所有被穿越的线段，得到有序序列 [S1, S2, ..., Sk]。
5. 该序列定义一个循环颜色置换：S1 的颜色映射到 S2 的颜色，S2 的颜色映射到 S3 的颜色，...，Sk 的颜色映射到 S1 的颜色。
6. 将此循环置换应用于网格上**所有线段**的像素（包括被穿越和未被穿越的）。若某线段的颜色不在置换映射中（即该线段未被穿越、其颜色也不等于任何被穿越线段的颜色），则该线段颜色不变。
7. 擦除灰(5) 标记条和橙(7) 控制像素（设为黑(0)）。
8. 原始标记像素对保留在原位（已被线段覆盖的情况下，颜色随线段一起变化）。背景像素不变。

**关键洞察**：射线并不擦除或高亮线段，而是用穿越顺序构造出一个循环颜色置换规则，再全局应用。不同的射线方向会产生不同的穿越序列，从而生成完全不同的置换——改变控制像素的位置就会改变所有线段的最终颜色。

1. `main(grid)` 必须实现新题描述中的确定性转换规则，不能只识别 `generate_input()` 的固定模板。禁止不同的input网格输出相同的output网格。

3. 生成器必须保证输入满足 `main()` 的隐式假设：对象不重叠、不越界、特殊标记唯一或可区分、匹配关系无歧义、关键分支出现概率相同。
4. 禁止把 ARC 颜色 id 、亮度、拼写等当作人类不可见的数值语义参与排序、大小比较或隐藏映射。颜色变化必须有可见结构线索。注意颜色亮度、拼写等也是不可见信息，若描述中出现违规的颜色id或者亮度，可自行使用少量的固定颜色替代，但注意生成时要在三个以内输入输出网格中对所有变换100%覆盖度。

6. 若规则有多个分支，生成器不能长期固定成一个分支；应让分支在随机样例中合理出现。分支概率不必平均——难以发现的隐蔽分支（如少数情况下才触发的特殊规则）应适当提高出现概率，确保在 3 个训练示例中至少出现一次，否则求解者无法归纳该规则。对于颜色映射类规则，确保 2 个左右的示例即可覆盖所有映射关系（每种颜色→颜色的映射至少在某个示例中出现过）。
