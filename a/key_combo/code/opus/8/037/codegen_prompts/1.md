## 新题 1：边框色决定镜像轴，连通性门控重涂色

**组合逻辑**：[颜色匹配边](创新：匹配结果不再决定平移方向，而是决定镜像轴) + [镜像](创新：镜像方向由外部条件而非标记臂决定) + [连通性/面积判断](创新：判断条件从原始面积变为镜像后的合并结果) → [重涂色]

**来源原语**：颜色匹配边/边框边(5034a0b5)、镜像(9bebae7a)、连通分量/连通性(e0fb7511)、重涂色(e0fb7511)

**依赖链**：边框侧色与精灵色的匹配结果决定该精灵的镜像轴方向；镜像操作后，原件与镜像副本是否4-连通合并为一个分量，又决定了该精灵是否被重涂色。三步之间任一环节缺失都无法确定最终输出。

将散布在彩色边框内的精灵沿其匹配边框侧对应的轴镜像，然后根据原件与副本是否连通来决定是否将合并体重涂为强调色。

**输入结构**：
- 约 15x15 的网格，黑(0)背景。
- 网格最外一圈为一像素宽的矩形边框，四条边（不含四个角像素）各为一种不同颜色，从上/右/下/左分别为红(2)、蓝(1)、绿(3)、黄(4)。四个角像素为黑(0)。
- 边框内部散布 3~5 个互不相邻的单色4-连通小图形（3~8像素），每个图形的颜色恰好是四种边框侧色之一。
- 每个图形与其匹配边框侧之间有足够空间放置镜像副本（生成约束：图形的边界框沿镜像方向到匹配边框侧的距离不小于图形在该方向的跨度）。
- 不同图形的镜像副本放置后互不重叠（生成约束）。

**规则**：
1. 确定每个内部图形的颜色所匹配的边框侧。匹配上侧(红(2))或下侧(绿(3))的图形，其镜像轴为水平轴（沿图形边界框的水平中线上下翻转）；匹配左侧(黄(4))或右侧(蓝(1))的图形，其镜像轴为垂直轴（沿图形边界框的垂直中线左右翻转）。
2. 将镜像副本放置在原件的匹配边框侧方向上、紧邻原件边界框（副本的近侧与原件的远侧相距1像素）。例如匹配上侧的图形，副本放在原件正上方紧邻处。
3. 检查原件与其副本是否通过4-连通相连（即合并后是否为同一个4-连通分量）。
4. 若原件与副本4-连通合并，将整个合并体重涂为橙(7)。若未合并（原件与副本不相连），两者均保留原色不变。
5. 边框本身保持不变。

**关键洞察**：是否重涂取决于镜像后原件与副本的连通性——只有沿镜像轴对称且在轴线处有像素相邻的图形才会合并，这要求求解者同时理解镜像方向规则和连通性判断，且只能通过对比多个示例（有的合并有的不合并）来确认判据。
