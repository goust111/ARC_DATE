## 新题 10：最近对连线后线段长度编码精灵体缩放倍率

**组合逻辑**：[连线 + 最小间距对触发](已有，创新：连线产生的不是视觉连接而是一个度量值) + [像素放大/pixel_scaling](创新：缩放倍率由连线长度决定而非固定) + [裁剪 + 拼接](已有)

**来源原语**：连线/connect + 最小间距对触发/min_gap_triggered + 对称标记对/mirrored_marker_pair + 间隔段/gap_segment + 中轴对称/center_axis_symmetry（5ad8a7c0）、像素放大/pixel_scaling（4522001f）、裁剪/crop + 拼接/concatenate（28bf18c6）、精灵体/sprite（28bf18c6）

**依赖链**：找到最近标记对 → 计算间距（连线段长度） → 间距值作为缩放因子 → 对精灵体执行等比放大 → 裁剪输出。删除间距计算则缩放因子不确定；删除缩放则间距信息无处使用；删除精灵体裁剪则无操作对象。

在对称标记行中找到间距最小的一对，用该间距值作为倍率放大网格中的精灵体。

**输入结构**：约 16x16 网格，黑(0)背景。网格分为两个功能区域（无显式分隔，靠空间位置区分）：
- 标记区（网格上半部分）：3-5 行，每行有两个红(2)像素关于网格垂直中轴对称放置。不同行的两个标记之间的水平间距不同（间距 = 两标记之间的背景像素数量，范围 2-6）。
- 精灵区（网格下半部分）：一个小型多色精灵体（使用蓝(1)、绿(3)等非红非黑颜色，约 2x2 到 3x3 像素，形态不规则，4-连通）。

不同示例中标记行的间距分布不同，精灵体形态和颜色也不同。生成约束：最小间距值在所有标记行中唯一（无并列最小值）；精灵体放大后不超出合理网格尺寸（最小间距 * 精灵体边界框尺寸 ≤ 20）。

**规则**：
1. 在标记区中找到所有红(2)标记行，每行有且仅有两个红(2)像素。
2. 计算每行两标记之间的水平间距 G（间距 = 两标记列号之差 - 1，即中间背景像素数）。
3. 找到间距最小的行，记其间距为 G_min。
4. 将该最小间距行的两个标记用红(2)连线（填充中间所有像素为红(2)）。其他标记行保持不变。
5. 裁剪精灵体到其最小边界框。
6. 将精灵体等比放大 G_min 倍：每个原始像素变为 G_min x G_min 的同色方块。
7. 输出仅为放大后的精灵体（丢弃标记区和原始背景，输出网格尺寸 = 精灵体边界框尺寸 * G_min）。

**关键洞察**：在源题中，最小间距对触发的是连线填充操作——连线是最终目的。此处连线仅是中间步骤，其真正作用是产出一个数值（间距长度），该数值成为另一个完全不同的操作（像素放大）的参数。求解者必须跨越两个看似无关的区域建立联系：上半部分的标记间距控制下半部分精灵体的放大倍率。单个示例中间距值和放大倍率的对应可能被误解为巧合，需要多个示例才能确认。
