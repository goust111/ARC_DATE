## 新题 4：引导三角定射线方向，多米诺定射线颜色

**组合逻辑**：[射线延伸 + 引导体](已有) + [擦除](已有) + [双色多米诺 + 四邻接配对](创新：多米诺不再执行配对变色，而是作为颜色选择器为射线提供颜色信息)

**来源原语**：射线延伸/ray_cast + 引导体/guide_object + 引导体定新对角线/guide_tip_seeds_parallel_diagonal（a78176bb）、擦除/erase（a78176bb）、对角线段/diagonal_segment（a78176bb）、双色多米诺/bicolor_domino + 四邻接配对/four_neighbor_pairing（d90796e8）、平行偏移/parallel_offset（a78176bb）

**依赖链**：引导三角的尖端 → 确定新对角线的位置和方向。多米诺中哪个颜色像素更靠近该三角 → 确定该对角线的颜色。两套信息分别回答"在哪画"和"用什么色画"。删除引导三角则不知道画在哪；删除多米诺则不知道用什么颜色；删除擦除则输出保留了辅助标记。

灰色三角标记新对角线的位置，每个三角旁的红绿多米诺中朝向三角的那个颜色决定该对角线的着色。

**输入结构**：约 16x16 网格，黑(0)背景。一条蓝(1)对角线段（从左上到右下或从右上到左下，长度 5-8 像素）。2-3 个灰(5)直角三角形对象（每个 3-6 像素，4-连通），每个三角形的一条直角边紧贴蓝色对角线。每个灰色三角形附近（不接触三角，但 8-邻域距离 ≤ 3）有一个红(2)-绿(3)多米诺（2 像素的 4-连通对，一个红一个绿）。不同示例中三角形数量、位置、多米诺朝向不同。生成约束：每个多米诺与恰好一个三角形最近（不会产生歧义配对）；多米诺的红、绿像素到其配对三角形的最近距离不相等（保证颜色选择无歧义）。

**规则**：
1. 保留原始蓝(1)对角线不变。
2. 对每个灰(5)三角形，找到其远离蓝色对角线的最远端尖端像素（与源题 a78176bb 相同的逻辑）。
3. 过该尖端像素画一条与原对角线平行的对角线，向两端延伸至网格边界。
4. 该新对角线的颜色由配对多米诺决定：找到距离该三角形最近的红绿多米诺，计算多米诺中红(2)像素和绿(3)像素分别到三角形最近像素的切比雪夫距离，取距离更小的那个颜色作为新对角线的颜色。
5. 擦除所有灰(5)像素（三角形移除）。
6. 保留所有多米诺像素不变。
7. 新对角线之间若交叉，交叉像素取后绘制的颜色（按三角形尖端行号从小到大的顺序绘制）。

**关键洞察**：在源题中，引导三角仅提供位置信息，射线颜色继承自原对角线；多米诺则只关心自身配对变色。此处两个原语产生全新的结构关系——三角提供"在哪里"，多米诺提供"用什么颜色"，两者必须配对解读才能确定每条新对角线的完整属性。

<description>
Recolor each closed orthogonal line loop so convex bend pixels are yellow and concave bend pixels are red.

Input structure
- The grid has a dominant background and exactly one foreground color.
- The foreground forms one or more 4-connected one-pixel-wide closed cycles; every foreground pixel has degree 2.
Rule
- Trace each cycle and inspect the turn at each foreground pixel.
- Straight pixels keep the original foreground color.
- Bend pixels whose turn direction is the majority direction for that cycle are convex corners and become yellow.
- Bend pixels whose turn direction is the minority direction for that cycle are concave corners and become red.
Key insight
- A simple rectilinear closed boundary has exactly four more convex bends than concave bends, so convexity can be inferred structurally from the majority turn sign within each traced cycle.
