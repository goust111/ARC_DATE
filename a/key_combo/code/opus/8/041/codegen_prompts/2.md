## 新题 2：孔洞数编码印章方向

**组合逻辑**：[计数（孔洞）](已有) + [印章覆盖](已有，创新：方向由孔洞数决定而非中心颜色匹配) + [颜色匹配](创新：边缘标记教学方向映射)

**来源原语**：计数/counting + 孔洞数映射/hole_count_to_color_mapping（37d3e8b2）、印章覆盖/stamp_repeat（985ae207）、颜色匹配/color_match（985ae207）、封闭背景区域/enclosed_background_region（37d3e8b2）

**依赖链**：孔洞计数 → 查找方向映射 → 确定印章方向和目标颜色 → 执行印章覆盖。删除孔洞计数则方向不确定；删除边缘标记则映射不可学习；删除印章覆盖则无输出动作。

统计每个前景对象内部的封闭孔洞数，以此决定该对象向哪个方向复制印章，印章颜色取自对应边缘的方向标记。

**输入结构**：约 21x21 网格，黑(0)背景。网格中有 3-4 个蓝(1)的 4-连通前景对象，每个约 5-10 像素，形态不规则（非矩形），各自封闭 0-3 个背景孔洞（4-连通封闭区域）。网格四条边的中点各有一个单像素方向标记：顶边中点为红(2)，右边中点为绿(3)，底边中点为黄(4)，左边中点为橙(7)。不同示例中对象形态不同但孔洞数范围不变。生成约束：每个对象的孔洞数互不相同（0、1、2、3 各出现一次，若对象不足 4 个则从中取子集）；对象之间以及对象与网格边缘之间留有足够空间容纳至少 2 个印章副本。

**规则**：
1. 统计每个蓝(1)对象内部的 4-连通封闭背景区域数量（孔洞数 H）。
2. 孔洞数映射到方向标记：H=0 → 顶边标记（红(2)，方向=上），H=1 → 右边标记（绿(3)，方向=右），H=2 → 底边标记（黄(4)，方向=下），H=3 → 左边标记（橙(7)，方向=左）。
3. 将每个对象沿映射方向复制印章：以对象边界框在该方向的尺寸为步长，逐次平移复制，直到下一个副本的边界框会超出网格边界时停止。
4. 每个印章副本的颜色替换为对应方向标记的颜色（例如 H=0 的对象，副本涂红(2)）。原始对象保持蓝(1)。
5. 移除四个边缘方向标记像素。
6. 多个对象的印章副本若发生重叠，按孔洞数从小到大的优先级绘制（孔洞数大的后绘制，覆盖前者）。

**关键洞察**：在源题 37d3e8b2 中，孔洞数映射到颜色；在源题 985ae207 中，中心像素颜色匹配目标矩形决定方向。此处孔洞数不再直接映射颜色，而是编码方向——颜色由方向标记间接提供。求解者必须对比多个示例才能归纳出"孔洞数→方向"的映射关系，因为边缘标记的颜色和位置需要跨示例才能确定。
