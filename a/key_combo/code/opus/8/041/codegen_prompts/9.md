## 新题 9：对称补全产生的新边界驱动外轮廓着色

**组合逻辑**：[对称补全（凸起/缺口）](已有) + [描边/outline](已有，创新：轮廓在补全后的形状上描绘，而非原始形状) + [区域可达性](已有，创新：补全改变了边界形态，从而改变了外轮廓的拓扑)

**来源原语**：对称补全/symmetric_complete + 凸起/tab + 缺口/notch + 边界/boundary + 对侧互补/opposite_side_complement + 跨行列投射/cross_span_projection（8dab14c2）、描边/outline + 外部邻接区域/exterior_adj_region（543a7ed5）、区域可达性/region_reachability（543a7ed5）

**依赖链**：识别 tab 和 notch → 执行对侧互补补全 → 补全后形状的边界轮廓与原始不同 → 在补全后的形状上描绘外轮廓。删除对称补全则不知道最终形状；删除外轮廓则补全后无新标记；两步通过"形状变化改变轮廓"紧密耦合。

先完成前景对象的 tab-notch 对称补全，再对补全后的整体形状描绘外轮廓。

**输入结构**：约 15x15 网格，黑(0)背景。一个蓝(1)的厚矩形前景对象（约 8x10 像素），边界上有 2-4 个凸起（tab，1 像素突出的前景像素，只有 1 个 4-邻接前景邻居）和对应数量的缺口（notch，1 像素切入的背景像素，有 3 个 4-邻接前景邻居）。凸起和缺口不一定已经成对出现在对侧——部分凸起的对侧可能没有缺口（需要补全），部分缺口的对侧可能没有凸起（也需要补全）。不同示例中凸起/缺口的数量、位置和分布不同。绿(3)和黄(4)在输入中不出现。生成约束：凸起和缺口各自通过跨行/列投射可以唯一确定对侧位置。

**规则**：
1. 对称补全（与源题 8dab14c2 相同）：
   - 每个凸起（tab）：在其跨行/列投射的对侧移除一个前景像素，形成配对缺口。
   - 每个缺口（notch）：在其跨行/列投射的对侧添加一个前景像素，形成配对凸起。
   - 紧邻凸起的缺口不作为独立源处理。
2. 在补全后的前景形状上执行外轮廓描绘：
   - 所有与前景像素 8-邻接的外部背景像素 → 涂绿(3)。
3. 补全后新产生的凸起位置（由缺口补全产生的新前景像素）→ 该像素本身保持蓝(1)，但其外侧轮廓像素涂黄(4)而非绿(3)。即：8-邻接于新增凸起像素的外部背景像素涂黄(4)。若某轮廓像素同时 8-邻接原始前景和新增凸起，涂黄(4)（黄优先）。
4. 原始前景像素和补全后仍存在的前景像素均保持蓝(1)。
5. 因凸起补全而被移除的像素恢复为背景色，若其 8-邻接剩余前景，则涂绿(3)轮廓色。

**关键洞察**：轮廓的颜色区分（绿 vs 黄）编码了"这部分边界是原始的还是补全产生的"。求解者必须先完成对称补全改变形状，再在新形状上描轮廓，并且发现黄色轮廓标记了补全引入的新边界——这层信息在源题中的任何一道都不存在。单看一个示例可以发现轮廓存在两种颜色，但必须对比多个示例中哪些位置是原始 vs 补全才能归纳出颜色分配规则。
