## 新题 5：同色物体滑向匹配墙壁后紧凑排列涌现孔洞，孔洞触发重涂与描边

**组合逻辑**：[滑动](同色墙壁吸引，碰撞阻挡) → [洪泛填充](创新：孔洞不是预设的而是滑动紧凑排列后涌现的) → [重涂色](有孔触发重涂) → [描边](对最终构型绘制轮廓)

**来源原语**：滑动+墙壁列+前景物体+同色物体朝同色墙+近者优先不重叠+碰撞停止（f0100645）；洪泛填充+封闭区域+包含+面积奇偶定填充色（868de0fa）；重涂色+封闭孔洞+有孔触发重涂（aa4ec2a5）；描边+draw_outline（aa4ec2a5）

**依赖链**：物体按距离顺序滑向匹配墙壁并碰撞停止 → 紧凑排列后不规则形状之间涌现背景孔洞 → 孔洞存在性触发参与围合的物体重涂 → 孔洞被填充 → 最终构型被描边。孔洞在输入中不存在，是滑动紧凑排列的涌现效果。

将不规则物体滑向同色墙壁紧凑排列，检测排列涌现的封闭孔洞，重涂围合物体并描边。

**输入结构**：约 15x15 的灰(5)背景网格。最左列全部填蓝(1)为左墙壁，最右列全部填红(2)为右墙壁。内部散布若干蓝(1)的 8-连通小物体（每个 3~6 像素，非矩形不规则形状）和若干红(2)的 8-连通小物体（同规格）。物体互不相邻，与墙壁不相邻。生成约束：至少一侧墙壁的物体滑动紧凑排列后会形成至少 1 个 4-连通灰(5)封闭区域（被墙壁和/或物体完全围合的背景区域）。

**规则**：
1. 清除所有内部（非墙壁列的）非背景像素为灰(5)。
2. 对蓝(1)物体，按其 8-连通边界框中心到左墙壁的水平距离从近到远排序处理：将每个物体水平向左平移，直到物体任一像素的左邻为墙壁像素或已安置的同色物体像素，停止。保持物体形状不变。
3. 对红(2)物体，按其到右墙壁距离从近到远排序处理，类似向右平移直到碰墙壁或已安置同色物体。
4. 所有物体安置完毕后，检测内部所有 4-连通灰(5)背景区域。若某灰色区域不与网格边界（除墙壁列外的边界行/列）相连，则为"封闭孔洞"。
5. 将每个封闭孔洞填充为品红(6)。
6. 将所有 4-邻接于任何封闭孔洞的物体像素重涂为青(8)（不论原为蓝或红）。未邻接孔洞的物体像素保持原色。
7. 对每个最终的非背景连通簇（包括墙壁、物体、青色像素、品红孔洞），绘制 1 像素宽的黄(4)描边：将簇的 8-邻域中属于灰(5)背景的像素涂为黄(4)。若描边像素与另一簇的描边重叠，保持黄(4)。描边不覆盖非背景像素。

**关键洞察**：孔洞是滑动紧凑排列的涌现产物——同一组物体放在不同初始位置可能产生完全不同的孔洞（甚至没有孔洞）。必须先模拟完整的滑动过程才能判断哪些物体参与围合并被重涂。
