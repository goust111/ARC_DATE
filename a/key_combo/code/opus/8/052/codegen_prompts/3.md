## 新题 3：颜色编码位移后碰撞涌现交叉点，交叉点触发环形标记

**组合逻辑**：[平移](颜色决定偏移) → [交叉检测](创新：位移后碰撞涌现交叉点，源题中不存在碰撞概念) → [描边](交叉邻域环涂色)

**来源原语**：平移+前景像素+颜色编码位移+颜色决定偏移（342dd610）；描边+全行条+全列条+交叉点+交叉邻域环涂色（67a423a3）

**依赖链**：每个像素的颜色编码其位移方向 → 所有像素同时位移 → 位移后两个或更多像素落在同一格时涌现"交叉点" → 交叉点触发 3x3 黄色环标记。交叉点是位移的涌现结果，源题中完全不存在：342dd610 没有碰撞概念，67a423a3 的交叉来自整行整列而非像素碰撞。

按颜色编码的方向位移所有像素，在位移后发生碰撞的位置画黄色环形标记。

**输入结构**：约 12x12 的黑(0)背景网格。散布约 6~10 个前景像素，颜色为橙(7)、红(2)、栗(9)、蓝(1)中的若干种（不要求四种全出现）。没有两个像素占据同一格。网格足够大，使得所有位移后的像素在大多数情况下仍在网格内。生成约束：位移后至少存在 1 个碰撞（两个或更多像素落入同一格），且至少存在 1 个未碰撞的像素，以便求解者区分碰撞与非碰撞行为。

**规则**：
1. 清空网格为全黑(0)。
2. 对每个前景像素按颜色编码位移：橙(7)向上移 2 格，红(2)向左移 2 格，栗(9)向下移 2 格，蓝(1)向右移 1 格。
3. 位移后落在网格外的像素丢弃。
4. 若某格恰好有一个像素落入（无碰撞），将该格涂为该像素的原始颜色。
5. 若某格有两个或更多像素落入（碰撞），该格为"交叉点"，涂为绿(3)。
6. 对每个交叉点，将其 8-邻域的 8 个格涂为黄(4)。
7. 优先级（高到低）：绿(3)交叉点 > 非碰撞像素原色 > 黄(4)环 > 黑(0)背景。即：交叉点不被环覆盖；非碰撞像素不被邻近的黄色环覆盖；环像素之间不冲突（都是黄色）。

**关键洞察**：交叉点纯粹是位移后的涌现——无法直接从输入读出，必须模拟全部位移才能知道哪些格发生碰撞。环标记是碰撞的可见信号。位移规则需要对比多个示例中不同颜色像素的前后位置才能归纳。
