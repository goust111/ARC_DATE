## 新题 1：去遮挡还原对称后洪泛填充涌现孔洞

**组合逻辑**：[擦除](去除遮挡矩形) → [对称补全](还原被遮挡的镜像对称形状) → [洪泛填充](创新：填充因补全而涌现的封闭孔洞，颜色由面积奇偶决定)

**来源原语**：擦除+遮挡+填充矩形+对称补全+去遮挡后镜像还原（3345333e）；洪泛填充+封闭区域+包含+面积奇偶定填充色（868de0fa）

**依赖链**：遮挡矩形被擦除后暴露出不完整的对称体 → 对称补全恢复缺失像素 → 补全后的完整形状才在内部围成封闭区域 → 封闭区域的面积奇偶决定填充颜色。孔洞在补全之前不存在，面积在补全完成前无法计算——三步环环相扣。

从含遮挡的不完整对称体中去除遮挡、补全对称、然后按面积奇偶填充因补全而涌现的内部孔洞。

**输入结构**：约 15x15 的黑(0)背景网格。包含一个蓝(1)单色 4-连通对象，该对象具有左右镜像对称性，在对称完整时其内部围成一个或多个黑(0)背景孔洞（4-连通封闭区域）。一个灰(5)填充矩形（实心连通分量，边界框为矩形且完全填满）与蓝(1)对象部分重叠，遮挡了对称体的若干像素（被遮挡的像素在输入中显示为灰(5)而非蓝(1)）。灰(5)矩形不完全覆盖对称体，至少一侧的对称信息完好。生成约束：对称体完整时至少围成 1 个孔洞；遮挡矩形必须遮盖与孔洞围合相关的像素，使得不补全对称就无法确认孔洞存在。

**规则**：
1. 检测灰(5)填充矩形分量（唯一的灰色实心矩形连通分量），将其所有像素擦除为黑(0)。
2. 以蓝(1)像素为对象，检测其左右镜像对称轴（竖直轴，x 坐标为蓝色像素水平范围的中点）。沿对称轴将所有现有蓝(1)像素镜像到对侧；若对侧为黑(0)则填蓝(1)，若已为蓝(1)则不变。
3. 补全完成后，检测所有 4-连通的黑(0)封闭区域——即完全被蓝(1)像素包围、不与网格边界相连的黑(0)连通分量。
4. 对每个封闭区域计算像素面积：面积为偶数则填充为红(2)，面积为奇数则填充为橙(7)。
5. 蓝(1)对象像素和外部黑(0)背景保持不变。

**关键洞察**：封闭孔洞是对称补全的涌现产物——输入中因遮挡而不存在完整围合，只有擦除遮挡并补全对称后孔洞才显现。面积奇偶规则需要对比多个示例（不同大小的孔洞）才能归纳。
