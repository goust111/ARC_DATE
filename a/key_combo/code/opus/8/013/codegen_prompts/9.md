## 新题 9：嵌入标记修补后以孤立标记为顶点画三角

**组合逻辑**：[修补](已有，嵌入标记重涂为主体色) + [嵌入与孤立](已有) → 孤立标记定位三角顶点(创新——孤立标记不再单纯延伸一格，而是成为三角形的顶点) → [描边](已有，提取修补后轮廓作为三角形底边) → [连线](已有) + 补斜边底边成三角(已有，但三角形的一条边来自主体对象轮廓)

**来源原语**：修补/repair (8886d717), 嵌入与孤立/embedded_vs_isolated (8886d717), 主体对象/main_object (8886d717), 标记像素/marker_pixel (8886d717), 描边/outline (4258a5f9, 31aa019c), 连线/draw_line (3bd67248), 端点连接/endpoint_connection (3bd67248), 补斜边底边成三角/draw_edges_form_triangle (3bd67248), 竖条/bar (3bd67248)

**依赖链**：先区分嵌入标记与孤立标记——嵌入标记修补后使主体对象完整化，孤立标记确定三角形顶点。修补改变了主体轮廓（填补了缺口），修改后的轮廓提供三角形的一条边。孤立标记的位置提供三角形对面的顶点。两类标记看起来相同，必须通过嵌入/孤立判断来区分用途。

将嵌入在主体对象中的标记修补为主体色使轮廓完整，然后从每个孤立标记向修补后的主体轮廓画三角形（斜边+底边）。

**输入结构**：约 14x14 的网格，背景为黑(0)。有一个大的蓝(1)主体对象（15~30 像素，4-连通，不规则形状），对象中有 1~2 个橙(7)像素嵌入其中（4-邻居中至少 3 个为蓝(1)）。网格背景区域有 1~2 个孤立的橙(7)像素（4-邻居全为黑(0)或网格边界）。网格某一边缘（如底边或右边）有一条完整的灰(5)边缘线（整行或整列的灰色像素）。生成约束：每个孤立橙色标记与修补后的主体对象之间存在清晰的水平或垂直视线（同行或同列，中间全为背景）；视线方向指向主体对象的一段连续轮廓边（该段轮廓至少 3 像素长且为直线段）。

**规则**：
1. 识别所有橙(7)像素，按嵌入/孤立分类：若一个橙(7)像素的 4-邻居中有 3 个或以上为蓝(1)，则为嵌入标记；否则为孤立标记。
2. 将所有嵌入标记重涂为蓝(1)（修补主体对象）。
3. 对修补后的主体对象提取轮廓：保留蓝(1)像素中 4-邻居含有非蓝(1)像素的那些（即边界像素）。
4. 对每个孤立橙(7)标记：找到从该标记出发沿行或列方向到主体轮廓的最近轮廓像素 P。沿轮廓从 P 出发找到与 P 同行或同列的连续轮廓线段（主体对象的一条直边），该线段作为三角形的"竖边"（类比参考题 3bd67248 的竖条）。
5. 以孤立标记为三角形的对角顶点：从标记位置画一条红(2)斜线连到竖边的远端端点（远离标记的那端），再画一条黄(4)直线从标记位置沿行或列方向连到竖边的近端端点（靠近标记的那端）。三角形由竖边（蓝(1)轮廓）、斜边（红(2)）、底边（黄(4)）组成。
6. 若多个孤立标记产生的三角形线段有重叠，后处理的（标记行号更大的先画，行号相同则列号更大的先画）覆盖先处理的。

**关键洞察**：橙色像素的嵌入/孤立属性决定了其完全不同的功能——嵌入的用于修补（使轮廓完整），孤立的用于定位三角形顶点。修补步骤改变了主体轮廓，进而影响三角形的"竖边"位置和长度。如果跳过修补，轮廓有缺口，三角形的边会对接到错误位置。
