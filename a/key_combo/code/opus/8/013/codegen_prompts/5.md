## 新题 5：标记形状决定象限旋转后再叠加

**组合逻辑**：[标记形状决定操作](已有，从区域级 T 标记改造为象限级 L 标记) → 按标记旋转各象限(创新——旋转粒度从全图变为单象限) + [擦除](已有) → [透明叠加](已有)

**来源原语**：旋转/rotate (21897d95), 标记形状决定操作/marker_shape_determines_operation (21897d95), 控制标记/control_marker (21897d95), 擦除/erase (21897d95), 透明叠加/transparent_overlay (75b8110e), 象限掩码/quadrant_mask (75b8110e), 四象限折叠同画布/quadrants_fold_one (75b8110e), 层叠顺序/layer_stack (75b8110e)

**依赖链**：每个象限是否旋转、旋转方向取决于其内部 L 标记的朝向；旋转改变了象限掩码的形状；叠加结果取决于旋转后的掩码。三步紧耦合——不检测标记就不知道旋转，不旋转就叠加错误，不叠加则不知道最终哪些像素可见。

四象限各含一个单色掩码，部分象限有 L 形控制标记指示该象限需预先旋转；擦除标记后，将旋转/未旋转的象限掩码折叠叠加到公共画布。

**输入结构**：偶数边长的方形网格（如 10x10 或 12x12），背景为黑(0)，被水平和垂直中线分为四个等大象限。每个象限包含一个单色前景掩码（使用红(2)、绿(3)、黄(4)、蓝(1) 四色之一，每象限颜色不同），掩码为 3~8 像素的 4-连通不规则形状。其中 1~3 个象限内额外包含一个栗(9) L 形控制标记（3 个像素呈 L 形，位于象限角落附近），L 形的弯折角朝向象限内部。其余象限无控制标记。生成约束：旋转后各掩码在公共画布上至少有一处重叠；L 标记不与掩码像素重叠。

**规则**：
1. 检测每个象限中是否存在栗(9) L 形标记（3 像素构成直角 L 形）。
2. 若存在标记，根据 L 形弯折角的朝向确定旋转：弯折角在右上 → 该象限逆时针旋转 90 度；弯折角在左上 → 顺时针旋转 90 度；弯折角在左下 → 旋转 180 度；弯折角在右下 → 不旋转（标记存在但弯折角在右下表示"0 度旋转"，即仅擦除标记）。旋转以象限中心为轴。
3. 擦除所有栗(9)标记像素（置为黑(0)）。
4. 将四个象限（已旋转或未旋转的）折叠到一个象限大小的公共画布上。叠加顺序固定为：左上 → 右下 → 左下 → 右上（与参考题 75b8110e 一致），后画的覆盖先画的。

**关键洞察**：控制标记既决定了象限是否旋转，又通过 L 的朝向编码了旋转角度。由于旋转在叠加之前发生，同一组掩码在不同标记朝向下会产生完全不同的叠加结果。求解者必须先正确解读每个象限的 L 标记（或其缺失），才能预测叠加输出。
