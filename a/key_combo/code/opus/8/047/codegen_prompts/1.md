## 新题 1：孔洞拓扑驱动旋转放置

**组合逻辑**：[计数/count](孔洞数不再映射颜色，而是映射旋转角度) + [旋转/rotate](旋转量由拓扑属性参数化) + [复制放置/copy_place](旋转后的模板替换原对象) + [重涂色/recolor](保留原对象颜色)

**来源原语**：计数+封闭区域+按孔洞数映射颜色(0a2355a6), 旋转+旋转族成员(be03b35f), 复制放置+精灵体(7d18a6fb), 重涂色(ed74f2f2)

**依赖链**：孔洞拓扑分析产生一个离散数值→该数值参数化旋转角度→旋转应用于共享模板→旋转后的模板以原对象颜色替换原对象位置。删掉孔洞计数则无法确定旋转量；删掉旋转则模板方向固定无法匹配输出；删掉重涂色则所有输出同色无法区分。

根据每个封闭形状的内部孔洞数量决定模板精灵体的旋转角度，用原形状的颜色将旋转后的模板放置到对应位置。

**输入结构**：
- 网格约 15x15，黑(0)背景。
- 网格右下角有一个单色的模板精灵体（4-连通，3~5 像素，非对称，颜色为灰(5)），占据一个 3x3 的边界框。
- 网格其余区域散布 3~4 个 4-连通单色封闭形状（每个形状颜色不同，使用蓝(1)、红(2)、绿(3)等），每个形状占据约 5x5~7x7 的边界框区域。
- 每个封闭形状内部包含 0~3 个由黑(0)像素构成的 4-连通封闭孔洞（孔洞被形状像素完全包围）。
- 各形状之间、形状与模板之间互不相邻（至少间隔 1 个黑像素）。
- 生成约束：不同形状的孔洞数互不相同；模板精灵体不具备 90 度旋转对称性（确保不同旋转产生可区分的结果）。

**规则**：
1. 识别右下角的灰(5)模板精灵体（唯一灰色 4-连通对象）。
2. 对每个非灰的前景封闭形状，计算其 4-连通内部封闭孔洞数 H（0、1、2 或 3）。
3. 将模板精灵体顺时针旋转 H x 90 度（0 个孔洞不旋转，1 个孔洞旋转 90 度，2 个孔洞旋转 180 度，3 个孔洞旋转 270 度）。
4. 在输出中，将每个封闭形状的边界框区域替换为：以该形状的原色绘制旋转后的模板（模板居中于原形状边界框中心，多余空间填黑(0)）。
5. 模板精灵体本身从输出中移除（其位置变为黑(0)背景）。
6. 背景保持黑(0)不变。

**关键洞察**：孔洞数量不是颜色编码（与源题 0a2355a6 不同），而是几何变换的参数；必须对比多个示例才能确定孔洞数到旋转角度的具体映射方向（顺时针 vs 逆时针）。
