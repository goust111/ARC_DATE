## 新题 9：最大框选裁瓦片后低频色印章

**组合逻辑**：[面积最大选取/largest_area_select + 裁剪/crop](从最大框架中提取内容) → [低频色掩码/low_frequency_color_mask + 印章覆盖/stamp_overlay](提取物中的低频色确定印章位置) + [最大框决定裁切/largest_frame_crops](最大框同时界定提取范围和输出比例)

**来源原语**：矩形框架+面积最大选取+裁剪+最大框决定裁切+重涂色(fcb5c309), 印章覆盖+瓦片+低频色掩码+最低频色定位(48f8583b)

**依赖链**：多个框架中选最大→裁剪其内部内容作为瓦片→分析瓦片中的最低频色→以最低频色像素位置为蓝图在更大画布上铺设瓦片。框架选择决定瓦片内容；瓦片内容中的颜色分布决定铺设位置；铺设产生的输出尺寸由瓦片自身结构决定——三步之间信息逐级变换而非简单传递。

从多个矩形框架中选取面积最大的，裁剪其内部作为瓦片模板，以瓦片中最低频颜色的像素位置为蓝图进行印章式铺设。

**输入结构**：
- 网格约 15x15，黑(0)背景。
- 网格中有 2~4 个不重叠的矩形框架（1 像素宽边框），每个框架使用不同的前景色（如蓝(1)、红(2)、绿(3)等）。
- 最大框架（按边界框面积 = 宽 x 高计算）的内部包含一个 3x3 的多色图案（使用 2~3 种颜色填充 9 个像素，其中一种颜色恰好只出现 1~2 次，为最低频色）。该图案不含黑(0)。
- 其余较小框架的内部为空（黑(0)背景）或包含干扰图案（在最终输出中被忽略）。
- 生成约束：最大框架面积严格大于所有其他框架；最大框架内部的 3x3 图案中恰好有一种颜色出现次数最少且唯一最少。

**规则**：
1. 计算每个矩形框架的边界框面积（宽 x 高），选取面积最大的框架。
2. 裁剪最大框架边框内部的 3x3 图案作为瓦片模板 T。
3. 在瓦片 T 中找到出现次数最少的颜色 C_rare（若平局则选在 T 中位置靠左上的颜色）。
4. 构建 9x9 全黑(0)输出画布，将其视为 3x3 的块阵列（每块 3x3）。
5. 对 T 中每个颜色为 C_rare 的像素位置 (r, c)（r, c 为 0~2），将整个瓦片 T 复制到输出画布的第 (r, c) 块中。其余块保持黑(0)。
6. 输入中的所有框架均不出现在输出中。

**关键洞察**：框架选择在源题 fcb5c309 中用于裁切输出范围，这里则用于选取印章模板——同一选择逻辑在新语境中作用于不同环节；低频色在源题 48f8583b 中直接取自输入瓦片，这里取自经过框架筛选和裁剪后的中间产物，使得选择和频率分析形成串联依赖。
