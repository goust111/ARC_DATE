## 新题 8：十字镜像后色条周期填充

**组合逻辑**：[擦除/erase + 镜像/mirror](十字轴移除后四向镜像) ⊗ [周期延伸/periodic_extension](创新：色条长度既是镜像内容又是填充周期) + [对称轴定义/symmetry_axis_def](十字定义镜像轴和区域边界)

**来源原语**：擦除+镜像+十字图案+前景遮罩+象限+对称轴定义+十字色作涂色源(47c1f68c), 周期延伸+色条+长度即周期+近者优先(1ae2feb7)

**依赖链**：十字定义对称轴和四象限边界→移除十字行列→源象限的色条镜像到其余三个象限→每条色条在其所在象限内按自身长度为周期向外重复延伸填满该象限行。十字结构同时服务于镜像和区域划分；色条长度既决定镜像后的内容形态又决定周期延伸的步长——这两个功能在源题中分属不同题目，此处通过同一物理量耦合。

移除中心十字后将源象限的色条四向镜像，每条色条在各象限内按自身长度为周期重复延伸填满整行。

**输入结构**：
- 网格为奇数边长的正方形（如 13x13 或 15x15）。
- 正中一行和正中一列被红(2)像素填满，形成十字图案，将网格分为四个等大象限。
- 左上象限中包含 2~3 条水平色条：每条色条占据一行中连续的若干像素，色条紧贴象限左边缘，颜色各异（如蓝(1)、绿(3)、黄(4)等），长度各不相同（1~3 像素不等）。色条所在行的其余像素为黑(0)背景。
- 其余三个象限全为黑(0)背景。
- 生成约束：左上象限的行数至少为 4（保证有足够行容纳色条和空行）；色条长度不超过象限宽度的一半。

**规则**：
1. 移除十字行和十字列（从网格中删除正中行和正中列），网格从 (2N+1)x(2N+1) 缩小为 (2N)x(2N)。
2. 将左上象限的色条图案以红(2)（原十字色）重涂色后，水平翻转复制到右上象限、垂直翻转复制到左下象限、中心对称复制到右下象限。翻转基于象限的对称轴（原十字位置）。
3. 对每个象限中的每条色条（原始的和镜像产生的），以该色条的像素长度 L 为周期，沿色条所在行在该象限范围内重复绘制：从色条原始末端开始，每隔 L 个像素绘制一段长度为 L 的同色色条，直到超出象限边界（超出部分截断）。
4. 不同色条的周期延伸在同一行不会冲突（每行最多一条色条，因为源象限中每行至多一条色条）。
5. 色条以红(2)重涂后绘制（即输出中色条颜色为红(2），而非原色）。

**关键洞察**：色条的物理长度同时承载两个语义角色——它是镜像复制的内容单元，也是周期延伸的重复间距；十字既是对称轴源又是涂色源，三重功能耦合在同一结构中；需要对比示例确认重涂色是否使用十字色以及延伸方向。
