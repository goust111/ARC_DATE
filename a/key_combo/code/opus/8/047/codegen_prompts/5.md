## 新题 5：字形解码驱动选择性角落装饰

**组合逻辑**：[编码字形/code_glyph + 字形映射颜色/glyph_maps_color](字形解码) → [描边/decorate](创新：装饰模式不再固定四角，而由解码颜色动态选择角落子集) + [配对/pairing](字形与方块的空间配对)

**来源原语**：编码字形+掩码区域+配对+字形映射颜色(ed74f2f2), 描边+前景方块+角标记+对角邻接+四角固定配色装饰(95990924)

**依赖链**：字形解码产生颜色→颜色查表得到角落装饰模式→按模式对配对方块执行选择性角落装饰。字形解码与装饰模式之间存在双重隐式映射（字形→颜色→角落子集），删掉任一环节都无法确定输出。

将每个字形解码为颜色，该颜色决定配对方块的哪些对角位置被装饰，实现"编码→选择→装饰"三级推理。

**输入结构**：
- 网格约 15x15，黑(0)背景。
- 网格中有 3~4 个灰(5)的 2x2 实心方块，彼此间距至少 4 像素。
- 每个灰方块正上方（间隔 1 行黑像素）有一个 3x3 的字形区域。字形区域中，灰(5)像素组成一个五像素编码图案（占据 3x3 区域中的 5 个位置），其余 4 个位置为黑(0)。
- 字形编码规则（需从示例归纳）：不同的五像素图案映射到不同颜色（如十字形→蓝(1)，倒 T 形→红(2)，L 形→绿(3)等）。每道题的具体码本固定但需从示例学习。
- 生成约束：每个方块配对的字形图案互不相同；字形图案至少有 3 种不同的。

**规则**：
1. 对每个灰(5)的 2x2 方块，找到其正上方（间隔 1 行）的 3x3 字形区域，建立配对关系。
2. 将字形中的灰像素图案与码本对照，解码为一种颜色 C（码本从训练示例中归纳）。
3. 根据解码颜色 C 确定装饰的角落子集（从训练示例中归纳映射）：
   - 颜色 A → 仅装饰西北角和东南角（对角线一对）。
   - 颜色 B → 仅装饰东北角和西南角（反对角线一对）。
   - 颜色 C → 装饰全部四个角。
4. 对选定的角落位置，在方块边界框外的对角邻接像素处涂上解码颜色 C（每个角仅 1 像素）。
5. 未选定的角落位置保持黑(0)背景不变。
6. 字形区域在输出中保持不变。灰方块本身保持不变。

**关键洞察**：字形不再仅供重涂色使用（与源题 ed74f2f2 不同），而是通过双重映射（字形→颜色→装饰模式）控制几何操作的作用范围；必须同时对比多个示例才能分别归纳出码本和颜色到角落子集的映射。
