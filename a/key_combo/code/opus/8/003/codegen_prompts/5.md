## 新题 5：复制旋转角落图案后以图案像素为锚计算距离场

**组合逻辑**：[图案复制 + 旋转](复制的图案不是装饰终点，而是后续距离计算的锚点集) → [同心层填充](距离目标从单一控制点变为一组分布式锚点的最近距离) + [奇偶距离决定颜色]

**来源原语**：图案复制/旋转/空心框/角落标记/源角到目标角映射/各角独立着色(4c416de3) + 同心层填充/以控制点为中心/奇偶距离决定颜色/矩形边框(b7fb29bc)

**依赖链**：角落图案复制+旋转确定了所有图案像素的位置 → 这些位置构成距离场的锚点集 → 每个内部像素到最近锚点的 Chebyshev 距离决定颜色。不做复制旋转则锚点缺失（只有源角有图案）；不做距离填充则复制无后续效应。

在空心矩形框的各角落复制旋转一个源图案，然后以所有图案像素为锚点集合，对框内部做基于最近锚点 Chebyshev 距离的奇偶着色。

**输入结构**：黑(0)背景网格，约 20x20。灰(5)像素构成一个空心矩形框（单像素宽边框，内部约 14x14 的黑(0)区域）。框的一个角落（如左上角）有一个由蓝(1)像素绘制的小图案（3~5 像素），图案沿该角落的内对角线方向分布（即从角落向内部延伸），图案关于该角落的内对角轴对称。其余 1~3 个角落的内对角线上各有一个不同颜色的单像素标记：如红(2)、绿(3)、黄(4)，标记位于图案最深偏移量 (k,k) 对应的位置。生成约束：图案的最大偏移量 k 不超过 4；各角落图案复制后互不重叠；框内部足够大使得距离场有意义（内部宽高均 >= 2k+4）。

**规则**：
1. 识别源角落（已有多像素图案的角落）及其图案。提取图案相对于角落的坐标偏移（规范化为左上角朝向）。
2. 对每个有单像素标记的非源角落，将规范化图案旋转到该角落的朝向（右上旋转 90 度、右下旋转 180 度、左下旋转 270 度），用该角落标记的颜色绘制图案。标记像素本身被图案覆盖。
3. 现在框的每个有标记的角落都有各自颜色的图案。收集所有图案像素（含源角落的蓝(1)像素和各目标角落的彩色像素）的坐标，形成锚点集合 A。
4. 对框内部每个黑(0)背景像素 p，计算 p 到锚点集合 A 中最近点的 Chebyshev 距离 D = min_{a in A} max(|p.row - a.row|, |p.col - a.col|)。
5. D 为奇数时涂品红(6)，D 为偶数（含 D=0，但 D=0 的位置已是图案像素不会再涂）时涂橙(7)。
6. 灰(5)框像素、所有图案像素保持各自颜色不变。

**关键洞察**：在源题中，角落图案复制是最终装饰；在源题中，同心填充以单个控制点为中心。这里，复制出的图案像素集合取代了单一控制点，成为分布式距离锚点。距离场的等值线不再是正方形环而是沿多个角落锚点形成的复杂沃罗诺伊样图案。必须先正确完成复制旋转，才能得到正确的距离场。
