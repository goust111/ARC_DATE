## 新题 7：滑动压缩区域后按原始围合面积解决重叠

**组合逻辑**：[滑动](从移动单像素变为移动整个连通区域) → [面积排名](排名依据不是当前面积，而是滑动前的围合背景面积) → [重涂色](按排名结果涂色)

**来源原语**：滑动/行列对齐/压缩到标记旁/擦除(ae3edfdc) + 重涂色/封闭区域/连通分量/面积排名(a8d7556c) + 标记像素(db7260a4)

**依赖链**：每个区域的围合背景面积在滑动前计算 → 滑动改变区域位置导致重叠 → 重叠像素归属由滑动前面积排名决定 → 最终按排名重涂色。面积必须在滑动前算（滑动后区域形状不变但围合关系变了），滑动后才出现重叠需仲裁。

将前景连通区域沿行或列滑动到对齐的标记点旁，重叠区域归属于滑动前围合背景面积更大的区域，最后按面积排名统一重涂色。

**输入结构**：黑(0)背景网格，约 16x16。蓝(1)像素形成 3~4 个互不相邻的 4-连通前景区域，每个区域为 5~10 像素的不规则形状（非矩形，有凹凸），部分区域围合了一小块黑(0)背景（即区域内部有孔洞或凹陷形成的封闭背景区域）。红(2)单像素标记点散布在网格中。每个前景区域与恰好一个标记点共享同一行或同一列（但不同时共享行和列）。生成约束：每个前景区域对应唯一一个标记点；滑动方向无歧义（每个区域与其标记在同行或同列中恰好只有一种选择）；滑动后至少有两个区域发生重叠；滑动距离为正数（区域与标记之间有间隔）。

**规则**：
1. 对每个蓝(1)前景区域，找到与该区域围合关系对应的封闭背景面积：将该区域视为边界，计算其内部（被该区域的像素在 4-连通意义下完全围合的）黑(0)背景像素数量。若区域不围合任何背景（无封闭内部），则围合面积为 0。记录每个区域的围合面积。
2. 对每个区域，找到与其共享行或列的唯一红(2)标记点。沿共享的行（若共享行）或列（若共享列），将整个区域平移（所有像素同步移动）直到区域的最近边界像素与标记点相邻（Chebyshev 距离 = 1）。擦除区域的原始位置像素。
3. 滑动后若两个或更多区域的像素重叠在同一格，该格归属围合面积最大的区域。若围合面积相同，则归属于滑动前边界框面积（高 x 宽）更大的区域。若仍相同，归属于滑动前边界框左上角行号更小的区域。
4. 对最终确定归属后的所有区域，按围合面积从大到小排名。排名第 1 的区域涂绿(3)，第 2 涂黄(4)，第 3 涂品红(6)，第 4 涂橙(7)。围合面积为 0 的区域保持蓝(1)不变。
5. 红(2)标记点保持不变。

**关键洞察**：重叠仲裁和最终着色都依赖于"围合背景面积"这个在滑动前才有意义的属性。滑动后，区域的邻接关系改变，围合关系也可能改变（原来围合的背景可能因移动而暴露）。求解者必须意识到面积是在滑动前计算的——这一点只有对比多个示例（不同围合面积的区域在不同重叠情境中的优先级）才能确认。
