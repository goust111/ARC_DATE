## 新题 4：膨胀通道重新划定区域后按面积排名涂色

**组合逻辑**：[膨胀求交](通道从高亮目标变为拓扑边界) → [重涂色 + 面积排名](排名作用于通道重定义后的区域，而非预存的连通分量)

**来源原语**：膨胀求交/路径组件/两路径间隙重叠区/通道/连通至边缘的部分(f1bcbc2c) + 重涂色/封闭区域/连通分量/面积排名/分量最大矩形涂(a8d7556c)

**依赖链**：膨胀求交找到通道 → 通道像素作为新边界加入前景 → 新边界改变了背景区域的连通性和面积 → 面积排名对重新划定的区域涂色。不找通道则区域划分不对；不做面积排名则通道无后续影响。

识别两条平行路径之间的膨胀中线通道，将通道视为新增边界，然后对被路径和通道共同分割出的背景封闭区域按面积排名涂色。

**输入结构**：黑(0)背景网格，约 18x18。橙(7)像素形成恰好两条 4-连通单像素宽的路径组件，大致平行（间距 2~3 像素），从网格上部延伸到下部，路径有弯折但不闭合，两端可能到达网格边缘或在网格内终止。两条路径之间的间隙为 2~3 像素宽。路径和网格边缘共同围成若干黑(0)背景封闭区域。生成约束：两条路径的膨胀交集恰好形成一条连续的单像素宽通道；通道至少有一个连通分量与网格顶边相连；路径和通道将背景分割为至少 3 个不同面积的封闭区域（4-连通意义下的连通分量）。

**规则**：
1. 对两条橙(7)路径组件分别做 8-邻域膨胀一格，取两次膨胀的交集，得到中间通道像素集合。
2. 将通道中与网格顶边相连的那个连通分量涂青(8)。此连通分量的像素在后续步骤中视为前景（边界）。
3. 现在前景由橙(7)路径 + 青(8)通道组成。计算所有被前景和网格边缘共同围成的黑(0)背景区域（4-连通连通分量）。
4. 将这些背景区域按像素面积从大到小排名。面积最大的区域涂红(2)，面积第二大的涂蓝(1)，面积第三大的涂绿(3）。若有更多区域，第四大涂黄(4)，第五大涂灰(5)，依此类推。若两个区域面积相同，边界框左上角更靠左上（先比行号小、再比列号小）的区域排名靠前。
5. 橙(7)路径和青(8)通道像素保持不变。

**关键洞察**：通道在源题中是最终输出的高亮区域，这里却变成了重新划分背景区域的隐形边界。如果不先找到通道，两条路径之间的间隙是一个连续的背景区域；加入通道后，这个间隙被分割成多个更小的独立区域。面积排名操作的对象完全依赖于通道识别的结果。求解者需要对比多个示例才能发现通道的"边界"角色（而非简单的"高亮"角色）。
