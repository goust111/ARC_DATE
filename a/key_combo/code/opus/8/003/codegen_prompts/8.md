## 新题 8：共享侧带标记同时约束射线延伸与同心环填充

**组合逻辑**：[射线延伸 + 标记排除对应行列] ⊗ [同心层填充 + 奇偶距离决定颜色]（两个操作共享同一组约束标记，非流水线而是同时约束满足）

**来源原语**：射线延伸/实心矩形/标记排除对应行列/侧边带对齐/延伸条纹(9def23fe) + 同心层填充/矩形边框/控制像素/以控制点为中心/奇偶距离决定颜色(b7fb29bc) + 标记像素(多题共有)

**依赖链**：一组标记同时控制两种操作——标记排除射线延伸的行列，同时排除同心环填充的行列。不做任一操作都会导致另一操作的排除规则看起来毫无关联。两种操作通过共享约束耦合，而非通过数据流串联。

在矩形框内以控制点为中心画同心方环，同时从矩形向四周延伸射线条纹，但侧带标记同时禁止对应行列的环填充和射线延伸。

**输入结构**：黑(0)背景网格，约 18x18。蓝(1)像素组成一个实心矩形（约 8x8），位于网格中心。矩形内部有一个绿(3)控制像素。在矩形的四个侧带区域（矩形正上方与矩形同列的区域、正下方同列、正左方同行、正右方同行，不含对角区域），散布若干红(2)单像素标记。生成约束：控制像素不位于矩形的边界行/列上（至少离边界 2 格）；每个侧带标记恰好位于矩形对应边的外侧 1~3 格处；被标记排除的行/列不超过矩形行/列总数的一半。

**规则**：
1. 识别蓝(1)实心矩形、绿(3)控制像素、红(2)侧带标记。
2. **射线延伸**（矩形外部）：对矩形的上侧和下侧，沿每个矩形列向上/向下延伸蓝(1)射线至网格边缘——但若该列在对应侧（上方或下方）有红(2)标记，则该侧该列不延伸。对矩形的左侧和右侧，沿每个矩形行向左/向右延伸蓝(1)射线至网格边缘——但若该行在对应侧（左方或右方）有红(2)标记，则该侧该行不延伸。射线遇到红(2)标记像素时在标记前一格停止（标记保持红(2)不变）。
3. **同心环填充**（矩形内部）：对矩形内部的每个蓝(1)像素（非控制像素），计算其到绿(3)控制像素的 Chebyshev 距离 D。D 为奇数时涂黄(4)，D 为偶数时涂灰(5)。但若该像素所在的行或列被任一侧带标记排除（即该行在左方或右方有红(2)标记，或该列在上方或下方有红(2)标记），则该像素保持蓝(1)不变（即被排除的行列上不画同心环）。
4. 绿(3)控制像素保持不变。红(2)标记保持不变。

**关键洞察**：同一组红(2)标记同时控制了两种不同的空间操作——外部的射线延伸和内部的同心环填充。在源题中，侧带标记只影响射线；在源题中，同心填充无任何排除机制。这里两者共享约束源，形成同时约束满足结构而非流水线。求解者需要对比多个示例才能同时发现标记的双重作用：仅看射线部分会以为标记只影响外部，仅看内部会以为某些行列"恰好"未填充。
