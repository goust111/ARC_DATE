## 新题 2：叠加涌现闭合环路后分类弯折

**组合逻辑**：[透明叠加](叠加不是终点，而是创造新几何结构的前置步骤) → [环路追踪 + 分类涂色](作用于叠加涌现出的环路，而非预先存在的环路)

**来源原语**：透明叠加/双面板对齐/分隔行/任一前景即输出(506d28a5) + 环路追踪/分类涂色/闭合正交环路/弯折像素/多数转向为凸/少数转向为凹(15663ba9)

**依赖链**：叠加产出新的几何形状 → 形状中涌现出闭合环路 → 环路追踪与弯折分类作用于涌现结构。单独任一面板不含闭合环路，故无法独立进行追踪；不做追踪则叠加结果缺少颜色分类。

将两个面板中各自不闭合的开放路径叠加合并，使之形成闭合环路，然后对涌现出的环路进行弯折分类着色。

**输入结构**：黑(0)背景网格，约 12x25（宽大于高）。中间有一整行灰(5)分隔行，将网格分为上下两个等大面板。上面板包含蓝(1)像素组成的若干不闭合的正交折线路径（4-连通，单像素宽，每条路径两个端点位于面板边缘或在面板内部自由终止）。下面板包含红(2)像素组成的若干不闭合的正交折线路径，结构类似。每条路径为 5~15 个像素的折线段。生成约束：上下面板的路径经叠加后，在对应位置恰好首尾相接形成若干闭合正交环路（每个前景像素度数恰好为 2），不会出现 T 形交叉或度数 >= 3 的节点。上面板路径端点的对应位置在下面板中恰好有路径端点与之衔接。

**规则**：
1. 移除灰(5)分隔行。将上面板与下面板逐像素对齐。
2. 任一面板中有前景像素的位置，在输出中变为绿(3)。
3. 合并后的绿(3)像素形成若干闭合正交环路。对每条环路进行追踪。
4. 在每个前景像素处判断转向：直行像素保持绿(3)；多数转向方向（凸弯）的像素涂黄(4)；少数转向方向（凹弯）的像素涂红(2)。
5. 输出网格的尺寸为单个面板的尺寸（即去掉分隔行后的半高宽度不变）。

**关键洞察**：闭合环路不存在于任何一个面板中，它们仅在叠加后涌现。求解者必须先识别叠加规则，再识别环路的形成，最后应用弯折分类。仅凭单个示例难以区分"叠加后直接涂绿"和"叠加后还要做弯折分类"，需要对比多个示例中不同弯折位置的颜色差异才能归纳完整规则。

p = Path("/home/lixinyu/snap/a/key_combo/code/opus/8/003/2.py")
mod = SourceFileLoader("new_arc_task", str(p)).load_module()
sigs = set()
for i in range(100):
    inp = mod.generate_input()
    out = mod.main(inp)
    assert isinstance(inp, np.ndarray)
    assert isinstance(out, np.ndarray)
    assert inp.ndim == 2 and max(inp.shape) <= 30, f"input grid exceeds 30x30: {inp.shape}"
    assert out.ndim == 2 and max(out.shape) <= 30, f"output grid exceeds 30x30: {out.shape}"
    sigs.add(hashlib.md5(inp.tobytes() + str(inp.shape).encode()).hexdigest())
print("variants", len(sigs))
assert len(sigs) >= 20
