## 新题 1：异或差异揭示平铺种子

**组合逻辑**：[异或叠加](已有) + [平铺](已有)（创新：种子不直接给出，而是两掩码异或的涌现结果；空腔与掩码区域共存于同一网格中）

**来源原语**：异或叠加、前景掩码、分隔行、对齐、前景不一致处涂色(99b1bc43)；平铺、矩形空腔、墙壁、种子图案、图案填满空腔、保持种子相位(a57f2f04)

**依赖链**：分隔列将网格分为左右两个等宽掩码区域 → 逐单元格对齐取异或得到差异掩码 → 差异掩码的 bbox 即为种子图案 → 种子以保持相位的方式平铺填满底部空腔。异或结果为空则空腔保持全黑；异或的形状直接决定铺出的图案——删掉异或步骤则种子未知，删掉平铺步骤则空腔未填。

将分隔线两侧掩码的前景对称差异作为种子图案，平铺填充同一网格中由墙壁围出的矩形空腔。

**输入结构**：
- 约 18x12 的网格，背景色为黑(0)。
- 一条灰(5)垂直满列将网格上半部分左右分为两个等宽的掩码区域（各约 5 列宽、占网格上部约 8 行）。
- 左半区包含绿(3)前景像素在黑背景上构成一个 4-连通不规则形状（约 5-10 像素）。
- 右半区包含黄(4)前景像素在黑背景上构成另一个 4-连通不规则形状，与左半区部分位置重合、部分不同。
- 网格下部有一个由橙(7)像素围成的矩形空腔（单像素厚的封闭框），空腔内部全为黑(0)。空腔不与掩码区域重叠，不与分隔列重叠。
- 生成约束：左右半区行数列数相同，使得逐单元格对齐有意义。异或结果非空（两个掩码不完全相同）且非全覆盖。空腔内部宽高分别为异或结果 bbox 宽高的正整数倍。

**规则**：
1. 找到灰(5)垂直满列作为分隔线。将分隔线左侧的掩码区域和右侧的掩码区域逐行逐列对齐。
2. 对每对对齐的单元格，若恰好一侧为前景（绿(3)或黄(4)）而另一侧为黑(0)背景，则标记该位置为"差异位"；若双方都是前景或都是背景，则不标记。
3. 取所有差异位的 bbox 作为种子图案。在种子 bbox 内，差异位像素涂蓝(1)，非差异位像素保持黑(0)。
4. 找到橙(7)矩形框围成的空腔。以种子图案的左上角与空腔内部左上角对齐，沿行列方向重复平铺，直到填满空腔内部。平铺时保留种子内部黑(0)位为空腔背景色，蓝(1)位涂蓝(1)。
5. 分隔列、橙框、原始掩码区域均保持不变。

**关键洞察**：种子图案不在输入中直接出现，必须通过两侧掩码的异或运算才能推导出来；不同示例中两掩码的差异形状不同，导致平铺图案完全不同。
