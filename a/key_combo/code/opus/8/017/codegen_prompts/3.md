## 新题 3：主干臂延伸遇走廊则变色贯穿

**组合逻辑**：[连线（主干+垂直臂）](已有) → [射线延伸 + 走廊检测](创新：走廊测试作用于臂的远端延伸方向，而非边界像素之间) → [重涂色](创新：涂色结果取决于走廊是否畅通)

**来源原语**：连线、控制像素、主干线段、连接到主干、共行列定义主干(bf89d739)；射线延伸、走廊、对边连通、无阻挡跨行列涂色(2bee17df)；重涂色(d931c21c)

**依赖链**：红像素中共行列的一对定义主干 → 其余红像素沿垂直方向连接到主干形成臂 → 每条臂从其红像素端点向远离主干的方向延伸射线至网格边缘 → 若射线路径上全为背景则该臂整体（含延伸段）涂绿(3)；若被其他前景像素阻挡则仅保留臂本身涂蓝(1)，阻挡像素不变。主干的检测决定臂的方向，臂的延伸检测决定臂的颜色——三步不可分割。

找到红色像素中共行或共列的一对构成主干，其余红像素垂直连接到主干形成臂，然后每条臂向远离主干方向做走廊测试：畅通则连同延伸段涂绿，受阻则仅臂涂蓝。

**输入结构**：
- 约 15x15 的网格，背景色为黑(0)。
- 网格中仅有红(2)和灰(5)两种前景色。
- 红(2)像素共 5-8 个，全为单像素点。其中恰好有一对红像素共享同一行或同一列，且该行/列不被其他红像素共享——该对定义主干。
- 其余红像素各自与主干方向垂直对齐（若主干水平，则各控制点与某主干像素在同一列上；若主干垂直，则在同一行上），且垂直坐标位于主干跨度范围内。
- 灰(5)像素为少量（2-4 个）分散的障碍物，位于部分红像素远离主干方向的延伸路径上。
- 生成约束：每个非主干红像素到主干之间全为背景（无障碍物）。部分红像素向远离主干方向到网格边缘之间有灰(5)阻挡，部分无阻挡。主干两端点之间也全为背景。

**规则**：
1. 在所有红(2)像素中找到恰好共享一行或一列的唯一一对——将它们之间的路径（含两端点）识别为主干。主干端点保持红(2)，端点之间的背景单元格涂橙(7)。
2. 对每个非主干红像素 P，画一条从 P 到主干的垂直连线（沿与主干方向垂直的方向），P 本身保持红(2)，P 与主干之间的背景像素涂橙(7)。
3. 对每个非主干红像素 P，从 P 沿远离主干的方向（即连线方向的反向）向网格边缘发射一条射线：
   - 若射线路径上直到网格边缘全为黑(0)背景（无灰(5)阻挡），则将该射线路径上的所有背景像素涂绿(3)，并将 P 与主干之间原本涂为橙(7)的连线像素也改涂为绿(3)，P 自身也涂为绿(3)。
   - 若射线路径在到达网格边缘前遇到灰(5)像素，则射线不绘制。P 与主干之间的连线像素保持橙(7)，P 自身保持红(2)。灰(5)阻挡像素保持不变。
4. 主干本身（两端红像素之间的橙色段及端点红像素）始终保持不变，不受臂测试影响。

**关键洞察**：同一结构（红色控制像素到主干的连接臂）会因远端走廊是否畅通而呈现完全不同的颜色——畅通臂变绿并贯穿至网格边缘，受阻臂保持橙色且不延伸；判断畅通与否需要考察每条臂各自方向上是否有灰色障碍。
