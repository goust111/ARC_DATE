## 新题 8：帧内象限掩码密度驱动方向性同心扩展

**组合逻辑**：[裁剪 + 角标色定象限涂色](已有) + [计数](创新：计数对象从标记像素变为各象限中的掩码像素密度) + [同心扩展](创新：扩展不再由内矩形尺寸决定，而是由掩码密度最高象限的方向决定，且仅向该方向单侧扩展)

**来源原语**：裁剪、边框、象限、角标像素、角标色定象限涂色(77fdfe62)；计数(878187ab/8e301a54)；同心扩展、内尺寸定扩展量、外围层(3a301edc)

**依赖链**：帧裁剪 → 象限划分并按角标色重涂 → 计算每个象限的掩码像素数 → 密度最高的象限决定扩展方向 → 以帧为核心向该方向做单侧同心扩展。象限涂色的中间结果（各象限的颜色分布）是计数步骤的输入，计数的结果又驱动几何扩展——三步形成不可跳过的推理链。

一个带角标的矩形帧内部的掩码按象限重涂后，掩码像素最密集的象限决定帧向外扩展的唯一方向。

**输入结构**：黑(0)背景网格，约 18x18。网格中有一个灰(5)矩形帧（宽度 1 像素的矩形环，内外边长差 2），帧的四个对角方向外侧各有一个单像素角标（四个角标颜色各不相同，从蓝(1)、红(2)、绿(3)、黄(4)中选取）。帧内部在黑(0)背景上有若干橙(7)掩码像素，分布不均匀——某一个象限的掩码像素明显多于其他三个象限。帧足够大（内部至少 8x8）以使四个象限的掩码密度差异明确。生成约束：恰好有一个象限的掩码像素数严格最多（无并列）；帧与网格边界之间在扩展方向上至少有 3 行或 3 列的空间。

**规则**：
1. 识别灰(5)矩形帧，裁剪其内部矩形区域（不含帧本身）。
2. 将内部矩形均分为四个象限（左上、右上、左下、右下）。若行列数为奇数则中间行/列归属左上象限。
3. 将每个象限中的橙(7)掩码像素重涂为该象限对应角标的颜色（左上角标色、右上角标色、左下角标色、右下角标色）。
4. 计算四个象限各自的掩码像素数量，找到密度最高的象限（称为主象限）。
5. 确定主象限相对于帧中心的方向（例如主象限为右下 → 方向为向右且向下）。
6. 以帧的外边界为起点，仅在主象限方向上添加一层同心扩展：
   - 若主象限在右侧（右上或右下）：在帧右侧外部添加一列，高度等于帧外边界高度，颜色为主象限的角标色。
   - 若主象限在下方（左下或右下）：在帧下方外部添加一行，宽度等于帧外边界宽度，颜色为主象限的角标色。
   - 若主象限在角落（如右下），则同时向右添加一列和向下添加一行，交汇角格也填充该色。
   - 同理处理左上（向左+向上）、右上（向右+向上）、左下（向左+向下）方向。
7. 帧本身、角标像素和重涂后的内部掩码保持不变。

**关键洞察**：同心扩展在源题(3a301edc)中是对称的四方向均匀扩展，其尺寸由内矩形几何确定。在本题中扩展变为非对称的单方向扩展，且驱动方向不来自几何属性，而来自统计属性（象限掩码密度）。象限重涂步骤看似仅是着色，实则是为密度比较创建分组依据——不做重涂分组就无法正确计数各象限的像素。
