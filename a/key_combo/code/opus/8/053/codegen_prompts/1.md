## 新题 1：面积仲裁的光环扩展与核心标记

**组合逻辑**：[邻域扩展](已有) + [面积比较](创新：从筛选语境改为冲突仲裁语境) + [重涂色](创新：从象限着色改为核心/光环区分标记) + [冲突优先级](已有)

**来源原语**：邻域扩展、仅填背景格、光环区域(dc1df850)；连通分量、面积比较、保留最大连通分量(1f85a75f)；重涂色(77fdfe62)；冲突优先级(d6542281)

**依赖链**：连通分量分析确定每个对象的像素集合 → 邻域扩展产生光环区域 → 光环重叠处需要面积比较来仲裁归属 → 仲裁完成后才能确定哪些是原始核心像素、哪些是光环像素 → 核心像素重涂色为灰(5)。删除任一步骤都无法得到正确输出：无面积比较则重叠区域归属不确定；无重涂色则无法区分核心与光环；无邻域扩展则无光环可言。

在黑(0)背景上，多个不同颜色的小型前景对象各自向外扩展一圈光环；当光环交叠时，面积更大的对象赢得争议像素；扩展完成后，每个对象的原始像素被标记为灰色以区分核心与光环。

**输入结构**：黑(0)背景网格，约 14x14。网格上散布 3~5 个互不相邻的单色 4-连通前景对象，每个对象使用不同的颜色（从蓝(1)、红(2)、绿(3)、黄(4)、橙(7)中选取），每个对象由 3~8 个像素组成，形状为不规则的 4-连通单色图形（非矩形，各示例中同色对象的具体形状不同）。不同对象之间的最近距离在 2~4 个像素之间，保证部分光环会重叠但对象本身不相邻。生成约束：任意两个对象的像素面积互不相等，以确保面积仲裁无歧义。

**规则**：
1. 识别所有 4-连通单色前景对象，记录每个对象的像素集合与像素面积。
2. 对每个对象的每个像素，将其 Chebyshev 距离 1 邻域（3x3 区域）中的所有黑(0)背景格标记为该对象的候选光环格。
3. 若某背景格同时被两个或多个对象标记为候选光环格，则该格归属于像素面积最大的那个对象，涂上该对象的颜色。
4. 无争议的候选光环格直接涂上对应对象的颜色。
5. 所有光环确定后，将每个对象的原始核心像素（非光环像素）重涂为灰(5)。

**关键洞察**：面积比较在源题(1f85a75f)中用于筛选保留哪个分量，但在本题中转变为空间冲突的仲裁依据——面积不再决定"谁被保留"，而是决定"谁占领争议领土"。求解者必须同时追踪对象面积和光环几何才能确定每个重叠像素的归属。
