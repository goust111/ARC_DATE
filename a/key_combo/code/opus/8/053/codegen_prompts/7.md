## 新题 7：跨尺度形状匹配提取比例因子驱动第三对象的滑动

**组合逻辑**：[形状匹配 + 跨尺度同形](已有) + [滑动 + 超界裁剪](创新：位移量不再是对象自身面积，而是从另一对对象间提取的缩放比例) + [擦除 + 干扰项忽略](已有)

**来源原语**：形状匹配、跨尺度同形、缩放对象、干扰对象、返回较小者(ce602527)；滑动、面积决定位移、超界裁剪(8e301a54)；擦除(87ab05b8)

**依赖链**：跨尺度形状匹配 → 识别配对并提取缩放因子 K；配对中较小者的边界框高度 H → 位移量 = K x H；第三对象（干扰项）按此位移量向下滑动并裁剪超界部分。形状匹配的结果（K 值）直接参数化滑动操作，二者不可分离：不做匹配就不知道 K，不知道 K 就无法计算位移。

在三个前景对象中找到跨尺度同形的一对，提取其缩放因子；用该因子乘以较小匹配对象的高度作为第三个对象的下滑距离。

**输入结构**：黑(0)背景网格，约 16x16。网格上有三个不同颜色的 4-连通单色前景对象（从蓝(1)、红(2)、绿(3)、黄(4)、品红(6)中选取三种），每个对象占 4~20 像素，形状为不规则连通图形。其中恰好两个对象具有相同形状但不同尺寸（一个是另一个的 2 倍或 3 倍缩放），第三个对象形状独特不与任何其他对象匹配。三个对象互不相邻，间距至少 2 像素。缩放后的较大对象可能被网格边界裁剪（仅部分可见）。生成约束：两个匹配对象之间的缩放因子恰好为 2 或 3（整数倍）；第三个对象的形状不是前两个形状的任何整数缩放。

**规则**：
1. 对每对前景对象尝试缩放匹配：将较小者的掩码放大 2 倍和 3 倍，检查是否与较大者的掩码一致（允许较大者被网格边界裁剪，仅比较网格内部分）。
2. 找到匹配对后，记录缩放因子 K（2 或 3）和较小匹配对象的边界框高度 H。
3. 擦除两个匹配对象（涂为黑(0)），保留第三个对象（"干扰项"在此题中反转为操作目标）。
4. 将第三个对象整体向下滑动 K x H 行，保持列坐标不变。超出网格底部的像素裁剪丢弃。
5. 清除第三个对象的原始位置（涂为黑(0)）。

**关键洞察**：源题(ce602527)中"干扰项"被丢弃而匹配对的较小者被保留输出，本题反转了这一角色——匹配对被丢弃，"干扰项"反而成为唯一的操作对象。更关键的是，匹配对虽被擦除，但从它们中提取的缩放因子仍然影响干扰项的运动，形成"消失的信息源仍在驱动变换"的结构。
