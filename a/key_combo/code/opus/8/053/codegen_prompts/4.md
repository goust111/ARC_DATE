## 新题 4：同心嵌套深度作为模板查表键

**组合逻辑**：[同心嵌套 + 严格内嵌](已有) + [计数](创新：计数对象从像素变为嵌套层数) + [查表映射 + 编码映射 + 固定模板](创新：查表键从主色身份变为几何深度值)

**来源原语**：同心嵌套、严格内嵌、矩形框、内部矩形、外围层(3a301edc)；计数(878187ab/8e301a54)；查表映射、固定模板、编码映射(9110e3c5)

**依赖链**：识别同心矩形框 → 计算嵌套层数 → 层数作为键查表 → 输出对应模板。如果不先正确识别同心结构就无法计数层数；如果不知道查表规则就无法从层数得到输出。此外最内层帧的偏心方向附加影响输出模板的朝向，使得嵌套几何分析和模板选择之间产生更深的耦合。

多层同心矩形框的嵌套深度编码一个离散类别，通过查表映射为一个固定 3x3 模板输出；最内层帧的偏心方向决定模板的朝向。

**输入结构**：黑(0)背景网格，约 15x15。网格中心区域有一组同心矩形框，每层框用不同颜色绘制（从蓝(1)、红(2)、绿(3)、黄(4)、橙(7)中按从外到内的顺序选取），每层框是宽度为 1 像素的矩形环。嵌套层数在 2~4 之间。最内层框的内部为黑(0)。最内层框不一定严格居中于次外层——它可能在水平或垂直方向上偏移 1 个像素（偏左、偏右、偏上或偏下）。生成约束：每层框严格内嵌于上一层框内部；相邻两层框之间至少间隔 1 行 1 列的黑(0)空间。

**规则**：
1. 识别所有同心矩形框层，计算嵌套层数 N。
2. 查表确定基础模板（3x3 黑(0)网格上的青(8)模板）：
   - N=2 → 青(8)填充左列（第 0 列三个格），即竖条模板；
   - N=3 → 青(8)填充中间行（第 1 行三个格），即横条模板；
   - N=4 → 青(8)填充主对角线（(0,0)、(1,1)、(2,2)三个格），即对角线模板。
3. 检测最内层框相对于次外层框的偏心方向：
   - 若最内层框水平居中且垂直居中 → 模板不旋转；
   - 若偏右 → 模板顺时针旋转 90 度；
   - 若偏下 → 模板旋转 180 度；
   - 若偏左 → 模板逆时针旋转 90 度（即顺时针 270 度）；
   - 若偏上 → 模板不旋转（与居中相同处理）。
4. 输出旋转后的 3x3 模板。

**关键洞察**：嵌套深度是一个从几何拓扑中抽取的离散量，功能等价于源题(9110e3c5)中的"主色类别"——都是从噪杂输入中提炼出的紧凑分类符号，但编码方式从颜色身份变为空间结构深度。偏心方向作为第二信号轴进一步约束输出，使得仅靠层数查表不够，还需分析空间对称性。
