## 新题 6：调色板行缺口定中心的瓦片阵列与逐列着色

**组合逻辑**：[平铺 + 阵列排布 + 瓦片](已有) + [以缺口为中心](创新：缺口从楔形展开的中心轴变为瓦片阵列的对齐锚点) + [重涂色](创新：调色板行既是颜色图例又是空间定位依据) + [调色板行](已有)

**来源原语**：平铺、阵列排布、瓦片(00576224)；调色板行、以缺口为中心、标记竖条(bae5c565)；重涂色(77fdfe62/cfb2ce5a)

**依赖链**：调色板行中的缺口位置 → 决定瓦片阵列的水平中心对齐列；调色板行中各格的颜色 → 决定该列所有瓦片的重涂色。缺口同时承载空间锚定和颜色例外（保持原色）两个语义。瓦片的几何排布和颜色分配被调色板行这一单一结构同时约束，二者无法独立求解。

调色板行中的每个彩色格定义对应列瓦片的颜色，缺口定义瓦片阵列的水平对齐中心且该列瓦片保持原始灰色。

**输入结构**：黑(0)背景网格，约 16x16。第 0 行是调色板行：该行的大部分格各有一种不同的非黑颜色（从蓝(1)、红(2)、绿(3)、黄(4)、橙(7)、青(8)中选取），其中恰好有一个格为黑(0)（即缺口）。调色板行的长度与网格宽度相同。第 1 行以下是黑(0)区域，其中有一个灰(5)小瓦片图案（2x2 或 2x3 的矩形区域内由灰(5)和黑(0)像素组成的小图案），位于网格中央偏左或偏右的位置。生成约束：网格宽度能整除瓦片宽度或近似整除（余数列不放置瓦片）；调色板行中各非黑格颜色互不相同。

**规则**：
1. 提取调色板行（第 0 行）和灰(5)瓦片图案（第 1 行以下的灰(5)连通块的紧凑边界框）。
2. 确定缺口列（调色板行中唯一的黑(0)格所在列）。
3. 在第 1 行以下的区域构建瓦片阵列：以缺口列为中心向两侧铺设瓦片列，每个瓦片列的宽度等于瓦片宽度，纵向从第 1 行开始向下重复铺设直到网格底部。
4. 若某瓦片列完全超出网格左右边界则不绘制。
5. 对每个瓦片列，取其中心列（若瓦片宽度为偶数则取左半的最右列）对应的调色板行颜色，将该瓦片列中所有灰(5)像素重涂为该颜色。
6. 中心列（缺口列）对应的瓦片列保持灰(5)不重涂。
7. 调色板行本身保持不变。

**关键洞察**：调色板行的缺口在源题(bae5c565)中是楔形展开的中心轴，在本题中变为瓦片阵列的对齐锚点——同一个"缺口"概念的空间角色完全改变。同时，调色板行中每个格的颜色不再是被逐行展开复制的对象，而是作为查表图例为对应列瓦片着色，使得一行信息同时编码位置和颜色两个维度。
