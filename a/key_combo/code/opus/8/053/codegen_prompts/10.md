## 新题 10：瓦片阵列中基于字形查表结果的选择性镜像

**组合逻辑**：[平铺 + 中间行翻转](创新：翻转行不固定为中间行，而是由查表匹配结果动态决定) + [查表匹配 + 对齐判定结果](创新：判定结果不再是底部色带的颜色，而是控制瓦片阵列中哪些行/列的瓦片被镜像) + [镜像](已有)

**来源原语**：平铺、瓦片、阵列排布、中间行翻转(00576224)；查表匹配、字形单元格、参考表、查询行、对齐判定结果、完整行列对齐(d8e07eb2)；镜像(cfb2ce5a/00576224)

**依赖链**：查表匹配确定哪些表格单元格被命中 → 命中的单元格所在行/列索引集合 → 在瓦片阵列中，这些索引对应的瓦片行/列使用镜像版本的瓦片，其余行/列使用原始瓦片。查表结果和平铺的耦合是通过索引映射实现的——改变查表结果直接改变瓦片阵列的对称结构。

一个小瓦片被铺成阵列，但哪些行的瓦片需要左右镜像取决于另一个查表匹配结构的命中行号。

**输入结构**：黑(0)背景网格，分为上下两个区域，由一条完整的品红(6)水平分隔行隔开。上方区域约 10 行高，包含一个参考查表结构：青(8)背景上有一行 3~4 个字形单元格（每个字形在 3x3 的单元格内用某种前景色绘制一个简单图案），下方紧跟一个 3~4 行 x 3~4 列的参考表，每格也是 3x3 字形单元格。上方区域的最上一行是查询行（含 3~4 个字形）。下方区域约 8~10 行高，左侧有一个 2x2 的小瓦片图案（由两种颜色如红(2)和绿(3)组成，不对称），右侧为空白。生成约束：瓦片不具有水平对称性；查询字形至少有一个能在参考表中匹配到。

**规则**：
1. 在上方区域执行查表匹配：将查询行中的每个字形与参考表中的所有字形比较（匹配条件：颜色和 3x3 形状完全一致）。
2. 记录所有命中的参考表单元格的行索引（参考表内部的行号，从 0 开始）。
3. 在下方区域，用 2x2 瓦片构建一个瓦片阵列，填满分隔行以下的整个区域（行列方向尽可能铺满，不足一个瓦片的边缘不铺）。
4. 对瓦片阵列中的每一瓦片行（从 0 开始编号）：若该行号出现在步骤 2 的命中行索引集合中，则该行的所有瓦片使用原始瓦片的水平镜像版本；否则使用原始瓦片。
5. 上方区域（含分隔行）保持不变。

**关键洞察**：源题(00576224)中镜像行固定为"中间行"，源题(d8e07eb2)中查表结果只控制底部色带颜色。本题中查表结果通过行索引映射动态选定了平铺阵列中哪些行发生镜像——两个原本毫无关联的操作（字形查表与瓦片翻转）通过"行索引"这个抽象接口耦合在一起，产生了源题中均不存在的结构关系。
