## 新题 5：噪声过滤提取印章模板并按锚点颜色匹配放置

**组合逻辑**：[保留最大连通分量 + 裁剪](创新：裁剪结果不是最终输出，而是后续印章操作的模板) + [印章放置 + 锚点标记 + 颜色匹配](创新：模板不预设于输入的独立区域，而是从过滤步骤动态提取) + [擦除 + 干扰项忽略](已有)

**来源原语**：连通分量、面积比较、保留最大连通分量、裁剪、噪声像素(1f85a75f)；印章放置、锚点标记、颜色匹配、最少色为锚点(a251c730)；擦除、干扰项忽略(87ab05b8)；仅填背景格(dc1df850)

**依赖链**：噪声过滤（识别并丢弃小分量）→ 提取最大分量作为模板（裁剪其边界框）→ 在锚点位置印章。过滤步骤的结果直接决定印章的内容——如果错误地保留了噪声或丢弃了信号，印章模板就会出错，所有后续印章位置的输出都会连锁出错。

从噪声前景中过滤出唯一的大型连通分量作为印章模板，然后在网格中散布的锚点标记位置印上该模板。

**输入结构**：黑(0)背景网格，约 18x18。网格上有一个较大的 4-连通单色前景对象（蓝(1)，8~15 像素，形状为不规则连通图形），以及若干噪声像素（红(2)或绿(3)，每个噪声分量仅 1~2 像素，总共 3~6 个噪声像素，随机散布）。另外有 1~3 个品红(6)单像素锚点标记，散布在网格的其他位置，与所有前景对象不相邻。锚点标记之间、以及锚点与大型对象之间的距离足够大，保证以锚点为中心放置模板后各副本之间不重叠。生成约束：蓝(1)对象是唯一面积 >= 3 的前景连通分量。

**规则**：
1. 识别所有 4-连通单色前景连通分量（忽略颜色差异，每个分量内部单色）。
2. 计算每个分量的面积。面积 <= 2 的分量视为噪声，擦除为黑(0)。
3. 面积最大的分量是信号对象。裁剪其紧凑边界框，得到一个小矩形模板（保留内部的黑(0)背景孔洞）。
4. 擦除信号对象在原始网格中的位置（涂为黑(0)）。
5. 对每个品红(6)锚点标记，将模板印章到网格上，使模板的几何中心（边界框中心，向下向右取整）与锚点位置对齐。印章时仅覆盖黑(0)背景格，不覆盖其他锚点标记。
6. 印章的颜色使用信号对象的原始颜色（蓝(1)）。品红(6)锚点标记在印章完成后保留不变。

**关键洞察**：源题(a251c730)的印章模板是输入中预设的独立区域，而本题中模板必须通过噪声过滤和裁剪从混杂的前景中"发现"——模板提取和印章放置形成紧密的上下游依赖，过滤阈值的判断直接影响印章内容。
