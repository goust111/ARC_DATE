## 新题 2：象限编码翻转方式的递归印章

**组合逻辑**：[递归印章 + 格位映射](已有) + [所属象限](创新：从区域填充选择器变为翻转类型编码器) + [镜像/翻转对应](创新：从固定模板翻转变为由控制像素位置动态选择的翻转)

**来源原语**：递归印章、控制像素、格位映射、输入图案(cce03e0d/ad7e01d0)；所属象限、控制像素(87ab05b8)；镜像、翻转对应(cfb2ce5a/00576224)

**依赖链**：控制像素的位置同时编码两个信息——它在哪个格位（决定输出中的哪个块）以及它在输入的哪个象限（决定该块内的图案如何翻转）。格位映射和象限归属是对同一个像素坐标的两种读取方式，二者缺一不可：缺格位映射则不知道印在哪里，缺象限归属则不知道印什么方向。

红(2)控制像素的位置同时决定在输出的哪个块印章、以及印章的翻转方式——落在输入左上象限则原样印，右上则水平翻转印，左下则垂直翻转印，右下则双轴翻转印。

**输入结构**：一个偶数边长的小网格（4x4 或 6x6），黑(0)背景上有一个由非红色前景像素（如蓝(1)、绿(3)等混合）构成的不对称图案，以及若干红(2)控制像素散布在图案内部或空白区域。红(2)像素不超过 4 个。网格行列数相等且为偶数，保证能均分为四个象限。生成约束：图案本身不具有水平或垂直对称性（否则翻转无法区分）；至少有两个红(2)像素落在不同象限中。

**规则**：
1. 将输入网格视为源图案（红(2)像素也是图案的一部分）。
2. 构造输出网格：每个输入像素对应输出中一个与输入同尺寸的块，输出总尺寸为（输入行数 x 输入行数）行 x（输入列数 x 输入列数）列。
3. 将输入均分为四个象限：左上（行 < H/2 且列 < W/2）、右上（行 < H/2 且列 >= W/2）、左下（行 >= H/2 且列 < W/2）、右下（行 >= H/2 且列 >= W/2）。
4. 对每个红(2)控制像素，根据其所属象限确定翻转方式：左上象限 → 不翻转；右上象限 → 水平翻转（左右镜像）；左下象限 → 垂直翻转（上下镜像）；右下象限 → 水平+垂直翻转（等价 180 度旋转）。
5. 将经过相应翻转的完整输入图案印入该控制像素对应的输出块中。
6. 非红(2)的输入像素对应的输出块全部填充黑(0)。

**关键洞察**：控制像素的坐标被同时用于两个独立用途——整数格位索引选定输出块位置，而同一坐标的象限归属选定翻转变换。求解者若只注意到递归印章的放置逻辑而忽略象限编码的翻转规则，将无法解释不同块中图案方向的差异。

Infer the repeated sprite from fully visible mixed-color blocks. Replace a
