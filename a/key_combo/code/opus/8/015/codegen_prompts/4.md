## 新题 4：行控制色重涂与连通融合填孔

**组合逻辑**：[重涂色/recolor](已有) + [每行独立取色/per_row_color](已有) → [连通分量检测/connected_component_detection](创新：在重涂产生的新颜色分布上检测连通分量) → [填充/fill](创新：对因融合而产生的封闭孔洞进行填充)

**来源原语**：重涂色(recolor)、占位像素(placeholder_pixel)、行控制色(row_control_color)、每行独立取色(per_row_color)、同行对齐(same_row_align) ← 参考题 c7d4e6ad；连通分量检测(connected_component_detection) ← 参考题 14754a24；洪泛填充(flood_fill)、路径连通(path_connectivity) ← 参考题 b782dc8a

**依赖链**：行控制色重涂赋予每行灰像素不同颜色；重涂后相邻行若恰好获得相同颜色，原本分离的灰色区块在颜色空间上融合为同一 4-连通分量；融合可能包围出新的黑色孔洞，这些孔洞被同色填充。重涂是融合的前提（不重涂则所有灰色区块已经同色，无法区分哪些该融合），融合是填孔的前提（不融合则无封闭孔洞），填孔依赖融合后的边界（不填则孔洞残留）。

用行控制色替换灰像素后，同色相邻区域融合，被融合区域完全包围的黑色孔洞用该颜色填充。

**输入结构**：约 12x12 黑(0)背景网格。灰(5)像素形成若干 4-连通的不规则形状（每个形状跨越 2~5 行，宽 3~6 像素，形状之间可能仅隔 1 行黑像素）。网格最右列为标记列，每个含灰像素的行在该列有一个非黑非灰的控制色像素（从蓝(1)、红(2)、绿(3)、黄(4)中选取）。生成约束：至少存在两个原本不 4-连通的灰色形状，在重涂后因相邻行获得相同控制色而 4-连通融合；至少一次融合会包围出一个或多个纯黑(0)的封闭孔洞（孔洞的所有 4-连通黑像素均不与网格边界相邻，且其所有 4-邻居要么是同一连通分量的像素要么是孔洞自身的像素）；标记列的控制色不全部相同。

**规则**：
1. 将每个灰(5)像素替换为该行标记列中的控制色。标记列的控制色像素本身保留不变。
2. 在重涂后的网格上，检测所有 4-连通同色前景连通分量。
3. 对每个连通分量，检查其是否完全包围了一个或多个黑(0)孔洞。孔洞定义：一组 4-连通的黑像素，该组中没有任何像素位于网格的第一行、最后一行、第一列或最后一列，且该组的所有 4-邻居要么属于该组自身要么属于同一个前景连通分量。
4. 将每个被完全包围的孔洞用包围它的连通分量的颜色填充。
5. 未被包围的黑像素（与网格边界 4-连通可达的）保持黑色。

**关键洞察**：控制色的分配不仅改变颜色，还改变拓扑——两个形状是否融合取决于它们接触行的控制色是否相同，而融合后的形状边界可能围出原本不存在的封闭区域。求解者需要对比多个示例（有些行颜色相同导致融合和填孔，有些行颜色不同保持分离和无孔）才能发现这一涌现效应。
