## 新题 6：引导条投射转对角射线

**组合逻辑**：[压缩/compress](已有) + [投射落间隙则擦/erase_if_gap](已有) → [射线延伸/ray_extend](创新：从引导条位置而非原始位置出发发射对角线射线) + [对角方向/diagonal_dir](创新：方向由像素原来在引导条哪一侧决定) → [擦除/erase](创新：引导条在输出中消失)

**来源原语**：压缩(compress)、引导条(guide_bar)、散布像素(scattered_pixel)、投射到引导条(project_to_guide)、投射落间隙则擦(erase_if_gap) ← 参考题 f83cb3f6；射线延伸(ray_extend)、对角方向(diagonal_dir)、角位控制射线(corner_controls_ray) ← 参考题 1f0c79e5；擦除(erase) ← 参考题 3dc255db

**依赖链**：压缩步骤将散布像素投射到引导条旁，过滤掉间隙处的像素并确定存活像素的引导条坐标；存活像素从引导条位置出发发射对角线射线，方向由原始侧别编码；引导条本身在输出中被擦除。引导条是瞬态结构——输入中存在（用于过滤和定位），输出中消失（只留射线痕迹）。

散布像素投射到引导条过滤存活后，从引导条位置沿对角线射出，方向取决于像素原来在引导条的哪一侧，引导条自身消失。

**输入结构**：约 15x15 黑(0)背景网格。一条垂直的绿(3)引导条（单像素宽），位于网格中部偏左（约第 4~5 列），含 1~2 个间隙（间隙处为黑(0)）。引导条左侧散布若干红(2)孤立像素；引导条右侧散布若干蓝(1)孤立像素。每个散布像素与引导条在同一行（即水平投射必定命中引导条的某一格或间隙）。生成约束：至少一个红像素和一个蓝像素的投射落在间隙上（被擦除）；存活的红和蓝像素至少各有 2 个；不同散布像素不在同一行；存活像素的射线在网格内有足够空间展开（不立即碰到边界）。

**规则**：
1. 对每个散布像素，水平投射到引导条。若该像素所在行的引导条格为间隙（黑色），该像素被擦除，不产生任何输出。
2. 存活像素确定其在引导条旁的发射位置：行号 = 原像素的行号，列号 = 引导条列号 - 1（原来在左侧的）或引导条列号 + 1（原来在右侧的）。
3. 每个存活像素从发射位置出发，沿两个对角方向各发射一条射线：原在引导条左侧的红(2)像素向右上和右下各发一条红色射线；原在引导条右侧的蓝(1)像素向左上和左下各发一条蓝色射线。
4. 射线沿 45 度对角线延伸，每步画一个与发射源同色的像素，直到碰到网格边界停止。
5. 若两条射线交叉在同一格，按发射源在引导条上从上到下的顺序绘制，后绘制的覆盖先绘制的。
6. 输出中引导条被擦除（所有绿(3)像素变为黑(0)），只保留射线像素和发射位置像素。

**关键洞察**：引导条是瞬态结构——它在输入中作为空间滤波器（间隙过滤）和定位锚点（确定射线起点），在输出中完全消失。像素原来在引导条哪一侧的信息通过射线方向被"记忆"在输出中。求解者需要对比输入和输出发现引导条消失、射线出现的对应关系。
