## 新题 5：射线穿越引导线计数驱动垂直平移

**组合逻辑**：[射线延伸/ray_extend](已有) → [穿越计数](创新：射线穿越引导线的次数替代面积作为位移量) → [平移/translate](已有，创新条件：位移=穿越数而非面积)

**来源原语**：射线延伸/ray_extend、引导线/guide_line、投射到引导线/projection_to_guide（来自 ac3e2b04）；平移/translate、全宽条纹/full_width_stripe、位移等于面积/shift_equals_area（来自 b2bc3ffd，创新为"位移等于穿越数"）

**依赖链**：每个对象内的灰像素位置 → 决定射线路径 → 射线穿越引导线的次数依赖于对象与引导线的空间关系 → 穿越次数成为该对象的垂直位移量 → 对象向上平移。删除射线步骤则无法获得穿越数；删除平移步骤则穿越数无处使用。同一对象在引导线增减后位移量会改变——位移是外部空间关系的函数而非对象自身属性。

从每个对象的灰像素向下发射射线，计算穿越水平引导线的次数，将对象整体向上平移该次数个格子。

**输入结构**：一个约 12x15 的网格，黑(0)背景。网格中有 2~4 条全宽水平红(2)引导线，均匀或不均匀分布。底部有一条全宽黄(4)条纹作为固定基线。在黄条纹上方、引导线之间或之上，散布 3~4 个小型单色 4-连通对象（每个 3~6 像素，颜色互不相同，取自蓝(1)、绿(3)、橙(7)、栗(9)）。每个对象内恰好有一个像素被替换为灰(5)——该像素是射线发射点，其余像素保持对象颜色。生成约束：各对象向上平移后不超出网格顶部、不互相重叠、不与引导线重叠；对象初始位置不与引导线重叠。

**规则**：
1. 对每个对象，从其灰(5)像素的位置向下（行号增大方向）发射一条垂直射线，直到到达黄(4)条纹。
2. 计算该射线穿越的红(2)引导线数量（射线经过的红色像素所在的不同行数），记为 C。
3. 将整个对象（包括其灰像素）向上平移 C 个像素（行号减少 C）。擦除对象原始位置。
4. 红(2)引导线和黄(4)条纹保持不变。
5. 从每个对象平移后的灰(5)像素位置向下绘制一条灰(5)垂直线段，直到碰到红(2)引导线或黄(4)条纹（不含终点），仅绘制在背景像素上。

**关键洞察**：与参考题 b2bc3ffd 中"位移=自身面积"不同，这里位移量由对象与引导线的外部空间关系决定。相同形状和大小的两个对象，若一个在所有引导线之上、另一个在所有引导线之下，位移量截然不同。需要对比示例确认位移来源是穿越数而非面积或其他属性。
