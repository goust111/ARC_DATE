## 新题 2：连通分量面积索引同心方环

**组合逻辑**：[面积计算/area_comparison](已有) → [面积→切比雪夫距离映射](创新：面积数值转化为空间坐标) → [同心方环填充/concentric_ring + fill](已有) ＋ [多像素涂色留单/multi_recolor_single](已有，创新用法：单像素分量保留原位且涂中心)

**来源原语**：重涂色/recolor、连通分量/connected_component、面积比较/area_comparison、多像素涂色留单/multi_recolor_single（来自 67385a82）；填充/fill、同心方环/concentric_ring、距离映射/distance_mapping、切比雪夫距离/chebyshev_distance、中心对齐/center_aligned（来自 ac0c2ac3）

**依赖链**：连通分量的拓扑结构决定面积 → 面积数值成为环距离索引 → 距离索引决定在输出中涂哪个方环 → 分量颜色决定该环的填充色。单像素分量走特殊路径：保留原位且额外填充中心格。删除面积计算则无法知道涂哪个环；删除环填充则面积信息无处体现。

将散布在奇数方阵上的各色连通分量擦除，按每个分量的面积值填充对应距离的同心方环，单像素分量保留原位并额外填充中心格。

**输入结构**：一个奇数边长的正方形网格（11x11 或 13x13），黑(0)背景。网格上散布 3~5 个单色 4-连通分量，每个分量颜色互不相同（从蓝(1)、红(2)、绿(3)、黄(4)、橙(7)中选取），面积互不相同（取值范围 1~5 像素）。各分量互不相邻（8-连通意义下不接触）。网格中心格为黑(0)背景。生成约束：所有面积值不超过 (边长-1)/2（保证对应方环完全在网格内）；不同分量面积两两不同。

**规则**：
1. 对每个面积大于 1 的连通分量：擦除其原始位置（恢复为黑(0)背景），然后将中心格的切比雪夫距离等于该分量面积的所有格子填充为该分量的颜色。即面积为 A 的分量填充距离中心恰好 A 的方环。
2. 对每个面积恰好为 1 的单像素分量：保留该像素在原始位置不动，同时将网格正中心格填充为该分量的颜色。
3. 若多个单像素分量存在，中心格取距离网格中心曼哈顿距离最近的那个单像素分量的颜色（生成时保证不出现等距平局）。
4. 各方环独立绘制，不同环之间不重叠（因为面积值互不相同）。环仅覆盖背景像素和已擦除位置，不覆盖保留的单像素分量。

**关键洞察**：分量的面积——一个数量属性——被重新解释为空间坐标（方环距离），而分量的原始空间位置对输出完全无关。单像素分量的特殊待遇（保留且涂中心）需要对比多个示例中有无单像素分量时输出的中心格差异才能归纳。
