## 新题 6：分隔叠加创建拓扑后最大者生长

**组合逻辑**：[透明叠加/transparent_overlay + 并集合并/union_merge](已有) → [连通分量拓扑分析](创新中间步骤：叠加结果的拓扑结构决定后续操作) → [生长/grow + 收缩/shrink + 面积最大者/largest_area](已有)

**来源原语**：透明叠加/transparent_overlay、分隔行/separator_row、前景掩码/foreground_mask、逐格对齐/cell_aligned、并集合并/union_merge（来自 ce4f8723）；生长/grow、收缩/shrink、前景对象/foreground_object、面积最大者/largest_area、最大外扩余内缩/max_grow_rest_shrink（来自 df978a02）

**依赖链**：上下两层掩码各自的前景图案 → 叠加并集创建新的前景分布 → 并集中 4-连通分量的数量和大小由叠加结果决定（两个原本独立的区域可能因叠加而合并为一个大分量） → 最大分量生长、其余分量收缩 → 生长/收缩的对象正是叠加产生的拓扑结构。删除叠加步骤则分量结构不同；删除生长/收缩步骤则叠加结果未经修改。

将被分隔行隔开的上下两层前景掩码做并集叠加，对叠加结果中面积最大的连通分量外扩一层、其余分量内缩一层。

**输入结构**：一个约 11x13 的网格（奇数行数），黑(0)背景。正中间有一行橙(7)分隔行，将网格分为等高的上半区和下半区。上半区有 2~3 个蓝(1)前景区域（4-连通，3~8 像素，形状不规则）。下半区有 2~3 个红(2)前景区域（4-连通，3~8 像素，形状不规则）。生成约束：上下半区对齐后，至少有一对分属上下的区域存在前景像素重叠（确保并集可能合并分量），且至少有一个分量在并集后仍然独立（确保存在大小差异）。并集后各分量面积互不相同（无平局）。最大分量外扩一层后不超出网格边界。

**规则**：
1. 去除橙(7)分隔行，将上半区和下半区逐格对齐。
2. 计算前景并集：对齐后每个格子若上半区为蓝(1)前景或下半区为红(2)前景，则该格子为前景，颜色统一设为绿(3)。仅当两者均为黑(0)背景时该格子为背景。
3. 对并集结果中的绿(3)前景像素做 4-连通分量分析，找出所有连通分量及其面积。
4. 面积最大的分量：其每个前景像素的 4-邻域中若有背景像素，则将该背景像素也涂为绿(3)（即向外扩展一层）。扩展不超出网格边界（输出网格高度 = 原网格高度减 1，即去掉分隔行）。
5. 所有其他分量：移除每个分量中处于分量边界的像素（即该像素在分量内的 4-邻域中至少有一个方向不属于同一分量）。面积为 1 或 2 的分量在此步骤后被完全擦除。

**关键洞察**：叠加并集可能将上下两个原本独立的小区域合并为一个大连通分量，改变"谁是最大者"的判定。仅看输入的上半区或下半区都无法预测输出——必须先完成并集才能确定拓扑结构，再由拓扑结构决定哪个分量生长。
