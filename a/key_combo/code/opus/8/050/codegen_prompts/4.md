## 新题 4：格子行键色控制填充色与交叉混合

**组合逻辑**：[标记像素共行/列连线填充](已有，来自 e760a62e) ＋ [行首控制像素决定填充色](已有，来自 c9f8e694，创新用法：控制色替代标记色作为填充色) → [双色交叉混合/intersect_blend_color](已有，创新用法：混合的不是标记色而是控制色)

**来源原语**：填充/fill、格子单元/lattice_cell、标记像素/marker_pixel、网格线/lattice_line、共行或共列/shared_row_col、双色交叉混合色/intersect_blend_color（来自 e760a62e）；重涂色/recolor、占位像素/placeholder_pixel、控制像素/control_pixel、同行对应/same_row_mapping、行首色决定填色/row_key_color（来自 c9f8e694）

**依赖链**：标记像素的颜色和位置 → 决定哪些格子行/列需要填充（几何信息）；控制像素的颜色 → 决定填充用什么颜色（色彩信息）；当两组填充区域在同一格子交叉时 → 需要混合规则。三条信息流在每个输出格子汇聚。删除标记则无法确定填充区域；删除控制像素则无法确定填充颜色；删除混合规则则交叉格子颜色不确定。

在格子网格中，标记像素的颜色决定哪些行列需要贯通填充，而每行首列的控制像素决定填充的实际颜色，行列交叉处使用品红混合色。

**输入结构**：一个约 15x18 的网格，由青(8)网格线划分为约 4x5 的矩形格子阵列（每个格子内部约 2x2 或 3x3 像素）。部分格子内含有一个红(2)或绿(3)标记像素（位于格子中心）。对于每个包含标记像素的格子行，该行最左侧格子内有一个"控制像素"，颜色为蓝(1)、黄(4)或橙(7)中的一种（不与标记色相同）。同一格子行内所有标记像素颜色相同（全红或全绿）。生成约束：至少有一个格子行含红标记、至少一个含绿标记；至少有一列同时出现红标记行和绿标记行的格子（保证存在交叉）。控制像素所在的最左格子不含红/绿标记。

**规则**：
1. 对每种标记色（红、绿）分别处理：找出所有含该色标记的格子行，对每行将最左标记所在格子到最右标记所在格子之间的所有格子标记为"行填充区"。同理找出所有含该色标记的格子列，对每列将最上标记到最下标记之间的所有格子标记为"列填充区"。
2. 对每个被标记为填充区的格子：其填充颜色不取标记的红/绿色，而取该格子所在格子行的最左格子中控制像素的颜色。若该格子行无控制像素（该行本身无标记，但因列填充延伸到此行），则取该列中最近的有控制像素的行的控制色（按格子行距离，先上后下）。
3. 若同一个格子同时属于"红标记源"填充区和"绿标记源"填充区（即行列交叉），则该格子填充品红(6)，无论控制像素如何。
4. 填充时整个格子内部全部涂色，保留青(8)网格线不变。原始标记像素和控制像素被填充色覆盖。

**关键洞察**：标记颜色决定的是空间几何（哪些行列贯通），不是输出颜色；输出颜色由一个完全独立的控制像素系统决定。需要对比多个示例才能发现"标记色管几何、控制色管颜色"的分离，以及交叉格子的品红规则独立于控制色。
