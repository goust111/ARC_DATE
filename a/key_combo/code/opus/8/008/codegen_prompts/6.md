## 新题 6：多源奇偶条纹射线与交叉涌现对角线

**组合逻辑**：[ray_extend + color_determines_motion](创新：颜色不再决定固定的轨迹形状，而是决定射线的基本方向——水平或垂直) + [parity_alternation](创新：奇偶交替同时作用于多条不同方向的射线) → [trail_intersection + cross_spawns_diagonal](创新：交叉效果不再仅限于红色水平与垂直轨迹的碰撞，而是任意不同方向射线的交叉) → [ray_extend 对角线](从交叉点发射)

**来源原语**：ray_extend / color_determines_motion / trail_intersection / cross_spawns_diagonal / marker_pixel / trail_segment（来自 ac605cbb）；ray_extend / parity_alternation / alternating_fill_to_edge / isolated_pixel（来自 97999447）；recolor（来自 689c358e）

**依赖链**：标记颜色编码射线方向（隐蔽规则） → 多条射线在网格中延伸并各自产生奇偶条纹 → 不同方向射线的交叉点位置由颜色-方向映射和标记位置共同决定 → 交叉点触发对角线射线。方向映射、奇偶着色、交叉检测、对角线发射形成四层耦合链。

各色标记像素沿颜色编码的方向发射奇偶交替条纹射线，不同方向射线交叉处产生黄色并向左下方发射对角线。

**输入结构**：约 15x15 网格，黑(0)背景。包含 3~5 个单像素标记，每个颜色不同。标记颜色与射线方向的映射为：红(2) → 向左延伸，蓝(1) → 向右延伸，绿(3) → 向下延伸，品红(6) → 向上延伸。同一方向最多一个标记。标记之间行列位置安排使得至少有两对不同方向的射线（一条水平、一条垂直）在网格内相交。灰(5)和黄(4)在输入中不出现，仅用于输出。

**规则**：
1. 对每个标记像素，根据颜色确定射线方向：红(2) → 左，蓝(1) → 右，绿(3) → 下，品红(6) → 上。
2. 从每个标记出发，沿射线方向逐格延伸至网格边界。距标记偶数步的像素涂为该标记颜色，奇数步涂为灰(5)。标记本身为第 0 步（保持原色）。
3. 当一条水平射线与一条垂直射线占据同一像素时，该像素涂为黄(4)。
4. 从每个黄(4)交叉像素出发，向左下方（行+1、列-1）逐格延伸至网格边界，全部涂为黄(4)。若对角线路径上遇到已有的非背景像素（标记、射线条纹、其他黄色像素），直接覆盖为黄(4)并继续延伸。
5. 同方向射线之间不产生交叉效果（若两条水平射线意外重叠，保持先绘制的颜色；绘制顺序按标记行号从小到大、行号相同按列号从小到大）。

**关键洞察**：颜色-方向映射是必须通过对比多个示例才能归纳的隐蔽规则；确认该映射后，交叉点位置完全由标记的行列位置决定，而对角线效果使得输出中出现输入中不存在的斜向结构。
