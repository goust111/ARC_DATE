## 新题 4：箭头方向编码的奇偶条纹射线

**组合逻辑**：[ray_extend + crossbar_determines](创新：箭头不再用于标记边框端点，而是为附近的标记像素指定射线发射方向) + [parity_alternation + alternating_fill_to_edge](创新：奇偶交替不再作用于单一标记的右向射线，而是作用于由箭头指定方向的多条射线) → [recolor at trail_intersection](创新：不同射线交叉处产生新颜色，而非固定的黄色对角线)

**来源原语**：ray_extend / arrow_sprite / crossbar_determines / orientation_aligned / frame_endpoint（来自 689c358e）；ray_extend / parity_alternation / alternating_fill_to_edge / isolated_pixel（来自 97999447）；trail_intersection / recolor（来自 ac605cbb）

**依赖链**：箭头横杆偏移编码方向 → 每个标记像素根据最近箭头获得射线方向 → 射线沿指定方向延伸并以奇偶交替着色 → 不同颜色射线在同一像素相交时产生混合色。方向编码、奇偶规则、交叉处理三层逻辑紧耦合。

根据箭头精灵编码的方向从各标记像素发射奇偶条纹射线，射线交叉处产生特定颜色。

**输入结构**：约 16x16 网格，黑(0)背景。包含 2~4 个单像素标记，颜色各异（如红(2)、绿(3)、蓝(1)）。另有 2~4 个灰(5)箭头精灵：每个箭头由 6 个灰色像素组成，沿主轴方向排列一条 4 像素长的杆，在杆的靠近尖端一侧排列一条 3 像素长的垂直横杆（横杆相对于杆中心的偏移方向指示箭头指向）。箭头的主轴为水平或垂直。标记像素与箭头精灵不重叠、不相邻。生成约束：每个标记像素的最近箭头（标记像素到箭头精灵任意像素的最小曼哈顿距离）是唯一的（无并列）；至少存在两条射线在网格内相交。

**规则**：
1. 对每个箭头精灵，根据横杆偏移方向确定其指向：横杆靠近杆的哪一端，箭头就指向那一端（例如水平杆上横杆偏左 → 箭头指向左；垂直杆上横杆偏上 → 箭头指向上）。
2. 对每个标记像素，找到与其曼哈顿距离最近的箭头精灵。该箭头的指向即为此标记像素的射线方向。
3. 从每个标记像素出发，沿其射线方向逐像素延伸至网格边界。沿射线方向，距标记偶数步（0, 2, 4, ...）的像素涂为标记的颜色，奇数步（1, 3, 5, ...）的像素涂为灰(5)。标记像素本身算第 0 步（保持自身颜色）。
4. 若两条不同颜色的射线占据同一像素，该像素涂为黄(4)，覆盖之前的颜色（无论是标记色还是灰色）。同色射线交叉处保持该颜色不变。
5. 箭头精灵本身保持灰(5)不变。射线经过箭头精灵像素时，不覆盖箭头像素（箭头像素优先保留）。

**关键洞察**：箭头的横杆位置是一个隐式的方向编码——必须对比多个示例才能确认横杆偏移与指向的对应关系，且这个方向决定了射线的几何走向，进而决定了哪些射线会相交。
