## 新题 4：射线穿透掩码的选择性染色

**组合逻辑**：[反向投射/射线延伸](已有) → [掩码决定保留](创新：掩码不再决定"保留哪些像素"，而是决定"射线能染色哪些像素") → [颜色替换](已有，创新：射线的轨迹色成为掩码像素的新颜色，多射线交叉时按处理顺序覆盖)

**来源原语**：射线延伸/ray_cast(9f8de559)、轨迹/trail(9f8de559)、反向投射/opposite_direction(9f8de559)、掩码决定保留/mask_determines_keep(f76d97a5, 创新为掩码决定可染色范围)、颜色替换/color_replacement(f76d97a5)、擦除/erase(多题)、标记像素/marker_pixel(9f8de559)

**依赖链**：轨迹方向决定射线方向（反向）→ 射线是否命中掩码像素决定该像素是否被染色 → 多条射线可交叉穿过掩码，交叉处颜色由处理顺序决定 → 未被任何射线命中的掩码像素保持灰色。掩码的形状、射线的方向、处理顺序三者共同决定最终图案。

从彩色标记像素沿其轨迹反方向发射射线，射线穿过灰色掩码区域时将路径上的灰色像素染为标记的颜色，最终擦除所有标记和轨迹。

**输入结构**：约 15x15 的网格。背景为黑(0)。网格中央偏某方向有一个灰(5)的不规则连通图形（4-连通，约 15-25 像素，形状不规则，可能有凹陷但无内部孔洞）作为掩码。掩码外围散布 3-4 个彩色标记像素，每个标记颜色各不相同，取自 {蓝(1), 红(2), 绿(3), 黄(4)}。每个标记像素旁有一条同色的直线轨迹（2-3 个像素，沿水平或垂直方向延伸，方向背离掩码）。标记和轨迹均在掩码外部，不与掩码相邻。生成约束：每条射线（从标记沿轨迹反方向延伸）都会穿过掩码的至少一部分；不同射线的路径可以交叉（在掩码区域内共享某些像素）。

**规则**：
1. 对每个彩色标记像素，确定其轨迹延伸方向（从标记朝向轨迹末端的方向）。
2. 从标记位置沿轨迹反方向（即从标记朝向掩码的方向）发射射线。
3. 射线逐格前进。对于射线路径上的每个位置：若该位置是灰(5)掩码像素，将其标记为待染色（染为该标记的颜色）；若该位置是黑(0)背景，跳过继续前进；若该位置是非背景非灰色像素或已超出网格边界，射线终止。
4. 按标记像素在网格中的阅读顺序（从上到下、从左到右）依次处理各条射线。后处理的射线覆盖先处理的射线在同一像素上的染色结果。
5. 所有射线处理完毕后，擦除所有标记像素和轨迹像素（替换为黑(0)）。
6. 未被任何射线命中的灰(5)掩码像素保持灰(5)不变。

**关键洞察**：射线不会在遇到掩码时停止——它穿透掩码，沿途染色所有灰像素，直到碰到其他障碍物或网格边缘。这意味着一条射线可以在掩码的凹陷处"跳过"黑色间隙，在掩码的另一段继续染色。当多条射线的路径在掩码内交叉时，交叉像素的最终颜色取决于处理顺序，而处理顺序由标记的空间位置（阅读顺序）决定——这是一个需要对比多个示例才能发现的隐蔽规则。
