## 新题 2：标记朝向编码平移方向的碰撞式拼装

**组合逻辑**：[标记朝向编码](创新：从"编码颜色"改为"编码平移方向") → [平移拼接](已有) → [碰撞阻挡](已有，创新：处理顺序由线段长度决定而非位置)

**来源原语**：标记朝向编码颜色/marker_orientation_encodes_color(604001fa, 创新为编码方向)、标记体/marker(604001fa)、平移拼接/translate_assemble(83b6b474)、线段条/bar_sprite(83b6b474)、碰撞阻挡/collision_blocking(5ffb2104)、擦除/erase(多题)、高度排序/height_ordering(31f7f899, 创新为长度排序)

**依赖链**：L-标记的缺角方向决定每根线段的平移方向 → 线段按长度排序决定处理先后 → 先处理的线段成为后续线段的障碍物，改变后续停靠位置。三层逻辑环环相扣：方向解码、排序策略、碰撞物理缺一不可。

读取每根彩色线段旁的 L-标记缺角方向作为平移方向，按线段长度从短到长依次平移，碰到已放置线段或网格边缘时停止。

**输入结构**：约 18x18 的网格。背景为黑(0)。网格中散布 4-5 根直线段（每根宽 1 像素、长 3-7 像素，可以是水平或垂直方向），每根线段颜色各不相同，取自 {蓝(1), 红(2), 绿(3), 黄(4), 青(8)}。每根线段旁（曼哈顿距离 1-2 像素处）有一个橙(7)的 2x2 L-三连块标记（即 2x2 方格中缺少一个角的 3 像素图形）。不同线段的标记缺角方向可能不同。线段之间互不接触，标记之间互不接触，线段与非对应标记也不接触。生成约束：每根线段恰好对应一个最近的标记；不同线段的长度两两不同。

**规则**：
1. 对每根线段，找到与其最近的橙(7) L-标记。
2. 确定标记的缺角位置（2x2 方格中缺失像素的位置），映射为平移方向：缺左上角 → 向左平移；缺右上角 → 向上平移；缺右下角 → 向右平移；缺左下角 → 向下平移。
3. 擦除所有橙(7)标记像素（替换为黑(0)）。
4. 按线段长度从短到长排序（长度 = 像素数）。
5. 按排序顺序依次处理每根线段：将线段沿其指定方向逐格平移，直到下一步会使线段的任一像素超出网格边界或与已放置的线段像素重叠，此时停止。保持线段形状和颜色不变。
6. 已处理并停靠的线段立即成为后续线段的障碍物。

**关键洞察**：处理顺序至关重要——短线段先移动并停靠，成为长线段的障碍物，因此最终布局取决于长度排序。同一组线段若改变处理顺序会得到完全不同的结果。标记的缺角-方向映射需要对比多个示例才能确定（例如区分"缺角方向=平移方向"还是"缺角方向=平移反方向"）。
