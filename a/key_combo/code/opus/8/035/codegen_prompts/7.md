## 新题 7：边界标记画线分区后按内容密度选模板补全

**组合逻辑**：[边界标记定贯穿线](已有) → [连线/分区](已有，创新：线不仅是视觉元素，还定义了区域边界) → [模板选择](创新：模板不固定在特定位置，而由区域内容密度决定) → [补全](已有，创新：缺失像素用分隔线颜色填充，分隔色同时承担分区和补全两种功能)

**来源原语**：边界标记定贯穿线/boundary_marker_span(6cdd2623)、连线/draw_line(6cdd2623)、画布边界/canvas_boundary(6cdd2623)、标记像素/marker_pixel(6cdd2623)、模板/template(1e32b0e9)、补全/completion(1e32b0e9)、缺失用分隔色填充/missing_filled_with_divider_color(1e32b0e9)、分隔线/divider_line(1e32b0e9)

**依赖链**：边界标记位置 → 决定分隔线位置 → 分隔线将网格切割为区域 → 各区域的非背景像素密度决定哪个是模板 → 模板图案与其他区域对比确定缺失位置 → 缺失位置用分隔线颜色填充。分隔线颜色同时是分区标识和补全填充色，形成功能复用的紧耦合。

找到仅出现在网格边界上的特殊颜色标记并画出贯穿线将网格分区，选内容最密集的区域为模板，在其他区域中将模板有色而该区域缺失的位置填上分隔线颜色。

**输入结构**：约 15x15 的网格。背景为黑(0)。网格边界（第 0 行、最后一行、第 0 列、最后一列）上有恰好 4 个栗(9)像素——2 个在水平边缘（标记列位置），2 个在垂直边缘（标记行位置）。这 4 个标记定义一条贯穿全宽的垂直线和一条贯穿全高的水平线。网格内部散布若干彩色像素（非黑、非栗），形成简单的小图案（每个图案 3-8 像素，颜色可以是蓝(1)、红(2)、绿(3)等）。这些图案分布在即将被分隔线划分的各区域内。生成约束：两条分隔线将网格分为 4 个矩形区域；其中一个区域的非背景像素数严格多于其他三个区域（该区域为模板）；模板区域中的图案在其他三个区域中都有对应位置的子集（即其他区域的图案是模板图案的残缺版本，部分位置被黑(0)替代）。

**规则**：
1. 找到仅出现在网格边界上的颜色（栗(9)）。
2. 对于在上边缘或下边缘的栗(9)标记，画一条该列的全高垂直线（颜色为栗(9)）。对于在左边缘或右边缘的栗(9)标记，画一条该行的全宽水平线（颜色为栗(9)）。画线时覆盖原有像素。
3. 分隔线将网格分为 4 个矩形区域（不含分隔线本身）。
4. 统计每个区域内非背景（非黑(0)、非栗(9)）像素的总数，选择像素数最多的区域作为模板。
5. 对其他三个区域，逐像素与模板对比（按区域内相对坐标对齐）：模板中有非背景像素而该区域对应位置为黑(0)的，将该位置填充为栗(9)。
6. 已有的非背景像素保持不变。分隔线保持不变。

**关键洞察**：栗色同时扮演两个角色——作为边界标记指示分隔线位置，以及作为补全填充色标记被模板覆盖但在当前区域中缺失的位置。模板不在固定位置（如左上角），而由内容密度决定，因此必须先完成分区和密度统计才能确定模板。仅看单个示例可能会把密度最高的区域误认为固定在某个象限。
