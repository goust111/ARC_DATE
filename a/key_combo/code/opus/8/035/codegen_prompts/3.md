## 新题 3：散落空心框按面积嵌套并翻转层色序

**组合逻辑**：[排序](已有，按面积) → [同心嵌套](创新：将散落对象重组为同心结构) → [层色序翻转](已有，创新：翻转对象是动态构建的嵌套结构而非输入中已有的同心结构)

**来源原语**：空心矩形/hollow_rectangle(00dbd492)、排序/sort(31f7f899)、同心方框层/concentric_layer(85c4e7cd)、深度排序/depth_order(85c4e7cd)、层色序内外翻转/reverse_layer_colors(85c4e7cd)

**依赖链**：面积排序确定嵌套层次（最大框最外层、最小框最内层）→ 嵌套建立同心结构才能定义"深度"→ 深度排序后翻转颜色序列。排序决定几何布局，几何布局决定颜色分配，两者方向相反（位置按从大到小排列，但颜色按从小到大的原色赋予），构成紧耦合。

将散落在网格中的不同大小的空心矩形框按面积排序、嵌套对齐成同心结构，然后将各层颜色按深度反转。

**输入结构**：约 20x20 的网格。背景为黑(0)。网格中散布 3-4 个空心矩形框（每个框是一像素厚的矩形环），大小各不相同（例如外径分别为 5x5、9x9、13x13），每个框的边框颜色各不相同，取自 {蓝(1), 红(2), 绿(3), 黄(4)}。各框在输入中位置随意，互不重叠。每个框内部为黑(0)。生成约束：每个框都是正方形（宽=高）；框的边长两两不同且均为奇数（保证可以精确居中嵌套）。

**规则**：
1. 识别所有空心矩形框，计算每个框的边长（外径）。
2. 按边长从大到小排序。
3. 构建输出网格：尺寸等于最大框的外径。将所有框居中对齐嵌套——最大框在最外层，最小框在最内层，各框共享中心点。
4. 记录嵌套后从外到内的颜色序列，将其反转：最外层框取原来最内层框的颜色，最内层框取原来最外层框的颜色，中间层类推。
5. 各框之间和最内层框内部的区域保持黑(0)。

**关键洞察**：输入中各框分散放置，没有嵌套关系，也无法直接看出深度——必须先完成面积排序和居中对齐才能建立同心结构。颜色翻转的方向与嵌套方向相反，即空间上最外层的框在颜色上获得原来空间最内层的颜色，使得位置排序和颜色赋值形成交叉映射。
