## 新题 1：对称修复后按孔洞面积染色

**组合逻辑**：[对称补全](已有) → [封闭区域检测](已有，创新：作用于修复后的图案而非给定图案) → [按面积映射颜色](创新：将"按边长映射"泛化为"按面积映射"，且面积值依赖前序修复结果)

**来源原语**：对称补全/symmetry_completion(3631a71a)、封闭区域/enclosed_region(e3721c99, 810b9b61)、按边长映射颜色/size_to_color_mapping(00dbd492, 创新为按面积映射)、填充/fill(00dbd492)、掩码像素/masked_pixel(3631a71a)

**依赖链**：灰色掩码破坏了对称图案中封闭区域的边界 → 必须先通过对称轨道修复掩码才能得到正确的封闭区域拓扑 → 修复后封闭区域的面积决定填充颜色。删除对称修复则孔洞边界错误、面积错误、颜色错误；删除面积映射则无法确定填充色。

将对称图案中被掩码损坏的封闭区域修复完整，再根据每个封闭区域的像素面积选择填充颜色。

**输入结构**：约 13x13 的正方形网格。背景为黑(0)。红(2)像素构成一个具有左右镜像对称性的连通图案（图案关于网格垂直中轴对称）。图案中存在 3-4 个不同大小的封闭黑(0)区域（即被红(2)像素完全包围、不与网格边缘相连的黑色连通分量），面积分别在 1-3、4-6、7-10 像素范围内（不同示例中具体面积不同，但落入同一区间的封闭区域总得到同一填充色）。部分红(2)像素被替换为灰(5)，形成掩码损坏——灰像素可能出现在封闭区域边界上，使某些封闭区域在修复前看起来与外部黑色连通或面积被错误计算。生成约束：灰(5)掩码关于垂直中轴不对称（即对于每个灰像素，其镜像位置保留原色），保证修复方案唯一；每个封闭区域至少有一部分边界未被损坏。

**规则**：
1. 识别灰(5)为掩码色。对每个灰(5)像素，取其关于网格垂直中轴的镜像位置的颜色，替换该灰像素，恢复完整的对称图案。
2. 在修复后的网格中，找到所有被红(2)完全包围的黑(0)连通分量（4-连通），即不与网格边缘上的黑(0)像素连通的黑色区域。
3. 统计每个封闭区域的像素数（面积），按面积区间填充颜色：面积 1-3 → 蓝(1)；面积 4-6 → 黄(4)；面积 7-10 → 绿(3)。填充时将该封闭区域的所有黑(0)像素替换为对应颜色。
4. 红(2)边界像素保持不变。非封闭的黑(0)区域（与网格边缘连通的背景）保持黑(0)。

**关键洞察**：灰色掩码可能打破封闭区域的边界，使原本封闭的区域看似与外部连通（面积变为"无穷大"而不被检测为封闭区域），或使两个相邻封闭区域合并为一个更大的区域。必须先完成对称修复才能得到正确的拓扑结构和面积。面积-颜色映射的具体区间需对比多个示例才能归纳。
