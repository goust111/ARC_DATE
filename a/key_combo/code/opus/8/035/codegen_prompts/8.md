## 新题 8：旋转拼合后跨象限孔洞分类填充

**组合逻辑**：[精灵裁剪](已有) → [旋转拼接](已有) → [封闭区域检测](已有，创新：检测对象是拼合后涌现的跨象限孔洞) → [按象限跨度分类填充](创新：填充颜色由孔洞横跨的象限数决定，这是拼合后才涌现的属性)

**来源原语**：精灵裁剪/sprite_crop(2697da3f)、旋转/rotate(2697da3f, 46442a0e)、拼接/concatenate(46442a0e)、四旋转变体组拼图/four_rotations_composite(46442a0e)、象限/quadrant(46442a0e)、封闭区域/enclosed_region(810b9b61, e3721c99)、有空洞则重涂/recolor_if_hole(810b9b61, 创新：不是重涂有洞对象而是填充洞本身)、填充/fill(00dbd492)

**依赖链**：裁剪+旋转+拼合生成 2x2 复合图案 → 复合图案中涌现出原始精灵中不存在的跨象限封闭区域 → 每个封闭区域跨越的象限数决定其填充颜色。涌现效应是核心：单个旋转变体中的孔洞在拼合后可能与邻接象限的孔洞合并，产生跨 2 或 3 个象限的大孔洞，这在任何单一象限中都无法预见。

将不对称精灵体裁剪并生成四个旋转变体拼为 2x2 网格，然后检测拼合后涌现的封闭区域并按其跨越的象限数分色填充。

**输入结构**：约 8x8 的网格。背景为黑(0)。网格中有一个蓝(1)的 4-连通不对称精灵体（无水平或垂直镜像对称性），约 8-15 像素，具有至少一个内部孔洞（被蓝像素完全包围的黑色区域）。精灵体不接触网格边界。生成约束：精灵体的边界框为 h x w；精灵体不具有 90° 旋转对称性（保证四个旋转变体互不相同）；精灵体的形状使得四变体拼合后在象限交界处会出现新的封闭区域（至少一个跨越 2 个象限的孔洞）。

**规则**：
1. 裁剪精灵体至其最小边界框（h x w）。
2. 生成四个变体：原始（0°）、顺时针 90°、180°、逆时针 90°。
3. 将四个变体排列为 2x2 网格：左上 = 原始，右上 = 顺时针 90°，左下 = 逆时针 90°，右下 = 180°。输出尺寸为 2h x 2w。
4. 在拼合后的 2h x 2w 网格中，找到所有被蓝(1)完全包围的黑(0)连通分量（4-连通），即不与网格边缘的黑色区域连通的封闭区域。
5. 对每个封闭区域，判断其像素跨越了哪些象限（左上、右上、左下、右下）：
   - 仅在 1 个象限内 → 填充为绿(3)。
   - 跨越恰好 2 个象限 → 填充为黄(4)。
   - 跨越 3 个或 4 个象限 → 填充为红(2)。
6. 蓝(1)像素保持不变。与网格边缘连通的黑(0)区域保持黑(0)。

**关键洞察**：原始精灵体中的孔洞在旋转拼合后可能与相邻象限的孔洞在边界处连通，形成跨象限的更大封闭区域——这是一种涌现效应，仅凭观察单个旋转变体无法预测。填充颜色取决于这种涌现后的拓扑属性（象限跨度），而非原始精灵体的任何属性。
