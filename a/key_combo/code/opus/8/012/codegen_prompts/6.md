## 新题 6：周期修复还原着陆面后重力下落

**组合逻辑**：[补全/周期修复](已有，从 e95e3d8e 提取；创新：修复结果不是最终输出，而是后续物理模拟的边界条件) → [重力下落](已有，从 c87289bb / df9fd884 提取；创新：着陆面不是网格底边或固定结构，而是由修复操作动态生成的)

**来源原语**：补全、周期瓦片、缺失像素、周期对齐、最小周期修复缺口（e95e3d8e）；重力下落、可移动对象、碰撞阻挡（c87289bb, df9fd884）

**依赖链**：黑色缺口隐藏了周期图案的真实形态 → 周期修复揭示出哪些位置是"实心地面" → 可移动对象在重力作用下下落直到碰到修复后的实心地面或底边。去掉周期修复则着陆面位置不确定、下落距离无法计算；去掉重力下落则修复只是填色、失去物理意义。

先修复含黑色缺口的周期背景图案，使隐藏的实心区域恢复可见；再将悬浮在缺口上方的彩色对象向下做重力下落，让它们落在修复后露出的实心表面上。

**输入结构**：约 15×12 的网格。

- 背景层：一个由 2~3 种颜色（从蓝(1)、绿(3)、灰(5)中选取）构成的矩形周期图案，最小周期矩形尺寸约 2×2 到 4×3。图案中散布着若干黑(0)缺口像素（占图案面积的 15%~30%），缺口分布使得每个周期残余类至少有一个可见样本。
- 前景层：2~3 个由红(2)或橙(7)像素构成的 4-连通小对象（每个 2~5 像素），悬浮在网格上半部。每个对象正下方（在其边界框各列中）存在至少一个黑色缺口。对象颜色不出现在背景周期图案中。

生成约束：每个前景对象下方的黑色缺口，在周期修复后将变为非黑色（成为着陆面的一部分或者露出着陆面），使得对象的下落距离在 1~6 行之间。不同对象的下落路径在列上不重叠。修复后的着陆面保证每个对象能水平放稳（对象最底行的每一列，在其着陆行的下一行都是非黑像素或网格底边）。

**规则**：
1. 找到背景层的最小周期矩形：枚举所有非黑、非前景色像素的位置和颜色，找到最小面积的 (ph, pw) 使得所有已知背景像素 (r, c) 满足 color(r, c) = color(r mod ph, c mod pw)（在已知像素中无矛盾，且每个残余类至少有一个样本）。
2. 将每个黑(0)像素替换为其残余类 (r mod ph, c mod pw) 对应的颜色，完成周期修复。前景对象的像素不参与修复（它们保持原色）。
3. 对每个前景对象，在修复后的网格上执行重力下落：整体向下平移，直到对象最底行的紧下一行全部为非黑非前景色像素（即碰到修复后的背景表面）或对象最底行到达网格最后一行。
4. 擦除对象原位置（设为修复后该位置应有的周期背景色）。在新位置绘制对象。
5. 若多个对象需处理，按对象边界框顶行从高到低（行号从大到小，即靠近底部的先处理）依次执行，已落位的对象视为障碍。
6. 输出网格与输入同尺寸。

**关键洞察**：对象下方的黑色像素既是"缺口"也是"虚假空间"——在修复前看起来像空洞可以穿过，修复后可能变成实心障碍面。对象的下落距离取决于修复结果，而非输入中的表观空隙大小。处理顺序规则（底部优先）需对比多个示例归纳。
