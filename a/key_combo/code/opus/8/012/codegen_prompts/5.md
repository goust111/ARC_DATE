## 新题 5：十字射线与标记矩形的优先级合成

**组合逻辑**：[连线/路径绘制](已有，从 29700607 提取) 并行 [填充 + 对角标记定矩形](已有，从 21f83797 提取) → [优先级合成](创新：两个独立构图共享画布，需要冲突解决)

**来源原语**：连线、路径绘制、边缘源像素、同色端点、同色配对、有端点则转弯、无端点则延伸（29700607）；填充、标记像素、矩形、行列分割线、对角标记定矩形（21f83797）

**依赖链**：路径绘制和矩形填充是两个独立的几何构图，但它们共享同一画布 → 重叠区域需要优先级规则来决定最终颜色。去掉路径绘制则画布只剩矩形填充；去掉矩形填充则只有路径；去掉优先级规则则重叠区域不确定。这不是流水线，而是两个并行构图的受约束合并。

顶边彩色像素向下绘制路径（有端点则转弯，否则直达底边），同时两个栗(9)标记像素定义一个矩形并将其内部填充蓝(1)。两个构图合成到同一画布上，按固定优先级处理重叠。

**输入结构**：约 15×15 的网格，黑(0)背景。

- 第 0 行：一段连续的 2~4 个不同颜色的像素（从绿(3)、黄(4)、橙(7)、品红(6)中选取），占据相邻的列，其余列为黑。这些是路径源像素。
- 网格内部：每个源像素颜色在网格中最多有一个同色的孤立端点像素（单个像素，不在第 0 行，不在源像素的同列）。有的源颜色有端点，有的没有。
- 网格中还有恰好 2 个栗(9)孤立像素，它们不在同一行也不在同一列，且不在第 0 行。它们是矩形标记。

生成约束：栗(9)标记不与任何端点像素重合；至少一条路径（有端点或无端点）的行/列范围与标记定义的矩形内部有交叉，以确保出现优先级冲突。

**规则**：
1. **路径绘制**：对第 0 行每个源像素，从其列向下绘制竖直段。若存在同色端点像素，竖直段画到端点所在行，然后画水平段从源列到端点列（含端点像素本身），路径颜色为源像素颜色。若不存在同色端点，竖直段一直画到底边（最后一行）。路径宽度为 1 像素。
2. **矩形构图**：两个栗(9)标记像素定义矩形的对角。画出经过两个标记行的完整水平线（跨网格全宽）和经过两个标记列的完整竖直线（跨网格全高），颜色为栗(9)。再将两个标记行之间、两个标记列之间的严格内部像素填充为蓝(1)。
3. **合成规则**（优先级从高到低）：栗(9)十字线 > 路径颜色 > 蓝(1)矩形填充 > 黑(0)背景。即：一个像素若同时被栗色十字线和路径覆盖，显示栗(9)；若同时被路径和蓝色填充覆盖，显示路径颜色；蓝色填充仅在无更高优先级元素时可见。
4. 输出网格与输入同尺寸。

**关键洞察**：路径和矩形填充是两个各自独立的几何操作，但它们的输出必须在同一画布上合成。三层优先级关系（栗色线 > 路径 > 蓝色填充）无法从单个示例可靠归纳——需要多个示例展示不同重叠配置来确认优先级顺序。

    assert out.ndim == 2 and max(out.shape) <= 30, f"output grid exceeds 30x30: {out.shape}"
    sigs.add(hashlib.md5(inp.tobytes() + str(inp.shape).encode()).hexdigest())
print("variants", len(sigs))
assert len(sigs) >= 20
