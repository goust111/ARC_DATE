## 新题 6：逐单元调色的克罗内克印章

**组合逻辑**：[克罗内克积/二值掩码](已有，掩码作为形状模板) + [颜色配对映射/标记像素](创新：不再全局统一调色，而是每个单元格的标记独立选择前景/背景色对)

**来源原语**：克罗内克积/kronecker_product、二值掩码/binary_mask、印章覆盖/stamp_overlay ← c803e39c；颜色配对映射/color_pair_mapping、标记像素/marker_pixel、窗口格/window_cell、标记色定窗口填充/marker_sets_window_fill ← 54d9e175

**依赖链**：二值掩码提供所有单元格共享的形状模板（空间结构），但每个单元格的前景/背景色由其中心标记像素通过颜色配对映射独立决定。掩码决定"哪些位置是前景"，标记决定"前景/背景分别涂什么色"——两者在每个单元格中交叉作用。删去掩码则无形状结构，删去标记映射则无法确定各单元格的着色方案。

将同一个二值掩码铺入每个标记单元格，但每个单元格的标记颜色独立选择该单元格中掩码前景和背景的具体着色。

**输入结构**：约 12x20 的网格，黑(0)为背景。一条灰(5)竖直分隔线将网格分为左右两区。左区：一个约 3x3 的二值掩码，前景像素为灰(5)、背景为黑(0)；掩码形状不关于任何轴对称（以便在输出中可辨认朝向）。右区：被灰(5)单像素宽分隔线切分为 2x3 或 3x3 的单元格阵列，每个单元格约 3x3；每个单元格中心位置有一个标记像素，颜色从{蓝(1), 红(2), 绿(3), 品红(6)}中取，其余位置为黑(0)。生成约束：至少使用 3 种不同的标记颜色；掩码中前景和背景像素均至少占 2 个。

**规则**：
1. 从左区提取二值掩码 M（区分前景位置和背景位置）。
2. 对右区的每个单元格，读取其中心标记像素的颜色 c。
3. 根据颜色 c 查找前景/背景色对：
   - 蓝(1) → 前景色=红(2)，背景色=橙(7)。
   - 红(2) → 前景色=黄(4)，背景色=栗(9)。
   - 绿(3) → 前景色=青(8)，背景色=灰(5)。
   - 品红(6) → 前景色=蓝(1)，背景色=绿(3)。
4. 将每个单元格替换为掩码 M 的着色副本：M 中前景位置填该单元格对应的前景色，背景位置填对应的背景色。
5. 输出仅包含右区变换后的结果（去除左区和左侧灰分隔线）。右区内部的灰(5)分隔线保持不变。

**关键洞察**：同一个掩码形状在每个单元格中重复出现（统一空间结构），但每个单元格的标记颜色通过一个隐式配对映射独立选择了前景/背景的着色方案（局部色彩自由度）。必须同时理解掩码形状逻辑和颜色配对映射才能正确生成输出——只看一个单元格无法确定映射表，需对比多个不同标记色的单元格。
