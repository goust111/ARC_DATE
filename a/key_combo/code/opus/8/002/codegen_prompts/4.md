## 新题 4：棋盘反转旋转拼接加框

**组合逻辑**：[旋转+拼接](已有) × [颜色反转](创新——反转不均匀施加，棋盘式交替选择象限) + [外框绘制](已有)

**来源原语**：旋转(rotate, 7953d61e/ed98d772), 拼接(assembly, 7953d61e), 逐象限旋转排布(quadrant_rotation_layout, 7953d61e), 颜色反转(color_invert, 48131b3c), 二值图案(binary_pattern, 48131b3c), 外框绘制(frame_draw, db93a21d), 尺寸倍增嵌套(size_doubled_nesting, db93a21d), 阵列排布(array_layout, ed98d772/a59b95c0)

**依赖链**：旋转产生四个象限内容 → 棋盘式选择决定哪些象限做颜色反转 → 反转改变选中象限的像素值 → 拼接合并四象限 → 外框绘制包裹拼接结果。反转选择模式需对比多个示例才能归纳。

将 n x n 二值输入旋转为四象限拼成 2n x 2n；对角线位置的两个象限做颜色反转（黑与前景色互换），另两个不反转；最后加绿色外框。

**输入结构**：一个较小的 n x n 正方形网格（n 为 3-5），仅含黑(0)和一种前景色（如红(2)），形成一个非对称的二值图案（图案在 90 度旋转下不与自身重合，以便区分各象限的旋转状态）。无背景边框或标记。

**规则**：
1. 构造 2n x 2n 的输出核心区域，由四个 n x n 象限组成：
   - 左上象限：原始输入，不做颜色反转。
   - 右上象限：输入逆时针旋转 90 度，然后做颜色反转（黑(0)变为前景色，前景色变为黑(0)）。
   - 左下象限：输入旋转 180 度，然后做颜色反转。
   - 右下象限：输入逆时针旋转 270 度（即顺时针 90 度），不做颜色反转。
2. 反转模式为棋盘式：将四象限视为 2x2 网格，左上(0,0)和右下(1,1)不反转，右上(0,1)和左下(1,0)反转。
3. 在 2n x 2n 核心区域外围绘制一圈单像素厚的绿(3)边框。最终输出大小为 (2n+2) x (2n+2)。

**关键洞察**：旋转序列（0/90/180/270）和源题相同是诱导项；真正的隐蔽规则是颜色反转的棋盘式施加——仅对角位置的象限（右上和左下）做反转，而非全部或交替。求解者必须对比多个示例区分"哪些象限被反转了"和"哪些象限只是旋转了"。
