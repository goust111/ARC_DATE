## 新题 7：行带平铺与标记计数驱动的印章优先级翻转

**组合逻辑**：[平铺](已有) ∥ [印章覆盖](已有) → [计数](创新——标记数量作为合成优先级的开关) → [重涂色](创新——优先级翻转改变最终可见层)

**来源原语**：平铺(tile, 8eb1be9a), 行带(row_band, 8eb1be9a), 纵向重复(vertical_repetition, 8eb1be9a), 前景行带铺满画布(foreground_band_tiles_to_fill_canvas, 8eb1be9a), 印章覆盖(stamp, 88a10436), 精灵体(sprite, 88a10436/776ffc46), 标记像素(marker_pixel, 88a10436/d43fd935), 中心对齐(center_align, 88a10436), 精灵对准标记复制(sprite_at_marker, 88a10436), 计数(counting, a59b95c0), 重涂色(recolor, 多源)

**依赖链**：行带纵向平铺产生全画布背景图案 → 精灵体印章到各标记位置产生前景副本 → 标记总数 K 决定合成规则（K <= 3 时印章优先覆盖平铺层；K > 3 时平铺层优先覆盖印章层）→ 最终可见像素取决于优先级。计数驱动合成规则翻转是核心创新。

网格含一条水平行带和一个小精灵体，行带纵向平铺铺满画布，精灵体印章到各灰色标记处；灰色标记总数决定平铺层与印章层的叠放优先级。

**输入结构**：约 15x15 的黑(0)背景网格。包含以下元素：(a) 一条水平行带——由 2-3 行连续的非黑像素组成（使用蓝(1)和黄(4)等颜色交替排列），横跨网格全宽，位于网格中部某处，行带上下方均有黑(0)行。(b) 一个小精灵体——一个 4-连通单色图形（3-5 像素，使用红(2)），位于行带上方或下方。(c) 2-6 个灰(5)标记像素，散布于网格各处（不在行带行内，不与精灵体重叠）。生成约束：精灵体的边界框不超过 3x3；标记位置保证印章后的精灵体副本不超出网格边界；行带至少包含两种颜色。

**规则**：
1. 识别水平行带（包含所有非黑像素的连续行范围，横跨全宽）。
2. 以行带为瓦片，纵向重复铺满整个画布：向上和向下复制行带，保持行带的原始行位置对齐（即从行带位置开始，向上每隔行带高度放一个副本，向下同理，直到超出网格边界）。超出部分裁剪。这产生"平铺层"。
3. 识别红(2)精灵体，提取其紧边界框掩码（边界框内黑(0)像素视为透明）。
4. 对每个灰(5)标记像素，以标记为中心对齐精灵体的边界框中心，放置一个精灵体副本（保持红(2)色）。移除灰标记像素（被精灵体覆盖或变为黑(0)）。这产生"印章层"。原始精灵体也保留在原位。
5. 计算灰标记的总数 K。
6. 合成两层：
   - 若 K <= 3：印章层优先——在平铺层之上绘制印章层，印章层的非透明像素覆盖平铺层。
   - 若 K > 3：平铺层优先——在印章层之上绘制平铺层，平铺层的非黑像素覆盖印章层。
7. 原始精灵体始终可见（不被任何层覆盖）。

**关键洞察**：标记数量本身不影响每个印章的位置或行带的铺排方式，但它翻转了两个图层的合成顺序。当标记少时，印章清晰可见于行带之上；当标记多时，行带遮盖了大部分印章，仅在行带的黑(0)间隙中露出印章痕迹。这个阈值规则必须通过对比不同标记数量的示例才能发现。
