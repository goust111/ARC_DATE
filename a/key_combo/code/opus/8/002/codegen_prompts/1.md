## 新题 1：射线计数驱动旋转叠色

**组合逻辑**：[射线延伸](已有) + [计数](已有) → [旋转](创新——旋转角度由全局计数动态决定) → [重涂色](创新——基于旋转后重叠位置触发)

**来源原语**：射线延伸(ray_extend, d43fd935), 行列对齐(row_col_alignment, d43fd935), 锚定方块(anchor_square, d43fd935), 标记像素(marker_pixel, d43fd935/88a10436), 旋转(rotate, 1a244afd), 计数(counting, a59b95c0), 重涂色(recolor, 多源), 距离保持不变(distance_preserved, 1a244afd)

**依赖链**：对齐检测确定哪些标记参与射线绘制 → 射线绘制产生线段 → 对齐标记的全局计数 K 决定所有射线的旋转角度(K*90 度) → 旋转后的射线像素若与非参与标记重合则触发重涂色。删除计数则旋转角度不确定；删除旋转则重叠永不发生；删除射线则无旋转对象。

从锚定方块出发，对齐标记发射射线，射线作为整体围绕锚心旋转（角度由对齐标记总数决定），旋转后与散落标记的重合位置被重涂为橙色。

**输入结构**：约 15x15 的黑(0)背景网格。网格中有一个红(2) 2x2 锚定方块，位于网格中部偏左。散布 4-6 个孤立单像素标记，每个标记颜色各不相同（使用蓝(1)、绿(3)、黄(4)、灰(5)、品红(6)中的若干种），标记之间不相邻。其中 2-4 个标记与锚定方块的某行或某列对齐（即标记的行坐标与方块占据的两行之一相同，或标记的列坐标与方块占据的两列之一相同），其余标记不与方块对齐。生成约束：所有标记与锚定方块之间至少间隔 2 个像素；旋转后的射线不超出网格边界（可通过调整标记距离保证）。

**规则**：
1. 识别红(2) 2x2 锚定方块，记录其中心点（2x2 方块的四格几何中心，坐标取四格中心的平均值，可能为半整数）。
2. 对于每个与方块行或列对齐的标记像素，从该标记向方块绘制一条水平或垂直线段，线段颜色为标记颜色，线段终点为距方块最近边缘相邻的那个像素（不覆盖方块本身）。标记本身保留。
3. 计算与方块对齐的标记总数 K。
4. 将所有绘制的线段像素（不含标记像素和方块像素）整体围绕锚定方块中心旋转 (K * 90) 度顺时针。旋转以最近整数坐标取整。旋转后超出网格边界的像素丢弃。
5. 在旋转后的线段位置绘制像素（保留旋转前的颜色）。原始线段位置不保留（只保留旋转后的位置）。
6. 旋转后的线段像素若与任何原始标记像素（无论是否对齐）占据同一位置，该位置变为橙(7)。
7. 锚定方块和所有原始标记像素保持不变（不被线段覆盖）。

**关键洞察**：对齐标记的全局总数决定了所有射线共同的旋转角度，因此增减一个对齐标记会同时改变旋转角和参与射线的集合。橙色重叠标记需要求解者同时追踪射线的旋转目的地和非对齐标记的固定位置。
