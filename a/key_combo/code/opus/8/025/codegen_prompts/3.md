## 新题 3：双面板合并构建射线障碍场

**组合逻辑**：[透明叠加/transparent_overlay](原有) → [射线延伸/ray_extend](原有)，创新点在于**叠加操作的输出成为射线操作的障碍地图**——障碍只在合并后才完整存在，单面板中的遮挡结构不完整

**来源原语**：
- 透明叠加(transparent_overlay), 二值掩码(binary_mask), 分隔列(divider_column), 双侧对齐(bilateral_alignment), 并集合并(union_merge) ← 5d2a5c43
- 射线延伸(ray_extend), 微型标记(micro_marker), 朝向决定方向(orientation_determines_direction) ← 9344f635

**依赖链**：两面板各自不完整→叠加合并产生完整障碍地图（青色像素）→射线从标记出发沿指定方向延伸→遇到青色障碍或网格边界时停止。删除叠加步骤则障碍不完整，射线终点错误；删除射线步骤则输出只有合并掩码缺少射线标记

合并蓝色分隔列两侧的黄色掩码为青色，再从橙色多米诺标记沿其朝向发射橙色射线直至遇到青色障碍。

**输入结构**：
- 约 11x23 的网格，黑(0)背景
- 正中央一列为蓝(1)分隔列（全高），将网格分为左右两个等宽面板（各约 11x11）
- 每个面板中散布黄(4)像素（各 8~15 个），构成二值掩码；两个面板在对齐后的同一位置至多有一个面板包含黄色像素（互补放置），但不完全覆盖所有位置
- 每个面板中有 1~2 个橙(7)多米诺标记（同色 2 像素，水平或垂直排列），放置在不与黄色像素正交相邻的位置
- 生成约束：合并后每个橙色多米诺沿其朝向的至少一个方向上存在青色障碍（射线不会无限延伸到网格边界以外的情况也合法）；两面板的橙色多米诺不在同一对齐位置重叠

**规则**：
1. 移除蓝(1)分隔列，将左右面板按行列对齐，输出画布为 11x11
2. 对齐后，任一面板中有黄(4)像素的位置涂为青(8)；两面板均为黑(0)的位置保持黑(0)
3. 合并两面板中的橙(7)多米诺标记，保留其对齐后的位置和朝向
4. 对每个橙色多米诺：水平朝向→向左和向右两个方向各发射一条射线；垂直朝向→向上和向下两个方向各发射一条射线
5. 射线从多米诺端点出发，沿指定方向逐格推进；遇到青(8)像素或网格边界时停止（终止格不涂色）；路径上经过的黑(0)格涂为橙(7)
6. 射线不覆盖已有的青(8)像素或其他橙(7)多米诺/射线；若两条射线路径交叉，交叉点涂为橙(7)

**关键洞察**：某些射线在单面板中看似可以畅通无阻，但合并后对侧面板的黄色像素恰好出现在路径上形成障碍——射线长度只有在两面板合并后才能确定
