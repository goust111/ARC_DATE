## 新题 8：图例查色确定循环调色起点

**组合逻辑**：[查表替换/lookup_replace](原有) + [循环填充/cyclic_filling](原有)，创新点在于**图例查表的结果不直接成为输出颜色，而是作为循环调色板的起始相位偏移**——同一调色板对不同编码块产生不同颜色图案

**来源原语**：
- 查表替换(lookup_replace), 图例面板(legend_panel), 编码块(encoded_block), 形状标记(shape_marker), 颜色与形状对应(color_shape_match), 旋转镜像等价匹配(rotation_reflection_match) ← b20f7c8b
- 循环填充(cyclic_filling), 对角带(diagonal_band), 调色板行(palette_row), 层深度递增(layer_depth_increasing), 层深模色板取色(depth_mod_palette_color) ← b457fec5

**依赖链**：图例面板将形状映射到颜色→颜色在调色板行中的位置索引即为起始偏移→每个编码块的同心层按 (层深 + 偏移) mod 调色板长度取色。删除图例查表则不知道偏移值；删除循环填充则不知道如何着色各层

根据每个编码块内标记形状在图例中对应的颜色确定调色板起始偏移，再以同心层深度循环调色板填充该块。

**输入结构**：
- 约 22x22 的网格，黑(0)背景
- 左上方约 10x6 区域为青(8)底色的图例面板，包含 3~4 个不同颜色的 4-连通小形状（3~5 像素），颜色从蓝(1)、红(2)、绿(3)、黄(4)中选取；每个形状在 8 种刚性变换下互不相同
- 图例面板正下方有一行调色板行：与图例面板中颜色相同的像素按固定顺序排列（如从左到右为蓝(1)、红(2)、绿(3)、黄(4)），各像素间隔 1 格黑(0)，位置索引从 0 开始
- 网格右侧及下方区域包含 3~4 个 7x7 编码块，互不重叠且不与图例面板/调色板行重叠
- 每个编码块内部背景为灰(5)，中央有一个橙(7)小形状（3~5 像素），该形状是图例面板中某个颜色形状的旋转或镜像版本
- 生成约束：每个编码块的橙色形状与图例中恰好一种颜色的形状匹配（在 8 种变换下）；不同编码块可以匹配不同或相同的图例颜色

**规则**：
1. 对每个 7x7 编码块，提取其内部橙(7)像素的相对坐标，与图例面板中各颜色形状的 8 种刚性变换逐一比较，找到唯一匹配的图例颜色 C
2. 在调色板行中查找颜色 C 的位置索引 k（从左到右，从 0 开始）
3. 将编码块内部 7x7 区域按同心层划分：第 0 层 = 最外圈（距块边界 0 像素的环形），第 1 层 = 距块边界 1 像素的环形，以此类推至中心（第 3 层为中心 1x1 像素）
4. 每层的颜色 = 调色板行中第 (层深 + k) mod 调色板长度 位置的颜色
5. 同心层颜色覆盖原有的灰(5)和橙(7)像素
6. 块外区域保持黑(0)；图例面板和调色板行保持不变

**关键洞察**：图例查表的目的不是确定最终颜色（那样每个块只会是单色），而是确定循环调色板的起始相位——两个匹配到调色板中相邻颜色的编码块，其同心环图案将呈现一格相位差；需对比多个示例才能区分"图例决定固定颜色"和"图例决定相位偏移"
