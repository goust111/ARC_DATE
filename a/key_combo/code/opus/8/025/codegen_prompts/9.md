## 新题 9：互补面板合并与反对角线结构修复

**组合逻辑**：[透明叠加/transparent_overlay](并集合并，原有) + [填充/infill](反对角线约束填充，原有)。创新点在于**两种修复策略必须协同工作且各自不充分——并集合并恢复大部分缺失值，但双面板共同缺失的稀少位置只能通过反对角线结构规则推断**——同时约束满足结构

**来源原语**：
- 透明叠加(transparent_overlay), 二值掩码(binary_mask), 分隔列(divider_column), 双侧对齐(bilateral_alignment), 并集合并(union_merge) ← 5d2a5c43
- 填充(infill), 边框层(frame_layer), 遮挡空洞(occlusion_hole), 反对角线等值(anti_diagonal_equivalence), 分区结构约束(partitioned_structure_constraint) ← 4aab4007

**依赖链**：（路径 A）两面板并集合并→恢复大部分遮挡空洞；（路径 B）合并后仍有少量双缺失位置→需利用反对角线等值约束从已知值推断→填补剩余空洞。仅用路径 A 有残留空洞无法填补，仅用路径 B 已知值太少（单面板空洞率 30%）无法可靠推断

合并分隔列两侧的互补色彩面板，再利用反对角线同色规则修复两面板共同缺失的像素。

**输入结构**：
- 约 11x23 的网格，黑(0)为缺失标记
- 正中央一列为灰(5)分隔列
- 左右两个 11x11 面板，各自展示同一幅彩色图案的带空洞版本：
  - 完整图案为 11x11，使用 3~4 种非黑非灰颜色（如蓝(1)、红(2)、绿(3)、黄(4)），其中同一条反对角线（row + col = 常数）上的所有像素颜色相同
  - 左面板中约 30% 的像素被替换为黑(0)空洞
  - 右面板中约 30% 的像素被替换为黑(0)空洞
  - 两面板的空洞位置大部分互补（左面板有空洞的位置右面板有值，反之亦然），但有约 5~8 个位置在两面板中均为空洞（双缺失）
- 生成约束：每条反对角线上在合并后（取两面板并集）至少保留一个非黑像素，保证反对角线规则可唯一推断所有双缺失位置的颜色

**规则**：
1. 移除灰(5)分隔列，将左右面板按行列对齐
2. 并集合并：对每个位置 (r,c)，若左面板该位置为非黑色则取左面板值，否则取右面板值（若两面板该位置都非黑则两者一致，取任一即可）
3. 合并后仍为黑(0)的位置为双缺失位置；对每个双缺失位置 (r,c)，计算其反对角线编号 k = r + c，在已有值中找到同一反对角线（r' + c' = k）上的非黑像素，用该颜色填充 (r,c)
4. 输出为 11x11 的无空洞完整图案

**关键洞察**：大部分空洞通过简单的面板合并即可消除，但少数双缺失位置要求发现"同一反对角线上颜色恒定"的结构约束——此规则在单面板中因空洞过多而难以可靠归纳（同一反对角线上可能大半是空洞），只有在合并后的近完整图案中才显现出清晰的反对角线色带
