## 新题 4：多色损伤提取与居中叠合

**组合逻辑**：[差异提取/difference_extraction](多对并行，创新后) → [裁剪/crop](原有) → [透明叠加/transparent_overlay](多色掩码居中合并，创新后)。创新点在于**多组独立的损伤检测结果被空间叠合成一个紧凑输出，各色损伤图案的组合揭示隐藏的空间规律**

**来源原语**：
- 差异提取(difference_extraction), 前景图案(foreground_motif), 缺损副本(damaged_copy), 缺失掩码(missing_cell_mask), 对齐比较(aligned_comparison) ← 2037f2c7
- 裁剪(crop), 透明叠加(transparent_overlay), 前景掩码(foreground_mask), 中心对齐(center_alignment), 多色掩码合并(multi_mask_merge) ← c8cbb738

**依赖链**：每对图案的差异提取→各自产生损伤掩码→裁剪归一化→居中叠合时各色掩码交织成组合图案。跳过差异提取则不知道哪些像素缺失；跳过居中叠合则各掩码分散在输入中无法显示组合结构

对每种颜色的完整/缺损图案对提取缺失像素掩码，裁剪后以各自颜色居中叠合到紧凑画布上。

**输入结构**：
- 约 20x20 的网格，黑(0)背景
- 包含 3~4 种非背景色（从蓝(1)、红(2)、绿(3)、黄(4)中选取），每种颜色出现恰好两个 4-连通图案
- 每对同色图案的边界框形状相同（宽高一致），一个为完整版（所有前景像素均为该颜色），另一个为缺损版（部分前景像素被替换为黑(0)背景）；完整版像素数严格大于缺损版
- 各颜色的图案之间互不重叠（边界框不相交），同色的两个图案也互不重叠
- 每种颜色的损伤掩码（完整版有而缺损版无的像素集合）裁剪后的边界框高度和宽度均为奇数
- 所有颜色的裁剪后掩码的最大边界框高度相同、最大边界框宽度相同（保证居中对齐时中心像素重合）
- 生成约束：各色损伤掩码居中叠合后互不重叠（不同颜色的掩码像素不落在同一位置）

**规则**：
1. 对每种颜色 C，在输入中找到同色的两个 4-连通图案，像素数多的为完整版，少的为缺损版
2. 按边界框左上角对齐两个图案，标记出完整版中为颜色 C 而缺损版中为黑(0)的像素位置，形成颜色 C 的损伤掩码
3. 将每个损伤掩码裁剪到自身最小边界框，保留原色 C
4. 输出画布尺寸 = 所有裁剪后掩码中最大高度 x 最大宽度，背景为黑(0)
5. 将每个裁剪后掩码居中放置到输出画布上（居中 = 掩码边界框中心对齐画布中心）
6. 各色掩码像素保留各自原色

**关键洞察**：单看某一种颜色只能得到孤立的损伤碎片，但所有颜色的损伤掩码居中叠合后形成一个有规律的组合图案——"损伤"本身是编码信号而非随机缺失；需对比多个示例确认是按像素数区分完整版与缺损版（而非按位置）
