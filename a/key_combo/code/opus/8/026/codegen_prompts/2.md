## 新题 2：镜像配对门控图例重涂

**组合逻辑**：[镜像对称检测](已有) + [重涂色](已有) + [颜色替换映射](已有) → 三者交织为"配对测试 + 图例查表"双重门控（创新——源题 ce039d91 中配对后固定涂蓝，源题 e9b4f6fc 中图例直接应用于裁剪对象；此处配对是涂色的前提，图例是涂色的参数，二者缺一不可）

**来源原语**：重涂色(ce039d91), 镜像对称(ce039d91), 镜像配对则涂色(ce039d91), 颜色替换映射(e9b4f6fc), 微型图例(e9b4f6fc), 裁剪(e9b4f6fc)

**依赖链**：镜像对称检测决定哪些像素有资格被涂色（门控）；图例决定涂成什么颜色（参数）。只做配对不查图例无法确定目标色；只查图例不做配对会错误地涂色到非对称像素。两层逻辑共同约束输出。

对前景掩膜中水平镜像配对的像素，按图例domino指定的颜色映射进行重涂；未配对的像素和配对但无图例对应的像素均保持不变。

**输入结构**：约 12x14 的网格（宽度为偶数），黑(0)背景。网格中有一个前景掩膜，由蓝(1)、红(2)、绿(3)三种颜色的像素组成（4-连通整体连通，约 25-40 像素），分布大致但不完全左右对称。掩膜外散布 2-3 个水平方向的两像素图例domino，每个domino的左像素为替换色、右像素为源色（如 [黄(4), 蓝(1)] 表示蓝→黄；[橙(7), 红(2)] 表示红→橙）。各domino的源色互不相同，且源色均为掩膜中实际出现的颜色。至少有一种掩膜颜色没有对应的domino。生成约束：对于每种有domino的颜色，掩膜中既有配对像素也有未配对像素。

**规则**：
1. 计算网格的垂直中线（列索引 = 宽度 / 2 - 0.5，即左半列与右半列的分界线）。
2. 对每个前景像素 (r, c)，找其水平镜像位置 (r, 宽度-1-c)。
3. 若 (r, c) 与其镜像位置颜色相同（均为前景色且颜色一致），则该像素为"已配对"。
4. 对每个已配对的像素，在图例中查找以该像素颜色为源色（右像素）的domino：
   - 若找到：将该像素重涂为domino的替换色（左像素）。
   - 若未找到：该像素保持原色不变。
5. 未配对的前景像素保持原色不变。
6. 背景像素和图例domino本身不出现在输出中——输出为整个网格（含图例位置和掩膜位置），图例domino像素在输出中擦除为黑(0)。

**关键洞察**：一个像素被重涂需要同时满足两个独立条件——它必须有镜像配对（几何约束），且其颜色必须在图例中有映射（颜色约束）。任一条件不满足都不会触发涂色，这使得同一颜色的像素在不同位置有不同命运。
