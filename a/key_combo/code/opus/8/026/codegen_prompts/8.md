## 新题 8：循环位移索引网格后像素放大

**组合逻辑**：[循环位移](已有) + [像素放大](已有) → 两步操作通过索引网格紧耦合（创新——源题 79cce52d 中位移后直接输出，源题 42f83767 中索引网格是静态的；此处位移改变了索引网格的内容排列，而放大操作依赖索引值选择模板，因此位移从根本上重组了放大结果）

**来源原语**：循环位移(79cce52d), 像素放大(42f83767), 索引网格(42f83767), 模板遮罩(42f83767), 颜色到模板映射(42f83767), 控制行(79cce52d), 控制列(79cce52d), 标记像素(79cce52d), 标记位定位移量(79cce52d), 顺序配对(42f83767), 色卡(42f83767)

**依赖链**：控制边框的标记位置编码位移量→循环位移重排索引网格→重排后的索引值决定每个位置使用哪个模板→像素放大生成最终输出。删掉位移则索引不变（退化为源题 42f83767）；删掉放大则位移结果只是颜色网格的平移（退化为源题 79cce52d）。只有组合在一起时，位移才通过影响索引选择而产生在两道源题中都不存在的"间接重组"效果。

先根据控制边框中标记像素的位置循环位移索引网格，再将位移后的索引网格按图例模板进行像素放大。

**输入结构**：约 9x9 的网格。最上一行为控制行：灰(5)填充色中有一个红(2)标记像素，位于某列 c（0-indexed）。最左一列为控制列：灰(5)填充色中有一个蓝(1)标记像素，位于某行 r（0-indexed）。控制行与控制列的交汇格（左上角）为灰(5)。去除控制边框后，剩余区域分为两部分：上方图例区和下方索引网格。图例区包含 2-3 个 2x2 色卡（每个色卡为单色实心方块，颜色互不相同，如黄(4)、绿(3)、橙(7)），以及对应数量的 2x2 模板遮罩（品红(6)像素构成不同图案，如对角线、L形、实心等）。色卡和模板遮罩按左右顺序一一配对。下方索引网格为 3x3 或 4x4，每个像素颜色为色卡颜色之一。生成约束：索引网格中每种色卡颜色至少出现一次。

**规则**：
1. 读取控制行中红(2)标记的列位置 c（在控制行中的 0-indexed 位置，不计控制列交汇格）。
2. 读取控制列中蓝(1)标记的行位置 r（在控制列中的 0-indexed 位置，不计控制行交汇格）。
3. 剥离控制行和控制列，分离出图例区和索引网格。
4. 将索引网格循环右移 c 列、循环下移 r 行。
5. 按左右顺序将色卡与模板遮罩配对（第 1 个色卡配第 1 个遮罩，以此类推）。
6. 对移位后的索引网格中的每个像素：找到与其颜色匹配的色卡，取配对的模板遮罩，将该像素替换为一个与遮罩等大的块——遮罩中品红(6)位置涂为该像素的颜色，遮罩中黑(0)位置保持黑(0)。
7. 输出为放大后的网格（索引网格每个像素变为 2x2 块，总尺寸为索引网格行数x2 乘以列数x2）。

**关键洞察**：控制标记不是装饰——它们编码的位移量决定了索引网格中每个位置"看到"哪个颜色，进而选择哪个模板。同一个索引网格配不同的标记位置会产生完全不同的放大图案，位移通过改变颜色-位置对应关系间接地重组了输出结构。

    sigs.add(hashlib.md5(inp.tobytes() + str(inp.shape).encode()).hexdigest())
print("variants", len(sigs))
assert len(sigs) >= 20
