## 新题 9：稀疏标记框定区域内众数颜色差异化高亮

**组合逻辑**：[重涂色(recolor)](创新：区域内按众数/非众数差异化涂色，而非统一涂为单色) ← [计数(counting)](创新：计数用于区分众数与非众数的差异化处理) ← [包围框内部(inside_bbox)](约束计数范围)

**来源原语**：重涂色(recolor) + 包围框内部(inside_bbox) + 稀疏标记框定高亮(sparse_marker_highlight) + 前景图案(foreground_pattern) ← 32597951；计数(counting) + 众数颜色决定输出(majority_color_out) ← ff2825db；标记像素(marker_pixel) ← 共用

**依赖链**：稀疏标记的包围框确定关注区域 → 在区域内分颜色计数 → 众数颜色获得一种高亮处理，非众数颜色获得另一种 → 区域外不变 → 删除包围框确定或删除计数，都无法完成差异化涂色

找到稀疏标记的包围框，在框内按颜色频率分众数与非众数做差异化重涂色。

**输入结构**：约 14x14 的黑(0)背景网格。网格中散布着由 3 种非黑颜色（如红(2)、蓝(1)、绿(3)）组成的混合前景像素图案（总计约 30-50 个前景像素，分布在网格中部区域，形成不规则的混色图案）。另有 2-4 个青(8)标记像素稀疏分布在图案周围或边缘。生成约束：青(8)标记不与任何前景像素相邻（4-连通）；在青标记的包围框内，三种前景色的像素数量两两不同，确保众数唯一；包围框外也有前景像素存在。

**规则**：
1. 找到所有青(8)标记像素的包围框（行列极值组成的矩形）。
2. 在包围框内部（含边界行列），统计每种非黑、非青颜色的像素数量。
3. 将像素数最多的颜色标记为"众数色"，其余非黑、非青颜色标记为"非众数色"。
4. 在包围框内部：所有众数色像素重涂为黄(4)；所有非众数色像素重涂为灰(5)；黑(0)像素和青(8)像素保持不变。
5. 包围框外部：所有像素保持不变（包括该区域的前景像素仍保持原色）。

**关键洞察**：仅凭包围框无法确定涂色方案（不知道涂哪种颜色为黄、哪种为灰），仅凭频率统计不知道在哪里涂——两个操作必须同时具备才能产生正确输出。求解者还需注意包围框外的前景像素不变，这排除了"全局众数"的错误假设。
