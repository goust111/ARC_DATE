## 新题 9：递归射线网络划分后压缩

**组合逻辑**：[射线延伸/ray_extend](已有) + [递归展开/recursive_expansion](已有) → [压缩/compress](创新：射线网络本身成为压缩的分区边界而非预设分隔线) ← 由 [正交转向/perpendicular_turn](已有) 和 [标记触发转向/marker_triggers_turn](已有) 和 [网格分区/grid_partition](创新：分区由射线动态生成而非预置) 和 [每区域折叠单像素/region_to_pixel](已有) 共同约束

**来源原语**：射线延伸(#b942fd60), 递归展开(#b942fd60), 起点像素(#b942fd60), 标记像素(#b942fd60), 射线网络(#b942fd60), 正交转向(#b942fd60), 标记触发转向(#b942fd60), 深度优先展开(#b942fd60), 压缩(#780d0b14), 网格分区(#780d0b14), 色块区域(#780d0b14), 每区域折叠单像素(#780d0b14)

**依赖链**：红起点像素发射水平射线 → 遇标记像素时正交转向递归展开 → 射线网络将网格分割为若干封闭区域 → 每个封闭区域内散布着同一颜色的非射线像素 → 按区域拓扑位置压缩为小网格

递归射线网络在网格上展开后形成分区边界，每个封闭区域压缩为一个像素输出。

**输入结构**：约 15x15 网格，黑(0)背景。一个红(2)起点像素位于左边缘某行。若干彩色标记像素（绿(3)或蓝(1)）散布在网格中，它们决定射线转向点。除起点和标记外，网格中还散布少量彩色像素（黄(4)、品红(6)、橙(7)等，每种颜色集中在某个空间区域内，每区域 2~4 个同色像素）。这些散布像素不在射线将要经过的行列上。生成时保证：射线网络展开后恰好将网格分割为若干个封闭矩形区域（射线 + 网格边界围成）；每个封闭区域内恰好包含一种非黑非红非标记色的散布像素（该颜色即为区域主色）；各区域主色互不相同；标记像素布局使得射线网络能完整分割网格（射线到达网格边界或与其他射线相交即封闭区域）。

**规则**：
1. 从红(2)起点像素向右发射水平射线，逐格绘红色直到遇到第一个标记像素或网格边界。
2. 首次遇到某个标记像素时，射线停在标记前一格。从该格发射正交方向（垂直）的射线，向两个方向延伸直到遇到标记或边界。同一标记再次被射线触及时仅阻停射线，不再触发新的正交展开。
3. 新射线按深度优先展开：对同一标记触发的两个方向，先处理右/下方向再处理左/上方向。
4. 重复直到无新标记可达。所有射线像素绘为红(2)。
5. 射线网络与网格边界共同将网格分割为若干封闭矩形区域。对每个区域，找到其中所有非黑非红非标记色的像素，取其颜色为该区域主色。
6. 构建输出网格：输出的行列数对应区域的拓扑行列布局（即被水平射线/边界分隔的行带数 x 被垂直射线/边界分隔的列带数）。每个输出格填入对应区域的主色。输出中区域的相对空间位置与输入一致（左上区域映射到输出左上格等）。

**关键洞察**：射线网络不是装饰图案而是结构性分区边界——改变一个标记像素的位置会完全改变射线走向、区域划分乃至输出网格的尺寸。射线展开与区域压缩是不可分离的同一推理过程的两个阶段。
