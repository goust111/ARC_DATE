## 新题 1：缺口环射线

**组合逻辑**：[循环移色/color_cycle](已有) + [射线延伸/ray_extend](创新：射线颜色由循环结果决定，射线方向由缺口朝向决定) ← 由 [缺口像素/gap_pixel](创新：从矩形框语境移植到环形语境) 和 [反向循环/opposite_cycle](已有) 共同约束

**来源原语**：循环移色(#46c35fc7), 反向循环(#46c35fc7), 角位像素(#46c35fc7), 边中像素(#46c35fc7), 角与边中分组(#46c35fc7), 射线延伸(#b942fd60/#292dd178), 缺口像素(#292dd178), 缺口定射线向(#292dd178)

**依赖链**：缺口位置决定射线方向 → 循环移色后缺口位置的"虚拟颜色"决定射线颜色 → 射线遇到其他环时停止，形成环间空间交互

将带缺口的多色 3x3 环先做角/边中反向循环移色，再从缺口向外发射由循环结果着色的射线。

**输入结构**：约 15x15 网格，黑(0)背景。散布若干 3x3 环形前景对象，每个环由 8 个非黑像素环绕 1 个黑(0)中心构成。每个环恰好缺少一个边中位置的像素（即上、下、左、右四个边中位之一为黑(0)），形成缺口。环的 8 个位置（实际可见 7 个）使用 2~3 种不同非黑颜色。不同环之间在缺口朝向所在的行或列上互不重叠（即从任一环的缺口向外延伸的射线路径上不会经过另一个环的缺口行/列，但可能遇到另一个环的外侧像素）。每个环的缺口朝向与环中心的相对位置明确（缺口在中心正上/正下/正左/正右）。生成时保证各环之间至少间隔 2 个像素。

**规则**：
1. 对每个 3x3 环，将四个角位像素的颜色沿顺时针方向循环一步（左上→右上→右下→左下→左上），将四个边中位像素的颜色沿逆时针方向循环一步（上→左→下→右→上）。缺口位置虽然无像素，但在边中循环中仍占位——其"虚拟颜色"等于循环后该位置应得的颜色。
2. 循环完成后，将缺口位置填入其虚拟颜色，成为射线起点。
3. 从缺口位置向外（远离环中心的方向）逐格延伸射线，射线颜色为该虚拟颜色。射线在以下条件停止（不含终点）：遇到任何非黑像素，或到达网格边界。
4. 环本身的 7 个可见像素按循环后的新颜色重绘。环中心保持黑(0)。

**关键洞察**：缺口虽然在输入中是空的，但它在边中循环中占有位置——必须模拟完整的四元循环才能确定缺口应该是什么颜色，而这个颜色正是射线的唯一着色依据。
