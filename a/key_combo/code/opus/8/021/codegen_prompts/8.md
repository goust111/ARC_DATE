## 新题 8：镜像线条画中的射线分支填充

**组合逻辑**：[射线延伸/墙段开口分支](创新——射线在镜像生成的结构中分支) + [镜像](创新——镜像不是最终操作而是中间几何生成步骤) + [洪泛填充/种子色标记填充](填充射线围出的区域) + [从边缘推进](已有原语)

**来源原语**：射线延伸/分支/边缘标记/墙段/从边缘推进/墙段开口分支(f9a67cb5)、镜像/象限(833dafe3)、洪泛填充/种子像素/封闭腔体/种子色标记填充(8b7bacbf)

**依赖链**：输入的墙段图案仅在左半部分，左右镜像后在中轴线处墙段对接，可能产生原本不存在的开口或封闭结构。边缘标记的射线从左侧边缘射入，遇到墙段时在开口处分支——而哪些位置是开口取决于镜像后墙段的对接情况。射线路径围出的封闭区域随后被填充为射线颜色。镜像改变了墙段拓扑，墙段拓扑决定了射线分支方式，射线路径决定了填充区域——三步形成不可跳步的推理链。

将左半部分的墙段左右镜像后，从边缘标记射入的射线在合并后的墙段开口处分支，最终填充射线围成的封闭区域。

**输入结构**：约 15x16 的网格（列数为偶数），背景为黑(0)。左半部分（前 8 列）包含 2~3 段绿(3)的水平或垂直墙段（每段 3~5 像素长，1 像素宽），墙段之间有间隔，不连通。右半部分全为背景。左侧边缘（第 0 列）有 1~2 个单像素边缘标记，颜色各不相同，取自红(2)、蓝(1)。标记不与墙段在同一行。生成约束：左半墙段经左右镜像后，在中轴线处（第 7-8 列交界）某些墙段的端点对接形成更长的连续墙，某些则在对接处留下 1~2 格的间隙（开口）；射线从边缘标记出发向右推进后，经过至少一次分支，并且分支后的射线路径与墙段共同围出至少 1 个封闭背景区域。

**规则**：
1. 将左半部分（第 0 至第 N/2-1 列，N 为网格宽度）的所有非背景像素以网格垂直中轴线为对称轴左右镜像到右半部分。边缘标记不参与镜像（仅墙段镜像）。
2. 从每个边缘标记出发，向右发射水平射线，将经过的背景像素涂为标记颜色。
3. 当射线的下一格是墙段像素时，射线停止。然后检查该墙段（与射线碰撞点在同一连通墙段中的所有像素）的两个端点之外各一格是否为背景：若是背景，则为开口，从每个开口位置沿射线原方向（向右）继续发射新射线。
4. 所有射线分支（包括二次、三次分支）重复步骤 2-3，直到射线离开网格右边界或遇到已涂色的射线像素（碰撞停止）。
5. 在完成所有射线绘制后，找出所有被射线路径和墙段共同围成的封闭背景区域（4-连通背景分量，不与网格边缘连通）。将每个封闭区域填充为围成它的射线的颜色。若一个区域的边界上有多种射线颜色，填充为其中出现次数更多的颜色。
6. 保留所有墙段和射线路径。

**关键洞察**：右半部分在输入中是空白的，求解者必须先推断出镜像规则；镜像后的墙段对接方式（连通还是留隙）决定了射线的分支路径，而分支路径又决定了哪些区域被围成封闭腔体——整个因果链由镜像这一看不见的中间步骤驱动。
