## 新题 5：稀疏层补全后的孔洞计数配对

**组合逻辑**：[补全](创新——补全改变拓扑结构从而影响后续匹配) + [计数](对补全结果的连通孔洞计数) + [嵌套放置](已有原语) + [重涂色](已有原语) + [孔洞数匹配](匹配的对象不是预给定的完整形状，而是补全后才确定的)

**来源原语**：补全/稀疏矩形层/嵌套矩形/由外到内嵌套/大层先画小层覆盖(5751f35e)、嵌套放置/重涂色/计数/空心框架/精灵体/孔洞/孔洞数匹配/连通孔洞数为键(8698868d)

**依赖链**：输入中的精灵体和框架都以稀疏像素给出，必须先补全才能确定它们的完整形状。补全后精灵体内部可能出现（或不出现）封闭孔洞——孔洞数量只有补全后才确定。框架内部的空腔数量也只有补全后才能计算。以孔洞数为键进行精灵体-框架配对，然后嵌套放置并重涂色。补全操作改变了拓扑（创建或消除孔洞），拓扑变化决定了匹配关系——这是源题中不存在的结构。

将稀疏提示的精灵体和框架各自补全为完整形状，再按补全后的连通孔洞数配对嵌套。

**输入结构**：约 20x20 的网格，背景为青(8)。网格中有 3 个空心正方形框架（边长 5~7 像素，边宽 1 像素），颜色各不相同，取自红(2)、绿(3)、橙(7)。每个框架以稀疏形式给出——仅显示边框像素的约 40%~60%，其余边框位置为背景色。框架不相邻、不重叠。另有 3 个小型精灵体（每个约 3x3~4x4 的边界框），颜色各不相同，取自蓝(1)、黄(4)、品红(6)。每个精灵体也以稀疏形式给出——仅显示约 50%~70% 的像素。精灵体放置在远离框架的位置，彼此也不相邻。生成约束：每个框架补全后其内部恰好形成 1 个连通背景腔体；3 个精灵体补全后分别包含 0、1、1 个连通背景孔洞（其中两个精灵体孔洞数相同，但框架侧也有对应——见规则）。实际上改为：3 个精灵体补全后分别包含 0、1、2 个连通背景孔洞，3 个框架补全后内部被框架边框分割的连通背景区域数分别为 1、2、3（对应框架内部可能有内嵌的稀疏隔断线，补全后将内部分成多个腔室）。这样孔洞数各不相同，配对唯一。

**规则**：
1. 对每个框架：根据已有的稀疏边框像素推断完整的轴对齐正方形边框（取所有同色像素的最小外接矩形作为完整边框），将缺失的边框像素补全。若框架内部有同色的稀疏隔断线段（未与边框连通的孤立像素），将其补全为连接对边的完整水平或垂直线段。
2. 对每个精灵体：取所有同色像素的最小外接矩形，将外接矩形内所有不属于已知连通背景孔洞边界的空位补全为精灵体颜色。连通背景孔洞定义为：在外接矩形内部被精灵体像素 4-连通包围的背景区域。
3. 统计每个补全后精灵体的连通背景孔洞数（4-连通分量数），以及每个补全后框架内部的连通背景腔室数。
4. 将精灵体与框架按数量配对：孔洞数为 N 的精灵体匹配腔室数为 N+1 的框架（框架的 N+1 个腔室中，1 个被精灵体占据，剩余 N 个对应精灵体的 N 个孔洞）。
5. 将每个精灵体居中放置在其匹配框架的第一个腔室内（按从左到右、从上到下的顺序取第一个足够大的腔室）。精灵体中的背景色孔洞重涂为框架的颜色。
6. 输出时保留所有框架和嵌套的精灵体，背景保持青(8)。

**关键洞察**：稀疏形式的框架看起来只是残缺的方框，但补全后可能出现内部隔断，将框架内部分成多个腔室——腔室数量只有补全后才知道，而这个数量恰好是配对的键。求解者必须先正确补全，再计数，再配对。
