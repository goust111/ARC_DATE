## 新题 6：对角偏移印章与交替翻转拼接

**组合逻辑**：[对角线偏移复制](创新——生成的对角纹理作为拼接的基础单元而非最终输出) + [交替翻转/堆叠](创新——对对角纹理整体进行翻转堆叠) + [画布加倍](已有原语) + [单行重叠拼接](已有原语)

**来源原语**：对角线偏移复制/前景图案/画布加倍(d13f3404)、堆叠/交替翻转/波形图案/单行重叠拼接(eb281b96)

**依赖链**：第一步的对角偏移复制将小图案扩展为一个具有对角条纹特征的中间纹理；这个中间纹理的几何形态决定了第二步翻转堆叠时重叠行的对齐方式。如果跳过对角复制，就没有可堆叠的波形；如果跳过堆叠，就只有单层对角条纹。两步的输出结构互相依赖——对角复制的边缘行恰好成为翻转堆叠的重叠缝合线。

先将前景图案沿对角线偏移复制到加倍画布上形成条纹纹理，再将该纹理作为波形单元进行交替翻转堆叠。

**输入结构**：约 4x4 至 5x5 的小网格，背景为黑(0)。包含 2~4 个前景像素，颜色取自红(2)、蓝(1)、绿(3)，形成一个稀疏的不规则小图案（4-连通，非对称）。生成约束：图案的最底行至少有一个前景像素，最顶行也至少有一个，以保证对角复制后条纹的首尾行都有非背景像素（堆叠时需要重叠行有内容）。

**规则**：
1. 创建一个高度和宽度都是输入两倍的中间画布，填充背景色黑(0)。
2. 对输入中每个前景像素 (r, c, color)，在中间画布上沿下-右对角线方向逐格复制：即在所有满足 0 <= r+k < 中间画布高度 且 0 <= c+k < 中间画布宽度 的整数 k 处，将中间画布 (r+k, c+k) 涂为 color。若多条对角线轨迹交汇于同一格，颜色相同则直接涂，颜色不同则保留输入中行坐标更小的像素的颜色。
3. 将中间画布作为"波形单元"P。创建输出画布，高度 = 4 * P的高度 - 3（四份波形，三个重叠行），宽度 = P 的宽度。
4. 将四份波形从上到下依次粘贴，奇数份（第 1、3 份）使用 P 原样，偶数份（第 2、4 份）使用 P 的上下翻转。相邻两份之间重叠 1 行（即第 N+1 份的首行与第 N 份的末行重合）。重叠行像素取两份中非背景色的那个；若都非背景色则保留来自奇数份的颜色。
5. 输出即为最终画布。

**关键洞察**：对角偏移复制产生的条纹天然具有"波形"特征——同一条纹在画布首尾行的非背景像素位置恰好互补，使得上下翻转后一行重叠就能无缝拼接。求解者需要理解这一几何必然性才能预测输出。
