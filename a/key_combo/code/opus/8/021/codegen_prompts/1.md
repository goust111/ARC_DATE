## 新题 1：瀑布雕刻砖块

**组合逻辑**：[溢出扩散](水流路径本身作为雕刻模板，而非预给定图案) + [挖孔](被动接受动态生成的模板) + [紧凑排列](已有原语) + [级联分支](已有原语)

**来源原语**：溢出扩散/级联分支/碰撞停止(36a08778)、挖孔/紧凑排列/单色块/保持行列顺序(58f5dbd5)

**依赖链**：水流从顶部水源下落，遇到作为"架子"的单色块时在块表面扩散——扩散的路径就是雕刻模板。水流溢出块边缘后继续下落，对下方的块重复此过程。每个块被水流接触到的表面像素被挖去（变为背景色），形成各不相同的雕刻图案。最终将所有被雕刻的块按原始行列顺序紧凑排列到输出网格中。水流路径动态生成雕刻模板——这一结构关系在任何源题中都不存在。

将水源下落产生的级联流径作为雕刻模板刻入下方的单色块，然后紧凑排列被雕刻的块。

**输入结构**：约 20x15 的网格，背景为黑(0)。顶部边缘有 2~3 个蓝(1)像素簇作为水源（每簇 1~2 像素，紧贴顶行）。网格中部和下部散布 3~5 个不同颜色的实心矩形块（每块约 4x4~5x5 像素，颜色各不相同，取自红(2)、绿(3)、黄(4)、灰(5)、品红(6)），这些块水平位置有错开，使得水流从上方块溢出后恰好落在下方块的不同位置。各块之间不相邻，垂直间距至少 2 行。生成约束：每个块的顶部至少有一部分在某个水源的正下方或在上方块溢出点的正下方，保证每个块都会被水流触及。

**规则**：
1. 水流从每个水源像素开始逐行向下扩展，在空白（背景）区域中垂直下落，将经过的背景像素标记为蓝(1)。
2. 当水流的下一行遇到某个单色块的顶面时，水流沿该块顶面向左右两侧扩散，直到块的左右边缘各再延伸一格（溢出位置）。块顶面被水流接触的所有像素被挖去（变为背景色黑(0)），但块的其余部分保持不变。
3. 从块左右两侧的溢出位置，水流各自继续向下垂直落下，重复步骤 1-2 的逻辑对下方的块进行雕刻。
4. 多股水流可能同时到达同一个块——所有水流触及的表面像素都被挖去。
5. 输出时去除水流痕迹和空白区域，仅将被雕刻后的块按它们在输入中的行列位置（行优先，从左上到右下）紧凑排列，块间间隔 1 像素背景色，外围 1 像素背景色边框。

**关键洞察**：雕刻模板不是预先给定的独立图案，而是由水流的物理模拟动态生成——上方块的形状和位置决定溢出点，进而决定下方块的雕刻位置，形成级联依赖。

p = Path("/home/lixinyu/snap/a/key_combo/code/opus/8/021/1.py")
mod = SourceFileLoader("new_arc_task", str(p)).load_module()
sigs = set()
for i in range(100):
    inp = mod.generate_input()
    out = mod.main(inp)
    assert isinstance(inp, np.ndarray)
    assert isinstance(out, np.ndarray)
    assert inp.ndim == 2 and max(inp.shape) <= 30, f"input grid exceeds 30x30: {inp.shape}"
    assert out.ndim == 2 and max(out.shape) <= 30, f"output grid exceeds 30x30: {out.shape}"
    sigs.add(hashlib.md5(inp.tobytes() + str(inp.shape).encode()).hexdigest())
print("variants", len(sigs))
assert len(sigs) >= 20
