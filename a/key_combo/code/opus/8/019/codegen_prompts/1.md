## 新题 1：重力沉降后的模板形状涌现与重涂

**组合逻辑**：[滑动/重力沉降](原有) -> [连通分量重构](创新：重力改变连通关系，使原本分离的对象合并为新形状) -> [归一化形状比对 + 匹配模板则重涂](原有)

**来源原语**：滑动/重力沉降/列内独立（1e0a9b12）、归一化形状比对/匹配模板则重涂/连通分量/模板对象（4ff4c9da）、重涂色（4ff4c9da）

**依赖链**：重力改变像素的纵向位置 -> 列内像素堆叠导致原本分离的同色连通分量合并为新形状 -> 新形状与模板进行归一化比对 -> 匹配者被重涂为模板色。重力结果决定了哪些像素相邻进而决定了哪些形状存在，形状比对筛选出重涂目标。删除重力环节则连通分量不变、无法产生匹配形状；删除比对环节则无法确定重涂目标。

所有前景像素在列内下沉后，与模板形状匹配的新连通分量被重涂为模板色。

**输入结构**：
- 黑(0)背景，约 12x12 网格
- 网格中散布多个小型单色 4-连通对象（每个 2~5 像素），使用蓝(1)和红(2)两种颜色，分布在网格中上部区域
- 恰好一个青(8)对象作为模板（3~5 像素，4-连通），固定于网格底行且其下方无空位（重力不影响它）
- 各对象初始互不相邻（8-连通意义下不接触），但在同一列中某些不同高度的同色对象之间仅有空行间隔
- 网格宽度约 12 列，确保列内重力后不同对象能合并
- 生成约束：至少两个同色对象在重力沉降后因列内堆叠而合并为一个新 4-连通分量，该新分量的平移归一化掩码与青(8)模板完全一致；至少一个对象沉降后形状不变且不匹配模板；模板本身的像素所在列中没有其他同色像素

**规则**：
1. 对所有非背景、非青(8)像素执行列内独立重力：每列中的蓝(1)和红(2)像素保持自上而下的相对顺序向下沉降，直到触碰已有非背景像素的上方或网格底边。青(8)模板像素视为障碍，不参与沉降。
2. 沉降完成后，以 4-连通方式对每种颜色独立重新计算连通分量。
3. 将青(8)模板对象的形状掩码平移归一化（将边界框左上角对齐至原点）。
4. 对每个非青连通分量，平移归一化其形状掩码并与模板掩码逐像素比对。若完全一致，将该分量所有像素重涂为青(8)。
5. 不匹配的连通分量保留其原色。模板对象本身和背景像素不变。
6. 处理顺序不影响结果（各分量的重涂互相独立）。

**关键洞察**：重力可使原本不相邻的同色像素在同一列内堆叠而合并为新连通分量——匹配模板的形状并非输入中已存在的，而是重力操作涌现出的。求解者必须先模拟重力再检查匹配，而非在原始布局中寻找模板。

## 实现要求

1. `main(grid)` 必须实现新题描述中的确定性转换规则，不能只识别 `generate_input()` 的固定模板。禁止不同的input网格输出相同的output网格。
2. `generate_input()` 必须随机生成多样样例，不能固定死。随机维度应覆盖：网格大小、对象数量、位置、颜色、方向、形状参数或关键分支。注意若描述中存在若干，需实现而不是只有单个，包括object或者对应关系等等。
3. 生成器必须保证输入满足 `main()` 的隐式假设：对象不重叠、不越界、特殊标记唯一或可区分、匹配关系无歧义、关键分支出现概率相同。
4. 禁止把 ARC 颜色 id 、亮度、拼写等当作人类不可见的数值语义参与排序、大小比较或隐藏映射。颜色变化必须有可见结构线索。注意颜色亮度、拼写等也是不可见信息，若描述中出现违规的颜色id或者亮度，可自行使用少量的固定颜色替代，但注意生成时要在三个以内输入输出网格中对所有变换100%覆盖度。
