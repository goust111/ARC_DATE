## 新题 8：裁剪后四折对称补全涌现封闭孔洞并填色

**组合逻辑**：[裁剪/角标记像素/中心图案](原有) -> [镜像/轴对称](创新：不是全画布水平镜像，而是对裁剪出的部分图案做四折对称补全) -> [填充/封闭孔洞](创新：孔洞在单象限中是开放的，仅在对称补全后才涌现封闭) + [角标色决定重涂](创新：角标色同时编码裁剪边界和填充颜色，裁剪时角标被移除但其颜色需跨步骤记忆)

**来源原语**：裁剪/角标记像素/中心图案/内部包含/角标色决定重涂/边框（3de23699）、镜像/轴对称/画布加倍（c9e6f938）、填充/封闭孔洞/仅填矩形内部/孔洞在框内（e73095fd）

**依赖链**：角标像素定义裁剪区并编码填充色 -> 裁剪出中心图案的左上象限（角标被移除）-> 四折对称补全 -> 对称使开放区域封闭形成孔洞 -> 用记忆中的角标色填充孔洞。孔洞是对称操作的涌现产物；填充色在裁剪步骤中就被丢弃，需要跨步骤记忆。

裁剪出角标框内的部分图案，四折对称补全后，用角标颜色填充因对称而涌现的封闭孔洞。

**输入结构**：
- 黑(0)背景，约 14x14 网格
- 一簇非黑像素位于网格中央偏左上方向
- 该簇的四角有四个青(8)角标像素，描绘一个矩形框（角标在框的四个角上，框的四条边不绘制）
- 框内部尺寸为偶数行 x 偶数列（例如 6x6 或 8x8）
- 框内部仅左上象限（上半行、左半列）有蓝(1)前景像素构成的非对称图形（3~8 像素），右上、左下、右下象限全为黑(0)
- 左上象限图形设计为：其轮廓在象限的右边界和/或下边界处有开口（未封闭），但若将该象限分别水平翻转生成右上象限、垂直翻转生成左下象限、同时水平+垂直翻转生成右下象限，则四个镜像副本拼合后开口被彼此封闭，在中央区域形成封闭孔洞
- 生成约束：四折对称补全后至少产生一个面积 >= 2 像素的封闭孔洞（被蓝(1)像素完全包围的黑(0)连通区域）；左上象限图形本身无封闭孔洞（所有内部黑色区域均与象限边界连通）

**规则**：
1. 找到四个青(8)角标像素，确定其围成的矩形。记录角标颜色为青(8)。
2. 裁剪矩形内部区域：去掉角标所在的行和列，得到一个偶数行 x 偶数列的子网格。角标像素不包含在子网格中。
3. 将子网格的左上象限（前一半行、前一半列）作为源象限 S。
4. 四折对称补全：
   - 右上象限 = S 水平翻转（左右镜像）
   - 左下象限 = S 垂直翻转（上下镜像）
   - 右下象限 = S 旋转 180 度（同时水平+垂直翻转）
5. 在补全后的完整子网格中，使用 flood fill 从四条边界的所有黑(0)像素开始扩展（4-连通，不穿越蓝(1)像素），标记所有可达的黑(0)像素为"外部"。
6. 剩余未标记的黑(0)4-连通区域即为封闭孔洞。将所有封闭孔洞像素填充为青(8)（步骤 1 中记录的角标颜色）。
7. 输出为补全并填充后的子网格（尺寸为偶数行 x 偶数列，不含角标和外框）。

**关键洞察**：左上象限中的图形开口朝向象限边界，单独看不存在任何封闭区域。但四折对称补全使四个副本的开口互相对接——对称操作涌现出了原始图案中不存在的封闭孔洞。角标颜色在裁剪时已被物理移除，但它编码了最终的填充色，求解者需跨步骤记忆这一信息。

## 实现要求

1. `main(grid)` 必须实现新题描述中的确定性转换规则，不能只识别 `generate_input()` 的固定模板。禁止不同的input网格输出相同的output网格。
2. `generate_input()` 必须随机生成多样样例，不能固定死。随机维度应覆盖：网格大小、对象数量、位置、颜色、方向、形状参数或关键分支。注意若描述中存在若干，需实现而不是只有单个，包括object或者对应关系等等。
3. 生成器必须保证输入满足 `main()` 的隐式假设：对象不重叠、不越界、特殊标记唯一或可区分、匹配关系无歧义、关键分支出现概率相同。
4. 禁止把 ARC 颜色 id 、亮度、拼写等当作人类不可见的数值语义参与排序、大小比较或隐藏映射。颜色变化必须有可见结构线索。注意颜色亮度、拼写等也是不可见信息，若描述中出现违规的颜色id或者亮度，可自行使用少量的固定颜色替代，但注意生成时要在三个以内输入输出网格中对所有变换100%覆盖度。
