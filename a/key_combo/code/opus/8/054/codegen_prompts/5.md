## 新题 5：矩形遮挡层序推断与同层间隙填充

**组合逻辑**：[层序推断](已有操作，但作用对象从直线变为矩形，推断逻辑从共线像素变为面积覆盖) → [间隙检测+条件填充](已有操作，但填充颜色不再固定，而由层序推断的结果动态决定) → [计数](已有，统计各层矩形数作为验证约束)

**来源原语**：层序推断(layer_infer, 22425bda), 遮挡层次(occlusion_order, 22425bda), 排序(sort, 22425bda), 填充(fill, ef135b50), 间隙区域(gap_region, ef135b50), 行列跨度重叠(row_span_overlap, ef135b50), 无遮挡才填充(fill_if_unobstructed, ef135b50), 计数(counting, b1986d4b)

**依赖链**：矩形重叠区域的可见颜色 → 推断出全局自底向上的层叠顺序 → 层叠顺序确定"同层"矩形对 → 同层矩形对之间的间隙若无更高层矩形遮挡则填充 → 填充颜色来自紧邻上层的颜色（层序推断的结果直接决定填充参数）。删除层序推断则无法确定同层关系和填充颜色；删除间隙填充则层序推断无可视化表达；删除遮挡条件判断则可能错误填充被上层遮挡的间隙。

推断重叠矩形的层叠顺序，在同一层的水平相邻矩形之间用上层矩形的颜色填充未被遮挡的间隙。

**输入结构**：黑(0)背景网格，约 16x16。网格中有 4~6 个不同颜色的实心矩形（每个矩形使用一种唯一的非背景色，如红(2)、蓝(1)、绿(3)、黄(4)、品红(6)），矩形大小约 4x3 至 7x5 像素。部分矩形有重叠区域（至少有 3 对矩形重叠），重叠处只显示层叠顺序中较高那个矩形的颜色。至少有 2 对矩形在水平方向上不重叠（列范围不交），但行范围有重叠，且它们在层叠顺序中处于同一层深度。它们之间的水平间隙中没有更高层矩形穿过。另有至少 1 对矩形满足间隙条件但有更高层矩形的边界框穿越该间隙。生成约束：层叠顺序唯一（不存在两种合法排列都能解释所有重叠区域的可见颜色）；同层深度的矩形至少 2 个。

**规则**：
1. 恢复每个矩形的完整范围：通过可见边缘推断被遮挡部分。对每种颜色，找到其所有可见像素的行范围和列范围，取最小外接矩形作为该颜色矩形的完整范围（假设每个矩形都是完整的实心矩形，无孔洞）。
2. 推断层叠顺序：对每对重叠矩形，重叠区域中可见的颜色在上、被遮挡的颜色在下。收集所有这样的"上/下"约束，拓扑排序得到唯一的自底向上层叠序列。将层叠位置编号为 1（最底层）到 N（最顶层）。
3. 确定同层矩形对：同层的定义——两个矩形之间不存在直接或传递的上/下约束（即在偏序关系中不可比），且在拓扑排序中被分配到相同的层深度（层深度 = 该矩形在约束图中最长上行路径的长度 + 1）。
4. 对每对同层矩形，检查是否满足间隙填充条件：(a) 列范围不重叠；(b) 行范围有重叠；(c) 在行范围重叠的那些行中，两个矩形之间的列区间（间隙）内，没有任何层深度更大（更高层）的矩形的完整范围与该间隙在行列上均有交集。
5. 对满足条件的间隙：确定紧邻上层颜色——在层叠顺序中，找到层深度恰好为当前层深度 + 1 的矩形颜色。若有多个，选择其完整范围与间隙行列区间重叠面积最大的那个颜色。若层深度 + 1 不存在矩形（当前已是最顶层），则填充灰(5)。
6. 用上述颜色填充间隙中、行范围重叠区间内的所有黑(0)像素。不改变任何已有矩形像素。
7. 处理顺序：按间隙的左上角阅读序依次填充。

**关键洞察**：源题 22425bda 的遮挡推断作用于一维直线的交叉点，本题将其推广到二维矩形的面积重叠。源题 ef135b50 的间隙填充使用固定颜色（栗(9)），本题的填充颜色由层叠分析的结果——紧邻上层的颜色——动态决定，使得遮挡推断和间隙填充之间形成了源题中不存在的信息回路。需要对比多个示例才能发现"同层"概念以及填充颜色来自上层的规则。
