## 新题 8：地形谷地中的精灵体嵌入

**组合逻辑**：[地形谷地识别](创新：将地形轮廓的凹陷区域视为"孔洞"的变体——不是 2D 对象中的缺口而是 1.5D 地形中的凹槽) → [形状嵌合](已有关系，但匹配维度从完整 2D 变为宽度优先的部分匹配) → [裁剪+对接](已有操作，但对接锚点由地形谷底位置决定而非连接点像素) → [放置后变色](已有条件)

**来源原语**：裁剪(crop, b94a9452/20270e3b), 形状嵌合(shape_fitting, 6a1e5592), 互补拼合(complement_fit, 6a1e5592), 地形轮廓(terrain_contour, e45ef808), 精灵体(sprite, 6a1e5592/20270e3b), 对接拼合(docking, 20270e3b), 拼块填孔洞后变色(pieces_fill_holes_recolor, 6a1e5592), 重涂色(recolor, 多源)

**依赖链**：地形轮廓分析识别谷地位置和形状 → 谷地宽度与精灵体裁剪后的宽度匹配决定放置关系 → 谷底高度决定精灵体的垂直放置位置 → 放置后精灵体统一变色标记已嵌入。删除地形分析则无法确定"孔洞"位置；删除形状匹配则无法决定哪个精灵体放入哪个谷地；删除变色则无法区分已放置和未放置的精灵体。

将散布在地形上方的精灵体按宽度匹配嵌入地形谷地中，嵌入后统一变色。

**输入结构**：黑(0)背景网格，约 16x14。底部区域（约下方 6~8 行）为绿(3)地形轮廓：每列从底边向上有连续的绿(3)像素，不同列高度不同，形成 2~3 个明显的谷地（连续多列地形表面低于两端相邻列的区域）。每个谷地的宽度（水平跨度，列数）互不相同（如分别为 2 列、3 列、4 列）。地形上方散布 2~3 个单色精灵体（每个精灵体使用不同的非背景非绿色，如红(2)、蓝(1)、黄(4)），每个为 3~7 像素的不规则 4-连通图形。精灵体数量等于谷地数量。精灵体之间互不接触，与地形也不接触（间隔至少 1 行）。生成约束：每个精灵体裁剪后的边界框宽度恰好等于某个谷地的宽度（一一对应，无歧义）；每个精灵体裁剪后的边界框高度不超过对应谷地的深度（谷地深度 = 谷地两端较低邻列的表面行号 - 谷底表面行号）。

**规则**：
1. 识别地形表面：对每列，最高的绿(3)像素的行号即为表面行号（行号越小，表面越高）。
2. 识别谷地：一个谷地是一段连续列范围 [c_left, c_right]，满足：(a) 范围内每列的表面行号都严格大于 c_left-1 列和 c_right+1 列的表面行号（即范围内地形比两端低）；(b) 范围是满足此条件的最大连续列段。谷地的宽度 = c_right - c_left + 1。谷地的谷底行 = 范围内表面行号的最大值（最低处）。谷地的深度 = 谷底行 - min(c_left-1 列表面行, c_right+1 列表面行)。
3. 裁剪每个精灵体至其边界框。
4. 匹配：对每个精灵体，找到边界框宽度等于该精灵体宽度的唯一谷地。
5. 放置：将精灵体放入匹配的谷地中——水平方向：精灵体边界框的最左列对齐谷地的 c_left 列。垂直方向：精灵体边界框的最底行对齐谷底行（使精灵体"坐"在谷底上）。若精灵体的某些像素与绿(3)地形像素重叠，精灵体像素覆盖地形像素。
6. 放置完成后，将所有已放置精灵体的像素统一重涂为品红(6)。
7. 擦除原始位置上的精灵体（涂为黑(0)）。
8. 无法匹配的精灵体（生成约束排除此情况）保持原位和原色。

**关键洞察**：源题 6a1e5592 的孔洞是 2D 对象中的平面缺口，精灵体以完整的 2D 形状嵌合。本题将"孔洞"概念转移到地形凹陷——一种 1.5D 的空间结构，匹配条件也从完整形状变为宽度优先（高度只需不超限即可）。放置位置由地形几何（谷底行号）而非孔洞坐标决定，使得嵌合逻辑与地形分析紧密耦合。需要对比多个示例确认匹配标准是宽度而非其他属性（如面积或高度）。
