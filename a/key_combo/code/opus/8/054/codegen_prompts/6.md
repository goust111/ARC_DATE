## 新题 6：双轴反射地形的极值列射线

**组合逻辑**：[镜像+平铺](已有) → [地形极值分析](已有操作，但作用于反射拼合后的复合地形而非原始地形，极值位置因对称性可能发生迁移) → [射线延伸](已有操作，但起点由复合地形中的标记像素经镜像复制后的位置决定，射线方向由所在半平面决定)

**来源原语**：镜像(mirror, 67e8384a), 平铺(tiling, 67e8384a), 象限排布(quadrant_layout, 67e8384a), 双轴反射(biaxial_reflection, 67e8384a), 地形轮廓(terrain_contour, e45ef808), 列高度极值(column_height_extreme, e45ef808), 最深与最浅列唯一(unique_deep_shallow, e45ef808), 射线延伸(ray_extend, f1cefba8), 标记像素(marker_pixel, 40853293)

**依赖链**：输入瓦片镜像平铺 → 复合地形的列高度分布与原瓦片不同（对称创造了新的极值候选）→ 极值分析在复合地形上产生与原瓦片不同的结果 → 标记像素在四个象限中各有一份镜像副本，射线方向由所在象限决定。删除平铺则无复合地形，极值退化为原瓦片的极值；删除极值分析则标记像素的射线缺少颜色区分；删除射线则极值分析无可视化输出。

将小地形瓦片双轴反射拼成四象限复合地形，找到复合地形中地表最深与最浅的列并标注颜色，从标记像素处向最近的水平边缘发射射线。

**输入结构**：黑(0)背景网格，约 8x7（较小，用于拼合后不超过 16x14）。第 0 行为灰(5)分隔行。第 1 行到最后一行为地形区域：每列从底边向上有连续的绿(3)地形像素，不同列高度不同（高度范围 2~6），形成不规则的地形表面。地形表面具有不对称性（左半部分和右半部分的高度分布不同，保证拼合后极值位置可能变化）。地形表面上有 2 个红(2)标记像素，分别嵌入不同列的表面顶部（即该列最高的绿(3)像素被替换为红(2)）。生成约束：原瓦片中地形表面最深列和最浅列各唯一；双轴反射拼合后，由于反射对称，复合地形中可能出现多列并列最浅的情况——此时选最右列，但最深列在拼合后仍唯一（通过让原瓦片的最深列不在瓦片的对称轴上来保证）。

**规则**：
1. 以输入网格为瓦片，创建 2x2 双轴反射拼合：左上为原图，右上为左右镜像，下半部分为上半部分的上下镜像。输出网格尺寸为 2H x 2W。
2. 在复合网格中重新计算地形表面：对每列，找到最高的绿(3)或红(2)像素（红(2)标记像素也视为地形的一部分），该像素的行号即为该列的表面行。
3. 找到复合地形中表面行号最大的列（地形最深处，即表面最低）。若有多列并列，选最左列。将该列从灰(5)分隔行（第 0 行和通过镜像产生的中间分隔行）到表面之间的所有黑(0)像素涂为橙(7)。
4. 找到复合地形中表面行号最小的列（地形最浅处，即表面最高）。若有多列并列，选最右列。将该列从分隔行到表面之间的所有黑(0)像素涂为黄(4)。
5. 对复合网格中每个红(2)标记像素：判断它位于上半部分还是下半部分。若在上半部分（行号 < H），从该像素向上发射射线直到第 0 行（不含第 0 行），射线颜色为红(2)。若在下半部分（行号 >= H），从该像素向下发射射线直到最后一行（含最后一行），射线颜色为红(2)。射线覆盖路径上的黑(0)像素，不覆盖已有的绿(3)、灰(5)、橙(7)、黄(4)像素。
6. 保持所有原有的地形像素、分隔行像素和标记像素不变。

**关键洞察**：双轴反射在源题中是对任意图案的纯几何操作，这里应用于地形后产生了涌现效应——反射对称可能使原本不在极值位置的列成为新的极值列，因为拼合创造了新的列高度对比关系。这种"对称操作改变统计极值"的效应在任何源题中都不存在。需要对比多个示例才能确认极值分析是在拼合后的复合地形上进行、而非在原瓦片上进行后复制。
