## 新题 2：地形表面射线的障碍偏转生长

**组合逻辑**：[地形轮廓分析](已有) → [射线延伸](已有操作，但起点由地形表面高度决定而非矩形边缘突起) → [障碍偏转生长](创新：射线在遇到障碍时横向偏移后继续，将路径生长的偏转逻辑嫁接到射线延伸上) → [极值列高亮](已有条件，但作用于射线颜色而非填充区域)

**来源原语**：射线延伸(ray_extend, f1cefba8), 地形轮廓(terrain_contour, e45ef808), 列高度极值(column_height_extreme, e45ef808), 生长(grow, d9f24cd1), 障碍像素(blocker_pixel, d9f24cd1), 遇障碍则绕行(detour_on_obstacle, d9f24cd1), 标记像素(marker_pixel, 40853293)

**依赖链**：地形轮廓确定每列的表面高度 → 标记像素在表面上的位置决定射线起点的行坐标（不同于源题中从固定边缘出发）→ 障碍像素迫使射线横向偏移（不同于源题中简单直线延伸）→ 极值列分析选出特殊列并改变其射线颜色（将地形分析的结果反馈到射线的视觉属性上）。删除地形则无法确定起点高度；删除偏转则射线被障碍截断失去意义；删除极值高亮则丢失地形深度与射线颜色的耦合。

从地形表面的标记点向上发射射线，射线遇到障碍横向偏转后继续上行，地形最深列的射线以特殊颜色标记。

**输入结构**：黑(0)背景网格，约 16x16。底部区域（约下方 5~8 行）为绿(3)地形轮廓：每列从底边向上有连续的绿(3)像素，不同列高度不同，形成参差的地形表面（最顶部的绿(3)像素即为该列的表面）。地形表面的若干列（3~5 列）上，表面正上方一格处有一个蓝(1)标记像素（即该列表面绿(3)像素上方紧邻的那个像素为蓝(1)）。地形上方的区域中散布若干灰(5)障碍像素（每个为单独的 1x1 像素，互不相邻，不在网格最顶行也不在最左/最右列），数量约 5~10 个。生成约束：每个蓝(1)标记像素所在列的地形表面高度互不相同（保证极值列唯一）；障碍像素不在任何标记像素正上方的同一列中连续出现两个（保证偏转后总能继续上行）；标记像素之间的列间距 >= 3（保证偏转不会导致射线合并）。

**规则**：
1. 识别地形表面：对每列，找到最高的（行号最小的）绿(3)像素，该行即为该列的表面行。
2. 识别标记像素：蓝(1)像素，每个位于某列地形表面正上方一格处。
3. 对每个标记像素发射射线：从标记像素所在位置开始，逐步向上生长（行号递减）。每步尝试向上移动一格：
   - 若上方一格为黑(0)背景或已有射线像素，则移动到该格并涂为蓝(1)。
   - 若上方一格为灰(5)障碍，则改为向右移动一格（列号加 1）并涂为蓝(1)，下一步继续尝试向上。
   - 若向右也超出网格边界，则射线停止。
   - 射线到达第 0 行时停止。
4. 确定极值列：在所有具有标记像素的列中，找到地形表面行号最大的列（地形最深处，即表面最低的列）。
5. 将该极值列的整条射线（包括标记像素和所有生长出的像素）重涂为黄(4)。
6. 处理顺序：按标记像素的列号从左到右依次生长射线。若一条射线偏转后进入了另一条射线将要经过的列，后处理的射线在该格遇到已有射线像素时视同障碍、继续向右偏转。

**关键洞察**：射线的起始高度不再是固定边缘，而是由地形轮廓的局部高度决定——同一组射线因地形参差而从不同行出发。障碍偏转使得射线路径不再是直线，而极值列的颜色替换将地形的全局统计属性注入到了射线的局部视觉表达中。需要对比多个示例才能发现射线处理顺序（左到右）对偏转冲突的影响。
