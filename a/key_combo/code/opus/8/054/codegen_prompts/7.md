## 新题 7：叶状突起选定面板的内容互换

**组合逻辑**：[叶状突起识别+行列选定](已有操作，但选定目标从矩形内的行列变为面板网格中的面板行/面板列) → [面板交换+图案掩码重涂色](已有操作，但不再对所有面板统一交换，而由叶状标记选择性触发) → [顺序依赖](创新：先执行列选定的交换、再执行行选定的交换，导致某些面板被交换两次，最终内容取决于执行顺序)

**来源原语**：叶状突起(leaf_protrusion, f1cefba8), 突起定行列(leaf_selects_row_col, f1cefba8), 交换(swap, 5a719d11), 分隔面板(separated_panel, 5a719d11), 图案掩码(motif_mask, 5a719d11), 成对交换(pairwise_exchange, 5a719d11), 底色作为涂色源(base_color_source, 5a719d11), 重涂色(recolor, 多源)

**依赖链**：叶状突起的方向判定 → 选定面板行或面板列 → 选定列中上下面板交换内容 → 选定行中左右相邻面板交换内容 → 交换顺序（先列后行）影响被两次选中的面板的最终结果。删除叶状突起则无法确定哪些面板参与交换（退化为全部交换或不交换）；删除交换机制则叶状突起的选定结果无用途；删除顺序规则则双重选定的面板结果不确定。

叶状突起标记选定哪些面板行和面板列参与内容互换，先交换选定列中的上下面板、再交换选定行中的相邻面板，被两次选中的面板获得双重交换效果。

**输入结构**：黑(0)背景网格，约 15x17。灰(5)分隔行和分隔列将网格划分为 2 行 x 3 列共 6 个矩形面板（每个面板约 5x4 像素）。每个面板有一种底色（从蓝(1)、红(2)、绿(3)、黄(4)、品红(6)、橙(7)中各取一种，6 个面板底色互不相同）和一种少数色组成的图案掩码（图案由该面板底色之外的某种颜色构成，约占面板面积的 20%~35%，为不规则的 4-连通小图形，不同面板的图案形状不同）。在某些面板的外边框处（即面板与灰(5)分隔区域的交界），有叶状突起：面板图案掩码颜色的单个像素伸入灰(5)分隔区域中，该像素在分隔区域中的唯一同色邻居指回面板内部。约有 2~3 个叶状突起，分布在不同面板上。生成约束：叶状突起的行列选定不产生冲突（即不会有同一面板列被两个不同叶状突起同时选中）；至少一个面板同时位于某个被选定的面板行和某个被选定的面板列中（保证双重交换发生）。

**规则**：
1. 识别叶状突起：在灰(5)分隔区域中找到非灰非黑像素，其在分隔区域中仅有一个同色邻居且该邻居位于某面板内部。
2. 判断叶状突起选定行还是列：若该突起的唯一同色邻居在其上方或下方（即突起从面板的左边或右边伸出），则选定该面板所在的面板行。若邻居在其左方或右方（即突起从面板的上边或下边伸出），则选定该面板所在的面板列。
3. 第一轮交换（列交换）：对每个被选定的面板列，交换该列中上方面板和下方面板的图案掩码。交换方式：提取上方面板的图案掩码形状 M_top 和下方面板的图案掩码形状 M_bot。将 M_bot 粘贴到上方面板中，涂为上方面板的底色。将 M_top 粘贴到下方面板中，涂为下方面板的底色。先将两面板各自清除为纯底色，再粘贴对方的掩码形状。
4. 第二轮交换（行交换）：对每个被选定的面板行，将该行中的面板从左到右两两配对交换（第 1 和第 2 面板交换，若有第 3 面板则不交换、保持当前状态）。交换方式同上：提取当前状态下的图案掩码形状，清除为底色后粘贴对方掩码并涂为接收面板底色。
5. 未被任何叶状突起选中行或列的面板保持原始状态不变。
6. 叶状突起像素本身保留在输出中（不擦除）。

**关键洞察**：叶状突起在源题 f1cefba8 中选定行列用于对矩形内部进行直线切割和重涂，本题中它们选定面板级别的行列来触发面板间内容交换——选定机制和交换机制来自不同源题，在本题中形成了"选定→交换"的新结构关系。更关键的是先列后行的执行顺序使得处于交叉位置的面板经历两次交换，其最终内容不是简单的"交换后的结果"而是"交换的交换"——这需要对比含有交叉选定和不含交叉选定的示例才能归纳出来。
