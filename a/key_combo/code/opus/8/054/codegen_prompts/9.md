## 新题 9：象限导向对角射线的端点模板印章

**组合逻辑**：[象限方向推断](已有) → [射线延伸](已有操作，但射线不再是终态而是中间步骤，射线端点成为后续操作的定位参数) → [模板提取+印章覆盖](已有操作，但印章位置不再由框架尺寸匹配决定，而由射线端点的几何坐标决定) → [擦除](已有，清除方向指示像素和原始模板)

**来源原语**：象限指示方向(quadrant_indicates_dir, 252143c9), 同色像素定角(same_color_corner, 252143c9), 中心像素(center_pixel, 252143c9), 射线延伸(ray_extend, f1cefba8/252143c9), 模板提取(template_extraction, 79369cc6), 印章覆盖(stamp_overlay, f21745ec), 擦除(erase, f21745ec/252143c9), 尺寸匹配(size_match, f21745ec)

**依赖链**：散布的同色像素所在象限 → 确定对角射线方向 → 射线端点（网格边角处）坐标 → 模板印章以端点为锚点粘贴 → 印章重涂为射线颜色。删除象限推断则射线方向不确定；删除射线则印章位置不确定；删除模板提取则无印章内容；三者形成信息链。

从中心像素向同色散布像素所指象限发射对角射线，在射线到达网格边缘的端点处印上从网格角落提取的模板图案。

**输入结构**：黑(0)背景网格，奇数正方形，约 13x13 或 15x15。网格正中心有一个绿(3)像素。另有 3~5 个绿(3)像素散布在中心的同一个对角象限中（例如全部在中心的右下方，即行号 > 中心行且列号 > 中心列）。网格的某个角落（如左上角）有一个小矩形模板（约 3x3 至 4x4），由蓝(1)和红(2)两种颜色构成不对称图案（如蓝(1)为边框、红(2)为内部花纹，花纹不关于任何轴对称）。模板与中心像素和散布像素不重叠。生成约束：散布的绿(3)像素全部严格位于中心的同一个对角象限中（不在轴上）；模板所在角落与散布像素所在象限不同（即模板不在射线路径上）；模板边界框尺寸足够小，印章放置在边角附近时不会超出网格边界太多（允许少量裁剪）。

**规则**：
1. 找到网格中心像素（行列均为 (H-1)/2 的位置），确认为绿(3)。
2. 收集所有非中心的绿(3)像素，判断它们所在的对角象限：全部在中心的右下方则方向为 (+1,+1)，左下方为 (+1,-1)，右上方为 (-1,+1)，左上方为 (-1,-1)。
3. 从中心像素沿确定的对角方向逐步延伸（每步行号和列号各加方向增量），将路径上的每个像素涂为绿(3)，直到行或列到达网格边缘（行号为 0 或 H-1，列号为 0 或 W-1）。射线的最后一个像素为端点。
4. 提取模板：找到网格中由蓝(1)和红(2)组成的连通区域，裁剪为其边界框，得到模板图案。
5. 将模板图案以射线端点为锚点印章到网格上。锚点对齐方式：端点对齐模板的中心像素（模板边界框中心，向下取整）。若印章的某些像素超出网格边界，超出部分丢弃。
6. 印章中的蓝(1)像素重涂为绿(3)（与射线同色）；红(2)像素保持红(2)不变。
7. 擦除所有散布的绿(3)指示像素（即非中心、非射线路径上的原始绿(3)像素，涂为黑(0)）。实际操作中，由于射线路径覆盖了从中心到边缘的对角线，散布像素若恰好在射线路径上则已被射线覆盖，不在路径上的散布像素则被擦除。
8. 擦除原始模板区域（将模板原位置的蓝(1)和红(2)像素涂为黑(0)）。

**关键洞察**：源题 252143c9 中射线是最终输出——画完射线就结束了。本题中射线是中间产物，其端点坐标成为印章操作的定位输入，射线充当了"计算印章位置"的几何工具。源题 f21745ec 中印章位置由框架尺寸匹配决定（静态匹配），本题中印章位置由射线动态计算得到（运行时确定）。两种原本独立的定位机制（象限选方向、尺寸选位置）被替换为串联关系（象限选方向 → 方向定射线 → 射线定位置），构成了源题中不存在的"几何传递链"。需要对比多个示例才能确认印章的锚点对齐方式（模板中心对齐端点）以及颜色重涂规则（蓝变绿、红不变）。
