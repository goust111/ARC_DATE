## 新题 4：降采样障碍图上的路径生长

**组合逻辑**：[降采样](已有操作，但产物不再是裁剪掩码而是可导航的障碍地图) → [寻路+生长](已有操作，但障碍不再是显式放置的像素而是通过尺度变换推导出的) → [擦除](已有，清除原始大图案)

**来源原语**：降采样(downsample, 6ecd11f4), 整数缩放对应(int_scale_correspond, 6ecd11f4), 单色图案(mono_pattern, 6ecd11f4), 寻路(pathfinding, d9f24cd1), 生长(grow, d9f24cd1), 起点像素(start_pixel, d9f24cd1), 遇障碍则绕行(detour_on_obstacle, d9f24cd1), 擦除(erase, 252143c9)

**依赖链**：大图案的降采样产生小障碍图 → 障碍图的空间结构决定路径可通行区域 → 起点像素在障碍图坐标下的位置决定路径起始 → 路径在障碍图上生长并偏转。删除降采样则不知道哪些格子是障碍；删除路径生长则降采样产物无用途；两者通过尺度变换紧密耦合。

将大尺度单色图案降采样为小障碍网格，从边缘起点出发在障碍网格上向右生长路径，遇障碍向下偏转。

**输入结构**：黑(0)背景网格，约 18x18。网格左上区域有一个大的蓝(1)单色图案，占据约 12x12 至 15x15 的范围，由蓝(1)和黑(0)组成，是一个小型二值网格（4x4 至 6x6）按整数倍（3 倍或 4 倍）放大得到的。即每个小格子对应大图案中一个 kxk 的块，全蓝块表示障碍，全黑块表示通行。网格右下角有一个小区域（与降采样后的障碍图同尺寸，如 5x5），其左边缘（第 0 列）上有 2~3 个起点像素，颜色各不相同（如红(2)、绿(3)、黄(4)），其余为黑(0)。生成约束：大图案的每个 kxk 块要么全蓝要么全黑（保证降采样无歧义）；降采样后的障碍图中，每行至少有一个通行格（保证路径不会完全被堵死）；起点像素所在行在障碍图中的对应格为通行格。

**规则**：
1. 分离大蓝(1)图案和小区域（小区域通过包含非蓝非黑像素来识别，或通过位置识别为右下角独立区域）。
2. 确定缩放因子 k：大图案边界框的宽度除以小区域的宽度（均为整数）。
3. 降采样：将大图案划分为 kxk 的块，每块若全部为蓝(1)则记为障碍(1)，否则记为通行(0)，得到与小区域同尺寸的障碍图。
4. 将小区域作为输出基底（初始为全黑(0)）。
5. 对每个起点像素（按其在小区域中的行号从上到下处理），从该像素位置开始向右生长路径：
   - 每步尝试向右移动一列（列号加 1）。
   - 若右方格在障碍图中为通行(0)且无已有路径像素，则移动并涂为该起点的颜色。
   - 若右方格为障碍(1)或已有其他路径像素，则改为向下移动一行（行号加 1）并涂色，下一步继续尝试向右。
   - 若向下也超出网格边界或为障碍，则路径停止。
   - 到达最右列时路径停止。
6. 擦除大蓝图案区域（全部涂黑(0)），输出仅包含小区域部分（即障碍图尺寸的网格，含路径）。

**关键洞察**：降采样在源题中生成裁剪用的二值掩码，本题中它生成路径导航用的障碍地图——同一个操作的产物在完全不同的下游逻辑中扮演关键角色。路径生长在源题中使用显式散布的障碍像素，本题中障碍结构是从大图案中通过尺度变换推导出的隐含信息。需要对比多个示例才能发现缩放因子的确定方法以及偏转方向（向下而非源题中的向右）。
