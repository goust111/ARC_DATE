## 新题 3：形状归一化分组与组内连线

**组合逻辑**：[平移归一化+形状分组](已有操作的创新应用：归一化后发现分组，而非已知分组后重涂色) → [重涂色](已有) → [连线](已有操作，但端点不再预设而是由分组结果动态确定) → [交叉优先级](创新：优先级不再由线段方向决定，而由分组成员数决定)

**来源原语**：形状相同(same_shape, ad38a9d0), 平移归一化(translate_normalize, ad38a9d0), 重涂色(recolor, ad38a9d0), 连线(draw_line, 40853293), 同色配对(same_color_pairing, 40853293), 行列对齐(row_col_align, 40853293), 竖线交叉优先(vertical_priority_at_cross, 40853293), 忽略干扰项(ignore_distractors, b1986d4b)

**依赖链**：平移归一化发现同形对象组 → 组的成员数决定涂色优先级和连线交叉优先级 → 连线端点由同组对象的位置决定（非预定义）→ 交叉点颜色由成员数多的组优先。删除归一化则无法分组；删除连线则只剩简单涂色（退化为源题 ad38a9d0）；删除交叉规则则多组连线的重叠无法解决。

将形状相同的占位符对象归为一组并涂色，组内对象两两连线，线段交叉处成员多的组颜色优先。

**输入结构**：黑(0)背景网格，约 17x17。网格中散布 8~12 个小型 4-连通单色对象，全部使用灰(5)作为占位符颜色，每个对象由 3~6 个像素组成，形状不规则（非简单矩形）。这些对象可分为 3~4 组，每组 2~4 个成员共享相同的平移归一化形状，各组形状互不相同。另有 1~2 个对象的归一化形状独一无二（不属于任何组），这些是干扰项。对象之间互不相邻（任意两个对象的边界框间至少隔 2 格）。同组内至少有一对对象的边界框中心共享行或列（保证存在非对角线连线）。生成约束：各组成员数互不相同（如分别为 2、3、4 个成员），保证成员数可作为唯一的优先级排序依据。

**规则**：
1. 裁剪每个灰(5)对象至其边界框，将边界框左上角平移至原点，得到归一化掩码。
2. 将归一化掩码相同的对象归为一组。仅含一个成员的"组"视为干扰项，保持灰(5)不变，不参与后续连线。
3. 为每个有效组分配颜色：按组成员数从大到小依次分配红(2)、蓝(1)、绿(3)、黄(4)。若成员数相同（生成约束排除此情况，但作为边界处理），以组内最靠左上的成员的边界框左上角阅读序在先者获得更早的颜色。
4. 将每组的所有成员对象重涂为该组的颜色。
5. 对每组内的所有成员，两两之间画连线：取两个对象各自边界框中心（行列坐标均取边界框行范围和列范围的算术平均值，向下取整），画一条从一个中心到另一个中心的折线——先水平段（从起点列到终点列，行不变），再垂直段（从起点行到终点行，列不变），使用该组颜色。若两中心同行则只画水平段，同列则只画垂直段。每对连线中，以边界框中心阅读序靠前的为起点。
6. 当不同组的连线经过同一像素时，成员数更多的组的颜色覆盖成员数少的组的颜色。
7. 连线覆盖背景像素和其他组的连线像素，但不覆盖任何对象本体像素（对象像素始终保留）。

**关键洞察**：在源题中，同色配对的端点由颜色直接给出；在本题中，"哪些对象是一对"必须通过形状归一化来发现，分组结果同时决定涂色方案和连线拓扑。交叉优先级由组的人口统计属性（成员数）决定，而非线段的几何方向——这是一种从源题不存在的"分组大小→绘图优先级"映射关系。需要对比多个示例确认干扰项的判定标准（唯一形状）以及交叉优先级的依据（成员数而非颜色编号）。

3. 生成器必须保证输入满足 `main()` 的隐式假设：对象不重叠、不越界、特殊标记唯一或可区分、匹配关系无歧义、关键分支出现概率相同。
4. 禁止把 ARC 颜色 id 、亮度、拼写等当作人类不可见的数值语义参与排序、大小比较或隐藏映射。颜色变化必须有可见结构线索。注意颜色亮度、拼写等也是不可见信息，若描述中出现违规的颜色id或者亮度，可自行使用少量的固定颜色替代，但注意生成时要在三个以内输入输出网格中对所有变换100%覆盖度。
5. 输出样例要视觉清晰，人类必须能从输入输出对中肉眼辨认出规律。具体要求：避免对象粘连、覆盖关系混乱、同一像素多重语义；不同逻辑步骤产生的结果不要大面积层叠在一起导致无法分辨哪个颜色属于哪个步骤；输入中各元素之间保持足够间距，输出中新增的标记/填充/路径等应与背景和已有元素在颜色上有明显区分；若规则涉及多层叠加，生成时控制对象密度和尺寸，确保叠加区域只占少数像素而非铺满整个网格。
6. 若规则有多个分支，生成器不能长期固定成一个分支；应让分支在随机样例中合理出现。分支概率不必平均——难以发现的隐蔽分支（如少数情况下才触发的特殊规则）应适当提高出现概率，确保在 3 个训练示例中至少出现一次，否则求解者无法归纳该规则。对于颜色映射类规则，确保 2 个左右的示例即可覆盖所有映射关系（每种颜色→颜色的映射至少在某个示例中出现过）。
