## 新题 7：控制像素侧计数生成水平条模板后逐槽位旋转

**组合逻辑**：[填充/fill] + [两侧计数决定长度/side_counts_length]（创新：生成的色条不是最终输出，而是作为旋转模板的输入） → [旋转/rotate] + [逐槽位累计旋转/successive_rotation_per_slot]（创新：模板不是预给的静态图案，而是由计数规则动态生成的）

**来源原语**：填充/fill、控制像素/control_pixel、计数像素/counter_pixel、同行对齐/same_row_aligned、两侧计数决定长度/side_counts_length（2a28add5）；旋转/rotate、逐槽位累计旋转/successive_rotation_per_slot、模板/template、槽位/slot、分隔线/divider_line、顺序排列/sequential_order（8e5a5113）

**依赖链**：控制像素行中的计数像素决定水平色条的长度，色条构成的模板图案依赖计数结果。模板图案随后在多个槽位中逐次旋转。计数规则不可省（没有它就无法生成模板），旋转不可省（单个模板不是完整输出），两者通过模板图案紧密耦合。

在第一个槽位中用行内计数规则动态生成水平色条模板，然后将该模板逐槽位顺时针旋转 90 度填充后续槽位。

**输入结构**：约 7x25 的网格。灰(5)垂直分隔线将网格分为 4 个等宽等高的正方形槽位（每个约 7x7，含分隔线后总宽约 25）。第一个槽位内包含：背景黑(0)，2-3 个品红(6)控制像素分布在不同行上，每行恰有一个品红像素；每个品红像素所在行还有若干散布的非黑、非品红的前景像素（颜色任意，作为计数像素）。其余 3 个槽位为空（全黑(0)）。生成约束：第一个槽位为正方形；每个控制像素所在行的左侧计数和右侧计数均不超过槽位宽度的一半（确保生成的色条不超出槽位边界）。

**规则**：
1. 从一个全黑的与第一槽位同尺寸的画布开始生成模板。
2. 对第一个槽位中的每个品红(6)控制像素：统计其所在行中严格在其左侧的非黑非品红像素数量 L，以及严格在其右侧的非黑非品红像素数量 R。在模板画布的同一行上，从列 (c - L) 到列 (c + R) 绘制青(8)水平色条（c 为控制像素的列位置）。
3. 将生成的模板放入第一个槽位。
4. 第 2 个槽位放入模板顺时针旋转 90 度的版本，第 3 个槽位放入旋转 180 度的版本，第 4 个槽位放入旋转 270 度的版本。
5. 灰(5)分隔线保持不变。原始的品红控制像素和计数像素不出现在输出中——它们仅用于编码模板。

**关键洞察**：控制像素和计数像素在输出中消失，它们唯一的作用是编码模板的几何形状；求解者必须先通过计数规则重建模板，才能理解后续槽位中旋转图案的来源。
