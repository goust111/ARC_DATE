## 新题 6：双色行列乘积提取后按长轴扫描序循环重涂色

**组合逻辑**：[提取/extract] + [行列乘积完整/row_col_product]（创新：提取不是终点，提取结果的几何属性决定后续重涂色的扫描方向） → [重涂色/recolor] + [颜色循环分配/cyclic_color_assignment] + [长轴决定扫描/longer_axis_determines_scan]

**来源原语**：提取/extract、双色图像/bicolor_image、行列乘积完整/row_col_product（b71a7747）；重涂色/recolor、颜色循环分配/cyclic_color_assignment、长轴决定扫描/longer_axis_determines_scan、扫描序/scan_order、孤立像素/isolated_pixel（9473c6fb）

**依赖链**：提取步骤从噪声网格中识别并压缩出隐藏的双色图像。提取后的子网格尺寸决定长轴方向（行优先还是列优先），进而决定前景像素的扫描顺序。扫描顺序决定循环颜色分配。跳过提取则无法确定子网格尺寸和扫描方向；跳过扫描序分析则无法确定重涂色顺序。

从噪声网格中提取隐藏的双色行列乘积图像，再根据提取后子网格的长轴方向确定扫描序，对前景像素循环分配新颜色。

**输入结构**：约 10x10 的网格。网格中有 4-5 种颜色。其中恰好一对颜色（设为蓝(1)和红(2)）的像素分布满足行列乘积性质：它们占据的行集合 R 和列集合 C 的笛卡尔积 R x C 中的每个位置恰好被蓝(1)或红(2)占据（无黑色空洞）。其他颜色（绿(3)、黄(4)、灰(5)等）构成填充物和分隔符，分布在 R x C 之外或与 R x C 无关的行列上。隐藏图像的行数和列数不相等（确保长轴方向唯一确定）。在隐藏的双色图像中，两种颜色中像素数较少的那种视为"前景"，较多的视为"底色"。前景像素数至少为 4 个。

**规则**：
1. 找到唯一的颜色对，使其像素恰好填满某行集 R 和列集 C 的笛卡尔积 R x C。
2. 仅保留 R 中的行和 C 中的列，提取出紧凑子网格（行和列按原始顺序保持）。
3. 在提取的子网格中，统计两种颜色的像素数，像素数少的为前景色，多的为底色。
4. 若子网格行数 >= 列数，则前景像素按行优先（从上到下、同行从左到右）排序；否则按列优先（从左到右、同列从上到下）排序。
5. 按排序顺序，将前景像素依次重涂为红(2)、青(8)、灰(5)、红(2)、青(8)、灰(5)... 循环分配。底色像素保持原色不变。
6. 输出为重涂色后的子网格。

**关键洞察**：提取步骤产出的子网格形状不仅是"内容"，其宽高比还决定了重涂色的扫描方向——这个几何属性只有在提取完成后才可知，不能提前判断。
