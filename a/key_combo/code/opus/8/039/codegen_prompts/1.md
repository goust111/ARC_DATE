## 新题 1：折叠拼合恢复周期壁纸

**组合逻辑**：[折叠/fold] + [透明叠加/transparent_overlay]（创新：叠加目的不是合并互补图案，而是拼凑足够的周期信息） → [周期推断/periodic_inference] + [间隙填充/gap_filling]（创新：推断依赖折叠后的合并数据，单侧数据不足以唯一确定瓦片）

**来源原语**：折叠/fold、透明叠加/transparent_overlay（e3497940）；周期推断/periodic_inference、间隙填充/gap_filling（1d0a4b61）；忽略缺失值推断/ignore_missing_to_infer（1d0a4b61）；分隔线/separator_line（e3497940）

**依赖链**：单独看上半区或下半区，黑色缺失位置太多，无法唯一确定最小周期瓦片。折叠操作将两个互补的不完整视图合并到同一坐标系中，暴露出足够的非黑像素，使周期推断变为唯一可解。推断出的瓦片再回填所有剩余黑洞。折叠不可省（信息不够），周期推断不可省（折叠后仍有黑洞），两者紧耦合。

将分隔线两侧各自不完整的同一周期壁纸折叠合并后，利用增补的可见像素推断最小瓦片并填满所有缺口。

**输入结构**：约 15x7 的网格。背景为黑(0)。一条贯穿全宽的灰(5)水平分隔线将网格分成高度相等的上下两个面板（各约 7x7 去掉分隔行后约 3 行高，具体高度视瓦片而定；也可为 11x7 等使每半区约 5x7）。上半区和下半区底层共享同一个最小周期瓦片（瓦片尺寸约 2x2 至 3x3，使用红(2)、蓝(1)、绿(3)等 2-3 种颜色），但各自有不同位置的像素被替换为黑(0)。上半区约 40%-60% 的像素可见（非黑），下半区同样约 40%-60% 可见，且两侧缺失位置互补——上半区黑的位置在下半区大多可见，反之亦然。生成约束：单独任一半区的可见像素不能唯一确定最小瓦片（至少有一个瓦片相位在该半区完全缺失），但两半合并后每个瓦片相位至少出现一次。

**规则**：
1. 移除灰(5)分隔行。
2. 将下半区垂直翻转（上下镜像），然后与上半区逐像素叠加到同一坐标系：对于每个位置 (r, c)，若上半区为非黑则取上半区颜色，否则取翻转后下半区颜色；若双方均为非黑，它们的颜色必然一致（生成时保证）。
3. 将叠加后仍为黑的像素视为缺失数据，对所有非黑像素执行最小周期瓦片推断，找到唯一的最小面积瓦片使其行列周期与所有非黑像素一致。
4. 用推断出的瓦片填充所有剩余黑像素，输出完整的无黑洞面板（尺寸等于单个半区）。

**关键洞察**：分隔线两侧不是对称互补的图案，而是同一周期壁纸的两份不完整采样；折叠不是为了重建对称结构，而是为了跨越信息门槛让周期推断成为可能。
