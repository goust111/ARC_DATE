## 新题 8：镜像与周期平铺的同时约束求解

**组合逻辑**：[镜像](创新：不是执行镜像操作，而是"输出必须满足镜像对称"作为约束) ⊗ [平铺](创新：不是执行平铺操作，而是"输出必须满足周期重复"作为约束) + [填充](已有：用满足双重约束的唯一颜色填入空白格)

**来源原语**：镜像·对称(c35c1b4c), 平铺·周期(963e52fc), 填充(e88171ec), 对称轨道(f9d67f8b), 周期图案(963e52fc), 宽度加倍延续周期(963e52fc)

**依赖链**：同时满足两个约束而非顺序执行两个操作 → 水平周期性决定了某些像素必须与周期偏移处同色 → 垂直对称性决定了某些像素必须与垂直镜像处同色 → 两个约束的传递闭包唯一确定每个空白格的颜色

输入网格局部给出了少量彩色像素和大量空白（黑色）格；输出中每个空白格必须同时满足水平周期约束和垂直对称约束，且所有约束的联合使得每个空白格的颜色唯一确定。

**输入结构**：约 12x10 网格（宽 > 高），黑(0)背景。网格中散布 8~15 个非黑前景像素（使用蓝(1)、红(2)、绿(3)、黄(4)中的 2~3 种颜色），其余为黑(0)。网格宽度 W 可被某个周期 p 整除（p 为 3 或 4），即 W = k * p（k >= 2）。网格具有一条垂直对称轴，位于网格水平中线（列索引 (W-1)/2 处，W 为奇数时恰好居中；W 为偶数时轴在两列之间）。前景像素的分布满足：对任意前景像素位于 (r, c)，位置 (r, c mod p) 定义了"周期等价类"，(r, W-1-c) 定义了"对称等价类"；在两种等价关系的传递闭包下，每个等价类内至少有一个前景像素提供颜色约束，且类内所有前景像素同色（无矛盾）。生成约束：前景像素的数量足以使每个空白格的颜色被唯一确定；前景像素之间无颜色矛盾。

**规则**：
1. 确定水平周期 p：p 是满足以下条件的最小正整数——对所有非黑像素 (r, c)，若 (r, c+p) 在网格内且非黑，则两者同色。
2. 确定垂直对称轴位于列 (W-1)/2 处（W 为网格宽度）。
3. 对每个黑(0)位置 (r, c)，沿周期方向寻找同周期等价类（列号 c, c+p, c-p, c+2p, ...，均取模后在 [0, W) 内的位置）和对称等价类（行相同、列为 W-1-c 的位置及其周期等价类）中已有颜色的前景像素。
4. 通过传递闭包（周期等价 + 对称等价的交替应用），确定 (r, c) 的唯一颜色，填入该颜色。
5. 所有原有前景像素保持不变。

**关键洞察**：这道题不是"先做镜像再做平铺"或反过来，而是两个约束同时生效的约束满足问题——求解者必须理解周期等价和对称等价如何通过传递闭包相互传播颜色信息，仅用其中一个约束会留下无法确定的空白格。
