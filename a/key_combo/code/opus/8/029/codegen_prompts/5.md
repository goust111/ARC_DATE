## 新题 5：对称修复揭示隐藏引导色

**组合逻辑**：[对称补全](已有：修复被遮挡像素) → [重涂色](创新：修复后暴露出的特殊颜色像素充当引导色，决定其所在区域的重涂颜色) + [擦除](创新：引导像素在完成颜色转移后自身被擦除)

**来源原语**：对称补全·遮挡像素·对称轨道(f9d67f8b), 重涂色·引导像素(aabf363d), 擦除(aabf363d), 角落色转移后消(aabf363d), 反射旋转定颜色(f9d67f8b), 分离区域(880c1354)

**依赖链**：遮挡色隐藏了部分对称图案 → 对称修复还原真实图案 → 修复后某些位置出现了一种在修复前未见的新颜色（引导色）→ 引导色像素所在的连通区域被整体重涂为引导色 → 引导色像素本身被擦除为背景色，仅保留重涂效果

修复一个被损坏的对称图案后，某些修复位置会"显现"出一种原本被隐藏的引导颜色；该颜色指示其所在区域应重涂为何色，随后引导像素自身消失。

**输入结构**：约 12x12 方形网格。网格包含一个以网格中心为对称中心的图案，使用 2~3 种前景色（取自蓝(1)、绿(3)、黄(4)）绘制在黑(0)背景上。图案同时具有水平和垂直反射对称性（未被遮挡时）。若干像素被栗(9)色覆盖（遮挡色），遮挡了原始图案。在被遮挡的像素中，大部分的真实颜色可由对称轨道中的可见像素唯一确定。其中 1~2 个被遮挡位置的真实颜色为红(2)——这是"引导色"，仅在对称修复后才出现（输入中不存在任何红(2)像素）。前景图案自然地将网格分割为若干 4-连通黑(0)背景区域。每个引导色像素恰好 4-连通邻接一个这样的背景区域。生成约束：每个背景区域至多被一个引导像素邻接；引导色的对称轨道中至少有一个非遮挡像素可用于确定其颜色。

**规则**：
1. 识别栗(9)为遮挡色（它是唯一一种移除后能使剩余图案具有关于网格中心的水平和垂直反射对称性的颜色）。
2. 对每个栗(9)像素，在其水平反射、垂直反射和 180 度旋转的对称位置中寻找非栗(9)像素，用找到的颜色替换该栗(9)像素。若多个对称位置给出颜色，它们必须一致（由生成约束保证）。
3. 修复完成后，找到所有红(2)像素——这些是引导像素。对每个红(2)引导像素，找到其 4-连通邻域中唯一的黑(0)背景连通区域 R。
4. 将区域 R 中的所有像素重涂为红(2)。
5. 最后，将所有原本为引导像素的位置（步骤 3 中识别的红(2)像素）擦除为黑(0)。

**关键洞察**：对称修复不仅是目的本身，更是揭示隐藏信息的手段——引导色被刻意编码在遮挡像素之下，只有完成对称修复后才能知道哪些区域需要重涂；引导色的"出现后自毁"机制需要对比修复前后的状态才能理解。
