## 新题 3：缺口朝向决定框内操作类型

**组合逻辑**：[平铺](已有：水平周期平铺) ⊕ [镜像](已有：垂直轴镜像) ← [缺口方向决定射线](创新：缺口方向不再决定射线，而是决定对框内图案执行平铺还是镜像) + [射线延伸](已有：缺口向外发射射线，颜色由变换结果决定)

**来源原语**：平铺·周期(963e52fc), 镜像·对称(c35c1b4c), 缺口方向决定射线(551d5bf1), 空心矩形·边框缺口(551d5bf1), 边界包围内部(62b74c02), 周期图案(963e52fc)

**依赖链**：缺口所在边的方向决定对框内图案执行哪种操作（条件分支）→ 操作结果填满框内部 → 填充后框内的主色决定从缺口外射的射线颜色 → 射线从缺口向外延伸直至遇障碍或边缘

在每个框体内放置一小块种子图案；框体的缺口位于水平边时，将种子沿垂直轴镜像后填入框内；缺口位于垂直边时，将种子沿水平方向周期平铺填入框内；然后从缺口向外发射一条射线，射线颜色为框内变换后出现次数最多的前景色。

**输入结构**：约 16x16 网格，黑(0)背景。网格中有 2~4 个蓝(1)单像素宽空心矩形框，每个框内部宽高均至少 3 像素。每个框恰好有一个缺口（一个非角的边框像素缺失）。框内左上角区域有一小块种子图案（2~3 像素宽，高度等于框内高度或宽度等于框内宽度，具体取决于缺口方向），种子颜色取自红(2)、绿(3)、黄(4)中的 1~2 种，剩余框内为黑(0)。框之间互不重叠，彼此间距至少 2 像素。生成约束：至少有一个框缺口在水平边、至少一个在垂直边，以确保两种操作都出现。

**规则**：
1. 对每个蓝(1)框，判断缺口所在边是水平边（上或下）还是垂直边（左或右）。
2. 若缺口在垂直边（左或右）：框内种子图案占据内部最左侧若干列，其宽度 w 为种子的列数。以 w 为水平周期，将种子向右重复平铺直至填满整个框内部（最后一个周期若超出则在框内右边界处裁剪）。
3. 若缺口在水平边（上或下）：框内种子图案占据内部最上方若干行，其高度 h 为种子的行数。将种子关于其底边做垂直镜像，得到种子+镜像拼合体（高度 2h-1，共享中间行），再以此拼合体为单元向下重复平铺填满框内部（最后一个周期若超出则在框内下边界处裁剪）。
4. 变换完成后，统计每个框内部非黑(0)像素中出现次数最多的颜色，记为该框的主色 mc（若出现次数相同，取在框内部从上到下从左到右扫描时最先出现的颜色）。
5. 从每个框的缺口位置，沿缺口朝外方向发射一条 1 像素宽射线，涂为 mc 色。射线遇到第一个非黑(0)像素时停止（不覆盖该像素），若先到网格边缘则止于边缘。
6. 蓝(1)框体像素保持不变。

**关键洞察**：缺口的朝向不仅决定射线的发射方向，更根本地决定了对框内种子执行哪种几何操作——仅看单个示例可能恰好只有一种缺口方向，必须对比包含两种方向的示例才能归纳出这一条件分支规则。
