## 新题 7：环形区域交换内部图案并几何适配

**组合逻辑**：[循环轮换](创新：不再轮换纯色，而是轮换区域内部的图案) + [裁剪](已有：提取每个区域内部图案) + [拉伸](创新：将图案从一个区域形状适配到下一个区域形状)

**来源原语**：循环轮换·环绕角度排序(880c1354), 分隔结构·分离区域(880c1354), 裁剪(be94b721), 拉伸·行列独立拉伸(b0f4d537), 顶点坐标映射(b0f4d537)

**依赖链**：角度排序确定区域的循环顺序 → 每个区域的内部图案被裁剪提取 → 图案按循环顺序移交给下一个区域 → 接收的图案按目标区域的边界框做行列独立拉伸以适配新形状

分隔结构周围的区域各自包含小图案；按角度顺序，每个区域将自己的图案传递给下一个区域，接收到的图案需拉伸到新宿主区域的边界框尺寸。

**输入结构**：约 15x15 网格，黑(0)背景。网格中央有一个由黄(4)和橙(7)像素构成的十字形或 T 形分隔结构（总计 8~15 像素），将网格分割为 3~4 个独立的黑(0)背景区域。每个区域内有一个小型多色图案（2x2 到 3x3 的边界框，使用蓝(1)、红(2)、绿(3)、灰(5)、品红(6)中的 2~3 种颜色），图案不接触分隔结构也不接触网格边缘。各区域的边界框尺寸各不相同（例如一个较宽较矮，另一个较窄较高）。生成约束：分隔结构的质心近似位于网格中心；各区域面积至少为 4x4 以容纳拉伸后的图案。

**规则**：
1. 识别黄(4)和橙(7)构成的分隔结构，将其像素标记为不可修改。
2. 以分隔结构的质心为原点，计算每个背景区域的质心相对于原点的角度（正右方 0 度，顺时针递增）。按角度从小到大排列区域，得到循环序列 R_0, R_1, ..., R_{n-1}。
3. 对每个区域 R_i，提取其内部图案的最小边界框，记为 P_i（边界框宽 w_i，高 h_i）。
4. 按循环轮换：区域 R_i 接收图案 P_{(i-1) mod n}（即前一个区域的图案）。
5. 将接收到的图案 P_{(i-1) mod n} 拉伸适配到 R_i 的可用空间：确定 R_i 中原图案 P_i 所占的边界框位置和尺寸（宽 w_i，高 h_i），将来源图案 P_{(i-1) mod n}（原宽 w_{i-1}，原高 h_{i-1}）做行列独立拉伸——水平方向缩放比为 w_i / w_{i-1}，垂直方向缩放比为 h_i / h_{i-1}，使用最近邻插值（目标像素 (r, c) 对应源像素 (floor(r * h_{i-1} / h_i), floor(c * w_{i-1} / w_i))）。拉伸后的图案放置在 R_i 中原图案 P_i 的边界框位置。
6. 分隔结构像素和网格边缘外的像素不变。

**关键洞察**：与参考题 880c1354 中仅轮换纯色标签不同，这里轮换的是完整的二维图案，而各区域形状不同迫使图案必须做几何适配——循环轮换确定"谁的图案去哪"，拉伸解决"怎么放进去"，两者缺一不可。
