## 新题 4：走廊动态遮挡下的贪心路径着色

**组合逻辑**：[贪心遍历](创新：每一步绘制的走廊会遮挡后续步骤的视线，使路径依赖于执行顺序) + [连线·走廊路径](已有) + [洪泛填充](创新：框内填充色取决于通向该框的走廊方向)

**来源原语**：贪心遍历·最近未访问优先(3490cc26), 连线·走廊路径(3490cc26), 视线遮挡判断(3490cc26), 洪泛填充(551d5bf1), 空心矩形(551d5bf1), 同行同列对齐(3490cc26), 方向(25ff71a9)

**依赖链**：贪心选择最近可见框 → 绘制走廊 → 走廊像素成为后续步骤的遮挡物，改变哪些框可见 → 到达框的走廊方向（水平或垂直）决定框内填充颜色 → 不可达的框不填充

从红色起点出发，贪心遍历灰色空心矩形框；每步绘制的橙色走廊会遮挡后续的视线通道，因此路径是动态决定的；每个被到达的框根据走廊抵达方向（水平到达填绿，垂直到达填黄）填充内部。

**输入结构**：约 17x17 网格，黑(0)背景。一个红(2) 2x2 实心起始块。4~6 个灰(5)单像素宽空心矩形框（内部宽高均至少 2，内部为黑(0)）。框的外边界框中心在某些行或列上与起始块或其他框对齐（共享至少 2 行或 2 列的带状区域）。框之间互不接触。生成约束：在静态视线下（忽略走廊遮挡），从起始块可达至少 4 个框；但在动态遮挡下（走廊阻挡视线），至少有 1 个框因被中间走廊遮挡而无法到达。

**规则**：
1. 当前位置初始化为红(2)起始块。
2. 在当前位置的 2 行宽或 2 列宽带状视野中，寻找所有尚未访问的灰(5)框。"可见"定义：当前块与目标框在同一个 2 行或 2 列的带状区域内，且两者之间的所有像素均为黑(0)——任何非黑像素（包括之前步骤绘制的橙(7)走廊像素和其他灰(5)框的边框像素）都会遮挡视线。
3. 从可见的未访问框中选择距离最近的一个（距离为当前块边缘到目标框边缘沿对齐方向的像素数；距离相同时选同一行/列带中靠上或靠左的框）。
4. 将当前块与选中框之间的所有黑(0)像素涂为橙(7)，形成走廊。记录走廊方向：若走廊沿行方向绘制则为"水平"，沿列方向则为"垂直"。
5. 根据走廊方向填充目标框内部：水平到达的框内部填绿(3)，垂直到达的框内部填黄(4)。
6. 将当前位置更新为目标框，重复步骤 2-5，直到无可见未访问框为止。
7. 未被到达的框保持原样（内部为黑(0)）。红(2)起始块和灰(5)框体像素均保留。

**关键洞察**：与参考题 3490cc26 中在静态网格上规划路径不同，这里每一步走廊的绘制都动态改变了后续的可视图——同样的框布局，若第一步选择了不同的最近框，后续路径可能完全不同；必须逐步模拟走廊绘制才能确定最终结果。
