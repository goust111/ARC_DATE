## 新题 1：晶格通道射线与缺口定界裁剪

**组合逻辑**：[射线延伸](创新：射线被约束在晶格通道内传播，不可穿越格线) + [裁剪](创新：裁剪窗口由缺失交叉点定义，而非射线范围) + [重涂色](已有)（三者共享同一晶格空间结构，但各自的语义角色不同）

**来源原语**：射线延伸/ray_extension、射线遇障停止/ray_stops_at_block、特定色为墙壁/specific_is_wall（参考题 6ffe8f07）；晶格网格/lattice_grid、标记行列选择/marker_row_column_selection（参考题 4f537728）；裁剪/crop、缺失交叉点/missing_intersection、四角围合/four_corner_bound、背景色空洞/background_hole（参考题 a644e277）

**依赖链**：晶格结构同时为射线提供通道约束和为裁剪提供边界标记——射线必须沿通道传播（否则会穿越格线产生错误结果），而裁剪区域由四个缺口独立编码（与射线范围无关）。最终输出是射线涂色后的网格在缺口定义的窗口内的截取，两步缺一不可。

在晶格通道内发射受阻射线，然后裁剪到四个缺失交叉点围成的矩形区域。

**输入结构**：约 20x20 的网格。灰(5) 单像素宽的晶格线在黑(0) 背景上形成规则的矩形格子，每个格子内部约 3x3。某一个格子内包含一个青(8) 实心矩形（2x2），是射线源。另有若干格子内各含一个蓝(1) 实心小对象（不规则 4-连通形状，2~5 像素），充当墙壁。其余格子内部为空（黑色背景）。在整个晶格中，恰好有四个交叉点处的灰像素被替换为黑(0)（即"缺口"），这四个缺口构成一个轴对齐矩形的四个角。生成约束：青矩形与蓝墙壁互不相邻；四个缺口所围矩形严格包含青矩形所在格子；蓝墙壁分布在缺口矩形内外均有。

**规则**：
1. 从青(8) 矩形所跨的每一行，沿该行的背景通道（同一行中两条晶格线之间的黑色像素带）向左和向右发射射线。射线仅在通道内传播，不穿越灰(5) 格线。
2. 从青(8) 矩形所跨的每一列，沿该列的背景通道向上和向下发射射线，同样不穿越格线。
3. 射线遇到蓝(1) 像素时停止（不包含蓝像素本身）；遇到网格边界时也停止。
4. 所有被射线经过的黑(0) 背景像素重涂为黄(4)。青矩形、蓝墙壁、灰格线均保持原色。
5. 找到四个缺口交叉点（本应为灰(5) 但实际为黑(0) 的晶格交叉位置）。以这四个点为角，确定一个轴对齐矩形区域。
6. 输出为该矩形区域的包含性裁剪（含四个角点所在行列），展示裁剪后的黄色射线图案、灰格线、青源、蓝墙壁及未修改的背景。

**关键洞察**：射线受晶格通道约束而无法跨行跨列扩散，而裁剪边界由四个缺口独立标记——两套规则共享同一晶格结构但用途完全不同，必须同时正确理解才能得到输出。
