## 新题 1：对称补墙与腔室染色

**组合逻辑**：[对称补全](创新：作用对象从前景图案改为墙壁像素，补全改变分区拓扑) + [洪泛填充](创新：腔室由补全后的墙壁动态定义) + [邻接多数决](已有)

**来源原语**：对称补全/旋转对称/四次旋转闭合(e40b9e2f)、洪泛填充/四连通分区/连通腔室/标记像素/正交邻接/邻接多数决(7c8af763)、分隔墙(782b5218)

**依赖链**：对称补全改变墙壁拓扑 → 新墙壁重新划分四连通腔室 → 标记像素按邻接多数决为各腔室着色。跳过补全则腔室边界错误（被打通的分区导致错误的合并或分裂），跳过填充则无颜色输出。补全操作的结果实质性改变了填充操作的输入：缺失墙壁段会打通相邻腔室使其合并，补全后这些腔室被正确隔开，不同腔室邻接的标记集合也随之改变。

从不完整的墙壁像素出发，通过四次旋转对称补全墙壁，利用补全后的墙壁将网格划分为若干腔室，再由标记像素的邻接多数投票为每个腔室着色。

**输入结构**：约 15x15 的网格。背景为黑(0)。灰(5)像素组成分隔墙，但墙壁图案只在部分区域完整绘制，其余区域有缺失段（整体呈不完整的四次旋转对称，旋转中心为网格中心）。网格中散布若干单像素标记点，颜色来自红(2)、蓝(1)、绿(3)三种，每个标记点正交邻接至少一个属于某腔室的背景像素。标记点不位于墙壁上，也不处于补全后新增墙壁的位置。生成约束：(1) 补全后的墙壁将网格分成至少 4 个四连通背景腔室；(2) 每个腔室邻接的标记点存在唯一多数色（不出现平票）；(3) 不同示例中缺失的墙壁区域不同，以防求解者通过记忆特定缺失位置解题；(4) 至少存在两个腔室，在补全前本为同一连通区域、补全后被分隔为不同腔室，且各自的多数投票色不同。

**规则**：
1. 以网格中心为旋转中心，将所有灰(5)墙壁像素旋转 90 度、180 度、270 度后取并集，补全墙壁图案至四次旋转对称。新增的墙壁像素涂灰(5)。
2. 将补全后的全部灰(5)像素视为阻隔，找出所有四连通背景(0)像素的连通腔室。
3. 对每个腔室，收集所有正交邻接该腔室任意像素的标记像素颜色（一个标记可以邻接多个腔室，每个腔室独立统计），取出现次数最多的颜色作为该腔室的填充色。
4. 将该腔室的全部背景(0)像素重涂为其填充色。灰(5)墙壁像素和彩色标记像素保持不变。

**关键洞察**：墙壁补全不是装饰性的——缺失的墙壁段恰好打通了本应分隔的腔室，使得补全前后同一标记点邻接的腔室集合发生变化，必须先补全再分区才能正确着色。
