## 新题 8：轮廓围合区域的十字模板匹配选择性填充

**组合逻辑**：[填充](创新：仅填充满足模板条件的围合区域) + [轮廓围合](定义区域边界) + [局部模板匹配](创新：检测区域内是否存在十字图案残留) + [擦除](创新：匹配成功后擦除残留再填充)

**来源原语**：填充(flood_fill) ← 753ea09b; 轮廓围合(contour_enclosure) ← 753ea09b; 封闭背景区域(enclosed_bg_region) ← 753ea09b; 小区域被填充(small_regions_filled) ← 753ea09b; 局部模板匹配(local_template_match) ← 7e02026e; 十字图案(plus_pattern) ← 7e02026e; 正交邻接(orthogonal_adjacency) ← 7e02026e; 擦除(erase) ← a2d730bd; 忽略干扰项(ignore_distractors) ← 753ea09b

**依赖链**：轮廓线将网格分为多个封闭背景区域 → 在每个区域内检测是否存在由特定颜色组成的十字图案（中心+四正交邻居） → 包含十字图案的区域：先擦除十字（变回背景色），再用轮廓色填充整个区域 → 不包含十字图案的区域保持原样不填充。模板匹配是填充的门控条件；擦除保证填充后十字痕迹消失。

仅填充内部含有十字标记的轮廓围合区域，填充前先擦除十字。

**输入结构**：约 18x18 的黑(0)背景网格。绿(3)色像素形成若干 8-连通的长轮廓片段（弧线或折线，每段 8~20 像素），这些片段相互连接或靠近网格边界，将网格内部分割为若干 4-连通的封闭背景区域（每个区域 5~25 个背景像素）和一两个与网格边界相通的大外部区域。部分封闭区域内有一个红(2)色十字图案：一个红(2)像素及其上下左右四个正交邻居也是红(2)（共 5 个红像素组成十字）。十字完全位于该封闭区域内部，不接触轮廓像素。其余封闭区域内部为纯黑(0)背景。网格中还散布少量橙(7)色干扰像素（1~3 个单独像素，可出现在任何位置），干扰像素不参与任何规则。生成约束：至少有 2 个封闭区域含十字，至少有 2 个不含十字；十字的五个像素全部是红(2)且全部位于同一封闭区域内。

**规则**：
1. 将所有非黑(0)像素（绿(3)轮廓、红(2)十字、橙(7)干扰）视为屏障，对黑(0)像素做 4-连通区域分割。
2. 识别所有不与网格边界相邻的封闭背景区域（与边界相通的外部区域排除）。
3. 对每个封闭区域，检查区域内部是否存在红(2)色十字图案（某个红(2)像素的上下左右四邻居均为红(2)且均位于该区域内部或该区域的红(2)像素集内）。
4. 若封闭区域内存在十字图案：先将该十字的 5 个红(2)像素全部改为黑(0)（擦除），然后将该区域的所有黑(0)像素（包括刚擦除变回黑(0)的位置）填充为绿(3)。
5. 若封闭区域内不存在十字图案：该区域保持黑(0)不变。
6. 橙(7)干扰像素保留不变。绿(3)轮廓像素保留不变。输出网格与输入同尺寸。

**关键洞察**：十字图案是"填充许可证"而非输出的一部分——它在触发填充后被擦除，所以输出中看不到任何红色。观察者必须注意到输入中某些区域有红十字而某些没有，且有十字的区域被填充、没有的保持空白。干扰像素是红鲱鱼（herring），需忽略。
