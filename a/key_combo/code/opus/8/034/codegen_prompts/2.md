## 新题 2：棋盘奇偶分流压缩与交叉区冲突合成

**组合逻辑**：[奇偶性选色](创新：奇偶两类分别独立压缩) + [压缩](创新：两个正交方向各压缩一类) + [交叉](创新：交叉区由两类压缩结果叠加决定颜色) + [重涂色]

**来源原语**：奇偶性选色(parity_selects_color) ← 5e6bbc0b; 压缩(compact) ← 5e6bbc0b; 交叉(crossing) ← ba97ae07; 重涂色(recolor) ← ba97ae07; 棋盘格图案(checkerboard_pattern) ← 5e6bbc0b; 横条(h_bar) ← ba97ae07; 竖条(v_bar) ← ba97ae07

**依赖链**：棋盘格的奇偶性将像素分为两类 → 奇类向左压缩、偶类向上压缩（方向由两个边缘标记决定） → 两类压缩后的像素可能在某些单元格重叠 → 重叠区域（"交叉区"）取两类颜色之外的第三种颜色。奇偶分类、压缩方向、冲突规则三者缺一不可。

将棋盘格的两种奇偶类分别沿不同方向压缩，在重叠区域合成第三种颜色。

**输入结构**：约 10x10 的黑(0)背景网格。网格中央有一个矩形区域（约 6x6 至 8x8）填满红(2)/蓝(1)棋盘格图案（(row+col)为偶数的单元格为红(2)，奇数为蓝(1)）。网格左边界或右边界上有一个绿(3)单像素标记，表示水平压缩方向（标记在左边界→向左压缩，在右边界→向右压缩）；网格上边界或下边界上有一个黄(4)单像素标记，表示垂直压缩方向（标记在上边界→向上压缩，在下边界→向下压缩）。两个标记不在同一行或同一列。生成约束：棋盘格区域至少 6x6，保证压缩后两类均有多行多列的像素。

**规则**：
1. 将棋盘格区域的像素按奇偶性分为两组：A 组为红(2)像素（(row+col)为偶数的位置），B 组为蓝(1)像素（(row+col)为奇数的位置）。
2. A 组像素在各自所在行中，向绿(3)标记指示的方向压缩（消除同行内 A 组像素之间的间隙，紧贴棋盘格区域在该方向的边缘）。
3. B 组像素在各自所在列中，向黄(4)标记指示的方向压缩（消除同列内 B 组像素之间的间隙，紧贴棋盘格区域在该方向的边缘）。
4. 压缩后，若某个单元格同时被 A 组和 B 组占据（发生重叠），则该单元格着灰(5)色。仅被 A 组占据的保持红(2)，仅被 B 组占据的保持蓝(1)，均无占据的保持黑(0)。
5. 绿(3)和黄(4)标记像素保留在原位，不参与压缩。输出网格与输入同尺寸。

**关键洞察**：重叠区域的灰(5)色是隐蔽规则——直觉上可能以为重叠区只保留其中一类的颜色，但实际上重叠产生了输入中不存在的第三种颜色。需对比多个示例（不同压缩方向组合导致不同重叠模式）才能发现灰色仅出现在双占区。
