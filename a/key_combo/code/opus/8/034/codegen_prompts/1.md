## 新题 1：射线围合深度着色

**组合逻辑**：[射线延伸](创新：从边界标记发射，遇到已有射线停止) + [填充](创新：区域深度决定填充色) + [计数](创新：计数穿越射线次数作为深度)

**来源原语**：射线延伸(ray_extension) ← 1d398264; 填充(flood_fill) ← 753ea09b; 计数(count) ← aaecdb9a; 边缘标记(edge_marker) ← 5e6bbc0b; 封闭背景区域(enclosed_bg_region) ← 753ea09b; 嵌套层(nested_layer) ← bd5af378

**依赖链**：边缘标记的位置决定射线方向和终点 → 射线网格将画布切分为封闭区域 → 每个区域的"围合深度"（从外边界到达该区域至少需穿越多少条射线）决定其填充颜色 → 深度值通过固定色序映射为具体颜色。删去射线则无分区；删去深度计算则无法选色；删去填充则无输出。

从边界标记发射射线并在射线交汇处截断，按围合深度为分区着色。

**输入结构**：约 15x15 的黑(0)背景网格。网格四条边界上各有 2~4 个单像素标记，使用蓝(1)色。标记不出现在角落。每个边界标记向网格内部发射一条与其所在边垂直的射线（左/右边界标记发射水平射线，上/下边界标记发射垂直射线）。生成约束：标记的位置使得发射的射线两两之间存在交叉（至少形成一个完全封闭的内部矩形区域），但无三线共点。标记像素本身是射线的一部分。

**规则**：
1. 从每个蓝(1)标记出发，沿垂直于其所在边界的方向画一条蓝(1)射线，射线在碰到另一条已存在的射线像素或对侧边界时停止（包含终点像素）。射线绘制顺序不影响最终结果（因为所有射线均为蓝(1)色且交叉点归属无歧义）。
2. 射线将网格划分为若干 4-连通背景区域。计算每个区域的"围合深度"：与网格外边界 4-连通相邻（不穿越任何射线即可到达边界）的区域深度为 0；需至少穿越 k 条射线才能从边界到达的区域深度为 k。
3. 深度为 0 的区域保持黑(0)不变；深度为 1 的区域填充绿(3)；深度为 2 的区域填充黄(4)；深度为 3 的区域填充橙(7)；更高深度依次使用红(2)、品红(6)。蓝(1)射线像素保持不变。
4. 输出网格与输入同尺寸。

**关键洞察**：深度到颜色的映射顺序（黑→绿→黄→橙→红→品红）是隐蔽规则，仅看单个示例可能猜错映射方向或跳色；需对比多个示例中不同深度区域的用色才能确定固定色序。
