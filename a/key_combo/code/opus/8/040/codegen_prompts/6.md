## 新题 6：交替镜像瓦片条带上的跨瓦片射线交叉

**组合逻辑**：[平铺 + 镜像/奇偶位交替翻转](已有) → [射线延伸 + 行列交叉 + 异源交叉特殊着色](创新：镜像产生的标记副本参与射线延伸，创造原始瓦片中不存在的交叉模式)

**来源原语**：平铺/镜像/瓦片/奇偶位交替翻转/拼接（#15 bc4146bd）、射线延伸/标记像素/十字引导线/行列交叉/异源交叉特殊着色（#1 45bbe264）

**依赖链**：原始瓦片中标记的列位置 → 镜像翻转改变副本的列位置 → 5 份拼接后所有标记（原始+镜像副本）的全局列位置确定 → 同色标记的行射线合并为同一条（行不变） → 不同色标记的列射线在新列位置交叉 → 交叉模式由瓦片结构和翻转规则共同决定

将瓦片交替镜像拼接为 5 份条带，条带中所有标记像素（含镜像副本）的行列引导线交叉处涂红。

**输入结构**：
- 一个 4x4 瓦片，黑(0)背景上有 2-3 个不同颜色的标记像素（使用蓝(1)、绿(3)、黄(4)等非黑非红颜色），每个标记占一个格，标记位于不同行不同列
- 输入即为此 4x4 瓦片（无其他元素）
- 生成约束：标记像素的行和列分布保证至少两个不同色标记在瓦片或其镜像副本中会共享某些列位置（使得交叉可发生）

**规则**：
1. 将输入瓦片扩展为 5 份水平拼接的条带（宽 4x5=20，高 4）：第 1、3、5 份为原始瓦片，第 2、4 份为水平镜像瓦片（每份内列坐标翻转，即原第 j 列变为第 3-j 列）
2. 在拼接后的 20x4 条带中，定位所有标记像素（含原始和镜像副本产生的）
3. 对每个标记像素，将其所在行的所有背景格涂为该标记的颜色，将其所在列的所有背景格涂为该标记的颜色。同色标记的射线自然合并（同色不产生新效果）。绘制顺序：按标记像素的全局坐标阅读顺序（行优先，列次之），后绘制的覆盖先绘制的
4. 同一标记颜色的不同副本产生的射线视为同源，交叉处不做特殊处理
5. 不同颜色标记的射线交叉处（该格同时位于颜色 A 的某个标记的行或列、以及颜色 B 的某个标记的行或列，且 A != B）涂为红(2)
6. 所有标记像素（原始和镜像副本）保持其原色不变

**关键洞察**：水平镜像改变了标记在条带中的列位置但不改变行位置。同色标记的行射线在所有 5 份中完全重合（因为行不变），但列射线因镜像而分裂到不同列上。交叉图案的对称性由拼接规则的奇偶翻转机制决定，而非由原始瓦片直接给出。
