## 新题 3：对称补全生成同色矩形副本后跨轴桥接

**组合逻辑**：[十字轴对称补全](已有，源自 60d73be6) + [同色矩形桥接](已有，源自 f3b10344) + [对称距离决定桥接拓扑](创新——矩形相对十字轴的距离决定反射副本之间的间隙大小，从而决定哪些副本对可以被桥接、桥接宽度多少)

**来源原语**：十字轴线(cross_axis, 60d73be6), 双轴对称(biaxial_symmetry, 60d73be6), 四象限镜像填充(quadrant_mirror, 60d73be6), 对称补全(symmetry_complete, 60d73be6), 实心矩形(solid_rect, f3b10344), 桥接条(bridge_bar, f3b10344), 同色配对(same_color_pair, f3b10344), 对向间隙(facing_gap, f3b10344), 最短间隙优先连(shortest_gap_first, f3b10344), 连线(draw_line, f3b10344)

**依赖链**：十字轴定位 → 各象限矩形按双轴反射 → 产生同色矩形副本对 → 副本对之间的间隙大小取决于原始矩形到轴的距离 → 仅在间隙行/列重叠达 3 格以上时绘制桥接。没有对称补全就没有同色配对可桥接；没有桥接规则就不知道反射后输出的完整形态。矩形离轴越近，反射副本间隙越小，越容易形成桥接——空间几何与连接判断紧密耦合。

将各象限中的单个矩形通过十字轴反射到四个象限，再在跨轴相邻的同色副本之间绘制桥接条。

**输入结构**：黑(0)背景的网格，约 15x15。一条绿(3)横行贯穿整个网格宽度，一条绿(3)纵列贯穿整个网格高度，交叉形成十字轴。十字将网格分为四个象限。在 2-3 个不同象限中各放置一个实心矩形（至少 2x3 像素），颜色各不相同（从蓝(1)、红(2)、黄(4)、灰(5)、品红(6)、橙(7)中选取），每种颜色仅出现一次。矩形完全位于其所在象限内，不与绿(3)十字轴重叠。无其他前景色。生成约束：每个矩形的行范围或列范围与十字轴的距离至少为 1 格；至少一个矩形在反射后，其副本对跨越十字轴时行或列重叠范围不少于 3 格。

**规则**：
1. 识别绿(3)十字轴：恰好一整行和一整列全为绿(3)。记录十字行号 R 和十字列号 C。
2. 对每个非黑(0)非绿(3)的实心矩形，将其反射到其他三个象限：关于十字行 R 做上下反射，关于十字列 C 做左右反射，关于两者同时反射。反射后的副本保持原矩形的颜色和尺寸。若反射目标象限已有另一颜色的矩形副本占据相同位置，后反射的覆盖先反射的（按颜色在输入中出现的从左到右、从上到下顺序决定反射先后，最后出现的最后反射因而覆盖）。
3. 反射完成后，在所有同色矩形副本对之间检查桥接条件：两个同色矩形必须在水平或垂直方向上隔着仅含绿(3)和黑(0)的间隙面对面，且它们在垂直（若水平面对）或水平（若垂直面对）方向上的重叠范围不少于 3 格。
4. 对每对满足条件的同色矩形，绘制青(8)桥接条：桥接条沿间隙方向从一个矩形的边缘延伸到另一个矩形的边缘（含起止列/行），宽度为重叠范围两端各缩进 1 格后的剩余范围。桥接条覆盖路径上的绿(3)像素。若同一颜色有多对候选桥接，仅绘制间隙最短的那对。
5. 未被桥接条覆盖的绿(3)十字像素保持绿(3)。

**关键洞察**：桥接是否发生不取决于输入中的矩形配对，而取决于对称反射后的副本几何——矩形离十字轴越近，反射副本间隙越小、重叠越大，越容易触发桥接。求解者必须理解对称操作如何改变空间邻接关系，才能预测桥接拓扑。
