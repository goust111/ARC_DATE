## 新题 5：孔洞数参数化印章缩放与着色

**组合逻辑**：[计数/counting]（沿用：数封闭孔洞） + [拉伸/stretch]（创新：拉伸倍率由孔洞数决定，而非由骨架锚点间距决定） + [印章覆盖/stamp]（创新：同一模板在不同矩形内以不同尺寸和颜色印出）

**来源原语**：计数/counting（0a2355a6）、封闭区域/enclosed_region（0a2355a6）、按孔洞数映射颜色/hole_count_to_color_mapping（0a2355a6）、印章覆盖/stamp（264363fd）、十字模板/crosshair_template（264363fd）、以标记为中心印章/stamp_on_marker_center（264363fd）、矩形/rectangle（264363fd）、标记像素/marker_pixel（264363fd）、内部包含/containment（264363fd）、拉伸/stretch（b0f4d537）

**依赖链**：孔洞计数决定缩放因子和颜色 → 缩放因子决定印章尺寸 → 印章尺寸决定印章能否在矩形内完整印出 → 印章在标记中心印出时需检查边界裁剪。删去计数则不知缩放和颜色，删去缩放则所有矩形印章相同（无法区分），删去印章则无输出变化

一句话总结：对每个矩形计数其边框包围的内部孔洞数，以此决定印章模板的缩放倍率和颜色，在矩形内每个标记像素中心印出缩放后的印章。

**输入结构**：
- 网格约 20~28 行列，背景为黑(0)。
- 网格中有 2~4 个由同一颜色（如蓝(1)）边框构成的矩形，矩形内部为黑(0)背景。矩形尺寸各不相同（最小约 7x7，最大约 13x13）。矩形互不重叠、互不相邻。
- 每个矩形的边框内部包含若干（0~3 个）由边框像素完全包围的 4-连通黑(0)封闭区域（孔洞）——这些孔洞是边框上的缺口形成的内部隔间，即矩形边框并非完整的实心框，而是在某些位置有 1 像素宽的缺口，将矩形内部分割为若干不与外部连通的封闭子区域。不同矩形的孔洞数互不相同。
- 每个矩形内部有 1~2 个橙(7)标记像素，位于矩形内部的黑色区域中。
- 网格中另有一个独立的小型十字模板精灵（3x3 的加号形状，由绿(3)像素组成，仅含上下左右 4 个臂像素，中心为黑(0)），位于所有矩形之外。
- 生成约束：每个矩形足够大，使得最大缩放后的印章（以最多孔洞数为倍率）仍可在矩形内以标记为中心完整印出而不超出矩形边框。孔洞数范围为 1~3（0 孔洞的矩形不参与印章操作，保持不变）。

**规则**：
1. 识别所有矩形（蓝(1)边框的 4-连通分量）及其内部结构。
2. 对每个矩形，计算其边框像素完全包围的 4-连通黑(0)封闭区域数量（孔洞数 H）。孔洞数为 0 的矩形跳过后续步骤，保持原样。
3. 根据孔洞数确定该矩形的印章颜色：H=1 → 红(2)，H=2 → 黄(4)，H=3 → 品红(6)。
4. 将十字模板按因子 H 等比缩放（原始模板 3x3，H=1 时保持 3x3，H=2 时缩放为 5x5 即臂长从 1 增至 2，H=3 时缩放为 7x7 即臂长从 1 增至 3）。缩放后的十字形状保持加号结构：中心为空，四个臂各向外延伸 H 个像素。
5. 对每个矩形内的每个橙(7)标记像素，以其坐标为中心，将缩放后的十字模板印在矩形内部：将十字臂像素位置处的黑(0)像素涂为步骤 3 确定的颜色。若印章的某个臂遇到矩形的蓝(1)边框像素，则该臂在边框前一个像素处截断（不覆盖边框）。
6. 橙(7)标记像素本身保持不变。十字模板精灵在输出中被擦除为黑(0)背景。

**关键洞察**：同一个十字模板在不同矩形中表现为不同尺寸和颜色——缩放倍率和着色并非由模板自身决定，而是由目标矩形的拓扑属性（孔洞数）参数化。求解者必须将"矩形结构分析"与"模板几何变换"关联起来。

import hashlib

p = Path("/home/lixinyu/snap/a/key_combo/code/opus/1/033/5.py")

    assert out.ndim == 2 and max(out.shape) <= 30, f"output grid exceeds 30x30: {out.shape}"
    sigs.add(hashlib.md5(inp.tobytes() + str(inp.shape).encode()).hexdigest())
print("variants", len(sigs))
assert len(sigs) >= 20

python -m py_compile "/home/lixinyu/snap/a/key_combo/code/opus/1/033/5.py"
