## 新题 7：正方形遮挡物的奇偶三分支恢复

**组合逻辑**：[补全/complete]（沿用：从可见周期推断被遮挡图案） + [标注中心/mark_center]（创新：中心标注色为遮挡物原色而非外部标记色） + [擦除/erase]（创新：擦除条件由形状分类和奇偶性联合决定）

**来源原语**：补全/complete（abbfd121）、周期平铺图案/periodic_tile（abbfd121）、矩形遮挡物/rect_occluder（abbfd121）、被遮挡/occluded（abbfd121）、最大矩形区域/max_rect_region（abbfd121）、标注中心/mark_center（22806e14）、实心正方形/solid_square（22806e14）、奇偶性/parity（22806e14）、奇边长才标注/odd_side_marked（22806e14）、擦除/erase（1c02dbbe）

**依赖链**：形状分类将遮挡物分为"非正方形矩形"和"正方形"两类 → 正方形进一步按边长奇偶分为两小类 → 三个分支各有不同的变换：非正方形保留不动、偶数正方形完全恢复底层图案、奇数正方形恢复图案并标注中心。删去周期推断则无法恢复，删去形状分类则不知哪些该恢复，删去奇偶判断则无法区分标注与否

一句话总结：在被多个矩形遮挡物覆盖的周期图案上，非正方形遮挡物保持不变，偶边长正方形遮挡物被底层图案替换，奇边长正方形遮挡物被底层图案替换后在中心额外标注遮挡物原色。

**输入结构**：
- 网格约 14~20 行列。
- 底层为一个行列周期平铺的彩色图案，基本瓦片为 2x2 或 3x3，由 2~3 种颜色组成（如蓝(1)和绿(3)交替）。
- 在周期图案上方叠加了 4~6 个单色实心矩形遮挡物，每个遮挡物由一种非图案颜色构成（从红(2)、黄(4)、灰(5)、品红(6)、橙(7)中选取），颜色互不相同。遮挡物互不重叠。
- 遮挡物中：至少 1 个是非正方形矩形（如 3x5 或 2x4），至少 1 个是偶边长正方形（如 2x2 或 4x4），至少 1 个是奇边长正方形（如 3x3 或 5x5）。
- 生成约束：周期图案的可见部分（遮挡物之外）足以唯一推断出基本瓦片的内容和对齐方式。

**规则**：
1. 从所有遮挡物之外的可见区域推断底层周期图案的最小平铺瓦片及其行列对齐相位。
2. 对每个遮挡物进行形状分类：
   - (a) 非正方形矩形（宽 =/= 高）：保持不变，遮挡物像素留在原处。
   - (b) 偶边长正方形（宽 = 高 且边长为偶数）：将遮挡物区域的所有像素替换为底层周期图案在该位置的颜色（完全恢复）。
   - (c) 奇边长正方形（宽 = 高 且边长为奇数）：先将遮挡物区域的所有像素替换为底层周期图案在该位置的颜色，然后将正方形中心像素（第 (边长/2) 行、第 (边长/2) 列，0-indexed）涂为该遮挡物的原始颜色。
3. 所有遮挡物之外的周期图案像素保持不变。

**关键洞察**：同为遮挡物，命运却由几何属性决定——求解者必须对每个遮挡物做两级分类（正方形与否、边长奇偶），才能确定它是被保留、被恢复、还是被恢复加标注。奇边长正方形中心的标注色来自遮挡物自身而非外部模板，这一点需对比多个示例才能归纳。
