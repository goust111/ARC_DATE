## 新题 4：分裂掩码的双色克罗内克积

**组合逻辑**：[分裂](已有，创新：分裂对象从实心矩形变为二值掩码) → [克罗内克积](已有) + [颜色互换](已有，创新：两半各自独立做积，颜色由对方决定)

**来源原语**：分裂/split (9f669b64), 穿越并分开/pass_through_split (9f669b64), 实心矩形/solid_rectangle (9f669b64), 克罗内克积/kronecker_product (8e2edd66), 二值掩码/binary_mask (8e2edd66), 颜色互换/color_swap (8e2edd66), 前景背景互换填充/fg_bg_inverted_fill (8e2edd66)

**依赖链**：红色水平条将蓝色掩码分裂为上下两部分 → 上部掩码做克罗内克自积但用下部的前景色（红），下部掩码做克罗内克自积但用上部的前景色（蓝） → 两个积结果纵向拼接，中间以红条分隔。分裂位置决定两个子掩码的形状，子掩码形状决定积的结果；颜色互换建立了两半之间的交叉依赖，不能独立求解任一半。

源题中克罗内克积作用于单一完整掩码，分裂作用于沿轴排列的实心矩形；此处二者结合在同一对象上——分裂创造出两个子掩码，每个子掩码独立执行克罗内克积，但颜色交叉引用对方，形成源题中不存在的"分裂-交叉积"结构。

**输入结构**：黑(0)背景，约 7x7 网格。网格中有蓝(1)像素构成一个非对称的二值图案（4-连通，约 8~14 像素，分布在多行多列）。一条红(2)水平单像素厚横条横穿整个网格宽度，将蓝色图案分为上下两个非空部分（横条所在行的蓝像素被横条覆盖，视为被切断）。生成约束：上部蓝色子图案和下部蓝色子图案的行数和列数均不超过 4，以保证克罗内克积输出不超过约 16x16。上下两部分各自至少包含 2 个蓝像素和 2 个黑背景像素。

**规则**：
1. 找到红(2)水平条所在行 r_split。
2. 提取上部子掩码 M_upper：行 [0, r_split) 中，取包含所有蓝像素的最小边界框，框内蓝像素标记为 1，黑像素标记为 0。
3. 提取下部子掩码 M_lower：行 (r_split, H) 中，同样取最小边界框并提取二值掩码。
4. 对 M_upper 计算克罗内克自积：M_upper 中每个 0 值单元格替换为 M_upper 的一个副本（其中 1 值像素涂为红(2)，0 值像素涂为黑(0)）；每个 1 值单元格替换为全黑(0)块。得到结果 K_upper。
5. 对 M_lower 计算克罗内克自积：M_lower 中每个 0 值单元格替换为 M_lower 的一个副本（其中 1 值像素涂为蓝(1)，0 值像素涂为黑(0)）；每个 1 值单元格替换为全黑(0)块。得到结果 K_lower。
6. 输出网格：K_upper 在上，其下一行为红(2)横条（宽度等于输出网格宽度，即 max(K_upper 宽, K_lower 宽)），再下为 K_lower。若 K_upper 和 K_lower 宽度不同，较窄者左对齐，右侧补黑(0)背景。

**关键洞察**：红色横条的双重身份是解题核心——它既是几何分割线（决定两个子掩码的形状），又是颜色供体（上半部分的积使用红色而非蓝色）。需对比多个示例才能发现颜色交叉规则（上用红、下用蓝）而非同色自积。
