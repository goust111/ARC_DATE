## 新题 7：路径分割区域差异填充

**组合逻辑**：[连线·两点路径](已有原语) + [重涂色·按原色区分](已有原语) + [填充](创新：填充目标不是预先存在的区域，而是由路径切割产生的新子区域) + [棋盘格图案](已有原语)

**来源原语**：连线(bcb3040b) + 重涂色(bcb3040b) + 按原色区分涂色(bcb3040b) + 两点直线路径(bcb3040b) + 填充(df8cc377) + 棋盘格图案(df8cc377) + 包含(df8cc377) + 空心矩形(df8cc377, 41e4d17e)

**依赖链**：红色标记对定义路径 → 路径穿过空心矩形时将蓝色边框格变绿、黑色内部格变红 → 红色路径格将矩形内部切分为两个子区域 → 两个子区域的面积大小决定各自的填充方式（大区域棋盘格填充，小区域纯色填充）。连线操作物理地修改了空间拓扑，创造出填充操作所依赖的新区域——先画线再分析结果是不可跳过的。

在蓝色空心矩形外放置成对的红色标记像素，每对标记的直线路径恰好穿过一个矩形。路径将蓝色边框格变为绿色、黑色格变为红色，由此在矩形内部产生两个被路径分隔的子区域，面积较大的子区域填充灰色棋盘格，面积较小的子区域填充纯黄色。

**输入结构**：
- 背景：黑(0)，网格约 13x13
- 2-3 个蓝(1)空心矩形（边框 1 格厚，内部全黑），各矩形之间互不接触且留有足够间隔
- 对于每个矩形，有恰好一对红(2)标记像素位于矩形外部，两者在水平、垂直或 45 度对角线上对齐，使得它们之间的直线段穿过该矩形
- 每对标记的路径仅穿过一个矩形，不同对的路径穿过不同矩形
- 生成约束：每条路径恰好穿过其目标矩形的两个边框格和若干内部格，将矩形内部分为两个 4-连通子区域（以路径上的红色格为边界），两个子区域面积不相等

**规则**：
1. 对每对红(2)标记像素，画出两者之间的包含端点的直线段（使用 Bresenham 直线或精确的女王移动路径）：
   - 路径上原来为蓝(1)的格（矩形边框）变为绿(3)。
   - 路径上原来为黑(0)的格（背景或矩形内部）变为红(2)。
   - 路径上原来为红(2)的格（标记本身）保持红(2)。
2. 所有路径画完后，分析每个被穿过的矩形内部：路径上的红(2)格将内部分割为两个 4-连通子区域（子区域中的格与路径红格和矩形边框蓝/绿格均不连通）。
3. 比较两个子区域的面积（格数）：
   - 面积较大的子区域为"主区域"。
   - 面积较小的子区域为"次区域"。
   - 若面积相等，以包含行号更小的格的子区域为主区域；若仍相等，以包含列号更小的格的子区域为主区域。
4. 主区域填充灰(5)棋盘格：以该子区域中行号最小、列号最小的格为起点，满足 (r - r_start + c - c_start) 为偶数的格涂为灰(5)，其余保持黑(0)。
5. 次区域全部填充为黄(4)。
6. 矩形边框（蓝(1)和绿(3)格）、路径（红(2)格）和矩形外部的所有格保持不变。

**关键洞察**：路径既是视觉元素又是拓扑工具——它同时完成两件事：将穿过的蓝色边框格标记为绿色（记录穿越点），以及用红色格在矩形内部创建一条物理分界线。求解者无法在画线之前确定子区域的形状和面积，因为分界线的几何取决于标记对的位置和矩形的交叉方式。
