## 新题 1：端口驱动的环形接力网络

**组合逻辑**：[循环移色](创新：循环改变端口朝向而非纯视觉变换) + [射线延伸](创新：射线方向由循环后的端口位置决定) + [级联激活](创新：激活触发循环，循环改变射线方向，射线传递激活)

**来源原语**：循环移色(46c35fc7) + 射线延伸(5961cc34, 8d510a79) + 级联激活(5961cc34) + 端口编码射线(5961cc34) + 反向循环(46c35fc7) + 角与边中分组(46c35fc7)

**依赖链**：激活触发环上的角/边中双向循环 → 循环使端口像素移动到新的边中位置 → 新的端口位置决定射线发射的方向 → 射线命中另一个环则触发下一轮激活。三个操作形成闭合回路：循环改变方向，方向决定射线目标，命中触发循环。

在黑色网格上散布若干 3x3 环形对象，每个环的四个边中像素中恰好一个颜色不同（充当端口），一个起始标记激活第一个环后引发级联：每次激活使边中色逆时针旋转、角色顺时针旋转，端口移至新位置后从环中心沿新方向发射射线，射线命中下一个环则继续级联。

**输入结构**：
- 背景：黑(0)，网格约 15x15
- 散布 3-5 个 3x3 环形对象，每个环由 8 个前景像素围绕一个黑(0)中心组成
- 每个环的 4 个角位像素为统一的基底色灰(5)，4 个边中像素中有 3 个也为灰(5)，恰好 1 个边中像素为独特的"端口色"（可以是红(2)、蓝(1)、绿(3)或黄(4)中的一种，不同环的端口色可以不同）
- 端口所在的边中位置（北N/南S/东E/西W）因环而异
- 网格中有 1 个黄(4)起始标记像素，紧邻（4-连通）某个环的外侧，且位于该环端口所指方向的对侧（即起始标记在端口背面）
- 生成约束：各环的放置保证每个被激活环的射线（沿循环后端口新方向）要么命中另一个尚未激活的环，要么到达网格边界；不会有两条射线同时命中同一个环

**规则**：
1. 起始标记激活与之相邻的环，随后擦除起始标记（该像素变为黑(0)）。
2. 当一个环被激活时，依次执行：
   - a. 四个边中像素的颜色逆时针旋转一步（北→西→南→东→北），即原来北边中的颜色移到西边中，西到南，南到东，东到北。端口色随之移动到新位置。
   - b. 四个角位像素的颜色顺时针旋转一步（左上→右上→右下→左下→左上）。
   - c. 从环的中心格向端口色的**新位置方向**发射一条射线：端口在北边中则射线向上，南则向下，东则向右，西则向左。
3. 射线从中心格的相邻格开始，沿确定方向逐格延伸，将经过的黑(0)格涂为端口色。射线遇到非黑(0)像素或网格边界时停止（不包含终点处的非黑像素）。
4. 若射线到达了另一个环的 8 个像素之一，则该环在下一步被激活（执行步骤 2）。
5. 级联持续进行直到某一步没有新环被激活。已激活过的环不能被再次激活。
6. 最终输出中：被激活的环显示循环后的颜色，射线保留可见，未被激活的环保持原样。

**关键洞察**：边中像素的逆时针循环使端口移动到新的基数方向——级联路径不是由静态连线决定的，而是由每个环被激活前的端口位置和固定的循环规则共同决定。同一个网络在不同的起始环处启动会产生完全不同的级联路径。
