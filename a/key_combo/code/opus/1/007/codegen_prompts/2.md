## 新题 2：平移碰撞，标记叠合

**组合逻辑**：[平移/按自身宽度平移](保留原语) → [透明叠加/标记无冲突合并](创新：叠加的触发条件不再是预对齐的对象，而是平移后产生的碰撞区)

**来源原语**：平移(64a7c07e)、按自身宽度平移(64a7c07e)、边界框决定偏移(64a7c07e)、透明叠加(25e02866)、填充矩形(25e02866)、标记像素(25e02866)、共享底色(25e02866)、同尺寸对齐(25e02866)、标记无冲突合并(25e02866)

**依赖链**：每个矩形按自身宽度右移 → 移动后某些矩形在空间上重合 → 重合区域内各矩形的标记像素需要合并 → 合并冲突时按原始位置判定优先级。平移幅度依赖几何（宽度），叠加发生在平移之后的新位置，而冲突解决又回溯到原始布局。

将多个同尺寸填充矩形各自向右平移其边界框宽度的距离，在碰撞区域内将各来源矩形的内部标记像素按坐标合并。

**输入结构**：
- 约 18x20 的黑(0)背景网格。
- 3~5 个填充矩形（4-连通、实心），全部具有相同的尺寸（如 4x3 或 5x4），并共享同一种底色（如蓝(1)）。
- 每个矩形内部有 1~3 个非底色标记像素（红(2)、绿(3)、黄(4)、橙(7)等），各标记在矩形内的相对位置互不相同（不同矩形的标记不占据相同的本地坐标）。
- 矩形沿水平方向排列，相邻矩形之间的水平间距恰好等于矩形自身宽度，从而平移后产生精确重叠。部分矩形之间间距可以不等于宽度（移动后不重叠）。
- 生成约束：至少有一对矩形在平移后完全重叠；不同矩形的标记像素在本地坐标上互不冲突（保证合并无歧义）；平移后所有矩形仍完全在网格内。

**规则**：
1. 找到所有 4-连通的底色（蓝(1)）填充矩形对象。
2. 将每个矩形的所有像素（含标记）向右平移其边界框宽度的列数。原位置全部置为黑(0)背景。
3. 若平移后两个或更多矩形的边界框完全重叠，则将它们合并为一个矩形：底色像素保持底色；各来源矩形的标记像素按本地坐标叠加到输出矩形的对应位置。
4. 若两个标记像素在合并时落到同一本地坐标（生成约束保证本轮不会出现此情况，但规则需完备描述）：保留原始位置更靠左（列号更小）的那个矩形的标记色。
5. 未发生重叠的矩形平移后独立保留。输出网格尺寸与输入相同。

**关键洞察**：平移幅度来自对象自身的几何属性（宽度），碰撞是否发生取决于原始间距与宽度的关系——求解者必须先测量宽度和间距才能判断哪些矩形会重叠以及如何合并标记。
