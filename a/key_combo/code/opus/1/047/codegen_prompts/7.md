## 新题 7：竖条高度排序编码循环移位量驱动区域颜色轮换

**组合逻辑**：[尺寸排序(size_ordering)](创新：排序排名不用于标记推进，而编码循环移位步长) + [环绕角度排序(angular_order_around_center) + 循环轮换(cyclic_shift)](已有：区域颜色循环) + [裁剪(crop)](创新：条形编码区在输出中被裁掉，仅保留变换后的主区域)

**来源原语**：竖直条(vertical_bar)、条高度(bar_height)、尺寸排序(size_ordering)、标记段(marker_segment)、半段位置保持(half_position_kept) ← 48634b99；分隔结构(divider_structure)、分离区域(separated_region)、环绕角度排序(angular_order_around_center)、循环轮换(cyclic_shift)、重涂色(recolor) ← 880c1354；裁剪(crop) ← 83eb0a57

**依赖链**：标记段所在条的高度排名 → 排名值 = 循环移位步长 S → 区域按角度排序后颜色旋转 S 步 → 裁掉条形编码区；删除排名则 S 未知，删除角度排序则区域顺序不确定，删除裁剪则输出格式错误

一句话总结：从独立编码区的竖条高度排名中读取循环移位步长，将主区域中围绕分隔结构的各色区域按角度顺序旋转该步数，最后裁掉编码区。

**输入结构**：约 14x18 网格，黑(0)背景。网格纵向分为左右两部分：右侧约 4 列为"编码区"，由一条灰(5)全高竖直分隔线与左侧主区域隔开。主区域中央有一个黄(4)/橙(7)构成的十字或 T 形分隔结构，围绕分隔结构有 4-6 个单色 4-连通区域（每个区域颜色互不相同，取自蓝(1)、红(2)、绿(3)、品红(6)、栗(9)等）。编码区内有 3-5 根灰(5)一像素宽竖直条，底部对齐，高度互不相同（范围 3-9 像素）。其中恰好一根条的上半段或下半段被染为红(2)（标记段），其余条全为灰(5)。生成约束：各示例中标记段所在条的高度排名不同（即标记出现在不同高度的条上）。

**规则**：
1. 识别灰(5)竖直分隔线，左侧为主区域，右侧为编码区。
2. 在编码区中找到所有竖直条，按高度升序排列，排名从 1 开始。
3. 找到携带红(2)标记段的条，其排名即为循环移位步长 S。
4. 在主区域中，识别黄(4)/橙(7)分隔结构和围绕它的各色区域。
5. 计算每个区域的质心，以分隔结构质心为原点，按屏幕坐标系顺时针角度排序各区域。
6. 每个区域保持其像素位置不变，但接收角度序列中前 S 个位置的区域颜色：即区域 i 的新颜色 = 区域 (i - S) mod N 的原始颜色（N 为区域总数）。
7. 分隔结构不变。输出仅保留主区域（裁掉分隔线和编码区）。

**关键洞察**：编码区是一个独立的"控制面板"——竖条高度的排序关系编码了一个数值参数，而不是直接参与空间变换。标记段在条上的位置（上半/下半）不影响移位量（与参考题 48634b99 中半段位置保持的作用完全不同）。必须对比多个示例中标记所在条的排名与区域颜色旋转的步数，才能归纳出"排名=步长"这一关系。
