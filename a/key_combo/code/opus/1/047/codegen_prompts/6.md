## 新题 6：角位 L 形补全三角后按最近归属裁剪并奇偶环纹填色

**组合逻辑**：[补全(complete)](创新：多个 L 形同时补全为三角，而非单个 L 扩展到更大画布) + [最近归属(nearest_ownership)](创新：归属区域由三角顶点定义而非角标记像素) + [奇偶距离决定填色(parity_distance_fill)](创新：环纹仅在三角轮廓内部绘制，而非全网格)

**来源原语**：角位边角(corner_piece)、三角轮廓(triangle_outline)、补全(complete)、补对角线边(fill_diagonal_side)、角位置对应(corner_correspond) ← e3f79277；角标记像素(corner_marker)、同心环(concentric_ring)、最近归属(nearest_ownership)、奇偶距离决定填色(parity_distance_fill) ← d22278a0；填充(fill) ← ce22a75a

**依赖链**：L 形角位 → 补对角线边得到三角轮廓 → 轮廓围成的区域定义该角的所有权范围 → 多个三角区域重叠处用最近归属分配 → 在归属确定的区域内按 Chebyshev 距离奇偶填色；删除补全则无三角区域，删除归属则重叠区无法着色，删除奇偶则区域内为纯色（丢失关键信息）

一句话总结：将各角落的 L 形补全为直角三角形轮廓，对三角内部像素按最近角顶点归属，再以 Chebyshev 距离奇偶交替填色与留空。

**输入结构**：约 15x15 网格，黑(0)背景。2-3 个不同角落各有一个一像素厚的彩色 L 形（每个 L 触碰其所在角的两条网格边缘，颜色互不相同，取自红(2)、蓝(1)、绿(3)等）。各 L 形的臂长不同（范围 4-7 像素）。L 形仅占据角落区域，互不接触。生成约束：各 L 形臂长选取使得补全后的三角形内部区域存在部分重叠（至少两个三角的填充区域有公共像素），但重叠区面积不超过任一三角面积的一半。

**规则**：
1. 对每个 L 形，确定其所在角落（左上/右上/左下/右下）和臂长 n。
2. 补全对角线边：连接 L 的两个自由端点，用该 L 的颜色画一条像素化的直线段（Bresenham 算法），形成完整直角三角形轮廓。
3. 确定每个三角形的内部填充区域：轮廓线围成的所有像素（含轮廓本身）。
4. 对网格中每个属于至少一个三角内部的像素，计算其到每个相关三角顶点（L 所在角落点）的欧氏距离平方。将该像素归属于距离最近的角；若距离相等（平局），该像素设为黑(0)背景。
5. 对已归属的像素，计算其到归属角的 Chebyshev 距离 d。若 d 为偶数，填该角 L 形的颜色；若 d 为奇数，填黑(0)。
6. 不属于任何三角内部的像素保持黑(0)。

**关键洞察**：L 形的补全不是最终目的（与参考题 e3f79277 不同），而是为了创建空间所有权区域。同一网格上多个三角相互竞争像素归属，归属边界不是预设的直线而是由三角顶点距离动态决定的。奇偶环纹填色进一步在每个归属区域内创建非平凡的纹理——整个输出是补全、归属、填色三层逻辑的交织结果。
