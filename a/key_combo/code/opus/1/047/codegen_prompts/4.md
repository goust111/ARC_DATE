## 新题 4：括号提取构造模板图案后逐锚点印章

**组合逻辑**：[括号界定提取(bracket_delimited_extraction) + 堆叠(stacking)](创新：提取结果不作为最终输出，而作为中间模板图案) + [印章放置(stamp) + 颜色替换(color_substitution)](创新：模板非预设，而由提取动态构造) + [颜色重叠匹配(color_overlap_match)](创新：用锚点颜色匹配模板中的对应像素来确定印章对齐位置)

**来源原语**：控制像素对(control_pixel_pair)、行段(row_segment)、括号界定提取范围(bracket_delimited_extraction)、堆叠(stacking) ← 505fff84；印章放置(stamp)、模板图案(stencil_pattern)、颜色替换(color_substitution)、规则示例(rule_example) ← abc82100；颜色重叠匹配(color_overlap_match)、最大重叠确定位置(max_overlap_pos) ← d6542281

**依赖链**：控制像素对括号 → 提取行段 → 堆叠构造多行模板 → 模板中的非黑像素为印章形状 → 锚点颜色与模板像素匹配确定印章平移量 → 印章印出并重涂色；删除提取则无模板，删除印章则模板无用，删除颜色匹配则不知印章位置

一句话总结：用蓝/青控制像素对从上半区提取行段并堆叠为模板图案，在下半区将该模板对齐到每个锚点像素处印出，印章颜色取锚点颜色。

**输入结构**：约 18x14 网格，黑(0)背景。网格水平分为上下两区，由一行黄(4)分隔线隔开。上区有 3-5 行包含蓝(1)/青(8)控制像素对，每行恰有一个蓝(1)在左、一个青(8)在右，所有行中蓝-青之间的间距相同（3-5 个像素）。两控制像素之间的像素为红(2)或黑(0)构成的图案段。其余行无控制像素。下区为一片空白画布（黑(0)），上面散布着若干单独的彩色锚点像素（颜色各异，取自绿(3)、品红(6)、橙(7)等，互不相同）。生成约束：锚点之间距离足够大，保证以锚点为中心放置模板后各模板实例互不重叠；模板尺寸不超过 5x5。

**规则**：
1. 识别黄(4)分隔行，上方为提取区，下方为印章区。
2. 在提取区从上到下扫描，找到所有包含蓝(1)和青(8)控制像素的行。
3. 对每个标记行，提取蓝(1)与青(8)之间（不含控制像素本身）的像素段。
4. 将提取的段按行序从上到下堆叠，形成一个多行模板图案（仅含红(2)和黑(0)）。
5. 模板中红(2)像素位置为印章的"实心"位置，黑(0)为"透明"位置。
6. 对下区每个锚点像素：将模板的几何中心（行数和列数各取中间值，向下向右取整）对齐到锚点位置，将模板中所有红(2)位置印出，颜色替换为该锚点的颜色。
7. 分隔行和上区在输出中被裁掉，仅输出下区（含印章结果）。

**关键洞察**：模板图案不是预先存在的空间实体，而是由括号提取动态构造的中间产物——提取过程的输出成为印章过程的输入工具。这种"提取即构造"的两阶段结构在任何单一参考题中都不存在。
