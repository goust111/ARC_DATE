## 新题 1：路由围合与调色板填充

**组合逻辑**：[connect/连线](保留路由机制) + [fill/填充](创新：填充目标不是预设封闭区域，而是路由路径动态围合出的新区域) + [palette_legend/调色板图例](保留查找机制，创新：查找键由围合边界的主色决定)

**来源原语**：connect, same_color_comp, obstacle_wall, shortest_detour (from f8f52ecc); fill, enclosed_region, palette_legend, border_to_fill_mapping (from dbff022c)

**依赖链**：路由路径与墙壁共同围合出输入中不存在的封闭区域 → 封闭区域边界的主色决定调色板查找键 → 调色板提供该区域的填充色。路由改变拓扑，填充依赖拓扑，调色板间接决定颜色——三环紧扣。

将同色分量用最短路径连接后，路径与障碍墙围成的新封闭区域通过调色板图例获得填充色。

**输入结构**：
- 约 15x15 网格，背景黑(0)。
- 2-3 种前景色（如红(2)、绿(3)、蓝(1)），每种颜色恰好有 2 个 4-连通小分量（各 3-6 像素，非矩形不规则形状），同色分量之间有足够的背景空间。
- 若干青(8)墙壁段（各 1-3 像素的短直线段），散布于网格中部，作为路由障碍。墙壁布局使某些直连路径被阻断。
- 网格底部边缘有一条 2xK 调色板图例（K = 前景色数 + 1），上行是边框色（红(2)、绿(3)、蓝(1)、青(8)），下行是对应填充色（如黄(4)、橙(7)、品红(6)、灰(5)）。调色板图例不参与路由计算。
- 生成约束：路由完成后至少存在 2 个由路径和/或墙壁完全围成的封闭背景区域（区域内无格子触碰网格四边）；各同色分量对之间的最短 L 形路径唯一（无等长替代路径）。

**规则**：
1. 对每种非背景(0)、非青(8)的前景色，将其 2 个 4-连通分量用最短 L 形路径连接：路径仅穿越背景(0)格子，绘制为该前景色。L 形路径由一段水平线段和一段垂直线段组成；若两种弯折方案路径长度相同，选择第一段为水平的方案。颜色的处理顺序为：按该颜色在网格中（从上到下、从左到右扫描）首次出现的位置排序，先出现的先路由。先画好的路径对后续颜色而言也是不可穿越的障碍。
2. 路径绘制完毕后，寻找所有封闭背景区域：一个背景(0)的 4-连通区域，若其中没有任何格子位于网格的四条边界上，则为封闭区域。
3. 对每个封闭区域，统计其所有 4-邻接的非背景格子的颜色，取出现次数最多的颜色作为该区域的"边框色"。若平局，取在调色板图例中位置更靠左的颜色。
4. 在调色板图例中查找该边框色对应的填充色，将封闭区域内所有背景格子涂为填充色。
5. 从输出中移除底部调色板图例所在的 2 行（恢复为背景(0)）。

**关键洞察**：路由路径不只是视觉上的连接线——它们与墙壁共同构成拓扑围墙，创造出输入中不存在的封闭空间。求解者必须意识到"连接"操作的副作用是"围合"，而填充颜色需经调色板间接查找确定。
