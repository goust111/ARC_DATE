## 新题 5：循环缩放后重叠裁定与角标装饰

**组合逻辑**：[resize/cycle/缩放循环](保留边长循环机制) + [decorate/描边](创新：装饰的目标是经过循环变换和重叠裁定后的方块，位置和可见性依赖前两步结果) + [overlap_priority/重叠优先级](创新：源题中不存在的冲突解决机制，作为中间决策节点)

**来源原语**：resize, odd_side_square, center_point, concentric_position, side_length_cycle (from 522fdd07); decorate, foreground_square, corner_marker, diagonal_adjacency, fixed_color_diagonal_corner_decoration (from 95990924)

**依赖链**：边长循环变换（小→大或大→小）→ 变换后方块可能重叠 → 按优先级规则裁定像素归属 → 对存活方块（至少有一个可见像素）添加对角角标记。角标记的位置取决于变换后尺寸，角标记是否绘制取决于重叠裁定结果。

将奇数边正方形的边长循环变换后，按小方块优先规则解决重叠，再对存活方块添加四角固定配色标记。

**输入结构**：
- 约 20x20 网格，背景黑(0)。
- 4-6 个实心奇数边正方形，边长属于 {1, 3, 5, 7, 9}，每个方块颜色各不相同（从红(2)、绿(3)、蓝(1)、黄(4)、品红(6)、橙(7)中选取）。方块中心互不重合。
- 输入中方块互不重叠，但部分方块的位置足够接近，使得循环变换后（特别是 1→9 的大幅膨胀）会产生重叠。
- 生成约束：循环变换后至少有一对方块发生重叠；至少有一个边长为 1 的方块（将膨胀为 9x9）；所有方块中心距网格边缘至少 5 格（确保 9x9 方块和角标记不完全超出边界）。

**规则**：
1. 将画布清空为背景(0)。
2. 对每个方块，保持中心和颜色不变，将边长 n 变为 n-2（当 n > 1）；边长 1 变为 9。
3. 按变换后边长从大到小的顺序绘制方块。若两个方块变换后边长相同，先绘制中心到网格左上角 (0,0) 曼哈顿距离更大的方块。后绘制的方块覆盖先绘制的像素——因此变换后边长更小的方块优先级更高。
4. 绘制完毕后，对每个至少有一个像素在最终画布上可见的方块，在其变换后边界框四个外侧对角各添加一个角标记像素：左上对角 → 蓝(1)，右上对角 → 红(2)，左下对角 → 绿(3)，右下对角 → 黄(4)。具体位置：若方块边界框左上角为 (r1, c1)，右下角为 (r2, c2)，则四个角标记分别在 (r1-1, c1-1)、(r1-1, c2+1)、(r2+1, c1-1)、(r2+1, c2+1)。
5. 若角标记位置超出网格边界，跳过该角标记。若角标记位置与某方块本体像素重叠，角标记仍然绘制（覆盖方块像素）。若两个方块的角标记重叠在同一格子，取变换后边长更小的方块的角标记色。

**关键洞察**：边长为 1 的方块变换后膨胀为 9x9，可能吞没邻近的较小方块，但绘制顺序保证小方块"刺穿"大方块。求解者须先正确执行循环变换、再推断绘制/优先级顺序、最后在正确位置绘制角标记——三步环环相扣，特别是从 1→9 的反直觉膨胀容易误判。
