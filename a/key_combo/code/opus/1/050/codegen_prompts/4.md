## 新题 4：标记计数编码变换类型以匹配占位符

**组合逻辑**：[counting/计数](创新：计数结果不用于选择或统计，而是编码变换类型) + [rotate/旋转 + mirror/镜像](创新：变换类型由计数值动态决定，非固定) + [shape_matching/形状匹配](创新：匹配在变换后形状与占位符之间进行) + [recolor/重涂色](保留)

**来源原语**：counting, sparse_marker, interior_marker_count (from 54db823b); rotate, mirror, pattern_match, transform_match_fill (from 7df24a62); shape_matching, placeholder_object, template_object, normalized_shape_matching (from 2a5f8217)

**依赖链**：计数精灵体内部标记 → 计数值编码变换类型 → 变换精灵体形状 → 变换后形状与占位符匹配 → 匹配成功则用精灵体颜色重涂占位符。不计数则变换未知；不变换则形状不匹配；不匹配则颜色分配不明。

统计各彩色精灵体内灰色标记数量以决定旋转/翻转方式，将变换后形状与蓝色占位符匹配并重涂。

**输入结构**：
- 约 15x15 网格，背景黑(0)。
- 3-4 个不同颜色的 4-连通小精灵体（各 5-8 像素，颜色从红(2)、绿(3)、黄(4)、品红(6)中选取），每个精灵体内部嵌有 0-3 个灰(5)标记像素。灰色标记是精灵体连通体内部的格子，与精灵体的主色不同。精灵体的形状（含灰色标记位置的总掩码）在 8 种刚性变换下互不等价——即每个精灵体的形状都是不对称的。
- 3-4 个蓝(1)占位符（实心 4-连通区域，仅由蓝色像素组成），散布于网格中，与精灵体不重叠。每个占位符的归一化边界框掩码恰好等于某个精灵体经特定变换后的归一化掩码。
- 生成约束：不同精灵体的灰色标记数量互不相同（分别为 0、1、2、3 中的不同值）；每个精灵体经编码变换后恰好匹配一个占位符，匹配关系是一一对应的。

**规则**：
1. 对每个彩色精灵体，计数其内部灰(5)标记像素数量 N。
2. 根据 N 确定变换类型：N=0 不变换；N=1 顺时针旋转 90 度；N=2 旋转 180 度；N=3 水平翻转（沿垂直轴左右对称）。
3. 对精灵体的完整形状掩码（精灵体主色像素 + 灰色标记像素的并集）施加步骤 2 确定的变换。
4. 将变换后掩码归一化至最小边界框，与每个蓝(1)占位符的归一化掩码逐一比较。找到唯一匹配的占位符。
5. 将匹配的蓝(1)占位符的所有像素重涂为该精灵体的主色（非灰色的那个颜色）。原精灵体区域（含灰色标记）保持不变。

**关键洞察**：灰色标记像素身兼二职——既是形状掩码的组成部分（影响几何匹配），又是变换类型的编码器（数量决定旋转/翻转方式）。仅看单个示例无法确定"计数→变换"的映射规则（需要对比多个示例中不同标记数对应的不同变换效果）。
