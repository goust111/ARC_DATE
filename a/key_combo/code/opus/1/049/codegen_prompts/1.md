## 新题 1：形状等价驱动的定向重力

**组合逻辑**：[形状匹配/shape_match](已有) → [重力下落/gravity_drop](创新：不是列内自由下落，而是朝配对伙伴方向坠落) → [重涂色/recolor](创新：着陆时吸收伙伴颜色)

**来源原语**：shape_match + dihedral_equiv（来自 6165ea8f）、gravity_drop + collision_stop（来自 1e0a9b12、2b83f449）、recolor（来自 a8610ef7、ae58858e）、foreground_object + connected_component（来自 ae58858e）、normalized_mask（来自 6165ea8f）

**依赖链**：形状匹配的输出（配对关系）决定了哪些对象成为重力下落的目标以及下落方向；重力下落的着陆位置决定了重涂色的触发条件和目标颜色。删除形状匹配则无法确定配对，重力无目标；删除重力则对象不移动，无法着陆；删除重涂色则丢失配对信息的视觉表达。

将散落在网格中的小图形按旋转/翻转等价关系配对，配对中较高的图形向下坠落至伙伴旁并吸收伙伴颜色。

**输入结构**：约 15x15 网格，黑(0)背景。散布 6~8 个小型 4-连通单色图形（每个 3~6 像素），每个图形使用不同颜色（从蓝(1)、红(2)、绿(3)、黄(4)、灰(5)、品红(6)、橙(7)、青(8)中选取）。这些图形以配对方式存在：每对中两个图形的归一化掩码在二面体群 D4（旋转 0/90/180/270 度 + 水平/垂直/对角翻转）下等价，但颜色不同。每对中一个图形的最小行坐标严格小于另一个（即一高一低）。不同对的图形所占列范围互不重叠，保证下落路径不冲突。可能存在 0~1 个无配对的孤立图形作为干扰项。

**规则**：
1. 对每个图形计算其归一化掩码（以边界框左上角为原点的相对像素坐标集合）。
2. 两个图形配对当且仅当其中一个的归一化掩码可以通过 D4 群中某个变换映射为另一个的归一化掩码。每个图形至多属于一对。
3. 对每对配对图形，最小行坐标较小的（在网格中位置较高的）是"坠落者"，另一个是"锚定者"。
4. 坠落者整体向下平移（所有像素同时下移相同行数），直到坠落者的任意像素与锚定者的任意像素在 4-连通方向上相邻（即到达锚定者正上方紧贴的位置）。坠落者保持其原始形态不变，不旋转。
5. 坠落者着陆后，其所有像素重涂为锚定者的颜色。
6. 锚定者保持位置和颜色不变。
7. 无配对的孤立图形保持位置和颜色不变。

**关键洞察**：必须先解决形状等价匹配（这要求识别旋转/翻转等价而非仅形状相同），才能知道哪些对象移动、移向何处。等价判断需要对比多个示例中不同旋转姿态的配对来确认使用的是 D4 等价而非仅平移等价。坠落者的最终颜色泄露了配对关系，但颜色变化规则（吸收伙伴色）需要多个示例才能归纳。
