## 新题 6：几何自适应折线连接与有序覆盖

**组合逻辑**：[同色配对/same_color_pairing](已有：同色标记成对) → [曼哈顿路径/manhattan_path + 折线连接/L_path_connection](创新：折线弯折方向不再固定为"先水平后垂直"，而由标记对自身的空间长宽比动态决定) + [处理顺序决定遮挡/order_determines_block](创新：按曼哈顿距离排序处理，而非按颜色索引或固定的水平/垂直优先级)

**来源原语**：连线(draw_line/line_drawing)、同色配对(same_color_pairing)、共行或共列(shared_row_or_column)、纵线覆盖横线(vertical_over_horizontal_priority) from 070dd51e；曼哈顿路径(manhattan_path)、折线连接(L_path_connection)、起点标记(start_marker)、终点标记(end_marker) from a2fd1cf0；处理顺序决定遮挡(order_determines_block) from 1190bc91

**依赖链**：同色配对确定哪些标记相连 → 每对标记的水平距离与垂直距离之比决定折线弯折方向（较大轴优先）→ 按曼哈顿距离从小到大处理，后画的覆盖先画的。去掉配对则连接关系不明；去掉几何规则则弯折方向不确定；去掉处理顺序则交叉处颜色有歧义。

将每对同色标记以 L 形折线连接，折线弯折方向取决于该对标记的主导分离轴，按曼哈顿距离从短到长依次绘制，后绘制的路径在交叉处覆盖先绘制的。

**输入结构**：约 12x12 的黑(0)背景网格。三到四种前景色，每种颜色恰好出现两个单像素标记。每对同色标记不共行也不共列（因此每对需要 L 形折线而非直线段）。不同颜色的标记不重叠。生成约束：至少一对标记的水平距离严格大于垂直距离，且至少一对标记的垂直距离大于等于水平距离（确保两种弯折方向都出现）；至少两条路径存在交叉（使处理顺序规则可被观察）。

**规则**：
1. 按颜色将标记配对。
2. 对每对标记 (r1, c1) 和 (r2, c2)，计算：
   - 水平距离 dH = |c1 - c2|
   - 垂直距离 dV = |r1 - r2|
   - 曼哈顿距离 D = dH + dV
3. 确定每对的弯折方向：
   - 若 dH > dV：先画水平段（从一个标记沿其行画到另一标记的列），再画垂直段（从该拐点沿列画到另一标记）。即"水平优先"。
   - 若 dV >= dH：先画垂直段（从一个标记沿其列画到另一标记的行），再画水平段（从该拐点沿行画到另一标记）。即"垂直优先"。
   - 具体选择哪个标记作为起点：以行坐标较小的标记作为起点；行坐标相同时以列坐标较小的作为起点。
4. 按曼哈顿距离 D 升序排列所有配对。D 相同时，取起点标记行坐标较小者优先；仍相同则取起点列坐标较小者优先。
5. 按此顺序依次绘制每对的 L 形路径，颜色为该对标记的颜色。两段线均包含端点。每个新绘制的像素覆盖该位置先前的任何颜色（包括之前配对的路径）。
6. 最后，确保所有原始标记像素恢复为其原始颜色（标记像素不被路径覆盖）。

**关键洞察**：L 形折线的弯折方向不是固定的（不像参考题 a2fd1cf0 中始终水平优先），而取决于每对标记自身的空间构型——"宽"的对先水平再垂直，"高"的对先垂直再水平。仅凭一个只含单一长宽比类型的示例无法推断完整规则——求解者必须观察到两种构型并归纳出"主导轴优先"的通用法则。覆盖顺序增添了第二层推理：短路径先画可能被长路径部分覆盖，交叉处的颜色揭示了处理次序。
