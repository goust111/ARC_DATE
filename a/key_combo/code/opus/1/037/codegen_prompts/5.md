## 新题 5：灰轨裁剪与角标编码的旋转对称补全

**组合逻辑**：[裁剪/crop + 竖直线段/vertical_segment + 角标记像素/corner_marker](已有：灰轨定裁剪范围) → [角标记像素 → 旋转方向编码](创新：角标不再仅标记边界，其对角占位模式编码旋转方向) → [对称补全/symmetry_completion + 旋转/rotate](创新：旋转方向不再固定为顺时针，而由输入几何特征动态决定)

**来源原语**：裁剪(crop)、竖直线段(vertical_segment)、角标记像素(corner_marker)、线段定裁剪列范围(lines_set_crop_columns)、扩展含角标行(row_includes_corner_markers)、边界(boundary) from 3f7978a0；对称补全(symmetry_completion)、旋转(rotate)、缺失部分标记新色(missing_marked_new_color)、旋转对称(rotational_symmetry) from 1b60fb0c；忽略干扰项(ignore_distractors) from cd3c21df

**依赖链**：灰轨 + 青角标定义裁剪区域（crop）→ 两个青角标占据裁剪矩形四角中的哪条对角线编码旋转方向 → 裁剪区域内的蓝色形状按推断方向旋转 90 度补全缺失部分。去掉裁剪则干扰像素使对称中心不可判断；去掉角标解读则旋转方向未知；去掉对称补全则形状不完整。角标像素同时服务于空间定界和参数编码，单一几何特征承担双重角色。

裁剪灰轨之间（含青色角标标定范围）的区域，再按角标对角占位所编码的方向补全内部蓝色形状的旋转对称性。

**输入结构**：约 16x16 的黑(0)背景网格，网格中散布 5-10 个青(8)干扰像素（随机位置，全部位于灰轨区域外部）。两根竖直灰(5)线段（每根 4-8 像素高，严格竖直排列）分别作为左轨和右轨。在灰轨顶端上方一行和底端下方一行，各有若干青(8)角标像素位于灰轨对应的列位置——恰好两个角标占据裁剪矩形四角中的一条对角线：要么 {左上, 右下}，要么 {右上, 左下}。灰轨之间（含角标行）的区域内有一个蓝(1)形状，该形状具有近似 4 重旋转对称性，但缺少约四分之一的像素（缺失部分为黑色）。形状的对称中心位于裁剪区域的几何中心。生成约束：裁剪区域为正方形或近正方形（行数与列数差不超过 1）；蓝色形状的三个象限部分存在且互相通过 90 度旋转吻合；缺失象限明确可辨。

**规则**：
1. 检测两根竖直灰色线段，按列位置从左到右排序。裁剪区域的列范围为左轨列到右轨列（含），行范围为较长线段顶端上方一行到底端下方一行（夹紧至网格边界）。
2. 在裁剪矩形的四个角位置中找到恰好两个青色像素（它们位于同一条对角线上）。
3. 确定旋转方向：
   - 若青标位于左上角和右下角：补全旋转方向为顺时针 90 度。
   - 若青标位于右上角和左下角：补全旋转方向为逆时针 90 度。
4. 在裁剪区域内，以蓝色形状边界框的几何中心作为对称中心。
5. 将每个蓝色像素绕对称中心按确定方向旋转 90 度。
6. 若旋转后的位置在裁剪区域内且当前为黑色（空），则涂为红(2)。若该位置已有蓝色像素，则保持蓝色不变。
7. 输出仅为裁剪区域（包含灰轨、青角标、蓝色形状和红色补全像素）。裁剪区域外的一切（含青色干扰像素）被丢弃。

**关键洞察**：青色角标像素表面上只是边界标记（如参考题 3f7978a0），但它们的对角占位模式隐含了旋转补全的方向信息。灰轨外的青色像素是纯干扰项。求解者必须同时在空间维度（定义裁剪边界）和符号维度（解读旋转方向）使用角标——单一几何特征承担双重语义。

    sigs.add(hashlib.md5(inp.tobytes() + str(inp.shape).encode()).hexdigest())
print("variants", len(sigs))
