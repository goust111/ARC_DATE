## 新题 1：同心环异或选层与深度反转着色

**组合逻辑**：[异或/xor](创新：逐层比较两组同心环的颜色异同，而非像素级异或) + [深度排序/depth_order] + [层色序内外翻转/reverse_layer_colors](创新：仅对"异"层取反转深度读色) + [重涂色/recolor]

**来源原语**：异或/xor(3428a4f5), 同心方框层/concentric_layer(85c4e7cd), 深度排序/depth_order(85c4e7cd), 层色序内外翻转/reverse_layer_colors(85c4e7cd), 分隔行/separator_row(3428a4f5), 重涂色/recolor(85c4e7cd)

**依赖链**：层深度识别为异或比较提供逐层配对 -> 异或结果划分"同层/异层" -> 异层从左侧面板取反转深度对应色 -> 最终涂色同时依赖异或结果和深度反转映射，二者缺一不可

将两组同心矩形环按深度逐层异或比较，同色层清空、异色层从左侧面板的镜像深度取色，输出一组新的同心环。

**输入结构**：约 11x23 的网格。中央有一列黄(4)分隔线，将网格分为左右两个等大面板（各约 11x11）。每个面板由同心矩形环组成——所有距最近边缘相同曼哈顿距离的像素共享同一颜色，形成 N 层嵌套环（N 约 4-6 层）。两个面板的层数相同，但各层颜色不同。两面板使用的颜色从红(2)、蓝(1)、绿(3)、灰(5)、品红(6)、橙(7)、青(8) 中选取，保证除黄(4)外无颜色冲突。生成约束：两面板至少有 2 层颜色不同、至少 1 层颜色相同，以确保异或结果非平凡。

**规则**：
1. 定位黄(4)分隔列，将网格拆为左面板和右面板（不含分隔列）。
2. 对每个面板，按距最近边缘的曼哈顿距离识别深度层：depth 0 为最外环，depth N-1 为最内层。记录左面板色序 L[0..N-1] 和右面板色序 R[0..N-1]。
3. 逐层比较：若 L[d] == R[d]，标记 depth d 为"同层"；若 L[d] != R[d]，标记为"异层"。
4. 输出为一个与单面板等大的同心环结构（不含分隔列）：
   - "同层"深度 d 的所有像素涂为黑(0)。
   - "异层"深度 d 的所有像素涂为 L[N-1-d]（即左面板中深度镜像位置的颜色）。
5. 输出尺寸等于单面板尺寸。

**关键洞察**：异或比较仅决定哪些层被激活，但被激活层的着色不来自原始深度，而来自左面板的反转深度——求解者必须同时发现异或筛选规则和深度反转映射规则，仅看单个示例容易把反转映射误读为直接取色。

7. 代码风格参考 `ARC_code`：使用 `numpy`，必要时使用本地 helper，但目标文件应能被 `SourceFileLoader` 直接加载。
8. 可以在目标目录放公共 helper 文件，但若只实现一道题，优先保持目标文件自包含，减少额外依赖。
