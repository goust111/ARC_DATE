## 新题 6：条棒旋转后按标记色着色与长度优先重叠裁决

**组合逻辑**：[旋转/rotate] + [朝向交换长度保持/orient_swap_keep] + [中心点不变/center_fixed] -> [重涂色/recolor](创新：由端点标记色决定整条棒的新颜色) -> [计数/counting](创新：长度比较解决重叠冲突) + [擦除/erase]

**来源原语**：旋转/rotate(f0f8a26d), 朝向交换长度保持/orient_swap_keep(f0f8a26d), 中心点不变/center_fixed(f0f8a26d), 单像素宽条/thin_bar(f0f8a26d), 标记像素/marker_pixel(e681b708, 477d2879), 重涂色/recolor(477d2879), 计数/counting(e681b708), 擦除/erase(93c31fbe)

**依赖链**：标记像素标识每根棒并指定新颜色 -> 旋转改变棒的朝向和占据的像素 -> 旋转后产生的重叠需要比较棒长度来裁决 -> 长度信息来自原始棒（旋转不改变长度）；删去标记则不知道着色，删去旋转则不产生冲突，删去长度比较则重叠像素颜色不确定

每根单色棒在端点有一个彩色标记；所有棒绕各自中心旋转 90 度后，整条棒着为其标记色，重叠处由较长棒胜出。

**输入结构**：约 19x19 的黑(0)背景网格。5-8 根灰(5)单像素宽条，每根为水平或垂直直线，奇数长度（3、5、7 或 9 像素）。每根棒的一个端点处（4-邻接的下一格，不是棒本身的像素）放有一个标记像素，颜色从红(2)、蓝(1)、绿(3)、黄(4)、橙(7)、青(8)中选取，不同棒的标记颜色可以相同也可以不同。生成约束：棒的原始位置互不重叠；每根棒旋转后的边界框不超出网格边界；至少有两对棒在旋转后会产生像素重叠，且这两对中至少一对涉及不同标记颜色和不同长度。

**规则**：
1. 识别所有灰(5)的 4-连通单像素宽条及其长度和中心点（奇数长度的正中像素）。
2. 对每根棒，找到其某个端点 4-邻接的非灰非黑标记像素，记录该标记颜色为这根棒的"目标色"。
3. 清空画布至全黑(0)。擦除所有原始标记像素。
4. 对每根棒，保持中心点不变、长度不变，交换朝向（水平变垂直，垂直变水平），计算旋转后的像素坐标集合。
5. 将每根旋转后的棒以其目标色绘制到画布上。
6. 若某像素被多根棒覆盖（重叠）：
   - 取这些棒中长度最大者的目标色。
   - 若长度最大者有多根且目标色不同，取其中原始中心点在阅读序（先行后列）中最靠前者的目标色。
7. 输出画布。

**关键洞察**：标记像素既是棒的身份标签又是目标着色指令，而旋转操作创造了原始布局中不存在的空间冲突；冲突的裁决依赖于棒的长度属性，而该属性在旋转后虽然不变但需要回溯到原始棒来测量——三个信息层（标记色、旋转位置、原始长度）必须同时协调。
