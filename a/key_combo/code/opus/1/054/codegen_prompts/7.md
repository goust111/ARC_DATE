## 新题 7：朝向决定字形印章填入十字缺口

**组合逻辑**：[矩形边框 + 十字缺口 + 朝向对应边色 + 开口朝向决定色](已有，创新：朝向不再决定单一颜色填充，而是选择字形字典条目) ⊗ [图案印章 + 字形字典 + 编码映射](已有，创新：字形不再由控制像素颜色触发，而是由缺口的空间朝向触发) → [裁剪/clip](已有)

**来源原语**：矩形边框/rectangular_frame（5b37cb25）、十字缺口/plus_notch（5b37cb25）、朝向对应边色/facing_side_color（5b37cb25）、开口朝向决定色/open_side_color（5b37cb25）、图案印章/stamp_glyph（dfadab01）、字形字典/glyph_dictionary（dfadab01）、编码映射/encoding_map（dfadab01）、填充/fill、裁剪/clip（dfadab01）

**依赖链**：每个十字缺口的开口朝向决定了它面向矩形边框的哪一侧——若不分析缺口的空间结构就无法确定朝向。边框侧面的颜色与字形字典的条目配对——若不知道朝向就无法查字典。字形需要被印入缺口区域并裁剪到缺口边界——若不知道字形就无法填充。三层决策逐级依赖。

检测内部对象上的十字缺口朝向哪侧边框，用该侧颜色查字形字典，将对应字形印入缺口。

**输入结构**：约 15x15 的网格。最外一圈为矩形边框，厚度 1 像素，四条边各为不同颜色（如上边蓝(1)、右边红(2)、下边绿(3)、左边黄(4)），四角像素为灰(5)。边框内部背景为黑(0)。内部有一个橙(7)色前景对象（4-连通，约 20~30 像素的不规则形状）。对象的边界上有 2~4 个十字形（加号形）的背景缺口——每个缺口由 5 个黑(0)像素组成十字形，十字的一个臂伸向边框方向（开口侧），对面三个方向被前景对象像素包围。网格外某个区域（如边框下方额外的行）有一个字形字典：4 个小型图案（每个 3x3），分别用蓝(1)、红(2)、绿(3)、黄(4)绘制，水平排列并用灰(5)分隔，展示四种方向对应的字形。生成约束：每个十字缺口恰好面向一侧边框（开口侧与边框之间无其他前景像素阻隔）；字形字典中每种颜色的 3x3 图案互不相同。

**规则**：
1. 识别矩形边框的四侧颜色：上侧 C_up、右侧 C_right、下侧 C_down、左侧 C_left。
2. 读取字形字典：颜色 C 对应 3x3 字形 G(C)。
3. 找到前景对象中的所有十字缺口。对每个缺口，判断其开口方向（十字的哪个臂延伸到无前景像素包围的一侧，即朝向边框的方向）。
4. 确定该朝向面对的边框颜色 C_dir。从字典中取出 G(C_dir)。
5. 将 G(C_dir) 以缺口中心为中心印入缺口区域。字形像素中的非背景像素覆盖缺口的黑(0)像素；如果字形超出缺口的 5 像素范围，超出部分不绘制（裁剪到缺口边界）。
6. 字形字典区域在输出中不保留——输出裁剪为仅包含边框及其内部的矩形。

**关键洞察**：字形字典的颜色键不是直接匹配缺口的颜色（缺口本身是黑色的），而是匹配缺口朝向所面对的边框侧颜色——这一间接映射需要理解空间朝向与颜色之间的关联。
