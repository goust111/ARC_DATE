## 新题 3：面板差异生成对称损伤图

**组合逻辑**：[逐像素比较](保留：左右面板对齐比较) → [差异分类着色](创新：差异位不再标红/蓝，而是统一标为绿色占位符) → [对称补全](创新：不再以给定的绿色为起点，而是由比较步骤产生绿色，再做双轴对称修复)

**来源原语**：逐像素比较/pixel_comparison(P10-d47aa2ff), 面板/panel(P10-d47aa2ff), 面板对齐/panel_align(P10-d47aa2ff), 分隔列/separator_col(P10-d47aa2ff), 对称补全/symmetry_completion(P13-903d1b4a), 双轴反射轨道/two_axis_orbit(P13-903d1b4a), 占位标记/placeholder_marker(P13-903d1b4a), 轨道内唯一可见色/unique_color_in_orbit(P13-903d1b4a)

**依赖链**：面板比较确定哪些格点"可信"、哪些是"损伤"→ 损伤格点被标记为绿色占位符 → 双轴对称约束从可信格点恢复损伤格点的颜色。跳过比较则不知道哪些格点损伤；跳过对称补全则损伤格点无法恢复。两步产生的信息类型完全不同（比较产出"可信/损伤"二分类，对称产出"具体颜色"），不可互替。

比较两个面板的像素，将一致处保留、差异处标为损伤占位符，再利用底层图案的双轴对称性修复所有损伤格点。

**输入结构**：网格列数为奇数（约 11-17 列），行数约 7-11。正中间有一列宽度为 1 的橙(7)分隔列，将网格分为宽度相等的左面板和右面板。两个面板的背景色均为黑(0)。底层设计是一个具有左右对称和上下对称性的彩色图案（使用 2-3 种非黑非橙非绿的颜色，如红(2)、蓝(1)、黄(4)等）。左面板展示该图案的一个"带噪声"版本：其中 2-4 个像素被随机替换为错误颜色或背景。右面板展示同一图案的另一个"带噪声"版本：在不同的 2-4 个位置有错误。两个面板不在同一位置同时出错——即对于每个设计位置，至少一个面板给出正确颜色。生成约束：底层图案严格满足水平和垂直两轴反射对称；每个对称轨道中至少有一个位置在两个面板中都正确。

**规则**：
1. 移除橙(7)分隔列。将左面板和右面板逐像素对齐比较。
2. 若两面板在位置 (r, c) 处颜色相同且为非背景色：输出该颜色（可信前景）。
3. 若两面板在位置 (r, c) 处均为背景(0)：输出背景(0)。
4. 若两面板在位置 (r, c) 处颜色不同（包括一方为背景另一方为前景，或两方为不同前景色）：输出绿(3)作为损伤占位符。
5. 现在得到一个单面板尺寸的中间网格，包含可信像素和绿(3)占位符。该中间网格在忽略绿色后具有双轴反射对称性。
6. 对每个绿(3)格点，找到它在水平反射和垂直反射下的轨道（最多 4 个位置）。轨道中恰好有一个非绿颜色出现在可信位置上。将该绿格点替换为该颜色。
7. 输出为修复后的单面板图案（无分隔列、无绿色）。

**关键洞察**：面板比较不是最终答案——它产生一个"损伤中间态"，必须再由对称约束修复。两个面板是同一对称设计的两个"有噪观察"；一致处提供可靠数据，不一致处标记损伤，而底层对称性恢复其余部分。单个示例可能让人以为只需取两面板的"或"，但当两面板在同一位置都给出前景（只是颜色不同）时，简单取并集会出错，必须走对称修复路径。

1. `main(grid)` 必须实现新题描述中的确定性转换规则，不能只识别 `generate_input()` 的固定模板。
2. `generate_input()` 必须随机生成多样样例，不能固定死。随机维度应覆盖：网格大小、对象数量、位置、颜色、方向、形状参数或关键分支。
3. 生成器必须保证输入满足 `main()` 的隐式假设：对象不重叠、不越界、特殊标记唯一或可区分、匹配关系无歧义、关键分支出现概率相同。
4. 禁止把 ARC 颜色 id 、亮度、拼写等当作人类不可见的数值语义参与排序、大小比较或隐藏映射。颜色变化必须有可见结构线索。注意颜色亮度、拼写等也是不可见信息，若描述中出现违规的颜色id或者亮度，可自行使用少量的固定颜色替代，但注意生成时要在三个以内输入输出网格中对所有变换100%覆盖度。

6. 若规则有多个分支，生成器不能长期固定成一个分支；应让分支在随机样例中合理出现。分支概率不必平均——难以发现的隐蔽分支（如少数情况下才触发的特殊规则）应适当提高出现概率，确保在 3 个训练示例中至少出现一次，否则求解者无法归纳该规则。对于颜色映射类规则，确保 2 个左右的示例即可覆盖所有映射关系（每种颜色→颜色的映射至少在某个示例中出现过）。
7. 代码风格参考 `ARC_code`：使用 `numpy`，必要时使用本地 helper，但目标文件应能被 `SourceFileLoader` 直接加载。
8. 可以在目标目录放公共 helper 文件，但若只实现一道题，优先保持目标文件自包含，减少额外依赖。
