## 新题 6：宏列按围合空洞数排序

**组合逻辑**：[列排序](保留：移动宏列的中心像素列) + [围合检测](创新：不再在二维网格上检测封闭背景区域，而是在一维中心像素序列中检测被夹的空洞段) → 排序键从"填充数"变为"空洞数"

**来源原语**：列排序/column_sorting(P6-42a15761), 宏单元/macro_cell(P6-42a15761), 中心像素列/center_pixel_col(P6-42a15761), 间隔列/gutter_column(P6-42a15761), 轮廓围合/contour_enclosure(P17-753ea09b), 封闭背景区域/enclosed_bg_region(P17-753ea09b), 计数/counting(P7-ff28f65a)

**依赖链**：宏网格结构决定中心像素的提取 → 一维空洞检测（围合概念的一维化）产出每列的空洞计数 → 计数作为排序键驱动列重排。删除宏网格结构则无法提取中心像素；删除空洞检测则无排序键；删除列排序则空洞信息无处体现。

在宏网格中提取每个宏列的中心像素序列，计算其中被填充像素两侧夹住的空洞段数，按空洞数从多到少重排宏列。

**输入结构**：一个矩形宏网格，由红(2)的 3x3 宏单元组成，宏单元之间以 1 像素宽的黑(0)间隔列和间隔行分隔。宏网格有 5-6 个宏列和 5-7 个宏行。每个宏单元的中心像素要么是红(2)（填充），要么是黑(0)（空）。整体网格尺寸约为 (宏行数x4-1) x (宏列数x4-1)，例如 6 宏行 x 5 宏列 = 23x19。生成约束：各宏列的空洞数互不相同（确保排序结果唯一）；至少一个宏列有 0 个空洞，至少一个宏列有 2 个以上空洞。

**规则**：
1. 解析宏网格结构。提取每个宏列的中心像素序列（从上到下），形成一维二值序列（填充/空）。
2. 对每个宏列的一维序列，计算"空洞数"：一个空洞定义为一个极大连续空段，且该段的上方和下方都紧邻填充像素。紧贴序列顶端或底端的连续空段不算空洞（它们是开放端，非围合）。例如：[填, 空, 填, 空, 填] 有 2 个空洞；[空, 填, 填, 填, 空] 有 0 个空洞；[填, 空, 空, 填, 空] 有 1 个空洞。
3. 按空洞数从大到小排序宏列。空洞数相同时（由生成约束保证不会发生），按原始从左到右顺序保持不变。
4. 将整个中心像素列移动到排序后的位置。红(2)宏单元边框和黑(0)间隔保持不动——仅中心像素跟随排序移动。

**关键洞察**：排序的键不是填充像素的数量（参考题 P6 的做法），而是填充像素之间"夹住"的空洞段数。一个全满的列（5 个填充、0 个空洞）排名低于一个有很多间断的列。这是"围合"概念从二维到一维的降维应用。仅看单个示例时，排序标准可能被误认为是填充数或某种外观特征，需要对比多个示例才能发现空洞计数规则。
