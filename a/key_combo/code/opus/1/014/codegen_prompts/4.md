## 新题 4：标记像素双重角色——选择门控与旋转补全种子

**组合逻辑**：[选择(selection)](按标记数最少选取) → [对称补全(symmetry_complete)](标记位置为旋转种子) + [裁剪(crop)]

**来源原语**：selection / minimum_marker_count / foreground_rectangle (7bb29440), symmetry_complete / rotational_symmetry / four_fold_closure (e40b9e2f), crop (7bb29440/42f14c03), marker_pixel (7bb29440/3e980e27)

**依赖链**：标记像素的数量决定选哪个方块（最少标记者胜出），而同一批标记像素的空间位置又作为旋转补全的种子。改变任一标记像素都同时影响选择判断和补全结果，两个逻辑通过同一组数据紧耦合。

从多个正方形区域中选出标记最少的那个，然后将其内部的标记像素图案做四次旋转补全后裁剪输出。

**输入结构**：约 18x18 的网格，黑(0)背景。3~4 个等大的单色实心正方形（边长 5~7），颜色互不相同（如蓝(1)、绿(3)、黄(4)），彼此不重叠，间距 >= 2。每个正方形内部有若干红(2)标记像素（1~4 个不等），它们替换了正方形填充色的对应位置。生成约束：恰好一个正方形的标记数严格最少（无并列）；标记最少的正方形中，标记像素关于正方形中心做 90/180/270 度旋转后落在的位置当前为该正方形的填充色（即旋转不冲突——不会旋转到另一个标记像素上或正方形外）。

**规则**：
1. 识别所有非黑色实心正方形区域。每个正方形有一个主导填充色和若干红(2)标记像素。
2. 统计每个正方形中红色标记像素的数量。选出标记数严格最少的那个正方形。
3. 在被选正方形中，以正方形的几何中心为旋转中心，对每个红色标记像素计算其 90、180、270 度顺时针旋转位置。将这些旋转位置也涂为红(2)（如果该位置已经是红色则不变）。
4. 裁剪被选正方形的边界框，输出该裁剪区域（包含填充色底色和旋转补全后的红色图案）。

**关键洞察**：标记像素承担双重角色——作为计数指标决定"选哪个对象"，又作为空间种子决定"补全出什么图案"。增删一个标记像素可能同时改变被选对象的身份和补全输出的形态，这种双重敏感性是本题核心。

## 实现要求

1. `main(grid)` 必须实现新题描述中的确定性转换规则，不能只识别 `generate_input()` 的固定模板。
2. `generate_input()` 必须随机生成多样样例，不能固定死。随机维度应覆盖：网格大小、对象数量、位置、颜色、方向、形状参数或关键分支。
3. 生成器必须保证输入满足 `main()` 的隐式假设：对象不重叠、不越界、特殊标记唯一或可区分、匹配关系无歧义、关键分支出现概率相同。
4. 禁止把 ARC 颜色 id 、亮度、拼写等当作人类不可见的数值语义参与排序、大小比较或隐藏映射。颜色变化必须有可见结构线索。注意颜色亮度、拼写等也是不可见信息，若描述中出现违规的颜色id或者亮度，可自行使用少量的固定颜色替代，但注意生成时要在三个以内输入输出网格中对所有变换100%覆盖度。
5. 输出样例要视觉清晰，人类必须能从输入输出对中肉眼辨认出规律。具体要求：避免对象粘连、覆盖关系混乱、同一像素多重语义；不同逻辑步骤产生的结果不要大面积层叠在一起导致无法分辨哪个颜色属于哪个步骤；输入中各元素之间保持足够间距，输出中新增的标记/填充/路径等应与背景和已有元素在颜色上有明显区分；若规则涉及多层叠加，生成时控制对象密度和尺寸，确保叠加区域只占少数像素而非铺满整个网格。
6. 若规则有多个分支，生成器不能长期固定成一个分支；应让分支在随机样例中合理出现。分支概率不必平均——难以发现的隐蔽分支（如少数情况下才触发的特殊规则）应适当提高出现概率，确保在 3 个训练示例中至少出现一次，否则求解者无法归纳该规则。对于颜色映射类规则，确保 2 个左右的示例即可覆盖所有映射关系（每种颜色→颜色的映射至少在某个示例中出现过）。

8. 可以在目标目录放公共 helper 文件，但若只实现一道题，优先保持目标文件自包含，减少额外依赖。
