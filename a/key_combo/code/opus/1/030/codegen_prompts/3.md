## 新题 3：引导掩码选定空心体后按孔洞形状匹配填色

**组合逻辑**：[裁剪/crop + 包围框包含/bbox_containment](保留：引导掩码选定唯一目标) → [形状匹配/shape_matching + 形状对应/shape_correspondence](创新：匹配的不是物体外形，而是裁剪后物体的内部孔洞形状) → [填充/fill](创新：用匹配到的模板颜色填充孔洞)

**来源原语**：裁剪/crop、引导掩码/guide_mask、空心精灵体/hollow_sprite、包围框包含/bbox_containment、唯一被框选对象/uniquely_enclosed（来自 bf699163）；填充/fill、形状匹配/shape_matching、模板/template、封闭孔洞/enclosed_hole、形状对应/shape_correspondence、匹配形状决定填色/shape_determines_fill（来自 93b4f4b3）

**依赖链**：裁剪步骤决定了哪个空心体被选中，从而暴露出其特定的内部孔洞形状——这个孔洞形状是形状匹配的输入。形状匹配的输出（匹配到的模板颜色）又是填充步骤的输入。三步构成信息变换链：空间选择 → 几何识别 → 颜色赋值。删除裁剪则不知道检查哪个孔洞；删除形状匹配则不知道用什么颜色；删除填充则识别结果无处落地。

用引导掩码从多个空心体中选出目标，裁剪后将其内部孔洞的形状与模板匹配，用匹配到的模板颜色填充孔洞并输出。

**输入结构**：约 20x20 网格，背景为黑(0)。网格上散布 3-5 个空心精灵体，每个是一种非黑单色（如红(2)、蓝(1)、绿(3)、黄(4)）的连通外壳（4-连通，5-10 像素），内部有一个独特形状的黑色封闭孔洞（2-5 像素）。各空心体的外壳形状可以相似，但内部孔洞形状两两不同。一组灰(5)稀疏像素构成引导掩码，其边界框恰好完全包含且仅包含一个空心体。在网格右下角区域，有 3-5 个微型实心模板对象（每个 2-5 像素，4-连通，颜色各不相同，取自橙(7)、品红(6)、栗(9)等），其形状与各空心体的孔洞形状一一对应（允许旋转/反射等价）。生成约束：各空心体的边界框互不重叠且与模板区域不重叠；引导掩码的边界框仅包含一个空心体；每个孔洞形状在旋转/反射下唯一匹配一个模板。

**规则**：
1. 识别所有空心精灵体：每个是一个非黑色的 4-连通前景区域，内部包含一个被该区域完全包围的黑色封闭孔洞区域。
2. 收集所有灰(5)像素作为引导掩码，计算其边界框。找到边界框完全被引导掩码边界框包含的唯一空心体。
3. 将该空心体及其孔洞裁剪到紧凑边界框。
4. 提取孔洞区域的形状（黑色连通区域），归一化到其自身的紧凑边界框。
5. 将归一化后的孔洞形状与右下角的每个模板对象（也归一化到各自边界框）在所有 4 种旋转 x 2 种反射下比较，找到唯一匹配的模板。
6. 用该模板的颜色填充裁剪结果中的孔洞像素。
7. 输出为裁剪后的紧凑网格（仅包含填充后的空心体，背景为黑色）。

**关键洞察**：引导掩码选择的是哪个空心体被裁剪（来自 bf699163 的选择机制），但输出颜色取决于被选空心体的内部孔洞几何形状与外部模板的匹配（来自 93b4f4b3 的匹配机制）。求解者容易误以为匹配的是空心体的外壳形状——必须对比多个示例（不同示例中被选空心体的外壳相似但孔洞不同，输出颜色随孔洞而变）才能发现匹配对象是孔洞而非外壳。
