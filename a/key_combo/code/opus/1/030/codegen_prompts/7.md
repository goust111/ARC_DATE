## 新题 7：边缘条距离延伸与列一致性筛选

**组合逻辑**：[延伸/extend + 朝近端扩展/toward_nearer_expand](保留：每个控制像素向近端边缘条延伸一格) → [擦除/erase](创新：擦除条件不是固定的中轴位置，而是由延伸结果的列内一致性动态决定)

**来源原语**：延伸/extend、边缘条/edge_bar、控制像素/control_pixel、标记在两边之间/marker_between_edges、朝近端扩展/toward_nearer_expand（来自 642248e4）；擦除/erase（来自 d23f8c26）

**依赖链**：延伸步骤为每列生成方向信息（朝上延伸 = 红色标签，朝下延伸 = 蓝色标签）。擦除步骤的触发条件消费这些方向信息——只有列内所有延伸方向一致时该列才保留，否则擦除非边缘条像素。删除延伸则无方向信息可判断一致性；删除擦除则延伸结果中的矛盾列无法处理。延伸的输出数据直接构成了擦除的触发条件。

每个控制像素向较近的边缘条延伸一格（用该条颜色），然后擦除所有延伸方向不一致的列中的非边缘条像素。

**输入结构**：约 15x11 网格（奇数列），背景为黑(0)。最顶行全为红(2)（上边缘条），最底行全为蓝(1)（下边缘条）。两条边缘条之间（中间 13 行）散布若干黄(4)控制像素（每列 0-3 个不等，总数 8-15 个）。生成约束：至少存在 2 列仅有朝同方向延伸的控制像素（纯向上或纯向下），以及至少 2 列同时有朝两个方向延伸的控制像素，以便筛选规则可观测；没有控制像素的列视为"一致"（无矛盾，保留）；没有控制像素恰好在正中间行（到两条边缘条距离相等）的情况。

**规则**：
1. 对每个黄(4)控制像素，计算其到上边缘条（第 0 行）的行距 d_top 和到下边缘条（最后一行）的行距 d_bot。
2. 若 d_top < d_bot，在该控制像素正上方一格画一个红(2)像素（朝上延伸）。若 d_bot < d_top，在该控制像素正下方一格画一个蓝(1)像素（朝下延伸）。若 d_top == d_bot（生成约束排除此情况），则同时向上画红色、向下画蓝色。
3. 延伸完成后，逐列检查：在某一列中，收集所有因延伸而新增的非背景像素的颜色集合。若该集合为空（该列无控制像素，无延伸）或仅包含一种颜色（所有延伸方向一致），该列保留不变。若该集合同时包含红(2)和蓝(1)（延伸方向不一致），则将该列中除顶行红色和底行蓝色外的所有像素设为黑色背景（擦除该列的控制像素和延伸像素）。
4. 输出与输入同尺寸。顶行和底行始终保留。

**关键洞察**：擦除规则不是基于列的固定位置（如 d23f8c26 的中轴列），而是基于延伸操作产生的方向一致性——一种涌现条件。求解者容易误以为某些固定列被保留，但实际上保留与否取决于该列控制像素的空间分布。必须对比多个示例（控制像素分布不同导致不同列被保留/擦除）才能归纳出一致性筛选规则。
