## 新题 8：按原型分组重排色块条带并互换原型

**组合逻辑**：[排序/sort + 整块移动保持内容/block_move_intact](创新：排序依据不是标记行顺序或块内颜色，而是块内精灵的原型归属) + [替换/replace + 互换原型/toggle_to_alternate_prototype](保留：每个精灵切换为对立原型)

**来源原语**：排序/sort、色块条带/color_stripe、整块移动保持内容/block_move_intact（来自 f18ec8cc）；替换/replace、缩放/scale、原型精灵/prototype_sprite、锚点区域/anchor_region、原型配对/prototype_pairing、互换原型/toggle_to_alternate_prototype（来自 c7f57c3e）

**依赖链**：原型识别同时服务于两个操作——它既决定了排序的分组依据（A 类在前、B 类在后），又决定了替换的目标（A 换 B、B 换 A）。排序改变了条带的空间位置，替换改变了条带内的精灵内容，两者共享原型识别这一前提步骤但各自产生不同的输出效果。在最终输出中，左侧条带包含的是原来属于 A 类的条带（因排序移到左侧），但其中的精灵已被切换为 B 类原型——这种"位置按旧类排、内容按新类换"的交叉使输入输出关系变得非直观。

将竖直色块条带按其内部精灵的原型归属分为两组重排（A 组在左 B 组在右），同时将每个精灵切换为对立原型。

**输入结构**：约 12x20 网格，被等宽的 4-5 条竖直色块条带填满（每条宽约 4-5 列）。每条条带有自己的主色（取自红(2)、蓝(1)、绿(3)、黄(4)、品红(6)，各不相同）填充大部分区域。每条条带内部包含一个由灰(5)和栗(9)两种颜色构成的小精灵图案（4-连通，4-10 像素）。这些精灵属于两种原型模式之一（称为 P 和 Q），可能以不同的整数缩放倍数出现（1x 或 2x）。最小尺寸的实例定义原型的基础形状。每个原型内部有一小块"锚点区域"像素（使用两种颜色中的一种，如灰(5)），用于缩放对齐。生成约束：每种原型至少出现 1 次；条带总数为 4 或 5；不同条带中的精灵缩放倍数可以不同但原型归属明确；各条带的主色两两不同。

**规则**：
1. 识别两种原型模式 P 和 Q：找到包含最小精灵（边界框面积最小）的条带，其精灵形状为一种原型的基础形状。找到另一种不同形状的最小精灵，其为另一种原型的基础形状。
2. 对每条条带，将其内部精灵归一化到基础缩放（除以其整数缩放因子），与 P 和 Q 比较，确定该条带属于 P 组还是 Q 组。缩放因子通过精灵边界框尺寸与基础原型尺寸的比值确定（必须是整数）。
3. 重排条带：所有 P 组条带移到左侧，所有 Q 组条带移到右侧。P 组内各条带保持原始的从左到右相对顺序，Q 组内同样保持原始相对顺序。
4. 在重排后的每条条带中，将精灵切换为对立原型：P 组的精灵替换为 Q 的形状，Q 组的精灵替换为 P 的形状，保持相同的缩放倍数。替换时以精灵内的锚点区域像素（灰(5)像素块）为对齐基准——新原型的锚点区域像素对齐到旧原型锚点区域的相同位置。
5. 条带的主色、宽度和其他非精灵像素随条带整体移动，保持不变。
6. 输出与输入同尺寸。

**关键洞察**：排序的依据和替换的规则都源于原型识别，但它们的效果交叉产生了反直觉的输出——左侧条带（按 P 组排列）内部显示的是 Q 原型的精灵，右侧条带（按 Q 组排列）内部显示的是 P 原型的精灵。求解者必须同时理解分组排序和原型互换，才能正确预测输出。单个示例中可能误以为排序依据是条带主色或其他属性，必须对比多个示例来排除替代假说。
