## 新题 5：遮挡序驱动的循环色印章

**组合逻辑**：[hollow_rectangle + overlap_layer + occlusion_order + overlap_determines](来自 68bc2e87) + [stamp + sprite_template + same_color_match + anchor_marker](来自 1b59e163 和 363442ee，创新：印章颜色不由模板自身颜色决定而由遮挡序的循环移位决定) + [erase + simultaneous_replacement](来自 3391f8c0，创新：擦除和重绘的时序由遮挡序约束)

**来源原语**：sorting、reconstruct、hollow_rectangle、overlap_layer、occlusion_order、overlap_determines（68bc2e87）；stamp、sprite、sprite_template、same_color_match、anchor_marker、anchor_positions_copy（1b59e163 / 363442ee）；erase、simultaneous_replacement、color_identifies_template（3391f8c0）

**依赖链**：遮挡关系分析得出层叠顺序 → 层叠顺序产生循环颜色映射（第 k 层的印章用第 k+1 层的颜色，最顶层用最底层颜色） → 颜色匹配关联矩形框与精灵模板 → 同步擦除后按新颜色重绘。去掉遮挡分析则循环映射无从建立，去掉颜色匹配则不知道哪个模板放哪个框，去掉同步擦除则重叠区域的绘制顺序出错。

根据重叠矩形框的遮挡层序，将每个框内的精灵模板用循环后移一位的层序颜色重新绘制。

**输入结构**：约 18x18 网格，背景黑(0)。包含 3~4 个单像素厚的空心矩形框，颜色各不相同（取自 {蓝(1), 红(2), 绿(3), 黄(4)}），矩形互有重叠（重叠处只显示最上层颜色）。网格底部 3 行是模板区：包含与每个矩形框同色的小型 4-连通精灵模板（每个 3~5 像素，形状不规则，各模板间互不相邻，边界框不超过 3x3）。生成约束：每对矩形至少有一个重叠像素可用于判断层序；模板区与矩形框区不重叠；所有矩形框大小相同（边界框尺寸一致，约 6x6 至 8x8）。

**规则**：
1. 将每个矩形框重建为其可见像素边界框的完整单像素边框。
2. 在每个重叠像素处，可见颜色所属的框在被遮挡颜色所属的框之上。综合所有重叠约束，推断唯一的从底到顶层叠顺序，记为排名 1（底）到 N（顶）。
3. 建立循环颜色映射：排名 k 的框映射到排名 (k mod N) + 1 的框的颜色。即排名 1 → 排名 2 的颜色，排名 2 → 排名 3 的颜色，...，排名 N → 排名 1 的颜色。
4. 在模板区中，通过颜色匹配找到每个框对应的精灵模板。
5. 同步擦除所有矩形框的内部区域（框线保留，内部设为黑(0)），同时擦除模板区（全部设为黑(0)）。
6. 对每个矩形框，将其对应的精灵模板居中印入框内部，但使用该框循环映射后的新颜色绘制。居中规则：模板边界框中心对齐框内部区域中心，四舍五入偏左偏上。
7. 框线保持原色不变。若印章像素与框线像素重叠，框线优先。

**关键洞察**：每个印章的颜色不是其模板的原色，而是由遮挡层序循环后移一位决定的——必须先完整解出层叠顺序才能确定颜色映射，且循环性质意味着最顶层的印章反而使用最底层的颜色，这是仅看单个示例难以确定的规则。
