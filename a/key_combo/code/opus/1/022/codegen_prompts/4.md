## 新题 4：前缀外推后布尔交集

**组合逻辑**：[prefix_matching + column_state_sequence + extrapolate + missing_suffix_continued_from_pattern](来自 90f3ed37，创新：外推应用于两个并列掩码而非行组) → [boolean_op + mask_region + divider_line + alignment + bg_intersection_out](来自 6430c8c4，创新：参与布尔运算的掩码是外推补全后的结果而非直接给出)

**来源原语**：complete、extrapolate、row_group、column_state_sequence、prefix_matching、missing_suffix_continued_from_pattern（90f3ed37）；boolean_op、mask_region、divider_line、alignment、bg_intersection_out（6430c8c4）

**依赖链**：上半区提供完整参考模式 → 下半区两个掩码各自只有参考模式的前缀 → 用参考模式外推补全两个掩码 → 对补全后的两个掩码做按位布尔运算输出交集背景。外推步骤依赖参考模式（无参考则前缀无法补全），布尔运算依赖补全结果（未补全的前缀做布尔运算会得到错误答案）。两步之间的信息变换：外推把不完整的空间模式转化为完整掩码，布尔运算把两个掩码的叠加关系转化为单一输出。

用共享参考模式分别外推补全两个不完整掩码，然后输出二者均为背景的位置。

**输入结构**：约 13x22 网格。一条完整宽度的橙(7) 水平分隔行将网格分为上下两半。上半区包含一个完整的列状态参考模式：每列要么为黑(0) 背景，要么在特定行偏移处有灰(5) 前景像素，形成一个可识别的列状态序列（如交替出现"空列-单像素列-双像素列"的循环）。下半区由一条完整高度的灰(5) 垂直分隔列分为左右两个等宽面板。左面板包含蓝(1) 前景像素构成的模式前缀（从最左列开始，覆盖若干列后中断，其余列为纯背景）。右面板包含红(2) 前景像素构成的另一段模式前缀（同样从最左列开始，长度与左面板不同）。生成约束：两个前缀的列状态序列与上半区参考模式的列状态序列前缀匹配；两个前缀长度不同且均短于参考模式；面板宽度等于参考模式列数。

**规则**：
1. 移除橙(7) 水平分隔行和灰(5) 垂直分隔列（它们是结构标记，不参与输出）。
2. 从上半区提取完整的列状态参考序列：逐列记录前景像素的行偏移模式。
3. 对左面板：识别其蓝(1) 像素构成的列状态前缀，与参考序列比对。从前缀终止处开始，按参考序列的后续列状态用蓝(1) 补全至面板右端。
4. 对右面板：同理用红(2) 补全。
5. 将补全后的左面板和右面板逐格对齐。输出一个与单面板同尺寸的网格：凡两个面板该格均为黑(0) 背景的位置，输出绿(3)；其余位置输出黑(0)。

**关键洞察**：两个掩码故意不完整——直接对不完整的前缀做布尔运算会因缺失区域全为背景而产生虚假的"双空"结果；必须先识别共享参考模式并补全两个前缀，才能得到正确的交集。
