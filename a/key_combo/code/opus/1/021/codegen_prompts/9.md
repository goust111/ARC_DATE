## 新题 9：空心框面积排名参数化周期填充相位

**组合逻辑**：[比较](保留面积比较) + [排序](面积排名) → [周期推断](创新：排名参数化每个框的颜色循环相位) + [间隙填充](保留填补空白)

**来源原语**：比较/compare ← 445eab21；计数/counting ← de1cd16c；周期推断/periodic_inference ← 1e97544e；间隙填充/gap_filling ← 1e97544e；空心矩形/hollow_rectangle ← 445eab21；封闭区域/enclosed_region ← 445eab21；面积比较/area_comparison ← 445eab21；空白单元格/blank_cell ← 1e97544e；按列周期取色/column_modular_phase ← 1e97544e（创新：相位由面积排名而非对角线位置决定）

**依赖链**：测量每个空心框的内部面积，面积排名为每个框分配颜色循环的起始相位，按相位填补该框内的空白像素。在 445eab21 中面积比较选出赢家输出 2x2 纯色块；在 1e97544e 中相位由对角线位置决定且作用于单一表格。这里面积排名参数化了周期相位并分布在多个独立框中，把几何属性（面积大小）转化为模式属性（颜色循环偏移），产生了源题中不存在的"尺寸编码模式"关系。

按多个空心框的内部面积排名分配颜色循环的起始相位，再按各框的相位填补内部空白。

**输入结构**：
- 黑(0)背景网格，约 20x20。
- 3 个灰(5)空心矩形框（一像素厚边框），内部面积互不相同（如内部分别为 3x3=9、4x3=12、5x4=20 像素）。框彼此不重叠，间距至少 2 像素。
- 每个框的内部使用逐列填色方式部分填充：框内每列的所有行使用同一颜色，颜色来自三色循环红(2)、蓝(1)、绿(3)。但每个框有若干内部像素为黑(0)（空白），表示需要被填补。
- 不同框的逐列循环起始相位不同（见规则），但这一信息不直接标注。
- 生成约束：每个框内至少有 2 个已填色像素和 2 个空白像素。每个框的内部列数至少为 3（保证循环至少完整出现一次）。已填色像素与规则中的相位一致。

**规则**：
1. 对每个灰(5)空心框，计算其内部面积（内部行数 x 内部列数）。
2. 按内部面积升序排名：最小面积为第 1 名，中等为第 2 名，最大为第 3 名。
3. 颜色循环定义为 C = [红(2), 蓝(1), 绿(3)]。每个框内部的列按从左到右编号为 j = 0, 1, 2, ...。框内第 j 列所有行的颜色 = C[(j + 排名 - 1) mod 3]。
4. 用步骤 3 的规则替换该框内部所有黑(0)空白像素为对应颜色。已有颜色的非黑像素不变（它们应与规则一致，可作为求解者的线索）。
5. 框边框保持灰(5)。框外背景保持黑(0)。各框独立处理。

**关键洞察**：面积不是用来选出唯一赢家（如 445eab21 输出赢家颜色），而是编码了每个框各自的颜色循环偏移量——必须先测量面积并排序得出排名，才能推断各框的正确填充模式。单看一个框可能误判其固有相位，必须跨框比较面积才能归纳规则。
