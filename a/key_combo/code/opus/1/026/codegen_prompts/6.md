## 新题 6：角标记扩展为字形后同色配对虚线连接

**组合逻辑**：[放置·角标记扩展为环绕字形](已有) + [同色配对·轴对齐](创新：从分隔栅格的格子配对改为字形中心配对) + [连线·奇偶虚线](已有) → [碰撞阻挡·交叉优先](创新：水平线优先规则)

**来源原语**：角标记像素(f35d900a)、环绕字形(f35d900a)、奇偶决定虚线(f35d900a)、同色配对(06df4c85)、轴对齐(06df4c85)、沿行列填充间隙(06df4c85)、碰撞阻挡(1f642eb9)

**依赖链**：角标记扩展为 3x3 字形 → 同色字形对确定连线端点 → 端点间绘制奇偶虚线 → 线段交叉时适用覆盖优先规则

每个彩色像素扩展为 3x3 字形（中心保持原色、外圈灰色），然后同色字形对之间用奇偶虚线连接，交叉处水平线优先。

**输入结构**：
- 约 17x17 黑(0)背景网格。
- 6~10 个单像素彩色标记，每种颜色恰好出现 2 次（3~5 对）。颜色从蓝(1)、绿(3)、黄(4)、橙(7)、品红(6)中选取。
- 每对同色标记要么同行（水平对齐）要么同列（垂直对齐），不存在既不同行也不同列的配对。
- 标记之间间距至少 5 个像素（保证字形扩展后不重叠且连线有足够空间）。
- 生成约束：至少存在一处两条连线（一水平一垂直）交叉。

**规则**：
1. 每个标记像素扩展为 3x3 字形：中心像素保持标记原色，周围 8 个像素涂灰(5)。
2. 对每对同色标记（它们的字形中心同行或同列），在两个字形之间画一条连线。连线沿两个中心之间的直线方向（水平或垂直）绘制，仅覆盖两个字形灰色边缘之间的空白间隔区域（不覆盖字形本身）。
3. 连线使用奇偶虚线模式：从靠近第一个字形的一端开始计数（距离 = 0，即紧邻字形灰色边缘的第一个像素），距离为偶数的像素涂该对的颜色，距离为奇数的像素保持黑(0)。
4. 若一条水平连线和一条垂直连线在某像素交叉：该像素涂水平连线的颜色（水平优先）。
5. 字形的灰(5)像素不受连线影响，始终保持灰色。

**关键洞察**：字形扩展不仅是装饰——灰色边缘定义了虚线的起始参考点，从而决定奇偶相位。交叉优先规则需要至少两个包含交叉的示例才能确认是"水平优先"而非"后绘制优先"或"特定颜色优先"等替代规则。
