## 新题 5：种子平铺后边界色匹配溶解分隔线

**组合逻辑**：[平铺·保持种子相位](已有) → [同色配对](创新：从"分隔栅格中标记配对"改造为"平铺结果中跨分隔线的像素配对") → [填充·溶解分隔](创新：配对成功则擦除分隔像素)

**来源原语**：平铺(a57f2f04)、种子图案(a57f2f04)、矩形空腔(a57f2f04)、保持种子相位(a57f2f04)、墙壁(a57f2f04)、分隔栅格(06df4c85)、同色配对(06df4c85)、填充(06df4c85)

**依赖链**：每个空腔的种子图案决定平铺结果 → 平铺结果在分隔线两侧产生特定颜色 → 分隔线两侧颜色是否匹配决定该分隔像素是否溶解

先将每个矩形空腔用其种子图案平铺填满，然后检查相邻空腔在共享分隔线两侧的颜色——匹配处分隔线像素被替换为该颜色，不匹配处保留。

**输入结构**：
- 约 15x15 网格。
- 红(2)分隔线（1 像素厚的水平和垂直完整条）将网格分为 4~6 个矩形空腔。
- 每个空腔的背景为黑(0)，其中包含一个小的种子图案（2~4 个像素，由一种非红非黑颜色组成，如蓝(1)、绿(3)、黄(4)、橙(7)等），种子在空腔内的位置决定平铺相位。
- 不同空腔的种子颜色可以相同也可以不同。
- 生成约束：平铺后，至少有一对相邻空腔在共享分隔线的某些位置颜色匹配（产生溶解），至少有一对不匹配（分隔线保留）。

**规则**：
1. 对每个空腔，取其种子图案像素的边界框作为平铺单元。以种子当前位置为相位基准，将该单元周期性地铺满整个空腔。单元周期覆盖的位置若对应种子色像素则涂种子色，否则保持黑(0)。
2. 平铺完成后，检查每个红色分隔线像素（不含分隔线交叉点，即同时属于水平和垂直分隔线的像素）。
3. 对于水平分隔线上的非交叉像素：查看其正上方和正下方的像素。若两者颜色相同且均非黑(0)，则该分隔线像素替换为该匹配颜色（溶解）；否则保持红(2)。
4. 对于垂直分隔线上的非交叉像素：查看其正左方和正右方的像素。若两者颜色相同且均非黑(0)，则该分隔线像素替换为该匹配颜色（溶解）；否则保持红(2)。
5. 分隔线交叉点（水平与垂直分隔线的公共像素）始终保持红(2)。

**关键洞察**：分隔线的命运由平铺结果决定——同一个种子图案在不同空腔中因相位和空腔尺寸不同而产生不同的边界像素序列。求解者必须先完成平铺（需理解周期性和相位），再判断边界匹配（需同时考虑两侧空腔的平铺结果）。连通性从平铺中涌现，而非预设。
