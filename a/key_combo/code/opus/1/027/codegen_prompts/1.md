## 新题 1：碎片帧重建为同心环后作射线屏障

**组合逻辑**：[排序 sorting]（按碎片帧边界框边长排序，创新为确定同心环嵌套顺序） + [同心层填充 concentric_fill]（将分散碎片重建为居中同心方环） → [射线延伸 ray_extend]（从边界标记向内发射射线，同心环像素充当终止屏障）

**来源原语**：排序 sorting、同心层填充 concentric_fill、碎片帧 fragmented_frame、嵌套层次 nesting_hierarchy（参考题 c658a4bd）；射线延伸 ray_extend、侧标记 side_marker、遇阻停止 stop_at_blocker（参考题 95755ff2）

**依赖链**：碎片帧的边界框边长 → 排序决定同心嵌套顺序 → 同心环重建确定屏障位置 → 射线从边界标记发出，遇到最近的同心环像素即停止 → 射线着色区域构成最终输出。排序结果改变了同心环的空间分布，进而改变射线的终止位置和着色范围。

输入中分散的碎片帧被按边长重组为居中同心方环，然后边界标记向内发射射线，射线遇同心环像素即停，形成分段着色。

**输入结构**：约 15x15 网格，背景黑(0)。网格中散布 3~4 组不同颜色的像素簇，每组像素属于同一颜色（如蓝(1)、绿(3)、黄(4)），每组的像素分布构成一个不完整的正方形框轮廓（碎片帧），各组边界框大小不同（如边长分别为 5、9、13）且可能互相重叠。网格最外一圈的四条边上各有 1 个标记像素，颜色为红(2)或橙(7)等非碎片帧颜色，标记像素位于该边的某一行或某一列上。生成约束：碎片帧边界框中心大致对齐（使重建同心环可居中放置）；各碎片帧的边长互不相同；标记像素所在行/列必须穿过重建后最外层同心环的内部。

**规则**：
1. 对每组同色碎片帧像素，计算其边界框的较大边长作为该颜色的"帧边长"。
2. 按帧边长从大到小排序所有碎片帧颜色。
3. 以网格中心为对称中心，依次绘制同心正方形环：最大边长的颜色绘制最外层环，次大的绘制次外层环，以此类推。每个环为 1 像素厚的正方形闭合框。输出网格大小等于最大帧边长（居中裁剪或扩展到该尺寸）。
4. 清除所有原始碎片帧像素和标记像素，仅保留重建后的同心环。
5. 对网格边界上的每个标记像素，沿其所在边的法线方向（顶边标记向下、底边标记向上、左边标记向右、右边标记向左）发射一条射线。射线沿途将背景像素(0)涂为该标记的颜色，直至遇到第一个同心环像素为止（该环像素本身不被覆盖）。射线不穿过同心环。
6. 若两条射线路径交叉于同一背景像素，后处理的射线（按顶→右→底→左的标记顺序）覆盖先处理的。
7. 同心环像素保持不变。

**关键洞察**：碎片帧在输入中的空间位置无关紧要——只有它们的边界框边长编码了同心环的嵌套层级。射线的终止位置完全取决于重建后同心环的空间布局，而非碎片帧的原始位置。

## 实现要求

1. `main(grid)` 必须实现新题描述中的确定性转换规则，不能只识别 `generate_input()` 的固定模板。
2. `generate_input()` 必须随机生成多样样例，不能固定死。随机维度应覆盖：网格大小、对象数量、位置、颜色、方向、形状参数或关键分支。
3. 生成器必须保证输入满足 `main()` 的隐式假设：对象不重叠、不越界、特殊标记唯一或可区分、匹配关系无歧义、关键分支出现概率相同。
4. 禁止把 ARC 颜色 id 、亮度、拼写等当作人类不可见的数值语义参与排序、大小比较或隐藏映射。颜色变化必须有可见结构线索。注意颜色亮度、拼写等也是不可见信息，若描述中出现违规的颜色id或者亮度，可自行使用少量的固定颜色替代，但注意生成时要在三个以内输入输出网格中对所有变换100%覆盖度。
5. 输出样例要视觉清晰，人类必须能从输入输出对中肉眼辨认出规律。具体要求：避免对象粘连、覆盖关系混乱、同一像素多重语义；不同逻辑步骤产生的结果不要大面积层叠在一起导致无法分辨哪个颜色属于哪个步骤；输入中各元素之间保持足够间距，输出中新增的标记/填充/路径等应与背景和已有元素在颜色上有明显区分；若规则涉及多层叠加，生成时控制对象密度和尺寸，确保叠加区域只占少数像素而非铺满整个网格。
6. 若规则有多个分支，生成器不能长期固定成一个分支；应让分支在随机样例中合理出现。分支概率不必平均——难以发现的隐蔽分支（如少数情况下才触发的特殊规则）应适当提高出现概率，确保在 3 个训练示例中至少出现一次，否则求解者无法归纳该规则。对于颜色映射类规则，确保 2 个左右的示例即可覆盖所有映射关系（每种颜色→颜色的映射至少在某个示例中出现过）。
7. 代码风格参考 `ARC_code`：使用 `numpy`，必要时使用本地 helper，但目标文件应能被 `SourceFileLoader` 直接加载。
8. 可以在目标目录放公共 helper 文件，但若只实现一道题，优先保持目标文件自包含，减少额外依赖。
