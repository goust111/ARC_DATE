## 新题 8：类比推理发现射线延伸变换规则

**组合逻辑**：[类比推理/analogy_inference](已有：训练对→规则发现) + [射线延伸/ray_extend](创新：被类比发现的变换规则恰好是射线行为)

**来源原语**：analogy_inference / rule_inference / training_pair_mapping / palette_match_pairing（4c7dc4dd）, hollow_frame / sprite（4c7dc4dd）, ray_extend / emit_from_arm_end / stop_at_fg（f8be4b64）, marker_pixel（13f06aa5）

**依赖链**：框架颜色匹配 → 训练对识别 → 比较训练对输入输出推断射线规则（方向、终止条件） → 将推断的规则应用于测试精灵体 → 裁剪输出。类比推理步骤确定变换类型和参数，射线延伸步骤执行该变换，两者共同约束最终输出。

从一对同色框架围住的精灵体中，推断射线延伸的变换规则（方向、终止条件），然后将该规则应用于另一个框架中的测试精灵体。

**输入结构**：黑(0)背景网格，约20x20。三个彩色空心正方形框架（每个7x7，1像素厚边框），彼此间隔至少2像素。框架A的边框为红(2)，框架A'的边框也为红(2)（训练对）。框架B的边框为绿(3)（测试用例）。框架A内部（5x5区域）：一个由蓝(1)像素组成的小型精灵体（3-5像素，4-连通），其中嵌入1-2个橙(7)标记像素（4-连通地连接于精灵体或与精灵体相邻）。框架A'内部：与A相同的蓝(1)精灵体布局，但每个橙(7)标记像素沿某个基本方向（上/下/左/右之一）延伸出橙(7)射线，射线在遇到蓝(1)精灵体像素或框架边框前停止（不含终止像素）。框架B内部：一个不同形状的蓝(1)精灵体（3-5像素），含有橙(7)标记像素，但无射线。生成约束：训练对中所有标记像素的射线方向一致（同一个基本方向）；训练对的边框色相同，测试框架边框色与训练对不同。

**规则**：
1. 通过匹配框架边框颜色识别训练对：两个边框色相同的框架为训练对（A和A'），边框色唯一的为测试用例（B）。
2. 比较A和A'的内部：从每个橙(7)标记像素出发，确定在A'中射线延伸的基本方向（即在哪个方向出现了A中没有的新橙色像素）。确认终止条件（射线在蓝像素前一格停止，还是在框架边框前一格停止——取先到者）。
3. 将推断的射线规则应用于框架B的内部：从B中每个橙(7)标记像素出发，沿同一方向延伸橙(7)射线，遵循相同的终止条件。
4. 输出：框架B内部经变换后的内容，裁剪为5x5（框架内部尺寸）。不含框架边框。

**关键洞察**：这是双重挑战——首先识别类比结构（哪些框架构成训练对），然后从训练对中精确推断射线参数（方向和终止规则）。射线方向在不同题目实例中可能不同（有时向右，有时向下等），必须从训练对的具体示范中读取，而非记忆固定规则。
