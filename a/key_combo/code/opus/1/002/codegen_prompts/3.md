## 新题 3：标记像素的对角邻居计数编码象限精灵体旋转角度

**组合逻辑**：[分类/classify](创新：对角邻居计数作为分类指标) → [旋转/rotate](创新：旋转角度由计数值决定，非固定)

**来源原语**：rotate / quadrant / quadrant_rotation（cf5fd0ad）, diagonal_neighbor（140c817e）, classify / diagonal_orientation（1d61978c）, sprite（8d5021e8）, cross_divider（0bb8deee）

**依赖链**：标记像素定位 → 对角邻居计数 → 计数映射为旋转角度 → 精灵体旋转 → 象限重组。计数步骤的输出直接参数化旋转步骤，两者不可分离。

每个象限内精灵体的旋转角度由其内部标记像素拥有的对角邻居数量编码：0个邻居=不旋转，1个=90度，2个=180度，3个=270度。

**输入结构**：黑(0)背景网格，约14x14，由一条1像素灰(5)水平线和一条1像素灰(5)垂直线（形成十字分隔线）分为四个等大象限。每个象限包含一个小型精灵体，由绿(3)像素组成（4-8像素，4-连通）。每个精灵体内恰好有一个像素为红(2)而非绿(3)——即标记像素。该标记像素的四个对角邻居位置（NW、NE、SW、SE）中，有0到3个是绿(3)精灵体像素。生成约束：四个精灵体的对角邻居计数分别为0、1、2、3，各不相同；每个精灵体的形状不对称（旋转后可见差异）。

**规则**：
1. 对每个象限，定位其精灵体中的红(2)标记像素。计算该标记像素四个对角邻居（NW、NE、SW、SE）中属于绿(3)精灵体像素的数量D。
2. 将红(2)标记像素替换为绿(3)，使精灵体变为纯绿色。
3. 将精灵体以其边界框中心为圆心，顺时针旋转 D x 90 度（D=0：不旋转；D=1：顺时针90度；D=2：180度；D=3：顺时针270度）。
4. 将旋转后的精灵体放回其所在象限，以象限中心为基准居中放置。灰(5)十字分隔线保持不变。

**关键洞察**：旋转角度不由象限位置固定决定（与参考题cf5fd0ad不同），而是从每个精灵体的内部微观结构（标记像素的对角邻居数）中读取。必须对比多个示例，观察不同对角邻居数与旋转结果的对应关系，才能归纳出D-to-rotation映射。
