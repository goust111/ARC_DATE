## 新题 4：方向精灵体射线触发镜像标记对间隙填充

**组合逻辑**：[射线延伸/ray_extend](创新：方向由质心偏移决定) → [连线/connect + 填充/fill](创新：射线终点触发镜像对之间的间隙填充)

**来源原语**：ray_extend / directional_sprite / centroid_bias_dir / dotted_ray_to_edge（13f06aa5）, connect / mirrored_marker_pair / center_axis_symmetry / min_gap_triggered（5ad8a7c0）, stop_at_fg（f8be4b64）, marker_pixel（13f06aa5）

**依赖链**：精灵体质心计算 → 射线方向确定 → 射线发射 → 射线命中镜像标记像素 → 触发该标记对之间的水平间隙填充。射线方向决定命中哪个镜像对，命中事件触发填充，两步紧密耦合。

不对称精灵体通过质心偏移编码射线方向；射线命中一个镜像标记对中的一端后，该对之间的间隙被填充为射线颜色。

**输入结构**：黑(0)背景网格，约16x16。2-3个小型方向精灵体，每个由灰(5)像素组成（恰好7个像素，形状相同但经旋转以编码不同方向）。每个精灵体内嵌入一个标记像素，颜色各不相同，从红(2)、蓝(1)、绿(3)中选取。此外，网格中有3-4对黄(4)单像素，每对关于网格垂直中轴对称（同一行内，两像素到中心列距离相等）。生成约束：每个精灵体的射线方向为四个基本方向之一（上、下、左、右），且每条射线路径上恰好有一个黄(4)像素会被命中。不同精灵体的射线不会命中同一个黄(4)像素。

**规则**：
1. 对每个精灵体，计算其灰(5)像素（不含标记像素）的质心C = (行均值, 列均值)。计算从质心C到标记像素M的偏移向量：dr = M行 - C行，dc = M列 - C列。射线方向为该偏移向量的主导基本方向：若 |dr| > |dc|，射线向下(dr>0)或向上(dr<0)；若 |dc| > |dr|，射线向右(dc>0)或向左(dc<0)；若 |dr| = |dc|（平局），取垂直方向（dr>0则向下，dr<0则向上）。
2. 从标记像素M出发，沿射线方向逐像素发射连续射线，将路径上的每个黑(0)像素涂为标记像素的颜色。
3. 射线遇到黄(4)像素时停止（该黄像素也被涂为标记颜色）。若路径上无黄像素，射线延伸至网格边界。
4. 当一个黄(4)像素被射线命中时，找到它的镜像伙伴（同一行中关于垂直中轴对称的另一个黄像素）。将该行中两个黄像素之间（含两端）的所有背景像素填充为射线的标记颜色。
5. 未被任何射线命中的黄(4)像素对保持黄(4)不变。灰(5)精灵体像素保持不变。

**关键洞察**：精灵体的不对称形体是方向天线——质心偏移编码射线发射方向。射线的落点决定激活哪个镜像对，连接颜色来自射线的源标记。删除方向分类则射线方向不定，删除镜像对连接则射线只是线段无后续效果。
