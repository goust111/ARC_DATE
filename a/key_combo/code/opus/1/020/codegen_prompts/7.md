## 新题 7：块条展开后的稀有象限轴向镜像

**组合逻辑**：[unfold_nest / reverse_order_read](2x2 块条展开为四象限嵌套图案) + [mirror / reflect_along_axis](创新：展开结果中最稀有外层色的象限被选中，沿轴指示器方向镜像覆盖对侧象限)

**来源原语**：unfold_nest / block_cell / quadrant / nested_layer / block_order_maps_layer / reverse_order_read（8fff9e47）；mirror / symmetry_axis / reflect_along_axis / min_pixel_color / outlier_selection（ad3b40cf）

**依赖链**：块条被展开为四个嵌套象限图案 → 统计四个象限外层颜色的全局像素数以找出最稀有者 → 轴指示器行/列决定镜像方向 → 最稀有外层色所在的象限被沿该轴反射，覆盖对侧象限。展开决定象限内容，像素统计决定选哪个象限，轴指示器决定镜像方向——三个独立信息源汇聚为一个操作。

展开块条为四象限嵌套图案，将外层色最稀有的象限沿轴指示器方向镜像覆盖其对侧。

**输入结构**：输入为一个矩形块条（短边 4 像素，如 4x8、4x10、10x4 等），由 2x2 块精确分割。块条一边（上/下/左/右）附加一行或一列均匀前景色像素作为"轴指示器"，使总输入比纯块条多一行或一列。块像素使用 4-6 种不同前景色（如红(2)、蓝(1)、绿(3)、黄(4)、品红(6)、橙(7)）。轴指示器使用其中一种颜色。生成约束：展开后四个象限的外层（最外圈）颜色中，恰好有一个象限的外层色在全输出中总像素数最少（唯一最稀有），其余三个象限的外层色有重复或像素数更多。

**规则**：
1. 分离轴指示器行/列与块条主体。记录轴指示器位于哪条边——这决定反射方向：若为行（上或下边）→ 垂直方向反射（上下翻转）；若为列（左或右边）→ 水平方向反射（左右翻转）。
2. 将块条展开为方阵输出，含四个象限嵌套图案：按反向行主序读取 2x2 块（右下块最先，向左移动，再向上行），将每个块的左上、右上、左下、右下像素分别送入左上、右上、左下、右下象限的对应层（如 8fff9e47 所述）。
3. 展开完成后，检查每个象限的最外层（第一层）颜色。统计这四种外层颜色各自在整个展开输出中的总像素数。找到总像素数最少的那个外层颜色所对应的象限（唯一确定）。
4. 将该象限的内容沿步骤 1 确定的方向反射到输出的对侧象限位置，覆盖对侧象限原有内容。具体地：若垂直反射，则上半部分的选中象限内容上下翻转后覆盖下半对应象限（或反之）；若水平反射，则左半选中象限左右翻转后覆盖右半对应象限（或反之）。
5. 输出：修改后的展开方阵。

**关键洞察**：展开步骤决定四个象限的内容，但哪个象限"胜出"并覆盖对侧取决于两个独立因素——轴指示器（决定反射方向：上下还是左右）和全局像素统计（决定选哪个象限）。改变轴指示器方向而不改变块条内容，会改变被覆盖的是哪个象限；改变块序而不改变轴，会改变哪个象限被选为源。需对比多个示例才能同时归纳出稀有性选择和轴向反射两条规则。

p = Path("/home/lixinyu/snap/a/key_combo/code/opus/1/020/7.py")
mod = SourceFileLoader("new_arc_task", str(p)).load_module()
sigs = set()
for i in range(100):
    inp = mod.generate_input()
    out = mod.main(inp)
    assert isinstance(inp, np.ndarray)
    assert isinstance(out, np.ndarray)
    assert inp.ndim == 2 and max(inp.shape) <= 30, f"input grid exceeds 30x30: {inp.shape}"
    assert out.ndim == 2 and max(out.shape) <= 30, f"output grid exceeds 30x30: {out.shape}"
    sigs.add(hashlib.md5(inp.tobytes() + str(inp.shape).encode()).hexdigest())
print("variants", len(sigs))
assert len(sigs) >= 20
