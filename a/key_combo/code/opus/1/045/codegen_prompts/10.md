## 新题 10：射线路径长度排序摘要

**组合逻辑**：[射线延伸 + 反弹](已有) → [计数·路径长度](创新：计数对象从静态物体变为射线路径上的动态像素数) → [排序 + 压缩](已有，创新：排序依据是射线追踪的数值结果，压缩格式为颜色行)

**来源原语**：射线延伸/ray_cast、反弹/bounce、碰撞停止/collision_stop、箭头精灵体/arrow_sprite、墙壁像素/wall_pixel、颜色继承/color_inheritance（来自 142ca369）；计数/counting（来自 58490d8a, 8ba14f53）；排序/sort、面积排序/area_ordering（来自 4df5b0ae）；压缩/compression、顺序排列/ordered_arrangement（来自 8ba14f53）

**依赖链**：射线追踪确定每条路径的长度 → 按长度排序各箭头 → 压缩为按排序顺序逐行输出颜色点的摘要网格。路径长度只有追踪完反弹后才能确定，排序和压缩依赖长度数值。输出完全丢弃了路径的空间形状，只保留长度的序关系。

追踪各箭头射线含反弹的完整路径，按路径长度升序压缩成行式摘要输出。

**输入结构**：约 14x14 的黑(0)背景网格。包含 3-4 个不同颜色的 2x2 缺角 L 形箭头精灵体（颜色从蓝(1)、绿(3)、黄(4)、品红(6)中取）。散布 4-8 个单像素墙壁（红(2)或灰(5)，不与箭头同色）。箭头的缺角方向各异。墙壁位置保证各箭头射线的路径长度互不相同（避免排序平局）。各箭头互不相邻，箭头与墙壁互不相邻。

**规则**：
1. 对每个箭头，按 142ca369 的规则追踪其对角射线（含反弹、颜色继承、碰撞停止）。记录该射线经过的背景格总数 L（不含箭头自身像素，不含墙壁像素，只计射线涂过的空背景格数；同一格被多次经过只计一次）。
2. 将所有箭头按 L 值从小到大排序。
3. 输出一个 N x Lmax 的网格（N 为箭头数，Lmax 为最大路径长度）。第 k 行（0-indexed，k=0 为最短路径的箭头）从左起连续填充 L_k 个该箭头原始颜色的像素，其余格子为黑(0)。
4. 输出网格仅包含颜色摘要，不包含任何箭头形状、墙壁或路径几何信息。

**关键洞察**：输出的空间结构（哪一行、多长的色条）完全由射线追踪的动态过程决定，但输出本身不包含任何路径痕迹——它是一个纯粹的统计摘要。墙壁的微小移动可能通过改变反弹次数大幅改变某条路径的长度，从而改变排序顺序和输出的行分配。

1. `main(grid)` 必须实现新题描述中的确定性转换规则，不能只识别 `generate_input()` 的固定模板。
2. `generate_input()` 必须随机生成多样样例，不能固定死。随机维度应覆盖：网格大小、对象数量、位置、颜色、方向、形状参数或关键分支。
3. 生成器必须保证输入满足 `main()` 的隐式假设：对象不重叠、不越界、特殊标记唯一或可区分、匹配关系无歧义、关键分支出现概率相同。

6. 若规则有多个分支，生成器不能长期固定成一个分支；应让分支在随机样例中合理出现。分支概率不必平均——难以发现的隐蔽分支（如少数情况下才触发的特殊规则）应适当提高出现概率，确保在 3 个训练示例中至少出现一次，否则求解者无法归纳该规则。对于颜色映射类规则，确保 2 个左右的示例即可覆盖所有映射关系（每种颜色→颜色的映射至少在某个示例中出现过）。
