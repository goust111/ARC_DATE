## 新题 9：自编码复制精灵体

**组合逻辑**：[平移复制](已有，创新：偏移量不来自外部锚点，而是编码在精灵体内部的特殊像素位置中) + [擦除·标记色](创新：标记色像素既是偏移编码又是应被擦除的非输出部分) → 隐式编码结构（精灵体同时是操作对象和操作指令）

**来源原语**：平移复制/translate_and_copy、锚点偏移对应/anchor_offset_correspondence、源锚点/source_anchor_marker（来自 2c737e39）；擦除/erase（来自 e41c6fd3）；标记色像素/marker_color_pixel（来自 ae4f1146）

**依赖链**：精灵体内部的红色像素位置 → 被解读为复制偏移量 → 在对应偏移位置放置精灵体的净形状（去除红色后的版本）。偏移量编码在精灵体自身中，删除编码就无法确定复制位置，删除复制操作就不知道编码的用途——精灵体同时是数据和指令。

精灵体内部的红色像素编码了复制偏移向量，将去红后的净形状复制到各偏移位置。

**输入结构**：约 15x15 的黑(0)背景网格。中央附近有一个 4-连通精灵体，由一种主色（如蓝(1)，4-8 个像素）和 1-3 个红(2)像素组成。红色像素与主色像素 4-连通（红色像素是精灵体的一部分，不是孤立的）。精灵体在边界框内有一个明确的参考点：边界框的左上角。红色像素相对于精灵体边界框左上角的行列偏移量 (dr, dc) 即为复制偏移向量。网格足够大，使得所有偏移复制都不会超出边界。不同红色像素给出的偏移向量互不相同。生成约束：各偏移副本之间以及副本与原始精灵体之间不重叠。

**规则**：
1. 定位精灵体的边界框，记其左上角为参考点 (R0, C0)。
2. 找出精灵体中所有红(2)像素，计算每个红色像素相对于 (R0, C0) 的偏移量 (dr_k, dc_k)。
3. 生成精灵体的"净形状"：将精灵体中所有红(2)像素替换为主色，得到一个纯主色图案。记录净形状中每个像素相对于 (R0, C0) 的坐标集合 S。
4. 对每个偏移量 (dr_k, dc_k)，在位置 (R0 + dr_k, C0 + dc_k) 为新参考点，绘制净形状的副本：对 S 中每个相对坐标 (sr, sc)，将 (R0 + dr_k + sr, C0 + dc_k + sc) 涂为主色。
5. 原始精灵体的位置也替换为净形状（红色像素变为主色）。
6. 若副本之间或副本与原始精灵体之间发生重叠，重叠像素仍为主色（无变化——同色覆盖）。
7. 输出网格与输入同尺寸，其余位置为黑(0)。

**关键洞察**：精灵体既是被复制的对象，又通过红色像素的空间位置编码了复制指令——这是一种隐式编码结构，求解者需在第一个示例中猜测红色像素的角色，通过多个示例确认"红色位置 = 偏移向量"这一非显然映射。
