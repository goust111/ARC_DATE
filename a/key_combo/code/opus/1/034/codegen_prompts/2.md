**组合逻辑**：[对称补全 symmetry_completion](创新：补全同时恢复轨道段和障碍物，两类信息对寻路的影响相反) → [寻路 pathfinding + 邻域禁区 neighbor_exclusion + 重涂色 recolor]

**依赖链**：栗色遮挡像素掩盖了部分轨道和障碍 → 利用反射对称性补全所有被遮挡的位置 → 补全同时恢复新的青色轨道段（开辟新通路）和新的橙色障碍（及其 8-邻域禁区，封死某些捷径） → 在补全后的网络中寻找两端点间的唯一安全路径

先用反射对称性修复被遮挡破坏的网格（同时恢复出隐藏的轨道和障碍），再在修复后的轨道网络中找到避开所有障碍邻域的唯一路径并标红。

**输入结构**：
- 黑(0)背景，网格约 15x15，底层图案关于某一列具有完美的左右反射对称性（对称轴不一定在网格正中央，但总是在某个整数列或两列之间的半整数位置）。
- 青(8)像素构成一个 4-连通轨道网络（含分支和环路），网络中恰好嵌有两个红(2)端点像素（红像素也是轨道的一部分，与青像素 4-连通）。
- 橙(7)像素作为障碍物散布在轨道附近（不在轨道上，即不与任何青/红像素重合）。
- 栗(9)像素作为遮挡色覆盖了若干位置——这些位置的真实颜色可能是青(8)、橙(7)或黑(0)中的任意一种。栗色像素的存在打破了表面上的对称性。
- 去除所有栗色像素后，剩余的青 + 橙 + 黑 + 红像素构成关于该对称轴的完美左右反射图案（红端点的位置也是对称的，或位于对称轴上）。
- 生成约束：每个输入至少有一个栗色像素。两个红端点不在任何橙障碍的 8-邻域内（补全前后均是如此）。补全后，橙障碍的 8-邻域禁区恰好使两端点间只存在唯一一条 4-连通安全路径（仅经过青和红像素且不经过任何禁区内的像素）。补全前若将栗色像素视为可通行，则路径不唯一。

**规则**：
1. 识别遮挡色为栗(9)——它是唯一一种移除后使剩余非黑像素（青、橙、红）关于某列呈完美左右反射对称的颜色。
2. 确定反射对称轴。对每个栗(9)像素，计算其关于对称轴的镜像位置，将栗色像素替换为该镜像位置的颜色（青(8)、橙(7)或黑(0)）。
3. 在补全后的网格中，将每个橙(7)像素及其 8-邻域（上下左右和四个对角方向各一步）内的所有像素标记为禁行区。
4. 在剩余的非禁行区青(8)和红(2)像素中，寻找两个红(2)端点之间的唯一 4-连通简单路径。
5. 将该路径上的青(8)像素重涂为红(2)。端点保持红色。所有其他像素（橙障碍、黑背景、非路径青像素、已被恢复的像素）保持不变。

**关键洞察**：遮挡像素同时隐藏了轨道和障碍——对称补全不只是修通路，还会"生出"新的橙色障碍及其 8-邻域禁区，堵死某些看似可行的捷径。求解者必须意识到补全结果中包含两种性质相反的信息才能找到正确路径。
