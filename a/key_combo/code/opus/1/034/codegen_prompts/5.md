## 新题 5：下移触发对角溅射级联穿透空心框

**组合逻辑**：[平移 shift + 触发条 trigger_bar → 射线延伸 ray_extend](创新：对角射线被空心框边界阻挡) + [擦除 erase + 填充 fill](创新：射线击中框时打开该框——擦除边界并填色内部——解除射线阻挡引发向上级联)

**来源原语**：
- 平移 shift、移动像素 moving_pixel、触发条 trigger_bar、邻接触发对角溅射 adjacency_triggers_diagonal_splash、固定步长移动 fixed_step_move ← 73c3b0d8
- 射线延伸 ray_extend ← c92b942c
- 空心矩形 hollow_rectangle、封闭区域 enclosed_region、擦除 erase、填充 fill、边框包围内部 frame_encloses_interior、空心内部变色 interior_recolor ← d5d6de2d

**依赖链**：红色像素下移一行 → 落到触发条正上方的像素向左上和右上发射对角射线 → 射线遇到灰框边界时停止并"打开"该框（擦除边界、内部填绿） → 边界被擦除后射线继续沿原方向延伸 → 可能击中更高处的灰框，再次触发打开 → 逐层级联直到射线离开网格

像素下移到触发条上方后发射对角射线；射线被空心框边界阻挡，但击中即打开该框（边框消失、内部染绿），之后射线继续向上延伸，级联打开所有对角线上的框。

**输入结构**：
- 黑(0)背景，网格约 18x18。
- 一条黄(4)全宽水平触发条位于网格下部（距底部约 2~3 行）。
- 2~3 个红(2)移动像素散布在触发条上方。部分红像素距触发条恰好 2 行（下移 1 行后将与触发条正交相邻），其余红像素距触发条更远（下移 1 行后仍不与触发条相邻）。
- 4~6 个灰(5)一像素宽空心矩形框（边界框尺寸 3x3 到 5x5），分布在触发条上方的区域，彼此不重叠不相邻。某些框在对角线方向上存在上下排列关系——即下方框恰好位于某条对角射线路径上，挡在上方框与射线源之间。
- 红像素不在任何框内部或边界上。
- 生成约束：每个将触发溅射的红像素（下移后与触发条相邻的像素）的至少一条对角射线路径上有一个灰框；其中至少一条路径上有两个纵向排列的灰框（下方框阻挡射线到达上方框），以产生级联效果。

**规则**：
1. 将每个红(2)像素从原位置擦除（变为黑(0)），并在同列、下移一行的位置重新绘制红(2)像素。
2. 对每个下移后与黄(4)触发条正交相邻（正上方一格）的红像素，发射两条上行对角射线：一条向左上方（每步行 -1、列 -1），一条向右上方（每步行 -1、列 +1）。不与触发条相邻的红像素只移动不发射。
3. 每条射线逐像素向上延伸，延伸过程中的处理规则：
   a. 若下一像素为黑(0)，将其涂为红(2)，继续延伸。
   b. 若下一像素为灰(5)（框边界），射线暂停。找到该灰像素所属的空心矩形框，执行打开操作：将该框全部灰(5)边界像素擦除为黑(0)，将该框原先封闭的黑色内部区域全部填充为绿(3)。打开完成后，射线从暂停处继续延伸——该位置现已从灰变为黑(0)，涂为红(2)，并继续检查下一像素。
   c. 若下一像素为绿(3)（已被打开的框内部），将其保持绿(3)不变，射线穿透继续延伸。
   d. 若下一像素为红(2)（另一条射线的痕迹）、黄(4)（触发条）或超出网格边界，射线永久停止。
4. 黄(4)触发条保持不变。

**关键洞察**：灰框既是射线的目标也是射线的障碍——低处的框挡住射线触及高处的框。只有先打开低处的框（擦除其边界），射线才能穿透继续上行并级联打开高处的框。求解者需要沿对角线追踪射线路径、判断框的遮挡层次，才能确定最终哪些框会被打开。
