**组合逻辑**：[差异提取 difference_extraction + 对齐比较 aligned_comparison](创新：差异掩码不直接使用其形状，而是将其逐列像素数作为数值编码) → [计数 counting] → [填充 fill](创新：计数值驱动柱状条高度生成)

**依赖链**：对齐完好图案与缺损副本，逐像素比较提取差异掩码 → 对差异掩码按列统计缺失像素数 → 每列的计数值映射为输出柱状条的高度 → 在基线上方生成对应高度的柱状条

比较同一图案的完好版与缺损版提取差异，差异掩码中每列的缺失像素数直接编码了输出柱状条的高度。

**输入结构**：
- 黑(0)背景，网格约 12x20（较高）。
- 网格上半区包含两个多色前景图案，水平排列且间隔至少 2 列黑色。左侧图案完好（无缺失），右侧图案是同一图案的缺损副本——仅移除了部分前景像素（将其变为黑(0)），不增加任何新像素。两图案的边界框尺寸相同，均为 R 行 x M 列（R 约 4~6，M 约 4~6）。图案内含 2~3 种前景色（不含黑色），各像素颜色和位置在完好版中已确定。
- 缺损副本中，每列被移除的前景像素数量互不相同（范围 0 到 R，且至少有一列为 0、至少有一列大于 0）。
- 网格下半区有一条灰(5)水平基线（全宽，占一行）。基线上方有 M 个等距的柱状条槽位，每个槽位一列宽，槽位的水平位置与图案的列一一对应（第 j 个槽位对应图案的第 j 列）。输入中柱状条槽位为空（黑色）。
- 生成约束：缺损副本中各列缺失数互不相同。完好图案和缺损副本的边界框左上角在同一行，便于逐列对齐比较。

**规则**：
1. 分别裁剪完好图案和缺损副本到各自的边界框。将两个裁剪结果按左上角对齐，逐像素比较。
2. 提取差异掩码：标记所有在完好图案中为非黑前景色、在缺损副本中为黑(0)的像素位置。
3. 对差异掩码逐列统计：第 j 列（j = 1, 2, ..., M，从左数）中被标记为缺失的像素数记为 H_j。
4. 在网格下半区，从灰(5)基线向上，在第 j 个槽位绘制高度为 H_j 的柱状条（即从基线上方第 1 行到第 H_j 行涂色）。柱状条颜色为青(8)。若 H_j = 0，该槽位不绘制任何像素。
5. 输出保留完整的网格：上半区两个图案保持原样（完好版不变，缺损版保持缺损状态），下半区显示灰基线和新生成的青色柱状条。

**关键洞察**：缺损不是随机的——每列的缺失像素数量经过精心设计以编码柱状条高度。求解者必须先完成差异提取、再按列统计缺失数，才能发现这一从图案空间到柱状图空间的隐式编码关系。单看缺损副本本身无法发现规律，必须与完好版对比。
