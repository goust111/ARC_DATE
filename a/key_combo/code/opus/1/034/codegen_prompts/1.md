## 新题 1：线段穿框与孔洞几何门控填色

**组合逻辑**：[连线 draw_line] + [孔洞几何决定填充 hole_geometry_sets_fill](创新：孔洞几何作为线段颜色传递的门控条件) + [擦除 erase]（线段和标记像素仅为中间媒介，输出中不可见）

- 孔洞 hole、仅正方形孔洞填充 only_square_holes_filled、孔洞几何决定填充 hole_geometry_sets_fill ← 44d8ac46

**依赖链**：连线确定哪条线段穿过哪个框（颜色分配） → 框内孔洞的几何形状决定是否接受该颜色（门控判断） → 通过门控的孔洞被填入对应线段的颜色 → 最终擦除所有线段和标记像素，仅保留框与填色结果

通过同色标记像素对之间的连线穿过空心框来传递颜色，但只有内部孔洞为正方形的框才真正接受颜色填充，其余框的孔洞保持空白。

**输入结构**：
- 黑(0)背景，网格约 15x15。
- 3~5 个灰(5)一像素宽空心矩形框（边界框尺寸 3x3 到 6x6 不等），散布在网格上，彼此不重叠且不相邻（任意两框的边界像素之间至少间隔 1 个黑色像素）。每个框内部有一个连通的黑(0)孔洞区域；部分孔洞的边界框为正方形且孔洞像素完全填满该边界框（即孔洞本身是一个实心正方形块），其余孔洞的边界框为非正方形或孔洞像素不完全填满其边界框（即形状不规则）。
- 与灰框数量相同的彩色标记像素对（每种颜色恰好出现两次，颜色从红(2)、绿(3)、黄(4)、蓝(1)、橙(7)中选取），每对共享同一行或同一列。
- 每对标记像素之间的直线段恰好穿过一个灰框（从框的一侧边界进入、从另一侧穿出），且每个灰框恰好被一条线段穿过。不同线段不交叉。
- 所有标记像素均在灰框外部，不在任何框的边界或内部上。

**规则**：
1. 对每对同色标记像素，确定它们之间的水平或垂直直线段（含两端点的所有整数坐标像素）。
2. 确定每条线段穿过的灰框（线段经过该框的至少一个边界像素）。
3. 对每个被线段穿过的灰框，检查其封闭的黑色孔洞区域：计算孔洞区域的边界框，若该边界框为正方形且孔洞像素完全填满该边界框，则将孔洞内所有像素填入穿过此框的线段颜色；否则孔洞保持黑(0)不变。
4. 擦除所有标记像素和线段路径上的所有像素（还原为黑(0)），但不擦除灰框边界。
5. 输出网格保留灰框边界和被填色（或未填色）的孔洞。

**关键洞察**：线段在输出中完全不可见——它们仅作为颜色到框的传递媒介；真正决定输出的是孔洞的几何形状，只有正方形孔洞才能"接收"颜色。求解者需要同时理解线段的路由功能和孔洞的几何过滤功能。
