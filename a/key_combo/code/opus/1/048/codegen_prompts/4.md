## 新题 4：迷宫路径是否穿越边框决定填充色

**组合逻辑**：[寻路](保留最短路径语义) + [填充](创新：填充颜色不由边框自身面积决定，而由全局路径是否经过该边框内部来决定) + [射线延伸→边框开口](创新：边框缺口同时是迷宫通道和填充激活条件的载体)

**来源原语**：寻路(pathfinding, #18-b15fca0b), 四邻接连通(four_neighbor_connect, #18), 障碍像素(blocker_pixel, #18), 端点像素(endpoint_pixel, #18), 最短路径唯一(unique_shortest_path, #18), 填充(fill, #3-84f2aca1), 矩形边框(rectangular_frame, #3), 封闭内部(enclosed_interior, #3), 面积阈值决定颜色(area_threshold_determines_color, #3)

**依赖链**：迷宫拓扑 + 边框缺口位置共同决定最短路径走向 → 路径是否穿过某边框内部取决于缺口朝向和迷宫阻塞情况 → "是否穿过"这个二值判定决定该边框内部的填充颜色。路径选择是全局最优化的结果，不能通过单独分析某个边框来预测。

找到两个端点之间穿越迷宫的最短路径，路径穿过其内部的边框填灰色，路径绕过的边框填其自身边框色。

**输入结构**：背景黑(0)，网格约 18x18。蓝(1)像素形成迷宫墙壁（分布在网格各处，形成连通或不连通的障碍结构）。网格中有 3~4 个不同颜色的单像素厚空心矩形边框（颜色从红(2)、绿(3)、橙(7)、品红(6)中取，边框尺寸 4x4 到 6x6 不等）。每个边框在其上下左右四条边中的两条对边上各有恰好一个缺口（缺失一个边框像素），形成两个出入口。两个红(2)端点像素分别位于网格的相对两侧（如左上区域和右下区域），不在任何边框内部。生成约束：存在唯一最短路径；该路径穿过至少一个边框的内部且绕过至少一个边框；蓝色墙壁不封死任何边框的两个缺口。

**规则**：
1. 将蓝(1)像素和完整的边框像素（非缺口位置）视为不可通行障碍。缺口位置和黑(0)背景格可通行。
2. 寻找从一个红(2)端点到另一个红(2)端点的唯一最短 4-邻接路径。
3. 将路径上的所有黑(0)格涂为黄(4)。
4. 对每个矩形边框判断：路径是否从该边框的一个缺口进入、经过其内部、从另一个缺口离开。
5. 若路径穿过该边框内部：将边框内部未被路径占据的黑(0)格填充为灰(5)。
6. 若路径未穿过该边框内部：将边框内部的黑(0)格填充为该边框自身的边框颜色。
7. 蓝色墙壁、边框像素、红色端点、黄色路径均保持不变。

**关键洞察**：每个边框的填充颜色并非由它自身的几何属性决定，而取决于全局最优路径是否"选择"经过它——这是一个涌现属性，改变远处一块蓝色墙壁可能导致路径改道，从而翻转某个边框的填充颜色。
