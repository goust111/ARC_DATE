## 新题 11：种子周期竖线与端点拼接的交织约束

**组合逻辑**：[种子周期生成竖线](创新：多个种子各生成一组周期竖线段，段组之间不独立而需对齐拼接) + [端点匹配拼接](创新：拼接对象不是预存的路径片段，而是种子动态生成的竖线段组) + [滑动/平移](保留竖直位移语义，用于对齐)

**来源原语**：连线(draw_line, #6-8403a5d5), 种子像素(seed_pixel, #6), 竖线段(vertical_bar, #6), 周期间隔(periodic_space, #6), 种子周期生成竖线(seed_periodic_bars, #6), 拼接(concatenation, #8-d017b73f), 端点对齐(endpoint_align, #8), 端点匹配拼接(endpoint_match_concat, #8), 路径片段(path_segment, #8), 滑动(sliding, #8)

**依赖链**：每个种子的行位置和颜色→决定其竖线段组的高度分布和颜色→段组的左右边缘竖线的顶端像素作为"端点"→相邻段组通过端点行匹配来决定竖直位移量→位移后拼接。种子的行位置同时控制了"自身图案"和"与邻居的对接方式"。

每个种子像素生成一组周期竖线段，然后按端点高度匹配将各段组竖直对齐后水平拼接为连续图案。

**输入结构**：背景黑(0)，网格约 6x20。网格中有 3~4 个不同颜色的种子像素（颜色从蓝(1)、红(2)、绿(3)、橙(7)中取），分布在不同列且不同行上。种子之间由全黑列分隔（每两个种子之间至少隔 3 个空列）。生成约束：各种子行位置互不相同；每个种子右侧至少有 4 列空间用于生成竖线段。

**规则**：
1. 按列坐标从左到右排列种子像素。
2. 对每个种子，从种子所在列开始，每隔 2 列向右生成一条竖线段（共 3 条），颜色为种子颜色。每条竖线从种子所在行向上延伸至网格顶行（第 0 行）。在竖线之间的列上放置灰(5)标记像素，交替放在第 0 行和最底行。
3. 每个段组的"右端点"定义为其最右竖线的顶端像素行号（即种子所在行，因为竖线从该行向上延伸到第 0 行）。每个段组的"左端点"定义为其最左竖线的顶端像素行号（同理）。
4. 去除段组之间的全黑分隔列。从最左段组开始，保持其竖直位置不变。对后续每个段组：将其整体竖直平移，使其左端点行与前一个段组的右端点行相同。
5. 水平拼接所有段组（直接左右相邻，无间隔列）。若平移后某竖线超出网格上方，则截断超出部分；若竖线不足以到达第 0 行（平移向下），则竖线在其新起始行终止。
6. 输出为拼接后的网格。输出高度等于输入高度，输出宽度等于所有段组宽度之和。

**关键洞察**：种子所在行的差异不仅决定了各自竖线段的长度，还决定了段组之间的竖直位移量——一个种子在第 2 行、邻居在第 4 行意味着拼接时后者要上移 2 行。种子行位置同时编码了"图案高度"和"对接偏移"两层信息。
