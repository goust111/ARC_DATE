## 新题 10：互补掩码印章构建脚手架后重力灌注

**组合逻辑**：[印章覆盖/像素放大](保留自身互补的掩码印章语义) + [重力下落](创新：不作用于预设的盆地，而作用于印章操作涌现出的脚手架结构) + [碰撞停止](创新：停止面是印章操作的产物，不是输入中预先存在的)

**来源原语**：印章覆盖(stamp_overlay, #15-0692e18c), 像素放大(pixel_scaling, #15), 前景像素(foreground_pixel, #15), 互补掩码(complement_mask, #15), 自身互补(self_complementary, #15), 前景位置放置瓦片(tile_at_foreground_positions, #15), 重力下落(gravity_drop, #1-28a6681f), 碰撞停止(collision_stop, #1)

**依赖链**：3x3 输入的前景像素位置 → 确定哪些 3x3 输出块放置瓦片 → 瓦片形状 = 输入的黑色像素掩码（互补）→ 印章后的 9x9 网格形成墙壁结构 → 墙壁结构的顶部空隙成为水源位置 → 水源像素重力下落穿过空隙、停在墙壁上。同一个 3x3 图案同时编码"哪里有墙"和"哪里有水源"。

一个 3x3 双色图案同时编码印章模板和放置位置：先做互补掩码印章生成 9x9 脚手架，再从脚手架顶部空隙灌入水滴并模拟重力沉积。

**输入结构**：背景黑(0)，一个 3x3 网格。其中若干格为蓝(1)前景像素，其余为黑(0)。蓝色像素数量在 3~5 之间（既不太满也不太空，以确保互补掩码有足够的墙壁结构和空隙）。生成约束：互补掩码印章后的 9x9 网格中，顶行（第 0 行）至少有一个黑色空隙（作为水源入口）；存在至少一条从顶行到底行的非全黑竖直通道（确保水能流到底部附近）。

**规则**：
1. 取 3x3 输入中所有黑(0)格的位置集合作为瓦片模板 T。
2. 创建一个 9x9 全黑输出网格。对输入中每个蓝(1)前景像素位置 (r, c)，将瓦片模板 T 印在输出网格的 3r~3r+2 行、3c~3c+2 列对应区块中，印章颜色为蓝(1)。（即：输入中蓝色位置的输出块用输入中黑色位置的形状来印。）
3. 对输入中每个黑(0)位置，输出对应的 3x3 块保持全黑。
4. 印章完成后，在 9x9 网格的第 0 行（最顶行）中，将每个黑(0)格放置一个红(2)水像素。
5. 模拟重力下落：每个红(2)水像素逐格向下移动穿过黑(0)格，遇到蓝(1)墙壁像素、其他已沉积的红(2)像素、或网格底边时停止。处理顺序：从最底行的红色像素开始向上逐行处理，同行从左到右。
6. 输出包含蓝(1)墙壁和红(2)沉积水像素的最终 9x9 网格。

**关键洞察**：互补关系产生了一个精妙的自矛盾——在某个 3x3 块中是墙壁的位置，在另一个块的对应位置恰恰是空隙（水源或通道）。3x3 图案越"满"（蓝色越多），印章模板越"空"（墙壁越少），导致水更容易流到底部；反之图案越"空"，墙壁越密，水被截留在高处。同一个图案的密度同时控制了两个相反的效果。
