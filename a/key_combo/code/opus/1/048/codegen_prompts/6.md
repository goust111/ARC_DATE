## 新题 6：标记滑动轨迹方向编码镜像轴

**组合逻辑**：[滑动](创新：不只移动一步，而是全程滑动留下轨迹) + [镜像](创新：镜像轴不预设，而由滑动轨迹的方向动态决定) + [画布倍增](保留：输出画布沿镜像方向翻倍)

**来源原语**：滑动(slide, #10-dc433765), 标记像素(marker_pixel, #10), 目标像素(target_pixel, #10), 共线对齐(collinear_aligned, #10), 趋近目标(approach_target, #10), 镜像(mirror, #9-cad67732), 画布倍增(canvas_doubled, #9), 周期重复(periodic_repeat, #9)

**依赖链**：绿-黄对齐方向（水平/竖直/对角）→ 轨迹方向 → 镜像轴（轨迹的垂直方向）→ 画布扩展方向 → 前景图案在扩展画布上的镜像副本位置。滑动动作本身编码了一条几何指令，该指令作用于整个画布上的所有其他内容。

绿色标记向黄色目标滑动留下轨迹，轨迹方向决定整个网格沿垂直方向镜像并拼接到翻倍画布上。

**输入结构**：背景黑(0)，网格约 8x8。恰好一个绿(3)标记像素和一个黄(4)目标像素，二者在同一行、同一列或同一条 45 度对角线上，且间距至少 3 格。网格中另有若干品红(6)像素构成一个不对称的小图案（3~5 像素的 4-连通图形），该图案不与绿色或黄色像素同行/同列/同对角线（不会被轨迹覆盖）。生成约束：品红图案完全在网格内部（距边界至少 1 格），以确保镜像后不出界。

**规则**：
1. 绿(3)标记沿其与黄(4)目标的共线方向逐格移动，直到到达黄色目标的紧邻格（不覆盖黄色像素）。每经过的格子涂为绿(3)，形成轨迹。原始绿色格保留。
2. 判断轨迹方向：水平（同行）、竖直（同列）、或对角（45度）。
3. 根据轨迹方向确定镜像操作和画布扩展：
   - 水平轨迹 → 沿水平方向的垂线即竖直轴镜像 → 画布宽度翻倍。原图放在左半，左右镜像放在右半。
   - 竖直轨迹 → 沿竖直方向的垂线即水平轴镜像 → 画布高度翻倍。原图放在上半，上下镜像放在下半。
   - 对角轨迹 → 画布宽度和高度均翻倍。原图放在左上象限，其余三个象限分别为左右镜像、上下镜像、中心对称。
4. 镜像操作作用于轨迹完成后的整个网格内容（包括轨迹本身、品红图案、黄色目标像素）。
5. 输出为扩展后的完整画布。

**关键洞察**：绿-黄的对齐关系不仅产生一条视觉轨迹，更隐式编码了一条对称指令——水平对齐意味着"竖直镜像"，竖直对齐意味着"水平镜像"，对角对齐意味着"双轴镜像"。这个方向到对称操作的映射关系需要对比不同示例才能归纳。
