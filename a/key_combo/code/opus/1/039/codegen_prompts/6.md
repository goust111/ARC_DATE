## 新题 6：镜像合并涌现封闭区域后洪泛填充

**组合逻辑**：[镜像/reflect + 纵向拼接/vertical_stacking](已有原语) → [逻辑或合并/logical_or_merge](创新：合并的是原图与自身镜像，而非两个独立掩码) → [洪泛填充/flood_fill](创新：填充的封闭区域仅在合并后才存在) → [擦除/erase](已有原语)

**来源原语**：reflect/vertical_stacking/symmetric_appending_reversed_rows(参考题7-8be77c9e)、logical_or_merge(参考题2-195ba7dc)、flood_fill/background_corridor/region_containment(参考题15-a64e4611)、enclosed_region/interior_containment(参考题8-b2862040)、erase(参考题9-f76d97a5)

**依赖链**：镜像产生对称副本 → 与原图或合并 → 合并后出现原图中不存在的封闭区域（涌现效应！） → 洪泛填充封闭区域 → 擦除墙壁像素。删除镜像则无封闭区域；删除合并则墙壁不完整；删除洪泛填充则输出为空。

将半封闭的墙壁结构与其垂直镜像合并，涌现出完整的封闭区域，再洪泛填充这些区域。

**输入结构**：黑(0)背景，约15x15网格。灰(5)像素构成若干互不相连的线段或弧形片段（每段3~8像素，4-连通），分布于网格上半部和下半部。关键约束：这些灰(5)片段在原图中不围成任何封闭的背景区域（即所有背景像素均与网格边界背景连通），但当整个网格沿水平中轴（行 H/2）上下翻转后与原图叠加（像素取或），叠加后的灰(5)墙壁围成至少1个且不超过4个封闭的4-连通背景区域。输入中不出现绿(3)。各封闭区域面积至少4像素。

**规则**：
1. 构造镜像网格：将原输入沿水平中轴上下翻转（第 r 行映射到第 H-1-r 行）。
2. 逻辑或合并：对每个位置 (r, c)，若原输入或镜像网格中任一为灰(5)，则合并结果为灰(5)；否则为黑(0)。输出网格尺寸与输入相同。
3. 在合并结果中，找到所有4-连通的黑(0)背景区域。将与网格边界相邻（区域中存在像素位于第0行、最后一行、第0列或最后一列）的背景区域标记为"外部"。
4. 对每个非外部的背景区域（即封闭区域），将其所有像素洪泛填充为绿(3)。
5. 将所有灰(5)像素擦除为黑(0)。
6. 输出：黑(0)背景上仅保留绿(3)的填充区域。

**关键洞察**：原图中没有任何封闭区域——封闭性完全是镜像合并后的涌现效果。求解者必须先想到"镜像叠加"这一构造步骤，才能理解绿色区域从何而来。这是典型的 A+B 涌现：单独的原图或单独的镜像都不产生封闭区域，合并后才出现。
