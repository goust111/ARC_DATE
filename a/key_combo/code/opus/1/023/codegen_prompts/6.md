## 新题 6：对角印章轨迹穿越分隔区域时变色

**组合逻辑**：[flood_fill + positional_ordering](按位置为分隔区域赋色) ⊕ [stamp + diag_offset_repeat + size_determines_stride](对角印章轨迹) → 轨迹格的颜色由其所在区域的填充色替换（交叉约束）

**来源原语**：flood_fill / divider_line / bounded_region / positional_ordering / position_determines_fill_color（来自 941d9a10）；stamp / solid_rect / diag_offset_repeat / size_determines_stride / clip（来自 e619ca6e）

**依赖链**：区域填充确定了每个格的区域归属色；印章轨迹的落点分布在多个区域中；落在已填充区域的印章格被强制变色为该区域色。两个操作不是先后执行——区域色影响印章外观，而印章是在区域之上绘制的。最终输出需要同时考虑区域填充和印章覆盖。

灰色分隔线将网格划分为若干区域并按位置赋色；小矩形沿对角线生成印章轨迹，轨迹格落在哪个已赋色区域就呈现该区域的颜色。

**输入结构**：约 18x18 的网格，背景为黑(0)。灰(5)水平线和竖直线将网格分割成 4-6 个矩形区域。在所有区域中，恰好有 3 个区域各包含一个单像素种子（分别为蓝(1)、红(2)、绿(3)），其余区域无种子。另外，网格上有 1-2 个小实心矩形（使用黄(4)或橙(7)，每个矩形约 2x2 或 2x3），位于某个区域内部（不跨越分隔线）。生成约束：三个种子所在区域互不相邻（不共享分隔线边界）；小矩形的对角轨迹路径至少穿过 2 个不同的已赋色区域；小矩形不与任何种子像素重叠。

**规则**：
1. 对每个含种子的区域做泛洪填充，将该区域所有黑(0)背景格填为种子颜色。填充不穿越灰(5)分隔线。种子像素本身也保持其颜色。无种子的区域保持黑(0)。
2. 灰(5)分隔线保持不变。
3. 对每个小实心矩形（高 h、宽 w），以该矩形为起始位置，沿左下对角方向（偏移 (+h, -w)）和右下对角方向（偏移 (+h, +w)）重复印章，直到整个印章完全超出网格。超出网格的部分裁剪丢弃。
4. 印章格的颜色规则：若该格位于一个已填充区域内（非黑非灰），则该印章格呈现该区域的填充色（覆盖矩形原色）；若该格位于黑(0)未填充区域或恰好在灰(5)分隔线上，则该印章格保持矩形的原始颜色。
5. 原始小矩形自身保持不变（不受区域填充影响，始终保持原色）。
6. 多个印章格重叠时，后生成的覆盖先生成的（按先左下方向、再右下方向、从近到远的顺序）。

**关键洞察**：对角轨迹是"探针"——同一条轨迹上的印章格可能穿越多个不同颜色的区域，每个格呈现其所在区域的颜色，使得轨迹变成一串变色的色块序列。求解者必须同时理解区域填充规则和印章轨迹规则，二者缺一不可。需对比示例确认印章在已填充区域上变色（而非覆盖区域色或被区域色阻挡）。
