## 新题 8：完整方块筛选后按路径位移平移，非方块体充当射线障碍

**组合逻辑**：[only_complete_marked](完整方块检测，分类为"行动者") ⊕ [endpoints_encode_disp](路径端点编码位移向量) → [translate](方块平移) → [diagonal_ray](从平移后方块的角发射对角射线) ← 非方块体作为射线障碍（分类的副产物）

**来源原语**：complete_square / only_complete_marked / corner_adjacency（来自 14b8e18c）；path_endpoint / endpoints_encode_disp / diagonal_ray / hollow_frame（来自 2b9ef948）；translate（来自 25ff71a9 / 2b9ef948）

**依赖链**：完整方块检测将物体分为两类——方块（行动者）和非方块（障碍）。这一分类的两个产物分别馈入不同操作：方块接受平移和射线发射，非方块留在原位充当射线终止器。路径端点编码的位移向量应用于所有方块。分类操作的两面（通过/不通过）同时活跃，缺一则输出不完整。

检测哪些前景物体是完整方块，将它们按路径端点编码的位移向量平移，再从平移后方块的四角发射对角射线；未通过方块检测的物体留在原位，阻挡射线传播。

**输入结构**：约 18x18 的网格，背景为黑(0)。网格中有 2-3 个蓝(1)单色 4-连通前景物体，其中恰好 1-2 个是完整方块（边界框为正方形且所有边框格被蓝(1)填满，大小 3x3 或 4x4），其余为非方形物体（如 L 形、条形、不规则块，3-8 像素）。另外，网格中有一条灰(5)路径（由相邻灰(5)像素连成的 4-连通链），路径的两端各有一个红(2)像素（路径端点标识）。路径可以拐弯但两端的红(2)像素是唯一的红色像素。生成约束：位移向量（从第一个红像素到第二个红像素）使得平移后的方块不超出网格边界且不与任何非方块物体重叠；平移后方块的对角射线路径上至少有一条会遇到非方块物体；两个红(2)端点分别位于路径的两端（路径拓扑上的度为 1 的节点）。

**规则**：
1. 识别所有蓝(1) 4-连通前景物体。对每个物体判断是否为完整方块：其边界框为正方形，且该正方形边框上每个格子都是蓝(1)。
2. 找到两个红(2)像素。计算从第一个红像素（行号较小者；若行号相同则列号较小者）到第二个红像素的位移向量 (dr, dc)。
3. 将每个完整方块沿 (dr, dc) 平移：原位置的蓝(1)像素变为黑(0)，新位置画上蓝(1)方块。
4. 从每个平移后方块的四个角像素出发，分别沿四个对角方向（左上、右上、左下、右下，每角一个朝外的方向）发射蓝(1)射线，逐像素延伸。
5. 射线终止条件：(a) 到达网格边界；(b) 遇到非方块的蓝(1)物体像素——射线在该像素的前一格停止（不覆盖非方块物体）。
6. 灰(5)路径和红(2)端点在输出中被擦除（变为黑(0)）——它们仅用于编码位移，不出现在输出中。
7. 非方块物体保持不变。

**关键洞察**：物体分类不是简单的筛选丢弃——未通过方块检测的物体不被丢弃，而是转变角色成为射线的障碍。同一个分类操作同时产生"行动者"和"障碍者"，两类产物在后续操作中交互。需对比示例才能确认射线遇到非方块物体时停止（而非穿过或覆盖）。
