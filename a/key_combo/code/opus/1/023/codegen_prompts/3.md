## 新题 3：包含深度决定重涂色与角标记颜色

**组合逻辑**：[containment_tree](嵌套结构分析) → [recolor](按深度赋色) → [marking + corner_adjacency](仅对完整方块做角标记，标记颜色由深度决定)

**来源原语**：nested_frame / containment_tree / topology_determines_layout（来自 2d0172a1）；recolor（来自 0d3d703e / ce9e57f2）；marking / complete_square / corner_outside_pixel / corner_adjacency / only_complete_marked（来自 14b8e18c）

**依赖链**：包含树深度同时决定两件事——框架自身的重涂色和角标记的颜色。角标记操作依赖重涂色的结果来确定标记颜色，而重涂色依赖包含树分析的结果来确定目标颜色。三者形成链式依赖：拓扑分析 → 重涂色 → 角标记颜色。同时，"完整方块"筛选条件独立于深度，与深度信息交叉决定最终输出。

分析多层嵌套框架的包含深度，按深度重涂色，然后仅对其中的完整方块框架做角外标记，标记颜色取该方块的深度颜色。

**输入结构**：约 20x20 的网格，背景为黑(0)。网格中有 4-6 个灰(5)空心框架（即矩形边框，内部为黑(0)），部分框架嵌套在其他框架内部。框架可以是正方形或长方形。嵌套深度最多 3 层（最外层深度 0，其内一层深度 1，再内一层深度 2）。同一深度可有多个并列的框架。所有框架初始均为灰(5)。生成约束：至少有 2 个框架是完整方块（边界框为正方形且所有边框格都被填满）；至少有 1 个框架是非方形矩形；嵌套的框架之间至少有 1 格间距；至少存在深度 0 和深度 1 两层。

**规则**：
1. 对所有灰(5)框架建立包含树：若框架 A 的内部区域完全包含框架 B，则 B 是 A 的子节点。最外层（不被任何框架包含）的框架深度为 0。
2. 按深度重涂色：深度 0 → 蓝(1)，深度 1 → 红(2)，深度 2 → 绿(3)。每个框架的所有像素都改为对应深度的颜色。
3. 在重涂色后的网格上，识别哪些框架是完整方块（边界框为正方形，且该正方形边框上的所有格子都被该框架的颜色填满）。
4. 对每个完整方块框架，在其四个角的外侧各画两个标记像素：每个角的外侧正交方向（上下或左右）各一个，标记颜色与该方块重涂色后的颜色相同。标记只画在背景格(黑(0))上；若该位置已有其他框架像素或超出网格，则不画。
5. 非完整方块的框架仅做重涂色，不做角标记。

**关键洞察**：角标记的颜色不是固定的红色或某个预设颜色，而是取决于该方块在包含树中的深度——同样是完整方块，外层的标蓝(1)、内层的标红(2)。求解者必须先完成拓扑分析和重涂色，才能确定标记颜色。仅看单个示例可能误以为标记颜色固定，需对比多个示例（不同深度的方块有不同标记色）才能归纳。
