## 新题 4：重力沉降压缩符号后投射 L 形射线

**组合逻辑**：[压缩/compress + 重力下落/gravity_drop + 标记指示方向](确定沉降后位置) → [射线延伸/ray_extend + 投射到最近边界](依赖沉降后位置确定方向)

**来源原语**：压缩/compress、空心符号/hollow_symbol、边缘标记线/edge_marker_line、栅格对齐/grid_aligned、标记指示方向/marker_indicates_dir、重力下落/gravity_drop（← #11 afe3afe9）；射线延伸/ray_extend、标记像素/marker_pixel、投射到最近边界/projection_to_nearest_edge（← #15 705a3229）

**依赖链**：边缘标记线决定重力方向 → 压缩后的像素沿重力方向沉降堆叠 → 沉降后每个像素到四条网格边的距离全部改变 → 最近边界方向（决定 L 形射线的两个臂朝向）完全依赖沉降后位置。同一组符号更换标记线位置，射线图案完全不同。

将粗格点上的空心 3x3 符号压缩为单像素，按边缘标记线指示的重力方向沉降堆叠，每个像素向最近的水平边和最近的垂直边各投射一条同色射线。

**输入结构**：
- 黑(0)背景网格，约 15x15
- 内含 4~6 个空心 3x3 符号（每个符号由一种独立颜色绘制，如红(2)、绿(3)、蓝(1)、橙(7)等；空心指中心像素为背景色，八个边界位中至少六个有色），分布在步长为 3 的粗格点上（如左上角在 (0,0), (0,3), (3,0) 等），符号之间有空行/列间隔
- 一条满跨的品红(6)线沿网格某一条边绘制（顶边/底边/左边/右边之一），宽度 1 像素
- 生成约束：符号的分布使得压缩+沉降后至少有 2 个像素的"最近水平边"方向或"最近垂直边"方向与仅压缩（不沉降）时不同

**规则**：
1. 将每个 3x3 空心符号替换为其颜色的一个像素，放置在该符号在粗格点中的逻辑坐标上；移除所有不含符号的格点行和格点列，得到紧凑网格（品红标记线不参与压缩，在压缩后移除）
2. 根据品红(6)标记线在原始网格中的位置确定重力方向：顶边 → 向右，右边 → 向下，底边 → 向左，左边 → 向上（顺时针映射）
3. 沿重力方向沉降所有像素：保持每个像素在垂直于重力方向的轴上的坐标不变，沿重力方向移动直到碰到紧凑网格的该方向边界或另一个已沉降的像素。处理顺序：沿重力方向距目标边界最近的像素先处理
4. 对沉降后的每个像素 P 位于 (r, c)，设紧凑网格尺寸为 H x W：
   - 计算到上边距离 d_up = r，到下边距离 d_down = H-1-r，到左边距离 d_left = c，到右边距离 d_right = W-1-c
   - 沿列方向（上或下）向 d_up 和 d_down 中较小者的方向画射线，从 P 到该边界（含边界格），颜色与 P 相同；若 d_up = d_down 则选上方
   - 沿行方向（左或右）向 d_left 和 d_right 中较小者的方向画射线，从 P 到该边界（含边界格），颜色与 P 相同；若 d_left = d_right 则选左方
5. 多条射线交叉时：后绘制的覆盖先绘制的。绘制顺序：按像素在沉降后网格中从左到右、从上到下的顺序
6. 像素本身的颜色保留（不被射线覆盖）

**关键洞察**：重力方向改变每个像素的最终位置，从而改变"最近边界"的判定和射线朝向——同一组符号仅改变标记线位置（换一条边），所有射线的方向和长度都可能完全改变。重力与射线通过位置深度耦合。

## 实现要求

1. `main(grid)` 必须实现新题描述中的确定性转换规则，不能只识别 `generate_input()` 的固定模板。禁止不同的input网格输出相同的output网格。
2. `generate_input()` 必须随机生成多样样例，不能固定死。随机维度应覆盖：网格大小、对象数量、位置、颜色、方向、形状参数或关键分支。注意若描述中存在若干，需实现而不是只有单个，包括object或者对应关系等等。
3. 生成器必须保证输入满足 `main()` 的隐式假设：对象不重叠、不越界、特殊标记唯一或可区分、匹配关系无歧义、关键分支出现概率相同。
4. 禁止把 ARC 颜色 id 、亮度、拼写等当作人类不可见的数值语义参与排序、大小比较或隐藏映射。颜色变化必须有可见结构线索。注意颜色亮度、拼写等也是不可见信息，若描述中出现违规的颜色id或者亮度，可自行使用少量的固定颜色替代，但注意生成时要在三个以内输入输出网格中对所有变换100%覆盖度。
5. 输出样例要视觉清晰，人类必须能从输入输出对中肉眼辨认出规律。具体要求：避免对象粘连、覆盖关系混乱、同一像素多重语义；不同逻辑步骤产生的结果不要大面积层叠在一起导致无法分辨哪个颜色属于哪个步骤；输入中各元素之间保持足够间距，输出中新增的标记/填充/路径等应与背景和已有元素在颜色上有明显区分；若规则涉及多层叠加，生成时控制对象密度和尺寸，确保叠加区域只占少数像素而非铺满整个网格。
6. 若规则有多个分支，生成器不能长期固定成一个分支；应让分支在随机样例中合理出现。分支概率不必平均——难以发现的隐蔽分支（如少数情况下才触发的特殊规则）应适当提高出现概率，确保在 3 个训练示例中至少出现一次，否则求解者无法归纳该规则。对于颜色映射类规则，确保 2 个左右的示例即可覆盖所有映射关系（每种颜色→颜色的映射至少在某个示例中出现过）。
