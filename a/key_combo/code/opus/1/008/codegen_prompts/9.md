## 新题 9：拉丁方约束消歧多标记邻接传色

**组合逻辑**：[邻接传色adjacency_transfer + 标记接触即赋色marker_touch_color](已有，创新：单个中性区域可能接触多个不同色标记导致歧义) + [拉丁方约束latin_square_constraint + 补全completion](已有，创新：拉丁方约束用于消除邻接传色的歧义而非直接填色) + [擦除erase](已有)

**来源原语**：标记像素(marker_pixel), 中性遮罩(neutral_mask), 邻接传色(adjacency_transfer), 标记接触即赋色(marker_touch_color), 擦除(erase) ← b7256dcd；补全(completion), 色表(color_table), 空白单元(blank_cell), 行列唯一约束(row_column_uniqueness_constraint), 拉丁方约束(latin_square_constraint) ← 4cd1b7b2；分隔行列(separator_row_col), 格点交叉(lattice_intersection) ← 95a58926

**依赖链**：中性区域的邻接标记颜色提供候选色集合，但当一个区域同时接触多种标记时，仅靠邻接无法确定唯一颜色。此时需要区域在 K x K 网格中的行列位置满足拉丁方约束才能消歧。若只有邻接传色，某些区域有多个候选色无法决定；若只有拉丁方约束，某些区域的候选色集合太大也无法唯一确定。两套约束同时作用才能唯一求解。

中性色区域从邻接标记获取候选颜色，但需要拉丁方行列唯一约束才能从候选中选出唯一正确的颜色。

**输入结构**：网格约 15x15，背景为黑(0)。网格被灰(5)色的单像素厚分隔行和分隔列切割为 K x K 个矩形单元（K = 4 或 5）。每个单元内部要么填有一种非黑非灰的前景色（固定单元），要么全部为青(8)色（中性待定单元，共 2~4 个）。在中性单元的边界外侧（紧邻分隔行或分隔列的另一侧），有彩色单像素标记（颜色取自蓝(1)、红(2)、绿(3)、黄(4)等已在固定单元中使用的颜色），通过分隔线间隙或分隔线外侧与中性单元 4-邻接。部分中性单元仅接触一种标记色（邻接即可确定），但至少有一个中性单元接触两种或以上标记色（仅靠邻接无法确定）。固定单元满足同行不重色、同列不重色。生成约束：邻接候选 + 拉丁方约束联合确定每个中性单元的唯一颜色。

**规则**：
1. 识别分隔行和分隔列（灰(5)色的完整行/列），确定 K x K 的单元网格结构。
2. 对每个青(8)色中性单元，收集其 4-邻接范围内（越过分隔线一像素）所有标记像素的颜色，作为该单元的候选色集合。
3. 将固定单元和候选色约束代入拉丁方求解框架：每行每列恰好包含全部 K 种前景色各一次。
4. 唯一确定每个中性单元的颜色后，将该单元的所有青(8)像素重涂为确定的颜色。
5. 擦除所有标记像素（变为背景黑(0)）。分隔行列保留灰(5)不变。

**关键洞察**：源题 b7256dcd 中每个中性区域最多接触一种标记色，邻接即可唯一确定；源题 4cd1b7b2 中拉丁方的候选色是全集减去已有色。本题中两套约束各自不足——邻接提供了局部候选但可能不唯一，拉丁方提供了全局约束但可能也不唯一——它们必须同时生效才能联合消歧，形成了真正的约束交织而非顺序叠加。
