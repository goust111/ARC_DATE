## 新题 8：边缘色序编码行偏移量扭曲周期瓦片

**组合逻辑**：[边缘像素edge_pixel + 颜色编码列color_coded_col](已有，创新：颜色编码的不是目标列而是循环偏移量) → [重复瓦片repeating_tile + 周期延拓periodic_extension + 补全completion](已有) + [周期偏移延续行period_shift_rows](已有，创新：偏移量来自外部编码序列而非图案内在周期)

**依赖链**：必须先从完整行推断并补全周期瓦片以获得完整图案。左边缘的颜色序列编码了每行的水平循环偏移量。必须按偏移量逐行移位才能得到最终输出。若跳过补全，含占位符的行无法参与移位；若忽略边缘序列，不知道每行偏移多少；若不移除边缘列，输出多一列。

补全部分可见的周期瓦片图案，然后按左边缘像素颜色编码的偏移量逐行水平循环移位，生成扭曲后的图案。

**输入结构**：网格约 10x12（10 行 12 列）。最左列（第 0 列）为指令列，每行恰好一个彩色像素，颜色取自蓝(1)、红(2)、绿(3)、黄(4)，编码该行的水平循环右移量（蓝(1) = 右移 1 格，红(2) = 右移 2 格，绿(3) = 右移 3 格，黄(4) = 右移 4 格）。瓦片区域（第 1 列到最后一列）：大部分行填有一个可识别的周期瓦片图案（最小瓦片约 3x3 到 4x4，使用 2~3 种颜色，取自灰(5)、橙(7)、青(8)等不与指令色重复的颜色），但有若干行（1~3 行）的瓦片不完整——行末若干连续格为品红(6)占位符。生成约束：品红(6)不出现在瓦片图案中也不出现在指令列中；占位符总是在行末连续出现；至少有 2 行是完整的（无占位符），足以推断最小瓦片。

**规则**：
1. 忽略第 0 列（指令列），对第 1 列到末列区域，利用完整行（不含品红(6)的行）推断最小水平周期瓦片。
2. 将瓦片周期延拓，替换所有品红(6)占位符像素为周期图案对应位置的颜色，得到完整的瓦片区域。
3. 对每行 r（r = 0 到末行），读取第 0 列的颜色编号 c_r，计算偏移量 d_r = c_r（即蓝 1→1，红 2→2，绿 3→3，黄 4→4）。
4. 将该行的瓦片区域（第 1 列到末列的完整图案）整体循环右移 d_r 格——右端溢出的像素回绕到第 1 列位置。
5. 输出仅包含移位后的瓦片区域（去掉第 0 列，输出宽度 = 原宽度 - 1）。

**关键洞察**：边缘像素在源题 f45f5ca7 中将单个像素滑动到颜色编码的目标列（一对一映射），这里同一个"颜色→数值"编码被用于完全不同的操作——整行循环移位。同时，周期补全在源题 50a16a69/53b68214 中是最终输出，这里只是中间步骤，补全后还要被扭曲。
