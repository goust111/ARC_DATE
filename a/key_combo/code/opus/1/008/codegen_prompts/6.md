## 新题 6：空心框遮蔽的对称图案恢复与内部色种计数填充

**组合逻辑**：[对称轨道symmetry_orbit + 对称恢复遮挡symmetry_restores](已有，创新：遮挡者是空心矩形框边框而非实心黑色矩形) → [计数counting](已有，创新：计数恢复后的色种数而非对象个数) + [填充fill + 重涂色recolor](已有，创新：填充颜色由色种计数决定而非框边长)

**来源原语**：遮挡矩形(occluding_rect), 平移对称图案(translational_pattern), 对称轨道(symmetry_orbit), 补全(completion), 对称恢复遮挡(symmetry_restores), 裁剪(crop) ← f9012d9b；空心矩形(hollow_rectangle), 填充(fill), 按边长映射颜色(size_to_color_mapping) ← 00dbd492；计数(counting), 色数决定倍率(color_count_scale) ← d4b1c2b1；重涂色(recolor) ← 95a58926

**依赖链**：框边框遮蔽了底层对称图案的部分像素，必须通过对称轨道恢复被遮蔽内容。恢复后统计框内部区域（含恢复的边框下方像素）的不同颜色数 C，C 值决定填充颜色。若跳过恢复，被边框覆盖的颜色可能缺失导致计数偏低；若跳过计数，无法确定填充色。

利用背景的平移对称性恢复被空心矩形框边框遮蔽的图案，统计框内恢复后的不同颜色数，以此决定框内部的统一填充色。

**输入结构**：网格约 15x15，全部由一个平移对称的多色图案填满（无真正的背景色，至少包含 3 种颜色，最小周期瓦片约 3x3 到 5x5）。网格中有 1~3 个灰(5)色的空心矩形框（单像素厚闭合边框），框边框像素覆盖了底层图案对应位置的颜色。框大小各异（5x5 到 9x9），框之间不重叠。框内部区域仍可见底层图案（仅边框位置被覆盖）。生成约束：灰(5)不出现在底层对称图案中；对称周期保证每个被边框覆盖的位置至少有一个同轨道的可见（非灰）位置；不同框的内部区域可能包含不同数量的色种（恢复后计数），使得不同框获得不同填充色。

**规则**：
1. 将灰(5)像素视为遮蔽标记。利用所有非灰像素检测底层图案的平移对称性（最小水平周期 Px 和垂直周期 Py）。
2. 对每个灰(5)像素，从其对称轨道（坐标差为 (k*Px, l*Py) 的所有位置）中找到一个非灰的等价位置，将该位置的颜色记为该灰色像素的恢复颜色。
3. 对每个框，收集其严格内部区域的所有像素（本来可见的内部像素 + 边框位置恢复后的颜色），统计共包含多少种不同颜色，记为 C。
4. 按 C 值映射填充颜色：C=1 对应蓝(1)，C=2 对应红(2)，C=3 对应绿(3)，C=4 对应黄(4)。
5. 将每个框的严格内部区域全部重涂为其对应的填充颜色。框的灰(5)色边框保留不变。

**关键洞察**：框的内部可以直接看到一部分颜色，但仅凭可见内部像素无法确定色种计数是否完整——边框覆盖的像素在恢复后可能引入内部不存在的新颜色，因此必须先通过对称恢复透视边框下的图案才能正确计数。这使得"恢复"不是为了获取内容本身（内容最终被填充覆盖），而是为了获取一个统计属性。
