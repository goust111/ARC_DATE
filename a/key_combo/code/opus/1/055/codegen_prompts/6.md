## 新题 6：框架嵌套层反转生成色表映射放大图案

**组合逻辑**：[像素放大/pixel_upscale](已有) + [层序反转/layer_order_reversal](已有，创新为从框架的层序提取颜色映射表而非在原地反转) + [重涂色/recolor](已有，创新为用反转映射表对放大后的图案重涂)

**来源原语**：像素放大(6b9890af)、包含于框架内(6b9890af)、框内尺寸决定缩放(6b9890af)、空心矩形/frame(6b9890af)、图案/pattern(6b9890af)、层序反转(8dae5dfc)、嵌套矩形层(8dae5dfc)、嵌套层次(8dae5dfc)、颜色序列逆转(8dae5dfc)、重涂色(5a5a2103)

**依赖链**：框架的嵌套层结构提供两项独立信息：(a)内部尺寸决定放大倍率，(b)层色序列反转生成颜色映射表；放大操作使用 (a)，重涂操作使用 (b)，二者从同一结构的不同属性分叉获取参数，最终在框架内部汇合；删除层分析则映射未知，删除框架则倍率未知。

从嵌套多层的矩形框架读取颜色层序并反转为映射表，同时用框架内部尺寸放大小图案，再按映射表重涂放大后的图案并填入框架内部。

**输入结构**：约 15x15 的网格，黑(0)背景。网格中有一个由嵌套矩形层构成的框架结构：从外到内依次为 3-4 种不同颜色的矩形环（如从外到内：红(2)、蓝(1)、绿(3)），最内层是一个空心区域（全黑），其尺寸为某个小整数 S 乘以小图案尺寸。在框架外的网格某处有一个小图案（如 3x3），使用与框架相同的那几种颜色的子集绘制在黑背景上。生成约束：框架内部尺寸恰好是小图案尺寸的整数倍（即 S 为正整数）；小图案使用的颜色是框架层颜色的子集。

**规则**：
1. 识别框架的嵌套层颜色序列，从最外层到最内层记为 [C_1, C_2, ..., C_k]。
2. 构建颜色映射表：C_i 映射到 C_{k+1-i}（即序列反转映射）。例如若层序为 [红, 蓝, 绿]，则映射为 红→绿, 蓝→蓝, 绿→红。
3. 计算放大倍率 S = 框架最内层空心区域的边长 / 小图案的对应边长。
4. 将小图案等比放大 S 倍（每个像素变为 SxS 的色块）。
5. 对放大后的图案应用步骤 2 的颜色映射表：将每个非黑像素的颜色替换为其映射颜色。黑(0)像素保持不变。
6. 将重涂后的放大图案放入框架内部空心区域。框架的嵌套层保持不变。

**关键洞察**：框架结构身兼二职——它的几何尺寸提供放大倍率，它的层色序列提供颜色映射规则；两项信息来自同一个对象的不同属性，在单个示例中可能误以为颜色映射是固定的，必须对比框架层序不同的多个示例才能归纳出反转规则。

## 实现要求

1. `main(grid)` 必须实现新题描述中的确定性转换规则，不能只识别 `generate_input()` 的固定模板。禁止不同的input网格输出相同的output网格。
2. `generate_input()` 必须随机生成多样样例，不能固定死。随机维度应覆盖：网格大小、对象数量、位置、颜色、方向、形状参数或关键分支。注意若描述中存在若干，需实现而不是只有单个，包括object或者对应关系等等。
3. 生成器必须保证输入满足 `main()` 的隐式假设：对象不重叠、不越界、特殊标记唯一或可区分、匹配关系无歧义、关键分支出现概率相同。
4. 禁止把 ARC 颜色 id 、亮度、拼写等当作人类不可见的数值语义参与排序、大小比较或隐藏映射。颜色变化必须有可见结构线索。注意颜色亮度、拼写等也是不可见信息，若描述中出现违规的颜色id或者亮度，可自行使用少量的固定颜色替代，但注意生成时要在三个以内输入输出网格中对所有变换100%覆盖度。
5. 输出样例要视觉清晰，人类必须能从输入输出对中肉眼辨认出规律。具体要求：避免对象粘连、覆盖关系混乱、同一像素多重语义；不同逻辑步骤产生的结果不要大面积层叠在一起导致无法分辨哪个颜色属于哪个步骤；输入中各元素之间保持足够间距，输出中新增的标记/填充/路径等应与背景和已有元素在颜色上有明显区分；若规则涉及多层叠加，生成时控制对象密度和尺寸，确保叠加区域只占少数像素而非铺满整个网格。
6. 若规则有多个分支，生成器不能长期固定成一个分支；应让分支在随机样例中合理出现。分支概率不必平均——难以发现的隐蔽分支（如少数情况下才触发的特殊规则）应适当提高出现概率，确保在 3 个训练示例中至少出现一次，否则求解者无法归纳该规则。对于颜色映射类规则，确保 2 个左右的示例即可覆盖所有映射关系（每种颜色→颜色的映射至少在某个示例中出现过）。
7. 代码风格参考 `ARC_code`：使用 `numpy`，必要时使用本地 helper，但目标文件应能被 `SourceFileLoader` 直接加载。
8. 可以在目标目录放公共 helper 文件，但若只实现一道题，优先保持目标文件自包含，减少额外依赖。
