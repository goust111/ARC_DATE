## 新题 1：按嵌套深度排序并反转层色的矩形拼列

**组合逻辑**：[层序反转/layer_order_reversal](已有) + [计数/counting](已有，创新为计数嵌套深度而非标记像素) + [排序/sorting](已有，创新为按深度排序整个对象) + [拼接/concatenate](已有，创新为按排序结果水平拼列)

**来源原语**：层序反转(8dae5dfc)、嵌套层次(8dae5dfc)、排序(85b81ff1/beb8660c)、拼接(412b6263)、计数(8efcae92)、实心矩形(8efcae92)

**依赖链**：嵌套深度分析同时提供两项信息——层反转所需的层序列和排序所需的深度值；层反转改变每个矩形的视觉内容，排序改变矩形之间的空间排列；拼接消费排序结果和反转结果，缺任何一项都无法生成输出。

将多个独立的嵌套矩形按各自的嵌套层数从少到多排成一行，每个矩形内部的颜色层序同时被反转。

**输入结构**：黑(0)背景，约 12x18 的网格。散布 3-4 个互不重叠的实心矩形对象，每个矩形由同心嵌套的矩形颜色层组成（类似洋葱剖面：最外层一种颜色，内缩一圈换色，再内缩再换色……），不同矩形的尺寸、层数（2-4 层）和用色各不相同。每层厚度至少 1 像素，层厚可不均匀。所有矩形使用的颜色从红(2)、蓝(1)、绿(3)、黄(4)、灰(5)、品红(6)中选取，每个矩形内各层颜色互不相同。生成约束：各矩形的嵌套层数互不相等，保证排序无歧义。

**规则**：
1. 对每个矩形对象，从最外层向内逐层剥离，识别所有嵌套层及其颜色序列 [C_1, C_2, ..., C_k]（C_1 为最外层），其中 k 为该矩形的嵌套深度。
2. 在每个矩形内部，将第 i 层的颜色替换为第 (k+1-i) 层的颜色，即最外层和最内层互换、次外层和次内层互换，以此类推。各层的几何形状（厚度和范围）保持不变，仅颜色改变。
3. 按嵌套深度从小到大对所有矩形排序。
4. 将排序后的矩形（已完成层色反转）从左到右水平排列，相邻矩形之间隔 1 列黑(0)。所有矩形底部对齐。输出高度等于最高矩形的高度，较矮的矩形上方以黑(0)填充。

**关键洞察**：嵌套深度既是层反转操作的结构参数（决定哪些层互换），又是排序的依据——同一次结构分析同时驱动两种不同变换，删除深度分析则反转和排序都无法进行。

## 实现要求

1. `main(grid)` 必须实现新题描述中的确定性转换规则，不能只识别 `generate_input()` 的固定模板。禁止不同的input网格输出相同的output网格。
2. `generate_input()` 必须随机生成多样样例，不能固定死。随机维度应覆盖：网格大小、对象数量、位置、颜色、方向、形状参数或关键分支。注意若描述中存在若干，需实现而不是只有单个，包括object或者对应关系等等。
3. 生成器必须保证输入满足 `main()` 的隐式假设：对象不重叠、不越界、特殊标记唯一或可区分、匹配关系无歧义、关键分支出现概率相同。
4. 禁止把 ARC 颜色 id 、亮度、拼写等当作人类不可见的数值语义参与排序、大小比较或隐藏映射。颜色变化必须有可见结构线索。注意颜色亮度、拼写等也是不可见信息，若描述中出现违规的颜色id或者亮度，可自行使用少量的固定颜色替代，但注意生成时要在三个以内输入输出网格中对所有变换100%覆盖度。
5. 输出样例要视觉清晰，人类必须能从输入输出对中肉眼辨认出规律。具体要求：避免对象粘连、覆盖关系混乱、同一像素多重语义；不同逻辑步骤产生的结果不要大面积层叠在一起导致无法分辨哪个颜色属于哪个步骤；输入中各元素之间保持足够间距，输出中新增的标记/填充/路径等应与背景和已有元素在颜色上有明显区分；若规则涉及多层叠加，生成时控制对象密度和尺寸，确保叠加区域只占少数像素而非铺满整个网格。
6. 若规则有多个分支，生成器不能长期固定成一个分支；应让分支在随机样例中合理出现。分支概率不必平均——难以发现的隐蔽分支（如少数情况下才触发的特殊规则）应适当提高出现概率，确保在 3 个训练示例中至少出现一次，否则求解者无法归纳该规则。对于颜色映射类规则，确保 2 个左右的示例即可覆盖所有映射关系（每种颜色→颜色的映射至少在某个示例中出现过）。
7. 代码风格参考 `ARC_code`：使用 `numpy`，必要时使用本地 helper，但目标文件应能被 `SourceFileLoader` 直接加载。
8. 可以在目标目录放公共 helper 文件，但若只实现一道题，优先保持目标文件自包含，减少额外依赖。
