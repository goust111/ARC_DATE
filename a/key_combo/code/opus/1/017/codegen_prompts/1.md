## 新题 1：视线配对矩形的间距调相棋盘填充

**组合逻辑**：[视线匹配](创新：从路径-标记配对改为矩形-矩形配对) + [边框与内部分离](已有) + [行列奇偶决定填充](创新：奇偶相位由间距距离调制) + [擦除](已有，用于移除未配对矩形)

**来源原语**：视线匹配 ← #2(696d4842)；边框与内部分离、行列奇偶决定填充 ← #10(ba9d41b8)；填充矩形 ← #8(36fdfd69)/#13(470c91de)；擦除 ← #11(9b365c51)/#18(6d0160f0)

**依赖链**：视线匹配确定矩形配对关系 → 配对间距测量得到距离 G → G 调制棋盘奇偶相位 → 未配对矩形被擦除。删除视线匹配则无法知道谁和谁配对；删除间距测量则无法确定棋盘相位；删除棋盘填充则无法产生内部图案变化。

用一句话概括：通过行列视线将矩形两两配对，在每个配对矩形的内部填充棋盘格，棋盘的奇偶相位由配对间距的奇偶性决定，未配对矩形则被清除。

**输入结构**：
- 黑(0)背景，约 20x20 网格。
- 4-8 个单色填充矩形，每个至少 4x4，各自颜色互不相同（均为非黑、非红的 ARC 颜色）。矩形互不重叠、互不接触。
- 每个矩形的边框上恰好有 1 个红(2)标记像素（替换了该位置原本的矩形颜色）。
- 矩形两两配对：每对中，两个矩形的红标记像素之间存在唯一的清晰水平或垂直视线（视线上所有中间格均为背景(0)）。
- 生成约束：每个红标记只与恰好一个其他红标记互相可见，形成完美配对（无歧义）。可能存在 0-2 个不参与任何配对的孤立矩形（它们的红标记的视线方向上不可见任何其他红标记）。

**规则**：
1. 配对识别：两个矩形配对当且仅当它们的红边框标记之间有一条仅穿过背景(0)格的水平或垂直直线段（不含两端红标记本身）。
2. 对每一对，测量间距 G = 两个红标记之间沿视线方向的背景格数量（不含两端标记格本身）。
3. 对每个已配对的矩形，保留其 1 像素宽的边框不变。
4. 填充内部（边框严格内侧的所有格）为棋盘图案：对内部格在内部区域内的局部坐标 (r, c)（以内部左上角为 (0,0)），若 (r + c + G) mod 2 == 0，则设为背景(0)；否则保留矩形原色。
5. 移除所有红标记像素（设为该矩形的原色，恢复边框完整性）。
6. 将所有未配对的矩形整体擦除（所有格设为背景(0)）。

**关键洞察**：间距 G 的奇偶性决定棋盘相位翻转——同一对中的两个矩形共享同一个 G 值，因此它们的棋盘图案在全局坐标系下可能同相或反相，取决于各自内部左上角坐标与 G 的联合奇偶。这一规则只有通过对比不同间距的配对才能归纳出来。
