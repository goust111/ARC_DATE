## 新题 8：精灵体对接改变条周期 + 周期填缺

**组合逻辑**：[对接 + 色彩互换](已有) → 对接改变条的色彩序列 → [补全/周期修缺](创新：周期分析的输入包含对接引入的新像素，周期因此改变) + [擦除](已有)

**来源原语**：对接/dock + 色彩互换/color_swap + 双色精灵体/two_tone_sprite + 色条/color_bar + 同色匹配/same_color_matching + 颜色反转映射/inverted_color_mapping（参考题 7c66cb00）、补全/complete + 周期瓦片/periodic_tile + 周期对齐/periodic_align + 缺失像素/missing_pixel + 最小周期修复缺口/min_period_repair_gap（参考题 e95e3d8e）、擦除/erase（多题）

**依赖链**：精灵体按颜色匹配对接入色条并完成色彩互换 → 对接后的色条包含互换后的新颜色，改变了条的一维周期结构 → 用新周期填充条中剩余的黑色缺口。对接和填充不可独立运行：不做对接则条的周期是原始的（缺少精灵体引入的颜色），填出的结果错误；不做填充则条有缺口，输出不完整。

双色精灵体按外色匹配对接入对应水平色条并进行色彩互换，对接后色条的颜色序列形成新的一维周期，用该周期修复条上的黑色缺口。

**输入结构**：约 12x18 网格（宽 > 高），黑(0)背景。下半区有 2~3 条水平色条，每条占一行，跨越大部分列（约 12~16 列），每条有一个填充色和一个边框色（两端各 1~2 像素为边框色，中间为填充色），部分中间像素为黑(0)（缺口）。上半区有 2~3 个双色精灵体（每个为 1x2 或 2x1 的小图形，外色 1 像素 + 内色 1 像素）。每个精灵体的外色等于某条色条的填充色（一一匹配，不重复）。生成约束：对接并色彩互换后（精灵体外色 → 条边框色，精灵体内色 → 条填充色），每条色条的非黑像素构成一个一维周期序列（周期长度 2~4），且该周期在对接前（没有精灵体引入的像素）是不同的或不完整的（缺少确定周期所需的样本数）；每条至少有 1 个黑色缺口需要用对接后的周期填充。

**规则**：
1. 识别上半区的双色精灵体和下半区的水平色条。
2. 将每个精灵体匹配到填充色等于精灵体外色的色条。
3. 将精灵体放置到其匹配色条的行上，列位置与精灵体在上半区的原始列位置相同（水平不移动，垂直下移到色条行）。放置时执行色彩互换：精灵体的外色像素重涂为色条的边框色，精灵体的内色像素重涂为色条的填充色。
4. 擦除上半区的原始精灵体（重涂为黑(0)）。
5. 对每条色条（现在包含原始像素 + 对接引入的像素），分析其非黑像素的一维周期：找到最小周期长度 P，使所有非黑像素 (col) 的颜色满足 color(col) = tile[col mod P]。
6. 对色条行中每个黑(0)缺口像素 col，替换为 tile[col mod P]。
7. 输出网格尺寸与输入相同。

**关键洞察**：精灵体不只是装饰性地嵌入色条——它们引入的互换后颜色参与了周期计算，改变了周期的结构（例如原条可能看起来周期为 2，但对接后精灵体在特定位置引入新颜色，暴露出真实周期为 4）。因此对接操作实质性地改变了填充操作的数学基础。
