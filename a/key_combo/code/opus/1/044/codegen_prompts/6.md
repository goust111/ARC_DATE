## 新题 6：L 标记放大 + 缺角印章级联

**组合逻辑**：[像素放大](创新：L 标记不扩展到网格外角，而是按三角标记框的边长缩放) → 扩展结果充当印章原型 → [印章覆盖 + 缺角决定翻转](已有)

**来源原语**：像素放大/pixel_scale + 角落标记/corner_marker + 朝向对应角/facing_corner + 扩展至外角/expand_to_corner（参考题 b745798f）、印章覆盖/stamp + 精灵体/sprite + 三角标记框/three_corner_frame + 缺角定位/missing_corner_pos + 缺角决定翻转/flip_by_missing_corner + 镜像/mirror（参考题 ac0c5833）

**依赖链**：3 像素 L 标记的朝向确定"基准角"（源象限方向） → L 被缩放为与三角框边长匹配的角 L 形状（臂长 = 框边长 - 1） → 该角 L 成为精灵体原型 → 对每个三角框，在其缺角位置放置精灵体，根据缺角象限相对于基准角的关系进行反射。L 标记既是方向种子又是形状原型，三角框既提供放置位置又决定缩放比例。

一个 3 像素 L 标记按三角标记框的尺寸缩放为角 L 精灵体，然后以该精灵体为原型，在每个三角框的缺角位置放置反射副本。

**输入结构**：约 17x17（奇数正方形）网格，黑(0)背景。网格中有一个红(2)色 3 像素 L 形标记，占据一个 2x2 区域中的三个像素（如左上角缺失则 L 朝右下）。另有 2~4 个黄(4)色三角标记框，每个框由三个黄色单像素组成，标记同一正方形的三个角（正方形边长 S 一致，约 5~7；所有框相同边长）。每个三角框恰好缺一个角，缺角位置各不相同（有的缺左上，有的缺右下等）。框之间互不重叠，且有足够空间容纳放置的精灵体。生成约束：红色 L 标记的位置远离所有三角框（不与任何框的缺角区域重叠）；L 标记的臂长为 1 像素（原始 3 像素），缩放后臂长为 S-1。

**规则**：
1. 识别红(2)色 3 像素 L 标记，确定其朝向（L 的"开口"方向对应其在 2x2 盒中的缺失角，即源象限方向：若缺左上角 → 开口朝左上 → 源角为左上）。
2. 确定三角框的统一边长 S。将红色 L 标记按比例缩放：臂长从 1 变为 S-1，形成一个占据 S x S 区域中一个角落的角 L 形状（沿两条边各 S-1 个像素加上角顶点，总像素 = 2*(S-1)-1）。此缩放 L 的朝向与原始 L 一致，颜色为红(2)。
3. 对每个三角框，确定其缺角位置（左上/右上/左下/右下）。
4. 将缩放 L 放置在缺角位置的 S x S 区域内，使 L 的角顶点与缺角重合。若缺角象限与源象限相同，直接放置；若水平翻转，则水平反射 L；若垂直翻转，则垂直反射；若对角翻转（180 度），则水平+垂直反射。放置颜色为红(2)。
5. 擦除原始红色 L 标记（重涂为黑(0)）。黄色三角标记像素保留。
6. 放置区域中若有黄色标记像素，红色覆盖黄色（红色优先）。

**关键洞察**：小 L 标记不是被放大到网格角落（如参考题 b745798f），而是被缩放到与三角框匹配的尺寸后充当印章原型——L 的朝向决定"默认姿态"，每个三角框缺角的方向决定该处副本需要哪种反射，因此同一原型在不同框产生不同朝向的副本。
