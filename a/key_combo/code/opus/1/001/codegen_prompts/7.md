## 新题 7：弹性拉伸对齐后逐像素差异提取

**组合逻辑**：[弹性拉伸/内部行程/按目标尺寸调整](已有) + [逐像素比较/异或差异判定](已有) → [差异标记](创新：比较对象不是两幅同尺寸面板，而是一幅拉伸后的模板与一幅原始面板——拉伸是比较的前提条件)

**来源原语**：弹性拉伸(elastic_stretching)、多色范例矩形(multicolor_exemplar_rect)、内部行程(interior_run)、按目标尺寸调整(resize_to_target)来自 40f6cd08；逐像素比较(cell_by_cell_comparison)、异或差异判定(xor_difference)、面板对齐(panel_alignment)、分隔列(separator_column)来自 34b99a2b

**依赖链**：分隔列划分两个面板 → 弹性拉伸将小面板的范例矩形调整为大面板矩形的尺寸 → 拉伸结果与大面板逐像素比较 → 差异位置标记为特殊颜色。如果不做拉伸，两个面板尺寸不同，无法逐像素比较。如果不做比较，拉伸结果本身不是最终答案。

将分隔面板中较小的范例矩形弹性拉伸至较大矩形的尺寸，然后逐像素对比两者，输出差异位置标记图。

**输入结构**：约 12x22 网格（宽大于高），黑(0)背景。一条竖直灰(5)分隔列将网格分为左右两个面板。左面板包含一个较小的多色范例矩形（约 4x5），其四条边框为同一颜色（如蓝(1)），内部包含 2~3 种其他颜色形成条带图案。右面板包含一个较大的矩形（约 4x8 或 6x5），与范例矩形具有相同的边框颜色，内部也包含类似但不完全相同的条带图案（相当于"弹性拉伸范例矩形后再修改了若干像素"的结果）。两个矩形的行数相同但列数不同（或列数相同但行数不同），且恰好一个维度的边框行/列数相同，差异仅在内部行程的长度上。生成约束：右面板矩形可被视为范例矩形的弹性拉伸版本加上 2~5 个像素的修改（改变了某些像素的颜色）。

**规则**：
1. 识别灰(5)分隔列。提取左面板的范例矩形和右面板的目标矩形。
2. 对范例矩形进行弹性拉伸以匹配目标矩形的尺寸。拉伸算法：对行和列分别进行行程编码，保持所有边框行程（首行程和末行程）的长度不变，仅拉伸唯一的内部行程（在行/列两个方向上，选择包含最多不同颜色的行程为内部行程；若颜色数相同则选择原始长度较短的行程）使总长度匹配目标。
3. 将拉伸后的范例矩形与目标矩形逐像素比较。
4. 输出 = 一个与目标矩形等大的网格。两者颜色相同的像素输出为黑(0)；颜色不同的像素输出为该位置在目标矩形中的颜色。
5. 分隔列和其他区域全部丢弃。

**关键洞察**：弹性拉伸不是最终变换（如参考题 40f6cd08 那样用拉伸结果替换实心矩形），而是一个中间步骤——它将两个不同尺寸的对象变为可比较的同尺寸对象。逐像素比较也不是在两个天然等大的面板上进行（如参考题 34b99a2b），而是在人工对齐后的对象上进行。拉伸算法本身（哪个行程是内部行程）需要对比多个示例来确认。
