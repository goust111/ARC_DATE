## 新题 8：模板匹配激活指示像素定向射线

**组合逻辑**：[形状匹配/归一化形状比对/匹配模板则重涂](已有) → [指示像素/邻接触碰](创新：指示像素的激活与否取决于其邻接对象是否通过了形状匹配测试) → [射线延伸](已有，创新：射线仅从被激活的指示像素发出)

**来源原语**：形状匹配(shape_match)、归一化形状比对(normalized_shape_matching)、匹配模板则重涂(recolor_on_match)来自 4ff4c9da；指示像素(indicator_pixel)、邻接触碰(adjacency_touch)来自 e8dc4411；射线延伸(ray_extend)来自 db695cfb/aba27056

**依赖链**：模板匹配筛选出哪些对象是"匹配对象" → 匹配对象被重涂为模板色 → 匹配对象旁的指示像素被"激活"，开始发射射线 → 非匹配对象旁的指示像素保持惰性（被清除）。匹配结果控制了哪些指示像素有效，进而控制了射线图案。如果不做匹配，所有指示像素看起来一样，无法区分激活与惰性。如果不做射线，匹配结果只是重涂（与参考题 4ff4c9da 相同，无创新）。

在含有模板对象和多个候选对象的网格上，匹配模板形状的对象被重涂并激活其邻接指示像素发射射线；不匹配的对象旁的指示像素被清除。

**输入结构**：约 15x15 网格，黑(0)背景。包含 5~7 个单色 4-连通前景对象，分布在网格各处。其中一个为青(8)对象（3~6 像素），作为形状模板。其余对象颜色为蓝(1)或红(2)（两种颜色的对象各至少 2 个）。仅有一种颜色（如蓝(1)）的对象中，部分对象的平移归一化形状与青(8)模板相同，其余形状不同。另一种颜色（如红(2)）的对象形状均不与模板匹配。每个非模板对象恰好有一个品红(6)单像素指示像素与其 4-邻接（指示像素不与其他任何对象邻接）。青(8)模板对象也有一个品红(6)指示像素与其邻接。生成约束：各对象互不接触（除了各自与其指示像素的邻接）；射线路径上无歧义（每条射线在碰到其他对象或网格边界前为直线路径）。

**规则**：
1. 以青(8)对象为模板，提取其平移归一化的像素掩码（4-连通）。
2. 对每个非黑、非青、非品红的对象，将其像素掩码平移归一化后与模板比较。归一化使用 4-连通。
3. 找到唯一的"匹配源色"——即存在与模板形状匹配的对象的那种颜色。将所有该源色中形状匹配的对象重涂为青(8)。
4. 对每个青(8)对象（含原始模板和新重涂的对象），其邻接的品红(6)指示像素被"激活"：从该指示像素出发，沿从对象质心（取所有像素坐标均值并四舍五入到最近整数）指向指示像素的方向（8 方向之一），发射一条青(8)射线，直到碰到网格边界或任何非黑像素为止（不包含终止位置的像素）。
5. 对每个不匹配的对象（无论哪种颜色），其邻接的品红(6)指示像素被"清除"：将该品红像素恢复为黑(0)背景。不匹配的对象本身保持其原有颜色不变。
6. 射线覆盖的黑色像素变为青(8)。射线碰到已有非黑像素则停止。多条射线的绘制顺序按射线起点的行号升序、行号相同则列号升序处理。先绘制的射线像素成为后续射线的障碍。

**关键洞察**：指示像素在视觉上对所有对象看起来完全相同（都是品红单像素），但其功能由邻接对象是否通过形状匹配测试来决定——匹配者的指示像素激活为射线发射器，不匹配者的指示像素被清除。这种"条件激活"是模板匹配和指示像素两个原语之间的新结构关系：匹配结果不仅改变对象颜色（如参考题 4ff4c9da），更控制了指示像素的行为模式（如参考题 e8dc4411 中指示像素总是激活的，而此题中激活是有条件的）。

print("variants", len(sigs))
