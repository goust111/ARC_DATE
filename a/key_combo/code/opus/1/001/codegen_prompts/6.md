## 新题 6：角落对象顺时针复制后标记计数驱动重涂

**组合逻辑**：[复制/顺时针到下一角](已有) → [连通检测/计数](创新：计数对象包含复制带来的新增标记，使计数结果依赖于复制步骤) → [重涂色](创新：重涂颜色由计数结果查表决定，映射关系需从示例推断)

**来源原语**：复制(copy)、顺时针到下一角(clockwise_next)、忽略干扰项(ignore_distractors)来自 bc93ec48；连通检测(connected_component_detection)、计数(counting)来自 2c0b0aff；重涂色(recolor)来自 e8dc4411/e9ac8c9e

**依赖链**：顺时针复制将角落对象（含标记像素）搬运到新角落 → 目标角落现在同时拥有原有对象和复制来的对象 → 标记计数在复制后进行，计数结果因复制而改变 → 计数值查表映射为颜色 → 以该颜色重涂该角落的所有非标记前景像素。三步操作中，每一步的输出都是下一步的必要输入。

将角落对象顺时针复制到下一角，然后统计每个角落区域内的绿色标记连通体数量，依据数量将该角落的蓝色像素重涂为对应颜色。

**输入结构**：约 14x14 网格，橙(7)背景。四个角落各有一个前景对象——以蓝(1)像素为主体（5~10 像素，不规则 4-连通形状），其中嵌有 1~3 个绿(3)单像素标记（绿色像素与蓝色像素 4-邻接或被蓝色包围，但绿色像素之间不互相 4-邻接，即每个绿色像素是一个独立的 1 像素连通体）。每个角落对象的包围框触碰两条相邻网格边界（即对象锚定于角落）。网格中央区域有 1~2 个红(2)干扰对象（不触碰任何角落边界），它们不参与任何操作。生成约束：顺时针复制后，四个角落的绿色标记连通体数量互不相同（通过各角落原有标记数和复制来源标记数的组合保证）。

**规则**：
1. 忽略所有非角落对象（红色干扰物不移动、不修改）。
2. 对每个角落对象，将其像素集合（蓝色 + 绿色）整体复制到顺时针方向的下一个角落：TL→TR、TR→BR、BR→BL、BL→TL。复制时保持对象形状不变，将包围框对齐到目标角落。复制像素覆盖目标位置的已有像素。原始角落的对象保留不变。
3. 复制完成后，对每个角落区域（以网格中心为界划分的四个象限），统计该区域内绿(3)像素的 4-连通独立连通体数量。
4. 根据绿色连通体数量，将该区域内所有蓝(1)像素重涂为指定颜色。映射关系固定但须从示例推断，例如：数量 2 → 黄(4)、数量 3 → 灰(5)、数量 4 → 红(2)、数量 5 → 品红(6)。
5. 绿色标记像素、橙色背景、红色干扰物保持不变。

**关键洞察**：复制步骤不仅改变了角落的视觉内容，更引入了新的绿色标记，使目标角落的标记计数不同于复制前。如果不执行复制就计数，得到的数量（和重涂颜色）会是错误的。计数-颜色映射表是隐蔽规则，需对比多个示例的角落标记数与输出颜色来推断。
