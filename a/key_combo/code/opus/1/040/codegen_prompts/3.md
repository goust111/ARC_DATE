## 新题 3：格子纯度门控·局域路径攀升

**组合逻辑**：[分隔线网格解析](已有) + [纯色即有效](已有，判定活跃/惰性格) → [路径生长+障碍偏转](已有，但被限制在活跃格内部) + [格内判定](创新：格子边界充当路径墙壁)

**来源原语**：分隔线网格+纯色单元格+格内判定+纯色即有效(458e3a53)、控制像素+路径生长+底行起始+逐步攀升+障碍偏转(712bf12e)

**依赖链**：格子解析把网格分割成宏观单元 → 纯度测试把单元分为活跃（纯色背景）和惰性（含杂色图案）两类 → 路径仅在活跃格中生长，格子分隔线充当墙壁 → 障碍偏转在格内局部发生。去掉纯度测试，路径会穿入杂色格导致结果错误；去掉格子边界约束，路径会跨格生长违反局域性。

在分隔线网格中，仅在纯黑的活跃格内部从底部控制像素向上生长路径，遇格内障碍向右偏转，路径不跨越格子边界。

**输入结构**：约 19x19 网格，黄(4)分隔线将网格划分为 4x4 共 16 个矩形单元（分隔线为完整的行和列，宽度 1 像素）。约 6~8 个单元为"活跃格"：内部全为黑(0)背景，其中部分活跃格的底行有 1~2 个红(2)控制像素，部分活跃格内散布少量灰(5)障碍像素（每格 0~3 个）。其余 8~10 个单元为"惰性格"：内部包含蓝(1)和绿(3)像素组成的多色杂乱图案（至少 2 种非背景色）。生成约束：每个含控制像素的活跃格至少有一条可行的向上路径（不被障碍完全封死）；控制像素不出现在惰性格中。

**规则**：
1. 用黄(4)分隔线（完整行和完整列）将网格切分为矩形单元。
2. 对每个单元检查其内部（不含分隔线像素）：若内部仅含黑(0)、红(2)、灰(5)三种颜色中的若干，则为"活跃格"；若内部出现任何其他颜色，则为"惰性格"。
3. 惰性格保持不变。
4. 在每个活跃格中，找到所有红(2)控制像素（位于该格底行）。
5. 从每个控制像素出发，在该格内部向上生长路径：
   a. 尝试移动到正上方一格。若该像素为黑(0)，涂为红(2)并继续。
   b. 若正上方为灰(5)障碍，则改为向右移动一格（同行）。若该像素为黑(0)，涂为红(2)，然后从新位置继续尝试向上。若右侧也不可用（障碍、非背景、或已到格子右边界），该路径停止。
   c. 若正上方超出该格上边界（到达分隔线或网格边缘），该路径停止。
6. 路径绝不跨越分隔线进入相邻格。
7. 同一活跃格内多条路径互不影响：先处理该格内最左侧的控制像素，再依次向右处理。先画的路径像素对后续路径而言视为障碍（不可进入）。

**关键洞察**：格子的纯度测试是宏观层面的门控，路径生长是微观层面的操作——两套逻辑在不同尺度上协作。仅看单个示例可能误以为路径可以跨格生长，需对比多个示例（尤其是活跃格与惰性格相邻的情形）才能确认格子边界的阻断作用。
