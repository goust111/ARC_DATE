## 新题 8：对边标记的互换对隐式定义同心扩展的交替色板

**组合逻辑**：[颜色互换color_swap + 对边配对opposite_edge_pair + 配对间像素互换toggle_between_pairs](创新：互换规则不再应用于线段上的静态像素翻转，而是生成同心扩展所需的无限交替色板) + [同心层填充concentric_fill + 切比雪夫距离索引chebyshev_index](创新：色板不是显式给出的一行像素，而是由互换对隐式定义的交替序列 A, B, A, B, ...)

**来源原语**：颜色互换color_swap、配对间像素互换toggle_between_pairs、对边配对opposite_edge_pair、标记像素marker_pixel、线段line_segment、网格边缘grid_edge → d2acf2cb；同心层填充concentric_fill、切比雪夫距离索引chebyshev_index、种子像素seed_pixel、色板按距离配色palette_color_by_distance、分隔行separator_row → 9356391f

**依赖链**：对边黄色标记定义互换颜色对 → 种子所在行决定使用哪个互换对 → 互换对生成交替色板（A, B, A, B, ...）→ 色板按切比雪夫距离索引驱动同心方环填充。互换规则和同心填充通过"色板"这一中间概念耦合——色板既不是显式给出的，也不是固定的，而是从互换对推导而来。

从网格对边的标记像素推导颜色互换对，以互换对生成交替色板，驱动种子像素的同心方环扩展。

**输入结构**：
- 约 15×15 的黑(0)背景网格。
- 网格左边缘和右边缘各有 1~2 个黄(4)标记像素，构成 1~2 个对边配对（同一行的左边缘标记与右边缘标记配对）。
- 每对黄色标记之间的行上（严格内部，不含标记本身），有两个相邻的非背景非黄色像素，颜色分别为 A 和 B（如红(2)和蓝(1)，或绿(3)和橙(7)），定义该行的互换对 A ↔ B。左侧为 A，右侧为 B。
- 灰(5)分隔行横跨全宽，将上方的互换对定义区与下方的种子扩展区分隔。
- 下方区域有 1~2 个种子像素，每个种子的颜色等于某个互换对的 A 色（即左侧色）。每个种子所在行与某个互换对定义行的行号差最小（以此确定关联——每个种子关联与其行号最近的互换对定义行）。
- 生成约束：每个种子的同心扩展半径（到网格边缘或分隔行的最短切比雪夫距离）至少为 3；不同种子的扩展区域不重叠（若有多个种子）。

**规则**：
1. 识别互换对：对每行，若左边缘和右边缘都有黄(4)标记，则该行严格内部的两个相邻非背景像素定义一个互换对 A ↔ B（左为 A，右为 B）。
2. 种子关联：每个种子关联行号距离最近的互换对。若距离相等则关联行号较小的互换对。
3. 色板生成：令种子的互换对为 A ↔ B，则色板为无限交替序列 palette[d] = A（d 为偶数）或 B（d 为奇数）。
4. 同心填充：以种子像素位置为中心，将切比雪夫距离为 d 的所有像素涂为 palette[d]。填充范围不超出网格边界，不覆盖分隔行（灰(5)）及其上方区域。距离 0（种子自身）涂为 A。
5. 黄(4)标记、互换对定义像素、分隔行（灰(5)）保持不变。

**关键洞察**：色板没有显式呈现在网格中——它由互换规则隐式定义为二元交替序列。求解者必须先识别对边标记和颜色互换对，再推导出交替色板，最后应用于同心扩展。仅看单个示例只能看到一种互换对的扩展效果（交替方环），需对比多个示例确认色板始终由互换对的两种颜色交替产生而非其他排列。
