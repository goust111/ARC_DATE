## 新题 8：外部标记定向裁剪后按图例膨胀围框

**组合逻辑**：[裁剪(crop) + 旋转(rotation)](由外部标记决定朝向) + [膨胀(dilate) + 颜色图例(color_legend)](创新：膨胀围框的颜色不再由固定图例条给出，而是由裁剪后内部颜色的出现次数匹配图例确定) + [外部标记像素(external_marker) × 封闭孔洞(enclosed_hole)](创新：旋转后孔洞的相对位置变化影响膨胀是否保留孔洞)

**来源原语**：裁剪/旋转/外部标记/内部标记/外部标记决定朝向 ← 94133066；膨胀/颜色图例/图例映射/封闭孔洞/孔洞保留不填 ← 5adee1b2

**依赖链**：外部标记确定矩形的旋转方向 → 裁剪并旋转矩形 → 旋转后统计内部非背景、非标记颜色的像素数 → 像素数最多的颜色作为"主色"去匹配图例左列 → 图例右列给出围框颜色 → 对旋转后的裁剪图执行 1 像素膨胀围框，但保留裁剪图中的封闭背景孔洞不填

用外部标记决定矩形裁剪朝向，再用旋转后内部主色查颜色图例获取围框色，膨胀围框时保留孔洞。

**输入结构**：约 16x16 的网格，背景黑(0)。网格中有一个约 5x6 的单色（如蓝(1)）实心矩形，内部嵌有 1~2 个单像素的颜色标记（如红(2)、绿(3)），以及 1 个由背景色(0)形成的 1~2 像素封闭孔洞。矩形外部有与内部标记同色的外部标记像素（每种标记色恰好内外各一个）。网格左边缘有 2~3 个 2x2 颜色图例块：每块左列为一种前景色（如蓝(1)、红(2)等），右列为对应的围框色（如黄(4)、栗(9)等）。生成约束：矩形内部蓝色像素数远多于标记色像素数，使蓝色为主色；外部标记的相对排列经旋转后与内部标记匹配，且旋转角度为 90/180/270 度之一。

**规则**：
1. 识别矩形及其内外标记像素。将外部标记像素的相对坐标（以外部标记群的左上角为原点）与内部标记像素的相对坐标（以内部标记群的左上角为原点）对比，找到唯一的旋转/翻转使两者匹配。
2. 裁剪矩形的最小边界框，对裁剪结果应用步骤 1 确定的旋转/翻转。
3. 在旋转后的裁剪图中，统计非背景(0)、非标记色的像素数量最多的颜色，记为主色 C。
4. 在左边缘图例中查找左列颜色 = C 的图例块，取其右列颜色作为围框色 H。
5. 将旋转后的裁剪图向四周各扩展 1 像素，扩展区域全部填为围框色 H。
6. 裁剪图内部的封闭背景孔洞（4-连通的黑(0)区域且不接触裁剪图边界）保持为黑(0)，不被围框色填充。
7. 输出为带围框的旋转裁剪图（尺寸 = 裁剪图 + 2 行 2 列）。

**关键洞察**：外部标记同时解锁旋转方向和内部结构的重排；旋转后主色可能因裁剪范围微调而变化（不同旋转下边界框可能不同），所以围框颜色依赖于旋转结果。孔洞保留规则进一步约束膨胀操作——不是简单扩边，而是要识别并避开内部封闭区域。
