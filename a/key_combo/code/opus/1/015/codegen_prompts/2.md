## 新题 2：格子槽频次控制矩形跳跃倍数

**组合逻辑**：[计数(counting)](创新：对格子槽中颜色出现次数计数) + [平移(translate)](创新：位移量为自身高度 × 频次) + [格子框架(lattice_frame) × 实心矩形(solid_rectangle)](创新：格子不再用于跨框架推断填充色，而是作为频次编码表)

**来源原语**：计数 ← fcc82909；平移/移动自身高度 ← 5521c0d9；格子框架/格子槽位/位置对应颜色 ← 2e65ae53；实心矩形 ← 5521c0d9

**依赖链**：格子槽位中各颜色的出现次数决定倍率 → 矩形的颜色匹配格子中的颜色获得倍率 → 矩形位移 = 自身高度 × 该倍率 → 移除原位矩形后在新位置绘制

统计左侧格子中各颜色出现的槽位数，将右侧同色矩形上移"自身高度 x 槽位数"的距离。

**输入结构**：约 18x18 的网格，背景黑(0)。左侧约占 1/3 宽度，包含一个灰(5)线条构成的矩形格子框架，内部被分为 3x3 或 4x3 等均匀槽位，部分槽位内部填有纯色（如红(2)、蓝(1)、绿(3)等），其余槽位为黑(0)背景。右侧约占 2/3 宽度，散布 2~4 个单色实心矩形（无重叠），每个矩形颜色与格子中某种填充色相同，矩形高度各异（1~4 像素），上方有足够空间容纳跳跃。生成约束：每种矩形颜色至少在格子中出现 1 个槽位；矩形跳跃后不超出网格上边界且不彼此重叠。

**规则**：
1. 在左侧格子中，统计每种非背景、非框架颜色占据了多少个槽位，记为该颜色的频次 F。
2. 对右侧每个实心矩形，找到其颜色在格子中的频次 F。
3. 将该矩形从原位清除（填黑(0)），然后在原位正上方偏移 (F x 矩形高度) 个像素处重新绘制。即矩形新的顶边行号 = 原顶边行号 - F x 高度。
4. 格子区域在输出中保持不变。
5. 若多个矩形颜色相同，它们共享同一频次 F，各自独立计算位移。处理顺序不影响结果（生成时保证跳跃后矩形互不重叠且不超出边界）。

**关键洞察**：格子不是用来推断缺失颜色的查阅表——它是频次编码器：同一颜色占据越多槽位，对应矩形跳得越远。位移量是频次与自身高度的乘积，需要同时获取两条信息才能确定输出。
