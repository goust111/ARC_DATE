## 新题 4：重叠矩形框遮挡序解码

**组合逻辑**：[transparent_overlay](已有，创新为 N 层遮挡叠加而非两面板合并) + [sorting](已有，创新为从局部遮挡线索推断偏序后拓扑排序)（创新核心：叠加可见性编码了隐式偏序关系，求解者需从边框交叉处的局部颜色推断全局堆叠排序——这是结构解构型推理，非流水线）

**来源原语**：transparent_overlay, cell_alignment (dae9d2b5); sorting, height_order (b7999b51); hollow_rect (f21745ec); counting (b7999b51)

**依赖链**：多个不同颜色的空心矩形框叠放于同一网格 -> 边框交叉处仅显示上层颜色 -> 从可见交叉格推断两两遮挡偏序 -> 部分框对之间无直接交叉，需经第三框传递推断 -> 拓扑排序得到全局从顶到底的颜色序列 -> 输出为一列颜色。

从多个重叠空心矩形框的边框交叉处可见颜色中推断完整堆叠顺序，输出从顶层到底层的颜色列。

**输入结构**：
- 网格约 15x15，背景黑(0)
- 4 个一格宽的空心矩形框（仅边框像素，内部为黑(0)），每个框使用不同颜色：蓝(1)、红(2)、绿(3)、黄(4)。边框外高各 5~9 格、外宽各 5~9 格，大小不完全相同
- 矩形框的位置使得：每两个相邻层级的框至少有一段边框交叉（存在某格同属两个框的边框路径）
- 交叉格仅显示堆叠层级更高的框的颜色（上层遮挡下层）
- 每个框的四个角像素中至少有两个可见（未被更高层框遮挡），确保可从可见像素重建每个框的完整矩形范围
- 生成约束：遮挡偏序可唯一确定一个全序（4! 排列中仅一种与所有可见交叉一致）；至少有一对框之间无直接边框交叉，其先后关系须通过与第三框的传递推断获得

**规则**：
1. 识别所有空心矩形框：每种前景颜色的可见像素构成某个矩形的边框子集。利用可见角点（至少两个可见角）推断每个框的完整矩形范围（左上角和右下角坐标）
2. 还原每个框的完整边框路径（矩形四边所有格的集合）。在两个框的边框路径交叉位置（同一格属于两框的边框），可见颜色属于堆叠层级更高的框。由此建立有向关系：可见色 -> 被遮挡色（可见色在上层）
3. 若两个框无直接交叉，其相对层级通过传递性推断（A 在 B 上，B 在 C 上 -> A 在 C 上）
4. 对所有有向关系做拓扑排序，得到唯一的从顶层到底层的颜色全序
5. 输出为 4x1 的列网格，从第 0 行到第 3 行依次填入从顶层到底层的框颜色

**关键洞察**：某些框之间无直接边框交叉，其先后关系必须通过与第三个框的传递推断获得——仅从直接遮挡对无法确定全序。需要对比多个示例来确认传递推断规则而非仅读取直接遮挡结果。
