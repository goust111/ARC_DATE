## 新题 5：图例双编码驱动同心展开

**组合逻辑**：[rank_correspond + legend_pos_color](已有) + [expand + center_expand](已有) + [counting](已有，创新为"图例像素数编码展开半径")（创新核心：图例同时承载两种信息维度——颜色排列位置编码映射对象，像素数量编码展开规模——单一元素的双重语义是源题中不存在的结构关系）

**来源原语**：rank_correspond, legend_pos_color, color_legend (fafd9572); expand, center_expand, parity_determines_color (db3e9e38); counting, pixel_count (f8ff0b80, 1fad071e)

**依赖链**：识别图例区域中各颜色的像素数 -> 像素数编码该颜色对应标记点的展开半径 -> 图例颜色的排列位置与标记点的空间排位一一对应确定颜色映射 -> 每个标记点以中心向外展开 n 层同心方环，奇偶层交替使用映射颜色与黑色。

图例中每种颜色的像素数量决定对应标记点的同心方环展开半径，图例的位置顺序决定颜色映射。

**输入结构**：
- 网格约 20x20，背景黑(0)
- 左上角区域（行 0，列 0~5 以内）有一个紧凑的水平图例：3 种颜色的像素紧密排成一行（水平相邻），如蓝(1)占 1 格、红(2)占 2 格、绿(3)占 3 格，从左到右排列。图例总宽 = 三种颜色像素数之和（此例为 6），高 1 格
- 网格中分布 3 个灰(5)单像素标记点，位置互不相邻且距网格边界至少 5 格，标记点两两曼哈顿距离 >= 10（保证展开后不重叠）
- 标记点按行优先（行号从小到大）、列次优先（列号从小到大）排列，与图例中颜色从左到右的顺序一一对应
- 生成约束：展开半径最大为 3 层（图例中单色最多 3 像素），展开后的同心方环不超出网格边界且不互相重叠

**规则**：
1. 识别图例：位于网格第 0 行最左端的连续非黑(0)非灰(5)像素段。图例中的颜色按从左到右出现的顺序排列，每种颜色连续占若干格
2. 统计图例中每种颜色的连续像素数量 n_c，该数值为展开半径
3. 将图例颜色按从左到右顺序排列，与灰(5)标记点按行优先、列次优先排序后一一对应：图例第 1 种颜色 -> 排序第 1 的标记点，依此类推
4. 对每个标记点：以该点为中心，绘制 n_c 层同心方形环。方形环的第 k 层（k >= 0）为所有切比雪夫距离恰好等于 k 的格集合。k=0（中心像素）用映射颜色填充。k >= 1 时：k 为奇数填黑(0)，k 为偶数填映射颜色
5. 灰(5)标记点被中心层的映射颜色覆盖
6. 图例区域保留不变
7. 超出网格边界的部分舍弃不绘制

**关键洞察**：图例的每种颜色同时编码两个独立维度——空间排列位置编码映射目标（对应哪个标记点），像素数量编码展开规模（几层环）。单个示例无法区分"像素数编码半径"与"颜色编号编码半径"等替代假说，需多个示例对比排除。
