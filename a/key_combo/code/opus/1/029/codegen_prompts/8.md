从目录匹配局部精灵对应的完整模板并印章到工作区，重叠区域由模板面积决定覆盖优先级：面积小的绘制在上层。

**输入结构**：

- 右侧 14 列：黑(0)工作区。包含 3 个局部精灵，每个是某个目录模板的连续子区域（至少包含模板前景像素的 40%，且包含该模板中唯一可识别的颜色组合或空间特征）
- 局部精灵的放置位置使得：将它们各自补全为完整模板后，至少有两个模板的边界框互相重叠（重叠面积至少 2x2 格）
- 生成约束：每个局部精灵唯一对应一个目录模板（无歧义匹配）；模板内不使用灰(5)色

**规则**：
1. 识别目录模板：灰(5)区域内，将所有非灰(5)非黑(0)的连通前景像素聚类为独立模板。记录每个模板的完整像素图案（相对坐标+颜色）及前景像素面积
2. 对工作区每个局部精灵（非黑(0)的连通前景组），在所有模板中搜索唯一包含该精灵像素图案（相同颜色、相同相对坐标关系）作为子区域的模板
3. 将匹配模板对齐——使已知子区域（局部精灵）与模板中的对应部分重合——确定模板在工作区的完整放置位置
4. 按模板前景像素面积从大到小的顺序依次绘制（面积最大的模板先画，面积最小的后画）。后画的覆盖先画的。模板边界框内黑(0)像素和灰(5)像素视为透明（不绘制，保留下层内容或黑色背景）

6. 工作区中不属于任何模板覆盖范围的格保持黑(0)

**关键洞察**：模板匹配仅确定"哪个模板放在哪里"，重叠区域的最终像素还取决于模板面积排序——面积小的模板优先显示（后绘制覆盖先绘制），此覆盖规则无法从匹配逻辑中推出，需从示例中重叠区域的实际颜色归纳得出。
