## 新题 6：种子条纹在标记线处分裂与颜色互换镜像

**组合逻辑**：[平铺/tiling + 种子定条纹周期/seed_sets_stripe_period] → [镜像/reflect + 跨标记线反射/reflect_across_markers](创新：标记线同时充当条纹裁剪边界、反射轴和颜色互换触发器) → [重涂色/recolor]

**来源原语**：tiling、seed_pixel、stripe、array_layout、seed_sets_stripe_period（来自 0a938d79）；reflect、sparse_marker_line、foreground_motif、parallel_axes、reflect_across_markers（来自 66ac4c3b）；recolor、parity_position_recolor（来自 d406998b）

**依赖链**：种子像素确定条纹周期和方向→条纹在整个网格生成→标记列将网格一分为二→种子侧保留原始条纹→另一侧为条纹的镜像加颜色互换。标记列的三重角色（裁剪边界、反射轴、颜色互换触发）在任何源题中都不存在。

两个种子像素生成周期条纹图案，稀疏标记列将网格一分为二：种子侧保留原色条纹，另一侧为条纹的镜像并交换两种种子色。

**输入结构**：
- 网格约 15x20（15 行 20 列），背景黑(0)。
- 网格左边缘（第 0 列）上有两个种子像素：一个红(2)、一个蓝(1)，位于不同行（如第 3 行和第 7 行）。两个种子之间行间距 d >= 2。
- 网格中部偏右有一条稀疏灰(5)标记列（某固定列 c，其中 c 约在第 10-14 列之间）：该列中每隔一行有一个灰(5)像素（如行号为偶数的位置为灰(5)，行号为奇数的位置为黑(0)），形成稀疏分布。
- 除种子像素和灰标记像素外，其余全为黑(0)。

**规则**：
1. 两个种子像素确定水平条纹图案：过红(2)种子所在行画一条全宽红(2)行，过蓝(1)种子所在行画一条全宽蓝(1)行。
2. 条纹周期 = 2 x |红种子行 - 蓝种子行|。以红蓝两行为起始，沿垂直方向以此周期重复：每个周期内，与红种子同相位的行为红(2)，与蓝种子同相位的行为蓝(1)，其余行保持黑(0)。
3. 以灰(5)标记列为分界：标记列左侧（含标记列所在列）保留步骤 1-2 生成的原始条纹。
4. 标记列右侧：将左侧条纹图案以标记列为轴左右镜像，同时将红(2)和蓝(1)互换——即原红(2)条纹行在右侧变为蓝(1)，原蓝(1)条纹行在右侧变为红(2)。
5. 灰(5)标记列上的灰(5)像素保持不变，该列中原为黑(0)的位置保持黑(0)（不受条纹影响）。
6. 条纹仅画在非灰标记位置上——若某位置原为灰(5)标记像素，该位置保持灰(5)不被条纹覆盖。

**关键洞察**：灰标记列不是简单的分隔线——它同时扮演三个角色：(1) 条纹的空间裁剪边界，(2) 镜像操作的对称轴，(3) 颜色互换的触发分界。种子间距决定条纹周期，标记列位置决定对称结构。必须看多个示例（种子位置和标记列位置不同）才能归纳出"右侧 = 镜像 + 换色"的完整规则。

1. `main(grid)` 必须实现新题描述中的确定性转换规则，不能只识别 `generate_input()` 的固定模板。禁止不同的input网格输出相同的output网格。

3. 生成器必须保证输入满足 `main()` 的隐式假设：对象不重叠、不越界、特殊标记唯一或可区分、匹配关系无歧义、关键分支出现概率相同。
