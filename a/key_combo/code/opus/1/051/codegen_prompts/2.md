## 新题 2：逻辑或非生成密度种子的区域筛选

**组合逻辑**：[逻辑运算/logical_op](NOR) → [计数/counting] → [筛选/filtering] + [洪泛填充/flood_fill]（创新：NOR 输出作为密度度量的输入，而非最终结果）

**来源原语**：logical_op、binary_mask、pixelwise_correspond、logical_NOR_combine（来自 1b2d62fb）；counting、flood_fill、filtering、partitioned_region、separator_line、densest_region_kept_filled（来自 29623171）

**依赖链**：NOR 运算的结果不是最终输出，而是中间掩模；对该掩模做逐区域计数才能决定哪些区域存活；存活区域的填充颜色由其内部两个掩模中像素较少的那个颜色决定。三步之间信息层层变换：逻辑运算→统计度量→空间筛选。

在分隔线划分的区域内，对每个区域的两色掩模做 NOR，以 NOR 空穴数最多的区域为胜者，用其少数色填充。

**输入结构**：
- 网格约 15x15，背景黑(0)。
- 黄(4)全宽行和全高列各 1 条，将网格分为 4 个矩形区域（2x2 布局）。黄(4)行列在交叉处重合。
- 每个区域内散布着恰好两种前景色的像素（从红(2)、蓝(1)、绿(3)、橙(7)中取两种，四个区域可使用不同的颜色对）。每种颜色在区域内有 3-8 个散布像素，形成一个二值掩模。同一区域内两种颜色的像素不重叠。
- 生成约束：四个区域的 NOR 空穴数（区域内两色掩模均为 0 的非背景内格数量）互不相同，保证唯一最大值。

**规则**：
1. 识别黄(4)分隔行/列，提取 4 个矩形区域（不含分隔线本身的像素）。
2. 对每个区域：取其两种前景色分别形成二值掩模 M_a 和 M_b（前景色位置为 1，其余为 0）。
3. 逐像素计算 NOR(M_a, M_b)：当且仅当该位置 M_a=0 且 M_b=0 时结果为 1。统计每个区域的 NOR=1 像素总数 N_nor。
4. 保留 N_nor 最大的区域（唯一）；其余三个区域所有像素清为黑(0)。
5. 对存活区域：统计其两种前景色的像素数，将整个区域（包括原黑(0)背景位置）填充为像素数较少的那种颜色。原两种前景像素均被覆盖。
6. 黄(4)分隔行/列保持不变。

**关键洞察**：NOR 空穴多意味着该区域"两色覆盖最稀疏"——但稀疏不等于颜色少，而是两色在空间上留下的联合空白最大。选出该区域后，填充色取决于区域内的少数色，又引入一次统计判断。必须对比多个示例才能确认存活条件是 NOR 最大而非简单的"前景像素最少"。

## 实现要求

1. `main(grid)` 必须实现新题描述中的确定性转换规则，不能只识别 `generate_input()` 的固定模板。禁止不同的input网格输出相同的output网格。
2. `generate_input()` 必须随机生成多样样例，不能固定死。随机维度应覆盖：网格大小、对象数量、位置、颜色、方向、形状参数或关键分支。注意若描述中存在若干，需实现而不是只有单个，包括object或者对应关系等等。
3. 生成器必须保证输入满足 `main()` 的隐式假设：对象不重叠、不越界、特殊标记唯一或可区分、匹配关系无歧义、关键分支出现概率相同。
4. 禁止把 ARC 颜色 id 、亮度、拼写等当作人类不可见的数值语义参与排序、大小比较或隐藏映射。颜色变化必须有可见结构线索。注意颜色亮度、拼写等也是不可见信息，若描述中出现违规的颜色id或者亮度，可自行使用少量的固定颜色替代，但注意生成时要在三个以内输入输出网格中对所有变换100%覆盖度。
5. 输出样例要视觉清晰，人类必须能从输入输出对中肉眼辨认出规律。具体要求：避免对象粘连、覆盖关系混乱、同一像素多重语义；不同逻辑步骤产生的结果不要大面积层叠在一起导致无法分辨哪个颜色属于哪个步骤；输入中各元素之间保持足够间距，输出中新增的标记/填充/路径等应与背景和已有元素在颜色上有明显区分；若规则涉及多层叠加，生成时控制对象密度和尺寸，确保叠加区域只占少数像素而非铺满整个网格。
6. 若规则有多个分支，生成器不能长期固定成一个分支；应让分支在随机样例中合理出现。分支概率不必平均——难以发现的隐蔽分支（如少数情况下才触发的特殊规则）应适当提高出现概率，确保在 3 个训练示例中至少出现一次，否则求解者无法归纳该规则。对于颜色映射类规则，确保 2 个左右的示例即可覆盖所有映射关系（每种颜色→颜色的映射至少在某个示例中出现过）。
7. 代码风格参考 `ARC_code`：使用 `numpy`，必要时使用本地 helper，但目标文件应能被 `SourceFileLoader` 直接加载。
8. 可以在目标目录放公共 helper 文件，但若只实现一道题，优先保持目标文件自包含，减少额外依赖。
