## 新题 8：形状分类决定投射行为与弹丸碰撞

**组合逻辑**：[朝向编码方向/orientation_encodes_direction](区分线段与三角精灵体) → [正交投射到边缘/orthogonal_projection_to_edge + 按距离排序绘制/draw_ordered_by_distance](创新：仅线段做投射) → [射线延伸/projectile_fire](创新：仅三角体发射弹丸) → [碰撞变色规则/collision_recolor_rule](创新：弹丸与投射条纹的碰撞，而非弹丸之间的碰撞)

**来源原语**：边缘实心条、平行线段、正交投射到边缘、按距离排序绘制、遮挡覆盖(13713586)；三角精灵体、朝向编码方向、射线延伸/projectile_fire、碰撞变色规则(409aa875)

**依赖链**：首先区分输入中的对象类型（线段 vs 三角体）→ 线段做正交投射产生彩色条纹 → 三角体按朝向发射弹丸 → 弹丸落点若在条纹上则将该条纹整体重涂色。形状分类是分叉点，两条行为路径最终在空间碰撞处汇合。

线段向边缘实心条投射彩色条纹（按距离排序覆盖），三角精灵体发射弹丸，弹丸命中的条纹整体被重涂为栗(9)。

**输入结构**：约 18x18 的灰(5)背景网格。一条边（如左边缘）为蓝(1)实心边缘条（整列蓝色）。网格内有 3~5 个不同颜色的一像素宽线段，每段 2~4 像素长，与边缘条平行（即垂直方向），颜色各不相同（从红(2)、绿(3)、黄(4)、橙(7)中选取）。网格内还有 1~2 个三角精灵体，每个由 3 个品红(6)像素组成 L 形（占 2x2 边界框的三格），其缺失角方向指向边缘条所在的一侧。线段和三角体之间互不相邻，三角体位于线段和边缘条之间（即比所有线段更靠近边缘条）。

**规则**：
1. 识别蓝(1)实心边缘条及其所在边（如左边缘）。所有非背景、非边缘条的前景对象均平行于边缘条。
2. 区分前景对象：占据单行连续像素的为"线段"，占据 2x2 区域中三个像素的 L 形为"三角体"。
3. 线段投射：每个线段向边缘条方向投射同色矩形条纹，从线段位置延伸到边缘条前一列（不含边缘条）。线段距边缘条越远（列距离越大），其条纹越先绘制；距边缘条越近的线段条纹后绘制，覆盖先前的条纹（在重叠区域）。
4. 三角体发射：每个三角体沿其缺失角方向（指向边缘条）发射一颗弹丸，弹丸从三角体顶点出发，沿水平方向前进恰好 5 格（若超出网格则在网格边缘停止）。弹丸落点标记为黑(0)。
5. 碰撞检测：若弹丸落点位于某条线段投射的条纹区域内，则该条纹整体重涂为栗(9)（含该条纹所有像素，不论是否被后续条纹覆盖——即恢复该条纹的完整范围并涂栗(9)，覆盖之上的一切）。
6. 三角体自身像素保持品红(6)不变。边缘条保持蓝(1)不变。

**关键洞察**：线段和三角体在输入中视觉相似（都是小型前景对象），但它们的行为完全不同——线段产生被动的投射条纹，三角体产生主动的弹丸；两者的交互决定了最终哪些条纹被摧毁。
