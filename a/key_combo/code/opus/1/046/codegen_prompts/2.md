## 新题 2：边缘矩形滑动留下面积分级的周期轨迹

**组合逻辑**：[接触边缘/touching_edge] → [滑动/slide + 滑至对侧/slide_to_opposite] → [面积分类/area_classification](创新：面积决定轨迹颜色和周期填充密度，而非决定对象自身颜色) → [循环填充/periodic_fill + 周期相位对齐/periodic_phase_align](创新：填充对象为轨迹条纹而非V形扩展) → [按距离排序绘制/draw_ordered_by_distance](创新：原用于投射到边缘的距离排序，此处用于轨迹重叠时的优先级)

**来源原语**：边缘矩形、接触边缘、滑至对侧边缘、轨迹条纹(b25e450b)；面积分类、面积决定颜色(d2abd087)；循环填充、周期相位对齐、对角线格点(c1990cce)；按距离排序绘制(13713586)

**依赖链**：边缘接触确定滑动方向 → 滑动产生矩形轨迹区域 → 矩形面积同时决定两件事：轨迹基底颜色（面积分类）和对角格点周期（面积映射到周期参数）→ 轨迹重叠时，距离出发边更远的矩形（即滑动距离更长的）优先绘制其轨迹。面积既决定外观又决定优先级之外的周期结构，是多路耦合。

将接触网格边缘的黑色矩形同时滑向对侧边缘，每个矩形留下的轨迹条纹的颜色和内部对角格点密度由矩形面积决定，重叠区域按滑动距离排序覆盖。

**输入结构**：约 16x16 的灰(5)背景网格。3~5 个黑(0)实心矩形，每个恰好接触网格的一条外边缘（上、下、左或右），不同矩形可接触不同边缘。矩形面积各不相同，范围在 2~12 像素之间（宽或高至少为 1，另一维至少为 2）。矩形之间不相邻，保证同方向滑动路径上不存在另一个矩形阻挡。

**规则**：
1. 确定每个黑(0)矩形接触的外边缘，该矩形向对侧边缘方向滑动（接触上边缘→向下，接触左边缘→向右，以此类推）。
2. 计算每个矩形的面积（像素数）。面积 <= 4 的矩形归为"小型"，面积 > 4 的归为"大型"。
3. 所有矩形同时滑动。滑动后，在矩形原位置到新位置之间的整个条纹区域绘制轨迹：小型矩形的轨迹基底色为橙(7)，大型矩形的轨迹基底色为青(8)。
4. 在每条轨迹内部叠加对角格点图案：沿 NW-SE 方向，每隔 K 格绘制一个前景点（颜色为蓝(1)）。K 值由面积决定：小型 K=2（每隔 2 格），大型 K=3（每隔 3 格）。格点相位以轨迹条纹左上角为原点，满足 (row + col) mod K == 0 的格子绘制蓝(1)点。
5. 矩形在对侧边缘的最终位置保持黑(0)。
6. 若两条轨迹区域重叠，以矩形距其出发边更远者（即从出发边到矩形中心的距离更大，等价于滑动路程更长的）的轨迹覆盖在上层。距离相同时，面积更大的覆盖。

**关键洞察**：矩形面积不仅决定轨迹颜色（二分类），还决定内部周期格点的间距，产生视觉上截然不同的条纹纹理；需要对比多个示例才能将面积阈值和周期参数同时归纳出来。
