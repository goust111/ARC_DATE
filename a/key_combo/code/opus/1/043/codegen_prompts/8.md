## 新题 8：角标记发射切比雪夫方块

**组合逻辑**：[空心矩形/rectangular_frame + 角标记/corner_marker](结构识别) → [切比雪夫距离/chebyshev_dist](标记到最近框边的距离作为方块半径) → [填充/fill](以标记为中心画实心方块) + [擦除/erase](移除矩形框)

**来源原语**：空心矩形(rectangular_frame) ← 952a094c；角标记(corner_marker) ← 952a094c；内外对角(interior_exterior_diagonal) ← 952a094c；切比雪夫距离(chebyshev_dist) ← ff72ca3e；填充(fill) ← ff72ca3e；正方形区域(square_region) ← ff72ca3e；擦除(erase) ← 952a094c

**依赖链**：矩形框的几何属性（各边位置）决定了每个角标记到最近边的切比雪夫距离——不识别框就无法计算距离；距离值成为以该标记为中心的实心方块的半径——没有距离就不知道方块大小；最终框被擦除，留下的方块布局间接反映了框的存在——框的结构信息被编码到方块的大小差异中。

矩形框内四角有标记像素，每个标记以其到最近框边的切比雪夫距离为半径向外发射实心彩色方块，然后矩形框自身被擦除。

**输入结构**：约 18x18 的黑(0)背景网格。一个品红(6)单像素厚的空心矩形框（非正方形，如 10x14），框不居中（距各网格边距不等）。框的内部四角各有一个彩色标记像素（4 个标记分别使用红(2)、蓝(1)、绿(3)、黄(4)四种颜色），每个标记恰好位于框内部区域的对应角落（即紧邻框的两条相交边各 1 格）。生成约束：矩形框非正方形，使得四个标记到最近框边的切比雪夫距离不全相同（至少有两个不同的距离值）；方块扩展后不超出网格边界。

**规则**：
1. 识别品红(6)空心矩形框及其内部四角的 4 个彩色标记像素。
2. 对每个标记，计算其到矩形框最近边（上边、下边、左边、右边）的切比雪夫距离 d。由于标记在角落，d = min(到两条相邻框边的距离) = 1（标记紧邻框边）... 不，让我重新设计位置。标记不一定紧邻框边——它们位于框内部区域的四个角落像素位置：左上角标记在 (top+1, left+1)，右上角在 (top+1, right-1)，左下角在 (bottom-1, left+1)，右下角在 (bottom-1, right-1)。这里 top/bottom/left/right 是框的行列坐标。每个标记到最近框边的切比雪夫距离均为 1。这不够有趣。

   重新设计：标记不在角落，而是在框内部的任意位置，但恰好 4 个。

**输入结构**（修正）：约 18x18 的黑(0)背景网格。一个品红(6)单像素厚的空心矩形框（如 12x14）。框内部散布 4 个彩色标记像素（分别为红(2)、蓝(1)、绿(3)、黄(4)），位置各异，不在同一行或同一列。生成约束：矩形框非正方形；每个标记到矩形框四条边的最小切比雪夫距离互不全相同（至少产生 2 种不同的距离值）；以各标记为中心、以其距离值为半径画出的实心方块不超出网格边界。

**规则**：
1. 识别品红(6)空心矩形框。
2. 找到框内部的 4 个彩色标记像素。
3. 对每个标记像素 M，计算 d(M) = M 到矩形框四条边中最近那条边的曼哈顿距离（即 min(M.row - top, bottom - M.row, M.col - left, right - M.col)，其中 top/bottom/left/right 为框的内边界坐标）。
4. 以每个标记 M 为中心，画一个边长为 (2*d(M) - 1) 的实心正方形，颜色为 M 的颜色。正方形只覆盖背景像素和品红框像素，不覆盖其他标记像素。若多个正方形重叠，按标记的 d 值从大到小绘制（大方块先画，小方块后画覆盖其上）。
5. 擦除所有剩余可见的品红(6)框像素（置为黑(0)）。

**关键洞察**：参考题 952a094c 中角标记被平移到框外对称位置，参考题 ff72ca3e 中方块半径由灰色阻挡像素的切比雪夫距离决定。这里矩形框既不是被保留的结构也不是阻挡物，而是一个隐式的距离标尺——它的边界决定了每个标记的方块大小，然后自身消失。求解者需要对比多个示例才能发现方块大小与标记到框边距离的对应关系。

p = Path("/home/lixinyu/snap/a/key_combo/code/opus/1/043/8.py")
mod = SourceFileLoader("new_arc_task", str(p)).load_module()
sigs = set()
for i in range(100):
    inp = mod.generate_input()
    out = mod.main(inp)
    assert isinstance(inp, np.ndarray)
    assert isinstance(out, np.ndarray)
    assert inp.ndim == 2 and max(inp.shape) <= 30, f"input grid exceeds 30x30: {inp.shape}"
    assert out.ndim == 2 and max(out.shape) <= 30, f"output grid exceeds 30x30: {out.shape}"
    sigs.add(hashlib.md5(inp.tobytes() + str(inp.shape).encode()).hexdigest())
print("variants", len(sigs))
assert len(sigs) >= 20
