## 新题 2：嵌套框缺口连通与种子洪泛重涂

**组合逻辑**：[严格包含](已有) + [框架缺口](创新：缺口不再发射射线，而是充当洪泛的通道) → [洪泛填充](创新：填充穿越多层框架缺口传播) → [重涂色](创新：涂色由拓扑可达性决定而非包含层级)

**来源原语**：严格包含、最外层颜色继承 ← 7d1f7ee8；框架缺口 ← e12f9a14；洪泛填充、路径连通 ← b782dc8a；保留边框涂内部 ← 50cb2852

**依赖链**：识别嵌套矩形框层级 → 定位每个框的单像素缺口 → 从外部种子发起4-连通洪泛 → 洪泛仅能通过缺口穿透框边界 → 缺口朝向与嵌套层级共同决定哪些内部区域可达 → 可达区域重涂为种子颜色

内部区域的颜色不是由包含它的最外层框决定（与参考题 7d1f7ee8 不同），而是由哪个外部种子能通过缺口链路到达它来决定。外框有缺口不意味着内框可达——内框本身也必须有朝向正确方向的缺口。

**输入结构**：
- 网格约 18x18，背景为黑(0)。
- 2-4 个矩形边框，每个边框为单像素宽的单色边界，颜色各不相同（如绿(3)、品红(6)、橙(7)、青(8)），部分框严格嵌套在其他框内部。
- 每个矩形边框恰好有一个1像素缺口：边框的某个边界位置为黑(0)背景色而非框色。
- 2-3 个种子像素位于所有框的外部，颜色各不相同（如红(2)、蓝(1)、黄(4)），各占单像素。
- 每个框至少 6x6（保证有非空内部区域）。
- 生成约束：每个最内层可达区域仅能被一个种子的洪泛到达（不存在两个种子同时可达同一最内层区域的情况）。不同种子可到达不同的框内部区域。至少存在一个框的内部区域不被任何种子到达。

**规则**：
1. 识别所有矩形边框及其严格包含层级关系。
2. 定位每个边框的唯一缺口像素（边框上颜色为黑(0)的位置）。
3. 从每个种子像素发起4-连通洪泛填充，仅通过黑(0)格扩展。洪泛不能穿越边框像素（非黑的边框格），只能通过缺口（边框上的黑色位置）进入框内部。
4. 对于被某个种子洪泛到达的框内部区域，将该区域内所有黑(0)像素重涂为该种子的颜色。
5. 未被任何种子到达的框内部区域保持黑(0)不变。
6. 所有边框像素保持原色不变。种子像素保持原色。

**关键洞察**：外层框的缺口开启了通往内层的可能性，但内层框自身的缺口位置决定了洪泛是否真正能渗透——缺口必须面向洪泛已到达的区域。缺口朝向与嵌套结构共同构成了一个隐式的可达性拓扑。
