## 新题 5：重叠框遮挡推断绘制顺序与深度涂色

**组合逻辑**：[严格包含](创新：不是真正的包含关系而是重叠遮挡关系，需逆向推断) + [计数](创新：计数的不是前景像素而是遮挡事件) → [重涂色](创新：涂色依据不是框自身颜色而是推断出的深度排名)

**来源原语**：矩形边框、严格包含 ← 7d1f7ee8；重涂色、最外层颜色继承 ← 7d1f7ee8；保留边框涂内部、矩形内部 ← 50cb2852；前景矩形 ← 50cb2852

**依赖链**：识别多个互相重叠的矩形边框 → 从可见边框像素重建每个框的完整边界框 → 分析重叠区域的遮挡关系（上层框的像素覆盖下层框的像素） → 推断从底到顶的绘制顺序(z-order) → 按z-order排名为每个框的内部涂上对应颜色

本题的推理核心是逆向工程：观察到的遮挡模式编码了绘制顺序，而绘制顺序又决定了输出的内部填色。没有空间包含层级，只有平面上的遮挡关系。

**输入结构**：
- 网格约 18x18，背景为黑(0)。
- 3-5 个矩形边框（单像素宽边界），颜色互不相同（从绿(3)、黄(4)、品红(6)、橙(7)、青(8)中选取）。
- 框与框之间存在部分重叠（边框交叉）。在重叠区域，后绘制（更高层）的框的边框像素覆盖了先绘制（更低层）的框的边框像素。
- 每个框至少 5x5，有非空的内部区域。
- 没有框完全嵌套在另一个框的内部——所有框都是在同一平面上部分重叠。
- 生成约束：从可见像素可以唯一确定每个框的完整边界框（每个框至少有两个对角位置或足够的边段可见）。遮挡关系可以唯一确定一个全序的z-order（即任意两个有重叠的框之间都能判定谁在上）。

**规则**：
1. 从可见的边框像素出发，重建每个矩形边框的完整边界框（包括被遮挡而不可见的部分）。每个颜色对应一个框。
2. 对于每一对有重叠区域的框A和B：如果在重叠区域中，A色像素被B色像素遮盖（即应出现A色的位置显示了B色），则B在A之上。
3. 建立从底到顶的z-order全序。最底层为排名1，最顶层为排名N。
4. 对排名为k的框，将其完整边界框内部（不含边框本身）所有像素涂为对应颜色：排名1→蓝(1)，排名2→红(2)，排名3→绿(3)，排名4→黄(4)，排名5→灰(5)。
5. 所有框的边框像素保持其原始颜色不变。若多个框的内部区域有重叠，排名高（更上层）的框的内部填色覆盖排名低的。
6. 背景保持黑(0)。

**关键洞察**：内部填充颜色与框的边框颜色无关——它完全由重叠遮挡推断出的深度位置决定。求解者必须先完成空间推理（重建被遮挡的边框，判断遮挡方向），再将推理结果映射到与原始颜色无关的新色方案。
