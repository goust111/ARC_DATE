## 新题 3：瓦片前景计数驱动同心环色板

**组合逻辑**：[计数](已有) + [排序](已有) → [距离映射](创新：距离场的颜色不来自固定色板，而由瓦片计数排序动态生成) + [曼哈顿距离](已有)

**来源原语**：计数、排序、前景数决定排序、阵列排布、瓦片 ← dc2aa30b；同心环、距离映射、曼哈顿距离、循环色板 ← aaef0977；分隔线 ← dc2aa30b；标记像素 ← aaef0977

**依赖链**：在3x3瓦片阵列中计数每个周边瓦片的前景像素 → 按计数排序得到8个瓦片的排名 → 每个瓦片的主色（非黑非前景的颜色）按排名顺序排列成色板 → 以中心瓦片的标记像素为圆心，在与输入同尺寸的输出网格上绘制曼哈顿距离同心环 → 环k使用色板第k个颜色（循环）

两种完全不同的几何结构——瓦片阵列和同心环——通过计数排序这个桥梁连接。阵列在输出中完全消失，被环结构取代。

**输入结构**：
- 11x11 网格，由两条黑(0)横行（第3、7行，0起始索引）和两条黑(0)纵列（第3、7列）将网格分割为3x3阵列的3x3瓦片。
- 中心瓦片（第1行第1列，0起始索引）包含一个标记像素（灰(5)），其余格为黑(0)。灰像素的位置即为同心环圆心在整个网格中的坐标。
- 8个周边瓦片各有若干蓝(1)前景像素和一个独特的底色（从红(2)、绿(3)、黄(4)、品红(6)、橙(7)、青(8)、栗(9)、灰(5)中选取，每个瓦片底色不同）。瓦片内非蓝非黑的格均为该瓦片底色。
- 8个周边瓦片的蓝(1)像素计数互不相同（各为1-8中的某个值，无平局）。
- 生成约束：8个瓦片的蓝像素数恰好覆盖1到8各一次。

**规则**：
1. 计数每个周边瓦片（排除中心瓦片）中蓝(1)像素的数量。
2. 按蓝像素数从小到大排序8个瓦片，得到排名1-8。
3. 构建色板序列：色板[k] = 排名为k的瓦片的底色（即该瓦片中非蓝非黑的颜色）。
4. 构建与输入同尺寸（11x11）的输出网格。以中心瓦片标记像素的全局坐标(r0, c0)为圆心。
5. 输出网格中每个位置(r, c)的曼哈顿距离 d = |r - r0| + |c - c0|。距离0处涂灰(5)（标记色）。距离d处涂色板[(d-1) mod 8]（1起始循环）。
6. 输出网格中原黑色分隔线位置也按曼哈顿距离涂色，不保留分隔线。

**关键洞察**：瓦片阵列仅用于编码色板——它在输出中被完全替换为以标记点为中心的同心环图案。仅看环形输出无法得知色板来源；仅看瓦片阵列无法得知环的形状。必须跨越两种几何理解才能求解。
