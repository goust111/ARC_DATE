## 新题 9：L标记编码的双通道直角连线

**组合逻辑**：[连线](已有) + [重涂色](创新：连线颜色由 L 标记朝向编码，而非固定色) + [擦除](已有) ← [标记体](创新：L 标记既标识起点端又编码路径颜色——双重角色) + [端点像素](已有) + [直角路径](已有) + [标记朝向编码颜色](已有) + [行列交汇](已有) + [拐角由终点列定](已有) + [标记在对象上方](已有)

**来源原语**：连线(draw_line, d4a91cb9), 重涂色(recolor, 604001fa), 擦除(erase, 604001fa), 标记体(marker, 604001fa), 端点像素(endpoint_pixel, d4a91cb9), 直角路径(right_angle_path, d4a91cb9), 标记朝向编码颜色(marker_orientation_encodes_color, 604001fa), 行列交汇(row_col_intersection, d4a91cb9), 拐角由终点列定(corner_at_target_col, d4a91cb9), 标记在对象上方(marker_above_object, 604001fa)

**依赖链**：L 标记标识哪个端点是路径起点（标记角色 1）→ L 标记朝向编码路径颜色（标记角色 2）→ 从起点端水平画线到终点端的列 → 从该交汇点垂直画线到终点端（直角路径构建）→ 擦除所有 L 标记像素。L 标记同时承载空间角色（标识起点）和语义角色（编码颜色），必须同时正确解码。

每对同色端点之间画直角路径，路径颜色由起点端上方的 L 标记朝向编码，L 标记同时标识哪个端点是起点。

**输入结构**：约 12x12 的黑(0)背景网格。包含 2~3 对端点像素，每对共享一种独特前景色（如蓝(1)、绿(3)、栗(9)等），每对中两个像素不在同一行也不在同一列。每对中恰好一个端点的正上方 2x2 区域内有一个橙(7)L-三联骨牌标记（占据 2x2 区域中的 3 个格子，留一个缺角）。另一个端点上方无标记。不同对的端点和标记互不重叠。生成约束：L 标记不超出网格边界；各对端点之间的直角路径互不交叉（路径区域无重叠）。

**规则**：
1. 按颜色配对端点像素：同色的两个像素为一对。
2. 在每对中，有 L 标记的端点为"起点端"，无标记的为"终点端"。
3. 读取 L 标记的缺角方向，映射为路径颜色：缺角在左上 → 绿(3)，缺角在右上 → 青(8)，缺角在左下 → 黄(4)，缺角在右下 → 品红(6)。
4. 擦除所有橙(7)L 标记像素为黑(0)。
5. 从起点端出发，沿水平方向画线（使用步骤 3 确定的颜色）到终点端所在列。
6. 从该交汇点出发，沿垂直方向画线（同一颜色）到终点端所在行。
7. 起点端和终点端像素保留原色不变，仅路径中间像素使用编码颜色。
8. 各对独立处理，顺序不影响结果（由生成约束保证无交叉）。

**关键洞察**：L 标记承担双重角色——它标识哪个端点是路径起点（空间角色），又通过缺角方向编码路径颜色（语义角色）。求解者必须先用标记分辨起终点（决定路径几何形状），再从同一标记解码颜色（决定路径外观），遗漏任一角色都无法正确作答。
