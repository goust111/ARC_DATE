## 新题 11：面积位移决定着陆区洪泛填充

**组合逻辑**：[滑动/slide](已有) + [面积决定位移/area_determines_displacement](已有) → [洪泛填充/flood_fill](创新：填充目标不由墙直接划定，而由分量着陆位置间接确定) + [四连通分区/four_connected_partition](已有)

**来源原语**：
- 滑动、连通分量、面积决定位移、超界裁剪 ← 8e301a54
- 洪泛填充、分隔墙、封闭区域、四连通分区 ← 782b5218
- 忽略干扰项 ← 782b5218
- 擦除 ← 9bebae7a

**依赖链**：计算每个连通分量的像素面积 → 按面积决定向下滑动距离 → 滑动后分量着陆在某个下区分区内 → 以分量颜色洪泛填充其着陆分区。面积信息同时控制两件事：位移距离（物理运动）和填充目标（着陆位置决定填充哪个分区）。两步紧耦合：改变面积则着陆分区改变；改变分区布局则同一面积的分量着陆不同区域。

将上方的彩色连通分量按各自面积向下滑动，每个分量所落入的下方分区被洪泛填充为该分量的颜色。

**输入结构**：约 15x15 的网格，背景为黑(0)。一条红(2) 水平墙（贯穿全宽，一像素厚，位于网格约 1/3 高度处，如第 5 行）将网格分为上下两区。上区：3~4 个单色 4-连通小分量（每个 2~5 像素，颜色互不相同：蓝(1)、绿(3)、黄(4)、橙(7) 等），散布在不同行列位置，互不接触。下区：红(2) 水平墙下方有若干条红(2) 垂直短墙段（不贯穿全高，仅覆盖下区的 2~4 行，从水平墙向下延伸），将下区分为 3~4 个大小不等的 4-连通非红区域（矩形子分区）。生成约束：每个上区分量按其面积像素数向下滑动后（穿过水平墙），其最底行像素恰好落入不同的下区分区（不同分量着陆在不同分区中）；至少一个分量因面积较大而完全滑出网格底部边界（该分量被丢弃，其对应的潜在着陆分区不被填充）。

**规则**：
1. 识别红(2) 水平墙上方的所有 4-连通单色分量。计算每个分量的像素面积 A。
2. 将每个分量从其原始位置向下平移 A 行（分量整体下移，保持形状和水平位置不变）。清除上区该分量原始位置的像素为黑(0)。红墙对滑动不构成阻碍（分量穿越红墙移动，红墙像素保持不变）。
3. 若平移后分量的任何像素超出网格底部边界，该分量整体丢弃（不绘制到输出中，不触发填充）。
4. 对未丢弃的分量，确定其最底行像素所在的下区分区（由红色水平墙、红色垂直墙段和网格边缘围成的 4-连通非红区域）。
5. 将该分区内所有非红像素洪泛填充为该分量的颜色。分量本身的像素不在输出中单独绘制（仅保留填充结果）。
6. 未被任何分量着陆的分区保持黑(0)。红(2) 墙结构（水平墙和垂直墙段）全部保持不变。

**关键洞察**：连通分量既是颜色信息的载体又是隐式寻址工具——它们的面积决定了向下滑动的距离，而滑动的终点决定了哪个分区被填充为该颜色；分量本身在输出中消失，只有它们"投递"的颜色留在着陆分区中。需要多个示例才能确认位移量等于面积（而非其他属性如边界框尺寸）。
