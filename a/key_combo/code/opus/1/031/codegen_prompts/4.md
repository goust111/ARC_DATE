## 新题 4：嵌套层次编码调色板，孔洞数索引调色板重涂

**组合逻辑**：[压缩/compress + 排序/sorting](创新：嵌套排序结果不输出为方环而是作为运行时调色板) → [计数/counting + 重涂色/recolor](创新：孔洞数不再映射固定颜色而是索引嵌套调色板)

**来源原语**：压缩/compress、排序/sorting、嵌套形状/nested_shape、嵌套层次/nesting_hierarchy、面积序映射环/area_order_to_ring（来自 eb5a1d5d）；计数/counting、重涂色/recolor、前景对象/foreground_object、封闭背景区域/enclosed_background_region、孔洞数映射颜色/hole_count_to_color_mapping（来自 37d3e8b2）；擦除/erase（来自 aa62e3f4）

**依赖链**：嵌套形状的面积排序生成颜色序列（调色板）→ 右侧对象的孔洞数作为调色板索引 → 索引选出的颜色用于重涂右侧对象 → 左侧嵌套形状擦除后调色板信息消失 → 必须先解码嵌套才能确定任何重涂结果

用一行描述：左半部嵌套彩色轮廓按面积排序形成调色板，右半部灰色对象按各自孔洞数从调色板中取色重涂，左半部随后擦除。

**输入结构**：约 18x18 黑(0)背景网格。左半区（约列 0~7）放置 3~4 层嵌套的单色轮廓形状（每层为一种不同颜色的 4-连通闭合环，从红(2)、蓝(1)、绿(3)、黄(4)中取色；外层包围内层；各层边界框面积严格递减）。右半区（约列 10~17）放置 3~4 个互不相邻的灰(5)4-连通实心对象（各约 15~30 像素），每个对象内部有 1~4 个不同的黑(0)封闭背景连通分量（孔洞）。生成约束：右侧对象的孔洞数互不相同，且最大孔洞数不超过嵌套层数。不同示例中嵌套颜色顺序不同（即同一嵌套深度在不同示例中使用不同颜色）。

**规则**：
1. 在左半区检测所有嵌套轮廓层。按边界框面积从大到小排序，得到颜色序列 P = [c1, c2, c3, ...]，其中 c1 是最外层颜色，c2 是次外层，以此类推。
2. 在右半区，对每个灰(5)对象，计算其内部的 4-连通黑(0)封闭区域数量 H。
3. 将每个灰(5)对象重涂为 P[H]（序列 P 的第 H 个颜色，从 1 开始索引，即 H=1 取 c1，H=2 取 c2 等）。对象形状不变，仅颜色从灰(5)变为 P[H]。
4. 将左半区所有嵌套轮廓擦除为黑(0)背景。

**关键洞察**：调色板不是固定的——它编码在输入本身的嵌套空间结构中，必须通过面积比较解码。不同示例的嵌套颜色顺序不同，因此单看一个示例无法确定"1 个孔洞对应什么颜色"，必须对比嵌套结构和重涂结果才能归纳出索引规则。
