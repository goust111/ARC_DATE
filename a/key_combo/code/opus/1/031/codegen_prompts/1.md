## 新题 1：计数平移十字与幽灵遮蔽距离环

**组合逻辑**：[计数/counting] → [平移/translate](创新：平移后旧位置留灰色幽灵) → [填充/fill](创新：Chebyshev 距离环被幽灵轨迹遮断)

**来源原语**：计数/counting、计数器像素/counter_pixel、平移/translate、计数决定偏移/count_determines_offset、计数器消失/counter_disappears（来自 e48d4e1a）；填充/fill、交叉点中心/intersection_center、偶数切比雪夫距离/even_chebyshev_distance（来自 759f3fd3）；擦除/erase（来自 d687bc17）

**依赖链**：计数器像素数量决定十字平移距离 → 平移改变交叉中心坐标 → 旧位置幽灵轨迹占据部分背景 → 新中心的 Chebyshev 距离环只能绘制在既不被新十字也不被幽灵占据的背景像素上 → 幽灵轨迹在距离环中打出不规则缺口

用一行描述：根据计数器像素平移十字后，在旧位置留下灰色幽灵痕迹，再以新交叉点为中心绘制偶数 Chebyshev 距离环，幽灵痕迹处不绘制。

**输入结构**：约 12x12 黑(0)背景网格。有一条完整的蓝(1)横行和一条完整的蓝(1)纵列，交叉形成十字。最右列的顶部连续放置 1~3 个灰(5)像素作为计数器（生成约束：灰像素数量保证平移后十字仍完全在网格内）。网格中无其他非黑像素。不同示例中十字的初始交叉位置不同，计数器数量也不同。

**规则**：
1. 数灰(5)像素的个数 N。将灰像素全部擦除为黑(0)。
2. 将蓝(1)十字整体平移：横行下移 N 行，纵列左移 N 列。原位置的蓝像素擦除为黑(0)，新位置绘制蓝(1)。
3. 平移后，将所有"原十字占据但新十字不占据"的像素涂灰(5)，形成幽灵轨迹。（新旧重叠处保留蓝色。）
4. 确定新十字的交叉点坐标 (r, c)。对网格中每个既非蓝(1)也非灰(5)的黑(0)像素，计算其到 (r, c) 的 Chebyshev 距离 d = max(|row-r|, |col-c|)。若 d 为正偶数，将该像素涂黄(4)。
5. 灰(5)幽灵像素和蓝(1)十字像素均保持不变，不被黄色覆盖。

**关键洞察**：幽灵轨迹不是纯装饰——它遮断了距离环，使得同一环在不同方向上出现缺口。求解者必须同时推断平移量（从计数器）和幽灵遮蔽规则（旧位置不画环），缺少任一条件都无法还原输出。
