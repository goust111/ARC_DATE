## 新题 2：对角链拓扑编码镜像轴

**组合逻辑**：[连通检测 + 对角链式连接](创新：8-连通区域的内部拓扑不再用于决定变色，而是编码面板的几何变换类型) + [镜像](创新：镜像轴不由显式引导线给出，而由标记区域的连通拓扑隐式编码) + [重涂色](创新：消除编码标记，使变换指令在输出中不可见)

**来源原语**：八连通区域、对角链式连接、仅对角接触变色（ecb67b6d）；镜像、九宫面板、引导线、轴线决定变换（4e7e0eb9）；重涂色（880c1354）

**依赖链**：灰色标记区域的 4-连通分解决定了拓扑类型（对角链 vs 实心块），拓扑类型决定镜像轴方向，镜像改变面板内容的空间排列，最后标记被重涂消除——拓扑分析的结果被镜像操作消费，而重涂消除了推理线索。

分析每个面板内灰色标记区域的内部连通拓扑，以此决定镜像方向，然后将标记吸收进面板图案。

**输入结构**：约 19x19 网格，由灰(5)的单像素宽网格线分割为 3x3 共 9 个面板，每个面板内部为 5x5。每个面板包含：
- 黑(0)背景上的一组彩色像素图案（使用蓝(1)、红(2)、绿(3)中的一种，每面板一色）。图案为 3-8 个非对称分布的像素。
- 恰好一个灰(5)标记区域（3-5 像素），位于面板内不与彩色图案重叠的位置。标记区域是 8-连通的（作为整体连通），但其内部 4-连通结构分为两种情况之一：
  - **对角链型**：标记区域可分解为 2-3 个 4-连通团块，团块之间仅通过对角角点接触（形成阶梯状链），无 4-连通的直接相邻。
  - **实心型**：标记区域本身就是一个 4-连通区域（所有像素通过上下左右相邻彼此连通）。
- 生成约束：每个面板的彩色图案关于该面板的水平中轴或垂直中轴均不对称（确保镜像产生可观察的变化）。9 个面板中两种标记类型至少各出现 2 次。

**规则**：
1. 对每个面板，提取其灰(5)标记区域。
2. 将标记区域分解为 4-连通团块。检查团块间的连接方式：
   - 若所有团块仅通过对角角点相连（即任意两个不同团块之间无 4-连通相邻，但存在 8-连通相邻），则该面板为"对角链型"。
   - 若标记区域整体就是单个 4-连通区域，则该面板为"实心型"。
3. 对角链型面板：以面板的垂直中轴为轴，将面板内容（含彩色图案，不含标记）左右镜像。
4. 实心型面板：以面板的水平中轴为轴，将面板内容（含彩色图案，不含标记）上下镜像。
5. 镜像完成后，将每个面板中的灰(5)标记像素重涂为该面板中彩色图案的颜色（即标记像素变为与该面板的蓝/红/绿图案同色）。
6. 灰(5)网格线保持不变。

**关键洞察**：面板内没有显式的引导线——灰色标记区域的拓扑结构（对角阶梯 vs 实心块）本身就是镜像轴的编码；完成镜像后标记被吸收进图案，编码信息在输出中消失。
