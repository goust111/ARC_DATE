## 新题 9：推移至边界后同色配对绘制虚线连接

**组合逻辑**：[推移 + 接触侧决定方向 + 推至边界停止](保留推移机制) + [连线 + 奇偶决定虚线](创新：连线的端点不是预设的角标记，而是推移后的对象位置；虚线的疏密由推移距离这一涌现量决定) + [同色匹配 + 对角配对](创新：配对依据从空间对角位置改为颜色相同，配对对象从标记像素改为推移后的对象)

**来源原语**：推移、擦除、固定标记、接触侧决定方向、推至边界停止（5623160b）；连线、奇偶决定虚线（f35d900a）；同色匹配（8f215267）；对角配对（f35d900a）

**依赖链**：接触侧分析产生推移方向（边界分析→运动参数）；推移将对象送至网格边缘（运动→位置变化）；推移后的位置成为连线端点（位置→几何构造的输入）；同色对象配对确定哪些对象之间画线（颜色匹配→关系建立）；线长由推移后的距离决定，线长又决定虚线的具体图案（距离→视觉节奏）。

将接触标记的同色对象对推向网格边界，然后在每对同色对象之间绘制虚线连接。

**输入结构**：黑(0)背景，约 15x15 网格。包含：
- 栗(9)像素组成的固定标记结构，位于网格中心区域，形成一个 4-连通的紧凑形状（4-8 像素）。
- 恰好 6 个小型 4-连通单色对象（各 2-4 像素），分为 3 种颜色（蓝(1)、红(2)、绿(3)），每种颜色恰好 2 个对象。
- 每个对象恰好在一个基本方向上与栗色标记 4-连通相邻（对象完全在标记的上/下/左/右方，接触边朝向标记）。
- 同色的两个对象位于标记的不同方向（例如一个蓝色对象在标记上方，另一个在标记右方）。
- 生成约束：每个对象推移到边界后不与其他已推移对象重叠；6 个对象覆盖至少 3 个不同方向。

**规则**：
1. 对每个非栗色对象，确定其与栗色标记的接触方向，推移方向为远离标记的方向。
2. 将每个对象从原位擦除，沿推移方向平移至网格边缘（对象紧贴边缘）。
3. 栗色标记保持不变。
4. 对每对同色对象（已在网格边缘），计算两者的质心坐标。
5. 在两个质心之间绘制灰(5)虚线段：
   - 若两质心同行，绘制水平线段。若同列，绘制垂直线段。若既不同行也不同列，绘制 L 形折线（先水平到目标列，再垂直到目标行；水平段在靠近行号较小的质心那一行绘制）。
   - 虚线规则：沿线段路径，从第一个质心出发，依次编号 0, 1, 2, ...。编号为偶数的位置绘制灰(5)，编号为奇数的位置保持黑(0)（或保持原有颜色不覆盖）。
6. 虚线不覆盖已推移到边缘的对象像素和栗色标记像素（遇到这些像素保持原色跳过编号）。
7. 若两条不同颜色对的虚线路径相交，先绘制的线保留（绘制顺序：蓝(1)对先绘、红(2)对次之、绿(3)对最后）。

**关键洞察**：栗色标记是多功能枢纽——它的形状决定了对象的接触方向（发射方向），对象飞向边界后的落点距离决定了配对虚线的长度和节奏；推移既分离了同色对象（创造了需要连接的间距），又通过距离影响了虚线的视觉密度。
