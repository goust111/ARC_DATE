## 新题 10：骨架对齐传递标注后标注像素发射对角射线

**组合逻辑**：[旋转/镜像 + 印章](骨架对齐→标注传递) → [射线延伸](传递后的标注像素→对角射线源) + [擦除](骨架和锚点消失，仅留射线)

**来源原语**：旋转(#20 36d67576), 镜像(#20), 印章覆盖(#20 / #15 d6542281), 射线延伸(#18 7ddcd7ec), 擦除(#5 917bccba), 精灵体(#20), 锚点像素(#20), 对角标记(#18), 实心正方形(#18→退化为锚点), 骨架对齐(#20), 对角邻接(#18), 完整标注传递副本(#20), 锚角对角射线至边(#18)

**依赖链**：骨架对齐确定每个副本的旋转/镜像变换→变换决定标注像素在副本上的具体位置→标注像素相对于锚点的对角方向决定射线方向→不同副本的旋转使同一标注产生不同方向的射线。删除骨架对齐则标注位置不确定；删除射线延伸则标注只是颜色标记无后续效果。

完整骨架的标注通过旋转/镜像传递到各副本后，每个标注像素从其位置向远离锚点的对角方向发射射线至网格边缘。

**输入结构**：约 16x16 的黑(0)背景网格。散布 4 个灰(5)骨架图形（每个骨架为 4~7 像素的 8-连通单色图形，形状相同但可能经过 0/90/180/270 度旋转或水平/垂直翻转），每个骨架含恰好一个蓝(1)锚点像素（位于骨架的某个端部或拐角处，是骨架的一部分）。其中恰好一个骨架额外包含 1~2 个标注像素（颜色为红(2)或绿(3)），每个标注像素位于锚点像素的某个对角方向的相邻位置（即标注像素与锚点在对角方向上 8-连通相邻）。标注像素不属于骨架（不是灰色），是额外附着的。其余 3 个骨架仅有灰(5)骨架 + 蓝(1)锚点，无标注。生成约束：各骨架互不重叠、互不相邻（间距 >= 3 像素）；各骨架可通过唯一的旋转/镜像变换相互映射。

**规则**：
1. 以含标注的骨架为源模板。对每个无标注的目标骨架，求出将源骨架的灰(5)像素集合和蓝(1)锚点映射到目标骨架的灰(5)像素集合和蓝(1)锚点的唯一二面体变换（旋转 + 可选镜像 + 平移）。
2. 将源模板上每个标注像素的相对位置（相对于锚点的行列偏移）通过该二面体变换映射到目标骨架的锚点，在目标位置绘制相同颜色的标注像素。
3. 现在每个骨架（含源模板）都有标注像素。对每个标注像素：确定它相对于其所属骨架锚点的对角方向（左上、右上、左下、右下之一）。从该标注像素出发，沿该对角方向持续延伸射线（每步行 +/-1、列 +/-1），绘制标注像素的颜色，直到射线离开网格边界。射线起始于标注像素的下一个对角位置（标注像素本身不重绘）。
4. 擦除所有灰(5)骨架像素和蓝(1)锚点像素（变为黑(0)）。标注像素本身也擦除。仅保留对角射线。
5. 若多条射线经过同一像素，后绘制的覆盖先绘制的（绘制顺序：骨架按锚点位置从左上到右下处理；同一骨架内多个标注按行优先序处理）。

**关键洞察**：骨架-标注传递系统不是为了视觉补全——传递后的标注像素是射线发射器的安装位置，而每个骨架的旋转状态决定了射线的发射方向。同一个标注模式在四个不同朝向的骨架上产生四组不同方向的对角射线，形成辐射状的几何图案。骨架是"方向编码载体"，用完即弃。
