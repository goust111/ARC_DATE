## 新题 8：种子选模板后按封闭区域形状裁切平铺

**组合逻辑**：[洪泛填充](识别封闭区域) + [种子选择](种子颜色→模板匹配) + [平铺](模板在包围盒内重复) + [裁剪](按边界形状裁切多余平铺)

**来源原语**：洪泛填充(#19 00d62c1b), 平铺(#4 a59b95c0), 裁剪(#1 67b4a34d / #11 995c5fa3), 种子像素(#6 8a6d367c), 模板(#6), 封闭区域(#19), 边界(#19), 拓扑内外(#19), 框内匹配(#6→扩展为区域内匹配), 种子选择模板(#6), 仅填封闭内部(#19)

**依赖链**：洪泛填充识别出区域和边界→区域内的种子像素决定选用哪个模板→模板在区域包围盒内平铺→平铺结果被区域边界裁切。每个区域独立执行此流程，且不同区域可能选择不同模板。

多个封闭区域各含一个种子像素，种子颜色选定对应模板，模板被平铺填满区域，超出边界的部分被裁切。

**输入结构**：约 16x16 的黑(0)背景网格。顶部两行是"模板展示区"，包含 3 个并排的小模板（每个 2x2 或 2x3），以 2 列黑(0)间隔分开。每个模板使用一种底色（如红(2)、蓝(1)、橙(7)）加黑(0)组成二值图案。顶部模板区下方（行 3 起）是"区域区"：绿(3)像素构成 3 条互不相交的闭合边界曲线，形成 3 个封闭区域，面积各异（约 8~25 像素），形状不规则（非矩形）。每个封闭区域内部恰好有一个种子像素，其颜色与某个模板的底色相同。三个种子分别匹配三个不同的模板。生成约束：每个封闭区域的包围盒尺寸是其对应模板尺寸的整数倍（宽和高分别独立为整数倍）。

**规则**：
1. 识别绿(3)边界围成的所有封闭区域。
2. 对每个封闭区域，读取其内部种子像素的颜色 C。
3. 在顶部模板区中找到底色为 C 的模板 T。
4. 计算该封闭区域的最小包围盒，将模板 T 在包围盒内做行列方向的密铺（平铺直到完全覆盖包围盒）。
5. 对平铺结果进行裁切：仅保留位于封闭区域内部（被绿边界包围的黑像素位置）的平铺像素，封闭区域外部的平铺像素丢弃。种子像素位置也被平铺像素覆盖。
6. 输出为完整的 16x16 网格：顶部模板区保留不变，绿边界保留不变，每个封闭区域内部被裁切后的平铺图案填满。

**关键洞察**：每个封闭区域是独立的"画布"，其形状不规则，平铺必须适配不规则轮廓（而非填满矩形框）。种子像素是三路分发器——同一个网格中三个区域可能出现三种完全不同的平铺图案，而选择逻辑隐含在颜色匹配中。

    4. Assign colors - pick outline color, optionally one fill color, and a marker color, all with distinct pixel counts. Fill shape concentrically (outline on border, fill inside, marker innermost).
