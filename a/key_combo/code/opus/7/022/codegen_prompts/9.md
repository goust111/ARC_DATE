## 新题 9：闸门旋转改变管道拓扑后洪泛填充新封闭区域

**组合逻辑**：[旋转](闸门 90 度旋转改变通路) + [洪泛填充](检测旋转后的新拓扑) + [重涂色](新封闭区域上色、旧封闭区域清色) — 三操作通过拓扑状态的前后对比耦合

**来源原语**：旋转(#16 2b83f449 / #20 36d67576), 洪泛填充(#19 00d62c1b), 重涂色(#2 d89b689b / #7 aabf363d), 闸门(#16), 管道网络(#16), 封闭区域(#19), 边界(#19), 拓扑内外(#19), 碰撞停止(#16→改为拓扑变化), 仅填封闭内部(#19)

**依赖链**：闸门旋转是拓扑操作——水平闸门变为垂直后，原本连通的通路可能被截断形成新封闭区域，原本封闭的区域可能被打开变为连通。填充操作必须在旋转后的拓扑上执行，且"新封闭 vs 旧封闭"的区分需要隐式的拓扑比较。

闸门从水平旋转为垂直后，管道网络的拓扑发生变化；仅对旋转后新形成的封闭区域进行填充。

**输入结构**：约 12x14 的网格。黑(0)像素构成管道壁（占据固定位置，形成迷宫状网络）。灰(5)像素为管道内部的通路空间。红(2)水平条（1x3 大小，1 行 3 列）为闸门，嵌在管道壁的间隙中（左右两端紧邻黑(0)壁，上下为灰(5)通路），共 2~4 个闸门。部分通路区域在当前（闸门未旋转）状态下已经形成了封闭区域（四周被壁包围），这些区域预填充了蓝(1)色。其余通路区域连通到网格边缘（非封闭），为灰(5)。生成约束：每个闸门的中心像素位置固定，旋转后变为 3x1（3 行 1 列）的垂直条，且旋转后的垂直条不与其他壁像素冲突；至少一个闸门旋转后会封闭新区域，至少一个闸门旋转后会打开已有封闭区域。

**规则**：
1. 将每个红(2) 1x3 水平闸门旋转 90 度为 3x1 垂直条：闸门中心像素位置不变，原水平闸门的三个像素位置变为灰(5)通路，新垂直闸门的三个像素位置（中心 + 上一行 + 下一行）变为红(2)壁。
2. 在旋转后的网格上做拓扑分析：从网格边缘对所有灰(5)像素做洪泛扩散，标记所有与边缘连通的灰色区域为"外部"。
3. 未被标记的灰(5)区域为旋转后的封闭区域。
4. 对比旋转前后的封闭状态：
   - 旋转前非封闭、旋转后封闭的区域（新封闭）→ 填充为黄(4)。
   - 旋转前封闭（已有蓝(1)填充）、旋转后仍封闭的区域 → 保持蓝(1)不变。
   - 旋转前封闭（蓝(1)）、旋转后非封闭的区域（被打开）→ 清除蓝(1)，恢复为灰(5)。
5. 管道壁黑(0)和旋转后的红(2)闸门保持不变。

**关键洞察**：闸门是拓扑开关而非障碍物——旋转操作同时创造和摧毁封闭区域，填充规则取决于旋转前后的拓扑差异而非绝对状态。"新封闭涂黄、旧封闭开放则清色"这一差分规则需要对比多个示例才能归纳。
