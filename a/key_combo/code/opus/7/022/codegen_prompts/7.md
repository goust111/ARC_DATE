## 新题 7：梳状结构高度参数化射线延伸距离

**组合逻辑**：[计数](梳状结构→射线长度参数) + [射线延伸](受限距离，非到边) + [连线](端点处转折) + [擦除](梳状结构消耗后消失)

**来源原语**：计数(#10 a1aa0c1e), 射线延伸(#14 99fa7670), 连线(#14→转折路径), 擦除(#5 917bccba), 梳状结构(#10), 色条(#10→退化为标记像素), 孤立像素(#14), 画布边界(#14 / #18 7ddcd7ec), 高度编码数量(#10), 行列对齐(#14), 转折至下一标记行(#14)

**依赖链**：梳状结构的固有高度必须先计数才能得到射线长度参数 N；射线从标记像素出发延伸 N 格后转折；梳状结构在输出中被擦除，因为它已完成编码任务。删除任一环节输出不确定。

每个标记像素有对应颜色的梳状结构，梳的实心行数 N 决定了该标记射线向右延伸 N 格后转折向下的距离。

**输入结构**：约 15x15 的黑(0)背景网格。左侧区域（列 0~2）有 3~4 个不同颜色的单像素标记，分布在不同行，颜色分别为红(2)、蓝(1)、绿(3)、黄(4)等。右侧区域（列 10~14）有与标记数量相等的三列宽梳状结构，每个梳状结构的颜色与一个标记像素匹配。梳状结构由交替的"三像素实心行"和"两侧像素行（中间空）"组成，实心行数量 N 在 1~5 之间变化（不同梳的 N 不同）。各梳状结构从不同行开始，互不重叠。生成约束：各标记像素的行位置互不相同；射线在延伸和转折过程中不会与其他射线或梳状结构冲突。

**规则**：
1. 对每个标记像素，找到颜色匹配的梳状结构，计数其实心行数量 N。
2. 从标记像素位置向右延伸 N 个像素的水平射线（含标记像素本身则总长 N+1；不含则为 N 格新像素），使用标记像素的颜色绘制。若射线在到达 N 格之前碰到网格右边界，则在边界处停止。
3. 在射线的右端点处转折向下，继续延伸 N 个像素的垂直射线（同色）。若垂直射线在到达 N 格之前碰到网格底边界，则在底边界处停止。
4. 擦除所有梳状结构（将其占据的像素恢复为黑(0)），标记像素保留（作为射线起点）。
5. 多条射线的绘制顺序为标记像素从上到下；若两条射线的路径存在像素重叠，后绘制的颜色覆盖先绘制的。

**关键洞察**：梳状结构不是输出的一部分，而是可读取的"参数存储器"——每个梳的垂直复杂度编码了一个数值，该数值限定了完全不同区域中射线的空间延伸范围。梳与射线通过颜色匹配关联，通过数值控制耦合。

Recolor each black or blue connected component with the color of the marker that borders it most.

Input structure
- The grid contains black regions, blue line components, and isolated non-black/non-blue marker pixels.
- Marker pixels are controls; the black and blue cells are the regions to recolor.
Rule
- Label black and blue cells separately using 4-connectivity.
- For each labeled component, count side-adjacencies to every marker pixel.
- Recolor the component with the marker color having the largest shared side boundary; equal counts use row-major marker order.
- Leave the marker pixels unchanged.
Key insight
- The color assignment is local to each original-color component and is decided by shared edge contact with nearby markers.

Sort objects to top or bottom edge by whether their shape (up to rotation/flip) is shared.

Input structure:
- bg = most common color.
- Several multicolor connected components (8-connected) scattered across the grid.

Rule:
- Compute each object's canonical shape (binary mask, invariant to rotation and flip).
- Objects whose shape appears in two or more components → translate to TOP edge (row 0).
- Objects whose shape is unique → translate to BOTTOM edge (row H−h).
- Horizontal position (left column) is preserved; only vertical translation changes.

Key insight: The sorting criterion is shape frequency (rotation-invariant), not area — duplicated shapes go up, unique shapes go down.
