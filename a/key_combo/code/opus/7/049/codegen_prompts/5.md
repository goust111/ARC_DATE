## 新题 5：统计选色镜像涂绘

**组合逻辑**：[镜像](创新：不是补全空白半区，而是将上半区的掩码几何镜像到下半区) + [计数/选择/最大增长差](原有) + [掩码决定保留](创新：从全局掩码改为半区掩码) + [擦除](原有)

**来源原语**：镜像、翻转对称、半区、空白半区补全（f25ffba3）；计数、选择、两区域比较、最大增长差、标记掩码（8597cfd7）；掩码决定保留、掩码像素、重涂色、擦除（f76d97a5）

**依赖链**：水平分隔 → 上半区灰像素位置构成几何掩码 → 上下半区分别统计各色像素数 → 计算增长差选出获胜色 → 将上半区灰像素位置垂直镜像到下半区 → 在下半区镜像位置涂获胜色 → 擦除下半区原有颜色像素。"画在哪"和"画什么色"来自两条独立信息线，缺一不可。

上半区的灰像素位置镜像到下半区决定"在哪画"，上下半区的颜色计数差决定"画什么色"，两者在下半区输出中交汇。

**输入结构**：
- 约 12x10 网格。
- 一条完整的灰(5)水平线（占据某一行的全部列）将网格分为上半区（约 5 行）和下半区（约 5 行）。
- 上半区：黑(0)背景上有若干灰(5)像素构成一个不规则的 4-连通图案（5~10 像素），还有少量彩色像素散布（如红(2) 3 个、蓝(1) 2 个）。
- 下半区：黑(0)背景上有多种颜色像素散布（如红(2) 5 个、蓝(1) 8 个、绿(3) 4 个），无灰像素。
- 生成约束：恰好有一种颜色的"下半区数 - 上半区数"为正且唯一最大；上半区灰像素镜像到下半区后不超出网格边界。

**规则**：
1. 识别灰(5)水平分隔线（整行全为灰(5)的行），将网格分为上半区和下半区。
2. 对每种非黑(0)非灰(5)颜色 C，统计 C 在上半区的像素数 U_C 和在下半区的像素数 D_C。
3. 计算增长差 delta_C = D_C - U_C，选择 delta 最大的颜色为"获胜色" W。
4. 提取上半区所有灰(5)像素的坐标 (r, c)。设分隔线行号为 S，将每个坐标镜像为 (2S - r, c)，得到下半区的"掩码位置"集合。
5. 构建输出网格（与输入同尺寸）：全黑(0)背景，分隔线保留灰(5)，上半区保持输入原样不变，下半区仅在掩码位置涂获胜色 W，其余为黑(0)。
6. 输出完整网格。

**关键洞察**："画在哪里"完全由上半区灰像素的几何形状（垂直镜像后）决定，"画什么颜色"完全由上下半区的颜色人口统计差决定——两条独立的信息线在下半区的输出中交汇，单看任一条都无法确定输出。
