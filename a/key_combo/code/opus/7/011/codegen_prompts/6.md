## 新题 6：嵌套深度决定对角周期填充的周期长度

**组合逻辑**：[嵌套层次](已有) + [循环填充](创新：周期长度由嵌套深度决定) + [对角线同余](创新：不同层使用不同周期的对角图案) + [调色板行](已有)

**来源原语**：嵌套层次/嵌套形状(eb5a1d5d), 循环填充/调色板行/层深度递增(b457fec5), 对角线同余/对角周期图案(c3f564a4)

**依赖链**：识别嵌套形状的层级 → 每层的深度值 D 决定该层间隙区域的对角周期长度 → 调色板行提供周期所需的颜色序列 → 深度为 1 的层使用周期 1（纯色填充），深度为 2 的使用周期 2（双色对角条纹），深度为 3 的使用周期 3（三色对角循环）→ 不知道嵌套深度就无法确定周期，不知道周期就无法正确填色

根据嵌套轮廓的层级深度，用相应周期长度的对角循环图案填充各层间的空隙区域。

**输入结构**：约 19x19 的网格，背景为黑(0)。网格中央有 3~4 层嵌套的单像素宽闭合轮廓线，从外到内颜色依次为红(2)、绿(3)、蓝(1)、品红(6)（按需选用前几个）。轮廓线形状为不规则但互不交叉的闭合环（各层之间间隔 2~4 像素），每层轮廓完全包含内层。轮廓线之间以及最内层内部为黑(0)背景。网格最底行为调色板行，从左到右依次放置 4 个连续像素：灰(5)、橙(7)、青(8)、黄(4)，其余为黑(0)。最外层轮廓与网格边缘之间的区域（深度 0）不做处理。

**规则**：
1. 识别所有闭合轮廓线（非黑非调色板的连通环），按包含关系确定嵌套层级。最外层轮廓深度 D=1，次外层 D=2，依此类推。
2. 对于深度为 D 的轮廓和深度为 D+1 的轮廓之间的间隙区域（或最内层轮廓内部，视为最大 D+1 层的间隙），用对角周期图案填充。
3. 该间隙区域的对角周期长度 = D（即外层轮廓的深度值）。
4. 对角周期规则：对于间隙区域中每个黑(0)像素，计算 (row + col) mod D，得到索引 I，用调色板行的第 I 个颜色替换该像素。
5. 轮廓线像素保持原色不变。调色板行在输出中保持不变。
6. 最外层轮廓外的区域（深度 0）保持黑(0)不变。

**关键洞察**：同一个调色板在不同嵌套层中被截取不同长度使用，导致相邻层产生视觉上截然不同的对角图案（内层图案更复杂），而这种差异完全由几何嵌套深度决定。
