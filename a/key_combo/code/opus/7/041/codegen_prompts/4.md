## 新题 4：标记朝向编码嵌套轮廓的着色序列

**组合逻辑**：[重涂色](创新：不是映射到单一颜色，而是映射到一个颜色循环序列) ← [标记朝向编码](创新：编码的是颜色排列顺序而非单一颜色) + [邻域全包含](创新：迭代腐蚀生成多层轮廓而非仅二值分类)

**来源原语**：标记体/marker(604001fa), 标记朝向编码颜色/marker_orientation_encodes_color(604001fa), 重涂色/recolor(09c534e7), 连通分量/connected_component(09c534e7), 邻域全包含/full_neighborhood_inside_component(09c534e7), 嵌套层/nested_layer(bd5af378), 标记在对象上方/marker_above_object(604001fa)

**依赖链**：L 标记的缺角位置 → 选择一个三色循环序列 → 对每个连通分量做迭代 3×3 腐蚀产生逐层轮廓 → 按层深度依次使用序列中的颜色重涂。标记编码的是"排列"而非"值"，与腐蚀层数形成乘法式组合。

L 形标记的朝向为每个连通分量选择一个三色循环序列，该序列按迭代腐蚀得到的轮廓层深度逐层着色。

**输入结构**：约 18×18 网格，背景黑(0)。有 3-4 个蓝(1)的 4-连通前景分量，每个分量包含粗实心区域（至少有内部像素可形成 2-3 层嵌套轮廓）和单像素宽的走廊连接。每个分量的边界框正上方有一个橙(7)的 2×2 L 形三联标记（占据 2×2 方框中的 3 个像素，缺角位置因分量而异）。标记底行紧贴分量边界框顶行上方，且列范围与分量重叠。生成约束：每个分量的粗实心区域足够大以产生至少 2 层腐蚀层（即实心区域至少有 5×5 的核心）；各分量的 L 标记缺角位置至少有两种不同取值；走廊部分像素的 3×3 邻域不能完全落在分量内。

**规则**：
1. 移除所有橙(7)标记像素为黑(0)。
2. 对每个蓝(1)连通分量，确定其上方 L 标记的缺角位置，并选择对应的三色循环序列：
   - 缺角在左上 → 序列为 [绿(3), 黄(4), 红(2)]
   - 缺角在右上 → 序列为 [红(2), 绿(3), 黄(4)]
   - 缺角在左下 → 序列为 [黄(4), 红(2), 绿(3)]
   - 缺角在右下 → 序列为 [绿(3), 红(2), 黄(4)]
3. 对该分量做迭代腐蚀以生成嵌套轮廓层：
   - 第 0 层：分量内 3×3 邻域完全落在分量内的所有像素。
   - 从分量中移除第 0 层像素。在剩余分量像素中再次找 3×3 邻域完全落在剩余集合内的像素，标记为第 1 层。
   - 重复直到无新层产生。
4. 将第 k 层像素重涂为颜色序列中第 (k mod 3) 个颜色。
5. 未被任何层覆盖的分量像素（走廊和外边界像素）保持蓝(1)不变。

**关键洞察**：L 标记在参考题 604001fa 中编码单一颜色（一对一映射），此处被提升为编码一个颜色排列（一对多映射）。求解者需要发现：(a) 标记朝向与着色序列的对应关系，(b) 序列按腐蚀深度循环使用。仅看单个示例无法区分四种序列。
