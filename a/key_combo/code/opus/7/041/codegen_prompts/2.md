## 新题 2：对角标记编码旋转角的栅格印章

**组合逻辑**：[对角标记像素](创新：编码旋转角度而非象限填充色) → [旋转](创新：角度由颜色查表确定) + [印章放置](创新：模板经旋转后放置) + [重叠区域重涂](已有)

**来源原语**：对角标记像素/diag_marker(e9ac8c9e), 角落对应/corner_correspond(e9ac8c9e), 印章放置/stamp(a395ee82), 旋转/rotate(2013d3e2), 栅格偏移/lattice_offset(a395ee82), 重叠区域重涂/overlap_recolor(a395ee82), 单像素布局/singleton_layout(a395ee82)

**依赖链**：对角标记的位置-颜色对应关系建立旋转查找表 → 各单像素的颜色通过查找表确定其对应的旋转角 → 模板在每个栅格位置被旋转后放置 → 重叠像素被重涂。查找表的编码方式必须从多示例中对比归纳，单示例无法确认四个角的旋转分配。

将对角标记像素作为旋转编码表，在栅格上放置经不同角度旋转的模板副本，重叠位置重涂为指定颜色。

**输入结构**：约 20×20 网格，背景黑(0)。网格中有一个不规则单色模板（蓝(1)，5-8 像素，4-连通，非矩形非对称）。模板边界框的四个对角位置（左上对角、右上对角、右下对角、左下对角各偏移 1 像素）各有一个单像素标记，颜色分别为四种不同颜色（从 {绿(3), 黄(4), 红(2), 橙(7)} 中取，每角一种，不重复）。网格其他位置散布若干单像素点（3-6 个），排列在均匀间距的栅格节点上，每个单像素的颜色是上述四种标记颜色之一。生成约束：栅格间距等于模板边界框的高和宽；各印章副本在旋转放置后至少有一对产生重叠，但不会有三个以上副本在同一像素重叠；模板形状在 0°/90°/180°/270° 旋转下互不相同（确保旋转角可被唯一识别）。

**规则**：
1. 识别模板（最大的蓝(1)连通分量）及其边界框。
2. 识别四个对角标记像素，按其相对于模板边界框角的位置建立旋转查找表：左上对角的颜色 → 0°，右上对角的颜色 → 90° 顺时针，右下对角的颜色 → 180°，左下对角的颜色 → 270° 顺时针。
3. 识别所有远离模板的单像素点。选取其中与模板同色（蓝(1)）的那个像素作为栅格原点。
4. 计算每个非蓝单像素相对于原点的偏移，以模板边界框尺寸为单位换算成栅格坐标。
5. 在每个栅格坐标处放置模板副本：先按该单像素颜色查旋转表得到角度，将模板旋转该角度后放置。原点位置放置一份 0° 副本，但将其颜色改为橙(7)（与模板色不同的指定颜色）。
6. 擦除原始模板区域、四个对角标记像素和所有单像素点为黑(0)。
7. 任何被两个或更多副本共同覆盖的像素重涂为灰(5)。

**关键洞察**：对角标记像素在参考题 e9ac8c9e 中编码象限填充颜色，此处被重新赋义为旋转角度编码表。求解者必须先破解"角位置→颜色→旋转角"的映射，再将其应用于每个栅格点。模板的不对称性是验证旋转角正确性的关键——对称模板会导致多种旋转角产生相同结果。
