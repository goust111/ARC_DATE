## 新题 10：旋转拼图缺块推断与补全

**组合逻辑**：[裁剪](已有：提取象限) + [旋转对称](创新：不是提取已知位置的源瓦片，而是通过旋转测试推断哪个象限是源) → [旋转](创新：生成缺失旋转角度的副本) + [透明叠加](创新：将生成的瓦片填入空白象限)

**来源原语**：裁剪/crop(2013d3e2), 旋转/rotate(2013d3e2), 象限/quadrant(2013d3e2), 旋转对称/rotational_symmetry(2013d3e2), 提取原始瓦片/extract_source_tile(2013d3e2), 透明叠加/transparent_overlay(7ed72f31), 精灵体/sprite(2013d3e2, 7ed72f31)

**依赖链**：裁剪四个象限 → 旋转对称测试确定哪些象限之间存在旋转关系以及源瓦片是谁 → 推断空白象限对应的缺失旋转角 → 生成缺失瓦片并叠加到空白位置。与参考题 2013d3e2 的关键差异：源瓦片不固定在左上角，空白象限位置不固定，输出是补全后的完整拼图而非提取的源瓦片。

识别四象限旋转拼图中缺失的一块，推断其应有的旋转角度，生成并填入。

**输入结构**：约 14×14 网格（偶数行偶数列），背景黑(0)。网格中央有一个正方形区域（边长为偶数，如 8×8 或 10×10），被均分为四个等大正方形象限。其中三个象限各包含一个彩色精灵体（同色，如红(2)，不规则形状，4-8 像素，非对称），第四个象限为纯黑(0)背景（空白）。三个非空象限中的精灵体互为 90° 旋转关系（即存在一个源瓦片，其他两个分别是该源的 90° 顺时针和 180° 或 90° 逆时针旋转）。空白象限的位置不固定（可以是四个角中的任意一个）。正方形区域外的网格部分全为黑(0)。生成约束：精灵体在 0°/90°/180°/270° 旋转下形状互不相同；三个已知象限恰好对应四种旋转中的三种（由此可唯一推断缺失的第四种旋转角）。

**规则**：
1. 定位中央正方形区域并将其均分为四个象限（左上、右上、右下、左下）。
2. 裁剪每个象限。识别哪个象限是空白的（全黑）。
3. 对三个非空象限做两两旋转测试：对象限 A，检验将其旋转 90°/180°/270° 后是否与象限 B 或 C 匹配。确定源瓦片及其在拼图中的原始位置。
4. 确定旋转方案：左上 = 0°, 右上 = 90° 顺时针, 右下 = 180°, 左下 = 270° 顺时针（即 90° 逆时针）。三个已知象限验证此方案。
5. 空白象限对应的旋转角由其位置确定。将源瓦片旋转该角度，生成缺失瓦片。
6. 将缺失瓦片透明叠加到空白象限位置（仅非黑像素写入）。
7. 输出为补全后的完整中央正方形区域（裁剪掉外围黑边）。

**关键洞察**：参考题 2013d3e2 中源瓦片固定在左上角且输出是提取它。此处源瓦片可能在任何象限，空白也在任何象限，输出是补全而非提取。求解者必须通过旋转匹配测试反向推断源瓦片身份和空白象限应有的旋转角——这是一个逆向推理过程而非正向提取。
