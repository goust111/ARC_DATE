## 新题 6：螺旋遇墙分裂续行

**组合逻辑**：[螺旋绘制](创新：遇到墙段不停止而是沿墙段分裂) + [墙段开口分支](创新：分裂点启动新螺旋而非线性射线) + [递增步长](创新：子螺旋继承父螺旋的步长计数继续递增)

**来源原语**：螺旋绘制/种子像素/递增步长/遇障碍停止(e5c44e8f)，射线延伸/分支/墙段/从边缘推进/墙段开口分支(f9a67cb5)

**依赖链**：种子像素启动一个正方形螺旋。螺旋臂碰到墙段时不停止，而是沿墙段的近侧绘制，并从墙段的每个开口处分裂出新螺旋。子螺旋从分裂点开始，继承父螺旋当前的步长计数器继续递增。所有螺旋共享同一个遇障碍停止规则（碰到另一颜色的障碍像素时停止）。墙段的位置和开口决定了螺旋的分裂拓扑。

种子像素启动螺旋，螺旋臂遇到墙段时沿墙分裂，从开口处衍生子螺旋，子螺旋继承步长继续增长。

**输入结构**：约 20x20 的黑(0)背景网格。包含一个蓝(1)色种子像素。若干灰(5)色墙段散布在网格中（每个墙段为水平或垂直的连续线段，长 3~6 像素，厚 1 像素），每个墙段至少有一端不接触网格边界或其他墙段（即存在开口）。可能有 0~2 个红(2)色障碍像素。种子像素不与任何墙段相邻。生成约束：墙段的位置使得主螺旋在前 2~3 条臂内至少碰到一个墙段；墙段之间不相连；开口处的空间足够子螺旋至少绘制 2 条臂。

**规则**：
1. 保留所有灰(5)墙段像素和红(2)障碍像素不变。
2. 从种子像素出发，按方向序列上、右、下、左循环，臂长按 2, 2, 4, 4, 6, 6, ... 递增，绘制蓝(1)色螺旋。每步尝试绘制一个像素：
   - 若目标像素在网格外：跳过（不绘制但步数计数器仍推进）。
   - 若目标像素是背景(0)：绘制蓝(1)。
   - 若目标像素是红(2)障碍：停止整条螺旋（不绘制该像素）。
   - 若目标像素是灰(5)墙段：不绘制该像素。沿当前前进方向找到该连续墙段的完整范围。在墙段面向螺旋来源方向的一侧（近侧），绘制蓝(1)色像素覆盖整个墙段长度对应的近侧行/列（仅覆盖背景像素）。然后从墙段的每个开口端（即墙段端点外侧的第一个背景像素位置），启动一条新的子螺旋。
3. 子螺旋规则：子螺旋从开口位置出发，方向序列与父螺旋相同（上、右、下、左），但起始方向为父螺旋碰撞时的前进方向。臂长计数器继承父螺旋碰撞时的当前臂长值，继续按 +2 递增。子螺旋用绿(3)色绘制（区别于父螺旋的蓝(1)）。子螺旋遵循相同的碰撞规则，但子螺旋碰墙段时不再分裂（只有父螺旋分裂）。
4. 所有螺旋绘制的像素不覆盖已有的非背景像素（墙段、障碍、先前螺旋的像素）。当螺旋的当前臂上所有剩余步都无法绘制时（全在网格外或全被占据），该螺旋终止。

**关键洞察**：螺旋的递增步长意味着碰撞发生在不同的臂长阶段时，子螺旋的起始臂长不同，从而产生不同大小的子螺旋图案。求解者需要同时追踪螺旋的几何轨迹和步长计数器的状态，才能确定分裂后的子螺旋形态。墙段的位置不仅阻断了路径，还通过开口位置决定了子螺旋的起点和大小。
