## 新题 4：棋盘奇偶驱动的对称补全分支

**组合逻辑**：[奇偶性选色](创新：奇偶性不选颜色而是选对称操作类型) + [对称补全](创新：同一网格中不同位置的遮罩用不同对称操作补全) + [重涂色](创新：补全后的像素颜色由底层棋盘奇偶决定)

**来源原语**：奇偶性选色/棋盘格图案(5e6bbc0b)，对称补全/遮罩像素/八重对称轨道(929ab4e9)，补全/对称图案/完整图案推断缺失(72322fa7)，重涂色(b94a9452)

**依赖链**：网格底层有隐式棋盘奇偶（由像素坐标 (r+c) 的奇偶性决定）。散布的对称图案部分被遮罩。每个遮罩像素所在位置的棋盘奇偶决定使用哪种对称操作来推断其应有的颜色：偶位置用水平轴反射，奇位置用垂直轴反射。补全后，所有新填入的像素再根据其自身位置的棋盘奇偶做最终着色调整。

在隐式棋盘奇偶场中，用位置奇偶决定的对称操作补全被遮罩的图案像素，再按奇偶对补全像素做最终重涂色。

**输入结构**：约 15x15 的黑(0)背景网格。包含 2~3 个完整的小型对称图案（每个约 3x3 至 5x5），由红(2)或蓝(1)像素构成，每个图案同时具有水平和垂直对称性。另有 3~4 个相同图案的不完整副本，其中若干像素被替换为灰(5)遮罩像素。完整图案和不完整图案散布在网格各处，互不重叠，间距至少 2 像素。每个不完整图案的中心像素保留（未遮罩），可用于识别它对应哪个完整图案。生成约束：每个不完整图案的遮罩位置经特定设计，使得仅用水平反射或仅用垂直反射中的任一种都无法补全所有遮罩——必须根据每个遮罩像素的棋盘奇偶位置选择不同的反射轴。

**规则**：
1. 保留所有完整图案像素和不完整图案中的非遮罩像素不变。
2. 对每个不完整图案，根据其中心像素颜色找到对应的完整图案作为参考。
3. 对每个遮罩像素，计算其全局坐标 (r, c) 的奇偶性 P = (r + c) mod 2：
   - P = 0（偶）：通过水平轴反射（以图案中心行为轴），找到该遮罩像素在图案内的对称位置，用该位置的颜色填充遮罩。
   - P = 1（奇）：通过垂直轴反射（以图案中心列为轴），找到该遮罩像素在图案内的对称位置，用该位置的颜色填充遮罩。
4. 若反射对称位置本身也是遮罩，则改用另一种反射轴。若两个对称位置都是遮罩，则使用完整参考图案中对应位置的颜色。
5. 补全完成后，对所有新填入的像素（原为遮罩的位置）做最终着色：若该像素全局坐标满足 (r + c) mod 2 = 0，颜色不变；若 (r + c) mod 2 = 1，则红(2)变为橙(7)，蓝(1)变为青(8)。

**关键洞察**：棋盘奇偶在这道题中扮演双重角色——既决定用哪种对称操作来推断缺失像素的值，又决定推断完成后是否需要重涂色。求解者必须先发现隐式的棋盘奇偶场，然后理解它对补全操作和着色操作的两种不同影响。仅看单个示例可能无法区分"所有遮罩都用同一种反射"和"按奇偶选择反射"这两种假设。
