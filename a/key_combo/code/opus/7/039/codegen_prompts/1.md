## 新题 1：缺口框级联重力灌注

**组合逻辑**：[洪泛填充] + [缺口定射线向](创新：射线受重力约束转为下落流) → [重力下落] + [溢出扩散](创新：灌注色在穿越每个框时交替) → [交替变色]

**来源原语**：洪泛填充/缺口矩形框/缺口定射线向(292dd178)，重力下落/溢出扩散/架子/级联分支/碰撞停止(36a08778)，交替变色(af726779)

**依赖链**：缺口方向决定灌注流的初始射出方向；射出后流体受重力向下运动，遇到架子则沿架子顶面扩展并从两端溢出；溢出流继续下落，若从另一个框的缺口进入则灌满该框并再次射出；每穿越一个框，填充色在红(2)和蓝(1)之间交替。缺口朝向、架子位置、框的垂直排布共同决定灌注路径和颜色分配。

从顶部灌注框开始，流体经缺口射出后在重力作用下沿架子级联向下传播，每穿过一个新框交替变色。

**输入结构**：约 20x20 的黑(0)背景网格。包含 3~5 个灰(5)色边框的矩形框（边框宽 1 像素，内部 2x2 至 4x4 不等），每个框的边框上恰好缺失一个非角落像素作为缺口。最顶部的框的内部已填充红(2)。框之间散布若干橙(7)色水平线段作为架子（长 3~6 像素，厚 1 像素）。各框和架子互不接触，垂直方向上有间隔。生成约束：最顶部框的缺口必须朝下或朝左/右使得射出后的流体路径能在重力作用下到达至少一个架子或另一个框的缺口；每个框的缺口不在角落位置。

**规则**：
1. 保留所有灰(5)框边框和橙(7)架子像素不变。
2. 从已填充的顶部框开始处理。该框内部颜色为当前灌注色（红(2)）。
3. 从当前框的缺口像素出发，沿缺口朝外方向绘制一条与灌注色同色的射线，直到碰到非背景像素或网格边界停止（不覆盖终点像素）。
4. 射线终点之后，流体转为重力模式：从射线末端的正下方逐格向下绘制灌注色像素，直到碰到非背景像素或网格底部。
5. 若下落流碰到架子顶面，则沿架子顶面的整个跨度（架子正上方一行，从架子左端到右端）绘制灌注色像素。然后从架子左端左侧一格和右端右侧一格两个位置各自重新开始向下执行步骤 4。
6. 若下落流碰到某个框的缺口像素，则灌注色切换（红(2)变蓝(1)，蓝(1)变红(2)），用新灌注色填充该框的全部内部区域，然后从该框的缺口重新执行步骤 3。
7. 若下落流碰到框的非缺口边框像素或网格底部，该分支终止。
8. 多个分支独立执行。若两条不同分支的流体到达同一个空白像素，先到达的分支（处理顺序：从上到下、从左到右扫描各框）保留其颜色。

**关键洞察**：框的缺口朝向决定了射线方向，但射线之后的运动由重力接管而非继续沿射线方向——这意味着水平缺口射出的流体最终也会转向下落，与垂直射出的流体汇入同一套架子级联逻辑。必须追踪完整的级联路径才能确定每个框的填充颜色。
