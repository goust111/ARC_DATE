## 新题 7：视线匹配编码帧外推速度

**组合逻辑**：[外推](创新：运动速度不由帧间差直接读取，而由视线间距编码) + [视线匹配](创新：匹配对象不是路径端点与标记，而是帧内精灵与帧外标记) + [间距编码尾长](创新：间距不编码重涂长度而是编码运动步幅) + [匀速运动延续]

**来源原语**：外推/帧序列/内部精灵/匀速运动延续/等间距排列(ba1aa698)，射线延伸/视线匹配/间距编码尾长(696d4842)

**依赖链**：输入包含一排共享边框的帧序列和若干帧外标记像素。每个帧内有一个精灵体在相同的行位置。帧外标记像素与最后一帧的精灵体有水平或垂直视线关系，标记到精灵体的间距编码了该精灵体在帧间的垂直运动步幅。求解者需先通过视线匹配读取步幅，再回看帧序列验证该步幅与帧间位移一致，最后外推下一帧的精灵体位置。

通过帧外标记像素与精灵体的视线间距解码运动步幅，外推精灵体在下一帧中的位置。

**输入结构**：约 8x25 的黑(0)背景网格（宽大于高）。灰(5)色边框将网格水平分为 3~4 个等宽帧（每帧约 8x5 至 8x6，帧间共享一列灰色边框），帧内填充黑(0)。每帧内有一个红(2)色小精灵体（2x2 或 L 形，3~4 像素），在各帧中保持相同的列位置但行位置逐帧变化（每帧向下移动 d 行，d 为一个正整数 1~3）。在最后一帧的右侧外部（不在任何帧内），有一个黄(4)色单像素标记，与最后一帧内的精灵体的某个像素在同一行上（水平视线对齐），标记与精灵体最右侧像素之间隔着 d 个背景像素（d 即为运动步幅）。生成约束：精灵体在各帧的位移恰好等于标记与精灵体的视线间距；精灵体在外推的下一帧中不会超出帧的垂直范围。

**规则**：
1. 找到黄(4)标记像素和最后一帧内与标记同行的精灵体像素，计算它们之间的水平背景间距 d（不含标记和精灵体像素本身）。
2. 验证：各帧中精灵体的行位置逐帧向下偏移量均为 d（这一步求解者自行验证，不需要在输出中体现）。
3. 构建输出：一个独立帧（与输入帧等大），灰(5)边框，黑(0)填充。将精灵体放入该帧中，列位置与输入帧相同，行位置为最后一帧中精灵体的行位置再向下偏移 d。
4. 输出仅为这一个独立帧，不包含输入的帧序列和标记。

**关键洞察**：步幅信息被同时编码在两个位置——帧间精灵体的位移差和帧外标记的视线间距。仅看帧序列可以直接读出位移差，但标记的存在引入了一个看似多余的冗余编码。真正的非显然规则是：在某些示例中帧数可能只有 2（仅一个位移差），此时不对比多个帧间差就无法确信步幅是恒定的，而视线间距提供了独立确认。求解者需要对比多个示例才能发现视线间距与运动步幅的编码关系。
