## 新题 2：转置触发区域填充

**组合逻辑**：[镜像/reflect + 沿主对角线转置](保留) + [区域填充/flood_fill](创新：填充由转置后种子像素的新位置触发) + [连通分量检测/connected_component_detection]（标注：转置已有，区域填充已有，创新在于转置改变种子与封闭区域的从属关系从而决定哪些区域被填充）

**来源原语**：镜像/reflect + 对角对称/diagonal_symmetry + 沿主对角线转置/transpose_along_diagonal（9dfd6313）、区域填充/flood_fill（1190bc91）、连通分量检测/connected_component_detection（12eac192）、分隔线/separator_line（e3fe1151）

**依赖链**：灰色墙壁将网格划分为多个封闭区域，种子像素位于部分区域内 → 转置操作同时改变墙壁结构和种子位置 → 转置后种子落入的新封闭区域被该种子颜色填充 → 未获得种子的区域保持背景色

将方阵沿主对角线转置后，种子像素落入的封闭区域被该种子颜色填充，未获种子的区域保持空白。

**输入结构**：一个 N x N 的方阵（N 约 9~13），背景为黑(0)。主对角线上所有像素为灰(5)，此外灰色还形成若干条单像素宽的水平或垂直墙壁线段（墙壁端点连接到主对角线或网格边缘），将网格内部划分为多个封闭的 4-连通背景区域。灰色墙壁关于主对角线不对称（转置后墙壁结构会改变，产生不同的区域划分）。散布 3~5 个单像素的彩色种子（使用红(2)、蓝(1)、绿(3)等不同颜色），每个种子位于某个封闭区域内的背景像素上。生成约束：转置后每个种子的新坐标不落在灰色像素上；转置后形成的新封闭区域中，至少一个区域不含任何种子，至少一个区域恰含一个种子；每个新区域至多获得一个种子。

**规则**：
1. 对整个 N x N 网格执行主对角线转置：将坐标 (r, c) 的像素移到 (c, r)。
2. 转置后，灰色结构形成新的墙壁布局，将网格分割为新的 4-连通背景封闭区域。
3. 对每个转置后位于背景像素上的彩色种子，用该种子的颜色对其所在封闭区域执行 4-连通 flood fill（仅覆盖黑(0)像素，灰色墙壁不被覆盖）。
4. 转置后没有种子落入的封闭区域保持黑(0)不变。
5. 若转置后某种子恰好落在灰色墙壁像素上（生成约束排除此情况，但规则完备性要求说明），该种子消失，不触发填充。

**关键洞察**：转置不仅是几何对称操作（如 9dfd6313 中的简单矩阵转置），还通过同时改变墙壁拓扑和种子位置来重新分配"谁填充谁"——同一种子在转置前后可能属于完全不同形状和大小的区域，需要从多个示例中归纳出转置而非其他变换。
