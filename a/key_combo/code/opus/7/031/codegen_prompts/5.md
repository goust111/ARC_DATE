## 新题 5：嵌套层拆解为印章模板

**组合逻辑**：[嵌套矩形层/nested_rect_layer + 嵌套层次/nesting_hierarchy](创新：剥离出的每层环形形状作为独立印章模板) + [印章覆盖/stamp_overlay + 空位接受印章/empty_accepts_stamp](创新：槽位通过内部尺寸匹配对应层) + [形状匹配/shape_matching]

**来源原语**：嵌套矩形层/nested_rect_layer + 嵌套层次/nesting_hierarchy + 颜色序列逆转/color_sequence_reversed（8dae5dfc）、印章覆盖/stamp_overlay + 空位接受印章/empty_accepts_stamp + 支撑签名匹配/support_match（e5062a87）、裁剪/crop（1cf80156）、实心矩形/solid_rectangle（23b5c85d）

**依赖链**：逐层剥离嵌套矩形 → 每层产生一个环形掩码（最内层为实心矩形）和对应颜色 → 灰色空框的内部尺寸与某层外部尺寸匹配 → 将该层的环形掩码以该层颜色填入对应灰色框内

逐层剥离嵌套矩形得到不同尺寸的环形掩码，每层颜色填入网格中内部尺寸匹配的灰色空矩形框内。

**输入结构**：约 20x20 的网格，背景为黑(0)。网格左侧有一个嵌套矩形结构，由外到内依次为不同颜色的均匀一像素宽环形层（如最外层红(2)环、中层蓝(1)环、最内层绿(3)实心矩形），共 3~4 层。嵌套矩形各层的外部尺寸分别为例如 9x7、7x5、5x3、3x1（每层向内缩一像素）。网格右侧散布 3~4 个灰(5)单像素宽空心矩形框（内部为黑色背景），灰色框之间互不重叠。每个灰色框的内部空间尺寸（高度 x 宽度）恰好等于嵌套矩形中某一层的外部尺寸。生成约束：灰色框数量等于嵌套矩形层数；每种尺寸恰好出现一个灰色框，形成一一对应。

**规则**：
1. 从嵌套矩形的最外层开始逐层剥离：第 k 层的掩码 = 第 k 层外边界矩形区域减去第 k+1 层外边界矩形区域（像素差集），形成一个一像素宽的环形。最内层为实心矩形。记录每层颜色和外部尺寸（高 x 宽）。
2. 对每个灰色空心框，测量其内部空间的高度和宽度。
3. 将每个灰色框的内部尺寸与嵌套矩形各层的外部尺寸匹配。
4. 在匹配的灰色框内部，以对应层的颜色绘制该层的掩码（环形或实心矩形），居中于框内部空间（因尺寸恰好吻合，无需调整）。灰色框线保留不变。
5. 嵌套矩形源结构保留不变。

**关键洞察**：嵌套矩形不是在原位反转颜色顺序（如 8dae5dfc），而是被拆解为独立的几何模板，每个模板通过尺寸匹配寻找自己的目标槽位——空间嵌套关系被解构为尺寸配对关系。需要同时理解剥离机制和尺寸匹配规则才能求解。
