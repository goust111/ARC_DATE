## 新题 4：轮廓路径方向决定对称补全轴

**组合逻辑**：[滑动/slide + 轮廓邻接/contour_adjacency](已有) + [对称补全/symmetry_completion](已有) → 创新关系：轮廓路径的净方向不用于定位标记终点，而用于编码对称轴选择

**来源原语**：滑动/slide、标记像素/marker_pixel、障碍轮廓/obstacle_contour、轮廓邻接/contour_adjacency、最长贴边路径/longest_adjacent_path（来自 97c75046）；对称补全/symmetry_completion、对称图案/symmetric_pattern、标记矩形/marker_rectangle、双轴反射对称/biaxial_reflection_symmetry、标记遮挡区域/marker_occludes_region（来自 0934a4d8）

**依赖链**：标记像素沿视线滑向障碍物 → 沿轮廓选最长贴边路径 → 计算起点到终点的净位移向量 → 净位移主方向（水平/垂直）决定对称补全使用的反射轴 → 用该轴的反射对称恢复被遮挡的像素。删除轮廓滑动则对称轴未知；删除对称补全则滑动无目的。

一个标记像素沿障碍物轮廓滑行后的净位移方向，决定用哪条反射轴来补全被遮挡区域的图案。

**输入结构**：约 17x17 的网格，背景黑(0)。网格大部分区域被一个具有双轴反射对称性的彩色图案（使用红(2)、蓝(1)、绿(3)等颜色）覆盖，但图案的某个区域被橙(7)单色矩形块遮挡（遮挡区域位于图案的一侧，使得仅用一条对称轴即可恢复）。图案外侧（靠近网格边缘）有一个灰(5)连通障碍物区域（4-连通，约 8-15 像素，形状不规则）。距障碍物若干像素处有一个绿(3)标记像素，与障碍物恰好有一条水平或垂直的视线（视线上无其他非背景像素阻挡）。生成约束：轮廓路径的净位移在水平和垂直分量上不相等（不出现 45 度歧义）；遮挡区域恰好需要与净位移主方向对应的反射轴来恢复。

**规则**：
1. 从绿(3)标记像素出发，沿其唯一的水平或垂直视线滑向灰(5)障碍物，停在障碍物前最后一个背景像素。
2. 从该停留点出发，尝试两个与视线方向成 45 度的对角转向，选择能沿障碍物外轮廓保持 4-邻接的最长路径方向，沿该方向走到路径尽头。
3. 计算标记像素的起点到路径终点的净位移向量 (dr, dc)。取主方向：若 |dc| > |dr| 则主方向为水平；若 |dr| > |dc| 则主方向为垂直。
4. 主方向为水平 → 使用垂直反射轴补全图案（将可见侧左右翻转到橙(7)遮挡处）。主方向为垂直 → 使用水平反射轴补全图案（将可见侧上下翻转到遮挡处）。
5. 输出中橙(7)像素被替换为反射对应位置的颜色，其余部分不变。标记像素和障碍物保持原位不动（滑动仅用于计算，不改变网格内容）。

**关键洞察**：轮廓路径的几何形态不是用来放置标记的终点位置（不同于源题 97c75046），而是一个方向信号——其净位移的主分量编码了应当使用哪条对称轴来恢复被遮挡的图案。必须对比多个示例才能确定"水平净位移 → 垂直轴"还是反过来。
