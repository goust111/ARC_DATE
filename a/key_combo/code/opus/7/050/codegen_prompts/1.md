## 新题 1：面板差异驱动沟槽分区着色

**组合逻辑**：[逐像素比较](已有) + [分区涂色](已有) + [边界框内外分色](创新：由比较结果动态决定边界框范围，而非由原始输入直接决定)

**来源原语**：逐像素比较/pixel_comparison、面板/panel、分隔列/separator_col、面板对齐/panel_align、差异分类着色/diff_class_color（来自 d47aa2ff）；分区涂色/zone_coloring、块阵列/block_array、网格沟槽/lattice_gutter、边界框/bounding_box、内部与外部沟槽/interior_vs_exterior_gutter、按边界框内外分色/color_by_bounding_box_membership（来自 137f0df0）

**依赖链**：逐像素比较决定哪些块存活及其颜色 → 存活块的集合重新定义边界框 → 边界框划分沟槽的内外归属 → 沟槽像素据此着色。删除比较步骤则边界框无法确定；删除沟槽着色则比较结果无后续用途。

将两块阵列面板逐块比较后重新着色，再根据存活块的边界框范围对沟槽间隙进行内外分区涂色。

**输入结构**：约 12x21 的网格。背景黑(0)。中央有一列宽度为 1 的绿(3)分隔列，将网格分为左右两个等宽面板（各约 12x10）。每个面板内有一个由灰(5) 2x2 方块组成的规则矩阵（例如 4 行 3 列方块），方块之间有 1 像素宽的沟槽间隙，沟槽为背景色。两个面板的方块矩阵行列结构完全一致，但部分位置的方块缺失（被背景色替代）——且两面板缺失位置不完全相同。生成约束：至少有 2 个方块位置仅在一个面板中出现，至少有 1 个方块在两个面板中都存在，且比较后存活块的边界框严格小于完整矩阵的边界框（即有些外围位置在比较后消失了）。

**规则**：
1. 移除绿(3)分隔列，将左右面板按位置对齐，逐 2x2 方块比较：
   - 该位置两面板都有方块 → 保留灰(5)。
   - 该位置仅左面板有方块 → 重涂为红(2)。
   - 该位置仅右面板有方块 → 重涂为蓝(1)。
   - 该位置两面板都无方块 → 保持黑(0)。
2. 输出为单个面板大小的网格，包含上述重涂后的方块。
3. 计算所有存活方块（灰、红、蓝）的最小外接矩形（边界框）。
4. 对沟槽像素（方块行带之间的水平空行、方块列带之间的垂直空列）着色：位于边界框内部的沟槽像素涂黄(4)；位于边界框外部、但与内部沟槽同行或同列延伸出去的沟槽像素涂橙(7)。
5. 不属于任何沟槽行带或列带的背景像素保持黑(0)。

**关键洞察**：面板比较不仅改变方块颜色，更通过消除某些外围方块收缩了边界框；沟槽的内外归属随比较结果动态变化，而非由原始矩阵几何静态决定。
