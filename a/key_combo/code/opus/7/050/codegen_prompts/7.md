## 新题 7：面板比较生成射线源

**组合逻辑**：[逐像素比较/pixel_comparison](已有) + [射线延伸/ray_extend](已有) + [印章覆盖/stamp_overlay](已有) → 创新关系：比较结果不仅分类像素颜色，更在功能上区分"活性射线源"与"惰性保留点"

**来源原语**：逐像素比较/pixel_comparison、面板/panel、分隔列/separator_col、面板对齐/panel_align、差异分类着色/diff_class_color（来自 d47aa2ff）；射线延伸/ray_extend、贯穿条/full_span_bar、控制像素/control_pixel、接触标记/contact_marker、投射/perpendicular_cast、命中处印标记/stamp_at_hit（来自 ecdecbb3）

**依赖链**：面板逐像素比较 → 差异像素（仅在一个面板中出现的）变为控制像素，共有像素变为惰性标记 → 控制像素向贯穿条投射射线 → 射线命中贯穿条处印章 3x3 标记。删除比较则无法区分控制像素和惰性像素；删除射线/印章则比较结果无后续变换。

两面板的前景像素经比较后，仅一方独有的像素变为射线源向贯穿条投射，命中处印章标记；双方共有的像素保持惰性不发射。

**输入结构**：约 12x23 的网格，背景黑(0)。一列宽为 1 的绿(3)分隔列居中，将网格分为左右两个等宽面板（各约 12x11）。每个面板内包含 1-2 根灰(5)水平贯穿条（横跨面板全宽），以及 3-6 个散布的孤立前景像素（颜色为橙(7)，不在贯穿条上）。两面板的贯穿条位置（行号）完全一致，但前景像素的分布不同：部分像素在两面板的同一位置都出现，部分仅在一个面板中出现。生成约束：至少 2 个像素为一方独有（产生射线源），至少 1 个像素为双方共有（保持惰性）；独有像素所在列上有贯穿条可供射线命中。

**规则**：
1. 移除绿(3)分隔列，将两面板按位置对齐，逐像素比较（仅比较非灰、非黑像素的位置）：
   - 该位置两面板都有橙(7)像素 → 在合并输出中标记为黄(4)（惰性：不发射射线）。
   - 该位置仅左面板有像素 → 标记为红(2)（活性控制像素）。
   - 该位置仅右面板有像素 → 标记为蓝(1)（活性控制像素）。
2. 合并为单面板输出。灰(5)贯穿条保留。
3. 对每个活性控制像素（红或蓝），沿垂直方向（贯穿条为水平时）向上下两侧投射射线，射线以该控制像素的颜色（红或蓝）绘制，遇到贯穿条时停止（射线终点为贯穿条前最后一个像素）。
4. 在每个射线-贯穿条命中点处，以灰(5)印章一个 3x3 方块（居中于命中点所在的贯穿条像素），然后将 3x3 方块的中心像素恢复为控制像素的颜色（红或蓝）。3x3 方块超出网格的部分裁剪。
5. 黄(4)惰性像素保持原位，不产生任何射线或印章。
6. 若两条射线在同一贯穿条像素处重合（来自不同控制像素），后处理的射线的 3x3 印章覆盖先处理的。处理顺序：按控制像素位置从上到下、从左到右。

**关键洞察**：面板比较在功能上不只是分类着色（源题 d47aa2ff 的终点），而是变成了射线延伸（源题 ecdecbb3）的前置筛选器——它将像素分为"活性"和"惰性"两个功能类别，只有差异像素才获得射线发射能力。
