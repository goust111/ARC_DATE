## 新题 3：射线延伸雕刻封闭口袋并按面积填色

**组合逻辑**：[射线延伸 + 标记排除](已有) → [封闭区域检测](创新：延伸条纹和原矩形共同构成围栏，从而在背景中切割出封闭区域) → [面积决定填充色](已有)

**来源原语**：射线延伸(ray_extend, 来自 9def23fe), 标记排除对应行列(marker_excludes_row_col, 来自 9def23fe), 控制像素(control_pixel, 来自 9def23fe), 洪泛填充(flood_fill, 来自 c0f76784), 封闭区域(enclosed_region, 来自 c0f76784), 面积决定填充色(area_determines_fill_color, 来自 c0f76784)

**依赖链**：标记像素决定哪些行/列的延伸被抑制 → 延伸条纹与原矩形、网格边缘共同构成围栏结构 → 围栏将黑色背景切割为若干封闭口袋和连通外部的开放区域 → 封闭口袋按面积涂色。每个标记像素的存在或缺失会改变延伸格局，进而改变口袋的数量、形状和面积，产生级联效应。

在一个实心矩形的四个方向上发射延伸条纹（标记像素阻断特定行列），延伸条纹与矩形和网格边缘围合出封闭的背景口袋，再按口袋面积填充不同颜色。

**输入结构**：约 15x15 的黑(0)背景网格。网格中央偏位有一个蓝(1)实心矩形（约 3x3 到 5x5），矩形四周留有足够的黑色背景空间（每侧至少 4 格到网格边缘）。若干橙(7)标记像素分布在矩形的四个侧边带区域中（侧边带定义：矩形上方的区域中与矩形列范围对齐的列、矩形下方同理、矩形左侧与矩形行范围对齐的行、矩形右侧同理）。每个标记像素恰好位于某个侧边带内。生成约束：标记像素的分布使得延伸后至少产生 2 个封闭口袋和至少 1 个非封闭背景区域；封闭口袋的面积至少涵盖两种不同的大小范围；矩形不紧贴网格任何边缘。

**规则**：
1. 从蓝(1)矩形的每条边向外延伸条纹：向上延伸矩形的每一列直到网格上边缘；向下延伸每一列直到下边缘；向左延伸每一行直到左边缘；向右延伸每一行直到右边缘。延伸的像素着蓝(1)色。
2. 对每个方向，检查该侧边带中的橙(7)标记像素。若某标记像素位于矩形上方且在矩形的第 j 列上，则抑制向上方向第 j 列的延伸（该列不画延伸条纹）。下方、左方、右方类推——标记抑制其所在侧边带方向上对应行或列的延伸。
3. 延伸完成后（原矩形 + 延伸条纹 + 网格边缘共同构成障碍），识别所有封闭的黑(0)背景区域：4-连通的黑色像素组，其所有像素的正交邻居都是蓝(1)像素或网格边界外（即不存在通过黑色路径连到其他非封闭区域的通路）。
4. 对每个封闭的黑色区域，按面积填色：1-4 个像素 → 红(2)；5-9 个像素 → 绿(3)；10 个及以上像素 → 黄(4)。
5. 非封闭的黑色背景保持黑(0)。橙(7)标记像素保持不变。原矩形和延伸条纹保持蓝(1)。

**关键洞察**：每个标记像素的效果是非局部的——它阻断一条延伸条纹，可能导致两个原本独立的小口袋合并为一个大口袋（从而改变颜色），或者使一个封闭口袋打开一个缺口变为非封闭区域（从而不填色）。标记像素塑造的是背景的拓扑结构，而非简单的局部排除。
