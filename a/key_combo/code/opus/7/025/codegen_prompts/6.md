## 新题 6：标记方位编码金字塔方向与交替色

**组合逻辑**：[展开/交替填色/金字塔](已有) + [旋转](已有，但旋转角度不再是固定的 90/180/270 而是由标记方位编码) + [控制像素](创新：单个标记同时编码方向和颜色两个参数)

**来源原语**：展开(expand, 来自 db3e9e38), 交替填色(alternating_fill, 来自 db3e9e38), 中心对称展开(center_expand, 来自 db3e9e38), 奇偶决定颜色(parity_determines_color, 来自 db3e9e38), 旋转(rotate, 来自 46442a0e), 控制像素(control_pixel, 来自 9def23fe), 标记像素(marker_pixel, 来自 32597951)

**依赖链**：线段确定金字塔的高度和轴心 → 标记像素的空间方位（相对于线段的上/下/左/右）编码金字塔的生长方向 → 标记像素的颜色作为交替填色中的第二种颜色 → 金字塔在对应方向上展开，奇偶距离决定使用线段色还是标记色。单个标记像素同时承载方向信息和颜色信息，两者缺一不可。

从一条彩色线段生成居中交替色金字塔，金字塔的展开方向由标记像素的方位决定，交替色由标记像素的颜色决定。

**输入结构**：约 12x12 的黑(0)背景网格。网格中有一条蓝(1)的垂直或水平线段（长度 3-6 像素，4-连通，沿单行或单列排列）。网格中另有一个标记像素，颜色为红(2)、绿(3)、黄(4)、或橙(7)中的一种（与线段颜色不同且非黑非灰）。标记像素不与线段相邻，位于线段包围框的严格外部，且处于线段的四个方位之一：若线段为垂直，标记在线段正上方（同列且行号 < 线段最小行号 - 1）、正下方、正左方（同行范围且列号 < 线段列号 - 1）、或正右方其中之一；若线段为水平，类推。生成约束：线段与标记之间的空间足以容纳完整金字塔（从线段端部到网格边缘沿标记方向的距离 >= 线段长度）。

**规则**：
1. 识别线段：找到所有蓝(1)像素，确认它们构成一条直线段（同行或同列）。记线段颜色 C1 = 蓝(1)，长度 L，中心轴位置（若垂直线段则为其列号，若水平线段则为其行号）。
2. 识别标记像素：找到唯一的非黑非蓝像素，记其颜色 C2，位置 (mr, mc)。
3. 确定金字塔生长方向 D：
   - 垂直线段时：标记在线段上方 → D = 向上；下方 → D = 向下；左方 → D = 向左；右方 → D = 向右。
   - 水平线段时：标记在线段上方 → D = 向上；下方 → D = 向下；左方 → D = 向左；右方 → D = 向右。
4. 构建黑(0)输出网格（与输入同尺寸）。
5. 以线段的一个端部作为金字塔尖端（选取靠近标记方向的那个端点），沿方向 D 逐步展开金字塔：
   - 第 k 步（k = 0, 1, ..., L-1）：在距离尖端 k 步的位置（沿 D 方向），画一条长度为 (2k+1) 的居中线段，垂直于 D 方向。
   - 该线段中每个像素的颜色由其到线段中心的距离 d 决定：d 为偶数 → C1；d 为奇数 → C2。
6. 标记像素在输出中保持其原色 C2。原线段位置被金字塔覆盖。

**关键洞察**：标记像素是一个双参数编码器——它的空间方位编码了旋转/生长方向（一个离散的四选一），它的颜色值编码了交替色（一个连续参数）。仅看一个示例时，求解者可能误以为方向是固定的或颜色是固定的；必须对比多个示例（标记在不同方位、不同颜色）才能归纳出这两条独立规则。
