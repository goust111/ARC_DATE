## 新题 5：桥接数编码环形色循环步数

**组合逻辑**：[连线/桥接](已有，但桥不再被新画而是作为已存在的输入结构) + [计数](已有) → [循环移色](已有，但循环步数由桥接数动态决定，且角位与边中反向循环)

**来源原语**：循环移色(color_cycle, 来自 46c35fc7), 角与边中分组(corner_side_group, 来自 46c35fc7), 反向循环(opposite_cycle, 来自 46c35fc7), 连线(draw_line, 来自 f3b10344), 桥接条(bridge_bar, 来自 f3b10344), 计数(counting, 来自 9af7a82c)

**依赖链**：识别网格中的 3x3 环和灰色桥接条 → 计算每个环连接了多少条桥 → 桥接数 N 直接作为该环的角位颜色顺时针循环步数和边中颜色逆时针循环步数。桥接拓扑决定循环幅度：同样的初始环，连 1 条桥旋转 1 步，连 3 条桥旋转 3 步，产生完全不同的色彩排列。

在包含多个彩色 3x3 环的网格中，环与环之间通过灰色桥连接；每个环根据其连接的桥数 N 进行 N 步色循环——角位顺时针、边中逆时针。

**输入结构**：约 12x12 的黑(0)背景网格。网格中有 3-5 个完整的 3x3 前景环（每个环由 8 个非黑像素围绕 1 个黑(0)中心组成，8 个像素使用 2-4 种不同的非黑颜色，具体颜色分配每个环各异）。环与环之间不直接相邻（任意两个环的像素距离至少 2 格）。某些环之间通过灰(5)桥连接：桥是宽度为 1 像素的水平或垂直线段，一端正交相邻于一个环的某个外围像素，另一端正交相邻于另一个环的某个外围像素。生成约束：每个环连接 0-3 条桥；至少有一个环连接 0 条桥（作为对照组不发生循环），至少有一个环连接 2 条及以上；桥不会交叉；每条桥恰好连接两个不同的环。

**规则**：
1. 识别所有 3x3 前景环：以黑(0)中心像素为锚点，检查其 8 个正交和对角邻居是否全为非黑像素，且这 8 个像素形成一个连通的环结构。
2. 识别所有灰(5)桥接条：4-连通的灰色线段，其两个端点各自正交相邻于不同环的外围像素。
3. 对每个环，计算与之相连的桥接条数量 N。
4. 对每个环执行 N 步双向循环：
   - 角位循环：将四个角位像素（左上、右上、右下、左下）的颜色沿顺时针方向循环移动 N 步。即左上的颜色移到顺时针第 N 个角位，其余类推。具体循环顺序为：左上 → 右上 → 右下 → 左下 → 左上...
   - 边中循环：将四个边中像素（上中、右中、下中、左中）的颜色沿逆时针方向循环移动 N 步。具体循环顺序为：上中 → 左中 → 下中 → 右中 → 上中...
5. N = 0 的环保持不变。
6. 灰(5)桥接条、黑(0)背景和黑(0)环中心保持不变。

**关键洞察**：桥接条承担双重功能——它定义了环之间的空间连通关系，同时其数量编码了每个环的颜色旋转参数。仅凭环的初始颜色无法确定输出（需要知道桥接数），仅凭桥接拓扑也无法确定输出（需要知道初始颜色）。求解者必须从多个示例中归纳出"桥接数 = 循环步数"这一隐蔽映射。
