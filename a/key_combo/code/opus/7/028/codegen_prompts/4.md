## 新题 4：弯折计数排序连线

**组合逻辑**：[计数](创新：弯折数不决定颜色，而决定对象在连线图中的排序位置) → [排序](创新：不是列的排列，而是对象的全序排列) → [连线](创新：连线拓扑由排序结果动态决定，非固定的行列对齐)

**来源原语**：计数 + 弯折数分类(e509e548)、排序 + 按计数升序排列(85b81ff1)、连线/描边(1bfc4729)

**依赖链**：检测每个图形的弯折数 → 按弯折数从少到多排序所有图形 → 按排序顺序将相邻排名的图形用直线段首尾相连，形成一条链 → 连线颜色由源端图形的弯折数决定。删除计数则无法排序；删除排序则连线无确定拓扑；删除连线则无输出变换。

统计散布图形的弯折数并按弯折数排序，然后按排序顺序用彩色线段依次连接，形成一条从弯折最少到最多的链。

**输入结构**：黑(0)背景网格，约 18x18。网格中有 5~7 个绿(3)色的 4-连通小图形（每个图形 4~8 像素，具有 1~4 个 L 形 2x2 弯折角）。各图形边界框互不重叠且间距至少 2 像素。每个图形的弯折数在输入图形集合中唯一（不存在两个图形弯折数相同的情况）。生成约束：图形在网格中的位置随机分布，不存在两个图形中心在同一行或同一列的情况（确保连线路径唯一）。

**规则**：
1. 检测所有绿(3)色 4-连通图形。对每个图形，扫描其像素掩码中所有 2x2 子块，统计恰好占据 L 形三像素的子块数量（即 2x2 子块中恰有 3 个前景像素的计数），此数为该图形的弯折数。
2. 按弯折数从小到大对所有图形排序。
3. 从排序后的第 1 个图形开始，依次连接到第 2 个、第 2 个到第 3 个，直到最后一个图形，形成一条链。每段连线的起点为源图形（弯折数较少者）边界框的中心像素（行列均取边界框中值，向下取整），终点为目标图形边界框的中心像素。
4. 每段连线绘制为两段直线段组成的直角折线：先从起点沿水平方向画到与终点同列的位置，再沿竖直方向画到终点。折线像素（含起点和终点）着色规则：弯折数 1→蓝(1)，弯折数 2→红(2)，弯折数 3→黄(4)，弯折数 4→灰(5)。每段折线使用源图形的弯折数对应颜色。
5. 原始绿(3)图形像素保持不变。若折线像素与绿(3)图形像素重合，绿(3)保留。若两段折线在同一像素重叠，弯折数较大的源图形对应的折线颜色优先。

**关键洞察**：图形的几何属性（弯折数）不是单纯的分类标签——它同时编码了连线的拓扑序和线段颜色。求解者必须发现弯折计数规则（需对比多个示例中不同弯折数图形被连接的顺序）、连线方向规则（先水平后竖直）和颜色映射规则，三者缺一不可。
