## 新题 2：字形门控弹射路径

**组合逻辑**：[射线延伸 + 边界反射](已有) → [解码指令](创新：字形不编码线段方向，而编码射线遇到字形时的转向指令) → [计数](创新：像素面积不决定颜色或线段参数，而决定射线物理行为) → [重涂色](创新：路径分割的区域面积决定涂色)

**来源原语**：射线延伸 + 边界反射(e179c5f4)、解码指令 + 字形指令(136b0064)、计数(e509e548)、重涂色(多题)

**依赖链**：射线从起点出发沿对角线弹射 → 遇到字形门时，字形的像素面积解码为转向指令，改变射线方向 → 射线继续弹射直到终止 → 路径将网格分为区域，较小区域被重涂色。删除弹射则路径无法延伸；删除字形解码则射线不受门控影响；删除面积计数则转向规则不确定；删除区域涂色则无最终输出变换。

对角弹射射线穿越网格，每经过一个字形门按其像素面积转向，最终路径封闭的较小区域被重涂色。

**输入结构**：黑(0)背景网格，约 15x15。网格底边有一个蓝(1)起点像素。网格内部散布 3~4 个灰(5)色的 3x3 字形门（每个字形是 3x3 边界框内的一个 4-连通灰色图形，像素面积分别为 3、4、5 中的某个值，各字形面积互不相同）。字形门之间不相邻，且不贴靠网格边缘。生成约束：射线从起点出发向右上方 45 度弹射时，其路径会依次穿过每个字形门的 3x3 边界框（即路径与每个字形的边界框至少有 1 个像素位置重合）；射线在经过所有字形门后最终从网格顶边射出。

**规则**：
1. 从蓝(1)起点像素出发，沿右上方 45 度对角线逐步延伸射线，每步行移 1 格、列移 1 格。遇到网格左右边界时水平方向反转（行方向不变），继续弹射。射线路径上的每个像素标记为蓝(1)。
2. 当射线的下一步将进入某个字形门的 3x3 边界框时，在进入点暂停，读取该字形的像素面积（3x3 框内灰色像素总数），按以下规则改变射线的行进方向：
   - 面积 3：射线穿过字形门不改变方向，继续原方向弹射。
   - 面积 4：射线方向顺时针旋转 90 度（例如原方向为右上变为右下）。
   - 面积 5：射线方向逆时针旋转 90 度（例如原方向为右上变为左上）。
3. 方向改变后，从字形门边界框的对侧边缘继续射线延伸。射线穿过字形门时，门内路径像素同样标记为蓝(1)，字形门的灰色像素保持不变。
4. 射线继续弹射（遇到网格边界仍反射），直到从网格的任意外边缘射出。
5. 射线路径将网格划分为若干连通区域（以路径像素和网格边缘为边界，4-连通判定）。计算每个区域的像素面积。将面积严格最小的那个区域中的所有黑(0)像素重涂为青(8)。若最小面积区域有多个且面积相同，全部涂为青(8)。

**关键洞察**：字形门的像素面积不是装饰属性而是物理指令——它直接改写射线的运动定律。求解者必须先识别出"面积→转向"的编码映射（需对比多个示例中不同面积字形对路径的影响），然后才能追踪完整路径并确定涂色区域。路径的最终形状是弹射物理与字形编码的涌现结果。

Paint yellow the background cells on the unobstructed shortest monotone corridor between two doorway frames.

Input structure
