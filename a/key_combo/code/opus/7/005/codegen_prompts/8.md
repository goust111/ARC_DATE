## 新题 8：对称补全激活隐藏列触发整列涂色与平铺

**组合逻辑**：[对称补全](已有原语) → [列激活判定](创新：补全后新增的前景像素可能激活之前无前景的列) → [含前景列整列涂色](已有原语) → [平铺](已有原语)（链式依赖：补全改变了列选择的输入，列选择改变了平铺的图案）

**来源原语**：对称补全(symmetry_completion) ← 3631a71a/47996f11；掩码像素(masked_pixel) ← 3631a71a；对称轨道(symmetry_orbit) ← 3631a71a；同轨道色填补损坏(orbit_mate_restores_damage) ← 3631a71a；平铺(tiling) ← f5b8619d；列选择(column_selection) ← f5b8619d；前景列(foreground_column) ← f5b8619d；含前景列整列涂色(fg_col_full_recolor) ← f5b8619d

**依赖链**：粉色掩码战略性地隐藏了某些列中仅有的前景像素。补全前，这些列看似纯背景列，不会被选中涂色。对称补全恢复了被隐藏的前景像素，使这些列"被激活"——从无前景列变为有前景列。激活后的列集合决定了涂色范围，涂色后的图案决定了平铺结果。删除补全步骤，部分列不被选中，输出图案不同；删除列涂色，平铺内容不同；删除平铺，输出尺寸不同。每一步的输出实质性改变下一步的输入。

先用左右对称补全恢复被粉色掩码隐藏的像素，再将所有含前景像素的列整列涂青，最后将结果 2x2 平铺输出。

**输入结构**：约 7x7 的网格，背景为黑(0)。网格具有关于垂直中轴的左右对称结构（列索引 j 和 W-1-j 的像素颜色应对称），但若干像素被粉(6)掩码替换，破坏了直接可见的对称性。非掩码的前景像素使用红(2)或绿(3)（不使用青(8)和粉(6)作为前景色）。关键生成约束：至少有一列，其所有前景像素都被粉色掩码覆盖——即该列在补全前看起来完全没有前景像素（只有黑(0)和粉(6)），但在对称补全后该列会出现前景像素。掩码像素只出现在网格的一半（例如仅在右半区），保证对称轨道伙伴中至少有一个是可见的非掩码前景色。

**规则**：
1. 识别粉(6)像素为掩码。网格关于垂直中轴具有左右镜像对称性。
2. 对每个粉(6)像素，找到其关于垂直中轴的镜像位置。将粉色像素替换为镜像位置上的颜色（该颜色必为非粉色的前景色或背景色）。
3. 补全后，检查每一列：若该列包含至少一个非背景(非 0)像素，则该列为"前景列"。
4. 在所有前景列中，将剩余的背景(0)像素涂为青(8)。前景像素保持不变。
5. 将步骤 4 的结果作为基本瓦片，进行 2x2 平铺：输出宽度 = 2 倍输入宽度，输出高度 = 2 倍输入高度，四个象限各放一份完整的瓦片副本。

**关键洞察**：粉色掩码的位置经过精心设计——它们恰好覆盖了某些列中仅有的前景像素。补全前这些列似乎是"空列"，补全后才暴露出前景，触发整列涂色。仅看补全前的网格会低估前景列的数量，导致涂色和平铺结果错误。需对比多个示例才能确认"先补全再选列"的顺序，而非"先选列再补全"。
