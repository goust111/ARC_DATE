## 新题 5：分隔层异或叠加生成滑动目标场

**组合逻辑**：[异或叠加/xor_overlay](已有) + [裁剪/crop + 分隔行](已有) → [滑动/sliding](创新：滑动目标由异或结果动态确定) + [行列对齐/row_column_alignment](已有) → [擦除/erase](已有)

**来源原语**：异或叠加/xor_overlay (99b1bc43), 分隔行/separator_row (99b1bc43), 前景掩码/foreground_mask (99b1bc43), 前景不一致处涂色/disagreement_cells_painted (99b1bc43), 滑动/sliding (ae3edfdc), 行列对齐/row_column_alignment (ae3edfdc), 压缩到标记旁/compress_to_adjacent_marker (ae3edfdc), 擦除/erase (ae3edfdc)

**依赖链**：移除分隔行对齐上下掩码 → 异或计算生成绿色目标像素 → 黄色标记各自找到行列对齐的唯一绿色像素 → 标记沿共享轴向绿色像素滑动至其邻接格 → 输出保留绿色和滑动后的黄色。两条源操作共享中间状态：异或结果既是"掩码比较的输出"又是"滑动的输入目标场"。

上下两层掩码经异或得到差异像素场，散落的标记沿行列向最近的差异像素滑动聚拢，形成差异点周围的标记簇。

**输入结构**：
- 黑(0)背景，约 14x22 网格（高度为偶数加一：2H+1 行）。
- 第 H+1 行（0 索引第 H 行）为一条灰(5)全宽分隔行，仅此行含灰色。
- 上半区（行 0 ~ H-1）：蓝(1)像素构成一个前景图案（4-连通，约 8~15 像素），其余为黑(0)。
- 下半区（行 H+1 ~ 2H）：红(2)像素构成另一个前景图案（4-连通，约 8~15 像素），其余为黑(0)。上下半区高度相同、宽度相同。
- 下半区中另有 3~6 个孤立黄(4)标记像素，分散在红色图案之外。
- 生成约束：上下两个掩码的前景对称差（异或）恰好产生 3~6 个像素，且每个黄色标记与恰好一个异或像素共享行或列（不可同时共享行和列）；不同黄色标记对应不同的异或像素；黄色标记与其对应异或像素之间路径上无其他前景像素阻挡。

**规则**：
1. 移除灰(5)分隔行，将上半区和下半区逐格对齐（上半区行 r 对应下半区行 r）。
2. 对齐后对每个位置做异或判断：若恰好一个半区在该位置有前景像素（蓝或红），则标记为绿(3)；若两个半区在该位置都有前景或都无前景，则标记为黑(0)。得到一个 H 行的异或结果网格。
3. 将黄(4)标记像素的位置映射到对齐后网格中（下半区行 r 映射为对齐后行 r）。
4. 对每个黄色标记，找到与其共享行或列的唯一绿色像素。沿该共享轴方向将黄色标记滑动到紧邻绿色像素的格位上（绿色像素与黄色标记之间更近的一侧）。
5. 输出为 H 行宽度不变的网格，包含绿(3)异或像素和滑动到位的黄(4)标记。其余位置为黑(0)。

**关键洞察**：黄色标记的滑动目标是异或运算动态生成的，而非输入中预设的固定锚点。求解者必须先心算出异或结果，才能判断标记应向何处移动；仅看标记和掩码的空间关系无法直接推断终点。
