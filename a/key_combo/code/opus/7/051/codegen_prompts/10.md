## 新题 10：十字模板匹配驱动的遮挡帧层序输出

**组合逻辑**：[局部模板匹配/local_template_match](已有) + [正交邻接/orthogonal_adjacency](已有) → [补全/reconstruct + 遮挡层序/occlusion_order](已有) → [排序/sorting](创新：输出排列由十字模板匹配数量调制)

**来源原语**：局部模板匹配/local_template_match (7e02026e), 正交邻接/orthogonal_adjacency (7e02026e), 十字图案/plus_pattern (7e02026e), 重涂色/recolor (7e02026e), 补全/reconstruct (68bc2e87), 空心矩形/hollow_rectangle (68bc2e87), 遮挡层序/occlusion_order (68bc2e87), 重叠定先后/overlap_determines (68bc2e87), 排序/sorting (68bc2e87)

**依赖链**：在多帧重叠的网格中检测黑色十字模板 → 统计每个帧内部（不含帧边本身）包含的完整十字数量 → 推断帧间遮挡层序 → 输出单列层序时，每种帧颜色的行数等于其包含的十字数量。模板匹配和层序推断独立进行但共同决定输出格式。

在多个重叠空心矩形帧的网格中，先推断帧的遮挡叠放顺序，同时统计每个帧内部包含多少个完整的黑色十字模板，输出层序列时每种颜色重复其十字计数行。

**输入结构**：
- 黑(0)背景，约 18x18 网格。
- 3~5 个不同颜色的一像素宽空心矩形帧相互重叠（颜色从红(2)、蓝(1)、绿(3)、黄(4)、青(8)中选取）。帧的重叠关系使得每对相邻层之间至少有一个可见的遮挡像素。
- 帧的内部区域（帧边框围起的空间，不含边框本身）中散布着一些黑(0)和品红(6)像素。黑色像素的一部分构成完整的十字模板（中心像素及其上下左右四个邻居均为黑色），其余黑色像素不构成完整十字。品红像素是"干扰填充"，不参与任何规则。
- 生成约束：每个帧内部至少包含 1 个完整十字模板，至多 3 个；帧内部的十字模板之间互不重叠；不同帧内部的十字数量互不相同；十字模板完全在某个帧的内部（不跨越帧边界），且对于同时被多个帧包围的区域，十字归属于最小（面积最小）的包围帧。

**规则**：
1. 对每种前景颜色，从可见像素推断其帧的完整边界框。
2. 利用重叠位置的可见颜色推断从底到顶的完整遮挡层序。
3. 对每个帧，确定其"独占内部区域"——被该帧包围但不被任何更小帧包围的像素集合。
4. 在每个帧的独占内部区域中，检测完整的十字模板：找到每个黑(0)像素，其上下左右四个邻居也是黑(0)的，该中心及其四邻居构成一个十字。统计该帧包含的十字数量 K。
5. 输出为单列网格，从底到顶列出每层帧的颜色：层序第 i 层（从底部层 0 开始）的帧颜色连续填充 K_i 行（K_i 为该帧的十字数量）。最终输出高度等于所有帧十字数量之和。

**关键洞察**：层序和十字计数是两条独立的推理线索，但它们在输出格式中交汇——层序决定颜色的排列方向，十字计数决定每种颜色的行数。求解者不能只推断层序而忽略十字计数（否则不知道每色占几行），也不能只数十字而忽略层序（否则不知道颜色排列方向）。
