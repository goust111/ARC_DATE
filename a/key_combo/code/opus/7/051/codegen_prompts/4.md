## 新题 4：射线滑动距离排序后逐一印章模板

**组合逻辑**：[滑动/sliding + 射线对齐 + 碰撞停止](已有) → [排序/sorting](创新：排序键是滑动距离) → [印章覆盖/stamp](创新：模板来自网格中的独立精灵图，颜色取自标记色)

**来源原语**：滑动/sliding (a48eeaf7), 射线对齐/ray_alignment (a48eeaf7), 碰撞停止/collision_stop (a48eeaf7), 填充块/filled_block (a48eeaf7), 排序/sorting (817e6c09/68bc2e87), 印章覆盖/stamp (22233c11), 精灵图/sprite (2546ccf6/8d5021e8), 擦除/erase (ae3edfdc)

**依赖链**：标记像素沿射线向锚块滑动 → 滑动距离被记录 → 距离决定印章顺序（远者先印、近者后印覆盖）→ 在终点位置用标记颜色印章模板精灵 → 后印覆盖先印。删除滑动则终点未知且距离缺失；删除排序则覆盖优先级错误；删除模板则无印章内容。

多个彩色标记沿射线向中心锚块滑动后，按滑动距离从远到近依次在终点位置印章同一个模板精灵（取各标记自身颜色），后印覆盖先印。

**输入结构**：
- 黑(0)背景，约 16x16 网格。
- 一个青(8)实心 2x2 方块位于网格中偏心位置（非正中央），作为锚块。
- 4~6 个孤立标记像素，每个颜色各异（从红(2)、蓝(1)、绿(3)、黄(4)、橙(7)、栗(9)中选取），每个标记与锚块的 2x2 区域共享同一行、同一列或 45 度对角线。标记与锚块之间有至少 3 格间距。
- 一个灰(5)模板精灵位于网格某角落（不与锚块共享行列或对角线），由 3~5 个 4-连通像素构成不规则形状，其边界框不超过 3x3。
- 生成约束：所有标记滑动到锚块邻接环后，以各自终点为中心放置 3x3 边界框时，边界框互相重叠至少 1 个像素（确保印章顺序影响最终可见像素）；模板精灵的边界框左上角作为锚点。

**规则**：
1. 对每个彩色标记像素，沿其与锚块共享的射线（行、列或 45 度对角线）向锚块方向滑动，停在紧邻锚块 2x2 区域的环形外圈对应格位上。记录每个标记的滑动距离 D（经过的格数）。
2. 将标记按 D 从大到小排列（距离最远的排在最前）。D 相同时按原始位置的阅读序（从上到下、从左到右）排列。
3. 按排好的顺序依次执行印章操作：以当前标记的终点位置为基准点（对应模板精灵边界框的中心），将模板精灵的形状绘制到网格上，颜色使用该标记自身的颜色（替换灰色）。后执行的印章覆盖先执行的。
4. 擦除模板精灵的原始灰(5)像素（设为黑(0)）。
5. 擦除所有标记像素的原始位置（设为黑(0)）。保留锚块和所有印章结果。

**关键洞察**：锚块周围的最终图案是多个同形状不同颜色的模板叠加，可见颜色由滑动距离排序后的覆盖优先级决定——距锚块最近的标记最后印章因而在最顶层。求解者必须同时推断出模板形状、滑动终点和距离排序三个要素。
