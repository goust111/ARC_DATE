## 新题 7：帧遮挡层序的奇偶筛选与选择性重建

**组合逻辑**：[补全/reconstruct + 遮挡层序/occlusion_order](已有) → [排序/sorting](已有) → [奇偶交替选择/alternating_parity_selection](创新：选择作用于层序而非空间排列) → [重涂色/recolor](已有) + [擦除/erase](已有)

**来源原语**：补全/reconstruct (68bc2e87), 空心矩形/hollow_rectangle (68bc2e87), 遮挡层序/occlusion_order (68bc2e87), 重叠定先后/overlap_determines (68bc2e87), 排序/sorting (68bc2e87/817e6c09), 奇偶交替选择/alternating_parity_selection (817e6c09), 重涂色/recolor (817e6c09), 擦除/erase (fe45cba4)

**依赖链**：重叠像素推断遮挡层序 → 层序定义从底到顶的编号 → 奇偶筛选保留偶数层帧 → 偶数层帧完整重建并统一重涂为灰色 → 奇数层帧全部擦除。层序判断是奇偶选择的前提；奇偶选择决定哪些帧存活；重建必须在擦除之后进行（否则被遮挡的偶数帧部分无法显示）。

从多个重叠的空心矩形帧中推断底到顶的叠放顺序，只保留偶数层（0, 2, 4...）的帧，将其完整重建并统一涂灰，擦除所有奇数层帧。

**输入结构**：
- 黑(0)背景，约 15x15 网格。
- 4~6 个不同颜色的一像素宽空心矩形帧相互重叠。每个帧的颜色唯一且从以下颜色中选取：红(2)、蓝(1)、绿(3)、黄(4)、青(8)、橙(7)。
- 帧之间存在部分重叠：在重叠像素处，只显示层序最高（最上层）帧的颜色。
- 每个帧的边界框可从其可见像素推断（即便部分边被遮挡，至少四条边中的每一条都有部分像素可见）。
- 生成约束：任意两个帧之间至少存在一个重叠像素可见较高层帧的颜色，使得完整的层序链可以通过传递推断唯一确定；帧的数量为偶数（确保输出非空）。

**规则**：
1. 对每种前景颜色，收集其所有可见像素的坐标，确定该颜色帧的边界框（最小行、最大行、最小列、最大列即为帧的四条边）。
2. 在所有重叠位置（多个帧的重建边界框都覆盖的像素），可见的颜色属于层序较高的帧。利用这些约束建立帧间的偏序关系，推导出唯一的从底（层 0）到顶的完整层序。
3. 对层序编号进行奇偶分组：偶数层（0, 2, 4, ...）保留，奇数层（1, 3, 5, ...）擦除。
4. 清空整个网格为黑(0)背景。
5. 按从底到顶的顺序，依次绘制保留的偶数层帧：将每个帧重建为其完整的一像素宽矩形边框，颜色统一涂为灰(5)。后绘制的帧在重叠位置覆盖先绘制的。

**关键洞察**：输入中的可见颜色同时编码了两层信息——帧的空间范围和帧间的遮挡关系。求解者必须先从局部遮挡推断全局层序，才能决定哪些帧是偶数层该保留；而保留帧的完整重建形态在输入中是看不到的（被奇数层帧遮挡的部分只有推断层序后才能还原）。
