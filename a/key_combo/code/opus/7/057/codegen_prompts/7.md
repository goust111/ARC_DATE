## 新题 7：最大框架内隐式原型驱动形状匹配

**组合逻辑**：[裁剪/crop] + [面积最大选取/largest_area_select] + [最大框决定裁切/largest_frame_crops](创新：裁切结果不是最终输出而是中间原型) → [形状匹配/shape_match] + [压缩/compress] + [旋转反射等价/rotation_reflection_eq] → [重涂色/recolor] + [擦除/erase]

**来源原语**：裁剪/crop、矩形框架/rect_frame、面积最大选取/largest_area_select、最大框决定裁切/largest_frame_crops（来自 fcb5c309）；形状匹配/shape_match、压缩/compress、原型对象/prototype_object、候选对象/candidate_object、旋转反射等价/rotation_reflection_eq、游程压缩后比较/run_length_compare（来自 bd14c3bf）；重涂色/recolor、擦除/erase

**依赖链**：在多个矩形框中找到面积最大者 → 裁剪出最大框内部内容作为原型 → 对每个候选对象进行游程压缩 → 将压缩后的候选掩码与原型掩码在旋转/反射下比较 → 匹配者重涂色、不匹配者擦除。删去框架选择则原型未知；删去压缩则拉伸变体无法匹配；删去匹配则裁切无后续意义。

从多个矩形框中选出面积最大的一个，提取其内部图形作为匹配原型，然后在框外的候选对象中筛选出与原型拓扑等价（允许旋转、反射和游程拉伸）的对象并重涂色，淘汰不匹配者。

**输入结构**：约 20x20 网格，黑(0) 背景。2~3 个灰(5) 单像素厚矩形框架（完整封闭的矩形环），面积各不相同。面积最大的框架内部包含一个红(2) 小型图形（3~6 像素的 4-连通图案，如 L 形、T 形或不规则形状）和黑(0) 背景；其他较小框架内部为纯黑(0) 或包含无关噪声像素（品红(6)，1~2 个）。框架外的网格区域散布着 4~6 个蓝(1) 候选对象，每个占 3~8 像素，部分候选对象是原型的旋转/反射/游程拉伸变体，部分不是。生成约束：最大框架面积严格大于次大框架面积；至少有 2 个匹配候选对象和 1 个不匹配候选对象。

**规则**：
1. 识别所有灰(5) 单像素厚矩形框架，计算每个框架的边界框面积（宽 x 高）。
2. 选出面积最大的框架。裁剪其内部区域（不含框架边界本身），得到一个子网格。
3. 在子网格中提取红(2) 像素构成的图案作为原型。将原型裁剪至其最小边界框，然后对其进行游程压缩：沿行方向折叠相邻的相同列内容，沿列方向折叠相邻的相同行内容，得到压缩后的原型掩码 M。
4. 对每个蓝(1) 候选对象：裁剪至最小边界框，执行同样的游程压缩，得到压缩掩码 C。
5. 将 C 与 M 在全部 8 种旋转/反射变换下逐一比较（二值掩码逐像素匹配）。若任一变换下 C 与 M 完全一致，则该候选匹配。
6. 匹配的候选对象重涂为绿(3)。不匹配的候选对象擦除为黑(0)。
7. 所有灰(5) 框架、框架内部内容（含红(2) 原型和品红(6) 噪声）保持不变。

**关键洞察**：原型不是显式给出的——它被编码在最大框架的内部结构中。解题者必须先执行"找最大框→裁切→提取原型"的空间推理，才能进行后续的拓扑匹配。框架的选择机制（面积最大）和匹配的比较机制（压缩+旋转反射）是两个独立的推理维度，必须同时正确才能得出输出。

Sort objects to top or bottom edge by whether their shape (up to rotation/flip) is shared.

Input structure:
- bg = most common color.
- Several multicolor connected components (8-connected) scattered across the grid.

Rule:
- Compute each object's canonical shape (binary mask, invariant to rotation and flip).
- Objects whose shape appears in two or more components → translate to TOP edge (row 0).
- Objects whose shape is unique → translate to BOTTOM edge (row H−h).
- Horizontal position (left column) is preserved; only vertical translation changes.

Key insight: The sorting criterion is shape frequency (rotation-invariant), not area — duplicated shapes go up, unique shapes go down.

<description>
Decode a block-grid image by swapping each sprite-coded cell with a solid cell and each blank cell with the sprite.

Input structure
The grid is partitioned by black separator rows and columns into equal-size
square blocks. Each block is either a copy of one two-color sprite or a
uniform blank block of the sprite's minority color; grey pixels are erased
cells that act as wildcards.

Rule
Infer the repeated sprite from fully visible mixed-color blocks. Replace a
block matching that sprite, ignoring grey erasures, with a solid block of
the sprite's majority color. Replace a uniform blank block with the sprite.
Separator rows and columns, including grey erasures on them, become black.

Key insight
The small sprite is a block-level code for one macro-cell state, and the
uniform minority-color block is the other state; the output renders the
opposite code in each macro-cell while cleaning erased pixels.
