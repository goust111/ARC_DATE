## 新题 2：杯形开口路由的链式灌注

**组合逻辑**：[填充/fill] + [开口朝向/opening_direction](创新：开口作为定向出口和定向入口的双重角色) → [射线延伸/ray_extend] → [链式连接/chain_linkage](创新：链的连通性由杯体开口的空间对准关系决定)

**来源原语**：填充/fill、杯形轮廓/cup_outline、开口/opening、封闭区域/enclosed_region、开口决定延伸向/opening_extend_dir（来自 d4f3cd78）；射线延伸/ray_extend（来自 d4f3cd78、d07ae81c）；链式连接/chain_linkage、链式序列/chained_sequence（来自 84551f4c）

**依赖链**：识别源杯（标记像素定位）→ 填充源杯内部 → 从源杯开口射线延伸 → 射线命中另一杯的开口则进入并填充 → 递归传播直到无新杯可达。删去开口分析则传播方向未知；删去链式传播则只填充一个杯；删去射线则杯间连接断裂。

从标记杯出发，填充内部后通过开口方向发射射线，射线若正好进入另一杯的开口则链式填充该杯并继续传播，未被射线从开口方向击中的杯保持空白。

**输入结构**：约 18x18 网格，黑(0) 背景。4~6 个红(2) 杯形轮廓散布于网格中，每个杯由一个矩形（约 3x3 至 5x5）的三条边组成（一个像素厚的 U 形轮廓，开口朝上、下、左或右中的某个方向）。恰好一个杯的内部有一个黄(4) 标记像素（标识源杯）。杯体之间至少间隔 2 个像素。部分杯的开口方向正对另一杯的开口方向（即一杯的出射方向与另一杯的入射方向在同一行或列上对准），形成可达链路；部分杯的开口面向空旷区域或面壁，不与任何其他杯连通。生成约束：杯与杯之间的射线路径上不存在其他杯的壁体像素阻挡（即射线在到达目标杯开口之前不会被中间障碍截断），且从源杯出发至少可链式到达 2 个以上其他杯。

**规则**：
1. 找到含黄(4) 标记像素的杯（源杯）。
2. 将源杯的封闭内部（杯壁围成的区域中的黑(0) 像素以及黄(4) 标记像素）全部填充为青(8)。
3. 确定源杯的开口方向（杯壁缺失的那一边）。从开口处的每个内边缘像素向开口方向发射射线（青(8) 着色），射线沿该方向直线前进，直到碰到非黑(0) 像素或离开网格边界时停止（不覆盖碰到的非黑(0) 像素本身）。
4. 如果某条射线停止时碰到的非黑(0) 像素属于另一个杯的红(2) 壁体，检查：该壁体像素是否是目标杯开口边的邻接像素（即射线从开口方向进入了目标杯）。若是，则该杯被"链式激活"——对其执行步骤 2-3（填充内部为青(8)，从其自身开口射出新射线）。若射线碰到的是目标杯的封闭壁体（非开口边），则该杯不被激活，射线在此处终止。
5. 链式激活递归进行：每个新激活的杯都执行步骤 2-4，直到没有新杯被激活为止。每个杯最多被激活一次。
6. 所有红(2) 杯壁保持不变。未被激活的杯内部保持黑(0)。

**关键洞察**：杯体的开口方向构成一个有向连通图——填充信号只能沿开口的出射方向传播，且只有当目标杯的开口面向来射方向时才能接收信号。空间中杯的朝向编排决定了哪些杯可达、哪些不可达，这不是简单的距离关系而是方向对准关系。
