## 新题 7：迷宫寻路 + 切比雪夫环形填充路径走廊

**组合逻辑**：[寻路/pathfinding](已有) → [填充/fill + 偶数切比雪夫距离/even_chebyshev_distance](创新：以路径像素为中心画切比雪夫环，环仅在走廊宽度内展开)

**来源原语**：寻路(pathfinding)·端点像素(endpoint_pixel)·障碍像素(blocker_pixel)·最短路径(shortest_path)·四邻接连通(four_neighbor_connect)·最短路径唯一(unique_shortest_path) ← b15fca0b；填充(fill)·十字前景(foreground_cross)·交叉点中心(intersection_center)·偶数切比雪夫距离(even_chebyshev_distance) ← 759f3fd3

**依赖链**：先在迷宫中找到两端点间的唯一最短路径 → 路径上的每个像素作为切比雪夫距离的中心 → 以每个路径像素为圆心、在其周围的背景像素中按切比雪夫距离奇偶性交替涂色 → 涂色范围被迷宫墙壁自然限制（墙壁既定义了寻路空间又裁切了环形填充）。路径形状决定了环心位置，迷宫结构同时约束路径和环形扩展。

在迷宫中找到最短路径后，以路径上每个像素为中心、在走廊内按切比雪夫距离交替涂色，迷宫墙壁同时限定路径和环的边界。

**输入结构**：约 15x15 的网格，黑(0) 背景。蓝(1) 像素构成迷宫墙壁（多个连通分量均可），形成宽度至少 3 格的走廊空间。恰好 2 个红(2) 端点像素位于走廊中，二者之间存在唯一的 4-邻接最短路径（路径仅经过黑(0) 格）。走廊足够宽，使得路径附近有至少 1~2 格的黑(0) 缓冲区。路径长度至少为 6。

**规则**：
1. 找到两个红(2) 端点，计算通过黑(0) 格的 4-邻接最短路径（蓝(1) 格为不可通行障碍）。将路径上的黑(0) 格（不含端点本身）涂为黄(4)。
2. 对网格中每个仍为黑(0) 的背景格，计算它到最近的路径格或端点格的切比雪夫距离 D。
3. 若 D 为偶数且 D > 0，将该格涂为绿(3)；若 D 为奇数，保持黑(0) 不变。
4. 蓝(1) 墙壁像素不参与计算也不被修改。红(2) 端点保持原色。黄(4) 路径像素保持原色。
5. 切比雪夫距离的计算仅在黑(0) 格和已涂色格之间进行，不穿过蓝(1) 墙壁——即计算路径距离时，若从该背景格到路径格的所有切比雪夫直线路径都被蓝墙壁阻断，则该格不涂色（保持黑(0)）。具体实现：使用不穿过蓝(1) 格的 8-邻接 BFS 从所有路径格/端点格出发计算最短距离。

**关键洞察**：迷宫墙壁承担双重角色——既为寻路定义可通行空间，又为切比雪夫环填充定义扩展边界。路径的弯折处，来自不同路径段的环形填充会产生干涉图样，这是路径几何与环形填充的涌现效应。
