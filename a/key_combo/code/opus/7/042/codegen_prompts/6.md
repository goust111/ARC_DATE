## 新题 6：二面体对称补全 + 模板印章扩展

**组合逻辑**：[对称补全/symmetry_completion](已有：从可见对称副本恢复遮挡区域) → [印章覆盖/stamp + 分块对应/block_correspondence](创新：恢复出的像素色构成印章的颜色源)

**来源原语**：对称补全(symmetry_completion)·对称图案(symmetric_pattern)·遮挡矩形(occluding_rect)·二面体对称(dihedral_symmetry)·可见副本恢复遮挡(visible_recover_occluded) ← f4081712；印章覆盖(stamp)·模板面板(template_panel)·前景像素(foreground_pixel)·分块对应(block_correspondence)·源色决定模板涂色(source_color_determines_template_recolor) ← b190f7f5

**依赖链**：绿色遮挡矩形覆盖了对称图案的一部分 → 利用二面体对称从可见部分恢复遮挡区域的颜色 → 恢复出的矩形区域本身作为"源网格"，其每个非背景像素的颜色和位置驱动印章扩展 → 输出是以恢复区域为蓝图的分块印章图。如果对称补全错误，印章的颜色配置也随之错误。

先利用对称性恢复被遮挡的区域，再将恢复结果作为源网格，把伴随的模板图案按源网格的颜色和位置印章扩展为输出。

**输入结构**：约 13x13 的正方形网格。网格整体图案在二面体群（4 次旋转 + 4 次反射）下对称，使用 2~3 种前景色（如红(2)、蓝(1)、黄(4)）在黑(0) 背景上绘制。一个绿(3) 实心矩形（约 3x4）覆盖在图案上方，遮挡部分像素。另外，在网格的一侧（与绿矩形不重叠的区域），有一个独立的灰(5) 单色小模板图案（3x3 边界框内的 4-连通图形，约 4~6 个灰像素，其余为黑(0)背景）。模板不参与对称结构，纯粹作为印章形状使用。

**规则**：
1. 对绿(3) 矩形覆盖的每个格，利用二面体对称找到其所有等价坐标（最多 8 个）。忽略同样被绿矩形覆盖的等价位置，从剩余可见的等价位置中读取颜色。所有可见等价位置颜色必须一致，该颜色即为恢复色。将恢复结果裁剪为绿矩形的边界框大小，得到"源网格"（设尺寸为 Rh x Rw）。
2. 将灰(5) 模板裁剪为其边界框（设尺寸为 Th x Tw）。
3. 创建输出画布，高 Rh * Th，宽 Rw * Tw，全部初始化为黑(0)。
4. 对源网格中每个非黑像素（位于源网格局部坐标 (r, c)，颜色为 C），将模板中所有灰(5) 像素重涂为 C，然后将该重涂模板印章到输出画布的块位置 (r, c)，即输出中行范围 [r*Th, (r+1)*Th)、列范围 [c*Tw, (c+1)*Tw) 的区域。
5. 源网格中黑(0) 背景位置对应的输出块保持全黑。

**关键洞察**：对称补全的结果不是最终输出，而是印章扩展的输入控制信号——恢复出的每个像素颜色决定了输出中一整个模板块的涂色。如果误判了被遮挡区域的颜色，错误会被模板印章放大到整个块。

1. `main(grid)` 必须实现新题描述中的确定性转换规则，不能只识别 `generate_input()` 的固定模板。禁止不同的input网格输出相同的output网格。
2. `generate_input()` 必须随机生成多样样例，不能固定死。随机维度应覆盖：网格大小、对象数量、位置、颜色、方向、形状参数或关键分支。注意若描述中存在若干，需实现而不是只有单个，包括object或者对应关系等等。且若涉及到最短路径，则输入网格中必涉及到多条路径，对选择造成干扰。

6. 若规则有多个分支，生成器不能长期固定成一个分支；应让分支在随机样例中合理出现。分支概率不必平均——难以发现的隐蔽分支（如少数情况下才触发的特殊规则）应适当提高出现概率，确保在 3 个训练示例中至少出现一次，否则求解者无法归纳该规则。对于颜色映射类规则，确保 2 个左右的示例即可覆盖所有映射关系（每种颜色→颜色的映射至少在某个示例中出现过）。
