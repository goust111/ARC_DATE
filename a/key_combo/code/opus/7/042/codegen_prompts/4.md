## 新题 4：邻接标记选择对象 + 对角线偏移壁纸

**组合逻辑**：[标记选中邻接体/marker_selects_neighbor](已有) → [裁剪/crop](已有) → [对角线偏移复制/diagonal_offset_copy + 画布加倍/canvas_doubling](创新：被选中的对象成为对角线瓦片的内容)

**来源原语**：裁剪(crop)·前景对象(foreground_object)·标记像素(marker_pixel)·邻接接触(adjacency_contact)·标记选中邻接体(marker_selects_neighbor) ← 48d8fb45；拼接(concatenate)·前景图案(foreground_motif)·对角线偏移复制(diagonal_offset_copy)·画布加倍(canvas_doubling) ← d13f3404

**依赖链**：标记像素通过邻接选择唯一目标对象 → 裁剪该对象为瓦片 → 瓦片在加倍画布上沿对角线偏移复制。被选中的对象形状直接决定对角线干涉图案——不同形状产生截然不同的输出。选择错误的对象则对角线条纹完全不同。

灰标记选中与其邻接的对象，裁剪后在双倍画布上沿右下对角线偏移铺展。

**输入结构**：约 10x12 的网格，黑(0) 背景。3 个蓝(1) 小型对象（各 3~6 像素，4-连通，形状互不相同——不同示例中对象的具体形状也不同，但均为不规则的 4-连通单色小图形）。1 个灰(5) 单像素标记，与其中恰好一个蓝对象有且仅有 1 个 4-邻接接触。其余蓝对象与灰标记无 4-邻接。对象间互不接触。

**规则**：
1. 找到灰(5) 标记像素，检测与其 4-邻接的蓝(1) 对象，该对象即为选中对象。
2. 将选中对象裁剪至其最小外接矩形（边界框），框内非对象像素保留为黑(0)。此矩形即为"瓦片"，设其高 H、宽 W。
3. 创建输出画布，高 2H、宽 2W，全部初始化为黑(0)。
4. 对瓦片中每个蓝(1) 像素（设其在瓦片内局部坐标为 (r, c)），在输出画布的所有位置 (r+k, c+k)（k = 0, 1, 2, ...）处涂蓝(1)，当且仅当 r+k < 2H 且 c+k < 2W。
5. 灰标记和未被选中的蓝对象不出现在输出中。

**关键洞察**：三个形状不同的对象中只有一个被选中；对角线偏移是对瓦片中每个像素独立进行的，因此瓦片内部的像素相对位置决定了对角线条纹是否交汇——这是选择与几何变换的耦合，而非简单串联。
