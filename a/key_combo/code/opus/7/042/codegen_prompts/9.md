## 新题 9：空心矩形封闭检测 + 旋转方向编码 + 擦除重组

**组合逻辑**：[封闭区域检测 + 含孔洞者选中/object_with_hole_selected](已有) → [旋转/rotate](创新：旋转角度由孔洞内标记像素的方位编码决定) → [擦除/erase + 裁剪/crop](创新：非空心对象被擦除，空心对象旋转后紧凑裁剪输出)

**来源原语**：裁剪(crop)·空心矩形(hollow_rectangle)·封闭区域(enclosed_region)·包围(enclosure)·含孔洞者选中(object_with_hole_selected) ← b9b7f026；旋转(rotate)·整体半周旋转(half_turn_rotation) ← 3c9b0459；标记像素(marker_pixel)·方位对应(direction_correspondence)·方位决定颜色(direction_color) ← d364b489；擦除(erase) ← a416fc5b

**依赖链**：封闭检测筛选出有孔洞的矩形 → 孔洞内部的标记像素位置编码了旋转角度 → 旋转操作改变矩形朝向 → 旋转后的矩形被紧凑裁剪输出。标记在孔洞内部的相对方位（而非绝对位置）决定旋转量，因此必须先识别孔洞边界才能计算方位。

检测空心矩形框，根据孔洞内标记像素相对于孔洞中心的方位确定旋转角度，旋转后裁剪输出。

**输入结构**：约 14x14 的网格，黑(0) 背景。包含 3~4 个单色矩形对象（每个由一种前景色的像素构成，颜色互不相同，可选蓝(1)、红(2)、绿(3)、黄(4)）。恰好一个矩形是完整的空心矩形框（宽度为 1 像素的矩形边框，内部封闭若干黑(0) 背景像素），其余为实心矩形。空心矩形框的内部恰好有 1 个灰(5) 标记像素，位于孔洞的非中心位置。矩形间互不重叠、互不接触。空心矩形框的内部孔洞至少 3x3，使标记有明确的方位偏离。

**规则**：
1. 检测所有矩形对象，识别唯一一个空心矩形框（其外接矩形内部存在不接触网格边界的封闭黑(0) 区域）。
2. 找到孔洞内部的灰(5) 标记像素。计算标记相对于孔洞中心（孔洞外接矩形的几何中心）的方位：若标记行 < 中心行，方位为"上"；若标记行 > 中心行，方位为"下"；若标记列 < 中心列，方位为"左"；若标记列 > 中心列，方位为"右"。若行和列都偏离，取偏离像素数更大的轴作为主方位。若相等，优先取行方向（上/下）。
3. 方位决定旋转角度：上 → 0°（不旋转）；右 → 90° 顺时针；下 → 180°；左 → 270° 顺时针。
4. 将空心矩形框（含其边框像素，不含灰标记）按确定的角度绕自身中心旋转。
5. 输出为旋转后的空心矩形框的最小外接矩形裁剪，边框保持原色，内部为黑(0)。灰标记不出现在输出中。实心矩形全部擦除。

**关键洞察**：标记像素在孔洞内部的相对偏移方向编码了旋转指令——这不是一个简单的"检测+旋转"流水线，因为旋转角度依赖于对孔洞边界的精确识别（需先判断哪个矩形是空心的、孔洞的精确范围是什么），而非标记的绝对位置。
