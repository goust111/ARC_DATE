## 新题 1：旋转族补全后的封闭区域条件填充

**组合逻辑**：[旋转/rotate + 补全/complete](已有) → [封闭区域检测/enclosure_detection](创新：在旋转补全结果上检测) → [填充/fill](创新：填充色由封闭面积阈值决定)

**来源原语**：旋转(rotate)·补全(complete)·缺失旋转变体(missing_rotation) ← be03b35f；填充(fill)·封闭区域(enclosed_region)·包围(enclosure)·含孔洞者选中(object_with_hole_selected) ← dbff022c / b9b7f026

**依赖链**：旋转补全恢复了第四象限的图案 → 恢复后才能判断各象限图案是否形成封闭区域 → 封闭区域面积决定填充颜色。缺失象限可能包含关键的封闭区域，因此补全是填充的前置条件而非独立步骤。

将被占位色遮蔽的旋转变体补全后，检测所有四个象限中图案围成的封闭区域，按面积分档填色。

**输入结构**：约 13x13 的网格。灰(5) 单像素宽的十字将网格分为四个等大的正方形象限（每个约 6x6）。三个象限内包含蓝(1) 像素在黑(0) 背景上构成的图案（4-连通、4~8 像素），三个图案互为 90° 旋转的连续变体。第四个象限被橙(7) 完全填充作为占位标记。图案的基础形态具有弯折结构，某些旋转方向下像素围成封闭回路，另一些则不围成。不同示例中基础形态的具体形状不同，但均保证在至少两个旋转方向上产生封闭区域，且不同旋转的封闭区域面积可能不同。

**规则**：
1. 识别三个可见图案的旋转关系，确定缺失的第四个 90° 旋转变体。将橙(7) 占位象限替换为该变体（蓝(1) 像素在黑(0) 背景上），旋转中心为象限中心。
2. 对全部四个象限分别执行封闭区域检测：在每个象限内部，找出被蓝(1) 像素完全包围的 4-连通黑(0) 区域，该区域的任何像素均不与象限边缘或灰(5) 十字相邻。
3. 对每个检测到的封闭区域计算面积（黑像素数量）。按面积分档填色：面积 1~2 → 填红(2)；面积 3~4 → 填绿(3)；面积 >= 5 → 填黄(4)。
4. 灰(5) 十字保持不变。非封闭的黑(0) 背景保持不变。蓝(1) 图案像素保持不变。

**关键洞察**：占位象限可能隐藏了面积最大的封闭区域，而面积阈值的分档只有在观察全部四个象限后才能验证——必须先补全再检测，无法跳过补全直接对三个可见象限做填充。
