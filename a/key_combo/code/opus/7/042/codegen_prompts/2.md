## 新题 2：周期瓦片恢复后的标记定向射线涂色

**组合逻辑**：[补全/complete](已有：周期推断) → [射线延伸/ray_cast](创新：射线方向由标记到最近边的方位决定) → [重涂色/recolor](创新：射线覆写恢复后的周期色)

**来源原语**：补全(complete)·周期瓦片(periodic_tile)·缺损像素(erased_pixel)·周期重复(periodic_repeat)·前景残留推断周期(residue_infers_period) ← ea959feb；射线延伸(ray_cast)·列遮挡(column_coverage)·遮挡列延伸至边(covered_col_to_edge) ← 6d58a25d；重涂色(recolor)·方位对应(direction_correspondence)·方位决定颜色(direction_color) ← d364b489

**依赖链**：周期推断恢复完整瓦片图案 → 标记像素位于原本属于图案的位置上（伪装成擦除） → 标记到最近网格边的方位决定射线方向 → 射线沿该方向覆写恢复后的图案像素为标记色。没有周期恢复就无法区分"真正的背景"和"被擦除的图案格"，也就无法定位标记的角色。

从部分擦除的周期壁纸中恢复完整图案，然后从伪装为擦除的标记像素出发，向最近网格边射出射线，沿途覆写为标记色。

**输入结构**：约 14x14 的网格。使用蓝(1)、红(2)、绿(3) 三种颜色构成的周期重复图案覆盖全网格，最小重复瓦片至少 3x3。部分图案像素被擦除为黑(0) 背景。另有 2~3 个橙(7) 单像素标记，放置在原本属于图案的位置上（替代了该位置的图案色）。标记不相邻，且各标记到最近网格边的射线路径互不重叠。黑(0) 既是背景色也是擦除色，但在恢复后的周期图案中不会出现歧义（每个残余类要么有前景证据，要么始终为背景）。

**规则**：
1. 忽略橙(7) 标记像素，从剩余的非黑、非橙前景像素中推断最小行/列周期。利用周期恢复全网格的完整图案（包括被擦除为黑(0) 的位置和被标记替代的位置）。
2. 对每个橙(7) 标记，计算其到四条网格边（上、右、下、左）的曼哈顿距离。选择距离最小的边作为射线方向。若距离相等，按顺时针优先序选择：上 > 右 > 下 > 左。
3. 从标记位置出发（含标记自身），沿选定方向逐格画射线直到到达网格边界（含边界格）。射线上所有格（无论恢复后是什么颜色）都被覆写为橙(7)。
4. 不在任何射线上的格保留恢复后的周期图案颜色。

**关键洞察**：橙标记伪装成擦除——它们占据了图案位置但颜色与图案色不同。只有在恢复周期后才能确认标记所在位置"本应"有什么颜色，从而理解标记是外来控制信号而非图案本身。射线方向完全由标记的绝对位置决定，与图案内容无关。
