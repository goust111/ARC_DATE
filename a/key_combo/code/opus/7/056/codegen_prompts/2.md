## 新题 2：模板匹配确定排位后图例重涂色

**组合逻辑**：[rotate + template_match](已有：旋转匹配碎片) → [rank_correspond](创新：匹配后的碎片按空间位置排位) → [recolor](创新：排位映射到图例颜色，碎片整体重涂为单色)

**来源原语**：rotate / template / fragment / template_match / scale_rotate_align_frag（6aa20dc0），rank_correspond / color_legend / legend_pos_color（fafd9572），recolor（6e82a1ae, fafd9572）

**依赖链**：模板匹配确定每个碎片是模板的哪个旋转副本，验证碎片身份。碎片的空间排位（边界框位置排序）决定它对应图例中的第几个颜色。图例颜色直接覆盖碎片的所有像素。三个环节缺一不可：没有模板匹配无法验证碎片有效性，没有排位无法建立碎片与图例的对应，没有图例没有目标颜色。

通过模板旋转匹配识别散落碎片的身份，按碎片空间位置排序后用紧凑图例逐一分配新颜色，每个碎片整体重涂为对应的图例色。

**输入结构**：约 18x18 的灰(5)背景网格。左上角区域有一个多色模板对象（使用 3-4 种非灰颜色，如红(2)、蓝(1)、绿(3)、黄(4)，是场景中颜色种类最多的连通体，约 3x3 到 4x4 像素）。网格中散布 3-5 个单色碎片（各自使用不同的非灰颜色，每个碎片是模板某个旋转版本的部分像素子集，至少包含模板像素的 60%，为 4-连通）。网格右边缘有一列紧凑的图例像素（每行一个像素，连续排列，使用橙(7)、品红(6)、青(8)等与碎片颜色不同的颜色，图例像素数 = 碎片数）。生成约束：每个碎片对应模板的一个旋转（0/90/180/270度），碎片的颜色和位置互不相同，碎片之间不重叠。

**规则**：
1. 识别颜色种类最多的连通体为模板。
2. 对每个非模板、非图例的前景连通体（碎片），尝试将模板的四种旋转版本与碎片对齐：找到一个旋转使得碎片的所有像素位置都是旋转后模板像素位置的子集。
3. 将所有成功匹配的碎片按边界框位置排序：先按边界框顶行升序，顶行相同则按边界框左列升序，得到排位 1, 2, 3, ...
4. 图例像素同样从上到下编号 1, 2, 3, ...
5. 将排位为 k 的碎片的所有像素重涂为图例中第 k 个像素的颜色。
6. 模板和图例在输出中保持不变。背景保持灰(5)。

**关键洞察**：图例不是要复制的图案，而是按空间排位分配颜色的"调色盘"。碎片的原始颜色与最终颜色无关——最终颜色完全由碎片在网格中的空间排列顺序和图例的对应位置决定。需要多个示例才能区分排位规则（空间位置 vs. 碎片面积 vs. 匹配旋转角度等备选方案）。

## 实现要求

2. `generate_input()` 必须随机生成多样样例，不能固定死。随机维度应覆盖：网格大小、对象数量、位置、颜色、方向、形状参数或关键分支。注意若描述中存在若干，需实现而不是只有单个，包括object或者对应关系等等。且若涉及到最短路径，则输入网格中必涉及到多条路径，对选择造成干扰。

6. 若规则有多个分支，生成器不能长期固定成一个分支；应让分支在随机样例中合理出现。分支概率不必平均——难以发现的隐蔽分支（如少数情况下才触发的特殊规则）应适当提高出现概率，确保在 3 个训练示例中至少出现一次，否则求解者无法归纳该规则。对于颜色映射类规则，确保 2 个左右的示例即可覆盖所有映射关系（每种颜色→颜色的映射至少在某个示例中出现过）。
