## 新题 4：跨框架推断完整图案后用作平铺种子

**组合逻辑**：[infer + cross_frame_match](已有：跨框架推断颜色) → [tiling](创新：推断结果不是填回框架，而是作为种子图案平铺到另一个区域)

**来源原语**：infer / lattice_frame / lattice_slot / cross_frame_match / slot_position_color（2e65ae53），tiling / seed_pattern / rectangular_cavity / wall / preserve_seed_phase / pattern_fills_cavity（a57f2f04）

**依赖链**：多个格子框架各自只展示了完整颜色图案的一部分。跨框架推断才能还原完整图案。该图案随后成为平铺种子，用于填充一个独立的大空腔。推断环节产出种子内容，平铺环节消费种子——前者的输出是后者的唯一输入来源。

从多个部分填充的格子框架中推断出完整颜色矩阵，再将该矩阵作为种子图案周期性地平铺填满独立的大空腔。

**输入结构**：约 20x16 的黑(0)背景网格。橙(7)的水平分隔行将网格分为上下两部分。上半部分包含 2-3 个小型格子框架（绿(3)像素构成 1 像素宽的网格线，将每个框架分为相同布局的槽位，如 2x3 或 3x3 个槽位，每个槽位内部约 2x2 像素）。各框架的部分槽位已填充颜色（红(2)、蓝(1)、黄(4)、品红(6)等），其余槽位为黑(0)。跨所有框架，每个逻辑槽位位置至少在一个框架中已被填充。下半部分包含一个由绿(3)墙壁围成的大矩形空腔（内部约 8x10，当前为黑(0)）。生成约束：所有框架的槽位布局相同（行列数相同）；同一个逻辑位置在不同框架中若被填充则颜色一致；大空腔的宽和高均为种子图案宽高的整数倍或更大。

**规则**：
1. 识别上半部分的所有格子框架，解析其槽位布局（R行 x C列）。
2. 对每个逻辑槽位位置 (r, c)，在所有框架中找到该位置已填充的颜色，记为该位置的颜色。
3. 将推断出的 RxC 颜色矩阵组装为一个矩形种子图案（每个逻辑位置对应种子中一个像素）。
4. 在下半部分的大空腔中，以空腔内部左上角为锚点，将种子图案周期性平铺，直到填满整个空腔。种子图案的每个像素对应空腔中一个像素（不做缩放）。
5. 输出仅保留下半部分（大空腔及其墙壁）。移除分隔行和上半部分的所有内容。

**关键洞察**：格子框架不是需要"修复"的目标，而是编码了平铺种子的分布式存储器。推断操作从多个不完整副本中恢复一份完整信息，该信息的用途（平铺填充）与其存储形式（格子框架）截然不同。需要多个示例来确认：推断结果不是填回框架本身，而是用于平铺另一个区域。
