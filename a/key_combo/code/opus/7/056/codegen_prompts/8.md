## 新题 8：双面板去遮挡对称补全后叠加取交集，按行控制色着色

**组合逻辑**：[erase + symmetry_completion](已有原语，创新组合：两个面板各自独立去遮挡并补全) → [overlay / per_pixel_comparison](创新：取两个补全后面板的交集而非各自输出) → [recolor / per_row_color](创新：交集像素不统一着色，而是按行从控制列取色)

**来源原语**：erase / occlusion / mirror_after_occluder_removal / symmetry_completion（3345333e），overlay / per_pixel_comparison / both_background_marked_foreground（94f9d214），recolor / per_row_color / row_control_color / same_row_align（c7d4e6ad），filled_rectangle（3345333e），panel / separator_row（0c9aba6e）

**依赖链**：(1) 遮挡物移除揭示了被隐藏的区域，但留下空洞。(2) 对称补全利用各面板自身的镜像对称修复空洞。(3) 两个面板补全后可能各自"过度生成"（将遮挡区域的对称位置也补全了），取交集过滤掉过度生成的像素，保留两个面板共同认可的前景。(4) 行控制色逐行为交集像素赋予不同颜色。四步依赖链中，每一步的输出实质性改变下一步的输入：遮挡物位置影响补全范围，补全范围影响交集结果，交集确定着色目标，控制色确定最终外观。

两个各自被不同矩形遮挡的对称面板分别去遮挡并镜像补全，叠加取交集得到可靠前景，再按行控制色逐行着色。

**输入结构**：约 14x14 的黑(0)背景网格。橙(7)的水平分隔行将网格分为上下两个等高面板（各约 6x14）。
- 上面板：一个蓝(1)单色图案在黑背景上，具有左右镜像对称性。一个红(2)实心矩形（约 2x3 到 3x4）覆盖了图案的一部分，遮挡了该区域的蓝色像素。
- 下面板：一个绿(3)单色图案在黑背景上，具有左右镜像对称性，与上面板的蓝色图案形状不同。一个红(2)实心矩形覆盖了该图案的另一部分。
- 网格最右列为控制色列：从上到下每行一个彩色像素（使用黄(4)、灰(5)、品红(6)、青(8)中的若干种），像素数等于单个面板的行数。控制色列不被分隔行中断（分隔行位置的控制色像素也存在，但不用于输出）。

生成约束：每个面板的对称图案在去除遮挡物并补全后为完整的对称图形；两个面板的完整图案有部分空间重叠（按位置对齐后至少有若干行列同时为前景）；红色不出现在图案或控制色中（红色仅用于遮挡物）。

**规则**：
1. 在每个面板中，识别红(2)实心矩形为遮挡物并擦除（将其像素设为黑(0)）。
2. 对每个面板，检测其前景图案的垂直镜像对称轴。将被遮挡区域中缺失的前景像素通过镜像反射补全（若对称轴一侧有前景像素而另一侧的镜像位置被遮挡物覆盖过，则在该镜像位置恢复前景像素）。补全后的前景色与原图案相同（上面板用蓝(1)，下面板用绿(3)）。
3. 移除分隔行，将两个补全后的面板按位置对齐。
4. 生成一个面板大小的输出网格。对每个像素位置：
   - 若上面板补全后该位置为前景（蓝(1)）**且**下面板补全后该位置也为前景（绿(3)）：标记为输出前景。
   - 否则：标记为黑(0)背景。
5. 对每个输出前景像素，根据其所在行在控制色列中的对应颜色进行着色（第 r 行的前景像素涂为控制色列第 r 个像素的颜色）。
6. 移除控制色列本身（不出现在输出中）。输出网格宽度 = 原面板宽度 - 1（去掉控制色列占用的列）。

**关键洞察**：单独看任一面板，去遮挡后补全可能"猜错"——遮挡区域的对称位置可能本来就没有前景像素，但补全操作会错误地添加。两个面板使用不同的遮挡位置，它们补全后的交集过滤掉了各自的过度生成，仅保留两个独立信息源共同支持的前景。这种"双源校验"机制是多示例才能归纳的核心——观察者需要理解交集的作用不是合并两个图案，而是互相验证。
</new_puzzle>
