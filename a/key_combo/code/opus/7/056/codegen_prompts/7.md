## 新题 7：竖条滑动至灰线后在停靠点印章模板

**组合逻辑**：[sliding / collision_blocking](已有：条状物滑动直到碰撞) → [stamp](创新：印章位置不由规则示例定义，而是由滑动后的停靠位置决定) + [erase]（辅助：清除引导结构）

**来源原语**：sliding / bar / same_col_align / collision_blocking / slide_until_near_target（3906de3d），stamp / stencil_pattern / recolor（abc82100），erase（3345333e, a78176bb）

**依赖链**：滑动操作决定每个竖条的最终位置，该位置成为印章操作的放置坐标。竖条的颜色决定印章副本的颜色。滑动距离（从起点到终点的行数差）决定重叠时的优先级。三个信息（位置、颜色、优先级）全部来源于滑动过程，驱动后续的印章操作。

彩色竖条沿各自列滑向灰色水平线直到紧邻，在每个停靠点以竖条颜色印章一份模板图案，滑动距离长者优先覆盖。

**输入结构**：约 15x15 的黑(0)背景网格。网格中部有一条水平灰(5)线（占据一整行，1 像素高）。灰线上方和下方各散布若干竖条（每个竖条宽 1 像素，高 2-3 像素，4-连通垂直线段），使用不同的非黑非灰非青颜色（如红(2)、蓝(1)、绿(3)、黄(4)、橙(7)等），每列最多一个竖条。网格的一个角落区域（如左下角）有一个青(8)色的小型连通图案（模板，3-5 像素，不规则形状），不与灰线和竖条重叠。生成约束：灰线上方的竖条与灰线之间至少有 1 行空隙；灰线下方的竖条与灰线之间至少有 1 行空隙；竖条滑动到灰线旁后，相邻竖条的印章图案可能部分重叠。

**规则**：
1. 识别灰(5)水平线为碰撞边界，青(8)连通体为模板图案。
2. 灰线上方的每个竖条向下滑动，直到竖条的底部像素紧邻灰线上方（即底部像素位于灰线行 - 1）。灰线下方的每个竖条向上滑动，直到竖条的顶部像素紧邻灰线下方（即顶部像素位于灰线行 + 1）。
3. 计算每个竖条的滑动距离（移动的行数，即终位置与起位置的差的绝对值）。
4. 在每个竖条滑动后的中心像素位置（竖条高度的中间行，若偶数高度取偏上的行；列为竖条所在列），放置一份模板图案的副本。放置方式：模板图案的边界框中心对齐到该位置。模板副本的颜色为该竖条的颜色（替换青色）。
5. 若不同竖条的模板副本有像素重叠，滑动距离更长的竖条优先（其副本覆盖另一方）。若距离相同，灰线上方滑来的竖条优先于下方滑来的。若方向也相同，列坐标更小（更靠左）的优先。
6. 擦除灰线、原始青(8)模板图案、以及竖条的起始位置残影（若有）。输出仅包含印章副本和黑色背景。

**关键洞察**：灰线是"集合点"，将分散的竖条吸引到中部。但竖条到达后并非简单停留——它们各自触发一次模板印章，且滑动距离（路途远近）决定了重叠冲突的裁决。来自远处的竖条拥有更高优先级，这条规则需要对比多个示例中的重叠情况才能归纳。
