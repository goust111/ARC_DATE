## 新题 10：框架宽高比定镜像轴 + 门缺口定源侧 → 双约束镜像补全

**组合逻辑**：[宽高比决定镜像轴](aspect_ratio_determines_mirror_axis) + [穿越门中心](through_door_center, 创新：门的位置不用于寻路而是标记"源侧") → [镜像](mirror) + [填充](fill, 创新：补全后封闭门缺口)

**来源原语**：矩形框架·母题在框架内·宽高比决定镜像轴·镜像 ← 18419cfa；门段·穿越门中心·平行墙壁 ← 7e576d6e；对称补全·缺失区域 ← 9ecd008a；填充 ← 78e78cff

**依赖链**：框架的宽高比决定镜像轴向（水平还是垂直），但仅凭轴向无法确定镜像方向（从左到右还是从右到左）。门缺口所在的半边指示"源侧"——图案从源侧镜像到对侧。两条约束同时作用于同一个操作，缺少任一条都有两种等概率的输出。

多个矩形框架各含半边图案和一个墙壁缺口；框架宽高比决定镜像轴向，缺口所在半边为源侧，将图案镜像补全到对侧后封闭缺口。

**输入结构**：黑(0)背景，网格大小约 22x22。网格上有 2~3 个互不重叠的灰(5)色一像素厚矩形框架，大小各异。每个框架的宽高比明显偏向一侧（宽框的宽 >= 高 x 1.5，或高框的高 >= 宽 x 1.5）。每个框架的一条边上有一个 1 像素的缺口（该边上一个灰(5)像素被替换为黑(0)背景，形成一个"门"）。缺口的位置将框架分为两半：对于宽框，缺口在左半边或右半边的水平边上；对于高框，缺口在上半边或下半边的垂直边上。在缺口所在的那一半框架内部，有一个由红(2)像素组成的小图案（3~6 像素的 4-连通图形）。另一半内部为空（黑(0)背景）。生成约束：不同框架中缺口所在侧不全相同（至少有一个框架的缺口在不同侧）；图案距离镜像轴至少 1 格（镜像后不与原图案重叠）。

**规则**：
1. 对每个灰(5)矩形框架，计算其内部区域的宽度 W 和高度 H。
2. 若 W > H，镜像轴为框架内部的垂直中线（列 = 框架内部左列 + W/2，取下整）。若 H > W，镜像轴为框架内部的水平中线（行 = 框架内部顶行 + H/2，取下整）。
3. 找到该框架边上的缺口位置，确定缺口在镜像轴的哪一侧——该侧为"源侧"。
4. 将源侧的所有红(2)像素关于镜像轴镜像到对侧：对于垂直轴，列坐标变为 2*axis - c；对于水平轴，行坐标变为 2*axis - r。镜像目标格必须在框架内部范围内。
5. 保留源侧的原始红(2)像素。
6. 封闭缺口：将缺口处的黑(0)像素恢复为灰(5)，使框架重新完整。
7. 所有框架独立处理，互不影响。

**关键洞察**：宽高比告诉你"沿哪个轴镜像"，但不告诉你"从哪边镜像到哪边"——这第二个自由度由门缺口的位置消除。两个几何线索协同解决同一个对称问题，缺少任何一个都会导致输出歧义。
