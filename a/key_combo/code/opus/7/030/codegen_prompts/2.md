## 新题 2：遮挡层序决定扩展冲突

**组合逻辑**：[层序推断/layer_infer](已有) + [拉伸/extrude](创新：扩展后的冲突区域由层序决定归属而非简单覆盖) + [边缘延伸角落留黑/edge_extrude_corner_black](已有，作为扩展的局部约束)

**来源原语**：层序推断/遮挡层次/交叉可见色为上层(22425bda, 1a2e2828)、拉伸/扩展/边缘延伸角落留黑(49d1d64f)、交叠区域(1a2e2828)

**依赖链**：重叠区域的可见颜色决定层序；层序决定扩展冲突的归属；扩展操作本身又在原始重叠区域之外创建新的接触区域，但这些新接触不改变已推断的层序（层序仅由输入中的重叠决定）。层序推断和扩展操作通过冲突解决规则紧密耦合。

从部分重叠的彩色矩形块中推断遮挡层序，然后将每个矩形向外扩展一圈，扩展冲突区域归属于层序更高的矩形。

**输入结构**：约 18x18 的网格，背景为黑(0)。包含 3~5 个不同颜色的实心矩形块（每个约 3x4 至 5x6 像素，颜色从蓝(1)、红(2)、绿(3)、黄(4)、灰(5)中选取），彼此部分重叠。在重叠区域中，高层矩形的颜色覆盖低层矩形的颜色（与 22425bda/1a2e2828 类似的遮挡可见性）。每对相邻层的矩形之间至少有一个重叠像素，使层序可以从可见颜色中完整推断。生成约束：所有矩形的层序构成唯一的全序（无循环遮挡）；任何两个矩形扩展后的一像素外框至少在一个非角落位置接触，以确保冲突解决可观测。

**规则**：
1. 还原每个矩形的完整范围：被遮挡的像素仍属于该矩形，其颜色在输出中可能被恢复或继续被遮挡。
2. 从重叠区域推断层序：若位置 (r,c) 属于矩形 A 和矩形 B 的重叠区域，且该位置显示 A 的颜色，则 A 在 B 之上。传递闭包得到完整的从低到高的层序。
3. 对每个矩形执行一像素外扩：在其边界框四周各扩展一行/列，扩展像素颜色与矩形相同，但扩展框的四个角落像素保持黑(0)（与 49d1d64f 一致）。
4. 冲突解决：若两个矩形的扩展区域（或扩展区域与另一矩形的原始区域）重叠于同一像素，该像素归属层序更高的矩形，显示该矩形的颜色。原始矩形体的遮挡关系同样延续（高层覆盖低层）。
5. 输出保留背景黑(0)以及所有经扩展和冲突解决后的矩形像素。

**关键洞察**：扩展操作本身不改变层序，但创造了新的冲突区域；求解者必须先从输入的原始重叠推断层序，再将同一层序应用于扩展后产生的全新冲突——两步使用同一推断结果但作用于不同几何范围。
