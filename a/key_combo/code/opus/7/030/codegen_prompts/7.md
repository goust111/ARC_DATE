## 新题 7：扩展角隙的对角邻接填充

**组合逻辑**：[拉伸/extrude · 边缘延伸角落留黑](已有) + [重涂色/recolor · 对角邻接背景着色](创新：对角邻接检测作用于扩展后的几何而非原始几何) → 涌现效应：扩展操作故意留出的角隙恰好是对角邻接规则的作用目标

**来源原语**：拉伸/扩展/边框绘制/边缘延伸角落留黑(49d1d64f, 0f63c0b9)、重涂色/仅对角邻接/对角邻接背景着色/封闭框/内层前景(396d80d7)

**依赖链**：每个封闭框先执行外扩（角隙留黑）→外扩后的框几何改变了哪些背景像素满足"仅对角邻接"条件→满足条件的像素被涂为内层前景色。扩展和对角填充两步操作的几何互相啮合：角隙是扩展规则刻意创建的，而对角填充规则恰好选中这些角隙。

将每个带有内层前景色的封闭框向外扩展一圈（角落留黑），然后用内层前景色填充所有仅与扩展后框体对角邻接的背景像素。

**输入结构**：约 18x18 的网格，背景为黑(0)。包含 2~3 个不重叠的封闭框结构，每个结构由两种颜色组成：一种颜色形成矩形环（框），宽度为一像素；另一种颜色（内层前景色）为框内部的 1~3 个像素。不同封闭框使用不同的颜色对，例如第一个框为红(2)框+蓝(1)内层，第二个框为绿(3)框+黄(4)内层。框的边界框严格包含内层前景像素的边界框。封闭框之间至少间隔 3 个像素，确保扩展后不会互相接触。

**规则**：
1. 对每个封闭框执行一像素外扩：在框的边界框四周各扩展一行/列，扩展像素颜色与框色相同，但扩展矩形的四个角落像素保持黑(0)。
2. 框内部的内层前景像素和原始框像素保持不变。
3. 扩展完成后，扫描整个网格。对每个黑(0)背景像素，检查其 8 邻域：若该像素与某个扩展后框色存在对角邻接（至少一个对角方向有该框色像素），但与该框色不存在正交邻接（上下左右均无该框色像素），则将该像素重涂为该封闭框的内层前景色。
4. 若一个背景像素同时满足多个封闭框的对角邻接条件（不会发生，因为框间距足够大），则按框的边界框面积从小到大优先（面积小的优先）。
5. 输出包含所有扩展后的框、内层前景、以及新涂色的对角邻接像素。

**关键洞察**：扩展操作刻意留出的四个角隙像素恰好满足"仅对角邻接于框"的条件，因此内层前景色总是精确地出现在扩展后的四个角——这一涌现效果不是任一规则单独能产生的，而是两条规则的几何契合。
