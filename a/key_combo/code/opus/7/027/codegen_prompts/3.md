## 新题 3：嵌套区域深度驱动的循环换色

**组合逻辑**：[内部包含 → 有序槽位](创新：嵌套拓扑定义循环顺序，非空间左右排列) + [循环移位](创新：移位方向由全局属性决定而非固定) + [重涂色](保留)

**来源原语**：
- 循环移位(cyclic_shift)、有序槽位(ordered_slots) ← 参考题 2601afb7
- 重涂色(recolor)、连通分量(connected_component)、封闭区域(enclosed_region)、内部包含(interior_containment)、含空洞对象重涂(objects_with_holes_recolored) ← 参考题 b2862040
- 计数(counting) ← 参考题 d4c90558

**依赖链**：首先通过拓扑分析建立嵌套深度序列，这是循环移位的前提——没有正确的深度排序就无法确定颜色如何轮转；然后全局像素计数决定移位方向，这是在深度序列基础上的第二层决策；最后按移位结果重涂，三步缺一不可。

根据封闭区域的嵌套深度排列颜色序列，依全局前景像素总数的奇偶性决定循环移位方向，重涂每层区域。

**输入结构**：约 13x13 的黑(0)背景网格。3-4 个不同颜色的封闭区域（不规则闭合曲线，每条曲线由单一非背景色的 4-连通像素构成，像素数 8-20）逐层嵌套：最外层区域完全包含第二层，第二层完全包含第三层，以此类推。各层颜色互不相同，取自蓝(1)、红(2)、绿(3)、黄(4)。每层区域内部（该层边界与下一层边界之间）的空间保持黑(0)背景。生成约束：嵌套层级为 3 或 4 层；各层之间有足够间隙（至少 1 像素），不存在共享边界像素的情况。

**规则**：
1. 识别所有封闭区域，按嵌套深度排序：最外层深度为 1，被其直接包含的为深度 2，以此类推。
2. 按深度顺序读取各层边界颜色，构成颜色序列 [C1, C2, ..., CN]。
3. 统计所有非背景像素的总数 T。若 T 为奇数，将颜色序列向内循环移位一位（每层取比自己深一层的颜色，最内层取最外层的颜色）：[C2, C3, ..., CN, C1]。若 T 为偶数，向外循环移位一位（每层取比自己浅一层的颜色，最外层取最内层的颜色）：[CN, C1, C2, ..., C(N-1)]。
4. 按移位后的序列重涂每层区域的边界像素。背景像素不变。

**关键洞察**：颜色轮转的方向由全局前景像素总数的奇偶性控制——单个示例只能观察到某一个方向的移位结果，必须对比奇偶性不同的多个示例才能归纳出方向选择规则。嵌套拓扑（而非空间排列）定义了"相邻槽位"的概念，这与参考题中的线性空间排列截然不同。
