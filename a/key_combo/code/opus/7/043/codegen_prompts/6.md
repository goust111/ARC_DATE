## 新题 6：U 框液位驱动的种子射线与螺旋生长

**组合逻辑**：[u_shaped_frame + empty_rows_map_to_fill_amount](已有，从 b0c4d837，但从仪表输出改为驱动远程操作的参数源) → [ray_extend + seed_color_determines_extend](已有，从 178fcbfb，但射线长度不再是全跨而是由液位值 N 决定) → [spiral_grow + turn_priority_rule](已有，从 da515329，但起点从十字臂端改为射线端点，步数由 N 控制)

**来源原语**：spiral_fill / u_shaped_frame / gauge_output / empty_rows_map_to_fill_amount / interior_containment（b0c4d837），ray_extend / seed_pixel / seed_color_determines_extend / stripe（178fcbfb），spiral_grow / turn_priority_rule / spacing_constraint / arm_tip（da515329）

**依赖链**：U 框内液面以上空行数 = N → N 决定种子射线长度 → 射线端点成为螺旋起点 → N 同时决定螺旋步数——U 框是"控制面板"，删掉它则射线和螺旋长度无法确定；种子颜色决定射线方向，删掉颜色规则则射线朝向不确定；螺旋从射线端点生长，删掉射线则螺旋无起点。

U 框内的空余行数被读取为参数 N，N 同时决定画布其他区域中种子射线的延伸长度和射线端点处螺旋的生长步数。

**输入结构**：
- 网格约 18x18，背景黑(0)。
- 左上象限（约 8x8 区域）：一个开口朝上的 U 形框架，框架色蓝(1)，内部底部有红(2) 液体填充（底对齐矩形）。框架内部液面以上有 1-5 行空行。
- 右下区域（远离 U 框）：2-3 个孤立种子像素。红(2) 种子发射向下的纵向射线，绿(3) 种子发射向右的横向射线。
- 生成约束：种子位置保证长度最多为 6 的射线和最多 6 步的螺旋均在网格内且不进入 U 框区域。种子之间至少间隔 4 像素以防螺旋碰撞。

**规则**：
1. 计算 N = U 框内部液面（最高红(2) 行）以上的空行数。
2. 红(2) 种子发射向下纵向射线，长度 N 格（从种子下方第 1 格起向下 N 格）。射线涂橙(7)。
3. 绿(3) 种子发射向右横向射线，长度 N 格（从种子右方第 1 格起向右 N 格）。射线涂橙(7)。
4. 种子像素保持原色（红或绿），不被覆盖。
5. 从每条射线的端点（第 N 格）开始生长顺时针螺旋，涂黄(4)：第一步从射线前进方向顺时针转 90 度出发，后续每步遵循"优先右转 > 直行 > 左转"的规则。每步涂 1 格，共生长 N 步。
6. 螺旋步若将落在已有非背景像素上或超出网格边界，则该步跳过（步数消耗，但不涂色，螺旋前进方向不因跳过而改变）。

**关键洞察**：U 框是"控制面板"——其液位编码了一个参数，驱动画布上完全不相关的操作。没有 U 框的液位读数，种子射线和螺旋的长度均无法确定。求解者必须识别出液位高度与射线/螺旋长度之间的跨区域因果关系。
