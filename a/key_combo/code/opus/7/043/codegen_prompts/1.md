## 新题 1：射线交叉点的同心环展开

**组合逻辑**：[ray_extend + seed_color_determines_extend](已有，从 178fcbfb) → [交叉点涌现为展开中心](创新——源题中射线独立，此处两组射线的笛卡尔积产生新锚点) → [concentric_fill + palette_color_by_distance](已有，从 9356391f，但作用对象从单一种子改为涌现交叉点)

**来源原语**：ray_extend / seed_pixel / seed_color_determines_extend（178fcbfb），concentric_fill / palette_row / chebyshev_index / palette_color_by_distance（9356391f），stamp_ring_at_cross 概念（ac3e2b04）

**依赖链**：种子颜色决定射线方向（红=纵、绿=横）；两组射线的每对交叉点成为同心环展开中心；色板行决定各环颜色；射线与环的重叠需按优先级解决——删掉射线无法定位中心，删掉色板无法确定环色，删掉同心展开则射线交叉毫无后续作用。

从散布的红/绿种子出发，红种子发射纵向射线、绿种子发射横向射线，在每对交叉点处以色板行颜色画出同心方环。

**输入结构**：
- 网格约 15x15，背景黑(0)。
- 第 0 行为色板条：从第 0 列起连续 3-4 个非背景色像素（例如红(2)、蓝(1)、黄(4)、绿(3)），其余第 0 行单元为黑(0)。
- 第 2 行及以下：散布若干孤立种子像素。红(2) 种子若干，绿(3) 种子若干。任意两个红种子不在同一列，任意两个绿种子不在同一行。
- 生成约束：至少 2 个红种子和 2 个绿种子，保证至少 4 个交叉点。所有红-绿配对的交叉点 (green_row, red_col) 均落在网格内。

**规则**：
1. 红(2) 种子发射纵向射线：将该种子所在列从第 1 行到末行全部填充灰(5)。绿(3) 种子发射横向射线：将该种子所在行全部填充灰(5)。色板行（第 0 行）不被射线覆盖。
2. 种子像素保持原色（红或绿），不被灰覆盖。
3. 对每对（红种子在列 c，绿种子在行 r），单元 (r, c) 为交叉中心。以该中心做同心方环展开：与中心切比雪夫距离为 d 的单元涂 palette[d]（0-索引）。若 d >= 色板长度，该单元不涂。展开裁剪到网格边界内。
4. 同心环像素覆盖灰色射线像素；但不覆盖种子像素。
5. 若两个交叉中心的同心环区域重叠，以欧氏距离较近的中心优先；距离相同则行号较小者优先，再同则列号较小者优先。

**关键洞察**：展开中心从未在输入中直接标记——它们是红种子列集与绿种子行集的笛卡尔积的涌现结果。中心数量等于两类种子数量之积，而非之和。
