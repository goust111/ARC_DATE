## 新题 6：噪声中检测矩形后图着色分组

**组合逻辑**：[最大矩形检测/max_rect_detection + 最小边长过滤/min_side_filter](已有) → [二部图结构/bipartite_structure + 交替着色/alternating_coloring](创新改造：二部图节点不是墙分隔的区域，而是从噪声中检测出的矩形，边由矩形的空间邻接定义)

**来源原语**：最大矩形检测/max_rect_detection、最小边长过滤/min_side_filter、纯色实心矩形/solid_mono_rect、噪声背景/noisy_background、重涂色/recolor（参考题 25094a63）；二部图结构/bipartite_structure、交替着色/alternating_coloring、四邻接连通/four_neighbor_connect（参考题 3bd292e8）

**依赖链**：必须先从噪声中检测出所有合格矩形，才能构建矩形间的邻接图；必须分析邻接图的二部结构，才能确定每个矩形的最终颜色。检测结果直接决定图结构，图结构决定着色。

从噪声网格中找出所有大矩形，根据矩形之间是否空间相邻构建二部图，交替涂色为黄(4)和绿(3)。

**输入结构**：约 18x18 的网格，每个像素的颜色从 0~9 中随机选取，形成多色噪声背景。隐藏在噪声中有 3~5 个同色实心矩形（每个矩形内部所有像素颜色相同），宽高均 >= 4。不同矩形的颜色可以不同。部分矩形之间存在 4-连通邻接（矩形边缘像素在上下左右方向上距另一个矩形的边缘像素恰好 1 格，中间仅隔一列/行噪声像素；或矩形直接共享一条边）。不同示例中矩形的颜色、位置、大小和邻接关系不同。生成约束：所有检测出的矩形构成一个连通的邻接图，且该图是二部图（无奇数环）；噪声中不存在其他宽高均 >= 4 的同色矩形区域。

**规则**：
1. 找出所有最大同色矩形（宽 >= 4 且高 >= 4）。"最大"指该矩形不能在保持同色的前提下向任意方向扩展一行或一列。
2. 构建邻接图：若两个检测出的矩形之间的最小 Manhattan 距离 <= 1（即边缘像素 4-连通相邻或共享一条边），则两矩形之间连一条边。
3. 对邻接图进行二部着色：找到与网格左上角距离最近（按矩形左上角的 Manhattan 距离）的矩形，将其标记为黄(4)。与之相邻的矩形标记为绿(3)，再相邻的标记为黄(4)，交替进行。
4. 将每个检测到的矩形的所有像素重涂为其被分配的颜色（黄(4)或绿(3)）。
5. 所有不属于检测矩形的像素保持原样不变。

**关键洞察**：矩形不是全部涂成同一种颜色——它们的最终颜色取决于矩形之间的空间邻接关系，邻接图的二部结构决定了哪些矩形是"同一阵营"，而这个图只有在完成检测后才能构建。
