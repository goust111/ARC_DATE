## 新题 4：去重压缩后菱形轮廓半径调整

**组合逻辑**：[压缩/compress + 去重/deduplicate + 合并相同行列/merge_identical_row_col](已有) → [收缩/shrink + 膨胀/dilate + 颜色决定操作/color_det_operation + 半径微调/radius_adjust](创新改造：在压缩后的坐标系中执行半径调整，而非原始坐标系)

**来源原语**：压缩/compress、去重/deduplicate、合并相同行列/merge_identical_row_col（参考题 e1baa8a4）；收缩/shrink、膨胀/dilate、菱形轮廓/diamond_outline、颜色决定操作/color_det_operation、半径微调/radius_adjust（参考题 d753a70b）

**依赖链**：输入的重复行列使菱形轮廓在视觉上被拉伸变形，直接在原始网格中无法正确识别菱形的中心和半径。必须先压缩去除重复行列，恢复真实几何关系，才能识别菱形并执行半径调整。

将拉伸变形的网格压缩为真实尺寸，再对压缩后网格中的红色菱形收缩一层、灰色菱形膨胀一层。

**输入结构**：约 20x20 的网格，橙(7)为背景。网格是一个约 10x10 的底层图案经行列重复拉伸而成（每行/每列被复制 1~3 次，形成相邻的完全相同行/列）。底层图案中包含 2~3 个一像素厚的 Manhattan 菱形轮廓，颜色为红(2)或灰(5)（不同菱形颜色可不同），另有 0~1 个蓝(1)菱形轮廓保持不变。菱形的 Manhattan 半径在 2~4 之间，中心不重合。不同示例中行列重复倍数、菱形位置和半径不同。生成约束：压缩后网格中菱形之间不重叠；红色菱形半径 >= 2（收缩后仍可见）；灰色菱形膨胀后不超出压缩网格边界。

**规则**：
1. 识别所有相邻完全相同的行组和列组，每组只保留第一行/列，得到压缩后的网格。
2. 在压缩网格中，识别红(2)和灰(5)的一像素厚 Manhattan 菱形轮廓，确定每个菱形的中心坐标和半径 r。
3. 清除所有红(2)和灰(5)菱形像素（恢复为橙(7)背景）。
4. 红(2)菱形以相同中心、半径 r-1 重新绘制，颜色不变。
5. 灰(5)菱形以相同中心、半径 r+1 重新绘制，颜色不变。
6. 蓝(1)菱形保持原位不变。
7. 输出为压缩后的网格（尺寸小于输入）。

**关键洞察**：重复的行列是对真实几何的伪装——在拉伸后的网格中，菱形的"轮廓"不再是等距的 Manhattan 距离圈，只有压缩后才能恢复菱形的本来面目并正确执行半径调整。
