## 新题 8：墙分隔区域的同心色带与邻域相位约束

**组合逻辑**：[洪泛填充/flood_fill + 距离决定调色板/distance_determines_palette + 循环色带/cyclic_color_bands](已有) ←约束→ [四邻接连通/four_neighbor_connect + 二部图结构/bipartite_structure](创新改造：二部性不决定区域颜色本身，而决定同心色带的起始相位偏移)

**来源原语**：洪泛填充/flood_fill、分区区域/partitioned_region、标记像素/marker_pixel、同心正方形层/concentric_square_layers、距离决定调色板/distance_determines_palette、循环色带/cyclic_color_bands（参考题 13e47133）；分隔墙线/separator_wall、背景区域/background_region、四邻接连通/four_neighbor_connect、二部图结构/bipartite_structure、交替着色/alternating_coloring（参考题 3bd292e8）

**依赖链**：标记像素的深度决定区域的调色板，但调色板的起始相位（从第 0 层开始还是第 1 层开始）由邻接区域的二部着色决定。两个共享墙壁的区域必须使用相反的起始相位——即使它们的调色板完全相同，最外层颜色也不同。单独的同心填充不足以确定相位，单独的二部着色不提供调色板内容。

墙壁分隔的区域内部按标记像素深度生成循环色带，但相邻区域的色带必须以相反相位起步，形成棋盘式的视觉节奏。

**输入结构**：约 15x15 的网格，黑(0)背景。栗(9)颜色的一像素厚墙线将网格分隔为 4~6 个不规则的 4-连通背景区域（每个区域约 15~40 像素）。每个区域内有 1~3 个标记像素，颜色从蓝(1)、红(2)、绿(3)、黄(4)中选取，位于距区域边界不同 Chebyshev 距离的位置（距离值从 0 到 3 不等）。若区域内无标记像素在边界上（距离=0），则该区域的底色（黑(0)）作为调色板的第一个颜色。不同示例中区域形状、标记像素颜色和深度不同。生成约束：墙线将所有区域构成一个连通的邻接图，且该图为二部图；每个区域至少 1 个标记像素；同一区域内不同标记像素位于不同 Chebyshev 深度。

**规则**：
1. 识别栗(9)墙线和被其分隔的 4-连通背景区域。
2. 对每个区域，读取其标记像素及它们到区域边界的 Chebyshev 距离 d，按 d 升序排列颜色得到调色板 P（若 d=0 无标记，则 P 以黑(0)开头）。
3. 构建区域的邻接图（共享墙壁的区域连边）。找到包含网格左下角像素的区域，标记为 A 组（相位偏移=0）；与之相邻的区域标记为 B 组（相位偏移=1）；交替传播。
4. 对每个区域中的每个像素，计算其到该区域边界的 Chebyshev 距离 d_cell。该像素的颜色 = P[(d_cell + 相位偏移) mod len(P)]。
5. 标记像素被色带覆盖（不保留原标记色）。
6. 墙线像素保持栗(9)不变。

**关键洞察**：同一套调色板在两个相邻区域中因相位偏移不同而呈现不同的最外层颜色——这不是独立的区域填充问题，而是一个受邻域拓扑约束的全局协调问题。
