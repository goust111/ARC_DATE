## 新题 7：射线阻影区与周期瓦片修复

**组合逻辑**：[射线延伸/ray_extend + 碰撞停止/collision_stop](已有) → [周期推断/periodic_inference + 忽略缺失值推断/ignore_missing_to_infer](创新改造：不仅黑色缺失像素被忽略，射线覆盖的区域也被排除在推断之外) → [填充/fill](创新改造：被射线阻影的缺失像素填充为阻影源的颜色而非瓦片色)

**来源原语**：射线延伸/ray_extend、碰撞停止/collision_stop、障碍块/obstacle_block（参考题 e87109e9）；周期推断/periodic_inference、忽略缺失值推断/ignore_missing_to_infer、周期瓦片/repeating_tile、缺失像素/missing_pixel（参考题 1d0a4b61）；填充/fill（参考题 c4d1a9ae）

**依赖链**：阻影源像素发射射线确定"被污染区"；周期推断必须同时忽略黑色缺失和被污染区才能推断正确瓦片；最终填充时，未被污染的缺失像素用瓦片色修复，被污染的缺失像素用阻影源色覆盖。三步形成信息分流——同一种缺失像素的修复策略取决于是否处于射线阴影中。

将阻影源的射线投影区标记为"污染区"，推断周期瓦片时排除污染区和缺失区，修复缺失像素时根据是否被污染选择不同颜色源。

**输入结构**：约 14x14 的网格。网格主体是一个周期重复的彩色壁纸图案（瓦片约 3x3 或 4x4，使用蓝(1)、绿(3)、黄(4)中的 2~3 种颜色），部分单元格被替换为黑(0)（缺失像素，约占 15~25%）。另有 1~2 个"阻影源"像素，颜色为红(2)，位于网格中非缺失位置（覆盖了原壁纸像素）。不同示例中瓦片的图案、大小、缺失像素位置和阻影源位置不同。生成约束：阻影源不在网格边缘；去除阻影源和缺失像素后，壁纸图案的每个瓦片相位至少出现一次；阻影源的射线路径上至少有 2 个黑色缺失像素。

**规则**：
1. 从每个红(2)阻影源像素出发，向四个基本方向（上、下、左、右）发射射线。射线逐格前进，标记所经过的黑(0)缺失像素为"被污染"。射线遇到非黑非背景的壁纸色像素时停止（不标记该终点）；遇到网格边界也停止。
2. 推断周期瓦片：忽略所有黑(0)像素和红(2)阻影源像素，仅使用壁纸色像素推断最小周期瓦片（方法同参考题 1d0a4b61：找行列周期使所有可见像素与其瓦片相位一致）。
3. 对未被污染的黑(0)缺失像素，用其对应瓦片相位的颜色填充。
4. 对被污染的黑(0)缺失像素，用污染它的阻影源的红(2)色填充。
5. 阻影源像素本身保留红(2)不变。

**关键洞察**：黑色缺失像素不全是等价的——阻影源的射线将某些缺失像素"据为己有"，这些像素被修复为阻影源的颜色而非壁纸的周期色。必须先确定射线阴影范围，才能知道哪些缺失像素可以用瓦片修复。
