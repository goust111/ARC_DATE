## 新题 3：边框定向平移后印章覆盖

**组合逻辑**：[颜色匹配边/color_match_side + 朝匹配边移动/move_toward_match](已有) → [印章覆盖/stamp + 以标记为中心印章/stamp_on_marker_center](创新改造：印章中心不是原始标记位置，而是平移后的位置) + [内部包含/containment](已有，用于裁剪)

**来源原语**：边框边/frame_side、内部像素/interior_pixel、颜色匹配边/color_match_side、朝匹配边移动/move_toward_match（参考题 5034a0b5）；印章覆盖/stamp、十字模板/crosshair_template、标记像素/marker_pixel、内部包含/containment（参考题 264363fd）；矩形/rectangle（参考题 264363fd）

**依赖链**：标记像素的颜色匹配到边框侧，决定平移方向；平移后的位置成为印章中心；印章臂被矩形边界裁剪。三步首尾相连——不知道边框颜色就无法平移，不平移就无法确定印章位置，不知道矩形边界就无法裁剪。

标记像素先朝匹配的边框侧平移一格，再以新位置为中心印上十字模板，模板臂超出所在矩形的部分被裁剪。

**输入结构**：约 15x15 的网格，黑(0)背景。网格最外一圈为一像素厚的边框：四个角落像素为黑(0)，上边为蓝(1)、下边为红(2)、左边为绿(3)、右边为黄(4)（每条边颜色统一且互不相同）。网格内部有 2~3 个互不重叠的实心矩形（橙(7)，宽高各 5~8 像素），每个矩形内部有 1~2 个标记像素，标记像素颜色为蓝(1)/红(2)/绿(3)/黄(4)中的一种（匹配某条边框边的颜色）。另有一个 3x3 的十字模板精灵体位于网格内部的背景区域（不在任何矩形内），十字模板由品红(6)像素组成（中心 1 像素 + 上下左右各 1 像素，共 5 像素）。不同示例中矩形的位置和大小、标记像素的位置和颜色、十字模板的位置可以不同。生成约束：标记像素不位于矩形的最外一行/列（即平移一格后仍在矩形内部）；十字模板与所有矩形不重叠。

**规则**：
1. 边框和十字模板精灵体在输出中保持不变。
2. 对每个标记像素，确定其颜色匹配的边框侧方向：蓝(1)→上、红(2)→下、绿(3)→左、黄(4)→右。
3. 将标记像素从原位置擦除（恢复为所在矩形的橙(7)色），并在朝匹配方向平移一格的位置重新放置该标记像素。
4. 以平移后的标记像素为中心，将十字模板的品红(6)像素印章到网格上。印章仅在标记像素所属矩形的边界框内部生效——超出矩形的十字臂部分不绘制。
5. 若印章像素落在矩形的橙(7)像素上，用品红(6)覆盖；若落在另一个标记像素上，也用品红(6)覆盖。
6. 多个标记像素按其在网格中从左到右、从上到下的顺序依次处理，后处理的印章覆盖先处理的。

**关键洞察**：边框的四种颜色并非装饰，而是每个标记像素的移动指令——平移改变了印章中心，导致最终印章图案偏离标记的原始位置，而矩形边界又进一步裁剪了印章形态。
