## 新题 6：类型分支对齐重涂色

**组合逻辑**：[分类(classify)](已有) + [行列对齐(row_col_align)](已有) + [重涂色(recolor)](创新：重涂色方式由对象类型决定——同一颜色信号在不同类型对象上产生不同视觉效果)

**来源原语**：分类(classify)、空心矩形(hollow_rectangle)、实心方块(solid_square)、内部判定类型(interior_determines_type) ← 2ba387bc；重涂色(recolor)、分隔线网格(separator_grid)、行列对齐(row_col_align)、对齐标记定颜色(aligned_marker_color)、单像素标记(singleton_marker) ← ef26cbf6

**依赖链**：分隔线网格定位单元格（空间依赖），单元格内对象被分类为空心框或实心块（分类依赖于定位），行列对齐确定每个对象应被涂的颜色（颜色依赖于对齐），但涂色规则因类型而异——空心框只涂边框，实心块全部涂色（涂色方式依赖于分类结果）。分类和对齐分别独立提供信息，两者在涂色环节交汇。

在分隔线网格中，按行/列对齐找到颜色标记，将标记色应用于同行/列的对象——但空心框只重涂边框像素，实心块整体重涂。

**输入结构**：
- 网格约 15×15，背景黑(0)。
- 灰(5)像素构成完整的水平和垂直分隔线，将网格划分为 3×3 或 4×4 的规则单元格阵列。每个单元格内部约 3×3。
- 部分单元格内包含一个居中的 3×3 对象：要么是空心矩形框（外圈一种颜色、内部 1×1 为黑(0)），要么是 3×3 的实心方块（全部填充同一种颜色）。这些对象初始颜色统一为白/栗(9)。
- 每行（或每列）的单元格中恰好有一个"标记单元格"，其中只包含一个单像素标记点，颜色为红(2)、蓝(1)、绿(3)或黄(4)中的某一种。
- 其余单元格为空（全黑(0)）。
- 生成约束：每个包含对象的单元格所在行或列中恰好有一个标记单元格（不会同时在行和列中各有一个标记），确保颜色指定唯一。

**规则**：
1. 找到灰(5)分隔线划分的单元格阵列。
2. 识别每个单元格的内容类型：空心框、实心块、单像素标记或空。
3. 对每个包含空心框或实心块的单元格，找到与之同行或同列的那个标记单元格，读取标记颜色 C。
4. 若该对象是空心框：将边框像素（外圈）重涂为颜色 C，内部保持黑(0)。
5. 若该对象是实心块：将全部 3×3 像素重涂为颜色 C。
6. 分隔线和标记像素在输出中保持不变。

**关键洞察**：同一套对齐机制（行/列对齐找标记色）对不同类型的对象产生不同的涂色效果。从单个示例中，如果所有对象恰好都是同一类型，则无法发现类型分支规则。必须看到两种类型并存的示例才能归纳出完整规则。
