## 新题 5：计数器门控对角约束拼合

**组合逻辑**：[计数(counting)](已有) → [对角线输出(diagonal_output)](创新：对角线不是最终输出，而是拼合的禁止区) + [拼合填充(packing)](创新：必须绕开对角线约束)

**来源原语**：计数(counting)、计数器像素(counter_pixel)、计数器消失(counter_disappears)、计数决定偏移(count_determines_offset) ← e48d4e1a；对角线标记(diagonal_marker)、数量决定边长(count_determines_side)、对角线输出(diagonal_output) ← d0f5fe59；多连块碎片(polyomino_fragment)、拼合填充(packing)、无重叠拼合(non_overlap_packing)、按面积降序放置(descending_area_place) ← b7cb93ac

**依赖链**：计数器决定输出方阵边长 N（尺寸依赖），N 决定对角线位置（约束依赖），对角线作为禁止区约束拼合操作的可用空间（拼合依赖于前两步）。删除计数则无法确定网格大小；删除对角约束则拼合退化为源题的无约束版本。

统计灰色计数器像素得 N，构建 N×N 方阵，将主对角线标记为禁区（填灰色），再将散落的多连块碎片无重叠地拼入非对角线区域。

**输入结构**：
- 网格约 14×14，背景黑(0)。
- 网格最右列包含若干灰(5)像素（从顶部开始连续排列），数量为 N（4-6）。其余最右列位置为黑(0)。
- 网格其余区域散布若干单色 4-连通多连块碎片（每块 2-5 像素），每块颜色不同，如红(2)、蓝(1)、绿(3)、黄(4)、橙(7)。碎片互不重叠、互不相邻。
- 生成约束：所有碎片的总面积恰好等于 N×N - N（即方阵面积减去对角线格数），确保拼合恰好填满。

**规则**：
1. 统计最右列中灰(5)像素的数量，记为 N。
2. 构建一个 N×N 的输出方阵，初始全黑(0)。
3. 将主对角线位置（(0,0)、(1,1)、...、(N-1,N-1)）填入灰(5)，这些位置不可放置碎片。
4. 将碎片按面积从大到小排序；面积相同时，按碎片在输入中的边界框左上角位置从左到右、从上到下排序。
5. 按排序顺序，对每个碎片尝试其原始方向以及 90°/180°/270° 旋转和水平镜像的所有朝向（共最多 8 种），在输出方阵的非对角线空位中从上到下、从左到右扫描第一个可放置位置，放入碎片。
6. 最右列的灰色计数器像素在输出中消失（不出现在输出网格中）。

**关键洞察**：对角线在源题中是最终输出内容，但这里它是拼合过程中的几何障碍。计数器的数值同时决定了两个相互依赖的约束——棋盘大小和障碍物位置。需要对比多个示例确认对角线是固定禁区（而非某种动态障碍）以及计数器与棋盘边长的等量关系。
