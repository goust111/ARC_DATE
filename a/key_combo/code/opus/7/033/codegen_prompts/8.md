## 新题 8：四重旋转对称补全中标记像素阻断填充

**组合逻辑**：[补全/complete + 镜像/mirror](创新：四重旋转对称而非简单镜像) → [标记像素阻断](创新：标记位置阻止对称位的填充) → [擦除/erase] → [冲突解决]（同时约束满足结构，非线性流水线）

**来源原语**：补全/complete（来自 6d75e8bb）；镜像/mirror、翻转对应/flip_correspond（来自 cfb2ce5a）；标记像素/marker_pixel（来自 36fdfd69）；擦除/erase（来自 952a094c）；控制定颜色映射/ctrl_color_map（来自 cfb2ce5a）

**依赖链**：网格具有近似四重旋转对称性但有缺损和标记像素。补全对称性需要将已有像素旋转复制到缺损位置，但标记像素会阻止其旋转对称位的填充——标记位置本身也变为背景。这形成了一个同时约束满足问题：每个像素位置的最终状态取决于其四个旋转对称位中是否有已知颜色像素和是否有标记像素，两种信息相互制约。

对称性填充规则与标记阻断规则在同一像素位置上可能冲突，产生的"被阻断的空洞"是两条规则交互的涌现结果。

**输入结构**：黑(0)背景的正方形网格，边长为奇数（约 13x13 至 17x17），中心像素为网格中心。网格上有一个围绕中心的彩色图案，图案使用 2-3 种非黑非红颜色（从蓝(1)、绿(3)、黄(4)、青(8)、橙(7)中取）。该图案具有近似的 90 度旋转对称性（以网格中心为旋转中心），但有若干缺损：部分本应有像素的位置是黑(0)背景。此外，网格中有 2-4 个红(2)标记像素，位于图案的非缺损位置上（即标记像素替换了原本应有的彩色像素）。生成约束：对于每个旋转对称组（由同一位置旋转 0/90/180/270 度得到的四个格点），至少有一个格点包含非黑非红的彩色像素（保证对称性可推断）。标记像素的四个旋转对称位中，至少有一个位置是缺损（黑色），使标记阻断效果可观察。

**规则**：
1. 确定网格中心为旋转中心。对于网格中每个像素位置 P，其旋转对称组包含 P 本身及 P 绕中心旋转 90/180/270 度后的三个位置（共四个位置，若 P 在中心则组只有一个位置）。
2. 对每个旋转对称组，收集组内所有非黑(0)非红(2)的彩色像素。若组内有彩色像素，则该组的"目标色"为该彩色像素的颜色（生成约束保证同组内若有多个彩色像素则颜色相同）。
3. 对组内每个缺损位置（黑(0)），检查该组内是否有红(2)标记像素：
   - 若组内无红(2)标记：将所有缺损位置填充为目标色
   - 若组内有红(2)标记：所有缺损位置保持黑(0)不填充
4. 组内的红(2)标记像素在输出中擦除为黑(0)。
5. 组内原有的彩色像素保持不变。
6. 若旋转对称组内全为黑(0)和/或红(2)（无彩色像素），则该组所有位置在输出中均为黑(0)。

**关键洞察**：红色标记不仅自身消失，还会"传染性地"阻止同一旋转对称组中所有缺损位置的填充——求解者必须理解标记的阻断作用是按旋转对称组整体生效的，而非仅影响标记的直接对称位。
