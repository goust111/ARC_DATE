## 新题 5：不完整矩形补全后按标记计数决定棋盘相位

**组合逻辑**：[补全/complete + 边界框推断/bbox_inference] → [计数/counting](创新：标记像素数量编码棋盘相位) → [棋盘格填充/parity_fill + 边框与内部分离/border_interior_split] → [擦除/erase]

**来源原语**：补全/complete、边界框推断/bbox_inference、缺失像素补新色/missing_new_color（来自 6d75e8bb）；棋盘格图案/checkerboard、行列奇偶决定填充/parity_fill、边框与内部分离/border_interior_split、实心矩形/solid_rectangle（来自 ba9d41b8）；计数/counting（来自 f3cdc58f）；标记像素/marker_pixel（来自 36fdfd69）；擦除/erase（来自 952a094c）

**依赖链**：先推断边界框并补全矩形边框，确定哪些像素属于内部；然后计数内部的标记像素数量，该计数的奇偶性决定棋盘图案的相位；最后在内部应用对应相位的棋盘镂空并擦除标记。补全决定了内部范围，计数决定了棋盘朝向，两者缺一不可。

边界框推断→补全→内部确定→标记计数→棋盘相位，形成环环相扣的信息链，每一步的输出都是下一步的必要输入。

**输入结构**：黑(0)背景网格，约 18x18。网格中有 3-4 个不完整的单色矩形，每个矩形使用不同的非黑、非红颜色（从蓝(1)、绿(3)、黄(4)、青(8)中取）。"不完整"指矩形边框的 1-3 条边上有像素缺失（被黑(0)替代），但每条边至少保留一个像素使边界框可唯一推断。每个矩形至少 5x5（边框 1 像素宽，内部至少 3x3）。矩形互不重叠且边界框互不相交。每个矩形的边界框内部（不含边框像素）散布有 1-4 个红(2)标记像素，位于内部的不同位置。生成约束：同一个矩形内部的标记像素数量在不同示例中可能不同，但同一道题内不同矩形的标记数量至少有两个不同值（保证奇偶性不全相同）。

**规则**：
1. 对每种前景色，找到该颜色所有像素的最小边界框——这就是该矩形的完整边界。
2. 补全边框：将边界框四条边上所有缺失的像素（黑(0)）填充为该矩形的颜色。
3. 统计每个矩形边界框严格内部（不含边框）的红(2)标记像素数量 K。
4. 对每个矩形的严格内部，以内部左上角为原点，对每个内部像素计算 (local_row + local_col) 的值：
   - 若 K 为奇数：(local_row + local_col) 为偶数的内部像素设为黑(0)（背景色），其余保持矩形颜色
   - 若 K 为偶数：(local_row + local_col) 为奇数的内部像素设为黑(0)（背景色），其余保持矩形颜色
5. 所有红(2)标记像素在输出中擦除为黑(0)（无论其位置是否被棋盘规则保留）。
6. 矩形边框像素始终保留，不受棋盘规则影响。

**关键洞察**：红色标记的数量——而非位置——决定了棋盘镂空的相位；求解者必须从多个示例中归纳出"标记计数的奇偶性控制棋盘对齐方式"这条隐蔽规则。
