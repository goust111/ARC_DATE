## 新题 3：对接拼装后的孔洞检测驱动描边与内填

**组合逻辑**：[拼接/stitch + 同色标记对齐对接/same_color_dock] → [封闭孔洞检测](创新：孔洞仅在对接后才涌现) → [有孔触发重涂/hole_presence_triggers_recolor + 描边/draw_outline + 填充/fill]

**来源原语**：拼接/stitch、同色标记对齐对接/same_color_dock、连接标记/connector_marker、标记侧面决定方向/marker_side_dir（来自 e9fc42f2）；描边/draw_outline、有孔触发重涂/hole_presence_triggers_recolor、封闭孔洞/enclosed_hole、包含关系/containment（来自 aa4ec2a5）；填充/fill（来自多题）

**依赖链**：多个分离的前景物体各自没有封闭孔洞，但通过连接标记对接拼装后，某些物体组合围出了封闭的背景孔洞。孔洞的存在触发了围合物体的重涂色和孔洞的填色，随后对整个拼装体描边。哪些物体参与围合、孔洞在哪里，都只有在完成对接后才能判断。

对接操作创造了单个物体中不存在的拓扑结构（封闭孔洞），该涌现结构反过来触发后续的颜色变换，形成"组装→拓扑涌现→条件触发"的推理链。

**输入结构**：黑(0)背景网格，约 22x22。网格中散布 4-6 个互不相邻的 4-连通多色前景物体，每个物体约 8-20 像素。所有物体共享同一种主体色（蓝(1)），但每个物体边界上有 1-2 个不同颜色的连接标记像素（从红(2)、绿(3)、黄(4)、橙(7)中取）。每种连接标记颜色恰好出现两次（分别在两个不同物体上），或出现一次（自由端，不参与对接）。标记像素位于物体的最外层像素（上/下/左/右边界），标记所在的边决定了对接方向。生成约束：每个物体单独看不含封闭的背景孔洞（即物体的 4-连通补集只有一个连通分量），但按连接标记对接拼装后，至少有一组物体（2-3 个）围出 1-2 个封闭的 4-连通背景孔洞。至少有一个物体对接后不参与围合任何孔洞。

**规则**：
1. 对每种出现两次的连接标记颜色，找到携带该标记的两个物体。确定每个标记像素在其物体中的边界方向（标记像素暴露的一侧：若标记在物体最上一行则方向为上，以此类推）。
2. 平移物体使两个同色标记像素在各自暴露方向上相邻（面对面接触）。对接后两个标记像素保留，物体其余部分保持原样。处理顺序：按标记颜色在调色板中的编号从小到大依次对接（先处理红(2)，再绿(3)，依此类推）。每次对接时固定已对接部分的位置，平移尚未连接的物体。
3. 拼装完成后，检测整个拼装体（所有已对接物体组成的 4-连通整体）内部的封闭 4-连通背景孔洞。
4. 对于包含封闭孔洞的拼装体：将所有参与围合该孔洞的物体像素（主体色蓝(1)和标记色）中的蓝(1)像素重涂为青(8)，标记像素颜色不变；将封闭孔洞填充为品红(6)。
5. 不参与围合任何孔洞的物体保持蓝(1)不变。
6. 最后，对整个拼装体（含重涂和填充后的所有像素）绘制一圈红(2)的 8-邻域描边（距拼装体像素 8-邻域距离为 1 的背景像素涂红(2)）。未参与对接的自由端物体也单独描边。

**关键洞察**：单个物体都不含孔洞——封闭孔洞是对接拼装后的涌现结构，因此重涂和填充的触发条件只有在完成空间组装后才能判定。
