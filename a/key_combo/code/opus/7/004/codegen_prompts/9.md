## 新题 9：双重约束筛选——引导条投射与迷宫连通性同时满足

**组合逻辑**：[压缩/投射到引导条](已有) + [洪泛填充/路径连通](创新：连通性不用于填充而用于筛选像素存活资格) —— 同时约束满足结构：两个独立条件必须同时成立，无固定执行顺序

**来源原语**：压缩/compress、引导条/guide_bar、散布像素/scattered_pixel、投射到引导条/project_to_guide、投射落间隙则擦/erase_if_gap（参考题 f83cb3f6）；洪泛填充/flood_fill、迷宫走廊/maze_corridor、种子像素/seed_pixel、路径连通/path_connectivity（参考题 b782dc8a）

**依赖链**：两个独立约束同时作用于每个散布像素：约束 A（引导条列对齐）判定投射是否有效；约束 B（迷宫连通性）判定像素是否可达种子。两个约束均满足的像素才出现在输出中，颜色由可达种子的颜色决定。无优先顺序，是逻辑与关系

散布像素必须同时满足两个条件才能出现在输出中：其列对应引导条实体段（非间隙），且经迷宫走廊 4-连通可达某个种子像素。

**输入结构**：黑(0)背景，约 16x16。一条红(2)水平引导条在网格中部，厚度 1 像素，有 2~3 个间隙。青(8)像素构成迷宫墙壁，分布在引导条上方和下方区域，形成宽度 1 的走廊网络。2 个种子像素分别为蓝(1)和绿(3)，位于走廊中（不在引导条上）。若干黄(4)散布像素（5~8 个）分布在走廊内。生成约束：部分散布像素所在列对应引导条实体段但不连通种子（仅满足 A）；部分散布像素连通种子但所在列对应间隙（仅满足 B）；部分散布像素两个条件均满足；至少 1 个像素两个条件均不满足。

**规则**：
1. 识别红(2)引导条及其间隙位置。
2. 对每个黄(4)散布像素 (r, c)：
   a. 条件 A：引导条在列 c 处是否有红(2)像素（非间隙）。
   b. 条件 B：从 (r, c) 出发，仅经过黑(0)背景像素做 4-连通搜索，是否能到达某个种子像素（蓝(1)或绿(3)）。青(8)墙壁和红(2)引导条均不可通过。
3. 仅当 A 和 B 同时满足时，将该像素沿垂直方向投射到引导条紧邻行（上方像素到引导条上方一行，下方像素到引导条下方一行），投射后的颜色为其可达的种子颜色（若可达多个种子，取 4-连通路径最短的种子的颜色；若路径等长，取行号较小的种子的颜色）。
4. 不满足任一条件的散布像素被擦除为黑(0)。
5. 引导条、迷宫墙壁、种子像素保持不变。

**关键洞察**：引导条间隙和迷宫墙壁是两套独立的空间过滤机制——间隙在列维度上筛选，迷宫在拓扑维度上筛选。求解者不能单独应用其中一套规则，必须理解两者的逻辑与关系，且投射后的颜色由连通性中的种子身份决定，进一步耦合了两个约束。

3. 生成器必须保证输入满足 `main()` 的隐式假设：对象不重叠、不越界、特殊标记唯一或可区分、匹配关系无歧义、关键分支出现概率相同。
4. 禁止把 ARC 颜色 id 、亮度、拼写等当作人类不可见的数值语义参与排序、大小比较或隐藏映射。颜色变化必须有可见结构线索。注意颜色亮度、拼写等也是不可见信息，若描述中出现违规的颜色id或者亮度，可自行使用少量的固定颜色替代，但注意生成时要在三个以内输入输出网格中对所有变换100%覆盖度。
