## 新题 6：按面积排名重涂色后做对称补全

**组合逻辑**：[排序/面积比较](创新：排名属性从长度改为像素面积) + [重涂色/颜色图例](已有) + [对称补全/对称轴借用](已有) —— 排名 -> 重涂色 -> 对称反射，但排名决定的颜色会被对称传播，形成"排名信息的几何扩散"

**来源原语**：排序/sort、面积比较/area_comparison、长度排名/length_ranking、颜色图例/color_legend、重涂色/recolor、高度即排名索引/legend_height_as_rank_index（参考题 97d7923e）；对称补全/symmetry_completion、镜像/mirror、对称体/symmetric_object、非对称体/asymmetric_object、对称轴借用/axis_borrowed、借轴复制非对称体/axis_replicates_asym（参考题 4c5c2cf0）

**依赖链**：面积排名决定每个碎片的新颜色 -> 重涂色后的碎片携带新颜色做对称补全 -> 对称反射传播排名信息到其他象限。删除排名步骤则颜色不确定；删除对称步骤则只有一个象限有内容；删除重涂色则排名信息无处落地

按面积排名查图例重涂色多个非对称碎片，然后借用对称锚点的双轴做四折对称补全。

**输入结构**：黑(0)背景，约 18x18。网格中央有一个灰(5)对称锚点对象，同时具有水平和垂直镜像对称性（如十字形、菱形等 4-连通形状，6~12 像素）。在锚点对称轴划分的四个象限中，仅左上象限包含 2~3 个单色小碎片（4-连通，3~6 像素，形状各异，非矩形），碎片颜色均为橙(7)。网格底部一行为颜色图例：2~3 个不同颜色的单像素点（如红(2)、蓝(1)、绿(3)），从左到右排列，间隔 1 像素。生成约束：碎片数量等于图例颜色数。各碎片像素面积互不相同。碎片不与对称锚点相邻。

**规则**：
1. 识别灰(5)对称锚点，确定其水平对称轴 (行 ar) 和垂直对称轴 (列 ac)。
2. 在左上象限中找到所有橙(7)碎片，按像素面积从大到小排序。最大面积为排名 1，次大为排名 2，依此类推。
3. 读取底部图例行：从左到右依次为颜色 C1, C2, C3...。排名 k 的碎片重涂为 Ck。
4. 对每个重涂后的碎片的每个像素 (r, c)，在其他三个象限绘制对称副本：(r, 2*ac - c)、(2*ar - r, c)、(2*ar - r, 2*ac - c)，颜色与重涂后的碎片相同。
5. 对称锚点保持灰(5)。图例保持不变。左上象限的原始碎片以重涂后的颜色保留。

**关键洞察**：对称补全传播的不是碎片的原始颜色，而是由面积排名通过图例映射后的新颜色——需要先完成排名-查表-重涂色的推理链，才能知道对称反射应该用什么颜色，单看任一步骤都无法确定最终输出。

## 实现要求

1. `main(grid)` 必须实现新题描述中的确定性转换规则，不能只识别 `generate_input()` 的固定模板。禁止不同的input网格输出相同的output网格。
2. `generate_input()` 必须随机生成多样样例，不能固定死。随机维度应覆盖：网格大小、对象数量、位置、颜色、方向、形状参数或关键分支。注意若描述中存在若干，需实现而不是只有单个，包括object或者对应关系等等。
3. 生成器必须保证输入满足 `main()` 的隐式假设：对象不重叠、不越界、特殊标记唯一或可区分、匹配关系无歧义、关键分支出现概率相同。
4. 禁止把 ARC 颜色 id 、亮度、拼写等当作人类不可见的数值语义参与排序、大小比较或隐藏映射。颜色变化必须有可见结构线索。注意颜色亮度、拼写等也是不可见信息，若描述中出现违规的颜色id或者亮度，可自行使用少量的固定颜色替代，但注意生成时要在三个以内输入输出网格中对所有变换100%覆盖度。
5. 输出样例要视觉清晰，人类必须能从输入输出对中肉眼辨认出规律。具体要求：避免对象粘连、覆盖关系混乱、同一像素多重语义；不同逻辑步骤产生的结果不要大面积层叠在一起导致无法分辨哪个颜色属于哪个步骤；输入中各元素之间保持足够间距，输出中新增的标记/填充/路径等应与背景和已有元素在颜色上有明显区分；若规则涉及多层叠加，生成时控制对象密度和尺寸，确保叠加区域只占少数像素而非铺满整个网格。
6. 若规则有多个分支，生成器不能长期固定成一个分支；应让分支在随机样例中合理出现。分支概率不必平均——难以发现的隐蔽分支（如少数情况下才触发的特殊规则）应适当提高出现概率，确保在 3 个训练示例中至少出现一次，否则求解者无法归纳该规则。对于颜色映射类规则，确保 2 个左右的示例即可覆盖所有映射关系（每种颜色→颜色的映射至少在某个示例中出现过）。
