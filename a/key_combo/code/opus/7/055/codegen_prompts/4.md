## 新题 4：格栅纯色单元格引导精灵体滑动归位

**组合逻辑**：[提取 extract + 格内判定 cell_interior_test](已有，识别纯色单元格) → [擦除 erase](已有，清除噪声单元格) → [滑动 slide](创新：目标不再是固定墙壁而是格栅中特定颜色的单元格位置，运动路径受格栅几何约束) + [碰撞停止 collision_stop](已有)

**来源原语**：提取、分隔线网格、纯色单元格、格内判定、纯色即有效、忽略干扰项（参考题 458e3a53）；滑动、碰撞停止、近者优先不重叠（参考题 f0100645）；擦除（参考题 87ab05b8）

**依赖链**：格栅分析→识别纯色单元格及其颜色和格栅坐标→颜色匹配将外部精灵体配对到目标单元格→精灵体沿格栅通道滑向目标，以分隔线为路径边界→噪声单元格清除后为滑动腾出空间。格栅同时承担三重角色：分析单元（区分信号与噪声）、运动路径约束、停止线。删除格栅分析则无法区分信号与噪声；删除颜色匹配则不知目标；删除滑动则精灵体不移动。

在一个由分隔线网格划分的画布中，识别少数纯色单元格作为目标、清除噪声单元格，然后将外围同色精灵体沿格栅通道滑向匹配颜色的目标单元格。

**输入结构**：约 19x19 网格。背景为黑(0)。橙(7)像素构成完整的水平和垂直分隔线（每条分隔线贯穿整个网格宽度或高度，宽度 1 像素），将网格分为若干矩形单元格（例如 4x4 的格栅布局，每个单元格内部约 3x3~4x4 像素）。大多数单元格内部填有重复的多色噪声图案（使用黑(0)以外的至少 2 种颜色混合），但有一个由 2x2 或 2x3 个相邻单元格组成的连续矩形区域，其中每个单元格内部为纯粹的单一颜色。这些纯色单元格各不相同，使用蓝(1)、红(2)、绿(3)、黄(4)中的 2~4 种颜色（每种颜色最多出现一个纯色单元格）。在网格的最外圈分隔线之外的边缘区域（宽 1~2 像素），存在若干 4-连通小精灵体（各 2~4 像素），每个精灵体的颜色与某个纯色单元格颜色相同，且每种纯色单元格颜色在外围恰好有一个对应精灵体。生成约束：每个精灵体沿水平或垂直方向与其目标纯色单元格对齐（即精灵体的行范围或列范围与目标单元格的行范围或列范围有交集）。

**规则**：
1. 用橙(7)分隔行和分隔列将网格切分为矩形单元格。检查每个单元格内部：若内部所有像素为同一种颜色，标记为纯色单元格并记录其颜色和格栅坐标。
2. 将所有非纯色单元格的内部清除为背景黑(0)（保留分隔线）。
3. 对每个外围精灵体，找到与其颜色匹配的纯色单元格作为目标。
4. 将精灵体沿其对齐方向（水平或垂直）向目标单元格滑动，保持精灵体形状不变。精灵体穿过分隔线（分隔线像素被精灵体临时覆盖，精灵体通过后分隔线恢复）。精灵体停在目标单元格外侧紧邻的分隔线位置（精灵体的最近边缘像素落在目标单元格相邻的分隔线上）。
5. 若两个精灵体的滑动路径相交，像素数少的精灵体先停（停在冲突位置前一个像素），像素数多的继续滑动。像素数相同时，距离目标更远的先停。
6. 橙(7)分隔线网格、纯色单元格内容保持不变。

**关键洞察**：格栅不仅是分析工具（区分信号与噪声），更是运动的物理通道——精灵体沿格栅结构滑动、在分隔线上停靠。纯色单元格的空间位置隐式编码了每个精灵体的目的地。
