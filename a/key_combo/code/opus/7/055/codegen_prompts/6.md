## 新题 6：极值高度竖条定义框架，框内环路弯折分类涂色

**组合逻辑**：[排序 sorting + 高度排名 height_ranking](已有) → [描框 draw_frame](创新：框的几何参数不来自控制像素的极值行列，而来自竖条高度排名的结果) → [包含 containment](已有，判定环路是否在框内) → [环路追踪 trace_cycle + 分类涂色 classify_and_color](已有) + [擦除 erase](已有，清除框外环路)

**来源原语**：排序、竖直线段、高度排名、保留极值高度分色（参考题 a61f2674）；描框、矩形框、极值行列、包含（参考题 e4075551）；环路追踪、闭合正交环路、弯折像素、直行像素、分类涂色、多数转向为凸、少数转向为凹（参考题 15663ba9）；擦除（参考题 87ab05b8）

**依赖链**：竖条高度排名→最高和最短竖条的列位置与高度定义矩形框的四个边→绘制框→判定每个闭合环路是否完全包含在框内→框内环路进行弯折分类涂色，框外环路擦除。三种分析类型（排名、包含判定、环路追踪）形成门控链：排名决定框的几何→框的几何决定哪些环路被处理→被选中的环路才进行弯折分析。删除排名则框未知；删除包含判定则所有环路都被处理（输出错误）；删除环路追踪则框内环路无法分类。

在散布着灰色竖条和绿色闭合环路的网格中，根据竖条高度排名确定最高和最短两根，用它们的列位置和高度定义一个矩形框；框内的环路按弯折凸凹分类涂色，框外的环路擦除。

**输入结构**：约 18x18 网格。背景为黑(0)。5~7 根灰(5)竖直线段（各 1 像素宽），底端均对齐在网格最底行，高度各不相同（从 3 到 15 像素不等，保证最高和最短的高度唯一）。竖条之间间隔至少 2 列。网格中还散布着 2~4 个由绿(3)像素构成的闭合正交环路，每个环路是 4-连通、1 像素宽的闭合回路，每个像素恰好有 2 个前景邻居。每个环路至少有 8 个像素、包含凸凹两种弯折。环路不与任何竖条像素重叠。生成约束：至少一个环路完全在"由最高和最短竖条定义的框"内部，至少一个环路部分或全部在框外。

**规则**：
1. 测量每根灰(5)竖条的高度（像素数）。找到高度最大的竖条（记其列为 C_tall、高度为 H_tall）和高度最小的竖条（记其列为 C_short、高度为 H_short）。
2. 定义矩形框的四条边：左边 = min(C_tall, C_short)，右边 = max(C_tall, C_short)，顶边 = 网格最底行行号 - H_tall + 1（即最高竖条的顶端所在行），底边 = 网格最底行。
3. 将最高竖条的像素重涂为蓝(1)，最短竖条的像素重涂为红(2)。擦除所有其他灰(5)竖条（设为背景）。
4. 用蓝(1)绘制框的左右两条垂直边（从顶边到底边），用红(2)绘制框的上下两条水平边（从左边到右边）。四个角像素使用蓝(1)。若框边与已重涂的竖条重合则不重复绘制。
5. 对每个绿(3)闭合环路，判定其边界框是否完全在矩形框的内部（严格在四条边以内，不接触框边）：
   - **完全在框内**：追踪该环路，统计弯折转向方向。多数转向方向的弯折为凸弯折→重涂为黄(4)；少数转向方向的弯折为凹弯折→重涂为红(2)；直行像素保持绿(3)。
   - **不完全在框内**：擦除该环路所有像素（设为背景黑(0)）。
6. 框的边线覆盖任何与之重叠的像素（框优先级最高）。

**关键洞察**：竖条的高度差异隐式编码了一个矩形边界——不是显式画出的框，而是从"最高"和"最短"的比较关系中涌现的空间结构。这个涌现的边界又成为门控条件，决定哪些环路值得进一步分析。
