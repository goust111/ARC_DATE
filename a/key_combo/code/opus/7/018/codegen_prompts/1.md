## 新题 1：嵌套深度定向射线

**组合逻辑**：[bbox_containment](已有) → [encoding_map](创新：嵌套深度→方向编码) → [ray_cast](已有，作用对象和触发条件均改变)

**来源原语**：bbox_containment、connected_component（#12 9720b24f）；ray_cast、collision_stop（#9 80a900e0）；encoding_map（#1 77fdfe62、#8 b91ae062）；recolor（#4 23581191）

**依赖链**：包围框包含层级分析确定每个对象的嵌套深度 → 深度值编码为射线发射方向 → 从对象顶点沿编码方向发射射线直至碰撞停止。三个环节缺一不可：无包含分析则方向未知，无方向编码则射线无序，无射线发射则深度信息不产生可见输出。射线按深度顺序绘制，先绘制的射线成为后续射线的障碍物，引入了处理顺序依赖。

输入中嵌套于其他对象包围框内的小对象向特定方向发射射线，射线方向由嵌套层数决定。

**输入结构**：
- 网格约 14x14，背景黑(0)。
- 含 4-5 个单色 4-连通对象，每个对象颜色互不相同，使用蓝(1)、绿(3)、黄(4)、灰(5)、橙(7) 等颜色，每个对象 3-8 像素，形状为任意连通形态（非特定命名形状）。
- 对象之间像素互不相邻。部分较小对象位于较大对象的包围框内部（但不与大对象像素重叠——小对象占据大对象包围框区域内的背景空间），形成深度 0-2 的嵌套层级。
- 生成约束：无部分包含（一个对象的包围框要么严格在另一个内部，要么完全不在）；每个对象的顶端最左像素在编码方向上有至少 2 格的背景空间可供射线延伸。

**规则**：
1. 识别所有 4-连通单色非黑对象，计算每个对象的包围框。
2. 计算嵌套深度：对象 X 的深度 = 包围框严格包含 X 包围框的其他对象数量。
3. 方向编码：深度 mod 4 → {0: 上, 1: 右, 2: 下, 3: 左}。
4. 按嵌套深度从浅到深的顺序处理对象。对于每个对象，找到其最顶端像素（同行取最左列）。从该像素出发，沿编码方向逐格延伸射线：将路径上的每个背景(0)像素涂为该对象的颜色，遇到非背景像素或网格边界时停止（不涂停止位置）。
5. 先处理的射线所涂像素对后续射线而言是障碍物（非背景）。同深度对象按顶端像素的行号升序处理，行号相同则列号升序。
6. 所有原始对象像素保持不变。

**关键洞察**：射线方向不是对象自身形状或颜色的属性，而是由该对象在全局包围框嵌套层级中的位置决定；确定层级需要联合分析所有对象的空间关系。此外，处理顺序使浅层射线成为深层射线的障碍物，产生了单看局部对象无法预判的遮挡效应。
