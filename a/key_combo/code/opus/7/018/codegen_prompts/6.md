## 新题 6：压缩揭示隐藏循环移位用于预测

**组合逻辑**：[compress + block_sampling](已有，来自 #19) → [cyclic_shift + predict_next_cycle + col_fixed_color](已有，来自 #2，但作用在压缩产物上) → [pixel_upscale](已有，来自 #8，反向展开)

**来源原语**：partitioned_grid、compress、block_sampling、sparse_foreground_pixel（#19 5783df64）；cyclic_shift、predict_next_cycle、col_fixed_color（#2 e78887d1）；pixel_upscale（#8 b91ae062）

**依赖链**：大尺度分区网格中每个分区仅含一个前景像素 → 压缩后得到小网格 → 小网格中连续行呈循环左移关系，且每列有固定颜色 → 预测下一行 → 将预测结果按分区尺度展开为输出。循环模式在全尺度下不可见（前景像素分散在大网格各处），必须先压缩才能发现规律；预测在压缩空间完成后必须重新展开，三者缺一不可。

将稀疏分区网格压缩后发现隐藏的循环左移规律，预测下一行并展开为分区尺度的输出。

**输入结构**：
- 网格高度和宽度各可被块大小 B 整除（B = 3 或 4），总尺寸约 12x16 至 16x16。
- 背景黑(0)为最常见颜色。
- 网格隐式分为 R x C 的等大分区块（R 行 C 列，C = 4），每块大小 BxB。
- 每个分区块内恰好有一个非背景前景像素，其余为背景。
- 压缩后得到 R x C 的小网格。在该小网格中：每列 j 在所有行中颜色相同（列固定颜色 C_j），且第 i+1 行是第 i 行向左循环移位一个位置的结果。
- 同一列 j 的所有分区块中，前景像素的块内相对位置 (r_j, c_j) 相同（不同列可以不同）。
- R >= 3，确保至少 3 行压缩数据可供归纳循环规律。

**规则**：
1. 确定块大小 B 和分区布局 R x C。
2. 压缩：对每个分区块，提取其中唯一的非背景像素的颜色 → 得到 R x C 的压缩颜色网格。同时记录每列 j 的块内前景像素相对位置 (r_j, c_j)。
3. 观察压缩网格中的行间关系：第 i+1 行是第 i 行循环左移一位。每列 j 有固定颜色 C_j。
4. 预测下一行：将压缩网格最后一行循环左移一位。移位后第 j 列的颜色为 C_{(j+1) mod C}。
5. 输出：高度 B、宽度 C*B 的条带。第 j 个分区块（0-索引，从左到右）为 BxB 全背景，但在相对位置 (r_j, c_j) 放置一个颜色为预测第 j 列颜色的像素。

**关键洞察**：在全尺度网格中，前景像素散布各处，循环移位关系完全不可见。求解者必须先发现分区结构并进行压缩，才能在压缩空间中识别循环规律。这种"尺度变换揭示隐藏模式"的结构在参考题中不存在——参考题 #19 的压缩是终点，参考题 #2 的循环移位作用在可见精灵体上，本题将两者的结构关系嵌套在不同尺度层级中。
