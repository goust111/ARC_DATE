## 新题 3：图案补全改变面积排名决定涂色命运

**组合逻辑**：[group_by_frame_color → pattern_union_completion](已有，来自 #3) → [area_ranking](已有，但排名输入被补全改变) → [recolor / erase](已有，由排名结果选择性触发)

**来源原语**：group_by_frame_color、pattern_union_completion、same_color_frames_share_motif（#3 42918530）；area_ranking（#18 a8d7556c）；pixel_upscale（#8 b91ae062）；erase（#12 9720b24f）

**依赖链**：同色边框分组 → 组内图案并集补全（改变了各组的实际像素数）→ 按补全后的图案大小排名 → 排名最高的组重涂为黄(4)，排名最低的组擦除，中间的组保留补全结果不变。核心耦合在于：补全步骤改变了像素计数，使得补全前的面积排名与补全后不同——如果跳过补全直接排名，会选错组。

将同色边框分组并补全共享图案后，按补全后的图案大小决定每组的命运：最大组升格涂色、最小组擦除、其余保留。

**输入结构**：
- 网格约 18x18，背景黑(0)。
- 含 4-6 个等大的彩色方形边框（外 5x5、内 3x3、单像素边框），按 2x3 或 3x2 网格排列，边框之间以 1 列/行背景分隔。
- 边框分 2-3 种颜色（如蓝(1)、红(2)、绿(3)），每种颜色有 2-3 个边框。
- 每个边框内部可能有若干与边框同色的像素构成部分图案。同色边框的内部图案是同一完整图案的不同子集（各自缺失不同位置）。
- 生成约束：至少存在一个颜色组，其补全后的图案像素数（每框内部着色像素数）大于另一组的补全前像素数，但小于该组的补全前像素数。即：补全操作使得排名发生逆转。

**规则**：
1. 识别所有彩色边框（单像素厚度的单色方形边界围成 3x3 内部区域的结构）。
2. 按边框颜色分组。
3. 并集补全：对每个颜色组，收集该组所有边框内部被着色的相对位置的并集，然后将并集中的所有位置填入该组每个边框的内部（使组内所有边框拥有相同的完整图案）。
4. 计算每组的"图案大小"= 补全后单个边框内部着色像素的数量（0-9 之间）。按图案大小降序排名。平局按该颜色的首个边框在光栅序（逐行从左到右、从上到下）中的出现位置升序排列。
5. 排名第 1 的组（图案最大）：将该组所有边框的全部像素（边界 + 内部着色像素）重涂为黄(4)。
6. 排名最末的组（图案最小）：将该组所有边框的全部像素擦除为背景(0)。
7. 其他中间排名的组：保留补全后的状态不变。

**关键洞察**：排名必须在补全之后进行——补全改变了各组的有效面积，使得补全前的"最大"组在补全后可能不再是最大。求解者需要先执行补全操作才能正确判断哪个组应被提升、哪个应被擦除。
