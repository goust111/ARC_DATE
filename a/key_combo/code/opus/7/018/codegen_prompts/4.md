## 新题 4：障碍感知的递增对角延伸

**组合逻辑**：[length_increment](已有) + [ray_cast + collision_stop](已有，碰撞对象从边界扩展为动态障碍) + [erase](创新：擦除条件由碰撞结果决定，且擦除改变后续障碍格局)

**来源原语**：diagonal_segment、same_antidiagonal、length_increment（#20 50c07299）；ray_cast、collision_stop（#9 80a900e0）；wall_barrier（#17 dd6b8c4b）；erase（#12 9720b24f、#20 50c07299）

**依赖链**：测量线段长度确定延伸量（L+1）→ 延伸时检测墙壁和其他线段的碰撞 → 完全被堵的线段被擦除 → 擦除改变了障碍地图，影响后续线段的延伸结果。处理顺序（最短优先）决定了哪些线段先尝试延伸或被擦除，这是一个迭代反馈结构，而非线性流水线。

每条对角线段尝试沿行进方向延伸比自身多一格的长度，遇墙停止；完全无法延伸的线段被擦除，可能为其他线段解除障碍。

**输入结构**：
- 网格约 12x15，背景黑(0)。
- 含灰(5)像素构成不规则墙壁障碍（不一定连通，散布于网格中）。
- 含 2-4 条对角线段，每条是沿单一对角线方向的连续同色像素串，颜色各不相同（如蓝(1)、红(2)、绿(3)），每条长度 2-4 像素。
- 每条线段有明确的行进方向：从起始端到末尾端沿对角线的方向（如左上→右下、右上→左下等）。
- 生成约束：至少一条线段的延伸端点紧邻墙壁（即第一个延伸像素就被墙壁阻挡，导致该线段被擦除）；至少一条线段可以自由延伸；至少两条线段长度不同。至少存在一种情况：线段 A 被擦除后，原本被 A 阻挡的线段 B 的延伸路径变为畅通。

**规则**：
1. 识别所有对角线段：沿主对角线或反对角线方向的同色像素极大连通串。记录每条线段的颜色、长度 L、行进方向（从第一个像素到最后一个像素的方向向量）。
2. 按长度升序处理线段。同长度按顶端像素行号升序排列，行号相同按列号升序。
3. 处理当前线段：尝试从其末端沿行进方向绘制 L+1 个新像素。逐个检查新位置：
   - 若位置在网格内且为背景(0)：涂上该线段的颜色。
   - 若位置超出网格、为墙壁灰(5)、或为其他线段/射线的像素：停止延伸（不涂该位置），结束该线段的处理。
4. 若延伸产生了 0 个新像素（第一个延伸位置就被阻挡）：擦除该线段的全部原始像素（设为背景(0)）。
5. 所有线段处理完毕后输出网格。墙壁像素始终保持不变。

**关键洞察**：处理顺序至关重要——短线段先处理，被擦除的短线段释放出空间，可能使长线段原本被阻挡的延伸路径变为畅通。求解者必须模拟迭代过程而非独立分析每条线段。
