## 新题 8：旋转异或揭示象限着色的不对称掩码

**组合逻辑**：[rotate](已有，来自 #7) + [cell_by_cell_comparison + xor_difference](已有，来自 #6) → [corner_sets_quadrant + quadrant_member](已有，来自 #1，着色逻辑独立于前两步但三者结果在同一输出汇合)

**依赖链**：输入包含图案和四角图例像素 → 将图案（不含角像素）旋转 180° → 原图案与旋转图案逐像素异或比较 → 差异位置按所在象限涂上对应角图例的颜色，一致位置设为背景。三条独立信息流（旋转角度、差异检测方法、象限颜色映射）在输出阶段汇聚——任一缺失都无法产生正确输出。这是多源汇聚结构，非线性流水线。

将图案旋转 180 度后与原图异或，差异像素按所在象限涂上四角图例对应的颜色。

**输入结构**：
- 正方形网格，边长为偶数（如 8x8 或 10x10），背景黑(0)。
- 四个角格各有一个互不相同的非黑颜色像素作为象限图例：(0,0) = 蓝(1)，(0,W-1) = 红(2)，(H-1,0) = 绿(3)，(H-1,W-1) = 黄(4)（具体颜色因示例而异，但四角颜色互不相同且与灰(5)不同）。
- 除四角外的内部区域包含灰(5)像素构成的图案，背景为黑(0)。图案不具有 180° 旋转对称性（必有非对称特征）。
- 生成约束：原图案与 180° 旋转图案之间至少有 4 个差异位置，且四个象限中至少有两个象限包含差异位置。

**规则**：
1. 记录四角图例颜色：C_TL = (0,0) 处颜色，C_TR = (0,W-1) 处颜色，C_BL = (H-1,0) 处颜色，C_BR = (H-1,W-1) 处颜色。
2. 创建"图案网格"：将输入复制一份，四角格设为黑(0)。
3. 创建"旋转网格"：将图案网格绕中心旋转 180°。
4. 逐像素比较图案网格与旋转网格：值不同的位置为"差异格"，值相同的位置为"一致格"。
5. 构建输出（与输入同大小，初始化为黑(0)）：
   - 对每个差异格 (r, c)：
     - 若 r < H/2 且 c < W/2 → 涂 C_TL
     - 若 r < H/2 且 c >= W/2 → 涂 C_TR
     - 若 r >= H/2 且 c < W/2 → 涂 C_BL
     - 若 r >= H/2 且 c >= W/2 → 涂 C_BR
   - 一致格保持黑(0)。

**关键洞察**：输出同时编码了三种信息——旋转类型（180° 而非 90° 或镜像，需对比多示例确认）、对称性缺失的位置（异或掩码）、以及象限空间归属（角图例）。求解者必须同时推断旋转角度、比较方法和颜色映射规则，三者独立但汇合于同一输出，无法单独求解。
