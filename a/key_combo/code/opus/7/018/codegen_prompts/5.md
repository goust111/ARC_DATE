## 新题 5：十字交叉点激活封闭区域涂色

**组合逻辑**：[ray_extend + intersection_colored](已有，来自 #4，几何构造阶段) → [containment + recolor_if_hole](创新：触发条件从拓扑属性改为交叉点空间存在性) → [recolor](创新：涂色颜色由交叉点的行贡献者决定)

**来源原语**：ray_extend、row_col_intersection、intersection_colored（#4 23581191）；enclosed_region、connected_component、containment、recolor_if_hole（#11 810b9b61）；recolor、area_ranking（#18 a8d7556c）

**依赖链**：孤立种子像素生成全行全列十字线 → 不同色十字线的交叉点被标记为红(2) → 包含红标记的封闭区域被激活涂色 → 涂色颜色取决于哪个种子的行（非列）穿过该区域。四个环节环环相扣：无十字线则无交叉点，无交叉点则区域无激活信号，无区域识别则标记无作用对象，无行/列区分则涂色颜色不确定。

通过种子像素的十字线交叉产生红色标记，任何包含红色标记的封闭区域被涂为贡献了行方向穿越的那个种子的颜色。

**输入结构**：
- 网格约 14x14，背景黑(0)。
- 含 2-3 个孤立单像素"种子"，颜色互不相同（如橙(7)、青(8)），任意两个种子不在同一行或同一列。
- 含 2-3 个灰(5)像素构成的封闭边界形状。每个形状是一个 4-连通闭合环路，围成一个 3-8 像素的背景内部区域。形状之间不接触，形状不接触种子像素。
- 生成约束：至少一个封闭区域的内部包含某个"十字交叉点"位置（即该区域内部存在某个格子 (r,c)，使得 r 是种子 A 的行号且 c 是种子 B 的列号，A 与 B 颜色不同）；至少一个封闭区域内部不包含任何交叉点位置。每个包含交叉点的区域内最多只有一个种子的行穿过（即不存在两个不同种子的行号同时出现在同一个封闭区域的内部像素中）。种子像素本身不在任何封闭区域内部。

**规则**：
1. 识别所有非黑、非灰的孤立单像素（种子）。记录其颜色和坐标。
2. 对每个种子，将其所在行和列中所有背景(0)像素涂为该种子的颜色。灰(5)边界像素和其他种子像素不被覆盖。
3. 交叉检测：若某个格子在步骤 2 中被两个不同种子都要涂色（该格子同时在种子 A 的行上和种子 B 的列上，或反之），则该格子涂为红(2)。
4. 识别所有封闭区域：由灰(5)像素完全围成的 4-连通内部区域（内部像素在步骤 2-3 后可能是背景、种子色或红色）。
5. 对每个封闭区域：检查其内部是否包含至少一个红(2)像素。若包含：找到穿过该区域的种子行——即确定哪个种子的行号与该区域内部某些像素的行号相同。将该区域内所有非红像素涂为该种子的颜色。红像素保持红色。
6. 不含红像素的封闭区域：保持不变。
7. 灰(5)边界像素始终不变。

**关键洞察**：十字线的绘制不是最终目的——它产生的交叉标记充当封闭区域涂色的激活信号。决定涂色颜色时，必须区分交叉点的行贡献者和列贡献者——贡献行方向的种子决定区域颜色，这是一个需要对比多个示例才能归纳的非显然规则。
