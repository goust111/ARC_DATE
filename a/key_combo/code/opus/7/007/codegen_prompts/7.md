## 新题 7：尺寸匹配嵌入并按腔壁标记决定是否镜像

**组合逻辑**：[嵌入填充/inlay_fill](已有) + [镜像/mirror](创新：是否镜像由空腔边界上的隐蔽标记决定，而非全局规则) ← 关系 [尺寸匹配/size_matching](已有) + 条件 [唯一槽位配对/unique_slot_pairing](已有) + [包围盒内翻转/flip_within_bbox](创新：翻转条件从"所有掩码都翻"变为"逐腔独立判定")

**来源原语**：嵌入填充、模板框架、精灵体、矩形空腔、尺寸匹配、唯一槽位配对 ← 5dbc8537；镜像、包围盒、包围盒内翻转 ← e74e1818

**依赖链**：尺寸匹配确定哪个精灵体填入哪个空腔 → 空腔边界上的标记像素决定填入前是否需要垂直镜像 → 镜像或不镜像后的精灵体嵌入空腔。三步缺一不可：无尺寸匹配则配对未知；无标记检测则镜像决策未知；无嵌入则无输出。同时，镜像决策是逐空腔独立判定的，不是全局统一的。

按尺寸将精灵体与空腔配对，根据每个空腔顶部边界是否有标记像素决定嵌入前是否垂直镜像。

**输入结构**：约 15x15 的黑(0)背景网格。网格中有一个由青(8)像素构成的大型模板框架（约 12x12，矩形外轮廓，内部被青(8)隔墙分成 2~4 个矩形空腔）。每个空腔尺寸各不相同（如 3x2、4x3、2x5 等）。空腔内部为黑(0)。部分空腔的顶部边界（空腔内部最上一行的正上方那一行青(8)隔墙像素中）有一个红(2)标记像素替换了原本的青(8)像素；其余空腔的顶部边界无红(2)标记。模板框架外部散布着与空腔数量相同的小精灵体，每个精灵体由一种独特颜色（蓝(1)、绿(3)、黄(4)、品红(6)中选取）的像素构成，形状为不规则但行数x列数与某个空腔完全匹配。生成约束：各空腔尺寸互不相同，各精灵体尺寸互不相同，且存在唯一的精灵体-空腔尺寸配对；至少一个空腔有红(2)标记、至少一个无。

**规则**：
1. 识别青(8)模板框架及其内部的所有矩形空腔（被青(8)隔墙完全围合的黑(0)矩形区域）。
2. 识别框架外部的所有精灵体（非黑(0)、非青(8)、非红(2)的 4-连通彩色对象）。
3. 按包围盒尺寸（行数 x 列数）将每个精灵体与唯一匹配的空腔配对。
4. 对每个空腔，检查其顶部边界（空腔首行正上方的那一行青(8)墙壁像素）中是否存在红(2)标记像素：若存在红(2)标记，则将匹配的精灵体在嵌入前做垂直镜像（以精灵体包围盒上下边界为轴翻转，即第 i 行与第 (h-1-i) 行交换，h 为精灵体行数）；若不存在，直接嵌入不翻转。
5. 将（可能经过镜像的）精灵体放置到其匹配空腔中，精灵体包围盒左上角对齐空腔左上角。
6. 输出为模板框架包围盒的裁剪（包含青(8)框架、红(2)标记和已嵌入的精灵体）。

**关键洞察**：尺寸匹配解决"哪块拼到哪"，但镜像决策隐藏在空腔边界上一个不起眼的红(2)像素中——它混杂在青(8)框架墙壁里，需要逐腔检查才能发现，且不同空腔的镜像指令可以不同。
