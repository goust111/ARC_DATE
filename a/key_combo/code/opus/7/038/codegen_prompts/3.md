## 新题 3：散点三角推断正方形与缺角对角分类填充

**组合逻辑**：[ignore_distractors](创新：干扰物是散布的灰色像素而非独立精灵体) + [corners_define_square + infer_center_from_known_corners](创新：从添加微缩副本变为绘制完整正方形边框并填充内部) + [diagonal_position](创新：对角线位置从排布编码变为填充颜色的分类条件) + [fill](创新：填充颜色取决于缺失角的几何分类而非面积排名)

**来源原语**：corners_define_square + infer_center_from_known_corners（11e1fe23）、ignore_distractors（72ca375d / 0a1d4ef5）、fill（694f12f3）、diagonal_position（11e1fe23）

**依赖链**：干扰排除 → 有效三角点组识别 → 第四角推断和正方形确定 → 缺失角的对角线归属分类 → 填充颜色确定。每一步的输出是下一步的必要输入，且缺失角分类与填充颜色之间的映射需要对比多个正方形（不同缺角位置）才能归纳。

从散点中排除干扰、识别三角点组推断正方形，缺失角落在主对角线还是副对角线决定内部填充色。

**输入结构**：约 18x18 的黑(0)背景网格。散布若干孤立彩色像素。其中 2-3 组同色像素各恰好 3 个，分别构成某个轴对齐正方形的 3 个角（正方形边长至少 5，保证内部面积 >= 9 个像素可供填充）。每组使用不同颜色（如绿(3)、橙(7)、青(8)）。另有 4-6 个灰(5)孤立像素作为干扰，散布在网格中不构成任何有效正方形角点。生成约束：不同组定义的正方形包围盒互不重叠；每个正方形内部区域不含任何其他像素（无灰色干扰也无其他组像素）；各组缺失角的对角线方向有所不同（至少一组缺主对角线角，至少一组缺副对角线角）。

**规则**：
1. 忽略所有灰(5)像素（干扰物）。
2. 将剩余非黑非灰彩色像素按颜色分组。对每组验证：3 个同色像素是否恰好构成某个轴对齐正方形的 3 个角（即存在唯一第 4 点使 4 点构成正方形）。不构成有效三角点的组忽略。
3. 对每个有效组，推断缺失的第 4 角位置。用该组颜色绘制正方形的完整边框（4 条边各 1 像素宽，包含 4 个角点）。原有的 3 个角点像素被边框覆盖（颜色相同所以视觉不变）。
4. 判定缺失角的对角线归属——以正方形自身为参照，左上角和右下角为"主对角线角"，右上角和左下角为"副对角线角"。若缺失角是主对角线角（左上或右下），用红(2)填充正方形内部（边框以内的所有像素）；若缺失角是副对角线角（右上或左下），用蓝(1)填充内部。
5. 灰色干扰像素保留在原位（若干扰像素不在任何正方形内部或边框上，则不受影响）。

**关键洞察**：填充颜色既不取决于角点颜色也不取决于正方形大小——它完全由缺失角的几何位置（主对角线 vs 副对角线）决定。这一分类条件只有在看到多个不同缺角方向的正方形后才能归纳出来。
