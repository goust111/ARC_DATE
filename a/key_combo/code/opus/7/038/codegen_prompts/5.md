## 新题 5：晶格螺旋可达性重涂色

**组合逻辑**：[lattice_grid](保留：规则晶格结构) + [spiral_drawing](创新：螺旋不是独立绘制几何图形，而是在已有晶格上的遍历算法) + [recolor](创新：重涂色区域由遍历可达性而非行列选择决定) + [truncate_at_blocker](创新：阻断的不是射线而是螺旋遍历路径)

**来源原语**：lattice_grid + marker_row_column_selection（4f537728）、spiral_drawing + origin_positioning（8b28cd80）、recolor（2204b7a8）、truncate_at_blocker（212895b5）

**依赖链**：标记节点确定螺旋起点 → 螺旋按晶格节点位置展开 → 遇到阻断节点时终止遍历 → 所有被遍历到的节点和连接边被重涂色。阻断节点的位置决定了螺旋能到达的范围——距离起点近但在螺旋路径后段的节点可能未被到达，而距离远但在螺旋路径早段的节点会被到达。这一"螺旋序 ≠ 空间距离"的区别是核心非显然规则。

标记节点发起晶格上的方形螺旋遍历，遇阻断节点时停止，被遍历到的节点重涂为标记色。

**输入结构**：约 15x15 的黑(0)背景网格。蓝(1)像素构成规则晶格：节点为 2x2 蓝色方块，节点间距为 3 像素（中心到中心），节点之间由 1 像素宽的蓝色连接线相连（水平和垂直方向）。晶格约为 4x4 = 16 个节点。其中一个节点的 2x2 方块被替换为红(2)（标记节点）。另有 1-2 个节点的 2x2 方块被替换为黄(4)（阻断节点）。其余均为蓝(1)节点和蓝(1)连接线。黑(0)填充所有空隙。生成约束：阻断节点不与标记节点相邻（螺旋至少能展开 2 圈）；阻断节点的位置使得至少有 1 个空间上距离标记较近但螺旋序较晚的蓝色节点未被到达。

**规则**：
1. 将晶格抽象为节点图：每个 2x2 方块是一个节点，节点间连接线是边。标记节点（红色）是螺旋起点。
2. 从标记节点出发，按方形螺旋顺序遍历晶格节点：初始方向向上，然后依次转右。臂长序列为 1, 1, 2, 2, 3, 3, ...（每两个臂长递增 1）。每"一步"是从当前节点移动到相邻节点。
3. 当螺旋下一步将到达一个黄色阻断节点时，终止遍历。阻断节点本身不被访问。若下一步超出晶格边界，跳过该步继续按螺旋方向尝试下一步（仅限跳过边界外的步，不跳过阻断节点）。
4. 将所有被螺旋遍历到的蓝色节点重涂为红(2)（与标记同色），同时将连接相邻已遍历节点的蓝色连接线也重涂为红(2)。
5. 标记节点本身保持红色。阻断节点保持黄色。所有未被遍历到的蓝色节点和连接线保持蓝色不变。

**关键洞察**：重涂范围不由 Manhattan 距离决定，而由螺旋遍历序决定。一个空间上很近的节点如果在螺旋路径上排在阻断节点之后，它将不会被重涂——这一点打破了"距离越近越先处理"的直觉。
