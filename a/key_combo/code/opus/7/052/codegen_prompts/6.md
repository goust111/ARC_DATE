## 新题 6：标记计数定缩放因子、面积约束过滤印章

**组合逻辑**：[counting/marker_in_panel](计数矩形内标记数) → [pixel_scaling/side_sets_scale](计数结果作为缩放因子) → [stamp/same_size_replace](缩放模板印入矩形) ← [面积几何约束过滤]（创新：计数结果同时受到几何容纳性的约束——缩放后模板必须能装入目标矩形，否则该矩形不获得印章而是保留原样，成为干扰项）

**来源原语**：counting/marker_pixel/marker_in_panel/max_marker_panel（e50d258f）、pixel_scaling/scale_correspond/side_sets_scale（447fd412）、stamp/same_size_replace（e76a88a6）、solid_rectangle（e76a88a6）、ignore_distractors（35ab12c3/de809cff/d90796e8）

**依赖链**：标记计数决定缩放因子，缩放因子与矩形尺寸共同决定模板是否能装入（几何约束），能装入则印章、不能则保留原样。删除计数步骤则缩放因子未知；删除几何约束判断则所有矩形都被印章（部分会溢出出错）；删除印章步骤则计数无输出效果。

一句话总结：计数每个灰色矩形内的红色标记数作为缩放因子，将模板按该因子放大后印入矩形内部，若放大后模板超出矩形尺寸则该矩形保持灰色不变。

**输入结构**：
- 网格约 20x20，背景为黑(0)。
- 一个小型多色模板精灵位于网格左上区域，大小为 2x2 或 2x3，使用蓝(1)和黄(4)像素。模板为 4-连通。
- 4~6 个实心灰(5)矩形散布于网格中，尺寸各异（宽高在 3x3 到 10x10 之间），矩形之间互不重叠、不接触、不与模板重叠。
- 每个灰矩形内部包含 1~4 个红(2)单像素标记，标记位置不在矩形边缘行/列上（位于严格内部）。不同矩形的标记数量可能不同。
- 生成约束：至少一个矩形的标记数 k 满足"模板放大 k 倍后尺寸 ≤ 矩形内部尺寸"（能装入），至少一个矩形的标记数 k 满足"模板放大 k 倍后至少一个维度 > 矩形内部尺寸"（装不进，作为干扰项）。

**规则**：
1. 识别模板精灵：网格中唯一的由蓝(1)和黄(4)像素组成的 4-连通多色区域。记录其边界框及内部像素图案。
2. 识别所有灰(5)实心矩形。对每个矩形，计数其内部的红(2)标记像素数量，记为 k。
3. 将模板按因子 k 进行像素级放大（模板中每个像素变为 k x k 的同色方块）。计算放大后模板的尺寸（原宽 * k, 原高 * k）。
4. 判断放大后模板是否能装入该灰矩形的内部（灰矩形内部 = 去掉最外一圈灰像素后的区域，即宽-2 x 高-2）。若放大后模板的宽 ≤ 内部宽 且 高 ≤ 内部高，则能装入；否则不能。
5. 能装入的矩形：将放大后的模板印在矩形内部的左上角（内部区域的第 0 行第 0 列开始），模板像素覆盖灰(5)像素。内部中未被模板覆盖的区域保持灰(5)。矩形最外一圈灰(5)边框保持不变。
6. 不能装入的矩形：保持完全不变（包括红标记也保留在原位）。
7. 能装入的矩形中，红(2)标记像素被模板覆盖或被灰色保留区覆盖——标记在输出中不单独保留（被覆盖即消失）。
8. 模板精灵本身在输出中保持不变。

**关键洞察**：标记数量与矩形尺寸之间存在隐式的几何兼容性约束——不是所有矩形都会被印章，求解者必须同时考虑"数多少标记"和"矩形够不够大"两个条件。仅凭一个示例难以区分"标记数=3 但太小所以不印"和"标记数=3 且刚好装入"之间的差异。
