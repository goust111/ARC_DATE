## 新题 3：风车拼合触发跨象限多米诺

**组合逻辑**：[rotate + concatenate](精灵四旋转拼成风车) → [four_neighbor_pairing](跨象限边界的异色 4-邻接对形成多米诺) → [recolor + erase](多米诺规则：绿存为青、红消)（创新：旋转的几何结果隐式定义了哪些像素会形成跨边界配对）

**来源原语**：rotate/concatenate/array_layout/four_rot_pinwheel（ed98d772）、bicolor_domino/four_neighbor_pairing/pair_recolor_erase（d90796e8）、recolor（多源）、erase（d90796e8）

**依赖链**：旋转决定各象限中像素的位置，位置决定哪些像素跨象限边界 4-邻接，4-邻接关系中的红-绿配对触发多米诺变换。删除旋转拼合则无跨边界邻接可检测；删除多米诺规则则风车与原题无异。一个输入像素的颜色变化可通过四次旋转在四条象限边界上产生连锁反应。

一句话总结：将输入精灵拼成 2x2 风车后，跨越象限边界的红-绿相邻像素对按多米诺规则变换——绿侧变青、红侧消除。

**输入结构**：
- 网格为 N x N（N 为 3 或 4），背景为黑(0)。输出为 2N x 2N。
- 精灵仅使用红(2)和绿(3)两种前景色，像素数在 3~8 之间。精灵不必连通，但至少有一个红像素和一个绿像素。
- 生成约束：拼成风车后，至少存在 2 对跨象限边界的红-绿 4-邻接配对；至少存在 1 对跨边界的同色 4-邻接（用于验证同色对不被处理）。每个前景像素至多参与一个跨边界多米诺对（若同一像素与多个跨边界邻居均构成红-绿对，按上邻优先、左邻次之的顺序只取第一个配对，其余保留原色）。

**规则**：
1. 构建 2N x 2N 输出网格。将原始精灵放在左上象限（行 0..N-1，列 0..N-1）。
2. 将精灵逆时针旋转 90 度后放在右上象限（行 0..N-1，列 N..2N-1）。
3. 将精灵旋转 180 度后放在左下象限（行 N..2N-1，列 0..N-1）。
4. 将精灵顺时针旋转 90 度后放在右下象限（行 N..2N-1，列 N..2N-1）。
5. 扫描所有跨象限边界的 4-邻接像素对。象限边界指行索引 N-1 与 N 之间（水平边界）以及列索引 N-1 与 N 之间（垂直边界）。对于水平边界上的对，即 (N-1, c) 与 (N, c) 为一对；对于垂直边界上的对，即 (r, N-1) 与 (r, N) 为一对。
6. 按行优先、列次之的顺序逐对检查：若该对中一个为红(2)一个为绿(3)，且两个像素均未在本轮被先前的配对消耗，则标记为多米诺对。将绿(3)像素重涂为青(8)，将红(2)像素设为黑(0)。
7. 跨边界的同色对、非红绿组合的异色对、以及非跨边界的所有像素对不做任何处理。
8. 风车内部（非跨边界）的所有像素保持不变。

**关键洞察**：输入精灵的颜色布局通过旋转在四条象限边界上映射出不同的邻接模式。求解者需要先在脑中完成旋转拼合，才能判断哪些位置会产生红-绿跨界对——这种间接性使得仅看单个示例难以确认配对扫描的精确顺序规则（上优先还是左优先）。

<description>
Replace each pink masked pixel with the color from its matching square-symmetry orbit.

Input structure:
- The grid is square and fully colored.
- Pink pixels are masks covering missing cells; every other pixel is part of the completed pattern.
- The completed pattern obeys main-diagonal symmetry and reflected square symmetry in a slightly larger hidden frame.

Rule:
- Infer the reflected square frame whose visible symmetry orbits make all non-pink cells agree.
- For each pink pixel, collect all visible cells related by diagonal, horizontal, vertical, and rotated reflections in that frame.
- Recolor the pink pixel to the unique non-pink color already present in its orbit.

Key insight:
Pink is not an object color; it hides entries of one globally D4-symmetric color table, so each missing value is copied from its symmetry orbit.
