## 新题 1：光晕桥接决定精灵存亡

**组合逻辑**：[dilation](灰标记膨胀为蓝光晕) → [connectivity_test](光晕链是否桥接多个精灵) → [recolor](同连通分量内精灵统一涂色) + [erase](孤立精灵擦除)

**来源原语**：dilation/neighborhood_expand/marker_retains_color（4258a5f9）、connectivity_test/connectivity/bridge_path（239be575）、recolor（f560132c/de809cff）、erase（d90796e8）

**依赖链**：灰标记膨胀产生的蓝光晕覆盖范围决定了哪些精灵被桥接进同一连通分量；连通分量的成员关系决定了最大精灵的颜色向其余成员传播；未被任何光晕链触达的孤立精灵被完全擦除。删除膨胀步骤则连通关系无法建立；删除连通判定则无法确定重涂色范围；删除擦除规则则孤立精灵的处理方式不明。

一句话总结：灰色标记点膨胀出蓝色光晕，光晕重叠链将多个精灵桥接为一组，组内所有精灵被重涂为最大精灵的颜色，无法被任何光晕链触达的孤立精灵被擦除。

**输入结构**：
- 网格约 15x15，背景为黑(0)。
- 3~5 个单色精灵体散布在网格中，每个精灵由 3~7 个同色像素组成的 4-连通区域构成，各精灵颜色互不相同（使用红(2)、绿(3)、黄(4)、橙(7)、栗(9)等非黑非灰非蓝颜色）。
- 若干灰(5)单像素标记散布于精灵之间的空白区域，标记不与任何精灵 4-邻接。
- 任意两个精灵之间至少间隔 3 个像素（曼哈顿距离），保证精灵本身不直接接触。
- 生成约束：至少存在一组精灵能通过灰标记光晕链桥接（即存在一系列灰标记，使得相邻标记的 3x3 邻域有重叠，且链的两端各触及一个精灵的像素）；至少存在一个精灵无法被任何光晕链触达。

**规则**：
1. 对每个灰(5)标记像素，将其裁剪后的 3x3 邻域中的所有黑(0)像素涂为蓝(1)。然后恢复灰标记像素本身为灰(5)（标记保留原色）。若邻域中已有非黑像素（精灵像素或其他标记/光晕），该位置不涂蓝，保留原有颜色。
2. 在全部光晕绘制完成后，构建所有非黑像素（精灵像素 + 蓝光晕 + 灰标记）的 4-连通分量。忽略颜色差异，仅凭 4-邻接关系判断连通。
3. 对于包含 2 个或更多精灵的连通分量：找到该分量中像素数最多的精灵（若平局，选边界框左上角行号更小者；仍平局则选列号更小者）。将分量中所有其他精灵的每个像素重涂为该最大精灵的颜色。
4. 对于仅包含 1 个精灵的连通分量（孤立精灵）：将该精灵的所有像素设为黑(0)（擦除）。
5. 移除所有蓝(1)光晕像素和灰(5)标记像素（设为黑(0)）。输出仅保留存活的精灵像素（部分已被重涂色）。

**关键洞察**：灰标记的空间分布构成了一个隐式的连通图——只有通过观察多个示例中标记的不同布局与精灵存亡结果的对应关系，才能归纳出"光晕重叠桥接"这一中间机制。单看输入输出无法直接看到光晕，因为光晕在最终输出中被移除。
