## 新题 7：障碍门计数驱动旋转量的走廊移动

**组合逻辑**：[移动 + 同轴对齐的矩形对](已有) → [障碍门处标记通道](已有) → [计数](创新：计数门的数量，而非原题中仅标记门) → [旋转](创新：旋转角度由门计数的模 4 值决定——每道门等于 90 度)

**来源原语**：移动(fc10701f), 同轴对齐的矩形对(fc10701f), 障碍门处标记通道(fc10701f), 计数(b1986d4b), 旋转(a25697e4), 障碍段(fc10701f)

**依赖链**：两个对象的同轴对齐确定移动方向 → 走廊中的障碍段产生门 → 门被标记为红色 → 门的数量被计数 → 计数值 mod 4 决定移动对象的旋转角度 → 旋转后的对象放置在目标位置。障碍的空间分布同时控制了走廊的视觉标记和目标位置处的几何变换。

沿走廊移动的不规则图形在穿过的每道障碍门处留下红色标记，门的总数决定图形到达目标时的旋转角度（每门 90 度）。

**输入结构**：约 14x14 网格，灰(5)背景。一个由橙(7)像素构成的小型不规则图形（4-连通，4-6 像素，边界框约 3x3，不同示例中具体形状不同）和一个栗(9)像素构成的同尺寸目标轮廓，两者共享行跨度或列跨度（即沿水平或垂直方向对齐），中间是一段走廊（宽度等于图形在移动垂直方向上的跨度）。走廊中有若干黑(0)障碍段（每段 2-4 像素长，垂直于移动方向排列），构成门状开口。生成约束：走廊中障碍门数量为 1-4 个；橙色图形在各旋转角度下的外形互不相同（即图形不具有 90 度旋转对称性）；栗色目标轮廓的形状与橙色图形在某个旋转角度下吻合。

**规则**：
1. 确定移动方向：橙(7)图形向栗(9)目标沿共享轴方向直线移动。
2. 在移动路径（走廊）中，识别所有由黑(0)障碍段两侧夹持的开口区域。每个障碍段计为一道门。
3. 将每道门的开口单元格标记为红(2)。
4. 计算门的总数 G。
5. 将橙(7)图形顺时针旋转 (G mod 4) x 90 度。旋转中心为图形边界框的中心（向左上取整）。
6. 擦除原始橙(7)图形位置（变为灰(5)背景）。
7. 将旋转后的橙(7)图形放置在栗(9)目标的位置（以目标边界框中心对齐图形旋转后的边界框中心），替换掉栗(9)像素。
8. 红(2)门标记和黑(0)障碍段保留在输出中。

**关键洞察**：障碍门承担双重功能——既是走廊的视觉标记（红色），又是旋转变换的计数器（每门 90 度）。需要对比门数量不同的多个示例，才能归纳出"门数 mod 4 决定旋转角度"这一非显然规则。
