## 新题 4：边界接触定轴的镜像探针选取条纹

**组合逻辑**：[接触边界定轴](已有) → [镜像](创新：镜像产物不是最终输出的一部分，而是作为空间探针使用) → [负片色映射](创新：映射后的颜色用于标记探针区域，使其与原始元素可区分) → [条纹决定填充轴 + 排序](创新：被探针覆盖的条纹被选中并按行序提取为输出)

**来源原语**：接触边界定轴(6f473927), 镜像(6f473927), 负片色映射(6f473927), 条纹(8e1813be), 排序(8e1813be), 填充(8e1813be), 裁剪(337b420f/414297c0)

**依赖链**：前景形状接触的边界决定镜像轴 → 镜像产生翻转副本 → 负片色映射将副本标记为探针（视觉上可区分）→ 探针的空间范围覆盖若干条纹 → 被覆盖的条纹被选中 → 选中条纹按原始行位置从上到下排列形成输出。形状几何决定了探针的空间范围，而这个范围恰好是条纹选择器。

将接触边界的红色形状镜像翻转形成空间探针，探针覆盖到的水平条纹被选中，按行序提取为单列输出。

**输入结构**：约 12x20 网格（宽大于高），黑(0)背景。一个由红(2)像素构成的前景形状（4-连通，6-12 像素，形态不规则——不同示例中具体外形不同）接触网格的恰好一条垂直边界（左边界或右边界），不接触水平边界。在网格远离该形状的一半区域，有 3-5 条水平条纹（每条 1 像素高，横跨部分网格宽度，颜色各不相同，取自 {蓝(1), 绿(3), 黄(4), 品红(6), 橙(7)}），分布在不同行。生成约束：形状镜像后的边界框在行方向上覆盖的范围至少包含 2 条条纹的行，且不覆盖所有条纹；条纹所在行互不相同。

**规则**：
1. 确定前景形状接触的垂直边界（左或右），该边界为镜像轴。
2. 将前景形状沿该镜像轴做水平翻转，在原轴的另一侧生成镜像副本。
3. 对镜像副本应用负片色映射：副本中红(2)像素变为青(8)，副本边界框内的黑(0)像素保持为黑(0)。（注意：映射仅作用于副本区域，不影响原始形状和条纹。）
4. 检查每条水平条纹：若该条纹的行坐标落在青(8)镜像副本的边界框行范围内，且该行中至少有一个青(8)像素存在，则该条纹被"选中"。
5. 输出为一个小网格：高度等于被选中的条纹数量，宽度为 1。按被选中条纹在原始网格中的行位置从上到下排列，每行填充对应条纹的颜色。
6. 原始形状、镜像副本、未选中条纹均不出现在输出中。

**关键洞察**：镜像翻转不是为了构造最终图案，而是作为"空间探针"——翻转后的形状决定了哪些行被激活，从而选中哪些条纹进入输出。改变前景形状的几何外形就改变了输出的颜色序列。
