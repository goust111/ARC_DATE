## 新题 2：自计数缩放与异尺度中心叠加

**组合逻辑**：[计数](创新：每个对象独立计数作为自身专属的缩放因子，而非全局统一计数) → [像素放大](创新：缩放倍率因对象而异) → [透明叠加·中心对齐](创新：叠加的图案尺寸各不相同，绘制顺序由像素数决定)

**来源原语**：像素放大 ← ac0a08a4/bf45cf4b | 计数 ← ac0a08a4 | 透明叠加 ← c8cbb738 | 中心对齐 ← c8cbb738 | 前景掩码 ← c8cbb738 | 数量决定倍率 ← ac0a08a4 | 多色掩码合并 ← c8cbb738

**依赖链**：每个颜色簇独立计数像素数 N → N 作为该簇专属的像素放大系数（不同簇倍率不同）→ 缩放后各图案尺寸各异 → 按像素数从大到小依次中心对齐绘制，像素数最少的簇最后画（显示在最顶层）。计数同时决定了缩放倍率和叠加顺序，两者不可独立确定。

每个颜色簇按自身像素数进行像素放大，然后所有放大后的簇按像素数降序中心对齐叠加到同一画布上，像素最少的簇显示在顶层。

**输入结构**：约 15x15 的网格，黑(0)背景。网格中有 3 个空间上互不 4-连通相邻的单色簇，颜色分别为红(2)、蓝(1)、绿(3)。每个簇为一个 4-连通的小图形（2~4 个像素，非对称形状，如 2 个像素组成的水平/垂直对、3 个像素组成的折线形、4 个像素组成的不规则块等）。生成约束：三个簇的像素数互不相等（如分别为 2、3、4）；各簇在输入中的位置对输出无影响。

**规则**：
1. 对每种非背景颜色，找到其 4-连通簇，裁剪到边界框，并计数像素数 N。
2. 对每个裁剪后的图案进行 N 倍像素放大：图案中每个像素（无论有色还是黑色背景）都变为 N x N 的方块（有色像素变为同色方块，黑色像素变为黑色方块）。
3. 输出画布为正方形，边长等于所有放大结果中最大边长，填充黑(0)。
4. 按像素数从大到小的顺序依次将放大结果中心对齐绘制到画布上：像素数最多的簇先画（底层），像素数最少的簇最后画（顶层）。后画的非黑(0)像素覆盖先画的。
5. 若放大结果小于画布，四周用黑(0)填充使其居中（行列方向各取较小偏移量使位置偏左上）。

**关键洞察**：与参考题 ac0a08a4 不同（全局统一缩放因子），这里每个对象"自我决定"自己的缩放倍率。像素数少的对象放大倍率低、物理尺寸小，但却显示在最顶层——这种"小者居上"的反直觉规则，加上倍率因对象而异的非全局性，需要对比多个示例才能归纳出来。
