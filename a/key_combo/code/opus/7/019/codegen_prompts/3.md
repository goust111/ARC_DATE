## 新题 3：四角异构镜像——指示色编码变换表

**组合逻辑**：[印章覆盖](创新：每个角的副本施加不同变换) ← [镜像](创新：由颜色编码的四态变换表驱动，而非二态开关) + [四角布局·插入间隔](已有) + [颜色配对](创新：颜色映射到变换类型而非目标位置)

**来源原语**：印章覆盖 ← 3e980e27/b1fc8b8e | 镜像 ← 3e980e27 | 分离 ← b1fc8b8e | 精灵体 ← 3e980e27/b1fc8b8e | 标记像素 ← 3e980e27 | 四角布局 ← b1fc8b8e | 颜色配对 ← 3e980e27 | 插入空行列间隔 ← b1fc8b8e | 特定标记触发镜像 ← 3e980e27

**依赖链**：提取中央的非对称精灵体 → 识别四个角落的指示像素颜色 → 建立颜色到变换类型的映射表（需对比多个示例确认，因为单个示例无法区分"颜色驱动"还是"位置驱动"）→ 对精灵体施加各角对应的变换 → 将结果放入四角并插入间隔行列。

一个非对称精灵体被四种不同的几何变换分别处理后放入输出的四个角落，每个角落的变换类型由该角的指示像素颜色唯一决定。

**输入结构**：约 10x10 的网格，黑(0)背景。网格中央区域有一个灰(5)的非对称小精灵体（边界框 3x3，含 4~6 个灰色像素，在水平和垂直方向均不对称）。网格的四个角落区域各有一个孤立的彩色指示像素：左上角附近一个，右上角附近一个，左下角附近一个，右下角附近一个。四个指示像素的颜色分别为红(2)、蓝(1)、绿(3)、黄(4)的某个排列（各不相同，不同示例中排列可不同）。生成约束：精灵体在恒等变换、水平镜像、垂直镜像、180 度旋转下产生四种互不相同的结果（即精灵体无任何对称轴）。

**规则**：
1. 提取灰(5)精灵体（网格中央的 4-连通灰色图形）及其边界框（设为 H x W）。
2. 识别四个角落区域各自的孤立彩色指示像素及其颜色。
3. 颜色到变换的映射为固定规则：红(2) → 保持不变（恒等），蓝(1) → 左右镜像，绿(3) → 上下镜像，黄(4) → 旋转 180 度。
4. 输出网格尺寸为 (2H + 1) x (2W + 1)，全部初始化为黑(0)。中间行（第 H 行）和中间列（第 W 列）为黑(0)间隔。
5. 对输出的四个象限，分别使用对应角落指示像素颜色所指定的变换处理精灵体，然后将结果放入该象限：左上象限使用输入左上角指示色对应的变换，右上象限使用输入右上角指示色对应的变换，左下象限使用输入左下角指示色对应的变换，右下象限使用输入右下角指示色对应的变换。
6. 输入中的指示像素不出现在输出中。

**关键洞察**：参考题 3e980e27 中指示色仅区分"镜像/不镜像"二态，参考题 b1fc8b8e 中四个副本变换完全相同。本题将颜色信号扩展为四种变换的选择器，且每个角落独立选择。仅凭单个示例，无法区分"颜色决定变换"和"角落位置决定变换"这两种假说——必须对比多个示例（其中指示色排列不同）才能确认映射规则。
