## 新题 7：奇偶分流压缩——枚举序位同时编码颜色与方向

**组合逻辑**：[交替选取·奇偶位决定涂色](创新：奇偶不仅决定颜色还决定压缩方向) + [压缩·压缩至远端边界](创新：同一列内的像素被拆分为两组，分别向相反方向压缩) + [重涂色](创新：颜色由枚举序位的奇偶性决定)

**来源原语**：交替选取 ← d406998b | 奇偶位决定涂色 ← d406998b | 压缩 ← 05a7bcf2 | 压缩至远端边界 ← 05a7bcf2 | 重涂色 ← d406998b/05a7bcf2 | 通道 ← 05a7bcf2 | 前景像素序列 ← d406998b

**依赖链**：在每个列（通道）中从上到下枚举前景像素并编号 → 编号的奇偶性同时决定两件事：(a) 重涂颜色（偶 → 绿、奇 → 红），(b) 压缩方向（偶 → 向底边压缩、奇 → 向顶边压缩）→ 同一列的像素被拆分为两组后分别向相反方向聚拢。颜色规则和方向规则共享同一个参数（枚举奇偶性），不可独立归纳。

每列中的前景像素按从上到下的枚举序位分为偶数组和奇数组，偶数组变绿并压向底边，奇数组变红并压向顶边。

**输入结构**：约 8x10 的网格（8 行 10 列），黑(0)背景。每列包含 2~4 个散布在不同行位置的灰(5)前景像素。不同列的灰色像素数量和行位置各不相同。网格中无其他颜色。生成约束：每列至少 2 个灰色像素；同一列中灰色像素不相邻（行间隔 >= 2）。

**规则**：
1. 独立处理每一列（通道）。
2. 在每列中，从上到下（行索引从小到大）枚举所有灰(5)像素，依次编号为 0、1、2、3...
3. 编号为偶数的像素（0、2、4...）重涂为绿(3)，并向该列的底边压缩：第一个偶数编号像素放在该列最底行，第二个放在倒数第二行，以此类推，保持原有的上下相对顺序（原序靠上的在压缩后仍靠上）。
4. 编号为奇数的像素（1、3、5...）重涂为红(2)，并向该列的顶边压缩：第一个奇数编号像素放在该列最顶行，第二个放在第二行，以此类推，保持原有的上下相对顺序。
5. 同一列中，压缩后的绿色像素和红色像素不会重叠（因为生成约束保证了像素数不超过行数的一半）。
6. 所有其他位置保持黑(0)。

**关键洞察**：枚举序位的奇偶性是一个"三合一"信号——它同时控制选择分组、输出颜色和压缩方向。观察单个列的单个示例时，"偶数→绿→向下"和"原位置靠上→绿→向下"等多种假说均可成立；必须对比多个列和多个示例（其中像素分布不同）才能确认驱动规则是枚举序位的奇偶性而非空间位置。
