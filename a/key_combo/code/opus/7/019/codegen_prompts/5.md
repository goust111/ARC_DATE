## 新题 5：循环对角铺满与计数衍生的切比雪夫排斥区

**组合逻辑**：[循环填充·同余类交错铺满](已有) + [切比雪夫距离](创新：排斥区半径不由局部距离决定，而由全局对角线数量决定) ← [计数](创新：计数对象从前景像素变为输入中的对角线条数，计数结果跨操作传递)

**来源原语**：循环填充 ← 05269061 | 对角线 ← 05269061 | 同余类交错铺满 ← 05269061 | 等距偏移 ← 05269061 | 切比雪夫距离 ← ff72ca3e | 阻挡像素 ← ff72ca3e | 填充 ← ff72ca3e | 近阻挡距定尺寸 ← ff72ca3e | 计数 ← ac0a08a4

**依赖链**：统计输入中的彩色对角线条数 D → D 同时用于两处：(a) 作为循环填充的铺满周期，(b) 作为每个灰色阻挡像素的切比雪夫排斥区半径 → 循环填充产生全网格覆盖 → 排斥区擦除区域内的填充像素。增减一条输入对角线会同时改变铺满周期和所有排斥区半径，产生完全不同的输出。

彩色对角线以自身条数为周期循环铺满整个网格，但灰色阻挡点周围的切比雪夫排斥区（半径也等于对角线条数）内不允许填充。

**输入结构**：9x9 的网格，黑(0)背景。包含 2 或 3 条完整的同斜率对角线（均为主对角线方向，即从左上到右下），每条颜色不同（如红(2)、蓝(1)、绿(3)），且这些对角线在垂直于对角线方向上等距分布（相邻对角线的垂直偏移量相等）。另有 1~2 个灰(5)的孤立阻挡像素散布在网格中（不在任何彩色对角线上）。生成约束：对角线互不相交；阻挡像素不与任何原始对角线像素重合。

**规则**：
1. 统计输入中彩色对角线的条数 D（通过非背景、非灰色的颜色种类数确定）。
2. 对每条彩色对角线，沿垂直于对角线的方向每隔 D 个偏移量重复一条相同颜色的平行对角线，铺满整个 9x9 网格。即：若某色对角线经过坐标 (r, c) 且 r - c = k，则所有满足 (r - c - k) mod D = 0 的位置都填入该颜色。各颜色的同余类互不重叠。
3. 对每个灰(5)阻挡像素，计算以该像素为中心、半径为 D 的切比雪夫排斥区（即以该像素为中心的 (2D+1) x (2D+1) 正方形区域，裁剪到网格边界内）。
4. 排斥区内的所有循环填充像素被清除为黑(0)。阻挡像素本身保持灰(5)。
5. 排斥区之外的循环填充像素正常保留。
6. 原始输入中的对角线像素若不在任何排斥区内则保留原色；若在排斥区内也被清除为黑(0)。

**关键洞察**：排斥区的大小不是阻挡像素的局部属性，而是由全局的对角线数量 D 衍生的——D 同时控制铺满周期和排斥半径。增加一条对角线会让铺满更密但排斥区更大，两种效果相互拮抗，产生涌现的图案变化。这种全局计数同时参数化两个不同操作的结构在源题中不存在。
