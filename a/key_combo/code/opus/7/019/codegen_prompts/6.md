## 新题 6：压缩域连通性分析与极值区域重涂

**组合逻辑**：[下采样·奇偶索引分离](已有) → [连通区域](创新：连通性在压缩域而非原始域中计算，压缩改变了邻接关系) → [重涂色·极值面积决定颜色](创新：面积在压缩域中重新计算，原始域中不可见的连通结构驱动重涂)

**来源原语**：下采样 ← 68b67ca3 | 分隔行列 ← 68b67ca3 | 奇偶索引分离 ← 68b67ca3 | 保留偶索引交叉 ← 68b67ca3 | 重涂色 ← 62ab2642 | 连通区域 ← 62ab2642 | 极值面积决定颜色 ← 62ab2642

**依赖链**：识别奇数索引行列为分隔行列 → 压缩得到紧凑网格（仅保留偶数行偶数列交叉位置）→ 在紧凑网格中重新判定 4-连通区域（压缩前被分隔行列隔开的像素在压缩后可能成为邻居）→ 按压缩域中的区域面积排名 → 对极值面积区域重涂色。不理解压缩规则就无法发现真正的连通结构，不分析连通性就无法确定重涂目标。

将带有分隔行列的稀疏网格压缩后，在压缩域中分析连通区域，对面积最小和最大的区域分别重涂为指定颜色。

**输入结构**：偶数尺寸网格（如 10x10 或 12x12），黑(0)背景。所有奇数索引的行（第 1、3、5... 行，从 0 开始计数）和所有奇数索引的列均为纯黑(0)像素（分隔行列）。偶数行偶数列的交叉位置上有若干蓝(1)像素和黑(0)像素。所有非背景前景像素均为蓝(1)。在原始稀疏网格中，蓝色像素之间被分隔行列隔开，视觉上每个蓝色像素都显得孤立。但在压缩后的紧凑网格中（尺寸为原始的一半），某些蓝色像素在新的坐标系下成为 4-连通邻居，形成连通区域。生成约束：压缩后至少形成 3 个蓝(1)的 4-连通区域，且面积互不相等；最小和最大区域各唯一。

**规则**：
1. 删除所有奇数索引的行和列，得到尺寸为原始一半的紧凑网格。偶数行偶数列交叉位置 (2i, 2j) 映射到紧凑网格的 (i, j)。
2. 在紧凑网格中，找出所有 4-连通的蓝(1)区域，计算各区域面积（像素数）。
3. 面积最小的唯一区域重涂为橙(7)。
4. 面积最大的唯一区域重涂为青(8)。
5. 其余蓝(1)区域保持蓝色不变。
6. 黑(0)背景保持不变。
7. 输出为紧凑网格。

**关键洞察**：在原始稀疏网格中，由于分隔行列的存在，所有蓝色像素至少相隔一行一列，视觉上完全孤立。只有在理解压缩规则（删除奇数行列）后，才能在紧凑网格中发现哪些像素实际上是相邻的。压缩不仅改变了网格尺寸，更根本性地改变了像素间的拓扑关系——这是决定重涂目标的前提。
