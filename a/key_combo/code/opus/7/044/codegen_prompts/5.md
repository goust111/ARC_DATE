## 新题 5：条高编码的叠加优先级

**组合逻辑**：[transparent_overlay] + [size_ordering](创新：尺寸排序决定图层优先级而非标记移动) + [erase](移除编码元素)

**来源原语**：transparent_overlay, panel, separator_column, layer_priority（281123b4）；size_ordering, vertical_bar（48634b99）；erase（多题）

**依赖链**：必须先测量条高度以确定堆叠顺序，然后擦除条并执行叠加。条高度是隐式优先级编码——移除尺寸排序则叠加顺序未知，移除叠加则无法合并面板。

将多个分隔面板叠加为一张图，前后优先级由每个面板中嵌入的竖条高度决定（最高者在最前）。

**输入结构**：网格约 6x27，由三列满高灰(5)分隔列分为四个 6x6 面板。每个面板包含：一个由单一前景色（取自 {蓝(1), 红(2), 绿(3), 黄(4)}，四个面板颜色互不相同）绘制的图案，图案中部分像素为前景色，其余为黑(0)背景；一条橙(7)竖条（1 像素宽，高度 1-6 像素各不相同，顶部与面板顶部对齐）。橙条不与面板图案像素重叠。

**规则**：
1. 测量每个面板中橙(7)竖条的高度（像素数）。
2. 按高度从大到小排列面板，确定前到后的图层优先级（最高条的面板在最前）。
3. 擦除所有橙(7)竖条像素（置为黑(0)）和灰(5)分隔列。
4. 将四个面板叠加为一个 6x6 输出：对每个位置，输出从前到后遇到的第一个非黑(0)颜色；若该位置所有面板均为黑色，则输出黑(0)。

**关键洞察**：橙色竖条不出现在输出图案中——它们是高度编码的优先级指令。求解者必须发现条高度控制堆叠顺序，这需要对比不同示例中相同图案但不同条高度导致不同叠加结果的情况。
