## 新题 10：分区调色板驱动的瓦片着色

**组合逻辑**：[tiling](创新：每个瓦片实例着色由外部调色板决定) + [downscale](创新：下采样结果用作颜色映射而非最终输出) + [grid_sampling]

**来源原语**：tiling, tile, array_layout（00576224）；downscale, rectangular_partition, grid_sampling, each_partition_reduced_to_one_pixel（90c28cc7）；recolor（多题）

**依赖链**：分区颜色需被采样以获得每个瓦片实例的着色指令；瓦片形状需被提取以获得重复的图案模板。两者并行解码后合并——分区提供颜色映射，瓦片提供形状模板，缺少任一都无法生成输出。

从分区网格中采样颜色映射，从模板区提取瓦片形状，将每个分区颜色扩展为一个以该颜色重涂的瓦片副本。

**输入结构**：网格约 15x15，由一列满高灰(5)分隔列分为左右两个区域。左侧区域：一个 3x3 或 4x4 的单色图案瓦片，由青(8)像素在黑(0)背景上构成（部分像素为青色，部分为黑色，形成一个小型花纹）。右侧区域：一个矩形分区网格，由大小不等的单色矩形拼成，颜色取自 {蓝(1), 红(2), 绿(3), 黄(4)}，形成隐含的 NxM 格局（如 3x4）。

**规则**：
1. 从左侧区域提取模板瓦片（青(8)/黑(0)图案，忽略分隔列和任何边距）。
2. 对右侧区域的分区结构进行下采样：收集各分区左上角的排序唯一行列位置，在每个位置采样颜色，得到 NxM 紧凑颜色网格。
3. 构建输出：一个 NxM 的瓦片阵列。对紧凑颜色网格的每个位置 (i,j)：
   - 放置一份模板瓦片的副本。
   - 将该副本中的青(8)像素重涂为位置 (i,j) 处的采样颜色。黑(0)像素保持黑色。
4. 输出为拼装好的瓦片阵列网格。分隔列和原始分区网格不包含在输出中。

**关键洞察**：模板瓦片和分区颜色在输入中分处两侧，必须组合使用——瓦片是形状模板，分区是颜色指令表。两个区域各自独立看都不像最终输出，只有理解了"瓦片 x 颜色映射"的乘法关系才能正确求解。
