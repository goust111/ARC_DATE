## 新题 7：旋转驱动的高度排序色带

**组合逻辑**：[旋转](已有) → [最高行决定序](创新：排序依据不是原始最高行，而是旋转后的最高行) → [排序](已有) + [压缩](已有)

**来源原语**：旋转(rotate) ← f0f8a26d；单像素宽条(thin_bar) ← f0f8a26d；中心点不变(center_fixed) ← f0f8a26d；朝向交换长度保持(orient_swap_keep) ← f0f8a26d；排序(sorting) ← 668eec9a；压缩(compress) ← 668eec9a；色条行(color_stripe_row) ← 668eec9a；最高行决定序(topmost_determines) ← 668eec9a；顺序排列(ordered_arrangement) ← 668eec9a

**依赖链**：彩色短条旋转 90 度 → 旋转改变每条短条的最高行（水平条变垂直后最高行上移，垂直条变水平后最高行下移至中心行）→ 按新最高行排序 → 输出压缩色带。旋转直接改变排序键，删去旋转则排序结果不同。

将彩色短条旋转 90 度后，按旋转后的最高行位置排序，输出为压缩色带摘要。

**输入结构**：约 15x15 的网格，黑(0)背景。4-5 条单像素宽的彩色短条，每条一种独特的非黑颜色（如红(2)、蓝(1)、绿(3)、黄(4)、品红(6)），长度为奇数（3-9 像素），可以是水平或垂直方向。各短条互不共享像素。生成约束：旋转后所有短条仍完全在网格内部；旋转后各短条的最高行互不相同（无需 tie-break）。

**规则**：
1. 将每条彩色短条绕其中心像素旋转 90 度（水平变垂直、垂直变水平），中心和长度不变。
2. 计算每条旋转后短条的最高行（即其像素中行坐标的最小值）。
3. 按最高行从小到大（从上到下）排列所有短条的颜色。
4. 输出一个 K x 3 的小网格（K = 短条数量），黑(0)背景。从上到下，每行填充一种颜色的 1x3 实心色带，颜色顺序为步骤 3 的排列顺序。

**关键洞察**：一条长 9 像素的水平条位于第 10 行，旋转后变为垂直条，中心仍在第 10 行，但最高行变为第 6 行（10 - 4 = 6）；而一条长 3 像素的垂直条原本最高行在第 3 行，旋转后变为水平条，最高行变为中心行第 4 行。旋转后的排序完全颠覆了原始位置的直觉顺序。需要对比输入中短条的方向/长度/位置与输出色带顺序的关系才能发现旋转这一中间步骤。
