## 新题 8：频率优先级决定重力碰撞顺序

**组合逻辑**：{[频率排序/frequency_rank](已有) → [冲突优先级/conflict_priority](已有，从空间位置改为频率决定)} + {[重力下落/gravity_drop + 碰撞阻挡/collision_blocking](已有)} → [条件重涂色](创新：触底与否决定最终颜色)

**来源原语**：滑动/slide、连通分量/connected_component、碰撞阻挡/collision_blocking、重力远近序处理/gravity_far_to_near、重力下落/gravity_drop（P18: 5ffb2104）；频率排序/frequency_rank（P12: 9caf5b84）；冲突优先级/conflict_priority（P7: 03560426）；重涂色/recolor（P9: 84db8fc4）

**依赖链**：频率排序决定碰撞时的处理优先级（谁先固定为障碍） → 碰撞结果决定每个对象的最终垂直位置 → 是否触底决定重涂色与否。三个机制同时约束最终布局——频率改变则碰撞顺序改变，碰撞顺序改变则触底判定改变，环环相扣。

所有对象同时下落，碰撞时颜色频率高的先固定为障碍，未触底的对象被涂为灰色。

**输入结构**：约 12x10 的黑(0)背景网格。4-6 个单色 4-连通对象（每个 2-5 像素，形状为不规则连通体），使用 3-4 种颜色（从蓝(1)、红(2)、绿(3)、黄(4)中选取）。部分颜色有多个对象（该颜色总像素数较高），部分颜色只有一个小对象（低频率）。对象分布在网格的中上部，底部留有下落空间。生成约束：各对象在水平方向上的列投影有部分重叠（至少两个不同颜色的对象在某些列有垂直遮挡关系——直接下落会碰撞）；各颜色的总像素数互不相等。

**规则**：
1. 统计输入中每种非背景颜色的总像素数，按像素数从高到低排序为优先级序列。
2. 按优先级从高到低依次处理每种颜色的所有对象：将该颜色的每个 4-连通对象在保持形状和列位置不变的前提下，向下滑动直到其最底行像素触及网格最后一行或碰到已固定的对象的像素的上一行而停止。同一颜色内若有多个对象，按原始最底行像素的行号从大到小（更靠下的先处理）依次固定。
3. 所有对象固定后，检查每个对象：若该对象的最底行像素位于网格最后一行（行 H-1），则保持原色；否则将该对象所有像素重涂为灰(5)。

**关键洞察**：碰撞优先级不由空间位置（谁更靠下或谁更靠右）决定，而由颜色的全局出现频率决定——高频色对象先行固定占位，可能在低频色对象的下落路径上形成障碍使其无法触底。需对比多个示例中不同频率分布下的碰撞结果来区分频率优先与空间优先。

6. 若规则有多个分支，生成器不能长期固定成一个分支；应让分支在随机样例中合理出现。分支概率不必平均——难以发现的隐蔽分支（如少数情况下才触发的特殊规则）应适当提高出现概率，确保在 3 个训练示例中至少出现一次，否则求解者无法归纳该规则。对于颜色映射类规则，确保 2 个左右的示例即可覆盖所有映射关系（每种颜色→颜色的映射至少在某个示例中出现过）。
