## 新题 2：拓扑分类决定展开几何

**组合逻辑**：[连通分量检测/connected_component_detection](已有) → [边界可达性分类/edge_reachability → 拓扑分类/topological_classification](已有) → {外部区域: [正交邻域展开](已有) | 内部区域: [对角邻域展开](已有)}（创新：拓扑属性而非标记颜色决定展开方向）

**来源原语**：连通分量检测/connected_component_detection、连通区域/connected_region、网格边界/grid_edge、边界可达性/edge_reachability、拓扑分类/topological_classification（P9: 84db8fc4）；印章覆盖/stamp_overlay、标记像素/marker_pixel、邻域扩展/neighborhood_expand、仅填背景格/only_fill_background（P1: dc1df850）；对角邻接/diagonal_adjacency、正交邻接/orthogonal_adjacency、标记色选邻域几何/marker_color_selects_neighborhood（P17: 0ca9ddb6）

**依赖链**：拓扑分类结果直接决定展开几何形状的选择分支——未完成分类时无法确定使用哪种展开模式。这不是线性流水线，而是分类后的条件分支结构。

根据红色标记像素所在黑色区域是否接触网格边缘，分别以正交或对角方式展开光环。

**输入结构**：约 15x15 的黑(0)背景网格。蓝(1)和绿(3)像素组成不规则屏障墙（4-连通的线状或块状结构），将黑色背景分割成多个 4-连通区域。部分黑色区域接触网格边缘（外部区域），部分被屏障完全包围（内部区域，至少 2 个）。在若干黑色区域内各有恰好一个红(2)标记像素（外部和内部区域各至少 1 个红标记）。生成约束：红标记与最近的屏障像素之间至少间隔 1 格黑色，使展开后的光环不触及屏障。

**规则**：
1. 将所有黑(0)像素按 4-连通性划分为若干独立区域。
2. 对每个区域分类：若其任意像素位于网格的第 0 行、最后一行、第 0 列或最后一列，则标记为"外部区域"；否则标记为"内部区域"。
3. 对每个红(2)标记像素：
   - 若该标记位于外部区域：将其上、下、左、右四个正交邻居中颜色为黑(0)的格涂为黄(4)。
   - 若该标记位于内部区域：将其左上、右上、左下、右下四个对角邻居中颜色为黑(0)的格涂为橙(7)。
4. 已有非黑色像素（屏障、红标记、已涂黄/橙的格）均不被覆盖。红标记像素本身保留。

**关键洞察**：所有标记像素颜色相同（均为红(2)），但展开方向完全不同——决定因素不是标记本身的任何属性，而是其所在背景区域的拓扑性质。需对比多个示例中外部和内部区域标记的展开结果来归纳此分支规则。
