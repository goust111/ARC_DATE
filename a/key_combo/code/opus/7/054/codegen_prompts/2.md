## 新题 2：标记射线驱动的不对称纵向填充

**组合逻辑**：[射线延伸+行对齐](创新：射线从标记像素水平发射至网格边缘，射线终端成为纵向填充的起点) → [延伸填充+距离控制高度+不对称递变](创新：射线到达位置的水平距离决定纵向填充高度，且左右两侧的高度递变公式不同) + [重涂色](射线源标记的颜色决定填充色)

**来源原语**：射线延伸+行对齐(673ef223), 标记像素(673ef223), 延伸填充+距离控制高度+不对称递变(5207a7b5), 纵条(5207a7b5), 重涂色(673ef223)

**依赖链**：标记像素的行位置决定射线方向和到达列 → 射线到达列与源纵条的水平距离决定填充高度（通过不对称递变公式） → 标记像素在纵条内的相对偏移决定填充颜色。射线的空间信息同时编码了填充的位置、高度和颜色三个参数。

标记像素从中央纵条向两侧发射水平射线，射线在边缘产生纵向填充柱，填充高度随距离不对称递变，填充颜色由标记在纵条内的位置决定。

**输入结构**：约 15x15 的网格，黑(0)为背景。网格中间有一条灰(5)纵条（1 像素宽，从第 0 行延伸到第 H-1 行，H 为纵条高度，约 4~7）。纵条上有 2~4 个标记像素，分别着色为红(2)或蓝(1)，替换纵条对应行的灰色。纵条左右两侧各至少有 3 列空间。标记像素之间不相邻（至少间隔一行）。

**规则**：
1. **识别纵条和标记**：找到灰(5)纵条及其上的非灰标记像素。记录纵条高度 H 和纵条所在列 C。
2. **发射射线**：每个标记像素向左和向右各发射一条水平射线，射线颜色为该标记像素的颜色。射线在标记所在行上从纵条向外延伸，填充该行上纵条与网格边缘之间的所有背景格子（不覆盖纵条本身）。
3. **纵向填充**：对左侧每一列（距纵条水平距离为 d，d=1,2,3,...），从该列顶部向下填充 H + 2d 个格子，颜色为触发该列射线的标记像素颜色。若多条射线经过同一列，填充高度取各射线中 H+2d 的最大值，颜色取该列最上方射线的颜色。对右侧每一列（距离 d=1,2,3,...），从该列顶部向下填充 max(H - 2d, 0) 个格子，规则同上。填充高度超出网格时裁剪到网格边界。填充高度为 0 或负值时不填充。
4. **保留纵条**：灰(5)纵条像素始终保持不变，标记像素保持其原色。
5. **射线与填充柱重叠时**：射线行上的像素同时属于水平射线和纵向填充柱，保持该标记颜色不变（两者颜色一致）。

**关键洞察**：左侧填充柱随距离增高、右侧随距离缩短，这一不对称递变规则需通过对比多个示例中不同距离列的填充高度差异才能归纳。射线本身只是一维的水平线段，但它驱动了二维的不对称填充图案。
