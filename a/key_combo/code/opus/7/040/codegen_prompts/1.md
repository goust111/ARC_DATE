## 新题 1：连通分量计数驱动的周期印章阵列

**组合逻辑**：[连通检测](已有) + [计数](已有) → [周期掩码](创新：计数结果作为周期参数) → [印章覆盖](已有) + [分隔行](已有)

**来源原语**：连通检测(3194b014)、计数/计数决定尺寸(902510d5)、周期掩码(6a980be1)、印章覆盖/模板区(b4a43f3b)、分隔行(b4a43f3b/ce4f8723)

**依赖链**：分隔行将网格分为模板区和控制区。控制区中各颜色的连通分量数量被计数，计数值成为该颜色在输出中的水平重复周期。模板区提供印章内容，印章的放置位置由周期值和颜色的行分配共同决定。删除连通检测则无法得到周期；删除印章则无输出内容；删除分隔行则无法区分模板和控制区。

将模板图案按各颜色连通分量数量所确定的不同周期印入对应输出行。

**输入结构**：约 18x18 的网格，黑(0)为背景。一行完整的灰(5)分隔行将网格分为上下两区。上区为一个紧凑的模板图案（约 3x3 至 4x4 的多色小图形，颜色使用蓝(1)和红(2)构成，4-连通，无孔洞）。下区包含 2~4 种前景颜色（如绿(3)、黄(4)、橙(7)），每种颜色由若干分散的单色 4-连通小块组成（每块 1~4 像素），各颜色的连通分量数量互不相同（范围 2~5）。不同颜色的小块互不接触。生成约束：各颜色的分量数量互不相同，以保证周期唯一。

**规则**：
1. 识别灰(5)分隔行，提取上方模板区（紧裁剪为最小边界框）和下方控制区。
2. 对控制区中每种非背景颜色，计算其 4-连通单色连通分量的数量 K。
3. 构建输出网格：宽度 = 模板宽度 x 下区中分量数量最大值，高度 = 颜色种数 x 模板高度。按各颜色的分量数量从小到大排列行组（分量数最少的颜色占最上方行组）。
4. 对每种颜色，在其行组内每隔 K 个模板宽度的位置印入一份模板副本（从该行组的最左列开始，以模板宽度为步长，在第 0, K, 2K, ... 个位置处印章），印章中所有非背景像素重涂为该颜色。超出输出网格右边界的部分舍弃。
5. 行组之间不留间隔，未被印章覆盖的输出单元格为黑(0)背景。

**关键洞察**：每种控制颜色的碎片化程度（连通分量数量）不是干扰信息而是编码信号——它直接决定了该颜色在输出中的印章重复节奏，分量越少则印章越密集。
