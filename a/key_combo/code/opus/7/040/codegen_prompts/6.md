## 新题 6：切比雪夫路径被周期条纹分段变色

**组合逻辑**：[连线/切比雪夫最短路径](已有) + [周期条纹](已有) → [重涂色](创新：路径颜色按跨越条纹的次数交替) + [计数](已有) + [摘要生成](已有)

**来源原语**：连线/切比雪夫最短路径/起终点之间(992798f6)、周期条纹(6a980be1)、重涂色(50cb2852)、计数/分类计数(5289ad53)、摘要生成(5289ad53)

**依赖链**：路径的几何形状由起终点决定；条纹的位置独立于路径而存在；但路径穿越条纹的位置将路径分段，每段的颜色由其段序号的奇偶决定。穿越次数被计数后生成摘要。路径和条纹是两个独立结构，它们的交互关系（穿越事件）是涌现的——单独看路径或条纹都无法预测分段模式。

沿切比雪夫最短路径连线，每穿越一条周期条纹就交替路径颜色，并在角落生成穿越计数的摘要。

**输入结构**：约 15x15 的网格，黑(0)为背景。网格包含水平周期条纹：每隔固定间距（3~4 行间隔），有一整行灰(5)像素横贯网格。网格中有一个蓝(1)起点标记像素和一个红(2)终点标记像素，均不在灰(5)条纹行上，两者在行和列上都有距离。生成约束：蓝(1)和红(2)的位置保证切比雪夫路径至少穿越 2 条灰(5)条纹行；路径不经过网格边界外。

**规则**：
1. 计算从蓝(1)到红(2)的切比雪夫最短路径（国王走法：每步在 8 方向中选一，先走对角步消除行列差的较小值，再沿剩余轴走直线步）。路径包含起点和终点之间的所有中间像素，不包含起点和终点本身。
2. 沿路径从蓝(1)端到红(2)端逐步绘制。初始颜色为绿(3)。每当路径的下一步从非条纹行进入灰(5)条纹行，视为一次"穿越"：从该穿越点开始，路径颜色切换（绿(3)→橙(7)→绿(3)→...交替）。穿越点本身使用切换后的新颜色绘制。路径像素覆盖灰(5)条纹像素（即条纹行上的路径像素为路径颜色，非路径像素的条纹保持灰(5)不变）。
3. 统计路径的总穿越次数 C。
4. 在网格右下角，从角落像素开始，沿底边向左绘制一个 1xC 的黄(4)横条（C 个像素），作为穿越计数摘要。若 C=0 则不绘制。
5. 保留蓝(1)和红(2)标记像素不变。

**关键洞察**：路径本身不编码颜色信息，条纹本身也不编码颜色信息——路径的分段变色完全由两者的空间交叉决定，这是一个几何涌现效应。
