## 新题 8：标记选区裁剪后的最大框架内部重涂

**组合逻辑**：[标记对齐指定半区/保留标记半区](已有) + [连通检测/筛选](已有) + [空心矩形/封闭区域](已有) + [最大内部面积胜出](已有) + [重涂色/保留边框涂内部](创新：重涂色仅作用于仲裁胜出的框架)

**来源原语**：标记对齐指定半区/保留标记半区(fbf15a0b)、连通检测/筛选(3194b014)、空心矩形/封闭区域/最大内部面积胜出(445eab21)、重涂色/保留边框涂内部/内外分离(50cb2852)、裁剪(be94b721)

**依赖链**：标记像素选择保留哪一半网格（空间约简）；裁剪后的半区中包含多个空心矩形框架；框架的封闭内部面积被比较以选出最大者；仅最大框架的内部被重涂为特定颜色，其他框架保持原样。标记选区决定了哪些框架参与比较（不同半区可能有不同框架），面积比较在选定半区内进行，重涂仅影响比较的胜出者。三个阶段的逻辑依次缩小作用范围：全网格→半区→单个框架内部。

标记像素选出半区，半区中按封闭面积找到最大框架，仅将该框架内部重涂。

**输入结构**：约 12x20（宽大于高）的网格，黑(0)为背景。网格可被视为左右两半（各约 12x10）。其中一半包含 2 个橙(7)标记像素（同行或同列对齐，表示选择该半区）。两半各包含 2~3 个不同颜色的单色空心矩形框架（每个框架一像素粗，内部为黑(0)背景，颜色从蓝(1)、红(2)、绿(3)、黄(4)、品红(6)中选取，不同框架颜色不同）。框架之间互不重叠且不接触。生成约束：标记所在半区的各框架封闭内部面积互不相同，保证最大者唯一；两个标记像素不与任何框架接触。

**规则**：
1. 找到两个橙(7)标记像素，确定它们的对齐方向：
   - 若两标记同行，按它们所在的列位置判断属于左半还是右半（均在左半列范围内则选左半，均在右半列范围内则选右半）。保留该半区，裁剪掉另一半。
   - 若两标记同列，按它们所在的行位置判断属于上半还是下半。保留该半区，裁剪掉另一半。
2. 在保留的半区中，将橙(7)标记像素重涂为黑(0)背景（擦除标记）。
3. 识别半区中所有空心矩形框架（单像素粗、4-连通、单色的闭合矩形环）。
4. 对每个框架，计算其封闭内部面积（严格位于矩形环内部的背景像素数量）。
5. 选出封闭内部面积最大的框架。将该框架的内部像素（边框内缩一圈的矩形区域）全部涂为青(8)。该框架的边框像素保留原色不变。
6. 其他框架保持原样，不做任何修改。

**关键洞察**：变换的作用范围经过三级逐步聚焦——标记像素选半区（空间筛选）、面积比较选框架（属性筛选）、内外分离选像素（几何筛选）——每一级的输出都是下一级的输入域，而非独立的变换步骤。
