## 新题 5：角落三角区的模板周期填充

**组合逻辑**：[计数/计数决定尺寸](已有) + [角落控制点/三角区域](已有) + [平铺](创新：平铺被三角区域的斜边裁剪) + [模板区](已有) + [擦除](已有)

**来源原语**：计数/计数决定尺寸(902510d5)、角落控制点/三角区域(902510d5)、平铺(c62e2108/6a980be1)、模板区(b4a43f3b)、擦除(6a980be1)

**依赖链**：角落控制点确定三角区域的位置和朝向；散点计数确定三角区域的边长；模板提供平铺内容；三角区域的斜边裁剪平铺范围。四个子系统（角落定位、计数定尺寸、模板内容、三角裁剪）共同决定输出，缺一不可。原题 902510d5 中三角区域是纯色填充，这里三角区域内的内容变为周期平铺的模板图案。

统计散点数量确定三角边长，在指定角落的三角区域内周期铺设模板图案。

**输入结构**：约 16x16 的网格，黑(0)为背景。网格的某一个角落（四角之一）有一个红(2)角标记像素（恰好在角落单元格）。网格中另有一个绿(3)的紧凑模板图案（4-连通，4~9 像素，约 2x2 至 3x3 边界框，可包含背景空隙，不接触网格边界）。网格中散布着若干黄(4)单像素控制点（3~6 个，各自独立、互不相邻、不接触模板和角标记）。生成约束：黄(4)控制点数量 N 满足 N x 模板边界框尺寸 <= 网格边长，保证三角区域不超出网格。

**规则**：
1. 识别红(2)角标记像素，确定三角区域所在的角落。
2. 统计黄(4)控制点的数量 N。
3. 以角标记所在角落为直角顶点，沿该角落的两条网格边各延伸 N x max(模板边界框高度, 模板边界框宽度) 个像素，定义一个等腰直角三角区域。三角区域包含所有满足"到两条边的像素距离之和 < N x max(模板高, 模板宽)"的单元格（即从角落向外的阶梯状三角区域）。
4. 在整个网格范围内，以模板的边界框为周期单元、以角标记位置为锚点进行周期平铺（模板边界框按行列无缝重复）。仅保留落在三角区域内的平铺像素，区域外的一律为黑(0)背景。平铺使用绿(3)颜色。
5. 擦除红(2)角标记和所有黄(4)控制点（变为黑(0)背景）。若原始模板位置在三角区域内则被平铺覆盖，若在区域外则被擦除。

**关键洞察**：控制点的计数不是直接给出三角边长的像素数，而是以模板尺寸为单位的倍数——这把计数、模板尺寸和三角几何三者耦合在一起，仅知其中两个不足以确定输出。
