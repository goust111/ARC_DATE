## 新题 7：象限折叠由形状匹配确定层叠配对

**组合逻辑**：[形状匹配/旋转/翻转](已有) + [象限掩码/四象限折叠同画布](已有) → [透明叠加/层叠顺序](创新：层叠顺序由形状相似性分组决定) + [重涂色](创新：同组重叠区域执行混色规则)

**来源原语**：形状匹配/旋转/翻转/八方向匹配(898e7135)、象限掩码/四象限折叠同画布(75b8110e)、透明叠加/层叠顺序(75b8110e)、重涂色(890034e9/50cb2852)

**依赖链**：四个象限各含一个前景图形。形状匹配（含旋转/翻转）将四个图形分为两对。配对关系决定叠加时的冲突解决规则：同对图形重叠处重涂为第三色，异对图形重叠处保留后绘制者的颜色。此处形状匹配不是为了拼入框架（如源题 898e7135），而是建立分组关系来指导叠加行为——形状相似性被重新定义为一种"社会关系"而非几何填充。

折叠四象限到同画布，形状匹配确定配对，同对重叠区域特殊着色。

**输入结构**：约 (2W)x(2W) 的偶数尺寸网格（W 约 6~8），黑(0)为背景。网格被均分为四个 WxW 象限（左上、右上、左下、右下）。每个象限包含一个 4-连通单色前景图形（4~10 像素，不规则形状），四个象限的图形颜色互不相同，分别使用蓝(1)、红(2)、绿(3)、黄(4)。四个图形中恰好有两对在旋转/翻转下形状匹配（例如蓝(1)和绿(3)形状匹配，红(2)和黄(4)形状匹配）。生成约束：各图形不接触象限边界，以保证折叠后不会超出 WxW 输出画布；匹配判断在 8 种方向（4 旋转 x 2 翻转）下进行，恰好只有一种配对方案使两对都匹配。

**规则**：
1. 通过形状匹配（比较 8 种旋转/翻转下的形状）将四个象限图形分为两对。
2. 将四个象限掩码折叠到一个 WxW 输出画布上（各象限图形保持其在象限内的相对位置）。
3. 绘制顺序：左上 → 右下 → 左下 → 右上（与源题 75b8110e 相同的固定层序）。后绘制的覆盖先绘制的。
4. 冲突解决（覆盖时的颜色规则）：
   - 若后绘制的图形与先绘制的图形属于同一匹配对：重叠像素涂为灰(5)（标记同对交汇）。
   - 若后绘制的图形与先绘制的图形属于不同匹配对：重叠像素保留后绘制者的颜色（正常覆盖）。
5. 非重叠前景像素保留其原始颜色。背景保持黑(0)。

**关键洞察**：叠加的层序是固定的（与源题相同），但重叠处的颜色行为取决于形状匹配的分组——解题者必须先完成形状匹配来确定哪些是"同组"，然后才能正确解析每个重叠像素的颜色。
