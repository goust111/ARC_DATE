## 新题 7：平台槽位插入与柱状条高度偏移的双约束定位

**组合逻辑**：[rotate + size_matches_slot](旋转矩形块使其宽度匹配槽位) ∩ [height_arithmetic + color_encodes_sign](柱状条算术决定垂直偏移量) · 水平定位和垂直定位由两个独立机制分别确定，必须同时满足

**来源原语**：rotate / insert / rectangular_block / platform_slot / size_matches_slot / aligned_and_width_matched（参考题 5）、counting / height_arithmetic / color_encodes_sign / vertical_bar（参考题 14）

**依赖链**：槽位宽度匹配决定"放在哪个槽"（水平位置），柱状条算术决定"放在槽内多高"（垂直偏移）。两个约束同时作用于同一个矩形块的放置坐标，不是流水线而是并行约束汇合。

将矩形块旋转后插入宽度匹配的平台槽位，垂直放置高度由与该块同色的柱状条加减运算决定。

**输入结构**：
- 约 14x18 的黑(0)背景网格。
- 底部两行：最后一行为灰(5)实心平台行；倒数第二行由灰(5)分隔段和黑(0)间隙交替组成，间隙即槽位，宽度各不相同（2~4 像素宽），共 3 个槽位。每个槽位上方为空（黑(0)），深度至少 6 像素。
- 网格上部散布 3 个单色实心矩形块（4-连通），颜色互不相同（如蓝(1)、绿(3)、橙(7)），每个矩形一条边长为 2 像素、另一条边长为 2~4 像素。
- 网格右侧区域有若干底部对齐的 1 像素宽柱状条，每根为青(8)或红(2)。每根条底部紧邻一个 1 像素的色块，颜色与某个矩形块相同，标明该条属于哪个矩形块。
- 生成约束：每个矩形块恰好有一个宽度匹配的槽位（旋转使 2 像素边为高后，另一边宽度与某个槽位相同）；每个矩形块的柱状条算术结果（青条高度和 - 红条高度和）为 0 到 4 之间的非负整数。

**规则**：
1. 对每个矩形块，若需要则旋转使其 2 像素边为垂直方向（高度 = 2）。旋转后的宽度与某个槽位宽度相同，确定该块的目标槽位。
2. 对每个矩形块，计算其柱状条算术结果 = 所属青(8)条高度之和 - 所属红(2)条高度之和，记为偏移量 h。
3. 将每个矩形块放入其目标槽位：矩形底边距离平台行顶部 h 个像素（h=0 时底边紧贴平台行上方，h=1 时底边上移 1 格，依此类推）。矩形的水平位置与槽位左对齐。
4. 清除矩形块的原始位置为黑(0)。柱状条和标记保持不变。平台结构保持不变。

**关键洞察**：每个矩形块的最终位置由两个完全独立的编码同时决定——槽位宽度匹配编码水平坐标，柱状条算术编码垂直坐标——这是一个二维约束满足问题而非线性流水线。
