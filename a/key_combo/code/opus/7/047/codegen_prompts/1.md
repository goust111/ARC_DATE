## 新题 1：射线沿同心色带变色行进

**组合逻辑**：[射线追踪(ray_cast)](已有) + [反弹(bounce)](已有) + [同心层填充(concentric_fill)](已有，创新：填充结果不作为最终输出，而作为射线逐像素取色的色图) → 逐像素交织

**来源原语**：射线追踪(ray_cast)、反弹(bounce)、颜色继承(color_inheritance)、碰撞停止(collision_stop) 来自 #7 142ca369；同心层填充(concentric_fill)、同心正方形层(concentric_layer)、按距离循环配色(distance_color_cycling) 来自 #5 a3f84088；墙壁像素(wall_pixel) 来自 #7 142ca369

**依赖链**：同心层填充在矩形框内建立一个不可见的颜色距离场。箭头精灵体发射的对角线射线在行进时，每个像素的绘制颜色不来自射线自身或墙壁继承，而取自该位置在距离场中对应的色带颜色。墙壁像素使射线反弹，改变路径方向。路径改变使射线经过不同距离的色带区域，从而产生颜色序列的变化。没有同心填充就无法确定射线的逐像素颜色；没有射线和反弹就无法确定哪些像素被绘制。两套操作在每一个像素上交织生效。

将箭头精灵体发出的对角线射线沿同心距离色带逐像素着色，射线遇墙反弹改变路径，最终输出一条颜色随距离场变化的弯折轨迹。

**输入结构**：黑(0)背景网格，约 14x14。一个灰(5)空心矩形框（1 像素厚壁，内部至少 10x10）占据网格大部分区域。框内放置 3-5 个墙壁像素，颜色为栗(9)，分散在内部，互不相邻。一个箭头精灵体（2x2 包围框缺一角的 3 像素 L 形，颜色为品红(6)）位于框内某一角落附近。框的内部其余像素为黑(0)。生成约束：墙壁像素的位置使射线在框内至少反弹 2 次后才会到达框边界或另一个箭头；箭头缺角方向指向框内部（使射线向内部发射）。

**规则**：
1. 计算框内部每个像素到框内壁最近距离（曼哈顿距离），得到距离值 d（d=1 为紧邻框壁的一圈，d=2 为再内一圈，依此类推）。建立不可见的颜色距离场：d=1 → 红(2)，d=2 → 蓝(1)，d=3 → 黄(4)，d=4 → 红(2)，d=5 → 蓝(1)，... 以 [红(2), 蓝(1), 黄(4)] 三色循环。此距离场不绘制在输出上，仅用于后续取色。
2. 箭头精灵体从其缺角方向发射一条对角线射线（沿 45 度方向，每步行/列各移动 1 格）。
3. 射线经过的每个黑(0)背景像素，被绘制为该像素在距离场中对应的颜色。
4. 当射线到达栗(9)墙壁像素时：墙壁像素保持栗(9)不变；射线执行标准反弹——正面碰撞（下一步位置是墙壁）反转两个轴方向，侧面接触（对角线方向上仅一个轴方向被阻挡）仅翻转被阻挡的轴。射线在反弹后继续行进。
5. 当射线到达灰(5)框壁或到达箭头精灵体自身时，射线停止。
6. 箭头精灵体保持品红(6)不变。灰(5)框壁保持不变。未被射线经过的框内黑(0)像素保持黑(0)。

**关键洞察**：射线的颜色不是固有属性，而是由其所处位置在同心距离场中的坐标决定的——同一条射线在靠近框壁时呈一种颜色，经过中心区域时呈另一种颜色。反弹改变路径方向，使射线在不同距离带之间穿梭，产生颜色变化节奏完全由几何路径决定的轨迹图案。
