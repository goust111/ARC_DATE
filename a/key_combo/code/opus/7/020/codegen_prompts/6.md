## 新题 6：三角间距缺口的索引色环修补

**组合逻辑**：[补全](已有，创新：缺口位置遵循三角数列而非随机损坏) + [递增间距序列](已有) + [三角数位置](已有) + [循环填充](已有，创新：循环索引由缺口在三角序列中的位次决定)

**来源原语**：补全(complete) / 从平行行列推断(infer_from_parallel) ← b7955b3c；递增间距序列(increasing_gap_sequence) / 三角数位置(triangular_number_positions) ← 72207abc；循环填充(cyclic_fill) / 色彩循环(color_cycle) ← 72207abc；填充(fill) ← 22eb0ac0

**依赖链**：墙壁行中缺口列号 → 列号间距递增验证 → 确认三角数列模式 → 缺口按序编号 k → 左缘色彩循环参考 → C[k mod len(C)] → 缺口填色。删除三角数识别则无法区分缺口与故意留白；删除循环填充则缺口颜色不确定。

水平墙壁行在三角数列列位置有缺口；缺口按序号从左缘色彩循环中取色修补，部分缺口预填了正确颜色作为线索。

**输入结构**：约 12x20 网格（宽>高），黑(0) 背景。3~4 条水平"墙壁行"（各行使用统一前景色灰(5)），几乎横贯网格宽度。每条墙壁行在若干列位置有黑(0) 缺口。缺口列位置为三角数列：列 0, 1, 3, 6, 10, 15, ...（相邻缺口间距依次为 1, 2, 3, 4, 5, ...）。在每条墙壁行中，部分缺口（约一半）已预先填入彩色像素（从 {红(2)、蓝(1)、绿(3)} 中选取），其余缺口仍为黑(0)。左缘列 0 上（非墙壁行的位置）有 3 个纵向排列的彩色参考像素，颜色与预填色一致，从上到下定义色彩循环 C。生成约束：所有墙壁行的三角数列缺口列位置相同；预填的缺口颜色与 C[k mod len(C)] 一致（k 为该缺口在三角序列中的位次，从 0 开始）。

**规则**：
1. 识别墙壁行：连续灰(5) 像素占多数的行。
2. 在墙壁行中定位所有非灰(5) 像素的列位置（包括黑(0) 缺口和已预填的彩色像素）。验证这些列位置的间距依次为 1, 2, 3, 4, ...，确认为三角数列。
3. 将这些缺口位置从左到右编号 k = 0, 1, 2, 3, ...。
4. 读取左缘色彩循环参考（从上到下）为 C = [c0, c1, c2]。
5. 对每条墙壁行中仍为黑(0) 的缺口：该缺口的位次为 k，填入 C[k mod len(C)]。
6. 已预填正确颜色的缺口保持不变。非墙壁行不受影响。

**关键洞察**：缺口看似随机分布，但间距序列 1, 2, 3, 4, ... 表明列位置遵循三角数列。已预填的彩色缺口是双重线索——既确认三角数位置模式，又揭示色彩循环与位次的映射。求解者必须同时识别空间模式（三角数列）和颜色模式（循环索引），且两者通过位次 k 耦合：若三角数列识别错误，k 值偏移导致颜色错误；若循环识别错误，即使 k 正确颜色也错。

p = Path("/home/lixinyu/snap/a/key_combo/code/opus/7/020/6.py")
mod = SourceFileLoader("new_arc_task", str(p)).load_module()
sigs = set()
for i in range(100):
    inp = mod.generate_input()
    out = mod.main(inp)
    assert isinstance(inp, np.ndarray)
    assert isinstance(out, np.ndarray)
    assert inp.ndim == 2 and max(inp.shape) <= 30, f"input grid exceeds 30x30: {inp.shape}"
    assert out.ndim == 2 and max(out.shape) <= 30, f"output grid exceeds 30x30: {out.shape}"
    sigs.add(hashlib.md5(inp.tobytes() + str(inp.shape).encode()).hexdigest())
print("variants", len(sigs))
assert len(sigs) >= 20
