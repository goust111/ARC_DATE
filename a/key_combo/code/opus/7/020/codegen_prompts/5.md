## 新题 5：环界投射分区与内→外图例着色

**组合逻辑**：[同心正方形层](已有) + [嵌套层序](已有，创新：层界被投射为另一区域的分隔线) → [重涂色](已有，创新：图例从几何嵌套结构隐式导出) + [网格分区](已有，创新：分区线非显式画出而由环界投射产生)

**来源原语**：同心正方形层(concentric_ring) / 嵌套层序(nesting_order) / 色沿层序循环移(colors_cycle_by_nesting) ← bda2d7a6；重涂色(recolor) / 象限对应图例颜色(quadrant_mapped_by_legend) ← 58743b76；网格分区(grid_partition) / 分隔线(separator_line) / 分区区域(partitioned_region) ← 272f95fa

**依赖链**：左半区环结构 → 环层边界行列坐标 → 投射为右半区隐式分隔线 → 右半区矩形分区 → 同时，环色内→外序列 → 分区着色图例 → 右半区前景像素重涂色。删除环结构则分区线和图例均不可知；删除投射则右半区无分区；删除重涂色则无输出变化。

左半区的同心矩形环的层界行列坐标投射到右半区形成隐式分隔线，环色从内到外构成重涂色图例。

**输入结构**：约 16x12 网格（宽>高），黑(0) 背景。左半区（约列 0~5）由 3~4 层同心矩形环填满，每层 1 像素宽，颜色各异（从 {红(2)、蓝(1)、绿(3)、黄(4)} 中选取）。右半区（约列 7~15，与左半区间隔 1 列黑色）包含若干橙(7) 前景像素散布在黑(0) 背景上，形成不规则但可辨识的图案。右半区没有显式画出的分隔线。生成约束：左半区环的水平和垂直层界投射到右半区后，恰好将右半区分成与环层数相同的矩形分区（例如 3 层环产生 2 条水平线和 2 条垂直线交叉形成 3x3=9 个分区，但仅最内层的十字形区域的 5 个分区有意义——取决于具体层界数量）。实际实现：环层界产生的水平和垂直分割线数量分别等于环层数-1；这些线将右半区分成 "环层数 x 环层数" 的矩形网格。分区按阅读顺序（从左到右，从上到下）编号。

**规则**：
1. 在左半区识别同心矩形环结构。记录每层环的颜色及其边界坐标（每层的上、下、左、右边界行/列）。
2. 将环层间的边界行坐标和边界列坐标投射到右半区：若第 k 层环与第 k+1 层环在行 r 处交界，则行 r 在右半区成为一条水平隐式分隔线；列坐标同理，但需平移到右半区对应位置（左半区的第 m 条垂直层界对应右半区等分的第 m 条垂直分隔线位置）。
3. 隐式分隔线将右半区划分为矩形分区。按阅读顺序（从上到下、从左到右）将分区编号为 0, 1, 2, ...。
4. 读取环色序列：从最内层到最外层依次为 C = [c_inner, ..., c_outer]。
5. 将编号为 i 的分区中所有橙(7) 前景像素重涂为 C[i mod len(C)]。黑(0) 背景像素不变。
6. 左半区环结构在输出中保持不变。隐式分隔线不画出（它们是虚拟的）。

**关键洞察**：环结构承担双重角色——既是分区结构的空间编码（层界 → 分隔线），又是颜色图例的来源（内→外层色序列）。求解者若只注意到其中一个功能，就无法完成任务。此外，图例的阅读方向是内→外而非外→内，这一点必须对比至少两个示例才能确认——外→内会产生不同的颜色分配。

## 实现要求

1. `main(grid)` 必须实现新题描述中的确定性转换规则，不能只识别 `generate_input()` 的固定模板。禁止不同的input网格输出相同的output网格。

3. 生成器必须保证输入满足 `main()` 的隐式假设：对象不重叠、不越界、特殊标记唯一或可区分、匹配关系无歧义、关键分支出现概率相同。
4. 禁止把 ARC 颜色 id 、亮度、拼写等当作人类不可见的数值语义参与排序、大小比较或隐藏映射。颜色变化必须有可见结构线索。注意颜色亮度、拼写等也是不可见信息，若描述中出现违规的颜色id或者亮度，可自行使用少量的固定颜色替代，但注意生成时要在三个以内输入输出网格中对所有变换100%覆盖度。

6. 若规则有多个分支，生成器不能长期固定成一个分支；应让分支在随机样例中合理出现。分支概率不必平均——难以发现的隐蔽分支（如少数情况下才触发的特殊规则）应适当提高出现概率，确保在 3 个训练示例中至少出现一次，否则求解者无法归纳该规则。对于颜色映射类规则，确保 2 个左右的示例即可覆盖所有映射关系（每种颜色→颜色的映射至少在某个示例中出现过）。
