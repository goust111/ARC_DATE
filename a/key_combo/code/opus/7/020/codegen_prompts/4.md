## 新题 4：区域邻接驱动的涨缩

**组合逻辑**：[洪泛填充](已有，创新：用于拓扑分析而非最终着色) + [计数](已有) + [区域邻接](已有) → [生长](已有，创新：生长量由邻域区域数决定) / [收缩](已有，创新：收缩量由邻域区域数决定) + [面积最大者](已有，作为豁免条件)

**来源原语**：洪泛填充(flood_fill) / 四连通分区(four_connected_partition) ← 782b5218；计数(counting) / 区域邻接(region_adjacency) ← e681b708；生长(grow) / 收缩(shrink) / 面积最大者(largest_area) / 最大外扩余内缩(max_grow_rest_shrink) ← df978a02

**依赖链**：前景对象作壁垒 → 4-连通背景区域分区 → 每个对象的邻域区域计数 B → B >= 3 则生长 B 像素 / B <= 2 则收缩 B 像素 → 面积最大的对象在 B <= 2 时豁免收缩。删除洪泛填充则无法确定区域拓扑；删除计数则无法确定涨缩方向和幅度；删除面积最大者豁免则规则不完备。

前景对象以全部非背景像素为壁垒分割背景为多个区域；每个对象按其接触的背景区域数量决定生长或收缩，面积最大者在低邻接数时豁免收缩。

**输入结构**：约 13x13 网格，黑(0) 背景。4~5 个单色 8-连通前景对象，每个对象颜色各异（从 {红(2)、蓝(1)、绿(3)、黄(4)、橙(7)} 中选取），每个对象为不规则形状（3~7 像素，非简单矩形）。对象互不接触（任意两个对象间至少隔 1 个背景像素）。对象的分布将背景分成 3~5 个 4-连通区域。生成约束：恰好 1~2 个对象的 B >= 3，恰好 1~2 个对象的 B <= 2，且面积最大的对象的 B <= 2（以便展示豁免规则）。

**规则**：
1. 将所有前景像素视为壁垒。对黑(0) 背景做 4-连通洪泛填充，识别所有背景区域并编号。
2. 对每个前景对象，计算其"边界邻域区域数" B：与该对象的像素 4-相邻的背景像素所属的不同背景区域的数量。
3. 若 B >= 3：该对象生长。在该对象的所有与背景 4-相邻的像素中，选择"邻域区域数最高"的背景像素（即该背景像素本身与最多不同背景区域 4-相邻），将其涂为该对象颜色。重复此过程共 B 次。同分时选最上方、再选最左方的像素。
4. 若 B <= 2 且该对象不是面积最大的对象：该对象收缩。从该对象边界像素（至少有一个 4-邻居为背景）中移除 B 个像素（涂为黑(0)）。优先移除"邻背景像素数最多"的边界像素；同分时选最下方、再选最右方。
5. 若 B <= 2 且该对象是所有对象中面积（像素数）最大的：该对象保持原样，不收缩。
6. 所有对象同时（基于原始输入状态）计算涨缩结果后一次性写入输出。

**关键洞察**：一个对象是涨是缩取决于一个拓扑属性——它接触多少个独立背景区域——而非局部几何特征（形状、面积、位置）。两个形状和面积相似的对象可能因为一个在"三叉路口"处（B=3）而另一个在"死胡同"处（B=1）而命运相反。面积最大者的豁免是一个需要至少两个示例才能归纳出的隐蔽规则，因为它仅在特定拓扑条件下触发。
