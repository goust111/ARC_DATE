## 新题 2：周期选择多模板印章

**组合逻辑**：[周期推断](已有) + [粗模板精细替换](已有，创新：不同列的宏单元格选择不同控制精灵体) → [印章覆盖](已有，创新：多个模板参与印章而非单一模板)

**来源原语**：周期推断(period_inference) / 周期相位对应(periodic_phase_match) ← c663677b；印章覆盖(stamp_overlay) / 粗模板精细替换(coarse_to_fine_substitution) / 控制精灵体(control_sprite) / 宏单元格模式(macro_cell_pattern) ← 5833af48

**依赖链**：底部标记行 → 周期 P → 宏单元格列号 j → 相位 j mod P → 标记颜色 → 对应控制精灵体 → 替换该宏单元格的前景像素。删除周期推断则无法确定列-精灵体映射；删除印章覆盖则无法将精灵体展开到宏单元格尺寸。

底部标记行的最小重复周期决定每列宏单元格使用哪个控制精灵体进行粗→细替换。

**输入结构**：约 18x18 网格，黑(0) 背景。左侧纵向排列 2~3 个控制精灵体，每个精灵体为填满的矩形（约 3x3），内部由青(8) 和一种"标签色"两种颜色组成（标签色各不相同，从 {红(2)、绿(3)、蓝(1)} 中选取）。精灵体之间间隔 1 行黑色。右上方为宏单元格模式区：一个矩形块由灰(5) 和青(8) 的均匀宏单元格（每个宏单元格 3x3）组成，排列为 R 行 x C 列的宏网格（R, C 各 2~4）。底部第 1 行有一行标签色标记像素，颜色从左到右以最小周期 P 重复（2 <= P <= 3，P <= 控制精灵体数量）。生成约束：宏网格的列数 C >= P+1，以保证周期可被推断。

**规则**：
1. 读取底部标记行，找到其最小重复周期 P：即满足标记行中所有非黑像素按列相位一致的最小正整数 P。
2. 将宏单元格模式区的列从左到右编号 0, 1, ..., C-1。列 j 的相位 = j mod P。
3. 底部标记行中相位为 j mod P 的颜色为某标签色 L。选取左侧标签色为 L 的控制精灵体作为该列的印章模板。
4. 对每个青(8) 宏单元格：将该列对应的控制精灵体中的青(8) 像素图案印入该宏单元格对应的 3x3 输出区域；控制精灵体中的标签色像素对应位置输出为灰(5)。
5. 灰(5) 宏单元格保持为 3x3 全灰(5)。
6. 左侧控制精灵体区域和底部标记行在输出中保持不变。

**关键洞察**：参考题 5833af48 中只有一个控制精灵体应用于全部宏单元格；此题中每列宏单元格依据底部标记行的周期相位选用不同精灵体。求解者必须同时推断周期 P 和标签色→精灵体的映射关系，二者缺一不可。单个示例中即使能看到某些列用了某精灵体，但若不推断周期就无法外推到新宏网格尺寸。
