## 新题 9：遮罩平铺与嵌套深度着色

**组合逻辑**：[平铺](已有) + [掩码裁剪](已有，创新：遮罩为不规则形状而非矩形窗口) → [重涂色](已有，创新：色由遮罩内嵌套深度决定) + [嵌套层序](已有，创新：嵌套定义为距遮罩外边界的4-连通最短距离)

**来源原语**：平铺(tiling) / 瓦片互锁拼合(tile_interlocking) ← 626c0bcc；掩码裁剪(mask_crop) ← 2f0c5170；重涂色(recolor) ← 58743b76；嵌套层序(nesting_order) ← bda2d7a6；图例(legend) ← 58743b76

**依赖链**：母题瓦片 → 铺满全区 → 遮罩形状裁剪 → 仅保留遮罩内像素 → 每个保留像素计算嵌套深度（距遮罩外边界的最短4-连通步数）→ 颜色图例（角落色带）→ 按深度重涂色。删除平铺则遮罩内无纹理；删除裁剪则无遮罩；删除嵌套深度则颜色单一。

小母题瓦片在全网格上重复铺展后以不规则遮罩裁剪，裁剪保留区内每个瓦片前景像素按其距遮罩外边界的嵌套深度从角落色带中取色重涂。

**输入结构**：约 15x15 网格，黑(0) 背景。左上角（约 3x3 区域）有一个小母题瓦片，使用青(8) 像素在黑(0) 背景上形成一个简单图案（如对角线、十字等，3~5 个青(8) 像素）。网格中央有一个不规则的灰(5) 轮廓线围成的封闭区域（轮廓为 1 像素宽的 8-连通闭合曲线，围成面积约 40~60 像素）。右下角有 3~4 个纵向排列的色彩参考像素（颜色各异，从 {红(2)、蓝(1)、绿(3)、黄(4)} 中选取），定义深度→颜色映射 D = [d0, d1, d2, ...]。生成约束：遮罩区域的最大嵌套深度 >= len(D)，以便展示循环取色；母题瓦片尺寸能整除或近似整除网格尺寸以简化铺展。

**规则**：
1. 提取左上角母题瓦片（以包围盒内最小矩形为单元，包含青(8) 和黑(0) 像素）。
2. 以该瓦片为单元，在全网格上平铺（向右和向下重复），生成一张虚拟全铺网格。全铺网格中，母题中的青(8) 位置为"前景"，黑(0) 位置为"背景"。
3. 识别灰(5) 轮廓线围成的封闭区域内部（不含轮廓线本身）。内部判定：以灰(5) 像素和网格边界为壁垒做 4-连通洪泛填充，不与网格边缘连通的背景区域为"内部"。
4. 对每个内部像素计算嵌套深度 L：该像素到最近的非内部像素（灰(5) 轮廓或外部区域）的 4-连通最短路径长度。轮廓像素本身 L = 0（但不参与着色）。
5. 读取右下角色彩参考从上到下为 D = [d0, d1, d2, ...]。
6. 对内部每个像素：若该像素在全铺网格中为"前景"（青(8) 位），则涂为 D[(L-1) mod len(D)]（L >= 1）；若为"背景"（黑(0) 位），则保持黑(0)。
7. 灰(5) 轮廓线保留。轮廓外部区域保持黑(0)。左上角母题瓦片保留。右下角色彩参考保留。

**关键洞察**：平铺决定了哪些像素"存在"（前景纹理），遮罩决定了哪些像素"可见"（裁剪边界），而嵌套深度决定了可见前景像素的颜色——三者缺一不可。遮罩的不规则形状使得同一瓦片在不同位置可能落入不同深度层，导致同一母题图案在不同位置显现不同颜色，这是规则矩形裁剪不会出现的效果。

## 实现要求

1. `main(grid)` 必须实现新题描述中的确定性转换规则，不能只识别 `generate_input()` 的固定模板。禁止不同的input网格输出相同的output网格。
2. `generate_input()` 必须随机生成多样样例，不能固定死。随机维度应覆盖：网格大小、对象数量、位置、颜色、方向、形状参数或关键分支。注意若描述中存在若干，需实现而不是只有单个，包括object或者对应关系等等。
3. 生成器必须保证输入满足 `main()` 的隐式假设：对象不重叠、不越界、特殊标记唯一或可区分、匹配关系无歧义、关键分支出现概率相同。
4. 禁止把 ARC 颜色 id 、亮度、拼写等当作人类不可见的数值语义参与排序、大小比较或隐藏映射。颜色变化必须有可见结构线索。注意颜色亮度、拼写等也是不可见信息，若描述中出现违规的颜色id或者亮度，可自行使用少量的固定颜色替代，但注意生成时要在三个以内输入输出网格中对所有变换100%覆盖度。
5. 输出样例要视觉清晰，人类必须能从输入输出对中肉眼辨认出规律。具体要求：避免对象粘连、覆盖关系混乱、同一像素多重语义；不同逻辑步骤产生的结果不要大面积层叠在一起导致无法分辨哪个颜色属于哪个步骤；输入中各元素之间保持足够间距，输出中新增的标记/填充/路径等应与背景和已有元素在颜色上有明显区分；若规则涉及多层叠加，生成时控制对象密度和尺寸，确保叠加区域只占少数像素而非铺满整个网格。
6. 若规则有多个分支，生成器不能长期固定成一个分支；应让分支在随机样例中合理出现。分支概率不必平均——难以发现的隐蔽分支（如少数情况下才触发的特殊规则）应适当提高出现概率，确保在 3 个训练示例中至少出现一次，否则求解者无法归纳该规则。对于颜色映射类规则，确保 2 个左右的示例即可覆盖所有映射关系（每种颜色→颜色的映射至少在某个示例中出现过）。
