## 新题 6：象限定位 + 字形字典查表的区域印章

**组合逻辑**：[象限映射](控制像素的象限位置确定目标区域) + [编码映射](控制像素颜色查字形字典) → [图案印章](将查到的字形印入对应象限) → [裁剪](输出仅保留面板区域)——两个独立查找操作（空间查找：哪个象限；颜色查找：哪个字形）的结果交叉组合确定"什么内容放在哪里"（创新：象限选址与字形选型解耦后再组合）

**来源原语**：象限映射/quadrant_mapping(19bb5feb)、图案印章/stamp_glyph(dfadab01)、裁剪/clip(dfadab01)、压缩/compress(19bb5feb)、控制像素/control_pixel(dfadab01, 52fd389e)、实心矩形面板/solid_rectangular_panel(19bb5feb)、字形字典/glyph_dictionary(dfadab01)、标记在面板象限内/marker_in_panel_quadrant(19bb5feb)、编码映射/encoding_map(dfadab01)

**依赖链**：控制像素的位置 → 象限定位（决定字形印在哪个区域）；控制像素的颜色 → 字形字典查表（决定印什么字形）。两条线汇合后才能完成印章操作。删去象限定位则不知道字形放在哪里；删去字形查表则不知道放什么内容。

将面板内各象限的控制像素颜色映射到字形字典，把对应字形印入该控制像素所在象限的中心位置。

**输入结构**：约 16x20 的黑(0)背景网格，分为左右两个区域。左侧区域为字形字典：2~4 个小型图案（每个为 3x3 像素的单色图形），自上而下排列，左边紧邻一个同色单像素标签——标签颜色即该字形的键色（如蓝(1)、红(2)、黄(4)、橙(7)）。字形内部图案各不相同（如十字形、对角线、框形等）。右侧区域为一个灰(5)实心矩形面板（约 12x12），面板内有 2~4 个单像素控制点，每个控制点的颜色匹配字形字典中的某个键色。控制点分散在面板的不同象限（将面板沿中心水平线和竖直线分为左上、右上、左下、右下四个象限）。每个象限最多一个控制点。生成约束：字形字典中的键色集合包含所有控制点颜色；每个象限足够大以容纳 3x3 字形。

**规则**：
1. 识别右侧灰(5)面板的边界框，将其内部沿中心横线和中心竖线分为四个象限（行数或列数为奇时中心线归左上象限）。
2. 识别左侧字形字典：每个字形是 3x3 图案，其键色由紧邻左侧的单像素标签确定。
3. 对面板内每个控制像素：(a) 确定其所在象限 Q；(b) 根据其颜色在字形字典中查找对应的 3x3 字形。
4. 将查到的字形印在象限 Q 的中心位置：字形的中心像素对齐到象限中心（象限行范围和列范围的中点）。字形使用其在字典中的原始颜色（即控制像素的颜色）绘制。
5. 移除控制像素（恢复为灰(5)面板色）。
6. 无控制像素的象限保持灰(5)面板色不变。
7. 输出仅包含面板区域（裁剪掉字形字典和面板外的所有像素）。

**关键洞察**：控制像素同时承载两种信息——位置信息（确定目标象限）和颜色信息（查找字形内容）。源题中这两类信息分别属于不同谜题（象限映射 19bb5feb 只关心位置、字形印章 dfadab01 只关心颜色），此处两个查找必须组合才能完成任务。
