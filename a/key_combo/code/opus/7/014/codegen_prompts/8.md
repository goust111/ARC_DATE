## 新题 8：周期瓦片补全为透明叠加恢复双面板掩码

**组合逻辑**：[补全](用平移对称性修复各半区的缺损瓦片) → [透明叠加](将修复后的两个半区作为掩码做位置并集) + [背景替换](输出背景改色)——补全是叠加的前置预处理（创新：周期修复不是终态而是数据恢复手段），分隔行同时定义半区边界和叠加对齐

**来源原语**：补全/inpaint(0dfd9992)、透明叠加/transparent_overlay(506d28a5)、背景替换/background_replace(32e9702f)、周期瓦片/periodic_tile(0dfd9992)、分隔行/divider_row(506d28a5)、二值掩码/binary_mask(506d28a5)、平移对称/translational_symmetry(0dfd9992)、双面板对齐/dual_panel_alignment(506d28a5)、轨道可见色填缺失/orbit_color_restores_missing(0dfd9992)、任一前景即输出/either_foreground_yields_output(506d28a5)

**依赖链**：两个半区各有缺损的周期瓦片 → 补全修复缺损 → 修复后的每个半区被视为二值掩码（任何非黑像素 = 前景）→ 两个掩码位置并集输出。删去补全则掩码有缺损，叠加结果错误；删去叠加则补全只是修复，无后续意义。

修复被分隔行分开的两组缺损周期瓦片，将修复后的两组分别视为掩码做位置并集输出。

**输入结构**：约 15x15 的黑(0)背景网格（行数为奇数），由一条品红(6)分隔行（完整的水平行）均分为上下两个大小相等的矩形半区（各 (H-1)/2 行）。上半区包含一个周期瓦片图案，使用蓝(1)作为前景色，但部分像素被替换为黑(0)（表示缺损，3~6 个像素）。下半区包含另一个独立的周期瓦片图案，使用红(2)作为前景色，同样有部分像素被替换为黑(0)（缺损位置与上半区不同）。两个半区的瓦片各自具有独立的平移周期（如上半区周期为 3x3，下半区周期为 2x4，周期不一定相同）。生成约束：每个半区的非缺损像素足以唯一确定其平移周期和完整瓦片图案。

**规则**：
1. 识别品红(6)分隔行，将网格分为上下两个半区。
2. 对上半区：检测蓝(1)前景像素的平移对称性，找到最小平移周期向量；利用平移对称性，将每个黑(0)缺损像素替换为其平移轨道中可见像素的颜色（蓝(1)或黑(0)的正确值）。
3. 对下半区：同样检测红(2)前景像素的平移对称性并修复所有缺损。
4. 修复后，将每个半区视为二值掩码：非黑(0)像素 = 前景，黑(0)像素 = 背景。
5. 输出一个与单个半区大小相同的网格（移除分隔行）。
6. 输出的每个像素：若上半区掩码或下半区掩码中对应位置至少有一个为前景，则输出绿(3)；否则输出灰(5)。
7. 分隔行不出现在输出中。

**关键洞察**：周期瓦片补全在源题中是最终目标（恢复美观图案），此处仅是中间步骤——补全的目的是生成准确的二值掩码供后续叠加使用。如果不先修复缺损就直接叠加，输出会在缺损位置产生错误。两种半区的瓦片周期可以不同，需要独立分析。
