## 新题 3：周期性与轴对称联合约束恢复标记空洞

**组合逻辑**：[平铺/tile + 周期/period](已有) + [对称补全/symmetry_completion + 双轴镜像/biaxial_mirror](创新：对称仅用于补充周期性无法恢复的位置，两种约束同时作用于同一数据) + [标记色空洞/marker_color_hole](已有)

**来源原语**：平铺(tile, 963e52fc), 周期(period, 963e52fc), 对称补全(symmetry_completion, b8825c91), 双轴镜像(biaxial_mirror, b8825c91), 标记色空洞(marker_color_hole, b8825c91), 标记处填入轨道色(fill_marker_with_orbit_color, b8825c91)

**依赖链**：周期性约束从非标记像素推断水平重复单元，为大部分标记像素恢复颜色；但某些列位置的所有周期副本均被标记遮蔽，周期性无法单独确定——此时调用重复单元内的垂直镜像对称补全剩余位置。两种约束在数据层面互补而非流水线串联：周期性覆盖空间维度，对称性覆盖单元内结构维度，缺任何一种都无法完全恢复所有空洞。

通过水平周期性和周期单元内部的垂直镜像对称两种约束联合确定所有标记空洞的颜色，任一约束单独使用均不充分。

**输入结构**：约 10x18 的网格（高度 10 行，宽度 18 列），使用 3-4 种非背景色（从蓝(1)、红(2)、绿(3)、灰(5)中选取）在黑(0)背景上形成水平重复图案。水平周期 P 为 4-6 列。每个周期单元（P 列宽、10 行高的子网格）内的图案具有垂直镜像对称（第 1 列与第 P 列镜像、第 2 列与第 P-1 列镜像，依此类推）。部分像素被替换为黄(4)标记色。标记放置满足：至少一个周期单元内的列位置，其所有周期副本均为黄(4)标记——因此仅用周期性无法恢复该位置。但该位置在周期单元中的镜像伙伴位置至少有一个非标记副本可用。生成约束：非标记像素足以唯一确定完整周期单元。

**规则**：
1. 识别标记色：黄(4)是唯一的颜色，使得去除它后剩余像素与某个水平周期一致。
2. 从非标记像素推断最短水平周期 P。
3. 对于周期单元中的每个列位置 c（c = 1, 2, ..., P）：收集该列位置在所有周期副本中的非标记像素值。若至少有一个非标记值存在，则该值即为列位置 c 的真实颜色——用它替换该列位置所有周期副本中的标记像素。
4. 若某列位置 c 在所有周期副本中全部是标记：利用周期单元的垂直镜像对称，找到其镜像伙伴位置 c'（c' = P + 1 - c）。该伙伴位置必定在步骤 3 中已被确定颜色。用伙伴位置的颜色值逐行填入位置 c 的所有标记像素。
5. 输出中不保留任何黄(4)像素，所有标记均被替换为推断出的颜色。

**关键洞察**：周期性和对称性不是先后执行的两步操作，而是对同一组空洞的两种互补恢复手段。求解者必须意识到某些列"全被遮蔽"的异常情况，并从周期性切换到对称性来恢复——仅凭一个示例无法确定对称约束的存在，必须对比多个示例才能发现这一隐蔽规则。

import hashlib
import numpy as np

p = Path("/home/lixinyu/snap/a/key_combo/code/opus/7/008/3.py")
mod = SourceFileLoader("new_arc_task", str(p)).load_module()
sigs = set()
for i in range(100):
    inp = mod.generate_input()
    out = mod.main(inp)
    assert isinstance(inp, np.ndarray)
    assert isinstance(out, np.ndarray)
    assert inp.ndim == 2 and max(inp.shape) <= 30, f"input grid exceeds 30x30: {inp.shape}"
    assert out.ndim == 2 and max(out.shape) <= 30, f"output grid exceeds 30x30: {out.shape}"
    sigs.add(hashlib.md5(inp.tobytes() + str(inp.shape).encode()).hexdigest())
print("variants", len(sigs))
assert len(sigs) >= 20
