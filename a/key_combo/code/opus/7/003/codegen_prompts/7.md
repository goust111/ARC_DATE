## 新题 7：路径生长到达的框边颜色决定轨迹着色

**组合逻辑**：[生长/grow](创新：路径生长的终点不是网格边界，而是语义实体——矩形框的某条边) + [连线/connect](创新：连线不是从散落点到框边的直线，而是沿路径生长的弯曲轨迹) + [重涂色/recolor](创新：重涂色的颜色不由属性查表决定，而是由几何终点决定) + [遇障碍则绕行/detour_on_obstacle] + [颜色对应边/color_to_side]

**来源原语**：生长、遇障碍则绕行、起点像素、障碍像素（d9f24cd1）；连线、矩形框、颜色对应边（5daaa586）；重涂色（a8610ef7）

**依赖链**：路径生长的轨迹（含绕行）决定路径最终到达框的哪条边；框边颜色反过来决定整条路径轨迹的着色。路径轨迹形状、终点位置、轨迹颜色三者环环相扣——改变一个障碍就可能改变路径到达的框边，从而改变整条轨迹的颜色。

路径从底部起点向上生长并绕过障碍，最终到达彩色矩形框的某条边；整条路径轨迹被重涂为它所到达的那条框边的颜色。

**输入结构**：黑(0)背景，约 15x13 网格。一个矩形框占据网格中央区域（约 9x9），框的四条边各用不同颜色的单像素线绘制：上边红(2)、左边蓝(1)、右边绿(3)、下边黄(4)。角落像素颜色取所在两条边中的上边或左边的颜色。框内部和框外部均为黑(0)背景。框外下方区域有 2-3 个黄(4)起点像素，位于框下边的正下方若干行处。框外部散布着灰(5)障碍像素，位于起点和框之间。生成约束：每个起点像素通过向上生长并绕行后，能且仅能到达框的一条边（上/左/右之一，不会到达下边因为路径从下方来）；不同路径不会交叉或共享像素；至少有两条路径到达不同的边。

**规则**：
1. 对每个黄(4)起点像素 S，从 S 开始逐步向上生长路径：
   - 优先尝试向上移动一格（行-1，列不变）。
   - 若上方为灰(5)障碍，则尝试向右移动一格（行不变，列+1）。
   - 若右方也是障碍或已到达网格右边界，则向左移动一格（行不变，列-1）。
   - 记录路径经过的每个格子。
2. 路径在触碰到矩形框的任一边像素时停止（不覆盖框像素本身）。
3. 确定路径停止时相邻的框边颜色 C。
4. 将路径经过的所有格子（不含起点和框边像素）重涂为颜色 C。
5. 起点像素保持黄(4)不变。矩形框保持原样。

**关键洞察**：路径的颜色不在起点决定，而在终点决定——只有完成全部生长并到达框边后，才能回溯为整条路径赋色。障碍的布局同时影响路径形状和最终着色。
