## 新题 3：格点间隙连通决定腔室填色与优先级

**组合逻辑**：[泛洪填充/flood_fill] + [填充/fill] + [计数/counting](创新：计数结果不驱动重复次数，而是编码优先级权重) + [格点骨架/lattice_frame] + [封闭腔室/enclosed_cavity] + [可达性/reachability]

**来源原语**：泛洪填充、可达性（8f3a5a89）；填充、格点骨架、封闭腔室、标记像素（17b866bd）；计数（4852f2fa）

**依赖链**：泛洪填充通过格点间隙传播，确定每个标记可到达的腔室集合。多个标记的可达集合可能重叠——冲突腔室归属于可达腔室总数最少的标记（即"活动范围最受限的标记优先"）。填色操作依赖泛洪结果和全局计数排序，三者环环相扣。

多色标记坐落在格点腔室中，通过间隙泛洪扩散；可达腔室总数最少的标记在冲突区域拥有优先填色权。

**输入结构**：黑(0)背景，约 17x17 网格。青(8)像素构成正交格点骨架（横竖线交叉），将内部分割为约 3x3 或 4x4 大小的黑(0)封闭腔室，总计约 9-16 个腔室。骨架中有 2-4 个单像素间隙（青像素被替换为黑(0)），使相邻腔室通过间隙连通。2-3 个不同颜色的标记像素（如红(2)、蓝(1)、绿(3)），各位于不同腔室中。生成约束：至少有一个腔室被两个不同标记同时可达；每个标记至少可达 2 个腔室；不同标记的可达腔室总数互不相等。

**规则**：
1. 对每个标记像素 M，以 M 所在腔室为起点，通过骨架间隙进行泛洪填充（扩散只穿过黑(0)像素，不穿过青(8)骨架像素），记录 M 可达的所有腔室集合 R(M)。
2. 计算每个标记的可达腔室总数 |R(M)|。
3. 对每个可达腔室分配颜色：
   - 若该腔室仅被一个标记可达，填充为该标记的颜色。
   - 若被多个标记可达，填充为其中 |R(M)| 最小的标记的颜色（可达范围最受限者优先）。
4. 将标记像素本身也视为其所在腔室的一部分，随腔室一同填色（标记像素被覆盖）。
5. 不可达的腔室保持黑(0)。骨架保持青(8)不变。

**关键洞察**：冲突解决规则要求全局视角——不能独立处理每个标记，必须先统计所有标记的可达集合大小，再根据"最受限者优先"原则分配颜色。这使得局部泛洪结果与全局计数排序形成紧耦合。
