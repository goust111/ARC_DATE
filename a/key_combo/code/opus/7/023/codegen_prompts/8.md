## 新题 8：缺陷修补与旋转补全的循环依赖

**组合逻辑**：[修补/嵌入与孤立](创新：嵌入判定需在旋转补全的假设下进行而非直接判定) + [旋转/对称补全](创新：补全的前提是先识别出缺陷并排除) + [射线延伸/边缘指示方向](创新：边缘线指示旋转中心而非射线方向)

**来源原语**：修补/嵌入与孤立/主体对象/标记像素(8886d717)、旋转/对称补全/四次旋转闭合/正方形区域(e40b9e2f)、射线延伸/边缘线/边缘指示方向(8886d717)

**依赖链**：主体对象接近四次旋转对称但含有标记色缺陷；边缘线的位置（行或列）指示旋转中心；求解者必须先假设旋转对称成立来判断哪些标记是"嵌入缺陷"（在旋转对应位置上应有主体色）、哪些是"真实特征"（所有旋转位置上一致存在）；修补嵌入缺陷后再执行旋转补全。修补和补全互为前提——不修补则无法识别对称轴，不知道对称轴则无法判断哪些是缺陷。

一个接近旋转对称的主体对象中混有标记色缺陷像素；边缘线指示旋转中心；只有在旋转对应位置缺少同色像素的标记才是缺陷（修补为主体色），其余标记是真实特征（保留并参与旋转补全）。

**输入结构**：约 15x15 的网格，背景黑(0)。网格的某一边（上边或左边）有一条贯穿的边缘线，颜色为灰(5)，宽 1 像素。网格中央有一个蓝(1)色的大型 4-连通主体对象（约 8x8 像素范围内，占据 15~25 个像素），对象整体接近四次旋转对称但不完全——部分位置缺少像素（需要补全），另有 2~4 个红(2)标记像素散布在对象内部或紧邻对象。标记像素分两类：(a) "缺陷标记"——该标记的旋转对应位置（0/90/180/270度）上其他三个位置要么是蓝(1)主体色要么为空，即该标记打断了旋转对称性；(b) "特征标记"——该标记的旋转对应位置上至少还有一个位置也是红(2)标记或将在补全后也成为标记。旋转中心由边缘线确定：若边缘线在上边（水平），则旋转中心的行坐标 = 边缘线行号，列坐标 = 主体对象边界框的水平中心（四舍五入）；若边缘线在左边（竖直），则旋转中心的列坐标 = 边缘线列号，行坐标 = 主体对象边界框的竖直中心。生成约束：至少有 1 个缺陷标记和 1 个特征标记；修补缺陷后主体对象恰好可以四次旋转闭合补全。

**规则**：
1. 识别边缘线（灰(5)，贯穿某一边）和主体对象（蓝(1)最大 4-连通分量）。
2. 确定旋转中心：若边缘线水平（在第 r 行），中心 = (r, 主体bbox水平中心列)；若边缘线竖直（在第 c 列），中心 = (主体bbox竖直中心行, c)。中心坐标取整数（边界框宽或高为偶数时取 floor((left+right)/2) 和 floor((top+bottom)/2)）。
3. 对每个红(2)标记像素 P，计算其在 90 度、180 度、270 度旋转下的三个对应位置。若这三个位置中没有任何一个也是红(2)标记，则 P 为缺陷标记，将其修补为蓝(1)主体色。否则 P 为特征标记，保留红(2)。
4. 修补完成后，对所有蓝(1)像素执行四次旋转对称补全：每个蓝(1)像素在 90/180/270 度旋转位置也涂为蓝(1)（若该位置在网格内且为黑(0)背景）。
5. 对所有红(2)特征标记也执行同样的旋转补全：每个红(2)像素在旋转位置也涂为红(2)。若旋转位置已有蓝(1)，红(2)覆盖蓝(1)。
6. 边缘线在输出中保留不变。

**关键洞察**：修补和旋转补全形成循环依赖：要判断标记是否为缺陷需要知道旋转中心和对称假设，而正确的对称只有在缺陷被修补后才成立。求解者必须同时推理"如果这是对称的，那么哪些标记破坏了对称"，这种"假设-验证"式推理在单纯的线性流水线中不会出现。
