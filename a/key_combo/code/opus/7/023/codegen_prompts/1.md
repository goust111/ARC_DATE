## 新题 1：蛇径定序的框内重涂

**组合逻辑**：[遍历顺序](创新：遍历顺序不用于展直而用于定义优先级) + [矩形框/边框包围内容](已有) + [重涂色](创新：目标色由遍历到达时的蛇身颜色决定) + [计数/内部标记计数](创新：计数结果用于筛选而非擦除)

**来源原语**：遍历顺序/蛇形路径(7b5033c1)、矩形框/边框包围内容(1a6449f1)、重涂色(c3fa4749)、计数/内部标记计数(54db823b)

**依赖链**：蛇径的遍历顺序为每个被穿过的矩形框分配一个到达序号；框内灰(5)标记像素的计数筛选出需要重涂的框（仅保留标记数超过 1 的框）；被保留框的内部全部重涂为蛇身在该框处的像素颜色；未被蛇穿过或标记数不足的框连同边框一并擦为背景。遍历提供排序、计数提供筛选、重涂执行变换——三者缺一不可。

在一张网格上，一条多色蛇形路径穿过若干单色矩形框；蛇到达每个框时的身体颜色决定该框内部的输出颜色，但只有框内灰(5)标记像素数量大于 1 的框才被保留并重涂，其余框连同边框一并擦除。

**输入结构**：约 18x18 的网格，背景黑(0)。网格中散布 3~5 个完整单色矩形框（边框一像素厚，每个框的边框颜色互不相同，使用蓝(1)、绿(3)、黄(4)、品红(6)中的若干种），框内部分单元格为灰(5)标记像素（每框 0~3 个灰像素），其余内部为黑(0)背景。一条 4-连通蛇形路径从网格的一端延伸到另一端，蛇身每段由不同非黑非灰颜色组成（可使用红(2)、橙(7)、青(8)、栗(9)），蛇经过某些框时穿过框的边框进入内部再穿出。蛇恰好有两个端点（各只有一个路径邻居）。各矩形框互不重叠，蛇路径与框边框的交叉处恰好各一个入口像素和一个出口像素。生成约束：蛇穿过的框中至少有一个框的灰标记数 <= 1，保证筛选确实去除了某些框。

**规则**：
1. 找到蛇形路径的两个端点，以行号较小者为起点（行号相同则取列号较小者），沿 4-连通路径逐像素遍历。
2. 记录蛇进入每个矩形框时（即蛇身像素首次落入框边框所围区域的那一步），该蛇身像素自身的颜色，称为"到达色"。
3. 对每个矩形框，统计其严格内部（不含边框）的灰(5)像素数量。
4. 若某框的灰像素数量 > 1，则将该框的严格内部所有像素（含灰标记）统一重涂为该框的到达色，边框保留原色不变。
5. 若某框的灰像素数量 <= 1，或该框未被蛇穿过，则将该框的边框和内部全部擦为黑(0)背景。
6. 蛇形路径本身在输出中全部擦为黑(0)背景。

**关键洞察**：蛇路径本身不出现在输出中，它纯粹充当"调色探针"——只有同时满足"被蛇穿过"且"内部灰标记足够多"两个独立条件的框才存活，而存活框的内部颜色由蛇到达瞬间的颜色唯一确定。
