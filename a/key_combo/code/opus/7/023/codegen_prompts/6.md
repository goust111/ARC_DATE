## 新题 6：镜像周期延伸中的孔洞守恒

**组合逻辑**：[周期延伸/长度即周期](创新：每个周期内执行一次镜像翻转而非简单复制) + [镜像](创新：镜像交替应用于周期副本) + [膨胀](创新：延伸区域的外框膨胀一像素作为边界光晕) + [封闭孔洞/孔洞保留不填](创新：孔洞在镜像和膨胀中均必须保留)

**来源原语**：周期延伸/长度即周期/分隔列(1ae2feb7)、镜像(6d0aefbc)、膨胀/封闭孔洞/孔洞保留不填(5adee1b2)

**依赖链**：分隔列一侧有带孔洞的彩色对象，对象宽度为延伸周期；向另一侧延伸时，奇数周期副本做左右镜像、偶数周期副本保持原样；每个副本外框膨胀一像素画光晕色边框；孔洞在镜像和膨胀中均保留（光晕不填入孔洞内部）。周期→镜像交替→膨胀→孔洞保留四个约束同时作用。

带孔洞的对象以自身宽度为周期向分隔列对面延伸，奇数次副本镜像翻转，每个副本外扩一像素光晕，孔洞全程保留不填。

**输入结构**：约 12x22 的网格，背景黑(0)。一条竖直灰(5)分隔列（宽 1 像素）将网格分为左右两半。左半包含 1~2 个彩色 4-连通对象（使用红(2)或蓝(1)），每个对象宽 3~4 列、高 3~5 行，对象内部包含至少一个封闭孔洞（即被对象像素完全包围的黑(0)区域，大小 1~2 像素）。右半为空白目标区域。左半另有一个 2x2 图例块紧贴网格左边缘：左列为对象色，右列为对应光晕色（使用绿(3)、黄(4)等）。右半宽度足够容纳至少 3 个周期的延伸。生成约束：对象不触碰分隔列（至少间隔 1 列），对象的形状在左右镜像后不与自身完全相同（保证镜像步骤可观察）。

**规则**：
1. 识别灰(5)分隔列。识别左半的彩色对象及其封闭孔洞。识别左边缘图例块，建立对象色→光晕色映射。
2. 对每个对象，取其边界框宽度 W 作为延伸周期。
3. 从分隔列右侧第一列开始，逐周期向右绘制对象副本：
   - 第 1 个副本（奇数）：将对象左右镜像后绘制。
   - 第 2 个副本（偶数）：保持对象原样绘制。
   - 第 3 个副本（奇数）：再次镜像。依此交替。
   - 每个副本的垂直位置与原对象相同（顶边行号一致）。
   - 副本之间紧密排列，无间隔。
   - 延伸直到下一个副本的任何像素超出网格右边界时停止（不绘制不完整的副本）。
4. 对每个已绘制的副本（不含原始左半对象），将其边界框向四周各扩展 1 像素（裁剪到网格边界内），在扩展区域中仅将黑(0)背景像素涂为该对象的光晕色。但：若扩展区域中的某黑(0)像素位于该副本的封闭孔洞内部（即该黑像素被副本像素在 4-连通意义下完全包围），则不涂光晕色，保留黑(0)。
5. 不同副本的光晕若重叠，后绘制的（更右侧的）覆盖先绘制的。
6. 分隔列灰(5)像素保留不变。左半原始对象和图例块保留不变。

**关键洞察**：参考题中周期延伸是简单的同向复制，此题中每个周期交替镜像翻转——这意味着孔洞的位置在相邻副本中左右颠倒，而膨胀光晕必须识别每个副本各自的孔洞拓扑才能正确保留。单纯记住"孔洞不填"的规则不够，还必须在每个镜像副本中重新计算孔洞位置。
