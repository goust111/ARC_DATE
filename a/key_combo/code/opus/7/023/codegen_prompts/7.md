## 新题 7：行列乘积定位后的蛇径展直读出

**组合逻辑**：[提取/行列乘积完整](创新：乘积判据不直接输出子图而是定位蛇径的读取区域) + [展直/蛇形路径/遍历顺序](创新：展直不作用于整条蛇而仅作用于蛇在乘积区域内的子段) + [裁剪](创新：输出是蛇径子段展直后的单列而非矩形裁剪)

**来源原语**：提取/双色图像/行列乘积完整(b71a7747)、展直/蛇形路径/遍历顺序/端点/保留像素序(7b5033c1)、裁剪(a87f7484)

**依赖链**：网格中隐藏一个双色区域满足行列乘积完整条件——该区域覆盖的行列定义了一个"窗口"；一条多色蛇形路径穿过整个网格，蛇在窗口内的子段被截取；子段按遍历顺序展直为单列输出。乘积判据→窗口→蛇截取→展直，四步缺一不可。

网格中有一条贯穿的多色蛇形路径和一个隐藏的双色行列乘积区域；找到该区域覆盖的行列作为窗口，截取蛇在窗口内的子段，按遍历顺序展直为单列输出。

**输入结构**：约 15x15 的网格，背景黑(0)。网格中有两层结构叠加：(a) 一条 4-连通蛇形路径贯穿网格，蛇身每像素颜色不全相同，使用红(2)、绿(3)、蓝(1)中的若干种轮替，蛇恰好有两个端点；(b) 一组由黄(4)和橙(7)两种颜色构成的像素散布在网格中（不与蛇重叠），这两种颜色的像素恰好占据某些行和某些列的完整交叉（即它们的行集 R 和列集 C 的笛卡尔积 R x C 中每个位置都被黄或橙占据，且不被其他颜色占据）。其余非蛇非乘积区域为黑(0)背景。蛇路径穿过乘积区域所在的若干行列，在窗口内有连续的子段。生成约束：蛇在窗口（R x C 定义的矩形）内的子段是连续的（蛇进入窗口后不离开再重新进入）；蛇在窗口内的子段长度 >= 3。

**规则**：
1. 找到满足行列乘积完整条件的唯一颜色对：枚举所有非背景非蛇色的颜色对，找到一对颜色使得它们共同占据的像素恰好是某行集 R 和列集 C 的笛卡尔积。记录 R 和 C。
2. 定义窗口为行集 R 和列集 C 所界定的矩形区域（min(R) 到 max(R) 行，min(C) 到 max(C) 列）。
3. 找到蛇路径的两个端点，以行号较小者为起点（行号相同取列号较小者），沿 4-连通路径遍历整条蛇。
4. 在遍历过程中，记录蛇进入窗口后连续经过的所有蛇身像素（即位于窗口矩形内的连续子段），按遍历顺序排列。
5. 输出一个 K x 1 的单列网格（K 为子段像素数），每行一个像素，颜色为蛇身子段按遍历顺序的对应颜色。

**关键洞察**：行列乘积区域在参考题中是直接提取的输出目标，此题中它仅作为"定位器"——定义一个隐式窗口来截取蛇路径的某段。求解者必须先发现行列乘积结构来确定窗口，再用蛇的遍历逻辑来读取窗口内的内容，两种来自不同参考题的判据在此交汇于同一空间区域。
