## 新题 10：侧边定色与面积排名的擦除竞争

**组合逻辑**：[接触侧定色](创新：侧边颜色不用于重涂而用于分组) + [面积排名](创新：排名在组内而非全局进行) + [擦除/最少标记者选中](创新：擦除对象不由标记数决定而由组内面积排名决定) + [填充](创新：擦除腾出的空间由同组存活者填充)

**来源原语**：接触侧定色/侧边标记/多色对象(c3fa4749)、面积排名(a87f7484)、擦除(54db823b)、填充/最近角距离(4a1cacc2)

**依赖链**：每个对象的侧边标记颜色将对象分入不同组；组内对象按面积排名，面积最小者被擦除；擦除后腾出的空间由同组中面积最大的对象向被擦除者方向填充矩形。分组→组内排名→擦除→定向填充四步耦合。

多个带侧边标记的对象按标记色分组，每组中面积最小的对象被擦除，腾出的空间由同组面积最大的对象朝被擦者方向填充矩形。

**输入结构**：约 18x18 的网格，背景黑(0)。包含 4~6 个蓝(1)色 4-连通单色对象（形状不规则，面积 4~12 像素不等），各对象互不相邻（边界框间距 >= 2）。每个对象的边界框恰好有一条边紧贴一个单像素宽的侧边标记条：该标记条由红(2)或绿(3)像素组成，长度等于对象在该边上的跨度。同色标记的对象属于同组。生成约束：红(2)标记组和绿(3)标记组各至少 2 个对象；每组内对象面积互不相同（保证面积排名唯一）。

**规则**：
1. 识别所有蓝(1)对象及其侧边标记。每个对象的侧边标记是紧贴其边界框某一边的非蓝非黑色条（红(2)或绿(3)），标记的颜色确定该对象所属的组。
2. 在每组内，按对象的前景像素面积从大到小排名。
3. 每组中面积最小的对象（排名末位）连同其侧边标记一起擦除为黑(0)背景。
4. 每组中面积最大的对象（排名首位）执行填充扩展：从该对象的边界框出发，向被擦除对象所在的方向（取两对象边界框中心的主基方向：上/下/左/右，取位移绝对值最大的轴方向）画一个矩形，矩形宽度等于该最大对象边界框在垂直于扩展方向上的跨度，矩形延伸到被擦除对象原边界框的近边位置（含），颜色为蓝(1)。填充不覆盖已有的非背景像素。
5. 组内排名居中的对象（既非最大也非最小）保留不变，其侧边标记也保留。
6. 最大对象的侧边标记保留不变。

**关键洞察**：侧边标记在参考题中用于决定重涂颜色，此题中标记颜色不影响任何像素的最终颜色——它纯粹是分组标签。面积排名在参考题中用于选出赢家，此题中排名同时决定"谁死"（最小者擦除）和"谁扩张"（最大者填充），而填充方向又依赖于被擦除者的空间位置。分组、排名、擦除、填充四个逻辑在空间和颜色两个维度上交织。
