## 新题 2：锚点距离定步长的周期阶梯碰撞

**组合逻辑**：[连线/阶梯图案](已有) + [周期延伸](创新：阶梯以周期方式重复生长而非单次绘制) + [碰撞阻挡/累积影响后续停靠](创新：多阶梯间的碰撞决定最终长度) + [最近角距离](创新：距离不用于填充而用于编码步长参数)

**来源原语**：连线/阶梯图案/锚点像素(d06dbe63)、周期延伸/长度即周期(1ae2feb7)、碰撞阻挡/累积影响后续停靠(4093f84a)、最近角距离(4a1cacc2)

**依赖链**：每个锚点到其最近网格角的曼哈顿距离决定该锚点阶梯的步长；阶梯以步长为周期沿两个对角方向重复延伸；多个锚点的阶梯可能碰撞，先绘制的阶梯像素阻挡后绘制的阶梯生长。距离→步长→周期→碰撞形成四层因果链。

多个彩色锚点各自生成灰(5)阶梯，每个阶梯的步长等于该锚点到最近网格角的曼哈顿距离；阶梯沿两个对角方向周期延伸直至撞上其他阶梯或网格边界，先到者阻挡后到者。

**输入结构**：约 20x20 的网格，背景黑(0)。网格中有 2~4 个单像素锚点，每个锚点颜色互不相同，使用蓝(1)、红(2)、绿(3)、黄(4)中的若干种。各锚点不在网格边界上，且任意两个锚点之间的曼哈顿距离 >= 6。生成约束：每个锚点到其最近角的曼哈顿距离在 2~5 之间（保证步长合理）；不同锚点的最近角不全相同（保证步长存在差异）。

**规则**：
1. 对每个锚点，计算其到四个网格角的曼哈顿距离，取最小值记为 S（步长）。
2. 从每个锚点出发，沿该锚点的两条对角方向（右上+左下为一组，左上+右下为一组；具体哪组由锚点所在象限决定：锚点离哪个角最近，就沿连接对角的方向画，即从锚点朝最近角方向和远离最近角方向各画一条臂）绘制阶梯。阶梯的绘制方式：每一步先画 S 个像素的水平段，再画 S 个像素的竖直段，交替进行，颜色为灰(5)。第一步的水平方向朝最近角的水平分量方向，竖直方向朝最近角的竖直分量方向；反向臂则两个方向均取反。
3. 阶梯周期延伸：上述水平段-竖直段交替是一个周期，持续重复直至下一段的像素超出网格边界或与已绘制的任何灰像素重叠。
4. 处理顺序：按锚点的步长 S 从小到大处理（S 相同时按锚点行号从小到大，再按列号从小到大）。先处理的锚点的阶梯像素已固定，后续阶梯遇到它们时立即截断。
5. 所有锚点像素在输出中保留原色不变。

**关键洞察**：步长不是预设常数而是由每个锚点的空间位置（到角距离）隐式编码的；必须对比多个示例才能确认"距离=步长"这一映射关系，而非直觉上的"每个阶梯步长相同"。

<description>
Fill enclosed regions along a line seeded by unique border pixels.

Input structure:
- bg = most common color.
- Colored lines/drawings on the grid.
- Unique single-pixel colors on the grid border mark seed endpoints of each line.

Rule:
- Each border seed pixel connects (8-connected) to a line drawing.
- Find closed bg cavities whose boundary touches that line.
- Flood-fill each such cavity with the seed pixel's color.

Key insight: Only cavities reachable through the seed's own line get filled; the seed's unique color acts as a per-line fill label.
