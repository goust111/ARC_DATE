## 新题 6：标记计数门控平铺与擦除分支

**组合逻辑**：[计数](创新：计数结果作为三路分支的判据) → {0: 不变 | 1: [平铺](创新：使用跨区域引用的模板) | 2+: [擦除+重涂色]} → 计数-分支-跨区域引用结构

**来源原语**：计数(counting) ← 358ba94e / a934301b / 6455b5f5；平铺(tiling)、模板精灵体(template_sprite)、间距保持一致(gaps_preserved) ← 9b2a60aa；擦除(erase)、标记超阈值则擦除(erase_above_threshold)、标记包含于对象(marker_in_object) ← a934301b；分隔线(divider_line)、封闭区域(enclosed_region)、面积比较(area_comparison) ← 6455b5f5；重涂色(recolor) ← 6455b5f5

**依赖链**：计数蓝色标记 → 计数值决定走哪条分支 → 单标记分支需要从模板区域获取模板形状 → 模板区域的识别依赖面积比较（最小区域）。计数是分支入口，模板区域是跨区域信息传递，两者不可省略。

红色分隔线将网格划分为多个区域。统计每个区域内的蓝色标记数量：0 个标记的区域不变；恰好 1 个标记的区域用来自最小区域的模板进行平铺填充；2 个及以上标记的区域整体涂为灰色。

**输入结构**：约 18x18 黑(0)背景网格。红(2)分隔线（1 像素宽，水平或垂直贯穿网格）将网格划分为 5-7 个互不重叠的矩形区域。每个区域内部为黑(0)背景。其中一个区域面积最小（生成时保证唯一最小），内部包含一个绿(3)模板精灵体（4-连通，3-6 像素，不对称形状，边界框不超过 3x3）。其余区域内散布 0-3 个蓝(1)标记像素（单像素，位置随意）。生成约束：至少一个区域有 0 个标记，至少一个区域有恰好 1 个标记，至少一个区域有 2 个或更多标记（保证三个分支均可观察）；单标记区域的尺寸至少为模板边界框的 2 倍（保证平铺可见）。

**规则**：
1. 识别面积最小的区域为模板区域。提取其中绿(3)模板精灵体的形状及其相对于模板区域左上角的边界框位置。模板区域在输出中保持不变。
2. 对每个非模板区域，统计其内部蓝(1)标记像素的数量 n。
3. n = 0：区域内部保持黑(0)，不做任何改动。
4. n = 1：以该区域的左上角为起点，以模板精灵体边界框的宽和高为步幅（列步幅 = 边界框宽，行步幅 = 边界框高），在区域内重复平铺模板形状。每个平铺副本着色为蓝(1)。超出区域边界的平铺副本仅保留区域内的部分（裁剪）。原有的蓝(1)标记像素若被平铺覆盖则自然融入，若不被覆盖则保留。
5. n >= 2：擦除区域内所有蓝(1)标记像素，将区域内部整体填充为灰(5)。
6. 红(2)分隔线在输出中保持不变。

**关键洞察**：标记像素的数量不是一个连续变量，而是一个离散的分支选择器：零、一、多分别触发完全不同的操作（保持、平铺、覆盖）。单标记分支的平铺模板并不在本区域内定义，而需跨区域从最小区域获取——这种跨区域信息传递使得单独分析一个区域无法得出结果。需要多个示例才能区分三条分支，并发现模板来源的规则。
