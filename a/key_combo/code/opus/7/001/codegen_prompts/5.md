## 新题 5：反射平铺构建寻路迷宫

**组合逻辑**：[平铺/tiling] + [镜像/mirror] + [双轴反射/biaxial_reflection]（已有，用于生成对称迷宫结构） → [寻路/pathfinding] + [障碍触发转向/barrier_triggers_turn]（创新：寻路的迷宫不是直接给定的，而是由平铺操作动态生成的）

**来源原语**：tiling/mirror/biaxial_reflection 来自 67e8384a（原用于将整个输入做四象限镜像拼贴）；pathfinding/barrier_triggers_turn 来自 2dd70a9a（原用于在给定迷宫中按障碍转向规则寻路）

**依赖链**：小网格定义障碍布局 → 反射平铺将障碍布局扩展为四倍大的对称迷宫 → 寻路在平铺后的迷宫中执行。迷宫结构仅在平铺后才存在——原始小网格中起点到终点可能无有效路径，但平铺后路径可经由相邻象限的反射副本绕行。

将一个小网格做四象限镜像平铺以构建对称迷宫，然后在该迷宫中按障碍转向规则寻找路径。

**输入结构**：
- 一个小矩形网格（5x5 至 7x7），背景为黑(0)。
- 若干青(8)障碍像素分布在网格中。
- 一个绿(3)像素标记起点，一个红(2)像素标记终点。起点和终点不在网格最外圈边界上。
- 起点绿(3)像素恰好有一个相邻格（上下左右之一）为青(8)障碍，该障碍的反方向即为初始行进方向。
- 生成约束：经过 2x2 反射平铺后，从原始象限（左上）的绿色起点到原始象限的红色终点存在一条合法路径（遵循障碍转向规则）。

**规则**：
1. 将输入做 2x2 反射平铺，生成一个宽高各为原始两倍的网格：
   - 左上象限：原始输入。
   - 右上象限：原始输入做左右镜像。
   - 左下象限：原始输入做上下镜像。
   - 右下象限：原始输入做上下+左右镜像。
2. 在平铺后的网格中，将所有反射产生的绿(3)和红(2)副本像素重新标记为青(8)障碍。仅保留左上象限中的原始绿色像素作为起点、原始红色像素作为终点。
3. 从起点出发，初始方向为起点相邻障碍的反方向。路径沿当前方向直行，遇到以下情况时转向 90 度（优先尝试左转，左转不可行则右转；两者都不可行则路径终止）：
   - 当前方向的下一格为青(8)障碍。
   - 当前方向的下一格超出平铺网格边界。
4. 当路径的当前方向下一格为红(2)终点时，路径结束。
5. 将路径经过的所有格（不含起点和终点）涂为绿(3)。
6. 输出：平铺后的完整网格，叠加绿色路径。

**关键洞察**：小输入网格本身不是完整的迷宫——反射平铺将障碍布局扩展为一个四倍面积的对称迷宫，路径可以穿越象限边界利用反射副本中的通道。同时，反射产生的起点/终点副本被转化为额外障碍，进一步塑造迷宫结构。求解者必须先完成平铺，才能确定路径。
