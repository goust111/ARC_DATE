## 新题 2：能量受限平移后的间隙桥接

**组合逻辑**：[平移 + 逐步充能](已有原语) → [行列跨度重叠检测](创新：检测对象是平移后的最终位置，而非原始位置) → [填充间隙](创新：填充条件依赖于平移是否因能量耗尽而提前停止)

**来源原语**：平移(translate)、逐步充能(incremental_charge)、能量上限步数(energy_caps_steps)、带边框容器(bordered_container)、目标标记(destination_marker)、颜色匹配配对(color_match_pairing) ← 271d71e2；填充(fill)、行列跨度重叠(row_span_overlap)、间隙区域(gap_region)、无遮挡才填充(fill_if_unobstructed) ← ef135b50

**依赖链**：灰单元格数上限容器的移动距离 → 移动后的最终位置决定哪些容器对有行列跨度重叠 → 只在重叠且无遮挡的容器对之间填充间隙。能量受限使得容器不一定到达目标，由此产生的非对称最终布局使间隙模式无法从初始布局直接推断。

带边框容器沿各自方向平移，灰(5)单元格逐步充能为橙(7)以驱动移动；平移结束后，在行跨度重叠且水平间隙无遮挡的容器对之间填充栗(9)色桥接。

**输入结构**：品红(6)背景，约 20x20 网格。3~4 个黑(0)边框矩形容器（每个约 3x5 ~ 4x6 大小），内部由灰(5)和橙(7)像素混合填充（灰像素数量 1~4 不等，其余为橙）。每个容器的一条短边外侧紧邻一个栗(9)色头部精灵（1 像素），在头部方向的远处沿同一行或列有一个同色栗(9)目标标记像素。头部到目标的方向为该容器的移动方向（仅水平或仅垂直）。生成约束：所有容器的移动方向均为水平（左或右）；容器在充分移动后不会相互碰撞；各目标标记不与任何容器重叠。

**规则**：
1. 对每个容器，确定其头部精灵和目标标记之间的曼哈顿距离 D，以及该容器内部灰(5)像素的数量 G。
2. 该容器沿头部→目标方向平移 min(D, G) 步（每步 1 像素）。每平移一步，将容器内部从头部朝向一侧起算的下一个灰(5)像素改为橙(7)（即从靠近头部的一侧向内依次充能）。
3. 所有容器完成平移后，检查每一对容器：若两个容器的边界框在行方向上有重叠跨度，且在列方向上有间隙（不相邻也不重叠），则该间隙为候选桥接区域。
4. 候选桥接区域定义为：行范围 = 两容器边界框行跨度的交集，列范围 = 两容器边界框之间的空列。
5. 若候选桥接区域内没有被第三个容器的边界框覆盖的行列交叉，则将该区域中所有背景像素涂为栗(9)。
6. 保留所有容器（含边框、充能后的内部）和剩余的头部/目标标记不变。

**关键洞察**：灰单元格数量不同导致容器停在不同位置，因此哪些容器对最终存在行跨度重叠、以及间隙宽度是否被第三方遮挡，都无法从初始布局直接判断——必须先完成能量受限平移才能确定桥接模式。
