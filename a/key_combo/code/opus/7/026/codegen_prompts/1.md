## 新题 1：最近标记定向擦除与外翻镜像

**组合逻辑**：[最近邻选择](创新：选择结果不决定颜色，而是决定擦除方位) → [擦除](创新：擦除边由外部标记方位决定，而非固定"最左两列") → [镜像](创新：擦除边即为镜像轴，向外翻转残余部分)

**来源原语**：擦除(erase) ← 52364a65；镜像(reflect) ← f8a8fe49；最近邻选择(nearest_neighbor_selection)、欧氏距离最小(minimum_euclidean_distance) ← 6df30ad6；相对自身定位(self_relative_pos) ← 52364a65

**依赖链**：最近标记的方位决定擦除哪条边 → 擦除后的缺失边成为镜像轴 → 残余像素沿该轴向外翻转并着标记色。三步之间的耦合点是"方位"：它既从最近邻关系中产生，又同时控制擦除的几何范围和镜像的对称轴。

根据每个灰(5)对象最近的彩色标记像素所在方位，擦除该对象朝向标记的那条边界行/列，再将剩余部分沿擦除边向外镜像，镜像副本着标记色。

**输入结构**：黑(0)背景，约 18x18 网格。散布 3~4 个灰(5)色 4-连通前景对象，每个对象为不规则形状（4~8 像素，边界框至少 3x3，无孔洞）。另有若干孤立的彩色标记像素（每种颜色恰好 1 个像素，颜色从蓝(1)、红(2)、绿(3)、黄(4)中选取，标记数量等于灰对象数量）。每个标记像素与恰好一个灰对象的欧氏距离最小（无平局），且标记不与任何灰对象同行同列（标记严格位于灰对象边界框的某一侧：上方、下方、左方或右方，不处于对角位置）。生成约束：各灰对象的边界框互不重叠且间距至少 3 像素；每个灰对象在擦除+镜像后的结果不超出网格边界。

**规则**：
1. 对每个灰(5)对象，计算所有标记像素到该对象任意像素的最小欧氏距离，选距离最小的标记作为该对象的配对标记。
2. 确定配对标记相对于灰对象边界框中心的主方位（上/下/左/右）：若标记行 < 边界框中心行则为"上"，标记行 > 则为"下"，标记列 < 则为"左"，标记列 > 则为"右"。
3. 擦除灰对象中朝向标记方位的边界行或列内的所有像素（设为黑(0)）。具体地："上"方位擦除对象边界框最上一行中属于该对象的像素；"下"擦除最下一行；"左"擦除最左一列；"右"擦除最右一列。
4. 将擦除后剩余的灰像素沿被擦除的那条边向外镜像：以被擦除的行/列所在位置为对称轴，将残余部分翻转到对象外侧。镜像副本的颜色为配对标记的颜色。
5. 保留原始残余灰像素不变。擦除配对标记像素（设为黑(0)）。镜像副本超出网格的部分裁剪丢弃。若多个对象的镜像副本重叠，按对象边界框左上角从左到右、从上到下的顺序绘制（后绘覆盖先绘）。

**关键洞察**：标记像素不提供颜色标签式的简单映射，而是通过其空间位置同时编码了"作用于哪个对象"（最近邻）、"作用于对象的哪条边"（方位）和"镜像副本的颜色"（标记色）三重信息。
