## 新题 7：对角复制体与原件之间的直角路径连接

**组合逻辑**：[平移 + 重涂色](创新：复制体位置由缺角方位决定) → [连线](创新：直角路径的两端不是独立的标记像素，而是原件-复制体对中的特定像素) + [拐角由终点列定](已有原语) + [遮挡条件裁剪](创新：路径遇到已有前景像素时截断)

**来源原语**：平移(translate)、重涂色(recolor)、对角偏移(diagonal_offset)、三连块(triomino)、缺角(missing_corner)、源色决定方向(source_color_decides) ← 1e5d6875；连线(draw_line)、直角路径(right_angle_path)、行列交汇(row_col_intersection)、拐角由终点列定(corner_at_target_col) ← d4a91cb9

**依赖链**：缺角方位 → 对角复制体位置和颜色 → 原件与复制体的位置差确定直角路径的两端 → 路径的拐角在原件行与复制体列的交点 → 路径遇到其他对象像素时截断。复制步骤创造了连线步骤的端点，而连线又受到复制结果的空间遮挡约束。

每个 L 三连块生成一个对角重涂副本，然后用直角路径连接原件与副本，路径遇到其他对象时截断。

**输入结构**：黑(0)背景，约 16x16 网格。3~4 个灰(5)色 L 三连块和 3~4 个红(2)色 L 三连块，各占据 2x2 中的 3 像素。各三连块边界框间距至少 4 像素。生成约束：每个三连块的对角复制体位置不与任何其他原件或复制体重叠；各原件-复制体对之间的直角路径（未截断版本）至少部分不被遮挡。

**规则**：
1. 灰(5)三连块向缺角方向对角平移 1 步，生成黄(4)色副本，保留原件。
2. 红(2)三连块向缺角反方向对角平移 1 步，生成绿(3)色副本，保留原件。
3. 对每个原件-副本对，确定连接端点：原件端为原件中距副本边界框中心最近的像素 P；副本端为副本中距原件边界框中心最近的像素 Q。
4. 从 P 开始水平画线直到 Q 所在列，然后垂直画线直到 Q 所在行，形成直角路径。路径颜色为副本颜色（灰→黄(4)，红→绿(3)）。
5. 路径绘制时，若下一个像素位置已被非背景像素占据（原件、副本或其他路径），则该路径在此处截断（不覆盖已有像素，也不继续延伸）。
6. 绘制顺序：先画所有灰系（黄色）路径，再画所有红系（绿色）路径。同系内按原件边界框左上角从左到右、从上到下排序。

**关键洞察**：路径的几何形状由复制体位置决定，而复制体位置由三连块的缺角方位和源色共同决定。路径的截断又受到所有复制体和其他路径的空间约束，使得绘制顺序成为影响最终结果的隐蔽规则。
