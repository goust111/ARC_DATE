## 新题 9：像素放大边缘印章与印章角落的内容感知装饰

**组合逻辑**：[像素放大 + 边缘像素复制/印章覆盖](已有原语) → [对角邻接检测](创新：检测的对象不是原始像素，而是放大后的 3x3 块) → [描边/装饰](创新：装饰颜色不固定，而是由印章在该角落位置是否有前景像素决定)

**来源原语**：像素放大(pixel_scaling)、印章覆盖(stamp_overlay)、前景掩码(foreground_mask)、块格阵列(block_lattice)、格位映射(cell_block_mapping)、边缘像素复制(edge_pixel_copy) ← 8719f442；描边(decorate)、角标记(corner_marker)、对角邻接(diagonal_adjacency)、前景方块(foreground_square) ← 95990924

**依赖链**：小掩码放大为块格阵列 → 边缘块向外印章原始掩码 → 印章内容在角落位置是否有前景像素 → 该信息决定角落装饰色。印章步骤生成的几何内容直接影响装饰步骤的颜色选择，两者通过"角落位置是否被前景占据"这一空间谓词耦合。

将 3x3 前景掩码放大为块格阵列并在边缘块外侧印章原始掩码，然后在每个前景块的四个外角位置，根据印章是否覆盖了该角落来决定装饰颜色。

**输入结构**：黑(0)背景，3x3 网格。1 种前景色（蓝(1)），4~6 个蓝色像素构成一个 4-连通图案，至少有 2 个像素位于边缘（第 0 行、第 2 行、第 0 列或第 2 列）。生成约束：前景图案不是全满（9 像素）也不是单像素；至少有一个边缘像素的对角外侧在 15x15 输出中有空间放置印章的角落像素。

**规则**：
1. 创建 15x15 黑(0)画布。将 3x3 输入的每个前景像素映射到画布中央 9x9 区域的对应 3x3 块（块格阵列），涂为蓝(1)实心块。
2. 对每个处于输入边缘（第 0 行、第 2 行、第 0 列、第 2 列）的前景像素对应的实心块，在该块的外侧（朝向网格边缘的方向）印章原始 3x3 前景掩码（仅前景像素，用蓝(1)色；一个块可能向多个方向印章——顶边和左边都算边缘的角块向两个方向各印一次）。印章的定位：以实心块的外边缘行/列为起始，向外放置 3x3 掩码。
3. 完成所有印章后，检查 9x9 中央区域每个蓝(1)实心块的四个对角外角位置（即 3x3 块外的对角 1 像素处）：
   - 若该角落位置被印章步骤产生的蓝(1)像素占据，则在该位置涂红(2)（覆盖蓝色）。
   - 若该角落位置为黑(0)（印章未到达），则涂黄(4)。
   - 若该角落位置超出 15x15 画布，则不处理。
4. 保留所有其他蓝(1)像素（实心块和印章）不变。

**关键洞察**：角落装饰色不是查表得到的固定值，而是由印章步骤的几何覆盖范围在运行时决定的——同一方位的角落在不同输入掩码下可能得到不同颜色，因为印章覆盖的空间模式随掩码形状而变化。
