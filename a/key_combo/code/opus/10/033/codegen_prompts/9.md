## 新题 9：同心距离壳叠加与形状频率优先级

**组合逻辑**：[形状匹配·计数/shape_matching·counting](创新：按宽高尺寸而非掩码做匹配) → [同心层填充/concentric_fill·按距离循环配色/distance_color_cycling](已有) → [冲突优先级/conflict_priority](创新：面积小的壳覆盖面积大的壳)

**来源原语**：同心层填充/concentric_fill、按距离循环配色/distance_color_cycling、嵌套层次/nesting_hierarchy、空心矩形/hollow_rectangle、同心正方形层/concentric_layer（来自 a3f84088）；形状匹配/shape_match、计数/counting、唯一重复形分涂/unique_vs_repeated_recolor、连通分量/connected_component（来自 b230c067）；冲突优先级/conflict_priority（来自 c92b942c）

**依赖链**：形状频率分类（按边界框尺寸）决定同心填充的颜色循环主题；多个框架的空间重叠由面积优先级解决。分类 → 配色主题 → 填充 → 重叠解决，每一步的结果都实质改变下一步的行为。两个相同尺寸（即"重复形"）的框架重叠时填充颜色相同，而不同尺寸框架重叠时颜色循环不同，产生可辨识的干涉带。

将多个空心矩形框按边界框尺寸分组，唯一尺寸的框用红色系同心填充、重复尺寸的用蓝色系同心填充，重叠区域小面积框优先。

**输入结构**：约 18x18 的网格，黑(0)为背景。3-5 个一像素厚的灰(5)空心矩形框，尺寸各异（最小约 5x5，最大约 13x13），可能部分重叠或嵌套。生成约束：恰好有一个矩形框的 (宽, 高) 尺寸对在所有框中唯一，至少有两个矩形框的 (宽, 高) 尺寸对相同（允许宽高互换视为不同尺寸对）。所有框的灰(5)轮廓像素互不重合（轮廓不相交），但框的内部区域可以空间重叠。

**规则**：
1. 提取所有灰(5)空心矩形框（每个框为一像素厚的封闭矩形环）。记录每个框的边界框尺寸 (宽, 高)。
2. 按 (宽, 高) 分组。尺寸对仅出现一次的框为"唯一尺寸"框，出现两次及以上的为"重复尺寸"框。
3. 对每个框执行同心层填充（从框的灰(5)边界向内逐层计算 Chebyshev 距离）：
   - 唯一尺寸框的颜色循环（从边界向内）：灰(5)→红(2)→灰(5)→黑(0)→灰(5)→红(2)→...（周期 4：灰、红、灰、黑）。
   - 重复尺寸框的颜色循环（从边界向内）：灰(5)→蓝(1)→灰(5)→黑(0)→灰(5)→蓝(1)→...（周期 4：灰、蓝、灰、黑）。
   - 距离 0 层（框边界本身）为灰(5)，距离 1 层为红(2)或蓝(1)，距离 2 层为灰(5)，距离 3 层为黑(0)，距离 4 层回到灰(5)，以此循环。
4. 框外区域保持黑(0)背景。
5. 当两个或更多框的填充区域在空间上重叠（同一像素属于多个框的内部）时，由面积最小的框（宽 x 高 最小）的填充颜色决定该像素的最终颜色。面积相同时，边界框左上角行号更小的框优先；行号也相同时列号更小的优先。
6. 灰(5)框边界像素始终保留，不被任何填充覆盖。

**关键洞察**：尺寸频率决定了颜色主题（红系 vs 蓝系），而空间重叠的优先级与尺寸频率无关——只看面积大小。这意味着一个小的"唯一尺寸"红色框可以在一个大的"重复尺寸"蓝色框内部"刻出"一块红色区域，而两个相同尺寸的蓝色框重叠时则通过位置 tie-break 决定哪个蓝色循环"获胜"。颜色分类规则和优先级规则需要分别对比不同示例才能分别归纳。
