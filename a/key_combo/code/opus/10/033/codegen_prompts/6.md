## 新题 6：边缘接触分流——递减延伸与滑动轨迹的冲突

**组合逻辑**：[条件分支：接触边缘/touching_edge](创新：同一类对象按空间属性分流到不同变换) → [递减填充/shrinking_fill | 滑动/slide·轨迹条纹/trail_stripe](创新：两种变换的产物可空间重叠) → [冲突优先级/conflict_priority](创新：轨迹覆盖延伸)

**来源原语**：递减填充/shrinking_fill、圆润对象/rounded_object、边缘行程/side_run、四方外扩/four_way_expansion、逐步缩短行程/progressively_shortened（来自 9772c176）；滑动/slide、轨迹条纹/trail_stripe、接触边缘/touching_edge、滑至对侧边缘/slide_to_opposite（来自 b25e450b）；冲突优先级/conflict_priority（来自 c92b942c）

**依赖链**：同一种颜色的对象仅凭空间属性（是否接触网格边缘）被分流到完全不同的变换管道：不接触边缘的做递减外扩延伸，接触边缘的做对侧滑动并留轨迹。两条管道的输出可在空间上交叠——轨迹条纹可能穿过延伸区域——此时冲突优先级规则介入。删除边缘检测步骤则无法确定任何对象的变换类型。

同色对象根据是否接触网格边缘分别执行不同变换：不接触的做四方递减延伸，接触的滑向对侧留轨迹，轨迹优先覆盖延伸。

**输入结构**：约 15x15 的网格，黑(0)为背景。3-5 个青(8)的 4-连通单色对象，每个对象约 4-8 像素。其中部分对象至少有一个像素位于网格边缘行或边缘列（接触边缘），其余对象完全在网格内部（不接触边缘）。不接触边缘的对象形状近似圆润（每条边——上、下、左、右最外侧像素构成的连续行程至少 2 像素长）。接触边缘的对象为紧凑矩形（宽或高至少 2 像素）。生成约束：至少有 1 个接触边缘的对象和至少 1 个不接触边缘的对象。接触边缘的对象恰好接触一条边缘（上、下、左、右之一）。滑动方向上无其他对象阻挡（保证滑动路径畅通到达对侧边缘）。

**规则**：
1. 判定每个青(8)对象是否接触网格边缘（至少一个像素在第 0 行、最后一行、第 0 列或最后一列）。
2. **不接触边缘的对象**——执行递减外扩延伸：
   - 取对象的上边缘行程（最上行的连续像素段）、下边缘行程、左边缘行程、右边缘行程。
   - 从每条边缘行程开始，沿外法方向（上边缘向上、下边缘向下、左边缘向左、右边缘向右）逐步延伸。第一步的延伸宽度 = 原行程长度 - 2，第二步 = 原行程长度 - 4，以此类推，直到宽度 ≤ 0 时停止。每步延伸一行（或一列）。延伸像素居中对齐于原行程。
   - 将延伸产生的背景像素涂为黄(4)。超出网格边界的部分舍弃。
3. **接触边缘的对象**——执行对侧滑动：
   - 接触上边缘的对象向下滑动直到底边接触网格底边缘。接触下边缘的向上滑动。接触左边缘的向右滑动。接触右边缘的向左滑动。
   - 对象原位置清空为黑(0)。
   - 对象扫过的矩形区域（从原位置到新位置之间的所有行或列，排除对象最终占据的位置）涂为橙(7)作为轨迹。
   - 对象在新位置保持青(8)。
4. **冲突处理**：所有变换同时计算，然后统一涂色。涂色优先级从高到低：青(8)滑动后的对象 > 青(8)原位不动的对象 > 橙(7)轨迹 > 黄(4)递减延伸 > 黑(0)背景。
5. 处理顺序：多个滑动对象按其原始位置从上到下、从左到右的顺序处理。多个不动对象的延伸互不影响。

**关键洞察**：同色、同类的对象仅因"是否接触边缘"这一空间属性而进入完全不同的变换管道。两条管道的产物（黄色延伸区和橙色轨迹带）可在空间上交叠，此时轨迹覆盖延伸——这意味着滑动对象的路径会"切断"内部对象的延伸图案，产生仅凭单个变换无法预见的干涉效果。
