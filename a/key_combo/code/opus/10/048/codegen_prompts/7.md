## 新题 7：压缩分区后克罗内克展开为反色阵列

**组合逻辑**：[压缩/网格分区](提取每区域代表色生成种子网格) → [克罗内克积](种子网格的前景掩码自乘展开) + [颜色互换/前景背景互换填充](展开时前景位置填背景、背景位置填前景色) — 压缩结果同时作为展开的掩码和内容，形成自指结构

**来源原语**：压缩(780d0b14)、网格分区(780d0b14)、分隔线(780d0b14)、每区域折叠单像素(780d0b14)、色块区域(780d0b14)、克罗内克积(8e2edd66)、二值掩码(8e2edd66)、前景背景互换填充(8e2edd66)、颜色互换(8e2edd66)

**依赖链**：压缩将大网格变为小种子。种子的非黑像素位置构成二值掩码。克罗内克展开用掩码决定哪些块被填充，但填充规则是反色的——掩码为 1 的位置放全黑块，掩码为 0 的位置放种子自身的颜色图案。压缩的输出既是掩码又是填充内容，两者角色互换（前景变空洞，背景位置反而获得内容）。

先将分隔线网格压缩为小种子，再以种子的前景掩码做克罗内克展开，展开时前景位置变空块、背景位置填充种子图案。

**输入结构**：约 15x15 的网格，由黑(0)色全行/全列分隔线划分为 3x3 或 4x4 的等大矩形区域（每区域约 3x3~4x4 像素）。每个区域内仅有一种非黑颜色的像素散布（区域内可能含黑色背景像素，但非黑像素颜色唯一）。不同区域颜色可相同可不同。至少有一个区域完全为黑（无前景色）。生成约束：区域网格为方阵（行数=列数），保证输出尺寸一致。

**规则**：
1. 识别所有贯穿全宽的黑色行和贯穿全高的黑色列作为分隔线，确定矩形区域网格（假设为 NxN）。
2. 对每个区域提取其代表色：若区域内有非黑像素，代表色为该非黑颜色；否则代表色为黑(0)。生成 NxN 的种子网格。
3. 以种子网格的非黑位置作为前景掩码 M（M[i][j]=1 当种子[i][j]非黑）。
4. 构建 (N*N)x(N*N) 的输出网格：对输出中坐标 (r,c)，令 block_r = r//N, block_c = c//N, inner_r = r%N, inner_c = c%N。
   - 若 M[block_r][block_c] = 1（前景位置），输出像素为黑(0)。
   - 若 M[block_r][block_c] = 0（背景位置），输出像素为种子网格[inner_r][inner_c] 的颜色。
5. 输出网格即为最终结果。

**关键洞察**：压缩生成的种子网格在展开时角色反转——有颜色的位置反而变成空洞，无颜色的位置获得种子的完整内容拷贝。这种"自指反色"需要同时理解压缩和克罗内克两步的语义才能归纳。
