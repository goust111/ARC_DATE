## 新题 3：补线构建封闭域与图例定色填充

**组合逻辑**：[补线line_completion](已有) + [洪泛填充flood_fill](创新：作用于补线后涌现的新封闭区域，而非预存区域) + [图例映射颜色legend_maps_color](创新：图例的键是封闭区域的边界颜色而非标记颜色)

**来源原语**：
- 补线(line_completion)、直线段(straight_line_segment)、间隙长度限制(gap_length_constraint) ← 7b80bb43
- 洪泛填充(flood_fill)、封闭区域(enclosed_region)、区域可达性(region_reachability) ← 543a7ed5
- 颜色图例(color_legend)、图例映射颜色(legend_maps_color) ← 9385bd28

**依赖链**：补线闭合间隙→间隙闭合后涌现出原本不存在的封闭区域→封闭区域的边界颜色查图例→图例给出填充色。补线是填充的前提（不补线则不封闭），图例是填充色的来源（不查图例则不知涂什么色）。三步环环相扣，删去补线步骤则区域不封闭，删去图例则填充色不确定。

断裂的彩色线段被补全后围合出新的封闭区域，每个封闭区域根据其边界线颜色查找图例确定填充色。

**输入结构**：约 15x15 的网格，黑(0)背景。3~5 条彩色直线段（水平或垂直），每条是同色像素的连续行/列段（长度 4~10 像素），颜色取自 {红(2), 蓝(1), 绿(3)}。部分线段中间有恰好 1 像素宽的间隙（该位置为黑(0)）。线段的端点位置经过安排，使得补全间隙后，某些不同颜色或同颜色的线段首尾相接或垂直交汇，围合出 1~3 个封闭矩形区域。网格左下角有一个竖直排列的颜色图例，每行为两个相邻像素：左像素为键色（红(2)/蓝(1)/绿(3)之一），右像素为值色（黄(4)/灰(5)/橙(7)之一），图例行数等于所用线段颜色种类数。生成约束：每个封闭区域的边界像素恰好只含一种线段颜色（即每个封闭区域由同一颜色的线段围合而成）；间隙宽度恰好为 1 像素；图例中键色不重复。

**规则**：
1. 扫描每条线段，若线段中存在恰好 1 像素的间隙（间隙两侧均为同色像素），则用该线段颜色填补间隙。
2. 补线完成后，识别所有封闭区域：从网格边界出发，通过黑(0)像素进行 4-连通洪泛扩展，标记所有可达的背景像素为"外部"。未被标记的黑(0)像素群构成封闭区域。
3. 对每个封闭区域，检查其 4-邻接的非背景像素颜色——根据生成约束，这些像素均为同一颜色 C。
4. 在图例中查找键色 = C 的行，取其值色 V。将该封闭区域的所有像素填充为 V。
5. 图例像素、线段像素（含补全的像素）及外部背景像素保持不变。

**关键洞察**：补线是封闭区域涌现的前提——输入中不存在封闭区域，只有补全间隙后才会形成；填充色不由边界颜色直接决定，而是通过图例间接映射，需要对比多个示例确认图例查表规则而非"边界色即填充色"。
