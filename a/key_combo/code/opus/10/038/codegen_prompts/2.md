## 新题 2：曼哈顿领地竞争与计数直方图

**组合逻辑**：[生长grow](创新：多种子同步曼哈顿距离竞争) + [计数counting](对生长结果的领地面积计数) + [填充fill / 计数编码为条长count_as_bar_length](创新：领地面积→直方图条高) + [忽略干扰项ignore_distractors](创新：距离并列区域不计入任何种子)

**来源原语**：
- 生长(grow)、逐步推进(stepwise_advance) ← 758abdf0
- 碰撞停止(collision_stop) ← 142ca369
- 计数(counting)、计数编码为条长(count_as_bar_length)、条形图(bar_chart)、忽略干扰项(ignore_distractors) ← 1fad071e
- 排序(sort)、顺序对应(ordinal_correspondence) ← f3cdc58f

**依赖链**：种子的空间分布决定曼哈顿领地划分→领地面积产生计数→计数转化为直方图条高→种子的输入位置顺序决定直方图列序。空间模拟的结果驱动聚合，聚合结果驱动渲染布局，删去任一步骤输出无法确定。

多个种子像素同时向外生长争夺领地，每个种子的最终领地面积被编码为直方图中对应颜色柱的高度。

**输入结构**：约 12x12 的网格，黑(0)背景。散布 3~5 个种子像素，每个种子颜色各不相同，取自 {红(2), 蓝(1), 绿(3), 黄(4), 橙(7)}。种子之间互不相邻（至少间隔 2 个像素）。网格中无其他前景元素。生成约束：种子数量 N 满足 N <= 网格行数，以保证直方图可容纳；不同种子到任一背景像素的曼哈顿距离不全相同（即总存在唯一最近种子的像素）。

**规则**：
1. 对网格中每个背景像素，计算其到所有种子的曼哈顿距离，归属于距离最小的种子。若存在两个或以上种子距离并列最小，该像素归为"争议区"，不计入任何种子领地。
2. 每个种子的领地面积 = 归属于该种子的像素数 + 1（种子自身）。
3. 按种子在输入网格中的列位置从左到右排序；若列相同则按行位置从上到下排序。
4. 输出为一个 N 列的直方图网格，宽度 = 种子数 N，高度 = 最大领地面积。每列对应排序后的一个种子，从底行向上填充该种子颜色，填充行数 = 该种子领地面积。未填充的单元格为黑(0)。

**关键洞察**：领地面积依赖所有种子的空间关系（非两两独立），改变任一种子位置会改变所有领地大小；争议区（并列距离）不计入任何种子的面积，需要对比多个示例才能归纳出并列处理规则。

<description>
Recolor each closed orthogonal line loop so convex bend pixels are yellow and concave bend pixels are red.

Input structure
- The grid has a dominant background and exactly one foreground color.
- The foreground forms one or more 4-connected one-pixel-wide closed cycles; every foreground pixel has degree 2.
Rule
- Trace each cycle and inspect the turn at each foreground pixel.
- Straight pixels keep the original foreground color.
- Bend pixels whose turn direction is the majority direction for that cycle are convex corners and become yellow.
- Bend pixels whose turn direction is the minority direction for that cycle are concave corners and become red.
Key insight
- A simple rectilinear closed boundary has exactly four more convex bends than concave bends, so convexity can be inferred structurally from the majority turn sign within each traced cycle.
