## 新题 4：对接拼装与涌现孔洞填充

**组合逻辑**：[拼接/stitch · 同色标记对齐对接/same_color_dock] + [填充/fill · 封闭孔洞/enclosed_hole](创新：被填充的孔洞不来自任何单个对象，而是多个对象对接后涌现的新封闭区域)

**来源原语**：拼接/stitch(e9fc42f2), 同色标记对齐对接/same_color_dock(e9fc42f2), 标记侧面决定方向/marker_side_dir(e9fc42f2), 连接标记/connector_marker(e9fc42f2), 填充/fill(e73095fd), 封闭孔洞/enclosed_hole(e73095fd), 连通分量/connected_component(a8d7556c)

**依赖链**：连接标记颜色配对 → 确定哪些对象对接；标记的暴露侧 → 确定对接方向和平移向量；对接后的组合形状 → 涌现出新的封闭黑色区域；封闭检测 → 确定哪些区域被填充。对接结果改变了填充的输入结构。

将带有彩色连接标记的灰色对象按同色标记对接拼装，拼装后在组合体内涌现的封闭黑色区域用黄色填充。

**输入结构**：
- 约 20x20 网格，背景黑(0)。
- 3-4 个灰(5)前景对象（4-连通，每个 8-15 像素），形状不规则，各有凹凸但单独观察时内部无封闭孔洞（即每个对象的边界框内，所有黑色像素都与外部黑色区域 4-连通）。
- 每个对象的边缘上有 1-2 个单像素彩色连接标记（如蓝(1)、绿(3)、橙(7)），每种标记颜色在所有对象中恰好出现两次，形成配对。
- 每个连接标记的「暴露侧」：标记像素在上/下/左/右四个方向中，有且仅有一个方向的相邻像素是背景黑(0)而非对象灰(5)，该方向即为暴露侧。
- 生成约束：按规则对接后，至少形成一个新的封闭黑色区域（4-连通黑色像素完全被灰色像素包围）。对接时不同对象的灰色像素不会重叠（取并集）。

**规则**：
1. 对每种出现两次的连接标记颜色，找到携带该颜色的两个对象。
2. 确定每个标记的暴露侧方向。
3. 平移其中一个对象，使两个同色标记 4-邻接，且各自的暴露侧彼此相对（例如一个标记暴露侧朝右，另一个朝左，则两者左右邻接）。
4. 连接标记配对按标记在输入中首次出现的扫描顺序处理（从上到下、从左到右扫描，先遇到的标记颜色先处理）。若平移导致对象像素与已放置的像素重合，保留两者的并集。
5. 对接完成后，将所有连接标记像素替换为灰(5)。
6. 在拼装后的组合结构中，找到所有被灰(5)像素完全 4-连通包围的黑(0)区域（即不与网格外部黑色区域连通的黑色连通分量），填充为黄(4)。

**关键洞察**：没有任何单个对象拥有封闭孔洞——所有被填充的黄色区域都是对接后才涌现的。对接顺序和连接方向共同决定了哪些凹陷会被封闭，而标记的暴露侧朝向是推理对接方向的唯一线索。需要多个示例来确认"暴露侧相对"这一对接规则。
