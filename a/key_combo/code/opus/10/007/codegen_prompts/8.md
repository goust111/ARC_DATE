## 新题 8：格点补全与形状键孔洞填色

**组合逻辑**：[补全/completion · 笛卡尔积缺位填充/cartesian_product_gap_fill](保留格点补全) → [形状匹配/shape_matching · 归一化形状对应/normalized_match](创新：从选择带孔对象变为在补全后的精灵中为孔洞匹配颜色) + [填充/fill](创新：填充对象是格点补全后才完整出现的所有精灵的孔洞) + [忽略干扰项/ignore_distractors](保留)

**来源原语**：补全/completion(5b526a93), 笛卡尔积缺位填充/cartesian_product_gap_fill(5b526a93), 格点对齐/lattice_alignment(5b526a93), 同形精灵体/identical_sprite(5b526a93), 形状匹配/shape_matching(42f14c03), 归一化形状对应/normalized_match(42f14c03), 忽略干扰项/ignore_distractors(42f14c03), 填充/fill(e73095fd), 带孔对象/object_with_holes(42f14c03), 标记形状/marker_shape(42f14c03)

**依赖链**：格点结构识别 → 补全缺失位置 → 新精灵也带有孔洞 → 需要确定孔洞的填充色 → 必须通过外部标记形状的归一化匹配来确定 → 干扰标记必须被排除。补全在先（否则不知道有多少孔洞需要填），形状匹配在后（确定颜色），两者紧耦合。

在部分填充的矩形格点上补全缺失的灰色精灵副本，然后通过外部标记形状与精灵内部孔洞的归一化匹配来确定每种孔洞的填充颜色。

**输入结构**：
- 约 20x20 网格，背景黑(0)。
- 4-6 个灰(5)精灵，外形完全相同（4-连通，每个 10-20 像素），排列在一个矩形格点上（行间距和列间距均匀）。至少有一个完整的行和一个完整的列被占据，其余格点位置为空。
- 每个精灵内部有恰好 2 个不同形状的孔洞（边界框内的 4-连通黑色区域），所有精灵的孔洞在相对位置和形状上完全一致。两个孔洞的形状不同（例如一个是 3 像素的 L 形连通区域，另一个是 2 像素的直线连通区域）。
- 网格上格点区域之外散布 3-4 个小型彩色标记形状（每个 2-5 像素，4-连通，各使用不同颜色，不使用灰(5)/黑(0)），其中恰好 2 个标记的归一化形状（将形状平移使其边界框左上角对齐原点后逐像素比较）分别与精灵的两种孔洞形状匹配。其余标记为干扰项。
- 生成约束：格点至少缺 2 个位置需要补全；干扰标记的形状与任何孔洞形状都不匹配。

**规则**：
1. 识别精灵外形和格点结构（行起始位置集合和列起始位置集合）。
2. 在所有笛卡尔积位置（行 × 列）中找到空缺位置，印章灰(5)精灵副本填充所有空缺。
3. 对精灵内部的两种孔洞形状，分别将其归一化（平移使边界框左上角位于原点）。
4. 对每个外部标记形状，同样归一化后与两种孔洞形状逐像素比较。匹配成功的标记颜色即为该种孔洞的填充色。不匹配的标记为干扰项。
5. 用匹配的标记颜色填充所有精灵（含原始精灵和新补全精灵）中对应形状的孔洞。
6. 移除所有外部标记形状（替换为黑(0)背景）。

**关键洞察**：格点补全必须先于孔洞填充——新补全的精灵同样有孔洞需要填充。填充颜色由形状匹配决定而非标记位置或颜色本身——将一个 L 形蓝标记和一个直线形绿标记对调颜色会改变孔洞填充结果。干扰标记考验求解者是否正确理解了匹配规则。
