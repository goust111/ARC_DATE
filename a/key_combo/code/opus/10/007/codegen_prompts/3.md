## 新题 3：贪心直角路径网络与颜色角色互换

**组合逻辑**：[贪心遍历/greedy_traversal] + [画线/draw_line · 直角路径/right_angle_path](创新：从两点间 L 路径变为贪心链式 L 路径网络) → [颜色角色互换/color_role_swap](创新：互换对象不是精灵与线段，而是路径与端点)

**来源原语**：贪心遍历/greedy_traversal(3490cc26), 最近未访问优先/nearest_unvisited_first(3490cc26), 画线/draw_line(d4a91cb9), 直角路径/right_angle_path(d4a91cb9), 拐角由终点列定/corner_at_target_col(d4a91cb9), 颜色角色互换/color_role_swap(c6141b15), 端点像素/endpoint_pixel(d4a91cb9)

**依赖链**：贪心最近邻顺序 → 决定路径拓扑（谁连谁）；直角路径规则 → 决定路径几何（L 形拐弯位置）；颜色互换 → 全局翻转结果的视觉语义。必须先完成完整遍历并绘制所有路径，才能执行互换。

从红色起点出发，以贪心最近邻方式依次用黄色 L 形直角路径连接所有青色端点，完成后将路径颜色与端点颜色互换。

**输入结构**：
- 约 14x14 网格，背景黑(0)。
- 一个红(2)单像素作为起点。
- 4-6 个青(8)单像素散布在网格中。
- 没有任何两个像素（含红色）处于同一行或同一列。
- 生成约束：贪心最近邻遍历可以访问所有青像素（不会出现无法到达的情况）；各 L 形路径互不经过任何其他端点像素。

**规则**：
1. 从红(2)像素出发，找到曼哈顿距离最近的未访问青(8)像素。距离相同时，选行号更小的；行号也相同则选列号更小的。
2. 从当前像素绘制黄(4) L 形直角路径：先水平画到目标像素所在列，再垂直画到目标像素所在行。拐角位于当前像素的行与目标像素的列交汇处。路径不覆盖起点和终点像素本身。
3. 将当前位置移至该青像素，重复步骤 1-2 直到所有青像素都已访问。
4. 执行颜色角色互换：所有黄(4)路径像素变为青(8)，所有原始青(8)端点像素变为黄(4)，红(2)起点像素也变为黄(4)。
5. 背景像素不变。

**关键洞察**：互换后输出的视觉含义反转——"连接线"呈现为青色（原来是端点色），"节点"呈现为黄色（原来是路径色）。求解者必须逆向推断：先"反转"颜色以还原路径结构，再分析贪心遍历顺序和 L 形规则。仅看一个示例可能误以为青色是路径、黄色是端点，需要多个示例才能发现颜色互换的存在。
