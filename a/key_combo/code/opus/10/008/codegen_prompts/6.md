## 新题 6：遮挡序定义周期填充色序

**组合逻辑**：[排序 + 遮挡顺序](从重叠边框的交叉可见性推断颜色序列) → [周期推断 + 间隙填充](用推断出的颜色序列作为周期循环填充表格空缺) + [对角线相位偏移](控制表格的相位结构)

**来源原语**：排序(c920a713)、遮挡顺序(c920a713)、交叉处可见性(c920a713)、空心矩形(445eab21)、遍历所有颜色(c920a713)、间隙填充(1e97544e)、周期推断(1e97544e)、对角线相位偏移(1e97544e)、按列周期取色(1e97544e)、表格(1e97544e)、空白单元格(1e97544e)

**依赖链**：边框交叉可见性 → 推断颜色排序 → 排序结果即为周期循环的色序 → 用该色序填充表格空白单元格（含对角线相位偏移）。边框分析和表格填充通过"颜色序列"紧密耦合：不解出遮挡顺序就不知道周期是什么颜色循环，不知道循环就无法填充表格。

解读重叠矩形边框的遮挡序列以确定颜色循环顺序，用该顺序作为周期循环填充内嵌表格中的空白单元格。

**输入结构**：约 20x20 的黑(0)背景网格，包含两个区域。(a) 左半区（约 20x10）有 3~5 个一像素厚的空心矩形边框，颜色各不相同（如红(2)、蓝(1)、绿(3)、黄(4)），边框相互重叠，重叠处可见色记录了从被遮挡框到可见框的有向遮挡关系。每个边框的完整矩形可从其可见像素的外接矩形推断。(b) 右半区（约 NxN，N 等于边框颜色数）是一个方形表格，部分单元格已填入边框颜色中的某种颜色，其余单元格为灰(5)表示空白。已填入的颜色遵循一个由边框颜色组成的列周期循环，且在主对角线处存在相位偏移。生成约束：遮挡关系构成唯一的全序（每一对颜色之间的遮挡方向唯一确定）；表格中已填入的像素数量恰好足以验证周期和相位，但不足以独立推断完整色序（至少需要遮挡分析的辅助）。

**规则**：
1. 在左半区，从每种颜色的可见像素推断其完整矩形边框。
2. 检查所有边框对的周边交叉点：若 A 和 B 的边框周边在同一像素相交且该像素显示 B 的颜色，则添加有向边 A→B（B 遮挡 A）。
3. 从有向遮挡关系中找出遍历所有颜色的唯一路径（从最底层到最顶层），得到颜色序列 [c0, c1, ..., cn-1]。
4. 在右半区的 NxN 表格中，填充空白（灰(5)）单元格：对于位置 (r, c)，若 r <= c 则颜色为序列中第 (c mod N) 个，若 r > c 则颜色为序列中第 ((c+1) mod N) 个。
5. 左半区保持不变。

**关键洞察**：重叠边框不是装饰——它们的交叉可见性编码了颜色优先级序列，而这个序列恰好是右侧周期表格缺失的循环色序；不解决空间遮挡就无法完成数值填充。
