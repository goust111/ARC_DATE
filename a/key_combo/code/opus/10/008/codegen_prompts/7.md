## 新题 7：墙壁扫描线镜像填充

**组合逻辑**：[裁剪 + 镜像](裁剪前景矩形并水平翻转) → [填充](翻转后的内容逐行填入墙壁像素界定的扫描线区间) + [墙壁界定范围](墙壁和标记列共同确定填充范围)

**来源原语**：裁剪(7468f01a)、镜像(7468f01a)、翻转裁剪区域(7468f01a)、前景矩形(7468f01a)、填充(78e78cff)、墙壁像素(78e78cff)、扫描线区间(78e78cff)、墙壁界定范围(78e78cff)、标记列为参考(78e78cff)、单点标记(78e78cff)

**依赖链**：裁剪前景矩形并镜像翻转 → 翻转内容的每一行对应一个扫描线行 → 墙壁像素界定每行的填充范围 → 翻转内容被裁切至墙壁区间内。翻转提供填充内容，墙壁提供填充边界——两者独立定义，在输出中交汇。

裁剪前景矩形并水平镜像，将镜像结果逐行铺入由墙壁像素和标记列界定的扫描线区间中。

**输入结构**：约 18x18 的黑(0)背景网格，包含三类元素。(a) 一个由多色像素组成的实心矩形区域（约 4~6 行 x 5~8 列），位于网格右下角，包含 2~3 种非背景颜色（如蓝(1)和绿(3)），内部有明确的非对称图案。(b) 灰(5)墙壁像素：分布在网格左半区的若干行上，每行 1~2 个灰像素，共覆盖 4~6 行（行数等于前景矩形的行数）。(c) 一个红(2)单点标记像素，位于灰墙壁像素所在行之间的某列。生成约束：墙壁行数等于前景矩形的行数；每个墙壁行中，标记列左侧最近的墙壁和右侧最近的墙壁之间的区间宽度 >= 前景矩形的宽度；墙壁行从上到下连续（中间不跳行）。

**规则**：
1. 找到前景矩形（所有非背景、非灰、非红像素）的紧凑外接矩形，裁剪出该区域。
2. 将裁剪结果水平镜像（左右翻转列顺序）。
3. 按墙壁行从上到下排序，将其与镜像结果的行从上到下一一对应（第一个墙壁行对应镜像第一行，以此类推）。
4. 在每个墙壁行中，确定标记列严格左侧最近的灰(5)像素位置 L 和标记列及其右侧最近的灰(5)像素位置 R。填充区间为 [L+1, R-1]。
5. 将镜像对应行的像素从左对齐填入该区间：镜像行的第 0 列像素放在 L+1，第 1 列放在 L+2，以此类推。若镜像行宽度小于区间宽度，多余位置保持背景；若大于区间宽度，超出部分截断。
6. 墙壁像素、标记像素和前景矩形原位置均保持不变。

**关键洞察**：前景矩形和墙壁结构是两个独立输入——矩形提供内容（经镜像变换），墙壁提供容器（扫描线区间）；求解者必须同时识别内容变换（镜像）和容器定义（墙壁+标记列），才能确定输出。
