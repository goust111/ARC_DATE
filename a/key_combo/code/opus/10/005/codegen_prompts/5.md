## 新题 5：角落模板经点对称重定位

**组合逻辑**：[角落标记 → 固定模板](已有) → [绕枢轴半周旋转](已有，但作用对象从前景掩码变为生成的模板) → [擦除](已有)

**来源原语**：印章覆盖(stamp_overlay)、擦除(erase)、角落标记(corner_marker)、固定模板(fixed_template)、角落位置选模板(corner_selects)、标记色传递给模板(marker_color_pass) ← fd02da9e；旋转(rotate)、枢轴像素(pivot_pixel)、点对称(point_symmetry)、绕枢轴半周旋转(half_turn_around_pivot) ← 90347967

**依赖链**：角落位置选择模板形状和朝向 → 生成的模板作为整体被点对称反射到新位置 → 最终模板的位置和朝向同时由角落选择和枢轴位置决定。两步缺一不可：不知道角落就无法生成正确模板，不知道枢轴就无法确定模板最终位置。

识别网格角落的彩色标记像素，生成角落特定的内向模板图案，再将所有模板绕灰色枢轴做 180 度点对称反射至新位置。

**输入结构**：黑(0)背景，8x8 网格。网格的四个角落中有 2~3 个角落各有一个单像素标记（颜色互不相同，从蓝(1)、红(2)、绿(3)、黄(4)中取）。网格内部（非边缘行列）有一个灰(5)枢轴像素。生成约束：每个角落模板经过 180 度反射后仍落在网格内部；不同角落模板的反射像互不重叠；枢轴不在网格正中心（否则反射等于原位，失去推理价值）。

**规则**：
1. 识别角落标记像素及其所在角落（左上、右上、左下、右下）。
2. 根据角落位置生成内向模板（使用标记颜色）：
   - 左上角标记 → 在 (1,1) 处起始的 2x2 方块（即行1~2、列1~2，0-indexed）。
   - 右上角标记 → 在 (1, W-3) 处起始的 2x2 方块（即行1~2、列W-3~W-2）。
   - 左下角标记 → 三像素内弯模板：(H-2, 0)、(H-2, 1)、(H-3, 0)。
   - 右下角标记 → 三像素内弯模板：(H-2, W-1)、(H-2, W-2)、(H-3, W-1)。
   （H=行数, W=列数, 坐标 0-indexed）
3. 擦除所有角落标记像素（设为背景色）。
4. 将步骤 2 生成的所有模板像素作为整体，绕灰(5)枢轴做 180 度点对称反射：对每个模板像素 (r, c)，将其颜色放置到 (2*pivot_r - r, 2*pivot_c - c)。原始模板位置设为背景色。
5. 枢轴像素保持灰(5)。若反射像素落在枢轴位置，枢轴颜色不变。若反射像素超出网格边界，舍弃该像素。

**关键洞察**：必须先由角落位置生成正确的模板形状（不同角落产生不同形状和朝向），再将生成的模板做点对称反射。求解者无法跳过任何一步：不生成模板就没有反射对象，不做反射就无法解释输出中模板的最终位置。

## 实现要求

1. `main(grid)` 必须实现新题描述中的确定性转换规则，不能只识别 `generate_input()` 的固定模板。禁止不同的input网格输出相同的output网格。
2. `generate_input()` 必须随机生成多样样例，不能固定死。随机维度应覆盖：网格大小、对象数量、位置、颜色、方向、形状参数或关键分支。注意若描述中存在若干，需实现而不是只有单个，包括object或者对应关系等等。且若涉及到最短路径，则输入网格中必涉及到多条路径，对选择造成干扰。
3. 生成器必须保证输入满足 `main()` 的隐式假设：对象不重叠、不越界、特殊标记唯一或可区分、匹配关系无歧义、关键分支出现概率相同。
4. 禁止把 ARC 颜色 id 、亮度、拼写等当作人类不可见的数值语义参与排序、大小比较或隐藏映射。颜色变化必须有可见结构线索。注意颜色亮度、拼写等也是不可见信息，若描述中出现违规的颜色id或者亮度，可自行使用少量的固定颜色替代，但注意生成时要在三个以内输入输出网格中对所有变换100%覆盖度。
5. 输出样例要视觉清晰，人类必须能从输入输出对中肉眼辨认出规律。具体要求：避免对象粘连、覆盖关系混乱、同一像素多重语义；不同逻辑步骤产生的结果不要大面积层叠在一起导致无法分辨哪个颜色属于哪个步骤；输入中各元素之间保持足够间距，输出中新增的标记/填充/路径等应与背景和已有元素在颜色上有明显区分；若规则涉及多层叠加，生成时控制对象密度和尺寸，确保叠加区域只占少数像素而非铺满整个网格。
6. 若规则有多个分支，生成器不能长期固定成一个分支；应让分支在随机样例中合理出现。分支概率不必平均——难以发现的隐蔽分支（如少数情况下才触发的特殊规则）应适当提高出现概率，确保在 3 个训练示例中至少出现一次，否则求解者无法归纳该规则。对于颜色映射类规则，确保 2 个左右的示例即可覆盖所有映射关系（每种颜色→颜色的映射至少在某个示例中出现过）。
