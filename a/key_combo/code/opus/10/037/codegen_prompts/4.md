## 新题 4：标记位置编码旋转角度的格点精灵填充

**组合逻辑**：[格点骨架识别](已有) → [精灵裁剪](已有) → [标记位置解码旋转量](创新：标记像素在格点间隙中的方位编码旋转角度) → [旋转后填入腔室](创新：将旋转和腔室填充耦合)

**来源原语**：格点骨架/lattice_frame、封闭腔室/enclosed_cavity、标记像素/marker_pixel、标记指定腔室/marker_designates_cavity、填充/fill（来自 17b866bd）；精灵裁剪/sprite_crop、旋转/rotate（来自 2697da3f）；旋转对应/rotational_match（来自 ff805c23）

**依赖链**：必须先识别格点结构找到腔室，再从唯一有内容的源腔室裁剪精灵，然后从标记像素的方位解码旋转角度，最后将旋转后的精灵填入目标腔室。标记位置的含义（旋转量）依赖于格点结构的方位框架，裁剪依赖于腔室识别，填充依赖于旋转结果。

格点骨架围成若干腔室，其中恰好一个腔室包含彩色精灵图案，其余腔室为空但部分腔室的角隙处有标记像素；标记在角隙中的方位（上/右/下/左）编码 0/90/180/270 度旋转，将精灵按指定角度旋转后填入对应腔室。

**输入结构**：约 17x17 的网格，由青(8)像素构成周期性格点骨架，骨架将网格划分为 3x3 共 9 个等大的正方形封闭腔室（每个腔室内部为 3x3 的黑(0)区域）。恰好一个腔室内部包含一个由红(2)像素构成的非对称小精灵图案（3~5 个红像素，4-连通，占据腔室 3x3 区域的部分位置，不具有 90 度旋转对称性）。其余 8 个腔室中，有 3~4 个腔室的西北角间隙处（格点骨架中两条骨架线交叉形成的十字中心的某个方位）有一个标记像素。标记像素颜色为黄(4)，其位置位于该腔室西北角骨架交叉点的四个间隙方位之一：偏上方位表示 0 度（不旋转），偏右方位表示顺时针 90 度，偏下方位表示 180 度，偏左方位表示逆时针 90 度（即顺时针 270 度）。没有标记的腔室保持空白。生成约束：精灵图案在 0/90/180/270 度旋转后均能装入 3x3 腔室；标记像素的方位在不同腔室间至少出现两种不同值。

**规则**：
1. 识别青(8)格点骨架，定位所有 3x3 封闭腔室。
2. 找到唯一包含红(2)像素的源腔室，裁剪其 3x3 内容作为精灵模板。
3. 对每个含黄(4)标记像素的腔室：
   - 确定标记像素相对于该腔室西北角骨架交叉点的方位：交叉点正上方一格为"上"，正右方一格为"右"，正下方一格为"下"，正左方一格为"左"。
   - "上"→ 将精灵模板旋转 0 度（原样），"右"→ 顺时针旋转 90 度，"下"→ 旋转 180 度，"左"→ 顺时针旋转 270 度。
   - 将旋转后的精灵填入该腔室的 3x3 区域（精灵中的红(2)像素覆盖到腔室中，背景位置保持黑(0)）。
4. 清除所有黄(4)标记像素（将其位置恢复为青(8)骨架色或黑(0)背景色，取决于该位置原本属于骨架还是间隙）。
5. 源腔室中的精灵保持不变。无标记的空腔室保持黑(0)。

**关键洞察**：标记像素不携带颜色信息（颜色统一为黄），而是通过空间方位编码变换参数；必须对比多个示例中标记方位与精灵朝向的对应关系才能破解编码规则。
