## 新题 2：碎片重建走廊中的粒子追踪

**组合逻辑**：[合并对齐碎片 + 行列跨度重叠](已有) → [补全为空心矩形墙壁](创新：碎片合并后重建为框壁而非实心填充) → [路径追踪 + 碰撞转向 + 碰撞停止](已有) → [计数](已有，创新用于统计碰撞次数编码输出)

**来源原语**：合并对齐碎片/行列跨度重叠/残缺矩形/连通分量(8fbca751)、路径追踪/碰撞转向/碰撞停止/粒子/走廊(9bbf930d)、计数(89565ca0)、空心矩形(68bc2e87)

**依赖链**：碎片合并决定墙壁的边界框 → 边界框重建为框壁确定走廊拓扑 → 走廊拓扑决定粒子路径 → 路径中的碰撞次数编码为最终输出

一句话总结：先将散布的碎片按行列跨度合并并重建为空心矩形墙壁，再在墙壁间的走廊中追踪粒子路径，根据碰撞次数生成输出编码。

**输入结构**：约 18x18 网格。黑(0)背景。散布 10-20 个青(8)像素碎片，每个碎片为 1-3 个像素的 4-连通小块，分属 3-5 个逻辑组（同组碎片的边界框在行跨度或列跨度上有重叠，不同组之间无跨度重叠）。品红(6)单像素粒子 2-3 个，放置在网格左边界上不同行。生成约束：合并后每组碎片的边界框为 3x3 到 6x6 的矩形；不同组的边界框之间至少间隔 2 行 2 列，留出可通行的走廊；每个粒子的初始行都在某条走廊的通行范围内。

**规则**：
1. 对所有青(8)碎片进行传递性合并：两个碎片的边界框若在行跨度或列跨度上有交集，则合为一组；合并过程迭代至收敛。
2. 对每个合并组，取该组所有像素的总边界框，将该边界框的四条边（单像素宽边框）全部涂为青(8)，内部保持黑(0)——形成空心矩形墙壁。原始碎片中位于边框以内的像素被墙壁覆盖。
3. 每个品红(6)粒子从左边界出发，初始方向向右。粒子逐像素前进；当下一个像素为青(8)墙壁或网格边界时，粒子发生碰撞：若当前方向为水平则转为向下，若为垂直则转为向右（始终做顺时针 90° 转向）。转向后继续前进。若转向后的下一像素仍为墙壁或边界，粒子停止。
4. 每个粒子经过的所有像素（含起点，不含停止后未到达的下一格）涂为绿(3)。粒子原始的品红像素被绿色覆盖。
5. 统计所有粒子的碰撞总次数 K。在网格最右列从上往下连续涂 K 个橙(7)像素（若 K 超过网格高度则截断至网格高度）。若最右列某像素已为其他颜色，橙色覆盖之。

**关键洞察**：散落碎片的空间分布看似随机，但合并后形成的墙壁布局完全确定了走廊拓扑。仅看碎片无法直接判断走廊走向——必须先完成跨度合并和边框重建。碰撞计数依赖完整路径，而路径又依赖墙壁重建，三步不可分割。不同示例中碎片位置不同导致走廊拓扑不同，需对比多个示例确认"顺时针 90° 转向"这一非显然规则（而非总是向下或总是转向更宽的走廊）。
