## 新题 5：碎片合并重建框架后推断遮挡堆叠序

**组合逻辑**：[合并对齐碎片 + 行列跨度重叠](已有，创新应用于多色碎片) → [重建空心矩形](已有) → [遮挡层序 + 重叠定先后](已有) → [排序](已有，输出堆叠序列)

**来源原语**：合并对齐碎片/行列跨度重叠/残缺矩形/连通分量(8fbca751)、重建/空心矩形/重叠层/遮挡层序/重叠定先后(68bc2e87)、排序(f8ff0b80)

**依赖链**：同色碎片按跨度合并 → 每色合并后重建为空心矩形框 → 框间重叠像素的可见颜色确定遮挡关系 → 遮挡关系排序为堆叠序

一句话总结：多种颜色的离散碎片各自按行列跨度合并后重建为空心矩形框，根据框重叠处的可见颜色推断从底到顶的堆叠顺序，输出为单列色序。

**输入结构**：约 14x14 网格。黑(0)背景。3-4 种前景色（从红(2)、绿(3)、蓝(1)、黄(4)中选取），每种颜色有 3-6 个离散像素碎片（每个碎片 1-3 像素，4-连通）。同色碎片分布使得它们的边界框在行跨度或列跨度上可传递性重叠，最终合为一组。不同颜色的合并后边界框之间有部分重叠区域（重叠区域宽度至少 1 像素）。在输入中，重叠位置上只显示最顶层框架的颜色。生成约束：每种颜色的碎片合并后形成唯一一个边界框，尺寸在 4x4 到 8x8 之间；堆叠层序唯一（即从所有重叠关系可推出完整的全序排列）；至少有一组重叠关系需要通过合并后的框推断（即原始碎片在该重叠区域无可见像素，必须重建框后才知道该位置有重叠）。

**规则**：
1. 对每种前景色独立进行碎片合并：两个同色碎片若边界框在行跨度或列跨度上有交集则合为一组，传递性迭代至收敛。
2. 对每种颜色的合并组，取总边界框，重建为该颜色的空心矩形（边界框四边涂为该色，内部为黑色）。
3. 在所有重建矩形框的边重叠的像素位置，输入中该像素的颜色即为最顶层的颜色。若输入中该像素为黑色（原始碎片未覆盖但重建框会经过），则取输入中该行或该列最近的同色碎片来推断——但实际上重叠处总有至少一种颜色的原始碎片可见，因此可直接从输入读取顶层颜色。
4. 根据所有重叠像素的层级关系，推断唯一的从底到顶堆叠全序。规则：若颜色 A 在某重叠位置被颜色 B 遮挡（该位置输入为 B 但 A 的重建框也经过此处），则 A 在 B 之下。
5. 输出为 Nx1 的单列网格（N = 前景色数量），从上到下为从底到顶的颜色序列。

**关键洞察**：单纯的连通分量分析无法正确恢复矩形框——同框碎片可能不相连但行列跨度重叠。合并策略直接决定了重建出的框的大小和位置，进而决定了哪些位置存在重叠。错误的合并会导致错误的遮挡推断。需对比多个示例确认"行列跨度重叠即合并"而非"4-连通即合并"的规则。
