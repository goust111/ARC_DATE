## 新题 1：双面板种子激活选择性填充

**组合逻辑**：[透明叠加 + 位置对齐](已有) → [封闭区域识别](已有，创新应用于叠加后的种子检测) → [填充](已有，由种子激活条件门控) → [计数 + 区域数映射长度](已有，创新用于编码激活数量)

**来源原语**：透明叠加/位置对齐/双面板背景交集(0c9aba6e)、封闭区域(89565ca0)、填充/角标记/矩形(af902bf9)、计数/区域数映射长度(89565ca0)

**依赖链**：面板对齐确定标记与区域的空间对应 → 封闭区域几何定义填充边界 → 标记落点决定哪些区域被激活 → 激活区域数量编码为附加输出条

一句话总结：将下面板的标记像素叠加到上面板，仅填充含标记的封闭区域，并在底部附加一段表示激活区域数的色条。

**输入结构**：约 15x7 网格（两个 7x7 面板 + 1 行灰(5)分隔行）。黑(0)背景。上面板：绿(3)单像素宽线段构成 2-4 个互不相交的闭合矩形框（框内像素均为黑色），每个框的边界框尺寸在 3x3 到 5x5 之间，框与框之间至少间隔 1 个像素。下面板：黄(4)单像素标记散布在黑色背景上，共 3-6 个，部分标记在位置对齐后落在上面板某些闭合框的内部区域，部分落在框外或框壁上。生成约束：每个闭合框至少有一个示例中含标记、至少有一个示例中不含标记，以确保规则可区分；不同示例中标记数量和位置不同，使得被激活的区域集合不同。

**规则**：
1. 移除灰(5)分隔行，将上下面板按列对齐。
2. 在上面板中识别所有由绿(3)像素完全围成的 4-连通黑(0)封闭区域（绿色边框像素不属于区域内部）。
3. 对于每个封闭区域，检查对齐后的下面板在相同位置集合中是否存在至少一个黄(4)像素。存在则该区域"被激活"。黄色像素落在绿色框壁上或框外的不计入任何区域。
4. 将所有被激活区域内的黑色像素填充为红(2)。未被激活的区域保持黑色。绿色框壁保持不变。
5. 输出为上面板尺寸（7x7）的网格，在其正下方拼接一行：该行从左起连续填充红(2)像素，数量等于被激活区域的总数，其余填黑(0)。

**关键洞察**：下面板并非简单的掩码——标记必须精确落在封闭区域内部才有效，落在框壁上或框外则被忽略。仅凭单个示例无法区分"填充所有区域"和"填充含标记的区域"，必须对比含标记区域不同的多个示例才能归纳出选择性激活规则。
