## 新题 2：膨胀交叠通道上的对边触发色互换

**组合逻辑**：[膨胀求交 dilate_intersect](已有) + [颜色互换 color_swap](创新：仅在膨胀通道与边缘标记选定线段的交集区域执行互换)

**来源原语**：膨胀求交/路径组件/通道/两路径间隙重叠区(f1bcbc2c), 颜色互换/标记像素/网格边缘/对边配对/配对间像素互换(d2acf2cb)

**依赖链**：两条路径的膨胀交叠定义出通道几何 → 对边黄标记选定行/列线段 → 通道几何与标记线段的交集区域才执行颜色互换；通道外的标记线段不互换，标记线段外的通道也不互换

输入中两条橙色路径的一像素膨胀交叠产生中间通道，但只有通道中被对边黄标记选中的那些像素才执行黑-青/品红-橙色互换。

**输入结构**：黑(0)背景，约 15x15 网格。橙(7)前景色形成两条 4-连通的单像素宽路径组件，两条路径大致平行但不接触，间距 2~3 像素，路径之间的间隙中散布着少量黑(0)、青(8)、品红(6)像素。网格的上下边缘（或左右边缘）各有 2~3 个黄(4)标记像素，形成对边配对——每对黄标记处于同一行（若上下对边）或同一列（若左右对边），标记之间的严格内部像素构成"选定线段"。生成约束：至少有一条选定线段穿过两路径之间的间隙区域，且至少有一条选定线段完全不经过间隙区域。

**规则**：
1. 将两条橙(7)路径各自在 8-邻域膨胀 1 像素，取两个膨胀结果的交集，得到中间通道（不包含橙(7)路径自身的像素）。
2. 识别所有黄(4)对边标记对。每对标记选定一条直线段（行段或列段），线段的严格内部像素（不含两端黄像素）构成"选定区域"。
3. 计算通道与所有选定区域的交集。仅对交集中的像素执行颜色互换：黑(0) <-> 青(8)，品红(6) <-> 橙(7)。
4. 黄(4)标记像素保持不变。通道中不在选定区域内的像素保持不变。选定区域中不在通道内的像素保持不变。所有其他像素保持不变。

**关键洞察**：颜色互换的空间范围不由单一规则决定——它是两个独立几何构造（路径膨胀交叠产生的通道、边缘标记选定的线段）的交集，求解者必须同时推断这两层结构才能确定哪些像素变化。

Input structure
- The background is black.
- One foreground color forms exactly two 4-connected one-pixel-wide path components.

Rule
