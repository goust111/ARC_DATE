## 新题 4：枢轴旋转后沿新方向延续周期图案

**组合逻辑**：[旋转 rotate](已有：绕枢轴四分之一转) + [平铺/周期延续 tile](创新：旋转改变了延续方向，周期图案必须在新方向上正确衔接)

**来源原语**：旋转/枢轴标记/绕点旋转/顺时针四分之一圈(c074846d), 平铺/周期图案/周期/宽度加倍延续周期(963e52fc)

**依赖链**：识别线段内部的周期图案 → 绕枢轴顺时针旋转 90° 得到新方向 → 沿新方向继续延续同一周期直至网格边界；旋转改变了图案的空间朝向，周期的"下一个单元"必须基于旋转后的坐标系计算

一条带有内部周期颜色图案的线段绕灰标记旋转 90 度后，沿新方向继续延续同一周期直到碰壁，同时原位置线段变绿。

**输入结构**：黑(0)背景，约 15x15 网格。一个灰(5)像素作为枢轴标记。一条从枢轴出发、沿水平或垂直方向延伸的线段（长度 4~8 像素），线段上的像素交替使用红(2)和蓝(1)两种颜色，形成周期为 2 的图案（即红蓝红蓝...或蓝红蓝红...），紧邻枢轴的第一个像素的颜色记为 C1。生成约束：顺时针旋转 90° 后的新方向上，从枢轴到网格边界的距离 ≥ 原线段长度 + 3，确保延续有足够空间。原线段方向上枢轴位于一端（线段从枢轴向一个方向延伸）。

**规则**：
1. 找到灰(5)枢轴和与之相邻的非黑非灰线段像素，确定线段方向（枢轴→线段末端的方向向量）。
2. 记录线段的周期颜色序列（从紧邻枢轴的像素开始：C1, C2, C1, C2, ...）和线段长度 L。
3. 将原线段的所有像素重涂为绿(3)（标记旧位置）。
4. 将方向向量顺时针旋转 90°，得到新方向。从枢轴沿新方向绘制新线段：前 L 个像素重复原周期（第 1 个像素=C1，第 2 个=C2，...），然后继续延续同一周期直到下一个像素超出网格边界为止。
5. 灰(5)枢轴像素保持不变。

**关键洞察**：旋转不只是改变了一根线段的位置——它改变了周期图案的延续方向，而延续长度取决于旋转后新方向上的可用空间，这是旋转前无法预知的。原线段的周期信息必须被"读取"后才能在新方向上正确续写。
