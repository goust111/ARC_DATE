## 新题 8：封闭环路面积排序压缩为等宽条纹

**组合逻辑**：[计数·围合面积](创新：计算的不是对象自身面积而是对象围成的封闭区域面积) → [排序·按围合面积](创新：排序键是对象的拓扑属性而非空间位置) → [压缩·条纹化](创新：每个对象被压缩为一行色条，宽度由对象自身像素数决定)

**来源原语**：计数(counting) ← e3721c99/df8cc377/8e301a54；封闭区域(enclosed_region) ← e3721c99；排序(sorting) ← 668eec9a；最高行决定序(topmost_determines) ← 668eec9a；压缩(compress) ← 7e4d4f7c；色条行(color_stripe_row) ← 668eec9a；连通分量(connected_component) ← 8e301a54

**依赖链**：必须先识别每个闭合环路围成的封闭背景区域并计算其面积（拓扑分析），才能确定排序顺序；排序顺序决定条纹在输出中从上到下的位置；而每个条纹的宽度取决于环路自身的像素计数（另一个独立的计数操作），两种计数的结果在输出中正交组合（纵向位置 vs. 横向宽度）。

将闭合环路按围合面积从小到大排序，每个环路压缩为一行色条（宽度等于环路像素数），垂直堆叠输出。

**输入结构**：黑(0)背景，约 18x18 网格。网格中有 3~5 个单像素宽的闭合环路，每个环路由不同颜色绘制（如蓝(1)、红(2)、绿(3)、黄(4)），每个环路是一个封闭的 4-连通回路（像素首尾相连形成一个不自交的闭合曲线，宽度为 1 像素），围成一块背景区域。各环路互不重叠、互不嵌套、互不相邻（环路之间至少隔 1 像素背景）。各环路围成的背景面积各不相同，各环路自身的像素数也各不相同。生成约束：环路的最大像素数不超过网格宽度（以便条纹宽度不超出输出网格）。

**规则**：
1. 识别每个非背景颜色的 4-连通分量（每个分量即一个闭合环路），记录其颜色和像素数 P。
2. 对每个环路，找到其围合的封闭区域：环路像素将某块背景区域完全包围（该背景连通域不与网格边界连通），计算该封闭背景区域的面积 A。
3. 按围合面积 A 从小到大排序所有环路。若 A 相同（生成时避免），按环路最上方像素行号从小到大排。
4. 构造输出网格：高度等于环路个数，宽度等于所有环路中最大的像素数 P_max。背景为黑(0)。
5. 从第 0 行起，按排序顺序逐行放置每个环路的色条：在该行从第 0 列起连续绘制 P 个像素（P 为该环路的像素数），颜色为该环路的颜色。剩余列保持背景。

**关键洞察**：同一个对象需要被度量两次——围合面积决定它在输出中的纵向位置，自身像素数决定它在输出中的横向宽度。两种计数结果正交组合，缺一不可：跳过围合面积则无法确定堆叠顺序，跳过像素计数则无法确定条纹宽度。源题 668eec9a 中排序键是空间位置（最高行），这里排序键是拓扑属性（围合面积），改变了排序的语义层级。
