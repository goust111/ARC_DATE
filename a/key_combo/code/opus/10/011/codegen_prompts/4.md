## 新题 4：射线方向推断模板选择与缩放补全

**组合逻辑**：[射线方向推断](创新：方向不再用于对接，而是用于从多个模板中选择正确的一个) + [补全·缩放](创新：被选中的模板按框内尺寸缩放后填充框内) + [擦除](已有原语)

**来源原语**：射线方向推断(ray_inferred_direction) ← 8b9c3697；内部槽位(interior_socket) ← 8b9c3697；对接(dock) ← 8b9c3697；补全(complete) ← 8a6d367c；种子选择模板(seed_selects_template) ← 8a6d367c；模板(template) ← 8a6d367c；缩放(scaling) ← 8a6d367c/46f33fce；矩形框(rectangular_frame) ← 8a6d367c/df8cc377；擦除(erase) ← 184a9768

**依赖链**：必须先从矩形框的内部槽位向外发射射线、确定射线命中的是哪个模板（方向推断），才能知道用哪个模板来补全框内；而补全时的缩放因子取决于框内尺寸与模板尺寸的比值，这又需要先裁剪出模板的边界框。最后擦除框外所有模板和未命中的组件。

从矩形框的内部空缺向外射线寻找最近模板，以射线命中的模板为源，缩放后填充框内，擦除框外所有辅助元素。

**输入结构**：青(8)背景，约 18x18 网格。网格中有一个灰(5)单像素宽空心矩形框（内部尺寸为 NxM，N 和 M 在 4~8 之间）。框内有少量红(2)种子像素（1~3 个，散落在框内背景位置）。框外四个方向（上、下、左、右）中的 2~3 个方向各放置一个小型多色模板（3x3 或 4x4 边界框，由 2~3 种非背景、非灰、非红的颜色组成，如蓝(1)、绿(3)、黄(4)），每个模板的前景形状不同。其中恰好有一个模板满足：框内尺寸是该模板边界框尺寸的整数倍（即 N/模板高 和 M/模板宽 都是正整数），且该模板的前景掩码按此倍率缩放后，缩放掩码覆盖了所有红(2)种子像素的位置。生成约束：从框内任意红(2)种子像素沿某个正交方向（上/下/左/右）射线扫描，第一个命中的模板就是正确模板（所有种子像素射线命中的是同一个模板）。其他模板不满足缩放整除条件或缩放后不覆盖种子。

**规则**：
1. 识别灰(5)空心矩形框，计算其内部尺寸 NxM。
2. 识别框内的红(2)种子像素。
3. 从每个种子像素位置沿上、下、左、右四个正交方向射线扫描（在原始输入上），找到第一个非背景、非灰像素所属的模板分量。所有种子像素命中同一个模板——该模板即为目标模板。
4. 计算缩放因子：scale_r = N / 模板边界框高度，scale_c = M / 模板边界框宽度（均为正整数）。
5. 将目标模板的每个像素扩展为 scale_r x scale_c 的色块，生成缩放后的模板图像（NxM）。
6. 将缩放后的图像填入矩形框内部，替换框内所有背景和种子像素。框的灰(5)边界保持不变。
7. 擦除框外的所有模板和种子以外的前景像素（恢复为背景色）。

**关键洞察**：射线方向推断在源题 8b9c3697 中用于确定对接的滑动方向，这里被重新用于从多个候选模板中选出正确的一个——方向成为选择键而非运动参数。种子像素同时扮演两个角色：它们既是射线的发射源（选择模板），又是缩放正确性的验证约束（种子必须落在缩放掩码上）。
