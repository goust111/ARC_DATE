## 新题 9：括号提取宽度驱动楔形展开与居中堆叠

**组合逻辑**：[括号界定提取](已有原语) → [排序·按宽度](创新：排序键从"行序"变为提取段的非背景像素数) → [逐行扩展楔形·以最窄段为中心](创新：楔形结构由排序后的段宽度差异自然产生)

**来源原语**：括号界定提取范围(bracket_delimited_extraction) ← 505fff84；控制像素对(control_pixel_pair) ← 505fff84；行段(row_segment) ← 505fff84；排序(sorting) ← 668eec9a；逐行扩展楔形(row_expand_wedge) ← bae5c565；以缺口为中心(centered_on_gap) ← bae5c565；堆叠(stacking) ← 505fff84

**依赖链**：括号提取的段宽度各不相同，宽度信息直接决定排序顺序（从窄到宽）；排序顺序决定堆叠的纵向位置；堆叠时每段居中对齐，宽度递增形成视觉楔形——这个楔形不是由预设规则逐行扩展一格产生的，而是由提取段自身的宽度差异自然涌现。

从控制像素对括号提取行段，按段内非背景像素数排序，居中堆叠形成宽度递增的楔形输出。

**输入结构**：黑(0)背景，约 15x20 网格。网格中有若干行包含蓝(1)-青(8)控制像素对：每个标记行恰好有一个蓝(1)像素在左、一个青(8)像素在右，两者之间的段包含红(2)和黑(0)像素的混合图案。不同标记行之间的段宽度（蓝与青之间的列数）各不相同（如 3、5、7、9 列）。非标记行无蓝或青像素。标记行有 3~5 行，散布在网格不同行上（不一定连续）。生成约束：每个段内的非背景像素数各不相同；段的最大宽度为奇数（以便居中对齐时左右对称）。所有段的宽度均为奇数。

**规则**：
1. 识别所有标记行（同时包含蓝(1)和青(8)各一个像素的行）。
2. 对每个标记行，提取蓝(1)和青(8)之间（不含蓝和青本身）的行段内容。
3. 计算每个行段内的非背景像素数 N（即红(2)像素的个数）。
4. 按 N 从小到大排序所有行段。
5. 构造输出网格：高度等于行段数，宽度等于最宽行段的宽度。背景为黑(0)。
6. 从第 0 行开始，按排序顺序依次放置行段：每个行段水平居中放置在该行（左右各补等量的背景像素使总宽度等于输出网格宽度；若段宽度与输出宽度之差为奇数——生成时已避免此情况——则多出的一列补在右侧）。
7. 输出网格从上到下段宽度递增，自然形成底宽顶窄的楔形。

**关键洞察**：楔形形状不是通过"每行多展开一列"的固定规则产生的（源题 bae5c565 的机制），而是从提取段自身宽度差异中涌现——排序后宽度自然递增。若跳过排序直接按原始行序堆叠，就不会形成楔形；若跳过括号提取直接排序，则没有段内容可供堆叠。三个操作的耦合产生了一个在源题中都不存在的视觉效果。
