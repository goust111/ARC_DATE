## 新题 6：重复图案筛选后四重对称补全

**组合逻辑**：[图案匹配·出现两次者选取](创新：选取的不是完整精灵体而是部分对称碎片) + [擦除·忽略干扰项](已有原语) → [对称补全·角落补四重](创新：补全对象来自筛选结果而非直接给定)

**来源原语**：图案匹配(pattern_match) ← f5aa3634；出现两次者选取(twice_pattern_selected) ← f5aa3634；裁剪(crop) ← f5aa3634；擦除(erase) ← e3721c99；忽略干扰项(ignore_distractors) ← e3721c99；对称补全(symmetry_completion) ← 4290ef0e；角落补全四重对称(corners_to_fourfold_symmetry) ← 4290ef0e；中心对齐(center_alignment) ← 4290ef0e

**依赖链**：必须先裁剪每个碎片并比较图案才能确定哪个颜色的碎片出现了恰好两次（筛选）；筛选结果直接决定哪些碎片被保留用于对称补全，其余被擦除；对称补全时需要从保留碎片的角落位置推断完整图案的尺寸和对称轴。

从多个彩色碎片中找到裁剪图案恰好出现两次的那个颜色，擦除其余颜色碎片，将保留碎片作为角落-L 碎片补全为四重对称图案。

**输入结构**：黑(0)背景，约 15x15 网格。网格中散布 3~4 种颜色的前景碎片，每种颜色有 1~3 个 4-连通分量。每个分量是一个小型图形（3~6 像素的角落-L 形碎片，即一个方向的直角形状）。其中恰好一种颜色（如红(2)）的所有分量（恰好 2 个）裁剪到边界框后图案完全相同（含内部背景像素）；其他颜色的分量裁剪后图案各不相同或只出现一次。红(2)的两个分量分布在网格不同区域，互不重叠。生成约束：出现两次的红色碎片形状为角落-L（占据某个 NxN 正方形的一个角落区域，形成直角），N 为奇数（3 或 5），使得四重对称补全后可以生成 NxN 的完整图案。

**规则**：
1. 识别所有非背景 4-连通分量，按颜色分组。
2. 对每个分量裁剪到其最小边界框（保留框内背景像素）。
3. 在每个颜色组内，比较所有分量的裁剪图案（逐像素比较）。找到恰好有 2 个分量裁剪图案完全相同的那个颜色，记为 C_valid。
4. 擦除所有颜色不是 C_valid 的前景像素（恢复为背景）。
5. 取 C_valid 的一个分量的裁剪图案作为角落-L 碎片。确定该碎片占据 NxN 正方形的哪个角落（前景像素集中在左上/右上/左下/右下哪个象限）。
6. 将该碎片在 NxN 正方形的四个角落各放置一份（对应旋转 0/90/180/270 度），合成四重对称图案。
7. 将合成的 NxN 图案居中放置在与输入同尺寸的黑色输出网格上。

**关键洞察**：源题 f5aa3634 中重复选取的是完整精灵体并直接输出其裁剪，这里重复选取的是碎片——选取本身不是终点而是对称补全的前置条件。若跳过重复检测直接补全，无法知道该补全哪个颜色的碎片；若跳过对称补全直接输出匹配结果，得到的只是碎片而非完整图案。
