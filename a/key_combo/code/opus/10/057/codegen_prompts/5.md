## 新题 5：印章重叠次数涌现多级颜色映射

**组合逻辑**：[stamp](放置多份模板副本) → [counting](创新：统计每个像素被副本覆盖的次数，源题中不存在此操作) → [recolor](覆盖次数映射为不同颜色，将二元重叠判断扩展为多级)

**来源原语**：stamp, template, singleton_layout, lattice_offset, overlap_recolor — 来自 a395ee82；counting, same_color_multiset, region_miss_pixel — 来自 e3fe1151；recolor, color_pair_mapping — 来自 54d9e175

**依赖链**：印章放置产生空间重叠，重叠次数需要计数统计，计数结果通过映射表转化为颜色。不放印章则无重叠可数；不计数则无法区分不同重叠层次；不执行映射重涂则输出不反映层次信息。三步形成信息变换链。

将模板按单像素布局印到多个栅格偏移位置，然后按每个像素被模板覆盖的总次数重涂为不同颜色。

**输入结构**：约 15x15 网格，黑(0)背景。一个红(2)色小模板（4-6 像素，4 连通，边界框不超过 3x3），位于网格左上角区域。4-6 个灰(5)色单像素标记散布在网格其余区域，排列在均匀间距的栅格上。其中一个标记为红(2)色（与模板同色），标识布局原点；其余标记为灰(5)。栅格行间距等于模板边界框高度，列间距等于模板边界框宽度。生成约束：标记数量和位置使得部分模板副本的覆盖区域产生二重甚至三重重叠（最大重叠次数不超过 3）；所有副本不超出网格边界。

**规则**：
1. 将每个标记（灰(5)和红(2)原点标记）的坐标偏移量转换为粗栅格单位（行偏移 / 模板边界框高度，列偏移 / 模板边界框宽度）。
2. 在每个栅格偏移处放置一份模板副本（模板左上角对齐到偏移后的坐标位置）。
3. 统计输出网格中每个像素被模板副本覆盖的总次数 k。
4. k = 1 的像素涂为红(2)（模板原色）。k = 2 的像素涂为蓝(1)。k = 3 的像素涂为黄(4)。k = 0 的像素为黑(0)。
5. 擦除所有标记像素原始位置（若该位置未被模板副本覆盖则置黑，若被覆盖则按覆盖次数着色）。
6. 擦除模板自身的原始显示位置（置为黑(0)）。

**关键洞察**：源题 a395ee82 中重叠仅产生二元判断（有重叠 → 重涂为一种颜色），本题中重叠产生多级计数值，每级映射到不同颜色——这是印章放置与计数操作耦合后涌现的效果：单独的印章操作不产生计数，单独的计数操作无对象可数。
