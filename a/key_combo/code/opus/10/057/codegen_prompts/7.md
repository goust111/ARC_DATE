## 新题 7：同心环颜色反向索引对象填充

**组合逻辑**：[concentric_ring + distance_mapping](同心环从"被标记像素染色的输出"反转为"提供颜色查找表的只读结构") → [fill](填充目标从环本身改为远处的空心框) + [chebyshev_distance](从标记到中心的距离改为框到中心的距离，作为查找键)

**来源原语**：concentric_ring, distance_mapping, chebyshev_distance, center_aligned, fill, recolor, marker_pixel — 来自 ac0c2ac3；rectangular_frame, enclosed_interior, interior_area, fill — 来自 84f2aca1；foreground_object, adjacency_contact — 来自 48d8fb45

**依赖链**：同心环建立"距离 → 颜色"查找表，空心框中心到网格中心的切比雪夫距离提供查找键，填充操作使用查找到的颜色填充框内部。删掉环则无颜色表可查；删掉距离计算则无法索引；删掉填充则框不变。

以同心方环的颜色为调色板，按每个空心矩形框中心到网格中心的切比雪夫距离查表，用对应环的颜色填充该框的内部。

**输入结构**：奇数边长正方形网格（如 15x15），黑(0)背景。网格中心区域绘有 3-4 层同心方环（以网格正中心像素为圆心），每层环宽 1 像素，各层颜色互不相同（如距离 1 为红(2)，距离 2 为绿(3)，距离 3 为黄(4)）。中心点为蓝(1)。环之间及环外为黑(0)背景。网格外围区域（保证与同心环区域不重叠）散布 3-4 个灰(5)色单像素厚空心矩形框，大小各异（内部面积 >= 2），互不重叠。每个框的中心到网格中心的切比雪夫距离恰好等于某一层同心环的距离值（1, 2, 3, ...）。不同框的距离值互不相同。生成约束：框距同心环区域至少间隔 2 像素，保证两者不重叠也不相邻。

**规则**：
1. 读取同心环结构，建立距离到颜色的映射表：距离 d 处环的颜色为 C_d（如 d=1 → 红(2)，d=2 → 绿(3)等）。
2. 对每个灰(5)空心矩形框，计算其中心坐标（行中心、列中心各取整），再计算该中心到网格中心的切比雪夫距离 d。
3. 在映射表中查找 C_d，将该框封闭内部的所有黑(0)像素填充为 C_d。
4. 灰(5)框轮廓保持不变。
5. 同心环区域保持不变。

**关键洞察**：同心环在源题 ac0c2ac3 中是被染色的输出对象（标记 → 环），本题中角色完全反转——环是只读颜色字典，真正被变换的是远处的空心框。框的空间位置不仅是它的几何属性，更是字典的查询键，建立了"空间位置 → 距离 → 颜色"的间接寻址链。

generation_strategy:
  approach: output-first
  steps:

    2. Build the output panel (H x W) by placing N connected mark blobs (one per color, 2-5 cells each) on a blank(0) background, ensuring no positional overlap. Verify marks are 4-connected per color.
    3. For each mark color, extract its cells as a separate panel patch (mark cells + blank elsewhere).
    4. Create 16x16 grid filled with separator. Place N panels (H x W) at random non-overlapping positions, each surrounded by >=1 separator border, with >=2 gap between panels. Paste each patch into its panel slot.
