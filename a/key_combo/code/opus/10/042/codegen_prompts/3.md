## 新题 3：射线吸收量决定柱状条重排序

**组合逻辑**：[射线延伸ray_extend](创新：射线被同色柱吸收而截断) + [排序sort](创新：排序键为吸收的射线数) + [重分配redistribute] ← [朝向决定方向orientation_determines_direction] + [槽位保持颜色slot_retains_color]

**来源原语**：射线延伸/ray_extend(f8be4b64、9344f635)、微型标记/micro_marker(9344f635)、行列条/row_column_bar(9344f635)、朝向决定方向/orientation_determines_direction(9344f635)、排序/sort(31f7f899)、重分配/redistribute(31f7f899)、柱状条/vertical_bar(31f7f899)、基线/baseline(31f7f899)、槽位保持颜色/slot_retains_color(31f7f899)、遇前景终止/stop_at_fg(f8be4b64)

**依赖链**：多米诺标记发射水平射线 → 射线遇到柱状条时被吸收（截断）→ 统计每根柱吸收的射线总数 → 以吸收数为键排序柱的形状轮廓 → 将轮廓重新分配到固定槽位并涂为槽位颜色。射线发射和柱位置在同一网格中互相影响（柱截断射线的同时也决定了自己的排序键）。

水平多米诺标记向两侧发射行射线；射线遇到柱状条时停止并被该柱"吸收"；统计每根柱吸收的射线总数，按此数值从小到大重新排列柱的轮廓到各槽位，槽位保留原色。

**输入结构**：约 14x18 黑(0)背景网格。底部有一条横跨全宽的灰(5)基线（第 12 行）。基线上方竖立 4 根柱状条，每根宽 1 像素、高度各不相同（3-7 格），颜色互不相同（从蓝(1)、红(2)、绿(3)、黄(4)中取）。网格左侧区域（柱状条左方的空白区）散布 3-5 个水平二像素多米诺标记，每个多米诺由橙(7)像素组成，分布在不同行上。生成约束：每个多米诺标记的行坐标在基线以上、至少有一根柱的高度范围内；每根柱至少被一条射线触达；无两根柱吸收数相同。

**规则**：
1. 每个水平橙(7)多米诺向右发射一条橙(7)行射线（从多米诺右端的下一列开始），射线逐列延伸直到遇到非黑像素（柱状条像素或网格右边界）时停止，不包含终止点。射线像素绘制为橙(7)。
2. 对每根柱，统计有多少条射线以该柱的像素作为终止点（即射线抵达该柱的列时停止）。记为该柱的"吸收数"。
3. 按吸收数从小到大排列所有柱的高度轮廓（形状不变，仅高度信息转移）。
4. 将排序后的轮廓依次放入从左到右的槽位（原各柱的 x 坐标位置），每个槽位涂为该槽位原来的柱颜色。
5. 基线保留不变。射线像素在输出中擦除（恢复为黑(0)背景）。

**关键洞察**：射线的传播路径被柱的空间位置截断，而截断次数反过来决定了柱的排序键——柱既是射线的障碍物，又是排序的被作用对象，两个角色互为因果。
