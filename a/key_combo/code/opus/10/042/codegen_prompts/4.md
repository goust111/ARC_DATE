## 新题 4：角标缩放与对称轴裁剪

**组合逻辑**：[像素放大scale_up](缩放倍率由角标间距隐式编码) + [镜像reflect](创新：角标颜色不对称时只保留一半) ← [角标记corner_marker](同时编码缩放区域和对称选择) + [对称轴关系symmetry_axis](创新：由帧线位置确定)

**来源原语**：像素放大/scale_up(8a004b2b)、角标记/corner_marker(8a004b2b、3de23699)、着色约束对齐缩放/color_evidence_constrains_scaled_placement(8a004b2b)、镜像/reflect(f8a8fe49)、框架线/frame_line(f8a8fe49)、对称轴关系/symmetry_axis(f8a8fe49)、裁剪/crop(f8a8fe49、3de23699)、内部图案/inner_pattern(f8a8fe49)

**依赖链**：角标定义目标区域 → 小精灵缩放填入区域 → 帧线将区域一分为二形成对称轴 → 角标颜色不对称性指示保留哪一半。缩放倍率、对称轴位置、输出裁剪范围全部由同一组角标和帧线隐式编码，必须联合解读。

将外部小精灵按角标定义的区域尺寸进行整数倍放大填入该区域，然后沿区域内的红色帧线做镜像对称轴裁剪——保留角标颜色出现次数较多的那一侧作为输出。

**输入结构**：约 16x16 黑(0)背景网格。网格一角（如左上 4x4 范围内）有一个 3x3 或 4x4 的多色小精灵（由蓝(1)、绿(3)、黄(4)像素组成，含黑背景像素）。网格另一区域有 4 个角标像素标定一个矩形目标区域（约 9x9 或 12x8）：其中 3 个角标为橙(7)，1 个角标为栗(9)。目标区域内部正中央有一条红(2)帧线（水平或垂直单像素线，贯穿区域宽或高）。目标区域内还散布 2-3 个与缩放后精灵一致的"证据像素"（非黑非红的彩色像素）。生成约束：目标区域的宽高恰好是精灵宽高的整数倍；帧线将区域精确对半分割；证据像素的位置和颜色与唯一正确的缩放放置方案一致。

**规则**：
1. 识别 4 个角标像素，确定目标矩形区域边界。
2. 计算目标区域尺寸与小精灵尺寸的比值，得到缩放倍率 k（水平和垂直相同）。
3. 将小精灵的每个像素放大为 k x k 块，在目标区域内找到与所有证据像素一致的唯一放置位置，将缩放后的精灵填入区域。
4. 识别区域内的红(2)帧线作为对称轴。帧线将区域分为两半。
5. 统计 4 个角标的颜色：橙(7)出现 3 次、栗(9)出现 1 次。保留栗(9)角标所在的那一半区域（帧线侧的半区），丢弃另一半。
6. 输出为保留的半区内容（含帧线像素），裁剪至紧凑边界框。

**关键洞察**：角标既编码了缩放对齐的空间约束，又通过颜色不对称性编码了镜像裁剪的方向选择——同一组标记承担双重语义角色，必须同时解读才能确定输出。

## 实现要求

1. `main(grid)` 必须实现新题描述中的确定性转换规则，不能只识别 `generate_input()` 的固定模板。禁止不同的input网格输出相同的output网格。
2. `generate_input()` 必须随机生成多样样例，不能固定死。随机维度应覆盖：网格大小、对象数量、位置、颜色、方向、形状参数或关键分支。注意若描述中存在若干，需实现而不是只有单个，包括object或者对应关系等等。且若涉及到最短路径，则输入网格中必涉及到多条路径，对选择造成干扰。
3. 生成器必须保证输入满足 `main()` 的隐式假设：对象不重叠、不越界、特殊标记唯一或可区分、匹配关系无歧义、关键分支出现概率相同。
4. 禁止把 ARC 颜色 id 、亮度、拼写等当作人类不可见的数值语义参与排序、大小比较或隐藏映射。颜色变化必须有可见结构线索。注意颜色亮度、拼写等也是不可见信息，若描述中出现违规的颜色id或者亮度，可自行使用少量的固定颜色替代，但注意生成时要在三个以内输入输出网格中对所有变换100%覆盖度。
5. 输出样例要视觉清晰，人类必须能从输入输出对中肉眼辨认出规律。具体要求：避免对象粘连、覆盖关系混乱、同一像素多重语义；不同逻辑步骤产生的结果不要大面积层叠在一起导致无法分辨哪个颜色属于哪个步骤；输入中各元素之间保持足够间距，输出中新增的标记/填充/路径等应与背景和已有元素在颜色上有明显区分；若规则涉及多层叠加，生成时控制对象密度和尺寸，确保叠加区域只占少数像素而非铺满整个网格。
