## 新题 7：连通面积门控聚集与多目标分配

**组合逻辑**：[聚集gather](创新：多目标竞争分配) + [擦除erase] + [重涂色recolor](按目标色着色) ← [可达性reachability](路径连通判定) + [面积比较area_comparison](作为资格门控) + [距离排序填充distance_ranked_fill](分配规则)

**来源原语**：聚集/gather(dd6b8c4b)、擦除/erase(dd6b8c4b)、墙壁障碍/wall_barrier(dd6b8c4b)、可达性/reachability(dd6b8c4b)、距离排序填充/distance_ranked_fill(dd6b8c4b)、重涂色/recolor(67385a82)、连通分量/connected_component(67385a82)、面积比较/area_comparison(67385a82)、孤立像素/isolated_pixel(67385a82)

**依赖链**：连通分量分析 → 面积计算 → 面积门控过滤候选 → 可达性判定候选与目标的连接 → 距离排序确定分配优先级 → 聚集到目标并涂色 → 原位擦除。面积门控和可达性是并行约束，必须同时满足才能参与分配。

散布的标记像素先按连通分量面积过滤（孤立单像素不参与），再按可达性分配到最近的目标块，聚集后涂为目标块中心色；被移走的像素原位擦除。

**输入结构**：约 14x14 黑(0)背景网格。含 2 个目标块：每个是一个 3x3 区域，中心为不同颜色（红(2)和蓝(1)），周围 8 格为黑(0)空位等待填入。网格中散布 15-20 个绿(3)前景像素，部分形成 2-4 像素的 4-连通簇，部分为孤立单像素。品红(6)墙壁像素形成若干短段障碍，将网格分为不完全连通的区域。生成约束：每个目标块周围恰好有 8 个空位；孤立绿像素至少 3 个（这些不参与聚集）；非孤立绿像素簇通过 flood-fill 各自恰好只能到达一个目标块；每个目标块可达的合格绿像素总数恰好为 8。

**规则**：
1. 识别所有绿(3)像素的 4-连通分量。面积为 1 的分量（孤立像素）标记为"非候选"，保持不变。面积 >= 2 的分量中所有像素标记为"候选"。
2. 对每个候选像素，做 4-连通 flood-fill（通过黑(0)背景和绿(3)像素，不穿越品红(6)墙壁），判定它能到达哪个目标块（红(2)中心或蓝(1)中心）。
3. 对每个目标块，将其可达的候选像素按曼哈顿距离从近到远排序。
4. 按距离顺序取前 8 个候选像素，将它们依次填入目标块的 3x3 区域空位（按从左上到右下的行优先顺序填入），填入时涂为该目标块的中心颜色。
5. 被移走的候选像素在原位置擦除为黑(0)。
6. 孤立绿像素、墙壁像素、目标中心像素保持不变。

**关键洞察**：面积判断和可达性判断构成双重门控——孤立像素虽然可能距离目标很近，但因面积不足被排除；大簇像素虽然面积达标，但若被墙壁隔绝则无法到达目标。两个条件缺一不可。
