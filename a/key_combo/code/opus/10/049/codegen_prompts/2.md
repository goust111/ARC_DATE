## 新题 2：双面板重力沉降后取并集

**组合逻辑**：[重力下落](已有) → [透明叠加 + 布尔并集](创新：叠加的不是原始掩码而是物理模拟后的沉降态)

**来源原语**：重力下落/gravity_drop（6ad5bdfd）、边墙/edge_wall（6ad5bdfd）、近墙优先结算/nearest_first_settling（6ad5bdfd）、碰撞停止/collision_stop（6ad5bdfd）、多米诺骨牌/domino（6ad5bdfd）、并列面板/side_by_side_panel（dae9d2b5）、透明叠加/transparent_overlay（dae9d2b5）、逐格对齐/cell_alignment（dae9d2b5）、布尔并集合并/boolean_union（dae9d2b5）、分隔列/divider_column（5d2a5c43）

**依赖链**：两个面板各自内部进行独立的重力沉降 → 沉降改变前景像素的空间分布 → 沉降后的掩码才是并集运算的输入；跳过沉降直接取并集会得到完全不同的结果

两个并列面板各含散布的多米诺骨牌和底部边墙；骨牌先在各自面板内下落堆叠，然后对两个沉降态取逐格布尔并集，输出单面板。

**输入结构**：约 12x25 的网格：两个 12x12 面板水平排列，中间由一列蓝(1)分隔列隔开。每个面板内：黑(0)背景，底行为一行完整的灰(5)边墙。面板中散布 4~6 个单色水平或垂直多米诺骨牌（每块恰好 2 像素），各骨牌颜色互不相同（可为红(2)、绿(3)、黄(4)、品红(6)、橙(7)等非黑非蓝非灰色）。左右面板的骨牌数量可不同、颜色可不同。生成约束：每个面板内骨牌互不相邻，骨牌不与边墙相邻。

**规则**：
1. 在每个面板内独立执行重力下落：所有骨牌向下（朝灰(5)边墙方向）滑动。离边墙最近的骨牌优先结算。骨牌刚性平移，逐行下移，碰到边墙、已结算骨牌或面板底边时停止。同距离的骨牌按边界框左上角列号从左到右依次结算。
2. 两个面板均沉降完成后，移除蓝(1)分隔列，将左右面板按行列逐格对齐。
3. 对齐后的每个格位：若左面板或右面板（或两者）在该位置有前景像素（非黑非灰），则输出品红(6)；否则输出黑(0)。灰(5)边墙行不出现在输出中——输出仅包含边墙上方的区域。
4. 输出为一个 11x12 的单面板（去掉底部边墙行）。

**关键洞察**：取并集的对象不是两个面板的原始布局，而是各自经过重力沉降后的状态。同样的骨牌在不同初始高度会沉降到不同位置，使得并集结果与原始掩码的并集截然不同。
