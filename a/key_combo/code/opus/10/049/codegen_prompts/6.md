## 新题 6：带噪声的平移对称图案遮挡恢复

**组合逻辑**：[计数 + 少数色替换](创新：频率分析用于识别噪声而非直接替换) → [补全 + 对称轨道](创新：补全对象同时包含噪声区和遮挡区，但识别机制不同) → [裁剪](已有)

**来源原语**：计数/counting（f8b3ba0a）、少数色替换/minority_replaced（9caf5b84）、补全/completion（f9012d9b）、平移对称图案/translational_pattern（f9012d9b）、对称轨道/symmetry_orbit（f9012d9b）、遮挡矩形/occluding_rect（f9012d9b）、对称恢复遮挡/symmetry_restores（f9012d9b）、裁剪/crop（f9012d9b）

**依赖链**：频率分析识别噪声色（少数色）→ 噪声色被排除后才能准确检测平移周期 → 平移对称既用于恢复噪声像素也用于恢复遮挡像素 → 最终裁剪输出遮挡区域。噪声和遮挡是两种不同的"缺损"，需要不同的检测手段（频率 vs. 空间连通性）但共享同一个恢复机制（对称轨道），形成诊断分叉-恢复汇合的结构

在一个具有平移对称性的彩色图案上，黑色矩形遮挡了一部分，同时部分未遮挡像素被随机替换为少数色噪声；先用频率识别噪声、再用平移对称恢复所有缺损，最后裁剪输出遮挡区。

**输入结构**：约 14x14 的网格，无真正背景色——整个网格本质上是一个平移对称的彩色瓦片图案（瓦片大小约 3x3 或 4x4），使用 3~4 种颜色（如红(2)、绿(3)、蓝(1)、黄(4)）。网格中有一个约 4x5 的矩形区域全部填充为黑(0)（遮挡矩形），位置不在网格边缘。在遮挡矩形之外，有 5~8 个像素被随机替换为橙(7)（噪声色）。橙(7)不出现在原始图案中。生成约束：瓦片至少在两个方向上各重复 3 次以上，确保每个被遮挡位置至少有一个非黑非橙的对称轨道伙伴可供恢复；噪声像素不聚集在一起（两两不 4-相邻）。

**规则**：
1. 统计所有非黑(0)像素的颜色频率。出现次数最少的颜色即为噪声色（在本题中为橙(7)）。将所有噪声色像素标记为"待恢复"，但暂不修改。
2. 仅使用非黑(0)、非噪声色的像素来检测平移对称周期：找到最小的水平周期 dx 和垂直周期 dy，使得对所有有效像素 (r, c)，有 color(r, c) == color(r+dy, c+dx)（忽略黑和噪声位置）。
3. 恢复噪声像素：对每个噪声色像素 (r, c)，找到其平移轨道中最近的非黑非噪声像素 (r+k*dy, c+k*dx)，将 (r, c) 的颜色设为该像素的颜色。若 k 为正负皆可，优先选 |k| 最小的。
4. 恢复遮挡像素：对遮挡矩形中每个黑(0)像素 (r, c)，用同样的平移轨道方法从已恢复的网格中找到非黑像素填充。
5. 输出仅为遮挡矩形区域的裁剪结果（恢复后的内容）。

**关键洞察**：噪声和遮挡都是"错误值"，但检测方式不同：噪声通过频率异常识别（全局统计），遮挡通过空间连通性识别（黑色矩形）。然而两者的恢复机制相同（平移对称轨道），且噪声必须先被识别并排除，否则会干扰对称周期的检测——构成不可跳步的诊断链。
