## 新题 4：最大分量定反射轴，其余分量被镜像

**组合逻辑**：[按面积筛选 + 保留最大分量](创新：最大分量不被操作，而是编码操作参数) → [镜像](创新：轴由最大分量的形状隐式决定)

**来源原语**：连通分量/connected_component（337b420f）、按面积筛选/size_filtered（337b420f）、保留最大分量/keep_largest（337b420f）、忽略干扰项/ignore_distractors（337b420f）、镜像/mirror（4e7e0eb9）、轴线决定变换/axis_determines_op（4e7e0eb9）

**依赖链**：识别最大分量 → 其边界框长宽比决定反射轴方向 → 其边界框中心线成为反射轴 → 所有非最大分量以此轴为参照镜像 → 最大分量本身不变且充当碰撞遮挡；面积比较、轴推断、镜像执行、冲突消解四步缺一不可

在多个散布的彩色连通分量中找到像素数最多的那个；它的边界框长宽比决定反射轴方向，边界框中心线即为轴；其余分量关于此轴镜像，与最大分量重叠的像素被丢弃。

**输入结构**：约 15x15 的网格，黑(0)背景。包含 4~6 个 4-连通的单色分量，每个分量颜色互不相同（可用红(2)、绿(3)、黄(4)、灰(5)、品红(6)、橙(7)等）。每个分量 3~10 像素，形状不规则（非矩形、非对称）。恰好一个分量的像素数严格大于其他所有分量。生成约束：最大分量大致位于网格中央区域；其余分量分布在最大分量周围；最大分量的边界框宽度与高度不相等（保证轴方向唯一）；镜像后至少有一个小分量与最大分量部分重叠。

**规则**：
1. 计算每个 4-连通分量的像素数。选出像素数最多的分量为"锚分量"。若存在平局，选边界框左上角行号更小者；仍平局则选列号更小者。
2. 计算锚分量的边界框。若边界框宽度 > 高度，反射轴为通过边界框中心行的水平线（上下镜像）；若高度 > 宽度，反射轴为通过边界框中心列的垂直线（左右镜像）。中心行 = (top + bottom) / 2（取下整），中心列 = (left + right) / 2（取下整）。
3. 锚分量保持不动，保留原色、原位。
4. 对每个非锚分量，将其所有像素关于反射轴做镜像。镜像后的像素若落在网格外则丢弃；若落在锚分量已有像素上则丢弃（锚分量优先）；若落在另一个已镜像分量的像素上，则后处理的分量覆盖先处理的（处理顺序：按原始分量边界框左上角行优先、列次优先排序）。
5. 非锚分量在原始位置的像素被擦除（置为黑(0)），仅保留其镜像位置的像素。

**关键洞察**：最大分量同时扮演三个角色——它的面积决定了它被选中为锚、它的几何形状编码了反射轴方向、它的物理占位充当了镜像结果的遮挡屏障。三个角色缺一不可。
