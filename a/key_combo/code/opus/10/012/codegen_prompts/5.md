## 新题 5：散布点扩展后按内嵌灰标记筛选

**组合逻辑**：[扩展(expand)](已有原语) + [裁剪(crop)](已有原语) + [计数(counting)](创新：计数对象是扩展后才被"捕获"的外部像素) + [散布点(sparse_dot)](已有原语) + [最少标记数→筛选条件](创新：标记的选择功能在扩展完成后才生效)

**来源原语**：扩展(expand) ← 305b1341；裁剪(crop) ← 23b5c85d/7bb29440；计数(counting) ← 42a15761/dce56571；散布点(sparse_dot) ← 305b1341；最少标记数(minimum_marker_count) ← 7bb29440；最小面积矩形保留(smallest_rect_retained) ← 23b5c85d

**依赖链**：散布点按颜色分组 → 扩展各组边界框并填充（必须先完成才能确定矩形范围）→ 计数每个扩展矩形内部的灰色像素（灰色像素在扩展前对分组无影响，扩展后才成为被"包围"的对象）→ 按灰色计数筛选并裁剪。灰色像素的双重角色是耦合的核心：它们不参与扩展，但扩展结果决定了哪些灰色像素"属于"哪个矩形。

将不同颜色的散布点各自扩展为填充矩形，然后选出内含灰色标记最少的矩形作为裁剪输出。

**输入结构**：约 15x15 的网格。黑(0)背景。3-4 种非灰非黑前景色（如红(2)、蓝(1)、绿(3)），每种颜色有 2-4 个散布点。另有若干灰(5)孤立像素散布于网格各处。不同颜色的散布点在空间上互不重叠（各颜色的边界框扩展 1 像素后仍不相交）。灰(5)像素可能落在某些颜色扩展后的矩形范围内，也可能落在所有矩形之外。不同示例中各颜色散布点的数量和位置不同，导致扩展矩形的大小和"捕获"的灰色像素数量不同。生成约束：恰好有一种颜色的扩展矩形内灰色像素数量严格最少（无平局）。

**规则**：
1. 对每种非灰前景色 C，找到所有颜色为 C 的散布点，计算其最小边界框，向四个方向各扩展 1 像素（不超出网格边界）。
2. 在扩展后的边界框内，将所有黑(0)背景像素填充为颜色 C。保留框内所有已有的非黑像素（包括灰(5)像素和其他颜色的点，但因生成约束，框内不会有其他颜色的散布点）。
3. 对每个扩展矩形，统计其内部灰(5)像素的个数。
4. 选择灰色像素个数最少的那个扩展矩形。
5. 输出为该矩形的裁剪结果：输出网格的尺寸等于该矩形的尺寸，包含其内部所有像素的原始颜色（填充色、原始散布点色、灰色像素均保留）。

**关键洞察**：灰色像素在扩展阶段完全是旁观者（不属于任何颜色组，不影响边界框计算），但在选择阶段变成了关键判据。求解者必须先理解扩展规则（复用自 305b1341），然后才能理解灰色像素的选择功能（类似 7bb29440 的标记筛选，但筛选对象是扩展后才存在的矩形）。两步操作不可独立求解。
