## 新题 8：垂直线对隐式定义矩形的面积优先填充

**组合逻辑**：[填充(fill)](创新：填充目标不是显式给定的矩形，而是从线段交叉隐式推断的矩形) + [连线(line_drawing)](创新：线段不是输出，而是输入中编码矩形参数的结构) + [同色配对(same_color_pairing)](创新：配对对象不是点而是线段) + [冲突优先级(conflict_priority)](创新：优先级基于推断出的面积而非给定顺序)

**来源原语**：填充(fill) ← 305b1341/ff72ca3e；连线→线段结构 ← 29700607；同色配对(same_color_pairing) ← 29700607/1f876c06；交叉点(crossing_point) ← 67a423a3；冲突优先级(conflict_priority) ← 305b1341；实心矩形(solid_rectangle) ← 23b5c85d/538b439f

**依赖链**：同色线段配对（一横一竖）→ 交叉点确定矩形角点 → 线段长度隐式定义矩形宽高 → 填充推断出的矩形 → 面积决定重叠优先级。整条链中矩形从未显式出现，是从线段几何推断的产物。删去配对→不知道哪两条线段属于同一矩形；删去交叉→不知道矩形定位；删去面积优先→重叠区域无法确定颜色。

每种颜色有一条水平线段和一条垂直线段，两者交叉点是隐式矩形的一个角，线段长度定义矩形的宽高，重叠时面积小的矩形优先。

**输入结构**：约 14x14 的网格。黑(0)背景。3-4 种前景色（如红(2)、蓝(1)、绿(3)、黄(4)），每种颜色恰好有一条水平线段（宽度 1 像素、长度 3-6 像素）和一条垂直线段（宽度 1 像素、长度 3-6 像素）。同色的水平和垂直线段恰好交于一个像素（交叉点）。不同颜色的线段可能在空间上交叉，但同色线段对之间的交叉点唯一。不同示例中线段位置不同，导致推断出的矩形大小和重叠关系不同。生成约束：每种颜色的两条线段共享恰好一个像素（交叉点）。

**规则**：
1. 对每种前景色 C，识别其水平线段和垂直线段。两段交于一点，该点为矩形的一个角。
2. 水平线段从交叉点向某方向延伸——矩形沿水平方向从交叉点向线段延伸的反方向扩展，宽度等于水平线段长度。垂直线段同理——矩形沿垂直方向从交叉点向线段延伸的反方向扩展，高度等于垂直线段长度。
   - 具体地：若水平线段从交叉点向右延伸，则矩形从交叉点向左展开，宽度=水平线段长度；若向左延伸，则矩形向右展开。垂直类似：若向下延伸，矩形向上展开；若向上延伸，矩形向下展开。
3. 用颜色 C 填充该矩形区域的所有像素（包括背景像素和其他颜色的填充像素）。
4. 所有颜色的矩形同时计算（不存在处理顺序），但重叠区域的颜色由面积决定：面积较小的矩形优先（其颜色显示在重叠区域）。若面积相同，交叉点行号较小者优先；行号也相同则列号较小者优先。
5. 所有原始线段像素保持不变（始终显示在最前层，不被填充覆盖）。

**关键洞察**：矩形在输入中不存在——它们必须从两条垂直线段的交叉几何关系中推断出来。线段不仅提供尺寸信息（长度=矩形边长），还提供方向信息（线段延伸方向的反向=矩形展开方向）。这种"线段即矩形的边、交叉点即矩形的角"的隐式编码关系在参考题中不存在，是对线段和交叉点原语的全新结构组合。
