## 新题 3：锚点距离定描边尺寸

**组合逻辑**：[描边(outline)](创新：描边尺寸不再固定，由外部距离计算决定) + [切比雪夫距离(chebyshev_dist)](创新：距离不再决定填充方块大小，而决定空心描边半径) + [标记色决定描边色(marker_color_determines_outline)](已有原语) + [冲突优先级(conflict_priority)](创新：优先级由距离值决定而非图例顺序)

**来源原语**：描边(outline) ← 913fb3ed；切比雪夫距离(chebyshev_dist) ← ff72ca3e；标记色决定描边色(marker_color_determines_outline) ← 913fb3ed；孤立像素(isolated_pixel) ← 913fb3ed；阻挡像素→锚点像素 ← ff72ca3e；冲突优先级(conflict_priority) ← 305b1341

**依赖链**：锚点距离计算 → 确定描边半径（不可跳过：无距离则不知道画多大）；标记颜色 → 确定描边颜色（不可跳过：无颜色映射则不知道用什么色）；距离值 → 确定重叠优先级（不可跳过：多描边重叠时无法决定谁覆盖谁）。三条规则平行生效，共同约束每个像素的最终颜色。

每个彩色标记像素根据到最近灰色锚点的切比雪夫距离画出相应大小的空心方框，颜色由标记色映射决定，重叠时近锚点者优先。

**输入结构**：约 15x15 的网格。黑(0)背景。3-5 个孤立的彩色标记像素，颜色取自 {绿(3), 青(8), 红(2)}。3-5 个灰(5)锚点像素散布于网格中。标记像素与锚点像素互不相邻（曼哈顿距离至少 2）。不同示例中标记和锚点的位置不同，但颜色→描边色的映射关系固定。生成约束：每个标记的切比雪夫距离 D 满足 2 <= D <= 5；所有描边框（边长 2D-1）不超出网格边界；描边框不覆盖任何锚点或标记像素。

**规则**：
1. 对每个彩色标记像素，计算其到最近灰(5)锚点的切比雪夫距离 D。
2. 以标记像素为中心，绘制边长为 (2D-1) 的空心正方形描边框（即描边位于距中心 D-1 的切比雪夫环上）。
3. 描边颜色由标记颜色决定：绿(3) → 品红(6)，青(8) → 黄(4)，红(2) → 蓝(1)。
4. 若两个描边框在某像素重叠，D 值较小的标记的描边优先显示；若 D 值相同，边界框左上角按阅读序（先上后左）靠前者优先。
5. 原始标记像素和灰色锚点像素始终保留，不被描边覆盖。描边仅覆盖黑色背景像素。

**关键洞察**：参考题 913fb3ed 的描边总是固定 3x3，参考题 ff72ca3e 的距离决定实心方块大小。本题将两者融合——距离决定空心描边的尺寸，创造出"距离→几何尺寸"和"颜色→外观"两条独立推理轴，求解者必须同时归纳两个维度的规则。

Input structure

- The output has the same shape as the input and preserves the yellow and grey pixels.

Rule
- For each yellow marker, find the minimum Chebyshev distance to any grey blocker.

  largest centered square that remains one cell short of every grey blocker.
