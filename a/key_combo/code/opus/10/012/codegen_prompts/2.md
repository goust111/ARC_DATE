## 新题 2：图例编码连接拓扑

**组合逻辑**：[图例(legend)](创新：图例行不映射颜色而编码空间拓扑类型) + [连线(line_drawing)](创新：同一操作有三种几何模式，由外部编码选择) + [同色配对(same_color_pairing)](已有原语) + [对角线段连接(diagonal_segment_connect)](已有原语)

**来源原语**：图例(legend) ← 305b1341；连线(line_drawing) ← 29700607；同色配对(same_color_pairing) ← 29700607/1f876c06；对角线段连接(diagonal_segment_connect) ← 1f876c06；端点对(endpoint_pair) ← 1f876c06

**依赖链**：图例的行序位编码连接拓扑类型（直线/对角线/L形），每种颜色的两个端点依据其在图例中的行序位选择相应的连接策略。删去图例→不知道哪种颜色用哪种连线方式；删去同色配对→不知道端点对；删去连线→无输出。图例与连线之间的关系是"编码→解码"，不是"先做A再做B"。

图例的行位置编码每种颜色端点对的连接几何类型——直线、对角线或 L 形路径。

**输入结构**：约 14x14 的网格。黑(0)背景。列 0 的前 3 行构成单列图例，每行一个不同颜色的像素（如行 0: 红(2)，行 1: 蓝(1)，行 2: 绿(3)）。网格其余区域（列 1 以右），每种图例颜色恰好出现 2 次，形成端点对。不同示例中，图例中的颜色排列顺序不同（例如一个示例中红在行 0、蓝在行 1，另一个示例中蓝在行 0、红在行 1），但同一示例中图例行顺序与连接类型的对应关系固定。生成约束：行 0 颜色的端点对共享同一行或同一列（保证直线连接可行）；行 1 颜色的端点对的行差绝对值等于列差绝对值（保证 45 度对角线可行）；行 2 颜色的端点对不在同行同列且行差不等于列差（保证只能用 L 形连接）；所有连线路径互不相交。

**规则**：
1. 读取图例：行 0 的颜色记为 C0，行 1 记为 C1，行 2 记为 C2。
2. 清除图例列（列 0 的前 3 行设为黑(0)）。
3. C0 的端点对：用该颜色绘制一条水平或垂直直线段连接两点（包含两端点及之间所有像素）。
4. C1 的端点对：用该颜色绘制一条 45 度对角线段连接两点（包含两端点及之间所有像素）。
5. C2 的端点对：用该颜色绘制一条 L 形路径连接两点——先从一个端点沿水平方向行进到另一个端点所在列，再沿垂直方向行进到另一个端点。若存在两条等长 L 形路径（先水平后垂直 vs. 先垂直后水平），选择先水平后垂直的路径。
6. 所有原始端点像素保持不变。

**关键洞察**：图例在参考题 305b1341 中编码颜色映射关系，但在本题中编码的是空间拓扑类型——这是对"图例"概念的本质性重构。仅看单个示例可能误以为每种颜色总是用某一固定的连接方式，必须对比多个示例（图例行顺序不同，连接方式随之变化）才能发现行位置才是决定因素。
