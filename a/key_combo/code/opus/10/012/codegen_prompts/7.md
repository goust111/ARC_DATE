## 新题 7：角侧多样性竞争决定填充与描边

**组合逻辑**：[计数(counting)](创新：计数对象是颜色种类数而非像素个数) + [填充(fill)](创新：填充目标和填充色都由比较结果动态决定) + [描边(outline)](创新：描边是否执行以及描边色由同一个比较结果的另一分支决定) + [角与边中分组(corner_side_group)](创新：分组不用于循环移色，而用于两组间的"竞争")

**来源原语**：计数(counting) ← 42a15761；填充(fill) ← ff72ca3e/305b1341；描边(outline) ← 913fb3ed；角与边中分组(corner_side_group) ← 46c35fc7；环形前景(ring_object) ← 46c35fc7；角位像素(corner_pixel) ← 46c35fc7；边中像素(side_center_pixel) ← 46c35fc7；空心矩形(hollow_square) ← 913fb3ed

**依赖链**：角位/边中分组 → 分别统计各组颜色多样性 Cc 和 Cs → 比较 Cc 与 Cs（分支节点，不可跳过）→ 比较结果决定：(a) 哪组提供中心填充色，(b) 哪组提供描边色，(c) 是否绘制描边。三条输出规则都依赖同一个比较结果，且"胜者填中心、败者画外框"的角色分配是非显然的。

在每个 3x3 环形对象中，比较角位像素与边中像素的颜色多样性，多样性更高的一组提供中心填充色，另一组提供 5x5 描边色；若相等则特殊处理。

**输入结构**：约 15x15 的网格。黑(0)背景。3-4 个 3x3 环形前景对象，彼此间距至少 3 像素（保证 5x5 描边不重叠）。每个环由 8 个前景像素围绕 1 个黑色中心构成。每个环的 4 个角位像素和 4 个边中像素可使用不同颜色，颜色取自 {红(2), 蓝(1), 绿(3), 黄(4), 品红(6), 橙(7)}。不同环的颜色分布不同——有的角位多样性高于边中，有的反之，有的相等。不同示例中同一位置的环的具体颜色不同。

**规则**：
1. 对每个 3x3 环形对象，将其 8 个像素分为角位组（4 个：左上、右上、左下、右下）和边中组（4 个：上中、右中、下中、左中）。
2. 统计角位组中不同颜色的种类数 Cc，统计边中组中不同颜色的种类数 Cs。
3. 若 Cc > Cs：
   - 用角位组中出现次数最多的颜色填充环的中心像素。若角位组内多色并列最多，选在角位组中按阅读序（左上→右上→左下→右下）最先出现的颜色。
   - 以边中组中出现次数最多的颜色（同样的并列规则，阅读序为上中→右中→下中→左中）绘制以环中心为中心的 5x5 空心正方形描边。描边仅覆盖黑色背景像素。
4. 若 Cc < Cs：
   - 用边中组的众数颜色填充中心。
   - 用角位组的众数颜色绘制 5x5 描边。
5. 若 Cc == Cs：
   - 用灰(5)填充中心。不绘制描边。
6. 原始环形像素保持不变。

**关键洞察**：参考题 46c35fc7 中角位和边中分组用于两组独立的循环移色。本题中这两组变成了竞争关系——多样性高者"赢得"中心填充权，低者"输"到外围描边。相等则两败（灰色中心、无描边）。这种竞争产生的角色互换（哪组填中心 vs. 哪组画描边）是跨示例才能归纳的隐蔽规则。
