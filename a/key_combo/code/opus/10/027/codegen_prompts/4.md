## 新题 4：周期行图案在十字遮罩下的联合推断与修复

**组合逻辑**：[周期平移推断](从未损伤行归纳垂直周期和水平偏移) <-> [补全](用推断的周期规律填充被遮罩破坏的像素) — 同时约束满足结构

**来源原语**：
- 周期平移(periodic_translation): 参考题 53b68214
- 行图案(row_pattern): 参考题 53b68214
- 周期偏移延续行(period_shift_rows): 参考题 53b68214
- 补全(complete): 参考题 b7955b3c、e7639916
- 十字遮罩(cross_mask): 参考题 b7955b3c
- 从平行行列推断(infer_from_parallel): 参考题 b7955b3c

**依赖链**：网格行图案遵循周期性水平偏移规律，但部分像素被灰(8)十字遮罩破坏。修复遮罩需要已知的周期参数，推断周期需要忽略受损行。两步互相依赖形成同时约束：必须在"跳过损伤区"和"利用周期关系"之间交替推理，先从完好行对中归纳参数，再用参数重建损伤像素。

网格行遵循周期性水平偏移规律但被十字形遮罩局部破坏，需从未损伤行推断周期参数并修复所有损伤像素。

**输入结构**：
- 网格约 12x12，背景为黑(0)。
- 前景使用红(2)，每行有若干红像素形成一维图案。行图案遵循周期规律：存在垂直周期 P（2 或 3）和水平偏移 S（1 或 2），第 r 行的图案等于第 (r - P) 行的图案整体右移 S 个像素（偏移后超出右边界的像素消失，不回绕）。
- 网格中有 1~2 个灰(8)十字遮罩（每个为 3x3 十字形：中心像素加上下左右各一像素共 5 像素），遮罩覆盖的像素被替换为灰(8)，遮盖了原始的黑(0)或红(2)值。
- 生成约束：至少存在两对完全未被遮罩影响的连续行（行号差为 P 的行对），使得周期 P 和偏移 S 可从中唯一确定；偏移后的图案在所有行中均不触及网格右边界（即最右侧红像素距右边界至少 S 列），避免回绕歧义。

**规则**：
1. 识别所有灰(8)像素为损伤位置，标记为"未知"。
2. 从完全不含灰(8)的行中，寻找使所有未损伤行对满足"第 r 行 = 第 (r - P) 行整体右移 S 像素"的唯一 (P, S) 参数对。
3. 对每个灰(8)像素 (r, c)：沿周期方向查找参考行 r' = r - P（若 r - P < 0 则用 r + P），读取位置 (r', c - S) 处的像素值（若 c - S < 0 则填黑(0)），将该值写入 (r, c)。
4. 若参考行 r' 的对应位置本身也是灰(8)（即参考位置也被遮罩），则递归查找 r - 2P 或 r + 2P，直到找到未损伤的参考像素（生成约束保证递归必然终止）。

**关键洞察**：源题 b7955b3c 的遮罩修复靠行列内容重复直接复制，源题 53b68214 的周期延续不涉及任何损伤。本题将两者交织为同时约束——遮罩破坏了周期的直接观察，求解者必须先在完好行对中归纳周期参数，再用该参数跨行重建损伤内容，形成"推断规则"与"应用规则"相互依赖的非线性推理结构。
