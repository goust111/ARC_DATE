## 新题 3：重力聚集后计数构建角落三角

**组合逻辑**：[重力下落](对象下落至障碍物上方) → [计数](统计着陆对象总数) → [众数颜色](确定填充色) → [填充三角区域](在标记角落绘制三角) + [擦除](清除对象与障碍物)

**来源原语**：
- 重力下落(gravity_drop): 参考题 825aa9e9
- 可动对象(movable_object): 参考题 825aa9e9
- 障碍物(obstacle): 参考题 825aa9e9
- 邻接阻挡(adjacency_blocking): 参考题 825aa9e9
- 计数(counting): 参考题 8f215267、ff2825db
- 计数决定尺寸(count_determines_size): 参考题 902510d5
- 众数颜色决定输出(majority_color_out): 参考题 ff2825db
- 角落控制点(corner_control): 参考题 902510d5
- 三角区域(triangle_region): 参考题 902510d5
- 填充(fill): 参考题 902510d5
- 擦除(erase): 参考题 8f215267、902510d5 等

**依赖链**：重力下落决定对象最终位置和着陆状态。只有成功着陆的对象参与计数，计数结果决定三角形边长。着陆对象中出现次数最多的颜色决定三角形填充色。角落控制点决定三角形朝向。重力作为计数的前置空间筛选器，计数同时喂入几何尺寸和颜色选择两条分支，形成不可跳步的多环依赖。

彩色对象在重力作用下着陆后被计数，计数值成为从标记角落绘制的实心三角形的边长，三角颜色取自着陆对象中的众数颜色。

**输入结构**：
- 网格约 14x14，背景为黑(0)。
- 网格底部 1~2 行有灰(5)障碍物像素，形成不规则地板（非完整行，有若干间断）。
- 网格上半区散布 3~6 个可动小对象，每个为 4-连通单色图形（2~4 像素），颜色从红(2)、蓝(1)、绿(3)中选取。至少使用两种颜色，其中一种颜色的对象数量严格多于其他任何颜色。
- 恰好一个角落像素为黄(4)，标记三角形的起始角（四个角落中的某一个），其余三个角落为黑(0)。
- 生成约束：每个可动对象正下方的垂直路径上至少存在一个障碍物像素，使所有对象在重力下落后均可着陆而不会落出网格底部；各对象下落后不会互相重叠。

**规则**：
1. 对每个可动对象，整体向下平移，每次一行，直到该对象的任一像素正下方一行处为障碍物像素或已着陆对象像素时停止。处理顺序：按对象底部像素的行号从大到小（最低的先落）。
2. 统计成功着陆的可动对象总数 N。
3. 确定着陆对象中出现频率最高的颜色 C（按对象个数计，非像素数；生成约束保证无平局）。
4. 擦除网格中所有可动对象像素和所有灰(5)障碍物像素（恢复为黑(0)）。
5. 以黄(4)控制点所在角落为顶点，绘制边长为 N 的实心直角三角形：两条直角边分别沿该角落的水平和垂直边界方向延伸，填充所有满足"到该角落的行距 + 列距 < N"的像素，颜色为 C。
6. 黄(4)控制点本身被颜色 C 覆盖。

**关键洞察**：重力下落不只是视觉变换，更是计数的前置筛选器——对象的起始位置和障碍物形态共同决定着陆后的堆叠布局，而着陆后的对象数量和颜色分布同时决定三角形的两个独立参数（边长与颜色），必须通过多示例对比才能区分"边长由数量决定"还是"由像素总数决定"。
