## 新题 10：分隔线格子中逐块形状匹配决定填充色

**组合逻辑**：[格子格局](保留) + [形状匹配](创新：不是在全局中找同形对象，而是在格子内逐块匹配模板字典) + [重涂色](创新：填充色由匹配到的模板颜色决定) + [分隔行列](保留)

**来源原语**：格子格局/lattice_layout(af24b4cc)、分隔行列/separator_row_col(af24b4cc)、形状匹配/shape_match(63613498)、掩码相同/mask_equality(63613498)、重涂色/recolor(a85d4709)、标记列决定整行色/marker_column_determines_row_color(a85d4709)

**依赖链**：分隔线将网格分为主体格子区和底部字典行→字典行中每个色块提供一种"形状→颜色"的映射→主体格子中每个块的灰色图形匹配字典中某个形状→匹配到的字典条目的颜色成为该块的填充色（无字典→不知道颜色映射；形状匹配错→填充色错）

网格由分隔线分为上方的主格子和下方的字典条。主格子每块内有一个灰色小图形，字典条中的彩色图形定义了"形状→颜色"映射。根据形状匹配将主格子中的灰色图形重涂为对应颜色。

**输入结构**：约 17x17 的黑(0)背景网格。橙(7)分隔线（宽 1 像素）将网格分为两部分：上方是一个 3x3 的主格子（每块约 4x4 像素），下方是一个 1x3 的字典行（每块约 4x4 像素，与主格子块同尺寸）。主格子的 9 个块中各有一个灰(5)的小型 4-连通图形（2~5 像素，形状不规则），其余像素为黑(0)。字典行的 3 个块中各有一个彩色 4-连通图形（颜色分别为蓝(1)、红(2)、绿(3)，每块一种颜色），形状各不相同。生成约束：主格子中每个灰色图形的归一化掩码恰好匹配字典中某一个彩色图形的归一化掩码（允许平移但不允许旋转或翻转）；字典中 3 种形状两两不同；主格子的 9 块中 3 种形状各出现 3 次。

**规则**：
1. 通过橙(7)分隔线识别主格子（3x3 块）和字典行（1x3 块）。
2. 提取字典行中每个块内的彩色图形，计算其归一化掩码（平移到原点后的像素相对坐标集合）和颜色，建立 3 个"掩码→颜色"的映射条目。
3. 对主格子中每个块，提取灰(5)图形的归一化掩码。
4. 在字典中查找掩码完全相同的条目，获得对应颜色。
5. 将该块中的灰(5)像素全部重涂为匹配到的字典颜色。
6. 分隔线、黑色背景和字典行保持不变。

**关键洞察**：颜色不是由图形的位置、大小或拓扑属性直接决定的，而是由一个显式的"形状字典"间接编码——必须先在字典中完成形状匹配，才能确定填充颜色。需要对比多个示例才能确认匹配规则是精确掩码相等而非近似相似。

## 实现要求

1. `main(grid)` 必须实现新题描述中的确定性转换规则，不能只识别 `generate_input()` 的固定模板。禁止不同的input网格输出相同的output网格。
2. `generate_input()` 必须随机生成多样样例，不能固定死。随机维度应覆盖：网格大小、对象数量、位置、颜色、方向、形状参数或关键分支。注意若描述中存在若干，需实现而不是只有单个，包括object或者对应关系等等。且若涉及到最短路径，则输入网格中必涉及到多条路径，对选择造成干扰。
3. 生成器必须保证输入满足 `main()` 的隐式假设：对象不重叠、不越界、特殊标记唯一或可区分、匹配关系无歧义、关键分支出现概率相同。
4. 禁止把 ARC 颜色 id 、亮度、拼写等当作人类不可见的数值语义参与排序、大小比较或隐藏映射。颜色变化必须有可见结构线索。注意颜色亮度、拼写等也是不可见信息，若描述中出现违规的颜色id或者亮度，可自行使用少量的固定颜色替代，但注意生成时要在三个以内输入输出网格中对所有变换100%覆盖度。
5. 输出样例要视觉清晰，人类必须能从输入输出对中肉眼辨认出规律。具体要求：避免对象粘连、覆盖关系混乱、同一像素多重语义；不同逻辑步骤产生的结果不要大面积层叠在一起导致无法分辨哪个颜色属于哪个步骤；输入中各元素之间保持足够间距，输出中新增的标记/填充/路径等应与背景和已有元素在颜色上有明显区分；若规则涉及多层叠加，生成时控制对象密度和尺寸，确保叠加区域只占少数像素而非铺满整个网格。
6. 若规则有多个分支，生成器不能长期固定成一个分支；应让分支在随机样例中合理出现。分支概率不必平均——难以发现的隐蔽分支（如少数情况下才触发的特殊规则）应适当提高出现概率，确保在 3 个训练示例中至少出现一次，否则求解者无法归纳该规则。对于颜色映射类规则，确保 2 个左右的示例即可覆盖所有映射关系（每种颜色→颜色的映射至少在某个示例中出现过）。
