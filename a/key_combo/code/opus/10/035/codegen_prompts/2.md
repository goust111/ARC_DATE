## 新题 2：异常象限位置编码错切方向

**组合逻辑**：[异常值选择/outlier_selection + 相等比较/equality_comparison](已有，用于识别唯一象限) → [象限位置→错切方向映射](创新：异常象限的空间位置编码变换参数) → [错切/shear](已有，但方向由异常检测结果动态决定)

**来源原语**：异常值选择/outlier_selection + 相等比较/equality_comparison + 象限/quadrant + 分隔十字/separator_cross（参考题 88a62173）；错切/shear + 行偏移递变/row_offset_progress（参考题 3cd86f4f）

**依赖链**：四个象限的逐对比较确定唯一象限的位置（左上/右上/左下/右下），该位置映射为错切方向（上→下切 / 下→上切 / 左→右切 / 右→左切），错切操作应用于三个共享图案的合并结果。异常检测的输出不仅决定"选什么"还决定"怎么变换"，形成条件→操作参数的跨步依赖。

识别四象限中的唯一图案，根据其所在象限位置确定错切方向，对共享图案执行相应方向的错切后输出。

**输入结构**：约 15x15 的网格（奇数行列），中间行和中间列为灰(5)色分隔十字，将网格分为四个大小相同的矩形象限（每个约 7x7）。三个象限包含相同的多色前景图案（由蓝(1)和橙(7)像素组成的 4-连通不规则小图形，约 6~10 像素，背景为黑(0)），第四个象限包含一个不同的同色系图案。不同示例中，唯一象限的位置不同，图案形状也不同。生成约束：三个共享象限的图案完全一致（含颜色和位置）；唯一象限的图案与共享图案至少有 2 个像素位置不同。

**规则**：
1. 比较四个象限的图案（以象限内相对坐标为准），找出仅出现一次的唯一图案及其所在象限位置。
2. 取共享图案（三个相同象限中任一个）作为错切操作的输入。
3. 根据唯一象限的位置确定错切方向：
   - 左上象限唯一 → 向左下错切（每行向左偏移量随行号递增，偏移量 = 行号 r，r 从 0 开始）
   - 右上象限唯一 → 向右下错切（每行向右偏移量 = r）
   - 左下象限唯一 → 向左上错切（每行向左偏移量 = 最大行号 - r）
   - 右下象限唯一 → 向右上错切（每行向右偏移量 = 最大行号 - r）
4. 在黑(0)画布上输出错切后的共享图案。画布宽度 = 原象限宽度 W + 原象限高度 H - 1，高度 = H。超出画布边界的部分舍弃。

**关键洞察**：唯一象限本身不出现在输出中——它的唯一价值是通过其空间位置编码错切方向，而被错切的反而是那个"普通"的共享图案。
