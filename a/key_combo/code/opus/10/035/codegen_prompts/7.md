## 新题 7：模板匹配定位锚点后从锚点发射对角射线

**组合逻辑**：[模板匹配/template_matching + 形状匹配/shape_matching + 含旋转反射变换/includes_rotation_reflection](已有) → [匹配位置→射线发射原点](创新：匹配结果的空间坐标作为后续操作的起点参数) → [射线延伸/ray_extend + 邻接触发对角溅射/adjacency_triggers_diagonal_splash](已有，但射线发射条件从"邻接触发条"变为"模板匹配成功") → [重涂色/recolor](已有)

**来源原语**：模板匹配/template_matching + 模板图案/template_motif + 形状匹配/shape_matching + 含旋转反射变换/includes_rotation_reflection + 忽略干扰项/ignore_distractors（参考题 50f325b5）；射线延伸/ray_extend + 邻接触发对角溅射/adjacency_triggers_diagonal_splash（参考题 73c3b0d8）；重涂色/recolor（参考题 50f325b5, e4941b18）

**依赖链**：模板匹配在绿色像素场中定位所有与青色模板形状一致的副本（含旋转反射），提取每个匹配副本的中心坐标。这些中心坐标成为对角射线的发射原点。射线从每个锚点同时向四个对角方向延伸，直到遇到非背景像素或网格边界停止。模板匹配的空间结果直接参数化射线的几何分布——匹配到的副本越多、位置越分散，射线网络就越复杂。

在含有模板及其隐藏副本的网格中，找出所有匹配位置，从每个匹配中心发射四条对角射线，输出射线交织后的网络图案。

**输入结构**：约 20x20 的黑(0)背景网格。左上角有一个青(8)色的小型模板图案（4-连通，3~5 像素，占据一个约 3x3 的边界框）。网格其余区域散布着绿(3)像素，其中包含 2~4 个模板的精确副本（可能经过 90/180/270 度旋转或水平/垂直翻转），嵌入在绿色干扰像素之间。不同示例中，模板形状、副本数量、副本位置和旋转/翻转方式不同。生成约束：各模板副本的边界框互不重叠；每个副本的中心像素（边界框中心取 floor）向四个对角方向延伸的射线路径在到达网格边界前不经过其他副本的边界框（保证射线不被其他副本截断，使射线长度仅由网格边界决定）。

**规则**：
1. 提取青(8)模板图案的边界框归一化掩码，枚举其全部 8 种旋转/翻转变体（去重后保留不同的）。
2. 以行优先顺序扫描网格，在绿(3)像素中查找与任一变体完全匹配的放置位置（放置区域内所有模板像素位置均为绿(3)）。匹配到的位置标记为已选，后续匹配跳过与已选位置重叠的放置。
3. 将每个匹配副本的像素重涂为青(8)。
4. 对每个匹配副本，计算其边界框中心 (cr, cc)（cr = floor((top+bottom)/2), cc = floor((left+right)/2)）。从 (cr, cc) 向四个对角方向 ((-1,-1), (-1,+1), (+1,-1), (+1,+1)) 逐步延伸，在每个经过的背景黑(0)像素处涂为青(8)，遇到非黑像素或网格边界时停止（不涂终点，若终点非黑）。
5. 不匹配的绿(3)干扰像素保持不变。

**关键洞察**：模板匹配不是为了给副本重新上色（那只是副效果），而是为了精确定位射线的发射原点。射线的交织图案完全取决于匹配位置的空间分布，这一分布在输入中被绿色干扰像素所遮蔽，必须通过形状匹配才能提取。
