## 新题 6：多次镜像恢复后去重选出唯一隐藏图案

**组合逻辑**：[镜像/mirror + 反射恢复遮挡/reflection_recovers](已有，但从恢复单个遮挡扩展为恢复多个) → [相等比较/equality_comparison](已有) → [去重筛选/uniqueness_filter + 图案仅出现一次/pattern_once](已有，但操作对象从可见精灵体变为刚被恢复的不可见图案) → [裁剪/crop](已有)

**来源原语**：镜像/mirror + 镜像对称/mirror_symmetry + 遮挡块/occluder + 被遮区域/occluded_region + 反射恢复遮挡/reflection_recovers（参考题 dc0a314f）；去重筛选/uniqueness_filter + 图案仅出现一次/pattern_once + 带框精灵体/framed_sprite（参考题 aee291af）；相等比较/equality_comparison（参考题 88a62173）

**依赖链**：镜像恢复为每个遮挡块重建隐藏内容，产生多个恢复补丁作为比较候选。相等比较在这些恢复补丁之间执行。去重筛选从中选出唯一的那个。关键耦合：比较的对象在输入中完全不可见——它们必须先被重建才能参与比较。若跳过镜像恢复，无候选可比；若跳过比较，无法区分哪个恢复结果独特。

在具有左右对称性的场景中恢复多个遮挡块下方的隐藏图案，比较后输出其中唯一不重复的那个。

**输入结构**：约 17x17 的网格，整体具有左右镜像对称性（对称轴为垂直中线）。背景为黑(0)，前景由红(2)和黄(4)像素组成的复杂对称图案。网格左半部有 3 个大小相同的实心栗(9)正方形遮挡块（每个约 3x3），分布在不同位置且互不重叠。这 3 个遮挡块的右半部对称位置均无遮挡（完全可见）。栗(9)颜色仅出现在遮挡块中。在对称图案的设计中，3 个遮挡块下方的隐藏内容中有 2 个相同、1 个不同。不同示例中，遮挡块的位置、隐藏内容、整体对称图案均不同。生成约束：3 个遮挡块均在对称轴左侧且与对称轴不相邻（保证右侧对称位置完整可见）；遮挡块之间不相邻、不重叠。

**规则**：
1. 识别所有栗(9)色实心正方形，记录每个的边界框位置。
2. 对每个遮挡块，计算其关于垂直中线的镜像位置。从镜像位置提取同大小的图案补丁，再将该补丁水平翻转，得到遮挡块下方的恢复内容。
3. 比较所有恢复补丁（像素级比较）。恰好一个补丁的内容与其他补丁不同。
4. 输出该唯一补丁。

**关键洞察**：所有待比较的对象在输入中都是不可见的——被遮挡块完全覆盖。求解者必须先利用全局对称性进行重建，才能获得比较的候选集，然后从重建结果中做异常值选择。这与直接在可见对象中选异常值有本质区别。
