## 新题 3：种子平铺生成参考基准以提取篡改区域

**组合逻辑**：[裁剪/crop + 角落即种子/corner_is_seed](已有) → [平铺/tiling](已有，但目的从"输出放大图"变为"构建比较基准") → [差异提取/difference_extraction + 对齐比较/aligned_comparison](已有，但比较对象从"两个分离物体"变为"自生成参考 vs 实际网格") → [裁剪/crop](已有，输出裁剪到差异区域)

**来源原语**：裁剪/crop + 角落即种子/corner_is_seed + 种子瓦片/seed_tile（参考题 d10ecb37）；平铺/tiling + 阵列排布/array_layout + 边长决定重复数/side_len_determines_rep（参考题 ccd554ac）；差异提取/difference_extraction + 对齐比较/aligned_comparison + 缺损副本/damaged_copy + 缺失掩码/missing_cell_mask（参考题 2037f2c7）

**依赖链**：种子提取确定瓦片内容，平铺将种子扩展为与输入同尺寸的"应有图案"，差异提取将实际输入与该参考逐像素比较以定位篡改区域，最终裁剪输出仅含篡改区域的正确颜色。四步之间环环相扣：无种子则无参考，无参考则无法比较，无比较则无法定位篡改。

从一个大部分正确的平铺网格中提取左上角种子，重新平铺为参考基准，比较后输出被篡改区域应有的正确内容。

**输入结构**：一个矩形网格（约 12x12），由一个小种子瓦片（约 3x3 或 4x4）在行列方向重复平铺而成。种子位于左上角，包含 2~3 种非黑颜色（如红(2)、蓝(1)、绿(3)）。网格中有一个连续的矩形子区域（约 3x4 或 4x3，不与左上角种子区域重叠）被篡改——该区域内的所有像素被替换为品红(6)。网格的行数和列数分别是种子高度和宽度的整数倍。不同示例中，种子内容、种子尺寸、篡改区域的位置和大小均不同。生成约束：篡改区域不与左上角的种子位置重叠，保证种子完整可读；篡改区域为实心矩形，内部全为品红(6)。

**规则**：
1. 检测平铺周期：找到最小的 H_tile x W_tile 使得左上角 H_tile x W_tile 区域在非品红(6)位置上与整个网格的对应周期相位一致。
2. 提取左上角 H_tile x W_tile 区域作为种子瓦片。
3. 将种子瓦片平铺至与输入网格相同的尺寸，得到参考网格。
4. 找出输入网格中为品红(6)的所有像素位置——这些即为篡改位置。
5. 将篡改位置对应的参考网格像素值提取出来，裁剪到篡改区域的边界框。
6. 输出该裁剪结果（仅含正确颜色，背景为黑(0)的位置保持黑(0)）。

**关键洞察**：品红色区域既不是噪声也不是目标图案——它是"数据被擦除"的标记。求解者需要意识到整个网格本应是完美平铺的，品红色是需要修复的"洞"，而修复的依据是网格自身的周期性结构。

1. `main(grid)` 必须实现新题描述中的确定性转换规则，不能只识别 `generate_input()` 的固定模板。禁止不同的input网格输出相同的output网格。
