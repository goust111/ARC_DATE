## 新题 4：镜像重叠计数柱状图

**组合逻辑**：[镜像/mirror](已有，创新：多个对象各自独立镜像) + [邻接/adjacency → 标记侧](已有) → [计数/counting](已有，创新：计数对象不是连通体个数而是跨对象的重叠像素数) → [排序/sort](已有) → [柱状填充/histogram_fill](已有，创新：柱状图的行颜色由重叠源决定)

**来源原语**：镜像(2bcee788), 邻接(2bcee788), 标记像素(2bcee788), 计数(2753e76c), 排序(2753e76c), 柱状填充(2753e76c), 靠端对齐(2753e76c), 按数量降序(2753e76c)

**依赖链**：标记像素位置 → 各对象的镜像方向 → 镜像副本的空间位置 → 不同对象的镜像副本与其他原始对象之间的重叠像素数量 → 按重叠数排序 → 柱状图输出。每个对象的镜像方向独立确定，但重叠计数是全局交互的结果——改变任一对象的标记位置会影响所有相关的重叠统计。

每个前景对象按红色标记指示的方向镜像翻转后，统计各对象的镜像副本与其他原始对象重叠的像素数，按重叠数降序输出右对齐柱状图。

**输入结构**：约 18x18 的黑(0)背景网格。3~5 个单色前景对象（每个为 4-连通的不规则形状，4~8 像素，各自颜色唯一，使用蓝(1)、绿(3)、黄(4)、橙(7)、品红(6)等）散布在网格中，彼此不相邻。每个对象有恰好 1 个红(2)标记像素紧邻其某一侧（上、下、左或右），标记像素的位置指示该对象的镜像方向（标记在哪侧就向哪侧翻转）。不同示例中对象的形状、大小、位置和标记方向均不同。生成约束：所有对象镜像后，至少有 2 个对象的镜像副本与某个其他原始对象存在像素重叠；各对象的重叠计数互不相等。

**规则**：
1. 识别所有非黑(0)、非红(2)的 4-连通前景对象。识别每个红(2)标记像素及其唯一相邻的前景对象。
2. 对每个前景对象，以其边界框的被标记侧外边缘为轴进行镜像翻转：标记在右侧则以边界框右边缘外一列为轴水平翻转，标记在下侧则以边界框下边缘外一行为轴垂直翻转，以此类推。镜像副本使用与原对象相同的颜色。
3. 在同一网格上叠加所有原始对象和所有镜像副本。对每个对象 O，计算 O 的镜像副本覆盖的像素中，有多少个与**其他**原始对象（非 O 自身）的像素位置重合，该数即为 O 的重叠计数。
4. 将所有对象按重叠计数降序排列。
5. 生成柱状图输出：输出宽度 = 最大重叠计数，高度 = 对象数。每行对应一个对象（按排名从上到下），左侧填充黑(0)，右侧填充该对象颜色 × 重叠计数个像素（右对齐）。

**关键洞察**：柱状图中每行的宽度不是由对象自身的属性（面积、形状）决定的，而是由其镜像副本与其他对象的空间交互决定的——这是一个全局涌现量，只有在所有对象完成镜像后才能计算。
