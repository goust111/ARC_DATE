## 新题 3：分块降噪后的跨区异或比对

**组合逻辑**：[降噪] + [压缩] + [异或叠加](创新：在压缩后的粗粒度网格上执行，非原始像素级) + [裁剪]

**来源原语**：降噪/压缩/网格分块/噪声像素/瓦片(5614dbcf)、异或叠加/分隔行/对齐/前景掩码(99b1bc43)、裁剪(99b1bc43)

**依赖链**：降噪清除灰色干扰像素 → 使每个分块的主色可正确识别 → 压缩将分块化为粗粒度网格 → 两半粗粒度网格逐格对齐做异或。跳过降噪则噪声污染导致压缩结果错误；跳过压缩则无法在对等粒度上对齐比较；跳过异或则无法产生输出。

将被分隔行隔开的上下两半分别降噪、压缩为粗网格后，逐格异或比对，输出差异图。

**输入结构**：
- 网格高 2k+1 行（k 为 3 的倍数，如 k=9 则网格高 19 行），宽为 3 的倍数（如 12 或 15 列）。
- 第 k 行（0-索引）是一条全宽红(2)分隔行，该颜色仅出现在这一行。
- 上半区（行 0 到 k-1）和下半区（行 k+1 到 2k）各自的行数和列数均为 3 的倍数，因此各自可被切分为 3x3 分块的晶格。
- 每个 3x3 分块中，8-9 个像素为同一种非背景非灰颜色（该分块的"主色"），0-1 个像素为灰(5)噪声像素。主色为黑(0)时表示该分块为纯背景分块（可能有灰噪声点缀）。
- 上半区和下半区的分块晶格尺寸相同（行数和列数相等）。
- 上半区和下半区使用的非背景主色不必相同，但至少各有一个非背景分块。

**规则**：
1. 移除红色分隔行。
2. 对上半区和下半区分别独立处理：
   a. 降噪：在每个 3x3 分块内，忽略灰(5)像素，统计剩余像素中出现次数最多的颜色作为该分块的主色。
   b. 压缩：将每个 3x3 分块替换为一个像素，颜色等于该分块的主色。上半区和下半区各自得到一个粗粒度网格。
3. 将两个粗粒度网格逐格对齐（行列坐标相同的格子对应）。
4. 异或比对：
   - 若对齐的两格中恰好一个是前景（非黑）而另一个是背景（黑）：输出绿(3)。
   - 若两格均为前景或均为背景：输出黑(0)。
5. 输出该异或结果网格（尺寸等于粗粒度网格的尺寸）。

**关键洞察**：异或操作发生在压缩后的粗粒度层面而非原始像素层面——一个灰色噪声像素若被错误当作主色，会翻转整个分块的压缩结果，从而改变异或输出。需要对比多个示例才能发现分块→压缩→异或的层级结构，而非直接在原始像素上做差异比较。

## 实现要求

1. `main(grid)` 必须实现新题描述中的确定性转换规则，不能只识别 `generate_input()` 的固定模板。禁止不同的input网格输出相同的output网格。
2. `generate_input()` 必须随机生成多样样例，不能固定死。随机维度应覆盖：网格大小、对象数量、位置、颜色、方向、形状参数或关键分支。注意若描述中存在若干，需实现而不是只有单个，包括object或者对应关系等等。且若涉及到最短路径，则输入网格中必涉及到多条路径，对选择造成干扰。
3. 生成器必须保证输入满足 `main()` 的隐式假设：对象不重叠、不越界、特殊标记唯一或可区分、匹配关系无歧义、关键分支出现概率相同。
4. 禁止把 ARC 颜色 id 、亮度、拼写等当作人类不可见的数值语义参与排序、大小比较或隐藏映射。颜色变化必须有可见结构线索。注意颜色亮度、拼写等也是不可见信息，若描述中出现违规的颜色id或者亮度，可自行使用少量的固定颜色替代，但注意生成时要在三个以内输入输出网格中对所有变换100%覆盖度。
5. 输出样例要视觉清晰，人类必须能从输入输出对中肉眼辨认出规律。具体要求：避免对象粘连、覆盖关系混乱、同一像素多重语义；不同逻辑步骤产生的结果不要大面积层叠在一起导致无法分辨哪个颜色属于哪个步骤；输入中各元素之间保持足够间距，输出中新增的标记/填充/路径等应与背景和已有元素在颜色上有明显区分；若规则涉及多层叠加，生成时控制对象密度和尺寸，确保叠加区域只占少数像素而非铺满整个网格。
6. 若规则有多个分支，生成器不能长期固定成一个分支；应让分支在随机样例中合理出现。分支概率不必平均——难以发现的隐蔽分支（如少数情况下才触发的特殊规则）应适当提高出现概率，确保在 3 个训练示例中至少出现一次，否则求解者无法归纳该规则。对于颜色映射类规则，确保 2 个左右的示例即可覆盖所有映射关系（每种颜色→颜色的映射至少在某个示例中出现过）。
