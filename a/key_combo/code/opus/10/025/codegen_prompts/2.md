## 新题 2：对角空位印入精灵体并经图例重涂色

**组合逻辑**：[对角互补](已有，定位空位) → [图案印章](创新：从占位符定位改为由对角空位定位) → [重涂色](已有，由图例驱动)

**来源原语**：对角互补/diagonal_complement(22233c11), 对角空位补块/complement_at_diagonal_vacancies(22233c11), 图案印章/stamp_glyph(edb79dae), 精灵体/sprite(edb79dae), 颜色图例/color_legend(edb79dae), 编码映射/encoding_map(edb79dae), 正方形块/square_block(22233c11)

**依赖链**：识别对角填充块 → 确定互补空位坐标 → 按填充色查找同色精灵体 → 在空位位置印入精灵体 → 按图例将精灵体重涂为输出色。对角空位提供"在哪里印"，填充色提供"印什么形状"，图例提供"涂什么颜色"——三重间接寻址缺一不可。

识别每个对角方块图案的两处空位，在空位处印入与方块同色的精灵体形状，再按颜色图例将印入的精灵体重涂为指定输出色。

**输入结构**：约 18x18 网格。黑(0)背景。2-4 个前景图案（"方块组"），每个方块组占据一个 2x2 排列的等大正方形子块区域（每个子块约 3x3 像素）。在每个方块组中，恰好两个对角位置的子块被填充为同一前景色（如红(2)、蓝(1)、绿(3)等），另外两个对角子块为背景色。不同方块组使用不同颜色。此外，网格中散布着与每种方块组颜色相同的小型精灵体（4-连通单色形状，3-6 像素，形状各异），不与任何方块组接触。网格的一个角落有颜色图例：由若干两像素对组成，每对中一个像素为方块组颜色、相邻一个像素为输出颜色（如红(2)旁放黄(4)表示红色精灵体重涂为黄色）。

**规则**：
1. 对每个方块组，识别已填充的两个对角子块位置（如左上+右下）和空缺的两个互补对角子块位置（如右上+左下）。
2. 对每个空缺子块位置，找到与该方块组前景色相同的精灵体。
3. 将精灵体印入空缺子块区域，对齐到子块的左上角。若精灵体超出子块边界，裁剪到子块范围内。
4. 将印入的精灵体像素重涂为图例中该前景色对应的输出颜色。
5. 原始对角填充块保持不变。原始精灵体（方块组外部的）从网格中擦除。图例保留。
6. 同一方块组的两个空缺位置印入相同形状的精灵体副本。

**生成约束**：每种方块组颜色恰好对应一个精灵体和一个图例条目。所有精灵体的边界框尺寸不超过子块尺寸。方块组之间不重叠。

**关键洞察**：空缺位置不是被纯色方块填充（不同于参考题 22233c11 的青色方块），而是被颜色查找到的精灵体形状填入，再经图例映射到输出色——从"位置决定填什么"到"颜色同时决定形状和输出色"的三重间接寻址是参考题中不存在的结构关系。
