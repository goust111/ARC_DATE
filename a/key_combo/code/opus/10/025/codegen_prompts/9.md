## 新题 9：字形查表判定结果控制边界矩形平移方向

**组合逻辑**：[查表匹配](已有) → [对齐判定结果](已有，但从视觉标记改为隐式控制) → [平移](创新：平移方向由判定结果参数化) + [重复色才移动](已有)

**来源原语**：查表匹配/table_lookup(d8e07eb2), 对齐判定结果/alignment_verdict(d8e07eb2), 完整行列对齐/full_row_or_column_alignment(d8e07eb2), 字形单元格/glyph_cell(d8e07eb2), 查询行/query_row(d8e07eb2), 参考表/reference_table(d8e07eb2), 平移/translate(22208ba4), 重复色才移动/repeated_color_moves(22208ba4), 边界矩形/boundary_rectangle(22208ba4), 贴边定位/border_aligned(22208ba4)

**依赖链**：查询字形匹配参考表 → 判定匹配单元格是否构成完整行或列 → 行对齐则平移方向为水平、列对齐则为垂直 → 仅重复色矩形沿该方向内移。查表结果不是最终输出的一部分（不像参考题那样标绿），而是隐式地决定了一个几何操作的参数——求解者必须先解字形谜题，再用答案指导空间变换。

查询字形在参考表中匹配后判定是否构成完整行或列，该判定结果隐式决定下区边界矩形的平移方向（行对齐→水平内移，列对齐→垂直内移），仅重复色矩形执行平移。

**输入结构**：约 20x20 网格，由一条全宽红(2)水平带（2 像素高）分为上下两个区域。
- 上区：青(8)背景，两条全宽品红(6)分隔行。第一条分隔行上方为查询行，包含若干 5x5 字形单元格（每个单元格内有一个 3x3 彩色形状，颜色和形状各异）。两条分隔行之间为参考表，由 5x5 字形单元格排列成的矩阵（如 3x3 或 4x4 矩阵）。
- 下区：黑(0)背景，若干单色实心矩形触及网格的角落或边缘。其中恰好一种前景颜色出现为多个分离的 4-连通矩形（重复色），其余颜色各只出现一次（单例色）。

**规则**：
1. 将查询行中的每个字形（按颜色和 3x3 形状同时匹配）在参考表中查找。
2. 检查所有匹配的参考表单元格位置：若它们构成参考表中的一个完整行，判定为"行对齐"；若构成一个完整列，判定为"列对齐"；否则判定为"未对齐"。
3. 在上区的视觉反馈：用绿(3)填充匹配的参考表单元格内部背景。若判定为"行对齐"或"列对齐"，用绿(3)填充查询行带和第二条分隔行下方的判定带背景；若"未对齐"，用红(2)填充判定带背景。
4. 在下区执行矩形平移：
   - 若判定为"行对齐"：每个重复色矩形沿水平方向向内平移（远离其触及的竖直边界），平移距离等于该矩形自身宽度。
   - 若判定为"列对齐"：每个重复色矩形沿垂直方向向内平移（远离其触及的水平边界），平移距离等于该矩形自身高度。
   - 若判定为"未对齐"：不移动任何矩形。
5. 单例色矩形永不移动。重复色矩形从原位擦除（设为背景）后绘制到新位置。

**冲突解决**：若平移后的重复色矩形与单例色矩形重叠，重叠区域取重复色矩形的颜色。若两个平移后的重复色矩形重叠，后绘制的覆盖先绘制的（按矩形原始位置从左上到右下的顺序绘制）。

**生成约束**：查询字形恰好匹配参考表中构成一个完整行或一个完整列（不同时构成两者）。至少有两个重复色矩形分别触及不同的边界。

**关键洞察**：字形查表的判定结果不仅是一个视觉标记（绿色/红色填充），更隐式地控制了网格另一个区域中矩形的平移方向。求解者必须先解决字形匹配谜题、判断行/列对齐，再将这个二元决策应用到完全不同的空间操作上——两个看似独立的子任务通过一个隐式参数链接。
