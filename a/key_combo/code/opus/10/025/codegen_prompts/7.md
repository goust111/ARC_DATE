## 新题 7：环绕平铺产生封闭区域触发边界分色

**组合逻辑**：[平铺 + 周期重复](已有) + [列环绕](创新：从阴影偏移的列环绕扩展为平铺后的拓扑连通性环绕) → [有孔触发重涂](已有) + [内外边界分色](已有)

**来源原语**：平铺/tiling(9b30e358), 周期重复/periodic_repeat(9b30e358), 种子图案/seed_motif(9b30e358), 列环绕/column_wrapping(310f3251), 描边/outline(aa4ec2a5/d931c21c), 有孔触发重涂/hole_presence_triggers_recolor(aa4ec2a5), 内外边界/inner_outer_bound(d931c21c), 内外边界分色/boundary_diff_color(d931c21c), 封闭孔洞/enclosed_hole(aa4ec2a5), 前景对象/foreground_object(aa4ec2a5)

**依赖链**：底部母题向上平铺填满网格 → 列环绕使左右边缘视为相邻 → 平铺后的蓝色前景可能围合出封闭背景区域 → 检测封闭区域 → 包围封闭区域的前景像素重涂为青色，封闭区域边界像素涂绿。平铺产生几何结构，环绕改变拓扑连通性，拓扑决定了哪些区域被封闭，封闭状态触发着色规则。

将底部母题向上周期平铺填满网格，以列环绕拓扑（左右边缘视为相邻）判定封闭背景区域，对围合出封闭区域的前景像素重涂色、对封闭区域的边界像素上色。

**输入结构**：约 12x12 网格。黑(0)背景。底部 3-4 行包含一个蓝(1)前景母题。母题在左侧边缘和右侧边缘附近都有像素，中间有间隔。母题不接触最左列和最右列的所有行（即母题像素在左右边缘附近但不一定在第 0 列或最后一列）。母题上方的行全部为背景(0)。

**规则**：
1. 将底部母题行块向上周期复制，填满整个网格（保持列对齐，每次复制母题行块的完整高度）。原始底部母题所在行保持不变。
2. 平铺完成后，计算连通性时采用列环绕拓扑：最右列的像素与最左列的像素视为水平相邻（即网格在水平方向形成圆柱面）。
3. 在此环绕拓扑下，找出所有 4-连通的背景(0)区域。将不接触网格顶行和底行的背景区域标记为"封闭区域"（因为列环绕使左右边不算开放边界，所以仅顶/底行是开放边界）。
4. 对每个封闭区域：将与该封闭区域 4-相邻的蓝(1)前景像素重涂为青(8)。
5. 对每个封闭区域内部的背景像素：若该像素与青(8)像素（含刚重涂的）8-相邻，则涂为绿(3)。
6. 不与任何封闭区域相邻的蓝(1)前景像素保持蓝(1)不变。
7. 非封闭的背景区域保持黑(0)。

**生成约束**：母题设计保证：在列环绕拓扑下至少存在一个封闭背景区域，但在非环绕拓扑下该区域不封闭（即该区域的封闭性依赖于左右边缘的环绕连通）。母题内部（单次复制）不包含封闭区域。

**关键洞察**：列环绕将平面网格的拓扑从矩形变为圆柱面——左侧边缘附近的母题像素与右侧边缘附近的像素在平铺后"接合"，围成原本不存在的封闭腔体。求解者必须意识到左右边缘在判定封闭性时被视为相邻，这在非环绕视角下不成立。
