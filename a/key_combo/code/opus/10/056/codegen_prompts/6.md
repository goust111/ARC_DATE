## 新题 6：角括号触发选择性擦除后释放重力下落

**组合逻辑**：[角括号 + 按标记色选择同色 + 擦除](从 1e81d6f9 提取，擦除作为前置操作而非最终输出) → [重力下落 + 碰撞阻挡 + 重力远近序处理](从 5ffb2104 提取，重力方向改为向下，且在擦除改变后的地形上运行)（创新：擦除不是终态而是改变碰撞地形的中间步骤，擦除哪种颜色决定了哪些障碍消失、哪些对象获得新的下落路径）

**来源原语**：角括号/corner_bracket(1e81d6f9)、标记在括号内部/marker_inside_bracket(1e81d6f9)、按标记色选择同色/select_same_color_by_marker(1e81d6f9)、保留标记本身/preserve_marker_itself(1e81d6f9)、擦除/erase(1e81d6f9)、重力下落/gravity_drop(5ffb2104)、碰撞阻挡/collision_blocking(5ffb2104)、重力远近序处理/gravity_far_to_near(5ffb2104)、连通分量/connected_component(5ffb2104)、网格边界/grid_edge(5ffb2104)

**依赖链**：角括号标记色决定擦除哪种颜色 → 擦除改变了网格中哪些位置是空的 → 空位分布改变了下落路径和碰撞点 → 最终物体位置取决于擦除后的地形。这是一条因果级联链：不同的标记色会产生完全不同的最终布局。删除擦除步骤则地形不变、物体不动（或无法下落）；删除重力步骤则擦除后留下空洞但物体不移动。

读取角括号内标记像素的颜色，擦除网格中所有同色像素（标记本身除外），然后让剩余前景对象在重力作用下向下沉降直到撞击网格底部或其他已沉降对象。

**输入结构**：黑(0)背景，约 15x18 网格。包含若干（4~6 个）不同颜色的单色 4-连通前景对象（颜色取自蓝(1)、红(2)、绿(3)、黄(4)、橙(7)、青(8)等），每个对象 3~8 像素，形状不规则。其中一种颜色的对象充当"障碍层"——它们水平分布在网格中部偏下，阻挡上方对象的下落。一个灰(5)角括号位于网格的某个角落，其包围盒内部（排除角括号自身像素）恰好有一个标记像素，标记像素的颜色与障碍层对象的颜色相同。生成约束：角括号和标记像素位于网格底部两行以内（确保角括号本身不受重力影响，因为它已在底部）；除角括号标记同色的对象（障碍层）外，其余对象均位于障碍层之上或与障碍层无直接接触。

**规则**：
1. 识别灰(5)角括号对象（最大的灰色 4-连通分量）。在其包围盒内部（排除灰色像素），找到唯一的非黑标记像素，读取颜色 C_erase。
2. 将网格中所有颜色为 C_erase 的像素（不含角括号内的标记像素本身）重涂为黑(0)背景。此步骤消除了障碍层。
3. 对擦除后剩余的所有非黑、非灰前景 4-连通对象执行向下重力沉降：
   a. 按每个对象包围盒的底行从下到上排序（底行最低的对象最先处理）。
   b. 依次处理每个对象：保持形状和颜色不变，将对象整体向下平移，每次移动一行，直到对象的某个像素再向下一行将超出网格底边、或与已沉降（已处理）的对象像素重叠。将对象固定在最后的合法位置。
4. 灰(5)角括号及其内部标记像素位置不变、不参与重力沉降。

**关键洞察**：角括号不是在做终态选择，而是在做环境改造——它指定擦除的颜色恰好是阻挡其他对象下落的障碍层，擦除后物体才能贯通下落；需要对比多个示例（不同标记色→不同障碍被擦→不同下落结果）才能归纳出因果链。
