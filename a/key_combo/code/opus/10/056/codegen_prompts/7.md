## 新题 7：格子槽位内的对角周期补全

**组合逻辑**：[格子框架 + 格子槽位 + 跨框架对应](从 2e65ae53 提取，槽位内容从均匀填充改为结构化对角图案) × [对角周期图案 + 对角线同余 + 对角周期补缺失](从 c3f564a4 提取，作用域从全局网格缩小到槽位内部，周期从全局唯一改为按行变化)（创新：对角周期规则被嵌入格子结构内部运行，周期参数通过跨槽位比较推断，形成"结构内嵌推断"）

**来源原语**：格子框架/lattice_frame(2e65ae53)、格子槽位/lattice_slot(2e65ae53)、跨框架对应/cross_frame_match(2e65ae53)、推断/infer(2e65ae53)、槽位位置决定颜色/slot_position_color(2e65ae53，改造为"槽位行决定对角周期")、对角周期图案/diagonal_periodic_pattern(c3f564a4)、对角线同余/diagonal_residue(c3f564a4)、补全/complete(c3f564a4)、对角周期补缺失/missing_by_diagonal_cycle(c3f564a4)

**依赖链**：每个槽位的对角周期参数（颜色循环序列）无法仅从该槽位自身推断（因为有缺失像素和多种可能的循环）。必须通过同一格子行的其他槽位交叉比较来确定共享的循环序列，然后用该序列补全每个槽位的缺失像素。格子结构提供了"哪些槽位共享参数"的信息，对角周期规则提供了"槽位内像素如何排布"的信息，两者交织：格子结构约束推断空间，对角规则约束填充空间。

多个格子框架将区域分割为槽位网格，每个槽位内部填有带缺失的对角条纹图案；同一格子行的所有槽位共享相同的颜色循环，通过跨槽位比较推断循环后补全所有缺失。

**输入结构**：黑(0)背景，约 20x20 网格。灰(5)像素构成 2~3 个一像素粗的矩形格子框架，每个框架由水平线和垂直线将内部划分为 R 行 C 列的槽位网格（R 和 C 各为 2~4）。不同框架的槽位数量相同（行列数相同），但槽位的物理尺寸可以不同（因框架位置和大小不同）。每个槽位内部用非黑非灰颜色填充对角条纹图案：同一对角线 (local_row + local_col) mod K 的像素颜色相同，其中 K 为该格子行的颜色循环长度（K = 2 或 3），颜色循环从蓝(1)、红(2)、绿(3)、黄(4)、品红(6)、橙(7)、青(8)、栗(9)中选取。同一格子框架同一行的所有槽位共享相同的 K 和颜色循环序列。不同行可以有不同的循环（不同 K 或不同颜色选择）。每个槽位有若干像素被替换为黑(0)（缺失），但每个循环中至少有一个颜色在该行的某个槽位中可见（确保可推断）。生成约束：每行的颜色循环互不相同；每个槽位至少保留一半像素未缺失。

**规则**：
1. 识别所有灰(5)矩形格子框架。每个框架的内部被灰色水平线和垂直线分割为 R x C 个矩形槽位。
2. 对每个框架的每一行（共 R 行），收集该行所有 C 个槽位中的非黑像素。
3. 对该行的非黑像素，按像素在各自槽位内的局部坐标 (local_row, local_col) 计算对角线残余 d = (local_row + local_col)。将所有同余 d mod K 的非黑像素归组。通过尝试 K = 2 和 K = 3，找到使每个同余类内颜色一致的最小 K 值。记录该行的循环序列：残余 0 → 颜色 A，残余 1 → 颜色 B，...，残余 K-1 → 颜色 X。
4. 对该行每个槽位中的每个黑(0)缺失像素 (local_r, local_c)，计算 d = (local_r + local_c) mod K，填入循环序列中对应的颜色。
5. 对所有框架的所有行重复上述步骤。
6. 灰色框架线、外部背景保持不变。

**关键洞察**：单个槽位的缺失像素无法独立补全——同一对角残余类的像素可能全部缺失于某个槽位，只有通过同行其他槽位的对应残余类才能确定颜色；格子框架的行结构定义了"共享循环"的边界。
