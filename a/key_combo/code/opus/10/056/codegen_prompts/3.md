## 新题 3：孔洞拓扑分类决定镜像或擦除

**组合逻辑**：[封闭孔洞检测 → 分类](从 ac2e8ecf 提取，分类标准保留但后果从移动方向改为变换类型选择) → [镜像 + 逐色独立变换 + 包围盒内翻转](从 e74e1818 提取，仅作用于有孔对象) ＋ [擦除](从 fc754716 提取，作用于无孔对象) → [碰撞解决：小包围盒优先]（创新：镜像后重叠区域的冲突解决）

**来源原语**：封闭孔洞/enclosed_hole(ac2e8ecf)、封闭对象/closed_object(ac2e8ecf)、开放对象/open_object(ac2e8ecf)、有孔者升无孔者降/hole_up_holeless_down(ac2e8ecf，改造为"有孔者镜像、无孔者擦除")、镜像/mirror(e74e1818)、逐色独立变换/per_color_transform(e74e1818)、包围盒内翻转/flip_within_bbox(e74e1818)、擦除/erase(fc754716)

**依赖链**：孔洞检测结果决定每个对象接受哪种操作（镜像还是擦除），这是一个条件分支节点。镜像操作可能使原本不重叠的有孔对象产生像素冲突，需要用包围盒面积进行优先级裁决。删除分类步骤则不知道哪些对象该镜像、哪些该擦除；删除冲突解决则镜像后输出不唯一。

检测每个前景对象是否包围背景孔洞：有孔对象在各自包围盒内垂直镜像，无孔对象被擦除；镜像后重叠处小包围盒对象覆盖大包围盒对象。

**输入结构**：黑(0)背景，约 15x15 网格。包含 4~6 个单色 4-连通前景对象，颜色互不相同（取自蓝(1)、红(2)、绿(3)、黄(4)、品红(6)、橙(7)等）。其中约一半对象为"封闭对象"——其 4-连通前景像素完全包围至少一个黑(0)背景孔洞（即对象包围盒内存在被对象像素 4-连通围住的背景区域）。另一半为"开放对象"——线状或弧状图形，包围盒内没有被完全围住的背景区域。每个对象 5~12 像素。封闭对象的包围盒之间可以在镜像后产生重叠（即存在至少一对封闭对象，其包围盒在垂直方向有交集列），但原始位置上所有对象的像素互不重叠。生成约束：所有封闭对象的包围盒面积互不相同，以保证冲突解决的唯一性。

**规则**：
1. 对每个非背景色前景对象 O，提取其所有像素，计算最小包围盒 B(O)。
2. 检查 B(O) 内部是否存在被 O 的像素 4-连通完全围住的黑(0)背景连通区域。具体方法：从 B(O) 内所有黑(0)像素出发做 4-连通洪泛，若某个黑色连通分量不与 B(O) 的边界行/列相邻，则该分量是一个封闭孔洞。
3. 若 O 至少有一个封闭孔洞：O 为"有孔对象"，对 O 执行垂直镜像——将 O 的每个像素 (r, c) 映射到 (r0 + r1 - r, c)，其中 r0、r1 分别为 B(O) 的顶行和底行。镜像后的像素保持 O 的颜色。
4. 若 O 没有封闭孔洞：O 为"无孔对象"，将 O 的所有像素擦除为黑(0)。
5. 冲突解决：所有有孔对象镜像完成后，若多个对象的镜像像素占据同一单元格，包围盒面积较小的对象优先（其颜色覆盖较大包围盒对象的颜色）。
6. 背景保持不变。

**关键洞察**：孔洞不是需要填充的目标，而是一个拓扑分类信号——它决定对象接受镜像变换还是被删除，且这一分类标准仅靠单个示例中个别对象难以确认，需对比有孔和无孔对象的不同命运才能归纳。
