## 新题 5：通道探测后按切比雪夫距离奇偶着色

**组合逻辑**：[洪泛填充 + 背景通道检测](从 a64e4611 提取，通道探测逻辑保留但着色规则替换) → [以控制点为中心 + 奇偶距离决定颜色](从 b7fb29bc 提取，作用域从矩形框内改为不规则通道区域)（创新：通道探测确定"在哪里画"，切比雪夫距离确定"画什么颜色"，两个独立几何系统在同一网格上叠加）

**来源原语**：洪泛填充/flood_fill(a64e4611)、背景通道/background_corridor(a64e4611)、杂色前景/clutter_foreground(a64e4611)、长矩形通道涂色/long_rectangular_corridors_filled(a64e4611)、区域包含/region_containment(a64e4611)、控制像素/control_pixel(b7fb29bc)、以控制点为中心/centered_on_control(b7fb29bc)、奇偶距离决定颜色/parity_distance_color(b7fb29bc)

**依赖链**：通道探测确定哪些像素是"可涂色的真通道"，距离奇偶规则确定每个可涂色像素的具体颜色。两者缺一不可：没有通道探测则不知哪些像素该涂（杂色间的小缝隙不算通道）；没有距离规则则不知涂什么颜色。控制像素的位置和通道的走向共同决定了最终的颜色分布——同一条通道上远端和近端可能颜色不同。

在杂色噪声中探测出隐藏的背景长通道，然后以控制像素为中心、按切比雪夫距离奇偶为每个通道像素染上红色或黄色。

**输入结构**：黑(0)背景，约 20x20 网格。大量橙(7)杂色前景像素随机散布，密度约 30%~40%，在视觉上形成噪声幕。噪声幕中隐藏着若干条宽 1~2 像素、长度至少为网格边长一半的水平或垂直黑(0)背景长通道（通道内所有像素的完整 3x3 邻域均为黑色背景——即通道像素周围无杂色像素紧邻）。杂色像素之间也存在小型黑色缝隙，但这些缝隙中的像素至少有一个 3x3 邻域内含有杂色像素，因此不被判定为通道。一个品红(6)控制像素位于网格中的某处（可以在通道上，也可以在通道外的背景区域），其 3x3 邻域内不含杂色像素。红(2)和黄(4)在输入中不出现。生成约束：通道之间不直接 4-连通相连；控制像素不在网格边缘。

**规则**：
1. 构建"清洁背景遮罩"：标记所有黑(0)像素中，其完整 3x3 邻域（包含自身及 8 邻居，边界外视为非背景）全部为黑(0)背景的像素。品红(6)控制像素不计入背景，但其 3x3 邻域若全为黑(0)或品红(6)则邻近的黑(0)像素仍可通过清洁测试。
2. 在清洁背景遮罩上提取所有极大矩形（矩形内所有像素均为清洁背景）。按面积从大到小排序。
3. 依次接受极大矩形：一个矩形被接受当且仅当其长轴长度 >= 网格对应边长的一半，且该矩形至少引入一个新像素（不被之前已接受矩形覆盖）。将所有被接受矩形覆盖的清洁背景像素标记为"通道像素"。
4. 对每个通道像素 (r, c)，计算其到品红(6)控制像素 (cr, cc) 的切比雪夫距离 d = max(|r - cr|, |c - cc|)。
5. 若 d 为偶数，将该通道像素涂为红(2)；若 d 为奇数，涂为黄(4)。
6. 控制像素保持品红(6)不变。杂色像素、非通道背景像素均保持不变。

**关键洞察**：通道不是用单一颜色简单着色的——控制像素的位置决定了沿通道的颜色渐变节奏，使得同一条直线通道上可能交替出现红黄条纹，条纹间距取决于通道相对控制像素的角度。
