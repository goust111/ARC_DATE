## 新题 5：降采样还原隐藏控制图以驱动印章覆盖

**组合逻辑**：[降采样 downsample + 整数缩放对应 int_scale_correspond]（创新：降采样的输出不做掩码裁剪，而作为控制精灵驱动印章操作） → [印章覆盖 stamp + 像素到块映射 pixel_block_mapping + 控制色选中则印章 stamp_where_control]

**来源原语**：downsample、int_scale_correspond、mono_pattern 来自 6ecd11f4；stamp、pixel_block_mapping、stamp_where_control、control_pixel 来自 ad7e01d0；polychrome_tile 来自 bf45cf4b

**依赖链**：大尺度单色图案是控制图的像素放大版本，必须通过降采样还原真实控制图。控制图的每个非背景像素驱动一次瓦片印章。去掉降采样则控制图不可用（大图案无法直接作为控制图，因为尺度不匹配）；去掉印章则控制图无用途。降采样的比例因子由瓦片尺寸决定，将两个操作绑定在一起。

将输入中大尺度单色图案降采样为与瓦片等大的控制精灵，再用控制精灵的非背景像素位置决定在哪些输出块中印章瓦片副本。

**输入结构**：约 15x15 网格，黑(0) 背景。一个大型单色蓝(1) 图案占据网格大部分区域，该图案为某个小型二值图案按整数倍（如 3x 或 5x）等比放大后的结果——每个"宏像素"是一个 k×k 的纯蓝或纯黑区块，k 为放大倍数。网格另一角落有一个小型多色方形瓦片（k×k 大小），使用红(2)、绿(3)、黄(4) 等非蓝非黑颜色。生成约束：大图案的边界框尺寸在两个方向上都是 k 的整数倍；大图案与瓦片不重叠；降采样后的控制图至少有 3 个非背景像素和 3 个背景像素。

**规则**：
1. 分离大型蓝色图案和小型多色瓦片。裁剪各自的边界框。
2. 确定缩放因子 k = 瓦片的边长（瓦片为 k×k 正方形）。验证大图案的边界框尺寸在两个方向上都是 k 的整数倍。
3. 将大图案按因子 k 降采样：将大图案划分为 k×k 的块，每个块若全为蓝则降采样为蓝(1)，若全为黑则降采样为黑(0)。得到一个小型控制图。
4. 输出网格尺寸等于大图案的边界框尺寸（与原始大图案同大小）。
5. 对控制图中的每个像素（行 r，列 c）：
   - 若该像素为蓝（非背景）：在输出的对应 k×k 块区域内印章瓦片的完整副本。
   - 若该像素为黑（背景）：对应 k×k 块保持全黑。
6. 输出仅包含印章结果，不包含原始蓝色图案或瓦片模板。

**关键洞察**：大尺度蓝色图案并非最终输出的一部分——它是控制图的"放大密文"。求解者必须发现瓦片尺寸同时是降采样因子和印章块大小，从而将蓝色区域"解码"为瓦片摆放指令。表面上看像像素放大，实际上是降采样还原+印章的两步操作。
