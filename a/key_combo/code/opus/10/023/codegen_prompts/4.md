## 新题 4：标签颜色比较选择镜像轴与重涂色

**组合逻辑**：[行列交叉 row_col_intersection + 标签同色时填充 labels_match_fill（创新：标签比较结果决定镜像轴和重涂色方式而非决定是否填充）] → [镜像 mirror + 跨框中线反射入内 reflect_centerline_in] + [重涂色 recolor]

**来源原语**：row_col_intersection、row_label、column_label、labels_match_fill 来自 a406ac07；mirror、hollow_rect、nearest_assign、reflect_centerline_in 来自 6855a6e4；recolor 来自 845d6e51

**依赖链**：标签颜色比较（同色/异色）是一个条件分支节点：同色时选水平镜像轴并重涂为标签色，异色时选垂直镜像轴并保持原色。镜像操作依赖标签比较的结果来确定轴向；重涂色操作依赖标签比较的结果来确定是否改色。三者形成条件分支图而非线性流水线。

根据框中心位置处的行标签与列标签是否同色，决定将框旁精灵体以何种轴向反射入框内、并决定是否改变精灵体颜色。

**输入结构**：约 14x14 网格，黑(0) 背景。最底行为列标签行：每列一个非黑色像素，颜色从蓝(1)、红(2)、绿(3)、黄(4) 中选取。最右列为行标签列：每行（不含最底行的交叉单元格）一个非黑色像素，颜色从同一集合中选取。内部区域有 3-4 个空心矩形框（灰(5) 单像素厚边界，奇数宽高如 5x5 或 7x7），框之间互不重叠且与标签行列不接触。每个框外（距框边界框 1-2 像素范围内）有一个小型橙(7) 精灵体（4-连通，3-6 像素，不规则形状）。生成约束：每个框的几何中心（向下取整）对应的行标签和列标签明确存在且非黑色；精灵体反射后的像素完全落在框的内部空间内；不同框的精灵体形状各不相同。

**规则**：
1. 对每个灰色空心矩形框，计算其边界框的中心行 r_c 和中心列 c_c（均向下取整）。
2. 读取行标签：右边最后一列第 r_c 行的颜色 L_row。读取列标签：最底行第 c_c 列的颜色 L_col。
3. 找到距该框最近（边界框间曼哈顿距离最小）的橙色精灵体。
4. 条件分支：
   - 若 L_row == L_col：将精灵体关于框的垂直中心线做水平反射，反射像素涂为 L_row 的颜色（不再是橙色）。
   - 若 L_row != L_col：将精灵体关于框的水平中心线做垂直反射，反射像素保持橙(7)。
5. 反射后的像素绘制在框内部（覆盖黑色背景）。擦除原始位置的橙色精灵体（涂黑）。
6. 灰色框、标签行列保持不变。
7. 多个框按其中心位置从左上到右下（先按行从上到下，同行按列从左到右）的顺序处理。由于框互不重叠且精灵体反射后在框内部，处理顺序不影响最终结果。

**关键洞察**：行列标签的语义从"是否填充单元格"变成了"选择哪种几何变换"——同色标签触发水平反射加变色，异色标签触发垂直反射不变色。求解者必须发现标签比较结果同时控制两个输出属性（轴向和颜色），而非仅控制一个。
