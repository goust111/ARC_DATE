## 新题 8：行带平铺与交替镜像配对色

**组合逻辑**：[平铺(tile)](保留纵向重复填满画布) + [镜像(mirror)](创新：不是分析输入的周期结构，而是在输出的交替副本上主动施加镜像) + [重涂色(recolor)](创新：镜像副本同时进行配对色映射) → 平铺产生多个副本 → 奇数副本同时执行水平镜像 + 配对色变换 → 偶数副本保持原样

**来源原语**：平铺(tile) + 行带(row_band) + 纵向重复(vertical_repetition) + 前景行带铺满画布(foreground_band_tiles_to_fill_canvas) ← 8eb1be9a；镜像(mirror) + 双轴反射(biaxial_reflection) ← 67e8384a；重涂色(recolor) + 配对色映射(paired_color_mapping) ← 6ea4a07e；反转(invert) ← 6ea4a07e

**依赖链**：识别前景行带 → 纵向平铺填满画布 → 对每个副本编号（从行带原始位置向上和向下，原位为 0） → 偶数编号副本保持原样 → 奇数编号副本同时执行左右镜像和配对色映射 → 两种变换的叠加创造出棋盘式的对称图案

将前景行带纵向平铺后，交替副本同时进行水平翻转和配对色变换，产生织物般的交错图案。

**输入结构**：一个 15x10 的黑(0)背景网格。网格中有一个连续的水平行带（3 行高，全宽），行带内含有 2~3 种非背景色像素（如青(8)和绿(3)，或灰(5)和青(8)），排列成非对称的图案（即左右翻转后图案不同）。行带位于网格的某一行段（不一定在中间），行带上方和下方是纯黑(0)背景行。行带内使用的每种颜色都必须在配对映射表中有对应：青(8)->红(2)、绿(3)->蓝(1)、灰(5)->黄(4)。生成约束：网格高度能被行带高度整除（即 15 / 3 = 5 个完整副本位置）；行带图案非左右对称。

**规则**：
1. 识别前景行带：包含所有非黑(0)像素的连续行段。
2. 以行带高度为步长，向上和向下复制行带，直到填满整个画布。保持行带在原始行位置对齐。将原始行带编号为 0，向上依次为 -1, -2, ...，向下依次为 1, 2, ...。
3. 偶数编号（0, -2, 2, -4, 4, ...）的副本保持行带原样不变。
4. 奇数编号（-1, 1, -3, 3, ...）的副本同时执行两个变换：(a) 水平翻转（左右镜像），(b) 对每个非黑(0)像素应用配对色映射：青(8)->红(2)、绿(3)->蓝(1)、灰(5)->黄(4)。黑(0)像素保持为黑(0)。
5. 两个变换必须同时应用于奇数副本——仅翻转不变色，仅变色不翻转，都不是正确的规则。

**关键洞察**：行带本身非对称且使用了有配对映射关系的颜色，这两个条件缺一不可：如果行带对称，镜像翻转不可见，求解者可能只归纳出颜色映射；如果行带只有一种颜色，颜色映射退化为单色替换，求解者可能只归纳出翻转。必须对比偶数和奇数副本才能同时识别出两种变换的叠加。

## 实现要求

1. `main(grid)` 必须实现新题描述中的确定性转换规则，不能只识别 `generate_input()` 的固定模板。禁止不同的input网格输出相同的output网格。
2. `generate_input()` 必须随机生成多样样例，不能固定死。随机维度应覆盖：网格大小、对象数量、位置、颜色、方向、形状参数或关键分支。注意若描述中存在若干，需实现而不是只有单个，包括object或者对应关系等等。且若涉及到最短路径，则输入网格中必涉及到多条路径，对选择造成干扰。
3. 生成器必须保证输入满足 `main()` 的隐式假设：对象不重叠、不越界、特殊标记唯一或可区分、匹配关系无歧义、关键分支出现概率相同。
4. 禁止把 ARC 颜色 id 、亮度、拼写等当作人类不可见的数值语义参与排序、大小比较或隐藏映射。颜色变化必须有可见结构线索。注意颜色亮度、拼写等也是不可见信息，若描述中出现违规的颜色id或者亮度，可自行使用少量的固定颜色替代，但注意生成时要在三个以内输入输出网格中对所有变换100%覆盖度。
