## 新题 10：双色矩形内外色互换延伸与反射对称检验

**组合逻辑**：[射线延伸 + 内外色互换(swap_extend)](保留叶状突起选行列和内外色互换机制) + [对称补全(symmetry_completion)](创新：延伸后的射线图案应与矩形形成联合反射对称，缺口处需补全) + [重涂色(recolor)](创新：不对称的延伸段用第三种颜色标记) → 叶状突起控制射线方向 → 射线在矩形外延伸并色互换 → 检测整体图案的垂直对称性 → 补全缺口或标记不对称部分

**来源原语**：射线延伸(ray_extend) + 叶状突起(leaf_protrusion) + 双色矩形(bicolor_rectangle) + 突起定行列(leaf_selects_row_col) + 内外色互换延伸(swap_extend) ← f1cefba8；对称补全(symmetry_completion) + 缺失像素(missing_pixel) + 对称轴(symmetry_axis) + 双轴镜像轨道(two_axis_orbit) + 轨道内已知色唯一(unique_known_in_orbit) ← af22c60d；重涂色(recolor) + 交集差集分别着色(intersection_diff_colored) ← a8610ef7

**依赖链**：叶状突起选定行列 → 选定行列在矩形内部用外层色切割，在矩形外部用内层色延伸到网格边界 → 对整个图案（矩形 + 延伸射线）做垂直轴反射对称检验 → 检验的对称轴为矩形的垂直中轴线 → 有对称配对的延伸像素保持内层色不变 → 无对称配对的延伸像素重涂为黄(4) → 矩形本身不变

叶状突起驱动内外色互换延伸后，对延伸线相对于矩形中轴的反射对称性进行检测，对称的射线保持原色，不对称的射线标记为黄色。

**输入结构**：约 15x19 的黑(0)背景网格。中央有一个约 5x7 的双色矩形：外层色为红(2)（覆盖四边外一圈像素），内层色为绿(3)（填充内部）。矩形的宽度（列数）为奇数以保证存在唯一垂直中轴线。矩形边缘有 4~6 个叶状突起（内层色绿(3)单像素，从外层色边缘伸出），分布不关于矩形垂直中轴对称——即左侧和右侧的突起数量或行位置不完全镜像。生成约束：(a) 至少有一对突起关于中轴对称（它们选定的行/列镜像对应）；(b) 至少有一个突起在中轴另一侧没有对应突起；(c) 突起只出现在矩形的左右两条垂直边上（简化为只选行），不出现在上下边。

**规则**：
1. 识别叶状突起：矩形外边缘伸出的绿(3)单像素。由于所有突起在左右垂直边上，每个突起选定其所在行。
2. 对每个选定的行，在矩形内部将该行的所有绿(3)像素重涂为红(2)（外层色切割）。在矩形外部，沿该行向左右两侧延伸至网格边缘，延伸像素涂为绿(3)（内层色延伸）。
3. 确定矩形的垂直中轴线（矩形水平中心列）。
4. 对每个延伸射线像素（矩形外部的绿(3)像素），检查其关于垂直中轴线的镜像位置是否也有延伸射线像素。若有，该像素保持绿(3)。若没有（即该侧有射线但镜像侧没有对应射线），该像素重涂为黄(4)。
5. 矩形内部（包括被切割的行）和突起像素保持不变。背景黑(0)像素保持不变。

**关键洞察**：左侧和右侧的叶状突起分布不对称导致延伸射线在两侧的行位置不同。有对称配对的射线行保持绿色，仅出现在一侧的射线行变黄——黄色标记精确指出了突起分布中的不对称成分。求解者必须先完成射线延伸，才能进行对称检测；单看突起分布无法直接预测哪些行的延伸会变黄（因为突起的选行规则和对称检测的基准都需要从示例中归纳）。
