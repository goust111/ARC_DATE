## 新题 4：流动轨迹的周期裁剪

**组合逻辑**：[流动绘制(flow_draw)](保留原始偏移机制) + [裁剪(crop)](创新：裁剪宽度不是预设的，而是由流动轨迹呈现的最小重复周期决定) + [镜像(mirror)](创新：周期检测需考虑含反射的重复) → 流动产生轨迹图案 → 图案呈现周期性 → 裁剪最小周期单元

**来源原语**：流动绘制(flow_draw) + 边缘起点像素(edge_source_pixel) + 偏移控制像素(deflector_pixel) + 逐步偏移(step_deflection) + 对齐时偏移(deflect_when_aligned) ← f15e1fac；裁剪(crop) + 周期(period) + 最小周期含翻转(smallest_period_flipped) ← 2dee498d；镜像(mirror) ← 2dee498d

**依赖链**：边缘起点像素发射流 → 偏移控制像素使流弯折 → 弯折后的轨迹图案在水平方向上呈现含反射的周期性 → 检测最小周期宽度 → 裁剪输出左起第一个周期单元

从网格边缘发射的流经偏移后形成重复图案，输出该图案的最小重复单元（含反射判定）。

**输入结构**：一个 6x24（高x宽）的黑(0)背景网格。左边缘上有 3~5 个青(8)像素（不相邻），沿左边缘的不同行分布。上边缘有若干红(2)像素（4~8 个），沿上边缘的不同列分布，且红像素的分布经过精心设计使其呈现以某个宽度 W 为周期的重复模式（可能含左右镜像）。生成约束：W 整除网格宽度；红像素在宽度方向上以 W 为周期排列（相邻周期可以是原样或水平翻转）；至少存在一个反射周期使得最小周期不等于整个网格宽度。

**规则**：
1. 从每个左边缘的青(8)像素出发，向右逐格前进（流动方向为从左到右）。
2. 每前进一格，检查当前所到列上是否有红(2)像素在上边缘。若有，则射线在当前位置向下偏移一格（远离上边缘），然后继续向右前进。
3. 所有射线路径用青(8)绘制在网格上，红(2)像素保持不变。
4. 对完成后的整个网格图案进行水平周期检测：从左起尝试候选周期宽度 W = 1, 2, 3, ...，对每个 W 检查每一块宽为 W 的列带是否是第一块列带的原样副本或左右镜像副本。选取最小的满足条件的 W。
5. 输出左起第一个宽为 W 的列带（高度不变），即整个网格高度 x W 宽度的子网格。

**关键洞察**：红像素的排布暗含周期性，但这一周期性只有在流动轨迹绘制完成后才能清晰观察到——直接看红像素的排列不一定能直接读出周期，因为流动偏移会放大或扭曲周期图案。求解者需要先完成流动模拟，再对结果进行周期分析。

2. `generate_input()` 必须随机生成多样样例，不能固定死。随机维度应覆盖：网格大小、对象数量、位置、颜色、方向、形状参数或关键分支。注意若描述中存在若干，需实现而不是只有单个，包括object或者对应关系等等。且若涉及到最短路径，则输入网格中必涉及到多条路径，对选择造成干扰。

6. 若规则有多个分支，生成器不能长期固定成一个分支；应让分支在随机样例中合理出现。分支概率不必平均——难以发现的隐蔽分支（如少数情况下才触发的特殊规则）应适当提高出现概率，确保在 3 个训练示例中至少出现一次，否则求解者无法归纳该规则。对于颜色映射类规则，确保 2 个左右的示例即可覆盖所有映射关系（每种颜色→颜色的映射至少在某个示例中出现过）。
