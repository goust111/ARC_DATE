## 新题 5：象限旋转选择器放置

**组合逻辑**：[复制放置(copy_place)](保留颜色索引匹配) + [旋转(rotate)](创新：旋转角度不由单独标记决定，而是由放置目标象限位置隐式编码) + [拼接+边框(concatenate+frame)](创新：最终结果加边框封装) → 象限位置同时决定"放在哪里"和"旋转多少度"

**来源原语**：复制放置(copy_place) + 选择器块(selector_block) + 颜色索引匹配(color_index_matching) + 图例位置映射(legend_position_mapping) + 象限(quadrant) ← 7d18a6fb；旋转(rotate) ← 412b6263；边框(frame) + 副本堆叠(copy_stacking) ← 412b6263；象限排布(quadrant_layout) ← 67e8384a

**依赖链**：选择器块中标记像素的象限位置 → 确定目标象限 + 该象限的旋转角度 → 找到同色外部精灵体 → 旋转后放入对应象限 → 整体加蓝色边框

选择器块的四个象限标记同时编码了放置位置和旋转角度，每个精灵体被不同角度旋转后放入对应象限。

**输入结构**：约 18x18 的黑(0)背景网格。网格中有一个 7x7 的选择器块，其主体色为栗(9)，四个 3x3 象限的中心各有一个不同颜色的标记像素（从红(2)、绿(3)、黄(4)、品红(6)中选取四种）。选择器块外散布 4 个精灵体，每个精灵体为单色 8-连通图形，边界框为 3x3，颜色分别与四个标记像素一一对应。每个精灵体在 3x3 边界框内是非对称的（即旋转 90/180/270 度后图案不同）。生成约束：每个精灵体在其 3x3 边界框内至少有 4 个像素、至多 7 个像素，且四次旋转产生四个不同图案。

**规则**：
1. 识别选择器块中四个标记像素的位置。左上象限中心、右上象限中心、左下象限中心、右下象限中心。
2. 旋转角度由象限位置决定：左上 = 0 度（不旋转）、右上 = 顺时针 90 度、右下 = 顺时针 180 度、左下 = 顺时针 270 度。
3. 对每个标记像素颜色，在外部找到同色精灵体，将其按步骤 2 确定的角度旋转。
4. 构建 7x7 黑(0)画布，分为四个 3x3 象限（由中间行和中间列分隔，分隔行列填充黑(0)）。将旋转后的精灵体放入对应象限。
5. 在 7x7 画布外加一圈蓝(1)边框（一像素宽），最终输出为 9x9。

**关键洞察**：象限位置承担双重角色——它既是放置目标（与参考题 7d18a6fb 相同），又隐式编码了旋转变换（参考题中不存在的新关系）。求解者只看一个示例可能将旋转误判为其他变换，必须对比多个示例（不同精灵体形状）才能归纳出"象限即旋转角度"的隐蔽映射规则。
