## 新题 2：叶状突起定向射线的逐步偏移

**组合逻辑**：[射线延伸(ray_extend)](创新：射线的起源不是矩形边界而是叶状突起所选定的行列) + [流动绘制中的逐步偏移(step_deflection)](创新：偏移控制不是边缘像素而是散布在网格中的障碍像素) → 突起确定射线存在性，障碍确定射线路径形变

**来源原语**：射线延伸(ray_extend) ← 6ffe8f07；叶状突起(leaf_protrusion) + 突起定行列(leaf_selects_row_col) ← f1cefba8；逐步偏移(step_deflection) + 对齐时偏移(deflect_when_aligned) ← f15e1fac；障碍对象(blocker_object) + 射线遇障停止(ray_stops_at_block) ← 6ffe8f07；双色矩形(bicolor_rectangle) ← f1cefba8

**依赖链**：叶状突起从双色矩形伸出 → 每个突起选定一行或一列 → 在选定行/列上向矩形外双向发射射线 → 射线在前进过程中遇到蓝(1)偏移像素时发生垂直偏移 → 偏移后射线继续前进直到出界或撞上另一条射线的轨迹

在双色矩形的叶状突起所定义的行列上发射射线，射线沿途被散布的蓝色偏移像素逐步弯折，最终形成阶梯状路径网络。

**输入结构**：约 20x20 的黑(0)背景网格。中央有一个约 6x8 的双色实心矩形：外层颜色（如红(2)）填充四条边的外一圈，内层颜色（如绿(3)）填充内部。矩形的外边缘上有 3~5 个单像素的内层色突起——每个突起从外层色边缘向外伸出一格，且其唯一的同色邻居在矩形内部（水平突起的同色邻居在左或右，垂直突起的同色邻居在上或下）。网格中散布 4~8 个蓝(1)像素作为偏移控制点，这些蓝像素不在矩形上也不与突起相邻。生成约束：不同突起选定的行列互不重复；蓝像素的分布保证每条射线至少经历一次偏移。

**规则**：
1. 识别叶状突起：矩形外边缘伸出的内层色单像素。若突起的唯一同色邻居在其上方或下方，则该突起选定其所在列；若在左方或右方，则选定其所在行。
2. 从每个突起出发，沿选定的行或列向矩形外侧双向发射射线（用黄(4)绘制路径）。射线每前进一格时检查：当前行/列上是否存在蓝(1)像素与射线在垂直方向上对齐（即若射线沿行前进，检查射线当前所在列是否有蓝像素；若沿列前进，检查当前所在行是否有蓝像素）。
3. 若对齐，射线在当前位置向远离该蓝像素的方向偏移一格（若蓝像素在射线上方，射线向下偏移一格；若在下方，向上偏移；左右同理），然后继续沿原方向前进。
4. 射线在以下情况停止：(a) 到达网格边界；(b) 下一格已被另一条射线的黄(4)路径占据。
5. 矩形本身保持原样（包括突起），背景保持黑(0)，蓝(1)偏移像素保持不变。

**关键洞察**：射线的最终路径不是直线而是阶梯形——叶状突起决定了哪些射线存在，而蓝像素的位置决定了射线如何弯折。必须同时理解突起选择规则和偏移规则才能重建完整输出；单独理解任一规则都不足以确定最终路径网络。
