## 新题 3：计数筛选后的尺寸匹配嵌入

**组合逻辑**：[计数(count)](创新：计数结果不直接映射尺寸，而是用作筛选阈值) + [嵌入填充(inlay_fill)](创新：不是所有精灵体都被放入，只有通过计数筛选的才被使用) → 计数产生筛选条件，筛选后的精灵体集合决定哪些空腔被填充

**来源原语**：计数(count) + 计数映射尺寸(count_maps_to_size) ← 878187ab；嵌入填充(inlay_fill) + 尺寸匹配(size_matching) + 唯一槽位配对(unique_slot_pairing) ← 5dbc8537；标记像素(marker_pixel) ← 878187ab / 56ff96f3；模板框架(template_frame) + 矩形空腔(rectangular_cavity) + 精灵体(sprite) ← 5dbc8537

**依赖链**：两种标记色的像素计数 → 较小计数 A 和较大计数 B 构成面积范围 [A, B] → 精灵体按面积筛选 → 通过筛选的精灵体与空腔按尺寸匹配 → 匹配成功则嵌入，否则空腔留空

统计两种标记色的像素数量得到一个面积区间，只有面积落入该区间的外部精灵体才有资格被放入模板空腔。

**输入结构**：约 20x20 的黑(0)背景网格。网格中有一个用品红(6)绘制的大型连通模板框架（约 12x14），框架内部有 4~6 个不同尺寸的矩形空腔（空腔内为黑(0)背景）。框架外部散布 4~6 个彩色小精灵体（每个精灵体是单色 4-连通图形，3~12 像素不等，形状各异但边界框为矩形），每个精灵体颜色互不相同（如红(2)、绿(3)、蓝(1)、黄(4)等）。此外，网格角落区域散布若干橙(7)标记像素和若干青(8)标记像素，总数各 3~8 个不等。生成约束：(a) 精灵体数量大于空腔数量；(b) 面积筛选后恰好有与空腔数量相同的精灵体通过；(c) 通过筛选的每个精灵体的边界框尺寸恰好匹配一个空腔，且无两个通过筛选的精灵体匹配同一空腔。

**规则**：
1. 计数所有橙(7)标记像素得到数值 A，计数所有青(8)标记像素得到数值 B。令 lo = min(A, B)，hi = max(A, B)。
2. 计算每个外部精灵体的面积（像素数）。只保留面积在 [lo, hi]（含端点）范围内的精灵体，其余精灵体被排除。
3. 对每个保留的精灵体，计算其边界框尺寸（高 x 宽）。将其与模板内的空腔按尺寸一一匹配（高和宽完全相同，或旋转 90 度后相同）。
4. 将匹配成功的精灵体放入对应空腔。若需旋转 90 度才能匹配，则旋转后放入。精灵体放入时左上角与空腔左上角对齐。
5. 无匹配精灵体的空腔保持黑(0)背景不变。
6. 输出为模板框架的边界框区域（包含框架和所有已填充/未填充的空腔），裁去框架外部的一切。

**关键洞察**：标记像素的颜色和数量本身不参与任何空间操作——它们纯粹是数值编码，产生一个过滤器来决定哪些精灵体有资格参与嵌入。求解者必须先理解"计数产生阈值"这一隐蔽规则，才能解释为何某些精灵体被放入而另一些被忽略。
