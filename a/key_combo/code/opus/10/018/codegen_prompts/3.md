## 新题 3：二面体等价分组决定滑动方向

**组合逻辑**：[形状匹配 + 旋转翻转等价](已有) → [滑动](创新改造：滑动方向不由缺口决定，而由等价类序号决定) ← [边缘图例](创新改造：图例不编码表格顺序，而编码方向映射)

**来源原语**：形状匹配/旋转翻转等价/归一化掩码(6165ea8f)、滑动(1e0a9b12/320afe60)、边缘图例(6165ea8f)、重涂色(recolor)

**依赖链**：二面体等价分组 → 每组获得一个等价类序号 → 边缘图例将序号映射到方向 → 对象按分配的方向滑动至边界 → 碰撞时保持不重叠。无形状匹配则无法分组，无图例则方向不确定，无滑动则无空间变换。三者形成三角依赖。

多个不同朝向的小对象按形状等价性分组，每组从边缘图例读取一个滑动方向，所有同组对象沿该方向滑至网格边缘。

**输入结构**：约 15x15 的网格，黑(0)背景。散布 6~8 个单色小对象（4-连通，3~6 像素），使用蓝(1)，它们的朝向各异但形状可分为 2~3 个二面体等价类（即旋转或翻转后形状相同的归为一类）。最上行放置 2~3 个单像素标记，从左到右依次为红(2)、绿(3)、黄(4)（数量与等价类数相同），表示方向映射：第 1 个标记色 = 向下滑，第 2 个标记色 = 向右滑，第 3 个标记色 = 向左滑。生成约束：对象间间隔足够，滑动后不相互重叠；每个等价类至少包含 2 个对象。

**规则**：
1. 将所有蓝(1)对象按 4-连通提取，对每个对象计算其归一化掩码（紧凑边界框内的像素模式）。
2. 将归一化掩码在二面体群（4 次旋转 x 2 次翻转）下等价的对象归为同一类。
3. 按每个等价类中边界框左上角行列最小的成员的位置排序，确定第 1、第 2、第 3 等价类。
4. 读取最上行的标记像素从左到右的顺序：第 1 个位置对应"向下"，第 2 个位置对应"向右"，第 3 个位置对应"向左"。将第 k 个等价类分配第 k 个方向。
5. 每个对象沿其等价类对应的方向整体平移，直到对象的前沿像素抵达网格边界（距边界 0 行/列），保持形状不变。同方向滑动的多个对象按离目标边界近的先放置，后续对象不与已放置对象重叠（遇到已放置对象则紧贴其前方停下）。
6. 滑动后，所有对象重涂为其等价类对应的标记颜色：第 1 类涂红(2)、第 2 类涂绿(3)、第 3 类涂黄(4)。

**关键洞察**：对象的朝向是干扰项——必须通过二面体等价归并才能确定组别，而组别又决定了运动方向和最终颜色，三者环环相扣。

## 实现要求

1. `main(grid)` 必须实现新题描述中的确定性转换规则，不能只识别 `generate_input()` 的固定模板。禁止不同的input网格输出相同的output网格。
2. `generate_input()` 必须随机生成多样样例，不能固定死。随机维度应覆盖：网格大小、对象数量、位置、颜色、方向、形状参数或关键分支。注意若描述中存在若干，需实现而不是只有单个，包括object或者对应关系等等。且若涉及到最短路径，则输入网格中必涉及到多条路径，对选择造成干扰。
3. 生成器必须保证输入满足 `main()` 的隐式假设：对象不重叠、不越界、特殊标记唯一或可区分、匹配关系无歧义、关键分支出现概率相同。
4. 禁止把 ARC 颜色 id 、亮度、拼写等当作人类不可见的数值语义参与排序、大小比较或隐藏映射。颜色变化必须有可见结构线索。注意颜色亮度、拼写等也是不可见信息，若描述中出现违规的颜色id或者亮度，可自行使用少量的固定颜色替代，但注意生成时要在三个以内输入输出网格中对所有变换100%覆盖度。

6. 若规则有多个分支，生成器不能长期固定成一个分支；应让分支在随机样例中合理出现。分支概率不必平均——难以发现的隐蔽分支（如少数情况下才触发的特殊规则）应适当提高出现概率，确保在 3 个训练示例中至少出现一次，否则求解者无法归纳该规则。对于颜色映射类规则，确保 2 个左右的示例即可覆盖所有映射关系（每种颜色→颜色的映射至少在某个示例中出现过）。
