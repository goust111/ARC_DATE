## 新题 10：阻挡点发射正交线后封闭区域的奇偶位筛选填充

**组合逻辑**：[对角线对齐 + 射线延伸 + 阻挡点发射正交线](已有) → [封闭区域检测](创新：射线交叉产生的封闭区域，类比容器) → [交替选取 + 填充](创新改造：按扫描序对封闭区域编号，奇偶位决定是否填充)

**来源原语**：对角线对齐/射线延伸/对角线上阻挡/阻挡点发射正交线(55783887)、容器/填充(db7260a4)、交替选取/奇偶位决定涂色(d406998b)

**依赖链**：主对角线绘制 → 阻挡点发射正交对角线 → 多条线交叉形成封闭区域 → 对封闭区域按行优先扫描编号 → 奇数位区域填充。无射线则无分割，无阻挡点则无正交线，无封闭区域则无填充目标，无奇偶筛选则全部填充。

一条主对角线上的阻挡点发射垂直对角线，射线交叉后围成若干封闭区域，按扫描序每隔一个区域填充一次。

**输入结构**：约 13x13 的网格，黑(0)背景。有一对蓝(1)标记像素位于同一条右下对角线的两端（如左上角和右下角附近）。在该对角线路径上有 2~3 个红(2)阻挡像素。生成约束：阻挡点之间间距至少 3 格；阻挡点发射的垂直对角线在网格内交叉，形成至少 4 个完全封闭的（被线段和网格边界围成的）4-连通背景区域。

**规则**：
1. 在两个蓝(1)端点之间绘制完整的右下对角线，颜色为蓝(1)。红(2)阻挡像素保留在对角线上不被覆盖。
2. 每个红(2)阻挡像素向两个垂直对角方向（左下和右上）发射红(2)射线，射线延伸直到到达网格边界，不覆盖已有的蓝(1)或红(2)像素（遇到则停止，不含终点）。
3. 所有射线绘制完毕后，识别网格中所有被线段像素和网格边界完全围成的 4-连通背景区域（封闭区域）。
4. 按行优先顺序（先按区域最小行号升序，同行按最小列号升序）对封闭区域编号：1, 2, 3, 4, ...。
5. 将编号为奇数（1, 3, 5, ...）的封闭区域填充为绿(3)。偶数编号的封闭区域保持黑(0)。
6. 所有线段像素（蓝和红）保留不变。

**关键洞察**：封闭区域的数量和形状完全由阻挡点的位置决定——移动一个阻挡点就会改变射线交叉的几何关系，从而改变封闭区域的划分和奇偶编号，使得填充模式发生全局变化。
