## 新题 1：重力沉降中的障碍绕行与方位涂色

**组合逻辑**：[重力沉降](已有) + [遇障碍则绕行](创新改造：从向上寻路改为向下重力场景) → [方位决定颜色](创新改造：绕行方向决定最终涂色)

**来源原语**：重力沉降(1e0a9b12)、遇障碍则绕行(d9f24cd1)、方位决定颜色(d364b489)、前景像素(1e0a9b12)、障碍像素(d9f24cd1)

**依赖链**：重力沉降驱动像素下落 → 障碍像素阻断垂直路径，迫使像素向一侧绕行 → 绕行方向（左/右）决定像素的最终颜色。若无重力则无下落，若无障碍则无绕行，若无方位涂色则绕行信息不可观测。

各列顶部散布的彩色像素在重力作用下下落，遇到固定灰色障碍时向空间更宽的一侧绕行一步后继续下落，最终根据绕行方向改变颜色。

**输入结构**：约 12x10 的网格，黑(0)背景。顶部若干行散布蓝(1)前景像素（每列至多一个）。网格中部散布灰(5)障碍像素（每个障碍像素左右至少有一侧的同行相邻格为空）。底部无障碍。生成约束：每个蓝像素的下落路径上至多遇到一个障碍；障碍左右两侧到最近已占用格或边界的距离不相等（确保绕行方向唯一）。

**规则**：
1. 对每个蓝(1)像素，沿其所在列逐步向下移动。
2. 若下一行同列为灰(5)障碍，检查障碍所在行中该障碍左侧和右侧到最近非背景像素或网格边界的连续空格数。像素向空格数更多的一侧水平移动一格，然后继续向下移动。
3. 像素移动直到抵达底行或下方已有非背景像素为止，在终点停留。
4. 未遇到障碍的像素保持蓝(1)不变。绕行向左的像素涂为红(2)，绕行向右的像素涂为绿(3)。灰(5)障碍像素在输出中保留。

**关键洞察**：绕行方向不是固定规则，而是由障碍周围的局部空间分布动态决定——必须比较障碍两侧的可用空间才能推断颜色。
