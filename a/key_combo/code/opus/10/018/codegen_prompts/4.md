## 新题 4：十字分割去噪后少数派像素数驱动线段发射

**组合逻辑**：[十字分隔线 + 去噪取主色](已有) → [像素数决定长度](创新改造：少数派像素数而非内部对象面积决定长度) → [方位对应](创新改造：象限位置决定线段发射方向)

**来源原语**：十字分隔线/四象限/去噪取主色(996ec1f3)、像素数决定长度(c61be7dc)、方位对应/direction_correspondence(d364b489)、压缩(996ec1f3)

**依赖链**：十字分隔确定四个象限 → 去噪得到主色和噪声像素 → 噪声像素计数变为线段长度 → 象限方位决定线段从中心发射的方向。去噪和计数不可分（噪声定义依赖主色判断），方位和线段不可分（线段无方向则放置不唯一）。

一个被十字线分割的四象限网格，每个象限去噪后，从中心向该象限方向发射一条线段，长度等于该象限的噪声像素数。

**输入结构**：约 13x13 的网格。有一整行和一整列由灰(5)像素构成的十字分隔线，将网格分为四个非空矩形象限。每个象限有一种唯一主色（从红(2)、绿(3)、黄(4)、蓝(1)中选），另有少量散布的其他颜色像素作为噪声（每个象限 1~4 个噪声像素）。生成约束：四个象限主色互不相同；各象限噪声像素数互不相同（便于区分）。

**规则**：
1. 找到网格中唯一的纯灰(5)行和纯灰(5)列，它们的交点为中心点。
2. 对每个象限，统计各颜色的像素数，出现最多的为主色，其余为噪声。记录噪声像素总数 n。
3. 输出为 (2*max_n+1) x (2*max_n+1) 的网格（max_n 为四个象限中噪声像素数的最大值），黑(0)背景，中心像素为灰(5)。
4. 从中心像素出发，向左上方延伸一条线段，长度等于左上象限的噪声像素数 n_LU，颜色为左上象限的主色；线段沿对角线方向（每步行-1、列-1）绘制。
5. 类似地：右上象限 → 向右上方延伸（行-1、列+1），长度 n_RU，颜色为右上主色；左下象限 → 向左下方延伸（行+1、列-1），长度 n_LD；右下象限 → 向右下方延伸（行+1、列+1），长度 n_RD。
6. 中心灰(5)像素保留。

**关键洞察**：输出的几何形状（四条不等长对角线）完全由输入中各象限"隐藏"的噪声数量编码——必须先完成去噪才能推出线段长度，而线段方向由象限空间位置隐式决定。
