## 新题 6：对角线奇偶筛选生成模板碎片并补全

**组合逻辑**：[对角线段 + 奇偶交替涂色](创新改造：奇偶位不是涂色而是筛选，偶数位像素组成碎片) → [碎片锚定放置位 + 补全](已有) ← [模板精灵体](已有)

**来源原语**：对角线段/序列索引/奇偶交替涂色(a5f85a15)、模板精灵体/碎片/碎片锚定放置位/补全(fd096ab6)、平移对齐(fd096ab6)、擦除(db7260a4)

**依赖链**：对角线中偶数位像素 → 构成碎片 → 与模板比对确定平移偏移 → 补全缺失像素。若无奇偶筛选，碎片形状错误导致匹配失败；若无模板，不知道补全成什么；若无补全，碎片残缺无意义。奇偶筛选是生成碎片的唯一途径，是独特的耦合点。

对角线段中交替提取的像素构成一个模板的部分碎片，根据模板补全缺失像素后擦除原始对角线的剩余部分。

**输入结构**：约 12x12 的网格，黑(0)背景。包含一个由灰(5)像素组成的完整模板精灵体（4-连通，6~10 像素，形状不规则，位于网格某个区域）。另有 2~3 条由不同颜色构成的右下对角线段（每条用一种颜色，如红(2)、绿(3)、蓝(1)），每条对角线段 4~8 像素长。生成约束：每条对角线段的偶数位像素（第 0、2、4、...个，从左上端计）恰好与模板在某个平移位置的部分像素重合；不同颜色对角线对应模板的不同平移位置；模板的各平移副本之间不重叠。

**规则**：
1. 识别灰(5)模板精灵体，提取其紧凑掩码。
2. 对每条非灰的对角线段（同色 4-连通像素沿右下对角方向排列），按从左上到右下的顺序编号 0, 1, 2, ...。保留偶数位像素（第 0、2、4 ...个），将这些像素视为该颜色的"碎片"。
3. 对每个碎片，找到唯一的平移偏移使得碎片像素全部落在模板掩码的对应位置上。
4. 以该偏移放置模板的完整副本，用碎片的颜色绘制模板掩码中所有像素位置（包括碎片已有的和缺失的）。
5. 擦除每条对角线段中奇数位像素（恢复为背景色）。灰(5)模板本身保留不变。

**关键洞察**：对角线段本身不是碎片——必须先通过奇偶位筛选去掉"干扰像素"，剩余像素才构成可与模板匹配的空间碎片。
