## 新题 5：射线命中触发链式替换

**组合逻辑**：[射线延伸/projectile_fire](原有) + [重涂色/recolor](原有：链式替换规则) + [朝向编码方向/orientation_encodes_direction](原有)

**来源原语**：射线延伸、三角精灵体、朝向编码方向、碰撞变色规则（409aa875）；重涂色、双列图例、图例行序决定替换、逐行顺序链式替换（e4888269）

**依赖链**：三角朝向确定射线方向 → 射线轨迹决定命中目标 → 命中次数和先后顺序决定链式替换的执行轮数 → 图例链式替换规则决定最终颜色

一句话总结：三角精灵体发射射线命中其他对象，每次命中触发一轮图例链式颜色替换，多次命中则多轮替换叠加。

**输入结构**：约 14x14 网格，黑(0)背景。包含：
- 4~6 个三像素 L 形精灵体，每个由 3 个像素占据 2x2 区域中的三格，颜色各不相同（使用蓝(1)、红(2)、绿(3)、黄(4)、品红(6)、橙(7)中的若干种）。各精灵体彼此间保持足够距离（至少 3 格间距），沿行或列大致对齐，使射线可命中。
- 一个 2 列 N 行的竖直双列图例，位于网格右下角，以灰(5)像素为边框包围。图例每行左列为源色、右列为目标色，共 3~4 行。图例不参与射线交互。
- 生成约束：至少有一个精灵体被恰好一条射线命中，另一个被恰好两条射线命中（以验证多轮替换效果）；图例中至少存在一组链式映射（如蓝→红出现在红→绿之前，使得蓝经一轮变红、经两轮变绿）；图例本身不在任何射线路径上。

**规则**：
1. 对每个 L 形精灵体，确定其缺角方向，据此得到发射方向（朝缺角的对角方向发射——即偏离实体部分的方向）。射线从精灵体的顶点像素出发，沿发射方向逐格延伸，直到碰到另一个精灵体的任意像素或到达网格边界为止。射线路径上的像素不改变颜色（射线不可见）。
2. 记录每个精灵体被命中的次数 k 和命中它的各条射线的来源距离（从射手顶点到被命中精灵体的曼哈顿距离）。
3. 对每个被命中的精灵体，按来源距离从近到远的顺序依次执行 k 轮链式替换。每轮替换：取精灵体当前颜色 c，从图例第一行到最后一行扫描——每当 c 等于该行左列颜色时，将 c 更新为右列颜色，继续向下扫描后续行（一轮内可多次更新）。一轮结束后 c 即为该轮替换的结果，作为下一轮的输入。
4. 将被命中精灵体的所有 3 个像素涂为最终颜色。未被命中的精灵体保持原色。图例保持不变。

**关键洞察**：命中次数不同导致链式替换执行不同轮数，同一初始颜色经一轮和两轮替换可到达不同的最终颜色。求解者必须同时推断射线方向规则、命中判定，以及图例的链式（而非单步）替换语义，三者缺一不可。
