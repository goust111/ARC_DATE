## 新题 1：缺口编码镜像轴与叠加不对称检测

**组合逻辑**：[缺口方向](创新：从射线方向改为编码镜像轴) + [镜像] + [逐像素比较/叠加](创新：原图与镜像图叠加分类) + [重涂色]

**来源原语**：缺口方向决定射线(551d5bf1) + 镜像(62c24649) + 逐像素比较(94f9d214) + 重涂色(9473c6fb)

**依赖链**：缺口位置决定镜像轴的选择 → 镜像操作生成对照图 → 原图与对照图逐像素比较产生三类像素 → 分类结果决定最终涂色。删除缺口检测则无法确定镜像轴；删除比较则无法区分对称与非对称区域。

将每个带缺口框架的内部图案沿缺口所指方向的垂直轴镜像，然后与原图案叠加，将像素按对称性分为三类并分别涂色。

**输入结构**：约 20x20 的网格，黑(0)背景。包含 2~3 个蓝(1)空心矩形框（边框宽 1 像素，每个框约 6x6 至 8x8），每个框恰好有一个边框缺口（某条边上缺少一个非角像素）。每个框内部包含一个由红(2)像素组成的不规则非对称 4-连通图案（3~7 像素）。不同示例中，缺口可能在框的上、下、左、右任一侧；内部图案的具体形状各不相同但均为非对称。各框互不相邻，间距至少 2 像素。生成约束：每个框的内部图案关于缺口所决定的镜像轴不完全对称（至少有一个像素不对称），以确保三类像素都存在。

**规则**：
1. 对每个蓝(1)框，定位其唯一的边框缺口像素位置。缺口在上边或下边 → 该框的镜像轴为水平轴（即沿框内部区域的水平中线上下翻转）；缺口在左边或右边 → 镜像轴为垂直轴（沿框内部区域的垂直中线左右翻转）。
2. 将框内部区域（不含边框本身）沿确定的轴做镜像，生成一个同尺寸的对照图案。
3. 逐像素比较原图案与对照图案：
   - 两者都是红(2)（即该位置关于镜像轴对称地存在前景）→ 保持红(2)不变。
   - 原图案为红(2)但对照为黑(0)（即该位置只在原图中有前景）→ 涂为绿(3)。
   - 原图案为黑(0)但对照为红(2)（即该位置只在镜像图中有前景）→ 涂为黄(4)。
   - 两者都是黑(0) → 保持黑(0)不变。
4. 修补缺口：将缺口位置的像素恢复为蓝(1)。
5. 蓝(1)边框像素和框外区域保持不变。

**关键洞察**：边框缺口不是需要修补的瑕疵，而是编码镜像轴方向的信号。输出中的三种颜色揭示了内部图案相对于缺口所编码轴的对称结构，这要求同时理解缺口的几何含义和叠加比较的逻辑。
