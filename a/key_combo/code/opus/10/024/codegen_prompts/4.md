## 新题 4：嵌套框深度驱动旋转

**组合逻辑**：[enclosure](检测同心嵌套框的层数) → [rotate/rotation_relation](层数决定旋转角度) + [recolor](最外层框色转移给精灵) + [crop/ordering](裁剪并按空间位置排列输出)

**来源原语**：enclosure、hollow_rectangle、enclosed_region、object_with_hole_selected（b9b7f026）；rotate、rotation_relation（a416fc5b, fc7cae8d）；recolor（多题）；crop（多题）；ordering（1bfc4729）

**依赖链**：嵌套框的拓扑结构（层数）编码旋转参数——不检测嵌套关系就无法确定旋转量。最外层框的颜色决定输出精灵的颜色——不识别最外层就无法涂色。各组在网格中的水平位置决定输出排列顺序。三个独立信息（层数、外框色、水平位置）必须从同一嵌套结构中同时提取。

统计同心嵌套框层数以确定精灵旋转角度，用最外层框色重涂精灵，按各组水平位置排列裁剪结果。

**输入结构**：一个约 20x20 的网格，黑(0) 背景。网格上有 3 组互不相邻的嵌套结构。每组由若干同心空心矩形框组成，框与框之间有 1 像素间隔。同一组内所有框使用同一种非黑颜色（不同组使用不同颜色，从蓝(1)、红(2)、绿(3)、黄(4) 中选取）。三组的嵌套层数分别为 1、2、3（顺序随机）。每组最内层框的内部放置一个灰(5) 色小精灵（4-连通单色图形，4~6 像素，非旋转对称——即 90 度旋转后与原图不同）。三组精灵形状相同（同一偏移集合）。生成约束：三组在水平方向上互不重叠（边界框的列范围不交叉）。

**规则**：
1. 识别所有非黑、非灰的 4-连通单色对象，按颜色分组。每组的多个同色空心矩形框构成一组同心嵌套结构。
2. 对每组嵌套结构，计算嵌套层数 D（空心框的个数）。
3. 提取最内层框内部的灰(5) 精灵，记录其像素相对于精灵边界框左上角的偏移。
4. 将精灵绕其边界框中心顺时针旋转 90° x D。具体地：D=1 旋转 90°，D=2 旋转 180°，D=3 旋转 270°。
5. 将旋转后的精灵重涂为该组框的颜色（即最外层框的颜色）。
6. 裁剪旋转后精灵的紧致边界框。
7. 将三组裁剪结果从左到右排列（按各组嵌套结构在输入中边界框最左列的从小到大顺序），相邻裁剪结果之间插入一列黑(0) 像素作为间隔。

**关键洞察**：嵌套层数不是选择标准（所有组都被处理），而是编码旋转参数的空间密码——框的层数越多旋转角度越大。精灵形状相同但旋转不同，迫使求解者从嵌套拓扑推断变换参数而非死记输出形状。

## 实现要求

1. `main(grid)` 必须实现新题描述中的确定性转换规则，不能只识别 `generate_input()` 的固定模板。禁止不同的input网格输出相同的output网格。
2. `generate_input()` 必须随机生成多样样例，不能固定死。随机维度应覆盖：网格大小、对象数量、位置、颜色、方向、形状参数或关键分支。注意若描述中存在若干，需实现而不是只有单个，包括object或者对应关系等等。且若涉及到最短路径，则输入网格中必涉及到多条路径，对选择造成干扰。
3. 生成器必须保证输入满足 `main()` 的隐式假设：对象不重叠、不越界、特殊标记唯一或可区分、匹配关系无歧义、关键分支出现概率相同。
4. 禁止把 ARC 颜色 id 、亮度、拼写等当作人类不可见的数值语义参与排序、大小比较或隐藏映射。颜色变化必须有可见结构线索。注意颜色亮度、拼写等也是不可见信息，若描述中出现违规的颜色id或者亮度，可自行使用少量的固定颜色替代，但注意生成时要在三个以内输入输出网格中对所有变换100%覆盖度。
5. 输出样例要视觉清晰，人类必须能从输入输出对中肉眼辨认出规律。具体要求：避免对象粘连、覆盖关系混乱、同一像素多重语义；不同逻辑步骤产生的结果不要大面积层叠在一起导致无法分辨哪个颜色属于哪个步骤；输入中各元素之间保持足够间距，输出中新增的标记/填充/路径等应与背景和已有元素在颜色上有明显区分；若规则涉及多层叠加，生成时控制对象密度和尺寸，确保叠加区域只占少数像素而非铺满整个网格。
6. 若规则有多个分支，生成器不能长期固定成一个分支；应让分支在随机样例中合理出现。分支概率不必平均——难以发现的隐蔽分支（如少数情况下才触发的特殊规则）应适当提高出现概率，确保在 3 个训练示例中至少出现一次，否则求解者无法归纳该规则。对于颜色映射类规则，确保 2 个左右的示例即可覆盖所有映射关系（每种颜色→颜色的映射至少在某个示例中出现过）。
7. 代码风格参考 `ARC_code`：使用 `numpy`，并把 `/home/lixinyu/snap/new/solvers/arc_utils.py` 作为公共参考工具箱，优先复用其中已经稳定的 bbox、连通域、裁剪、变换和颜色工具；目标文件必须能被 `SourceFileLoader` 直接加载。
