## 新题 5：射线可达性筛选目标矩形，面积排序决定保留或擦除

**组合逻辑**：[射线投射 ray_cast + 视线可达 line_of_sight](已有) → [筛选 filter](创新：筛选标准不是几何属性而是射线可达性) → [排序 sort + 按面积降序 largest_to_smallest_area](已有) → [重涂色 recolor / 擦除 erase](创新：排序名次映射到不同操作——保留、重涂、擦除三种分支)

**来源原语**：射线投射 ray_cast + 视线可达 line_of_sight + 可见行数最多 max_visible_rows + 忽略干扰项 ignore_distractors（参考题 #12 3d588dc9），排序 sort + 按面积降序 largest_to_smallest_area（参考题 #7 20818e16），筛选 filter + 最小尺寸过滤 minimum_size_filtering（参考题 #6 0a1d4ef5），重涂色 recolor（参考题 #4 4f537728），擦除 erase（参考题 #12 3d588dc9），填充矩形 filled_rectangle（参考题 #6 0a1d4ef5, #7 20818e16），源区域 source_region（参考题 #12 3d588dc9）

**依赖链**：源区域位置 → 射线可达性判定哪些矩形被"看见" → 被看见的矩形集合进入排序 → 排序名次决定操作类型（第 1 名保留、第 2 名重涂、其余擦除）。未被看见的矩形不参与排序，保持原样。删除射线环节则所有矩形都参与排序（结果不同）；删除排序则无法区分保留与擦除；删除分支操作则排序无意义。

从灰色源区域水平射出射线，仅射线可达的矩形参与面积排序；排序第一名保留原色，第二名重涂为灰色，其余擦除。

**输入结构**：黑(0)背景，约 20x18 网格。一个灰(5)源区域（约 2x3 的实心矩形）位于网格左侧或右侧。4~6 个单色实心矩形散布于网格中，每个矩形尺寸在 2x2 到 5x4 之间，颜色各不相同（选自蓝(1)、红(2)、绿(3)、黄(4)、橙(7)、品红(6)），矩形之间不重叠。另有 2~4 个单像素干扰点（栗(9)色），散布于网格中。生成约束：从源区域的每一行像素向左右两侧水平延伸射线时，至少有 2 个矩形可被射线直接到达（射线路径上只经过背景像素即到达矩形边缘），且至少有 1 个矩形被其他矩形遮挡而不可达；干扰点不阻挡射线（射线穿过干扰点继续延伸）。

**规则**：
1. 忽略所有栗(9)色单像素干扰点（它们不阻挡射线，不参与任何逻辑）。
2. 从灰(5)源区域的每一行像素出发，向左和向右发射水平射线。射线沿水平方向逐像素前进，遇到非背景、非干扰色的像素时停止（到达某个矩形的边缘）。
3. 一个矩形是"可达的"当且仅当存在至少一条射线到达了它的某个边缘像素。
4. 收集所有可达矩形，按面积（宽 x 高）从大到小排序。面积相同时，按矩形左上角行坐标升序排列。
5. 排序后：第 1 名矩形保持原色不变；第 2 名矩形整体重涂为灰(5)；第 3 名及之后的所有可达矩形擦除为黑(0)背景。
6. 不可达的矩形保持原色和原位不变。
7. 源区域保持灰(5)不变。干扰点擦除为背景色。

**关键洞察**：一个面积很大的矩形如果被另一个矩形完全挡住射线而不可达，它不参与排序因此保持原样——而一个面积较小但可达的矩形可能反而成为排序第一名被保留；求解者需要对比示例中矩形空间布局变化对可达性的影响来理解"可达"而非"存在"是排序的入场条件。
