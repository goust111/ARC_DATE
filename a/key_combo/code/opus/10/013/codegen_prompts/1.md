## 新题 1：标记计数驱动旋转，旋转后面积决定堆叠序

**组合逻辑**：[计数 counting](创新：计数结果不直接编码到输出，而是作为旋转参数) → [旋转 rotate](已有) → [排序 sort + 堆叠 stack](创新：排序依据是旋转后而非旋转前的面积)

**来源原语**：计数 counting（参考题 #2 794b24be, #8 6773b310），旋转 rotate（参考题 #16 11852cab, #18 fd4b2b02），排序 sort + 堆叠 stack + 角对齐 corner_aligned + 按面积降序 largest_to_smallest_area（参考题 #7 20818e16），标记像素 marker_pixel（参考题 #8 6773b310）

**依赖链**：标记像素的计数决定旋转次数 → 旋转改变非正方形图形的包围盒宽高比 → 旋转后的包围盒面积重新排列了堆叠顺序 → 堆叠时的遮挡关系依赖于该顺序。删除计数环节则旋转无据；删除旋转环节则排序退化为原始面积排序（与参考题 #7 相同）；删除排序堆叠则旋转无意义。

将散落的非正方形彩色图形按各自灰(5)标记像素数量旋转后，以旋转后包围盒面积降序堆叠于左上角。

**输入结构**：黑(0)背景，约 20x20 网格。散布 3-5 个互不重叠的单色 4-连通前景图形，每个图形使用不同的非黑非灰颜色（如红(2)、绿(3)、黄(4)、蓝(1)等），形状为非正方形的紧凑连通区域（3~8 像素，包围盒宽高不等）。每个图形旁边（4-邻域外一格处）有 0~3 个灰(5)像素作为标记，标记与其关联图形的距离最近（每个标记归属于距离其包围盒最近的那个图形）。生成约束：不同图形的标记区域互不混淆（每个灰像素与恰好一个图形最近）。

**规则**：
1. 将每个灰(5)标记像素归属于包围盒中心与其欧氏距离最近的图形（生成时保证归属无歧义）。
2. 统计每个图形关联的灰标记像素数量 N（0~3）。
3. 将每个图形以其包围盒中心为旋转中心，顺时针旋转 N x 90 度。旋转后重新计算其最小包围盒。
4. 以所有旋转后图形中最大的包围盒宽度为输出宽度、最大的包围盒高度为输出高度，创建黑(0)背景输出网格。
5. 按旋转后的包围盒面积从大到小排列图形（面积相同时，按图形在输入中包围盒左上角的行优先坐标升序排列）。
6. 依次将图形绘制到输出网格的左上角（0,0）对齐，后绘制的覆盖先绘制的。
7. 灰标记像素不出现在输出中。

**关键洞察**：同一图形旋转 0 度和 180 度包围盒相同，但旋转 90 度时宽高互换导致面积不变而形状改变——真正改变堆叠可见性的是宽高比翻转后的遮挡关系，而非面积本身；需要对比多个示例才能确认旋转参数来自标记计数而非其他属性。
