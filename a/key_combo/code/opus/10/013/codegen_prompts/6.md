## 新题 6：邻居计数同时决定放大倍率与对角标记条件

**组合逻辑**：[计数 counting](创新：计数对象是 4-邻域前景邻居数，且同一次计数同时产出全局参数和逐像素条件) → [像素放大 pixel_upscale](已有) → [连线 draw_line + 对角共线 diag_collinear](创新：标记条件由邻居数与全局最大值的比较决定，而非由背景/前景身份决定)

**来源原语**：像素放大 pixel_upscale + 连线 draw_line + 对角共线 diag_collinear + 共对角背景标记 bg_diag_marked（参考题 #1 f0afb749），计数 counting + 色数决定倍率 color_count_scale（参考题 #13 d4b1c2b1），前景像素 fg_pixel + 对角线标记 diag_marker（参考题 #1 f0afb749）

**依赖链**：全部前景像素的 4-邻域邻居计数 → 取全局最大值 M 作为放大倍率 → 每个前景像素放大为 MxM 块 → 邻居数 < M 的像素在其 MxM 块中仅绘制主对角线（而非实心块），邻居数 = M 的像素为实心块。全局参数和逐像素属性来自同一次计数运算，耦合于 M 的值：M 变化时既改变了输出尺寸，也改变了哪些像素获得对角标记。

统计每个前景像素的 4-连通前景邻居数，取最大值作为放大倍率；邻居数等于最大值的像素放大为实心块，其余放大为仅含主对角线的空心块。

**输入结构**：黑(0)背景，小网格（4x4 至 6x6）。前景像素 3~8 个，使用 1~3 种非黑颜色（如红(2)、绿(3)等），形成不规则的 4-连通图形。前景像素的 4-邻域前景邻居数范围在 1~4 之间，且不全相同（至少存在两种不同的邻居数）。生成约束：最大邻居数 M 在 2~4 之间（保证输出尺寸合理，即输出为 (M x 输入行数) x (M x 输入列数)）。

**规则**：
1. 对每个前景像素，计算其上下左右四个方向中有多少个相邻像素也是前景（不论颜色），得到该像素的邻居数 N_i。
2. 取所有前景像素邻居数的最大值 M。
3. 创建输出网格，高度 = M x 输入高度，宽度 = M x 输入宽度。
4. 将每个输入像素映射到输出中对应的 MxM 子块：
   - 背景像素(0)：MxM 子块全部为黑(0)。
   - 前景像素且 N_i = M：MxM 子块全部填为该像素的原色（实心块）。
   - 前景像素且 N_i < M：MxM 子块中仅主对角线位置（即子块内 (r, c) 满足 r = c 的像素，r 和 c 从 0 开始）填为蓝(1)，其余位置为黑(0)。
5. 无其他后处理。

**关键洞察**：放大倍率不是固定常数也不是颜色种类数，而是前景像素中邻居数的峰值——这意味着在输入中增减一个像素可能同时改变输出尺寸和对角标记模式；求解者需要对比多个示例中不同连通结构下的倍率变化才能发现"最大邻居数 = 倍率"这一编码关系。
