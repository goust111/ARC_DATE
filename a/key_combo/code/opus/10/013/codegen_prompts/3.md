## 新题 3：框内色彩多样性编码拉伸距离，标记方位编码拉伸方向

**组合逻辑**：[计数 counting](创新：计数对象是颜色种类数而非像素数) + [方向指示 direction_indication](创新：由外部标记像素的方位而非对象自身形态决定) → [拉伸 stretch](已有) → [重涂色 recolor + 内外分离 interior_exterior_sep](创新：拉伸后的新内部区域统一重涂)

**来源原语**：计数 counting + 色数决定倍率 color_count_scale（参考题 #13 d4b1c2b1），拉伸 stretch + 标记决定拉伸终点 marker_determines_stretch_endpoint（参考题 #5 b548a754），方向指示 direction_indication（参考题 #11 25d487eb），重涂色 recolor + 内外分离 interior_exterior_sep + 保留边框涂内部 keep_border_fill_inside（参考题 #20 50cb2852），空心矩形 hollow_rectangle（参考题 #5 b548a754），标记像素 marker_pixel（参考题 #5 b548a754）

**依赖链**：框内散布像素的颜色种类数 → 拉伸距离（非来自空间位置，而来自颜色信息）；标记像素相对框的方位 → 拉伸方向；拉伸改变框的几何形状 → 新的内外边界 → 重涂内部。删除色彩计数则拉伸距离无据；删除标记方位则拉伸方向无据；删除内外分离重涂则拉伸效果不完整。三路信息（距离、方向、涂色目标）汇聚到拉伸操作。

统计空心矩形内部散布像素的颜色种类数作为拉伸步长，按外部标记像素的方位拉伸框架，然后将拉伸后的完整内部重涂为标记色。

**输入结构**：黑(0)背景，约 18x18 网格。包含 2~3 个互不重叠的空心矩形框（每个框至少 5x5，边框为单一颜色如蓝(1)、绿(3)等，边框宽度 1 像素，内部为黑色背景）。每个框的内部散布若干彩色像素（1~4 种不同颜色，总共 2~6 个像素，颜色选自非边框色、非背景色、非标记色的可用色）。每个框外部恰好有 1 个标记像素，与该框的某一条边在行或列方向上对齐（即标记像素位于框的正上方、正下方、正左方或正右方，与框边的延长线上），距离框边 1~3 像素。标记像素的颜色为红(2)或黄(4)，与框的边框色不同。生成约束：每个框的标记像素方位各不相同；框内像素颜色种类数在 1~4 之间且各框不完全相同；拉伸后的框不超出网格边界且互不重叠。

**规则**：
1. 对每个空心矩形框，统计其内部（不含边框像素）所有非背景像素的颜色种类数 K。
2. 找到该框外部的标记像素，确定标记相对于框的方位（上、下、左、右）。
3. 将框的对应边沿标记方向向外平移 K 个像素，扩展框架：新边框用原框的边框颜色绘制，框的其他三条边保持原位。
4. 将拉伸后的框的完整内部区域（新边界以内、边框以外的所有像素）全部重涂为该框的标记像素颜色。原先框内部的散布像素被覆盖。
5. 移除标记像素（该位置如果在新边框上则为边框色，否则为背景色）。
6. 处理顺序：按框的包围盒面积从小到大处理；若拉伸后区域与后续框重叠，后处理的框覆盖先处理的框的像素。

**关键洞察**：框内部的散布像素不是装饰，而是通过颜色多样性编码了拉伸步长——像素的位置和数量无关紧要，只有颜色种类数起作用；需要对比多个示例中不同种类数与拉伸距离的对应关系才能发现这一非显然映射。
