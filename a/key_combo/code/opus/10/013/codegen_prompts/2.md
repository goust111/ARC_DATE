## 新题 2：对角射线划分区域，区域归属决定填色

**组合逻辑**：[射线延伸 ray_extend + 对角放射 diagonal_radiation](已有) → [网格分区 grid_partition](创新：分区边界由对角线交叉涌现而非预设分隔线) → [填充 fill](创新：填色由区域边界归属关系决定)

**来源原语**：射线延伸 ray_extend + 对角放射 diagonal_radiation + 延伸至边界 extend_to_edge（参考题 #17 ea786f4a），网格分区 grid_partition（参考题 #8 6773b310），填充 fill（参考题 #9 b0c4d837, #19 e9afcf9a），孤立像素 isolated_pixel（参考题 #17 ea786f4a）

**依赖链**：孤立像素的位置决定对角线的走向 → 对角线交叉涌现出区域边界（非预设分区） → 每个区域的边界射线归属决定填色 → 填色结果依赖于所有像素的射线布局（全局约束）。这是一个同时约束满足结构：所有射线必须先全部绘制，才能识别封闭区域，才能判断归属。

在均匀背景上放置若干彩色孤立像素，从每个像素发射四方向对角射线至边界；射线交叉将网格切分为多边形区域，仅被单一来源像素的射线包围的区域填为该像素颜色。

**输入结构**：橙(7)均匀背景，约 15x15 网格。2~3 个孤立前景像素，每个颜色不同（如红(2)、蓝(1)、绿(3)），彼此不在同一行、同一列或同一对角线上（保证射线不重合）。无其他前景元素。生成约束：像素位置使得对角射线在网格内部产生至少 2 个交叉点，形成足够的封闭区域。

**规则**：
1. 保留输入网格的全部内容。
2. 从每个孤立彩色像素出发，沿四个对角方向（左上、右上、左下、右下）逐像素绘制黑(0)射线，直到到达网格边界（包含边界像素）。射线覆盖原有背景色。
3. 射线将网格划分为若干 4-连通的非黑区域（每个区域内部不含黑像素）。
4. 对每个非黑区域，检查其边界（与该区域 4-相邻的所有黑像素）属于哪些来源像素的射线。若该区域的边界射线全部来自同一个来源像素，则将该区域所有像素重涂为该来源像素的颜色。
5. 若一个区域的边界射线来自 2 个及以上不同来源像素，则该区域保持橙(7)背景色不变。
6. 来源像素自身保持原色不变。射线交叉点处（同一像素被多条射线经过），该像素仍为黑(0)。

**关键洞察**：区域归属不取决于距离最近的来源像素，而取决于包围该区域的射线是否全部源自同一像素——一个几何上紧邻某像素的区域，如果它的边界包含了另一个远处像素的射线，就不会被填色；需要对比多个示例中像素位置变化导致的归属翻转才能归纳出此规则。
