## 新题 3：对称补全涌现杯形与射线发射

**组合逻辑**：[对称补全](已有) → [开口检测](创新：开口不是输入中预设的，而是对称补全后因原始碎片不完整而涌现的) → [填充+射线延伸](已有操作，但作用对象是涌现结构)

**来源原语**：对称补全(symmetry_completion) ← 4938f0c2；标记定义双轴镜像(marker_biaxial_mirror) ← 4938f0c2；标记方块(marker_square) ← 4938f0c2；填充(filling) ← d4f3cd78；射线延伸(ray_extend) ← d4f3cd78；开口朝向(opening_direction) ← d4f3cd78；从开口发射(emit_from_opening) ← d4f3cd78

**依赖链**：输入中仅有一个象限的半成品轮廓碎片加一个 2x2 标记方块；对称补全后，碎片扩展为近似矩形环但在某一侧因原始碎片本身缺口而形成开口——这个开口的位置和大小完全由碎片形态决定；接下来填充环内部并从开口向外延伸射线。对称补全的结果同时决定了填充区域和射线方向。

将标记方块周围的局部轮廓碎片做双轴镜像补全，补全后的环形轮廓因碎片原始缺口产生开口；填充环内部并从开口向外发射射线至网格边缘。

**输入结构**：黑(0)背景网格，约 15x15。网格中部有一个绿(3) 2x2 标记方块。在标记方块的一个象限（如左上）分布着红(2)像素构成的 L 形或阶梯形轮廓碎片（5~8 像素，4-连通，模拟矩形环的一角但在某一边有 1~2 格宽的缺口）。其余三个象限无红色像素。生成约束：碎片经双轴镜像后形成的红色环在恰好一个朝向上有连续缺口（即开口宽度 1~2 格），环内部为连通的黑色区域；开口不在对角线方向而在上/下/左/右某一侧；碎片中的缺口不位于镜像轴上（否则补全后缺口消失）。

**规则**：
1. 以绿(3) 2x2 标记方块的中心为对称中心，对每个红(2)像素分别做水平镜像、垂直镜像、180度旋转，在对应位置绘制红(2)像素（不覆盖绿色标记方块自身）。
2. 补全后的红色像素形成一个不完全封闭的环形轮廓。找到该环的边界框，检查边界框四条边上的红色像素分布：某一条边上存在连续的背景格间隙即为开口，记录开口朝向（上/下/左/右）和开口格位置。
3. 对环内部的黑(0)区域（边界框内、被红色像素 4-连通包围的背景区域，不含开口外侧）填充为黄(4)。
4. 从开口处的每个黄(4)格（开口行或列上与环内部相邻的格子）出发，沿开口朝向逐格绘制黄(4)，直到到达网格边缘。若路径上遇到非背景像素则停止该条射线（不覆盖该像素）。
5. 绿色标记方块保持不变。

**关键洞察**：开口并非输入直接给出，而是对称补全的涌现结果——碎片中偏离对称位置的缺口经四份复制后在环上形成一个朝向确定的开口；求解者必须先完成补全才能判断射线方向。
