## 新题 8：重力下落后跨度连线与障碍保护

**组合逻辑**：[重力下落](已有概念，创新应用：不是列延伸而是像素下落) + [连线/首尾跨度填充](已有) + [标记框内保护](创新：保护区不是标记像素定义的固定矩形，而是障碍像素周围的动态曼哈顿邻域)

**来源原语**：重力下落(gravity_drop) ← c87289bb 概念衍生；连线(connect) ← ded97339；首尾跨度填充(span_fill_between) ← ded97339；同行列对齐(row_col_aligned) ← ded97339；固定障碍(fixed_barrier) ← 9c56f360；靠近障碍停止(stop_at_barrier) ← 9c56f360；标记框内保护(marker_bbox_protect) ← d37a1ef5；内部区域(interior_region) ← d37a1ef5

**依赖链**：散布在网格上方的标记像素先做重力下落（向下掉到最低可用位置或障碍之上）；下落后的新位置决定了哪些像素在同一行/同一列，进而决定跨度连线的几何结构；但连线不得穿过障碍像素周围的保护区（障碍像素上下左右各 1 格），穿过保护区的连线段被截断。下落改变对齐关系→对齐关系决定连线→障碍保护区截断连线。

标记像素受重力下落后重新排布，在新位置之间按同行/同列关系做跨度连线，但连线不得进入障碍像素周围的保护区域。

**输入结构**：黑(0)背景网格，约 14x14 至 16x16。网格上半区（前 3~5 行）散布 4~6 个蓝(1)标记像素（各自孤立）。网格下半区有 2~3 个红(2)固定障碍像素（各自孤立，不在最底行）。标记像素和障碍像素均不在同一列上有多个（保证下落路径唯一）。生成约束：每个标记像素正下方到网格底边或最近障碍之间无其他标记像素；下落后至少有两个标记像素落在同一行且至少有两个落在同一列；至少一条潜在连线路径会穿过某个障碍的保护区（从而被截断）。

**规则**：
1. 对每个蓝(1)标记像素执行重力下落：该像素从当前位置向下逐格移动，直到遇到网格底边、另一个已落定的蓝色像素、或红(2)障碍像素的正上方一格位置（即不进入障碍所在格也不进入障碍正上方格——停在障碍上方第 2 格）。不对——简化规则：标记像素向下移动直到下一格是网格边界外、红(2)障碍像素、或已有非背景像素，停在当前格。处理顺序：按初始行号从大到小（最低的先落）。
2. 所有标记像素落定后，构建保护区：每个红(2)障碍像素的上下左右各 1 格（4 格邻域，若越界则忽略）标记为保护区。保护区可视化为不可见——不改变网格颜色，仅影响连线规则。
3. 对落定后的蓝(1)像素按行和列做跨度连线：
   a. 对每一行，若有 2 个以上蓝像素，从最左到最右逐格填充蓝(1)；但若某格位于保护区内，跳过该格（保持背景色），连线在保护区入口截断并在保护区出口恢复。
   b. 对每一列，若有 2 个以上蓝像素，从最上到最下逐格填充蓝(1)；同样跳过保护区内的格子。
4. 红(2)障碍像素在输出中保持不变。连线不覆盖红色像素。
5. 行连线与列连线的交叉格正常填充蓝(1)（无冲突）。

**关键洞察**：同一组标记像素在不同障碍布局下会落到不同位置，产生完全不同的行列对齐关系和连线图案；障碍同时扮演两个角色——阻挡下落（改变像素落点）和保护区截断连线（改变连线几何），这两个效应耦合在同一组红色像素上。
