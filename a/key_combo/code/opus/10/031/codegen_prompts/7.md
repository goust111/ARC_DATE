## 新题 7：多标记折线路径网络的交叉区域填充

**组合逻辑**：[连线/draw_line + 折线路径/folded_path](创新：多条独立路径的几何交互) + [平行配对/parallel_pairing + 段间区域填充/fill_between_segments](创新：填充对象是路径间的涌现区域) + [中心偏移选角/center_offset_selects_corner](已有) → 生成 → 检测涌现交互 → 填充

**来源原语**：连线/draw_line、标记像素/marker_pixel、折线路径/folded_path、列对齐/column_alignment、中心偏移选角/center_offset_selects_corner（参考题 7ec998c9）；填充/fill、平行配对/parallel_pairing、段间区域填充/fill_between_segments、对角线段/diagonal_segment、平行四边形区域/parallelogram_region（参考题 7666fa5d）

**依赖链**：每个标记独立生成折线路径（路径方向由标记列位置决定），但填充区域只在两条路径的对角段平行时出现——这是涌现效应。单个标记不产生填充；填充区域的形状由两条路径的相对几何关系决定。路径生成 → 平行段检测 → 区域填充。

多个标记各自生成折线路径后，在路径对角线段平行的位置之间填充平行四边形区域。

**输入结构**：橙(7)背景网格，约 15x18。网格上有 2-3 个非背景非蓝的标记像素（如红(2)、绿(3)），分别位于不同列，行位置不限但通常不在第一或最后一行。蓝(1)在输入中不出现。不同标记的列位置互不相同。生成约束：至少有一对标记的列位置满足——两者生成的折线路径的对角线段具有相同斜率（即两者都在中心列或都不在中心列），从而能产生平行对角段。网格列数为奇数，使中心列唯一。

**规则**：
1. 对每个标记像素，生成蓝(1)折线路径：将该标记所在列从顶到底全部涂蓝(1)（标记像素本身保留原色不变）。
2. 判断该标记是否位于网格的唯一中心列（列索引 = (宽度-1)/2）。
   - 若在中心列：从列顶端向右上角画对角线段，从列底端向左下角画对角线段（蓝(1)像素逐行向目标角偏移一列，直到到达网格边缘）。
   - 若不在中心列：从列顶端向左上角画对角线段，从列底端向右下角画对角线段。
3. 所有标记的路径绘制完成后，检测不同路径的对角线段之间的平行关系：两条对角段平行当且仅当它们斜率相同（同为+1或同为-1）且分别属于不同标记的路径。
4. 对每对平行的对角段，沿主对角线方向（r-c = 常数）扫描：在两条平行段之间（严格在两段之间、不含段本身的像素），将所有橙(7)背景像素填充为黄(4)。
5. 已有蓝(1)像素和标记像素不被覆盖。非平行的对角段之间不产生填充。

**关键洞察**：每个标记的路径生成是独立的、确定性的，但填充区域是路径间几何关系的涌现结果。中心列判断决定对角段方向——若两个标记一个在中心列、一个不在，它们的对角段斜率相反，不产生平行填充。须多例对比才能发现中心列判断规则及其对填充区域存在性的影响。
