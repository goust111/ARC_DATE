## 新题 10：邻域计数条件化的棋盘放大

**组合逻辑**：[像素放大/pixel_upscaling + 棋盘格图案/checkerboard_pattern](创新：棋盘朝向由邻域属性决定而非固定) + [计数/counting](创新：4-连通邻域计数作为条件判据) + [按颜色条件分支/color_conditional_branch](创新：分支由空间上下文而非像素自身颜色触发) → 局部上下文 → 条件化局部变换

**来源原语**：像素放大/pixel_upscaling、棋盘格图案/checkerboard_pattern、按颜色条件分支/color_conditional_branch、像素/pixel（参考题 2072aba6）；计数/counting（参考题 9af7a82c、39a8645d）

**依赖链**：每个前景像素的 2x2 放大块图案取决于该像素的 4-连通前景邻居数量的奇偶性。必须先在原始分辨率下完成邻域分析，才能确定放大后的局部图案。放大不改变邻域关系（邻域在源网格中计算），但邻域分析的结果嵌入到了放大后的图案中。

将每个前景像素放大为 2x2 棋盘块，棋盘的起始角颜色由该像素在原始网格中的前景邻居数量奇偶性决定。

**输入结构**：黑(0)背景网格，约 5x6。网格上有灰(5)前景像素构成的一个连通或近连通的图形（约 8-15 个前景像素），形状为不规则的单连通图形（无孔洞），像素间通过 4-连通关系相连。图形内部像素（4 个方向都有前景邻居）和边缘像素（1-3 个前景邻居）混合存在。生成约束：保证图形中同时存在邻居数为偶数和邻居数为奇数的前景像素。

**规则**：
1. 创建输出网格：高度 = 输入高度 x 2，宽度 = 输入宽度 x 2。
2. 对输入中每个黑(0)像素，对应的 2x2 输出块全部填黑(0)。
3. 对输入中每个灰(5)前景像素，计算其在输入网格中的 4-连通前景邻居数 N（上、下、左、右四个方向中为灰(5)的数量，0 <= N <= 4）。
4. 若 N 为偶数（0, 2, 4）：对应的 2x2 输出块填充为 [[蓝(1), 红(2)], [红(2), 蓝(1)]]（左上角蓝）。
5. 若 N 为奇数（1, 3）：对应的 2x2 输出块填充为 [[红(2), 蓝(1)], [蓝(1), 红(2)]]（左上角红）。

**关键洞察**：视觉上看，放大后的图案像是一个大棋盘，但仔细观察会发现棋盘在某些 2x2 块处"翻转"了。翻转位置不随机——它精确对应原始网格中邻居数奇偶性发生变化的边界。求解者不能用全局棋盘规则解释输出，必须回到原始分辨率分析每个像素的局部连通性。须对比多例（不同形状 → 不同邻域模式）才能排除"按位置奇偶"等替代假设。
