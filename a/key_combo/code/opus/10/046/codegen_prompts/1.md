## 新题 1：射线穿越周期壁纸的缺损修复

**组合逻辑**：[射线延伸](从对角射线种子出发，穿越网格) + [周期推断](推断瓦片周期) + [补全](用射线路径上的已知像素恢复缺损) → 三者耦合：射线路径决定修复范围，周期相位决定修复值，但射线遇到的非缺损像素反过来验证周期参数

**来源原语**：射线延伸(ray_extend) ← 7e2bad24；周期推断(period_inference) ← c663677b；补全(complete) ← c663677b；对角射线种子(diagonal_ray_seed) ← 7e2bad24；缺损像素(corrupted_pixel) ← c663677b

**依赖链**：射线路径确定哪些缺损像素需要修复（不在路径上的缺损保持黑(0)不变）；周期推断从非缺损像素中提取瓦片周期；射线路径上的已知像素同时作为周期推断的约束输入——删除射线路径信息则不知修复哪些像素，删除周期推断则不知修复为什么颜色

一句话总结：沿对角射线路径，用推断出的瓦片周期恢复路径上的缺损像素，路径外的缺损保持不变。

**输入结构**：约 14x14 的网格。背景是一个由 3x3 或 4x4 的彩色瓦片（使用红(2)、绿(3)、黄(4)、青(8)等 3~4 种颜色）周期铺满的壁纸。部分像素被替换为黑(0)表示缺损，缺损像素散布于网格各处（约占总像素的 20%~30%）。网格中有一条由蓝(1)像素标记的 8-连通对角线段（长度 2~3 像素），作为射线种子，位于网格边缘附近。射线种子的像素覆盖了原壁纸颜色。生成约束：壁纸的每个周期相位至少在某个非缺损、非射线位置出现一次，保证周期可被唯一确定。

**规则**：
1. 从射线种子的端点出发，沿种子指示的对角方向（左上/右上/左下/右下之一），逐像素延伸直到离开网格边界，形成完整射线路径。射线路径上的像素（包括种子本身）标记为"待处理"。
2. 分析网格中所有非黑(0)、非蓝(1)的像素，推断最小行周期 P_r 和列周期 P_c，使得所有已知像素满足 grid[r][c] == tile[r mod P_r][c mod P_c]。
3. 对射线路径上的每个像素位置 (r, c)：若该位置当前为黑(0)（缺损），则用 tile[r mod P_r][c mod P_c] 的颜色填充；若该位置为蓝(1)（种子），也用瓦片颜色替换。
4. 路径外的缺损像素保持黑(0)不变。输出网格中射线路径被壁纸颜色覆盖（射线消失），路径外缺损仍为黑(0)。

**关键洞察**：射线不是装饰而是"修复刷"——它限定了补全的空间范围；求解者必须同时推断周期和理解射线的作用域限制，二者缺一不可。
