## 新题 8：拉伸入框后的重叠遮挡排序

**组合逻辑**：[拉伸/包围盒映射](多个小精灵体分别拉伸到对应空心框内) + [包含/重叠](拉伸后多个框区域有重叠部分) + [排序](根据精灵体原始面积确定绘制顺序/遮挡优先级) → 耦合：拉伸确定每个精灵体在输出中的空间范围，重叠区域需要遮挡规则，面积排序决定谁在上层

**来源原语**：拉伸(stretch) ← 465b7d93；包围盒映射(bbox_mapping) ← 465b7d93；空心矩形(hollow_rectangle) ← 465b7d93；精灵体(sprite) ← 9bebae7a/465b7d93；排序(sorting) ← b7999b51；包含(containment) ← 868de0fa

**依赖链**：每个精灵体必须拉伸到其配对框的内部（不拉伸则无法确定输出位置）；框与框有重叠区域（重叠是拉伸后的涌现结果）；重叠区域的像素归属由精灵体原始面积的排序决定（面积最小的在最上层）——删除拉伸则无空间分配，删除排序则重叠区域无法确定

一句话总结：将多个外部小精灵体分别拉伸到配对的空心框内部，框有重叠时按精灵体原始面积从大到小的顺序绘制（小面积的最后绘制，在最上层）。

**输入结构**：约 16x16 的网格。背景为黑(0)。网格中有 3 个不同颜色的 1 像素厚空心矩形框（使用灰(5)、栗(9)、青(8)），框的大小不同（内部约 4x4 到 7x7），且两两之间有部分内部区域在空间上重叠（框的边框可以交叉或嵌套）。网格的某个角落区域有 3 个对应颜色的小 4-连通精灵体（每个 3~6 像素），精灵体颜色与框颜色一一匹配。精灵体之间间隔至少 1 像素。生成约束：三个精灵体的像素数两两不同；三个框的内部区域两两有非空交集。

**规则**：
1. 按颜色将每个精灵体与同色矩形框配对。
2. 对每对 (精灵体, 框)：将精灵体的边界框映射到框的内部区域边界框（四角对四角），精灵体中相邻像素之间用水平/垂直线段连接，然后填充连接线段围成的封闭区域（与参考题 465b7d93 相同的拉伸方法）。
3. 确定绘制顺序：按精灵体的原始像素数从大到小排序。像素数最多的最先绘制（最底层），像素数最少的最后绘制（最上层）。
4. 按此顺序依次将拉伸结果绘制到输出画布上。重叠区域被后绘制的覆盖。
5. 输出保留所有框的边框像素不变，框外区域（包括原精灵体位置）清为黑(0)。

**关键洞察**：框的重叠不是偶然的——它制造了必须用遮挡规则解决的冲突；遮挡优先级由精灵体在拉伸前的"原始复杂度"（像素数）决定，小而简单的图案反而有最高优先级，这一反直觉的映射需要对比多个示例才能发现。
