## 新题 10：分隔格字形解码驱动选择性擦除

**组合逻辑**：[分隔线网格](将输入划分为格子阵列) + [解码/字形映射](每格内的图案是编码符号) + [擦除](根据解码结果选择性擦除特定格子) → 耦合：分隔格定义解码单元，字形模式决定该格是否被保留，最终输出只包含"有效"格子的内容

**来源原语**：分隔线网格(separator_lattice) ← 458e3a53；格内判定(cell_interior_test) ← 458e3a53；解码(decode) ← 995c5fa3；字形映射颜色行(glyph_maps_to_color_row) ← 995c5fa3（创新改造：字形不映射颜色而映射保留/擦除指令）；擦除(erase) ← 9bebae7a

**依赖链**：分隔线划分格子单元（无分隔则无法定义独立的字形区域）；每格内的图案作为字形被解码为"保留"或"擦除"指令（不解码则不知保留哪些格子）；被标记为"擦除"的格子内容清空，保留的格子紧凑拼接为输出——三步串联，删任一步均无法得到正确输出

一句话总结：在分隔格阵列中，每格包含一个小图形；图形是否接触格子上边界编码了"保留/擦除"指令，保留的格子内容按行优先顺序紧凑拼接为输出。

**输入结构**：约 15x15 的网格。灰(5)分隔线将网格划分为 4x4 的格子阵列（每格内部约 3x3）。每个格子内有一个由某种颜色（红(2)、蓝(1)、绿(3)、黄(4)之一）构成的小 4-连通图形（2~5 像素）。图形分两类：一类的最上方像素位于格子内部第 0 行（接触格子上边界），另一类的最上方像素位于格子内部第 1 行或更低（不接触上边界）。生成约束：每种类型至少出现 3 格；接触上边界的格子数量在 4~8 之间。

**规则**：
1. 通过灰(5)完整行和完整列划分格子，得到 4x4 的格子阵列。
2. 对每个格子，检查其内部非黑非灰图形的最顶部像素行是否为格子内部第 0 行（紧邻上方灰分隔线的下一行）。
3. 若是（接触上边界）：该格标记为"保留"。若否：标记为"擦除"。
4. 将所有"保留"格子的内部内容（3x3 区域，保留原色），按行优先、列次优先的顺序（即先第一行从左到右，再第二行从左到右...）水平拼接。每两个保留格之间无间隔。
5. 输出为一行高度 3（等于格子内部高度），宽度为 3 * (保留格数量) 的网格。

**关键洞察**：格内图形的具体形状和颜色不编码任何信息——唯一有意义的特征是图形是否"够到"格子的上边界，这个微妙的位置属性作为二值编码决定了整格的命运。
