## 新题 14：封闭区域面积驱动的选择性对角平铺

**组合逻辑**：[洪泛填充/封闭区域检测](找到线条围成的封闭区域) + [面积决定填充色](创新改造：面积不决定颜色，而决定是否参与后续操作) + [对角线偏移复制](符合面积条件的封闭区域内容被对角平铺) → 耦合：封闭区域检测确定候选区域集合，面积阈值筛选出目标区域，筛选结果决定哪些内容被对角复制

**来源原语**：洪泛填充(flood_fill) ← 868de0fa/c0f76784；封闭区域(enclosed_region) ← 868de0fa/c0f76784；面积决定填充色(area_determines_fill_color) ← c0f76784（创新改造：面积决定是否平铺）；对角线偏移复制(diagonal_offset_copy) ← d13f3404；画布加倍(canvas_doubling) ← d13f3404

**依赖链**：线条框出多个封闭区域（不检测封闭区域则无操作对象）；只有面积最小的封闭区域被选中（面积比较是筛选器，不是颜色分配器）；选中区域的内容作为图案进行对角平铺到加倍画布上——封闭检测提供候选，面积筛选确定目标，平铺执行输出

一句话总结：在灰色线条围成的多个封闭区域中，找到面积最小的那个，将其内部图案对角平铺到双倍大小的输出画布上。

**输入结构**：约 10x10 的网格。背景为黑(0)。灰(5)像素构成多条相交的直线段（水平和垂直各 2~3 条），交叉形成 3~5 个大小不同的矩形封闭区域。每个封闭区域内有不同颜色的简单图案（使用红(2)、蓝(1)、绿(3)、黄(4)等，每区域一种颜色，图案为 2~4 个像素的小图形）。各封闭区域面积（内部像素总数，不含灰边界）两两不同。生成约束：面积最小的封闭区域唯一，其内部图案的边界框不超过该区域范围。

**规则**：
1. 找到所有被灰(5)像素完全包围的 4-连通黑(0)+彩色区域（封闭区域）。每个封闭区域的面积 = 其包含的非灰像素总数。
2. 选择面积最小的封闭区域，提取其内部所有像素（包含背景黑(0)和彩色图案）作为矩形图案块 P（边界框裁剪）。
3. 创建高度和宽度均为 P 的两倍的输出画布，填充黑(0)。
4. 对 P 中每个非黑像素 (r, c)，在输出画布的所有位置 (r+k, c+k)（k = 0, 1, 2, ...，不越界）画上该颜色。
5. 输出即为对角平铺后的画布。灰线和其他封闭区域不出现在输出中。

**关键洞察**：多个封闭区域是"候选池"而非都需要处理——面积最小这一条件将候选缩减为唯一目标，然后对角平铺将一个局部图案扩展为全局输出，两级筛选+变换的结构需要逐步推理。
