## 新题 5：十字补全计数决定镜像轴

**组合逻辑**：[补全](已有) → 产生计数结果 → [镜像](创新：镜像轴由检测阶段的数量结果动态决定) · 检测结果的量化属性控制全局变换类型

**来源原语**：补全/十字图案/标记像素/基底像素/行列对齐/标记推断十字涂底/忽略干扰项(50846271)、镜像/前景遮罩/象限/对称轴定义(47c1f68c)、计数(9565186b)

**依赖链**：首先在灰(5)基底中识别并补全由红(2)标记像素指示的不完整十字图案，统计补全的十字总数 N。N 的奇偶性决定全局镜像方向：奇数为左右镜像，偶数为上下镜像。删除补全步骤则无法得到 N；删除镜像步骤则 N 无用武之地。

在灰色基底中补全红色标记指示的不完整十字图案，用补全的十字数量的奇偶性决定全局镜像方向。

**输入结构**：约 14x14 的网格，黑(0)背景中分布着灰(5)基底像素（占网格约 40%~60%，形成不规则但大致连通的区域）和若干红(2)标记像素。红(2)像素位于灰(5)区域中，标示不完整十字图案的部分臂。所有有效十字共享同一臂长 R（R 为 2 或 3），即每个完整十字是以某像素为中心、上下左右各延伸 R 格的等臂加号。每个有效十字的中心和臂上的部分格子已是红(2)，其余臂格为灰(5)（待补全）。有效十字的所有臂格（无论红还是灰）必须在网格内且非黑(0)。生成约束：有效十字为 2~4 个，互不重叠；臂长 R 可从输入中红(2)像素在非黑(0)水平或垂直连续段中的最大奇数跨度推断；灰(5)区域中还散布少量干扰红(2)像素，这些像素不属于任何有效十字。

**规则**：
1. 推断臂长 R：在所有非黑(0)水平和垂直连续段中，找到包含红(2)像素的最长奇数段，R = (该段长度 - 1) / 2。
2. 寻找有效十字：对每个红(2)像素 (r, c)，检查以 (r, c) 为中心、臂长 R 的十字掩码——上下左右各 R 格共 4R+1 格。若这些格子全部为非黑(0)（灰(5)或红(2)），且该行和该列各至少有 1 个红(2)像素在臂范围内，则 (r, c) 是候选中心。
3. 贪心选择：按候选中心包含的红(2)像素数从多到少排序。依次选入候选中心；若一个候选中心的掩码与已选中心的掩码有重叠，跳过该候选。直到所有红(2)标记像素都被某个已选十字的掩码覆盖。
4. 对每个选中的十字，将其掩码中所有灰(5)格子涂为青(8)。红(2)格子保持不变。
5. 统计选中的十字总数 N。
6. 若 N 为奇数，将整个网格沿垂直中轴左右镜像（列顺序反转，行不变）。若 N 为偶数，将整个网格沿水平中轴上下镜像（行顺序反转，列不变）。
7. 镜像后输出整个网格，尺寸与输入相同。

**关键洞察**：十字补全是一个局部模式识别任务，其结果（数量 N）被提升为控制全局几何变换的参数。求解者必须对比至少两个示例——一个 N 为奇数（左右镜像），一个 N 为偶数（上下镜像）——才能归纳出奇偶-轴向映射规则。单个示例无法区分"总是左右镜像"和"奇数时左右镜像"。
