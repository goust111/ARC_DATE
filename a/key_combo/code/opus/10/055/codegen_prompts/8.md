## 新题 8：类比训练对揭示逐列重涂规则

**组合逻辑**：[类比推理/训练对映射](已有) → 发现隐含变换规则 → [重涂色/逐列对应](创新：调色带规则本身需通过类比推断而非显式给出) · 元推理层与执行层耦合

**来源原语**：类比推理/规则推断/空心框/训练对映射/调色板匹配配对(4c7dc4dd)、重涂色/裁剪/调色带/逐列对应/调色带指定列色(278e5215)

**依赖链**：三个带框区域中，两个通过内部颜色集匹配形成训练对，第三个是测试输入。训练对的源→目的变换展示了一种逐列颜色映射规则。求解者必须先识别训练对（需要颜色集比较），再从训练对中推断出逐列映射的具体规则（需要逐列比对源和目的内容），最后将该规则应用于测试输入。删除类比识别则不知道哪个是源哪个是目的；删除规则推断则映射未知；删除重涂色则无输出变换。

识别训练对并从中推断逐列颜色映射规则，将同一规则应用于测试精灵体的每一列。

**输入结构**：约 18x18 的网格，黑(0)背景。包含 3 个大小相同的正方形空心框（边长 5~7 像素的 1 像素宽边框），边框颜色各不相同（如灰(5)、栗(9)、品红(6)）。每个框内部为 (边长-2)x(边长-2) 的区域，包含由 2~3 种非黑(0)非边框色颜色组成的小型图案（不规则的像素排列，每列至少有 1 个非黑像素）。三个框的内部图案中，恰好两个框的内部使用相同的颜色集合（非黑颜色种类相同，但排列/数量可以不同）——这两个框构成训练对。第三个框的内部使用不同的颜色集合——这是测试输入。生成约束：训练对的源和目的可通过以下方式区分：源的内部图案复杂度更高（非黑像素数量更多）；训练对的源和目的内部宽度（列数）相同；测试输入的内部宽度也与训练对相同。

**规则**：
1. 识别训练对：对三个框的内部区域，统计各自包含的非黑(0)颜色集合（不计数量，只看种类）。颜色集合相同的两个框为训练对。颜色集合不同的框为测试输入。
2. 区分训练源和训练目的：训练对中非黑(0)像素数量更多的为训练源 S，更少的为训练目的 D。
3. 推断逐列颜色映射：对训练源 S 和训练目的 D 的每一列 j（j = 0, 1, ..., 内部宽度-1），观察 S 第 j 列中出现的非黑颜色 Cs_j 和 D 第 j 列中出现的非黑颜色 Cd_j。建立映射 Cs_j → Cd_j。若某列 S 中有多种颜色，取该列出现次数最多的颜色作为 Cs_j；D 列同理取最多的作为 Cd_j。最终得到一个全局颜色映射 M：对所有列收集的 (Cs_j, Cd_j) 对取并集（同一 Cs 对应的 Cd 在所有列中一致）。
4. 对测试输入框 T 的内部区域，逐像素应用映射 M：若像素颜色在 M 的定义域中，替换为 M 映射的目标色；若不在定义域中（包括黑(0)），保持不变。
5. 输出为测试框的内部区域（裁剪到框内部，不含边框），替换完成后的结果。

**关键洞察**：这是一个"A 之于 B 如同 C 之于 ?"的类比题，但其中隐含的变换不是几何变换（旋转、翻转等），而是逐列颜色映射。求解者必须先通过颜色集合匹配找到训练对，再通过逐列比对推断映射规则，最后将规则泛化到使用不同颜色集合的测试输入上。由于映射是从训练对颜色到训练对颜色的，而测试输入使用不同颜色，泛化的关键在于：映射按"列位置"传递（第 j 列的颜色被第 j 列对应的映射后颜色替代），而非按颜色值直接传递。这需要对比多个示例中不同的训练对和测试输入才能归纳。
