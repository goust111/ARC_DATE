## 新题 3：图例过滤擦除改变射线障碍地图

**组合逻辑**：[擦除/图例过滤](已有) → 移除特定障碍 → [射线延伸](创新：射线终止条件由擦除结果动态决定) · 过滤操作改变延伸操作的拓扑约束

**来源原语**：擦除/连通分量/图例区域/包含全部目标色/图例作为过滤器(d59b0160)、射线延伸/外推/等距标记点/算术线/等距共线/边界内延续(0b17323b)

**依赖链**：射线从标记三元组末端向前延伸，遇到非背景像素时停止。图例过滤擦除了某些连通分量（变为背景），消除了射线路径上的障碍物。不同的图例内容会擦除不同的分量，导致同一组标记三元组产生不同长度的射线。删除擦除步骤则射线被现有分量截断；删除射线延伸则擦除后无输出变换。

先用图例指定颜色集擦除含全部目标色的连通分量（障碍消失），然后从存活的标记三元组执行射线延伸，射线遇非背景像素或网格边界时停止。

**输入结构**：约 18x20 的网格，黑(0)背景。左上角有一个图例区域：由栗(9)色像素围成的 L 形边框（底边一行 + 右边一列，各含 3~4 个栗(9)像素），内部 2x2 或 2x3 区域含 2 种目标色像素（如蓝(1)和红(2)各 1~2 个），其余为黑(0)。网格其余区域分布着 3~5 个 4-连通连通分量，每个由 2~4 种非黑(0)非栗(9)非绿(3)颜色组成，5~12 像素，形状为不规则 4-连通团簇（非矩形、非对称的自由形状）。另有 2~3 组绿(3)标记三元组，每组 3 个绿(3)像素位于同一水平线或垂直线上且等间距排列。生成约束：至少 1 个连通分量包含图例中的全部目标色（将被擦除）；至少 1 组标记三元组的延伸方向上，被擦除分量曾是障碍（擦除后射线变长）；至少 1 组标记三元组的延伸方向上无障碍（射线长度不受擦除影响）；标记三元组的标记点不与任何连通分量共享像素位置。

**规则**：
1. 读取图例：图例 L 形栗(9)边框所围内部区域中，所有非黑(0)非栗(9)颜色构成目标色集 T。
2. 对网格中每个 4-连通连通分量（仅统计非黑(0)非栗(9)非绿(3)像素），检查其是否包含 T 中的**全部**颜色。若包含，将该分量所有像素擦除为黑(0)。图例区域（含边框）不受擦除影响。
3. 对每组绿(3)标记三元组（3 个同色等距共线像素），按行主序排列标记点，计算相邻标记点之间的步长向量 (dr, dc)。
4. 从最后一个标记点开始，沿步长方向逐步延伸：对每个新位置 (r + k*dr, c + k*dc)（k=1,2,...），若该位置在网格内且当前颜色为黑(0)，则涂为红(2)；否则停止（不涂该位置）。
5. 原始绿(3)标记点保留不变。未被擦除的连通分量保留不变。图例及边框保留不变。

**关键洞察**：图例内容控制哪些分量被擦除，被擦除的分量若恰好挡在射线路径上，则射线"穿过"其原来位置继续延伸。求解者必须对比多个示例：在某些示例中障碍被擦除导致射线更长，在另一些示例中障碍未被擦除导致射线被截断，才能归纳出"射线遇非背景停止"且"图例过滤移除障碍"的联合规则。
