## 新题 7：双源汇聚——角位 L 定几何、对角基元定填充

**组合逻辑**：[放大画布(expand_canvas) + 连线(draw_line)](从角位 L 推断三角形轮廓并绘制在扩展画布上) + [平铺(tile)](对角基元图案周期填充三角形内部)（双源汇聚结构：几何信息和填充信息分别来自输入的两个不同区域，合并后产生输出）

**来源原语**：角位边角(corner_piece)/放大画布(expand_canvas)/三角轮廓(triangle_outline)/角位置对应(corner_correspond)/补对角线边(fill_diagonal_side) ← e3f79277; 基元图案(motif)/平铺(tile)/逐级展开(successive_placement) ← 762cd429; 连线(draw_line) ← 1478ab18

**依赖链**：角位 L 的位置和长度编码三角形的角、大小和轮廓色（几何通道），对角基元图案编码内部填充纹理（纹理通道）。两条通道独立输入、在输出中汇合：三角轮廓圈定填充边界，基元图案提供填充内容。删去 L→不知道画什么三角形；删去基元→内部为空（不同题目）；删去画布扩展→轮廓画不下。

从角位 L 推断扩展画布上的直角三角形轮廓，用输入对角位置的基元图案周期平铺填充三角形内部。

**输入结构**：正方形网格（边长 n，约 5~7），背景为黑(0)。在四个角之一，有一个 1 像素厚的前景色（如蓝(1)）L 形结构，L 的两条边分别贴合该角的两条网格边缘。两条边长度可以不等（如水平边 4 像素、垂直边 3 像素），以确保三角形方向唯一确定。在输入网格关于中心的对角位置（如 L 在左上角，则基元在右下角区域），放置一个 2x2 的多色基元图案（4 格分别为不同颜色，如红(2)、绿(3)、黄(4)、橙(7)）。L 和基元图案之间的区域为背景色。生成约束：L 的两条边长度不等（以消除对称歧义）；基元图案的 4 格颜色互不相同且与 L 颜色和背景色均不同；L 与基元不重叠不相邻。

**规则**：
1. 从 L 的位置确定三角形所在的角（与 L 同角）。从 L 的两条边长度（设为 a 和 b）确定三角形的两条直角边长度：输出画布边长 = max(2a, 2b) + 1，两条直角边长度分别为 2a 和 2b。
2. 在输出画布的对应角绘制直角三角形轮廓：两条直角边沿画布边缘绘制（颜色为 L 的颜色），对角线连接两条边的自由端点（使用 Bresenham 直线算法绘制，同样使用 L 的颜色）。
3. 以三角形直角顶点为对齐原点，将 2x2 基元图案沿行列方向周期平铺覆盖整个画布，然后仅保留落在三角形内部（轮廓线以内、不含轮廓线本身）的平铺像素。轮廓线上和外部的平铺像素全部丢弃。
4. 输出中不包含原始输入的 L 和基元图案——它们被几何信息和纹理信息消费后丢弃，输出仅含扩展画布上的三角形轮廓和内部平铺纹理。

**关键洞察**：L 和基元图案各自携带解题所需的一半信息——L 给出"在哪个角画多大的三角形"，基元给出"用什么纹理填充内部"。两者在输入中空间分离、角位对称，必须同时正确解读才能产生完整输出。基元的对齐起点为三角形直角顶点这一规则需要对比多个示例（L 在不同角的情形）才能确认。
