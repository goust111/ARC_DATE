## 新题 7：锚点平移复制后部分重叠区域异或擦除

**组合逻辑**：[平移复制/translate_and_copy + 锚点偏移对应/anchor_offset_correspondence](创新：复制位置与原件部分重叠) → [异或/xor](创新：异或不是在分隔的两半掩码之间进行，而是在原件和复制件的重叠区域进行) + [擦除/erase](已有：擦除锚点标记)

**来源原语**：平移复制/锚点偏移对应/源锚点/目标锚点(2c737e39)，异或/逐像素异或输出(3428a4f5)，擦除(f45f5ca7)

**依赖链**：锚点偏移决定复制位置 → 复制位置与原件产生空间重叠 → 重叠区域内逐像素做异或判定（双方都有非背景像素则擦为背景） → 最终输出是原件与复制件的对称差。复制步骤生成了异或的第二操作数，且重叠范围由偏移量隐式决定。

将精灵体按锚点偏移复制到部分重叠的位置，在重叠区域执行异或逻辑：双方均有非背景像素的位置擦除为背景，仅单方有像素的位置保留。

**输入结构**：约 12x12 的网格，黑(0)为背景。一个 4-连通的多色精灵体（multicolor_sprite，8-15 像素，包含 2-3 种非背景颜色如蓝(1)、红(2)、绿(3)），其中恰好有一个灰(5)标记像素位于精灵体内部（与精灵体其他像素 4-相邻）。另有一个孤立的灰(5)标记像素位于网格其他位置。生成约束：源标记到目标标记的偏移量使得复制后的精灵体与原精灵体有 30%-70% 的包围框面积重叠（保证有重叠但不完全重叠）；目标标记的位置使得复制后的精灵体不超出网格边界。

**规则**：
1. 识别精灵体内部的灰(5)像素为源锚点，孤立的灰(5)像素为目标锚点。
2. 计算偏移向量 (dr, dc) = (目标行 - 源行, 目标列 - 源列)。
3. 将源锚点和目标锚点都擦除为黑(0)背景。
4. 对精灵体中每个非灰像素（即图案像素），计算其复制位置 = (原行 + dr, 原列 + dc)。
5. 构建输出网格：
   - 原精灵体的非灰像素保留在原位。
   - 复制像素绘制到复制位置。
   - 对于重叠区域（某个位置既有原件像素又有复制件像素）：无论两者颜色是否相同，该位置擦除为黑(0)背景。
   - 对于非重叠区域：原件独有的像素保留原色，复制件独有的像素保留复制色。
6. 最终输出是原件和复制件的空间对称差（symmetric difference）。

**关键洞察**：灰色锚点的偏移故意造成部分重叠，而重叠区域的异或擦除使输出既不是原件也不是简单复制——求解者必须识别重叠区域并理解"双方共有则消除"的抵消规则。

## 实现要求

1. `main(grid)` 必须实现新题描述中的确定性转换规则，不能只识别 `generate_input()` 的固定模板。禁止不同的input网格输出相同的output网格。
2. `generate_input()` 必须随机生成多样样例，不能固定死。随机维度应覆盖：网格大小、对象数量、位置、颜色、方向、形状参数或关键分支。注意若描述中存在若干，需实现而不是只有单个，包括object或者对应关系等等。且若涉及到最短路径，则输入网格中必涉及到多条路径，对选择造成干扰。

4. 禁止把 ARC 颜色 id 、亮度、拼写等当作人类不可见的数值语义参与排序、大小比较或隐藏映射。颜色变化必须有可见结构线索。注意颜色亮度、拼写等也是不可见信息，若描述中出现违规的颜色id或者亮度，可自行使用少量的固定颜色替代，但注意生成时要在三个以内输入输出网格中对所有变换100%覆盖度。

6. 若规则有多个分支，生成器不能长期固定成一个分支；应让分支在随机样例中合理出现。分支概率不必平均——难以发现的隐蔽分支（如少数情况下才触发的特殊规则）应适当提高出现概率，确保在 3 个训练示例中至少出现一次，否则求解者无法归纳该规则。对于颜色映射类规则，确保 2 个左右的示例即可覆盖所有映射关系（每种颜色→颜色的映射至少在某个示例中出现过）。
