## 新题 3：蛇形路径端点方向决定垂直射线印戳位置

**组合逻辑**：[展直/蛇形路径追踪](创新：追踪目的不是展直输出，而是获取端点局部方向) → [射线延伸 + 投射](创新：射线方向由蛇身端点切线的垂直方向决定) → [印章覆盖](已有)

**来源原语**：蛇形路径/snake_path + 端点/endpoint + 遍历顺序/traversal_order（7b5033c1）, 射线延伸/ray_extend + 投射/perpendicular_cast + 贯穿条/full_span_bar + 控制像素/control_pixel + 接触标记/contact_marker + 命中处印标记/stamp_at_hit（ecdecbb3）

**依赖链**：蛇形路径追踪 → 确定端点位置及端点处蛇身的局部行进方向 → 取该方向的两个垂直方向作为射线方向 → 射线与贯穿条相交确定印戳位置 → 蛇身颜色决定印戳颜色。蛇的几何形态直接编码了射线方向——不同形状的蛇产生不同方向的射线，这是源题中不存在的结构关系。

追踪蛇形路径以获取端点处的行进方向，沿垂直于该方向的轴线投射射线，在射线命中贯穿条处印制以蛇身颜色为主色的接触标记。

**输入结构**：网格约 15x20。黑(0)背景。2-3 条水平贯穿条（整行为灰(5)）分布在网格中，将空间分为若干水平带。每个水平带中有 1-2 条蛇形路径，每条蛇使用不同颜色（红(2)、绿(3)、蓝(1)等），长度 5-10 像素，4-连通链状，恰好有 2 个端点（仅有 1 个链内邻居的像素）。蛇的端点不与贯穿条相邻。每条蛇在端点处的局部方向为水平或垂直（端点到其唯一邻居的方向向量）。生成约束：不同蛇的端点射线互不交叉；每个端点的至少一个垂直方向上存在一条贯穿条。

**规则**：
1. 识别所有蛇形路径：黑(0)背景上的非灰(5)彩色 4-连通链，每条链恰好有 2 个端点。
2. 对每条蛇的每个端点，确定局部方向向量 D = (端点的唯一邻居的坐标 - 端点坐标)。
3. 计算 D 的两个垂直方向 D_perp1 和 D_perp2（例如 D=(0,1) 则垂直方向为 (1,0) 和 (-1,0)）。
4. 从端点出发，分别沿 D_perp1 和 D_perp2 逐像素投射射线。
5. 如果射线命中一个灰(5)贯穿条像素：(a) 将端点到命中点之间（不含端点，含命中点）的所有像素涂为该蛇的颜色；(b) 以命中点为中心印制 3x3 的灰(5)方块（超出网格边界的部分舍弃），然后将该 3x3 方块的中心像素恢复为蛇的颜色。
6. 如果某个垂直方向上射线到达网格边界仍未命中贯穿条，该方向不产生任何绘制。

**关键洞察**：射线的方向不是预设的上下或左右——它由蛇身在端点处的弯曲几何形态动态决定。同一条蛇的两个端点可能朝不同方向发射射线，因为蛇身在两端的行进方向不同。
