## 新题 2：桥接通道将孔洞分组，组内面积排名定填色

**组合逻辑**：[连通判定](创新：判定对象从前景转为背景孔洞之间的通道连通) → [面积分级](已有) → [填充](创新：填色由组内排名而非全局排名决定)

**来源原语**：连通判定/connectivity_test + 桥接路径/bridge_path + 连通性/connectivity（239be575）, 封闭孔洞/enclosed_hole + 填充/fill（93b4f4b3）, 面积分级/area_ranking + 面积决定颜色/area_determines_color + 计数/counting（e8593010）

**依赖链**：桥接通道的连通性将孔洞组织成若干组 → 组的成员确定后才能在组内排名 → 组内面积排名映射到颜色 → 同一全局面积在不同组中可能获得不同颜色。孤立孔洞（无桥接）不填充，形成"连通性门控"效应。

通过模板中的窄通道检测孔洞之间的连通关系，将连通的孔洞分组，按组内面积从小到大排名映射颜色，孤立孔洞留空。

**输入结构**：网格约 15x15。灰(5)模板覆盖大部分网格。模板内有 5-7 个互不相连的黑(0)封闭孔洞，每个孔洞为 4-连通区域，面积 2-8 像素，形状不规则（非矩形）。部分孔洞对之间存在恰好 1 像素宽的黑(0)"桥接通道"——即一条宽度始终为 1 像素的黑色路径穿过灰色模板连接两个孔洞的边缘。通道本身不算入任何孔洞的面积。2-4 条这样的桥接通道将部分孔洞连接成 2-3 个连通组，每组包含 2-3 个孔洞。剩余 1-2 个孔洞没有任何桥接通道连接（孤立）。生成约束：同一连通组内所有孔洞面积互不相同；桥接通道仅连接孔洞边缘像素，不在模板中形成额外的封闭区域。

**规则**：
1. 识别所有灰(5)模板内的黑(0)封闭区域。将面积 >= 2 的区域标记为孔洞，将宽度始终为 1 像素且两端分别连接两个不同孔洞的黑色路径标记为桥接通道。
2. 构建连通图：如果两个孔洞之间存在桥接通道，则它们属于同一连通组。通过传递闭包确定所有连通组。
3. 对每个连通组，按组内孔洞的面积从小到大排序，排名从 1 开始。
4. 按排名填充颜色：排名 1 → 蓝(1)，排名 2 → 红(2)，排名 3 → 绿(3)，排名 4 → 黄(4)。
5. 孤立孔洞（不属于任何连通组）保持黑(0)不填充。
6. 桥接通道保持黑(0)不变。

**关键洞察**：同样面积为 3 的孔洞，在一个组里可能排名第 1（填蓝），在另一个组里可能排名第 2（填红）——颜色不由绝对面积决定，而由组内相对排名决定。必须对比多个示例才能发现颜色取决于组内排名而非全局面积。
