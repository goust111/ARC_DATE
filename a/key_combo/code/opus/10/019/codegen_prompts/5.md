## 新题 5：标记像素定切分位、列序定下段色

**组合逻辑**：[分割](创新：切分点不是等分而是由标记像素的行位置决定) + [列序映射颜色](创新：从列序→前景色改为列序→切分下段色) + [重涂色](已有)

**来源原语**：竖直条/vertical_bar + 等分/equal_split + 下半变色/lower_half_recolored + 重涂色/recolor（ce9e57f2）, 列归属/column_membership + 列序映射颜色/column_rank_to_color（575b1a71）, 标记像素/marker_pixel + 同色配对/same_color_pairing（40853293）

**依赖链**：标记像素的行位置决定各竖条的切分高度（局部信息，逐条不同）→ 切分产生上段和下段 → 竖条在所有竖条中的列序排名决定下段颜色（全局信息，需比较所有竖条的列位置）。两条独立的信息流（标记行 → 切分位置，列位置 → 颜色）在同一竖条上汇合，缺少任何一条都无法确定输出。

每根竖直红条在其标记像素所在行处被切分为上下两段，上段保持红色，下段的颜色由该竖条在所有竖条中的从左到右列序排名决定。

**输入结构**：网格约 12x12。黑(0)背景。3-4 根竖直红(2)条，每根宽 1 像素，高度 4-10 像素不等，分布在不同列上，互不相邻。每根红条中恰好有一个像素被替换为另一种非红非黑颜色（即标记像素，用于指示切分行位置；各标记像素可以是不同颜色，如蓝(1)、绿(3)等，但标记自身的颜色不影响规则——仅其行位置有意义）。标记像素不在竖条的最顶行或最底行（确保切分后上下段均非空）。生成约束：各竖条位于不同的列。

**规则**：
1. 识别所有竖直红(2)条：每根是同一列中连续红(2)像素的极大竖直段。在每根红条中找到唯一的非红非黑像素——标记像素。
2. 以标记像素所在行为分界：从红条顶行到标记像素所在行（含标记行）为上段，标记行下方一行到红条底行为下段。
3. 上段（含标记像素位置）全部涂为红(2)（标记像素恢复为红色）。
4. 将所有竖条按其所在列从左到右排序，得到列序排名（最左 = 排名 1，次左 = 排名 2，以此类推）。
5. 下段按列序排名重涂色：排名 1 → 蓝(1)，排名 2 → 绿(3)，排名 3 → 黄(4)，排名 4 → 灰(5)。

**关键洞察**：每根竖条的输出由两个独立来源的信息共同决定——标记像素给出"在哪里切"（局部、逐条不同），列位置给出"切后下段涂什么色"（全局、需要横向比较所有竖条）。单看一根竖条无法确定下段颜色；单看列位置无法确定切分高度。

## 实现要求

1. `main(grid)` 必须实现新题描述中的确定性转换规则，不能只识别 `generate_input()` 的固定模板。禁止不同的input网格输出相同的output网格。
2. `generate_input()` 必须随机生成多样样例，不能固定死。随机维度应覆盖：网格大小、对象数量、位置、颜色、方向、形状参数或关键分支。注意若描述中存在若干，需实现而不是只有单个，包括object或者对应关系等等。且若涉及到最短路径，则输入网格中必涉及到多条路径，对选择造成干扰。

6. 若规则有多个分支，生成器不能长期固定成一个分支；应让分支在随机样例中合理出现。分支概率不必平均——难以发现的隐蔽分支（如少数情况下才触发的特殊规则）应适当提高出现概率，确保在 3 个训练示例中至少出现一次，否则求解者无法归纳该规则。对于颜色映射类规则，确保 2 个左右的示例即可覆盖所有映射关系（每种颜色→颜色的映射至少在某个示例中出现过）。
