## 新题 9：空心框内部的标记角定向对角扩展与面积优先叠压

**组合逻辑**：[擦除/erase + 填充/fill + 边框包围内部/frame_encloses_interior](空心框擦除后识别内部区域) + [标记位决定展开/marker_pos_sets_expansion + 对角方向/diagonal_dir](标记像素的角落位置决定对角扩展方向) + [贪心选择/greedy_selection + 从大到小优先/largest_first_priority + 非重叠约束/non_overlapping_constraint](扩展区域冲突时按面积优先级解决)

**来源原语**：擦除/erase + 填充/fill + 空心矩形/hollow_rectangle + 封闭区域/enclosed_region + 边框包围内部/frame_encloses_interior (d5d6de2d), 标记像素/marker_pixel + 标记位决定展开/marker_pos_sets_expansion + 对角方向/diagonal_dir + 填充色块/fill_block (4522001f), 贪心选择/greedy_selection + 从大到小优先/largest_first_priority + 非重叠约束/non_overlapping_constraint (31adaf00)

**依赖链**：每个空心框擦除后产生一个内部矩形区域 -> 框内角落的标记像素指定对角扩展方向 -> 每个内部区域沿指定对角方向产生一个偏移副本（原位 + 对角偏移位各一个色块）-> 不同框的扩展区域可能重叠 -> 面积较大的框的扩展区域优先占据重叠像素。框决定了区域形状；标记决定了扩展方向；面积优先规则决定了冲突解决——三者缺一不可。

擦除多个空心框边界后，按各框内角落标记的对角方向扩展其内部填充，扩展冲突时面积大的框优先。

**输入结构**：黑(0)背景上有 2 至 4 个不同颜色的空心矩形框（单像素宽边框，颜色各异，从蓝(1)、红(2)、绿(3)、黄(4)中取值），大小各不相同（内部区域从 2x2 到 5x5 不等）。每个框的内部有一个灰(5)标记像素，位于内部区域的四个角落之一（左上、右上、左下、右下）。网格约 18x18 至 22x22。生成约束：各框互不重叠且间距足够（至少间隔 2 像素）；每个框的对角扩展后至少有一对框的扩展区域存在重叠（以触发冲突解决）；扩展区域不超出网格边界。

**规则**：
1. 识别所有空心矩形框及其颜色。
2. 对每个框：记录其内部区域的矩形范围（不含边框像素），记录灰(5)标记像素在内部区域中的角落位置。
3. 擦除所有框的边框像素（变为黑背景）。擦除灰标记像素。
4. 对每个框，确定对角扩展方向：标记在左上角 -> 向右下扩展；标记在右上角 -> 向左下扩展；标记在左下角 -> 向右上扩展；标记在右下角 -> 向左上扩展（方向是从标记指向其对角）。
5. 对每个框，生成两个色块：(a) 原位色块——在内部区域的原始位置填充该框的颜色；(b) 偏移色块——将内部区域沿扩展方向平移（行偏移 = 内部区域高度，列偏移 = 内部区域宽度，符号由方向决定），在平移后的位置填充该框的颜色。
6. 冲突解决：按框的内部面积从大到小排序处理。先处理面积最大的框（绘制其两个色块），后处理面积较小的框。后绘制的色块不覆盖已绘制的像素（已占据像素保持先绘制者的颜色）。
7. 输出最终网格。

**关键洞察**：源题(4522001f)中对角扩展作用于一个 2x2 的微小结构，输出是固定的 4x4 块对。这里，对角扩展作用于任意大小的矩形内部，且多个框的扩展可能空间冲突——冲突解决引入了源题(31adaf00)的面积优先贪心策略，但规则方向相反：面积大的框优先绘制但后绘制者不覆盖，这意味着面积小的框在非重叠区域仍然可见。这种"先大后小、不覆盖"的规则与 31adaf00 的"先大后小、占据"逻辑形似但细节不同，需要对比有重叠和无重叠的示例才能归纳出精确的冲突解决机制。
