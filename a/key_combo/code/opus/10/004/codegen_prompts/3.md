## 新题 3：散布对象计数决定模板精灵体的缩放倍率

**组合逻辑**：[计数/counting](统计散布对象数量) -> [像素放大/pixel_scaling](计数值作为缩放因子) -> [平铺/tiling + 控制像素对应副本/control_pixel_to_copy](缩放后的模板沿控制线复制)

**来源原语**：计数/counting + 连通分量/connected_component + 数量决定边长/count_determines_side (d0f5fe59), 像素放大/pixel_scaling (4522001f), 模板精灵体/template_sprite + 控制像素行/control_pixel_line + 控制像素对应副本/control_pixel_to_copy + 间距保持一致/gaps_preserved (9b2a60aa), 重涂色/recolor (9b2a60aa)

**依赖链**：计数散布对象得到 N -> N 作为像素放大因子将模板精灵体缩放 -> 缩放后的模板沿控制像素行复制，每个副本重涂为对应控制像素的颜色，副本间距由控制像素间距按 N 倍展开。删去计数则缩放因子未知；删去模板则无内容可缩放；删去控制线则副本数量和颜色不确定。

统计网格中散布小对象的数量 N，将模板精灵体的每个像素放大为 NxN 块，然后沿控制像素行排列多个缩放副本。

**输入结构**：黑(0)背景上有三类元素。(a) 模板精灵体：一个红(2)的 4-连通单色小图形（3 至 6 像素），位于网格左上区域。(b) 控制像素行：一行水平排列的孤立像素（各像素颜色各异，其中恰好一个为红(2)与模板同色），位于网格底部某一行，各控制像素之间间隔 1 至 3 个黑背景像素。(c) 散布对象：2 至 4 个灰(5)的 4-连通小图形（每个 2 至 4 像素），散布在网格右半区域，各对象互不相邻且不与模板或控制线接触。网格约 20x25 至 25x30。生成约束：控制像素的间距和缩放后模板的尺寸保证所有副本能在网格宽度内排下且互不重叠。

**规则**：
1. 识别红(2) 4-连通模板精灵体，记录其形状（相对像素坐标集合）和边界框。
2. 识别灰(5) 4-连通散布对象，计数得到 N。
3. 将模板精灵体像素放大 N 倍：每个像素变为 NxN 的色块，边界框从 (h, w) 变为 (h*N, w*N)。
4. 读取控制像素行，从左到右排列。与红(2)控制像素对应的副本是模板自身（保持红色）；其他控制像素对应的副本使用该控制像素的颜色重涂。
5. 副本排列：以控制像素行的位置为基准，每个控制像素的水平位置映射为对应缩放副本的左边缘列坐标。具体地，设控制像素行中相邻两个像素的列间距为 d，则对应两个副本的左边缘列间距为 d * N。所有副本的底边行与控制像素行对齐。
6. 清除原始模板、散布对象和控制像素行；输出仅包含黑背景和排列好的缩放副本。

**关键洞察**：散布的灰色对象不参与输出的任何视觉内容——它们只是计数令牌，其数量编码了缩放因子。这与 d0f5fe59 中对象数量决定输出边长的思路同构，但在这里数量决定的是模板的缩放倍率而非网格大小。求解者需要对比不同示例中散布对象数量与输出模板尺寸的对应关系，才能归纳出"数量即缩放因子"这一非显然规则。
