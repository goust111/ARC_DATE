## 新题 8：图例查表确定配对色后射线填充对向间隙

**组合逻辑**：[查表替换 lookup_replace](从编码块解码改为确定配对关系) + [射线延伸 ray_extend](填充同色对向间隙而非缺口外泄) + [颜色与形状对应 color_shape_match](查表建立颜色等价类) → 查表-配对-填充链

**来源原语**：查表替换(#1 b20f7c8b)、图例面板(#1 b20f7c8b)、颜色与形状对应(#1 b20f7c8b)、射线延伸(#9 292dd178 / #17 2bee17df)、对边连通(#17 2bee17df)、无阻挡跨行列涂色(#17 2bee17df)

**依赖链**：图例面板建立"形状→颜色"映射 → 散落形状通过查表获得逻辑颜色 → 同逻辑颜色且在同行/列上对向的形状对之间的间隙被填充。查表改变了颜色语义（视觉颜色→逻辑颜色），填充依赖逻辑颜色的匹配而非视觉颜色。

通过图例面板将散落形状翻译为逻辑颜色，然后在同逻辑颜色的对向形状之间的无阻挡间隙中填充该逻辑颜色。

**输入结构**：约 16x16 的网格，背景黑(0)。左上角有一个约 5x5 的青(8)色实心面板（图例区），面板内用背景色挖出 2-3 个不同的小形状（每个形状 2-4 像素的连通孔洞），每个孔洞旁紧邻一个单色像素标签（颜色取自蓝(1)、红(2)、绿(3)），表示该形状对应的逻辑颜色。面板外的网格区域散布着 4-8 个小形状（各 2-4 像素，4-连通），每个形状使用黄(4)色绘制（视觉上颜色相同），但形状各异——每个形状与图例中某个形状在平移归一化后一致。不同示例中：图例中的形状和颜色标签不同，散落形状的位置不同。生成约束：每种图例形状在散落区域恰好出现偶数次（2 或 4 次）；同一逻辑颜色的形状中，至少存在一对在同一行或同一列上且之间无其他非背景像素阻挡。

**规则**：
1. 从图例面板中提取每个孔洞形状（平移归一化）及其对应的颜色标签，建立形状→逻辑颜色的映射表。
2. 对网格中每个黄(4)色散落形状，将其形状平移归一化后查表，获得其逻辑颜色。
3. 将每个散落形状的黄色像素重涂为其逻辑颜色。
4. 对所有同逻辑颜色的形状对，检查是否存在同行或同列的对向关系（两个形状的边界框在某一行或某一列上有重叠投影，且该行/列上两形状之间的所有像素均为背景色）。
5. 对满足条件的对向形状对，将两者之间该行/列上的所有背景像素填充为该逻辑颜色。
6. 若多对形状的填充路径在某像素交叉，按逻辑颜色在图例中从上到下的出现顺序决定优先级，排位靠上的颜色覆盖排位靠下的。
7. 保持图例面板区域不变。

**关键洞察**：散落形状视觉上颜色完全相同（都是黄色），无法直接判断哪些应该互相连接——必须通过形状查表将它们分类为不同逻辑颜色后，才能确定配对和填充关系。查表不是改变外观而是揭示隐藏的分组结构。
