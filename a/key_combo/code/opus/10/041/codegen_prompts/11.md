## 新题 11：双色图像提取后作为模板瓦片进行双层平铺

**组合逻辑**：[裁剪/提取 crop+extract](从混合网格中分离目标图像) + [平铺 tile](提取物作为瓦片重复铺设) + [行列乘积完整 row_col_product](提取判据) + [双层图案叠加 two_level_pattern](提取物既是精细层又与粗糙层交互) → 提取驱动平铺

**来源原语**：裁剪(#13 b71a7747)、提取(#13 b71a7747)、行列乘积完整(#13 b71a7747)、双色图像(#13 b71a7747)、平铺(#3 f931b4a8)、模板瓦片(#3 f931b4a8)、像素数决定尺寸(#3 f931b4a8)、双层图案叠加(#3 f931b4a8)、控制区域(#3 f931b4a8)

**依赖链**：行列乘积判据定位并提取双色子图 → 提取出的子图成为平铺模板 → 控制区域像素数决定平铺尺寸 → 执行双层平铺。提取步骤的输出是平铺步骤的输入模板——不完成提取就没有可用的瓦片。

从混合网格中按行列乘积完整准则提取隐藏的双色图像，用它作为瓦片按控制区域指定的尺寸进行平铺输出。

**输入结构**：约 16x16 的网格，无统一背景色。网格被分为三个区域（由灰(5)色单像素线分隔）：上半区（约 10x16）是一个充满多种颜色像素的混合区域，其中隐藏着一对颜色（如蓝(1)和红(2)），这对颜色的像素恰好覆盖了它们所在行和所在列的完整叉积（即若这对颜色出现在行 {r1,r2,r3} 和列 {c1,c2,c3,c4}，则这 12 个交叉位置全部被蓝或红占据），其余颜色不满足此条件。下半区左侧（约 3x3）是控制区域 A，包含若干橙(7)色像素（非背景像素数 = 输出高度）。下半区右侧（约 3x3）是控制区域 B，包含若干橙(7)色像素（非背景像素数 = 输出宽度）。控制区域的背景为黑(0)。不同示例中：隐藏双色图像的行列位置、颜色对、控制区域像素数均不同。生成约束：恰好有一对颜色满足行列乘积完整条件；提取后的双色子图尺寸不大于控制区域指定的输出尺寸。

**规则**：
1. 在上半区中，枚举所有颜色对 (c_a, c_b)，找到唯一满足以下条件的颜色对：将 c_a 和 c_b 像素合并后，它们覆盖的行集 R 和列集 C 的叉积 R x C 中每个位置恰好是 c_a 或 c_b（无遗漏、无其他颜色侵入）。
2. 保留这些行和列，删除其他行和列，得到提取的双色子图 P（尺寸 |R| x |C|）。
3. 统计控制区域 A 中非黑像素数为 H，控制区域 B 中非黑像素数为 W。
4. 生成 H x W 的输出网格，将 P 作为瓦片在输出中周期性平铺（行方向以 |R| 为周期，列方向以 |C| 为周期），超出部分截断。

**关键洞察**：上半区视觉上是杂乱的多色网格，隐藏双色图像不靠颜色稀有性或空间连通性识别，而靠行列乘积完整这一代数判据——必须检验每对颜色的行列覆盖才能定位目标，提取物随后作为瓦片进入完全不同的平铺逻辑。
