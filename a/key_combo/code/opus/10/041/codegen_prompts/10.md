## 新题 10：链式填充路径由包含层级约束宽度

**组合逻辑**：[链式填充 chain_fill](填充宽度不由首块决定，而由包含层级决定) + [严格包含 strict_containment](包含深度转化为宽度参数) + [拼接 assemble](多个链从不同凹槽生长) → 包含层级参数化链式生长

**来源原语**：链式填充(#6 16b78196)、凹槽(#6 16b78196)、中心条(#6 16b78196)、固定条带宽度(#6 16b78196)、严格包含(#7 7d1f7ee8)、矩形边框(#7 7d1f7ee8)、拼接(#6 16b78196)

**依赖链**：包含层级分析确定每个凹槽的深度 → 深度决定该凹槽启动的链式填充的条带宽度 → 不同宽度的链从不同凹槽独立生长。层级分析是全局的，链式填充是局部的，前者的全局信息参数化了后者的局部行为。

中心条的凹槽处于不同嵌套深度的矩形框内，凹槽的包含深度决定了从该凹槽生长出的链式填充条带宽度。

**输入结构**：约 20x20 的网格，背景黑(0)。网格中央有一根灰(5)色的水平或垂直实心条（宽 2 像素，长约 12-14 像素），条的边界上有 2-3 个凹槽（背景色的缺口，每个缺口宽 1-3 像素）。凹槽处于不同的空间环境中：某些凹槽外围有 1 层矩形框包围（蓝(1)色），某些凹槽外围有 2 层嵌套矩形框包围（蓝(1)色外层 + 红(2)色内层），某些凹槽不被任何框包围。矩形框为单像素厚、不完全封闭（在朝向中心条的一侧有开口以容纳凹槽连接）。散落在网格各处的有若干单色精灵体（3-6 像素的不规则连通分量），颜色各异。不同示例中：凹槽数量和位置不同，包围框的层数不同，精灵形状和颜色不同。生成约束：每个凹槽的包含深度（0 = 不被框包围，1 = 被 1 层框包围，2 = 被 2 层框包围）对应链式填充条带宽度（深度 0 → 宽度 1，深度 1 → 宽度 2，深度 2 → 宽度 3）；每个凹槽处恰好有一个精灵的形状能精确填入凹槽。

**规则**：
1. 识别中心条及其凹槽。对每个凹槽，计算其包含深度 d（该凹槽中心点被多少层矩形框严格包含）。
2. 根据深度确定该凹槽的链式填充条带宽度 w = d + 1。
3. 在散落精灵中，找到形状能精确填入该凹槽的根精灵（根精灵的形状与凹槽的背景孔洞形状完全吻合）。
4. 将根精灵放入凹槽（颜色保持根精灵原色）。从根精灵开始，沿垂直于中心条的方向向外链式生长：每一级新块占据前一级块边界框内的背景像素区域，限制在宽度 w 的条带内（以凹槽中心线为轴心），颜色循环使用根精灵颜色。链式生长直到条带内无更多背景像素可填（遇到网格边界或非背景像素）。
5. 不同凹槽的链独立生长，互不干扰。若链路径重叠，先处理深度大的凹槽（深度大 → 条带宽 → 优先级高）。
6. 保持中心条、矩形框不变。清除未被使用的散落精灵（设为背景色）。

**关键洞察**：链式填充的条带宽度不是由首块自身决定的，而是由凹槽所处的嵌套环境决定——同一中心条上的不同凹槽因为处于不同包含深度而生成不同粗细的链，这是包含层级分析与链式生长的结构耦合。
