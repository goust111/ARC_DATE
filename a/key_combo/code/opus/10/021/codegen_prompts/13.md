## 新题 13：镜像产生双色图案后按面积差异擦除半边

**组合逻辑**：[镜像/mirror + 分隔线为对称轴/separator_as_reflection_axis](创新：镜像不在原位互换颜色，而是在反射侧生成一个与原图颜色不同的副本) + [计数/counting + 面积筛选/area_filtering](创新：计数两侧各自的前景面积，面积大的一侧保留) + [擦除/erase](创新：擦除整个半边而非单个对象)

**来源原语**：镜像/mirror、分隔线/separator_line、分隔线为对称轴/separator_as_reflection_axis、双色源图案/two_color_source_pattern(参考题 2b01abd0)；计数/counting、面积筛选/area_filtering(参考题 a3325580)；擦除/erase(参考题 54db823b)

**依赖链**：识别分隔线和其一侧的源图案 → 将源图案镜像到另一侧并重涂为不同颜色 → 比较两侧前景像素的面积 → 擦除面积较小的一侧 → 输出仅含面积较大一侧的裁剪结果。镜像生成了两个候选输出，面积比较决定了保留哪个。

将单侧源图案镜像到分隔线另一侧并换色，然后保留前景面积较大的一侧，擦除另一侧并裁剪输出。

**输入结构**：约 10x21 的网格，黑(0)背景。一条灰(5)色竖直分隔线位于网格正中列，将网格分为左右两个约 10x10 的区域。一侧（左或右，不固定）包含一个由两种非黑颜色（如红(2)和蓝(1)）构成的源图案（4-连通图形，约 12~20 像素，边界框约 5x5~7x7）。另一侧为纯黑背景。源图案的两种颜色中，一种的像素数严格多于另一种。生成约束：源图案关于分隔线的镜像位置完全落在另一侧区域内（不越过网格边缘）；源图案不接触分隔线（间隔至少 1 列）。

**规则**：
1. 识别灰(5)竖直分隔线，确定其列位置 c_sep。
2. 找到源图案所在的一侧（含有非黑非灰像素的一侧）。
3. 确定源图案使用的两种颜色，其中像素数较多的为"主色"、较少的为"副色"。
4. 将源图案关于 c_sep 镜像到另一侧：镜像副本中，原来的主色像素涂为副色，原来的副色像素涂为主色（即主副色互换）。
5. 现在两侧各有一个图案。计算每侧非背景像素中主色（以该侧自身的定义）的像素数——源侧的主色像素数为原始主色像素数，镜像侧的主色像素数为原始副色像素数（因为互换了）。
6. 保留主色像素数较多的一侧（即原始源侧），擦除另一侧的所有非背景像素（置为黑(0)）。
7. 移除分隔线列，将保留侧裁剪输出（输出宽度为原宽度减 1 再除以 2）。

**关键洞察**：镜像加颜色互换后，两侧看起来形状完全相同但颜色分配相反。选择保留哪一侧的规则基于"主色面积更大的一侧胜出"——由于互换后镜像侧的主色变少了，实际上总是保留原始源侧。但求解者需要理解整个镜像-互换-比较的逻辑链才能确信这一规则，因为不同示例中源侧可能在左也可能在右。
