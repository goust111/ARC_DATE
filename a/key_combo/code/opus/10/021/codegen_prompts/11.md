## 新题 11：分隔面板中精灵体的孔洞数决定循环位移量

**组合逻辑**：[裁剪/crop + 分隔条/separator_bar + 等分面板/equal_panel](创新：面板不用于叠加合并，而是提供独立的计数上下文) + [计数/counting + 封闭背景区域/enclosed_background_region](创新：孔洞数不映射颜色，而是编码位移量) + [循环位移/cyclic_roll](创新：位移量不来自控制列标记，而是来自同一面板中图形的孔洞数)

**来源原语**：裁剪/crop、分隔条/separator_bar、等分面板/equal_panel(参考题 5ecac7f7)；计数/counting、封闭背景区域/enclosed_background_region、孔洞数映射颜色/hole_count_to_color_mapping(参考题 37d3e8b2)；循环位移/cyclic_roll、标记位定位移量/marker_is_shift(参考题 6d1d5c90)

**依赖链**：分隔条划分面板 → 每个面板含一个有孔洞的精灵体和一个条纹图案 → 数精灵体的孔洞数 → 孔洞数作为该面板中条纹图案的循环下移行数 → 对每个面板独立执行循环位移 → 拼接所有位移后的面板。孔洞计数直接决定位移量，二者不可分离。

每个面板中精灵体的封闭孔洞数编码了该面板内条纹图案的循环下移行数，各面板独立位移后拼接输出。

**输入结构**：约 10x23 的网格，黑(0)背景。两条灰(5)色竖直分隔线将网格等分为三个约 10x7 的面板。每个面板分为上下两个区域：上方约 4 行放置一个彩色精灵体（面板各自的颜色：左红(2)、中蓝(1)、右绿(3)），精灵体是不规则 4-连通图形（约 8~14 像素），内部有 1~3 个封闭的黑(0)背景孔洞（每个孔洞 1~2 像素），三个面板的孔洞数互不相同。下方约 6 行是一个黄(4)和黑(0)交替的水平条纹图案（每行要么全黄要么全黑，从分界行起奇偶交替）。生成约束：精灵体完全位于面板上半部分，条纹图案完全位于下半部分，二者不接触；三个面板的孔洞数恰好是 {1,2,3} 的某个排列。

**规则**：
1. 识别灰(5)分隔线，裁剪出三个面板。
2. 在每个面板中，识别上半部分的彩色精灵体和下半部分的条纹图案区域。分界行定义为面板内从上到下第一个全黑或全黄的行。
3. 统计每个面板中精灵体内部的封闭黑(0)背景连通分量数目，记为 h（1、2 或 3）。
4. 对每个面板的条纹图案区域，将该区域的行循环下移 h 行（底部溢出的行回卷到条纹区域顶部）。精灵体区域保持不变。
5. 将三个处理后的面板从左到右拼接（中间恢复灰(5)分隔线），输出完整网格。

**关键洞察**：精灵体本身在输出中外形不变，但它的内部拓扑结构（孔洞数）隐式地控制了同面板内另一个完全独立的图案的变换参数。求解者需要发现精灵体与条纹图案之间跨区域的因果关系。
