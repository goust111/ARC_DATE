## 新题 12：连线构建矩形框后框内棋盘格按控制像素着色

**组合逻辑**：[连线/draw_line + 控制像素/control_pixel](创新：连线不连接枢轴到边界，而是在控制像素之间构建矩形框的边) + [棋盘格图案/checkerboard_pattern](创新：棋盘格不是输入的背景，而是在框内生成的输出图案) + [重涂色/recolor + 位序选择/positional_selection](创新：棋盘格的两种颜色由控制像素的位置属性决定)

**来源原语**：连线/draw_line、控制像素/control_pixel、矩形框/rect_frame(参考题 e4075551)；棋盘格图案/checkerboard_pattern(参考题 80a900e0)；重涂色/recolor(参考题 2a5f8217)；位序选择/positional_selection(参考题 5ecac7f7)

**依赖链**：找到四个控制像素确定矩形范围 → 四个控制像素中最上方和最左方的颜色成为棋盘格的两种颜色 → 在矩形框内部填充棋盘格图案 → 矩形框边界用剩余两个控制像素的颜色交替着色。连线（画框边）与棋盘格生成依赖于同一组控制像素的位置和颜色信息，但使用方式完全不同。

四个控制像素确定矩形区域，其中两个的颜色定义框内棋盘格的双色，另两个的颜色交替绘制矩形边框。

**输入结构**：约 15x15 的网格，黑(0)背景。网格中有恰好四个单像素控制点，颜色互不相同（使用红(2)、蓝(1)、绿(3)、黄(4)中的四种）。四个控制点分别承担最上（行最小）、最下（行最大）、最左（列最小）、最右（列最大）四个极值位置，且每个控制点只承担一个极值。生成约束：四个控制点互不共行也互不共列；由极值定义的矩形框内部（不含边框）至少为 4x4（保证棋盘格可见）；四个控制点不位于矩形框的角上（即最上点的列不等于最左或最右点的列，以此类推）。

**规则**：
1. 找到四个控制像素，确定最上行 r_top、最下行 r_bot、最左列 c_left、最右列 c_right。
2. 确定棋盘格的两种颜色：色 A 为最上方控制点的颜色，色 B 为最左方控制点的颜色。
3. 确定边框的两种颜色：色 C 为最下方控制点的颜色，色 D 为最右方控制点的颜色。
4. 绘制矩形边框：边框像素位于第 r_top 行、第 r_bot 行（水平边）以及第 c_left 列、第 c_right 列（垂直边）的 r_top 到 r_bot 范围内。边框像素按 (行+列) 的奇偶交替使用色 C 和色 D：(行+列) 为偶数涂色 C，奇数涂色 D。
5. 在矩形框内部（r_top+1 到 r_bot-1 行，c_left+1 到 c_right-1 列）填充棋盘格图案：(行+列) 为偶数涂色 A，奇数涂色 B。
6. 四个控制点原来的位置被边框或内部图案覆盖。框外保持黑(0)背景。

**关键洞察**：四个控制像素被分成两组发挥不同作用：位于上方和左方的贡献棋盘格内部颜色，位于下方和右方的贡献边框颜色。这种按方位分组的规则需要对比多个示例（控制点颜色变化但分组规则不变）才能归纳。
