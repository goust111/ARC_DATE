## 新题 2：连接杆编码周期平铺

**组合逻辑**：[擦除](已有) + [平铺](创新：平铺方向由连接杆几何结构编码) + [周期内指定位变色](创新：变色周期由连接杆长度编码)

**来源原语**：连接杆/connector_stem（98cf29f8）、擦除/erase（98cf29f8）、平铺/tiling（e8dc4411）、指示决定方向色/indicator_dir_color（e8dc4411）、邻接触碰/adjacency_touch（e8dc4411）、周期排布/periodic_layout（d304284e）、周期内指定位变色/cyclic_pos_recolored（d304284e）

**依赖链**：连接杆方向 → 决定平铺延伸方向；连接杆长度 → 决定重涂色的周期间隔；杆末端标记颜色 → 决定变色目标色。三个参数全部从同一个几何结构中提取，形成紧密的信息编码关系。

每个精灵体的连接杆方向决定平铺延伸方向，连接杆长度 L 决定周期——每连续 L 个副本中最后一个被重涂为杆末端标记的颜色。

**输入结构**：
- 约 20x20 黑(0)背景网格
- 2~3 个不同颜色的精灵体，每个为 4-连通单色前景对象（3~6 像素，非矩形非对称），颜色各不相同（如蓝(1)、绿(3)）
- 每个精灵体有一条同色的单像素宽直线连接杆（长度 2~4 像素）沿某个正方向（上/下/左/右）延伸
- 每条连接杆的远端（远离精灵体的末端像素）紧邻一个不同颜色的单像素标记（标记与杆末端 4-邻域接触），各标记颜色互不相同且与精灵体颜色不同（如红(2)、黄(4)）
- 生成约束：各精灵体沿其杆方向的平铺路径互不交叉（边界框投影不重叠）；精灵体分布在网格的不同区域；至少有一个精灵体的杆方向不是向下

**规则**：
1. 对每个精灵体，识别其连接杆：从精灵体边缘沿某正方向延伸的同色单像素宽直线段。杆的方向即为平铺方向，杆的长度 L 为杆像素数（不含精灵体本体像素，不含末端标记像素）
2. 记录杆末端紧邻的单像素标记的颜色，作为该精灵体的变色目标色
3. 擦除所有连接杆像素和末端标记像素（精灵体本体保留）
4. 沿连接杆方向，以精灵体边界框在该方向的尺寸 + 1 为步幅，从精灵体的相邻位置开始，依次放置精灵体的副本，直到副本完全超出网格边缘（部分超出的副本保留网格内部分，裁剪掉超出部分）
5. 将原始精灵体视为序列中的第 1 号元素。副本依次编号为 2, 3, 4, ...。在每组连续 L 个元素中，编号为 L 的倍数的元素被重涂为该精灵体的变色目标色，其余保持原色
6. 不同精灵体的平铺序列若发生像素重叠（因生成约束此情况不会出现，仅作保险规则），按精灵体边界框左上角的行优先、列次优先排序，靠后的覆盖靠前的

**关键洞察**：连接杆在源题中是滑动路径（编码距离和方向以供物体平移），但在本题中被重新诠释为参数编码器——同一根杆同时编码了"往哪铺"（方向）和"每几个变色"（长度=周期），两个参数从同一个几何结构中提取。求解者必须意识到杆的长度不是无关细节而是关键参数。
