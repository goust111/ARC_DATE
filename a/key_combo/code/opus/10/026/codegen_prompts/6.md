## 新题 6：双镜像约束下的旋转匹配放置

**组合逻辑**：[旋转](已有) + [镜像](创新：锚点同时约束原像和镜像两个放置位置) + [形状匹配](已有) + [稀疏像素引导放置](创新：部分锚点属于原像、部分属于镜像，事先不可区分)

**来源原语**：旋转/rotate（0e206a2e）、镜像/mirror（6fa7a44f, ad3b40cf）、形状匹配/shape_matching（1caeab9d）、颜色一致对齐/color_consistent_align（0e206a2e）、稀疏像素引导放置/sparse_pixels_guide_placement（0e206a2e）、翻转后拼接/flip_append（6fa7a44f）、沿轴反射/reflect_along_axis（ad3b40cf）

**依赖链**：稀疏锚点像素同时约束精灵体原像（上半区）和镜像（下半区）的位置和颜色 → 求解者无法事先区分哪些锚点属于原像、哪些属于镜像 → 必须同时搜索旋转变体和放置位置使原像+镜像一起覆盖所有锚点 → 这是一个同时约束满足问题而非线性流水线。

从 8 种旋转/翻转变体中找到唯一一种，使精灵体放在上半区、其上下镜像放在下半区对称位置后，两者合计覆盖所有散布的锚点像素且颜色完全一致。

**输入结构**：
- 约 12x16（宽 x 高）黑(0)背景网格，高度为偶数
- 一个多色精灵体（由蓝(1)和红(2)像素组成，4-连通，约 6~10 像素，非对称——8 种旋转/翻转变体两两不同），位于网格的某个角落区域
- 6~10 个散布的单像素锚点（颜色为蓝(1)或红(2)），分布在网格的上半区（行 0 到行 height/2-1）和下半区（行 height/2 到行 height-1）
- 网格的水平中线（行 height/2 的位置）是隐含的镜像轴
- 生成约束：恰好只有一个旋转/翻转变体和一个上半区放置位置满足以下条件——将该变体放在上半区该位置后，其关于水平中线的上下镜像放在下半区对称位置，两个放置合计的所有前景像素与全部锚点像素在位置和颜色上完全一致（锚点不多不少恰好被覆盖）；精灵体原像和镜像不跨越中线，不与角落的原始精灵体重叠

**规则**：
1. 分离精灵体（最大多色连通对象）和单像素锚点（孤立的蓝(1)或红(2)像素）
2. 确定网格高度 H，水平中线轴位于行 H/2（中线本身不属于上半区或下半区，但若 H 为偶数则中线在行 H/2 和行 H/2-1 之间）
3. 生成精灵体的 8 种变体（0/90/180/270 度旋转，每种可选是否左右翻转）
4. 对每种变体和上半区的每个可能放置位置（变体完全位于行 0 到行 H/2-1 内）：
   a. 在该位置放置变体
   b. 将变体关于水平中线做上下镜像，计算镜像位置（每个像素 (r, c) 映射到 (H-1-r, c)）
   c. 检查：原像和镜像的所有前景像素的位置和颜色集合是否与所有锚点像素的位置和颜色集合完全相同
5. 选择唯一满足条件的变体和位置
6. 擦除原始精灵体（角落区域的）和所有锚点像素
7. 在确定的位置绘制变体原像（蓝(1)和红(2)像素），在镜像位置绘制上下镜像
8. 原像和镜像不会重叠（生成约束保证）

**关键洞察**：锚点中有些属于上半区的原像、有些属于下半区的镜像，但求解者无法事先判断哪些是哪些。仅看上半区的锚点可能存在多个旋转变体都能匹配，加入下半区锚点的约束后才收敛到唯一解。这迫使求解者将旋转搜索和镜像约束作为一个整体问题同时求解，而非分步执行。
