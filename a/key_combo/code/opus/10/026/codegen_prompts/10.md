## 新题 10：对角偏移平铺中的晶格坐标标记

**组合逻辑**：[对角偏移重复](已有) + [标记](创新：每个副本内的标记位置由晶格坐标决定) + [尺寸决定步幅](已有) + [局部对应晶格坐标](创新：从全局晶格坐标映射到局部像素坐标)

**来源原语**：对角偏移重复/diag_offset_repeat（e619ca6e）、尺寸决定步幅/size_determines_stride（e619ca6e）、实心矩形/solid_rect（e619ca6e）、裁剪/clip（e619ca6e）、自相似晶格映射/self_similar_lattice_mapping（456873bc）、局部对应晶格坐标/local_maps_lattice_coord（456873bc）、标记/mark（456873bc）、重涂色/recolor（456873bc）

**依赖链**：矩形尺寸决定对角偏移步幅 → 沿两个向下对角方向放置副本 → 每个副本在对角晶格中获得一个坐标 (i, j) → 坐标通过取模映射到副本内部的一个像素位置 → 该像素被标记为另一种颜色。每个副本外观几乎相同但内部各有一个独特的标记点，标记位置编码了其全局晶格坐标。

将实心矩形沿两个向下对角方向按自身尺寸为步幅重复放置，每个副本内标记一个像素——标记位置是该副本在对角晶格中的坐标对矩形尺寸取模后的内部像素。

**输入结构**：
- 约 20x20 黑(0)背景网格
- 一个红(2)实心矩形（高 h 行 x 宽 w 列，约 3x3 到 4x4）
- 矩形内恰好有一个像素被涂为青(8)，位于矩形内部的第 0 行第 0 列（即左上角，表示原始矩形的晶格坐标 (0,0)）
- 矩形位于网格中偏上偏中的位置，使得至少向两个对角方向各能放置 2 个完整或部分副本
- 生成约束：h 和 w 均至少为 3（以确保取模映射不退化）

**规则**：
1. 识别红(2)实心矩形及其内部的青(8)标记像素，确定矩形的高 h 和宽 w
2. 将原始矩形的晶格坐标定义为 (0, 0)
3. 沿向下-左对角方向，以步幅 (h, -w) 放置副本，依次编号为 (1, -1), (2, -2), ...；直到副本完全超出网格（部分超出者保留网格内部分并裁剪）
4. 沿向下-右对角方向，以步幅 (h, w) 放置副本，依次编号为 (1, 1), (2, 2), ...；同样裁剪和停止
5. 每个副本（包括原始矩形）全部绘制为红(2)实心矩形
6. 对每个副本，取其晶格坐标 (i, j)，计算内部标记位置：标记行 = |i| mod h，标记列 = |j| mod w
7. 将该副本内部第（标记行）行第（标记列）列的像素从红(2)重涂为青(8)
8. 若副本被裁剪导致标记位置不在网格内，则该副本没有可见标记

**关键洞察**：每个副本看起来几乎相同（都是红色实心矩形），但内部各有一个独特的青色标记点。标记点的位置不是随机的——它系统性地编码了该副本在全局对角晶格中的坐标。求解者必须发现晶格坐标到局部像素坐标的取模映射关系，而这种映射只有在对比多个副本的标记位置后才能归纳得出。

Complete a self-similar lattice of red sprites and mark each copy's lattice coordinate in teal.

Input structure
- The grid is a square partitioned into a k by k lattice of k by k slots, with
  uniform background separators between slots.
- One foreground color forms a solid rectangle that hides one whole slot row
  or one whole slot column; the other foreground color forms repeated copies
  of a single k by k sprite in the visible slots.

Rule
- Use the sprite's own foreground mask as the coarse lattice mask: a slot
  contains a copy exactly when the corresponding cell in the sprite is filled.
- Erase the occluder, redraw every required sprite copy, and recolor in each
  copy the cell whose local coordinate equals that copy's lattice coordinate.

Key insight
- The repeated sprite is a miniature map of the complete coarse arrangement,
  so the hidden row or column is recovered by reading that miniature map.
</description>

## 实现要求

1. `main(grid)` 必须实现新题描述中的确定性转换规则，不能只识别 `generate_input()` 的固定模板。禁止不同的input网格输出相同的output网格。
2. `generate_input()` 必须随机生成多样样例，不能固定死。随机维度应覆盖：网格大小、对象数量、位置、颜色、方向、形状参数或关键分支。注意若描述中存在若干，需实现而不是只有单个，包括object或者对应关系等等。且若涉及到最短路径，则输入网格中必涉及到多条路径，对选择造成干扰。
3. 生成器必须保证输入满足 `main()` 的隐式假设：对象不重叠、不越界、特殊标记唯一或可区分、匹配关系无歧义、关键分支出现概率相同。
4. 禁止把 ARC 颜色 id 、亮度、拼写等当作人类不可见的数值语义参与排序、大小比较或隐藏映射。颜色变化必须有可见结构线索。注意颜色亮度、拼写等也是不可见信息，若描述中出现违规的颜色id或者亮度，可自行使用少量的固定颜色替代，但注意生成时要在三个以内输入输出网格中对所有变换100%覆盖度。
5. 输出样例要视觉清晰，人类必须能从输入输出对中肉眼辨认出规律。具体要求：避免对象粘连、覆盖关系混乱、同一像素多重语义；不同逻辑步骤产生的结果不要大面积层叠在一起导致无法分辨哪个颜色属于哪个步骤；输入中各元素之间保持足够间距，输出中新增的标记/填充/路径等应与背景和已有元素在颜色上有明显区分；若规则涉及多层叠加，生成时控制对象密度和尺寸，确保叠加区域只占少数像素而非铺满整个网格。
6. 若规则有多个分支，生成器不能长期固定成一个分支；应让分支在随机样例中合理出现。分支概率不必平均——难以发现的隐蔽分支（如少数情况下才触发的特殊规则）应适当提高出现概率，确保在 3 个训练示例中至少出现一次，否则求解者无法归纳该规则。对于颜色映射类规则，确保 2 个左右的示例即可覆盖所有映射关系（每种颜色→颜色的映射至少在某个示例中出现过）。
