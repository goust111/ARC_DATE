## 新题 3：对称补全驱动计数蛇形摘要

**组合逻辑**：[对称补全](已有) + [计数](创新：计数对象是补全后的像素而非原始像素) + [排序](已有) + [蛇形填充](已有)

**来源原语**：对称补全/symmetry_completion（929ab4e9）、八重对称轨道/eightfold_orbit（929ab4e9）、轨道内唯一可见色/unique_color_in_orbit（929ab4e9）、遮罩像素/mask_pixel（929ab4e9）、计数/counting（5289ad53）、分类计数/categorical_count（5289ad53）、排序/sort（cdecee7f）、蛇形填充/boustrophedon_fill（cdecee7f）、奇行反序/odd_row_reversed（cdecee7f）

**依赖链**：遮罩像素隐藏了部分前景 → 对称补全恢复被遮罩的像素 → 恢复的像素改变了各颜色的计数结果 → 按补全后的计数排序颜色 → 以蛇形顺序将排序后的颜色填入摘要网格。若跳过补全直接计数，结果会不同。

先用八重对称补全恢复被遮罩的像素，再统计各前景色的像素数并按降序排列，以蛇形顺序将每种颜色按其计数填入 3x3 摘要网格。

**输入结构**：
- 一个正方形网格（边长 9 或 11，为奇数），黑(0)背景
- 恰好 3 种非黑前景色（从蓝(1)、红(2)、绿(3)、黄(4)中选取）形成具有八重对称性的图案（关于水平轴、垂直轴、主对角线、副对角线均对称）
- 灰(5)作为遮罩色，覆盖了若干本应有前景色的位置（将原有前景色替换为灰(5)）
- 忽略灰(5)后，每个八重对称轨道中至少有一个非黑(0)非灰(5)的可见像素
- 生成约束：补全后 3 种前景色的像素数两两不同，且三者之和恰好为 9；至少一种颜色的补全前可见计数与补全后计数不同（即遮罩确实隐藏了某些颜色的像素）

**规则**：
1. 识别灰(5)为遮罩色
2. 对每个灰(5)像素，计算其在正方形的八重对称群下的完整轨道（恒等、90/180/270度旋转、水平/垂直/主对角/副对角反射，共 8 个变换，去重后得到轨道）
3. 在该轨道的所有位置中找到唯一的非黑(0)非灰(5)颜色，将该灰(5)像素替换为此颜色
4. 补全完成后，统计每种非黑前景色的总像素数
5. 按像素数从多到少排序 3 种颜色（生成约束保证无并列）
6. 创建 3x3 黑(0)输出网格
7. 按排序顺序依次填入各颜色：第一种颜色填入其像素数个格子，紧接着第二种颜色填入其像素数个格子，最后第三种颜色填入剩余格子。填充路径为蛇形——第 0 行从左到右，第 1 行从右到左，第 2 行从左到右

**关键洞察**：遮罩不是均匀覆盖各颜色的——某些颜色被遮罩的比例更高，导致补全前后该颜色的排名发生变化。求解者如果直接统计可见像素会得到错误的排序，必须先完成对称补全才能获得正确计数。
