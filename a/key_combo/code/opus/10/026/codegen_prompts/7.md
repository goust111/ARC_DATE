## 新题 7：指示方向平铺后全局重力堆叠

**组合逻辑**：[平铺](已有) + [重力下落](创新：对平铺完成后的全部副本施加重力) + [碰撞阻挡](创新：不同方向平铺产生的副本在重力下互相碰撞堆叠) + [指示决定方向色](已有)

**来源原语**：平铺/tiling（e8dc4411）、指示像素/indicator_pixel（e8dc4411）、邻接触碰/adjacency_touch（e8dc4411）、指示决定方向色/indicator_dir_color（e8dc4411）、重力下落/gravity_drop（84ba50d3）、碰撞阻挡/collision_blocking（98cf29f8）、穿透与停靠/pass_through_or_stop（84ba50d3）

**依赖链**：指示像素方向 → 决定各方向的平铺路径 → 平铺产生多方向的彩色副本 → 全局重力将所有副本（含原始模板）向下拉 → 不同颜色的副本在下落中碰撞堆叠。平铺的空间布局决定了重力后的堆叠形态，而堆叠结果与任何单一平铺方向的输出都不同。

将黑色模板沿各指示像素方向平铺并着色后，对全部副本施加向下重力，副本之间碰撞堆叠形成最终布局。

**输入结构**：
- 约 18x18 灰(5)背景网格
- 一个黑(0)的 4-连通模板对象（约 3x3 边界框，3~6 像素，非矩形），位于网格上半区
- 2~3 个单像素指示对象紧邻模板边界（与模板的某个像素 4-邻域接触），颜色各不相同且非灰(5)非黑(0)（如红(2)、蓝(1)、绿(3)）
- 生成约束：至少一个指示像素指向上方或水平方向（使平铺后存在"悬空"的副本需要重力下落）；各方向的平铺副本的边界框列范围可以重叠（以产生碰撞堆叠）

**规则**：
1. 识别灰(5)背景、黑(0)模板对象和紧邻模板的单像素指示对象
2. 对每个指示像素，确定其相对于模板的方向（从模板中心指向指示像素的方向：上/下/左/右，取最近的正方向）和颜色
3. 擦除所有指示像素（恢复为灰(5)背景）
4. 沿每个指示方向，以模板边界框在该方向的尺寸 + 1 为步幅，从模板相邻位置开始放置副本。副本使用对应指示像素的颜色（非黑(0)），直到副本完全超出网格边缘（部分超出者保留网格内部分）
5. 原始黑(0)模板保持不变
6. 对全部非灰(5)像素（包括黑(0)模板像素和所有彩色副本像素）施加向下重力：每个非灰像素在其所在列独立下落，落到网格底行或落到该列已堆积的非灰像素上方时停止
7. 同一列中多个像素的下落顺序：从最底行的像素开始处理，依次向上（自然重力堆积顺序）
8. 像素颜色在下落过程中保持不变

**关键洞察**：向上和向左/向右方向的平铺副本在重力作用下会向下坠落并与向下方向的副本碰撞堆叠，形成一个非直觉的最终布局。求解者不能只看平铺结果或只看重力结果——必须先完成平铺再施加重力，两步不可分割。尤其是向上平铺的副本反而最终可能落在最下方（经过最长距离的下落），而向下平铺的副本已在底部附近保持不动。
