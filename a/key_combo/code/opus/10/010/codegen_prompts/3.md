## 新题 3：游程压缩揭示形状等价后按拉伸量排序涂色

**组合逻辑**：[压缩/compression](已有) → [形状匹配/shape_match + 旋转反射等价](已有) → [重涂色/recolor + 面积比较](创新：比较的不是对象面积，而是压缩前后的面积差——即"拉伸量"，作为隐蔽排序指标)

**来源原语**：压缩、游程压缩后比较(bd14c3bf, ce8d95cc)；形状匹配、旋转反射等价、原型对象、候选对象(bd14c3bf)；重涂色、面积比较、极值区域分别涂色(6455b5f5)

**依赖链**：压缩使拉伸的候选形状可以与原型比较 → 匹配结果决定哪些对象被保留 → 保留对象的拉伸量（原始像素数 - 压缩后像素数）决定最终颜色。三步缺一不可：无压缩则无法匹配；无匹配则不知保留谁；无拉伸量排序则不知涂什么色。

将拉伸程度不同的候选对象通过行列压缩还原后与原型匹配，匹配成功的按拉伸量极值分别涂色，不匹配的擦除。

**输入结构**：约 18x18 的黑(0)背景网格。包含一个灰(5)原型对象（4-连通，4~8 像素，形状不规则，无孔洞）。另有 4~6 个红(2)候选对象散布于网格中，互不接触。候选对象中部分是原型的旋转或反射版本经过行方向或列方向的拉伸（某些相邻行或列被复制 1~3 次）后得到的；其余候选对象是与原型无关的随机 4-连通形状。生成约束：至少 2 个候选对象匹配原型，至少 1 个不匹配；匹配的候选对象之间拉伸量互不相同。

**规则**：
1. 对每个红(2)候选对象，提取其最小边界框，然后逐行扫描：若相邻两行的像素图案完全相同，则合并为一行；再逐列扫描做同样的合并。得到压缩后的形状。
2. 将每个压缩后的候选形状与灰(5)原型形状在所有 4 个旋转和 2 个镜像（共 8 种变换）下比较。若任一变换下逐像素一致，则该候选匹配成功。
3. 不匹配的候选对象全部擦除为黑(0)。
4. 对匹配成功的候选对象，计算其拉伸量 = 原始边界框像素数 - 压缩后边界框像素数。
5. 拉伸量最大的候选对象重涂为蓝(1)，拉伸量最小的重涂为青(8)。其余匹配的候选对象保持红(2)不变。若最大或最小存在并列，则并列的对象全部涂对应颜色。
6. 灰(5)原型对象保持不变。

**关键洞察**：拉伸量（冗余行列数）是一个隐藏属性——它在视觉上表现为对象"更胖"或"更长"，但求解者必须通过压缩操作才能量化这一差异，而不能仅凭外观尺寸判断，因为旋转/反射使得行列方向的拉伸交叉混合。
