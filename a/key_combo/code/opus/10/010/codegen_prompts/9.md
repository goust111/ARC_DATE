## 新题 9：纵列重排为金字塔后对称性解码掩码

**组合逻辑**：[堆叠/stack + 重排/rearrange](创新：重排不仅改变布局，还创造出原本不存在的对称结构) → [对称补全/symmetry_completion](创新：对称性不是输入的固有属性，而是重排后涌现的结构约束)

**来源原语**：堆叠、重排、前景列像素、居中金字塔、奇数宽度递增(3d6c6e23)；对称补全、掩码像素、对称轨道映射(47996f11)

**依赖链**：纵列像素按奇数宽度递增排列为居中金字塔 → 金字塔具有左右对称结构 → 利用对称性推断品红掩码像素的真实颜色 → 最终输出包含修复后的金字塔。删除堆叠重排则无金字塔、无对称可利用；删除对称补全则品红像素无法恢复。

将含有掩码缺损的纵列像素堆叠为居中金字塔，利用金字塔的左右对称性解码掩码像素的真实颜色。

**输入结构**：约 18x18 的黑(0)背景网格。包含 1~2 根垂直前景列（每根占一列），每根列中有 n^2 个非背景像素从上向下排列（n = 2 或 3，即 4 或 9 个像素），像素颜色来自红(2)、蓝(1)、绿(3)、黄(4)中的若干种，从上到下按颜色分为长度 1, 3, 5, ... 的连续段。每根列中有 1~2 个像素被替换为品红(6)，表示掩码。品红像素仅出现在长度 >= 3 的段内（不在长度为 1 的顶部段）。生成约束：每个品红像素在金字塔重排后的位置有一个关于金字塔垂直中轴的镜像位置，且镜像位置的像素不是品红色，从而保证可修复。不同列的金字塔在输出中的水平位置不重叠。

**规则**：
1. 对每根前景列，从上到下读取所有非黑像素（包括品红(6)），得到序列 S，长度为 n^2。
2. 将 S 拆分为连续子段，长度依次为 1, 3, 5, ...（第 1 段 1 个像素，第 2 段 3 个像素，第 3 段 5 个像素，依此类推），共 n 段。
3. 在输出中，以该列的列号为水平中心，将每段排列为水平居中的行，从上到下依次排列。第 1 段（1 像素）在最顶行，第 n 段（2n-1 像素）在最底行。所有段底部对齐于原列最底部像素的行号。
4. 金字塔具有关于其垂直中轴的左右对称性。对每个品红(6)像素，找到其关于金字塔垂直中轴的镜像位置，将镜像位置的颜色复制到品红像素处。
5. 原始前景列中的像素在输出中被清除为黑(0)（它们已被重新排列到金字塔中）。
6. 若有多根列，每根独立处理，输出中多个金字塔共存。

**关键洞察**：品红掩码在一维纵列中无法推断——纵列本身没有对称结构。只有当像素被重排为二维金字塔后，左右对称约束才涌现，使得每个掩码像素恰好有一个可见的对称伙伴。重排操作不仅是布局变换，更是"激活"了隐藏的约束信息。
