## 新题 4：分隔线颜色编码的弹射滑动

**组合逻辑**：[滑动/slide](创新：滑动不再单向到底，而是遇到特定颜色的分隔线时反弹并改变自身颜色) + [颜色互换/color_swap](创新：互换不再由反射触发，而是由碰撞的分隔线颜色触发) + [碰撞停止](创新：停止条件分化——灰线停止，橙线反弹)

**来源原语**：滑动、碰撞停止、颜色匹配、同色滑向同色边(17829a00)；颜色互换、反射触发色换(a25697e4)；分隔线(6455b5f5)

**依赖链**：滑动方向由对象颜色决定 → 碰撞分隔线的颜色决定是停止还是反弹 → 反弹同时改变对象颜色，从而改变滑动方向 → 最终位置和最终颜色由整个弹射链共同决定。删除滑动则无运动；删除分隔线颜色判断则无弹射；删除颜色互换则弹射后方向不变导致无限循环。

小对象在水平分隔线之间滑动，遇到灰色分隔线停下，遇到橙色分隔线则颜色翻转并反弹，直至遇到灰色线或网格边界。

**输入结构**：约 15x20 的黑(0)背景网格。4~6 条完整的水平分隔线将网格分成 5~7 个水平带。每条分隔线颜色为灰(5)或橙(7)，两种颜色交替或随机分布，但保证至少有 2 条灰(5)和 2 条橙(7)。网格的最顶行和最底行视为隐含的灰(5)边界（不绘制）。每个水平带内包含 0~2 个小型单色对象（4-连通，3~5 像素），颜色为红(2)或蓝(1)。对象不接触任何分隔线，且同一列中不存在两个对象。生成约束：每个对象的弹射路径最终会遇到灰(5)分隔线或网格边界而停止（不会无限弹射）。

**规则**：
1. 红(2)对象向上滑动，蓝(1)对象向下滑动。对象作为刚体沿垂直方向移动，保持形状和水平位置不变。
2. 对象滑动直到其边界框的前沿（红色为顶边，蓝色为底边）紧邻一条分隔线或网格边界。
3. 若碰到的是灰(5)分隔线或网格边界：对象停在当前位置，滑动结束。
4. 若碰到的是橙(7)分隔线：对象的颜色在红(2)和蓝(1)之间互换，然后立即反转方向继续滑动（原来向上变为向下，反之亦然），从碰撞位置出发继续寻找下一条分隔线。
5. 弹射可能连续发生多次。每次碰到橙(7)线都互换颜色并反弹。
6. 处理顺序：按对象的初始位置从上到下逐个处理（行号小的先处理）。先处理完的对象成为后续对象的障碍物——后续对象碰到已停止的对象时也视为碰到灰(5)线（停下，不互换颜色）。
7. 分隔线保持不变。对象原始位置留下的区域恢复为黑(0)。

**关键洞察**：橙色分隔线是"颜色反转镜"——它同时翻转对象的颜色和运动方向，使对象在分隔线之间形成弹射链。最终停止位置和最终颜色取决于整条弹射路径上橙色线的数量：偶数次弹射颜色不变，奇数次弹射颜色翻转。
