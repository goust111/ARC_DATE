## 新题 10：周期壁纸修复重建拓扑边界后标记色洪泛填充

**组合逻辑**：[completion + tiling](从残存前景推断周期并修复壁纸) → [connected_component_detection](修复后的壁纸形成新的拓扑分隔) → [fill](以标记像素的颜色洪泛填充其所在封闭房间)

**来源原语**：completion / periodic_tile / residue_infers_period / periodic_repeat（来自 ea959feb）；connected_component_detection / edge_reachability（来自 84db8fc4）；fill（来自 dbff022c）；marker_pixel（来自 97239e3d）

**依赖链**：残缺壁纸 → 推断周期并修复所有缺损像素 → 修复后的壁纸构成灰色障碍网络 → 障碍网络将黑色背景分隔为若干封闭"房间" → 房间中若有彩色标记则用标记色洪泛填充该房间

先修复残缺的灰色周期壁纸以重建房间墙壁，再用各房间内预置的彩色标记像素洪泛填充该房间。

**输入结构**：约 14x14 网格。灰(5)像素构成一个周期性的网格状壁纸图案（例如每隔 3-4 行有一条灰色横线、每隔 3-4 列有一条灰色竖线，形成规则的"房间"格局），但部分灰色像素被擦除为黑(0)（即壁纸有缺损，某些墙壁断裂）。黑(0)像素构成背景和房间内部。若干彩色单像素标记（使用红(2)、蓝(1)、绿(3)、黄(4)中的若干种）分别位于不同的"房间"区域内（每个被标记的房间恰好一个标记）。生成约束：残存的灰色像素足以唯一确定行周期和列周期；缺损位置仅出现在灰色壁纸应有的位置（不会有多余的黑色像素）；修复壁纸后，每个含标记的房间是完全封闭的（灰色像素完全包围）；至少一个房间不含标记（保持黑色）；标记像素不在灰色壁纸像素的位置上。

**规则**：
1. 忽略彩色标记像素和黑色像素，仅从残存的灰(5)像素推断壁纸的行周期 Pr 和列周期 Pc（即找到使得每个 (row mod Pr, col mod Pc) 残差类中，所有可见灰色像素一致的最小周期）。
2. 对每个应为灰色的残差类（即该残差类中存在至少一个灰色像素），将该残差类中所有非灰色、非标记的像素（即被擦除为黑色的像素）修复为灰(5)。标记像素位置不受影响。
3. 修复完成后，将黑(0)像素（不含标记像素）按 4-连通性分为若干连通区域。灰色像素视为障碍。
4. 对每个黑色连通区域：若该区域内包含一个彩色标记像素，则将该区域内所有黑色像素（不含标记本身）填充为标记的颜色，并保留标记像素本身。若区域内无标记，则保持黑色不变。
5. 灰色壁纸像素（包括修复后的）在输出中保持灰色。

**关键洞察**：在壁纸修复之前，缺损的墙壁使相邻房间连通为一个大区域——如果直接洪泛填充，标记的颜色会泄漏到相邻房间。只有先修复壁纸（重建所有墙壁），房间之间的拓扑隔离才能恢复，洪泛填充才能正确限定在单个房间内。修复步骤是填充步骤的必要前提。
