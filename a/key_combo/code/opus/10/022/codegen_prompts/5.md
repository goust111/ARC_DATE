## 新题 5：线路弯折次数编码形状循环步进

**组合逻辑**：[transmit](沿线路传输令牌) + [shape_transform](形状按循环变换) + [counting](计数线路弯折次数决定变换步数) — 线路几何结构编码变换规则

**来源原语**：transmit / wire_network / endpoint_pairing（来自 a47bf94d）；shape_transform / shape_cycle_mapping（来自 a47bf94d）；counting（来自 d5c634a2）

**依赖链**：识别线路网络和端点配对 → 计数每条线路的直角弯折次数 → 弯折次数决定形状循环前进步数 → 在接收端绘制变换后的形状

彩色令牌沿灰色线路传输到对端，但到达时的形状不是固定的互补形状，而是由线路弯折次数在"实心→交叉→菱形"循环中步进决定的。

**输入结构**：约 15x15 网格，黑(0)背景。灰(5)像素构成 2-4 条独立的线路路径，每条线路是宽 1 像素的 4-连通路径，两端各有一个端点。线路之间互不连通。线路包含若干直角弯折（从水平方向变为垂直方向或反之）。在若干线路的一个端点处（紧邻端点外侧），有一个 3x3 彩色令牌，令牌类型为以下三种之一：实心块（3x3 全填充同色）、X 形（仅四个角像素和中心像素填充）、菱形（中心像素加上下左右四个相邻像素填充）。令牌颜色使用红(2)、蓝(1)、绿(3)等。对端端点处为空（3x3 区域全黑）。生成约束：每条线路长度至少 5 像素；3x3 令牌区域不与其他线路重叠；每条线路弯折次数为 0-5 次。

**规则**：
1. 识别每条灰色线路及其两个端点。对于有令牌的线路，确定源端（有令牌的一端）和目标端（空的一端）。
2. 统计每条线路中的直角弯折次数 B（即路径方向从水平变为垂直或从垂直变为水平的次数）。
3. 定义形状循环：实心 → X 形 → 菱形 → 实心（循环长度 3）。
4. 对于每个源令牌，确定其形状在循环中的位置 S（实心=0，X=1，菱形=2）。目标端的形状 = 循环位置 (S + B) mod 3 对应的形状。
5. 在目标端的 3x3 区域中，用源令牌的颜色绘制变换后的形状。源令牌保持不变。
6. 无令牌的线路（两端均空）不产生任何变化。

**关键洞察**：线路的几何属性（弯折次数）编码了形状变换的程度——直线传输保持原形状，每增加一个弯折就在循环中前进一步。求解者必须同时关注线路拓扑（配对端点）和线路几何（数弯折），两者共同决定输出。
