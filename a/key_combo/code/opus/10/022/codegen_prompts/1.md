## 新题 1：拓扑封闭性门控印章放置

**组合逻辑**：[connected_component_detection](用于区域拓扑分类) + [stamp_overlay](在门控通过的标记位置执行印章) + [erase](清除未通过门控的标记)

**来源原语**：connected_component_detection / edge_reachability / topological_classification（来自 84db8fc4）；stamp_overlay / mask_selects_placement（来自 48f8583b）；erase（来自 1b8318e3）

**依赖链**：灰色障碍物将背景划分为若干 4-连通区域 → 拓扑分类判定每个区域是封闭（不可达网格边缘）还是开放（可达网格边缘） → 封闭区域内的绿色标记像素接受印章操作，开放区域内的绿色标记像素被擦除 → 印章操作将角落处的模板瓦片以标记为中心复制到输出

从角落读取模板瓦片，根据灰色障碍物形成的拓扑封闭性，决定哪些绿色标记位置接受瓦片印章、哪些被擦除。

**输入结构**：约 15x15 网格，黑(0)背景。灰(5)像素形成不规则的连通障碍网络（类似墙壁），将黑色背景分割为若干大小不等的 4-连通区域——其中一些区域的黑色像素可经 4-连通路径到达网格最外圈边缘，另一些完全被灰色像素包围而无法到达边缘。网格左上角固定放置一个 3x3 的彩色模板瓦片（使用红(2)和黄(4)两色，内部图案各示例不同）。若干绿(3)单像素标记散布在网格各区域中（每个区域 0 或 1 个标记），总计 3-6 个标记。生成约束：每个封闭区域至少足够大（至少 5x5 空间），以容纳一个 3x3 印章而不与灰色障碍重叠；模板瓦片所在的左上角 3x3 区域不包含灰色障碍。

**规则**：
1. 读取左上角 3x3 区域作为模板瓦片，记录其颜色图案。
2. 将黑(0)背景像素按 4-连通性分为若干连通区域（灰色像素视为障碍，不属于任何区域）。
3. 对每个连通区域判定拓扑类型：若该区域存在至少一个像素位于网格第 0 行、最后一行、第 0 列或最后一列，则为"开放区域"；否则为"封闭区域"。
4. 对每个绿(3)标记像素：若它位于封闭区域内，则以该标记为中心，将 3x3 模板瓦片覆盖到输出（模板像素覆盖该位置的原有内容；若印章范围超出网格边界则裁剪掉超出部分）；同时擦除该绿色标记（被模板覆盖）。若它位于开放区域内，则将该绿色像素擦除为黑(0)。
5. 灰色障碍物和左上角模板区域在输出中保持不变。

**关键洞察**：绿色标记本身不携带"是否应被印章"的信息——这一判断完全由其所在区域的拓扑封闭性决定。仅看标记位置无法判断，必须追踪其所在连通区域是否可达网格边缘。
