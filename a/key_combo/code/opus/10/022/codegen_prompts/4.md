## 新题 4：连通分量面积门控周期图案修复

**组合逻辑**：[connected_component_detection + counting](检测黑色污渍并测量面积) + [completion + tiling](从残存前景推断周期瓦片并修复小污渍下方的图案) — 两条分析线索汇合于同一输出决策

**来源原语**：connected_component_detection / area_classification / area_threshold_filter（来自 84db8fc4, d2abd087, 12eac192）；completion / periodic_tile / residue_infers_period / periodic_repeat（来自 ea959feb）；counting（来自 d5c634a2）

**依赖链**：黑色污渍覆盖了周期壁纸的部分区域 → 需要从残存的彩色像素推断壁纸的最小重复周期 → 同时需要检测每个黑色连通分量的面积 → 面积 <= 阈值的污渍被修复（用推断出的壁纸图案填充），面积 > 阈值的污渍保持黑色

在被多个黑色污渍遮挡的周期壁纸上，仅修复小面积污渍下方的壁纸图案，大面积污渍视为永久障碍保持不变。

**输入结构**：约 13x13 网格。壁纸背景由两种颜色（如红(2)和黄(4)）构成严格的二维周期图案（周期为 2x2 至 4x4，行周期和列周期可以不同），覆盖整个网格。若干黑(0)污渍（4-连通的黑色连通分量）散布在网格上，遮盖了壁纸的部分像素。污渍大小各异：有些面积为 1-4 像素（小污渍），有些面积为 6-12 像素（大污渍）。生成约束：残存的未被遮盖的壁纸像素足以唯一确定行周期和列周期（即每个周期残差类至少有一个可见的前景像素）；小污渍和大污渍之间的面积不存在歧义（生成时保证面积 5 的污渍不出现，形成清晰的阈值间隔）；至少有 2 个小污渍和 1 个大污渍。

**规则**：
1. 忽略所有黑(0)像素，仅从可见的红(2)和黄(4)像素推断壁纸的最小行周期 Pr 和列周期 Pc。方法：找到使得所有同一 (row mod Pr, col mod Pc) 残差类中的可见像素颜色一致的最小 Pr 和 Pc。
2. 检测所有黑(0)的 4-连通分量，计算每个分量的面积（像素数）。
3. 面积 <= 4 的黑色分量：将其中每个黑色像素替换为该像素所属残差类 (row mod Pr, col mod Pc) 在壁纸中对应的颜色（即修复壁纸）。
4. 面积 >= 6 的黑色分量：保持黑色不变。
5. 所有未被污渍遮盖的壁纸像素保持不变。

**关键洞察**：求解者必须同时进行两项独立分析——周期推断（从残存像素恢复壁纸规律）和面积分类（判断哪些污渍该修复）——并将两者的结果汇合：周期告诉你每个位置"应该是什么颜色"，面积告诉你"是否需要恢复"。两项分析的结果缺一不可。面积阈值（4 和 6 之间的间隔）需要通过对比多个示例来归纳。
