## 新题 6：骨架格子中标记计数驱动填充模式与重叠优先级

**组合逻辑**：[expand_fill](在骨架格子上扩展标记色到边界矩形) + [counting](计数每种标记色的数量) → [recolor](计数结果双重作用：决定填充模式 + 决定重叠优先级)

**来源原语**：expand_fill / scaffold_lattice / hollow_cell_frame / marker_lattice_align / marker_span_extent（来自 97239e3d）；counting（来自 d5c634a2）；recolor / area_determines_color（来自 d2abd087）；conflict_priority（来自 1b8318e3）

**依赖链**：识别骨架格子和各色标记 → 对每种颜色计数标记数量 N → N 同时控制两件事：(a) 填充模式（N<=2 只画边界轮廓 vs N>=3 画边界且填满内部框心）；(b) 重叠区域的优先级（N 更大的颜色覆盖 N 更小的颜色）

在骨架格子中，每种标记色的数量决定了其扩展矩形是仅画轮廓还是全部填充，并且同一个计数还充当重叠冲突时的优先级。

**输入结构**：约 18x18 网格，黑(0)背景。灰(5)像素构成一个规则的骨架格子：由若干空心 3x3 小框排列成行列阵列，小框之间共享 1 像素宽的灰色边界行和边界列。每个小框的中心像素为黑(0)。2-3 种颜色的标记像素（使用红(2)、蓝(1)、绿(3)中的若干种）各自出现在 1-4 个小框的中心位置（替换该中心的黑色）。不同颜色的标记数量互不相同。生成约束：同一中心不会同时有两种颜色标记；每种颜色的标记至少 1 个；不同颜色的标记数量两两不等；至少两种颜色的扩展矩形在边界上有重叠。

**规则**：
1. 从灰色像素推断骨架格子结构：识别所有灰色边界行和边界列，它们将网格划分为若干 3x3 小框单元。
2. 对每种标记颜色 C，找到所有包含 C 色标记的小框单元，确定这些单元在格子中的行列坐标范围，得到最小外接矩形（以格子单元坐标表示）。
3. 统计 C 色标记的数量 N_C。
4. 若 N_C <= 2（轮廓模式）：将该外接矩形边界上经过的所有灰色边界段（边界行/列中属于矩形周长的部分）涂为 C 色。矩形内部小框的中心像素不做处理。
5. 若 N_C >= 3（填充模式）：除了涂边界段外，还将矩形内部所有小框的中心像素涂为 C 色（包括原本无标记的小框中心）。
6. 当两种颜色的矩形边界段或中心像素重叠时，N 值更大的颜色覆盖 N 值更小的颜色。若 N 值相同（生成约束保证不会出现），以格子中标记位置扫描序（从左上到右下逐行扫描）更靠前的颜色优先。
7. 未被任何颜色矩形覆盖的灰色边界段和黑色中心保持原色不变。

**关键洞察**：计数 N 不是简单的统计量——它同时充当两个决策的输入：填充模式（外观截然不同）和重叠优先级（决定谁覆盖谁）。删掉计数环节，两个决策都无法确定。仅看一个示例无法区分 N=2（轮廓）和 N=3（填充）的阈值，必须对比多个示例。
