## 新题 8：面积筛选的引导体射线延伸

**组合逻辑**：[connected_component_detection + counting](检测灰色对象并测量面积) → [ray_cast](仅通过大面积对象的远端尖端投射平行对角线) + [erase](清除所有灰色对象)

**来源原语**：ray_cast / diagonal_segment / parallel_offset / guide_tip_seeds_parallel_diagonal（来自 a78176bb）；connected_component_detection / area_classification / area_threshold_filter（来自 12eac192, d2abd087）；erase（来自 a78176bb）；counting（来自 d5c634a2）

**依赖链**：检测灰色连通分量 → 按面积分为引导体（大）和噪声（小） → 仅引导体的远端尖端作为新对角线的种子点 → 射线延伸在种子点处生成与原对角线平行的新对角线 → 所有灰色对象被擦除

一条红色对角线旁散布着大小不等的灰色对象；大对象是构造引导体，其远端尖端生成平行对角线；小对象是噪声，被忽略并擦除。

**输入结构**：约 14x14 网格，黑(0)背景。一条红(2)对角线段（从网格某角或边缘区域延伸，方向为左上-右下或左下-右上，长度至少 5 像素）。3-6 个灰(5) 4-连通对象散布在网格中，部分紧邻红色对角线，部分远离。灰色对象面积各异：小对象 1-2 像素，大对象 4-8 像素（大对象形态类似三角形或楔形，有一个可辨识的尖端像素——即距离原始红色对角线最远的像素）。生成约束：面积 3 的灰色对象不出现（确保大小分类无歧义）；每个大对象有唯一的距原对角线最远像素（以曼哈顿距离度量）；大对象至少 2 个。

**规则**：
1. 检测所有灰(5) 4-连通分量，计算每个分量的面积（像素数）。
2. 面积 <= 2 的分量标记为"噪声"。面积 >= 4 的分量标记为"引导体"。
3. 对每个引导体：计算其所有像素到原始红色对角线的最短曼哈顿距离，找到距离最大的像素作为"尖端"（若多个像素距离相同且最大，选行号最小的；行号也相同选列号最小的）。
4. 确定原始红色对角线的方向（左上-右下即 +row+col，或左下-右上即 -row+col）。
5. 通过每个尖端像素，沿与原对角线相同的方向绘制红(2)对角线，向两个方向延伸直到到达网格边界。
6. 擦除所有灰(5)像素（变为黑(0)），无论是噪声还是引导体。
7. 原始红色对角线保持不变；新生成的对角线若与原对角线重叠，颜色相同无视觉差异。

**关键洞察**：面积分类将同色对象分配到不同角色——引导体提供构造信息（尖端位置），噪声被忽略。若不做面积分类，噪声像素也会生成错误的对角线。面积阈值需要对比多个示例归纳（有些示例中小对象靠近对角线但不应生成新线）。

  distractors:
    0-1 disconnected 8-connected non-bg components with no seed; may contain line+frame structure or be a single frame loop
  output: same grid with each connected cavity flood-filled by its seed's color

generation_strategy:
  approach: output-first
  steps:
    1. Choose grid size, bg color, 1-2 seeds with unique colors, and per-seed line_color
    2. For each seed, draw a meandering 8-connected line path from the seed's border position inward, using diagonal and orthogonal steps
    3. Along each line, attach 2-5 frame loops (closed rings of a frame_color enclosing a 2x2 bg cavity); the line touches the loop at 1-2 outer edge positions (8-adjacent to the frame ring)

    5. Optionally add 0-1 disconnected non-bg component as a distractor network
    6. Verify: each cavity has single-color boundary; cavities connected to a line are fillable; at least 1 unfilled cavity exists
