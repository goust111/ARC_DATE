## 新题 7：列敏感的缺角补全与循环背景填充

**组合逻辑**：[补全·缺角填色](创新：补全颜色由顶行色序的对应列决定，非固定色) + [循环填充·分隔下填色](创新：补全后的像素成为填充障碍)

**来源原语**：补全/completion（3aa6fb7a）、缺角补全正方形/missing_corner_completes_square（3aa6fb7a）、填充/fill（bd4472b8）、顶行色序/top_row_color_sequence（bd4472b8）、分隔行/separator_row（bd4472b8）、分隔下循环填色/below_separator_cycle_fill（bd4472b8）、包围框内部/inside_bbox（3aa6fb7a）

**依赖链**：顶行色序 → 决定每列的补全颜色 → L 形对象的缺角按所在列获取颜色 → 补全后的 2x2 方块阻断循环填充的流向 → 填充最终以顶行色序逐列循环但绕过所有非背景像素。补全和填充共享同一个颜色源（顶行色序），但补全在填充之前执行，补全结果改变了填充的"背景"定义。

在灰色分隔行下方，先将 L 形对象的缺角补全为该列对应的顶行颜色，再用顶行色序循环填充剩余背景。

**输入结构**：约 10x10 的网格，背景黑(0)。顶行（第 0 行）包含一个宽度等于网格列数的颜色序列，每个单元格为红(2)、蓝(1)、绿(3) 中的一种，构成可辨识的重复模式（如 [红,蓝,绿,红,蓝,绿,...] 或 [红,红,蓝,绿,红,红,蓝,绿,...]）。第 1 行为满行灰(5) 分隔行。第 2 行及以下为黑(0) 背景，其中散布 3~5 个青(8) L 形对象（每个为 3 像素的 4-连通区域，恰好占据某个 2x2 边界框中的 3 个格子，缺少 1 个角）。生成约束：各 L 形对象的 2x2 边界框互不重叠；每个 L 的缺失角所在列在不同示例中可以不同（以迫使求解者发现列→颜色映射规则）。

**规则**：
1. 保持顶行和灰(5) 分隔行不变。
2. 对灰(5) 行下方每个青(8) L 形对象，找到其 2x2 边界框中唯一的黑(0) 缺角单元格，记其列坐标为 c。
3. 将该缺角单元格涂为顶行第 c 列的颜色（如列 c 处顶行为蓝(1)，则补为蓝(1)）。青(8) 像素保持不变。
4. 补全全部完成后，将灰(5) 行下方所有仍为黑(0) 的单元格填充为顶行色序的循环：每个单元格 (r, c) 填入顶行第 c 列的颜色。
5. 已有的青(8) 像素和步骤 3 中补全的像素均不被覆盖。

**关键洞察**：补全颜色不是固定的蓝色（与原始 L 补全题不同），而是由缺角所在列从顶行色序中查询得到。这意味着不同位置的 L 形对象即使形状相同、缺角方位相同，补全颜色也可能不同。循环填充看似会覆盖一切背景，但补全的像素先于填充执行，成为填充时的非背景障碍，改变了"哪些格子需要填充"的集合。
