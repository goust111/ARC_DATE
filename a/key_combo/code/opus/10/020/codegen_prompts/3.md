## 新题 3：载体色控滑动后的对角线同余铺满

**组合逻辑**：[滑动·颜色决定方向] + [循环填充·同余类交错](创新：在滑动后的新位置上执行同余延伸，且限制在载体带内)

**来源原语**：滑动/slide（9b4c17c4）、颜色决定方向/color_determines_direction（9b4c17c4）、载体区域/carrier_region（9b4c17c4）、循环填充/cyclic_fill（05269061）、同余类交错铺满/congruence_interlaced（05269061）、对角线/diagonal（05269061）

**依赖链**：载体颜色决定对角线段的水平滑动方向 → 滑动改变对角线的列坐标 → 以新坐标为基准做模 3 同余延伸 → 延伸被限制在载体带的行范围内。滑动结果直接改变同余类的相位，因此同一对角线在不同载体中会产生完全不同的铺满图案。

将对角线段按载体色方向滑至载体边缘后，在载体带内以模 3 同余类铺满该对角线。

**输入结构**：约 10x10 的网格，无背景——网格被水平载体带完全填满。载体带交替为蓝(1) 和青(8)，每带 3~4 行高，覆盖整个网格宽度。每个载体带内含一条对角线段（3~5 像素长），颜色各不相同且非蓝非青非黑（如红(2)、绿(3)、黄(4)、橙(7)），斜率方向统一（均为左上→右下或均为右上→左下）。生成约束：每条对角线段严格在其载体带的行范围内；各带的对角线段互不接触。

**规则**：
1. 识别每条对角线段及其所在载体带的颜色。
2. 水平滑动对角线段：蓝(1) 载体 → 整体右移，直至线段最右端像素的列坐标等于载体带的最右列（即网格右边缘）；青(8) 载体 → 整体左移，直至线段最左端像素的列坐标等于载体带的最左列（即列 0）。滑动过程中对角线段形状不变，滑动前的原始位置还原为载体色。
3. 以滑动后的对角线段为种子，在载体带行范围内做模 3 同余延伸：沿列方向每隔 3 列重复绘制同斜率的完整对角线（仅覆盖载体色像素，不覆盖已有的其他对角线色像素），裁切到载体带的行范围。
4. 若两个相邻载体带的同余延伸在边界行产生冲突（同一单元格被两个带的延伸同时覆盖），上方载体带的颜色优先。

**关键洞察**：载体色决定对角线的锚定边缘（左或右），锚定位置决定同余相位，因此同一根对角线在蓝载体和青载体中会产生镜像式的铺满结果。必须先滑动再铺满，两步的耦合不可跳过。
