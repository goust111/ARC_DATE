## 新题 10：对角同余交叉点的环形印章

**组合逻辑**：[循环填充·同余类交错] × 2（两组反向对角线独立延伸） + [印章覆盖·交叉点印章](创新：印章位置由两组同余延伸的交叉点涌现) + [擦除]（模板环消耗后消失）

**来源原语**：循环填充/cyclic_fill（05269061）、同余类交错铺满/congruence_interlaced（05269061）、对角线/diagonal（05269061）、等距偏移/equidistant_offset（05269061）、印章覆盖/stamp（ac3e2b04）、交叉点印章环形/stamp_ring_at_cross（ac3e2b04）、标记环/marker_ring（ac3e2b04）、擦除/erase（fbf15a0b）

**依赖链**：两组反向斜率对角线各自做模 3 同余延伸 → 两组延伸线的交叉点被计算出来 → 交叉点涂为特殊色 → 在每个交叉点处印章一个环形 → 环形模板在印章完成后被擦除。交叉点的位置只能通过两组同余延伸的叠加涌现，单独一组对角线无法确定印章位置。

两组反向对角线各自做同余延伸后，在其交叉点处印章环形并擦除模板环。

**输入结构**：约 12x12 的网格，背景黑(0)。包含两组对角线段：第一组为 2~3 条红(2) 对角线段（斜率为左上→右下，即每步行+1列+1），每段 3~5 像素长；第二组为 2~3 条蓝(1) 对角线段（斜率为右上→左下，即每步行+1列-1），每段 3~5 像素长。此外，网格中有一个绿(3) 的 3x3 空心环（8 个绿(3) 像素环绕 1 个黑(0) 中心），不与任何对角线重叠。生成约束：各对角线段互不重叠，且两组对角线的同余延伸必然在网格内产生至少 2 个交叉点；绿(3) 环不位于任何预期交叉点的 3x3 邻域内。

**规则**：
1. 对每条红(2) 对角线段，做模 3 同余延伸：沿左上→右下方向，从该段所在的对角线出发，每隔 3 列偏移绘制平行对角线，仅覆盖黑(0) 背景像素，涂为红(2)。裁切到网格边界。
2. 对每条蓝(1) 对角线段，做模 3 同余延伸：沿右上→左下方向，从该段所在的对角线出发，每隔 3 列偏移绘制平行对角线，仅覆盖黑(0) 背景像素，涂为蓝(1)。裁切到网格边界。
3. 找到所有同时被红(2) 延伸和蓝(1) 延伸覆盖的单元格（即两组同余延伸的交叉点）。将这些单元格涂为黄(4)。
4. 以每个黄(4) 交叉点为中心，印章一个 3x3 绿(3) 空心环：将以该点为中心的 3x3 区域中 8 个外围单元格涂为绿(3)，但不覆盖红(2)、蓝(1) 或黄(4) 像素（仅覆盖黑(0) 背景）。中心保持黄(4)。超出网格边界的环像素丢弃。
5. 擦除原始的绿(3) 环模板（将其 8 个绿(3) 像素设为黑(0)）。

**关键洞察**：交叉点并非输入中存在的对象，而是两组独立同余延伸叠加后涌现的结构。印章形状来自输入中的模板环，但模板本身在使用后被擦除——它是一次性指令，不是输出内容。需对比多个示例才能确认交叉点涂黄、环形印章仅覆盖背景这两条规则。
