## 新题 2：双轴杯体弹射的笛卡尔碰撞

**组合逻辑**：[弹射·双向独立](创新：分为垂直弹射组和水平弹射组) + [行列交叉·碰撞检测](创新：交叉点变色) + [像素数守恒]

**来源原语**：弹射/ejection（3dc255db）、尾部朝向决定射出/tail_determines_emission（3dc255db）、行列交叉/row_col_intersection（2281f1f4）、像素数守恒/pixel_count_conservation（3dc255db）、擦除/erase（3dc255db）

**依赖链**：各杯体独立弹射内容像素 → 垂直弹射和水平弹射的路径在网格中形成行列交叉 → 交叉点发生碰撞需特殊着色。弹射方向由杯体尾刺决定，但碰撞位置只有两组弹射路径同时到达才会出现——单独一组弹射无法产生碰撞色。

沿两个正交方向弹射杯体内容后，垂直路径和水平路径交叉的像素变为碰撞色。

**输入结构**：约 12x12 的网格，背景黑(0)。网格上方边缘附近有 2~3 个杯形框架，尾刺朝下（即开口朝上），边框各用不同颜色（如蓝(1)、绿(3)），每个杯口内有 1~4 个黄(4) 内容像素。网格左侧边缘附近另有 2~3 个杯形框架，尾刺朝右（即开口朝左），边框用另一组不同颜色（如红(2)、灰(5)），杯口内同样有 1~4 个黄(4) 内容像素。各杯形框架由 3~5 个边框像素构成，杯口为 1~2 个像素宽的开口，尾刺为 1 像素突出。生成约束：所有杯体互不重叠且弹射路径不与其他杯体框架相交。

**规则**：
1. 对每个杯体，计数其内容像素数 N，擦除杯口内所有黄(4) 内容像素（还原为黑(0)）。
2. 从杯体尾刺端点起，沿尾刺方向（上方杯体朝下、左侧杯体朝右）连续绘制 N 个黄(4) 像素。如果超出网格边界则丢弃超出部分。
3. 对每个网格单元格，检查是否同时被一条垂直弹射路径（来自上方杯体）和一条水平弹射路径（来自左侧杯体）经过。若是，将该单元格涂为橙(7) 而非黄(4)。
4. 仅被一条弹射路径经过的单元格保持黄(4)。
5. 杯体边框像素保持原色不变。

**关键洞察**：碰撞色(橙(7))只出现在垂直弹射线段和水平弹射线段的交叉点上，这是一个笛卡尔积结构——但其行列坐标由各杯体的内容数量和尾刺位置联合决定，而非由边缘标记的固定位置给出。需对比多个示例才能区分"单路径=黄色"和"双路径交叉=橙色"。
