## 新题 1：标记距离编码瓦片周期的噪声修复

**组合逻辑**：[标记像素·距离读取](创新：距离编码周期) + [修复噪声·多数投票] + [擦除]（标记像素的"定位"功能被重构为"参数编码"功能）

**来源原语**：标记像素/marker_pixel（fbf15a0b）、修复噪声/repair_noise（135a2760）、周期瓦片/periodic_tile（135a2760）、擦除/erase（fbf15a0b）、框架分区/frame_partition（135a2760）、忽略干扰项/ignore_distractors（135a2760）

**依赖链**：标记像素的空间距离 → 确定瓦片周期 → 以此周期修复噪声图案 → 擦除标记。没有标记距离就无法推断正确的周期；没有正确的周期，多种瓦片尺寸都能部分匹配噪声数据，无法唯一确定修复结果。

在框架分区的噪声网格中，每个分区内嵌入的一对标记像素的曼哈顿距离即该分区的瓦片周期；以此周期修复噪声并擦除标记。

**输入结构**：约 15x15 的网格，背景黑(0)。灰(5) 色的满行/满列将网格分割为 3~4 个矩形分区。每个分区内有一种前景色（各分区颜色不同，例如红(2)、蓝(1)、绿(3)）构成的周期性图案，但其中 2~4 个像素被错误地替换为黑(0) 或其他颜色（噪声）。每个分区内还有恰好两个橙(7) 标记像素，位于分区内部（不在灰色分隔线上），且不与图案像素重叠。生成约束：每个分区的两个橙(7) 标记之间的曼哈顿距离恰好等于该分区图案的行方向周期与列方向周期（两者相等，即瓦片为正方形 PxP）；不同分区的标记距离可以不同。

**规则**：
1. 对每个灰(5) 分隔的矩形分区，找到其内部的两个橙(7) 标记像素，计算它们之间的曼哈顿距离 D。
2. 该分区的瓦片尺寸为 DxD。将分区内的非橙(7)、非灰(5) 像素按行列坐标对 D 取余，对每个余数位置做多数投票，确定正确的瓦片单元。
3. 用正确的瓦片单元重新铺满该分区（替换所有噪声像素）。
4. 将两个橙(7) 标记像素设为黑(0)（背景色）。
5. 灰(5) 分隔线保持不变。

**关键洞察**：标记像素并非图案内容，也不是用于选择半区或定位的标签——它们的空间距离编码了一个数值参数（瓦片周期），这个参数是修复噪声的前提。需要对比多个示例才能归纳出"曼哈顿距离 = 瓦片周期"这一编码规则。

## 实现要求

1. `main(grid)` 必须实现新题描述中的确定性转换规则，不能只识别 `generate_input()` 的固定模板。禁止不同的input网格输出相同的output网格。
2. `generate_input()` 必须随机生成多样样例，不能固定死。随机维度应覆盖：网格大小、对象数量、位置、颜色、方向、形状参数或关键分支。注意若描述中存在若干，需实现而不是只有单个，包括object或者对应关系等等。且若涉及到最短路径，则输入网格中必涉及到多条路径，对选择造成干扰。
3. 生成器必须保证输入满足 `main()` 的隐式假设：对象不重叠、不越界、特殊标记唯一或可区分、匹配关系无歧义、关键分支出现概率相同。
4. 禁止把 ARC 颜色 id 、亮度、拼写等当作人类不可见的数值语义参与排序、大小比较或隐藏映射。颜色变化必须有可见结构线索。注意颜色亮度、拼写等也是不可见信息，若描述中出现违规的颜色id或者亮度，可自行使用少量的固定颜色替代，但注意生成时要在三个以内输入输出网格中对所有变换100%覆盖度。
5. 输出样例要视觉清晰，人类必须能从输入输出对中肉眼辨认出规律。具体要求：避免对象粘连、覆盖关系混乱、同一像素多重语义；不同逻辑步骤产生的结果不要大面积层叠在一起导致无法分辨哪个颜色属于哪个步骤；输入中各元素之间保持足够间距，输出中新增的标记/填充/路径等应与背景和已有元素在颜色上有明显区分；若规则涉及多层叠加，生成时控制对象密度和尺寸，确保叠加区域只占少数像素而非铺满整个网格。
6. 若规则有多个分支，生成器不能长期固定成一个分支；应让分支在随机样例中合理出现。分支概率不必平均——难以发现的隐蔽分支（如少数情况下才触发的特殊规则）应适当提高出现概率，确保在 3 个训练示例中至少出现一次，否则求解者无法归纳该规则。对于颜色映射类规则，确保 2 个左右的示例即可覆盖所有映射关系（每种颜色→颜色的映射至少在某个示例中出现过）。
