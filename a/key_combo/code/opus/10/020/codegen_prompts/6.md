## 新题 6：对齐后按边缘标记匹配性决定镜像

**组合逻辑**：[对齐·边界对齐] + [镜像·标记匹配/不匹配触发](创新：镜像条件基于两端标记一致性，且在对齐之后评估)

**来源原语**：对齐/align（984d8a3e）、边界对齐/edge_alignment（984d8a3e）、色段/color_run（984d8a3e）、同行排列/row_arrangement（984d8a3e）、镜像/mirror（846bdb03）、边色不符则翻转/mismatch_flip（846bdb03）、颜色匹配/color_match（846bdb03）、标记像素/marker_pixel（fbf15a0b）

**依赖链**：所有行的色段右对齐 → 对齐改变了各行的像素布局 → 读取每行两端的标记像素颜色 → 若两端标记不匹配则镜像该行内容。对齐步骤改变了行内容的空间位置，而镜像决策依赖对齐后的标记关系——如果跳过对齐直接判断镜像，结果会不同。

将各行色段右对齐后，根据每行左右端标记像素是否同色来决定该行是否水平镜像。

**输入结构**：约 10x12 的网格。使用五种颜色：绿(3) 为中间色段、蓝(1) 为左侧填充色、红(2) 为右侧填充色、黄(4) 和橙(7) 为边缘标记色。每行结构：最左列（列 0）是一个标记像素，为黄(4) 或橙(7)；最右列是另一个标记像素，为黄(4) 或橙(7)；中间列从左到右依次是若干蓝(1) 像素、一段连续绿(3) 色段（长度逐行不同）、若干红(2) 像素。不同行中绿(3) 色段的起止列不同（右边缘参差不齐）。生成约束：每行恰好一段连续绿(3)；行数至少 5 行；至少有一行的两端标记同色，至少有一行的两端标记异色。

**规则**：
1. 找到所有行中绿(3) 色段右边缘列坐标的最小值 C_min。
2. 对每行，将绿(3) 色段水平左移，使其右边缘对齐到列 C_min（若色段起点会移到列 1 之前，则色段起点固定在列 1）。绿(3) 段左侧用蓝(1) 填充，右侧用红(2) 填充（标记列不参与移动，保持原位）。
3. 对齐完成后，逐行检查：若该行列 0 的标记色与最右列的标记色相同（同为黄(4) 或同为橙(7)），保持该行不变。
4. 若该行列 0 的标记色与最右列的标记色不同（一黄一橙），则将该行列 1 到倒数第 2 列的内容水平镜像翻转（标记像素本身不参与翻转，留在原列原色）。
5. 两端标记像素在输出中保持其原始颜色和位置。

**关键洞察**：镜像判断发生在对齐之后，因此对齐步骤实质性地改变了镜像的效果（翻转的是重排后的内容，而非原始布局）。标记像素的功能从"定位"转变为"二元条件开关"——它们的颜色配对关系（匹配/不匹配）控制操作选择，而非指示空间位置。
