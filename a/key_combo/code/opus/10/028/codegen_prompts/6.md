## 新题 6：封闭区域计数驱动图例查色后同色框桥接

**组合逻辑**：[计数](框内标记统计) → [重涂色](计数结果作为图例索引查找新颜色，创新：计数不直接决定输出形态而是作为查找键) → [擦除](清除标记) → [连线/桥接](同新色框之间最短间隙桥接)

**来源原语**：计数(counting)/标记数决定行长(marker_count_row_len)←d4c90558、重涂色(recolor)←0becf7df、图例(legend)/图例行内配对(legend_row_pairing)←0becf7df、空心矩形(hollow_rect)←d4c90558/b9630600、标记像素(marker_pixel)←d4c90558、连线(connect)←b9630600、最短可见间距(shortest_gap)←b9630600、最小生成树连接(min_spanning_tree)←b9630600、包含(containment)←d4c90558、擦除(erase)←a2d730bd

**依赖链**：标记计数 → 计数值索引图例得到新颜色 → 框被重涂为新颜色 → 原本不同色的框可能变成同色 → 同色框做最短间隙桥接连通。核心耦合在于：计数结果经过图例映射后改变了框的颜色分组，而颜色分组决定了连通拓扑。删除图例映射则不知道重涂什么颜色；删除计数则不知道查图例哪一行；删除桥接则输出不完整。

统计每个灰色框内的标记数，以此数量为索引查图例获取新颜色并重涂框，再将同色框桥接连通。

**输入结构**：约 20×20 的网格，背景为黑(0)。网格中有 5-6 个灰(5)空心矩形框（边框宽 1 像素），大小各异（内部 3×3 到 6×6），彼此不重叠且间距至少 2 像素。每个框内部有 1-3 个孤立的橙(7)标记像素。网格左上角有一个与其他框分离的图例区域：图例由 3 行 1 列的彩色像素组成，从上到下依次为红(2)、绿(3)、蓝(1)，分别对应标记数量 1、2、3。图例区域不被任何灰色框包围。生成约束：每个框内的标记数量在 1-3 范围内；至少有两个框的标记数量相同（重涂后它们将同色，需要桥接）；同色框之间至少存在一条水平或垂直的可见间隙（间隙全为背景，两侧框的行跨度或列跨度重叠至少 3 像素）。

**规则**：
1. 识别图例：网格左上角的 3×1 彩色列，第 1 行=红(2)、第 2 行=绿(3)、第 3 行=蓝(1)。
2. 对每个灰(5)空心矩形框，统计其内部（不含边框像素）的橙(7)标记像素数量 N。
3. 将每个框的边框颜色从灰(5)重涂为图例第 N 行对应的颜色（N=1→红(2)，N=2→绿(3)，N=3→蓝(1)）。
4. 擦除所有框内部的橙(7)标记像素（置为背景色黑(0)）。
5. 对每种重涂后的颜色，找出该颜色所有框之间的水平或垂直可见间隙。可见间隙要求：间隙通道内全为背景像素，两端框在垂直于间隙方向上的跨度重叠至少 3 像素。
6. 对每种颜色的框集合，用最小生成树策略选择间隙：按间隙长度升序排列，依次选择不形成环路的最短间隙，直到该颜色的所有框连通。
7. 对每条被选中的间隙，绘制走廊：在两框重叠跨度范围内缩进两端各 1 像素后的边界行（或列）之间，将间隙像素绘制为该颜色。同时擦除间隙两端框壁上被走廊穿过的像素（置为背景色，形成开口）。
8. 图例区域保持不变。输出完成后的网格。

**关键洞察**：灰色框看似相同，但内部标记数量通过图例映射将它们重新分组——原本同色的框变成了不同颜色的组，而桥接拓扑完全由这个重新分组决定；需要对比示例才能发现图例是按行索引而非按颜色匹配。

2. `generate_input()` 必须随机生成多样样例，不能固定死。随机维度应覆盖：网格大小、对象数量、位置、颜色、方向、形状参数或关键分支。注意若描述中存在若干，需实现而不是只有单个，包括object或者对应关系等等。且若涉及到最短路径，则输入网格中必涉及到多条路径，对选择造成干扰。
