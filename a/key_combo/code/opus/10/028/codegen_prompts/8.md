## 新题 8：滑动物体到同色墙后射线回弹标记路径

**组合逻辑**：[滑动](物体向同色墙压缩) → [射线延伸](创新：从物体的原始位置沿滑动方向反向发射射线标记移动路径) → [遮挡覆盖](路径相交处按到达顺序覆盖)

**来源原语**：滑动(slide)←f0100645、墙壁列(wall_column)←f0100645、同色物体朝同色墙(same_color_wall)←f0100645、近者优先不重叠(nearest_first)←f0100645、射线延伸(ray_extend)←13713586、遮挡覆盖(occlusion_overwrite)←13713586、按距离排序绘制(draw_ordered_by_distance)←13713586

**依赖链**：物体滑向同色墙后的落定位置决定了路径的终点 → 从原始位置到落定位置的路径决定了射线的起止 → 路径相交时的覆盖顺序由滑动距离决定。滑动结果直接约束射线参数，两个操作共享同一组空间信息但用途不同。

物体滑向同色墙着陆后，从每个物体的原始位置到着陆位置绘制轨迹线，轨迹交叉处滑动距离短的覆盖距离长的。

**输入结构**：约 15×15 的网格，背景为黑(0)。网格最左列填满蓝(1)形成左墙，最右列填满红(2)形成右墙。网格内部有 3-4 个蓝(1)小物体（每个 2-4 像素的 4-连通区域）和 3-4 个红(2)小物体（同样 2-4 像素）。蓝色物体将向左滑向蓝色墙，红色物体将向右滑向红色墙。生成约束：同色物体不在同一行（避免滑动冲突）；不同颜色物体可以在同一行（它们滑向相反方向，路径可能交叉）；所有物体到各自墙壁之间的路径上无其他同色障碍（除了先到达的同色物体）。

**规则**：
1. 记录每个前景物体（不含墙壁列）的原始位置。
2. 对每种墙壁颜色，将其物体按到墙壁的距离从近到远排序，依次向墙壁方向水平滑动每个物体直到接触墙壁或已着陆的同色物体，记录着陆位置。
3. 在输出网格上绘制墙壁列（保持不变）和所有物体的着陆位置（保持原色）。
4. 对每个物体，从其原始位置到着陆位置之间的所有背景像素绘制为灰(5)轨迹线。轨迹线仅覆盖物体移动经过的行范围和列范围（即物体的每一行像素水平滑动扫过的区域）。
5. 轨迹绘制顺序：滑动距离（原始位置与着陆位置的列间距）更大的物体先绘制轨迹，距离更小的后绘制。后绘制的灰(5)轨迹覆盖先绘制的灰(5)轨迹（在交叉区域内短距离者可见）。
6. 轨迹线不覆盖任何着陆后的物体像素或墙壁像素。

**关键洞察**：轨迹线的可见性取决于滑动距离——短距离的轨迹在交叉处覆盖长距离的，因此输出中的灰色路径不是简单叠加而是按距离分层的；需要对比示例才能发现覆盖优先级与距离的逆序关系。
