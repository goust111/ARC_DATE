## 新题 5：跨标记线反射后原件与镜像共同参与重力交互

**组合逻辑**：[镜像/反射](跨标记线生成镜像副本) → [擦除](移除标记线) → [重力下落](原件与镜像同时下落并相互碰撞，创新：反射产生的新物体与原物体在物理模拟中交互)

**来源原语**：镜像(mirror)/跨标记线反射(reflect_across_markers)←66ac4c3b、稀疏标记线(sparse_marker_line)←66ac4c3b、前景图案(foreground_motif)←66ac4c3b、平行对称轴(parallel_axes)←66ac4c3b、重力下落(gravity_drop)←f0100645、碰撞停止(collision_stop)←f0100645、擦除(erase)←a2d730bd、重涂色(recolor)←66ac4c3b

**依赖链**：反射生成镜像副本（新的物理实体） → 镜像副本的像素位置影响原件下落时的碰撞判定 → 原件的落定位置又反过来阻挡镜像副本的下落。两者在重力过程中形成双向约束，不是单向流水线。

将前景图案跨标记行反射并涂为新颜色，然后原件和镜像同时参与向下重力下落，在下落过程中相互作为障碍物。

**输入结构**：约 14×10 的网格，背景为黑(0)。网格中有一条横贯全宽的灰(5)标记行，位于网格垂直方向的中部偏上位置（约第 4-5 行）。标记行上方有一个红(2)前景图案（3-8 像素的 4-连通区域，不接触标记行，距标记行 1-2 行）。标记行下方为空白背景区域（至少 6 行空间）。生成约束：红色图案整体位于标记行上方，反射后的镜像不会超出网格底部边界；图案不接触网格顶边。

**规则**：
1. 将红(2)前景图案跨灰(5)标记行做垂直反射：对图案中每个像素 (r, c)，计算其关于标记行行坐标 R 的镜像位置 (2R - r, c)。
2. 将镜像位置的像素涂为绿(3)。原件保持红(2)不变。
3. 擦除灰(5)标记行（所有该行像素置为背景色）。
4. 对所有前景像素（红色原件 + 绿色镜像）施加向下重力。处理方式：逐行从底部向上扫描，每个前景像素向下滑动直到遇到网格底边或遇到已落定的前景像素（无论颜色），即停止。同一行内的像素同时处理（它们互不阻挡，只受下方障碍约束）。
5. 输出完成后的网格：包含重力落定后的红色和绿色像素，背景为黑(0)，标记行已消失。

**关键洞察**：反射不只是视觉变换——它创造了真实参与后续物理过程的新实体。原件和镜像的相对距离由标记行位置决定，而这个距离直接影响下落时的堆叠结构；标记行既是反射轴又是间距编码器。

## 实现要求

1. `main(grid)` 必须实现新题描述中的确定性转换规则，不能只识别 `generate_input()` 的固定模板。禁止不同的input网格输出相同的output网格。
2. `generate_input()` 必须随机生成多样样例，不能固定死。随机维度应覆盖：网格大小、对象数量、位置、颜色、方向、形状参数或关键分支。注意若描述中存在若干，需实现而不是只有单个，包括object或者对应关系等等。且若涉及到最短路径，则输入网格中必涉及到多条路径，对选择造成干扰。
3. 生成器必须保证输入满足 `main()` 的隐式假设：对象不重叠、不越界、特殊标记唯一或可区分、匹配关系无歧义、关键分支出现概率相同。
4. 禁止把 ARC 颜色 id 、亮度、拼写等当作人类不可见的数值语义参与排序、大小比较或隐藏映射。颜色变化必须有可见结构线索。注意颜色亮度、拼写等也是不可见信息，若描述中出现违规的颜色id或者亮度，可自行使用少量的固定颜色替代，但注意生成时要在三个以内输入输出网格中对所有变换100%覆盖度。
5. 输出样例要视觉清晰，人类必须能从输入输出对中肉眼辨认出规律。具体要求：避免对象粘连、覆盖关系混乱、同一像素多重语义；不同逻辑步骤产生的结果不要大面积层叠在一起导致无法分辨哪个颜色属于哪个步骤；输入中各元素之间保持足够间距，输出中新增的标记/填充/路径等应与背景和已有元素在颜色上有明显区分；若规则涉及多层叠加，生成时控制对象密度和尺寸，确保叠加区域只占少数像素而非铺满整个网格。
6. 若规则有多个分支，生成器不能长期固定成一个分支；应让分支在随机样例中合理出现。分支概率不必平均——难以发现的隐蔽分支（如少数情况下才触发的特殊规则）应适当提高出现概率，确保在 3 个训练示例中至少出现一次，否则求解者无法归纳该规则。对于颜色映射类规则，确保 2 个左右的示例即可覆盖所有映射关系（每种颜色→颜色的映射至少在某个示例中出现过）。
7. 代码风格参考 `ARC_code`：使用 `numpy`，并把 `/home/lixinyu/snap/new/solvers/arc_utils.py` 作为公共参考工具箱，优先复用其中已经稳定的 bbox、连通域、裁剪、变换和颜色工具；目标文件必须能被 `SourceFileLoader` 直接加载。
8. 可以在目标目录放公共 helper 文件，或从 `arc_utils.py` 摘取少量必要函数；若只实现一道题，优先保持目标文件自包含，减少额外依赖。
