## 新题 1：对齐筛选与距离排序同心重建

**组合逻辑**：[行列对齐](创新：用于筛选参与者而非射线延伸) + [排序](创新：按到锚点距离而非边长) + [同心层填充](保留) + [忽略干扰项](保留)

**来源原语**：行列对齐(d43fd935)、锚定方块(d43fd935, d89b689b)、排序(c658a4bd)、同心层填充(c658a4bd)、忽略干扰项(0a2355a6, be94b721)

**依赖链**：对齐检测的结果决定哪些颜色进入同心重建的候选集；距离计算的结果决定候选颜色的环层顺序；两者缺一则无法确定输出。

从散布的彩色单像素中，仅选取与中央锚块行列对齐的像素，按它们到锚块的曼哈顿距离排序后，以对应颜色画出同心方环。

**输入结构**：黑(0)背景，约 15x15 网格。中央有一个 2x2 的灰(5)锚定方块。周围散布 6~8 个不同颜色的单像素点（从蓝(1)、红(2)、绿(3)、黄(4)、品红(6)、橙(7)、青(8)中选取，每色至多一个）。其中 3~5 个像素与锚块共享行或列（即位于锚块所占的两行或两列的延伸上），其余像素不与锚块对齐。生成约束：对齐像素到锚块中心的曼哈顿距离互不相同；对齐像素数量为奇数（保证有唯一中心层）。

**规则**：
1. 识别 2x2 灰(5)锚块，确定其占据的两行和两列。
2. 筛选：保留与锚块共享至少一行或一列的单像素；其余像素视为干扰项，输出中擦除为黑(0)。
3. 对筛选出的像素，计算每个到锚块中心（2x2 块的几何中心取左上角像素坐标）的曼哈顿距离，按距离从大到小排序。
4. 以锚块中心为中心，画出 N 层同心方环（N = 筛选出的像素数）。最外层环的半边长为 N，次外层为 N-1，以此类推，最内层为 1（即中心单像素）。
5. 距离最大的像素颜色画最外层环，距离最小的画最内层。锚块本身被同心环覆盖。
6. 输出网格尺寸调整为刚好容纳所有同心环的最小正方形（边长 = 2N+1 如果 N 层时最外半边长为 N；实际边长 = 2*筛选像素数 - 1）。

**关键洞察**：非对齐像素是干扰项，对齐关系是进入同心重建的门票；环层顺序由原始距离（而非颜色编号或面积）决定，需对比多个示例才能确认筛选规则和排序依据。
