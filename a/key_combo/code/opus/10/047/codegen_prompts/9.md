## 新题 9：对角连线涌现封闭区域后按边数填色

**组合逻辑**：[连线/connect](保留) + [对角对齐](保留) + [封闭区域](创新：由连线涌现而非预存) + [填充](保留) + [计数→颜色映射](创新：计数对象从孔洞变为边界线段数)

**来源原语**：连线(db695cfb)、对角像素对(db695cfb)、对角对齐(db695cfb)、封闭区域(0a2355a6, 44d8ac46)、填充(44d8ac46)、按孔洞数映射颜色(0a2355a6)

**依赖链**：必须先完成所有对角连线才能确定哪些区域被封闭；必须数每个封闭区域的边界段数才能确定填充颜色。连线结果直接决定封闭区域的存在和形状——典型的涌现效应。

同色对角像素对之间画对角线段，这些线段在网格中划分出若干封闭区域；每个封闭区域根据其边界上不同颜色线段的数量被填充对应颜色。

**输入结构**：黑(0)背景，约 13x13 网格。若干彩色单像素散布在网格中，颜色使用蓝(1)和绿(3)两种。同色像素两两配对，每对恰好位于同一条 45 度对角线上（即行差绝对值 = 列差绝对值）。生成约束：所有配对的对角线段（连接同色像素对的 45 度线段）在网格内部围出 2~4 个封闭区域（封闭区域定义：被对角线段和/或网格边界完全包围的连通黑色区域）；蓝色对数 2~3，绿色对数 2~3；线段之间可以交叉。

**规则**：
1. 识别所有同色对角像素对（同色且行差绝对值 = 列差绝对值的两个像素为一对）。每个颜色的像素数为偶数，按距离最近原则配对（若有歧义则按左上优先配对）。
2. 在每对之间画对角线段：沿 45 度方向逐像素填充该对的颜色（包含端点）。
3. 线段绘制完成后，识别被线段和网格边界完全封闭的黑(0)连通区域（4-连通）。仅保留面积 >= 3 像素的封闭区域。
4. 对每个封闭区域，统计其边界上接触的不同颜色线段数量（只看蓝和绿两色，接触定义为区域边界像素的 8-邻域中存在该色线段像素）：
   - 仅接触蓝色线段 → 填充黄(4)
   - 仅接触绿色线段 → 填充红(2)
   - 同时接触蓝和绿色线段 → 填充橙(7)
5. 线段像素保持其颜色不变。非封闭区域（连通到网格边界的黑色区域）保持黑(0)。

**关键洞察**：对角连线本身不带有"封闭"的意图，但多条线交叉后涌现出封闭区域——求解者必须先完成所有连线才能看到分区结果，再根据边界接触的线色组合来确定填充色，这是典型的涌现效应。
