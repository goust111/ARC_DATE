## 新题 5：图例编码空间变换的瓦片铺设

**组合逻辑**：[平铺](保留) + [镜像](保留) + [颜色图例](创新：编码空间变换类型而非重涂颜色) + [编码映射](创新：颜色→变换而非颜色→颜色) + [阵列排布](保留)

**来源原语**：平铺(00576224)、镜像(00576224, 7ed72f31)、颜色图例(fafd9572)、编码映射(7ed72f31)、阵列排布(00576224)、排位对应(fafd9572)

**依赖链**：必须先解读图例中每个颜色对应的变换类型；再将变换应用于瓦片的对应位置。图例解读错误则整个铺设结果错误；不铺设则图例无处施展。

输入含一个小瓦片和一列彩色图例像素；图例每个像素的颜色编码一种空间变换，瓦片按 3x3 阵列铺设时，每行的变换方式由图例对应行的颜色决定。

**输入结构**：黑(0)背景，约 10x10 网格分为两个区域。左侧：一个 3x3 的彩色瓦片（使用 2~4 种非黑颜色，图案不对称以便区分变换）。右侧：一列 3 个纵向排列的单像素，颜色取自蓝(1)、红(2)、绿(3)、黄(4)四种（可重复）。瓦片与图例由至少 2 列黑色间隔。生成约束：瓦片图案在水平镜像和 180 度旋转下均与原图不同（保证变换可区分）。

**规则**：
1. 识别 3x3 瓦片和 3 个图例像素（图例从上到下分别对应输出的第 1、2、3 瓦片行）。
2. 颜色-变换映射：蓝(1) = 保持原样，红(2) = 水平镜像（左右翻转），绿(3) = 垂直镜像（上下翻转），黄(4) = 旋转 180 度。
3. 构建输出：3 行 x 3 列瓦片阵列（输出为 9x9）。每行 3 个瓦片相同，均为原始瓦片经该行对应变换后的结果。
4. 输出仅包含 9x9 的瓦片阵列，不保留图例。

**关键洞察**：图例像素的颜色不是"涂什么色"的指令，而是"做什么变换"的编码——语义层面从属性映射跃迁为操作映射，必须对比多个示例（观察同一图例颜色在不同瓦片内容下的效果一致性）才能建立映射。
