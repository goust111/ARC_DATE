## 新题 3：印章放置与对角虚线连接

**组合逻辑**：[stamp](已有：颜色匹配锚点放置) + [diagonal_pairing](创新：从角标记的配对关系变为印章目标位置的配对关系) + [draw_line + parity_dash](创新：虚线连接的不是固定标记而是印章后的精灵体边缘)

**来源原语**：stamp、color_matching、rarest_color_as_anchor（a251c730）；diagonal_pairing、draw_line、parity_dash（f35d900a）；erase（a680ac02）

**依赖链**：锚点颜色匹配 → 确定精灵体与标记的对应关系 → 印章放置确定精灵体的实际位置和边界 → 对角配对确定哪些精灵体之间需连线 → 虚线绘制依赖精灵体的边界位置。印章结果决定虚线端点，配对关系决定虚线存在性，二者交织。

在目标框架中通过颜色匹配印章精灵体，然后在对角配对的精灵体之间绘制奇偶虚线。

**输入结构**：约 25x12 的网格，黑(0)背景。左半区是一个灰(5)边框围成的矩形源区域（约 10x12），内含 2-3 个小型多色精灵体（每个 3x3 至 4x4 的 4-连通图形，使用 2-3 种颜色），每个精灵体中恰好有一个像素的颜色在该精灵体内出现次数最少，作为锚点色。右半区是一个灰(5)边框围成的矩形目标区域（约 10x12），内部为黑(0)，其中散布若干单像素标记，颜色与源区域精灵体的锚点色一一对应。目标区域中的标记成对出现——每种锚点色恰好有 2 个标记，且这 2 个标记位于某个隐含轴对齐矩形的对角位置（生成约束：同色标记对的行坐标不同且列坐标不同）。

**规则**：
1. 对每个源区域精灵体，找到其锚点色（精灵体内出现次数最少的颜色）。
2. 在目标区域中找到与该锚点色相同颜色的两个标记像素。
3. 将精灵体分别复制到两个标记位置，使精灵体的锚点像素与标记像素重合。超出目标区域边框的部分裁剪丢弃。
4. 对每对同色标记（即同一精灵体的两个副本），确定它们定义的轴对齐矩形。沿该矩形的四条边，在两个精灵体的边界框之间的空隙区域（不含精灵体占据的像素）绘制灰(5)虚线：空隙中的每个像素，若其到较近一端精灵体边界框的距离为偶数则涂灰(5)，为奇数则保持黑(0)。
5. 输出仅保留目标区域的内部内容（去掉灰边框），源区域不出现在输出中。
6. 若两个精灵体副本的虚线区域互相重叠，后处理的（按锚点色在源区域中从上到下、从左到右出现的顺序）覆盖先处理的。

**关键洞察**：同色标记总是成对出现在对角位置——这个配对关系将印章操作和虚线绘制绑定在一起：只有先完成印章才知道虚线的端点位置，而虚线的奇偶规则需要对比多个示例中不同间距的配对才能确认。

p = Path("/home/lixinyu/snap/a/key_combo/code/opus/3/006/3.py")
mod = SourceFileLoader("new_arc_task", str(p)).load_module()
sigs = set()
for i in range(100):
    inp = mod.generate_input()
    out = mod.main(inp)
    assert isinstance(inp, np.ndarray)
    assert isinstance(out, np.ndarray)
    assert inp.ndim == 2 and max(inp.shape) <= 30, f"input grid exceeds 30x30: {inp.shape}"
    assert out.ndim == 2 and max(out.shape) <= 30, f"output grid exceeds 30x30: {out.shape}"
    sigs.add(hashlib.md5(inp.tobytes() + str(inp.shape).encode()).hexdigest())
print("variants", len(sigs))
assert len(sigs) >= 20
