## 新题 6：沙漏遮罩下的环路弯折分区

**组合逻辑**：[坐标压缩](已有) → [环路追踪 + 分类涂色](已有) ← [沙漏距离谓词](已有，但作为遮罩覆盖弯折分类结果——创新耦合：两种独立空间分析竞争同一像素的颜色归属)

**来源原语**：环路追踪/trace_cycle（15663ba9）、分类涂色/classify_and_color（15663ba9）、多数转向为凸/majority_turn_is_convex（15663ba9）、坐标压缩/coordinate_compression（7d419a02）、分隔线/separator_line（7d419a02）、定位标记/anchor_marker（7d419a02）、块距离/block_distance（7d419a02）、沙漏距离谓词/hourglass_distance_predicate（7d419a02）

**依赖链**：压缩坐标得到真实几何 → 在压缩网格上追踪环路并分类弯折 → 同时从品红标记计算沙漏距离谓词 → 沙漏区域内的环路像素一律涂为指定色，覆盖弯折分类结果；沙漏外的弯折像素保持分类涂色。两条分析链（弯折分类 vs 沙漏遮罩）共享坐标压缩结果但独立计算，最终在像素层面竞争。

在坐标压缩后的网格上追踪正交环路并分类弯折，同时计算品红标记的沙漏距离场；沙漏区域内的环路像素统一变为指定颜色，覆盖弯折分类结果。

**输入结构**：约 18x18 的网格。黑(0)背景，青(8)前景形成一条闭合正交环路（1 像素宽，每个像素度数为 2）。若干黑(0)完整行或完整列穿过网格（与青像素不冲突——环路像素所在位置不属于完整黑行/列的一部分；这些完整行/列是分隔线）。分隔线全部平行（全为行或全为列）。一个 2x2 的品红(6)标记位于环路内部或外部。生成约束：环路至少有 4 个凹弯折；品红标记不与环路相邻。

**规则**：
1. 识别完整黑(0)分隔线（贯穿整个网格宽度/高度的纯黑行或列，不含任何前景像素）。移除这些分隔线，将网格坐标压缩。
2. 在压缩后的网格上追踪青(8)环路。对每个像素判定：直行、凸弯折（多数转向方向）或凹弯折（少数转向方向）。
3. 在压缩坐标系中，以品红(6)标记的中心为原点，计算每个环路像素的块距离。分隔线方向为沙漏窄轴，另一方向为开口轴。满足沙漏距离谓词的像素（窄轴距离 ≤ 开口轴距离，且两轴距离均不为零）属于"沙漏区域"。
4. 输出着色（在压缩后的网格上）：
   - 沙漏区域内的环路像素：无论弯折类型，一律涂为黄(4)。
   - 沙漏区域外的凸弯折像素：涂为红(2)。
   - 沙漏区域外的凹弯折像素：涂为绿(3)。
   - 沙漏区域外的直行像素：保持青(8)。
5. 品红(6)标记在输出中保持不变。背景保持黑(0)。
6. 输出网格为压缩后的尺寸（小于输入）。

**关键洞察**：沙漏遮罩优先级高于弯折分类——一个凸弯折若在沙漏内则变黄而非变红。求解者必须同时理解两个独立机制（弯折分类和沙漏距离）及其优先级关系，这只能通过对比沙漏边界附近的像素颜色来归纳。
