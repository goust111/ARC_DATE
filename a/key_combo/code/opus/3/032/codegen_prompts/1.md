## 新题 1：弯折分类光环叠印

**组合逻辑**：[环路追踪 + 分类涂色](已有) → [印章覆盖 + 邻域扩展](已有，但印章颜色由弯折分类决定——创新耦合) → [重涂色](创新：叠印冲突区产生第三色)

**来源原语**：环路追踪/trace_cycle（15663ba9）、分类涂色/classify_and_color（15663ba9）、印章覆盖/stamp_overlay（dc1df850）、邻域扩展/neighborhood_expand（dc1df850）、仅填背景格/only_fill_background（dc1df850）、重涂色/recolor

**依赖链**：环路追踪得到每个像素的弯折类型 → 弯折类型决定该像素光环的颜色 → 不同颜色光环在空间上重叠时产生第三种颜色。删除追踪步骤则无法分类弯折；删除分类则光环无颜色依据；删除重叠规则则无法确定冲突区颜色。

根据环路上每个像素的弯折类型，在其周围印上不同颜色的光环；当两种光环重叠时，重叠区域变为第三种颜色。

**输入结构**：约 15x15 的黑(0)背景网格。绿(3)前景色形成一条或多条闭合正交环路（每条环路为 1 像素宽、4-连通、每个前景像素恰好有 2 个前景邻居）。不同环路互不接触，且均不触碰网格边界。环路包含凸弯折和凹弯折（即环路形状不是简单矩形，至少有一个凹角）。生成约束：任意两个弯折像素的 Chebyshev 距离至少为 1（即它们的 3x3 光环区域可以重叠，但弯折像素本身不相邻），以保证光环重叠模式可辨识。

**规则**：
1. 对每条闭合环路执行环路追踪。在每个前景像素处判定转向：若该像素的两个邻居共线则为直行像素；否则为弯折像素。
2. 对每条环路统计所有弯折像素的转向方向。出现次数较多的方向为凸弯折，出现次数较少的方向为凹弯折。
3. 对每个凸弯折像素，以其为中心在 3x3 邻域内将所有黑(0)背景格涂为黄(4)。不覆盖任何非黑像素（包括绿(3)环路像素和已涂色的光环像素）。
4. 对每个凹弯折像素，以其为中心在 3x3 邻域内将所有黑(0)背景格涂为红(2)。同样不覆盖非黑像素。
5. 凸光环和凹光环的印章按环路追踪顺序依次执行。若某个背景格同时处于某凸弯折的 3x3 范围和某凹弯折的 3x3 范围内，则无论印章顺序如何，该格最终颜色为蓝(1)。具体实现：所有印章完成后，检查每个已涂色格——若它既在某凸弯折的 3x3 范围内又在某凹弯折的 3x3 范围内，则改涂为蓝(1)。
6. 直行像素和环路像素保持绿(3)不变。

**关键洞察**：蓝(1)像素只出现在凸弯折光环与凹弯折光环的空间交集处。求解者必须先正确分类弯折类型，再理解"双重覆盖→第三色"的冲突解决规则，两者缺一不可。不同环路形状产生不同的重叠图案，需要对比多个示例才能确认冲突规则。
