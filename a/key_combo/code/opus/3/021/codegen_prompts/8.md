## 新题 8：循环位移后最近边重涂色

**组合逻辑**：[循环位移/cyclic_roll](控制列编码的偏移量驱动内容滚动) + [最近边归属/nearest_side_assignment](滚动后像素与边框四边的距离关系改变) + [重涂色/recolor](按新的最近边归属重涂前景像素) + [空心矩形/rectangular_frame](框的四边各有独立颜色)

**来源原语**：循环位移(6d1d5c90)、控制列(6d1d5c90)、标记像素(6d1d5c90)、标记位定位移量(6d1d5c90)、行偏移编码(6d1d5c90)、最近边归属(9aec4887)、最近边决定涂色(9aec4887)、重涂色(9aec4887)、空心矩形(9aec4887)、前景掩码(9aec4887)

**依赖链**：控制列中标记位置 → 确定循环位移量 → 框内前景图案按该量向下滚动（环绕） → 滚动后每个前景像素到四边的距离改变 → 按新的最近边归属重涂颜色。重涂色的结果完全取决于滚动后的布局，而滚动量来自外部控制列，求解者必须先破解位移编码、再破解最近边规则。

读取控制列中标记的行位置作为滚动偏移量，将框内前景图案循环下移后，按每个前景像素到框四边的最近距离重涂为该边颜色。

**输入结构**：黑(0)背景网格，约 10x12（高 10、宽 12）。最左一列为控制列，全部为品红(6)，其中恰好一个像素为红(2)标记，其余为品红(6)。控制列右侧为主区域（10x11），主区域中央有一个空心矩形框，框的四条边各用不同颜色：上边绿(3)、下边蓝(1)、左边黄(4)、右边橙(7)，四角留为黑(0)背景。框的内部尺寸为 n x n（约 5x5 至 7x7）。框内有若干灰(5)前景像素构成不规则图案（4-连通，约 6~12 像素），其余内部为黑(0)。生成约束：红(2)标记的行索引 r 满足 1 <= r <= n-1，保证滚动量有意义；灰(5)图案不对称，以使滚动后最近边归属发生可见变化；不同示例中灰(5)图案形状不同。

**规则**：
1. 读取控制列中红(2)标记像素的行索引 r（从 0 开始计数）。删除控制列，输出宽度减 1。
2. 将框内部的内容（灰(5)像素和黑(0)背景）作为一个 n x n 子网格，循环向下滚动 r 行（最底部的 r 行移到最顶部）。框边框不动。
3. 滚动完成后，对每个灰(5)前景像素，计算它到框内部区域四边的距离（到上边 = 像素行 - 内部顶行，到下边 = 内部底行 - 像素行，到左边 = 像素列 - 内部左列，到右边 = 内部右列 - 像素列）。
4. 若最近的边唯一（四个距离中最小值唯一出现），则将该像素重涂为对应边的颜色（上→绿(3)，下→蓝(1)，左→黄(4)，右→橙(7)）。若最近边不唯一（存在并列最小距离），则该像素保留灰(5)不变。
5. 输出保留框边框、重涂后的前景像素、以及框内的黑(0)背景。框外区域保持黑(0)。

**关键洞察**：循环位移改变了每个前景像素在框内的相对位置，从而改变其最近边归属和最终颜色——同一个灰像素在不同滚动量下会被涂成不同颜色。求解者必须先发现控制列编码了滚动量（对比不同示例中标记行与像素移动的关系），再理解最近边涂色规则，两条规则的推理相互独立但结果紧密耦合。
