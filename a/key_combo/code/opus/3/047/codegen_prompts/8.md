## 新题 8：边缘标记压缩构建走廊的路径追踪

**组合逻辑**：[压缩/栅格对齐](已有) → [标记指示方向/滑动](已有) → [碰撞转向/遇障碍直角转](创新：障碍物本身是压缩+滑动的产物) → [路径绘制](已有)

**来源原语**：压缩/栅格对齐/空心符号/边缘标记线/标记指示方向(afe3afe9), 碰撞转向/遇障碍直角转/起点条/障碍像素/走廊路径(6bcdb01e), 滑动(afe3afe9), 路径绘制(da515329)

**依赖链**：空心符号被压缩为像素 → 边缘标记线指示重力方向 → 压缩后的像素沿该方向滑动堆叠形成墙壁 → 起点条在压缩后的网格中发射路径 → 路径沿走廊前进，遇墙壁（即滑动后的压缩像素）转弯 → 走廊的形状完全取决于压缩和滑动的结果。

将粗栅格中的空心符号压缩为像素并按边缘标记方向滑动堆叠，压缩像素成为走廊墙壁，然后从起点条出发在走廊中追踪路径直到离开网格。

**输入结构**：约 15x15 的黑(0)背景网格。网格的一条完整边（上、下、左或右之一）被蓝(1)像素填满，作为边缘标记线。网格内部按 3x3 粗栅格排布（共 5x5 = 25 个栅格位，每个栅格位 3x3 像素），其中 6~10 个栅格位放有空心 3x3 符号（黄(4)色外框，中心黑色），其余栅格位为空。网格的某条非标记边上有一个绿(3)色的 2 像素 4-连通起点条（水平或垂直相邻的两个绿像素），其中恰好一个像素位于网格边界。生成约束：蓝色标记线所在边与起点条所在边不同；压缩并滑动后形成的墙壁构成至少包含两个转弯的走廊；起点条的方向使其初始运动方向指向网格内部。

**规则**：
1. 压缩：将每个空心 3x3 符号替换为位于其栅格中心的单个黄(4)像素，同时将粗栅格收缩为每栅格位 1 像素的紧凑网格（5x5）。蓝色标记线收缩为紧凑网格对应边的一行/列蓝像素。起点条收缩为紧凑网格对应位置的 2 像素条。
2. 滑动：根据蓝色标记线的位置确定滑动方向——顺时针读边：上边 → 向右滑动，右边 → 向下滑动，下边 → 向左滑动，左边 → 向上滑动。将紧凑网格中所有黄(4)像素沿该方向滑动，直到撞到网格边界或另一个黄像素。蓝色标记线像素从输出中移除（它仅作为方向指示器）。
3. 路径追踪：从起点条的边界像素出发，沿穿过另一个起点像素的方向进入网格。逐格前进，每前进一格将该格涂为绿(3)。当下一格为黄(4)像素（墙壁）时，检查左右两个垂直方向：选择不是墙壁且不超出网格的方向转弯 90°（恰好有唯一选择，因为走廊保证只有一个可行转向）。当下一格超出网格边界时停止。
4. 起点条的两个像素都保持绿(3)。黄色墙壁像素保持黄(4)。路径像素为绿(3)。其余为黑(0)背景。

**关键洞察**：空心符号、边缘标记和起点条在原始输入中看似独立的三组元素，在压缩后协同构建了一个完整的走廊迷宫系统——符号变成墙壁，标记决定墙壁的堆叠方式（从而决定走廊形状），起点条发射路径。改变标记线所在的边会完全重组墙壁布局，产生完全不同的路径。

1. `main(grid)` 必须实现新题描述中的确定性转换规则，不能只识别 `generate_input()` 的固定模板。禁止不同的input网格输出相同的output网格。

3. 生成器必须保证输入满足 `main()` 的隐式假设：对象不重叠、不越界、特殊标记唯一或可区分、匹配关系无歧义、关键分支出现概率相同。
4. 禁止把 ARC 颜色 id 、亮度、拼写等当作人类不可见的数值语义参与排序、大小比较或隐藏映射。颜色变化必须有可见结构线索。注意颜色亮度、拼写等也是不可见信息，若描述中出现违规的颜色id或者亮度，可自行使用少量的固定颜色替代，但注意生成时要在三个以内输入输出网格中对所有变换100%覆盖度。
