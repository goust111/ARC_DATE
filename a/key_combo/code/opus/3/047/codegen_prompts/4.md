## 新题 4：精灵体像素自编码的错切平铺

**组合逻辑**：[像素数定尺寸数](已有) → [平铺/阵列排布](已有) → [错切/行偏移递变](创新：错切量由网格维度决定，而网格维度又来自像素计数)

**来源原语**：像素数定尺寸数/平铺/阵列排布/精灵体(91413438), 错切/行偏移递变/行内容保持(3cd86f4f), 计数(91413438)

**依赖链**：3x3 精灵体中的前景/背景像素数同时编码了输出阵列的维度和副本数量 → 平铺操作使用这两个数值生成阵列 → 错切操作将每行右移 r 列（r 为行号对阵列边长取模），而阵列边长正是背景像素数 → 精灵体既是平铺内容也是尺寸编码器也是错切参数源。

将 3x3 精灵体按其自身的前景/背景像素数平铺成方阵，然后将整个方阵按行做等差错切，错切周期等于方阵的槽位边长。

**输入结构**：一个 3x3 的小网格，包含黑(0)背景像素和恰好一种非黑前景色的像素。前景像素数 F 在 2~5 之间，背景像素数 B = 9 - F 在 4~7 之间。生成约束：F < B（保证副本数小于总槽位数）。

**规则**：
1. 计数：统计 3x3 输入中前景像素数 F 和背景（黑色）像素数 B。
2. 构建输出画布：大小为 (3B) x (3B + B - 1)，即 B 行槽位，每行 B 个槽位宽度加上最大错切量。初始化为全黑。（注：由于错切，画布宽度需要额外的 B-1 列。）
3. 平铺：在画布上按行优先顺序放置 F 个 3x3 精灵体副本。第 i 个副本（i 从 0 开始）放在槽位行 floor(i/B)、槽位列 i mod B 处。每个槽位为 3x3 像素，槽位 (sr, sc) 的左上角像素坐标为 (3*sr, 3*sc)。
4. 错切：对输出画布的每个像素行 r，将该行的所有像素整体右移 (r mod (3*B)) / 3 取整 = floor(r / 3) 列。即每 3 个像素行共享相同的偏移量，偏移量随槽位行号线性增长。空出的左侧位置填黑(0)。
5. 超出画布右边界的像素丢弃。

**关键洞察**：精灵体的像素组成是一个自指编码——前景像素数决定"画多少个"，背景像素数决定"画布多大"以及"错切多剧烈"。改变精灵体中哪怕一个像素的颜色，会同时改变平铺数量、画布尺寸和错切周期，产生截然不同的输出。
