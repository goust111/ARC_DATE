## 新题 1：异常块就地反转

**组合逻辑**：[计数/counting] + [异常值提取/outlier_extraction](创新：异常块不裁剪，而是就地变换) → [反转填充/occupancy_inversion](创新：仅对被选中的单个块执行，反转色用新颜色标记)

**来源原语**：计数、背景孔洞、异常值提取（358ba94e）；反转填充、重涂色、瓷砖（1c0d0a4b）

**依赖链**：孔洞计数产生每个块的特征值 → 异常值判断选出唯一目标块 → 反转填充仅作用于该目标块，其余块不变。计数结果决定了反转填充的作用域，而反转填充的输入图案正是计数时分析的孔洞分布。

将多个同色前景块中孔洞数量唯一的那一个就地执行占用反转，反转后的新前景用另一颜色标记，其余块保持原样。

**输入结构**：黑(0)背景，约 15x18 的网格。一种前景色（如蓝(1)）形成 4-6 个互不相连的同尺寸方块（每个约 5x5），各方块之间至少间隔 1 行/列背景。每个方块内部有若干黑(0)背景孔洞（1-4 个像素），形成不同的内部图案。大多数方块的孔洞数量相同（如都是 2 个），恰好一个方块的孔洞数量与其余不同（如 3 个）。生成约束：孔洞数量的众数恰好出现 N-1 次（N 为方块总数），剩余一个方块的孔洞数量唯一。

**规则**：
1. 对每个蓝(1)方块，计算其 5x5 包围盒内黑(0)背景像素的数量（即孔洞数）。
2. 找到孔洞数在所有方块中唯一出现的那一个方块（异常块）。
3. 对异常块执行占用反转：将其包围盒内原本为蓝(1)的像素改为黑(0)，原本为黑(0)的像素改为红(2)。
4. 所有其他方块保持不变，背景保持不变。
5. 输出完整网格。

**关键洞察**：异常块不是被裁剪提取出来，而是在原位被反转——用于识别异常的孔洞分布图案，恰好也是反转后新图案的"底片"，因此同一组孔洞同时承担了选择功能和变换定义。

1. `main(grid)` 必须实现新题描述中的确定性转换规则，不能只识别 `generate_input()` 的固定模板。禁止不同的input网格输出相同的output网格。
2. `generate_input()` 必须随机生成多样样例，不能固定死。随机维度应覆盖：网格大小、对象数量、位置、颜色、方向、形状参数或关键分支。注意若描述中存在若干，需实现而不是只有单个，包括object或者对应关系等等。
3. 生成器必须保证输入满足 `main()` 的隐式假设：对象不重叠、不越界、特殊标记唯一或可区分、匹配关系无歧义、关键分支出现概率相同。
4. 禁止把 ARC 颜色 id 、亮度、拼写等当作人类不可见的数值语义参与排序、大小比较或隐藏映射。颜色变化必须有可见结构线索。注意颜色亮度、拼写等也是不可见信息，若描述中出现违规的颜色id或者亮度，可自行使用少量的固定颜色替代，但注意生成时要在三个以内输入输出网格中对所有变换100%覆盖度。
