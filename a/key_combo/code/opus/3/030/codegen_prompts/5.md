## 新题 5：面板内面积众数筛选后跨面板叠合

**组合逻辑**：[计数/counting](创新：计数目标从颜色频次改为对象面积) → [多数投票/majority_vote](创新：投票对象是面积值而非颜色) → [筛选/filtering] → [拼接/merge] + [位序选择/positional_selection](创新：不按面板序号选位序，而是保留所有通过筛选的对象)

**来源原语**：计数、多数投票、多数决（27a77e38）；拼接、位序选择、等分面板、分隔条（5ecac7f7）；筛选（23b5c85d）

**依赖链**：面板分割定义独立子问题 → 每个面板内对对象面积做众数投票 → 众数面积作为筛选阈值保留匹配对象 → 三个面板的存活对象叠合到统一画布。面板结构决定投票范围；投票结果决定筛选条件；筛选后对象集决定叠合内容。

在三个分隔面板中，分别对前景对象的像素面积做众数投票，仅保留面积等于众数的对象，然后将三个面板的保留对象叠合到一个画布上。

**输入结构**：约 10x32 的网格，由两条垂直灰(5)分隔条等分为三个 10x10 的面板（分隔条各 1 列宽）。每个面板的背景为黑(0)，包含 4-5 个单色 4-连通前景对象，每个对象使用面板内唯一的颜色（同一面板内不同对象颜色不同，但不同面板间颜色可重复）。各对象像素面积在 3-8 之间。生成约束：每个面板内恰好有一个面积值出现次数最多（严格众数），且不同面板的众数面积值可以不同；每个面板内至少有 2 个对象的面积等于众数，至少有 1 个对象面积不等于众数。

**规则**：
1. 按灰(5)分隔条将网格切分为三个 10x10 面板（左、中、右）。
2. 在每个面板内，计算每个 4-连通前景对象的像素面积。
3. 对每个面板，找到面积值的严格众数（出现次数最多的面积值）。
4. 仅保留面积等于该面板众数的对象，擦除其余对象（恢复为黑(0)）。
5. 创建一个 10x10 的黑(0)画布。将三个面板中保留的对象按原始面板内坐标叠合到该画布上。
6. 若不同面板的保留对象在同一位置重叠，右侧面板的对象覆盖左侧面板的对象。
7. 输出 10x10 画布（不含分隔条）。

**关键洞察**：众数投票在每个面板内独立进行且投票对象是面积而非颜色，因此不同面板可能保留不同大小的对象；最终叠合时，空间冲突由面板顺序（右优先）解决，这意味着即使知道了保留规则，仍需推断面板叠合的覆盖优先级。
