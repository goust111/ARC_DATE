## 新题 5：射线交叉分区后按面积排序填色

**组合逻辑**：[射线延伸](已有，十字射线) → [洪泛填充](创新：对射线划分出的区域做填充) → [排序](创新：按区域面积排序) → [重涂色](由面积排名决定颜色)

**来源原语**：射线延伸(ray_extend, 23581191)、洪泛填充(flood_fill, 941d9a10)、排序(sort, 941d9a10)、重涂色(recolor, 941d9a10)、孤立像素(isolated_pixel, 23581191)、封闭区域(bounded_region, 941d9a10)、行列交叉(row_col_intersection, 23581191)、位置排序(positional_ordering, 941d9a10)、位置决定填充色(position_determines_fill_color, 941d9a10)

**依赖链**：孤立像素的位置决定十字射线的走向 → 多条射线在网格中交叉，将空间划分为矩形区域 → 区域的面积由射线的相对位置隐式决定 → 面积排序决定每个区域的填充颜色

一句话总结：从多个孤立像素发射全行全列十字射线，射线将网格切割为若干矩形区域，按区域面积从小到大排序并依次着色。

**输入结构**：约 14x14 的网格，黑(0) 背景。3~4 个孤立像素，颜色各不相同（如橙(7)、蓝(1)、红(2)），互不在同一行且互不在同一列。生成约束：像素位置使得射线将网格划分出的矩形区域面积互不相同（避免平局）。

**规则**：
1. 对每个孤立像素，将其整行和整列都涂为灰(5) 色（像素自身也变为灰色）。灰色射线是分隔线。
2. 灰色射线将网格分割为若干矩形区域（不含射线本身的像素）。
3. 计算每个矩形区域的面积（像素数）。
4. 按面积从小到大排序。面积最小的区域填充蓝(1)，第二小的填充红(2)，第三小的填充绿(3)，第四小的填充黄(4)，第五小的填充品红(6)，第六小的填充橙(7)，以此类推。若区域数超过 6，多余的区域填充青(8)。
5. 灰色分隔线保持不变。

**关键洞察**：输入中只有几个孤立像素，但它们的精确位置决定了整个网格的分区方式和每个区域的面积。求解者需要理解射线分区的几何效应，才能预测面积排序并确定颜色分配。像素的原始颜色是干扰项，最终全部被灰色覆盖。
