## 新题 1：重力合并改变像素计数与着色

**组合逻辑**：[重力下落](已有) → [连通分量检测](创新：检测落地后的合并体而非原始对象) → [计数→重涂色](已有映射规则，但输入来自合并后的新分量)

**来源原语**：重力下落(gravity_drop, 825aa9e9)、计数(count, 6e82a1ae)、重涂色(recolor, 6e82a1ae)、连通分量检测(connected_component_detection, 84db8fc4)、可动对象(movable_object, 825aa9e9)、障碍物(obstacle, 825aa9e9)、缓冲行间距(cushion_row_gap, 825aa9e9)、像素数映射颜色(count_to_color, 6e82a1ae)

**依赖链**：重力下落改变对象的空间位置 → 落地后原本不相邻的对象可能变为 4-连通相邻从而合并成更大的连通分量 → 合并后的像素数与原始对象的像素数不同 → 按合并后的像素数执行颜色映射

一句话总结：灰色小对象在重力作用下落到障碍物上方（保留一行缓冲），落地后相邻的对象合并为新连通体，根据合并后的像素总数重新着色。

**输入结构**：约 12x10 的网格，黑(0) 背景。底部有栗(9) 色障碍物像素（不规则分布，不一定连续，但至少部分触碰底边）。网格上半区散布若干灰(5) 色 4-连通小对象（每个 2~4 像素，形状各异，如竖条、横条、弯折碎片等）。对象之间在初始位置互不 4-连通，但部分对象在同一列或相邻列上垂直分布，使得下落后可能相邻合并。生成约束：下落后至少有一对原本独立的对象合并为一个连通分量，且合并后像素数仍在 2~6 范围内。

**规则**：
1. 栗(9) 色像素和黑(0) 色背景保持不变。将栗色像素、栗色像素正上方一行的单元格、以及网格最底行标记为"阻塞"。
2. 将每个灰(5) 色 4-连通对象视为刚体，整体向下移动，直到其任一像素的下一行位置为阻塞单元格或另一个已静止的灰色对象时停止。处理顺序：按对象最低像素行号从大到小（最接近底部的先落）。
3. 所有对象静止后，重新检测所有灰色像素的 4-连通分量（此时某些原本独立的对象可能已合并）。
4. 按合并后的像素数重涂色：2 像素→绿(3)，3 像素→红(2)，4 像素→蓝(1)，5 像素→黄(4)，6 像素→品红(6)。

**关键洞察**：重力下落不只是移动对象——它会改变连通性，使原本独立的小对象合并为更大的连通体，从而改变像素计数和最终颜色。求解者不能先着色再移动，必须先完成所有重力模拟才能确定正确的像素计数。
