## 新题 6：重力重排证据后推断周期瓦片

**组合逻辑**：[重力下落](已有，目的改为证据重排) → [周期推断](已有，但证据经重力打乱后重排才一致) → [补全](已有)

**来源原语**：重力下落/gravity_drop (36a08778, 2b83f449), 周期推断/period_inference (c663677b), 补全/complete (c663677b), 重复瓦片/repeating_tile (c663677b), 缺损像素/corrupted_pixel (c663677b), 周期相位对应/periodic_phase_match (c663677b), 碰撞停止/collision_stop (36a08778), 非缺损像素一致性/non_corrupted_consistency (c663677b)

**依赖链**：输入中部分瓦片证据被位移到错误行（悬浮），直接做周期推断会得到矛盾的相位信息。重力下落将悬浮像素移回正确的列底部位置，使非黑像素在列内恢复正确的空间关系后，周期推断才能找到唯一的最小重复瓦片。删除重力步骤则证据不一致无法推断周期；删除周期推断则无法补全缺损位置。

先将悬浮的彩色证据像素按重力下落到各列底部，使其相位归位后推断最小重复瓦片并补全所有缺损位置。

**输入结构**：约 12x12 的网格。大部分单元格为黑(0)（缺损/空位）。其余单元格使用红(2)、蓝(1)、绿(3)三种颜色，呈现某个周期瓦片的部分证据。该瓦片的行周期 P_r 和列周期 P_c 均为 2-4 之间的小整数。证据像素分为两类：一类已处于正确位置（与隐含瓦片的相位一致），另一类被人为抬高——在同一列中上移了若干行，下方留出黑色空位。每列内的非黑像素之间没有黑色间隔（悬浮像素紧贴在正确位置像素上方或独立悬浮在列顶部附近）。生成约束：重力下落后（每列内非黑像素堆叠到列底部，保持列内相对顺序），所有非黑像素恰好满足唯一的最小周期瓦片相位一致性；下落前则不满足。每个瓦片相位至少在一个非黑像素中可见。

**规则**：
1. 对每列独立执行重力下落：将该列中所有非黑像素向下移动，堆叠到列的底部（或已有非黑像素之上），保持列内非黑像素的从上到下相对顺序不变。腾出的上方位置变为黑(0)。
2. 下落完成后，将所有黑(0)单元格视为缺损位置。
3. 找到最小的行周期 P_r 和列周期 P_c（P_r >= 1, P_c >= 1，P_r * P_c > 1），使得所有非黑像素按 (row mod P_r, col mod P_c) 相位分组时，同相位像素颜色一致。
4. 由推断出的瓦片相位，将每个缺损（黑色）单元格重涂为其相位对应的颜色。
5. 输出完整修复的周期壁纸网格。

**关键洞察**：悬浮的证据像素提供了某些列中缺失的瓦片相位信息，但只有在重力将它们移到正确的行位置后，这些信息才与整体瓦片周期一致。重力下落与周期推断之间的耦合不是简单的前后传递——重力改变了像素的行坐标，而行坐标直接决定相位计算。
