## 新题 4：跨面板镜像与障碍绕行重涂色

**组合逻辑**：[镜像](已有：行序翻转) + [连线/绕行](创新：绕行目标不再是同色分量间的连接，而是镜像目标位置与实际放置位置之间的位移路径) + [重涂色](创新：重涂条件不再是形状匹配，而是是否发生了位移绕行)

**来源原语**：镜像·整幅画布·翻转行序 来自 68b16354；连线·障碍墙·同色连通分量·绕障碍最短路径 来自 f8f52ecc；分隔行·跨面板搬运 来自 dc46ea44；重涂色 来自 776ffc46

**依赖链**：上面板对象镜像到下面板计算目标位置 → 检测目标位置与障碍墙冲突 → 冲突对象通过 BFS 搜索最近无冲突放置位置 → 绘制位移连接路径 → 被位移的对象重涂为黄色以区分。镜像提供目标、障碍产生冲突、绕行解决冲突、重涂标记冲突——四步形成因果闭环。

将上面板的彩色对象镜像到下面板；与障碍墙冲突的对象被移至最近可用位置，绘制绿色连接路径，并重涂为黄色标记位移。

**输入结构**：
- 网格约 15x30（宽），背景黑(0)。
- 一条贯穿全宽的灰(5)水平分隔行将网格分为等高的上面板（行 0 至分隔行-1）和下面板（分隔行+1 至最后一行）。
- 上面板包含 3-5 个小型 4-连通单色对象（每个 3-6 像素），颜色各不相同且非灰非黄（如红(2)、蓝(1)、绿(3)、橙(7)、栗(9)）。对象间互不相邻。
- 下面板包含 2-4 段青(8)障碍墙：每段是短的水平或垂直条（3-5 像素长）。障碍的放置保证至少 2 个上面板对象的镜像目标位置与障碍重叠，且至少 1 个不重叠。
- 生成约束：对每个存在冲突的对象，下面板中存在通过背景像素可达的、能容纳该对象完整形状的无冲突区域，且该区域与镜像目标位置的曼哈顿距离不超过 5。

**规则**：
1. 保留分隔行不变。
2. 保留下面板所有青(8)障碍墙不变。
3. 对上面板中每个彩色对象，计算其镜像目标位置：每个像素的行 r 映射到 分隔行行号 + (分隔行行号 - r)，列不变。
4. 若镜像后的对象所有像素均不与任何障碍像素或已放置对象像素重叠，则将该对象以原色放置在镜像位置。
5. 若镜像后的对象有任何像素与障碍或已放置对象重叠：
   - 以镜像位置的质心为起点，对该对象执行 BFS 位移搜索：依次尝试将整个对象向上、右、下、左平移 1, 2, 3, ... 像素，找到第一个使所有对象像素均落在背景空位上（不与障碍、分隔行、已放置对象重叠）的位移方案。搜索按曼哈顿距离升序、同距离时按上-右-下-左优先。
   - 在镜像质心与实际放置质心之间绘制一条 1 像素宽的绿(3) L 形连接路径（先水平后垂直）。路径像素仅覆盖背景像素，遇到障碍或其他非背景像素则跳过该像素（路径不连续处断开）。
   - 将该对象重涂为黄(4)后放置在实际位置。
6. 按上面板对象的行主序（从上到下，同行从左到右）依次处理。先放置的对象成为后续对象的障碍。
7. 上面板的所有对象像素在输出中清除为背景。

**关键洞察**：镜像本身是平凡的，但障碍冲突将问题转化为带优先级的放置博弈：处理顺序决定了哪些对象能获得镜像位置、哪些被挤到次优位置并被标记为位移，使最终布局不可从单个对象独立推断。
