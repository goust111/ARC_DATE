## 新题 5：括号提取调色板驱动对角带层填充

**组合逻辑**：[裁剪/括号提取](已有：蓝·青标记对界定行段) + [循环填充](已有：层深度模调色板取色) — 创新在于调色板不再是输入中显式给出的一行像素，而是通过括号提取从网格的另一区域间接获得

**来源原语**：裁剪·控制像素对·行段·括号界定提取范围·按行序堆叠等宽段 来自 505fff84；循环填充·对角带·调色板行·层深度递增·层深模色板取色 来自 b457fec5

**依赖链**：识别蓝·青括号对标记行 → 提取每行括号间的像素段 → 每段的左起第一个非背景像素颜色成为调色板的一个条目 → 用此调色板按层深度循环填充对角带。提取步骤产出调色板，填充步骤消费调色板，两者缺一均无法确定输出。

从括号标记对界定的行段中提取隐含的调色板序列，再用该调色板按层深度循环填充网格另一区域的对角带。

**输入结构**：
- 网格约 20x20，背景黑(0)。
- 左半区（约列 0-9）：3-5 行中各有一个蓝(1)像素和一个青(8)像素，蓝在左、青在右。每对蓝·青之间恰有 1 个单色像素（颜色为红(2)、绿(3)、橙(7)、栗(9)等，各行不同）。括号对行不一定连续，但按行号升序排列对应调色板的索引顺序。其余行为纯背景。
- 一条垂直灰(5)分隔线位于约第 10 列，贯穿全高。
- 右半区（约列 11-19）：2-3 条灰(5)对角带，每条宽 3-4 像素、沿对角方向长 6-10 像素，方向为 45 度。每条带在靠近网格顶部的一端有平坦的顶帽。
- 生成约束：提取出的调色板条目数大于等于所有对角带中最大层深度加 1。

**规则**：
1. 找到所有同时包含蓝(1)和青(8)像素的行，按行号升序排列。
2. 对每行，取蓝像素与青像素之间（不含端点）的像素段。段中左起第一个非背景像素的颜色记为调色板的一个条目。按行号升序，依次得到有序调色板 P[0], P[1], ..., P[k-1]。
3. 在输出中移除所有蓝(1)和青(8)标记像素（设为背景），移除垂直灰(5)分隔线（设为背景）。保留括号间提取出的彩色像素不变。
4. 对右半区的每条灰(5)对角带，计算每个像素的层深度：层 0 为带最外层边界像素，层 1 为下一内层，层深度等于该像素沿垂直于带轴方向到最近带边缘的距离。平坦顶帽的所有像素均属于层 0。
5. 将每个灰(5)带像素重涂为 P[层深度 mod k]。
6. 若带与分隔线的原位置重叠，带的重涂色优先。

**关键洞察**：调色板并非显式排列的一行颜色，而是隐藏在括号标记界定的提取结构中；求解者必须先识别提取模式、重建调色板序列，才能解读对角带的填充规则。

1. `main(grid)` 必须实现新题描述中的确定性转换规则，不能只识别 `generate_input()` 的固定模板。禁止不同的input网格输出相同的output网格。

3. 生成器必须保证输入满足 `main()` 的隐式假设：对象不重叠、不越界、特殊标记唯一或可区分、匹配关系无歧义、关键分支出现概率相同。
