## 新题 2：角落标记决定旋转方向从而改变色条排序结果

**组合逻辑**：[裁剪·内部区域提取](已有原语) + [旋转](创新：旋转角度由角落标记隐式编码) → [排序·最高行决定序 + 压缩·色条行](已有原语，但排序键被旋转改变)

**来源原语**：裁剪/空心矩形/内部区域/最大边框内部提取(1c786137)，旋转/角位置对应(412b6263, e3f79277)，排序/压缩/色条行/最高行决定序(668eec9a)

**依赖链**：角落标记 → 确定旋转角度 → 旋转改变"最高行"的语义 → 同一组线段在不同旋转下产生不同的排序结果 → 输出色条顺序随角落标记位置而变。这不是线性流水线：旋转步骤回溯性地改变了排序步骤的判据，形成隐式循环依赖。

从矩形边框中提取内部区域，按角落标记指示的方向旋转内容，然后将旋转后内部的前景线段按新的最高行排序，压缩为水平色条输出。

**输入结构**：约 14x14 网格。背景为黑(0)。一个灰(5)单像素厚的完整矩形边框占据网格中央区域。边框内部包含 3-4 条单像素厚的线段，每条线段用不同的非黑、非灰颜色（取自 {蓝(1), 红(2), 绿(3), 橙(7)}），线段方向为水平或垂直，长度 2-5 像素不等，分布在内部区域的不同行列位置。边框的四个角恰好有一个被替换为品红(6)像素，其余三角保持灰(5)。生成约束：内部线段的行位置经任意 90 度旋转后仍互不相同，保证排序无歧义。

**规则**：
1. 找到灰(5)矩形边框并提取其严格内部区域（不含边框像素本身）。品红(6)角像素属于边框的一部分，不进入内部。
2. 品红(6)像素所在的角确定旋转角度：左上角 → 不旋转(0°)，右上角 → 顺时针 90°，右下角 → 180°，左下角 → 顺时针 270°。此映射需对比多个示例归纳。
3. 将提取的内部区域按确定的角度顺时针旋转。
4. 在旋转后的内部区域中，识别每种前景颜色占据的最高行（行索引最小）。按最高行从上到下排序各颜色。
5. 输出一个 5x3 网格，背景为黑(0)。从底行开始，依排序顺序（最高行最靠上的颜色放在输出最底行）逐行向上放置 1x3 纯色条。未使用的行保持黑(0)。

**关键洞察**：品红角标不只是装饰元数据——它实质性地改变了排序键的方向。相同的内部内容在不同旋转下，"最高行"指向完全不同的线段，因此输出色条顺序会彻底改变。求解者必须先确定旋转映射规则，才能正确排序。
