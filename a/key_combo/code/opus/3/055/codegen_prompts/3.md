## 新题 3：线段长度参数化同心方框层厚

**组合逻辑**：[排序·最高行决定序](已有原语) → [计数](创新：统计像素数作为几何参数而非选择依据) + [嵌套包裹·逐层构建](创新：层厚不由色条高度决定，而由线段像素数决定)

**来源原语**：排序/线段对象/顺序排列/最高行决定序(668eec9a)，计数(a87f7484)，嵌套包裹/同心正方形层/逐层构建/条高决定框厚(45a5af55)

**依赖链**：线段的垂直位置决定层序（谁包谁），线段的像素数量决定层厚——这两个属性在输入中独立变化：短线段可能在最顶行（成为最外层），长线段可能在最底行（成为最内层）。必须同时正确读取位置和长度两个属性才能构建输出。

将网格中分散的彩色线段按其最高行排序确定同心嵌套层序，每条线段的像素数量决定其对应层的厚度，逐层由内向外包裹构建同心正方形结构。

**输入结构**：约 18x12 网格。背景为黑(0)。3-5 条单像素厚的线段分散在网格各处，每条线段为水平或垂直方向，使用不同的非黑颜色（取自 {蓝(1), 红(2), 绿(3), 橙(7), 品红(6)}），像素数在 1-4 之间。各线段占据的最高行互不相同。线段之间互不接触。生成约束：所有线段像素数之和的 2 倍减去线段数量不超过 15（保证输出网格不过大）。

**规则**：
1. 识别每种前景颜色的线段，记录其占据的最高行（行索引最小的行）和像素数量。
2. 按最高行从上到下排序所有线段。排序后，最底行的线段（排序末位）为最内层，最顶行的线段（排序首位）为最外层。
3. 从最内层开始构建：最内层线段的像素数 p 决定中心实心正方形的边长为 p，颜色为该线段颜色。
4. 按从内到外的顺序，每一层线段以其像素数为厚度，以其颜色为框色，在当前结构外侧包裹一圈同心正方形框。设当前结构边长为 s，新层厚度为 t，则包裹后边长为 s + 2t。
5. 输出仅包含最终的同心正方形结构，大小恰好容纳。

**关键洞察**：垂直位置和线段长度是完全独立的两个编码通道——位置编码层序（谁在里谁在外），长度编码层厚。一条仅 1 像素的线段如果在最底行就是 1x1 的核心方块；一条 4 像素的线段如果在最顶行就是厚度为 4 的最外框。必须对比多个示例才能区分这两个通道的作用。
