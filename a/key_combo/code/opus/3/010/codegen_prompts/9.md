## 新题 9：周期补全揭示隐藏的轴向重复后裁剪唯一瓦片

**组合逻辑**：[补全/completion](已有) → [裁剪/crop](创新：裁剪的前提是补全后涌现的结构——补全前看不到重复) ← [平移等价/translation_equivalence] 驱动补全，补全后 [轴向复制/axial_dup] 才成立，触发 [沿重复轴取首半/first_half_extract]

**来源原语**：补全(484b58aa), 裁剪(7b7f7511), 平移等价(484b58aa), 轴向复制(7b7f7511), 平移向量决定填充(484b58aa), 沿重复轴取首半(7b7f7511), 缺失像素(484b58aa), 重复瓦片(7b7f7511)

**依赖链**：网格有大量缺失像素（黑洞），破坏了视觉上的重复性 → 用周期平移向量填补所有黑洞 → 补全后的网格恰好是一个瓦片沿某一轴的两份完全拷贝 → 裁剪出其中一份。删除补全步骤则两半不同（缺失位置不同），无法识别重复轴；删除裁剪步骤则输出不确定。

先用周期平移向量填补网格中的缺失像素，然后发现补全后的网格恰好是一个瓦片的两份轴向复制，裁剪输出该唯一瓦片。

**输入结构**：约 8x16（或 16x8）的网格。包含一个由 3~4 种颜色（如蓝(1)、红(2)、绿(3)、黄(4)）构成的图案，但约 20%~30% 的像素被替换为黑(0)（缺失像素），散布在网格各处。未被替换的像素保留原色。关键特征：网格的长轴恰好是短轴的 2 倍（如 8x16），但由于缺失像素的干扰，从视觉上看不出长轴方向上两半是否相同。生成约束：底层的真实图案是一个 8x8（或等尺寸）瓦片沿长轴复制一次得到的 8x16 网格；缺失像素在两半中的位置不同，使得两半在补全前看起来不一样；存在唯一的非零平移向量使得所有可见像素一致。

**规则**：
1. 在所有非零平移向量中，找到使得重叠区域内可见像素对（两端都非黑(0)）全部颜色一致、且这样的一致对数量最多的向量。
2. 用该向量及其逆向量传播颜色：对每个黑(0)像素，若沿该向量（或逆向量）偏移后的位置有非黑颜色，则用该颜色填充当前黑(0)像素。重复传播直到所有可填充的黑(0)像素都被填满。
3. 补全后，检查网格是否沿某一轴可分为两个完全相同的半部（上下或左右）。找到唯一的这样的轴。
4. 输出该轴上的前半部（上半或左半）。

**关键洞察**：缺失像素的分布故意使得两半看起来不同——如果直接比较上下（或左右）半部会发现大量不匹配。周期补全是发现隐藏的轴向对称性的必要前提步骤。补全本身不是目的，而是揭示瓦片结构的工具。
