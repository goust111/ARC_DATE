## 新题 6：堆叠掩码交集选择需要恢复周期图案的区域

**组合逻辑**：[压缩/compress](创新：逐格比较的结果不是最终输出，而是选择掩码) → [补全/complete](创新：周期恢复不是全局应用，而是只在交集选出的区域执行) ← [逐格比较/cell_comparison] 产生的交集掩码控制 [被遮挡/occluded] 区域的恢复范围

**依赖链**：上下两半各有周期图案被不同矩形遮挡 → 逐格比较找出"双重遮挡"位置（两半都被遮挡的位置）→ 从两半中未被遮挡的像素推断周期瓦片 → 仅在双重遮挡位置恢复周期图案，其他位置保持上半部内容不变。两半互为信息来源：比较操作需要两半，周期推断从两半的可见部分共同获取约束。

将上下堆叠的两半逐格比较，找出两半都被矩形遮挡的位置，然后仅在这些双重遮挡位置恢复出被隐藏的周期背景图案。

**输入结构**：约 20x12 的网格，上下等分为两个 10x12 的半区。每个半区包含一个由 2x2 或 3x3 最小瓦片周期铺成的背景图案（两半的周期图案相同，颜色使用蓝(1)和黄(4)的交替模式）。每个半区上叠加了 2~3 个纯色矩形遮挡物（遮挡物颜色为红(2)、绿(3)或灰(5)，每个遮挡物为实心矩形，约 2x3 至 4x5 大小）。关键特征：上半区和下半区的遮挡物位置不同，但存在部分空间重叠——即某些像素在上半区和下半区都被遮挡物覆盖。生成约束：两半的未被遮挡区域合在一起足以唯一确定周期瓦片；至少有一个位置是双重遮挡的。

**规则**：
1. 将网格水平等分为上半区和下半区（行数相等）。
2. 逐格比较上下两半对应位置的像素：
   - 若上半区该位置为遮挡物颜色（红(2)/绿(3)/灰(5)中的一种，且属于一个实心矩形连通块）且下半区对应位置也为遮挡物颜色 → 标记为"双重遮挡"。
   - 判断遮挡物的方法：找到每个半区中所有 4-连通的非周期色单色块，其边界框为实心填充矩形且两个维度均 > 1 的即为遮挡物。
3. 从两个半区中所有非遮挡位置的像素收集可见周期数据，推断最小重复瓦片（行周期和列周期最小的矩形，使得所有可见像素与瓦片一致）。
4. 输出一个与单个半区同尺寸的网格：
   - 双重遮挡位置：用周期瓦片恢复该位置应有的颜色。
   - 所有其他位置：复制上半区对应像素（无论是图案色还是遮挡物色）。

**关键洞察**：下半区不出现在输出中——它的唯一作用是与上半区交叉比较以标定"双重遮挡区"。只看上半区无法知道哪些遮挡区需要恢复；只看下半区无法知道输出内容。两半是对称的信息源但角色不同：一个提供输出框架，另一个提供选择掩码。
