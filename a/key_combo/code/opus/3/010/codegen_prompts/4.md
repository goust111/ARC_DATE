## 新题 4：格子奇偶与边缘内部的双重分类决定四种单元格处理

**组合逻辑**：[印章覆盖/stamp_overlay](已有) + [重涂色/recolor](创新：重涂色规则不是单一分类，而是两个独立分类的笛卡尔积) ← [同奇偶格接收副本/same_parity_receive_copy] x [边缘与内部区分/perimeter_interior_distinction] 构成 2x2 决策矩阵

**来源原语**：印章覆盖(92e50de0), 重涂色(8a371977), 同奇偶格接收副本(92e50de0), 边缘与内部区分(8a371977), 格子结构(8a371977), 单元格阵列(92e50de0), 种子图案(92e50de0)

**依赖链**：格子将网格分成单元格阵列 → 种子图案的位置确定"同奇偶"类别 → 单元格的阵列行列坐标确定"边缘/内部"类别 → 两个类别的组合（2x2 矩阵）决定四种不同处理方式。删除任一分类维度，四种处理退化为两种，无法解释所有示例。

在格子单元格阵列中，用奇偶性和边缘/内部位置两个独立维度的交叉来决定每个单元格的处理方式：同奇偶内部格印章种子图案，异奇偶内部格填红色，同奇偶边缘格填绿色，异奇偶边缘格保持原色。

**输入结构**：约 23x23 的网格。橙(7)色格子线（1 像素宽）将网格分成至少 5 行 x 5 列的单元格阵列，每个单元格约 3x3 至 4x4 像素。所有单元格初始填充为灰(5)。其中一个非边缘单元格内包含一个多色种子图案（使用蓝(1)和黄(4)两种颜色，2~4 像素，4-连通，位于该单元格内部，其余像素为灰(5)），该单元格的阵列行索引和列索引的奇偶性确定"种子奇偶类"。生成约束：单元格阵列至少 5x5 以确保有足够的内部格和边缘格；种子图案足够小以完全容纳在最小单元格内。

**规则**：
1. 识别橙(7)格子线和它们围成的单元格阵列。按从上到下、从左到右对单元格编行列索引（从 0 开始）。
2. 定位包含种子图案的单元格，记录其阵列坐标 (r_s, c_s)。种子奇偶类定义为 (r_s mod 2, c_s mod 2)。
3. 对每个单元格，判断两个独立属性：
   - 奇偶匹配：该单元格的 (row mod 2, col mod 2) 是否等于种子奇偶类。
   - 位置类型：该单元格的行索引或列索引是否位于阵列边缘（第 0 行、最末行、第 0 列、最末列）——是则为"边缘格"，否则为"内部格"。
4. 四种处理：
   - 同奇偶 + 内部格：将种子图案的像素（相对于种子单元格左上角的偏移）印章到该单元格，其余像素保持灰(5)。
   - 异奇偶 + 内部格：整格填充为红(2)。
   - 同奇偶 + 边缘格：整格填充为绿(3)。
   - 异奇偶 + 边缘格：保持灰(5)不变。
5. 种子单元格自身保留其原始图案不变。橙(7)格子线保持不变。

**关键洞察**：仅观察边缘格会以为规则是"边缘绿色或灰色交替"；仅观察内部格会以为规则是"内部印章或红色交替"。只有同时考虑两个维度的交叉，才能解释所有单元格的处理方式——这一 2x2 决策矩阵需要对比多个示例中不同位置的种子格才能归纳。
