## 新题 8：方位编码旋转与目标区域平铺

**组合逻辑**：[定位(locate) / 相对方位(relative_position)](创新：方位信息不选择目标内的槽位，而是编码旋转角度) → [旋转(rotate)](创新：旋转角度由空间方位隐式编码，而非显式标注) → [平铺(tiling)](创新：平铺的单元不是原始输入，而是经旋转变换后的图形)

**来源原语**：控制像素(control_pixel)/相对方位(relative_position)/方位决定槽位(position_selects_slot) ← 18286ef8；旋转(rotate)/交替旋转换色(alt_rotate_recolor) ← fd4b2b02；平铺(tiling)/周期瓦片(periodic_tile) ← f823c43c；边框(border)/保留边框填内部(keep_border_fill_in) ← e88171ec

**依赖链**：必须先判定控制像素相对于精灵体的方位（上/右/下/左），由此确定旋转角度；旋转后的精灵体才是平铺的单元；平铺的目标区域（红色边框内部）是独立于精灵体和控制像素的第三个元素。三者缺一不可：没有方位无法确定角度，没有旋转无法确定瓦片，没有目标区域无法确定平铺范围。

由控制像素相对精灵体的方位决定旋转角度，将旋转后的精灵体作为瓦片周期性平铺到红色边框内部。

**输入结构**：约 15x15 的网格，黑(0)背景。网格中有三类元素：(a) 一个由蓝(1)像素组成的小型非正方形 4-连通精灵体（3-6 像素，宽高不等以使旋转可见），位于网格某处；(b) 一个灰(5)单像素控制点，位于精灵体附近（不与精灵体邻接，但在精灵体包围盒外 1-3 格范围内）；(c) 一个由红(2)像素构成的 1 像素宽空心矩形边框，位于网格另一处，内部尺寸至少 5x5。精灵体和控制点不与红色边框重叠。不同示例中精灵体形状、控制点方位和边框位置/大小均不同。生成约束：控制点相对精灵体包围盒中心的偏移在水平和垂直方向上不等大（有明确的主方向）。

**规则**：
1. 计算灰(5)控制像素相对于蓝(1)精灵体包围盒中心的方位：
   - 若控制点在中心正上方（或偏移量中垂直分量为负且绝对值大于水平分量）：旋转 0 度（不旋转）
   - 若控制点在中心正右方（或偏移量中水平分量为正且绝对值大于垂直分量）：顺时针旋转 90 度
   - 若控制点在中心正下方（或偏移量中垂直分量为正且绝对值大于水平分量）：顺时针旋转 180 度
   - 若控制点在中心正左方（或偏移量中水平分量为负且绝对值大于垂直分量）：顺时针旋转 270 度
2. 将精灵体绕其包围盒中心旋转上述角度，得到旋转后的瓦片图案（保持蓝(1)色）
3. 找到红(2)边框矩形，确定其严格内部区域
4. 从内部区域的左上角开始，将旋转后的瓦片按行优先周期性平铺填满内部区域：
   - 瓦片包围盒按网格排列，行间距 = 瓦片高度，列间距 = 瓦片宽度
   - 超出内部区域右边界或下边界的瓦片做裁剪（仅绘制落在内部的部分）
5. 擦除原始精灵体和控制像素为黑(0)
6. 红(2)边框保持不变

**关键洞察**：控制像素既不移动也不改变任何对象的颜色——它通过自身的空间方位隐式编码了一个旋转角度。这个角度应用于精灵体后产生的旋转版本才是平铺的基本单元，而平铺的目标区域又是一个完全独立的结构。网格中三个功能区域（源形状、控制信号、目标容器）的协同才能确定输出。
