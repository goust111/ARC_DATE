## 新题 5：最大矩形锚定对称轴与标记穿透填充

**组合逻辑**：[定位(locate) / 最大实心矩形(largest_solid_rect)](创新：矩形不是被填充的目标，而是为其他操作定义参考系) → [对称补全(symmetry_complete) / 双轴对称(biaxial_symmetry)](创新：对称轴由矩形中心决定，不由输入中的显式十字线定义) → [填充(fill) / 保留边框填内部(keep_border_fill_in)](创新：填充必须避开对称补全后的标记像素)

**来源原语**：最大实心矩形(largest_solid_rect)/边框(border)/保留边框填内部(keep_border_fill_in)/忽略干扰项(ignore_distractors) ← e88171ec；对称补全(symmetry_complete)/稀疏标记(sparse_marker)/双轴对称(biaxial_symmetry)/四象限镜像填充(quadrant_mirror) ← 60d73be6；填充(fill) ← 37ce87bb

**依赖链**：必须先找到最大矩形（定位）来确定对称轴中心；有了轴才能做标记的双轴对称补全；补全后的标记位置影响了填充的结果（标记处不填），三步形成不可跳过的链。矩形的角色从"被操作对象"变为"元信息提供者"，这是源题中不存在的结构关系。

找到最大灰色矩形以其中心为对称轴，将散布的彩色标记做双轴反射补全，最后用青色填充矩形内部但保留标记像素不被覆盖。

**输入结构**：约 15x15 的网格，黑(0)背景。网格中有一个较大的实心灰(5)矩形（至少 5x5，边长为奇数以保证中心点唯一），位置不固定。网格中散布着若干单像素的彩色标记点（红(2)、蓝(1)、绿(3)），有些在矩形内部，有些在矩形外部。标记点不位于矩形的边框像素上。标记点的分布不对称。不同示例中矩形的大小和位置不同，标记点的颜色、数量和位置也不同。生成约束：矩形是网格中唯一的最大实心同色矩形（无歧义）；矩形边长为奇数；标记点不位于矩形中心的水平和垂直轴线上（避免反射到自身）。

**规则**：
1. 找到网格中面积最大的实心灰(5)矩形
2. 计算该矩形的中心点坐标 (cr, cc)，以此定义水平对称轴（行=cr）和垂直对称轴（列=cc）
3. 对网格中每个彩色标记像素（非黑非灰），执行双轴反射：
   - 关于水平轴反射：(r, c) → (2*cr - r, c)
   - 关于垂直轴反射：(r, c) → (r, 2*cc - c)
   - 关于两轴同时反射：(r, c) → (2*cr - r, 2*cc - c)
   - 每个反射位置放置与原标记相同颜色的像素
   - 落在网格外的反射位置丢弃
4. 保留灰(5)矩形的 1 像素宽边框不变
5. 将矩形严格内部（不含边框）的所有非标记像素填充为青(8)
   - 已有的原始标记和反射生成的标记保留其颜色，不被青色覆盖
6. 矩形外部的标记和反射标记保持原色，矩形外部的黑色背景不变

**关键洞察**：最大矩形本身不是变换的对象——它提供对称轴的位置。对称轴不是输入中画出的显式线条，而是从矩形几何隐含推导的。这意味着在不同示例中矩形位置不同，对称轴也随之移动，必须对比多个示例才能发现"轴随矩形走"的规则。
