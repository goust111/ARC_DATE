## 新题 5：L 形投影构建滑动障碍

**组合逻辑**：[射线延伸/ray_extend](已有，投射到最近边界形成L形) + [滑动/sliding](已有，像素向标记压缩) → 投影线构成障碍物改变滑动终点

**来源原语**：射线延伸(705a3229)、投射到最近边界(705a3229)、标记像素(705a3229, ae3edfdc)、滑动(ae3edfdc)、行列对齐(ae3edfdc)、压缩到标记旁(ae3edfdc)、孤立像素(ae3edfdc, 705a3229)

**依赖链**：橙色投影器发射L形射线 → L形射线覆盖部分网格形成屏障 → 蓝色滑动器沿行/列向红色目标移动时遇到屏障则停止。投影步骤的几何输出直接改变滑动步骤的终止条件——不执行投影则滑动结果错误，不执行滑动则投影无功能意义。

先将橙色标记投射为朝最近两条边的 L 形射线墙，再将蓝色像素沿行/列向红色目标滑动，遇射线墙则提前停止。

**输入结构**：黑(0)背景网格，约 14x14。网格中有 2~3 个橙(7)孤立像素（投影器），每个投影器距一条水平边和一条垂直边更近（无中点平局）。另有 2~4 个蓝(1)孤立像素（滑动器），每个滑动器与恰好一个红(2)孤立像素（目标）共享同一行或同一列。滑动器和目标之间的路径上无其他前景像素（在投影前）。生成约束：至少有一个滑动器的滑动路径会被某条 L 形射线横穿；至少有一个滑动器的路径不被任何射线横穿（以便对比）。投影器不与任何滑动器或目标共行/列。

**规则**：
1. **投影阶段**：对每个橙(7)像素，沿其所在列向较近的水平边界（上或下）画橙(7)线，同时沿其所在行向较近的垂直边界（左或右）画橙(7)线。仅覆盖黑(0)像素。若两条边界等距，则选上方/左方（但生成时保证不出现等距）。
2. **滑动阶段**：对每个蓝(1)像素，找到与其共行或共列的唯一红(2)目标。沿蓝→红方向逐格移动：
   - 若下一格为黑(0)或已是蓝(1)，继续移动。
   - 若下一格为橙(7)射线像素，停止在当前格（不进入橙像素）。
   - 若下一格为红(2)目标像素，停止在当前格（紧邻目标，不覆盖目标）。
3. 将蓝像素从原位擦除（变黑(0)），在停止位置涂蓝(1)。
4. 红(2)目标像素和橙(7)投影像素均保留不变。
5. 滑动器按其初始位置从上到下、从左到右的顺序处理。已移动的蓝像素视为前景，阻挡后续蓝像素（后续蓝像素遇到已到位的蓝像素时停在其前一格）。

**关键洞察**：L 形投影必须先于滑动执行，因为投影线构成了影响滑动终点的屏障。被屏障截停的滑动器与未被截停的滑动器在输出中位置差异显著——需要对比两种情况的示例才能发现屏障的截停作用，而非误以为所有滑动器都到达目标旁。
