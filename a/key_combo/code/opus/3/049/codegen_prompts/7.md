## 新题 7：主对角线转置揭示行组前缀模式以进行外推补全

**组合逻辑**：[镜像(沿主对角线转置)/diag_transpose](揭示隐藏的行组结构) → [前缀匹配/prefix_matching](识别下方行组为上方完整模式的前缀) → [外推/extrapolate](用蓝色续写缺失部分) → [镜像(逆转置)/diag_transpose](将结果转回原始方向)

**来源原语**：镜像/沿主对角线转置（参考题 74dd1130）；前缀匹配、外推、行组、列状态序列、完整模式续写缺失（参考题 90f3ed37）；补全（参考题 90f3ed37）

**依赖链**：原始方向上行组看不出前缀关系（模式在列方向上呈现，而非行方向）→ 转置后行列互换，前缀匹配模式才变得可见 → 在转置空间中完成外推 → 逆转置还原。跳过转置则无法发现前缀规律，跳过逆转置则输出方向错误

[输入的行组前缀模式隐藏在列方向中，需先沿主对角线转置使其变为行方向，完成外推补全后再转置回去]

**输入结构**：一个 N x N 的正方形网格（N 约 12~15），黑(0)为背景。
- 网格中有若干由黄(4)像素组成的前景图案。
- 直接观察行（水平方向）：各行的黄(4)像素分布看不出明显的前缀/续写关系。
- 但若将网格沿主对角线转置（行列互换），则转置后的网格呈现出如下结构：
  - 转置后的各列由黑(0)背景行分隔为若干行组。
  - 最上方的行组横跨所有列，形成完整的列状态参考模式（每列或有前景或无前景，构成一个二值序列）。
  - 下方的行组从左列开始，是上方完整模式的逐渐缩短的前缀（即只覆盖前若干列，右侧列缺失）。
- 生成约束：转置后的行组分隔行全为黑(0)；每个下方行组的列状态序列是上方完整行组的一个严格前缀（压缩后的列状态序列一致）。

**规则**：
1. 将整个 N x N 网格沿主对角线转置：像素 (r, c) 移动到 (c, r)。
2. 在转置后的网格中，识别由全黑(0)行分隔的行组。最上方行组为完整参考模式 P。
3. 对每个下方行组，其已有的列状态序列是 P 的前缀。将 P 中剩余的列状态用蓝(1)续写到该行组中：对缺失的每一列，若 P 在该列有前景则填蓝(1)，否则留黑(0)。保留行组中原有的黄(4)像素不变。
4. 将补全后的转置网格再次沿主对角线转置（即逆转置），恢复原始方向。
5. 输出为逆转置后的 N x N 网格。

**关键洞察**：前缀续写模式藏在网格的列方向中——直接读行看到的是无规律的图案。求解者必须先发现转置操作（通过对比多个示例中行读与列读的规律性差异），在转置空间中完成补全，再转置回来。单个示例中无法区分"按行读"和"按列读"两种假说，必须对比多个示例。
