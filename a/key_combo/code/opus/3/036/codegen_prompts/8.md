## 新题 8：压缩色格的颜色计数匹配内腔填充

**组合逻辑**：[筛选·最小尺寸过滤 + 压缩·包围盒行列分组](已有) → [计数](创新：计数对象从前景像素改为压缩色格中的同色单元) → [面积匹配·像素数等于腔面积](创新：匹配的一端来自压缩结果) → [填充](已有)

**来源原语**：筛选/最小尺寸过滤/忽略干扰项/填充矩形/包围盒行列分组/压缩(0a1d4ef5), 计数/填充/擦除/轮廓对象/行内腔/面积匹配/像素数等于腔面积(7acdf6d3)

**依赖链**：压缩步骤将散落的矩形格子聚合为紧凑色格，色格中每种颜色的单元数成为后续匹配的关键参数；轮廓内腔面积与色格颜色计数匹配才决定填充目标和颜色。删除压缩则无法得到颜色计数，删除面积匹配则无法确定哪个内腔填充哪种颜色。

先将大矩形格子（过滤干扰后）压缩为紧凑色格，再统计色格中每种颜色出现的次数，将次数与各轮廓对象的内腔面积配对，匹配成功的内腔填充为对应颜色。

**输入结构**：黑(0)背景，约 22x22 网格。分为两个区域（上半区和下半区，或左半区和右半区）。一个区域包含若干单色填充矩形（每个至少 3x3），排列成行列格子，其中穿插一些小于 3x3 的零散干扰像素。填充矩形使用 3~4 种颜色（如蓝(1)、绿(3)、黄(4)、橙(7)），排列为 2x3 或 3x3 格子。另一区域包含若干不同颜色（灰(5)或品红(6)）的 8-连通轮廓框（闭合边界），各框的行内腔面积互不相同。生成约束：压缩色格中每种颜色的出现次数恰好与某一个轮廓框的内腔面积相等，且这种匹配是一一对应的（无歧义）。干扰像素的颜色可以与矩形颜色相同，但尺寸小于 3x3 且不能恰好填满其包围盒。

**规则**：
1. 在矩形区域中，保留所有至少 3x3 且恰好填满其包围盒的单色 4-连通矩形，移除其余像素（干扰）。
2. 将保留的矩形按包围盒的行区间和列区间分组，相同行区间归为同一输出行，相同列区间归为同一输出列，形成紧凑的 M x N 色格。
3. 统计色格中每种颜色出现的单元数：color_count(c) = 色格中颜色 c 的单元数。
4. 在轮廓区域中，识别所有 8-连通轮廓框，计算每个框的行内腔面积 A（每行中最左与最右轮廓像素之间的非轮廓像素数之和）。
5. 对每种颜色 c，若存在唯一一个轮廓框的 A = color_count(c)，则将该框的行内腔全部填充为颜色 c。
6. 无法匹配的轮廓框保持不变。

**关键洞察**：填充颜色不是由轮廓框自身的属性决定的，而是由远处的矩形格子压缩后的颜色统计决定的——两个空间上分离的结构通过数值匹配产生了跨区域的信息传递。
