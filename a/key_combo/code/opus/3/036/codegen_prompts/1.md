## 新题 1：对角射线命中计数选腔

**组合逻辑**：[射线延伸·对角线激活](创新：从源像素出发沿对角方向射线) → [计数](创新：统计射线穿过各轮廓内腔的命中数) → [面积匹配→命中匹配](创新：选择标准从面积相等改为命中数相等) → [填充 + 擦除]

**来源原语**：射线延伸/对角线激活(d07ae81c), 计数(7acdf6d3/d631b094), 轮廓对象/行内腔/面积匹配(7acdf6d3), 填充/擦除(7acdf6d3)

**依赖链**：对角射线路径决定了哪些轮廓内腔被命中，命中计数提供了选择目标轮廓的判据（替代原始的面积匹配），被选中的轮廓才执行填充。删除射线步骤则无法确定目标轮廓，删除计数则退化为无选择标准的填充。

将源像素群的对角射线穿透各轮廓内腔，以命中总数等于源像素数量为条件锁定唯一目标轮廓，擦除源像素并将目标内腔涂为源色。

**输入结构**：黑(0)背景，约 20x20 网格。网格中有 3~5 个不同颜色的 8-连通轮廓对象（如蓝(1)、绿(3)、橙(7)的闭合框），每个轮廓是单色的闭合边界，内部为黑(0)背景像素，各轮廓的行内腔面积互不相同（约 3~12 像素）。另有一簇红(2)源像素（3~8 像素的 4-连通小图形），位于所有轮廓之外，与任何轮廓不相邻。生成约束：恰好一个轮廓的内腔被源像素的全部对角射线命中的次数等于源像素总数，其余轮廓的命中数均不等于源像素总数。

**规则**：
1. 识别所有 8-连通单色轮廓对象及其行内腔（每行中最左与最右轮廓像素之间的背景像素）。
2. 识别红(2)源像素集合，记录其总数 N。
3. 从每个红(2)源像素出发，沿四条对角方向（NE、NW、SE、SW）向网格边界延伸射线，射线仅用于计数，不改变任何像素颜色。
4. 对每个轮廓对象，统计其行内腔中被对角射线经过的像素总次数（同一像素被多条射线经过则累加计数）。
5. 选出行内腔命中总次数恰好等于 N 的唯一轮廓作为目标。
6. 将所有红(2)源像素擦除为黑(0)。
7. 将目标轮廓的行内腔全部填充为红(2)。

**关键洞察**：目标轮廓不是通过面积直接匹配选出的，而是由源像素的空间位置通过对角射线间接编码的——移动源像素群的位置会改变命中模式，从而可能改变目标轮廓。
