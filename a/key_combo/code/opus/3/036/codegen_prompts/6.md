## 新题 6：等差递推的缩放锚点印章

**组合逻辑**：[等差递推](创新：控制的不是边框笔画而是锚点位置和缩放倍率) → [缩放·尺寸比编码缩放](已有) → [印章放置](已有) → [裁剪·画布裁切可见](已有)

**来源原语**：等差递推/等差序列/画布裁切可见(f8c80d96), 缩放/尺寸比编码缩放/锚点方块/图案母题/印章放置(b10624e5)

**依赖链**：等差递推同时决定了新锚点的位置和缩放倍率（两者耦合在同一个递推关系中），缩放倍率决定印章大小，位置决定印章放置处，画布边界决定是否可见。删除等差递推则无法预测新锚点，删除缩放则印章尺寸错误。

从已有的若干不同缩放倍率的母题副本中归纳锚点位置和缩放倍率的等差规律，沿递推方向继续放置新的缩放副本，直到下一个副本完全超出画布。

**输入结构**：黑(0)背景，约 25x25 网格。包含同一母题的 3 份副本，母题是一个约 3x3 像素的非对称单色小图形（如品红(6)）。每份副本附着于一个红(2)实心正方形锚点块，锚点块的边长分别为 1、2、3（或 2、3、4 等连续整数）。母题相对于锚点的位置固定（如始终在锚点的右上方），母题的缩放倍率等于锚点边长与最小锚点边长之比（即 1x、2x、3x）。三个锚点的中心坐标形成等差数列（行坐标差和列坐标差分别恒定）。生成约束：沿等差方向至少还能再放 1 个副本（部分或全部在画布内），但再下一个副本必须完全在画布外。

**规则**：
1. 识别所有红(2)正方形锚点块，按边长从小到大排序，记录其中心坐标序列和边长序列。
2. 验证中心坐标形成等差数列（行差 dr、列差 dc 恒定），边长形成等差数列（公差 ds 恒定，通常 ds=1）。
3. 从最小锚点的副本中提取母题掩模（锚点周围的非背景、非红(2)像素相对于锚点中心的偏移）。
4. 沿等差方向逐步外推：下一个锚点中心 = 最后一个中心 + (dr, dc)，下一个边长 = 最后边长 + ds。
5. 对每个外推位置，按当前边长与最小边长之比缩放母题掩模（最近邻缩放），将缩放后的母题和新锚点绘制到网格上。
6. 仅绘制落在网格内的像素，超出边界的部分裁切。
7. 当某一步的锚点块和缩放母题完全位于网格外时停止。
8. 同方向的反向也检查一次：如果反向外推可以产生边长 >= 1 的锚点且至少部分在画布内，也绘制之。

**关键洞察**：位置递推和尺寸递推共享同一个等差结构，求解者必须同时从空间坐标和锚点大小两个维度归纳出同一条等差规律——单看位置或单看尺寸都无法确定完整的外推参数。
