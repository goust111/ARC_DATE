## 新题 7：尺寸阶梯框架间角标记级联迁移

**组合逻辑**：[平移/translate + 角标记/corner_marker + 内外对角/interior_exterior_diagonal](来自 952a094c，创新：角标记不再在同一框架的内外角之间迁移，而是跨框架按尺寸排序迁移) + [尺寸排序/size_ordering](来自 48634b99) + [擦除/erase](来自 952a094c)

**来源原语**：平移、角标记、内外对角、空心矩形（952a094c）；尺寸排序（48634b99）；擦除（952a094c）

**依赖链**：多个框架 → 按边长排序建立尺寸阶梯 → 找到带角标记的框架 → 该框架角标记的相对位置（左上/右上/左下/右下）被保持 → 标记从当前框架擦除 → 标记出现在尺寸阶梯中下一个更大框架的对应角位置（紧贴外角）。尺寸排序建立了框架间的逻辑邻接关系；角标记位置的保持提供了空间映射规则。两者缺一不可。

多个不同尺寸的矩形框架按边长排序；带角标记的框架将其标记迁移到尺寸阶梯中下一个更大框架的对应外角位置。

**输入结构**：约 18x18 的黑(0)背景网格。网格中有 3~5 个蓝(1)像素构成的单像素宽空心矩形框架，各框架尺寸互不相同（外边长分别为如 3x3、5x5、7x7、9x9 等奇数尺寸），框架之间互不重叠且不相邻。恰好一个框架的四个内角位置（紧贴框架内侧的四个对角像素）有红(2)角标记像素（4 个红像素）。其余框架内部和外部均为黑(0)。生成约束：所有框架均为正方形；框架之间至少间隔 2 个黑像素；带标记的框架不是最大的框架。

**规则**：
1. 识别所有蓝(1)空心矩形框架，计算每个框架的外边长。
2. 按外边长从小到大排序，建立尺寸阶梯序列。
3. 找到带红(2)角标记的框架（源框架），确定其在尺寸阶梯中的位置 i。
4. 找到尺寸阶梯中位置 i+1 的框架（目标框架，即下一个更大的框架）。
5. 将源框架四个内角的红(2)标记擦除为黑(0)。
6. 在目标框架的四个外角位置（紧贴框架外侧的四个对角像素）放置红(2)标记像素。具体位置：目标框架外边界框向外扩展一像素后的四个角点。
7. 所有框架的蓝(1)边框保持不变。

**关键洞察**：框架的空间位置无关紧要——决定标记迁移目标的是尺寸排序而非空间邻近。最小框架的标记可能迁移到空间上距离很远但尺寸恰好大一级的框架。求解者必须先建立尺寸阶梯，再确定迁移方向和目标角位置。
