## 新题 5：缺口列位定位模板印章行

**组合逻辑**：[填充/filling + 条缺口/bar_gap + 列对齐/col_align](来自 cf133acc，创新：缺口不再用于纵向填色，而是标定水平印章位置) + [印章覆盖/stamp_overlay + 多色模板/multicolor_template + 尺寸匹配/size_matching](来自 e76a88a6) + [擦除/erase](来自 952a094c)

**来源原语**：条缺口、列对齐、标记（cf133acc）；印章覆盖、多色模板、尺寸匹配（e76a88a6）；擦除（952a094c）

**依赖链**：水平条中的缺口列位置 → 确定印章的水平放置坐标 → 缺口所在行确定印章的垂直放置坐标 → 模板通过尺寸匹配选定 → 模板被印到每个缺口位置 → 原始水平条和缺口被擦除。缺口位置编码了印章坐标这一信息，是两步操作的桥梁。

水平彩色条中的一像素缺口标定了多色模板的印章放置位置；每个缺口处印上尺寸匹配的模板副本，原始条被擦除。

**输入结构**：约 15x20 的黑(0)背景网格。网格上半区有 3~5 条水平彩色条（每条为同一种非黑颜色，从蓝(1)、红(2)、绿(3)、黄(4)中选取，不同条颜色可相同或不同），每条宽 1 像素、横跨大部分列，各条位于不同行且行间距至少为 4。每条水平条恰好有 1 个一像素缺口（该位置为黑(0)）。网格下半区有一个多色模板（一个 3x3 的由多种非黑颜色构成的连通图案，不含黑(0)像素）。模板与水平条不接触。生成约束：所有缺口的列位置互不相同；模板尺寸为 3x3；每个缺口位置周围 3x3 范围内不与其他水平条重叠（即印章放置后不会与其他条冲突）。

**规则**：
1. 识别所有水平条及其缺口位置。每个缺口定义一个锚点 (gap_row, gap_col)。
2. 识别下半区的 3x3 多色模板，裁剪提取。
3. 对每个缺口锚点，将模板副本以锚点为中心放置（模板中心对齐缺口位置），即模板占据 (gap_row-1, gap_col-1) 到 (gap_row+1, gap_col+1) 的 3x3 区域。仅覆盖黑(0)背景像素；若模板某像素落在非背景位置（如另一条水平条上），该像素不被覆盖（保留原有非背景色）。
4. 放置顺序按缺口行从上到下依次处理。
5. 擦除所有原始水平条像素（将其涂为黑(0)），但已被模板覆盖的位置保留模板颜色。
6. 擦除原始模板所在位置（将其涂为黑(0)）。

**关键洞察**：水平条本身不出现在输出中——它们的唯一作用是通过缺口位置编码印章坐标。缺口从"需要填充的空洞"（源题 cf133acc 的语义）被重新解读为"放置目标的定位标记"，与模板印章形成全新的结构关系。
