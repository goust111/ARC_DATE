## 新题 2：格子单元对称分级涂色

**组合逻辑**：[镜像/对称检测](创新：不是对整图做镜像变换，而是对每个格子单元独立做对称性测试作为分类依据) + [重涂色](创新：同一格子内部根据逐像素对称匹配结果做差异化涂色) + [格子单元分区] + [交集差集分别着色]

**来源原语**：镜像/mirror(参考题 a8610ef7)，重涂色/recolor(参考题 a8610ef7, 94f9d214)，填充/fill(参考题 e760a62e)，格子单元/lattice_cell(参考题 e760a62e)，网格线/lattice_line(参考题 e760a62e)，反射对称/reflection_symmetry(参考题 a8610ef7)，逐像素比较/per_pixel_comparison(参考题 94f9d214)，交集差集分别着色/intersection_diff_colored(参考题 a8610ef7)

**依赖链**：青(8)网格线将画布分割为格子单元→每个单元内的前景图案被独立提取→对每个图案做左右反射对称测试→测试结果决定涂色方案（完全对称→整体涂绿；不完全对称→对称匹配的像素涂蓝、不匹配的像素涂红）。网格分割定义了测试边界，对称测试定义了分类，分类决定了涂色方案——三者形成不可跳步的推理链。

在青(8)网格线划分的每个格子单元中，对前景图案做左右对称测试：完全对称的单元前景涂绿(3)，不对称的单元中对称匹配像素涂蓝(1)、不匹配像素涂红(2)。

**输入结构**：约 13x13 的黑(0)背景网格。青(8)的单像素宽网格线将画布分为 3x3 或 4x4 的等大矩形格子单元（每个单元内部约 3x3 像素）。每个格子单元内部有若干橙(7)前景像素组成的小图案（1~6 个像素的 4-连通或散布图案）。不同单元中的图案形状各异：部分具有左右反射对称性，部分不具有。至少有一个单元无前景像素（全黑）。生成约束：每个单元内部尺寸为奇数列宽（如 3 或 5），以保证左右对称轴为整数列。

**规则**：
1. 识别青(8)网格线，确定所有格子单元的边界。青(8)网格线在输出中保持不变。
2. 对每个格子单元，提取其内部的前景像素图案（忽略网格线像素）。
3. 若该单元内无前景像素，保持全黑(0)不变。
4. 对有前景像素的单元，以该单元内部的垂直中轴为对称轴，做左右反射对称测试：将每个前景像素 (r, c) 映射到 (r, c_mirror)，其中 c_mirror = 单元左边界 + 单元宽度 - 1 - (c - 单元左边界)。
5. 若单元内所有前景像素都有对应的反射像素（即图案完全左右对称），则将该单元内所有前景像素重涂为绿(3)。
6. 若图案不完全对称：对于每个前景像素，若其反射位置也是前景像素，则该像素重涂为蓝(1)；若其反射位置不是前景像素，则该像素重涂为红(2)。
7. 背景像素保持黑(0)。

**关键洞察**：完全对称与不完全对称采用不同的涂色方案（统一绿色 vs. 蓝红分离），这一分支规则需要在同一示例中同时看到两种情况、或对比多个示例才能归纳出来。

    sigs.add(hashlib.md5(inp.tobytes() + str(inp.shape).encode()).hexdigest())
print("variants", len(sigs))
assert len(sigs) >= 20
