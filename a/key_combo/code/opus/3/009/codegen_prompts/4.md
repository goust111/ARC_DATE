## 新题 4：带边框反弹的面板序列外推

**组合逻辑**：[序列外推](创新：外推不再是简单平移延续，而受边框几何条件修改) + [镜像](创新：不作用于图案本身，而作用于运动矢量的分量) + [缺口决定方向](创新：缺口不决定滑动方向，而决定哪个方向不反弹)

**来源原语**：序列外推(351d6448)、面板帧(351d6448)、恒定偏移平移(351d6448)、镜像(93c31fbe)、缺口决定方向(320afe60)、边框缺口(320afe60)

**依赖链**：前四帧确定恒定偏移矢量 → 第五帧的目标位置由外推得到 → 边框几何（哪些边封闭、哪条边有缺口）决定是否发生反弹 → 反弹修改目标位置和/或精灵朝向。外推提供初始预测，边框提供边界条件，两者联合才能得到正确的第五帧。

从四帧动画序列中外推下一帧，但精灵体遇到封闭边框会反弹，通过缺口则自由通过。

**输入结构**：约 9x35 的竖长网格。由 4 个等高（约 9x9）面板上下堆叠，面板之间由单行灰(5)分隔行隔开。每个面板内部：黑(0)背景，沿 3 条边各有一行蓝(1)像素构成的边框（第 4 条边无边框，即"缺口"），以及 1 个小的红(2)精灵体（2x2 的 4-连通小图形）位于面板内部。四帧中的边框形状完全相同（缺口始终在同一条边）。精灵体在四帧之间以恒定偏移 (dr, dc) 平移。生成约束：精灵体在前四帧中均未接触任何边框像素；但按恒定偏移继续平移时，精灵体在第五帧会碰到某条封闭边框边。

**规则**：
1. 识别四个面板及其分隔行。提取每帧中精灵体的位置（以精灵体包围盒左上角在面板内的坐标表示）。
2. 计算相邻帧之间的恒定偏移量 (dr, dc)。验证三个间隔的偏移一致。
3. 将偏移量施加于第四帧精灵体位置，得到第五帧的"候选位置"。
4. 检查候选位置是否导致精灵体的任何像素落在封闭边框上或超出封闭边框之外：
   - 若碰到上方或下方封闭边框：将 dr 取反（反弹），重新计算精灵体行坐标为边框内侧行 +/- 溢出距离的镜像值。
   - 若碰到左方或右方封闭边框：将 dc 取反（反弹），重新计算精灵体列坐标为边框内侧列 +/- 溢出距离的镜像值。
   - 若碰到缺口方向的边界：精灵体自由通过，不反弹，直接截断超出面板范围的部分（保留面板内的像素）。
5. 输出为单个面板大小的网格，包含第四帧的边框布局和反弹/通过后的精灵体。

**关键洞察**：仅凭前四帧的恒定平移可以外推出一个候选位置，但这个候选位置是错的——边框结构修改了运动规则。缺口决定哪个方向"不设防"，封闭边则触发反弹。求解者必须同时理解运动模式和边界条件。
