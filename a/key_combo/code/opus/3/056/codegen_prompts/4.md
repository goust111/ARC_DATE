## 新题 4：对称补全揭示重涂色目标

**组合逻辑**：[symmetric_complete](已有) + [recolor](已有) + [marker_identifies_window](创新：窗口资格取决于补全操作的结果而非原始输入) + [max_marker_no_overlap](已有)

**来源原语**：symmetric_complete, tab, notch, boundary, opposite_side_complement, cross_span_projection（来自 8dab14c2）；recolor, solid_window, marker_pixel, center_pixel, marker_identifies_window, max_marker_no_overlap（来自 9caba7c3）

**依赖链**：边界缺口补全 -> 填入的前景像素使原本不完整的 3x3 区域变为实心窗口 -> 新窗口中包含红色标记像素 -> 对最大标记集窗口执行重涂色。删除补全步骤则窗口不完整不符合重涂色条件；删除重涂色步骤则补全只是几何修复无进一步意义。

先对前景对象的边界做对称补全（填缺口、补凸起），补全后新出现的实心 3x3 窗口成为重涂色目标。

**输入结构**：约 14x14 的网格，黑(0)背景。一个厚实的直角多边形灰(5)前景对象（约 8x10 像素范围，内部填实）。边界上有 2-3 个单像素凸起（tab：仅有一个前景4-邻居的边界前景像素）和 2-3 个单像素缺口（notch：有三个前景4-邻居的黑色背景像素）。前景内部嵌有若干红(2)标记像素。某些包含红(2)标记像素的 3x3 区域在当前输入中并非全部为前景——因为该区域边界上的缺口使得 3x3 中有一个黑色像素。生成约束：每个缺口被填充后恰好使其所在的某个 3x3 区域变为完全前景（9 个像素全为灰或红），且该 3x3 区域包含至少一个红(2)像素且中心为灰(5)；补全后不会出现新的缺口或凸起导致需要迭代。

**规则**：
1. 对称补全边界：对每个凸起（tab），沿其所在行或列投射到前景跨度的对侧边缘，移除对侧边缘像素（创建对称缺口）。对每个缺口（notch），沿其所在行或列投射到对侧边缘外一格，添加前景像素（创建对称凸起）。
2. 补全完成后，扫描所有 3x3 区域，找出满足以下条件的候选窗口：(a) 9 个像素全为前景色（灰(5)或红(2)），(b) 至少包含一个红(2)像素，(c) 中心像素为灰(5)。
3. 若多个候选窗口重叠，比较它们的红(2)像素集合——选取红像素集不是任何其他候选窗口红像素集严格子集的窗口（最大标记集筛选）。
4. 对每个选中的窗口：将灰(5)中心像素重涂为黄(4)，将窗口内其他灰(5)像素重涂为橙(7)。红(2)像素保持不变。
5. 选中窗口之外的所有像素（包括补全操作产生的新前景像素）保持原色不变。

**关键洞察**：在补全之前，标记像素所在的 3x3 区域因缺口存在而不符合"实心窗口"条件。对称补全填入了关键像素，使窗口"亮起"——重涂色目标完全由边界几何变换决定。

## 实现要求

1. `main(grid)` 必须实现新题描述中的确定性转换规则，不能只识别 `generate_input()` 的固定模板。禁止不同的input网格输出相同的output网格。

3. 生成器必须保证输入满足 `main()` 的隐式假设：对象不重叠、不越界、特殊标记唯一或可区分、匹配关系无歧义、关键分支出现概率相同。
4. 禁止把 ARC 颜色 id 、亮度、拼写等当作人类不可见的数值语义参与排序、大小比较或隐藏映射。颜色变化必须有可见结构线索。注意颜色亮度、拼写等也是不可见信息，若描述中出现违规的颜色id或者亮度，可自行使用少量的固定颜色替代，但注意生成时要在三个以内输入输出网格中对所有变换100%覆盖度。
