**组合逻辑**：[提取 + 边框包围中心](已有) → [传输 + 端点配对](创新：传输的不是令牌形状而是提取出的颜色) + [忽略干扰项](已有) + [擦除](已有)

**依赖链**：边框检测定位各框心色 → 线路网络确定框间配对关系 → 配对双方互换框心色 → 干扰像素被擦除。删掉边框检测则不知道传输什么颜色；删掉线路则不知道传输给谁；删掉干扰过滤则输出含噪声。

在散布着干扰像素的网格中，找出由单色边框围住中心像素的多个 3x3 框，沿灰色线路配对连接，互换框心颜色，同时擦除所有干扰像素。

**输入结构**：约 18x18 的网格，背景黑(0)。网格中包含偶数个（2 或 4 个）3x3 的"信号框"：每个信号框的 8 个边界像素是同一种非背景色（框色，从蓝(1)、绿(3)、橙(7) 中选取，不同框的框色可以相同也可以不同），中心像素是另一种非背景、非框色的颜色（从红(2)、黄(4)、品红(6) 中选取）。信号框两两配对，每对之间用灰(5) 的一像素宽正交折线（水平段和垂直段的组合，无分叉）连接，折线的两个端点分别与一对信号框的外侧相邻（4-邻接框边界的某个像素）。网格中另有若干与框色或中心色相同颜色的孤立散布像素作为干扰项（每个干扰像素均不与任何信号框或灰线路 4-邻接）。生成约束：不同配对的灰线路互不相交；干扰像素不形成 3x3 框结构。

**规则**：
1. 识别所有 3x3 信号框（8 个边界像素同色、中心像素异色且非背景的 3x3 窗口）。
2. 沿灰(5) 线路追踪配对关系：从每个信号框外侧出发，沿 4-连通灰像素路径到达另一个信号框，确定配对。
3. 在输出中保留所有信号框的边界像素和灰线路不变。
4. 对每一对配对的信号框 A 和 B：将 A 的中心像素改为 B 的原始中心色，将 B 的中心像素改为 A 的原始中心色（互换）。
5. 将所有不属于信号框和灰线路的非背景像素（即干扰像素）设为黑(0)。

**关键洞察**：散布的同色像素是干扰项而非信号框的组成部分；只有完整 3x3 边框结构才是有效信号框。线路网络定义的是互换关系而非单向传输。
