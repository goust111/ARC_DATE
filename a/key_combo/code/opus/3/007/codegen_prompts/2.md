## 新题 2：形状嵌合路径上的障碍奇偶决定拼块颜色

**组合逻辑**：[形状嵌合(shape_fitting)](已有) → [曼哈顿路径(manhattan_path)](已有) + [障碍段(barrier_segment)](已有) → [路径穿越奇偶数决定颜色翻转](创新：双色互换的奇偶泛化)

**来源原语**：形状嵌合, 互补拼合, 精灵体, 孔洞, 拼块填孔洞后变色 (from 6a1e5592); 障碍段, 障碍门处标记通道 (from fc10701f); 双色互换 (from d511f180); 曼哈顿路径, 折线连接 (from a2fd1cf0)

**依赖链**：形状匹配确定每块拼块的目标孔洞 → L 形移动路径由起终点确定 → 路径上的橙色障碍穿越次数 → 奇偶性决定拼块最终颜色 → 删除形状匹配则目标错误，删除路径追踪则无法确定颜色

将灰色拼块嵌入红色框架的匹配孔洞中；每块拼块沿 L 形路径移动时穿越奇数个障碍则变青色，偶数个则保持灰色。

**输入结构**：约 15x15 的黑(0)背景网格。一个红(2)框架状连通对象，内部包含 3-4 个黑(0)孔洞（每个孔洞 3-6 像素，4-连通，形状各异——可能是不规则的非矩形轮廓）。与红色框架不相连的灰(5)拼块 3-4 个（每块 3-6 像素，4-连通），分布在框架周围，各拼块形状互不相同。每个灰色拼块的形状恰好与某个孔洞的形状匹配（归一化到各自边界框后像素模式一致，一一对应无歧义）。橙(7)单像素散布于红色框架外部（约 3-8 个），不与灰色拼块或红色框架相邻。生成约束：每个拼块到其匹配孔洞的 L 形路径上存在 0-3 个橙色像素，且不同拼块的路径在奇偶性上有差异（不全为奇或全为偶）。

**规则**：

1. 将每个灰(5)拼块的形状归一化到其边界框，与红色框架中各孔洞的归一化形状逐一比较，找到唯一匹配的孔洞。
2. 对每个拼块，构造从拼块边界框中心到匹配孔洞边界框中心的 L 形路径：先从拼块中心列水平移动到孔洞中心列，再从该列垂直移动到孔洞中心行。路径包含起点和终点之间的所有整数坐标点（含起终点）。
3. 统计该 L 形路径经过的所有像素位置中，输入网格上为橙(7)的像素数量 → K。
4. 若 K 为奇数，将该拼块重涂为青(8)；若 K 为偶数（含 0），保持灰(5)不变。
5. 将处理后的拼块平移至其匹配孔洞的位置，像素一一对应填入。原始拼块位置变为背景(0)。
6. 红色框架和所有橙色像素在输出中保持不变。

**关键洞察**：两个拼块即使形状完全相同地匹配到了各自的孔洞，它们的最终颜色也可能不同——因为它们在网格上的空间位置不同，导致各自的 L 形移动路径穿越的障碍数量不同。颜色不由形状决定，也不由绝对位置决定，而由"拼块到孔洞的特定路径上的障碍拓扑"决定。需要对比多个示例（不同的拼块位置和障碍布局导致不同的奇偶结果）才能归纳出这个隐蔽的奇偶规则。
