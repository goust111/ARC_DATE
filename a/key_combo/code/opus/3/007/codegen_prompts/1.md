## 新题 1：图元类型决定射线几何与障碍穿越标记

**组合逻辑**：[分解(decompose)](已有) → [图元形状决定射线几何类型](创新：原为决定涂色，此处决定射线方向类别) → [射线延伸(ray_extend)](已有) → [障碍门处标记(barrier_gate_mark)](已有，原为标记通道，此处标记射线穿越点)

**来源原语**：分解, 基本图元, 图元形状决定涂色 (from 150deff5); 射线延伸, 画布边界 (from 8d510a79, fe9372f3); 障碍段, 障碍门处标记通道 (from fc10701f)

**依赖链**：分解决定图元类型 → 图元类型同时决定涂色和射线方向类别（方块=对角射线, 长条=基数方向射线）→ 射线路径上的障碍位置决定黄色标记 → 所有环节缺一不可

将灰色复合体分解为方块和长条图元，方块从四角发射对角射线、长条从两端发射基数方向射线，射线穿越橙色障碍处变为黄色。

**输入结构**：约 18x18 的黑(0)背景网格。一个或多个由灰(5)像素组成的 4-连通前景区域，每个区域可被唯一分解为若干不重叠的 2x2 方块和 1x3 或 3x1 长条（生成时保证分解唯一，每个连通区域至少含 2 个图元）。若干橙(7)线段（1 像素宽，2-4 像素长，水平或垂直方向），散布于网格中，与灰色区域的任何像素至少间隔 1 个空像素。橙色线段总计约 3-6 段。

**规则**：

1. 将每个灰(5)连通区域分解为不重叠的 2x2 方块和 1x3/3x1 长条。
2. 将每个 2x2 方块的 4 个像素重涂为青(8)；每个长条的 3 个像素重涂为红(2)。
3. 对每个青(8)方块：从其 4 个角像素分别沿远离方块中心的对角方向发射蓝(1)射线（左上角像素向左上延伸，右上角向右上延伸，左下角向左下延伸，右下角向右下延伸），逐像素延伸直至网格边界。
4. 对每个红(2)长条：从其两个端像素分别沿长条长轴方向向外发射蓝(1)射线（水平长条从左端向左、右端向右发射；垂直长条从上端向上、下端向下发射），逐像素延伸直至网格边界。
5. 射线逐像素绘制：若某射线像素恰好落在橙(7)障碍像素上，该位置涂为黄(4)而非蓝(1)，障碍像素被覆盖；射线在该点之后继续延伸为蓝(1)。
6. 若射线像素落在已有的非背景、非障碍像素上（包括图元像素、其他射线像素），该射线在该像素处停止，不覆盖已有像素，也不包含该停止点。
7. 射线绘制顺序：先处理所有方块的射线（方块按边界框左上角坐标从上到下、同行从左到右排序），再处理所有长条的射线（同样排序方式）。同一图元的多条射线方向各异不会相互冲突。

**关键洞察**：分解结果同时决定两件事——图元的颜色（青 vs 红）和射线的几何类别（对角 vs 基数方向），使得错误的分解不仅导致颜色错误，还导致射线方向完全错误。障碍段的黄色标记则证实了射线路径的正确性。单个示例中可能只展示一种图元类型的射线效果，需要对比多个示例才能归纳出"方块=对角，长条=基数"的完整映射。

import numpy as np

p = Path("/home/lixinyu/snap/a/key_combo/code/opus/3/007/1.py")
mod = SourceFileLoader("new_arc_task", str(p)).load_module()
sigs = set()
for i in range(100):
    inp = mod.generate_input()
    out = mod.main(inp)
    assert isinstance(inp, np.ndarray)
    assert isinstance(out, np.ndarray)
    assert inp.ndim == 2 and max(inp.shape) <= 30, f"input grid exceeds 30x30: {inp.shape}"
    assert out.ndim == 2 and max(out.shape) <= 30, f"output grid exceeds 30x30: {out.shape}"
    sigs.add(hashlib.md5(inp.tobytes() + str(inp.shape).encode()).hexdigest())
print("variants", len(sigs))
assert len(sigs) >= 20
