## 新题 1：对称性分流的射线互锁

**组合逻辑**：[对称检测](创新：检测结果不做筛选/裁剪，而是将对象分为射线源与障碍两种角色) + [射线延伸](创新：射线方向由源对象的不对称侧决定，非固定轴) + [重涂色](已有) + [阻挡/射线遇障停止](已有，但障碍身份由对称性测试动态赋予)

**来源原语**：对称检测/symmetry_detect（参考题 73ccf9c2）、唯一非轴对称/unique_asymmetric（参考题 73ccf9c2）、射线延伸/ray_extend（参考题 6ffe8f07）、射线遇障停止/ray_stops_at_block（参考题 6ffe8f07）、重涂色/recolor（参考题 a79310a0, d406998b）、障碍对象/blocker_object（参考题 6ffe8f07）、面积筛选/area_filtering（参考题 a3325580）

**依赖链**：对称检测的结果同时决定两件事——(1) 哪些对象是射线源、哪些是障碍，(2) 每个射线源的发射方向。射线的终点取决于障碍的位置，而障碍身份又取决于对称检测。删除对称检测则无法区分角色；删除射线延伸则无法产生输出变化；删除重涂色则射线无法可见。

输入中散布着若干单色小图形，通过对称性测试将它们分为射线发射源和障碍物两类；每个发射源沿其"重心偏移侧"投射射线，射线遇到障碍物停止并将障碍物重涂为射线源的颜色。

**输入结构**：黑(0)背景，约 18x18 网格。散布 5~7 个互不相邻的单色 4-连通小图形（每个 4~8 像素），每个图形使用不同的非黑颜色（从蓝(1)、红(2)、绿(3)、黄(4)、灰(5)、品红(6)中选取）。其中部分图形在其紧凑边界框内具有左右镜像对称性，其余图形不具有左右镜像对称性。对称与不对称图形的数量在不同示例中不同（但保证至少各有 1 个）。所有图形的紧凑边界框互不重叠，且任意两个图形之间在水平或垂直方向上至少间隔 2 个空像素。生成约束：不对称图形的"重心偏移侧"指向的方向上必须存在至少一个对称图形，使得每条射线都能命中一个障碍。

**规则**：
1. 对每个前景图形，提取其紧凑边界框内的前景掩码，测试该掩码是否与其左右镜像完全一致。
2. 左右镜像对称的图形标记为"障碍"；不对称的图形标记为"射线源"。
3. 对每个射线源，计算其前景像素在紧凑边界框内的质心列坐标 c_mass 与边界框中心列坐标 c_center 的关系：若 c_mass > c_center，则"重心偏移侧"为右；若 c_mass < c_center，则为左；若相等，则为上（即沿列方向向上投射，此为 tie-break 规则）。
4. 从射线源边界框的偏移侧外缘（右侧则从 bbox 右边缘右移一格开始，左侧则从 bbox 左边缘左移一格开始，上侧则从 bbox 上边缘上移一格开始）沿该方向逐格投射射线。射线的行坐标固定为射线源质心所在行（水平射线时）或列坐标固定为射线源质心所在列（垂直射线时），取整到最近整数。
5. 射线每经过一个背景像素，将该像素涂为射线源的颜色。
6. 当射线的下一个像素属于某个"障碍"图形时，射线停止（不包含该障碍像素本身）。同时将该障碍图形的全部像素重涂为射线源的颜色。
7. 若射线在到达任何障碍之前到达网格边缘，则射线在边缘处停止，不产生障碍重涂。
8. 多条射线如果经过同一个背景像素，后处理的射线覆盖先处理的。射线源按其边界框左上角的行优先、列次优先顺序依次处理。

**关键洞察**：对称检测在源题中用于选出唯一异常对象并裁剪输出，但在此题中它将所有对象分为两个互动角色（源与障碍），且不对称图形的具体不对称形态（质心偏向哪侧）直接编码了射线方向——这种"形状即指令"的关系需要对比多个示例中不同不对称形态与射线方向的对应才能归纳。

## 实现要求

1. `main(grid)` 必须实现新题描述中的确定性转换规则，不能只识别 `generate_input()` 的固定模板。禁止不同的input网格输出相同的output网格。
2. `generate_input()` 必须随机生成多样样例，不能固定死。随机维度应覆盖：网格大小、对象数量、位置、颜色、方向、形状参数或关键分支。注意若描述中存在若干，需实现而不是只有单个，包括object或者对应关系等等。
3. 生成器必须保证输入满足 `main()` 的隐式假设：对象不重叠、不越界、特殊标记唯一或可区分、匹配关系无歧义、关键分支出现概率相同。
4. 禁止把 ARC 颜色 id 、亮度、拼写等当作人类不可见的数值语义参与排序、大小比较或隐藏映射。颜色变化必须有可见结构线索。注意颜色亮度、拼写等也是不可见信息，若描述中出现违规的颜色id或者亮度，可自行使用少量的固定颜色替代，但注意生成时要在三个以内输入输出网格中对所有变换100%覆盖度。
5. 输出样例要视觉清晰，人类必须能从输入输出对中肉眼辨认出规律。具体要求：避免对象粘连、覆盖关系混乱、同一像素多重语义；不同逻辑步骤产生的结果不要大面积层叠在一起导致无法分辨哪个颜色属于哪个步骤；输入中各元素之间保持足够间距，输出中新增的标记/填充/路径等应与背景和已有元素在颜色上有明显区分；若规则涉及多层叠加，生成时控制对象密度和尺寸，确保叠加区域只占少数像素而非铺满整个网格。
