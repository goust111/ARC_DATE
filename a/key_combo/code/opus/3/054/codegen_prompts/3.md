## 新题 3：交替镜像平铺后的跨瓦片近端扩展

**组合逻辑**：[镜像 + 平铺/交替翻转平铺](已有，生成大网格) → [延伸 + 朝近端扩展](创新：原题中边缘条和控制像素在同一输入中给定，此处由平铺过程涌现——相邻瓦片的边缘条面对面形成新的"两边之间"关系，控制像素在瓦片内部但其"近端"可能是相邻瓦片的边缘条)

**来源原语**：镜像/reflect、平铺/tile、交替翻转平铺/alternating_reflections_tiling、精灵体/sprite（参考题 8d5021e8）；延伸/extend、边缘条/edge_bar、控制像素/control_pixel、标记在两边之间/marker_between_edges、朝近端扩展/toward_nearer_expand（参考题 642248e4）

**依赖链**：平铺的翻转方式决定了相邻瓦片中边缘条的朝向（镜像后边缘条可能翻转到对面），边缘条的新空间关系决定了控制像素的"近端"指向哪条边缘条，近端方向决定了扩展方向和颜色。不执行平铺则不知道边缘条的最终位置；不知道边缘条位置则无法判断近端方向。

将含有边缘条和控制像素的小精灵体做交替镜像平铺，然后在平铺后的大网格中，每个控制像素根据距离最近的边缘条（可能属于相邻瓦片）向该方向扩展一格并涂为该边缘条的颜色。

**输入结构**：黑(0)背景，输入为一个约 5x6 的小精灵体。精灵体的上边缘和下边缘各有一条完整的单像素行作为边缘条，上边缘条颜色为红(2)，下边缘条颜色为蓝(1)。边缘条之间（即精灵体内部行）有 2~3 个孤立的灰(5)控制像素，其余内部像素为黑(0)背景。生成约束：控制像素不与任何边缘条直接相邻（至少间隔 1 行），且各控制像素到上下两条边缘条的距离不相等（确保近端唯一确定）。输出网格为输入的 3 倍高、2 倍宽（即约 15x12）。

**规则**：
1. 将输入精灵体视为源瓦片 T。
2. 构建中间带：将 T 与 T 的左右镜像水平拼接，得到 2 倍宽的中间带 M。
3. 构建上下带：将 M 做上下镜像得到 M'。
4. 将 M' 放在最上方，M 放在中间，M' 放在最下方，垂直堆叠得到 3 倍高 2 倍宽的大网格 G。
5. 在大网格 G 中，识别所有边缘条像素（红(2)和蓝(1)的完整行段，它们来自原始瓦片的上下边缘及其镜像）和所有控制像素（灰(5)像素）。
6. 对每个灰(5)控制像素，沿垂直方向（上和下）分别计算到最近的边缘条像素的曼哈顿距离（仅在同一列上测量，即向上逐行和向下逐行搜索最近的红(2)或蓝(1)边缘条像素）。
7. 选取距离更近的那条边缘条。在控制像素与该边缘条之间、紧邻控制像素的那一格背景像素处涂上该边缘条的颜色（红(2)或蓝(1)）。若该格已被占据（非背景），则不涂。
8. 所有原有的边缘条像素和控制像素保持不变。

**关键洞察**：源题 642248e4 中边缘条和控制像素的空间关系是输入直接给定的，而此题中这些关系由平铺过程涌现——上下镜像翻转使得原本在瓦片上缘的红色边缘条在翻转后出现在相邻瓦片的下缘附近，改变了控制像素的"近端"判断。求解者必须先正确执行平铺（包括翻转方向），然后在平铺结果上重新评估每个控制像素的近端方向，而非简单复制原始瓦片内的扩展结果。这种"平铺改变局部关系"的效应需要对比不同瓦片交界处的控制像素行为才能归纳。

## 实现要求

1. `main(grid)` 必须实现新题描述中的确定性转换规则，不能只识别 `generate_input()` 的固定模板。禁止不同的input网格输出相同的output网格。
2. `generate_input()` 必须随机生成多样样例，不能固定死。随机维度应覆盖：网格大小、对象数量、位置、颜色、方向、形状参数或关键分支。注意若描述中存在若干，需实现而不是只有单个，包括object或者对应关系等等。
3. 生成器必须保证输入满足 `main()` 的隐式假设：对象不重叠、不越界、特殊标记唯一或可区分、匹配关系无歧义、关键分支出现概率相同。
4. 禁止把 ARC 颜色 id 、亮度、拼写等当作人类不可见的数值语义参与排序、大小比较或隐藏映射。颜色变化必须有可见结构线索。注意颜色亮度、拼写等也是不可见信息，若描述中出现违规的颜色id或者亮度，可自行使用少量的固定颜色替代，但注意生成时要在三个以内输入输出网格中对所有变换100%覆盖度。
5. 输出样例要视觉清晰，人类必须能从输入输出对中肉眼辨认出规律。具体要求：避免对象粘连、覆盖关系混乱、同一像素多重语义；不同逻辑步骤产生的结果不要大面积层叠在一起导致无法分辨哪个颜色属于哪个步骤；输入中各元素之间保持足够间距，输出中新增的标记/填充/路径等应与背景和已有元素在颜色上有明显区分；若规则涉及多层叠加，生成时控制对象密度和尺寸，确保叠加区域只占少数像素而非铺满整个网格。
6. 若规则有多个分支，生成器不能长期固定成一个分支；应让分支在随机样例中合理出现。分支概率不必平均——难以发现的隐蔽分支（如少数情况下才触发的特殊规则）应适当提高出现概率，确保在 3 个训练示例中至少出现一次，否则求解者无法归纳该规则。对于颜色映射类规则，确保 2 个左右的示例即可覆盖所有映射关系（每种颜色→颜色的映射至少在某个示例中出现过）。
