## 新题 4：拉伸后空心化画叉

**组合逻辑**：[拉伸](已有) → [擦除+连线·X 图案](已有) — 拉伸改变矩形内部尺寸，从而改变 X 图案的臂长和几何形态（创新耦合）

**来源原语**：拉伸(stretch) — b548a754；擦除(erase) — 8cb8642d；连线(draw_lines) — 8cb8642d；实心矩形(solid_rectangle) — 8cb8642d；空心矩形(hollow_rectangle) — b548a754；标记像素(marker_pixel) — b548a754, 8cb8642d；标记在矩形内(marker_inside_rect) — 8cb8642d；标记决定拉伸终点(marker_determines_stretch_endpoint) — b548a754

**依赖链**：外部标记像素 → 确定拉伸方向和终点 → 矩形扩展为新尺寸 → 新尺寸决定内部空间 → 内部空间决定 X 图案的对角线长度和交叉点位置。三个操作通过矩形的几何尺寸链式耦合。

将实心矩形拉伸到外部标记像素处，然后空心化并在扩展后的内部绘制嵌入标记色的 X 图案。

**输入结构**：
- 约 12x14 的黑(0)背景网格。
- 一个蓝(1)实心矩形（约 3x3 到 4x5），内部有一个嵌入的红(2)标记像素，严格在矩形边框内部（不在边界行列上）。
- 矩形外部有一个黄(4)孤立像素，位于矩形的正上方、正下方、正左方或正右方（与矩形的某条边在行或列上对齐）。
- 生成约束：黄(4)像素与矩形最近边之间至少隔 3 行或 3 列，保证拉伸后内部空间足够绘制 X 图案（内部至少 3x3）。

**规则**：
1. 确定黄(4)标记像素相对于矩形的方向（上/下/左/右）。
2. 将矩形的对应边拉伸到黄(4)标记所在的行或列。黄标记像素被拉伸后的蓝(1)边框覆盖。矩形的其他三条边不动。
3. 保留拉伸后矩形的蓝(1)外边框（一像素宽的矩形环）。
4. 将边框围住的内部区域清空为黑(0)。
5. 从内部区域的四个角像素出发，分别沿 45 度对角线方向画红(2)线段，直到线段相遇或到达对角方向的内部边界。
6. 若内部宽度或高度为奇数，中心行列的交汇像素也填红(2)以连通 X 的四臂。

**关键洞察**：外部标记决定拉伸方向和距离，从而改变矩形内部尺寸，最终影响 X 图案的几何形态——若不先完成拉伸，就无法确定 X 的绘制范围。嵌入标记像素在拉伸前标识颜色角色、在拉伸后被空心化消除，其信息仅通过 X 的颜色传递。
