## 新题 9：标记密度选模板后递归印章

**组合逻辑**：[裁剪·标记色最多者选中](已有) x [印章覆盖·递归](已有) — 标记色同时担任选取判据和递归印章的宏位置标记（创新双重角色）

**来源原语**：裁剪(crop) — ae4f1146；印章覆盖(stamp_overlay) — cce03e0d；精灵体(sprite) — ae4f1146；标记色像素(marker_color_pixel) — ae4f1146；控制像素(control_pixel) — cce03e0d；形状内色频(color_frequency_within_shape) — ae4f1146；格位映射(cell_block_mapping) — cce03e0d；标记色最多者选中(max_marker_count_selected) — ae4f1146；递归印章(recursive_stamp) — cce03e0d

**依赖链**：全局最稀有色 = 标记色 → 比较各精灵体中标记色像素数 → 选出标记色最多的精灵体为模板 → 模板中标记色像素的位置 = 递归印章的宏位置 → 在宏位置粘贴模板副本。标记色在"选择哪个模板"和"模板内哪些位置做递归"两个逻辑中扮演不同角色，但指向同一批像素。

从多个精灵体中选出标记色最密的那个作为模板，再将该模板在其标记色像素位置递归印章。

**输入结构**：
- 约 10x10 的黑(0)背景网格。
- 3~4 个分离的 3x3 实心精灵体（边界框恰好 3x3，内部全部填满），每个精灵体由两种非背景色构成。
- 全局有一种颜色在所有前景像素中出现次数最少，记为标记色（如红(2)）。
- 各精灵体中标记色像素的数量互不相同，恰好一个精灵体的标记色像素数严格最多。
- 生成约束：被选中模板中标记色像素数为 2~4 个（过多会导致输出过大）。

**规则**：
1. 确定标记色：统计所有非背景色像素的出现次数，出现最少的颜色为标记色。
2. 裁剪每个 4-连通精灵体为 3x3 边界框。
3. 比较各精灵体中标记色像素的数量，选出数量最多的那个作为模板 T。
4. 在模板 T 中，记录标记色像素的位置坐标（相对于 3x3 边界框）。
5. 构建 9x9 的输出画布（3x3 个 3x3 的块）。
6. 对模板 T 的每个像素位置 (r, c)：若该位置是标记色，则在输出画布的第 (r, c) 个 3x3 块中填入模板 T 的完整副本；否则该 3x3 块全部填黑(0)。

**关键洞察**：标记色的"全局最稀有"特征用于在精灵体间做出选择，而被选中后，标记色在模板内的空间分布又决定了递归印章的宏观布局——同一颜色属性在统计选择和几何布局两个完全不同的层面起作用。
