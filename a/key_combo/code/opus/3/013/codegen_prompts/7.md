## 新题 7：隐藏通道检测配合图例位置匹配分色填充

**组合逻辑**：[洪泛填充+背景通道检测](创新：检测到的通道不统一涂色而是分别按位置匹配着色) + [相对位置对应+最小距离匹配](创新：匹配对象从占位块变为负空间通道) + [图例矩形](创新：图例不驱动前景对象重涂色而是驱动负空间通道填色)

**来源原语**：洪泛填充(a64e4611) + 背景通道(a64e4611) + 长矩形通道涂色(a64e4611) + 图例矩形(1da012fc) + 控制标记点(1da012fc) + 相对位置对应(1da012fc) + 最小距离匹配(1da012fc)

**依赖链**：通道检测确定哪些负空间是"真通道"→通道中心的相对位置与图例标记的相对位置建立对应→匹配结果确定每条通道的填充颜色。去掉通道检测，不知道负空间在哪；去掉位置匹配，不知道哪条通道用哪种颜色；去掉图例，无色可选。

识别被杂色掩盖的隐藏通道，再根据图例中标记点的位置对应关系为每条通道分配不同的填充颜色。

**输入结构**：约 16x16 的网格，主背景色为黑(0)。橙(7)像素作为杂色前景散布在网格中（密度约 10%~20%），其中隐藏着 2~4 条长矩形通道（全黑的长条形区域，长轴至少为网格边长的一半，方向为水平或垂直）。网格的右下角（或任一角落）放置一个灰(5)实心矩形（约 4x4），其内部嵌入与通道数量相同的彩色标记像素，颜色各不相同，从红(2)、蓝(1)、绿(3)、黄(4)中选取。生成约束：每条通道的中心相对于网格边界框的归一化位置与恰好一个图例标记相对于图例边界框的归一化位置最近，且该最近匹配是唯一的（无平局）。通道之间互不相交。

**规则**：
1. 保留 3x3 邻域全为黑色的背景像素（一像素间隙清除），在此清洁掩码上枚举极大矩形，按面积降序接受长轴至少为网格边长一半的矩形作为"真通道"。
2. 计算每条真通道的中心坐标 (r_c, c_c)，归一化到网格边界框 [0,1]x[0,1]。
3. 计算灰色图例矩形内每个彩色标记像素的位置，归一化到图例边界框 [0,1]x[0,1]。
4. 用最小欧氏距离将每条通道匹配到唯一的图例标记。
5. 将每条通道内的黑色像素填充为其匹配标记的颜色。橙色杂色、图例矩形和标记像素保持不变。

**关键洞察**：图例看似只是角落里的一个灰色方块，实则其内部标记点的空间布局编码了每条隐藏通道应该被涂什么颜色——通道和标记通过归一化位置相互对应，而非通过计数顺序或颜色名称。
