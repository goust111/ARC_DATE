## 新题 10：双面板并集掩码驱动对角线段间选择性填充

**组合逻辑**：[透明叠加+并集取前景](创新：并集掩码不直接涂色而是作为后续填充操作的空间约束) + [填充+段间区域填充](创新：只填充掩码覆盖的子区域而非所有段间区域) + [对角线段+平行配对](已有原语)

**来源原语**：透明叠加(d19f7514) + 并集取前景(d19f7514) + 逐像素对齐(d19f7514) + 填充(7666fa5d) + 对角线段(7666fa5d) + 平行配对(7666fa5d) + 段间区域填充(7666fa5d)

**依赖链**：两个面板的并集掩码确定了"活跃区域"→对角线段在活跃区域内识别平行对→仅填充活跃区域内的段间像素。去掉并集掩码，无法区分活跃/非活跃区域，所有段间区域都会被填充（产生过多填充）；去掉段间填充，掩码无意义。

叠合两个面板的前景得到活跃区域掩码，仅在掩码范围内填充平行对角线段之间的空隙。

**输入结构**：约 10x20 的网格（偶数高度），沿水平中线分为上下两个等大的 10x10 面板。上面板：黑(0)背景上有绿(3)前景像素构成的不规则掩码区域（4-连通，约占面板面积的 30%~50%）。下面板：黑(0)背景上有灰(5)前景像素构成的不规则掩码区域（4-连通，约占面板面积的 30%~50%），同时有若干橙(7)像素构成的短反对角线段（每段 2~4 像素，位于 r+c=常数 上），这些线段成对出现在平行的反对角线上。生成约束：上下面板的前景掩码并集（对齐后）覆盖了部分段间区域但不覆盖所有段间区域；至少有一个段对的段间区域被并集掩码部分覆盖、部分未覆盖。

**规则**：
1. 将上面板和下面板逐像素对齐。对于每个坐标位置，若上面板该位置是绿(3)或下面板该位置是灰(5)或橙(7)（即任一面板为非黑前景），则标记该位置为"活跃"。
2. 在下面板中，识别橙(7)像素构成的反对角线段，按主对角线轴（r-c 值）分组并按反对角线索引（r+c 值）排序，相邻段形成配对。
3. 对每个段对，沿主对角线轴扫描严格位于两段之间的像素：仅当该像素位置被标记为"活跃"且在下面板中为黑(0)时，将其填充为红(2)。
4. 输出为下面板大小的网格：橙(7)线段保留，红(2)填充出现在活跃的段间区域，其余保持下面板原样。

**关键洞察**：上面板的绿色区域看似与下面板的对角线结构无关，但它通过并集掩码间接控制了哪些段间空隙会被填充——两个面板的空间信息必须叠合后才能确定最终的填充范围。
