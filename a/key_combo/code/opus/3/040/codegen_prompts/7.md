## 新题 7：最密分区定义主干轴线后其余分区生成垂直连接线

**组合逻辑**：[计数 + 筛选 + 最密区域保留填充](已有) → 最密区域的空间位置涌现为主干轴线(创新：主干不由共行列像素定义，而由统计最大值的空间位置推导) → [连线 + 连接到主干](已有原语，但主干来源从坐标重复变为统计选举) → [擦除](已有)

**来源原语**：计数、筛选、最密区域保留填充、分区区域、分隔线（29623171）；连线、连接到主干、共行列定义主干、擦除（bf89d739）

**依赖链**：统计每个分区的彩色像素数量 → 识别最密分区 → 最密分区的中心行和中心列成为主干十字轴线 → 每个非最密分区向最近的主干轴画连接线 → 最密分区洪泛填充，非最密分区的原始散点被擦除（仅保留连接线）。主干位置由统计选举决定，改变任何分区的像素密度都可能改变主干，从而改变所有连接线的方向和长度。

在分隔线划分的网格中，找到散点最密集的分区作为主干十字轴线的中心，其余分区各画一条连接线到最近的轴线，最密分区整体填充，其余分区仅保留连接线。

**输入结构**：约 15x15 的网格。灰(5)全行和全列分隔线将网格分成 3x3 或 4x4 的矩形分区阵列。每个分区内为黑(0)背景，散布着单一非黑非灰颜色的像素（每个分区 1-8 个像素，不同分区颜色不同）。生成约束：恰好一个分区的彩色像素数严格多于所有其他分区；该最密分区不位于分区阵列的边界行或边界列（以便主干轴线有足够延伸空间）。

**规则**：
1. 统计每个分区内的非黑非灰彩色像素数量。识别唯一的最密分区（像素数最多）。
2. 用该分区的颜色洪泛填充整个最密分区（覆盖其中的黑色间隙）。
3. 确定最密分区内部区域的中心行（内部行范围的中位行，若为偶数行则取靠上的）和中心列（内部列范围的中位列，若为偶数列则取靠左的）。以灰(5)沿该中心行画一条贯穿全网格的水平线，沿该中心列画一条贯穿全网格的垂直线。这两条线构成十字主干轴线（与已有分隔线视觉上相同但可能位于分区内部）。
4. 对每个非最密分区：计算该分区中心像素到水平主干轴线的行距和到垂直主干轴线的列距。选择距离更近的轴线（若相等则选水平轴线）。从该分区的中心像素出发，沿垂直方向（若连接水平轴线）或水平方向（若连接垂直轴线）画一条一像素宽的直线，颜色为该分区的原始颜色，直到到达对应的主干轴线（不包含轴线本身的那一格）。
5. 擦除所有非最密分区中的原始散点像素（变为黑色），仅保留步骤 4 中画出的连接线。
6. 原有的灰色分隔线保持不变。

**关键洞察**：主干轴线不是预设在输入中的——它由"哪个分区最密"这个全局统计量的空间位置推导出来。如果改变一个像素使另一个分区成为最密者，主干轴线就会移到完全不同的位置，所有连接线的方向和长度都会随之改变。统计选举与几何绘制之间的耦合是本题的核心。
