## 新题 8：镜像色带后由标记总数编码镜像副本的腐蚀半径

**组合逻辑**：[镜像 + 色带翻转到对侧 + 对称](已有) → 镜像产生副本(创新：副本不是原样复制，而是受损的复制) → [计数](已有) → 计数结果编码为半径(创新：标记总数的全局属性编码每个标记的局部效果) → [擦除 + 禁区](已有原语，但作用于镜像副本中的特定区域)

**来源原语**：镜像、对称、色带翻转到对侧、色带行（496994bd）；计数、前景像素（794b24be）；擦除（bf89d739）；像素计数编码半径、禁区（cb2d8a2c）；标记像素（e57337a4）

**依赖链**：原始顶部色带（含嵌入标记）完整镜像到底部 → 统计色带中标记像素的总数 T → 每个标记在镜像副本中的对应位置生成切比雪夫半径为 (T-1) 的腐蚀区 → 腐蚀区内的镜像像素被擦除。标记数量越多，每个标记的破坏力越大（因为 T-1 更大），产生非线性的损伤放大效应。

将顶部色带镜像到底部，但色带中嵌入的标记像素在镜像副本中制造腐蚀孔洞——每个标记的腐蚀半径等于标记总数减一，标记越多，每个孔洞越大。

**输入结构**：约 12x12 的网格。黑(0)背景。顶部 2-3 行为贯穿全宽的彩色色带，色带主色为一种前景色（如蓝(1)）。色带内嵌入 1-3 个单像素的标记，颜色与色带主色不同（如红(2)）。色带下方所有行均为黑色。生成约束：标记像素不在色带最顶行；各标记之间的间距足够大，使得当标记数 = 2 时腐蚀半径为 1、标记数 = 3 时腐蚀半径为 2 时，腐蚀区在镜像副本中不互相覆盖完全重叠（允许部分重叠）；色带宽度足以让腐蚀后仍有可见残留。

**规则**：
1. 将顶部色带镜像到网格底部：色带的行序上下翻转后放置在网格最底部的对应行数内。原始顶部色带保持不变。中间的黑色间隔保持不变。
2. 统计原始色带中标记像素的总数 T。
3. 对原始色带中的每个标记像素，找到它在镜像副本中的对应位置（行翻转后的坐标）。
4. 在镜像副本中，以每个标记对应位置为中心，将切比雪夫距离 <= (T-1) 范围内的所有镜像副本像素擦除为黑(0)。此擦除仅影响镜像副本区域，不影响原始色带和中间间隔。
5. 原始色带（包括其中的标记像素）完全不变。

**关键洞察**：标记像素具有双重角色——它们是色带图案的一部分（被镜像复制），同时又是腐蚀炸弹（在镜像副本中制造空洞）。更微妙的是，每个标记的破坏力不是固定的，而是由标记总数全局决定的：1 个标记时半径为 0（无破坏），2 个标记时每个半径为 1（小孔），3 个标记时每个半径为 2（大洞）。这种"群体越大个体越强"的非线性规则需要对比不同标记数量的示例才能归纳。

## 实现要求

1. `main(grid)` 必须实现新题描述中的确定性转换规则，不能只识别 `generate_input()` 的固定模板。禁止不同的input网格输出相同的output网格。

3. 生成器必须保证输入满足 `main()` 的隐式假设：对象不重叠、不越界、特殊标记唯一或可区分、匹配关系无歧义、关键分支出现概率相同。
4. 禁止把 ARC 颜色 id 、亮度、拼写等当作人类不可见的数值语义参与排序、大小比较或隐藏映射。颜色变化必须有可见结构线索。注意颜色亮度、拼写等也是不可见信息，若描述中出现违规的颜色id或者亮度，可自行使用少量的固定颜色替代，但注意生成时要在三个以内输入输出网格中对所有变换100%覆盖度。
5. 输出样例要视觉清晰，人类必须能从输入输出对中肉眼辨认出规律。具体要求：避免对象粘连、覆盖关系混乱、同一像素多重语义；不同逻辑步骤产生的结果不要大面积层叠在一起导致无法分辨哪个颜色属于哪个步骤；输入中各元素之间保持足够间距，输出中新增的标记/填充/路径等应与背景和已有元素在颜色上有明显区分；若规则涉及多层叠加，生成时控制对象密度和尺寸，确保叠加区域只占少数像素而非铺满整个网格。
6. 若规则有多个分支，生成器不能长期固定成一个分支；应让分支在随机样例中合理出现。分支概率不必平均——难以发现的隐蔽分支（如少数情况下才触发的特殊规则）应适当提高出现概率，确保在 3 个训练示例中至少出现一次，否则求解者无法归纳该规则。对于颜色映射类规则，确保 2 个左右的示例即可覆盖所有映射关系（每种颜色→颜色的映射至少在某个示例中出现过）。
