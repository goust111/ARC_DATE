## 新题 9：墙壁门径与滑动锚点

**组合逻辑**：[寻路/连线(pathfinding/draw_path)](已有) + [滑动(slide)](已有) → 创新：滑动后的停靠位置成为路径的强制锚点，滑动结果重塑路径几何

**来源原语**：连线(draw_path)、寻路(pathfinding)、平行墙壁(parallel_walls)、门段(door_segment)、穿越门中心(through_door_center)、走廊正交路径(corridor_ortho_path)、标记像素(marker_pixel) ← 7e576d6e；滑动(slide)、可移动行程(movable_run)、固定障碍(fixed_barrier)、靠近障碍停止(stop_at_barrier)、同行阻挡(same_row_blocking) ← 9c56f360

**依赖链**：走廊中的彩色段向下方墙壁滑动 → 停靠位置确定路径的必经锚点列 → 连线穿越门中心并经过锚点列 → 路径在每段走廊中取该走廊色段颜色

走廊中的彩色段先滑动到墙壁边停靠，停靠位置成为穿门路径的必经锚点，路径以锚点颜色分段绘制。

**输入结构**：
- 黑(0)背景，约12x18网格。
- 灰(5)像素构成2~3道全跨水平墙壁（每道墙占一整行），将网格分成3~4条走廊。
- 每道墙壁有一个3像素宽的门段（门段为黑(0)间隙），各墙壁的门段位置不同。
- 最上走廊和最下走廊各有一个橙(7)标记像素（路径的起止点），位于走廊内任意位置。
- 中间走廊各有一个彩色水平行程（红(2)或绿(3)，2~4像素长的连续水平色段），位于走廊中部偏上，不紧贴任何墙壁。
- 生成约束：每条走廊最多一个色段；各色段水平位置与门段中心列不相同。

**规则**：
1. 对每条中间走廊的彩色行程：整体向下滑动（保持水平位置不变），直到行程的底边像素紧贴该走廊下方墙壁（若走廊下方是网格底边则贴底边）。
2. 以最上走廊的橙(7)标记为起点、最下走廊的橙(7)标记为终点，画一条正交路径依次穿越所有门中心，从上向下逐层推进。
3. 路径在每条中间走廊内必须经过该走廊中已滑动就位的色段的水平中心列（取色段水平跨度的中间列，向左取整）。
4. 路径画法：从当前位置水平移动到目标列（锚点中心列或门中心列），再垂直移动到下一道墙的门中心行，穿过门中心进入下一走廊。无色段的走廊（最上和最下走廊）直接以最短路径水平对齐到下一个/上一个门中心列。
5. 路径在含色段的走廊段内使用该色段的颜色绘制；在最上走廊和最下走廊段内使用橙(7)绘制。
6. 滑动后的色段像素保留在新位置。路径像素不覆盖色段像素（若路径经过色段位置则跳过该像素，色段已有颜色）。

**关键洞察**：色段滑动后的停靠列成为路径的强制锚点，改变了路径的水平走向——不同示例中色段的初始位置不同，滑动后锚点不同，路径形状随之改变。跳过滑动则锚点未定，路径无法确定。
