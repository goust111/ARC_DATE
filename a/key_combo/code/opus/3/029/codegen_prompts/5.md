## 新题 5：标记选择晶格带后图例映射射线重涂色

**组合逻辑**：[标记行列选择](已有原语) + [射线延伸](创新：射线仅从标记选中的带与控制列的交点发射，而非从所有控制像素发射) + [图例配色映射](创新：射线颜色不等于控制像素自身颜色，而是通过图例间接映射) → 三个独立信息源（标记位置、控制像素列、图例映射）在交汇点产生涌现输出

**来源原语**：晶格网格、标记块、标记行列选择、行列带穿越标记（4f537728）；射线延伸、控制像素、同列对齐（981add89）；图例、图例配色、图例顺序决定层级、冲突优先级（305b1341）；重涂色（58e15b12）

**依赖链**：红(2)标记块选中晶格的两行两列 → 选中行列确定"活跃带" → 顶行控制像素中，仅列号落在活跃列上的控制像素触发射线 → 射线沿选中列向下延伸穿过整个网格 → 射线涂画颜色由图例映射决定（控制像素颜色 → 图例配对色）→ 射线与选中行的交点处，若多条射线重叠，按图例行序（上方优先）解决冲突。三个信息源缺一不可：标记决定"哪里"，控制像素决定"是否发射"，图例决定"什么颜色"。

红色标记块选中晶格中的行列带，仅与选中列对齐的顶行控制像素发射向下射线，射线颜色由角落图例间接映射，多射线重叠时图例行序决定优先级。

**输入结构**：约 16x16 的网格，黑(0)背景。蓝(1)像素构成一个规则晶格（等间距的水平线和垂直线，线宽 1 像素，间距约 3-4 像素，覆盖网格大部分区域）。在晶格的某个交叉点处，一个 2x2 的红(2)标记块替换了四个蓝(1)像素。网格左上角占据 2 行 x 2 列的区域作为图例：第 0 行第 0 列 = 绿(3)，第 0 行第 1 列 = 黄(4)；第 1 行第 0 列 = 橙(7)，第 1 行第 1 列 = 青(8)。图例区域不与晶格重叠。顶行（第 0 行）的若干非图例列上放置控制像素，颜色为绿(3)或橙(7)（与图例左列颜色对应）。生成约束：至少有一个控制像素的列恰好落在标记块选中的两个列之一上，至少有一个不落在选中列上；图例区域严格在网格左上 2x2 范围内，不与晶格线重合。

**规则**：
1. 找到红(2)标记块所占的两行（r1, r2）和两列（c1, c2）。
2. 将这两行和两列上所有蓝(1)晶格像素重涂为红(2)——标记出选中的行带和列带。
3. 扫描顶行（第 0 行）的所有控制像素。对于每个控制像素：若其列号等于 c1 或 c2（即落在选中列带上），则该控制像素"激活"，从该控制像素正下方开始，沿该列向下逐格延伸射线直到网格底部。若控制像素的列号不在选中列上，则不激活，不发射任何射线。
4. 射线经过的每个格子涂上图例映射后的颜色：绿(3)控制像素的射线涂黄(4)，橙(7)控制像素的射线涂青(8)（即图例同行右列的颜色）。射线覆盖该列上的所有像素（包括黑(0)背景和红(2)选中带像素），但不覆盖蓝(1)未选中的晶格像素。
5. 若同一个格子被多条射线覆盖（仅在 c1 = c2 时可能，但此题保证 c1 != c2，故无冲突；但若不同控制像素落在同一选中列上，则按图例行序解决：第 0 行图例对应的颜色优先于第 1 行）。
6. 清除图例区域（左上 2x2）为黑(0)背景。控制像素本身保持原色不变。

**关键洞察**：标记块不仅高亮晶格带，更充当射线的空间门控——只有列与标记对齐的控制像素才会"通电"。图例提供了一层间接映射，使射线的颜色与控制像素的颜色不同，必须对比示例才能发现颜色转换规则。三个独立编码的信息（标记位置、控制像素分布、图例映射）在输出中交汇。
