## 新题 10：边缘源像素的螺旋路径绘制与同色端点终止

**组合逻辑**：[螺旋绘制](从起点按螺旋规则向内绘制路径) → [同色配对+端点触发终止](路径在遇到同色端点像素时终止，不同颜色的路径独立螺旋) → [重涂色](未被任何路径覆盖的端点像素重涂为背景色)（螺旋绘制来自 28e73c20，同色配对/端点触发来自 29700607，重涂色来自 477d2879；创新点在于螺旋不再从角落开始也不再只有一条——多条不同色路径从网格边缘的不同位置同时螺旋向内，各自在遇到同色端点时停止，路径之间的交叉由先到先占决定）

**来源原语**：螺旋绘制/spiral_draw (28e73c20), 同色配对/same_color_matching (29700607), 有端点则转弯/endpoint_triggers_turn (29700607), 碰撞转向/turn_on_collision (28e73c20), 重涂色/recolor (477d2879), 边缘源像素/edge_source_pixel (29700607), 同色端点/same_color_endpoint (29700607), 路径/path (28e73c20)

**依赖链**：网格边缘上有多个不同色的源像素，网格内部有同色的端点像素。每条路径从其源像素出发按顺时针螺旋规则向内绘制。路径遇到已被其他路径占据的像素时视为障碍，执行螺旋转向。路径遇到与自身同色的端点像素时立即终止（该端点像素被路径覆盖）。螺旋规则与同色终止条件交织——路径的绘制顺序影响障碍分布，进而影响其他路径的螺旋形状。

多条彩色路径从网格边缘出发同时向内螺旋，各自遇到同色端点时停止，路径间先到先占。

**输入结构**：黑(0)背景，正方形网格约 11x11。网格边缘（第一行、最后一行、第一列、最后一列）上有 2~3 个不同色的源像素（如蓝(1)在左上角附近、红(2)在右上角附近、绿(3)在左下角附近），分布在不同的边上。网格内部有对应的同色端点像素（如蓝(1)端点一个、红(2)端点一个、绿(3)端点一个），各端点互不相邻且距离边缘至少 3 格。生成约束：每种颜色恰好一个源像素和一个端点像素；源像素位于网格边缘，端点位于内部；各源像素所在的边不相同；螺旋路径在合理步数内（< 网格面积的一半）能到达其端点。

**规则**：
1. 按源像素在网格边缘的位置，从左上角顺时针排序确定绘制优先顺序。
2. 按优先顺序依次绘制每条路径。每条路径从源像素位置出发，初始方向为朝向网格内部（上边→向下，右边→向左，下边→向上，左边→向右）。
3. 路径按螺旋规则推进：沿当前方向前进；当下一步会离开网格、进入已被任何颜色占据的非背景像素（含其他路径和端点）时，顺时针转向 90 度。若转向后仍被阻挡，继续转向；若四个方向都被阻挡，路径终止。
4. 特殊终止条件：路径的下一步位置恰好是与自身同色的端点像素时，将该端点位置绘制为路径颜色并终止该路径（端点被路径吞没）。
5. 不同色的端点像素对该路径视为障碍（触发转向而非终止）。
6. 所有路径绘制完成后，将未被任何路径到达的端点像素重涂为黑(0)背景色（即清除未配对的残留端点）。

**关键洞察**：每条路径的螺旋形状不仅取决于网格边界，还取决于先绘制的其他路径所留下的"障碍痕迹"。绘制顺序（由源像素位置决定）实质性地改变了后续路径的几何形状——这是多条螺旋之间的涌现交互，在任何单条螺旋或单条直线路径的参考题中都不存在。
