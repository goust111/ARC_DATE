## 新题 6：控制条方向选择异常值对象滑动

**组合逻辑**：[异常值选择](在同色对象群中找出唯一不同色的对象) → [控制条方向读取](读取控制条的朝向确定滑动方向) → [滑动](将异常值对象沿控制条方向滑动到碰撞停止) + [擦除](移除控制条)（异常值选择来自 ad3b40cf，控制条/跨度对齐来自 c62e2108，滑动来自 2faf500b；创新点在于控制条不指导平铺而是指导滑动方向，且滑动目标由异常值条件从多个对象中筛选出）

**来源原语**：异常值选择/outlier_selection (ad3b40cf), 滑动/slide (2faf500b), 擦除/erase (c62e2108), 控制条/control_bar (c62e2108), 跨度对齐/span_alignment (c62e2108), 前景对象/foreground_object (2faf500b)

**依赖链**：网格中有多个同色对象和一个异色对象（异常值）。控制条的方向（水平或竖直）决定滑动轴。异常值对象沿控制条方向向控制条所在侧滑动，直到碰到另一个对象或网格边缘。非异常值对象不移动。控制条在输出中被擦除。异常值的识别和控制条的方向读取是两个独立的信息提取步骤，缺一不可。

找出颜色独特的异常对象，沿控制条指示的方向将其滑动至碰撞停止，同时移除控制条。

**输入结构**：黑(0)背景，网格大小约 12x12。网格中有 3~4 个形状各异的 4-连通单色小对象（3~6 像素），其中恰好 3 个为同一颜色（如红(2)），1 个为不同颜色（如绿(3)，即异常值）。另有一条灰(5)控制条：一像素厚的完整水平行或竖直列。控制条与异常值对象在滑动轴上的跨度有重叠（即异常值对象的行跨度或列跨度与控制条的位置在垂直轴上部分对齐）。生成约束：异常值对象与控制条之间在滑动方向上有空间可移动（至少 2 格间距）；滑动路径上可能有也可能没有其他对象作为障碍。

**规则**：
1. 识别异常值对象：在所有非背景、非灰(5)的前景对象中，找到颜色唯一（仅出现一次的颜色）的对象。
2. 读取控制条方向：灰(5)控制条若为水平行则滑动方向为竖直，若为竖直列则滑动方向为水平。滑动朝向为从异常值对象指向控制条的方向（即异常值向控制条靠拢）。
3. 将异常值对象整体沿确定的方向逐格滑动，直到对象的任何像素的下一步位置会与非背景像素（含其他前景对象，不含已擦除的控制条位置）重叠，或超出网格边界。
4. 擦除控制条：将灰(5)控制条的所有像素设为黑(0)背景。
5. 其他对象保持原位不变。

**关键洞察**：控制条在参考题中指导平铺重复的方向，这里它改为指导滑动方向——同一结构元素的语义因上下文而变。异常值选择在参考题中用于选择被镜像的颜色，这里用于选择被移动的对象。两个选择机制（选什么、往哪走）必须同时正确才能得到正确输出。
