## 新题 9：四象限旋转角度由引导线类型决定

**组合逻辑**：[象限分割](将网格分成四个象限) → [引导线类型判断](每个象限中的引导线形态编码旋转角度) → [旋转](按编码角度旋转该象限内容) → [拼接](将旋转后的象限重新拼合)（象限/拼接来自 0c786b71，引导线/轴线决定变换来自 4e7e0eb9，旋转来自 90347967/be03b35f；创新点在于引导线不再指示镜像轴而是编码旋转角度，四个象限各自独立旋转后重新拼合）

**来源原语**：旋转/rotate (90347967), 拼接/concatenation (0c786b71), 象限/quadrant (0c786b71), 引导线/guide_line (4e7e0eb9), 轴线决定变换/axis_determines_op (4e7e0eb9), 四象限对称/four_quadrant_symmetry (0c786b71)

**依赖链**：网格被十字分隔线分成四个等大的正方形象限。每个象限内部有一条特定形态的引导线（无引导线=0度、水平线=90度、竖直线=180度、对角线=270度），引导线类型编码该象限需要顺时针旋转的角度。移除引导线后，将每个象限的前景内容按编码角度旋转，最后将四个处理后的象限按原位置拼合输出。

读取每个象限中引导线编码的旋转角度，旋转该象限内容后重新拼合。

**输入结构**：黑(0)背景，网格为奇数边长的正方形（如 11x11 或 13x13）。中间行和中间列为黄(4)十字分隔线，将其余区域分成四个等大的正方形象限（每个约 5x5 或 6x6）。每个象限内有一个小型多色前景图案（2~3 种颜色，如蓝(1)和红(2)，占 4~8 像素，形状不规则且非旋转对称）。每个象限内还可能有一条灰(5)引导线，形态为以下四种之一：(a) 无灰色线 = 不旋转；(b) 一条水平灰线横穿象限中部 = 顺时针 90 度；(c) 一条竖直灰线纵穿象限中部 = 顺时针 180 度；(d) 一条主对角线方向的灰线 = 顺时针 270 度。生成约束：四个象限的引导线类型两两不同（四种各出现一次）；引导线像素不与前景图案像素重叠。

**规则**：
1. 识别黄(4)十字分隔线，确定四个象限的范围。
2. 对每个象限，检测灰(5)引导线的形态：无灰色像素→0度；灰色像素形成水平线段→90度；形成竖直线段→180度；形成对角线段→270度。
3. 擦除每个象限内的灰(5)引导线像素（设为黑(0)）。
4. 将每个象限内的非背景前景图案绕象限中心顺时针旋转对应角度（0/90/180/270度）。旋转后超出象限范围的像素舍弃。
5. 移除黄(4)十字分隔线，将四个处理后的象限按原位拼合（左上、右上、左下、右下），输出网格尺寸为去掉十字线后的大小（即 (原宽-1) x (原高-1) 的四象限无缝拼合）。

**关键洞察**：参考题 4e7e0eb9 中引导线决定镜像方向，参考题 0c786b71 中四象限通过固定的镜像规则拼合。本题中引导线的语义变为编码旋转角度，且四个象限的变换各不相同。求解者必须先在每个象限中"解码"引导线，才能执行正确旋转——引导线既是需要移除的元素，又是变换指令的载体。
