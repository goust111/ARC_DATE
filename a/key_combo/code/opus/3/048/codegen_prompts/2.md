## 新题 2：隐式枢轴推断与旋转差异提取

**组合逻辑**：[点对称推断](从两个近似副本反推枢轴位置) → [旋转+对齐比较](将一个副本绕推断枢轴旋转180度并与另一副本逐像素比较) → [差异提取+裁剪](提取不匹配像素并裁剪输出)（点对称来自 90347967，差异提取来自 2037f2c7；创新点在于枢轴不直接给出而必须从两个副本的空间关系中推断，且比较需先施加旋转变换）

**来源原语**：旋转/rotate (90347967), 点对称/point_symmetry (90347967), 差异提取/difference_extraction (2037f2c7), 裁剪/crop (2037f2c7), 对齐比较/aligned_comparison (2037f2c7), 枢轴像素/pivot_pixel (90347967), 缺失掩码/missing_cell_mask (2037f2c7)

**依赖链**：两个前景对象是同一图案的点对称副本（其中一个有少量缺损）。求解者必须先找到使两者构成 180 度旋转对称的枢轴点，然后通过该枢轴旋转其中一个副本以对齐另一个，最后提取不匹配的像素。枢轴推断依赖两个副本的位置关系；差异提取依赖正确的旋转对齐；若枢轴错误则差异结果完全错误。

找到两个前景副本之间的隐式旋转中心，绕该中心旋转对齐后提取缺损像素的掩码。

**输入结构**：黑(0)背景上有恰好两个多色 4-连通前景对象（使用蓝(1)、红(2)、绿(3)等色，不含灰(5)）。两个对象的边界框大小相同（约 4x4 至 6x6）。对象 A 是完整图案，对象 B 是对象 A 绕某个枢轴点 180 度旋转后再移除 1~3 个前景像素的结果。枢轴点不在任何前景像素上，位于两个对象边界框的中间位置（即两个对象关于枢轴点中心对称分布）。网格大小约 15x15。生成约束：枢轴坐标为半整数（即位于四个像素的交汇处），使旋转映射唯一；被移除的像素在对象 B 中变为黑(0)背景色。

**规则**：
1. 识别两个前景对象 A（像素较多）和 B（像素较少）。
2. 计算枢轴点：枢轴是使 A 旋转 180 度后与 B 的前景像素最大重合的点。具体地，枢轴 = ((A的质心行 + B的质心行) / 2, (A的质心列 + B的质心列) / 2)。
3. 将 A 的每个像素 (r, c) 映射到 (2*pivot_r - r, 2*pivot_c - c)，得到旋转后的 A'。
4. 提取 A' 中前景而 B 中背景的像素位置，即 B 的缺损部分。
5. 将这些像素裁剪到其最小边界框，前景像素重涂为青(8)，背景为黑(0)，作为输出。

**关键洞察**：参考题 90347967 中枢轴像素直接以灰色标出，参考题 2037f2c7 中两个副本直接对齐比较。本题将二者的前提条件都隐藏了——枢轴需要从两个对象的空间布局推断，比较需要先做 180 度旋转，使得推断和变换形成不可分割的链条。
