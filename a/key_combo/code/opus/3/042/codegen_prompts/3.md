## 新题 3：路径端点位移解码驱动走廊路径铺设

**组合逻辑**：[端点编码位移](创新：位移用于平移门框而非空心框) + [平移] + [路径填充](创新：在平移后的新位置之间铺设走廊) + [最短路径并集]

**来源原语**：端点编码位移/endpoints_encode_disp（2b9ef948）、平移/translate（2b9ef948, 8ee62060）、路径填充/path_fill（692cd3b6）、门框/doorway_frame（692cd3b6）、走廊路径/corridor_path（692cd3b6）、路径端点/path_endpoint（2b9ef948）、最短路径并集/monotone_shortest_path_union（692cd3b6）

**依赖链**：每个门框各关联一条灰色折线路径 -> 路径两端的彩色端点编码一个位移向量 -> 每个门框按各自的位移向量平移到新位置 -> 在两个平移后的门框之间计算并绘制单调最短路径并集走廊 -> 路径的弯折形状无关紧要，只有端点间的净向量决定位移

先从灰色路径的彩色端点解码位移向量，将两个门框分别平移到新位置，然后在新位置间铺设单调最短路径并集走廊。

**输入结构**：约 20x20 的网格，黑(0)背景。两个蓝(1)小型门框结构（每个约 3x3 至 4x4 的单像素厚矩形框，框上恰有一个缺口即门洞，门洞内有一个红(2)标记像素）。每个门框附近有一条灰(5)像素组成的折线路径（3-7 个灰像素，可含转弯），路径一端连接一个绿(3)像素，另一端连接一个黄(4)像素。绿(3)像素和黄(4)像素不与门框相邻。两条路径互不相交，两个门框互不重叠。生成约束：每个门框按其关联路径的位移向量平移后仍在网格内且两者不重叠，平移后两个门框之间存在至少一条背景单元格组成的单调路径。

**规则**：
1. 识别两个蓝(1)门框及其内部红(2)标记像素。
2. 对每个门框，找到其附近的灰(5)折线路径。路径的两个端点分别是一个绿(3)像素和一个黄(4)像素。
3. 计算位移向量：从绿(3)端点指向黄(4)端点的向量 (dr, dc) = (r_yellow - r_green, c_yellow - c_green)。灰色路径的中间弯折不影响位移。
4. 将门框（含其蓝(1)像素和红(2)标记）整体平移 (dr, dc)。擦除原始位置的门框像素和路径（灰、绿、黄）像素，全部置为黑(0)。
5. 在两个平移后的门框之间铺设走廊：找到每个门框的门洞缺口外侧第一个背景单元格（外门口单元格）。
6. 以两个外门口单元格为起止点，仅允许朝向对方的行/列步进（单调步进），收集所有此类最短路径经过的背景单元格的并集，将其涂为黄(4)。同时将两个门洞缺口处的背景单元格也涂为黄(4)。
7. 平移后的门框蓝(1)像素和红(2)标记保持不变。

**关键洞察**：灰色折线路径的几何走势是干扰项——无论路径多么曲折，只有两端彩色像素之间的净向量决定门框位移；求解者必须先正确解码位移、完成平移后才能确定走廊路线，两步之间存在不可跳过的信息依赖。
