## 新题 3：模板匹配选定精灵体拉伸入框

**组合逻辑**：[形状匹配/shape_match](已有) + [掩码相同/mask_equality](已有) → 目标选择(创新：匹配结果不是重涂色而是选定拉伸目标) → [拉伸/stretch](已有) + [包围盒映射/bbox_mapping](已有) + [线段连接再填充/connect_then_fill](已有) + [擦除/erase](已有)

**来源原语**：形状匹配、模板、框架、前景对象、掩码相同、模板选同形重涂 (参考题 #16 63613498)；拉伸、精灵体、空心矩形、包围盒映射、线段连接再填充 (参考题 #9 465b7d93)

**依赖链**：L形框架内的模板定义了目标形状掩码；该掩码在多个候选精灵体中筛选出唯一匹配者；被选中的精灵体随即被拉伸映射进空心矩形框架的内部；未匹配的精灵体和L形框架区域被保留。没有模板匹配就无法确定拉伸哪个精灵体；没有拉伸步骤就不知道如何填充空心框。

L形框架是形状选择器，空心矩形是拉伸画布；模板匹配将二者桥接。

**输入结构**：约 15x15 网格，黑(0)背景。组件如下：
- 灰(5) L形框架位于网格一角（竖直臂在右、水平臂在底），L形框架围合区域内有一个单色小模板图形（绿(3)，4-连通，3-6 像素，形状为不规则多连通体而非标准几何形），模板不接触L形框架。
- 一个橙(7)空心矩形框（1 像素厚，约 5x5 至 7x7 外径），位于网格另一区域，内部为背景。
- 3-4 个小型单色精灵体散布在两个框架之外，各有不同颜色（蓝(1)、红(2)、黄(4)、品红(6)），各 3-6 像素，4-连通。其中恰好一个精灵体的归一化掩码（平移无关形状）与模板一致，其余精灵体形状各不相同且与模板不同。
- 生成约束：匹配精灵体与模板的像素数相同且归一化后形状重合；其他精灵体的像素数或归一化形状至少有一项与模板不同。

**规则**：
1. 提取灰(5) L形框架围合区域内的绿(3)模板图形，计算其归一化掩码（将边界框左上角对齐到原点后的二值形状）。
2. 对框架外的每个精灵体计算归一化掩码，找到唯一与模板掩码一致的精灵体（不考虑颜色）。
3. 将匹配精灵体的边界框四角映射到空心矩形框内部区域的四角（左上对左上、右下对右下）。
4. 对于匹配精灵体中每对 4-连通相邻像素，在映射后的坐标之间画水平或垂直直线段，使用该精灵体的原色。
5. 用同一颜色填充由上述线段围合的封闭背景区域。
6. 擦除匹配精灵体在原位置的像素（设为背景）。擦除灰(5) L形框架及绿(3)模板（均设为背景）。
7. 未匹配的精灵体和橙(7)空心矩形框保持不变。

**关键洞察**：源题 #16 中匹配后只做重涂色，源题 #9 中只有唯一精灵体无需选择。此处模板匹配的输出不是颜色变换而是一个选择决策——在多个候选者中挑出拉伸对象。L形框架是"形状查询"，空心矩形是"画布"，两个框架功能完全不同却必须协同。

p = Path("/home/lixinyu/snap/a/key_combo/code/opus/3/005/3.py")
mod = SourceFileLoader("new_arc_task", str(p)).load_module()
sigs = set()
for i in range(100):
    inp = mod.generate_input()
    out = mod.main(inp)
    assert isinstance(inp, np.ndarray)
    assert isinstance(out, np.ndarray)
    assert inp.ndim == 2 and max(inp.shape) <= 30, f"input grid exceeds 30x30: {inp.shape}"
    assert out.ndim == 2 and max(out.shape) <= 30, f"output grid exceeds 30x30: {out.shape}"
    sigs.add(hashlib.md5(inp.tobytes() + str(inp.shape).encode()).hexdigest())
print("variants", len(sigs))
assert len(sigs) >= 20
