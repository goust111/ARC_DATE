## 新题 3：面积排名填色与轮廓厚度编码填充模式

**组合逻辑**：[计数](创新：同时计两种属性——内部面积和轮廓厚度) → [排序/面积排序](创新：面积排名映射到色键序列，而非直接输出颜色列) → [填充](创新：填充模式由轮廓厚度二值决定，实心或棋盘) + [棋盘格图案](创新：棋盘不再填满整个网格，而是限于单个闭合区域内部，且相位固定)

**来源原语**：计数(f8ff0b80/e50d258f)、面积排序(f8ff0b80)、填充(e9afcf9a)、棋盘格图案(e9afcf9a)、空心矩形(6b9890af)、裁剪区背景替换(a740d043)

**依赖链**：面积排名决定颜色分配（去掉排序则颜色无法确定）；轮廓厚度决定填充模式（去掉厚度检测则无法区分实心与棋盘）；两条规则交叉作用于同一区域——颜色来自排名链，模式来自厚度链，两者缺一不可。

多个空心矩形按内部面积从小到大对应色键行中从左到右的颜色，轮廓为 1 像素厚的实心填充，轮廓为 2 像素厚的棋盘填充。

**输入结构**：
- 约 20×20 的黑(0)背景网格。
- 网格顶部第 0 行有一行"色键"：K 个单像素，颜色互不相同且均非黑(0)和灰(5)，从左到右依次排列，彼此间隔 1 个黑像素。K 在 3~5 之间。
- 网格其余区域散布 K 个灰(5)空心矩形（即仅有边框，内部为黑(0)）。各矩形大小不同（内部面积互不相等），且边界框互不重叠。
- 每个矩形的轮廓厚度为 1 像素或 2 像素（即边框宽度为 1 或 2）。同一矩形四条边厚度一致。
- 生成约束：各矩形内部面积互不相等，保证排名无歧义。色键中颜色数量恰好等于矩形数量。

**规则**：
1. 计算每个灰(5)空心矩形的内部面积（边框内部的黑色像素数）。
2. 按内部面积从小到大排序，将色键行中从左到右的颜色依次分配给排序后的矩形（最小面积的矩形得到最左侧的颜色，依此类推）。
3. 检测每个矩形的轮廓厚度：
   - 厚度为 1：用分配到的颜色实心填充矩形内部（所有内部黑像素变为该颜色）。
   - 厚度为 2：用分配到的颜色与黑(0)交替的棋盘格填充矩形内部。棋盘格相位固定：内部区域左上角像素为分配颜色，右邻为黑(0)，逐列交替、逐行翻转。
4. 灰(5)轮廓像素保持不变。色键行保持不变。

**关键洞察**：颜色和填充模式由两条独立的属性链决定——面积排名选颜色，轮廓厚度选模式。仅看单个矩形无法确定其颜色（因为颜色取决于全局排名），必须对比所有矩形的面积才能推断。
