## 新题 5：去噪共识后按对称性重涂修复

**组合逻辑**：[单像素为噪声 → 擦除](创新：噪声过滤不是最终目的，而是共识投票的前置清洗) → [重复图块 + 多数投票共识 → 修复异常](已有) → [对称类型决定颜色 → 重涂色](创新：共识形状的对称性决定输出颜色，而非原色) + [受损副本被标记](已有)

**来源原语**：单像素为噪声(a09f6c25)、擦除(a09f6c25)、重复图块/分隔网格/多数投票共识/修复异常/受损副本被标记(e84fef15)、对称类型决定颜色/重涂色(a09f6c25)

**依赖链**：噪声过滤清洗每个图块 → 清洗后的图块参与多数投票 → 投票产生共识形状 → 共识形状的反射对称类别决定输出颜色 → 与共识不同的单个受损图块的损坏位置标记为灰(5)。噪声若未清除会污染投票，进而改变共识形状，进而改变对称分类和输出颜色——这是一条跨越三步的因果链。

从包含噪声和一个受损副本的重复图块阵列中，滤除噪声后投票恢复共识形状，根据共识形状的对称性分类决定输出颜色，并标记受损位置。

**输入结构**：约 20x20 的网格。一种分隔色（如灰(5)）形成单像素宽的横竖分隔线，将网格划分为 3x3 或 4x3 的等大图块阵列（每个图块约 4x4 至 6x6）。每个图块内部有一个由同一种非背景、非分隔色的颜色（如红(2)）组成的 4-连通图形，背景为黑(0)。所有图块是同一母图的副本，但：(a) 恰好一个图块有损坏——若干母图像素被覆盖为背景色；(b) 若干图块（含或不含受损图块）内散布了 1~2 个孤立单像素的随机彩色噪声点（颜色各异，与母图色不同）。生成约束：母图形具有恰好一种反射对称类别（水平/垂直/对角之一）；噪声像素不与母图像素 4-连通相邻；受损图块至少有 2 个像素被擦除。

**规则**：
1. 在每个图块内，删除所有孤立单像素（4-连通邻居中无同色像素的非背景像素），将其还原为背景。
2. 对清洗后的图块阵列执行多数投票：在每个图块局部坐标 (r, c) 处，取所有图块该位置颜色的众数作为共识颜色。
3. 找到与共识不同的唯一受损图块。
4. 判断共识形状的反射对称类别：
   - 仅有水平对称轴 → 输出颜色为蓝(1)
   - 仅有垂直对称轴 → 输出颜色为绿(3)
   - 有对角对称轴（含 90 度旋转对称等非正交反射） → 输出颜色为品红(6)
   - 同时有水平和垂直对称轴 → 输出颜色为黄(4)
5. 输出为单个图块大小的网格：用步骤 4 确定的颜色绘制共识形状，但在受损图块中被擦除的那些局部坐标位置改涂为灰(5)。

**关键洞察**：噪声看似无害（都是孤立像素），但如果不清除就投票，噪声像素可能恰好出现在多数图块的同一位置，伪造出"共识"——这会改变形状的对称性分类，导致输出颜色完全错误。
