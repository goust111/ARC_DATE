## 新题 8：骨架对齐传播标注到镂空体内部

**组合逻辑**：[矩形镂空体 + 擦除](创新：尾部擦除不是最终操作，而是为暴露内部骨架做准备) → [骨架对齐 + 锚点像素 + 旋转/镜像](已有) → [印章覆盖 + 完整标注传递副本](创新：印章区域被镂空体的矩形边界裁剪) → [视线可达](创新：标注像素只在镂空体开口方向一侧可见，另一侧被墙壁遮挡而不绘制)

**来源原语**：矩形镂空体/擦除(3d588dc9)、骨架对齐/锚点像素/旋转/镜像/精灵体/印章覆盖/完整标注传递副本(36d67576)、视线可达(3d588dc9)

**依赖链**：尾部擦除暴露镂空体内部的完整骨架 → 骨架对齐在镂空体之间建立旋转/翻转映射 → 标注从完整标注的镂空体传播到其他镂空体 → 但标注像素受镂空体矩形壁约束：只有从开口方向可见的标注位置才被绘制，被内壁遮挡的位置丢弃。空间容器（镂空体）同时是标注传播的载体和裁剪器。

擦除每个矩形镂空体的尾部后，利用内部骨架的锚点像素对齐各镂空体间的旋转关系，将完整标注体的装饰色传播到其他镂空体，但每个标注像素仅在从镂空体开口方向"可见"时才保留。

**输入结构**：约 25x25 的网格，背景为占主导的浅色（如灰(5)）。网格中有 3~4 个黑(0)的矩形镂空体——每个由一个实心黑色矩形（约 6x6 至 8x8）加上一条 2 像素的黑色尾巴构成，尾巴从矩形的某一边中央向外延伸（表示开口方向的反面，即尾巴所在侧为封闭侧，对侧为开口侧）。每个镂空体的矩形内部挖空为背景色，内部绘有一个由蓝(1)像素组成的小型骨架图案（3~5 像素，4-连通）和一个红(2)锚点像素。恰好一个镂空体在骨架上还附加了其他颜色的标注像素（如绿(3)、黄(4)），这是完整标注体。其余镂空体只有骨架和锚点。生成约束：所有镂空体内的骨架是同一图案的旋转/翻转变体（dihedral 群）；锚点在骨架中的局部位置固定；标注像素不与矩形内壁相邻。

**规则**：
1. 擦除每个镂空体的 2 像素尾巴（将尾巴像素改为背景色）。尾巴原来所在的侧为封闭侧，对侧为开口侧。
2. 以完整标注体为源模板。对每个非标注镂空体，找到唯一的旋转/反射变换使得源模板的蓝(1)骨架和红(2)锚点与目标镂空体的骨架和锚点重合。
3. 将源模板中所有非骨架、非锚点的标注像素位置通过该变换映射到目标镂空体的局部坐标系中。
4. 对每个映射后的标注位置 (r, c)，判断它是否位于目标镂空体矩形内部。若不在内部，丢弃。
5. 若在内部，进一步判断：从该位置沿开口方向（水平或垂直）到矩形边界之间是否有骨架像素阻挡。若无阻挡（视线畅通到开口边），绘制该标注像素。若有阻挡，丢弃。
6. 保留所有骨架、锚点和矩形边框。完整标注体自身保持不变。

**关键洞察**：骨架对齐和镂空体开口方向形成双重约束——对齐告诉你标注"应该"在哪里，但镂空体的开口方向过滤掉被自身骨架遮挡的标注位置，使得同一套标注在不同朝向的镂空体中呈现不同的可见子集。
