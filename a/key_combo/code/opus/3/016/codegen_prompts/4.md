## 新题 4：瓦片周期驱动双重操作——修复与压缩

**组合逻辑**：[补全](已有) + [压缩](创新：压缩的分块尺寸由推断出的瓦片周期决定) — 补全操作推断的瓦片周期同时作为压缩的分块参数，两个操作共享同一个推断结果

**来源原语**：补全/completion（参考 ca8f78db）、压缩/compress（参考 5783df64）、重复瓦片/repeating_tile（参考 ca8f78db）、遮挡区域/occluded_region（参考 ca8f78db）、分区网格/partitioned_grid（参考 5783df64）、稀疏前景像素/sparse_foreground_pixel（参考 5783df64）、可见像素约束推断/infer_from_visible（参考 ca8f78db）、分区采样/block_sampling（参考 5783df64）

**依赖链**：输入网格包含一个周期性瓦片图案，部分区域被黑色遮挡。首先从可见像素推断出最小重复瓦片的行周期 Pr 和列周期 Pc。用推断出的瓦片修复所有被遮挡的像素。然后以 Pr x Pc 为分块尺寸对修复后的网格做压缩——每个分块取其中心像素的颜色作为输出像素。推断瓦片周期是两个操作的共享前提：没有推断就无法修复也无法确定分块尺寸；修复失败则压缩采样到错误颜色。

从部分遮挡的周期性网格中推断最小瓦片，修复遮挡区域，再按瓦片周期大小压缩为缩略图。

**输入结构**：约 12x12 至 18x18 的网格（行列数分别是瓦片行周期 Pr 和列周期 Pc 的整数倍）。网格由一个 Pr x Pc 的最小瓦片（3x3 或 4x4）周期平铺而成，瓦片使用 2-3 种非黑颜色（如红(2)、蓝(1)、黄(4)）。1-3 个互不重叠的矩形黑(0)区域覆盖了部分瓦片像素。生成约束：遮挡区域不超过总面积的 40%；每个瓦片周期的每一行中至少有一个像素在某处可见（即可见像素覆盖了瓦片的所有残差类）；各遮挡矩形的边界不与瓦片周期边界对齐（避免整行/整列瓦片信息完全丢失）。

**规则**：
1. 将黑(0)像素视为未知。从所有非黑像素推断最小矩形周期 (Pr, Pc)，使得任意非黑像素 (r, c) 的颜色等于 (r mod Pr, c mod Pc) 处瓦片原型的颜色。保证推断结果唯一。
2. 用推断出的瓦片原型填充所有黑像素：像素 (r, c) 的颜色 = 瓦片原型 (r mod Pr, c mod Pc) 的颜色。
3. 将修复后的网格按 Pr x Pc 的分块大小划分为矩形块（保证整除）。每个块取中心像素 (floor(Pr/2), floor(Pc/2)) 处的颜色作为输出对应位置的像素。
4. 输出网格尺寸 = (输入行数 / Pr) x (输入列数 / Pc)。

**关键洞察**：瓦片周期既是修复的依据又是压缩的参数——这个双重角色必须通过观察多个不同周期大小的示例（如一个示例周期 3x3，另一个 4x4）才能归纳出"压缩分块尺寸 = 瓦片周期"这一非显然关系。

1. `main(grid)` 必须实现新题描述中的确定性转换规则，不能只识别 `generate_input()` 的固定模板。禁止不同的input网格输出相同的output网格。

3. 生成器必须保证输入满足 `main()` 的隐式假设：对象不重叠、不越界、特殊标记唯一或可区分、匹配关系无歧义、关键分支出现概率相同。
4. 禁止把 ARC 颜色 id 、亮度、拼写等当作人类不可见的数值语义参与排序、大小比较或隐藏映射。颜色变化必须有可见结构线索。注意颜色亮度、拼写等也是不可见信息，若描述中出现违规的颜色id或者亮度，可自行使用少量的固定颜色替代，但注意生成时要在三个以内输入输出网格中对所有变换100%覆盖度。
