## 新题 8：区域物体计数分派不同几何操作

**组合逻辑**：[计数](已有) + [按颜色条件分支](创新：分支条件从颜色类别变为数值区间) + [描边](已有) + [填充](已有) + [重涂色](已有)

**来源原语**：计数(counting) + 网格分区(grid_partition) + 四连通物体(four_conn_object) ← edcc2ff0, 6773b310；按颜色条件分支(color_conditional_branch) ← 2072aba6；描边(border_draw) + 沿边界绘边框(draw_border_frame) ← 6f8cd79b；填充(fill) ← 3eda0437；重涂色(recolor) ← edcc2ff0；分隔线(separator_line) ← 6773b310

**依赖链**：分隔线将网格划分为区域 → 统计每个区域内 4-连通前景物体的数量 → 数量落入不同区间触发不同的几何操作（0→不变，1→描边，2→全填充，3+→重涂色+描边）。这不是线性流水线而是条件分派结构：同一个计数结果导致不同输出形态，求解者必须同时学习计数规则和四个分支的映射。

根据分隔线分割出的每个区域内小物体的数量，对该区域施加不同的几何操作——从不变、描边、全填充到重涂色加描边。

**输入结构**：
- 背景：黑(0)，网格约 16x16。
- 灰(5)的完整宽度分隔行和完整高度分隔列将网格划分为 3x3 共 9 个矩形区域（每个区域约 4x4 内部单元）。
- 每个区域内包含 0~4 个小型 4-连通前景物体（每个物体 2~5 像素，颜色从蓝(1)、红(2)、绿(3)、黄(4)、橙(7)中取，同一区域内各物体颜色可相同或不同），散布在黑(0)背景上。物体形状各异，非固定几何模式。
- 生成约束：9 个区域中至少各有一个区域分别包含 0、1、2、3 个物体（保证四个分支都出现）。同一区域内的物体互不相邻（4-连通意义上各自独立）。

**规则**：
1. 对每个区域，统计其中 4-连通前景物体的数量 K（忽略物体颜色，仅计数独立连通分量）。
2. 根据 K 的值对该区域执行不同操作：
   - **K = 0**：该区域保持不变（全黑）。
   - **K = 1**：在该区域的内部边界（紧贴分隔线或网格边缘的一圈内侧单元）绘制青(8)边框，宽度 1 像素。区域内原有的单个物体保持不变。
   - **K = 2**：将该区域内部全部填充为蓝(1)，覆盖所有原有物体和背景。
   - **K >= 3**：将该区域内所有前景物体的颜色统一重涂为红(2)（形状保持不变），同时在该区域的内部边界绘制青(8)边框，宽度 1 像素。若边框位置与物体像素重叠，边框覆盖物体。
3. 灰(5)分隔线保持不变。

**关键洞察**：计数不是为了汇总信息，而是作为一个条件分派器——同一种"数数"操作的不同结果导向完全不同的几何变换，四个分支必须全部正确识别才能通过所有测试用例。
