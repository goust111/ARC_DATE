## 新题 7：外部标记计数覆盖弹射长度

**组合逻辑**：[弹射](创新：弹射长度由外部标记计数决定而非内部内容像素数) + [计数](创新：计数对象从区域内物体变为散布在全局的同色标记) + [擦除](已有) + [同色对应](已有)

**来源原语**：弹射(ejection) + 杯形框架(cup_frame) + 尾刺(tail_spike) + 内容像素(content_pixel) + 尾部朝向决定射出(tail_determines_emission) + 像素数守恒(pixel_count_conservation) ← 3dc255db；计数(counting) + 标记像素(marker_pixel) ← edcc2ff0, 6773b310；同色对应(same_color_match) ← 1b59e163

**依赖链**：杯形框架的尾刺确定弹射方向（保留原始机制）→ 散布在网格中与杯框同色的独立标记被计数 → 计数值替代内容像素数成为弹射长度 → 内容像素被擦除但不参与长度计算。尾刺决定"往哪射"，外部标记决定"射多远"，内容像素只是被清除的"废料"——三个信息源缺一不可。

杯形框架弹射一条射线，方向由尾刺决定，但射线长度等于网格中与杯框同色的独立标记数量，而非杯内内容像素的数量。

**输入结构**：
- 背景：黑(0)，网格约 18x18。
- 2~3 个杯形框架（U 形或类似凹形结构，各约 5x4 到 6x5 像素），每个框架的边框颜色各不相同（如蓝(1)、红(2)、绿(3)）。
- 每个杯框有一个收敛的尾刺在某一侧，开口（嘴部）在对侧。嘴部内部有 1~4 个橙(7)内容像素。
- 网格空白区域（杯框外部）散布着孤立的标记像素，颜色与某个杯框的边框色相同。例如：蓝(1)杯框对应 3 个散布的蓝(1)标记，红(2)杯框对应 1 个散布的红(2)标记。
- 生成约束：每种杯框颜色的独立标记数量与该杯内容像素数量不同（否则无法区分两种规则）。标记像素不与任何杯框相邻。至少有一个杯框的标记数 > 内容像素数，至少一个杯框的标记数 < 内容像素数。弹射路径上无其他非背景像素（直到网格边界）。

**规则**：
1. 对每个杯形框架，识别其尾刺方向：尾刺的外向方向（远离嘴部的方向）即为弹射方向。
2. 统计网格中与该杯框边框颜色相同的独立标记像素数量（不含杯框自身的边框像素）。记为 M。
3. 擦除杯框嘴部内的所有橙(7)内容像素为背景色。
4. 从尾刺尖端沿弹射方向画一条橙(7)直线段，长度为 M 像素（每个像素紧接前一个，从尾刺尖端的下一个单元开始）。超出网格边界的部分被截断。
5. 擦除所有独立标记像素为背景色。杯框的边框结构保持不变。
6. 各杯框的弹射独立执行。若两条弹射线段交叉，后处理的覆盖先处理的（处理顺序：按杯框尾刺尖端的行坐标从小到大，行相同则按列坐标从小到大）。

**关键洞察**：直觉上会假设弹射长度等于被清除的内容像素数量（源题 3dc255db 的规则），但实际长度由外部同色标记数量决定——这个"长度来源错位"需要对比内容像素数与弹射长度不一致的多个示例才能归纳出。
