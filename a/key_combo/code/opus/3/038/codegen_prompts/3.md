## 新题 3：对称掩码提取为周期平铺模板

**组合逻辑**：[裁剪+镜像检测→对称图案选取(已有)] → [异常值选择(创新：非对称掩码不再被丢弃，其包围框成为待填充区域)] → [平铺(创新：对称裁剪体不再是最终输出，而是成为周期平铺的瓦片模板)]

**来源原语**：裁剪、镜像、对称、颜色掩码、包围框、对称图案选取、异常值选择（参考题 d56f2372）；平铺、周期间隔（参考题 8403a5d5）；循环重复（参考题 12422b43）

**依赖链**：对称检测选出唯一模板 → 非对称掩码的包围框定义填充区域 → 对称模板被周期平铺到这些区域中。删除对称检测：不知道哪个掩码是模板→无法确定瓦片内容；删除非对称掩码的包围框定位：有模板但不知道铺在哪里；删除平铺：知道模板和区域但无变换输出。

从多种颜色掩码中选出唯一具有左右对称性的掩码裁剪体作为瓦片，擦除其余非对称掩码并在其原包围框范围内周期铺设该瓦片。

**输入结构**：约 18x18 网格，黑(0)背景。3-4 种非黑颜色各自形成一组像素（颜色掩码），每组可能由多个 4-连通部分组成。各颜色掩码的包围框互不重叠。恰好有一种颜色的掩码裁剪到包围框后呈左右镜像对称，其余颜色的掩码裁剪后均不对称。对称掩码的裁剪体尺寸不超过 5x5。非对称掩码的包围框尺寸至少为对称裁剪体尺寸的 2 倍（在行方向和列方向上均如此），保证能容纳至少 2x2 个瓦片。生成约束：对称掩码中非背景像素构成一个视觉上明确的对称图案（不同示例的具体形状不同），各掩码颜色互不相同。

**规则**：
1. 对每种非黑颜色，将该颜色的全部像素裁剪到其最小包围框，得到候选裁剪体（框内其他颜色位置视为黑(0)）。
2. 选出唯一满足"裁剪体等于其左右翻转"的候选，该裁剪体即为瓦片模板 T（尺寸 h x w）。
3. 记录所有非对称掩码的包围框（每个框为一个矩形区域）。
4. 擦除所有非对称掩码的像素（设为黑(0)）。
5. 在每个记录的包围框内，从包围框左上角开始，以周期 (h, w) 在行方向和列方向重复铺设瓦片 T。超出包围框边界的部分裁去。瓦片中非黑像素保留瓦片原色（即对称掩码自身的颜色），黑(0)像素位置保持黑(0)。
6. 对称掩码本身保留在原位不变。

**关键洞察**：对称性不是用来选出"答案"（与参考题 d56f2372 不同），而是用来选出"工具"——对称掩码变成了一把模具，而被它淘汰的非对称掩码反而用自身的空间位置定义了模具的使用范围。
