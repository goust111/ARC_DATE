## 新题 2：宽度门控的重力落种与容器填充

**组合逻辑**：[重力下落(已有)] + [宽度决定行为(创新：不再决定"穿透 vs 停靠于分隔行"，而是决定"能否通过杯口进入容器")] → [填充(已有，但填充颜色不再固定，而是由捕获的种子决定)] + [擦除(已有)]

**来源原语**：重力下落、精灵、分隔行、穿透与停靠、宽度决定行为（参考题 84ba50d3）；杯形容器、封闭区域、填充、内部包含、开口朝向（参考题 aba27056）；种子像素（参考题 8403a5d5）；擦除（参考题 d90796e8）

**依赖链**：杯口宽度筛选哪些种子能进入 → 重力确定种子的下落路径（列对齐） → 种子-容器匹配后种子颜色决定填充色 → 填充作用于杯形封闭区域。删除宽度门控：所有种子都能进入任何杯→错误匹配；删除重力：不知道种子到达哪个杯→无匹配；删除填充：知道匹配但无输出变换。

不同宽度的水平色条在重力下下落，只有宽度不超过杯口的色条能通过杯口进入杯内，捕获后以色条颜色填充杯的封闭区域。

**输入结构**：约 15x15 网格，黑(0)背景。底部区域有 2-3 个灰(5)色杯形容器，每个杯开口朝上、开口宽度各不相同（2-5 像素宽）。杯壁为灰(5)，杯内为黑(0)。顶部区域散布若干水平色条（每条由同色像素组成的 4-连通水平线段，宽度 1-4 像素），颜色各不相同且非灰非黑。每条色条占据一行中连续的若干列。色条之间不在同一行。生成约束：每个杯口正上方的列范围内最多只有一条能通过宽度门控的色条（避免歧义）；至少有一条色条因宽度超出所有杯口而无法进入任何杯。

**规则**：
1. 识别所有灰(5)杯形容器及其开口。开口定义为杯形包围框顶行中连续的非灰像素段，宽度为该段的像素数。
2. 识别顶部所有水平色条，记录每条色条的宽度和所占列范围。
3. 每条色条沿重力方向（向下）逐行移动。色条能通过一个杯的开口当且仅当：色条宽度 <= 杯口宽度，且色条的水平列范围完全包含在杯口的列范围内。
4. 色条在下落路径上遇到的第一个满足宽度门控条件的杯即为其目标杯。色条被该杯捕获。
5. 用捕获色条的颜色填充目标杯的全部封闭内部像素（原来的黑(0)像素改为色条颜色）。
6. 未被任何杯捕获的色条（宽度超出所有正下方杯口、或正下方无杯）从网格中擦除。
7. 杯壁（灰(5)）保持不变。未捕获任何色条的杯保持内部为黑(0)。
8. 被捕获的色条本身也从原位置擦除（不在原位保留）。

**关键洞察**：杯口宽度不仅是几何特征，更是一种物理筛选器——它将种子按尺寸分流到不同容器中，使得"什么颜色填什么杯"不由颜色匹配决定，而由几何兼容性决定。
