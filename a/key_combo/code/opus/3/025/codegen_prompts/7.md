**输入结构**：黑(0)背景，约 15x21 网格。一列灰(5)分隔列贯穿全高，将网格分为左面板和右面板。左面板包含一个蓝(1)源精灵体（4-连通，约 4x4 至 6x6 像素范围的不规则形状）。右面板被均匀划分为 2x2 或 2x3 个等大槽位（每个槽位大小与精灵体 bbox 相同），槽位之间由 1 像素宽的黑(0)间隔分开。部分槽位（2-4 个）各包含一个红(2)标记像素，标记像素不在槽位中心，而是偏向槽位的某个象限（左上/右上/左下/右下）。未标记的槽位为全黑。生成约束：不同槽位中的标记像素位于不同的象限位置。

**规则**：
1. 识别左面板的蓝(1)源精灵体和右面板中每个含红(2)标记像素的槽位。
2. 将源精灵体印入每个标记槽位（精灵体在槽位中居中放置，以精灵体 bbox 对齐槽位边界）。
3. 确定标记像素落在槽位的哪个象限：以槽位中心为分界，标记像素在左上/右上/左下/右下。若标记像素恰好在中心线上，按照先水平后垂直的优先级判断（中心线左侧算左，中心线上算右；中心线上方算上，中心线上算下）。
4. 仅保留该象限内的精灵体像素，将其余三个象限内的精灵体像素擦除为黑(0)。象限边界按槽位中心行/列划分。
5. 移除红(2)标记像素（设为黑(0)背景）。

**关键洞察**：标记像素在参考题 363442ee 中仅充当"选择开关"（有/无标记决定是否印章），但此处它的精确空间位置携带了额外信息——决定精灵体的哪一部分被保留。这意味着标记像素同时编码了"选中此槽位"和"从此方位裁剪"两层语义，需要对比多个标记位于不同象限的示例才能发现位置的作用。
