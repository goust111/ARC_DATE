**组合逻辑**：[计数](创新：统计重复对的数量作为构造参数) + [异常值选择] + [裁剪] + [外框绘制](创新：层数和颜色由其他对象的统计属性决定) + [图案匹配] + [擦除]

**依赖链**：图案匹配将精灵体分为重复组与异常体 → 重复对的数目 N 决定外框嵌套层数 → 各重复对的颜色按空间顺序映射为各层外框的颜色 → 异常体的裁剪结果成为嵌套中心内容。四条信息流（分类、计数、颜色序列、中心图案）汇聚于最终输出，缺少任何一条都无法确定结果。

统计重复精灵体对的数目 N，将唯一的异常精灵体作为中心，围绕它绘制 N 层同心外框，每层颜色取自一个重复对。

**输入结构**：约 15x15 网格，黑(0)背景。网格中散布 5-7 个小型 4-连通单色精灵体，每个精灵体由 3-6 个像素组成，边界框不超过 3x3。这些精灵体分为若干组：2-3 组重复对（同组两个精灵体的边界框裁剪图案完全相同，颜色相同，位置不同）以及恰好 1 个无配对的异常精灵体。每个重复对使用唯一颜色，从 {红(2), 蓝(1), 绿(3)} 中取用；异常精灵体使用黄(4)。各精灵体的边界框互不重叠，且异常精灵体位于网格中央区域（距离四边至少留出 N+1 格，N 为重复对数量），以保证外框有足够空间绘制。

**规则**：
1. 对每个 4-连通精灵体，裁剪其边界框（含框内黑(0)像素）作为标准图案。
2. 将图案完全相同（像素逐格比较）的精灵体配对。拥有唯一图案（无配对）的精灵体为异常体。
3. 统计重复对的数量 → N。
4. 将所有重复对按其两个精灵体的边界框中心的平均列坐标从小到大排序（列坐标相同则按平均行坐标从小到大）。排序后第 k 对（k 从 1 开始）对应第 k 层外框。
5. 以异常体的边界框为中心区域，向外逐层绘制 N 个同心矩形外框。第 k 层外框紧贴第 k-1 层外框外侧（k=1 时紧贴异常体边界框外侧），框宽 1 像素。第 k 层外框颜色为第 k 对重复对的颜色。
6. 擦除所有重复对精灵体（恢复为黑(0)）。保留异常体及其周围的嵌套外框。

**关键洞察**：重复精灵体不是干扰项——它们的数目编码了嵌套深度，它们的颜色编码了各层外框的色彩，它们的空间位置编码了颜色的排列顺序。异常精灵体则是嵌套的几何中心。所有精灵体共同携带构造输出所需的全部信息。
