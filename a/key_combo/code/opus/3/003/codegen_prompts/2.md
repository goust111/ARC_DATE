## 新题 2：锚点定向复制与矩形容器过滤

**组合逻辑**：[包含于边界框 in_bounding_box](已有，创新用途：过滤锚点目标) + [锚点对齐 anchor_alignment](已有) + [方向指示 dir_indication](创新：矩形上的标记决定副本镜像方向) → [平移复制 translate_and_copy](已有) + [镜像 mirror](条件性触发)

**来源原语**：平移复制/锚点对齐/锚点偏移对应(2c737e39), 包含于边界框/仅处理区域内标记(a04b2602), 镜像/方向指示/标记指示放置侧(760b3cac)

**依赖链**：矩形的边界框决定哪些目标锚点有效（过滤） → 矩形上的方向标记决定复制品是否镜像（朝向） → 源精灵体的锚点与有效目标锚点的偏移决定复制品的放置位置（定位） → 矩形框线在冲突时遮挡复制品（遮挡优先级）

一句话总结：将源精灵体按锚点偏移复制到矩形框内的目标位置，矩形边缘的方向标记决定副本是否水平翻转，框外的锚点是干扰项。

**输入结构**：黑(0)背景网格，约 18x18。包含以下元素：
- 一个多色源精灵体（由 2~3 种非背景颜色组成的 4-连通小图形，约 8~15 像素），其中恰好包含一个灰(5)像素作为源锚点。源精灵体形状不对称（水平翻转后与原形不同）。
- 2~4 个绿(3)空心矩形框（仅边框一像素宽，内部为黑色背景，尺寸至少 5x5），彼此不重叠且不与源精灵体重叠。每个绿矩形的左边框或右边框上恰好有一个栗(9)方向标记像素（位于该边框的中点位置）。
- 3~6 个孤立的灰(5)目标锚点像素，散布于网格各处。其中部分位于某个绿矩形的边界框内部（不在框线上），其余位于所有绿矩形边界框之外。
- 生成约束：源精灵体的尺寸小于任何绿矩形的内部空间，确保副本可以完整放入；各绿矩形之间、矩形与源精灵体之间至少间隔 2 像素；至少有一个目标锚点在矩形内部，至少有一个在矩形外部。

**规则**：
1. 识别源精灵体及其灰(5)源锚点。识别所有孤立灰(5)目标锚点（不属于源精灵体的灰像素）。
2. 过滤目标锚点：仅保留落在某个绿矩形边界框内部（严格在矩形内，不在框线上）的目标锚点。框外的目标锚点为干扰项，忽略。
3. 对每个有效目标锚点，确定其所在的绿矩形。检查该矩形的栗(9)方向标记位于左边框还是右边框。
4. 计算偏移向量：从源锚点到该有效目标锚点的行列差。
5. 将源精灵体的所有非灰像素按该偏移向量平移复制到目标位置。若方向标记在左边框，则先将精灵体图案水平镜像后再平移复制；若方向标记在右边框，则保持原朝向直接复制。
6. 绘制顺序与冲突解决：先保留所有绿矩形框线和栗标记，再绘制复制品。复制品的像素不覆盖绿框线和栗标记（框线优先级更高）。有效目标锚点在绘制复制品前擦除为黑(0)。多个复制品像素冲突时，所属矩形边界框面积较小的复制品优先。

**关键洞察**：绿矩形同时承担三重角色——过滤哪些目标锚点有效（容器）、通过方向标记决定副本朝向（编码器）、以及框线遮挡副本边缘（遮罩）。仅看一个示例中只有右标记矩形的情况，无法推断出左标记矩形要求镜像的规则。
