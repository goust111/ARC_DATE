## 新题 5：贪心正方形选择与邻接数标记

**组合逻辑**：[贪心选择 greedy_selection + 非重叠约束 + 从大到小优先](已有) → [计数 counting](创新用途：不再计数区域，而是计数选中方块之间的邻接关系) → [标记 marking + 角点邻接](创新：标记方式由邻接计数决定) + [重涂色 recolor](条件性触发)

**来源原语**：贪心选择/空白正方形区域/障碍像素/非重叠约束/从大到小优先/最小边长约束(31adaf00), 计数(89565ca0), 标记/角外像素/角点邻接/完整方块才标记(14b8e18c), 重涂色(多题)

**依赖链**：贪心选择确定哪些正方形区域被选中 → 选中方块构成一个邻接图 → 每个方块的邻接度数决定其标记方式 → 标记/重涂色的具体操作取决于邻接计数值

一句话总结：在障碍网格中贪心选取互不重叠的最大全黑正方形区域，然后根据每个选中方块与其他选中方块的邻接数量决定其着色和角标记方式。

**输入结构**：黑(0)背景网格，约 18x18。散布着灰(5)障碍像素，将空白区域分隔为各种不规则形状的黑色空间，其中部分区域可容纳边长 >= 2 的正方形。生成约束：确保经贪心选择后至少有 4 个不同的正方形被选中；选中方块中至少存在一个孤立方块（无邻接）、一个有恰好 1 个邻接的方块、和一个有 >= 2 个邻接的方块。

**规则**：
1. 搜索所有可能的全黑(0)正方形区域（边长 >= 2，区域内所有像素为黑色背景，不含灰障碍）。
2. 按边长从大到小排序。依次选择：若当前候选正方形与所有已选中方块无像素重叠，则选中；否则跳过。同一边长的候选按其左上角坐标从上到下、从左到右排序处理。
3. 将所有选中方块的内部像素涂为蓝(1)。
4. 计算每个选中方块的邻接度数：两个选中方块"邻接"当且仅当它们的边界像素之间存在至少一对 8-邻域相邻的像素（即两个蓝色方块之间的最小棋盘距离 <= 1）。
5. 根据邻接度数决定处理方式：
   - 度数 = 0（孤立）：保持蓝(1)，在该方块四个角的外侧各绘制 2 个红(2)标记像素（与角像素正交相邻的两个背景像素位置，如 14b8e18c 的角标记方式）。若标记位置不是黑(0)背景（如是灰障碍或其他方块），则该位置不绘制标记。
   - 度数 = 1（单邻接）：保持蓝(1)，仅在最靠近其唯一邻接方块的那两个角的外侧绘制红(2)标记（共 4 个标记像素）。"最靠近邻接方块的两个角"定义为：该方块四个角中，到邻接方块中心欧氏距离最小的两个角。
   - 度数 >= 2（多邻接）：将该方块从蓝(1)重涂为黄(4)，不绘制任何角标记。
6. 灰(5)障碍像素保持不变。

**关键洞察**：角标记的数量和位置不仅取决于方块自身的几何属性，更取决于贪心选择产生的全局邻接结构——改变一个障碍像素可能改变选择结果，进而级联改变多个方块的邻接度数和标记方式。单示例中如果所有选中方块恰好邻接度相同，则无法区分三种标记规则。
