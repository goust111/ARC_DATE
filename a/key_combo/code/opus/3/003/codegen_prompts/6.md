## 新题 6：完整方块的空心/实心分支处理

**组合逻辑**：[完整方块才标记 only_complete_marked](已有，作为第一级分支条件) + [包含关系/封闭孔洞 containment + enclosed_hole](创新用途：作为第二级分支条件) → [标记 marking + 角外像素](条件分支 A) / [填充 fill + 重涂色 recolor + 描边 draw_outline](条件分支 B) / [描边 draw_outline](默认分支)

**来源原语**：完整方块/角外像素/角点邻接/标记(14b8e18c), 封闭孔洞/包含关系/有孔触发重涂/描边/填充/重涂色(aa4ec2a5)

**依赖链**：完整方块检测（第一级分支）→ 空心/实心检测（第二级分支，仅对完整方块执行）→ 实心方块走角标记分支 / 空心方块走孔填充+重涂+描边分支 / 非方块走纯描边分支

一句话总结：检测前景对象是否为完整方块，再检测完整方块内部是否有孔洞——实心方块获得角标记，空心方块获得孔洞填充和边框重涂，非方块对象仅获得描边。

**输入结构**：黑(0)背景网格，约 16x16。包含 4~6 个 4-连通单色前景对象（每个对象由一种非背景颜色组成），颜色从蓝(1)、绿(3)、黄(4)、橙(7)、栗(9)中选取，不同对象颜色可相同也可不同。对象类型包括：
- 实心完整方块：边界框为正方形，且边界框边界上所有像素都填充为该对象颜色，内部也全部填充（无背景孔洞）。边长范围 3~6。
- 空心完整方块：边界框为正方形，边界框边界上所有像素都填充为该对象颜色，但内部包含一个或多个 4-连通的黑(0)背景孔洞。边长范围 4~6（至少 4 才能容纳内部孔洞）。
- 非方块不规则对象：4-连通的单色前景图形，边界框不是正方形，或边界框边界上存在缺失像素。大小 4~12 像素。
- 生成约束：至少包含一个实心完整方块、一个空心完整方块、和一个非方块对象。各对象彼此不相邻（8-邻域不接触），确保描边不会冲突。

**规则**：
1. 对每个 4-连通前景分量，检测是否为"完整方块"：其边界框必须为正方形（宽 = 高），且该边界框四条边上的所有像素都是该对象的颜色。
2. 对每个完整方块，检测是否"空心"：在边界框内部（不包括边界行列），是否存在至少一个 4-连通的黑(0)背景区域被该方块完全包围（该背景区域的泛洪填充无法到达网格边界）。
3. 分支处理：
   - **实心完整方块**：保持原色不变。在其四个角各自的外侧绘制 2 个红(2)标记像素——即与角像素正交相邻的两个外部位置（一个沿行方向，一个沿列方向）。若外部位置已被其他对象像素占据或超出网格边界，则不绘制该标记。共计最多 8 个红标记。
   - **空心完整方块**：将该方块的所有对象像素重涂为青(8)。将其内部所有封闭的黑(0)孔洞像素填充为品红(6)。然后绘制一圈红(2)描边：对该方块（含已填充孔洞区域）的每个像素，检查其 8-邻域中是否存在不属于该方块也不属于已填充孔洞的像素（即外部像素）；在所有这样的外部邻居位置绘制红(2)。若该外部位置已有其他对象像素，则不覆盖。
   - **非方块对象**：保持原色不变。仅绘制红(2)描边（规则同空心方块的描边步骤，但不做重涂和孔洞填充）。
4. 绘制顺序：先处理所有对象的内部变换（重涂、孔洞填充），再统一绘制所有描边和角标记。描边像素之间无冲突（因为对象彼此不相邻）。

**关键洞察**：同样是"完整方块"，空心和实心走向完全不同的处理路径——实心方块获得角标记（来自 14b8e18c 的逻辑），空心方块获得内部填充+重涂+描边（来自 aa4ec2a5 的逻辑）。仅看包含实心方块的示例无法推断空心方块的规则，反之亦然。两个来源题的规则在这里通过"空心/实心"判断交织成一个决策树。

3. 生成器必须保证输入满足 `main()` 的隐式假设：对象不重叠、不越界、特殊标记唯一或可区分、匹配关系无歧义、关键分支出现概率相同。
4. 禁止把 ARC 颜色 id 、亮度、拼写等当作人类不可见的数值语义参与排序、大小比较或隐藏映射。颜色变化必须有可见结构线索。注意颜色亮度、拼写等也是不可见信息，若描述中出现违规的颜色id或者亮度，可自行使用少量的固定颜色替代，但注意生成时要在三个以内输入输出网格中对所有变换100%覆盖度。
