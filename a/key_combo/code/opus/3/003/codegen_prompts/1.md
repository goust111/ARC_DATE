## 新题 1：十字线围合洪填

**组合逻辑**：[射线延伸 ray_extend](已有) → [行列交叉 row_column_crossing + 异源交叉特殊着色](已有) → [泛洪填充 flood_fill](创新：将十字线作为围合墙壁而非终态) → [重涂色 recolor](创新：填充色由围合边界的标记源数量决定)

**来源原语**：射线延伸/行列交叉/异源交叉着色(45bbe264), 泛洪填充/可达性(8f3a5a89), 重涂色(多题)

**依赖链**：射线延伸生成十字线网格 → 交叉点变红形成额外墙壁节点 → 十字线+交叉点共同围合出封闭区域 → 泛洪填充识别封闭区域 → 每个封闭区域的填充色取决于其边界上有几个不同标记源的十字线，该计数信息只有在射线全部画完后才能确定

一句话总结：将孤立标记像素扩展为全行全列十字线，然后根据每个被围合区域边界上来自几个不同标记的十字线数量来决定该区域的填充色。

**输入结构**：黑(0)背景网格，约 15x15。网格上散布 3~5 个孤立的非背景、非红色标记像素，每个标记颜色互不相同（从蓝(1)、绿(3)、黄(4)、灰(5)、品红(6)、橙(7)、青(8)、栗(9)中选取），且任意两个标记不在同一行也不在同一列。生成约束：标记数量和位置确保至少产生一个仅由两个标记的十字线围合的区域，以及至少一个由三个或更多标记的十字线围合的区域。

**规则**：
1. 对每个标记像素，将其所在整行和整列的所有背景像素(0)涂为该标记的颜色。标记像素本身保持原色。
2. 当来自不同标记的十字线交叉于同一像素时（即某标记的行线穿过另一标记的列线所在位置），将该交叉像素涂为红(2)。若某像素同时被同一标记的行线和列线覆盖（即标记自身位置），保持标记原色。涂色冲突解决：先绘制所有行线（按标记从上到下的行顺序），再绘制所有列线（按标记从左到右的列顺序），后绘制的覆盖先绘制的；最后将所有异源交叉点统一涂红。
3. 十字线将网格划分为若干矩形区域。对每个区域执行泛洪填充检测：从区域内任一背景像素出发，沿四方向扩展，以非背景像素（十字线、红色交叉点、标记像素）和网格边界为阻挡。如果该区域的所有背景像素都无法到达网格的任何一条边（即该区域被十字线完全围合），则该区域为"封闭区域"。
4. 对每个封闭区域，统计其边界上涉及几个不同标记源的十字线（每条十字线的颜色可追溯其来源标记；红色交叉点同时属于两个标记源）。若恰好 2 个不同标记源的十字线参与围合，将该区域内所有背景像素填充为黄(4)。若 3 个或更多标记源参与围合，填充为橙(7)。
5. 接触网格边的非封闭区域不填充，保持黑(0)。

**关键洞察**：十字线不是最终输出的主体，而是中间构造物——它们充当泛洪填充的墙壁。每个封闭区域的填充色不取决于任何单个标记的属性，而取决于围合该区域的十字线来自几个不同的标记源，这一信息只有在所有十字线全部绘制完毕后才可计算。
