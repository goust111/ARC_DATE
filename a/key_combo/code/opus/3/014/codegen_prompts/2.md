## 新题 2：分量内部厚度驱动同心环层数

**组合逻辑**：[重涂色·内部检测](创新：内部像素计数作为参数输出而非直接重涂目标) → [同心层填充](创新：层数由内部计数决定，非由对角标记序列长度决定) + [单点标记定心定色]

**来源原语**：实心内部(solid_interior, 09c534e7), 邻域全包含(full_neighborhood_inside_component, 09c534e7), 标记在分量内(marker_inside_component, 09c534e7), 同心层填充(concentric_fill, 99306f82), 嵌套层次(nesting_hierarchy, 99306f82), 单点标记(singleton_marker, 多题)

**依赖链**：对每个连通分量执行 3×3 邻域内部检测并计数 → 内部像素数 N 决定同心矩形环的层数 → 标记像素位置决定环中心、标记颜色决定交替色 → 分量中超出环范围的像素被擦除为背景

以每个前景连通分量的几何厚度（内部像素计数）决定围绕其标记像素绘制的同心矩形环层数，交替使用分量色和标记色。

**输入结构**：
- 约 15×18 网格，黑(0) 背景。
- 2~4 个互不相邻的同色（如蓝(1)）4-连通前景连通分量，各分量形状为不规则实心团块（非矩形，含凸出和凹陷），像素数在 8~30 之间，厚度不均——薄处 1~2 像素宽，厚处 3~5 像素宽——使得不同分量拥有不同数量的内部像素（范围 1~4）。
- 每个分量内恰好包含一个颜色不同于分量色的单点标记像素（如红(2)、绿(3) 等），标记位于分量的较厚区域，保证标记本身的 8 邻域全在分量内。
- 不同分量的标记颜色可以相同也可以不同。
- 生成约束：每个分量的内部像素数 N 定义为所有 8 邻域均属于同一分量的像素数量（标记像素不计入 N，但标记的 8 邻域属于分量则标记的邻居可能被计入）；N 在 1~4 之间；以标记为中心的 (2N-1)×(2N-1) 矩形区域不超出网格边界。

**规则**：
1. 对每个前景连通分量，找出所有内部像素——8 邻域全部属于该分量的像素（标记像素本身不计入内部像素）。记内部像素数为 N。
2. 以该分量的标记像素为中心，绘制 N 层同心矩形环：第 1 层为中心 1×1 像素，第 2 层为围绕第 1 层的宽 1 像素矩形环（整体形成 3×3），第 k 层形成 (2k-1)×(2k-1) 的外边框环。
3. 环的颜色从最外层向内交替分配：第 N 层（最外层）使用分量的原始颜色，第 N-1 层使用标记颜色，第 N-2 层使用分量色，依此类推。
4. 擦除该分量中所有不属于同心环 (2N-1)×(2N-1) 区域的像素（设为背景色(0)）。
5. 各分量独立处理；保留背景不变。

**关键洞察**：分量的几何厚度（内部像素计数）不再是直接重涂的目标区域（如源题 09c534e7 中内部被涂为标记色），而是控制另一种几何构造（同心环）的规模参数——必须先完成局部拓扑分析才能确定全局几何输出的形态。

p = Path("/home/lixinyu/snap/a/key_combo/code/opus/3/014/2.py")
mod = SourceFileLoader("new_arc_task", str(p)).load_module()
sigs = set()
for i in range(100):
    inp = mod.generate_input()
    out = mod.main(inp)
    assert isinstance(inp, np.ndarray)
    assert isinstance(out, np.ndarray)
    assert inp.ndim == 2 and max(inp.shape) <= 30, f"input grid exceeds 30x30: {inp.shape}"
    assert out.ndim == 2 and max(out.shape) <= 30, f"output grid exceeds 30x30: {out.shape}"
    sigs.add(hashlib.md5(inp.tobytes() + str(inp.shape).encode()).hexdigest())
print("variants", len(sigs))
assert len(sigs) >= 20
