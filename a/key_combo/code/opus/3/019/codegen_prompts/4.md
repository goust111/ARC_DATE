## 新题 4：桥接连通分量大小决定像素放大倍率

**组合逻辑**：[连通判定](经桥接路径将前景对象分组) → [计数](每组包含的对象数) → [像素放大](对象数即为该组每个对象的放大倍率) → [擦除](移除桥接路径)

**来源原语**：连通判定(connectivity_test) ← 239be575；计数(counting) ← 902510d5/8698868d；像素放大(pixel_scaling) ← 8719f442；擦除(erase) ← 902510d5；桥接路径(bridge_path) ← 239be575；前景对象(foreground_object) ← 239be575；计数决定尺寸(count_determines_size) ← 902510d5

**依赖链**：桥接像素的连通关系决定哪些对象属于同一组 → 组内对象数量成为所有组员共享的放大倍率 → 放大后的对象尺寸和位置取决于该数量 → 桥接像素在最终输出中被擦除，使得分组依据不再可见。

将散布的小型前景对象通过青色桥接路径分组，每组包含的对象数量即为该组所有对象的像素放大倍率；桥接路径最后被擦除。

**输入结构**：
- 网格约 12x12，黑(0)背景。
- 3-5 个小型单色前景对象，每个对象 2-4 像素，4-连通，颜色各异（可用红(2)、绿(3)、黄(4)、橙(7)、品红(6)）。对象间互不相邻。
- 青(8)桥接像素形成若干 4-连通路径，将部分对象连接起来（某个对象的某像素与青(8)路径的端点 4-相邻即视为连接）。某些对象不与任何桥接路径相连（孤立对象）。
- 生成约束：至少存在一个包含 2 个对象的连通组和一个包含 3 个对象的连通组（或一个孤立对象），以展现不同放大倍率；放大后的对象不超出网格边界（因此对象原始位置需靠近左上方且尺寸较小）；同一组内不同对象放大后不互相重叠。

**规则**：
1. 在所有非黑像素（前景对象 + 青(8)桥接像素）上做 4-连通分量分析，忽略颜色差异。每个连通分量构成一个"组"。
2. 统计每个组中包含的前景对象数量（一个对象 = 一个同色 4-连通区域，青色桥接不算对象），记为 S。孤立对象（无桥接连接）自成一组，S = 1。
3. 对每个组中的每个前景对象：以该对象边界框的左上角为锚点，将对象做 S 倍像素放大（每个原始像素变为 S x S 的同色方块）。放大后的像素仅覆盖黑(0)背景位置。
4. 若同组内两个放大后的对象发生重叠（生成约束应避免此情况，但作为兜底规则）：原始位置列号更大的对象绘制在上层。
5. 擦除所有青(8)桥接像素（设为黑(0)）。

**关键洞察**：桥接路径在输出中被擦除，但它决定了每个对象的放大倍率。求解者必须从放大倍率的差异反推出分组关系，进而理解输入中已不可见的桥接连接是分组依据。将更多对象桥接到同一组反而让每个对象变得更大——这种"连接越多越膨胀"的涌现效应是反直觉的。
