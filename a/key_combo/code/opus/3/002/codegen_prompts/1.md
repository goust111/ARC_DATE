## 新题 1：载体方向射线划分区域交替填色

**组合逻辑**：[射线延伸](创新：方向由载体颜色决定而非朝固定锚点) + [洪泛填充](创新：填充对象是射线划分出的子区域而非绿色边界围成的封闭区) + [交替着色](已有原语) + [遇障碍截断](已有原语)

**来源原语**：射线延伸(ray_extend) ← d43fd935/212895b5；载体区域(carrier_region) + 颜色决定方向(color_determines_direction) ← 9b4c17c4；洪泛填充(flood_fill) + 交替着色(alternating_coloring) ← 3bd292e8；障碍像素(blocker_pixel) + 遇障碍截断(truncate_at_blocker) ← 212895b5

**依赖链**：载体颜色决定射线方向 → 射线在载体内部形成结构性隔断 → 隔断将载体区域分割成子区域 → 子区域之间交替填色。射线的几何形态直接决定子区域的形状和邻接关系，进而改变交替填色的图案。删除任一环节均无法独立求解。

用载体颜色编码的方向射线将载体区域切割成子区域，再对子区域进行交替填色。

**输入结构**：约 15x15 的黑(0)背景网格。网格中有 2-3 个互不重叠的矩形色块区域，每个区域为蓝(1)或青(8)单色填充，宽度 5-8 像素、高度 4-7 像素。每个色块区域内部分布有 1-3 个红(2)单像素标记和 0-2 个黄(4)单像素障碍。标记和障碍不与区域边界像素重合，各标记在区域内的行位置互不相同（即同一载体内没有两个标记在同一行）。生成约束：每个载体区域至少有一个标记；标记与同行障碍之间至少间隔 1 个空格。

**规则**：
1. 对每个红(2)标记像素，根据其所在载体区域的颜色决定射线方向：蓝(1)载体内的标记向右延伸，青(8)载体内的标记向左延伸。
2. 射线沿水平方向逐像素绘制红(2)，遇到以下任一条件停止（不包含停止点本身）：(a) 到达载体区域的边界像素所在列；(b) 遇到黄(4)障碍像素。
3. 红色射线连同载体区域的边界共同将每个载体的内部划分为若干 4-连通子区域。以每个载体左上角像素所在的子区域为起始区域，将其填充为灰(5)；与起始区域隔一条射线相邻的子区域填充为绿(3)；再隔一条射线的子区域回到灰(5)，如此交替。
4. 红色射线像素、黄色障碍像素、载体边界像素均保持不变。黑色背景区域不受影响。
5. 若载体内无射线（无标记的载体不存在，受生成约束保证），整个内部为灰(5)。

**关键洞察**：射线不是装饰性的线条——它们是结构性的内部隔墙，其方向由载体颜色隐式编码。求解者必须同时推断方向规则和交替填色规则，仅看单个载体无法区分"蓝→右"还是"蓝→左"。
