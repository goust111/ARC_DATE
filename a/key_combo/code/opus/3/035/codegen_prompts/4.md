## 新题 4：穿越分裂后棋盘格填内部再四象限镜像

**组合逻辑**：[分裂 + 滑动](矩形穿越目标并分裂) → [填充 + 奇偶棋盘格](创新：对穿越后抵达边缘的矩形做棋盘格填充，而非对被分裂的目标) → [镜像 + 四象限排布](整幅画面做右-下镜像扩展)

**来源原语**：分裂、滑动、穿越并分开、实心矩形、网格边缘、轴线排列(9f669b64)；填充、矩形内部、棋盘格图案、边框与内部分离、行列奇偶决定填充(ba9d41b8)；镜像、四象限排布、翻转形成对称铺展(62c24649)

**依赖链**：穿越分裂改变了矩形的位置（移到边缘）和目标的形态（一分为二）——这决定了棋盘格填充的锚点位置和填充区域；镜像扩展使用的是经过分裂+填充后的完整画布，分裂的不对称细节通过镜像产生全局对称图案。三步环环相扣：分裂输出是填充的前提，填充输出是镜像的输入。

中央矩形穿越目标条至网格边缘并将目标分裂为两半，到达边缘的矩形内部被棋盘格填充，最后整幅画面做左右-上下镜像得到四象限对称输出。

**输入结构**：
- 网格约 8x8，背景黑(0)。
- 三个单色前景对象沿同一水平或垂直轴排列：
  - 轴一端：一个"推者"矩形，蓝(1)，宽 2 高 2~3（沿运动轴方向为高）。
  - 轴中间：一个"穿越者"矩形，橙(7)，宽 2 高 2~3，至少 4x4（沿运动轴方向为高，确保有内部区域）。
  - 轴另一端：一个"目标条"，绿(3)，长边垂直于运动轴，宽 1 高 4~6。
- 穿越者在推者与目标条之间。穿越者到目标条方向的网格边缘距离至少为穿越者的高加 2。
- 生成约束：穿越者至少 4x4（含边框和内部），以保证有非空内部可做棋盘格。

**规则**：
1. 穿越者沿"从推者指向目标条"的方向滑动，直至其边界框在该方向上与网格边缘齐平。
2. 穿越者在滑动路径上穿过目标条的位置，将目标条切为两半。两半各沿垂直于运动方向的方向向外平移 1 像素。
3. 擦除穿越者和目标条的原始位置（若尚未被覆盖则置黑）。推者保留在原位不变。
4. 对到达边缘的穿越者：保留其 1 像素宽的边框为橙(7)，对内部区域做棋盘格填充——以内部左上角像素为锚点，(行-锚行+列-锚列) 为偶数的填红(2)，奇数的保持黑(0)。
5. 将此时的完整画布作为"左上象限"，生成输出：右侧拼接其左右镜像，下方拼接上半的上下镜像，右下为双轴镜像。输出尺寸为输入的 2 倍宽、2 倍高。

**关键洞察**：棋盘格的奇偶锚点由穿越者的最终位置（紧贴边缘）决定，而非初始位置；镜像扩展让被分裂的不对称半条在输出中呈现对称，但棋盘格的相位在镜像后恰好翻转，产生视觉上的"反相对称"效果。
