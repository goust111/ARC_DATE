## 新题 6：旋转风车拼合产生涌现区域后面积定色

**组合逻辑**：[旋转 + 拼接](四旋转风车拼合) → [连通分量检测](创新：拼合接缝处的墙对齐情况产生源瓦片中不存在的涌现区域) → [重涂色 + 极值面积](对涌现区域做面积排名定色)

**来源原语**：旋转、拼接、正方形画布、阵列排布、四旋转组成风车(7fe24cdd)；连通区域、分隔墙、墙分隔区域、极值面积决定颜色(62ab2642)；重涂色(多题)

**依赖链**：旋转决定四个象限的墙布局；拼合后接缝处相邻象限的墙段可能对齐也可能不对齐——对齐处墙连通形成隔断，不对齐处黑色区域跨象限连通；这种涌现拓扑在源瓦片中看不到，必须完成拼合才能确定连通区域；面积排名在涌现拓扑上计算。

正方形瓦片内含灰墙分隔出若干黑色区域；将瓦片做四旋转风车拼合后，接缝处墙的对齐/错位产生源瓦片中不存在的涌现大区域，面积最大的涌现区域涂青，最小涂橙。

**输入结构**：
- 网格为 NxN 正方形（N = 5~7），背景黑(0)。
- 灰(5)像素构成 1 像素宽的墙段（水平或垂直线段），将黑色背景分为 3~5 个区域。墙段不一定与网格边缘相连——有些墙浮在网格内部。
- 另有 1 个蓝(1)像素位于任一黑色区域内，充当方向定位标记（不参与墙或区域计算，仅帮助确认旋转正确性）。
- 生成约束：在 2Nx2N 拼合结果中，4-连通黑色区域的数量与源瓦片中的区域数量不同（有区域因接缝处墙不对齐而合并，或因墙对齐而新增隔断）；面积最大和最小的黑色区域各唯一。

**规则**：
1. 以输入 NxN 瓦片为左上象限（原样），生成 2Nx2N 输出画布：
   - 右上象限：输入顺时针旋转 90 度。
   - 左下象限：输入逆时针旋转 90 度。
   - 右下象限：输入旋转 180 度。
2. 在 2Nx2N 画布中，以灰(5)像素为墙，找到所有 4-连通黑(0)区域（蓝像素视为黑色参与连通计算，但保留其颜色）。
3. 面积最大的黑色区域的所有像素涂青(8)；面积最小的黑色区域的所有像素涂橙(7)。
4. 蓝(1)像素保持蓝色（即使它所在的区域被涂色，蓝像素仍为蓝）。其余黑色区域和灰墙不变。

**关键洞察**：源瓦片中看到的区域在拼合后可能合并也可能被新隔断分开——关键在于接缝处相邻象限的墙段末端是否恰好对齐；这种对齐关系只有在理解旋转如何映射坐标后才能推断。
