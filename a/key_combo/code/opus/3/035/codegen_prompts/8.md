## 新题 8：中心投影种子间距决定同心边框层数

**组合逻辑**：[投影](创新：投影不是终态操作，而是为后续生长提供种子) → [生长 + 描边](创新：同心边框的层数由相邻种子间距决定，而非全局常数) → [重涂色](创新：边框颜色继承对应源对象的颜色)

**来源原语**：投影、前景对象、边行、中心对齐、对象中心在边行标(54d82841)；生长、描边、种子像素、同心方框层、间距决定同心重复(5c2c9af4)；重涂色(多题)

**依赖链**：每个前景对象的边界框中心列被投影到底行形成种子→相邻种子之间的列间距决定从该种子出发的生长层数→生长使用源对象的颜色而非统一色→对象的位置同时影响种子位置和层数参数，两者不可分离。

前景对象的水平中心被投影到底行产生种子标记；每个种子向上生长同心方框，层数等于它与最近邻种子的列间距；边框颜色继承源对象颜色。

**输入结构**：
- 网格约 18x18，背景黑(0)。
- 上半区（行 0~8 左右）分布 3~5 个单色 4-连通前景对象，每个对象 4~10 像素，颜色各不相同（从蓝(1)、红(2)、绿(3)、黄(4)、品红(6) 中取），形状为任意连通体（非矩形亦可）。各对象的边界框互不重叠，且边界框中心列互不相同。
- 下半区（行 9~17）为空（全黑），底行（最后一行）专用于放置投影标记。
- 生成约束：相邻种子的列间距至少为 3（保证生长空间）；种子数量使得每个种子到最近邻的距离在 3~8 之间。

**规则**：
1. 对每个前景对象，计算其边界框的中心列：center_col = 左列 + (右列 - 左列) // 2。在网格底行（最后一行）的 center_col 位置放置一个黄(4)标记像素。
2. 将所有底行标记按列从左到右排序。对每个标记，计算它与左侧最近标记的列间距 dL 和右侧最近标记的列间距 dR。取 d = min(dL, dR)；若只有一侧有邻居（最左或最右标记），则 d = 那一侧的间距。
3. 从每个标记位置出发，向上生长 d 层同心正方形边框：第 1 层为标记上方 1 格为中心的边长 3 正方形边框，第 2 层为边长 5，...，第 k 层为边长 (2k+1)。边框颜色使用投影到该标记的源对象的颜色（非黄色）。
4. 边框超出网格范围的像素舍弃。多个种子的边框在同一像素重叠时，层数更大的（离种子更远的）覆盖层数更小的；若层数相同，列号更小（更靠左）的种子的颜色优先。
5. 底行的黄(4)标记保留。上半区的源对象保留原色不变。未被覆盖的黑色像素保持黑(0)。

**关键洞察**：同心边框的层数不是固定的——它由相邻种子的间距决定，而间距来自对象的水平位置分布；对象越密集，投影种子越近，各自的生长层数越少；反之越多。必须对比多个示例中对象间距与生长层数的对应关系才能归纳出此规则。
