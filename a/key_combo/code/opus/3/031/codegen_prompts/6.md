## 新题 6：框体尺寸定缩放、框色过滤模板

**组合逻辑**：[像素放大/pixel_scaling](已有，但缩放因子由框体尺寸而非标记方块边长决定——创新) × [颜色匹配/color_match 过滤模板像素](创新：框色作为掩码选择模板中的特定颜色) + [擦除/erase 干扰标记](已有)

**来源原语**：像素放大/pixel_scaling、模板/template、缩放对应/scale_correspond、边长定缩放因子/side_sets_scale（参考题 447fd412）；空心框架/hollow_frame、颜色匹配/color_match（参考题 8f215267）；擦除/erase、忽略干扰项/ignore_distractors（参考题 8f215267, 817e6c09）；标记像素/marker_pixel（参考题 846bdb03）

**依赖链**：框体几何尺寸 → 推导缩放因子 → 缩放模板；框体颜色 → 过滤模板中同色像素 → 仅保留匹配色的缩放像素。框体同时编码两个独立参数（尺寸→缩放、颜色→过滤），删除任一解码路径都使输出不确定。

一个多色模板根据每个空心框的内部短边长缩放后，仅保留与该框颜色匹配的模板像素，填入框内。

**输入结构**：黑(0)背景，约 20x20 网格。网格左上角有一个小型多色模板图案（3x3 像素），模板中包含 2~3 种不同的非背景色（如红(2)、绿(3)、蓝(1)），每种颜色至少占 2 个像素。网格其余区域分布有 2~3 个空心矩形框（1 像素宽边框），每个框使用模板中出现的某种颜色（如一个红(2)框、一个绿(3)框）。不同框的内部尺寸（内部空间的短边长度）互不相同且均为模板边长（3）的整数倍，如内部为 3x3、6x6、9x9（对应缩放因子 k=1, 2, 3）。框与框之间不重叠，框不与模板重叠。在一些框的外侧附近有 1~2 个灰(5)干扰标记像素。生成约束：每个框的内部短边长是模板边长的整数倍。

**规则**：
1. 擦除所有灰(5)干扰标记像素（替换为黑(0)）。
2. 识别左上角的 3x3 模板图案。
3. 对每个空心矩形框：测量其内部空间的短边长度 S；计算缩放因子 k = S / 3（模板边长）。
4. 将模板按因子 k 像素放大（每个模板像素变为 k x k 块）。
5. 颜色过滤：在缩放后的模板中，仅保留与该框边框颜色相同的像素，其余像素变为黑(0)。
6. 将过滤后的缩放模板放置于框的内部空间，左上角对齐框内部的左上角。若缩放模板尺寸与框内部不完全匹配（因框为非正方形），多出的部分裁剪。
7. 框边框本身保留不变。

**关键洞察**：单个框同时编码两个信息维度——几何尺寸编码缩放因子，颜色编码模板过滤掩码。需对比多个示例确认缩放因子来自框的内部尺寸而非外部尺寸或面积，并确认颜色过滤保留的是与框同色的模板像素而非其他。
