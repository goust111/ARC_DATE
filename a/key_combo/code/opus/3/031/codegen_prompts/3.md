## 新题 3：方向耦合的反转印章与碰撞着色

**组合逻辑**：[颜色反转/color_invert](已有) → [印章覆盖/stamp + 对角偏移重复](已有，但原色与反色分别沿不同对角方向——创新耦合) → [碰撞检测着色](创新：两条轨迹重叠处产生第三种颜色)

**来源原语**：颜色反转/color_invert、二值图案/binary_pattern（参考题 48131b3c）；印章覆盖/stamp、对角偏移重复/diag_offset_repeat、尺寸决定步幅/size_determines_stride、实心矩形/solid_rect（参考题 e619ca6e）

**依赖链**：颜色反转产生反色副本 → 原色副本沿右下印章、反色副本沿左下印章 → 两条轨迹在交叉点产生碰撞 → 碰撞像素被赋予第三种颜色。删除反转则两条轨迹同色、无法区分方向；删除碰撞规则则交叉点处理不确定；删除对角印章则无交叉可碰撞。

将一个二值图案块沿右下对角印章原色副本、沿左下对角印章反色副本，在两条轨迹的交叉处将重叠像素标记为红(2)。

**输入结构**：黑(0)背景，约 25x25 网格。网格内有一个小型二值图案块：一个轴对齐的矩形区域（高 2~3、宽 3~4 像素），内含黑(0)和一种前景色（如蓝(1)）的混合图案。图案块位于网格中上部偏左位置，使得沿两条对角方向印章时，至少一对副本在网格内交叉。图案块不对称（左右翻转后图案不同），以确保原色轨迹与反色轨迹视觉可区分。生成约束：图案块位置保证两条对角轨迹在网格范围内至少有一个重叠区域。

**规则**：
1. 设图案块高 h、宽 w，前景色为 C。
2. 创建图案块的颜色反转副本：原图案中黑(0)像素变为 C，原 C 像素变为黑(0)。
3. 以图案块左上角为起点，沿右下对角方向在偏移 (h, w)、(2h, 2w)…处印章原色图案块（保持原始颜色），超出网格裁剪，完全超出后停止。
4. 以图案块左上角为起点，沿左下对角方向在偏移 (h, -w)、(2h, -2w)…处印章反色图案块，超出网格裁剪，完全超出后停止。
5. 原始图案块本身也保留在输出中（属于原色轨迹的第 0 个副本）。
6. 印章顺序：先绘制右下轨迹（从远到近），再绘制左下轨迹（从远到近），最后绘制原始图案块。
7. 碰撞规则：若某个像素同时被原色轨迹中的非黑像素和反色轨迹中的非黑像素覆盖（即两条轨迹都在该位置放置了前景色 C 的像素），则该像素最终变为红(2)。判定逻辑：对每个像素，记录它是否在原色轨迹中被赋予过 C，以及是否在反色轨迹中被赋予过 C；若两个记录都为真，最终颜色为红(2)，否则按最后一次印章的颜色绘制。

**关键洞察**：红(2)碰撞色不在输入中出现，是两条轨迹交叉的涌现结果。需对比多个示例确认三点：原色沿右下、反色沿左下；碰撞仅在双方都放置前景色时才发生（一方的黑色不算碰撞）；碰撞色固定为红(2)。
