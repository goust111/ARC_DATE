## 新题 2：对称性决定平铺翻转模式

**组合逻辑**：[对称检测/symmetry_detection](已有，但从布尔输出改为控制后续操作——创新) → [平铺/tiling + 条件性镜像/mirror](已有的平铺和镜像，但由对称检测结果分支决定——创新耦合)

**来源原语**：对称检测/symmetry_detection、镜像轴/mirror_axis（参考题 44f52bb0）；平铺/tiling、拼接/concatenation、奇偶位交替翻转/alternating_flip（参考题 bc4146bd）；镜像/mirror（参考题 846bdb03）

**依赖链**：检测每个精灵体是否具有左右镜像对称性 → 对称结果决定平铺时是否在偶数位置翻转 → 最终平铺结果取决于对称检测。删除对称检测则无法确定使用哪种平铺方式；删除平铺则对称检测结果无处应用。

检测每个小精灵体的左右对称性，对称者平铺为 5 份均一条带，不对称者平铺为 5 份交替翻转条带，再按颜色标记顺序纵向堆叠。

**输入结构**：黑(0)背景，约 20x25 网格，分为上下两区。上区包含 2~3 个互不相邻的小型单色精灵体，每个精灵体是一个 4-连通的单色区域（3~8 像素），使用不同的前景色（如蓝(1)、绿(3)、橙(7)），每个精灵体严格包含在一个 3x4 或 4x4 的边界框内。其中部分精灵体具有左右镜像对称性，部分不具有。下区是一行颜色标记像素，从左到右排列，每个标记像素的颜色对应上区某个精灵体的颜色，标记像素之间间隔 1 列，标记像素的颜色不重复，且与上区精灵体颜色一一对应。生成约束：至少一个精灵体对称、至少一个不对称。

**规则**：
1. 对每个精灵体，提取其边界框内容（包含精灵体像素和黑色背景像素）作为瓦片单元。
2. 检测瓦片单元是否具有左右镜像对称性（将瓦片水平翻转后，非背景像素的相对位置与原瓦片完全一致即为对称）。
3. 若对称：将瓦片水平拼接 5 份，全部使用原始朝向，构成一条水平条带。
4. 若不对称：将瓦片水平拼接 5 份，第 1、3、5 份使用原始朝向，第 2、4 份使用左右镜像，构成一条交替翻转的水平条带。
5. 按下区颜色标记像素的从左到右顺序，依次将对应精灵体的条带纵向堆叠（第一个标记对应的条带在最上方）。条带之间无间隔。
6. 输出仅包含堆叠后的条带区域，输出尺寸 = 条带高度之和 x 条带宽度。

**关键洞察**：对称检测的结果不再是一个颜色指示像素（如参考题 44f52bb0），而是一个控制后续平铺算法的分支条件。需要对比多个示例才能发现：对称精灵体使用均一平铺，不对称精灵体使用交替翻转平铺，且条带堆叠顺序由标记像素而非空间位置决定。
