## 新题 8：重力对齐后按原始高度排名交替着色

**组合逻辑**：[对齐/align 至基线](已有，但对齐擦除了原始位置信息——创新设置) → [排序/sorting 按原始高度](创新：排序依据是变换前的属性而非变换后的) → [重涂色/recolor + 奇偶交替选择/alternating_parity_selection](已有的交替选择，但基于原始高度排名——创新耦合)

**来源原语**：对齐/align、基线对齐/baseline_aligned、标记行/marker_row（参考题 41ace6b5）；排序/sorting、沿轴排列/axis_arrangement（参考题 817e6c09）；重涂色/recolor、奇偶交替选择/alternating_parity_selection（参考题 817e6c09）；小方块/small_square（参考题 817e6c09）；忽略干扰项/ignore_distractors（参考题 817e6c09）

**依赖链**：记录每个方块的原始行位置 → 将所有方块下落至基线行上方 → 按原始行位置（离基线越远排名越前）排序 → 排名奇偶决定着色。对齐操作抹去了空间信息，但颜色编码了被抹去的信息——删除对齐则无法产生正确的空间布局；删除基于原始高度的排序则无法确定着色。

散落在不同高度的同色方块下落至基线后，按其原始距离基线的远近排名，交替涂为两种颜色。

**输入结构**：黑(0)背景，约 15x20 网格。网格中有一条水平灰(5)标记行位于下方（约第 15 行），宽度占满整行。标记行上方散布着 4~6 个蓝(1)小方块（每个 2x2 像素），各方块占据不同的列（每列至多一个方块），且各方块的底边到标记行的距离互不相同。方块之间水平不相邻（列间距至少 1）。生成约束：所有方块的底边到标记行的垂直距离互不相同，以确保排名无歧义。

**规则**：
1. 保留灰(5)标记行不变。
2. 记录每个蓝(1)方块的底边行号，计算其到标记行的垂直距离 d（标记行行号减去方块底边行号）。
3. 将所有方块下移至标记行正上方：每个方块的底边行号变为标记行行号减 2（因方块高 2 像素，底边紧贴标记行上方一行），列位置保持不变。
4. 按原始垂直距离 d 从大到小排序所有方块，排名从 0 开始（原始位置离标记行最远的方块排名 0）。
5. 排名为偶数（0, 2, 4, ...）的方块重涂为青(8)。
6. 排名为奇数（1, 3, 5, ...）的方块重涂为红(2)。
7. 方块的原始位置上留下黑(0)背景（方块已移走）。

**关键洞察**：下落后所有方块对齐到同一行，空间上无法区分谁原来更高，但颜色编码了这一被抹去的信息。仅看输出无法判断着色依据（因为方块已在同一行），必须结合输入的原始高度才能理解交替规则。需对比多个示例确认排序依据是原始垂直距离而非列位置。
