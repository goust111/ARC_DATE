## 新题 6：跨尺度异或合成与频率定位框选

**组合逻辑**：[形状匹配/跨尺度同形](已有，创新：匹配后不裁剪返回，而是用于生成对齐掩码) → [异或合成/恰一为前景](已有，创新：两个掩码不是空间对齐的半区，而是通过缩放对齐) → [频率唯一性/最低频色定位](已有，创新：频率分析作用于异或结果而非原始输入) → [描边/框](已有)

**来源原语**：形状匹配/跨尺度同形/返回较小者(ce602527), 缩放对象/干扰对象(ce602527), 异或合成/对齐/恰一为前景(31d5ba1a), 前景掩码/半区掩码(31d5ba1a), 计数/频率唯一性/最低频色定位目标(31aa019c), 描边/框(31aa019c)

**依赖链**：在三个对象中匹配跨尺度同形对 → 将较小对象放大至与较大对象同尺寸 → 两个同尺寸掩码执行异或合成 → 异或结果中存在多种颜色区域(来自两个对象的不同原色) → 统计异或结果中各颜色的像素数量 → 频率最低的颜色像素位置被框选输出

找到跨尺度匹配的形状对，将小形状放大后与大形状异或，在差异区域中定位出现频率最低的颜色并用框标记。

**输入结构**：约 16x16 的网格，黑(0)背景。包含三个不同颜色的 4-连通前景对象：对象 A 为蓝(1)，较大（约 6x6 边界框内的不规则图形）；对象 B 为绿(3)，较小（约 3x3 边界框），与对象 A 形状相同但缩小 2 倍；对象 C 为橙(7)，与 A、B 形状均不同（干扰对象）。三个对象互不相邻，各自独立。生成约束：对象 A 和 B 的形状在 2 倍缩放下完全匹配（B 放大 2 倍后与 A 的掩码逐像素一致，忽略颜色）；对象 A 允许部分超出画布边界（被裁剪），此时 B 放大后同样在对应位置裁剪；对象 A 和 B 的形状差异（若 A 被裁剪导致掩码不完全对称）使异或结果中至少有一个颜色的像素数明显少于另一个。

**规则**：
1. 将三个对象按颜色分离。尝试对每对对象进行缩放匹配（将较小者放大 2 倍），找到掩码完全匹配的一对（A 和 B）。
2. 将较小对象 B 放大 2 倍，对齐到对象 A 的边界框左上角。放大后的 B 掩码中前景像素保持绿(3)。
3. 在对象 A 的边界框范围内执行异或合成：仅 A 有前景的位置输出蓝(1)，仅放大 B 有前景的位置输出绿(3)，两者都有或都没有的位置输出黑(0)。
4. 统计异或结果中蓝(1)和绿(3)像素的数量。找到数量较少的那种颜色（频率最低色）。
5. 输出：在与输入同尺寸的黑(0)网格上，找到所有频率最低色像素的位置（这些位置在原始输入中属于对象 A 的边界框区域），对每个这样的像素用红(2)绘制 3x3 框（该像素为中心，周围 8 格涂红(2)，中心像素保持其异或结果颜色）。框超出网格边界的部分舍弃。多个框重叠时红(2)简单叠加（不影响，因为都是红(2)）。
6. 干扰对象 C 不出现在输出中。

**关键洞察**：跨尺度匹配在源题中用于选择并裁剪返回较小者，此处创新为用匹配生成对齐条件以进行异或合成——匹配不再是终点而是中间步骤。异或合成在源题中作用于空间对齐的两半，此处作用于通过缩放对齐的两个对象。频率分析在源题中作用于原始输入，此处作用于异或合成的计算结果。三个来自不同源题的原语形成了一条全新的信息传递链：匹配→缩放对齐→异或→频率分析→框选。
