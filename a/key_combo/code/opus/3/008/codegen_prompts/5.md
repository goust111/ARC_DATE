## 新题 5：隐含十字中心驱动距离递变楔形生成与孤立条擦除

**组合逻辑**：[隐含十字检测/缺失中心](已有) → [距离递变/填充/三角楔形](已有，创新：锚点不是给定的线段而是检测出的隐含中心) → [擦除](已有，创新：擦除判据来自检测结果的反面——未构成十字的条) + [冲突解决](创新：楔形与原有微型条重叠时的优先级规则)

**来源原语**：重涂色/缺失中心(9f5f939b), 微型条/隐含十字/四向对齐(9f5f939b), 填充/距离递变/逐行宽度递变成楔(a65b410d), 三角楔形/线段(a65b410d), 擦除(47c1f68c/31aa019c)

**依赖链**：检测隐含十字 → 中心标记为黄(4)并成为楔形锚点 → 从每个锚点向上下扩展距离递变楔形 → 楔形基宽由该十字的水平臂跨度决定 → 未参与任何十字结构的孤立微型条被擦除 → 楔形像素与十字微型条像素重叠时，微型条优先保留

检测微型条构成的隐含十字，以中心为锚生长楔形区域，同时清除不属于任何十字的孤立条。

**输入结构**：约 15x15 的网格，黑(0)背景。蓝(1)的水平和垂直二像素微型条散布在网格中，总数约 18~30 个。其中若干条在四个基方向上围绕空白中心排列（中心与条之间隔 1 像素），形成 2~4 个隐含十字。剩余微型条不属于任何十字（孤立条）。生成约束：不同十字中心之间至少相隔 5 行，使各自的楔形区域不完全重叠；每个十字的水平臂（左右各一条水平微型条）总跨度为 6 像素（中心 1 + 间隔 1 + 条 2 + 间隔 1 + 条 2 - 1 = 6，含中心）。若两个十字的楔形确有部分重叠，按先上后下、先左后右的锚点处理顺序处理，后处理的楔形不覆盖已有非黑非蓝像素。

**规则**：
1. 检测所有隐含十字中心：对每个黑(0)像素，检查上、下、左、右偏移 2~3 格处是否各有一根方向匹配的蓝(1)二像素条（水平条在左右，垂直条在上下）。四个方向均满足则标记该中心为黄(4)。
2. 对每个检测到的黄(4)中心，计算其水平臂总跨度 W（左侧水平条最左像素到右侧水平条最右像素的距离 +1）。W 即为楔形基宽。
3. 从中心向上生长绿(3)楔形：中心行宽度为 W，向上每行宽度 +1（左右各扩 0.5 取整，交替扩左/扩右），直到宽度达到网格宽度或碰到网格上边界时停止。楔形水平居中于中心列。
4. 从中心向下生长栗(9)楔形：中心行宽度为 W，向下每行宽度 -1（左右各缩 0.5 取整，交替缩左/缩右），直到宽度缩为 0 时停止。楔形水平居中于中心列。
5. 识别所有未参与任何隐含十字结构的蓝(1)微型条（即既不是某十字的水平臂也不是某十字的垂直臂），将这些孤立条的像素设为黑(0)。
6. 冲突解决：参与十字的蓝(1)微型条像素优先于楔形像素（楔形不覆盖蓝(1)）。黄(4)中心像素优先于一切。多个楔形重叠时，锚点行号较小（靠上）的楔形优先；行号相同则列号较小（靠左）的优先。

**关键洞察**：同一批微型条在逻辑中承担双重身份——构成十字的条提供检测信号并决定楔形参数，不构成十字的条则被擦除。检测结果同时驱动"建造什么"（楔形）和"拆除什么"（孤立条），这种对称的生灭逻辑在源题中不存在。解题者必须先发现哪些条属于十字、哪些不属于，才能同时理解楔形的来源和条的消失规律。
