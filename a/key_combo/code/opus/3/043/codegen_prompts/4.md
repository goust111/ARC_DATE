## 新题 4：路径钉住行列的选择性压缩

**组合逻辑**：[压缩](合并相邻重复行列) ⊗ [路径绘制](路径像素阻止其所在行列被合并) — 两个机制同时约束输出，非线性先后

**来源原语**：压缩(compression)←ce8d95cc, 路径绘制(path_drawing)←891232d6, 重复行(dup_row)←ce8d95cc, 重复列(dup_column)←ce8d95cc, 路径网络(path_network)←d35bdbdc, 相邻相同(adjacent_identical)←ce8d95cc, 相同行列合并(merge_identical)←ce8d95cc, 路径连通(path_connectivity)←d35bdbdc

**依赖链**：压缩规则要求合并相邻相同的行/列 → 但路径像素所在的行/列被豁免合并 → 路径的空间位置因此直接影响压缩结果的几何形状。移除压缩则输出等于输入（错误）；移除路径豁免则全压缩丢失路径结构（错误）。两者同时约束输出。

对一个行列拉伸过的网格做压缩，但包含灰色路径像素的行和列被路径"钉住"，不参与合并，从而产生局部压缩、局部保留的非对称输出。

**输入结构**：约 16x16 网格。网格是一个小图案（约 6x6）沿行和列做游程扩展后的结果：部分相邻行完全相同，部分相邻列完全相同。图案使用 2~3 种前景色（如红(2)、蓝(1)）在黑(0)背景上。灰(5)像素形成一条 4 连通路径，穿越网格中部分重复行和重复列区域。路径宽度为 1 像素。路径像素替换了图案中的对应位置像素（即路径像素所在格的原始图案色被灰(5)覆盖）。生成约束：路径至少经过 2 个不同的重复行带和 2 个不同的重复列带；路径不经过的某些重复带仍然存在（以便展示正常压缩效果的对比）。

**规则**：
1. 标记所有包含至少一个灰(5)路径像素的行为"钉住行"，所有包含至少一个灰(5)路径像素的列为"钉住列"。
2. 行压缩：从上到下扫描行。对于相邻的连续相同行组成的"行带"（忽略灰(5)像素后其余像素完全相同的行也算相同）：
   - 若行带内无任何钉住行：合并为一行，保留行带中的第一行。
   - 若行带内存在钉住行：该行带内每一行均单独保留，不合并。
3. 列压缩：对行压缩后的结果，从左到右扫描列，应用完全对称的规则：
   - 无钉住列的相邻相同列带合并为一列。
   - 有钉住列的列带内每列单独保留。
4. 输出为选择性压缩后的网格。灰(5)路径像素在输出中保持原位。

**关键洞察**：路径不只是视觉元素——它在结构上阻止了所经过区域的行列合并，使得同一个拉伸图案的不同区域以不同的比率被压缩。求解者必须发现路径对压缩的抑制作用。

    sigs.add(hashlib.md5(inp.tobytes() + str(inp.shape).encode()).hexdigest())
print("variants", len(sigs))
assert len(sigs) >= 20
