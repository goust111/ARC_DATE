## 新题 8：框缝射线长度编码拉伸系数

**组合逻辑**：[射线延伸](从带框块缝隙向外发射射线) → [计数](射线长度作为数值) → [拉伸](用射线长度作为参考面板的拉伸系数)；射线的空间测量结果跨区域地参数化了另一个操作

**来源原语**：射线延伸(ray_extend)←e12f9a14, 拉伸(stretch)←9841fdad, 带框块(framed_block)←e12f9a14, 框架缺口(frame_gap)←e12f9a14, 参考面板(reference_panel)←9841fdad, 压缩与展开(compress_expand)←9841fdad, 连接跨越(connection_span)←9841fdad, 碰撞停止(collision_stop)←e12f9a14

**依赖链**：框缝位置和方向决定射线路径 → 射线遇到障碍或边界时停止，长度被测量 → 水平射线长度成为水平拉伸系数，垂直射线长度成为垂直拉伸系数 → 参考面板按这两个系数被拉伸。移除射线则拉伸系数未知；移除拉伸则参考面板无法变换；两个射线分别贡献水平和垂直参数。

两个带框方块的缝隙分别朝水平和垂直方向发射射线，射线在碰到障碍或网格边缘时停止；两条射线的长度分别作为参考面板内容的水平和垂直拉伸系数。

**输入结构**：约 18x18 网格，黑(0)背景。左上角有一个灰(5)边框包围的参考面板，内部为一个小型彩色图案（2x3 或 3x2，使用红(2)、蓝(1)等前景色，黑(0)背景）。网格中另有 2 个带框块：每个是 4x4 的绿(3)方框包围 2x2 的单色内部（如黄(4)和橙(7)），方框上恰有 1 个缺口像素（绿(3)被黑(0)替换）。一个带框块的缺口朝水平方向（缺口在框的左侧或右侧中间），另一个缺口朝垂直方向（缺口在框的上侧或下侧中间）。两个带框块之间、以及带框块与参考面板之间有足够间距（至少 3 格黑(0)背景）。生成约束：每条射线到达障碍或边界前至少经过 2 格背景，保证拉伸系数 >= 2。

**规则**：
1. 保留输入网格中的所有像素。
2. 对每个带框块，从其缺口位置向外（远离框中心的方向）发射一条射线，颜色为该框内部 2x2 块的颜色。射线逐格延伸，涂过的每个黑(0)背景格变为该颜色。
3. 射线在遇到以下情况时停止（最后一个涂色格为停止前一格）：下一格为非黑(0)像素（任何前景色、框、面板边框等），或下一格超出网格边界。
4. 测量每条射线的长度 L（射线涂色的背景格数）。
5. 确定拉伸系数：
   - 缺口朝水平方向的框的射线长度 = 水平拉伸系数 H。
   - 缺口朝垂直方向的框的射线长度 = 垂直拉伸系数 V。
6. 将参考面板内部图案（不含灰(5)边框）做最近邻拉伸：每个像素在水平方向重复 H 次、在垂直方向重复 V 次。
7. 将拉伸后的图案放置在参考面板的原始位置，覆盖原参考面板及其灰(5)边框。若拉伸后图案超出原面板区域，向右和向下扩展，覆盖对应的背景格。若拉伸后图案与带框块或射线重叠，拉伸图案优先覆盖。
8. 带框块和射线保留在输出中（除非被拉伸图案覆盖）。

**关键洞察**：射线不是装饰性输出——它们的长度是对空间距离的测量，被用作另一个完全不同的操作（拉伸）的参数。求解者必须发现射线长度与拉伸系数之间的跨区域数值对应关系。

4. 禁止把 ARC 颜色 id 、亮度、拼写等当作人类不可见的数值语义参与排序、大小比较或隐藏映射。颜色变化必须有可见结构线索。注意颜色亮度、拼写等也是不可见信息，若描述中出现违规的颜色id或者亮度，可自行使用少量的固定颜色替代，但注意生成时要在三个以内输入输出网格中对所有变换100%覆盖度。
