## 新题 3：射线屏障阻断顺时针角落复制

**组合逻辑**：[射线延伸 + 端点发射](已有) → [碰撞停止](已有) → [射线形成屏障](创新：射线的作用从视觉标记变为逻辑门控) → [顺时针角落复制](已有，但受屏障条件门控)

**来源原语**：射线延伸/ray_cast、端点发射/emit_from_endpoints、碰撞停止/collision_stop、对角线段/diagonal_segment（80a900e0）；复制/copy、顺时针到下一角/clockwise_next、角落对象/corner_object、接触两边缘/touching_two_edges（bc93ec48）

**依赖链**：对角线段的端点发射射线 → 射线遇非背景像素或边缘停止 → 射线像素构成屏障 → 检查每个角落对象到其顺时针下一角的边缘路径是否被射线阻断 → 未阻断则复制，阻断则不复制。删除射线则所有角都复制（退化为 bc93ec48）；删除复制规则则射线无意义。

对角线段端点发射射线形成屏障线，角落对象只有在通往顺时针下一角的边缘路径未被射线阻断时才执行复制。

**输入结构**：
- 背景：黑(0)。网格约 15x15。
- 2~4 个彩色角落对象，各自锚定在网格的不同角（触及该角的两条边缘），每个对象 4-连通、4~8 像素、颜色互不相同（选自红(2)、绿(3)、蓝(1)、黄(4)）。
- 1~2 条短对角线段，每条 2~3 像素长，颜色灰(5)，位于网格边缘附近但不在角落区域内。
- 生成约束：对角线段的位置使得从其端点向外发射的对角射线（方向为远离网格中心的对角方向）恰好穿过某些"边缘路径带"（连接相邻两角的行带或列带），从而阻断部分顺时针复制，但不阻断全部。至少有一个角落对象的复制被阻断，至少有一个不被阻断。

**规则**：
1. 保持所有已有元素不变。
2. 对每条灰(5)对角线段，从其两个端点分别发射一条对角射线。射线方向为远离网格中心的对角方向（即朝最近的网格角方向）。射线逐格延伸，将经过的背景像素涂为灰(5)，遇到非背景像素或到达网格边缘时停止（停止点不涂色）。
3. 定义"边缘路径带"：从一个角到其顺时针方向下一个角的路径沿网格边缘行进——左上到右上的路径带是第 0 行，右上到右下的路径带是最后一列，右下到左下的路径带是最后一行，左下到左上的路径带是第 0 列。
4. 对每个角落对象，检查从它到顺时针下一角的边缘路径带上是否存在任何灰(5)射线像素。若路径带上无射线像素（未被阻断），则将该角落对象复制到顺时针下一角，对齐方式为将对象包围盒贴合目标角的两条边缘。
5. 若路径带上存在射线像素（被阻断），则该角落对象不执行复制。
6. 复制处理顺序：左上、右上、右下、左下。若目标角已有对象（原始或先前复制的），新复制的对象覆盖已有像素。
7. 若某个角没有角落对象，则跳过该角（无复制来源）。

**关键洞察**：对角线段和射线看似只是视觉装饰，实际上它们构成了逻辑门控——射线是否穿过两角之间的边缘路径带决定了复制是否被"放行"，使得本来完全对称的顺时针复制变得选择性生效。
