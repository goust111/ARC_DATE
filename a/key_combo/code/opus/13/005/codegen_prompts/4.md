## 新题 4：边缘标记笛卡尔网格筛选自平移对象

**组合逻辑**：[平移/translate + 按自身宽度平移/shift_by_own_width](已有原语) + [填充/fill + 行列交叉/row_col_intersection + 边缘标记笛卡尔积/edge_marker_cartesian_product](创新：笛卡尔积位置不再直接填色，而是充当"合法落点") + [擦除/erase](已有原语) + [重涂色/recolor](已有原语)

**来源原语**：平移、边界框决定偏移、按自身宽度平移（64a7c07e）；填充、行列交叉、边缘标记笛卡尔积（2281f1f4）；连线/draw_line、边界标记定贯穿线（6cdd2623）；重涂色（b1948b0a）；擦除（6ca952ad）

**依赖链**：顶边标记确定目标列集合、右边标记确定目标行集合 → 笛卡尔积生成合法落点网格 → 每个前景对象按自身宽度右移 → 判断移动后边界框左上角是否恰好落在某个合法落点上 → 命中则保留并重涂为该行标记的颜色，未命中则擦除。对象的宽度（几何属性）决定了它能否对齐到全局网格（空间结构），两者的交互是求解关键。

顶边和右边的标记像素定义笛卡尔合法落点网格，每个前景对象右移自身宽度后，仅保留落在合法位置的对象并重涂为对应行标记颜色。

**输入结构**：网格约 16x16，背景黑(0)。顶边（第 0 行）有若干橙(7)标记像素，标记特定列。右边（最后一列）有若干彩色标记像素（从红(2)、绿(3)、蓝(1)中选取），标记特定行，每行最多一个标记。网格内散布若干灰(5)的 8-连通前景对象（每个 3~9 像素），形状各异，互不接触。生成约束：每个对象的边界框宽度在 1~5 之间；恰好有一部分对象（不少于 2 个、不超过总数的一半）在右移自身宽度后其边界框左上角落在某个笛卡尔交叉点上；其余对象移动后不落在任何交叉点上。笛卡尔交叉点定义为：行号等于某个右边标记的行号，且列号等于某个顶边标记的列号。

**规则**：
1. 确定顶边所有橙(7)标记的列号集合 C_set，右边所有彩色标记的行号集合 R_set 及每行标记的颜色。
2. 合法落点集合 = { (r, c) | r 在 R_set 中且 c 在 C_set 中 }。
3. 对每个灰(5)前景对象，计算其边界框宽度 W，将对象整体右移 W 列。
4. 移动后，检查该对象边界框的左上角坐标 (r0, c0)：
   - 若 (r0, c0) 在合法落点集合中：保留该对象在移动后的位置，并将所有像素从灰(5)重涂为该行右边标记的颜色。
   - 若 (r0, c0) 不在合法落点集合中：擦除该对象（原位置和移动后位置均不保留）。
5. 顶边和右边的标记像素保持不变。

**关键洞察**：对象能否"存活"取决于其自身宽度与全局笛卡尔网格的对齐关系——这是对象局部几何属性与全局空间结构之间的隐含共振，求解者需要同时理解自平移规则和笛卡尔筛选机制才能预测输出。

```yaml
  distractors:
    0-1 disconnected 8-connected non-bg components with no seed; may contain line+frame structure or be a single frame loop
  output: same grid with each connected cavity flood-filled by its seed's color

generation_strategy:
  approach: output-first
  steps:
    1. Choose grid size, bg color, 1-2 seeds with unique colors, and per-seed line_color
    2. For each seed, draw a meandering 8-connected line path from the seed's border position inward, using diagonal and orthogonal steps
    3. Along each line, attach 2-5 frame loops (closed rings of a frame_color enclosing a 2x2 bg cavity); the line touches the loop at 1-2 outer edge positions (8-adjacent to the frame ring)
    4. Place 0-3 additional distractor loops (same frame_color or different) NOT 8-connected to any line
    5. Optionally add 0-1 disconnected non-bg component as a distractor network
    6. Verify: each cavity has single-color boundary; cavities connected to a line are fillable; at least 1 unfilled cavity exists
    7. Output is derived by flood-filling each connected cavity with its seed_color
```
</generation_spec>
</reference_puzzle>

1. `main(grid)` 必须实现新题描述中的确定性转换规则，不能只识别 `generate_input()` 的固定模板。禁止不同的input网格输出相同的output网格。
2. `generate_input()` 必须随机生成多样样例，不能固定死。随机维度应覆盖：网格大小、对象数量、位置、颜色、方向、形状参数或关键分支。注意若描述中存在若干，需实现而不是只有单个，包括object或者对应关系等等。且若涉及到最短路径，则输入网格中必涉及到多条路径，对选择造成干扰。

6. 若规则有多个分支，生成器不能长期固定成一个分支；应让分支在随机样例中合理出现。分支概率不必平均——难以发现的隐蔽分支（如少数情况下才触发的特殊规则）应适当提高出现概率，确保在 3 个训练示例中至少出现一次，否则求解者无法归纳该规则。对于颜色映射类规则，确保 2 个左右的示例即可覆盖所有映射关系（每种颜色→颜色的映射至少在某个示例中出现过）。
