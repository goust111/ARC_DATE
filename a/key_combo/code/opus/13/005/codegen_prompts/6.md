## 新题 6：对角线段长度索引矩形框，被选框内容做象限旋转平铺

**组合逻辑**：[平移绘制/translate_draw + 长度递增/length_increment + 同反对角线/same_antidiagonal](创新：对角线段长度不仅推进自身，还作为选择索引) + [裁剪/crop + 完整边框检测/complete_border_check](已有原语) + [旋转/rotate + 平铺/tile + 四象限各不同旋转/quadrant_rotation](已有原语)

**来源原语**：平移绘制、长度递增、同反对角线（50c07299）；裁剪、矩形框、完整边框检测、最大面积选取（1a6449f1）；旋转、平铺、四象限各不同旋转、象限（cf5fd0ad）

**依赖链**：对角线段当前长度 L → 推进后新长度 L+1 → L+1 索引到按面积排序的矩形框列表中的第 (L+1) 个框 → 裁剪该框内部 → 对裁剪结果执行四象限旋转平铺生成输出。对角线段的几何属性（长度）同时驱动两个不同系统：自身的推进规则和框的选择逻辑。删除对角线段则无法确定选哪个框；删除四象限平铺则无法生成输出。

对角线段推进后的新长度作为索引选取对应矩形框，裁剪该框内部内容后做四象限旋转平铺生成输出。

**输入结构**：网格约 20x20，背景黑(0)。网格中有 3~5 个不同大小的完整单色矩形框（一像素宽边框，颜色各异，从蓝(1)、红(2)、绿(3)、黄(4)中选取）。每个框的内部包含由灰(5)和品红(6)组成的非平凡图案（非全空、非全满，至少 3 个非背景像素，图案本身无 4 重旋转对称性）。框的内部区域为正方形（宽=高）。网格角落区域有一条橙(7)对角线段，位于某条反对角线上，长度为 L（L 在 1~4 之间，且 L+1 不超过框的数量）。生成约束：各框互不重叠且不与对角线段重叠；将框按内部面积从小到大排序后，第 (L+1) 个框存在。

**规则**：
1. 识别橙(7)对角线段，计算其长度 L（像素数）。
2. 推进对角线段：擦除当前线段，在同一反对角线上、紧接当前线段右上端之后，绘制长度为 L+1 的新橙(7)线段（与参考题 50c07299 规则一致）。但此推进结果不出现在最终输出中——仅用于计算新长度 L+1。
3. 找到所有完整矩形框，按其内部面积从小到大排序，编号为 1, 2, 3, ...。
4. 选取编号为 (L+1) 的矩形框，裁剪其内部内容（不含边框），得到一个 MxM 的正方形图案 P。
5. 以 P 为基本单元，按四象限旋转规则生成 2Mx2M 的输出：
   - 左上象限：P 旋转 180 度。
   - 右上象限：P 顺时针旋转 90 度。
   - 左下象限：P 逆时针旋转 90 度。
   - 右下象限：P 保持不变。
6. 输出仅为 2Mx2M 的四象限平铺结果，不包含原始网格中的任何其他元素。

**关键洞察**：对角线段的长度是一个"指针"，其推进规则（长度+1）决定了指向哪个矩形框。求解者需要同时理解三个独立机制（对角线推进、面积排序索引、象限旋转平铺），并发现它们通过长度值这一隐含参数串联在一起。仅看单个示例可能混淆"选框依据"（不知道是按颜色、位置还是面积排序），需要对比多个示例中不同长度的对角线段与被选框的对应关系才能确定排序规则。
