## 新题 1：稀有色双重身份的循环铺展

**组合逻辑**：[最低频色定位](创新：同一颜色既标记位置又充当母题内容) + [循环填充] + [遇障碍截断]

**来源原语**：最低频色定位(48f8583b), 标记界定母题(12422b43), 循环填充/cyclic_fill(12422b43), 遇障碍截断(212895b5), 障碍像素(212895b5)

**依赖链**：频率分析同时确定填充起点和母题内容中的组成色；循环填充从种子向下铺展母题；障碍像素截断铺展边界。最低频色在母题内是内容、在母题外是位置标记，形成自指耦合——去掉频率分析则不知在哪填，去掉循环填充则不知填什么，去掉障碍截断则不知何处停止。

以母题中最稀有颜色的外部散布位置为种子，向下循环铺展母题行，遇障碍停止。

**输入结构**：
- 约 15x18 的网格，背景为黑(0)。
- 网格左上角有一个矩形母题区域（约 3 行 x 4 列至 4 行 x 5 列），其左边界由灰(5)标记列界定（标记列占 1 列，与母题等高）。母题区域内包含 2-3 种前景色（如蓝(1)、绿(3)、黄(4)），其中恰好一种颜色 C_rare 的像素数严格最少（仅 1-2 个像素）。
- 母题区域外，在网格的中下部散布着 2-4 个颜色为 C_rare 的孤立单像素，它们是填充种子。种子之间互不相邻，也不与母题区域 4-连通相邻。
- 网格中另有若干红(2)障碍像素，散布在种子的下方各行。障碍像素不与种子同行。
- 生成约束：每个种子正下方在到达网格底边前至少有一个障碍像素。母题区域外 C_rare 的出现总数等于种子数。各种子所在列加上母题宽度后的列范围互不重叠。

**规则**：
1. 在母题区域（灰色标记列右侧、与标记列等高的矩形范围）中，统计每种非背景(0)、非灰(5)颜色的像素数，找到像素数严格最少的颜色 C_rare。
2. 清除灰(5)标记列为背景，提取标记列右侧等高的矩形作为母题 M（保留 M 中所有颜色，包括 C_rare 本身）。M 的尺寸为 H_m 行 x W_m 列。
3. 找到母题区域外所有颜色为 C_rare 的像素，记为种子集合。
4. 对每个种子 S（位于第 r 行、第 c 列），从 S 的下一行开始向下循环铺展母题：第 r+1 行铺展 M 的第 0 行、第 r+2 行铺展 M 的第 1 行、...、第 r+H_m 行铺展 M 的第 H_m-1 行、第 r+H_m+1 行再铺展 M 的第 0 行，以此类推。铺展时，种子所在列 c 对齐 M 的第 0 列，即第 c 列至第 c+W_m-1 列依次对应 M 的各列。
5. 逐行铺展过程中，若当前行中待写入范围内（第 c 列至第 c+W_m-1 列的任一位置）存在红(2)障碍像素，则该种子的整个铺展在上一行之后终止（当前行不写入任何像素）。
6. 种子像素本身保留 C_rare 颜色。障碍像素保持红(2)不变。母题区域（含原标记列位置）清除为背景。
7. 若两个种子的铺展区域有列重叠，按种子列号从小到大的顺序处理，先铺展的像素不被后铺展的覆盖。

**关键洞察**：C_rare 在母题内是图案的一部分（铺展时照常写入），在母题外却是空间定位标记——求解者必须识别出同一颜色的两种角色，并区分"作为种子的 C_rare"与"作为母题内容被铺展出的 C_rare"。
