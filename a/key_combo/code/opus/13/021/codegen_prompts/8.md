## 新题 8：标记方向旋转的循环母题填充

**组合逻辑**：[循环填充](创新：填充方向由外部标记决定) + [边界标记](创新：标记位置决定母题旋转角度) + [标记指定观察方向] + [标记界定母题]

**来源原语**：循环填充(12422b43), 标记界定母题(12422b43), 母题行(12422b43), 边界标记(f341894c), 标记指定观察方向(f341894c), 填充(6cf79266)

**依赖链**：灰色标记列界定母题内容，边界标记决定每个空白区域的填充方向。填充方向不同导致母题在每个区域中以不同旋转角度铺展。删去母题提取则无填充内容，删去方向判断则不知旋转角度，删去循环填充则无铺展机制。三者交织为：母题提供内容，标记提供旋转指令，循环填充提供铺展方式。

提取标记界定的母题，根据每个空白区域边缘标记的方向旋转母题后循环填充。

**输入结构**：
- 约 15x15 的网格，背景为黑(0)。
- 网格最左列（第 0 列）的前 N 行（N 约 2-4）为灰(5)标记像素，界定母题高度。第 1 至 M 列的前 N 行构成母题区域（M 约 3-5），包含蓝(1)、红(2)、绿(3)等前景色。母题是 N 行 x M 列的矩形图案。
- 网格中有 3-4 个由黄(4)色像素围成的封闭矩形边框（边框宽 1 像素），边框内部全为背景色。各边框尺寸各不相同，互不重叠，不与母题区域重叠。
- 每个封闭边框的外侧恰好有 1 个品红(6)色标记像素，紧贴边框某一条边的中点外侧一格（即该边中间位置向外偏移 1 格）。
- 生成约束：不同边框的品红标记分别位于不同方向（如一个在上方、一个在右方、一个在下方、一个在左方；若只有 3 个边框则 3 个方向各一个）。母题的行数和列数不等（确保旋转后形状变化可观察）。

**规则**：
1. 提取母题：清除灰(5)标记列（第 0 列前 N 行）为背景，读取第 1 至 M 列的前 N 行作为母题 M_pat（N 行 x M 列）。
2. 对每个黄色封闭边框：
   a. 确定品红(6)标记的位置——在边框的上方、下方、左方还是右方。
   b. 根据标记方向旋转母题：
      - 标记在上方（标记指向下方进入边框）：母题不旋转（0 度），保持 N 行 x M 列。
      - 标记在右方（标记指向左方进入边框）：母题顺时针旋转 90 度，变为 M 行 x N 列。
      - 标记在下方（标记指向上方进入边框）：母题旋转 180 度，保持 N 行 x M 列。
      - 标记在左方（标记指向右方进入边框）：母题顺时针旋转 270 度，变为 M 行 x N 列。
   c. 用旋转后的母题从边框内部左上角开始循环填充：先铺满第一个母题宽度的列，再右移一个母题宽度继续铺，列方向用尽后换行继续。超出边框内部区域的部分截断不写入。母题行用尽后从第一行重新循环。
3. 黄(4)边框保持不变。品红(6)标记保持不变。母题区域（第 0 列标记 + 母题内容行）清除为背景。

**关键洞察**：所有边框中的图案来源于同一个母题，但因标记方向不同而呈现为不同旋转角度的变体——求解者需要识别出它们是同一母题的旋转版本，并从标记位置推断旋转角度。仅看单个边框无法确定旋转规则（不知道 0 度是什么样），必须对比多个边框才能归纳出标记方向与旋转角度的对应关系。
