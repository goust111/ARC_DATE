## 新题 9：重力下落与平台计数决定形态变换

**组合逻辑**：[重力下落] + [形状变换](创新：变换次数由路径上的事件计数决定) + [形状循环映射] + [计数]

**来源原语**：重力下落(c87289bb), 形状变换(a47bf94d), 形状循环映射(a47bf94d), 计数(df8cc377), 障碍线段(c87289bb)

**依赖链**：重力决定像素的下落路径，路径上经过的平台缺口数决定形态变换次数，变换次数通过形状循环映射选定最终形态，最终形态在着陆位置展开。删去重力则不知落点，删去计数则不知变换几次，删去形状映射则不知变什么形态。三步形成：运动机制 -> 事件计数 -> 形态选择 的链式耦合。

彩色像素在重力下落过程中，每穿过一个平台缺口就经历一次形态变换，着陆时展开最终形态。

**输入结构**：
- 约 12x15 的网格（12 列、15 行），背景为黑(0)。
- 第 0 行有 2-4 个彩色前景单像素（颜色各不相同，如蓝(1)、红(2)、绿(3)、黄(4)），分布在不同列，是下落种子。
- 第 0 行以下有 1-3 条水平平台线，每条由灰(5)像素组成，跨越大部分网格宽度但含有若干单列缺口（缺口处为背景色）。不同平台线在不同行（行间距至少 4 行）。
- 生成约束：每个种子所在列在每条平台线上要么有灰(5)像素（阻挡）要么是缺口（通过），至少有一个种子的列上某条平台有缺口（确保有穿越发生）。穿越次数最多为 3 次。每个种子着陆后展开的 3x3 形态不超出网格边界，且不同种子的着陆形态互不重叠。

**规则**：
1. 每个种子像素从第 0 行所在列开始垂直下落（重力方向为向下）。
2. 下落过程中，若当前列在某条平台线上是灰(5)像素，则种子停在平台上方一行（着陆）。若当前列在平台线上是缺口（背景），则种子穿越该平台继续下落，穿越计数 +1。
3. 若种子穿越了所有平台（或无平台阻挡），则停在网格最后一行（着陆）。
4. 着陆时，根据穿越计数 P 决定形态：
   - P = 0（未穿越任何平台）：保持单像素，不变换。
   - P = 1（穿越 1 次）：展开为 3x3 实心方块，以着陆位置为中心。
   - P = 2（穿越 2 次）：展开为 X 形（中心 + 4 个对角方向各 1 像素，共 5 像素），以着陆位置为中心。
   - P = 3（穿越 3 次）：展开为菱形（中心 + 4 个基本方向各 1 像素，共 5 像素），以着陆位置为中心。
5. 所有展开形态使用该种子的原始颜色。超出网格边界的像素不绘制。
6. 原始种子像素位置（第 0 行）清除为背景。平台线保持灰(5)不变。
7. 若多个种子着陆位置的展开形态有重叠，按种子在第 0 行的列号从左到右依次处理，后处理的覆盖先处理的。

**关键洞察**：同一条平台对不同列的种子可能是阻挡（该列有灰色像素）或通过（该列是缺口），因此同一条平台同时决定了部分种子的着陆位置和另一部分种子的变换次数——平台既是"地面"又是"变换器"，具体角色取决于种子所在列是否恰好对准缺口。
