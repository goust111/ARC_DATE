## 新题 3：调色板索引式射线绕行

**组合逻辑**：[调色板行](创新：作为空间到颜色的查找表) + [射线延伸] + [绕行] + [遇障碍绕最近侧]

**来源原语**：调色板行(bae5c565), 以缺口为中心(bae5c565), 射线延伸(c87289bb), 绕行(c87289bb), 遇障碍绕最近侧(c87289bb), 障碍线段(c87289bb)

**依赖链**：调色板行的缺口定义射线起点（源自 bae5c565 的缺口机制），射线下行遇障碍线段后绕行到新列（源自 c87289bb 的绕行机制），而绕行水平段的颜色由新列上方的调色板格子决定——调色板既是起点定义者又是颜色查找表，射线路径动态索引调色板的不同位置。删去调色板则无起点也无颜色信息，删去射线则无路径，删去绕行则路径被障碍阻断。

从调色板行的缺口向下发射射线，遇障碍线段绕行，每段水平绕行的颜色由目标列对应的调色板颜色决定。

**输入结构**：
- 约 12x15 的网格（12 列、15 行），背景为黑(0)。
- 第 0 行是调色板行：12 个格子中 11 个各有前景色（可以有相同颜色，但至少用 3 种不同颜色），恰好 1 个格子为背景色（缺口）。缺口不在第 0 列或最末列。
- 第 1 行以下，散布着 2-4 条水平障碍线段，每条由灰(5)像素组成，宽度 2-5 像素，各条不在同一行，相邻障碍行间距至少 2 行。
- 生成约束：缺口所在列被至少一条障碍线段覆盖（确保至少发生一次绕行）。每次绕行后新列在到达下一条障碍线段前至少有 1 行垂直空间。绕行目标列不超出网格范围。

**规则**：
1. 读取调色板行（第 0 行），记录每列的颜色。找到缺口列 c_start（背景色的列）。射线的垂直段颜色 C_ray 定义为缺口左侧相邻列（第 c_start-1 列）的调色板颜色。
2. 从第 1 行、列 c_start 开始，向下逐行画垂直射线，颜色为 C_ray。
3. 当射线到达第 r 行，且第 r+1 行在当前列是障碍线段的一部分时：
   a. 确定该障碍线段的左端列 c_L 和右端列 c_R。
   b. 计算射线当前列到左外侧（c_L - 1）和右外侧（c_R + 1）的距离，选择距离更近的外侧列 c_new。若等距则选右侧。
   c. 在第 r 行，从射线当前列到 c_new 画一条水平线段。该水平线段的颜色为调色板行中第 c_new 列的颜色。
   d. 射线跳至列 c_new，从第 r+2 行（障碍线段下方一行）继续垂直下行，垂直段颜色仍为 C_ray。
4. 射线到达网格最后一行后停止（最后一行也画上颜色）。
5. 调色板行保留不变。障碍线段保留灰(5)不变。

**关键洞察**：每次水平绕行的颜色不是固定的，而是由绕行目标列在调色板行中的颜色决定——调色板是一张空间到颜色的映射表，射线路径决定了它"读取"调色板的哪些列。不同的障碍布局导致射线走不同路径、索引不同的调色板位置，产生不同的水平段颜色组合。

<description>
Recolor each closed orthogonal line loop so convex bend pixels are yellow and concave bend pixels are red.

Input structure
- The grid has a dominant background and exactly one foreground color.
- The foreground forms one or more 4-connected one-pixel-wide closed cycles; every foreground pixel has degree 2.
Rule
- Trace each cycle and inspect the turn at each foreground pixel.
- Straight pixels keep the original foreground color.
- Bend pixels whose turn direction is the majority direction for that cycle are convex corners and become yellow.
- Bend pixels whose turn direction is the minority direction for that cycle are concave corners and become red.
Key insight
- A simple rectilinear closed boundary has exactly four more convex bends than concave bends, so convexity can be inferred structurally from the majority turn sign within each traced cycle.
