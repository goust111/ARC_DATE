## 新题 6：位移向量解码驱动的精灵体裁剪嵌入

**组合逻辑**：[平移 + 位移向量推断](从部分副本推断位移方向) → [裁剪](沿位移方向裁剪精灵体得到适配形状) → [嵌入填充](将裁剪后的精灵体嵌入匹配的空腔)（创新：位移向量不是用于重复投射精灵体，而是指示裁剪方向——沿位移反方向裁去精灵体的一部分使其恰好适配目标空腔）

**来源原语**：平移(translate)、位移向量(displacement_vec)、部分副本(partial_copy)、副本指示方向与色(copy_dir_and_color) ← 045e512c；裁剪(crop) ← 57edb29d；嵌入填充(inlay_fill)、模板框架(template_frame)、矩形空腔(rectangular_cavity)、尺寸匹配(size_matching)、唯一槽位配对(unique_slot_pairing) ← 5dbc8537

**依赖链**：部分副本的偏移揭示位移向量；位移向量的方向指示裁剪方向（从精灵体的哪一侧裁去像素）；裁剪量由目标空腔的尺寸决定；裁剪后精灵体必须与某个空腔尺寸严格匹配才能嵌入。三个步骤互锁——不知道位移方向就不知道裁剪方向，不知道空腔尺寸就不知道裁剪量。

通过部分副本推断位移方向，沿该方向裁剪精灵体至目标空腔尺寸后嵌入。

**输入结构**：约 18x18 的黑(0)背景网格。网格中央有一个灰(5)大矩形模板框架（约 8x10），内部挖有 2~3 个矩形空腔（黑(0)区域），空腔尺寸各不相同。模板外散布 2~3 个彩色精灵体（每个 4~6 像素的 4-连通单色小图形，颜色各异如红(2)、蓝(1)、绿(3)）。每个精灵体旁边有一个同色的部分副本——副本是精灵体的一个连续子集（1~2 个像素），与精灵体沿某个基本方向（上/下/左/右）偏移若干格放置。精灵体的完整尺寸大于任一空腔的对应维度 1~2 个像素。生成约束：每个精灵体恰好有唯一一个裁剪方向和裁剪量使其匹配唯一一个空腔；各精灵体对应不同空腔。

**规则**：
1. 识别模板框架及其内部空腔，记录每个空腔的行数和列数。
2. 对每个精灵体，找到其同色的部分副本。将部分副本的像素坐标与精灵体的像素坐标对齐，确定使副本成为精灵体子集的最佳平移向量 (dr, dc)。该向量即为位移方向。
3. 位移方向指示裁剪侧：若位移向右 (dc>0)，从精灵体左侧裁去列；若向左 (dc<0)，从右侧裁去列；若向下 (dr>0)，从顶部裁去行；若向上 (dr<0)，从底部裁去行。裁剪量选取使裁剪后精灵体的边界框尺寸恰好匹配某个空腔的尺寸。
4. 将裁剪后的精灵体（保持其像素图案的相对位置）嵌入匹配的空腔，左上角对齐。精灵体像素覆盖空腔中的黑(0)像素。
5. 无法匹配任何空腔的精灵体不做处理。输出为模板框架区域的裁剪（含已嵌入的精灵体）。

**关键洞察**：部分副本不是用来指示射线延伸的方向（如参考题 045e512c），而是编码裁剪方向——精灵体必须沿位移的反方向被裁去多余部分才能适配空腔。
