## 新题 4：拼图组装后按最近边重涂色

**组合逻辑**：[拼接/assemble + 连接配对/connector_pairing + 逐步拼合/incremental_assembly](散落精灵体经连接像素组装) → [重涂色/recolor + 最近边归属/nearest_side_assignment](组装后的结构按像素到边界框各边的距离重涂色)

**来源原语**：拼接、精灵体、锚点精灵、连接像素、连接配对、逐步拼合（参考题 cbebaa4b）；重涂色、空心矩形、前景掩码、最近边归属、最近边决定涂色（参考题 9aec4887）

**依赖链**：精灵体通过红色连接像素逐步拼合为一体 → 拼合后的整体形状决定了其边界框 → 每个非连接像素到边界框四边的 Manhattan 距离决定其重涂色目标 → 距离相等时保留原色（暴露了组装前的原始精灵色作为例外信息）。组装步骤决定最终形状，最终形状决定距离关系，距离关系决定颜色——因果链不可跳步。

将散落的带连接像素的精灵体拼装成完整结构，然后根据每个像素到组装体边界框四边的距离，将其重涂为对应边的颜色。

**输入结构**：
- 网格约 20x20，背景 = 黑(0)
- 一个锚点精灵体，包含一个 3x3 黄(4)实心块，周边带有若干红(2)连接像素，总像素数约 12-16
- 另有 3-5 个可移动精灵体散布在网格上，每个精灵体由一种独特的体色（取自 {蓝(1), 绿(3), 灰(5), 品红(6), 橙(7)} 中的不同颜色）加上红(2)连接像素构成，每个精灵体总像素数 4-8，形状为不规则的 4-连通图形
- 所有精灵体之间互不重叠、互不相邻
- 生成约束：连接配对无歧义——每个红(2)像素恰好与另一个红(2)像素配对（可通过空间位置唯一确定配对关系）；完成组装后的整体结构的边界框至少 6x6

**规则**：
1. 锚点精灵体保持原位。逐个将其余精灵体平移，使其某一红(2)连接像素与已组装体上一个未配对的红(2)像素重合。每次只添加一个精灵体，每个红(2)连接像素恰好与另一个配对
2. 组装完成后，计算整个拼合体的紧凑边界框（最小包围矩形）
3. 定义边界框四边的颜色：顶边 = 蓝(1)，右边 = 绿(3)，底边 = 橙(7)，左边 = 品红(6)
4. 对于拼合体中每个非红(2)的像素，计算其在边界框内部的 Manhattan 距离到四边的距离（顶边距离 = 该像素行号 - 边界框顶行，底边距离 = 边界框底行 - 该像素行号，左边距离和右边距离同理）
5. 若该像素到四边中最近的唯一一边距离严格最小，将该像素重涂为该边对应的颜色
6. 若最近距离存在平局（到两边或多边距离相同），保留该像素当前的颜色不变
7. 红(2)连接像素始终保持红(2)不变
8. 裁剪输出为边界框大小（含边界框最外行列）

**关键洞察**：组装前各精灵体的独特体色在输出中几乎完全被边距颜色覆盖——体色仅在到多边等距的像素上存活，成为间接暴露组装结构的"化石"。需要对比多个示例才能推断四边对应的固定颜色映射（顶→蓝、右→绿等），因为这一映射无法从输入结构直接推导。
