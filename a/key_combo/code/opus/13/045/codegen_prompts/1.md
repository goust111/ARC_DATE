## 新题 1：射线凿壁迷宫与奇偶洪泛

**组合逻辑**：[射线延伸](创新：射线击中迷宫墙壁时擦除墙壁像素而非绘制) → [擦除](射线贯穿墙壁使不连通走廊贯通) → [洪泛填充 + 路径奇偶交替涂色](创新：在被射线修改后的拓扑上执行，奇偶性由被凿开的捷径决定)

**来源原语**：射线延伸/碰撞停止(e12f9a14), 擦除(456873bc/6d0160f0), 洪泛填充/路径奇偶交替涂色(b782dc8a), 迷宫走廊/种子像素(b782dc8a), 带框块/框架缺口(e12f9a14)

**依赖链**：框架缺口位置决定射线方向 → 射线与迷宫墙壁的交点决定哪些墙壁被凿开 → 凿开后的拓扑连通性决定两个种子洪泛的交汇位置 → 从种子到每个走廊格子的 BFS 距离奇偶性决定涂色。删除射线凿壁步骤，走廊拓扑不变，洪泛结果完全不同；删除洪泛步骤，凿壁效果无处着色。

根据带框块的缺口位置发出对角射线凿穿迷宫墙壁，再用两色种子沿修改后的走廊网络做奇偶交替洪泛填充。

**输入结构**：
- 约 18x18 网格，黑(0)背景。
- 青(8)像素构成 1 像素宽的迷宫墙壁，墙壁之间的黑(0)像素为走廊。迷宫保证存在至少两个不连通的走廊连通分量。
- 2 个带框块：每个由绿(3)像素构成 4x4 外框，内含 2x2 单色块（一个红(2)、一个蓝(1)）。每个外框恰好有 1 个缺口像素（框上一个位置为黑(0)而非绿(3)）。带框块位于迷宫墙壁之间的走廊交叉处。生成保证每个带框块的 4x4 区域不与其他带框块或网格边界重叠。
- 2 个种子像素：一个红(2)、一个蓝(1)，各位于不同走廊连通分量中的走廊格子上。生成保证两个种子分属不同连通分量（在射线凿壁之前）。

**规则**：
1. 对每个带框块，从缺口像素出发向外发射对角射线。射线方向由缺口相对于 2x2 内块中心的方位决定：缺口在内块的右上方 → 射线向右上（行-1, 列+1）；缺口在左下方 → 射线向左下；以此类推四个对角方向。射线颜色为内块颜色。
2. 射线沿对角方向逐像素前进。遇到黑(0)走廊像素时跳过（不改变该像素）；遇到青(8)墙壁像素时**擦除该墙壁像素为黑(0)**（凿开通道），射线继续前进；遇到绿(3)框架像素或另一条射线已凿开的路径或非黑非青像素时停止；到达网格边界时停止。射线本身不留痕迹——它只擦除墙壁。
3. 所有射线处理完毕后，从红(2)种子像素出发，对所有 4-连通的黑(0)走廊格子执行 BFS 洪泛。BFS 距离为偶数的格子涂红(2)，奇数的涂蓝(1)。种子本身距离为 0（偶数），涂红(2)。
4. 同时从蓝(1)种子像素出发，对其所在连通分量的黑(0)走廊格子执行 BFS 洪泛。BFS 距离为偶数的涂蓝(1)，奇数的涂红(2)。
5. 若射线凿壁使两个种子的连通分量合并，则每个走廊格子取距离它更近的种子来决定奇偶（取到两个种子的 BFS 距离中较小者）。若距两个种子等距，取行号较小的种子（行号也相同则取列号较小的）。
6. 绿(3)框架、内块像素、剩余的青(8)墙壁像素保持不变。

**关键洞察**：射线不绘制而是擦除——它改变的是迷宫拓扑而非视觉外观。被凿开的墙壁产生捷径，捷径改变 BFS 距离，距离的奇偶性决定每个走廊格子的最终颜色。射线几何与迷宫结构的交互决定了哪些墙壁被打通，这是无法跳过的中间推理步骤。
