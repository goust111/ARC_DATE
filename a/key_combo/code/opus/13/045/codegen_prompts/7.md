## 新题 7：区域级奇偶洪泛与面积排名屏障

**组合逻辑**：[排序](按面积排名封闭区域) → [洪泛填充](创新：洪泛以区域为单位而非以像素为单位推进，交替着色按区域边界穿越次数的奇偶性) → [重涂色](创新：最小面积区域成为屏障阻断传播，改变有效图距离)

**来源原语**：排序/长度排名(97d7923e), 洪泛填充/路径奇偶交替涂色(b782dc8a), 路径连通(b782dc8a), 重涂色(97d7923e), 轮廓围合/封闭背景区域/轮廓线(753ea09b), 小区域被填充(753ea09b), 连通分量(753ea09b)

**依赖链**：轮廓线 → 区域分割 → 面积计算 → 排名 → 最小区域成为屏障 → 区域邻接图（去除屏障节点后）→ 从种子区域 BFS → 区域图距离奇偶 → 涂色。面积排名改变图结构（删除屏障节点），图结构决定 BFS 距离，距离奇偶决定颜色。

轮廓线围合出多个区域后按面积排名，最小面积区域成为传播屏障，两色种子在区域邻接图上做 BFS，每穿过一个区域边界交替一次颜色。

**输入结构**：
- 约 16x16 网格，黑(0)背景。
- 橙(7)像素构成 1 像素宽的闭合轮廓线，将网格划分为 6~8 个大小不等的封闭背景区域（4-连通的黑(0)像素集合，以橙(7)像素和网格边界为 barrier）。
- 各区域面积（黑像素数）互不相同（保证排名无平局）。
- 一个红(2)种子像素位于某个封闭区域内。
- 一个蓝(1)种子像素位于另一个封闭区域内。
- 生成保证：种子所在区域不是最小面积区域；去除最小面积区域后，所有剩余区域仍 4-连通可达（即屏障不会将图完全分割成不可达部分）。两个种子在去除屏障后可通过区域邻接图相互到达。

**规则**：
1. 识别所有被橙(7)轮廓线围合的 4-连通黑(0)封闭区域。网格外侧的背景不算封闭区域。
2. 按像素数（面积）对封闭区域排名，面积最小的为排名 1。
3. 所有面积相同为最小值的区域（本题保证唯一）成为"屏障区域"：它们不参与洪泛传播，保持黑(0)不变。
4. 构建区域邻接图：若两个非屏障区域共享至少一个橙(7)轮廓像素作为公共边界（即两区域中各有一个像素与同一个橙像素 4-相邻），则这两个区域在图中有一条边。屏障区域不参与建图。
5. 在区域邻接图上从红(2)种子所在区域和蓝(1)种子所在区域各自做 BFS。每个非屏障区域的"图距离"定义为从种子区域到该区域在邻接图上经过的最少边数。
6. 对每个非屏障区域：取其到两个种子区域的图距离中较小值 d，以及对应的最近种子颜色 C。若 d 为偶数，该区域所有黑(0)像素涂为 C；若 d 为奇数，涂为另一种种子颜色。种子区域自身 d=0（偶数），涂为自身颜色。
7. 若某区域到两个种子的图距离相等（d 值相同），取种子区域面积更大的那个种子的颜色作为 C（面积大的优先）。
8. 橙(7)轮廓线和屏障区域保持不变。

**关键洞察**：颜色交替发生在区域边界穿越层面而非像素步进层面——一个大区域内所有像素颜色相同，因为它们距种子的"区域图距离"相同。最小面积区域作为屏障会迫使洪泛绕行，改变有效图距离从而翻转某些区域的奇偶性。仅看单个示例可能误以为是像素级洪泛或简单空间分区着色，需对比多示例中屏障位置不同导致奇偶翻转的情况才能归纳出正确规则。
