## 新题 3：排名驱动的循环色带重涂

**组合逻辑**：[排序/长度排名](按像素数排名色带) → [重涂色](创新：图例高度索引的是排名位次而非空间位置) → [填充/空缺借邻色](创新：借色沿排名序循环而非沿空间左右序循环)

**来源原语**：排序/长度排名/高度即排名索引(97d7923e), 重涂色(97d7923e), 填充/空缺借邻色/循环相邻(c4d1a9ae), 竖向色带(c4d1a9ae), 颜色图例/竖条(97d7923e)

**依赖链**：各色带的非黑像素总数 → 排名序 → 图例高度到排名的映射 → 色带重涂颜色确定 → 以排名邻接（而非空间邻接）确定间隙借色来源。跳过排名直接用空间邻接借色会得到错误结果；跳过重涂则借色颜色不对。

按像素数量排名垂直色带，用图例高度索引排名位次来重涂色带，再按排名循环顺序填充色带间隙。

**输入结构**：
- 约 14x20 网格，黑(0)背景。
- 4~5 条垂直色带，每条占据独立的列范围（列范围不重叠），使用互不相同的颜色（如红(2)、蓝(1)、绿(3)、黄(4)、灰(5)）。每条色带跨越网格的全部行，但带内有若干黑(0)间隙像素（该列范围内某些行的像素为黑色而非色带颜色）。
- 各色带的有色像素总数互不相同（保证排名无平局）。
- 网格左上角（行 0~5、列 0~2 的区域）放置图例：图例由若干单色矩形块竖向排列组成，每块宽 1 像素、高 h 像素（h 在 1~5 之间），颜色各不相同，且每种颜色恰好出现在某条色带中。不同图例块之间用 1 行黑(0)间隔。图例块的高度值互不相同。
- 图例区域不与任何色带的列范围重叠。

**规则**：
1. 统计每条色带的有色（非黑）像素总数，按总数从多到少排名：最多的为排名 1，次多为排名 2，以此类推。
2. 读取图例：每个图例块具有颜色 K 和高度 h。高度 h 表示排名位次。
3. 找到排名为 h 的色带，将该色带中所有有色像素重涂为颜色 K。（例如图例块高度为 3、颜色为红(2)，则排名第 3 的色带所有有色像素改为红(2)。）
4. 所有色带重涂完毕后，填充间隙：对每条色带内的黑(0)间隙像素，填充为排名序中下一位色带的（重涂后的）颜色。排名最末的色带借排名第 1 的颜色，形成循环。
5. 擦除图例区域（图例块所有像素置为黑(0)）。色带列范围外的黑(0)背景不变。

**关键洞察**：间隙借色的循环顺序基于像素数量排名而非色带在网格中的空间左右顺序。仅凭单个示例无法区分这两种循环顺序——必须对比空间顺序和排名顺序不一致的多个示例，才能归纳出正确规则。
