## 新题 10：压缩去重提取头序列后驱动对角平铺填充空白区

**组合逻辑**：[压缩(compress) + 去重(deduplicate)](已有) → [平铺(tiling)](已有，创新：头序列不直接给出而从压缩结果中提取) ← [头序列(header_sequence)](已有) + [分隔线(divider_line)](已有) + [相邻重复(adjacent_repeat)](已有) + [合并相同行列(merge_identical_row_col)](已有) + [对角索引映射(diag_index_map)](已有) + [分隔线两侧(opposite_sides_of_divider)](已有)

**来源原语**：压缩(compress)、去重(deduplicate)、相邻重复(adjacent_repeat)、合并相同行列(merge_identical_row_col) ← e1baa8a4；平铺(tiling)、头序列(header_sequence)、对角索引映射(diag_index_map)、循环头序列倍增(cyclic_header_doubled) ← 539a4f51；分隔线(divider_line)、分隔线两侧(opposite_sides_of_divider) ← 05a7bcf2

**依赖链**：压缩操作从膨胀区域中提取本质矩阵，该矩阵的首行/首列即为头序列。头序列驱动对角索引平铺规则，填充分隔线另一侧的空白区域。没有压缩就无法获得头序列（膨胀数据中头序列被冗余掩盖）；没有平铺则头序列提取后无处使用；分隔线将数据源与目标区分开。

分隔线一侧是膨胀的颜色矩阵，对其压缩去重后提取头序列，用该头序列按对角索引规则平铺填充分隔线另一侧的空白区域。

**输入结构**：黑(0)背景，约 14x20（高大于宽）网格。一条品红(6)色水平分隔线将网格分为上下两区。上区包含一个彩色矩阵（占据上区全部空间，无黑色背景），该矩阵是某个小矩阵（3x3 到 5x5）经行列膨胀后的结果——每行被重复 2~3 次，每列被重复 2~3 次（不同行的重复次数可不同，不同列的重复次数也可不同）。小矩阵满足对角索引性质：其首行与首列相同，且每格颜色等于首行/首列序列在 max(row, col) 位置的颜色。小矩阵使用的颜色从蓝(1)、红(2)、绿(3)、黄(4)、灰(5)、橙(7)中选取（不含黑(0)）。下区完全为黑(0)空白，尺寸为正方形，边长等于上区压缩后小矩阵边长的两倍。生成约束：上区膨胀矩阵的行列重复模式在不同示例中不同（防止求解者直接记忆固定的压缩比例）。

**规则**：
1. 对上区的膨胀矩阵执行压缩：识别所有最大相同相邻行组（从上到下连续内容完全相同的行），每组保留第一行；对列同理（从左到右连续内容完全相同的列，每组保留第一列）。得到压缩后的小矩阵。
2. 提取小矩阵的首行作为头序列 H，长度为 K。
3. 去掉头序列 H 末尾连续的黑(0)元素（若有），得到有效头序列 H'，长度为 K'。（本题中小矩阵不含黑色，故通常 K' = K。）
4. 将 H' 循环扩展至长度 2K'，记为 H''（即 H'' = H' 重复两次拼接后取前 2K' 个）。
5. 在下区填充一个 2K' x 2K' 的正方形，每格 (r, c) 的颜色为 H''[max(r, c)]。
6. 分隔线和上区在输出中保持不变。

**关键洞察**：头序列不是直接给定的（如原题 539a4f51），而是隐藏在膨胀矩阵的冗余结构中——求解者必须先完成压缩去重（逆向工程数据生成过程），才能获得驱动平铺的指令，两步形成"解码数据→生成图案"的紧耦合流水线。

Paint the maze corridor and framed rooms lying on shortest paths between the two colored endpoint components.

Input structure
- The grid has a dominant background, one wall color forming thin orthogonal frames, and one endpoint/fill color.
- The endpoint/fill color forms exactly two 4-connected solid rectangular components; their larger side lengths define the framed room sizes.

Rule
