## 新题 7：双面板逻辑交集生成对象后按排位图例着色

**组合逻辑**：[逻辑运算(logical_operation)](已有) → [排序(sort) + 重涂色(recolor)](已有，创新：逻辑运算的结果生成待着色对象而非直接输出) ← [等宽面板(equal_width_panel)](已有) + [分隔列(separator_column)](已有) + [颜色图例(color_legend)](已有) + [排位对应(rank_correspond)](已有) + [逐格比较(cell_comparison)](已有)

**来源原语**：逻辑运算(logical_operation)、分隔列(separator_column)、等宽面板(equal_width_panel)、逐格比较(cell_comparison)、双空交集涂色(intersect_empty_fill) ← f2829549；排位对应(rank_correspond)、颜色图例(color_legend)、重涂色(recolor)、图例位映射色(legend_pos_color) ← fafd9572

**依赖链**：逻辑交集运算生成若干连通区域（新对象）。这些区域需按面积排位，再由图例映射颜色。没有交集就没有待着色的区域；没有排位和图例就无法确定颜色。交集运算从"结果"变成了"中间产物生成器"。

两个面板逐格求交集，交集区域按面积排位，每个排位从颜色图例中取色着色输出。

**输入结构**：黑(0)背景，约 12x25（宽大于高）网格。一条红(2)色竖直分隔列将网格分为等宽的左右面板。每个面板上有若干蓝(1)色 4-连通图形（3~8 像素），左右面板上的图形位置不完全相同但有重叠区域。分隔列下方（或网格底部行）有一行小型颜色图例：由 2~4 个不同颜色的单像素横排（从绿(3)、黄(4)、品红(6)、橙(7)中选取），从左到右排列。生成约束：左右面板的蓝色图形交集会产生 2~4 个互不相连的 4-连通区域，区域面积两两不同（保证排位无歧义）；图例颜色数量 >= 交集区域数量。

**规则**：
1. 移除红(2)分隔列，将左右面板叠合到同一坐标系（两面板尺寸相同）。
2. 逐格比较：若某格在左面板和右面板中都是蓝(1)（前景），则标记为交集像素；否则标记为背景黑(0)。
3. 在交集结果中识别所有 4-连通区域，按面积从大到小排序。面积相同时按边界框左上角行号从小到大、再按列号从小到大排序。
4. 读取图例：图例中的颜色从左到右分别对应排位第 1、第 2、第 3 ......的区域。
5. 将每个交集区域的所有像素重涂为其对应排位的图例颜色。
6. 输出仅包含着色后的交集区域（裁剪到交集区域的最小包围矩形，背景为黑(0)），不含分隔列和原面板。

**关键洞察**：逻辑交集不像原题那样直接涂绿输出，而是成为生成新对象的中间步骤——交集区域的面积排位才是决定最终颜色的关键，求解者需要理解整个"生成→排序→着色"三级管道。
