## 新题 6：噪声中检测矩形墙壁并追踪走廊路径

**组合逻辑**：[最大矩形检测 + 最小边长过滤](已有) → [射线延伸(ray_extend) + 转弯(turn)](已有，创新：走廊由检测出的矩形隐式界定而非显式给出) ← [噪声背景(noisy_background)](已有) + [纯色实心矩形(solid_mono_rect)](已有) + [起点条(start_bar)](已有) + [碰撞转向(collision_turn)](已有)

**来源原语**：纯色实心矩形(solid_mono_rect)、噪声背景(noisy_background)、最小边长过滤(min_side_filter)、最大矩形检测(max_rect_detection) ← 25094a63；射线延伸(ray_extend)、起点条(start_bar)、走廊路径(corridor_path)、碰撞转向(collision_turn)、遇障碍直角转(right_turn_at_block) ← 6bcdb01e

**依赖链**：矩形检测的结果定义了走廊的墙壁——不先检测就无法确定走廊在哪里。路径追踪需要墙壁信息来决定何时转弯。检测与追踪缺一不可：单独检测只能标出矩形（如原题 25094a63），不会产生路径；单独追踪需要已知的走廊（如原题 6bcdb01e），但此处走廊被噪声遮蔽。

在含噪声的网格中检测出隐藏的大型矩形作为墙壁，然后从边缘起点条出发，在这些墙壁与网格边界之间的缝隙中追踪走廊路径。

**输入结构**：多色噪声网格，约 18x20。噪声由随机颜色像素构成（使用蓝(1)、红(2)、橙(7)、栗(9)等色），无大面积同色区域。在噪声中隐藏有 2~4 个灰(5)色实心矩形（每个矩形的宽和高均 >= 4），矩形彼此不重叠，它们之间以及它们与网格边界之间至少留有 1 像素宽的间隙。网格某条边上有一个 2 像素的绿(3)色起点条（4-连通，一个像素在边界上）。起点条位于某两个矩形之间的间隙入口处。生成约束：矩形的排列保证从起点条出发存在一条唯一的蜿蜒路径（宽度恰好 1 像素），路径在矩形墙壁之间转弯并最终到达网格的另一条边界。

**规则**：
1. 检测所有最大同色矩形，保留宽和高均 >= 4 的灰(5)矩形。这些矩形是墙壁。
2. 将检测出的矩形像素重涂为黄(4)以标记墙壁。
3. 从绿(3)起点条出发，沿从边界像素穿过另一个像素的方向进入网格。
4. 逐步延伸路径，将经过的非墙壁像素（包括噪声像素）涂为绿(3)。
5. 当路径前方下一格是墙壁像素（黄(4)）时，转向唯一可通行的垂直方向继续前进（走廊宽度为 1 保证转弯方向唯一）。
6. 当路径到达网格边界时停止。
7. 输出中，墙壁为黄(4)，路径为绿(3)，其余噪声像素保持原样。

**关键洞察**：走廊在输入中被噪声完全遮蔽——求解者必须先透过噪声发现大型矩形的存在（感知任务），然后才能在矩形之间的负空间中执行路径追踪（导航任务），两个认知过程相互依赖。
