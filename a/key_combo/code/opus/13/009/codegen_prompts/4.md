## 新题 4：周期性修复与对称性修复的级联

**组合逻辑**：[补全/平移对称](已有) → [对称补全/对称轨道映射](创新：在单周期内使用镜像对称而非全局 D4 对称) ← 信息级联（第一步输出解锁第二步约束）

**来源原语**：补全/周期瓦片/平移对称/轨道可见色填缺失(0dfd9992), 对称补全/对称图案/掩码像素/对称轨道映射/全对称群轨道约束(47996f11)

**依赖链**：黑色像素通过平移周期轨道修复→修复后的像素为粉色像素的镜像参照提供信息→粉色像素通过周期内镜像对称修复。部分粉色像素的镜像伙伴原先是黑色的，只有先修复黑色才能获得镜像数据。两种修复机制针对不同类型的损伤，且存在信息依赖。

在一个同时含有黑色遮挡和粉色掩码的周期性花纹中，先用平移周期修复黑色遮挡，再用周期内的镜像对称修复粉色掩码。

**输入结构**：约 12x12 的网格。整体是一个彩色周期性花纹（周期约 4x4 或 6x3），使用蓝(1)、红(2)、绿(3)、黄(4) 等颜色。花纹在每个周期单元内具有垂直镜像对称（即左半和右半关于中轴对称）。部分像素被替换为黑(0)（表示遮挡缺损，约 8-12 个），另一部分被替换为粉(6)（表示掩码缺损，约 6-10 个）。生成约束：(a) 每个黑色像素的平移轨道中至少有一个非黑非粉的可见像素。(b) 至少有 3 个粉色像素的镜像伙伴在输入中是黑色的（即必须先修复黑色才能获得镜像参照）。(c) 所有粉色像素在黑色修复完成后，其镜像伙伴或镜像伙伴的平移轨道中有非粉可见像素。

**规则**：
1. 第一阶段（周期修复）：检测非黑(0)非粉(6)像素之间的平移对称向量。对每个黑(0)像素，沿平移轨道收集所有非黑非粉的颜色值，将该黑色像素修复为该颜色。
2. 第二阶段（对称修复）：在第一阶段结果之上操作。确定每个周期单元的范围和垂直镜像轴。对每个粉(6)像素，找到其在所属周期单元内的垂直镜像位置。若镜像位置是非粉颜色，直接复制。若镜像位置也是粉色，则沿平移轨道找到该镜像位置的一个非粉副本，复制其颜色。
3. 输出不含任何黑(0)或粉(6)像素（背景色不是黑色，黑色仅表示遮挡）。

**关键洞察**：两种损伤类型（黑色遮挡与粉色掩码）需要不同的修复机制，且修复必须分阶段进行——部分粉色像素的对称伙伴在第一阶段之前是黑色的，只有周期修复先还原了这些黑色像素，对称修复才能获得有效的参照值。

## 实现要求

1. `main(grid)` 必须实现新题描述中的确定性转换规则，不能只识别 `generate_input()` 的固定模板。禁止不同的input网格输出相同的output网格。
2. `generate_input()` 必须随机生成多样样例，不能固定死。随机维度应覆盖：网格大小、对象数量、位置、颜色、方向、形状参数或关键分支。注意若描述中存在若干，需实现而不是只有单个，包括object或者对应关系等等。且若涉及到最短路径，则输入网格中必涉及到多条路径，对选择造成干扰。
3. 生成器必须保证输入满足 `main()` 的隐式假设：对象不重叠、不越界、特殊标记唯一或可区分、匹配关系无歧义、关键分支出现概率相同。
4. 禁止把 ARC 颜色 id 、亮度、拼写等当作人类不可见的数值语义参与排序、大小比较或隐藏映射。颜色变化必须有可见结构线索。注意颜色亮度、拼写等也是不可见信息，若描述中出现违规的颜色id或者亮度，可自行使用少量的固定颜色替代，但注意生成时要在三个以内输入输出网格中对所有变换100%覆盖度。
5. 输出样例要视觉清晰，人类必须能从输入输出对中肉眼辨认出规律。具体要求：避免对象粘连、覆盖关系混乱、同一像素多重语义；不同逻辑步骤产生的结果不要大面积层叠在一起导致无法分辨哪个颜色属于哪个步骤；输入中各元素之间保持足够间距，输出中新增的标记/填充/路径等应与背景和已有元素在颜色上有明显区分；若规则涉及多层叠加，生成时控制对象密度和尺寸，确保叠加区域只占少数像素而非铺满整个网格。
