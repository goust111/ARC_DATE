## 新题 7：筛选压缩矩形阵列后 D4 对称补全

**组合逻辑**：[筛选](已有) + [压缩](已有) → [对称补全/对称轨道映射](创新：对称作用于压缩后的紧凑颜色网格而非原始网格) + [掩码像素](创新：粉色矩形作为整个格位的掩码)

**来源原语**：压缩/筛选/填充矩形/颜色网格/包围盒行列分组/最小尺寸过滤/忽略干扰项(0a1d4ef5), 对称补全/对称图案/掩码像素/对称轨道映射/全对称群轨道约束(47996f11)

**依赖链**：筛选去除干扰像素→压缩将有效矩形的颜色映射到紧凑网格→紧凑网格具有 D4 对称性但有粉色缺失位→利用 D4 轨道从已知位补全缺失位→还原到原始网格中对应矩形的颜色。不筛选则干扰破坏阵列分组，不压缩则对称性不可见，不用对称则粉色位无法确定颜色。

从散布的矩形中筛选有效对象并压缩为紧凑颜色表，再利用 D4 对称性补全表中的粉色缺失项，最后将补全后的颜色写回对应矩形。

**输入结构**：约 20x20 的网格，背景黑(0)。散布若干单色填充矩形（每个至少 3x3，严格填满其包围盒），形成一个隐含的方阵排列（如 4x4 或 5x5 的格位），矩形之间有不等的间距。部分格位的矩形被替换为同尺寸的粉(6)填充矩形（3-5 个粉色矩形），表示该格位颜色缺失。此外有少量干扰像素（单像素或 2 像素的非矩形连通分量）散布于矩形之间。有效矩形的颜色取自蓝(1)、红(2)、绿(3)、黄(4)、灰(5)、橙(7)。生成约束：阵列的行列数相同（方阵），且压缩后的颜色表满足 D4 对称性（在 0/90/180/270 度旋转及水平/竖直/两对角线翻转下不变）。每个粉色位在 D4 轨道中至少有一个非粉色伙伴。

**规则**：
1. 筛选：保留所有单色 4-连通分量且严格为矩形（宽>=3，高>=3，完全填满包围盒）的对象。忽略所有其他像素（干扰项）。
2. 压缩：将筛选后矩形的竖直包围盒区间分组为行，水平包围盒区间分组为列（区间重叠的归为同组）。构建紧凑的 NxN 颜色网格，每格取对应矩形的颜色。粉(6)矩形在颜色网格中记为粉(6)。
3. 对称补全：紧凑网格具有 D4 对称性。对每个粉(6)格位，收集其 D4 轨道中所有非粉格位的颜色（0/90/180/270 旋转 + 水平/竖直/两对角线翻转共最多 8 个位置），将粉色位替换为该唯一颜色。
4. 写回：将补全后的颜色写回原始网格中对应位置的矩形——将该粉(6)矩形的所有像素改为补全得到的颜色。其余像素（背景、干扰、有效矩形）不变。

**关键洞察**：对称性隐藏在两层抽象之下——原始网格中看不出 D4 对称（矩形大小不同、间距不等），必须经过筛选和压缩将空间结构提炼为颜色表后，对称性才显现。三步操作形成不可跳步的推理链。
