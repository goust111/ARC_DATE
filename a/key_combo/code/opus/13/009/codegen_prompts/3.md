## 新题 3：射线延伸划分腔室后按标记多数色填充

**组合逻辑**：[射线延伸](已有) → [交叉](创新：交叉点产生的新颜色同时参与腔室边界定义) + [连通腔室](创新：腔室由延伸线动态创建) → [计数](已有) + [邻接多数决](创新：从边界投票改为内部标记统计) → [填充](已有)

**来源原语**：射线延伸/交叉/交叉点标记新色(bdad9b1f), 填充/连通腔室/分隔墙/标记像素/邻接多数决(7c8af763), 计数/频率统计(81c0276b)

**依赖链**：短条段延伸为全宽/全高线→线条划定腔室边界→交叉点标记黄色→腔室内标记像素的多数颜色决定腔室填充色。线条位置决定腔室形状，腔室形状决定哪些标记归属哪个腔室。删除延伸则无腔室，删除标记统计则无填充依据。

将水平和竖直短条段延伸为全跨线，交叉点标黄，由此形成的矩形腔室用其内部标记像素的多数色填充。

**输入结构**：约 14x14 的网格，背景黑(0)。包含 2-3 条水平短条段和 2-3 条竖直短条段，每条 1 像素宽、长 2-4 像素，颜色各不相同（从蓝(1)、红(2)、绿(3)、橙(7) 中取）。任意两条同方向条段不在同一行/列。另有 8-15 个单像素标记散布在网格中，颜色从蓝(1)、红(2)、绿(3)、橙(7) 中取（与条段颜色可重复）。条段和标记互不重叠。生成约束：每条水平条段与每条竖直条段的行列交叉点处为黑(0)（即交叉点在条段原始范围之外）。延伸后形成的每个腔室内至少有一个标记像素，且每个腔室内存在唯一多数色（无平局）。

**规则**：
1. 将每条水平条段沿其所在行延伸至网格全宽，保留原色。将每条竖直条段沿其所在列延伸至网格全高，保留原色。
2. 水平线与竖直线的交叉像素涂为黄(4)。
3. 延伸后的线条（含交叉点）将背景分割为若干矩形腔室（4-连通黑色区域）。
4. 对每个腔室，统计其内部标记像素各颜色的数量，将整个腔室填充为数量最多的颜色。
5. 绘制顺序：先填充腔室，再绘制线条（线条覆盖填充），最后绘制交叉点黄色（覆盖线条）。标记像素被腔室填充覆盖（不保留原始标记）。

**关键洞察**：条段的位置同时决定了两件事——腔室的几何边界和标记的归属划分。移动任何一条线段都会改变多个腔室的标记组成，从而改变多个腔室的填充色。求解者必须先完成延伸才能判断哪些标记属于哪个腔室。
