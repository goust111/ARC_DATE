## 新题 5：镜像精灵位置后按像素数生成衰减楔形

**组合逻辑**：[平移/镜像位置](创新：保留朝向的位置镜像产生楔形起点) + [计数](创新：像素数不用于排序而用于确定几何尺寸) → [填充/距离递变](创新：楔形从镜像位置而非原始位置展开) + [碰撞阻挡](创新：楔形之间的重叠由像素数少者优先)

**来源原语**：平移/镜像位置/内部朝向不变(8ee62060), 填充/距离递变/三角楔形/逐行宽度递变成楔(a65b410d), 计数(81c0276b), 碰撞阻挡(5ffb2104)

**依赖链**：原始对象的位置经镜像变换→镜像位置成为楔形起点→原始对象的像素数决定楔形基底宽度→楔形向下逐行递减→多个楔形重叠时像素数少的对象优先（小楔形画在上层）。位置属性和数值属性分别来自对象的两个独立维度，共同决定输出图案。

将左半区的小对象镜像到右半区，从镜像位置向下生成宽度等于该对象像素数的三角楔形，重叠时小对象优先绘制在上层。

**输入结构**：约 16x16 的网格，背景黑(0)。在网格左半区（列 0 到列 7）散布 3-5 个单色 4-连通小对象，每个对象 3-6 像素，包围盒不超过 3x3，颜色互不相同（从蓝(1)、红(2)、绿(3)、橙(7)、青(8) 中取）。各对象互不相邻，且都位于网格上半区（行 0 到行 7）。生成约束：各对象镜像后的位置互不重叠，且楔形不超出网格底边（即对象行号 + 对象像素数 <= 网格高度）。

**规则**：
1. 清除输入中的所有前景对象，生成空白黑(0)画布。
2. 对每个对象，计算镜像位置：行不变，列镜像（new_col = grid_width - object_width - old_col），内部像素布局不翻转（朝向不变）。
3. 在镜像位置绘制该对象（保留原色原形）。
4. 从该对象镜像位置的包围盒底边的最左列开始，向下逐行填充该对象的颜色：第 1 行（紧接包围盒下方）宽度 = 对象像素数 P，第 2 行宽度 = P-1，...，第 P 行宽度 = 1。每行左对齐于包围盒最左列。超出网格右边界的部分截断。
5. 绘制顺序：先绘制像素数多的对象及其楔形，再绘制像素数少的对象及其楔形（后绘制的覆盖先绘制的）。像素数相同时，原始位置更靠上的对象后绘制。

**关键洞察**：对象的空间属性（位置）和数值属性（像素数）分别控制输出的不同维度——镜像位置决定楔形的水平起点，像素数决定楔形的纵向延伸范围和宽度。两者缺一不可，且重叠规则进一步耦合了不同对象之间的关系。
