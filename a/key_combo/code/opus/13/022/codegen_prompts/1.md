## 新题 1：凸起计数排名驱动的分色传播

**组合逻辑**：[凸起/tab 分析](创新：从边界特征分析转为全局计数指标) → [排序/sorting](已有) → [重涂色/recolor](已有) → [邻接传色/adjacency_transfer](已有)

**来源原语**：凸起/tab（8dab14c2）、排序/sorting + 高度排名/height_ranking（a61f2674）、重涂色/recolor（a61f2674, c3fa4749）、邻接传色/adjacency_transfer + 标记接触即赋色/marker_touch_color（b7256dcd）、中性遮罩/neutral_mask（b7256dcd）

**依赖链**：边界凸起计数 → 全局排名确定哪个对象获得哪种颜色 → 重涂色改变对象颜色 → 邻接传色将新颜色传播到相邻中性区域。每一步的输出是下一步不可替代的输入：不计数就无法排名，不排名就不知道涂什么色，不涂色则中性区域无法获得正确传播色。

在黑(0)背景上有若干厚实的直角多边形前景对象和相邻的中性区域，通过分析每个对象的边界凸起数量进行全局排名，将极值排名对象分别涂为指定颜色，再将新颜色传播到各对象相邻的中性区域。

**输入结构**：约 18x18 的网格，背景为黑(0)。包含 3~5 个互不相邻的灰(5) 4-连通厚实直角多边形前景对象（每个对象约 8~20 像素，宽度至少 2 像素，形状各异——有的呈阶梯状、有的呈凹字形等）。每个对象的边界上有若干 1 像素凸起（凸起定义：仅有 1 个同色 4-邻居的边界像素）。每个对象的凸起数量互不相同（生成约束）。每个对象至少有一个边（可多个边）与一片橙(7)的中性遮罩区域 4-邻接，中性区域为 2~6 像素的 4-连通分量，彼此不相邻，且每个中性区域只与一个灰对象邻接（生成约束）。

**规则**：
1. 对每个灰(5)前景对象，计算其边界凸起数量（凸起 = 恰好有 1 个灰色 4-邻居的灰色像素）。
2. 将凸起数最多的对象重涂为蓝(1)，凸起数最少的对象重涂为红(2)，其余对象保持灰(5)不变。
3. 对每个橙(7)中性遮罩区域，找到与其 4-邻接的前景对象（经步骤 2 可能已变色），将该中性区域重涂为该对象当前的颜色。
4. 其余所有像素（背景、不与任何中性区域相关的像素）保持不变。

**关键洞察**：凸起不是需要补全的边界缺陷，而是全局排名的计数依据——必须遍历所有对象统计凸起后才能确定哪个对象获得哪种颜色，而颜色传播到中性区域又依赖排名结果，形成跨对象的信息聚合链。
