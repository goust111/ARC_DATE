## 新题 6：引导掩码选定精灵体 + 全局对角周期填色

**组合逻辑**：[引导掩码/guide_mask + 包围框包含/bbox_containment](已有) ⊕ [对角线同余/diagonal_residue 周期填色](创新：对角周期不是修复缺失，而是根据精灵体全局位置生成填充色) → [裁剪/crop](已有)

**来源原语**：引导掩码/guide_mask + 空心精灵体/hollow_sprite + 包围框包含/bbox_containment + 唯一被框选对象/uniquely_enclosed（bf699163）、对角周期图案/diagonal_periodic_pattern + 对角线同余/diagonal_residue（c3f564a4）、裁剪/crop（bf699163）

**依赖链**：两条独立的分析路径在最终输出处汇合——路径 A：引导掩码的包围框确定输出哪个精灵体；路径 B：所有精灵体的颜色和位置构成一个对角周期映射，决定每个精灵体中心空洞的填充色。两条路径缺一不可：不做引导选择就不知道输出哪个，不做全局对角分析就不知道空洞填什么色。

在若干空心精灵体和一个引导掩码中，通过引导掩码选定目标精灵体，同时用所有精灵体位置构建的对角周期规则填充所有空心中心，最终裁剪输出被选中的精灵体（含其填充后的中心）。

**输入结构**：约 15x15 的网格，背景为黑(0)。包含 4~6 个 3x3 空心正方形精灵体（边框 8 像素为某前景色，中心 1 像素为黑(0)空洞），每个精灵体边框颜色不同（使用蓝(1)、红(2)、绿(3)、黄(4)等不同颜色）。精灵体之间间距至少 2 像素，互不相邻。另有一组品红(6)像素构成稀疏引导掩码（3~5 个散落像素），其包围框恰好完整包含某一个精灵体且不包含其他精灵体（生成约束）。引导掩码像素本身不与任何精灵体重叠。

**规则**：
1. 识别所有 3x3 空心正方形精灵体（边框 8 像素同色、中心 1 像素为黑(0)的 4-连通分量）及其边框颜色和中心位置 (r, c)。
2. 将所有精灵体的边框颜色按其中心位置排序（按行优先、列其次，即从上到下、从左到右），形成颜色序列 C = [c0, c1, c2, ...]。
3. 对每个精灵体，计算其对角同余值 d = (r + c) mod len(C)，将中心空洞填充为 C[d]（即颜色序列中第 d 个颜色）。
4. 找到品红(6)引导掩码像素，计算其包围框。
5. 在所有精灵体中，找到唯一一个完整落在引导掩码包围框内的精灵体。
6. 输出该精灵体的 3x3 裁剪（包含已填充的中心像素）。

**关键洞察**：引导掩码仅负责"选哪个"，但被选精灵体中心的填充色取决于所有精灵体的全局空间分布——改变任何一个精灵体的位置都会改变对角周期映射，从而改变所有精灵体的中心填色。求解者必须同时理解两个独立的子问题（选择 + 填色）并在输出端组合。
