## 新题 5：压缩介导的面板序列外推

**组合逻辑**：[压缩/compress + 分区采样/block_sampling](已有) → [序列外推/sequence_extrapolation](创新：外推发生在压缩表示上而非原始像素上) → [像素放大/pixel_upscale](已有，作为逆压缩的扩展回复)

**来源原语**：压缩/compress + 分区采样/block_sampling + 分区网格/partitioned_grid（5783df64）、序列外推/sequence_extrapolation + 面板帧/panel_frame + 分隔行/separator_row + 恒定偏移平移/constant_offset_translation（351d6448）、像素放大/pixel_upscale（c59eb873）

**依赖链**：将每个面板压缩为摘要网格 → 在压缩序列上识别外推规则（像素级规则在全尺寸面板上被噪声干扰，压缩后才可见） → 生成下一帧压缩摘要 → 将摘要扩展回全尺寸面板。压缩是"看见"规律的前提，外推是生成新帧的手段，扩展是还原尺度的必要步骤。

输入是一叠面板，每个面板是可按分区压缩的大网格；压缩后的摘要序列呈现出简单的平移规律，外推出下一帧摘要后再扩展回全尺寸输出。

**输入结构**：约 30x10 的网格（高远大于宽）。由灰(5)全宽分隔行分为 3 个等高面板，每个面板为 9x9（即 9 行 10 列中 9 列为面板内容，含左右各可能的边距）。实际面板内容区为 9x9。每个面板可视为 3x3 的分区网格（每个分区为 3x3 的子块）。背景为黑(0)。每个 3x3 子块中恰好有 1 个非黑前景像素（颜色为红(2)、蓝(1)、绿(3)等），其余为黑(0)。从面板 1 到面板 3，前景像素在各子块内的位置可能变化，但压缩后（每个子块取其唯一前景色）得到的 3x3 摘要网格呈现简单的空间变换规律：整个前景图案在 3x3 摘要中以恒定偏移平移（如每帧向右移 1 列，循环回绕）。不同示例中平移方向和步长不同（生成约束：平移规律在 3 帧内可唯一确定）。

**规则**：
1. 用灰(5)分隔行将输入切分为 3 个面板，每个面板是 9x9 网格。
2. 将每个面板按 3x3 分区压缩：每个 3x3 子块中的唯一非黑色成为对应摘要像素的颜色，得到 3x3 摘要网格。
3. 比较 3 个摘要网格，找出帧间变换规律（恒定偏移平移，行偏移 dr 和列偏移 dc 每帧相同，越界时循环回绕）。
4. 对第 3 帧摘要施加一次相同的偏移，生成第 4 帧摘要。
5. 将第 4 帧摘要扩展回 9x9 面板：摘要中位置 (i,j) 的颜色 c 放置在对应 3x3 子块的中心像素 (3i+1, 3j+1)，子块其余位置为黑(0)。
6. 输出仅为扩展后的 9x9 面板（不含分隔行和其他面板）。

**关键洞察**：外推规律在全尺寸 9x9 面板上几乎不可见（前景像素稀疏且散落在大网格中），但压缩到 3x3 摘要后规律一目了然。压缩不是最终目标而是"感知辅助"——改变表示粒度使隐藏规律显现，这是求解者必须发现的核心推理步骤。

3. 生成器必须保证输入满足 `main()` 的隐式假设：对象不重叠、不越界、特殊标记唯一或可区分、匹配关系无歧义、关键分支出现概率相同。
4. 禁止把 ARC 颜色 id 、亮度、拼写等当作人类不可见的数值语义参与排序、大小比较或隐藏映射。颜色变化必须有可见结构线索。注意颜色亮度、拼写等也是不可见信息，若描述中出现违规的颜色id或者亮度，可自行使用少量的固定颜色替代，但注意生成时要在三个以内输入输出网格中对所有变换100%覆盖度。
5. 输出样例要视觉清晰，人类必须能从输入输出对中肉眼辨认出规律。具体要求：避免对象粘连、覆盖关系混乱、同一像素多重语义；不同逻辑步骤产生的结果不要大面积层叠在一起导致无法分辨哪个颜色属于哪个步骤；输入中各元素之间保持足够间距，输出中新增的标记/填充/路径等应与背景和已有元素在颜色上有明显区分；若规则涉及多层叠加，生成时控制对象密度和尺寸，确保叠加区域只占少数像素而非铺满整个网格。
6. 若规则有多个分支，生成器不能长期固定成一个分支；应让分支在随机样例中合理出现。分支概率不必平均——难以发现的隐蔽分支（如少数情况下才触发的特殊规则）应适当提高出现概率，确保在 3 个训练示例中至少出现一次，否则求解者无法归纳该规则。对于颜色映射类规则，确保 2 个左右的示例即可覆盖所有映射关系（每种颜色→颜色的映射至少在某个示例中出现过）。
