## 新题 7：按封闭区域内容排序的精灵体图集打包

**组合逻辑**：[提取摘要/extract_summary + 封闭区域/enclosed_region](创新：从网格表格压缩变为单个精灵体内部空洞内容的量化) → [排序/sorting](创新：排序依据从竖直线段高度变为空洞内像素计数) → [紧凑排列/compact_packing](已有)

**来源原语**：提取摘要/extract_summary + 封闭区域/enclosed_region + 不接触边缘/not_touching_edge（ac6f9922）、排序/sorting + 高度排名/height_ranking（a61f2674）、紧凑排列/compact_packing + 精灵体/sprite + 按输入位置排列/order_by_input_position（1990f7a8）、裁剪/crop（1990f7a8）

**依赖链**：分析每个精灵体内部封闭区域中的前景像素数量 → 按此数量排序 → 排序结果决定打包顺序（替代原题中的空间位置排序）。内容分析驱动了空间排列，而非空间位置驱动。

将散落的精灵体按其内部封闭空洞中包含的前景像素数量排序，然后按排名紧凑打包为 2x2 图集。

**输入结构**：约 20x20 的网格，背景为黑(0)。包含恰好 4 个互相分离的 8-连通灰(5)前景精灵体，每个精灵体限制在一个 5x5 包围框内。每个精灵体的灰(5)像素围成一个封闭区域（即精灵体有一个"洞"——被灰色完全包围的黑(0)像素组成的 4-连通分量，不接触网格边缘）。每个封闭区域内包含 0~3 个红(2)前景像素（不同精灵体内的红色像素数量互不相同，生成约束）。精灵体在网格中的空间位置随机分布，不遵循特定的行列对齐规律。

**规则**：
1. 找到 4 个 8-连通灰(5)精灵体，裁剪每个精灵体的 5x5 包围框（保留内部黑(0)空洞和红(2)前景像素）。
2. 对每个精灵体，找到其内部封闭的黑(0)区域（被灰色完全包围、不接触网格边缘的 4-连通黑色分量）。
3. 计算每个封闭区域中红(2)像素的数量（0、1、2、3）。
4. 按红色像素数量升序排列 4 个精灵体。若数量相同（生成约束排除此情况），则按精灵体包围框左上角的行坐标升序排列。
5. 将排序后的 4 个裁剪结果打包为 2x2 图集：排名第 1（最少）放左上，排名第 2 放右上，排名第 3 放左下，排名第 4（最多）放右下。相邻精灵体之间有 1 行/1 列黑(0)间隔，输出为 11x11 的画布。

**关键洞察**：打包顺序不由精灵体在输入中的空间位置决定（与参考题 1990f7a8 完全不同），而由每个精灵体内部封闭区域的红色像素计数决定——这是一个从"内容"到"布局"的映射，求解者必须发现内部细节驱动外部排列的逻辑。
