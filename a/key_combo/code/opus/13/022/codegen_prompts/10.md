## 新题 10：图例展开串按竖直线段高度排序堆叠

**组合逻辑**：[展开/expand + 图例锚定对齐/legend_anchored_alignment](已有) → [排序/sorting + 高度排名/height_ranking](创新：排序依据从竖直线段自身高度变为"与标记同色的竖直线段的高度") → [纵向拼接/vertical_stacking](已有)

**来源原语**：展开/expand + 边缘图例串/edge_legend_string + 孤立标记/isolated_marker + 图例锚定对齐/legend_anchored_alignment + 颜色位置匹配/color_position_matching（5af49b42）、排序/sorting + 高度排名/height_ranking + 竖直线段/vertical_bar（a61f2674）、纵向拼接/vertical_stacking（8be77c9e）

**依赖链**：每个标记像素展开为图例串（确定内容行） → 每个标记的颜色关联到同色竖直线段 → 线段高度决定展开行的堆叠顺序。展开和排序使用同一组标记颜色但提取不同信息（展开用颜色在图例中的位置，排序用颜色对应线段的高度），两条信息流在堆叠步骤汇合。

将散落的单像素标记各自展开为完整的图例串，然后根据每个标记颜色所对应的竖直线段高度对展开结果进行排序，最终按排名纵向堆叠输出。

**输入结构**：约 15x12 的网格，背景为黑(0)。结构分为三个区域：

顶部区域（第 0 行）：一行水平的边缘图例串，包含 K 种不同前景颜色（K 在 3~5 之间），如 [蓝(1), 红(2), 绿(3), 黄(4)]，从左侧开始连续排列，其余位置为黑(0)。

中部区域（第 2~6 行左右）：K 个孤立标记像素（单像素），每个标记颜色恰好是图例串中的某一种颜色，且每种颜色恰好一个标记。标记散落在中部区域的不同行和列上（每个标记在不同行，生成约束）。

底部区域（第 8 行至底部）：K 条竖直线段（每条宽 1 像素），颜色分别与图例串中的 K 种颜色一一对应。线段底端对齐（都在最后一行），高度各不相同（高度范围 2~6 像素），线段之间至少间隔 1 列。各线段高度互不相同（生成约束）。

各区域之间有至少 1 行黑(0)背景间隔。

**规则**：
1. 识别顶部图例串：第 0 行中所有非黑像素构成的水平颜色序列 L = [L0, L1, ..., L_{K-1}]。
2. 识别中部的 K 个孤立标记像素及其颜色和所在行。
3. 对每个标记，执行图例展开：将图例串 L 水平放置在标记所在行上，位移使得 L 中与标记同色的那个位置对齐到标记的列坐标上。展开结果超出网格左右边界的部分舍弃。
4. 识别底部的 K 条竖直线段及其颜色和高度。
5. 为每个标记赋予排序键：找到与标记同色的竖直线段，取其高度作为排序键。
6. 按排序键从大到小（最高线段对应的标记排在最上方）排列所有展开行。
7. 将排序后的 K 行展开结果紧密纵向堆叠（无间隔行），形成 K 行 x 网格宽度的输出。

**关键洞察**：图例串同时扮演两个角色——它是展开操作的模板（标记展开为完整图例），也通过颜色将标记与竖直线段关联起来。展开使用标记颜色在图例中的位置来对齐，排序使用标记颜色对应线段的高度来排名——两个操作从同一颜色中提取了完全不同的信息维度。
