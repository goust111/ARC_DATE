## 新题 9：双源集成——压缩摘要着色格点补全

**组合逻辑**：[压缩/compress + 提取摘要/extract_summary](已有) ⊕ [笛卡尔积缺位填充/cartesian_product_gap_fill + 印章覆盖/stamp_overlay](已有) → [重涂色/recolor](创新：摘要网格作为颜色映射表驱动格点精灵体变色)

**来源原语**：压缩/compress + 提取摘要/extract_summary + 封闭区域/enclosed_region + 网格表格/grid_table + 不接触边缘/not_touching_edge（ac6f9922）、笛卡尔积缺位填充/cartesian_product_gap_fill + 同形精灵体/identical_sprite + 行列格点/row_column_lattice + 印章覆盖/stamp_overlay + 格点对齐/lattice_alignment（5b526a93）、重涂色/recolor（a61f2674）

**依赖链**：左半部分的网格表格压缩为颜色矩阵 → 右半部分的格点补全确定空间布局 → 颜色矩阵的 (i,j) 位置颜色对应格点第 i 行第 j 列精灵体的涂色。两个半区各自编码输出的一个维度（颜色 vs. 空间），缺任一半都无法生成输出。

输入被垂直分隔线分为两个半区：左半区是一个网格表格（压缩后得到颜色矩阵），右半区是一个有缺位的精灵体格点（补全后得到空间布局）；将颜色矩阵作为着色指令施加到完成的格点上，输出着色后的完整格点。

**输入结构**：约 15x30 的网格（宽大于高），背景为黑(0)。中央有一条垂直的栗(9)分隔线（1 像素宽，贯穿全高）将网格分为左右两个半区。

左半区（约 15x14）：包含一个由灰(5)线条构成的网格表格框架，框架围出 3x3 共 9 个封闭的矩形区域（每个约 3x3 像素）。部分区域内含有 1 个有色像素（颜色各异，取自蓝(1)、红(2)、绿(3)、黄(4)），其余区域为空（全黑(0)）。至少 5 个区域有内容（生成约束）。

右半区（约 15x14）：包含若干个相同形状的蓝(1) 4-连通精灵体（每个约 3x3 像素，非矩形的不规则小图形），排列在一个 3x3 的行列格点上。格点中有 2~4 个位置缺失（空）。已有精灵体至少覆盖了 3x3 格点的每一行和每一列各至少一个位置（生成约束）。

**规则**：
1. 以栗(9)垂直分隔线为界，将输入分为左半区和右半区。
2. 左半区：找到灰(5)框架围出的所有封闭区域，按位置排为 3x3 矩阵（行从上到下 0-2，列从左到右 0-2）。提取每个区域的摘要颜色：区域内有非黑像素则取该颜色，否则为黑(0)。得到 3x3 颜色矩阵 M。
3. 右半区：识别所有已有精灵体，提取公共形状模板。确定格点的行坐标集合和列坐标集合（从已有精灵体位置推断）。
4. 补全格点：在每个空缺位置，用精灵体模板的副本填入（颜色暂定为蓝(1)，与已有精灵体相同）。
5. 着色：对格点中第 i 行第 j 列的精灵体（i, j 从 0 开始），查询颜色矩阵 M[i][j]。若 M[i][j] 非黑(0)，则将该精灵体所有像素重涂为 M[i][j]；若 M[i][j] 为黑(0)，则保持蓝(1)不变。
6. 输出仅包含右半区（去除分隔线和左半区），即着色后的完整 3x3 格点。

**关键洞察**：输入的两个半区分别编码了输出的不同维度——左半区通过网格表格编码"每个位置应该是什么颜色"，右半区通过格点结构编码"每个位置应该放什么形状"。任何一半都无法独立产生输出，且两者通过 (i,j) 坐标映射耦合。

<description>
Complete scaled copies of the blue source template at matching red marker squares.

Input structure
- A black background contains one 4-connected mixed-color template object and detached same-color target squares.
- The template has source-color pixels and marker-color pixels; the detached marker objects are solid k x k squares.
- The output shape is unchanged.

Rule
- Use the template bbox as the pattern coordinate system.
- Group target marker squares into sets whose top-left corners match the template marker coordinates at one common scale k.
- For each matched group, scale every source-color template cell to a k x k block and paint it at that instance's origin, clipping any part outside the grid.

Key insight
The detached marker squares are enlarged copies of the template's marker cells; their side length gives the scale for copying the source-color cells.
