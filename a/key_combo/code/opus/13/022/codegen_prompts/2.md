## 新题 2：对称补全揭示隐藏连接器的拼装

**组合逻辑**：[对称补全/symmetry_completion](创新：补全的目的不是视觉修复而是揭示隐藏的连接信息) → [同色标记对齐对接/same_color_dock](已有) → [裁剪/crop](已有)

**来源原语**：对称补全/symmetry_completion + 双轴镜像轨道/two_axis_orbit + 缺失像素/missing_pixel（af22c60d）、同色标记对齐对接/same_color_dock + 连接标记/connector_marker + 标记侧面决定方向/marker_side_dir（e9fc42f2）、裁剪/crop（1990f7a8）

**依赖链**：每个物体有黑(0)缺失像素破坏了其二轴对称 → 对称补全恢复完整图案 → 补全后的像素中出现了之前被遮蔽的连接器标记颜色 → 用标记颜色匹配进行对接拼装 → 裁剪输出。对称补全不仅修复外观，更是"解密"步骤：不补全就看不到连接器，无法决定如何拼装。

将若干带有缺失像素的多色前景物体进行二轴对称补全以揭示隐藏的连接器标记颜色，然后按同色标记对接拼装所有物体，紧凑裁剪输出。

**输入结构**：约 20x20 的网格，背景为黑(0)。包含 3~4 个互不重叠的多色 4-连通前景物体，彼此间距至少 3 像素。每个物体主体为蓝(1)，约 5x5~7x7 像素，本身具有关于水平轴和垂直轴的二轴对称结构。但每个物体有 2~4 个像素被替换为黑(0)（缺失），破坏了对称性。在补全这些缺失像素后，部分恢复的像素颜色不是蓝(1)而是特定的连接器颜色（红(2)、绿(3)、黄(4)等），且这些连接器像素恰好位于物体边界上。每种连接器颜色恰好出现在两个不同物体上（生成约束），形成配对。连接器像素所在物体边界的朝向（上/下/左/右）决定了对接方向。

**规则**：
1. 对每个前景物体，确定其二轴对称的水平和垂直反射轴（从可见的非缺失像素推断）。
2. 对每个黑(0)缺失像素，收集其水平镜像、垂直镜像和双轴镜像位置上的已知颜色（仅考虑物体边界框内的镜像位置），将缺失像素填充为轨道内的唯一已知颜色。
3. 补全后，识别每个物体边界上的非主体色（非蓝(1)）像素作为连接器标记。
4. 对每对同色连接器标记，将两个物体平移对接：两个标记像素在各自物体边界的外露方向相对，平移后标记像素边对边接触。若标记在物体右边界则该物体从左侧靠近，若在上边界则从上方靠近，以此类推。
5. 当有多对连接器时，按连接器颜色在调色板中的编号从小到大依次对接（先对接红(2)、再绿(3)、再黄(4)等）。每次对接固定已对接的物体组，新物体向已对接组平移。
6. 对接完成后，输出所有物体的紧凑裁剪（最小包围框），背景填黑(0)。

**关键洞察**：黑色缺失像素不是随机破损——它们精确遮蔽了连接器标记的位置，使得不做对称补全就无法发现物体间的拼装关系。对称补全是一个"信息解密"步骤，而非纯粹的视觉修复。
