## 新题 2：周期种子射线遇壁反弹并继承壁色

**组合逻辑**：[射线延伸(ray_extend) + 种子周期生长(seed_periodic_growth)](创新：周期间隔使射线对墙壁产生"盲区") → [反弹(bounce) + 颜色继承(color_inheritance)](创新：反弹仅在射线步进点恰好命中墙壁时触发) → [碰撞停止(collision_stop)]

**来源原语**：射线延伸(ray_extend) ← 3ac3eb23；种子周期生长(seed_periodic_growth) ← 3ac3eb23；反弹(bounce) ← 142ca369；颜色继承(color_inheritance) ← 142ca369；碰撞停止(collision_stop) ← 142ca369；墙壁像素(wall_pixel) ← 142ca369；轨迹(trail) ← 3ac3eb23

**依赖链**：种子周期生长决定射线的落点序列（每隔一格），只有落点恰好与墙壁重合才触发反弹和颜色继承；若取消周期性（每格都落），射线会更早命中墙壁，路径完全不同；若取消反弹，射线直接终止而非改变方向。周期性和反弹的交互产生了"墙壁盲区"这一涌现效应。

种子发射隔行对角射线，仅当步进点命中彩色墙壁时反弹并变色，步进间的墙壁被"跨过"。

**输入结构**：黑(0)背景，约 15x15 网格。包含 2-3 个孤立彩色种子像素（各不同色，如蓝(1)、红(2)），以及 4-8 个彩色墙壁像素（颜色与种子不同，如绿(3)、黄(4)、橙(7)），散布于网格中。种子像素之间至少间隔 5 个像素。生成约束：每条射线路径上至少有一个墙壁恰好落在奇数步位置（确保至少一次反弹可观察），并且至少有一个墙壁落在偶数步位置（确保"盲区跨越"可观察）。

**规则**：
1. 从每个种子像素出发，向右下方发射对角射线，步进序列为 (r+1,c+1), (r+2,c+2), (r+3,c+3), ...，但仅在**奇数步**（第 1, 3, 5, 7... 步）放置轨迹像素。偶数步位置不放置像素也不检测碰撞。
2. 当某个奇数步位置恰好是一个墙壁像素时，触发反弹：射线的行方向取反（原来向下变为向上，或原来向上变为向下），列方向不变。反弹后射线颜色变为该墙壁像素的颜色。墙壁像素本身保留原色。
3. 反弹后步数计数器重置为 0，继续按新方向前进，同样仅在奇数步放置轨迹像素并检测碰撞。
4. 射线在以下情况终止：(a) 步进位置超出网格边界；(b) 奇数步位置是另一个种子像素。
5. 各射线独立处理，绘制顺序按种子在网格中从左上到右下的阅读顺序。后绘制的轨迹像素覆盖先绘制的。

**关键洞察**：周期性步进（隔行放置）使射线对偶数步位置上的墙壁"视而不见"，这一盲区效应在参考题中不存在——参考题的周期生长无反弹（3ac3eb23），参考题的反弹射线无周期间隔（142ca369）。
