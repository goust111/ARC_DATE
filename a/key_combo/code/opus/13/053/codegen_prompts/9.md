## 新题 9：T 形方向标记指定分离精灵的角落位置

**组合逻辑**：[分离(separate)](来自 b1fc8b8e) → [方向标记(direction_marker) + 朝向决定粘贴侧(orientation_determines_side)](创新：T 标记的四个朝向映射到四个角落而非上下两侧) → [印章覆盖(stamp_overlay) + 四角布局(four_corner_layout) + 插入空行列间隔(insert_blank_gap)]

**来源原语**：分离(separate) ← b1fc8b8e；四角布局(four_corner_layout) ← b1fc8b8e；插入空行列间隔(insert_blank_gap) ← b1fc8b8e；方向标记(direction_marker) ← 4c177718；朝向决定粘贴侧(orientation_determines_side) ← 4c177718；印章覆盖(stamp_overlay) ← e6721834；标记锚定精灵(marker_anchors_sprite) ← e6721834

**依赖链**：分离操作将紧凑排列的精灵拆开（确定各精灵的身份和形状），T 标记的朝向将每个精灵分配到特定角落（朝向 → 位置映射），印章覆盖将精灵放入目标位置。删除分离则不知道有哪些精灵；删除 T 标记则不知道各精灵去哪个角落；删除印章覆盖则无法组装输出。

从紧凑堆叠中分离四个精灵，依据各自旁边 T 标记的朝向将其分配到 5x5 输出的四个角落。

**输入结构**：黑(0)背景，约 10x10 网格。中央有一个约 4x4 至 5x5 的区域，其中包含 4 个不同颜色的 2x2 精灵（如蓝(1)、绿(3)、黄(4)、橙(7)），以平移方式紧凑排列（部分精灵相邻共享边，覆盖整个区域的大部分像素但不重叠）。在紧凑区域的四周（上/下/左/右各一侧），各有一个红(2)色 T 形方向标记（3x3 边界框内的 5 像素 T 形，横臂在顶部或底部、或竖臂在左侧或右侧），每个 T 标记最近的精灵就是它所指定的精灵。T 标记与紧凑区域之间间隔 1 像素。4 个 T 标记的横臂/竖臂朝向各不相同（分别指向上/右/下/左四个方向之一）。生成约束：每个精灵恰好是一个 T 标记的最近精灵（通过精灵中心到 T 标记中心的曼哈顿距离判断，无平局）。

**规则**：
1. 识别紧凑区域中的 4 个 2x2 精灵（按颜色分离，每种颜色恰好 4 个像素构成一个 2x2 方块）。
2. 识别 4 个红(2) T 形方向标记。每个 T 标记的横臂方向（横臂所在侧）定义其"指向"：横臂在顶部 → 指向上 → 分配到左上角；横臂在右侧 → 指向右 → 分配到右上角；横臂在底部 → 指向下 → 分配到右下角；横臂在左侧 → 指向左 → 分配到左下角。
3. 将每个 T 标记与其最近的精灵配对（按精灵中心到 T 标记中心的曼哈顿距离，取最近者）。
4. 输出为 5x5 黑(0)网格。根据步骤 2 的分配规则，将每个精灵（2x2）印入对应角落：左上角 → (0:2, 0:2)；右上角 → (0:2, 3:5)；左下角 → (3:5, 0:2)；右下角 → (3:5, 3:5)。中间行（第 2 行）和中间列（第 2 列）保持黑(0)。

**关键洞察**：参考题 b1fc8b8e 中四个精灵无差别地进入四角，参考题 4c177718 中 T 标记只区分上/下两侧。此处 T 标记的四个朝向编码了四个角落位置——从二选一扩展到四选一。需要对比多个示例（T 标记朝向不同导致精灵到角落的分配不同）才能确定完整的朝向-角落映射。
