## 新题 6：杯口朝向决定精灵旋转角度后印入杯内

**组合逻辑**：[开口朝向(opening_direction)](来自 aba27056) → [旋转(rotate)](创新：旋转角度由杯口方向编码而非显式标记) → [印章覆盖(stamp_overlay) + 内部包含(interior_containment)](创新：印入目标是杯形容器内部而非面板)

**来源原语**：旋转(rotate) ← ff805c23；开口朝向(opening_direction) ← aba27056；杯形容器(cup_shape) ← aba27056；印章覆盖(stamp_overlay) ← 4c177718；精灵体(sprite) ← e6721834；示范到输出面板(demo_to_output_panel) ← 4c177718；裁剪(crop) ← ff805c23

**依赖链**：杯口朝向编码了旋转角度（几何属性 → 操作参数），旋转后的精灵必须与杯内部空间对齐才能正确印入。删除朝向检测则旋转角度未知；删除旋转则精灵方向错误；删除印章覆盖则无输出。

读取每个杯的开口方向，将统一精灵旋转相应角度后印入杯的内部空间。

**输入结构**：黑(0)背景，约 14x14 网格。上方 3 行为灰(5)背景的展示条，其中包含一个由蓝(1)像素构成的小型 4-连通精灵（3-5 像素，非旋转对称，如不规则 L 形或 Z 形），精灵的"自然朝向"为开口朝上。下方为黑(0)背景主区域，包含 2-4 个杯形容器，各杯由红(2)像素围成（壁厚 1 像素），内部空间均为 3x3 像素。各杯的开口方向不同（上/下/左/右），各杯之间至少间隔 3 像素。生成约束：精灵在裁剪后的边界框不超过 3x3（确保能放入杯内）；精灵旋转 90/180/270 度后的形状各不相同（确保旋转可观察）。

**规则**：
1. 从展示条中裁剪出蓝(1)精灵的最小边界框，记为基准精灵（朝向：开口朝上）。
2. 识别每个红(2)杯形容器及其开口方向。
3. 旋转映射：开口朝上 → 0 度（不旋转）；开口朝右 → 顺时针 90 度；开口朝下 → 180 度；开口朝左 → 顺时针 270 度。
4. 对每个杯，将基准精灵按该杯的旋转映射旋转，得到目标精灵。
5. 将目标精灵印入杯内部 3x3 空间，左上角对齐。仅在精灵像素为蓝(1)的位置写入蓝(1)，其余位置保持黑(0)。
6. 展示条中精灵像素在输出中保留不变。杯壁红(2)像素保留不变。

**关键洞察**：杯口方向在参考题 aba27056 中驱动射线发射方向，此处它被重新解释为旋转角度的编码器——两种用法的共同点是"几何朝向 → 操作参数"，但操作类型完全不同。需要对比多个开口方向的杯才能确定旋转映射规则。
