## 新题 7：面积排序的模板选择印入窗口格

**组合逻辑**：[排序sorting](创新：排序结果作为模板选择索引而非直接输出) + [印章覆盖stamp_overlay](创新：印章内容由面积排名间接决定) + [索引映射index_mapping](创新：映射的键是颜色，值是面积排名编号)

**来源原语**：排序+区域排列顺序(7447852a)、印章覆盖+颜色重叠匹配(d6542281)、窗口格+分隔线+标记像素+标记色定窗口填充(54d9e175)、索引映射+模板对象+行列位置对应+按控制色重涂(33b52de3)、面积排名(a8d7556c)

**依赖链**：模板区的多个模板按面积排序获得编号 → 窗口格中心标记像素的颜色通过固定映射指向编号 → 对应编号的模板被印章到该窗口格内。排序结果创建了一个动态图例——模板的面积排名决定其编号，标记颜色查询该编号——这种间接映射在任何源题中都不存在。

模板按面积排序后获得编号，窗口格中的标记颜色指定编号，对应模板被印入窗口。

**输入结构**：约 16x16 的网格，黑(0) 背景。灰(5) 水平和垂直线将网格上部区域分割为 3x3 或 4x3 的窗口格阵列，每个窗口格内部为 3x3 的黑色空间。每个窗口格的中心像素是一个标记像素，颜色为红(2)、蓝(1) 或绿(3) 三种之一。网格底部保留区（与窗口格阵列之间由一条灰线分隔）放置 3 个小模板形状，每个模板为不同颜色（橙(7)、黄(4)、品红(6)）的 4-连通小图形（2-5 像素），面积各不相同，模板之间间隔至少 2 列。生成约束：三个模板的面积严格不等；每个模板的边界框不超过 3x3（以适配窗口格）。

**规则**：
1. 识别底部保留区的 3 个模板形状及其面积（像素数）。
2. 按面积从小到大排序，赋予编号：最小 → 编号 1，中间 → 编号 2，最大 → 编号 3。
3. 窗口格中心标记颜色到编号的映射：红(2) → 编号 1，蓝(1) → 编号 2，绿(3) → 编号 3。
4. 对每个窗口格，根据其中心标记颜色查找对应编号，取该编号的模板形状，将模板居中印章到该 3x3 窗口格内。印章使用模板的原始颜色。若模板小于 3x3，则居中放置（边界框中心对齐窗口格中心），未覆盖的窗口格像素保持黑(0)。
5. 擦除底部保留区的所有模板形状（替换为黑(0)）。
6. 中心标记像素被模板印章覆盖（模板中心位置的像素替换标记颜色）。灰色分隔线保持不变。

**关键洞察**：标记颜色不直接对应模板颜色——它对应的是模板的面积排名编号。若更换模板（改变各模板的面积大小关系），同一个标记颜色可能指向不同的模板。必须对比不同示例中模板面积与窗口格内容的对应关系才能归纳出"颜色→排名编号→模板"的间接映射。
