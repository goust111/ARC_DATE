## 新题 5：封闭性与面积的同时约束决定重涂色

**组合逻辑**：[洪泛填充flood_fill](创新：用于拓扑分类而非直接填色) + [计数counting](创新：面积阈值由同类对象的中位数动态决定) + [重涂色recolor](创新：颜色由两个独立约束的交叉结果决定)

**来源原语**：洪泛填充(7447852a)、连通分量+面积排名(a8d7556c)、重涂色+面积超阈值则变色(ae58858e)、边缘与内部区分(8a371977)、封闭区域(a8d7556c)

**依赖链**：灰色墙壁构成迷宫 → 对每个红色连通分量做拓扑分类（是否被完全封闭） → 仅对封闭类分量计算面积中位数作为阈值 → 面积 >= 中位数的封闭分量涂蓝，面积 < 中位数的封闭分量涂绿 → 非封闭分量保持红色不变。拓扑分类和面积阈值是两个独立维度的约束，必须同时满足才能确定输出颜色。

灰色迷宫中的红色连通分量根据是否被完全封闭分为两类，封闭类内部再按面积中位数阈值分涂两种颜色。

**输入结构**：约 13x13 的网格，黑(0) 背景。灰(5) 像素构成不规则的迷宫状墙壁结构（非网格化，有弯折和分叉）。红(2) 前景像素散布于迷宫内部，形成 5-7 个 4-连通分量，面积各异（2-10 像素）。部分红色分量被灰色墙壁完全包围（从该分量出发，沿黑色像素 4-连通路径无法到达网格边缘），其余分量可通过黑色像素路径连通到网格边缘。生成约束：完全封闭的红色分量至少有 3 个（使中位数有意义）；封闭分量的面积不全相同；至少有一个封闭分量面积高于中位数且一个低于中位数。

**规则**：
1. 识别灰(5) 墙壁和所有红(2) 4-连通分量。
2. 对每个红色分量进行拓扑封闭性测试：从该分量的任意相邻黑(0) 像素出发，沿 4-连通黑色像素做洪泛扩展。若洪泛扩展无法到达网格边缘任何一行一列的边缘像素（所有路径都被灰色墙壁截断），则该分量为"封闭类"；否则为"通达类"。
3. 收集所有封闭类分量的面积（像素数），计算中位数 M。若封闭类分量数为偶数，M 取较小的中间值。
4. 将面积 >= M 的封闭类分量重涂色为蓝(1)。
5. 将面积 < M 的封闭类分量重涂色为绿(3)。
6. 通达类分量保持红(2) 不变。
7. 灰色墙壁和黑色背景保持不变。

**关键洞察**：颜色变换不是简单的"大变蓝、小变绿"——只有在拓扑上被完全封闭的分量才参与面积比较。通达类分量无论面积大小都保持红色。需要对比多个示例才能分离出"封闭性"和"面积阈值"这两个独立约束维度。

    structure: 8-connected meandering path from seed through the grid (1px wide, uses diagonal steps so NOT 4-connected)
    length: 6-45 line_color pixels per seed's component
    the line is part of a larger 8-connected non-bg component that includes frame loops
  frame_loops:
    count: 1-9 total across the grid (single-color-boundary cavities)
    shape: closed ring of a single frame_color enclosing bg pixels; cavity is mostly 2x2 rectangular (27/36 observed), occasionally larger
    each loop's boundary is entirely one frame_color; the line_color pixels touch the loop's OUTER edges (8-adjacent) without bordering the cavity directly
    1-4 distinct frame colors per example; a frame_color can form multiple loops
  connectivity:
    loops attached to the seed's line (8-connected via line_color) get their cavity filled with seed_color
    filled: 1-8 per example; unfilled (distractor): 0-5
    at least 1 unfilled cavity exists in 5/6 examples [observed]
  distractors:
    0-1 disconnected 8-connected non-bg components with no seed; may contain line+frame structure or be a single frame loop
  output: same grid with each connected cavity flood-filled by its seed's color

generation_strategy:
  approach: output-first
  steps:
    1. Choose grid size, bg color, 1-2 seeds with unique colors, and per-seed line_color
    2. For each seed, draw a meandering 8-connected line path from the seed's border position inward, using diagonal and orthogonal steps
    3. Along each line, attach 2-5 frame loops (closed rings of a frame_color enclosing a 2x2 bg cavity); the line touches the loop at 1-2 outer edge positions (8-adjacent to the frame ring)
    4. Place 0-3 additional distractor loops (same frame_color or different) NOT 8-connected to any line
    5. Optionally add 0-1 disconnected non-bg component as a distractor network
    6. Verify: each cavity has single-color boundary; cavities connected to a line are fillable; at least 1 unfilled cavity exists
    7. Output is derived by flood-filling each connected cavity with its seed_color
