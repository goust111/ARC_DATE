## 新题 4：反射图案的端点选择性膨胀

**组合逻辑**：[镜像reflect](已有) + [扩展expand](创新：膨胀不均匀，由反射后图案的局部连通性决定哪些像素膨胀) + [计数counting](创新：计数邻居数作为膨胀条件而非直接输出) + [擦除erase](已有)

**来源原语**：镜像+稀疏标记线+平行对称轴+跨标记线反射(66ac4c3b)、扩展+正交对角分工(0962bcdd)、计数(ae58858e)、引导像素+角落定位+角落色转移后消(aabf363d)

**依赖链**：引导像素提供颜色 → 前景图案跨标记线反射生成副本 → 副本的每个像素检测其在副本内的 4-邻居连通数 → 邻居数 <= 1 的端点像素向四方膨胀一格，邻居数 >= 2 的内部像素不膨胀。反射决定了副本的形状，形状的局部拓扑（端点 vs 内部）决定了膨胀行为——同一个反射操作的输出在不同位置产生不同的后续变换。

前景图案跨标记线反射后，反射副本的末端像素向外膨胀、内部像素保持不变，形成一个拓扑敏感的生长图案。

**输入结构**：约 14x12 的网格，黑(0) 背景。一条水平稀疏标记线由灰(5) 像素组成，位于网格的中间行附近（如第 5 行），标记线上的灰色像素间隔 2-3 格（即非连续，仅在若干列上有灰色像素）。标记线上方有一个红(2) 前景图案（不规则形状，4-8 个 4-连通像素，整体不对称，包含至少 2 个端点——即仅有 1 个 4-邻居属于该图案的像素）。网格左下角有一个蓝(1) 引导像素。生成约束：图案与标记线之间至少间隔 1 行；反射后的图案（含膨胀后的额外像素）不超出网格边界；图案反射后的位置不与原图案重叠。

**规则**：
1. 读取左下角的引导像素颜色（蓝(1)），然后将该像素擦除为黑(0)。
2. 将红(2) 前景图案以稀疏标记线所在行为对称轴进行垂直镜像反射。反射副本的每个像素以引导颜色蓝(1) 绘制。
3. 对反射副本中的每个蓝(1) 像素，计算其在副本内的 4-连通邻居数量（即上下左右四个方向中有多少个同属反射副本的蓝色像素）。
4. 邻居数 <= 1 的像素为端点像素：将其四个基数方向（上下左右）各膨胀 1 格，膨胀像素同为蓝(1)。膨胀仅覆盖黑(0) 像素，不覆盖红(2) 原图案、灰(5) 标记线或已有的蓝(1) 像素。
5. 邻居数 >= 2 的像素为内部像素，不做任何膨胀。
6. 原始红(2) 图案和灰(5) 标记线保持不变。

**关键洞察**：反射副本并非均匀膨胀——其形状的拓扑特征（端点 vs 连接处）自动决定了哪些部分会生长。不同示例中原图案的形状不同，导致端点位置不同，因此膨胀模式也不同。必须理解"端点检测 → 选择性膨胀"这一规则，而非试图记忆某种固定的膨胀图案。

## 实现要求

1. `main(grid)` 必须实现新题描述中的确定性转换规则，不能只识别 `generate_input()` 的固定模板。禁止不同的input网格输出相同的output网格。
2. `generate_input()` 必须随机生成多样样例，不能固定死。随机维度应覆盖：网格大小、对象数量、位置、颜色、方向、形状参数或关键分支。注意若描述中存在若干，需实现而不是只有单个，包括object或者对应关系等等。且若涉及到最短路径，则输入网格中必涉及到多条路径，对选择造成干扰。
3. 生成器必须保证输入满足 `main()` 的隐式假设：对象不重叠、不越界、特殊标记唯一或可区分、匹配关系无歧义、关键分支出现概率相同。
4. 禁止把 ARC 颜色 id 、亮度、拼写等当作人类不可见的数值语义参与排序、大小比较或隐藏映射。颜色变化必须有可见结构线索。注意颜色亮度、拼写等也是不可见信息，若描述中出现违规的颜色id或者亮度，可自行使用少量的固定颜色替代，但注意生成时要在三个以内输入输出网格中对所有变换100%覆盖度。
5. 输出样例要视觉清晰，人类必须能从输入输出对中肉眼辨认出规律。具体要求：避免对象粘连、覆盖关系混乱、同一像素多重语义；不同逻辑步骤产生的结果不要大面积层叠在一起导致无法分辨哪个颜色属于哪个步骤；输入中各元素之间保持足够间距，输出中新增的标记/填充/路径等应与背景和已有元素在颜色上有明显区分；若规则涉及多层叠加，生成时控制对象密度和尺寸，确保叠加区域只占少数像素而非铺满整个网格。
6. 若规则有多个分支，生成器不能长期固定成一个分支；应让分支在随机样例中合理出现。分支概率不必平均——难以发现的隐蔽分支（如少数情况下才触发的特殊规则）应适当提高出现概率，确保在 3 个训练示例中至少出现一次，否则求解者无法归纳该规则。对于颜色映射类规则，确保 2 个左右的示例即可覆盖所有映射关系（每种颜色→颜色的映射至少在某个示例中出现过）。
