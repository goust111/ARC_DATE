## 新题 8：滑动构建障碍后的射线绘制

**组合逻辑**：[滑动sliding](创新：滑动的目的不是移动对象到最终位置，而是构建后续操作的空间条件) + [射线延伸ray_extend](创新：射线路径由滑动后的对象位置决定) + [擦除erase](已有)

**来源原语**：滑动+前景对象+方向+固定步长平移(25ff71a9)、射线延伸+障碍对象+射线遇障停止+特定色为墙壁(6ffe8f07)、擦除(3d588dc9)

**依赖链**：方向标记指示每个蓝色对象的滑动方向 → 对象滑到边缘或碰到其他对象后停止 → 停止位置的蓝色对象成为射线障碍 → 从红色源点向四方投射射线，遇蓝色障碍停止。滑动的结果决定了障碍的空间分布，障碍分布决定了射线的长度和覆盖范围——输入中看到的对象位置不是最终起作用的位置。

蓝色对象按方向标记滑动到最终位置后充当射线障碍，红色源点投射的射线在这些动态障碍处截止。

**输入结构**：约 14x14 的网格，黑(0) 背景。中心有一个红(2) 单像素作为射线源点。网格中散布 3-4 个蓝(1) 小对象（每个 2-3 像素的 4-连通块，不同示例中形状不同）。每个蓝色对象的某一侧紧邻一个黄(4) 单像素作为方向标记：黄像素在蓝对象上方表示向上滑，在下方表示向下滑，在左侧表示向左滑，在右侧表示向右滑。黄像素与蓝对象的相邻关系是 4-连通的（上下左右之一）。生成约束：每个蓝色对象恰好有一个相邻黄色方向标记；滑动后所有蓝色对象互不重叠且不覆盖红色源点；至少有一个蓝色对象滑动后位于红色源点的某个基数方向上（确保至少一条射线被截断）。

**规则**：
1. 对每个蓝(1) 对象，识别其相邻的黄(4) 方向标记。黄像素相对于蓝对象的方位即为滑动方向（黄在蓝的北侧 → 滑向北，以此类推）。
2. 将每个蓝色对象沿其滑动方向整体平移，直到对象的前沿像素碰到网格边缘或碰到另一个已经停止的对象（按距网格边缘由近到远的顺序依次处理——即最靠近滑动方向目标边缘的对象最先滑动并固定）。
3. 擦除所有黄(4) 方向标记像素（替换为黑(0)）。
4. 从红(2) 源点向上、下、左、右四个基数方向投射射线。射线经过的黑(0) 像素变为绿(3)。射线遇到蓝(1) 对象的像素时停止（不包含蓝色像素本身）。射线遇到网格边缘也停止。
5. 红色源点保持红(2)，蓝色对象保持蓝(1)。

**关键洞察**：输入中蓝色对象的位置是"初始位置"而非"最终位置"——求解者必须在脑中执行滑动操作来确定对象的最终位置，然后才能判断射线的长度。黄色方向标记是消耗性指令，执行后消失。
