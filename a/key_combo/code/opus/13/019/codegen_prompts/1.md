## 新题 1：像素计数定旋转角的模板印章

**组合逻辑**：[计数counting](创新：像素数编码旋转角) + [旋转rotate](创新：旋转角由外部计数决定而非固定) + [印章覆盖stamp_overlay](已有) + [擦除erase](已有)

**来源原语**：计数(ae58858e)、旋转(ed36ccf7)、印章覆盖(d6542281)、擦除(aabf363d)、连通分量(a8d7556c)、多色精灵体(d6542281)

**依赖链**：散落的单色小对象的像素数量编码了旋转参数 → 旋转参数决定模板精灵体的朝向 → 旋转后的精灵体印章到小对象的位置 → 小对象被消耗。像素计数、旋转、印章三步紧耦合：不计数就不知道旋转多少度，不旋转就不知道印什么形状，不知道小对象位置就不知道印在哪里。

每个散落的小对象既是放置位置的标记，也是旋转指令的编码——其像素数量决定模板旋转多少个 90 度后印章到该位置。

**输入结构**：约 15x15 的网格，黑(0) 背景。左上角区域放置一个多色模板精灵体（约 3x4 像素，使用红(2) 和蓝(1) 两种颜色构成不对称图案，保证四种旋转态互不相同）。网格其他区域散布 3-4 个绿(3) 单色 4-连通小对象，每个对象的像素数量分别为 1、2、3 或 4 个像素（不同示例中同类对象的具体形状不同，但像素数量与旋转角的映射关系保持一致）。各小对象的边界框互不重叠，且与模板精灵体间隔至少 2 个像素。生成约束：每个小对象的边界框中心向四周扩展模板精灵体的边界框尺寸后不超出网格边界，且扩展区域互不重叠。

**规则**：
1. 识别模板精灵体（左上角的红(2)+蓝(1) 多色对象）及所有绿(3) 4-连通小对象。
2. 对每个绿色小对象，计算其像素数量 N。旋转角度 = (N - 1) x 90 度顺时针。即：1 像素→0 度，2 像素→90 度顺时针，3 像素→180 度，4 像素→270 度顺时针。
3. 将模板精灵体按对应角度旋转后，以该绿色小对象的边界框中心为锚点进行印章覆盖（模板的边界框中心对齐锚点）。印章保留模板原有的红(2)+蓝(1) 颜色。
4. 擦除所有绿(3) 小对象的像素（替换为黑(0)）。被印章覆盖的绿色像素同样被替换。
5. 原始模板精灵体保持不变。

**关键洞察**：每个小对象承载双重信息——其位置标记印章的放置点，其大小（像素数）编码了模板应如何旋转。必须对比多个示例才能确定"像素数 → 旋转角"的具体映射规则（而非其他可能的映射如像素数→缩放）。
