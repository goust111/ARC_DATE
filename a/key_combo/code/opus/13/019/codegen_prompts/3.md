## 新题 3：嵌套区域深度决定周期性填充颜色

**组合逻辑**：[洪泛填充flood_fill](创新：填充目标由嵌套深度和面积排名的双重索引决定) + [排序sorting](创新：在每个深度层内部独立排序) + [重涂色recolor](已有)

**来源原语**：洪泛填充+排序+等间隔采样填充+区域排列顺序(7447852a)、封闭区域+面积排名(a8d7556c)、边缘与内部区分(8a371977)、空心矩形+内部区域(d37a1ef5)

**依赖链**：灰色边界构成嵌套结构 → 分析每个封闭区域的嵌套深度 → 同一深度的区域按面积排序 → 按周期规则（隔一选一）选取目标区域 → 深度值决定填充颜色。嵌套深度同时控制"选哪些区域"（通过周期采样在同深度内筛选）和"用什么颜色"（深度映射到颜色），两者缺一不可。

灰色墙壁围成多层嵌套区域，每层内按面积排序后隔一填充，填充颜色由嵌套层数决定。

**输入结构**：约 14x14 的网格，黑(0) 背景。灰(5) 像素构成嵌套的矩形或准矩形边界，形成 3-4 层深度的嵌套结构。最外层灰色边界紧贴网格边缘或距边缘 1 像素。内层边界嵌套在外层内部，同一深度可以有多个互不连通的封闭区域（即同一层可并列多个独立的灰色围框）。每个封闭区域的面积在 4-20 像素之间。生成约束：同一深度至少有 2 个封闭区域（以便周期采样有意义）；不同深度的区域面积范围有重叠（防止仅凭面积推断深度）。

**规则**：
1. 识别所有被灰(5) 墙壁围成的 4-连通黑(0) 封闭区域。
2. 计算每个区域的嵌套深度 D：从该区域出发到达网格边缘需要穿越的灰色边界数量。紧邻网格边缘且外侧无灰色边界的区域深度为 0（若存在），被一层灰色边界包围的区域深度为 1，以此类推。
3. 在每个深度层内，将所有区域按面积从大到小排序。面积相同时按边界框左上角的行优先、列次之排序。
4. 在每个深度层的排序序列中，选取索引为偶数的区域（第 0、2、4、... 个，即隔一选一），对选中的区域执行洪泛填充。
5. 填充颜色由深度决定：深度 1 → 红(2)，深度 2 → 蓝(1)，深度 3 → 绿(3)，深度 4 → 黄(4)。深度 0 的区域不填充。
6. 未被选中的区域保持黑(0)，灰色边界保持不变。

**关键洞察**：填充决策是双重索引的——嵌套深度决定颜色，面积排名在同层内决定周期选取。单看一个示例可能无法区分"按面积填充"和"按位置填充"，必须对比多个示例中同深度不同面积区域的填充/不填充状态才能归纳出周期采样规则。

Fill enclosed regions along a line seeded by unique border pixels.

Input structure:
- bg = most common color.
- Colored lines/drawings on the grid.
- Unique single-pixel colors on the grid border mark seed endpoints of each line.

Rule:
- Each border seed pixel connects (8-connected) to a line drawing.
- Find closed bg cavities whose boundary touches that line.
- Flood-fill each such cavity with the seed pixel's color.

Key insight: Only cavities reachable through the seed's own line get filled; the seed's unique color acts as a per-line fill label.
