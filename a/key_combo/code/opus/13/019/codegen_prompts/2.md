## 新题 2：射线投射构建动态障碍后的跨障碍交换

**组合逻辑**：[射线延伸ray_extend](创新：射线的产物不是最终输出，而是为后续操作构建障碍) + [交换swap](创新：交换的障碍来自计算生成而非输入预设) + [擦除erase](已有)

**来源原语**：射线延伸+实心矩形+障碍对象+射线遇障停止+特定色为墙壁(6ffe8f07)、交换+障碍段+跨障碍配对+同行列两侧各一(1efba499)、擦除(3d588dc9)

**依赖链**：实心矩形向外投射射线，蓝色障碍物截断射线 → 射线轨迹形成黄色障碍段 → 散落的标记像素根据黄色障碍段进行跨障碍配对交换。射线投射的结果构建了交换操作的前提条件：不计算射线就不知道障碍在哪里，不知道障碍就无法确定哪些标记构成配对。

射线从矩形出发被障碍截断后形成新的隔墙，散落的标记像素依据这些隔墙进行跨墙位置交换。

**输入结构**：约 16x16 的网格，黑(0) 背景。中心附近有一个青(8) 实心矩形（约 2x3）。网格中散布 3-5 个蓝(1) 单像素作为射线截断障碍。另有若干成对的红(2) 和绿(3) 单像素标记，分布在射线将要经过的路径两侧（每对由一个红像素和一个绿像素组成，位于同一行或同一列，且在射线路径的两侧各一个）。生成约束：青色矩形的每一行和每一列上的射线路径至少经过一个蓝色障碍；每对红绿标记恰好被一条射线路径分隔（即该行或列上的射线段将红、绿标记分在两侧）。

**规则**：
1. 从青(8) 矩形的每一行向左、向右投射射线，从每一列向上、向下投射射线。射线经过的黑(0) 像素变为黄(4)。射线遇到蓝(1) 障碍像素时停止（不包含蓝像素本身，即蓝像素保持蓝色）。射线不覆盖非黑色像素。
2. 黄(4) 射线段现在作为障碍段。扫描每一行和每一列：若某行或列恰好穿过一段连续的黄色障碍段，且该障碍段的两侧各有恰好一个非黑非黄非蓝非青的标记像素，则这两个标记构成一个跨障碍配对。
3. 对每个配对，将两个标记交换到障碍段对侧紧邻的位置：原在障碍段左侧的标记移动到障碍段右端紧邻的右侧一格（若该行方向），原在右侧的移动到左端紧邻的左侧一格；上下方向同理。原位置擦除为黑(0)。
4. 若某行或列上只有一侧有标记像素（另一侧无标记），不做任何操作。
5. 青色矩形、蓝色障碍、黄色射线段在输出中保持不变。

**关键洞察**：交换操作依赖的障碍墙并非输入中预设的，而是通过射线投射计算生成的——必须先完成射线投射才能确定哪些标记构成可交换的配对以及交换的目标位置。蓝色像素同时扮演两个角色：截断射线（间接决定障碍墙的长度和位置）和间接控制交换行为。
