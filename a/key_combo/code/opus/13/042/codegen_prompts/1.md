## 新题 1：射线遇框即停，命中框体洪泛填色

**组合逻辑**：[射线延伸](从3x3块八方辐射，但遇到灰色框边界即停止而非到达网格边缘——创新改造) + [洪泛填充](被命中的框体内部按命中射线着色——创新改造：填充触发由射线碰撞决定，填色由最短射线决定) + [封闭区域/空心矩形](作为射线障碍物而非独立填充目标——创新角色)

**来源原语**：射线延伸/ray_extension(1d398264)、罗盘方向/compass_direction(1d398264)、排除中心像素/exclude_center_pixel(1d398264)、洪泛填充/flood_fill(c0f76784)、封闭区域/enclosed_region(c0f76784)、空心矩形/hollow_rectangle(c0f76784)、包围/enclosure(c0f76784)

**依赖链**：3x3块的非中心像素确定8条射线的方向和颜色 → 射线向外延伸时检测是否碰到灰色框边界（空间碰撞判定） → 碰撞截断射线长度，同时标记该框为"被命中" → 对每个被命中的框，比较所有命中射线的行进距离，选最短者的颜色 → 用该颜色洪泛填充框的封闭内部。删除碰撞检测则射线直达边缘且框体无法被触发填充；删除距离比较则多射线命中时填色不确定；删除洪泛填充则命中无效果。

将一个3x3色块的八方射线投射到含有若干灰色空心矩形框的网格中：射线遇框停止，被射线命中的框按最短命中射线的颜色填充其封闭内部。

**输入结构**：
- 约15x15的网格，黑(0)背景。
- 网格中有一个实心3x3色块：中心像素为一种颜色（如灰(5)），周围8个像素各有颜色（取自蓝(1)、红(2)、绿(3)、黄(4)，允许相邻像素同色但不全同色）。
- 网格中散布3~5个灰(5)色空心矩形框，每个框为1像素厚的封闭矩形边框，内部为黑(0)。框的内部尺寸在2x2到4x4之间。
- 各框互不重叠、互不相邻，且不与3x3色块重叠。
- 生成约束：至少有2个框位于某条射线的路径上（即从3x3块某非中心像素沿其罗盘方向延伸的直线能命中该框的边框像素）；至少有1个框不在任何射线路径上；至少有1个框被2条以上射线同时命中。

**规则**：
1. 确定3x3色块的中心像素位置。对其余8个非中心像素，根据其相对于中心的位置确定罗盘方向（正上方为N，右上为NE，正右为E，依此类推共8个方向）。
2. 从每个非中心像素出发，沿其罗盘方向逐像素向外绘制射线，射线颜色为该起始像素的颜色。
3. 射线碰撞规则：若射线下一个待绘制像素是灰(5)色框边框像素，则射线在当前像素停止（不覆盖框边框）。若射线到达网格边界仍未碰到任何框，则在边界处停止。
4. 对每个被至少一条射线命中的框（"命中"指有射线因碰到该框边框而停止）：计算每条命中射线从起始像素到停止像素的曼哈顿距离。选择距离最短的射线的颜色，将该框的封闭黑(0)内部全部填充为该颜色。
5. 若同一个框被多条射线命中且最短距离相同（平局），按罗盘方向顺时针排序（N, NE, E, SE, S, SW, W, NW），选排序在前的射线的颜色。
6. 未被任何射线命中的框保持不变（灰(5)边框，黑(0)内部）。
7. 3x3色块本身保持不变。

**关键洞察**：射线不总是延伸到网格边缘——灰色框的边框充当障碍物截断射线。一个框的填充颜色由"哪条射线最先到达它"决定，这将射线的几何路径与洪泛填充的触发和选色紧密耦合。一个框还可能"遮蔽"其身后的框，使后方的框不被该方向的射线命中。
