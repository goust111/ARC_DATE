## 新题 8：坐标压缩揭示角点正方形后在中心缩小复制

**组合逻辑**：[坐标压缩](已有) + [缩小复制](已有)（创新：角点标记在原始网格中因分隔线扭曲而不构成正方形，压缩后才暴露正方形几何关系——压缩操作不是简单的预处理，而是实质性地改变对象间的空间关系使后续推断成为可能）

**来源原语**：坐标压缩/分隔线 ← 7d419a02；缩小复制/角点标记/已知角点推断中心/对角线位置/角点定义正方形/中心像素 ← 11e1fe23

**依赖链**：原始网格有不均匀分布的分隔行/列 → 3 个同色角点在原始坐标中不构成正方形的角点 → 压缩后移除分隔行/列后角点恰好构成正方形 3 角 → 推断第 4 角和中心 → 在中心周围缩小复制角点图案。删除坐标压缩则角点不构成正方形、推断失败；删除缩小复制则中心无输出。

移除分隔线进行坐标压缩后，三个角点标记才构成正方形的三角，进而推断中心并缩小复制角点图案。

**输入结构**：黑(0)背景，约 14x14 网格。若干完整的黑(0)行和黑(0)列作为分隔线（每条分隔线整行或整列全为黑色，共 2~4 条，分布不均匀）。在非分隔线的单元格中，背景为灰(5)。恰好 3 个像素为非灰非黑的同一颜色（如红(2)），位于网格中不同位置。这 3 个像素在原始坐标中不构成任何轴对齐正方形的三个角点（因为分隔线插入导致间距不等），但移除所有分隔行/列后（坐标压缩），这 3 个像素在压缩坐标中恰好位于某个轴对齐正方形的 3 个角上，且正方形中心为整数坐标。生成约束：压缩后正方形边长至少为 4（保证中心与角点之间至少有 1 个空位放置缩小复制结果），且正方形区域内（压缩坐标下）的其他位置均为灰(5)背景。

**规则**：
1. 识别所有全黑的完整行和完整列（分隔线）。
2. 移除这些行和列，将剩余行列紧凑排列（坐标压缩）。输出网格尺寸 = 原始网格尺寸减去分隔线数量。
3. 在压缩后的网格中，找到 3 个同色（红(2)）像素。它们恰好构成某个轴对齐正方形的 3 个角点。
4. 推断缺失的第 4 个角点位置。在该位置画一个红(2)像素。
5. 计算正方形中心位置。在中心画一个黑(0)像素。
6. 对于已有的 3 个角点标记中的每一个，在中心到该角点方向上距中心 1 步的对角线位置，画一个该角点颜色（红(2)）的像素（缩小复制：将角点图案在中心周围缩小一步重现）。
7. 缺失角点同样在其对应的缩小位置画红(2)像素。
8. 最终输出为压缩后的网格（不恢复分隔线）。

**关键洞察**：分隔线在视觉上让 3 个角点看起来间距不等（例如两个角点之间隔了 2 条分隔线而另一对之间只隔了 1 条），直觉上不像正方形的角。只有在脑中执行坐标压缩后，正方形结构才浮现。这一步是认知瓶颈——压缩不是清理噪声，而是揭示隐藏的几何关系。
