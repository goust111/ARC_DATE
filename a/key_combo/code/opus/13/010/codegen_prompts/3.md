## 新题 3：补全被遮挡形状后按标尺匹配进行平铺

**组合逻辑**：[补全](已有) + [平铺](已有)（创新：补全操作恢复的真实边长成为标尺匹配的前提，标尺的附着图案成为平铺的内容源）

**来源原语**：补全/被遮挡形状/矩形足迹/前景遮挡/隐含区域重涂 ← 52df9849；平铺/标尺条/瓦片图案/端部附着/标尺长度决定重复 ← 9c1e755f

**依赖链**：被遮挡矩形的真实边长在补全前不可知 → 补全后暴露真实边长 → 标尺条长度与真实边长匹配决定配对 → 配对标尺的附着图案沿匹配边平铺填入矩形内部。删除补全步骤则真实边长未知、标尺无法正确配对；删除平铺步骤则矩形虽恢复但内部缺少图案。

先补全互相遮挡的矩形，再将边长匹配的标尺条上的图案平铺到对应矩形内部。

**输入结构**：黑(0)背景，约 18x20 网格。3~4 个不同颜色的实心矩形（颜色从蓝(1)、红(2)、绿(3)、黄(4)中取），部分矩形互相重叠（一个矩形的部分像素被另一颜色覆盖，但被遮挡矩形的完整矩形足迹内无背景像素——被遮挡的格子都被前景色占据）。在网格边缘（上边缘或右边缘），有 2~3 条灰(5)标尺条（水平或竖直的单像素宽直线段，长度各不相同），每条标尺的一端附着一个小的非灰非背景色矩形图案（2x2 或 2x3，图案由两种颜色组成，如橙(7)和青(8)的棋盘格或条纹）。生成约束：每个被遮挡矩形恢复后，其较长边的长度恰好等于某条标尺的长度（像素数），且此匹配唯一（不同矩形的较长边长度各不相同，各与不同标尺匹配）。未被遮挡的矩形没有匹配的标尺。

**规则**：
1. 识别所有被遮挡的矩形：对每种前景色，其边界框内全为前景像素（无背景）但含有其他前景色 → 该颜色的矩形被部分遮挡。
2. 补全每个被遮挡矩形：将其矩形足迹内所有非本色像素重涂为本色。所有矩形同时补全（各自恢复各自的足迹，按画家算法处理重叠：面积较小的矩形覆盖面积较大的）。
3. 补全后，测量每个矩形较长边的像素长度。
4. 将每个矩形与较长边长度相等的标尺条配对。
5. 对配对成功的矩形：取标尺附着的图案，沿矩形较长边方向周期性平铺，填满矩形的整个内部（矩形边框一像素宽保留原矩形颜色，内部区域被图案平铺覆盖）。平铺从矩形内部的左上角开始，图案在较长边方向重复，在较短边方向也重复。超出内部区域的图案截断。
6. 未配对的矩形保持补全后的纯色填充。
7. 擦除所有标尺条和附着图案。

**关键洞察**：标尺与矩形的配对依赖于"真实较长边长度"，但这个长度在输入中被遮挡掩盖了。必须先完成补全才能正确配对。如果跳过补全直接用可见边长配对，会得到错误的匹配关系——这是整道题的核心欺骗点。

Sort objects to top or bottom edge by whether their shape (up to rotation/flip) is shared.

Input structure:
- bg = most common color.
- Several multicolor connected components (8-connected) scattered across the grid.

Rule:
- Compute each object's canonical shape (binary mask, invariant to rotation and flip).
- Objects whose shape appears in two or more components → translate to TOP edge (row 0).
- Objects whose shape is unique → translate to BOTTOM edge (row H−h).
- Horizontal position (left column) is preserved; only vertical translation changes.

Key insight: The sorting criterion is shape frequency (rotation-invariant), not area — duplicated shapes go up, unique shapes go down.

Rotate each 2x2 block's four diagonal corner colors clockwise, then extend the rotated colors outward as diagonal rays.

Input structure
- The background is the dominant color.
- One foreground color forms one or more solid 2x2 blocks.
- Each block has four non-background, non-block corner pixels diagonally adjacent to it.

Rule
- Around every block, move the NW corner color to NE, NE to SE, SE to SW, and SW to NW.
- From each rotated corner, paint along the outward diagonal until the grid edge or another 2x2 block is reached.
- If a ray reaches a same-colored outgoing corner of another block that has its own visible continuation, stop the incoming ray at that junction.

Key insight
- The 2x2 blocks are color rotators and ray blockers; the corner pixels are not independent dots but the four ports of each block.
