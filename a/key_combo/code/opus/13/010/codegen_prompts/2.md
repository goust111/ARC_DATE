## 新题 2：重力落子创造封闭区域后按控制色填充

**组合逻辑**：[重力下落](已有) + [洪泛填充](创新：填充对象不是预存的框，而是重力落子与障碍物共同围合出的涌现区域) + [控制色定行为](创新：控制像素不再决定穿透/停靠，而是决定围合区域的填充颜色)

**来源原语**：重力下落/障碍物/控制像素/穿透或停靠 ← 963c33f8；洪泛填充/封闭区域/标记在封闭区域内 ← 4b6b68e5；控制色定行为 ← 963c33f8

**依赖链**：重力下落的着陆位置取决于障碍物分布 → 着陆后的像素与障碍物共同围合出封闭区域（涌现属性，单看障碍物或单看落子都不构成封闭）→ 每个封闭区域的填充颜色由落入该区域边界的控制像素颜色决定。删除重力则无封闭区域，删除控制色规则则无法确定填充颜色。

将顶部色条按重力下落到障碍物上，落子与障碍物围合出封闭区域，再根据边界上的控制像素颜色填充这些区域。

**输入结构**：黑(0)背景，约 15x20 网格。顶部两行为一条水平色条：第一行（最顶行）全部为栗(9)色像素，第二行每个像素为蓝(1)或红(2)，作为逐列控制像素。网格中下部散布灰(5)障碍像素，障碍像素排列为若干水平或竖直的短线段（2~5 像素长），彼此间留有间隙。障碍线段的排列方式使得：当色条各列下落并停靠在障碍上方后，停靠的色条像素与灰障碍物的组合恰好围合出若干矩形封闭背景区域（每个区域至少 2x2 大小）。生成约束：每个围合区域的上边界必定包含至少一个控制像素列的落点，且同一围合区域上边界的所有控制像素颜色相同（全蓝或全红），以保证填充颜色唯一确定。

**规则**：
1. 擦除顶部两行色条。
2. 将每列色条（上方栗(9)+下方控制色）视为一个 2x1 的竖直块，在该列沿重力方向（向下）下落，直到紧贴该列中第一个灰(5)障碍像素的正上方停靠。若该列无障碍像素，则停靠在网格最底行。
3. 所有列下落完毕后，识别由停靠的色条像素和灰(5)障碍像素共同形成的边界所围合的 4-连通背景(0)封闭区域。封闭区域定义：从该区域出发沿 4-连通方向无法到达网格边缘而不穿过栗(9)或灰(5)像素。
4. 对每个封闭区域：检查其上边界（紧邻该区域上方的栗色像素下方的控制像素）的颜色。若控制色为蓝(1)，将整个区域填充为蓝(1)；若控制色为红(2)，填充为红(2)。
5. 非封闭区域中的背景像素保持不变。

**关键洞察**：封闭区域不预先存在于输入中——它是重力下落后才涌现的几何属性。控制像素的"下落后位置"同时决定了它所在区域的边界形状和该区域的填充颜色，两个作用不可分割。求解者必须先在脑中模拟重力，再识别围合，最后查找控制色，三步紧密串联。
