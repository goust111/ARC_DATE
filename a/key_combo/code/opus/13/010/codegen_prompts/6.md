## 新题 6：稠密化改变边缘轮廓后按边缘匹配链接排入框架

**组合逻辑**：[稠密化](已有) + [排序/链式连接](已有)（创新：稠密化操作改变精灵体的边缘像素分布，使得稀疏态下的边缘匹配关系在稠密化后完全不同——链接顺序由稠密化后的边缘决定，而非原始稀疏形态）

**来源原语**：稠密化/稀疏精灵体/稀疏边框/等距排列入框 ← db615bd4；排序/精灵体/分隔线/边缘像素匹配/链式连接排序 ← 78332cb0

**依赖链**：稀疏精灵体在两步格点上 → 稠密化将每个前景像素扩展为 2x2 块（填充格点间隙）→ 稠密化后的边缘轮廓与稀疏态不同 → 按稠密态的边缘匹配确定链接顺序 → 按链接顺序排入稠密化后的框架。删除稠密化则边缘轮廓错误、链接顺序错误；删除链接排序则精灵体顺序不确定。

先将稀疏精灵体和稀疏边框稠密化，再按稠密化后的边缘像素匹配关系链接排序，最后将精灵体按链接顺序等距排入稠密框架。

**输入结构**：黑(0)背景，约 20x20 网格，含一种格点色（如橙(7)，在偶数行偶数列出现的规律性底纹，可被前景覆盖）。一个大型稀疏矩形边框（青(8)色，像素仅出现在两步格点上，形成虚线矩形，约 14x14 范围）。边框外散布 3~4 个稀疏精灵体（每个精灵体一种颜色，从蓝(1)、红(2)、绿(3)、黄(4)中取，像素同样仅在两步格点上，每个精灵体 4~8 个像素，边界框约 5x5）。生成约束：稀疏态下精灵体的边缘像素分布使得任意两个精灵体之间不存在边缘匹配（左右边缘或上下边缘的前景像素在相同偏移处重叠），但稠密化（每个前景像素扩展为 2x2 块）后，精灵体恰好可以按某一唯一顺序首尾链接（A 的右边缘前景像素偏移集合与 B 的左边缘前景像素偏移集合有非空交集 → A 链接 B）。

**规则**：
1. 将稀疏边框稠密化：清除边框区域内所有像素，用青(8)画一个 1 像素宽的实心矩形边框（范围与原稀疏边框的外边界一致）。
2. 将每个稀疏精灵体稠密化：将每个前景像素扩展为以该像素为左上角的 2x2 实心块（同色）。
3. 对稠密化后的精灵体进行链式连接：比较每对精灵体的面对边缘（A 的右边缘 vs B 的左边缘）。若两个边缘在相同行偏移处都有前景像素，则 A 可链接到 B 的左侧。找出能将所有精灵体串成一条完整链的唯一排列。
4. 框架方向判定：若稠密化边框的宽度 > 高度，精灵体沿水平方向排列（左到右）；否则沿竖直方向排列（上到下）。
5. 将链接好的精灵体等距放入稠密边框内部。间距 = (框架内部可用长度 - 所有精灵体在排列方向上的总长度) / (精灵体数量 + 1)，向下取整。多余像素分配给首尾间距。
6. 清除框架外部的所有精灵体残留像素和格点底纹。

**关键洞察**：稀疏态下的边缘轮廓是离散的点，稠密化后变成连续的线段，前景像素的偏移分布发生质变。如果在稀疏态下尝试边缘匹配，会得到"无匹配"的结论；只有稠密化后才能找到有效的链接关系。这意味着稠密化不仅是视觉美化——它实质性地改变了对象之间的拓扑关系。
