## 新题 8：完整与损伤方块双分支计数的对角线交叉编码

**组合逻辑**：[计数/counting](创新：同一操作分两条分支并行执行，计数对象由分类条件决定) + [编码/encoding + 对角线编码/diagonal_encoding](创新：两个计数结果分别编码在主对角线和反对角线上，共享同一输出网格) + [擦除/erase + 忽略干扰项/ignore_distractors](已有)

**来源原语**：计数/counting + 对角线编码/diagonal_encoding + 完整方块过滤/full_square_filter + 忽略干扰项/ignore_distractors ← 3b4c2228；编码/encoding + 计数决定填充位/count_sets_positions ← ff28f65a；擦除/erase ← a416fc5b, e3721c99

**依赖链**：这是分叉-汇合结构而非线性流水线。输入经两条独立分支处理——完整方块计数和损伤方块计数——然后两条分支的结果汇合到同一个输出网格的两条对角线上。主对角线和反对角线在中心格可能交叉，此时需要冲突解决规则。删除任一分支的计数，对应对角线就无法确定。

区分并分别计数完整的绿色 2x2 方块和被损伤的绿色方块，将两个计数分别编码为输出网格主对角线和反对角线上的有色格子数。

**输入结构**：黑(0)背景上的方形网格，尺寸约 12x12~15x15。网格中散布以下元素：
- **完整绿色方块**：恰好 2x2 的绿(3)实心方块，1~4 个，互不接触。
- **损伤绿色方块**：一个 2x2 区域中有恰好 3 个绿(3)像素和 1 个红(2)像素（红像素在四个位置之一），1~4 个，互不接触且不与完整方块接触。
- **干扰项**：若干孤立的蓝(1)单像素散布在网格中（不与任何方块相邻）。
生成约束：完整方块数 + 损伤方块数 <= 4（保证对角线编码不超出 4x4 输出网格）；完整方块数和损伤方块数各至少为 1。

**规则**：
1. 识别所有绿(3)的 4-连通前景对象。对每个对象判断类别：
   - 若对象恰好占据一个 2x2 区域且面积为 4（全绿），归为"完整"。
   - 若对象为 3 个绿(3)像素，且这 3 个像素加上一个相邻的红(2)像素恰好构成一个 2x2 区域，归为"损伤"。
   - 其余绿色对象（孤立像素等）归为干扰，忽略。
2. 蓝(1)孤立像素全部忽略（干扰项）。
3. 统计完整方块数 C_full 和损伤方块数 C_dmg。
4. 生成一个 4x4 黑(0)输出网格：
   - 在主对角线上（(0,0), (1,1), (2,2), (3,3)），从左上开始填入 C_full 个绿(3)格子。
   - 在反对角线上（(0,3), (1,2), (2,1), (3,0)），从右上开始填入 C_dmg 个红(2)格子。
   - 若主对角线和反对角线在某格交叉（即 C_full 和 C_dmg 都覆盖了该格），该格填绿(3)（完整优先于损伤）。
5. 输出仅为 4x4 编码网格，输入中的所有元素均不保留。

**关键洞察**：红色像素在输入中是"损伤标记"而非独立对象——它标记了一个方块的缺损位置。将红像素误判为干扰项会导致损伤计数为零。两条对角线在输出网格中心可能交叉，交叉处的优先规则（绿色覆盖红色）只有在 C_full >= 2 且 C_dmg >= 3（或反之满足交叉条件）的示例中才能被观察到，必须对比多个示例才能完整归纳规则。
