## 新题 4：贪心方块选取后按面积排名从调色板着色

**组合逻辑**：[贪心选择/greedy_selection](已有) + [排序/sorting](创新：排序的键不是预设的标记数而是贪心选取后的面积分组) + [重涂色/recolor](创新：颜色来源不是对象自身属性而是外部调色板的位置映射)

**来源原语**：贪心选择/greedy_selection + 空白正方形区域/blank_square_region + 障碍像素/obstacle_pixel + 从大到小优先/largest_first_priority + 非重叠约束/non_overlapping_constraint + 最小边长约束/minimum_side_length_constraint ← 31adaf00；排序/sorting + 按计数升序排列/sorted_by_count ← d4c90558；重涂色/recolor ← d4c90558

**依赖链**：贪心选取确定哪些方块存在及其尺寸 → 按尺寸分组排序得到排名 → 排名与调色板位置对应得到颜色 → 着色。障碍像素的布局决定了可用空间，进而决定哪些方块能被选中，再决定尺寸分布和排名分配。这条信息链中任一环节缺失都导致输出不确定。

在障碍像素之间贪心选取最大非重叠空白方块，然后按方块面积从大到小排名，使用输入左侧调色板列中对应排名的颜色为每组方块着色。

**输入结构**：网格尺寸约 20x22。最左列为调色板列：从第 0 行开始，依次填入 3~5 种不同颜色（如红(2)、蓝(1)、绿(3)、黄(4)、品红(6)），其余格为黑(0)。调色板中的第 k 个颜色（从上到下第 k 个非黑格）对应面积排名第 k 的方块组。从第 1 列到最右列的区域为搜索区域：黑(0)背景上散布灰(5)障碍像素（约 15~25 个），障碍像素形成不规则的空间分隔。生成约束：障碍布局保证搜索区域中至少存在 3 种不同边长的全黑正方形区域（边长 >= 2），且同一尺寸的正方形至少有 1 个、至多有 4 个能通过贪心选取存活。

**规则**：
1. 在搜索区域（第 1 列到最右列）中，枚举所有全黑(0)正方形候选区域，边长 >= 2。
2. 按边长从大到小处理候选方块。对于每个候选方块，若其区域与已选定的任何方块无像素重叠，则选定该方块。同一边长的候选方块按其左上角坐标从上到下、从左到右的顺序处理。
3. 将选定的方块按边长分组。边长最大的组排名 1，次大的排名 2，以此类推。
4. 读取调色板列：第 1 个非黑格的颜色赋给排名 1 的组，第 2 个非黑格赋给排名 2 的组，以此类推。
5. 将每组中所有方块的所有像素重涂为对应的调色板颜色。
6. 若不同边长的分组数多于调色板中的颜色数，多余的组（排名最后的最小方块组）保持黑(0)不着色。
7. 障碍像素和调色板列保持不变。

**关键洞察**：调色板的颜色顺序不能直接对应任何空间位置——它编码的是面积排名，而排名取决于贪心选取的结果。不同示例中障碍布局不同，产生不同的方块集合和尺寸分布，导致同一调色板位置映射到不同的绝对尺寸。必须对比多个示例才能归纳出"调色板位置 = 面积排名"的规则。
