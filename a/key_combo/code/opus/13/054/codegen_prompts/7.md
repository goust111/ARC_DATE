## 新题 7：对称筛选条棒拼框

**组合逻辑**：[对称检测 + 筛选](创新：对称性决定谁参与拼装而非谁被输出) → [计数 → 像素数定尺寸](已有原语) → [平移拼接](已有原语)

**来源原语**：对称检测(symmetry_detect)·筛选(filter)·对称性筛选目标(symmetry_filter)·忽略干扰项(ignore_distractors) ← 72ca375d, 73ccf9c2；平移拼接(translate_assemble)·线段条(bar_sprite)·矩形边框(rectangular_frame)·拼合覆盖(assembly_coverage)·像素数定尺寸(pixel_count_determines_size) ← 83b6b474

**依赖链**：对称检测筛选出合格的条棒（丢弃不对称的干扰体） → 合格条棒的总像素数决定目标矩形边框的周长 → 由周长反推最平衡的矩形尺寸 → 条棒通过平移精确铺满边框。删去筛选则干扰体的像素被错误计入，导致周长和尺寸都错；删去拼接则无边框输出。

先用对称性过滤掉干扰体，再将幸存的条棒按总像素数计算矩形框尺寸，最后平移拼装成恰好铺满的矩形边框。

**输入结构**：约 15x15 网格。黑(0) 背景。6-8 个单色 4-连通前景对象，颜色从蓝(1)、红(2)、绿(3)、橙(7) 中选取（不同对象颜色可不同）。对象分两类：(A) 直条棒——宽 1 像素的水平或垂直线段，长度 2-7 像素，这些对象天然具备镜像对称性（垂直条棒关于垂直轴对称，水平条棒关于水平轴对称）；(B) 不规则形体——宽和高均大于 1 的 4-连通形状，像素数 3-6，不具备任何轴对称性。生成约束：所有类型 A 对象的像素总数等于 2*(W+H)，其中 W >= 3，H >= 3，W 和 H 的差值在所有可行尺寸中最小（最平衡）。类型 A 对象的形状和颜色组合必须恰好能通过平移（不旋转）铺满 W x H 矩形边框（单像素厚）。

**规则**：
1. 对每个前景对象，计算其紧边界框裁剪图，检测是否关于垂直轴或水平轴镜像对称。
2. 丢弃所有不对称对象（设为黑(0)）。幸存对象均为直条棒。
3. 计算所有幸存条棒的像素总和 P。P 即为目标矩形边框的周长。
4. 找到满足 2*(W+H) = P 的所有整数对 (W, H)（W >= 3, H >= 3），从中选择 |W - H| 最小的一对。若有多对 |W - H| 相同，取 W <= H 的那对。
5. 将所有幸存条棒通过平移（不旋转、不翻转）放置到 W x H 矩形边框的边界像素上，使得每根条棒覆盖边框的一段连续边缘，所有条棒恰好无重叠无遗漏地铺满整个边框。
6. 边框内部填充黑(0)。输出拼装后的矩形边框网格（尺寸为 W x H）。

**关键洞察**：对称性在这里不是选择"哪个对象是答案"，而是选择"哪些对象是建材"——干扰体的像素数被排除后，总像素数才能正确指向目标边框尺寸。任何一个干扰体被误判为条棒，周长就会改变，导致整个拼装方案失效。
