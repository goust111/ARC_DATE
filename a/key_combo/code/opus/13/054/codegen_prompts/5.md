## 新题 5：互补匹配门控移动

**组合逻辑**：[形状匹配](创新：匹配结果不是直接输出，而是确定移动目的地) + [移动](创新：路径上增加门控标记) + [填充](已有原语)

**来源原语**：形状匹配(shape_match)·互补形状(complementary_shape)·缺口形状唯一配对(unique_complement)·模板缺口(template_gap) ← 18447a8d；移动(move)·障碍段(barrier_segment)·障碍门处标记通道(barrier_gate_mark)·同轴对齐的矩形对(coaxial_rect_pair) ← fc10701f；填充(fill) ← 62b74c02

**依赖链**：形状匹配确定每个源形状的目的地模板（非位置邻近决定） → 移动操作沿水平路径将源形状推送到匹配的模板缺口 → 路径上的障碍门决定哪些位置被标记为栗(9) → 源形状填入模板缺口。删去形状匹配则不知道目的地；删去移动和门控标记则缺少路径信息；删去填充则模板不完整。

将右侧的彩色小形状通过带障碍门的水平通道移入左侧模板中轮廓匹配的缺口。

**输入结构**：约 20x20 网格。黑(0) 背景。一条绿(3) 竖线（单像素宽的完整列）将网格分为左右两半。左半区：3 个单色实心矩形模板（颜色分别为红(2)、蓝(1)、黄(4)），每个矩形约 5x5 到 7x7，内部各有一个由黑(0) 像素构成的连通缺口（缺口形状为 2-4 像素的 4-连通区域，三个缺口的归一化形状互不相同）。三个模板在垂直方向上不重叠，之间有至少 2 行黑(0) 间距。右半区：3 个小彩色形状（颜色分别为橙(7)、灰(5)、品红(6)），每个形状为 2-4 像素的 4-连通区域。在绿(3) 竖线与每个右侧形状之间，散布若干水平黑(0) 障碍段（每段至少 2 像素长，垂直于水平移动方向，位于移动通道的上下两侧）。生成约束：每个右侧源形状的归一化轮廓恰好与左侧某个模板缺口的归一化轮廓相同，且配对关系一一对应。

**规则**：
1. 在左半区，对每个模板矩形提取其缺口形状（矩形内部黑(0) 连通像素集合，归一化为相对坐标）。
2. 在右半区，提取每个源形状（归一化为相对坐标）。
3. 将每个源形状与唯一轮廓相同的模板缺口配对。
4. 对每个配对：
   a. 擦除源形状原始位置（设为黑(0)）。
   b. 将源形状的像素填入配对模板的缺口位置，颜色使用源形状的原色。
   c. 沿源形状原始位置到配对模板之间的水平通道（源形状所在行范围内），逐列检查：若该列的通道行范围紧邻上方和下方都存在黑(0) 障碍像素（即障碍段从两侧夹住通道形成"门"），则将该列通道内的格子涂为栗(9)。仅从一侧伸出的障碍段不算门，忽略。
5. 绿(3) 分隔列保持不变。

**关键洞察**：移动的目的地不由空间邻近性决定，而由形状互补匹配唯一确定——交换任意两个源形状的目的地会导致缺口形状不匹配。门控标记则揭示了移动路径上的结构信息，是匹配和移动都不会产生的第三层输出。
