## 新题 4：异常象限前缀延展

**组合逻辑**：[裁剪 + 异常值选择](已有原语) → [延伸](创新：延展目标不再是整张图，而是异常值选择的结果)

**来源原语**：裁剪(crop)·象限(quadrant)·分隔十字(separator_cross)·相等比较(equality_comparison)·异常值选择(outlier_selection)·输出唯一象限(output_unique_quadrant) ← 88a62173；延伸(extend)·封闭行段(closed_row_segment)·边界包围内部(boundary_encloses_interior)·前缀图案闭合延展(prefix_pattern_closure_extension) ← 62b74c02

**依赖链**：四象限比较确定哪个是异常值 → 裁剪出异常象限 → 异常象限的行具有特定的前缀结构 → 对每行执行闭合延展。删去异常值选择则不知道处理哪个象限；删去前缀延展则输出只是原始异常象限的裁剪（退化为参考题 88a62173）。

在四象限中找出唯一不同的那个，然后对该象限的每一行按闭合前缀规则向右延展。

**输入结构**：15x15（奇数边长）网格。灰(5) 填充中间行和中间列，形成分隔十字，将网格分为四个 7x7 象限。三个象限包含完全相同的多色图案（像素级一致）。第四个象限（异常象限）图案不同：该象限中每行从左边缘开始有一段连续的非黑前缀（至少 3 像素），前缀之后全为黑(0)。每段前缀的第一个像素和最后一个像素颜色相同（称为边界色），中间像素可以是不同颜色。前缀使用的颜色从蓝(1)、红(2)、绿(3)、黄(4)、橙(7) 中选取。生成约束：三个相同象限必须像素级一致；异常象限每行的前缀长度不超过象限宽度的一半（以确保延展后不超出象限宽度）。

**规则**：
1. 移除灰(5) 分隔十字的中间行和中间列，提取四个 7x7 象限。
2. 将六对象限两两比较（逐像素）。恰好有一个象限与其余三个都不同，即异常象限。
3. 裁剪出异常象限。
4. 对该象限的每一行：
   a. 从左边缘识别连续非黑前缀，记其长度为 L，边界色为前缀第一个（也是最后一个）像素的颜色。
   b. 将前缀末尾之后、行右端之前的所有黑(0) 格子填充为边界色。
   c. 将前缀去掉第一个像素后的子序列（长度 L-1）复制到行的最后 L-1 个格子中，保持原顺序。
5. 输出变换后的 7x7 象限。

**关键洞察**：异常值选择决定了"对什么操作"，前缀延展决定了"怎么操作"——两者缺一不可。仅凭单个示例无法同时确定异常象限的位置规律和延展规则，必须对比多个示例中异常象限出现在不同角落的情况。
