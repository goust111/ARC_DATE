## 新题 7：标记半区裁剪后连通分量计数决定对角复制步数

**组合逻辑**：[标记对齐指定半区/裁剪](已有) → [计数/连通分量](创新：计数结果不决定边长，而决定对角平移步数) → [平移/对角偏移](创新：平移步数由前步计数动态决定) → [重涂色](已有)

**来源原语**：标记对齐指定半区/marker_selects_half(fbf15a0b), 裁剪/crop(fbf15a0b), 标记像素/marker_pixel(fbf15a0b), 计数/counting(d0f5fe59), 连通分量/connected_component(d0f5fe59), 数量决定边长/count_determines_side(d0f5fe59→创新为数量决定步数), 平移/translate(1e5d6875), 对角偏移/diagonal_offset(1e5d6875), 重涂色/recolor(1e5d6875)

**依赖链**：标记像素确定保留哪个半区 → 裁剪后计算保留半区中前景对象的连通分量数 N → N 决定对角复制的步数 → 对每个连通分量沿其重心到裁剪区中心的方向平移 N 步并重涂色。半区选择改变了连通分量集合；分量数改变了步数；步数改变了输出布局。

按标记像素裁剪出半个网格，数其中连通分量的个数 N，将每个分量沿其偏离中心的方向对角平移 N 步并重涂色。

**输入结构**：
- 约 14x14 的网格，黑(0)背景。
- 网格中散布若干蓝(1)色的 4-连通前景对象（2~6 像素的不规则小图形），共 4~8 个，分布在网格的两个半区（左半和右半，或上半和下半）中。
- 恰好有 2 个品红(6)标记像素位于同一行（或同一列），且都落在同一个半区中，标记该半区为保留半区。标记像素不属于任何前景对象。
- 生成约束：保留半区中蓝色连通分量数 N 在 2~4 之间；每个分量对角平移 N 步后仍在网格范围内（以保留半区为画布扩展到完整网格尺寸）；各分量平移后互不重叠。

**规则**：
1. 找到 2 个品红(6)标记像素。若它们共享同一行，则按它们所在的列范围确定保留左半还是右半；若共享同一列，则确定保留上半还是下半。保留包含两个标记像素的那个半区。
2. 在保留半区内，将品红(6)标记像素擦除为黑(0)。
3. 计算保留半区内蓝(1)连通分量（4-连通）的个数 N。
4. 计算保留半区的中心坐标 C（行中心, 列中心，向下取整）。
5. 对每个蓝(1)连通分量，计算其重心坐标 G（所有像素行坐标均值, 列坐标均值，四舍五入取整）。确定从 C 到 G 的方向向量 D = (sign(G_row - C_row), sign(G_col - C_col))，其中 sign 返回 -1/0/1。
6. 将该分量的每个像素坐标加上 N * D，得到新位置。新位置上的像素颜色设为绿(3)（重涂色）。原位置的蓝色像素保留不变。
7. 超出网格边界的像素丢弃。若新像素与原蓝色像素重叠，新绿色覆盖原蓝色。
8. 输出网格尺寸与原完整网格相同。被淘汰半区内的所有像素清为黑(0)。

**关键洞察**：连通分量数 N 既是被计数的对象数，又是每个对象移动的步数——增加一个对象会让所有对象（包括新增的）都多移动一步，形成"自指"式的数量-距离耦合。
