## 新题 2：最短路径筛选色块后挖孔紧凑排列

**组合逻辑**：[寻路/最短路径](创新：路径不作为输出，而作为筛选判据) → [筛选](创新：路径经过与否决定色块存亡) → [挖孔/同色匹配](已有) → [紧凑排列](创新：排列顺序由路径上的遭遇顺序决定)

**来源原语**：寻路/pathfinding(3ad05f52), 最短路径/shortest_path(3ad05f52), 筛选/filtering(29623171), 挖孔/punch_holes(58f5dbd5), 同色匹配/same_color_matching(58f5dbd5), 紧凑排列/compact_packing(58f5dbd5), 模板图案/motif_stencil(58f5dbd5), 单色块/monochrome_block(58f5dbd5), 端点分量/endpoint_component(3ad05f52), 走廊通道/corridor(3ad05f52)

**依赖链**：最短路径决定哪些色块存活（路径未经过的色块被淘汰）→ 只有存活色块才执行挖孔操作 → 紧凑排列的顺序取决于路径首次经过各色块的先后。路径改变则存活集合和排列顺序都改变；挖孔依赖存活筛选；排列依赖路径顺序——三者环环相扣。

在迷宫中寻找两端点间的最短路径，保留路径经过的色块并用同色模板挖孔，按路径遭遇顺序紧凑排列。

**输入结构**：
- 约 20x20 的网格，黑(0)背景。
- 栗(9)色像素构成单像素宽的正交墙壁，形成迷宫走廊。
- 迷宫中散布 4~5 个 5x5 的单色实心方块（各用不同颜色：蓝(1)、绿(3)、黄(4)、品红(6)等）。方块占据走廊的一部分，但不阻断通路（方块周围至少有一条绕行通道）。
- 迷宫的两侧（如左上角和右下角）各有一个 2x2 的红(2)端点分量，标记路径的起止点。
- 在远离走廊的区域（如网格底部边缘外侧的留白行），放置与每个方块同色的小型模板图案（3~5 像素的 4-连通不规则图形），每个模板颜色唯一对应一个方块。
- 生成约束：两端点间存在唯一最短路径（无平局）；最短路径必经过部分但非全部色块的边界框内部；模板图案的边界框不超过 5x5，能居中放入方块内。

**规则**：
1. 将栗(9)墙壁像素视为阻塞，其余像素视为可通行。求两个红(2)端点分量之间的 4-连通最短路径（路径像素集合）。
2. 检查每个 5x5 单色方块：若最短路径至少经过该方块边界框内的一个像素，则该方块存活；否则淘汰。
3. 对每个存活方块，找到与其同色的模板图案，将模板居中对齐到方块上，模板覆盖的像素位置在方块中被擦除为黑(0)（挖孔）。居中方式：模板边界框的中心与 5x5 方块中心对齐（向左上取整）。
4. 按最短路径首次进入各存活方块边界框的先后顺序，将挖孔后的方块紧凑排列为一行，相邻方块间隔 1 列黑(0)像素，左侧留 1 列黑(0)边框。
5. 输出网格高度为 5+2（上下各 1 行边框），宽度为 存活方块数x5 + (存活方块数-1)x1 + 2（左右各 1 列边框）。

**关键洞察**：最短路径不是最终输出的一部分，而是充当"筛选器"和"排序器"的隐式中间结果——同一组色块和模板，在不同迷宫布局下会因路径不同而产出完全不同的排列。
