## 新题 9：嵌套形状面积排序后按环层射线延伸填色

**组合逻辑**：[排序/嵌套层次/面积序](已有) → [射线延伸](创新：射线不在原图上延伸，而在压缩后的方环结构中从中心向外辐射) → [填充](创新：射线经过的环层被填充为该环的颜色，未经过的保持背景色)

**来源原语**：排序/sorting(eb5a1d5d), 嵌套层次/nesting_hierarchy(eb5a1d5d), 面积序映射环/area_order_to_ring(eb5a1d5d), 方环/square_ring(eb5a1d5d), 射线延伸/ray_extend(d968ffd4, b942fd60), 填充/fill(17b866bd), 标记像素/marker_pixel(17b866bd, b942fd60)

**依赖链**：嵌套形状按面积排序确定环层分配 → 标记像素在中心区域的位置和朝向决定射线方向 → 射线从中心向外穿过各环层，只有被射线穿过的环层像素才被填色，其余环层保持黑色。排序决定了哪种颜色在哪一层；射线决定了哪些层可见——两者共同决定最终输出。

将嵌套形状按面积排序映射为方环骨架，再根据中心标记像素射出的射线方向选择性填色各环层。

**输入结构**：
- 约 15x15 的黑(0)背景网格。
- 网格中有 3~5 个不同颜色的单色嵌套形状（如蓝(1)、绿(3)、黄(4)、品红(6)），从大到小嵌套排列。每层形状为不规则但有明确边界框的 4-连通区域。
- 最内层形状的中心有一个红(2)标记像素。
- 标记像素的上、下、左、右四个相邻位置中，恰好有 1~3 个方向被最内层形状像素占据，其余方向为黑(0)。被占据的方向即为射线发射方向。
- 生成约束：各嵌套形状的边界框面积互不相同；标记像素恰好在最内层中心（边界框中心取整）；射线方向至少 1 个、至多 3 个。

**规则**：
1. 检测所有非黑、非红的单色连通区域，计算各自的边界框面积（宽 x 高），按面积从大到小排序。
2. 创建输出方环网格：设有 K 个形状，输出为 (2K-1) x (2K-1) 的网格。面积最大的颜色为最外层环（第 1 圈边框像素），次大的为第 2 层环，...，最小的为中心像素。
3. 检查红(2)标记像素的 4 个正交邻居：若邻居为非黑、非红像素，则该方向为射线方向。
4. 从方环网格的中心像素出发，沿每个射线方向延伸直线直到网格边缘。
5. 只有被至少一条射线穿过的像素才保留其环层颜色；未被任何射线穿过的像素设为黑(0)。中心像素始终保留其颜色。
6. 红(2)标记像素不出现在输出中。

**关键洞察**：嵌套形状的面积排序决定了环层颜色分配，但最终可见的环层取决于标记像素邻域的占据模式——一个在输入中看似无关紧要的局部特征（标记像素的邻居方向）控制了输出中哪些环层可见，这需要同时理解全局排序和局部方向编码。
