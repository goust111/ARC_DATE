## 新题 1：遮挡揭示后的对称补全决定腔室存亡

**组合逻辑**：[擦除](已有) → [对称补全](创新：作用于格点腔室内的碎片而非独立对象) → [计数](已有) → [筛选+填充](创新：计数结果作为腔室间的竞争判据)

**来源原语**：擦除/erase(3345333e), 对称补全/symmetry_completion(3345333e), 填充/fill(17b866bd), 计数/counting(d0f5fe59, 29623171), 筛选/filtering(29623171), 格点骨架/lattice_frame(17b866bd), 封闭腔室/enclosed_cavity(17b866bd), 填充矩形/filled_rectangle(3345333e), 遮挡/occlusion(3345333e)

**依赖链**：遮挡移除改变了腔室内的可见像素集 → 对称补全依赖移除后的像素集推断完整图案 → 完整图案的像素数是腔室间竞争的判据 → 竞争胜出决定哪些腔室被填充、哪些被清空。删除任一环节均无法独立求解：不移除遮挡则对称轴检测失败；不做对称补全则像素数不准确，竞争结果错误；不做竞争筛选则不知道保留哪些腔室。

从格点腔室中移除遮挡矩形、对称补全碎片图案，再以补全后像素数最多的腔室胜出并被洪泛填充，其余腔室清空。

**输入结构**：
- 约 17x17 的网格，灰(5)色像素构成周期性格点骨架（横竖各 1 像素宽的灰线），将内部分隔为若干矩形腔室（每个腔室内部约 4x4 至 5x5 像素）。
- 其中 3~4 个腔室包含单色碎片图案（每个腔室使用不同颜色，如蓝(1)、绿(3)、黄(4)等），碎片为 4-连通的不规则小图形（3~8 像素），具有潜在的左右镜像对称性。
- 每个含图案的腔室中有一个红(2)填充矩形（2x2 或 2x3），部分覆盖碎片图案，遮挡了图案的部分像素。被遮挡的部分恰好包含对称补全所需的关键像素。
- 其余腔室为纯黑(0)背景。
- 生成约束：每个碎片图案在其腔室中具有唯一的左右镜像对称轴；遮挡矩形的颜色（红(2)）与所有图案颜色不同；遮挡移除后的残余像素足以唯一确定对称补全结果；各腔室图案补全后像素数互不相同（保证筛选无歧义）。

**规则**：
1. 识别每个腔室内的红(2)填充矩形，将其像素擦除为黑(0)。
2. 对每个腔室内剩余的非黑、非灰像素集合，检测其左右镜像对称轴（轴为腔室内的某一竖直列或两列之间的中线）。将现有像素沿该轴镜像翻转，在对称位置补上缺失像素，颜色与源像素相同。
3. 统计每个腔室内补全后的图案像素总数。
4. 像素数最多的腔室胜出：将该腔室内所有黑(0)像素替换为该图案的颜色（即洪泛填充整个腔室内部）。所有其他含图案的腔室，将图案像素擦除为黑(0)。
5. 格点骨架和空腔室保持不变。

**关键洞察**：遮挡矩形的位置经过精心放置，使得不移除遮挡时，残余像素的朴素计数会指向错误的腔室；只有正确补全对称后，真实像素数最多的腔室才会被揭示。

## 实现要求

1. `main(grid)` 必须实现新题描述中的确定性转换规则，不能只识别 `generate_input()` 的固定模板。禁止不同的input网格输出相同的output网格。
2. `generate_input()` 必须随机生成多样样例，不能固定死。随机维度应覆盖：网格大小、对象数量、位置、颜色、方向、形状参数或关键分支。注意若描述中存在若干，需实现而不是只有单个，包括object或者对应关系等等。且若涉及到最短路径，则输入网格中必涉及到多条路径，对选择造成干扰。
3. 生成器必须保证输入满足 `main()` 的隐式假设：对象不重叠、不越界、特殊标记唯一或可区分、匹配关系无歧义、关键分支出现概率相同。
4. 禁止把 ARC 颜色 id 、亮度、拼写等当作人类不可见的数值语义参与排序、大小比较或隐藏映射。颜色变化必须有可见结构线索。注意颜色亮度、拼写等也是不可见信息，若描述中出现违规的颜色id或者亮度，可自行使用少量的固定颜色替代，但注意生成时要在三个以内输入输出网格中对所有变换100%覆盖度。
5. 输出样例要视觉清晰，人类必须能从输入输出对中肉眼辨认出规律。具体要求：避免对象粘连、覆盖关系混乱、同一像素多重语义；不同逻辑步骤产生的结果不要大面积层叠在一起导致无法分辨哪个颜色属于哪个步骤；输入中各元素之间保持足够间距，输出中新增的标记/填充/路径等应与背景和已有元素在颜色上有明显区分；若规则涉及多层叠加，生成时控制对象密度和尺寸，确保叠加区域只占少数像素而非铺满整个网格。
6. 若规则有多个分支，生成器不能长期固定成一个分支；应让分支在随机样例中合理出现。分支概率不必平均——难以发现的隐蔽分支（如少数情况下才触发的特殊规则）应适当提高出现概率，确保在 3 个训练示例中至少出现一次，否则求解者无法归纳该规则。对于颜色映射类规则，确保 2 个左右的示例即可覆盖所有映射关系（每种颜色→颜色的映射至少在某个示例中出现过）。
