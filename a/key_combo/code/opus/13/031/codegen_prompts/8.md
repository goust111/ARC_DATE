## 新题 8：原型互换后按遮挡层序输出颜色序列

**组合逻辑**：[替换(replace) + 互换原型(toggle_to_alternate_prototype)](已有) → [遮挡层序(occlusion_order) + 排序(sorting)](已有，但排序对象是互换后而非原始的精灵体) ← 互换改变了颜色分布，从而改变了遮挡关系的判读

**来源原语**：替换(replace)、缩放(scale)、原型精灵(prototype_sprite)、锚点区域(anchor_region)、原型配对(prototype_pairing)、互换原型(toggle_to_alternate_prototype) ← c7f57c3e；排序(sorting)、补全(reconstruct)、空心矩形(hollow_rectangle)、重叠层(overlap_layer)、遮挡层序(occlusion_order)、重叠定先后(overlap_determines) ← 68bc2e87

**依赖链**：识别两种原型并互换每个精灵体的原型 → 互换后精灵体的形状改变，导致重叠区域和遮挡关系改变 → 根据新的遮挡关系推断层序并输出。若跳过互换直接判层序，得到的是原始层序（不同）；若跳过层序判断则不知输出什么。

将所有精灵体切换为另一种原型后，根据新布局中的遮挡关系推断从底到顶的层序，输出为单列颜色序列。

**输入结构**：
- 背景为黑(0)，网格约 16x16。
- 存在两种小型原型图案 A 和 B（均为 3x3 以内的二值掩码，形状不同但像素数相近）。原型 A 和 B 各自有一个标准形态（不旋转不翻转）。
- 网格上有 3~4 个精灵体，每个精灵体是原型 A 或 B 的整数倍缩放版本（缩放因子 1~3），使用不同前景色（蓝(1)、红(2)、绿(3)、黄(4) 等），放置在网格上可能相互重叠。
- 重叠处仅显示最上层精灵体的颜色（遮挡关系）。
- 每种原型至少有一个精灵体实例。
- 生成约束：每个精灵体可通过颜色唯一识别。互换原型后（A→B、B→A，保持同一缩放因子，以精灵体内锚点对齐），所有精灵体仍在网格内。互换后的重叠关系使得层序可唯一确定（任意两个重叠的精灵体之间的遮挡方向一致）。

**规则**：
1. 从最小面积的精灵体中识别出两种原型图案 A 和 B。
2. 对每个精灵体，确定其当前原型（A 或 B）、缩放因子 s 和颜色 c。
3. 将每个精灵体切换为另一种原型：原型 A 的精灵体变为原型 B 的 s 倍版本，反之亦然。对齐方式：以精灵体边界框的左上角为锚点。
4. 清空画布为黑(0)。按原始的从底到顶顺序绘制互换后的精灵体（顶层最后绘制，覆盖下层）。
5. 从互换后的画布中推断层序：对每对在新画布上重叠的精灵体，观察重叠处可见的颜色确定谁在上层。
6. 输出一个 Nx1 的单列网格（N = 精灵体数量），从上到下按从底层到顶层的顺序排列各精灵体的颜色。

**关键洞察**：直接从输入画面读取的层序是互换前的遮挡关系——互换原型后形状改变，新的重叠区域不同于旧的，但层序本身不变（层序是精灵体的固有属性，不因形状改变）。真正的难点在于：求解者必须先完成原型互换才能验证层序的正确性，因为输入中某些遮挡区域在互换后可能不再重叠（无法提供层序约束），而互换后新出现的重叠区域提供了额外约束。需对比多个示例才能确认层序在互换前后保持一致。
