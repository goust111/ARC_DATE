## 新题 10：双面板对称修复后印章覆盖共识位置

**组合逻辑**：[对称补全(symmetry_completion) + 推断对称轴(infer_symmetry_axes)](已有) + [逐像素比较(pixel_comparison)](已有) → [印章覆盖(stamp_overlay)](创新：印章位置由两面板共识像素决定，非由高频色决定)

**来源原语**：对称补全(symmetry_completion)、修复(repair)、双轴对称图案(biaxial_symmetric_pattern)、缺失像素(missing_pixel)、镜像对应(mirror_correspondence)、推断对称轴(infer_symmetry_axes) ← 981571dc；逐像素比较(pixel_comparison)、面板(panel)、分隔列(separator_col)、面板对齐(panel_align) ← d47aa2ff；印章覆盖(stamp_overlay)、输入图案(input_pattern)、块槽位(block_slot)、高频色定印章位(dominant_color_selects_pos) ← 27f8ce4f

**依赖链**：对称补全修复两个面板中的缺失像素 → 逐像素比较修复后的两面板找到共识前景位置 → 共识位置的布局决定印章的放置位置。对称补全改变了比较的输入；比较结果改变了印章位置——三步紧耦合，删除任一步结果不同。

修复两个面板各自的对称缺损，比较修复结果找出共同前景位置，在这些位置对应的缩放块槽中印上一个源图案。

**输入结构**：
- 网格约 9x19（高 9，宽 19），中间第 10 列为灰(5) 色分隔列。左右各一个 9x9 面板。
- 每个面板包含一个 4 色对称图案（使用蓝(1)、红(2)、绿(3)、黄(4)），具有双轴对称性（水平轴和竖直轴）。每个面板中有 2~4 个像素被擦除为黑(0)，破坏了对称性。两个面板的完整对称图案相同，但被擦除的位置不同。
- 网格底部额外附加 3 行（总高度变为 12x19），这 3 行的左侧 3 列包含一个 3x3 的源图案（使用品红(6) 和青(8) 两种颜色），其余为黑(0)。
- 生成约束：每个面板中被擦除的像素可以通过该面板自身的对称性唯一恢复（至少一条对称轴上的镜像位置保留了正确颜色）。两面板修复后完全相同。修复后的面板可以被视为 3x3 的逻辑块网格（每块 3x3 像素）。

**规则**：
1. 对每个面板，从其非黑像素推断水平和竖直对称轴，用镜像位置的颜色填补黑(0) 缺失像素，恢复完整对称图案。
2. 逐像素比较修复后的左右面板。因两面板修复后相同，所有位置都是"共识"位置。提取共识前景位置（非黑像素）。
3. 将 9x9 的共识图案视为 3x3 的逻辑块网格（每块 3x3 像素）。对每个逻辑块位置，若该块内存在至少一个前景像素，则标记该逻辑位置为"活跃"。
4. 创建一个 9x9 的黑(0) 输出网格（同样分为 3x3 逻辑块）。对每个"活跃"的逻辑位置，将底部的 3x3 源图案复制到该位置对应的 3x3 块中。
5. 非活跃的逻辑位置保持黑(0)。

**关键洞察**：两个面板各自有不同的缺损，单独看任一面板都无法确定完整图案（某些位置两条对称轴的镜像都被擦除）。但两面板的缺损位置不同，互相补充——修复后比较可验证结果正确性。印章位置不由某种颜色的频率决定（与源题 27f8ce4f 不同），而由修复-比较流程的结果决定。

## 实现要求

1. `main(grid)` 必须实现新题描述中的确定性转换规则，不能只识别 `generate_input()` 的固定模板。禁止不同的input网格输出相同的output网格。
2. `generate_input()` 必须随机生成多样样例，不能固定死。随机维度应覆盖：网格大小、对象数量、位置、颜色、方向、形状参数或关键分支。注意若描述中存在若干，需实现而不是只有单个，包括object或者对应关系等等。且若涉及到最短路径，则输入网格中必涉及到多条路径，对选择造成干扰。
3. 生成器必须保证输入满足 `main()` 的隐式假设：对象不重叠、不越界、特殊标记唯一或可区分、匹配关系无歧义、关键分支出现概率相同。
4. 禁止把 ARC 颜色 id 、亮度、拼写等当作人类不可见的数值语义参与排序、大小比较或隐藏映射。颜色变化必须有可见结构线索。注意颜色亮度、拼写等也是不可见信息，若描述中出现违规的颜色id或者亮度，可自行使用少量的固定颜色替代，但注意生成时要在三个以内输入输出网格中对所有变换100%覆盖度。
