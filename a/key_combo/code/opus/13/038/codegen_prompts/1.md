## 新题 1：朝向分流的射线格点

**组合逻辑**：[朝向决定方向/orientation_determines_direction](创新：从行/列条改为对角线/基数方向分流) → [射线延伸/ray_extend](创新：从单方向改为按分类多方向发射) → [循环填充/periodic_fill](创新：仅施加于一类射线，与另一类形成填充模式差异) → [冲突优先级/conflict_priority](已有原语，适配新的两类射线)

**来源原语**：朝向决定方向(9344f635)、射线延伸(623ea044, 9344f635)、循环填充/周期相位对齐(c1990cce)、坐标奇偶匹配(d492a647)、冲突优先级(9344f635)

**依赖链**：朝向分类决定射线几何类型（对角线 vs 基数方向），几何类型同时决定填充模式（实心 vs 周期性），两类射线交叠时需冲突解决规则；三层决策彼此不可分离——去掉朝向分类则射线类型不确定，去掉周期调制则其中一类射线的输出错误，去掉冲突规则则交叠像素无法确定颜色。

根据微型标记（2 像素同色连通体）的朝向，将其分为两类并发射不同几何形态、不同填充密度的射线，交叠处按类型优先级覆盖。

**输入结构**：约 14x14 的网格，黑(0)背景。散布 3-5 个微型标记（domino），每个由 2 个相邻同色像素组成，颜色两两不同（取自 1-9 中的不同颜色）。标记分为水平朝向（两像素同行相邻列）和垂直朝向（两像素同列相邻行）两类。生成约束：不同标记间至少间隔 2 个空行空列；所有标记均不位于网格边缘行/列。

**规则**：
1. 按朝向将标记分为两组：垂直标记和水平标记。
2. **垂直标记**——从标记的两个像素各自出发，沿四个对角方向（左上、右上、左下、右下）画射线，一直延伸到网格边界，沿途每个格子都涂上该标记的颜色（实心填充）。标记本身的两个像素保持不变。
3. **水平标记**——从标记的两个像素各自出发，沿上、下两个基数方向画射线，一直延伸到网格边界，但采用周期性填充：仅涂色那些与出发像素的 (行+列) 奇偶性相同的格子（即 `(r_cell + c_cell) mod 2 == (r_source + c_source) mod 2` 的格子涂色，其余格子跳过保持黑(0)）。标记本身的两个像素保持不变。
4. **冲突解决**：当两条射线声称同一个格子时——(a) 水平标记的射线优先于垂直标记的射线（水平覆盖垂直）；(b) 同类标记之间，出发像素到争议格子的曼哈顿距离更近的标记优先；(c) 距离也相同时，出发像素行号更小的优先，行号也相同则列号更小的优先。

**关键洞察**：朝向不仅决定射线方向（对角 vs 基数），还同时决定填充密度（实心 vs 间隔），这是需要对比多个示例才能归纳的双重编码——单看一个示例可能误以为填充密度与颜色有关而非与朝向有关。

<description>
Move every red object horizontally until it is flush with the side of its enclosing blue or teal region.

Input structure
- The grid contains only blue, red, and teal pixels.
- The red pixels form one or more 4-connected objects.
- Each red object is embedded in exactly one adjacent non-red carrier color.

Rule
- Clear each red object back to its carrier color to recover the blue and teal regions.
- A red object carried by blue moves right until its bounding box touches the right edge of that blue region.
- A red object carried by teal moves left until its bounding box touches the left edge of that teal region.
- Preserve the object's shape and rows, and apply all object moves simultaneously.

Key insight
- The red objects are sliders inside colored horizontal lanes; the carrier color encodes the slide direction.
