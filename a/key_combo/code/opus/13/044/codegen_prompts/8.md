## 新题 8：平行对角线段填充面积转化为排序柱状条

**组合逻辑**：[填充](对角段间平行四边形区域填充既是视觉输出又是面积度量) → [计数](填充面积) → [排序+堆叠](面积→柱状条高度，段色→柱色，面积升序排列)

**来源原语**：填充/对角线段/平行四边形区域/平行配对/段间区域填充(7666fa5d) + 计数(37ce87bb) + 排序/堆叠(2ba387bc) + 柱状条/高度加减运算(37ce87bb)

**依赖链**：识别平行反对角线段对 → 填充段对之间的平行四边形区域为红(2) → 计算每个平行四边形的红(2)像素数作为面积 → 面积决定柱状条高度 → 段对的原始颜色决定柱状条颜色 → 按面积升序在右侧结果区排列柱状条

一句话总结：填充平行对角线段对之间的区域，然后将填充面积转化为右侧结果区中按面积排序的彩色柱状条。

**输入结构**：约 15x22 的网格，沿垂直方向分为左区（约 15x15）和右区（约 15x7）。左区为黑(0)背景，包含 3~4 对平行反对角线段（每对由同色的 2 条短反对角线段组成，每段 3~5 像素长，两段平行且位于不同反对角线 r+c=k1 和 r+c=k2 上）。不同段对使用不同颜色（从蓝(1)、绿(3)、黄(4)、品红(6)、橙(7)中选取）。段对之间不交叉。右区为黑(0)背景的空白结果区域，底部有一条灰(5)水平基线（最后一行全灰）。生成约束：各段对形成的平行四边形面积互不相同。

**规则**：
1. 在左区中，按颜色分组识别反对角线段对。每对包含 2 条同色段，分别位于反对角线 r+c=k1 和 r+c=k2 上（k1 < k2）。
2. 对每对段，沿主对角线方向 (r-c = const) 在 k1 和 k2 之间填充：对于每条主对角线轴，若该轴上存在两段覆盖的行列范围，则将两段之间（不含段本身）的所有黑(0)背景单元格填充为红(2)。
3. 计算每个平行四边形区域内红(2)像素的总数，记为该段对的面积 A。
4. 将所有段对按面积 A 升序排列。
5. 在右区中，从左到右依次绘制柱状条（每条宽 1 列，相邻柱状条之间间隔 1 列空列）。第 i 个柱状条（从左起第 i 个奇数列）使用第 i 小面积的段对的原始颜色，高度 = A，从灰(5)基线向上生长（不含基线行）。
6. 左区的段和填充保持不变。

**关键洞察**：填充操作的一体两用是核心创新——它既是左区的视觉变换输出，又是右区柱状条高度的度量输入。源题中段间填充是最终结果，这里填充面积还驱动了后续的排序和堆叠。颜色从段对传递到柱状条而非使用填充的红色，需对比示例确认这一映射。
