## 新题 2：对角象限周期平铺着色

**组合逻辑**：[标记块 + 对角映射](已有，定义四象限) → [周期平铺图案](已有，提供纹理模板) → [重涂色](创新：不再是全局双色互换，而是按象限将模板前景色替换为该象限的标记色)

**来源原语**：标记块/象限区域/对角映射/标记色填对角区(#5 93b581b8), 周期平铺图案(#13 abbfd121), 重涂色(#14 d511f180)

**依赖链**：标记块的对角映射将网格划分为四个象限并指定每个象限的"目标色"。周期平铺图案提供内部纹理但不含颜色信息（或只有一种前景色）。每个象限用标记色替换纹理的前景色后进行平铺填充。去掉标记块则象限边界和目标色均不可知；去掉周期图案则象限内容无从生成；去掉重涂色则所有象限的纹理颜色相同，无法区分。

以 2x2 标记块的对角映射划分象限，在每个象限中铺设同一周期图案，但将图案前景色替换为该象限对应的标记色。

**输入结构**：约 13x13 网格，背景为黑(0)。网格中偏中央位置有一个 2x2 标记块，四个像素颜色互不相同，从蓝(1)、红(2)、绿(3)、黄(4)中取四种。网格的一个角落（如左上角）有一个小矩形区域（约 2x3 或 3x2），内部包含由灰(5)和黑(0)组成的二值周期图案（如棋盘格、条纹等），该图案可按行和列周期平铺。标记块与周期图案区域不重叠。其余区域为纯黑(0)背景。生成约束：标记块不在网格边缘（确保四个象限均有面积）；周期图案的行周期和列周期均不超过 3。

**规则**：
1. 找到 2x2 标记块，记录其四个像素的位置和颜色。
2. 按对角映射规则划分四个象限：标记块左上像素的颜色分配给右下象限，右上像素的颜色分配给左下象限，左下像素的颜色分配给右上象限，右下像素的颜色分配给左上象限。每个象限是从标记块对应角向外延伸到网格边界的矩形区域（不含标记块本身的 2x2 区域）。
3. 找到角落处的周期图案模板，确定其行周期 pr 和列周期 pc。
4. 对每个象限区域，按行列周期平铺该模板（以象限左上角为平铺原点）。模板中灰(5)像素替换为该象限的目标色，黑(0)像素保持黑(0)。
5. 标记块本身的 2x2 区域保留不变。角落的模板区域被所在象限的平铺结果覆盖（模板只是定义用的，不在输出中单独保留）。

**关键洞察**：周期图案模板只有一份，但在四个象限中以不同颜色呈现——标记块既定义了空间分区又定义了颜色赋值，周期图案只提供几何纹理。单个示例无法确定对角映射方向（左上→右下还是其他），必须对比多个示例才能归纳。
