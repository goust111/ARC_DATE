## 新题 5：印章复制后内嵌标记计数决定膨胀厚度

**组合逻辑**：[印章覆盖/相对坐标复制](已有) → [计数/内嵌标记计数](创新：计数对象不是原始物体中的标记而是印章复制后才出现的标记) → [扩展填充/膨胀](已有)

**来源原语**：印章覆盖/相对坐标复制/控制像素/锚点像素/最强邻接为锚点(f5c89df1), 扩展填充/计数/膨胀/内嵌标记计数/计数决定扩展量(52fd389e)

**依赖链**：源精灵体通过锚点像素定义坐标系，被复制到多个目标控制像素位置。但每个目标控制像素颜色不同，印章完成后该颜色像素会嵌入到复制体中（替换复制体在目标位置处的像素），形成不同数量的"标记"。计数每个复制体中标记像素的数量，以此为厚度向外膨胀出同色光环。删掉印章则无复制体；删掉计数则不知膨胀厚度；删掉膨胀则计数无意义。

将源精灵体印章复制到各目标位置，每个目标处的控制像素颜色嵌入复制体中形成标记，标记数量决定该复制体的膨胀光环厚度。

**输入结构**：约 18x18 的黑(0)背景网格。包含以下元素：
- 一个蓝(1)的源精灵体（4-连通，5~10 像素，形状不规则但边界框不超过 4x4）。
- 一个红(2)锚点像素，4-邻域中与蓝(1)源精灵体接触的边数最多（若平局则取行号最小、再列号最小的）。
- 3~4 个分散的目标控制像素，颜色各不相同，从绿(3)、黄(4)、品红(6)、橙(7)中选取。每个目标像素所在位置恰好对应于源精灵体相对于锚点的某个非黑像素偏移位置——即如果将源精灵体以锚点为原点建立坐标系，目标像素在其目标位置处占据了源精灵体某个像素的对应位置。
- 生成约束：各目标位置的印章区域互不重叠，距网格边界至少 3 行/列（为膨胀留空间）；每个目标控制像素的颜色恰好出现 1 次。

**规则**：
1. 识别锚点：红(2)像素中 4-邻域接触蓝(1)像素数最多的那个为锚点。
2. 计算源精灵体相对于锚点的像素偏移集合 S = {(dr, dc) | 蓝像素位于 (锚点行+dr, 锚点列+dc)}。
3. 对每个目标控制像素 T（位于 (tr, tc)，颜色为 C_t）：在 (tr+dr, tc+dc) 处对所有 (dr,dc) in S 绘制蓝(1)像素——但如果 (tr, tc) 本身对应偏移集合中的某个 (dr0, dc0)，则该位置保留 C_t 颜色而非蓝色。
4. 擦除原始源精灵体和锚点像素。
5. 对每个印章复制体：统计其中颜色为 C_t 的像素数量 N（即嵌入标记数，始终为 1，但目标像素可能与精灵体的多个像素重合——此处 N 等于该控制像素颜色在复制体边界框内出现的总次数）。
6. 将每个复制体的边界框向上下左右各扩展 N 个像素，扩展区域填充颜色 C_t。扩展区域不覆盖复制体本身的蓝(1)像素和 C_t 标记像素——它们保持可见。不同复制体的膨胀区域若重叠，后处理的（按目标像素行号从小到大、行号相同则列号从小到大的顺序处理）覆盖先处理的。

**关键洞察**：目标控制像素不仅标记印章的放置位置，其颜色还会嵌入复制体成为标记——标记数量编码了膨胀距离，标记颜色编码了光环颜色，这种"位置信息转化为参数信息"的编码需要对比多个印章副本的不同膨胀结果才能归纳。
