## 新题 9：多数投票共识图案作为印章模板盖在标记位置上

**组合逻辑**：[修复异常/多数投票共识](已有) → [印章渲染](创新：模板不来自输入的专用区域而来自投票修复的结果) ← [标记像素/颜色索引模板](创新：标记颜色编码模板的旋转角度而非模板选择)

**来源原语**：修复异常/重复图块/分隔网格/多数投票共识/受损副本被标记(e84fef15), 印章渲染/模板掩码/标记像素/颜色索引模板/编码映射(65b59efc)

**依赖链**：输入的上半部分是分隔网格中的重复瓦片（含一个受损副本），通过多数投票恢复出共识图案作为模板。输入的下半部分散布标记像素，每个标记像素的颜色编码模板的旋转角度（如蓝=0度、红=90度、绿=180度、黄=270度）。在标记位置以对应旋转角度印章共识模板。模板来源和印章放置分属不同逻辑步骤，紧密耦合。

从重复瓦片的多数投票中修复出共识模板，然后按标记像素的颜色编码旋转角度，将模板印章到标记位置。

**输入结构**：约 18x20 的黑(0)背景网格，由一条灰(5)水平分隔行分为上下两个区域。
- 上区域：一个 2x3 或 3x2 的瓦片格（每个瓦片约 3x3 到 4x4），瓦片之间由灰(5)单像素列/行分隔。所有瓦片是同一图案的副本，使用橙(7)和青(8)两种颜色构成图案（黑(0)为瓦片内背景）。其中恰好一个瓦片有 1~2 个像素被损坏（替换为黑色）。
- 下区域：黑(0)背景上散布 2~4 个标记像素，颜色从蓝(1)、红(2)、绿(3)、黄(4)中选取。每种颜色至多出现一次。
- 生成约束：每个标记像素周围有足够空间（至少等于模板尺寸）放置印章且印章间互不重叠；标记像素仅出现在下区域。

**规则**：
1. 在上区域中识别灰(5)分隔行/列，提取所有瓦片副本。
2. 对每个瓦片局部坐标 (lr, lc)，取所有副本中该位置出现次数最多的颜色作为共识色，得到共识模板 M（尺寸 Hm x Wm）。
3. 颜色-旋转映射：蓝(1)=0 度（不旋转），红(2)=90 度顺时针，绿(3)=180 度，黄(4)=270 度顺时针。
4. 对下区域的每个标记像素 T（位于 (tr, tc)，颜色为 C_t）：将共识模板 M 按 C_t 对应的角度旋转，然后以 (tr, tc) 为旋转后模板的左上角进行印章渲染。印章像素覆盖目标区域（包括覆盖标记像素本身），黑(0)像素不覆盖（透明）。
5. 输出仅包含下区域（从灰分隔行下方一行开始到网格底部），其中包含所有印章结果。若多个印章重叠，后处理的（按标记像素行号从小到大、行号相同则列号从小到大）覆盖先处理的。上区域和灰分隔行不出现在输出中。

**关键洞察**：共识模板不是直接给出的而是需要从冗余副本中修复得到——如果不做多数投票修复，受损的瓦片会污染模板导致印章结果错误。同时标记颜色到旋转角度的编码映射是隐蔽规则，需要对比多个标记位置的印章朝向才能归纳出颜色-角度对应关系。
