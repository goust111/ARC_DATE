## 新题 3：射线分区后按区域面积排序循环填充

**组合逻辑**：[射线延伸](已有) → [区域填充](创新：填充对象是射线分隔出的不规则区域而非预定义形状) ← [排序](创新：区域面积排序决定填充颜色分配) + [循环填充](创新：调色板循环应用于按面积排列的区域序列)

**来源原语**：射线延伸/射线遮挡分区/处理顺序决定遮挡(1190bc91), 循环填充/顺序排列/调色板列(e7b06bea), 排序(62593bfd), 区域填充(1190bc91)

**依赖链**：多色水平长线段的每个像素向四个 45 度方向发射射线（按从左到右顺序，先发射的遮挡后发射的），射线将网格分割为若干不规则连通区域。然后统计每个区域的面积并按面积从小到大排序，用右侧调色板列中的颜色按顺序循环分配给排序后的区域。删掉射线步骤则无区域可填；删掉排序则不知颜色如何分配；删掉调色板则无颜色来源。

从水平长线段发射对角射线将网格分割为不规则区域，然后按区域面积从小到大使用右边的调色板列循环着色。

**输入结构**：约 15x15 的黑(0)背景网格。一条水平多色长线段（4~8 像素）位于网格中部偏上位置（约 row 3~5），由 3~5 种不同非黑颜色的像素组成（如蓝(1)、红(2)、黄(4)、橙(7)等），每种颜色出现 1~2 次。网格最右列为调色板列，从上到下排列 2~4 种颜色的像素（如绿(3)、品红(6)、青(8)），其余位置为黑(0)。生成约束：多色线段不与调色板列相邻（中间至少隔 2 列黑色）；线段长度和位置保证射线能在网格内形成至少 4 个封闭或半封闭区域。

**规则**：
1. 在空白画布上，处理多色水平线段从左到右的每个像素：每个像素向四个 45 度方向（左上、右上、左下、右下）发射射线，射线以该像素的颜色着色。射线在碰到已有非黑像素或网格边界时停止（不覆盖该终点像素）。
2. 射线和线段像素将网格（不含调色板列所在的最右列）分割成若干 4-连通的黑色背景区域。计算每个区域的面积（像素数）。
3. 将所有区域按面积从小到大排序。面积相同的区域按其最上最左像素的位置排序（先比较行号小的优先，行号相同则列号小的优先）。
4. 读取调色板列从上到下的颜色序列 P。按排序后的区域顺序，第 i 个区域（从 0 开始）填充颜色 P[i mod len(P)]。
5. 输出网格中保留射线像素和线段像素不变，调色板列擦除为黑(0)。

**关键洞察**：射线的发射顺序造成遮挡差异，使得相同长度的线段在不同示例中可能产生不同数量和形状的区域——区域面积排序将这种不规则几何转化为有序序列，而调色板循环则将序列映射为颜色，三层逻辑缺一不可。
