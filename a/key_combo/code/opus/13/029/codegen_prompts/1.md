## 新题 1：重力堆叠高度决定同心环半径

**组合逻辑**：[重力下落](已有) + [计数](已有) → [同心层填充](创新：环半径不由固定色板给出，而由堆叠高度动态决定) ← [种子像素](已有) + [边墙](已有)

**来源原语**：重力下落/堆叠/边墙/碰撞停止(6ad5bdfd), 同心层填充/切比雪夫距离索引/种子像素(9356391f), 计数(52fd389e)

**依赖链**：重力下落将散落的单色小物体堆向边墙，堆叠完成后每列的堆叠高度被计数；种子像素所在列的堆叠高度直接决定以该种子为中心的同心方环扩展半径；环的颜色取自该列中从靠近墙面到远离墙面的堆叠颜色顺序。删掉重力步骤则不知半径；删掉同心填充则堆叠结果无用途。

从散落在网格中的单色小物体出发，先将它们堆向底部边墙，然后以每个种子像素为中心、以该列堆叠高度为半径画同心方环，环色依堆叠顺序从内向外排列。

**输入结构**：约 15x15 的黑(0)背景网格。底部一整行为红(2)边墙。网格中散布 4~7 个单色 4-连通小物体（每个 2~4 像素，形状各异但保持连通），颜色从蓝(1)、绿(3)、黄(4)、橙(7)中选取，同一列可能有多个不同颜色的物体。另有 1~3 个灰(5)种子像素，每个位于不同列，且这些列中都有至少 2 个可堆叠的物体。生成约束：不同物体在水平方向可重叠的列中垂直方向不重叠；每个种子像素的列中堆叠高度不超过 4（以保证同心环不超出网格）。

**规则**：
1. 固定红(2)底部边墙不动。将所有非红、非灰的前景物体从其原位置擦除。
2. 每个物体沿垂直方向整体向下滑动，直到碰到边墙或已结算的其他物体。距边墙最近的物体先结算。物体保持原有形状不变形。
3. 堆叠完成后，对每个灰(5)种子像素：计算该种子所在列中堆叠物体占据的总行数 H。
4. 以种子像素为中心，画 H 层同心方环（切比雪夫距离 d=1,2,...,H）。第 d 层的颜色取自该列堆叠体从最靠近墙面的物体到最远处物体的颜色序列中的第 d 个颜色；若 d 超过颜色序列长度则循环重复。
5. 种子像素自身保持灰(5)不变。同心环超出网格边界的部分裁剪丢弃。同心环不覆盖堆叠后的前景物体——若环像素与已有堆叠物体冲突，堆叠物体优先保留。

**关键洞察**：重力堆叠不仅决定最终布局，还隐式编码了同心环的半径和颜色序列——堆叠高度=环数，堆叠顺序=颜色顺序，这层编码关系需要对比多个示例（不同列有不同堆叠高度和颜色顺序）才能归纳出来。
