## 新题 6：散落组件面积参数化空心框的同心填充深度

**组合逻辑**：[计数/面积](测量连通分量像素数) → [同心层填充](创新：填充深度由外部测量值决定而非固定循环) + [最近距离](创新：匹配组件到框架)（计数、同心层填充、最近距离为已有原语；面积控制填充深度为创新结构关系）

**来源原语**：同心层填充/concentric_fill(a3f84088), 按距离循环配色/distance_color_cycling(a3f84088), 空心矩形/hollow_rectangle(a3f84088), 嵌套层次/nesting_hierarchy(a3f84088), 连通分量/connected_component(1f85a75f), 面积比较/area_comparison(1f85a75f), 最近距离/nearest_distance(d6e50e54), 计数/counting(8597cfd7), 重涂色/recolor(8dae5dfc)

**依赖链**：每个散落组件的像素面积是一个数值 → 通过曼哈顿距离将每个组件绑定到最近的空心框 → 面积值 N 决定该框内部填充 N 层同心壳 → 组件颜色决定壳的着色 → 删去距离匹配则组件和框无对应关系，删去面积计数则填充深度不确定，删去同心填充则无输出结构

散落的小对象通过距离关联到空心框，其像素数量控制框内同心壳的层数，其颜色决定壳的颜色。

**输入结构**：约 17x17 网格，黑(0)背景。包含 2-3 个灰(5)单像素厚的空心正方形框，外框尺寸各异（如 5x5、7x7、9x9），内部全为黑(0)，框之间互不相邻。网格上散布 2-3 个小型单色 4-连通连通分量，每个颜色各不相同（如红(2)、蓝(1)、绿(3)），每个分量由 2-5 个像素组成，形状不规则（非固定几何形状，不同示例中同色分量形状不同）。每个分量与恰好一个框的距离最近（从分量任一像素到框任一像素的曼哈顿距离的最小值），且各组件的最近框互不重复。分量位于框的外部，不与框相邻。生成约束：每个分量的像素数不超过该框内部可容纳的最大同心壳数（框内边长为 S 时最大壳数为 ceil(S/2)）。

**规则**：
1. 对每个灰(5)空心框，计算所有连通分量到该框的最小曼哈顿距离（从分量任一像素到框边框任一像素），选择距离最小的分量作为该框的"参数对象"。
2. 计算参数对象的像素数量 N。
3. 从框内部最外圈（紧贴框边框的内侧一圈）开始，向内填充 N 层同心矩形壳。
4. 奇数层（第 1、3、5...层，从外到内计数）填充参数对象的颜色；偶数层（第 2、4、6...层）填充黑(0)。
5. 若 N 大于框内部可容纳的壳数 M，则填满全部 M 层（按上述奇偶规则）。若 N 小于 M，第 N+1 层起的内部区域保持黑(0)。
6. 灰(5)框边框本身始终保留不变。

**关键洞察**：散落的小对象看似噪声或装饰——实际上每个对象编码了两条信息：其颜色决定对应框的填充色，其面积（像素数）决定填充深度。距离度量为曼哈顿距离（而非欧氏距离），面积度量为像素计数（而非包围框面积），两者均需通过多个示例确认。
