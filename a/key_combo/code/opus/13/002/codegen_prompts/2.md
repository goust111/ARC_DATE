## 新题 2：对称补全揭示隐藏分隔线后计数生成网格

**组合逻辑**：[对称补全](恢复遮罩像素) → [计数](创新：对补全后涌现的完整分隔线进行区域计数) → [生成网格](以区域数为尺寸)（对称补全、计数、生成网格为已有原语；"补全后涌现分隔线"为创新结构关系）

**来源原语**：对称补全/symmetry_completion(929ab4e9), 遮罩像素/mask_pixel(929ab4e9), 八重对称轨道/eightfold_orbit(929ab4e9), 轨道内唯一可见色/unique_color_in_orbit(929ab4e9), 分隔线/separator_line(7039b2d7), 分区数决定尺寸/partition_count_determines_size(7039b2d7), 计数/counting(8597cfd7, 7039b2d7), 生成网格/generate_grid(7039b2d7)

**依赖链**：遮罩像素刻意打断了分隔线的连续性，使得补全前无法识别任何完整分隔线 → 八重对称补全恢复被遮挡的像素后，某些前景像素恰好连成贯穿全宽或全高的完整线 → 只有完整线才计入分隔，统计行方向和列方向的区域数 → 以区域数为尺寸生成均匀背景色网格

对称补全遮罩后，涌现的完整分隔线将网格划分为区域，区域行列数决定输出尺寸。

**输入结构**：约 11x11 或 13x13 的正方形网格，黑(0)背景。前景像素使用两种颜色：蓝(1)作为图案色，灰(5)作为遮罩色。蓝(1)像素的可见部分关于正方形中心具有八重对称性（上下翻转、左右翻转、两条对角线翻转、90/180/270度旋转均不变）。部分蓝(1)像素被灰(5)遮罩替换——被遮罩的位置经过精心选择，使得原本贯穿全宽的某条水平蓝色线和贯穿全高的某条垂直蓝色线各被打断至少一处。每个灰(5)像素的八重对称轨道中至少存在一个可见的蓝(1)像素。网格中除了分隔线段外还有其他蓝(1)装饰像素（也满足八重对称），但这些装饰像素不构成贯穿全宽或全高的完整线。生成约束：补全后恰好有 1-2 条完整水平分隔线和 1-2 条完整垂直分隔线。

**规则**：
1. 将所有灰(5)遮罩像素替换为其八重对称轨道中唯一可见的蓝(1)色（每个遮罩像素在正方形的 8 个对称位置中，至少有一个位置是可见的蓝(1)像素，用该颜色填充遮罩位置）。
2. 在补全后的网格中，找出所有由蓝(1)像素构成的完整水平线（该行每个像素均为蓝(1)，贯穿全宽）和完整垂直线（该列每个像素均为蓝(1)，贯穿全高）。不完整的线段和装饰像素不计入。
3. 将完整线视为分隔线。统计分隔线之间及边界之间的非分隔行的连续段数（行区域数 R）和非分隔列的连续段数（列区域数 C）。
4. 输出一个 R x C 的均匀网格，全部填充黑(0)。

**关键洞察**：遮罩并非随机损坏——它精确地打断了分隔线的关键段落，使补全前任何一条水平线或垂直线都不完整。只有完成对称补全后，真正的分隔线才从装饰像素中"浮现"，而哪些线是分隔线、哪些是装饰需要靠完整性判断。
