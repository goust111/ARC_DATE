## 新题 3：红色轴线镜像后涌现双色乘积图并提取

**组合逻辑**：[镜像](创新：绕指定轴线镜像而非全局拼接) + [提取](创新：寻找满足行列乘积性质的双色子图) + [擦除](去除轴线)（镜像、提取为已有原语；"镜像创造乘积性质"为创新结构关系）

**来源原语**：镜像/mirror(6d0aefbc), 拼接/concatenate(6d0aefbc), 双色图像/bicolor_image(b71a7747), 裁剪/crop(b71a7747, 1f85a75f), 行列乘积完整/row_col_product(b71a7747), 擦除/erase(6e4f6532), 分隔线/separator(7039b2d7)

**依赖链**：输入中没有任何双色组合满足行列乘积性质 → 识别红色水平线为镜像轴（而非分隔线） → 将轴线上方像素镜像到下方后，某对颜色的像素恰好填满其活跃行与活跃列的笛卡尔积 → 提取该双色子网格为输出

绕红色轴线上下镜像后，涌现一对满足行列完全乘积的双色图案，提取为输出。

**输入结构**：约 12x10 网格，黑(0)背景。网格中有一条红(2)水平线贯穿全宽，位于网格中部偏上或偏下的某一行（不在首行或末行）。红线上方分布着若干颜色各异的像素点，使用绿(3)和黄(4)两种颜色以及少量其他干扰色（如蓝(1)、橙(7)）。红线下方也有一些散布的像素，但颜色分布与上方不对称。在原始输入中，绿(3)和黄(4)的像素不满足行列乘积条件（即它们的活跃行集合与活跃列集合的笛卡尔积中存在空缺）。生成约束：红线上方的绿(3)和黄(4)像素经镜像到下方后，合并的活跃行集合与活跃列集合的笛卡尔积恰好全部被这两种颜色覆盖；干扰色像素在镜像后不满足此性质。

**规则**：
1. 识别唯一贯穿全宽的红(2)水平线，记其行号为 R。
2. 将第 0 行到第 R-1 行的所有像素镜像到红线下方对应位置：第 r 行 (r < R) 的像素复制到第 2R - r 行。若目标行超出网格边界则舍弃。镜像像素覆盖目标位置原有的颜色。
3. 将红线所在行（第 R 行）全部擦除为黑(0)背景。
4. 在处理后的网格中，枚举所有非背景色的双色组合 (A, B)。对每个组合，计算 A 和 B 的活跃行集合（包含 A 或 B 的行）和活跃列集合（包含 A 或 B 的列）。检验这两种颜色的像素是否恰好覆盖了活跃行 x 活跃列的每一个交叉单元格（每个单元格恰为 A 或 B 之一）。
5. 找到唯一满足此行列乘积条件的双色组合。保留其活跃行和活跃列，删除其余行列，输出得到的子网格。

**关键洞察**：红色横线不是分隔线或区域标记——它是镜像轴。原始输入中不存在任何满足行列乘积性质的双色组合，只有沿红线镜像后该性质才涌现。镜像方向（上方覆盖下方而非反向）需要对比多个示例确定。
