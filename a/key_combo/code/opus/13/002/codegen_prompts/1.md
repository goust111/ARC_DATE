## 新题 1：边缘标记射线穿越格子的距离优先填色

**组合逻辑**：[射线延伸](从边缘标记沿行/列穿越格子) + [填充](射线经过的格子槽位着色) + [最近距离](创新：射线交叉时距离决定优先级)（射线延伸、填充为已有原语；距离优先解决射线冲突为创新组合）

**来源原语**：射线延伸/ray_cast(673ef223), 格子框架/lattice_frame(2e65ae53), 格子槽位/lattice_slot(2e65ae53), 标记像素/marker_pixel(d6e50e54, 673ef223), 行列对齐/row_col_aligned(d6e50e54), 最近距离/nearest_distance(d6e50e54), 填充/fill(5b37cb25)

**依赖链**：边缘标记的位置决定射线方向和路径 → 射线穿越格子为每个经过的槽位赋色 → 当行射线和列射线在同一槽位交叉时，标记到格子边框的距离决定谁的颜色覆盖谁 → 删去射线投影则槽位无色源，删去距离优先级则交叉处歧义无法解决

从边缘标记发射行/列射线穿越中央格子，交叉处由标记到格子的距离决定优先填色。

**输入结构**：约 15x15 网格，黑(0)背景。中央有一个灰(5)单像素厚的矩形格子框架，将内部划分为 3x3 或 4x4 的矩形槽位（全部为黑(0)）。沿网格四条边缘散布若干孤立标记像素，颜色各异（如红(2)、蓝(1)、绿(3)、黄(4)），每个标记恰好与格子的一行或一列对齐（即标记所在行穿过某行槽位，或标记所在列穿过某列槽位）。每行槽位至多有两个标记（分别来自对面的两条边），每列槽位同理。各标记到格子框架最近像素的距离（沿射线方向的背景像素数）各不相同。生成约束：保证不会出现三条及以上射线交于同一槽位。

**规则**：
1. 每个标记像素沿其对齐的行或列方向，向格子框架发射一条射线。射线穿过格子框架后继续前进，直到到达网格边界或对面的边缘。
2. 射线经过的每个槽位（不含框架线像素）被填充为该标记的颜色。
3. 当某个槽位同时被一条行方向射线和一条列方向射线穿过时（交叉冲突），计算两个标记到格子框架最近像素之间的背景像素数目（不含标记自身和框架像素）。距离较小的标记胜出，该槽位填充胜出标记的颜色。
4. 若两条交叉射线的标记到框架距离相等，行方向射线（水平射线）优先。
5. 未被任何射线经过的槽位保持黑(0)。
6. 灰(5)框架线像素始终不变。

**关键洞察**：标记到格子的距离不是无意义的间距——它编码了射线之间的优先级。距离更近的标记在交叉点覆盖距离更远的标记；等距时水平优先的规则需对比多个示例才能归纳。
