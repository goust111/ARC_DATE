## 新题 7：重复行列压缩后提取最大连通分量

**组合逻辑**：[压缩](去除重复行列还原隐藏结构) → [选择/裁剪](创新：在压缩结果中识别并提取最大连通分量)（压缩、裁剪为已有原语；压缩作为去噪前置步骤以暴露可分离对象为创新结构关系）

**来源原语**：压缩/compression(ce8d95cc), 重复行/dup_row(ce8d95cc), 重复列/dup_column(ce8d95cc), 相邻相同/adjacent_identical(ce8d95cc), 相同行列合并/merge_identical(ce8d95cc), 连通分量/connected_component(1f85a75f), 面积比较/area_comparison(1f85a75f), 保留最大连通分量/keep_largest_component(1f85a75f), 裁剪/crop(1f85a75f, b71a7747)

**依赖链**：原始网格因行列拉伸而模糊了对象边界，看似均匀噪声 → 合并相邻相同行和相同列后恢复紧凑的小网格 → 压缩后的网格中出现多个不同颜色的前景连通分量和散布的干扰像素 → 选择面积最大的单色 4-连通分量并裁剪其边界框 → 删去压缩则无法识别对象边界，删去最大分量选择则输出不确定

外观混乱的拉伸网格经重复行列压缩后还原出多个对象，提取其中面积最大的连通分量。

**输入结构**：约 18x18 至 22x22 的矩形网格。网格表面看起来没有明显结构——多种颜色的像素分布其中，但没有清晰的对象边界。实际上该网格是一个约 7x7 至 9x9 的小网格经行列不均匀拉伸生成的：每行被复制了 1-4 次（相邻的 1-4 行完全相同），每列被复制了 1-4 次（相邻的 1-4 列完全相同），且不同行/列的拉伸倍数不同。小网格的内容为：黑(0)背景上有一个面积最大（8-15 像素）的单色 4-连通前景对象（颜色随示例变化），以及 2-4 个较小的干扰分量（各 1-3 像素，颜色各异，可与最大对象同色或异色，但每个分量面积严格小于最大对象）。生成约束：最大对象的面积严格大于第二大对象面积的两倍；拉伸倍数不超过 4。

**规则**：
1. 从上到下扫描行：若当前行与紧接的下一行完全相同（每列像素颜色一致），标记下一行为重复行。保留每组连续相同行中的第一行，删除其余重复行。
2. 从左到右扫描列：若当前列与紧接的右侧列完全相同（每行像素颜色一致），标记右侧列为重复列。保留每组连续相同列中的第一列，删除其余重复列。
3. 取保留的行与列的交集，得到压缩后的小网格。
4. 在压缩后的小网格中，确定背景色为出现次数最多的颜色。
5. 找出所有非背景色的 4-连通单色连通分量，选择像素数量最大的唯一分量。
6. 输出该分量的最小包围框（矩形裁剪），框内保留该分量的像素和背景色像素（保留内部孔洞），其余颜色的像素替换为背景色。

**关键洞察**：原始网格不是简单的噪声——它是一幅有意义图像的拉伸版本。不同行列的拉伸倍数不同，因此简单的等比缩放或下采样无法还原；必须检测相邻完全相同的行/列向量并合并。压缩后才能识别出原始对象边界，进而提取最大分量。

2. `generate_input()` 必须随机生成多样样例，不能固定死。随机维度应覆盖：网格大小、对象数量、位置、颜色、方向、形状参数或关键分支。注意若描述中存在若干，需实现而不是只有单个，包括object或者对应关系等等。且若涉及到最短路径，则输入网格中必涉及到多条路径，对选择造成干扰。
