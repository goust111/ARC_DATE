## 新题 8：相邻区域标记色交换填充

**组合逻辑**：[洪泛填充(flood_fill) + 封闭区域(enclosed_region)](已有) + [四邻接配对(four_neighbor_pairing)](创新：配对单位从像素升级为区域，通过共享边判定邻接) + [颜色匹配(color_matching)](创新：同色标记不配对，异色标记才配对并交换) → [填充(fill)](颜色由配对关系决定)

**来源原语**：四邻接配对、配对则变色擦除(d90796e8)；洪泛填充、位置排序、封闭区域(941d9a10)；颜色匹配(17829a00)；填充(dbff022c/db7260a4)

**依赖链**：灰色分隔线定义区域边界 → 区域邻接关系构建图结构 → 标记像素颜色 + 邻接关系决定配对 → 配对关系决定填充模式（交换 vs 自填）。区域几何结构（邻接）与标记颜色（属性）共同决定输出，单独知道任一方面都不够。

灰色线划分出多个封闭区域，部分区域含彩色标记像素；相邻区域中不同色标记互相交换颜色来填充对方区域，孤立标记用自身颜色填充所在区域。

**输入结构**：约 14x14 的黑(0)背景网格。灰(5)线段（宽 1 像素的水平和垂直线段，不一定贯穿全网格）将网格划分为 4~7 个不规则封闭区域（每个区域为 4-连通的黑像素连通块，被灰线和/或网格边界完全包围）。其中 3~5 个区域各含恰好一个彩色标记像素（颜色从红(2)、蓝(1)、绿(3)、黄(4)中选取），其余区域无标记（纯黑）。生成约束：至少存在一对相邻区域（共享至少一段灰色边界线）各含不同色标记（确保交换发生）；至少存在一个含标记的区域，其所有相邻的含标记区域的标记色都与自身相同或该区域无相邻含标记区域（确保自填发生）。每个标记像素不在灰线上、不在网格边界行/列上。不同示例中区域拓扑和标记颜色分配不同。

**规则**：
1. 识别灰(5)分隔线，通过洪泛填充找到所有黑(0)连通区域（4-连通）。
2. 建立区域邻接图：若两个区域之间存在一段灰(5)像素使得一侧为区域 A 的像素、另一侧为区域 B 的像素（灰像素的 4-邻居分别属于两个区域），则 A 和 B 邻接。
3. 对每个含标记像素的区域，在其邻接区域中寻找含**不同颜色**标记的区域：
   a. 若找到恰好一个：两个区域构成"交换对"。
   b. 若找到多个：选择标记像素与自身标记像素欧氏距离最近的那个作为配对对象（唯一配对）。每个区域最多参与一个交换对。配对按标记像素行坐标从小到大、行相同则列坐标从小到大的顺序贪心匹配（先匹配的优先）。
   c. 若找不到（所有邻接含标记区域都与自身同色，或无邻接含标记区域）：该区域为"孤立标记"。
4. 对每个交换对 (A, B)：用 B 的标记颜色洪泛填充区域 A（覆盖所有黑像素，包括 A 自身的标记像素位置），用 A 的标记颜色洪泛填充区域 B。
5. 对每个孤立标记区域：用自身标记颜色洪泛填充该区域。
6. 无标记的区域保持黑(0)不变。
7. 灰(5)分隔线保持不变。

**关键洞察**：标记像素之间通过共享灰色墙壁"握手"——异色邻接标记交换颜色来填充对方领地，而同色邻接或无邻接的标记只能用自己的颜色。仅看填充结果无法区分"交换"与"自填"，必须对比包含两种情况的示例才能发现配对交换机制。

Decode a block-grid image by swapping each sprite-coded cell with a solid cell and each blank cell with the sprite.

Input structure
The grid is partitioned by black separator rows and columns into equal-size
square blocks. Each block is either a copy of one two-color sprite or a
uniform blank block of the sprite's minority color; grey pixels are erased
cells that act as wildcards.

Rule
Infer the repeated sprite from fully visible mixed-color blocks. Replace a
block matching that sprite, ignoring grey erasures, with a solid block of
the sprite's majority color. Replace a uniform blank block with the sprite.
Separator rows and columns, including grey erasures on them, become black.

Key insight
The small sprite is a block-level code for one macro-cell state, and the
uniform minority-color block is the other state; the output renders the
opposite code in each macro-cell while cleaning erased pixels.

<description>
Rotate each 2x2 block's four diagonal corner colors clockwise, then extend the rotated colors outward as diagonal rays.

Input structure
- The background is the dominant color.
- One foreground color forms one or more solid 2x2 blocks.
- Each block has four non-background, non-block corner pixels diagonally adjacent to it.

Rule
- Around every block, move the NW corner color to NE, NE to SE, SE to SW, and SW to NW.
- From each rotated corner, paint along the outward diagonal until the grid edge or another 2x2 block is reached.
- If a ray reaches a same-colored outgoing corner of another block that has its own visible continuation, stop the incoming ray at that junction.

Key insight
- The 2x2 blocks are color rotators and ray blockers; the corner pixels are not independent dots but the four ports of each block.
