## 新题 7：空心框排序拼接后标记射线

**组合逻辑**：[仅保留空心对象(hollow_only_retained) + 忽略干扰项(ignore_distractors)](已有) → [排序(sort) + 沿主轴排列(along_main_axis) + 拼接(concatenate)](已有) → [方向指示(direction_indication)](创新：标记像素在框边界上的位置编码射线方向) → [射线延伸(ray_extend) + 延伸至边界(extend_to_edge)](创新：射线从拼接后的新位置发射，非原始位置)

**来源原语**：空心矩形、实心方块、仅保留空心对象、忽略干扰项、排序、沿主轴排列、拼接(a680ac02)；射线延伸、延伸至边界(ea786f4a)；方向指示(25d487eb)；标记像素(25d487eb/db7260a4)

**依赖链**：干扰项过滤决定哪些对象参与后续 → 排序+拼接改变对象的绝对位置 → 标记像素在框边上的位置编码方向信息 → 射线从拼接后的新位置出发（非原位置），故必须先完成拼接才能确定射线起点。四步顺序依赖。

过滤掉实心干扰方块后，将空心框按位置排序拼接成条带，再从每个框边界上的橙色标记像素向其指示方向射出射线。

**输入结构**：约 15x20 的黑(0)背景网格。散布 3~5 个 4x4 空心矩形框（各边 1 像素宽的边框、内部 2x2 为黑(0)空腔），框体颜色各不相同（从红(2)、蓝(1)、绿(3)、黄(4)中选取）。另有 1~2 个 4x4 灰(5)实心方块作为干扰项。每个空心框的外边界上恰好有一个像素被替换为橙(7)（标记像素），标记像素位于框的上、下、左或右边的中间位置。生成约束：空心框的位置在列方向上的跨度大于行方向（保证水平拼接）或反之（保证垂直拼接），不同示例方向不同；各对象互不重叠且间距 >= 2 像素。

**规则**：
1. 识别并丢弃所有实心方块（灰(5)干扰项），仅保留空心矩形框。
2. 计算所有空心框的位置分布：若框的列坐标跨度 > 行坐标跨度，按各框边界框左上角的列坐标从小到大排序（列相同则行小优先），拼接方向为水平；反之按行坐标排序，拼接方向为垂直。
3. 将排序后的空心框沿拼接方向依次紧密排列（边与边相邻，无间隙），起始位置为输出网格的 (0,0)。输出网格大小 = 拼接后条带的边界框大小加上射线延伸所需的空间（在拼接方向上等于条带长度，在垂直方向上等于网格对应维度取 max(条带宽度+10, 原网格该维度)，上限为 30）。
4. 对每个拼接后的空心框，定位其橙(7)标记像素在框边界上的位置：
   - 标记在框的顶边 → 射线方向为向上。
   - 标记在框的底边 → 射线方向为向下。
   - 标记在框的左边 → 射线方向为向左。
   - 标记在框的右边 → 射线方向为向右。
5. 从标记像素的拼接后坐标出发，沿射线方向逐格绘制橙(7)像素，直到到达输出网格边界（含边界行/列本身）。射线覆盖路径上的黑(0)像素；若遇到另一个框的非黑像素，射线停止于该像素的前一格（不覆盖框体）。
6. 框体内部空腔和框体像素（含橙标记像素本身）保持不变。

**关键洞察**：标记像素的信息在排序拼接前后发生了语义迁移——在原始网格中它标记方向，在拼接后的条带中它成为射线的发射点。必须对比多个示例才能确认：(a) 实心块被丢弃、(b) 标记位置编码方向、(c) 射线从拼接后位置而非原始位置出发。
