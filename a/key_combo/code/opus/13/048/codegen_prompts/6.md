## 新题 6：交替打孔后连通分裂的条件重涂

**组合逻辑**：[中线交替打孔/alternating_holes_on_center](已有) + [连通性/connectivity](创新：打孔后的拓扑变化成为分类依据) + [重涂色/recolor](创新：重涂颜色由分裂产生的分量数决定) + [擦除/erase](已有) + [面积大于一则涂/recolor_if_area_gt_one](创新：面积阈值用于过滤碎片)

**来源原语**：中线交替打孔(3bdb4ada)、交替(3bdb4ada)、矩形(3bdb4ada)、中心线(3bdb4ada)、连通性(e0fb7511)、重涂色(e0fb7511/a09f6c25)、擦除(3bdb4ada)、面积大于一则涂(e0fb7511)

**依赖链**：对每个矩形执行中线交替打孔 -> 检查打孔后每个矩形是否在4-连通意义下分裂 -> 分裂为2个分量的矩形重涂为一种颜色，分裂为3+个分量的重涂为另一种颜色，未分裂的重涂为第三种颜色 -> 面积为1的碎片分量被擦除

对矩形执行交替打孔，根据打孔导致的连通分量分裂数目决定重涂颜色，碎片被擦除。

**输入结构**：黑(0)背景，网格约16x16。包含3~5个灰(5)单色矩形，每个矩形短边长度为3，长边为奇数（5~11），可以水平或垂直放置。矩形之间互不相邻（边界框间距至少2像素）。生成约束：打孔后至少出现"未分裂""分裂为2""分裂为3+"三种情况各一次（通过控制矩形长度实现——长度5打孔后可能分裂为2段，长度9以上可能分裂为3+段，长度5且打孔位置特殊可能不分裂）。

**规则**：
1. 对每个灰(5)矩形，沿其长轴方向的中线（短边方向的中间行或列），从距端点1像素处开始，每隔一个像素设为黑(0)（交替打孔）。
2. 打孔完成后，对每个原矩形区域内剩余的灰(5)像素做4-连通分量分析，计算连通分量数目C。
3. 面积为1的连通分量（单像素碎片）擦除为黑(0)，不计入C。
4. 根据有效分量数C重涂：C=1（未分裂）-> 所有有效分量像素重涂为蓝(1)；C=2 -> 重涂为红(2)；C>=3 -> 重涂为绿(3)。
5. 输出网格尺寸与输入相同，背景保持黑(0)。

**关键洞察**：交替打孔是一个确定性的几何操作，但它对不同长度的矩形产生不同的拓扑效果——长矩形被切成更多段，短矩形可能保持连通；求解者必须先执行打孔操作，再分析拓扑结果来确定颜色，不能跳过任何一步。
