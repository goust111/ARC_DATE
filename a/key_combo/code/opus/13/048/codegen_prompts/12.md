## 新题 12：尺寸匹配印章与连通性过滤的联合约束

**组合逻辑**：[尺寸匹配/size_matching](已有) + [印章覆盖/stamp_overlay](创新：印章前需要通过连通性检测筛选合格模板) + [连通性/connectivity](创新：作为印章资格的过滤条件) + [面积大于一则涂/recolor_if_area_gt_one](创新：面积条件用于排除碎片化模板) + [纯色矩形/solid_rectangle](已有) + [多色模板/multicolor_template](已有)

**来源原语**：尺寸匹配(e76a88a6)、同尺寸替换(e76a88a6)、印章覆盖(e76a88a6)、多色模板(e76a88a6)、纯色矩形(e76a88a6)、连通性(e0fb7511)、面积大于一则涂(e0fb7511)、重涂色(e0fb7511)

**依赖链**：识别所有多色模板和灰色目标矩形 -> 按尺寸匹配候选模板与目标矩形 -> 对每个候选模板做连通性分析 -> 仅当模板中最大连通分量的面积超过模板总面积一半时，该模板合格 -> 合格模板印章到匹配尺寸的目标矩形 -> 不合格模板对应的目标矩形填充为红色警示

识别尺寸匹配的模板和目标矩形，但只有连通性良好的模板才能被印章复制到目标位置，碎片化模板的目标填红色。

**输入结构**：黑(0)背景，网格约18x18。包含3~4个矩形区域作为"模板"，每个模板是一个HxW的边界框内由2~3种非黑非灰颜色绘制的图案（可能连通也可能碎片化）。另有3~4个灰(5)实心矩形作为"目标"，其中每个目标的尺寸(H,W)恰好与某个模板的边界框尺寸匹配。生成约束：每种尺寸至多出现一对（一个模板+一个目标）；部分模板的非黑像素构成一个主体连通分量（面积>总面积的50%），部分模板的非黑像素碎片化为多个小分量（无一分量面积>50%）。

**规则**：
1. 识别所有非灰(5)的多色矩形区域作为模板，记录其边界框尺寸(H,W)。
2. 识别所有灰(5)实心矩形作为目标，记录其尺寸。
3. 按尺寸将模板与目标一一匹配（相同H和W）。
4. 对每个模板，分析其边界框内所有非黑像素的4-连通分量。找出面积最大的分量，计算其面积是否超过模板内所有非黑像素总面积的50%。
5. 若超过50%（模板合格）：将该模板完整复制到匹配的灰色目标位置，替换灰色像素。
6. 若不超过50%（模板不合格/碎片化）：将匹配的灰色目标矩形整体填充为红(2)。
7. 所有原始模板和背景保持不变。

**关键洞察**：尺寸匹配是必要条件但不充分——模板还必须通过连通性质量检测才能被采用；碎片化的模板虽然尺寸正确，但在逻辑上被判定为"损坏"而拒绝复制，其目标矩形变红作为"警报"信号。
