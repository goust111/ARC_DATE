## 新题 9：查表结果参数化对角印章

**组合逻辑**：[查表匹配/table_lookup](创新：查表结果不是布尔判定，而是提取行列坐标作为参数) + [对角偏移重复/diag_offset_repeat](创新：重复次数和方向由查表坐标决定) + [印章覆盖/stamp](已有) + [裁剪/clip](已有) + [字形单元格/glyph_cell](已有)

**来源原语**：查表匹配(d8e07eb2)、字形单元格(d8e07eb2)、参考表(d8e07eb2)、对角偏移重复(e619ca6e)、印章覆盖(e619ca6e)、裁剪(e619ca6e)、尺寸决定步幅(e619ca6e)、实心矩形(e619ca6e)

**依赖链**：在每个实心矩形内部识别小字形标记 -> 在参考表中查找该字形的行列位置 -> 行索引决定对角印章方向（向左下 vs 向右下） -> 列索引决定印章重复次数 -> 以矩形自身尺寸为步幅执行对角印章 -> 超出网格的部分裁剪

每个矩形内嵌的字形标记在参考表中定位，行索引决定对角复制方向，列索引决定复制次数。

**输入结构**：黑(0)背景，网格约20x20。上方区域（行0~6）是一个青(8)背景的参考表，由灰(5)单像素分隔线划分为RxC个单元格（R=2行，C=3~4列），每个单元格内有一个由某种非青非灰非黑颜色绘制的3x3小字形图案（颜色和形状的组合唯一标识每个字形）。下方区域（行8~19）黑(0)背景上有2~4个不同颜色的实心矩形（高2~3、宽2~4像素），每个矩形内部恰好有一个1像素的标记，标记的颜色和位置编码了一个3x3字形的特征色（即标记颜色与参考表中某个字形的绘制颜色相同）。生成约束：每个矩形内标记颜色在参考表中恰好匹配一个字形；参考表第1行的字形对应方向为右下，第2行对应左下。

**规则**：
1. 解析参考表：识别分隔线位置，提取每个单元格中的字形及其绘制颜色，记录字形在表中的行号r（0或1）和列号c（0起始）。
2. 对下方每个实心矩形，提取其内部标记像素的颜色，在参考表中找到使用该颜色的唯一字形，获取其(r, c)。
3. 方向由r决定：r=0时方向为右下（偏移为(+h, +w)），r=1时方向为左下（偏移为(+h, -w)），其中h和w分别是该矩形的高度和宽度。
4. 重复次数为c+1（列索引0对应1次额外复制，列索引1对应2次，以此类推）。
5. 保留原始矩形，沿确定的方向以(h, w)为步幅印章该矩形c+1次。超出网格边界的部分裁剪丢弃。
6. 多个矩形的印章区域重叠时，面积较小的矩形覆盖面积较大的。

**关键洞察**：参考表不是用于是/否判定（如参考题中的行列对齐检测），而是一个二维参数编码器——字形的表内位置被解码为两个独立参数（方向和次数），分别控制印章操作的不同维度。
