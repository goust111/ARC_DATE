## 新题 8：滑动对象匹配孔洞形状停靠

**组合逻辑**：[滑动/slide](创新：停止条件从碰撞变为形状匹配) + [形状对应/shape_correspondence](创新：形状匹配触发嵌入而非仅对齐) + [碰撞停止/collision_stop](创新：未匹配对象碰壁后消失) + [封闭孔洞/enclosed_hole](已有) + [近者优先不重叠/nearest_first](已有)

**来源原语**：滑动(f0100645)、碰撞停止(f0100645)、近者优先(f0100645)、形状对应(93b4f4b3)、封闭孔洞(93b4f4b3)、模板(93b4f4b3)、填充(93b4f4b3)

**依赖链**：识别模板中的孔洞和散落的可移动对象 -> 所有对象向模板方向滑动 -> 对象到达模板边界时检查是否有形状匹配的孔洞在正前方 -> 匹配成功则嵌入孔洞（用对象颜色填充） -> 不匹配则继续滑动直到碰壁消失 -> 近距离优先处理避免冲突

可移动对象向模板方向滑动，形状与孔洞匹配的对象嵌入孔洞并填色，不匹配的对象滑出网格消失。

**输入结构**：黑(0)背景，网格约16x12。左侧（列0~5）有一个橙(7)连通模板，模板内有2~3个被橙(7)完全包围的黑(0)孔洞（每个孔洞3~5像素，4-连通不规则形状）。右侧（列7~15）散布4~5个彩色小对象（每个对象一种颜色，从红(2)、绿(3)、蓝(1)、黄(4)、品红(6)中选取，每个对象3~5像素，4-连通不规则形状），其中恰好2~3个对象的归一化掩码与某个孔洞的归一化掩码相同（无需旋转），其余对象的形状与任何孔洞都不匹配。生成约束：每个孔洞至多被一个对象匹配；匹配对象的行范围与对应孔洞有重叠（保证水平滑动时能正确对齐）。

**规则**：
1. 提取左侧模板中所有黑(0)孔洞区域，将每个孔洞掩码归一化到其边界框。
2. 提取右侧所有彩色对象，将每个对象掩码归一化到其边界框。
3. 按对象到模板右边界的水平距离从近到远排序，依次处理每个对象。
4. 对象向左水平滑动。滑动时，对象保持其形状和垂直位置不变，每步左移一列。
5. 当对象的边界框左边缘接触模板区域时，检查对象正前方（左方）是否存在一个孔洞，使得对象的归一化掩码与该孔洞的归一化掩码完全一致，且对象的边界框顶行与孔洞的边界框顶行对齐。若匹配成功，用对象颜色填充该孔洞，对象从原位置消失。
6. 若不匹配任何孔洞，对象继续左滑直到完全移出网格左边界，从输出中消失。
7. 输出仅保留左侧模板区域（列0~模板右边界），橙(7)不变，被填充的孔洞使用对应对象颜色，未被填充的孔洞保持黑(0)。

**关键洞察**：滑动机制中的"停止"不再是简单的物理碰撞，而是几何形状的识别匹配——对象像钥匙一样寻找锁孔，只有形状吻合才会停下并嵌入，这将空间运动与形状识别耦合为一个不可分割的判断。
