## 新题 5：标记侧镜像扩展后内部涂色并组装风车

**组合逻辑**：[镜像](标记像素指示翻转轴) → [重涂色](合并形状的内外分离) → [旋转+拼接](四旋转风车拼贴)

**来源原语**：镜像+前景对象+标记像素+邻接+标记侧翻转且变色（2bcee788）；重涂色+前景矩形+矩形内部+内外分离+保留边框涂内部（50cb2852）；旋转+拼接+正方形画布+阵列排布+四旋转组成风车（7fe24cdd）

**依赖链**：标记位置 → 决定镜像轴 → 改变合并形状的轮廓 → 轮廓决定哪些像素是"内部" → 内部涂色后的画面被旋转成四象限 → 标记位置的微小变化在四个象限中被放大

红色标记指示镜像方向，将矩形沿该方向镜像翻转后为合并形状的内部涂色，最终组装成 2x2 风车拼贴。

**输入结构**：正方形网格，边长 N（7 <= N <= 10）。黑(0)背景。一个蓝(1)实心矩形（宽和高各至少 3，且宽 != 高），位于网格中不贴边的位置。一个红(2)单像素标记，与矩形的某一条边 4-邻接（只贴一条边）。生成约束：矩形加上其镜像后的合并形状完全在网格内；合并形状在两个维度上都至少 3 像素（以保证存在内部像素）。

**规则**：
1. 确定红(2)标记贴在矩形的哪条边。以该边为镜像轴，将整个矩形翻转一次。翻转副本与原矩形共享该边。红像素被翻转副本覆盖。
2. 合并原矩形和翻转副本为一个组合形状。计算组合形状的 1 像素内缩边界：将不在最外层边框上的所有内部像素重涂为青(8)，边框像素保持蓝(1)。
3. 将处理后的正方形网格作为基础瓦片，构建 2x2 风车拼贴输出：左上 = 基础瓦片原样，右上 = 顺时针 90° 旋转，左下 = 逆时针 90° 旋转，右下 = 180° 旋转。

**关键洞察**：红色标记在输出中完全不出现——它仅指示镜像方向，但其位置决定了合并形状的轮廓，进而决定了青色内部区域的形态，该形态在四个风车象限中以四种旋转呈现。

1. `main(grid)` 必须实现新题描述中的确定性转换规则，不能只识别 `generate_input()` 的固定模板。禁止不同的input网格输出相同的output网格。
2. `generate_input()` 必须随机生成多样样例，不能固定死。随机维度应覆盖：网格大小、对象数量、位置、颜色、方向、形状参数或关键分支。注意若描述中存在若干，需实现而不是只有单个，包括object或者对应关系等等。且若涉及到最短路径，则输入网格中必涉及到多条路径，对选择造成干扰。

6. 若规则有多个分支，生成器不能长期固定成一个分支；应让分支在随机样例中合理出现。分支概率不必平均——难以发现的隐蔽分支（如少数情况下才触发的特殊规则）应适当提高出现概率，确保在 3 个训练示例中至少出现一次，否则求解者无法归纳该规则。对于颜色映射类规则，确保 2 个左右的示例即可覆盖所有映射关系（每种颜色→颜色的映射至少在某个示例中出现过）。
