## 新题 6：逐行异常值提取后条纹对齐到中位基准

**组合逻辑**：[提取](逐行异常值选择) → [裁剪](提取条纹几何特征) → [对齐+裁剪](以中位条纹为参考归一化)

**来源原语**：提取+裁剪+网格单元+精灵体+逐行比较+异常值选择（38007db0）；对齐+裁剪+线段+平行共向+中位线为参考（e376de54）

**依赖链**：异常值检测决定哪些单元被选中 → 选中单元的内部条纹属性（长度、垂直位移）各不相同 → 中位条纹被选为参考 → 所有条纹对齐到中位参考的位置和长度。跳过异常值检测则无从获得条纹；跳过对齐则条纹参差不齐。

从网格每行中找出异常单元，提取其中的水平条纹，然后以中位条纹为基准对齐所有条纹的位置和长度。

**输入结构**：网格被品红(6)色分隔线划分为 MxN 的等大矩形单元（M 行 N 列，M 在 3~5 之间，N 在 3~5 之间），分隔线宽 1 像素。单元内部背景为黑(0)。每行 N 个单元中有 N-1 个共享完全相同的内部精灵图案，1 个是异常值——其内部图案与同行其他单元不同。每个异常值单元包含一条水平彩色条纹（1 像素高，长度 2~6 像素的连续同色水平段），颜色取自蓝(1)、绿(3)、黄(4)、红(2)，且不同行的异常值条纹颜色互不相同。不同行异常值的条纹长度和在单元内的垂直位置（距单元顶部的行偏移）各不相同。生成约束：M >= 3 以保证中位数唯一（M 为奇数）。

**规则**：
1. 对每行单元，逐对比较内部图案，找出出现恰好 1 次的异常值单元。
2. 从每个异常值单元中提取水平条纹：记录其颜色、像素长度 L、以及条纹在单元内的垂直偏移 V（从单元内部顶部第 0 行起计）。
3. 将所有提取的条纹按垂直偏移 V 排序，取中位条纹（第 ceil(M/2) 个）作为参考，记其垂直偏移为 V_ref、长度为 L_ref。
4. 对每条条纹，将其垂直偏移调整为 V_ref（上下平移），长度调整为 L_ref（从左端起保留 L_ref 像素；若原长度 < L_ref 则向右用同色延伸）。
5. 构建输出：单列网格（1 列 M 行），每个单元大小与原输入单元相同，用品红(6)分隔线分隔。每行放入对齐后的条纹，保持原条纹颜色。

**关键洞察**：参考基准不是最长或最短的条纹，而是按垂直偏移排序后的中位值——必须提取所有异常值后才能确定参考，然后才能执行对齐。
