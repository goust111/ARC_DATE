## 新题 1：噪点修复后按面积排列为同心框

**组合逻辑**：[擦除/重涂色](邻接判定归并或删除) → [排序](按修复后边长降序) → [同心层填充](居中嵌套绘制)

**来源原语**：擦除+重涂色+邻接+merge_or_delete（7e0986d6）；排序+同心层填充+嵌套层次+descending_side_order（c658a4bd）；矩形+noise_pixel（7e0986d6）；concentric_layer（c658a4bd）

**依赖链**：噪点归并改变矩形边界框 → 修复后的边长决定同心嵌套顺序 → 嵌套顺序决定输出着色

将散布噪点的多个彩色矩形经邻接清洗后，按修复边长重建为居中同心正方形框。

**输入结构**：黑(0)背景网格，约 18x18。3~4 个互不相邻的实心单色矩形（每个至少 3x3），颜色各不相同，取自蓝(1)、绿(3)、黄(4)、品红(6)。橙(7)噪点以 1~3 像素的小簇散布于矩形表面及附近（每个噪点连通分量面积不超过 3）。生成约束：不同矩形的边界框互不相交（间距 >= 2），保证噪点归并后各矩形仍是矩形形状；每个矩形至少有 1 个噪点簇与之 4-邻接。

**规则**：
1. 识别所有橙(7)色 4-连通分量（面积 <= 3 的为噪点）。
2. 对每个噪点像素，统计其 4-邻居中属于矩形颜色的像素数。若 >= 2，将该噪点像素重涂为其中占多数的矩形颜色（若数量相同，取该噪点所在行上首先遇到的矩形颜色）；若 < 2，擦除为黑(0)。
3. 归并完成后，对每种矩形颜色计算其所有同色像素的边界框的较长边边长，记为该颜色的 side。
4. 创建正方形输出，边长等于所有颜色中最大的 side。
5. 按 side 从大到小排序。从最大开始，逐一在输出中央绘制对应颜色的正方形边框（1 像素厚），边长等于该颜色的 side。后绘制的覆盖先绘制的。最内层框的内部（若有）填充为最内层颜色。

**关键洞察**：噪点归并不只是清理——它改变了矩形的有效尺寸，直接影响同心嵌套的层序。仅凭清理前的边长无法得出正确排列。
