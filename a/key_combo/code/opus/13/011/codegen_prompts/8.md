## 新题 8：重叠碎片帧的噪点归属决定遮挡优先级与内层填充

**组合逻辑**：[擦除/重涂色](噪点邻接判定) ⟂ [排序](修复后边长定层序) → [同心层填充+洪泛填充](按优先级叠绘并填充最内层)——噪点归属同时影响帧边长和遮挡关系，形成隐式双重约束

**来源原语**：擦除+重涂色+矩形+噪点+邻接+merge_or_delete（7e0986d6）；排序+同心层填充+碎片帧+嵌套层次+descending_side_order（c658a4bd）；洪泛填充（4e469f39）；内外分离（50cb2852）

**依赖链**：噪点归属改变帧的有效边长 → 边长改变遮挡优先级（小帧在上）→ 优先级改变重叠处的可见颜色 → 最内层帧的身份取决于修复后谁最小 → 该帧内部被洪泛填充。噪点既影响几何尺寸又影响视觉层次，两条约束必须同时满足。

多个彩色正方形边框相互重叠且受噪点干扰，清除噪点后按修复边长确定遮挡顺序居中重绘，最内层框内部填充。

**输入结构**：黑(0)背景网格，约 16x16。3~4 个不同颜色的正方形边框（1 像素厚），颜色取自蓝(1)、绿(3)、黄(4)、品红(6)。边框大小各不相同（边长 4~12），中心点接近但不完全相同，因此部分边框像素相互重叠（重叠处仅显示一种颜色，具体哪种是输入的给定事实）。橙(7)噪点像素（单个或 2 像素簇）散布在边框上和边框附近。生成约束：每种颜色的边框像素（含被遮挡的隐藏像素）加上归属该颜色的噪点像素后，边界框为正方形；不同颜色修复后的边长互不相同。

**规则**：
1. 识别橙(7)噪点（4-连通分量面积 <= 2）。对每个噪点像素统计其 4-邻居中各边框颜色的数量。若总边框色邻居 >= 2，将噪点重涂为最多邻居对应的边框颜色（平局时取行号更小的邻居的颜色）；否则擦除为黑(0)。
2. 修复后，对每种边框颜色，计算其所有同色像素边界框的边长（应为正方形，取较大维度）。
3. 确定遮挡优先级：边长越小，优先级越高（画在最上层）。
4. 构建输出：以最大边长为输出网格边长。以输出中心为公共中心，从最大帧（最低优先级）到最小帧（最高优先级）依次绘制正方形边框，每帧颜色不变，后绘制的覆盖先绘制的。
5. 最内层（最小）帧的内部（边框以内的区域）用该帧颜色洪泛填充。

**关键洞察**：噪点归属同时改变两件事——帧的有效边长和哪个帧成为最内层被填充对象。一个噪点归入错误的帧会同时扭曲层序和填充目标，两条信息必须一致。
