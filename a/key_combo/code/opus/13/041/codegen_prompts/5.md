## 新题 5：镜像平铺后按角标像素分象限重涂色

**组合逻辑**：[镜像(mirror) + 平铺(tiling) → 四象限排布(four_quadrant_layout)] + [角标像素(corner_pixel) + 象限归属(quadrant_member) → 重涂色(recolor)]

**来源原语**：镜像(mirror)、平铺(tiling)、四象限排布(four_quadrant_layout)、画布(canvas)、翻转形成对称铺展(mirror_symmetric_expand) 来自 62c24649；角标像素(corner_pixel)、象限(quadrant)、象限归属(quadrant_member)、角标色定象限涂色(corner_sets_quadrant)、裁剪(crop)、重涂色(recolor) 来自 77fdfe62

**依赖链**：四个角标像素标记了各象限的"替代色" → 先移除角标像素并将图案镜像展开为四象限 → 在每个象限中，将图案内的特定颜色（所有象限共用同一个"可替换色"，即输入中非背景、非角标的出现频率最高的颜色）替换为该象限对应的角标色。镜像创建了空间结构，角标定义了该结构内的颜色差异——两者缺一不可。

将输入小网格镜像展开为四象限对称图案，再按四个角标像素的颜色分别重涂每个象限中的主前景色。

**输入结构**：约 6x6 的网格（不含角标时为 4x4 的有效图案区）。四个角落像素（(0,0)、(0,W-1)、(H-1,0)、(H-1,W-1)）各为一个不同的单色标记，颜色从黄(4)、品红(6)、橙(7)、青(8) 中选取四种。其余区域在黑(0)背景上绘有一个多色图案，使用 2~3 种非背景色（如红(2)、蓝(1)、绿(3)），其中一种颜色的像素数明显多于其他（该色即"可替换色"）。角标色与图案色完全不重叠。生成约束：图案中可替换色的像素数严格大于任何其他非背景色的像素数，以保证唯一确定。

**规则**：
1. 读取四个角落像素的颜色作为象限图例：左上角色 → 左上象限，右上角色 → 右上象限，左下角色 → 左下象限，右下角色 → 右下象限。
2. 将四个角落像素替换为黑(0)背景，得到清理后的源图案 P（尺寸 HxW）。
3. 识别源图案 P 中的"可替换色"：在所有非背景色中，像素数量最多的那种颜色。
4. 构造 (2H)x(2W) 的输出网格，分四个象限放置 P 的镜像副本：
   - 左上象限：P 原样
   - 右上象限：P 的左右镜像
   - 左下象限：P 的上下镜像
   - 右下象限：P 的上下+左右镜像（等价于 180 度旋转）
5. 在每个象限中，将所有"可替换色"像素替换为该象限对应的角标色。其他颜色（背景和非可替换前景色）保持不变。

**关键洞察**：镜像操作在源题 62c24649 中产生纯对称图案，角标重涂色在源题 77fdfe62 中作用于裁剪后的掩码。此题中镜像和角标重涂同时作用于同一图案——镜像保证了四个象限的几何结构完全对称，但角标重涂打破了颜色对称，使输出呈现"形状对称但颜色分区"的独特视觉效果。必须同时理解两层规则才能得出正确输出。
