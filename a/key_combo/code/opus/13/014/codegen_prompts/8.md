## 新题 8：重叠框架分解与遮挡深度定序重涂色

**组合逻辑**：[counting](创新：计数对象为可见角点，用于推断遮挡关系) + [recolor + conflict_priority](创新：遮挡深度序作为重涂色的排序依据) → 结构解构型

**来源原语**：counting (37d3e8b2, 4852f2fa), recolor (9b5080bb), conflict_priority (1b8318e3), ordering (4364c1c4), connected_component (60b61512), inside_bbox / bounding_box (60b61512, f25fbde4)

**依赖链**：框架边缘像素叠加为单色图案 → 必须通过角点可见性分解出独立框架 → 角点分析确定遮挡深度 → 深度序决定每个框架的颜色。不完成分解就无法知道有几个框架；不确定深度就无法分配颜色。

多个同色空心矩形框重叠为单色图案，根据角点遮挡关系推断深度顺序并按深度重涂色。

**输入结构**：约 14x14 的网格。背景为黑(0)。网格中有 3~4 个灰(5)空心矩形框相互重叠。每个矩形框仅由边框像素组成（1 像素宽边框），内部为黑(0)背景。所有框架统一为灰(5)色，重叠处仅显示一个灰色像素（看不出属于哪个框架）。矩形框的尺寸互不相同（宽和高的组合唯一）。生成约束：每个矩形框至少有一个角点（四角之一）未被其他框架的边缘遮挡（即可见），使得深度排序可唯一确定；任意两个框架不完全包含关系（即一个框架不完全在另一个内部）；框架之间存在 T 形交叉点（一个框架的边终止于另一个框架的边上）。

**规则**：
1. 将所有灰(5)像素视为候选边框像素集合。识别其中所有可能的轴对齐矩形框：枚举所有四角组合 (r1,c1,r2,c2)，验证该矩形的四条边是否全部包含在灰色像素集中（允许与其他框共享像素）。从最大矩形开始贪心匹配，确保每个矩形的尺寸(宽,高)组合唯一。
2. 确定遮挡深度（1 = 最前方）。规则：在 T 形交叉点处（一个框架的边在某处垂直穿过另一个框架的边并终止），被穿过的框架在前方（深度更浅），终止的框架在后方（深度更深）。若框架 A 的边穿过框架 B 的边而终止，则 B 在 A 前方。用所有 T 形交叉点的约束做拓扑排序，得到唯一深度序。
3. 按深度序重涂色：深度 1（最前方）→ 红(2)，深度 2 → 蓝(1)，深度 3 → 绿(3)，深度 4 → 黄(4)。
4. 重涂色时，重叠像素归属前方框架（深度值较小者）。每个框架的所有边框像素（包括与后方框架重叠的像素）涂为该框架的颜色。框架内部的黑色背景保持不变。

**关键洞察**：所有框架都是同一颜色，重叠使得单独的框架结构不可直接观察。求解者必须从 T 形交叉点推断"谁在谁前面"——这是一个空间推理问题，而非简单的属性检测。深度序不是由大小或位置直接决定的，而是由遮挡几何关系决定。
