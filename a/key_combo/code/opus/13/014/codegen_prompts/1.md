## 新题 1：重力落点决定磁吸锚与面板反色

**组合逻辑**：[gravity_drop] → [snap + nearest_frame_assign](创新：重力后的落点位置取代原始位置决定最近锚) → [recolor + opposite_panel_color](创新：反色取自锚所属面板的对侧面板色)

**来源原语**：gravity_drop / cushion_row_gap (825aa9e9), snap / nearest_frame_assign / anchor_block / outer_frame (1b8318e3), recolor / opposite_panel_color / panel_membership (9b5080bb)

**依赖链**：重力改变像素落点 → 落点决定最近锚块 → 锚块所属面板决定反色来源。删除重力步骤则最近锚分配完全不同；删除面板反色则只有位置信息无颜色变换；三环节缺一不可。

将散落的彩色像素先做重力下落，再磁吸到落点附近灰色锚块的外框上，最终按锚块所属面板赋予对侧面板颜色。

**输入结构**：约 15x20 的网格。背景黑(0)。网格被一条垂直的灰(5)分隔线（位于中间列）分成左右两个面板，左面板底色为蓝(1)、右面板底色为红(2)，分隔线仅一列宽。每个面板内有 2~3 个灰(5) 2x2 锚块，锚块不与分隔线相邻，锚块之间曼哈顿距离至少 5。网格上半部散布 4~6 个绿(3)孤立像素（单像素），所有绿像素的初始行号小于所有锚块的最高行号。面板底色仅填充最底部两行（作为地板），其余面板区域为黑(0)背景。生成约束：每个绿像素在重力下落后与其最近锚块的归属必须唯一（不出现等距歧义）。

**规则**：
1. 将所有绿(3)像素在各自所在列内向下移动，直到碰到面板地板行的上方一行（cushion = 1 行）或碰到灰(5)锚块正上方一行时停止（即不落入锚块所在行或其正上方行）。同列有多个绿像素时，下方的先落位，上方的堆叠在其上方。
2. 对每个落位后的绿像素，计算其与每个灰(5) 2x2 锚块的国际象棋距离（king-move distance，即 Chebyshev 距离），选择距离最小的锚块。将该像素移动到该锚块的单格外框（4x4 区域减去 2x2 核心的 12 个格）中离落位点最近的空格上（若最近空格已被占，选次近空格）。
3. 确定每个锚块属于左面板还是右面板（依据锚块中心列与分隔线的位置关系）。左面板的锚块对应对侧色为红(2)；右面板的锚块对应对侧色为蓝(1)。将吸附到该锚块的所有像素重涂为该对侧颜色。
4. 分隔线、面板地板、灰色锚块均保持不变。原始绿像素位置恢复为黑(0)背景。

**关键洞察**：绿像素的最终颜色不由其自身属性决定，而由重力落点间接决定——落点改变了"最近锚块"的归属，而锚块的面板身份又反转了颜色。同一个绿像素在不同的初始列会得到不同的输出颜色。
