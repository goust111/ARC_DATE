## 新题 9：最短路径转弯计数驱动端点区域缩放

**组合逻辑**：[pathfinding + unique_shortest_path](寻路) → [counting](创新：计数对象为路径的转弯次数而非孔洞) → [pixel_scaling + crop](创新：缩放因子由转弯计数编码)

**来源原语**：pathfinding / unique_shortest_path / endpoint_pixel / blocker_pixel / four_neighbor_connect / shortest_path (b15fca0b), counting (37d3e8b2), pixel_scaling / crop / bounding_box / scale_with_gaps (f25fbde4), recolor (9b5080bb)

**依赖链**：最短路径的几何形状决定转弯次数 → 转弯次数编码缩放因子 → 缩放因子应用于端点所在区域的裁剪放大。路径形状是计算中间量，不直接出现在最终输出中。

在迷宫中找两个端点间的最短路径，统计路径转弯次数，以转弯数作为倍率裁剪并放大其中一个端点周围的特征区域。

**输入结构**：约 15x15 的网格。背景为黑(0)。蓝(1)像素组成迷宫墙壁（稀疏分布，形成通道）。恰好两个红(2)端点像素，分别位于网格的不同区域。其中一个端点（称为"目标端点"）周围 3x3 范围内有一个由黄(4)像素组成的小图案（2~4 个黄色像素，形成某种非对称图形）；另一个端点（"起始端点"）周围无黄色像素。生成约束：两端点间存在唯一最短 4-邻接路径（不经过蓝色墙壁）；该最短路径的转弯次数在 2~4 之间（保证缩放因子合理）；目标端点的 3x3 邻域不含蓝色墙壁。

**规则**：
1. 找到两个红(2)端点间的唯一最短 4-邻接路径，蓝(1)像素为不可通行墙壁。路径包含两个端点本身。
2. 将路径上除两个端点外的黑(0)像素涂为灰(5)（标记路径，但端点保持红色）。
3. 统计路径的转弯次数 T：路径中方向改变的位置数量（从水平变为垂直或反之即为一次转弯）。
4. 识别目标端点（周围有黄(4)像素的那个端点）。以目标端点为中心裁剪 3x3 区域。
5. 将该 3x3 裁剪区域做像素放大，倍率 = T（即每个像素变为 TxT 的块）。放大后的区域即为最终输出（输出尺寸为 3T x 3T）。

**关键洞察**：路径本身不是最终输出的主体——它的几何形状（转弯次数）编码了一个数值参数，该参数控制了一个看似无关的缩放操作。求解者需要意识到转弯次数是连接寻路步骤和缩放步骤的桥梁。
