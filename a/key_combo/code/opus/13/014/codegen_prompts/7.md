## 新题 7：孔洞计数双重驱动：重涂色与射线排斥半径

**组合逻辑**：[counting + enclosed_background_region](共享计算) → 并行分支：[recolor + hole_count_to_color_mapping] 与 [ray_extend + obstacle_avoidance + pixel_count_encodes_radius](创新：孔洞数作为排斥半径而非标记像素数)

**来源原语**：counting / enclosed_background_region / foreground_object / hole_count_to_color_mapping (37d3e8b2), ray_extend / obstacle_avoidance / pixel_count_encodes_radius / exclusion_zone / path_start (cb2d8a2c), recolor (9b5080bb)

**依赖链**：孔洞计数同时服务于两个下游任务——(a) 决定对象颜色，(b) 决定对象的排斥半径。重涂色改变了对象的视觉属性，排斥半径改变了射线路径。两个分支共享同一个上游计算，且射线路径必须绕开已重涂色的对象（排斥区大小由孔洞数决定），所以颜色和路径在空间上交互。

对前景对象按内部孔洞数重涂色，同时以孔洞数为排斥半径从边缘种子发射绕障射线。

**输入结构**：约 18x18 的网格。背景为黑(0)。网格中有 4~5 个灰(5) 4-连通前景对象，每个对象是填充矩形（约 3x3 到 5x5），内部挖有 1~3 个黑(0)背景孔洞（每个孔洞为单个黑色像素）。对象之间间距至少 3 格。网格左边缘（第 0 列）有 1~2 个绿(3)种子像素，位于不同行。生成约束：不同对象的孔洞数互不相同（1、2、3 分别出现）；种子像素所在行不与任何对象的行范围重叠。

**规则**：
1. 对每个灰(5)前景对象，计算其包围框内被对象完全围合的黑(0)背景连通分量的数量（即孔洞数 H）。
2. 重涂色：按孔洞数 H 将对象所有灰色像素重涂——H=1 → 蓝(1)，H=2 → 红(2)，H=3 → 橙(7)。孔洞内的黑色像素保持黑色。
3. 每个对象的排斥半径 = H。排斥区为以对象包围框为基础向外 Chebyshev 膨胀 H 格的矩形区域。
4. 从每个绿(3)种子像素出发，向右发射水平射线（涂绿色）。射线前进时必须与所有对象的排斥区保持距离——射线像素不得进入任何排斥区内。若射线被排斥区阻挡，则在阻挡点沿垂直方向（上或下，选择能更快绕过排斥区的方向）绕行，绕过排斥区后恢复水平前进。射线到达网格右边缘终止。
5. 绕行时若上下两个方向等距，选向上。射线路径不得穿过任何非背景像素（重涂色后的对象像素也算阻挡）。种子像素保持绿色。

**关键洞察**：孔洞数是唯一的信息来源，但它同时编码了两个完全不同维度的输出特征——颜色和排斥半径。孔洞多的对象不仅颜色不同，还在空间上对射线产生更大的排斥效应，迫使射线走更远的弯路。
