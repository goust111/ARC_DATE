## 新题 2：重力生成障碍后的分叉射线模拟

**组合逻辑**：[gravity_drop](创新：下落的色块转化为射线障碍) → [ray_extend + branching + collision_generates_side_wakes](创新：障碍集合包含重力生成的新障碍)

**来源原语**：gravity_drop / cushion_row_gap / movable_object (825aa9e9), ray_extend / branching / collision_generates_side_wakes / seed_pixel / obstacle_pixel / row_propagation (79fb03f4)

**依赖链**：重力决定色块落位 → 落位色块成为障碍 → 障碍布局决定射线路径与分叉模式。不执行重力则障碍布局不同，射线路径完全改变；无射线模拟则重力结果无后续变换。

悬浮色块先做重力下落成为固定障碍，然后从左边缘种子像素发射水平射线，遇障碍产生侧翼尾迹与分叉。

**输入结构**：约 18x18 的网格。背景为黑(0)。最左列有 2~3 个绿(3)种子像素（它们固定在最左列的不同行）。网格中散布 3~5 个红(2)固定障碍像素（单像素，位于网格中下部，不在最左列）。网格上半部有 2~4 个橙(7)小色块（每个为 1x2 或 2x1 的连通体），它们悬浮在空中（下方有空间可以下落）。网格最底行为灰(5)地板（整行填充）。生成约束：橙色块下落后不会落到种子像素所在行（不遮挡种子）；下落后至少有一个橙色块恰好落在某个种子像素的射线路径上（确保产生交互）。

**规则**：
1. 所有橙(7)色块在各自所在列内向下做重力下落，直到触碰灰(5)地板上方一行（cushion = 1）或触碰已有障碍/已落位色块的上方一行时停止。下落顺序：行号大的先落位。
2. 落位后的橙(7)像素全部重涂为红(2)，与原有红色障碍像素合并为统一障碍集合。原橙色位置恢复为黑(0)。
3. 从每个绿(3)种子像素出发，向右发射水平射线（涂绿色）。射线传播规则与参考题 79fb03f4 相同：
   - 射线沿行向右逐格涂绿(3)，遇背景则继续。
   - 遇红(2)障碍时停止，障碍像素保持红色不变。在障碍像素的上下各一格、左一格组成的"三格侧翼尾迹"范围内，将可用的背景格涂绿(3)。侧翼尾迹被其他障碍占据则该侧跳过。
   - 若被撞障碍的左上和左下对角格均为红(2)障碍，则当前射线终止，在上下两行各产生一条新的向右全射线（从障碍右侧一格开始）。
4. 灰(5)地板和所有红(2)障碍保持不变。射线到达网格右边界时自然终止。

**关键洞察**：射线路径的分叉模式完全取决于障碍的空间分布，而障碍分布的一部分是由重力下落动态生成的。仅看橙色块的初始位置无法推断射线结果，必须先完成重力模拟。
