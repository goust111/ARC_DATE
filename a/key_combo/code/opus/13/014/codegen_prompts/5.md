## 新题 5：吸引-排斥滑动与标记编码的互斥区

**组合逻辑**：[slide + color_determines_direction + toward_and_away](创新：滑动方向由颜色和分隔线位置共同决定) + [pixel_count_encodes_radius + exclusion_zone](创新：排斥半径编码从射线障碍域转用于滑动停止条件) → 同时约束满足

**来源原语**：slide / color_determines_direction / movable_object (9b4c17c4), toward_and_away / divider_line / color_determines_ray_direction (8d510a79), pixel_count_encodes_radius / exclusion_zone (cb2d8a2c), marker_pixel (b457fec5)

**依赖链**：颜色决定滑动方向（朝向/背离分隔线），标记像素数编码每个对象的排斥半径，滑动距离受其他对象排斥区的约束。方向、距离、约束三者交织为同时满足的约束集，删除任一信息源都无法确定最终位置。

彩色矩形沿水平方向朝向或背离灰色分隔线滑动，但每个矩形携带标记像素编码自身的排斥半径，任何矩形不得进入他者的排斥区。

**输入结构**：约 15x20 的网格。背景为黑(0)。一条垂直灰(5)分隔线位于网格中部（如第 10 列），仅一列宽，贯穿全高。分隔线两侧各有 2~3 个彩色实心矩形（2x2 或 2x3 或 3x2），同侧矩形在不同行、互不重叠。左侧矩形颜色为红(2)，右侧矩形颜色为蓝(1)。每个矩形的正上方紧邻 1~3 个绿(3)标记像素（排成水平行，个数 1~3），标记像素不与任何矩形重叠。生成约束：所有矩形在滑动后不会重叠，也不会越过分隔线；至少有一对矩形的滑动被另一个矩形的排斥区截停（非被分隔线或边界截停）。

**规则**：
1. 每个矩形的排斥半径 = 其正上方绿(3)标记像素的个数。排斥区定义为以矩形包围框为中心、向外扩展排斥半径格的矩形区域（Chebyshev 膨胀）。
2. 红(2)矩形向右滑动（朝向分隔线）；蓝(1)矩形向左滑动（朝向分隔线）。每个矩形的目标位置是包围框紧贴分隔线（但不覆盖分隔线）。
3. 所有矩形同时尝试向目标滑动。若某矩形在滑动过程中其包围框进入了另一个矩形的排斥区（以另一个矩形的最终位置计算），则该矩形停在刚好不进入排斥区的位置。当多个约束冲突时，按矩形离分隔线的初始距离从近到远依次确定最终位置（近者优先占位）。
4. 滑动后矩形保持原色和原形状。绿(3)标记像素不移动，保留在原位。腾出的原矩形位置恢复为黑(0)。分隔线不变。

**关键洞察**：每个矩形的排斥区大小由标记编码，但排斥区约束的是其他矩形的运动而非自身——标记越多的矩形越"排斥"邻居。求解者需同时考虑方向规则和互斥约束，不能逐个独立计算。
