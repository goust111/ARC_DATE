## 新题 3：交替平移后对角连线与触发点分束

**组合逻辑**：[alternating_shift + parity_determines_dir] → [connect + diagonal_alignment](创新：连线的对角对是平移后涌现的，非原始存在) → [trigger_splits_beam](创新：触发点作用于连线而非预设对角线)

**来源原语**：alternating_shift / ordering / parity_determines_dir / mono_foreground_obj (4364c1c4), connect / diagonal_alignment / diagonal_pixel_pair (db695cfb), trigger_splits_beam / trigger_pixel (db695cfb)

**依赖链**：交替平移改变对象位置 → 新位置产生原本不存在的对角对齐 → 对角连线穿过触发点时分束。删除平移则对角关系不同；删除触发分束则连线无后续效应；三步紧耦合。

多个单色对象先按垂直排名交替左右平移，平移后新产生对角对齐关系的对象对被连线，连线经过触发像素处产生垂直分束射线。

**输入结构**：约 16x16 的网格。背景为黑(0)。有 5~7 个蓝(1)单色 4-连通前景对象，每个对象 3~6 像素，形状各异（非特定命名形状），每个对象的包围框顶行互不相同，从而有唯一的从上到下排序。网格中另有 2~4 个品红(6)孤立像素（触发像素），分布在网格中部区域。生成约束：在交替平移（奇数排名左移 1 列、偶数排名右移 1 列）之后，恰好有 2~3 对蓝色对象的质心落在同一条 45 度或 135 度对角线上（平移前不在同一对角线上）；至少有一条对角连线经过某个品红像素。

**规则**：
1. 按包围框顶行从小到大排序所有蓝(1)对象，排名从 1 开始。奇数排名的对象整体左移 1 列，偶数排名的对象整体右移 1 列。移出网格边界的像素丢弃。腾出的原始位置恢复为黑(0)。
2. 在平移后的位置上，计算每个蓝色对象的质心（像素坐标平均值，取整到最近整数）。若两个对象的质心行差的绝对值等于质心列差的绝对值（即在同一 45 度或 135 度对角线上），则称它们"对角对齐"。
3. 对每对对角对齐的对象，用绿(3)画一条从一个质心到另一个质心的对角线段（逐格走 45 度方向）。若线段经过蓝(1)像素，该蓝色像素保持不变（绿色不覆盖蓝色）。若线段经过品红(6)触发像素，触发像素保持品红色。
4. 对每个被对角连线穿过的品红(6)触发像素，从该像素出发沿连线的垂直方向（即旋转 90 度的对角方向）向两侧发射品红(6)射线，射线延伸至网格边界。射线经过黑(0)背景格时涂品红(6)；遇到任何非背景像素时停止（不覆盖、不穿透）。
5. 未被任何对角连线穿过的品红(6)触发像素保持原位不变，不产生射线。

**关键洞察**：对角对齐关系是交替平移后涌现的几何结构——平移前这些对象不在同一对角线上。求解者必须先推断出平移规则（奇偶→方向），才能确定哪些对象会产生连线，进而确定哪些触发像素会分束。
