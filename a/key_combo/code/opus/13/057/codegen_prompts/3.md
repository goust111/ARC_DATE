## 新题 3：碎片合并后按面积分支处理

**组合逻辑**：[补全/合并对齐碎片](已有) + [掏空](创新：仅对面积达标的合并矩形执行) + [重涂色](创新：仅对面积不达标的合并矩形执行) → 面积阈值驱动操作分支

**来源原语**：补全(complete)、合并对齐碎片(merge_aligned_fragments)、残缺矩形(fragmented_rectangle)、连通分量(connected_component)、行列跨度重叠(span_overlap) ← #10 8fbca751；掏空(hollowing)、保留边擦除内部(keep_border_erase_interior) ← #7 4347f46a；重涂色(recolor) ← #4 36fdfd69

**依赖链**：碎片合并确定每个完整矩形的边界 → 矩形面积（行数 x 列数）作为分支判断依据 → 面积 >= 9 的矩形执行掏空（边框保留原色，内部涂黄(4)） → 面积 < 9 的矩形整体填充为红(2) → 两种后续操作使用不同颜色，且掏空操作本身要求矩形足够大才有"内部"可掏

将分散的前景碎片按行列跨度重叠规则合并为完整矩形后，大矩形掏空为黄(4)内腔边框，小矩形整体填充为红(2)。

**输入结构**：
- 黑(0)背景网格，约 15x15。
- 前景为 teal(8) 像素，分布为若干不规则碎片（每个碎片是 4-连通的 teal 像素团，3~8 像素不等）。
- 碎片属于 3~5 个不同的"隐含矩形"：同一矩形的碎片分布在该矩形边界框的角落或边缘附近，碎片之间可能不 4-连通但边界框在行跨度或列跨度上重叠。
- 不同矩形的碎片边界框在行跨度和列跨度上均不重叠（即可通过传递合并完全区分不同矩形）。
- 生成约束：合并后的矩形中至少有一个面积 >= 9（即至少 3x3），至少有一个面积 < 9（如 2x3 = 6）。所有矩形面积不等，以避免歧义。

**规则**：
1. 找到所有 4-连通的 teal(8) 碎片。
2. 传递合并边界框在行跨度或列跨度上有重叠的碎片组（与参考题 #10 相同的合并逻辑）。
3. 对每个合并组，计算其包含边界框的面积 S = 高 x 宽。
4. 若 S >= 9：
   - 将边界框的 1 像素厚边框涂为 teal(8)（保留原色）。
   - 将严格内部全部涂为黄(4)。
5. 若 S < 9：
   - 将边界框内所有像素（含边框）涂为红(2)。
6. 边界框外的黑(0)背景不变。

**关键洞察**：同样的合并逻辑产生的矩形，因面积不同而走向完全不同的处理分支。面积阈值 9 本身需要从多个示例中归纳（观察哪些矩形被掏空、哪些被填实），而不能仅从单一示例确定。

Input structure

- Each marker has exactly one background 4-neighbor, the doorway gap; the next cell outward is the exterior doorway cell.
