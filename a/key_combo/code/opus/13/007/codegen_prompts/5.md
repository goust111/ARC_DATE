## 新题 5：选择器色块旋转角度由面积排名决定

**组合逻辑**：[颜色索引匹配 + 图例位置映射](已有原语) + [面积排名](创新：排名结果编码为旋转角度) → [旋转](创新：旋转角度不固定，由跨对象比较决定) → [复制放置](已有原语)

**来源原语**：复制放置/选择器块/象限/颜色索引匹配/图例位置映射(7d18a6fb), 旋转/拼接(ed98d772), 面积排名/裁剪/前景最多者选出(a87f7484)

**依赖链**：这是一个并行-汇合结构。两条独立信息流（颜色匹配→放置位置；面积排名→旋转角度）汇合于最终放置步骤。颜色匹配告诉"放在哪个象限"，面积排名告诉"旋转多少度"，缺少任一条信息流都无法得到正确输出。

将每个精灵体按颜色匹配放入选择器块的对应象限，但放入前需根据该精灵体在所有精灵体中的前景像素数排名决定顺时针旋转角度。

**输入结构**：约 17x17 的黑(0)背景网格。一个 7x7 的选择器块，主体填充灰(5)，在其四个 3x3 象限的中心位置各有一个不同颜色的标记像素（从红(2)、蓝(1)、绿(3)、黄(4)中选取 4 种）。选择器块之外有 4 个精灵体，每个精灵体的边界框为 3x3，使用单一前景颜色（与 4 个标记颜色一一对应）画在黑(0)背景上；4 个精灵体的前景像素数互不相同（范围 3-8 像素，保证排名唯一）。精灵体之间和精灵体与选择器块之间互不接触，至少间隔 1 像素。

**规则**：
1. 将每个精灵体与选择器块中同色标记配对（精灵体颜色 = 标记像素颜色）。
2. 统计每个精灵体边界框内的前景（非黑）像素数。按像素数从少到多排序，得到排名 1（最少）到排名 4（最多）。像素数保证互不相同，无需 tie-break。
3. 根据排名确定顺时针旋转角度：排名 1 → 0 度（不旋转），排名 2 → 90 度，排名 3 → 180 度，排名 4 → 270 度。
4. 对每个精灵体，裁剪其 3x3 边界框内容，按步骤 3 的角度顺时针旋转。
5. 构建 7x7 输出网格，背景为黑(0)。将其分为四个 3x3 象限：左上(行0-2, 列0-2)、右上(行0-2, 列4-6)、左下(行4-6, 列0-2)、右下(行4-6, 列4-6)，中间行(行3)和中间列(列3)保持黑(0)。
6. 将每个旋转后的精灵体放入其配对标记所在的象限。输出仅包含该 7x7 网格。

**关键洞察**：单个精灵体的旋转角度不取决于它自身的任何性质，而取决于它与其他所有精灵体的像素数比较结果。改变任意一个精灵体的形状都可能改变所有精灵体的排名，从而改变所有旋转角度——这是一个全局耦合。仅看一个示例，若恰好排名与位置顺序一致，可能误以为旋转由象限位置决定，必须对比多个示例才能归纳出排名规则。
