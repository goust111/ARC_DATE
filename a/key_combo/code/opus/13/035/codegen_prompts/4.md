## 新题 4：嵌套框深度控制交替扩展层数

**组合逻辑**：[计数(counting)](创新：度量矩形嵌套深度作为参数) + [展开(expand)](创新：以种子像素为中心按曼哈顿距离扩展，层数由嵌套深度决定) + [交替填色(alternating_fill)](已有) + [擦除(erase)](已有)

**来源原语**：矩形边框、严格包含、最外层颜色继承(7d1f7ee8)；展开、交替填色、中心对称展开、奇偶决定颜色(db3e9e38)；计数(5289ad53)；擦除(a48eeaf7)

**依赖链**：嵌套深度计数决定扩展层数 → 种子像素位置决定扩展中心 → 交替填色按奇偶层着色 → 框边界约束扩展范围。深度、种子、框边界三者共同决定输出，缺一不可。

根据每组嵌套矩形框的深度决定内部种子像素的曼哈顿菱形扩展层数，奇数层用种子色、偶数层用黑色，扩展不超出最内层框边界，最终擦除所有框仅保留菱形图案。

**输入结构**：约 18x18 网格，背景黑(0)。网格中有 2-3 组互不相交的嵌套矩形边框（空心矩形），每组 1-3 层嵌套。所有框统一为蓝(1) 色。每组最内层框的中心格有一个彩色种子像素（红(2)、绿(3) 或黄(4)，各组不同）。框之间至少间隔 2 格。生成约束：最内层框的内部空间足够容纳深度层数的菱形扩展；不同组的嵌套深度不全相同。

**规则**：
1. 对每组嵌套框，计算嵌套深度 D（单层框 D=1，框内套框 D=2，以此类推）。
2. 以种子像素为中心，按曼哈顿距离扩展 D 层菱形环。第 0 层是种子像素本身（保持种子色），第 1 层是曼哈顿距离为 1 的 4 个格，第 2 层是距离为 2 的 8 个格，依此类推直到第 D 层。
3. 交替着色：种子像素和奇数层（第 1、3、5...层）使用种子颜色，偶数层（第 2、4、6...层）使用黑(0)。
4. 扩展不超出最内层框的内部区域：任何超出该区域的层像素被裁剪（不绘制）。
5. 擦除所有蓝(1) 框像素（设为黑(0)）。输出中仅保留种子像素及其菱形扩展图案。
6. 若两组扩展图案的绘制区域重叠（仅在框被擦除后可能出现），嵌套深度更大的组优先（其像素覆盖另一组）。

**关键洞察**：框不是装饰结构——它们既编码了扩展参数（嵌套深度 = 菱形层数），又限定了扩展边界（最内层框的内壁），最终自身被擦除。求解者必须从框的嵌套层级中读取数值信息，而非仅视觉辨认框。菱形使用曼哈顿距离（而非切比雪夫距离产生的正方形）需要对比示例确认。

Input structure:
- bg = most common color.
- Several multicolor connected components (8-connected) scattered across the grid.

Rule:
- Compute each object's canonical shape (binary mask, invariant to rotation and flip).
- Objects whose shape appears in two or more components → translate to TOP edge (row 0).
- Objects whose shape is unique → translate to BOTTOM edge (row H−h).
- Horizontal position (left column) is preserved; only vertical translation changes.

Key insight: The sorting criterion is shape frequency (rotation-invariant), not area — duplicated shapes go up, unique shapes go down.
