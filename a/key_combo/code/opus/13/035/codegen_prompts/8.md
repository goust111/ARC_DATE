## 新题 8：频率锚定像素定位框心，种子图案填充框内

**组合逻辑**：[计数(counting)](已有，频率分析定位锚点) + [描边(outline)](创新：以锚点为中心生成空心框，框尺寸由种子图案决定) + [平铺(tiling)](已有，种子图案填充框内) + [擦除(erase)](已有)

**来源原语**：计数、孤立像素、框、频率唯一性、最低频色定位目标(31aa019c)；平铺、种子图案、矩形空腔、图案填满空腔、保持种子相位(a57f2f04)；描边(31aa019c)；擦除(a48eeaf7)

**依赖链**：频率分析找到锚点位置 → 种子图案的包围盒尺寸决定框大小 → 框以锚点为中心绘制 → 种子图案平铺填充框内腔体。锚点决定"在哪"，种子决定"多大"和"填什么"，三类信息来源不同、汇合于输出。

在散布像素中找出频率唯一（仅出现一次）的颜色像素作为锚点，以其为中心绘制空心框，框大小由网格中另一处种子图案的包围盒决定，最后用种子图案平铺填满框内区域。

**输入结构**：约 15x15 网格，背景黑(0)。网格上散布着若干单像素点，使用 2-3 种颜色，每种出现 2-4 次；恰有一种颜色仅出现一次（锚点色）。另有一个由独立颜色（不同于任何散布像素颜色，如品红(6)）构成的 4-连通小图案（2x2 或 2x3 或 3x2 的不规则形状，3-6 像素），位于网格某处，与散布像素互不相邻。生成约束：锚点像素距网格边界至少 4 格（确保框不越界）；种子图案的包围盒至少 2x2。

**规则**：
1. **频率分析**：统计每种非黑颜色的散布单像素出现次数。出现恰好 1 次的颜色为锚点色，其唯一像素为锚点。
2. **确定框尺寸**：找到非散布像素的多像素连通区域（种子图案），取其包围盒宽 W 和高 H。框尺寸为 (2W+1) x (2H+1)。
3. **画框**：以锚点为中心，绘制红(2) 空心矩形框，外廓尺寸 (2W+1) x (2H+1)。框线宽 1 像素。
4. **擦除散布像素**：将所有散布单像素（包括锚点）设为黑(0)。仅保留框和种子图案。
5. **平铺填充**：将种子图案平铺到框内腔体（框内部的 (2W-1) x (2H-1) 区域）。平铺从腔体左上角开始，逐行逐列重复种子图案的包围盒内容（含背景黑格）。超出腔体边界的部分裁剪。种子图案原始实例被擦除（设为黑(0)）。
6. 框像素保持红(2)，背景保持黑(0)。

**关键洞察**：输出由三个独立信息源共同决定——锚点位置（来自频率分析）、框大小（来自种子图案的几何尺寸）、填充内容（来自种子图案的形状）——三者在输入中毫无空间关联，仅在输出中汇合。频率分析规则（出现次数 = 1）和框尺寸公式（2W+1, 2H+1）需对比多个示例方能归纳。
