## 新题 8：频率过滤后角度排序绘制交替色连接线

**组合逻辑**：[计数 + 频率排序 + 跳过最高频](创新：过滤改变区域集合从而改变连接拓扑) → [环绕角度排序 + 分离区域](已有) → [连线 + 交替着色](创新：交替色连线应用于角度排序的区域间而非边框内部) + [擦除](已有)

**来源原语**：计数、频率排序、跳过最高频 ← f8b3ba0a；环绕角度排序、分离区域、分隔结构 ← 880c1354；连线、交替着色 ← a6f40cea；擦除 ← 54dc2872

**依赖链**：像素计数 → 识别并擦除最大区域 → 幸存区域角度排序 → 相邻区域间绘制交替色路径。干扰区域如果被包含会产生错误的连接。

用一句话概括：移除像素最多的干扰区域，将剩余区域按绕中心分隔结构的角度排序，在角度相邻的区域对之间绘制交替色曼哈顿路径。

**输入结构**：
- 网格约 15x15，黑(0)背景。
- 中心：一个小型分隔结构（加号或十字形，约 5-7 像素），颜色为灰(5)，大致居中。
- 分隔结构周围：5 到 7 个单色 4-连通区域，每个颜色不同（取自{蓝(1)、红(2)、绿(3)、黄(4)、品红(6)、橙(7)、青(8)}中的若干种）。区域互不接触，也不接触分隔结构。其中一个区域的像素数严格多于其他所有区域（干扰项）。其余区域的像素数两两不同。
- 生成约束：干扰区域在角度排序中位于两个其他区域之间，其移除会改变角度邻接图（使原本不相邻的两个区域变为相邻）。

**规则**：
1. 统计每个非分隔结构前景区域的像素总数。
2. 识别像素最多的区域（干扰项），将其所有像素擦除为黑(0)。
3. 计算灰(5)分隔结构的质心坐标。
4. 将剩余区域按其质心相对于分隔结构质心的角度排序，以屏幕坐标系正右方向为 0 度顺时针递增。
5. 对每对角度相邻的区域（包括末尾与开头的环绕配对），绘制曼哈顿路径：
   - 路径连接两个区域质心的最近整数格坐标。
   - 路径采用 L 形走法：先从起始质心水平移动到目标质心所在列，再垂直移动到目标质心（若此路线与任何前景对象相交则改为先垂直后水平；若两条路线均无阻挡则使用先水平后垂直）。
   - 路径像素在两个相连区域的颜色之间交替着色，从靠近角度序中排前的区域的那一端开始使用该区域的颜色。
6. 若两条路径的像素位置重叠，后绘制的路径覆盖先绘制的。绘制顺序沿角度序列依次进行（区域 0-1 之间的路径先画，再画 1-2，以此类推，最后画 N-1 到 0 的环绕路径）。

**关键洞察**：最大区域是一个诱饵，必须先识别并移除才能正确连接。如果保留干扰项，它会改变角度邻接关系，导致连线连错区域对。干扰项的角度位置被特意设计在两个幸存区域之间，使得其移除从根本上改变了连接图。

<description>
Rotate each 2x2 block's four diagonal corner colors clockwise, then extend the rotated colors outward as diagonal rays.

Input structure
- The background is the dominant color.
- One foreground color forms one or more solid 2x2 blocks.
- Each block has four non-background, non-block corner pixels diagonally adjacent to it.

Rule
- Around every block, move the NW corner color to NE, NE to SE, SE to SW, and SW to NW.
- From each rotated corner, paint along the outward diagonal until the grid edge or another 2x2 block is reached.
- If a ray reaches a same-colored outgoing corner of another block that has its own visible continuation, stop the incoming ray at that junction.

Key insight
- The 2x2 blocks are color rotators and ray blockers; the corner pixels are not independent dots but the four ports of each block.
