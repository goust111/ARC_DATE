## 新题 2：图元分解计数驱动轮廓腔填充

**组合逻辑**：[分解 + 基本图元](创新：分解的结果不直接重涂色，而是作为计数输入) → [计数](已有) → [面积匹配](创新：用分解计数而非源像素数做匹配) → [填充](已有，填入轮廓腔内)

**来源原语**：分解、基本图元、图元形状决定涂色 ← 150deff5；计数 ← f8b3ba0a；轮廓对象、行内腔、面积匹配、像素数等于腔面积 ← 7acdf6d3；填充 ← 7acdf6d3

**依赖链**：分解复合形状为图元 → 按类型计数 → 计数结果与轮廓腔面积匹配 → 匹配成功的腔被填入对应颜色。分解结果改变计数值，计数值决定填充目标——三步之间有实质信息变换。

用一句话概括：将灰色复合体分解为正方形和长条两种图元并分别计数，以计数值匹配轮廓对象的内腔面积，用图元类型对应的颜色填充匹配到的腔。

**输入结构**：
- 网格约 16x16，黑(0)背景。
- 一个灰(5)复合形状（单个 4-连通区域，10-18 像素），可唯一分解为若干 2x2 正方形和若干 1x3 或 3x1 长条。该形状位于网格的一个象限。
- 网格其他位置有 2 到 3 个轮廓对象，每个轮廓用不同的前景色绘制（如蓝(1)、红(2)、绿(3)），每个轮廓是 1 像素厚的封闭环形，围成一个内腔。各轮廓的内腔面积（逐行统计：每行中轮廓最左像素与最右像素之间的背景像素数之和）互不相同。其中恰好有两个腔面积分别等于正方形计数 S 和长条计数 R。
- 生成约束：灰色形状的分解方式唯一（不存在两种合法分解给出不同的 S 和 R 值）。各轮廓的内腔面积两两不同。

**规则**：
1. 将灰(5)复合形状分解为不重叠的图元，仅允许两种类型：2x2 正方形和 1x3 或 3x1 长条。每个灰色像素恰好属于一个图元。
2. 统计 2x2 正方形的数量 S 和长条的数量 R。
3. 对每个轮廓对象，计算其行跨度内腔面积：在轮廓占据的每一行上，统计最左轮廓像素与最右轮廓像素之间严格内部的背景像素数，跨行求和。
4. 内腔面积等于 S 的轮廓：将其整个内腔填充为青(8)。
5. 内腔面积等于 R 的轮廓：将其整个内腔填充为红(2)。
6. 内腔面积既不等于 S 也不等于 R 的轮廓：保持不变（内腔仍为黑(0)）。
7. 灰色复合形状保留在原位，不被擦除或重涂。

**关键洞察**：灰色形状的作用不是视觉输出（不同于源题中的就地重涂），而是一个"编码器"——其分解结果产生的数值信息在空间上跨区域选择了填充目标。图元类型到颜色的映射（正方形→青、长条→红）复用了分解逻辑但施加在完全不同的空间语境中。
