## 新题 5：路径像素数作为循环轮换参数

**组合逻辑**：[端到端遍历 + 单像素宽路径](创新：路径不携带有意义的颜色信息，其像素数才是信息) → [计数](创新：计数对象是路径像素而非对象数量) → [循环轮换](创新：轮换量可变而非固定为 1) + [环绕角度排序](已有) → [擦除](已有)

**来源原语**：单像素宽路径、端到端遍历 ← 5792cb4d；计数 ← f8b3ba0a；循环轮换、环绕角度排序、分离区域、分隔结构 ← 880c1354；擦除 ← 54dc2872

**依赖链**：计数路径像素 → 路径长度 L 对区域数 N 取模 → 得到循环轮换量 K → 按角度排序区域 → 轮换颜色 → 擦除路径。不测量路径则 K 未知；不做角度排序则轮换方向未定义。

用一句话概括：计算单色路径的像素数量，以此作为周围各区域颜色沿角度排序的循环轮换步数，然后擦除路径。

**输入结构**：
- 网格约 15x15，黑(0)背景。
- 中心：一个小型分隔结构（十字形或加号形，约 5-7 像素），颜色为橙(7)，质心大致位于网格中心。
- 分隔结构周围：4 到 6 个单色 4-连通区域，每个区域颜色不同（取自{蓝(1)、红(2)、绿(3)、黄(4)、品红(6)、青(8)}中的若干种）。区域互不接触，也不接触分隔结构。
- 一条单色 4-连通单像素宽路径，颜色为灰(5)，穿越背景区域但不触碰任何彩色区域或分隔结构。路径恰好有两个端点，无分叉。路径长度在 3 到 15 像素之间。
- 生成约束：轮换量 K = (路径长度) mod N 不为 0 且不为 1（确保轮换效果非平凡且与源题固定 1 步轮换不同），其中 N 为区域数量。

**规则**：
1. 计算灰(5)路径的像素总数，记为 L。
2. 识别所有非分隔结构、非路径的前景区域，记其数量为 N。
3. 计算轮换量 K = L mod N。
4. 计算橙(7)分隔结构的质心坐标。
5. 按各区域质心相对于分隔结构质心的角度排序：以屏幕坐标系中正右方向为 0 度，顺时针递增（右 = 0°，下 = 90°，左 = 180°，上 = 270°），得到区域序列 [R_0, R_1, ..., R_{N-1}]。
6. 循环轮换颜色：角度位置 i 的区域接收角度位置 (i - K) mod N 处区域的原始颜色。区域形状和位置不变，仅颜色改变。
7. 擦除灰色路径（所有路径像素设为黑(0)）。分隔结构保持不变。

**关键洞察**：路径是一个计数器而非导管——其长度编码了轮换幅度，而其颜色和形状无关紧要。求解者必须同时测量路径长度并确定角度排序，才能预测输出。
