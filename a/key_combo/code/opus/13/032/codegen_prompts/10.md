## 新题 10：路径颜色首现序反转定义区域重涂映射

**组合逻辑**：[颜色序列反转 + 单像素宽路径 + 端到端遍历](创新：反转不施加于路径本身而用于构造颜色置换) → [重涂色](创新：重涂规则由路径反转产生而非预定义) → [颜色配对](创新：配对关系动态生成而非由空间标记固定) + [擦除](已有)

**来源原语**：颜色序列反转、单像素宽路径、端到端遍历、形状不变仅反色序 ← 5792cb4d；重涂色 ← 150deff5 / 880c1354 等；分离区域 ← 880c1354；颜色配对 ← 54dc2872；擦除 ← 54dc2872

**依赖链**：遍历路径记录颜色首现序 → 反转首现序 → 逐位配对构造颜色置换 → 对区域施加置换 → 擦除路径。路径被当作指令读取然后销毁，而非自身被变换。

用一句话概括：沿多色路径行走提取颜色首现顺序，将其反转得到颜色置换映射，以此重涂网格上同色的各单色区域，最后擦除路径。

**输入结构**：
- 网格约 14x14，黑(0)背景。
- 一条 4-连通单像素宽路径（无分叉，恰好两个端点），使用 N 种不同的前景色（N = 3 或 4），每种颜色至少出现 1 次。路径共 6-12 个像素，位于网格的一个部分（如上半部）。
- N 个单色 4-连通区域（每个 5-15 像素，每个颜色不同），位于网格的另一个部分（如下半部）。这 N 个区域恰好使用与路径相同的 N 种颜色。区域互不接触，也不接触路径。
- 生成约束：路径的首现序列及其反转所产生的颜色置换不是恒等映射（至少一种颜色映射到不同颜色）。行索引较小（若行索引相同则列索引较小）的端点为指定起点。

**规则**：
1. 从行索引较小的端点（若行索引相同则列索引较小）出发，沿路径遍历到另一端点。记录每种颜色首次出现的顺序，得到首现序列 [c_1, c_2, ..., c_N]（c_1 是最先遇到的新颜色，c_N 是最后遇到的新颜色）。
2. 反转首现序列：[c_N, c_{N-1}, ..., c_1]。
3. 构建颜色置换映射：c_1 → c_N，c_2 → c_{N-1}，...，c_N → c_1。即首现序中第 i 个颜色映射到反转序中第 i 个颜色。
4. 对所有区域施加该颜色映射：每个颜色为 X 的区域，其所有像素重涂为映射后的颜色。
5. 擦除路径（所有路径像素设为黑(0)）。

**关键洞察**：路径不是被变换的对象——它被"读取"然后"销毁"。它的颜色序列及其反转共同定义了一个颜色置换，该置换作用于远处的独立对象。路径的空间结构（哪个像素连着哪个）创建了序列；反转操作创建了置换；远处的区域接收变换。这与源题（路径上颜色就地反转）在角色上完全不同。
