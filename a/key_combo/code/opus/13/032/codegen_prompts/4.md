## 新题 4：双重编码对角标记控制精灵体变换

**组合逻辑**：[对角配对](创新：对角方向编码旋转方向而非用于生成字形) + [旋转 + 角落对应](创新：旋转方向由标记空间排列而非标记位置推断) + [颜色配对](创新：标记颜色同时编码目标位置) + [平移 + 擦除](已有)

**来源原语**：对角配对、角标记像素 ← f35d900a；旋转、角落对应、标记定旋转源目 ← ecaa0ec1；颜色配对 ← 54dc2872；平移、擦除 ← 54dc2872；精灵体 ← 多题

**依赖链**：识别标记对 → 对角方向推断旋转方向（TL-BR 对角 → 顺时针 90°，TR-BL 对角 → 逆时针 90°）AND 标记颜色推断目标精灵体 → 旋转精灵体 → 平移至目标位置。标记同时编码旋转和目的地两种独立信息，缺一不可。

用一句话概括：每个精灵体旁的同色标记对既通过对角方向编码旋转方向，又通过颜色指定目标精灵体，旋转后的精灵体移至颜色匹配的目标位置。

**输入结构**：
- 网格约 14x14，黑(0)背景。
- 3 个小型单色精灵体（每个为 3x3 的非对称 4-连通形状，各自颜色不同，取自{蓝(1)、红(2)、绿(3)}）。精灵体互不重叠、互不接触，各有明确的边界框。
- 每个精灵体的边界框外对角位置放置恰好 2 个同色标记像素：两个标记分别位于边界框对角方向外扩一格的位置（例如，一个在左上角外扩位置，一个在右下角外扩位置；或一个在右上角外扩位置，一个在左下角外扩位置）。同一标记对的两个像素颜色相同，且该颜色等于另一个精灵体的主体颜色。
- 3 个标记对的颜色构成循环置换：精灵体 A 的标记色 = 精灵体 B 的主体色，精灵体 B 的标记色 = 精灵体 C 的主体色，精灵体 C 的标记色 = 精灵体 A 的主体色。
- 生成约束：每个精灵体均无 90 度旋转对称性；每个标记对要么在 TL-BR 对角线上，要么在 TR-BL 对角线上（同一对内部不混合）。

**规则**：
1. 对每个精灵体，识别其边界框外对角方向的 2 个同色标记像素。
2. 判断标记对的对角类型：
   - 标记分别位于边界框左上外扩和右下外扩 → 该精灵体旋转 90° 顺时针。
   - 标记分别位于边界框右上外扩和左下外扩 → 该精灵体旋转 90° 逆时针。
3. 确定目标位置：标记对的颜色与某个精灵体的主体颜色相同，该精灵体的边界框中心即为目标位置。
4. 先计算所有精灵体的旋转结果和目标位置，然后同时执行所有平移（每个旋转后的精灵体移动至其目标精灵体的原始边界框中心对齐，被替换的精灵体同时移走——所有移动基于原始位置计算，不级联）。
5. 擦除所有标记像素（设为黑(0)）。

**关键洞察**：同一对标记像素编码了两种独立信息——它们的空间排列（占据哪两个角）决定旋转方向，它们的颜色决定目标位置。两种信息互不可替代，必须同时从标记中读取。
