## 新题 7：视线方向决定宽高归一化方式

**组合逻辑**：[视线对齐 + 最近邻](创新：视线方向不用于驱动滑动目标而用于选择归一化模式) + [宽高互换 + 归一化朝向](创新：归一化方向不是固定产出两份而是由外部空间关系条件分支决定) + [滑动](已有，归一化后沿视线方向靠近方块) + [颜色配对](已有，按颜色匹配矩形与方块) + [擦除](已有)

**来源原语**：视线对齐、最近邻、实心方块 ← e1d2900e；宽高互换、归一化朝向、单色矩形 ← d749d46f；滑动 ← e1d2900e；颜色配对 ← 54dc2872；擦除 ← 54dc2872

**依赖链**：颜色匹配矩形与方块 → 判断视线轴向（水平还是垂直）→ 轴向决定归一化方向（水平→横向，垂直→纵向）→ 归一化 → 沿视线滑动至方块旁 → 擦除方块。空间关系编码了条件分支逻辑。

用一句话概括：每个彩色矩形与同色 2x2 方块配对，视线轴向决定矩形归一化为横版还是竖版，然后矩形沿视线方向滑动至方块旁。

**输入结构**：
- 网格约 14x20，黑(0)背景。
- 3 到 4 个不同颜色的单色实心矩形（如蓝(1) 2x5、红(2) 4x3、绿(3) 1x6），分散放置，互不接触。每个矩形宽高不等（非正方形）。
- 每个矩形对应一个同色的 2x2 实心方块，放置在网格其他位置。每个方块与其配对矩形之间仅共享行范围（方块某些行在矩形行范围内，但列位置不同）或仅共享列范围（方块某些列在矩形列范围内，但行位置不同），不会同时共享两者。这决定了视线是水平还是垂直。
- 方块不与任何矩形重叠，也不与配对矩形相邻。
- 生成约束：每对矩形-方块之间的视线路径（连接它们的行或列）上没有其他前景对象阻挡。不同矩形滑动后不会互相碰撞。

**规则**：
1. 对每种前景颜色，识别矩形（超过 4 像素的对象）和配对的 2x2 方块（恰好 4 像素的对象）。
2. 判断视线轴向：
   - 方块的行范围与矩形的行范围有交集 → 视线为水平方向。
   - 方块的列范围与矩形的列范围有交集 → 视线为垂直方向。
3. 根据视线归一化矩形：
   - 水平视线 → 横向：若矩形高 > 宽，交换宽高（旋转 90°）。归一化后的矩形重新居中于原中心（半像素时向左上取整）。若已为横向则不变。
   - 垂直视线 → 纵向：若矩形宽 > 高，交换宽高。重新居中。若已为纵向则不变。
4. 将归一化后的矩形沿视线轴向朝方块方向滑动，逐像素移动，直到矩形最近边缘与方块最近边缘相邻（间隔恰好 1 像素，无重叠）。
5. 擦除所有 2x2 方块（设为黑(0)）。
6. 处理顺序：先对所有矩形执行归一化，再同时执行滑动。

**关键洞察**：视线轴向不仅是移动方向——它决定了形状归一化规则。水平空间关系强制横向归一化，垂直空间关系强制纵向归一化。这种空间排列与形状变换之间的条件关联是核心的非显然环节。
