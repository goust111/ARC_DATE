## 新题 2：象限镜像着色——模板反射 + 多数票决色

**组合逻辑**：[计数+多数标记色](已有) → [镜像+象限排布](创新：镜像方向由象限位置决定) → [重涂色](创新：涂色由投票结果而非查找表决定)

**来源原语**：计数(counting)+多数标记色涂色(majority_marker_color) ← e681b708；镜像(mirror)+象限排布(quadrant_layout)+双轴反射(biaxial_reflection) ← 67e8384a；重涂色(recolor) ← c64f1187/14754a24；图例模板(legend_template) ← c64f1187

**依赖链**：模板的形状定义了各象限要放置的图案轮廓；象限位置决定镜像方向（水平/垂直/双轴）；标记像素的多数票决色决定各象限图案的颜色。三者缺一不可——没有模板则无形状可放，没有镜像规则则方向错误，没有投票计数则颜色未知。

将左上角模板按象限位置做双轴镜像放入其余三个象限，每个象限中的模板颜色由该象限内标记像素的多数颜色决定。

**输入结构**：黑(0)背景，约 17x17 网格（奇数尺寸以保证中心分割线）。灰(5)单像素十字线将网格分为四个大小相等的象限（一条水平线贯穿整行，一条垂直线贯穿整列，交于网格中心点）。左上象限内有一个用青(8)绘制的非对称单色图案（4-连通，8-15 像素，形状因示例而异），占据象限内部分单元格。其余三个象限（右上、左下、右下）各包含 5-9 个孤立的单像素标记，颜色取自蓝(1)、红(2)、绿(3)、黄(4)，分布在象限内随机位置。生成约束：每个非模板象限中恰好有一种颜色的标记数严格多于其他任何颜色（无平局）。模板图案不具备水平或垂直对称性（以确保镜像后可区分方向）。

**规则**：
1. 识别左上象限中的青(8)图案为模板。
2. 对其余三个象限，分别统计该象限内各颜色标记像素的数量，选出数量最多的颜色作为该象限的"指定色"。
3. 将模板放入各象限，镜像方式由象限位置决定：右上象限 = 水平翻转（左右镜像）；左下象限 = 垂直翻转（上下镜像）；右下象限 = 水平+垂直双轴翻转（等价于 180 度旋转）。放置时，模板在目标象限内的相对位置与原模板在左上象限内的相对位置关于对应轴对称。
4. 将放入的模板像素从青(8)重涂为该象限的指定色。
5. 擦除所有原始标记像素（替换为背景色）。
6. 左上象限的原始青(8)模板保持不变。灰(5)分割线保持不变。

**关键洞察**：模板的形状通过镜像传播到各象限，但颜色信息并非来自模板本身，而是由各象限内分散标记的统计多数投票独立决定——形状和颜色的信息源完全分离。
