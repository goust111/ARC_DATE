## 新题 3：腔室内射线交替着色——奇偶反转由壁标记数决定

**组合逻辑**：[洪泛填充](已有) → [射线延伸+奇偶交替](创新：交替相位由外部条件翻转) ← [计数+条件判断](创新：壁标记奇偶数决定射线相位)

**来源原语**：洪泛填充(flood_fill)+区域邻接(region_adjacency) ← e681b708；射线延伸(ray_extend)+奇偶交替(parity_alternation)+交替填充至边界(alternating_fill_to_edge) ← 97999447；计数(counting) ← 39a8645d/e681b708；墙壁线段(wall_segment) ← e681b708；标记像素(marker_pixel) ← e681b708/dc433765

**依赖链**：洪泛填充划定腔室边界→确定哪些壁标记属于哪个腔室→计数壁标记→奇偶性翻转射线交替相位。射线的起点由腔室内的发射像素决定，终点由腔室壁决定，着色的奇偶相位由壁标记计数决定。这是一个三源汇聚结构：腔室分割、射线几何、标记计数三条信息流同时约束最终着色。

在由墙壁分隔的腔室中，从发射像素发出四方向射线并交替着色；壁上灰色标记的数量决定该腔室内射线的交替相位是否反转。

**输入结构**：黑(0)背景，约 16x16 网格。蓝(1)单像素线段组成墙壁，将网格划分为 3-5 个矩形腔室（墙壁由水平和垂直线段构成，线段端点接在网格边界或其他线段上）。每个腔室内恰好有一个"发射像素"，颜色取自红(2)、绿(3)、黄(4)、品红(6)、橙(7)——各腔室的发射颜色互不相同。在蓝(1)墙壁上散布若干灰(5)孤立标记像素（灰像素替换了该位置原本的蓝色，即它在墙壁线段上但颜色为灰而非蓝）。每个腔室周围墙壁上有 0-4 个灰标记。生成约束：每个腔室的发射像素不紧邻墙壁（与最近墙壁至少隔 1 个背景单元格）；各腔室至少 5x5 大小以容纳可见射线；灰标记不出现在墙壁交叉点上。

**规则**：
1. 将灰(5)标记视为墙壁的一部分（它们阻挡射线且不被射线覆盖），然后从背景色区域洪泛填充以识别各个腔室。
2. 对每个腔室的发射像素，向上、下、左、右四个方向延伸射线。每条射线从发射像素的相邻单元格开始，逐格延伸，遇到墙壁像素（蓝或灰）或网格边界时停止（停止位置不着色）。
3. 默认交替相位（正相）：从发射像素算起，距离为偶数(2,4,6,...)的射线格涂发射像素的颜色，距离为奇数(1,3,5,...)的射线格涂灰(5)。发射像素本身保持原色不变。
4. 统计每个腔室四周墙壁上灰(5)标记的总数。若总数为奇数，则该腔室的交替相位反转（反相）：奇数距离涂发射色，偶数距离涂灰(5)。若总数为偶数（含 0），保持正相不变。
5. 墙壁像素（蓝和灰标记）全部保持不变。

**关键洞察**：射线的几何模式（交替条纹）看似只取决于发射位置和墙壁距离，但其色彩相位还受到一个隐蔽的外部条件控制——腔室周边灰标记的奇偶性；这条规则仅靠单个示例几乎无法归纳，必须对比多个具有不同标记数量的腔室才能发现。
