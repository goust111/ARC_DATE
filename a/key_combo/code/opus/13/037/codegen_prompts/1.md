## 新题 1：孔洞分流——有孔填充、无孔滑移

**组合逻辑**：[封闭孔洞检测](已有) → 条件分支{[擦除+填充](创新：填充色继承框色) | [滑动+碰撞停止](创新：滑向右边缘而非特定列)}

**来源原语**：封闭孔洞(enclosed_hole) ← ac2e8ecf；擦除(erase)+填充(fill)+空心内部变色(interior_recolor) ← d5d6de2d；滑动(slide)+碰撞停止(collision_stop) ← ac2e8ecf/9c56f360

**依赖链**：孔洞检测的结果决定对该对象施加哪一种操作——有孔对象走"擦框填洞"分支，无孔对象走"平移堆叠"分支。两个分支的操作完全不同，删除孔洞检测则无法确定任何对象的处理方式；删除任一分支则该类对象无法正确变换。

将有孔洞的封闭框变为实心填充块、将无孔洞的开放精灵滑移至右侧边缘堆叠，孔洞的拓扑属性决定分支走向。

**输入结构**：黑(0)背景，约 14x16 网格。包含 4-6 个单色 4-连通前景对象，颜色取自蓝(1)、红(2)、绿(3)、黄(4)。其中一部分对象是空心矩形框（单像素厚的矩形边框，内部为背景色，即存在封闭孔洞），边框尺寸约 3x3 至 5x5；另一部分对象是开放精灵（4-连通单色小图形，3-8 像素，无封闭背景孔洞），形状因示例而异（不固定为特定外形）。所有对象互不重叠、互不相邻。网格右侧至少留有 8 列空白，以容纳滑移后的精灵堆叠。生成约束：不同开放精灵的行范围（bounding box 的行跨度）可以重叠，但各精灵滑移到右侧后不会超出网格边界。

**规则**：
1. 对每个前景对象做拓扑分类：若该对象的 4-连通像素围合出至少一个纯背景色区域（即存在封闭孔洞），则归为"封闭类"；否则归为"开放类"。
2. 封闭类处理：将该对象的所有边框像素擦除为背景(0)；将其原来围合的背景孔洞区域全部填充为该对象的原始颜色。即边框消失，孔洞变为实心色块。
3. 开放类处理：将该对象从原位擦除；然后将其整体（保持形状不变）水平滑移至网格最右侧。具体放置方式：保持对象 bounding box 的行位置不变，将 bounding box 的右边缘贴靠网格右边界（最后一列）；若该位置与已放置的其他开放类对象重叠，则向左移动直到不重叠为止。处理顺序：按各开放对象原始 bounding box 右边缘列号从大到小（最靠右的最先处理）。
4. 所有未被上述操作涉及的像素保持不变。

**关键洞察**：决定一个对象命运的不是它的颜色或大小，而是它是否围合出背景孔洞——这个拓扑属性将对象分流到两种截然不同的变换路径。
