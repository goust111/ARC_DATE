## 新题 6：条形码编码的双轴镜像平铺——长度即重复数、颜色即边框色

**组合逻辑**：[控制条→数值编码](创新：条长度编码平铺重复数) + [平铺+双轴反射](已有) + [填充](创新：条颜色编码分隔线颜色)

**来源原语**：控制条(control_bar)+跨度对齐(span_alignment)+沿控制条重复(repeat_along_bar) ← c62e2108；平铺(tiling)+双轴反射(biaxial_reflection)+象限排布(quadrant_layout) ← 67e8384a；填充(fill) ← d5d6de2d/0a938d79；擦除(erase) ← c62e2108；精灵体(sprite) ← 39a8645d/4df5b0ae

**依赖链**：水平控制条的长度决定平铺列数，垂直控制条的长度决定平铺行数——几何长度被隐式编码为数值参数。控制条的颜色决定对应方向分隔线的颜色——同一个对象同时编码了数值和颜色两种信息。平铺模式为双轴反射（非简单复制），使相邻瓦片呈镜像衔接。三层信息（尺寸、颜色、反射方向）缺一不可。

从两根控制条中解码平铺网格的行列数和分隔线颜色，然后用双轴镜像反射方式将精灵平铺为该尺寸的阵列，并在瓦片间绘制彩色分隔线。

**输入结构**：黑(0)背景，约 22x22 网格。包含三个互不重叠的元素：(a) 一个非对称单色小精灵（4-连通，bounding box 为 3x3 或 3x4），颜色为青(8)；(b) 一根水平控制条（单像素高，长度 2-4），颜色为红(2)；(c) 一根垂直控制条（单像素宽，长度 2-4），颜色为绿(3)。三者在网格中相互分离，无对齐关系。精灵不具备水平或垂直对称性（以保证反射后可区分方向）。生成约束：设精灵 bounding box 宽 W 高 H，水平条长度 C，垂直条长度 R，则网格至少需 C*W + (C-1) 列宽和 R*H + (R-1) 行高以容纳完整平铺及分隔线。

**规则**：
1. 读取水平控制条的长度 C（像素数）和垂直控制条的长度 R（像素数）。
2. 构建一个 R 行 x C 列的瓦片阵列。每个瓦片是精灵 bounding box 的一个拷贝，方向由瓦片在阵列中的行列位置决定：
   - 行号和列号均从 0 起计。
   - 列号为奇数时，对该列的瓦片做水平翻转（左右镜像）。
   - 行号为奇数时，对该行的瓦片做垂直翻转（上下镜像）。
   - 若行号和列号均为奇数，则同时做水平+垂直翻转。
3. 在相邻瓦片列之间插入 1 列宽的分隔线，颜色为水平控制条的颜色（红(2)）。
4. 在相邻瓦片行之间插入 1 行高的分隔线，颜色为垂直控制条的颜色（绿(3)）。
5. 分隔线交叉点（行分隔与列分隔的交汇单元格）使用垂直控制条的颜色（绿(3)优先）。
6. 整个平铺阵列（含分隔线）的左上角放置在精灵原始 bounding box 的左上角位置。
7. 擦除原始的水平控制条和垂直控制条（替换为背景色）。

**关键洞察**：控制条不是像 c62e2108 中那样指示方向和终止线，而是通过自身长度隐式编码了一个整数参数（重复次数），同时通过自身颜色编码了另一个参数（分隔线颜色）——同一个几何对象承载了双重信息。
