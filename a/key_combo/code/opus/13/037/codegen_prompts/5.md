## 新题 5：频率排序精灵图鉴——计数、排序、印章拼装

**组合逻辑**：[连通分量检测+形状相同](已有) → [计数+面积排序](创新：排序依据是出现频率而非面积) → [印章覆盖+擦除](创新：将去重后的精灵按频率序印入图鉴区)

**来源原语**：连通分量检测(connected_component_detection)+形状相同(shape_identity)+最高频精灵输出(most_frequent_sprite_output) ← 39a8645d；计数(counting) ← 39a8645d/e681b708；排序(sort)+面积排序(area_ordering) ← 4df5b0ae；印章覆盖(stamp_overlay) ← c64f1187/414297c0；擦除(erase) ← d5d6de2d/c62e2108；拼接(concatenate)+基线对齐排列(baseline_aligned_pack) ← 4df5b0ae

**依赖链**：连通分量检测→提取所有精灵→归一化为类型→计数每种类型的出现次数→按频率排序→在图鉴区从左到右印章排列。计数结果同时决定排序位置和（隐蔽规则）精灵在图鉴中的涂色深浅：出现次数最少的保留原色，每多出现一次则用灰(5)替换精灵中像素值最小的一个非背景像素。

将网格中散布的各类小精灵去重、按出现频率升序排列并印入底部图鉴条，同时擦除所有原始精灵。

**输入结构**：黑(0)背景，约 20x20 网格。主区域（上方 16-17 行）散布 10-18 个小型单色 4-连通精灵，每个精灵 bounding box 不超过 3x3。精灵共有 3-4 种不同类型（以归一化后的 bounding box 掩码 + 颜色判定类型是否相同）。每种类型出现次数互不相同（无平局），范围在 2-6 次。网格最底部 3 行是一条贯穿全宽的灰(5)水平条带（图鉴区），条带内初始全部为灰(5)。颜色取自蓝(1)、红(2)、绿(3)、黄(4)、橙(7)。生成约束：图鉴条宽度足以容纳所有去重类型（每类占 3 列 + 类间 1 列分隔）。

**规则**：
1. 检测主区域中所有 4-连通前景精灵（不含图鉴区）。
2. 将每个精灵归一化为其 bounding box 内的掩码（相对像素坐标 + 颜色），得到精灵类型。
3. 统计每种类型的出现次数。
4. 将去重后的类型按出现次数升序排列（出现最少的排最左）。
5. 在图鉴条中从左起第 1 列开始，依次印入每种类型的 3x3 bounding box 掩码（保留原色），相邻类型之间留 1 列灰(5)分隔。精灵在图鉴条的 3 行中垂直居中（若精灵高度 < 3 则顶部对齐）。
6. 擦除主区域中所有原始精灵（替换为背景色）。
7. 图鉴条中未被精灵占据的位置保持灰(5)。

**关键洞察**：输出并非简单地复制某个精灵（如 39a8645d 只输出最高频的一种），而是要对所有类型做聚合统计后按频率排成序列——排序依据不是几何属性（面积/位置），而是需要遍历全网格才能获得的频率信息。
