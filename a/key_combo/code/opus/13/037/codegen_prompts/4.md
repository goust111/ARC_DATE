## 新题 4：双色对象对撞——滑移碰停、互换着色、缝隙填补

**组合逻辑**：[滑动+碰撞停止](已有) → [颜色互换](创新：互换发生在滑移之后) → [填充](创新：缝隙颜色取决于互换之前的少数色)

**来源原语**：滑动(slide)+碰撞停止(collision_stop) ← ac2e8ecf/9c56f360；颜色互换(color_swap)+对象内双色配对(bicolor_pairing_within_object)+同对象内互换(swap_within_same_object) ← 45737921；填充(fill) ← d5d6de2d/0a938d79；分离(separation) ← ac2e8ecf

**依赖链**：滑移产生空间邻接（原本分离的对象对碰到一起）→碰停留出1列缝隙→颜色互换改变对象外观→缝隙的填充色由互换前左侧对象的少数色决定。这是一条时序依赖链：缝隙颜色引用的是变换前的状态，而最终显示的对象颜色是变换后的状态——求解者必须同时追踪变换前后两个时态。

将水平配对的双色对象相向滑移至碰停（留1列缝隙），互换每个对象内的两种颜色，然后用左侧对象互换前的少数色填充缝隙列。

**输入结构**：黑(0)背景，约 14x18 网格。包含 2-3 对双色对象，每对由两个 3x3 实心正方形组成。每个 3x3 对象恰好使用两种非背景色，其中一种占 5 个像素（多数色），另一种占 4 个像素（少数色）。同一对的两个对象使用相同的两种颜色（但像素分布不同）。不同对使用不同的颜色组合。每对中的两个对象位于同一行带（bounding box 行范围相同），中间水平间隔 4-8 列背景。各对之间行带不重叠。颜色取自蓝(1)、红(2)、绿(3)、黄(4)、品红(6)、橙(7)。生成约束：同一对中的两个对象的少数色和多数色可以不同（即左对象中 A 是多数色 B 是少数色，右对象中可能 A 是少数色 B 是多数色）。

**规则**：
1. 识别每对对象：两个 3x3 对象共享相同的两种颜色且行范围完全重合，即为一对。
2. 每对中的两个对象相向滑移：左对象右移、右对象左移，直到两者的 bounding box 之间恰好留有 1 列空隙（即 bounding box 水平间距 = 1）。
3. 滑移完成后，对每个 3x3 对象执行颜色互换：原多数色变为少数色，原少数色变为多数色（像素位置不变，仅颜色交换）。
4. 填充缝隙：两个对象之间的 1 列 x 3 行空隙（3 个像素），全部填充为**左侧对象在互换前的少数色**。
5. 其余所有像素保持背景色。

**关键洞察**：缝隙列的颜色不是来自任何对象的当前外观，而是来自左侧对象在颜色互换发生之前的少数色——求解者必须记忆变换前的状态来确定一个变换后才出现的元素的颜色。
