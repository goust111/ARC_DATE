## 新题 4：角标记矩形与掩码选色的双向尺寸依赖

**组合逻辑**：[四角标记围定内部](保留：黄色角点定义矩形) + [掩码决定保留](创新：灰色掩码决定矩形内部哪些像素被着色) + [尺寸分类](创新：同一个面积度量同时驱动颜色分配和重叠优先级，且方向相反) → 同时约束满足结构：面积既决定颜色又决定优先级

**来源原语**：四角标记围定内部(four_corners_define_interior, af902bf9), 角标记(corner_marker, af902bf9), 填充(fill, af902bf9), 行列对齐(row_column_alignment, af902bf9), 掩码决定保留(mask_determines_keep, f76d97a5), 颜色替换(color_replacement, f76d97a5), 尺寸分类(size_classification, b27ca6d3), 矩形(rectangle, f3e14006/af902bf9)

**依赖链**：黄色角标记确定矩形几何 → 矩形面积排名同时决定填充颜色**和**重叠优先级 → 灰色掩码进一步筛选矩形内部的着色像素。面积排名做双重用途（颜色+优先级），且两个用途方向相反：最大矩形得到最显眼颜色但在冲突中优先级最低。

黄色角点定义多个矩形，矩形内灰色掩码处按面积排名着色，重叠区域由面积最小的矩形优先覆盖。

**输入结构**：黑(0)背景网格，约 14x14。黄(4)像素标记 2~3 个矩形的四角（每个矩形由 4 个黄像素定义，它们恰好共享两个行值和两个列值）。矩形内部（不含角点的区域）散布若干灰(5)像素作为掩码，每个矩形内有 3~8 个灰像素，灰像素之间可以不连通。生成约束：至少两个矩形的内部区域存在重叠；各矩形的内部面积（= (行数-2) x (列数-2)，即不含角点和边的纯内部）两两不等；重叠区域中两个矩形的掩码均有灰像素存在。

**规则**：
1. 从黄(4)像素中识别矩形：找到共享两行两列的四元组，每组定义一个矩形。
2. 计算每个矩形的内部面积（行数 x 列数，含角点行列）。按面积从大到小排名：最大 → 排名 1，次大 → 排名 2，最小 → 排名 3。
3. 按排名分配颜色：排名 1（最大）→ 红(2)，排名 2 → 蓝(1)，排名 3 → 绿(3)。
4. 对每个矩形的内部区域（不含黄色角点所在的像素）：仅在灰(5)掩码像素所在位置涂上该矩形的分配颜色，其余位置保持黑(0)。
5. 若某像素同时落在多个矩形的掩码区域内：面积**较小**的矩形优先——使用该矩形的颜色。
6. 黄(4)角标记像素在输出中保持不变。

**关键洞察**：面积排名承担双重职责且方向相反——最大的矩形获得视觉最突出的颜色（红），但在重叠冲突中反而让位于更小的矩形。求解者必须同时理解这两层映射关系，仅看颜色分配规则或仅看优先级规则都不足以完全确定输出。
