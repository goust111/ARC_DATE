## 新题 6：分隔栅格连线与邻域决定的半段变色

**组合逻辑**：[同色配对 + 连线](保留：同色端点沿行/列连接) + [等分 + 下半变色](创新：连接线段被等分后半段变色) + [颜色查找键](创新：变色目标颜色由栅格邻域隐式编码) → 隐式编码结构：分隔栅格的拓扑本身编码了颜色映射表

**来源原语**：分隔栅格(divider_grid, 06df4c85), 同色配对(same_color_pairing, 06df4c85), 连线(connect, 06df4c85), 沿行列填充间隙(fill_gap_along_row_col, 06df4c85), 等分(equal_split, ce9e57f2), 下半变色(lower_half_recolored, ce9e57f2), 颜色查找键(color_lookup_key, d35bdbdc), 分隔线划分(separator_partition, 06df4c85)

**依赖链**：同色像素对的位置决定连接方向和长度 → 连接产生的线段被等分 → 后半段需要变色，而变色目标颜色取决于该线段在栅格中的邻域里存在什么其他颜色 → 邻域关系由栅格拓扑决定。从连接到分割到查色，每步输出改变下步的参数。

在分隔栅格中连接同色端点对，将每条连接线段等分后，后半段变为与该线段在栅格中相邻的另一条线段的颜色。

**输入结构**：黑(0)背景网格，约 13x13。灰(5)满行和满列将网格分割为矩形单元（约 3~4 行 x 3~4 列的单元阵列）。部分单元中央有一个彩色像素（非灰非黑，如蓝(1)、红(2)、橙(7)、品红(6)等）。每种颜色恰好出现 2 次，且两次出现位于同一单元行或同一单元列（即沿栅格行对齐或列对齐）。至少有 3 对不同颜色。生成约束：至少有两对线段在连接后共享一条灰色分隔线（即一对的连接方向为水平，另一对也为水平，且它们位于相邻的单元行，中间隔一条水平灰线；或类似的垂直情形）。每对之间的间隔单元数至少为 1。

**规则**：
1. 识别灰(5)分隔线构成的栅格，确定单元划分。
2. 对每种非灰非黑颜色，找到同色的两个像素，它们位于同一单元行或同一单元列。
3. 沿该行或列方向，将两像素之间所有黑(0)单元填充为该颜色（灰分隔线像素不被覆盖，仅填充黑色单元区域）。
4. 每条连接线段（含两端点像素和填充区域）按像素总长度等分：前 ceil(长度/2) 个像素为前半段，后 floor(长度/2) 个像素为后半段。方向定义：水平线段从左到右为前→后；垂直线段从上到下为前→后。
5. 对每条线段的后半段确定变色颜色：在栅格拓扑中，查找与该线段共享一条灰分隔线的另一条线段。"共享灰分隔线"指两条线段分别位于该灰线两侧的相邻单元行（对于水平线段）或相邻单元列（对于垂直线段）。后半段变为该相邻线段的**原始颜色**。
6. 若一条线段有多个邻居，选择与该线段中点距离最近的邻居线段（按中点之间的曼哈顿距离）。若无邻居，后半段保持原色不变。
7. 灰分隔线在输出中保持不变。

**关键洞察**：栅格分隔线不仅组织了端点的配对，还隐式定义了线段之间的邻接关系——变色查找表不是显式给出的，而是从栅格拓扑中读取的。求解者必须发现"共享分隔线 = 颜色供体"这一隐蔽规则。
