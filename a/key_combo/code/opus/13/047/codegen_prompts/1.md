## 新题 1：标记对棋盘矩形与面积优先叠层

**组合逻辑**：[标记对定义跨度](创新：同色孤立像素对定义矩形角点) + [编织填充](创新：以像素对为锚点的局部棋盘填充) + [尺寸分类](创新：矩形面积排序驱动重叠优先级) → 三者交织为同时约束满足结构

**来源原语**：标记对定义跨度(marker_pair_span, f3e14006), 编织填充(weave_fill, f3e14006), 奇偶交替颜色(parity_alt_color, f3e14006), 尺寸分类(size_classification, b27ca6d3), 矩形(rectangle, f3e14006/af902bf9)

**依赖链**：同色像素对的坐标决定矩形范围 → 矩形范围决定编织填充的锚点和区域 → 多矩形重叠时面积排序决定哪个矩形的编织花样可见。三层逻辑缺一不可：没有像素对就没有矩形；没有编织规则就不知道每个像素的颜色；没有面积优先级就无法解决重叠冲突。

同色像素对定义矩形区域，每个矩形内按奇偶校验填充棋盘编织花样，重叠区域由面积较小的矩形优先覆盖。

**输入结构**：黑(0)背景网格，约 12x12。网格上有 2~3 对同色孤立像素（每对颜色不同，如蓝(1)、红(2)、橙(7)）。每对两个像素不在同一行也不在同一列。各像素之间互不相邻（8-连通距离至少为 2）。生成约束：至少有两个矩形的投影区域存在重叠；各对颜色两两不同；每对恰好 2 个像素。

**规则**：
1. 对于每对同色像素 (r1,c1) 和 (r2,c2)，以它们为对角定义一个矩形区域：行范围 [min(r1,r2), max(r1,r2)]，列范围 [min(c1,c2), max(c1,c2)]。
2. 对矩形区域内的每个单元格 (r,c)，计算 (r - r_min + c - c_min)。若该值为偶数，填入该对的颜色；若为奇数，保持黑(0)。其中 r_min 和 c_min 分别是该矩形的最小行号和最小列号。
3. 两个像素对本身的位置始终显示为自身颜色（即使按奇偶校验该位置应为黑色，也强制保留）。
4. 当多个矩形在同一单元格重叠时：比较涉及的各矩形的总面积（面积 = 行数 x 列数），面积**较小**的矩形优先——使用其编织花样颜色。若面积相同，按矩形左上角行号较小者优先；行号也相同则列号较小者优先。
5. 不属于任何矩形的单元格保持黑(0)。

**关键洞察**：每个矩形的棋盘编织相位以自身左上角为锚点，不同矩形的编织相位互相独立——重叠区域的颜色不能通过全局棋盘推断，必须分别计算每个矩形的局部相位再按面积规则取舍。
