## 新题 2：重力沉降进骨架捕获与行填充触发

**组合逻辑**：[重力沉降](创新：像素不落到底而是被骨架空心中心捕获) + [骨架格子 + 空心小框](创新：格子中心作为捕获容器) + [计数 + 扩展填充](创新：行满触发边界着色) → 结构解构型：先通过物理模拟（重力）改变分布，再由分布的统计属性（行完整性）触发第二阶段操作

**来源原语**：重力沉降(gravity_settling, 3618c87e), 同列对齐(same_col_align, 3618c87e), 骨架格子(scaffold_lattice, 97239e3d), 空心小框(hollow_cell_frame, 97239e3d), 扩展填充(expand_fill, 97239e3d), 标记跨度决定范围(marker_span_extent, 97239e3d), 计数(counting, 5582e5ca)

**依赖链**：散落像素的列位置决定它们进入哪列骨架 → 重力顺序决定哪个中心被占（同列先到先得）→ 占据结果决定哪些骨架行"满员" → 满员行的颜色统计决定边界涂色。四步之间每一步的输出都是下一步的必要输入。

散落在骨架上方的彩色像素受重力落入骨架空心框的中心，当某行框的中心全部被占时，该行框的灰色边界被涂成行内出现最多的颜色。

**输入结构**：黑(0)背景网格，约 15x15。网格下半部有一个由灰(5)空心 3x3 框排列成的规则骨架（例如 3 列 x 3 行，共 9 个框），框与框之间有 1 像素间隔。每个 3x3 框的中心（1x1）为黑(0)。网格上半部（骨架之上的区域）散落 5~8 个彩色像素（使用 2~3 种非灰非黑颜色，如蓝(1)、红(2)、绿(3)），各像素互不相邻。生成约束：每个彩色像素的列坐标必须恰好等于某个框中心的列坐标；至少有一行骨架框的所有中心列上方都有像素（保证至少触发一次行填充）；同一列上方的像素数不超过该列的框中心数。

**规则**：
1. 识别骨架格子：灰(5)像素构成的重复 3x3 空心框阵列。每个框中心坐标记为 (rc_i, cc_j)。
2. 每个彩色像素按列匹配到该列的框中心序列中。同一列有多个框中心时，按从上到下排列。
3. 对每列的彩色像素按照它们在输入中的行号从高（远离底部）到低（靠近底部）排序。最靠近底部的像素落入该列最上面一个空的框中心（即最接近顶部的尚未被占据的中心），依次向下填充。若所有中心已满，剩余像素被擦除。
4. 沉降完成后，检查骨架的每一行框。若某行的**所有**框中心都被占据，则该行被"激活"。
5. 对每个被激活的行：统计该行各中心所含颜色的出现次数。将该行所有框的灰(5)边界像素（3x3 框的 8 个边像素 + 框间间隔中属于该行的灰像素）重涂为出现次数最多的颜色。若平局，选择该行中最左侧中心所含的颜色。
6. 未被激活的行保持原样（灰边界 + 占据/空的中心）。骨架上方区域清空为黑(0)。

**关键洞察**：骨架不是装饰——其列对齐决定了哪些像素能被捕获，行完整性条件创造了阈值效应：增减一个像素可能导致某行从不激活变为激活，从而引发大面积边界重涂。

    crop to mask bbox; mask pixels get column color from palette row 0; bg holes get hole_color

generation_strategy:
  approach: output-first
  steps:
    1. Pick grid size H x W (10-18 each), mask bbox size mh x mw (5-10 each).
    2. Choose 3-5 distinct column colors + 1 hole_color + mask_color=5, all mutually distinct and != 0.
    3. Build palette row as contiguous color runs totalling mw columns (4-5 runs, lengths 1-3).
    4. Construct the output grid (mh x mw) — tile palette row over all rows, then randomly set ~30-40% of cells to hole_color ensuring every row and col keeps >=1 non-hole pixel and the non-hole region is 4-connected.
    5. Derive the mask boolean from output: cell != hole_color → mask pixel, else bg hole.
    6. Place mask (as color 5) and palette (3-row strip) in the full grid at non-overlapping row bands with 1-3 row gap, arbitrary column offsets that fit.

## 实现要求

1. `main(grid)` 必须实现新题描述中的确定性转换规则，不能只识别 `generate_input()` 的固定模板。禁止不同的input网格输出相同的output网格。
2. `generate_input()` 必须随机生成多样样例，不能固定死。随机维度应覆盖：网格大小、对象数量、位置、颜色、方向、形状参数或关键分支。注意若描述中存在若干，需实现而不是只有单个，包括object或者对应关系等等。且若涉及到最短路径，则输入网格中必涉及到多条路径，对选择造成干扰。

6. 若规则有多个分支，生成器不能长期固定成一个分支；应让分支在随机样例中合理出现。分支概率不必平均——难以发现的隐蔽分支（如少数情况下才触发的特殊规则）应适当提高出现概率，确保在 3 个训练示例中至少出现一次，否则求解者无法归纳该规则。对于颜色映射类规则，确保 2 个左右的示例即可覆盖所有映射关系（每种颜色→颜色的映射至少在某个示例中出现过）。
