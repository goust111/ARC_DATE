## 新题 6：折叠合成环与条件循环移色

**组合逻辑**：[折叠/fold](已有) + [循环移色/color_cycle](已有) + [透明叠加/transparent_overlay](已有) + [角与边中分组/corner_side_group](创新：分组不再决定循环方向，而是决定折叠时从哪一侧取色) + [反向循环/opposite_cycle](已有)

**来源原语**：折叠、透明叠加、分隔线、对称互补、前景优先（e3497940）；循环移色、角与边中分组、反向循环、环形前景（46c35fc7）

**依赖链**：折叠将左右两侧的环合并为一个复合环（角取左侧色、边中取右侧色） → 仅合并产生的复合环执行循环移色 → 单侧独有的环保持原样。折叠结果决定了哪些环是"复合的"（即触发循环的条件），同时折叠中的取色规则依赖角/边中分组。

沿分隔线折叠网格，对称位置的两个环按角位/边中位分组合成为一个复合环，复合环执行一步颜色循环，非对称位置的单侧环保持不变。

**输入结构**：约 11x23 网格（宽大于高）。灰(5)垂直分隔列位于网格正中，将两侧分为等宽的左右面板（各约 11x11）。每个面板中放置 2-3 个 3x3 环形前景对象（8 像素围绕 1 个背景中心），各环的角位和边中位像素有不同颜色（取自红(2)、绿(3)、蓝(1)、黄(4)、橙(7)、品红(6)等）。部分环在左右面板中占据镜像对称位置（即以分隔列为轴，左侧某环的位置与右侧某环关于分隔列对称），部分环仅出现在一侧。生成约束：至少有 1 对对称环和 1 个单侧环。

**规则**：
1. 移除灰(5)分隔列。将右面板水平镜像翻转，叠加到左面板上，形成一个 11x11 输出网格。
2. 在镜像对称位置上同时存在左右两个环的情况下，合成一个复合环：复合环的 4 个角位像素取自左侧环对应位置的颜色，4 个边中位像素取自右侧环对应位置的颜色（镜像后的位置）。
3. 仅出现在一侧的环保持原始颜色不变，直接放入输出。
4. 对每个复合环执行一步颜色循环：角位颜色顺时针移动 1 步，边中位颜色逆时针移动 1 步。
5. 单侧环不执行颜色循环。
6. 背景像素保持黑(0)。

**关键洞察**：折叠不是简单的像素叠加——它是按像素在环中的角色（角 vs 边中）选择性地从两侧取色，生成一个全新的复合环。只有复合环才触发颜色循环，单侧环是静态的。求解者必须同时理解三个规则：折叠的取色策略、复合环的判定条件、循环的触发条件。

## 实现要求

1. `main(grid)` 必须实现新题描述中的确定性转换规则，不能只识别 `generate_input()` 的固定模板。禁止不同的input网格输出相同的output网格。
2. `generate_input()` 必须随机生成多样样例，不能固定死。随机维度应覆盖：网格大小、对象数量、位置、颜色、方向、形状参数或关键分支。注意若描述中存在若干，需实现而不是只有单个，包括object或者对应关系等等。且若涉及到最短路径，则输入网格中必涉及到多条路径，对选择造成干扰。
3. 生成器必须保证输入满足 `main()` 的隐式假设：对象不重叠、不越界、特殊标记唯一或可区分、匹配关系无歧义、关键分支出现概率相同。
4. 禁止把 ARC 颜色 id 、亮度、拼写等当作人类不可见的数值语义参与排序、大小比较或隐藏映射。颜色变化必须有可见结构线索。注意颜色亮度、拼写等也是不可见信息，若描述中出现违规的颜色id或者亮度，可自行使用少量的固定颜色替代，但注意生成时要在三个以内输入输出网格中对所有变换100%覆盖度。
5. 输出样例要视觉清晰，人类必须能从输入输出对中肉眼辨认出规律。具体要求：避免对象粘连、覆盖关系混乱、同一像素多重语义；不同逻辑步骤产生的结果不要大面积层叠在一起导致无法分辨哪个颜色属于哪个步骤；输入中各元素之间保持足够间距，输出中新增的标记/填充/路径等应与背景和已有元素在颜色上有明显区分；若规则涉及多层叠加，生成时控制对象密度和尺寸，确保叠加区域只占少数像素而非铺满整个网格。
6. 若规则有多个分支，生成器不能长期固定成一个分支；应让分支在随机样例中合理出现。分支概率不必平均——难以发现的隐蔽分支（如少数情况下才触发的特殊规则）应适当提高出现概率，确保在 3 个训练示例中至少出现一次，否则求解者无法归纳该规则。对于颜色映射类规则，确保 2 个左右的示例即可覆盖所有映射关系（每种颜色→颜色的映射至少在某个示例中出现过）。
