## 新题 8：楔形填充区域与面板掩码的透明叠加

**组合逻辑**：[对角线边界/diagonal_boundary + 标记定义楔形范围/marker_define_wedge](已有) → 填充生成右面板前景 → [面板对应/panel_correspondence + 无重叠时叠加/overlay_no_overlap](创新：叠加的右面板内容不是给定的而是推理出的)

**来源原语**：fill、marker_pixel、triangular_wedge、diagonal_boundary、marker_define_wedge（参考题 17: 896d5239）；transparent_overlay、panel、separator_column、foreground_mask、panel_correspondence、overlay_no_overlap（参考题 16: bbb1b8b6）

**依赖链**：右面板中的绿标记像素暗示三角楔形边界 → 填充楔形区域生成青色掩码 → 移除分隔列后将右面板的掩码叠加到左面板 → 仅在不重叠处叠加。楔形推理决定叠加掩码的形状，掩码形状决定叠加的兼容性。

左面板有一个蓝色前景图案，右面板有稀疏的绿色对角线标记；先从标记推断三角楔形并填充青色，然后将填充结果透明叠加到左面板的空白区域。

**输入结构**：约 13x27 网格（宽型）。一根橙(7)竖直分隔列（高度占满，宽 1 列）将网格分为左右两个等大的面板（各约 13x13）。左面板：黑(0)背景上有蓝(1)前景像素构成一个 4-连通不规则形状（约 15~30 像素），形状不靠近面板边缘。右面板：黑(0)背景上有若干绿(3)像素。绿像素排列在 45 度对角线方向上，定义 1~2 个三角楔形区域的边界。每个楔形由一个顶点和两条从顶点出发的对角射线构成，射线上间隔出现绿像素作为边界线索。生成约束：填充后的楔形区域与左面板蓝色形状存在部分位置重叠、部分不重叠。若有 2 个楔形，其中一个与左面板蓝色完全不重叠（可以叠加），另一个存在重叠（不能叠加）。

**规则**：
1. 在右面板中，识别三角楔形：对每个作为楔形顶点的绿(3)像素，找到两条从该顶点出发的 45 度对角射线（四个朝向中选两条相邻的，形成 90 度角）。射线上必须在相同距离处各有一个绿线索像素。楔形高度 = 最远的共享线索距离。
2. 填充每个楔形：将楔形三角区域内部（由顶点和两条对角边界线围成的直角三角形）中所有非绿的像素涂为青(8)。绿(3)标记像素本身保持绿色。
3. 移除分隔列。以左面板为输出画布（保持蓝色图案不变）。
4. 对右面板中的每个独立楔形区域（含其绿标记和青填充），检查该区域的所有前景像素（绿和青）在对应左面板位置上是否全部为背景黑(0)。
5. 若该楔形区域与左面板完全不重叠：将该区域的绿(3)和青(8)像素复制到左面板的对应位置。
6. 若该楔形区域与左面板存在任何重叠（任一前景像素对应位置在左面板也是前景）：完全忽略该楔形，不复制任何像素。
7. 输出即为叠加后的左面板。

**关键洞察**：叠加的目标掩码不是直接给出的固定图案——它需要通过稀疏对角线标记的几何推理来构建。这意味着求解者必须先完成一个空间推理子问题（从散点推断三角形），然后用推理结果参与另一个空间判断（重叠兼容性测试）。两层推理共用相同的坐标空间但逻辑独立。
