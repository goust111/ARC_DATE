## 新题 5：引导条投射生成路径障碍

**组合逻辑**：[投射到引导条/project_to_guide + 投射落间隙则擦/erase_if_gap](创新：投射结果不是压缩显示，而是在引导条旁生成障碍物) + [路径绘制/path_drawing + 绕行/detour](创新：绕行方向不由障碍颜色决定，而由障碍相对于引导条的上下位置决定)

**来源原语**：投射到引导条、引导条、散布像素、投射落间隙则擦（来自 f83cb3f6）；路径绘制、绕行、边界标记、障碍条、阻挡、障碍色决定绕行（来自 96a8c0cd）

**依赖链**：引导条间隙决定哪些散布像素被过滤 -> 有效像素投射到引导条旁形成障碍 -> 障碍的上下位置（相对引导条）决定绕行方向 -> 红色轨迹绕过所有障碍画出路径。删除投射步骤则障碍不存在；删除间隙过滤则障碍过多或位置错误；删除路径绘制则无输出轨迹。引导条同时承担投射过滤器、障碍定位参考和绕行方向隐式决定者三重角色。

散布像素经引导条投射过滤后在引导条旁生成障碍，红色边界标记沿水平方向绘制轨迹，遇障碍时根据其位于引导条上方或下方决定绕行方向。

**输入结构**：约 12x20 的网格，黑(0)背景。一条水平绿(3)引导条位于网格垂直中部附近的某行，厚度一个像素，横跨网格大部分宽度，其中有 1-3 个间隙（黑(0)单元格）。4-8 个散布蓝(1)像素分布在引导条上方和下方（与引导条垂直距离至少 2 格），互不共列。一个红(2)标记像素位于网格左边界（第 0 列），所在行与引导条不同行。生成约束：无两个蓝像素共享同一列；每个蓝像素所在列要么有绿引导像素要么是间隙；投射后的障碍互不相邻列（保证绕行路径不重叠）。

**规则**：
1. 对每个蓝(1)像素，沿垂直方向向引导条投射：
   - 若蓝像素在引导条上方，检查其同列引导条单元格。若为绿(3)，在该列引导条正上方一格（guide_row - 1）放置一个蓝(1)障碍像素。若为间隙（黑(0)），不生成障碍。
   - 若蓝像素在引导条下方，同理：若同列引导条为绿(3)，在引导条正下方一格（guide_row + 1）放置蓝(1)障碍。若为间隙则不生成。
2. 擦除所有散布蓝像素的原始位置（投射消耗了它们），原位变黑(0)。
3. 红(2)标记从左边界沿其所在行向右开始绘制轨迹。
4. 当轨迹遇到同行的蓝(1)障碍像素时绕行：
   - 若障碍在引导条上方（位于 guide_row - 1）：轨迹向下绕行——依次向下一格、向右一格、向上一格，然后恢复向右行进。
   - 若障碍在引导条下方（位于 guide_row + 1）：轨迹向上绕行——依次向上一格、向右一格、向下一格，然后恢复向右行进。
5. 轨迹继续向右直到网格右边缘。仅轨迹经过的黑(0)单元格变为红(2)。
6. 引导条、障碍像素和其他非黑单元格不被轨迹覆盖。
7. 若绕行路径中某步会超出网格边界，轨迹在边界处停止。

**关键洞察**：引导条身兼三职——投射有效性过滤器（间隙使像素失效）、障碍定位参考（障碍固定在引导条上下一格）、绕行方向的隐式决定者（障碍在引导条上方则轨迹向下绕，下方则向上绕）。散布像素的位置与引导条的间隙模式共同决定障碍布局，障碍布局再决定轨迹形状。
