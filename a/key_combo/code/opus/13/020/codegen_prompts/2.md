## 新题 2：镜像十字架的间隙擦除

**组合逻辑**：[镜像/mirror](已有) + [控制定颜色映射/ctrl_color_map](已有) + [擦除/erase](创新：擦除规则不是基于中轴列，而是基于十字架分隔线中的间隙位置，间隙所在行/列的所有象限内容被擦除)

**来源原语**：镜像、模板块、象限、控制像素、翻转对应、控制定颜色映射（来自 cfb2ce5a）；擦除（来自 d23f8c26）；引导条、投射落间隙则擦（来自 f83cb3f6）

**依赖链**：镜像翻转生成四象限内容 -> 控制像素重涂改变各象限颜色 -> 十字架间隙确定擦除的行/列 -> 擦除破坏镜像对称性。删除镜像步骤则象限内容不存在；删除间隙擦除则输出保持完美对称（与实际输出不符）；间隙的非对称分布使得两侧象限受到不同程度的破坏，必须对比多个示例才能归纳出"间隙行全擦"的规则。

镜像模板到四象限并用控制像素重涂，然后十字架分隔线的间隙选择性擦除对应行/列的象限内容。

**输入结构**：一个 (2K+1)x(2K+1) 的正方形网格（如 11x11 或 13x13），黑(0)背景。网格中央有一个绿(3)十字形结构（+），由一整行和一整列组成，将网格分为四个 KxK 象限。十字的交叉单元格始终为绿(3)，但十字的行部分或列部分中有 1-3 个间隙（该位置为黑(0)而非绿(3)）。左上象限包含一个由蓝(1)和红(2)两种颜色在黑(0)上构成的完整模板图案（4-连通的不规则图形片段，3-8 像素）。其余三个象限仅包含稀疏的控制像素（非黑、非绿的孤立像素），其余为黑(0)。

**规则**：
1. 将左上象限的模板翻转到其他三个象限：右上象限为水平翻转，左下象限为垂直翻转，右下象限为双轴翻转。
2. 在每个非左上象限中，对每个控制像素位置，将该位置翻转后的模板像素颜色替换为控制像素的颜色；没有对应控制像素的翻转模板位置变为黑(0)。左上象限保持不变。
3. 完成四象限后，处理绿(3)十字的间隙：
   - 对于中央列中的每个间隙（黑(0)单元格）：将该间隙所在行中、左右两个象限内的所有非绿像素擦除为黑(0)。
   - 对于中央行中的每个间隙（黑(0)单元格）：将该间隙所在列中、上下两个象限内的所有非绿像素擦除为黑(0)。
4. 绿(3)十字像素（包括交叉点）保持不变。已经为黑的单元格不受影响。

**关键洞察**：绿色十字架同时担当镜像对称轴（定义象限结构）和擦除引导条（其间隙选择性地破坏镜像结果）的双重角色。中央列中的一个间隙会擦除一整行的象限内容，但左右象限包含模板的不同翻转版本，因此同一个间隙对左右两侧产生了视觉上不对称的破坏效果。

Collapse the scattered non-guide pixels orthogonally onto the cells immediately beside the straight guide bar.

Input structure
- The background is the dominant color.
- One non-background color forms a one-cell-thick horizontal or vertical guide bar, possibly with gaps along the bar axis.
- The only other non-background color appears as isolated source pixels scattered on either side of the guide.

Rule
- Start from an otherwise empty background canvas and keep the guide bar fixed.
- If the guide is horizontal, each source pixel whose column contains a guide pixel moves to the row directly above or below that guide pixel, preserving its side of the guide.
- If the guide is vertical, each source pixel whose row contains a guide pixel moves to the column directly left or right of that guide pixel, preserving its side of the guide.
- Source pixels whose perpendicular projection would hit a gap in the guide are erased.

Key insight
- The guide bar defines the valid landing slots; the scattered pixels are not copied in place, but compressed along perpendicular sightlines to the nearest cells beside that guide.
</description>

<description>
Push the central solid rectangle to the grid edge, splitting the perpendicular target rectangle around its path.

Input structure
- The background is the dominant color.
- There are exactly three monochrome foreground objects arranged on one
  horizontal or vertical axis.
- The middle object on that axis is a solid rectangular moving object.
- One end object is a solid rectangle or bar whose long side is perpendicular
  to the movement axis; this is the target to split.

Rule
- Move the middle rectangle along the axis toward the target until it is
  flush with the grid edge in that direction.
- Clear the original middle rectangle and the original target.
- Split the target through the moving rectangle's two-cell-wide path and
  shift the two halves one cell outward perpendicular to the movement.
- Keep the other end object unchanged.

Key insight
- The non-target end object acts as a pusher; the central rectangle travels
  away from it through the perpendicular target, opening a matching gap.
</description>
