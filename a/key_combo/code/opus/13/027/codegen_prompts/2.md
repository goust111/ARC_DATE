## 新题 2：障碍阴影泛洪与图例查表重涂

**组合逻辑**：[泛洪填充](填充半封闭区域并穿过开口辐射) + [查表替换](创新：种子色不是输出色，而是图例中的查找键，输出色由图例决定) ← [障碍投射阴影](障碍物阻断辐射方向上的填充传播)

**来源原语**：泛洪填充(flood_fill) ← b9e38dc0；障碍投射阴影(obstacle_casts_shadow) ← b9e38dc0；半封闭墙(partial_enclosure) ← b9e38dc0；查表替换(lookup_replace) ← b20f7c8b；图例面板(legend_panel) ← b20f7c8b/58743b76

**依赖链**：泛洪填充确定每个区域的形状（受墙壁和障碍物约束）→ 种子颜色在图例中查找对应的输出颜色 → 将填充区域重涂为查表结果色。去掉泛洪填充则无区域形状；去掉障碍物则区域形状不同；去掉图例则无法确定最终颜色。

半封闭墙围出的区域通过开口泛洪外溢，障碍物在辐射方向投射阴影截断填充范围；填充完成后，种子颜色经图例查表替换为输出颜色。

**输入结构**：约 15x15 的黑(0)背景网格。顶部 2 行为图例区：由灰(5)分隔线隔开若干 1x2 色块对，每对左列为"输入色"、右列为"输出色"（例如红(2)→绿(3)、蓝(1)→黄(4)），图例中的颜色对数量与下方封闭区域数量一致。图例下方为主操作区，包含 2-3 个灰(5)的 U 形半封闭墙（每个由 3 段灰线围成，一侧留有 1-2 格宽的开口，开口朝向不同的基本方向）。每个封闭区域内部恰好有一个单色种子像素（颜色匹配图例的某个输入色），各封闭区域的种子颜色互不相同。主操作区中还散布 1-2 个橙(7)障碍物像素，位于某些封闭区域的开口辐射路径上。生成约束：每个种子色在图例中恰好出现一次；障碍物不在封闭区域内部也不在墙壁上。

**规则**：
1. 对每个半封闭区域，从其内部种子像素出发进行泛洪填充：先填满封闭区域内所有黑(0)像素，再沿开口方向向外辐射填充。
2. 辐射方向上的橙(7)障碍物阻断填充：障碍物所在位置不被填充，且障碍物沿辐射方向正后方的所有像素也不被填充（即障碍物投射"阴影"）。辐射在遇到网格边缘、另一个封闭区域的墙壁、或另一个已填充区域时停止。
3. 填充完成后，查找图例：将每个填充区域中所有像素的颜色从种子色替换为图例中对应的输出色。
4. 保留图例区、灰(5)墙壁、橙(7)障碍物及分隔线不变。

**关键洞察**：种子颜色是一个查找键而非最终颜色——仅看填充结果无法确定输出色，必须发现图例的映射关系；同时障碍物的阴影效应只在对比有无障碍的示例后才能归纳。
