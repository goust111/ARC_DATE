## 新题 1：频率角色驱动的射线分区与交替填色

**组合逻辑**：[射线延伸](从孤立像素发射十字射线，用于分区) + [重涂色/交替着色](对分区后的矩形区域按奇偶规则填色) ← [按频率分配](创新：频率不再决定十字图案中的角色，而是决定哪种颜色成为射线源、哪两种颜色成为交替填色的调色板)

**来源原语**：射线延伸(ray_extend) ← 9def23fe/99fa7670；重涂色(recolor) ← c8f0f002；按频率分配(freq_role_assignment) ← 3979b1a8；交替着色(alternating_coloring) ← 3bd292e8；孤立像素(isolated_pixel) ← 99fa7670；背景区域(background_region) ← 3bd292e8

**依赖链**：频率分配决定三种颜色的角色（射线/偶填/奇填）→ 射线源像素发射十字射线，划分画布为矩形区域 → 区域的行带-列带奇偶性决定使用哪种填色。三个环节紧耦合：不知道频率就无法分配角色，没有射线就没有分区，没有分区就没有奇偶位置。

将散落三色像素按频率分配为射线源与填色对，射线分割画布后用奇偶规则交替填入两种填色。

**输入结构**：约 12x12 的黑(0)背景网格。恰好包含 3 种非黑颜色的孤立单像素（互不相邻、不在同一行或同一列）。三种颜色的像素数量各不相同（例如 1、2、4 个），不同示例中充当各角色的具体颜色会变化。所有非黑像素均为孤立点（4-邻接无同色邻居）。生成约束：三色像素数量严格互不相等；射线源色的像素不共享行或列（保证射线不重叠）。

**规则**：
1. 统计三种非黑颜色各自的像素数量。像素数最少的颜色记为"射线色"，中间的记为"偶填色"，最多的记为"奇填色"。
2. 从每个射线色像素出发，沿上、下、左、右四个方向画射线直到网格边缘，将路径上的所有黑(0)像素涂为射线色。射线经过其他非黑像素时跳过该像素（保留原色），继续向后延伸。
3. 射线将黑色背景划分为若干 4-连通的矩形区域。以网格左上角所在区域为 (0,0)，按行带索引 r 和列带索引 c 编号各区域（行带从上到下递增，列带从左到右递增）。
4. 若 r+c 为偶数，将该区域内所有黑(0)像素涂为偶填色；若 r+c 为奇数，涂为奇填色。
5. 保留所有射线像素和原始非射线色的孤立像素不变。

**关键洞察**：同一颜色在不同示例中可能扮演射线源或填色角色——角色完全由像素数量的相对排名决定，需对比多个示例才能归纳出频率-角色映射规则。
