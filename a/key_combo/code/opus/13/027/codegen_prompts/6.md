## 新题 6：路径选择性掩码交换

**组合逻辑**：[路径追踪](从棋盘格出发追踪引导路径，选定操作目标) + [交换](创新：不是在水平相邻面板间交换，而是在路径连接的任意两个区域间交换) ← [底色作为涂色源](交换后重涂色使用目标区域的底色)

**来源原语**：路径追踪(path_follow) ← 9ba4a9aa；棋盘格(checkerboard) ← 9ba4a9aa；引导像素(guide_pixel) ← 9ba4a9aa；路径连接(path_connected) ← 9ba4a9aa；交换(swap) ← 5a719d11；成对交换(pairwise_exchange) ← 5a719d11；底色作为涂色源(base_color_source) ← 5a719d11；图案掩码(motif_mask) ← 5a719d11；忽略干扰项(ignore_distractors) ← 5a719d11

**依赖链**：棋盘格定位出发点 → 追踪引导路径找到两个目标区域 → 提取两个区域的图案掩码 → 掩码互换并用目标底色重涂。路径决定"换谁"，底色决定"涂什么色"，两者缺一不可。未被路径连接的其他区域为干扰项。

棋盘格发出的引导路径连接两个带有图案的区域，仅这一对区域进行掩码互换，互换后各掩码用目标区域的底色重涂。

**输入结构**：约 15x15 的黑(0)背景网格。包含以下元素：(a) 3-4 个散布的矩形区域（约 4x4 至 5x5），每个区域有一个主色（底色，占该区域大多数像素）和一个少数色（图案色，占 2-4 个像素，形成 4-连通小图形）；不同区域的底色互不相同，图案色也互不相同。(b) 一个 3x3 棋盘格物体（两种颜色交替排列的 9 像素块）。(c) 若干引导像素：从棋盘格边缘出发，沿水平/垂直方向以 2 格间隔排列，形成一条路径，路径终点与某个矩形区域相邻；该路径再从该区域的另一侧延伸出第二段路径，连接到另一个矩形区域。引导像素的颜色与棋盘格相邻的那个引导像素颜色一致。(d) 网格中可能还有 1-2 条颜色不同的其他引导路径，连接其他区域，但不与棋盘格相连（干扰项）。生成约束：路径恰好连接两个区域；被连接的两个区域底色与图案色均不同。

**规则**：
1. 找到 3x3 棋盘格物体及其唯一相邻的引导像素，记录该引导像素的颜色。
2. 沿该颜色的引导像素追踪路径（每步水平或垂直移动 2 格到下一个同色引导像素），直到路径与某个矩形区域相邻。标记该区域为区域 X。
3. 从区域 X 的另一侧继续追踪同色引导路径，到达第二个矩形区域 Y。
4. 将区域 X 清空为其底色，将区域 Y 清空为其底色。
5. 将区域 Y 的图案掩码（像素偏移集合）印入区域 X，使用区域 Y 的底色作为印章颜色。
6. 将区域 X 的图案掩码印入区域 Y，使用区域 X 的底色作为印章颜色。
7. 所有其他区域、引导路径（包括干扰路径）、棋盘格保持不变。

**关键洞察**：多条引导路径可能存在，但只有与棋盘格相连的路径指示交换目标——其他路径是干扰项；求解者必须先识别棋盘格作为起点，再追踪正确路径，最后执行交换与重涂。
