## 新题 3：轴分组镜像与对角堆叠冲突

**组合逻辑**：[堆叠/对角链排列](将矩形按对角链堆叠) + [镜像](创新：不是跨外部轴反射，而是根据矩形相对轴的分组决定是否自身水平镜像) ← [冲突优先级](创新：重叠区域的胜者不由绘制顺序决定，而由是否经过镜像变换决定)

**来源原语**：堆叠(stacking) ← 03560426；对角链排列(diagonal_chain_layout) ← 03560426；角点重叠(corner_overlap) ← 03560426；冲突优先级(conflict_priority) ← 03560426；镜像(mirror) ← 88207623；轴线段(axis_segment) ← 88207623；按左边缘排序(ordered_by_left_edge) ← 03560426

**依赖链**：轴线段将矩形分为左右两组 → 右组矩形进行水平自镜像（形状改变）→ 所有矩形按原始左边缘顺序沿对角链堆叠 → 重叠像素由镜像属性决定优先级。去掉轴则无法分组；去掉镜像则形状不对；去掉堆叠则无重叠；去掉冲突规则则重叠区不确定。

底部一排矩形被红色轴分为左右两组，右组做水平镜像后全体按左边缘顺序沿对角链堆叠，重叠处镜像组优先。

**输入结构**：约 10x18 的黑(0)背景网格。底部行上排列着 4-5 个互不重叠的单色实心矩形（每个矩形底边紧贴最底行，宽 2-4 格，高 2-4 格，各矩形颜色互不相同，均非黑(0)且非红(2)）。矩形之间有一条红(2)竖线段（高度至少与最高矩形相同，底端也紧贴最底行），将矩形分为左组和右组，每组至少有 1 个矩形。各矩形的左边缘列坐标互不相同。生成约束：矩形的宽高选择使得对角堆叠后不超出约 10x18 的输出画布；左组和右组中至少各有一个非对称矩形（宽 =/= 高），以使镜像效果可观察。

**规则**：
1. 识别红(2)竖线段的列位置，将其左侧的矩形归为"左组"，右侧归为"右组"。红线本身不参与后续堆叠。
2. 对右组的每个矩形，以其自身垂直中心线为轴进行水平镜像（即左右翻转该矩形内部像素图案）。左组矩形保持不变。（注：当矩形为纯色实心时镜像无可见变化，但若矩形含多色图案则效果可见。本题中矩形为实心单色，故此步对形状无影响，但影响冲突规则中的"镜像标记"属性。）
3. 清空画布为黑(0)。将所有矩形按其原始左边缘列坐标从小到大排序。将第一个矩形放置于画布左上角 (0,0)。对于每个后续矩形，其左上角放在前一个矩形左上角偏移 (前一高度-1, 前一宽度-1) 的位置（即角点重叠堆叠）。
4. 重叠像素冲突解决：若重叠的两个像素来自同一组（都是左组或都是右组），则后放置的覆盖先放置的；若来自不同组，则右组（已镜像）的像素始终优先覆盖左组的像素，无论放置顺序。
5. 输出堆叠后的画布（不含红线）。

**关键洞察**：冲突解决规则与绘制顺序不完全一致——跨组重叠时镜像组始终胜出，这需要对比存在跨组重叠与仅有同组重叠的不同示例才能归纳出该优先级规则。
