## 新题 9：引导行平铺与墙壁二部擦除

**组合逻辑**：[平铺/画布扩展](按引导行选择瓦片带) + [擦除](创新：不是擦除射线标记的行列，而是根据墙壁构成的二部图结构选择性擦除瓦片内的子区域) ← [引导行或列](双重功能：选择平铺带 + 锚定二部擦除的保留类)

**来源原语**：平铺(tiling) ← 15696249；画布扩展(canvas_expansion) ← 15696249；引导行或列(guide_row_or_column) ← 15696249；引导线定填充带(guide_determines_band) ← 15696249；擦除(erase) ← 9def23fe；分隔墙线(separator_wall) ← 3bd292e8；二部图结构(bipartite_structure) ← 3bd292e8；交替着色(alternating_coloring) ← 3bd292e8；四邻接连通(four_neighbor_connect) ← 3bd292e8

**依赖链**：引导行确定平铺带位置 → 瓦片被复制到该带的每个块中 → 瓦片内的墙壁像素将瓦片分为子区域 → 子区域构成二部图 → 引导行所在的子区域决定保留类 → 另一类子区域被擦除为黑(0)。引导行承担双重决策功能，且二部擦除依赖瓦片内部结构，无法跳过。

输入瓦片按引导行平铺到对应行带，然后瓦片内墙壁划分的子区域按二部规则选择性擦除，仅保留引导行所在类。

**输入结构**：约 5x5 的输入瓦片。瓦片内包含：(a) 若干红(2)墙壁像素，形成 1 像素宽的线段，将瓦片内部分为 2-4 个 4-连通的非墙壁子区域；(b) 非墙壁区域由多种颜色填充（如蓝(1)、绿(3)、黄(4)等各种非黑非红颜色）；(c) 恰好一行为完整的单色实心行（引导行），该行的颜色与该行穿过的某个子区域的主色一致。墙壁将子区域分为两组（类似棋盘的黑白格），满足二部图性质：任意两个相邻子区域（共享墙壁边界的子区域对）属于不同组。生成约束：墙壁结构保证子区域邻接图是二部图（无奇数环）；引导行的所有像素都属于同一个二部类（引导行可能穿过墙壁，墙壁像素本身不属于任何子区域）。

**规则**：
1. 识别输入瓦片中的引导行（恰好一整行为同一种非黑非红颜色填满的行），记录其行索引 r。
2. 确定引导行为行引导（若存在引导列则按列处理，规则对称）。创建 nxn 块的全黑画布（n = 瓦片边长），将输入瓦片复制到块行 r 的每个块位置中（即画布的第 r 个块行的所有块都是瓦片副本，其余块行为全黑）。
3. 在每个已放置的瓦片副本中，识别红(2)墙壁像素，将非墙壁像素按 4-连通性分为子区域。
4. 对子区域邻接图进行二部染色（二着色），将引导行像素所在的子区域标记为"保留类"，与之相邻的子区域标记为"擦除类"，交替传播。
5. 将所有"擦除类"子区域的像素替换为黑(0)。保留"保留类"子区域像素和所有红(2)墙壁像素不变。
6. 画布中未放置瓦片的区域保持黑(0)。

**关键洞察**：引导行不仅选择平铺的行带位置，还锚定二部擦除的保留类——同一条引导行同时控制两个独立的决策维度，求解者须对比引导行在不同子区域的示例才能发现二部擦除规则。
