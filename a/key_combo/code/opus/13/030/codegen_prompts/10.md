## 新题 10：裁剪标记区域后按嵌套计数填充

**组合逻辑**：[裁剪](已有) + [背景色空洞/四角围合](已有，创新：空洞标记不再直接对应最终裁剪区域，而是标记出工作区域的边界) + [洪泛填充](已有) + [包含/嵌套](已有，创新：不再判断奇偶而是计数嵌套层数) + [计数](已有，创新：计数对象从连通分量变为嵌套包含关系的层数)

**来源原语**：裁剪/网格线/缺失交叉点/四角围合/背景色空洞(a644e277)，洪泛填充/空心矩形/封闭区域/包含(868de0fa)，计数(aaecdb9a)

**依赖链**：四个背景色空洞标记裁剪区域 → 裁剪后在子区域中识别嵌套矩形框 → 统计每个框内被包含的框的数量 → 数量映射为填充颜色。删除裁剪则工作区域不确定（网格其他位置可能有干扰元素）；删除嵌套计数则填充色不确定。

通过四个背景色空洞标记裁剪出工作区域，在其中根据矩形框的嵌套包含层数决定内部填充颜色。

**输入结构**：约 18x18 的网格，由灰(5)单像素厚的规则网格线构成（水平线和垂直线间隔 3~4 格），格子之间为黑(0)背景。恰好四个网格线交叉点处的灰(5)像素被替换为黑(0)（背景色空洞），它们构成一个轴对齐矩形的四个角。在这四个角围成的矩形区域内部（含边界网格线），有若干红(2)一像素厚空心矩形框，部分框嵌套在其他框内部。区域外部也可能有一些红(2)矩形框作为干扰。生成时保证：(1) 四个空洞恰好构成矩形四角；(2) 裁剪区域内的红框嵌套层数从 0 到 2 不等（有的框不包含任何其他框，有的包含 1 个，有的包含 2 个）；(3) 嵌套的框之间有间隔（不共享边框像素）。

**规则**：
1. 找到灰(5)网格线上四个被替换为黑(0)的交叉点，确定它们构成的矩形区域。
2. 裁剪该矩形区域（含边界行列）作为输出。
3. 在裁剪区域中，识别所有红(2)空心矩形框。
4. 对每个矩形框，计算其内部（不含自身边框）直接包含的其他红框数量 d（只计直接包含，不递归）。
5. 按从最内层到最外层的顺序填充每个框的内部空间（不覆盖已有的红框边框和已填充的内层区域）：d=0（最内层，不包含任何其他框）→ 填充绿(3)；d=1 → 填充黄(4)；d≥2 → 填充蓝(1)。
6. 灰(5)网格线和红(2)框边保持不变。区域外的内容被裁剪丢弃。

**关键洞察**：裁剪步骤排除了区域外的干扰矩形框，使得嵌套计数仅在工作区域内进行。填充颜色由嵌套层数（而非面积奇偶）决定，必须正确识别包含关系才能计数。区域外的干扰框是解题陷阱，必须对比多个示例（有的示例中区域外框不影响结果）才能确认裁剪的必要性。
