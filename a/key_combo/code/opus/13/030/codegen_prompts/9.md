## 新题 9：画线分区后各区施加不同变换组合

**组合逻辑**：[连线/描边](已有，创新：画出的线不是装饰而是空间分区工具) + [镜像/翻转列序](已有) + [颜色互换](已有) + [半区分色](已有，创新：从二分扩展为三分，且每个分区对应不同的操作组合)

**来源原语**：连线/描边/孤立像素/半区分色(1bfc4729)，镜像/翻转列序(67a3c6ac)，颜色互换/双色源图案(2b01abd0)

**依赖链**：两个孤立像素确定两条水平线 → 线将网格分为三个水平带 → 每个带内的双色图案受到不同操作：上带仅镜像、下带仅色换、中带镜像+色换。操作类型由带的位置决定，不可分离——删除线划分则不知道哪里施加什么操作；删除任一操作则某些带的输出错误。

两个标记像素画出的水平线将网格分为三个水平带，每带内的双色图案分别接受不同的变换组合。

**输入结构**：约 14x14 的黑(0)背景网格。网格上分布着一个由绿(3)和黄(4)两种颜色构成的稀疏图案（若干孤立像素或小连通块，分布在网格各处）。另有两个孤立标记像素：一个红(2)像素在网格上部（约第 3~4 行），一个蓝(1)像素在网格下部（约第 10~11 行），两者不在同一行。红和蓝像素不与任何绿/黄像素同行。生成时保证：(1) 红像素行号 < 蓝像素行号；(2) 三个水平带（红线上方、红蓝之间、蓝线下方）内均有绿/黄图案像素；(3) 各带内的绿/黄像素分布使得镜像和色换后不与标记线冲突。

**规则**：
1. 通过红(2)像素所在行画一条红(2)水平线（覆盖该行全部列）。通过蓝(1)像素所在行画一条蓝(1)水平线（同理）。
2. 这两条线将网格分为三个水平带：上带（红线上方的所有行）、中带（红线与蓝线之间，不含线本身的行）、下带（蓝线下方的所有行）。
3. 对上带内的所有绿(3)/黄(4)像素：执行左右镜像（以网格垂直中轴为对称轴翻转列位置），颜色不变。
4. 对下带内的所有绿(3)/黄(4)像素：执行颜色互换（绿(3)→黄(4)，黄(4)→绿(3)），位置不变。
5. 对中带内的所有绿(3)/黄(4)像素：同时执行镜像和颜色互换（先翻转列位置，再互换颜色）。
6. 红(2)和蓝(1)水平线保持不变。黑(0)背景不变。

**关键洞察**：中带的变换是上带和下带各自变换的组合（镜像 + 色换），这一规则不能从单个示例中完全确定——必须对比多个示例中三个带的变化模式才能发现中带是两种操作的叠加。

## 实现要求

1. `main(grid)` 必须实现新题描述中的确定性转换规则，不能只识别 `generate_input()` 的固定模板。禁止不同的input网格输出相同的output网格。
2. `generate_input()` 必须随机生成多样样例，不能固定死。随机维度应覆盖：网格大小、对象数量、位置、颜色、方向、形状参数或关键分支。注意若描述中存在若干，需实现而不是只有单个，包括object或者对应关系等等。且若涉及到最短路径，则输入网格中必涉及到多条路径，对选择造成干扰。
3. 生成器必须保证输入满足 `main()` 的隐式假设：对象不重叠、不越界、特殊标记唯一或可区分、匹配关系无歧义、关键分支出现概率相同。
4. 禁止把 ARC 颜色 id 、亮度、拼写等当作人类不可见的数值语义参与排序、大小比较或隐藏映射。颜色变化必须有可见结构线索。注意颜色亮度、拼写等也是不可见信息，若描述中出现违规的颜色id或者亮度，可自行使用少量的固定颜色替代，但注意生成时要在三个以内输入输出网格中对所有变换100%覆盖度。
5. 输出样例要视觉清晰，人类必须能从输入输出对中肉眼辨认出规律。具体要求：避免对象粘连、覆盖关系混乱、同一像素多重语义；不同逻辑步骤产生的结果不要大面积层叠在一起导致无法分辨哪个颜色属于哪个步骤；输入中各元素之间保持足够间距，输出中新增的标记/填充/路径等应与背景和已有元素在颜色上有明显区分；若规则涉及多层叠加，生成时控制对象密度和尺寸，确保叠加区域只占少数像素而非铺满整个网格。
6. 若规则有多个分支，生成器不能长期固定成一个分支；应让分支在随机样例中合理出现。分支概率不必平均——难以发现的隐蔽分支（如少数情况下才触发的特殊规则）应适当提高出现概率，确保在 3 个训练示例中至少出现一次，否则求解者无法归纳该规则。对于颜色映射类规则，确保 2 个左右的示例即可覆盖所有映射关系（每种颜色→颜色的映射至少在某个示例中出现过）。
