## 新题 7：锯齿链覆盖决定矩形框填充

**组合逻辑**：[平铺/旋转/对角锯齿排布](已有，创新：锯齿链不是最终输出而是几何判据) + [交替旋转换色](已有) + [洪泛填充](已有，创新：填充触发条件不再是面积奇偶而是外部图案的覆盖数) + [计数](已有，创新：计数对象从连通分量变为几何重叠段数)

**来源原语**：平铺/旋转/矩形条/对角锯齿排布/交替旋转换色(fd4b2b02)，洪泛填充/空心矩形/封闭区域(868de0fa)，计数(aaecdb9a)

**依赖链**：从种子矩形条生成覆盖全画布的对角锯齿链 → 统计每个空心矩形框的边框被锯齿链覆盖的段数 → 覆盖段数决定填充颜色。删除锯齿链生成则无法计数；删除覆盖计数则填充色不确定。

生成横跨画布的锯齿链图案后，根据链条覆盖每个空心矩形框边框的段数来决定内部填充颜色。

**输入结构**：约 20x20 的黑(0)背景网格。网格上有：(1) 一个绿(3)实心非正方矩形条（如 2x4 或 3x5），作为锯齿链的种子；(2) 3~5 个一像素厚灰(5)空心矩形框（内部为黑，各框尺寸不同，互不重叠）。灰框与种子矩形条不重叠。生成时保证：(1) 种子矩形条在网格中部附近；(2) 各灰框分布在不同位置，使得锯齿链覆盖它们边框的段数各不相同（范围 0~3）。

**规则**：
1. 以绿(3)矩形条为种子，沿两条 45° 对角线方向扩展锯齿链：在对角线上每隔 (种子高+种子宽) 个格放一个种子副本（绿(3)），在相邻副本之间放一个 90° 旋转的矩形条（品红(6)）。链条延伸到画布边界，超出部分裁剪。
2. 对每个灰(5)空心矩形框，统计其边框像素中有多少个被锯齿链的某个矩形条（绿或品红）覆盖。将连续覆盖的边框像素视为一"段"，统计总段数 s。
3. 根据 s 填充矩形框内部：s=0 → 内部保持黑(0)不变；s=1 → 填充红(2)；s=2 → 填充黄(4)；s≥3 → 填充蓝(1)。
4. 锯齿链的矩形条在灰框边框上方绘制（覆盖灰像素），但灰框的整体结构（包括被覆盖的边框像素位置）仍可识别。
5. 输出中同时保留锯齿链图案和填充后的矩形框。

**关键洞察**：锯齿链是全局图案，矩形框是局部结构；填充颜色取决于全局图案与局部结构的交叉程度。不同矩形框因位置不同而有不同的覆盖段数，这种交互关系需要对比多个框才能归纳。
