## 新题 1：对角条纹分类决定框内镜像补全轴

**组合逻辑**：[分类/classify](创新：分类结果不再直接映射颜色，而是选择几何变换参数) + [镜像/mirror] + [对称补全/symmetry_completion] + [擦除/erase]

**来源原语**：分类、对角朝向、多数朝向决定色（参考题 1d61978c）；镜像、矩形框、角标记、内部图案、宽高比决定镜像轴（参考题 93c31fbe）；对称补全（参考题 2546ccf6）

**依赖链**：对角条纹的多数朝向分类结果 → 决定该框的镜像轴选择 → 镜像轴驱动蓝色图案补全 → 补全后擦除分类依据（对角条纹）。删除分类则镜像轴不确定；删除镜像则图案不完整；删除擦除则输出含冗余信息。

将每个彩色框内对角条纹的多数朝向作为编码信号，选择该框蓝色图案的镜像补全轴，然后擦除条纹和框外噪声。

**输入结构**：约 20x20 网格，黑(0)背景。含 2-3 个互不重叠的矩形框，每个框由绿(3) 的 2x2 L 形角标三联骨牌（分别标记左上、右上、左下、右下四角）定义。每个框的内部包含两种元素：(a) 蓝(1)像素构成的非对称图案，大致占据框内 3/4 区域但缺失约 1/4 的镜像对称部分；(b) 红(2)像素构成的短对角线段（每段 2-3 像素，4-6 段），这些线段在同一框内以 NW-SE 或 NE-SW 其中一个朝向为主（多数朝向的线段至少比少数朝向多 2 段）。不同框的多数朝向可以不同。框外的黑色背景上散布少量蓝(1)噪声像素（1-3 个）。生成约束：每个框的宽高至少为 6，框与框之间至少间隔 2 像素；每个框的蓝色图案恰好缺失一个象限的镜像对称部分。

**规则**：
1. 识别每个绿(3)角标框，确定其边界框。
2. 在每个框内部，对红(2)像素进行对角朝向分类：若一个红像素在 NW 或 SE 方向有红色邻居，则计入 NW-SE 组；若在 NE 或 SW 方向有红色邻居，则计入 NE-SW 组。统计两组的像素数。
3. 若框内 NW-SE 组像素数多于 NE-SW 组，则以框中心的竖直轴为镜像轴，将蓝(1)图案左右镜像补全。
4. 若框内 NE-SW 组像素数多于 NW-SE 组，则以框中心的水平轴为镜像轴，将蓝(1)图案上下镜像补全。
5. 镜像产生的新蓝像素只填入框内原本为黑(0)的位置，不覆盖已有蓝像素或红像素。
6. 补全完成后，擦除框内所有红(2)像素（替换为黑(0)）。
7. 擦除框外所有蓝(1)像素（替换为黑(0)）。
8. 绿(3)角标保持不变。

**关键洞察**：框的自身宽高比不决定镜像轴（与参考题 93c31fbe 不同）——镜像轴由框内红色对角条纹的多数朝向编码，这一编码是每个框独立的隐式指令，必须跨示例对比才能排除"与框形状相关"的假设。
