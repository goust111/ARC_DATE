## 新题 8：反转的钥匙瓦片控制格子连线通道

**组合逻辑**：[反转填充](已有，作用对象创新：从全局反转变为单个钥匙瓦片的反转) → [连线/填充](已有，连通条件由反转结果动态决定) + [同色同子格位置](已有)

**来源原语**：反转填充(occupancy_inversion)、瓷砖(tile) 来自参考题 1c0d0a4b；连线(connect)、填充(fill)、格子瓦片(lattice_tile)、端点标记(endpoint_marker)、分隔线(separator_line)、同行列对齐(same_row_col_align)、同色同子格位置(same_color_subcell) 来自参考题 a096bf4d

**依赖链**：钥匙瓦片的反转结果定义了哪些子格位置允许连线——这是一个编码-解码结构：钥匙瓦片是密文，反转是解码操作，解码后的图案是连线规则。连线操作的合法性完全取决于反转后的激活子格集合。删除反转步骤，连线通道不可确定；删除连线步骤，反转后的信息无处应用。

格子中的一个特殊钥匙瓦片经占用反转后产生"连通掩码"，该掩码决定哪些子格位置的同色端点标记可以被连线贯通。

**输入结构**：约 15x15 网格。整个网格被单像素宽的橙(7)分隔行和分隔列划分为 4x4 共 16 个瓦片，每个瓦片内部为 2x2（共 4 个子格位置：左上、右上、左下、右下）。所有瓦片的默认填充为黑(0)背景。左上角的瓦片（第 0 行第 0 列瓦片）是"钥匙瓦片"，其 2x2 内部包含蓝(1)和黑(0)的图案（1~3 个蓝像素，其余黑色）。其余 15 个瓦片中，部分瓦片的某个子格位置放置了一个彩色端点标记像素（颜色从红(2)、绿(3)、黄(4)中选取），其余子格为黑(0)。同色端点标记可能分布在多个瓦片中，但每个瓦片最多有一个端点标记。生成约束：每种端点颜色至少有 2 个标记；同色标记至少有一对共享同一瓦片行或瓦片列且占据相同的子格位置；钥匙瓦片不包含端点标记。

**规则**：
1. 对钥匙瓦片（左上角瓦片）执行占用反转：蓝(1)像素变为黑(0)，黑(0)像素变为蓝(1)。反转后蓝(1)所在的子格位置标记为"激活"，黑(0)所在的子格位置标记为"未激活"。
2. 对每种端点颜色 C，找到所有颜色为 C 的端点标记，按其所在子格位置分组。
3. 在每个子格位置分组中：若该子格位置为"激活"，则对同一瓦片行中所有共享该子格位置的同色标记对，用颜色 C 填充它们之间每个中间瓦片的对应子格位置；对同一瓦片列中的同色标记对执行相同操作。若该子格位置为"未激活"，则不连线，标记保持原样。
4. 当同一子格位置有多对标记需要连线且路径重叠时，后绘制的颜色覆盖先绘制的。处理顺序：按端点颜色在输入中首次出现的行优先、列次优先的顺序处理。
5. 钥匙瓦片在输出中显示反转后的状态（蓝(1)和黑(0)互换后的图案）。

**关键洞察**：钥匙瓦片中看到的蓝色像素是连通掩码的反面——必须反转才能得到真正的激活通道。求解者可能直觉性地认为"蓝色子格 = 允许连线"，但实际上是"蓝色子格反转后为黑色 = 不允许连线"。这个反直觉规则必须通过对比多个示例中哪些端点被连线、哪些未被连线来归纳。
