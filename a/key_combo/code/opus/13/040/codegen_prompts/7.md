## 新题 7：逐侧标记计数决定线条图拉伸距离

**组合逻辑**：[计数](创新：按空间分区分别计数) → [拉伸 + 重绘](创新：拉伸量由计数结果决定而非标记位置) + [擦除]

**来源原语**：拉伸/重绘/边缘对齐控制点/控制像素/直角线条图（baf41dbf）、计数/频率匹配（2685904e）、擦除（952a094c）

**依赖链**：每侧的控制标记数量决定该侧的拉伸距离——这是扇出-扇入结构：四条独立的计数通道分别驱动四个方向的拉伸操作，所有拉伸共同作用于同一个线条图。去掉计数则拉伸量不确定；去掉拉伸则计数无用；去掉线条图则没有拉伸对象。

矩形线条图四侧外的控制标记数量分别编码了该侧的拉伸距离，线条图的外边框向外扩展相应格数后重绘连接线段。

**输入结构**：黑(0)背景网格，约 18x18。网格中心有一个蓝(1)一像素厚的直角线条图，形状为矩形框或十字形（由水平和垂直线段组成，4-连通，约 5x5 到 7x7）。线条图边界框的四侧外各散布若干红(2)单像素控制标记：每个标记距离线条图边界框对应边恰好 1 格（紧邻外侧），不同侧的标记数量不同（1-3 个）。四侧的标记数量互不相同。标记沿该侧的边均匀分布但具体位置不影响拉伸量。生成约束：网格足够大，使得所有方向的拉伸（最大 3 格）后线条图不超出网格边界。

**规则**：
1. 识别蓝(1)线条图和红(2)控制标记。
2. 计算线条图边界框四侧各有多少个红(2)控制标记：上侧 N_top 个，右侧 N_right 个，下侧 N_bottom 个，左侧 N_left 个。判断标记属于哪一侧的方法：标记行号小于线条图边界框最小行号且列号在边界框列范围内 → 上侧；标记列号大于边界框最大列号且行号在边界框行范围内 → 右侧；以此类推。若标记处于角落位置（同时满足两侧条件），归属行方向的侧（上或下）。
3. 线条图的上边框（最上方的水平线段）向上移动 N_top 格；下边框向下移动 N_bottom 格；左边框向左移动 N_left 格；右边框向右移动 N_right 格。
4. 移动后，重绘连接线段：所有原始垂直线段延伸到新的上下边界，所有原始水平线段延伸到新的左右边界。线段的列/行位置不变，只是长度延伸。
5. 擦除所有红(2)控制标记为背景(0)。

**关键洞察**：控制标记不是拉伸的目标位置（源题 baf41dbf 中标记直接标出目标边界），而是计数令牌——每侧的标记数量才是拉伸距离。必须对比不同示例中各侧标记数与对应拉伸结果的关系，才能发现"数量=距离"的编码规则。
