## 新题 2：框心对称门控填充与擦除

**组合逻辑**：[反射对称](创新：对称轴不再是对象自身中心或网格中心，而是外部容器框的中心线) → [填充 / 擦除](创新：同一对称测试的通过/失败分别触发相反的空间操作) → [重涂色](创新：擦除后在框心线位置绘制标记线)

**来源原语**：反射对称(reflection_symmetry, a8610ef7), 填充(fill, b7249182), 擦除(erase, e39e9282/184a9768), 矩形边框(rectangular_frame, 7ee1c6ea/890034e9), 框内区域(interior_region, 7ee1c6ea), 框内限定(frame_interior_only, 7ee1c6ea)

**依赖链**：对称测试的参考轴是框的中心线而非精灵体自身的对称轴，因此同一个精灵体在不同位置的框内可能得出不同结论。测试结果直接分叉为两条互斥路径（填充 vs. 擦除+标记），任何一条路径都不能在缺少测试结论的情况下执行。

检测每个框内精灵体相对于框竖直中心线的对称性：对称则将精灵体洪泛填充至整个框内部，不对称则擦除精灵体并在框的中心列画一条标记线。

**输入结构**：约 16x16 网格，黑(0) 背景。包含 3-4 个灰(5) 色的薄矩形框（1 像素厚边框），彼此不重叠不嵌套。每个框的内部区域（不含边框）至少 5x5。每个框内有一个由唯一颜色构成的 4-连通单色精灵体（3-8 像素），颜色取自 {蓝(1), 红(2), 绿(3), 黄(4)}，各框内精灵体颜色互不相同。部分精灵体恰好位于框内部的水平中心（相对于框的竖直中心线左右对称），部分精灵体偏向一侧。生成约束：至少有一个精灵体通过对称测试、至少有一个精灵体不通过，以确保两条路径都有可观察的示例。

**规则**：
1. 对每个框，计算其内部区域的竖直中心列 Cmid（若内部宽度为偶数，取左侧的那一列作为 Cmid）。
2. 对框内精灵体执行关于 Cmid 的竖直反射对称测试：将精灵体的每个像素 (r, c) 映射到 (r, 2*Cmid - c)，检查映射后的像素是否也属于该精灵体。所有像素都通过则判定"对称"，否则"不对称"。
3. 对称路径：用该精灵体的颜色洪泛填充框内所有背景像素（精灵体扩展至填满整个框的内部区域）。
4. 不对称路径：擦除框内精灵体的所有像素（置为背景色），然后沿 Cmid 列在框的整个内部高度范围内绘制一条红(2) 色的竖直标记线。
5. 所有框的灰(5) 边框像素始终保留不变。
6. 处理顺序：按框的左上角坐标从左到右、从上到下依次处理。

**关键洞察**：对称参考轴是框的几何中心而非精灵体自身的中心——一个自身完全对称的精灵体如果偏置于框内，仍会被判定为不对称而遭擦除。框既是空间容器又是对称判据的来源。

<description>
Move each marked cross object away from its marker to the grid edge while rotating the colored cross 180 degrees.

Input structure:
- The background is the dominant color.
- Each 8-connected foreground object has nine pixels: a 4-pixel marker-color
  sprite attached to a 5-pixel non-marker colored cross.
- Each object bbox is either 3x6 or 6x3, so the marker sprite is on exactly
  one side of the cross.

Rule:
- Move the whole object straight away from its marker side until the object
  bbox touches the corresponding grid edge.
- Keep the marker sprite unchanged within the object.
- Rotate the 3x3 colored cross block by 180 degrees before placing it.

Key insight:
The marker sprite is a directional tail; the cross is the leading payload,
and only that payload turns around during the slide to the edge.
