## 新题 4：外推穿越障碍的颜色状态机

**组合逻辑**：[等距共线外推](已有) → [碰撞检测](创新：碰撞不终止运动，而是触发颜色状态转移) → [重涂色](创新：重涂色的目标颜色由碰撞次数的状态序列决定)

**来源原语**：外推(extrapolate, 0b17323b), 等距共线(equally_spaced_collinear, 0b17323b), 碰撞阻挡(collision_blocking, 05f2a901), 障碍块(obstacle_block, e87109e9), 重涂色(recolor, 多题), 边界内延续(continue_within_bounds, 0b17323b)

**依赖链**：外推提供射线路径，障碍物位置将路径分割为段落，每个段落的颜色由已穿越的障碍数决定。去掉外推则无路径可分割；去掉障碍检测则无颜色变化点；去掉颜色状态序列则分割后的段落无法着色。三者形成不可简化的闭合依赖。

三个等距共线标记定义一条外推线，外推射线穿越障碍块时不停止但切换颜色，每穿过一个障碍颜色推进一级。

**输入结构**：约 16x16 网格，黑(0) 背景。包含 2-3 组等距共线标记，每组恰好 3 个相同颜色的像素，颜色取自 {蓝(1), 绿(3), 黄(4)}，各组颜色不同。3 个标记严格等距排列在一条直线上（可以是水平、垂直或 45 度对角线）。另有 1-3 个灰(5) 色的小障碍块（2x2 实心方块），散布在网格上。生成约束：每条外推射线在到达网格边界之前至少穿过 1 个障碍块，至多穿过 2 个，以确保颜色状态机有足够的可观察转换。不同组的外推射线路径互不相交。

**规则**：
1. 对每组 3 个同色标记，按行优先方向排序，计算相邻标记之间的步进向量 (dr, dc)。
2. 从第 3 个标记（行优先方向最末的标记）的下一个步进位置开始，沿 (dr, dc) 方向逐步绘制外推射线。
3. 射线初始颜色 = 该组标记的颜色。射线上的每个新像素按以下规则着色：
   - 若该像素位于背景上：用当前颜色绘制。
   - 若该像素位于障碍块上：不修改该像素（障碍块保持灰(5) 不变），但将当前颜色状态推进一级。
4. 颜色状态序列（按穿越障碍次数递增）：
   - 0 次穿越：标记原色
   - 1 次穿越后：红(2)
   - 2 次穿越后：品红(6)
5. 穿越障碍后的下一个背景像素开始使用新颜色。
6. 射线到达网格边界时停止（最后一个仍在网格内的背景像素被绘制）。
7. 原始标记像素保持不变。障碍块像素保持灰(5) 不变。
8. 不同组的射线独立处理，不相互影响。

**关键洞察**：障碍块在这里不是"墙"而是"变色门"——外推射线穿过它们时不改变方向也不停止，只改变颜色状态。射线变成了一条分段着色的路径，每段的颜色编码了该段之前穿越了多少个障碍。
