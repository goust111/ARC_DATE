## 新题 4：异常值块图案成为平铺种子

**组合逻辑**：[计数/异常值提取](已有) + [平铺/周期重复](已有)（创新：异常值不是直接裁剪输出，而是被转化为平铺种子传播到独立的目标区域；孔洞结构从筛选特征变为视觉纹理）

**来源原语**：计数/counting ← 358ba94e；背景孔洞/background_hole ← 358ba94e；异常值提取/outlier_extraction ← 358ba94e；孔洞数量唯一/unique_hole_count ← 358ba94e；平铺/tile ← 9b30e358；周期重复/periodic_repeat ← 9b30e358；填满网格/fill_grid ← 9b30e358

**依赖链**：多个同形块中必须先通过孔洞计数识别异常值→异常值块的完整图案（包括其孔洞位置结构）成为平铺种子→种子被重复铺满独立的目标区域。改变异常值的判定意味着改变平铺内容，两步紧密耦合。

在多个相同大小的前景块中找出孔洞数量独特的异常块，将其完整图案平铺填满下方的目标区域。

**输入结构**：
- 黑(0)背景网格，约 20x25。
- 上半区包含 4~6 个大小相同的正方形前景块（如 5x5），颜色相同（如红(2)）。块之间互不接触，且不接触网格边界。每个块的边框为实心前景色，内部（3x3 区域）包含若干背景(0)像素作为孔洞，孔洞数量和位置各块不同。
- 恰好一个块的孔洞数量与其他所有块的孔洞数量都不同（异常值）。其余块的孔洞数量至少有一个重复伙伴（例如 4 个块的孔洞数分别为 2, 3, 2, 5，则 5 和 3 各出现一次，但 3 也只出现一次——需保证仅有一个唯一值。更严格地：其余块中每个孔洞数至少出现两次）。
- 下半区有一个由灰(5)单像素厚边框围成的大矩形目标区域，内部为黑(0)背景。目标区域内部尺寸（高 x 宽）是前景块尺寸（5x5）的整数倍，如 10x15（即 2x3 个块的大小）。
- 生成约束：恰好一个块为异常值；目标区域内部尺寸是块尺寸的正整数倍；上半区的块按从左到右、从上到下的顺序排列。

**规则**：
1. 对每个前景块，计算其内部区域（边框以内的 3x3 区域）中背景(0)像素的数量。
2. 找出孔洞数量在所有块中唯一出现（仅此一块具有该数量）的前景块，即异常值。
3. 裁剪该异常块为 5x5 图案（保留其前景色边框和内部孔洞结构）。
4. 将该 5x5 图案作为瓦片，从目标区域内部左上角开始，按从左到右、从上到下的顺序逐块复制，直到完全填满目标区域内部。
5. 保留灰(5)目标区域边框不变。上半区所有前景块保留原样。输出网格尺寸不变。

**关键洞察**：异常值的判定依赖于对比所有块的孔洞计数——不是固定阈值，每道题的异常值数量都不同。被选中的块不是简单裁剪输出（如参考题 358ba94e），而是成为空间传播的种子——块内的孔洞结构（原本仅作为筛选特征）成为平铺后的视觉纹理内容。
