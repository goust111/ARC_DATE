## 新题 6：周期偏差像素揭示隐藏图案

**组合逻辑**：[周期瓦片/最小周期推断](已有) + [重涂色](已有) + [擦除/补全](已有)（创新：周期分析不用于修复缺口，而用于检测与周期不一致的偏差像素；偏差像素不是要清除的噪声，而是隐藏信息的载体——概念完全反转）

**来源原语**：周期瓦片/periodic_tile ← e95e3d8e；周期对齐/periodic_align ← e95e3d8e；最小周期修复缺口/min_period_repair_gap ← e95e3d8e；重涂色/recolor ← ce039d91；擦除/erase ← 7f4411dc

**依赖链**：必须先从多数一致的像素中推断最小周期瓦片→用周期预期值逐像素比对全网格→区分两类异常：缺口（黑色像素）需要用周期值修复，偏差（非黑但与周期不符的像素）需要标记为新颜色→偏差像素的位置集合构成嵌入在周期载体中的隐藏图案。周期推断和偏差检测互相依赖——偏差太多会干扰推断，因此题目保证偏差占比低。

在一个近似周期的彩色网格中，推断最小周期、修复黑色缺口、并将不符合周期的偏差像素统一涂为蓝色以揭示隐藏图案。

**输入结构**：
- 网格约 12x12，完全填满（无背景边框区域，每个像素都有颜色）。
- 大多数像素（85%~90%）服从一个 2x2 或 2x3 的最小矩形周期瓦片，瓦片使用 2~3 种颜色（如红(2)、绿(3)、黄(4)）。
- 少量像素（约 10%~15%）的颜色被故意替换为与周期预期不同的合法颜色（仍为 0~9 中的某个值，但不是该位置周期应有的颜色，且非黑(0)色）。这些偏差像素的位置集合构成一个可辨识的 4-连通或近连通图案（如一条折线、一个简单封闭形状等）。
- 另有少量黑(0)像素（约 5%）作为缺口——这些位置的原始周期颜色被移除了（与偏差不同：缺口是"丢失数据"，偏差是"替换数据"）。
- 生成约束：偏差像素占比不超过 15%，确保从多数像素中可唯一确定周期瓦片；偏差像素的替换颜色与该位置的周期预期颜色不同且非黑色；缺口像素为黑(0)且不与偏差像素相邻（避免混淆）；蓝(1)不作为周期瓦片的颜色使用（留给输出标记）。

**规则**：
1. 从所有非黑像素中推断最小矩形周期瓦片（行周期 pH、列周期 pW）：对每个残差类 (r mod pH, c mod pW)，该类中出现次数最多的颜色为周期预期颜色。
2. 对每个黑(0)像素（缺口），用其残差类的周期预期颜色填充。
3. 对每个非黑像素，比对其颜色与残差类周期预期颜色：
   - 若一致，保持不变。
   - 若不一致，将该像素重涂为蓝(1)。
4. 输出网格尺寸不变。

**关键洞察**：参考题 e95e3d8e 中只有一类异常（黑色缺口），修复缺口即可完成任务。这里存在两类异常——缺口（缺失数据，需修复）和偏差（替换数据，需标记），必须区分对待。偏差像素的位置本身是答案的核心——它们不是噪声而是故意嵌入周期载体中的隐藏信号。解题者需要先"看穿"周期才能发现隐藏内容。
