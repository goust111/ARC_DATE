## 新题 1：邻接清洗后标记定向平铺

**组合逻辑**：[擦除/邻接过滤](已有) + [平铺/周期重复](已有) + [标记定方向](创新组合：标记编码平铺方向而非压缩方向)

**来源原语**：擦除/erase ← 7f4411dc；邻接/adjacency ← 7f4411dc；邻接不足则删除/delete_unsupported ← 7f4411dc；平铺/tile ← 9b30e358；周期重复/periodic_repeat ← 9b30e358；填满网格/fill_grid ← 9b30e358；边缘标记/edge_marker ← 5e6bbc0b；标记定方向/marker_sets_dir ← 5e6bbc0b

**依赖链**：噪声像素与图案像素同色，只能通过邻接支撑度区分——清洗改变了种子母题的内容。清洗后的图案才是真正的种子，而种子的平铺方向由远端标记像素的位置暗中编码。三个环节缺一不可：无清洗则平铺传播噪声，无标记则平铺方向不确定，无平铺则清洗后的图案没有用途。

在边缘图案带中清除邻接支撑不足的噪声像素，再沿标记所指方向将清洁图案平铺到全网格。

**输入结构**：
- 黑(0)背景网格，约 15x15。
- 四条边中的某一条（上/下/左/右）的相邻 3~5 行（或列）被一种非黑前景色（如绿(3)）填充形成图案带。图案带中包含背景色(0)间隙，构成周期性母题。
- 图案带中混入若干同色（绿(3)）孤立噪声像素。噪声像素的 4-邻域中同色像素不超过 1 个，而图案结构像素的同色 4-邻居至少为 2 个。
- 在与图案带相对的那条边上，有一个青(8)标记像素，标示平铺方向（从图案带向标记所在边平铺）。
- 生成约束：图案带所在边与标记所在边不同且相对；图案带去噪后的厚度（行数或列数）能整除网格在平铺方向上的跨度；噪声像素仅出现在图案带内，不出现在其他区域。

**规则**：
1. 对图案带中的每个前景像素，计算其 4-邻域中同色像素的数量。保留拥有至少 2 个同色 4-邻居的像素，将不足 2 个的像素设为黑(0)。
2. 清洗后的图案带（包括其中的背景间隙）即为种子母题。
3. 确定平铺方向：从图案带所在边指向青(8)标记所在边。
4. 沿该方向将种子母题逐段复制，每段保持行（或列）内容不变，仅在垂直于图案带的方向上平移，直到填满整个网格。
5. 移除青(8)标记像素（设为黑(0)）。输出网格尺寸与输入相同。

**关键洞察**：噪声像素与图案像素共享同一颜色，无法通过颜色区分——只有局部邻接支撑度才能把它们分开。平铺方向则由远离图案带的标记像素暗中编码，需对比多个示例（图案带在不同边、标记在对应的相反边）才能归纳出方向规则。
