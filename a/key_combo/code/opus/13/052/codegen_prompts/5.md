## 新题 5：连通体像素数索引图例选择操作类型

**组合逻辑**：[连通分量检测](已有) + [计数](已有，创新：计数结果不压缩为输出宽度，而是索引操作类型) → [固定图例/位置对应颜色](已有，创新：图例编码的不是缺失位补色，而是操作类型的着色参数) → [印章覆盖 | 描边 | 填充](已有，创新：三种操作按索引分支执行)

**来源原语**：连通分量检测（9720b24f, 84db8fc4）；计数（d631b094）；固定图例、位置对应颜色（a834deea）；印章覆盖、中心展开（b60334d2）；描边（95990924）；填充（4a1cacc2）；对角邻接（95990924, 396d80d7）

**依赖链**：必须先检测连通体并计数才能索引图例→图例颜色决定装饰用色→像素数又决定执行哪种操作（印章/对角光晕/边界框轮廓/边界框填充）。图例提供颜色，计数提供操作类型，两者缺一不可。

统计每个灰色前景连通体的像素数，用该数值索引一个 2x2 颜色图例，选出颜色后对该连通体执行与像素数对应的特定几何装饰。

**输入结构**：约 15x15 网格，黑(0)背景。右上角有一个 2x2 的颜色图例，四个位置分别为：左上=蓝(1)，右上=红(2)，左下=绿(3)，右下=黄(4)。图例与其余内容之间至少隔 2 行 2 列的黑色间距。网格剩余区域散布 4~6 个灰(5)的 4-连通前景对象，像素数分别为 1、2、3 或 4（每种像素数至少出现一次）。每个对象的边界框外至少有 2 格黑色空余。对象形状不固定：1 像素即孤立点；2 像素为任意相邻的两格；3 像素为任意 4-连通的三格形态（非固定形状）；4 像素为任意 4-连通的四格形态。生成约束：不同对象的边界框互不重叠（含 2 格间距）。

**规则**：
1. 找出所有 4-连通的灰(5)前景对象，统计每个对象的像素数 N。
2. 按 N 索引 2x2 图例的颜色：N=1 → 图例左上色（蓝(1)），N=2 → 图例右上色（红(2)），N=3 → 图例左下色（绿(3)），N=4 → 图例右下色（黄(4)）。
3. 按 N 执行对应的几何操作，使用索引到的颜色 C：
   - N=1：在该像素的上下左右四个正交邻居位置涂色 C。中心像素保持灰(5)。
   - N=2：找出该对象所有"仅对角邻接"的背景像素（与对象像素有对角邻接但无正交邻接的黑色像素），涂色 C。对象像素保持灰(5)。
   - N=3：计算对象的边界框，在边界框的轮廓像素位置涂色 C，但与对象重合的轮廓位置保持灰(5)不变。
   - N=4：计算对象的边界框，将边界框内部所有像素（包括对象像素自身）涂色 C，对象像素被覆盖。
4. 图例像素保持不变。

**关键洞察**：对象像素数同时决定两件事——查表获取颜色和选择几何操作类型。这是一个多分支结构而非线性流水线：不同大小的对象走完全不同的变换路径，需要对比含有不同大小对象的多个示例才能归纳出完整的分支规则。
