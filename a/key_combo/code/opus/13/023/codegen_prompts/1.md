## 新题 1：L 标记编码区域重力方向

**组合逻辑**：[检测/朝向对应角](将 L 朝向从"选择外角"创新为"编码重力方向") + [重力下落](从全局统一方向创新为按区域独立方向) + [擦除](清除方向标记)

**来源原语**：朝向对应角/facing_corner（b745798f）、角落标记/corner_marker（b745798f）、重力下落/gravity_drop（88e364bc）、封闭区域/enclosed_region（88e364bc/00d62c1b）、碰撞停止/collision_stop（88e364bc）、擦除/erase（1a07d186）

**依赖链**：L 标记的朝向决定该区域的重力方向 → 重力方向决定可移动像素的滑动轨迹 → 区域边界决定碰撞停止位置。三者缺一不可：不解码朝向则方向未知；不识别区域则碰撞边界不存在；不施加重力则无变换。

将封闭区域内的 L 标记朝向解码为重力方向，驱动同区域内的散落像素沿该方向滑动堆叠，然后擦除标记本身。

**输入结构**：约 13x13 的网格，黑(0)背景。灰(5)线段将网格分隔为 3~4 个互不连通的矩形封闭区域（灰线宽 1 像素，构成完整的矩形隔墙）。每个区域内部包含：(a) 恰好一个单色 4-连通 3 像素 L 形标记（占据 2x2 边界框的三个格子），颜色为红(2)；(b) 1~3 个散落的单像素，颜色各异（从蓝(1)、绿(3)、黄(4)、橙(7)中选取），不与 L 标记相邻。不同区域内的 L 标记朝向不同（四种朝向至少出现两种）。生成约束：每个区域至少 4x4 大小，散落像素在其重力方向上有足够空间滑动至少 1 格。

**规则**：
1. 识别灰(5)隔墙围成的所有矩形封闭区域。
2. 在每个区域中定位红(2) L 标记，确定其朝向。L 标记占据 2x2 框的三格，空缺格的位置即为 L 的"开口方向"。重力方向的映射规则为：开口朝右下 → 重力向左上；开口朝左下 → 重力向右上；开口朝右上 → 重力向左下；开口朝左上 → 重力向右下。即重力方向与开口方向相反，沿 45 度对角线。
3. 擦除该区域内的红(2) L 标记（置为黑(0)背景）。
4. 将该区域内所有非背景、非隔墙的散落像素沿重力方向的两个分量依次滑动：先沿垂直分量滑动直到碰到隔墙或区域边界或另一像素，再沿水平分量滑动直到碰到隔墙或区域边界或另一像素。处理顺序：沿重力方向，距目标角最远的像素先处理。
5. 灰(5)隔墙保持不变。

**关键洞察**：L 标记不是装饰而是方向编码器——其开口方向的反向即为区域重力。需要对比多个示例（不同朝向、不同区域）才能归纳出开口方向与重力方向之间的反向映射规则。
