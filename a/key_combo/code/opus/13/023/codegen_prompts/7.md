## 新题 7：等差间距补全横竖条后在交叉点标记特殊颜色

**组合逻辑**：[补全/等差递推](保留原逻辑，补全缺失的条) → [重涂色/交叉区换前景色](将"两色交叉互换"创新为"交叉点统一标记为第三种颜色") + [描边/交叉邻域环涂色](将"环形描边"创新为"交叉点单像素重涂")

**来源原语**：补全/completion（f8c80d96）、等差递推/arithmetic_progression（f8c80d96）、等差序列/arithmetic_sequence（f8c80d96）、满行列条/full_span_bar（1a07d186）、交叉/crossing（ba97ae07）、重涂色/recolor（ba97ae07）、横条/h_bar（ba97ae07）、竖条/v_bar（ba97ae07）、交叉点/crossing_point（67a423a3）

**依赖链**：识别现有条的等差间距 → 补全缺失条 → 完整条网络产生所有交叉点 → 交叉点被重涂为第三种颜色。补全步骤改变了交叉点的数量和位置——缺失条被补全后产生的新交叉点是仅凭原始输入无法预测的。

识别横条和竖条位置的等差规律，补全缺失的条，然后将所有交叉像素重涂为黄色。

**输入结构**：约 15x15 的网格，黑(0)背景。包含若干贯穿全宽的蓝(1)水平条（宽 1 像素）和若干贯穿全高的红(2)垂直条（宽 1 像素）。水平条的行位置构成一个等差数列（公差 d_h >= 2），但其中 1~2 个成员缺失。垂直条的列位置构成另一个等差数列（公差 d_v >= 2），其中也有 1~2 个成员缺失。现有的横竖条交叉处显示的颜色为蓝(1)或红(2)之一（取决于绘制顺序，但这不影响输出）。生成约束：水平条至少出现 3 个（缺失前至少 4 个成员）；垂直条至少出现 3 个（缺失前至少 4 个成员）；等差数列的首末成员均存在（便于推断公差）。

**规则**：
1. 分别收集所有蓝(1)水平条的行坐标和所有红(2)垂直条的列坐标。
2. 对行坐标序列，求相邻差的最大公约数作为公差 d_h，确定完整的等差数列范围（以最小行坐标为首项、最大行坐标为末项），补全所有缺失的行——在缺失行位置绘制蓝(1)贯穿全宽的水平条。
3. 对列坐标序列同理，求公差 d_v，补全缺失的红(2)垂直条。
4. 在补全后的完整网格中，所有横条与竖条交叉的像素（即同时属于某条水平条和某条垂直条的像素）统一重涂为黄(4)。
5. 非交叉的条像素保留原色（蓝或红）。

**关键洞察**：补全步骤不是简单的"画更多线"——它通过等差推断产生了额外的交叉点。输出中黄(4)标记的数量 = 完整横条数 x 完整竖条数，而不是原有可见交叉数。需要多个示例（不同的缺失位置和公差）来确认等差补全规则和交叉标记规则是联动的。
