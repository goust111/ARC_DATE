## 新题 6：逐行跨度填充揭示面积，按面积排序后紧凑堆叠

**组合逻辑**：[填充/逐行跨度填充](保留原逻辑，将稀疏轮廓变为实心) → [排序/位置排序](将"按位置排序"创新为"按填充后面积排序") → [堆叠/对齐紧凑排布](保留原逻辑) + [裁剪](提取各形状的最小边界框)

**来源原语**：填充/fill（22168020）、逐行跨度填充/row_span_fill（22168020）、行内边界配对/row_boundary_pairing（22168020）、轮廓线/outline（22168020）、堆叠/stacking（4acc7107）、排序/sorting（4acc7107）、对齐紧凑排布/aligned_compact_layout（4acc7107）、裁剪/crop（662c240a）、单色前景对象/monochrome_foreground_object（4acc7107）

**依赖链**：逐行跨度填充将稀疏轮廓变为实心形状 → 实心面积（像素计数）成为排序键 → 排序决定堆叠顺序 → 裁剪+堆叠产生最终输出。填充步骤的结果直接决定排序结果——如果不执行填充，轮廓像素数量接近而面积差异大的形状会被错误排序。

将每个稀疏对角线轮廓按行边界对填充为实心，然后按填充后面积从小到大裁剪并垂直堆叠在输出底部。

**输入结构**：约 12x18 的网格（12 列 18 行），黑(0)背景。包含 3~4 个单色 8-连通轮廓，每个轮廓在其占据的每一行恰好有 2 个前景像素（左右边界对），形成类似菱形或梯形的斜边轮廓。不同轮廓使用不同颜色（蓝(1)、红(2)、绿(3)、橙(7)），轮廓之间不重叠（行范围可重叠，但列范围不重叠）。不同轮廓的行跨度不同、宽度不同，因此填充后面积各不相同。生成约束：至少有两个轮廓的边界像素总数接近（差 <= 2），但填充后面积差异明显（差 >= 5），以确保必须填充才能正确排序。

**规则**：
1. 对每个轮廓，逐行找到该行的两个边界像素，将它们之间（含端点）的所有像素涂为该轮廓的颜色，得到实心形状。
2. 计算每个实心形状的面积（前景像素总数）。
3. 按面积从小到大排序。面积相同时，按原始最上方行号从小到大排序（行号小的排前面）。
4. 将排好序的形状依次裁剪为最小边界框。
5. 在与输入同宽的输出网格中，从底部向上依次放置裁剪后的形状：面积最大的贴底、面积最小的在最上方。每两个相邻形状之间留 1 行黑(0)间隔。所有形状左对齐（边界框左边缘对齐到输出网格第 0 列）。输出高度 = 所有裁剪后形状高度之和 + (形状数 - 1) 行间隔。

**关键洞察**：稀疏轮廓隐藏了真实面积——两个轮廓的边界像素数量可能接近，但填充后面积差异很大（一个窄高、一个矮宽）。排序键是填充后面积而非边界像素数或边界框面积。需要对比多个示例才能确认面积而非其他几何量是排序依据。
