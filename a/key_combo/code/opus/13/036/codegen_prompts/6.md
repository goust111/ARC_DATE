## 新题 6：残缺精灵互补合并确定完整模板，跨车道数量守恒转移

**组合逻辑**：[补全·对齐合并取并集·各副本互补缺失](已有) → [移动·数量守恒](创新：转移的精灵形状由合并步骤动态确定而非预存) + [重涂色](已有) -- 残缺副本同时编码模板形状和转移数量（双重角色对象）

**来源原语**：补全+部分图案+模板掩码+对齐合并取并集+各副本互补缺失(f8cc533f), 移动+精灵体+标记条+车道+最近配对+数量守恒(9aaea919), 重涂色(9aaea919)

**依赖链**：红(2)车道中的部分精灵互相补充 → 对齐合并得到完整模板（形状信息） → 同时统计每条红车道中的副本数量（数量信息） → 完整模板决定转移到绿(3)车道的精灵形状，副本数量决定转移的个数 → 红车道原有精灵重涂为灰(5)。删除合并步骤则不知完整形状（无法正确绘制转移的精灵）；删除数量统计则不知放几个；删除车道配对则不知往哪放。

红色标记车道中散布着互补的残缺精灵副本；将它们按左上对齐取并集得到完整模板后，以完整形状转移到最近的绿色标记车道中，转移数量等于源红车道中残缺副本的个数，源副本重涂为灰色。

**输入结构**：
- 黑(0)背景矩形网格，约 16~22 行、18~24 列。
- 网格中有若干条垂直车道。每条车道由其左侧 1 像素宽、贯穿网格全高的标记条定义：红(2)标记条标识源车道，绿(3)标记条标识目标车道。每条车道宽 4~6 列（不含标记条本身）。车道之间有 1~2 列黑(0)间隔。共 2 条红车道、2 条绿车道，按红-绿交替排列（如从左到右：红、绿、红、绿）。
- 每条红(2)车道内包含 2~3 个同色的精灵副本（颜色为橙(7)），在车道内等间距垂直排列（相邻副本的包围框顶边间距固定）。每个副本是同一精灵模板的**部分版本**——模板是一个 4-连通的不规则形状（约 3x3 至 4x4 像素，5~10 个前景像素），每个副本缺失了模板中的 1~3 个像素位置（对应位置为黑(0)）。同一红车道内不同副本缺失的位置不同。所有红车道中全部副本的并集恰好覆盖完整模板的全部像素位置（互补缺失）。
- 每条绿(3)车道内当前为空（全黑(0)）。绿车道的垂直格点间距与最近的红车道相同。每条绿车道从底部起至少有与配对红车道副本数量相同的空格点位置。
- 生成约束：不同红车道中的副本数量可以不同（如左红车道 3 个、右红车道 2 个）。所有红车道中的精灵副本颜色相同（橙(7)）。每条红车道配对距离最近的绿车道（按标记条列坐标差的绝对值，若两侧等距则取右侧绿车道）。

**规则**：
1. 对所有红(2)车道中的全部精灵副本，逐个裁剪到各自的最小包围框。将所有裁剪后的副本按左上角对齐；若不同副本的包围框尺寸不同，则填充到最大高度和最大宽度（左上角对齐，填充位为黑(0)）。对所有填充后的副本逐像素取并集：任一副本在该位置有前景色(橙(7))则结果为前景色，得到完整模板 T。
2. 对每条红(2)车道，统计其中的精灵副本数量 N。找到该红车道最近的绿(3)车道（按标记条列坐标差绝对值最小的；若两侧等距则取右侧）。
3. 在配对的绿(3)车道中，从底部第一个格点位置开始向上，依次放置 N 个完整模板 T 的副本。副本颜色为橙(7)（与源车道精灵颜色相同）。相邻副本间距与红车道中原有副本的间距相同。每个副本的左上角与格点对齐。
4. 将所有红(2)车道中原有的精灵副本像素重涂为灰(5)。
5. 移除所有标记条：红(2)和绿(3)标记条像素变为黑(0)。

**关键洞察**：红车道中的残缺副本承担双重角色——它们的**形状信息**互补合并后决定"转移什么形状"，它们的**数量**决定"转移几个"。这两条信息编码在同一组对象中，求解者必须同时从残缺副本中提取形状和数量两种属性。单个示例中可能所有红车道恰好副本数相同，需对比多个示例（不同红车道副本数不等的情况）才能确认数量守恒规则而非"每条绿车道固定放 N 个"。
