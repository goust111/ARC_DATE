## 新题 1：弹射路径分割区域，标记色编码面积摘要

**组合逻辑**：[射线延伸·边界反射](创新：弹射路径作为动态分割墙壁而非仅重涂背景) → [计数·封闭背景区域](创新：封闭区域由路径动态创建而非预存于对象内部) → [压缩·顺序排列](已有)

**来源原语**：射线延伸+反弹路径+边界反射(e179c5f4), 计数+封闭背景区域+孔洞面积决定输出(8ba14f53), 标记像素+同色对应(a2d730bd), 压缩+顺序排列(8ba14f53)

**依赖链**：弹射路径的几何轨迹决定了区域的边界形状 → 区域边界决定了每个标记所属区域及其面积 → 面积数值和标记颜色共同决定输出的行填充内容。删除路径步骤则无法确定区域划分；删除计数步骤则无法得到面积；删除标记则无法将区域与颜色关联。

将起点像素的弹射对角路径作为墙壁，把网格切分为封闭区域；每个区域内的标记像素颜色和区域面积被压缩为紧凑行填充输出。

**输入结构**：
- 黑(0)背景矩形网格，约 12~16 行、8~12 列。
- 网格底边某列有一个蓝(1)起点像素。从起点出发，一条蓝(1)对角弹射路径已绘制在网格上：路径每步沿对角线移动（行-1，列+1 或列-1），遇网格左右边界时水平方向反转，路径到达顶边（行=0）时终止。所有路径经过的像素均为蓝(1)。
- 2~4 个孤立的单像素标记，颜色各不相同（从红(2)、绿(3)、黄(4)、灰(5)中选取），散布在网格内部的黑(0)位置上。
- 生成约束：每个标记不与蓝(1)路径像素重合；蓝(1)路径与网格四边共同将网格内部划分为若干 4-连通封闭区域，每个标记恰好落在一个区域内且不同标记落在不同区域中；每个含标记的区域中黑(0)像素数量在 1~9 之间。

**规则**：
1. 识别蓝(1)路径像素和网格四边共同构成的边界。将路径像素和网格外部均视为不可通行墙壁。
2. 从每个标记像素出发，用 4-连通洪水填充找到其所在的封闭区域。统计该区域中黑(0)像素的数量（不含标记像素自身，不含蓝(1)路径像素）。此数量记为该标记的"面积值"。
3. 构造输出网格，宽度固定为 3 列。按标记像素在输入中的**列坐标从小到大**排序（列坐标相同时按行坐标从小到大）。对排序后的每个标记，在输出的当前行起从左到右逐格填入该标记颜色的像素，共填入"面积值"个像素。一行填满 3 格后换到下一行继续。一个标记的像素填完后，下一个标记从**新行**开始（不与前一个共享行），未填完的行的剩余格填黑(0)。

**关键洞察**：弹射路径不是视觉装饰——它是将网格动态切分为封闭区域的墙壁，标记像素不标识路径方向而是标识区域归属。输出中标记的排列顺序由其列位置决定，需对比多个示例才能排除"按颜色编号排序"或"按面积大小排序"等备选假说。

Paint yellow the background cells on the unobstructed shortest monotone corridor between two doorway frames.

Input structure
- The grid has a background, two small frame objects in one foreground color, and one center marker in each frame.
- Each marker has exactly one background 4-neighbor, the doorway gap; the next cell outward is the exterior doorway cell.

Rule
- Treat all existing foreground cells as blockers.
- Between the two exterior doorway cells, allow only row/column steps that move toward the other exterior cell.
- Paint every background cell that lies on some such path from one exterior cell to the other, plus the two doorway gaps, yellow.

Key insight
- The output is not a single chosen route: it is the union of all shortest monotone paths that can pass between the two frames.
