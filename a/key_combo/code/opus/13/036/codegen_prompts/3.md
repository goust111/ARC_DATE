## 新题 3：边框色定向重力沉降，接触边框处生长端帽

**组合逻辑**：[滑动·颜色匹配边](创新：从单步移动扩展为完整重力沉降，四个方向并存) + [射线延伸·端帽](创新：端帽由沉降后的单像素在边框接触面生长而非由矩形生长) -- 两操作通过"是否接触边框"的空间条件耦合

**来源原语**：滑动+重力沉降+列内独立(1e0a9b12), 边框边+内部像素+颜色匹配边+朝匹配边移动(5034a0b5), 射线延伸+端帽+轴线对齐(a2d730bd), 画布边界(496994bd)

**依赖链**：边框四边颜色决定每个内部像素的滑动方向 → 滑动距离和最终位置取决于同方向其他像素的堆叠顺序 → 只有直接接触边框的像素才触发端帽生长 → 端帽方向由像素滑动方向的垂直方向决定。删除颜色匹配则不知滑动方向；删除重力沉降则不知最终位置；删除接触检测则不知哪些像素生长端帽。

内部像素按颜色匹配边框侧边的方向做完整重力沉降（四个方向并存），沉降后直接接触边框的像素在边框表面生长 3 像素宽的垂直端帽。

**输入结构**：
- 黑(0)背景矩形网格，约 11~15 行、11~15 列。
- 最外一圈为 1 像素宽的矩形边框。四个角像素为黑(0)。上边为红(2)、下边为绿(3)、左边为蓝(1)、右边为黄(4)（具体颜色分配可能因示例而异，但每条边自身纯色且四边互不同色）。
- 边框内部（去掉边框后的矩形区域）以黑(0)为底色，散布 6~12 个前景像素。每个前景像素的颜色恰好等于四条边框边中某一条的颜色。
- 生成约束：对于向上或向下滑动的像素，同一列中同方向像素不超过 3 个；对于向左或向右滑动的像素，同一行中同方向像素不超过 3 个——以防堆叠后溢出内部区域。不同方向的像素在沉降过程中路径不交叉（生成时保证无冲突）。

**规则**：
1. 确定边框四边的颜色分配。对每个内部前景像素，找到颜色相同的边框边，该边所在方向即为此像素的滑动方向（上边→向上滑，下边→向下滑，左边→向左滑，右边→向右滑）。
2. 对四个方向独立处理各自的像素群。在每个方向内：按像素到目标边框的距离从小到大排序，距离近的先处理。每个像素沿滑动方向逐格移动，直到下一格是边框像素或已停止的同方向像素为止，在当前格停止。
3. 沉降完成后，检查每个已停止像素是否与边框像素 4-连通相邻（即紧贴边框）。对每个紧贴边框的像素，生长端帽：沿边框表面方向（即垂直于该像素滑动方向），以该像素为中心向两侧各延伸 1 个像素，共 3 个像素宽。这 3 个端帽像素绘制在**边框所在的行或列上**（即覆盖对应的边框像素），颜色与该内部像素相同。若端帽超出网格边界则截断。
4. 若两个端帽在同一边框像素位置重叠，保留**离该边框侧边的中点更近**的那个像素的颜色（即在边框边上更靠中央位置的端帽优先；若距中点相等则保留先处理方向的——处理顺序为上、右、下、左）。
5. 未紧贴边框的像素（被其他像素挡住停在内部的）保持在沉降后位置不变，不生长端帽。

**关键洞察**：重力方向不是全局统一的，而是由像素颜色与边框侧边的匹配关系逐像素决定——同一网格中四个方向的"重力"同时作用。端帽仅在像素直接接触边框时才生长，被堆叠挡住的内层像素不生长端帽。此规则需对比多个示例中不同堆叠深度（单像素 vs 多像素堆叠）的情况才能归纳。
