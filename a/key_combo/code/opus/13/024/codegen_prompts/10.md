## 新题 10：裁剪最大连通分量后以其轮廓做相位平铺

**组合逻辑**：[裁剪/面积选择](创新：裁剪出的对象不直接输出，而是被分析其轮廓结构以提取相位编码) + [平铺/相位编码](创新：相位模式不来自独立的字形输入，而来自裁剪对象的轮廓)

**来源原语**：裁剪(crop) ← be94b721；平铺(tile) ← eee78d87；解码(decode) ← eee78d87；连通分量(connected_component) ← be94b721；轮廓字形(contour_glyph) ← eee78d87；周期格点(periodic_lattice) ← eee78d87；面积比较(area_comparison) ← be94b721；选取最大面积对象(largest_area_selected) ← be94b721；相位编码(phase_encoding) ← eee78d87

**依赖链**：裁剪选出最大连通分量并提取其边界框内容，该内容作为平铺操作的"模板图案"——不裁剪则不知道用什么图案平铺，不平铺则裁剪结果没有最终用途。裁剪结果的几何形状直接决定平铺的周期和相位，两步逻辑通过"模板图案"这一中间表示紧密关联。

从多个前景对象中按面积选出最大者并裁剪，将裁剪结果的二值掩码作为周期平铺模板，铺满目标画布并以指定颜色着色。

**输入结构**：约 16x16 的网格，背景为黑(0)。网格上有 3~5 个互不相连的单色 4-连通前景对象，颜色各不相同（从红(2)、蓝(1)、绿(3)、黄(4)、灰(5)中选取），面积（像素数）互不相同。最大面积对象的边界框为 3x3 或 4x4，其形状是一个具有清晰轮廓的小型图案（如中空的方形轮廓、十字轮廓、对角线等——具体形状不固定，由生成决定）。其余较小对象为干扰项。在网格的某个角落有一个单独的栗(9)像素，标记输出的着色色。生成约束：最大面积对象的边界框尺寸能整除目标输出尺寸（输出尺寸为 12x12 或 16x16，保证可被 3 或 4 整除）。

**规则**：
1. 找到所有 4-连通单色前景连通分量，计算各自像素面积。
2. 选出面积最大的唯一连通分量，裁剪其边界框得到一个 kxk 的二值模板（对象像素为 1，背景像素为 0），其中 k = 3 或 4。
3. 读取栗(9)标记像素确定输出着色色为栗(9)。
4. 创建一个边长为 12（若 k=3）或 16（若 k=4）的黑(0)输出画布。
5. 将 kxk 二值模板以周期 k 在输出画布上平铺（水平和垂直方向均重复），模板中值为 1 的位置涂为栗(9)，值为 0 的位置保持黑(0)。
6. 干扰对象和标记像素不出现在输出中。

**关键洞察**：最大连通分量不是"答案"而是"密码"——它的几何轮廓编码了平铺模板的形状。干扰对象的面积提供了排除依据，而栗色标记像素看似无关却决定了输出的颜色。求解者必须跨越"选择→解码→生成"三个层次才能理解输入到输出的完整映射。
