## 新题 6：连线段长度编码同心框层参数

**组合逻辑**：[连线/跨度填充](创新：连线结果不作为最终输出，而是产生具有可测量属性——长度——的中间几何体) → [嵌套包裹](创新：框的厚度和层序不来自色条高度，而来自连线段的长度属性)

**来源原语**：连线(connect) ← ded97339；嵌套包裹(nested_wrapping) ← 45a5af55；标记像素(marker_pixel) ← ded97339；同心正方形层(concentric_square_frame) ← 45a5af55；首尾跨度填充(span_fill_between) ← ded97339；逐层构建(layer_by_layer_build) ← 45a5af55；行列对齐(row_col_alignment) ← ded97339；条高决定框厚(stripe_height_as_thickness) ← 45a5af55

**依赖链**：连线操作生成若干线段，线段的长度成为嵌套包裹操作的厚度参数，线段的颜色成为框的颜色——连线是计算框参数的手段，嵌套包裹是消费这些参数的目标操作。没有连线就无法获得厚度信息，没有嵌套包裹则线段长度就是一个未被利用的属性。

将同色标记对连线产生的线段长度，转化为同心正方形框的层厚和颜色，按长度排序层叠构建嵌套框。

**输入结构**：约 12x12 的网格，背景为黑(0)。网格上有 3~4 种颜色的标记像素（从红(2)、绿(3)、蓝(1)、黄(4)中选取），每种颜色恰好出现 2 个像素，且每对同色像素共享同一行或同一列。不同颜色对之间的连线不交叉。生成约束：每对同色像素之间的跨度（不含端点，即线段的净长度，以像素数计）互不相同，且所有线段净长度之和加上最短线段净长度的二倍不超过输出网格半宽（确保嵌套框可容纳）。各对标记像素之间的跨度长度在 1~4 之间。

**规则**：
1. 对于每种颜色，找到该颜色的两个标记像素，确认它们共享一行或一列。记录它们之间的净跨度长度 L（不含两个端点像素，即端点列差或行差减 1）。
2. 将所有颜色按其净跨度长度从小到大排序。长度最小的颜色排最内层。
3. 构建同心正方形框输出：最内层颜色形成一个边长 = 2*L_min 的实心正方形（L_min 为最短线段净长度）。随后每一层颜色以其净跨度长度 L_k 为框厚，从外侧包裹当前结构。
4. 输出的画布大小恰好容纳最外层框，背景为黑(0)。输入中的标记像素和连线不出现在输出中——输出仅为嵌套同心框。

**关键洞察**：标记像素的空间分布编码了嵌套框的构造参数——连线不是要画出来的结构，而是一种测量手段，用来从空间距离中提取出框厚度数值。求解者需要先理解"连线产生的长度"这个中间量，再理解该量如何参数化嵌套框的构建，两步推理缺一不可。
