## 新题 9：循环移位预测下一帧连线锚点

**组合逻辑**：[循环移位/预测](创新：预测的下一帧位置不直接绘制精灵体，而是生成连线操作的锚点坐标) + [连线](创新：连线端点来自预测推断而非输入中可见的像素)

**来源原语**：循环移位(cyclic_shift) ← e78887d1；连线(connect) ← 60a26a3e；预测下一周期行(predict_next_cycle) ← e78887d1；精灵体(sprite) ← e78887d1；精灵网格(sprite_lattice) ← e78887d1；线段(line_segment) ← 60a26a3e；列固定颜色(col_fixed_color) ← e78887d1；同行同列对齐(same_row_column_alignment) ← 60a26a3e；仅相邻锚点间连接(connect_only_between_adjacent_anchors) ← 60a26a3e

**依赖链**：循环移位分析产生预测位置，预测位置成为连线锚点——不分析移位规律则不知道锚点在哪，不连线则预测结果无法表达。预测和连线通过"锚点坐标集合"耦合，该坐标集在输入中完全不存在。

从精灵网格的循环移位规律预测出下一帧中各精灵的中心位置，以这些预测位置为锚点绘制行列对齐的连接线段。

**输入结构**：约 15x15 的网格，背景为黑(0)。网格包含一个精灵网格布局：3~4 列精灵位置，列间以单列黑色分隔；3 行精灵行，行间以单行黑色分隔。每列有固定颜色（如第 1 列红(2)、第 2 列蓝(1)、第 3 列绿(3)）。每个精灵位置为一个 3x3 的区域，其中放置了一个小型单色 4-连通图形（3~5 像素，形状各异——可能是折线、小角、短杆等，具体形状不固定）或全黑（表示该位置为空）。忽略颜色后，每行的非空精灵图案是前一行非空精灵图案循环左移一个位置的结果。生成约束：精灵列数 = 3 或 4，至少有 2 个非空精灵，且预测的下一行中至少有 2 个预测锚点共享同一行或同一列。

**规则**：
1. 识别精灵网格的行列结构和每列的固定颜色。
2. 提取每行的精灵图案序列（忽略颜色），验证相邻行之间的循环左移关系。
3. 根据循环左移规则，预测下一行（第 4 行或第 n+1 行）各列应放置哪个精灵图案。记录每个预测非空精灵的中心坐标（精灵所在 3x3 区域的中心像素位置，行坐标为紧接最后一个分隔行之后的精灵行中央，列坐标为各列 3x3 区域的中心列）。
4. 以预测中心坐标集为锚点，对共享同一行的锚点对绘制水平连线（蓝(1)），对共享同一列的锚点对绘制垂直连线（蓝(1)）。连线从一个锚点中心延伸到另一个锚点中心，包含端点。
5. 输出网格 = 输入网格 + 连线。预测的精灵图案不绘制，仅绘制连线。

**关键洞察**：输出中的连线端点在输入中不存在——它们是通过理解精灵循环移位规律后"预测"出来的虚拟位置。求解者需要先发现精灵行间的循环移位模式，然后推断下一帧的锚点位置，最后才能绘制连线。三层推理环环相扣。
