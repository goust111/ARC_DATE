## 新题 6：外部色计数与内部空洞面积的序数配对填充

**组合逻辑**：[计数 + 排序](外部散点按色计数排名) ‖ [连通分量检测 + 排序](内部空洞按面积排名) → [序数配对 + 填充](两个排名对位映射，空洞被填色)

**来源原语**：计数/排序/调色板顺序 ← f3cdc58f；填充 ← 56ff96f3, 22eb0ac0；连通分量 ← 08ed6ac7

**依赖链**：这不是线性流水线而是并行排序后汇合的结构。外部散点的颜色计数和内部空洞的面积是两个独立指标，各自排序后通过序数位置一一配对。颜色与空洞之间没有空间邻接关系——关联纯粹是"第 k 大计数的颜色填入第 k 大面积的空洞"。跳过任一侧的排序都无法确定配对。

统计灰色边界外部各色散点的数量，按数量排名；同时将边界内部的空洞按面积排名；按排名对位将颜色填入对应空洞。

**输入结构**：黑(0)背景网格，约 14x14。一个连通的灰(5)边界结构占据网格中部（由灰(5)像素围成的封闭或半封闭形状，厚度 1 像素），其内部围出 3-4 个不同大小的黑(0)空洞（互不相连的封闭区域，面积各不相同，范围约 2-8 像素）。灰(5)边界外部的黑(0)背景上散布着 3-4 种前景色的孤立像素（蓝(1)、红(2)、绿(3)、黄(4)），每种色的像素数互不相同。外部前景色的种类数等于内部空洞数。生成约束：空洞按面积排列的序与外部颜色按计数排列的序不一致于任何简单的空间规律（如不是左到右或上到下）。

**规则**：
1. 识别灰(5)边界结构，将网格分为"边界外部"和"边界内部"。
2. 在边界外部，统计每种前景色的像素数量。按数量降序排列得到颜色序列 [C1, C2, C3, ...]。
3. 在边界内部，识别所有被灰(5)完全包围的黑(0) 4-连通区域（空洞）。按面积（像素数）降序排列得到空洞序列 [H1, H2, H3, ...]。
4. 按序数对位：用 C1 填充 H1 的所有像素，用 C2 填充 H2 的所有像素，依此类推。
5. 灰(5)边界保持不变。
6. 外部的散布前景色像素清除为黑(0)。

**关键洞察**：外部散点与内部空洞在空间上完全隔离——没有射线、没有邻接、没有视线可以将某个颜色"指向"某个空洞。唯一的关联是序数排名：计数最多的颜色进入面积最大的空洞，以此类推。求解者必须分别理解两个独立的排序逻辑，再发现它们通过排名序数耦合。

    3. Compute exterior cells. Verify they differ in both row and col (diagonal corridor). If not, re-pick gap directions.
    4. Run solver's monotone BFS from both endpoints; compute the yellow region. Verify the path is non-empty (it always will be if no extra obstacles exist and endpoints differ in both dimensions).
    5. Return the input grid (frames + markers on black bg); output is computed by solver.

## 实现要求

1. `main(grid)` 必须实现新题描述中的确定性转换规则，不能只识别 `generate_input()` 的固定模板。禁止不同的input网格输出相同的output网格。
2. `generate_input()` 必须随机生成多样样例，不能固定死。随机维度应覆盖：网格大小、对象数量、位置、颜色、方向、形状参数或关键分支。注意若描述中存在若干，需实现而不是只有单个，包括object或者对应关系等等。且若涉及到最短路径，则输入网格中必涉及到多条路径，对选择造成干扰。
3. 生成器必须保证输入满足 `main()` 的隐式假设：对象不重叠、不越界、特殊标记唯一或可区分、匹配关系无歧义、关键分支出现概率相同。
4. 禁止把 ARC 颜色 id 、亮度、拼写等当作人类不可见的数值语义参与排序、大小比较或隐藏映射。颜色变化必须有可见结构线索。注意颜色亮度、拼写等也是不可见信息，若描述中出现违规的颜色id或者亮度，可自行使用少量的固定颜色替代，但注意生成时要在三个以内输入输出网格中对所有变换100%覆盖度。
5. 输出样例要视觉清晰，人类必须能从输入输出对中肉眼辨认出规律。具体要求：避免对象粘连、覆盖关系混乱、同一像素多重语义；不同逻辑步骤产生的结果不要大面积层叠在一起导致无法分辨哪个颜色属于哪个步骤；输入中各元素之间保持足够间距，输出中新增的标记/填充/路径等应与背景和已有元素在颜色上有明显区分；若规则涉及多层叠加，生成时控制对象密度和尺寸，确保叠加区域只占少数像素而非铺满整个网格。
6. 若规则有多个分支，生成器不能长期固定成一个分支；应让分支在随机样例中合理出现。分支概率不必平均——难以发现的隐蔽分支（如少数情况下才触发的特殊规则）应适当提高出现概率，确保在 3 个训练示例中至少出现一次，否则求解者无法归纳该规则。对于颜色映射类规则，确保 2 个左右的示例即可覆盖所有映射关系（每种颜色→颜色的映射至少在某个示例中出现过）。
