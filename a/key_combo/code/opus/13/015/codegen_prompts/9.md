## 新题 9：面板叠加确定精灵体遮挡序，提取异常精灵体后裁剪互换色

**组合逻辑**：[透明叠加/transparent_overlay](创新：叠加不是为了合成最终画面，而是为了暴露精灵体之间的遮挡关系) + [去重筛选/uniqueness_filter](保留：识别出现一次的图案) + [裁剪/crop + 双色互换/recolor](保留但组合创新：对筛选结果而非固定输入执行裁剪互换)

**来源原语**：透明叠加/图层优先级(6a11f6da), 等高面板(6a11f6da), 去重筛选/图案仅出现一次/异常值选择(aee291af), 带框精灵体(aee291af), 裁剪(b94a9452), 双色互换(b94a9452)

**依赖链**：三层面板叠加 → 合成图中出现多个精灵体的叠加视图 → 还原每个精灵体的完整形态（被遮挡部分需从其他层推断） → 比较精灵体图案找出唯一不重复的一个 → 裁剪该精灵体并执行双色互换。叠加揭示遮挡关系决定了精灵体还原，还原质量决定了去重比较的正确性，去重选择决定了裁剪对象。

三层面板叠合后还原出被遮挡的精灵体全貌，找出唯一无重复图案的精灵体，裁剪并双色互换输出。

**输入结构**：约 24x10 的网格，纵向等分为三层面板（每层约 8x10）。
- 每层面板背景为黑(0)，包含 3~4 个小型矩形精灵体（每个约 3x3 ~ 4x4），每个精灵体恰好使用两种非背景颜色填充（无背景孔洞）。
- 三层面板中的精灵体位于相同的水平位置（即叠合后精灵体会重叠）。每个位置上，三层中的精灵体形状和颜色可能不同。
- 大部分位置上三层的精灵体图案相同（该位置的精灵体"重复出现"三次），但恰好有一个位置上某一层的精灵体图案与其他层不同（异常值）。
- 生成约束：叠合时底层优先级最高。异常精灵体不在底层（若在底层则叠合后直接可见、无需还原）。异常精灵体的两种颜色与其他位置的精灵体颜色不同，以确保可区分。

**规则**：
1. 将三层面板叠合：中层为底，上层覆盖中层，下层覆盖所有（与源题 6a11f6da 优先级一致）。得到一个与单层等大的合成图。
2. 合成图中每个精灵体位置显示的是最高优先级层的图案。对于重复精灵体（三层图案相同），合成图直接呈现正确图案。对于异常精灵体所在位置，合成图显示的可能是覆盖了异常精灵体的其他层图案。
3. 逐位置比较三层中的精灵体：在每个精灵体位置，提取三层各自的图案并比对。若某层图案与其他两层不同，该层的该位置精灵体为异常精灵体。
4. 提取异常精灵体的图案（从其所在层直接读取，不受叠合遮挡影响）。
5. 裁剪为精灵体的最小边界框。
6. 对裁剪结果执行双色互换：将精灵体中使用的两种非背景颜色互换。
7. 输出互换后的裁剪图案。

**关键洞察**：叠合操作的图层优先级可能将异常精灵体遮挡在合成图之下，使其无法直接从合成图中识别；求解者必须理解叠合的遮挡机制，回到原始三层逐层比对才能找到异常值——叠合在此题中不是解题工具而是"障眼法"，真正的去重筛选需要绕过叠合直接操作原始层。
