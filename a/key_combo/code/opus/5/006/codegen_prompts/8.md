## 新题 8：门控路径决定格子槽位填色

**组合逻辑**：[寻路 + 穿越门中心 + 走廊正交路径](从参考题10提取，创新为"路径不是连接两个标记而是从标记出发填充格子槽位") → [填充 + 槽位位置决定颜色](从参考题12提取，创新为"颜色不是由跨框架推断而是由到达该槽位的路径来源决定") → [连线 + 绘制](从参考题10提取，创新为"路径本身也是输出的一部分")

**来源原语**：寻路(pathfinding)、连线(draw_path)、平行墙壁(parallel_walls)、门段(door_segment)、标记像素(marker_pixel)、穿越门中心(through_door_center)、走廊正交路径(corridor_ortho_path) 来自参考题 7e576d6e；填充(fill)、格子框架(lattice_frame)、格子槽位(lattice_slot)、槽位位置决定颜色(slot_position_color)、跨框架对应(cross_frame_match) 来自参考题 2e65ae53；绘制(drawing) 来自参考题 13f06aa5

**依赖链**：识别格子框架的内部墙壁和门段位置 → 从每个彩色标记出发沿正交路径穿过门中心进入槽位 → 路径到达的槽位被填充为该标记的颜色 → 路径穿过门进入下一个相邻槽位时继续传播 → 两条路径同时到达一个槽位时按路径长度裁决

在格子框架的外侧放置彩色标记，每个标记沿正交路径穿过内部墙壁的门洞到达各个槽位，路径经过的槽位被填充为标记颜色，路径冲突时短路径优先。

**输入结构**：约 17x17 的网格，背景为黑(0)。灰(5)色 1 像素厚的线条构成一个 3x3 或 4x3 的格子框架（矩形网格状），将内部划分为若干矩形槽位（每个槽位 3x3 或 4x3 像素）。相邻槽位之间的灰色墙壁上各有恰好一个门（门 = 墙壁上 1 个被清除为背景色的像素）。格子框架外围的四条边上各有 0~2 个彩色标记像素（单像素，紧贴框架外壁），颜色从蓝(1)、红(2)、绿(3)、黄(4)中选取，共 3~5 个标记，颜色互不相同。框架外壁上也有门（外壁上被清除的像素），每个标记恰好与一个外壁门相邻。生成约束：从每个标记出发经过门可以到达至少 2 个槽位；所有槽位至少可被某个标记的路径到达；存在至少 1 个槽位可被两个不同标记的路径到达。

**规则**：
1. 识别格子框架（灰(5)线条）、门（灰色墙壁上的背景色缺口，每个门恰好 1 像素宽）、彩色标记（紧贴框架外壁的非背景非灰单像素）、槽位（灰色框架围成的矩形内部区域）。
2. 对每个标记像素，从其相邻的外壁门进入框架内部。路径规则：在槽位内部沿正交方向（水平或垂直）直线行进，方向为从入口门朝向槽位内部。路径到达对面墙壁时，如果该墙上有门，则穿过门进入相邻槽位并继续沿同一方向行进；如果无门，路径在当前槽位中转 90 度（优先向右转；右转方向也无门则向左转；两个方向都无门则路径终止），寻找有门的墙壁继续。
3. 路径经过的每个槽位被标记为该路径颜色的候选。记录从标记出发到进入该槽位所经过的门的数量作为"路径长度"。
4. 对每个槽位：如果只有一个标记的路径到达，填充该标记的颜色。如果有多个标记的路径到达，取路径长度最短的标记颜色填充；路径长度相同时，取标记像素距框架左上角曼哈顿距离更近的标记颜色。
5. 在输出中绘制路径：从每个标记出发的路径用该标记颜色在槽位背景上画 1 像素宽的线。路径线只画在最终获胜的槽位中（即该槽位被填充为该标记颜色的情况下才画该标记的路径线）。
6. 框架的灰色线条保持不变。标记像素保持不变。未被任何路径到达的槽位保持背景色（不应存在，见生成约束）。

**关键洞察**：槽位的颜色不是由其在框架中的位置静态决定的，而是由动态路径竞争的结果决定——同一个槽位在不同示例中可能因为标记位置和门的布局变化而被不同颜色的路径占据；需要多个示例才能归纳出路径长度优先的冲突解决规则和转向优先级。

4. 禁止把 ARC 颜色 id 、亮度、拼写等当作人类不可见的数值语义参与排序、大小比较或隐藏映射。颜色变化必须有可见结构线索。注意颜色亮度、拼写等也是不可见信息，若描述中出现违规的颜色id或者亮度，可自行使用少量的固定颜色替代，但注意生成时要在三个以内输入输出网格中对所有变换100%覆盖度。
