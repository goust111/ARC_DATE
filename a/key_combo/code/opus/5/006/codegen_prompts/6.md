## 新题 6：同心方阵按色频循环缩放后位移

**组合逻辑**：[计数](从参考题14提取，创新为"色频不用于选择颜色而用于确定循环步数") → [缩放 + 边长循环变换 + 同心定位](从参考题18提取，创新为"循环步数由外部色频决定而非固定为 1 步") → [平移 + 颜色编码位移](从参考题5提取，创新为"位移施加在缩放后的方阵上而非单像素上")

**来源原语**：计数(counting)、众数颜色决定输出(majority_color_out) 来自参考题 ff2825db；缩放(resize)、奇数边正方形(odd_side_square)、中心点(center_point)、同心定位(concentric_position)、边长循环变换(side_length_cycle) 来自参考题 522fdd07；平移(translate)、颜色编码位移(color_encoded_disp)、颜色决定偏移(color_determines_offset)、前景像素(foreground_pixel) 来自参考题 342dd610

**依赖链**：统计散布标记像素中各颜色的数量 → 每个方阵按自身颜色对应的标记数量在循环序列中前进相应步数 → 缩放后若两个方阵中心重合且新边长相同则合并（保留原来更靠近网格中心的那个） → 存活的方阵按自身颜色编码的位移向量平移

统计散布标记像素的颜色频率，以此决定每个同心奇数边正方形在尺寸循环中前进的步数，缩放后按颜色编码的位移向量平移到最终位置。

**输入结构**：约 25x25 的网格，背景为黑(0)。网格中有 3~5 个单色实心正方形，边长为奇数且属于集合 {1, 3, 5, 7, 9}，颜色各不相同，从橙(7)、红(2)、栗(9)、蓝(1)中选取。各方阵互不重叠，中心位置各异。网格中另外散布若干单独的前景像素（不与任何方阵相邻），颜色只从方阵使用的颜色中选取。生成约束：每种方阵颜色对应的散布像素数量在 1~4 之间；缩放后不会有两个方阵的中心恰好重合（除非题目设计需要合并的情况）；方阵颜色仅限橙(7)、红(2)、栗(9)、蓝(1)四种。

**规则**：
1. 识别所有实心奇数边正方形（边长属于 {1, 3, 5, 7, 9} 的 4-连通同色实心方块）和所有散布标记像素（不属于任何方阵的非背景孤立像素）。
2. 对每种方阵颜色 c，统计颜色为 c 的散布标记像素数量 n_c。
3. 对每个方阵，当前边长为 s，在循环序列 (1, 9, 7, 5, 3, 1, 9, 7, 5, 3, ...) 中从 s 出发前进 n_c 步，得到新边长 s'。保持方阵中心不变，将边长替换为 s'。循环规则：1→9→7→5→3→1→...
4. 清空画布为背景色。对每种颜色的位移规则为：橙(7)向上平移 2 格，红(2)向左平移 2 格，栗(9)向下平移 2 格，蓝(1)向右平移 1 格。
5. 对每个方阵，以其中心为锚点，施加颜色对应的位移向量，在新位置绘制边长为 s' 的同色实心正方形。超出网格边界的部分裁剪丢弃。
6. 如果两个方阵缩放后的新边长相同且平移后占据的区域有重叠，则后绘制的覆盖先绘制的。绘制顺序：按方阵中心到网格中心的曼哈顿距离从大到小绘制（离中心远的先画，近的后画覆盖）。
7. 散布标记像素不出现在输出中。

**关键洞察**：同一种颜色的标记像素数量越多，对应方阵在尺寸循环中跳跃越远——标记像素不是简单的装饰，而是编码了缩放的"步数参数"；需要对比多个示例才能发现颜色-位移映射（尤其区分橙向上、红向左等方向）以及计数-步数的关系。

import hashlib
import numpy as np

p = Path("/home/lixinyu/snap/a/key_combo/code/opus/5/006/6.py")
mod = SourceFileLoader("new_arc_task", str(p)).load_module()
sigs = set()
for i in range(100):
    inp = mod.generate_input()
    out = mod.main(inp)
    assert isinstance(inp, np.ndarray)
    assert isinstance(out, np.ndarray)
    assert inp.ndim == 2 and max(inp.shape) <= 30, f"input grid exceeds 30x30: {inp.shape}"
    assert out.ndim == 2 and max(out.shape) <= 30, f"output grid exceeds 30x30: {out.shape}"
    sigs.add(hashlib.md5(inp.tobytes() + str(inp.shape).encode()).hexdigest())
print("variants", len(sigs))
assert len(sigs) >= 20
