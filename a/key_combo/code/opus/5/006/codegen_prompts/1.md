## 新题 1：缩放模板级联激活网络

**组合逻辑**：[像素放大 + 缩放对应](从参考题1提取，创新为"缩放匹配揭示端口方向") → [级联激活 + 射线延伸](从参考题3提取，创新为"大型形状的端口方向由模板匹配旋转量决定") → [重涂色](已有原语，创新为"激活状态决定涂色")

**来源原语**：像素放大(pixel_upscale)、缩放对应(scale_correspondence)、八方向匹配(all_orientations_matching) 来自参考题 898e7135；级联激活(cascade_activation)、射线延伸(ray_extend)、端口编码射线(port_encodes_ray)、链式反应传播(chain_reaction_propagation) 来自参考题 5961cc34；重涂色(recolor) 来自参考题 2de01db2

**依赖链**：缩放匹配确定每个大型形状对应的小模板及旋转量 → 旋转量决定大型形状上端口的实际朝向 → 端口朝向决定射线发射方向 → 射线命中触发级联激活 → 激活状态决定最终涂色

从散布的小模板和大型形状之间建立缩放匹配关系，利用匹配所需的旋转量推导大型形状的端口方向，从起点出发通过端口射线逐级激活形状，将被激活的形状重涂为红(2)。

**输入结构**：约 25x25 的网格，背景为黑(0)。网格中散布着 3~4 个小模板（每个是 3~5 像素的单色 4-连通图形，颜色各不相同，形状各异且不对称）和 3~4 个大型形状。每个大型形状是某个小模板的 k 倍放大版本（k 由最小实心正方形块的边长确定，约为 2 或 3），可能经过 90 度旋转或翻转。每个小模板上恰好有 1 个绿(3)像素紧邻其边界，标记端口方向（绿像素相对于模板质心的方向即为端口射线方向）。网格底部有一个黄(4)像素紧贴一段短红(2)线段作为起始标记，红线段指向某个大型形状。生成约束：大型形状之间互不重叠；每个大型形状恰好对应一个小模板；至少有一个大型形状无法被起始射线的级联链到达。

**规则**：
1. 识别所有小模板（3~5 像素的非背景 4-连通分量，排除起始标记和绿像素）和所有大型形状（像素数 >= 小模板像素数 x k^2 的非背景 4-连通分量）。确定缩放因子 k = 大型形状中最小的实心正方形块的边长。
2. 对每个大型形状，按 k 倍降采样得到缩小版掩码，与每个小模板在 8 个方向（4 次旋转 x 是否翻转）下比较，找到唯一匹配的模板及所需的旋转/翻转变换 T。
3. 从起始标记的红线段方向发出一条射线（颜色为红(2)），射线沿红线段延伸方向逐像素前进，直到命中某个大型形状的边界或到达网格边缘。
4. 命中的大型形状被"激活"：将其所有像素重涂为红(2)。
5. 对被激活的大型形状，找到其匹配模板上的绿像素端口方向，将该方向施加变换 T 的旋转/翻转分量，得到大型形状上端口的实际射线方向。从大型形状边界沿该方向发出射线（颜色红(2)），射线宽度为 k 像素，逐像素前进直到命中另一个大型形状或到达网格边缘。
6. 重复步骤 4-5，直到没有新的形状被激活。
7. 输出：被激活的大型形状涂为红(2)，射线保留为红(2)，未激活的大型形状保持原色，小模板和绿像素、起始标记保持不变。

**关键洞察**：端口方向不是直接标注在大型形状上的，而是标注在小模板上——必须先通过缩放匹配确定旋转量，才能推算大型形状上端口的真实朝向；同一个模板的不同放大副本可能因旋转不同而射线方向完全不同。

    sigs.add(hashlib.md5(inp.tobytes() + str(inp.shape).encode()).hexdigest())
print("variants", len(sigs))
assert len(sigs) >= 20
