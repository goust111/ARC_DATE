## 新题 5：面积排序的滑轨对接

**组合逻辑**：[排序](面积决定处理顺序) → [平移](滑动对接) → [轨迹涂黑](创新：轨迹成为后续对接的物理障碍) — 排序和平移为已有原语，创新在于滑动轨迹不只是视觉标记，还作为障碍影响后续方块的对接位置，形成处理顺序→轨迹→位置冲突的涌现效应。

**来源原语**：排序、边框方块、距离优先排序（源自 b5ca7ac4）；平移、括号框、通道对齐、目标底边对齐（源自 df9fd884）；对接、内部槽位、轨迹涂黑（源自 8b9c3697）

**依赖链**：边框颜色匹配方块与括号框 → 面积排序确定处理顺序 → 处理顺序决定谁先占位 → 先到者的轨迹和占位阻挡后到者 → 被阻挡者被迫向右偏移 → 偏移量取决于先到者的尺寸。

按面积从大到小依次将各边框方块向左滑入同色括号框，滑动留下灰色轨迹，后处理的方块若目标位置被先到者的轨迹或占位阻挡则右移一个方块宽度。

**输入结构**：
- 网格约 22x18，黑(0)为背景。
- 左侧边缘：3-4 个括号框（C 形，开口朝右），各自使用一种独特颜色（如蓝(1)、红(2)、绿(3)、黄(4)）。括号框沿左侧垂直排列，各框之间至少隔 2 行背景。每个括号框的开口高度与其对应方块的边长匹配。
- 右半区域：3-4 个边框方块，尺寸分别不同（如 3x3、5x5、7x7），每个方块有 1 像素厚的边框（颜色与某个括号框相同）和独特的内部填充色。方块散布在网格右半部分。
- 生成约束：每个括号框颜色恰好对应一个方块。至少两个括号框的行范围重叠（它们的开口在垂直方向有交叉）。所有方块面积互不相同。

**规则**：
1. 按边框颜色将每个方块与同色括号框配对。
2. 按方块面积从大到小排序（面积不同，无需 tie-break）。
3. 按此顺序依次处理每个方块：
   a. 目标位置：方块保持原始行不变，左移使其左边缘对齐括号框开口右侧的第一列（即紧贴括号框内侧）。
   b. 检查目标位置的所有像素是否均为黑(0)（未被先前放置的方块或轨迹占据）。
   c. 若目标位置有任何非黑像素，将目标列右移该方块的宽度，重复检查，直到找到完全空闲的位置。
4. 将方块放置在最终确定的目标位置（保留原始边框和填充颜色）。
5. 方块从原始位置到最终位置之间经过的所有像素列（不含最终位置本身，含原始位置），在方块的行范围内涂为灰(5)——这是滑动轨迹。若轨迹像素覆盖了更早的轨迹，后来的轨迹覆盖先前的。
6. 括号框保持不变。

**关键洞察**：大方块先到先得，它不仅占据括号框附近的空间，其宽大的滑动轨迹还横跨大片区域。后处理的小方块即使目标括号框在不同行，也可能因大方块的轨迹经过其目标位置而被迫右移。这种"轨迹即障碍"的涌现效应在任何源题中都不存在——处理顺序不仅决定谁先到，还通过物理痕迹改变后续者的约束空间。

## 实现要求

1. `main(grid)` 必须实现新题描述中的确定性转换规则，不能只识别 `generate_input()` 的固定模板。禁止不同的input网格输出相同的output网格。
2. `generate_input()` 必须随机生成多样样例，不能固定死。随机维度应覆盖：网格大小、对象数量、位置、颜色、方向、形状参数或关键分支。注意若描述中存在若干，需实现而不是只有单个，包括object或者对应关系等等。
3. 生成器必须保证输入满足 `main()` 的隐式假设：对象不重叠、不越界、特殊标记唯一或可区分、匹配关系无歧义、关键分支出现概率相同。
4. 禁止把 ARC 颜色 id 、亮度、拼写等当作人类不可见的数值语义参与排序、大小比较或隐藏映射。颜色变化必须有可见结构线索。注意颜色亮度、拼写等也是不可见信息，若描述中出现违规的颜色id或者亮度，可自行使用少量的固定颜色替代，但注意生成时要在三个以内输入输出网格中对所有变换100%覆盖度。
5. 输出样例要视觉清晰，人类必须能从输入输出对中肉眼辨认出规律。具体要求：避免对象粘连、覆盖关系混乱、同一像素多重语义；不同逻辑步骤产生的结果不要大面积层叠在一起导致无法分辨哪个颜色属于哪个步骤；输入中各元素之间保持足够间距，输出中新增的标记/填充/路径等应与背景和已有元素在颜色上有明显区分；若规则涉及多层叠加，生成时控制对象密度和尺寸，确保叠加区域只占少数像素而非铺满整个网格。
6. 若规则有多个分支，生成器不能长期固定成一个分支；应让分支在随机样例中合理出现。分支概率不必平均——难以发现的隐蔽分支（如少数情况下才触发的特殊规则）应适当提高出现概率，确保在 3 个训练示例中至少出现一次，否则求解者无法归纳该规则。对于颜色映射类规则，确保 2 个左右的示例即可覆盖所有映射关系（每种颜色→颜色的映射至少在某个示例中出现过）。
