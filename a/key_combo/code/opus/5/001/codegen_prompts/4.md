## 新题 4：嵌套深度偏移的同心填充

**组合逻辑**：[包含树](树分析得深度) → [填充](创新：以深度为参数偏移循环色板) + [循环色板](创新：起始位置由外部参数控制) — 包含树和循环色板为已有原语，创新在于嵌套深度成为色板偏移量驱动填充着色，源题中包含树用于布局规范化、色板使用固定起始。

**来源原语**：规范化、嵌套框架、封闭区域、包含树、拓扑决定布局（源自 2d0172a1）；填充、同心环、距离映射、曼哈顿距离、循环色板（源自 aaef0977）

**依赖链**：检测框架嵌套结构 → 构建包含树 → 树中各区域的深度值确定 → 深度值偏移循环色板的起始颜色 → 曼哈顿距离选择色板中的具体条目 → 叶区域用同心环、非叶区域用深度对应的单色。

在嵌套矩形框架结构中，对叶区域按中心曼哈顿距离绘制同心色环，色板起始色由该区域的嵌套深度偏移；非叶区域涂其深度对应的单色。

**输入结构**：
- 网格约 20x20，黑(0)为背景。
- 灰(5)像素构成矩形框架边界（1 像素厚）。框架为轴对齐矩形，嵌套深度最多 3 层。一个框架的内部可能包含 0 个或多个子框架。
- 存在至少 2 棵独立的框架树（互不嵌套的最外层框架）。
- 叶区域：框架内部不含任何子框架的空间。非叶区域：框架内部包含至少一个子框架的空间（子框架周围的区域）。
- 生成约束：至少存在两个叶区域处于不同的嵌套深度。所有框架至少 5x5（内部至少 3x3）。同一深度若有多个叶区域，其内部尺寸应不同（使环纹看起来不同），以引导求解者注意深度而非尺寸。

**规则**：
1. 构建包含树：框架 A 是框架 B 的父级，当且仅当 B 的内部完全在 A 的内部之内，且不存在另一框架 C 满足 A 包含 C 包含 B。
2. 赋深度：最外层框架（无父级）深度为 1。子框架深度 = 父框架深度 + 1。
3. 定义循环色板：[蓝(1), 红(2), 绿(3), 黄(4), 橙(7), 品红(6), 青(8), 栗(9)]，长度 L=8。
4. 对每个叶区域：取其内部矩形的中心像素坐标（宽和高均取 floor(center_row), floor(center_col)）。对内部每个非边框像素，计算到中心的曼哈顿距离 D。涂色为色板位置 ((D + depth - 1) mod L)，其中 depth 是该区域的嵌套深度。中心像素 D=0，涂色板位置 ((depth - 1) mod L)。
5. 对每个非叶区域：其内部中不属于任何子框架或子框架内部的像素，统一涂色板位置 ((depth - 1) mod L) 对应的单色。
6. 灰(5)框架边界保持不变。
7. 所有框架外部的像素保持黑(0)。

**关键洞察**：同样距中心为 D 的像素，在不同嵌套深度的叶区域中会呈现不同颜色——深度偏移了色板起始位置。求解者无法仅看单个区域推断色板规则，必须比较不同深度的区域才能发现偏移关系。这种"参数化填充"结构源题中不存在。

## 实现要求

1. `main(grid)` 必须实现新题描述中的确定性转换规则，不能只识别 `generate_input()` 的固定模板。禁止不同的input网格输出相同的output网格。

3. 生成器必须保证输入满足 `main()` 的隐式假设：对象不重叠、不越界、特殊标记唯一或可区分、匹配关系无歧义、关键分支出现概率相同。
4. 禁止把 ARC 颜色 id 、亮度、拼写等当作人类不可见的数值语义参与排序、大小比较或隐藏映射。颜色变化必须有可见结构线索。注意颜色亮度、拼写等也是不可见信息，若描述中出现违规的颜色id或者亮度，可自行使用少量的固定颜色替代，但注意生成时要在三个以内输入输出网格中对所有变换100%覆盖度。
