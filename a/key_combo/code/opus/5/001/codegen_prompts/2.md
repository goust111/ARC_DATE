## 新题 2：沿引导路径弹射

**组合逻辑**：[弹射](创新：轨迹由路径而非直线决定) → [路径追踪](创新：路径作为弹射轨道而非通向目标物体) → [像素数守恒](创新：决定路径着色长度而非射线长度) — 弹射与路径追踪均为已有原语，创新在于路径充当弹射轨道，源题中弹射走直线、路径通向终点物体，二者从未组合为"沿任意路径弹射"的结构。

**来源原语**：弹射、杯形框架、内容像素、尾刺、尾部朝向决定射出、像素数守恒（源自 3dc255db）；路径追踪、引导像素、路径连接（源自 9ba4a9aa）

**依赖链**：尾刺尖端的位置选择相邻的引导路径入口 → 引导路径提供弯折的弹射轨道 → 杯内内容像素数决定沿路径着色的长度 → 内容被擦除，路径前 N 格被重涂为内容色。

将杯形框架内的内容像素擦除，沿从尾刺出发的灰色引导路径重新着色，着色长度等于原内容像素数。

**输入结构**：
- 网格约 18x18，黑(0)为背景。
- 2-3 个杯形框架，各自使用一种独特的边框颜色（如蓝(1)、绿(3)）。每个杯形为一个 4-连通的开口容器：三面封闭、一面开口（"杯口"），杯口对面有一个汇聚的尾刺（1-2 个像素构成的尖端，指向杯外）。杯形框架约 5-8 像素高、4-6 像素宽。
- 每个杯的杯口内部包含 2-5 个内容像素，各杯的内容颜色互不相同且与边框色、背景色不同（如红(2)、黄(4)）。
- 引导路径：从每个尾刺尖端的 4-邻接位置出发，由灰(5)像素组成的 4-连通链条，蜿蜒穿过网格。每条路径不进入任何杯的内部，不与其他路径交叉，不经过其他杯的边框。每条路径的灰(5)像素数至少等于其对应杯的内容像素数。
- 生成约束：每个尾刺尖端恰好有一条灰(5)路径与之 4-邻接。路径链条无分叉（每个路径像素至多有两个同色 4-邻居）。

**规则**：
1. 对每个杯，统计其杯口内的内容像素数 N，记录内容颜色 C，定位尾刺尖端。
2. 擦除杯口内所有内容像素（置为黑(0)）。
3. 找到与尾刺尖端 4-邻接的灰(5)像素作为引导路径的起点。沿路径追踪：从起点出发，每一步移动到当前像素的唯一未访问灰(5) 4-邻居。
4. 将路径的前 N 个像素从灰(5)重涂为内容颜色 C。
5. 将路径中第 N+1 个及之后的所有灰(5)像素擦除（置为黑(0)）。
6. 杯形框架的边框像素保持不变。

**关键洞察**：弹射轨迹不是直线（区别于源题 3dc255db 的直线射出），而是沿着任意弯折的引导路径行进。尾刺的作用从"方向指示器"变为"路径选择器"——它指向一条特定引导路径的入口，而非指示罗盘方向。求解者需同时理解杯的结构（找尾刺和内容数量）和路径追踪（找轨迹），二者缺一不可。
