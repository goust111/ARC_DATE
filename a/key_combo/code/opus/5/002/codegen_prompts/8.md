## 新题 8：枢纽射线分区与种子洪泛的双向信息流

**组合逻辑**：[hub_square → ray_extend → ray_partition](创新组合：从枢纽中心发射射线分割空间，而非从线性序列的像素发射) + [seed_region + flood_fill](已有，创新：洪泛范围受射线分区约束) → [adjacency_count_determines_color](已有，创新：枢纽颜色由洪泛面积最大的种子决定——信息从分区回流到枢纽)

**来源原语**：path_network, hub_square, seed_region, adjacency_color_transfer, adjacency_count_determines_color (800d221b); ray_extend, ray_partition (1190bc91); flood_fill (1190bc91); separator_line, sep_color_fills_gap (538b439f)

**依赖链**：枢纽位置决定射线方向 → 射线分割空间为扇区 → 每个扇区内种子洪泛至扇区边界 → 洪泛面积决定枢纽颜色。信息从枢纽流出（射线）又流回枢纽（颜色），形成双向依赖。

从中心枢纽向四个对角方向发射射线将网格分割为扇区，每个扇区内的种子区域洪泛填充至射线边界，洪泛面积最大的种子颜色回传给枢纽中心。

**输入结构**：约 21x21 的黑(0)背景网格。网格中央偏某方向有一个 3x3 的灰(5)实心正方形作为枢纽。散布在网格中（枢纽外部）有 4 个小型种子区域（各 2~5 像素的 4-连通块），颜色分别为蓝(1)、红(2)、绿(3)、黄(4)。生成约束：枢纽不在网格正中心（使四个扇区面积不等）；4 个种子区域分布在枢纽的不同方位（但不要求每个对角扇区各一个——某些扇区可能无种子，某些扇区可能有两个）；种子区域不与枢纽相邻（至少间隔 2 像素）。

**规则**：
1. 找到 3x3 的灰(5)枢纽正方形，记其中心像素坐标为 (hr, hc)。
2. 从 (hr, hc) 向四个 45 度方向（左上、右上、左下、右下）各发射一条射线：射线逐像素沿对角方向前进，将经过的像素涂为灰(5)，直到到达网格边界为止。
3. 四条射线将网格分为 4 个扇区（上、下、左、右）。扇区的归属规则：射线像素和枢纽像素不属于任何扇区；其余像素按其相对于枢纽中心的方位归入扇区——正上方（行 < hr 且列 = hc 的列附近）为上扇区，依此类推。精确定义：像素 (r, c) 属于上扇区当 r < hr 且 |c - hc| < hr - r；属于右扇区当 c > hc 且 |r - hr| < c - hc；属于下扇区当 r > hr 且 |c - hc| < r - hr；属于左扇区当 c < hc 且 |r - hr| < hc - c。落在扇区边界上（|c - hc| = |r - hr|）的像素已被射线覆盖，归为灰色。
4. 对每个扇区，找到其中的种子区域。若该扇区有种子区域，从种子的每个像素出发做 4-连通洪泛填充：将扇区内所有可达的黑(0)像素涂为该种子的颜色，洪泛不跨越灰(5)射线像素、枢纽像素或网格边界。若一个扇区有多个种子，按包围盒左上角从上到下、从左到右的顺序依次洪泛，后洪泛的不覆盖已被涂色的像素。
5. 洪泛完成后，统计每种种子颜色的洪泛总面积（所有扇区中该颜色的洪泛像素数之和）。
6. 将枢纽 3x3 区域的中心像素 (hr, hc) 重涂为洪泛总面积最大的种子颜色。枢纽的其余 8 个像素保持灰(5)。若两种颜色面积相等，取在输入中种子区域像素数较少的那种颜色（即原始种子更小但洪泛更大，说明它占据了更大的空间）。

**关键洞察**：枢纽既是空间分割的"发射源"（射线从枢纽出发），又是颜色信息的"接收者"（颜色从洪泛结果回流）——信息先从枢纽向外流出划定边界，再从边界内的洪泛结果向枢纽回流，形成一个需要完整执行才能确定枢纽颜色的闭环。

3. 生成器必须保证输入满足 `main()` 的隐式假设：对象不重叠、不越界、特殊标记唯一或可区分、匹配关系无歧义、关键分支出现概率相同。
4. 禁止把 ARC 颜色 id 、亮度、拼写等当作人类不可见的数值语义参与排序、大小比较或隐藏映射。颜色变化必须有可见结构线索。注意颜色亮度、拼写等也是不可见信息，若描述中出现违规的颜色id或者亮度，可自行使用少量的固定颜色替代，但注意生成时要在三个以内输入输出网格中对所有变换100%覆盖度。
