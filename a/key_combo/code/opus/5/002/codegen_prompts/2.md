## 新题 2：面积匹配的模板印章填入轮廓腔体

**组合逻辑**：[count + area_matching](已有，创新：计数对象从源像素集变为模板图块，匹配目标从单个轮廓变为多个轮廓) → [stamp_overlay](已有，创新：印章不是按标记位置放置，而是按面积匹配结果放入对应腔体) → [erase](已有)

**来源原语**：stamp_overlay, template_tile, marker_position (e734a0e8); count, area_matching, outline_object, row_interior, erase (7acdf6d3); count_maps_to_size (878187ab)

**依赖链**：必须先同时计算每个模板的像素数和每个轮廓的腔体面积，再通过面积相等关系建立一一匹配，最后将匹配的模板印入对应腔体。跳过计数则无法建立匹配；跳过匹配则不知道哪个模板放入哪个腔体。

统计多个模板图块的像素数和多个封闭轮廓的内腔面积，按面积相等进行一一匹配，将每个模板印入其匹配轮廓的内腔并擦除模板原位。

**输入结构**：约 20x25 的黑(0)背景网格。网格中散布 3 个互不相邻的小型模板图块（每个 3~8 像素，4-连通，单色，各用不同颜色如蓝(1)、红(2)、绿(3)，形状不规则且各不相同）。另有 3 个用灰(5)像素绘制的封闭轮廓对象（单像素宽的 8-连通闭合环，内部全为黑(0)背景）。每个轮廓的行向内腔面积（对每一占用行，统计最左与最右轮廓像素之间的背景像素数之和）恰好等于某一个模板的像素数，且三对匹配互不冲突（即三个内腔面积互不相同）。模板与轮廓在空间上不接触。生成约束：每个轮廓的内腔是简单连通的（无内部岛屿），内腔的行数和列数都不小于对应模板的包围盒行数和列数。

**规则**：
1. 识别所有灰(5)的 8-连通闭合轮廓。对每个轮廓，计算其行向内腔面积：对该轮廓像素占据的每一行，统计该行上最左和最右灰像素之间（不含灰像素本身）的黑(0)像素数量，求和得到该轮廓的内腔面积。
2. 识别所有非黑、非灰的 4-连通前景色图块（即模板），统计每个模板的像素总数。
3. 将每个模板与内腔面积等于该模板像素数的轮廓配对（一一对应）。
4. 对每对匹配：将模板图块逐像素复制到对应轮廓的内腔中，以内腔包围盒的左上角为锚点，模板的包围盒左上角与之对齐。复制时保持模板的颜色不变。
5. 擦除模板在原位置的所有像素（替换为黑(0)）。
6. 灰色轮廓像素保持不变。

**关键洞察**：模板和轮廓之间没有颜色关联或空间邻近关系——唯一的配对线索是像素数与腔体面积的数值相等，必须两侧都计数才能建立对应。

p = Path("/home/lixinyu/snap/a/key_combo/code/opus/5/002/2.py")

    assert out.ndim == 2 and max(out.shape) <= 30, f"output grid exceeds 30x30: {out.shape}"
    sigs.add(hashlib.md5(inp.tobytes() + str(inp.shape).encode()).hexdigest())
print("variants", len(sigs))
assert len(sigs) >= 20
