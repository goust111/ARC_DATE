## 新题 2：射线弹射构建图拓扑与最短路径求解

**组合逻辑**：[射线延伸 + 反弹](创新：射线路径不再是输出本身，而是用于构建图的边) + [最短路径](创新：图的边不再预先画出，需由射线物理模拟推导) + [颜色继承](创新：继承的颜色标记边的权重类别)

**来源原语**：射线延伸/ray_cast、反弹/bounce、箭头精灵体/arrow_sprite、墙壁像素/wall_pixel、颜色继承/color_inheritance、碰撞停止/collision_stop（142ca369）；最短路径/shortest_path、节点方块/node_square、终端节点/terminal_node、图结构/graph_structure、最短路径选择/shortest_path_selection（7b0280bc）

**依赖链**：射线弹射模拟确定哪些节点之间存在连接（即图的邻接关系），这一拓扑信息是最短路径求解的前提。射线在弹射中继承的墙壁颜色区分了两类边——只有特定颜色类别的边参与最短路径计算。删除射线模拟则图拓扑未知；删除最短路径则无法确定高亮哪些节点和路径。

通过射线弹射物理模拟推导出隐式图的边集，再在该图上求解最短路径，将物理模拟与图论算法紧耦合。

**输入结构**：约 18x18 的网格，背景为黑(0)。网格中有 5~7 个 2x2 的单色方块作为图节点，其中恰好 2 个方块为红(2)（终端节点），其余为蓝(1)（中间节点）。每个方块的边界框外紧邻一个缺角的 2x2 区域（即 3 像素的 L 形箭头精灵体），颜色为灰(5)，缺角方向指示射线发射的对角方向。网格中散布若干黄(4)和绿(3)的单像素墙壁像素。生成约束：每个节点发出的射线经过弹射后至少能到达另一个节点（射线到达某节点的 2x2 区域的任一相邻像素时视为连接该节点）；两个红(2)终端之间至少存在一条通路。

**规则**：
1. 从每个节点的箭头精灵体出发，沿缺角指示的对角方向发射射线。射线在背景上传播，不绘制任何像素。
2. 射线碰到墙壁像素时执行弹射：正面碰撞（射线下一步恰为墙壁像素）反转两个轴方向；侧面接触（射线当前位置的垂直或水平邻居为墙壁像素且射线正朝该轴移动）只翻转接触轴方向。射线记录碰到的最后一个墙壁像素的颜色。
3. 射线到达某个节点方块的 4-邻接像素时停止，在发射节点与到达节点之间建立一条图边。若射线未碰到任何墙壁就到达另一个节点，该边标记为"直连边"；若碰到的最后一个墙壁为黄(4)，标记为"黄边"；若为绿(3)，标记为"绿边"。射线出网格则不产生边。
4. 在构建的图中，仅使用"直连边"和"黄边"（忽略"绿边"），求两个红(2)终端节点之间的最短路径（以边数计）。
5. 最短路径上的中间蓝(1)节点方块重涂为绿(3)；两个红(2)终端不变；所有其他节点方块、墙壁像素和箭头精灵体保持不变。

**关键洞察**：图的边不是预先画出的轨道段，而是由射线弹射物理模拟隐式确定的；且弹射中继承的墙壁颜色区分了可用边和不可用边，使得拓扑发现与路径求解深度耦合。

p = Path("/home/lixinyu/snap/a/key_combo/code/opus/5/011/2.py")
mod = SourceFileLoader("new_arc_task", str(p)).load_module()
sigs = set()
for i in range(100):
    inp = mod.generate_input()
    out = mod.main(inp)
    assert isinstance(inp, np.ndarray)
    assert isinstance(out, np.ndarray)
    assert inp.ndim == 2 and max(inp.shape) <= 30, f"input grid exceeds 30x30: {inp.shape}"
    assert out.ndim == 2 and max(out.shape) <= 30, f"output grid exceeds 30x30: {out.shape}"
    sigs.add(hashlib.md5(inp.tobytes() + str(inp.shape).encode()).hexdigest())
print("variants", len(sigs))
assert len(sigs) >= 20
