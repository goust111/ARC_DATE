## 新题 9：射线弹射路径约束周期瓦片修复范围

**组合逻辑**：[射线延伸 + 反弹](创新：射线路径不用于绘色，而是标记"可信区域") + [修复噪声](创新：只修复射线可达的区域，不可达区域原样保留) + [颜色继承](创新：射线弹射继承的颜色确定该区域使用哪组瓦片参数)

**来源原语**：射线延伸/ray_cast、反弹/bounce、箭头精灵体/arrow_sprite、墙壁像素/wall_pixel、颜色继承/color_inheritance、碰撞停止/collision_stop（142ca369）；修复噪声/repair_noise、周期瓦片/periodic_tile、周期重复/periodic_repetition、忽略干扰项/ignore_distractors（135a2760）

**依赖链**：箭头精灵体发射射线，射线弹射路径划定了"可信修复区域"——只有射线经过的像素所在的周期区域才执行瓦片修复。射线弹射时继承墙壁颜色，不同颜色的墙壁区分了不同的周期区域（各区域有各自的瓦片尺寸和内容）。射线未到达的区域中的噪声是"有意装饰"不应被修复。删除射线则不知修复哪些区域；删除瓦片推断则无法修复；删除颜色继承则无法区分不同区域的瓦片参数。

射线弹射路径标记可信修复范围，弹射中继承的墙壁颜色区分不同瓦片区域，对射线可达区域执行周期瓦片修复而保留不可达区域的噪声。

**输入结构**：约 20x20 的网格，背景为黑(0)。网格被若干单像素宽的墙壁线分割成 2~3 个矩形区域。墙壁线颜色不全相同：部分为红(2)，部分为蓝(1)，每种颜色的墙壁线围成至少一个完整的矩形区域。每个区域内部有一个小周期瓦片（2x2 或 3x3）铺满，使用黄(4)、绿(3)、橙(7)等颜色，但其中有 2~4 个像素被替换为灰(5)（噪声）。网格某角落有一个灰(5)的 L 形箭头精灵体（2x2 缺一角，共 3 像素），缺角指向网格内部的对角方向。生成约束：箭头射线经弹射后只能到达部分区域（至少 1 个区域射线不可达）；射线到达某区域时会先碰到该区域的墙壁边界，从而继承墙壁颜色。

**规则**：
1. 从箭头精灵体出发，沿缺角对角方向发射射线。射线在黑(0)背景上传播（不绘制任何像素）。碰到墙壁像素时按弹射规则反射（正面碰撞翻转两轴，侧面碰撞翻转单轴），并记录碰撞墙壁的颜色。射线进入某个区域内部后继续传播，碰到该区域对面的墙壁时再次弹射。射线出网格或回到起始区域时停止。
2. 记录射线经过的所有区域及进入每个区域时最后碰撞的墙壁颜色。
3. 对射线到达的每个区域：在该区域内部推断最小周期瓦片（多数投票法，灰(5)像素参与投票但权重为 0），用干净瓦片替换区域内所有像素（包括修复灰(5)噪声）。
4. 射线未到达的区域：保持原样不变（包括其中的灰(5)噪声像素）。
5. 墙壁线、箭头精灵体保持不变。

**关键洞察**：同样包含噪声的两个区域命运不同——射线可达的区域被修复，不可达的区域噪声被保留——求解者必须先模拟射线弹射路径才能判断哪些区域需要修复，这使得物理模拟与图案修复不可分割。
