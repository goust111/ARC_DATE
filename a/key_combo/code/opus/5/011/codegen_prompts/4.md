## 新题 4：角位编码三角轮廓与相位平铺内部填充

**组合逻辑**：[放大画布 + 角位置对应](创新：角位置不再仅决定三角朝向，还决定平铺的起始相位) + [三角轮廓绘制](已有) + [解码 + 平铺](创新：平铺区域不再是完整矩形画布，而是三角轮廓围成的不规则内部)

**来源原语**：放大画布/expand_canvas、补全/complete、角位边角/corner_piece、三角轮廓/triangle_outline、角位置对应/corner_correspond、补对角线边/fill_diagonal_side（e3f79277）；平铺/tile、解码/decode、轮廓字形/contour_glyph、相位编码/phase_encoding（eee78d87）

**依赖链**：角位 L 形确定三角轮廓的位置和朝向（限定了内部区域的几何形状）；轮廓字形解码出周期瓦片（限定了填充的图案内容）；三角内部区域的形状又反过来决定了瓦片的裁剪边界和起始相位（由角位置决定瓦片从哪个相位开始铺设）。三者循环依赖：无角位则无三角、无字形则无图案、无三角则不知铺哪里。

根据角位 L 形在放大画布上绘制三角轮廓，再将字形解码的周期图案铺入三角内部，角位置同时决定铺设的相位起点。

**输入结构**：约 7x7 的网格，背景为黑(0)。网格中包含两个不重叠的元素：(a) 一个由红(2)像素构成的 L 形角位标记，位于网格的某个角落（左上/右上/左下/右下），L 的两条腿各长 2~3 像素、宽 1 像素，分别沿水平和垂直方向延伸并触及对应的网格边缘；(b) 一个由蓝(1)像素构成的 3x3 轮廓字形，位于网格中央区域，字形是以下四种之一：十字形、H 形、X 形或四角点。生成约束：L 形和字形的边界框不重叠。

**规则**：
1. 计算输出画布尺寸：边长 = 3n - 2，其中 n 为输入网格的边长。
2. 用黑(0)填充输出画布。
3. 根据 L 形角位确定三角轮廓的位置：L 的两条腿加倍长度即为三角的两条直角边长度，两条直角边沿输出画布的对应角落边缘放置，两条直角边的自由端点用对角线连接，构成直角三角形轮廓。轮廓用红(2)绘制，宽 1 像素。
4. 将蓝(1)的 3x3 字形解码为 3x3 的相位瓦片：字形中蓝(1)像素位置对应瓦片中黄(4)像素，字形中黑(0)像素位置对应瓦片中黑(0)像素。
5. 用此 3x3 瓦片周期平铺输出画布的内部。平铺的相位起点由角位置决定：左上角 → 从 (0,0) 开始铺设；右上角 → 从 (0, 画布宽-1) 对齐右边缘开始铺设；左下角 → 从 (画布高-1, 0) 对齐下边缘开始铺设；右下角 → 从 (画布高-1, 画布宽-1) 对齐右下开始铺设。
6. 仅保留严格位于三角轮廓内部（不含轮廓线本身）的平铺像素；轮廓外部和轮廓线上的平铺像素清除为黑(0)。三角轮廓线保持红(2)。

**关键洞察**：角位 L 形同时编码了两条信息——三角轮廓的几何朝向和周期平铺的相位起点——必须将同一个几何线索用于两个不同的变换步骤，仅看单个示例无法区分相位对齐规则与简单的默认左上起铺。

import hashlib
import numpy as np

p = Path("/home/lixinyu/snap/a/key_combo/code/opus/5/011/4.py")
mod = SourceFileLoader("new_arc_task", str(p)).load_module()
sigs = set()
for i in range(100):
    inp = mod.generate_input()
    out = mod.main(inp)
    assert isinstance(inp, np.ndarray)
    assert isinstance(out, np.ndarray)
    assert inp.ndim == 2 and max(inp.shape) <= 30, f"input grid exceeds 30x30: {inp.shape}"
    assert out.ndim == 2 and max(out.shape) <= 30, f"output grid exceeds 30x30: {out.shape}"
    sigs.add(hashlib.md5(inp.tobytes() + str(inp.shape).encode()).hexdigest())
print("variants", len(sigs))
assert len(sigs) >= 20
