## 新题 2：可达性门控的原型互换

**组合逻辑**：[可达性/reachability + 墙壁障碍/wall_barrier](创新：可达性不再用于筛选聚集目标，而是作为操作门控) + [替换/replace + 互换原型/toggle_to_alternate_prototype](创新：互换不再全局无条件执行，而是仅对可达子集生效)

**来源原语**：替换/replace、互换原型/toggle_to_alternate_prototype、原型精灵/prototype_sprite、原型配对/prototype_pairing（来自 c7f57c3e）；可达性/reachability、墙壁障碍/wall_barrier、标记像素/marker_pixel（来自 dd6b8c4b）；擦除/erase（来自 e3721c99）

**依赖链**：识别两种原型模式 → 从源标记出发洪水填充判定可达性 → 可达精灵体执行原型互换，不可达精灵体保持原样。可达性判定与原型识别是独立的两条信息来源，必须同时满足才能确定最终输出：可达性决定"哪些"互换，原型配对决定"换成什么"。

一句话总结：仅对从黄色标记出发经背景可达（不穿越墙壁）的精灵体执行原型互换，不可达精灵体保持不变。

**输入结构**：
- 背景：橙(7)。网格约 18x18。
- 品红(6) 像素构成墙壁障碍，形成不规则的连通屏障，将网格分割为 2-4 个不同的连通区域。墙壁厚度为 1 像素，总像素数约 15-25。
- 两种原型模式：原型 A 为蓝(1) 色的 3x3 十字形（中心 + 四个正交邻居，共 5 像素），原型 B 为红(2) 色的 3x3 菱形（中心 + 四个对角邻居，共 5 像素）。
- 6-8 个精灵体实例散布在网格中，每个精灵体为原型 A 或原型 B 的精确副本（比例因子 1），精灵体之间互不重叠，与墙壁不相邻。
- 恰好一个精灵体的中心像素被替换为黄(4)，标记该精灵体为"源"。源精灵体本身仍可识别其原型（通过周围 4 个臂像素的颜色判定）。
- 生成约束：源精灵体所在连通区域至少包含 2 个其他精灵体；至少 1 个精灵体位于源不可达的区域。两种原型在可达区域和不可达区域各至少出现 1 次。

**规则**：
1. 识别两种原型模式：蓝(1) 十字形为原型 A，红(2) 菱形为原型 B。
2. 以源精灵体的中心位置为种子，通过背景色(橙 7) 单元格进行 4-连通洪水填充。墙壁(品红 6)和所有精灵体像素阻断填充。记录所有被填充触及的单元格为"可达区域"。
3. 判定每个精灵体的可达性：若精灵体的任一像素与可达区域 4-相邻，则该精灵体可达。
4. 对每个可达精灵体（包括源精灵体）：将其替换为另一种原型——原型 A 变为原型 B（蓝像素变红，十字变菱形），原型 B 变为原型 A（红像素变蓝，菱形变十字）。替换时以精灵体原中心位置为对齐点。
5. 对每个不可达精灵体：保持原样不变。
6. 将源精灵体中心的黄(4) 标记像素替换为互换后原型的中心颜色（若源原本是 A 则变红(2)，若源原本是 B 则变蓝(1)）。

**关键洞察**：原型互换并非全局操作而是受墙壁拓扑控制的局部操作——相同类型的精灵体可能因位于墙壁不同侧而产生不同输出，仅看单个精灵体无法判断它是否会被互换，必须追溯其与源标记之间的连通关系。

## 实现要求

1. `main(grid)` 必须实现新题描述中的确定性转换规则，不能只识别 `generate_input()` 的固定模板。禁止不同的input网格输出相同的output网格。
2. `generate_input()` 必须随机生成多样样例，不能固定死。随机维度应覆盖：网格大小、对象数量、位置、颜色、方向、形状参数或关键分支。注意若描述中存在若干，需实现而不是只有单个，包括object或者对应关系等等。
3. 生成器必须保证输入满足 `main()` 的隐式假设：对象不重叠、不越界、特殊标记唯一或可区分、匹配关系无歧义、关键分支出现概率相同。
4. 禁止把 ARC 颜色 id 、亮度、拼写等当作人类不可见的数值语义参与排序、大小比较或隐藏映射。颜色变化必须有可见结构线索。注意颜色亮度、拼写等也是不可见信息，若描述中出现违规的颜色id或者亮度，可自行使用少量的固定颜色替代，但注意生成时要在三个以内输入输出网格中对所有变换100%覆盖度。
