## 新题 8：缩略图解码锚点定位与射线压缩

**组合逻辑**：[补全/complete + 缩略图/minimap + 坐标映射/coordinate_mapping + 已有块确认对齐/existing_blocks_confirm_alignment](创新：缩略图不再指导色块补全，而是解码锚块目标位置) → [压缩/compress + 锚块/anchor_block + 射线像素/ray_pixel + 同色射线归属锚块/ray_belongs_anchor + 射线像素紧缩至锚/compact_to_anchor](创新：压缩目标不是预置锚块的位置，而是由缩略图解码获得)

**来源原语**：补全/complete、缩略图/minimap、色块网格/colored_block_grid、坐标映射/coordinate_mapping、已有块确认对齐/existing_blocks_confirm_alignment（来自 c4d067a0）；压缩/compress、锚块/anchor_block、射线像素/ray_pixel、同色射线归属锚块/ray_belongs_anchor、射线像素紧缩至锚/compact_to_anchor（来自 f28a3cbb）

**依赖链**：缩略图中的彩色像素编码锚块在主网格中的目标位置 → 已有锚块校准缩放/偏移映射 → 在解码出的目标位置放置缺失锚块 → 散落的同色射线像素向对应锚块压缩。缩略图解码为压缩操作提供目标坐标，校准锚块同时服务于映射验证和压缩参照——两个操作通过锚块位置紧密耦合。

一句话总结：根据左上角缩略图解码出缺失锚块的位置并放置，然后将散落在各锚块射线方向上的同色像素紧缩至对应锚块。

**输入结构**：
- 背景：黑(0)。网格约 22x22。
- 左上角：一个 R x C 的小缩略图（如 3x4），每个像素为单色或背景色，形成颜色图案。缩略图中非背景像素的位置编码了主网格中锚块的目标位置。缩略图与主网格之间有 1-2 行/列的背景间隔。
- 主网格区域：按规则网格排列的位置中，部分位置已有 3x3 实心彩色锚块（如红(2)、蓝(1)、绿(3)、黄(4)），部分位置为空（全背景）。已有锚块的颜色和位置与缩略图中对应像素的颜色和位置一致（经过缩放和偏移映射）。
- 对每种出现在缩略图中的颜色，主网格中有 3-5 个同色孤立像素散布在该颜色锚块（已有或待补全）的水平/竖直射线方向上。
- 生成约束：至少 2 个锚块已存在（用于校准映射），至少 2 个锚块位置为空（需补全）。每种颜色至少有 2 个射线像素。缩略图中每个非背景像素恰好对应一个锚块位置。射线像素不与锚块、缩略图或其他射线像素重叠。

**规则**：
1. 识别左上角缩略图（与主网格通过背景间隔分离的最小矩形彩色区域）。
2. 利用已有锚块推断缩放因子 S 和偏移向量 (dr, dc)：缩略图中位置 (i, j) 的非背景像素对应主网格中位置 (dr + i*S, dc + j*S) 的 3x3 锚块中心。通过匹配已有锚块的颜色和位置确认 S 和偏移量。
3. 对缩略图中每个非背景像素，若其对应的主网格位置尚无锚块，在该位置放置一个该颜色的 3x3 实心锚块。
4. 对每种颜色的每个射线像素，确定其所属锚块：该像素与该颜色的某个锚块位于同一行或同一列，且两者之间无其他同色锚块。
5. 沿射线方向将每个散落像素向其所属锚块滑动，填入紧贴锚块边缘的第一个空位。同一方向的多个像素按离锚块从近到远的顺序依次填入。
6. 擦除缩略图（替换为背景色）。散落像素的原始位置替换为背景色。

**关键洞察**：锚块位置不是直接给出的——部分锚块缺失，其目标位置编码在缩略图中。已有锚块同时扮演两个角色：它们既是压缩操作的目标参照点，又是缩略图坐标映射的校准锚点。必须先解码缩略图补全锚块，才能正确执行射线压缩。
