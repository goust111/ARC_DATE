## 新题 5：边界标记定向的非对称间隙分割

**组合逻辑**：[射线延伸/ray_extend + 间隙对半分/gap_bisect + 奇数间隙留中线/odd_gap_midline](创新：奇数间隙的中线不再留空，而是由外部标记裁定归属) + [边界标记/boundary_marker + 标记指定观察方向/marker_view_dir](创新：标记不再指挥微型片段排序，而是决定间隙分割的偏向性)

**来源原语**：射线延伸/ray_extend、矩形/rectangle、间隙对半分/gap_bisect、奇数间隙留中线/odd_gap_midline（来自 d968ffd4）；边界标记/boundary_marker、标记指定观察方向/marker_view_dir、近远端色固定序/near_far_fixed（来自 f341894c）

**依赖链**：两个对齐矩形定义间隙 → 边界标记从外部指定"优先侧" → 间隙被非对称分割（优先侧多占一行/列）。标记方向同时确定哪个矩形在观察方向上更近（"近端"），近端矩形获得间隙中线的额外行/列。无标记则无法确定奇数间隙中线归谁；无矩形对则无间隙可分割。

一句话总结：两个同色同尺寸对齐矩形各自向对方延伸填充间隙的一半，当间隙为奇数宽时，边界标记所指方向的近端矩形多占一行/列。

**输入结构**：
- 背景：黑(0)。网格约 16x16。
- 2 对同色同尺寸的实心矩形（每对一种颜色，如红(2) 一对、蓝(1) 一对）。每对矩形在同一行跨度或同一列跨度上对齐，之间有 3-7 个像素的背景间隙。矩形尺寸约 3x4 或 4x3。
- 每对矩形关联一个位于网格边界上的标记像素，颜色为黄(4)。该标记所在的边（上/下/左/右）垂直于矩形对的对齐轴：
  - 若矩形对水平排列（左右关系），标记位于上边或下边。
  - 若矩形对竖直排列（上下关系），标记位于左边或右边。
- 每个标记像素与其对应矩形对通过同行/同列的空间对齐关系关联（标记的行/列在矩形对的行/列跨度范围内）。
- 生成约束：至少一对矩形的间隙为奇数宽度，至少一对为偶数宽度，以便对比归纳规则。不同矩形对互不重叠，标记之间互不冲突。

**规则**：
1. 识别同色同尺寸矩形对及其对齐方向（水平 = 左右对齐，竖直 = 上下对齐）。
2. 测量每对矩形之间面对面的间隙宽度 G（行数或列数）。
3. 找到每对矩形关联的黄(4) 边界标记。标记的位置决定"观察方向"：标记在上边 → 从上往下看；标记在下边 → 从下往上看；标记在左边 → 从左往右看；标记在右边 → 从右往左看。
4. 确定"近端矩形"：沿标记的观察方向看去，先遇到的那个矩形为近端，后遇到的为远端。对于水平排列：标记在上/下边时，观察方向为竖直方向，此时左右矩形本身无上下关系，改为：标记偏向哪个矩形的列范围则该矩形为近端。实际判定规则：标记的列坐标距离哪个矩形中心更近，则该矩形为近端。
5. 间隙分割：
   - 若 G 为偶数：间隙均分。近端矩形向远端延伸 G/2 行/列，远端矩形向近端延伸 G/2 行/列，颜色分别为各矩形自身颜色。延伸跨度为矩形的全宽/全高。
   - 若 G 为奇数：近端矩形延伸 (G+1)/2 行/列，远端矩形延伸 (G-1)/2 行/列（近端多占中间行/列）。
6. 标记像素保持不变。矩形原始像素保持不变。

**关键洞察**：边界标记的作用不是直接参与填充，而是打破间隙分割的对称性——偶数间隙时标记看似无用（因为均分），只有对比奇数间隙的示例才能发现标记决定了中线归属，且必须通过距离判定近端矩形。

## 实现要求

1. `main(grid)` 必须实现新题描述中的确定性转换规则，不能只识别 `generate_input()` 的固定模板。禁止不同的input网格输出相同的output网格。
2. `generate_input()` 必须随机生成多样样例，不能固定死。随机维度应覆盖：网格大小、对象数量、位置、颜色、方向、形状参数或关键分支。注意若描述中存在若干，需实现而不是只有单个，包括object或者对应关系等等。
3. 生成器必须保证输入满足 `main()` 的隐式假设：对象不重叠、不越界、特殊标记唯一或可区分、匹配关系无歧义、关键分支出现概率相同。
4. 禁止把 ARC 颜色 id 、亮度、拼写等当作人类不可见的数值语义参与排序、大小比较或隐藏映射。颜色变化必须有可见结构线索。注意颜色亮度、拼写等也是不可见信息，若描述中出现违规的颜色id或者亮度，可自行使用少量的固定颜色替代，但注意生成时要在三个以内输入输出网格中对所有变换100%覆盖度。
