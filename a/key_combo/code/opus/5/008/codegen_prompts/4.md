## 新题 4：前景射线切割与碎片金字塔重组

**组合逻辑**：[切割(cutting) + 射线分割区域(ray_partition) + 控制像素(control_pixel)](已有) → [滑动(sliding) + 边界归属决定保留(border_ownership_keeps)](已有) → [堆叠(stack) + 奇数宽度递增(odd_width_increment) + 基线对齐(baseline_aligned)](创新：滑动后的碎片不保持原形，而是将像素按金字塔规则重新排列)

**来源原语**：cutting、ray_partition、control_pixel、sliding、border_ownership_keeps（来自 4a21e3da）；stack、odd_width_increment、baseline_aligned（来自 3d6c6e23）

**依赖链**：控制像素射线切割前景对象 → 边界归属筛选保留碎片 → 碎片滑动到网格角落 → 碎片像素数决定金字塔层数 → 像素按金字塔规则重排。切割决定碎片像素数，像素数约束金字塔形状，形成跨步骤的数量耦合。

射线从边缘控制像素向内切割中心前景对象，保留靠近控制边的碎片滑到角落后，将碎片像素重新堆叠为底部对齐的居中金字塔。

**输入结构**：约 16x16 的网格，背景黑(0)。包含：
- **前景对象**：一个较大的蓝(1)单色 4-连通图形（20~30 像素），大致居中，形状不规则但无孔洞。
- **控制像素**：1~2 个红(2)单像素，位于网格边缘（每个在不同的边缘上）。
- **生成约束**：射线切割后，每个保留碎片的像素数为完全平方数（如 4、9、16），以确保金字塔完整。控制像素位置使得至少有 2 个保留碎片。

**规则**：
1. 从每个红(2)控制像素沿其所在行或列向网格内部发射射线。射线仅穿过背景像素（遇到蓝(1)前景像素时跳过，不中断射线，继续向前），直到对边边缘。
2. 射线将网格分为若干区域。蓝(1)前景对象被射线切割：位于切割线上的前景像素归属于包含控制像素所在边缘的区域。
3. 仅保留与控制像素共享网格边缘的区域中的蓝(1)碎片。其他区域的蓝(1)像素擦除为背景。若两个控制像素在不同边缘，各自边缘的区域碎片均保留。
4. 每个保留碎片向其所属控制边缘的最近角落滑动（平移到角落区域，碎片的边界框角对齐网格角落，留 1 像素边距）。
5. 滑动到角落后，碎片的像素被重新排列为底部对齐的居中金字塔：从底向上依次为宽度 2k-1, 2k-3, ..., 3, 1 的水平行（k 为层数，总像素 = k^2）。金字塔每行居中对齐，底行的中心列与角落区域的水平中心对齐，底行紧贴角落区域的底边（留 1 像素边距）。
6. 金字塔颜色保持蓝(1)。擦除控制像素。

**关键洞察**：切割位置决定每块碎片有多少像素，而像素数必须恰好是完全平方数才能形成完整金字塔。求解者需反向推断：生成约束保证像素数为平方数，因此金字塔层数 k = sqrt(像素数)，这将切割操作和堆叠操作通过数量关系紧密耦合。
