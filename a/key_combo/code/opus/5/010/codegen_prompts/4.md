## 新题 4：标记筛选后的周期遮罩射线

**组合逻辑**：[标记色筛选物体/marker_filters + 擦除/erase](已有) → [朝向编码方向/orientation_encodes_direction](创新：物体边界框长宽比编码射线方向而非 domino 朝向) → [射线延伸/ray_extend](已有) + [周期掩码/periodic_mask](创新：射线仅在周期激活的行/列上可见)

**来源原语**：指示条/indicator_bar, 标记像素/marker_pixel, 标记色筛选物体/marker_filters, 计数/counting, 擦除/erase — 来自参考题 edcc2ff0；矩形边框/rectangular_frame, 周期条纹/periodic_stripe, 周期掩码/periodic_mask, 射线延伸/ray_extend — 来自参考题 6a980be1；朝向决定方向/orientation_determines_direction, 微型标记/micro_marker — 来自参考题 9344f635

**依赖链**：顶行标记像素定义合法颜色集合 → 擦除不合法颜色的前景物体 → 幸存物体的边界框长宽比决定射线方向（宽>高→水平，高>宽→垂直）→ 从灰(5)边框内的橙(7)条纹推断周期掩码 → 射线仅在掩码激活的行或列上可见，形成间断虚线

标记筛选确定哪些物体可发射射线，物体朝向确定射线方向，边框内周期条纹定义射线的可见行列。

**输入结构**：黑(0)背景，约 18×18 的网格。第 0 行为黑(0)指示条，其中从第 0 列起有 2~3 个不同颜色的单像素标记（如红(2)、绿(3)），相邻标记之间间隔至少 1 个黑(0)像素。网格中央偏下有一个灰(5)一像素宽矩形边框（约 8×8 外尺寸），边框内部在等间距的行上有橙(7)水平条纹（如每隔 2 行一条，宽度 1 像素），形成周期行掩码。边框外散布 4~6 个单色 4-连通小物体（每个 3~8 像素），颜色包含标记中出现的颜色和未出现的颜色（如蓝(1)、黄(4)为非标记色）。每个物体的边界框为非正方形矩形（宽严格大于高或高严格大于宽）。生成时保证：至少有一个标记颜色对应 2 个以上物体；至少有一个非标记颜色的物体存在用于被擦除；各物体之间不接触。

**规则**：
1. 读取第 0 行指示条中所有非黑(0)像素的颜色，构成合法颜色集合 S。
2. 将网格中颜色不属于 S 的所有前景物体的像素重涂为黑(0)（擦除）。灰(5)边框和橙(7)条纹不受影响。
3. 对每个幸存物体，计算其边界框的宽 W 和高 H：W > H → 水平朝向，发射水平射线；H > W → 垂直朝向，发射垂直射线。
4. 射线从物体边界框的中心行（水平射线时取中心行，若像素数为偶则取偏上的行）或中心列（垂直射线时取中心列，若像素数为偶则取偏左的列）出发，向两端延伸至网格边界。
5. 从灰(5)边框内的橙(7)条纹推断周期行掩码：记录所有含橙(7)条纹的行号，计算行间距 p，将该周期延伸至整个网格高度，得到激活行集合。射线像素仅在激活行（对于水平射线）或激活列（对于垂直射线，需从边框内垂直条纹推断列周期；若边框内无垂直条纹则垂直射线全部可见）上绘制；非激活位置的射线像素不显示。
6. 射线颜色与发射物体颜色相同。射线不覆盖已有的非背景像素（包括幸存物体、灰(5)边框、橙(7)条纹）。

**关键洞察**：周期掩码像栅栏一样过滤射线——同一条连续射线在空间上变成间断的虚线段，虚线的间距由边框内条纹的周期决定，而非射线本身的任何属性；三个独立机制（标记筛选、朝向编码、周期掩码）会聚在最终输出上，缺少任何一个都无法正确绘制。
