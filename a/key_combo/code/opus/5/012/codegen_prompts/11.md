## 新题 11：连通分量面积排序控制印章缩放

**组合逻辑**：[裁剪(crop) + 连通分量(connected_component) + 面积递增排列(area_ascending_order)] → 排序结果编码缩放因子(创新：分量的面积排名决定印章的缩放倍数) → [印章放置(stamp) + 锚点标记(anchor_marker) + 颜色匹配(color_matching)] + [拉伸(stretch)]

**来源原语**：裁剪、连通分量、按面积筛选（337b420f）；面积递增排列、排序（8abad3cf）；印章放置、锚点标记、颜色匹配、最少色为锚点（a251c730）；拉伸（465b7d93）

**依赖链**：裁剪出源区域中的各个连通分量并按面积排序 → 面积排名第 k 的分量被缩放 k 倍 → 缩放后的分量按锚点标记颜色匹配印章到目标区域中的对应位置。面积排序决定缩放因子，颜色匹配决定放置位置，两者共同决定最终输出。

源区域中的连通分量按面积从小到大排名，排名即为缩放倍数，缩放后按锚点颜色匹配印章到目标区域。

**输入结构**：约 18x10 的网格。背景为黑(0)。网格左半部分为源区域，包含 3 个不同颜色（红(2)、蓝(1)、绿(3)）的 4-连通分量，每个分量 2~6 像素，形状各异，分量之间不相邻。每个分量中有一个像素颜色与其余不同，该像素颜色为黄(4)、灰(5)、品红(6) 之一，作为锚点标记（每个分量中最少的颜色）。网格右半部分为目标区域，全为背景色，其中有 3 个孤立的标记像素，颜色分别为黄(4)、灰(5)、品红(6)，与源区域的锚点颜色一一对应。生成约束：三个分量的面积（包括锚点像素）互不相等。缩放后的分量在目标区域中不会相互重叠也不会超出网格边界。

**规则**：
1. 在源区域中找到所有非背景连通分量。对每个分量，识别其主体色和锚点色（像素数最少的颜色）。
2. 将分量按总面积（像素数）从小到大排序，赋予排名 1、2、3。
3. 对排名为 k 的分量，将其裁剪到最小边界框，然后进行 k 倍等比缩放：原分量中每个像素扩展为 k x k 的像素块，保持颜色不变。
4. 在目标区域中找到与分量锚点色相同的标记像素。将缩放后的分量平移，使其缩放后的锚点像素块的左上角与目标标记像素对齐。
5. 将缩放后的分量绘制到目标区域，覆盖背景。若缩放后的分量之间有重叠，排名大的（面积大的、缩放倍数大的）先绘制，排名小的后绘制并覆盖在上层。
6. 擦除源区域的所有内容（置为背景色）。擦除目标区域中已被分量覆盖的标记像素。
7. 输出完整网格。

**关键洞察**：面积排名不只是排序标签——它直接转化为缩放倍数，使最小的分量保持原尺寸而最大的分量变成 3 倍大小。这意味着面积排序的结果会被"放大"体现在输出中：如果排序错误，不仅位置错误，大小也错误。必须对比示例中分量面积与输出中对应图案大小的关系才能发现这一规则。
