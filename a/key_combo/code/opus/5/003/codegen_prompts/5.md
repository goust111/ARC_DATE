## 新题 5：重力投递种子像素决定腔体填充归属

**组合逻辑**：[重力下落](创新：下落物不是待排列的标记而是待分配的种子——重力路径决定种子与腔体的配对关系) + [填充](保留封闭腔体的泛洪填充核心，但种子不是固定在边界的静态点，而是经重力路径到达的动态着陆点) + [障碍拦截](从"穿透或停靠"简化为"障碍阻断种子到达腔体"的过滤机制)

**来源原语**：重力下落/边缘标记/障碍物/控制色定行为(963c33f8)，填充/种子像素/封闭腔体/线条画/连通可达/种子色标记填充(8b7bacbf)

**依赖链**：种子像素从顶边下落 → 障碍物拦截部分种子（搁浅） → 未被拦截的种子落在线条画边界上 → 着陆点决定种子与哪个封闭腔体相邻 → 相邻腔体被该种子颜色泛洪填充。删除重力下落则种子停在顶边无法到达任何腔体；删除泛洪填充则种子着陆但腔体不变。种子-腔体配对完全由重力路径和障碍布局决定——移动一个障碍可能让种子滑过原本的目标到达另一个腔体，彻底改变输出。这是"路由决定赋值"的结构，非线性流水线。

种子像素从顶边下落，着陆位置决定它填充哪个封闭腔体；被障碍拦截的种子搁浅，不填充任何腔体。

**输入结构**：

- 约 20x20 网格，背景黑(0)。
- 下方约三分之二区域：灰(5)像素绘制的线条画，形成 3~5 个互不嵌套的封闭环路，每个环路围成一个大小不同的背景色腔体（腔体面积 4~20 像素）。环路之间互不接触，由背景隔开。
- 上方约三分之一区域：若干灰(5)障碍像素散布其中，不属于任何线条画环路（4-连通不与任何环路相连）。
- 顶边（第 0 行）上放置 3~5 个不同颜色的种子像素（如红(2)、蓝(1)、绿(3)、黄(4)、橙(7)），各占不同列。
- 生成约束：每个种子的正下方列最终经过恰好一个环路的边界（确保着陆唯一性）；不同种子着陆后相邻的腔体各不相同（一对一映射）；至少一个种子的正下方有障碍像素阻挡，使其搁浅于障碍上方而非到达任何环路。

**规则**：

1. 每个种子像素从顶边向下做重力下落（每次移动 1 格）。
2. 种子在遇到正下方第一个非背景像素时停止——停在该像素正上方一格。该非背景像素可能是灰(5)障碍像素或灰(5)线条画像素。
3. 判断种子着陆处下方的灰(5)像素是否属于某个封闭环路的边界：
   - 若该灰(5)像素属于某个封闭环路（4-连通追踪可达一个完整闭合结构）：种子"到达"该环路。对该环路围成的背景腔体执行 4-连通泛洪填充，填充色为种子颜色。填充完成后种子本身被消耗（从输出中移除，仅保留填充后的腔体）。
   - 若该灰(5)像素不属于任何封闭环路（孤立障碍像素或开放线段）：种子"搁浅"。种子保留在着陆位置，不对任何腔体执行填充。
4. 线条画（所有灰(5)环路和障碍像素）在输出中保留不变。
5. 未被任何种子到达的封闭腔体保持背景色不变。

**关键洞察**：障碍像素是拦截器——它们在种子到达腔体前将其捕获，阻止特定填充的发生。障碍的空间布局决定了哪些种子到达哪些腔体，构成一个重力路由谜题。移动一个障碍可能让种子落到不同的腔体上，完全改变输出。必须对比多个示例才能发现：(a)"搁浅"与"到达"的区别取决于着陆点下方像素是否属于闭合环路；(b) 成功填充的种子被消耗而搁浅的种子保留。
