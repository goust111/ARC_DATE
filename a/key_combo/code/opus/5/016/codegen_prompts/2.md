## 新题 2：对齐比较门控的对称补全

**组合逻辑**：[对称补全](保留投射机制) + [对齐比较 + 颜色匹配定去向](创新：比较结果决定补全或擦除) + [擦除](已有)

**来源原语**：对称补全/symmetric_complete、凸起/tab、缺口/notch、对侧互补/opposite_side_complement、跨行列投射/cross_span_projection（来自 8dab14c2）；分隔线/separator_line、参考像素/reference_pixel、对齐比较/aligned_comparison、颜色匹配定去向/color_match_dest、擦除/erase（来自 7d7772cc）

**依赖链**：分隔线将参考像素与边界特征对齐；颜色比较的结果（匹配 vs 不匹配）决定每个凸起/缺口是被对称补全还是被擦除——不是所有边界特征都有资格补全，补全是有条件的。自上而下的处理顺序使先处理的补全可能改变后续特征的边界上下文。

根据参考像素的颜色匹配结果，选择性地对矩形形状的边界凸起和缺口执行对称补全或擦除。

**输入结构**：约 15x20 的网格，黑(0)为背景。一条全高的灰(5)竖直分隔线将网格分为左右两区。左区：一个青(8)填充的厚实直角多边形（约占左区 60% 面积，边界厚度至少 3 像素），其边界上有 3-6 个单像素凸起（向外突出的青(8)像素，仅 1 个 4-邻居是青(8)）和单像素缺口（向内凹入的背景像素，恰好 3 个 4-邻居是青(8)）。这些凸起和缺口分布在形状的左右两侧边界上。右区：一列彩色参考像素，每个参考像素的行坐标与左区某个凸起或缺口的行坐标对齐。参考像素的颜色为青(8)或红(2)（各至少出现一次）。生成约束：每个凸起/缺口恰好对应一个参考像素；凸起和缺口不相邻（间隔至少 2 行）。

**规则**：
1. 识别左区形状边界上的所有凸起和缺口。
2. 自上而下逐个处理每个凸起/缺口（按行坐标从小到大）。
3. 对于当前特征，读取右区同行的参考像素颜色：
   - 若参考像素颜色 = 青(8)（与形状同色）：执行对称补全——沿该特征所在行或列横穿形状，在对侧边界添加互补特征（凸起→对侧加凸起，缺口→对侧加缺口）。投射距离 = 形状在该行/列的跨度。
   - 若参考像素颜色 = 红(2)（与形状异色）：执行擦除——将凸起像素改为背景(0)，或将缺口像素填为青(8)，使该处边界变得平滑。
4. 处理完毕后，移除分隔线和所有参考像素（置为背景(0)）。
5. 输出为处理后的左区内容（不含分隔线及右区）。

**关键洞察**：在 8dab14c2 中所有边界特征无条件补全，在 7d7772cc 中颜色比较决定移动方向。这里颜色比较决定的是一个更根本的分支——补全还是销毁。补全会在对侧创造新的边界像素，这可能改变后续特征的边界判定（一个先被补全的凸起可能在对侧创建了一个新像素，影响后续缺口的 4-邻居计数），使处理顺序成为隐蔽的关键规则。

p = Path("/home/lixinyu/snap/a/key_combo/code/opus/5/016/2.py")
mod = SourceFileLoader("new_arc_task", str(p)).load_module()
sigs = set()
for i in range(100):
    inp = mod.generate_input()
    out = mod.main(inp)
    assert isinstance(inp, np.ndarray)
    assert isinstance(out, np.ndarray)
    assert inp.ndim == 2 and max(inp.shape) <= 30, f"input grid exceeds 30x30: {inp.shape}"
    assert out.ndim == 2 and max(out.shape) <= 30, f"output grid exceeds 30x30: {out.shape}"
    sigs.add(hashlib.md5(inp.tobytes() + str(inp.shape).encode()).hexdigest())
print("variants", len(sigs))
assert len(sigs) >= 20
