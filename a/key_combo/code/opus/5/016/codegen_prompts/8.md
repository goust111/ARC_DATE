## 新题 8：管道路由决定图例着色的令牌下落

**组合逻辑**：[重力下落](保留管道物理) + [旋转/闸门](保留闸门开启) + [重涂色 + 图例映射颜色](创新：落点列索引图例条目)

**来源原语**：重力下落/gravity_drop、令牌/token、管道网络/pipe_network、闸门/gate、旋转/rotate、入口侧决定列/entry_side_determines_column、碰撞停止/collision_stop（来自 2b83f449）；填充/fill、颜色图例/color_legend、图例映射颜色/legend_maps_color、处理顺序保护/processing_order_protection（来自 9385bd28）

**依赖链**：闸门旋转改变管道拓扑→管道拓扑决定令牌下落路径→令牌最终落入哪一列→该列底部的图例色块决定令牌的最终颜色。物理路由（来自 2b83f449）与颜色映射（来自 9385bd28）通过"列位置"这一中间变量紧耦合——令牌的最终颜色不取决于自身初始颜色，而取决于它被管道引导到了哪一列。

令牌落入管道网络后，以最终所在列的底部图例色块重新着色。

**输入结构**：约 15x12 的网格。黑(0)为管道壁，橙(7)为管道内部（背景/可通行区域）。管道网络由黑(0)壁围成若干竖直和水平通道，形成 3-4 条从顶部通向底部的路径，路径在中部有交叉或分岔。网格内有 2-3 个水平 1x3 的灰(5)闸门横跨管道。令牌为 1 像素的彩色像素（如红(2)、蓝(1)、绿(3)），位于网格顶行的管道入口处（橙(7)像素的正上方或同行）。网格最底行：每个管道出口列放置一个彩色像素作为图例色块（颜色与令牌颜色均不同，如黄(4)、品红(6)、青(8)等），每列至多一个。生成约束：令牌数量 <= 管道出口数量；每个管道出口列恰好有一个图例色块；闸门旋转后不会完全封堵所有通向某出口的路径（保证每个令牌都能到达某个出口）。

**规则**：
1. 开启闸门：每个 1x3 水平闸门旋转为 3x1 竖直——闸门原占的 3 个像素变为橙(7)（可通行），同时在闸门中心像素的正上方和正下方各放置一个黑(0)壁像素（模拟竖直闸门占位）。若上方或下方已是壁或网格边界则不重复放置。
2. 令牌下落：按令牌从左到右的顺序依次处理。每个令牌从其初始位置向下移动：
   - 在橙(7)格内逐格下落。
   - 遇到水平分岔时，令牌选择入口侧对应的极端列（从左侧入→选最左列，从右侧入→选最右列）。
   - 遇到已停下的其他令牌或壁则停止（碰撞停止），停在障碍物正上方的最后一个橙(7)格。
   - 令牌原始位置恢复为橙(7)。
3. 图例着色：每个令牌停下后，读取其所在列最底行的图例色块颜色，将令牌像素重涂为该颜色。若令牌停下的列在最底行没有图例色块（因碰撞停在了非出口列），令牌保持原色不变。
4. 移除最底行的所有图例色块（置为橙(7)）。
5. 输出为处理后的完整网格。

**关键洞察**：令牌的最终颜色不由自身决定，而由管道网络的物理路由决定——闸门的旋转改变了管道拓扑，管道拓扑决定令牌落入哪列，落入的列决定图例查找的结果。这是一条从物理模拟到颜色映射的间接因果链，将 2b83f449 的路由机制和 9385bd28 的图例映射通过"列位置"这一涌现变量连接在一起。
