**组合逻辑**：[归一化朝向](创新：朝向不固定，由外部信号决定) + [排列/紧凑排列](保留打包规则) + [对齐比较 + 颜色匹配定去向](创新：匹配结果映射为宽/高朝向)

**依赖链**：在 d749d46f 中每个矩形无条件产生横竖两份副本。这里每个矩形只出现一次，朝向由外部参考像素的颜色比较结果决定——匹配则横放、不匹配则竖放。参考像素移除了"双份"的确定性，引入了逐个体的条件分支。矩形的最终视觉形态取决于两步互相依赖的推理：先做颜色比较确定朝向，再按朝向计算打包布局。

每个矩形根据其颜色与对齐参考像素的匹配结果选择横放或竖放，然后统一打包。

**输入结构**：约 15x20 的网格，黑(0)为背景。一条全高的灰(5)竖直分隔线位于网格中部偏右（如 col 12）。分隔线左侧：3-5 个不同颜色的实心矩形（非正方形，如 2x4、3x5、1x3 等），从上到下间隔排列，颜色各不同（如红(2)、蓝(1)、绿(3)、黄(4)）。分隔线右侧：一列参考像素，从上到下排列，每个参考像素的行坐标与左侧一个矩形的垂直中心对齐。参考像素颜色为左侧矩形颜色之一（可与对齐的矩形同色或异色）。生成约束：矩形均为非正方形（宽 != 高）；参考像素数量 = 矩形数量，一一对应。

**规则**：
1. 按从上到下的顺序配对每个矩形与其对齐的参考像素。
2. 对每一对，比较矩形颜色和参考像素颜色：
   - 颜色相同 → 横放：该矩形以 min(h,w) 行 x max(h,w) 列的形态呈现，顶部对齐到输出网格 row 0。
   - 颜色不同 → 竖放：该矩形以 max(h,w) 行 x min(h,w) 列的形态呈现，底部对齐到输出网格最后一行（row 9）。
3. 构建一个 10 行的输出画布（宽度 = 所有矩形打包后的总宽度）。
4. 按输入中从上到下的顺序，将矩形从左到右依次排入画布，相邻矩形间隔 1 列背景。横放矩形顶部对齐 row 0，竖放矩形底部对齐 row 9。
5. 画布背景色为黑(0)。分隔线和参考像素不出现在输出中。

**关键洞察**：在 d749d46f 中所有矩形都产生两份（横+竖），朝向是确定的。在 7d7772cc 中颜色匹配决定移动方向（靠近 vs 远离分隔线）。这里颜色匹配决定的是朝向选择——每个矩形只出现一次，但其形态由外部参考信号控制。这使得输出无法仅从矩形尺寸推断，必须同时考虑参考像素的颜色。
