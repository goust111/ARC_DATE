## 新题 4：计数奇偶门控架子渗透性的瀑布级联

**组合逻辑**：[重力下落/gravity_drop](已有) + [溢出扩散/overflow_spread](已有) + [计数/counting](创新：计数结果不再直接产出填充长度，而是作为奇偶门控改变架子的物理属性)

**来源原语**：gravity_drop、overflow_spread、水源/water_source、架子/shelf、级联分支/cascading_branch、碰撞停止/collision_stop（参考题 36a08778）；counting、计数像素/counter_pixel（参考题 2a28add5）

**依赖链**：计数架子上的标记点 → 奇偶性决定架子渗透/阻挡 → 渗透性改变瀑布级联路径 → 级联路径决定水流终点。计数和重力在同一空间结构（架子）上交互：计数改变架子属性，架子属性改变重力行为。

水流从顶部源头向下流动，遇到架子时根据架子上绿色标记点的奇偶数量决定架子是渗透（水穿过）还是阻挡（水溢出到两端），渗透/阻挡的判定从根本上改变了瀑布的级联分支拓扑。

**输入结构**：黑(0)背景，网格约 18x22。顶行有 1-2 个蓝(1)水源像素簇（每簇 1-3 像素宽）。网格中分布 4-6 条灰(5)水平架子段，每条架子为 1 像素高、4-10 像素宽，处于不同行。每条架子的表面（紧贴架子上方一行）散布若干绿(3)标记点像素，标记点的列号落在架子的水平范围内。生成约束：每条架子的绿色标记点数量在 1-4 之间；至少有一条架子标记点为奇数、至少一条为偶数；整个级联路径中至少存在一处因渗透/阻挡差异导致水流到达不同终点的分叉。

**规则**：
1. 对每条灰(5)架子，计数其正上方一行中与架子水平范围重叠的绿(3)标记点像素数量 N。
2. 若 N 为奇数：该架子为渗透架子——水流可以穿透它继续下落，架子不阻挡水流。
3. 若 N 为偶数：该架子为阻挡架子——水流被阻挡后沿架子表面水平扩散至架子两端，然后从两端各向外延伸 1 像素位置开始继续下落（即标准溢出）。
4. 水从蓝(1)源像素逐列向下流动，将经过的背景像素涂为蓝(1)。水流遇到阻挡架子时执行第 3 步的溢出。水流遇到渗透架子时直接穿过继续下落。水流到达网格底边时停止。
5. 多条水流在同一列相遇时合并为一条。水流不会穿过其他水流已占据的像素（自然合并，不阻挡）。
6. 输出中保留灰(5)架子和绿(3)标记点，蓝(1)水流覆盖在背景上。

**关键洞察**：绿色标记点不是装饰——它们的数量奇偶性决定每条架子是"实体墙"还是"虚空"。删除或添加一个标记点就能翻转一条架子的物理属性，从而将整棵瀑布级联树的拓扑结构彻底改变。

    sigs.add(hashlib.md5(inp.tobytes() + str(inp.shape).encode()).hexdigest())
print("variants", len(sigs))
assert len(sigs) >= 20
