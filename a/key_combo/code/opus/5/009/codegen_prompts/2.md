## 新题 2：描边围栏捕获重力落点触发空洞重涂

**组合逻辑**：[描边/draw_outline](已有) → [重力下落/gravity_drop](已有) → [重涂色/recolor](创新：重涂条件不再由对象自身属性决定，而由外部落点事件触发)

**来源原语**：draw_outline、前景对象/foreground_object、封闭孔洞/enclosed_hole、包含关系/containment、有孔触发重涂/hole_presence_triggers_recolor（参考题 aa4ec2a5）；gravity_drop、碰撞停止/collision_stop（参考题 36a08778、88e364bc）

**依赖链**：描边在对象周围创建一圈红色屏障 → 屏障改变重力下落路径（部分点被屏障拦截而无法进入空洞） → 落点是否落入空洞决定该对象是否被重涂。三步环环相扣：无描边则无屏障，落点路径不同；无重力则不知道哪些空洞被"命中"；无重涂则最终结果无法确定。

在前景对象周围画红色描边，描边形成围栏改变黄色散点的重力下落轨迹，最终根据散点是否落入对象的封闭空洞来决定是否重涂该对象。

**输入结构**：黑(0)背景，网格约 20x20。网格中散布 4-5 个蓝(1)前景对象，每个是 4-连通的单色连通分量，约 10-20 像素。其中 2-3 个对象内部有封闭空洞（对象包围框内被对象像素 4-连通包围的背景区域），其余对象为实心。在所有前景对象的上方（行号更小的位置），散布若干黄(4)单像素点，每个点下方的垂直路径上至少存在一个前景对象或其未来描边位置。生成约束：描边完成后，部分黄点的下落路径恰好通过某个空洞对象的空洞开口进入空洞内部，其余黄点被描边或对象表面拦截。至少一个空洞对象会被命中，至少一个空洞对象不会被命中。

**规则**：
1. 对网格中每个蓝(1)前景连通分量，在其 8-邻域的所有背景像素位置画红(2)描边（即对象边界向外扩 1 像素的壳层，仅占据原为背景的像素）。
2. 所有黄(4)像素执行重力下落：每个黄像素沿所在列逐行向下移动，遇到红(2)描边像素、蓝(1)对象像素、另一个已停止的黄像素、或网格底边时停止，停在障碍物正上方一格。多个黄像素在同一列时从最低的开始依次结算。
3. 下落结束后，检查每个含封闭空洞的蓝(1)对象：若至少一个黄像素停留在该对象封闭空洞内部（即停留位置处于对象包围框内、且该位置原为被对象像素 4-连通包围的背景像素），则该对象被"命中"。
4. 被命中的对象：将其蓝(1)体色重涂为青(8)，并将其所有封闭空洞（无论是否有黄像素）填充为品红(6)。品红填充覆盖空洞内已停留的黄像素。
5. 未被命中的空洞对象和所有实心对象保持蓝(1)不变。描边保持红(2)。未落入空洞的黄像素保留在其停止位置。

**关键洞察**：描边屏障在对象周围构建了额外的遮挡层，它既是视觉标记又是物理障碍——描边的存在改变了黄点的下落路径，使得只有特定列的黄点能穿过描边缺口进入空洞。重涂条件不再是对象自身"有洞就重涂"，而是"有洞且洞被外部事件命中才重涂"。
