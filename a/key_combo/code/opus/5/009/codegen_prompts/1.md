## 新题 1：裂缝分裂后的互补形状配对填充

**组合逻辑**：[滑动/slide](创新：不再物理推开两半，而是用裂缝将对象分解为候选子形状) + [形状匹配/shape_match](已有) + [填充/fill](已有)

**来源原语**：slide、裂缝标记线/fracture_line、沿短轴分裂/split_along_short（参考题 2faf500b）；shape_match、模板缺口/template_gap、互补形状/complementary_shape、缺口形状唯一配对/unique_complement（参考题 18447a8d）

**依赖链**：裂缝分裂产生子形状 → 子形状的几何外形决定其与哪个模板缺口互补 → 互补匹配成功后才能确定填充位置和颜色。删除裂缝分裂步骤则子形状不存在、匹配无法进行；删除匹配步骤则不知道哪个子形状填入哪个缺口。

将带有裂缝标记线的前景对象沿裂缝分裂为两个子形状，再将每个子形状与模板缺口进行互补匹配，匹配成功的子形状填入缺口。

**输入结构**：黑(0)背景，网格约 18x18。网格分为上下两个水平区域，中间隔 1-2 行背景。上区域放置 3 个前景对象，每个对象是一种独立颜色（分别为绿(3)、黄(4)、橙(7)），每个对象是 4-连通的单色连通分量，约 8-12 像素。每个对象内部嵌有一条灰(5)裂缝标记线——宽 1 像素、沿对象包围框短轴方向完整贯穿对象。裂缝将每个对象分为两个子形状，且同一对象的两个子形状在归一化后形状不同。下区域放置 3 个蓝(1)模板矩形（约 5x5 至 7x7），每个矩形内部有一块不规则缺口（缺口由矩形内的背景色像素构成）。生成约束：每个对象的两个子形状中恰好有一个与某个模板缺口的归一化形状完全相同，且三个对象的匹配目标互不重复（一一对应）。

**规则**：
1. 对上区域的每个前景对象，定位其灰(5)裂缝标记线（1 像素宽、沿包围框短轴方向完整贯穿对象的灰色像素段）。
2. 移除裂缝像素（置为背景），将裂缝两侧的体色像素分为两个独立子形状。每个子形状归一化为相对于自身包围框左上角的坐标集合。
3. 对下区域的每个蓝(1)模板矩形，计算其缺口形状 = 模板矩形包围框内所有背景色像素的坐标集合，归一化为相对于缺口最小包围框左上角的坐标集合。
4. 将每个子形状与所有缺口形状匹配：归一化形状完全相同即为匹配（不旋转、不翻转）。每个缺口恰好匹配一个子形状。
5. 输出：将匹配成功的子形状填入对应模板缺口位置，填充颜色为该子形状的原体色。上区域中，匹配成功的子形状和裂缝线被擦除（置为背景），未匹配的子形状保留原位。模板矩形的蓝(1)像素保留不变。

**关键洞察**：待匹配的形状在输入中不可见——它们隐藏在完整对象的裂缝两侧，只有正确识别并移除裂缝标记线后，子形状才"浮现"，之后才能与模板缺口进行互补配对。
