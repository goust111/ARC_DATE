```text
从九个瓦片中投票重建从未画出的原型图案，并输出一张 3x3 的瓦片级差错地图。

输入结构
- 网格恰为 3x3 个同尺寸瓦片的拼接，每个瓦片都是同一原型图案的副本。
- 每个副本至多有一个像素被改成了某种非背景的错误颜色，错误颜色可各不相同。
- 原型图案本身从未单独给出。

规则
- 对每个瓦片内坐标取九个瓦片的多数颜色，重建原型。
- 逐瓦片与原型比对，输出一个 3x3 网格：
  损坏瓦片对应格写入该瓦片中错误像素的颜色，完好瓦片对应格为背景 0。

关键洞察
- 答案不在像素层而在瓦片层：先靠跨瓦片多数投票凭空恢复原型，
  再把逐像素差异聚合成一张 3x3 的摘要图；原型与差错都不曾直接可见。
```
