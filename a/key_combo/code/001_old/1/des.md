## 新题 1：图例改写射线的通行规则

**组合逻辑**：[微型图例/图例色替换](创新：图例不再静态替换全图颜色，而是定义射线的"可穿透墙色→穿透后转变色"动态规则) → [边缘标记+射线延伸]（已有原语） → [墙段阻挡/穿透判定]（创新：阻挡与否由图例内容决定，重涂色只发生在射线实际穿过的墙格上）

**来源原语**：微型图例、颜色替换映射、图例色替换（e9b4f6fc）；边缘标记、射线延伸、墙段（f9a67cb5、8886d717）；重涂色（e9b4f6fc）；擦除（494ef9d7）

**依赖链**：图例是一条"通行法则"——它指定唯一可被穿透的墙色以及穿透后该墙格的新颜色。射线走多远取决于图例（决定哪种墙挡它），哪些墙格被重涂又取决于射线几何路径（只有被射线穿过的墙格才变色）。删掉图例则无法判定射线终点，删掉射线则无法确定哪些格被换色——两条逻辑在"触发条件"层面互锁。

- **摘要**：边缘上的单像素标记向网格内部发射一条直线射线。网格内有两种颜色的墙段挡路，角落里一个异色双像素图例规定：左色的墙可被穿透且穿透处变为右色，其余颜色的墙一律挡停射线。输出画出射线路径、改写被穿过的墙格、擦除图例。
- **输入**：黑(0)背景网格（约 10x14 至 14x14）。恰有一个单像素标记位于某条边界上（颜色任意，与其他前景色不同）。内部有 3~6 段轴对齐的单色直线墙段（每段 3~6 像素，宽 1 像素），墙段共用恰好 2 种颜色，均不同于标记色；至少一段墙横在射线路径上。另有一个水平相邻的双像素图例，两格颜色互不相同：左格颜色是两种墙色之一，右格颜色在输入其他位置不出现；图例与所有墙段、标记的切比雪夫距离 ≥ 2（保证可通过"2 像素且双色"唯一识别图例）。
- **输出**：与输入同尺寸。从标记出发垂直于所在边向内逐格推进：当前格为黑(0)则涂成标记色；下一格是图例左色的墙格，则把该墙格涂成图例右色并继续推进（该格不涂标记色）；下一格是任何其他颜色的墙格，则射线停止（该墙格保持原色）；到达对侧边界则结束。未被射线穿过的墙格全部保持原色。图例两格擦为黑(0)。标记本身保留原色原位。其余格与输入相同。
- **key**：必须先在多个示例间对比才能归纳出图例的语义（左色=可穿透的墙色、右色=穿透后的颜色），单看一例无法区分"左右哪个是源色"；射线的终点和被改写的墙格集合由图例与墙的几何布局共同决定，属于"操作 A（读图例）改变操作 B（射线推进）的触发条件"的紧耦合，任何一步都不可跳过。

## 新题 2：列唯一约束下的左滑停靠

**组合逻辑**：[滑动]（已有原语，改造：滑动终点不再由"碰到同伴"决定） → [行列唯一约束](创新：约束不再用于补全空格，而是作为滑动的动态停靠条件) → [擦除原位]（已有原语）

**来源原语**：滑动、擦除（494ef9d7）；行列唯一约束、拉丁方约束（4cd1b7b2）；标记像素（8886d717）

**依赖链**：每个像素向左滑动，但停靠列由"上方已定格像素的颜色分布"决定——先处理的行改变后处理行的合法停靠位置。滑动（操作）与列唯一（条件）不是先后两步，而是每一步滑动都在实时查询约束状态；约束状态又是此前滑动结果累积出来的。

- **摘要**：所有彩色像素向左紧凑排列，但一个像素不能停在"上方行已有同色像素"的列里，遇到这种列就跳过继续找下一列。逐行自上而下结算,输出最终排布。
- **输入**：黑(0)背景方形网格（8x8 至 12x12）。若干行（至少 4 行,不必连续）各含 1~3 个彩色像素（颜色 1~9,同一行内颜色互不相同，不同行之间允许同色重复出现）；其余行全黑。生成约束：按下述规则结算时，每个像素总能在网格宽度内找到合法停靠列。
- **输出**：与输入同尺寸。按行号从小到大处理每个非空行；行内像素按列号从小到大依次结算。每个像素的停靠列是满足以下两个条件的最小列号 c：(a) c 未被本行已结算的像素占用；(b) 在所有已结算完成的行中，列 c 不存在与该像素同色的像素。像素落位到 (本行, c)，原位置置黑。全部像素结算完毕后的网格即为输出；空行保持全黑。
- **key**：单看一例像"向左的重力压缩"，但部分像素会莫名停在更靠右的列——只有对比多例才能归纳出"同色不同列"的隐蔽约束。这不是流水线：不存在"先滑动再检查"的分离阶段，每次滑动的合法性依赖此前所有滑动的结果（状态累积型约束满足），删掉约束退化为平凡重力，删掉滑动则约束无从体现。

## 新题 3：同心环的色数循环移位

**组合逻辑**：[同心环](创新：环从"被绘制的输出物"变为"输入的分解单元") → [计数]（已有原语，改造：按环分别计数而非全局计数） → [循环移位](创新自"循环填充/等距偏移"：偏移发生在环形闭合路径上，步长逐环独立)

**来源原语**：同心环（d22278a0）；计数（6e02f1e3）；循环填充、等距偏移（05269061）；嵌套层、块序映射层序（8fff9e47）

**依赖链**：必须先把网格分解为以中心格为核的一圈圈方形环（结构解构），再对每个环独立统计其非黑颜色数 k，最后把该环上的全部内容沿环形路径顺时针循环移动 k 格。计数的对象由分解产生，移位的步长由计数产生，三者缺一不可；且每个环的参数互不相同，无法用一次全局操作替代。

- **摘要**：把奇数边长方阵分解为围绕中心格的同心方环。每个环上的像素沿环顺时针整体循环移动 k 格，k 等于该环上出现的非黑颜色种数。中心格不动。
- **输入**：奇数边长的方形网格（7x7、9x9 或 11x11），黑(0)背景。把网格看作围绕中心格的若干同心方环（边长 s 的环含 4(s-1) 个格）。每个环上散布若干彩色像素（占环格数的 20%~60%），恰用 1~3 种互不相同的非黑颜色；环与环之间用色可以重叠。中心格为黑或任一颜色。像素在环上的排布无对称性（生成约束：任何环整体循环移位 1~3 格后与原环不同，保证答案可判别）。
- **输出**：与输入同尺寸。对每个同心环独立操作：设该环上非黑颜色种数为 k（1≤k≤3），把环上全部 4(s-1) 个格的内容（含黑格）沿环形路径顺时针循环移动 k 格（"顺时针"指顶边向右、右边向下、底边向左、左边向上）。所有环各自移位后拼合，中心格保持原样。若某环全黑则保持不变。
- **key**：最隐蔽的是移位步长——单看一例无法区分"固定移 2 格"和"按色数移位"，必须对比同一示例中不同环（色数不同则步长不同）或多个示例才能归纳。推理链为"解构→逐环计数→逐环参数化移位"，属于分解后逐部件独立参数化的骨架：删掉分解则不知道操作边界，删掉计数则步长无解。

## 新题 4：最大边框作画布，四方位印章汇聚

**组合逻辑**：[完整边框检测+最大面积选取]（已有原语，改造：最大框内部不再是答案内容，而是空白目标画布） → [象限映射](创新：从"标记压缩成 2x2 摘要"改为"供体框相对画布的方位决定印章落点") → [裁剪+印章覆盖]（已有原语）

**来源原语**：矩形框、完整边框检测、最大面积选取、边框包围内容（1a6449f1）；象限映射（19bb5feb）；印章覆盖（c803e39c、db118e2a）；裁剪（多题）；内部图案（db118e2a）

**依赖链**：最大完整边框的选取同时决定两件事——输出窗口（其内部）和坐标参照系（其中心）。每个小框的内部图案要盖印到画布内部的哪个角，由该小框中心相对画布中心的方位决定。选取、方位判定、盖印三者汇聚到同一张画布上，是多源汇聚而非线性传递。

- **摘要**：网格里散布若干完整矩形边框和噪声点。内部面积最大的框是空画布；其余每个框把自己的内部图案按"自己在画布哪个斜方位"盖印到画布内部对应的角上。输出画布内部。
- **输入**：黑(0)背景网格（14x14 至 18x18），含 3~5 个单色矩形边框（边框 1 像素厚且完整闭合，颜色互不相同），另有 4~8 个孤立单像素噪声点（不与任何框相邻）。恰有一个框的内部面积严格最大，其内部全黑，内部高宽均为偶数且 ≥4；其余每个框内部含一个 4-连通的彩色小图案（2~5 像素，可多色）。生成约束：每个小框的中心行、中心列都不与大框中心行列重合（方位无歧义）；每个斜方位（左上/右上/左下/右下）至多一个小框；每个小图案的边界框尺寸不超过画布内部对应象限。
- **输出**：输出为最大框的内部区域（不含边框），初始全黑。对每个其余的框：取其内部图案的边界框裁剪；按该框中心相对最大框中心的方位（上且左=左上，上且右=右上，下且左=左下，下且右=右下），把裁剪块贴入输出的对应角落并与该角完全贴齐（如左上方位则裁剪块的左上角对齐输出的 (0,0)；右下方位则其右下角对齐输出的右下角）。噪声点与所有边框本身不进入输出。
- **key**：解题需三次独立判定并汇聚：先用"边框完整性+面积最大"选出画布（噪声点排除不完整框的误检），再对每个供体框做相对方位判定，最后裁剪贴齐。隐蔽规则是贴齐方式——图案不是贴到原比例对应位置，而是压到对应角上，必须对比多例归纳。删掉最大框选取则既无输出窗口也无方位参照，删掉方位映射则落点无解。

## 新题 5：标记指认完好半区，镜像修补残缺半区

**组合逻辑**：[标记对齐指定半区]（已有原语，改造：标记指认的是**供体**而非输出——输出的是不含标记的那一半） → [镜像位置](创新：镜像从"精灵搬家"变为跨半区的取色对应关系) → [修补]（已有原语，改造：修补来源是另一半区而非邻域）

**来源原语**：标记像素、标记对齐指定半区、保留标记半区（fbf15a0b）；镜像位置（8ee62060）；修补（8886d717）；分隔线（8e5a5113、c3202e5a）；裁剪、擦除（多题）

**依赖链**：两个标记像素落在哪一半，决定哪一半是完好参照、哪一半是待修补的答案（与参考题相反，输出的是**无标记**的一半）。残缺半区的每个坏点必须到另一半的**镜像位置**取色——半区选择（条件）决定了修补的方向和源，镜像关系决定了逐格对应,修补操作消费这两者的结果。

- **摘要**：灰线把网格分成两半，两半图案关于灰线镜像对称，但一半缺了若干像素（被抹黑）。带两个标记点的一半是完好参照。输出残缺的那一半，用参照半区的镜像内容补全缺口。
- **输入**：网格被一条满行或满列的灰(5)分隔线分成等大的两半（每半约 5x9 至 8x12）。存在一幅彩色图案（2~4 种颜色、覆盖每半 30%~60% 面积、无特定形状），完好半区含其完整版本，残缺半区含其关于分隔线的镜像版本但有 3~8 个图案像素被抹成黑(0)。完好半区内另有恰好 2 个标记像素，颜色在全图其他地方不出现；标记落在背景黑格上，且其镜像位置在残缺半区也是背景黑格（生成约束）。
- **输出**：尺寸等于一个半区。取**不含**标记像素的那一半作为基底；对其中每个黑(0)格，查看它关于分隔线的镜像格在另一半的颜色：若该镜像格非黑且非标记色，则填入该颜色；否则保持黑。非黑格保持原样。分隔线与标记不出现在输出中。
- **key**：两个隐蔽规则都需跨示例对比：(1) 输出的是不含标记的一半——标记是"完好认证章"而非"选中章"，与直觉相反；(2) 取色按镜像对应而非平移对应，图案不对称时二者结果不同。被"舍弃"的半区实为修补数据源，两半缺一不可；删掉半区判定则不知道谁修谁，删掉镜像关系则坏点取色错位。

## 新题 6：同色成对建墙，落单播种填色

**组合逻辑**：[同色配对判定](创新自"同色系配对"：配对标准改为"该颜色恰出现两次"，并且配对的用途从相互吸引改为连线建墙) → [连线]（已有原语，改造：线是区域分割器而非答案编码） → [洪泛填充](已有原语，改造：种子色由区域内落单像素提供，而非固定色)

**来源原语**：像素对、同色系配对（494ef9d7）；连线（6e02f1e3）；洪泛填充、封闭区域、区域排列顺序（7447852a）；标记像素（8886d717）

**依赖链**：先按"颜色出现次数"给像素分角色：出现两次的颜色是墙对，出现一次的颜色是种子。墙对连线后与网格边界共同把平面切成若干区域——区域这个对象是连线操作创造出来的；随后每个含种子的区域被洪泛成种子色。分类结果决定建墙集合，建墙结果决定种子的归属区域，填充消费前两步的全部输出。

- **摘要**：把每种恰好出现两次且两像素同行或同列的颜色连成直线段；这些线段把黑色平面分割成若干区域；每个区域若含一个落单颜色的像素，就整体洪泛成那个颜色，无种子的区域保持黑色。
- **输入**：黑(0)背景网格（10x10 至 14x14）。含 2~4 个"墙对"：每对是两个同色像素，同行或同列，颜色各对互不相同；另含 1~3 个"种子"像素，每个种子的颜色在全图恰出现一次，且与所有墙对颜色不同。生成约束：各墙对的连线段互不相交、不重叠、不经过种子像素；连线完成后，任何 4-连通黑色区域内至多含一个种子；至少存在一个无种子区域。
- **输出**：与输入同尺寸。第一步：对每个墙对，把两像素之间的直线段（含两端点）全部涂成该对颜色。第二步：把非墙格按 4-连通划分成区域（墙线段视为边界）；含种子的区域整体涂成该种子的颜色（种子本身颜色不变），不含种子的区域全部保持黑(0)。
- **key**：最隐蔽的是角色分类规则——像素是墙还是种子不由颜色本身决定，而由**出现次数**（2 次成对且共线=墙，1 次=种子）决定，必须对比示例中不同颜色的不同命运才能归纳。三步环环相扣且有涌现效应：单独连线得不到填色区域，单独填色没有边界可依，分类错误则全盘皆错；这是"角色分类→构造分割→按归属播种"的骨架，无法两两拆开。

## 新题 7：扫描序旋转的克罗内克印章

**组合逻辑**：[二值掩码+克罗内克积]（已有原语，改造：被盖印的瓦片不再恒定） → [顺序排列](创新：前景格在行优先扫描中的序号成为参数源) → [逐位累计旋转](创新自"逐槽位累计旋转"：槽位从分隔线切出的区域变为掩码前景格，旋转计数只在前景格上推进)

**来源原语**：二值掩码、克罗内克积、色块面板/分隔线（c803e39c）；旋转、逐槽位累计旋转、顺序排列（8e5a5113）；印章覆盖（c803e39c、db118e2a）

**依赖链**：外层掩码同时扮演两个角色：几何上它决定哪些块位放瓦片（克罗内克布局），序数上它决定每个块位放的是瓦片的第几次旋转（该前景格在行优先扫描中排第 k 个就转 (k−1)×90°）。旋转参数依赖掩码内容的全局扫描计数，不是块位坐标的局部函数——两条逻辑在每个块位上交织，无法先后分离。

- **摘要**：左面板是外层布局掩码，右面板是一个无旋转对称的图案瓦片。输出按克罗内克方式展开：掩码的第 k 个前景格（行优先计数）处放瓦片顺时针旋转 (k−1)×90° 的版本，背景格处放全黑块。
- **输入**：一列满高的灰(5)分隔线把输入分成左右两个面板。左面板是 n×n 二值掩码（n 为 3 或 4）：格子为黑(0)或某一单色 A，前景格数 ≥3。右面板是 m×m 瓦片（m 为 3 或 4）：黑底上的单色 B 图案（B≠A，B≠灰），图案无 90°/180° 旋转对称（生成约束：瓦片的四个旋转版本两两不同）。
- **输出**：(n·m)×(n·m) 网格。将左掩码按行优先顺序扫描，前景格依次编号 k=1,2,3,…。掩码格 (i,j) 对应输出中以 (i·m, j·m) 为左上角的 m×m 块：若该格是背景则整块为黑(0)；若该格是第 k 个前景格，则该块放右瓦片顺时针旋转 (k−1)×90° 后的图案（颜色保持 B 与黑不变）。
- **key**：隐蔽规则是旋转计数器只在**前景格**上推进——若误以为按块位坐标或按全部格子计数,多数块会对不上，必须逐块比对示例才能发现。骨架是"展开结构 × 序数参数化"的交织：克罗内克布局告诉你在哪放，扫描序号告诉你放哪个旋转态,二者来自同一个掩码的两种读法，删掉任何一种读法输出都不可复原。

## 新题 8：边缘线段编码相位、周期与画线方向

**组合逻辑**：[边缘线](创新：从"指示方向的参照物"变为同时编码三个参数——周期、相位、轴向的密码条) → [计数/同余选择](创新自"同余类交错铺满"：同余不再用于铺满而用于筛选幸存像素) → [连线+擦除]（已有原语）

**来源原语**：边缘线、边缘指示方向（8886d717）；同余类、等距偏移（05269061）；计数（6e02f1e3）；连线（6e02f1e3）；擦除（494ef9d7、fbf15a0b）

**依赖链**：贴边灰线段是一个三参数编码器：所在边决定筛选与画线的轴向（左/右边→按行，上/下边→按列），起点位置决定同余相位，长度决定模数。散点中只有坐标与线段起点同余（模长度）的存活，存活者沿对应轴扩展成整行/整列直线。测量、筛选、绘制层层依赖：不数长度就不知道模数，不筛选就不知道该画哪些线。

- **摘要**：网格一条边上贴着一段灰色线段，内部散布彩色像素。只有行号（或列号，取决于线段贴哪条边）与线段起点同余（模 = 线段长度）的像素存活，并各自扩展成贯穿网格的整行（或整列）直线；其余像素与灰线段全部擦除。
- **输入**：黑(0)背景网格（9x9 至 13x13）。恰有一段长度 L（2~4）的灰(5)连续线段完整贴在某一条边界上（在左或右边界时为竖直段，占据行 t 至 t+L−1；在上或下边界时为水平段，占据列 t 至 t+L−1）。内部（不含边界灰段所在格）散布 4~8 个彩色单像素（颜色 1~9 除灰外，可重复），任意两个像素不同行且不同列（生成约束，避免画线冲突）。至少 2 个像素满足下述存活条件，至少 2 个不满足。
- **输出**：与输入同尺寸,先全部置黑。设灰段起点坐标为 t（竖直段取最上端行号，水平段取最左端列号）。若灰段在左/右边界：行号 r 满足 r ≡ t (mod L) 的彩色像素存活，每个存活像素把它所在的**整行**涂成自己的颜色；若灰段在上/下边界：列号 c 满足 c ≡ t (mod L) 的像素存活，各自把所在**整列**涂成自己的颜色。不存活的像素不保留。灰段不保留。
- **key**：一个对象编码三个参数是本题的涌现点——贴哪条边、从哪开始、有多长，分别控制轴向、相位、模数；任何一例中三者纠缠在一起，必须跨示例对比（不同边、不同长度、不同起点）才能把三个自由度解耦。骨架是"单对象多参数解码→同余筛选→轴向绘制"，与其余各题的分解、汇聚、约束满足骨架均不同；删掉长度测量则筛选条件缺失，删掉轴向判定则画线方向不定。
