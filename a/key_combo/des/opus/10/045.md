## 新题 1：螺旋路径分区计数

**组合逻辑**：[螺旋绘制](已有) → [分区数决定尺寸](创新：源题中分隔线是直线，此处分隔结构是螺旋路径) → [计数+生成网格](已有)

**来源原语**：螺旋绘制(spiral_draw) ← e5c44e8f；遇障碍停止(stop_at_blocker) ← e5c44e8f；分区数决定尺寸(partition_count_determines_size) ← 7039b2d7；计数(count) ← 7039b2d7；生成网格(generate_grid) ← 7039b2d7

**依赖链**：螺旋绘制在网格上画出一条曲折路径，该路径本身充当不规则分隔结构，将背景分割为若干 4-连通区域；障碍像素终止螺旋生长，改变路径长度从而改变分区数量；分区计数的结果决定输出网格的行列尺寸。三者环环相扣——螺旋形态决定分区拓扑，分区拓扑决定输出形状。

从种子像素出发沿螺旋路径绘制前景色，遇障碍停止；统计螺旋路径将背景分割成的 4-连通区域数量，输出以背景色填满的该尺寸正方形网格。

**输入结构**：黑(0)背景网格，约 12x12 至 16x16。网格中有一个蓝(1)种子像素和 1~3 个红(2)障碍像素。种子像素不在网格边角（距每条边至少 2 格）。障碍像素分布在种子的不同象限，彼此不相邻（8-连通下各自孤立）。生成约束：障碍分布使得螺旋路径至少延伸 3 个完整边（即步长序列至少到 2,2,4 的第三段）后才被终止或到达网格边界；螺旋路径结束后，背景被分割为至少 2 个且不超过 6 个 4-连通区域。

**规则**：
1. 从种子像素位置开始，沿方向序列"上→右→下→左"循环，步长依次为 2,2,4,4,6,6,...（每个方向用两次后步长加 2），逐格绘制蓝(1)像素。
2. 每一步检查目标格：若目标格超出网格边界，跳过该步但步数仍计入当前边的步长消耗；若目标格已有红(2)障碍像素，立即停止整个螺旋（不覆盖该障碍）；若目标格是黑(0)背景，将其涂为蓝(1)。
3. 螺旋结束后（因遇障碍停止或当前边步长全部走完且下一边第一步即遇障碍/全部出界），对剩余黑(0)背景像素做 4-连通区域标记，统计区域总数 N。
4. 输出一个 N x N 的纯黑(0)网格。

**关键洞察**：螺旋路径不是预设的直线分隔符，它的弯折结构和障碍截断位置共同决定了背景被分割的方式；同一组障碍放在不同位置会产生完全不同的分区数，求解者必须完整模拟螺旋后才能计数。

## 新题 2：滑动累积涌现封闭区域填充

**组合逻辑**：[滑动+累积影响后续停靠](已有) → [封闭区域检测](创新：封闭区域不是输入中预设的，而是滑动累积后涌现的) → [填充+颜色对应](创新：填色依据不是固定编码，而是围成封闭区域的累积物颜色)

**来源原语**：滑动(sliding) ← 4093f84a；累积影响后续停靠(mass_affects_stops) ← 4093f84a；最短基方向吸附(nearest_cardinal_attract) ← 4093f84a；封闭区域(enclosed_region) ← aba27056；填充(filling) ← d37a1ef5；颜色对应形状(color_to_shape) ← 98c475bf

**依赖链**：散落的彩色小图形向灰色吸附体滑动、依次停靠（先到的改变后到的停靠位置）；累积后的团块与网格边缘可能围成封闭的背景区域（涌现结构）；每个封闭区域的填充颜色取决于其边界上像素数最多的非灰色颜色。滑动顺序改变停靠几何→几何改变封闭区域存在性→封闭区域边界颜色决定填色。

散落的彩色小图形依次向灰色吸附体滑动并停靠，累积后的结构与网格边缘围成封闭背景区域，用边界上占比最高的非灰色颜色填充每个封闭区域。

**输入结构**：黑(0)背景网格，约 14x14 至 18x18。网格中央偏位置有一个灰(5)矩形条（宽 1~2 格、长 4~7 格，水平或垂直放置）。灰条周围散布 3~5 个单色小图形（每个图形 2~4 像素，4-连通，颜色各异，从蓝(1)、红(2)、绿(3)、黄(4)中选取）。每个小图形与灰条在同一行或同一列上有交叠投影（即存在一个基方向使其可以直线滑向灰条）。生成约束：按照离灰条由近到远的顺序依次滑动后，累积团块与至少一条网格边缘共同围成至少一个封闭的黑(0) 4-连通区域；各小图形的滑动路径在初始时互不阻挡（不存在两个图形在同一直线上夹灰条的情况）。

**规则**：
1. 将所有非灰非背景的小图形按其与灰条的曼哈顿距离从小到大排序（距离按图形最近像素到灰条最近像素计算）；距离相同时，按图形边界框左上角先行后列排序。
2. 按上述顺序依次处理每个图形：找到图形到当前累积团块（初始为灰条）的最短基方向（上/下/左/右），沿该方向平移图形直到其某像素与累积团块 4-连通相邻，将该图形像素写入网格（保留原色，不涂灰），并将其加入累积团块。
3. 全部图形停靠完成后，在网格上对所有黑(0)背景像素做 4-连通区域标记。对每个背景区域判断是否"封闭"：若该区域不与网格的任何边缘行/列相邻，则为封闭区域。
4. 对每个封闭区域，检查其 4-连通边界上（与该区域相邻的非背景像素）各颜色的像素数量，忽略灰(5)，选像素数最多的颜色作为填充色；若有并列，选在输入中该颜色图形离灰条更近的那个颜色。用该颜色填充整个封闭区域。
5. 非封闭的背景区域保持黑(0)不变。灰条和已停靠图形的像素保持不变。

**关键洞察**：封闭区域不存在于输入中，它是滑动累积过程的涌现产物；改变任一图形的滑动顺序或停靠位置，封闭区域可能出现、消失或改变形状，进而改变填充颜色。

## 新题 3：对称补全涌现杯形与射线发射

**组合逻辑**：[对称补全](已有) → [开口检测](创新：开口不是输入中预设的，而是对称补全后因原始碎片不完整而涌现的) → [填充+射线延伸](已有操作，但作用对象是涌现结构)

**来源原语**：对称补全(symmetry_completion) ← 4938f0c2；标记定义双轴镜像(marker_biaxial_mirror) ← 4938f0c2；标记方块(marker_square) ← 4938f0c2；填充(filling) ← d4f3cd78；射线延伸(ray_extend) ← d4f3cd78；开口朝向(opening_direction) ← d4f3cd78；从开口发射(emit_from_opening) ← d4f3cd78

**依赖链**：输入中仅有一个象限的半成品轮廓碎片加一个 2x2 标记方块；对称补全后，碎片扩展为近似矩形环但在某一侧因原始碎片本身缺口而形成开口——这个开口的位置和大小完全由碎片形态决定；接下来填充环内部并从开口向外延伸射线。对称补全的结果同时决定了填充区域和射线方向。

将标记方块周围的局部轮廓碎片做双轴镜像补全，补全后的环形轮廓因碎片原始缺口产生开口；填充环内部并从开口向外发射射线至网格边缘。

**输入结构**：黑(0)背景网格，约 15x15。网格中部有一个绿(3) 2x2 标记方块。在标记方块的一个象限（如左上）分布着红(2)像素构成的 L 形或阶梯形轮廓碎片（5~8 像素，4-连通，模拟矩形环的一角但在某一边有 1~2 格宽的缺口）。其余三个象限无红色像素。生成约束：碎片经双轴镜像后形成的红色环在恰好一个朝向上有连续缺口（即开口宽度 1~2 格），环内部为连通的黑色区域；开口不在对角线方向而在上/下/左/右某一侧；碎片中的缺口不位于镜像轴上（否则补全后缺口消失）。

**规则**：
1. 以绿(3) 2x2 标记方块的中心为对称中心，对每个红(2)像素分别做水平镜像、垂直镜像、180度旋转，在对应位置绘制红(2)像素（不覆盖绿色标记方块自身）。
2. 补全后的红色像素形成一个不完全封闭的环形轮廓。找到该环的边界框，检查边界框四条边上的红色像素分布：某一条边上存在连续的背景格间隙即为开口，记录开口朝向（上/下/左/右）和开口格位置。
3. 对环内部的黑(0)区域（边界框内、被红色像素 4-连通包围的背景区域，不含开口外侧）填充为黄(4)。
4. 从开口处的每个黄(4)格（开口行或列上与环内部相邻的格子）出发，沿开口朝向逐格绘制黄(4)，直到到达网格边缘。若路径上遇到非背景像素则停止该条射线（不覆盖该像素）。
5. 绿色标记方块保持不变。

**关键洞察**：开口并非输入直接给出，而是对称补全的涌现结果——碎片中偏离对称位置的缺口经四份复制后在环上形成一个朝向确定的开口；求解者必须先完成补全才能判断射线方向。

## 新题 4：连线绕行与孤立像素清除

**组合逻辑**：[连线/首尾跨度填充](已有) + [绕行/遇障碍绕最近侧](创新：源题中绕行作用于垂直下落的列，此处作用于水平/垂直跨度连线) → [擦除/单像素分量移除](已有操作，但触发条件是绕行产生的拐角残留)

**来源原语**：连线(connect) ← ded97339；首尾跨度填充(span_fill_between) ← ded97339；同行列对齐(row_col_aligned) ← ded97339；绕行(detour) ← c87289bb；遇障碍绕最近侧(detour_nearest_side) ← c87289bb；擦除(erase) ← 42a50994；单像素分量移除(single_pixel_removed) ← 42a50994；八连通判定(eight_connectivity) ← 42a50994

**依赖链**：标记像素需要按行/列连线，但障碍线段阻挡直线路径，连线必须绕行；绕行的拐弯处可能产生孤立的单像素突出（因水平段转垂直段时的交汇几何）；最终清除所有 8-连通下的单像素分量。连线几何依赖障碍位置，擦除目标依赖连线几何，三步不可跳过。

将同行/同列的标记像素用跨度连线相连，连线遇障碍线段时绕行至障碍最近端外侧继续；完成后清除所有 8-连通下的孤立单像素。

**输入结构**：黑(0)背景网格，约 15x15 至 18x18。网格中有 4~6 个蓝(1)标记像素（各自孤立，不相邻），其中至少两对标记像素共享同一行、至少两对共享同一列。另有 1~2 段红(2)水平障碍线段（每段长 3~5 格、高 1 格），放置在某些标记像素对的连线路径上。生成约束：每段障碍线段恰好阻挡一条标记对的直线连线路径（即障碍与该标记对在同一行或同一列，且位于两标记之间）；障碍的两端至少有一端距离网格边缘或其他障碍 2 格以上（保证绕行有空间）；不存在一条绕行路径恰好覆盖另一个标记像素的位置。

**规则**：
1. 对每一行，找出该行所有蓝(1)标记像素，若有 2 个以上，需从最左到最右连线。对每一列同理，从最上到最下连线。连线颜色为蓝(1)。
2. 连线时逐格沿水平（或垂直）方向前进。若下一格是红(2)障碍像素，执行绕行：在当前位置向垂直方向（水平连线时向上或向下）检查障碍线段的两端，选择距当前格更近的那一端作为绕行方向（距离相同时选上方或左方）；沿垂直方向绘制蓝(1)绕过障碍线段，在障碍端外一格处转回原水平方向继续前进直到到达下一个标记像素。垂直连线遇障碍时同理，改为水平方向绕行。
3. 所有连线和绕行完成后，在整个网格上对蓝(1)像素做 8-连通分量标记。删除所有大小为 1 的分量（将其改回黑(0)背景）。大小大于 1 的分量全部保留。
4. 红(2)障碍像素在输出中保持不变。

**关键洞察**：绕行路径的拐角处可能留下仅通过对角线相连的突出像素，这些像素在 8-连通下属于大分量而被保留，但那些因绕行路径未能汇入主连线的真正孤立残留会被清除；判断哪些是残留需要完整追踪绕行几何。

## 新题 5：镜像拼接涌现分隔线与分区角色重涂

**组合逻辑**：[镜像+拼接](已有) → [分隔线检测](创新：分隔线不是输入中预设的，而是镜像接缝处对称像素对齐后涌现的完整行/列) → [角色分配+重涂色](创新：角色不按频率而按分区面积排名分配)

**来源原语**：镜像(mirror) ← 6d0aefbc；拼接(concatenate) ← 6d0aefbc；拼接镜像副本(append_mirror_copy) ← 6d0aefbc；分隔线(separator_line) ← 7039b2d7；分区数决定尺寸(partition_count_determines_size) ← 7039b2d7；角色分配(role_assignment) ← 3979b1a8；重涂色(recolor) ← e048c9ed

**依赖链**：输入网格水平镜像拼接后，接缝处可能出现完整的前景色列（涌现分隔线）；以这些涌现分隔线加上输入中已有的前景行/列为分隔线体系，将拼接后的网格分成若干矩形区域；按区域面积从大到小排名，分别涂上不同颜色。镜像决定哪些列变成分隔线→分隔线决定分区→分区面积决定涂色。

## 新题 6：带错切的容器平移与碰撞截停

**组合逻辑**：[平移+逐步充能](已有) + [错切/逐行偏移](创新：源题中错切是静态形变，此处错切在每步平移中累积，动态改变碰撞判定) + [碰撞阻挡](创新：碰撞对象是错切后的变形轮廓而非原始矩形)

**依赖链**：容器向目标平移，每步同时做一格错切（各行逐行偏移），灰色内部格逐步充能为橙色（能量上限）；错切使容器轮廓逐步变宽，可能提前碰到固定障碍而停止，即使能量尚未耗尽。停止条件是能量耗尽与错切碰撞中先触发的那个——两个约束同时作用，无法单独判断。

带边框容器向目标平移，每步充能一格灰变橙，同时各行逐步错切；当错切后的轮廓碰到固定障碍或能量耗尽时停止。

**输入结构**：品红(6)背景网格，约 16x20。网格中有一个黑(0)边框的矩形容器（外框 1 格厚黑色，内部 3~5 行 x 2~3 列，内部格为灰(5)或橙(7)，灰格在靠近移动反方向一侧连续排列）。容器一侧外部紧邻一个栗(9)方向标记像素，该像素与容器之间的方向指示平移方向（向左/右/上/下）。在平移方向的远端有一个同色栗(9)目标标记像素。平移路径的侧方（垂直于平移方向）有 1~2 个红(2)固定障碍像素。生成约束：容器内灰(5)格数量（能量）足够让容器到达目标之前至少走 3 步；固定障碍的位置使得容器在错切 2~4 步后其变形轮廓恰好碰到障碍；障碍触发的停止步数严格小于能量耗尽的步数（即障碍碰撞是实际截停原因）。

**规则**：
1. 确定平移方向：从栗(9)方向标记指向容器外侧的基方向即为平移方向的反方向（容器朝目标方向移动）。
2. 逐步执行：每一步中——
   a. 将容器整体沿平移方向移动 1 格。
   b. 对容器的每一行（沿平移方向编号，第 0 行为平移前方、第 k 行为第 k 行），将该行沿垂直于平移方向的轴偏移 k 格（方向固定为：水平平移时向下偏移，垂直平移时向右偏移）。这是累积错切——第 n 步时第 k 行的总偏移量为 k*n 格（注意：不是 k，而是 k 乘以已走步数）。不对，让我重新设计——每步对第 k 行额外偏移 1 格，即第 n 步后第 k 行的总偏移为 k 格（错切量等于行号，与步数无关；但容器移动了 n 步所以形状固定但位置变了）。
   
   修正：错切是在每步平移时累积的。具体地，在第 n 步（n 从 1 开始），容器内从平移前方数第 k 行（k 从 0 开始）沿垂直轴偏移 k 格（方向固定：水平平移时向下，垂直平移时向右）。错切量仅取决于行号 k，不随步数累加——即容器始终保持同一错切形态，但整体位置随步数前移。
   
   c. 将容器内最靠近平移反方向的一个灰(5)格改为橙(7)（充能），灰格按距平移前方由远到近的顺序消耗。
   d. 碰撞检测：若错切后的容器任一黑(0)边框像素或内部像素与红(2)固定障碍像素重叠，则撤销本步移动，容器停在上一步位置。
   e. 能量检测：若本步充能后无剩余灰(5)格，容器在当前位置停止。
3. 碰撞检测先于能量检测执行：若本步同时碰撞且耗尽能量，视为碰撞（撤销本步）。
4. 输出完整网格：容器在最终位置（含错切形态和充能状态），障碍和标记保持不变，容器原位置恢复为品红(6)背景。

**关键洞察**：错切使容器在垂直于平移方向上占据更多空间，虽然容器形态本身不随步数变化，但其在网格上的绝对占位因平移而改变，从而在某一步恰好与侧方障碍重合；求解者必须同时追踪位移和错切几何才能判断在哪一步被截停。

## 新题 7：遮挡层序确定平铺优先级

**组合逻辑**：[堆叠+遮挡层序+排序](已有) → [平铺+跨度对齐](创新：源题中平铺方向由控制条决定，此处平铺顺序由遮挡层序决定，先铺的占位后铺的绕开) → [沿控制条重复](已有)

**依赖链**：多个同模板精灵相互重叠，需先从可见碎片推断遮挡层序（谁在上谁在下）；每个精灵有一根匹配的控制条指示平铺方向；按遮挡层序从顶层到底层依次平铺——先铺的精灵副本占据空间，后铺的精灵副本若与已铺区域冲突则跳过该位置。遮挡分析→排序→依序平铺互斥占位，三者紧耦合。

从重叠的同模板精灵碎片中推断遮挡层序，然后按从顶层到底层的顺序，各精灵沿匹配控制条方向平铺完整副本，先铺的副本占位阻止后铺的副本放置在同一位置。

**输入结构**：黑(0)背景网格，约 16x20。网格中有 3~4 个不同颜色的精灵碎片，均为同一个 4x4 空心方框模板（12 像素边框、4 像素黑色内部）的有色副本，相互部分重叠（上层精灵遮挡下层精灵的部分边框像素）。每个精灵使用不同颜色，从蓝(1)、红(2)、绿(3)、黄(4)中选取。网格边缘区域有与精灵同色的 1 格厚控制条（水平或垂直线段），每个精灵恰好匹配一根控制条（通过颜色相同且行跨度或列跨度对齐判定）。生成约束：每对相邻层精灵之间至少有 2 个像素的遮挡关系（即下层精灵至少有 2 个模板位置被上层精灵颜色占据）；控制条的方向使得从精灵原位到控制条方向上至少可放 2 个完整副本的空间；不同精灵的控制条方向不全相同。

**规则**：
1. 识别所有非背景非控制条的彩色像素。对每种颜色 C，将其所有像素拟合到 4x4 空心方框模板的一个平移位置（选使可见像素全部落在模板边框位置上的平移偏移量），得到精灵 C 的锚点位置和完整模板像素集合。
2. 构建遮挡关系：对精灵 C 的模板中应有但实际被颜色 D 占据的像素，记录"D 在 C 之上"。对所有颜色对的遮挡关系做拓扑排序，得到从顶层到底层的序列。
3. 为每个精灵匹配控制条：找到与精灵颜色相同的控制条，且控制条的行跨度（水平条）等于精灵的行跨度或列跨度（垂直条）等于精灵的列跨度。控制条方向即平铺方向：水平条→向控制条方向水平平铺，垂直条→向控制条方向垂直平铺。
4. 清除所有控制条像素（变为背景）。
5. 按遮挡层序从顶层到底层依次处理每个精灵：从精灵原始锚点出发，沿平铺方向每隔 4 格（模板尺寸）放置一个完整的 4x4 空心方框副本，直到下一个副本的任一像素超出网格边界或到达控制条原位置。放置时，对每个副本逐像素检查：若该像素位置已被先前步骤放置的非背景像素占据，则跳过该像素（不覆盖）；否则涂上当前精灵颜色。
6. 精灵原始位置也按步骤 5 的规则处理（即重绘完整模板，但同样尊重先前精灵的占位）。

**关键洞察**：遮挡层序和平铺优先级是同一排序——顶层精灵不仅在原始重叠处遮挡下层，在平铺副本中也优先占位；这意味着底层精灵的平铺副本在某些位置会出现"缺口"，其几何形状取决于顶层精灵的平铺路径，必须先完成遮挡分析才能确定最终图案。

## 新题 8：重力下落后跨度连线与障碍保护

**组合逻辑**：[重力下落](已有概念，创新应用：不是列延伸而是像素下落) + [连线/首尾跨度填充](已有) + [标记框内保护](创新：保护区不是标记像素定义的固定矩形，而是障碍像素周围的动态曼哈顿邻域)

**来源原语**：重力下落(gravity_drop) ← c87289bb 概念衍生；连线(connect) ← ded97339；首尾跨度填充(span_fill_between) ← ded97339；同行列对齐(row_col_aligned) ← ded97339；固定障碍(fixed_barrier) ← 9c56f360；靠近障碍停止(stop_at_barrier) ← 9c56f360；标记框内保护(marker_bbox_protect) ← d37a1ef5；内部区域(interior_region) ← d37a1ef5

**依赖链**：散布在网格上方的标记像素先做重力下落（向下掉到最低可用位置或障碍之上）；下落后的新位置决定了哪些像素在同一行/同一列，进而决定跨度连线的几何结构；但连线不得穿过障碍像素周围的保护区（障碍像素上下左右各 1 格），穿过保护区的连线段被截断。下落改变对齐关系→对齐关系决定连线→障碍保护区截断连线。

标记像素受重力下落后重新排布，在新位置之间按同行/同列关系做跨度连线，但连线不得进入障碍像素周围的保护区域。

**输入结构**：黑(0)背景网格，约 14x14 至 16x16。网格上半区（前 3~5 行）散布 4~6 个蓝(1)标记像素（各自孤立）。网格下半区有 2~3 个红(2)固定障碍像素（各自孤立，不在最底行）。标记像素和障碍像素均不在同一列上有多个（保证下落路径唯一）。生成约束：每个标记像素正下方到网格底边或最近障碍之间无其他标记像素；下落后至少有两个标记像素落在同一行且至少有两个落在同一列；至少一条潜在连线路径会穿过某个障碍的保护区（从而被截断）。

**规则**：
1. 对每个蓝(1)标记像素执行重力下落：该像素从当前位置向下逐格移动，直到遇到网格底边、另一个已落定的蓝色像素、或红(2)障碍像素的正上方一格位置（即不进入障碍所在格也不进入障碍正上方格——停在障碍上方第 2 格）。不对——简化规则：标记像素向下移动直到下一格是网格边界外、红(2)障碍像素、或已有非背景像素，停在当前格。处理顺序：按初始行号从大到小（最低的先落）。
2. 所有标记像素落定后，构建保护区：每个红(2)障碍像素的上下左右各 1 格（4 格邻域，若越界则忽略）标记为保护区。保护区可视化为不可见——不改变网格颜色，仅影响连线规则。
3. 对落定后的蓝(1)像素按行和列做跨度连线：
   a. 对每一行，若有 2 个以上蓝像素，从最左到最右逐格填充蓝(1)；但若某格位于保护区内，跳过该格（保持背景色），连线在保护区入口截断并在保护区出口恢复。
   b. 对每一列，若有 2 个以上蓝像素，从最上到最下逐格填充蓝(1)；同样跳过保护区内的格子。
4. 红(2)障碍像素在输出中保持不变。连线不覆盖红色像素。
5. 行连线与列连线的交叉格正常填充蓝(1)（无冲突）。

**关键洞察**：同一组标记像素在不同障碍布局下会落到不同位置，产生完全不同的行列对齐关系和连线图案；障碍同时扮演两个角色——阻挡下落（改变像素落点）和保护区截断连线（改变连线几何），这两个效应耦合在同一组红色像素上。
