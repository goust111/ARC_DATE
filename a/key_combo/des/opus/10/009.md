## 新题 1：平行四边形面积排名着色

**组合逻辑**：[对角分解/diag_decompose](已有) → [连线/draw_line](已有，创新：绘制平行四边形四边而非两点直线) → [计数/counting](已有，创新：计算封围面积而非对象个数) → [排序/sort](已有) → [重涂色/recolor](已有，创新：颜色由面积排名决定)

**来源原语**：对角分解(cb227835), 连线(cb227835/29c11459), 计数(2753e76c/a87f7484), 排序(2753e76c), 重涂色(009d5c81/22a4bbc2), 控制序列(3e6067c3), 标记像素(cb227835)

**依赖链**：标记像素对的向量经对角分解生成平行四边形几何 → 几何形状决定封围面积 → 面积排名决定在控制行中的索引 → 索引映射到最终轮廓颜色。面积计算依赖于对角分解产生的具体几何形状，排名依赖面积，颜色依赖排名——删除任一环节均无法确定最终输出。

在黑(0)背景上，多对同色标记像素各自通过对角分解生成平行四边形轮廓；根据每个平行四边形的封围面积排名，从底部控制行读取对应颜色重涂轮廓。

**输入结构**：约 20x20 的黑(0)背景网格。网格中散布 3~5 对标记像素，每对同色（颜色互不相同，使用蓝(1)、绿(3)、黄(4)等），每对中两点的行列偏移既有行分量又有列分量且行列分量大小不等（保证对角分解唯一）。每对标记像素间无其他前景像素遮挡。网格最底行为控制行：从左到右排列 K 个不同颜色的单像素（K = 标记对数），颜色与标记对颜色均不同，使用如红(2)、橙(7)、品红(6)等。不同示例中标记对数量、位置、偏移方向均不同。生成约束：所有平行四边形的封围面积互不相等；不同平行四边形轮廓不重叠；控制行像素数恰好等于标记对数。

**规则**：
1. 识别所有标记像素对：同色且非黑(0)、非控制行颜色的前景像素恰好成对出现，每种颜色恰 2 个像素，作为一对。
2. 对每对标记像素，计算两点间的行列偏移向量 (dr, dc)。将该向量分解为一个 45 度对角分量和一个轴对齐分量（对角分量的行列绝对值相等且等于 min(|dr|, |dc|)，方向与原向量各分量同号；轴对齐分量为原向量减去对角分量）。
3. 以两个标记像素为对角顶点，以对角分量和轴对齐分量为相邻两边，确定平行四边形的四个顶点。沿四边画绿(3)轮廓线（含四个顶点），但保留标记像素原色不变。
4. 计算每个平行四边形内部的像素数（严格位于轮廓线内部的黑色像素数量）作为其封围面积。
5. 将所有平行四边形按封围面积降序排列，得到排名 1, 2, ..., K。
6. 读取控制行的 K 个颜色像素（从左到右对应排名 1, 2, ..., K）。将排名为 i 的平行四边形的全部轮廓像素（不含标记像素）重涂为控制行第 i 个颜色。
7. 擦除控制行（恢复为黑(0)）。擦除所有标记像素（恢复为黑(0)）。

**关键洞察**：轮廓的最终颜色既非标记颜色也非绘制颜色，而是由封围面积在所有平行四边形中的相对排名间接决定的——必须先构造所有几何形状、计算所有面积，才能确定任何一条轮廓的颜色。

## 新题 2：对侧精灵体滑动轨迹交叉染色

**组合逻辑**：[对侧配对/opposite_pairing](已有，创新：配对对象从孤立像素扩展为多像素精灵体) → [滑动/sliding](已有，创新：精灵体整体滑动而非单像素移动) → [碰撞停止/collision_stop](已有，创新：对向精灵体边界框相遇时停止) + [扫过轨迹/swept_trail](已有) → [重涂色/recolor](已有，创新：不同对的轨迹交叉处涂灰)

**来源原语**：对侧配对(29c11459), 滑动(29c11459), 碰撞停止(6e453dd6), 扫过轨迹(5e6bbc0b), 重涂色(009d5c81/22a4bbc2), 精灵体(a87f7484/e21a174a)

**依赖链**：对侧反射确定配对 → 每对的共享轴确定滑动方向 → 精灵体整体滑动留下各自颜色的轨迹 → 不同对的轨迹在空间上交叉时产生灰色覆盖。多对同时滑动的轨迹是否交叉取决于所有精灵体的初始位置和形状，属于全局涌现效应。

在黑(0)背景上，成对出现在对侧边缘的彩色精灵体沿共享轴相向滑动至边界框相遇，留下各自颜色的轨迹；不同对的轨迹重叠处统一涂灰(5)。

**输入结构**：约 18x18 的黑(0)背景网格。2~4 对彩色精灵体（每个精灵体为 4-连通的单色小图形，2~5 像素，形状不规则）分布在网格的对侧边缘。每对精灵体颜色相同且唯一（如一对蓝(1)、一对红(2)、一对黄(4)），分别紧贴网格的上下两侧或左右两侧。同一对的两个精灵体通过沿对称轴的反射可以确定配对关系（反射后两者的行或列重合）。不同对的精灵体可以出现在不同的边缘方向（如一对在上下、另一对在左右）。生成约束：每对精灵体滑动路径上无其他精灵体阻挡（只会被配对方阻挡）；至少有两对的轨迹在空间上存在重叠区域。

**规则**：
1. 识别所有精灵体（4-连通的非黑单色前景区域），按颜色分组。每种颜色恰好出现两个精灵体，形成一对。
2. 对每对精灵体，确定其共享的滑动轴：若两者分别紧贴上下边缘，则沿列方向（纵向）相向滑动；若分别紧贴左右边缘，则沿行方向（横向）相向滑动。
3. 每对精灵体沿共享轴同时向对方滑动，每步移动 1 像素。精灵体经过的每个像素位置留下该精灵体颜色的轨迹（即滑动扫过区域涂上精灵体颜色）。当两个精灵体的边界框在滑动轴方向上相邻（间距为 0）时停止。精灵体停留在最终位置。
4. 所有对独立完成滑动后，检查全局轨迹重叠：若某个像素被两个或以上不同对的轨迹覆盖（包括精灵体最终位置与另一对的轨迹重叠），则该像素重涂为灰(5)。仅被同一对的两个精灵体轨迹共同覆盖的像素保持该对颜色不变。

**关键洞察**：每对精灵体的滑动独立进行，但轨迹的交叉是全局涌现的——需要计算所有对的完整轨迹后才能确定灰色像素的位置；精灵体的形状和初始位置共同决定了哪些像素会出现跨对重叠。

## 新题 3：平移聚合后孔洞位置编码填色

**组合逻辑**：[平移/translate](已有) + [边缘对齐/flush_with_separator](已有) → [封闭区域检测](创新：封闭区域的产生依赖于平移后的空间关系) → [位置对应颜色/position_to_color](已有，创新：位置编码基于孔洞在父形状中的相对坐标而非固定图例)

**来源原语**：平移(6e453dd6), 边缘对齐(6e453dd6), 封闭区域(6e453dd6), 填充(a834deea), 位置对应颜色(a834deea), 固定图例(a834deea), 分隔列(6e453dd6)

**依赖链**：黑色形状平移至分隔列 → 平移后形状与分隔列接合产生封闭孔洞（仅在接合后才出现）→ 每个孔洞在其所属形状边界框中的相对行列位置决定查阅图例的哪个单元格 → 图例单元格的颜色成为该孔洞的填充色。孔洞的存在依赖平移，孔洞的颜色依赖其空间位置，二者缺一不可。

将左侧黑色形状右移至灰色分隔列，平移产生的封闭孔洞根据其在父形状内的相对位置查阅角落图例获取填充颜色。

**输入结构**：约 16x20 的网格，背景色为青(8)。一条纵向灰(5)分隔列位于网格中偏右位置（约第 13~15 列），将网格分为左右两部分。左侧有 2~4 个黑(0)的 4-连通形状（每个约 8~15 像素，形状不规则，内部包含 1~3 个单像素或双像素的背景色凹槽，但这些凹槽在形状未靠上分隔列时并不形成封闭区域）。右侧为纯背景色。网格左上角或右下角有一个 3x3 的边框区域（黑(0)边框，内部 1x1 至 3x3），其内部每个位置填有不同颜色作为位置图例——3x3 内部九个位置分别对应九种颜色中的某种（如左上=蓝(1)、中上=红(2)、右上=绿(3)等），颜色分配在不同示例中不同。生成约束：每个黑色形状至少有一个凹槽在平移靠上分隔列后变为封闭孔洞；所有孔洞在其父形状边界框中的归一化位置映射到图例的不同单元格；图例区域不在任何形状的平移路径上。

**规则**：
1. 识别灰(5)分隔列和左上角/右下角的边框图例区域（3x3 黑色边框包围的内部区域，内部各单元格颜色各异）。
2. 识别左侧所有黑(0)的 4-连通形状。
3. 将每个黑色形状整体水平右移，直到其最右列紧邻分隔列左侧（边缘对齐）。原位置恢复为背景色青(8)。
4. 平移后，检测每个黑色形状内部的封闭区域：被黑(0)像素和分隔列灰(5)像素共同包围的背景色青(8)连通区域即为孔洞。仅在形状触及分隔列的一侧才可能形成封闭。
5. 对每个孔洞，计算其质心（所有孔洞像素的行列平均值，向下取整）在其父形状（包含该孔洞的黑色形状）边界框中的相对位置：将边界框均匀三等分为 3x3 的九个区域，质心落入哪个区域就对应图例的哪个位置。
6. 从图例中读取对应位置的颜色，将该孔洞的所有像素填充为该颜色。
7. 保留分隔列、黑色形状和图例不变。

**关键洞察**：孔洞在平移前并不封闭——只有形状右移靠上分隔列后，凹槽才被封堵成为真正的封闭区域；而孔洞的填充色不是固定的，是由其在父形状中的空间位置通过图例间接解码的，因此必须先完成平移才能确定孔洞的存在和位置，再通过空间编码确定颜色。

## 新题 4：镜像重叠计数柱状图

**组合逻辑**：[镜像/mirror](已有，创新：多个对象各自独立镜像) + [邻接/adjacency → 标记侧](已有) → [计数/counting](已有，创新：计数对象不是连通体个数而是跨对象的重叠像素数) → [排序/sort](已有) → [柱状填充/histogram_fill](已有，创新：柱状图的行颜色由重叠源决定)

**来源原语**：镜像(2bcee788), 邻接(2bcee788), 标记像素(2bcee788), 计数(2753e76c), 排序(2753e76c), 柱状填充(2753e76c), 靠端对齐(2753e76c), 按数量降序(2753e76c)

**依赖链**：标记像素位置 → 各对象的镜像方向 → 镜像副本的空间位置 → 不同对象的镜像副本与其他原始对象之间的重叠像素数量 → 按重叠数排序 → 柱状图输出。每个对象的镜像方向独立确定，但重叠计数是全局交互的结果——改变任一对象的标记位置会影响所有相关的重叠统计。

每个前景对象按红色标记指示的方向镜像翻转后，统计各对象的镜像副本与其他原始对象重叠的像素数，按重叠数降序输出右对齐柱状图。

**输入结构**：约 18x18 的黑(0)背景网格。3~5 个单色前景对象（每个为 4-连通的不规则形状，4~8 像素，各自颜色唯一，使用蓝(1)、绿(3)、黄(4)、橙(7)、品红(6)等）散布在网格中，彼此不相邻。每个对象有恰好 1 个红(2)标记像素紧邻其某一侧（上、下、左或右），标记像素的位置指示该对象的镜像方向（标记在哪侧就向哪侧翻转）。不同示例中对象的形状、大小、位置和标记方向均不同。生成约束：所有对象镜像后，至少有 2 个对象的镜像副本与某个其他原始对象存在像素重叠；各对象的重叠计数互不相等。

**规则**：
1. 识别所有非黑(0)、非红(2)的 4-连通前景对象。识别每个红(2)标记像素及其唯一相邻的前景对象。
2. 对每个前景对象，以其边界框的被标记侧外边缘为轴进行镜像翻转：标记在右侧则以边界框右边缘外一列为轴水平翻转，标记在下侧则以边界框下边缘外一行为轴垂直翻转，以此类推。镜像副本使用与原对象相同的颜色。
3. 在同一网格上叠加所有原始对象和所有镜像副本。对每个对象 O，计算 O 的镜像副本覆盖的像素中，有多少个与**其他**原始对象（非 O 自身）的像素位置重合，该数即为 O 的重叠计数。
4. 将所有对象按重叠计数降序排列。
5. 生成柱状图输出：输出宽度 = 最大重叠计数，高度 = 对象数。每行对应一个对象（按排名从上到下），左侧填充黑(0)，右侧填充该对象颜色 × 重叠计数个像素（右对齐）。

**关键洞察**：柱状图中每行的宽度不是由对象自身的属性（面积、形状）决定的，而是由其镜像副本与其他对象的空间交互决定的——这是一个全局涌现量，只有在所有对象完成镜像后才能计算。

## 新题 5：网格缺失交叉点计数决定选取间隔

**组合逻辑**：[计数/counting](已有，创新：计数对象为网格缺失交叉点而非前景对象) → [每隔N选取/every_nth_selection](已有，创新：N 由缺失交叉点数量动态决定) → [裁剪/crop](已有) → [拼接/concatenation](已有)

**来源原语**：计数(2753e76c/a87f7484), 每隔N选取(22a4bbc2), 缺失交叉点(a644e277), 背景色空洞(a644e277), 网格线(a644e277), 裁剪(a87f7484/0bb8deee), 拼接(0bb8deee), 精灵体(a87f7484/0bb8deee), 按位置排序(22a4bbc2)

**依赖链**：识别网格线和交叉点 → 统计缺失交叉点数 K → K 作为选取间隔参数 → 对网格单元中的精灵体按阅读顺序排列后每隔 K 个选取一个 → 裁剪选中的精灵体 → 水平拼接为输出。K 的值由网格结构的异常（缺失交叉点）编码，这使得选取规则无法从单个示例中确定（不同示例 K 不同）。

统计网格中缺失的交叉点数量 K，然后按阅读顺序每隔 K 个单元格选取一个精灵体，裁剪并横向拼接为输出。

**输入结构**：约 15x15 的网格，背景色为黑(0)。一套灰(5)的单像素宽水平和垂直网格线将网格均匀划分为若干矩形单元（如 4x4 或 5x5 的单元排列）。网格线的每个交叉点（水平线与垂直线相交处）通常为灰(5)，但恰好有 K 个交叉点被替换为黑(0)背景色（K 在 2~4 之间，不同示例不同）。部分单元内包含彩色精灵体（4-连通单色小图形，2~4 像素，各自颜色可不同），其余单元为空。非空单元至少有 2K 个以上（保证选取后至少得到 2 个精灵体）。生成约束：按阅读顺序（从左上到右下逐行扫描单元）排列非空单元后，以 K 为间隔选取（第 1 个、第 K+1 个、第 2K+1 个...）恰好选出 2~5 个精灵体；缺失交叉点不在网格边缘（避免与边界混淆）。

**规则**：
1. 识别灰(5)网格线构成的规则栅格，确定单元边界。
2. 统计栅格交叉点中颜色为黑(0)（与背景相同）的数量，记为 K。
3. 按阅读顺序（上到下、左到右）遍历所有单元，收集包含非背景非灰色前景像素的非空单元，按遍历顺序编号为 1, 2, 3, ...
4. 从编号 1 开始，每隔 K 个选取一个非空单元：选取编号 1, 1+K, 1+2K, ... 的单元。
5. 对每个选中单元，将其中的精灵体裁剪至紧凑边界框（保留内部背景孔洞）。
6. 将所有裁剪结果按选取顺序从左到右水平拼接，相邻裁剪之间插入 1 列黑(0)分隔列，形成输出。

**关键洞察**：选取间隔 K 不是固定常数，而是由网格结构自身的异常（缺失交叉点数量）隐式编码的——求解者必须首先发现网格交叉点的异常并计数，然后用计数结果作为参数驱动后续的选取逻辑，这一"元参数"关系需对比多个示例才能归纳。

## 新题 6：自相似印章展开后控制序列着色

**组合逻辑**：[印章覆盖/stamp_overlay](已有) + [像素到块映射/pixel_to_block_mapping](已有) → [计数/counting](创新：前景像素数隐式决定了控制序列长度) → [重涂色/recolor](已有，创新：每个印章副本的颜色由控制序列的对应位置决定)

**来源原语**：印章覆盖(5b6cbef5), 像素到块映射(5b6cbef5), 前景位放自身副本(5b6cbef5), 控制序列(3e6067c3), 访问顺序编码(3e6067c3), 计数(2753e76c), 重涂色(009d5c81)

**依赖链**：种子精灵的前景像素数 = 印章副本数 = 控制序列长度（三者必须一致）→ 自相似展开确定每个副本的空间位置 → 按阅读顺序访问各副本 → 控制序列第 i 个颜色涂给第 i 个访问到的副本。种子精灵同时充当空间模板和数量参数，控制序列充当颜色赋值器，两者的长度耦合是隐式约束。

将单色种子精灵自相似展开为多个副本，然后按阅读顺序依次将每个副本重涂为控制行中对应位置的颜色。

**输入结构**：约 20x20 的黑(0)背景网格，分为上下两部分。上方为一个 NxN（N 在 3~5 之间）的单色种子精灵（前景色如蓝(1)，背景像素为黑(0)），精灵内有 M 个前景像素（M 在 3~7 之间）。下方紧贴网格底边有一行控制序列：恰好 M 个彩色像素从左到右排列（颜色各不相同，使用红(2)、绿(3)、黄(4)、灰(5)、橙(7)、品红(6)等），其余位置为黑(0)。不同示例中种子精灵的形状和大小不同（因此 M 不同），控制序列的长度和颜色也相应变化。生成约束：控制序列的像素数恰好等于种子精灵的前景像素数。

**规则**：
1. 识别上方的 NxN 种子精灵区域（以其紧凑边界框为准），记录其前景像素的二维分布。
2. 识别底行的控制序列：从左到右读取所有非黑(0)像素的颜色，记为 c1, c2, ..., cM。
3. 创建一个 (N*N) x (N*N) 的黑(0)输出网格（原种子精灵和控制行不出现在输出中）。将输出网格划分为 NxN 个大小为 NxN 的块，每个块对应种子精灵的一个像素位置。
4. 对种子精灵中的每个前景像素位置，将种子精灵的完整图案（保持前景/背景分布不变）复制到输出网格中对应的块中，前景像素暂时统一使用种子精灵的原色。背景像素位置对应的块保持全黑(0)。
5. 按阅读顺序（上到下、左到右）遍历所有含有副本的块，依次编号为 1, 2, ..., M。将第 i 个块中所有前景像素的颜色替换为 ci。

**关键洞察**：种子精灵同时扮演两个角色——它是自相似展开的空间模板（决定副本放在哪里），也是每个副本内部的形状模板（决定副本长什么样）；而控制序列的长度必须恰好等于前景像素数，这一隐式数值约束将空间结构和颜色赋值绑定在一起。

## 新题 7：压缩聚形后镜像补全并按奇偶填充

**组合逻辑**：[压缩/compact](已有，创新：压缩方向由边缘标记决定) → [对称/symmetry](创新：压缩后的聚合形状恰好构成某对称图形的一半) → [镜像/mirror](已有，创新：镜像轴由压缩方向决定) → [填充/fill + 内部行段填充/fill_interior_spans](已有) + [奇偶性选色/parity_selects_color](已有，创新：用边缘标记的棋盘奇偶性选择填充颜色)

**来源原语**：压缩(5e6bbc0b), 标记定压缩方向(5e6bbc0b), 边缘标记(5e6bbc0b), 奇偶性选色(5e6bbc0b), 镜像(bf32578f), 对称(bf32578f), 半侧轮廓(bf32578f), 填充(bf32578f), 内部行段填充(bf32578f)

**依赖链**：边缘标记位置 → 压缩方向 → 散布像素压缩后形成半侧轮廓（涌现结构）→ 压缩方向决定镜像轴 → 镜像补全为完整闭合轮廓 → 轮廓内部行段填充 → 填充颜色由边缘标记的棋盘奇偶性（行+列之和的奇偶）决定。压缩是产生半侧轮廓的必要手段，镜像轴的方向与压缩方向正交，填充颜色的判定需要回溯到原始标记的坐标属性。

将散布像素按边缘标记方向压缩聚合为半侧轮廓，沿正交轴镜像补全为完整闭合轮廓，内部填充色由标记像素的棋盘奇偶性决定。

**输入结构**：约 15x15 的黑(0)背景网格。若干蓝(1)的前景像素（约 8~15 个）散布在网格中（非连通，不构成可识别的图案）。恰好 1 个青(8)的标记像素位于网格的某一侧边缘（上边缘、下边缘、左边缘或右边缘的非角落位置）。不同示例中散布像素的数量、位置不同，标记像素的边缘位置也不同。生成约束：将所有蓝(1)像素沿标记所在边缘方向压缩（合并到该侧）后，结果恰好构成一个关于标记所在边缘的正交方向轴对称的半侧轮廓（即沿与边缘平行的中轴镜像后可形成一个单像素宽的闭合轮廓）；闭合轮廓内部的面积至少为 3 个像素。

**规则**：
1. 识别青(8)边缘标记像素，确定其所在边缘方向（上/下/左/右）。
2. 将所有蓝(1)前景像素沿标记所在边缘方向压缩：若标记在左边缘，则每行的蓝色像素向左压缩（保持行内相对顺序，移至该行最左侧的连续位置）；若标记在上边缘，则每列的蓝色像素向上压缩；以此类推。原位置恢复为黑(0)。
3. 压缩后的蓝色像素集合构成一个半侧轮廓。确定镜像轴：以压缩后蓝色像素集合在垂直于压缩方向上的中央线为对称轴（若压缩方向为水平则以垂直中央行为轴，若压缩方向为垂直则以水平中央列为轴）。
4. 将压缩后的蓝色像素关于该镜像轴做镜像，补全出另一半轮廓。镜像像素也涂蓝(1)。现在蓝色像素构成一个完整的单像素宽闭合轮廓。
5. 确定填充颜色：读取青(8)标记像素的坐标 (r, c)，若 r+c 为偶数则填充色为红(2)，若 r+c 为奇数则填充色为绿(3)。
6. 对完整闭合轮廓内部的每一行，找到该行最左和最右的蓝(1)像素，将两者之间（不含端点）的所有黑(0)像素填充为上一步确定的颜色。
7. 擦除标记像素（恢复为黑(0)）。

**关键洞察**：散布的像素在压缩前看似杂乱无章，但压缩操作是使其"涌现"为半侧轮廓的关键步骤；填充颜色不由轮廓形状或面积决定，而是回溯到触发整个流程的标记像素的坐标奇偶性——一个空间属性横跨整个推理链首尾。

## 新题 8：互补形状匹配填充后孔洞触发射线

**组合逻辑**：[形状匹配/shape_match](已有) + [互补形状/complementary_shape](已有) → [填充/fill](已有，创新：填充使原本不封闭的区域变为封闭) → [封闭区域检测](创新：封闭区域在填充后才涌现) → [射线延伸/ray_cast](已有，创新：射线的起点由涌现的封闭区域决定) + [碰撞停止/collision_stop](已有)

**来源原语**：形状匹配(18447a8d), 互补形状(18447a8d), 缺口形状唯一配对(18447a8d), 封闭区域(6e453dd6), 孔洞触发射线(6e453dd6), 射线延伸(6e453dd6), 碰撞停止(6e453dd6), 填充(a834deea), 源形状(18447a8d), 模板缺口(18447a8d)

**依赖链**：源形状与模板缺口互补匹配 → 源形状填入对应模板缺口 → 填入后模板内部出现新的封闭孔洞（填入前缺口连通外界，填入后缺口被堵住，内部剩余空间被封闭）→ 从每个封闭孔洞向四个基本方向发射该模板边框颜色的射线 → 射线遇到其他模板边框时停止。互补匹配决定了哪些孔洞会涌现，孔洞位置决定射线路径，射线碰撞依赖所有模板的全局空间布局。

将源形状匹配填入模板缺口，补全后产生的封闭孔洞向外发射射线，射线颜色为模板边框色，碰到其他模板边框时停止。

**输入结构**：约 20x20 的黑(0)背景网格。左半区域有 2~4 个矩形模板（每个为 5x5 至 7x7 的单色边框，如灰(5)边框、蓝(1)边框等，边框颜色各不相同），每个模板的内部区域（3x3 至 5x5）大部分为黑(0)背景，但有一个 L 形、T 形或不规则形状的缺口——该缺口使内部与外部连通（即从边框内部的某些黑色像素可以不穿过边框到达边框外部）。右半区域散布 2~4 个单色小形状（3~6 像素的 4-连通不规则图形），颜色与任何边框颜色不同（使用红(2)、绿(3)、黄(4)等）。每个源形状的外形恰好与某个模板缺口互补（旋转平移后可恰好堵住缺口）。不同示例中模板和源形状的形状均不同。生成约束：每个源形状恰好匹配一个模板缺口（唯一配对）；填入后每个模板内部至少产生 1 个封闭孔洞（面积 1~4 像素）；不同模板在行列方向上有重叠范围（使射线有可能碰到另一个模板）。

**规则**：
1. 识别所有矩形边框模板（单色闭合边框，内部含缺口）。识别右侧所有单色源形状。
2. 对每个源形状，在所有模板缺口中寻找其唯一的互补匹配：将源形状的外形（忽略颜色）与每个缺口的负空间比较（允许平移但不旋转），找到形状完全互补的唯一配对。
3. 将每个源形状移入其匹配模板的缺口位置，用源形状的颜色填充缺口像素。擦除源形状原来位置的像素（恢复为黑(0)）。
4. 填入后，检测每个模板内部的封闭区域：被模板边框像素和已填入的源形状像素共同围合的黑(0)连通区域即为封闭孔洞。
5. 对每个封闭孔洞，从孔洞的每个像素出发，向上、下、左、右四个方向各发射一条射线。射线颜色为该孔洞所属模板的边框颜色。射线穿过黑(0)背景像素（将其涂为射线颜色），遇到任何非黑(0)像素（包括其他模板的边框、已填入的源形状、或其他射线）时停止，不覆盖终点像素。
6. 若多条射线经过同一像素，后绘制的覆盖先绘制的（按模板从左上到右下的顺序处理各模板的射线）。

**关键洞察**：射线的起点在输入中并不存在——只有在源形状填入模板缺口堵住连通通道后，内部空间才变为封闭孔洞，孔洞才能触发射线；哪些孔洞会涌现完全取决于互补匹配的结果，因此形状匹配的正确性直接决定了射线网络的拓扑。
