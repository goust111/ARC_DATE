## 新题 1：射线穿越周期壁纸的缺损修复

**组合逻辑**：[射线延伸](从对角射线种子出发，穿越网格) + [周期推断](推断瓦片周期) + [补全](用射线路径上的已知像素恢复缺损) → 三者耦合：射线路径决定修复范围，周期相位决定修复值，但射线遇到的非缺损像素反过来验证周期参数

**来源原语**：射线延伸(ray_extend) ← 7e2bad24；周期推断(period_inference) ← c663677b；补全(complete) ← c663677b；对角射线种子(diagonal_ray_seed) ← 7e2bad24；缺损像素(corrupted_pixel) ← c663677b

**依赖链**：射线路径确定哪些缺损像素需要修复（不在路径上的缺损保持黑(0)不变）；周期推断从非缺损像素中提取瓦片周期；射线路径上的已知像素同时作为周期推断的约束输入——删除射线路径信息则不知修复哪些像素，删除周期推断则不知修复为什么颜色

一句话总结：沿对角射线路径，用推断出的瓦片周期恢复路径上的缺损像素，路径外的缺损保持不变。

**输入结构**：约 14x14 的网格。背景是一个由 3x3 或 4x4 的彩色瓦片（使用红(2)、绿(3)、黄(4)、青(8)等 3~4 种颜色）周期铺满的壁纸。部分像素被替换为黑(0)表示缺损，缺损像素散布于网格各处（约占总像素的 20%~30%）。网格中有一条由蓝(1)像素标记的 8-连通对角线段（长度 2~3 像素），作为射线种子，位于网格边缘附近。射线种子的像素覆盖了原壁纸颜色。生成约束：壁纸的每个周期相位至少在某个非缺损、非射线位置出现一次，保证周期可被唯一确定。

**规则**：
1. 从射线种子的端点出发，沿种子指示的对角方向（左上/右上/左下/右下之一），逐像素延伸直到离开网格边界，形成完整射线路径。射线路径上的像素（包括种子本身）标记为"待处理"。
2. 分析网格中所有非黑(0)、非蓝(1)的像素，推断最小行周期 P_r 和列周期 P_c，使得所有已知像素满足 grid[r][c] == tile[r mod P_r][c mod P_c]。
3. 对射线路径上的每个像素位置 (r, c)：若该位置当前为黑(0)（缺损），则用 tile[r mod P_r][c mod P_c] 的颜色填充；若该位置为蓝(1)（种子），也用瓦片颜色替换。
4. 路径外的缺损像素保持黑(0)不变。输出网格中射线路径被壁纸颜色覆盖（射线消失），路径外缺损仍为黑(0)。

**关键洞察**：射线不是装饰而是"修复刷"——它限定了补全的空间范围；求解者必须同时推断周期和理解射线的作用域限制，二者缺一不可。

## 新题 2：重力沉降后的跨尺度形状配对

**组合逻辑**：[滑动/重力沉降](像素沿列下落) + [形状匹配/跨尺度同形](识别尺度不同但形状相同的对) + [重涂色](匹配对用统一颜色标记) → 耦合：重力沉降改变像素位置后才能识别形状，匹配结果决定重涂色方案

**来源原语**：滑动(sliding) ← 3618c87e；重力沉降(gravity_settling) ← 3618c87e；形状匹配(shape_matching) ← ce602527；跨尺度同形(cross_scale_same_shape) ← ce602527；重涂色(recolor) ← 7e2bad24

**依赖链**：重力沉降将散落的像素聚合成可识别的连通形状（沉降前像素分散无法形成有意义的形状）；形状匹配在沉降后的结果上运行，找出尺度为 1:2 的同形对；匹配对用绿(3)重涂，未配对的形状用红(2)重涂——删除重力步骤则形状不成立，删除匹配步骤则不知如何分配颜色

一句话总结：先让所有彩色像素按列下落到底部，再找出沉降后形成的形状中尺度为 1:2 的同形配对，配对成功的涂绿，失败的涂红。

**输入结构**：约 12x10 的网格。背景为黑(0)。散布着多组彩色像素（使用蓝(1)、黄(4)、品红(6)、橙(7)等 4~5 种颜色），每组同色像素在水平方向上的列坐标已经构成某个 4-连通形状的轮廓，但垂直方向上被随机抬升了不同的行数（即同一形状的像素被"炸开"到不同高度）。不同颜色的像素列坐标范围互不重叠。生成约束：沉降后每种颜色形成恰好一个 4-连通图形（3~8 像素），且恰好存在若干对形状相同但尺度为 1:2 的配对（至少一对），也存在至少一个无法配对的形状。

**规则**：
1. 对每一列，将该列中所有非黑像素按原始相对顺序下移到该列最底部的连续空位中（标准重力沉降）。
2. 沉降完成后，按颜色分离出各连通分量，裁剪为最小边界框内的二值掩码。
3. 对所有形状对 (A, B)，检查 A 的掩码放大 2 倍后是否与 B 的掩码完全一致（或反过来）。若匹配，则 A 和 B 构成一对。每个形状最多属于一对；若多个候选配对冲突，选边界框面积之和最小的配对方案。
4. 配对成功的形状所有像素重涂为绿(3)；未配对的形状所有像素重涂为红(2)。背景保持黑(0)。

**关键洞察**：输入中的像素分布看似随机噪声，只有执行重力沉降后才能"显影"出有意义的形状，而配对判断必须在显影后进行——两步之间有不可跳过的因果关系。

## 新题 3：环形边框编码旋转角度

**组合逻辑**：[环形周期/平铺](边框段在矩形边界上的周期分布) + [解码](边框段的位置编码旋转角度) + [旋转](对内部模板施加解码得到的旋转) → 耦合：边框段的周期位置是密码，解码后得到旋转参数，旋转作用于框内模板

**来源原语**：环形周期(cyclic_period) ← 30f42897；边框段(border_segment) ← 30f42897；矩形边界(rectangular_border) ← 30f42897；解码(decode) ← e6de6e8f/995c5fa3；旋转(rotate) ← 8e5a5113；模板(template) ← 8e5a5113

**依赖链**：边框段在环形路径上的起始相位编码旋转倍数（相位 0/1/2/3 对应 0/90/180/270 度）；旋转角度作用于矩形框内部的模板图案——删除边框解码则不知旋转多少度，删除旋转则边框信息无用

一句话总结：读取矩形边框上彩色段的环形起始位置，解码为旋转角度，对框内的灰色模板施加该旋转后输出。

**输入结构**：约 11x11 的网格。背景为黑(0)。网格中央有一个灰(5)像素构成的 1 像素厚完整矩形框（内部约 5x5 到 7x7）。框内有一个由红(2)像素组成的非对称 4-连通小图形（4~6 像素，无旋转对称性）。矩形框的外侧紧邻一圈边界路径（即框外一圈像素），该路径上有一段连续的蓝(1)像素（长度为边界周长的 1/4）。蓝段的其余边界位置为黑(0)。生成约束：蓝段起始位置恰好在周长的 0/4、1/4、2/4、3/4 处之一（按从左上角顺时针展开计算），保证解码无歧义。

**规则**：
1. 找到灰(5)矩形框，提取其外侧一圈像素作为环形边界路径（从左上角开始顺时针展开为一维序列）。
2. 设边界周长为 L。找到蓝(1)段的起始索引 s。计算旋转倍数 k = s / (L/4)，得到 k 属于 {0, 1, 2, 3}。
3. 提取矩形框严格内部的红(2)图案作为模板。
4. 将模板顺时针旋转 k x 90 度。
5. 输出仅包含旋转后的模板（裁剪到模板边界框大小），背景为黑(0)。灰框和蓝段均不出现在输出中。

**关键洞察**：蓝色边框段不是装饰边框，而是一个环形位置编码器——它在周长上的相对起始位置是旋转指令的密码，必须先展开环形路径才能解读。

## 新题 4：分隔格中连通分量引导的选择性镜像

**组合逻辑**：[分隔线网格/格内判定](用分隔线划分区域并判断格内属性) + [计数/连通分量计数](计算每格内的连通分量数) + [镜像](根据计数结果决定镜像方向) → 耦合：分隔格定义独立处理单元，连通分量计数决定镜像类型，镜像结果填回原格

**来源原语**：分隔线网格(separator_lattice) ← 458e3a53；格内判定(cell_interior_test) ← 458e3a53；计数(counting) ← 868de0fa/b0039139；连通分量计数(component_count) ← b0039139；镜像(mirror) ← 9bebae7a

**依赖链**：分隔线划分出独立格子（无分隔则无法确定镜像的作用域）；每格内连通分量数决定镜像类型（1 个分量→水平镜像，2 个分量→垂直镜像，3 个及以上→不变）；镜像操作在格内独立执行——删除计数则不知如何选择镜像方式，删除分隔则无法划分独立操作域

一句话总结：在由灰色分隔线划分的格子中，对每个格子数其内部连通分量数，1 个分量则水平翻转格内图案，2 个分量则垂直翻转，其余保持不变。

**输入结构**：约 15x15 的网格。灰(5)像素构成完整的行列分隔线（1 像素厚），将网格均匀划分为 3x3 或 4x4 的等大格子（每格内部约 3x3 到 4x4）。每个格子内部有黑(0)背景和由某种非灰非黑颜色（红(2)、蓝(1)、黄(4)、绿(3)中的一种）构成的 4-连通图形，每格可能有 1~3 个独立连通分量（每个分量 2~4 像素）。不同格子的图形颜色可能不同。生成约束：每格内的连通分量数明确可数（分量之间至少隔一个黑像素），且至少存在一个 1 分量格、一个 2 分量格和一个 3+ 分量格。

**规则**：
1. 通过灰(5)完整行和完整列定位分隔线，划分出所有格子的内部区域。
2. 对每个格子内部，计算非背景(非黑非灰) 4-连通分量的数量 n。
3. 若 n == 1：将该格内部图案沿水平中轴做上下镜像翻转。
4. 若 n == 2：将该格内部图案沿垂直中轴做左右镜像翻转。
5. 若 n >= 3：格内图案保持不变。
6. 输出保留灰色分隔线不变，每格内部替换为对应变换后的结果。

**关键洞察**：连通分量数不是用来填色或排序的，而是作为一个"操作选择器"——它决定的是变换类型而非变换参数，这种从计数到操作类型的映射需要对比多个示例才能归纳。

## 新题 5：对角平铺叠加后的面积奇偶填色

**组合逻辑**：[对角线偏移复制/平铺](前景图案沿对角线重复铺开) + [洪泛填充](填充叠加后形成的封闭区域) + [面积奇偶定填充色](封闭区域面积的奇偶决定颜色) → 耦合：平铺产生交叠形成新的封闭区域（源图案本身不封闭），面积奇偶决定填色

**来源原语**：对角线偏移复制(diagonal_offset_copy) ← d13f3404；平铺(tile) ← d13f3404；洪泛填充(flood_fill) ← 868de0fa/c0f76784；封闭区域(enclosed_region) ← 868de0fa/c0f76784；面积奇偶定填充色(parity_sets_fill) ← 868de0fa

**依赖链**：对角平铺使原本开放的线条图案产生交叉点，形成封闭区域（不平铺则无封闭区域）；封闭区域的面积奇偶决定填色（不计算面积则不知填什么颜色）——平铺是封闭区域产生的前提，面积是颜色的判据

一句话总结：将输入的线条图案沿右下对角线平铺到加倍画布上，对平铺后产生的每个封闭背景区域，按面积奇偶分别填入红或黄。

**输入结构**：约 7x7 的网格。背景为黑(0)。蓝(1)像素构成一个非封闭的线条图案（一条或两条不交叉的折线段，总共 5~10 像素，4-连通，不形成环路）。图案设计使得沿右下方向偏移复制后，不同副本的线条会交叉形成封闭区域。生成约束：平铺到 14x14 画布后，至少产生 2 个面积不同的封闭背景区域，且至少一个面积为奇数、一个为偶数。

**规则**：
1. 创建高度和宽度均为输入两倍的输出画布，填充黑(0)。
2. 对输入中每个蓝(1)像素 (r, c)，在输出画布的所有位置 (r+k, c+k)（k = 0, 1, 2, ...，只要不越界）画上蓝(1)。
3. 在输出画布中，找到所有被蓝(1)像素完全包围的 4-连通黑(0)区域（即不与画布边界的黑(0)连通的区域）。
4. 对每个封闭区域，计算其像素数（面积）。面积为偶数的填充红(2)，面积为奇数的填充黄(4)。
5. 蓝(1)像素和与边界连通的黑(0)区域保持不变。

**关键洞察**：输入的线条本身不围成任何区域，封闭区域完全是对角平铺的涌现产物——求解者必须先在脑中执行平铺操作，才能发现待填充的区域。

## 新题 6：控制像素排除后的周期壁纸裁剪

**组合逻辑**：[标记排除对应行列](控制像素标记哪些行列被排除) + [周期推断](从剩余像素推断瓦片周期) + [裁剪/下采样](移除被排除的行列后输出压缩网格) → 耦合：排除标记确定哪些行列被删除，周期推断仅在未排除区域运行用于验证，最终输出是删除标记行列后的压缩结果

**来源原语**：标记排除对应行列(marker_excludes_row_col) ← 9def23fe；控制像素(control_pixel) ← 9def23fe；周期推断(period_inference) ← c663677b；裁剪(crop) ← 1a6449f1；下采样(downsample) ← 68b67ca3

**依赖链**：控制像素指示哪些行/列是"干扰行列"（其中像素打乱了周期规律）；移除这些行列后剩余部分恢复完美周期；输出是移除干扰行列后的压缩网格——不识别控制像素则不知删哪些行列，不执行删除则周期不成立无法验证答案

一句话总结：识别网格边缘的橙色控制像素所标记的干扰行和干扰列，删除这些行列后输出剩余网格（剩余部分恢复为完美周期壁纸）。

**输入结构**：约 12x12 的网格。主体是一个用 3~4 种颜色（红(2)、绿(3)、青(8)、黄(4)）构成的周期壁纸（周期约 3x3 或 4x4），但其中有 2~3 行和 2~3 列被"注入"了随机颜色（打破了周期规律）。网格最左列和最上行作为控制边（不属于壁纸本体）：最上行中，被注入列对应位置有橙(7)像素，其余为黑(0)；最左列中，被注入行对应位置有橙(7)像素，其余为黑(0)。左上角(0,0)固定为黑(0)。生成约束：移除控制边和所有被标记的行列后，剩余网格严格满足周期性。

**规则**：
1. 读取第 0 行（控制行）：所有橙(7)像素的列索引构成"干扰列集合" C。
2. 读取第 0 列（控制列）：所有橙(7)像素的行索引构成"干扰行集合" R。
3. 从网格中删除第 0 行、第 0 列（控制边）、所有属于 R 的行、所有属于 C 的列。
4. 将剩余像素按原始相对顺序紧凑排列，形成输出网格。

**关键洞察**：控制像素不是标记"保留什么"，而是标记"删除什么"——求解者需要理解橙色标记的是破坏周期的干扰源位置，删除后壁纸才能恢复完整，这与直觉中"标记 = 重要"相反。

## 新题 7：射线转折路径决定柱状图排列

**组合逻辑**：[射线延伸/转折路径](从标记出发向右延伸并在边界转折向下) + [排序/柱状图](射线经过的颜色按经过顺序排列为柱状图) + [计数/包围盒高决定柱高](每种颜色的连续经过长度决定柱高) → 耦合：射线路径顺序决定柱排列顺序，路径上的连续同色段长度决定柱高

**来源原语**：射线延伸(ray_extend) ← 99fa7670；转折至下一标记行(turning_path_to_next_marker_row) ← 99fa7670；排序(sorting) ← b7999b51；柱状图(histogram_bar) ← b7999b51；包围盒高决定柱高(bbox_height_bar_height) ← b7999b51；计数(counting) ← 868de0fa

**依赖链**：射线沿路径经过不同颜色的色块，路径的转折点由色块边界决定；经过顺序定义柱排列的左右顺序（不走射线则无序）；每段连续同色的路径长度成为对应柱的高度（不测量路径段长度则无法确定柱高）——射线路径同时编码了排列顺序和高度参数

一句话总结：沿射线路径（先右后下交替转折）扫描网格中的色块，按首次经过顺序排列各颜色为柱状图列，柱高等于该颜色在路径上的总像素数。

**输入结构**：约 10x12 的网格。背景为黑(0)。网格中有 4~5 个不重叠的单色矩形色块（使用红(2)、蓝(1)、绿(3)、黄(4)、品红(6)中的不同颜色，每块约 2x3 到 4x5 像素）。网格左上角(0,0)有一个灰(5)起点标记像素。色块之间有黑色间隔。生成约束：从起点出发按"先向右到达右边界，再向下一行，再向左到达左边界，再向下一行..."的蛇形路径，保证每个色块至少被路径穿过一次。

**规则**：
1. 从灰(5)起点像素出发，生成蛇形扫描路径：第一行向右走到最右列，下移一行，向左走到最左列，下移一行...直到遍历完所有行。
2. 沿路径依次记录经过的非黑像素颜色。对同一颜色的所有路径像素计数求和，得到该颜色的"路径长度"。
3. 按颜色在路径上首次出现的顺序（先遇到的排左边），为每种颜色生成一列柱状图。
4. 输出网格宽度等于不同颜色数，高度等于最大路径长度。每列底部对齐，填充对应颜色的像素，高度等于该颜色的路径长度，上方留黑(0)。

**关键洞察**：柱的排列顺序不是按颜色编号或面积，而是按蛇形射线首次遇到的时间顺序——必须模拟完整路径才能确定顺序，空间位置偏左的色块不一定先被扫描到（因为蛇形路径在偶数行是从右向左的）。

## 新题 8：拉伸入框后的重叠遮挡排序

**组合逻辑**：[拉伸/包围盒映射](多个小精灵体分别拉伸到对应空心框内) + [包含/重叠](拉伸后多个框区域有重叠部分) + [排序](根据精灵体原始面积确定绘制顺序/遮挡优先级) → 耦合：拉伸确定每个精灵体在输出中的空间范围，重叠区域需要遮挡规则，面积排序决定谁在上层

**来源原语**：拉伸(stretch) ← 465b7d93；包围盒映射(bbox_mapping) ← 465b7d93；空心矩形(hollow_rectangle) ← 465b7d93；精灵体(sprite) ← 9bebae7a/465b7d93；排序(sorting) ← b7999b51；包含(containment) ← 868de0fa

**依赖链**：每个精灵体必须拉伸到其配对框的内部（不拉伸则无法确定输出位置）；框与框有重叠区域（重叠是拉伸后的涌现结果）；重叠区域的像素归属由精灵体原始面积的排序决定（面积最小的在最上层）——删除拉伸则无空间分配，删除排序则重叠区域无法确定

一句话总结：将多个外部小精灵体分别拉伸到配对的空心框内部，框有重叠时按精灵体原始面积从大到小的顺序绘制（小面积的最后绘制，在最上层）。

**输入结构**：约 16x16 的网格。背景为黑(0)。网格中有 3 个不同颜色的 1 像素厚空心矩形框（使用灰(5)、栗(9)、青(8)），框的大小不同（内部约 4x4 到 7x7），且两两之间有部分内部区域在空间上重叠（框的边框可以交叉或嵌套）。网格的某个角落区域有 3 个对应颜色的小 4-连通精灵体（每个 3~6 像素），精灵体颜色与框颜色一一匹配。精灵体之间间隔至少 1 像素。生成约束：三个精灵体的像素数两两不同；三个框的内部区域两两有非空交集。

**规则**：
1. 按颜色将每个精灵体与同色矩形框配对。
2. 对每对 (精灵体, 框)：将精灵体的边界框映射到框的内部区域边界框（四角对四角），精灵体中相邻像素之间用水平/垂直线段连接，然后填充连接线段围成的封闭区域（与参考题 465b7d93 相同的拉伸方法）。
3. 确定绘制顺序：按精灵体的原始像素数从大到小排序。像素数最多的最先绘制（最底层），像素数最少的最后绘制（最上层）。
4. 按此顺序依次将拉伸结果绘制到输出画布上。重叠区域被后绘制的覆盖。
5. 输出保留所有框的边框像素不变，框外区域（包括原精灵体位置）清为黑(0)。

**关键洞察**：框的重叠不是偶然的——它制造了必须用遮挡规则解决的冲突；遮挡优先级由精灵体在拉伸前的"原始复杂度"（像素数）决定，小而简单的图案反而有最高优先级，这一反直觉的映射需要对比多个示例才能发现。

## 新题 9：周期缺损位置编码重复次数

**组合逻辑**：[周期推断](推断壁纸的瓦片周期) + [计数](统计每种相位位置的缺损数量) + [重复/计数决定重复次数](缺损数决定模板重复次数) + [裁剪](提取一个完整瓦片作为模板) → 耦合：周期推断提取瓦片并确定相位坐标，缺损统计在相位空间进行，计数结果决定输出中瓦片的重复次数

**来源原语**：周期推断(period_inference) ← c663677b；缺损像素(corrupted_pixel) ← c663677b；计数(counting) ← 868de0fa/b0039139；计数决定重复次数(count_determines_repetition) ← b0039139；重复(repeat) ← b0039139；裁剪(crop) ← 1a6449f1

**依赖链**：从非缺损像素推断瓦片周期并重建完整瓦片（不推断周期则无法获得模板，也无法定义"相位"）；统计黑(0)缺损像素在瓦片相位空间中最集中的那一行的缺损数 n（不映射到相位空间则无法有意义地计数）；输出为该瓦片水平重复 n 次——三步环环相扣

一句话总结：推断周期壁纸的基本瓦片，统计缺损最集中的相位行中的缺损像素数，将瓦片水平重复该数目次作为输出。

**输入结构**：约 12x12 的网格。是一个由 3x3 或 4x4 彩色瓦片（使用红(2)、蓝(1)、绿(3)、黄(4)等颜色）周期铺满的壁纸，部分像素被替换为黑(0)缺损。缺损并非均匀分布：某一个瓦片相位行的缺损密度明显高于其他行（该行约 60%~80% 的对应位置为黑(0)，其他行不超过 20%）。生成约束：非缺损像素足够推断唯一瓦片；缺损最密集的相位行唯一（不存在并列）；该行的缺损数在 2~5 之间。

**规则**：
1. 从所有非黑(0)像素推断最小行周期 P_r 和列周期 P_c，重建完整瓦片 tile[P_r x P_c]。
2. 对瓦片的每一相位行 i (0 <= i < P_r)：统计输入网格中所有满足 r mod P_r == i 的位置中，值为黑(0)（缺损）的像素总数，记为 count[i]。
3. 找到 count 值最大的相位行索引 i_max，令 n = count[i_max]。
4. 输出为瓦片水平重复 n 次的网格（高度 P_r，宽度 P_c * n），各副本之间无间隔直接拼接。

**关键洞察**：缺损像素通常被视为需要修复的噪声，但此题中缺损的分布模式本身携带信息——缺损最集中的相位行的缺损数量编码了一个数值指令，这种"噪声即信号"的反转需要跨示例对比才能发现。

## 新题 10：分隔格字形解码驱动选择性擦除

**组合逻辑**：[分隔线网格](将输入划分为格子阵列) + [解码/字形映射](每格内的图案是编码符号) + [擦除](根据解码结果选择性擦除特定格子) → 耦合：分隔格定义解码单元，字形模式决定该格是否被保留，最终输出只包含"有效"格子的内容

**依赖链**：分隔线划分格子单元（无分隔则无法定义独立的字形区域）；每格内的图案作为字形被解码为"保留"或"擦除"指令（不解码则不知保留哪些格子）；被标记为"擦除"的格子内容清空，保留的格子紧凑拼接为输出——三步串联，删任一步均无法得到正确输出

一句话总结：在分隔格阵列中，每格包含一个小图形；图形是否接触格子上边界编码了"保留/擦除"指令，保留的格子内容按行优先顺序紧凑拼接为输出。

**输入结构**：约 15x15 的网格。灰(5)分隔线将网格划分为 4x4 的格子阵列（每格内部约 3x3）。每个格子内有一个由某种颜色（红(2)、蓝(1)、绿(3)、黄(4)之一）构成的小 4-连通图形（2~5 像素）。图形分两类：一类的最上方像素位于格子内部第 0 行（接触格子上边界），另一类的最上方像素位于格子内部第 1 行或更低（不接触上边界）。生成约束：每种类型至少出现 3 格；接触上边界的格子数量在 4~8 之间。

**规则**：
1. 通过灰(5)完整行和完整列划分格子，得到 4x4 的格子阵列。
2. 对每个格子，检查其内部非黑非灰图形的最顶部像素行是否为格子内部第 0 行（紧邻上方灰分隔线的下一行）。
3. 若是（接触上边界）：该格标记为"保留"。若否：标记为"擦除"。
4. 将所有"保留"格子的内部内容（3x3 区域，保留原色），按行优先、列次优先的顺序（即先第一行从左到右，再第二行从左到右...）水平拼接。每两个保留格之间无间隔。
5. 输出为一行高度 3（等于格子内部高度），宽度为 3 * (保留格数量) 的网格。

**关键洞察**：格内图形的具体形状和颜色不编码任何信息——唯一有意义的特征是图形是否"够到"格子的上边界，这个微妙的位置属性作为二值编码决定了整格的命运。

## 新题 11：边框段间隔编码填充色映射

**组合逻辑**：[环形周期/边框段平铺](矩形边界上的多色段按间隔排列) + [洪泛填充](填充矩形内部) + [解码](段间间隔长度编码为颜色索引) → 耦合：边框上的多色段定义了填色候选，段之间的黑色间隔长度决定哪种颜色被选中用于填充内部

**来源原语**：环形周期(cyclic_period) ← 30f42897；边框段(border_segment) ← 30f42897；间隔等长重复(repeat_equal_gap) ← 30f42897（创新改造：间隔不再等长，间隔长度本身携带信息）；洪泛填充(flood_fill) ← 868de0fa/c0f76784；封闭区域(enclosed_region) ← c0f76784；解码(decode) ← e6de6e8f

**依赖链**：边框上有多段不同颜色的像素，它们之间的间隔（黑像素数）各不相同；最长间隔紧接其后（顺时针方向）的色段颜色被选为填充色；填充色应用于矩形内部——不分析间隔则无法确定填充色，不填充则间隔信息无用

一句话总结：在矩形边框上找出各色段之间的间隔，最长间隔之后紧跟的色段颜色即为矩形内部的填充色。

**输入结构**：约 10x10 的网格。背景为黑(0)。有一个由灰(5)像素构成的 1 像素厚完整矩形框（内部约 6x6 到 8x8），内部全为黑(0)。矩形框的外侧紧邻一圈位置上，分布着 3~4 段不同颜色的连续像素段（使用红(2)、蓝(1)、绿(3)、黄(4)等颜色，每段 2~4 像素长）。色段之间由黑(0)像素间隔，各间隔长度两两不同（范围 1~5 像素）。色段按顺时针方向排列。生成约束：最长间隔唯一；色段不超过框外周长的一半。

**规则**：
1. 定位灰(5)矩形框，提取其外侧一圈像素作为环形路径（从左上角顺时针展开）。
2. 在环形路径上识别所有非黑色段及其之间的黑色间隔。
3. 找到长度最大的黑色间隔 G_max。
4. 确定 G_max 在顺时针方向上紧接其后的第一个色段，读取该色段的颜色 C。
5. 将矩形框内部所有黑(0)像素填充为颜色 C。
6. 输出保留灰色框和外圈色段不变，内部被填充为 C。

**关键洞察**：间隔不是无意义的空白，而是一个"投票"机制——最长的沉默之后发出的信号才是真正的指令。这要求求解者将注意力从色段本身转移到色段之间的空隙上。

## 新题 12：重力沉降穿越分隔线的选择性通过

**组合逻辑**：[滑动/重力沉降](像素向下坠落) + [分隔线](水平灰线作为"滤网") + [形状匹配/纯色即有效](只有满足特定宽度条件的像素组能穿过滤网) → 耦合：重力驱动下落，分隔线作为条件屏障，形状属性决定是否通过

**来源原语**：滑动(sliding) ← 3618c87e；重力沉降(gravity_settling) ← 3618c87e；分隔线(divider_line) ← 8e5a5113；纯色即有效(solid_is_valid) ← 458e3a53（创新改造：有效条件从"纯色"变为"宽度匹配"）；格内判定(cell_interior_test) ← 458e3a53

**依赖链**：重力使所有像素向下运动；水平分隔线作为过滤屏障（像素遇到分隔线时判断是否可通过）；每条分隔线有一个"通行宽度"（由分隔线上的缺口宽度指示），只有连通分量水平宽度不超过缺口宽度的像素组才能穿过，否则停在分隔线上方——三者形成"有条件的重力系统"

一句话总结：彩色像素受重力下落，但水平灰线是滤网——每条灰线中有一个缺口，只有宽度不超过缺口的连通色块能穿过，超宽的停在灰线上方。

**输入结构**：约 14x10 的网格。背景为黑(0)。有 2~3 条完整宽度的水平灰(5)线（各占一行），将网格分为 3~4 个水平区段。每条灰线中有一个连续缺口（缺口位置为黑(0)，宽度 1~3 像素不等，各线缺口宽度可能不同）。最上方若干行散布着多个不同颜色的 4-连通小色块（每块 1~4 像素，水平宽度 1~3 像素），色块使用红(2)、蓝(1)、绿(3)、黄(4)等颜色。生成约束：至少有一个色块宽度超过某条灰线缺口（会被阻挡），至少有一个色块宽度不超过所有缺口（能落到底部）。

**规则**：
1. 识别所有水平灰(5)行作为"滤网层"，记录每条滤网的缺口宽度 w_i。
2. 识别网格中所有非黑非灰的 4-连通色块，计算每个色块的水平跨度（边界框宽度）。
3. 对每个色块执行重力下落：色块整体向下移动，保持内部像素相对位置不变。
4. 当色块的最下方像素即将进入一条滤网行时：若色块水平跨度 <= 该滤网缺口宽度，色块穿过滤网继续下落（滤网行本身不被修改）；若色块水平跨度 > 缺口宽度，色块停止，其最下方像素紧贴滤网上方一行。
5. 穿过滤网的色块继续下落直到遇到下一条滤网（重复判断）或到达网格底部。
6. 多个色块在同一列可能堆叠：先处理原始位置最低的色块，再处理更高的（底部优先）。
7. 输出保留灰线（含缺口），色块在最终停止位置。

**关键洞察**：分隔线不是简单的地面——它是一个尺寸过滤器，且每层的过滤阈值不同。同一个色块可能通过第一层但被第二层阻挡，求解者必须逐层模拟才能确定最终位置。

## 新题 13：旋转槽位中的跨尺度模板匹配

**组合逻辑**：[旋转/逐槽位累计旋转](模板在分隔槽位中逐步旋转) + [形状匹配/跨尺度同形](某个槽位中的图案与外部参考形状跨尺度匹配) + [重涂色](匹配成功的槽位重涂为参考色) → 耦合：旋转生成候选形状序列，跨尺度匹配在候选中找到目标，匹配结果决定重涂哪个槽位

**来源原语**：旋转(rotate) ← 8e5a5113；逐槽位累计旋转(successive_rotation_per_slot) ← 8e5a5113；分隔线(divider_line) ← 8e5a5113；槽位(slot) ← 8e5a5113；形状匹配(shape_matching) ← ce602527；跨尺度同形(cross_scale_same_shape) ← ce602527；重涂色(recolor) ← 7e2bad24

**依赖链**：模板在各槽位中累计旋转产生 4 种朝向（不旋转则无候选比对）；外部小参考形状放大 2 倍后与某个槽位的旋转结果匹配（不做跨尺度比较则无法建立关联）；匹配到的槽位整体重涂为参考形状的颜色，其余槽位保持原色——旋转产生候选，匹配筛选目标，重涂标记结果

一句话总结：模板在 4 个槽位中依次累计旋转 90 度，找出哪个旋转版本与外部小参考形状跨尺度相同，将该槽位重涂为参考形状的颜色。

**输入结构**：约 16x7 的网格（宽大于高）。灰(5)竖线将网格分为 4 个等宽槽位和 1 个较窄的参考区（最右侧）。第一个槽位内有一个蓝(1)的非对称 4-连通模板（约 3x3 边界框，4~6 像素）。第 2~4 个槽位为黑(0)空槽。最右侧参考区有一个红(2)的小 4-连通图形（约 2x2 边界框，2~3 像素），该图形放大 2 倍后恰好与模板的某个 90 度旋转版本形状一致。生成约束：模板的四种旋转两两不同（无旋转对称）；参考形状放大 2 倍后与且仅与一个旋转版本匹配。

**规则**：
1. 定位灰(5)竖分隔线，划分出 4 个主槽位和右侧参考区。
2. 提取第一个槽位中的蓝(1)模板。
3. 将模板依次顺时针旋转 90 度，填入第 2、3、4 槽位（第 k 个槽位放置旋转 (k-1)*90 度的版本）。
4. 提取参考区的红(2)图形，将其掩码放大 2 倍。
5. 将放大后的掩码与 4 个槽位中的模板掩码逐一比较，找到完全匹配的那个槽位 j。
6. 将槽位 j 中的所有蓝(1)像素重涂为红(2)。其余槽位保持蓝(1)不变。
7. 输出包含所有 4 个槽位（含重涂结果）和灰分隔线，参考区清为黑(0)。

**关键洞察**：参考形状不是用来直接放置到某处的——它是一个"搜索查询"，经过放大后在旋转候选序列中寻找匹配。求解者必须理解尺度变换和旋转变换的交互关系。

## 新题 14：封闭区域面积驱动的选择性对角平铺

**组合逻辑**：[洪泛填充/封闭区域检测](找到线条围成的封闭区域) + [面积决定填充色](创新改造：面积不决定颜色，而决定是否参与后续操作) + [对角线偏移复制](符合面积条件的封闭区域内容被对角平铺) → 耦合：封闭区域检测确定候选区域集合，面积阈值筛选出目标区域，筛选结果决定哪些内容被对角复制

**来源原语**：洪泛填充(flood_fill) ← 868de0fa/c0f76784；封闭区域(enclosed_region) ← 868de0fa/c0f76784；面积决定填充色(area_determines_fill_color) ← c0f76784（创新改造：面积决定是否平铺）；对角线偏移复制(diagonal_offset_copy) ← d13f3404；画布加倍(canvas_doubling) ← d13f3404

**依赖链**：线条框出多个封闭区域（不检测封闭区域则无操作对象）；只有面积最小的封闭区域被选中（面积比较是筛选器，不是颜色分配器）；选中区域的内容作为图案进行对角平铺到加倍画布上——封闭检测提供候选，面积筛选确定目标，平铺执行输出

一句话总结：在灰色线条围成的多个封闭区域中，找到面积最小的那个，将其内部图案对角平铺到双倍大小的输出画布上。

**输入结构**：约 10x10 的网格。背景为黑(0)。灰(5)像素构成多条相交的直线段（水平和垂直各 2~3 条），交叉形成 3~5 个大小不同的矩形封闭区域。每个封闭区域内有不同颜色的简单图案（使用红(2)、蓝(1)、绿(3)、黄(4)等，每区域一种颜色，图案为 2~4 个像素的小图形）。各封闭区域面积（内部像素总数，不含灰边界）两两不同。生成约束：面积最小的封闭区域唯一，其内部图案的边界框不超过该区域范围。

**规则**：
1. 找到所有被灰(5)像素完全包围的 4-连通黑(0)+彩色区域（封闭区域）。每个封闭区域的面积 = 其包含的非灰像素总数。
2. 选择面积最小的封闭区域，提取其内部所有像素（包含背景黑(0)和彩色图案）作为矩形图案块 P（边界框裁剪）。
3. 创建高度和宽度均为 P 的两倍的输出画布，填充黑(0)。
4. 对 P 中每个非黑像素 (r, c)，在输出画布的所有位置 (r+k, c+k)（k = 0, 1, 2, ...，不越界）画上该颜色。
5. 输出即为对角平铺后的画布。灰线和其他封闭区域不出现在输出中。

**关键洞察**：多个封闭区域是"候选池"而非都需要处理——面积最小这一条件将候选缩减为唯一目标，然后对角平铺将一个局部图案扩展为全局输出，两级筛选+变换的结构需要逐步推理。

## 新题 15：蛇形扫描解码与条件式镜像拼接

**组合逻辑**：[解码/连线](蛇形路径上的颜色序列编码指令) + [镜像](根据解码指令对模板执行特定方向的镜像) + [拼接/相邻拼接](镜像结果按指令顺序拼接) → 耦合：蛇形路径的读取顺序决定指令序列，指令内容决定镜像方式，镜像结果按路径顺序拼接

**来源原语**：解码(decode) ← e6de6e8f/995c5fa3；连线(trace) ← e6de6e8f；镜像(mirror) ← 9bebae7a；相邻拼接(adjacent_placement) ← 9bebae7a；顺序排列(sequential_order) ← e6de6e8f/8e5a5113

**依赖链**：蛇形路径定义读取顺序，从特殊位置提取颜色指令序列（无蛇形读取则指令顺序不确定）；每种颜色编码一种镜像操作（红=水平镜像，蓝=垂直镜像，绿=原样复制）；指令依次作用于模板并将结果水平拼接——路径确定序列，颜色确定操作，拼接确定输出

一句话总结：从网格顶部的指令区按蛇形路径读取颜色序列，每种颜色对应一种镜像操作，将这些操作依次应用于底部模板并水平拼接所有结果。

**输入结构**：约 12x8 的网格。网格被一条水平灰(5)线分为上下两区。上区（约 3x8）：背景为黑(0)，散布着若干彩色像素（红(2)、蓝(1)、绿(3)三种颜色各出现 1~2 次），它们的位置决定了蛇形读取的顺序。上区左上角(0,0)有一个栗(9)起点标记。下区（约 8x8 减去分隔行）：包含一个由黄(4)像素构成的非对称 4-连通模板（约 4x3 边界框，5~7 像素），模板无任何对称性。生成约束：上区像素位置保证蛇形扫描经过它们时不会产生歧义（同一扫描位置不会有两个彩色像素）；指令数量为 3~4 个。

**规则**：
1. 从上区的栗(9)起点标记出发，按蛇形路径（第 0 行从左到右，第 1 行从右到左，第 2 行从左到右...）扫描上区所有位置。
2. 按扫描顺序记录遇到的非黑非灰非栗像素颜色，形成指令序列 [c1, c2, c3, ...]。
3. 对下区的黄(4)模板执行指令序列中的每条指令：红(2) = 将模板上下镜像；蓝(1) = 将模板左右镜像；绿(3) = 保持模板原样。每条指令独立作用于原始模板（不是累计变换）。
4. 将所有指令结果按顺序从左到右水平拼接，相邻结果之间无间隔。
5. 输出为拼接后的矩形网格（高度 = 模板边界框高度，宽度 = 模板边界框宽度 * 指令数），背景为黑(0)，模板像素为黄(4)。

**关键洞察**：指令不是写在固定位置的标签，而是散落在二维空间中的像素，只有通过特定的蛇形扫描路径才能确定它们的正确顺序——空间位置到时间序列的转换是核心难点。
