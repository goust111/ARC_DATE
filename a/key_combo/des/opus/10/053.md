## 新题 1：奇偶门控区域填充

**组合逻辑**：[洪泛填充](已有) + [坐标奇偶匹配](创新：从全局格点约束改为封闭区域内局部约束) → [重涂色](已有)

**来源原语**：洪泛填充(flood_fill)、内外分区(in_out_partition)、封闭区域(enclosed_region)、边界连通分内外(border_in_out) ← 7b6016b9；坐标奇偶匹配(coord_parity_match)、同奇偶背景涂色(same_parity_colored)、奇偶格点(parity_lattice) ← d492a647；标记像素(marker_pixel) ← 多题共有

**依赖链**：识别灰色墙体确定封闭区域边界 → 在每个区域中定位标记像素获取颜色和坐标 → 标记的坐标奇偶决定该区域内哪些背景像素被填充 → 标记的颜色决定填充色。删去任一环节均无法独立求解：无墙体则区域不明；无奇偶约束则退化为整区均匀填充；无标记则颜色和填充相位均未知。

在灰色墙壁围成的多个封闭区域中，每个区域的标记像素既指定填充颜色，又通过自身坐标奇偶选择区域内的填充格点，生成局部棋盘图案。

**输入结构**：黑(0)背景的网格（约 15x15 至 20x20）。灰(5)像素形成 4-连通的墙壁结构，将网格划分为若干封闭区域（每个区域为被墙壁完全围合的 4-连通黑色像素集合）和外部区域（与网格边界 4-连通的黑色像素）。每个封闭区域内恰好有一个非黑非灰的彩色标记像素（颜色取自红(2)、蓝(1)、绿(3)、黄(4)等，各区域标记颜色可相同也可不同）。生成约束：每个封闭区域至少 4x4 大小；标记像素不与墙壁 4-相邻；不同示例中同一区域的标记位于不同奇偶坐标以展示相位变化。

**规则**：
1. 保留所有灰(5)墙壁像素不变。
2. 外部区域（与网格边界 4-连通的背景像素）保持黑(0)不变。
3. 对每个封闭区域：找到其中唯一的标记像素，记其坐标为 (r, c)，记 row_parity = r mod 2，col_parity = c mod 2。
4. 在该封闭区域内，将所有满足 (行号 mod 2 = row_parity) 且 (列号 mod 2 = col_parity) 的黑(0)背景像素涂为标记的颜色。其余背景像素保持黑(0)。
5. 标记像素本身保留原色不变（它自身天然满足奇偶匹配条件，属于填充图案的一部分）。

**关键洞察**：同一区域的填充图案相位取决于标记像素的坐标奇偶性——标记位于偶行偶列与位于奇行奇列会产生不同的棋盘相位，这一规则需对比多个示例中不同位置的标记才能归纳，仅看单一示例会误认为是固定棋盘或全区填充。

## 新题 2：连线长度调色板

**组合逻辑**：[连线](已有) + [排序](已有) + [对角序映射色环](创新：从同心层带映射改为按长度排名映射连线颜色)

**来源原语**：连线(connect)、同行列对齐(row_col_aligned)、相邻标记间填充(fill_between_markers)、标记像素(marker_pixel) ← dbc1a6ce；对角线标记(diagonal_marker)、对角序映射色环(diagonal_color_bands) ← 99306f82；排序(sort)、对齐(alignment) ← beb8660c

**依赖链**：定位蓝色标记 → 找出同行或同列标记对并生成连线 → 测量每条连线长度 → 读取对角线调色板序列 → 按长度升序将调色板颜色依次分配给各连线。删去任一环节均无法独立求解：无连线则无需调色；无长度排序则调色板分配无据；无调色板则不知用何颜色。

将同行或同列的蓝色标记之间的连线按长度从短到长排序，依次分配对角线调色板中的颜色。

**输入结构**：黑(0)背景的网格（约 15x15 至 20x20）。网格左上角有一组沿主对角线排列的单像素彩色标记（位于 (0,0), (1,1), (2,2), ... 等位置，每个占一格），颜色互不相同且均非黑(0)、非蓝(1)（如红(2), 绿(3), 黄(4), 橙(7), 品红(6)等），构成有序调色板序列。网格其余位置散布若干蓝(1)标记像素。部分蓝标记共享同一行或同一列（每行最多 2 个蓝标记，每列最多 2 个蓝标记）。生成约束：对角线调色板的颜色数量 >= 所有可形成的连线数量；蓝标记不出现在对角线调色板占用的坐标上；同行或同列的蓝标记对之间无其他非背景像素阻挡。

**规则**：
1. 保留所有输入像素（蓝标记和对角线调色板像素）不变。
2. 在每一行中，若恰好有两个蓝(1)标记像素，在它们之间严格内部的所有背景像素上画水平连线段。在每一列中，若恰好有两个蓝(1)标记像素，在它们之间严格内部的所有背景像素上画垂直连线段。
3. 测量每条连线段的长度（连线段不含两端蓝标记像素，长度 = 中间被填充的像素数）。
4. 将所有连线段按长度从短到长排序。若两段长度相同，按连线段起始端像素坐标排序（先比较行号再比较列号，较小者优先）。
5. 读取对角线调色板序列（从 (0,0) 到 (K-1,K-1)，共 K 个颜色）。将排序后第 i 条连线段（i 从 1 开始）的所有像素涂为调色板第 i 个颜色。

**关键洞察**：连线颜色既非固定也非由端点位置决定，而是由连线长度在所有连线中的排名索引到外部调色板——需对比多个示例中不同长度的连线获得不同调色板颜色才能排除"按方向分色"或"固定颜色"等假设。

## 新题 3：字典映射约束生长

**组合逻辑**：[颜色映射](已有) + [洪泛填充](创新：从内外二分改为区域内受限生长，且填充色由外部字典决定) + [编码映射](创新：从模板索引改为种子色到填充色的显式字典)

**来源原语**：颜色映射(color_mapping)、匹配对推导映射(pair_defines_mapping) ← b0722778；洪泛填充(flood_fill)、封闭区域(enclosed_region)、边界连通分内外(border_in_out) ← 7b6016b9；标记像素(marker_pixel)、编码映射(encoding_map) ← 65b59efc；瓦片(tile)、分隔行(separator_row)

**依赖链**：读取字典区的色彩对构建映射表 → 在主区中识别灰色墙壁围成的封闭区域 → 定位每个区域内的种子像素 → 查表将种子颜色转换为填充颜色 → 在区域内洪泛填充。删去任一环节：无字典则不知填何色；无墙壁则生长无界；无种子则无起始点且无法查表。

通过顶部字典区学习颜色映射规则，再将底部每个封闭区域内的种子像素按映射后的颜色进行洪泛填充，种子像素保留原色。

**输入结构**：网格（约 18x12），由一行灰(5)分隔行水平切割为上下两区。上区（字典区，约 2 至 3 行高）：在黑(0)背景上排列若干颜色对，每对由水平相邻的两个像素组成（左像素为源色，右像素为目标色），各对之间隔两列黑色背景。颜色对使用红(2)、蓝(1)、绿(3)、黄(4)、橙(7)、品红(6)等颜色，每对的源色互不重复，源色与目标色不同。下区（主区，约 14 行高）：灰(5)像素构成 4-连通墙壁，围成若干封闭区域（各区域为被墙壁完全围合的 4-连通黑色像素集合）。每个封闭区域内恰好有一个彩色种子像素，种子颜色一定是字典区某个源色。生成约束：字典区的源色集合覆盖所有种子颜色；各封闭区域互不连通；种子像素不与墙壁 4-相邻。

**规则**：
1. 读取字典区中的颜色对：在上区的非背景像素中，每对水平相邻的两个非黑像素构成一个映射条目，左侧为源色、右侧为目标色。构建映射表 {源色 -> 目标色}。
2. 保留灰(5)分隔行和所有墙壁像素不变。
3. 对下区每个封闭区域：
   a. 找到区域内唯一的种子像素，读取其颜色 C_seed。
   b. 在映射表中查找 C_seed 对应的目标色 C_fill。
   c. 将该封闭区域内所有黑(0)背景像素涂为 C_fill。
   d. 种子像素保留其原始颜色 C_seed 不变。
4. 外部区域（与网格边界 4-连通的背景）保持黑(0)。

**关键洞察**：区域的填充色不是种子自身的颜色，而是通过字典区的映射规则转换后的颜色——种子像素在填充后保留原色形成视觉对照，需同时观察种子色与填充色的差异并参照字典区的对应关系才能归纳映射规则，仅看一个区域会误以为填充色是固定的或随机的。

## 新题 4：等差旋转补全

**组合逻辑**：[旋转](已有) + [等差递推](已有) + [印章覆盖](创新：从标记选槽改为序列位置决定旋转角度) + [补全](已有)

**来源原语**：旋转(rotate)、旋转族成员(rotation_family)、缺失旋转变体(missing_rotation) ← be03b35f；等差序列(arithmetic_sequence)、等差递推(arithmetic_progression)、补全(completion) ← f8c80d96；印章覆盖(stamp)、精灵体(sprite)、槽位(slot) ← 363442ee

**依赖链**：识别模板精灵体 → 识别等距排列的槽位序列 → 从已填槽位中归纳旋转递进规则（每个槽位的旋转角度 = 槽位序号 x 90 度 mod 360 度）→ 推断空槽应放置的旋转变体 → 印章填入。删去任一环节：无模板则不知印什么；无等距间距则槽位序号不明；无旋转规则则角度无法确定。

在等距排列的槽位序列中，已占槽位包含模板精灵体的旋转变体，空槽位需根据位置序号推断正确的旋转角度并补全。

**输入结构**：网格（约 20x20）。左上角有一个由非背景色（如红(2)）绘制的小型非对称精灵体模板（占据一个 3x3 或 4x4 的边界框，4-连通，形状既非中心对称也非轴对称，以确保 0 度、90 度、180 度、270 度 四个顺时针旋转变体各不相同）。网格下方（或右方）有一列等距排列的正方形槽位，每个槽位尺寸与精灵体边界框相同。相邻槽位之间由一行（或一列）灰(5)像素分隔，间距相等。共 5 至 8 个槽位。部分槽位包含精灵体的某个顺时针旋转变体（用与模板相同的颜色绘制），部分槽位为空（全为黑(0)背景）。生成约束：已填槽位数量 >= 3，空槽位数量 >= 1；旋转规则为顺时针——slot 序号从 0 开始，slot i 的旋转角度 = i x 90 度 mod 360 度。

**规则**：
1. 识别左上角的精灵体模板，记为 T（以其边界框内的像素图案为准）。
2. 识别等距槽位序列，按空间顺序（从上到下或从左到右）编号为 slot 0, slot 1, slot 2, ...。
3. 旋转规则：slot i 应包含 T 顺时针旋转 (i x 90 度 mod 360 度) 的变体。即 slot 0 = 原始 T，slot 1 = T 顺时针旋转 90 度，slot 2 = T 顺时针旋转 180 度，slot 3 = T 顺时针旋转 270 度，slot 4 = T 原始（周期重复），依此类推。
4. 对每个空槽位，根据其序号 i 计算旋转角度，将 T 的对应旋转变体印章填入该槽位，使用与模板相同的颜色。
5. 已填槽位和模板区域保持不变。灰(5)分隔像素保持不变。

**关键洞察**：旋转角度不是固定的（并非所有槽位都旋转 90 度），而是与槽位在序列中的绝对位置绑定——slot 0 总是 0 度、slot 4 也是 0 度（周期为 4），需对比多个已填槽位的序号和旋转状态才能归纳出"序号 x 90 度 mod 360 度"的周期规律，而非简单的"相邻槽位差 90 度"。

## 新题 5：拓扑计数定缩放与内外染色

**组合逻辑**：[计数](创新：从前景色种类数改为封闭区域数量) → [像素放大](已有) → [洪泛填充 + 内外分区](已有)

**来源原语**：计数(counting)、前景色数定倍率(color_count_sets_scale) ← b91ae062；像素放大(pixel_upscale)、均匀倍率缩放(uniform_scale_factor) ← c59eb873；洪泛填充(flood_fill)、内外分区(in_out_partition)、边界连通分内外(border_in_out)、线条对象(line_object)、封闭区域(enclosed_region)、画布边界(canvas_boundary) ← 7b6016b9

**依赖链**：识别前景线条对象 → 计数其围成的封闭区域数 K → 以 K 为倍率放大整个网格 → 在放大后的网格中执行内外分区并分别染色。删去任一环节：无计数则缩放倍率不明；无放大则输出尺寸错误；无内外染色则仅是普通放大（退化为 c59eb873）。

先统计前景线条围成的封闭区域数量作为缩放倍率，放大网格后，将外部背景染绿、内部背景染红。

**输入结构**：小型网格（5x5 至 7x7），黑(0)背景上有一种非背景色（如蓝(1)）的 4-连通线条对象。线条对象将背景划分为外部区域（与网格边界 4-连通的黑色像素集合）和若干封闭区域（不与网格边界 4-连通的黑色像素连通分量）。封闭区域数量为 2 至 4 个。生成约束：线条对象为单一 4-连通分量；不同训练示例中封闭区域数量不同（如一个示例 2 个孔、另一个示例 3 个孔），以体现缩放倍率随拓扑变化。

**规则**：
1. 识别网格中唯一的非背景色前景线条对象。
2. 计算线条对象围成的封闭背景区域数量 K（封闭区域 = 不与网格边界 4-连通的黑(0)像素连通分量的个数）。
3. 将整个网格以倍率 K 进行像素放大：每个输入像素变为 K x K 的同色方块，输出网格尺寸为原始行数 x K 行、原始列数 x K 列。
4. 在放大后的网格中：
   a. 线条对象像素（放大后的 K x K 方块）保持原色不变。
   b. 与放大后网格边界 4-连通的黑(0)背景像素涂为绿(3)（外部区域）。
   c. 不与放大后网格边界 4-连通的黑(0)背景像素涂为红(2)（内部封闭区域）。

**关键洞察**：缩放倍率不是常数也不是由颜色种类数决定，而是由线条对象的拓扑性质（围成的空洞数）决定——需对比不同示例中不同空洞数导致不同输出尺寸才能归纳此规则，而且缩放后内外分区的结果在视觉上与缩放前一致但更加醒目。

## 新题 6：像素计数重排与局部棋盘纹理

**组合逻辑**：[压缩重排](已有) + [坐标奇偶匹配](创新：从全局网格奇偶改为各方块内部局部坐标奇偶) → [重涂色](已有)

**来源原语**：压缩重排(repack)、色块(color_group)、正方形(square)、面积递增排列(area_ascending_order)、像素数定边长(pixel_count_determines_side) ← 8abad3cf；坐标奇偶匹配(coord_parity_match)、奇偶格点(parity_lattice)、同奇偶背景涂色(same_parity_colored) ← d492a647；排序(sort)、重涂色(recolor)

**依赖链**：统计每种前景色像素数 → 开平方得边长 → 按边长升序排列 → 重排为底对齐方块序列 → 在每个方块内部施加局部坐标奇偶纹理。删去任一环节：无像素计数则边长未知；无排序则排列无据；无局部奇偶纹理则输出为实心方块（退化为 8abad3cf）。

将散布的颜色像素按数量重排为递增大小的实心方块，然后在每个方块内部施加基于局部坐标的棋盘纹理。

**输入结构**：黑(0)背景的网格（约 15x15）。网格中散布着若干种非背景色的像素（如红(2)、蓝(1)、绿(3)、黄(4)），每种颜色的像素分布形态任意（可以是不规则的连通或不连通形状），但每种颜色的像素总数恰好是完全平方数（如 1、4、9、16）。各颜色的像素总数互不相同。生成约束：非背景色种类数为 3 至 5 种；各色像素总数分别为不同的完全平方数。

**规则**：
1. 统计每种非背景色的像素数量 N，计算边长 S = sqrt(N)。
2. 按边长 S 从小到大排序各颜色。
3. 创建输出网格：从左到右依次放置各色的 S x S 方块，所有方块底边对齐于输出网格最底行，相邻方块之间间隔一列黑(0)背景。输出网格宽度 = 所有方块宽度之和 + 间隔列数，高度 = 最大方块的边长。
4. 在每个方块内部施加棋盘纹理：以方块自身左上角为局部坐标原点 (0, 0)，对方块内局部坐标 (lr, lc)，若 (lr + lc) 为偶数则保持该颜色不变，若 (lr + lc) 为奇数则涂为灰(5)。
5. 未被方块覆盖的背景区域保持黑(0)。

**关键洞察**：棋盘纹理使用的是每个方块内部的局部坐标而非网格全局坐标——不同大小的方块放置在不同的全局列位置，但每个方块的棋盘图案始终从左上角以原色开始，需对比不同位置方块的纹理起始相位才能排除"全局坐标奇偶"的假设。

## 新题 7：拓扑判向滑动与边界重涂

**组合逻辑**：[分类](创新：分类结果决定运动方向而非堆叠列) + [滑动](已有) + [重涂色](创新：由碰撞类型而非拓扑本身触发)

**来源原语**：分类(classify)、内部判定类型(interior_determines_type) ← 2ba387bc；滑动(sliding)、趋近目标(approach_target) ← dc433765；重涂色(recolor)、含空洞对象重涂(objects_with_holes_recolored) ← b2862040；连通分量(connected_component)、封闭区域(enclosed_region)

**依赖链**：识别各连通对象 → 判断有无内部空洞进行分类 → 分类结果决定滑动方向 → 按处理顺序逐个滑动至碰撞 → 碰撞类型（边界 vs 其他对象）决定是否重涂。删去任一环节：无分类则滑动方向不明；无滑动则位置不变；无碰撞判定重涂则输出与简单滑动无区别。

根据连通对象的拓扑类型（有孔为框型、无孔为实心）决定滑动方向：实心向下、框型向上；滑动后被网格边界阻停的对象重涂为灰色，被其他对象阻停的保留原色。

**输入结构**：黑(0)背景的网格（约 15x18）。网格中散布 4 至 6 个 4-连通的单色对象，每个对象使用不同的非背景色（如红(2)、蓝(1)、绿(3)、黄(4)、橙(7)、品红(6)）。部分对象是实心的（对象像素内部无被完全围合的黑色空洞），部分对象是框型的（对象像素围成至少一个 4-连通黑色空洞）。每个对象约 6 至 15 像素，形状各异（不限于矩形，包含不规则连通形状）。生成约束：对象之间互不 4-相邻（至少间隔 1 像素）；各对象沿其滑动方向的路径上不存在多重碰撞（即每个对象在滑动过程中最多碰到一个障碍物）；至少有一个对象滑动后被边界阻停，至少有一个被其他对象阻停。

**规则**：
1. 识别所有非背景色的 4-连通对象。
2. 分类：若对象内部存在被其自身像素完全 4-连通围合的黑(0)背景像素连通分量（空洞），标记为"框型"；否则标记为"实心"。
3. 滑动方向：实心对象向下滑动；框型对象向上滑动。
4. 处理顺序：向下滑动的对象按其最低行坐标从大到小处理（最靠近底边的先滑）；向上滑动的对象按其最高行坐标从小到大处理（最靠近顶边的先滑）。两组分别独立处理完毕（先处理所有向下的，再处理所有向上的）。
5. 每个对象沿指定方向逐行滑动，保持形状和内部结构不变，直到其任意像素的下一步位置超出网格边界或与已固定的非背景像素重叠时停止。
6. 重涂规则：滑动完成后，若对象是因触及网格边界而停止的（即向下滑动的对象其最低像素位于最底行，或向上滑动的对象其最高像素位于最顶行），则将该对象所有像素重涂为灰(5)（空洞保持黑色不变）；若对象是因碰到另一个对象而停止的，则保留原色不变。

**关键洞察**：对象的滑动方向由其拓扑属性（是否含空洞）决定，而最终是否变灰取决于碰撞类型（边界 vs 其他对象）而非拓扑本身——需对比多个示例中相同拓扑类型但不同碰撞结果的对象，才能同时归纳出方向规则和重涂条件这两条独立但耦合的规则。
