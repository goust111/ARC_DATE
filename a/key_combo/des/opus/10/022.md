## 新题 1：拓扑封闭性门控印章放置

**组合逻辑**：[connected_component_detection](用于区域拓扑分类) + [stamp_overlay](在门控通过的标记位置执行印章) + [erase](清除未通过门控的标记)

**来源原语**：connected_component_detection / edge_reachability / topological_classification（来自 84db8fc4）；stamp_overlay / mask_selects_placement（来自 48f8583b）；erase（来自 1b8318e3）

**依赖链**：灰色障碍物将背景划分为若干 4-连通区域 → 拓扑分类判定每个区域是封闭（不可达网格边缘）还是开放（可达网格边缘） → 封闭区域内的绿色标记像素接受印章操作，开放区域内的绿色标记像素被擦除 → 印章操作将角落处的模板瓦片以标记为中心复制到输出

从角落读取模板瓦片，根据灰色障碍物形成的拓扑封闭性，决定哪些绿色标记位置接受瓦片印章、哪些被擦除。

**输入结构**：约 15x15 网格，黑(0)背景。灰(5)像素形成不规则的连通障碍网络（类似墙壁），将黑色背景分割为若干大小不等的 4-连通区域——其中一些区域的黑色像素可经 4-连通路径到达网格最外圈边缘，另一些完全被灰色像素包围而无法到达边缘。网格左上角固定放置一个 3x3 的彩色模板瓦片（使用红(2)和黄(4)两色，内部图案各示例不同）。若干绿(3)单像素标记散布在网格各区域中（每个区域 0 或 1 个标记），总计 3-6 个标记。生成约束：每个封闭区域至少足够大（至少 5x5 空间），以容纳一个 3x3 印章而不与灰色障碍重叠；模板瓦片所在的左上角 3x3 区域不包含灰色障碍。

**规则**：
1. 读取左上角 3x3 区域作为模板瓦片，记录其颜色图案。
2. 将黑(0)背景像素按 4-连通性分为若干连通区域（灰色像素视为障碍，不属于任何区域）。
3. 对每个连通区域判定拓扑类型：若该区域存在至少一个像素位于网格第 0 行、最后一行、第 0 列或最后一列，则为"开放区域"；否则为"封闭区域"。
4. 对每个绿(3)标记像素：若它位于封闭区域内，则以该标记为中心，将 3x3 模板瓦片覆盖到输出（模板像素覆盖该位置的原有内容；若印章范围超出网格边界则裁剪掉超出部分）；同时擦除该绿色标记（被模板覆盖）。若它位于开放区域内，则将该绿色像素擦除为黑(0)。
5. 灰色障碍物和左上角模板区域在输出中保持不变。

**关键洞察**：绿色标记本身不携带"是否应被印章"的信息——这一判断完全由其所在区域的拓扑封闭性决定。仅看标记位置无法判断，必须追踪其所在连通区域是否可达网格边缘。

## 新题 2：朝向计数作为路径路由隐式开关

**组合逻辑**：[classify + counting](对小对象按长轴方向分类并计数) → [draw_line](根据计数结果选择 L 形路径的拐弯顺序) + [erase](清除投票对象)

**来源原语**：classify / orient_group / orient_determines_panel（来自 d5c634a2）；counting / count_maps_slot（来自 d5c634a2）；draw_line / manhattan_path / L_path_connection（来自 a2fd1cf0）；erase（来自 a78176bb）；same_color_pairing / shared_row_or_column（来自 070dd51e）

**依赖链**：红色小对象按包围盒长轴方向分为水平组和垂直组 → 计数两组数量 → 多数组决定绿色标记对使用"先水平后垂直"的 L 形路径，蓝色标记对使用相反顺序；少数组则反之 → 路径绘制完成后擦除所有红色对象

统计散布的红色小对象的朝向多数派，以此决定两对彩色标记各自采用哪种拐弯顺序的 L 形连线。

**输入结构**：约 13x13 网格，黑(0)背景。3-5 个红(2)小对象散布在网格中，每个对象为 4-连通单色区域（3-6 像素），形状不对称：其包围盒在一个维度上严格更长（例如宽 > 高 或 高 > 宽），长轴方向即为该对象的"朝向"。两个绿(3)单像素标记，共享同一行或同一列。两个蓝(1)单像素标记，共享同一行或同一列（与绿色对不同的行/列）。生成约束：红色对象不与任何标记共享行列；绿色对和蓝色对不在同一行也不在同一列；各对象和标记之间至少隔 2 个像素；水平朝向和垂直朝向的红色对象数量不相等（确保有唯一多数派）。

**规则**：
1. 对每个红色对象计算包围盒。若包围盒宽度 > 高度，归入"水平组"；若高度 > 宽度，归入"垂直组"。（生成约束保证不会出现正方形包围盒。）
2. 统计水平组数量 Nh 和垂直组数量 Nv。
3. 若 Nh > Nv（水平为多数派）：绿色标记对之间绘制绿(3) L 形路径，先水平移动再垂直移动；蓝色标记对之间绘制蓝(1) L 形路径，先垂直移动再水平移动。若 Nv > Nh（垂直为多数派）：绿色用先垂直后水平，蓝色用先水平后垂直。
4. L 形路径的绘制方式：从一个标记出发，沿指定的第一方向（水平或垂直）画直线直到与另一个标记对齐（同列或同行），然后转向画直线到达另一个标记。路径包含起止点，仅覆盖黑色背景像素。
5. 擦除所有红(2)像素（变为黑(0)）。
6. 若绿色路径和蓝色路径在某像素交叉，蓝色路径后绘制因此蓝色覆盖绿色。

**关键洞察**：红色对象不出现在输出中——它们仅作为"投票者"决定路径路由策略。求解者必须发现朝向多数派与 L 形拐弯顺序之间的隐式映射，这一映射只有对比多个示例（红色对象朝向分布不同导致路径拐弯顺序翻转）才能归纳。

## 新题 3：重力落位决定形状匹配填色

**组合逻辑**：[gravity_drop](小对象垂直下落至平台) + [shape_matching](将落点处的对象形状与平台下方密钥图案比较) → [fill](匹配成功则将密钥图案染色) + [erase](匹配成功的对象被吸收移除)

**来源原语**：gravity_drop / collision_stop（来自 36a08778）；shape_matching / support_match（来自 e5062a87）；fill（来自 dbff022c）；erase（来自 1b8318e3）

**依赖链**：对象垂直下落 → 水平位置决定它落在哪个平台上 → 落在平台后，与该平台关联的密钥图案进行形状比较 → 匹配成功触发颜色转移（对象色→密钥图案），不匹配则对象原地保留

彩色小对象从顶部下落至灰色平台，仅当对象形状与平台下方的灰色密钥图案匹配时，密钥图案被染上对象的颜色并吸收该对象。

**输入结构**：约 14x12 网格，黑(0)背景。顶部区域（第 0-2 行）：3-4 个小型 4-连通单色对象（每个 3-5 像素），颜色各不相同（使用红(2)、蓝(1)、绿(3)、黄(4)中的若干种），形状各异。中下部区域：2-4 个灰(5)水平平台段（每段宽 5-7 像素，高 1 像素），分布在不同行高。每个平台正下方一行处有一个灰(5)密钥图案（3-5 像素的 4-连通图形，包围盒不超过平台宽度），密钥图案的形状与某些顶部对象的形状相同或不同。生成约束：每个顶部对象的水平范围恰好与一个平台的水平范围有交叠（确保它能落在该平台上）；不同对象落在不同平台上（水平范围不重叠多个平台）；至少一个对象与其目标平台的密钥不匹配。

**规则**：
1. 每个顶部彩色对象整体向下平移（所有像素同时下移），保持水平位置不变，直到对象最底行像素的正下方一行遇到灰色平台像素时停止（即对象底边紧贴平台顶面）。
2. 对象停稳后，取该对象的像素图案（在其包围盒内的相对坐标集合），与它所停靠的平台正下方的密钥图案的像素图案（在密钥包围盒内的相对坐标集合）进行比较。比较时忽略颜色，仅看相对坐标集合是否完全一致（不允许旋转或翻转）。
3. 若匹配：将密钥图案的所有灰色像素重涂为该对象的颜色。同时将停靠在平台上的该对象的所有像素擦除为黑(0)（对象被"吸收"）。
4. 若不匹配：对象保留在其停靠位置（保持其原色），密钥图案保持灰色不变。
5. 所有平台本身（灰色水平段）在输出中保持不变。

**关键洞察**：重力仅决定空间配对（哪个对象遇到哪个平台），但颜色转移需要形状匹配的二次确认。两个条件缺一不可——即使形状完全匹配，若对象在错误的水平位置（落在别的平台上），也不会发生转移。

## 新题 4：连通分量面积门控周期图案修复

**组合逻辑**：[connected_component_detection + counting](检测黑色污渍并测量面积) + [completion + tiling](从残存前景推断周期瓦片并修复小污渍下方的图案) — 两条分析线索汇合于同一输出决策

**来源原语**：connected_component_detection / area_classification / area_threshold_filter（来自 84db8fc4, d2abd087, 12eac192）；completion / periodic_tile / residue_infers_period / periodic_repeat（来自 ea959feb）；counting（来自 d5c634a2）

**依赖链**：黑色污渍覆盖了周期壁纸的部分区域 → 需要从残存的彩色像素推断壁纸的最小重复周期 → 同时需要检测每个黑色连通分量的面积 → 面积 <= 阈值的污渍被修复（用推断出的壁纸图案填充），面积 > 阈值的污渍保持黑色

在被多个黑色污渍遮挡的周期壁纸上，仅修复小面积污渍下方的壁纸图案，大面积污渍视为永久障碍保持不变。

**输入结构**：约 13x13 网格。壁纸背景由两种颜色（如红(2)和黄(4)）构成严格的二维周期图案（周期为 2x2 至 4x4，行周期和列周期可以不同），覆盖整个网格。若干黑(0)污渍（4-连通的黑色连通分量）散布在网格上，遮盖了壁纸的部分像素。污渍大小各异：有些面积为 1-4 像素（小污渍），有些面积为 6-12 像素（大污渍）。生成约束：残存的未被遮盖的壁纸像素足以唯一确定行周期和列周期（即每个周期残差类至少有一个可见的前景像素）；小污渍和大污渍之间的面积不存在歧义（生成时保证面积 5 的污渍不出现，形成清晰的阈值间隔）；至少有 2 个小污渍和 1 个大污渍。

**规则**：
1. 忽略所有黑(0)像素，仅从可见的红(2)和黄(4)像素推断壁纸的最小行周期 Pr 和列周期 Pc。方法：找到使得所有同一 (row mod Pr, col mod Pc) 残差类中的可见像素颜色一致的最小 Pr 和 Pc。
2. 检测所有黑(0)的 4-连通分量，计算每个分量的面积（像素数）。
3. 面积 <= 4 的黑色分量：将其中每个黑色像素替换为该像素所属残差类 (row mod Pr, col mod Pc) 在壁纸中对应的颜色（即修复壁纸）。
4. 面积 >= 6 的黑色分量：保持黑色不变。
5. 所有未被污渍遮盖的壁纸像素保持不变。

**关键洞察**：求解者必须同时进行两项独立分析——周期推断（从残存像素恢复壁纸规律）和面积分类（判断哪些污渍该修复）——并将两者的结果汇合：周期告诉你每个位置"应该是什么颜色"，面积告诉你"是否需要恢复"。两项分析的结果缺一不可。面积阈值（4 和 6 之间的间隔）需要通过对比多个示例来归纳。

## 新题 5：线路弯折次数编码形状循环步进

**组合逻辑**：[transmit](沿线路传输令牌) + [shape_transform](形状按循环变换) + [counting](计数线路弯折次数决定变换步数) — 线路几何结构编码变换规则

**来源原语**：transmit / wire_network / endpoint_pairing（来自 a47bf94d）；shape_transform / shape_cycle_mapping（来自 a47bf94d）；counting（来自 d5c634a2）

**依赖链**：识别线路网络和端点配对 → 计数每条线路的直角弯折次数 → 弯折次数决定形状循环前进步数 → 在接收端绘制变换后的形状

彩色令牌沿灰色线路传输到对端，但到达时的形状不是固定的互补形状，而是由线路弯折次数在"实心→交叉→菱形"循环中步进决定的。

**输入结构**：约 15x15 网格，黑(0)背景。灰(5)像素构成 2-4 条独立的线路路径，每条线路是宽 1 像素的 4-连通路径，两端各有一个端点。线路之间互不连通。线路包含若干直角弯折（从水平方向变为垂直方向或反之）。在若干线路的一个端点处（紧邻端点外侧），有一个 3x3 彩色令牌，令牌类型为以下三种之一：实心块（3x3 全填充同色）、X 形（仅四个角像素和中心像素填充）、菱形（中心像素加上下左右四个相邻像素填充）。令牌颜色使用红(2)、蓝(1)、绿(3)等。对端端点处为空（3x3 区域全黑）。生成约束：每条线路长度至少 5 像素；3x3 令牌区域不与其他线路重叠；每条线路弯折次数为 0-5 次。

**规则**：
1. 识别每条灰色线路及其两个端点。对于有令牌的线路，确定源端（有令牌的一端）和目标端（空的一端）。
2. 统计每条线路中的直角弯折次数 B（即路径方向从水平变为垂直或从垂直变为水平的次数）。
3. 定义形状循环：实心 → X 形 → 菱形 → 实心（循环长度 3）。
4. 对于每个源令牌，确定其形状在循环中的位置 S（实心=0，X=1，菱形=2）。目标端的形状 = 循环位置 (S + B) mod 3 对应的形状。
5. 在目标端的 3x3 区域中，用源令牌的颜色绘制变换后的形状。源令牌保持不变。
6. 无令牌的线路（两端均空）不产生任何变化。

**关键洞察**：线路的几何属性（弯折次数）编码了形状变换的程度——直线传输保持原形状，每增加一个弯折就在循环中前进一步。求解者必须同时关注线路拓扑（配对端点）和线路几何（数弯折），两者共同决定输出。

## 新题 6：骨架格子中标记计数驱动填充模式与重叠优先级

**组合逻辑**：[expand_fill](在骨架格子上扩展标记色到边界矩形) + [counting](计数每种标记色的数量) → [recolor](计数结果双重作用：决定填充模式 + 决定重叠优先级)

**来源原语**：expand_fill / scaffold_lattice / hollow_cell_frame / marker_lattice_align / marker_span_extent（来自 97239e3d）；counting（来自 d5c634a2）；recolor / area_determines_color（来自 d2abd087）；conflict_priority（来自 1b8318e3）

**依赖链**：识别骨架格子和各色标记 → 对每种颜色计数标记数量 N → N 同时控制两件事：(a) 填充模式（N<=2 只画边界轮廓 vs N>=3 画边界且填满内部框心）；(b) 重叠区域的优先级（N 更大的颜色覆盖 N 更小的颜色）

在骨架格子中，每种标记色的数量决定了其扩展矩形是仅画轮廓还是全部填充，并且同一个计数还充当重叠冲突时的优先级。

**输入结构**：约 18x18 网格，黑(0)背景。灰(5)像素构成一个规则的骨架格子：由若干空心 3x3 小框排列成行列阵列，小框之间共享 1 像素宽的灰色边界行和边界列。每个小框的中心像素为黑(0)。2-3 种颜色的标记像素（使用红(2)、蓝(1)、绿(3)中的若干种）各自出现在 1-4 个小框的中心位置（替换该中心的黑色）。不同颜色的标记数量互不相同。生成约束：同一中心不会同时有两种颜色标记；每种颜色的标记至少 1 个；不同颜色的标记数量两两不等；至少两种颜色的扩展矩形在边界上有重叠。

**规则**：
1. 从灰色像素推断骨架格子结构：识别所有灰色边界行和边界列，它们将网格划分为若干 3x3 小框单元。
2. 对每种标记颜色 C，找到所有包含 C 色标记的小框单元，确定这些单元在格子中的行列坐标范围，得到最小外接矩形（以格子单元坐标表示）。
3. 统计 C 色标记的数量 N_C。
4. 若 N_C <= 2（轮廓模式）：将该外接矩形边界上经过的所有灰色边界段（边界行/列中属于矩形周长的部分）涂为 C 色。矩形内部小框的中心像素不做处理。
5. 若 N_C >= 3（填充模式）：除了涂边界段外，还将矩形内部所有小框的中心像素涂为 C 色（包括原本无标记的小框中心）。
6. 当两种颜色的矩形边界段或中心像素重叠时，N 值更大的颜色覆盖 N 值更小的颜色。若 N 值相同（生成约束保证不会出现），以格子中标记位置扫描序（从左上到右下逐行扫描）更靠前的颜色优先。
7. 未被任何颜色矩形覆盖的灰色边界段和黑色中心保持原色不变。

**关键洞察**：计数 N 不是简单的统计量——它同时充当两个决策的输入：填充模式（外观截然不同）和重叠优先级（决定谁覆盖谁）。删掉计数环节，两个决策都无法确定。仅看一个示例无法区分 N=2（轮廓）和 N=3（填充）的阈值，必须对比多个示例。

## 新题 7：最近锚点分配 + L 形路径运动轨迹

**组合逻辑**：[snap / nearest_frame_assign](将孤立像素分配到最近锚块) + [draw_line / L_path_connection](绘制 L 形路径显示运动轨迹) + [erase](清除原始像素位置) — 分配决定目的地，路径可视化运动过程

**来源原语**：snap / singleton_pixel / anchor_block / outer_frame / nearest_distance / nearest_frame_assign（来自 1b8318e3）；draw_line / manhattan_path / L_path_connection（来自 a2fd1cf0）；erase（来自 a78176bb）；conflict_priority（来自 1b8318e3）

**依赖链**：计算每个孤立像素到每个锚块的距离 → 最近距离决定分配关系 → 根据分配关系确定目的地（锚块外框上最近的单元格） → 从原始位置到目的地绘制 L 形路径 → 路径交叉时，总路径更长的覆盖更短的

每个彩色孤立像素沿 L 形路径"移动"到最近的灰色锚块外框上，路径用该像素的颜色绘制；交叉路径按长度决定覆盖优先级。

**输入结构**：约 13x13 网格，黑(0)背景。2-3 个灰(5) 2x2 锚块，位置互相远离（锚块间至少隔 4 像素）。4-6 个彩色孤立单像素，每个颜色不同（使用红(2)、蓝(1)、绿(3)、黄(4)、品红(6)、橙(7)中的若干种）。生成约束：每个孤立像素有唯一的最近锚块（不存在等距情况）；每个锚块被分配到至少 1 个孤立像素；每个孤立像素与其最近锚块不在同一行且不在同一列（保证 L 形路径有拐弯）；至少存在一对路径在某像素位置交叉。

**规则**：
1. 对每个彩色孤立像素 P，计算它到每个锚块最近像素的切比雪夫距离（国王移动距离），将 P 分配到距离最小的锚块 A。
2. P 的目的地是锚块 A 的 1 像素宽外框（环绕 2x2 锚块的 12 个相邻单元格，含对角相邻）上，与 P 切比雪夫距离最小的单元格。若有多个等距外框单元格，选行号更小的；行号也相同则选列号更小的。
3. 从 P 的原始位置到目的地绘制 L 形路径：先沿水平方向移动（列号逐步趋近目的地列号），到达目的地所在列后，再沿垂直方向移动（行号逐步趋近目的地行号），直到到达目的地。路径包含起点和终点，所有路径像素涂为 P 的颜色。
4. 路径绘制顺序：按路径总长度（路径覆盖的像素数）从短到长依次绘制。后绘制的路径覆盖先绘制的路径（即更长的路径覆盖更短的）。
5. 灰色锚块像素保持不变。孤立像素的原始位置已被路径起点覆盖（颜色相同，无视觉变化）。

**关键洞察**：最近锚块分配决定了每个像素"去哪里"，L 形路径让这个运动过程可见。路径的覆盖优先级与路径长度挂钩——更长的路径（来自更远的像素）覆盖更短的路径，这一规则需要对比存在交叉的示例才能归纳。

## 新题 8：面积筛选的引导体射线延伸

**组合逻辑**：[connected_component_detection + counting](检测灰色对象并测量面积) → [ray_cast](仅通过大面积对象的远端尖端投射平行对角线) + [erase](清除所有灰色对象)

**来源原语**：ray_cast / diagonal_segment / parallel_offset / guide_tip_seeds_parallel_diagonal（来自 a78176bb）；connected_component_detection / area_classification / area_threshold_filter（来自 12eac192, d2abd087）；erase（来自 a78176bb）；counting（来自 d5c634a2）

**依赖链**：检测灰色连通分量 → 按面积分为引导体（大）和噪声（小） → 仅引导体的远端尖端作为新对角线的种子点 → 射线延伸在种子点处生成与原对角线平行的新对角线 → 所有灰色对象被擦除

一条红色对角线旁散布着大小不等的灰色对象；大对象是构造引导体，其远端尖端生成平行对角线；小对象是噪声，被忽略并擦除。

**输入结构**：约 14x14 网格，黑(0)背景。一条红(2)对角线段（从网格某角或边缘区域延伸，方向为左上-右下或左下-右上，长度至少 5 像素）。3-6 个灰(5) 4-连通对象散布在网格中，部分紧邻红色对角线，部分远离。灰色对象面积各异：小对象 1-2 像素，大对象 4-8 像素（大对象形态类似三角形或楔形，有一个可辨识的尖端像素——即距离原始红色对角线最远的像素）。生成约束：面积 3 的灰色对象不出现（确保大小分类无歧义）；每个大对象有唯一的距原对角线最远像素（以曼哈顿距离度量）；大对象至少 2 个。

**规则**：
1. 检测所有灰(5) 4-连通分量，计算每个分量的面积（像素数）。
2. 面积 <= 2 的分量标记为"噪声"。面积 >= 4 的分量标记为"引导体"。
3. 对每个引导体：计算其所有像素到原始红色对角线的最短曼哈顿距离，找到距离最大的像素作为"尖端"（若多个像素距离相同且最大，选行号最小的；行号也相同选列号最小的）。
4. 确定原始红色对角线的方向（左上-右下即 +row+col，或左下-右上即 -row+col）。
5. 通过每个尖端像素，沿与原对角线相同的方向绘制红(2)对角线，向两个方向延伸直到到达网格边界。
6. 擦除所有灰(5)像素（变为黑(0)），无论是噪声还是引导体。
7. 原始红色对角线保持不变；新生成的对角线若与原对角线重叠，颜色相同无视觉差异。

**关键洞察**：面积分类将同色对象分配到不同角色——引导体提供构造信息（尖端位置），噪声被忽略。若不做面积分类，噪声像素也会生成错误的对角线。面积阈值需要对比多个示例归纳（有些示例中小对象靠近对角线但不应生成新线）。

## 新题 9：滑动变形后投影中心并按面积解决冲突

**组合逻辑**：[slide](对象像素按东南支撑规则右移变形) → [projection](将变形后对象的包围盒中心列投影到底行) + [counting](面积计数用于解决投影冲突) — 滑动改变几何形状，从而改变中心列位置

小对象按东南支撑规则滑动变形后，每个对象的水平中心列被投影到底行标记；若两个投影重叠，面积更大的对象占据该位置。

**输入结构**：约 12x10 网格，黑(0)背景。3-5 个小型 4-连通单色对象（每个 3-7 像素），颜色各不相同（使用红(2)、蓝(1)、绿(3)、黄(4)等），分布在网格的上半部分（第 0-6 行）。每个对象的形状不对称，部分像素在其东南方向有同对象的其他像素（"有东南支撑"），部分像素没有（"无东南支撑"即东南轮廓）。底行（最后一行）全部为黑色。生成约束：对象之间互不接触（至少隔 1 像素）；滑动后对象不会超出网格右边界；滑动后各对象不会重叠；至少两个对象滑动后的包围盒中心列相同（制造投影冲突）。

**规则**：
1. 对每个对象独立执行滑动操作：遍历该对象的每个像素，若该像素在同对象中存在另一个像素位于其严格右下方（行号更大且列号更大），则将该像素向右移动 1 列。同一对象内所有符合条件的像素同时移动（使用移动前的位置判断条件）。此操作仅执行一轮（不迭代）。
2. 滑动完成后，计算每个对象新位置的包围盒，取包围盒的水平中心列（左列+右列整除 2，向下取整）。
3. 在网格底行，于每个对象的中心列位置绘制一个该对象颜色的像素。
4. 若两个对象的中心列相同（投影冲突）：像素数更多的对象占据该底行位置；像素数更少的对象的投影向右偏移 1 列。若像素数也相同，包围盒左上角行号更小（更靠上）的对象优先占据原位，另一个偏移。
5. 上半部分的对象保持滑动后的状态显示在输出中（不擦除）。

**关键洞察**：滑动改变了每个对象的几何形状和包围盒范围，因此改变了其中心列——投影结果是滑动后的产物，而非原始位置的直接映射。中心列冲突的解决依赖于面积（像素数），这是第三层逻辑。三者紧密耦合：滑动决定新形状 → 新形状决定中心列 → 面积解决中心列冲突。

## 新题 10：周期壁纸修复重建拓扑边界后标记色洪泛填充

**组合逻辑**：[completion + tiling](从残存前景推断周期并修复壁纸) → [connected_component_detection](修复后的壁纸形成新的拓扑分隔) → [fill](以标记像素的颜色洪泛填充其所在封闭房间)

**来源原语**：completion / periodic_tile / residue_infers_period / periodic_repeat（来自 ea959feb）；connected_component_detection / edge_reachability（来自 84db8fc4）；fill（来自 dbff022c）；marker_pixel（来自 97239e3d）

**依赖链**：残缺壁纸 → 推断周期并修复所有缺损像素 → 修复后的壁纸构成灰色障碍网络 → 障碍网络将黑色背景分隔为若干封闭"房间" → 房间中若有彩色标记则用标记色洪泛填充该房间

先修复残缺的灰色周期壁纸以重建房间墙壁，再用各房间内预置的彩色标记像素洪泛填充该房间。

**输入结构**：约 14x14 网格。灰(5)像素构成一个周期性的网格状壁纸图案（例如每隔 3-4 行有一条灰色横线、每隔 3-4 列有一条灰色竖线，形成规则的"房间"格局），但部分灰色像素被擦除为黑(0)（即壁纸有缺损，某些墙壁断裂）。黑(0)像素构成背景和房间内部。若干彩色单像素标记（使用红(2)、蓝(1)、绿(3)、黄(4)中的若干种）分别位于不同的"房间"区域内（每个被标记的房间恰好一个标记）。生成约束：残存的灰色像素足以唯一确定行周期和列周期；缺损位置仅出现在灰色壁纸应有的位置（不会有多余的黑色像素）；修复壁纸后，每个含标记的房间是完全封闭的（灰色像素完全包围）；至少一个房间不含标记（保持黑色）；标记像素不在灰色壁纸像素的位置上。

**规则**：
1. 忽略彩色标记像素和黑色像素，仅从残存的灰(5)像素推断壁纸的行周期 Pr 和列周期 Pc（即找到使得每个 (row mod Pr, col mod Pc) 残差类中，所有可见灰色像素一致的最小周期）。
2. 对每个应为灰色的残差类（即该残差类中存在至少一个灰色像素），将该残差类中所有非灰色、非标记的像素（即被擦除为黑色的像素）修复为灰(5)。标记像素位置不受影响。
3. 修复完成后，将黑(0)像素（不含标记像素）按 4-连通性分为若干连通区域。灰色像素视为障碍。
4. 对每个黑色连通区域：若该区域内包含一个彩色标记像素，则将该区域内所有黑色像素（不含标记本身）填充为标记的颜色，并保留标记像素本身。若区域内无标记，则保持黑色不变。
5. 灰色壁纸像素（包括修复后的）在输出中保持灰色。

**关键洞察**：在壁纸修复之前，缺损的墙壁使相邻房间连通为一个大区域——如果直接洪泛填充，标记的颜色会泄漏到相邻房间。只有先修复壁纸（重建所有墙壁），房间之间的拓扑隔离才能恢复，洪泛填充才能正确限定在单个房间内。修复步骤是填充步骤的必要前提。
