## 新题 1：遮挡物尺寸决定射线方向

**组合逻辑**：[擦除](保留) + [射线延伸](创新：方向由遮挡物几何属性决定) + [尺寸匹配](创新：从匹配对象属性变为编码方向信息)

**来源原语**：擦除/erase(3345333e)、射线延伸/ray_extend(ec883f72)、填充矩形/filled_rectangle(3345333e)、尺寸匹配/size_matching(e76a88a6)、角对角对齐/corner_diagonal_align(ec883f72)

**依赖链**：必须先擦除遮挡物才能看到被遮挡对象的完整角点；遮挡物的宽高比决定从哪些角点发射对角射线（非擦除→无角点，非遮挡物几何→无方向选择）

从每个前景对象上擦除矩形遮挡物后，根据遮挡物的宽高关系选择对象的特定角点，从这些角点向外发射对角射线。

**输入结构**：约 18x18 的黑(0)背景网格。网格中有 2~3 个单色 4-连通前景对象（颜色各不相同，从蓝(1)、绿(3)、品红(6)中选取），每个对象占 8~15 像素，形状不规则但有明确的边界框四角。每个前景对象上叠有一个灰(5)实心矩形遮挡物，遮挡物完全位于对象边界框内部，遮住对象的部分像素。遮挡物要么宽>高（横向），要么高>宽（纵向），不出现正方形遮挡物。不同对象上的遮挡物宽高关系可以不同。生成约束：遮挡物不能完全覆盖对象的任何一个边界框角点区域（即四角的 2x2 子区域至少有一个对象像素可见）。

**规则**：
1. 找到所有灰(5)实心矩形连通分量，将其像素设为黑(0)，露出被遮挡的前景对象像素。
2. 对每个前景对象，计算其边界框的四个角点坐标（左上、右上、左下、右下）。
3. 检查该对象上原先遮挡物的形状：若遮挡物宽>高，选择对象边界框的左上角和右上角；若遮挡物高>宽，选择左上角和左下角。
4. 从每个被选中的角点出发，沿远离边界框中心的对角方向（左上角→左上方，右上角→右上方，左下角→左下方，右下角→右下方），逐像素绘制该前景对象颜色的射线，直到到达网格边界。射线覆盖路径上的所有像素（包括黑(0)背景），但不覆盖其他前景对象的已有像素。
5. 多条射线交叉时，后处理的对象（按边界框左上角行优先、列次优先排序，靠前的先处理）的射线覆盖先处理对象的射线。

**关键洞察**：遮挡物不仅是需要移除的噪声，其宽高比编码了射线的发射方向——横向遮挡物激活水平方向的两个角，纵向遮挡物激活垂直方向的两个角。必须对比多个示例才能归纳出宽高比与角点选择的映射关系。

## 新题 2：格子多数色压缩生成印章模板

**组合逻辑**：[压缩 + 多数决](保留) → [印章覆盖](创新：模板来自压缩结果而非固定前景对象) + [尺寸匹配](保留)

**来源原语**：压缩/compress(af24b4cc)、多数决/majority_vote(af24b4cc)、格子格局/lattice_layout(af24b4cc)、印章覆盖/stamp_overlay(e76a88a6)、纯色矩形/solid_rectangle(e76a88a6)、尺寸匹配/size_matching(e76a88a6)

**依赖链**：印章模板的内容由格子压缩动态生成，不是输入中直接可见的图案；目标矩形的尺寸必须与压缩结果的尺寸匹配才能接受印章（压缩不执行→无模板→无法印章；格子结构错误→压缩结果错误→印章内容错误）

将格子区域的每个色块压缩为多数色得到一个小型多色模板，然后将该模板印入网格中与之同尺寸的灰色目标矩形。

**输入结构**：约 20x20 的黑(0)背景网格。网格左半区有一个由橙(7)分隔线划分的矩形格子区域，分隔线宽 1 像素，将内部分为 3x3 共 9 个等大色块（每块约 3x3 像素）。每个色块内有一种主色和少量干扰色像素（主色占色块像素的严格多数）。主色从蓝(1)、红(2)、绿(3)、黄(4)、品红(6)中选取。网格右半区散布 2~4 个灰(5)实心矩形，其中恰好一个的尺寸为 3x3（与压缩后的格子摘要尺寸相同），其余灰矩形尺寸各异但都不是 3x3。生成约束：格子区域和所有灰矩形互不重叠且不相邻。

**规则**：
1. 识别橙(7)分隔线围成的格子区域，找到 3x3 的色块布局。
2. 对每个色块，统计其中出现次数最多的颜色作为该块的代表色（生成时保证每块多数色唯一）。
3. 将 9 个代表色按格子位置组成一个 3x3 的多色模板。
4. 在网格右半区找到尺寸恰好为 3x3 的灰(5)矩形。
5. 将多色模板逐像素覆盖到该灰矩形的位置上，替换灰色。
6. 其余灰矩形和格子区域保持原样不变。

**关键洞察**：印章模板不是输入中可以直接读取的图案，而是必须通过对格子色块执行多数决压缩后才能得到的中间产物。需要对比多个示例才能确认"干扰色像素存在但不影响代表色"以及"只有尺寸匹配的灰矩形才被替换"。

## 新题 3：对称轴借用后沿轴行独立反转

**组合逻辑**：[对称轴借用](创新：轴不用于复制像素，而用于划定反转区域) + [反转](创新：从全行独立变为仅在轴界定的半区内反转) + [擦除](保留)

**来源原语**：对称轴借用/axis_borrowed(4c5c2cf0)、对称体/symmetric_object(4c5c2cf0)、反转/invert(2de01db2)、逐行独立/row_independent(2de01db2)、主色与背景互换/native_bg_swap(2de01db2)、擦除/erase(52364a65)

**依赖链**：对称体确定垂直对称轴的列位置→该轴将网格分为左右两半区→仅对轴右侧半区逐行执行前景/背景反转→对称体本身被擦除（不识别对称体→不知道轴在哪里→不知道反转哪半区）

找到具有垂直对称轴的标记对象，用其对称轴将网格分为两半，擦除标记对象后，仅对右半区逐行执行前景色与背景色互换。

**输入结构**：约 15x15 的黑(0)背景网格。网格中有一个红(2)的小型对象（4~8 像素），具有明确的垂直镜像对称轴（该轴落在某一列或两列之间；生成时保证落在某一整数列上）。另有若干蓝(1)像素散布在网格各处（对称体左右两侧都有），这些蓝像素构成需要被反转的前景内容。蓝像素不与红对象重叠。生成约束：红对象的对称轴不在网格最左列或最右列；蓝像素在对称轴左右两侧的每一行都至少出现一个。

**规则**：
1. 找到红(2)连通对象，检测其垂直镜像对称轴所在的列 C。
2. 将红(2)对象的所有像素擦除为黑(0)。
3. 对网格中列索引 > C 的区域（右半区），逐行执行反转：该行右半区中蓝(1)像素变为黑(0)，黑(0)像素变为蓝(1)。
4. 列索引 <= C 的区域（左半区及对称轴列）保持不变（蓝像素留存，黑背景留存）。

**关键洞察**：对称体的作用不是提供反射复制的种子（与参考题 4c5c2cf0 不同），而是提供一条几何分界线——其对称轴划定了反转操作的作用域。必须对比多个示例才能发现"只有右半区被反转"这一非对称规则。

## 新题 4：形状匹配选择性恢复被遮挡周期图案

**组合逻辑**：[形状匹配](创新：匹配目标不是前景对象而是遮挡物的形状) + [补全](创新：仅对匹配的遮挡物区域恢复周期图案) + [周期平铺图案](保留)

**来源原语**：形状匹配/shape_match(63613498)、掩码相同/mask_equality(63613498)、框架/frame(63613498)、补全/complete(abbfd121)、周期平铺图案/periodic_tile(abbfd121)、矩形遮挡物/rect_occluder(abbfd121)

**依赖链**：框架内的模板定义目标形状→在多个遮挡物中找到形状匹配者→仅对匹配的遮挡物执行周期图案恢复（无形状匹配→无法确定恢复哪个遮挡物；无周期推断→无法计算恢复内容）

网格覆盖着周期背景图案，多个单色矩形遮挡了该图案。灰色 L 框标记了一个模板形状，只有与模板同形的遮挡物才被恢复为周期图案，其余遮挡物保留。

**输入结构**：约 18x18 的网格，整体由一个 2x2 或 3x3 的小瓦片行列周期铺满（瓦片使用蓝(1)和绿(3)两种颜色）。网格上有 3~4 个单色实心矩形遮挡物，颜色各不相同，从红(2)、黄(4)、品红(6)、橙(7)中选取，每个遮挡物的边界框尺寸互不相同（如 2x3、3x4、4x2、3x3 等）。网格某角落有一个灰(5)L 形框架（竖腿在右、横腿在底），框架内左上方区域包含一个栗(9)色的小型连通对象（3~6 像素），该对象的归一化掩码恰好与某一个遮挡物的归一化掩码（即边界框内的占据形状）相同。生成约束：恰好只有一个遮挡物的归一化掩码与模板匹配；所有遮挡物都是实心矩形（所以归一化掩码就是其边界框尺寸）；模板形状也是矩形，因此匹配条件退化为边界框尺寸相同。

**规则**：
1. 识别灰(5)L 形框架，提取框架内左上区域中栗(9)对象的边界框尺寸（高 x 宽）。
2. 在所有单色实心矩形遮挡物中，找到边界框尺寸与模板相同的那一个。
3. 从遮挡物之外的可见像素推断出最小行列周期瓦片。
4. 用推断出的周期瓦片重绘匹配遮挡物所在区域，恢复被遮挡的图案。
5. 其余遮挡物、L 形框架和模板对象保持原样不变。

**关键洞察**：并非所有被遮挡区域都要恢复——L 框内的模板是一个形状选择器，只有尺寸与模板匹配的遮挡物才会被"治愈"。需要对比多个示例才能确认未匹配的遮挡物始终被保留。

## 新题 5：标记像素的行位置编码缩放倍率用于放大瓦片

**组合逻辑**：[像素放大](创新：放大倍率不固定，由标记位置动态编码) + [互补掩码](保留) + [尺寸比编码缩放](创新：从锚点方块间比值变为标记行位置编码) + [前景位置放置瓦片](保留)

**来源原语**：像素放大/pixel_scaling(0692e18c)、互补掩码/complement_mask(0692e18c)、前景位置放置瓦片/tile_at_foreground_positions(0692e18c)、自身互补/self_complementary(0692e18c)、尺寸比编码缩放/size_ratio_encodes_scale(b10624e5)、标记像素/marker_pixel(a85d4709)

**依赖链**：标记像素的行位置决定缩放倍率→缩放倍率决定互补瓦片的尺寸→前景像素位置决定瓦片放置坐标（标记行位置不同→倍率不同→输出网格尺寸不同→瓦片放置完全不同）

一个小型图案的互补掩码作为瓦片印在前景位置，但瓦片的缩放倍率由网格边缘的标记像素的行位置编码。

**输入结构**：约 8x8 的黑(0)背景网格。网格内有一个 3x3 的子区域位于左上角（行 0~2，列 0~2），其中部分像素为蓝(1)（前景），其余为黑(0)（背景）。网格最右列（列 7）上恰好有一个红(2)标记像素，位于第 r 行（r 从 0 开始计数）。网格其余区域全为黑(0)。生成约束：r 的值为 1、2 或 3（编码缩放倍率）；3x3 子区域中前景像素至少 2 个、至多 7 个。

**规则**：
1. 读取最右列上红(2)标记像素的行号 r，缩放倍率 S = r + 1（即行 0→S=1，行 1→S=2，行 2→S=3，行 3→S=4）。
2. 提取左上角 3x3 子区域的前景掩码 M（蓝=1，黑=0），计算其互补掩码 M'（黑→1，蓝→0）。
3. 输出网格尺寸为 (3*S) x (3*S)。
4. 对 3x3 中的每个像素位置 (i,j)：若 M[i][j]=1（前景），则在输出的第 (i*S)~(i*S+S-1) 行、第 (j*S)~(j*S+S-1) 列的 SxS 子块中，按 M' 的图案放置蓝(1)像素（M'中为 1 的位置涂蓝(1)，为 0 的位置涂黑(0)；当 S > 3 时，将 M' 等比缩放到 SxS 后再放置，缩放方式为最近邻插值）；若 M[i][j]=0（背景），则该 SxS 子块全为黑(0)。
5. 红(2)标记像素不出现在输出中。

**关键洞察**：输出网格的尺寸和每个子块内的图案都由标记像素的行号间接控制——行号编码了缩放倍率，而非直接编码颜色或方向。必须对比多个示例（不同行号的标记）才能归纳出行号到倍率的映射。

## 新题 6：边缘竖条配对的行偏移驱动对角楔形填充

**组合逻辑**：[射线延伸](创新：从水平射线变为对角楔形传播) + [对称配对](保留) + [标记偏移映射对侧](保留) + [沿对角线传播 + 收缩楔形](创新：楔形起点由标记行偏移决定)

**来源原语**：射线延伸/ray_cast(673ef223)、边缘竖条/edge_bar(673ef223)、对称配对/symmetric_pair(673ef223)、标记偏移映射对侧/marker_maps_opposite(673ef223)、沿对角线传播/diagonal_propagate(b5bb5719)、收缩楔形/shrinking_wedge(b5bb5719)、逐行交换双色/row_swap_bicolor(b5bb5719)

**依赖链**：标记像素在源竖条上的行偏移→映射到对侧竖条的对应行→从对应行出发向网格内部生长对角楔形→楔形逐行收缩并交替双色（无偏移映射→不知道楔形起点行；无收缩规则→不知道楔形形态）

标记像素选择源竖条上的行，映射到对侧竖条的同偏移行，从该行出发向内绘制一个逐行收缩、颜色交替的对角楔形。

**输入结构**：约 15x20 的黑(0)背景网格。左右边缘各有一条红(2)实心竖条，高度相同（约 8~12 像素），顶部对齐。1~2 个绿(3)标记像素位于左侧竖条的同列但在竖条行范围内（每个标记独占一行）。生成约束：标记像素的行偏移（相对于竖条顶部）在右侧竖条中也有对应行；楔形生长不超出网格边界；多个楔形互不重叠。

**规则**：
1. 识别左右两条红(2)竖条，确认它们高度相同且顶部行对齐。
2. 对每个绿(3)标记像素，计算其在左侧竖条中的行偏移 d（从竖条顶行开始计数，顶行 d=0）。
3. 将标记像素重涂为黄(4)。
4. 在右侧竖条中找到偏移 d 对应的行 R。从该行出发，向左（朝网格内部）绘制楔形：
   - 第 0 层（行 R 本身）：从右侧竖条左邻列开始，向左绘制宽度 W 的一行像素（W = 竖条高度 - 2*d，若 W<=0 则该标记不产生楔形）。颜色为绿(3)。
   - 第 k 层（行 R-k 和行 R+k，k>=1）：宽度缩减为 W - 2*k（当宽度 <=0 时停止），起始列不变（紧邻竖条左侧），颜色在绿(3)和黄(4)之间按 k 的奇偶交替（k 奇数→黄(4)，k 偶数→绿(3)）。
5. 楔形像素不覆盖红(2)竖条像素。多个楔形重叠时，行偏移 d 较小的楔形优先（其像素不被覆盖）。

**关键洞察**：楔形的宽度由标记在竖条上的相对位置决定——越靠近竖条中部的标记产生越宽的楔形，越靠近端部的标记产生越窄的楔形。偏移量同时编码了楔形的位置和尺寸。

**关键洞察**：单个标记像素通过其二维坐标同时编码了两个独立参数——水平偏移编码擦除量，垂直位置编码对称轴类型。这两个参数协同作用于同一个对象的变换，必须全部正确解读才能得到正确输出。

**依赖链**：框内像素的多数色决定射线颜色→实心矩形角点射线经过框角才激活→射线用多数色绘制（多数色错→射线颜色错；框角对齐判断错→射线激活状态错）

网格中有一个空心框和一个实心矩形。框内部散布着多色像素，取多数色。从实心矩形角点发射对角射线，只有经过框角点的射线才被激活，且射线颜色为框内多数色。

**输入结构**：约 16x16 的黑(0)背景网格。一个灰(5)单像素厚空心矩形框（约 6x6 到 8x8）位于网格中部。框内部（被框围住的区域）散布着若干彩色像素（从蓝(1)、红(2)、绿(3)中选取 2~3 种颜色，共 5~10 个像素），其中一种颜色的像素数严格最多（多数色）。一个橙(7)实心矩形（2x2 或 3x3）位于框外部，其某些角点的对角延长线恰好经过灰框的角点像素。生成约束：实心矩形的至少一个角点对角线经过灰框的某个角点；实心矩形不与灰框重叠；灰框的四个角点像素属于框本体。

**规则**：
1. 识别灰(5)空心矩形框，找到其四个角点坐标。
2. 统计框内（不含框本体像素）所有非黑像素的颜色，确定出现次数严格最多的颜色 C（生成时保证唯一多数）。
3. 将框内所有非黑像素擦除为黑(0)，然后将框内整个区域填充为颜色 C。
4. 识别橙(7)实心矩形，找到其四个外角点。
5. 从每个外角点出发沿远离矩形中心的对角方向追踪射线：若射线上遇到的第一个非黑非橙像素是灰(5)框的某个角点，则该射线被激活——继续沿同方向绘制颜色 C 的像素直到网格边界（穿过框角点后的所有背景像素都涂为 C，但不覆盖灰框和橙矩形）。
6. 若射线上先遇到的是非角点像素或直接到达网格边界，则该射线不激活。

**关键洞察**：框不仅是射线的门控条件（角点对齐才激活），其内部像素还通过多数决动态确定射线和填充的颜色——框同时充当空间过滤器和颜色信息源。
