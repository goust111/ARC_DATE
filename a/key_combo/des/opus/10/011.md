## 新题 1：孔洞拓扑选配拼合

**组合逻辑**：[计数·孔洞拓扑](创新：对精灵体自身的孔洞计数作为选配键) → [拼合填充](创新：由拓扑匹配而非几何匹配决定哪个精灵填入哪个腔体)

**来源原语**：计数(counting) ← e3721c99/df8cc377；拼合填充(tiling_fill) ← 184a9768；封闭孔洞(enclosed_hole) ← 184a9768；精灵体(sprite) ← e3721c99/184a9768；孔洞数映射颜色(hole_count_to_color_mapping) ← e3721c99

**依赖链**：必须先对每个精灵体计算其自身的封闭孔洞数，才能确定它应该被平移到哪个大型对象的腔体中；而拼合填充的几何可行性又反过来验证了配对的唯一性——拓扑匹配确定候选对，几何拼合确定唯一放置方案。

将大型对象腔体中的精灵体按自身孔洞数与腔体的孔洞计数配对，再将配对的精灵体无旋转地精确拼合进对应腔体。

**输入结构**：黑(0)背景，约 20x20 网格。网格中有 2~3 个大型单色前景对象（各用不同颜色，如蓝(1)、绿(3)），每个大型对象内部有一个由背景色构成的封闭腔体（形状不规则，面积约 4~10 像素）。网格中另有 2~3 个小型多色精灵体（4-连通，3~8 像素，颜色与大型对象不同，如红(2)、黄(4)），分散在大型对象外部，互不相邻。每个精灵体自身也可能包含 0、1 或 2 个封闭的背景孔洞（精灵体边界框内、被精灵体像素完全 4-连通包围的背景连通域）。每个大型对象的腔体中恰好也包含 0、1 或 2 个由该对象颜色构成的内部柱（将腔体分隔成若干子区域，子区域数即为腔体的"孔洞计数"替代量——此处定义腔体的"拓扑指标"为腔体内背景连通域的个数）。生成约束：每个精灵体的孔洞数与恰好一个腔体的拓扑指标相等，且配对后精灵体的前景像素形状恰好能无旋转地精确覆盖腔体内的所有背景像素。

**规则**：
1. 识别大型前景对象（像素数 > 15 的非背景 4-连通分量）及其内部封闭腔体（对象边界框内、被对象像素 4-连通包围的背景连通域）。
2. 计算每个腔体的拓扑指标：腔体内部背景连通域的个数（若腔体内有对象颜色的内部柱将背景分隔为多块，则计数为分隔后的块数）。
3. 识别小型精灵体（像素数 <= 15 的非背景 4-连通分量，不与任何大型对象相邻）。
4. 计算每个精灵体的封闭孔洞数：精灵体边界框内、被精灵体前景像素完全包围（4-连通意义下不与边界框外部背景连通）的背景连通域个数。
5. 将精灵体与腔体按孔洞数/拓扑指标一一配对（值相等者配对，保证唯一）。
6. 对每对配对：将精灵体的前景像素平移（不旋转、不变色）到对应腔体位置，使精灵体前景恰好覆盖腔体中所有背景像素。平移偏移量唯一。
7. 清除精灵体原始位置的所有像素（恢复为背景色）。保留大型对象和腔体内的内部柱不变。

**关键洞察**：选配不是靠颜色或位置，而是靠精灵体自身的拓扑属性（孔洞数）与腔体的拓扑属性匹配——这是源题中不存在的结构关系：184a9768 中拼合靠几何形状匹配，e3721c99 中孔洞数映射到颜色，而这里孔洞数成为连接拓扑选配与几何拼合的桥梁。

## 新题 2：对角射线穿透分裂矩形

**组合逻辑**：[射线延伸·对角方向](已有原语) + [分裂·垂直于射线](创新：障碍不阻挡射线而是被射线劈开) + [轨迹涂色](创新：分裂缝隙着色标记射线路径)

**来源原语**：射线延伸(ray_cast) ← 7ddcd7ec；对角标记(diag_marker) ← 7ddcd7ec；实心正方形(solid_square) ← 7ddcd7ec；分裂(split) ← 9f669b64；穿越并分开(pass_through_split) ← 9f669b64；锚角对角射线至边(anchor_diag_to_edge) ← 7ddcd7ec；轨迹涂黑(trail_painted_black) ← 8b9c3697

**依赖链**：对角射线的方向决定了遇到矩形障碍时的分裂轴（垂直于射线前进方向分裂）；分裂产生的缝隙又成为射线继续前进的通道，缝隙被涂上射线颜色；射线是否到达网格边界取决于路径上有多少障碍及其分裂后的间隙是否允许通过。

从锚点方块的对角标记发射对角射线，射线穿过路径上的实心矩形时将其沿射线垂直方向劈开并移位，缝隙涂上射线颜色，射线继续直至网格边缘。

**输入结构**：黑(0)背景，约 18x18 网格。网格中央有一个蓝(1)实心 2x2 正方形作为锚点。锚点的 1~2 个角上各有一个蓝(1)对角邻接像素作为射线种子（如锚点右下角的 (r+2,c+2) 位置有一个蓝像素）。沿每个射线种子指向的对角方向（远离锚点），路径上有 1~3 个灰(5)实心矩形障碍（宽或高 2~4 像素，长边垂直于射线方向），互不重叠，与射线路径有交叉。射线种子和障碍之间、障碍之间有足够背景间距（至少 2 像素）。生成约束：每个障碍的长边严格垂直于其所在射线的对角方向（即障碍沿该对角线有 1~2 像素厚度，垂直方向有 2~4 像素长度），且障碍中心落在射线路径上。

**规则**：
1. 识别蓝(1) 2x2 实心正方形（锚点）。
2. 识别锚点角上的对角邻接蓝像素（射线种子），每个种子定义一条从种子位置沿远离锚点的对角方向延伸的射线。
3. 沿每条射线逐像素前进。遇到背景(0)像素时，涂为红(2)（射线颜色）。
4. 当射线前进到灰(5)矩形障碍时：将该障碍沿射线前进方向劈开——障碍在射线穿过的对角线上裂开一像素宽的缝隙（具体地：射线经过障碍的那一列/行对角像素被移除，障碍被分为两半，两半各沿垂直于射线方向向外平移一个像素）。缝隙中的像素涂为红(2)。
5. 射线穿过缝隙后继续前进，重复步骤 3-4，直至离开网格边界。
6. 保留锚点和射线种子不变。超出网格边界的障碍半体像素被裁剪。
7. 多条射线独立处理。若两条射线都经过同一障碍（生成时避免此情况），则按射线种子在锚点上的顺时针顺序先处理先到的射线。

**关键洞察**：射线不被障碍阻挡——它把障碍劈开后继续前进，劈开的缝隙本身成为射线路径的一部分。这与源题的机制都不同：7ddcd7ec 中射线遇到的是空背景，9f669b64 中分裂由矩形滑动引起而非由射线穿透引起。

## 新题 3：面积位移后局部位置重涂色

**组合逻辑**：[计数·面积](已有原语) → [滑动·面积决定位移](已有原语) → [重涂色·局部位置分类](创新：在位移后的新位置上按角/边/内部分别着色，重叠区域由面积决定优先级)

**来源原语**：滑动(slide) ← 8e301a54；面积决定位移(area_determines_displacement) ← 8e301a54；计数(counting) ← 8e301a54；重涂色(recolor) ← b6afb2da；局部位置分类(local_position_classification) ← b6afb2da；角边内部分别涂色(corner_border_interior_recolored) ← b6afb2da；超界裁剪(clip_beyond_edge) ← 8e301a54

**依赖链**：面积计算同时服务于两个不同环节——既决定向下位移的距离，又在位移后决定重叠冲突的优先级（面积小的对象在上层）。位移改变了对象的空间分布，可能产生重叠，而重涂色必须在位移后的最终位置上执行，因为局部位置（角/边/内部）取决于矩形在新位置的几何形态（可能被裁剪）。

将灰色矩形向下滑动自身面积步数，在新位置按角/边/内部重涂三色，重叠处小面积矩形覆盖大面积矩形。

**输入结构**：黑(0)背景，约 20x25 网格（高度较大以容纳位移）。网格上半部分有 2~4 个灰(5)实心矩形，每个矩形至少 2x2，面积各不相同（如 4、6、9、12 像素），矩形之间互不重叠且不相邻。矩形在网格上半区（前 10 行内），下方有足够空间容纳位移后的结果（但部分矩形位移后可能超出网格底边）。生成约束：各矩形面积互不相等；位移后至少有两个矩形在垂直投影上有列重叠（即它们的列范围有交集），使得位移后可能产生空间重叠。

**规则**：
1. 识别所有灰(5) 4-连通矩形分量。计算每个矩形的面积（像素数）。
2. 将每个矩形向下平移，平移行数等于其面积。清除原始位置（恢复为黑(0)）。
3. 平移后超出网格底边的像素被裁剪丢弃。若整个矩形都移出网格，则该矩形消失。
4. 对每个仍然可见的矩形（含被裁剪的），在其当前可见像素上执行局部位置重涂色：将矩形的**原始完整几何形态**（未裁剪前的形状）作为参考，判断每个可见像素在原始矩形中属于角、边还是内部——四个角像素涂蓝(1)，非角的边界像素涂黄(4)，严格内部像素涂红(2)。
5. 若两个矩形位移后在某些像素位置重叠，则面积较小的矩形绘制在上层（其像素覆盖面积较大矩形的像素）。绘制顺序：按面积从大到小依次绘制，后绘制的覆盖先绘制的。
6. 背景保持黑(0)。

**关键洞察**：面积在此题中承担双重角色——既是物理运动的参数（位移距离），又是逻辑冲突的仲裁标准（重叠优先级）。这种双重依赖在源题中不存在：8e301a54 中面积只决定位移，b6afb2da 中不存在位移和重叠。仅看单个示例可能无法确定重叠时的优先级规则（需对比多个示例中不同面积矩形的重叠结果）。

## 新题 4：射线方向推断模板选择与缩放补全

**组合逻辑**：[射线方向推断](创新：方向不再用于对接，而是用于从多个模板中选择正确的一个) + [补全·缩放](创新：被选中的模板按框内尺寸缩放后填充框内) + [擦除](已有原语)

**来源原语**：射线方向推断(ray_inferred_direction) ← 8b9c3697；内部槽位(interior_socket) ← 8b9c3697；对接(dock) ← 8b9c3697；补全(complete) ← 8a6d367c；种子选择模板(seed_selects_template) ← 8a6d367c；模板(template) ← 8a6d367c；缩放(scaling) ← 8a6d367c/46f33fce；矩形框(rectangular_frame) ← 8a6d367c/df8cc377；擦除(erase) ← 184a9768

**依赖链**：必须先从矩形框的内部槽位向外发射射线、确定射线命中的是哪个模板（方向推断），才能知道用哪个模板来补全框内；而补全时的缩放因子取决于框内尺寸与模板尺寸的比值，这又需要先裁剪出模板的边界框。最后擦除框外所有模板和未命中的组件。

从矩形框的内部空缺向外射线寻找最近模板，以射线命中的模板为源，缩放后填充框内，擦除框外所有辅助元素。

**输入结构**：青(8)背景，约 18x18 网格。网格中有一个灰(5)单像素宽空心矩形框（内部尺寸为 NxM，N 和 M 在 4~8 之间）。框内有少量红(2)种子像素（1~3 个，散落在框内背景位置）。框外四个方向（上、下、左、右）中的 2~3 个方向各放置一个小型多色模板（3x3 或 4x4 边界框，由 2~3 种非背景、非灰、非红的颜色组成，如蓝(1)、绿(3)、黄(4)），每个模板的前景形状不同。其中恰好有一个模板满足：框内尺寸是该模板边界框尺寸的整数倍（即 N/模板高 和 M/模板宽 都是正整数），且该模板的前景掩码按此倍率缩放后，缩放掩码覆盖了所有红(2)种子像素的位置。生成约束：从框内任意红(2)种子像素沿某个正交方向（上/下/左/右）射线扫描，第一个命中的模板就是正确模板（所有种子像素射线命中的是同一个模板）。其他模板不满足缩放整除条件或缩放后不覆盖种子。

**规则**：
1. 识别灰(5)空心矩形框，计算其内部尺寸 NxM。
2. 识别框内的红(2)种子像素。
3. 从每个种子像素位置沿上、下、左、右四个正交方向射线扫描（在原始输入上），找到第一个非背景、非灰像素所属的模板分量。所有种子像素命中同一个模板——该模板即为目标模板。
4. 计算缩放因子：scale_r = N / 模板边界框高度，scale_c = M / 模板边界框宽度（均为正整数）。
5. 将目标模板的每个像素扩展为 scale_r x scale_c 的色块，生成缩放后的模板图像（NxM）。
6. 将缩放后的图像填入矩形框内部，替换框内所有背景和种子像素。框的灰(5)边界保持不变。
7. 擦除框外的所有模板和种子以外的前景像素（恢复为背景色）。

**关键洞察**：射线方向推断在源题 8b9c3697 中用于确定对接的滑动方向，这里被重新用于从多个候选模板中选出正确的一个——方向成为选择键而非运动参数。种子像素同时扮演两个角色：它们既是射线的发射源（选择模板），又是缩放正确性的验证约束（种子必须落在缩放掩码上）。

## 新题 5：像素膨胀后对角光晕与画布描边

**组合逻辑**：[像素放大·局部膨胀](已有原语) → [对角邻接背景着色](创新：作用于膨胀后的中间结果而非原始输入) → [描边·画布边界](创新：描边颜色由光晕颜色统一决定，形成微观-宏观视觉呼应)

**来源原语**：像素放大(pixel_expand) ← 46f33fce；孤立像素(isolated_pixel) ← 46f33fce；仅对角邻接(diagonal_only_adj) ← 396d80d7；对角邻接背景着色(diagonal_bg_color) ← 396d80d7；描边(border_draw) ← 6f8cd79b；画布边界(canvas_boundary) ← 6f8cd79b；内层前景(inner_foreground) ← 396d80d7

**依赖链**：像素膨胀改变了对象的几何形态（从 1x1 变为 2x2），从而改变了哪些背景像素与前景"仅对角邻接"——这些邻接关系在膨胀前不存在。对角光晕的颜色又被复用为画布描边的颜色，将局部效果和全局边框视觉统一。三步中任一步的输出都是下一步的必要输入。

将孤立像素膨胀为 2x2 块，在每个块的纯对角邻接背景位置绘制光晕色，最后用同一光晕色沿画布边界描一圈边框。

**输入结构**：黑(0)背景，约 12x12 网格。网格中有 3~5 个孤立的非黑单像素，颜色均相同（如蓝(1)），像素之间至少间隔 3 格（确保膨胀和光晕不重叠）。网格的某个角（如左上角 (0,0)）有一个单独的橙(7)像素作为光晕色图例——这个像素不参与膨胀，仅提供光晕和描边的颜色信息。生成约束：所有蓝像素距离网格边界至少 2 格，确保膨胀后的 2x2 块不紧贴边界；各像素之间曼哈顿距离 >= 5，确保光晕区域互不重叠。

**规则**：
1. 识别角落的颜色图例像素（位于网格四角之一的非黑非蓝像素），记其颜色为 C_halo（如橙(7)）。将该图例像素擦除（恢复为背景）。
2. 识别所有蓝(1)孤立像素（与图例颜色不同的非背景 1x1 分量）。
3. 将每个蓝像素膨胀为 2x2 蓝色块：以原像素为右下角，向上和向左各扩展一格（即原像素 (r,c) 膨胀为 {(r-1,c-1), (r-1,c), (r,c-1), (r,c)}）。
4. 在膨胀后的网格上，找出所有满足以下条件的背景(0)像素 p：p 与至少一个蓝(1)像素对角邻接（8-连通中的四个对角方向），且 p 与任何蓝(1)像素都不正交邻接（上下左右四方向）。将这些像素涂为 C_halo。
5. 最后，沿网格的第一行、最后一行、第一列、最后一列绘制宽度为 1 的边框，边框颜色为 C_halo。边框像素覆盖该位置原有的任何颜色。
6. 非边框、非光晕、非蓝色块的区域保持黑(0)背景。

**关键洞察**：对角邻接检测在源题 396d80d7 中作用于预先存在的封闭框，而这里作用于像素膨胀的中间产物——膨胀创造了新的几何体，从而生成了原始输入中不存在的对角邻接关系。光晕色同时决定画布边框色这一设计，使得图例像素的信息同时影响局部和全局两个尺度的操作。

## 新题 6：重复图案筛选后四重对称补全

**组合逻辑**：[图案匹配·出现两次者选取](创新：选取的不是完整精灵体而是部分对称碎片) + [擦除·忽略干扰项](已有原语) → [对称补全·角落补四重](创新：补全对象来自筛选结果而非直接给定)

**来源原语**：图案匹配(pattern_match) ← f5aa3634；出现两次者选取(twice_pattern_selected) ← f5aa3634；裁剪(crop) ← f5aa3634；擦除(erase) ← e3721c99；忽略干扰项(ignore_distractors) ← e3721c99；对称补全(symmetry_completion) ← 4290ef0e；角落补全四重对称(corners_to_fourfold_symmetry) ← 4290ef0e；中心对齐(center_alignment) ← 4290ef0e

**依赖链**：必须先裁剪每个碎片并比较图案才能确定哪个颜色的碎片出现了恰好两次（筛选）；筛选结果直接决定哪些碎片被保留用于对称补全，其余被擦除；对称补全时需要从保留碎片的角落位置推断完整图案的尺寸和对称轴。

从多个彩色碎片中找到裁剪图案恰好出现两次的那个颜色，擦除其余颜色碎片，将保留碎片作为角落-L 碎片补全为四重对称图案。

**输入结构**：黑(0)背景，约 15x15 网格。网格中散布 3~4 种颜色的前景碎片，每种颜色有 1~3 个 4-连通分量。每个分量是一个小型图形（3~6 像素的角落-L 形碎片，即一个方向的直角形状）。其中恰好一种颜色（如红(2)）的所有分量（恰好 2 个）裁剪到边界框后图案完全相同（含内部背景像素）；其他颜色的分量裁剪后图案各不相同或只出现一次。红(2)的两个分量分布在网格不同区域，互不重叠。生成约束：出现两次的红色碎片形状为角落-L（占据某个 NxN 正方形的一个角落区域，形成直角），N 为奇数（3 或 5），使得四重对称补全后可以生成 NxN 的完整图案。

**规则**：
1. 识别所有非背景 4-连通分量，按颜色分组。
2. 对每个分量裁剪到其最小边界框（保留框内背景像素）。
3. 在每个颜色组内，比较所有分量的裁剪图案（逐像素比较）。找到恰好有 2 个分量裁剪图案完全相同的那个颜色，记为 C_valid。
4. 擦除所有颜色不是 C_valid 的前景像素（恢复为背景）。
5. 取 C_valid 的一个分量的裁剪图案作为角落-L 碎片。确定该碎片占据 NxN 正方形的哪个角落（前景像素集中在左上/右上/左下/右下哪个象限）。
6. 将该碎片在 NxN 正方形的四个角落各放置一份（对应旋转 0/90/180/270 度），合成四重对称图案。
7. 将合成的 NxN 图案居中放置在与输入同尺寸的黑色输出网格上。

**关键洞察**：源题 f5aa3634 中重复选取的是完整精灵体并直接输出其裁剪，这里重复选取的是碎片——选取本身不是终点而是对称补全的前置条件。若跳过重复检测直接补全，无法知道该补全哪个颜色的碎片；若跳过对称补全直接输出匹配结果，得到的只是碎片而非完整图案。

## 新题 7：旋转推断后缩放模板驱动路径绘制

**组合逻辑**：[旋转·推断正确旋转角](创新：旋转角不是给定的，而是从边缘标记与模板列的对应关系推断) → [缩放·像素放大](已有原语) → [路径绘制·从标记到缩放体](创新：射线终点由缩放后的模板位置决定)

**依赖链**：必须先从底边标记的列位置推断模板需要哪个旋转角度（使旋转后模板的前景列与标记列对齐），才能确定旋转后的模板形态；旋转后的模板决定缩放体的形状和位置；缩放体的前景像素位置又决定了从底边标记向上绘制射线的终点和颜色。

从底边标记的列分布推断小模板的旋转角，将旋转后的模板缩放绘制在顶部，再从每个底边标记向上画射线至碰到缩放体的前景像素为止，射线着色为命中像素的颜色。

**输入结构**：黑(0)背景，约 16x16 网格。左上角区域有一个小型多色模板（3x3 或 4x4 边界框，由 2~3 种颜色组成，如蓝(1)、绿(3)、黄(4)，前景像素呈不规则非对称形状）。网格底边（最后一行）有 2~4 个灰(5)单像素标记，分布在不同列上。网格其余区域为背景。生成约束：模板的四种旋转（0/90/180/270 度）中，恰好有一种旋转使得旋转后模板前景像素的列集合（在模板局部坐标系中）与底边标记的列集合（经过适当平移对齐后）完全一致。缩放因子为正整数（2 或 3），使得缩放后的模板宽度不超过网格宽度。

**规则**：
1. 识别小型多色模板（左上角区域的非背景 4-连通分量群，所有颜色合在一起的边界框不超过 4x4）。
2. 识别底边灰(5)标记像素，记录其列坐标集合 S_marker。
3. 对模板尝试 0/90/180/270 度顺时针旋转。对每种旋转，计算旋转后模板前景像素的列坐标集合（相对于模板边界框左列）。找到唯一的旋转角度 R，使得存在正整数缩放因子 k 和列偏移 d，满足：旋转后模板每个前景列 c 对应的缩放列范围 [d + c*k, d + (c+1)*k - 1] 中至少有一列属于 S_marker，且 S_marker 中每个标记列都落在某个前景列的缩放范围内。
4. 将模板旋转 R 度，然后将每个像素缩放为 k x k 的色块。将缩放后的图像放置在网格顶部（顶行对齐网格第 0 行，左列对齐列 d）。
5. 从每个底边标记像素向上（行号递减方向）绘制射线：逐行扫描同一列，遇到背景(0)像素涂为红(2)，遇到第一个非背景像素时停止（不覆盖该像素）。射线的最后一个红色像素紧接在缩放体下方。
6. 保留左上角的原始模板不变。擦除底边标记像素（恢复为背景），因为射线已经标识了标记位置。

**关键洞察**：旋转角度不是直接给定的——必须从底边标记的空间分布反推模板需要旋转多少度才能让前景列与标记列对齐。这种"从输出约束反推变换参数"的推理模式在源题中不存在：103eff5b 中旋转方向是固定的（顺时针 90 度），891232d6 中路径方向是固定的（向上）。

## 新题 8：封闭环路面积排序压缩为等宽条纹

**组合逻辑**：[计数·围合面积](创新：计算的不是对象自身面积而是对象围成的封闭区域面积) → [排序·按围合面积](创新：排序键是对象的拓扑属性而非空间位置) → [压缩·条纹化](创新：每个对象被压缩为一行色条，宽度由对象自身像素数决定)

**来源原语**：计数(counting) ← e3721c99/df8cc377/8e301a54；封闭区域(enclosed_region) ← e3721c99；排序(sorting) ← 668eec9a；最高行决定序(topmost_determines) ← 668eec9a；压缩(compress) ← 7e4d4f7c；色条行(color_stripe_row) ← 668eec9a；连通分量(connected_component) ← 8e301a54

**依赖链**：必须先识别每个闭合环路围成的封闭背景区域并计算其面积（拓扑分析），才能确定排序顺序；排序顺序决定条纹在输出中从上到下的位置；而每个条纹的宽度取决于环路自身的像素计数（另一个独立的计数操作），两种计数的结果在输出中正交组合（纵向位置 vs. 横向宽度）。

将闭合环路按围合面积从小到大排序，每个环路压缩为一行色条（宽度等于环路像素数），垂直堆叠输出。

**输入结构**：黑(0)背景，约 18x18 网格。网格中有 3~5 个单像素宽的闭合环路，每个环路由不同颜色绘制（如蓝(1)、红(2)、绿(3)、黄(4)），每个环路是一个封闭的 4-连通回路（像素首尾相连形成一个不自交的闭合曲线，宽度为 1 像素），围成一块背景区域。各环路互不重叠、互不嵌套、互不相邻（环路之间至少隔 1 像素背景）。各环路围成的背景面积各不相同，各环路自身的像素数也各不相同。生成约束：环路的最大像素数不超过网格宽度（以便条纹宽度不超出输出网格）。

**规则**：
1. 识别每个非背景颜色的 4-连通分量（每个分量即一个闭合环路），记录其颜色和像素数 P。
2. 对每个环路，找到其围合的封闭区域：环路像素将某块背景区域完全包围（该背景连通域不与网格边界连通），计算该封闭背景区域的面积 A。
3. 按围合面积 A 从小到大排序所有环路。若 A 相同（生成时避免），按环路最上方像素行号从小到大排。
4. 构造输出网格：高度等于环路个数，宽度等于所有环路中最大的像素数 P_max。背景为黑(0)。
5. 从第 0 行起，按排序顺序逐行放置每个环路的色条：在该行从第 0 列起连续绘制 P 个像素（P 为该环路的像素数），颜色为该环路的颜色。剩余列保持背景。

**关键洞察**：同一个对象需要被度量两次——围合面积决定它在输出中的纵向位置，自身像素数决定它在输出中的横向宽度。两种计数结果正交组合，缺一不可：跳过围合面积则无法确定堆叠顺序，跳过像素计数则无法确定条纹宽度。源题 668eec9a 中排序键是空间位置（最高行），这里排序键是拓扑属性（围合面积），改变了排序的语义层级。

## 新题 9：括号提取宽度驱动楔形展开与居中堆叠

**依赖链**：括号提取的段宽度各不相同，宽度信息直接决定排序顺序（从窄到宽）；排序顺序决定堆叠的纵向位置；堆叠时每段居中对齐，宽度递增形成视觉楔形——这个楔形不是由预设规则逐行扩展一格产生的，而是由提取段自身的宽度差异自然涌现。

**规则**：
1. 识别所有标记行（同时包含蓝(1)和青(8)各一个像素的行）。
2. 对每个标记行，提取蓝(1)和青(8)之间（不含蓝和青本身）的行段内容。
3. 计算每个行段内的非背景像素数 N（即红(2)像素的个数）。
4. 按 N 从小到大排序所有行段。
5. 构造输出网格：高度等于行段数，宽度等于最宽行段的宽度。背景为黑(0)。
6. 从第 0 行开始，按排序顺序依次放置行段：每个行段水平居中放置在该行（左右各补等量的背景像素使总宽度等于输出网格宽度；若段宽度与输出宽度之差为奇数——生成时已避免此情况——则多出的一列补在右侧）。
7. 输出网格从上到下段宽度递增，自然形成底宽顶窄的楔形。

**关键洞察**：楔形形状不是通过"每行多展开一列"的固定规则产生的（源题 bae5c565 的机制），而是从提取段自身宽度差异中涌现——排序后宽度自然递增。若跳过排序直接按原始行序堆叠，就不会形成楔形；若跳过括号提取直接排序，则没有段内容可供堆叠。三个操作的耦合产生了一个在源题中都不存在的视觉效果。

**组合逻辑**：[掩码映射·列范围提取](创新：掩码的连续前景列段被解读为矩形区域的列跨度) + [填充·棋盘格](创新：棋盘填充的区域由掩码列段动态决定) + [标记竖条·缺口居中](创新：掩码中的背景缺口列成为竖条标记位置)

**来源原语**：掩码映射(mask_mapping) ← 7e4d4f7c；首行掩码(top_row_mask) ← 7e4d4f7c；压缩(compress) ← 7e4d4f7c；填充(fill) ← df8cc377；棋盘格图案(checkerboard) ← df8cc377；空心矩形(hollow_rect) ← df8cc377；标记竖条(marker_bar) ← bae5c565；以缺口为中心(centered_on_gap) ← bae5c565；列标记(column_marker) ← 7e4d4f7c

**依赖链**：首行掩码的前景/背景分布同时编码了两种信息——连续前景列段定义棋盘填充的列范围，背景缺口定义竖条标记的列位置。棋盘填充的行范围由首列的竖条标记高度决定（来自另一个维度的信息）。三种元素（掩码、竖条、棋盘）的几何参数互相引用，形成闭环约束。

读取首行掩码的前景列段和缺口位置，在首列竖条标记指定的行范围内，对每个前景列段区域填充棋盘格图案，在缺口列绘制竖条。

**输入结构**：黑(0)背景，约 12x12 网格。第 0 行（首行）是一个掩码行：部分列为蓝(1)前景，部分列为黑(0)背景。前景像素形成 1~3 个连续列段（每段至少 2 列宽），段之间被单列的背景缺口分隔。第 0 列从第 1 行开始向下有一条绿(3)竖条标记（连续的绿色像素，高度 H 在 3~6 之间）。网格其余像素为背景。(0,0) 位置由首行掩码决定——若第 0 列在掩码中是前景则为蓝(1)，否则为黑(0)。生成约束：掩码中恰好有 1~2 个背景缺口列（每个缺口宽度恰好 1 列），缺口不在首列或末列。

**规则**：
1. 读取第 0 行掩码，识别所有连续蓝(1)前景列段及背景缺口列。
2. 读取第 0 列的绿(3)竖条标记，记录其高度 H（从第 1 行到第 H 行）。
3. 清除整个网格为黑(0)背景。
4. 对每个连续前景列段 [c_start, c_end]：在行范围 [1, H] 和列范围 [c_start, c_end] 定义的矩形区域内填充棋盘格图案——以区域左上角 (1, c_start) 为棋盘起始格（着色格），颜色为蓝(1)，相邻格为背景(0)，交替排列。
5. 对每个背景缺口列 c_gap：在行范围 [1, H] 的所有行上绘制绿(3)竖条（c_gap 列从第 1 行到第 H 行全部涂绿(3)）。
6. 保留第 0 行掩码原样（蓝和黑的原始分布）。第 0 列的绿色竖条保留原样。
7. 棋盘格与竖条若在同一像素重叠（仅当缺口列同时落在某前景段范围内时发生——生成时已通过缺口定义排除此情况，因为缺口是前景段之间的分隔），竖条颜色优先。

**关键洞察**：首行掩码在源题 7e4d4f7c 中仅用于生成一行重涂色掩码，这里被重新解读为空间区域的列跨度定义。掩码中的"前景"和"缺口"编码了两种完全不同的操作目标——前景段触发棋盘填充，缺口触发竖条绘制——同一行的不同像素驱动不同的变换分支，形成隐式的条件分支结构。
