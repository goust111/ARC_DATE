## 新题 1：象限控制镜像印章

**组合逻辑**：[所属象限/containing_quadrant](创新：从选择填充区域改为编码镜像轴) → [镜像/mirror](创新：作用于精灵体而非整图) → [印章覆盖/stamp](已有) → [擦除/erase](已有)

**来源原语**：所属象限/containing_quadrant（87ab05b8）、镜像/mirror（3af2c5a8, c35c1b4c）、印章覆盖/stamp + 锚点标记/anchor_marker + 目标标记/destination_marker + 同色对应/same_color_match（1b59e163）、控制像素/control_pixel（87ab05b8）、擦除/erase（87ab05b8）

**依赖链**：控制像素的象限位置决定镜像类型（水平、垂直、或双轴），镜像类型决定精灵体被变换后的形态，变换后的形态才是被印章到各目标标记处的内容。三步形成不可拆分的因果链：不知道象限就无法确定镜像轴，不做镜像就印章了错误的形态，不印章就没有输出。

根据控制像素所在的网格象限确定对精灵体施加的镜像类型，然后将变换后的精灵体印章到每个同色目标标记位置。

**输入结构**：约 13x13 的网格，黑(0)背景。网格中有以下元素：
- 一个单色小精灵体（红(2)，4-连通，3~6 像素，不规则形状，具体形状因示例而异，非轴对称，以保证镜像后形态明确改变）。
- 一个蓝(1)锚点标记像素，与精灵体 4-邻接（紧贴精灵体边界框外侧一格）。
- 一个黄(4)控制像素，位于网格中某处，不与任何前景对象相邻。
- 3~5 个蓝(1)目标标记像素，散布于网格各处，彼此不相邻，也不与精灵体相邻。
- 生成约束：精灵体关于水平轴和垂直轴均不对称；各目标标记位置保证印章后的精灵体不超出网格边界且互不重叠；控制像素不与任何蓝(1)像素共行或共列。

**规则**：
1. 找到精灵体：与蓝(1)锚点标记 4-邻接的红(2) 4-连通分量。记录精灵体掩码及锚点标记在精灵体边界框内的相对坐标。
2. 判定控制像素所属象限——以网格中心（行数/2, 列数/2，下取整）为分界：
   - 控制像素在左半（列 < 列数/2）：对精灵体掩码施加**水平镜像**（左右翻转），同时翻转锚点的相对列坐标。
   - 控制像素在上半（行 < 行数/2）：对精灵体掩码施加**垂直镜像**（上下翻转），同时翻转锚点的相对行坐标。
   - 两条规则独立生效，可同时触发（如控制像素在左上象限 → 双轴镜像；右下象限 → 不做任何镜像）。
3. 清空整个网格为黑(0)。
4. 对每个蓝(1)目标标记像素，将变换后的精灵体掩码以变换后的锚点相对坐标为对齐点印章到目标标记位置，用红(2)着色。目标标记像素本身保留为蓝(1)，不被精灵体覆盖。
5. 印章顺序：按目标标记的位置从左上到右下（先行后列）依次印章；后印章的像素覆盖先印章的像素（但生成约束已保证不重叠）。

**关键洞察**：控制像素不选择区域也不选择对象，而是通过其在网格中的象限位置编码一个几何变换指令——这个"位置即指令"的映射关系在任何单道参考题中都不存在，必须对比多个示例（控制像素出现在不同象限）才能归纳。

## 新题 2：种子射线构造分区与异常单元提取

**组合逻辑**：[射线延伸/ray_extend](创新：射线不绘制而是定义分区边界) → [等分网格/equal_partition](创新：分区由射线动态构造而非预绘分隔线) → [异常值选择/outlier_selection](已有) → [裁剪/crop](已有)

**来源原语**：射线延伸/ray_extend + 种子像素/seed_pixel + 种子色决定延伸/seed_color_determines_extend（178fcbfb）、裁剪/crop + 提取/extract + 网格单元/grid_cell + 等分网格/equal_partition + 唯一单色单元/unique_mono_cell + 异常值选择/outlier_selection（c3202e5a）

**依赖链**：种子像素的颜色和位置决定射线方向和位置，射线位置构造出分区网格，分区网格划定单元边界后才能逐单元检查颜色一致性，颜色一致性检查才能找到唯一的异常单元并裁剪输出。分区网格是中间涌现结构——输入中没有任何可见的分隔线。

将边缘种子像素解释为分区边界指令，构造隐式网格分区，然后提取唯一内部单色一致的单元。

**输入结构**：约 15x15 的网格，黑(0)背景。网格中有以下元素：
- 最顶行：2~3 个红(2)种子像素，分布在不同列位置。
- 最左列：2~3 个蓝(1)种子像素，分布在不同行位置。
- 内部区域（不含最顶行和最左列）：密集散布各色前景像素（绿(3)、黄(4)、灰(5)、品红(6)、橙(7)等），大部分区域包含多种颜色混杂。
- 生成约束：红种子的列坐标和蓝种子的行坐标将内部区域恰好划分为矩形单元（不要求等大）；恰好一个单元内的所有非黑像素为同一颜色，其余单元均包含至少两种不同的非黑颜色；种子像素的行列坐标不与网格边界重合（即不在第 0 行的第 0 列位置等角落位置）。

**规则**：
1. 识别种子像素：最顶行的红(2)像素和最左列的蓝(1)像素。
2. 构造分区边界：每个红种子的列坐标定义一条垂直分界线，每个蓝种子的行坐标定义一条水平分界线。分界线将内部区域（行 1 至末行，列 1 至末列）切割为矩形单元。
3. 逐单元检查：统计每个单元内所有非黑像素的颜色种类数。
4. 找到唯一的单色单元（非黑像素颜色种类数 = 1）。
5. 输出该单元的裁剪结果：保留其黑像素和唯一前景色，尺寸为该单元的行列范围。

**关键洞察**：分区网格不是预绘制的可见分隔线，而是由边缘种子像素的位置隐式编码的——求解者必须先理解"种子位置 = 分界线坐标"这个编码规则，才能构造出分区、进而识别异常单元。

## 新题 3：拓扑分类着色与面积排序同心环

**组合逻辑**：[计数/counting + 弯折数分类/bend_count_class](已有) → [重涂色/recolor](创新：颜色由拓扑属性而非原始颜色决定) ⊕ [面积排序/area_ordering](已有) → [同心环绘制/concentric_draw](创新：环的颜色来自拓扑分类而非输入原色)

**来源原语**：计数/counting + 重涂色/recolor + 弯折形状/bent_shape + 拐角/corner_bend + 弯折数分类/bend_count_class + 弯折数决定颜色/bend_count_color（e509e548）、排序/sort + 同心环绘制/concentric_draw + 连通分量/connected_component + 嵌套方环/nested_square_ring + 面积排序/area_ordering + 面积决定嵌套序/area_nesting_order（5587a8d0）

**依赖链**：两条独立的分析路径（拓扑→颜色，面积→位置）必须在同心环绘制时汇合。删除拓扑分析→环的颜色未知；删除面积排序→环的内外顺序未知。两条路径的结果在输出中交织为一个结构：每个环同时承载拓扑信息（颜色）和面积信息（位置），二者缺一不可。

将同色对象按拓扑属性（弯折数）重新着色，再按面积从大到小排列为同心方环，输出一个几何结构编码两种独立属性。

**输入结构**：约 14x14 的网格，黑(0)背景。网格中有以下元素：
- 3~5 个绿(3) 4-连通单色对象，彼此不相邻（最近像素间距 >= 2）。
- 每个对象是一个小型不规则连通图形（4~10 像素），具有不同数量的 L 形 2x2 拐角弯折（弯折数从 1 到对象总数各不相同）。
- 每个对象的像素总数（面积）互不相同。
- 生成约束：所有对象同为绿(3)色；弯折数与面积之间没有单调对应关系（即面积最大的对象不一定弯折数最多），以迫使求解者独立分析两个属性。

**规则**：
1. 识别所有绿(3) 4-连通分量，记录每个分量的像素集。
2. 对每个分量，扫描其掩码中所有 2x2 子区域，统计恰好有 3 个前景像素的 L 形拐角数量（即弯折数）。
3. 按弯折数重涂色：弯折数 1 → 蓝(1)，弯折数 2 → 红(2)，弯折数 3 → 黄(4)，弯折数 4 → 灰(5)，弯折数 5 → 品红(6)。
4. 按像素总数从大到小排序所有分量。
5. 构造输出：边长为 2N-1（N = 分量数）的正方形网格。最大面积分量的重涂色颜色填充最外层方环，次大面积的颜色填充次外层方环，依此类推，最小面积的颜色填充中心像素。

**关键洞察**：输入中所有对象同色（绿），因此输出中的颜色不来自输入的原色——它是由拓扑属性（弯折数）间接决定的。同时，环的嵌套顺序由另一个独立属性（面积）决定。求解者必须同时推断两条独立的映射规则并在输出中合并它们。

## 新题 4：叠加合成模板用于旋转副本补全

**组合逻辑**：[透明叠加/transparent_overlay + 并集合并/union_merge](创新：叠加结果不是最终输出而是中间模板) → [模板提取/template_extraction](创新：模板从叠加涌现而非直接可见) → [补全/completion + 旋转反射等价/rotation_reflection_equivalence](已有)

**来源原语**：透明叠加/transparent_overlay + 分隔行/separator_row + 前景掩码/foreground_mask + 逐格对齐/cell_aligned + 并集合并/union_merge（ce4f8723）、模板提取/template_extraction + 补全/completion + 矩形模板/rectangular_template + 变换副本/transformed_copy + 对齐签名匹配/alignment_signature_matching + 旋转反射等价/rotation_reflection_equivalence（79369cc6）

**依赖链**：模板不直接存在于输入中，必须先将两个分区掩码叠加合并才能合成模板；合成的模板才能用于识别和补全下方的旋转/反射副本。叠加是模板补全的前置条件，而非独立的最终操作（与 ce4f8723 的用法根本不同）。

将分隔符上下两层的互补局部图案叠加为完整模板，再用该模板补全网格中散布的旋转/反射不完整副本。

**输入结构**：约 14x20 的网格（14 行 20 列），黑(0)背景。网格中有以下元素：
- 一条全宽灰(5)水平分隔行，位于约第 5 行，将网格分为上区（行 0~4）和下区（行 6~末行）。
- 上区：红(2)前景像素散布在黑背景上，形成一个局部图案。图案包含在一个约 4x4 的边界框内，位于上区中央。
- 下区分为两部分：
  - 左侧（与上区等高等宽的区域）：蓝(1)前景像素散布在黑背景上，形成另一个局部图案，与上区的红图案占据相同的边界框范围。红图案和蓝图案在相同边界框内没有重叠位置（没有任何坐标既是红又是蓝）。二者的并集构成一个完整的矩形模板。
  - 右侧及下方空白区域：散布 2~3 组品红(6)像素簇，每组是该模板的某个旋转或反射版本的不完整副本——每组中仅展示模板的部分"开"像素位置（以品红标记），其余"开"像素位置为空（黑色）。
- 生成约束：不同训练示例中红/蓝图案的分割方式不同（同一模板的不同二分法），但并集始终相同；每组品红副本至少展示模板"开"像素数的一半，以保证旋转/反射方向可唯一确定；品红副本之间互不重叠。

**规则**：
1. 定位上区的红(2)图案和下区左侧的蓝(1)图案，二者边界框对齐。
2. 逐格合并：某位置为"开"当且仅当该位置在红图案中为红(2)或在蓝图案中为蓝(1)。合并结果即为模板掩码。
3. 在下区的品红区域中，搜索模板的所有 4 种旋转 x 2 种反射（共 8 种取向）的放置：对每种取向的模板放置，检查该取向模板的所有"开"位置中，标记为品红(6)的子集是否与实际品红像素完全吻合。
4. 对每个匹配的放置，将该取向模板中非品红的"开"位置（即缺失位置）涂为绿(3)。已有的品红像素保持品红不变。
5. 输出整个网格：上区和分隔行保持原样，下区展示补全后的结果。

**关键洞察**：模板是一个涌现结构——它不以任何单一颜色完整呈现，必须通过合并两种颜色的互补碎片来合成。不同训练示例的分割方式不同，迫使求解者从多个示例中归纳出"取并集"这个合成规则，而非记忆某一种特定分割。

## 新题 5：象限编码填充方向的条纹转移

**组合逻辑**：[计数/counting + 像素数转为条纹/pixels_to_stripes](已有) ⊕ [所属象限/containing_quadrant](创新：从选择填充区域改为编码填充方向) → [填充/fill](创新：填充方向不由接触边决定而由象限决定) → [擦除/erase](已有)

**来源原语**：计数/counting + 填充/fill + 擦除/erase + 条形段/bar_segment + 矩形容器/rect_container + 相邻接触/adjacent_touch + 像素数转为条纹/pixels_to_stripes（d93c6891）、控制像素/control_pixel + 象限/quadrant + 所属象限/containing_quadrant（87ab05b8）、区域填充/region_fill（87ab05b8）

**依赖链**：灰条像素计数决定填充量（"多少"），而矩形所在象限决定填充方向（"从哪边开始"）。两者在同一操作中交汇：填充量和填充方向共同唯一确定输出中的灰条纹位置。删除计数→不知道填多少行/列；删除象限判断→不知道从哪边开始填。二者的交互产生源题中不存在的行为：在 d93c6891 中方向由接触边决定，这里接触边可能与象限编码的方向不同。

将灰条像素数转移为矩形容器内的条纹，但条纹的起始边由矩形所在的网格象限决定而非由灰条的接触方向决定。

**输入结构**：约 14x14 的偶数尺寸网格，黑(0)背景。网格中有以下元素：
- 一条全宽黄(4)水平线位于网格垂直中点（第 rows/2 行），一条全高黄(4)垂直线位于网格水平中点（第 cols/2 列），形成十字分隔，将网格分为四个象限。
- 每个象限内恰好有一个实心橙(7)矩形（宽 3~5 像素，高 3~5 像素），完全位于该象限内部，不接触黄线。
- 部分橙矩形外侧有灰(5)条形段（1 像素宽，长度不等）与之 4-邻接。同一矩形的所有灰条形段方向相同（全水平或全垂直）。灰条不跨越黄线，不触及其他矩形。
- 部分橙矩形无任何灰条接触。
- 生成约束：每个有灰条接触的矩形，其灰条总像素数不超过该矩形在填充方向上的行数或列数（保证填充不溢出）；至少有一个示例中，灰条的实际接触边与象限编码的填充方向不一致（例如灰条从矩形左侧接触，但该矩形在右上象限，应从右侧开始填充）。

**规则**：
1. 识别黄(4)十字分隔线，确定四个象限。
2. 对每个象限内的橙(7)矩形，统计所有 4-邻接灰(5)像素的总数 N。
3. 根据矩形所在象限确定填充起始边：
   - 左上象限：从矩形顶边向下填充 N 个完整行。
   - 右上象限：从矩形右边向左填充 N 个完整列。
   - 左下象限：从矩形左边向右填充 N 个完整列。
   - 右下象限：从矩形底边向上填充 N 个完整行。
4. "填充 N 行"指：将矩形内从指定边开始的连续 N 行所有像素从橙(7)改为灰(5)。"填充 N 列"类似。
5. 将所有原始灰(5)条形段（矩形外部的）清除为黑(0)。
6. 无灰条接触的橙矩形保持全橙不变。
7. 黄(4)十字分隔线保持不变。

**关键洞察**：填充方向不由灰条的物理接触方位决定，而由矩形所在的象限隐式编码——这意味着同样的灰条配置放在不同象限会产生不同的填充结果。求解者必须对比多个象限的行为才能发现方向由象限而非接触边决定。

## 新题 6：种子射线构筑壁障下的标记消除行走

**组合逻辑**：[射线延伸/ray_extend + 种子色决定延伸/seed_color_determines_extend](创新：射线作用从绘制条纹改为构筑不可通行壁障) → [逐步移动/stepwise_move + 消除/consume + 最近标记优先/nearest_marker_first](创新：行走空间被射线壁障重塑) → [擦除/erase](已有)

**来源原语**：射线延伸/ray_extend + 种子像素/seed_pixel + 种子色决定延伸/seed_color_determines_extend（178fcbfb）、逐步移动/stepwise_move + 消除/consume + 三角精灵体/triangle_sprite + 标记像素/marker_pixel + 朝向决定搜索线/facing_sets_search_line + 最近标记优先/nearest_marker_first（5545f144）、擦除/erase（87ab05b8）

**依赖链**：射线壁障修改了行走的可达空间，导致"最近可达标记"与"最近标记"不同——壁障可能挡住几何上更近的标记，迫使精灵绕行或跳过。最终位置完全取决于壁障拓扑。删除射线→壁障消失→行走路径改变→最终位置错误。删除行走→无输出。射线不是装饰，它实质性重塑了行走的决策图。

将边缘种子射线构筑为行走壁障，三角精灵体在壁障约束下逐步消除标记，输出最终精灵体位置。

**输入结构**：约 12x12 的网格，黑(0)背景。网格中有以下元素：
- 边缘种子像素：2~4 个红(2)种子像素位于最顶行或最底行，1~3 个蓝(1)种子像素位于最左列或最右列。
- 一个三角精灵体（绿(3)，由 3 个像素组成等腰直角三角形，朝向四个基本方向之一：尖端指向朝向方向）。精灵体不在最外行/列。
- 3~5 个黄(4)标记像素散布于网格内部（不在最外行/列，不与种子共行列）。
- 生成约束：种子射线构筑的壁障保证精灵体至少能消除一个标记；至少存在一个标记被壁障挡住而不可直接到达（即壁障在精灵体与该标记之间的搜索线上），迫使精灵体绕行或跳过该标记；精灵体能消除所有标记（不会出现永久不可达标记）。

**规则**：
1. 构筑壁障：
   - 每个位于最顶行或最底行的红(2)种子，其所在列的所有内部行像素（行 1 至行 rows-2）标记为壁障。
   - 每个位于最左列或最右列的蓝(1)种子，其所在行的所有内部列像素（列 1 至列 cols-2）标记为壁障。
   - 壁障像素不在输出中绘制，仅作为不可通行的逻辑障碍。
2. 逐步行走（与 5545f144 相同机制，但增加壁障约束）：
   - 从精灵体当前位置出发，沿朝向方向的半直线搜索标记。搜索在遇到壁障时截止（壁障后的标记不可见）。
   - 如果朝向方向无可见标记，依次检查右转 90 度、左转 90 度、后转 180 度方向的半直线（优先级：朝向 > 右转 > 左转 > 后转）。
   - 在选定方向的半直线上，移动到最近的标记，消除该标记，精灵体朝向改为移动方向。
   - 重复直到四个方向均无可见标记。
3. 输出：清空整个网格为黑(0)背景，仅绘制精灵体在最终位置的绿(3)形态（朝向为最后一次移动的方向）。

**关键洞察**：种子射线不绘制可见条纹，而是构筑不可见的壁障，壁障截断搜索视线，使精灵体的标记消除顺序与无壁障时完全不同。必须对比有壁障和无壁障的示例才能意识到壁障的存在和作用。

## 新题 7：图例编码精灵外推印章

**组合逻辑**：[外推/extrapolate + 匀速运动延续/constant_motion](已有) ⊕ [位置对应/positional_mapping + 图例色替换标记/legend_replaces_marker](创新：图例映射的不是标记颜色而是输出精灵的外观) → [印章覆盖/stamp](已有)

**来源原语**：外推/extrapolate + 平移/translate + 帧序列/frame_sequence + 内部精灵/inner_sprite + 等间距排列/equal_spacing + 匀速运动延续/constant_motion（ba1aa698）、印章覆盖/stamp + 裁剪/crop + 图例精灵/legend_sprite + 分隔行/separator_row + 标记像素/marker_pixel + 位置对应/positional_mapping + 图例色替换标记/legend_replaces_marker（20fb2937）

**依赖链**：三条信息线在输出中汇合：(a) 运动外推决定精灵的空间位置，(b) 颜色循环规则决定使用哪个图例条目，(c) 图例映射决定精灵的外观。三者缺一不可：不做外推→位置未知；不识别颜色循环→不知道查询哪个图例条目；不读图例→不知道精灵的外观。任何两者的组合都不能独立产出正确输出。

从帧序列中外推运动位置并推断颜色循环规律，用图例将下一帧的颜色映射为具体精灵外观，在外推位置印章该精灵。

**输入结构**：约 10x28 的宽网格，黑(0)背景。网格中有以下元素：
- 图例区（上部，约 4 行高）：3 个小型填充方块（每个 2x2 像素），颜色各不相同（例如红(2)、蓝(1)、黄(4)），从左到右等距排列。每个方块正下方 1 格处有一个标记像素，颜色与方块不同且各标记颜色互不相同（例如绿(3)、灰(5)、橙(7)）。标记像素的列坐标与方块中心列对齐。
- 一条全宽灰(5)水平分隔行，位于图例区下方。
- 帧序列区（分隔行下方）：3~4 个等宽面板，面板之间共享灰(5)垂直边界列。每个面板内有黑(0)背景和一个单像素标记（颜色为图例标记色之一），位于面板内的某个位置。
- 帧序列中标记的行坐标在连续面板间以固定增量 delta 变化（匀速垂直运动）。列坐标在面板局部坐标系中保持不变。
- 标记颜色在连续面板间按图例从左到右的顺序循环出现（例如：绿、灰、橙、绿、灰、...）。
- 生成约束：面板数 >= 3 以保证运动增量可确认；颜色循环至少走完一轮以保证循环规律可归纳；外推后的标记位置保证印章的方块不超出面板边界。

**规则**：
1. 解析图例：建立标记颜色 → 方块颜色的映射（例如：绿(3) → 红(2), 灰(5) → 蓝(1), 橙(7) → 黄(4)）。同时记录方块的 2x2 形态。
2. 分析帧序列：
   - 识别每个面板中标记像素的局部坐标（行偏移、列偏移）。
   - 计算连续面板间行偏移的差值 delta（应为常数）。
   - 记录连续面板的标记颜色序列。
3. 外推一帧：
   - 位置：在最后一个面板的行偏移基础上加 delta，列偏移不变。
   - 颜色：颜色序列按图例从左到右的顺序循环，取下一个颜色。
4. 构造输出（一个独立面板，与输入面板等宽等高）：
   - 黑(0)背景。
   - 在外推位置处，以标记位置为中心印章图例中对应颜色的 2x2 方块。方块颜色为图例映射的目标颜色（方块本身的颜色），不是标记颜色。
5. 输出仅包含该单个面板，不包含图例和分隔行。

**关键洞察**：标记的颜色不是精灵的颜色——它是一个索引，通过图例间接映射到精灵外观。颜色循环的规律（按图例从左到右的空间顺序）必须从多个示例中归纳，而非从颜色编号的数值顺序推断。

## 新题 8：对称补全揭示连通桥接

**组合逻辑**：[对称补全/symmetry_completion](创新：补全的目的不是最终输出而是创造连通条件) → [连线/connect + 同色配对/same_color_pairing + 沿行列填充间隙/fill_gap_along_row_col](创新：连线的可行性取决于补全是否创造了连续桥接) → 输出整合

**来源原语**：对称补全/symmetry_completion + 镜像/mirror + 主色前景对象/dominant_fg_object + 中轴线/center_axis + 对称/symmetry + 最高频色为目标/most_frequent_target（c35c1b4c）、连线/connect + 填充/fill + 标记像素/marker_pixel + 同色配对/same_color_pairing + 轴对齐/axis_aligned + 沿行列填充间隙/fill_gap_along_row_col（06df4c85）

**依赖链**：对称补全在网格中新增前景像素，这些新像素可能恰好填补了两个同色标记之间的间隙，使得连通条件成立。删除对称补全→桥接不存在→连线无法判定。删除连线→标记对不产生可见效果→输出与补全结果无区别（退化为单逻辑题）。对称补全本身改变了连线决策的输入条件——这种"操作 A 的输出改变操作 B 的触发条件"正是紧耦合。

将不对称的主色图案关于垂直中轴做镜像补全，补全后新增的像素可能在同色标记对之间形成连续水平桥，仅对形成桥接的标记对执行间隙连线。

**输入结构**：约 11x11 的奇数宽度网格，黑(0)背景。网格中有以下元素：
- 红(2)前景像素构成一个 4-连通图案，分布偏向网格的左半侧（或右半侧），关于垂直中轴线（列 cols/2）不对称。该图案是网格中像素数最多的前景色。
- 3~5 对标记像素散布于网格中：每对由 2 个相同颜色的像素组成（可用的颜色为蓝(1)、黄(4)、灰(5)、品红(6)、橙(7)等，每对一种颜色），同对的两个标记位于同一行（行对齐）。标记像素不与红图案重叠。
- 生成约束：对称补全后（红图案关于中轴镜像），至少一对标记之间的所有单元格都被红(2)像素覆盖（形成连续桥接），至少一对标记之间存在未被红像素覆盖的间隙（不形成桥接）。标记对之间不含其他标记像素。

**规则**：
1. 识别主色：像素数最多的前景色（红(2)）。
2. 对称补全：将每个红(2)像素关于网格垂直中轴线（列 cols/2，取整）做镜像，在镜像位置也涂红(2)。若镜像位置已有非黑像素（标记），红(2)不覆盖标记（标记优先）。
3. 桥接检测：对每对同色标记（同行的两个同色像素），检查二者之间同行的所有单元格是否全部为红(2)或为该对标记的颜色。
   - 全部满足 → 该标记对"已桥接"。
   - 存在黑(0)间隙 → 该标记对"未桥接"。
4. 连线：对每个"已桥接"的标记对，将二者之间同行所有单元格的颜色改为该标记对的颜色（覆盖红(2)像素），形成一条彩色水平连线。
5. "未桥接"的标记对保持原状（两个标记像素仍在，之间的间隙保持黑或红）。
6. 输出整个网格：包含补全后的红图案、连线、未连线的标记和未修改的区域。

**关键洞察**：对称补全不是目的，而是手段——它创造了连通条件，使得某些标记对之间的间隙被红像素填满。哪些标记对能被连线完全取决于补全的几何结果，而这只有在完成补全后才能判定。求解者需先做补全、再做桥接检测，最后才能决定哪些标记对被连线。

## 新题 9：标记选择精灵体平铺入分区空槽

**组合逻辑**：[邻接接触/adjacency_contact + 标记选精灵涂色/marker_sprite_recolor](创新：标记不只提取精灵，还指定了平铺内容) → [裁剪/crop](已有) → [平铺/tile + 已填瓦片填空槽/filled_tile_to_empty_slots](创新：平铺的模式不是输入中已有的填充单元，而是被标记选出的精灵) → [擦除/erase](已有)

**来源原语**：裁剪/crop + 重涂色/recolor + 精灵体/sprite + 标记像素/marker_pixel + 邻接接触/adjacency_contact + 标记选精灵涂色/marker_sprite_recolor（5117e062）、平铺/tile + 分隔线/separator_line + 瓦片图案/tile_pattern + 网格分区/grid_partition + 已填瓦片填空槽/filled_tile_to_empty_slots（c444b776）

**依赖链**：标记选择机制确定哪个精灵被提取（"什么"），分区网格确定平铺的目标位置（"哪里"）。两者共同约束——没有标记选择，任何一个精灵都可能是瓦片；没有分区网格，提取的精灵无处可放。二者是同时约束关系而非先后顺序：选择和放置必须同时满足才能产出唯一解。

用标记像素从多个候选精灵中选出目标精灵，裁剪后将其平铺到分隔网格的所有空单元中。

**输入结构**：约 15x15 的网格，黑(0)背景。网格中有以下元素：
- 灰(5)分隔线：全宽水平线和全高垂直线将网格分为 3x3 或 2x3 的等大矩形单元。
- 单元内容：
  - 2~3 个单元各包含一个不同的小型单色前景精灵体（4-连通，3~6 像素，颜色各不相同，如红(2)、蓝(1)、黄(4)等），精灵体完全位于单元内部，不触及分隔线。
  - 恰好一个包含精灵体的单元中，额外有一个青(8)标记像素与该精灵体 4-邻接（在精灵体边界框外侧 1 格）。
  - 其余单元为空（全黑）。
- 生成约束：被标记的精灵体的边界框尺寸不超过任何空单元的尺寸（保证平铺不溢出）；各精灵体形状互不相同。

**规则**：
1. 识别分隔线（灰(5)的全宽行和全高列），确定单元网格。
2. 找到包含青(8)标记像素的单元，该单元内与标记 4-邻接的前景 4-连通分量即为目标精灵体。
3. 裁剪目标精灵体的边界框，得到瓦片图案。图案中精灵像素保持原色，标记像素排除（不进入瓦片）。
4. 将该瓦片图案复制到每个空单元中：瓦片在空单元内居中放置（若无法精确居中则偏左上 1 像素）。
5. 包含非目标精灵体的单元：清除其内容为全黑。
6. 被标记精灵体所在的单元：保留该精灵体原样（含原始像素，不含标记像素；标记像素清除为黑(0)）。
7. 分隔线保持灰(5)不变。

**关键洞察**：网格中有多个精灵体，但只有被青(8)标记选中的那个才成为平铺的种子——其他精灵体是干扰项，被清除。求解者必须同时理解"标记选择精灵"和"选中精灵填充空槽"两个规则，单独理解任一个都无法确定完整输出。
