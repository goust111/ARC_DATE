## 新题 1：路径偏移回声标记驱动格子交叉填充

**组合逻辑**：[偏移阴影](创新：从偏移单个像素改为对每个格子标记生成虚拟回声标记) + [填充](已有) + [双色交叉混合色](已有) ← 由 [端点编码位移](创新：从编码物体平移改为编码标记回声偏移) 参数化

**来源原语**：偏移阴影/offset_shadow(310f3251), 填充/fill(e760a62e), 双色交叉混合色/intersect_blend_color(e760a62e), 端点编码位移/endpoints_encode_disp(2b9ef948), 格子单元/lattice_cell(e760a62e), 标记像素/marker_pixel(e760a62e), 路径端点/path_endpoint(2b9ef948)

**依赖链**：路径端点编码偏移向量 → 每个标记像素按此向量生成虚拟回声标记 → 原始标记与回声标记共同参与格子行列填充 → 交叉区域产生混合色。去掉路径编码则回声位置不可知；去掉回声则填充范围退化为原始标记的简单连线；去掉混合色规则则交叉区域颜色不确定。

将路径端点编码的偏移向量施加于格子中的每个标记像素以产生虚拟回声标记，回声与原始标记共同驱动格子交叉填充，红绿交叉区域变为品红。

**输入结构**：约 15x15 网格。青(8)色格子线（1 像素宽）将画布划分为若干等大的矩形背景(0)单元格（约 3x3 至 4x4 个单元格）。部分单元格内放有单个标记像素：红(2)或绿(3)，每个标记位于其所在单元格内任意位置。网格的一个角落区域（格子线外侧），一条由 3-5 个灰(5)像素构成的路径连接两个黄(4)端点像素。两个端点之间有明确的空间位移关系。每种颜色至少有 2 个标记像素。

**规则**：
1. 解码偏移向量：取距网格左上角较近的黄(4)端点为起点，另一个为终点，向量 = 终点坐标 - 起点坐标，得到 (dr, dc)。
2. 对每个标记像素（位置 (r,c)，颜色 K），计算回声位置 (r+dr, c+dc)。若回声位置落在某个格子单元格内部（不在格子线上、不超出网格边界），则在该单元格注册一个颜色为 K 的虚拟回声标记；否则丢弃该回声。
3. 合并原始标记和虚拟回声标记集合。对每种颜色分别处理：若某格子行内有 2 个或以上同色标记，则将该行中最左标记单元格到最右标记单元格之间的所有单元格填充为该颜色；同理处理格子列（最上到最下）。填充区域覆盖整个单元格内部，不覆盖格子线。
4. 若某单元格同时被红(2)填充和绿(3)填充覆盖，该单元格最终颜色为品红(6)。
5. 擦除路径和黄色端点（用背景(0)覆盖）。保留所有青色格子线。标记像素（原始和回声位置）保留其颜色，覆盖在填充之上。
6. 回声标记在输出中可见——以其颜色绘制在回声所在单元格内。

**生成约束**：至少一个回声标记落入有效单元格并创建出仅靠原始标记不会产生的新填充连接（即至少一条填充线段的存在依赖于回声标记）。

**关键洞察**：路径不移动任何对象，而是为每个标记创造一个不可见的"回声副本"，回声改变了哪些格子行列被激活填充。求解者必须先解码偏移、再心算回声位置、最后重新计算填充范围——三步中任何一步缺失都无法得到正确输出。

## 新题 2：对角空位印入精灵体并经图例重涂色

**组合逻辑**：[对角互补](已有，定位空位) → [图案印章](创新：从占位符定位改为由对角空位定位) → [重涂色](已有，由图例驱动)

**来源原语**：对角互补/diagonal_complement(22233c11), 对角空位补块/complement_at_diagonal_vacancies(22233c11), 图案印章/stamp_glyph(edb79dae), 精灵体/sprite(edb79dae), 颜色图例/color_legend(edb79dae), 编码映射/encoding_map(edb79dae), 正方形块/square_block(22233c11)

**依赖链**：识别对角填充块 → 确定互补空位坐标 → 按填充色查找同色精灵体 → 在空位位置印入精灵体 → 按图例将精灵体重涂为输出色。对角空位提供"在哪里印"，填充色提供"印什么形状"，图例提供"涂什么颜色"——三重间接寻址缺一不可。

识别每个对角方块图案的两处空位，在空位处印入与方块同色的精灵体形状，再按颜色图例将印入的精灵体重涂为指定输出色。

**输入结构**：约 18x18 网格。黑(0)背景。2-4 个前景图案（"方块组"），每个方块组占据一个 2x2 排列的等大正方形子块区域（每个子块约 3x3 像素）。在每个方块组中，恰好两个对角位置的子块被填充为同一前景色（如红(2)、蓝(1)、绿(3)等），另外两个对角子块为背景色。不同方块组使用不同颜色。此外，网格中散布着与每种方块组颜色相同的小型精灵体（4-连通单色形状，3-6 像素，形状各异），不与任何方块组接触。网格的一个角落有颜色图例：由若干两像素对组成，每对中一个像素为方块组颜色、相邻一个像素为输出颜色（如红(2)旁放黄(4)表示红色精灵体重涂为黄色）。

**规则**：
1. 对每个方块组，识别已填充的两个对角子块位置（如左上+右下）和空缺的两个互补对角子块位置（如右上+左下）。
2. 对每个空缺子块位置，找到与该方块组前景色相同的精灵体。
3. 将精灵体印入空缺子块区域，对齐到子块的左上角。若精灵体超出子块边界，裁剪到子块范围内。
4. 将印入的精灵体像素重涂为图例中该前景色对应的输出颜色。
5. 原始对角填充块保持不变。原始精灵体（方块组外部的）从网格中擦除。图例保留。
6. 同一方块组的两个空缺位置印入相同形状的精灵体副本。

**生成约束**：每种方块组颜色恰好对应一个精灵体和一个图例条目。所有精灵体的边界框尺寸不超过子块尺寸。方块组之间不重叠。

**关键洞察**：空缺位置不是被纯色方块填充（不同于参考题 22233c11 的青色方块），而是被颜色查找到的精灵体形状填入，再经图例映射到输出色——从"位置决定填什么"到"颜色同时决定形状和输出色"的三重间接寻址是参考题中不存在的结构关系。

## 新题 3：射线碰撞计数充当柱状图频率阈值

**组合逻辑**：[射线延伸 + 碰撞产生侧翼](已有，模拟射线) → [计数](创新：从计数静态标记段改为计数动态碰撞事件) → [频率匹配](已有，但阈值来源变为碰撞计数) → [柱状填充](已有)

**来源原语**：射线延伸/ray_extend(79fb03f4), 碰撞产生侧翼/collision_generates_side_wakes(79fb03f4), 计数/counting(2685904e), 频率匹配/frequency_matching(2685904e), 柱状填充/histogram_fill(2685904e), 种子像素/seed_pixel(79fb03f4), 障碍像素/obstacle_pixel(79fb03f4), 分隔行/separator_row(2685904e), 编码行/code_row(2685904e)

**依赖链**：种子发射射线 → 碰撞障碍产生侧翼/分裂 → 统计每颗种子激活的障碍总数 → 该计数作为频率阈值匹配编码行颜色 → 匹配色在对应列生成等高柱状条。射线模拟的动态性决定了碰撞计数，计数同时充当"筛选条件"和"填充高度"，任何一步不可跳过。

在上区模拟种子射线碰撞并统计每颗种子激活的障碍数，将此碰撞计数作为频率阈值筛选下区编码行中的颜色，被筛中颜色在分隔行上方生成等高柱状条。

**输入结构**：约 15x20 网格。一条全宽灰(5)水平分隔行将网格分为上区和下区。
- 上区：最左列有 2-3 个种子像素（颜色各异，非灰非背景色，如红(2)、蓝(1)、绿(3)），其余区域散布若干单像素橙(7)障碍物。部分障碍物位于种子所在行，部分位于种子行的斜前方（前进方向的对角位置），可能触发射线分裂。
- 下区：最底行为编码行，包含多种颜色的像素（如红(2)、黄(4)、青(8)、蓝(1)等），每种颜色在编码行中出现若干次，分布在不同列。分隔行与编码行之间为背景(0)空白区域。

**规则**：
1. 在上区执行射线模拟：每个种子向右发射水平射线，以种子颜色绘制。射线遇到障碍像素时，障碍像素不变，在障碍上方和下方各绘制最多 3 个像素的侧翼尾迹（以种子颜色绘制，仅覆盖背景像素）。若障碍的前进方向两个对角位置都有障碍，原射线停止，在两条相邻行上各产生新的水平射线继续传播。侧翼被未激活的障碍阻挡时，只绘制开放侧的尾迹和阻挡障碍右侧一格。
2. 对每个种子，统计该种子的射线及其所有后代分支直接接触（8-邻域相邻）的不同障碍像素总数，记为该种子的碰撞计数 C。
3. 在编码行中，找出出现次数恰好等于某个种子碰撞计数 C 的所有颜色。
4. 对每个频率匹配的颜色 K（出现次数 = C），在编码行中 K 出现的每一列，从分隔行正上方向上填充 C 个格子，颜色为 K。
5. 上区射线标记保留在输出中。分隔行和编码行保留。
6. 若多个种子的碰撞计数相同，其频率匹配结果合并（同一颜色只需匹配任一种子的计数即可）。

**冲突解决**：若两个频率匹配的柱状条在同一格重叠（来自不同颜色的不同匹配计数），在编码行中列位置靠左的颜色优先。

**生成约束**：至少一个种子的碰撞计数与某编码行颜色的频率相等。每个种子至少碰撞一个障碍。不同种子的射线不在初始状态互相干扰（种子位于不同行）。

**关键洞察**：障碍碰撞计数取代了参考题 2685904e 中的静态标记段长度作为柱状图阈值——求解者必须先模拟射线动力学（含分叉和侧翼）才能算出计数值，而该计数同时充当频率筛选器和柱状条高度，一值二用。

## 新题 4：格子填充后按触边轴镜像并颜色互换

**组合逻辑**：[填充](已有，格子行列填充) → [镜像](已有，但轴由格子触边决定) + [负片色映射](创新：从整体负片改为特定双色互换，品红作为不动点)

**来源原语**：填充/fill(e760a62e), 共行或共列/shared_row_col(e760a62e), 双色交叉混合色/intersect_blend_color(e760a62e), 镜像/mirror(6f473927), 拼接/concatenate(6f473927), 接触边界定轴/touching_border_determines_axis(6f473927), 负片色映射/negative_color_remap(6f473927), 格子单元/lattice_cell(e760a62e), 标记像素/marker_pixel(e760a62e)

**依赖链**：格子内标记驱动行列填充 → 交叉产生品红 → 格子触边确定镜像轴 → 整体镜像到空白半区 → 镜像半区执行红绿互换但品红不变。填充必须先于镜像（否则镜像无内容）；轴判定来自格子结构（非显然）；品红的互换不变性是隐蔽规则（需多示例归纳）。

先在半区格子中完成红绿标记的行列填充（交叉产生品红），再按格子触边确定镜像轴，将填充结果镜像到另一半区，镜像中红绿互换但品红保持不变。

**输入结构**：约 10x20 网格（宽度为高度的两倍）。网格的一半（左半或右半）被青(8)格子线划分为矩形单元格（至少 3 行 3 列单元格），另一半为纯背景(0)空白。格子半区恰好触及一条竖直边界（左边界或右边界）。格子单元格内放有红(2)和绿(3)标记像素，每种颜色至少 3 个标记。标记的分布保证至少存在一个红绿交叉单元格（某单元格同时在一条红色填充线段和一条绿色填充线段上）。

**规则**：
1. 在格子半区内执行交叉填充：对每种颜色（红、绿），若某格子行内有 2 个或以上同色标记，将该行中最左标记单元格到最右标记单元格之间的所有单元格填充为该颜色。格子列同理。填充覆盖整个单元格内部，不覆盖格子线。
2. 同时被红色和绿色填充覆盖的单元格颜色设为品红(6)。
3. 确定格子半区触及的竖直边界——该边界即为镜像轴。
4. 将整个格子半区（含格子线、填充色、标记像素）沿镜像轴水平翻转到空白半区。
5. 在翻转副本中执行颜色互换：红(2) → 绿(3)，绿(3) → 红(2)。品红(6)不变。青(8)格子线不变。背景(0)不变。
6. 原始格子半区保持不变。

**生成约束**：格子半区恰好占网格宽度的一半。至少存在一个品红单元格。格子半区触及且仅触及一条竖直边界。

**关键洞察**：品红是红与绿的"混合"，在红↔绿互换下保持不变——这使得两个半区的品红单元格呈现对称一致，而红绿单元格呈现颜色镜像翻转。求解者必须从多个示例中发现品红的不动点性质，仅看单个示例可能误以为品红也参与互换。

## 新题 5：图例排名选取竖条位置编码空心框位移

**组合逻辑**：[排序 + 高度即排名索引](已有，选出特定竖条) → [端点编码位移](创新：从路径端点改为竖条空间属性编码位移) → [平移](已有) + [对角射线](已有)

**来源原语**：排序/sort(97d7923e), 高度即排名索引/legend_height_as_rank_index(97d7923e), 竖条/vertical_bar(97d7923e), 颜色图例/color_legend(97d7923e), 长度排名/length_ranking(97d7923e), 平移/translate(2b9ef948), 空心框/hollow_frame(2b9ef948), 对角射线/diagonal_ray(2b9ef948)

- 右侧区域：一个 3x3 黄(4)色空心框（中心为蓝(1)像素的控制色）。

**规则**：
1. 找出所有以栗(9)为帽端的竖条，按其内部长度降序排名（最长 = 第 1 名，次长 = 第 2 名，依此类推）。
2. 读取图例块的高度 k，选出排名第 k 的竖条。
3. 计算位移向量：dr = 被选竖条的顶部帽端行号 - 空心框左上角行号，dc = 被选竖条所在列号 - 空心框左上角列号。
4. 将空心框平移 (dr, dc) 到新位置。
5. 用蓝(1)（控制色）填充整个网格背景（覆盖原有的竖条、图例、旧框位置等）。
6. 在新位置绘制 3x3 黄(4)空心框。
7. 从框的四个角格子各发射一条黄(4)对角射线，方向分别为左上、右上、左下、右下，延伸至网格边界。

**生成约束**：平移后框完全位于网格内部，且四个方向的对角射线至少各延伸 3 格。只有一种帽端颜色（栗色）。各竖条内部长度互不相同。

**关键洞察**：排名的结果不是重涂竖条颜色（不同于参考题 97d7923e），而是将被选竖条的空间属性（位置和高度）提取为一个位移向量——竖条从"被操作的对象"变成了"编码参数的载体"，这种角色转换是参考题中不存在的结构关系。

**依赖链**：全部图块做多数投票 → 找出受损图块及其受损局部坐标 → 坐标映射到框架内部 → 对应位置的占位符被激活 → 按占位符色查找精灵体并印入 → 按图例重涂。图块晶格是"指令编码器"，框架是"指令执行器"，两者通过共享的局部坐标系耦合。

**输入结构**：约 20x22 网格，由一条 2 像素宽的灰(5)水平带分为上下两个区域。
- 上区（图块晶格）：由 1 像素宽灰(5)行列分隔的等大图块（如 4x4）组成的阵列（至少 2x3 排列）。所有图块是同一母题的副本（母题在黑(0)背景上包含 2-3 种颜色的像素），但其中恰好一个图块有若干像素被覆写为背景(0)（受损）。蓝(1)不出现在输入中。
- 下区（框架区域）：一个单色矩形框架（如红(2)边框），内部尺寸与单个图块相同。框架内部的若干位置放有彩色占位符像素（如黄(4)、绿(3)、橙(7)等），其余位置为背景(0)。框架外部：每种占位符颜色对应一个小型精灵体（4-连通同色形状，3-6 像素）。另有颜色图例（相邻像素对），将每种占位符颜色映射到一种输出颜色。

**规则**：
1. 对图块晶格中所有图块的每个局部坐标 (lr, lc) 取多数投票颜色，得到共识母题。
2. 找到唯一与共识母题不同的受损图块，记录其受损的局部坐标集合 D = {(lr1, lc1), (lr2, lc2), ...}。
3. 对集合 D 中的每个坐标 (lr, lc)，映射到框架内部的同一局部坐标位置。
4. 在每个映射位置，若该位置恰好有占位符像素，则该占位符被"激活"：找到与占位符颜色相同的精灵体，将精灵体以该位置为中心印入框架内部。
5. 将每个印入的精灵体像素重涂为图例中该占位符颜色对应的输出颜色。
6. 映射位置上没有占位符的受损坐标不产生任何效果。未被受损坐标映射到的占位符像素从框架中擦除（设为背景色）。
7. 输出仅包含框架区域（含框架边框和内部内容），不包含图块晶格。

**冲突解决**：若印入的精灵体超出框架内部边界，裁剪到框架内部。若两个精灵体印入区域重叠，受损坐标中行号较大的（即更靠近框架底部的）后绘制并覆盖先绘制的。

**生成约束**：至少 2 个受损坐标恰好对应占位符位置。框架内部尺寸与图块尺寸完全相同。每种占位符颜色都有对应精灵体和图例条目。

**关键洞察**：图块晶格不是被修复的对象——它的受损模式是一组编码信息，通过局部坐标系映射到框架中，选择性地激活占位符。求解者必须跨越两个空间系统（图块晶格与框架内部）进行坐标对齐推理，这种"一个结构的缺陷是另一个结构的指令"的关系在参考题中不存在。

## 新题 7：环绕平铺产生封闭区域触发边界分色

**组合逻辑**：[平铺 + 周期重复](已有) + [列环绕](创新：从阴影偏移的列环绕扩展为平铺后的拓扑连通性环绕) → [有孔触发重涂](已有) + [内外边界分色](已有)

**来源原语**：平铺/tiling(9b30e358), 周期重复/periodic_repeat(9b30e358), 种子图案/seed_motif(9b30e358), 列环绕/column_wrapping(310f3251), 描边/outline(aa4ec2a5/d931c21c), 有孔触发重涂/hole_presence_triggers_recolor(aa4ec2a5), 内外边界/inner_outer_bound(d931c21c), 内外边界分色/boundary_diff_color(d931c21c), 封闭孔洞/enclosed_hole(aa4ec2a5), 前景对象/foreground_object(aa4ec2a5)

**依赖链**：底部母题向上平铺填满网格 → 列环绕使左右边缘视为相邻 → 平铺后的蓝色前景可能围合出封闭背景区域 → 检测封闭区域 → 包围封闭区域的前景像素重涂为青色，封闭区域边界像素涂绿。平铺产生几何结构，环绕改变拓扑连通性，拓扑决定了哪些区域被封闭，封闭状态触发着色规则。

将底部母题向上周期平铺填满网格，以列环绕拓扑（左右边缘视为相邻）判定封闭背景区域，对围合出封闭区域的前景像素重涂色、对封闭区域的边界像素上色。

**输入结构**：约 12x12 网格。黑(0)背景。底部 3-4 行包含一个蓝(1)前景母题。母题在左侧边缘和右侧边缘附近都有像素，中间有间隔。母题不接触最左列和最右列的所有行（即母题像素在左右边缘附近但不一定在第 0 列或最后一列）。母题上方的行全部为背景(0)。

**规则**：
1. 将底部母题行块向上周期复制，填满整个网格（保持列对齐，每次复制母题行块的完整高度）。原始底部母题所在行保持不变。
2. 平铺完成后，计算连通性时采用列环绕拓扑：最右列的像素与最左列的像素视为水平相邻（即网格在水平方向形成圆柱面）。
3. 在此环绕拓扑下，找出所有 4-连通的背景(0)区域。将不接触网格顶行和底行的背景区域标记为"封闭区域"（因为列环绕使左右边不算开放边界，所以仅顶/底行是开放边界）。
4. 对每个封闭区域：将与该封闭区域 4-相邻的蓝(1)前景像素重涂为青(8)。
5. 对每个封闭区域内部的背景像素：若该像素与青(8)像素（含刚重涂的）8-相邻，则涂为绿(3)。
6. 不与任何封闭区域相邻的蓝(1)前景像素保持蓝(1)不变。
7. 非封闭的背景区域保持黑(0)。

**生成约束**：母题设计保证：在列环绕拓扑下至少存在一个封闭背景区域，但在非环绕拓扑下该区域不封闭（即该区域的封闭性依赖于左右边缘的环绕连通）。母题内部（单次复制）不包含封闭区域。

**关键洞察**：列环绕将平面网格的拓扑从矩形变为圆柱面——左侧边缘附近的母题像素与右侧边缘附近的像素在平铺后"接合"，围成原本不存在的封闭腔体。求解者必须意识到左右边缘在判定封闭性时被视为相邻，这在非环绕视角下不成立。

## 新题 8：标记段频率筛选门控碎片矩形补全

**组合逻辑**：[计数](已有) + [频率匹配](已有，但从直接驱动柱状图改为充当碎片激活门) → [移动 + 补全](已有，碎片拼成矩形) ← [频率等于标记数](已有，充当选择条件)

**来源原语**：计数/counting(2685904e), 频率匹配/frequency_matching(2685904e), 频率等于标记数/frequency_equals_marker_count(2685904e), 标记段/marker_run(2685904e), 分隔行/separator_row(2685904e), 编码行/code_row(2685904e), 移动/move(fe45cba4), 补全/complete(fe45cba4), 碎片/fragment(fe45cba4), 锚定物体/anchor_object(fe45cba4), 互补拼合/complement_fit(fe45cba4), 同色碎片拼成矩形/same_color_join(fe45cba4), 碎片触边锚不触边/frag_edge_anchor(fe45cba4)

**依赖链**：计数标记像素得 N → 编码行中找出出现恰好 N 次的颜色 → 仅这些颜色的碎片对被"激活" → 激活的碎片对执行移动补全成矩形 → 未激活碎片对保持原位。频率匹配充当空间操作的门控条件，计数来自一个独立结构（标记段），作用于另一个独立结构（碎片对）——两个原本无关的子系统通过频率阈值耦合。

统计标记像素数量 N，在编码行中筛选出出现恰好 N 次的颜色，仅允许同色碎片对中颜色被筛中的执行移动补全成矩形，其余碎片对保持原位。

**输入结构**：约 15x18 网格，分为上下两个区域。
- 上区：一条全宽灰(5)分隔行。分隔行上方有一段连续的橙(7)标记段（N 个像素的水平连续同色块，N 在 2-5 之间）。分隔行下方一行为编码行，包含多种颜色的像素（如红(2)、蓝(1)、绿(3)、黄(4)），每种颜色出现不同次数，分布在不同列。
- 下区：3-4 对同色碎片。每对中一个碎片（4-连通不规则形状，3-8 像素）触及网格左边界，另一个碎片（锚定物体）远离任何边界。每对颜色各不相同，与编码行中的某些颜色对应。每对碎片可通过平移拼合成一个实心轴对齐矩形。

**规则**：
1. 计数分隔行上方橙(7)标记段的像素数，得到 N。
2. 在编码行中，找出出现次数恰好为 N 的所有颜色，记为激活色集合 S。
3. 对下区的每对碎片，若其颜色属于 S，则该对被"激活"。
4. 对每对激活碎片：将触边碎片平移到唯一使其与锚定物体合并为实心矩形的位置。擦除触边碎片的原始位置（设为背景色）。
5. 未激活的碎片对保持原位（触边碎片仍在边界，锚定物体不动）。
6. 上区（标记段、分隔行、编码行）保留在输出中。

**生成约束**：至少一种碎片颜色被激活，至少一种未被激活。每对激活碎片的补全矩形互不重叠，也不与未激活碎片重叠。编码行中至少有一种颜色的出现次数不等于 N。

**关键洞察**：频率匹配在参考题 2685904e 中直接驱动柱状图填充，此处改为"门控"角色——它不产生视觉输出，而是选择哪些碎片对有资格执行空间操作。求解者必须先完成计数和频率匹配（两个抽象操作），才能决定下区的哪些碎片会移动，两个子系统通过一个数值阈值产生了参考题中不存在的耦合。

## 新题 9：字形查表判定结果控制边界矩形平移方向

**组合逻辑**：[查表匹配](已有) → [对齐判定结果](已有，但从视觉标记改为隐式控制) → [平移](创新：平移方向由判定结果参数化) + [重复色才移动](已有)

**来源原语**：查表匹配/table_lookup(d8e07eb2), 对齐判定结果/alignment_verdict(d8e07eb2), 完整行列对齐/full_row_or_column_alignment(d8e07eb2), 字形单元格/glyph_cell(d8e07eb2), 查询行/query_row(d8e07eb2), 参考表/reference_table(d8e07eb2), 平移/translate(22208ba4), 重复色才移动/repeated_color_moves(22208ba4), 边界矩形/boundary_rectangle(22208ba4), 贴边定位/border_aligned(22208ba4)

**依赖链**：查询字形匹配参考表 → 判定匹配单元格是否构成完整行或列 → 行对齐则平移方向为水平、列对齐则为垂直 → 仅重复色矩形沿该方向内移。查表结果不是最终输出的一部分（不像参考题那样标绿），而是隐式地决定了一个几何操作的参数——求解者必须先解字形谜题，再用答案指导空间变换。

查询字形在参考表中匹配后判定是否构成完整行或列，该判定结果隐式决定下区边界矩形的平移方向（行对齐→水平内移，列对齐→垂直内移），仅重复色矩形执行平移。

**输入结构**：约 20x20 网格，由一条全宽红(2)水平带（2 像素高）分为上下两个区域。
- 上区：青(8)背景，两条全宽品红(6)分隔行。第一条分隔行上方为查询行，包含若干 5x5 字形单元格（每个单元格内有一个 3x3 彩色形状，颜色和形状各异）。两条分隔行之间为参考表，由 5x5 字形单元格排列成的矩阵（如 3x3 或 4x4 矩阵）。
- 下区：黑(0)背景，若干单色实心矩形触及网格的角落或边缘。其中恰好一种前景颜色出现为多个分离的 4-连通矩形（重复色），其余颜色各只出现一次（单例色）。

**规则**：
1. 将查询行中的每个字形（按颜色和 3x3 形状同时匹配）在参考表中查找。
2. 检查所有匹配的参考表单元格位置：若它们构成参考表中的一个完整行，判定为"行对齐"；若构成一个完整列，判定为"列对齐"；否则判定为"未对齐"。
3. 在上区的视觉反馈：用绿(3)填充匹配的参考表单元格内部背景。若判定为"行对齐"或"列对齐"，用绿(3)填充查询行带和第二条分隔行下方的判定带背景；若"未对齐"，用红(2)填充判定带背景。
4. 在下区执行矩形平移：
   - 若判定为"行对齐"：每个重复色矩形沿水平方向向内平移（远离其触及的竖直边界），平移距离等于该矩形自身宽度。
   - 若判定为"列对齐"：每个重复色矩形沿垂直方向向内平移（远离其触及的水平边界），平移距离等于该矩形自身高度。
   - 若判定为"未对齐"：不移动任何矩形。
5. 单例色矩形永不移动。重复色矩形从原位擦除（设为背景）后绘制到新位置。

**冲突解决**：若平移后的重复色矩形与单例色矩形重叠，重叠区域取重复色矩形的颜色。若两个平移后的重复色矩形重叠，后绘制的覆盖先绘制的（按矩形原始位置从左上到右下的顺序绘制）。

**生成约束**：查询字形恰好匹配参考表中构成一个完整行或一个完整列（不同时构成两者）。至少有两个重复色矩形分别触及不同的边界。

**关键洞察**：字形查表的判定结果不仅是一个视觉标记（绿色/红色填充），更隐式地控制了网格另一个区域中矩形的平移方向。求解者必须先解决字形匹配谜题、判断行/列对齐，再将这个二元决策应用到完全不同的空间操作上——两个看似独立的子任务通过一个隐式参数链接。

## 新题 10：孔洞面积排名配对孤立像素距离排名决定填色与桥接

**组合逻辑**：[描边 + 有孔触发重涂](已有) + [排序](创新：对孔洞面积和像素间距同时排序) → [连线 + 分色矩形桥接](已有) ← [长度排名](创新：扩展为双域排名配对)

**来源原语**：描边/outline(aa4ec2a5/d931c21c), 有孔触发重涂/hole_presence_triggers_recolor(aa4ec2a5), 封闭孔洞/enclosed_hole(aa4ec2a5), 前景对象/foreground_object(aa4ec2a5), 连通分量/connected_component(d931c21c), 排序/sort(97d7923e), 长度排名/length_ranking(97d7923e), 连线/draw_line(b7249182), 孤立像素/isolated_pixel(b7249182), 空心矩形/hollow_rectangle(b7249182), 中点对称/midpoint_symmetry(b7249182), 行列对齐/row_column_alignment(b7249182), 分色矩形桥接/split_rect_bridges_pixels(b7249182), 包含关系/containment(aa4ec2a5)

**依赖链**：检测孔洞 → 按孔洞面积排名 → 同时按孤立像素对间距排名 → 同名次配对 → 配对决定孔洞填充色（取配对像素对的颜色）和像素对桥接。排名在两个不同的度量域（面积 vs. 距离）上同步进行，产生非显然的一一对应关系——这种双域排名配对是参考题中不存在的结构关系。

检测含孔洞的蓝色前景对象并按孔洞面积排名，同时按间距排名孤立像素对，同名次配对后孔洞填充为配对像素对的颜色，像素对之间以同色桥接连通。

**输入结构**：约 16x16 网格。黑(0)背景。
- 3-4 个蓝(1) 4-连通前景对象，形状各异（每个对象 8-20 像素，形状不规则但保持连通性）。其中部分对象包围了一个或多个 4-连通黑色封闭孔洞（孔洞不触及网格边缘且仅与一个蓝色对象相邻）。包含孔洞的对象数量等于孤立像素对的数量。每个含孔对象仅包含一个孔洞，且各孔洞面积（像素数）互不相同。
- 与含孔对象数量相同的孤立像素对。每对由两个相同颜色的单像素组成（颜色非蓝非黑，如红(2)、绿(3)、黄(4)等），两像素共享同一行或同一列（水平或垂直对齐）。各对颜色各不相同，各对的像素间距（曼哈顿距离）互不相同。
- 不含孔洞的蓝色对象也可能存在。

**规则**：
1. 识别所有蓝(1)前景对象。检查每个对象是否包围了封闭的黑(0)孔洞。
2. 将含孔对象按其孔洞面积升序排名（最小孔洞 = 第 1 名，次小 = 第 2 名，...）。
3. 将孤立像素对按其像素间距升序排名（最短距离 = 第 1 名，次短 = 第 2 名，...）。
4. 将排名相同的含孔对象与孤立像素对配对。
5. 对每个配对：
   a. 将含孔对象的蓝色边框重涂为青(8)。
   b. 将该对象的封闭孔洞填充为配对像素对的颜色。
   c. 在配对像素对的两个像素之间绘制桥接：在两像素的中点位置放置一个分色空心矩形（矩形长轴沿像素对对齐方向，宽 3 像素、长为两像素间距的一半），矩形的靠近第一个像素的一半使用该对颜色，靠近第二个像素的一半也使用该对颜色（同色桥接）。连接线从每个像素延伸到矩形最近的边。
6. 不含孔洞的蓝色对象：绘制红(2)色 8-邻域描边（在对象外侧的背景像素上），对象本身保持蓝(1)。
7. 不含孔洞的蓝色对象不参与配对。

**处理顺序**：先绘制所有桥接和连接线，再绘制所有描边。若描边像素与桥接/连线像素重叠，描边优先。

**生成约束**：含孔对象数量等于孤立像素对数量（均为 2-4 个）。所有孔洞面积互不相同。所有像素对间距互不相同。无像素对的桥接路径穿过任何蓝色对象的边界框。

**关键洞察**：孔洞面积和像素间距是两个完全不同度量空间中的量，排名创造了一个非显然的一一对应——求解者必须分别测量所有孔洞面积和所有像素间距、各自排序、然后按名次配对，才能确定每个孔洞的填充色和每对像素的桥接关系。仅看单个示例时，配对看起来可能是任意的，必须对比多个示例才能发现排名配对规则。
