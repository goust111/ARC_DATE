## 新题 1：射线竞距填充空心框

**组合逻辑**：[射线延伸](从边界标记向网格内部发射) → [碰撞阻挡](射线遇空心框架边框停止) → [填充](框架内部以最短射线颜色填充) + [擦除](移除标记与射线痕迹)

**来源原语**：
- 射线延伸(ray_extend): 参考题 13f06aa5、689c358e
- 碰撞阻挡(collision_blocking): 参考题 1f642eb9
- 填充(fill): 参考题 902510d5
- 空心框架(hollow_frame): 参考题 8f215267
- 标记像素(marker_pixel): 参考题 13f06aa5、32597951、1f642eb9 等
- 画布边界(canvas_boundary): 参考题 1f642eb9
- 擦除(erase): 参考题 8f215267、902510d5 等

**依赖链**：射线从边界标记出发向内延伸，遇到空心框架边框时停止。射线的终点位置确定哪些框架被命中；当多条射线命中同一框架时，行进距离最短的射线独占填充权——距离不仅是"是否到达"的判断，更是颜色优先级的仲裁机制。删除射线则无法确定命中关系；删除距离比较则多射线命中时颜色不确定；删除填充则射线命中无后续效果。

根据边界标记发射的射线命中空心框架，每个被命中框架的内部以行进距离最短的射线颜色填充。

**输入结构**：
- 网格约 15x15，背景为黑(0)。
- 网格中散布 2~4 个空心矩形框架，每个框架由灰(5)的一像素宽边框围成，内部为黑(0)。框架之间互不重叠、互不相邻，每个框架边框尺寸在 3x3 到 6x6 之间。
- 网格四条边界上分布 3~5 个标记像素，每个标记颜色互不相同（从红(2)、绿(3)、蓝(1)、黄(4)、橙(7)中选取），位于边界的非角落位置。
- 生成约束：每个标记沿朝向网格内部的方向延伸的直线必须经过至少一个框架的边框像素；不同标记的射线在到达各自第一个框架之前不会互相交叉；至少存在一个框架被两条以上射线命中（以触发距离仲裁规则）。

**规则**：
1. 对每个边界标记像素，沿其朝向网格内部的唯一方向（上边界标记向下，下边界标记向上，左边界标记向右，右边界标记向左）逐像素延伸射线。
2. 射线遇到任何灰(5)框架边框像素时立即停止（终点不含该边框像素本身）。记录射线颜色、行进距离（标记到终点的曼哈顿距离）、以及被命中的框架。
3. 对每个被至少一条射线命中的框架：若仅一条射线命中，填充色为该射线颜色；若多条射线命中，填充色为行进距离最短的射线的颜色（生成约束保证无平局）。
4. 用填充色填满该框架内部所有黑(0)像素（边框灰(5)保持不变）。
5. 擦除所有射线路径上的像素和边界标记像素（恢复为黑(0)）。
6. 未被任何射线命中的框架保持原状（空心）。

**关键洞察**：射线的行进距离不仅决定"是否命中"，还在多射线竞争同一框架时充当颜色优先级的仲裁——标记与框架之间的空间距离隐式编码了颜色的优先级排序，必须对比多个示例中不同距离竞争的胜负才能归纳此规则。

## 新题 2：方向编码旋转印章

**组合逻辑**：[质心偏移定向](检测方向精灵体朝向) → [同色匹配](配对精灵体与锚点) → [旋转](方向映射为旋转角度) + [印章覆盖](旋转后的固定图案粘贴至锚点) + [擦除](移除精灵体)

**来源原语**：
- 质心偏移定向(centroid_bias_dir): 参考题 13f06aa5
- 方向精灵体(directional_sprite): 参考题 13f06aa5
- 同色匹配(same_color_matching): 参考题 8f215267
- 旋转(rotate): 参考题 7fe24cdd
- 印章覆盖(stamp): 参考题 a9f96cdd
- 锚点像素(anchor_pixel): 参考题 a9f96cdd
- 固定图案(fixed_pattern): 参考题 a9f96cdd
- 擦除(erase): 参考题 8f215267、902510d5 等

**依赖链**：方向精灵体的质心偏移编码朝向，朝向被重新解释为固定图案的旋转角度（源题中朝向用于射线方向，此处用于旋转控制）。颜色匹配将每个精灵体绑定到一个锚点，确定图案粘贴位置。删除方向检测则旋转角度不确定；删除颜色匹配则锚点与精灵体的对应关系不确定；删除印章则最终输出无法生成。三者缺一不可。

方向精灵体的朝向决定旋转角度，通过颜色匹配将旋转后的固定图案印在对应锚点上。

**输入结构**：
- 网格约 18x18，背景为黑(0)。
- 网格中有 2~4 个方向精灵体，每个由灰(5)像素组成的 8-连通非对称小图形（5~7 像素），其质心相对几何中心有明确偏移方向。每个精灵体内部嵌入一个唯一颜色的标记像素（从红(2)、蓝(1)、绿(3)、黄(4)中选取，各精灵体标记颜色互不相同）。
- 所有精灵体具有相同的灰(5)像素形状模板，但各自旋转了不同的 90 度倍数（0、90、180、270 度之一），使质心偏移方向分别朝上、右、下、左之一。
- 网格中另有与精灵体等数量的孤立锚点像素，每个锚点颜色与恰好一个精灵体的标记颜色相同。锚点周围 3x3 邻域内无其他非背景像素，且与所有精灵体间距至少 4 像素。
- 生成约束：精灵体数量等于锚点数量，颜色一一对应；各精灵体的旋转角度互不相同。

**规则**：
1. 对每个方向精灵体，计算其灰(5)像素质心相对于其标记像素的偏移方向。质心偏离标记的方向为"尾部方向"，反方向为"指向方向"（上、右、下、左之一）。
2. 将指向方向映射为旋转角度：上对应 0 度，右对应 90 度顺时针，下对应 180 度，左对应 270 度顺时针。
3. 对每个锚点像素，找到与之颜色相同的精灵体，读取其旋转角度。
4. 固定的 3x3 图案定义为：位置 (0,0) 和 (0,1) 为橙(7)，位置 (2,2) 为品红(6)，其余为黑(0)（即左上角两像素为橙，右下角一像素为品红）。将此图案按步骤 2 的角度顺时针旋转后，以锚点为中心粘贴到网格上（锚点对应图案的中心位置 (1,1)）。
5. 擦除所有方向精灵体的全部像素（灰像素和标记像素恢复为黑(0)）。

**关键洞察**：同一个几何特征（质心偏移）在源题中编码射线发射方向，在本题中被重新解释为印章图案的旋转角度——方向精灵体不发射任何射线，而是充当旋转指令的载体，需要对比多个示例中不同朝向对应的不同旋转结果才能归纳此映射。

## 新题 3：重力聚集后计数构建角落三角

**组合逻辑**：[重力下落](对象下落至障碍物上方) → [计数](统计着陆对象总数) → [众数颜色](确定填充色) → [填充三角区域](在标记角落绘制三角) + [擦除](清除对象与障碍物)

**来源原语**：
- 重力下落(gravity_drop): 参考题 825aa9e9
- 可动对象(movable_object): 参考题 825aa9e9
- 障碍物(obstacle): 参考题 825aa9e9
- 邻接阻挡(adjacency_blocking): 参考题 825aa9e9
- 计数(counting): 参考题 8f215267、ff2825db
- 计数决定尺寸(count_determines_size): 参考题 902510d5
- 众数颜色决定输出(majority_color_out): 参考题 ff2825db
- 角落控制点(corner_control): 参考题 902510d5
- 三角区域(triangle_region): 参考题 902510d5
- 填充(fill): 参考题 902510d5
- 擦除(erase): 参考题 8f215267、902510d5 等

**依赖链**：重力下落决定对象最终位置和着陆状态。只有成功着陆的对象参与计数，计数结果决定三角形边长。着陆对象中出现次数最多的颜色决定三角形填充色。角落控制点决定三角形朝向。重力作为计数的前置空间筛选器，计数同时喂入几何尺寸和颜色选择两条分支，形成不可跳步的多环依赖。

彩色对象在重力作用下着陆后被计数，计数值成为从标记角落绘制的实心三角形的边长，三角颜色取自着陆对象中的众数颜色。

**输入结构**：
- 网格约 14x14，背景为黑(0)。
- 网格底部 1~2 行有灰(5)障碍物像素，形成不规则地板（非完整行，有若干间断）。
- 网格上半区散布 3~6 个可动小对象，每个为 4-连通单色图形（2~4 像素），颜色从红(2)、蓝(1)、绿(3)中选取。至少使用两种颜色，其中一种颜色的对象数量严格多于其他任何颜色。
- 恰好一个角落像素为黄(4)，标记三角形的起始角（四个角落中的某一个），其余三个角落为黑(0)。
- 生成约束：每个可动对象正下方的垂直路径上至少存在一个障碍物像素，使所有对象在重力下落后均可着陆而不会落出网格底部；各对象下落后不会互相重叠。

**规则**：
1. 对每个可动对象，整体向下平移，每次一行，直到该对象的任一像素正下方一行处为障碍物像素或已着陆对象像素时停止。处理顺序：按对象底部像素的行号从大到小（最低的先落）。
2. 统计成功着陆的可动对象总数 N。
3. 确定着陆对象中出现频率最高的颜色 C（按对象个数计，非像素数；生成约束保证无平局）。
4. 擦除网格中所有可动对象像素和所有灰(5)障碍物像素（恢复为黑(0)）。
5. 以黄(4)控制点所在角落为顶点，绘制边长为 N 的实心直角三角形：两条直角边分别沿该角落的水平和垂直边界方向延伸，填充所有满足"到该角落的行距 + 列距 < N"的像素，颜色为 C。
6. 黄(4)控制点本身被颜色 C 覆盖。

**关键洞察**：重力下落不只是视觉变换，更是计数的前置筛选器——对象的起始位置和障碍物形态共同决定着陆后的堆叠布局，而着陆后的对象数量和颜色分布同时决定三角形的两个独立参数（边长与颜色），必须通过多示例对比才能区分"边长由数量决定"还是"由像素总数决定"。

## 新题 4：周期行图案在十字遮罩下的联合推断与修复

**组合逻辑**：[周期平移推断](从未损伤行归纳垂直周期和水平偏移) <-> [补全](用推断的周期规律填充被遮罩破坏的像素) — 同时约束满足结构

**来源原语**：
- 周期平移(periodic_translation): 参考题 53b68214
- 行图案(row_pattern): 参考题 53b68214
- 周期偏移延续行(period_shift_rows): 参考题 53b68214
- 补全(complete): 参考题 b7955b3c、e7639916
- 十字遮罩(cross_mask): 参考题 b7955b3c
- 从平行行列推断(infer_from_parallel): 参考题 b7955b3c

**依赖链**：网格行图案遵循周期性水平偏移规律，但部分像素被灰(8)十字遮罩破坏。修复遮罩需要已知的周期参数，推断周期需要忽略受损行。两步互相依赖形成同时约束：必须在"跳过损伤区"和"利用周期关系"之间交替推理，先从完好行对中归纳参数，再用参数重建损伤像素。

网格行遵循周期性水平偏移规律但被十字形遮罩局部破坏，需从未损伤行推断周期参数并修复所有损伤像素。

**输入结构**：
- 网格约 12x12，背景为黑(0)。
- 前景使用红(2)，每行有若干红像素形成一维图案。行图案遵循周期规律：存在垂直周期 P（2 或 3）和水平偏移 S（1 或 2），第 r 行的图案等于第 (r - P) 行的图案整体右移 S 个像素（偏移后超出右边界的像素消失，不回绕）。
- 网格中有 1~2 个灰(8)十字遮罩（每个为 3x3 十字形：中心像素加上下左右各一像素共 5 像素），遮罩覆盖的像素被替换为灰(8)，遮盖了原始的黑(0)或红(2)值。
- 生成约束：至少存在两对完全未被遮罩影响的连续行（行号差为 P 的行对），使得周期 P 和偏移 S 可从中唯一确定；偏移后的图案在所有行中均不触及网格右边界（即最右侧红像素距右边界至少 S 列），避免回绕歧义。

**规则**：
1. 识别所有灰(8)像素为损伤位置，标记为"未知"。
2. 从完全不含灰(8)的行中，寻找使所有未损伤行对满足"第 r 行 = 第 (r - P) 行整体右移 S 像素"的唯一 (P, S) 参数对。
3. 对每个灰(8)像素 (r, c)：沿周期方向查找参考行 r' = r - P（若 r - P < 0 则用 r + P），读取位置 (r', c - S) 处的像素值（若 c - S < 0 则填黑(0)），将该值写入 (r, c)。
4. 若参考行 r' 的对应位置本身也是灰(8)（即参考位置也被遮罩），则递归查找 r - 2P 或 r + 2P，直到找到未损伤的参考像素（生成约束保证递归必然终止）。

**关键洞察**：源题 b7955b3c 的遮罩修复靠行列内容重复直接复制，源题 53b68214 的周期延续不涉及任何损伤。本题将两者交织为同时约束——遮罩破坏了周期的直接观察，求解者必须先在完好行对中归纳周期参数，再用该参数跨行重建损伤内容，形成"推断规则"与"应用规则"相互依赖的非线性推理结构。

## 新题 5：路径路由的图例重涂色

**组合逻辑**：[路径追踪](追踪引导路径确定图例与目标的绑定) → [颜色替换映射](从绑定的图例读取替换规则) → [重涂色](对目标对象执行颜色替换) + [擦除](移除路径和图例)

**来源原语**：
- 路径追踪(path_follow): 参考题 9ba4a9aa
- 引导像素(guide_pixel): 参考题 9ba4a9aa
- 路径连接(path_connected): 参考题 9ba4a9aa
- 终点相邻(endpoint_adjacent): 参考题 9ba4a9aa
- 颜色替换映射(color_sub_map): 参考题 e9b4f6fc
- 微型图例(micro_legend): 参考题 e9b4f6fc
- 图例色替换(legend_color_replace): 参考题 e9b4f6fc
- 重涂色(recolor): 参考题 e9b4f6fc、ff2825db、32597951
- 多色目标对象(multicolor_target): 参考题 e9b4f6fc
- 擦除(erase): 参考题 8f215267、902510d5 等

**依赖链**：网格中有多个多色目标对象和多个图例色块，但哪个图例作用于哪个对象不由空间临近度决定，而由引导像素组成的路径连接决定。路径追踪建立绑定关系，图例读取提供颜色替换规则，重涂色在绑定目标上执行。三步缺一不可：无路径则绑定不确定，无图例则替换规则不确定，无重涂色则路径和图例无后续效果。

引导像素路径将分散的颜色图例路由到各自的多色目标对象，每个对象仅按其路径连接的图例执行颜色替换。

**输入结构**：
- 网格约 20x20，背景为黑(0)。
- 网格中有 2~3 个多色目标对象，每个为 4-连通的紧凑区域（8~15 像素），使用 2~3 种非背景颜色（如蓝(1)+红(2)、绿(3)+黄(4)等）。各目标对象互不相邻，间距至少 3 像素。
- 网格中有与目标对象等数量的水平二像素图例色块（1x2 domino），每个图例左像素为替换色、右像素为被替换色。图例的被替换色（右像素）恰好出现在一个目标对象中，替换色（左像素）不出现在任何目标对象中。
- 各图例与其对应的目标对象之间由灰(5)引导像素组成的路径连接。路径上相邻引导像素间水平或垂直间隔恰好 2 个单元格（中间隔一个空像素）。每条路径的一端与恰好一个图例 8-相邻，另一端与恰好一个目标对象 8-相邻。
- 不同路径不共享引导像素，路径之间不交叉、不相邻。
- 生成约束：每个目标对象恰好连接一条路径通向一个图例，每个图例恰好连接一条路径通向一个目标对象；一一对应。

**规则**：
1. 找到所有灰(5)引导像素，按两像素间距的 4-连通关系（水平或垂直方向间隔恰好 2 个单元格的引导像素视为连通）将它们分组为独立路径。
2. 对每条路径，找到与路径端点 8-相邻的图例色块和目标对象，建立图例-目标绑定。
3. 对每个绑定的目标对象：读取其图例的左像素颜色（替换色 R）和右像素颜色（被替换色 S），将目标对象中所有颜色为 S 的像素替换为 R，其他颜色保持不变。
4. 擦除所有图例色块和引导像素（恢复为黑(0)）。
5. 未被任何路径连接的目标对象（如有）保持不变。

**关键洞察**：源题中图例通过空间临近或全局颜色匹配自动绑定到唯一目标；本题中绑定关系被编码在路径拓扑中——相同的图例如果连接到不同路径会作用于完全不同的对象，迫使求解者先追踪路径再执行颜色替换，而非直接根据颜色对应关系推断。

## 新题 6：计数驱动的原型非均匀拉伸

**组合逻辑**：[计数](统计各行带/列带中的锚点数) → [计数决定尺寸](计数值作为各方向独立拉伸因子) → [拉伸](按非均匀因子拉伸紧凑原型) + [擦除](输出仅含拉伸结果)

**来源原语**：
- 计数(counting): 参考题 8f215267、ff2825db
- 计数决定尺寸(count_determines_size): 参考题 902510d5
- 拉伸(stretch): 参考题 b0f4d537
- 紧凑原型(compact_prototype): 参考题 b0f4d537
- 稀疏骨架锚点(sparse_anchor): 参考题 b0f4d537
- 行列独立拉伸(independent_stretch): 参考题 b0f4d537
- 顶点坐标映射(vertex_coord_mapping): 参考题 b0f4d537（改造：坐标用于分带而非直接映射）
- 擦除(erase): 参考题 8f215267 等

**依赖链**：源题 b0f4d537 中锚点的空间坐标直接给出拉伸后的顶点位置，拉伸比例由坐标差隐式确定。本题中锚点坐标仅用于分组归带，拉伸因子由各带中的锚点数量决定——同样的锚点布局若数量分布不同会产生完全不同的拉伸结果。计数喂入拉伸参数，拉伸依赖计数结果，两者不可跳步。

锚点在各行带和列带中的数量决定对应方向的拉伸因子，紧凑原型按这些因子独立拉伸后输出。

**输入结构**：
- 网格约 16x16，背景为黑(0)。上下两个面板由一整行灰(5)横线分隔。
- 上面板包含一个紧凑原型（3x3 至 4x4），由多种颜色的像素组成（如蓝(1)和红(2)的线段交叉构成简单图形）。原型行数为 R，列数为 C。
- 下面板包含若干黄(4)锚点像素。锚点按行自然分为 R 个行带（对应原型的 R 行），按列自然分为 C 个列带（对应原型的 C 列）。行带之间和列带之间有明确间隔（至少 2 行/列的空白间隙），使分带归属无歧义。
- 生成约束：每个行带中的锚点总数为 1~3 的整数，每个列带中的锚点总数为 1~3 的整数。不同行带的锚点数允许不同，不同列带的锚点数允许不同。至少有两个行带或两个列带的锚点数不同（否则拉伸退化为均匀缩放，太简单）。

**规则**：
1. 识别上面板中的紧凑原型，确定其行数 R 和列数 C。
2. 将下面板的黄(4)锚点按行坐标聚类为 R 个行带（按行带从上到下的顺序对应原型的第 1 行到第 R 行），按列坐标聚类为 C 个列带（从左到右对应原型第 1 列到第 C 列）。
3. 统计第 i 个行带中的锚点总数为行拉伸因子 H_i，第 j 个列带中的锚点总数为列拉伸因子 W_j。
4. 构建输出网格（大小为 sum(H_i) x sum(W_j)）：原型的像素 (i, j) 被扩展为 H_i x W_j 的矩形块，填充原型 (i, j) 的颜色。各矩形块按行列顺序紧密排列。
5. 输出仅包含拉伸后的原型，不包含锚点、分隔线或面板结构。

**关键洞察**：源题中锚点的空间坐标直接编码拉伸后的目标位置（位置差 = 拉伸量），本题中锚点的坐标仅用于判断归属哪个带，而每带中的锚点个数才是拉伸控制参数——从"坐标映射"到"计数映射"的转变是核心创新，需要对比多个示例才能发现锚点数量（而非位置）决定了拉伸因子。

## 新题 7：箭头朝向分叉选择图例与端点

**组合逻辑**：[横杆偏移定方向](检测箭头精灵朝向) →分叉→ 分支1: [射线延伸至框架端点](确定涂色位置) + 分支2: [方向选择边缘图例](确定涂色颜色) →汇合→ [重涂色](端点涂为图例替换色) + [擦除](移除箭头和图例)

**来源原语**：
- 箭头精灵(arrow_sprite): 参考题 689c358e
- 横杆偏移定方向(crossbar_determines): 参考题 689c358e
- 矩形边框(rectangular_frame): 参考题 689c358e
- 边框端点(frame_endpoint): 参考题 689c358e
- 射线延伸(ray_extend): 参考题 13f06aa5
- 朝向对齐(orientation_aligned): 参考题 689c358e
- 微型图例(micro_legend): 参考题 e9b4f6fc
- 颜色替换映射(color_sub_map): 参考题 e9b4f6fc
- 重涂色(recolor): 参考题 e9b4f6fc、689c358e
- 擦除(erase): 参考题 8f215267 等

**依赖链**：箭头精灵的横杆偏移同时编码两条独立信息：（1）射线发射方向，确定命中框架的哪个端点（涂色位置）；（2）箭头面朝的边缘方位，确定从四条边缘中的哪一条读取图例（涂色颜色来源）。这两条信息在端点涂色时汇合。单独知道端点位置而不知图例则颜色不确定；单独知道图例而不知端点则位置不确定；不检测方向则两者都不确定。方向是分叉节点，端点涂色是汇合节点，构成分叉-汇合的非线性依赖图。

框架内的箭头精灵通过朝向同时确定射线命中的框架端点和所选用的边缘图例，端点被涂上图例对箭头体色的替换结果色。

**输入结构**：
- 网格约 15x15，最外层为灰(5)的一像素宽矩形边框。边框内部背景为黑(0)。
- 框内有 2~3 个箭头精灵，每个由灰(5)像素组成：一条长度 4 的主杆和一条长度 3 的横杆，横杆距主杆短端一侧偏移一个像素（共约 6 个灰像素）。每个箭头内嵌一个唯一颜色的标记像素（体色），如红(2)、蓝(1)、绿(3)等，各箭头体色互不相同。各箭头朝向不同方向（从上、下、左、右中选取互不相同的方向）。
- 边框的四条边外侧各紧贴放置一个水平二像素图例色块（1x2 domino）：上边外侧居中放在边框正上方一行，下边外侧居中放在边框正下方一行，左边外侧居中放在边框正左方一列（垂直排列的 2x1），右边外侧居中放在边框正右方一列（垂直排列的 2x1）。每个图例的第一个像素（上/左图例为上/左像素，下/右图例为下/右像素）为替换色，第二个像素为源色。
- 生成约束：每个箭头的体色恰好等于其朝向所指边缘的图例的源色；四个图例的源色各不相同，恰好覆盖所有箭头体色（未被箭头使用的图例的源色不出现在任何箭头中）。

**规则**：
1. 对每个箭头精灵，通过横杆相对主杆的偏移确定其指向方向 D（横杆偏向的一端为尾部，反方向为指向方向）。
2. 沿方向 D 从箭头主杆前端逐像素延伸射线，直到命中灰(5)边框像素。该边框像素为端点 E。
3. 读取方向 D 对应的边缘外侧图例色块，获取替换色 R 和源色 S。
4. 将端点 E 的颜色从灰(5)改为 R。
5. 擦除所有箭头精灵（灰像素和标记像素恢复为黑(0)）和所有图例色块（恢复为黑(0)）。
6. 边框其余灰(5)像素保持不变。

**关键洞察**：箭头朝向是一个分叉决策节点——它同时决定"在哪里涂"（端点位置由射线确定）和"涂什么颜色"（图例由方向选择），这两条信息路径在端点涂色处汇合。单独追踪任何一条路径都只能获得部分信息，必须同时解读方向的双重含义才能确定完整输出。

## 新题 8：标记计数决定瓦片旋转角度的拼图

**组合逻辑**：[计数](统计每个瓦片中的标记像素数) → [旋转](计数值映射为旋转角度) + [擦除](移除标记和分隔线) → [拼接](旋转后的瓦片组装为紧凑拼图)

**来源原语**：
- 计数(counting): 参考题 8f215267、ff2825db
- 旋转(rotate): 参考题 7fe24cdd
- 拼接(concatenate): 参考题 7fe24cdd
- 阵列排布(array_layout): 参考题 7fe24cdd
- 四旋转组成风车(rotations_pinwheel): 参考题 7fe24cdd（改造：旋转角度不由位置硬编码而由计数决定）
- 网格分区(grid_partition): 参考题 6d0160f0
- 瓦片(tile): 参考题 6d0160f0
- 分隔线(separator_line): 参考题 6d0160f0
- 标记像素(marker_pixel): 参考题 32597951、6d0160f0 等
- 擦除(erase): 参考题 8f215267 等

**依赖链**：源题 7fe24cdd 的旋转角度由瓦片在网格中的位置硬编码（左上=0度等），不需任何推理。本题中旋转角度由各瓦片内部的标记像素数量编码，必须先计数才能确定旋转，标记擦除后才能获得干净的瓦片用于拼接。计数→旋转→拼接形成三步不可跳步链：删除计数则旋转角度不确定；删除旋转则拼接内容不确定；删除擦除则标记污染输出图案。

2x2 网格的四个瓦片各含不同数量的标记像素，标记数（0~3）指定该瓦片的顺时针旋转次数，擦除标记后按旋转角度在原位组装为最终拼图。

**输入结构**：
- 网格为 (2N+1) x (2N+1)（N 约 4~6），中央有灰(5)十字分隔线（一整行 + 一整列）将网格分为四个 NxN 瓦片（左上、右上、左下、右下）。
- 四个瓦片共享同一个基础图案（由蓝(1)和红(2)像素组成的非对称 4-连通图形，约 4~8 像素），基础图案在每个瓦片中放置于相同的本地坐标位置，其余本地位置为黑(0)背景。
- 每个瓦片中额外有 0~3 个黄(4)标记像素，放置在该瓦片内基础图案之外的黑(0)位置上。四个瓦片的标记数量互不相同，恰好是 {0, 1, 2, 3} 的某种排列。
- 生成约束：基础图案不具有 90 度旋转对称性（即旋转 90 度后与原图案不同，确保不同旋转角度产生可区分的结果）；标记像素不位于瓦片的旋转中心上。

**规则**：
1. 识别灰(5)分隔线，将网格分为四个 NxN 瓦片，记录每个瓦片的位置（左上、右上、左下、右下）。
2. 对每个瓦片，统计其中黄(4)标记像素的数量 K（0、1、2 或 3）。
3. 擦除该瓦片中所有黄(4)标记像素（恢复为黑(0)）。
4. 将该瓦片顺时针旋转 K x 90 度（K=0 不旋转，K=1 旋转 90 度，K=2 旋转 180 度，K=3 旋转 270 度）。
5. 将四个旋转后的瓦片按其原始位置（左上、右上、左下、右下）紧密排列组装为 2N x 2N 的输出网格（不含分隔线）。

**关键洞察**：源题中旋转角度由瓦片在 2x2 网格中的位置硬编码（所有示例共享同一旋转方案），本题中旋转角度被隐式编码在瓦片内部的标记数量中——同一个图案携带不同数量的标记会产生不同的旋转输出，迫使求解者先计数再旋转，且必须对比多个示例才能归纳出"标记数 = 顺时针旋转次数"而非其他可能的映射（如"标记数 = 逆时针次数"或"标记数 = 缩放因子"等）。
