## 新题 1：双面板种子激活选择性填充

**组合逻辑**：[透明叠加 + 位置对齐](已有) → [封闭区域识别](已有，创新应用于叠加后的种子检测) → [填充](已有，由种子激活条件门控) → [计数 + 区域数映射长度](已有，创新用于编码激活数量)

**来源原语**：透明叠加/位置对齐/双面板背景交集(0c9aba6e)、封闭区域(89565ca0)、填充/角标记/矩形(af902bf9)、计数/区域数映射长度(89565ca0)

**依赖链**：面板对齐确定标记与区域的空间对应 → 封闭区域几何定义填充边界 → 标记落点决定哪些区域被激活 → 激活区域数量编码为附加输出条

一句话总结：将下面板的标记像素叠加到上面板，仅填充含标记的封闭区域，并在底部附加一段表示激活区域数的色条。

**输入结构**：约 15x7 网格（两个 7x7 面板 + 1 行灰(5)分隔行）。黑(0)背景。上面板：绿(3)单像素宽线段构成 2-4 个互不相交的闭合矩形框（框内像素均为黑色），每个框的边界框尺寸在 3x3 到 5x5 之间，框与框之间至少间隔 1 个像素。下面板：黄(4)单像素标记散布在黑色背景上，共 3-6 个，部分标记在位置对齐后落在上面板某些闭合框的内部区域，部分落在框外或框壁上。生成约束：每个闭合框至少有一个示例中含标记、至少有一个示例中不含标记，以确保规则可区分；不同示例中标记数量和位置不同，使得被激活的区域集合不同。

**规则**：
1. 移除灰(5)分隔行，将上下面板按列对齐。
2. 在上面板中识别所有由绿(3)像素完全围成的 4-连通黑(0)封闭区域（绿色边框像素不属于区域内部）。
3. 对于每个封闭区域，检查对齐后的下面板在相同位置集合中是否存在至少一个黄(4)像素。存在则该区域"被激活"。黄色像素落在绿色框壁上或框外的不计入任何区域。
4. 将所有被激活区域内的黑色像素填充为红(2)。未被激活的区域保持黑色。绿色框壁保持不变。
5. 输出为上面板尺寸（7x7）的网格，在其正下方拼接一行：该行从左起连续填充红(2)像素，数量等于被激活区域的总数，其余填黑(0)。

**关键洞察**：下面板并非简单的掩码——标记必须精确落在封闭区域内部才有效，落在框壁上或框外则被忽略。仅凭单个示例无法区分"填充所有区域"和"填充含标记的区域"，必须对比含标记区域不同的多个示例才能归纳出选择性激活规则。

## 新题 2：碎片重建走廊中的粒子追踪

**组合逻辑**：[合并对齐碎片 + 行列跨度重叠](已有) → [补全为空心矩形墙壁](创新：碎片合并后重建为框壁而非实心填充) → [路径追踪 + 碰撞转向 + 碰撞停止](已有) → [计数](已有，创新用于统计碰撞次数编码输出)

**来源原语**：合并对齐碎片/行列跨度重叠/残缺矩形/连通分量(8fbca751)、路径追踪/碰撞转向/碰撞停止/粒子/走廊(9bbf930d)、计数(89565ca0)、空心矩形(68bc2e87)

**依赖链**：碎片合并决定墙壁的边界框 → 边界框重建为框壁确定走廊拓扑 → 走廊拓扑决定粒子路径 → 路径中的碰撞次数编码为最终输出

一句话总结：先将散布的碎片按行列跨度合并并重建为空心矩形墙壁，再在墙壁间的走廊中追踪粒子路径，根据碰撞次数生成输出编码。

**输入结构**：约 18x18 网格。黑(0)背景。散布 10-20 个青(8)像素碎片，每个碎片为 1-3 个像素的 4-连通小块，分属 3-5 个逻辑组（同组碎片的边界框在行跨度或列跨度上有重叠，不同组之间无跨度重叠）。品红(6)单像素粒子 2-3 个，放置在网格左边界上不同行。生成约束：合并后每组碎片的边界框为 3x3 到 6x6 的矩形；不同组的边界框之间至少间隔 2 行 2 列，留出可通行的走廊；每个粒子的初始行都在某条走廊的通行范围内。

**规则**：
1. 对所有青(8)碎片进行传递性合并：两个碎片的边界框若在行跨度或列跨度上有交集，则合为一组；合并过程迭代至收敛。
2. 对每个合并组，取该组所有像素的总边界框，将该边界框的四条边（单像素宽边框）全部涂为青(8)，内部保持黑(0)——形成空心矩形墙壁。原始碎片中位于边框以内的像素被墙壁覆盖。
3. 每个品红(6)粒子从左边界出发，初始方向向右。粒子逐像素前进；当下一个像素为青(8)墙壁或网格边界时，粒子发生碰撞：若当前方向为水平则转为向下，若为垂直则转为向右（始终做顺时针 90° 转向）。转向后继续前进。若转向后的下一像素仍为墙壁或边界，粒子停止。
4. 每个粒子经过的所有像素（含起点，不含停止后未到达的下一格）涂为绿(3)。粒子原始的品红像素被绿色覆盖。
5. 统计所有粒子的碰撞总次数 K。在网格最右列从上往下连续涂 K 个橙(7)像素（若 K 超过网格高度则截断至网格高度）。若最右列某像素已为其他颜色，橙色覆盖之。

**关键洞察**：散落碎片的空间分布看似随机，但合并后形成的墙壁布局完全确定了走廊拓扑。仅看碎片无法直接判断走廊走向——必须先完成跨度合并和边框重建。碰撞计数依赖完整路径，而路径又依赖墙壁重建，三步不可分割。不同示例中碎片位置不同导致走廊拓扑不同，需对比多个示例确认"顺时针 90° 转向"这一非显然规则（而非总是向下或总是转向更宽的走廊）。

## 新题 3：格栅去噪后按单元对称性条件重涂色

**组合逻辑**：[擦除 + 完整行列为分隔线](已有) → [对称检测 + 镜像轴](已有，创新应用于格栅单元内容) → [重涂色](已有，由对称性判断结果决定涂色方案)

**来源原语**：擦除/分隔行列/格点交叉/噪声像素/完整行列为分隔线/行列交叉(95a58926)、对称检测/镜像轴/对称否决定输出色/图案(44f52bb0)、重涂色(09629e4f)

**依赖链**：去噪还原真实格栅线 → 格栅线定义单元边界 → 在每个单元中正确提取图案 → 对称检测决定输出颜色

一句话总结：清除格栅上的噪声像素以还原分隔线，对每个单元格内的图案进行水平镜像对称检测，根据对称性结果将图案重涂为不同颜色。

**输入结构**：约 15x15 网格。黑(0)背景。蓝(1)完整行和完整列构成格栅分隔线，将网格分为 3x3 或 4x4 的等大单元（每个单元约 3x3 到 4x4 像素）。橙(7)噪声像素散布在格栅线上和部分单元内（共 5-10 个噪声像素）。每个单元内有一个由红(2)像素构成的小图案（2-5 个像素的 4-连通形状），图案不触及单元边界。生成约束：不同示例中噪声像素位置不同；每个示例中至少有一个对称单元和一个不对称单元；格栅线完全由蓝色像素组成（噪声可能覆盖其中一些像素使其变橙）；单元内的红色图案不与噪声像素位置重叠。

**规则**：
1. 识别真正的格栅分隔线：若某行或某列上非黑像素（含蓝色和橙色）的总数等于该行/列的长度，则该行/列为分隔线。
2. 将所有橙(7)像素擦除为黑(0)。将所有分隔线行和列重涂为蓝(1)。分隔线交叉点（同时属于分隔行和分隔列的像素）涂为橙(7)。
3. 对每个单元，提取其内部区域（不含分隔线像素）中的红(2)图案。以单元中间行为水平镜像轴，检测图案是否具有上下镜像对称性（对称要求：第 i 行的红色像素列集合与倒数第 i 行的红色像素列集合完全相同，行数为奇数时中间行与自身比较）。
4. 对称的单元：将其内部红色图案重涂为绿(3)，黑色背景不变。不对称的单元：将其内部红色图案重涂为黄(4)。
5. 格栅线和交叉点颜色保持第 2 步的结果不变。

**关键洞察**：噪声像素可能恰好位于格栅线上，使格栅线看起来不完整，如果不先去噪就直接切分单元，单元边界会出错导致对称检测失败。去噪和对称检测虽是两个独立概念，但在此题中构成硬性前后依赖——只有正确去噪才能正确切分，只有正确切分才能正确检测。需对比多个示例才能确认对称→绿、不对称→黄的映射关系（单个示例中若碰巧所有单元都对称，则无法区分）。

## 新题 4：螺旋路径遇障碍跳跃与像素总量守恒

**组合逻辑**：[螺旋绘制 + 格点阵列 + 起点定位](已有) → [绕障重绘](创新：不绕行而是跳过障碍格点) → [像素数守恒 + 边界裁剪](已有，创新为螺旋尾部延伸补偿)

**来源原语**：螺旋绘制/格点阵列/起点定位/边界裁剪/前景像素(8b28cd80)、绕障重绘/障碍精灵体/像素数守恒/边界贴合(88bcf3b4)

**依赖链**：起点像素定位螺旋中心 → 螺旋路径生成遇障碍格点 → 跳过障碍像素 → 守恒约束要求尾部补偿延伸 → 延伸受边界裁剪限制

一句话总结：在格点阵列上从标记点绘制外展方形螺旋，遇到障碍格点时跳过，但通过在螺旋尾部延伸来保持总像素数不变，延伸不得超出网格边界。

**输入结构**：9x9 网格。黑(0)背景。一个红(2)前景像素位于 3x3 输入区域的某个位置（该 3x3 区域的 9 个格点映射到 5x5 格点阵列的偶数坐标节点）。另有 1-2 个蓝(1)障碍块，每个障碍为 1-2 像素的小块，占据 9x9 网格中的若干格点位置或边中点位置。生成约束：障碍不与红色起点重叠；障碍位于螺旋路径会经过的位置上（否则题目退化为无障碍情况）；起点不在阵列角落（以保证螺旋有足够展开空间）。

**规则**：
1. 将红色像素在 3x3 中的位置 (r, c) 映射到 5x5 格点阵列的节点 (2r, 2c)，作为螺旋起点。
2. 从起点开始绘制外展方形螺旋：按"上、右、下、左"的方向顺序，步长依次为 1, 1, 2, 2, 3, 3, ...。螺旋沿格点节点行进，相邻节点之间的边中点像素也一并绘制。
3. 计算无障碍情况下螺旋在 5x5 阵列边界内能绘制的总像素数 T（含节点和边中点，受边界裁剪限制）。
4. 绘制螺旋时，若某个即将绘制的像素位置被蓝色障碍占据，则跳过该像素（不绘制，不改变障碍颜色），螺旋继续沿原方向前进到下一位置。
5. 设实际跳过了 S 个像素。在螺旋原本的终止点之后，继续沿螺旋方向额外延伸 S 个像素（若延伸超出 9x9 网格边界则停止，不再补偿）。
6. 所有螺旋像素涂红(2)。障碍保持蓝(1)。其余保持黑(0)。

**关键洞察**：障碍不仅在局部挖去螺旋的一段，还通过守恒约束在远端改变了螺旋的延伸范围。仅看单个示例可能无法区分"障碍处跳过且尾部延伸"和"障碍处跳过但不延伸"——需对比障碍数量不同的示例观察尾部长度差异来归纳守恒规则。

## 新题 5：碎片合并重建框架后推断遮挡堆叠序

**组合逻辑**：[合并对齐碎片 + 行列跨度重叠](已有，创新应用于多色碎片) → [重建空心矩形](已有) → [遮挡层序 + 重叠定先后](已有) → [排序](已有，输出堆叠序列)

**来源原语**：合并对齐碎片/行列跨度重叠/残缺矩形/连通分量(8fbca751)、重建/空心矩形/重叠层/遮挡层序/重叠定先后(68bc2e87)、排序(f8ff0b80)

**依赖链**：同色碎片按跨度合并 → 每色合并后重建为空心矩形框 → 框间重叠像素的可见颜色确定遮挡关系 → 遮挡关系排序为堆叠序

一句话总结：多种颜色的离散碎片各自按行列跨度合并后重建为空心矩形框，根据框重叠处的可见颜色推断从底到顶的堆叠顺序，输出为单列色序。

**输入结构**：约 14x14 网格。黑(0)背景。3-4 种前景色（从红(2)、绿(3)、蓝(1)、黄(4)中选取），每种颜色有 3-6 个离散像素碎片（每个碎片 1-3 像素，4-连通）。同色碎片分布使得它们的边界框在行跨度或列跨度上可传递性重叠，最终合为一组。不同颜色的合并后边界框之间有部分重叠区域（重叠区域宽度至少 1 像素）。在输入中，重叠位置上只显示最顶层框架的颜色。生成约束：每种颜色的碎片合并后形成唯一一个边界框，尺寸在 4x4 到 8x8 之间；堆叠层序唯一（即从所有重叠关系可推出完整的全序排列）；至少有一组重叠关系需要通过合并后的框推断（即原始碎片在该重叠区域无可见像素，必须重建框后才知道该位置有重叠）。

**规则**：
1. 对每种前景色独立进行碎片合并：两个同色碎片若边界框在行跨度或列跨度上有交集则合为一组，传递性迭代至收敛。
2. 对每种颜色的合并组，取总边界框，重建为该颜色的空心矩形（边界框四边涂为该色，内部为黑色）。
3. 在所有重建矩形框的边重叠的像素位置，输入中该像素的颜色即为最顶层的颜色。若输入中该像素为黑色（原始碎片未覆盖但重建框会经过），则取输入中该行或该列最近的同色碎片来推断——但实际上重叠处总有至少一种颜色的原始碎片可见，因此可直接从输入读取顶层颜色。
4. 根据所有重叠像素的层级关系，推断唯一的从底到顶堆叠全序。规则：若颜色 A 在某重叠位置被颜色 B 遮挡（该位置输入为 B 但 A 的重建框也经过此处），则 A 在 B 之下。
5. 输出为 Nx1 的单列网格（N = 前景色数量），从上到下为从底到顶的颜色序列。

**关键洞察**：单纯的连通分量分析无法正确恢复矩形框——同框碎片可能不相连但行列跨度重叠。合并策略直接决定了重建出的框的大小和位置，进而决定了哪些位置存在重叠。错误的合并会导致错误的遮挡推断。需对比多个示例确认"行列跨度重叠即合并"而非"4-连通即合并"的规则。

## 新题 6：走廊长度查稀疏色表决定重涂色

**组合逻辑**：[路径追踪 + 碰撞停止](已有) → [计数](已有，创新为测量走廊路径长度) → [稀疏单元色查找表 + 位置索引](已有，创新为长度索引映射) → [重涂色](已有，用查表颜色涂轨迹)

**来源原语**：路径追踪/碰撞停止/走廊/粒子/碰撞转向(9bbf930d)、计数(89565ca0)、稀疏单元色查找表/位置索引/分隔栅格(09629e4f)、重涂色(09629e4f, a79310a0)

**依赖链**：各单元走廊拓扑决定粒子轨迹 → 轨迹长度作为索引 → 稀疏查找表将索引映射为颜色 → 用该颜色重涂整条轨迹

一句话总结：在分隔网格中，每个非查找单元内的粒子沿走廊运动直至停止，测量轨迹长度后到查找单元中按长度索引取色，将该色涂满整条轨迹。

**输入结构**：约 13x13 网格。灰(5)单像素宽分隔线将网格分为 3x3 排列的 9 个等大单元（每个单元约 3x3 像素内部空间）。左上角单元为查找单元：其内部在某些位置有不同颜色的单像素（从红(2)、蓝(1)、绿(3)、黄(4)中选取 3-4 种，每种恰好一个像素），其余位置为黑(0)。其他 8 个单元各为一个微型迷宫：灰(5)像素构成内部墙壁（1-3 个灰色像素），品红(6)单像素粒子位于单元内某边缘位置，其余为黑(0)通道。生成约束：查找单元中有色像素数 P 在 3-4 之间；每个迷宫单元的粒子轨迹长度（从起点到停止的像素数）在 1 到 P 之间，使得所有轨迹长度都能在查找表中找到对应颜色；不同示例中迷宫墙壁布局不同。

**规则**：
1. 识别查找单元（左上角，即第 0 行第 0 列的单元）。将其内部有色像素按行优先顺序编号为 1, 2, 3, ...（从上到下、从左到右扫描，遇到非黑像素则编号递增）。记录编号到颜色的映射。
2. 对其余每个单元，在该单元内部模拟粒子运动：粒子初始方向为朝向单元中心（若粒子在左边缘则向右，在上边缘则向下，在右边缘则向左，在下边缘则向上；若在角落则向右优先）。粒子逐像素前进，遇灰色墙壁或单元边界时停止（不转向，直接停止）。
3. 计算每个粒子的轨迹长度 L（含起点像素，含停止时所在像素）。
4. 用 L 作为编号，在查找单元的映射中找到对应颜色 C。
5. 将该单元内粒子的整条轨迹（所有 L 个像素）重涂为颜色 C。粒子原始品红色被覆盖。
6. 查找单元内容保持不变。灰色分隔线和灰色迷宫墙壁保持不变。

**关键洞察**：查找单元的空间布局编码了一张颜色表，而表的索引不是位置而是距离。每个走廊的几何结构决定了粒子能走多远，而这个距离反过来决定了走廊被涂成什么颜色。查找表和走廊是两个独立的几何结构，但通过"长度→索引→颜色"这条抽象链条紧密耦合。仅看单个示例无法确认索引规则（可能是长度、可能是碰撞数、可能是单元位置），必须对比多个走廊长度和颜色的对应关系。

## 新题 7：对齐精灵体后按面积优先级解决重叠并色板重映射

**组合逻辑**：[对齐 + 对齐到锚点 + 共享归一掩码](已有) → [面积排序](已有，创新为重叠冲突解决优先级) → [拼接 + 色板决定填色](已有，创新为精灵色到色板色的映射)

**来源原语**：对齐/对齐到锚点/共享归一掩码/精灵体/锚点像素(e41c6fd3)、面积排序/像素数量/前景色掩码/按像素数降序(f8ff0b80)、拼接/色板决定填色/纯色色板/模板掩码(15660dd6)

**依赖链**：锚点精灵体确定对齐目标行 → 对齐后精灵体在行方向重叠 → 面积排序决定重叠处的可见颜色 → 合成的可见掩码作为模板 → 色板映射将精灵体颜色替换为输出颜色

一句话总结：将多个同形异色精灵体垂直对齐到锚点精灵体所在行，按原始面积大者优先解决重叠，再用底部色板将每种精灵体颜色映射为新颜色输出。

**输入结构**：约 15x15 网格。黑(0)背景。4-5 个单色精灵体，每个精灵体由 4-7 个同色像素组成的 4-连通形状（所有精灵体归一化后形状相同——即平移到原点后掩码一致）。颜色分别取自蓝(1)、红(2)、绿(3)、黄(4)、品红(6)。其中一个青(8)精灵体为垂直对齐锚点。各精灵体在水平方向上互不重叠（列范围不交），但垂直位置各异。网格最底 1 行为色板行：对于每种非青精灵体颜色，在色板行中有一个 1x1 像素紧邻一个不同颜色的 1x1 像素（如在列 k 处品红(6)紧邻橙(7)，表示品红映射为橙），色板对之间间隔至少 1 个黑色像素。生成约束：对齐后至少两个精灵体的行范围有重叠；各精灵体的原始像素数不全相同（以区分优先级）；色板映射的目标颜色互不相同且不与任何精灵体颜色重复。

**规则**：
1. 识别青(8)精灵体，记录其顶行位置 R_anchor。
2. 对每个非青精灵体，保持其列范围不变，将其垂直平移使其顶行等于 R_anchor（如原顶行为 R_orig，则每个像素行坐标减去 R_orig - R_anchor）。青色精灵体保持原位。
3. 对齐后若多个精灵体覆盖同一像素位置，保留原始像素数最多的精灵体的颜色（像素数指该精灵体在输入中的总像素数，不是对齐后的可见像素数）。像素数相同时保留在输入中顶行更靠上的精灵体。
4. 解析色板行（最底 1 行）中的颜色映射对：每对由两个相邻非黑像素组成，左像素为源色（某精灵体颜色），右像素为目标色。
5. 在对齐后的合成图中，将每种精灵体颜色替换为其色板目标色。青(8)锚点精灵体无色板映射，保持青色。
6. 输出为去掉色板行后的网格（高度减 1）。

**关键洞察**：对齐创造了原本不存在的空间冲突，而解决冲突需要引入一个源自完全不同结构的属性（面积）。色板映射又是第三层独立逻辑——它不影响几何布局，只改变最终颜色。三层逻辑各自负责位置、可见性、颜色，缺一不可。需对比多个示例才能区分面积优先级规则和其他可能的优先级规则（如"右侧优先""颜色编号优先"等）。

## 新题 8：旋转对称补全后路径颜色反转

**组合逻辑**：[对称补全 + 四次旋转闭合](已有) → [端到端遍历 + 单像素宽路径](已有，创新为在旋转补全后的新拓扑上遍历) → [颜色序列反转 + 形状不变仅反色序](已有)

**来源原语**：对称补全/四次旋转闭合/旋转对称/正方形区域/前景图案(e40b9e2f)、端到端遍历/单像素宽路径/端点像素(5792cb4d)、颜色序列反转/形状不变仅反色序(5792cb4d)

**依赖链**：旋转补全改变路径拓扑（可能封闭开口或产生新端点）→ 新拓扑决定遍历方向和端点 → 颜色反转在新拓扑上操作

一句话总结：先将不完整的多色像素路径按四次旋转对称补全，然后沿补全后的完整路径从一端到另一端反转颜色序列。

**输入结构**：约 11x11 网格。黑(0)背景。一条多色单像素宽 4-连通路径（无分支，恰好两个端点），由 3-4 种前景色（如红(2)、蓝(1)、绿(3)、黄(4)）分段着色，每段 2-4 个像素。路径位于一个可识别的正方形区域内（正方形边长为奇数，5-9 像素）。路径像素在 0°/90°/180°/270° 旋转下无颜色冲突（即若位置 P 有色 C，则 P 的各旋转像在输入中要么与 P 同色要么为黑色）。路径是不完整的——旋转补全后会增加新的前景像素。生成约束：补全后的前景像素仍构成单像素宽 4-连通路径（无分支），且恰好两个端点（即补全不会产生环路或交叉）；补全后的路径至少比原路径多 30% 的像素；两个端点分别位于正方形的不同边上。

**规则**：
1. 找到包含所有前景像素的最小正方形区域 S（边长为奇数，中心为正方形中心点）。
2. 对 S 内的每个前景像素 P（颜色 C，位置 (r, c)），计算其关于 S 中心的 90°、180°、270° 旋转位置。将所有旋转位置若为黑色则涂为 C。
3. 补全后检查：所有前景像素应构成一条无分支的 4-连通路径，恰好两个端点（端点定义：4-连通前景邻居恰好 1 个的像素）。
4. 从两个端点中选取行坐标更小的（若行相同则选列坐标更小的）作为路径起点 A，另一个为终点 B。
5. 从 A 沿 4-连通路径遍历到 B，记录像素序列 [p1, p2, ..., pN] 及其颜色序列 [c1, c2, ..., cN]。
6. 将颜色序列反转：p1 涂 cN，p2 涂 c(N-1)，...，pN 涂 c1。路径形状不变。
7. 正方形区域外和黑色背景保持不变。

**关键洞察**：旋转补全和颜色反转各自都是简单操作，但补全改变了路径长度和拓扑，这使得反转作用在一条与原始输入完全不同的路径上。补全产生的新像素继承了源像素的颜色，但反转后这些颜色被重新分配到完全不同的位置。仅看输入路径的颜色分布无法推断输出——必须先补全再反转。需对比多个示例区分"直接反转原路径"和"先补全再反转"两种可能规则。
