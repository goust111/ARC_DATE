## 新题 1：异常精灵体充当像素放大模板

**组合逻辑**：[裁剪 + 图案匹配 + 异常值选择](从 cd3c21df 提取，用于推断模板而非直接输出) → [像素放大 + 颜色到模板映射](从 42f83767 提取，模板来源从显式图例改为异常值推断)

**来源原语**：裁剪/cropping(cd3c21df)、图案匹配/pattern_match(cd3c21df)、异常值选择/outlier_selection(cd3c21df)、忽略干扰项/ignore_distractors(cd3c21df)、像素放大/pixel_expand(42f83767)、模板遮罩/stencil_mask(42f83767)、索引网格/index_grid(42f83767)、颜色到模板映射/color_stencil_map(42f83767)、精灵体/sprite(88a10436, cd3c21df)

**依赖链**：异常值检测的结果（唯一精灵体的裁剪形状）直接决定像素放大时使用的模板遮罩。若异常值识别错误，模板形状错误，整个扩展输出全错。同时，索引网格的颜色映射依赖模板形状中哪些像素属于前景、哪些属于透明，两步信息不可分割。

从散布的精灵体中找出唯一不重复的那个，用其形状作为模板遮罩，将网格中的小型颜色索引矩阵逐像素放大为模板形状的色块拼图。

**输入结构**：黑(0)背景，约 20x20 网格。网格分为两个区域：上半区散布 5~7 个单色 4-连通精灵体（每个 4~8 像素，形状不规则，颜色各异），其中恰好有一个精灵体的包围盒裁剪图案在所有精灵体中仅出现一次，其余精灵体两两配对（同一裁剪图案各出现恰好两次）。下半区有一个 2x3 或 3x2 的小型密集色块矩阵（索引网格），每个单元格为一个非黑前景色像素，颜色从上半区精灵体使用的颜色中选取。生成约束：唯一精灵体的包围盒宽高均为奇数；索引网格的颜色仅使用上半区出现过的精灵体颜色。

**规则**：
1. 将上半区每个 4-连通精灵体裁剪到其最小包围盒，得到裁剪图案（包围盒内的背景像素视为透明，保留前景像素的相对位置）。
2. 比较所有裁剪图案（逐像素精确匹配，包括透明位置）。找出恰好出现一次的唯一裁剪图案，即异常精灵体。
3. 将该异常精灵体的裁剪图案作为模板遮罩 M（宽 W、高 H）：前景像素位置为"实心"，背景像素位置为"透明"。
4. 读取下半区的索引网格（R 行 C 列）。输出网格尺寸为 (R*H) x (C*W)。
5. 对索引网格中第 r 行第 c 列的像素颜色 K：在输出网格的子区域 [r*H .. (r+1)*H-1, c*W .. (c+1)*W-1] 内，将模板遮罩 M 中"实心"的位置涂为颜色 K，"透明"位置涂为黑(0)。
6. 上半区的所有精灵体不出现在输出中（输出仅由扩展后的索引网格构成）。

**关键洞察**：模板遮罩不是显式给出的图例，而必须通过异常值检测从多个精灵体中推断——裁剪图案的重复计数是唯一的筛选标准，与颜色、大小或位置无关。

## 新题 2：跨分隔线对齐参考色决定轮廓填充颜色

**组合逻辑**：[对齐比较 + 分隔线 + 参考像素](从 7d7772cc 提取，空间对齐逻辑保留但作用从"移动"变为"供色") → [填充 + 轮廓线 + 行内边界配对](从 22168020 提取，填充色从自身色变为外部参考色) ＋ [擦除](从 fc754716 提取，无参考时触发)

**来源原语**：对齐比较/aligned_comparison(7d7772cc)、分隔线/separator_line(7d7772cc)、参考像素/reference_pixel(7d7772cc)、填充/fill(22168020)、轮廓线/outline(22168020)、行内边界配对/row_boundary_pairing(22168020)、逐行跨度填充/row_span_fill(22168020)、擦除/erase(fc754716)

**依赖链**：轮廓线提供需要填充的空间区域，但不提供填充颜色——颜色必须通过跨分隔线的行对齐从参考像素获取。参考像素的存在与否还决定了该轮廓线是被填充还是被擦除，形成条件分支。删除对齐机制则无法确定填充色；删除轮廓线则无区域可填。

在分隔线一侧的稀疏轮廓线按行跨度填充，但每条轮廓线的填充颜色由分隔线另一侧与之行对齐的参考像素提供；无参考像素对齐的轮廓线被擦除。

**输入结构**：黑(0)背景，约 15x20 网格。一条灰(5)水平分隔线横贯整个网格宽度，将网格分为上下两区。上区包含 3~5 条单色 8-连通轮廓线（每条轮廓线占据若干行，每行恰好有左右两个边界像素，颜色互不相同，取自蓝(1)、红(2)、绿(3)、黄(4)、品红(6)等）。下区沿某一列排列若干参考像素（每个参考像素颜色各异，取自与上区轮廓线不同的颜色集合，如橙(7)、青(8)、栗(9)等）。每个参考像素占据一行。部分轮廓线所占行范围内，在同一行上下区有参考像素存在（即该轮廓线的某一行与某个参考像素行号关于分隔线镜像对称）；部分轮廓线的行范围内无任何参考像素对齐。生成约束：每条轮廓线至多与一个参考像素对齐；每个参考像素至多与一条轮廓线对齐；对齐关系定义为轮廓线占据的某一行 r_上 与参考像素所在行 r_下 满足 r_上 + r_下 = 2 * 分隔线行号（即关于分隔线行对称）。

**规则**：
1. 识别灰(5)水平分隔线，记其行号为 S。
2. 对上区每条轮廓线 L，检查其所占的每一行 r：是否存在下区参考像素位于行 2S - r。若存在，记该参考像素的颜色为 L 的填充色 C_fill。
3. 若轮廓线 L 找到了对齐的参考像素：对 L 所占的每一行，将该行左边界像素与右边界像素之间（含边界像素）的所有像素涂为 C_fill。
4. 若轮廓线 L 在其所有行上都无参考像素对齐：将 L 的所有像素擦除为黑(0)。
5. 分隔线、参考像素本身、以及黑色背景保持不变。

**关键洞察**：轮廓线的几何结构（行跨度）决定了哪些空间被填充，但填充颜色完全由另一侧的参考像素通过行镜像对齐关系注入——两套独立的几何结构通过分隔线发生跨区域耦合。

## 新题 3：孔洞拓扑分类决定镜像或擦除

**组合逻辑**：[封闭孔洞检测 → 分类](从 ac2e8ecf 提取，分类标准保留但后果从移动方向改为变换类型选择) → [镜像 + 逐色独立变换 + 包围盒内翻转](从 e74e1818 提取，仅作用于有孔对象) ＋ [擦除](从 fc754716 提取，作用于无孔对象) → [碰撞解决：小包围盒优先]（创新：镜像后重叠区域的冲突解决）

**来源原语**：封闭孔洞/enclosed_hole(ac2e8ecf)、封闭对象/closed_object(ac2e8ecf)、开放对象/open_object(ac2e8ecf)、有孔者升无孔者降/hole_up_holeless_down(ac2e8ecf，改造为"有孔者镜像、无孔者擦除")、镜像/mirror(e74e1818)、逐色独立变换/per_color_transform(e74e1818)、包围盒内翻转/flip_within_bbox(e74e1818)、擦除/erase(fc754716)

**依赖链**：孔洞检测结果决定每个对象接受哪种操作（镜像还是擦除），这是一个条件分支节点。镜像操作可能使原本不重叠的有孔对象产生像素冲突，需要用包围盒面积进行优先级裁决。删除分类步骤则不知道哪些对象该镜像、哪些该擦除；删除冲突解决则镜像后输出不唯一。

检测每个前景对象是否包围背景孔洞：有孔对象在各自包围盒内垂直镜像，无孔对象被擦除；镜像后重叠处小包围盒对象覆盖大包围盒对象。

**输入结构**：黑(0)背景，约 15x15 网格。包含 4~6 个单色 4-连通前景对象，颜色互不相同（取自蓝(1)、红(2)、绿(3)、黄(4)、品红(6)、橙(7)等）。其中约一半对象为"封闭对象"——其 4-连通前景像素完全包围至少一个黑(0)背景孔洞（即对象包围盒内存在被对象像素 4-连通围住的背景区域）。另一半为"开放对象"——线状或弧状图形，包围盒内没有被完全围住的背景区域。每个对象 5~12 像素。封闭对象的包围盒之间可以在镜像后产生重叠（即存在至少一对封闭对象，其包围盒在垂直方向有交集列），但原始位置上所有对象的像素互不重叠。生成约束：所有封闭对象的包围盒面积互不相同，以保证冲突解决的唯一性。

**规则**：
1. 对每个非背景色前景对象 O，提取其所有像素，计算最小包围盒 B(O)。
2. 检查 B(O) 内部是否存在被 O 的像素 4-连通完全围住的黑(0)背景连通区域。具体方法：从 B(O) 内所有黑(0)像素出发做 4-连通洪泛，若某个黑色连通分量不与 B(O) 的边界行/列相邻，则该分量是一个封闭孔洞。
3. 若 O 至少有一个封闭孔洞：O 为"有孔对象"，对 O 执行垂直镜像——将 O 的每个像素 (r, c) 映射到 (r0 + r1 - r, c)，其中 r0、r1 分别为 B(O) 的顶行和底行。镜像后的像素保持 O 的颜色。
4. 若 O 没有封闭孔洞：O 为"无孔对象"，将 O 的所有像素擦除为黑(0)。
5. 冲突解决：所有有孔对象镜像完成后，若多个对象的镜像像素占据同一单元格，包围盒面积较小的对象优先（其颜色覆盖较大包围盒对象的颜色）。
6. 背景保持不变。

**关键洞察**：孔洞不是需要填充的目标，而是一个拓扑分类信号——它决定对象接受镜像变换还是被删除，且这一分类标准仅靠单个示例中个别对象难以确认，需对比有孔和无孔对象的不同命运才能归纳。

## 新题 4：补全被遮挡形状后由角括号选取印章源

**组合逻辑**：[补全 + 前景遮挡 + 隐含区域重涂](从 52df9849 提取，补全揭示真实形状) → [角括号 + 标记在括号内部 + 按标记色选择同色](从 1e81d6f9 提取，选择机制保留但后果从擦除改为选取印章源) → [印章覆盖 + 中心对齐 + 标记像素](从 88a10436 提取，印章源从显式给出改为补全后推断)

**来源原语**：补全/complete(52df9849)、被遮挡形状/occluded_shape(52df9849)、前景遮挡/foreground_occlusion(52df9849)、隐含区域重涂/implied_region_recolor(52df9849)、矩形足迹/rectangular_footprint(52df9849)、角括号/corner_bracket(1e81d6f9)、标记像素/marker_pixel(1e81d6f9, 88a10436)、标记在括号内部/marker_inside_bracket(1e81d6f9)、按标记色选择同色/select_same_color_by_marker(1e81d6f9)、印章覆盖/stamp(88a10436)、中心对齐/center_align(88a10436)、精灵体/sprite(88a10436)

**依赖链**：形状补全揭示出被遮挡区域的真实范围（形状的完整轮廓在补全前不可见）。角括号内的标记色指定从补全后的形状中选取哪一个作为印章源。该印章源的裁剪图案被复制到每个灰色标记像素位置。三步紧密耦合：补全结果决定印章形状，括号标记决定印章选择，标记像素位置决定印章去向。跳过补全则印章形状不完整；跳过括号选择则不知印哪个形状。

先将互相遮挡的前景形状各自补全为完整矩形，再由角括号内的标记颜色选出一个补全后的形状，将其裁剪图案印章覆盖到网格中每个灰色标记位置。

**输入结构**：黑(0)背景，约 18x18 网格。包含 3~4 个不同颜色的实心前景形状（蓝(1)、红(2)、绿(3)、黄(4)等），各自原本为实心矩形但因互相部分重叠而显示为不完整——被另一颜色覆盖的区域显示为覆盖色而非自身色。每个形状至少有部分像素可见。一个灰(5)单色 4-连通角括号对象位于网格某个角落附近（形如直角折线，2~3 像素宽的水平段和垂直段各一），角括号的包围盒内部（不含角括号自身像素）恰好有一个前景色标记像素，其颜色与某个被遮挡形状的颜色相同。另有 2~3 个灰(5)标记像素散布在网格的空白区域（与角括号不相邻）。生成约束：被角括号标记色指定的那个形状补全后的包围盒宽高均为奇数，以确保印章有唯一中心；所有灰色标记像素周围留有足够空间，使印章不会超出网格边界。

**规则**：
1. 对每个非黑、非灰前景色 K，收集所有颜色为 K 的像素，计算其最小包围盒 B_K。
2. 检查 B_K 内是否所有像素都是非黑前景色（即 B_K 内无黑色背景像素）。若是，说明 B_K 内被其他颜色覆盖的像素原本属于 K 的实心矩形——将 B_K 内所有非 K 颜色的前景像素重涂为 K，完成形状 K 的补全。对所有颜色按此方式独立补全。若多个形状的补全区域重叠，按后补全覆盖先补全的方式处理（补全顺序：按颜色编号从小到大）。
3. 识别灰(5)角括号对象。在角括号的包围盒内部（排除角括号自身像素），找到唯一的非黑非灰标记像素，读取其颜色 C_sel。
4. 提取颜色 C_sel 的补全后形状的包围盒裁剪图案 S：将补全后 B_{C_sel} 内所有像素记录为 S 的实心区域（均为颜色 C_sel），S 的中心为其包围盒的中心单元格。
5. 对网格中每个不属于角括号的孤立灰(5)像素（即非角括号 4-连通分量的灰色像素），以该像素位置为中心，粘贴裁剪图案 S：S 中每个实心像素覆盖目标位置的原有像素（无论原有像素是什么颜色）。灰色标记像素本身被 S 的中心像素覆盖。
6. 角括号及其内部标记像素保持不变。

**关键洞察**：印章的形状在输入中不直接可见——被遮挡区域使形状看起来不完整，只有正确补全遮挡后才能获得真实的印章图案；角括号不是"擦除选择器"而是"印章源选择器"。

## 新题 5：通道探测后按切比雪夫距离奇偶着色

**组合逻辑**：[洪泛填充 + 背景通道检测](从 a64e4611 提取，通道探测逻辑保留但着色规则替换) → [以控制点为中心 + 奇偶距离决定颜色](从 b7fb29bc 提取，作用域从矩形框内改为不规则通道区域)（创新：通道探测确定"在哪里画"，切比雪夫距离确定"画什么颜色"，两个独立几何系统在同一网格上叠加）

**来源原语**：洪泛填充/flood_fill(a64e4611)、背景通道/background_corridor(a64e4611)、杂色前景/clutter_foreground(a64e4611)、长矩形通道涂色/long_rectangular_corridors_filled(a64e4611)、区域包含/region_containment(a64e4611)、控制像素/control_pixel(b7fb29bc)、以控制点为中心/centered_on_control(b7fb29bc)、奇偶距离决定颜色/parity_distance_color(b7fb29bc)

**依赖链**：通道探测确定哪些像素是"可涂色的真通道"，距离奇偶规则确定每个可涂色像素的具体颜色。两者缺一不可：没有通道探测则不知哪些像素该涂（杂色间的小缝隙不算通道）；没有距离规则则不知涂什么颜色。控制像素的位置和通道的走向共同决定了最终的颜色分布——同一条通道上远端和近端可能颜色不同。

在杂色噪声中探测出隐藏的背景长通道，然后以控制像素为中心、按切比雪夫距离奇偶为每个通道像素染上红色或黄色。

**输入结构**：黑(0)背景，约 20x20 网格。大量橙(7)杂色前景像素随机散布，密度约 30%~40%，在视觉上形成噪声幕。噪声幕中隐藏着若干条宽 1~2 像素、长度至少为网格边长一半的水平或垂直黑(0)背景长通道（通道内所有像素的完整 3x3 邻域均为黑色背景——即通道像素周围无杂色像素紧邻）。杂色像素之间也存在小型黑色缝隙，但这些缝隙中的像素至少有一个 3x3 邻域内含有杂色像素，因此不被判定为通道。一个品红(6)控制像素位于网格中的某处（可以在通道上，也可以在通道外的背景区域），其 3x3 邻域内不含杂色像素。红(2)和黄(4)在输入中不出现。生成约束：通道之间不直接 4-连通相连；控制像素不在网格边缘。

**规则**：
1. 构建"清洁背景遮罩"：标记所有黑(0)像素中，其完整 3x3 邻域（包含自身及 8 邻居，边界外视为非背景）全部为黑(0)背景的像素。品红(6)控制像素不计入背景，但其 3x3 邻域若全为黑(0)或品红(6)则邻近的黑(0)像素仍可通过清洁测试。
2. 在清洁背景遮罩上提取所有极大矩形（矩形内所有像素均为清洁背景）。按面积从大到小排序。
3. 依次接受极大矩形：一个矩形被接受当且仅当其长轴长度 >= 网格对应边长的一半，且该矩形至少引入一个新像素（不被之前已接受矩形覆盖）。将所有被接受矩形覆盖的清洁背景像素标记为"通道像素"。
4. 对每个通道像素 (r, c)，计算其到品红(6)控制像素 (cr, cc) 的切比雪夫距离 d = max(|r - cr|, |c - cc|)。
5. 若 d 为偶数，将该通道像素涂为红(2)；若 d 为奇数，涂为黄(4)。
6. 控制像素保持品红(6)不变。杂色像素、非通道背景像素均保持不变。

**关键洞察**：通道不是用单一颜色简单着色的——控制像素的位置决定了沿通道的颜色渐变节奏，使得同一条直线通道上可能交替出现红黄条纹，条纹间距取决于通道相对控制像素的角度。

## 新题 6：角括号触发选择性擦除后释放重力下落

**组合逻辑**：[角括号 + 按标记色选择同色 + 擦除](从 1e81d6f9 提取，擦除作为前置操作而非最终输出) → [重力下落 + 碰撞阻挡 + 重力远近序处理](从 5ffb2104 提取，重力方向改为向下，且在擦除改变后的地形上运行)（创新：擦除不是终态而是改变碰撞地形的中间步骤，擦除哪种颜色决定了哪些障碍消失、哪些对象获得新的下落路径）

**来源原语**：角括号/corner_bracket(1e81d6f9)、标记在括号内部/marker_inside_bracket(1e81d6f9)、按标记色选择同色/select_same_color_by_marker(1e81d6f9)、保留标记本身/preserve_marker_itself(1e81d6f9)、擦除/erase(1e81d6f9)、重力下落/gravity_drop(5ffb2104)、碰撞阻挡/collision_blocking(5ffb2104)、重力远近序处理/gravity_far_to_near(5ffb2104)、连通分量/connected_component(5ffb2104)、网格边界/grid_edge(5ffb2104)

**依赖链**：角括号标记色决定擦除哪种颜色 → 擦除改变了网格中哪些位置是空的 → 空位分布改变了下落路径和碰撞点 → 最终物体位置取决于擦除后的地形。这是一条因果级联链：不同的标记色会产生完全不同的最终布局。删除擦除步骤则地形不变、物体不动（或无法下落）；删除重力步骤则擦除后留下空洞但物体不移动。

读取角括号内标记像素的颜色，擦除网格中所有同色像素（标记本身除外），然后让剩余前景对象在重力作用下向下沉降直到撞击网格底部或其他已沉降对象。

**输入结构**：黑(0)背景，约 15x18 网格。包含若干（4~6 个）不同颜色的单色 4-连通前景对象（颜色取自蓝(1)、红(2)、绿(3)、黄(4)、橙(7)、青(8)等），每个对象 3~8 像素，形状不规则。其中一种颜色的对象充当"障碍层"——它们水平分布在网格中部偏下，阻挡上方对象的下落。一个灰(5)角括号位于网格的某个角落，其包围盒内部（排除角括号自身像素）恰好有一个标记像素，标记像素的颜色与障碍层对象的颜色相同。生成约束：角括号和标记像素位于网格底部两行以内（确保角括号本身不受重力影响，因为它已在底部）；除角括号标记同色的对象（障碍层）外，其余对象均位于障碍层之上或与障碍层无直接接触。

**规则**：
1. 识别灰(5)角括号对象（最大的灰色 4-连通分量）。在其包围盒内部（排除灰色像素），找到唯一的非黑标记像素，读取颜色 C_erase。
2. 将网格中所有颜色为 C_erase 的像素（不含角括号内的标记像素本身）重涂为黑(0)背景。此步骤消除了障碍层。
3. 对擦除后剩余的所有非黑、非灰前景 4-连通对象执行向下重力沉降：
   a. 按每个对象包围盒的底行从下到上排序（底行最低的对象最先处理）。
   b. 依次处理每个对象：保持形状和颜色不变，将对象整体向下平移，每次移动一行，直到对象的某个像素再向下一行将超出网格底边、或与已沉降（已处理）的对象像素重叠。将对象固定在最后的合法位置。
4. 灰(5)角括号及其内部标记像素位置不变、不参与重力沉降。

**关键洞察**：角括号不是在做终态选择，而是在做环境改造——它指定擦除的颜色恰好是阻挡其他对象下落的障碍层，擦除后物体才能贯通下落；需要对比多个示例（不同标记色→不同障碍被擦→不同下落结果）才能归纳出因果链。

## 新题 7：格子槽位内的对角周期补全

**组合逻辑**：[格子框架 + 格子槽位 + 跨框架对应](从 2e65ae53 提取，槽位内容从均匀填充改为结构化对角图案) × [对角周期图案 + 对角线同余 + 对角周期补缺失](从 c3f564a4 提取，作用域从全局网格缩小到槽位内部，周期从全局唯一改为按行变化)（创新：对角周期规则被嵌入格子结构内部运行，周期参数通过跨槽位比较推断，形成"结构内嵌推断"）

**来源原语**：格子框架/lattice_frame(2e65ae53)、格子槽位/lattice_slot(2e65ae53)、跨框架对应/cross_frame_match(2e65ae53)、推断/infer(2e65ae53)、槽位位置决定颜色/slot_position_color(2e65ae53，改造为"槽位行决定对角周期")、对角周期图案/diagonal_periodic_pattern(c3f564a4)、对角线同余/diagonal_residue(c3f564a4)、补全/complete(c3f564a4)、对角周期补缺失/missing_by_diagonal_cycle(c3f564a4)

**依赖链**：每个槽位的对角周期参数（颜色循环序列）无法仅从该槽位自身推断（因为有缺失像素和多种可能的循环）。必须通过同一格子行的其他槽位交叉比较来确定共享的循环序列，然后用该序列补全每个槽位的缺失像素。格子结构提供了"哪些槽位共享参数"的信息，对角周期规则提供了"槽位内像素如何排布"的信息，两者交织：格子结构约束推断空间，对角规则约束填充空间。

多个格子框架将区域分割为槽位网格，每个槽位内部填有带缺失的对角条纹图案；同一格子行的所有槽位共享相同的颜色循环，通过跨槽位比较推断循环后补全所有缺失。

**输入结构**：黑(0)背景，约 20x20 网格。灰(5)像素构成 2~3 个一像素粗的矩形格子框架，每个框架由水平线和垂直线将内部划分为 R 行 C 列的槽位网格（R 和 C 各为 2~4）。不同框架的槽位数量相同（行列数相同），但槽位的物理尺寸可以不同（因框架位置和大小不同）。每个槽位内部用非黑非灰颜色填充对角条纹图案：同一对角线 (local_row + local_col) mod K 的像素颜色相同，其中 K 为该格子行的颜色循环长度（K = 2 或 3），颜色循环从蓝(1)、红(2)、绿(3)、黄(4)、品红(6)、橙(7)、青(8)、栗(9)中选取。同一格子框架同一行的所有槽位共享相同的 K 和颜色循环序列。不同行可以有不同的循环（不同 K 或不同颜色选择）。每个槽位有若干像素被替换为黑(0)（缺失），但每个循环中至少有一个颜色在该行的某个槽位中可见（确保可推断）。生成约束：每行的颜色循环互不相同；每个槽位至少保留一半像素未缺失。

**规则**：
1. 识别所有灰(5)矩形格子框架。每个框架的内部被灰色水平线和垂直线分割为 R x C 个矩形槽位。
2. 对每个框架的每一行（共 R 行），收集该行所有 C 个槽位中的非黑像素。
3. 对该行的非黑像素，按像素在各自槽位内的局部坐标 (local_row, local_col) 计算对角线残余 d = (local_row + local_col)。将所有同余 d mod K 的非黑像素归组。通过尝试 K = 2 和 K = 3，找到使每个同余类内颜色一致的最小 K 值。记录该行的循环序列：残余 0 → 颜色 A，残余 1 → 颜色 B，...，残余 K-1 → 颜色 X。
4. 对该行每个槽位中的每个黑(0)缺失像素 (local_r, local_c)，计算 d = (local_r + local_c) mod K，填入循环序列中对应的颜色。
5. 对所有框架的所有行重复上述步骤。
6. 灰色框架线、外部背景保持不变。

**关键洞察**：单个槽位的缺失像素无法独立补全——同一对角残余类的像素可能全部缺失于某个槽位，只有通过同行其他槽位的对应残余类才能确定颜色；格子框架的行结构定义了"共享循环"的边界。
