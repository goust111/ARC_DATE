## 新题 1：菱形收缩与反射对称分色

**组合逻辑**：[收缩(shrink)](创新：对所有菱形统一执行，不再按颜色区分收缩/膨胀) + [重涂色(recolor)](创新：着色依据不是原色，而是收缩后的反射对称检测结果) + [反射对称检测](从镜像/交集差集分别着色提炼) → 三者紧耦合：收缩改变形状，形状决定对称性，对称性决定着色

**来源原语**：收缩(shrink) ← d753a70b；重涂色(recolor) + 交集差集分别着色(intersection_diff_colored) ← a8610ef7；配对色映射(paired_color_mapping) ← 6ea4a07e；菱形轮廓(diamond_outline) ← d753a70b；反射对称(reflection_symmetry) ← a8610ef7

**依赖链**：收缩改变菱形的几何形状 → 被网格边界裁切的菱形在收缩后可能重新变得完整或仍然残缺 → 对收缩后的菱形做水平反射对称检测 → 对称像素与非对称像素分别着色 → 对称像素的颜色由配对映射决定而非原色

将部分被边界裁切的菱形轮廓统一收缩一层后，按收缩结果的水平反射对称性将像素分为对称组和非对称组，对称组使用配对色映射着色，非对称组着灰色。

**输入结构**：约 18x18 的橙(7)背景网格上有 3~5 个曼哈顿菱形轮廓（一像素厚的菱形环），每个菱形使用不同的非背景色（如青(8)、绿(3)、灰(5)等），半径在 3~6 之间。部分菱形的中心靠近网格边缘，导致轮廓被边界裁切（仅可见一部分弧）。不同菱形的轮廓互不接触、互不重叠。生成约束：每个菱形至少有一个是被边界裁切的，至少有一个是完整未裁切的。

**规则**：
1. 将每个菱形轮廓统一收缩一层：保持中心不变，半径减 1，重新绘制收缩后的轮廓。如果半径减至 0，该菱形退化为单个中心像素。被网格边界裁切的菱形同样按完整菱形的规则收缩，收缩后仍只保留网格内可见的部分。
2. 对每个收缩后的菱形独立执行水平反射对称检测：以该菱形中心所在行为对称轴，检查每个轮廓像素在行方向上的镜像位置是否也有同属该菱形的轮廓像素。
3. 有镜像对应像素的像素标记为"对称"；无镜像对应的标记为"非对称"。
4. 对称像素使用配对色映射重涂色：青(8)->红(2)、绿(3)->蓝(1)、灰(5)->黄(4)。如果原色不在此映射表中（如品红(6)），则对称像素保持原色不变。
5. 非对称像素统一重涂为灰(5)。若原色本身是灰(5)，则非对称像素重涂为栗(9)以示区分。
6. 背景橙(7)像素不变。

**关键洞察**：完整菱形收缩后仍完整对称，所有像素都会被配对色映射着色；而被边界裁切的菱形收缩后仍可能不对称，其裁切边的像素会变成灰色——收缩是否能"修复"裁切导致的不对称，取决于菱形中心位置与边界的距离关系，需要对比多个示例才能确认这一规则。

## 新题 2：叶状突起定向射线的逐步偏移

**组合逻辑**：[射线延伸(ray_extend)](创新：射线的起源不是矩形边界而是叶状突起所选定的行列) + [流动绘制中的逐步偏移(step_deflection)](创新：偏移控制不是边缘像素而是散布在网格中的障碍像素) → 突起确定射线存在性，障碍确定射线路径形变

**来源原语**：射线延伸(ray_extend) ← 6ffe8f07；叶状突起(leaf_protrusion) + 突起定行列(leaf_selects_row_col) ← f1cefba8；逐步偏移(step_deflection) + 对齐时偏移(deflect_when_aligned) ← f15e1fac；障碍对象(blocker_object) + 射线遇障停止(ray_stops_at_block) ← 6ffe8f07；双色矩形(bicolor_rectangle) ← f1cefba8

**依赖链**：叶状突起从双色矩形伸出 → 每个突起选定一行或一列 → 在选定行/列上向矩形外双向发射射线 → 射线在前进过程中遇到蓝(1)偏移像素时发生垂直偏移 → 偏移后射线继续前进直到出界或撞上另一条射线的轨迹

在双色矩形的叶状突起所定义的行列上发射射线，射线沿途被散布的蓝色偏移像素逐步弯折，最终形成阶梯状路径网络。

**输入结构**：约 20x20 的黑(0)背景网格。中央有一个约 6x8 的双色实心矩形：外层颜色（如红(2)）填充四条边的外一圈，内层颜色（如绿(3)）填充内部。矩形的外边缘上有 3~5 个单像素的内层色突起——每个突起从外层色边缘向外伸出一格，且其唯一的同色邻居在矩形内部（水平突起的同色邻居在左或右，垂直突起的同色邻居在上或下）。网格中散布 4~8 个蓝(1)像素作为偏移控制点，这些蓝像素不在矩形上也不与突起相邻。生成约束：不同突起选定的行列互不重复；蓝像素的分布保证每条射线至少经历一次偏移。

**规则**：
1. 识别叶状突起：矩形外边缘伸出的内层色单像素。若突起的唯一同色邻居在其上方或下方，则该突起选定其所在列；若在左方或右方，则选定其所在行。
2. 从每个突起出发，沿选定的行或列向矩形外侧双向发射射线（用黄(4)绘制路径）。射线每前进一格时检查：当前行/列上是否存在蓝(1)像素与射线在垂直方向上对齐（即若射线沿行前进，检查射线当前所在列是否有蓝像素；若沿列前进，检查当前所在行是否有蓝像素）。
3. 若对齐，射线在当前位置向远离该蓝像素的方向偏移一格（若蓝像素在射线上方，射线向下偏移一格；若在下方，向上偏移；左右同理），然后继续沿原方向前进。
4. 射线在以下情况停止：(a) 到达网格边界；(b) 下一格已被另一条射线的黄(4)路径占据。
5. 矩形本身保持原样（包括突起），背景保持黑(0)，蓝(1)偏移像素保持不变。

**关键洞察**：射线的最终路径不是直线而是阶梯形——叶状突起决定了哪些射线存在，而蓝像素的位置决定了射线如何弯折。必须同时理解突起选择规则和偏移规则才能重建完整输出；单独理解任一规则都不足以确定最终路径网络。

## 新题 3：计数筛选后的尺寸匹配嵌入

**组合逻辑**：[计数(count)](创新：计数结果不直接映射尺寸，而是用作筛选阈值) + [嵌入填充(inlay_fill)](创新：不是所有精灵体都被放入，只有通过计数筛选的才被使用) → 计数产生筛选条件，筛选后的精灵体集合决定哪些空腔被填充

**来源原语**：计数(count) + 计数映射尺寸(count_maps_to_size) ← 878187ab；嵌入填充(inlay_fill) + 尺寸匹配(size_matching) + 唯一槽位配对(unique_slot_pairing) ← 5dbc8537；标记像素(marker_pixel) ← 878187ab / 56ff96f3；模板框架(template_frame) + 矩形空腔(rectangular_cavity) + 精灵体(sprite) ← 5dbc8537

**依赖链**：两种标记色的像素计数 → 较小计数 A 和较大计数 B 构成面积范围 [A, B] → 精灵体按面积筛选 → 通过筛选的精灵体与空腔按尺寸匹配 → 匹配成功则嵌入，否则空腔留空

统计两种标记色的像素数量得到一个面积区间，只有面积落入该区间的外部精灵体才有资格被放入模板空腔。

**输入结构**：约 20x20 的黑(0)背景网格。网格中有一个用品红(6)绘制的大型连通模板框架（约 12x14），框架内部有 4~6 个不同尺寸的矩形空腔（空腔内为黑(0)背景）。框架外部散布 4~6 个彩色小精灵体（每个精灵体是单色 4-连通图形，3~12 像素不等，形状各异但边界框为矩形），每个精灵体颜色互不相同（如红(2)、绿(3)、蓝(1)、黄(4)等）。此外，网格角落区域散布若干橙(7)标记像素和若干青(8)标记像素，总数各 3~8 个不等。生成约束：(a) 精灵体数量大于空腔数量；(b) 面积筛选后恰好有与空腔数量相同的精灵体通过；(c) 通过筛选的每个精灵体的边界框尺寸恰好匹配一个空腔，且无两个通过筛选的精灵体匹配同一空腔。

**规则**：
1. 计数所有橙(7)标记像素得到数值 A，计数所有青(8)标记像素得到数值 B。令 lo = min(A, B)，hi = max(A, B)。
2. 计算每个外部精灵体的面积（像素数）。只保留面积在 [lo, hi]（含端点）范围内的精灵体，其余精灵体被排除。
3. 对每个保留的精灵体，计算其边界框尺寸（高 x 宽）。将其与模板内的空腔按尺寸一一匹配（高和宽完全相同，或旋转 90 度后相同）。
4. 将匹配成功的精灵体放入对应空腔。若需旋转 90 度才能匹配，则旋转后放入。精灵体放入时左上角与空腔左上角对齐。
5. 无匹配精灵体的空腔保持黑(0)背景不变。
6. 输出为模板框架的边界框区域（包含框架和所有已填充/未填充的空腔），裁去框架外部的一切。

**关键洞察**：标记像素的颜色和数量本身不参与任何空间操作——它们纯粹是数值编码，产生一个过滤器来决定哪些精灵体有资格参与嵌入。求解者必须先理解"计数产生阈值"这一隐蔽规则，才能解释为何某些精灵体被放入而另一些被忽略。

## 新题 4：流动轨迹的周期裁剪

**组合逻辑**：[流动绘制(flow_draw)](保留原始偏移机制) + [裁剪(crop)](创新：裁剪宽度不是预设的，而是由流动轨迹呈现的最小重复周期决定) + [镜像(mirror)](创新：周期检测需考虑含反射的重复) → 流动产生轨迹图案 → 图案呈现周期性 → 裁剪最小周期单元

**来源原语**：流动绘制(flow_draw) + 边缘起点像素(edge_source_pixel) + 偏移控制像素(deflector_pixel) + 逐步偏移(step_deflection) + 对齐时偏移(deflect_when_aligned) ← f15e1fac；裁剪(crop) + 周期(period) + 最小周期含翻转(smallest_period_flipped) ← 2dee498d；镜像(mirror) ← 2dee498d

**依赖链**：边缘起点像素发射流 → 偏移控制像素使流弯折 → 弯折后的轨迹图案在水平方向上呈现含反射的周期性 → 检测最小周期宽度 → 裁剪输出左起第一个周期单元

从网格边缘发射的流经偏移后形成重复图案，输出该图案的最小重复单元（含反射判定）。

**输入结构**：一个 6x24（高x宽）的黑(0)背景网格。左边缘上有 3~5 个青(8)像素（不相邻），沿左边缘的不同行分布。上边缘有若干红(2)像素（4~8 个），沿上边缘的不同列分布，且红像素的分布经过精心设计使其呈现以某个宽度 W 为周期的重复模式（可能含左右镜像）。生成约束：W 整除网格宽度；红像素在宽度方向上以 W 为周期排列（相邻周期可以是原样或水平翻转）；至少存在一个反射周期使得最小周期不等于整个网格宽度。

**规则**：
1. 从每个左边缘的青(8)像素出发，向右逐格前进（流动方向为从左到右）。
2. 每前进一格，检查当前所到列上是否有红(2)像素在上边缘。若有，则射线在当前位置向下偏移一格（远离上边缘），然后继续向右前进。
3. 所有射线路径用青(8)绘制在网格上，红(2)像素保持不变。
4. 对完成后的整个网格图案进行水平周期检测：从左起尝试候选周期宽度 W = 1, 2, 3, ...，对每个 W 检查每一块宽为 W 的列带是否是第一块列带的原样副本或左右镜像副本。选取最小的满足条件的 W。
5. 输出左起第一个宽为 W 的列带（高度不变），即整个网格高度 x W 宽度的子网格。

**关键洞察**：红像素的排布暗含周期性，但这一周期性只有在流动轨迹绘制完成后才能清晰观察到——直接看红像素的排列不一定能直接读出周期，因为流动偏移会放大或扭曲周期图案。求解者需要先完成流动模拟，再对结果进行周期分析。

## 新题 5：象限旋转选择器放置

**组合逻辑**：[复制放置(copy_place)](保留颜色索引匹配) + [旋转(rotate)](创新：旋转角度不由单独标记决定，而是由放置目标象限位置隐式编码) + [拼接+边框(concatenate+frame)](创新：最终结果加边框封装) → 象限位置同时决定"放在哪里"和"旋转多少度"

**来源原语**：复制放置(copy_place) + 选择器块(selector_block) + 颜色索引匹配(color_index_matching) + 图例位置映射(legend_position_mapping) + 象限(quadrant) ← 7d18a6fb；旋转(rotate) ← 412b6263；边框(frame) + 副本堆叠(copy_stacking) ← 412b6263；象限排布(quadrant_layout) ← 67e8384a

**依赖链**：选择器块中标记像素的象限位置 → 确定目标象限 + 该象限的旋转角度 → 找到同色外部精灵体 → 旋转后放入对应象限 → 整体加蓝色边框

选择器块的四个象限标记同时编码了放置位置和旋转角度，每个精灵体被不同角度旋转后放入对应象限。

**输入结构**：约 18x18 的黑(0)背景网格。网格中有一个 7x7 的选择器块，其主体色为栗(9)，四个 3x3 象限的中心各有一个不同颜色的标记像素（从红(2)、绿(3)、黄(4)、品红(6)中选取四种）。选择器块外散布 4 个精灵体，每个精灵体为单色 8-连通图形，边界框为 3x3，颜色分别与四个标记像素一一对应。每个精灵体在 3x3 边界框内是非对称的（即旋转 90/180/270 度后图案不同）。生成约束：每个精灵体在其 3x3 边界框内至少有 4 个像素、至多 7 个像素，且四次旋转产生四个不同图案。

**规则**：
1. 识别选择器块中四个标记像素的位置。左上象限中心、右上象限中心、左下象限中心、右下象限中心。
2. 旋转角度由象限位置决定：左上 = 0 度（不旋转）、右上 = 顺时针 90 度、右下 = 顺时针 180 度、左下 = 顺时针 270 度。
3. 对每个标记像素颜色，在外部找到同色精灵体，将其按步骤 2 确定的角度旋转。
4. 构建 7x7 黑(0)画布，分为四个 3x3 象限（由中间行和中间列分隔，分隔行列填充黑(0)）。将旋转后的精灵体放入对应象限。
5. 在 7x7 画布外加一圈蓝(1)边框（一像素宽），最终输出为 9x9。

**关键洞察**：象限位置承担双重角色——它既是放置目标（与参考题 7d18a6fb 相同），又隐式编码了旋转变换（参考题中不存在的新关系）。求解者只看一个示例可能将旋转误判为其他变换，必须对比多个示例（不同精灵体形状）才能归纳出"象限即旋转角度"的隐蔽映射规则。

## 新题 6：菱形收缩计数驱动的矩形填充模式

**组合逻辑**：[收缩(shrink)](保留半径减 1 的语义) + [计数(count)](创新：计数的不是标记像素而是收缩后的残余像素) + [填充(fill)](创新：填充方式由计数结果与矩形周长的比较关系决定) → 几何变换产生数值 → 数值与另一几何量比较 → 比较结果决定第三种几何操作的模式

**来源原语**：收缩(shrink) + 半径微调(radius_adjust) + 菱形轮廓(diamond_outline) ← d753a70b；计数(count) + 计数映射尺寸(count_maps_to_size) ← 878187ab；填充(fill) + 同色对定义矩形(pair_defines_rect) + 对角配对(diagonal_pairing) ← 56ff96f3；标记像素(marker_pixel) ← 56ff96f3；颜色决定操作(color_det_operation) ← d753a70b

**依赖链**：菱形轮廓收缩一层 → 统计每个菱形收缩后残余像素数 C → 同色标记像素对定义矩形 → 计算每个矩形的周长 P → 若 C > P 则实心填充该矩形，若 C ≤ P 则只描边（一像素宽边框）

菱形轮廓收缩后的残余像素数与对应矩形的周长做比较，决定矩形是实心填充还是仅描边。

**输入结构**：约 18x18 的橙(7)背景网格。网格上有 3 个不同颜色的曼哈顿菱形轮廓（一像素厚），颜色分别为青(8)、绿(3)、灰(5)，半径分别在 2~6 之间，互不重叠。网格上还有 3 对标记像素，每对标记像素与一个菱形同色（即有两个青像素、两个绿像素、两个灰像素），每对标记像素位于菱形外部，不与任何菱形或其他标记像素相邻。每对标记像素定义了一个矩形的对角。生成约束：(a) 菱形互不重叠且完全在网格内部；(b) 标记像素对所定义的矩形互不重叠且不与菱形重叠；(c) 3 个菱形中至少有一个收缩后残余像素数大于其对应矩形周长，至少有一个小于等于。

**规则**：
1. 对每个菱形轮廓执行收缩：保持中心不变，半径减 1，重新绘制轮廓。半径减至 0 时退化为单像素。
2. 统计每个菱形收缩后的轮廓像素数 C。（半径为 r 的完整曼哈顿菱形轮廓有 4r 个像素；半径为 0 时有 1 个像素。）
3. 对每种颜色，找到该颜色的两个标记像素，以它们为对角确定一个轴对齐矩形。计算该矩形的周长 P = 2 x (宽 + 高)（以像素格计，宽和高为边界框的像素列数和行数）。
4. 若 C > P：用该颜色实心填充整个矩形区域（含内部）。
5. 若 C ≤ P：仅用该颜色描该矩形的一像素宽边框，内部保持橙(7)背景。
6. 擦除所有原始菱形轮廓（收缩前的位置恢复为背景色）。收缩后的菱形也不保留在输出中——它们只是中间计算量。标记像素本身也不保留。
7. 输出只包含填充/描边后的矩形与橙(7)背景。

**关键洞察**：菱形在输出中完全消失——它们存在的唯一目的是通过收缩产生一个数值，用该数值控制矩形的填充模式。这种"几何体作为数值编码器"的角色在任一参考题中都不存在。

## 新题 7：膨胀阻断的扫描线填充

**组合逻辑**：[膨胀(dilate)](创新：膨胀的对象不是菱形而是小型障碍精灵体，膨胀后作为填充阻断器) + [填充(fill)](保留逐行扫描线填充逻辑) + [连线(draw_line)](创新：连接相邻障碍中心的对角线也参与阻断) → 膨胀扩展障碍范围 → 对角线连接障碍 → 两者共同阻断扫描线填充的跨度

**来源原语**：膨胀(dilate) ← d753a70b；填充(fill) + 逐行扫描(row_scan) + 填充轮廓间区域(fill_between_outlines) + 轮廓像素(outline_pixel) + 跨度(span) ← aa18de87；连线(draw_line) + 对角线(diagonal_line) ← 878187ab；障碍对象(blocker_object) + 射线遇障停止(ray_stops_at_block) ← 6ffe8f07

**依赖链**：障碍精灵体膨胀一层 → 相邻障碍中心用对角线连接 → 轮廓像素定义扫描线跨度的端点 → 膨胀后的障碍像素和对角线像素在扫描线上充当跨度阻断器（将一个跨度切分为多段）→ 仅填充未被阻断的子跨度

在有对角轮廓线和小型障碍精灵体的网格上执行扫描线填充，但障碍先膨胀一层并以对角线相连，它们共同打断填充跨度。

**输入结构**：约 16x16 的黑(0)背景网格。网格上有若干绿(3)像素组成的对角线笔画（两三条 45 度斜线段，每段 4~8 像素），形成一个近似封闭的多边形轮廓。多边形内部散布 2~4 个小型灰(5)精灵体（每个为 4-连通单色图形，2~4 像素，形状不固定），精灵体之间互不接触但彼此距离不超过 4 格。生成约束：(a) 绿像素构成的轮廓在每行中最多出现两个轮廓像素（保证扫描线可正确配对）；(b) 灰精灵体完全在轮廓围成的区域内；(c) 至少有一对灰精灵体的中心连线方向接近 45 度。

**规则**：
1. 对每个灰(5)精灵体执行膨胀一层：将精灵体中每个像素的 4-连通邻居（上下左右）中为黑(0)背景的像素也设为灰(5)。若邻居是绿(3)轮廓像素或另一个灰精灵体像素，则不覆盖。
2. 对所有灰精灵体，按边界框中心的位置从左到右排序。对每对相邻精灵体（排序后），从前一个的边界框中心到后一个的边界框中心绘制黄(4)对角线（Bresenham 直线算法），仅绘制在黑(0)背景像素上——不覆盖绿(3)轮廓或灰(5)像素。
3. 执行逐行扫描线填充：在每一行中，从左到右找到所有绿(3)轮廓像素，每两个相邻轮廓像素之间的区域为一个潜在跨度。
4. 在每个潜在跨度内部，检查是否有灰(5)像素或黄(4)像素。若有，这些像素将跨度分割为多个子跨度。仅将纯黑(0)的子跨度填充为红(2)。
5. 所有绿(3)、灰(5)、黄(4)像素保持不变。跨度外部的黑(0)背景保持不变。

**关键洞察**：去掉膨胀步骤，障碍体积太小不足以阻断跨度，填充结果与无障碍时相同；去掉对角线连接，各障碍独立且阻断范围有限。膨胀和连线协同将多个孤立的小障碍升级为一条连续的阻断带，从根本上改变了扫描线填充的拓扑——这种协同效应是任一参考题中都不存在的涌现结果。

## 新题 8：行带平铺与交替镜像配对色

**组合逻辑**：[平铺(tile)](保留纵向重复填满画布) + [镜像(mirror)](创新：不是分析输入的周期结构，而是在输出的交替副本上主动施加镜像) + [重涂色(recolor)](创新：镜像副本同时进行配对色映射) → 平铺产生多个副本 → 奇数副本同时执行水平镜像 + 配对色变换 → 偶数副本保持原样

**来源原语**：平铺(tile) + 行带(row_band) + 纵向重复(vertical_repetition) + 前景行带铺满画布(foreground_band_tiles_to_fill_canvas) ← 8eb1be9a；镜像(mirror) + 双轴反射(biaxial_reflection) ← 67e8384a；重涂色(recolor) + 配对色映射(paired_color_mapping) ← 6ea4a07e；反转(invert) ← 6ea4a07e

**依赖链**：识别前景行带 → 纵向平铺填满画布 → 对每个副本编号（从行带原始位置向上和向下，原位为 0） → 偶数编号副本保持原样 → 奇数编号副本同时执行左右镜像和配对色映射 → 两种变换的叠加创造出棋盘式的对称图案

将前景行带纵向平铺后，交替副本同时进行水平翻转和配对色变换，产生织物般的交错图案。

**输入结构**：一个 15x10 的黑(0)背景网格。网格中有一个连续的水平行带（3 行高，全宽），行带内含有 2~3 种非背景色像素（如青(8)和绿(3)，或灰(5)和青(8)），排列成非对称的图案（即左右翻转后图案不同）。行带位于网格的某一行段（不一定在中间），行带上方和下方是纯黑(0)背景行。行带内使用的每种颜色都必须在配对映射表中有对应：青(8)->红(2)、绿(3)->蓝(1)、灰(5)->黄(4)。生成约束：网格高度能被行带高度整除（即 15 / 3 = 5 个完整副本位置）；行带图案非左右对称。

**规则**：
1. 识别前景行带：包含所有非黑(0)像素的连续行段。
2. 以行带高度为步长，向上和向下复制行带，直到填满整个画布。保持行带在原始行位置对齐。将原始行带编号为 0，向上依次为 -1, -2, ...，向下依次为 1, 2, ...。
3. 偶数编号（0, -2, 2, -4, 4, ...）的副本保持行带原样不变。
4. 奇数编号（-1, 1, -3, 3, ...）的副本同时执行两个变换：(a) 水平翻转（左右镜像），(b) 对每个非黑(0)像素应用配对色映射：青(8)->红(2)、绿(3)->蓝(1)、灰(5)->黄(4)。黑(0)像素保持为黑(0)。
5. 两个变换必须同时应用于奇数副本——仅翻转不变色，仅变色不翻转，都不是正确的规则。

**关键洞察**：行带本身非对称且使用了有配对映射关系的颜色，这两个条件缺一不可：如果行带对称，镜像翻转不可见，求解者可能只归纳出颜色映射；如果行带只有一种颜色，颜色映射退化为单色替换，求解者可能只归纳出翻转。必须对比偶数和奇数副本才能同时识别出两种变换的叠加。

## 新题 9：重力沉降后的嵌套层次压缩

**组合逻辑**：[滑动(sliding)](创新：重力方向不是水平而是向下，且多个对象互相碰撞阻挡) + [压缩(compress)](创新：压缩的层次顺序不由面积决定，而是由重力沉降后的垂直堆叠顺序决定) → 重力改变对象的空间排列 → 沉降后的垂直分层顺序作为嵌套层次的编码 → 压缩为嵌套方环

**来源原语**：滑动(sliding) + 碰撞阻挡(collision_block) + 重力沉降(gravity_settle) + 前景对象(fg_object) + 画布边界(canvas_boundary) ← d282b262；压缩(compress) + 嵌套形状(nested_shape) + 方环(square_ring) + 嵌套层次(nesting_hierarchy) + 面积序映射环(area_order_to_ring) ← eb5a1d5d；排序(sorting) ← eb5a1d5d

**依赖链**：多个不同色的精灵体散布在网格上 → 向下滑动直到全部沉降（碰撞阻挡） → 沉降后从底部到顶部形成垂直层叠顺序 → 最底层（最先着地）为最外层环，最顶层为最内层 → 压缩为嵌套方环图案

多个彩色精灵体经重力沉降后按垂直堆叠顺序压缩为嵌套方环，底部最先着地的精灵体成为最外层环。

**输入结构**：约 14x14 的黑(0)背景网格。网格中有 4~5 个单色 4-连通精灵体（各 6~15 像素，形状各异，非矩形），每个精灵体颜色不同（如红(2)、蓝(1)、绿(3)、黄(4)、品红(6)）。精灵体散布在网格的不同高度，互不接触。部分精灵体在水平方向上有重叠的列范围（即垂直投影有交集），使得下落时会发生碰撞阻挡。生成约束：(a) 至少有两个精灵体的列范围有重叠，使得沉降时发生非平凡的堆叠；(b) 沉降后每个精灵体的底部行各不相同（不存在两个精灵体在完全相同的行段上着地），从而可以无歧义地确定从底到顶的顺序；(c) 沉降后的垂直顺序与原始的面积大小顺序不同（否则退化为面积排序）。

**规则**：
1. 将每个精灵体视为刚体，同时向下滑动一格。如果某个精灵体的下一格位置被网格底边界或另一个已停止的精灵体占据，则该精灵体停止。重复此过程直到所有精灵体停止。（处理顺序：每一轮中所有可移动的精灵体同时尝试移动；一个精灵体在其正下方没有障碍时才移动。）
2. 沉降完成后，确定垂直层叠顺序：按每个精灵体底部最低行的位置排序。底部最低行最大（最靠近网格底边）的排第一（"最先着地"），底部最低行最小的排最后。
3. 构建嵌套方环输出：精灵体数量为 N，则输出为 (2N-1) x (2N-1) 的网格。排第一的精灵体颜色填充最外层环（第一圈），排第二的填充次外层环，以此类推，排最后的颜色填充中心一个像素。
4. 精灵体的原始形状和大小在输出中不保留——仅保留颜色和沉降后的堆叠顺序。

**关键洞察**：面积排序在本题中完全无用——外环颜色不是由最大精灵体决定，而是由最早着地的精灵体决定。而着地顺序取决于初始高度和碰撞阻挡的交互作用（一个较高的精灵体可能被一个更高的精灵体阻挡而停在高处），必须完整模拟重力过程才能得出正确顺序。

**依赖链**：叶状突起选定行列 → 选定行列在矩形内部用外层色切割，在矩形外部用内层色延伸到网格边界 → 对整个图案（矩形 + 延伸射线）做垂直轴反射对称检验 → 检验的对称轴为矩形的垂直中轴线 → 有对称配对的延伸像素保持内层色不变 → 无对称配对的延伸像素重涂为黄(4) → 矩形本身不变

叶状突起驱动内外色互换延伸后，对延伸线相对于矩形中轴的反射对称性进行检测，对称的射线保持原色，不对称的射线标记为黄色。

**输入结构**：约 15x19 的黑(0)背景网格。中央有一个约 5x7 的双色矩形：外层色为红(2)（覆盖四边外一圈像素），内层色为绿(3)（填充内部）。矩形的宽度（列数）为奇数以保证存在唯一垂直中轴线。矩形边缘有 4~6 个叶状突起（内层色绿(3)单像素，从外层色边缘伸出），分布不关于矩形垂直中轴对称——即左侧和右侧的突起数量或行位置不完全镜像。生成约束：(a) 至少有一对突起关于中轴对称（它们选定的行/列镜像对应）；(b) 至少有一个突起在中轴另一侧没有对应突起；(c) 突起只出现在矩形的左右两条垂直边上（简化为只选行），不出现在上下边。

**规则**：
1. 识别叶状突起：矩形外边缘伸出的绿(3)单像素。由于所有突起在左右垂直边上，每个突起选定其所在行。
2. 对每个选定的行，在矩形内部将该行的所有绿(3)像素重涂为红(2)（外层色切割）。在矩形外部，沿该行向左右两侧延伸至网格边缘，延伸像素涂为绿(3)（内层色延伸）。
3. 确定矩形的垂直中轴线（矩形水平中心列）。
4. 对每个延伸射线像素（矩形外部的绿(3)像素），检查其关于垂直中轴线的镜像位置是否也有延伸射线像素。若有，该像素保持绿(3)。若没有（即该侧有射线但镜像侧没有对应射线），该像素重涂为黄(4)。
5. 矩形内部（包括被切割的行）和突起像素保持不变。背景黑(0)像素保持不变。

**关键洞察**：左侧和右侧的叶状突起分布不对称导致延伸射线在两侧的行位置不同。有对称配对的射线行保持绿色，仅出现在一侧的射线行变黄——黄色标记精确指出了突起分布中的不对称成分。求解者必须先完成射线延伸，才能进行对称检测；单看突起分布无法直接预测哪些行的延伸会变黄（因为突起的选行规则和对称检测的基准都需要从示例中归纳）。
