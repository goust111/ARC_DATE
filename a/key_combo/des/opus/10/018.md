## 新题 1：重力沉降中的障碍绕行与方位涂色

**组合逻辑**：[重力沉降](已有) + [遇障碍则绕行](创新改造：从向上寻路改为向下重力场景) → [方位决定颜色](创新改造：绕行方向决定最终涂色)

**来源原语**：重力沉降(1e0a9b12)、遇障碍则绕行(d9f24cd1)、方位决定颜色(d364b489)、前景像素(1e0a9b12)、障碍像素(d9f24cd1)

**依赖链**：重力沉降驱动像素下落 → 障碍像素阻断垂直路径，迫使像素向一侧绕行 → 绕行方向（左/右）决定像素的最终颜色。若无重力则无下落，若无障碍则无绕行，若无方位涂色则绕行信息不可观测。

各列顶部散布的彩色像素在重力作用下下落，遇到固定灰色障碍时向空间更宽的一侧绕行一步后继续下落，最终根据绕行方向改变颜色。

**输入结构**：约 12x10 的网格，黑(0)背景。顶部若干行散布蓝(1)前景像素（每列至多一个）。网格中部散布灰(5)障碍像素（每个障碍像素左右至少有一侧的同行相邻格为空）。底部无障碍。生成约束：每个蓝像素的下落路径上至多遇到一个障碍；障碍左右两侧到最近已占用格或边界的距离不相等（确保绕行方向唯一）。

**规则**：
1. 对每个蓝(1)像素，沿其所在列逐步向下移动。
2. 若下一行同列为灰(5)障碍，检查障碍所在行中该障碍左侧和右侧到最近非背景像素或网格边界的连续空格数。像素向空格数更多的一侧水平移动一格，然后继续向下移动。
3. 像素移动直到抵达底行或下方已有非背景像素为止，在终点停留。
4. 未遇到障碍的像素保持蓝(1)不变。绕行向左的像素涂为红(2)，绕行向右的像素涂为绿(3)。灰(5)障碍像素在输出中保留。

**关键洞察**：绕行方向不是固定规则，而是由障碍周围的局部空间分布动态决定——必须比较障碍两侧的可用空间才能推断颜色。

## 新题 2：对角弹射路径穿越容器的循环色填充

**组合逻辑**：[射线延伸 + 反射弹回](已有) → [容器检测 + 填充](创新改造：容器不由列对齐触发，而由射线经过触发) → [色彩循环](创新改造：弹射次数驱动循环推进)

**来源原语**：射线延伸/反射弹回(a3df8b1e)、容器/填充/列对齐落入(db7260a4)、色彩循环(72207abc)、边缘图例(6165ea8f)

**依赖链**：反射弹回的射线遍历网格 → 射线路径决定哪些容器被"穿越"→ 每次弹射推进色彩循环的索引 → 容器的填充色由穿越时的循环索引决定。无弹射则射线只覆盖一条对角线，无容器则无填充目标，无循环则所有容器同色。

一个起点像素发射对角弹射射线，射线在网格边界反弹，每次反弹推进一个颜色循环位，射线列经过的 U 形容器被填充为当前循环色。

**输入结构**：约 15x15 的网格，黑(0)背景。左上角或右上角有一个蓝(1)起点像素。网格中散布 3~4 个由红(2)像素构成的 U 形容器（两条竖直侧壁 + 底部横段，内部为空心矩形区域，宽 3~5 格，高 3~4 格）。最左列从上到下排列 2~4 个单色像素（非蓝非红，颜色互不相同），定义色彩循环顺序。生成约束：容器之间不重叠不相邻；射线路径能经过至少 2 个容器的水平覆盖范围。

**规则**：
1. 从起点像素出发，向右下方发射对角射线（每步行+1、列+1）。
2. 射线遇到左右边界时水平方向反转，遇到上下边界时垂直方向反转，射线始终前进。射线到达网格角点时同时反转两个方向。射线路径不绘制、不改变任何像素。
3. 读取最左列的单色像素从上到下作为色彩循环 C[0], C[1], C[2], ...。射线起始时循环索引 i=0。每次射线发生一次反弹（边界反射），i 递增 1 并对循环长度取模。
4. 当射线经过某一行时，若该行中存在一个 U 形容器且射线当前列处于该容器两侧壁之间（含侧壁列），则用当前循环色 C[i] 填充该容器的全部空心内部。每个容器只在射线首次穿越时填充，后续穿越忽略。
5. 未被射线穿越的容器保持空心不变。起点像素在输出中擦除。

**关键洞察**：必须追踪射线的完整弹射轨迹并计算反弹次数，才能确定每个容器的填充颜色——容器的颜色既取决于几何位置（决定是否被穿越）又取决于拓扑顺序（第几次弹射后穿越）。

## 新题 3：二面体等价分组决定滑动方向

**组合逻辑**：[形状匹配 + 旋转翻转等价](已有) → [滑动](创新改造：滑动方向不由缺口决定，而由等价类序号决定) ← [边缘图例](创新改造：图例不编码表格顺序，而编码方向映射)

**来源原语**：形状匹配/旋转翻转等价/归一化掩码(6165ea8f)、滑动(1e0a9b12/320afe60)、边缘图例(6165ea8f)、重涂色(recolor)

**依赖链**：二面体等价分组 → 每组获得一个等价类序号 → 边缘图例将序号映射到方向 → 对象按分配的方向滑动至边界 → 碰撞时保持不重叠。无形状匹配则无法分组，无图例则方向不确定，无滑动则无空间变换。三者形成三角依赖。

多个不同朝向的小对象按形状等价性分组，每组从边缘图例读取一个滑动方向，所有同组对象沿该方向滑至网格边缘。

**输入结构**：约 15x15 的网格，黑(0)背景。散布 6~8 个单色小对象（4-连通，3~6 像素），使用蓝(1)，它们的朝向各异但形状可分为 2~3 个二面体等价类（即旋转或翻转后形状相同的归为一类）。最上行放置 2~3 个单像素标记，从左到右依次为红(2)、绿(3)、黄(4)（数量与等价类数相同），表示方向映射：第 1 个标记色 = 向下滑，第 2 个标记色 = 向右滑，第 3 个标记色 = 向左滑。生成约束：对象间间隔足够，滑动后不相互重叠；每个等价类至少包含 2 个对象。

**规则**：
1. 将所有蓝(1)对象按 4-连通提取，对每个对象计算其归一化掩码（紧凑边界框内的像素模式）。
2. 将归一化掩码在二面体群（4 次旋转 x 2 次翻转）下等价的对象归为同一类。
3. 按每个等价类中边界框左上角行列最小的成员的位置排序，确定第 1、第 2、第 3 等价类。
4. 读取最上行的标记像素从左到右的顺序：第 1 个位置对应"向下"，第 2 个位置对应"向右"，第 3 个位置对应"向左"。将第 k 个等价类分配第 k 个方向。
5. 每个对象沿其等价类对应的方向整体平移，直到对象的前沿像素抵达网格边界（距边界 0 行/列），保持形状不变。同方向滑动的多个对象按离目标边界近的先放置，后续对象不与已放置对象重叠（遇到已放置对象则紧贴其前方停下）。
6. 滑动后，所有对象重涂为其等价类对应的标记颜色：第 1 类涂红(2)、第 2 类涂绿(3)、第 3 类涂黄(4)。

**关键洞察**：对象的朝向是干扰项——必须通过二面体等价归并才能确定组别，而组别又决定了运动方向和最终颜色，三者环环相扣。

## 新题 4：十字分割去噪后少数派像素数驱动线段发射

**组合逻辑**：[十字分隔线 + 去噪取主色](已有) → [像素数决定长度](创新改造：少数派像素数而非内部对象面积决定长度) → [方位对应](创新改造：象限位置决定线段发射方向)

**来源原语**：十字分隔线/四象限/去噪取主色(996ec1f3)、像素数决定长度(c61be7dc)、方位对应/direction_correspondence(d364b489)、压缩(996ec1f3)

**依赖链**：十字分隔确定四个象限 → 去噪得到主色和噪声像素 → 噪声像素计数变为线段长度 → 象限方位决定线段从中心发射的方向。去噪和计数不可分（噪声定义依赖主色判断），方位和线段不可分（线段无方向则放置不唯一）。

一个被十字线分割的四象限网格，每个象限去噪后，从中心向该象限方向发射一条线段，长度等于该象限的噪声像素数。

**输入结构**：约 13x13 的网格。有一整行和一整列由灰(5)像素构成的十字分隔线，将网格分为四个非空矩形象限。每个象限有一种唯一主色（从红(2)、绿(3)、黄(4)、蓝(1)中选），另有少量散布的其他颜色像素作为噪声（每个象限 1~4 个噪声像素）。生成约束：四个象限主色互不相同；各象限噪声像素数互不相同（便于区分）。

**规则**：
1. 找到网格中唯一的纯灰(5)行和纯灰(5)列，它们的交点为中心点。
2. 对每个象限，统计各颜色的像素数，出现最多的为主色，其余为噪声。记录噪声像素总数 n。
3. 输出为 (2*max_n+1) x (2*max_n+1) 的网格（max_n 为四个象限中噪声像素数的最大值），黑(0)背景，中心像素为灰(5)。
4. 从中心像素出发，向左上方延伸一条线段，长度等于左上象限的噪声像素数 n_LU，颜色为左上象限的主色；线段沿对角线方向（每步行-1、列-1）绘制。
5. 类似地：右上象限 → 向右上方延伸（行-1、列+1），长度 n_RU，颜色为右上主色；左下象限 → 向左下方延伸（行+1、列-1），长度 n_LD；右下象限 → 向右下方延伸（行+1、列+1），长度 n_RD。
6. 中心灰(5)像素保留。

**关键洞察**：输出的几何形状（四条不等长对角线）完全由输入中各象限"隐藏"的噪声数量编码——必须先完成去噪才能推出线段长度，而线段方向由象限空间位置隐式决定。

## 新题 5：缺口方向滑动后边界反弹与光环印章

**组合逻辑**：[缺口决定方向 + 滑动](已有) → [反射弹回](创新改造：从对角线弹射改为正交滑动弹射) → [邻域扩展 + 仅填背景格](已有，应用于弹射终点)

**来源原语**：滑动/缺口决定方向/靠边对齐(320afe60)、反射弹回(a3df8b1e)、邻域扩展/光环区域/仅填背景格(dc1df850)、重涂色(320afe60)

**依赖链**：缺口检测 → 决定初始滑动方向 → 滑动到边界后弹射（方向反转）→ 弹射后继续移动一段距离（等于对象在滑动方向上的宽度）→ 在终点位置绘制光环。缺口、弹射距离、光环三环节分别决定方向、终点、可见标记，删除任一环节均无法求解。

带缺口的对象向缺口指示的边界滑动，碰壁后弹回一段等于自身宽度的距离，在终点生成光环。

**输入结构**：约 14x14 的网格，黄(4)背景。2~3 个蓝(1) 4-连通对象（4~8 像素），每个对象的边界框某一侧有一个由背景色构成的缺口（缺口在边界框的左、右、上或下边，且每个对象的缺口方向唯一可辨）。对象之间间距至少 4 格。生成约束：每个对象沿缺口方向滑动到边界后弹回自身宽度（沿滑动轴方向的边界框尺寸）的距离，终点位置不与其他对象或其光环重叠，且不超出网格。

**规则**：
1. 检测每个蓝(1)对象的边界框。检查边界框的上、下、左、右四条边：若某条边上存在背景色缺口（该边上至少一个格为背景色，且缺口两侧有对象像素），则该方向为滑动方向。
2. 将对象沿缺口方向整体平移，直到对象前沿抵达网格边界。
3. 对象到达边界后，方向反转，继续平移距离 d 格，d 等于对象在滑动方向上的边界框尺寸（水平滑动则 d = 边界框宽度，垂直滑动则 d = 边界框高度）。
4. 对象在最终位置绘制，颜色从蓝(1)重涂为红(2)。
5. 对最终位置的每个红(2)像素，将其 Chebyshev 距离 1 邻域内的所有背景格涂为绿(3)，不覆盖任何非背景像素。
6. 原始位置清空为背景色。

**关键洞察**：对象的最终位置同时取决于两个独立信息——缺口方向（决定去哪面墙弹射）和对象自身宽度（决定弹回多远），两者缺一不可。

## 新题 6：对角线奇偶筛选生成模板碎片并补全

**组合逻辑**：[对角线段 + 奇偶交替涂色](创新改造：奇偶位不是涂色而是筛选，偶数位像素组成碎片) → [碎片锚定放置位 + 补全](已有) ← [模板精灵体](已有)

**来源原语**：对角线段/序列索引/奇偶交替涂色(a5f85a15)、模板精灵体/碎片/碎片锚定放置位/补全(fd096ab6)、平移对齐(fd096ab6)、擦除(db7260a4)

**依赖链**：对角线中偶数位像素 → 构成碎片 → 与模板比对确定平移偏移 → 补全缺失像素。若无奇偶筛选，碎片形状错误导致匹配失败；若无模板，不知道补全成什么；若无补全，碎片残缺无意义。奇偶筛选是生成碎片的唯一途径，是独特的耦合点。

对角线段中交替提取的像素构成一个模板的部分碎片，根据模板补全缺失像素后擦除原始对角线的剩余部分。

**输入结构**：约 12x12 的网格，黑(0)背景。包含一个由灰(5)像素组成的完整模板精灵体（4-连通，6~10 像素，形状不规则，位于网格某个区域）。另有 2~3 条由不同颜色构成的右下对角线段（每条用一种颜色，如红(2)、绿(3)、蓝(1)），每条对角线段 4~8 像素长。生成约束：每条对角线段的偶数位像素（第 0、2、4、...个，从左上端计）恰好与模板在某个平移位置的部分像素重合；不同颜色对角线对应模板的不同平移位置；模板的各平移副本之间不重叠。

**规则**：
1. 识别灰(5)模板精灵体，提取其紧凑掩码。
2. 对每条非灰的对角线段（同色 4-连通像素沿右下对角方向排列），按从左上到右下的顺序编号 0, 1, 2, ...。保留偶数位像素（第 0、2、4 ...个），将这些像素视为该颜色的"碎片"。
3. 对每个碎片，找到唯一的平移偏移使得碎片像素全部落在模板掩码的对应位置上。
4. 以该偏移放置模板的完整副本，用碎片的颜色绘制模板掩码中所有像素位置（包括碎片已有的和缺失的）。
5. 擦除每条对角线段中奇数位像素（恢复为背景色）。灰(5)模板本身保留不变。

**关键洞察**：对角线段本身不是碎片——必须先通过奇偶位筛选去掉"干扰像素"，剩余像素才构成可与模板匹配的空间碎片。

## 新题 7：分栏面板中异常块提取后按三角数位置拼装

**组合逻辑**：[分栏面板 + 逆序扫描](已有) → [颜色多样性比较 + 异常值选择 + 裁剪](已有) → [三角数位置](创新改造：三角数不用于单行像素，而用于块的放置间距)

**来源原语**：分栏面板/分隔列/逆序扫描(25c199f5)、实心小块/颜色多样性比较/异常值选择/颜色最多者入选(9a4bb226)、裁剪/crop(9a4bb226)、三角数位置/递增间距序列(72207abc)

**依赖链**：面板分割 → 每个面板内独立做异常值选择（颜色最多的块）→ 裁剪异常块 → 按逆序面板顺序 + 三角数列间距放置。面板分割决定分组，异常值选择决定内容，三角数位置决定布局——三者正交且缺一不可。

多面板中各选出颜色最丰富的异常小块，按面板逆序在输出行中以三角数间距排列。

**输入结构**：约 5x21 的网格（宽大于高）。由 2 条灰(5)全高分隔列将网格分为 3 个等宽面板（每个面板约 5x6）。每个面板包含 2~3 个互不相邻的实心小块（每个小块占据 2x2 或 3x2 区域），小块内部像素使用不同颜色填满。在每个面板中，恰好一个小块使用了 3 种不同颜色，其余小块仅使用 2 种颜色。背景为黑(0)。生成约束：3 个异常块的尺寸相同（统一为 hxw）。

**规则**：
1. 识别灰(5)全高分隔列，将网格分为 3 个面板。
2. 在每个面板中，识别所有连续的非背景矩形区域（实心小块）。
3. 对每个小块统计其包含的不同颜色数。选出每个面板中颜色数最多的小块（即异常块，恰好使用 3 种颜色）。
4. 裁剪每个异常块为 hxw 子网格。
5. 按面板从右到左的顺序排列异常块（最右面板的异常块排第 1 个，最左排最后）。
6. 输出网格高度为 h，宽度足够容纳所有块及间距。将异常块依次放置在列位置 0、1、3（即三角数 T_0=0, T_1=1, T_2=3）处（每个位置指该块左列的起始列号），块之间的间隙用背景色填充。

**关键洞察**：输出中块的间距呈递增模式（间隔为 1、2、3...），但块的内容和顺序取决于面板内的异常值筛选和面板的逆序扫描——仅观察间距模式无法确定内容，仅观察内容无法确定布局。

## 新题 8：路径穿越腔室触发邻接多数决填充

**组合逻辑**：[寻路 + 逐步推进 + 遇障碍则绕行](已有) → [连通腔室](已有，但腔室的填充由路径访问触发而非全部填充) → [邻接多数决](已有，决定填充颜色)

**来源原语**：寻路/逐步推进/遇障碍则绕行/起点像素(d9f24cd1)、连通腔室/分隔墙/正交邻接/邻接多数决/填充(7c8af763)

**依赖链**：路径从底部起点向上生长 → 路径穿越腔室壁时进入新腔室 → 仅被路径访问过的腔室执行邻接多数决填充 → 未访问腔室保持空白。路径选择了填充的对象集合，多数决选择了填充的颜色——删除路径则不知道填哪些腔室，删除多数决则不知道填什么颜色。

从底部起点向上生长的路径穿越若干腔室，被穿越的腔室以其边界标记像素的多数颜色填充。

**输入结构**：约 14x10 的网格，黑(0)背景。灰(5)分隔墙将网格内部分成 4~6 个 4-连通的背景腔室，墙不延伸到网格边界（腔室之间至少有一个像素宽的通道或墙上有间隙）。每个腔室的墙壁上正交相邻的位置放置 2~4 个彩色标记像素（从红(2)、绿(3)、黄(4)、蓝(1)中选），每个腔室有一种多数标记颜色。底行某一列有一个栗(9)起点像素。生成约束：路径从起点出发能通过墙间隙到达至少 2 个但不是全部腔室；每个腔室的标记颜色中存在唯一多数色。

**规则**：
1. 从栗(9)起点像素向上逐行推进。
2. 若上方一格为墙壁(灰(5))，则向右偏移一格后继续向上（遇障碍绕行）。若右侧也是墙壁或网格边界，则向左偏移一格后继续向上。若左右均不可行则路径终止。
3. 路径经过的每个格涂为栗(9)。路径到达顶行或无法继续时终止。
4. 记录路径经过的所有腔室（路径像素所在的 4-连通背景区域）。
5. 对每个被路径访问过的腔室，收集与该腔室正交相邻（共享边）的所有标记像素颜色，取出现次数最多的颜色，将整个腔室（除路径像素和墙壁外的背景格）填充为该颜色。
6. 未被路径访问的腔室保持黑(0)不变。灰(5)墙壁和标记像素保留原位。

**关键洞察**：路径的几何形状决定了哪些腔室"被激活"——改变起点列就会改变路径穿越的腔室集合，从而改变哪些区域被填充，这是局部路径选择与全局填充结果的非显然耦合。

## 新题 9：精灵体分离后按引导条方向压缩为线段的四角布局

**组合逻辑**：[分离 + 精灵体](已有) → [像素数决定长度](已有) + [引导条决定朝向](已有) → [四角布局 + 插入空行列间隔](创新改造：放置的不是原始精灵体而是压缩后的线段)

**来源原语**：分离/精灵体/四角布局/插入空行列间隔(b1fc8b8e)、引导条/引导条决定朝向/像素数决定长度/线段/重建(c61be7dc)

**依赖链**：分离 → 得到单个精灵体的掩码和像素数 → 引导条确定线段朝向 → 像素数确定线段长度 → 四角布局确定放置位置。精灵体内容决定长度，引导条决定朝向，四角布局决定排列——三者交织，分离是入口，布局是出口，中间的压缩步骤不可跳过。

紧密排列的精灵体被分离，每个精灵体根据自身像素数被压缩为一条线段，按引导条指示的朝向在四角布局中排列。

**输入结构**：约 8x8 的网格，黑(0)背景。前景为蓝(1)像素，组成 4 个相同 2x2 掩码的平移副本紧密排列（与参考题 b1fc8b8e 类似的 6x6 区域）。网格右侧或下方有一对橙(7)引导条：两条平行的短线段（2~3 像素长），若为水平线段则指示水平朝向，若为垂直线段则指示垂直朝向。生成约束：4 个精灵体可被唯一地分离为相同掩码的 4 个平移副本。

**规则**：
1. 识别蓝(1)前景区域，找到唯一的 2x2 掩码使得该掩码的 4 个平移副本恰好覆盖全部蓝像素。
2. 计算每个精灵体的前景像素数 p（即掩码中蓝色像素的数量，每个都是 p）。
3. 检测橙(7)引导条的朝向：若引导条为水平线段则朝向 = 水平，否则为垂直。
4. 构造输出网格：若朝向水平，输出为 (1+gap+1) 行 x (p+gap+p) 列 = 3 行 x (2p+1) 列，gap=1；若朝向垂直，输出为 (p+gap+p) 行 x (1+gap+1) 列 = (2p+1) 行 x 3 列。
5. 在输出的四角各放置一条长度为 p 的蓝(1)线段（水平朝向则为水平线段，垂直朝向则为垂直线段）。四条线段分别占据左上角、右上角、左下角、右下角，中间由 1 行/列背景间隔分隔。
6. 引导条不出现在输出中。

**关键洞察**：输入中看到的是紧密堆叠的二维精灵体，但输出是一维线段——精灵体的面积信息被压缩为长度，而引导条决定了压缩的方向维度，二者缺一则输出不唯一。

## 新题 10：阻挡点发射正交线后封闭区域的奇偶位筛选填充

**组合逻辑**：[对角线对齐 + 射线延伸 + 阻挡点发射正交线](已有) → [封闭区域检测](创新：射线交叉产生的封闭区域，类比容器) → [交替选取 + 填充](创新改造：按扫描序对封闭区域编号，奇偶位决定是否填充)

**来源原语**：对角线对齐/射线延伸/对角线上阻挡/阻挡点发射正交线(55783887)、容器/填充(db7260a4)、交替选取/奇偶位决定涂色(d406998b)

**依赖链**：主对角线绘制 → 阻挡点发射正交对角线 → 多条线交叉形成封闭区域 → 对封闭区域按行优先扫描编号 → 奇数位区域填充。无射线则无分割，无阻挡点则无正交线，无封闭区域则无填充目标，无奇偶筛选则全部填充。

一条主对角线上的阻挡点发射垂直对角线，射线交叉后围成若干封闭区域，按扫描序每隔一个区域填充一次。

**输入结构**：约 13x13 的网格，黑(0)背景。有一对蓝(1)标记像素位于同一条右下对角线的两端（如左上角和右下角附近）。在该对角线路径上有 2~3 个红(2)阻挡像素。生成约束：阻挡点之间间距至少 3 格；阻挡点发射的垂直对角线在网格内交叉，形成至少 4 个完全封闭的（被线段和网格边界围成的）4-连通背景区域。

**规则**：
1. 在两个蓝(1)端点之间绘制完整的右下对角线，颜色为蓝(1)。红(2)阻挡像素保留在对角线上不被覆盖。
2. 每个红(2)阻挡像素向两个垂直对角方向（左下和右上）发射红(2)射线，射线延伸直到到达网格边界，不覆盖已有的蓝(1)或红(2)像素（遇到则停止，不含终点）。
3. 所有射线绘制完毕后，识别网格中所有被线段像素和网格边界完全围成的 4-连通背景区域（封闭区域）。
4. 按行优先顺序（先按区域最小行号升序，同行按最小列号升序）对封闭区域编号：1, 2, 3, 4, ...。
5. 将编号为奇数（1, 3, 5, ...）的封闭区域填充为绿(3)。偶数编号的封闭区域保持黑(0)。
6. 所有线段像素（蓝和红）保留不变。

**关键洞察**：封闭区域的数量和形状完全由阻挡点的位置决定——移动一个阻挡点就会改变射线交叉的几何关系，从而改变封闭区域的划分和奇偶编号，使得填充模式发生全局变化。
