## 新题 1：标记计数驱动旋转，旋转后面积决定堆叠序

**组合逻辑**：[计数 counting](创新：计数结果不直接编码到输出，而是作为旋转参数) → [旋转 rotate](已有) → [排序 sort + 堆叠 stack](创新：排序依据是旋转后而非旋转前的面积)

**来源原语**：计数 counting（参考题 #2 794b24be, #8 6773b310），旋转 rotate（参考题 #16 11852cab, #18 fd4b2b02），排序 sort + 堆叠 stack + 角对齐 corner_aligned + 按面积降序 largest_to_smallest_area（参考题 #7 20818e16），标记像素 marker_pixel（参考题 #8 6773b310）

**依赖链**：标记像素的计数决定旋转次数 → 旋转改变非正方形图形的包围盒宽高比 → 旋转后的包围盒面积重新排列了堆叠顺序 → 堆叠时的遮挡关系依赖于该顺序。删除计数环节则旋转无据；删除旋转环节则排序退化为原始面积排序（与参考题 #7 相同）；删除排序堆叠则旋转无意义。

将散落的非正方形彩色图形按各自灰(5)标记像素数量旋转后，以旋转后包围盒面积降序堆叠于左上角。

**输入结构**：黑(0)背景，约 20x20 网格。散布 3-5 个互不重叠的单色 4-连通前景图形，每个图形使用不同的非黑非灰颜色（如红(2)、绿(3)、黄(4)、蓝(1)等），形状为非正方形的紧凑连通区域（3~8 像素，包围盒宽高不等）。每个图形旁边（4-邻域外一格处）有 0~3 个灰(5)像素作为标记，标记与其关联图形的距离最近（每个标记归属于距离其包围盒最近的那个图形）。生成约束：不同图形的标记区域互不混淆（每个灰像素与恰好一个图形最近）。

**规则**：
1. 将每个灰(5)标记像素归属于包围盒中心与其欧氏距离最近的图形（生成时保证归属无歧义）。
2. 统计每个图形关联的灰标记像素数量 N（0~3）。
3. 将每个图形以其包围盒中心为旋转中心，顺时针旋转 N x 90 度。旋转后重新计算其最小包围盒。
4. 以所有旋转后图形中最大的包围盒宽度为输出宽度、最大的包围盒高度为输出高度，创建黑(0)背景输出网格。
5. 按旋转后的包围盒面积从大到小排列图形（面积相同时，按图形在输入中包围盒左上角的行优先坐标升序排列）。
6. 依次将图形绘制到输出网格的左上角（0,0）对齐，后绘制的覆盖先绘制的。
7. 灰标记像素不出现在输出中。

**关键洞察**：同一图形旋转 0 度和 180 度包围盒相同，但旋转 90 度时宽高互换导致面积不变而形状改变——真正改变堆叠可见性的是宽高比翻转后的遮挡关系，而非面积本身；需要对比多个示例才能确认旋转参数来自标记计数而非其他属性。

## 新题 2：对角射线划分区域，区域归属决定填色

**组合逻辑**：[射线延伸 ray_extend + 对角放射 diagonal_radiation](已有) → [网格分区 grid_partition](创新：分区边界由对角线交叉涌现而非预设分隔线) → [填充 fill](创新：填色由区域边界归属关系决定)

**来源原语**：射线延伸 ray_extend + 对角放射 diagonal_radiation + 延伸至边界 extend_to_edge（参考题 #17 ea786f4a），网格分区 grid_partition（参考题 #8 6773b310），填充 fill（参考题 #9 b0c4d837, #19 e9afcf9a），孤立像素 isolated_pixel（参考题 #17 ea786f4a）

**依赖链**：孤立像素的位置决定对角线的走向 → 对角线交叉涌现出区域边界（非预设分区） → 每个区域的边界射线归属决定填色 → 填色结果依赖于所有像素的射线布局（全局约束）。这是一个同时约束满足结构：所有射线必须先全部绘制，才能识别封闭区域，才能判断归属。

在均匀背景上放置若干彩色孤立像素，从每个像素发射四方向对角射线至边界；射线交叉将网格切分为多边形区域，仅被单一来源像素的射线包围的区域填为该像素颜色。

**输入结构**：橙(7)均匀背景，约 15x15 网格。2~3 个孤立前景像素，每个颜色不同（如红(2)、蓝(1)、绿(3)），彼此不在同一行、同一列或同一对角线上（保证射线不重合）。无其他前景元素。生成约束：像素位置使得对角射线在网格内部产生至少 2 个交叉点，形成足够的封闭区域。

**规则**：
1. 保留输入网格的全部内容。
2. 从每个孤立彩色像素出发，沿四个对角方向（左上、右上、左下、右下）逐像素绘制黑(0)射线，直到到达网格边界（包含边界像素）。射线覆盖原有背景色。
3. 射线将网格划分为若干 4-连通的非黑区域（每个区域内部不含黑像素）。
4. 对每个非黑区域，检查其边界（与该区域 4-相邻的所有黑像素）属于哪些来源像素的射线。若该区域的边界射线全部来自同一个来源像素，则将该区域所有像素重涂为该来源像素的颜色。
5. 若一个区域的边界射线来自 2 个及以上不同来源像素，则该区域保持橙(7)背景色不变。
6. 来源像素自身保持原色不变。射线交叉点处（同一像素被多条射线经过），该像素仍为黑(0)。

**关键洞察**：区域归属不取决于距离最近的来源像素，而取决于包围该区域的射线是否全部源自同一像素——一个几何上紧邻某像素的区域，如果它的边界包含了另一个远处像素的射线，就不会被填色；需要对比多个示例中像素位置变化导致的归属翻转才能归纳出此规则。

## 新题 3：框内色彩多样性编码拉伸距离，标记方位编码拉伸方向

**组合逻辑**：[计数 counting](创新：计数对象是颜色种类数而非像素数) + [方向指示 direction_indication](创新：由外部标记像素的方位而非对象自身形态决定) → [拉伸 stretch](已有) → [重涂色 recolor + 内外分离 interior_exterior_sep](创新：拉伸后的新内部区域统一重涂)

**来源原语**：计数 counting + 色数决定倍率 color_count_scale（参考题 #13 d4b1c2b1），拉伸 stretch + 标记决定拉伸终点 marker_determines_stretch_endpoint（参考题 #5 b548a754），方向指示 direction_indication（参考题 #11 25d487eb），重涂色 recolor + 内外分离 interior_exterior_sep + 保留边框涂内部 keep_border_fill_inside（参考题 #20 50cb2852），空心矩形 hollow_rectangle（参考题 #5 b548a754），标记像素 marker_pixel（参考题 #5 b548a754）

**依赖链**：框内散布像素的颜色种类数 → 拉伸距离（非来自空间位置，而来自颜色信息）；标记像素相对框的方位 → 拉伸方向；拉伸改变框的几何形状 → 新的内外边界 → 重涂内部。删除色彩计数则拉伸距离无据；删除标记方位则拉伸方向无据；删除内外分离重涂则拉伸效果不完整。三路信息（距离、方向、涂色目标）汇聚到拉伸操作。

统计空心矩形内部散布像素的颜色种类数作为拉伸步长，按外部标记像素的方位拉伸框架，然后将拉伸后的完整内部重涂为标记色。

**输入结构**：黑(0)背景，约 18x18 网格。包含 2~3 个互不重叠的空心矩形框（每个框至少 5x5，边框为单一颜色如蓝(1)、绿(3)等，边框宽度 1 像素，内部为黑色背景）。每个框的内部散布若干彩色像素（1~4 种不同颜色，总共 2~6 个像素，颜色选自非边框色、非背景色、非标记色的可用色）。每个框外部恰好有 1 个标记像素，与该框的某一条边在行或列方向上对齐（即标记像素位于框的正上方、正下方、正左方或正右方，与框边的延长线上），距离框边 1~3 像素。标记像素的颜色为红(2)或黄(4)，与框的边框色不同。生成约束：每个框的标记像素方位各不相同；框内像素颜色种类数在 1~4 之间且各框不完全相同；拉伸后的框不超出网格边界且互不重叠。

**规则**：
1. 对每个空心矩形框，统计其内部（不含边框像素）所有非背景像素的颜色种类数 K。
2. 找到该框外部的标记像素，确定标记相对于框的方位（上、下、左、右）。
3. 将框的对应边沿标记方向向外平移 K 个像素，扩展框架：新边框用原框的边框颜色绘制，框的其他三条边保持原位。
4. 将拉伸后的框的完整内部区域（新边界以内、边框以外的所有像素）全部重涂为该框的标记像素颜色。原先框内部的散布像素被覆盖。
5. 移除标记像素（该位置如果在新边框上则为边框色，否则为背景色）。
6. 处理顺序：按框的包围盒面积从小到大处理；若拉伸后区域与后续框重叠，后处理的框覆盖先处理的框的像素。

**关键洞察**：框内部的散布像素不是装饰，而是通过颜色多样性编码了拉伸步长——像素的位置和数量无关紧要，只有颜色种类数起作用；需要对比多个示例中不同种类数与拉伸距离的对应关系才能发现这一非显然映射。

## 新题 4：对称补全恢复晶格，然后沿标记行列带重涂

**组合逻辑**：[对称补全 symmetry_completion + 旋转对称 rotational_symmetry](已有) → [标记行列选择 marker_row_column_selection + 重涂色 recolor](已有)（创新：补全操作恢复的像素也参与被重涂的行列带，形成"先修复再标记"的依赖）

**来源原语**：对称补全 symmetry_completion + 旋转对称 rotational_symmetry + 旋转恢复缺失像素 rotation_restores_missing（参考题 #16 11852cab），重涂色 recolor + 标记行列选择 marker_row_column_selection + 行列带穿越标记 row_column_band_through_marker（参考题 #4 4f537728），晶格网格 lattice_grid + 标记块 marker_block（参考题 #4 4f537728）

**依赖链**：晶格部分缺损 → 对称补全恢复完整晶格（补全后新增的像素可能落在标记的行列带上） → 标记块的行列带选择在完整晶格上执行重涂。若先做行列带重涂再补全，则补全后新像素不会被涂色（结果不同）；若不做补全，则行列带上部分位置缺少晶格像素无法被涂（结果也不同）。两个操作的顺序耦合于补全像素是否落在行列带内。

在一个部分缺损的晶格网格上，先利用 90 度旋转对称补全缺失像素，再将标记块所在行列上的全部晶格像素重涂为标记色。

**输入结构**：黑(0)背景，约 15x15 网格。前景由蓝(1)像素构成的规则晶格图案（如每隔 3 行 3 列出现一个蓝像素的点阵，或每隔 2 行 2 列出现一个 1 像素宽的十字交叉线），整体关于网格中心具有 90 度旋转对称性。晶格的一个象限区域有若干蓝像素被擦除为黑(0)（约占该象限蓝像素的 30%~60%），模拟缺损。在缺损区域内嵌入一个 2x2 的标记块，颜色为红(2)，占据晶格交叉点位置（标记块的位置恰好在晶格图案中某个应有蓝像素的位置上）。生成约束：缺损区域连通且仅在一个象限内；标记块所在的行和列上至少各有 3 个原始（未缺损）晶格像素；补全后标记块的行列上至少新增 1 个恢复的晶格像素。

**规则**：
1. 检测晶格网格的旋转对称中心（网格几何中心）。
2. 将所有非黑、非标记色的前景像素（蓝(1)）通过 90 度、180 度、270 度旋转映射到其他三个对称位置。若对称位置为黑(0)，则填入蓝(1)以恢复缺损。
3. 标记块（红(2)像素）不参与旋转补全——不在其旋转对称位置填入红色。
4. 补全完成后，找到标记块占据的 2 行和 2 列。
5. 将这 2 行和 2 列上所有蓝(1)晶格像素重涂为红(2)。
6. 背景像素和标记块本身保持不变。

**关键洞察**：标记块故意放置在缺损区域内，使得其行列带上的部分晶格像素在补全之前不存在——求解者必须先补全再重涂，否则会漏涂补全后新增的像素；需对比示例中缺损位置不同导致的重涂范围变化来确认这一顺序依赖。

## 新题 5：射线可达性筛选目标矩形，面积排序决定保留或擦除

**组合逻辑**：[射线投射 ray_cast + 视线可达 line_of_sight](已有) → [筛选 filter](创新：筛选标准不是几何属性而是射线可达性) → [排序 sort + 按面积降序 largest_to_smallest_area](已有) → [重涂色 recolor / 擦除 erase](创新：排序名次映射到不同操作——保留、重涂、擦除三种分支)

**来源原语**：射线投射 ray_cast + 视线可达 line_of_sight + 可见行数最多 max_visible_rows + 忽略干扰项 ignore_distractors（参考题 #12 3d588dc9），排序 sort + 按面积降序 largest_to_smallest_area（参考题 #7 20818e16），筛选 filter + 最小尺寸过滤 minimum_size_filtering（参考题 #6 0a1d4ef5），重涂色 recolor（参考题 #4 4f537728），擦除 erase（参考题 #12 3d588dc9），填充矩形 filled_rectangle（参考题 #6 0a1d4ef5, #7 20818e16），源区域 source_region（参考题 #12 3d588dc9）

**依赖链**：源区域位置 → 射线可达性判定哪些矩形被"看见" → 被看见的矩形集合进入排序 → 排序名次决定操作类型（第 1 名保留、第 2 名重涂、其余擦除）。未被看见的矩形不参与排序，保持原样。删除射线环节则所有矩形都参与排序（结果不同）；删除排序则无法区分保留与擦除；删除分支操作则排序无意义。

从灰色源区域水平射出射线，仅射线可达的矩形参与面积排序；排序第一名保留原色，第二名重涂为灰色，其余擦除。

**输入结构**：黑(0)背景，约 20x18 网格。一个灰(5)源区域（约 2x3 的实心矩形）位于网格左侧或右侧。4~6 个单色实心矩形散布于网格中，每个矩形尺寸在 2x2 到 5x4 之间，颜色各不相同（选自蓝(1)、红(2)、绿(3)、黄(4)、橙(7)、品红(6)），矩形之间不重叠。另有 2~4 个单像素干扰点（栗(9)色），散布于网格中。生成约束：从源区域的每一行像素向左右两侧水平延伸射线时，至少有 2 个矩形可被射线直接到达（射线路径上只经过背景像素即到达矩形边缘），且至少有 1 个矩形被其他矩形遮挡而不可达；干扰点不阻挡射线（射线穿过干扰点继续延伸）。

**规则**：
1. 忽略所有栗(9)色单像素干扰点（它们不阻挡射线，不参与任何逻辑）。
2. 从灰(5)源区域的每一行像素出发，向左和向右发射水平射线。射线沿水平方向逐像素前进，遇到非背景、非干扰色的像素时停止（到达某个矩形的边缘）。
3. 一个矩形是"可达的"当且仅当存在至少一条射线到达了它的某个边缘像素。
4. 收集所有可达矩形，按面积（宽 x 高）从大到小排序。面积相同时，按矩形左上角行坐标升序排列。
5. 排序后：第 1 名矩形保持原色不变；第 2 名矩形整体重涂为灰(5)；第 3 名及之后的所有可达矩形擦除为黑(0)背景。
6. 不可达的矩形保持原色和原位不变。
7. 源区域保持灰(5)不变。干扰点擦除为背景色。

**关键洞察**：一个面积很大的矩形如果被另一个矩形完全挡住射线而不可达，它不参与排序因此保持原样——而一个面积较小但可达的矩形可能反而成为排序第一名被保留；求解者需要对比示例中矩形空间布局变化对可达性的影响来理解"可达"而非"存在"是排序的入场条件。

## 新题 6：邻居计数同时决定放大倍率与对角标记条件

**组合逻辑**：[计数 counting](创新：计数对象是 4-邻域前景邻居数，且同一次计数同时产出全局参数和逐像素条件) → [像素放大 pixel_upscale](已有) → [连线 draw_line + 对角共线 diag_collinear](创新：标记条件由邻居数与全局最大值的比较决定，而非由背景/前景身份决定)

**来源原语**：像素放大 pixel_upscale + 连线 draw_line + 对角共线 diag_collinear + 共对角背景标记 bg_diag_marked（参考题 #1 f0afb749），计数 counting + 色数决定倍率 color_count_scale（参考题 #13 d4b1c2b1），前景像素 fg_pixel + 对角线标记 diag_marker（参考题 #1 f0afb749）

**依赖链**：全部前景像素的 4-邻域邻居计数 → 取全局最大值 M 作为放大倍率 → 每个前景像素放大为 MxM 块 → 邻居数 < M 的像素在其 MxM 块中仅绘制主对角线（而非实心块），邻居数 = M 的像素为实心块。全局参数和逐像素属性来自同一次计数运算，耦合于 M 的值：M 变化时既改变了输出尺寸，也改变了哪些像素获得对角标记。

统计每个前景像素的 4-连通前景邻居数，取最大值作为放大倍率；邻居数等于最大值的像素放大为实心块，其余放大为仅含主对角线的空心块。

**输入结构**：黑(0)背景，小网格（4x4 至 6x6）。前景像素 3~8 个，使用 1~3 种非黑颜色（如红(2)、绿(3)等），形成不规则的 4-连通图形。前景像素的 4-邻域前景邻居数范围在 1~4 之间，且不全相同（至少存在两种不同的邻居数）。生成约束：最大邻居数 M 在 2~4 之间（保证输出尺寸合理，即输出为 (M x 输入行数) x (M x 输入列数)）。

**规则**：
1. 对每个前景像素，计算其上下左右四个方向中有多少个相邻像素也是前景（不论颜色），得到该像素的邻居数 N_i。
2. 取所有前景像素邻居数的最大值 M。
3. 创建输出网格，高度 = M x 输入高度，宽度 = M x 输入宽度。
4. 将每个输入像素映射到输出中对应的 MxM 子块：
   - 背景像素(0)：MxM 子块全部为黑(0)。
   - 前景像素且 N_i = M：MxM 子块全部填为该像素的原色（实心块）。
   - 前景像素且 N_i < M：MxM 子块中仅主对角线位置（即子块内 (r, c) 满足 r = c 的像素，r 和 c 从 0 开始）填为蓝(1)，其余位置为黑(0)。
5. 无其他后处理。

**关键洞察**：放大倍率不是固定常数也不是颜色种类数，而是前景像素中邻居数的峰值——这意味着在输入中增减一个像素可能同时改变输出尺寸和对角标记模式；求解者需要对比多个示例中不同连通结构下的倍率变化才能发现"最大邻居数 = 倍率"这一编码关系。

## 新题 7：精灵朝向决定象限拼合，拼合瓦片交替镜像平铺

**组合逻辑**：[裁剪 crop + 朝向映射 orientation_mapping + 缺角决定目标象限 missing_corner_determines_quadrant](已有) → [平铺 tiling + 镜像 mirror + 奇偶位交替翻转 alternating_flip](已有)（创新：两个源题各自独立的变换嵌套为"先拼合再平铺"的层级结构，拼合结果成为平铺的种子瓦片，且镜像翻转使得象限中精灵的朝向在相邻瓦片中反转，产生涌现的全局对称图案）

**来源原语**：裁剪 crop + 朝向映射 orientation_mapping + 缺角决定目标象限 missing_corner_determines_quadrant + 精灵体 sprite + 象限区 quadrant（参考题 #14 a61ba2ce），平铺 tiling + 镜像 mirror + 奇偶位交替翻转 alternating_flip + 瓦片 tile（参考题 #10 bc4146bd）

**依赖链**：精灵朝向 → 象限分配 → 组装成 4x4 种子瓦片 → 种子瓦片的内部结构（含中心 2x2 空洞）决定了镜像翻转后的外观 → 交替原像/镜像平铺扩展画布。删除朝向映射则无法正确拼合种子瓦片；删除平铺则只有单瓦片输出（与参考题 #14 相同）。两者的耦合在于：种子瓦片中精灵的不对称分布使得镜像版本与原版视觉上显著不同，而平铺后相邻瓦片边界处的精灵恰好形成新的对称图案。

四个三像素 L 形精灵按缺角方位拼入 4x4 瓦片的对应象限，再将该瓦片以交替左右镜像方式铺满 3x3 网格。

**输入结构**：黑(0)背景，约 15x15 网格。恰好 4 个三像素 L 形精灵（每个占据 2x2 包围盒中的 3 个像素，缺少 1 个角），每个精灵使用不同颜色（选自蓝(1)、红(2)、绿(3)、黄(4)），四个精灵的缺角方位分别为左上、右上、左下、右下（各一个，不重复）。精灵散布于网格各处，互不接触。生成约束：四种缺角方位恰好各出现一次。

**规则**：
1. 裁剪每个精灵到其 2x2 包围盒。
2. 按照缺角方位与象限的对应关系放置到 4x4 种子瓦片中：缺角在右下 → 放左上象限（第 0~1 行、第 0~1 列）；缺角在左下 → 放右上象限（第 0~1 行、第 2~3 列）；缺角在右上 → 放左下象限（第 2~3 行、第 0~1 列）；缺角在左上 → 放右下象限（第 2~3 行、第 2~3 列）。每个精灵的缺角朝向种子瓦片的中心，使中心形成 2x2 黑(0)空洞。
3. 创建 12x12 的输出网格（3 行 x 3 列的 4x4 瓦片）。
4. 在 3x3 的瓦片网格中，按行优先从左上到右下填充：瓦片位置 (R, C) 中，若 (R + C) 为偶数，放置种子瓦片原像；若 (R + C) 为奇数，放置种子瓦片的左右镜像。
5. 无其他后处理。

**关键洞察**：种子瓦片自身不具备左右对称性（四个精灵颜色和位置不对称），因此镜像版和原版是不同的——平铺后相邻瓦片在边界处的精灵形成互为镜像的配对，产生一种棋盘状的全局对称性，这一图案不存在于任一源题中，是拼合与镜像平铺两步耦合后的涌现效果。

## 新题 8：分隔网格内连通性过滤标记，过滤后计数驱动螺旋仪表

**组合逻辑**：[网格分区 grid_partition](已有) → [筛选 filter](创新：筛选标准是区域内 4-连通性而非几何尺寸) → [计数 counting](已有) → [压缩 compress + 螺旋填充 spiral_fill](创新：每个分区压缩为 3x3 仪表盘，螺旋长度编码过滤后的计数)

**来源原语**：网格分区 grid_partition + 分隔线 separator_line + 双标记区域出前景 dual_marker_foreground（参考题 #8 6773b310），筛选 filter + 忽略干扰项 ignore_distractors + 最小尺寸过滤 minimum_size_filtering（参考题 #6 0a1d4ef5, #12 3d588dc9），计数 counting（参考题 #2 794b24be, #8 6773b310），螺旋填充 spiral_fill + 仪表盘 gauge_output + 空行数映射填充量 empty_rows_map_to_fill_amount（参考题 #9 b0c4d837），压缩 compress + 包围盒行列分组 bbox_row_column_grouping（参考题 #6 0a1d4ef5），标记像素 marker_pixel（参考题 #8 6773b310）

**依赖链**：分隔线划分区域 → 每个区域内的标记像素需要通过连通性过滤（只保留与至少一个其他标记 4-相邻的标记，剔除孤立标记） → 过滤后的计数驱动螺旋仪表的填充长度 → 每个区域压缩为一个 3x3 仪表格。删除分区则无法确定"同区域内"的连通判定边界；删除连通性过滤则计数值不同（包含了干扰项）；删除螺旋映射则计数无处编码。三步之间信息逐步变换而非简单传递。

在分隔线划分的网格中，过滤掉每个区域内的孤立标记像素（仅保留与同区域其他标记 4-相邻的），然后将每个区域的有效标记数编码为 3x3 顺时针螺旋仪表盘，输出紧凑网格。

**输入结构**：黑(0)背景，约 15x15 网格。灰(5)色全宽行和全高列作为分隔线，将网格分为 3x3 共 9 个矩形区域（每个区域约 4x4 大小）。每个区域内有 1~6 个红(2)标记像素。其中部分标记像素彼此 4-相邻（即在同一区域内上下左右相邻），部分标记像素是孤立的（4-邻域内无其他红像素，或其 4-邻居中的红像素属于分隔线另一侧的不同区域）。生成约束：每个区域内至少有 1 个孤立标记和 1 个非孤立标记（保证过滤有实际效果）；过滤后每个区域的有效标记数在 0~8 之间（适配 3x3 螺旋的 8 个非中心格 + 中心格 = 9 格容量）；分隔线为 1 像素宽。

**规则**：
1. 识别所有灰(5)全宽行和全高列作为分隔线，将网格划分为矩形区域。
2. 对每个区域，检查其中的红(2)标记像素：若某个红像素在该区域内部的 4-邻域中没有任何其他红像素，则视为孤立标记，过滤掉（不计入有效标记）。
3. 统计每个区域内的有效标记数量 V（仅包括与至少一个同区域红像素 4-相邻的红像素）。
4. 创建 3x3 输出网格（对应 9 个区域的紧凑布局，行列顺序与输入区域的行列顺序一致）。每个输出格为一个 3x3 子块，共形成 9x9 的总输出。
5. 对每个 3x3 子块，以黑(0)为底色，从左上角开始沿顺时针螺旋方向（右→下→左→上→中心）依次填充 V 个红(2)像素。螺旋顺序为：(0,0)→(0,1)→(0,2)→(1,2)→(2,2)→(2,1)→(2,0)→(1,0)→(1,1)。
6. V = 0 时，该子块保持全黑。

**关键洞察**：区域边界（分隔线）对连通性判定至关重要——两个红像素在像素坐标上 4-相邻但被分隔线隔开时不算连通，因此同一个红像素在不同的分隔线布局下可能被保留或过滤；求解者必须理解"同区域内的 4-连通性"而非"全局 4-连通性"才能正确计数。
