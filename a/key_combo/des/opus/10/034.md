## 新题 1：缺口编码镜像轴与叠加不对称检测

**组合逻辑**：[缺口方向](创新：从射线方向改为编码镜像轴) + [镜像] + [逐像素比较/叠加](创新：原图与镜像图叠加分类) + [重涂色]

**来源原语**：缺口方向决定射线(551d5bf1) + 镜像(62c24649) + 逐像素比较(94f9d214) + 重涂色(9473c6fb)

**依赖链**：缺口位置决定镜像轴的选择 → 镜像操作生成对照图 → 原图与对照图逐像素比较产生三类像素 → 分类结果决定最终涂色。删除缺口检测则无法确定镜像轴；删除比较则无法区分对称与非对称区域。

将每个带缺口框架的内部图案沿缺口所指方向的垂直轴镜像，然后与原图案叠加，将像素按对称性分为三类并分别涂色。

**输入结构**：约 20x20 的网格，黑(0)背景。包含 2~3 个蓝(1)空心矩形框（边框宽 1 像素，每个框约 6x6 至 8x8），每个框恰好有一个边框缺口（某条边上缺少一个非角像素）。每个框内部包含一个由红(2)像素组成的不规则非对称 4-连通图案（3~7 像素）。不同示例中，缺口可能在框的上、下、左、右任一侧；内部图案的具体形状各不相同但均为非对称。各框互不相邻，间距至少 2 像素。生成约束：每个框的内部图案关于缺口所决定的镜像轴不完全对称（至少有一个像素不对称），以确保三类像素都存在。

**规则**：
1. 对每个蓝(1)框，定位其唯一的边框缺口像素位置。缺口在上边或下边 → 该框的镜像轴为水平轴（即沿框内部区域的水平中线上下翻转）；缺口在左边或右边 → 镜像轴为垂直轴（沿框内部区域的垂直中线左右翻转）。
2. 将框内部区域（不含边框本身）沿确定的轴做镜像，生成一个同尺寸的对照图案。
3. 逐像素比较原图案与对照图案：
   - 两者都是红(2)（即该位置关于镜像轴对称地存在前景）→ 保持红(2)不变。
   - 原图案为红(2)但对照为黑(0)（即该位置只在原图中有前景）→ 涂为绿(3)。
   - 原图案为黑(0)但对照为红(2)（即该位置只在镜像图中有前景）→ 涂为黄(4)。
   - 两者都是黑(0) → 保持黑(0)不变。
4. 修补缺口：将缺口位置的像素恢复为蓝(1)。
5. 蓝(1)边框像素和框外区域保持不变。

**关键洞察**：边框缺口不是需要修补的瑕疵，而是编码镜像轴方向的信号。输出中的三种颜色揭示了内部图案相对于缺口所编码轴的对称结构，这要求同时理解缺口的几何含义和叠加比较的逻辑。

## 新题 2：柱高算术参数化模板复制数量

**组合逻辑**：[高度加减运算](已有) + [计数](创新：算术结果作为复制次数而非直接输出) + [裁剪] + [重涂色] + [排序拼接]

**来源原语**：高度加减运算/颜色编码正负(37ce87bb) + 计数(08ed6ac7) + 裁剪(12997ef3) + 重涂色(12997ef3) + 排序拼接/按位置排序标记(12997ef3)

**依赖链**：柱高算术计算出数值 N → N 决定从标记序列中取前 N 个 → 每个被选中标记的颜色驱动模板重涂 → 重涂后的模板按标记顺序拼接为输出。删除算术则无法确定取几个标记；删除标记排序则拼接顺序不确定。

对左区的彩色竖条做加减算术得到 N，从右区的标记序列中取前 N 个，将模板依次重涂为各标记颜色后纵向拼接输出。

**输入结构**：约 15x20 的网格，黑(0)背景。左半区包含 3~5 根底部对齐的单像素宽竖条，青(8)竖条为正值、红(2)竖条为负值，高度各不相同（2~7 像素）。右半区包含一个灰(5)多像素模板图案（一个 3x3 至 4x4 的不规则 4-连通形状，不限具体外形，但每个示例形状不同），以及一列纵向排列的单像素标记点，每个标记颜色互不相同（可用蓝(1)、绿(3)、黄(4)、品红(6)、橙(7)等），标记数量多于算术结果值（即有冗余标记）。左半区和右半区之间至少间隔 2 列。生成约束：青(8)竖条总高度严格大于红(2)竖条总高度，保证结果 N >= 1；标记数量 >= N + 1，保证有冗余。

**规则**：
1. 在左半区计算：N = 所有青(8)竖条的高度之和 - 所有红(2)竖条的高度之和。
2. 在右半区裁剪灰(5)模板图案到其边界框。
3. 将标记点按从上到下的顺序排列，取前 N 个标记（第 N+1 个及之后的标记被忽略）。
4. 为每个被选中的标记生成一份模板副本，将灰(5)像素重涂为该标记的颜色。
5. 将 N 份重涂后的模板副本按标记从上到下的顺序纵向拼接（副本之间无间隔），形成输出网格。输出仅包含拼接结果，不包含原始输入的任何部分。

**关键洞察**：竖条的算术结果并不直接画成柱状图，而是控制了另一个完全不同的操作的参数——模板复制次数。求解者必须同时理解两个子系统（算术区和模板区），并发现它们之间的数值传递关系。

## 新题 3：边缘链式排序驱动循环涂色与交替打孔相位

**组合逻辑**：[边缘像素匹配/链式连接排序](已有) + [颜色循环分配](已有) + [中线交替打孔](创新：打孔起始相位由链位奇偶决定)

**来源原语**：边缘像素匹配/链式连接排序(78332cb0) + 颜色循环分配(9473c6fb) + 中线交替打孔/交替(3bdb4ada)

**依赖链**：边缘匹配确定链式顺序 → 链位序号决定循环涂色 → 链位奇偶同时决定中线打孔的起始相位。链式排序同时驱动两个下游操作的不同参数，形成扇出结构而非线性流水线。

将散布的矩形块按边缘前景像素匹配链成序列，链位决定涂色（循环三色），链位奇偶决定中线打孔的起始偏移。

**输入结构**：约 20x25 的网格，黑(0)背景。包含 4~6 个灰(5)单色实心矩形块，每个块短边为 3 像素、长边为 5 或 7 像素（奇数），可为水平或垂直朝向。各块散布在网格上，互不接触，间距至少 2 像素。每个块的两条短边上各有一组前景像素标记（1~2 个灰(5)像素延伸到块外一格，形成"接口"），这些接口像素的偏移位置在短边方向上各不相同。恰好存在一种链式排列使得每对相邻块的面对边接口像素在同一偏移位置重合。生成约束：链式排列唯一（不存在分叉），且全链方向一致（全水平或全垂直拼接）。

**规则**：
1. 提取所有灰(5)矩形块及其接口像素。两个块"可连接"当且仅当：将它们沿某方向拼接时，一个块的右/下接口像素与另一个块的左/上接口像素在垂直于拼接方向的偏移上重合。
2. 从只有一端可连接的端点块出发，沿连接关系依次串联所有块，得到链序 1, 2, 3, ... 。
3. 按链序循环分配颜色：第 1 个→红(2)，第 2 个→青(8)，第 3 个→绿(3)，第 4 个→红(2)，依此循环。将每个块的所有灰(5)像素（含接口像素）重涂为分配的颜色。
4. 对每个块，找到其沿长轴方向的中心线（短边为 3 故中心线为中间一行或一列）。沿中心线从长轴起始端第二个像素开始，每隔一个像素打孔（设为黑(0)）。打孔起始相位：链位为奇数（1, 3, 5...）的块从中心线第 2 个像素开始打孔（第 2, 4, 6... 位置变黑）；链位为偶数（2, 4, 6...）的块从中心线第 3 个像素开始打孔（第 3, 5, 7... 位置变黑）。
5. 块保持在原始网格位置，输出与输入同尺寸。

**关键洞察**：链式排序的结果被用于两个不同层面——颜色分配取模 3，打孔相位取模 2——同一个序号驱动两套不同周期的映射，使得相邻块在颜色和纹理上都可能不同。需要对比多个示例才能分离出这两个独立的周期规律。

## 新题 4：标记朝向编码间隙填充色

**组合逻辑**：[标记朝向编码颜色](创新：编码的不是对象自身的颜色而是间隙填充色) + [行列跨度重叠/间隙区域] + [无遮挡才填充] + [擦除]

**来源原语**：标记朝向编码颜色(604001fa) + 行列跨度重叠/间隙区域/无遮挡才填充(ef135b50) + 擦除(604001fa)

**依赖链**：L 标记的朝向解码出颜色 → 该颜色赋予对应矩形的"间隙填充色"属性 → 矩形对之间的行列跨度重叠测试决定间隙是否存在 → 无遮挡条件判断间隙是否可填 → 可填间隙使用左侧矩形的解码颜色。标记信息和空间几何信息必须联合使用才能确定输出。

读取每个矩形上方 L 标记的朝向以解码颜色，擦除标记后，在行列跨度重叠且无遮挡的矩形对之间填充左侧矩形的解码颜色。

**输入结构**：约 18x18 的网格，黑(0)背景。包含 3~5 个蓝(1)实心矩形（各约 2x3 至 3x5 像素，具体尺寸各异），水平散布。每个矩形正上方（紧贴其边界框顶边）有一个橙(7)的 2x2 L 三联骨牌标记（即 2x2 区域中恰好 3 个像素为橙(7)，1 个为黑(0)）。各矩形的行跨度（所占行范围）有部分重叠的对，也有完全不重叠的对。生成约束：至少存在一对矩形有行跨度重叠且间隙无遮挡；至少存在一对有行跨度重叠但间隙被第三个矩形遮挡（使该条件可被验证）；每个矩形的 L 标记缺角位置在不同示例中不完全相同。

**规则**：
1. 对每个蓝(1)矩形，读取其正上方的橙(7) L 标记。标记缺角位置→解码颜色：左上缺→绿(3)，右上缺→青(8)，左下缺→黄(4)，右下缺→品红(6)。将解码颜色记为该矩形的"间隙色"。
2. 擦除所有橙(7)标记像素（设为黑(0)）。
3. 对每一对蓝(1)矩形 (A, B)，其中 A 在 B 的左侧：检查 A 与 B 的列跨度是否分离（不重叠），以及行跨度是否重叠。两者都满足时，定义间隙区域为 A 和 B 边界框之间、在共享行跨度范围内的矩形区域。
4. 若间隙区域内没有任何第三个蓝(1)矩形的边界框与之交叉（无遮挡条件），则将间隙区域填充为矩形 A 的间隙色（步骤 1 中解码的颜色）。
5. 所有蓝(1)矩形像素保持不变。

**关键洞察**：L 标记的朝向不是用来改变矩形自身的颜色（与源题 604001fa 不同），而是编码了该矩形向右方间隙投射的填充色。要确定某个间隙的颜色，必须同时完成几何判断（跨度重叠、无遮挡）和编码解读（L 标记朝向），两者缺一不可。

## 新题 5：图例编码旋转角度后弹性拉伸填充

**组合逻辑**：[图例编码](创新：从转向编码改为旋转角度编码) + [旋转] + [弹性拉伸/模板填充] + [按目标尺寸调整]

**来源原语**：图例条/编码映射(e87109e9) + 旋转(4c416de3) + 弹性拉伸/模板填充/按目标尺寸调整(40f6cd08)

**依赖链**：图例中每个颜色条目的位置编码旋转角度 → 目标矩形的颜色查表确定旋转角 → 范例矩形先旋转再弹性拉伸 → 拉伸后的图案填入目标矩形。旋转改变了范例的行列结构，导致弹性拉伸的内部行程方向不同，最终产生不同的填充效果。

根据图例将范例矩形旋转指定角度后弹性拉伸，填入每个与图例颜色对应的纯色目标矩形。

**输入结构**：约 20x25 的网格，黑(0)背景。顶部 1~2 行是灰(5)背景的图例带。图例带中有 2~4 个彩色单元格（宽 2 像素），每个单元格内有一个 1 像素的小竖条标记，竖条的位置编码旋转角度：竖条在单元格左列→0度，竖条在单元格右列→90度顺时针，竖条在单元格左列且偏上→180度，竖条在单元格右列且偏上→270度。图例下方的主网格包含一个多色范例矩形（约 4x5，四角同色，内部有 2~3 种其他颜色构成图案）和若干个纯色目标矩形（各色不同，尺寸各异，均为同一外框色但颜色与图例中某条目匹配）。生成约束：每个目标矩形的颜色在图例中恰好出现一次；范例矩形不是正方形（使旋转可观察到效果）；目标矩形的尺寸与旋转后的范例在至少一个轴上不同（使拉伸生效）。

**规则**：
1. 读取图例带，移除图例带（不出现在输出中）。对每个彩色单元格，根据内部竖条位置解码旋转角度：左列下方→0度，右列下方→90度顺时针，左列上方→180度，右列上方→270度顺时针。记录颜色→旋转角的映射。
2. 识别主网格中的多色范例矩形（四角像素颜色相同的矩形，其余像素中至少包含两种不同颜色）。
3. 对每个纯色目标矩形，查图例得到其颜色对应的旋转角度 R。
4. 将范例矩形旋转 R 度（以矩形中心为旋转中心，旋转后边界框可能行列互换）。
5. 对旋转后的范例做弹性拉伸以匹配目标矩形尺寸：在行方向和列方向上分别做行程编码，保持边界行程固定，拉伸内部行程（选择代表行中颜色种类最多的行程作为内部行程）。
6. 用拉伸结果替换目标矩形。范例矩形本身保持不变。

**关键洞察**：图例不是简单的颜色映射表，它编码的是几何变换参数。同尺寸的两个目标矩形若颜色不同，会因图例编码的旋转角不同而得到完全不同的填充图案。旋转在拉伸之前执行，改变了范例的行列结构，因此旋转角度实质性地影响了拉伸方向和最终图案。

## 新题 6：灰色 L 模板双重功能——定位样本与排名决定框色

**组合逻辑**：[标记模板/标记后框选副本](已有) + [模式匹配/形状相同](已有) + [计数/排序](创新：模板像素数排名编码框色) + [描框] + [擦除]

**来源原语**：标记模板/标记后框选副本(e2092e0c) + 模式匹配/形状相同(e2092e0c) + 计数/排序(08ed6ac7) + 描框(e2092e0c) + 擦除(604001fa)

**依赖链**：L 模板的空间位置→定位 3x3 样本→模式匹配找到副本→需要框色；L 模板的像素数量→排名→框色映射。同一对象（L 模板）的两个独立属性（位置和大小）分别驱动两个不同环节，形成双重功能结构。

多个不同大小的灰色 L 模板各标记一个 3x3 样本区域，找到每个样本的副本后，按模板像素数排名决定框选颜色。

**输入结构**：约 20x20 的网格，黑(0)背景上有散布的彩色像素构成多个 3x3 图案区域。2~4 个灰(5) L 形标记分布在不同的 3x3 图案旁边：每个 L 标记紧贴一个 3x3 区域的右侧和/或下侧（与源题 e2092e0c 类似），但不同 L 标记的长度不同——最短的为标准 L（3+2=5 像素），较长的在 L 的一臂或两臂上额外延伸 1~2 像素（6~8 像素）。每个被标记的 3x3 图案在网格中恰好有一个完全相同的副本（颜色和位置模式完全一致），且副本四周各有至少 1 像素的空白边距。不同的 3x3 图案互不相同。生成约束：所有 L 标记的像素数两两不同（保证排名无歧义）；3x3 样本的副本不被任何 L 标记接触。

**规则**：
1. 识别所有灰(5)连通分量，每个即为一个 L 标记。
2. 对每个 L 标记，根据其空间位置确定它标记的 3x3 样本区域：样本位于 L 标记的左上侧（L 的竖臂紧贴样本右侧，横臂紧贴样本下侧）。
3. 在网格中搜索每个 3x3 样本的精确副本（排除被 L 标记覆盖的原始位置）。
4. 计算每个 L 标记的灰(5)像素数，按像素数从多到少排名：第 1 名（最大）→蓝(1)，第 2 名→红(2)，第 3 名→绿(3)，第 4 名→黄(4)。
5. 在每个副本周围画一个 1 像素厚的矩形框，框色为对应 L 标记的排名色。框不覆盖副本内部像素，仅画在副本外围的空白区域。
6. 擦除所有灰(5) L 标记像素（设为黑(0)）。其余像素不变。

**关键洞察**：灰色 L 模板不是单纯的位置指示器——它同时承载两种信息：空间位置（决定标记哪个样本）和像素数量（决定框选颜色）。求解者必须从模板中读取这两个独立属性，而仅凭单个示例无法确定像素数到颜色的映射规则，必须对比多个示例中的排名才能归纳。

## 新题 7：竖条高度雕刻画布轮廓，竖条颜色多数决定雕刻象限后四象限镜像

**组合逻辑**：[排序](已有) + [颜色编码正负](创新：从加减号改为象限投票) + [擦除](创新：从中线打孔改为轮廓雕刻) + [四象限镜像]

**来源原语**：排序(08ed6ac7) + 颜色编码正负(37ce87bb, 创新为颜色编码象限投票) + 擦除(3bdb4ada, 创新为轮廓雕刻) + 四象限排布/镜像(62c24649)

**依赖链**：竖条高度排序→生成雕刻轮廓序列（每列雕刻深度）；竖条颜色多数投票→决定在画布的哪个象限执行雕刻；单象限雕刻结果→四象限镜像铺展为完整输出。高度和颜色从同一组对象中提取但编码不同信息，两者必须分别解析。

按高度排序竖条得到雕刻轮廓，按颜色多数投票选择画布象限，雕刻后四象限镜像铺展。

**输入结构**：约 15x18 的网格，黑(0)背景。上半区包含 3~5 根底部对齐的单像素宽竖条，每根竖条为蓝(1)或红(2)中的一种，高度各不相同（2~6 像素）。下半区包含一个绿(3)实心正方形画布（边长为偶数，8x8 或 10x10）。竖条数量不超过画布半边长。生成约束：蓝(1)竖条数量与红(2)竖条数量不相等（保证多数投票无歧义）；排序后的高度序列长度 <= 画布半边长。

**规则**：
1. 将所有竖条按高度从大到小排序，得到高度序列 H_1 >= H_2 >= ... >= H_K。
2. 统计竖条颜色：蓝(1)多于红(2) → 选择画布左上象限；红(2)多于蓝(1) → 选择画布右上象限。
3. 在选定象限中（宽 W/2 列，高 H/2 行），从该象限的左列开始，对第 i 列（i=1,2,...,K），从该象限的顶行向下擦除 H_i 个像素（设为黑(0)）。若 K 小于象限宽度，剩余列不擦除。
4. 以画布中心为对称中心，将雕刻后的象限做四象限镜像铺展：左上→左右翻转得右上，上半→上下翻转得下半。用铺展结果替换整个画布。
5. 竖条区域在输出中全部擦除为黑(0)（仅保留画布）。

**关键洞察**：同一组竖条对象同时编码了两种独立信息——高度编码雕刻深度，颜色编码雕刻位置（象限）。求解者必须将颜色信号与高度信号分离：颜色不影响雕刻多深，高度不影响雕刻在哪。四象限镜像进一步掩盖了雕刻象限的位置，需要对比不同示例中的颜色多数关系才能确定选象限的规则。

## 新题 8：宽高比决定扫描序分配孔洞，旋转匹配嵌入拼图块

**组合逻辑**：[长轴决定扫描/扫描序](创新：扫描对象从孤立像素改为孔洞) + [旋转/拼合] + [形状匹配/拼图块嵌入孔洞] + [裁剪]

**来源原语**：长轴决定扫描/扫描序(9473c6fb) + 旋转/拼合/拼图块嵌入孔洞(97a05b5b) + 形状匹配(228f6490) + 裁剪(97a05b5b)

**依赖链**：红色物体的宽高比→决定孔洞扫描方向→孔洞获得顺序编号；拼图块按尝试旋转匹配孔洞形状→匹配成功则嵌入；扫描序决定"先到先得"的分配优先级（多个块可能匹配同一孔时，序号小的孔优先被满足）。全局几何属性（宽高比）影响局部操作（嵌入顺序）。

裁剪红色物体为画布，按其宽高比确定孔洞扫描方向，将拼图块旋转匹配后按扫描序优先嵌入。

**输入结构**：约 18x18 的网格，黑(0)背景。包含一个由红(2)像素构成的大型连通物体（约 10x12 像素区域），内部有 3~5 个黑(0)孔洞（每个孔洞为一个 4-连通的黑色区域，完全被红色像素包围），孔洞形状各不相同（不规则形，3~6 像素）。网格其他位置散布着与孔洞数量相同的多色拼图块，每个块是一个小型 4-连通图形（3~6 像素），包含红(2)像素作为嵌合模板和至少一种其他颜色的像素作为填充内容。不同示例中红色物体的宽高比不同（有的宽大于高，有的高大于宽）。生成约束：每个拼图块恰好匹配一个孔洞（可能需要旋转 0/90/180/270 度）；不存在两个块匹配同一个孔洞的情况。

**规则**：
1. 裁剪红(2)物体到其边界框，作为输出画布。
2. 测量裁剪后画布的宽高比：若高度 >= 宽度，按行主序（从上到下、同行从左到右）扫描孔洞；若宽度 > 高度，按列主序（从左到右、同列从上到下）扫描孔洞。扫描序以每个孔洞的边界框左上角坐标为排序依据。
3. 对每个拼图块，提取其红(2)像素的相对位置作为嵌合模板，尝试 0/90/180/270 度四种旋转。
4. 按孔洞的扫描序依次处理：对当前孔洞，在未使用的拼图块中寻找其嵌合模板（某旋转下）与孔洞形状完全匹配的块。找到后，将该块的非红色像素按对应旋转粘贴到孔洞位置，该块标记为已使用。
5. 输出仅包含裁剪后的画布（含嵌入的拼图块）。

**关键洞察**：扫描方向由红色物体的全局宽高比决定，而非由孔洞本身的属性决定。这意味着同样的孔洞和拼图块配置，如果红色物体的宽高比不同，嵌入顺序可能改变。求解者必须先判断全局几何属性，才能正确理解局部操作的执行顺序。

## 新题 9：种子图案四象限镜像展开后填入黑色方孔

**组合逻辑**：[全黑窗口换前景色](创新：填充内容从纯色改为构造图案) + [裁剪] + [翻转形成对称铺展/四象限镜像] + [填充]

**依赖链**：种子图案裁剪 → 四象限镜像展开构造填充图案 → 黑色方孔检测 → 用构造图案填充方孔。填充图案不是直接给出的，必须先从种子构造，而方孔尺寸恰好是种子的两倍（四象限展开后匹配），这个尺寸关系是隐式的。

**规则**：
1. 定位灰(5)边框像素，确定其围住的 2x2 种子区域，裁剪出种子图案 S。
2. 将 S 做四象限镜像展开为 4x4 图案 P：S 放左上角，S 的左右镜像放右上角，上半（2x4）的上下镜像放下半，得到 4x4 的 P。
3. 扫描整个网格的所有 4x4 窗口，找到所有 16 个像素均为黑(0)的窗口。
4. 将每个全黑 4x4 窗口的内容替换为图案 P。若多个窗口有重叠（实际上不会，因为全黑窗口之间应间隔），按从左上到右下的顺序处理。

**关键洞察**：填充图案不是直接给出的 4x4 块，而是从 2x2 种子经对称展开构造而来。方孔的 4x4 尺寸恰好是种子 2x2 尺寸的四象限展开结果——这个 2 倍关系是隐式的，求解者必须发现种子尺寸与方孔尺寸的对应才能理解构造规则。灰色边框是定位种子的唯一线索，而非装饰。

## 新题 10：干扰体排除后按标记朝向重涂色再形状匹配嵌入

**组合逻辑**：[干扰体排除](已有) + [标记朝向编码颜色](创新：从重涂前景对象改为重涂拼图块) + [擦除] + [形状匹配/拼图块嵌入孔洞]

**来源原语**：干扰体(228f6490) + 标记朝向编码颜色(604001fa) + 擦除(604001fa) + 形状匹配/拼图块嵌入孔洞(228f6490)

**依赖链**：最常见非灰色识别干扰体→排除干扰体→剩余块各有 L 标记→标记朝向解码颜色→块被重涂→重涂后的块按形状匹配嵌入孔洞。L 标记同时作为"非干扰体证书"（只有非干扰体才有标记）和"重涂色指令"，双重功能缺一不可。

排除干扰体，读取每个有效拼图块上方 L 标记的朝向以确定重涂色，重涂后按形状匹配嵌入灰色物体的孔洞。

**输入结构**：约 20x20 的网格，黑(0)背景。包含 2~3 个灰(5)矩形物体（约 5x6 至 7x8），每个灰色物体内部有 1~2 个黑(0)孔洞（不规则 4-连通区域，3~6 像素，完全被灰色像素包围）。网格其他位置散布着若干彩色小图形（精灵体）：部分为"有效块"，部分为"干扰体"。干扰体的颜色是所有非灰色精灵体中出现次数最多的颜色（如出现 3 个红(2)精灵体和各 1 个蓝(1)、绿(3)精灵体，则红(2)为干扰色）。每个有效块（非干扰色的精灵体）正上方紧贴一个橙(7)的 2x2 L 三联骨牌标记。干扰体没有 L 标记。生成约束：干扰色精灵体数量严格多于任何其他单色精灵体数量；每个有效块的形状（二值掩码）与恰好一个孔洞匹配；所有孔洞都有对应的有效块。

**规则**：
1. 统计所有非灰(5)精灵体的颜色，出现次数最多的颜色为干扰色。将所有干扰色精灵体标记为干扰体并忽略。
2. 对每个剩余的有效块，读取其正上方的橙(7) L 标记（紧贴块边界框顶边的 2x2 区域中 3 个橙色像素）。根据缺角位置解码目标颜色：左上缺→绿(3)，右上缺→青(8)，左下缺→黄(4)，右下缺→品红(6)。
3. 擦除所有橙(7)标记像素（设为黑(0)）。
4. 将每个有效块的所有像素重涂为其解码的目标颜色（覆盖原始颜色）。
5. 对每个有效块，将其二值掩码（非黑像素的位置模式）与每个孔洞的掩码比较。找到形状完全匹配的孔洞后，将重涂后的块平移嵌入该孔洞位置。
6. 擦除所有干扰体像素和所有有效块的原始位置像素（设为黑(0)）。灰(5)物体像素和黑(0)背景保持不变。

**关键洞察**：有效块的原始颜色在输出中完全消失——它既不决定嵌入位置（由形状决定），也不决定输出颜色（由 L 标记决定）。原始颜色唯一的作用是在干扰体识别中被统计。L 标记同时充当两个角色：它的存在本身标识了非干扰体身份，它的朝向编码了重涂色指令。
