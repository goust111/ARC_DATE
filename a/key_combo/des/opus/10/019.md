## 新题 1：旋转补全揭示形状以匹配孔洞

**组合逻辑**：[对称补全](创新：补全结果不绘制，仅用于推断完整形状) → [形状匹配](已有) → [填充](已有，但填色由补全像素数决定——创新)

**来源原语**：对称补全/symmetry_completion（1b60fb0c）, 形状对应/shape_correspondence + 封闭孔洞/enclosed_hole + 填充/fill（93b4f4b3）, 旋转对称/rotational_symmetry（1b60fb0c）, 计数/counting（e8593010）

**依赖链**：旋转补全揭示每个不完整对象的真实完整形状 → 完整形状才能与模板孔洞进行归一化掩码匹配 → 匹配确定哪个孔洞由哪个对象负责 → 补全时实际添加的像素数量决定该孔洞的填充颜色。补全同时产出两个信息：形状（用于匹配）和添加量（用于定色），二者缺一不可。

将不完整对象旋转补全以推断其完整轮廓，按完整轮廓匹配到模板孔洞中，根据补全所需像素数量决定填充颜色。

**输入结构**：网格约 20x10，由一列灰(5)像素从中间纵向分为左右两个面板。左面板：一个蓝(1)单色模板占据大部分区域，模板内有 3-4 个不相连的黑(0)背景孔洞，每个孔洞为 4-连通区域，面积 4-8 像素，形状各异（无两个形状相同）。右面板：3-4 个单色对象分布在黑(0)背景上，每个对象使用不同颜色（红(2)、绿(3)、黄(4)、品红(6)等），每个对象具有近似 4 重旋转对称性但缺失了恰好一个 90 度扇区的像素（即将完整形状按旋转中心分为 4 个 90 度区域后，其中一个区域的像素被移除）。对象的完整形状（补全后）面积为 4-8 像素，与某个左面板孔洞的归一化掩码完全一致。生成约束：每个右面板对象补全后恰好匹配一个左面板孔洞，一一对应；不同对象补全时需要添加的像素数量互不相同（范围 1-4）。

**规则**：
1. 对每个右面板对象，检测其旋转对称中心，将所有现有像素绕该中心顺时针旋转 90 度，将旋转后落在黑(0)位置上的像素标记为"补全像素"。记录补全像素的数量 P。
2. 将每个对象的完整形状（原有像素 + 补全像素）归一化到其边界框，得到归一化掩码。
3. 对左面板每个孔洞，将其归一化到边界框得到孔洞掩码。将每个对象的归一化掩码与各孔洞掩码比较，找到唯一匹配的孔洞。
4. 用以下颜色填充匹配的孔洞：P=1 → 蓝(1)，P=2 → 红(2)，P=3 → 绿(3)，P=4 → 黄(4)。
5. 输出仅包含左面板（含已填充的孔洞），右面板和分隔列不出现在输出中。

**关键洞察**：对象的完整形状在输入中不可见——必须先通过旋转补全推断出来才能进行形状匹配。同时，补全所需的像素数量编码了填充颜色，这意味着补全步骤同时承担形状推断和颜色编码两个角色，删除此步骤则两项信息都无法获取。

## 新题 2：桥接通道将孔洞分组，组内面积排名定填色

**组合逻辑**：[连通判定](创新：判定对象从前景转为背景孔洞之间的通道连通) → [面积分级](已有) → [填充](创新：填色由组内排名而非全局排名决定)

**来源原语**：连通判定/connectivity_test + 桥接路径/bridge_path + 连通性/connectivity（239be575）, 封闭孔洞/enclosed_hole + 填充/fill（93b4f4b3）, 面积分级/area_ranking + 面积决定颜色/area_determines_color + 计数/counting（e8593010）

**依赖链**：桥接通道的连通性将孔洞组织成若干组 → 组的成员确定后才能在组内排名 → 组内面积排名映射到颜色 → 同一全局面积在不同组中可能获得不同颜色。孤立孔洞（无桥接）不填充，形成"连通性门控"效应。

通过模板中的窄通道检测孔洞之间的连通关系，将连通的孔洞分组，按组内面积从小到大排名映射颜色，孤立孔洞留空。

**输入结构**：网格约 15x15。灰(5)模板覆盖大部分网格。模板内有 5-7 个互不相连的黑(0)封闭孔洞，每个孔洞为 4-连通区域，面积 2-8 像素，形状不规则（非矩形）。部分孔洞对之间存在恰好 1 像素宽的黑(0)"桥接通道"——即一条宽度始终为 1 像素的黑色路径穿过灰色模板连接两个孔洞的边缘。通道本身不算入任何孔洞的面积。2-4 条这样的桥接通道将部分孔洞连接成 2-3 个连通组，每组包含 2-3 个孔洞。剩余 1-2 个孔洞没有任何桥接通道连接（孤立）。生成约束：同一连通组内所有孔洞面积互不相同；桥接通道仅连接孔洞边缘像素，不在模板中形成额外的封闭区域。

**规则**：
1. 识别所有灰(5)模板内的黑(0)封闭区域。将面积 >= 2 的区域标记为孔洞，将宽度始终为 1 像素且两端分别连接两个不同孔洞的黑色路径标记为桥接通道。
2. 构建连通图：如果两个孔洞之间存在桥接通道，则它们属于同一连通组。通过传递闭包确定所有连通组。
3. 对每个连通组，按组内孔洞的面积从小到大排序，排名从 1 开始。
4. 按排名填充颜色：排名 1 → 蓝(1)，排名 2 → 红(2)，排名 3 → 绿(3)，排名 4 → 黄(4)。
5. 孤立孔洞（不属于任何连通组）保持黑(0)不填充。
6. 桥接通道保持黑(0)不变。

**关键洞察**：同样面积为 3 的孔洞，在一个组里可能排名第 1（填蓝），在另一个组里可能排名第 2（填红）——颜色不由绝对面积决定，而由组内相对排名决定。必须对比多个示例才能发现颜色取决于组内排名而非全局面积。

## 新题 3：蛇形路径端点方向决定垂直射线印戳位置

**组合逻辑**：[展直/蛇形路径追踪](创新：追踪目的不是展直输出，而是获取端点局部方向) → [射线延伸 + 投射](创新：射线方向由蛇身端点切线的垂直方向决定) → [印章覆盖](已有)

**来源原语**：蛇形路径/snake_path + 端点/endpoint + 遍历顺序/traversal_order（7b5033c1）, 射线延伸/ray_extend + 投射/perpendicular_cast + 贯穿条/full_span_bar + 控制像素/control_pixel + 接触标记/contact_marker + 命中处印标记/stamp_at_hit（ecdecbb3）

**依赖链**：蛇形路径追踪 → 确定端点位置及端点处蛇身的局部行进方向 → 取该方向的两个垂直方向作为射线方向 → 射线与贯穿条相交确定印戳位置 → 蛇身颜色决定印戳颜色。蛇的几何形态直接编码了射线方向——不同形状的蛇产生不同方向的射线，这是源题中不存在的结构关系。

追踪蛇形路径以获取端点处的行进方向，沿垂直于该方向的轴线投射射线，在射线命中贯穿条处印制以蛇身颜色为主色的接触标记。

**输入结构**：网格约 15x20。黑(0)背景。2-3 条水平贯穿条（整行为灰(5)）分布在网格中，将空间分为若干水平带。每个水平带中有 1-2 条蛇形路径，每条蛇使用不同颜色（红(2)、绿(3)、蓝(1)等），长度 5-10 像素，4-连通链状，恰好有 2 个端点（仅有 1 个链内邻居的像素）。蛇的端点不与贯穿条相邻。每条蛇在端点处的局部方向为水平或垂直（端点到其唯一邻居的方向向量）。生成约束：不同蛇的端点射线互不交叉；每个端点的至少一个垂直方向上存在一条贯穿条。

**规则**：
1. 识别所有蛇形路径：黑(0)背景上的非灰(5)彩色 4-连通链，每条链恰好有 2 个端点。
2. 对每条蛇的每个端点，确定局部方向向量 D = (端点的唯一邻居的坐标 - 端点坐标)。
3. 计算 D 的两个垂直方向 D_perp1 和 D_perp2（例如 D=(0,1) 则垂直方向为 (1,0) 和 (-1,0)）。
4. 从端点出发，分别沿 D_perp1 和 D_perp2 逐像素投射射线。
5. 如果射线命中一个灰(5)贯穿条像素：(a) 将端点到命中点之间（不含端点，含命中点）的所有像素涂为该蛇的颜色；(b) 以命中点为中心印制 3x3 的灰(5)方块（超出网格边界的部分舍弃），然后将该 3x3 方块的中心像素恢复为蛇的颜色。
6. 如果某个垂直方向上射线到达网格边界仍未命中贯穿条，该方向不产生任何绘制。

**关键洞察**：射线的方向不是预设的上下或左右——它由蛇身在端点处的弯曲几何形态动态决定。同一条蛇的两个端点可能朝不同方向发射射线，因为蛇身在两端的行进方向不同。

## 新题 4：闭合环路凸弯折数编码内部区域填充色

**组合逻辑**：[环路追踪](已有) → [分类涂色中的弯折分类](创新：不是涂弯折像素本身，而是统计凸弯折数量) → [计数 + 面积决定颜色](创新：凸弯折数量映射颜色，作用对象从弯折像素变为环路内部封闭区域)

**来源原语**：环路追踪/trace_cycle + 闭合正交环路/closed_orthogonal_loop + 弯折像素/bend_pixel + 多数转向为凸/majority_turn_is_convex（15663ba9）, 计数/counting + 面积决定颜色/area_determines_color（e8593010）, 封闭孔洞/enclosed_hole + 填充/fill（93b4f4b3）

**依赖链**：环路追踪确定每个闭合环的像素序列 → 逐像素分析转向以区分凸弯折和凹弯折 → 凸弯折计数 C 成为环路的几何特征量 → C 映射到调色板决定该环路所围封闭区域的填充色。环路的边界几何特性（凸弯折数）跨越边界作用于其内部区域——这种"边界属性决定内部颜色"的关系在源题中不存在。

追踪每个闭合正交环路并统计其凸弯折数量，以此数量映射颜色来填充环路所围的内部区域。

**输入结构**：网格约 15x15。黑(0)背景。3-4 个互不接触的闭合正交环路，每个由灰(5)像素构成，一像素宽，4-连通，每个像素恰有 2 个环路邻居。环路形状各异：有简单矩形（4 个凸弯折、0 个凹弯折），也有 L 形或 T 形凹陷的复杂直角多边形（6、8、10 个凸弯折，分别有 2、4、6 个凹弯折）。每个环路完全围住一个黑(0)内部区域（面积 >= 2 像素）。环路不接触网格边界。生成约束：各环路的凸弯折数互不相同，范围在 4-10 之间（仅偶数）。

**规则**：
1. 识别所有灰(5)闭合正交环路：每个环路是一组灰(5)像素构成的 4-连通闭合链，每个像素恰有 2 个灰(5)邻居。
2. 对每个环路，沿链追踪一圈。在每个像素处检查其两个邻居的相对位置：若两个邻居在同一直线上（共行或共列），该像素为直行像素；否则为弯折像素。
3. 统计弯折像素中转向方向属于多数方向的数量——这些是凸弯折。记凸弯折数量为 C。（一个简单直角多边形中凸弯折总比凹弯折多恰好 4 个。）
4. 确定每个环路的内部区域：从环路像素向内进行洪水填充确定被包围的黑(0)连通区域。
5. 根据 C 填充内部区域：C=4 → 蓝(1)，C=6 → 红(2)，C=8 → 绿(3)，C=10 → 黄(4)。
6. 环路像素（灰(5)）保持不变。

**关键洞察**：内部区域的颜色不由区域自身的任何属性（面积、形状）决定，而由包围它的环路边界的几何复杂度（凸弯折数）决定。必须分析边界才能推断内部颜色——这是一种跨边界的信息传递。

## 新题 5：标记像素定切分位、列序定下段色

**组合逻辑**：[分割](创新：切分点不是等分而是由标记像素的行位置决定) + [列序映射颜色](创新：从列序→前景色改为列序→切分下段色) + [重涂色](已有)

**来源原语**：竖直条/vertical_bar + 等分/equal_split + 下半变色/lower_half_recolored + 重涂色/recolor（ce9e57f2）, 列归属/column_membership + 列序映射颜色/column_rank_to_color（575b1a71）, 标记像素/marker_pixel + 同色配对/same_color_pairing（40853293）

**依赖链**：标记像素的行位置决定各竖条的切分高度（局部信息，逐条不同）→ 切分产生上段和下段 → 竖条在所有竖条中的列序排名决定下段颜色（全局信息，需比较所有竖条的列位置）。两条独立的信息流（标记行 → 切分位置，列位置 → 颜色）在同一竖条上汇合，缺少任何一条都无法确定输出。

每根竖直红条在其标记像素所在行处被切分为上下两段，上段保持红色，下段的颜色由该竖条在所有竖条中的从左到右列序排名决定。

**输入结构**：网格约 12x12。黑(0)背景。3-4 根竖直红(2)条，每根宽 1 像素，高度 4-10 像素不等，分布在不同列上，互不相邻。每根红条中恰好有一个像素被替换为另一种非红非黑颜色（即标记像素，用于指示切分行位置；各标记像素可以是不同颜色，如蓝(1)、绿(3)等，但标记自身的颜色不影响规则——仅其行位置有意义）。标记像素不在竖条的最顶行或最底行（确保切分后上下段均非空）。生成约束：各竖条位于不同的列。

**规则**：
1. 识别所有竖直红(2)条：每根是同一列中连续红(2)像素的极大竖直段。在每根红条中找到唯一的非红非黑像素——标记像素。
2. 以标记像素所在行为分界：从红条顶行到标记像素所在行（含标记行）为上段，标记行下方一行到红条底行为下段。
3. 上段（含标记像素位置）全部涂为红(2)（标记像素恢复为红色）。
4. 将所有竖条按其所在列从左到右排序，得到列序排名（最左 = 排名 1，次左 = 排名 2，以此类推）。
5. 下段按列序排名重涂色：排名 1 → 蓝(1)，排名 2 → 绿(3)，排名 3 → 黄(4)，排名 4 → 灰(5)。

**关键洞察**：每根竖条的输出由两个独立来源的信息共同决定——标记像素给出"在哪里切"（局部、逐条不同），列位置给出"切后下段涂什么色"（全局、需要横向比较所有竖条）。单看一根竖条无法确定下段颜色；单看列位置无法确定切分高度。

## 新题 6：控制像素射线选通象限，对角标记定象限色

**组合逻辑**：[射线延伸](创新：射线用于选通而非绘制) + [分割/象限](已有) + [对角标记色映射象限](已有) + [擦除](已有)——三条独立信息（标记定色、射线定激活、等分定区域）同时约束输出

**来源原语**：射线延伸/ray_extend + 中心向外辐射/radiate_from_center（1d398264）, 分割/split + 象限/quadrant + 对角标记像素/diag_marker + 角落对应/corner_correspond + 标记色映射象限/marker_color_to_quad（e9ac8c9e）, 控制像素/control_pixel + 投射/perpendicular_cast（ecdecbb3）, 擦除/erase（7c66cb00）

**依赖链**：灰色矩形等分为四象限（定义区域）→ 对角标记像素为每个象限命名潜在颜色 → 控制像素发射射线，射线进入的象限被"激活" → 仅被激活的象限获得对角标记色，未激活象限保持灰色。三条信息流并行汇聚于每个象限：区域划分、颜色命名、激活判定，构成同时约束满足结构。

将灰色矩形等分为四象限，对角标记像素为每个象限提供潜在颜色，但只有被外部控制像素射线命中的象限才实际着色。

**输入结构**：网格约 15x15。黑(0)背景。一个灰(5)实心矩形居于网格中心偏位置，尺寸为偶数行 x 偶数列（如 8x6 或 6x8），确保可被精确等分为四个相等象限。矩形四个角的对角方向各有一个标记像素（即左上角的左上对角位置、右上角的右上对角位置、左下角的左下对角位置、右下角的右下对角位置），每个标记像素颜色不同（从蓝(1)、红(2)、绿(3)、黄(4)、品红(6)中选取四种）。另有 2-3 个橙(7)控制像素分布在矩形外部远处，每个控制像素与矩形轴对齐（即控制像素的行在矩形的行范围内，或控制像素的列在矩形的列范围内，但不同时满足两个——确保射线方向唯一）。生成约束：不同控制像素的射线进入不同的象限（每个控制像素恰好激活一个象限）；至少有一个象限不被任何控制像素的射线命中。

**规则**：
1. 将灰(5)矩形沿水平中线和垂直中线等分为四个象限：左上、右上、左下、右下。
2. 为每个象限关联其对角方向的标记像素颜色（左上象限 ↔ 左上对角标记，右上象限 ↔ 右上对角标记，以此类推）。
3. 对每个橙(7)控制像素，沿其与矩形之间最短的轴对齐方向（水平或垂直）投射射线直到进入矩形。射线进入矩形的位置所属象限被标记为"激活"。
4. 激活的象限填充为其对应对角标记像素的颜色；未激活的象限保持灰(5)。
5. 从输出中擦除所有对角标记像素和橙(7)控制像素（设为黑(0)）。

**关键洞察**：对角标记定义"哪个象限是什么颜色"，控制像素射线定义"哪个象限被激活"。这两套系统独立运作但必须同时满足——没有标记则不知道该涂什么色，没有射线则不知道该涂哪些象限。这是一种并行约束结构，而非线性流水线。

## 新题 7：缺口环剔除后幸存环参与色循环

**组合逻辑**：[连通判定](创新：判定对象从前景连通分量变为同心层的完整性检测) → [色沿层序循环移](创新：循环移仅在幸存子集上执行，子集不同则循环结果不同)

**来源原语**：连通判定/connectivity_test + 连通性/connectivity（239be575）, 同心正方形层/concentric_ring + 嵌套层序/nesting_order + 色沿层序循环移/colors_cycle_by_nesting + 重涂色/recolor（bda2d7a6）

**依赖链**：完整性检测筛选出幸存环 → 幸存环的颜色子集和嵌套序构成循环移的操作对象 → 循环移结果直接取决于哪些环幸存（移除一个环改变所有幸存环的颜色分配）。筛选结果与循环操作之间存在整体依赖——改变任何一个环的幸存状态都会导致全部幸存环颜色重新分配。

检测同心矩形环中哪些有缺口像素，剔除有缺口的环，在剩余完整环之间按嵌套顺序执行颜色循环移位。

**输入结构**：网格约 13x13。整个网格被填满为一组同心单像素厚矩形环（从最外层到最内层，覆盖所有像素；如果网格为奇数尺寸则最内层为单个像素）。每层环为单一颜色，外到内依次使用不同颜色（如蓝(1)、红(2)、绿(3)、黄(4)、灰(5)等；颜色可在后续层重复出现）。共 5-7 层环。其中 1-2 层环有 1-3 个像素被替换为黑(0)——这些是"缺口"，使该层不完整。缺口不在角落位置（确保视觉上可识别为该层的缺失像素而非相邻层的干扰）。生成约束：缺口所在层与完整层交替分布，不连续相邻（避免大片黑色区域造成歧义）。

**规则**：
1. 识别所有同心矩形环层。对于 HxW 的网格，第 k 层（k 从 0 开始）由所有满足 min(r, c, H-1-r, W-1-c) = k 的像素 (r,c) 组成。
2. 对每层检查是否所有像素均为非黑(0)色。若该层存在任何黑(0)像素，标记为"缺口层"。
3. 缺口层的所有像素（包括非缺口的原色像素）全部设为黑(0)——整层擦除。
4. 收集所有完整层（非缺口层），按嵌套顺序（外到内）记录它们的颜色序列，去重得到颜色循环列表 [C1, C2, ..., Cm]。
5. 执行颜色循环移位：C1 → Cm，C2 → C1，C3 → C2，...，Cm → Cm-1。即每种颜色替换为循环列表中其前一种颜色（第一种替换为最后一种）。
6. 将所有完整层像素按此映射重涂色。

**关键洞察**：剔除缺口层不仅仅是删除——它改变了参与循环的颜色集合，从而改变所有幸存层的最终颜色。例如外到内颜色为 A,B,C,D 且 B 层有缺口：幸存层 A,C,D 的循环移位结果（A→D, C→A, D→C）与四层全完整时的结果（A→D, B→A, C→B, D→C）完全不同。

## 新题 8：蛇形遮罩下的周期图案恢复与序列化读出

**组合逻辑**：[补全/inpaint](已有) + [展直/straighten](创新：展直的对象不是蛇本身的颜色而是被蛇遮盖后恢复的隐藏颜色) + [平移对称](已有) + [遍历顺序](创新：遍历路径由遮罩形状定义)——蛇形路径同时充当遮罩和读出序列，双重身份是源题不存在的结构关系

**来源原语**：补全/inpaint + 周期瓦片/periodic_tile + 平移对称/translational_symmetry + 轨道可见色填缺失/orbit_color_restores_missing（0dfd9992）, 蛇形路径/snake_path + 端点/endpoint + 展直/straighten + 遍历顺序/traversal_order + 保留像素序/preserve_pixel_order（7b5033c1）

**依赖链**：蛇形路径定义了哪些像素被遮罩（用于补全）→ 周期性平移对称恢复每个被遮罩像素的原始颜色 → 蛇形路径的追踪顺序定义了恢复颜色的输出排列（用于展直）。蛇身同时是"破坏者"（遮罩）和"读取器"（序列化路径），删除蛇身的任一身份都导致无法求解。

识别周期图案中被蛇形黑色路径遮盖的像素，利用平移对称恢复它们的原色，然后沿蛇形路径的遍历顺序将恢复的颜色序列化输出为单列。

**输入结构**：网格约 12x12。一个 2x2 或 2x3 的小型瓦片以平移方式铺满整个网格，瓦片使用 2-3 种非黑颜色（如红(2)、蓝(1)、绿(3)），形成清晰可辨的重复图案。一条由黑(0)像素构成的蛇形路径覆盖在图案之上——该路径是 4-连通的像素链，长度 8-15 像素，恰有 2 个端点（各自仅有 1 个黑色链内邻居）。蛇形路径破坏了其所经过位置的原始图案颜色。蛇的路径不沿着瓦片重复方向走直线（确保不会遮罩整个平移轨道，使得每个被遮罩像素至少有一个同轨道的可见参考像素）。生成约束：蛇形路径不超过每个平移轨道中像素总数的一半，保证每个被遮罩位置可通过至少一个同轨道可见像素恢复。

**规则**：
1. 识别蛇形路径：网格中所有黑(0)像素构成的唯一 4-连通链，该链恰有 2 个端点。
2. 检测周期图案的平移对称性：分析所有非黑像素，找到最小平移向量组 (dx, dy)，使得对任意非黑像素 (r, c)，(r+dy, c+dx) 处若非黑则颜色相同。
3. 对蛇形路径上的每个黑(0)像素 (r, c)，遍历其平移轨道 {(r+k*dy, c+k*dx) | k 为整数, 位置在网格内}，找到轨道中某个非黑像素的颜色，将 (r, c) 的恢复颜色设为该值。
4. 确定蛇的遍历起点：选择两个端点中行号更小的那个；若行号相同则选列号更小的。
5. 从起点沿蛇形路径逐像素遍历至另一端点，按遍历顺序收集每个位置的恢复颜色。
6. 输出一个 Nx1 的单列网格（N = 蛇形路径像素数），每行对应遍历顺序中的一个恢复颜色。

**关键洞察**：蛇形路径承担双重角色——既是遮罩（决定哪些像素需要恢复）又是读取序列（决定恢复结果的输出排列）。这种双重身份在任何单一源题中都不存在：补全源题（0dfd9992）中遮罩是散布的黑点，无序列含义；展直源题（7b5033c1）中蛇身自带颜色，无需恢复。二者组合后蛇的角色发生质变。
