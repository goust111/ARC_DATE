## 新题 1：十字膨胀分区涂色

**组合逻辑**：[扩展(expand)](创新：扩展结果用作屏障而非视觉输出) + [洪泛填充(flood_fill)](已有) + [重涂色(recolor)](已有)；决策节点：[正交对角分工(ortho_diag_role_split)](创新：分工结果构成空间拓扑) + [区域邻接(region_adjacency)](已有) + [多数标记色涂色(majority_marker_color)](创新：投票对象为扩展产生的中心色像素而非预设标记)

**来源原语**：expand、ortho_diag_role_split（参考题 0962bcdd）；flood_fill、region_adjacency、majority_marker_color（参考题 e681b708）；marker_pixel（参考题 928ad970、e681b708、4258a5f9）

**依赖链**：十字扩展按正交/对角分工铺色 → 扩展后的像素形成屏障网络 → 屏障网络划分出若干封闭区域 → 区域边界的中心色像素投票 → 投票结果决定区域填充色。扩展拓扑变则区域变，区域变则投票结果变——删除任一环节均无法独立求解。

将若干小十字扩展为屏障网络，再用屏障围成的区域收集中心色投票来决定区域填充色。

**输入结构**：黑(0)背景网格，约 18x18。包含 3-5 个小型 3x3 十字图案，每个十字有唯一的臂色和唯一的中心色（取自颜色 1-9 中的不同颜色）。十字之间有间距（中心间距约 5-7 像素），使得扩展后彼此接近或略有重叠。网格中另散布 4-8 个单像素彩色标记（非十字所用颜色），位于十字之间的空隙中。生成约束：所有十字的臂色互不相同，中心色互不相同，且臂色集合与中心色集合互不重叠；标记颜色属于某个十字的中心色。

**规则**：
1. 扩展每个十字：从十字中心出发，沿四个正方向（上下左右）额外延伸 2 步（加上原有臂长 1 步，总臂长 3 步），使用该十字的臂色绘制；沿四个对角方向从中心延伸 2 步，使用该十字的中心色绘制。
2. 重叠冲突：若两个十字的扩展像素落在同一位置，该像素归属中心曼哈顿距离更近的十字；若距离相等，归属中心行号更小的十字；行号也相等则归属中心列号更小的十字。
3. 将所有扩展后的十字像素（臂色 + 中心色）视为屏障。对剩余黑色像素进行 4-连通洪泛填充，识别各个封闭的开放区域。
4. 对每个开放区域，检查区域边界像素的 8-邻域中所有属于某十字中心色的像素，统计每种中心色出现的次数。
5. 将该区域填充为出现次数最多的中心色；若存在平局，选择其对应十字中心与该区域质心（所有区域像素的行列平均值，向下取整）曼哈顿距离最小的中心色。
6. 原始单像素标记保持不变（不被填充覆盖）；扩展后的十字像素保持不变。

**关键洞察**：十字的中心色在扩展中沿对角方向铺展，同时作为屏障的一部分和区域标签的来源——它既参与构建空间分区，又决定分区如何着色，这种双重角色是仅看单个示例无法确定的（需要对比多个示例来确认"中心色投票"而非"臂色投票"或"面积投票"）。

## 新题 2：对称分拣对角铺色

**组合逻辑**：[对称检测(symmetry_detect)](创新：对称性用于角色分派而非选取输出) → [平铺(tiling)](创新：铺设内容由对称性分派的角色决定) + [重涂色(recolor)](已有)；决策节点：[选无对角对称瓦片(select_asym_tile)](创新：不对称者成为模板而非输出) + [对角索引映射(diag_index_map)](已有) + [行调色板(row_palette)](创新：调色板来自对称瓦片的位置序而非显式标记)

**来源原语**：symmetry_detect、select_asym_tile（参考题 662c240a）；tiling、diag_index_map（参考题 539a4f51）；recolor、row_palette（参考题 5a5a2103）

**依赖链**：对称检测将瓦片分为"不对称模板"和"对称调色板来源"两个角色 → 对称瓦片的空间顺序提供调色板 → 不对称瓦片的掩码提供铺设形状 → 对角索引映射将一维调色板投射到二维平铺输出。角色分派、调色板提取、铺设形状三者同时由同一组输入元素决定，无法独立求解任何子任务。

检测瓦片对称性以分派角色——唯一的不对称瓦片充当铺设模板，对称瓦片的前景色按位置排列为调色板——然后用对角索引规则将模板铺满输出。

**输入结构**：网格约 12x15，包含一列纵向堆叠的 N 个同尺寸正方形瓦片（边长 3 或 4），瓦片之间以单行灰(5)水平条分隔。每个瓦片在黑(0)背景上用一种前景色绘制二值图案。恰好有 1 个瓦片不具有对角对称性（沿主对角线转置后与原图不同）；其余 N-1 个瓦片均为对角对称。每个瓦片的前景色互不相同。生成约束：N 在 4-6 之间；不对称瓦片不在第一个或最后一个位置（避免平凡情况）。

**规则**：
1. 沿灰(5)分隔条将输入切分为 N 个瓦片。
2. 对每个瓦片测试对角对称：将瓦片像素矩阵沿主对角线转置，若转置结果与原矩阵不完全相同，则该瓦片为不对称瓦片。
3. 提取唯一的不对称瓦片作为模板掩码（保留其形状，忽略其颜色）。
4. 将所有对称瓦片的前景色按其在输入中从上到下的顺序收集，形成长度为 P = N-1 的调色板序列 c₀, c₁, ..., c_{P-1}。
5. 构建输出：一个 P×P 的瓦片网格（每个格子与输入瓦片同尺寸），格子之间以单像素灰(5)条分隔。
6. 每个格子 (r, c)（0-索引）中印入模板掩码，使用调色板中索引 max(r, c) 处的颜色绘制，背景为黑(0)。

**关键洞察**：对称性不是用来选出"答案瓦片"的（参考题 662c240a 只选出一个瓦片作为输出），而是同时将同一组瓦片分成两种功能角色——模板提供者与调色板提供者。仅看单个示例可能误判哪种对称性是筛选标准（主对角线 vs. 副对角线 vs. 旋转对称），必须对比多个示例才能确认。

## 新题 3：重力着陆对角射线

**组合逻辑**：[重力下落(gravity_drop)](已有) → [射线延伸(ray_extend)](创新：射线起点由重力着陆位置决定而非固定)；冲突解决：[面积区分角色(area_determines_role)](创新：面积决定射线交叉点的颜色优先级而非角色划分)

**来源原语**：gravity_drop、stop_at_bottom、area_determines_role（参考题 6ca952ad）；ray_extend、diagonal_dir（参考题 5c0a986e）

**依赖链**：重力下落改变方块位置 → 着陆位置决定射线起点 → 射线轨迹在空间交叉 → 交叉点颜色由方块面积（下落前的固有属性）决定。着陆位置和面积信息缺一不可。

将悬浮方块落至底部，再从每个着陆方块的上边缘两角向上发射对角射线，射线交叉处以面积大的方块色优先。

**输入结构**：黑(0)背景网格，约 15x15。包含 2-3 个不同颜色的正方形方块（边长 2 或 3，颜色取自 1-9），悬浮在不同高度。各方块的列范围互不重叠（水平上完全分离），保证下落时不会堆叠。生成约束：各方块面积互不相等；方块位置使得下落后的对角射线至少有一处交叉。

**规则**：
1. 将所有方块沿垂直方向下落，直到方块的底边接触网格底部（因列范围不重叠，无堆叠情况）。
2. 对每个着陆方块，从其上边缘的左上角像素发射一条对角射线，方向为左上（行 -1、列 -1），持续直到下一步越出网格边界为止；从上边缘的右上角像素发射一条对角射线，方向为右上（行 -1、列 +1），同样延伸至网格边界。射线使用该方块的颜色绘制。
3. 射线仅绘制在黑(0)背景像素上；若目标像素已有方块本体颜色，跳过（方块本体不被覆盖）。
4. 若两条来自不同方块的射线交叉于同一像素：该像素取面积更大的方块的颜色；若面积相等，取中心列号更小（更靠左）的方块的颜色。
5. 着陆后的方块保持原色不变。

**关键洞察**：射线的起点不在输入中直接可见——必须先在脑中完成重力下落，才能确定射线从何处发出。面积信息只在射线交叉时才需要，而交叉是否发生又取决于着陆位置，形成了"位置→轨迹→冲突→面积"的推理链。

## 新题 4：标记框内种子定条纹

**组合逻辑**：[描边(draw_frame)](已有) + [填充(fill)](创新：填充区域和参数由描边结果定义的坐标系决定)；决策节点：[极值内缩定边框(frame_inset_from_extrema)](已有) + [种子定条纹周期(seed_sets_stripe_period)](创新：种子位置在框内坐标系中解读，而非全局坐标)

**来源原语**：draw_frame、marker_pixel、rectangular_frame、frame_inset_from_extrema（参考题 928ad970）；fill、seed_pixel、stripe、seed_sets_stripe_period（参考题 0a938d79）

**依赖链**：标记像素的极值定义外框 → 外框划出内部区域 → 种子像素在内部区域的相对位置决定条纹方向和周期 → 条纹填充框内区域。移动标记像素会改变框，改变框会改变种子的相对位置，从而改变条纹参数——框和条纹无法独立求解。

四个标记像素定义矩形框，框内两个种子像素的相对位置决定条纹的方向和周期，条纹填满框的内部。

**输入结构**：黑(0)背景网格，约 15x15。包含 4 个红(2)标记像素，它们具有唯一的最小行、最大行、最小列、最大列（四个极值各由一个标记提供）。另有 2 个种子像素（一个蓝(1)、一个绿(3)），位于四个红标记围成的矩形范围内部（严格在内框线以内）。生成约束：四个红标记的极值内缩一行/列后仍能围成至少 6x6 的内部区域；两个种子像素不在同一行且不在同一列。

**规则**：
1. 取四个红(2)标记的行极值 r_min、r_max 和列极值 c_min、c_max。
2. 在 (r_min+1, c_min+1) 到 (r_max-1, c_max-1) 的矩形边框上绘制黄(4)边框线（即在极值内缩一行/列处画矩形框）。
3. 定义内部区域 I 为黄框严格内部的所有像素（不含框线本身）。
4. 计算两个种子像素相对于 I 左上角 (r_min+2, c_min+2) 的行偏移 dr₁, dr₂ 和列偏移 dc₁, dc₂。
5. 条纹方向判定：若 |dr₁ - dr₂| > |dc₁ - dc₂|，则条纹为水平方向；否则为垂直方向。
6. 条纹周期 T = max(|dr₁ - dr₂|, |dc₁ - dc₂|)。
7. 在内部区域 I 中填充交替条纹：
   - 若水平方向：从 I 的顶部开始，每 T 行交替使用蓝(1)和绿(3)绘制整行。蓝(1)从种子中行偏移较小者的相对行开始，绿(3)从另一个开始，以周期 T 重复。具体地：I 中相对行号 r'（从 0 开始）满足 (r' mod T) 在 [min(dr₁,dr₂) mod T] 范围内的行涂蓝(1)种子的颜色（即行偏移较小的种子色），其余涂另一种子色。更精确地说：若 r' mod (2T) < T 则涂蓝(1)，否则涂绿(3)（蓝绿交替，首色为行偏移较小的种子色）。
   - 若垂直方向：类似地，每 T 列交替使用蓝(1)和绿(3)绘制整列，首色为列偏移较小的种子色。
8. 红(2)标记像素保持原色。黄(4)框线保持。种子像素被条纹颜色覆盖（融入条纹）。

**关键洞察**：种子像素的绝对坐标不直接决定条纹参数——必须先确定框的位置，再计算种子在框内的相对坐标，才能推导条纹方向和周期。这意味着框和条纹不是两个独立的装饰，而是通过一个隐式的局部坐标系紧密耦合的。

## 新题 5：膨胀接触归并或删除

**组合逻辑**：[膨胀(dilation)](创新：膨胀对象为同类标记像素而非异类种子与背景) → [擦除(erase)](已有) + [重涂色(recolor)](已有)；决策节点：[邻接(adjacency)](创新：邻接判定在膨胀后的光晕之间进行而非原始像素之间) + [邻接够归并否则删(merge_or_delete)](创新：阈值应用于光晕接触面积而非像素与矩形的接触)

**来源原语**：dilation、halo、neighborhood_expand、marker_retains_color（参考题 4258a5f9）；erase、adjacency、merge_or_delete（参考题 7e0986d6）；recolor（参考题 df978a02、7e0986d6）

**依赖链**：膨胀创建光晕 → 光晕之间的 4-邻接面积决定归并/删除 → 删除孤立标记改变剩余标记的同色邻居计数 → 同色邻居计数决定重叠区域的颜色优先级。删除步骤的结果反馈影响颜色优先级判定，形成非线性依赖。

每个标记像素膨胀一圈形成同色光晕；光晕间接触面积不足者连同标记一并删除；光晕重叠处的颜色由幸存同色邻居数决定。

**输入结构**：黑(0)背景网格，约 12x12。包含 8-12 个单像素标记，颜色为 2-3 种（如红(2)、绿(3)、蓝(1)），散布于网格各处。部分标记之间距离 ≤ 2（膨胀后光晕会接触），部分距离 > 2（膨胀后孤立）。生成约束：每种颜色至少出现 2 次；至少有 2 个标记的光晕会彼此孤立（最终被删除）；至少有 2 对不同色标记的光晕会重叠。

**规则**：
1. 对每个标记像素执行膨胀：将其裁剪后的 3x3 邻域涂为该标记的颜色；标记中心像素保持原色不变。
2. 定义每个标记的光晕为其 3x3 邻域中被涂色的像素集合（含中心）。
3. 对每个标记 M，计算其光晕与所有同色标记光晕的 4-邻接接触像素数之和（即 M 的光晕像素中，有多少个像素的 4-邻域内存在属于另一个同色标记光晕的像素）。
4. 若该接触像素数 ≥ 2：标记 M 存活（归并入同色群组）。
5. 若 < 2：擦除标记 M 及其整个光晕（恢复为黑(0)）。
6. 在所有擦除完成后，处理幸存标记间的光晕重叠：若两个不同颜色的幸存标记的光晕在某像素重叠，该像素取幸存同色邻居数更多的那个标记的颜色。（"幸存同色邻居数"= 该标记在步骤 4-5 完成后仍存活的同色标记中，光晕与它有 4-邻接接触的个数。）若相等，取行号更小的标记的颜色；行号也相等则取列号更小的。
7. 所有幸存标记的中心像素保持其原色。

**关键洞察**：归并/删除的判定对象不是原始像素，而是膨胀后才存在的光晕——必须先"想象"膨胀结果才能做邻接判定。同时，删除孤立标记后，剩余标记的同色邻居数可能改变，从而影响重叠区域的颜色仲裁，形成删除-反馈的隐含依赖。

## 新题 6：生长收缩竞赛变描边标记

**组合逻辑**：[生长(grow)](已有) + [收缩(shrink)](已有) → [描边(draw_frame)](创新：描边的标记点来自收缩操作的副产品)；决策节点：[面积最大者(largest_area)](已有) + [最大外扩余内缩(max_grow_rest_shrink)](已有) → [极值内缩定边框(frame_inset_from_extrema)](创新：极值来自收缩产生的位置而非预置标记)

**来源原语**：grow、shrink、foreground_object、center_gap、largest_area、max_grow_rest_shrink（参考题 df978a02）；draw_frame、marker_pixel、rectangular_frame、bounding、frame_inset_from_extrema（参考题 928ad970）

**依赖链**：面积比较决定生长/收缩角色 → 收缩操作移除尖端像素并将其转化为标记 → 标记位置的行列极值定义边框 → 生长操作的获胜者颜色成为边框绘制色。哪些对象收缩、收缩尖端在哪里、以及边框用什么颜色，三者通过面积比较同时确定。

四个对象围绕中心间隙竞争：面积最大者向外生长，其余收缩丢失尖端；丢失的尖端像素变为标记，标记的行列极值定义一个矩形框，框以获胜者颜色绘制。

**输入结构**：黑(0)背景网格，约 14x14。包含 4 个 8-连通单色前景对象，颜色各不相同（取自 1-9），围绕一个中心背景间隙从四个基本方向（上、下、左、右）指向中心。每个对象是一个 4-8 像素的不规则形状（非矩形），其最靠近中心的一端有一个尖端像素（仅 1 像素宽的突出部分）。恰好有一个对象面积最大。生成约束：四个对象面积互不相等；中心间隙约为 2x2 到 3x3 的空白区域；尖端像素为该对象中与中心间隙曼哈顿距离最小的像素。

**规则**：
1. 确定中心间隙：所有前景对象的边界框的交集区域内的背景像素集合（或更精确地，最小化到四个对象聚合距离的背景连通区域）。
2. 找到面积最大的对象 W（获胜者）。
3. 获胜者 W 生长：在 W 远离中心的一侧（即 W 的主方向的外侧），沿 W 与中心间隙的连线方向上，在 W 的最外端添加一个 3 像素宽的帽状延伸（居中对齐于 W 所在的行或列），使用 W 的颜色。
4. 其余 3 个非获胜对象收缩：将每个对象最靠近中心间隙的像素（尖端）重涂为橙(7)（转化为标记像素），该像素不再属于原对象。
5. 收集 3 个橙(7)标记像素的位置，取其行最小值、行最大值、列最小值、列最大值作为四个极值。
6. 在极值内缩一行/列处绘制矩形边框，边框颜色为获胜者 W 的颜色。
7. 所有原有前景像素（含生长部分、不含收缩尖端）保持不变；橙(7)标记保持不变。

**关键洞察**：收缩操作不仅是视觉变化——被移除的尖端像素转化为功能性标记，这些标记的空间分布直接决定边框的位置和大小。哪些对象提供标记、标记落在哪里、边框用谁的颜色，全部通过"谁面积最大"这一判断同时确定，三路输出来自一个决策点。

## 新题 7：引导带铺设边缘级联

**组合逻辑**：[平铺(tiling)](已有) + [画布扩展(canvas_expansion)](已有) + [印章覆盖(stamp_overlay)](创新：印章触发来自铺设结果的边缘像素分布)；决策节点：[引导线定填充带(guide_determines_band)](已有) + [边缘像素复制(edge_pixel_copy)](创新：边缘判定在铺设后的瓦片格子层级进行，而非像素层级)

**来源原语**：tiling、canvas_expansion、input_tile、guide_row_or_column、guide_determines_band（参考题 15696249）；stamp_overlay、foreground_mask、edge_pixel_copy（参考题 8719f442）

**依赖链**：引导线选定主铺设带 → 瓦片被铺入主带的每个格子 → 检查每个已铺瓦片的边缘像素 → 边缘有前景像素的方向触发将瓦片复制到相邻空格子 → 级联复制可能进一步触发更多复制（但仅传播一层）。主带的位置决定哪些瓦片存在，瓦片的边缘内容决定级联方向，两者不可分离。

输入瓦片按引导线铺入画布的一个行带或列带，然后每个已铺瓦片的边缘前景像素触发向相邻空格子的一次复制。

**输入结构**：一个 n x n 瓦片（n 为 4 或 5）。瓦片在黑(0)背景上有若干前景色像素组成的图案。瓦片中恰好有一整行或一整列被同一种颜色完全填满（引导线），其余行/列不全为同一颜色。生成约束：前景像素中至少有 2 个位于瓦片边缘（第 0 行、第 n-1 行、第 0 列或第 n-1 列），且这些边缘像素不全在引导线方向上（确保级联不退化）。

**规则**：
1. 识别引导线：若瓦片的第 r 行全部为同一非黑色 → 引导线为行 r；若第 c 列全部为同一非黑色 → 引导线为列 c。
2. 创建 n x n 的格子画布（总大小 n² x n²），所有格子初始为黑(0)。
3. 主铺设：若引导线为行 r，将瓦片复制到格子行 r 的所有 n 个格子中；若引导线为列 c，将瓦片复制到格子列 c 的所有 n 个格子中。
4. 边缘级联（仅执行一轮）：对每个已铺瓦片所在的格子 G，检查瓦片在四个边缘（上、下、左、右）上是否有非黑前景像素：
   - 若瓦片第 0 行有前景像素且 G 的上方相邻格子为空 → 将瓦片复制到该上方格子。
   - 若瓦片第 n-1 行有前景像素且 G 的下方相邻格子为空 → 将瓦片复制到该下方格子。
   - 若瓦片第 0 列有前景像素且 G 的左方相邻格子为空 → 将瓦片复制到该左方格子。
   - 若瓦片第 n-1 列有前景像素且 G 的右方相邻格子为空 → 将瓦片复制到该右方格子。
5. 若同一空格子被多个方向的级联同时指向，只复制一次（瓦片内容相同，无冲突）。
6. 越出画布边界的级联被忽略（裁剪）。

**关键洞察**：引导线决定主铺设带，但最终输出的铺设范围超出了主带——额外的瓦片由边缘像素的分布"自动"生成。哪些方向会触发级联完全取决于瓦片图案本身（哪些边缘有前景像素），而非引导线的位置，两个规则交织产生的铺设图案无法从单一规则推导。

## 新题 8：四角射线分区投票填充

**组合逻辑**：[射线延伸(ray_extend)](创新：每个方块四角各发一条对角射线形成 X 形屏障) + [洪泛填充(flood_fill)](已有) + [计数(counting)](已有)；决策节点：[对角方向(diagonal_dir)](创新：四个方向同时使用而非仅两个) + [区域邻接(region_adjacency)](已有) + [多数标记色涂色(majority_marker_color)](已有)

**来源原语**：ray_extend、square、canvas_boundary、diagonal_dir、color_diag_corner_edge（参考题 5c0a986e）；flood_fill、open_region、marker_pixel、region_adjacency、majority_marker_color（参考题 e681b708）；counting（参考题 1190e5a7、e681b708）

**依赖链**：方块位置决定射线轨迹 → 射线形成 X 形屏障网络 → 屏障网络将画布划分为不规则区域 → 区域边界上的标记像素投票 → 投票结果确定区域填充色。方块数量和位置决定区域拓扑，标记分布决定各区域颜色，两者同时作用于最终输出。

每个正方形方块的四角各发一条对角射线至网格边缘，射线网络切割空间成多个区域，每个区域以边界上相邻标记像素的多数色填充。

**输入结构**：黑(0)背景网格，约 16x16。包含 2-3 个不同颜色的 2x2 正方形方块（颜色取自 {1, 2, 3}），位于网格中部区域。另有 6-10 个单像素彩色标记（颜色取自 {4, 6, 7, 8} 等与方块颜色不同的颜色），散布于方块周围。生成约束：方块之间至少相隔 3 像素（射线不被另一个方块遮挡）；标记颜色至少使用 2 种不同色；每种标记色至少出现 2 次。

**规则**：
1. 对每个 2x2 方块，从四个角像素各发一条对角射线：
   - 左上角像素 → 方向 (-1, -1)，延伸至网格边界。
   - 右上角像素 → 方向 (-1, +1)，延伸至网格边界。
   - 左下角像素 → 方向 (+1, -1)，延伸至网格边界。
   - 右下角像素 → 方向 (+1, +1)，延伸至网格边界。
   射线使用该方块的颜色绘制，仅绘制在黑(0)像素上。
2. 射线遇到另一条射线或另一个方块的像素时不停止，继续穿过（射线画在黑像素上，已有颜色的像素跳过）。
3. 将所有方块像素和射线像素视为屏障。对剩余黑色像素和标记像素一起进行 4-连通洪泛填充，识别连通的开放区域。
4. 对每个开放区域，统计区域内所有标记像素的颜色，找到出现次数最多的标记色（多数色）。
5. 将该区域中所有非标记像素（黑色像素）填充为多数色；若区域内无标记像素，保持黑(0)不变。
6. 多数色平局时，取该区域中平局标记色里行号最小的标记像素（若行号相同则取列号最小的）所对应的颜色。
7. 方块像素、射线像素、标记像素均保持不变。

**关键洞察**：参考题 5c0a986e 中蓝块只用西北角、红块只用东南角（两色两角），而此处每个方块从全部四角发射射线形成完整的 X 形图案，多个方块的 X 形射线交叠形成的分区拓扑远比两条对角线复杂。分区的形状和数量取决于方块的相对位置，而分区的颜色取决于标记的空间分布——两种完全不同的几何信息在输出中耦合。
