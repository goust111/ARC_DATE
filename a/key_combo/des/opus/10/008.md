## 新题 1：射线分区计数重涂

**组合逻辑**：[射线延伸](从孤立像素向四方向发射，而非沿行延伸至边界) + [计数](统计分区内而非全局的前景像素) + [重涂色](由区域内计数决定，而非行控制色) → [像素数映射颜色](映射规则同源但作用域从全局变为射线分区)

**来源原语**：射线延伸(97999447, e9bb6954)、计数(4852f2fa, 6e82a1ae)、重涂色(c7d4e6ad, 6e82a1ae)、像素数映射颜色(6e82a1ae)、行列对齐(e9bb6954)

**依赖链**：射线延伸产生的网格线将画布分割为矩形区域 → 每个区域内的灰色像素数量决定该区域的重涂颜色 → 没有射线就无法确定分区边界，没有分区就无法正确计数

从散布在网格中的彩色孤立像素发射十字射线，射线交叉将画布切割为矩形区域；统计每个区域内灰色小图形的像素数量，按计数将灰色像素重涂为对应颜色。

**输入结构**：约 18x18 的黑(0)背景网格。3~5 个孤立彩色像素（蓝(1)、红(2)、绿(3)等，每个颜色仅用一次）散布在网格内部，彼此不同行不同列。另有 6~10 个灰(5)色的 4-连通小图形（每个 2~5 像素，形状不规则，如折线、斜对角组合等），分布在网格各处，互不相邻，且不与任何孤立像素同行同列。生成约束：每个孤立像素的行和列上不得有灰色图形的任何像素；每个射线分区内至少有一个灰色图形。

**规则**：
1. 从每个孤立彩色像素向上、下、左、右四个方向延伸射线至网格边界，射线颜色与该像素相同。射线仅覆盖背景像素，不覆盖灰色图形像素。
2. 射线网络（含网格边界）将画布分割为若干矩形区域。
3. 对每个矩形区域，统计其中灰(5)色像素的总数（跨越多个小图形时累加；若一个图形被射线切割，则按区域分别计数各部分）。
4. 按计数重涂该区域内的灰色像素：2 个像素 → 绿(3)，3 个像素 → 红(2)，4 个像素 → 蓝(1)，5 个像素 → 黄(4)。不属于以上计数的区域（如仅 1 个灰色像素）保持灰(5)不变。
5. 射线像素、孤立彩色像素和背景像素均保持不变。

**关键洞察**：彩色像素不是灰色图形的标签——它们是射线发射器，其交叉网络定义了互不相通的计数区域；同一个灰色图形若被射线切割，其两部分可能因所在区域的总计数不同而被涂为不同颜色。

## 新题 2：掩码解码周期平铺

**组合逻辑**：[掩码匹配](解码指令区域为掩码，但掩码作用于周期补全后的结果而非原始格子) + [补全/平铺](先推断最小周期再补全，但补全结果需经掩码过滤) + [重涂色](掩码匹配位置重涂为指令色)

**来源原语**：掩码匹配(15113be4)、块解码为掩码(15113be4)、平铺(d8c310e9)、补全(d8c310e9)、最小周期单元(d8c310e9)、列周期重复(d8c310e9)、重涂色(15113be4)、指令区域(15113be4)

**依赖链**：周期推断并补全整个图案 → 掩码解码确定哪些子位置保留 → 掩码过滤补全后的图案。三步不可跳过：不补全就无法知道哪些位置有前景，不解码掩码就无法知道保留哪些位置，两者缺一则输出不确定。

将局部可见的行周期图案补全至全宽，再用指令区域编码的二值掩码过滤每个周期单元内的像素位置，被掩码选中的前景像素重涂为指令色，未选中的恢复为背景。

**输入结构**：约 16x16 的黑(0)背景网格。网格分为两个区域：上方主区域（约 12 行）和下方指令区域（4 行 x 4 列，位于网格左下角）。主区域左侧 4~8 列包含一个由蓝(1)像素组成的前景图案，呈现明显的列周期（周期宽度 2~4 列），右侧为黑(0)背景（未补全部分）。图案在每个周期内是一个 2x2、2x3 或 3x3 的子模式，不同行的模式可以不同。指令区域是 4x4 的块，内部由品红(6)的 2x2 实心小块和黑(0)的 2x2 空块组成，排列在 2x2 的宏网格中（即 4 个宏位置，每个是 2x2 像素），其中 1~3 个宏位置被品红(6)填充，其余为黑(0)。生成约束：列周期能整除主区域宽度；指令区域的宏网格尺寸与周期单元的行列数一致（如周期为 2 列且图案高 2 行，则掩码为 2x2）。

**规则**：
1. 在主区域中，找到使所有可见蓝(1)像素按行和列残差一致的最小列周期 P。
2. 将该周期图案重复平铺至主区域的全部列，补全右侧缺失部分。
3. 将指令区域解码为二值掩码：每个 2x2 品红(6)块对应掩码中的一个 ON 位，每个 2x2 黑(0)块对应 OFF 位，得到与周期单元同尺寸的掩码（如 2x2）。
4. 对主区域中每个周期单元，仅保留掩码 ON 位置处的蓝(1)像素，并将其重涂为品红(6)；掩码 OFF 位置的像素（无论原来是蓝还是黑）均设为黑(0)。
5. 指令区域本身在输出中保持不变。

**关键洞察**：必须先补全周期图案才能知道每个单元内哪些位置有前景像素，但补全后仍需掩码过滤——掩码并非选择"哪些单元保留"，而是选择"每个单元内的哪些子位置保留"，两个步骤作用于不同粒度。

## 新题 3：奇偶距离图最短路径

**组合逻辑**：[射线延伸 + 奇偶交替](射线的奇偶性决定两节点是否连通，而非仅视觉交替) → [图结构](由距离奇偶性涌现的连通图，源题中图由轨道段显式给出) → [最短路径 + 重涂色](在奇偶约束图上求最短路径)

**来源原语**：射线延伸(97999447)、奇偶交替(97999447)、图结构(7b0280bc)、最短路径(7b0280bc)、节点方块(7b0280bc)、终端节点(7b0280bc)、重涂色(7b0280bc)

**依赖链**：射线奇偶性决定节点间是否连通 → 连通关系定义隐式图 → 在该图上求终端节点间最短路径。三步紧耦合：连通性依赖距离奇偶（非空间邻近），图结构依赖连通性判定，路径依赖图结构。

从每个节点方块中心发射交替色射线，仅当射线以节点色（而非灰色）到达另一节点时两者连通；在此奇偶约束图上求两个终端节点间的最短路径并标记。

**输入结构**：约 21x21 的黑(0)背景网格。5~7 个蓝(1)色实心 2x2 方块作为节点，分散在网格中，彼此中心不同行不同列。其中恰好 2 个方块的左上角有一个红(2)像素覆盖（标记为终端节点）。生成约束：任意两节点中心的曼哈顿行距和列距均 >= 4；存在至少一条从一个终端到另一个终端的奇偶连通路径（见规则中的连通定义）；整个节点集合不构成完全图（即至少有一对节点因奇偶性而不连通）。

**规则**：
1. 从每个蓝(1)节点方块的中心像素，向上、下、左、右四方向发射射线。射线沿途像素交替着色：偏移量为偶数（0, 2, 4, ...）的像素涂蓝(1)，偏移量为奇数（1, 3, 5, ...）的像素涂灰(5)。射线延伸至网格边界或遇到另一个节点方块的边界像素为止。
2. 两个节点 A、B 被视为"连通"当且仅当：A 的某条射线到达 B 的边界，且该到达像素的颜色为蓝(1)（即距离为偶数）。连通关系是对称的（若 A 到 B 偶数距离，则 B 到 A 也是偶数距离）。
3. 以连通关系构建无向图。在此图上，求两个红(2)标记终端节点之间的最短路径（边数最少）。生成约束保证最短路径唯一。
4. 将最短路径上的所有非终端节点方块重涂为绿(3)。将最短路径上每对相邻路径节点之间的射线段重涂为黄(4)（仅限两节点之间的直线段，包含蓝和灰像素全部改为黄）。
5. 不在路径上的节点、射线及所有其他像素保持不变。终端节点保持蓝(1)底色加红(2)标记。

**关键洞察**：空间上相邻的两个节点未必连通——连通性取决于中心距离的奇偶性；这意味着最短路径可能绕过近邻而经过远端节点。

## 新题 4：面板差异驱动射线网络

**组合逻辑**：[逐像素比较 + 异或差异判定](产生差异掩码) → [差异标记](差异位置成为射线控制标记，而非直接输出) → [递归展开 + 正交转向](标记驱动射线网络生长)

**来源原语**：逐像素比较(34b99a2b)、异或差异判定(34b99a2b)、差异标记(34b99a2b)、面板(34b99a2b, e133d23d)、分隔列(34b99a2b)、面板对齐(34b99a2b)、递归展开(b942fd60)、正交转向(b942fd60)、标记触发转向(b942fd60)、深度优先展开(b942fd60)、射线网络(b942fd60)

**依赖链**：两面板逐像素异或 → 差异位置成为标记 → 从固定起点出发射线遇标记转向 → 递归展开生成网络。面板比较的结果决定标记分布，标记分布决定射线路径——跳过比较就不知道标记在哪，跳过射线就无法生成最终图案。

比较分隔列两侧的面板，将异或差异位置作为转向标记植入新画布，从左上角起点发射水平射线，遇标记正交转向，深度优先展开生成红色射线网络。

**输入结构**：约 15x31（奇数宽度）的网格。中间一列为黄(4)分隔列。左面板（15x15）在黑(0)背景上有蓝(1)前景像素组成的不规则图案（单连通，约 15~25 像素）。右面板（15x15）在黑(0)背景上有绿(3)前景像素组成的另一不规则图案（单连通，约 15~25 像素，形状与左面板相似但不完全相同）。两面板的前景图案有部分重叠、部分差异。生成约束：异或差异像素（仅一侧为前景的位置）数量为 4~8 个；差异像素的分布使得从起点出发的深度优先射线网络能经过所有差异标记（即网络完全连通）；差异像素不出现在第 0 行第 0 列（起点位置保留为射线起始）。

**规则**：
1. 移除分隔列，将左右面板按位置对齐，逐像素比较：左面板前景且右面板背景，或左面板背景且右面板前景，记为差异位置。
2. 创建一个 15x15 的黑(0)输出网格。在每个差异位置放置一个橙(7)标记像素。
3. 从输出网格的 (0, 0) 位置开始，向右发射红(2)水平射线。
4. 射线沿当前方向逐像素推进，将背景像素涂为红(2)。当射线的下一个像素是橙(7)标记时：在标记前的那个红色像素处，向垂直方向（同时向上和向下）发射新的红(2)射线分支。标记像素本身保持橙(7)不变，当前射线在标记处停止。
5. 新分支射线同样遵循规则 4：遇到橙(7)标记时，在标记前像素处向水平方向发射新分支（同时向左和向右），标记处停止。已被涂为红(2)的像素不重复处理。
6. 所有分支按深度优先展开，直到所有射线都到达标记、网格边界或已涂红的像素而停止。
7. 橙(7)标记像素、红(2)射线网络和黑(0)背景构成最终输出。

**关键洞察**：射线网络的形状完全由两面板的结构差异决定——差异像素的空间分布编码了射线的转向拓扑，最终的网络图案是两面板不一致性的几何可视化。

## 新题 5：计数旋转印章覆盖

**组合逻辑**：[计数](统计各色标记数量) → [旋转](计数值决定旋转角度，源题中旋转作用于整个网格，此处作用于精灵体且角度由外部条件决定) → [印章覆盖 + 粗模板精细替换](旋转后的精灵体按颜色对应关系印入宏单元格)

**来源原语**：计数(4852f2fa)、旋转(ed36ccf7)、印章覆盖(5833af48)、控制精灵体(5833af48)、宏单元格模式(5833af48)、粗模板精细替换(5833af48)、单像素标记(4852f2fa)、标记计数驱动重复(4852f2fa)、整体旋转(ed36ccf7)

**依赖链**：各色标记的计数 → 决定精灵体旋转角度 → 旋转后精灵体印入对应颜色的宏单元格。计数、旋转、印章三步紧耦合：不统计标记就不知道旋转多少度，不旋转就不知道印章的形态，不知道颜色对应就不知道印入哪个宏单元格。

统计散布标记的各色数量以确定控制精灵体的旋转角度，将旋转后的精灵体印入粗模板中对应颜色的宏单元格。

**输入结构**：约 20x20 的黑(0)背景网格，包含三类元素：(a) 左上角一个 4x4 的控制精灵体，由红(2)和青(8)像素组成的非对称图案（确保 0/90/180/270 度旋转结果互不相同）；(b) 右上角一个 3x3 的粗模板，每个宏单元格为 4x4 像素，模板由黑(0)背景和 2~3 种颜色的宏单元格组成（如绿(3)、黄(4)、蓝(1)），每种颜色出现 1~3 个宏单元格；(c) 网格下半区散布着孤立的单像素标记，颜色为绿(3)、黄(4)、蓝(1)中的若干种，每种标记 0~3 个。生成约束：每种颜色的标记数量对 4 取模后互不相同（如绿 1 个、黄 2 个、蓝 0 个），以保证不同颜色对应不同旋转角度；控制精灵体恰好为 4x4 且旋转不变量互不相同。

**规则**：
1. 统计每种宏单元格颜色对应的孤立单像素标记数量 C（C 可为 0）。
2. 将控制精灵体逆时针旋转 90 x C 度（C=0 不旋转，C=1 旋转 90 度，C=2 旋转 180 度，C=3 旋转 270 度）。若 C>=4 则取 C mod 4。
3. 在粗模板中，所有该颜色的宏单元格位置，用步骤 2 得到的旋转精灵体替换：精灵体中的青(8)像素写入宏单元格，红(2)像素的位置填入该宏单元格的颜色（如绿(3)）。
4. 对每种宏单元格颜色分别执行步骤 1~3。
5. 黑(0)宏单元格保持黑色不变。控制精灵体原始区域在输出中保持不变。标记区域清除为背景。

**关键洞察**：孤立标记的颜色是分组键，数量是旋转编码——同色标记不是"重复 N 次"，而是"旋转 N 个 90 度"；不同颜色组的计数不同意味着同一精灵体以不同朝向出现在不同颜色的宏单元格中。

## 新题 6：遮挡序定义周期填充色序

**组合逻辑**：[排序 + 遮挡顺序](从重叠边框的交叉可见性推断颜色序列) → [周期推断 + 间隙填充](用推断出的颜色序列作为周期循环填充表格空缺) + [对角线相位偏移](控制表格的相位结构)

**来源原语**：排序(c920a713)、遮挡顺序(c920a713)、交叉处可见性(c920a713)、空心矩形(445eab21)、遍历所有颜色(c920a713)、间隙填充(1e97544e)、周期推断(1e97544e)、对角线相位偏移(1e97544e)、按列周期取色(1e97544e)、表格(1e97544e)、空白单元格(1e97544e)

**依赖链**：边框交叉可见性 → 推断颜色排序 → 排序结果即为周期循环的色序 → 用该色序填充表格空白单元格（含对角线相位偏移）。边框分析和表格填充通过"颜色序列"紧密耦合：不解出遮挡顺序就不知道周期是什么颜色循环，不知道循环就无法填充表格。

解读重叠矩形边框的遮挡序列以确定颜色循环顺序，用该顺序作为周期循环填充内嵌表格中的空白单元格。

**输入结构**：约 20x20 的黑(0)背景网格，包含两个区域。(a) 左半区（约 20x10）有 3~5 个一像素厚的空心矩形边框，颜色各不相同（如红(2)、蓝(1)、绿(3)、黄(4)），边框相互重叠，重叠处可见色记录了从被遮挡框到可见框的有向遮挡关系。每个边框的完整矩形可从其可见像素的外接矩形推断。(b) 右半区（约 NxN，N 等于边框颜色数）是一个方形表格，部分单元格已填入边框颜色中的某种颜色，其余单元格为灰(5)表示空白。已填入的颜色遵循一个由边框颜色组成的列周期循环，且在主对角线处存在相位偏移。生成约束：遮挡关系构成唯一的全序（每一对颜色之间的遮挡方向唯一确定）；表格中已填入的像素数量恰好足以验证周期和相位，但不足以独立推断完整色序（至少需要遮挡分析的辅助）。

**规则**：
1. 在左半区，从每种颜色的可见像素推断其完整矩形边框。
2. 检查所有边框对的周边交叉点：若 A 和 B 的边框周边在同一像素相交且该像素显示 B 的颜色，则添加有向边 A→B（B 遮挡 A）。
3. 从有向遮挡关系中找出遍历所有颜色的唯一路径（从最底层到最顶层），得到颜色序列 [c0, c1, ..., cn-1]。
4. 在右半区的 NxN 表格中，填充空白（灰(5)）单元格：对于位置 (r, c)，若 r <= c 则颜色为序列中第 (c mod N) 个，若 r > c 则颜色为序列中第 ((c+1) mod N) 个。
5. 左半区保持不变。

**关键洞察**：重叠边框不是装饰——它们的交叉可见性编码了颜色优先级序列，而这个序列恰好是右侧周期表格缺失的循环色序；不解决空间遮挡就无法完成数值填充。

## 新题 7：墙壁扫描线镜像填充

**组合逻辑**：[裁剪 + 镜像](裁剪前景矩形并水平翻转) → [填充](翻转后的内容逐行填入墙壁像素界定的扫描线区间) + [墙壁界定范围](墙壁和标记列共同确定填充范围)

**来源原语**：裁剪(7468f01a)、镜像(7468f01a)、翻转裁剪区域(7468f01a)、前景矩形(7468f01a)、填充(78e78cff)、墙壁像素(78e78cff)、扫描线区间(78e78cff)、墙壁界定范围(78e78cff)、标记列为参考(78e78cff)、单点标记(78e78cff)

**依赖链**：裁剪前景矩形并镜像翻转 → 翻转内容的每一行对应一个扫描线行 → 墙壁像素界定每行的填充范围 → 翻转内容被裁切至墙壁区间内。翻转提供填充内容，墙壁提供填充边界——两者独立定义，在输出中交汇。

裁剪前景矩形并水平镜像，将镜像结果逐行铺入由墙壁像素和标记列界定的扫描线区间中。

**输入结构**：约 18x18 的黑(0)背景网格，包含三类元素。(a) 一个由多色像素组成的实心矩形区域（约 4~6 行 x 5~8 列），位于网格右下角，包含 2~3 种非背景颜色（如蓝(1)和绿(3)），内部有明确的非对称图案。(b) 灰(5)墙壁像素：分布在网格左半区的若干行上，每行 1~2 个灰像素，共覆盖 4~6 行（行数等于前景矩形的行数）。(c) 一个红(2)单点标记像素，位于灰墙壁像素所在行之间的某列。生成约束：墙壁行数等于前景矩形的行数；每个墙壁行中，标记列左侧最近的墙壁和右侧最近的墙壁之间的区间宽度 >= 前景矩形的宽度；墙壁行从上到下连续（中间不跳行）。

**规则**：
1. 找到前景矩形（所有非背景、非灰、非红像素）的紧凑外接矩形，裁剪出该区域。
2. 将裁剪结果水平镜像（左右翻转列顺序）。
3. 按墙壁行从上到下排序，将其与镜像结果的行从上到下一一对应（第一个墙壁行对应镜像第一行，以此类推）。
4. 在每个墙壁行中，确定标记列严格左侧最近的灰(5)像素位置 L 和标记列及其右侧最近的灰(5)像素位置 R。填充区间为 [L+1, R-1]。
5. 将镜像对应行的像素从左对齐填入该区间：镜像行的第 0 列像素放在 L+1，第 1 列放在 L+2，以此类推。若镜像行宽度小于区间宽度，多余位置保持背景；若大于区间宽度，超出部分截断。
6. 墙壁像素、标记像素和前景矩形原位置均保持不变。

**关键洞察**：前景矩形和墙壁结构是两个独立输入——矩形提供内容（经镜像变换），墙壁提供容器（扫描线区间）；求解者必须同时识别内容变换（镜像）和容器定义（墙壁+标记列），才能确定输出。

## 新题 8：十字覆盖后的格内掩码检测

**组合逻辑**：[射线延伸/擦除](实心方块在格子内延伸十字，交叉处擦除) → [掩码匹配](对擦除后的格子内容做掩码匹配) + [重涂色](匹配的格子重涂)。擦除改变了格子内容，使得掩码匹配的结果与原始内容不同——耦合发生在擦除对匹配结果的间接影响上。

**来源原语**：擦除(e9bb6954)、实心方块(e9bb6954)、十字图案(e9bb6954)、行列对齐(e9bb6954)、交叉点重置背景(e9bb6954)、掩码匹配(15113be4)、格子单元(15113be4)、格线(15113be4)、格子分割(15113be4)、像素匹配掩码位置(15113be4)、重涂色(15113be4)、指令区域(15113be4)

**依赖链**：实心方块在格子内延伸十字 → 不同方块的十字在格子内交叉时擦除为背景 → 擦除后的每个格子形成新的像素模式 → 将此模式与指令区域解码的掩码比较 → 匹配的格子被重涂。十字延伸和交叉擦除改变了格子内像素分布，进而影响掩码匹配结果。

在格线划分的格子中，实心方块沿行列延伸十字并在交叉处擦除；对擦除后的格子内容做掩码匹配，命中的格子前景像素重涂为指令色。

**输入结构**：约 19x19 的黑(0)背景网格，由黄(4)格线分割为 3x3 的格子阵列（每个格子 5x5 像素，格线宽 1 像素，共 3 行 3 列 = 9 个格子）。部分格子（3~5 个）内有蓝(1)色实心 2x2 方块，位于格子内的固定相对位置（每个方块占据格子内 4 个像素）。方块在不同格子中的位置可以不同（如左上、中心、右下等）。网格右下角的格子是指令区域：内部由品红(6)的 1x1 像素在 5x5 空间中标记出一个二值掩码模式（品红 = ON，黑 = OFF），该掩码有 3~4 个 ON 位。生成约束：至少有两个方块处于同行或同列的不同格子中（以产生十字交叉）；指令区域格子内无蓝色方块；掩码的 ON 位模式使得至少 1 个格子在十字延伸+擦除后匹配，至少 1 个格子不匹配。

**规则**：
1. 在每个含蓝(1)方块的格子内，将方块中心所在行和列（格子内局部坐标）全部填充为蓝(1)，形成局部十字。十字不跨越格线，仅在格子内部延伸。
2. 若同一格子内有两个来自不同方块的局部十字（即该格子本身有方块，同时另一个同行/同列格子的方块延伸到此格子的对应行/列），则在两条十字线交叉的像素处将颜色重置为黑(0)背景。
3. 解码指令区域格子为 5x5 二值掩码（品红(6)位置 = ON）。
4. 对每个非指令格子，检查格子内蓝(1)像素的位置集合是否恰好等于掩码 ON 位置的集合。
5. 若匹配，将该格子内所有蓝(1)像素重涂为品红(6)。若不匹配，保持蓝(1)不变。
6. 格线、指令区域和无方块的空格子保持不变。

**关键洞察**：掩码匹配的对象不是原始方块，而是十字延伸并经交叉擦除后的残余图案——一个格子是否匹配取决于其自身方块的位置以及同行/同列其他方块是否对其产生了擦除干扰。

## 新题 9：拉伸色带定义同心环颜色

**组合逻辑**：[拉伸 + 压缩与展开](将参考面板的压缩色段展开为全宽色带) → [排序 + 遮挡顺序](从边框交叉推断深度序) → [重绘](按深度序绘制同心方框，但每层颜色由色带在该层中心行的颜色决定，而非边框原色)

**来源原语**：拉伸(9841fdad)、压缩与展开(9841fdad)、参考面板(9841fdad)、端点标记(9841fdad)、分隔线(9841fdad)、连接跨越(9841fdad)、排序(c920a713)、遮挡顺序(c920a713)、重绘(c920a713)、同心方框(c920a713)、交叉处可见性(c920a713)、矩形边框(c920a713)

**依赖链**：参考面板的色段展开为色带 → 边框遮挡分析给出深度序 → 同心环按深度序排列但颜色取自色带在对应行的值。色带定义"颜色来源"，遮挡序定义"层级关系"，两者共同决定每个同心环的颜色——单独任一信息都不够。

展开参考面板的压缩色段为水平色带，同时从重叠边框推断深度序列；以深度序绘制同心方框，每层颜色由色带在该层中心行处的颜色决定。

**输入结构**：约 22x22 的网格。(a) 最左 3 列为参考面板（灰(5)边框包裹），内含若干水平色段：每行一种颜色或背景，色段用端点标记和连接段表示（端点占 1 列，连接段若存在则将两个端点连为同色整行）。参考面板有 3~5 种颜色（如红(2)、蓝(1)、绿(3)、黄(4)、橙(7)），分布在不同行上。(b) 面板右侧隔 1 列灰(5)分隔线后是主工作区（约 18x18）。工作区包含 3~5 个一像素厚的空心矩形边框，颜色为栗(9)，相互重叠，重叠交叉处的可见色记录遮挡关系。工作区背景为黑(0)。生成约束：边框数量等于参考面板中非背景色段数量；边框按深度序排列后，第 k 层边框（从外到内）的中心行恰好落在参考面板某个色段对应的行上；每个色段对应的行唯一映射到一个深度层。

**规则**：
1. 解析参考面板：每行若有非背景非灰颜色像素，该颜色覆盖的行号记为该色段的位置。端点标记仅出现在面板左端列或右端列表示色段的上下界。连接段（两端点间的同色像素）表示该色段在两端点之间连续存在。
2. 将参考面板的色段拉伸至工作区全宽：每个色段在工作区中对应一个水平色带（行范围不变，列跨越整个工作区宽度）。色带之间不重叠。未被色段覆盖的行保持黑(0)。
3. 在工作区中，从每个栗(9)边框的可见像素推断其完整矩形。检查所有边框对的交叉点，确定遮挡顺序（全序）。
4. 计算每个边框的中心行（上下边的平均行号，向下取整）。查找该中心行属于哪个色带，记录该色带颜色为此边框的"环颜色"。
5. 按遮挡顺序从最外层到最内层，以色带颜色（而非栗色）绘制一像素厚的同心正方形框，输出大小等于最外层边框的外接正方形边长。最外层边框绘制在输出边缘，后续每层向内缩进 2 像素（每侧 1 像素间距 + 1 像素环宽）。

**关键洞察**：同心环的层级顺序由边框遮挡决定，但每层的颜色不是边框本身的颜色——而是由参考面板展开的水平色带在该层中心行处提供的颜色；层级和颜色来自两个独立的信息源。

## 新题 10：占位像素周期传播行级重涂

**组合逻辑**：[补全 + 列周期重复](推断最小周期并补全图案，灰色占位像素也随之周期传播) → [重涂色 + 每行独立取色](传播后的灰色像素按所在行的控制色重涂，不同行取不同颜色)

**来源原语**：补全(d8c310e9)、列周期重复(d8c310e9)、最小周期单元(d8c310e9)、最小周期扩展(d8c310e9)、局部图案(d8c310e9)、重涂色(c7d4e6ad)、占位像素(c7d4e6ad)、行控制色(c7d4e6ad)、同行对齐(c7d4e6ad)、每行独立取色(c7d4e6ad)

**依赖链**：周期补全将局部图案（含灰色占位像素）扩展至全宽 → 灰色像素在每个周期副本中出现 → 每行的控制色决定该行所有灰色像素的最终颜色。必须先补全才知道灰色占位在哪些新位置出现，然后才能按行重涂——跳过补全则右侧无灰色像素，跳过重涂则灰色未被替换。

将包含灰色占位像素的局部图案按最小列周期补全至全宽，再将每个补全后的灰色占位像素替换为其所在行的控制色。

**输入结构**：约 12x18 的黑(0)背景网格。左侧约 4~8 列包含前景图案：由蓝(1)像素和灰(5)像素混合组成，蓝像素构成主要结构，灰像素嵌在其中作为占位（每行 0~2 个灰像素，总计 3~6 个灰像素）。图案呈明显的列周期（周期宽度 2~4 列），可见至少 2 个完整周期。右侧列为黑(0)背景（待补全）。最右一列为控制列：每个包含灰色像素的行在该列有一个彩色控制像素（如红(2)、绿(3)、黄(4)等），不同行的控制色可以不同；不含灰色像素的行在控制列为黑(0)。生成约束：每个含灰色像素的行有且仅有一个控制色像素在最右列；列周期能整除（网格宽度 - 1）（最右列为控制列不参与平铺）；控制列中至少有 2 种不同颜色。

**规则**：
1. 忽略最右一列（控制列），在剩余列中找到使所有可见蓝(1)和灰(5)前景像素按行和列残差一致的最小列周期 P。
2. 将该周期图案重复平铺至全部非控制列，补全右侧缺失部分。补全后，原本仅在左侧出现的灰(5)像素现在也出现在每个周期副本的对应位置。
3. 对每一行，若控制列有非背景颜色 C，则将该行所有灰(5)像素（包括原始位置和补全产生的新位置）替换为颜色 C。
4. 蓝(1)像素在原始和补全位置保持蓝色不变。
5. 控制列在输出中保持不变。

**关键洞察**：灰色占位像素本身是周期图案的一部分——它们和蓝色像素一起被平铺复制；但复制后每一行的灰色像素并不保留灰色，而是从该行的控制色获取最终颜色，使得同一周期模式在不同行呈现不同颜色。
