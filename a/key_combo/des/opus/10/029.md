## 新题 1：墙壁裁形的同心环

**组合逻辑**：[生长/同心方框](创新：环只在可达区域内绘制) + [泛洪填充](创新：不作为涂色手段，仅作为可达性掩码计算) → 交织耦合（每个环格逐一检验可达性）

**来源原语**：生长/grow、同心方框层/concentric_layer、等距对角排列/equi_diag_array（参考题 5c2c9af4）；泛洪填充/flood_fill、墙壁障碍/wall_barrier、可达性/reachability（参考题 8f3a5a89, 9edfc990）；种子像素/seed_pixel（参考题 5c2c9af4, 9edfc990）

**依赖链**：同心环生长提供"画什么几何图案"；泛洪填充提供"哪些格子画得出来"。两者交织——每一个候选环格都必须通过可达性测试才能被绘制。删掉生长，不知道画什么；删掉泛洪填充，环会穿墙；两者互不可缺。

在有墙壁分隔的网格中，从三颗等距对角种子生长同心方框环，但每个环格仅在从中心种子泛洪可达时才绘制，形成被墙壁裁切的局部环。

**输入结构**：约 15x15 网格，黑(0)背景。蓝(1)像素构成墙壁障碍，将网格分隔为若干连通房间（墙壁为 4-连通的蓝色线段或折线，至少有一面与网格边界相连以确保分隔有效）。在其中一个房间内，恰好有三个绿(3)像素沿 45 度对角线等距排列（间距 d >= 2），中间那个是中心种子。墙壁不穿过这三个种子所在的直线段，但墙壁可能紧邻种子所在房间的边界。生成时保证：中心种子所在房间足够大，使得至少第一层同心环有部分格子可绘制；三颗种子全部在同一个连通房间内。

**规则**：
1. 找到三个绿(3)种子像素，按对角线方向排序，中间那颗为中心 C，与相邻种子的切比雪夫距离为 d。
2. 以 C 为中心，在半径 k*d（k = 1, 2, 3, ...）处生成同心方框环——即所有与 C 的切比雪夫距离恰好等于 k*d 的格子集合。如果某个 k 值对应的环完全落在网格之外，停止生成更大的环。
3. 从中心种子 C 出发，对黑(0)格做 4-邻泛洪填充，蓝(1)墙壁阻断传播，得到可达格集合 R。
4. 对于步骤 2 产生的每个候选环格 (r, c)：若 (r, c) 在 R 中，则涂为橙(7)；否则不绘制（保持该格原色不变）。
5. 三颗种子保持绿(3)不变；蓝(1)墙壁保持不变；其余黑(0)格保持不变。

**关键洞察**：同心环是完美几何方框，但泛洪可达性掩码将其裁剪为房间形状的局部弧段——改变墙壁位置会完全改变哪些弧段出现、哪些被隐藏。

## 新题 2：标记计数定旋转角的自相似印章

**组合逻辑**：[计数](创新：计数结果不用于选择对象，而是参数化旋转角度) → [旋转](创新：角度由计数决定而非固定) → [印章覆盖/自相似嵌套](创新：被印章的模板是旋转后版本) + 标记像素的双重身份（既编码角度又参与形状）

**来源原语**：计数/counting、标记像素/marker_pixel（参考题 8efcae92, e50d258f）；旋转/rotate（参考题 1a244afd）；印章覆盖/stamp、自相似嵌套/self_similar_nesting（参考题 8f2ea7aa）

**依赖链**：计数产生旋转参数；旋转改变模板形态；印章将旋转后的模板做自相似展开。关键耦合点：红色标记像素既是计数的对象（决定旋转角），又是模板形状的一部分（旋转后被吸收回前景色），因此模板形状在计数之后才能确定。删掉计数则旋转角未知；删掉旋转则印章模板错误；删掉印章则输出尺寸错误。

统计模板内标记像素的数量以确定旋转角度，将标记重新吸收为前景后旋转模板，再用旋转后的模板做自相似展开。

**输入结构**：网格为 N x N，其中 N = k^2（典型值 k=3 即 9x9，或 k=4 即 16x16）。黑(0)背景上有一个 k x k 的单色前景图案（由蓝(1)像素构成的 4-连通小图形，3~6 个前景像素，具体形状因示例而异），包含在该图案的 k x k 边界框内。该图案中恰好有 1、2 或 3 个像素被替换为红(2)标记像素（标记位置随示例变化）。标记像素在形状上与蓝(1)前景同属一个连通体——仅颜色不同。生成时保证：标记数量在 {1, 2, 3} 中取值；模板的 k x k 边界框完全在网格内；同一组题的不同示例中标记数量至少有两个不同的值。

**规则**：
1. 裁剪前景图案的 k x k 边界框，得到模板 M（包含蓝(1)、红(2)和黑(0)三种颜色）。
2. 统计模板 M 中红(2)标记像素的数量 C（C 为 1、2 或 3）。
3. 将模板 M 中所有红(2)像素重新涂为蓝(1)，使模板变为纯蓝+黑的二色图案 M'。
4. 将 M' 整体顺时针旋转 C x 90 度，得到旋转后的模板 M''。
5. 自相似展开：创建 N x N 的黑(0)输出网格。将 M'' 视为 k x k 的块布局图：对于 M'' 中每个前景（蓝(1)）像素在局部坐标 (r, c) 处，将整个 M'' 的副本粘贴到输出网格的第 (r, c) 个 k x k 块中（块的左上角为 (r*k, c*k)）。M'' 中黑(0)位置对应的输出块保持全黑。

**关键洞察**：红色标记像素具有双重身份——它们编码旋转角度（通过数量），同时又是模板形状的一部分（被吸收回前景后改变了模板的像素分布）。求解者必须先"读取"标记信息，再"擦除"标记，最后用处理过的模板做自相似展开。

## 新题 3：标记选面板后行移位变形

**组合逻辑**：[计数/标记最多者选取](已有原语) → [裁剪](已有原语) → [行移位/逐行交替方向](创新：作用对象从格子体变为裁剪后的面板，标记像素随行移位一同变形)

**来源原语**：计数/counting、标记像素/marker_pixel、矩形面板/rect_panel、标记归属面板/marker_in_panel、最多标记面板输出/max_marker_panel（参考题 e50d258f, 8efcae92）；裁剪/crop（参考题 e50d258f, 8efcae92, 1f85a75f）；行移位/shift、逐行交替方向/alternating_direction_per_row、底行锚定/bottom_row_anchored（参考题 1c56ad9f）

**依赖链**：计数结果决定选取哪个面板（选择环节）；选取后裁剪得到操作对象（提取环节）；行移位对裁剪结果做变形（变换环节）。关键耦合：标记像素既是选择依据又是变形对象——被选中的面板恰恰因为标记最多，所以移位后标记的空间分布改变最显著。删掉计数则不知裁剪哪个面板；删掉移位则输出是未变形的面板；删掉裁剪则移位作用范围错误。

从多个面板中选出标记最多的那个，裁剪后对其各行做交替方向的单像素移位。

**输入结构**：约 10x20 网格，黑(0)背景。网格中有 3 至 4 个互不相邻的实心矩形面板（各自为 4-连通的青(8)矩形区域，宽高各至少 4 像素，具体尺寸因示例而异）。每个面板内部散布有若干红(2)标记像素（替换部分青(8)格，数量 1~5 个不等，位置随示例变化）。恰好一个面板的红色标记数量严格大于其他所有面板。生成时保证：各面板互不相邻（边界框不相交且不共享边）；每个面板至少有 1 个红色标记。

**规则**：
1. 识别所有青(8)的 4-连通矩形面板，统计每个面板内的红(2)标记像素数量。
2. 选取红色标记数量最多的唯一面板 P。
3. 裁剪 P 的精确边界框，得到一个 H x W 的子网格（保留青(8)和红(2)像素，面板内如有黑(0)孔洞也保留）。
4. 对裁剪结果做逐行交替移位，以底行（第 H-1 行）为锚：
   - 底行（第 H-1 行）不动。
   - 从底行向上，每隔一行施加移位：第 H-2 行不动，第 H-3 行向右移 1 像素，第 H-4 行不动，第 H-5 行向右移 1 像素，依此类推。
   - 被移位的行：最右侧像素移出边界后丢弃，最左侧空出的格子填为黑(0)。
5. 输出移位后的 H x W 子网格。

**关键洞察**：红色标记像素在此题中扮演双重角色——其数量决定了哪个面板被选中，其空间位置又是移位变形的对象。只看单个示例无法确定移位方向规则（左还是右、从顶还是从底锚定），必须对比多个示例中锚定行与移位方向的关系。

## 新题 4：象限定旋转的精灵体紧凑图集

**组合逻辑**：[旋转](创新：旋转角度由精灵体所在象限决定，而非由枢轴配对) + [紧凑排列](创新：排列的是旋转后的精灵体，排序依据原始位置而非旋转后位置) — 共享输入（位置信息同时驱动旋转参数和排序键）

**来源原语**：旋转/rotate、距离保持不变/distance_preserved（参考题 1a244afd）；紧凑排列/compact_packing、精灵体/sprite、图集画布/atlas_canvas、空间位置排序/spatial_position_ordering、按输入位置排列/order_by_input_position（参考题 1990f7a8）

**依赖链**：精灵体的位置同时决定两件事——旋转角度和排列顺序。旋转改变精灵体的外观，排列决定精灵体在图集中的位置。两个操作共享同一个输入属性（空间位置），但从中提取不同的信息（象限 → 角度，坐标 → 排列序）。删掉旋转则图集中的精灵体朝向错误；删掉排列则旋转后的精灵体仍散布在原位。

根据四个精灵体各自所在的网格象限确定旋转角度，旋转后按原始位置顺序紧凑打包成 2x2 图集。

**输入结构**：约 15x15 网格，黑(0)背景，恰有一种前景色绿(3)。四个互不相邻的 4-连通绿(3)精灵体，每个精灵体的边界框恰好为 3x3（内部可含黑(0)孔洞，具体像素分布因示例而异，不同示例中同一象限的精灵体形状不同）。四个精灵体的边界框中心分别位于网格的四个象限（以网格中心为分界：行索引 < H/2 为上半，>= H/2 为下半；列索引 < W/2 为左半，>= W/2 为右半），每个象限恰好一个精灵体。生成时保证：没有精灵体的边界框中心恰好在中心线上（无歧义）。

**规则**：
1. 识别四个绿(3)精灵体，裁剪每个的 3x3 边界框。
2. 根据每个精灵体边界框中心所在象限确定顺时针旋转角度：
   - 左上象限（行 < H/2 且列 < W/2）：不旋转（0 度）
   - 右上象限（行 < H/2 且列 >= W/2）：顺时针 90 度
   - 右下象限（行 >= H/2 且列 >= W/2）：顺时针 180 度
   - 左下象限（行 >= H/2 且列 < W/2）：顺时针 270 度
3. 对每个精灵体的 3x3 裁剪应用其对应的旋转。
4. 按原始输入位置排序：先上方两个（左先右后），再下方两个（左先右后），得到排列序 [左上, 右上, 左下, 右下]。
5. 将排序后的四个旋转精灵体粘贴到一个 7x7 黑(0)画布中，呈 2x2 布局：
   - 序号 1 → 画布 (0,0) 起始的 3x3 块
   - 序号 2 → 画布 (0,4) 起始的 3x3 块
   - 序号 3 → 画布 (4,0) 起始的 3x3 块
   - 序号 4 → 画布 (4,4) 起始的 3x3 块
   - 块之间有 1 行/1 列黑(0)间隔。
6. 输出 7x7 画布。

**关键洞察**：精灵体的空间位置同时编码了两种信息——象限决定旋转角度，坐标决定排列顺序。将一个精灵体移到另一个象限会同时改变它的旋转和排列位置。需对比多个示例才能确定象限-角度的对应关系（0/90/180/270 四种角度与四个象限的映射）。

## 新题 5：角落映射后曼哈顿扩张碰撞

**组合逻辑**：[平移/角落映射](已有原语) → [填充/逐步扩张](创新：从四角同时向内做曼哈顿距离扩张) + 碰撞规则（创新：同步到达的格子变为冲突色） — 同时约束满足结构

**来源原语**：平移/translate、前景块/foreground_block、网格角落/grid_corner、块内位置对应角落/block_position_maps_to_corner、相对位置保持展开/relative_position_preserved_expansion（参考题 66e6c45b）；填充/fill、逐行递增/row_by_row_increment、每行递增扩展/row_incremental_expand（参考题 bbc9ae5d）

**依赖链**：角落映射确定四个扩张源的颜色和位置；曼哈顿扩张使每个源的颜色向内铺展；碰撞规则解决重叠。三者形成同时约束满足结构——四个源并行扩张，碰撞边界的几何形状由网格长宽比和四角颜色共同决定。删掉映射则无扩张源；删掉扩张则只有四个角像素；删掉碰撞规则则重叠区域颜色不确定。

将 2x2 前景块的四种颜色映射到网格四角，然后从四角同步向内做曼哈顿距离扩张；同步到达的边界格涂为灰色。

**输入结构**：网格为 H x W（H 和 W 均为偶数，约 8x10 到 12x14），黑(0)背景。网格中某处有一个 2x2 的前景块，由四个互不相同的非黑颜色填充（如蓝(1)、红(2)、绿(3)、黄(4)，具体颜色因示例而异）。2x2 块的四格分别位于块的左上、右上、左下、右下。生成时保证：四种颜色互不相同且都不是黑(0)或灰(5)。

**规则**：
1. 识别 2x2 前景块，记录其四格颜色：左上 = A，右上 = B，左下 = C，右下 = D。
2. 创建与输入同尺寸的全黑输出网格。将颜色 A 放在输出的左上角 (0, 0)，B 放在右上角 (0, W-1)，C 放在左下角 (H-1, 0)，D 放在右下角 (H-1, W-1)。
3. 从四个角同步向内扩张：在步骤 s（s = 1, 2, 3, ...），每个角 X 的势力范围为所有与角 X 的曼哈顿距离 <= s 的格子。
4. 对每个输出格 (r, c)，计算它到四个角的曼哈顿距离：d_A = r + c，d_B = r + (W-1-c)，d_C = (H-1-r) + c，d_D = (H-1-r) + (W-1-c)。取这四个距离中的最小值 d_min。
5. 如果恰好一个角到 (r, c) 的距离等于 d_min，则该格涂为该角的颜色。
6. 如果有两个或更多角到 (r, c) 的距离同为 d_min（同步碰撞），则该格涂为灰(5)。
7. 2x2 前景块的原始位置在输出中按上述规则正常涂色（原始块位置不做特殊保留）。

**关键洞察**：2x2 前景块是四色 Voronoi 分区的压缩编码。四种颜色从角落同步扩张，碰撞边界形成灰(5)十字或菱形图案，其几何形状完全由网格长宽比决定。方形网格产生对角线交叉的灰色 X，长方形网格产生偏移的交叉图案。

## 新题 6：双面板叠加补集定种子的泛洪填充

**组合逻辑**：[透明叠加/占用补集](创新：补集结果不作为最终输出，而是转化为第三区域的种子坐标) → [泛洪填充](创新：种子位置由两个面板的补集计算得出，而非预先给定) — 跨域信息传递

**来源原语**：透明叠加/transparent_overlay、二值掩码/binary_mask、双侧对齐/bilateral_alignment、占用补集/occupancy_complement（参考题 66f2d22f）；泛洪填充/flood_fill、种子像素/seed_pixel、障碍物/blocker、四邻连通/four_neighbor_connectivity、种子沿连通域扩散/spread_from_seed_through_connected（参考题 9edfc990）

**依赖链**：叠加补集确定种子坐标（两个面板任一单独无法确定）；泛洪填充从这些种子出发，在第三面板中扩散（第三面板有自己的障碍拓扑）。两步操作的领域完全不同——第一步是集合论运算（补集），第二步是拓扑扩散——通过坐标传递耦合。删掉叠加则种子位置未知；删掉泛洪填充则只有离散种子点而非连通区域。

从两个面板的叠加占用补集中提取种子坐标，将其投射到第三面板作为泛洪填充的起点。

**输入结构**：约 6x20 网格，由灰(5)竖线分隔为三个并列的 6x6 面板（总宽 = 6+1+6+1+6 = 20 列）。左面板：黑(0)背景上有蓝(1)前景像素构成的 4-连通图形（3~8 像素，形状因示例而异）。中面板：黑(0)背景上有红(2)前景像素构成的 4-连通图形（3~8 像素，形状因示例而异，与左面板图形不同）。右面板：黑(0)背景上有黄(4)障碍像素形成迷宫状路径结构。生成时保证：左面板与中面板的前景联合占用不覆盖全部 6x6 格（至少留有 4 个补集位置）；补集位置中至少有一个对应到右面板的黑(0)格（即有效种子至少 1 个）；右面板中黄(4)障碍不完全封死，从有效种子出发至少能填充到 1 个额外黑格。

**规则**：
1. 提取三个 6x6 面板（忽略灰(5)分隔列）。
2. 将左面板和中面板按位置对齐：对于每个坐标 (r, c)（r 为 0~5，c 为 0~5），如果左面板 (r,c) 是蓝(1)或中面板 (r,c) 是红(2)，则该位置为"已占用"；否则为"补集"。
3. 收集所有补集位置的坐标集合 S。
4. 在右面板中，对 S 中的每个坐标 (r, c)：若右面板 (r, c) 为黑(0)，则将其设为绿(3)种子像素；若为黄(4)障碍则不放置种子。
5. 从右面板中所有绿(3)种子出发，做 4-邻泛洪填充：遍历相邻黑(0)格并涂为绿(3)；黄(4)障碍阻断传播。
6. 输出仅右面板的 6x6 网格（包含绿(3)种子和填充区域、黄(4)障碍、未被填充的黑(0)格）。

**关键洞察**：单独观察左面板或中面板都无法确定种子位置——必须计算二者的占用补集。而右面板的障碍拓扑独立于前两个面板，使得相同的种子集合在不同的障碍布局下产生完全不同的填充结果。

## 新题 7：可达性门控的自相似印章

**组合逻辑**：[泛洪填充](创新：在模板内部运行，用于区分"活跃"与"不活跃"前景像素) → [印章覆盖/自相似嵌套](创新：印章模板和展开位置同时被泛洪结果过滤) — 约束传播结构

**来源原语**：泛洪填充/flood_fill、种子像素/seed_pixel、障碍物/blocker、四邻连通/four_neighbor_connectivity（参考题 9edfc990）；印章覆盖/stamp、自相似嵌套/self_similar_nesting、前景位置决定印章/foreground_positions_determine_stamp（参考题 8f2ea7aa）

**依赖链**：泛洪填充在模板内部确定哪些前景像素是"活跃"的（从种子可达且未被障碍阻隔）。活跃像素同时决定两件事：(a) 印章模板中哪些像素保留，(b) 展开时哪些块位置会粘贴副本。这构成约束传播——模板内的一个障碍像素可能切断可达性，使部分前景变为不活跃，同时减少模板内容和展开位置。删掉泛洪填充则所有前景都活跃（过多的印章位置和错误的模板）；删掉印章则只有一个小型填充结果。

在模板内部做泛洪填充以确定活跃像素，然后仅用活跃像素版本的模板做自相似展开。

**输入结构**：网格 N x N，N = k^2（典型值 k=3 即 9x9 或 k=4 即 16x16）。黑(0)背景上有一个 k x k 的前景图案，由绿(3)像素构成（4-连通，3~6 个前景像素，具体形状因示例而异）。在该图案的 k x k 边界框内，恰有 1~2 个红(2)障碍像素替换了部分绿(3)位置（红色像素将原本连通的绿色区域隔成两部分或截断一条分支）。恰有 1 个蓝(1)种子像素替换了一个绿(3)位置。生成时保证：蓝(1)种子与至少一个绿(3)像素 4-邻相邻；红(2)障碍使得至少一个原本属于前景的绿(3)像素从种子不可达；k x k 边界框完全在网格内。

**规则**：
1. 裁剪前景图案的 k x k 边界框，得到模板 M（包含绿(3)、红(2)、蓝(1)和黑(0)）。
2. 在模板 M 内，从蓝(1)种子出发做 4-邻泛洪填充：可通行的格为绿(3)和黑(0)；红(2)障碍阻断传播。得到可达集 R。
3. 定义"活跃像素"为：蓝(1)种子本身，以及 R 中所有绿(3)像素。
4. 构造印章模板 M'：将模板 M 中所有活跃像素涂为绿(3)（蓝种子也变绿），所有非活跃的绿(3)像素和红(2)障碍像素均涂为黑(0)（变为背景）。
5. 自相似展开：创建 N x N 黑(0)输出网格。对于 M' 中每个绿(3)像素在局部坐标 (r, c)，将 M' 的完整副本粘贴到输出第 (r, c) 个 k x k 块（块左上角 = (r*k, c*k)）。M' 中黑(0)位置对应的块保持全黑。
6. 输出 N x N 网格。

**关键洞察**：红色障碍在模板内部切断可达路径，使得部分前景像素"沉默"——既不出现在印章模板中，也不触发展开。一个障碍的位置可能使可达像素从 5 个降到 3 个，同时使展开的块数从 5 降到 3、每个块的内容也减少——双重过滤效应。

## 新题 8：对角射线构建堆叠生长的动态边界

**组合逻辑**：[射线延伸/反射](已有原语) + [堆叠/逐行递增](创新：每行的增长上限不再是网格宽度，而是射线路径在该行的列位置) — 两个独立几何计算的交汇

**来源原语**：射线延伸/ray_cast、反射/reflect、对角线段/diagonal_segment、矩形障碍/rect_obstacle、射线路径/ray_path、碰撞反弹/collision_bounce、射线遇障碍翻转/ray_flips_on_obstacle（参考题 508bd3b6）；堆叠/stack、色段/color_run、逐行递增/row_by_row_increment、每行递增扩展/row_incremental_expand（参考题 bbc9ae5d）

**依赖链**：射线追踪（含反射）计算出一条贯穿网格的分段对角路径；堆叠生长从顶行色段向下逐行扩展。射线路径充当每行的右侧边界——生长在遇到射线格时截止。两个计算独立产出（射线几何 + 三角形生长），通过逐行交汇生成最终形状。删掉射线则生长产生常规三角形；删掉生长则只有射线路径；射线的反射改变了路径斜率，直接改变三角形的轮廓形状。

从顶行色段向下逐行递增生长，但每行的增长被一条带反射的对角射线路径截断，形成由射线轮廓裁剪的不规则三角形。

**输入结构**：约 12x12 网格，黑(0)背景。顶行（第 0 行）最左侧 2~3 个格为蓝(1)色段，其余为黑(0)。网格中有一小段青(8)对角线段（恰好 2 个像素，沿 45 度方向相邻），位于网格中部偏左区域，指示射线的初始方向。网格中有一个红(2)矩形条（宽 1~2 像素，高 3~5 像素），位于射线路径上。生成时保证：从青(8)对角线段的右下端点沿其指示方向延伸的射线会经过蓝色堆叠生长的区域（即射线路径在某些行的列坐标位于 0 到 11 之间且大于该行生长的自然宽度）；射线至少与红色矩形发生一次反射。

**规则**：
1. 识别青(8)对角线段，确定其指示的 45 度方向。从该线段的两个端点分别沿对角方向向外延伸绿(3)射线。
2. 当射线遇到红(2)矩形时，翻转被阻挡的方向分量（水平碰撞则翻转水平方向，垂直碰撞则翻转垂直方向），继续延伸绿(3)射线。红(2)矩形本身不被覆盖。
3. 射线到达网格边界时停止。所有射线经过的黑(0)格涂为绿(3)。
4. 从第 0 行的蓝(1)色段开始向下堆叠生长：
   - 第 0 行：保持原始蓝(1)色段（假设从列 0 到列 K-1，宽 K 格）。
   - 第 i 行（i >= 1）：蓝(1)色段从列 0 开始，自然宽度为 K + i 格。但该行实际填充的右边界为 min(K + i - 1, R_i - 1)，其中 R_i 是该行中第一个绿(3)射线格的列号。如果该行没有绿(3)格，则右边界为 min(K + i - 1, W - 1)（W 为网格宽度）。
   - 蓝(1)色段不覆盖绿(3)射线格——在射线格之前停止。
5. 生长一直持续到网格底行，或色段自然宽度为 0 时停止。
6. 青(8)线段、红(2)矩形保持原色不变。

**关键洞察**：射线的反射改变了其斜率，直接改变了生长三角形的轮廓——从直线斜边变为折线斜边。如果没有红色反射体，生长区域是一个被完美对角线截断的三角形；加入反射体后，截断轮廓产生折角。

## 新题 9：间隙桥接开通泛洪新通路

**组合逻辑**：[填充/间隙区域涂色](创新：桥接不是最终目的，而是改变拓扑以使后续泛洪到达新区域) → [泛洪填充](创新：在桥接修改后的拓扑上运行，填充范围取决于桥是否存在) — 拓扑修改驱动扩散

**来源原语**：填充/fill、矩形对象/rectangle_object、间隙区域/gap_region、两体之间/between_two_objects、间隙区域涂色/gap_region_recolor（参考题 d6ad076f）；泛洪填充/flood_fill、种子像素/seed_pixel、四邻连通/four_neighbor_connectivity、种子沿连通域扩散/spread_from_seed_through_connected（参考题 9edfc990）

**依赖链**：间隙填充修改网格拓扑——原本被两个矩形隔断的区域因桥接而连通。泛洪填充在修改后的拓扑上扩散，其结果取决于桥是否存在、桥的位置以及桥的可通行性。删掉桥接则泛洪被阻断在矩形一侧；删掉泛洪则只有静态桥接。关键在于桥不只是视觉连接——它打通了拓扑瓶颈。

在两个矩形之间建桥，使泛洪能穿越矩形障碍到达桥对面的区域。

**输入结构**：约 12x12 网格，黑(0)背景。两个绿(3)实心矩形（各为 3~5 像素宽、3~5 像素高的 4-连通矩形，具体尺寸因示例而异），水平或垂直排列，中间隔有 1~3 格黑(0)间隙。若干红(2)障碍像素散布在网格中（不在间隙内，不在矩形内），形成局部屏障。一个蓝(1)种子像素位于其中一个绿矩形的同侧（与该矩形 4-邻相邻或位于其附近的黑(0)格上）。在两个绿矩形和间隙形成的"桥"的对面，有一片黑(0)开放区域。生成时保证：蓝(1)种子在不建桥的情况下无法通过 4-邻黑(0)路径绕过两个绿矩形到达对面区域（绿矩形 + 红障碍共同封锁了所有绕行路径）；建桥后，桥接青(8)格与蓝(1)种子之间存在一条仅经过黑(0)和青(8)格的 4-邻通路。

**规则**：
1. 识别两个绿(3)矩形连通分量。
2. 找到几何上位于两个矩形之间的所有黑(0)格——即在两矩形的边界框之间、沿它们对齐轴方向夹在中间的黑格（若两矩形水平排列，则间隙格的行范围为两矩形行范围的交集，列范围为两矩形之间的空列；垂直排列类似）。
3. 将这些间隙格涂为青(8)——形成桥梁。
4. 从蓝(1)种子出发，做 4-邻泛洪填充：可通行格为黑(0)和青(8)；绿(3)矩形和红(2)障碍阻断传播。
5. 将所有被填充到达的黑(0)格涂为蓝(1)。青(8)桥梁格保持青色不变（桥被穿越但不被重涂）。
6. 绿(3)矩形、红(2)障碍、蓝(1)种子保持原色。未被填充到达的黑(0)格保持黑色。

**关键洞察**：桥不是装饰——它是拓扑瓶颈的唯一打通点。不建桥时泛洪只能覆盖种子一侧的区域；建桥后泛洪穿越间隙到达对面，覆盖范围急剧扩大。间隙的宽度和位置决定了桥的形状，而桥的形状又影响泛洪能到达的区域。
