## 新题 1：镜像配对选色板方向的多种子同心扩展

**组合逻辑**：[镜像对称/mirror_symmetry](创新：从判定像素涂色改为决定色板读取方向) + [同心层填充/concentric_fill](已有) + [切比雪夫距离索引/chebyshev_index](已有) + [重涂色/recolor](创新：重叠区域按距离优先规则解决冲突)

**来源原语**：镜像对称/recolor_if_mirror_pair(ce039d91)，同心层填充/chebyshev_index/色板按距离配色(9356391f)，忽略干扰项(ce039d91)

**依赖链**：镜像配对检测的结果决定每个种子读取色板的方向（正序/逆序），从而同一组色板对不同种子产生不同的环色序列；多种子扩展的重叠冲突由切比雪夫距离裁决，因此扩展结果既依赖于配对判断又依赖于种子之间的空间关系。

从种子位置的水平镜像关系推断色板读取方向，将多个种子的同心环扩展叠加到同一画布上，重叠处保留距离更近的种子的颜色。

**输入结构**：约 15x15（偶数宽度）的网格，黑(0)为背景。顶部两行分别是两条色板行（palette_row），每行从左端起有 3-5 个连续非背景像素，颜色各不相同（如蓝(1)、红(2)、绿(3)等），其余为背景。两条色板行之间用一行灰(5)分隔行隔开。分隔行下方的区域中散布 3-5 个种子像素（seed_pixel），每个种子是单个非背景像素，颜色均为第一条色板行的首个颜色（即 palette_1[0]）。种子之间互不 4-连通，且不紧贴网格边缘（距边缘至少 2 格）。生成约束：至少有一对种子关于网格竖直中线呈水平镜像位置（列索引之和等于网格宽度减 1），且至少有一个种子无镜像配对。

**规则**：
1. 令网格宽度为 W。对每个种子像素，检查列 (W-1-c) 同行处是否也有种子像素。若是，则该种子为"配对种子"；若否，则为"孤立种子"。
2. 配对种子使用色板行 1（上方那行），从左到右读取颜色序列 P1[0], P1[1], P1[2], ...。孤立种子使用色板行 2（下方那行），从右到左读取颜色序列 P2[L-1], P2[L-2], ...（L 为色板行 2 的有效长度）。
3. 对每个种子 S，计算网格中每个像素到 S 的切比雪夫距离 d。该像素在 S 的扩展中取色为 palette[d]（palette 为该种子对应的色板序列）。若 d >= 色板长度，则该像素不属于 S 的扩展范围。
4. 多个种子的扩展可能覆盖同一像素。冲突解决：取切比雪夫距离最小的种子的颜色（即更近的环覆盖更远的环）。若距离相同，取行索引更小的种子；若行索引也相同，取列索引更小的种子。
5. 所有种子像素本身保持其原始颜色（即 palette[0]），不被其他种子的环覆盖（视为距离 0，最高优先级）。
6. 分隔行和色板行保持不变。

**关键洞察**：种子的镜像配对关系——而非种子本身的颜色——决定了它使用哪条色板以及色板的读取方向；需要对比多个示例（配对/孤立种子产生不同环色序列）才能归纳出这一规则。

## 新题 2：时钟旋转后连接器拼装

**组合逻辑**：[旋转/rotate + 时钟指针编码角度/clock_hand_encodes_rotation](创新：旋转改变连接器几何位置而非画布放置) → [拼接/assemble + 连接配对/connector_pairing + 逐步拼合/incremental_assembly](创新：连接匹配必须在旋转后进行)

**来源原语**：旋转/时钟指针编码角度(a32d8b75)，拼接/连接配对/逐步拼合(cbebaa4b)，锚点对齐(a32d8b75)

**依赖链**：每个精灵体的连接器像素位置在旋转后发生改变，因此在匹配连接器之前必须先完成旋转；旋转角度由时钟指针编码，拼装顺序由旋转后的连接器对齐关系决定——两步形成不可跳过的耦合。

读取每个精灵体的时钟指针旋转角度，旋转精灵体后通过红色连接器像素将所有精灵体拼装到黄色锚点精灵上。

**输入结构**：约 20x20 的网格，黑(0)为背景。包含 4-6 个互不重叠的精灵体（sprite），每个精灵体由以下部分组成：(a) 彩色像素构成的图案主体（3-8 个像素，4-连通，颜色为蓝(1)、绿(3)、灰(5)、橙(7)中的一种或多种，不含红(2)和黄(4)）；(b) 1-3 个红(2)连接器像素位于精灵体边缘（与图案主体 4-相邻但向外突出）；(c) 一个 3x3 的旋转指示区域，位于精灵体包围框内但与主体分隔至少 1 像素，中心为黑(0)，四个正方向邻居中恰好有一个品红(6)像素，指示旋转方向（上=0度，右=90度，下=180度，左=270度）。其中恰好一个精灵体包含一个 3x3 黄(4)实心块作为锚点标记（该精灵体的旋转指示器中心方向为上，即 0 度旋转）。生成约束：旋转后各精灵体的连接器恰好能两两配对，且锚点精灵不需旋转。

**规则**：
1. 识别包含 3x3 黄(4)块的精灵体为锚点精灵，其位置固定不动。
2. 对每个非锚点精灵体，找到其 3x3 旋转指示区域，读取品红(6)像素相对于中心的方向：上→0度、右→90度、下→180度、左→270度。
3. 以该精灵体包围框的中心为旋转中心，将整个精灵体（图案 + 连接器 + 旋转指示区域）顺时针旋转相应角度。旋转后的像素坐标取最近整数。
4. 从锚点精灵开始，逐步拼装：在当前已拼装结构上找到所有未配对的红(2)连接器像素。对于每个尚未拼装的旋转后精灵体，检查其红色连接器中是否有某个与已拼装结构上某个未配对红色连接器位置重合（即平移该精灵体后两个红色像素坐标一致）。若匹配成功，平移该精灵体使匹配的连接器重合，完成拼装。
5. 若多个精灵体同时可拼装，优先选择旋转前包围框左上角行索引最小的；行索引相同则列索引最小的。
6. 每对红色连接器恰好配对一次。配对后的红色像素在输出中保持红(2)。
7. 旋转指示区域的品红(6)像素在输出中保留。

**关键洞察**：未旋转的精灵体的连接器位置与已拼装结构上的未配对连接器不匹配——必须先根据时钟指针完成旋转，才能发现正确的连接关系。

## 新题 3：对角朝向投票决定墙分区二部着色锚点

**组合逻辑**：[分类/classify + 对角朝向/diagonal_orientation + 多数朝向决定色/majority_orient_color](创新：投票结果不直接重涂色，而是选择二部图着色的锚点区域) + [洪泛填充/flood_fill + 交替着色/alternating_coloring + 二部图结构/bipartite_structure](创新：锚点由空间投票而非固定角落决定)

**来源原语**：分类/对角朝向/多数朝向决定色(1d61978c)，洪泛填充/交替着色/二部图结构/分隔墙线/背景区域(3bd292e8)，四邻接连通(3bd292e8)

**依赖链**：全局对角朝向投票确定"优势朝向"→ 各区域内优势朝向像素的数量确定锚点区域 → 锚点区域固定后二部交替着色传播至所有区域。删除投票步骤则无法确定锚点；删除区域划分则无法着色。

统计全局对角线段的朝向多数，找到含最多优势朝向像素的区域作为着色锚点，从该区域开始对墙分隔的二部区域交替着色。

**输入结构**：约 13x13 的网格，黑(0)为背景。红(2)墙像素形成若干 4-连通、单像素宽的线段，将网格分隔为 5-8 个 4-连通的背景区域。部分背景区域内包含 2-5 个灰(5)对角线段像素，每个灰像素属于恰好一种对角朝向（NW-SE 或 NE-SW），判定方法为该灰像素的对角邻居中哪个方向也是灰像素。不同区域中两种朝向的灰像素均可能出现。生成约束：全局两种朝向的像素总数不相等（存在严格多数）；恰好有一个区域拥有最多的优势朝向像素（无并列）；墙的分隔使得区域邻接关系构成二部图。

**规则**：
1. 将网格中所有灰(5)像素按对角朝向分类：若某灰像素在 NW 或 SE 方向有灰邻居，归为 NW-SE 朝向；若在 NE 或 SW 方向有灰邻居，归为 NE-SW 朝向。
2. 统计两种朝向的全局像素总数，像素更多的为"优势朝向"。
3. 识别所有被红(2)墙分隔的 4-连通背景(0)区域。
4. 对每个区域，统计其内部属于优势朝向的灰像素数量。数量最多的区域为"锚点区域"。
5. 构建区域邻接的二部图（两个区域若在某墙段的两侧 4-相邻，则互为邻居）。
6. 将锚点区域填充为青(8)。沿二部图邻接关系交替着色：锚点区域的邻居填充橙(7)，邻居的邻居填充青(8)，以此类推。
7. 所有红(2)墙像素保持不变。所有灰(5)对角线段像素保持不变（不被区域填充覆盖）。

**关键洞察**：着色锚点既不固定在角落也不由颜色直接编码，而是由全局朝向投票选出优势朝向后、再在空间上定位该朝向最密集的区域——需要对比不同示例中优势朝向方向的变化才能归纳此规则。

## 新题 4：互补残缺图案联合还原后平铺入框架模板

**组合逻辑**：[补全/complete + 各副本互补缺失/copies_complement + 对齐合并取并集/align_merge_union](创新：还原出的完整掩码不是就地填色，而是作为后续平铺的单元精灵) → [平铺/tile + 框架模板/frame_template](已有) → [放置/place + 标记编码位置/marker_encodes_position](已有)

**来源原语**：补全/各副本互补缺失/对齐合并取并集/部分图案/模板掩码(f8cc533f)，平铺/框架模板/单元精灵/放置/标记编码位置(a32d8b75)，锚点对齐(a32d8b75)

**依赖链**：多个互补的残缺副本联合还原出完整精灵掩码 → 该掩码成为平铺操作的单元精灵 → 平铺填入框架模板生成放大复合体 → 标记像素编码的锚点位置决定复合体在画布上的放置。任何一步缺失都无法得到最终输出。

将若干互补的残缺彩色精灵副本联合还原为完整掩码，以该掩码为单元精灵平铺入框架模板，再按标记像素编码的锚点放置到输出画布上。

**输入结构**：约 18x18 的网格，黑(0)为背景。品红(6)分隔列将网格分为左右两部分。左部包含 3-4 个不同颜色（蓝(1)、绿(3)、黄(4)等）的残缺精灵副本，每个副本是一个 4-连通单色图案（3-7 像素），各副本左上角对齐放置但彼此在行方向上间隔至少 2 行背景行。它们是同一完整掩码的不同子集，任意单个副本至少缺失 1 个像素，但所有副本的像素位置取并集后恰好构成完整掩码。右部自上而下包含：(a) 一个框架模板——由橙(7)像素和黑(0)像素构成的小矩形区域（约 3x3 至 4x4），橙像素标记活跃单元格；(b) 一个 5x5 的灰(5)边框正方形，其 3x3 内部区域中恰好有一个红(2)标记像素。生成约束：各残缺副本的像素位置互不重叠且并集完整；框架模板中活跃单元格数量为 3-6 个。

**规则**：
1. 裁剪每个残缺副本到其包围框，按左上角对齐补零至相同尺寸（取所有裁剪结果的最大高度和最大宽度），然后对所有副本逐像素取 OR，得到完整的二值掩码 M。
2. 在框架模板中，每个橙(7)活跃单元格替换为一份完整掩码 M 的副本（活跃像素绘制为红(2)，非活跃像素为黑(0)）。非活跃的黑(0)单元格替换为与 M 等大的全黑块。整体拼合为一个放大的复合图案。
3. 读取 5x5 灰边框中红(2)标记像素在 3x3 内部网格中的位置 (r, c)（r, c 各为 0/1/2）。r=0 表示垂直锚点在顶部，r=1 表示中部，r=2 表示底部；c 同理对应左/中/右。
4. 输出画布大小与右部区域（去除分隔列）相同，全部初始化为黑(0)。将复合图案放置到画布上，使复合图案的锚点（由 r, c 决定的行列对齐方式）与画布的对应边/中线对齐。若复合图案超出画布，超出部分裁剪。
5. 品红(6)分隔列不出现在输出中。

**关键洞察**：没有任何单个彩色副本是完整的——必须先通过对齐联合还原出完整掩码，才能知道要平铺什么形状。掩码的形状直接影响最终放大复合体的外观。

## 新题 5：滑动对齐后射线延伸，滑动距离编码尾部重涂长度

**组合逻辑**：[滑动对齐/slide_to_align + 颜色匹配锚点/color_match_anchor + 边缘位置决定轴/edge_position_determines_axis](创新：对齐后的新位置成为射线起点) → [射线延伸/ray_extend](创新：射线方向由锚点所在边缘的反方向决定) + [重涂色/recolor + 间距编码尾长/gap_distance_encodes_tail_length](创新：滑动距离替代间距编码尾长)

**来源原语**：滑动对齐/颜色匹配锚点/边缘位置决定轴/边界锚点(581f7754)，射线延伸/间距编码尾长(696d4842)，重涂色(696d4842)，标记像素(581f7754/696d4842)

**依赖链**：精灵体滑动到锚点对齐位置 → 滑动距离 D 被记录 → 从对齐后的标记像素沿锚点反方向发射射线 → 射线末端 D 个像素被重涂为锚点颜色。滑动步骤同时完成空间变换和度量提取，射线步骤依赖两者。

将多色精灵体滑动对齐到匹配的边界锚点，然后从对齐后的标记像素发射射线，射线末端被重涂的长度等于滑动距离。

**输入结构**：约 14x14 的网格，灰(5)为背景。内部有 2-3 个小型多色精灵体（multicolor_sprite，每个 4-8 像素，4-连通），每个精灵体包含一个"少数色"标记像素（marker_pixel），其颜色与该精灵体其余像素不同。网格四条边上各有 0-1 个孤立的非背景像素作为边界锚点（border_anchor），其颜色与某个精灵体的标记像素颜色相同。每个精灵体恰好匹配一个锚点（颜色一一对应）。精灵体与其匹配锚点之间沿滑动轴方向有 2-5 个背景像素的间距。生成约束：滑动后精灵体之间不重叠，且射线路径不穿过其他精灵体。

**规则**：
1. 将每个精灵体与共享标记颜色的边界锚点配对。
2. 确定滑动轴：锚点在顶边或底边（非角落）→ 水平滑动精灵体使标记像素列 = 锚点列；锚点在左边或右边（含角落）→ 垂直滑动精灵体使标记像素行 = 锚点行。
3. 计算滑动距离 D = 标记像素在滑动轴上移动的绝对像素数。
4. 滑动精灵体到对齐位置（整个精灵体平移，原位置擦除为背景）。
5. 从对齐后的标记像素位置出发，沿锚点的反方向（锚点在顶边→射线向下；锚点在底边→射线向上；锚点在左边→射线向右；锚点在右边→射线向左）逐像素延伸射线，使用精灵体主体颜色（非标记色的多数颜色）绘制，直到遇到非背景像素或网格边缘为止（不包含终点处的非背景像素）。
6. 将射线末端的 D 个像素（从远端向标记方向数 D 个）重涂为锚点/标记的颜色。若射线总长度小于 D，则将整条射线全部重涂。
7. 锚点像素本身保持不变。

**关键洞察**：滑动距离——由锚点对齐决定的空间量——同时充当射线尾部重涂的长度参数，将空间对齐步骤与射线着色步骤耦合为不可分离的整体。

## 新题 6：十字延伸分区后按输入颜色数周期填充

**组合逻辑**：[射线延伸/ray_extend + 交叉/crossing + 交叉点标记新色/crossing_cell_marked_new_color](创新：延伸出的十字线将画布切分为区域) → [计数/counting + 色数决定缩放/color_count_sets_scale](创新：颜色计数不用于缩放而用于确定周期填充间隔) → [洪泛填充/flood_fill + 等间隔采样填充/periodic_fill + 区域排列顺序/region_order](创新：区域来自十字分区而非弹跳分隔线)

**来源原语**：射线延伸/交叉/交叉点标记新色/横条段/竖条段(bdad9b1f)，计数/色数决定缩放(469497ad)，洪泛填充/等间隔采样填充/区域排列顺序/封闭区域(7447852a)，排序(7447852a)

**依赖链**：横竖条段延伸形成十字并标记交叉点 → 十字将画布分隔为若干区域 → 原始输入中不同非背景颜色的数量 N 决定填充周期 → 区域按阅读序排列后每隔 N 个填充一次。三步形成链式依赖：十字创建区域、颜色计数给出周期、周期作用于排序后的区域。

延伸输入中的一横一竖条段为穿越全画布的十字线，标记交叉点，然后统计原始输入的非背景颜色数量作为周期 N，对十字分隔出的区域按阅读序每 N 个填充一次。

**输入结构**：约 12x12 的网格，黑(0)为背景。包含一段水平条段（h_bar_segment，蓝(1)，宽 2-4 像素，高 1 像素）和一段垂直条段（v_bar_segment，绿(3)，高 2-4 像素，宽 1 像素），两者的行列交叉处为背景像素（即它们不在同一位置上实际相交）。此外，网格中还散布 1-3 个孤立的单色像素（颜色可以是红(2)、黄(4)、橙(7)等，各不相同），这些像素不在横条段所在行也不在竖条段所在列上。生成约束：横条段和竖条段分别只有一段，不紧贴网格边缘；所有孤立像素互不相邻。

**规则**：
1. 将水平条段所在行的全部像素填充为蓝(1)；将垂直条段所在列的全部像素填充为绿(3)。
2. 横竖延伸线的交叉单元格（唯一的行列交汇点）涂为黄(4)。
3. 原始输入中的孤立彩色像素在延伸操作中被覆盖（如果恰好在延伸行或列上）或保留（如果不在延伸行列上）。被覆盖的像素取延伸线的颜色。
4. 统计原始输入（延伸前）中出现的不同非背景颜色的数量，记为 N（至少包含蓝(1)和绿(3)两种，N >= 2）。
5. 识别延伸后网格中所有 4-连通的黑(0)背景区域。
6. 按每个区域包围框左上角的位置排序：先按行从上到下，行相同则按列从左到右。记排序后的区域索引为 0, 1, 2, ...。
7. 对索引为 0, N, 2N, 3N, ... 的区域，用橙(7)洪泛填充（如果橙(7)已作为孤立像素颜色出现在非延伸区域内，则该像素被保留，区域其余背景像素填充为橙(7)）。
8. 保持所有延伸线像素（蓝、绿）和交叉点像素（黄）不变。

**关键洞察**：输入中那些看似无关的孤立彩色像素既不参与延伸也不参与填充，但它们增加了非背景颜色的计数 N，从而改变了填充周期——颜色数量是语义信息，区域分隔是几何信息，两种不同维度的输入属性共同决定输出。

## 新题 7：锚点平移复制后部分重叠区域异或擦除

**组合逻辑**：[平移复制/translate_and_copy + 锚点偏移对应/anchor_offset_correspondence](创新：复制位置与原件部分重叠) → [异或/xor](创新：异或不是在分隔的两半掩码之间进行，而是在原件和复制件的重叠区域进行) + [擦除/erase](已有：擦除锚点标记)

**来源原语**：平移复制/锚点偏移对应/源锚点/目标锚点(2c737e39)，异或/逐像素异或输出(3428a4f5)，擦除(f45f5ca7)

**依赖链**：锚点偏移决定复制位置 → 复制位置与原件产生空间重叠 → 重叠区域内逐像素做异或判定（双方都有非背景像素则擦为背景） → 最终输出是原件与复制件的对称差。复制步骤生成了异或的第二操作数，且重叠范围由偏移量隐式决定。

将精灵体按锚点偏移复制到部分重叠的位置，在重叠区域执行异或逻辑：双方均有非背景像素的位置擦除为背景，仅单方有像素的位置保留。

**输入结构**：约 12x12 的网格，黑(0)为背景。一个 4-连通的多色精灵体（multicolor_sprite，8-15 像素，包含 2-3 种非背景颜色如蓝(1)、红(2)、绿(3)），其中恰好有一个灰(5)标记像素位于精灵体内部（与精灵体其他像素 4-相邻）。另有一个孤立的灰(5)标记像素位于网格其他位置。生成约束：源标记到目标标记的偏移量使得复制后的精灵体与原精灵体有 30%-70% 的包围框面积重叠（保证有重叠但不完全重叠）；目标标记的位置使得复制后的精灵体不超出网格边界。

**规则**：
1. 识别精灵体内部的灰(5)像素为源锚点，孤立的灰(5)像素为目标锚点。
2. 计算偏移向量 (dr, dc) = (目标行 - 源行, 目标列 - 源列)。
3. 将源锚点和目标锚点都擦除为黑(0)背景。
4. 对精灵体中每个非灰像素（即图案像素），计算其复制位置 = (原行 + dr, 原列 + dc)。
5. 构建输出网格：
   - 原精灵体的非灰像素保留在原位。
   - 复制像素绘制到复制位置。
   - 对于重叠区域（某个位置既有原件像素又有复制件像素）：无论两者颜色是否相同，该位置擦除为黑(0)背景。
   - 对于非重叠区域：原件独有的像素保留原色，复制件独有的像素保留复制色。
6. 最终输出是原件和复制件的空间对称差（symmetric difference）。

**关键洞察**：灰色锚点的偏移故意造成部分重叠，而重叠区域的异或擦除使输出既不是原件也不是简单复制——求解者必须识别重叠区域并理解"双方共有则消除"的抵消规则。

## 新题 8：视线匹配路径后同心环扩展，间距同时编码环数和尾部重涂

**组合逻辑**：[视线匹配/sightline_matching + 间距编码尾长/gap_distance_encodes_tail_length](创新：间距不仅编码尾长，还编码同心环数) → [同心层填充/concentric_fill + 切比雪夫距离索引/chebyshev_index + 色板按距离配色/palette_color_by_distance](创新：扩展中心是标记像素而非专门的种子) + [重涂色/recolor](创新：尾部重涂颜色取自最外环)

**来源原语**：视线匹配/间距编码尾长/路径对象/标记像素(696d4842)，同心层填充/切比雪夫距离索引/色板按距离配色/种子像素/色板行(9356391f)，射线延伸(696d4842)，重涂色(696d4842)

**依赖链**：标记像素通过视线与路径端点匹配 → 间距 D 同时决定两个后续操作的参数：(a) 以标记为中心扩展 D 层同心环，(b) 从路径对侧端点重涂 D 个路径像素 → 尾部重涂的颜色来自同心环最外层的色板颜色。间距这一单一度量同时驱动扩展范围、重涂长度和重涂颜色三个输出特征。

通过视线将标记像素匹配到路径端点，以两者间距 D 为参数：围绕标记扩展 D 层同心方环（颜色从色板行读取），同时从路径对侧端点将 D 个像素重涂为最外环颜色。

**输入结构**：约 16x16 的网格，黑(0)为背景。顶部一行为色板行（palette_row），从左端起有 4-6 个连续非背景像素，颜色依次不同（如蓝(1)、红(2)、绿(3)、黄(4)等）。色板行下方 1 行为品红(6)分隔行。分隔行下方区域中包含 2-3 条单色路径对象（path_object，每条路径是一像素宽、无分叉的正交路径，5-10 像素长，每条路径颜色不同，如橙(7)、青(8)、栗(9)等）。同时有等数量的孤立标记像素（marker_pixel），每个标记像素与恰好一条路径的某个端点共享同一行或同一列，且两者之间全为背景像素（形成清晰的视线）。标记-路径的匹配是全局唯一的一一对应。生成约束：每个标记与其匹配路径端点之间的间距为 2-4 个背景像素；各路径之间互不相邻；标记的同心环扩展范围不与其他路径重叠。

**规则**：
1. 将每个标记像素与路径端点通过行/列视线唯一匹配（标记与路径端点在同一行或同一列，之间全为背景）。
2. 计算间距 D = 标记与匹配端点之间的背景像素数（不含标记和端点本身）。
3. 用路径对象的颜色填充间距（将标记和端点之间的 D 个背景像素涂为路径颜色），标记像素本身保持原色。
4. 以标记像素为中心，扩展 D 层同心方环：切比雪夫距离 d (1 <= d <= D) 的所有像素取色板行第 d 个颜色（palette[d-1]，从左起第 d 个非背景色）。若 D 大于色板有效长度 L，则 d > L 的环取 palette[(d-1) mod L]（循环使用色板）。标记像素本身保持原色。环像素仅覆盖背景像素，不覆盖已有的路径、标记或间距填充像素。
5. 确定最外环颜色 C_outer = palette[(D-1) mod L]。
6. 在匹配路径的对侧端点（未被标记匹配的那个端点）起，沿路径方向将连续 D 个路径像素重涂为 C_outer。若路径总长度（不含间距填充）小于 D，则将整条路径全部重涂。
7. 色板行和分隔行保持不变。

**关键洞察**：标记到路径端点的间距 D 是一个数值枢纽——它同时控制同心环的层数（几何扩展）、尾部重涂的长度（路径修改）以及通过索引色板间接决定重涂的颜色，三者不可独立确定。
