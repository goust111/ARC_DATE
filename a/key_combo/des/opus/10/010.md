## 新题 1：射线分区决定同心方块缩放方向

**组合逻辑**：[射线延伸](创新：射线不再擦除，而是将空间分为命中/未命中两个区域) → [射线命中/ray_intersection](已有) → [缩放/resize + 边长循环变换](创新：循环方向不再统一，而是由射线命中关系分叉决定)

**来源原语**：射线延伸、标记条、控制像素(2f767503)；缩放、奇数边正方形、中心点、边长循环变换(522fdd07)；射线命中(2f767503)

**依赖链**：射线将方块集合分成两组 → 分组结果决定每个方块的循环方向 → 循环方向不同导致同一边长的方块在输出中变成不同尺寸。删除射线则无法知道循环方向；删除循环则知道分组也无法确定输出。

将射线投射到一组奇数边同心正方形上，命中的方块边长缩小一级，未命中的方块边长增大一级，边长在 1-3-5-7-9 间循环。

**输入结构**：约 20x20 的黑(0)背景网格。包含一个由三像素组成的灰(5)水平或垂直标记条，以及一个紧邻标记条中心的栗(9)控制像素。网格中散布 4~6 个互不重叠的单色实心正方形，每个正方形边长为奇数（属于集合 {1, 3, 5, 7, 9}），颜色互不相同，从红(2)、绿(3)、黄(4)、蓝(1)、橙(7)中选取。各方块中心之间至少间隔 12 像素，保证边长 9 时不重叠。标记条放置在网格边缘附近，控制像素位于标记条中心的上/下/左/右之一。生成约束：至少有一个方块被射线命中且至少一个未被命中。

**规则**：
1. 从灰(5)标记条的中心像素出发，沿远离栗(9)控制像素的方向投射一条单像素宽的无限射线（上/下/左/右四个方向之一），射线延伸至网格边界。
2. 判定每个正方形是否被射线命中：射线经过该正方形的任意一个像素即视为命中。
3. 被命中的正方形：保持中心位置和颜色不变，边长按 n → n-2 缩小；若 n=1，则循环到 n=9。
4. 未被命中的正方形：保持中心位置和颜色不变，边长按 n → n+2 增大；若 n=9，则循环到 n=1。
5. 先清除画布为黑(0)，然后按方块中心从左上到右下的顺序（先比较行号，行号相同再比较列号）逐个绘制变换后的方块。后绘制的覆盖先绘制的。
6. 标记条和控制像素在输出中擦除（不绘制）。

**关键洞察**：射线不是用来擦除的，而是一个二值分区器——命中与否决定了每个方块经历相反方向的尺寸循环，使得同为 5x5 的两个方块在输出中可能变成 3x3 或 7x7。

## 新题 2：对角连线重构封闭区域后洪泛填充

**组合逻辑**：[连线/connect](创新：对角线不再是装饰性连接，而是构成新的封闭边界) + [洪泛填充/flood_fill](创新：填充的区域不是输入中已有的轮廓框，而是对角线与轮廓共同围成的新区域) + [多数色决定填充](已有)

**来源原语**：连线、同色矩形对、对角偏移、对角补全连接(342ae2ed)；洪泛填充、轮廓框、标记像素、封闭区域、标记在封闭区域内、多数色决定填充(4b6b68e5)

**依赖链**：对角连线改变了区域的拓扑结构 → 新拓扑决定了哪些标记像素落入哪个封闭子区域 → 子区域内的多数标记色决定填充颜色。删除连线则区域拓扑不同、填充结果错误；删除填充则连线本身不构成答案。

在灰色轮廓框内部，用同色矩形对之间的对角线将封闭区域切分为子区域，然后根据每个子区域内标记像素的多数颜色进行洪泛填充。

**输入结构**：约 18x18 的黑(0)背景网格。包含 1~2 个灰(5)像素组成的 4-连通封闭轮廓框（每个轮廓宽一像素，围成一个至少 8x8 的矩形或 L 形区域）。轮廓框内部存在 2~3 对同色小矩形（每个矩形为 1x1 至 2x2 的实心块），每对使用不同颜色（从红(2)、绿(3)、蓝(1)中选取）。每对矩形中的两个块呈 45 度对角偏移，其对角连线完全位于封闭区域内部。轮廓框内部还散布若干单像素标记点，颜色为黄(4)或橙(7)。生成约束：每条对角线都与至少一条轮廓边或另一条对角线相交，确保切分出新的子区域；每个新子区域内至少包含一个标记像素。

**规则**：
1. 保留灰(5)轮廓框的所有像素不变。
2. 对每对同色矩形，找到两个矩形面向彼此的最近角点，在两角点之间（不含角点本身）沿 45 度对角线绘制该颜色的像素。若对角路径上有其他非背景像素，则该条连线在遇到第一个非背景像素前一格停止。
3. 将轮廓框像素、对角连线像素、矩形对像素共同视为"墙壁"。从轮廓框的外部边界出发做 4-连通洪泛标记，所有不可达的黑(0)连通区域即为独立封闭子区域。
4. 对每个封闭子区域，统计其内部标记像素（黄(4)或橙(7)）的颜色。将该子区域的所有黑(0)像素填充为其中出现次数最多的标记颜色。若黄(4)和橙(7)数量相同，选用在该子区域中位置更靠上（行号更小）的那个标记像素的颜色。
5. 填充完成后，擦除所有单像素标记点（恢复为黑(0)），但保留矩形对和对角连线。

**关键洞察**：对角连线不是终态的一部分，而是构造步骤——它们与轮廓框共同形成新的拓扑边界，把原本单一的封闭空间切分成多个子区域，从而改变了标记像素的"归属"和填充颜色的分配。

## 新题 3：游程压缩揭示形状等价后按拉伸量排序涂色

**组合逻辑**：[压缩/compression](已有) → [形状匹配/shape_match + 旋转反射等价](已有) → [重涂色/recolor + 面积比较](创新：比较的不是对象面积，而是压缩前后的面积差——即"拉伸量"，作为隐蔽排序指标)

**来源原语**：压缩、游程压缩后比较(bd14c3bf, ce8d95cc)；形状匹配、旋转反射等价、原型对象、候选对象(bd14c3bf)；重涂色、面积比较、极值区域分别涂色(6455b5f5)

**依赖链**：压缩使拉伸的候选形状可以与原型比较 → 匹配结果决定哪些对象被保留 → 保留对象的拉伸量（原始像素数 - 压缩后像素数）决定最终颜色。三步缺一不可：无压缩则无法匹配；无匹配则不知保留谁；无拉伸量排序则不知涂什么色。

将拉伸程度不同的候选对象通过行列压缩还原后与原型匹配，匹配成功的按拉伸量极值分别涂色，不匹配的擦除。

**输入结构**：约 18x18 的黑(0)背景网格。包含一个灰(5)原型对象（4-连通，4~8 像素，形状不规则，无孔洞）。另有 4~6 个红(2)候选对象散布于网格中，互不接触。候选对象中部分是原型的旋转或反射版本经过行方向或列方向的拉伸（某些相邻行或列被复制 1~3 次）后得到的；其余候选对象是与原型无关的随机 4-连通形状。生成约束：至少 2 个候选对象匹配原型，至少 1 个不匹配；匹配的候选对象之间拉伸量互不相同。

**规则**：
1. 对每个红(2)候选对象，提取其最小边界框，然后逐行扫描：若相邻两行的像素图案完全相同，则合并为一行；再逐列扫描做同样的合并。得到压缩后的形状。
2. 将每个压缩后的候选形状与灰(5)原型形状在所有 4 个旋转和 2 个镜像（共 8 种变换）下比较。若任一变换下逐像素一致，则该候选匹配成功。
3. 不匹配的候选对象全部擦除为黑(0)。
4. 对匹配成功的候选对象，计算其拉伸量 = 原始边界框像素数 - 压缩后边界框像素数。
5. 拉伸量最大的候选对象重涂为蓝(1)，拉伸量最小的重涂为青(8)。其余匹配的候选对象保持红(2)不变。若最大或最小存在并列，则并列的对象全部涂对应颜色。
6. 灰(5)原型对象保持不变。

**关键洞察**：拉伸量（冗余行列数）是一个隐藏属性——它在视觉上表现为对象"更胖"或"更长"，但求解者必须通过压缩操作才能量化这一差异，而不能仅凭外观尺寸判断，因为旋转/反射使得行列方向的拉伸交叉混合。

## 新题 4：分隔线颜色编码的弹射滑动

**组合逻辑**：[滑动/slide](创新：滑动不再单向到底，而是遇到特定颜色的分隔线时反弹并改变自身颜色) + [颜色互换/color_swap](创新：互换不再由反射触发，而是由碰撞的分隔线颜色触发) + [碰撞停止](创新：停止条件分化——灰线停止，橙线反弹)

**来源原语**：滑动、碰撞停止、颜色匹配、同色滑向同色边(17829a00)；颜色互换、反射触发色换(a25697e4)；分隔线(6455b5f5)

**依赖链**：滑动方向由对象颜色决定 → 碰撞分隔线的颜色决定是停止还是反弹 → 反弹同时改变对象颜色，从而改变滑动方向 → 最终位置和最终颜色由整个弹射链共同决定。删除滑动则无运动；删除分隔线颜色判断则无弹射；删除颜色互换则弹射后方向不变导致无限循环。

小对象在水平分隔线之间滑动，遇到灰色分隔线停下，遇到橙色分隔线则颜色翻转并反弹，直至遇到灰色线或网格边界。

**输入结构**：约 15x20 的黑(0)背景网格。4~6 条完整的水平分隔线将网格分成 5~7 个水平带。每条分隔线颜色为灰(5)或橙(7)，两种颜色交替或随机分布，但保证至少有 2 条灰(5)和 2 条橙(7)。网格的最顶行和最底行视为隐含的灰(5)边界（不绘制）。每个水平带内包含 0~2 个小型单色对象（4-连通，3~5 像素），颜色为红(2)或蓝(1)。对象不接触任何分隔线，且同一列中不存在两个对象。生成约束：每个对象的弹射路径最终会遇到灰(5)分隔线或网格边界而停止（不会无限弹射）。

**规则**：
1. 红(2)对象向上滑动，蓝(1)对象向下滑动。对象作为刚体沿垂直方向移动，保持形状和水平位置不变。
2. 对象滑动直到其边界框的前沿（红色为顶边，蓝色为底边）紧邻一条分隔线或网格边界。
3. 若碰到的是灰(5)分隔线或网格边界：对象停在当前位置，滑动结束。
4. 若碰到的是橙(7)分隔线：对象的颜色在红(2)和蓝(1)之间互换，然后立即反转方向继续滑动（原来向上变为向下，反之亦然），从碰撞位置出发继续寻找下一条分隔线。
5. 弹射可能连续发生多次。每次碰到橙(7)线都互换颜色并反弹。
6. 处理顺序：按对象的初始位置从上到下逐个处理（行号小的先处理）。先处理完的对象成为后续对象的障碍物——后续对象碰到已停止的对象时也视为碰到灰(5)线（停下，不互换颜色）。
7. 分隔线保持不变。对象原始位置留下的区域恢复为黑(0)。

**关键洞察**：橙色分隔线是"颜色反转镜"——它同时翻转对象的颜色和运动方向，使对象在分隔线之间形成弹射链。最终停止位置和最终颜色取决于整条弹射路径上橙色线的数量：偶数次弹射颜色不变，奇数次弹射颜色翻转。

## 新题 5：对称修复先于像素放大的框内图案重建

**组合逻辑**：[裁剪/crop](已有) + [对称补全/symmetry_completion](创新：对称补全不再作用于整个网格，而是作用于框内的微型种子图案) → [像素放大/pixel_upscale](创新：放大的不是原始图案，而是修复后的图案——修复必须在放大之前完成)

**来源原语**：裁剪、像素放大、矩形边框、内部图案、图案在框内、图案倍增填框(e7a25a18)；对称补全、掩码像素、对称轨道映射、全对称群轨道约束(47996f11)

**依赖链**：裁剪定义输出尺寸 → 内部种子图案包含掩码像素（品红色缺损）→ 对称补全利用种子图案的双轴对称性修复掩码 → 修复后的完整图案以 2 倍放大填入框内。删除裁剪则输出尺寸错误；删除对称修复则放大后图案有品红色错误像素；删除放大则图案尺寸不匹配框内空间。

裁剪到矩形框，将框内含缺损的微型种子图案先用对称性修复再 2 倍放大填入框内。

**输入结构**：约 20x20 的黑(0)背景网格。包含一个单色矩形边框（绿(3)，宽一像素，内部空间为偶数行 x 偶数列，范围 6x6 到 10x10）。框内有一个由非背景、非框色、非品红颜色组成的小图案，占据框内空间的左上 1/4 区域（即框内空间一半行数 x 一半列数），这个小图案具有关于其自身中心的左右对称性。图案中有 1~3 个像素被替换为品红(6)，表示缺损。框外可能有若干干扰像素（任意颜色的孤立点），需忽略。生成约束：缺损像素的对称伙伴（关于图案中心的左右镜像位置）一定是未缺损的，从而保证可修复；修复后的图案以 2 倍放大后恰好填满框内空间。

**规则**：
1. 裁剪输出至绿(3)矩形边框的边界框（含框本身）。
2. 提取框内空间中非黑(0)、非绿(3)像素的最小边界框，作为种子图案。忽略品红(6)像素的位置——它们被视为"未知"。
3. 种子图案具有左右对称性（关于其水平中轴线镜像）。对每个品红(6)像素，找到其关于水平中轴线的镜像位置，将该镜像位置的颜色复制到品红像素处。
4. 将修复后的种子图案在水平和垂直方向各放大 2 倍（每个像素扩展为 2x2 块），写入框内空间，左上角对齐。放大后图案恰好填满整个框内空间。
5. 边框像素保持不变。框外所有内容在输出中不出现（已裁剪）。

**关键洞察**：品红像素不是图案的一部分——它们是在缩小尺度上的缺损标记。求解者必须先在小尺度下利用对称性修复缺损，然后才能正确放大；若先放大再修复，缺损会扩散为 2x2 的错误块，且放大后的对称结构更难识别。

## 新题 6：背景子区域计数编码颜色循环步数

**组合逻辑**：[计数/counting](创新：计数结果不再输出为像素列，而是编码为另一个操作的参数) + [循环轮换/cyclic_shift](创新：轮换步数不再固定为 1，而是由计数结果动态决定) + [前景屏障](创新：屏障不再只是分隔背景，同时是某个区域的内部结构)

**来源原语**：计数、连通分量、背景区域、前景屏障、区域数编码像素列(e872b94a)；循环轮换、分隔结构、分离区域、环绕角度排序(880c1354)

**依赖链**：中央分隔结构将空间分成若干有色区域 → 某些区域内部有屏障将该区域的背景部分切分为子区域 → 统计全网格的背景子区域总数得到 K → 所有有色区域的颜色按角度顺序循环轮换 K 步。删除计数则不知轮换多少步；删除循环轮换则计数无用；删除屏障则子区域数不同导致 K 错误。

中央分隔结构周围的彩色区域颜色按角度顺序循环轮换，步数等于全网格中被屏障切分出的背景子区域总数。

**输入结构**：约 15x15 的黑(0)背景网格。网格中央有一个由黄(4)和橙(7)像素组成的十字形或 T 形分隔结构（与参考题 880c1354 类似）。分隔结构将网格分为 4~6 个空间区域，每个区域填充一种独特的非黄非橙前景色（从红(2)、蓝(1)、绿(3)、灰(5)、青(8)、栗(9)中选取），且区域内有若干黑(0)背景像素。部分区域内部包含同色前景像素形成的细线段（1 像素宽，2~4 像素长），这些线段将该区域内的黑(0)背景像素切分为多个 4-连通子区域。生成约束：全网格的背景子区域总数 K 满足 1 < K < 区域数量，确保循环轮换不退化为恒等变换。

**规则**：
1. 黄(4)和橙(7)分隔结构保持不变。
2. 识别所有非背景、非分隔结构的前景色区域。每个区域是一个 4-连通的同色连通分量。
3. 统计整个网格中黑(0)背景像素的 4-连通连通分量数，记为 K。注意：区域内的屏障线段会把该区域的背景切分为多个子分量，均计入 K；不同区域的背景分量如果通过分隔结构之间的缝隙相连，则视为同一个分量。
4. 按每个前景区域质心相对于分隔结构质心的角度排序（以屏幕坐标系的正右方为 0 度，顺时针递增）。
5. 每个区域保持其空间位置和形状不变（包括内部的屏障线段），但颜色按顺时针方向循环移动 K 步：排序中第 i 个区域获得第 (i-K) mod N 个区域的颜色（N 为区域总数）。

**关键洞察**：区域内部的前景屏障线段看起来只是区域的纹理细节，但它们通过切分背景来增加全局计数 K，从而间接改变了所有区域的颜色分配——屏障的数量和位置编码了循环轮换的步长。

## 新题 7：多尺度印章的负空间涌现标记线

**组合逻辑**：[像素缩放/pixel_scaling + 边长定缩放因子](已有) + [印章覆盖/stamp_overlay + 仅填背景格](已有) → [全空行列检测 + 重涂色/空行列涂标记色](创新：空行列不是在输入中检测，而是在所有印章叠加后的复合图案中涌现出来的)

**来源原语**：像素缩放、模板、标记方块、缩放对应、边长定缩放因子(447fd412)；印章覆盖、仅填背景格(f0df5ff0)；全空行列、重涂色、空行列涂标记色(c1d99e64)

**依赖链**：标记方块的边长确定缩放因子 → 模板按对应因子缩放后印章覆盖到标记位置 → 所有印章共同在网格上形成复合图案 → 复合图案中完全空白的行和列被标记为绿色。删除印章则无图案可分析；删除空行列检测则印章就是终态（缺少绿色标记线）；删除缩放因子推断则印章大小错误。

**输入结构**：约 20x20 的黑(0)背景网格。左上角有一个蓝(1)模板图案（4-连通，占据约 3x3 到 4x4 的边界框，形状不规则，不填满整个边界框）。网格其余区域散布 3~5 个红(2)实心正方形（标记方块），边长为 2 或 3，互不重叠。模板与所有标记方块互不接触。绿(3)在输入中不出现。生成约束：所有印章完成后，至少存在一行和一列仍然完全为黑(0)；同时至少存在一行和一列不完全为黑(0)。

**规则**：
1. 识别蓝(1)模板图案的最小边界框，记为 P（宽 w、高 h）。
2. 对每个红(2)标记方块，取其边长 k 作为缩放因子。
3. 将模板 P 的每个蓝(1)像素放大为 k x k 的蓝(1)块，得到缩放后的图案 P_k（尺寸 kw x kh）。
4. 将 P_k 的左上角对齐到该标记方块的左上角位置，逐像素写入网格。仅覆盖当前为黑(0)的格子（已有非背景像素的位置跳过）。红(2)标记方块本身的像素在此步骤前先擦除为黑(0)。
5. 按标记方块左上角从左上到右下的顺序（先行后列）依次处理。
6. 所有印章完成后，扫描整个网格：将所有完全由黑(0)组成的行的每个像素涂为绿(3)；将所有完全由黑(0)组成的列的每个像素涂为绿(3)。行列交叉点也为绿(3)。
7. 原始蓝(1)模板保留在左上角。

**关键洞察**：绿色标记线不是预设的——它们从多个不同尺度印章的组合负空间中涌现。求解者必须先完成所有缩放和印章才能确定哪些行列完全空白，无法从单个印章推断最终的绿色线位置。

## 新题 8：射线选择生长对象与原色追踪

**组合逻辑**：[射线延伸/ray_extend + 射线命中](已有) → [生长/grow](创新：生长不再无条件应用于所有同心方块，而是仅应用于射线命中的对象) + [颜色互换/inner_outer_swap](创新：所有对象都做颜色互换，但生长材料的颜色取决于互换前的原始边框色，需要"记忆"原色)

**来源原语**：射线延伸、标记条、控制像素、射线命中(2f767503)；生长、同心正方形层、外延矩形、内外层交换、框核换色后延伸(3befdf3e)

**依赖链**：射线命中判定 → 分为"命中组"和"未命中组" → 两组都执行内外色互换 → 命中组额外执行四方向矩形生长 → 生长材料颜色为互换前的原始边框色（非当前边框色）。删除射线则不知谁生长；删除互换则颜色错误；删除"原色追踪"则生长材料颜色错误。

射线命中的同心方块既互换内外色又向四方生长，未命中的仅互换，生长材料取原始边框色。

**输入结构**：约 18x18 的黑(0)背景网格。包含一个灰(5)三像素水平或垂直标记条和一个紧邻标记条中心的栗(9)控制像素。网格中散布 3~4 个互不重叠的同心正方形图案，每个由一个 3x3 或 5x5 的单色内层正方形加上一圈宽一像素的不同色外层边框组成。内层和外层颜色从红(2)、蓝(1)、绿(3)、黄(4)、橙(7)、青(8)中选取，每个同心方块的两种颜色互不相同且不与其他方块重复。各同心方块之间留有至少 3 像素的间距以容纳生长。生成约束：射线至少命中 1 个方块且至少有 1 个未命中；命中方块的生长不会超出网格边界或侵入其他方块的原始区域。

**规则**：
1. 从灰(5)标记条中心沿远离栗(9)控制像素的方向投射射线至网格边界。
2. 射线经过任意像素属于某同心方块（内层或外层均算），则该方块被标记为"命中"。
3. 对所有同心方块（无论命中与否），记录其原始外层边框颜色 C_border，然后执行颜色互换：内层颜色变为原外层颜色，外层颜色变为原内层颜色。
4. 对命中的同心方块，额外执行四方向生长：在互换后的方块的上、下、左、右四个方向各延伸一个矩形条，宽度等于方块外层边长，长度为 2 像素。延伸条的颜色为步骤 3 中记录的原始外层边框颜色 C_border（注意：此时该颜色已不在方块的外层，而是在内层）。延伸超出网格边界的部分裁剪掉。
5. 未命中的同心方块仅做颜色互换，不生长。
6. 标记条和控制像素在输出中擦除。
7. 绘制顺序：先绘制所有互换后的方块，再绘制所有生长矩形。若生长矩形之间重叠，按方块中心从左上到右下的顺序，后绘制的覆盖先绘制的。

**关键洞察**：颜色互换和生长使用的是同一个原始颜色，但在不同的角色中——互换后该颜色从外层移到内层，而生长材料仍引用它。求解者必须追踪颜色的"原始身份"而非"当前位置"来确定生长材料的颜色。

## 新题 9：纵列重排为金字塔后对称性解码掩码

**组合逻辑**：[堆叠/stack + 重排/rearrange](创新：重排不仅改变布局，还创造出原本不存在的对称结构) → [对称补全/symmetry_completion](创新：对称性不是输入的固有属性，而是重排后涌现的结构约束)

**来源原语**：堆叠、重排、前景列像素、居中金字塔、奇数宽度递增(3d6c6e23)；对称补全、掩码像素、对称轨道映射(47996f11)

**依赖链**：纵列像素按奇数宽度递增排列为居中金字塔 → 金字塔具有左右对称结构 → 利用对称性推断品红掩码像素的真实颜色 → 最终输出包含修复后的金字塔。删除堆叠重排则无金字塔、无对称可利用；删除对称补全则品红像素无法恢复。

将含有掩码缺损的纵列像素堆叠为居中金字塔，利用金字塔的左右对称性解码掩码像素的真实颜色。

**输入结构**：约 18x18 的黑(0)背景网格。包含 1~2 根垂直前景列（每根占一列），每根列中有 n^2 个非背景像素从上向下排列（n = 2 或 3，即 4 或 9 个像素），像素颜色来自红(2)、蓝(1)、绿(3)、黄(4)中的若干种，从上到下按颜色分为长度 1, 3, 5, ... 的连续段。每根列中有 1~2 个像素被替换为品红(6)，表示掩码。品红像素仅出现在长度 >= 3 的段内（不在长度为 1 的顶部段）。生成约束：每个品红像素在金字塔重排后的位置有一个关于金字塔垂直中轴的镜像位置，且镜像位置的像素不是品红色，从而保证可修复。不同列的金字塔在输出中的水平位置不重叠。

**规则**：
1. 对每根前景列，从上到下读取所有非黑像素（包括品红(6)），得到序列 S，长度为 n^2。
2. 将 S 拆分为连续子段，长度依次为 1, 3, 5, ...（第 1 段 1 个像素，第 2 段 3 个像素，第 3 段 5 个像素，依此类推），共 n 段。
3. 在输出中，以该列的列号为水平中心，将每段排列为水平居中的行，从上到下依次排列。第 1 段（1 像素）在最顶行，第 n 段（2n-1 像素）在最底行。所有段底部对齐于原列最底部像素的行号。
4. 金字塔具有关于其垂直中轴的左右对称性。对每个品红(6)像素，找到其关于金字塔垂直中轴的镜像位置，将镜像位置的颜色复制到品红像素处。
5. 原始前景列中的像素在输出中被清除为黑(0)（它们已被重新排列到金字塔中）。
6. 若有多根列，每根独立处理，输出中多个金字塔共存。

**关键洞察**：品红掩码在一维纵列中无法推断——纵列本身没有对称结构。只有当像素被重排为二维金字塔后，左右对称约束才涌现，使得每个掩码像素恰好有一个可见的对称伙伴。重排操作不仅是布局变换，更是"激活"了隐藏的约束信息。

## 新题 10：表格单元内压缩匹配决定填充色

**组合逻辑**：[分隔线网格 + 网格单元格](已有) → [压缩/compression + 形状匹配/shape_match](创新：单元格的不同尺寸相当于不同程度的拉伸，压缩用于消除容器引入的形变) → [填充/fill](创新：填充颜色不再由表格位置决定，而是由匹配结果决定)

**来源原语**：分隔线网格、网格单元格、表格行列位(e9c9d9a1)；压缩、相同行列合并(ce8d95cc)；形状匹配、旋转反射等价、游程压缩后比较、原型对象、候选对象(bd14c3bf)；填充(e9c9d9a1)

**依赖链**：分隔线定义单元格边界 → 单元格尺寸不同导致内部图案被拉伸 → 压缩消除拉伸后与原型比较 → 匹配结果决定该单元格的背景填充色。删除网格则无法确定图案边界；删除压缩则拉伸的图案无法匹配；删除匹配则不知填什么色。

绿色网格的单元格内包含不同拉伸程度的图案，压缩后与原型单元格的图案匹配的涂蓝色背景，不匹配的涂红色背景。

**输入结构**：约 20x20 的黑(0)背景网格。绿(3)像素组成完整的水平和垂直分隔线，将网格划分为 3x3 或 4x3 的单元格矩阵。各单元格的行高和列宽不完全相同（有的行高 3，有的行高 5；有的列宽 4，有的列宽 6），但同一行的所有单元格高度相同，同一列的所有单元格宽度相同。左上角单元格包含一个黄(4)的原型图案（4-连通，3~6 像素，不填满单元格，有一定形状特征）。其余单元格中，部分包含黄(4)图案（是原型在该单元格的行高/列宽下拉伸后的旋转或反射版本），部分包含黄(4)的无关图案（像素数和形状与原型不同）。少数单元格可能为空（全黑）。生成约束：至少 3 个非原型单元格包含匹配图案，至少 2 个包含不匹配图案。

**规则**：
1. 绿(3)分隔线全部保留不变。
2. 识别左上角单元格为原型单元格，提取其中黄(4)像素的最小边界框作为原型形状 P。原型单元格的背景保持黑(0)不变。
3. 对每个非原型、非空单元格：
   a. 提取其中黄(4)像素的最小边界框。
   b. 对该边界框做行列压缩：合并相邻的完全相同行，合并相邻的完全相同列。
   c. 将压缩后的形状在 8 种刚体变换（4 旋转 x 2 镜像）下与原型 P 比较。
   d. 若任一变换下逐像素匹配：该单元格的所有黑(0)背景像素填充为蓝(1)，黄(4)图案像素保留。
   e. 若所有变换下均不匹配：该单元格的所有黑(0)背景像素填充为红(2)，黄(4)图案像素保留。
4. 空单元格（无黄色像素）的背景保持黑(0)。

**关键洞察**：表格的行高列宽不均匀充当了一种"隐性编码器"——同一个图案在窄列中被压缩、在宽列中被拉伸，外观差异巨大。求解者必须意识到行列压缩能消除这种容器引入的形变，还原出底层的拓扑等价关系。
