## 新题 1：对称性筛选的层序合成

**组合逻辑**：[筛选/filter](创新：对称性作为面板存活条件) + [计数/counting](创新：像素数量决定遮挡深度) + [透明叠加/transparent_overlay](已有) → 条件分支筛选 + 动态层序合成

**来源原语**：筛选/filter、对称性筛选目标/symmetry_filter（参考题 72ca375d）；透明叠加/transparent_overlay、前后遮挡/front_back_occlusion、面板顺序即层序/panel_order_is_depth、分隔列/separator_column（参考题 cf98881b）；计数/counting（参考题 9af7a82c）

**依赖链**：对称性检测决定哪些面板存活（筛选），存活面板的像素数量决定遮挡顺序（计数→排序），遮挡顺序决定合成结果（透明叠加）。三步缺一不可：不筛选则不知合成哪些层，不计数则不知层序，不合成则无输出。

将多个被分隔列隔开的色彩面板中通过对称性筛选的面板，按其前景像素数量从少到多的遮挡顺序合成为单一输出。

**输入结构**：黑(0)背景网格，约 7x25。网格被 3-4 条红(2)单像素宽的竖直分隔列等距分为 4-5 个面板，每个面板宽度相同（约 5 列）。每个面板内使用一种独特的非黑非红颜色（如蓝(1)、绿(3)、黄(4)、灰(5)等）绘制一个单色图案，黑(0)像素视为透明。各面板内图案的像素数量互不相同。其中恰好有 2-3 个面板的图案具备某种反射对称性（垂直、水平或对角线），其余面板的图案不具备任何反射对称性。生成约束：保证存活面板的像素数量互不相等。

**规则**：
1. 在红(2)分隔列位置将输入切分为若干等宽面板。
2. 对每个面板的前景图案逐一检测反射对称性（垂直、水平、对角线任一即可）。不具备任何对称性的面板被丢弃。
3. 对存活面板，统计各自的前景（非黑）像素数量。
4. 将存活面板按像素数量从少到多排定层序：像素最少的面板作为最底层（最先绘制），像素最多的面板作为最顶层（最后绘制）。
5. 创建一个与单面板等大的黑(0)输出画布。按层序依次将存活面板叠加到输出上：每个面板中的非黑像素覆盖画布上对应位置的已有像素，黑(0)像素不覆盖（透明）。

**关键洞察**：面板的存活与否取决于对称性检测（几何属性），层序取决于像素数量（统计属性），两者独立决定但共同约束最终合成结果。仅看单个示例无法确定层序规则是由像素数量还是由面板位置决定，须对比多例。

## 新题 2：环形领地的频率柱状图

**组合逻辑**：[填充/fill](创新：生成同心环作为中间结构) + [计数/counting](创新：统计空间领地中的特定环格) + [排序/sort + 柱状图/histogram_bar](已有) → 空间几何计算 → 统计读出

**来源原语**：同心环/concentric_ring、角标记像素/corner_marker_pixel、最近归属/nearest_ownership、奇偶距离决定填色/parity_distance_fill（参考题 d22278a0）；计数/counting、排序/sort、频率排序/frequency_ranking、柱状图/histogram_bar、频率降序柱状图/descending_frequency_histogram（参考题 9af7a82c）

**依赖链**：角标记位置决定环形领地的空间划分（最近归属），Chebyshev 距离奇偶性决定哪些领地格被计为"有效环格"（奇偶填色），有效环格数量决定柱状图列高与排列顺序（频率排序）。空间结构的量化结果直接编码为柱状图输出。

根据角标记生成同心方环领地，统计每个标记拥有的偶数距离环格数，以频率降序柱状图输出。

**输入结构**：黑(0)背景网格，约 11x11。在网格的 2-3 个角落各放置一个不同颜色的标记像素（如蓝(1)、红(2)、绿(3)），其余角落为空。标记颜色互不相同。生成约束：保证各标记的偶数距离领地格数互不相等，网格尺寸为奇数以避免过多对称平局。

**规则**：
1. 对网格中每个非标记的单元格，计算它到每个角标记的 Chebyshev 距离（max(|dr|, |dc|)）。
2. 将每个单元格归属于距它最近的唯一角标记；若到两个或更多标记距离相等，该单元格不归属于任何标记（视为无主）。
3. 在每个标记的领地内，计算 Chebyshev 距离为偶数的单元格数量（包括距离 0，即标记本身），记为该标记的"环格计数"。
4. 构建输出柱状图：输出网格高度 = 最大环格计数，宽度 = 标记数量。每列对应一个标记，列从左到右按环格计数降序排列。每列从顶行开始向下填充该标记的颜色，填充行数 = 该标记的环格计数，剩余行为黑(0)。

**关键洞察**：柱状图的列高不是直接从输入可读的——它是空间领地划分与距离奇偶条件的共同产物。不同角落组合会因领地边界的几何形状而产生非直觉的计数差异。须对比多个示例才能确认计数规则是 Chebyshev 距离而非欧氏距离，以及奇偶筛选条件。

## 新题 3：逐色对称决定自印章朝向

**组合逻辑**：[逐色处理/per_color_processing](创新：判定每色层的对称性) + [印章覆盖/stamp_overlay + 自身为模板/self_as_stencil](已有) + [镜像/reflect](创新：由对称性判断结果条件触发) → 同时约束满足

**来源原语**：印章覆盖/stamp_overlay、自身为模板/self_as_stencil、非背景处印章/stamp_at_nonbg（参考题 007bbfb7）；逐色处理/per_color_processing、对称轴/symmetry_axis（参考题 8e5c0c38）；镜像/reflect（参考题 8d5021e8）；按颜色条件分支/color_conditional_branch（参考题 2072aba6）

**依赖链**：必须先逐色判定对称性，才能知道每个前景像素对应的印章应正贴还是镜像贴。印章内容是输入自身，但贴入方向由该像素所属颜色层的对称属性决定。对称性检测、像素归色、印章朝向三者交织，缺一不可。

将小精灵体自身作为印章扩展为大网格，每个前景像素位置贴入原图副本，但所属色层具有垂直对称性的像素位置贴入左右镜像副本。

**输入结构**：黑(0)背景网格，约 4x5。网格上有一个小精灵体，使用恰好两种非黑颜色（如蓝(1)和红(2)），合计约 8-12 个前景像素。其中一种颜色的像素集合关于该色层自身的垂直中轴具有左右对称性，另一种颜色的像素集合不具有垂直对称性。两种颜色的像素空间上交错分布，不形成两个分离的连通区域。生成约束：两种颜色各至少占 3 个像素；对称色层的垂直中轴须可从该色层像素位置唯一确定。

**规则**：
1. 识别输入中的两种非黑颜色。对每种颜色，提取该颜色所有像素的位置集合，独立判定其是否关于某条垂直轴具有左右对称性。记对称的颜色为 S，非对称的颜色为 A。
2. 构建输出网格：高度 = 输入高度 x 输入高度，宽度 = 输入宽度 x 输入宽度。将输出划分为与输入等大的块（每块对应输入中一个像素位置）。
3. 对输入中每个黑(0)像素，对应的输出块全部填黑(0)。
4. 对输入中每个颜色为 A（非对称色）的像素，将整个输入精灵体原样复制到对应输出块中。
5. 对输入中每个颜色为 S（对称色）的像素，将整个输入精灵体左右镜像后复制到对应输出块中。

**关键洞察**：印章内容本身不变（始终是原图或其镜像），但每个块的朝向由该块对应的源像素所属的颜色层的对称属性决定。确定哪种颜色对称需要逐色独立分析，这不是全局对称判断。仅看单个示例可能无法区分"按颜色决定朝向"和"按位置决定朝向"，须多例对比。

## 新题 4：前缀匹配长度驱动楔形填充

**组合逻辑**：[前缀匹配/prefix_matching](创新：匹配长度作为数值参数输出) + [填充/fill + 距离递变/distance_gradient](创新：楔形宽度由匹配长度参数化) → 参数提取 → 参数化生成

**来源原语**：行组/row_group、列状态序列/column_state_sequence、前缀匹配/prefix_matching（参考题 90f3ed37）；填充/fill、距离递变/distance_gradient、逐行宽度递变成楔/row_width_increments_form_wedge、线段/segment（参考题 a65b410d）

**依赖链**：参考行组编码了颜色序列"密钥"；每个下方线段是密钥的前缀，匹配长度 L 决定楔形宽度参数；楔形的逐行递变由 L 值控制。不读取参考行组无法确定 L，不确定 L 无法生成正确楔形。参考行组既非被补全的对象也非填充模板——它是解锁楔形参数的密码本。

读取顶部参考色带确定每个下方线段的前缀匹配长度，以该长度为基宽生成上扩下缩的三角楔形。

**输入结构**：黑(0)背景网格，约 15x12。顶部有一个跨满网格宽度的单行色带（行组），由多种非黑颜色的像素按特定顺序排列组成（如 [蓝(1), 蓝(1), 红(2), 绿(3), 红(2), 黄(4), ...]），每种颜色可出现多次。色带下方间隔若干空行后，分布着 2-3 条互不相邻的水平单行线段，每条线段左端对齐网格左边缘，使用灰(5)像素绘制，长度各不相同（约 2-6 像素）。各线段所在行互相间隔至少 4 行（为楔形留空间）。线段上方的灰(5)像素序列恰好是顶部色带从左端开始的前缀子序列的长度标记（即线段长度 = 该前缀在色带中匹配到的列数 L）。生成约束：每条线段的匹配长度 L 互不相同且均 >= 2；每条线段上下各有至少 L 行空间（不超出网格边界且不与其他线段的楔形重叠）。

**规则**：
1. 提取顶部色带的颜色序列 C[0], C[1], ..., C[W-1]（W = 网格宽度）。
2. 对每条灰(5)水平线段，测量其长度 L（像素数）。验证：C[0..L-1] 的前缀序列被该线段长度所标记（L 即为匹配长度）。
3. 保留原始线段不变（灰(5)）。
4. 在线段上方逐行填充蓝(1)：距线段 d 行处（d = 1, 2, ...），从左边缘开始填充宽度 = L + d 的蓝(1)像素。向上持续直到宽度超过网格宽度或遇到其他已有非黑元素，此时停止（不含该行）。
5. 在线段下方逐行填充绿(3)：距线段 d 行处（d = 1, 2, ...），从左边缘开始填充宽度 = L - d 的绿(3)像素。当 L - d < 1 时停止（不再填充）。

**关键洞察**：线段本身不携带颜色信息——它的长度 L 须通过与顶部色带的前缀对照才能获得语义。L 同时控制楔形的初始宽度和扩缩范围。不同线段因 L 不同而产生大小各异的楔形，而 L 的确定依赖于全局参考信息。须对比多个示例才能确认楔形宽度与线段长度的精确关系（+d 还是其他函数）。

## 新题 5：交替反射平铺后的跨边界轨道修复

**组合逻辑**：[平铺/tile + 镜像/reflect](创新：平铺为修复创造冗余而非作为最终目的) + [对称补全/symmetry_completion + 双轴反射轨道/two_axis_orbit](创新：轨道跨越瓦片边界) → 创造冗余 → 利用冗余修复

**来源原语**：平铺/tile、镜像/reflect、交替翻转平铺/alternating_reflections_tiling、阵列排布/array_layout（参考题 8d5021e8）；对称补全/symmetry_completion、占位标记/placeholder_marker、双轴反射轨道/two_axis_orbit、轨道内唯一可见色/unique_color_in_orbit（参考题 903d1b4a）

**依赖链**：平铺操作将小网格扩展为大网格，建立跨瓦片边界的反射对称关系；在大网格中，每个占位标记的反射轨道可能包含来自不同瓦片的单元格；利用轨道中的非占位色修复占位标记。平铺不只是展示——它构造了修复所需的轨道结构。不平铺则无轨道可用；不修复则占位标记残留。

先将含有损坏像素的小图案交替反射平铺为大网格，再利用跨瓦片边界的反射轨道修复所有损坏位置。

**输入结构**：黑(0)背景网格，约 4x3。网格上有一个使用 2-3 种非黑非绿颜色（如蓝(1)、红(2)、黄(4)）绘制的图案，其中部分位置被绿(3)像素替代，标记为"损坏"。绿(3)像素约占总前景像素的 20%-40%。生成约束：将输入按交替反射方式平铺为 3 倍高、2 倍宽的大网格后，每个绿(3)像素的反射轨道（最多 6 个成员，包括自身在不同瓦片中的像素）中至少有一个成员是非绿颜色，从而保证所有损坏位置可修复。输入中不能所有前景像素都是绿色。

**规则**：
1. 将输入视为源瓦片。构建中间带：将源瓦片与其左右镜像水平拼接。
2. 将中间带上下翻转得到翻转带。
3. 将翻转带、中间带、翻转带从上到下堆叠，得到 3 倍高、2 倍宽的平铺大网格。
4. 在平铺大网格中，对每个绿(3)像素，找到其在水平和垂直反射下的完整轨道（即：通过瓦片间的反射对称关系，该像素在大网格中对应的所有对称位置的集合）。
5. 若轨道中存在非绿(3)像素，则该轨道内所有绿(3)像素被替换为该非绿颜色（轨道内唯一可见色规则）。
6. 若轨道中所有成员均为绿(3)（由生成约束保证不会发生），则保持绿(3)不变。
7. 输出修复后的完整大网格。

**关键洞察**：平铺看似是简单的图案重复，但它的真正作用是为每个像素创造多个反射副本。这些副本构成了修复轨道——只要轨道中有一个未损坏的成员，所有损坏成员都可恢复。平铺和修复是不可分的：单独的小图无法自修复（轨道太小），单独的修复无轨道可用。须对比多例才能确认平铺方式（交替反射而非简单复制）和修复机制（轨道唯一色而非最近邻插值）。

## 新题 6：去噪后频率重排的色层拼图

**组合逻辑**：[逐色处理/per_color_processing + 对称补全/symmetry_completion](创新：去噪改变了统计量) + [计数/counting + 排序/sort](创新：排序对象是去噪后的色层裁剪) + [裁剪/crop + 拼接/pack](创新：拼接顺序由去噪后计数决定) → 变换 → 副效应测量 → 重排

**来源原语**：逐色处理/per_color_processing、对称轴/symmetry_axis、色层/color_layer（参考题 8e5c0c38）；擦除/erase（参考题 8e5c0c38）；计数/counting、排序/sort、频率排序/frequency_ranking（参考题 9af7a82c）；裁剪/crop（参考题 72ca375d）；拼接/pack（参考题 50aad11f）

**依赖链**：去噪改变各色层的像素数量（某些颜色可能丢失大量噪声像素），这使得去噪前后的频率排名可能不同。排列顺序必须基于去噪后的真实计数，不能基于原始计数。裁剪和拼接的空间布局由排序结果决定。去噪 → 计数变化 → 排名变化 → 拼接顺序。

对每种颜色独立去噪（移除破坏对称性的像素），再按去噪后像素数降序将各色层裁剪并排排列。

**输入结构**：黑(0)背景网格，约 14x14。网格上有 3-4 种非黑颜色（如蓝(1)、红(2)、黄(4)、品红(6)），每种颜色的像素形成一个近似于关于某条垂直轴对称的图案。每种颜色有各自独立的对称轴（轴位置互不相同）。每种颜色中有若干"噪声"像素——这些像素在该色层的垂直轴上没有对称配对。不同颜色的噪声比例不同：某些颜色噪声多（去噪后像素大幅减少），某些颜色噪声少。不同颜色的像素空间上互不重叠。生成约束：去噪后各色层像素数互不相等；至少有一对颜色在去噪前后频率排名发生反转（即颜色 X 去噪前比颜色 Y 多，去噪后比 Y 少）。

**规则**：
1. 对每种非黑颜色独立处理：找到该颜色所有像素关于垂直轴的最佳对称轴（使保留像素最多的轴）。移除该颜色中所有在对称轴上没有同色镜像配对的像素（将其置为黑(0)）。
2. 去噪完成后，对每种颜色统计剩余像素数量。
3. 对每种颜色的去噪结果，裁剪到其最小包围框（bounding box）。
4. 构建输出：将各色层的裁剪结果从左到右水平拼接，顺序为去噪后像素数降序（最多的在最左）。相邻裁剪块之间插入一列黑(0)间隔。如果裁剪块高度不同，所有块顶端对齐，下方用黑(0)填充至最高块的高度。

**关键洞察**：去噪是"纠正"操作，但它的副效应——像素数量变化——驱动了后续的空间排列。一种颜色如果噪声比例高，去噪后排名可能大幅下降。求解者不能跳过去噪直接计数排序，因为噪声像素会导致错误的排列顺序。须对比多例才能确认排序依据是去噪后而非去噪前的计数。

## 新题 7：多标记折线路径网络的交叉区域填充

**组合逻辑**：[连线/draw_line + 折线路径/folded_path](创新：多条独立路径的几何交互) + [平行配对/parallel_pairing + 段间区域填充/fill_between_segments](创新：填充对象是路径间的涌现区域) + [中心偏移选角/center_offset_selects_corner](已有) → 生成 → 检测涌现交互 → 填充

**来源原语**：连线/draw_line、标记像素/marker_pixel、折线路径/folded_path、列对齐/column_alignment、中心偏移选角/center_offset_selects_corner（参考题 7ec998c9）；填充/fill、平行配对/parallel_pairing、段间区域填充/fill_between_segments、对角线段/diagonal_segment、平行四边形区域/parallelogram_region（参考题 7666fa5d）

**依赖链**：每个标记独立生成折线路径（路径方向由标记列位置决定），但填充区域只在两条路径的对角段平行时出现——这是涌现效应。单个标记不产生填充；填充区域的形状由两条路径的相对几何关系决定。路径生成 → 平行段检测 → 区域填充。

多个标记各自生成折线路径后，在路径对角线段平行的位置之间填充平行四边形区域。

**输入结构**：橙(7)背景网格，约 15x18。网格上有 2-3 个非背景非蓝的标记像素（如红(2)、绿(3)），分别位于不同列，行位置不限但通常不在第一或最后一行。蓝(1)在输入中不出现。不同标记的列位置互不相同。生成约束：至少有一对标记的列位置满足——两者生成的折线路径的对角线段具有相同斜率（即两者都在中心列或都不在中心列），从而能产生平行对角段。网格列数为奇数，使中心列唯一。

**规则**：
1. 对每个标记像素，生成蓝(1)折线路径：将该标记所在列从顶到底全部涂蓝(1)（标记像素本身保留原色不变）。
2. 判断该标记是否位于网格的唯一中心列（列索引 = (宽度-1)/2）。
   - 若在中心列：从列顶端向右上角画对角线段，从列底端向左下角画对角线段（蓝(1)像素逐行向目标角偏移一列，直到到达网格边缘）。
   - 若不在中心列：从列顶端向左上角画对角线段，从列底端向右下角画对角线段。
3. 所有标记的路径绘制完成后，检测不同路径的对角线段之间的平行关系：两条对角段平行当且仅当它们斜率相同（同为+1或同为-1）且分别属于不同标记的路径。
4. 对每对平行的对角段，沿主对角线方向（r-c = 常数）扫描：在两条平行段之间（严格在两段之间、不含段本身的像素），将所有橙(7)背景像素填充为黄(4)。
5. 已有蓝(1)像素和标记像素不被覆盖。非平行的对角段之间不产生填充。

**关键洞察**：每个标记的路径生成是独立的、确定性的，但填充区域是路径间几何关系的涌现结果。中心列判断决定对角段方向——若两个标记一个在中心列、一个不在，它们的对角段斜率相反，不产生平行填充。须多例对比才能发现中心列判断规则及其对填充区域存在性的影响。

## 新题 8：精灵体形状频率决定遮挡层与重涂色

**组合逻辑**：[形状相同/shape_identity + 计数/counting](创新：频率排名同时驱动颜色和深度两个属性) + [重涂色/recolor](创新：颜色由排名而非原色决定) + [透明叠加/transparent_overlay + 前后遮挡/front_back_occlusion](创新：遮挡顺序由频率而非空间位置决定) → 分类 → 单一排名 → 双属性赋值

**来源原语**：精灵体/sprite、形状相同/shape_identity、计数/counting、最高频精灵输出/most_frequent_sprite_output（参考题 39a8645d）；重涂色/recolor（多题）；透明叠加/transparent_overlay、前后遮挡/front_back_occlusion（参考题 cf98881b）；裁剪/crop（参考题 72ca375d）

**依赖链**：形状识别将精灵体分组 → 计数得到各形状类型的频率 → 频率排名同时决定该组的重涂颜色和遮挡层级。一个排名维度同时控制两个视觉属性，使它们不可独立推断。不计数则无法确定颜色映射也无法确定遮挡顺序。

统计各精灵体形状类型的出现次数，以频率排名同时确定每组的重涂颜色和遮挡优先级，合成带遮挡的输出。

**输入结构**：黑(0)背景网格，约 18x15。网格上散布着多个单色小精灵体（4-连通，各自包围框为 3x3），使用灰(5)绘制。精灵体总数约 8-12 个，属于 3 种不同的形状类型（按 3x3 包围框内的像素掩码区分，各类型像素数在 3-6 之间，形状为不规则连通图形）。每种类型出现次数互不相同（如 2 次、3 次、5 次）。部分精灵体之间存在空间重叠（包围框有交集）。生成约束：三种形状类型的出现次数严格不同；至少有 2 对精灵体的包围框有重叠。

**规则**：
1. 识别每个灰(5) 4-连通精灵体，裁剪到 3x3 包围框得到掩码。
2. 按掩码形状将精灵体分为若干类型组。统计每种类型的出现次数。
3. 按出现次数降序排名：排名 1（最多）、排名 2、排名 3。
4. 按排名分配颜色：排名 1 → 红(2)，排名 2 → 蓝(1)，排名 3 → 绿(3)。
5. 按排名分配遮挡层级：排名 1 为最前层（最后绘制），排名 3 为最后层（最先绘制）。
6. 构建输出：创建与输入等大的黑(0)画布。按层级从后到前依次绘制：先绘制排名 3 的所有精灵体（绿(3)），再绘制排名 2（蓝(1)），最后绘制排名 1（红(2)）。每个精灵体在其原始位置以新颜色绘制。后绘制的覆盖先绘制的。

**关键洞察**：颜色和遮挡优先级由同一个变量（频率排名）同时决定，但它们的效果在不同维度显现——颜色在非重叠区可见，遮挡在重叠区可见。求解者必须同时理解这两个映射才能产生正确输出。仅看非重叠区可推断颜色映射但无法确认遮挡规则；仅看重叠区可推断遮挡但难以确认颜色来源。须综合多例中的重叠与非重叠区域。

## 新题 9：周期推断驱动平铺与相位重涂

**组合逻辑**：[平铺/tile + 平移周期/translate_period](创新：推断的周期 P 同时用于平铺和重涂) + [重涂色/recolor](创新：颜色由列相位 mod P 的奇偶决定) + [补全至指定跨度/complete_to_span](已有) → 单参数双用途

**来源原语**：平铺/tile、重涂色/recolor、平移周期/translate_period、补全至指定跨度/complete_to_span、重复精灵体/repeated_sprite（参考题 017c7c7b）；按颜色条件分支/color_conditional_branch（参考题 2072aba6）；奇偶距离决定填色/parity_distance_fill（参考题 d22278a0）

**依赖链**：从部分重复推断周期 P → P 决定平铺截止位置（补全至跨度 12）→ P 同时决定每个像素的相位（列索引 mod P）→ 相位奇偶决定重涂颜色。P 是连接平铺和重涂的唯一桥梁：错误的 P 同时导致错误的平铺范围和错误的着色。

推断水平重复精灵体的平移周期，补全至 12 列宽，并按列相位的奇偶性分别重涂为两种颜色。

**输入结构**：黑(0)背景网格，高约 5-7 行，宽约 6-9 列（宽度 < 12）。网格上有蓝(1)前景像素构成的图案，该图案由一个基础切片沿水平方向平移重复得到（至少可见 1.5 个完整周期）。平移周期 P 约 3-4 列。基础切片内的蓝(1)像素形成一个小的不规则连通图形。生成约束：P 可从可见的重复中唯一确定（至少有两个完整周期的列可供比对）；12 能被 P 整除或留有不完整周期时按最后一个完整周期截断（即输出宽度 = 12 列，最右侧允许不完整周期的部分列）。

**规则**：
1. 分析蓝(1)像素在水平方向的重复模式，推断最小正平移周期 P（使得将图案向右平移 P 列后与自身重合的最小正整数 P）。
2. 提取宽度为 P 的基础切片（输入最左侧 P 列）。
3. 将基础切片沿水平方向重复平铺，直到总宽度达到 12 列。若 12 不是 P 的整数倍，最后一个周期只保留前 (12 mod P) 列。保持高度不变。
4. 在完成平铺的 12 列宽网格中，对每个非黑像素计算其列索引 c（从 0 开始）的相位值：phase = c mod P。
5. 若 phase 为偶数（0, 2, 4, ...），将该像素重涂为红(2)。
6. 若 phase 为奇数（1, 3, 5, ...），将该像素重涂为绿(3)。
7. 黑(0)像素保持不变。

**关键洞察**：周期 P 承担双重角色——它既是空间补全的终止条件（何时停止平铺），又是颜色分配的数学参数（mod P 决定相位）。P=3 和 P=4 的输入不仅平铺范围不同，着色图案也完全不同。求解者必须正确推断 P 才能同时得到正确的空间结构和颜色结构。须对比多例（不同 P 值）才能归纳出相位着色规则。

## 新题 10：邻域计数条件化的棋盘放大

**组合逻辑**：[像素放大/pixel_upscaling + 棋盘格图案/checkerboard_pattern](创新：棋盘朝向由邻域属性决定而非固定) + [计数/counting](创新：4-连通邻域计数作为条件判据) + [按颜色条件分支/color_conditional_branch](创新：分支由空间上下文而非像素自身颜色触发) → 局部上下文 → 条件化局部变换

**来源原语**：像素放大/pixel_upscaling、棋盘格图案/checkerboard_pattern、按颜色条件分支/color_conditional_branch、像素/pixel（参考题 2072aba6）；计数/counting（参考题 9af7a82c、39a8645d）

**依赖链**：每个前景像素的 2x2 放大块图案取决于该像素的 4-连通前景邻居数量的奇偶性。必须先在原始分辨率下完成邻域分析，才能确定放大后的局部图案。放大不改变邻域关系（邻域在源网格中计算），但邻域分析的结果嵌入到了放大后的图案中。

将每个前景像素放大为 2x2 棋盘块，棋盘的起始角颜色由该像素在原始网格中的前景邻居数量奇偶性决定。

**输入结构**：黑(0)背景网格，约 5x6。网格上有灰(5)前景像素构成的一个连通或近连通的图形（约 8-15 个前景像素），形状为不规则的单连通图形（无孔洞），像素间通过 4-连通关系相连。图形内部像素（4 个方向都有前景邻居）和边缘像素（1-3 个前景邻居）混合存在。生成约束：保证图形中同时存在邻居数为偶数和邻居数为奇数的前景像素。

**规则**：
1. 创建输出网格：高度 = 输入高度 x 2，宽度 = 输入宽度 x 2。
2. 对输入中每个黑(0)像素，对应的 2x2 输出块全部填黑(0)。
3. 对输入中每个灰(5)前景像素，计算其在输入网格中的 4-连通前景邻居数 N（上、下、左、右四个方向中为灰(5)的数量，0 <= N <= 4）。
4. 若 N 为偶数（0, 2, 4）：对应的 2x2 输出块填充为 [[蓝(1), 红(2)], [红(2), 蓝(1)]]（左上角蓝）。
5. 若 N 为奇数（1, 3）：对应的 2x2 输出块填充为 [[红(2), 蓝(1)], [蓝(1), 红(2)]]（左上角红）。

**关键洞察**：视觉上看，放大后的图案像是一个大棋盘，但仔细观察会发现棋盘在某些 2x2 块处"翻转"了。翻转位置不随机——它精确对应原始网格中邻居数奇偶性发生变化的边界。求解者不能用全局棋盘规则解释输出，必须回到原始分辨率分析每个像素的局部连通性。须对比多例（不同形状 → 不同邻域模式）才能排除"按位置奇偶"等替代假设。
