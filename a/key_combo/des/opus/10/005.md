## 新题 1：反射创建邻接以触发颜色传递

**组合逻辑**：[旋转/点对称](已有) + [邻接传色](已有，但触发条件由反射创造) → [擦除](已有) + [重涂色](已有)

**来源原语**：旋转(rotate)、枢轴像素(pivot_pixel)、点对称(point_symmetry)、绕枢轴半周旋转(half_turn_around_pivot) ← 90347967；重涂色(recolor)、擦除(erase)、标记像素(marker_pixel)、中性遮罩(neutral_mask)、邻接传色(adjacency_transfer)、标记接触即赋色(marker_touch_color) ← b7256dcd

**依赖链**：原始输入中没有任何标记像素与中性遮罩组件 4-邻接——反射通过枢轴创建新的空间邻接关系——邻接传色规则在反射后的布局上生效——传色结果决定最终输出。反射改变了传色的触发条件，传色改变了反射结果的颜色分布，两者交织为一个不可拆分的推理链。

在黑色背景上，将所有前景像素绕灰色枢轴做 180 度点对称反射以创建新邻接，然后利用新邻接关系将标记颜色传递给中性遮罩组件。

**输入结构**：黑(0)背景，约 15x15 网格。包含一个灰(5)枢轴像素。散布着 3~5 个橙(7)色 4-连通组件（每个 3~8 像素，形状各异——可以是不规则斑块、弯曲条带等），作为中性遮罩。另有 2~3 个孤立单像素标记，颜色各不相同（从蓝(1)、红(2)、绿(3)中取），每个标记与所有橙色组件之间至少间隔 2 格（即不存在 4-邻接关系）。生成约束：经过 180 度反射后，至少每个标记的反射像或每个橙色组件的反射像会与某个对方元素产生 4-邻接。所有前景像素（含反射后位置）不超出网格边界。枢轴不与任何其他前景像素重合。

**规则**：
1. 对每个非枢轴、非背景像素 (r, c)，在 (2*pivot_r - r, 2*pivot_c - c) 处放置相同颜色的副本；原始像素保留不动。如果目标位置已有非背景像素，反射像覆盖原有像素。
2. 反射完成后，对每个橙(7)色 4-连通组件（包括原始组件和反射产生的新组件），检查其 4-邻接位置是否有标记像素（包括原始标记和反射产生的标记副本）。
3. 若某橙色组件恰好与一种标记颜色 4-邻接，将该组件整体重涂为该标记颜色。
4. 若某橙色组件与零种或多于一种标记颜色 4-邻接，保持橙(7)不变。
5. 最后擦除所有标记像素（原始和反射副本均设为背景色）。枢轴像素保持灰(5)。

**关键洞察**：原始输入中没有任何标记触碰任何橙色组件——所有颜色传递都是由 180 度反射创造的新邻接关系触发的。求解者必须先在脑中完成点对称反射，才能判断哪些组件会获得哪种颜色。

## 新题 2：长度排名决定对角链重叠优先级

**组合逻辑**：[堆叠/对角链排列](已有) + [长度排名](已有，但决定的不是颜色而是图层优先级) → [冲突优先级](创新：由条状物长度而非放置顺序决定)

**来源原语**：堆叠(stacking)、平移对齐(translate_and_align)、实心矩形(solid_rectangle)、对角链排列(diagonal_chain_layout)、角点重叠(corner_overlap)、按左边缘排序(ordered_by_left_edge)、冲突优先级(conflict_priority) ← 03560426；排序(sorting)、细条(thin_bar)、长度排名(length_ranking)、排名决定颜色(rank_determines_color) ← ea32f347

**依赖链**：矩形按左边缘排序后堆叠成对角链，产生角点重叠区域；每个矩形内部的灰色条长度产生全局排名；排名决定重叠处哪个矩形的颜色胜出。排名与堆叠是正交维度上的操作，在重叠点处交汇为冲突解决规则。

将底部排列的彩色矩形打包为对角链，在角点重叠处用矩形内嵌灰色条的长度排名决定哪个颜色胜出。

**输入结构**：黑(0)背景，约 18x22 网格。底部一行上排列着 4~6 个实心单色矩形（颜色各异，从蓝(1)、红(2)、绿(3)、黄(4)、品红(6)、橙(7)中取），每个矩形底边紧贴网格最后一行，各矩形的左边缘位置互不相同。每个矩形内部嵌有一条灰(5)色水平直线段（1 像素厚），各矩形内灰条长度互不相同。矩形宽度范围 2~5，高度范围 2~5。生成约束：灰条不触碰矩形边界（至少与左右边缘各留 0 像素间距即可——灰条可与矩形同宽，但不超出矩形），灰条长度互不相同。

**规则**：
1. 按左边缘从左到右排列矩形。将第一个矩形放置在网格左上角。
2. 每放完一个宽 w、高 h 的矩形后，下一个矩形的左上角放在 (上一个矩形的顶行 + h - 1, 上一个矩形的左列 + w - 1)，即角点恰好重叠一个像素。
3. 在角点重叠位置，比较两个矩形内部灰条的长度：灰条更长的矩形颜色胜出，占据该像素。
4. 从输出中移除所有灰(5)条像素——将灰条位置恢复为其所在矩形的颜色。
5. 如果对角链超出网格范围，超出部分裁剪。

**关键洞察**：源题 03560426 中后放置的矩形总是覆盖先放的；本题中优先级由内嵌灰条的长度排名决定，而非放置顺序。一个早放的矩形如果灰条更长，反而能在重叠点胜出。求解者必须测量所有灰条长度后才能判断每个重叠点的颜色。

## 新题 3：对称补全改变邻接侧从而重定向周期平铺

**组合逻辑**：[对称补全](已有) → [邻接侧决定方向](已有，但作用于补全后的形状) → [周期平铺](已有)

**来源原语**：对称补全(symmetric_completion)、镜像(mirror)、对称轴(symmetry_axis)、控制标记(control_marker)、控制标记指示源侧(control_marker_indicates_source)、轴对称反射(axial_mirror_reflection) ← 5b692c0f；周期平铺(periodic_tiling)、射线延伸(ray_extension)、标记块(marker_tile)、邻接侧决定方向(adjacency_side_determines_dir)、不覆盖源对象(preserve_source_object) ← 53fb4810

**依赖链**：对称补全改变了中心图案的几何轮廓 → 轮廓变化改变了标记块相对于图案的邻接侧 → 邻接侧决定了标记块周期平铺的方向。补全前后，同一标记块可能从"在图案左侧"变为"在图案下方"，导致平铺方向从水平变为垂直。

先镜像补全一个带黄色轴线的不完整图案，然后根据补全后图案的轮廓确定各标记块的邻接方向，向外周期平铺至网格边界。

**输入结构**：黑(0)背景，约 18x18 网格。网格中心区域有一个由非黄色前景色（如蓝(1)）构成的不完整图案（5~10 像素，4-连通，非对称）。一条黄(4)色直线（水平或垂直，3~7 像素长）穿过或紧邻该图案，作为对称轴。在轴的一侧有一个离轴黄(4)像素标记源侧。在图案周围（与图案或轴 4-邻接）有 2~4 个小标记块（每块 1~2 像素，颜色从红(2)、绿(3)、橙(7)中取，各标记块颜色可相同或不同）。生成约束：补全后的完整图案是关于黄色轴线对称的；标记块在补全前后的邻接侧发生变化（至少一个标记块原本邻接图案的某一侧，补全后因图案扩展而变为邻接另一侧）。标记块不与轴线重叠。

**规则**：
1. 识别黄(4)轴线和离轴黄(4)像素。离轴像素所在的那一侧为源侧。
2. 将源侧的蓝(1)色图案像素沿黄色轴线镜像到对侧，得到关于轴线对称的完整图案。黄色轴线和源侧像素保持不变。
3. 对每个标记块，判断它 4-邻接于补全后完整图案（含轴线）的哪一侧（上、下、左、右）。判断依据：标记块中心相对于它所邻接的图案像素的方向。如果标记块同时邻接多侧，取标记块几何中心到图案整体几何中心的连线方向（取四个基本方向中最接近的）。
4. 将每个标记块沿其邻接侧的反方向（即远离图案的方向）周期重复平铺，直到网格边界。每次平铺复制整个标记块图案，间距为标记块在平铺方向上的尺寸（无间隙紧密排列）。
5. 完整图案、黄色轴线及离轴标记的像素不被平铺覆盖。

**关键洞察**：补全操作改变了图案的几何轮廓，直接影响了标记块的邻接侧判定。一个标记块在补全前可能紧挨图案的右侧（向右平铺），但补全后图案向右扩展并超过该标记块，使其变为邻接图案的下侧（向下平铺）。求解者必须先完成镜像补全，再判断邻接方向。

## 新题 4：计数选区域后多米诺方向重定向填充目标

**组合逻辑**：[计数 + 筛选](已有) → [四邻接配对/方向](已有，但用于重定向填充目标而非擦除) → [洪泛填充](已有，但填充位置由多米诺方向决定)

**来源原语**：计数(counting)、洪泛填充(flood_fill)、筛选(filtering)、分区区域(partitioned_region)、分隔线(separator_line)、最密区域保留填充(densest_region_kept_filled) ← 29623171；双色多米诺(bicolor_domino)、四邻接配对(four_neighbor_pairing)、方向(direction)、擦除(erase) ← d90796e8

**依赖链**：计数确定哪些区域胜出 → 胜出区域中的多米诺方向决定填充发生在哪个相邻区域 → 填充目标区域获得颜色，胜出区域本身可能反而留空。计数是选择机制，多米诺是重定向机制，两者共同决定最终哪些区域被填充。

在分隔线划分的网格中，先按散布像素密度筛选区域，再由胜出区域中的红绿多米诺方向决定将填充色投射到哪个相邻区域。

**输入结构**：黑(0)背景，约 15x15 网格。灰(5)色完整行和完整列将网格分为若干矩形区域（3x3 至 5x5 大小的区域，约 6~9 个区域）。每个区域内部散布着少量同色像素（非黑、非灰，每个区域只有一种散布色，从蓝(1)、红(2)、绿(3)、黄(4)、橙(7)中取——注意红和绿也可以作为散布色存在），数量 1~5 个。部分区域（至少 2 个）还各包含恰好一个由红(2)和绿(3)构成的 4-连通双像素多米诺（多米诺的红绿像素不计入散布像素计数）。生成约束：存在唯一最大散布计数值（无并列），且拥有该最大计数的区域中至少有一个包含多米诺。至少有一个拥有最大计数的区域不包含多米诺（以展示两种不同处理方式）。多米诺的红绿排列提供四个方向之一（红在上绿在下→向下，红在左绿在右→向右，以此类推：方向定义为从红(2)指向绿(3)的方向）。

**规则**：
1. 识别灰(5)色分隔线，提取所有被分隔的矩形区域。
2. 对每个区域，计数其中散布的非黑、非灰、非多米诺像素数量。
3. 找到全局最大计数值。保留计数等于该最大值的区域，其余区域内容清空为黑(0)。
4. 对于保留的最大计数区域：
   - 若该区域不含多米诺：用其散布色填满该区域（覆盖所有黑色像素，灰色分隔线不变）。
   - 若该区域含多米诺：不填充该区域自身；改为填充该多米诺方向上相邻的那个区域（从红到绿的方向越过一条灰色分隔线后到达的区域），使用该区域的散布色进行填充。多米诺像素擦除为黑(0)。
5. 被多米诺重定向填充的目标区域即使原本计数不是最大值也会被填充。
6. 灰(5)色分隔线始终保持不变。

**关键洞察**：最密区域"赢得"了填充权，但如果它含有多米诺，这个权利会被多米诺的方向重定向到相邻区域——胜出者反而把奖励给了邻居。求解者必须同时完成计数比较和多米诺方向解读，才能确定最终哪些区域被填充。

## 新题 5：角落模板经点对称重定位

**组合逻辑**：[角落标记 → 固定模板](已有) → [绕枢轴半周旋转](已有，但作用对象从前景掩码变为生成的模板) → [擦除](已有)

**来源原语**：印章覆盖(stamp_overlay)、擦除(erase)、角落标记(corner_marker)、固定模板(fixed_template)、角落位置选模板(corner_selects)、标记色传递给模板(marker_color_pass) ← fd02da9e；旋转(rotate)、枢轴像素(pivot_pixel)、点对称(point_symmetry)、绕枢轴半周旋转(half_turn_around_pivot) ← 90347967

**依赖链**：角落位置选择模板形状和朝向 → 生成的模板作为整体被点对称反射到新位置 → 最终模板的位置和朝向同时由角落选择和枢轴位置决定。两步缺一不可：不知道角落就无法生成正确模板，不知道枢轴就无法确定模板最终位置。

识别网格角落的彩色标记像素，生成角落特定的内向模板图案，再将所有模板绕灰色枢轴做 180 度点对称反射至新位置。

**输入结构**：黑(0)背景，8x8 网格。网格的四个角落中有 2~3 个角落各有一个单像素标记（颜色互不相同，从蓝(1)、红(2)、绿(3)、黄(4)中取）。网格内部（非边缘行列）有一个灰(5)枢轴像素。生成约束：每个角落模板经过 180 度反射后仍落在网格内部；不同角落模板的反射像互不重叠；枢轴不在网格正中心（否则反射等于原位，失去推理价值）。

**规则**：
1. 识别角落标记像素及其所在角落（左上、右上、左下、右下）。
2. 根据角落位置生成内向模板（使用标记颜色）：
   - 左上角标记 → 在 (1,1) 处起始的 2x2 方块（即行1~2、列1~2，0-indexed）。
   - 右上角标记 → 在 (1, W-3) 处起始的 2x2 方块（即行1~2、列W-3~W-2）。
   - 左下角标记 → 三像素内弯模板：(H-2, 0)、(H-2, 1)、(H-3, 0)。
   - 右下角标记 → 三像素内弯模板：(H-2, W-1)、(H-2, W-2)、(H-3, W-1)。
   （H=行数, W=列数, 坐标 0-indexed）
3. 擦除所有角落标记像素（设为背景色）。
4. 将步骤 2 生成的所有模板像素作为整体，绕灰(5)枢轴做 180 度点对称反射：对每个模板像素 (r, c)，将其颜色放置到 (2*pivot_r - r, 2*pivot_c - c)。原始模板位置设为背景色。
5. 枢轴像素保持灰(5)。若反射像素落在枢轴位置，枢轴颜色不变。若反射像素超出网格边界，舍弃该像素。

**关键洞察**：必须先由角落位置生成正确的模板形状（不同角落产生不同形状和朝向），再将生成的模板做点对称反射。求解者无法跳过任何一步：不生成模板就没有反射对象，不做反射就无法解释输出中模板的最终位置。

## 新题 6：图例展开后按布局轴方向紧密拼接

**组合逻辑**：[展开/图例锚定对齐](已有) → [布局轴方向](已有，但应用于展开结果的空间分布) → [裁剪 + 拼接](已有，但拼接的是展开后的图例实例)

**来源原语**：展开(expand)、边缘图例串(edge_legend_string)、孤立标记(isolated_marker)、颜色位置匹配(color_position_matching)、图例锚定对齐(legend_anchored_alignment) ← 5af49b42；裁剪(crop)、拼接(concatenate)、连通精灵(connected_sprite)、布局轴方向(layout_axis_direction)、按位置紧密排列(tight_packing_by_position) ← 67636eac

**依赖链**：每个孤立标记独立展开为一个图例副本 → 展开后各副本的空间位置继承标记的分布特征 → 标记的分布方向决定沿哪个轴拼接 → 最终输出是所有展开副本沿布局轴紧密拼接的结果。展开决定了每个片段的内容，布局轴决定了拼接方向，两者分别控制"是什么"和"怎么排"。

将每个孤立标记展开为其对应的边缘图例副本，然后按标记群的空间分布方向将所有副本紧密拼接。

**输入结构**：黑(0)背景，约 12x18 网格。网格顶边或底边有 1~2 条水平图例串（每条 3~6 像素，由不同颜色组成的连续水平序列，如蓝(1)-红(2)-绿(3)-黄(4)）。网格内部散布 3~5 个孤立单像素标记，每个标记的颜色恰好出现在某条图例串中的某个位置。标记的中心分布要么在水平方向跨度更大，要么在垂直方向跨度更大（明确的主布局轴）。生成约束：每个标记颜色在所有图例串中仅出现一次。各标记展开后的图例副本的边界框高度相同（均为 1 行），宽度等于所属图例串长度。

**规则**：
1. 对每个孤立标记像素，找到包含该颜色的唯一图例串。
2. 将该图例串复制到标记所在行，水平移位使图例串中与标记同色的位置恰好落在标记的列上。超出网格左右边界的部分裁剪掉。
3. 对每个展开后的图例副本，裁剪到其边界框（去除黑色边距）。
4. 计算所有标记像素的位置分布：若标记中心的列跨度（最大列 - 最小列）大于行跨度（最大行 - 最小行），布局轴为水平；否则为垂直。
5. 若水平布局：按标记列坐标从左到右排序，将裁剪后的图例副本水平拼接（无间隙）。若垂直布局：按标记行坐标从上到下排序，将裁剪后的图例副本垂直拼接（无间隙）。
6. 输出即为拼接后的紧凑网格。

**关键洞察**：每个标记不仅选择了要展开的图例串和锚定位置（源自 5af49b42 的逻辑），标记群的空间分布还决定了最终拼接的轴向（源自 67636eac 的逻辑）。单看某个标记的展开过程无法推断输出形状——必须同时考虑所有标记的相对位置才能确定拼接方向。

## 新题 7：去噪标记缺陷后镜像补全

**组合逻辑**：[去噪 + 缺陷标记](已有) → [对称补全/镜像](已有，但作用在去噪和标记后的结果上)——顺序约束型耦合

**来源原语**：去噪(denoise)、缺陷标记(defect_mark)、前景区域(foreground_region)、凹痕(dent)、邻域多数色(neighborhood_majority_color)、反色填充(opposite_color_fill)、忽略干扰项(ignore_distractors) ← de809cff；对称补全(symmetric_completion)、镜像(mirror)、对称轴(symmetry_axis)、控制标记(control_marker)、控制标记指示源侧(control_marker_indicates_source)、轴对称反射(axial_mirror_reflection) ← 5b692c0f

**依赖链**：去噪必须先于镜像（否则噪声被镜像放大）→ 缺陷标记在去噪后产生青色中心和反色补丁 → 镜像补全将清理+标记后的图案作为源侧复制到另一侧。三步的顺序不可颠倒：去噪影响缺陷检测的结果，缺陷标记影响镜像的内容。

先对含噪声和黑色凹痕的双色前景区域进行去噪和缺陷标记，再沿黄色轴线将清理后的一侧镜像补全到另一侧。

**输入结构**：黑(0)背景，约 15x15 网格。包含两种前景颜色的大区域（如蓝(1)和红(2)，各占约 15~25 像素），区域内有小的黑(0)色凹痕（1~2 像素的黑色空洞被前景色包围）和边界噪声（孤立单像素色斑、单像素突起）。一条黄(4)色直线段（水平或垂直，长度覆盖前景区域跨度）穿过或紧邻前景区域，作为对称轴。在轴的一侧有一个离轴黄(4)单像素标记。生成约束：前景区域集中在轴的源侧（含离轴标记的一侧）；轴的另一侧可能有少量残留前景像素（表示"不完整"的另一半），也可能为空。凹痕仅出现在源侧的前景区域内。

**规则**：
1. 去噪——在源侧前景区域中：
   - 将被某种前景色 8-邻域包围的孤立异色单像素（含孤立黑点和异色色斑）重涂为周围多数前景色。
   - 将边界处伸入另一前景区域的单像素突起重涂为其所在位置 3x3 邻域中的多数色。
2. 缺陷标记——对源侧中每个原始黑(0)凹痕位置（去噪前即为黑色且被前景色包围的像素）：
   - 确定其 3x3 邻域中的多数前景色。
   - 将以该凹痕为中心的 3x3 区域填充为另一种前景色（即非多数色的那种前景色）。
   - 将凹痕中心像素重涂为青(8)。
   - 3x3 区域超出网格的部分忽略；3x3 区域可以覆盖已有前景像素。
3. 镜像补全——将轴的源侧（含离轴黄标记的那侧）的所有内容（包括去噪和缺陷标记的结果）沿黄(4)轴线镜像到对侧，覆盖对侧原有内容。
4. 黄色轴线和离轴标记像素保持不变。

**关键洞察**：去噪和缺陷标记必须发生在镜像之前。如果先镜像再去噪，噪声会被对称复制导致无法正确清除；如果跳过缺陷标记直接镜像，输出中不会出现青色中心和反色补丁。求解者需通过对比多个示例确认这三步的执行顺序。

## 新题 8：反射创建障碍截断射线延伸

**组合逻辑**：[点对称反射](已有) → [射线延伸](已有，但终止条件由反射产生的障碍决定)——反射改变了射线的终止条件

**来源原语**：射线延伸(ray_extend)、画布生成(canvas_generation)、中心标记像素(center_marker) ← c1990cce；旋转(rotate)、前景掩码(foreground_mask)、枢轴像素(pivot_pixel)、点对称(point_symmetry)、绕枢轴半周旋转(half_turn_around_pivot) ← 90347967

**依赖链**：反射产生新的障碍像素 → 障碍像素截断从标记发出的射线 → 射线长度由原始和反射障碍的共同分布决定。不做反射，射线会更长或不受阻挡；不做射线延伸，反射本身不产生最终的线形输出。

将蓝色障碍像素绕灰色枢轴做 180 度反射以加倍障碍集，然后从红色标记向四个基本方向发射射线，射线遇到障碍或网格边界即停止。

**输入结构**：黑(0)背景，约 13x13 网格。包含一个灰(5)枢轴像素、一个红(2)标记像素、以及 3~6 个蓝(1)障碍像素（各自孤立，不相邻）。障碍像素分布在网格的一侧（如大部分在枢轴的左上方）。生成约束：红(2)标记不在枢轴位置；所有蓝色像素经 180 度反射后仍在网格内且不与原始蓝色像素、红色标记或枢轴重叠；反射后至少有一个反射蓝色像素落在红色标记的某个基本方向射线路径上（即反射确实改变了至少一条射线的长度）。

**规则**：
1. 对每个蓝(1)障碍像素 (r, c)，在 (2*pivot_r - r, 2*pivot_c - c) 处放置一个蓝(1)副本。原始蓝色像素保留。
2. 从红(2)标记像素的位置出发，沿上、下、左、右四个方向各发射一条射线。
3. 每条射线逐像素延伸（使用红(2)色），直到遇到蓝(1)色障碍（原始或反射产生的）或网格边界时停止。终止位置的蓝色障碍保留蓝色（射线不包含障碍所在像素）。射线包含起点像素（即红色标记本身）。
4. 枢轴像素保持灰(5)。若射线经过枢轴位置，枢轴被红色射线覆盖。

**关键洞察**：原始输入中障碍可能只集中在一侧，使得某些方向的射线本应延伸到边界。但反射在对称的另一侧创建了新障碍，截断了原本畅通的射线。求解者必须先完成反射以确定完整的障碍分布，才能正确计算每条射线的长度。

## 新题 9：条长度排名编码区域内滑动参数

**组合逻辑**：[长度排名](已有) → [滑动](已有，但方向和距离由排名和条朝向联合编码) + [分区区域](已有，作为滑动的局部范围)——排名是全局操作，滑动是局部操作，两者通过条的属性桥接

**来源原语**：滑动(sliding)、前景对象(foreground_object)、方向(direction)、固定步长平移(fixed_step_translate) ← 25ff71a9；排序(sorting)、细条(thin_bar)、长度排名(length_ranking) ← ea32f347；分区区域(partitioned_region)、分隔线(separator_line) ← 29623171

**依赖链**：条的长度排名（全局）决定对应区域内对象的滑动距离 → 条的朝向决定滑动方向 → 各区域独立执行滑动但参数由全局排名决定。改变任何一根条的长度可能影响所有区域的排名和滑动距离——全局-局部耦合。

在分隔线划分的网格中，每个区域含一个小图形和一根灰色细条；条的长度全局排名决定该图形的滑动距离，条的朝向决定滑动方向，图形在区域内循环滑动。

**输入结构**：黑(0)背景，约 16x16 网格。灰(5)色完整行和完整列将网格分为 4~6 个矩形区域（每个至少 4x4）。每个区域内有：一个小的单色 4-连通前景图形（3~6 像素，颜色各异，从蓝(1)、红(2)、绿(3)、黄(4)、橙(7)中取）和一根灰(5)色直线段（水平或垂直，1 像素厚）。不同区域中灰条长度互不相同。灰条不与图形重叠，不触碰灰色分隔线。生成约束：灰条长度为 1 到区域数之间的不同整数（确保排名唯一）。

**规则**：
1. 对所有区域中的灰(5)条按长度从长到短排名：最长为排名 1，次长为排名 2，以此类推。
2. 对每个区域：
   - 滑动距离 = 该区域灰条的排名值（即排名 1 的滑动 1 像素，排名 2 的滑动 2 像素）。
   - 滑动方向：若灰条为水平，图形向下滑动；若灰条为垂直，图形向右滑动。
3. 在各区域内独立执行滑动：将图形整体沿指定方向平移指定距离。若图形的任何像素超出区域边界（灰色分隔线为边界），则从对面边界循环进入（周期性边界条件）。
4. 从输出中移除所有灰(5)条像素（将其设为黑(0)），但灰(5)色分隔线保持不变。

**关键洞察**：最长的条获得最小的滑动距离（排名 1 → 滑 1 格），最短的条获得最大的滑动距离。这与直觉相反——不是"越长滑越远"。此外，滑动方向由条的朝向编码（水平条→纵向滑，垂直条→横向滑），方向编码也是间接的。求解者必须对比多个示例来发现这个反直觉的排名-距离映射。

## 新题 10：面板旋转后透明叠加

**组合逻辑**：[方向编码 → 旋转](创新：标记位置编码旋转角度) → [透明叠加 + 象限层序](已有)——旋转在叠加之前改变每个面板的内容，使叠加结果不可预测

**来源原语**：透明叠加(transparent_overlay)、裁剪(crop)、面板(panel)、十字分隔线(cross_separator)、图层优先级(layer_priority)、象限位决定层序(quadrant_layer_order) ← e99362f0；方向编码(direction_encoding)、着色标记(colored_marker)、色块决定输出位置(color_direction_determines_placement) ← a8c38be5；旋转(rotate) ← 36d67576

**依赖链**：每个面板中的标记位置编码旋转角度 → 旋转改变面板中图案的朝向 → 旋转后的面板按固定象限层序透明叠加 → 叠加结果由旋转角度和层序共同决定。旋转影响叠加内容，层序影响冲突解决，两者正交耦合。

将十字线分隔的四个面板各自按内部标记编码的角度旋转后，按固定象限层序透明叠加为一个面板。

**输入结构**：黑(0)背景，约 16x16 网格（行列均为偶数+1，使十字线居中）。一条灰(5)色完整行和一条灰(5)色完整列构成十字，将网格分为四个大小相等的矩形面板。每个面板中有一组前景图案（由一种非灰非黑颜色构成，3~8 像素，4-连通，面板间图案颜色各不相同，从蓝(1)、红(2)、绿(3)、黄(4)中取）。每个面板中还有一个品红(6)色单像素标记，位于面板四条边之一的中点附近（距边 0~1 像素）。生成约束：四个面板大小相同（均为 (H-1)/2 x (W-1)/2）。标记位于面板边缘区域的上中、右中、下中或左中位置（一个面板的四种选择之一）。旋转后各面板前景像素不全重叠（确保叠加后能区分图层效果）。

**规则**：
1. 移除灰(5)十字分隔线。
2. 读取每个面板中品红(6)标记的位置，确定旋转角度：
   - 标记在面板上边中部 → 不旋转（0 度）。
   - 标记在面板右边中部 → 顺时针旋转 90 度。
   - 标记在面板下边中部 → 旋转 180 度。
   - 标记在面板左边中部 → 顺时针旋转 270 度。
3. 擦除品红(6)标记像素（设为黑色），然后将每个面板的前景图案按确定的角度绕面板中心旋转。
4. 将四个旋转后的面板对齐到同一画布（大小等于单个面板），按以下层序从底到顶叠加：左下面板（最底层）→ 右上面板 → 左上面板 → 右下面板（最顶层）。
5. 叠加规则：非背景（非黑色）像素覆盖下层。同一位置有多个非背景像素时，层序更高的面板胜出。
6. 输出为叠加后的单面板大小网格。

**关键洞察**：叠加的层序是固定的（由象限位置决定），但每个面板的实际图案朝向由其内部标记编码的旋转决定。两个面板可能有相同的原始图案但不同的旋转角度，导致叠加结果完全不同。求解者必须先分别解码每个面板的旋转，再在脑中执行四层叠加。
