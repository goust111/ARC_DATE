## 新题 1：同色族群数驱动膨胀与优先级冲突

**组合逻辑**：[计数(count)](对连通分量按颜色分组统计) → [膨胀(dilate)](统计结果控制膨胀半径) → [重涂色(recolor)](重叠区域按优先级冲突解决)

**来源原语**：计数(count) ← aaecdb9a; 膨胀(dilate)/扩展填充(expansion_fill) ← 52fd389e; 连通分量(connected_component) ← e0fb7511; 面积大于一则涂(recolor_if_area_gt_one) ← e0fb7511; 计数决定扩展量(count_determines_expansion) ← 52fd389e

**依赖链**：全局统计（每种颜色的连通分量个数）决定局部几何变换（每个分量的膨胀半径），膨胀后不同颜色的扩展区域在空间上发生重叠，重叠冲突的解决又依赖于同一个统计量（分量数更少的颜色优先级更高）。统计→变换→冲突解决三者共享同一个数值来源，形成环形约束。

根据每种前景色的连通分量个数膨胀各分量，重叠处保留分量数更少的颜色。

**输入结构**：黑(0)背景的网格（约 15x15 至 20x20）。前景包含 3~4 种颜色的小型 4-连通单色对象（每个对象 2~6 像素，形态不规则，非矩形）。每种颜色出现的连通分量个数互不相同（如红(2)出现 3 个分量、蓝(1)出现 2 个、绿(3)出现 1 个）。各对象间距足够大，使得膨胀后部分区域重叠但不至于完全覆盖。生成约束：同一颜色的分量个数不超过 4；不同颜色分量个数两两不等；任意两个同色分量之间至少间隔 3 格。

**规则**：
1. 对每种前景色，统计其 4-连通分量的个数，记为 K。
2. 将该颜色的每个分量向外膨胀 (K - 1) 个像素——即以每个分量的边界框为基础，四边各外扩 K-1 格，扩展区域填充该颜色。K = 1 的颜色不膨胀，保持原样。
3. 膨胀区域超出网格边界的部分直接舍弃。
4. 当两种或多种颜色的膨胀区域重叠时，保留 K 值更小的颜色（即分量数更少、膨胀半径更小的颜色优先）。
5. 所有原始前景像素保持原色不变（优先级最高，不被任何膨胀覆盖）。

**关键洞察**：膨胀半径等于"同色兄弟数 - 1"而非"同色兄弟数"——单独存在的颜色不膨胀；且冲突解决规则与膨胀半径反相关（膨胀少的反而优先），需要对比多个示例中不同 K 值的情形才能归纳出完整规则。

## 新题 2：引导条选择性恢复周期瓦片并压缩

**组合逻辑**：[补全(complete)](从可见区推断最小瓦片并周期延拓) → [擦除(erase)](引导条间隙列投射过滤) → [压缩(compress)](存活列向远端打包)

**来源原语**：补全(complete)/周期延拓(periodic_extension) ← 50a16a69; 引导条(guide_bar) ← f83cb3f6; 投射到引导条(project_to_guide) ← f83cb3f6; 投射落间隙则擦(erase_if_gap) ← f83cb3f6; 压缩(compress)/压缩至远端边界(pack_to_far_edge) ← 05a7bcf2; 占位符区域(placeholder_region) ← 50a16a69

**依赖链**：周期补全产生完整的瓦片画面，引导条的有/无间隙决定哪些列被保留或擦除（信息选择性丢失），擦除后的残余列被压缩打包到远端（空间重排）。补全的结果供擦除筛选，擦除的结果供压缩重排——删去任一步都无法得到最终输出。

补全被占位符遮盖的周期瓦片，仅保留投射到引导条实体段的列，再将存活列压缩至远端。

**输入结构**：黑(0)背景网格（约 12x18）。上部区域的左侧是一个可辨认的矩形周期瓦片重复区（至少 2 次完整重复，瓦片约 3x3 至 4x4，含 2~3 种前景色如蓝(1)、红(2)、绿(3)），右侧及底部被灰(5)占位符填满。沿网格的某一水平边缘（上边或下边）有一条青(8)引导条，宽度 1 像素，但引导条内存在 1~3 个间隙（该位置为黑(0)背景）。生成约束：引导条总长度等于网格列数；间隙不在引导条端点；瓦片颜色与引导条颜色和占位符颜色均不同。

**规则**：
1. 从左上角的可见重复区推断最小矩形瓦片，将其周期性延拓至整个网格尺寸（忽略占位符和引导条所在行）。
2. 对每一列，检查该列在引导条行中是否有引导条像素（青(8)）。若有，保留该列的全部已补全瓦片像素；若该列落在引导条间隙中，将该列的所有瓦片像素擦除为背景色。
3. 将所有存活列向引导条对侧边缘压缩打包（引导条在底边则向上压缩，在顶边则向下压缩），消除中间的空白列，保持列间相对顺序不变。
4. 输出网格行数等于输入行数减 1（去除引导条行），列数等于存活列数。

**关键洞察**：引导条的间隙模式是一个二进制掩码，决定哪些列的瓦片信息得以存活；压缩方向由引导条的位置（上/下边缘）隐式编码——需对比多个示例（引导条分别在上边和下边的情形）才能发现方向规则。

## 新题 3：十字周期射线被障碍截停并染色障碍

**组合逻辑**：[平铺/周期延拓(tile/periodic_extension)](十字中心行列序列向四方射出) + [障碍截停](障碍段阻断射线) → [重涂色(recolor)](被截停的障碍接触像素吸收射线末端颜色)（射线与障碍双向耦合）

**来源原语**：十字图案(cross_pattern)/周期序列(periodic_sequence)/中心行列种子(center_seed) ← e21d9049; 周期性延伸(periodic_extension) ← e21d9049; 障碍段(barrier_segment) ← fc10701f; 障碍门处标记通道(barrier_gate_mark) ← fc10701f; 重涂色(recolor) ← ba97ae07

**依赖链**：十字图案提供周期色序（射线内容），障碍段的空间位置决定射线截停点（几何约束），截停位置处的周期色序值反过来决定障碍像素的新颜色（颜色注入）。射线内容依赖十字图案，射线长度依赖障碍位置，障碍颜色依赖射线内容——三者形成有向三角耦合。

从十字图案中心沿行列方向射出周期色序射线，射线遇垂直障碍段截停，障碍的接触像素吸收射线到达时的颜色。

**输入结构**：黑(0)背景网格（约 17x17）。中心区域有一个多色十字图案（臂宽 1 像素），十字的水平臂和垂直臂各含 3~5 种颜色的序列（如蓝(1)-红(2)-绿(3)循环，从中心向外排列）。网格中散布 2~4 条栗(9)色短障碍段（每段 2~4 像素长，4-连通，呈一条直线），方向与可能到达的射线方向垂直（即水平射线遇到竖直障碍段，竖直射线遇到水平障碍段）。十字中心与各障碍之间有空背景间距。生成约束：每条射线方向上最多遇到一条障碍段；障碍段不与十字图案相邻（至少间隔 2 格）；至少有一个方向上没有障碍（射线延伸到边缘）。

**规则**：
1. 提取十字图案的中心行色序和中心列色序（从中心向外的颜色排列）。
2. 从十字中心向上、下、左、右四个方向，沿行/列分别以对应色序周期性延伸，逐格填色。
3. 当射线（某行或某列的延伸像素）遇到一条垂直于射线方向的障碍段时，射线在障碍前一格停止（不覆盖障碍本身）。
4. 障碍段中与射线同行或同列的那个接触像素，被重涂为射线在该位置本应填入的周期色序颜色。障碍段的其余像素保持原色栗(9)不变。
5. 若某方向上没有障碍，射线延伸至网格边缘。

**关键洞察**：障碍接触点的最终颜色取决于它与十字中心的距离在周期色序中的位置——同一条障碍如果平移到不同距离，接触点颜色就会改变。需要对比多个示例中障碍距离不同的情形，才能确认颜色来自周期序列映射而非固定颜色映射。

## 新题 4：图例象限着色叠加连通性噪声过滤

**组合逻辑**：[重涂色(recolor)](图例 2x2 颜色键映射象限) + [擦除(erase)](4-连通面积判断过滤孤立噪声)（分支结构：同一像素需同时通过象限归属判定和连通性判定，两个条件独立且缺一不可）

**来源原语**：图例(legend)/数据区象限(data_quadrant) ← 58743b76; 象限对应图例颜色(quadrant_mapped_by_legend) ← 58743b76; 连通分量(connected_component)/孤立像素(isolated_pixel) ← e0fb7511; 连通性(connectivity) ← e0fb7511; 面积大于一则涂(recolor_if_area_gt_one) ← e0fb7511; 分隔线(divider_bar) ← 58743b76

**依赖链**：图例提供象限→颜色映射（颜色决策），连通性分析提供像素是否为噪声的判断（存留决策）。两个决策对同一批像素独立施加约束：非噪声像素获得象限对应颜色，噪声像素被擦除。去掉图例→不知道涂什么颜色；去掉连通性过滤→噪声像素错误保留；两者必须同时工作。

数据区前景像素按所在象限重涂为图例对应颜色，但孤立的单像素噪声点直接擦除。

**输入结构**：灰(5)背景网格（约 14x14）。一条品红(6)粗分隔条（2 像素宽）将网格分为十字形的四个象限。网格的一个角落（如左上 2x2 区域）有一个 2x2 的图例色块，四格分别为蓝(1)、红(2)、绿(3)、黄(4)，对应左上、右上、左下、右下四个象限。四个象限内散布橙(7)前景像素，其中大部分形成 2~5 像素的 4-连通小群（不规则形态），但每个象限中也混有 1~2 个孤立的单橙(7)像素（噪声）。生成约束：分隔条完整横贯/纵贯网格；图例 2x2 块紧贴角落且不与分隔条重叠；各象限至少有一个面积 > 1 的连通分量和一个孤立噪声点。

**规则**：
1. 用分隔条将数据区划分为四个等面积象限（忽略图例所在角落的 2x2 区域，该区域保持不变）。
2. 对每个象限内的橙(7)前景像素，做 4-连通分量分析。
3. 面积 > 1 的连通分量：所有像素重涂为该象限对应的图例颜色（左上象限→图例左上格颜色，依此类推）。
4. 面积 = 1 的孤立像素：擦除为背景色灰(5)。
5. 分隔条、图例、背景保持不变。

**关键洞察**：图例颜色映射和连通性过滤是两条独立的判断通道，像素必须同时通过"属于哪个象限"和"是否为噪声"两重判定——仅看单个示例可能误以为所有橙色像素都被重涂（忽略噪声过滤），需要对比多个示例中孤立像素被擦除的模式才能发现面积阈值规则。

## 新题 5：同心环深度定位标记并生成噪声过滤柱状图

**组合逻辑**：[计数(count)](标记像素按所在环层深度分类统计) + [擦除(erase)](孤立标记点作为干扰项过滤) → [排序(sort)/重涂色(recolor)](按深度序生成底对齐柱状图)（聚合结构：空间深度分析→噪声过滤→信息压缩为一维直方图）

**来源原语**：同心方框层(concentric_layer)/深度排序(depth_order) ← 85c4e7cd; 标记像素(marker_pixel) ← 705a3229; 计数(count)/柱状图(histogram)/基线对齐(baseline_aligned) ← aaecdb9a; 连通分量(connected_component)/孤立像素(isolated_pixel)/连通性(connectivity) ← e0fb7511; 忽略干扰项(ignore_distractors) ← 1478ab18

**依赖链**：同心环结构提供深度坐标系（每个像素归属于某一深度层），连通性分析排除干扰标记（噪声过滤），过滤后的标记按深度层计数（分类聚合），计数结果转化为柱状图（几何输出）。环结构→深度归属→计数→柱状图是四步信息变换，且过滤步骤改变计数结果——删去任一步都导致错误输出。

统计同心环各层内的有效（非孤立）标记像素数，输出按层深度排列的底对齐柱状图。

**输入结构**：黑(0)背景网格（约 15x15）。网格中央有一组 3~5 层同心矩形环，每层颜色不同（从外到内如蓝(1)、红(2)、绿(3)、黄(4)），每层厚 1 像素。环结构内散布橙(7)标记像素，覆盖在环色之上：部分标记像素以 2~3 个像素的 8-连通小簇出现（有效标记），部分为单个孤立像素（干扰项）。标记像素总是位于某一层环的像素位置上（即标记覆盖了环像素）。生成约束：同心环是完整闭合矩形；标记像素覆盖在环像素之上但不破坏环结构的可推断性（每层环至少有 60% 的像素未被标记覆盖）；至少有一层无有效标记（柱状图中该列高度为 0）。

**规则**：
1. 识别同心矩形环结构，按距网格边缘的距离标定每层深度（最外层深度 1，次外层深度 2，依此类推，共 D 层）。
2. 对所有橙(7)标记像素做 8-连通分量分析。面积 = 1 的分量为干扰项，排除不计。
3. 对每个有效标记分量（面积 > 1），判定其所在的环层深度（取该分量覆盖的环层像素中出现最多的深度值）。
4. 统计每层深度上的有效标记分量个数（是分量数，不是像素数）。
5. 输出一个新网格：宽度 = D（环层总数），高度 = 最大分量计数值。第 i 列对应深度 i 的环层，从底部向上填充该层环的颜色，填充高度等于该层的有效标记分量数。其余格为黑(0)背景。列序从左到右为深度 1（最外层）到深度 D（最内层）。

**关键洞察**：柱状图的每一列不是直接数标记像素数，而是数有效标记的连通分量数——需要先过滤孤立干扰点，再按连通分量（而非像素）计数。对比多个示例会发现：增加一个孤立标记像素不改变柱状图，但增加一个 2 像素标记簇会让对应列 +1。

## 新题 6：模板匹配决定矩形内部变换分支

**组合逻辑**：[旋转(rotate)](对模板做旋转尝试匹配) + [模板匹配(template_match)](判定矩形内部是否包含模板变体) → [重涂色(recolor)](匹配成功与失败走不同变换路径)（条件分支结构：匹配结果决定后续操作类型）

**来源原语**：模板(template)/碎片(fragment)/模板匹配(template_match) ← 6aa20dc0; 旋转(rotate)/缩放旋转对齐碎片(scale_rotate_align_frag) ← 6aa20dc0; 实心矩形(filled_rectangle)/内部与边框(interior_vs_border)/仅内部像素变色(only_interior_recolored) ← bb43febb; 重涂色(recolor) ← bb43febb

**依赖链**：模板匹配是决策节点——匹配成功的矩形执行"边框重涂为模板主色 + 内部保留匹配图案"，匹配失败的矩形执行"整体重涂为警示色"。两条路径的触发条件（模板是否匹配）和执行内容（边框涂色 vs 整体涂色）完全不同，缺少模板匹配步骤则无法区分两种矩形。

检测每个灰色矩形内部是否包含模板的旋转变体，匹配成功则边框重涂模板主色、内部保留图案，匹配失败则整体涂红。

**输入结构**：黑(0)背景网格（约 18x18）。网格中有 3~5 个灰(5)实心矩形（每个至少 4x4，高宽不全相同，互不重叠，互不相邻）。网格的一个角落放置一个小型多色模板图案（约 2x3 或 3x3，含 2~3 种非灰非黑颜色，4-连通，非对称以便区分旋转状态）。部分矩形的内部（排除 1 像素宽边框后的区域）包含该模板经 0/90/180/270 度旋转后的嵌入（模板非背景像素替换对应位置的灰色像素，嵌入位置在内部区域中任意合法位置，其余内部仍为灰(5)）；其余矩形内部为纯灰(5)，无嵌入。生成约束：模板嵌入时不做缩放，仅旋转；每种旋转角度至多使用一次；至少有一个矩形不含模板；模板图案的边界框严格小于所有矩形的内部区域。

**规则**：
1. 识别角落的模板图案，提取其形状和颜色分布。确定模板中出现次数最多的颜色为主色。
2. 对每个灰(5)矩形，检查其内部（去掉 1 像素宽边框后的区域）是否存在模板的某个旋转版本。匹配标准：存在一个位置和旋转角度，使得模板的所有非黑(0)像素与矩形内部对应位置的颜色完全一致。
3. **匹配成功的矩形**：将其 1 像素宽边框全部重涂为模板主色；内部保持不变（保留嵌入的模板图案和灰(5)填充）。
4. **匹配失败的矩形**：将整个矩形（含边框和内部）全部重涂为红(2)。
5. 模板图案本身从输出中擦除（替换为背景色黑(0)）。

**关键洞察**：模板匹配不仅是检测——它同时决定了两个不同变换分支的触发。边框涂色使用的是模板的"主色"（出现最多的颜色），而非模板中的任意颜色或矩形自身的颜色，需要对比含有不同多色模板的示例才能确认这一映射规则。

## 新题 7：双源汇聚——角位 L 定几何、对角基元定填充

**组合逻辑**：[放大画布(expand_canvas) + 连线(draw_line)](从角位 L 推断三角形轮廓并绘制在扩展画布上) + [平铺(tile)](对角基元图案周期填充三角形内部)（双源汇聚结构：几何信息和填充信息分别来自输入的两个不同区域，合并后产生输出）

**来源原语**：角位边角(corner_piece)/放大画布(expand_canvas)/三角轮廓(triangle_outline)/角位置对应(corner_correspond)/补对角线边(fill_diagonal_side) ← e3f79277; 基元图案(motif)/平铺(tile)/逐级展开(successive_placement) ← 762cd429; 连线(draw_line) ← 1478ab18

**依赖链**：角位 L 的位置和长度编码三角形的角、大小和轮廓色（几何通道），对角基元图案编码内部填充纹理（纹理通道）。两条通道独立输入、在输出中汇合：三角轮廓圈定填充边界，基元图案提供填充内容。删去 L→不知道画什么三角形；删去基元→内部为空（不同题目）；删去画布扩展→轮廓画不下。

从角位 L 推断扩展画布上的直角三角形轮廓，用输入对角位置的基元图案周期平铺填充三角形内部。

**输入结构**：正方形网格（边长 n，约 5~7），背景为黑(0)。在四个角之一，有一个 1 像素厚的前景色（如蓝(1)）L 形结构，L 的两条边分别贴合该角的两条网格边缘。两条边长度可以不等（如水平边 4 像素、垂直边 3 像素），以确保三角形方向唯一确定。在输入网格关于中心的对角位置（如 L 在左上角，则基元在右下角区域），放置一个 2x2 的多色基元图案（4 格分别为不同颜色，如红(2)、绿(3)、黄(4)、橙(7)）。L 和基元图案之间的区域为背景色。生成约束：L 的两条边长度不等（以消除对称歧义）；基元图案的 4 格颜色互不相同且与 L 颜色和背景色均不同；L 与基元不重叠不相邻。

**规则**：
1. 从 L 的位置确定三角形所在的角（与 L 同角）。从 L 的两条边长度（设为 a 和 b）确定三角形的两条直角边长度：输出画布边长 = max(2a, 2b) + 1，两条直角边长度分别为 2a 和 2b。
2. 在输出画布的对应角绘制直角三角形轮廓：两条直角边沿画布边缘绘制（颜色为 L 的颜色），对角线连接两条边的自由端点（使用 Bresenham 直线算法绘制，同样使用 L 的颜色）。
3. 以三角形直角顶点为对齐原点，将 2x2 基元图案沿行列方向周期平铺覆盖整个画布，然后仅保留落在三角形内部（轮廓线以内、不含轮廓线本身）的平铺像素。轮廓线上和外部的平铺像素全部丢弃。
4. 输出中不包含原始输入的 L 和基元图案——它们被几何信息和纹理信息消费后丢弃，输出仅含扩展画布上的三角形轮廓和内部平铺纹理。

**关键洞察**：L 和基元图案各自携带解题所需的一半信息——L 给出"在哪个角画多大的三角形"，基元给出"用什么纹理填充内部"。两者在输入中空间分离、角位对称，必须同时正确解读才能产生完整输出。基元的对齐起点为三角形直角顶点这一规则需要对比多个示例（L 在不同角的情形）才能确认。
