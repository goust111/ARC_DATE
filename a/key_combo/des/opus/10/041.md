## 新题 1：嵌套深度索引色带序列

**组合逻辑**：[严格包含 strict_containment](从判断遮挡改为计算深度) + [压缩 compress](从最终输出改为中间查找表) + [重涂色 recolor](由深度索引驱动而非由包含者颜色驱动) → 深度-色带联合决定重涂

**来源原语**：严格包含(#7 7d1f7ee8)、压缩(#12 4be741c5)、色带(#12 4be741c5)、重涂色(#7 7d1f7ee8)、空间排列顺序(#12 4be741c5)

**依赖链**：压缩产生有序色表 → 包含分析产生每帧深度 → 深度索引色表确定填充色 → 执行重涂。压缩不改变色表就无法确定颜色，包含分析不完成就无法确定索引，两者缺一不可。

将嵌套矩形框的包含深度作为索引，查询由色带压缩生成的颜色序列，用查到的颜色重涂每层框内区域。

**输入结构**：约 18x18 的网格，背景黑(0)。左侧约占 12x12 的区域内有 3-4 层严格嵌套的单像素厚单色矩形框（每层颜色各异，如蓝(1)、红(2)、绿(3)、黄(4)），框之间有至少 1 像素的背景间隔。右侧有一列宽 1 像素、高约 6-8 的竖直色带，由 4-5 种不同颜色的连续段组成（如从上到下：橙(7)、品红(6)、灰(5)、青(8)），每段高度不等（2-3 像素），段间无间隔。不同示例中：嵌套层数可变（2-4 层），色带段数与层数相同，色带颜色和顺序在不同示例中不同。生成约束：色带段数恰好等于嵌套层数；框的颜色与色带的颜色互不重叠。

**规则**：
1. 对右侧色带进行行主色压缩：沿纵轴方向将每段相同颜色连续行压缩为一个像素，得到从上到下的颜色序列 S（长度等于段数）。
2. 对左侧嵌套矩形框计算包含深度：最外层框深度为 1，被恰好一层框严格包含的框深度为 2，依此类推。
3. 对深度为 d 的矩形框，将其框线内所有背景像素（即该框内部、下一层框外部的区域）重涂为 S[d]（序列第 d 项，从 1 开始计数）。
4. 保留所有原始矩形框的框线颜色不变。最内层框内部的背景像素重涂为 S[最大深度]。
5. 右侧色带区域在输出中保持不变。

**关键洞察**：色带的空间排列顺序不是装饰而是查找表，嵌套的几何层级不是为了确定颜色继承方向而是为了产生索引值——两个独立的空间分析（压缩 + 包含层级）必须同时完成才能确定输出。

## 新题 2：对称补全部分形状以驱动印章匹配

**组合逻辑**：[对称补全 symmetry_completion](从全局马赛克修复改为局部形状恢复) + [归一化形状比对 normalized_shape_matching](补全后的形状才能匹配) + [印章覆盖 stamp_overlay](匹配结果决定印章选择与放置)

**来源原语**：对称补全(#2 981571dc)、推断对称轴(#2 981571dc)、归一化形状比对(#15 4ff4c9da)、印章覆盖(#10 e6721834)、标记锚定精灵(#10 e6721834)

**依赖链**：目标区的残缺形状需补全 → 补全后形状才能与源区精灵匹配 → 匹配确定印章选择 → 执行印章覆盖。补全改变了待匹配形状的拓扑，匹配决定了印章内容，三步构成信息变换链。

先对称补全目标面板中的残缺轮廓以恢复完整形状，再将完整形状与源面板的精灵进行归一化匹配，最后将匹配到的完整精灵印章覆盖到目标位置。

**输入结构**：约 20x10 的网格，由灰(5)色竖线分为左右两个 20x4（或类似）的面板。左侧源面板背景黑(0)，包含 2-3 个完整的多色精灵体（每个约 3x3 到 5x5 像素，4-连通，每个精灵由 2 种颜色组成，其中一种颜色构成精灵的外轮廓形状，另一种填充内部）。右侧目标面板背景青(8)，包含 2-3 个残缺形状——每个残缺形状是某个源精灵外轮廓的一部分（保留了关于某一对称轴的一侧像素，另一侧被擦除为背景色）。残缺形状仅使用红(2)单色绘制。不同示例中精灵形状不同（但均具有至少一个对称轴），残缺的方向（上下或左右）也可能不同。生成约束：每个残缺形状恰好对应一个源精灵的外轮廓；不同残缺形状对应不同源精灵；源精灵的外轮廓均具有至少一条对称轴（垂直或水平）。

**规则**：
1. 对目标面板中每个红(2)色 4-连通分量，推断其保留像素暗示的对称轴（垂直或水平），沿该轴将缺失侧补全为完整形状。
2. 将补全后的形状进行平移归一化（左上角对齐原点），与源面板每个精灵的外轮廓（同样平移归一化）逐一比对，找到形状一致的匹配。
3. 将匹配到的源精灵完整地（包括外轮廓和内部填充的两种颜色）平移到目标面板中对应残缺形状的位置，对齐方式为补全后形状的边界框左上角与源精灵边界框左上角重合。源精灵中黑(0)背景色透明（不覆盖目标面板的青(8)背景）。
4. 保持分隔线和源面板不变。

**关键洞察**：残缺形状不是直接可匹配的标记，必须先通过对称补全恢复完整轮廓后才能与源精灵比对——补全步骤是匹配步骤的前提，而非独立的修复操作。

## 新题 3：像素计数控制模板旋转角度后执行图案补全

**组合逻辑**：[计数 counting](从控制尺寸改为控制旋转角度) + [旋转 rotation](每实例独立旋转) + [补全 completion](用旋转后的模板逐一补全) → 计数-旋转-补全三段耦合

**来源原语**：计数(#3 f931b4a8)、像素数决定尺寸(#3 f931b4a8)、旋转(#1 b20f7c8b / #18 2c181942)、补全(#20 72322fa7)、完整图案推断缺失(#20 72322fa7)、对称图案(#20 72322fa7)

**依赖链**：局部像素计数 → 确定旋转角度 → 旋转模板 → 用旋转后模板补全该局部的残缺图案。计数结果直接参数化旋转，旋转结果改变补全的参照模板，三者串联且每步输出都改变下一步的行为。

统计每个残缺图案旁的控制点像素数以确定旋转倍数，将全局模板旋转相应角度后用作该实例的补全参照。

**输入结构**：约 15x15 的网格，背景黑(0)。网格中央有一个完整的 5x5 单色图案（如蓝(1)），该图案无旋转对称性（即 0/90/180/270 度旋转各不相同），但具有某种可辨识的结构（如一个不对称的连通区域）。网格其余位置分散着 3-4 个残缺图案，每个是上述完整图案某个旋转版本的子集（保留了约 60-80% 的像素，缺失部分为背景色），使用绿(3)色绘制。每个残缺图案的边界框外、紧邻其上方或左方 1 像素处有一个由红(2)色像素构成的小簇（1-4 个像素的 4-连通分量）。不同示例中：完整图案的具体形状不同，残缺图案的缺失位置不同，红色小簇的像素数不同。生成约束：每个红色小簇的像素数 k 取值 0-3（对应 0/90/180/270 度）；每个残缺图案恰好是完整图案旋转 k×90 度后擦除部分像素的结果；残缺部分足够多使得不旋转模板则无法唯一确定补全方案。

**规则**：
1. 识别网格中央的蓝(1)色完整图案 T（5x5 边界框内的完整连通区域）。
2. 对每个绿(3)色残缺图案 P_i，找到其紧邻的红(2)色小簇 C_i，统计 C_i 的像素数 k_i。
3. 将模板 T 顺时针旋转 k_i × 90 度，得到旋转模板 T_i。
4. 将 T_i 与 P_i 对齐（边界框左上角重合），在 P_i 中缺失（为背景色）但 T_i 中有像素的位置填入绿(3)色，完成该残缺图案的补全。
5. 保持蓝色完整图案和红色小簇不变。

**关键洞察**：完整图案无旋转对称性，因此不同的旋转角度产生不同的补全结果——像素计数不是在控制空间尺寸，而是在从四个离散旋转态中选择正确的模板朝向，这个选择直接决定了补全内容。

## 新题 4：框内色带压缩决定洪泛填充颜色

**组合逻辑**：[压缩 compress](从独立输出改为中间参数提取) + [洪泛填充 flood_fill](填充色不再固定，由压缩结果动态决定) + [射线延伸 ray_extend](射线颜色继承动态填充色) → 压缩驱动填充

**来源原语**：压缩(#12 4be741c5)、行主色压缩单像素(#12 4be741c5)、洪泛填充(#9 292dd178)、缺口矩形框(#9 292dd178)、射线延伸(#9 292dd178)、缺口定射线向(#9 292dd178)

**依赖链**：框内杂色图案 → 行主色压缩得到首色 → 首色成为填充参数 → 洪泛填充框内并射线延伸出缺口。框内图案既是压缩的输入又是填充的目标区域，两个操作共享同一空间但功能正交。

提取每个缺口矩形框内部杂色图案的行主色序列首项作为该框的专属填充色，用该色洪泛填充框内并通过缺口射线延伸至网格边缘。

**输入结构**：约 20x20 的网格，背景黑(0)。网格中分布 2-3 个互不重叠的缺口矩形框，每个框为单像素厚的灰(5)色边框，尺寸约 6x6 到 8x8，每个框的某条非角落边上恰好缺少一个像素（缺口）。每个框的内部（框线围成的矩形区域）不是空白，而是填满了由 2-3 种颜色构成的杂色图案（如交替的蓝(1)和红(2)条纹、或绿(3)和黄(4)的棋盘式分布），每种颜色占据若干完整行或部分行。不同框内部的颜色组合不同。不同示例中：框的数量、位置、缺口位置、内部颜色图案均不同。生成约束：每个框内部图案沿纵轴方向可以被行主色压缩为非平凡序列（至少 2 种颜色交替）；缺口不在框的角落位置；从缺口向外的射线路径上无其他框或非背景像素阻挡。

**规则**：
1. 对每个缺口矩形框 F_i，提取其内部区域的所有像素行（相对于框内部坐标从上到下）。
2. 对每行统计行主色（出现次数最多的非背景颜色；若平局则取该行最左出现的颜色）。
3. 将行主色序列压缩为去连续重复的颜色序列 S_i，取 S_i 的第一个颜色作为该框的填充色 c_i。
4. 将 F_i 内部所有像素（无论原来什么颜色）替换为 c_i。
5. 从 F_i 的缺口位置开始，沿缺口朝外方向（即远离框内部的方向）逐像素延伸，将路径上的背景像素替换为 c_i，直到到达网格边界为止。遇到非背景像素则停止（不包含该像素）。
6. 保持所有框的灰色边框像素不变（包括缺口处不填充框线色）。

**关键洞察**：框内部的杂色图案不是随机噪声而是编码了自身填充色的信息源——必须先"读懂"图案（压缩提取首色）才能决定如何覆盖它，图案同时是信息载体和操作目标。

## 新题 5：局部翻转改变邻接关系后触发选择性连线

**组合逻辑**：[局部翻转 local_reverse](改变空间排列) + [同色邻接 same_color_adjacent](翻转后重新计算) + [连线 connect](仅连接翻转后新产生的同色邻接) → 翻转-邻接-连线耦合

**来源原语**：局部翻转(#14 833966f4)、中心分隔像素(#14 833966f4)、各侧独立翻转(#14 833966f4)、连线(#5 33067df9)、同色邻接(#5 33067df9)、连接条(#5 33067df9)

**依赖链**：翻转改变像素的物理位置 → 位置变化导致邻接关系重组 → 新的同色邻接对触发水平连线。翻转不只是视觉变化，它通过改变拓扑来决定哪些连线存在——连线的存在性完全取决于翻转结果。

在多列像素段中独立执行局部翻转，翻转后相邻列中新出现的水平同色像素对之间绘制连接条。

**输入结构**：约 5x13 的网格（5 行 13 列），背景黑(0)。网格中有 4 个竖直的 5x1 像素列，列间隔 2 像素（即位于第 1、4、7、10 列）。每个 5x1 列由 5 个不同颜色的像素组成，中间像素（第 3 行）为灰(5)色分隔符，上方 2 像素和下方 2 像素各为一个段，段内两像素颜色各异，取自{蓝(1)、红(2)、绿(3)、黄(4)、橙(7)、品红(6)}。列间的 2 像素宽间隔全部为背景色。不同示例中：各列内像素的具体颜色排列不同，但均满足灰色分隔符在第 3 行。生成约束：翻转前后相邻列之间至少存在一个水平同色邻接对的变化（即翻转创造了新的同色邻接或消除了旧的同色邻接）。

**规则**：
1. 对每个 5x1 列，保持灰(5)色中心像素不动，将上方 2 像素的顺序翻转（第 1 行和第 2 行交换），将下方 2 像素的顺序翻转（第 4 行和第 5 行交换）。
2. 翻转完成后，检查所有水平相邻的列对（第 1 列与第 4 列、第 4 列与第 7 列、第 7 列与第 10 列），逐行比较同行像素颜色。
3. 若两个相邻列在同一行的像素颜色相同（且均非背景色和灰色），则在该行上将两列之间的 2 个背景像素填充为该相同颜色，形成连接条。
4. 若翻转前该行已有同色邻接（即不翻转也同色），仍然连线（规则只看翻转后的状态）。
5. 其余位置保持不变。

## 新题 9：对接拼合方向由走廊检测确定

**规则**：
1. 检测网格边界上的标记像素，按颜色配对。对每对同色标记，确定其连线方向（水平/垂直）。

4. 将旋转后的精灵平移至紧邻 hub 该侧边外部的位置，接触边与 hub 侧边对齐（居中）。
5. 输出仅包含 hub 和所有已拼合的精灵，其余像素（包括边界标记和原位置精灵）清除为背景色。

**关键洞察**：精灵与 hub 侧面的配对不靠颜色匹配（两者颜色不同），而靠边界走廊的空间指向——走廊是一个隐式的方向指示器，必须先完成走廊检测才能确定拼合方案。

## 新题 10：链式填充路径由包含层级约束宽度

**组合逻辑**：[链式填充 chain_fill](填充宽度不由首块决定，而由包含层级决定) + [严格包含 strict_containment](包含深度转化为宽度参数) + [拼接 assemble](多个链从不同凹槽生长) → 包含层级参数化链式生长

**来源原语**：链式填充(#6 16b78196)、凹槽(#6 16b78196)、中心条(#6 16b78196)、固定条带宽度(#6 16b78196)、严格包含(#7 7d1f7ee8)、矩形边框(#7 7d1f7ee8)、拼接(#6 16b78196)

**依赖链**：包含层级分析确定每个凹槽的深度 → 深度决定该凹槽启动的链式填充的条带宽度 → 不同宽度的链从不同凹槽独立生长。层级分析是全局的，链式填充是局部的，前者的全局信息参数化了后者的局部行为。

中心条的凹槽处于不同嵌套深度的矩形框内，凹槽的包含深度决定了从该凹槽生长出的链式填充条带宽度。

**输入结构**：约 20x20 的网格，背景黑(0)。网格中央有一根灰(5)色的水平或垂直实心条（宽 2 像素，长约 12-14 像素），条的边界上有 2-3 个凹槽（背景色的缺口，每个缺口宽 1-3 像素）。凹槽处于不同的空间环境中：某些凹槽外围有 1 层矩形框包围（蓝(1)色），某些凹槽外围有 2 层嵌套矩形框包围（蓝(1)色外层 + 红(2)色内层），某些凹槽不被任何框包围。矩形框为单像素厚、不完全封闭（在朝向中心条的一侧有开口以容纳凹槽连接）。散落在网格各处的有若干单色精灵体（3-6 像素的不规则连通分量），颜色各异。不同示例中：凹槽数量和位置不同，包围框的层数不同，精灵形状和颜色不同。生成约束：每个凹槽的包含深度（0 = 不被框包围，1 = 被 1 层框包围，2 = 被 2 层框包围）对应链式填充条带宽度（深度 0 → 宽度 1，深度 1 → 宽度 2，深度 2 → 宽度 3）；每个凹槽处恰好有一个精灵的形状能精确填入凹槽。

**规则**：
1. 识别中心条及其凹槽。对每个凹槽，计算其包含深度 d（该凹槽中心点被多少层矩形框严格包含）。
2. 根据深度确定该凹槽的链式填充条带宽度 w = d + 1。
3. 在散落精灵中，找到形状能精确填入该凹槽的根精灵（根精灵的形状与凹槽的背景孔洞形状完全吻合）。
4. 将根精灵放入凹槽（颜色保持根精灵原色）。从根精灵开始，沿垂直于中心条的方向向外链式生长：每一级新块占据前一级块边界框内的背景像素区域，限制在宽度 w 的条带内（以凹槽中心线为轴心），颜色循环使用根精灵颜色。链式生长直到条带内无更多背景像素可填（遇到网格边界或非背景像素）。
5. 不同凹槽的链独立生长，互不干扰。若链路径重叠，先处理深度大的凹槽（深度大 → 条带宽 → 优先级高）。
6. 保持中心条、矩形框不变。清除未被使用的散落精灵（设为背景色）。

**关键洞察**：链式填充的条带宽度不是由首块自身决定的，而是由凹槽所处的嵌套环境决定——同一中心条上的不同凹槽因为处于不同包含深度而生成不同粗细的链，这是包含层级分析与链式生长的结构耦合。

**组合逻辑**：[裁剪/提取 crop+extract](从混合网格中分离目标图像) + [平铺 tile](提取物作为瓦片重复铺设) + [行列乘积完整 row_col_product](提取判据) + [双层图案叠加 two_level_pattern](提取物既是精细层又与粗糙层交互) → 提取驱动平铺

**来源原语**：裁剪(#13 b71a7747)、提取(#13 b71a7747)、行列乘积完整(#13 b71a7747)、双色图像(#13 b71a7747)、平铺(#3 f931b4a8)、模板瓦片(#3 f931b4a8)、像素数决定尺寸(#3 f931b4a8)、双层图案叠加(#3 f931b4a8)、控制区域(#3 f931b4a8)

**依赖链**：行列乘积判据定位并提取双色子图 → 提取出的子图成为平铺模板 → 控制区域像素数决定平铺尺寸 → 执行双层平铺。提取步骤的输出是平铺步骤的输入模板——不完成提取就没有可用的瓦片。

从混合网格中按行列乘积完整准则提取隐藏的双色图像，用它作为瓦片按控制区域指定的尺寸进行平铺输出。

**输入结构**：约 16x16 的网格，无统一背景色。网格被分为三个区域（由灰(5)色单像素线分隔）：上半区（约 10x16）是一个充满多种颜色像素的混合区域，其中隐藏着一对颜色（如蓝(1)和红(2)），这对颜色的像素恰好覆盖了它们所在行和所在列的完整叉积（即若这对颜色出现在行 {r1,r2,r3} 和列 {c1,c2,c3,c4}，则这 12 个交叉位置全部被蓝或红占据），其余颜色不满足此条件。下半区左侧（约 3x3）是控制区域 A，包含若干橙(7)色像素（非背景像素数 = 输出高度）。下半区右侧（约 3x3）是控制区域 B，包含若干橙(7)色像素（非背景像素数 = 输出宽度）。控制区域的背景为黑(0)。不同示例中：隐藏双色图像的行列位置、颜色对、控制区域像素数均不同。生成约束：恰好有一对颜色满足行列乘积完整条件；提取后的双色子图尺寸不大于控制区域指定的输出尺寸。

**规则**：
1. 在上半区中，枚举所有颜色对 (c_a, c_b)，找到唯一满足以下条件的颜色对：将 c_a 和 c_b 像素合并后，它们覆盖的行集 R 和列集 C 的叉积 R x C 中每个位置恰好是 c_a 或 c_b（无遗漏、无其他颜色侵入）。
2. 保留这些行和列，删除其他行和列，得到提取的双色子图 P（尺寸 |R| x |C|）。
3. 统计控制区域 A 中非黑像素数为 H，控制区域 B 中非黑像素数为 W。
4. 生成 H x W 的输出网格，将 P 作为瓦片在输出中周期性平铺（行方向以 |R| 为周期，列方向以 |C| 为周期），超出部分截断。

**关键洞察**：上半区视觉上是杂乱的多色网格，隐藏双色图像不靠颜色稀有性或空间连通性识别，而靠行列乘积完整这一代数判据——必须检验每对颜色的行列覆盖才能定位目标，提取物随后作为瓦片进入完全不同的平铺逻辑。

## 新题 12：奇偶虚线模式由走廊长度动态决定间距

**组合逻辑**：[连线 draw_line](绘制走廊连接线) + [奇偶决定虚线 parity_dash](虚线模式应用于走廊) + [计数 counting](走廊长度参数化虚线周期) + [对边连通 opposite_edge_connect](走廊检测) → 长度驱动的变周期虚线

**来源原语**：连线(#8 f35d900a)、奇偶决定虚线(#8 f35d900a)、对角配对(#8 f35d900a)、对边连通(#17 2bee17df)、走廊(#17 2bee17df)、无阻挡跨行列涂色(#17 2bee17df)、计数(#3 f931b4a8)、边界像素(#17 2bee17df)

**依赖链**：边界像素对检测出走廊 → 走廊长度（像素数）被计数 → 长度模 3 的余数决定虚线周期（余 0 → 周期 2，余 1 → 周期 3，余 2 → 周期 4）→ 按该周期绘制虚线填充走廊。不同走廊因长度不同而展现不同的虚线节奏，计数结果直接改变视觉输出的模式。

检测边界间的无阻挡走廊，根据每条走廊的长度动态计算虚线周期，用变周期虚线填充各走廊。

**输入结构**：约 15x15 的网格，背景黑(0)。网格四条边界上有若干单色标记像素（颜色取自蓝(1)、红(2)、绿(3)），每种颜色恰好在相对的两条边界上各出现一次（如蓝色在左边界第 3 行和右边界第 3 行各一个），形成对边配对。每对标记在同一行或同一列上，且之间所有像素为背景色（无阻挡走廊）。走廊长度（两标记之间的背景像素数，不含标记本身）各不相同。网格内部可能有一些灰(5)色的阻挡像素，它们不在任何走廊路径上但限制了其他可能的虚假走廊。不同示例中：标记数量 2-4 对，位置不同，走廊长度不同。生成约束：走廊长度对 3 取余的结果至少有两种不同值（以确保虚线模式不全相同）。

**规则**：
1. 对网格边界上的标记像素按颜色配对。对每对同色标记 (m_a, m_b)，确认它们在同一行或同一列上且之间全为背景色。
2. 计算走廊长度 L = 两标记之间的背景像素数（不含标记本身）。
3. 计算虚线周期 T：若 L mod 3 = 0 则 T = 2；若 L mod 3 = 1 则 T = 3；若 L mod 3 = 2 则 T = 4。
4. 从靠近网格左边界或上边界的标记开始，沿走廊方向依次编号背景像素为 0, 1, 2, ...。将编号 mod T < T/2（向下取整）的像素填充为该对标记的颜色，其余保持背景色。
5. 标记像素本身在输出中保持不变。
6. 灰色阻挡像素保持不变。

**关键洞察**：走廊不是均匀填充也不是固定奇偶虚线，虚线周期由走廊自身长度编码——同一网格中不同走廊展现不同节奏的虚线，必须逐一计算长度才能确定每条走廊的虚线模式，长度与模式的映射关系需要对比多个示例才能归纳。
