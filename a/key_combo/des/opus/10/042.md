## 新题 1：可达性定向折叠与重叠涂色

**组合逻辑**：[折叠fold](方向判定机制创新：由可达性决定而非空间大侧) + [重涂色recolor](触发条件创新：折叠后重叠区域) ← [可达性reachability](作为方向选择器) + [墙壁障碍wall_barrier](阻断可达路径)

**来源原语**：折叠/fold(230f2e48)、铰接标记/hinge_marker(230f2e48)、端点标记/endpoint_marker(230f2e48)、固定端与活动端/fixed_vs_free(230f2e48)、重涂色/recolor(67385a82)、可达性/reachability(dd6b8c4b)、墙壁障碍/wall_barrier(dd6b8c4b)

**依赖链**：可达性分析 → 决定每根杆的折叠方向 → 折叠后产生像素重叠 → 重叠位置触发涂色。可达性分析依赖墙壁布局，折叠方向依赖可达性结论，涂色位置依赖折叠结果。三者紧密耦合，删除任一步骤则无法确定最终输出。

将带铰接标记的直线杆沿铰接点折叠，折叠方向取决于从杆的自由端能否通过非墙壁路径到达网格中的目标锚点；折叠后若多根杆的像素重叠，则将重叠位置涂为指定颜色。

**输入结构**：约 15x15 黑(0)背景网格。含 3-4 根直线杆（水平或垂直），每根杆由同一前景色（蓝(1)或绿(3)）的 5-7 个像素组成，杆上有一个灰(5)端点标记和一个红(2)铰接标记。网格中散布若干品红(6)墙壁像素（单像素或 2-3 像素短段），形成不规则屏障。网格中有一个橙(7)目标锚点像素。生成约束：每根杆的自由端（非端点标记侧）恰好有一个方向可通过非墙壁背景像素的 4-连通路径到达橙(7)锚点，另一个方向被墙壁完全阻断。各杆折叠后至少存在一对重叠。

**规则**：
1. 对每根杆，识别灰(5)端点标记侧为固定段，红(2)铰接标记为折叠轴心，铰接标记另一侧为自由段。
2. 从自由段的末端像素出发，尝试沿两个垂直方向（相对于杆的轴向）做 4-连通 flood-fill，仅通过黑(0)背景像素和橙(7)锚点。选择能到达橙(7)锚点的方向作为折叠方向。
3. 将自由段绕铰接标记旋转 90 度到该方向（即自由段从原轴向变为垂直方向的射线，起点紧邻铰接标记）。固定段和铰接标记位置不变。
4. 所有杆折叠完成后，检查每个像素坐标：若有两根或以上杆的非标记像素同时占据该坐标，将该坐标涂为黄(4)。其余杆像素保持原色。
5. 墙壁像素、锚点像素保留不变。

**关键洞察**：折叠方向并非由几何空间决定，而由墙壁障碍构成的可达性拓扑决定——必须分析 flood-fill 路径才能确定每根杆应该向哪侧折叠。

## 新题 2：重力沉降后周期瓦片补全

**组合逻辑**：[重力下落gravity_drop](作用于特定像素) + [补全completion](创新：在重力改变布局后推断周期) ← [碰撞停止collision_stop](决定沉降终点) + [行列周期row_col_period](从沉降后格局推断)

**来源原语**：重力下落/gravity_drop(28a6681f)、碰撞停止/collision_stop(28a6681f)、沿路径滑动/slide_along_path(28a6681f)、补全/completion(f823c43c)、周期瓦片/periodic_tile(f823c43c)、标记为缺失值/markers_missing_val(f823c43c)、行列周期/row_col_period(f823c43c)、障碍物/obstacle(28a6681f)

**依赖链**：重力沉降改变像素布局 → 沉降后的非标记像素揭示底层周期结构 → 用周期推断补全标记位置。沉降必须先于周期推断（否则位置不对），而周期推断必须排除尚未沉降的游离像素类型。两逻辑共享同一坐标空间，互相约束。

蓝色"水"像素在重力作用下穿过背景向下沉降直到碰撞停止；沉降完成后，网格中剩余的非水、非标记像素呈现出一个周期瓦片结构，用该周期替换所有品红标记像素。

**输入结构**：约 12x12 黑(0)背景网格。网格中有红(2)和绿(3)像素组成的部分周期图案（最小周期为 3x3 或 4x2 等小尺寸），该图案中若干位置被品红(6)标记像素替代（表示缺失值，3-5 个）。另有 4-6 个蓝(1)"水"像素散布在网格上半部分的背景位置（不与现有图案像素重合）。网格底部和中部有灰(5)固体障碍像素（单像素或短段）。生成约束：蓝(1)像素下落后不会落在品红(6)标记位置上；去除蓝(1)和品红(6)后剩余的红(2)/绿(3)像素与一个唯一最小周期瓦片一致。

**规则**：
1. 蓝(1)像素受向下重力作用：每个蓝像素沿列逐格下移，穿过黑(0)背景格，遇到非黑像素或网格底边时停止在其正上方的最后一个黑(0)格。
2. 若蓝像素正下方无黑(0)格可移动，则保持原位。
3. 重力处理完成后，忽略所有蓝(1)像素和品红(6)像素，仅从红(2)/绿(3)像素推断最小矩形周期瓦片（行周期 pr、列周期 pc，使得每个红/绿像素的颜色与其坐标 (r mod pr, c mod pc) 处的瓦片颜色一致）。
4. 将每个品红(6)像素替换为其坐标对应的瓦片颜色（红(2)或绿(3)）。
5. 蓝(1)像素在其沉降后的位置保留，不被瓦片覆盖。其余黑(0)背景不变。

**关键洞察**：水像素沉降后占据的位置不参与周期推断——求解者必须先模拟重力确定蓝像素最终位置，再从剩余证据中反推周期，两步推理共享且争夺同一坐标空间。

## 新题 3：射线吸收量决定柱状条重排序

**组合逻辑**：[射线延伸ray_extend](创新：射线被同色柱吸收而截断) + [排序sort](创新：排序键为吸收的射线数) + [重分配redistribute] ← [朝向决定方向orientation_determines_direction] + [槽位保持颜色slot_retains_color]

**来源原语**：射线延伸/ray_extend(f8be4b64、9344f635)、微型标记/micro_marker(9344f635)、行列条/row_column_bar(9344f635)、朝向决定方向/orientation_determines_direction(9344f635)、排序/sort(31f7f899)、重分配/redistribute(31f7f899)、柱状条/vertical_bar(31f7f899)、基线/baseline(31f7f899)、槽位保持颜色/slot_retains_color(31f7f899)、遇前景终止/stop_at_fg(f8be4b64)

**依赖链**：多米诺标记发射水平射线 → 射线遇到柱状条时被吸收（截断）→ 统计每根柱吸收的射线总数 → 以吸收数为键排序柱的形状轮廓 → 将轮廓重新分配到固定槽位并涂为槽位颜色。射线发射和柱位置在同一网格中互相影响（柱截断射线的同时也决定了自己的排序键）。

水平多米诺标记向两侧发射行射线；射线遇到柱状条时停止并被该柱"吸收"；统计每根柱吸收的射线总数，按此数值从小到大重新排列柱的轮廓到各槽位，槽位保留原色。

**输入结构**：约 14x18 黑(0)背景网格。底部有一条横跨全宽的灰(5)基线（第 12 行）。基线上方竖立 4 根柱状条，每根宽 1 像素、高度各不相同（3-7 格），颜色互不相同（从蓝(1)、红(2)、绿(3)、黄(4)中取）。网格左侧区域（柱状条左方的空白区）散布 3-5 个水平二像素多米诺标记，每个多米诺由橙(7)像素组成，分布在不同行上。生成约束：每个多米诺标记的行坐标在基线以上、至少有一根柱的高度范围内；每根柱至少被一条射线触达；无两根柱吸收数相同。

**规则**：
1. 每个水平橙(7)多米诺向右发射一条橙(7)行射线（从多米诺右端的下一列开始），射线逐列延伸直到遇到非黑像素（柱状条像素或网格右边界）时停止，不包含终止点。射线像素绘制为橙(7)。
2. 对每根柱，统计有多少条射线以该柱的像素作为终止点（即射线抵达该柱的列时停止）。记为该柱的"吸收数"。
3. 按吸收数从小到大排列所有柱的高度轮廓（形状不变，仅高度信息转移）。
4. 将排序后的轮廓依次放入从左到右的槽位（原各柱的 x 坐标位置），每个槽位涂为该槽位原来的柱颜色。
5. 基线保留不变。射线像素在输出中擦除（恢复为黑(0)背景）。

**关键洞察**：射线的传播路径被柱的空间位置截断，而截断次数反过来决定了柱的排序键——柱既是射线的障碍物，又是排序的被作用对象，两个角色互为因果。

## 新题 4：角标缩放与对称轴裁剪

**组合逻辑**：[像素放大scale_up](缩放倍率由角标间距隐式编码) + [镜像reflect](创新：角标颜色不对称时只保留一半) ← [角标记corner_marker](同时编码缩放区域和对称选择) + [对称轴关系symmetry_axis](创新：由帧线位置确定)

**来源原语**：像素放大/scale_up(8a004b2b)、角标记/corner_marker(8a004b2b、3de23699)、着色约束对齐缩放/color_evidence_constrains_scaled_placement(8a004b2b)、镜像/reflect(f8a8fe49)、框架线/frame_line(f8a8fe49)、对称轴关系/symmetry_axis(f8a8fe49)、裁剪/crop(f8a8fe49、3de23699)、内部图案/inner_pattern(f8a8fe49)

**依赖链**：角标定义目标区域 → 小精灵缩放填入区域 → 帧线将区域一分为二形成对称轴 → 角标颜色不对称性指示保留哪一半。缩放倍率、对称轴位置、输出裁剪范围全部由同一组角标和帧线隐式编码，必须联合解读。

将外部小精灵按角标定义的区域尺寸进行整数倍放大填入该区域，然后沿区域内的红色帧线做镜像对称轴裁剪——保留角标颜色出现次数较多的那一侧作为输出。

**输入结构**：约 16x16 黑(0)背景网格。网格一角（如左上 4x4 范围内）有一个 3x3 或 4x4 的多色小精灵（由蓝(1)、绿(3)、黄(4)像素组成，含黑背景像素）。网格另一区域有 4 个角标像素标定一个矩形目标区域（约 9x9 或 12x8）：其中 3 个角标为橙(7)，1 个角标为栗(9)。目标区域内部正中央有一条红(2)帧线（水平或垂直单像素线，贯穿区域宽或高）。目标区域内还散布 2-3 个与缩放后精灵一致的"证据像素"（非黑非红的彩色像素）。生成约束：目标区域的宽高恰好是精灵宽高的整数倍；帧线将区域精确对半分割；证据像素的位置和颜色与唯一正确的缩放放置方案一致。

**规则**：
1. 识别 4 个角标像素，确定目标矩形区域边界。
2. 计算目标区域尺寸与小精灵尺寸的比值，得到缩放倍率 k（水平和垂直相同）。
3. 将小精灵的每个像素放大为 k x k 块，在目标区域内找到与所有证据像素一致的唯一放置位置，将缩放后的精灵填入区域。
4. 识别区域内的红(2)帧线作为对称轴。帧线将区域分为两半。
5. 统计 4 个角标的颜色：橙(7)出现 3 次、栗(9)出现 1 次。保留栗(9)角标所在的那一半区域（帧线侧的半区），丢弃另一半。
6. 输出为保留的半区内容（含帧线像素），裁剪至紧凑边界框。

**关键洞察**：角标既编码了缩放对齐的空间约束，又通过颜色不对称性编码了镜像裁剪的方向选择——同一组标记承担双重语义角色，必须同时解读才能确定输出。

## 新题 5：异常象限平铺为精灵阵列

**组合逻辑**：[裁剪crop](由异常值选择触发) + [平铺tile](创新：铺设次数由非异常象限的前景像素计数决定) + [计数counting](跨象限信息提取) ← [颜色异常值选择outlier_color_selection](决定裁剪目标) + [像素数定尺寸数pixel_count_sets_size_copies](决定铺设参数)

**来源原语**：裁剪/crop(0b148d64)、象限/quadrant(0b148d64)、分隔行列/separator_row_col(0b148d64)、颜色异常值选择/outlier_color_selection(0b148d64)、平铺/tile(91413438)、计数/counting(91413438)、像素数定尺寸数/pixel_count_sets_size_copies(91413438)、精灵体/sprite(91413438)、阵列排布/array_layout(91413438)

**依赖链**：异常象限选择 → 裁剪得到精灵内容 → 非异常象限的像素计数 → 确定输出画布尺寸和铺设份数 → 按阵列排布铺设精灵。异常值判断提供"铺什么"，计数提供"铺多少"，两者来自同一输入的不同部分，缺一不可。

从四象限中选出唯一异常色象限的图案作为精灵，统计三个同色象限的前景像素总数确定铺设份数，将精灵按行优先顺序铺入方形画布。

**输入结构**：约 13x13 网格（含中央分隔线），由一条全黑(0)水平线和一条全黑(0)垂直线将网格分为 4 个 6x6 象限。三个象限各含若干同色前景像素（如红(2)），形成稀疏不规则图案；第四个象限含不同色前景像素（如蓝(1)），形成一个紧凑的 3x3 连通图案。生成约束：三个同色象限的前景像素总数为一个完全平方数（如 4 或 9）；异常象限的图案裁剪后恰好为 3x3。

**规则**：
1. 识别水平和垂直全黑分隔线，将网格分为 4 个象限。
2. 统计每个象限中非黑前景像素的颜色。三个象限共享同一颜色，一个象限颜色不同——该象限为异常象限。
3. 裁剪异常象限中非黑像素的最小边界框，得到精灵（保留黑背景像素结构）。
4. 统计三个非异常象限中前景像素的总数 N。
5. 构建 sqrt(N) x sqrt(N) 个槽位的方形输出画布（每个槽位大小等于精灵边界框尺寸），背景为黑(0)。
6. 将精灵复制到前 N 个槽位（按行优先从左上到右下），剩余槽位保持黑(0)。

**关键洞察**：输出内容和输出尺寸编码在输入的不同象限中——异常象限提供"铺什么"（精灵形状），而非异常象限的像素总数提供"铺多少次到多大画布"，必须综合两类信息。

## 新题 6：滑动碰撞叠层与旋转量编码

**组合逻辑**：[滑动translate](多对象同时运动) + [旋转rotate](创新：旋转角度由行程距离编码) + [透明叠加transparent_overlay](创新：层优先级由到达顺序决定) ← [标记指示方向marker_indicates_dir] + [抵达边界reach_edge]

**来源原语**：滑动/translate(99caaf76)、旋转/rotate(99caaf76)、十字形/cross_shape(99caaf76)、标记精灵/marker_sprite(99caaf76)、网格边缘/grid_edge(99caaf76)、标记指示方向/marker_indicates_dir(99caaf76)、抵达边界/reach_edge(99caaf76)、透明叠加/transparent_overlay(75b8110e)、层叠顺序/layer_stack(75b8110e)

**依赖链**：标记方向 → 决定滑动方向 → 计算行程距离 → 行程距离决定旋转量（短程 90 度、长程 180 度）→ 多对象到达终点后叠层 → 叠层优先级由行程长短决定（长程在上）。运动、旋转、叠层三者全由同一个"距离"变量串联，不可分割。

多个带方向标记的十字形对象沿标记方向滑向网格边缘，滑动距离短的旋转 90 度、距离长的旋转 180 度；到达终点后若多对象重叠，行程更长的对象在上层覆盖下层。

**输入结构**：约 15x15 黑(0)背景网格。含 3-4 个独立对象，每个对象由一个 3x3 彩色十字（5 像素，各对象颜色不同，从蓝(1)、绿(3)、黄(4)、栗(9)中取）和一个 2x1 或 1x2 的灰(5)标记精灵组成。标记精灵紧贴十字的一侧（上/下/左/右），指示该对象应向对侧方向滑动。各对象初始位置互不相邻，距网格对应边缘的距离各不相同。生成约束：至少有一对对象滑动后终点区域重叠；各对象到目标边缘的距离互不相同。

**规则**：
1. 对每个对象，灰(5)标记精灵相对于十字的方位指示"尾巴方向"，对象向尾巴的反方向滑动（如标记在左侧则向右滑）。
2. 将整个对象（十字 + 标记）沿该方向平移，直到对象边界框的前沿触及网格边缘。记录滑动格数 d。
3. 对十字部分（不含标记精灵）施加旋转：若 d <= 4，顺时针旋转 90 度；若 d > 4，旋转 180 度。标记精灵相对于十字的位置关系在旋转后保持（标记始终在运动尾端）。
4. 所有对象到达终点后，处理重叠：同一像素坐标被多个对象占据时，保留行程 d 更大的对象的颜色（长程覆盖短程）。
5. 无重叠的对象像素保持各自颜色。背景保持黑(0)。

**关键洞察**：滑动距离同时编码了两个后续决策——旋转角度和叠层优先级。求解者必须先计算每个对象的行程，再用同一个数值分别决定旋转量和覆盖关系，形成从单一属性扇出到双重效果的推理结构。

## 新题 7：连通面积门控聚集与多目标分配

**组合逻辑**：[聚集gather](创新：多目标竞争分配) + [擦除erase] + [重涂色recolor](按目标色着色) ← [可达性reachability](路径连通判定) + [面积比较area_comparison](作为资格门控) + [距离排序填充distance_ranked_fill](分配规则)

**来源原语**：聚集/gather(dd6b8c4b)、擦除/erase(dd6b8c4b)、墙壁障碍/wall_barrier(dd6b8c4b)、可达性/reachability(dd6b8c4b)、距离排序填充/distance_ranked_fill(dd6b8c4b)、重涂色/recolor(67385a82)、连通分量/connected_component(67385a82)、面积比较/area_comparison(67385a82)、孤立像素/isolated_pixel(67385a82)

**依赖链**：连通分量分析 → 面积计算 → 面积门控过滤候选 → 可达性判定候选与目标的连接 → 距离排序确定分配优先级 → 聚集到目标并涂色 → 原位擦除。面积门控和可达性是并行约束，必须同时满足才能参与分配。

散布的标记像素先按连通分量面积过滤（孤立单像素不参与），再按可达性分配到最近的目标块，聚集后涂为目标块中心色；被移走的像素原位擦除。

**输入结构**：约 14x14 黑(0)背景网格。含 2 个目标块：每个是一个 3x3 区域，中心为不同颜色（红(2)和蓝(1)），周围 8 格为黑(0)空位等待填入。网格中散布 15-20 个绿(3)前景像素，部分形成 2-4 像素的 4-连通簇，部分为孤立单像素。品红(6)墙壁像素形成若干短段障碍，将网格分为不完全连通的区域。生成约束：每个目标块周围恰好有 8 个空位；孤立绿像素至少 3 个（这些不参与聚集）；非孤立绿像素簇通过 flood-fill 各自恰好只能到达一个目标块；每个目标块可达的合格绿像素总数恰好为 8。

**规则**：
1. 识别所有绿(3)像素的 4-连通分量。面积为 1 的分量（孤立像素）标记为"非候选"，保持不变。面积 >= 2 的分量中所有像素标记为"候选"。
2. 对每个候选像素，做 4-连通 flood-fill（通过黑(0)背景和绿(3)像素，不穿越品红(6)墙壁），判定它能到达哪个目标块（红(2)中心或蓝(1)中心）。
3. 对每个目标块，将其可达的候选像素按曼哈顿距离从近到远排序。
4. 按距离顺序取前 8 个候选像素，将它们依次填入目标块的 3x3 区域空位（按从左上到右下的行优先顺序填入），填入时涂为该目标块的中心颜色。
5. 被移走的候选像素在原位置擦除为黑(0)。
6. 孤立绿像素、墙壁像素、目标中心像素保持不变。

**关键洞察**：面积判断和可达性判断构成双重门控——孤立像素虽然可能距离目标很近，但因面积不足被排除；大簇像素虽然面积达标，但若被墙壁隔绝则无法到达目标。两个条件缺一不可。

## 新题 8：坐标压缩后沙漏谓词选择折叠目标

**组合逻辑**：[坐标压缩coordinate_compression](揭示真实拓扑距离) + [折叠fold](创新：仅对沙漏区域内的杆执行) ← [沙漏距离谓词hourglass_distance_predicate](作为目标选择器) + [分隔线separator_line](定义压缩轴和沙漏窄轴) + [铰接标记hinge_marker](折叠轴心)

**来源原语**：坐标压缩/coordinate_compression(7d419a02)、分隔线/separator_line(7d419a02)、沙漏距离谓词/hourglass_distance_predicate(7d419a02)、块距离/block_distance(7d419a02)、定位标记/anchor_marker(7d419a02)、折叠/fold(230f2e48)、铰接标记/hinge_marker(230f2e48)、直线杆/straight_rod(230f2e48)、空间大侧折入/fold_toward_space(230f2e48)

**依赖链**：移除分隔线做坐标压缩 → 在压缩坐标系中定位锚点 → 计算各杆到锚点的沙漏距离 → 沙漏谓词判定哪些杆在"沙漏区域"内 → 仅对沙漏区域内的杆执行折叠 → 折叠方向按空间大侧决定。压缩坐标决定沙漏判定结果，沙漏判定决定折叠目标集，三步逻辑紧耦合不可跳步。

移除黑色分隔线做坐标压缩后，以锚点为中心用沙漏距离谓词筛选出位于沙漏形区域内的直线杆，仅对它们执行铰接折叠（方向取空间大侧），区域外的杆保持不动。

**输入结构**：约 17x17 网格，背景为黑(0)。含 3 条全宽水平黑(0)分隔线和 3 条全高垂直黑(0)分隔线（将网格视觉上分为 4x4 块区域）。各块区域中有 5-6 根直线杆（水平或垂直，长 4-6 像素），由绿(3)像素组成，每根杆上有一个红(2)铰接标记。网格中有一个唯一的橙(7) 2x2 锚点标记。分隔线方向为水平方向较密集。生成约束：移除分隔线做坐标压缩后，各杆在压缩坐标中的块距离可计算；满足沙漏谓词的杆为 2-3 根（窄轴为水平即分隔线密集轴），不满足的为 2-3 根；满足谓词的杆两侧空间不对称。

**规则**：
1. 识别所有贯穿全宽/全高的纯黑行和列作为分隔线，将它们从网格中移除并做坐标压缩（剩余行列紧凑排列）。
2. 在压缩坐标系中定位橙(7) 2x2 锚点的中心位置。
3. 对每根绿(3)直线杆，在压缩坐标系中计算其中点到锚点中心的块距离（分别计算水平块距离 dh 和垂直块距离 dv，以分隔线间隔为单位）。
4. 分隔线较密集的轴为沙漏窄轴（此题为水平轴）。对每根杆判定沙漏谓词：dh > 0 且 dv > 0 且 dh（窄轴距离）<= dv（开口轴距离）时，该杆在沙漏区域内。
5. 仅对沙漏区域内的杆执行折叠：以红(2)铰接标记为轴心，将杆的较长侧段旋转 90 度朝向空间更大的一侧（压缩坐标中距网格边缘更远的方向有更多空白格的一侧）。
6. 沙漏区域外的杆保持原位不变。分隔线在输出中保留（恢复原网格尺寸）。

**关键洞察**：分隔线既定义了坐标压缩规则又定义了沙漏谓词的窄轴方向——同一结构元素承担双重语义。求解者必须先压缩坐标才能正确计算块距离，再用距离做沙漏判断来筛选折叠目标。
