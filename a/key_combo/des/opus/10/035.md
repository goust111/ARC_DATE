## 新题 1：噪声清除揭示隐藏对称性并补全

**组合逻辑**：[擦除/erase](已有) → [邻接/adjacency + 邻接不足则删除/delete_unsupported](已有，作为擦除条件) → [对称补全/symmetry_complete](已有，但作用对象从"空白半区"变为"去噪后涌现的不完整对称图案") → [镜像/mirror](已有，但对称轴需从清洗后的图案中推断而非预设)

**来源原语**：擦除/erase + 邻接/adjacency + 邻接不足则删除/delete_unsupported（参考题 7f4411dc）；对称补全/symmetry_complete + 翻转对称/flip_symmetry（参考题 f25ffba3）；镜像/mirror + 镜像对称/mirror_symmetry（参考题 dc0a314f）

**依赖链**：噪声像素干扰了对称性的识别——必须先执行基于邻接支撑的擦除来去掉孤立噪点，去噪后的图案才呈现出带缺损的近似左右对称结构，进而对称补全才能确定哪些缺失像素应被填充。跳过擦除则对称轴无法稳定检测；跳过补全则图案残缺不完整。

从含噪声的近似对称图案中先清除孤立噪点，再利用涌现出的左右对称性补全缺失区域，输出修复后的完整对称图案。

**输入结构**：约 15x15 的黑(0)背景网格。网格中央偏左或偏右有一个由红(2)像素组成的 4-连通前景图案（约 15~30 像素），该图案具有近似的左右镜像对称性，但其中一侧有 2~4 个像素被移除（变为黑(0)），造成对称性不完美。同时，网格中散布着 5~8 个孤立的红(2)噪声像素，这些噪声像素与主图案不 4-连通，且每个噪声像素的非黑(0)4-邻居数量为 0。不同示例中，主图案的具体形状不同（可以是不规则连通区域、有孔洞的封闭区域等），但均满足：去掉噪声后，图案关于某条垂直线近似对称，且恰好有若干像素仅出现在对称轴的一侧。生成约束：噪声像素不落在主图案的对称补全位置上；主图案中每个属于图案本体的像素至少有 2 个非黑 4-邻居。

**规则**：
1. 遍历所有红(2)像素，计算每个像素的非黑(0)4-邻居数量。将非黑 4-邻居数少于 2 的红像素涂为黑(0)（擦除噪声）。
2. 对剩余红(2)像素组成的连通图案，找到其边界框的垂直中心线作为对称轴（对称轴为 x = (bbox_left + bbox_right) / 2）。
3. 对于对称轴一侧存在红(2)像素而另一侧对应位置为黑(0)的情况，将黑(0)位置填充为红(2)。
4. 输出修复后的完整网格。

**关键洞察**：噪声像素和缺损像素都是红色的"异常"，但它们的处理完全相反——噪声需要删除，缺损需要补上。区分二者的关键是先用邻接支撑规则去噪，去噪后涌现的对称结构才能指导补全方向。

## 新题 2：异常象限位置编码错切方向

**组合逻辑**：[异常值选择/outlier_selection + 相等比较/equality_comparison](已有，用于识别唯一象限) → [象限位置→错切方向映射](创新：异常象限的空间位置编码变换参数) → [错切/shear](已有，但方向由异常检测结果动态决定)

**来源原语**：异常值选择/outlier_selection + 相等比较/equality_comparison + 象限/quadrant + 分隔十字/separator_cross（参考题 88a62173）；错切/shear + 行偏移递变/row_offset_progress（参考题 3cd86f4f）

**依赖链**：四个象限的逐对比较确定唯一象限的位置（左上/右上/左下/右下），该位置映射为错切方向（上→下切 / 下→上切 / 左→右切 / 右→左切），错切操作应用于三个共享图案的合并结果。异常检测的输出不仅决定"选什么"还决定"怎么变换"，形成条件→操作参数的跨步依赖。

识别四象限中的唯一图案，根据其所在象限位置确定错切方向，对共享图案执行相应方向的错切后输出。

**输入结构**：约 15x15 的网格（奇数行列），中间行和中间列为灰(5)色分隔十字，将网格分为四个大小相同的矩形象限（每个约 7x7）。三个象限包含相同的多色前景图案（由蓝(1)和橙(7)像素组成的 4-连通不规则小图形，约 6~10 像素，背景为黑(0)），第四个象限包含一个不同的同色系图案。不同示例中，唯一象限的位置不同，图案形状也不同。生成约束：三个共享象限的图案完全一致（含颜色和位置）；唯一象限的图案与共享图案至少有 2 个像素位置不同。

**规则**：
1. 比较四个象限的图案（以象限内相对坐标为准），找出仅出现一次的唯一图案及其所在象限位置。
2. 取共享图案（三个相同象限中任一个）作为错切操作的输入。
3. 根据唯一象限的位置确定错切方向：
   - 左上象限唯一 → 向左下错切（每行向左偏移量随行号递增，偏移量 = 行号 r，r 从 0 开始）
   - 右上象限唯一 → 向右下错切（每行向右偏移量 = r）
   - 左下象限唯一 → 向左上错切（每行向左偏移量 = 最大行号 - r）
   - 右下象限唯一 → 向右上错切（每行向右偏移量 = 最大行号 - r）
4. 在黑(0)画布上输出错切后的共享图案。画布宽度 = 原象限宽度 W + 原象限高度 H - 1，高度 = H。超出画布边界的部分舍弃。

**关键洞察**：唯一象限本身不出现在输出中——它的唯一价值是通过其空间位置编码错切方向，而被错切的反而是那个"普通"的共享图案。

## 新题 3：种子平铺生成参考基准以提取篡改区域

**组合逻辑**：[裁剪/crop + 角落即种子/corner_is_seed](已有) → [平铺/tiling](已有，但目的从"输出放大图"变为"构建比较基准") → [差异提取/difference_extraction + 对齐比较/aligned_comparison](已有，但比较对象从"两个分离物体"变为"自生成参考 vs 实际网格") → [裁剪/crop](已有，输出裁剪到差异区域)

**来源原语**：裁剪/crop + 角落即种子/corner_is_seed + 种子瓦片/seed_tile（参考题 d10ecb37）；平铺/tiling + 阵列排布/array_layout + 边长决定重复数/side_len_determines_rep（参考题 ccd554ac）；差异提取/difference_extraction + 对齐比较/aligned_comparison + 缺损副本/damaged_copy + 缺失掩码/missing_cell_mask（参考题 2037f2c7）

**依赖链**：种子提取确定瓦片内容，平铺将种子扩展为与输入同尺寸的"应有图案"，差异提取将实际输入与该参考逐像素比较以定位篡改区域，最终裁剪输出仅含篡改区域的正确颜色。四步之间环环相扣：无种子则无参考，无参考则无法比较，无比较则无法定位篡改。

从一个大部分正确的平铺网格中提取左上角种子，重新平铺为参考基准，比较后输出被篡改区域应有的正确内容。

**输入结构**：一个矩形网格（约 12x12），由一个小种子瓦片（约 3x3 或 4x4）在行列方向重复平铺而成。种子位于左上角，包含 2~3 种非黑颜色（如红(2)、蓝(1)、绿(3)）。网格中有一个连续的矩形子区域（约 3x4 或 4x3，不与左上角种子区域重叠）被篡改——该区域内的所有像素被替换为品红(6)。网格的行数和列数分别是种子高度和宽度的整数倍。不同示例中，种子内容、种子尺寸、篡改区域的位置和大小均不同。生成约束：篡改区域不与左上角的种子位置重叠，保证种子完整可读；篡改区域为实心矩形，内部全为品红(6)。

**规则**：
1. 检测平铺周期：找到最小的 H_tile x W_tile 使得左上角 H_tile x W_tile 区域在非品红(6)位置上与整个网格的对应周期相位一致。
2. 提取左上角 H_tile x W_tile 区域作为种子瓦片。
3. 将种子瓦片平铺至与输入网格相同的尺寸，得到参考网格。
4. 找出输入网格中为品红(6)的所有像素位置——这些即为篡改位置。
5. 将篡改位置对应的参考网格像素值提取出来，裁剪到篡改区域的边界框。
6. 输出该裁剪结果（仅含正确颜色，背景为黑(0)的位置保持黑(0)）。

**关键洞察**：品红色区域既不是噪声也不是目标图案——它是"数据被擦除"的标记。求解者需要意识到整个网格本应是完美平铺的，品红色是需要修复的"洞"，而修复的依据是网格自身的周期性结构。

## 新题 4：周期推断越过遮挡块恢复被遮内容

**组合逻辑**：[周期推断/periodic_inference + 忽略缺失值推断/ignore_missing_to_infer](已有，但需同时忽略两类未知像素) → [间隙填充/gap_filling](已有，但填充目标从"所有黑色缺失"变为"仅遮挡区域") → [裁剪/crop](已有，输出裁剪到遮挡块的边界框)

**来源原语**：周期推断/periodic_inference + 间隙填充/gap_filling + 周期瓦片/repeating_tile + 缺失像素/missing_pixel + 忽略缺失值推断/ignore_missing_to_infer（参考题 1d0a4b61）；遮挡块/occluder + 被遮区域/occluded_region + 裁剪/crop（参考题 dc0a314f）

**依赖链**：周期推断必须同时跳过黑色缺失像素和遮挡块像素两类"未知数据"，从剩余已知像素中归纳最小周期瓦片。间隙填充使用该瓦片恢复遮挡块下方的内容（黑色缺失像素也被同步填充，但不影响输出）。裁剪将结果限定到遮挡块的边界框。周期推断的难度因遮挡块覆盖了一整片区域而增加——丢失的信息比零散缺失更集中，可能导致某些相位仅有极少观测值。

在一个带零散缺失和一个实心遮挡块的周期壁纸中，推断周期瓦片，恢复并输出遮挡块下方隐藏的图案。

**输入结构**：约 14x14 的网格，整体为一个由小周期瓦片（约 2x3 或 3x2）重复平铺的多色壁纸，使用红(2)、绿(3)、黄(4)等颜色。网格中有 4~8 个零散像素被替换为黑(0)（缺失数据）。另有一个约 4x4 的实心蓝(1)正方形遮挡块覆盖在壁纸上，完全遮住其下方的图案。蓝(1)颜色仅出现在遮挡块中，不出现在壁纸图案中。网格行列数分别为瓦片高宽的整数倍。不同示例中，瓦片内容、遮挡块位置和大小、黑色缺失位置均不同。生成约束：去掉遮挡块和黑色缺失后，周期瓦片的每个相位至少在网格中出现一次且为非黑色，保证周期可唯一推断。

**规则**：
1. 将黑(0)像素和蓝(1)像素均标记为"未知"。
2. 从所有"已知"像素（非黑且非蓝）中推断最小周期瓦片：找到最小的 H x W 使得所有已知像素在 (row mod H, col mod W) 处的颜色一致。
3. 用推断出的周期瓦片填充所有未知像素：每个未知位置 (r, c) 的颜色 = tile[r mod H][c mod W]。
4. 裁剪到蓝(1)遮挡块的边界框位置，输出该矩形区域填充后的内容。

**关键洞察**：恢复遮挡内容的机制不是镜像对称（参考题 dc0a314f 的方法），而是周期性——壁纸的重复结构本身就编码了被遮部分的信息，只要周期瓦片的每个相位在遮挡块外至少可观测一次。

## 新题 5：重复体计数决定唯一体的平移距离

**组合逻辑**：[计数/counting + 相等比较/equality_comparison](已有) → [异常值选择/outlier_selection](已有) → [计数结果→平移参数](创新：数量信息跨步编码变换幅度) → [平移/shift](已有，但步长由计数动态确定) → [擦除/erase](已有)

**来源原语**：计数/counting + 相等比较/equality_comparison + 象限/quadrant（参考题 88a62173）；异常值选择/outlier_selection（参考题 88a62173, 38007db0, aee291af）；平移/shift + 固定步长移动/fixed_step_move（参考题 73c3b0d8）；擦除/erase（参考题 7f4411dc）

**依赖链**：相等比较确定哪些带状区域共享图案、哪个是唯一的；计数得出共享者的数量 K；K 直接成为唯一精灵体的平移步长。若跳过计数，平移距离无法确定；若跳过异常选择，不知道移动哪个精灵体；若跳过平移，输出位置错误。计数的输出不是用于选择（选择由异常检测完成），而是作为另一操作的数值参数——这种"量化跨步传递"在参考题中不存在。

在等分的水平带状区域中，找出唯一图案的精灵体，将其向右平移"重复体数量"个像素，擦除所有重复体。

**输入结构**：约 20x10 的黑(0)背景网格，被等高的黑色空行分隔为 N 个水平带（N 在 4~6 之间，每带高 3~4 行，带间隔 1 行黑色）。每个带的中央有一个小型 4-连通单色精灵体（绿(3)，约 3~6 像素）。其中 N-1 个带的精灵体形状完全相同（相对带内位置相同），恰好 1 个带的精灵体形状不同。不同示例中 N 值不同、精灵体形状不同、唯一精灵体所在带的位置不同。生成约束：唯一精灵体右移 N-1 像素后不超出网格右边界；所有精灵体在各自带内的列位置相同（均左对齐于同一列），以排除位置差异对形状比较的干扰。

**规则**：
1. 将网格按空行分割为 N 个水平带，提取每带中的绿(3)精灵体的形状掩码（相对于精灵体自身边界框的像素分布）。
2. 比较所有精灵体形状，找出出现次数 > 1 的共享形状和出现恰好 1 次的唯一形状。令 K = 拥有共享形状的带的数量（即 N - 1）。
3. 将唯一精灵体整体向右平移 K 个像素（每个像素列坐标 +K），保持行坐标不变。
4. 将所有拥有共享形状的精灵体的像素涂为黑(0)（擦除）。
5. 输出修改后的完整网格（仅剩平移后的唯一精灵体）。

**关键洞察**：重复体的数量不是用来"选择"或"过滤"的——它们被擦除了——而是作为数值参数控制唯一体的平移幅度。求解者必须意识到"有多少个重复"这一数量信息被编码为几何变换的步长。

**组合逻辑**：[镜像/mirror + 反射恢复遮挡/reflection_recovers](已有，但从恢复单个遮挡扩展为恢复多个) → [相等比较/equality_comparison](已有) → [去重筛选/uniqueness_filter + 图案仅出现一次/pattern_once](已有，但操作对象从可见精灵体变为刚被恢复的不可见图案) → [裁剪/crop](已有)

**来源原语**：镜像/mirror + 镜像对称/mirror_symmetry + 遮挡块/occluder + 被遮区域/occluded_region + 反射恢复遮挡/reflection_recovers（参考题 dc0a314f）；去重筛选/uniqueness_filter + 图案仅出现一次/pattern_once + 带框精灵体/framed_sprite（参考题 aee291af）；相等比较/equality_comparison（参考题 88a62173）

**依赖链**：镜像恢复为每个遮挡块重建隐藏内容，产生多个恢复补丁作为比较候选。相等比较在这些恢复补丁之间执行。去重筛选从中选出唯一的那个。关键耦合：比较的对象在输入中完全不可见——它们必须先被重建才能参与比较。若跳过镜像恢复，无候选可比；若跳过比较，无法区分哪个恢复结果独特。

在具有左右对称性的场景中恢复多个遮挡块下方的隐藏图案，比较后输出其中唯一不重复的那个。

**输入结构**：约 17x17 的网格，整体具有左右镜像对称性（对称轴为垂直中线）。背景为黑(0)，前景由红(2)和黄(4)像素组成的复杂对称图案。网格左半部有 3 个大小相同的实心栗(9)正方形遮挡块（每个约 3x3），分布在不同位置且互不重叠。这 3 个遮挡块的右半部对称位置均无遮挡（完全可见）。栗(9)颜色仅出现在遮挡块中。在对称图案的设计中，3 个遮挡块下方的隐藏内容中有 2 个相同、1 个不同。不同示例中，遮挡块的位置、隐藏内容、整体对称图案均不同。生成约束：3 个遮挡块均在对称轴左侧且与对称轴不相邻（保证右侧对称位置完整可见）；遮挡块之间不相邻、不重叠。

**规则**：
1. 识别所有栗(9)色实心正方形，记录每个的边界框位置。
2. 对每个遮挡块，计算其关于垂直中线的镜像位置。从镜像位置提取同大小的图案补丁，再将该补丁水平翻转，得到遮挡块下方的恢复内容。
3. 比较所有恢复补丁（像素级比较）。恰好一个补丁的内容与其他补丁不同。
4. 输出该唯一补丁。

**关键洞察**：所有待比较的对象在输入中都是不可见的——被遮挡块完全覆盖。求解者必须先利用全局对称性进行重建，才能获得比较的候选集，然后从重建结果中做异常值选择。这与直接在可见对象中选异常值有本质区别。

## 新题 7：模板匹配定位锚点后从锚点发射对角射线

**组合逻辑**：[模板匹配/template_matching + 形状匹配/shape_matching + 含旋转反射变换/includes_rotation_reflection](已有) → [匹配位置→射线发射原点](创新：匹配结果的空间坐标作为后续操作的起点参数) → [射线延伸/ray_extend + 邻接触发对角溅射/adjacency_triggers_diagonal_splash](已有，但射线发射条件从"邻接触发条"变为"模板匹配成功") → [重涂色/recolor](已有)

**来源原语**：模板匹配/template_matching + 模板图案/template_motif + 形状匹配/shape_matching + 含旋转反射变换/includes_rotation_reflection + 忽略干扰项/ignore_distractors（参考题 50f325b5）；射线延伸/ray_extend + 邻接触发对角溅射/adjacency_triggers_diagonal_splash（参考题 73c3b0d8）；重涂色/recolor（参考题 50f325b5, e4941b18）

**依赖链**：模板匹配在绿色像素场中定位所有与青色模板形状一致的副本（含旋转反射），提取每个匹配副本的中心坐标。这些中心坐标成为对角射线的发射原点。射线从每个锚点同时向四个对角方向延伸，直到遇到非背景像素或网格边界停止。模板匹配的空间结果直接参数化射线的几何分布——匹配到的副本越多、位置越分散，射线网络就越复杂。

在含有模板及其隐藏副本的网格中，找出所有匹配位置，从每个匹配中心发射四条对角射线，输出射线交织后的网络图案。

**输入结构**：约 20x20 的黑(0)背景网格。左上角有一个青(8)色的小型模板图案（4-连通，3~5 像素，占据一个约 3x3 的边界框）。网格其余区域散布着绿(3)像素，其中包含 2~4 个模板的精确副本（可能经过 90/180/270 度旋转或水平/垂直翻转），嵌入在绿色干扰像素之间。不同示例中，模板形状、副本数量、副本位置和旋转/翻转方式不同。生成约束：各模板副本的边界框互不重叠；每个副本的中心像素（边界框中心取 floor）向四个对角方向延伸的射线路径在到达网格边界前不经过其他副本的边界框（保证射线不被其他副本截断，使射线长度仅由网格边界决定）。

**规则**：
1. 提取青(8)模板图案的边界框归一化掩码，枚举其全部 8 种旋转/翻转变体（去重后保留不同的）。
2. 以行优先顺序扫描网格，在绿(3)像素中查找与任一变体完全匹配的放置位置（放置区域内所有模板像素位置均为绿(3)）。匹配到的位置标记为已选，后续匹配跳过与已选位置重叠的放置。
3. 将每个匹配副本的像素重涂为青(8)。
4. 对每个匹配副本，计算其边界框中心 (cr, cc)（cr = floor((top+bottom)/2), cc = floor((left+right)/2)）。从 (cr, cc) 向四个对角方向 ((-1,-1), (-1,+1), (+1,-1), (+1,+1)) 逐步延伸，在每个经过的背景黑(0)像素处涂为青(8)，遇到非黑像素或网格边界时停止（不涂终点，若终点非黑）。
5. 不匹配的绿(3)干扰像素保持不变。

**关键洞察**：模板匹配不是为了给副本重新上色（那只是副效果），而是为了精确定位射线的发射原点。射线的交织图案完全取决于匹配位置的空间分布，这一分布在输入中被绿色干扰像素所遮蔽，必须通过形状匹配才能提取。

## 新题 8：走廊转弯次数编码平铺重复因子

**组合逻辑**：[射线延伸/ray_extend + 转弯/turn + 碰撞转向/collision_turn + 遇障碍直角转/right_turn_at_block](已有) → [路径拓扑→数值参数](创新：转弯次数作为独立操作的数值输入) → [平铺/tiling + 边长决定重复数/side_len_determines_rep](已有，但重复因子从边长改为转弯计数)

**来源原语**：射线延伸/ray_extend + 转弯/turn + 起点条/start_bar + 障碍像素/blocker_pixel + 走廊路径/corridor_path + 碰撞转向/collision_turn + 遇障碍直角转/right_turn_at_block（参考题 6bcdb01e）；平铺/tiling + 瓦片/tile + 阵列排布/array_layout + 边长决定重复数/side_len_determines_rep（参考题 ccd554ac）

**依赖链**：走廊路径追踪确定路径的转弯次数 T。种子瓦片的平铺使用 T 作为行列方向的重复因子。两个操作在语义上完全无关（路径追踪是拓扑操作，平铺是几何操作），但通过一个数值量 T 紧密耦合。若跳过路径追踪，T 未知，无法确定平铺规模；若跳过平铺，路径追踪不产生输出所需的图案。走廊的几何复杂度直接编码了一个不相关变换的参数。

追踪走廊路径并计数转弯次数，用该次数作为种子瓦片的平铺重复因子，输出平铺结果。

**输入结构**：约 18x18 的网格，由灰(5)竖直分隔线分为左右两个区域。左区域（约 18x12）：黑(0)背景上散布青(8)障碍像素和一个绿(3)的 2 像素 4-连通起点条。起点条恰好有一个像素在左区域的边界上。青(8)障碍像素排列形成一条一像素宽的走廊，起点条沿走廊方向延伸，每遇到一个障碍像素就直角转弯，直到路径离开网格。右区域（约 18x5）：黑(0)背景上有一个小型多色种子瓦片（约 3x3 或 2x2），位于右区域的左上角，由红(2)、蓝(1)等颜色组成。不同示例中，走廊形状不同（转弯次数 T 在 2~5 之间变化），种子瓦片内容不同。生成约束：走廊在每个障碍处有且仅有一个合法的 90 度转弯方向；右区域足够大以容纳 T x T 的平铺结果（即 T * 种子宽度 <= 右区域宽度 且 T * 种子高度 <= 右区域高度）。

**规则**：
1. 在左区域中，找到绿(3)起点条（2 像素 4-连通线段），确定其边界像素和初始行进方向（从边界像素朝另一个像素的方向进入网格）。
2. 从非边界像素出发，沿当前方向逐步前进。若下一个位置是青(8)障碍，转向唯一可用的垂直方向继续前进，转弯计数 +1。若下一个位置超出左区域或网格边界，停止。
3. 记录总转弯次数 T。
4. 在右区域中，提取左上角的种子瓦片（其边界框为从右区域左上角开始的最小矩形，使得该矩形包含所有非黑像素）。
5. 将种子瓦片在行方向重复 T 次、列方向重复 T 次，生成 T x T 的平铺结果。
6. 输出该平铺结果（大小为 T*H_seed x T*W_seed），不含左区域和分隔线。

**关键洞察**：走廊路径的拓扑复杂度（转弯次数）与平铺操作在语义上毫无关联，但在题目中通过数值传递形成了不可绕过的耦合——走廊是一个"计算器"，其物理结构编码了平铺所需的算术参数。
