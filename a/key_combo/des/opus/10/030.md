## 新题 1：交叉层序决定腔室填充色

**组合逻辑**：[层序推断](已有) + [洪泛填充](已有)，创新点：层序分析的结果不再是最终输出，而是参数化填充操作的颜色选择依据

**来源原语**：层序推断/遮挡层次/正交交叉/交叉可见色为上层（22425bda, 1a2e2828）+ 洪泛填充/封闭区域（e69241bd）+ 全幅条（1a2e2828）+ 标记像素/标记色填充区域（e69241bd）

**依赖链**：交叉点的可见颜色 → 推断条带层序 → 层序决定每个腔室的填充色；含标记的腔室覆盖层序规则，改用标记色填充。删掉层序推断则无法确定无标记腔室的颜色；删掉填充则层序结果无空间用途

输入中正交条带的交叉遮挡关系编码了层序，该层序不作为排列输出，而是决定条带围成的每个腔室用哪种颜色填充；含标记的腔室例外地使用标记色

**输入结构**：约 15x15 网格，黑(0)背景。3-4 条 1 像素宽的全幅条带，每条水平或垂直贯穿整个网格，颜色各不相同（如蓝(1)、红(2)、绿(3)、黄(4)）。水平条与垂直条相交处，显示其中一条的颜色（该条在上层）。条带将网格分割成若干矩形腔室。部分腔室内各含一个灰(5)单像素标记。生成约束：条带数量和位置保证至少形成 4 个腔室；交叉遮挡关系可唯一推出所有条带的全序；每个含标记的腔室恰好一个标记

**规则**：
1. 从可见的共线像素重建每条条带的完整轨迹（某些交叉处的像素显示的是上层条带的颜色，需还原被遮挡条带的存在）
2. 在每个交叉点，可见颜色所属条带高于被遮挡条带。从所有交叉约束推断条带从低到高的唯一全序
3. 对每个腔室（由条带和/或网格边界围成的矩形区域）：
   - 若腔室内含灰(5)标记像素，将腔室内所有非条带像素填充为灰(5)
   - 若腔室内无标记，找出围成该腔室的所有条带（2-4 条），取其中层序最高的条带颜色，将腔室内所有非条带像素填充为该颜色
4. 条带像素本身保持不变

**关键洞察**：层序推断在源题中是最终输出（输出一个颜色序列），此处层序成为空间填充的参数——不同腔室的填充色取决于其边界条带中哪条层序最高，这一"层序→填充色"的结构关系在所有源题中均不存在

## 新题 2：对称性分支双路变换

**组合逻辑**：[对称检测](已有) → 分支 → {对称路径: [平移](已有) | 非对称路径: [标记环绕](已有)}，创新点：对称性不再用于选取/裁剪，而是作为条件分支将不同对象送入不同变换

**来源原语**：对称检测/唯一非轴对称/异常值选择（73ccf9c2）+ 平移/控制像素/角位指示方向/对角固定步移（470c91de）+ 标记环绕/缺陷像素/邻域包围（71e489b6）

**依赖链**：对称检测结果 → 分支判断 → 对称精灵走平移路径（控制像素指示方向）/ 非对称精灵走环绕标记路径。删掉对称检测则无法判断走哪条路径；删掉任一变换路径则输出不完整

将对称性检测用作条件分支：左右对称的精灵沿控制像素方向对角平移，唯一非对称的精灵原地不动但获得橙色光环

**输入结构**：约 18x18 网格，黑(0)背景。4-5 个小型单色 8-连通精灵，每个精灵颜色各异（如蓝(1)、红(2)、绿(3)、黄(4)、灰(5)），像素数 4-8，彼此不相邻（边界框间距至少 2 像素）。每个精灵恰好有一个角落像素被替换为橙(7)控制像素（该角落是精灵边界框的某个顶角位置）。除一个精灵外，其余精灵的前景掩码（在自身紧凑边界框内）关于垂直轴左右镜像对称。恰有一个精灵不满足该对称性。生成约束：平移后的精灵不会超出网格边界；各精灵移动后的落点区域互不重叠

**规则**：
1. 对每个精灵，在其紧凑边界框内检测前景掩码（不含橙(7)控制像素，该位置视为前景色）是否关于垂直中轴左右镜像对称
2. 对称精灵：擦除原始足迹（含控制像素），将控制像素位置恢复为精灵本色以还原完整精灵，然后将完整精灵整体沿控制像素所在角的对角方向平移 1 格（如控制像素在右上角则向右上移 1 格）
3. 非对称精灵（恰好一个）：不移动。擦除其橙(7)控制像素（替换为黑(0)），然后对该精灵每个前景像素的 8-邻域中所有黑(0)像素涂为橙(7)。精灵自身像素保持原色
4. 对称精灵按边界框面积从小到大依次处理；若某个平移后的精灵与已放置的精灵重叠，先放置的精灵像素保留，后者冲突像素丢弃

**关键洞察**：对称检测在源题（73ccf9c2）中用于选取唯一非对称对象并裁剪输出，此处它变为条件分支节点——对称与否决定精灵经历完全不同的变换（平移 vs. 光环标记），且控制像素在两条路径中的语义不同：对称路径中它指示方向，非对称路径中它被丢弃

## 新题 3：平铺偏差定位缺陷并环绕标记

**组合逻辑**：[平铺推断](已有) → [擦除+标记环绕](创新组合)，创新点：平铺推断不是用来补全遮挡区域，而是建立"期望模式"以识别偏差像素，偏差像素触发环绕标记

**来源原语**：平铺/重复瓦片/可见像素约束推断（ca8f78db）+ 标记环绕/缺陷像素/邻域包围（71e489b6）+ 擦除（71e489b6）

**依赖链**：推断最小重复瓦片 → 计算每个位置的期望颜色 → 与实际颜色比较找出偏差像素 → 纠正偏差像素为期望色 → 在偏差位置周围绘制光环。删掉平铺推断则无法识别哪些是偏差；删掉环绕标记则只是平铺修复

推断重复瓦片模式后，将不符合期望模式的像素识别为缺陷，纠正缺陷并在其位置周围绘制橙色光环

**输入结构**：约 14x14 网格。绝大多数像素遵循一个可见的二维重复颜色模式（瓦片周期约 3x3 或 4x4，使用 2-3 种颜色如蓝(1)、红(2)、绿(3)）。少量（2-5 个）散布的像素颜色与该位置的期望瓦片颜色不同，这些偏差像素使用黄(4)。生成约束：偏差像素彼此不 8-相邻（光环不重叠）；偏差像素不在网格最外一圈（光环不截断）；偏差像素数量足够少，不影响瓦片周期的唯一推断

**规则**：
1. 将黄(4)像素视为可疑，从其余像素推断最小矩形重复瓦片（如同 ca8f78db 中将黑色视为未知进行推断）
2. 用推断出的瓦片铺满全网格，计算每个位置的期望颜色
3. 标记"缺陷像素"：实际颜色与期望颜色不同的像素（即那些黄(4)像素）
4. 将每个缺陷像素纠正为其位置的期望颜色（擦除偏差）
5. 对每个缺陷位置，将其 8-邻域中所有非橙(7)像素涂为橙(7)。缺陷位置本身保持纠正后的期望颜色。橙色光环覆盖在瓦片图案之上

**关键洞察**：平铺推断在源题（ca8f78db）中的目标是"修复遮挡"——黑色像素是被遮挡的未知值。此处平铺推断的目标是"建立参照基准"——偏差像素不是遮挡而是异常，其身份只有通过与推断出的瓦片比较才能确定。缺陷的定义完全依赖推断结果，而非像源题（71e489b6）那样依赖局部形态（小连通分量或叶像素）

## 新题 4：有序级联滑动

**组合逻辑**：[排序](已有) → [滑动](已有，创新为级联模式)，创新点：排序结果不输出为颜色序列，而是规定滑动的处理顺序，先滑动的对象成为后续对象的阻挡物，产生涌现的空间格局

**来源原语**：排序/遮挡层次/唯一序链（22425bda）+ 滑动/实心方块/视线对齐/最近邻/沿视线移至近块旁（e1d2900e）

**依赖链**：标记列定义处理顺序 → 按顺序逐个滑动矩形 → 先滑动的矩形成为后续矩形的障碍物。删掉排序/顺序则所有矩形独立滑动（无级联效应）；删掉滑动则顺序无意义

标记列规定矩形的滑动顺序，每个矩形向右滑动直到碰到障碍物，先滑动的矩形成为后续矩形的新障碍

**输入结构**：约 18x18 网格，黑(0)背景。左半区域有 4-5 个单色填充矩形（宽 2-3 像素，高 1-3 像素），颜色各异（如蓝(1)、红(2)、绿(3)、黄(4)、灰(5)），垂直方向各占不同行区间且不重叠，水平位置参差不齐。网格最右列为"顺序标记列"：该列中有若干单像素，每个像素颜色对应一个矩形的颜色，从上到下排列定义处理顺序（最上方标记对应的矩形最先处理）。生成约束：所有矩形初始位置在标记列左侧至少 3 列；标记列中标记的颜色与矩形颜色一一对应；不同矩形的行区间互不重叠（滑动路径不交叉）

**规则**：
1. 读取最右列标记像素的颜色，从上到下确定处理顺序
2. 按该顺序依次处理每个矩形：将矩形向右水平滑动，直到其右边缘与最近障碍物（另一个已滑动到位的矩形的左边缘，或网格右边界减去标记列的 1 列）相邻（间距 0，紧贴）
3. 每个矩形滑动到位后，其占据的新位置立即成为后续矩形的障碍物
4. 所有矩形滑动完成后，擦除标记列（整列替换为黑(0)）

**关键洞察**：排序在源题（22425bda）中输出一个颜色序列，此处排序的结果成为操作调度的时序——相同的矩形集合以不同顺序滑动会产生不同的空间布局。涌现效应：早期滑动的矩形缩短了后期矩形的滑动距离，最终排列取决于全局顺序而非任何单个矩形的独立行为

## 新题 5：封闭轮廓内部异或与外缘描边

**组合逻辑**：[填充](已有) + [逻辑运算](创新为空间域异或) + [轮廓描边](已有)，创新点：逻辑运算不再作用于对齐的二值掩模，而是作用于从封闭轮廓推断的空间内部区域；描边作用于逻辑运算的结果而非原始轮廓

**来源原语**：逻辑运算/二值掩模/逐像素对应（1b2d62fb）+ 填充/内部区域（e88171ec）+ 轮廓描边/轮廓线/外侧相邻（aa62e3f4）+ 擦除（aa62e3f4）

**依赖链**：识别两条封闭轮廓 → 分别确定内部区域 → 逐像素异或得到"恰在一个轮廓内部"的区域 → 擦除原始轮廓 → 填充异或区域 → 对填充区域做外缘描边。删掉内部推断则无法构造逻辑操作的操作数；删掉异或则只有两个独立内部；删掉描边则输出不完整

对两条封闭轮廓的内部区域做空间异或，然后擦除原始轮廓，填充异或区域并描绘其外缘

**输入结构**：约 15x15 网格，黑(0)背景。两条 1 像素宽的封闭轮廓，一条红(2)、一条蓝(1)。每条轮廓是简单封闭曲线（4-连通路径，无自交叉），各自围成一个内部区域。两条轮廓有部分重叠——它们的封闭区域存在交集（但轮廓线本身不共享像素）。生成约束：两条轮廓均完全在网格内部（不触及网格边界）；每条轮廓围成的内部区域至少 5 个像素；两者内部的交集区域和各自独占区域均非空

**规则**：
1. 对每条轮廓，通过从网格边界向内洪泛（4-连通，不穿越该轮廓的像素）确定外部区域；非外部、非轮廓的像素即为该轮廓的内部区域
2. 计算两个内部区域的逐像素异或（XOR）：恰好属于一个内部区域（不是同时属于两个，也不是都不属于）的像素集合
3. 擦除所有红(2)和蓝(1)轮廓像素（替换为黑(0)）
4. 将异或区域的所有像素涂为绿(3)
5. 对绿(3)区域做外缘描边：每个与至少一个绿(3)像素 4-相邻的黑(0)像素涂为黄(4)
6. 绿(3)像素和黄(4)像素共存于输出中，其余为黑(0)

**关键洞察**：逻辑运算在源题（1b2d62fb）中作用于显式给出的二值掩模对（用分隔条对齐），此处操作数是隐式的——必须从封闭轮廓推断出内部区域才能构造掩模。轮廓描边在源题（aa62e3f4）中作用于原始轮廓的外侧，此处作用于逻辑运算产物的外缘，描边对象由前序逻辑计算决定

## 新题 6：框内计数索引精灵选择与像素放大

**组合逻辑**：[计数](已有) → [裁剪/选择](创新为索引选择) → [像素放大+掩码映射](已有)，创新点：计数结果不渲染为计数图，而是作为索引从候选集中选取对象，被选对象再经像素放大变换

**来源原语**：计数/矩形框/标记像素/框内包含/标记数映射填充/忽略干扰项（c8b7cc0f）+ 像素放大/掩码映射/全局掩码/块单元/自身色选掩码（973e499e）+ 裁剪（73ccf9c2）

**依赖链**：计数框内标记 → 计数值 N 作为索引 → 从精灵行中选取第 N 个精灵 → 对选取的精灵做像素放大（自身色掩码）。删掉计数则无法确定选哪个精灵；删掉像素放大则选出的精灵无变换

框内标记数量决定从候选精灵行中选取第几个，选中的精灵再通过自身色掩码规则进行像素放大

**输入结构**：约 20x20 网格，黑(0)背景。上半区有一个红(2)矩形框（1 像素宽，内部至少 5x5），框内外散布若干灰(5)单像素标记。下半区有一排 3-5 个小型多色精灵（每个约 3x3），水平排列，间距 2 像素，每个精灵使用 2-3 种颜色（从蓝(1)、绿(3)、黄(4)、橙(7)、栗(9)中选取），各精灵的颜色组合和图案互不相同。生成约束：框内灰(5)标记数量在 1 到精灵总数之间（含端点）；框外标记为干扰项；精灵排列从左到右位置明确

**规则**：
1. 统计红(2)矩形框严格内部的灰(5)标记像素数量，记为 N。忽略框外和框线上的标记
2. 从下方精灵行中选取第 N 个精灵（从左到右 1-索引）
3. 对选取的精灵做像素放大，放大因子等于精灵的行数（即精灵有 R 行则因子为 R）：精灵中每个颜色为 c 的像素扩展为一个与精灵同形状的块，在块内仅当原始精灵对应位置也是颜色 c 时涂为 c，其余涂为黑(0)
4. 输出为放大后的精灵，置于黑(0)背景上，网格大小恰好容纳放大结果

**关键洞察**：计数在源题（c8b7cc0f）中渲染为 3x3 计数图，此处计数值成为位置索引，驱动一个选择操作。像素放大在源题（973e499e）中作用于整个输入网格，此处仅作用于被索引选中的单个精灵。计数→选择→放大构成三步信息变换链，每步输出实质改变下步输入

## 新题 7：模板印章改变腔室拓扑后洪泛填充

**组合逻辑**：[模板匹配](创新为颜色+尺寸键匹配) + [印章覆盖](已有) → [洪泛填充](已有)，创新点：印章覆盖不是最终输出，而是改变封闭腔室的内部拓扑结构，从而决定后续洪泛填充的连通区域

**来源原语**：模板匹配/目录模板/目录区域/印章覆盖（3ed85e70）+ 洪泛填充/墙壁/封闭区域/标记像素/标记在区域内/标记色填充区域（e69241bd）

**依赖链**：腔室内的单色矩形通过颜色和尺寸匹配到目录中的模板 → 用完整模板替换矩形（印章） → 模板内部结构在腔室内创造新的子区域和通道 → 从标记像素出发洪泛填充，连通范围受模板结构约束。删掉模板匹配则腔室内无结构变化；删掉洪泛填充则印章后的腔室未着色

用颜色和尺寸将腔室中的单色矩形匹配到目录模板，印章完整模板后，模板的内部结构重塑腔室拓扑，再用标记色洪泛填充

**输入结构**：约 22x22 网格，黑(0)背景。灰(5)墙壁将网格分为上方目录区和下方 2-3 个腔室。目录区以栗(9)为背景，其中展示 2-3 个多色模板精灵（每个约 4x4-5x5，使用蓝(1)、红(2)、绿(3)等颜色，内部含若干黑(0)孔洞/通道），模板间有间距。每个模板有一个明显的"边框色"（模板中像素数最多的颜色）。每个下方腔室内含：(a) 一个单色填充矩形，其颜色等于某个模板的边框色，其尺寸（宽x高）等于该模板的边界框尺寸；(b) 矩形外、腔室内的某处有一个品红(6)单像素标记。生成约束：每个腔室的矩形唯一匹配一个模板（颜色+尺寸组合无歧义）；品红标记不与矩形相邻；腔室足够大以容纳模板和标记

**规则**：
1. 对每个腔室内的单色矩形，在目录中找到边框色和边界框尺寸均匹配的唯一模板
2. 用完整模板替换该矩形（左上角对齐），模板中的栗(9)像素（原目录背景）视为透明，不覆盖腔室内容
3. 所有模板印章完成后，对每个腔室执行洪泛填充：从品红(6)标记像素出发，4-连通扩展，将所有可达的黑(0)像素（不穿越灰(5)墙壁、不穿越模板非黑像素）涂为品红(6)
4. 墙壁、模板彩色像素、目录区域均保持不变

**关键洞察**：模板匹配在源题（3ed85e70）中以部分视图做匹配且印章是最终输出，此处用颜色+尺寸键做匹配且印章是中间步骤。关键耦合：模板内部的黑色孔洞和通道决定了洪泛填充能渗透到腔室的哪些子区域——不同模板产生不同的连通拓扑，因此匹配结果实质性改变填充的空间范围

## 新题 8：擦除像素留下隐形阻挡的中轴射线

**组合逻辑**：[擦除](已有) + [射线延伸](已有)，创新点：被擦除的像素不是简单消失，而是在原位留下"幽灵阻挡"——视觉上不可见但会终止射线，形成信息悖论式耦合

**来源原语**：擦除/中轴列/仅保留中轴/前景像素（d23f8c26）+ 射线延伸/阻挡像素/视线对齐/遇阻停止（95755ff2, e1d2900e）

**依赖链**：记录所有非中轴列像素的位置 → 擦除它们（只保留中轴列像素） → 中轴列像素向两侧发射水平射线 → 射线在"幽灵位置"处终止。删掉中轴提取则不知哪些像素发射射线；删掉幽灵阻挡则射线延伸到网格边缘

保留中轴列的彩色像素作为射线源，擦除其余像素，但被擦除像素的原始位置作为不可见的障碍物终止射线

**输入结构**：约 13x13 网格（奇数列），黑(0)背景。散布若干单像素彩色点，颜色各异（如蓝(1)、红(2)、绿(3)、黄(4)），共 8-12 个。其中 3-4 个恰好位于网格的中间列（第 7 列），其余分布在其他列。生成约束：中轴列上的像素至少 3 个；每个中轴像素的左右两侧至少各有一个非中轴像素（确保射线不会都延伸到边缘）；非中轴像素不在中轴像素的同一行上彼此相邻（每行每侧至多一个幽灵阻挡）

**规则**：
1. 记录所有非中轴列彩色像素的位置，作为"幽灵阻挡位置"集合
2. 擦除所有非中轴列像素（替换为黑(0)），仅保留中轴列上的彩色像素
3. 每个中轴列像素向左和向右各发射一条水平射线，射线颜色为该像素的颜色
4. 射线沿行方向逐格绘制：将黑(0)像素涂为射线颜色，遇到幽灵阻挡位置时停止（该位置本身保持黑(0)，不被涂色），遇到网格边缘时也停止
5. 若同一像素被两条不同射线覆盖（来自不同中轴像素），行索引较小（更靠上）的射线源优先，其颜色保留

**关键洞察**：擦除在源题（d23f8c26）中是最终操作——删掉非中轴像素即可。此处擦除的像素留下"记忆痕迹"，形成一个隐含约束层：视觉上消失的像素仍然控制着射线的传播距离。求解者必须通过多个示例发现"射线在某些位置莫名停止"这一现象，并推断出停止位置对应原始输入中被擦除的像素

## 新题 9：距离决定标记重涂色后洪泛填充腔室

**组合逻辑**：[重涂色](已有) + [洪泛填充](已有)，创新点：重涂色的结果不是最终输出，而是确定洪泛填充的颜色参数；且距离计算穿越墙壁（曼哈顿距离），但洪泛填充受墙壁约束（4-连通），形成空间规则的内在张力

**来源原语**：重涂色/边缘线/标记像素/最近距离/标记继承最近源色（2204b7a8）+ 洪泛填充/墙壁/封闭区域/标记在区域内/标记色填充区域（e69241bd）

**依赖链**：计算每个标记到两侧边缘线的曼哈顿距离 → 重涂标记为较近边缘线的颜色 → 用重涂后的颜色洪泛填充标记所在腔室。删掉距离重涂则标记无分化颜色；删掉洪泛填充则只有标记点变色

每个绿色标记按曼哈顿距离继承较近边缘线的颜色，然后以该颜色洪泛填充其所在腔室

**输入结构**：约 15x15 网格，黑(0)背景。左边缘整列为红(2)，右边缘整列为蓝(1)。网格内部有若干灰(5)墙壁线段（水平或垂直，1 像素宽，长度 3-7 像素），将内部空间分隔为 4-6 个腔室。每个腔室内恰好有一个绿(3)单像素标记。生成约束：墙壁将内部完全分隔为不连通的腔室（每个腔室是 4-连通的黑色区域）；每个腔室恰一个标记；至少有一个腔室的标记更靠近红边但腔室主体偏向网格右侧（制造距离与位置的直觉冲突）

**规则**：
1. 对每个绿(3)标记像素，计算其到左边缘红(2)线中最近像素的曼哈顿距离 d_R，以及到右边缘蓝(1)线中最近像素的曼哈顿距离 d_B。曼哈顿距离直接计算，无视墙壁（墙壁不影响距离度量）
2. 若 d_R <= d_B，将该标记重涂为红(2)；否则重涂为蓝(1)
3. 对每个腔室，从其内部的重涂后标记出发，4-连通洪泛填充：将腔室内所有黑(0)像素涂为该标记的新颜色。墙壁阻断填充扩展
4. 边缘线、墙壁像素保持不变

**关键洞察**：距离重涂在源题（2204b7a8）中是最终变换，此处它成为填充操作的颜色决策前置步骤。核心张力在于：距离度量无视墙壁（纯几何），但填充受墙壁约束（拓扑）——一个标记可能几何上离红边更近但被墙壁围在右半区的腔室里，使整个右侧腔室被涂红，产生反直觉的空间效果
