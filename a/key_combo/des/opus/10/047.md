## 新题 1：对齐筛选与距离排序同心重建

**组合逻辑**：[行列对齐](创新：用于筛选参与者而非射线延伸) + [排序](创新：按到锚点距离而非边长) + [同心层填充](保留) + [忽略干扰项](保留)

**来源原语**：行列对齐(d43fd935)、锚定方块(d43fd935, d89b689b)、排序(c658a4bd)、同心层填充(c658a4bd)、忽略干扰项(0a2355a6, be94b721)

**依赖链**：对齐检测的结果决定哪些颜色进入同心重建的候选集；距离计算的结果决定候选颜色的环层顺序；两者缺一则无法确定输出。

从散布的彩色单像素中，仅选取与中央锚块行列对齐的像素，按它们到锚块的曼哈顿距离排序后，以对应颜色画出同心方环。

**输入结构**：黑(0)背景，约 15x15 网格。中央有一个 2x2 的灰(5)锚定方块。周围散布 6~8 个不同颜色的单像素点（从蓝(1)、红(2)、绿(3)、黄(4)、品红(6)、橙(7)、青(8)中选取，每色至多一个）。其中 3~5 个像素与锚块共享行或列（即位于锚块所占的两行或两列的延伸上），其余像素不与锚块对齐。生成约束：对齐像素到锚块中心的曼哈顿距离互不相同；对齐像素数量为奇数（保证有唯一中心层）。

**规则**：
1. 识别 2x2 灰(5)锚块，确定其占据的两行和两列。
2. 筛选：保留与锚块共享至少一行或一列的单像素；其余像素视为干扰项，输出中擦除为黑(0)。
3. 对筛选出的像素，计算每个到锚块中心（2x2 块的几何中心取左上角像素坐标）的曼哈顿距离，按距离从大到小排序。
4. 以锚块中心为中心，画出 N 层同心方环（N = 筛选出的像素数）。最外层环的半边长为 N，次外层为 N-1，以此类推，最内层为 1（即中心单像素）。
5. 距离最大的像素颜色画最外层环，距离最小的画最内层。锚块本身被同心环覆盖。
6. 输出网格尺寸调整为刚好容纳所有同心环的最小正方形（边长 = 2N+1 如果 N 层时最外半边长为 N；实际边长 = 2*筛选像素数 - 1）。

**关键洞察**：非对齐像素是干扰项，对齐关系是进入同心重建的门票；环层顺序由原始距离（而非颜色编号或面积）决定，需对比多个示例才能确认筛选规则和排序依据。

## 新题 2：图元分解定角色的迷宫寻路

**组合逻辑**：[分解](保留) + [寻路/最短路径](创新：端点由分解结果中的特定图元类型决定) + [填充](创新：填充路径而非区域) + [图元形状决定涂色](创新：形状决定寻路角色而非颜色)

**来源原语**：分解(150deff5)、基本图元(150deff5)、寻路(3ad05f52)、最短路径(3ad05f52)、填充(3ad05f52)、图元形状决定涂色(150deff5)

**依赖链**：分解操作产出两类图元；图元类型决定寻路中的角色（端点 vs 障碍）；只有完成分解才能确定路径起终点，只有完成寻路才能确定填充位置。

将灰色连通区域分解为 2x2 方块和 1x3 条块后，方块作为寻路端点、条块作为额外障碍，在剩余背景通道中找到连接所有方块的最短路径并填充。

**输入结构**：黑(0)背景，约 18x18 网格。灰(5)前景像素形成一个或多个 4-连通区域。每个区域可无重叠地分解为若干 2x2 方块和若干 1x3 或 3x1 条块（两种图元混合）。灰色区域之间由黑色通道（宽度至少 1 像素）分隔。生成约束：方块总数为 2~4 个；分解方案唯一；任意两个方块之间在将条块视为障碍后仍存在至少一条 4-连通通路。

**规则**：
1. 将所有灰(5)像素分解为不重叠的 2x2 方块和 1x3/3x1 条块（分解唯一）。
2. 将所有 2x2 方块重涂为青(8)，标记为寻路端点。
3. 将所有 1x3/3x1 条块重涂为红(2)，标记为障碍（不可通行）。
4. 在黑(0)背景像素中（条块和方块占据的像素均不可通行），找到连接所有青色方块的最小 Steiner 树路径（4-连通，像素级，最少总像素数）。
5. 将 Steiner 树路径上的黑色像素填充为绿(3)。
6. 其余像素保持不变。

**关键洞察**：分解不是为了涂色——图元的几何形状决定了它在拓扑网络中的角色（端点还是墙），这个角色分配只有通过对比多个示例（观察方块总被连接、条块总被绕过）才能归纳。

## 新题 3：孔洞拓扑编码射线方向与几何编码射线颜色

**组合逻辑**：[射线延伸](创新：方向由孔洞数量编码) + [孔洞计数→映射](创新：映射目标从颜色变为方向) + [孔洞几何决定填充](创新：决定射线颜色而非是否填充) + [首个障碍](保留)

**来源原语**：射线延伸(9f8de559, d43fd935)、封闭区域/孔洞(0a2355a6, 44d8ac46)、按孔洞数映射颜色(0a2355a6)、孔洞几何决定填充(44d8ac46)、首个障碍(9f8de559)

**依赖链**：必须先识别每个对象的孔洞数量才能确定射线方向；必须分析孔洞几何才能确定射线颜色；方向和颜色缺一则输出不确定。

每个带孔洞的灰色对象从其包围框中心发射一条射线：孔洞数量决定方向（上/右/下/左），孔洞是否为正方形决定射线颜色。

**输入结构**：黑(0)背景，约 16x16 网格。3~5 个灰(5)的 4-连通对象，互不相邻（包围框间距至少 2 像素）。每个对象内部包含 1~4 个封闭的黑(0)孔洞（4-连通黑色区域被灰色完全包围）。每个对象的所有孔洞要么全部是正方形（包围框为正方形且完全填满），要么全部非正方形。生成约束：不同对象的孔洞数量互不相同（保证方向映射无冲突）；每个对象从包围框中心沿对应方向到网格边界的路径上，第一个非黑非本对象像素的位置确定（即射线会遇到另一个对象或网格边界）。

**规则**：
1. 识别所有灰(5)的 4-连通对象及其内部封闭黑色孔洞。
2. 方向映射：1 个孔洞 → 向上，2 个 → 向右，3 个 → 向下，4 个 → 向左。
3. 颜色判定：若该对象的孔洞全为正方形 → 射线颜色为红(2)；若孔洞非正方形 → 射线颜色为蓝(1)。
4. 从每个对象包围框中心像素出发，沿确定方向逐像素延伸射线，遇到第一个非黑(0)像素时停止（不包含该终点像素）。
5. 射线像素涂为步骤 3 确定的颜色。灰色对象本身保持不变。
6. 若射线起点（包围框中心）本身是灰色像素，射线从该像素的下一个像素（沿方向）开始绘制。

**关键洞察**：同一子结构（孔洞）的两个不同属性（数量和几何形状）分别编码了射线的两个独立参数（方向和颜色），必须同时正确解码才能产生正确输出。

## 新题 4：包含关系触发局部十字擦除

**组合逻辑**：[十字擦除](创新：作用域从全局限定为容器内部) + [包围框包含](创新：用于确定擦除者而非删除目标) + [异色包含则删](创新：不删除而是转化为擦除器) + [特定色像素豁免](保留)

**来源原语**：十字擦除(319f2597)、包围框包含(9720b24f)、异色包含则删(9720b24f)、特定色像素豁免(319f2597)、标记块(319f2597)

**依赖链**：必须先通过包围框包含关系识别哪些小对象充当擦除器、哪些大对象是被擦除的画布；然后在每个画布内部独立执行十字擦除，受保护色约束。移除包含检测则不知道谁擦谁；移除十字规则则不知道擦什么形状。

被大对象的包围框包含的小对象，在大对象内部执行十字擦除（擦除小对象所在行列与大对象重叠的像素），但红色像素豁免。

**输入结构**：黑(0)背景，约 20x20 网格。2~3 个大的单色 8-连通对象（颜色各不相同，从蓝(1)、绿(3)、黄(4)中选），每个面积 30~60 像素，形状为不规则但大致矩形的块状。每个大对象内部包含 1~2 个小的单色对象（2x2 像素，颜色与容器不同，从橙(7)、青(8)、品红(6)中选）。"包含"定义：小对象的包围框完全在大对象的包围框内部。此外，大对象中散布少量红(2)像素（3~5 个）。生成约束：每个小对象的行和列在大对象包围框范围内至少穿过 3 个大对象像素（保证擦除可见）。

**规则**：
1. 找到所有 8-连通单色非黑对象，按面积分为大对象和小对象（面积 > 20 为大，<= 4 为小）。
2. 对每个小对象，检查其包围框是否被某个大对象的包围框完全包含。若是，该小对象成为该大对象的"擦除器"。
3. 对每个大对象，取其所有擦除器。对每个擦除器：确定擦除器占据的所有行和所有列。
4. 在大对象的包围框范围内，将这些行和列上属于大对象的像素重涂为黑(0)——但红(2)像素豁免（保持红色不变）。
5. 擦除器像素本身也被清除为黑(0)。
6. 不被任何大对象包含的小对象保持不变（作为干扰项）。

**关键洞察**：包含关系不再意味着"删除被包含者"，而是将被包含者转化为擦除工具——角色完全反转；且擦除的作用域严格限定在容器内部而非全网格，需要对比示例才能确认这一局部性。

## 新题 5：图例编码空间变换的瓦片铺设

**组合逻辑**：[平铺](保留) + [镜像](保留) + [颜色图例](创新：编码空间变换类型而非重涂颜色) + [编码映射](创新：颜色→变换而非颜色→颜色) + [阵列排布](保留)

**来源原语**：平铺(00576224)、镜像(00576224, 7ed72f31)、颜色图例(fafd9572)、编码映射(7ed72f31)、阵列排布(00576224)、排位对应(fafd9572)

**依赖链**：必须先解读图例中每个颜色对应的变换类型；再将变换应用于瓦片的对应位置。图例解读错误则整个铺设结果错误；不铺设则图例无处施展。

输入含一个小瓦片和一列彩色图例像素；图例每个像素的颜色编码一种空间变换，瓦片按 3x3 阵列铺设时，每行的变换方式由图例对应行的颜色决定。

**输入结构**：黑(0)背景，约 10x10 网格分为两个区域。左侧：一个 3x3 的彩色瓦片（使用 2~4 种非黑颜色，图案不对称以便区分变换）。右侧：一列 3 个纵向排列的单像素，颜色取自蓝(1)、红(2)、绿(3)、黄(4)四种（可重复）。瓦片与图例由至少 2 列黑色间隔。生成约束：瓦片图案在水平镜像和 180 度旋转下均与原图不同（保证变换可区分）。

**规则**：
1. 识别 3x3 瓦片和 3 个图例像素（图例从上到下分别对应输出的第 1、2、3 瓦片行）。
2. 颜色-变换映射：蓝(1) = 保持原样，红(2) = 水平镜像（左右翻转），绿(3) = 垂直镜像（上下翻转），黄(4) = 旋转 180 度。
3. 构建输出：3 行 x 3 列瓦片阵列（输出为 9x9）。每行 3 个瓦片相同，均为原始瓦片经该行对应变换后的结果。
4. 输出仅包含 9x9 的瓦片阵列，不保留图例。

**关键洞察**：图例像素的颜色不是"涂什么色"的指令，而是"做什么变换"的编码——语义层面从属性映射跃迁为操作映射，必须对比多个示例（观察同一图例颜色在不同瓦片内容下的效果一致性）才能建立映射。

## 新题 6：拓扑条件决定缩放表示的象限归位

**组合逻辑**：[缩小复制](创新：条件性缩放，有孔洞则退化为单像素) + [象限对应](保留) + [锚定方块](创新：从 2x2 扩展为 4x4 以容纳缩放结果) + [孔洞几何决定填充](创新：决定表示方式而非填充颜色)

**来源原语**：缩小复制(11e1fe23)、象限对应(d89b689b)、锚定方块(d89b689b)、象限决定目标格(d89b689b)、封闭区域/孔洞(44d8ac46)、孔洞几何决定填充(44d8ac46)

**依赖链**：必须先分析每个精灵体是否含孔洞来决定表示方式（缩放 vs 单像素）；再根据象限位置确定放置位置。拓扑分析决定"画什么"，象限检测决定"画在哪"，两者独立但缺一不可。

四个象限各有一个彩色小精灵体围绕中央 4x4 灰色锚块分布；无孔精灵体缩小为 2x2 放入锚块对应象限，有孔精灵体仅以单色像素代表。

**输入结构**：黑(0)背景，约 14x14 网格。中央有一个 4x4 的灰(5)方块作为锚定区域。四个象限（左上、右上、左下、右下）各有一个 4-连通的小精灵体（4~8 像素），颜色各不相同（从蓝(1)、红(2)、绿(3)、黄(4)中选）。精灵体的包围框不超过 4x4。部分精灵体内部有一个封闭的黑色孔洞（至少 1 像素），部分没有。生成约束：恰好 2 个有孔洞、2 个无孔洞；无孔洞的精灵体可以无歧义地缩小为 2x2（即其形状在 2x2 像素中有唯一的最佳近似：保留四个象限中像素数最多的颜色）。

**规则**：
1. 识别 4x4 灰(5)锚块和四个彩色精灵体。根据精灵体中心相对于锚块中心的位置确定象限归属。
2. 对每个精灵体检测是否存在封闭黑色孔洞（被精灵体像素完全 4-连通包围的黑色区域）。
3. 无孔洞精灵体：将其包围框内容等比缩小为 2x2（每个 2x2 目标像素取对应源区域中精灵体颜色像素数 >= 背景像素数则填精灵体颜色，否则填黑(0)）。将 2x2 结果放入锚块对应象限的 2x2 子区域。
4. 有孔洞精灵体：仅在锚块对应象限的 2x2 子区域中心偏左上的那个像素填入精灵体颜色（即 2x2 子区域的左上角像素），其余 3 像素保持灰(5)。
5. 清除输入中所有精灵体像素为黑(0)。输出仅保留修改后的锚块和黑色背景。

**关键洞察**：同样是象限归位，精灵体的拓扑属性（有无孔洞）决定了它在目标区域中的表示精度——无孔者保留 2x2 形态信息，有孔者退化为单像素标记。表示方式的二分规则需要对比多个示例才能归纳。

## 新题 7：散布帧重心排序与叠加优先级冲突

**组合逻辑**：[同心层填充](创新：重新居中后产生新重叠) + [排序](创新：排序键为原始位置到网格中心的距离而非尺寸) + [透明叠加](创新：叠加优先级与嵌套顺序相反) + [面积比较](保留)

**来源原语**：同心层填充(c658a4bd)、排序(c658a4bd)、透明叠加(7ed72f31)、面积比较(be94b721)、按边长降序排列(c658a4bd)、嵌套层次(c658a4bd)

**依赖链**：先按边长确定嵌套层次（大在外）进行同心重建；但重叠处的绘制优先级由原始距离决定而非层次——两种排序可能冲突，冲突解决规则是核心难点。

多个不同大小的彩色正方形框散布在网格中，重新居中为同心环后，重叠像素的颜色由框的原始重心到网格中心的距离决定（近者优先）。

**输入结构**：黑(0)背景，约 17x17 网格。4~5 个不同颜色的单像素厚度正方形空心框（仅边框，内部透明/黑色），边长分别为 3、5、7、9、11（或其子集），颜色从蓝(1)、红(2)、绿(3)、黄(4)、橙(7)中选取，各不相同。框在输入中散布于不同位置，可能部分重叠。生成约束：框的边长互不相同；框的重心到网格中心的距离互不相同；存在至少两对框在同心重建后会共享像素（即它们的边长差为 2 时外框和内框的边恰好相邻或重合）。

**规则**：
1. 识别所有单像素厚度正方形空心框，记录每个框的颜色、边长、原始重心坐标。
2. 按边长从大到小排序，确定嵌套层次：最大的在最外层。
3. 以输出网格中心为公共中心，按嵌套层次绘制同心方环：最外层半边长 = (最大边长-1)/2，依次向内每层边长减小。输出网格边长 = 最大框边长。
4. 从最外层到最内层依次绘制。若某像素已被之前绘制的层着色，则比较两层的原始重心到网格中心的距离：距离更小的颜色胜出（保留）。
5. 即：绘制时若当前层的原始重心更近则覆盖已有颜色；否则跳过该像素。
6. 背景像素保持黑(0)。

**关键洞察**：嵌套顺序（由大小决定）和覆盖优先级（由原始位置决定）是两个独立的排序，当一个大而远的框与一个小而近的框在角落共享像素时，近者胜出——这种"位置记忆"规则必须对比多个示例中的冲突像素才能发现。

## 新题 8：路径长度奇偶性决定模板色传递

**组合逻辑**：[寻路/最短路径](保留) + [框架色传递同形](创新：传递条件增加路径奇偶约束) + [尺寸匹配](保留) + [重涂色](保留)

**来源原语**：寻路(3ad05f52)、最短路径(3ad05f52)、框架色传递同形(890034e9)、尺寸匹配(890034e9)、空心矩形/rectangular_frame(890034e9)、走廊通道(3ad05f52)

**依赖链**：必须先完成寻路得到路径长度；路径长度的奇偶性决定传递哪种颜色；无路径则无法判断颜色选择，无模板则无颜色可传递。

模板矩形框的颜色通过迷宫路径传递给同尺寸的空窗口，但奇数路径长度传框色，偶数路径长度传框内填充色。

**输入结构**：黑(0)背景，约 20x20 网格。一个完整的单色矩形空心框（"模板"，如蓝(1)，尺寸 4x4 外框内部 2x2），框内部 2x2 区域填充另一颜色（如红(2)）。网格中另有 2~3 个同外框尺寸（4x4）的区域，其边框为灰(5)、内部为黑(0)（"空窗口"）。灰(5)像素构成迷宫墙壁连接各处，形成宽度为 1 的通道网络。生成约束：从模板框到每个空窗口存在唯一最短路径（4-连通，通过黑色通道像素）；不同窗口的最短路径长度奇偶性不全相同（至少一个奇数一个偶数）。

**规则**：
1. 识别模板：唯一的非灰非黑色完整矩形框（蓝(1)边框），记录其尺寸和内部填充色（红(2)）。
2. 识别空窗口：与模板外框同尺寸、边框为灰(5)、内部全为黑(0)的矩形。
3. 对每个空窗口，计算从模板框边界任一像素到该窗口边界任一像素的最短 4-连通路径长度（只经过黑(0)像素）。
4. 若最短路径长度为奇数：将该窗口的灰(5)边框重涂为模板框色蓝(1)。
5. 若最短路径长度为偶数：将该窗口的灰(5)边框重涂为模板内部填充色红(2)。
6. 窗口内部保持黑(0)。路径本身不可视化（不填充）。模板保持不变。

**关键洞察**：模板同时携带两种颜色信息（框色和内部色），路径长度的奇偶性——一个数论属性——决定传递哪种颜色。这个判据无法从单个示例归纳（一个示例只展示一种情况），需要对比奇偶不同的窗口才能发现。

## 新题 9：对角连线涌现封闭区域后按边数填色

**组合逻辑**：[连线/connect](保留) + [对角对齐](保留) + [封闭区域](创新：由连线涌现而非预存) + [填充](保留) + [计数→颜色映射](创新：计数对象从孔洞变为边界线段数)

**来源原语**：连线(db695cfb)、对角像素对(db695cfb)、对角对齐(db695cfb)、封闭区域(0a2355a6, 44d8ac46)、填充(44d8ac46)、按孔洞数映射颜色(0a2355a6)

**依赖链**：必须先完成所有对角连线才能确定哪些区域被封闭；必须数每个封闭区域的边界段数才能确定填充颜色。连线结果直接决定封闭区域的存在和形状——典型的涌现效应。

同色对角像素对之间画对角线段，这些线段在网格中划分出若干封闭区域；每个封闭区域根据其边界上不同颜色线段的数量被填充对应颜色。

**输入结构**：黑(0)背景，约 13x13 网格。若干彩色单像素散布在网格中，颜色使用蓝(1)和绿(3)两种。同色像素两两配对，每对恰好位于同一条 45 度对角线上（即行差绝对值 = 列差绝对值）。生成约束：所有配对的对角线段（连接同色像素对的 45 度线段）在网格内部围出 2~4 个封闭区域（封闭区域定义：被对角线段和/或网格边界完全包围的连通黑色区域）；蓝色对数 2~3，绿色对数 2~3；线段之间可以交叉。

**规则**：
1. 识别所有同色对角像素对（同色且行差绝对值 = 列差绝对值的两个像素为一对）。每个颜色的像素数为偶数，按距离最近原则配对（若有歧义则按左上优先配对）。
2. 在每对之间画对角线段：沿 45 度方向逐像素填充该对的颜色（包含端点）。
3. 线段绘制完成后，识别被线段和网格边界完全封闭的黑(0)连通区域（4-连通）。仅保留面积 >= 3 像素的封闭区域。
4. 对每个封闭区域，统计其边界上接触的不同颜色线段数量（只看蓝和绿两色，接触定义为区域边界像素的 8-邻域中存在该色线段像素）：
   - 仅接触蓝色线段 → 填充黄(4)
   - 仅接触绿色线段 → 填充红(2)
   - 同时接触蓝和绿色线段 → 填充橙(7)
5. 线段像素保持其颜色不变。非封闭区域（连通到网格边界的黑色区域）保持黑(0)。

**关键洞察**：对角连线本身不带有"封闭"的意图，但多条线交叉后涌现出封闭区域——求解者必须先完成所有连线才能看到分区结果，再根据边界接触的线色组合来确定填充色，这是典型的涌现效应。

## 新题 10：轨迹方向编码镜像类型

**组合逻辑**：[镜像](保留) + [轨迹](创新：编码反射类型而非射线方向) + [反向投射/方向推断](创新：推断的不是射线方向而是反射轴朝向) + [精灵体](保留) + [擦除](创新：擦除轨迹而非障碍)

**来源原语**：镜像(7ed72f31)、反射轴标记(7ed72f31)、轨迹(9f8de559)、反向投射(9f8de559)、精灵体(7ed72f31)、擦除(9f8de559)、标记几何定类型(7ed72f31)

**依赖链**：必须先识别轨迹方向才能确定反射类型；必须知道反射类型才能正确镜像精灵体；轨迹移除后输出中无方向提示——方向信息被"消费"后消失。

每个精灵体旁附带一条短轨迹，轨迹的朝向编码镜像类型：水平轨迹意味着垂直镜像，垂直轨迹意味着水平镜像，对角轨迹意味着点反射。镜像后轨迹被擦除。

**输入结构**：黑(0)背景，约 16x16 网格。3~4 个不同颜色的小精灵体（4-连通，5~8 像素，不对称形状），颜色从蓝(1)、绿(3)、黄(4)、橙(7)中选取。每个精灵体的 8-邻域中有一条红(2)短轨迹（3 个红像素排成直线：水平/垂直/45度对角）。轨迹的一端与精灵体相邻（8-连通）。生成约束：精灵体之间间距足够大（包围框间距 >= 4），使得镜像后的像素不会与其他精灵体重叠；精灵体形状在水平镜像、垂直镜像、点反射下结果互不相同。

**规则**：
1. 识别每个非黑非红的 4-连通精灵体，及其相邻的红(2)轨迹（3 像素直线段）。
2. 判定轨迹方向：
   - 水平排列（3 像素同行）→ 反射类型为垂直镜像（沿精灵体包围框的水平中轴翻转）
   - 垂直排列（3 像素同列）→ 反射类型为水平镜像（沿精灵体包围框的垂直中轴翻转）
   - 对角排列（3 像素在 45 度线上）→ 反射类型为点反射（绕精灵体包围框中心旋转 180 度）
3. 对每个精灵体执行对应的镜像变换。镜像结果覆盖写入（原始精灵体像素被替换为镜像后的图案，保持包围框位置不变）。
4. 擦除所有红(2)轨迹像素为黑(0)。
5. 其余像素保持不变。

**关键洞察**：轨迹的几何朝向（而非颜色或长度）是变换类型的密钥——水平轨迹触发垂直操作、垂直轨迹触发水平操作，这种"正交编码"关系需要对比多个示例中不同轨迹朝向与对应镜像效果才能归纳。
