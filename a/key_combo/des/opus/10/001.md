## 新题 1：对称补全障碍场中的路径生长

**组合逻辑**：[对称补全](从 2546ccf6 的格元镜像改为障碍像素镜像) + [路径生长](已有) + [障碍偏转](已有，但偏转对象由补全结果动态决定)

**来源原语**：对称补全/symmetry_completion (2546ccf6)、镜像/mirror (2546ccf6)、路径生长/path_grow (712bf12e)、障碍偏转/obstacle_deflection (712bf12e)、三存一缺推断/infer_missing_from_three (2546ccf6)、分割线/divider_line (2546ccf6)、控制像素/control_pixel (712bf12e)、障碍块/blocker (712bf12e)

**依赖链**：对称补全的输出（第四象限的障碍位置）直接决定路径生长在该象限的偏转行为——路径在三个已知象限中的走向可以直接观察，但在第四象限中的走向必须先完成对称推断才能确定。两个逻辑共享同一组障碍像素，删除任一环节都无法独立求解。

将部分隐藏的障碍场通过镜像对称补全，再从底部控制像素向上生长路径，路径在完整障碍场中逐步偏转。

**输入结构**：黑(0)背景网格，约 15x15。灰(5)分割线将网格分为 2x2 的四个等大矩形格元（一条水平线、一条垂直线交叉）。其中三个格元内散布着绿(3)障碍像素（每个格元 3~6 个，位置不规则），第四个格元为空（仅有黑色背景）。四个格元中障碍图案满足：三个已知格元的障碍位置是第四个格元障碍位置的水平/垂直镜像，即任取三个可唯一推断第四个。红(2)控制像素位于网格最底行，每个控制像素所在列贯穿至少一个已知障碍格元和缺失格元。控制像素 2~3 个，列位置互不相同。生成约束：补全后的障碍不与控制像素同列同行；每条路径至少经历一次偏转。

**规则**：
1. 识别灰(5)分割线，将网格分为 2x2 的四个格元。找到无障碍的空格元。
2. 根据其余三个格元中绿(3)障碍像素的位置，通过水平和/或垂直镜像推断空格元中的障碍位置（与 2546ccf6 的三存一缺推断相同），将推断出的障碍像素绘制为绿(3)。
3. 从每个红(2)控制像素出发，向上逐格生长路径：若正上方一格为黑(0)背景，则将其涂为红(2)并从该格继续；若正上方一格为绿(3)障碍，则向右平移一格，若该格为黑(0)背景则涂为红(2)并从该格继续向上；若右移目标不可用（越界、非背景或为灰分割线），则该路径终止。
4. 路径穿越灰(5)分割线时直接跳过分割线所在行（视分割线为透明通道，不在分割线格上涂色），继续在分割线另一侧的格元中按相同规则生长。
5. 路径到达网格顶行后终止。多条路径互不干扰（生成约束保证路径不相交）。

**关键洞察**：第四象限的障碍是隐藏的——三个可见象限的对称关系编码了第四象限的障碍布局。路径在可见象限中的偏转可以直接观察验证，但在隐藏象限中的偏转是对称补全正确性的唯一证据。必须同时掌握对称推断规则和路径偏转规则才能求解。

## 新题 2：射线分区与归属洪填充

**组合逻辑**：[射线延伸](已有) + [洪填充](已有，但填充颜色由射线归属分析决定——源题无此逻辑) + [异源交叉特殊着色](已有，作为归属判定的排除条件)

**来源原语**：射线延伸/ray_extend (45bbe264)、填充/flood_fill (8b7bacbf)、行列交叉/row_column_crossing (45bbe264)、异源交叉特殊着色/cross_source_special_color (45bbe264)、连通可达/connectivity_reachable (8b7bacbf)、封闭腔体/enclosed_cavity (8b7bacbf)、种子色标记填充/seed_color_labels_fill (8b7bacbf)、标记像素/marker_pixel (45bbe264)

**依赖链**：射线延伸同时产生两个结果——分区墙壁和墙壁归属信息。洪填充的触发条件（区域是否唯一归属于某标记）依赖于射线交叉模式，而射线交叉模式又取决于标记的空间布局。三个逻辑环节（射线、交叉判定、归属填充）形成非线性依赖：射线结果同时被交叉判定和填充规则消费。

标记像素发射全行全列射线形成分区墙壁，再根据各区域边界的射线归属决定洪填充颜色。

**输入结构**：黑(0)背景网格，约 13x13。3~4 个孤立的单色标记像素，颜色各不相同，均为非红(2)非黑(0)的颜色（如蓝(1)、绿(3)、黄(4)、品红(6)中选取）。标记像素的行和列互不相同。网格中另有若干灰(5)墙壁像素，形成短线段（长 2~4 像素），部分阻断射线传播路径。生成约束：标记数量和灰墙位置保证至少产生 2 个可唯一归属的封闭区域和 1 个不可归属的区域。

**规则**：
1. 从每个标记像素出发，向上、下、左、右四个方向延伸射线。射线沿途每格涂为该标记的颜色，直到遇到灰(5)墙壁像素或网格边缘时停止（不覆盖灰墙，不越过灰墙）。标记像素自身保持原色。
2. 若某格同时被两个不同标记的射线覆盖（一个来自行方向、一个来自列方向，或两条不同方向的射线重合），则该格涂为红(2)。
3. 射线（含红色交叉格）+ 灰墙 + 网格边缘将背景分割为若干封闭区域。对每个封闭区域，检查其边界上所有非灰、非红的射线像素颜色：若边界上仅出现一种标记颜色，则用该颜色洪填充该区域；若边界上出现两种及以上标记颜色（或边界上仅有灰墙和红色交叉而无单色射线），则该区域保持黑(0)不填充。
4. 灰(5)墙壁像素、标记像素、射线像素（含红色交叉格）均保持不变，仅黑色封闭区域被填充。

**关键洞察**：灰墙不仅阻断射线传播（改变分区拓扑），还改变了射线到达区域边界的颜色分布——移动一段灰墙可能使某区域从"唯一归属"变为"多重归属"或反之，从而翻转该区域是否被填充。红色交叉格是归属判定的"盲区"，不计入任何标记的归属。

## 新题 3：地形轮廓裁切下的距离梯度填充

**组合逻辑**：[延伸填充](从顶部向下生长，改为受地形裁切) + [重涂色](已有，但触发条件改为"填充是否被地形截断") + [列高度极值](已有，与延伸高度公式交互产生新判定)

**来源原语**：延伸填充/extension_fill (5207a7b5)、重涂色/recolor (e45ef808)、地形轮廓/terrain_contour (e45ef808)、纵条/vertical_bar (5207a7b5)、距离控制高度/distance_controls_height (5207a7b5)、不对称递变/asymmetric_gradient (5207a7b5)、列高度极值/column_height_extreme (e45ef808)、最深与最浅列唯一/unique_deep_shallow (e45ef808)

**依赖链**：延伸填充的目标高度由距离公式决定，但实际高度被地形轮廓裁切。重涂色的触发条件是"实际高度 < 目标高度"（即被裁切），这需要同时知道距离公式和地形高度才能判定。三者形成约束满足结构：距离公式、地形轮廓、裁切判定必须同时成立。

灰色纵条向两侧产生不对称高度梯度的彩色填充，填充遇到底部地形轮廓时被截断，被截断的列发生重涂色。

**输入结构**：黑(0)背景网格，约 18x12。底部区域（约占下方 1/3）有绿(3)地形轮廓——每列从底行向上有连续的绿色像素，各列高度不同（形成山丘状起伏，高度范围 1~5 行）。顶行有一根灰(5)纵条（1 像素宽，从第 0 行向下延伸 3~5 格），位于网格中部偏左或偏右。纵条左右两侧各至少有 3 列空间。生成约束：纵条高度和地形高度的组合保证至少有 1 列被裁切、至少有 1 列未被裁切；地形最高点和最低点各唯一。

**规则**：
1. 保留灰(5)纵条和绿(3)地形轮廓不变。
2. 设纵条高度为 H（纵条占据的行数）。对纵条左侧距离为 d（d=1,2,3,...）的每一列，计算目标填充高度 T = H + 2*d。从该列第 0 行起向下填充青(8)色，实际填充行数为 min(T, 该列地形顶部行号)（即填充到地形表面或目标高度，取较小者）。
3. 对纵条右侧距离为 d 的每一列，计算目标填充高度 T = H - 2*d。若 T <= 0 则不填充。否则从该列第 0 行起向下填充品红(6)色，实际填充行数为 min(T, 该列地形顶部行号)。
4. 对每一列（左侧和右侧均适用），若实际填充高度 < 目标填充高度（即填充被地形截断），则将该列的填充颜色整体替换为橙(7)。未被截断的列保持原色（青或品红）。
5. 填充不覆盖绿(3)地形像素，不覆盖灰(5)纵条像素。

**关键洞察**：填充颜色不仅取决于列在纵条的哪一侧（左青右品红），还取决于地形是否截断了该列的理论高度。同一侧的相邻列可能因地形起伏而呈现不同颜色（被截断的橙色 vs 未截断的原色），这要求求解者同时推断距离公式和地形裁切规则。

## 新题 4：颜色导航滑动与邻域标记

**组合逻辑**：[平移/滑动](已有，方向由颜色决定) + [描边/mark_neighbors](已有，但邻域类型由滑动距离决定——源题无此逻辑) + [行重叠内移](已有，作为冲突解决)

**来源原语**：平移/translate (b5ca7ac4)、滑动/sliding (ae3edfdc)、描边/mark_neighbors (0ca9ddb6)、颜色决定目标/color_determines_destination (b5ca7ac4)、对角邻接/diagonal_adjacency (0ca9ddb6)、正交邻接/orthogonal_adjacency (0ca9ddb6)、标记色选邻域几何/marker_color_selects_neighborhood (0ca9ddb6)、行重叠内移/row_overlap_shifts_inward (b5ca7ac4)、距离优先排序/distance_priority_ordering (b5ca7ac4)

**依赖链**：滑动的目标位置决定了每个方块最终在哪里，这直接决定了描边的像素位置。同时，滑动距离（方块移动了多少格）决定了描边使用对角邻域还是正交邻域。行重叠内移改变了最终位置，进而改变了滑动距离和邻域类型选择。三个逻辑互相约束：位置 -> 距离 -> 邻域类型，且冲突解决改变位置。

彩色小方块按颜色滑向指定网格边缘，到达后根据滑动距离的奇偶性选择对角或正交邻域进行标记。

**输入结构**：黑(0)背景网格，约 15x15。散布 4~6 个 3x3 单色实心小方块，颜色为蓝(1)或红(2)。方块之间互不相邻（边界框间隔至少 1 格）。无其他前景元素。生成约束：蓝方块按列位置从左到右处理，红方块按列位置从右到左处理；冲突解决后所有方块无重叠；至少有一对同色方块发生行重叠。

**规则**：
1. 蓝(1)方块向左滑动至网格左边缘（方块左边与第 0 列对齐），保持原始行位置不变。红(2)方块向右滑动至网格右边缘（方块右边与最后一列对齐），保持原始行位置不变。
2. 同色方块按距离目标边缘从近到远的顺序依次处理。若某方块滑动后其行范围与已放置的同侧方块行范围有重叠，则该方块向内移动一个方块宽度（3 格）放置（即蓝方块改为左边与第 3 列对齐，红方块改为右边与倒数第 4 列对齐）。
3. 计算每个方块的滑动距离 D = |最终列位置 - 原始列位置|（取方块左上角列坐标之差的绝对值）。
4. 若 D 为奇数，在该方块的四个角像素的对角邻位（即方块外部的四个对角方向各一格）涂黄(4)（仅在网格范围内且为黑色背景的位置涂色）。若 D 为偶数，在该方块四条边的中点像素的正交邻位（即方块外部的上下左右各一格，每条边中点一个）涂橙(7)（同样仅在背景位置涂色）。
5. 方块本身保持原色不变。邻域标记不覆盖任何方块像素。

**关键洞察**：行重叠内移不仅改变方块的最终位置，还改变了滑动距离的奇偶性，从而翻转该方块的邻域标记类型（对角 vs 正交）。仅观察颜色和最终位置不足以推断标记类型——必须回溯原始位置计算滑动距离。

## 新题 5：分区压缩驱动的螺旋调色板填充

**组合逻辑**：[压缩/downscale](已有) + [填充/cyclic_color_bands](已有，但调色板来源从标记像素改为压缩结果) + [网格采样](已有，但采样结果的空间排列编码调色板顺序——源题无此二次利用)

**来源原语**：压缩/downscale (90c28cc7)、填充/flood_fill (13e47133)、矩形分区/rectangular_partition (90c28cc7)、同心正方形层/concentric_square_layers (13e47133)、网格采样/grid_sampling (90c28cc7)、距离决定调色板/distance_determines_palette (13e47133)、每分区缩为单像素/each_partition_reduced_to_one_pixel (90c28cc7)、循环色带/cyclic_color_bands (13e47133)、分割线/divider_line (2546ccf6)

**依赖链**：压缩结果是一个小色彩矩阵，其内容和空间排列共同编码了调色板——内容提供颜色集合，空间排列（螺旋读取顺序）决定颜色在调色板中的次序。调色板再驱动同心环填充。删除压缩步骤则调色板未知；删除同心环填充则压缩结果无处应用。

左半区的矩形分区压缩为小色彩矩阵，按螺旋顺序读取为调色板，用该调色板以同心方环填充右半区的空白方阵。

**输入结构**：黑(0)背景网格，约 16x22（高 16，宽 22）。灰(5)垂直分割线将网格分为左右两半（各约 16x10）。左半区包含一个彩色矩形分区网格：由不同颜色的单色矩形块紧密拼接（无间隔），形成 N 行 M 列的分区（N, M 在 3~5 之间），各块大小可不同但同行等高、同列等宽。每块颜色从蓝(1)、红(2)、绿(3)、黄(4)、品红(6)、橙(7)、青(8)中选取，块间颜色可重复。右半区包含一个正方形空白区域（边长为左半区分区行列数的较大值的 2 倍 + 3，如分区为 3x4 则边长为 2*4+3=11），正方形边框用栗(9)色绘制（1 像素宽），内部为黑(0)。生成约束：右半区正方形完全在网格内；左半区分区至少包含 4 种不同颜色。

**规则**：
1. 对左半区矩形分区执行压缩：采样每个分区块左上角像素的颜色，生成一个 NxM 的小色彩矩阵。
2. 按螺旋顺序（从矩阵左上角出发，顺时针向内螺旋）读取小矩阵的所有颜色，形成一个长度为 N*M 的颜色序列，去除相邻重复色（若螺旋序列中连续两格颜色相同则只保留一个），得到最终调色板 P。
3. 在右半区的栗(9)色正方形内部填充同心方环：正方形内部每个像素计算其到正方形内边界的切比雪夫距离 d（最内层 d 最大）。将像素涂为 P[d mod len(P)]。
4. 栗(9)色边框保持不变。左半区和灰分割线保持不变。

**关键洞察**：左半区分区块的空间排列（而非仅颜色集合）决定了调色板顺序——相同颜色集合在不同空间排列下产生不同螺旋读取序列，进而产生不同的同心环图案。求解者必须同时推断压缩规则、螺旋读取方向和同心环填充规则。

## 新题 8：中位对齐线段构建洪填充边界

**来源原语**：对齐/align (e376de54)、裁剪/trim (e376de54)、填充/flood_fill (8b7bacbf)、线段/line_segment (e376de54)、封闭腔体/enclosed_cavity (8b7bacbf)、平行共向/parallel_codirectional (e376de54)、中位线为参考/median_as_reference (e376de54)、连通可达/connectivity_reachable (8b7bacbf)、种子像素/seed_pixel (8b7bacbf)

**依赖链**：对齐操作将分散的平行线段裁剪/延伸至统一范围，形成紧密排列的平行墙壁。这些墙壁加上网格边缘围成封闭区域。然后根据区域内预置种子像素的颜色进行洪填充。中位线的选择直接决定线段的最终长度，从而决定哪些区域被封闭、哪些区域连通——改变中位线就改变了填充拓扑。

平行线段按中位线参考对齐裁剪后形成封闭围栏，种子像素决定各围栏内的填充颜色。

**输入结构**：黑(0)背景网格，约 15x18。5~7 条水平线段（各 1 像素高），颜色均为灰(5)，沿垂直方向均匀分布（相邻线段间隔 2~3 行）。各线段起止列不同（长度 5~15 像素不等），但方向相同（均为水平）。在线段之间的若干黑色空隙区域中，各放置 1 个孤立的彩色种子像素（颜色从蓝(1)、红(2)、绿(3)、黄(4)中选取，颜色可重复），种子像素不与任何线段相邻。生成约束：中位线段（按行位置排序取中位数对应的线段）的长度严格介于最长和最短之间；对齐后至少产生 2 个被完全封闭的区域（由对齐后的线段端点、线段本身和网格左右边缘围成）和 1 个与网格上下边缘连通的非封闭区域。

**规则**：
1. 识别所有灰(5)水平线段，按行位置排序。取行位置的中位数对应的线段作为参考线段 R。
2. 将所有线段的起始列对齐到 R 的起始列，终止列对齐到 R 的终止列：比 R 长的线段被裁剪，比 R 短的线段被延伸（两端用灰(5)补齐），使所有线段等长且列范围相同。
3. 对齐后的平行线段形成水平栅栏。栅栏的左端和右端分别与线段起止列对应的垂直虚拟边界构成封闭区域的左右壁（即视线段的公共起止列为两道垂直墙壁）。相邻线段之间的空间若左右均被公共起止列封闭，则构成封闭区域。最上方线段之上和最下方线段之下的区域与网格上下边缘连通，视为非封闭。
4. 对每个封闭区域，若其中包含恰好一个种子像素，则用该种子的颜色洪填充整个封闭区域（4-连通，不穿越灰(5)线段）。若封闭区域无种子或有多个种子，则不填充。
5. 非封闭区域不填充。线段保持灰(5)。种子像素被填充色覆盖。

**关键洞察**：中位线段的长度决定了对齐后所有线段的统一范围，进而决定了封闭区域的宽度和位置。若中位线段较短，对齐后的栅栏较窄，可能使某些种子像素落在封闭区域外（不被填充）；若较长，则更多种子被封闭在内。参考线的选择是隐蔽规则——必须对比多个示例才能确认是中位线而非最长线或最短线。

## 新题 9：障碍偏转路径构建洪填充围栏

**组合逻辑**：[路径生长 + 障碍偏转](已有，但路径不是最终输出，而是围栏边界的构成部分) + [洪填充](已有，但填充边界由生长路径动态构建) + [种子色标记填充](已有，但种子与路径起点的对应关系通过行列对齐建立——源题无此关系)

**依赖链**：路径生长产生的偏转轨迹形成不规则的垂直隔墙，这些隔墙与网格边缘围成封闭区域。路径的偏转方向取决于障碍分布，障碍分布决定了封闭区域的形状。然后种子像素（与控制像素同行或同列的孤立像素）的颜色决定对应区域的填充色。三个逻辑形成链式依赖：障碍位置 -> 路径形状 -> 区域拓扑 -> 填充颜色。

**输入结构**：黑(0)背景网格，约 15x12。底行有 3~4 个灰(5)控制像素，列位置均匀分布。网格中散布绿(3)障碍像素（10~15 个，不在底行，不在顶行）。在底行的控制像素之间（不与控制像素相邻），放置 2~3 个彩色种子像素（蓝(1)、红(2)、黄(4)等，颜色各不相同）。生成约束：每个控制像素的路径至少偏转 1 次；路径到达顶行，路径之间不相交；相邻路径之间至少有 1 个种子像素；每个封闭区域内恰好有 1 个种子像素。

**规则**：
1. 从每个灰(5)控制像素向上生长路径：向上一格，若为黑(0)则涂灰(5)并继续；若为绿(3)障碍则向右移一格（若右移格为黑(0)则涂灰(5)并从该格继续向上；否则路径终止）。路径到达第 0 行时终止。
2. 生长后的灰色路径从底行到顶行形成竖向隔墙（可能带有因偏转产生的水平段）。
3. 相邻两条路径 + 底行 + 顶行围成一个封闭区域。最左路径与网格左边缘之间、最右路径与网格右边缘之间也各形成一个封闭区域。
4. 对每个封闭区域，找到其中唯一的彩色种子像素（非黑、非灰、非绿），用该种子颜色洪填充该区域内所有黑(0)像素（4-连通，不穿越灰路径、绿障碍和网格边缘）。
5. 控制像素和路径保持灰(5)，障碍保持绿(3)，种子像素被填充色覆盖。

**关键洞察**：路径因障碍偏转而产生的水平段改变了相邻区域的面积和形状——两个看似对称的区域因一侧路径多一次偏转而面积不同。种子像素的颜色归属取决于它落在哪两条路径之间，而路径的走向又取决于障碍分布。求解者必须先模拟路径生长才能确定区域划分和填充。

**依赖链**：标记像素的颜色同时控制两个变换：X 交叉线的颜色和切比雪夫环带的配色方案。X 交叉线占据了矩形内部的部分像素，环带填充仅作用于 X 未覆盖的剩余空间。两个变换共享矩形内部空间，且先后顺序影响最终图案——交叉线先绘制，环带填充时跳过已有交叉线像素。删除任一逻辑，剩余输出都不完整。

每个实心带标记矩形变为空心框 + 内部 X 交叉线 + 切比雪夫距离环带，标记颜色同时控制 X 颜色和环带配色。

**输入结构**：黑(0)背景网格，约 20x20。2~3 个灰(5)实心矩形，尺寸各异（宽高均为奇数，范围 7x7~11x11），互不重叠且间隔至少 2 格。每个矩形内部恰好嵌入 1 个标记像素，颜色各不相同（从蓝(1)、红(2)、绿(3)中选取），标记像素严格在矩形边框内部（不在边框行列上）。生成约束：矩形宽高均为奇数（保证中心唯一）；标记像素位置任意（不必在中心）。

**规则**：
1. 将每个灰(5)实心矩形替换为空心矩形框：仅保留边框一圈灰(5)像素，内部清为黑(0)。
2. 在每个空心矩形内部，用标记像素的颜色绘制 X 交叉图案：从内部四个角（紧邻边框的四个角像素）出发画 45 度对角线，线条在矩形中心交汇。若矩形宽高不等，交叉线在较短维度用完后终止（即从角出发的对角线到达行边界或列边界时停止）。中心像素（内部区域的几何中心）也涂为标记色。
3. 以矩形内部区域的几何中心为原点，计算内部每个像素到中心的切比雪夫距离 d。对于内部尚为黑(0)的像素（未被 X 交叉线覆盖的位置）：若 d 为偶数，涂为黄(4)；若 d 为奇数，保持黑(0)。
4. 标记像素在步骤 2 中已被 X 交叉线覆盖（标记色），不再额外处理。边框保持灰(5)。矩形外部保持黑(0)。

**关键洞察**：X 交叉线和切比雪夫环带在矩形内部交织——交叉线恰好穿过某些环带，形成彩色条纹打断黄色环的视觉效果。标记像素的原始位置不影响 X 的绘制方式（X 总是从角到中心），但标记颜色决定了 X 的视觉效果。求解者需要分辨哪些像素属于 X 交叉线（标记色）、哪些属于偶数距离环（黄色）、哪些是奇数距离间隙（黑色），三者交织在同一矩形内部。
