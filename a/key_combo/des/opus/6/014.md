## 新题 1：对角链连接性决定生长方向

**组合逻辑**：[重涂色(recolor)](用于分类标记) + [对角链式连接(diagonal_chain)](创新：从分类判据变为方向编码) → [生长(grow)](创新：沿对角轴而非垂直方向生长) + [交替变色(alternating_color)](保留)

**来源原语**：重涂色、对角链式连接、仅对角接触变色（ecb67b6d）；生长、交替变色、间隔行生成（af726779）；八连通区域（ecb67b6d）

**依赖链**：对角链连接性分析同时决定两件事——该区域的角色（生长种子 vs 障碍）和生长方向（链的主对角轴）。生长的扩展范围受障碍区域的空间位置限制。删除连接性分析则无法确定方向和角色；删除生长规则则分类无意义；删除障碍则无法确定生长终止条件。

根据灰(5)区域的内部连接性将其分为对角链种子和四连通障碍，种子沿其对角链主轴方向双向交替色生长，障碍阻止生长并被标记为红(2)。

**输入结构**：约 15x15 网格，黑(0)背景。散布着 4~6 个灰(5)像素构成的 8-连通区域（每个区域 4~10 像素）。部分区域的内部连通依赖对角角接触（即将其分解为 4-连通子块后，子块之间仅通过对角角点相连，形成非分叉的对角阶梯链）；其余区域完全是 4-连通的（内部无对角角接触依赖）。不同示例中各区域的具体形状不同，但每个示例中至少有 1 个对角链区域和 1 个四连通区域。各区域之间在 8-连通意义下互不相连，且任意两个区域的曼哈顿距离至少为 4（保证生长空间）。生成约束：每个对角链区域的最长对角连续段唯一确定一个主对角方向（NE-SW 或 NW-SE），不存在两个方向等长的歧义情况。

**规则**：
1. 对每个灰(5) 8-连通区域进行连接性分类：将区域分解为 4-连通子块，若子块之间仅通过对角角接触相连且形成非分叉链或环，则该区域为"对角链区域"（生长种子）；否则为"四连通区域"（障碍）。
2. 将所有障碍区域重涂为红(2)。生长种子保持灰(5)不变。
3. 对每个生长种子，确定其主对角轴：找到区域内最长的对角连续像素段，其方向（NE-SW 或 NW-SE）即为主轴。
4. 从种子区域的边界像素出发，沿主对角轴双向生长。生长规则：在当前活跃像素沿主轴方向隔一格处放置子代像素（即跳过一个对角格），第一代用品红(6)，第二代用橙(7)，交替进行。
5. 生长在以下任一情况停止：(a) 下一个位置超出网格边界；(b) 下一个位置被红(2)障碍区域的像素占据；(c) 下一个位置已被另一个种子的生长像素占据。
6. 当两个种子的生长路径试图占据同一格时，先到者（按种子区域的边界框左上角行优先列次优先排序，排序靠前的种子先处理）保留该格。

**关键洞察**：对角链连接性分析在源题(ecb67b6d)中仅用于分类重涂色，这里它同时编码了生长方向——链的几何轴线直接成为扩展轴，连接性分析既是分类器又是方向编码器。

## 新题 2：标记朝向选方向、图例定颜色、边距定周期

**组合逻辑**：[朝向决定方向(orientation_determines_direction)](保留) + [图例配色(legend_color_pair)](创新：从填充色映射变为延伸色映射) + [周期延伸(periodic_extension)](创新：周期由空间距离编码而非条长度) + [冲突优先级(conflict_priority)](创新：由距离决定而非绘制顺序)

**来源原语**：朝向决定方向、微型标记（9344f635）；图例配色、图例顺序决定层级（305b1341）；周期延伸、长度即周期、近者优先（1ae2feb7）；冲突优先级（9344f635/305b1341）

**依赖链**：标记朝向决定延伸方向→图例决定延伸颜色→标记到边距决定周期→距离决定冲突优先级。四个参数来自四个不同的信息源，缺一不可。

读取图例将标记色映射为延伸色，按标记朝向在对应方向上周期性延伸，周期等于标记到最近网格边（沿延伸方向）的距离，重叠时离边近者优先。

**输入结构**：约 14x14 网格，黑(0)背景。左上角有一个 2 列 N 行的图例区域（N=2~4 行）：每行左侧格为一种源色，右侧格为对应的输出色（如左红(2)右蓝(1)、左绿(3)右黄(4)等）。图例区域外散布着 2~4 个 2-像素同色双联骨牌标记（每个标记恰好 2 像素，颜色为图例中的某种源色）。水平双联骨牌（两像素同行相邻）标记一行延伸；垂直双联骨牌（两像素同列相邻）标记一列延伸。各标记之间不相邻。生成约束：每种图例源色在标记中至多出现一次；不同标记的延伸方向上至少有一处交叉以测试冲突优先级。

**规则**：
1. 读取图例区域（左上角 2 列，从第 0 行开始的连续非背景行），建立源色→输出色映射。然后将图例区域清除为背景。
2. 对每个双联骨牌标记，确定朝向：水平标记→沿该行水平延伸；垂直标记→沿该列垂直延伸。
3. 计算每个标记沿延伸方向到最近网格边的像素距离（标记中心到边缘的格数）→ 该值为延伸周期 P。
4. 从标记位置出发，沿延伸方向每隔 P 格放置一个延伸像素，颜色为图例映射后的输出色。延伸覆盖整行（水平标记）或整列（垂直标记），但仅在周期位置着色，其余位置保持背景。
5. 标记自身的像素也替换为输出色。
6. 当两个延伸在同一格重叠时，沿各自延伸方向距最近网格边更近的标记优先（距离小者胜出）。若距离相同，行标记覆盖列标记。

**关键洞察**：延伸周期不是由条的长度决定（与源题 1ae2feb7 不同），而是由标记在网格中的空间位置隐式编码——同一个标记移到不同位置会产生不同的周期。需要对比多个示例才能排除"周期固定"的假设。

## 新题 3：形状频次排序后相邻对象间隙对半填充

**组合逻辑**：[排序(sorting) + 平移(translate)](保留排序机制) → [间隙对半分(gap_bisect)](创新：从矩形间间隙变为排序后相邻对象间隙) + [形状频次分组(shape_frequency_grouping)](创新：分组结果决定排序目标行，进而决定哪些对象成为邻居)

**来源原语**：排序、平移、形状频次分组、旋转翻转不变、共享与唯一形状（62593bfd）；间隙对半分、奇数间隙留中线（d968ffd4）；填充(fill)（多源）

**依赖链**：形状频次分类→决定对象移动到顶部还是底部→排序后产生新的邻接关系→邻接对象之间执行间隙对半填充。间隙的存在和位置完全由排序结果决定，而排序依赖形状分类。删除分类则不知谁移动到哪里；删除间隙填充则排序无后续效果。

将对象按形状频次分到顶行或底行后，同行内相邻对象之间的水平间隙被两侧对象的颜色对半填充。

**输入结构**：约 16x16 网格，黑(0)背景。散布着 5~8 个单色小对象（每个 3~7 像素，4-连通），颜色各不相同（从 1~9 中选取）。对象的形状（旋转/翻转不变的规范形态）有重复：至少 2 个对象共享同一形状，至少 1 个对象形状唯一。各对象之间互不接触，边界框不重叠。不同示例中同类对象的具体像素排列不同（如同为 5 像素的 4-连通形状，可以是不同的五联骨牌），迫使求解者用结构属性而非记忆特定外形来分类。生成约束：所有对象的边界框高度 h 满足 h <= 4，以保证移动到顶/底后有足够行空间。

**规则**：
1. 计算每个对象的规范形状（将对象的二值掩码归一化到所有旋转和翻转中字典序最小的形式）。
2. 统计每种规范形状出现的次数。出现 >= 2 次的形状为"共享形状"，出现 1 次的为"唯一形状"。
3. 共享形状的对象平移到网格顶部（边界框顶边对齐到第 0 行），唯一形状的对象平移到网格底部（边界框底边对齐到最后一行）。水平位置（边界框左列）保持不变。
4. 在同一目标行（顶部或底部）中，按边界框左列从左到右排列所有对象。对每对相邻对象（按左列顺序），计算它们之间的水平间隙（左对象边界框右列 +1 到右对象边界框左列 -1）。
5. 间隙的左半部分（前 floor(gap_width/2) 列）填充为左侧对象的颜色，右半部分（后 floor(gap_width/2) 列）填充为右侧对象的颜色。填充范围的行跨度为两个相邻对象边界框行跨度的并集。
6. 若间隙宽度为奇数，中间一列保持背景色。
7. 原始对象的像素保持不变（不被间隙填充覆盖）。

**关键洞察**：间隙填充发生在排序后的相邻对象之间——哪些对象成为邻居完全取决于形状频次分类的结果。在源题(d968ffd4)中，间隙存在于固定的两个矩形之间；这里，间隙是排序的涌现产物，不同的形状分类会产生完全不同的间隙模式。

## 新题 4：切换射线破坏空心精灵体的填充资格

**组合逻辑**：[射线延伸(ray_extend) + 切换重涂(toggle_recolor)](保留) → [封闭区域(enclosed_region)](创新：射线可能破坏封闭性) → [填充(fill) + 边框色映射填充色(border_to_fill_mapping)](保留映射但条件受射线影响)

**来源原语**：射线延伸、切换重涂、控制像素、同列对齐、颜色匹配（981add89）；填充、封闭区域、调色板图例、编码映射、边框色映射填充色（dbff022c）；空心精灵体（dbff022c）

**依赖链**：控制像素发射切换射线→射线穿过空心精灵体时可能擦除边框像素→被擦破的精灵体不再形成封闭区域→调色板虽有映射但因封闭性丧失而无法填充。射线处理和填充判定之间存在因果依赖：不处理射线就无法知道哪些精灵体仍然封闭。

顶行控制像素向下发射切换射线，可能擦破空心精灵体边框；仅对射线处理后仍保持内部封闭的精灵体，用调色板图例映射的颜色填充。

**输入结构**：约 14x14 网格，黑(0)背景。3~4 个空心精灵体散布在网格中部和下部，每个精灵体是一个用单色边框围成的封闭区域（边框颜色各不相同，从蓝(1)、红(2)、绿(3)、黄(4)中选取；边框宽 1 像素；内部为黑(0)背景的矩形空洞，空洞至少 2x2）。网格右侧边缘有一个 2 列 N 行的调色板图例（N 等于精灵体数量）：左列为各边框色，右列为对应的填充色（如蓝(1)→橙(7)、红(2)→青(8)等）。顶行（第 0 行）有 1~2 个控制像素，颜色与某些精灵体的边框色相同。生成约束：至少一个控制像素的列与某个精灵体的边框像素所在列对齐（使得射线会穿过该边框），至少一个精灵体不被任何射线穿过边框。

**规则**：
1. 读取右侧边缘的调色板图例，建立边框色→填充色映射。
2. 对每个顶行控制像素，沿其所在列向下发射切换射线（从第 1 行到最后一行）：
   - 遇到与控制像素颜色相同的非背景像素→将该像素擦除为背景色（切换效果的"关"）。
   - 遇到其他非背景像素→将该像素涂为控制像素的颜色（切换效果的"开"）。
   - 控制像素本身保留。
3. 射线处理按控制像素从左到右的顺序执行（左列的控制像素先处理，其结果影响后续射线）。
4. 所有射线处理完毕后，检测每个精灵体的封闭性：对精灵体原始边框范围内的内部区域做 4-连通洪泛，若洪泛结果不触及网格边界且不触及边框外部的背景区域，则该精灵体仍然封闭。
5. 对仍然封闭的精灵体，用调色板映射的填充色填充其内部空洞。
6. 不再封闭的精灵体（边框被射线擦破）的内部保持背景色。
7. 最后将调色板图例区域清除为背景色。

**关键洞察**：调色板为所有精灵体都提供了填充映射，但切换射线可能擦除精灵体的边框像素（当射线颜色与边框色相同时发生切换"关"），破坏封闭性。一个精灵体是否被填充不取决于调色板中是否有它的条目，而取决于它是否在射线处理后仍保持封闭——这是源题(dbff022c)中不存在的条件门控。

## 新题 5：射线命中集内按形状频次决定擦除或旋转

**组合逻辑**：[射线延伸(ray_extend) + 射线命中(ray_intersection)](保留选择机制) → [形状频次分组(shape_frequency_grouping) + 旋转翻转不变(rotation_flip_invariant)](创新：仅在命中集内分类) → [擦除(erase) | 旋转(rotate)](创新：分类结果决定不同操作)

**来源原语**：射线延伸、擦除、标记条、控制像素、射线命中、命中即整体擦除（2f767503）；排序、形状频次分组、旋转翻转不变、共享与唯一形状（62593bfd）；旋转（a416fc5b/412b6263）

**依赖链**：射线确定命中集→仅对命中集做形状频次分析→共享形状者擦除、唯一形状者原地旋转 90 度。三层紧耦合：射线决定谁进入分类池，分类决定谁被擦除/旋转，旋转需要知道对象形状。未被射线命中的对象完全不参与后续逻辑。

标记条和控制像素确定射线方向，射线命中的目标对象按形状频次分组——共享形状者整体擦除，唯一形状者原地顺时针旋转 90 度，未命中者不变。

**输入结构**：约 16x16 网格，黑(0)背景。一个 3-像素直线标记条（灰(5)，水平或垂直）和一个与标记条中心相邻的单像素控制点（栗(9)），共同指定射线方向（从标记条中心朝远离控制点的方向）。另有 5~7 个单色目标对象（4-连通，每个 3~6 像素），颜色从蓝(1)、红(2)、绿(3)、黄(4)、橙(7)中选取，颜色各不相同。目标对象的形状（旋转/翻转不变的规范形态）有部分重复：至少 2 个对象共享同一规范形状，至少 1 个对象形状唯一。射线至少命中 3 个目标对象（射线的直线路径至少穿过 3 个目标对象的某个像素），且命中集中既有共享形状的对象也有唯一形状的对象。生成约束：唯一形状对象旋转 90 度后不会超出网格边界，也不会与其他未擦除对象重叠。

**规则**：
1. 从标记条中心沿远离控制点的方向发射一条直线射线（水平或垂直方向），延伸到网格边缘。
2. 确定命中集：射线路径上（含射线经过的所有格子）接触到像素的每个 4-连通目标对象进入命中集。
3. 对命中集中的对象计算规范形状（旋转/翻转不变）。统计命中集内每种规范形状出现的次数。
4. 命中集内共享形状（规范形状在命中集内出现 >= 2 次）的对象：将其所有像素擦除为背景色。
5. 命中集内唯一形状（规范形状在命中集内仅出现 1 次）的对象：以其边界框中心为旋转中心，顺时针旋转 90 度。旋转后像素保持原色。
6. 未被射线命中的对象保持不变。
7. 标记条和控制点保持不变。

**关键洞察**：源题(2f767503)中射线命中即无条件整体擦除；这里命中仅确定"候选集"，真正的操作由候选集内部的形状频次分析决定。同一个对象形状在全局中可能是唯一的，但在命中集内是共享的（因为射线恰好命中了两个相同形状），反之亦然。这种"局部频次"与"全局频次"的差异需要多个示例才能辨别。

## 新题 6：标记射线选择性启用中心对称补全

**组合逻辑**：[射线延伸(ray_extend)](创新：射线标记"活跃"行或列) + [补全(complete) + 中心对称(center_symmetry)](创新：仅在活跃区域执行对称补全) + [擦除(erase)](保留清理标记)

**来源原语**：射线延伸、标记条、控制像素（2f767503）；补全（a416fc5b/8a6d367c）；中心对称（833966f4）；擦除（981add89/2f767503）

**依赖链**：标记条+控制像素确定射线方向→射线经过的行或列被标记为"活跃"→仅在活跃行/列中对空白格执行 180 度中心对称补全→擦除标记工具。射线决定了对称补全的空间范围，两者不可分离：没有射线则不知补全范围，没有对称规则则射线标记无意义。

标记条确定射线方向，射线经过的行或列为活跃区域；对网格内容仅在活跃区域中执行 180 度旋转对称补全，非活跃区域保持原样。

**输入结构**：约 11x11 网格（奇数行列以保证中心格存在），黑(0)背景。网格上半部分有一些彩色像素构成部分图案（2~4 种颜色，从蓝(1)、红(2)、绿(3)、黄(4)中选取，每种 3~8 像素），图案不具有完整的 180 度旋转对称性，但在某些行/列中存在对称的配对位置。网格一角（不与彩色图案重叠）有一个 3 像素的灰(5)直线标记条（水平或垂直），以及一个相邻的栗(9)控制像素。生成约束：射线为水平时标记活跃行，为垂直时标记活跃列；在活跃区域内，每个非背景像素的 180 度旋转对称位置当前为背景（保证补全不冲突）；在非活跃区域内，存在至少一处"看似可以对称补全但不应补全"的位置（用来区分"全局补全"假设）。

**规则**：
1. 从标记条中心沿远离控制像素的方向发射直线射线至网格边缘。
2. 记录射线经过的所有行号（若射线水平）或列号（若射线垂直）→这些为"活跃"行/列。
3. 确定网格的中心点 (center_r, center_c) = ((H-1)/2, (W-1)/2)。
4. 遍历网格中所有非背景像素 (r, c, color)。计算其 180 度旋转对称位置 (r', c') = (H-1-r, W-1-c)。若 (r', c') 为背景，且 r'（射线水平时）或 c'（射线垂直时）在活跃行/列集合中，则将 (r', c') 涂为 color。
5. 若对称位置不在活跃行/列中，即使是背景也不填充。
6. 将标记条和控制像素擦除为背景色。

**关键洞察**：输出是一种"局部对称"——只有射线扫过的行或列被补全为 180 度旋转对称，其余行/列的不对称性被故意保留。从单个示例看，求解者可能误以为是"全局对称补全"或"仅补全特定颜色"；需要多个示例（不同射线方向和位置）才能归纳出射线选择性启用补全的规则。

## 新题 7：种子行生长与分隔列另侧周期延伸的交叉叠加

**组合逻辑**：[生长(grow) + 间隔行生成(gap_row_generate) + 交替变色(alternating_color)](保留) ‖ [周期延伸(periodic_extension) + 长度即周期(length_as_period)](保留) → 两者在分隔列两侧独立生成后交叉覆盖(创新：两种独立机制的输出在空间上碰撞)

**来源原语**：生长、种子行、交替变色、间隔行生成、相邻间隔（af726779）；周期延伸、分隔列、色条、长度即周期、近者优先（1ae2feb7）；冲突优先级（305b1341/9344f635）

**依赖链**：生长从种子行向下扩展产生三角形图案；周期延伸从色条向对侧水平扩展产生条纹；两者的输出在分隔列的同一侧重叠时，必须解决冲突——近侧色条的延伸覆盖生长像素。单独执行任一侧的规则都无法得到正确输出。

分隔列左侧从种子行向下交替色生长出三角形，右侧色条周期性延伸到左侧；延伸条纹覆盖生长像素的区域，产生被条纹"切割"的三角形图案。

**输入结构**：约 15x18 网格，绿(3)背景。一条垂直的灰(5)分隔列（宽 1 像素）将网格分为左区和右区。左区第 2 行有一条水平的橙(7)种子行（3~5 个像素，可能不连续），其余为背景。右区有 2~3 条水平色条紧贴分隔列右侧或距分隔列数格（同一行内连续的同色像素段），颜色各不相同（从蓝(1)、红(2)、黄(4)中选取），长度各不相同（2~4 像素）。色条分布在不同行上。生成约束：至少一条色条所在行与生长产生的活跃行重合（确保有交叉覆盖发生）；种子行的像素在左区内，不跨越分隔列。

**规则**：
1. **左区生长**：从种子行开始，按 af726779 的规则向下生长——每隔一行（跳过一行），在当前活跃行中找所有"活跃-背景-活跃"三元组的中间位置放置子代。第一代子代用品红(6)，第二代用橙(7)，交替进行，直到无法生成子代或超出网格底部。生长仅发生在左区（分隔列左侧）。
2. **右区周期延伸**：对右区每条色条，以其像素长度 L 为周期，向左侧穿过分隔列延伸到左区。延伸方式：从色条左端向左，每隔 L 格放置一个该色条颜色的像素，直到左区左边缘。
3. **冲突解决**：当周期延伸的像素与生长产生的像素位于同一格时，距分隔列更近的色条的延伸像素优先保留（覆盖生长像素）。不同色条之间的冲突同样按距分隔列远近解决（近者优先）。
4. 分隔列自身像素保持灰(5)不变。
5. 种子行的原始橙(7)像素保持不变（不被延伸覆盖）。

**关键洞察**：左区的三角形生长图案被右区色条的周期延伸"穿刺"——最终图案是一个被水平条纹切割的收缩三角形。在源题中，生长(af726779)和周期延伸(1ae2feb7)各自独立运作在封闭区域内；这里两种机制的输出在同一空间区域碰撞，产生了两个源题中都不存在的交叉图案。

## 新题 8：字形指令编码平移方向、颜色匹配目标、顺序处理形成动态障碍

**组合逻辑**：[解码指令(decode_instructions) + 字形指令(glyph_instruction) + 编码映射(encoding_map)](创新：编码平移方向而非折线段) + [滑动(translate) + 贴墙移动(move_to_wall)](创新：移动终点由动态障碍决定) + [颜色匹配(color_match)](创新：颜色匹配指令到目标对象) + [顺序读取(sequential_reading)](创新：处理顺序产生涌现效应——先移动的对象成为后续对象的障碍)

**来源原语**：解码指令、字形指令、编码映射、顺序读取（136b0064）；滑动、贴墙移动（9f41bd9c）；颜色匹配（981add89）；目标对象（2f767503）

**依赖链**：字形像素数编码平移方向→字形颜色匹配目标对象→按字形从左到右顺序逐一平移对象→先完成平移的对象占据新位置，成为后续对象的阻挡物。每一步的结果改变下一步的空间状态，产生顺序依赖的涌现效应。

顶部字形序列逐一指挥下方同色对象沿编码方向滑动至碰壁停止，先滑动的对象成为后续对象的新障碍。

**输入结构**：约 15x15 网格，黑(0)背景。顶部 3 行为指令区域，包含 3~4 个 3x3 彩色字形，字形之间用 1 列背景分隔，按列排列。每个字形由单一前景色绘制在黑(0)背景上，颜色各不相同（从蓝(1)、红(2)、绿(3)、黄(4)中选取）。每个字形的非背景像素数为 3、4、5 或 6 之一（不重复），编码一个方向。指令区域下方（第 4 行起）散布着与字形数量相同的单色 4-连通小对象（每个 3~8 像素），每个对象的颜色恰好匹配一个字形的颜色。对象之间、对象与网格边缘之间有足够空间。生成约束：按字形从左到右的顺序平移对象后，至少有一个对象的最终位置受到了先前已平移对象的阻挡（即它的终点与移动方向上的下一个障碍物是另一个已移动的对象，而非网格边缘）。

**规则**：
1. 读取指令区域中的字形，按从左到右的列顺序排列。每个字形的非背景像素数 A 编码一个平移方向：A=3→上，A=4→右，A=5→下，A=6→左。
2. 每个字形的颜色 C 匹配下方区域中颜色为 C 的唯一目标对象。
3. 按字形从左到右的顺序依次处理：
   a. 确定当前字形对应的目标对象和平移方向。
   b. 将该对象沿指定方向滑动，直到对象的任一像素的下一格遇到网格边缘、另一个对象的像素、或指令区域边界（第 3 行）为止。对象停在最后一个不碰撞的位置。
   c. 对象移动后，其新位置立即生效（成为后续对象的潜在障碍）。
4. 所有对象处理完毕后，将指令区域（顶部 3 行）清除为背景色。

**关键洞察**：指令的处理顺序产生涌现效应——改变字形的左右排列顺序会改变最终布局，因为先移动的对象成为后续对象的障碍。源题(136b0064)中指令顺序编码折线段，各段互不干涉；这里指令顺序引入了动态障碍——每条指令执行后改变了世界状态，使得同一组指令按不同顺序执行会产生完全不同的结果。
