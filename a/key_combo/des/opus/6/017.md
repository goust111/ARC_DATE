## 新题 1：奇偶门控重力与分层缓冲

**组合逻辑**：[标注中心](创新：中心标记不只是视觉注记，而是改变物理行为的控制信号) + [重力下落](创新：缓冲距离由标记状态动态决定) + [奇偶性](创新：从单纯的筛选条件变为重力参数的调制器)

**来源原语**：标注中心/奇偶性/奇边长才标注(22806e14), 重力下落/缓冲行间距(825aa9e9), 擦除(多题)

**依赖链**：奇偶性判定 → 决定是否标注中心 → 中心标记状态决定缓冲行数 → 缓冲行数改变重力停靠位置。删除奇偶判定则无法区分缓冲距离；删除重力下落则无空间变换；删除中心标注则缓冲信号丢失。

对每个实心正方形先判断边长奇偶来标注中心，然后让所有正方形在重力下落时根据中心标记状态获得不同的缓冲间距，形成交错的落地层次。

**输入结构**：约 18x12 的网格，背景为黑(0)。底部有一行灰(5)像素作为地板。网格上半部分散布 4~6 个不同颜色的实心正方形（每个正方形为同色的 4-连通填充区域，边长在 2~5 之间，颜色从蓝(1)、红(2)、绿(3)、黄(4)、品红(6)中选取，各正方形颜色互不相同）。正方形之间水平方向互不重叠（列范围无交集），保证下落路径不冲突。生成约束：至少有 2 个奇边长正方形和 2 个偶边长正方形。

**规则**：
1. 识别所有实心正方形，计算每个正方形的边长。
2. 对边长为奇数的正方形，将其中心像素重涂为橙(7)。偶边长正方形不做标注。
3. 保持灰(5)地板和所有正方形的列位置不变，将每个正方形向下平移。
4. 带橙(7)中心标记的正方形（原奇边长）在距地板顶面 2 行空隙处停靠（即正方形底边与地板顶面之间恰好有 2 行黑(0)）。
5. 无中心标记的正方形（原偶边长）在距地板顶面 0 行空隙处停靠（即正方形底边紧贴地板顶面）。
6. 若多个正方形落入同一行区间，按列位置从左到右依次处理，各正方形在同一列范围内独立停靠，互不影响（生成时已保证列范围无交集）。

**关键洞察**：中心标记不仅是视觉输出，更是控制重力缓冲距离的信号——必须先判断奇偶、执行标注，才能确定每个正方形的停靠高度。单看一个示例可能误以为缓冲距离与颜色或面积有关，需要对比多个示例才能归纳出奇偶性是决定因素。

## 新题 2：射线寻靶印章放置

**组合逻辑**：[角落位置选模板](创新：角落仍然选择模板形状，但不再固定放置偏移) + [射线延伸](创新：射线不再涂色，而是探测放置坐标) + [印章覆盖](创新：印章位置由射线终点决定而非角落附近的固定位置)

**来源原语**：角落标记/固定模板/角落位置选模板/标记色传递给模板(fd02da9e), 射线延伸/射线遇障停止/特定色为墙壁(6ffe8f07), 印章覆盖/擦除(fd02da9e)

**依赖链**：角落位置 → 选择模板形状 + 确定射线方向 → 射线沿该方向延伸直到遇障 → 障碍物前方位置确定印章放置坐标 → 用角落标记颜色涂印章。删除角落识别则无法选模板也无法定方向；删除射线则无法定位放置点；删除印章则无输出。

从角落标记的位置选取对应模板形状，再沿角落向内方向投射射线直到遇障，在障碍物前放置该模板。

**输入结构**：约 12x12 的网格，背景为黑(0)。网格内散布若干蓝(1)像素块作为障碍物（每个障碍物为 1~3 像素的 4-连通团簇，总共 3~5 个障碍物，分布在网格中部区域）。四个角落中的 2~3 个各有一个前景色像素作为角落标记（颜色从红(2)、绿(3)、黄(4)、品红(6)中选取，各标记颜色互不相同），放置在距角顶点恰好 (0,0) 的位置（即角顶点本身）。四种角落对应的模板：左上角 → 2x2 实心块，右上角 → 竖直 3x1 条，左下角 → 水平 1x3 条，右下角 → L 形（2x2 去右上角的 3 像素）。生成约束：每条从角落沿对角线向中心的射线路径上至少有一个蓝(1)障碍物像素；模板放置区域不与障碍物或其他已放置模板重叠。

**规则**：
1. 识别每个角落标记，记录其颜色 c 和所在角落（左上/右上/左下/右下）。
2. 根据角落位置选择模板形状：左上 → 2x2 实心块，右上 → 竖直 3x1 条，左下 → 水平 1x3 条，右下 → L 形（2x2 区域去掉右上角像素的 3 像素图案）。
3. 从角落标记位置沿 45 度对角线向网格中心方向逐像素投射射线。射线在遇到蓝(1)障碍物像素时停止（不包含该障碍像素）。
4. 将模板以射线终点（停止前最后一个空像素）作为模板的靠近角落一侧的锚点，放置模板。具体地：左上角模板的右下角像素对齐射线终点；右上角模板的左下角像素对齐射线终点；左下角模板的右上角像素对齐射线终点；右下角模板的左上角像素对齐射线终点。
5. 模板所有像素涂为标记颜色 c。
6. 擦除原始角落标记像素为背景黑(0)。障碍物保持不变。
7. 多个模板按角落标记在网格中从左上到右下的阅读顺序依次放置，后放置的覆盖先放置的。

**关键洞察**：角落位置同时编码了两条独立信息——模板形状和射线方向——而射线终点又依赖障碍物分布，因此模板的最终位置是三重信息（角落、方向、障碍物）的交汇。仅看一个示例可能以为模板总在固定偏移处，需对比不同障碍物位置的示例才能发现射线机制。

## 新题 3：包含层级驱动的嵌套重建与图例变色

**组合逻辑**：[包围框包含](创新：从删除判据变为层级排序的依据) + [嵌套](创新：嵌套顺序不由面积排序而由包含深度决定) + [重涂色](创新：颜色通过边缘图例映射，而非保留原色) + [裁剪](已有)

**来源原语**：包围框包含/异色包含则删(9720b24f), 嵌套/面积递减嵌套/角落对齐嵌套(6cbe9eb8), 重涂色(多题), 边缘图例/等价表格(6165ea8f), 裁剪(6cbe9eb8)

**依赖链**：识别包围框包含关系 → 构建包含深度树 → 深度排序决定嵌套层次 → 图例提供颜色映射 → 按深度从外到内逐层嵌套重建并变色。删除包含关系则无法确定嵌套顺序；删除图例则无法确定输出颜色；删除嵌套则无空间重建。

根据对象间包围框的包含关系建立层级树，再用边缘图例将每层颜色映射为输出色，最终按层级从外向内嵌套重建。

**输入结构**：约 16x16 的网格，背景为黑(0)。网格中有 3~5 个不同颜色的 4-连通单色对象（形状为矩形框或实心矩形，颜色从蓝(1)、红(2)、绿(3)、黄(4)、品红(6)中选取）。这些对象的包围框形成严格的嵌套关系（每个对象的包围框要么完全包含另一个，要么完全不相交，不存在部分重叠），构成一棵单链深度树（深度 0 → 深度 1 → ... → 深度 N-1）。网格右侧最后一列有若干成对的单像素，每对上下相邻：上方像素颜色为输入中某对象的颜色，下方像素颜色为该对象的输出映射色（从灰(5)、橙(7)、青(8)、栗(9)中选取）。每个输入对象颜色恰好在图例中出现一次。生成约束：包含链中相邻层级的包围框之间在每个方向至少有 2 行/列的间距。

**规则**：
1. 识别所有非黑(0)、非图例列的 4-连通单色对象，计算每个对象的包围框。
2. 构建包含关系：若对象 A 的包围框严格包含对象 B 的包围框，则 A 是 B 的父节点。取直接父节点构建深度树，根节点深度为 0。
3. 读取右侧图例列：每对上下相邻的非黑像素定义颜色映射（上色 → 下色）。
4. 输出网格大小等于深度 0（最外层）对象的包围框尺寸。
5. 从深度 0 开始，逐层向内重建：每层对象用图例映射后的颜色绘制其原始形状（框或实心），放置位置为其在父层包围框内的左上角对齐（即子对象的包围框左上角与父对象内部区域的左上角对齐）。
6. 深度较大（更内层）的对象后绘制，覆盖先绘制的像素。

**关键洞察**：包围框包含关系在源题中用于判断"删除与否"，这里被重新诠释为空间层级排序的依据；图例在源题中用于等价标注，这里成为颜色转换表。需要对比多个示例才能确认嵌套对齐方式是左上角对齐而非居中对齐。

## 新题 4：对角滑动后形状等价检测与条件变色

**组合逻辑**：[平移/对角固定步移](创新：滑动不是一步而是滑到边界) + [旋转翻转等价](创新：不用于建表，而是作为滑动后对象间的关系判据) + [重涂色](创新：变色条件是后验的空间邻接+形状等价的合取)

**来源原语**：平移/角位指示方向/对角固定步移(470c91de), 控制像素(470c91de), 旋转翻转等价/形状匹配(6165ea8f), 重涂色(多题), 抵达边界(99caaf76)

**依赖链**：识别控制像素角位 → 对角滑动至边界 → 滑动后检测邻接对 → 对邻接对做形状等价判定 → 等价对变色/非等价对保持。删除滑动则对象位置不变、邻接关系不同；删除等价判定则无法区分变色对象；删除控制像素则无法确定滑动方向。

每个精灵体沿控制像素指示的对角方向滑到网格边界，滑动后彼此邻接的精灵体若形状旋转翻转等价则重涂为红色。

**输入结构**：约 15x15 的网格，背景为黑(0)。网格中有 4~6 个小型 4-连通单色精灵体（每个 3~6 像素，形状不规则但各自紧致在 3x3 包围框内，颜色从蓝(1)、绿(3)、黄(4)、品红(6)、橙(7)中选取，各精灵体颜色互不相同）。每个精灵体恰好有一个像素被替换为青(8)作为控制像素，该控制像素位于精灵体包围框的四个角之一。精灵体初始分布在网格中部区域，彼此不相邻。生成约束：每个精灵体沿其控制像素所在角的对角方向滑到边界后，至少有一对精灵体的包围框 8-邻接（包围框之间无间隔或仅隔 1 行/列）；至少存在一对邻接且形状等价的精灵体和一对邻接但形状不等价的精灵体。

**规则**：
1. 识别每个精灵体及其青(8)控制像素。将控制像素视为精灵体的一部分，其原本颜色视同精灵体颜色。
2. 确定控制像素在精灵体 3x3 包围框中的角位：左上 → 向左上滑，右上 → 向右上滑，左下 → 向左下滑，右下 → 向右下滑。
3. 擦除所有精灵体的原位置为黑(0)。
4. 沿确定的对角方向逐步平移精灵体（包含控制像素位置），直到精灵体包围框的某条边触及网格边界。按各精灵体到边界的距离从近到远依次放置（距离相同则按精灵体包围框左上角行优先、列次之排序），先放置的占据位置，后放置的若冲突则停在冲突前一格。
5. 所有精灵体放置完毕后，检查每对精灵体是否 8-邻接（两者包围框之间在水平或垂直方向存在相邻或重叠的行/列区间，且最近像素的切比雪夫距离 <= 1）。
6. 对每对 8-邻接的精灵体，提取各自的归一化掩码（去除控制像素后的形状紧致掩码），判断是否在旋转(0/90/180/270度)或翻转(水平/垂直)下等价。
7. 若一对邻接精灵体形状等价，将两者所有像素（包括控制像素位置）重涂为红(2)。若不等价，保留各自原色。一个精灵体若与多个邻接精灵体中至少一个等价，即重涂为红(2)。
8. 控制像素在输出中不单独显示，已融入精灵体颜色（红(2)或原色）。

**关键洞察**：滑动终点由控制像素角位和网格边界共同决定，而形状等价判定发生在滑动之后——同一组精灵体在不同输入布局下可能因滑动后邻接关系不同而产生不同的变色结果。必须对比多个示例才能排除"按颜色变色"或"按面积变色"等错误假设。

## 新题 5：孔洞计数排序链与可变分隔色

**组合逻辑**：[计数](创新：孔洞数不用于颜色映射，而是确定排列顺序) + [排序/链式连接](创新：排序依据从边缘像素匹配变为拓扑属性) + [重涂色](创新：分隔线颜色由相邻块的孔洞数差值决定)

**来源原语**：计数/封闭区域/孔洞数映射颜色(e3721c99), 排序/链式连接排序/分隔线(78332cb0), 精灵体(多题), 颜色图例(e3721c99), 重涂色(多题)

**依赖链**：计算每个块的孔洞数 → 按孔洞数升序排列 → 计算相邻块孔洞数差值 → 差值映射分隔色 → 组装输出条带。删除孔洞计数则无法排序也无法算差值；删除排序则顺序不定；删除差值映射则分隔色不定。

对散布的精灵体按封闭孔洞数排序拼成条带，相邻精灵体之间的分隔线颜色由它们孔洞数的差值通过图例映射决定。

**输入结构**：约 20x20 的网格，背景为黑(0)。网格中散布 4~5 个灰(5)精灵体（每个精灵体为 4-连通的灰(5)像素团，紧致在 5x5 包围框内，像素数 10~20，可以包含 0~3 个封闭的黑(0)孔洞——孔洞为被灰(5)像素完全包围的黑(0)连通域且不触及精灵体包围框边界）。各精灵体的孔洞数互不相同。网格底部一行中有若干颜色图例标记：图例由成对的单像素组成，每对水平相邻，左像素颜色为蓝(1)、右像素颜色从红(2)、绿(3)、黄(4)、品红(6)中选取；蓝(1)像素旁标注的数值由其在图例行中从左到右的位置序号隐含表示（第 1 对表示差值 1，第 2 对表示差值 2，第 3 对表示差值 3）。生成约束：相邻精灵体（排序后）的孔洞数差值都在图例覆盖的范围内（1~3）。精灵体数量与图例范围保证所有差值都能查到映射。

**规则**：
1. 识别所有灰(5)精灵体，对每个精灵体计算其封闭孔洞数（被该精灵体灰(5)像素完全 4-连通包围的黑(0)连通域，且不触及精灵体包围框的边界）。
2. 将精灵体按孔洞数从小到大排序。孔洞数相同不会出现（生成约束保证互不相同）。
3. 读取底部图例行：从左到右依次取出每对水平相邻的非黑像素，第 k 对（k=1,2,3,...）的右侧颜色定义差值 k 对应的分隔色。
4. 将排序后的精灵体裁剪为各自 5x5 包围框，水平拼接成一行条带。相邻精灵体之间插入 1 列宽的分隔线。
5. 第 i 个与第 i+1 个精灵体之间的分隔线颜色 = 图例中差值 |hole_count(i+1) - hole_count(i)| 对应的颜色。
6. 条带首尾不加分隔线。输出网格高度为 5，宽度为 (精灵体数 x 5 + 分隔线数 x 1)。
7. 精灵体在输出中保持灰(5)，孔洞保持黑(0)。

**关键洞察**：孔洞数同时承担两个角色——决定排列顺序（全局排序键）和计算分隔颜色（局部差值键）。单看一个示例可能以为分隔色与精灵体位置或颜色有关，必须对比多个示例观察差值与分隔色的对应关系才能发现图例编码的是差值映射而非直接映射。

## 新题 6：奇偶条件像素放大与掩码分化

**组合逻辑**：[像素放大](创新：放大规则不再统一，由像素所属对象的属性决定放大方式) + [掩码映射](创新：掩码选择在自身色选掩码的基础上增加条件分支) + [标注中心](创新：中心标注不是最终输出，而是改变该像素放大时所用掩码的控制信号) + [奇偶性](创新：奇偶性不直接作用于输出，而是分流放大算法)

**来源原语**：像素放大/掩码映射/自身色选掩码/全局掩码/块单元(973e499e), 标注中心/奇偶性/奇边长才标注/十字标记(22806e14), 擦除(多题)

**依赖链**：判断每个正方形的边长奇偶 → 奇边长正方形标注中心 → 逐像素放大时根据像素是否为标注中心、所属正方形的奇偶类别选择不同的掩码规则 → 生成最终输出。删除奇偶判定则无法分流放大规则；删除中心标注则中心像素的特殊掩码丢失；删除像素放大则无输出。

将输入中的每个像素放大为与输入同尺寸的块，但奇边长正方形的像素使用自身色掩码，偶边长正方形的像素使用全填充块，中心标注像素使用十字掩码。

**输入结构**：一个 4x4 或 5x5 的小网格。网格中包含 2~3 个不同颜色的实心正方形（边长 1~3，颜色从蓝(1)、红(2)、绿(3)中选取，互不相同），其余位置为黑(0)背景。正方形之间不重叠不相邻。生成约束：至少一个奇边长（1 或 3）和一个偶边长（2）的正方形。黄(4)不出现在输入中，保留作为标注色。

**规则**：
1. 识别每个实心正方形及其边长。
2. 对边长为奇数的正方形，将其中心像素颜色改为黄(4)作为标注。边长为 1 的正方形只有一个像素，即中心，也标注为黄(4)。偶边长正方形不做标注。
3. 将标注后的网格进行像素放大：输入每个像素扩展为一个与输入网格同尺寸的块（输入为 NxM 则每个块也是 NxM），输出网格为 (N*N)x(M*M)。
4. 块内容规则按像素所属类别分三种情况：
   - 属于偶边长正方形的像素（颜色 c）：块内所有位置都填充为 c（实心块）。
   - 属于奇边长正方形的非中心像素（颜色 c）：块内仅在标注后输入中颜色也为 c 的位置填充 c，其余为黑(0)（自身色掩码）。
   - 中心标注像素（黄(4)）：块内仅在标注后输入中颜色为黄(4)的位置（即所有被标注的中心位置）填充黄(4)，其余为黑(0)（黄色掩码）。
5. 黑(0)背景像素的块全部为黑(0)。

**关键洞察**：同一张输入网格被同时用作放大对象和掩码模板，但不同类别的像素读取掩码的方式不同——偶边长正方形的像素忽略掩码直接全填充，奇边长正方形的像素按自身色选掩码，中心标注像素按标注色选掩码。三种放大方式共存于同一输出中，需要对比多个示例才能区分这三条规则。

## 新题 7：门控走廊中的累积旋转移动

**组合逻辑**：[移动](创新：移动不再是单步到达目标，而是逐段通过多个门) + [旋转](创新：旋转不是一次性 180 度，而是每过一个门累积 90 度) + [障碍门处标记通道](创新：标记形状随旋转后的矩形朝向变化)

**来源原语**：移动/同轴对齐的矩形对/障碍段/障碍门处标记通道(fc10701f), 旋转(99caaf76), 重涂色(多题), 擦除(多题)

**依赖链**：识别起止矩形和走廊上的门 → 移动过程中每过一个门旋转 90 度 → 旋转改变矩形宽高 → 标记形状取决于当前朝向 → 最终矩形朝向取决于门的总数。删除门识别则不知何处旋转；删除旋转则标记形状和终态朝向错误；删除移动则无空间变换。

一个彩色矩形沿走廊向目标移动，每穿过一个障碍门旋转 90 度，到达目标位置时朝向由经过的门数决定。

**输入结构**：约 7x20 的网格（窄高或宽矮，走廊沿长轴方向），背景为黑(0)。走廊一端（如最左侧）有一个橙(7)的 2x3 实心矩形（宽 2 高 3），另一端（如最右侧）有一个同尺寸位置放置的栗(9)实心矩形标记目标区域。两者之间共用行跨度（如果走廊水平）。走廊中间有 1~3 组灰(5)障碍段，每组由走廊两侧的灰(5)像素构成"门"——两侧灰(5)像素在门所在列各占若干行，中间留出恰好能让当前朝向的矩形通过的缺口。生成约束：走廊足够宽（7 行），使得矩形旋转后（3x2 变 2x3 或反之）仍能在走廊中纵向居中通过；各门之间水平间距至少 4 列。

**规则**：
1. 识别橙(7)矩形（起始）、栗(9)矩形（目标）和所有灰(5)障碍门。确定移动方向为从橙(7)矩形指向栗(9)矩形的水平或垂直方向。
2. 擦除橙(7)矩形为黑(0)。保留栗(9)矩形和灰(5)障碍门。
3. 将橙(7)矩形沿移动方向逐列（或逐行）平移。每当矩形完全通过一个灰(5)门（矩形后缘离开门所在列/行后），将矩形顺时针旋转 90 度。旋转以矩形中心为轴，旋转后矩形在走廊的垂直于移动方向的维度上居中放置。
4. 矩形通过每个门时，在门的缺口处（矩形穿越门时门所在列/行中矩形占据的非灰像素位置）涂上红(2)标记。标记的形状反映矩形穿越该门时的当前朝向（第一个门时矩形是原始 2x3，标记宽 2；若经过一次旋转后矩形变 3x2，下一个门标记宽 3；以此类推）。
5. 矩形到达栗(9)标记区域后，用橙(7)覆盖栗(9)的位置，矩形的最终朝向为初始朝向经过 N 次 90 度顺时针旋转的结果（N 为门的数量）。
6. 灰(5)障碍门和红(2)门标记保留在输出中。

**关键洞察**：门的数量不仅产生标记效果，还累积改变矩形的朝向，导致后续门的标记形状和最终矩形形态都是门数量的函数。需要对比不同门数量的示例才能发现旋转是累积的而非交替的。

## 新题 8：隐含十字中心驱动腔室填充选色

**组合逻辑**：[四向对齐/缺失中心](创新：中心检测不再是输出标注，而是间接寻址信号) + [标记指定腔室/填充](创新：标记不是显式像素而是隐式检测到的位置) + [最近距离](创新：从吸附场景迁移到中心-腔室的匹配场景)

**来源原语**：四向对齐/微型条/隐含十字/缺失中心(9f5f939b), 标记指定腔室/格点骨架/封闭腔室/填充(17b866bd), 最近距离(1b8318e3), 邻接(17b866bd)

**依赖链**：检测微型条的四向排列 → 定位隐含十字中心 → 计算每个中心到最近腔室的距离 → 中心颜色作为填充色填入最近腔室。删除十字中心检测则无标记位置；删除最近距离匹配则无法确定哪个腔室被填充；删除填充则无输出变换。

在格点骨架中，通过检测微型条构成的隐含十字来定位中心，将中心作为虚拟标记寻找最近腔室并填充。

**输入结构**：约 17x17 的网格。青(8)像素构成周期性格点骨架（如每隔 4 列和 4 行有青(8)像素组成的十字交叉线），骨架围出若干 3x3 的黑(0)封闭腔室。骨架外围区域（网格边缘附近 2~3 行/列的空白区域）散布着若干颜色各异的水平或垂直 2 像素微型条（每条为 2 个同色 4-连通像素，颜色从红(2)、绿(3)、黄(4)、品红(6)中选取）。某些微型条在空间上形成隐含十字排列：以某个空背景像素为中心，上下左右各偏移 2~3 格处各有一个同色微型条指向该中心，上下方向为竖直条，左右方向为水平条。生成约束：每种颜色的微型条要么全部参与隐含十字、要么有多余的干扰条（不构成完整十字）；隐含十字的数量不超过腔室数量；各隐含十字的中心到最近腔室的距离互不相同（避免距离冲突）。

**规则**：
1. 扫描所有非骨架、非黑的 2 像素微型条，记录每条的颜色、方向（水平/垂直）和位置。
2. 对每个黑(0)背景像素 p，检查上下左右四个方向偏移 2 格和 3 格处是否各有一条同色微型条朝向 p（上下方向要求竖直条，左右方向要求水平条）。四个方向的偏移值需一致（全部是 2 或全部是 3）。若四个方向均满足且颜色相同，则 p 是一个隐含十字中心，颜色为该微型条的颜色。
3. 对每个检测到的隐含十字中心，计算其到每个封闭腔室中心像素的曼哈顿距离，选择最近的腔室。
4. 将最近腔室中的所有黑(0)像素填充为隐含十字中心的颜色。
5. 未被任何隐含十字选中的腔室保持黑(0)。不构成完整隐含十字的干扰微型条保留在原位不变。骨架保持不变。
6. 隐含十字中心本身（黑(0)背景像素）不改变颜色，仅作为寻址信号。

**关键洞察**：微型条本身看起来只是散落的碎片，必须识别出四向排列的隐含结构才能定位中心；而中心又不是直接标注，而是通过最近距离匹配间接选择腔室。单看一个示例可能以为腔室颜色直接由附近的微型条决定，需对比多个示例才能发现中心检测和最近距离匹配的双重间接机制。

## 新题 9：投影对齐吸附与冲突竞争

**组合逻辑**：[吸附](创新：吸附对象从单像素变为有结构的条状体) + [凸起匹配标记列](创新：凸起匹配不用于嵌入对齐，而是作为吸附的精细定位和竞争裁判) + [冲突优先级](创新：冲突解决从距离比较变为匹配质量比较)

**来源原语**：吸附/最近距离/最短距离分配/冲突优先级/孤立像素/锚块(1b8318e3), 凸起条/列对齐/凸起匹配标记列/框架槽(4c3d4a41), 擦除(多题)

**依赖链**：识别锚块和凸起条 → 每条按最近距离分配到候选锚块 → 检查凸起与锚块标记列的匹配度 → 匹配度作为冲突优先级裁决多条竞争同一锚块的情况 → 胜出条吸附到锚块上方。删除最近距离则无法做初始分配；删除凸起匹配则无法精细定位也无法解决冲突；删除吸附则无空间变换。

多个带凸起的条状体吸附到最近的锚块，凸起与锚块标记列的匹配程度决定冲突时的优先级。

**输入结构**：约 15x18 的网格，背景为黑(0)。网格中有 2~3 个灰(5) 2x2 锚块，每个锚块上方 1 行处有 2~4 个红(2)单像素作为标记列（标记列的列坐标落在锚块列范围及其左右各扩展 1 列的范围内）。网格中还有 3~5 个彩色条状体，每个条状体由一行水平像素构成（宽 3~5 像素，颜色从蓝(1)、绿(3)、黄(4)、品红(6)、橙(7)中选取，互不相同），部分像素上方有同色的 1 像素凸起（构成向上突出的齿状），凸起数 1~3 个。条状体分布在网格各处，不与锚块相邻。生成约束：至少有一个锚块被两个条状体竞争（两条到该锚块的最近距离相等或都是最近）。

**规则**：
1. 识别所有灰(5) 2x2 锚块和它们上方 1 行处的红(2)标记列像素。将每个锚块与其标记列关联。
2. 识别所有彩色条状体（水平主体+向上凸起）。
3. 对每个条状体，计算其主体中心到每个锚块中心的曼哈顿距离，选择最近的锚块作为目标。若到多个锚块距离相等，选择列坐标更靠左的锚块。
4. 计算每个条状体对其目标锚块的"匹配度"：将条状体水平居中对齐到锚块上方（条状体中心列对齐锚块中心列），统计条状体的凸起列与锚块标记列重合的数量。匹配度 = 重合凸起数。
5. 若多个条状体竞争同一锚块，匹配度最高的胜出。匹配度相同则选择主体像素数更少（更短）的条状体。仍相同则选原始位置行号更小（更靠上）的。
6. 胜出的条状体擦除原位置，移动到锚块正上方 2 行处（条状体主体底边距锚块顶边 2 行），水平居中对齐锚块。凸起保持相对位置。
7. 未胜出的条状体擦除为黑(0)，不出现在输出中。
8. 锚块和标记列保持不变。

**关键洞察**：凸起不仅是视觉特征，更是竞争裁决的量化标准——凸起与标记列的空间重合度决定了哪个条状体有资格占据目标锚块。单看一个示例可能以为吸附只看距离，需对比有冲突和无冲突的示例才能发现匹配度机制。

## 新题 10：控制色分流的穿透重力与边缘接触合并

**组合逻辑**：[控制色定行为/穿透或停靠](创新：控制色不再区分两种对象行为，而是区分同一对象内不同列的行为，且穿透列可与停靠列在落地后产生分裂) + [重力下落](创新：同一对象的不同列独立下落到不同高度) + [边缘像素匹配](创新：从块排序的判据变为分裂后碎片的合并条件)

**来源原语**：控制色定行为/穿透或停靠/控制像素/边缘标记(963c33f8), 重力下落/障碍物(963c33f8, 825aa9e9), 边缘像素匹配/链式连接排序(78332cb0), 重涂色(多题)

**依赖链**：读取控制行决定每列的下落行为 → 各列独立下落（穿透或停靠）→ 列落到不同高度导致对象分裂为多个碎片 → 检测碎片间边缘像素匹配 → 匹配的碎片合并重涂。删除控制色则所有列行为相同、无分裂；删除独立下落则无高度差；删除边缘匹配则无法确定合并对。

一个宽对象的底行是控制条，蓝色列停靠在障碍物上、栗色列穿透到底部，由此分裂为碎片，边缘像素吻合的碎片合并并重涂。

**输入结构**：约 15x10 的网格，背景为黑(0)。网格顶部（第 0~2 行）有一个宽 5~7 列、高 3 行的前景对象：前两行为绿(3)，第三行（底行）为控制行，每个像素是蓝(1)或栗(9)。网格中部和下部散布若干灰(5)像素作为障碍物（每个障碍物为单个像素或 2~3 像素的水平段）。生成约束：控制行中蓝(1)和栗(9)各至少 2 列；每个蓝(1)列的正下方路径上至少有一个灰(5)障碍物；栗(9)列的正下方路径上可以有也可以没有灰(5)障碍物；蓝(1)列遇到的障碍物高度（行号）至少有两个不同值，使对象分裂为至少 2 个碎片。

**规则**：
1. 识别顶部前景对象，提取其底行（第三行）的控制行：蓝(1)列和栗(9)列。对象的前两行为绿(3)数据行。
2. 擦除原对象位置为黑(0)。
3. 将对象按列拆分，每列包含该列的 2 个绿(3)像素和 1 个控制像素。每列独立下落：
   - 蓝(1)控制列：向下移动直到该列的最下方像素（控制像素）即将进入灰(5)障碍物的正上方一格位置时停止。若该列下方无障碍物，则移动到网格底部。
   - 栗(9)控制列：忽略所有灰(5)障碍物，直接移动到网格最底行（控制像素落在最后一行）。
4. 所有列落定后，擦除每列的控制像素（蓝(1)或栗(9)），只保留 2 个绿(3)像素。
5. 将水平相邻且行位置相同的绿(3)像素列合并为碎片（4-连通的绿(3)连通域）。
6. 对每对碎片，检查它们在垂直方向上是否可以通过平移对齐使得接触边缘的绿(3)像素在同一行偏移上吻合（即碎片 A 的右边缘列的绿像素行集合与碎片 B 的左边缘列的绿像素行集合有非空交集，或反之）。
7. 存在边缘吻合的碎片对全部重涂为红(2)。无任何吻合对的碎片保持绿(3)。一个碎片只要与任意另一碎片吻合即重涂。
8. 灰(5)障碍物保持不变。

**关键洞察**：控制行创造了差异化的下落行为，这种差异导致原本连续的对象在垂直方向上被撕裂成高度不同的碎片。碎片间的边缘吻合检测本质上是在验证"哪些分裂是可逆的"——若两个碎片的边缘仍然互补，说明它们可以重新拼合，因此被标记为红色。必须对比多个示例才能区分出控制色机制和边缘匹配机制的独立作用。
