## 新题 1：嵌套深度映射为同心方环

**组合逻辑**：[包含树/containment_tree](已有) → [计数/counting](已有，创新用于计算嵌套深度) → [距离映射/distance_mapping](创新：嵌套深度映射为切比雪夫距离) → [填充/fill](已有，用于填充同心方环)

**来源原语**：包含树/containment_tree(#2d0172a1)、嵌套框架/nested_frame(#2d0172a1)、封闭区域/enclosed_region(#2d0172a1)、拓扑决定布局/topology_determines_layout(#2d0172a1)、同心方环/concentric_ring(#ac0c2ac3)、距离映射/distance_mapping(#ac0c2ac3)、切比雪夫距离/chebyshev_distance(#ac0c2ac3)、标记像素/marker_pixel(#ac0c2ac3)、计数/counting(#8698868d, #58490d8a)

**依赖链**：必须先对所有前景轮廓进行包含关系分析，得到每组嵌套的深度值；然后将每个标记像素的嵌套深度映射为输出方环的切比雪夫距离层级；最后用标记颜色填充对应层。删除包含树分析则深度未知，删除距离映射则输出结构未知，删除填充则无法生成方环。

将散布的嵌套轮廓组按包含深度解读为同心方环的颜色层序，完全丢弃输入的空间布局，仅保留拓扑嵌套信息。

**输入结构**：
- 网格约 20x20，背景黑(0)。
- 灰(5) 前景像素形成若干组嵌套的闭合轮廓线（每条轮廓为 4-连通、一像素厚的闭合环）。每组内轮廓严格包含于外层轮廓所围合的区域中，嵌套层数 2~4 层（从最外层算起，外层 = 深度 1）。
- 不同嵌套组在网格上空间分离（最外层轮廓互不重叠、互不接触）。
- 每组嵌套的最内层轮廓所围合区域内，恰好有一个非灰(5)、非黑(0) 的彩色标记像素（单像素）。不同组使用不同颜色，如红(2)、绿(3)、蓝(1)、黄(4)等。
- 生成约束：所有标记像素的嵌套深度（从最外层轮廓到标记所在最内层轮廓穿越的边界数）两两不同。若存在 K 个标记，则深度值恰好覆盖 1, 2, ..., K。

**规则**：
1. 对每组嵌套轮廓，构建包含树：确定轮廓之间的严格包含关系。标记像素位于最内层轮廓的围合区域内。
2. 计算每个标记像素的嵌套深度 d：从该组最外层轮廓的外部出发，穿越 d 道轮廓边界才能到达标记所在区域（即标记被 d 层轮廓嵌套包围）。
3. 设 D = 所有标记中的最大嵌套深度。输出为边长 2D+1 的正方形网格。
4. 以输出网格中心为原点，对每个输出像素计算其到中心的切比雪夫距离 dist。
5. 距离 dist = d 的所有像素填充为深度 d 处标记的颜色（d 从 1 到 D）。距离 dist = 0 的中心像素填充为深度最大（D）的标记颜色。距离 dist > D 的像素不存在（因为网格半径恰好为 D）。
6. 修正映射方向：嵌套最深的标记（深度 D）→ 中心（距离 0）；嵌套最浅的标记（深度 1）→ 最外环（距离 D-1）。即深度 d 的标记映射到切比雪夫距离 D-d。距离 D 的最外一圈像素保持黑(0)背景，作为边框。

**关键洞察**：输入中各组嵌套轮廓的具体位置、形状、大小完全不影响输出——只有拓扑嵌套深度决定颜色在方环中的层级。这是一种"空间几何编码拓扑信息"的解码题：求解者必须意识到嵌套深度才是唯一有效信号，而非轮廓的几何外形。

## 新题 2：边框侧色轨迹与门结构截停

**组合逻辑**：[滑动/slide](已有) + [朝向对应边色/facing_side_color](创新：将边框侧色用于决定轨迹颜色而非填充缺口色) + [门前停止/stop_at_gate](创新：门结构嵌入边框内部作为截停器)

**来源原语**：滑动/slide(#b25e450b)、接触边缘/touching_edge(#b25e450b)、轨迹条纹/trail_stripe(#b25e450b)、滑至对侧边缘/slide_to_opposite(#b25e450b)、边缘矩形/edge_rectangle(#b25e450b)、矩形边框/rectangular_frame(#5b37cb25)、朝向对应边色/facing_side_color(#5b37cb25)、重涂色/recolor(#5b37cb25)、门结构/gate_motif(#182e5d0f)、门前停止/stop_at_gate(#182e5d0f)、擦除/erase(#182e5d0f)

**依赖链**：三种机制同时约束输出——接触边决定滑动方向，门结构决定轨迹长度，边框侧色决定轨迹颜色。三者缺一不可：无边框侧色则轨迹颜色未知；无门结构则所有滑块都到达对侧（退化为参考题#b25e450b）；无滑动则不产生轨迹。

小矩形块从边框内侧滑向对侧，门结构截停滑动，扫过区域涂为起始侧的边框颜色。

**输入结构**：
- 网格约 15x15，背景黑(0)。
- 网格外围有一个一像素厚的矩形边框。四条边各为纯色：上边=红(2)，右边=绿(3)，下边=蓝(1)，左边=黄(4)。四个角像素为灰(5)。
- 边框内部有若干小矩形色块（每个为 1~2 像素厚、2~4 像素长的黑(0)矩形），每个色块恰好 4-邻接触边框的某一条内侧边。
- 边框内部还有若干门结构：每个门由 3 个像素组成一条直线段，垂直于对应滑动方向放置，排列模式为 [该侧边框色 - 灰(5) - 该侧边框色]。例如，若门位于纵向滑道中，则门为横向 3 像素，两端颜色与门所在位置较近的上边或下边颜色一致。
- 生成约束：每个滑动色块的滑道上至多有一个门结构。不同色块的滑道互不重叠（保证同时滑动无冲突）。部分色块的滑道上无门。

**规则**：
1. 每个黑色矩形色块从其接触的边框内侧出发，朝对侧边框方向滑动（接触上边 → 向下滑，接触左边 → 向右滑，以此类推）。所有色块同时滑动。
2. 若滑道上存在门结构，色块停在门的灰(5)中心像素的前一格（色块与门灰心相邻但不重叠）。若无门，色块滑至对侧边框内侧（与对侧边框像素相邻）。
3. 色块原始位置到最终位置之间的扫过区域（不包括色块最终占据的像素）涂为该色块起始接触的边框侧颜色。例如，接触上边（红(2)）的色块留下红(2)轨迹。
4. 色块本身在最终位置涂为橙(7)。
5. 所有门结构保持不变。边框保持不变。

**关键洞察**：单看一个示例时，轨迹颜色可能被误解为固定色或与滑动方向绑定；必须对比多个示例（不同示例中边框四侧可以有不同的颜色分配）才能归纳出"轨迹色=起始侧边框色"这一规则。门结构的存在使轨迹长度不统一，进一步增加了从单个示例推断规则的难度。

## 新题 3：轮廓围合面积转为排列方阵

**组合逻辑**：[泛洪填充/flood_fill](已有) + [轮廓围合/contour_enclosure](已有) → [计数/counting](创新：将不规则围合面积量化为数值) → [压缩重排/repack](已有，创新：面积值决定方阵边长) + [面积递增排列/area_ascending_order](已有)

**来源原语**：泛洪填充/flood_fill(#753ea09b)、轮廓线/contour_line(#753ea09b)、封闭背景区域/enclosed_bg_region(#753ea09b)、轮廓围合/contour_enclosure(#753ea09b)、小区域被填充/small_regions_filled(#753ea09b)、忽略干扰项/ignore_distractors(#753ea09b)、压缩重排/repack(#8abad3cf)、排序/sort(#8abad3cf)、面积递增排列/area_ascending_order(#8abad3cf)、像素数定边长/pixel_count_determines_side(#8abad3cf)、色块/color_group(#8abad3cf)、正方形/square(#8abad3cf)、计数/counting(#58490d8a)、标记像素/marker_pixel(#ac0c2ac3)

**依赖链**：轮廓围合面积 → 泛洪填充确定各色区域 → 计数得到像素面积 → 面积开方得方阵边长 → 按边长排序重排。不规则轮廓的几何形状隐式编码了数值（面积），该数值驱动输出方阵尺寸。删除任一环节都无法得到正确输出。

将轮廓线围合的不规则区域按标记色填充，然后丢弃所有几何信息，仅用各色面积值重建为按大小排列的实心方阵。

**输入结构**：
- 网格约 18x18，背景黑(0)。
- 灰(5) 像素形成 8-连通的轮廓线片段，围合出 3~5 个封闭区域。轮廓线一像素厚，形状不规则（非矩形）。
- 橙(7) 像素作为固定干扰物散布在部分区域内部，将区域内的背景进一步分隔。橙像素不会被重涂色，也不计入填充面积。
- 每个封闭区域的背景部分（不含灰轮廓、不含橙干扰物）内恰好有一个彩色标记像素（单像素），颜色为红(2)、蓝(1)、绿(3)、黄(4)之一，各区域颜色互不相同。
- 生成约束：每个区域内背景像素总数（含标记像素本身、不含橙干扰物和灰轮廓）为一个完全平方数（4, 9, 16, 25 等），且各区域的平方数值两两不同。网格中最大的两个背景连通分量为外部区域，不参与填充。

**规则**：
1. 将所有非黑像素（灰轮廓 + 橙干扰物 + 彩色标记）视为障碍。将背景按 4-连通性分割为若干区域。
2. 丢弃最大的两个背景区域（它们是轮廓画外部的空间）。
3. 对每个剩余的封闭背景区域，用区域内标记像素的颜色进行泛洪填充。标记像素本身算作已填充。
4. 统计每种颜色的填充总像素数 A。计算方阵边长 s = sqrt(A)。
5. 输出为新网格：将每种颜色生成一个 s x s 的实心方阵，按 s 值从小到大从左到右排列，所有方阵底部对齐（底边位于输出网格最后一行），相邻方阵之间留一列黑(0)间隔。输出网格高度 = 最大 s 值，宽度 = 所有 s 值之和 + (颜色数 - 1)。

**关键洞察**：不规则的轮廓几何只是面积数值的一种空间编码——求解者必须先通过空间推理（泛洪填充 + 排除干扰物）解码出面积，再完全丢弃二维几何，将面积转换为一维排列的方阵。橙干扰物的存在使面积不等于简单的包围盒面积，必须精确排除才能得到正确的平方数。

## 新题 4：障碍投影阻断射线填充后计数入图例

**组合逻辑**：[泛洪填充/flood_fill + 射线延伸/radiate](已有) + [障碍投射阴影/obstacle_casts_shadow](已有) → [计数/counting](创新：统计阴影影响后的实际填充面积) → [填充图例/populate_legend](已有，创新：图例点数由阴影后面积决定)

**来源原语**：泛洪填充/flood_fill(#b9e38dc0)、射线延伸/radiate(#b9e38dc0)、半封闭墙/partial_enclosure(#b9e38dc0)、障碍物/obstacle(#b9e38dc0)、填充种子/fill_seed(#b9e38dc0)、开口方向/opening_direction(#b9e38dc0)、障碍投射阴影/obstacle_casts_shadow(#b9e38dc0)、计数/counting(#58490d8a)、填充图例/populate_legend(#58490d8a)、图例框/legend_box(#58490d8a)、颜色索引行/color_keyed_row(#58490d8a)、计数映射点序列/count_to_dot_sequence(#58490d8a)

**依赖链**：障碍物位置 → 阴影方向与范围 → 实际被填充的像素集合（而非无障碍情况下的完整扇面）→ 精确像素计数 → 图例中的点序列长度。阴影机制与计数-图例机制分属两个不同的推理层：前者是空间模拟，后者是数值编码。两者汇合于"填充面积"这一中间量。

对多个半封闭墙体内的种子执行射线填充，障碍物在射线方向投射阴影阻断填充，统计每种颜色的实际填充面积并在图例框中以点序列报告。

**输入结构**：
- 网格约 18x22，背景黑(0)。
- 左侧区域：3~4 个灰(5)半封闭墙体（U 形或 C 形，一像素厚），每个墙体围合一个小区域并留有一个开口（开口朝上、下、左或右之一）。每个墙体内部恰有一个填充种子像素，颜色各不相同：红(2)、绿(3)、蓝(1)、黄(4)。
- 在部分墙体开口的外侧、射线延伸路径上，有橙(7)障碍像素（1 像素宽），位于墙体开口与网格边界之间。障碍不完全封堵射线路径（只遮挡部分列或部分行）。
- 右侧区域：一个灰(5)描边的黑(0)矩形图例框。图例框内最左侧非灰列中，自上而下排列色键像素（红、绿、蓝、黄，与左侧墙体内种子颜色一一对应），色键像素之间间隔一行空行。图例框内其余区域为黑(0)。
- 生成约束：每个墙体的可填充面积（封闭内部 + 无遮挡射线区域）在 2~8 像素之间。不同墙体的可填充面积两两不同。

**规则**：
1. 对每个半封闭墙体，用种子颜色泛洪填充墙体围合的内部区域。
2. 从开口处沿开口方向向外射线延伸填充：对开口所跨的每一行（或列，取决于开口朝向），向外逐像素填充种子颜色，直到遇到网格边界或非黑像素时停止。
3. 障碍投影规则：对于射线路径上的每个橙(7)障碍像素，该障碍在射线延伸方向上投射"阴影"——障碍像素本身不被填充，且障碍正后方（沿射线方向更远处）、与障碍同行或同列的所有像素也不被填充，直到该行/列结束。障碍旁侧（不在障碍正后方的列/行）正常填充。
4. 统计每种颜色的实际新增填充像素总数（内部填充 + 未被阴影阻断的射线填充；包含种子像素本身）。
5. 在图例框中，对每个色键行：从色键像素的右侧第 2 格开始，每隔一格放置一个该色的点，点的总数等于步骤 4 中该颜色的填充面积数。

**关键洞察**：图例中的点数不等于"无障碍时的完整填充面积"——障碍阴影减少了实际填充面积，而且阴影是沿射线方向无限延伸的（不只遮挡一格），这使得微小的障碍位移会显著改变填充计数。求解者必须同时掌握阴影投射机制和图例编码机制，才能从输入推算出正确的点数。

## 新题 5：逐步消耗标记的顺序决定方环着色层级

**组合逻辑**：[逐步移动/stepwise_move + 消除/consume](已有) + [朝向决定搜索线/facing_sets_search_line](已有) + [最近标记优先/nearest_marker_first](已有) → [距离映射/distance_mapping](创新：消耗顺序映射为切比雪夫距离层) → [填充/fill](已有，创新：用消耗序列中的颜色填充同心方环)

**来源原语**：逐步移动/stepwise_move(#5545f144)、消除/consume(#5545f144)、三角精灵体/triangle_sprite(#5545f144)、标记像素/marker_pixel(#5545f144)、朝向决定搜索线/facing_sets_search_line(#5545f144)、最近标记优先/nearest_marker_first(#5545f144)、同心方环/concentric_ring(#ac0c2ac3)、距离映射/distance_mapping(#ac0c2ac3)、切比雪夫距离/chebyshev_distance(#ac0c2ac3)、填充/fill(#ac0c2ac3)

**依赖链**：三角精灵体的初始朝向 → 搜索线上的最近标记 → 消耗该标记并转向 → 继续搜索下一标记 → 完整消耗序列确定 → 序列中第 k 个颜色涂入第 k 层方环。精灵体的路径模拟产出颜色序列，该序列编码了方环的径向着色方案。删除路径模拟则序列未知；删除方环映射则无输出结构。

三角精灵体依朝向逐步消耗散布的彩色标记，消耗顺序决定输出同心方环从中心到外围的颜色排列。

**输入结构**：
- 网格约 15x15，背景黑(0)。
- 一个灰(5)三角箭头精灵体（3~5 像素的 4-连通图形，尖端指示初始朝向：上、下、左或右之一），位于网格中部某处。
- 3~6 个单像素彩色标记散布在网格上，每个标记颜色不同，从红(2)、绿(3)、蓝(1)、黄(4)、品红(6)、橙(7)中选取。
- 生成约束：从精灵体初始位置和朝向出发，沿朝向方向的半线上恰好有一个可达标记（同行或同列，位于朝向方向一侧）。消耗该标记后精灵体转向该标记方向，从新位置和新朝向出发，又恰好有一个可达标记。以此类推，直到所有标记被消耗。整个消耗路径是确定性的、无歧义的。

**规则**：
1. 精灵体从初始位置出发，沿朝向方向的半线（同行向左/右，或同列向上/下）搜索最近的彩色标记像素。
2. 精灵体移动到该标记位置，消耗它（标记从网格移除）。精灵体的新朝向变为移动方向（若向右移动则朝右，以此类推）。
3. 重复步骤 1-2，直到所有标记均被消耗。
4. 记录消耗顺序：第 1 个被消耗的标记颜色为 c1，第 2 个为 c2，...，第 N 个为 cN。
5. 输出为一个边长 2N+1 的正方形网格，以同心方环填充：
   - 中心像素（切比雪夫距离 0）= c1（第一个被消耗的颜色）。
   - 切比雪夫距离 1 的环 = c2。
   - 切比雪夫距离 k-1 的环 = ck（第 k 个被消耗的颜色）。
   - 切比雪夫距离 N 的最外环 = 黑(0)背景边框。
6. 精灵体本身不出现在输出中。

**关键洞察**：标记像素在输入网格上的空间坐标完全不影响输出——唯一重要的是精灵体消耗它们的先后顺序，而该顺序由朝向搜索机制（每步只看朝向半线上的最近标记）动态决定。求解者必须完整模拟精灵体的逐步路径才能确定颜色序列，而方环结构要求将这种线性序列映射为二维径向结构——两种截然不同的空间推理在同一题中交织。

## 新题 6：交替转向路径生成轮廓并填充围合区

**组合逻辑**：[路径模拟/path_simulation + 交替转向/alternating_turn](已有) + [颜色循环/color_cycle](已有) → [轮廓围合/contour_enclosure](创新：路径轨迹本身成为轮廓线) → [泛洪填充/flood_fill](已有，创新：填充色由轮廓的局部颜色决定)

**来源原语**：路径模拟/path_simulation(#195c6913)、交替转向/alternating_turn(#195c6913)、粒子/particle(#195c6913)、起始标记/start_marker(#195c6913)、颜色循环/color_cycle(#195c6913)、碰撞停止/collision_stop(#195c6913)、轮廓围合/contour_enclosure(#753ea09b)、泛洪填充/flood_fill(#753ea09b)、封闭背景区域/enclosed_bg_region(#753ea09b)、小区域被填充/small_regions_filled(#753ea09b)

**依赖链**：路径模拟的交替转向规则决定轨迹形状 → 轨迹自然形成闭合或半闭合轮廓 → 轮廓围合出背景区域 → 颜色循环使轨迹不同段为不同颜色 → 围合区的填充色取决于接触的轨迹段颜色。路径模拟与轮廓填充不是独立的两步——路径的颜色信息穿越到填充步骤，形成深度耦合。

粒子沿交替转向规则在空白网格上画出彩色轨迹，轨迹本身构成轮廓线，围合出的背景区域用相邻轨迹中最后绘制的颜色填充。

**输入结构**：
- 网格约 15x15，背景黑(0)。
- 左上角区域：2~3 个 2x2 单色色块从左到右排列，定义颜色循环序列（如红(2)、绿(3)、蓝(1)），按排列顺序循环使用。
- 网格某条边上有一个灰(5)起始标记像素，紧邻它的内侧像素为黑(0)背景。起始标记的位置确定粒子的初始运动方向（从边缘向网格内部移动）。
- 网格其余区域为黑(0)背景（除颜色循环色块外无其他前景元素）。
- 生成约束：在给定的循环序列和起始位置下，粒子至少碰撞 4 次边界（产生足够转弯来形成围合区域），且最终因计划转向方向的像素已被涂色而停止。停止时，轨迹至少围合 1 个小背景区域。

**规则**：
1. 粒子从起始标记位置出发，沿初始方向移动。起始标记像素在输出中保留为灰(5)。
2. 粒子每移动一步，将当前像素涂为颜色循环中的下一色（第 1 步涂序列第 1 色，第 2 步涂序列第 2 色，到达序列末尾后回到第 1 色循环）。
3. 当粒子到达网格边界像素时：该像素涂为黄(4)（碰撞标记），然后粒子尝试转向 90 度。转向方向交替进行：第 1 次碰撞 → 逆时针转 90 度；第 2 次碰撞 → 顺时针转 90 度；第 3 次 → 逆时针；第 4 次 → 顺时针；以此交替。
4. 若计划转向后的下一个像素已被涂色（非黑(0)）或超出网格，粒子停止，路径结束。
5. 路径结束后，将所有已涂色像素（轨迹 + 碰撞标记）视为前景障碍。将剩余黑(0)背景按 4-连通性分割为若干区域。
6. 找到最大的背景区域（外部区域），不填充。对每个其他背景区域（被轨迹围合的小区域）：找到与该区域 4-邻接的所有轨迹像素，其中绘制步骤编号最大（最后绘制）的那个轨迹像素的颜色即为该区域的填充色。用此颜色泛洪填充整个区域。
7. 左上角的颜色循环色块在输出中保留不变。

**关键洞察**：路径模拟不仅产生轨迹形状，还通过颜色循环将颜色信息编码进轨迹的每个像素中。围合区的填充色不是由区域位置决定，而是由接触该区域的轨迹像素中"最晚绘制"的那个决定——这意味着同一段轨迹在不同侧围合的两个区域可能获得不同的填充色。求解者必须同时追踪路径模拟（含交替转向）和绘制顺序，才能预测围合区的颜色。
