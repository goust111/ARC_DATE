## 新题 1：射线奇偶触发的原型翻转

**组合逻辑**：[射线延伸](创新：射线沿格子框架的行/列通道传播，受框线阻挡) + [互换原型](创新：由射线命中奇偶性决定是否触发) + [跨框架对应](已有) + [遇阻停止](已有)

**来源原语**：射线延伸、侧标记、遇阻停止(95755ff2)；互换原型、原型精灵、原型配对(c7f57c3e)；格子框架、格子槽位、跨框架对应(2e65ae53)

**依赖链**：格子框架的框线充当射线阻挡物，划定射线的传播范围 --> 射线命中次数的奇偶性决定每个精灵是否翻转原型 --> 翻转后的颜色由跨框架对应关系推断

在格子框架中，侧标记发射的射线沿行或列通道传播并被框线阻挡，精灵体根据被命中次数的奇偶性决定是否切换为另一种原型形态。

**输入结构**：约 18x18 的网格。背景为黑(0)。灰(5) 色单像素宽线条构成一个格子框架，将网格分为 3x3 共 9 个等大矩形槽位。每个槽位内部放置一个 4-连通单色小图形（3~5 像素），颜色为蓝(1) 或红(2)，分别代表两种原型。同一原型的所有实例共享相同的归一化形状（平移等价），但两种原型形状不同。格子框架的外侧边缘上（紧贴框线外一列或一行）散布若干绿(3) 色侧标记像素，每个标记像素位于某行或某列上。生成约束：每种原型至少出现 3 次；每行和每列的侧标记数量在不同示例中不同，以确保奇偶关系需从多示例归纳。

**规则**：
1. 每个绿(3) 侧标记像素沿其所在行（若在左/右边缘）或列（若在上/下边缘）向格子内部发射一条射线。射线穿过背景像素和精灵像素，遇到灰(5) 框线像素时停止（不穿透框线进入下一槽位）。
2. 统计每个槽位内精灵被射线经过的次数（同一射线经过该精灵占据的任意像素只计 1 次）。
3. 若一个精灵的被命中总次数为奇数，将其替换为另一种原型（保持精灵边界框左上角位置不变）；若为偶数（含 0），保持原样。
4. 替换时，原蓝(1) 精灵变为红(2) 原型形状，原红(2) 精灵变为蓝(1) 原型形状。
5. 侧标记像素、框线、背景均保持不变。

**关键洞察**：框线既是视觉分隔也是射线阻挡物，同一行/列的多个标记累积命中同一精灵，但只有奇数次命中才触发翻转——需对比多个示例才能排除"命中即翻转"的错误假设。

## 新题 2：重力落入菱形仓后按到达顺序堆叠

**组合逻辑**：[重力下落](已有) + [排序](创新：排序键为像素的原始水平位置，仓的框色决定排列方向) + [菱形框](创新：作为收集容器而非射线边界) + [碰撞停止](已有) + [框内填充](已有)

**来源原语**：重力下落、碰撞停止(36a08778)；菱形框、框内填充(95755ff2)；排序、整块移动保持内容(f18ec8cc)

**依赖链**：重力下落决定每个像素落入哪个菱形仓 --> 同仓内像素按原始列坐标排序 --> 菱形框的框色决定排序方向（升序/降序） --> 排序后的像素在菱形内部从底部向上堆叠

散落的彩色像素在重力作用下落入下方的菱形仓中，同仓像素按原始水平位置排序后自底向上堆叠，排序方向由菱形框色决定。

**输入结构**：约 20x15 的网格。背景为黑(0)。网格下半区有 2~3 个不重叠的菱形框（空心，由单像素宽线条围成），框线颜色分别为橙(7) 或栗(9)。每个菱形内部初始为空（全黑）。网格上半区散布若干单独的彩色像素（颜色从蓝(1)、红(2)、绿(3)、黄(4) 中取，每个像素颜色可能不同），每个彩色像素的正下方必定有且仅有一个菱形能接住它（即该像素所在列穿过某个菱形的内部）。生成约束：每个菱形至少接收 2 个像素；不同菱形接收的像素数量不同，以便观察排序效果。

**规则**：
1. 每个彩色像素沿其所在列垂直下落，穿过背景像素，直到进入某个菱形框的内部区域。
2. 收集落入同一菱形的所有像素，记录每个像素的原始列坐标。
3. 若菱形框色为橙(7)，将该组像素按原始列坐标从小到大排序；若框色为栗(9)，按从大到小排序。
4. 排序后，将像素从菱形内部最低可用行开始、沿菱形中轴列逐行向上放置（每行放一个像素，保持像素原色）。若菱形内部某行宽度不足一个像素（靠近顶点），则跳过该行继续向上。
5. 菱形框线、背景及上半区原位置的彩色像素均清除为背景（像素已"落入"仓中）。

**关键洞察**：菱形不是射线边界而是收集容器，框色编码了排序方向——需对比多个示例中橙框与栗框的堆叠顺序差异才能归纳出排序规则。

## 新题 3：缺陷条的循环位移与跨面板镜像修复

**组合逻辑**：[循环移位](创新：作用于缺陷条在矩形周长上的位置而非条形图的属性) + [镜像](创新：镜像副本中缺陷被修复) + [缺陷条](已有) + [对侧面板色](已有) + [分隔色填充间隙](已有)

**来源原语**：循环移位(2601afb7)；缺陷条、面板、所属面板、对侧面板色(9b5080bb)；镜像、分隔线、分隔色填充间隙(538b439f)

**依赖链**：缺陷条在矩形周长上的位置循环移位 --> 移位量由面板归属决定 --> 镜像到对面面板时缺陷被修复 --> 原件与镜像之间的间隙用分隔色填充

有缺陷的矩形在镜像到对侧面板时被修复为完整矩形，但原件的缺陷位置沿周长做面板依赖的循环位移，间隙用分隔色填充。

**输入结构**：约 20x20 的网格。背景为黑(0)。一条绿(3) 色全宽水平分隔线将网格分为上下两个面板。上面板的主色调为蓝(1)（面板内大部分背景区域为黑，但蓝色用于标记该面板身份，具体方式为：分隔线上方紧邻一行蓝色像素作为面板标识带）。下面板类似，标识色为红(2)。每个面板内有 1~2 个灰(5) 色实心矩形（4~6 行 x 3~5 列），每个矩形有 1~2 个缺陷条——即矩形边缘上连续 2 个像素被替换为背景色，形成缺口。缺陷条总是位于矩形的某一条边上。生成约束：上下面板的矩形互不在同一列范围内重叠（镜像后不会遮挡）。

**规则**：
1. 将每个矩形的四条边展开为一个周长序列（按顺时针从左上角开始）。在该序列中定位所有缺陷条（连续 2 个背景像素）。
2. 对上面板的矩形，缺陷条在周长序列中向后（顺时针）移动 2 个位置；对下面板的矩形，向前（逆时针）移动 2 个位置。移动后缺陷条可能绕到另一条边上。
3. 在原件位置，按移位后的缺陷条更新矩形（新缺陷位置变为背景，旧缺陷位置恢复为灰(5)）。
4. 将每个更新后的矩形跨分隔线镜像到对侧面板的对称位置。镜像副本为完整矩形（无缺陷），颜色改为对侧面板标识色（上面板矩形镜像后为红(2)，下面板矩形镜像后为蓝(1)）。
5. 原件与其镜像之间的矩形投影区域内，所有背景像素填充为绿(3)（分隔色）。
6. 分隔线与面板标识带保持不变。

**关键洞察**：缺陷条不是简单保留或消除，而是沿周长做循环位移——移位方向取决于面板归属，需对比两个面板的矩形行为才能归纳出方向规则。镜像副本的"修复"与原件的"移位"形成不对称变换。

## 新题 4：地形轮廓编码色带填充高度与极值列特殊着色

**组合逻辑**：[填充](创新：填充量由地形轮廓编码而非固有属性决定) + [地形轮廓](创新：作为编码信息源而非直接操作对象) + [空缺借邻色填充](创新：与地形极值联动产生例外) + [列高度极值](已有) + [竖向色带](已有)

**来源原语**：地形轮廓、列高度极值、分隔行(e45ef808)；竖向色带、循环相邻、空缺借邻色填充(c4d1a9ae)；填充(多题共有)

**依赖链**：地形轮廓的列高度编码各色带需要填充的像素数 --> 色带间循环借色确定填充颜色 --> 地形极值列标记特殊色带，覆盖循环借色规则

网格上半部分的地形高度编码下半部分各色带的填充像素数量，填充颜色由循环借邻色决定，但地形最高和最低点对应的色带使用特殊颜色。

**输入结构**：约 20x16 的网格。背景为黑(0)。一条灰(5) 色全宽水平分隔行将网格分为上下两部分。上部是地形轮廓区：每列从底部（紧邻分隔行上方）向上有连续的橙(7) 色像素，高度在 1~6 之间变化，形成起伏的轮廓线；轮廓以上为背景。下部是色带区：有 N 条竖向色带（N 与上部列数相同，每条色带宽 1 列），每条色带的顶部有 1~2 个该带固有色的像素（固有色从蓝(1)、红(2)、绿(3)、黄(4) 中取，相邻带颜色不同），其余为背景。生成约束：地形高度序列中存在唯一最大值和唯一最小值。

**规则**：
1. 读取上部地形区每列的橙(7) 像素高度 h(c)。
2. 在下部色带区，对第 c 列色带，从该带已有像素的下方开始，向下填充 h(c) 个像素。
3. 填充颜色规则：正常情况下，第 c 列色带的填充色为第 (c+1) 列色带的固有色（最右列循环取最左列的固有色）。
4. 例外：地形高度最大的那一列，其色带填充色改为栗(9)；地形高度最小的那一列，其色带填充色改为品红(6)。
5. 各色带原有的固有色像素保持不变。分隔行与地形区保持不变。

**关键洞察**：地形轮廓不是直接被变换的对象，而是编码了色带填充量的"指令区"——需同时理解跨区域的高度-数量映射和循环借色规则，并发现极值列的特殊着色例外。

## 新题 5：图最短路径定义分形种子掩码

**组合逻辑**：[最短路径](创新：路径不再被重涂色，而是转化为二值掩码) + [递归展开](创新：种子掩码由图路径生成而非预先给定) + [图结构](已有) + [自相似替换](已有) + [节点方块](已有)

**来源原语**：最短路径、图结构、节点方块、终端节点、轨道段(7b0280bc)；递归展开、种子掩码、自相似替换、前景背景分别替换(58c02a16)

**依赖链**：图遍历得到最短路径 --> 路径投影到节点网格生成二值种子掩码 --> 种子掩码递归展开为分形图案

在节点-轨道图中找到两终端之间的最短路径，将路径上的节点位置映射为一个 NxN 二值掩码，然后以此掩码为种子进行一次分形递归展开。

**输入结构**：约 21x21 的网格。背景为黑(0)。蓝(1) 色 2x2 方块作为节点，排列成 3x3 的规则网格（节点中心间距 6 像素）。节点之间由黄(4) 色单像素宽轨道段连接（不是所有相邻节点都有连接，形成非完全图）。恰好 2 个节点为红(2) 色（终端节点），其余为蓝(1)。生成约束：两终端之间存在唯一最短路径（边数最少），路径长度至少为 3 条边。

**规则**：
1. 将节点视为图的顶点，轨道段视为边。用 BFS 找到两个红(2) 终端节点之间的最短路径。
2. 构造一个 3x3 的二值掩码 M：对于 3x3 节点网格中第 (r,c) 位置的节点，若该节点在最短路径上则 M[r][c]=1（前景），否则 M[r][c]=0（背景）。
3. 以 M 为种子进行一级递归展开：构造一个 9x9 的输出网格（未裁剪前）。对 M 中每个前景位置，放置一份 3x3 的 M 副本，前景像素着绿(3)；对 M 中每个背景位置，放置一个 3x3 全灰(5) 方块。
4. 将 9x9 结果居中放置在一个 11x11 的黑(0) 背景输出网格中（四周各留 1 像素边距）。

**关键洞察**：图的最短路径不是被直接涂色输出的终态，而是生成分形种子的中间表示——同一路径在两个尺度上以自相似方式出现，需要先理解图遍历再理解分形展开。

## 新题 6：计数编码旋转角的锚定拼接

**组合逻辑**：[计数](创新：计数结果编码旋转角度而非条形长度) + [旋转](创新：旋转角度由空间计数动态决定) + [拼接](已有) + [锚定定位](创新：零计数精灵定位锚点) + [标记像素](已有)

**来源原语**：计数、控制像素、计数像素、两侧计数决定长度(2a28add5)；旋转、拼接、矩形精灵体、标记像素、锚定定位(7b3084d4)

**依赖链**：统计每个精灵的标记像素分布 --> 分布不对称性编码旋转角 --> 旋转后的精灵按锚点规则拼接成完整矩形

每个矩形精灵边缘的标记像素数量差编码了该精灵应旋转的角度，旋转后拼接成无缝矩形，标记像素数为零的精灵固定在输出左上角。

**输入结构**：约 18x18 的网格。背景为黑(0)。4 个不重叠的矩形精灵散布在网格中，每个精灵为单一颜色的实心矩形（颜色从蓝(1)、红(2)、绿(3)、黄(4) 中取，各不相同）。每个精灵的边缘像素中，有若干像素被替换为品红(6)（标记像素），这些标记像素分布在精灵的上边缘和右边缘上。生成约束：4 个精灵恰好能拼成一个大矩形（经适当旋转后）；恰好一个精灵没有任何标记像素。

**规则**：
1. 对每个精灵，统计其上边缘的标记像素数量 T 和右边缘的标记像素数量 R。
2. 计算差值 D = T - R。D=0 且无标记 → 不旋转（此精灵为锚定件）；D>0 → 顺时针旋转 90°；D<0 → 顺时针旋转 270°（即逆时针 90°）；D=0 且有标记 → 顺时针旋转 180°。
3. 旋转前，先将所有标记像素恢复为精灵本色（标记仅用于编码旋转信息）。
4. 将锚定件（无标记的精灵）放置在输出矩形的左上角。
5. 将其余 3 个旋转后的精灵拼入输出矩形，使所有精灵无缝铺满矩形、无重叠无间隙。拼接顺序：按精灵在输入中的边界框面积从大到小，依次放入输出中第一个能容纳该精灵的空位（从左到右、从上到下扫描空位）。
6. 输出仅包含拼接后的矩形，不含周围背景。

**关键洞察**：标记像素不是装饰或缺陷，而是一种空间编码——上边缘与右边缘的标记数之差映射到旋转角，必须对比多个示例中不同 D 值与对应旋转结果才能归纳出映射规则。

**关键洞察**：流体的传播路径和填充颜色是完全解耦的两个信息源——路径由左框架缺口拓扑决定，颜色由右框架的位置对应关系决定。必须同时理解这两层逻辑才能求解。

**组合逻辑**：[滑动](创新：滑动后产生的间隙宽度成为排序输入) + [排序](创新：排序键不是预先给定的属性而是滑动操作的副产物) + [色段](已有) + [间隙带](创新：间隙宽度编码信息) + [边界对齐](已有)

同时满足两层约束的变换：每行的色段滑动到右边界对齐，产生的左侧间隙宽度成为各列的排序键，最终按该键对列重新排序。

**输入结构**：约 12x12 的网格。背景为黑(0)。网格中有 4~5 列"活跃列"，每列包含一个连续的单色色段（2~5 像素高），颜色从蓝(1)、红(2)、绿(3)、黄(4)、橙(7) 中取，各列颜色不同。每个色段上方为背景，下方为背景。色段在不同列中的起始行不同，色段长度也不同。非活跃列全为背景。生成约束：各活跃列的色段长度互不相同。

**规则**：
1. 对每个活跃列，将该列的色段向下滑动，直到色段底部与网格最后一行对齐（即色段的最低像素移到该列的最底行）。
2. 滑动后，计算每个活跃列中色段上方的背景像素数量 G（即间隙宽度 = 网格行数 - 色段长度）。
3. 按 G 从小到大对活跃列排序：G 最小的列排在最左边，G 最大的列排在最右边（即色段最长的列排最左，最短的排最右）。
4. 排序后的活跃列紧密排列（中间无空列），从网格第 0 列开始放置。排序后右侧多余的列全填背景。
5. 非活跃列在排序后被移除（被活跃列挤占或变为右侧背景）。

**关键洞察**：滑动和排序不是独立的两步——排序的键值（间隙宽度）恰好由滑动操作创造，如果不先执行滑动，就无法确定排序依据；而等价地，间隙宽度与色段长度互补，但需从示例中归纳出"按间隙升序"而非"按色段降序"（两者在整数上等价，但验证需要多个示例确认方向）。

## 新题 9：面板归属决定重力方向与穿越分隔线时变色

**组合逻辑**：[重力下落](创新：重力方向由面板归属决定，非固定向下) + [对侧面板色](创新：穿越分隔线时触发变色) + [忽略干扰项](已有) + [碰撞停止](已有) + [分隔线](创新：分隔线有缺口允许穿越)

**来源原语**：重力下落、碰撞停止(36a08778)；面板、所属面板、对侧面板色(9b5080bb)；分隔线、忽略干扰项(538b439f)

**依赖链**：面板归属决定每个连通体的重力方向 --> 连通体沿该方向移动直到碰撞停止 --> 能通过分隔线缺口的连通体穿越到对面面板时变为对侧面板色 --> 散布的单像素干扰项不参与移动

两个面板中的连通体在相反的重力方向下运动，穿过分隔线缺口时变色为对侧面板的标识色，单像素干扰项被忽略。

**输入结构**：约 15x15 的网格。背景为黑(0)。一条黄(4) 色全宽水平线在网格中间将其分为上面板和下面板。该分隔线上有 2~3 个缺口（缺口处黄色像素被替换为背景，每个缺口宽 1 像素）。上面板有 2~3 个蓝(1) 色 4-连通连通体（每个 3~5 像素，形状不规则）和若干散布的单个红(2) 像素（干扰项）。下面板有 2~3 个红(2) 色 4-连通连通体（每个 3~5 像素）和若干散布的单个蓝(1) 像素（干扰项）。生成约束：至少一个上面板连通体的某像素列与缺口列重合；至少一个下面板连通体无法穿越（无列对应缺口）。

**规则**：
1. 识别所有 4-连通连通体。像素数为 1 的为干扰项，保持原位不变。像素数 >= 2 的为活跃体。
2. 上面板的活跃体受向下重力：整体向下平移，直到任一像素碰到分隔线（非缺口位置）或碰到另一个已停止的活跃体或到达网格底部。
3. 下面板的活跃体受向上重力：整体向上平移，直到任一像素碰到分隔线（非缺口位置）或碰到另一个已停止的活跃体或到达网格顶部。
4. 穿越判定：当一个活跃体向下（或向上）移动时，若其所有像素所在的列都有缺口，且移动路径上无阻挡，则该活跃体穿过分隔线继续移动到对面面板，直到碰撞停止。穿越后，其颜色变为对面面板的活跃体颜色（蓝变红，红变蓝）。
5. 若活跃体的像素列中有任何一列没有缺口，则该活跃体不穿越，停在分隔线前。
6. 处理顺序：离分隔线近的活跃体先移动（按活跃体最近像素到分隔线的距离从小到大处理）。

**关键洞察**：重力方向是面板依赖的（上向下、下向上），穿越条件是列对齐依赖的（所有列必须有缺口），变色规则是跨面板依赖的——三层条件交织，必须分离干扰项后才能正确识别活跃体，再综合面板、缺口、碰撞三重约束才能确定每个活跃体的终态。

**规则**：
1. 找到高度最大的竖直条（起点）和高度最小的竖直条（终点）。
2. 将竖直条视为节点、走廊段视为边，构建图结构。用 BFS 找到起点到终点的最短路径。
3. 对路径上的所有竖直条（按路径顺序排列），执行反向轮转：颜色序列向右循环移位 1 位（路径上第 i 根条获得第 i-1 根条的颜色，第 0 根获得最后一根的颜色）；同时高度序列向左循环移位 1 位（第 i 根获得第 i+1 根的高度，最后一根获得第 0 根的高度）。
4. 不在路径上的竖直条和所有走廊段保持原色不变。路径上的走廊段重涂为品红(6) 以标记路径。
5. 背景保持不变。

**关键洞察**：高度的极值关系确定了寻路端点（非固定的终端标记），而路径上的条形图属性执行了与全局轮转不同的局部轮转——需理解哪些条在路径上才能确定轮转范围，而路径又依赖于走廊连通性。
