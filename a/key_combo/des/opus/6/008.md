## 新题 1：形状普查同心构建器

**组合逻辑**：[translate_normalize](已有) → [same_shape → marker_grouping](创新：平移归一化后按形状分组，标记色标识组别) → [count](已有，但作用对象变为"组内实例数") → [nested_wrapping](已有，但厚度来源于计数而非色条高度) → [recolor](已有)

**来源原语**：translate_normalize、same_shape（ad38a9d0）；count（aaecdb9a）；nested_wrapping、layer_by_layer_build、concentric_square_frame（45a5af55）；recolor（多题）

**依赖链**：平移归一化确定形状等价类 → 等价类决定分组和标记色 → 组内计数决定同心框每层厚度 → 各组成员的空间位置决定层的排列顺序 → 最终构建同心正方形结构

将散布的小图形按形状分组，用各组实例数量作为层厚构建同心正方形框架，层序由空间位置决定。

**输入结构**：约 20x20 网格，背景黑(0)。散布 8-15 个小型 4-连通单色图形，主体为灰(5)，每个 3-6 像素。每个图形中恰好有一个像素被替换为非灰色标记色（从红(2)、蓝(1)、绿(3)、黄(4)中取）。拥有相同平移归一化掩码（含标记像素相对位置）的图形总是共享相同的标记色。共有 3-5 个不同的形状组，每组 1-4 个实例。各图形互不相邻，且不触碰网格边界。生成约束：不同形状组的标记色两两不同；同组内图形可能位于网格任意位置。

**规则**：
1. 对每个灰色图形做平移归一化（将边界框左上角对齐到原点），得到归一化掩码（含标记像素在掩码中的相对坐标）。
2. 将归一化掩码完全相同的图形归为一组，每组的标识色即为其标记色。
3. 对每组计算实例数量 C。
4. 对各组按以下方式排序：取该组中所有成员的边界框左上角，找行号最小的那个（若行号相同取列号最小的），以此作为该组的排序键，按行优先、列其次升序排列。
5. 构建同心正方形框架：排序第一的组形成中心实心正方形，边长 = 该组的实例计数 C，颜色 = 该组标记色。排序第二的组在中心外围包裹一层正方形框，框厚度 = 该组 C，颜色 = 该组标记色。依此类推逐层向外包裹。
6. 输出：仅包含该同心正方形结构的最小边界框（背景为黑(0)），结构居中。

**关键洞察**：形状恒等性决定分组，空间位置决定层序，实例计数决定层厚——三个逻辑上独立的属性共同约束输出，缺少任何一个都无法唯一确定结果。

## 新题 2：色匹配级联腔体填充

**组合逻辑**：[flood_fill](创新：填充由级联激活触发而非直接由种子触发) ← [path_follow](创新：路径连接腔体而非棋盘格到环) ← [cascade_activation](创新：激活条件增加颜色匹配约束) ← [seed_color_labels_fill](创新：种子色作为激活门控而非直接填充色)

**来源原语**：flood_fill、seed_pixel、enclosed_cavity、line_drawing、connectivity_reachable（8b7bacbf）；path_follow、path_connected（9ba4a9aa）；cascade_activation、chain_reaction_propagation（5961cc34）

**依赖链**：起始腔体激活 → 引导路径确定邻接腔体 → 路径色与目标种子色匹配才允许激活 → 新激活腔体再次发出路径探索 → 级联直到无新激活

从标记起始腔体出发，沿着引导路径级联填充相邻腔体，但只有路径颜色与目标腔体种子色匹配时才能激活。

**输入结构**：约 25x25 网格，背景黑(0)。灰(5)线条画将网格分割为 6-10 个封闭腔体（每个腔体 10-40 像素，形状不规则）。每个腔体内部恰好有一个种子像素，颜色从 {红(2), 蓝(1), 绿(3), 黄(4), 橙(7)} 中取（各腔体种子色可重复）。腔体之间的灰色墙壁上有单像素宽的缺口，缺口外侧有一条由同色像素组成的 4-连通引导路径，该路径穿越背景区域连接到另一个腔体的墙壁缺口。每条引导路径颜色均匀，取自与种子相同的色表。一个特殊腔体的墙壁有一个双像素宽的缺口（"起始门"），其种子为红(2)。生成约束：从起始腔体出发，至少存在一条完整的级联链能激活 3 个以上腔体；同时至少存在 2 条"死路"（路径色与目标种子色不匹配）。

**规则**：
1. 找到起始腔体（拥有双像素宽缺口的那个），将其内部背景像素用红(2)填充（种子像素保留）。
2. 检查所有从已填充腔体墙壁缺口出发的引导路径。沿每条路径的像素序列走到另一端的腔体。
3. 对每条到达的目标腔体：比较引导路径颜色与该腔体种子像素颜色。仅当两者相同时，用种子色填充该腔体的内部背景像素。若不同，该路径为死路，不填充。
4. 对每个本轮新填充的腔体，重复步骤 2-3。
5. 级联持续直到没有新腔体被激活。
6. 未被激活的腔体保持原状（背景色 + 种子像素不变）。引导路径像素和灰色墙壁始终保持不变。

**关键洞察**：引导路径同时编码连接拓扑和颜色约束——路径颜色必须与目标种子色匹配才能激活，形成一个颜色选择性的传播网络。部分路径通向种子色不匹配的腔体，构成阻断级联的死路。

## 新题 3：压缩后象限旋转

**组合逻辑**：[compress/compact_to_anchor](已有) → [rotate/quadrant_rotation](已有，但旋转对象是压缩后的象限内容而非原始网格)

**来源原语**：compress、compact_to_anchor、anchor_block、ray_pixel、ray_belongs_anchor（f28a3cbb）；rotate、tile、quadrant_rotation、quadrant（cf5fd0ad）

**依赖链**：散布像素沿视线压缩至锚块 → 压缩结果改变各象限的空间内容 → 象限旋转对压缩后的臂结构施加几何变换 → 四象限旋转后涌现出向心对称图案

将四个象限中散布的射线像素压缩到各自锚块后，对每个象限施加不同角度的旋转，使外指的压缩臂变为向心对称图案。

**输入结构**：16x16 网格，背景黑(0)。网格被等分为 4 个 8x8 象限。每个象限包含恰好一个 3x3 实心锚块，颜色分别为红(2)、蓝(1)、绿(3)、黄(4)（每象限一个唯一颜色），锚块中心位于该象限的中心位置（即距象限边界各 2-3 像素）。每个锚块有 2-5 个同色散布像素，分别位于从锚块出发的行、列或对角线视线上（同一视线上可有多个），均在同一象限内且不触碰象限边界。生成约束：每个锚块至少有两个不同方向的散布像素。

**规则**：
1. 对每个锚块，将其所有同色散布像素沿各自视线（行/列/对角线）向锚块方向滑动，直到紧贴锚块边缘或紧贴另一个已滑动到位的同色像素。原始散布位置清除为背景。
2. 压缩完成后，对每个象限独立施加旋转：左上象限旋转 180 度，右上象限顺时针旋转 90 度，左下象限逆时针旋转 90 度，右下象限不旋转（0 度）。旋转以象限中心为中心。
3. 输出：16x16 网格，各象限内容为压缩 + 旋转后的结果。

**关键洞察**：压缩将散布像素聚拢为方向性的"臂"结构（如从锚块向右和向下各伸出几个像素）。这些臂的朝向在压缩阶段看似随意，但经过特定的象限旋转后，原本朝外的臂统一转向网格中心，四个锚块的臂形成一个向心对称图案——这种涌现效应只有压缩和旋转联合才能产生。

## 新题 4：象限门控楔形传播

**组合逻辑**：[erase/distractor_ignored](已有) → [containing_quadrant](已有，但同时编码偏移参数) → [diagonal_propagate + row_swap_bicolor](已有，但传播区域受象限约束)

**来源原语**：erase、distractor_ignored、control_pixel、containing_quadrant、quadrant（87ab05b8）；fill、diagonal_propagate、shrinking_wedge、top_row_band、row_swap_bicolor（b5bb5719）

**依赖链**：擦除干扰像素以净化画布 → 控制像素的象限位置选择传播区域 → 控制像素的象限内行深度设定起始偏移 → 顶行色带按收缩楔形规则向下传播但仅绘制在选定象限内

擦除干扰项后，由控制像素选定一个象限并编码行偏移，顶行色带的收缩楔形仅在该象限内绘制且跳过顶部若干行。

**输入结构**：15x15 网格（奇数边长），背景橙(7)。第 0 行（顶行）包含一段关于网格中心列对称的、由红(2)和灰(5)交替排列的色带（宽度为奇数，5-11 像素）。网格中散布 5-10 个干扰像素，颜色从 {蓝(1), 绿(3), 黄(4)} 中取，不位于第 0 行。网格中恰好有一个额外的红(2)像素（控制像素），位于第 0 行以下且不在中心行或中心列上。生成约束：控制像素不与任何干扰像素相邻；控制像素在其所属象限内的行深度（距象限顶边的行数）不超过楔形在该象限可延展的总行数。

**规则**：
1. 擦除所有干扰像素（非红、非灰、非背景的像素）为背景色。
2. 以中心行和中心列将网格等分为四个象限。确定控制像素所在的象限。
3. 计算控制像素在其象限内的行偏移 K（控制像素行号减去该象限首行行号）。
4. 按 b5bb5719 规则从顶行色带向下传播收缩楔形：对第 0 行以下的第 r 行（r >= 1），楔形覆盖列范围 [span_left + r, span_right - r]；每个楔形像素的颜色取自其左上方对角线对应的顶行像素，且每下一行红↔灰互换一次。
5. 但仅绘制落在控制像素所属象限内的楔形像素；其他象限的楔形像素不绘制（保持背景）。
6. 在所选象限内，额外跳过前 K 行的楔形像素（即该象限最顶部 K 行不绘制楔形，从第 K+1 行开始绘制）。
7. 擦除控制像素本身为背景色。

**关键洞察**：控制像素从单个位置同时编码两个独立参数——所在象限选择传播区域，象限内行深度决定传播起始偏移。两者共同约束楔形的可见部分，必须同时确定才能画出正确输出。

## 新题 5：格线分区多数过滤

**组合逻辑**：[four_corner_bound/missing_intersection](创新：缺失交叉点定义分区边界而非裁剪输出) → [count](创新：对分区内外分别计数同色连通分量) → [erase](创新：按多数规则选择性擦除)

**来源原语**：lattice_line、missing_intersection、four_corner_bound、background_hole、crop（a644e277）；count、connected_component（aaecdb9a）；erase、distractor_ignored（87ab05b8）

**依赖链**：缺失交叉点确定分区矩形 → 对每种颜色独立统计分区内外的连通分量数 → 多数侧保留、少数侧擦除 → 各颜色可能保留不同侧

通过格线缺失交叉点划定分区，对每种前景色独立统计分区内外的连通分量数量，保留多数侧、擦除少数侧。

**输入结构**：约 25x25 网格，背景黑(0)。绿(3)格线（1 像素粗，水平和垂直各 3-5 条，等间距）形成规则网格图案。恰好有四个格线交叉点为背景色（缺失），这四个点构成一个轴对齐矩形的四角。格线单元格中散布若干 8-连通单色物体，颜色从 {红(2), 蓝(1), 黄(4), 橙(7)} 中取（3-4 种颜色），每种颜色有 3-7 个连通分量，每个分量 2-10 像素。物体不与绿色格线重叠。生成约束：对至少两种颜色，分区内外的分量数不相等；至少一种颜色的多数在内侧，至少一种颜色的多数在外侧；不存在横跨分区边界的分量（每个分量完全在内或完全在外）。

**规则**：
1. 找到四个缺失的格线交叉点（背景色替代了绿色格线像素的位置），它们确定一个轴对齐矩形的四角，定义"分区边界"。
2. 对每种非绿、非背景的前景色，分别计算分区边界内部（含边界行列）的 8-连通分量数量 C_in 和外部的数量 C_out。
3. 对每种颜色独立决定：若 C_in > C_out，擦除该颜色在分区外部的所有分量（置为背景）。若 C_out >= C_in（含相等），擦除该颜色在分区内部的所有分量。
4. 绿色格线和缺失交叉点保持不变。
5. 输出：完整的 25x25 网格（不裁剪）。

**关键洞察**：缺失交叉点定义的是分区而非裁剪——输出保留全网格。不同颜色可能因各自的分区内外多数关系而保留不同的侧面，使得最终输出中某些颜色只在分区内出现、某些只在分区外出现。

## 新题 6：路径定向旋转印章

**组合逻辑**：[path_follow](已有) → [rotate](创新：旋转角度由路径到达方向编码而非固定象限分配) → [stamp](已有，但放置位置由路径终点决定而非栅格偏移) → [erase](已有)

**来源原语**：path_follow、checkerboard、ring_object、guide_pixel、path_connected、endpoint_adjacent（9ba4a9aa）；rotate、quadrant_rotation（cf5fd0ad）；stamp、template、overlap_recolor（a395ee82）；erase（87ab05b8）

**依赖链**：引导路径的可达性筛选目标环 → 路径到达目标的方向编码旋转角度 → 路径访问顺序决定重叠覆盖优先级 → 模板在各目标位置旋转印章 → 非目标元素擦除

沿引导路径从棋盘格出发访问可达的环形目标，按路径到达方向旋转模板后印章到各目标位置。

**输入结构**：约 25x25 网格，背景黑(0)。左上角 5x5 区域内有一个由蓝(1)像素组成的非对称模板形状（4-连通，6-12 像素，形状不规则且关于任何轴都不对称）。网格中有一个 3x3 棋盘格对象（蓝(1)和黑(0)交替，中心为蓝(1)）。另有 4-6 个 3x3 环形对象（外圈 8 像素为某种颜色，中心为背景），颜色从 {红(2), 绿(3), 黄(4), 橙(7)} 中取（可重复）。引导像素分布于 2 格间距的格点上，颜色均匀，形成从棋盘格出发可沿水平或垂直方向逐步追踪的路径网络。生成约束：棋盘格恰好有一个相邻引导像素；路径可分叉；至少 2 个环可达、至少 1 个环不可达；不同的可达环的路径到达方向不全相同。

**规则**：
1. 找到棋盘格对象，识别其唯一相邻引导像素的颜色。
2. 从该引导像素开始，沿同色引导像素以 2 格水平/垂直步进追踪路径（路径可分叉）。
3. 路径相邻（8-邻域）的环形对象标记为"目标"。对每个目标，记录路径到达它的方向（路径末端引导像素相对于环中心的方位）：从北侧到达 → 0 度，从东侧到达 → 顺时针 90 度，从南侧到达 → 180 度，从西侧到达 → 逆时针 90 度。
4. 按路径访问顺序（从棋盘格出发的 BFS 序，同层按行优先列其次）处理各目标：将模板旋转该目标对应的角度后，以环中心为模板边界框中心进行印章放置，印章颜色使用该环的外圈颜色。
5. 若多个印章重叠，后放置（BFS 序更晚）的覆盖先放置的。
6. 擦除棋盘格对象、所有引导像素和非目标环形对象（置为背景）。目标环形对象本身被印章覆盖。保留模板原件不变。

**关键洞察**：路径网络同时执行三重功能——筛选哪些环获得印章（可达性过滤）、编码每个印章的旋转角度（到达方向）、决定重叠冲突的覆盖优先级（BFS 序）。不可达的环是干扰项。

## 新题 7：弹射计数柱状图

**组合逻辑**：[ray_cast + bounce](已有，但射线不继承墙壁色) → [count](创新：计数对象是弹射次数而非连通分量数) → [sort](已有，但排序键是弹射数而非颜色) → [histogram](创新：柱高编码弹射数而非分量计数)

**来源原语**：ray_cast、bounce、arrow_sprite、wall_pixel、collision_stop、color_inheritance（142ca369）；count、sort、histogram、connected_component、fixed_color_order、baseline_aligned（aaecdb9a）

**依赖链**：箭头发射射线 → 射线与墙壁交互产生弹射 → 弹射次数作为每支箭头的统计量 → 按弹射次数升序排序 → 排序结果构建底部对齐柱状图

模拟每支箭头的对角弹射路径，统计弹射次数后按升序排列为柱状图。

**输入结构**：约 20x20 网格，背景黑(0)。3-5 个箭头精灵体（2x2 边界框中缺少一个角的 L 形，3 像素），每个箭头颜色唯一，从 {红(2), 蓝(1), 绿(3), 黄(4), 橙(7)} 中取。散布若干灰(5)墙壁像素（8-20 个），不与箭头重叠。生成约束：任意两支箭头互不相邻；每支箭头的射线在终止前经历 0-5 次弹射；不同箭头的弹射次数不全相同。

**规则**：
1. 每支箭头从其缺角方向发射一条对角线射线。
2. 射线在背景像素上行进，逐格绘制箭头颜色。遇到墙壁像素时：若正面撞击（沿对角线方向的下一格是墙壁）则两个对角分量同时反转；若侧面接触（对角线方向无障碍但某一轴方向有墙壁）则仅反转接触轴的分量。弹射时射线保持箭头原色（不继承墙壁色）。
3. 射线在以下情况终止：下一步超出网格边界；下一步命中另一支箭头精灵体（不绘制该格）。
4. 记录每支箭头射线的弹射总次数 B。
5. 按 B 升序排列所有箭头。若 B 相同，按箭头边界框左上角位置排序（行优先升序，行相同则列优先升序）。
6. 输出一个新网格：宽度 = 箭头总数，高度 = 所有箭头中最大的 B 值（若最大 B 为 0 则高度为 1），背景黑(0)。按排序后的顺序从左到右，每支箭头占一列（1 像素宽），从底部向上填充该箭头颜色，高度等于其 B 值。B=0 的列保持全背景。

**关键洞察**：完整的空间弹射模拟仅仅是为了得到每支箭头的一个整数（弹射次数）。输出完全丢弃了射线路径的空间信息，将复杂的几何模拟压缩为一维排序柱状图——从空间域到统计域的抽象跳跃。

## 新题 8：图例双重映射楔形与光晕

**组合逻辑**：[diagonal_propagate + row_swap_bicolor](已有) + [dilate + holes_preserved](已有) ← [legend_mapping](创新：同一图例同时映射楔形色和膨胀光晕色) + 物体阻挡楔形传播（创新交互）

**来源原语**：diagonal_propagate、shrinking_wedge、top_row_band、row_swap_bicolor（b5bb5719）；dilate、color_legend、legend_mapping、enclosed_hole、holes_preserved（5adee1b2）；recolor（多题）

**依赖链**：图例定义源色→目标色映射 → 顶行色带按楔形规则传播并经图例变色 → 前景物体阻挡楔形传播产生空缺 → 物体膨胀的光晕色也由同一图例决定 → 光晕部分填入楔形空缺区但不填孔洞

顶行色带的收缩楔形经图例变色后向下传播，遇前景物体被阻挡；物体按同一图例膨胀光晕，光晕部分填补楔形空缺，但物体内孔洞保持为背景。

**输入结构**：约 20x20 网格，背景橙(7)。左上角有一个 2 行的颜色图例：第一行为 1x2 块，左像素红(2)、右像素蓝(1)；第二行为 1x2 块，左像素灰(5)、右像素绿(3)。图例表示映射关系：红→蓝、灰→绿。第 0 行（顶行）从图例右侧起有一段红(2)和灰(5)交替排列的色带（宽 7-13 像素，奇数宽度）。网格下方散布 2-4 个 4-连通单色小物体（红(2)或灰(5)，每个 4-10 像素，形状不规则），其中至少一个包含由背景色构成的封闭孔洞（1-3 像素的内部空腔，被物体像素完全围合）。各物体互不相邻，且不触碰网格边界或顶行色带。生成约束：至少一个物体位于楔形传播路径上（即该物体的某些像素所在行列会被楔形覆盖）。

**规则**：
1. 从第 0 行色带向下传播收缩楔形：对第 r 行（r >= 1），楔形覆盖列范围 [span_left + r, span_right - r]（若区间为空则该行无楔形）。每个楔形像素的原始颜色取自其左上对角线对应的第 0 行色带像素，并在每下移一行时将红↔灰互换。
2. 应用图例映射对楔形像素变色：红(2)→蓝(1)，灰(5)→绿(3)。
3. 楔形像素不覆盖已有的前景物体像素——物体阻挡传播（该像素位置保留物体原色）。
4. 对每个前景物体，计算其边界框向外扩展 1 格（上下左右各 1 格，裁剪至网格范围内）。在扩展区域中，将背景像素（橙(7)）填充为该物体源色经图例映射后的目标色（红色物体的光晕为蓝(1)，灰色物体的光晕为绿(3)）。但不填充物体内部的封闭孔洞（孔洞像素保持背景色），也不覆盖已有的楔形像素或其他物体像素。处理顺序：按物体边界框左上角行优先、列其次升序依次处理。
5. 擦除图例本身（图例区域像素置为背景色）。
6. 输出：完整的 20x20 网格。

**关键洞察**：颜色图例同时驱动两个视觉上完全不同的效果——楔形图案的色调变换和物体膨胀光晕的颜色选择——通过共享同一映射表实现统一的配色方案。物体物理阻挡楔形传播产生的空缺被光晕部分弥合，形成楔形、物体、光晕三者的空间交织。
