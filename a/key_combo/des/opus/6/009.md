## 新题 1：奇偶模板铺贴

**组合逻辑**：[奇偶性选色](创新：由选色改为选模板形状) + [像素放大] + [颜色到模板映射](创新：双模板双色交错)

**来源原语**：奇偶性选色(5e6bbc0b)、棋盘格图案(5e6bbc0b)、像素放大(42f83767)、模板遮罩(42f83767)、颜色到模板映射(42f83767)、色卡(42f83767)

**依赖链**：棋盘格每个像素的奇偶性决定选用哪个模板遮罩 → 该像素的颜色决定遮罩内活性像素的填充色 → 两者共同决定输出中每个 k×k 块的图案

根据棋盘格像素的位置奇偶性选取模板形状，再以该像素颜色填充模板，逐像素放大为铺贴图案。

**输入结构**：网格约 15×15，分为上方图例区和下方棋盘区，中间隔一行背景色黑(0)。图例区包含两个 k×k（k 约为 3~4）的灰(5)色模板遮罩，从左到右排列，间隔 1 列背景色。遮罩内部分像素为灰(5)、其余为黑(0)背景（即遮罩有镂空）。两个遮罩形状不同（不同示例中具体形状会变化，可能是对角线图案、十字图案、角落图案等，用结构属性而非固定名称描述）。棋盘区为一个 M×N（M、N 约 3~5）的双色棋盘格，使用两种非背景非灰颜色（如红(2)和蓝(1)），相邻像素颜色交替。生成约束：两个模板遮罩尺寸相同且均为正方形；棋盘区每行每列严格颜色交替；两个遮罩内灰色像素数量不同（确保可区分）。

**规则**：
1. 将图例区的两个模板遮罩按从左到右的顺序编号为模板 A 和模板 B。
2. 对棋盘区的每个像素 (r, c)（r 为像素在棋盘区内的行号，c 为列号，均从 0 开始），计算 (r + c) mod 2。若结果为 0，选用模板 A；若结果为 1，选用模板 B。
3. 将该像素替换为所选模板的一个副本：模板中灰(5)像素改涂为该棋盘像素的颜色，模板中黑(0)像素保持为背景(0)。
4. 输出网格大小为 (M×k) 行 × (N×k) 列，仅包含展开后的铺贴结果，不包含图例区。
5. 不同示例中模板的具体形状不同，但规则（奇偶选模板、颜色填充）保持一致。

**关键洞察**：棋盘格的位置奇偶性不再选择颜色（如源题 5e6bbc0b），而是选择几何模板——同一颜色的像素因位置不同会展开为不同的形状图案，需要对比多个示例才能确定"奇偶→模板"这一非颜色维度的映射规则。

## 新题 2：蛇径编码重力方向

**组合逻辑**：[展直/遍历顺序](创新：蛇径方向编码为操作参数) → [重力下落] + [碰撞停止]

**来源原语**：蛇形路径(7b5033c1)、端点(7b5033c1)、遍历顺序(7b5033c1)、保留像素序(7b5033c1)、封闭区域(88e364bc)、墙壁障碍(8f3a5a89)、重力下落(88e364bc)、可移动像素(88e364bc)、碰撞停止(88e364bc)

**依赖链**：蛇形路径的遍历顺序 → 对每个封闭区域，找到第一个沿其墙壁的蛇径直线段 → 该段的遍历方向成为区域内可移动像素的重力方向 → 像素在区域内滑动并堆叠

蛇形路径在走廊中蜿蜒，其局部行进方向决定相邻封闭区域内黄色像素的重力朝向。

**输入结构**：网格约 18×18，背景黑(0)。蓝(1)色墙壁将网格分割为若干互不连通的矩形封闭区域（每个区域至少 3×3 内部空间），区域之间有宽度至少为 1 的走廊。每个封闭区域内部有 1~3 个黄(4)像素散布在背景上。一条灰(5)色蛇形路径在走廊中蜿蜒通过，路径为 4-连通单像素宽度链，恰好有两个端点（仅一个路径邻居的像素）。蛇径至少经过每个封闭区域的一侧墙壁旁。生成约束：每个封闭区域至少有一个蛇径直线段沿其某条墙壁外侧经过（即该段中每个灰色像素与该区域的某个蓝色墙壁像素 4-相邻）；蛇径不穿过墙壁也不进入封闭区域内部；各封闭区域为轴对齐矩形。

**规则**：
1. 找到蛇径的两个端点（仅有一个 4-邻居路径像素的灰色像素），选择行号更小的为起点（行号相同则选列号更小的）。从起点沿蛇径依次遍历每个像素。
2. 将蛇径分解为极大直线段（每段内所有像素在同一行或同一列上连续排列）。每段的方向为沿遍历顺序从段首到段尾的方向（上/下/左/右四个方向之一）。
3. 对每个封闭区域，扫描所有蛇径直线段，找到第一个（按段首像素在遍历序列中的位置最早的）与该区域的墙壁正交相邻（段中至少一个灰色像素与该区域的蓝色墙壁像素 4-相邻）的直线段。该段的方向即为此区域的重力方向。
4. 在每个区域内，所有黄(4)像素沿重力方向滑动。滑动按距远端墙壁由近到远的顺序依次执行（最靠近重力方向远端墙壁的像素先移动），每个像素一直移动到碰到该区域的远端墙壁或另一个已停止的黄色像素为止。
5. 垂直于重力方向的坐标保持不变（像素只沿重力方向平移）。
6. 蛇径像素和墙壁像素在输出中保持不变。

**关键洞察**：蛇径不只是路径——它的局部行进方向是对相邻区域重力方向的隐式编码；理解这一编码需要先确定蛇径遍历的起点和方向，然后将空间上的路径方向转化为区域内的物理操作。

## 新题 3：缺角三角形充当区域填充模板

**组合逻辑**：[缺角定位](创新：缺角形状用作填充模板而非连线) + [形状匹配/缩放对应] + [填充]

**来源原语**：标记像素(1478ab18)、包围方块(1478ab18)、缺角定位(1478ab18)、缺角为直角顶点(1478ab18)、直角三角形(1478ab18)、形状匹配(898e7135)、缩放对应(898e7135)、封闭区域(88e364bc)、填充(aaef0977)、重涂色(aaef0977)、擦除(52364a65)

**依赖链**：三个同色标记点的缺角位置 → 确定直角三角形的朝向 → 三角形作为二值模板 → 按边界框边长与封闭矩形区域尺寸匹配 → 模板内像素填充为标记颜色

从标记点方阵的缺角推断三角形朝向，将该三角形作为模板填充到尺寸匹配的矩形区域内。

**输入结构**：网格约 20×20，背景黑(0)。网格中有若干组标记点（每组 3 个同色像素），每组使用不同颜色（如红(2)、绿(3)、蓝(1)等，共 2~4 组）。每组 3 个像素恰好占据一个正方形边界框（边长 S，S 在 3~6 之间）的三个角位置，第四个角为背景色（即缺角）。此外网格中有若干个灰(5)色轴对齐矩形框（由灰色像素围成的 1 像素宽矩形边框，内部为背景色），每个框的内部空间为正方形且边长等于某组标记点的边界框边长 S。标记点组数与矩形框数量相同。生成约束：不同标记组的边界框不重叠且不与矩形框重叠；每组标记点的边界框边长唯一（无两组边长相同）；矩形框内部为空（纯背景色）。

**规则**：
1. 对每组同色标记点，确定其 S×S 边界框中缺失的角位置（左上/右上/左下/右下）。
2. 根据缺角构造一个 S×S 的直角三角形二值模板：缺角位置为直角顶点，两条直角边沿边界框的两条边延伸，斜边连接另外两个有标记的角。模板中三角形区域内的像素（从直角顶点出发，第 i 行含 i+1 个或 S-i 个像素，取决于朝向，使整体构成一个填满半个正方形的阶梯形三角区域）标记为"填充"，其余标记为"背景"。具体地：若缺角在左上，则第 r 行（从 0 开始）的填充像素为列 0 到列 r（含），构成左上→右下的三角形。若缺角在右上，则第 r 行的填充像素为列 (S-1-r) 到列 (S-1)。若缺角在左下，则第 r 行的填充像素为列 0 到列 (S-1-r)。若缺角在右下，则第 r 行的填充像素为列 r 到列 (S-1)。
3. 将每组标记点与内部边长相同的灰色矩形框配对（唯一匹配）。
4. 在每个配对的矩形框内部，按三角形模板填充：模板中"填充"位置的像素涂为对应标记组的颜色，"背景"位置保持黑(0)。模板左上角对齐矩形框内部空间的左上角。
5. 标记点像素在输出中擦除为背景色。灰色矩形框边框保留不变。

**关键洞察**：三个标记点的"缺角"不是用来画线（如源题 1478ab18），而是定义一个三角形的朝向——几何推理的结果被重新用作另一个区域的空间填充模板，配对关系则由尺寸而非颜色决定。

## 新题 4：叠加修补嵌套框架后按深度染色

**组合逻辑**：[标记对齐 + 透明叠加](创新：叠加目的从补全精灵变为修补墙壁缺口) → [泛洪填充/可达性] → [重涂色](创新：颜色由嵌套深度循环决定)

**来源原语**：标记对齐(83eb0a57)、透明叠加(83eb0a57)、共享标记(83eb0a57)、框架(898e7135)、泛洪填充(8f3a5a89)、可达性(8f3a5a89)、重涂色(21897d95)、封闭区域(88e364bc)、循环色板(aaef0977)

**依赖链**：散布的修补精灵通过共享标记对齐叠加到框架上 → 叠加修补了框架墙壁的缺口 → 泛洪填充从网格角落开始确定各区域可达性 → 不可达区域的嵌套深度（被几层框架包围）决定该区域的填充颜色

用散落的修补块按标记对齐修补嵌套矩形框架的缺口，然后按封闭深度给内部区域染色。

**输入结构**：网格约 22×22，背景黑(0)。网格中有 2~3 个嵌套的蓝(1)色矩形框架（1 像素宽的矩形边框，一个套在另一个内部，各框架之间有至少 2 像素的间隔）。每个框架有 1~2 个缺口（缺口为框架边上连续 2~3 个蓝色像素被擦除为背景）。网格外围（最外层框架之外）散布若干小型修补精灵（每个由 2~4 个蓝(1)色像素组成的 4-连通块），每个精灵中恰好有 1 个像素为红(2)标记色。每个框架缺口的一端旁边（缺口外侧 4-相邻位置）也恰好有 1 个红(2)标记像素。每个修补精灵与恰好一个框架缺口的红色标记共享位置对齐关系。生成约束：修补精灵叠加到框架后恰好填补所有缺口，使每层框架各自完全封闭；修补前所有嵌套层的内部区域都因缺口而连通到外部；精灵数量等于缺口数量；各精灵形状与对应缺口互补。

**规则**：
1. 对每个修补精灵，找到网格中与之红(2)标记像素位置最近（曼哈顿距离最小）的缺口旁红色标记。将精灵平移使精灵中的红色像素与该缺口旁的红色标记重合。
2. 在平移后的位置，将精灵的蓝(1)色像素叠加到网格上（覆盖背景像素），红色标记像素保留为红色。此操作修补了对应缺口。
3. 对所有精灵完成叠加后，从网格左上角 (0,0) 开始进行 4-连通泛洪填充，标记所有从该角可达的背景像素为"外部"（蓝色框架和红色标记为障碍，不可穿越）。
4. 剩余的背景像素形成若干封闭区域。每个封闭区域的"嵌套深度"定义为：从外部区域出发，沿任意路径到达该区域最少需穿越的蓝色框架层数（即跨过的蓝色连通边框数量）。
5. 按深度重涂色：深度 1 的封闭区域内所有背景像素填红(2)，深度 2 填绿(3)，深度 3 填黄(4)。若存在更深层，循环使用红(2)→绿(3)→黄(4)。
6. 框架像素（蓝色）在输出中保持蓝(1)。红色标记像素保持红(2)。外部区域保持背景色黑(0)。

**关键洞察**：叠加操作的目的不是补全精灵图案（如源题 83eb0a57），而是修补墙壁缺口——叠加改变了网格的拓扑连通性，从而决定了哪些区域被封闭以及各区域的嵌套深度，嵌套深度再循环映射为颜色。三步操作的信息依次变换：几何形状→拓扑连通性→整数深度→颜色。

## 新题 5：边缘标记射线交叉点作为距离场种子

**组合逻辑**：[连线](创新：从边缘标记向内画贯穿射线) → [距离映射 + 曼哈顿距离](创新：种子点为射线交叉点而非预设标记) + [循环色板]

**来源原语**：连线(1478ab18)、边缘标记(5e6bbc0b)、标记像素(aaef0977)、距离映射(aaef0977)、曼哈顿距离(aaef0977)、循环色板(aaef0977)

**依赖链**：边缘标记的位置决定射线的行列 → 射线绘制在网格上 → 水平线和垂直线的交叉点成为距离场种子 → 每个非射线像素按到最近种子的曼哈顿距离索引循环色板得到颜色

从网格边缘的标记像素画轴对齐射线，射线交叉点成为曼哈顿距离场的种子，用循环色板为全网格染色。

**输入结构**：网格约 17×17，背景橙(7)。网格四条边上共有 4~8 个青(8)色标记像素：上边和下边的标记将产生垂直线，左边和右边的标记将产生水平线。标记像素不位于网格四个角落。生成约束：至少有 1 个标记在上边或下边，且至少有 1 个标记在左边或右边，确保至少存在一个交叉点；同一行或同一列上不会有两个标记（即不同标记产生的射线两两不同行不同列）。

**规则**：
1. 从每个边缘标记像素出发，沿垂直于该边的方向画一条青(8)色直线，贯穿整个网格直到对面边缘。上边/下边的标记画垂直线（整列涂青色），左边/右边的标记画水平线（整行涂青色）。
2. 标识所有交叉点：同时属于某条水平线和某条垂直线的像素。交叉点像素保持青(8)色。
3. 对网格中每个非青色像素，计算它到所有交叉点中最近一个的曼哈顿距离 D（取最小值）。
4. 按 D 值用循环色板重涂色：D mod 5 = 0 → 绿(3)，D mod 5 = 1 → 黄(4)，D mod 5 = 2 → 黑(0)，D mod 5 = 3 → 灰(5)，D mod 5 = 4 → 红(2)。
5. 所有青色射线像素（包括交叉点和非交叉的射线像素）在输出中保持青(8)色不变。

**关键洞察**：距离场的种子不是输入中预设的标记点（如源题 aaef0977），而是由射线绘制后产生的交叉点——种子位置是计算的中间结果而非直接输入，求解者需先推断射线规则、计算交叉位置，才能定位距离场种子并完成染色。

## 新题 6：可达性分区决定局部操作类型

**组合逻辑**：[泛洪填充/可达性](决策节点) → {可达区域：[擦除 + 相对自身定位]} / {不可达区域：[压缩 + 标记定方向]}（条件分支）

**来源原语**：泛洪填充(8f3a5a89)、可达性(8f3a5a89)、墙壁障碍(8f3a5a89)、边界连通区分结构(8f3a5a89)、角落标记(8f3a5a89)、装饰碎片(8f3a5a89)、擦除(52364a65)、相对自身定位(52364a65)、按对象局部裁切(52364a65)、压缩(5e6bbc0b)、标记定压缩方向(5e6bbc0b)、边缘标记(5e6bbc0b)

**依赖链**：角落标记确定泛洪填充起点 → 可达性将前景对象分为两组 → 可达组执行局部擦除（删除每个对象自身边界框内最左两列） → 不可达组执行压缩（向角落标记所在边压缩） → 装饰性墙壁碎片被擦除

泛洪填充从角落标记出发，可达区域的前景对象局部裁剪左两列，不可达区域的对象向标记侧压缩，装饰墙壁被清除。

**输入结构**：网格约 18×18，背景黑(0)。蓝(1)色像素形成墙壁结构，将网格分为若干区域。其中一些墙壁与网格边界 4-连通相连（结构性墙壁），另一些完全在网格内部不接触边界（装饰性碎片，约 2~4 个小的 4-连通蓝色块，每个 2~5 像素）。网格的一个角落有一个品红(6)标记像素。各区域中散布着若干红(2)色 4-连通前景对象（每个 4~8 像素，连通且不规则），每个对象的边界框至少跨 3 列。生成约束：结构性墙壁将网格分为至少两个从角落标记不互通的背景区域（可达区域和不可达区域各至少一个）；每个区域至少有一个红色前景对象；装饰碎片不影响区域连通性（移除它们不会连通原本分隔的区域）；品红标记在网格四角之一。

**规则**：
1. 识别墙壁类型：与网格边界 4-连通相连的蓝(1)色连通分量为结构性墙壁，保留不变；不与网格边界相连的蓝色连通分量为装饰碎片，擦除为背景(0)。
2. 从品红(6)角落标记出发，以结构性墙壁为障碍进行 4-连通泛洪填充，标记所有可达的背景像素。
3. 对可达区域中的每个红(2)色前景对象：在该对象自身边界框内，将最左 2 列中的红色像素擦除为背景(0)，该对象其余红色像素保持不变。
4. 对不可达区域中的每个红(2)色前景对象：确定品红标记所在的网格边（上/下/左/右）。将该对象的所有像素整体向该边方向水平或垂直平移，直到该对象最靠近该边的像素紧贴结构性墙壁或网格边缘。像素间的相对位置不变。若多个对象在同一行/列上压缩，按距目标边由近到远的顺序依次移动（近的先停，远的堆在其后方）。
5. 品红标记像素在输出中保留。

**关键洞察**：同一网格中的同类对象（红色前景）接受完全不同的操作（局部擦除 vs. 整体压缩），分流依据是一个全局属性（从角落标记的可达性）——求解者需先做泛洪填充推理判断每个对象属于哪个分区，才能确定应施加哪种变换。

## 新题 7：分隔框架的房间数决定精灵印章次数

**组合逻辑**：[计数/区域数映射](创新：计数结果作为空间操作的重复参数) → [印章覆盖] + [颜色匹配] + [重叠停止]

**来源原语**：计数(89565ca0)、区域数映射长度(89565ca0)、分隔框架(89565ca0)、封闭区域(89565ca0)、印章覆盖(985ae207)、精灵体(985ae207)、中心像素(985ae207)、颜色匹配(985ae207)、重叠停止(985ae207)

**依赖链**：每个分隔框架的封闭区域数 N → N 同时决定配对精灵的印章重复次数 → 精灵通过中心像素颜色与框架颜色匹配 → 印章沿框架最长边方向步进，直到完成 N 次或碰到非背景像素停止

数清每个彩色分隔框架内的封闭房间数，将配色精灵沿框架方向重复印章该次数。

**输入结构**：网格约 22×22，背景黑(0)。网格中有 2~3 个不同颜色的分隔框架（每个由同一颜色的 1 像素宽线条构成的矩形外框加若干内部分隔线，如红(2)框架、绿(3)框架等），每个框架内被分隔线分成 N 个背景色的封闭矩形房间（N 在 2~5 之间）。框架之间不重叠，间距至少 2 像素。网格中另有 2~3 个 3×3 的精灵体，每个精灵的 8 个边框像素为同一颜色（如蓝(1)），中心像素颜色与某个框架颜色相同（如中心为红(2)对应红色框架）。精灵与框架不重叠，精灵之间不重叠。生成约束：每个框架颜色唯一且与精灵边框色不同；每个精灵的中心色匹配恰好一个框架；框架非正方形（最长边方向明确）；精灵沿其印章方向有足够空间完成所需次数的印章而不超出网格。

**规则**：
1. 对每个分隔框架，计算其内部 4-连通的背景色封闭区域数量 N。
2. 将每个 3×3 精灵与其中心像素颜色相同的框架配对。
3. 确定印章方向：若框架水平边更长，印章方向为水平（若精灵在框架左侧或正上/下方偏左则向右，否则向左）；若框架垂直边更长，印章方向为垂直（若精灵在框架上方或正左/右方偏上则向下，否则向上）。精灵在框架的哪一侧由精灵中心与框架中心的相对位置判断。
4. 从精灵原位置开始，沿印章方向每 3 个像素步进，复制完整的 3×3 精灵（保留边框色和中心色），共复制 N-1 次（加上原位的精灵共 N 个副本）。
5. 若某次复制的 3×3 区域与任何非背景像素（包括框架或其他精灵的印章轨迹）重叠，则该次及其后所有复制取消，已完成的副本保留。
6. 框架和未被覆盖的背景保持不变。

**关键洞察**：计数操作的结果（房间数 N）不是直接映射为输出中的几何长度（如源题 89565ca0 的柱状图），而是跨操作传递为另一种操作（印章重复）的参数——一个数值在两种截然不同的空间操作之间架起了桥梁。

## 新题 8：缺口朝向决定多对象同步滑动与碰撞分流

**组合逻辑**：[缺口决定方向](创新：从靠边改为四方向自由滑动) + [重力下落/碰撞停止](创新：多对象同步运动的碰撞交互) + [重涂色](创新：涂色由最终运动方向决定)

**来源原语**：边框缺口(320afe60)、缺口决定方向(320afe60)、重涂色(320afe60)、前景对象(320afe60)、靠边对齐(320afe60)、重力下落(df9fd884)、碰撞停止(88e364bc)、滑动(88e364bc)

**依赖链**：每个对象的边界框缺口位置 → 确定该对象的滑动方向（四个基本方向之一） → 所有对象同步开始滑动 → 碰撞检测决定各对象的停止位置 → 最终是否移动及运动方向决定重涂色

每个前景对象的边界框缺口决定其滑动方向，对象同步滑动并在碰撞时停止，最终按运动方向重涂色。

**输入结构**：网格约 16×16，背景黄(4)。网格中散布 4~6 个蓝(1)色 4-连通前景对象（每个 4~8 像素，连通但不规则，边界框至少 3×3），对象间不相邻（边界框间隔至少 1 像素）。每个对象的边界框恰好在一侧有一个缺口：该侧的边界框边上存在一个被背景色占据的位置，且该位置沿边框方向的两侧各有该对象的至少一个像素。缺口可以出现在上/下/左/右任意一侧，不同对象的缺口方向可以不同。生成约束：每个对象的边界框恰好只有一侧有缺口（其余三侧边框上凡是边框位置都有该对象的像素或被对象像素包围）；所有对象颜色相同均为蓝(1)。

**规则**：
1. 对每个前景对象，检测其边界框四侧哪侧有缺口（该侧的边界框边上存在背景色像素，且该背景像素沿边框方向的两侧各有该对象的至少一个像素）。缺口在上侧→该对象向上滑动；缺口在下侧→向下；缺口在左侧→向左；缺口在右侧→向右。
2. 所有对象同步开始滑动。模拟逐步进行：每个时间步中，每个尚未停止的对象沿自身方向移动 1 个像素（整个对象平移 1 格）。
3. 在每个时间步结束时检测碰撞：若某对象的当前位置导致其任一像素与另一个对象（无论该对象是否已停止）的任一像素占据同一格，或该对象的任一像素超出网格边界，则回退该步移动并将该对象标记为"已停止"。同一时间步中多个对象同时发生碰撞时，各自独立回退并停止。
4. 重复步骤 2-3 直到所有对象停止。
5. 重涂色：最终位置相对于初始位置水平移动过的对象（向左或向右，且移动距离 >= 1）涂红(2)；垂直移动过的对象（向上或向下，且移动距离 >= 1）涂绿(3)；未移动的对象（第一步就发生碰撞被阻挡）保持蓝(1)不变。
6. 背景保持黄(4)。

**关键洞察**：缺口方向不再仅仅决定左右靠边（如源题 320afe60），而是决定四向自由滑动——多对象同步运动产生涌现性碰撞交互，某些对象可能因被其他对象的运动路径阻挡而提前停止甚至完全无法移动，这改变了它们的最终颜色分类。单个示例中某些碰撞情况可能不出现，需对比多个示例才能归纳完整的碰撞与染色规则。

## 新题 9：对象形状隐式编码模板选择

**组合逻辑**：[形状匹配/八方向匹配](创新：匹配目的从拼块填充孔洞变为索引选择) + [像素放大] + [颜色到模板映射](创新：索引由形状而非颜色确定)

**来源原语**：形状匹配(898e7135)、八方向匹配(898e7135)、拼块(898e7135)、像素放大(42f83767)、模板遮罩(42f83767)、颜色到模板映射(42f83767)、索引网格(42f83767)、连通分量(337b420f)

**依赖链**：图例区展示索引形状与模板遮罩的配对 → 下方散布的前景对象通过形状匹配（含旋转/翻转的 8 个朝向）找到对应的索引形状 → 匹配到的模板遮罩用于像素放大该对象 → 放大时模板活性像素涂为该对象的颜色

对象的几何形状（而非颜色）隐式选择一个模板遮罩，然后用该模板将对象的每个像素放大为一个图案块。

**输入结构**：网格约 22×22，背景黑(0)。网格上方为图例区，包含 2~3 对"索引形状 + 模板遮罩"配对，从左到右排列，每对之间隔 2 列背景色。每个索引形状为灰(5)色的小型 4-连通图形（3~5 像素），位于其配对模板遮罩的正上方，间隔 1 行背景色。每个模板遮罩为一个 k×k（k 约 3~4）的方块区域，其中部分像素为灰(5)（活性像素），其余为黑(0)（镂空像素）。图例区下方隔 2 行背景色为散布区，包含 2~4 个不同颜色的 4-连通前景对象（如红(2)、绿(3)、蓝(1)、橙(7)等），每个对象由 3~5 像素组成。生成约束：每个下方对象的形状在旋转/翻转的 8 个朝向中恰好匹配一个图例索引形状（以像素相对位置为准，忽略颜色）；不同索引形状之间在 8 个朝向下互不相同（确保匹配唯一）；下方对象间距足够大，使放大后的区域不重叠。

**规则**：
1. 从图例区提取每对索引形状和模板遮罩。同一对中索引形状在模板遮罩正上方，配对关系由上下位置确定（索引形状的水平中心与模板遮罩的水平中心对齐，取最近者配对）。
2. 对散布区的每个前景对象，提取其形状（像素的相对位置集合，归一化为左上角对齐），与图例中每个索引形状在 8 个朝向（0/90/180/270 度旋转，各搭配是否水平翻转）下进行匹配。找到唯一匹配的索引形状。
3. 取该索引形状配对的 k×k 模板遮罩。对前景对象的每个像素，在输出中替换为该模板遮罩的一个副本：遮罩中灰(5)位置涂为该前景对象的颜色，遮罩中黑(0)位置保持背景色(0)。
4. 输出网格仅包含散布区的放大结果。各对象的放大区域按对象原始边界框左上角位置乘以 k 定位。对象按其原始边界框左上角从上到下、从左到右的顺序依次放置（先放置的优先占据像素，后放置的遇到已占据像素时跳过该像素）。
5. 输出网格大小取所有放大区域的最小包围矩形。

**关键洞察**：模板选择的索引不是颜色值（如源题 42f83767 用颜色选模板），而是对象本身的几何形状——求解者必须先识别形状匹配关系（还要考虑旋转/翻转的 8 个朝向），才能确定每个对象应使用哪个模板进行放大。这使得选择机制从一维（颜色查表）变为高维（形状空间匹配）。
