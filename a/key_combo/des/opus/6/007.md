## 新题 1：墙壁分区下的重力落入与形状嵌孔

**组合逻辑**：[重力下落](创新：受墙壁阻断的竖直下落) + [嵌入填充](创新：候选池由可达性过滤) ← [可达性](创新：墙壁划分每个孔洞的可匹配精灵集) + [形状匹配孔洞] + [面积区分角色]

**来源原语**：重力下落·面积区分角色（6ca952ad），嵌入填充·形状匹配孔洞·旋转翻转不变（67e490f4），墙壁障碍·可达性（dd6b8c4b）

**依赖链**：面积区分角色先把前景对象分为移动精灵和模板框架 → 墙壁障碍把网格上半区划分为若干竖直通道，每条通道下方对应模板框架中不同的孔洞 → 精灵沿自身所在通道竖直下落（被墙壁限制不可横跨通道） → 每个精灵只能与本通道底部直接对应的那个孔洞做形状匹配（旋转/翻转允许） → 匹配成功则以精灵颜色填充孔洞并擦除精灵；匹配失败则精灵停在通道底部模板框架顶面上方

将散布在被墙壁分隔的竖直通道中的彩色精灵按重力下落，只有沿自身通道可达的孔洞才能尝试形状匹配并填充。

**输入结构**：
- 约 20x20 网格，背景色为黑(0)。
- 网格下部有一个单色模板框架（灰(5)），框架内部有若干孔洞（黑(0)背景区域），各孔洞形状不同（4~8 像素的 4-连通区域）。
- 网格上半部分散布若干单色精灵体（3~8 像素的 4-连通图形），每个精灵颜色各不相同（从红(2)、绿(3)、黄(4)、蓝(1)、品红(6)中选取），每个精灵的面积 > 3 像素。
- 上半部分有若干竖直的品红(6)墙壁段（宽 1 像素、高至少 3 像素），将上半区域分隔为互不连通的竖直通道。每条通道底部恰好对应模板框架中的一个孔洞。
- 生成约束：每条通道至多包含一个精灵；每个孔洞至多被一条通道覆盖；恰好有若干精灵的形状（在旋转/翻转下）与其通道对应的孔洞形状一致，其余精灵不匹配任何孔洞。

**规则**：
1. 按通道从左到右的顺序依次处理每个精灵。
2. 将精灵整体向下平移，直到精灵的最低像素行抵达模板框架顶面上方一行（即框架边界框顶行 - 1）或网格底部（取先到者）。精灵不可穿越墙壁或模板框架像素。
3. 检查该精灵的形状（像素的相对坐标集合）在 4 种旋转 x 2 种翻转下是否与该通道正下方的孔洞形状一致。
4. 若匹配：擦除精灵（恢复为背景），将孔洞区域填充为精灵的颜色。
5. 若不匹配：精灵停留在步骤 2 的落点位置，颜色不变。
6. 墙壁和模板框架本身在输出中保持不变。

**关键洞察**：墙壁不只是阻挡运动的障碍物——它们划定了每个精灵的"管辖孔洞"，使得形状匹配不是全局搜索而是一对一的局部判定。即使某个精灵的形状与另一通道的孔洞完美匹配，它也无法到达那个孔洞。

## 新题 2：可达单点计数决定同心菱形轮廓层数

**组合逻辑**：[计数](创新：计数对象为经可达性过滤的单点) + [描边](创新：画菱形轮廓，层数由计数结果决定) ← [可达性](创新：墙壁限定每个菱形中心可访问的单点集合) + [同心定位] + [颜色决定操作](创新：颜色决定菱形层数的奇偶起始)

**来源原语**：计数·计数决定尺寸·角落控制点（902510d5），描边·菱形轮廓·半径微调（d753a70b），可达性·墙壁障碍（dd6b8c4b），同心定位·中心点（522fdd07），颜色决定操作（d753a70b）

**依赖链**：墙壁把网格分成若干区域，每个区域中央有一个彩色中心点 → 从每个中心点出发，通过地板格（不穿越墙壁）做洪泛，统计可达的单像素标记点数量 k → 以该中心点为圆心，画 k 层同心曼哈顿菱形轮廓（半径分别为 1, 2, ..., k） → 中心点颜色决定涂色模式：红(2)中心从半径 1 开始用红画奇数层、灰(5)画偶数层；灰(5)中心反之

在被墙壁隔开的区域中，每个中心点根据可达的标记点数量画出对应层数的同心菱形轮廓，中心颜色决定奇偶层着色方案。

**输入结构**：
- 约 25x25 网格，背景色为黑(0)。
- 栗(9)色墙壁段将网格分隔为 2~4 个不规则区域（每个区域面积足够容纳半径约 5 的菱形）。墙壁为 4-连通的连续线段。
- 每个区域内恰好有一个中心点像素，颜色为红(2)或灰(5)。
- 网格中散布若干橙(7)色单像素标记点，分布在各个区域内（有些可能紧贴墙壁但位于地板侧）。
- 生成约束：每个区域内的标记点数量为 1~5；不同区域内标记点数量不全相同；每个区域的面积大于以该区域标记点数量为半径的菱形面积，保证菱形不会被裁剪。

**规则**：
1. 对每个中心点，执行从该中心出发的 4-连通洪泛（只经过背景色和橙(7)色格子，不穿越墙壁和其他中心点），统计可达的橙(7)标记点数量 k。
2. 擦除所有橙(7)标记点（恢复为背景色）。
3. 以该中心点为圆心，依次画半径 r = 1, 2, ..., k 的曼哈顿菱形轮廓（菱形轮廓 = 到中心曼哈顿距离恰好为 r 的所有像素）。
4. 涂色规则取决于中心点颜色：
   - 红(2)中心：奇数层（r = 1, 3, 5, ...）用红(2)，偶数层（r = 2, 4, ...）用灰(5)。
   - 灰(5)中心：奇数层用灰(5)，偶数层用红(2)。
5. 中心点像素本身保持原色不变。
6. 墙壁保持不变。若菱形轮廓像素落在墙壁上或网格外，则该像素不画（跳过）。
7. 处理顺序：各区域独立处理，无交互。

**关键洞察**：同一个标记点的作用完全取决于它属于哪个区域（由墙壁决定）——改变墙壁的布局会重新分配标记点的归属，从而改变每个菱形的层数。求解者需要同时推断出洪泛规则、计数规则和交替涂色规则。

## 新题 3：空心符号开口方向编码射线发射

**组合逻辑**：[压缩](创新：空心符号压缩为单像素) + [射线延伸](创新：射线方向由符号的开口位置决定，而非外部标记) ← [朝向编码方向](创新：空心符号的开口位置取代三角精灵体的功能) + [碰撞变色规则]

**来源原语**：压缩·空心符号·栅格对齐（afe3afe9），射线延伸·碰撞变色规则·朝向编码方向（409aa875）

**依赖链**：每个空心 3x3 符号有一个缺口（8 个边框像素中恰缺 1 个），缺口的位置（上/下/左/右）编码一个射线方向 → 将每个 3x3 符号压缩为其中心像素颜色的单像素，放置在粗栅格的对应位置 → 每个压缩像素沿其方向发射射线，射线行进直到碰到另一个压缩像素或网格边界 → 射线路径上的空格涂为该像素的颜色 → 两条射线交汇于同一空格时该格涂为蓝(1)，射线命中另一个已有的压缩像素时该像素重涂为栗(9)

空心符号先压缩为点，再沿符号缺口方向发射彩色射线；交叉点变蓝，命中已有点变栗。

**输入结构**：
- 约 15x15 网格，背景色为黑(0)。
- 网格上按 4x4 的粗栅格排列若干空心 3x3 符号（相邻符号间隔 1 列/行的背景）。每个符号是单色的 3x3 边框，但恰好缺少 8 个边框位置中的 1 个像素（中心像素始终为背景色，即符号是空心的）。
- 缺口方向定义：缺口在顶行中央 → 方向为上；缺口在底行中央 → 方向为下；缺口在左列中央 → 方向为左；缺口在右列中央 → 方向为右。
- 各符号颜色从红(2)、绿(3)、黄(4)、橙(7)中选取，不同符号颜色可相同。
- 生成约束：至少 4 个符号；至少有一对符号面对面发射（射线会相遇）；至少有一条射线会命中另一个符号的压缩位置。粗栅格上不是所有位置都有符号。

**规则**：
1. 将每个空心 3x3 符号压缩为 1 个像素，颜色为该符号的边框色，放置在粗栅格中对应的单元格（即原符号中心在粗栅格中的坐标）。清除所有非压缩像素（粗栅格外的像素全部恢复为背景色）。输出网格的尺寸为粗栅格的尺寸。
2. 确定每个压缩像素的射线方向（由原符号的缺口方向决定）。
3. 按从左到右、从上到下的顺序依次处理每个压缩像素。从该像素出发沿射线方向逐格前进：
   - 若下一格为背景色且无其他射线占据：涂为当前像素的颜色。
   - 若下一格已被另一条射线涂色（非蓝(1)）：将该格涂为蓝(1)，射线继续前进。
   - 若下一格已为蓝(1)：保持蓝(1)，射线继续前进。
   - 若下一格是另一个压缩像素：将该压缩像素重涂为栗(9)，射线停止（不穿透）。
   - 若到达网格边界：射线停止。
4. 发射顺序严格按照步骤 3 的从左到右、从上到下扫描顺序；后发射的射线遇到先发射射线的痕迹时触发交叉规则。

**关键洞察**：同一个视觉元素（空心符号的缺口）同时编码了符号身份和射线方向。在源题中，压缩和射线发射使用完全不同的对象类型（空心符号 vs 三角精灵体），这里将两者融合到一个对象上，使求解者必须从同一形状中提取两层信息。

## 新题 4：类比推断轮廓操作与稀有色画笔

**组合逻辑**：[类比推理](源题用法：从训练对推断变换) + [轮廓描边](创新：描的是外侧轮廓而非简单映射) + [擦除] ← [训练对映射] + [外侧相邻](创新：轮廓定义来自类比推断的结果) + [最小色为画笔](创新：画笔色由测试框内部的稀有色独立决定)

**来源原语**：类比推理·训练对映射·调色板匹配配对·空心框（4c7dc4dd），轮廓描边·外侧相邻·最小色为画笔·擦除（aa62e3f4）

**依赖链**：网格中有三个空心方框，各自内部包含小图案 → 两个框的内部调色板相同（训练对），第三个框为测试输入 → 观察训练对：源框内部是实心图形，目标框内部是该图形的外侧轮廓 → 推断变换规则为"提取外侧 4-邻接轮廓，擦除原始内容" → 轮廓的绘制颜色不是简单复制——目标框中轮廓的颜色是源框内部最稀有的颜色 → 将此规则应用于测试框：擦除测试框内部的所有图形，画出其外侧轮廓，颜色为测试框内部最稀有的非背景色

通过训练对推断"实心→外侧轮廓"的变换规则，并用测试框内部最稀有色作为轮廓画笔色，输出测试框的变换结果。

**输入结构**：
- 约 20x20 网格，背景色为黑(0)。
- 三个不重叠的空心方框（边框宽 1 像素），方框颜色各不相同（如红(2)、绿(3)、蓝(1)），大小约为 7x7 至 9x9。
- 每个方框内部包含一个由 2~3 种颜色组成的 4-连通实心图案（3~12 像素），图案不触碰方框边框。
- 训练对的两个方框内部使用完全相同的颜色集合（调色板一致）；测试方框的内部调色板与训练对不同。
- 训练源框内部是实心图案；训练目标框内部是该图案的外侧 4-邻接轮廓，轮廓颜色为源框内部出现像素数最少的颜色。
- 生成约束：训练源框和目标框的方框颜色不同但内部调色板相同；测试框的方框颜色与另外两个都不同；每个方框内部至少有 2 种非背景色且各色像素数不同（保证"最稀有色"唯一）。

**规则**：
1. 识别训练对：找到内部调色板（非背景色集合）相同的两个方框，它们构成训练源→目标。第三个方框为测试输入。
2. 判断源→目标的方向：训练对中内部像素数较多的为源框，较少的为目标框（轮廓比实心图案像素少）。
3. 推断变换：源框内部的实心图案被替换为其外侧 4-邻接轮廓（即：所有与实心图案 4-邻接但自身为背景色的像素集合）。轮廓颜色 = 源框内部出现像素数最少的颜色。
4. 应用于测试框：擦除测试框内部的所有非背景像素，计算其原始图案的外侧 4-邻接轮廓，用测试框内部最稀有的非背景色绘制该轮廓。
5. 输出仅包含测试框（裁剪到测试框的边界框），边框保留，内部只有变换后的轮廓。

**关键洞察**："做什么变换"和"用什么颜色"来自两个独立的信息通道。变换类型（实心→外侧轮廓）需要从训练对比较中归纳，而画笔颜色需要在测试框内部独立地计算稀有度。仅看一个训练示例对也可能看到轮廓，但无法确定轮廓颜色的选取规则——必须对比训练源与目标的颜色统计。

## 新题 5：帧序列外推与菱形半径循环缩放

**组合逻辑**：[外推](创新：外推的量是菱形半径而非空间位移) + [缩放/收缩/膨胀](创新：半径按循环序列变化而非等差递进) ← [帧序列·等间距排列](框架结构) + [同心定位·菱形轮廓](操作对象) + [边长循环变换](创新：循环应用于菱形半径而非正方形边长) + [匀速运动延续](创新："匀速"指半径变化率恒定)

**来源原语**：外推·帧序列·等间距排列·匀速运动延续·平移（ba1aa698），缩放·边长循环变换·奇数边正方形·同心定位（522fdd07），菱形轮廓·收缩·膨胀·半径微调（d753a70b）

**依赖链**：输入是一排共享边框的面板（帧序列） → 每个面板内部包含一个以面板中心为圆心的菱形轮廓 → 观察连续面板中菱形半径的变化：半径以恒定步长 delta 递减或递增 → 当半径减至 0 时，下一步跳变为最大半径（循环规则，类似 1→9→7→5→3→1） → 输出是外推的下一个面板：按相同 delta 继续变化半径（必要时执行循环跳变），并保持面板的填充色和边框色

从帧序列中归纳菱形半径的等差+循环变化规律，外推生成下一帧面板。

**输入结构**：
- 网格为一行 3~4 个共享竖直边框列的面板。每个面板宽 9 列、高 9 行（含边框）。面板边框色为绿(3)，面板填充色为黑(0)。
- 每个面板的内部（7x7 区域）包含一个以内部中心为圆心的曼哈顿菱形轮廓。菱形轮廓颜色为红(2)，半径为 r（r 属于 {1, 2, 3}，因为内部区域最大支持半径 3）。
- 连续面板中的菱形半径形成一个等差序列，步长 delta = -1 或 +1。
- 当半径经过步长调整后变为 0：实际半径跳变为 3（最大值），即循环 1 → (0→3) → 2 → 1。当半径经过步长调整后变为 4：实际半径跳变为 1（最小值），即循环 3 → (4→1) → 2 → 3。
- 生成约束：至少 3 个面板；面板序列中至少经历一次循环跳变（以便求解者能从示例中归纳循环规则）。

**规则**：
1. 读取连续面板中菱形的半径序列 r_1, r_2, ..., r_n，推断步长 delta = r_2 - r_1（在循环发生之前的面板之间测量）。
2. 计算下一个半径 r_next = r_n + delta。
3. 若 r_next <= 0，则 r_next = 3（最大循环值）。若 r_next >= 4，则 r_next = 1（最小循环值）。
4. 构建一个独立面板（宽 9 列含左右边框，不与输入共享边框）。
5. 在该面板内部以中心为圆心画半径 r_next 的红(2)曼哈顿菱形轮廓。面板边框为绿(3)，填充色为黑(0)。
6. 输出仅为该独立面板。

**关键洞察**：外推的目标不是位移量而是几何参数（半径），并且半径变化遵循循环边界条件。仅凭最后一帧无法确定输出——必须观察连续多帧来区分等差递减和循环跳变后的继续递减。

## 新题 6：被遮挡区域用碎片拼图补全（镜像对称约束消歧）

**组合逻辑**：[补全](创新：补全所需的填充图案来自外部碎片而非自身颜色) + [拼图组装](创新：拼图的"孔洞"是遮挡产生的缺失区域) ← [前景遮挡·被遮挡形状·矩形足迹](确定缺失区域) + [碎片·形状匹配孔洞](碎片匹配缺失区域) + [镜像对称](创新：对称约束用于从多个候选碎片中选出唯一正确的那个) + [同色不相邻](附加约束)

**来源原语**：补全·被遮挡形状·矩形足迹·前景遮挡·隐含区域重涂（52df9849），拼图组装·碎片·镜像对称·同色不相邻（e8686506），形状匹配孔洞·旋转翻转不变（67e490f4）

**依赖链**：网格中若干前景色矩形互相遮挡 → 每个被遮挡矩形的完整足迹可从其可见部分推断（矩形边界框） → 被遮挡区域（足迹内被其他颜色覆盖的部分）形成一个不规则形状的"缺口" → 网格边缘散布着若干小碎片，每个碎片的形状在旋转/翻转下与某个缺口匹配 → 用匹配的碎片的颜色填充缺口 → 若多个碎片在旋转/翻转后都能匹配同一个缺口：选择使得补全后的矩形具有左右镜像对称性的那个碎片 → 额外约束：最终结果中同色碎片不可 4-邻接

用外部碎片填补被遮挡矩形的缺失区域，以镜像对称约束在多候选碎片中做唯一消歧。

**输入结构**：
- 约 18x18 网格，背景色为黑(0)。
- 网格中部有 2~3 个单色实心矩形，颜色各不相同（如红(2)、蓝(1)、黄(4)），部分矩形互相遮挡（前景矩形覆盖后方矩形的部分像素）。遮挡关系可从 z-order 推断：后方矩形的可见像素加上被覆盖像素恰好填满一个完整矩形。
- 网格边缘区域（距离中部矩形群至少 2 格）散布 2~4 个小碎片（每个碎片为 2~5 像素的 4-连通单色图形），碎片颜色为绿(3)、橙(7)或灰(5)。
- 生成约束：每个被遮挡矩形恰好有一个缺口（一块被前方矩形覆盖的连通区域）；每个缺口恰好有一个碎片在旋转/翻转下形状匹配（可能有多个碎片形状相同但只有一个使补全结果满足镜像对称）；碎片的颜色与被遮挡矩形的颜色不同。

**规则**：
1. 对每个被遮挡矩形，根据其可见像素推断完整的矩形边界框（bbox 内所有非背景像素加上被其他颜色占据的像素构成完整矩形）。
2. 缺口 = bbox 内被其他矩形颜色占据的像素集合（这些像素属于前方矩形）。提取缺口的形状（相对坐标集合）。
3. 在边缘碎片中搜索与缺口形状在 4 种旋转 x 2 种翻转下匹配的碎片。
4. 若唯一匹配：用该碎片的颜色替换缺口中的像素（即将前方矩形在该缺口区域的颜色替换为碎片颜色）。
5. 若多个碎片匹配：逐个试放，选择使补全后的被遮挡矩形（原色 + 碎片色的组合图案）具有左右镜像对称性的碎片。
6. 已使用的碎片从网格边缘擦除（恢复为背景色）。
7. 处理顺序：按被遮挡矩形的 bbox 左上角从左到右、从上到下处理。
8. 最终检查：输出中同色碎片填充区域不可 4-邻接（此约束保证唯一解）。

**关键洞察**：补全不是简单地用自身颜色填回缺口，而是从外部碎片池中搜索匹配件。碎片带来新颜色，使得补全后的矩形变成了双色图案。镜像对称约束是消歧的关键——它不是装饰性要求，而是在多候选碎片中选出唯一正确答案的必要条件。

## 新题 7：聚集方向编码印章朝向

**组合逻辑**：[聚集](创新：聚集路径的方向信息被保留) + [印章放置](创新：印章的旋转角度由聚集方向决定) + [擦除] ← [可达性·墙壁障碍](过滤可聚集的标记) + [距离排序填充](决定聚集顺序) + [颜色替换](印章重涂色) + [模板图案](印章模板)

**来源原语**：聚集·距离排序填充·可达性·墙壁障碍·目标块·标记像素·擦除（dd6b8c4b），印章放置·模板图案·颜色替换·规则示例（abc82100）

**依赖链**：网格中有一个青(8)色的 T 形模板图案和一个红(2)色目标中心点 → 散布着若干栗(9)色标记像素，被品红(6)色墙壁分隔 → 只有从标记像素到目标中心可通过地板洪泛到达的标记像素才是候选 → 按到目标中心的曼哈顿距离排序，取最近的 4 个 → 这 4 个标记像素聚集到目标中心周围的 4 个基本方向格（上/下/左/右） → 每个标记像素被青(8)色模板图案的一个副本替换，副本的旋转角度由该标记像素到目标中心的方向决定（从左方来→模板不旋转；从上方来→顺时针 90 度；从右方来→180 度；从下方来→逆时针 90 度） → 模板副本被重涂为该标记像素原始位置所在区域的地板主色

将可达的标记像素聚集到目标中心，并在每个聚集位置放置模板印章，印章朝向由标记到达的方向决定。

**输入结构**：
- 约 20x20 网格，背景色为黑(0)。
- 品红(6)色墙壁段将网格划分为若干区域。每个区域内的非墙壁非标记非目标像素有一个主色（从蓝(1)、绿(3)、黄(4)、橙(7)中选取，不同区域主色不同），作为该区域的"地板色"。
- 恰好 1 个红(2)色像素为目标中心，位于某个区域内。
- 5~8 个栗(9)色单像素标记散布在各区域中。
- 恰好 1 个青(8)色 T 形模板图案（一个 3x2 或 2x3 的非对称 4-连通图形，约 4~5 像素），位于网格边角。
- 生成约束：至少 4 个标记像素可通过洪泛（经地板色格子，不穿越墙壁）到达目标中心；可达标记到目标的曼哈顿距离互不相同；恰好从上、下、左、右各方向各有一个最近可达标记（即 4 个最近标记分别从 4 个不同方向接近目标中心）。

**规则**：
1. 从目标中心做 4-连通洪泛（经过地板色和栗(9)色格子，不穿越墙壁、模板、目标本身），标记所有可达的栗(9)标记像素。
2. 按曼哈顿距离到目标中心从近到远排序，选取最近的 4 个标记。
3. 对每个选中的标记，确定其相对于目标中心的主方向（若标记在目标正上方或偏上：方向=上；正下方或偏下：方向=下；正左方或偏左：方向=左；正右方或偏右：方向=右。主方向 = 曼哈顿距离中绝对值较大的那个轴，若相等则取行方向优先）。
4. 擦除选中的 4 个标记（恢复为所在区域的地板色），擦除青(8)色模板图案（恢复为背景色）。未选中的标记保持不变。
5. 在目标中心的上/下/左/右各 1 格处放置模板图案的旋转副本：
   - 从左方聚集来的 → 模板原始朝向（不旋转），锚点对齐到目标左方格。
   - 从上方聚集来的 → 模板顺时针旋转 90 度，锚点对齐到目标上方格。
   - 从右方聚集来的 → 模板旋转 180 度，锚点对齐到目标右方格。
   - 从下方聚集来的 → 模板逆时针旋转 90 度（即顺时针 270 度），锚点对齐到目标下方格。
   - 模板的锚点为其边界框的左上角像素。
6. 每个模板副本重涂色：青(8)替换为该标记原始所在区域的地板主色。
7. 目标中心像素保持红(2)。模板副本超出网格边界的像素不画。

**关键洞察**：聚集操作通常只关心"谁被聚集了"，但这里还保留了"从哪个方向来"的信息，并将其传递给后续的印章旋转操作。方向信息在源题中是丢失的中间产物，这里被提升为关键参数。同时，印章的重涂色来自标记的来源区域而非标记本身的颜色，形成了第二条信息通道。

## 新题 8：标记路由与拓扑条件分支重涂色

**组合逻辑**：[移动](创新：标记按相对顺序决定移动目的地) + [重涂色](创新：重涂方案由目标对象的拓扑属性分支选择) + [填充] + [描边] ← [标记在矩形外侧·相对顺序决定出口](路由规则) + [包含关系·封闭孔洞·有孔触发重涂](拓扑判断) + [频率排序·少数色替换](备选重涂方案)

**来源原语**：移动·标记在矩形外侧·相对顺序决定出口·标记像素·擦除（e4941b18），重涂色·描边·封闭孔洞·有孔触发重涂·包含关系（aa4ec2a5），频率排序·少数色替换（9caf5b84）

**依赖链**：网格中有若干独立的前景对象和一行标记像素在对象上方 → 标记像素成对出现，每对中两个标记颜色不同 → 每对标记的左右相对顺序决定它们"指向"对象群的哪一侧（左侧标记先→指向左半区对象，右侧标记先→指向右半区对象） → 标记被移动（路由）到其指向的最近对象上 → 被标记选中的对象执行拓扑条件分支重涂色：若对象有封闭孔洞 → 对象体涂青(8)、孔洞填品红(6)、外侧描红(2)轮廓；若对象无孔洞 → 对象中少数色像素被替换为橙(7)

标记对按左右顺序路由到目标对象，然后根据目标对象是否含孔洞来分支选择两套不同的重涂色方案。

**输入结构**：
- 约 18x22 网格，背景色为黑(0)。
- 网格中部偏下区域有 4~6 个分离的 4-连通前景对象，由 2~3 种颜色组成（如蓝(1)和绿(3)混合），面积 8~20 像素。部分对象内部有 4-连通的黑(0)封闭孔洞（完全被对象像素包围），部分对象没有孔洞。
- 对象按水平位置可分为左半区和右半区（以网格中线为界，每半区至少 1 个对象）。
- 网格最上方一行有 2~3 对标记像素。每对标记由一个红(2)像素和一个灰(5)像素组成，水平相邻。不同标记对之间间隔至少 2 个背景格。
- 生成约束：标记对的数量 <= 对象数量的一半（不是每个对象都会被选中）；左半区和右半区中各自至少有一个含孔洞对象和一个不含孔洞对象。

**规则**：
1. 对每一对标记，判断其内部顺序：若红(2)在灰(5)左边 → 该标记对指向左半区；若灰(5)在红(2)左边 → 该标记对指向右半区。
2. 在指向的半区中，选择离该标记对水平中心最近的尚未被选中的对象作为目标（按对象 bbox 中心的水平距离衡量）。若距离相等，选择 bbox 中心更靠上的对象。
3. 擦除该标记对（恢复为背景色）。
4. 对选中的目标对象执行拓扑分支：
   - **有孔洞分支**：将对象所有像素重涂为青(8)；将对象内部的每个封闭孔洞（4-连通背景区域完全被对象像素包围）填充为品红(6)；在对象+孔洞填充的整体外围画 1 像素宽的红(2) 8-邻接轮廓。
   - **无孔洞分支**：统计该对象使用的各颜色的像素数量；将出现次数最少的颜色的所有像素替换为橙(7)；若多色并列最少则全部替换。
5. 标记对按从左到右的顺序依次处理（先处理左边的标记对）。
6. 未被任何标记对选中的对象保持原样不变。

**关键洞察**：标记对的内部排列顺序（红-灰 vs 灰-红）是一个隐蔽的方向编码，必须对比多个示例才能归纳出这条规则。更深层的洞察是：同一个"选中"操作之后分叉为两种完全不同的视觉效果（有孔→青+品红+红轮廓 vs 无孔→少数色→橙），使得求解者需要同时推断路由规则和两套分支规则。
