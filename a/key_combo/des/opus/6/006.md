## 新题 1：对称分类重力分道

**组合逻辑**：[重涂色/recolor] + [排序/sort] + [重力下落/gravity_drop]（已有原语），以 [对称类型决定颜色/symmetry_det_color]（创新：原题中对称类型直接映射输出颜色，此处对称类型决定的是空间路由——进入哪条车道）作为决策节点，[高度排序/height_ordering]（创新：原题中按柱高排序，此处按精灵体像素数排序后决定重力堆叠顺序）决定落位

**来源原语**：重涂色、对称类型决定颜色、对称轴 ← a09f6c25；排序、重分配、高度排序、柱状条、基线、槽位保持颜色 ← 31f7f899；重力下落、碰撞停止 ← f0100645；单像素为噪声 ← a09f6c25

**依赖链**：对称分类决定每个精灵体归属哪个车道 → 车道归属决定精灵体的目标 x 坐标 → 同车道内按像素数排序决定堆叠的 y 坐标 → 重涂色使用车道的颜色。删去对称分类则车道分配无据；删去排序则同车道内堆叠顺序不确定；删去重力下落则无法得到最终位置

根据对称类型将散布的精灵体归入对应颜色车道，同车道内按像素数从小到大重力堆叠

**输入结构**：
- 背景：黑(0)。网格约 18x22。
- 一条灰(5)水平基线横跨整个网格宽度，位于网格下方约第 18 行。
- 基线上方散布 6-9 个单色 4-连通小精灵体（每个 3-7 像素，形状不规则且互不相同），每个精灵体使用不同的非黑非灰颜色。精灵体互不相邻、不接触基线。此外，网格中散布 2-3 个孤立的单像素点（颜色与某些精灵体相同），这些是噪声。
- 基线正下方一行中有 3 个等距的单像素彩色标记，分别为蓝(1)、绿(3)、红(2)（从左到右），标记所在列即为车道列。
- 生成约束：每个非噪声精灵体恰好属于三种反射对称类型之一——水平轴对称、垂直轴对称、无对称。每种类型至少有 2 个精灵体。不存在同时拥有多种对称的精灵体。

**规则**：
1. 忽略所有孤立单像素（噪声），只处理像素数 >= 2 的 4-连通精灵体。
2. 判定每个精灵体的反射对称类型：水平轴对称、垂直轴对称、或无对称。
3. 对称类型到车道颜色的映射需通过对比多个示例归纳（例如，所有示例中水平轴对称→蓝(1)车道，垂直轴对称→绿(3)车道，无对称→红(2)车道；但具体映射在不同题目实例中可能不同）。
4. 将同车道内的精灵体按像素数升序排列；若像素数相同，则按精灵体边界框左上角行坐标较小者优先。
5. 从基线向上逐个放置：将排序后第一个（最小）精灵体的边界框底边紧贴基线、边界框水平中心对齐车道列（若边界框宽度为偶数，中心偏左取整）。后续精灵体的边界框底边紧贴前一个精灵体的边界框顶边。
6. 每个精灵体重涂为其所在车道的标记颜色。
7. 原位置的精灵体和噪声像素擦除为背景色。基线和车道标记保持不变。

**关键洞察**：车道标记颜色与对称类型的对应关系是隐藏规则，必须对比多个输入输出示例才能确定；这一隐藏映射同时控制了空间路由和颜色重涂两个维度。

## 新题 2：绕障路径连接器配对

**组合逻辑**：[绕障重绘/reroute_around_obstacle]（创新：原题中单条线段绕单个障碍，此处多条路径各自绕不同障碍）+ [连接配对/connector_pairing]（创新：原题中连接器用于拼接精灵体，此处连接器定义路径的端点对）+ [擦除/erase]，以 [像素数守恒/pixel_count_conservation] + [边界贴合/boundary_hugging] + [近者优先不重叠/nearest_first] 作为约束

**来源原语**：绕障重绘、障碍精灵体、边界贴合、像素数守恒 ← 88bcf3b4；连接配对、连接像素 ← cbebaa4b；近者优先不重叠、碰撞停止 ← f0100645；擦除 ← 22208ba4

**依赖链**：连接器配对确定哪些端点之间需要画路径 → 障碍物的位置决定路径必须绕行的轨迹 → 绕行轨迹必须贴合障碍边界 → 路径总像素数等于无障碍时的曼哈顿距离（守恒）→ 多条路径按端点对距离从近到远依次绘制，先画的路径成为后续路径的额外障碍。删去配对则不知道连哪两点；删去绕障则路径穿越障碍；删去守恒约束则路径长度不确定

通过同色连接器像素配对确定路径端点，每条路径贴合障碍边界绕行，总长度守恒，先画路径成为后续路径的新障碍

**输入结构**：
- 背景：黑(0)。网格约 20x20。
- 3-5 个灰(5)障碍精灵体（4-连通，5-12 像素，形状不规则），散布在网格中央区域，互不接触。
- 6-10 个彩色连接器像素散布在网格边缘区域（距网格边界 1-3 格内）。连接器像素成对出现——每种颜色恰好出现 2 次，使用红(2)、蓝(1)、绿(3)、黄(4)等颜色。每对同色连接器像素之间的直线路径上至少有一个障碍物。
- 生成约束：任意两对连接器的最短绕障路径不存在无法解决的死锁（即总存在一个绘制顺序使得所有路径都能绕行成功）。

**规则**：
1. 将同色的两个连接器像素配对，形成 3-5 条路径需求。
2. 计算每对连接器之间的曼哈顿距离（不含两个端点本身），记为该路径的目标长度 L。
3. 按曼哈顿距离从小到大排序路径需求；距离相同时，按连接器对中行坐标较小的那个像素的行坐标排序，再按列坐标排序。
4. 依次绘制每条路径：从一个连接器像素出发，沿正交方向（上下左右）行进。遇到障碍物（灰(5)精灵体或已绘制的路径像素）时，贴合障碍物边界绕行——沿障碍物外轮廓的 4-邻接像素前进，选择使总路径长度最短的绕行方向（顺时针或逆时针）。绕过障碍后恢复直线行进方向。路径恰好画 L 个像素（不含两个端点）。
5. 路径像素使用该连接器对的颜色绘制。连接器端点像素本身保留不变。
6. 已绘制完成的路径像素在后续路径的绘制中视为障碍物。

**关键洞察**：先绘制的路径会改变后续路径的障碍地形——路径绘制顺序（由端点距离决定）实质性地改变了后续路径的形状，而非仅仅是叠加。

## 新题 3：逐色去噪后方向性滑动压缩

**组合逻辑**：[对称补全(去噪)/symmetry_completion]（已有原语）+ [滑动/slide]（创新：原题中滑动方向由同色墙决定，此处滑动方向由去噪后各色层对称轴的位置决定），以 [逐色处理/per_color_processing] 作为结构框架，[碰撞停止/collision_stop] + [忽略干扰项/ignore_distractors] 作为约束

**来源原语**：对称补全(去噪)、逐色处理、对称轴、忽略干扰项 ← 8e5c0c38；滑动、碰撞停止 ← f0100645；墙壁列 ← f0100645；色层 ← 6ffbe589

**依赖链**：逐色对称去噪决定每个色层保留哪些像素 → 去噪后色层的对称轴位置决定该色层的滑动方向 → 滑动时各色层像素独立移动但共享碰撞检测。删去去噪则保留了噪声像素导致对称轴偏移、滑动方向可能反转；删去滑动则只完成了去噪没有压缩

对每个色层独立执行对称去噪，然后根据去噪后对称轴偏左或偏右决定该色层的滑动压缩方向

**输入结构**：
- 背景：黑(0)。网格约 18x18。
- 左右两侧各有一列灰(5)墙壁，占满整列（第 0 列和最后一列）。
- 网格内部有 3-4 种非黑非灰颜色的色层，如红(2)、蓝(1)、绿(3)。每种颜色的像素群构成一个近似关于某条垂直轴对称的图案（5-15 像素），但其中 1-3 个像素是噪声（破坏对称性的多余像素或缺失像素）。
- 不同色层的像素互不重叠。每种颜色的对称轴位置各不相同——有的偏左（对称轴列坐标 < 网格宽度/2），有的偏右（对称轴列坐标 >= 网格宽度/2）。
- 生成约束：每种颜色去噪后的对称图案在水平滑动到墙壁后不会与其他色层的滑动结果重叠。各色层的对称轴列坐标互不相同。

**规则**：
1. 对每种非背景、非灰颜色独立执行对称去噪：找到最能解释该色像素分布的垂直对称轴（使对称像素对数量最多的整数或半整数列坐标），移除没有对称配对的像素。
2. 确定去噪后每个色层的对称轴列坐标 x_axis。若 x_axis < 网格宽度/2，该色层向左滑动；若 x_axis >= 网格宽度/2，该色层向右滑动。
3. 将每个色层的所有像素作为一个整体，沿确定的水平方向滑动。整体平移，直到该色层中距目标墙壁最近的像素紧贴墙壁（与灰(5)墙壁列相邻），或与已到位的其他色层像素发生碰撞（4-邻接）时停止。
4. 各色层按对称轴距其目标墙壁的距离从小到大依次滑动（离墙近的先滑）。
5. 灰(5)墙壁列保持不变。原位置像素擦除为背景。

**关键洞察**：去噪步骤不仅清理了视觉噪声，更改变了对称轴的精确位置，而对称轴位置直接决定了滑动方向——噪声像素的存在可能使对称轴从左半部偏移到右半部，完全反转滑动方向。

## 新题 4：三重编码精灵体嵌套

**组合逻辑**：[嵌套/dock] + [旋转/rotate] + [复制放置/replicate_stamp]（已有原语），以 [面积匹配/area_matching]（已有）+ [像素数编码旋转/pixel_count_encodes_rotation]（已有）+ [标记交叉定位/marker_intersection_positioning]（创新：原题中标记定义位置的目标是精灵体副本，此处标记定义的是空腔在框架中的语义地址，用于匹配精灵体）三重编码交汇

**来源原语**：嵌套、旋转、翻转、面积匹配、反射触发色换 ← a25697e4；像素数编码旋转、提示精灵体、同色匹配 ← 6ffbe589；复制放置、标记交叉定位、框架标记、颜色匹配配对 ← 247ef758；空腔 ← a25697e4

**依赖链**：面积匹配将精灵体与空腔配对 → 同色提示精灵体的像素数决定旋转角度 → 框架边缘标记的交叉位置确定每个空腔的唯一地址 → 三者缺一不可：面积确定配谁，旋转确定朝向，标记确定放哪。这是一个多源汇聚结构，三条独立的信息通道同时约束一个放置操作

将散布的精灵体按面积匹配嵌入框架空腔，旋转角度由提示精灵体像素数编码，放置位置由框架边缘标记的行列交叉确定

**输入结构**：
- 背景：黑(0)。网格约 22x22。
- 一个灰(5)矩形框架（外边框，内部为黑色背景），约 14x14，位于网格右半部分。框架内部有 3-4 个不同大小的矩形空腔（黑色区域被灰(5)边框完全包围的洞），面积各不相同（如 4、6、8、9 像素）。
- 框架的上边框和左边框上各有若干彩色标记像素（替换灰色的位置），颜色来自红(2)、蓝(1)、绿(3)、黄(4)。上边框的某个标记颜色与左边框的某个标记颜色相同时，它们的行列交叉位置对应一个空腔的中心。每个空腔恰好对应一个颜色交叉。
- 网格左半部分散布 3-4 个双色精灵体（4-连通，不接触框架），每个精灵体由两种颜色组成。其中一种颜色的像素区域面积恰好等于某个空腔的面积。
- 网格中还有 3-4 个小型单色提示精灵体（1-4 像素），每个提示精灵体的颜色与某个空腔标记颜色相同。
- 生成约束：每个空腔的面积与恰好一个精灵体的一个颜色区域面积匹配。每个精灵体在正确旋转后，其匹配色区域恰好能填满对应空腔。提示精灵体的像素数 mod 4 不全相同。

**规则**：
1. 对每个空腔，找到框架上边框和左边框中同色标记颜色对，确定该空腔的"标记颜色"。
2. 对每个精灵体，计算其两种颜色区域各自的面积。将面积与某个空腔面积匹配的那个颜色区域标记为"填充区域"。
3. 找到与空腔标记颜色相同的提示精灵体，计算其像素数 P。旋转角度 = (P mod 4) x 90 度顺时针。
4. 将精灵体整体旋转指定角度。旋转后，将填充区域对齐到空腔位置（填充区域的边界框左上角与空腔的左上角对齐）。填充区域的像素填入空腔内，使用填充区域的原色；精灵体中非填充区域的像素绘制在空腔外部的相邻位置（覆盖灰色框架像素）。
5. 若旋转后的精灵体需要翻转才能使填充区域精确贴合空腔形状，则执行水平翻转，并将精灵体的两种颜色互换。
6. 处理顺序：按空腔面积从小到大。所有精灵体放置完毕后，原位置的精灵体和提示精灵体擦除为背景。

**关键洞察**：三个独立的编码系统（面积→配对、提示像素数→旋转、标记交叉→定位）必须同时正确解码才能得到正确输出；任何一个编码系统的误读都会导致完全错误的结果。

## 新题 5：参考像素条件分叉变换

- 网格内部散布 3-6 个品红(6)触发像素。每个触发像素恰好位于某条射线路径上（与某个发射器同行或同列）。

## 新题 10：重复色选择 + 迷宫寻路 + 终点印章

**组合逻辑**：[印章覆盖/stamp_overlay]（已有原语）+ [寻路/pathfinding]（已有原语）+ [擦除/erase]（已有原语），以 [重复色才移动/repeated_color_moves]（创新：原题中重复色对象向内平移，此处重复色对象沿迷宫路径移动到目标位置）+ [走廊正交路径/corridor_ortho_path]（创新：原题中路径穿越门中心，此处路径从重复色对象出发寻找最近的单色对象）作为联合条件

**来源原语**：印章覆盖、标记指定放置位置 ← e734a0e8；寻路、走廊正交路径、平行墙壁、门段 ← 7e576d6e；擦除、重复色才移动、重复色对象、边界矩形、贴边定位 ← 22208ba4；碰撞停止 ← f0100645

**依赖链**：识别重复色（出现次数 > 1 的颜色）选定移动对象 → 迷宫走廊约束可行路径 → 寻路找到从重复色对象到最近单色对象的最短正交路径 → 在路径终点用重复色对象的形状覆盖（印章）单色对象 → 删去原位重复色对象。删去重复色判定则不知道谁移动；删去寻路则不知道怎么走；删去印章则不知道终点形态

识别重复色矩形为移动者，沿迷宫走廊寻找到最近单色矩形的最短路径，在终点以移动者形状覆盖目标

**输入结构**：
- 背景：黑(0)。网格约 20x25。
- 灰(5)像素构成迷宫墙壁：若干水平和垂直的灰(5)线段形成走廊结构。走廊宽度为 1 像素（两面灰墙之间恰好 1 列或 1 行空隙）。墙壁中有若干 1 像素宽的门段（墙壁上的缺口）。
- 走廊中散布 5-8 个小型单色实心矩形（2x2 到 3x4 像素），每个矩形位于走廊的交叉点或拐角处。其中恰好一种颜色出现 2 次以上（重复色），其他颜色各出现恰好 1 次（单色）。
- 重复色矩形和单色矩形的面积可能相同或不同。
- 生成约束：每个重复色矩形到其最近的单色矩形之间存在唯一最短正交路径（无并列最短路径）。该最短路径的终点单色矩形的面积 >= 重复色矩形的面积（保证覆盖时不溢出走廊）。不同重复色矩形的最近单色目标互不相同。

**规则**：
1. 统计每种非黑非灰颜色的 4-连通对象数量。出现次数 > 1 的颜色为重复色，出现恰好 1 次的为单色。
2. 对每个重复色矩形，计算它到每个单色矩形的迷宫内最短正交路径长度（路径只能沿走廊空隙行走，穿过门段，不能穿越墙壁）。距离以矩形边界框中心之间的路径步数计。选择距离最短的单色矩形作为该重复色矩形的目标。
3. 按重复色矩形到其目标的路径长度从短到长依次处理：
   - 擦除该重复色矩形原位置（填黑(0)）。
   - 在目标单色矩形的位置，将重复色矩形的形状以印章方式覆盖——重复色矩形的中心对齐目标矩形的中心，重复色像素覆盖目标区域的对应位置。目标矩形中未被覆盖的像素保留原色。
4. 不属于重复色的矩形（单色矩形）中，未被任何印章覆盖的保持不变。
5. 迷宫墙壁保持不变。走廊中不绘制路径痕迹（仅执行端点操作）。

**关键洞察**：颜色的出现次数这一统计属性决定了哪些对象参与移动，而迷宫的几何结构决定了"最近"的含义不是欧氏距离而是走廊距离——同一个单色目标从欧氏距离看可能很近，但迷宫路径可能极长。
