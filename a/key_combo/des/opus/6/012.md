## 新题 1：射线分区方向重力

**组合逻辑**：[射线延伸](创新：射线不是标记路径，而是切割空间形成区域图) + [重力下落](创新：重力方向不固定，由区域的二部图标签决定) + [重涂色](创新：碰撞边界触发重涂色)

**来源原语**：射线延伸(ray_extend) ← 2b9ef948/8886d717; 重力下落(gravity_drop) ← 84ba50d3; 重涂色(recolor) ← 800d221b; 二部图结构(bipartite_structure) ← 3bd292e8; 边缘指示方向(edge_indicates_direction) ← 8886d717

**依赖链**：射线分区产生二部图标签 → 标签决定每个精灵的重力方向 → 重力下落后精灵是否接触射线边界决定是否重涂色。三步之间环环相扣：不分区无法确定重力方向，不施加重力无法确定最终位置，最终位置决定重涂色目标。

将边缘标记像素发出的射线作为空间分区工具，分区的二部图标签控制精灵的重力方向（偶区向下、奇区向上），落地后接触射线的精灵被重涂为射线颜色。

**输入结构**：约 18x18 的网格，背景为黑(0)。网格的四条边上各有 1~2 个红(2)标记像素。每个标记像素沿其所在边的法线方向（顶边标记向下、左边标记向右，依此类推）射出一条红(2)射线，射线穿过整个网格直到对边。射线将网格分割成若干 4-连通区域。在这些区域中散布 3~5 个单色 4-连通精灵（每个精灵 3~8 像素），颜色取自蓝(1)、绿(3)、黄(4)、灰(5)，每个精灵颜色不同。精灵不触碰射线，且不跨越射线边界。生成约束：射线至少将网格分成 3 个区域；每个精灵完全位于一个区域内；精灵之间在垂直方向上不共享列（不会相互阻挡）。

**规则**：
1. 保留所有红(2)射线像素不变。
2. 将射线分割出的 4-连通背景区域构建邻接图：两个区域若在射线的两侧 4-邻接则相连。对该图做二部图二着色，将包含网格左上角 (0,0) 的区域标记为 A 类，与之交替的标记为 B 类。
3. A 类区域中的精灵向下做重力下落：每个精灵整体向下平移，直到精灵的任一像素的正下方是射线像素、网格底边或另一个已停靠精灵的像素（取最先触碰的位置）。B 类区域中的精灵向上做重力下落（同理，向上平移直到触碰射线、顶边或已停靠精灵）。同一区域内有多个精灵时，按初始位置离目标边较近者先处理。
4. 重力完成后，若精灵的任一像素 4-邻接一条射线像素，将该精灵整体重涂为橙(7)；否则保持原色。

**关键洞察**：二部图着色不是视觉装饰，而是重力场方向的编码器——同一张网格中不同区域的重力方向相反，精灵的最终颜色取决于它落地后是否碰到了射线边界。

## 新题 2：互补形状的克罗内克印章

**组合逻辑**：[形状匹配](已有) + [印章覆盖 × 克罗内克积](创新：匹配的两个形状不是"源填入模板"，而是互为 Kronecker 乘积的两个因子) + [计数](创新：连通分量计数决定使用哪对调色板颜色)

**来源原语**：形状匹配(shape_match) ← 18447a8d; 互补形状(complementary_shape) ← 18447a8d; 克罗内克积(kronecker_product) ← c803e39c; 印章覆盖(stamp_overlay) ← c803e39c; 连通分量计数(component_count) ← b0039139; 面板提供调色板(panel_as_palette) ← c803e39c

**依赖链**：互补形状匹配确定配对 → 每对中较大形状做外层掩码、较小形状做内层图案(Kronecker) → 源形状的连通分量数选择调色板行 → 调色板颜色填入 Kronecker 结果。不做匹配不知道哪两个形状组合；不计数不知道用哪组颜色。

互补形状配对后，以较大者为外层布局、较小者为内层图案做 Kronecker 展开，展开所用的前景/背景色由源形状的连通分量数从调色板中选取。

**输入结构**：约 20x20 的网格，背景黑(0)。左半区有 2~3 个灰(5)模板矩形（每个约 4x4~5x5），每个模板内有一个由背景像素构成的不规则缺口（3~6 像素的 4-连通区域）。右半区有与缺口数量相同的独立小形状，每个形状由不同颜色绘制（蓝(1)、绿(3)、黄(4)等），形状像素数 3~6，可以是单连通或多连通（1~3 个 4-连通分量）。网格底部有一个调色板行：3 列，每列 2 个像素高，自左向右分别对应分量数 1、2、3，每列上方像素为前景色、下方像素为背景色（取自红(2)、品红(6)、橙(7)、青(8)、栗(9)的不同组合）。生成约束：每个右侧形状归一化后恰好与某个左侧缺口形状全等（唯一配对）；不同形状的连通分量数不完全相同以展示规则差异。

**规则**：
1. 将每个右侧形状归一化为相对坐标集合（平移使最小行列为 0），同样归一化每个左侧缺口形状。
2. 匹配：找到归一化形状完全相同的唯一配对（右侧形状 S 配左侧缺口 G）。
3. 计算每个右侧形状 S 的 4-连通分量数 k。
4. 从底部调色板第 k 列取前景色 Cf 和背景色 Cb。
5. 以缺口 G 的归一化形状为外层掩码、S 的归一化形状为内层图案，计算 Kronecker 积：外层掩码的每个前景像素替换为内层图案（前景色 Cf），外层掩码的每个背景像素替换为与内层图案等大的纯 Cb 块。
6. 将 Kronecker 积结果放置在对应模板缺口的位置（左上角对齐缺口 bbox 左上角），超出网格的部分截断。
7. 清除右侧原始形状像素为背景。调色板行保持不变。

**关键洞察**：互补形状在原题中是"源填入缺口"的简单嵌合；这里两个互补形状变成 Kronecker 乘积的两个因子，匹配关系同时决定了空间映射和代数运算的操作数。

## 新题 3：枢纽路径计数驱动的同心填充

**组合逻辑**：[flood_fill × 同心正方形层](创新：同心带的调色板不由标记深度定义，而由路径分支的邻接计数排序生成) + [计数](创新：路径分支对种子区域的邻接数编码调色板顺序) + [重涂色](已有：路径分支继承种子色)

**来源原语**：flood_fill ← 13e47133; 同心正方形层(concentric_square_layers) ← 13e47133; 距离决定调色板(distance_determines_palette) ← 13e47133; 路径网络(path_network) ← 800d221b; 中心枢纽(hub_square) ← 800d221b; 种子区域(seed_region) ← 800d221b; 邻接计数决定色(adjacency_count_determines_color) ← 800d221b; 连通分量计数(component_count) ← b0039139

**依赖链**：路径分支邻接种子区域的分支数 → 对种子颜色按分支数从少到多排序形成调色板 → 枢纽内部用该调色板做同心矩形带循环填充 → 路径分支本身重涂为其接触最多的种子颜色。分支计数同时驱动了两个不同操作（调色板排序和路径重涂），删除任一环节均无法确定输出。

路径网络的分支邻接计数生成调色板排序，再以此调色板对中心枢纽做同心矩形带循环填充，同时路径分支按邻接规则继承种子色。

**输入结构**：约 20x20 的网格，背景黑(0)。灰(5)像素构成一个薄型正交路径网络（线宽 1 像素），网络中心有一个 4x4 或 5x5 的灰(5)实心正方形枢纽。从枢纽向外延伸 3~5 条路径分支，每条分支末端或侧面 4-邻接一个 2x2~3x3 的单色种子区域。种子颜色取自蓝(1)、红(2)、绿(3)、黄(4)、品红(6)（各不相同）。不同种子区域可能有不同数量的路径分支与之邻接（1~3 条）。生成约束：每条路径分支恰好邻接一个种子区域；枢纽不直接邻接任何种子区域；种子区域之间不相邻。

**规则**：
1. 识别灰(5)的最大连通分量为路径网络。在网络中找到最大的全灰正方形作为枢纽，其余灰像素为路径分支像素。
2. 将路径分支分割为独立的 4-连通段（在枢纽边界处断开）。
3. 对每个种子区域，计算与之 4-邻接的路径分支段数，记为 count(seed)。
4. 按 count 从小到大对种子颜色排序，形成调色板 P = [c1, c2, ...]。若两个种子的 count 相同，按种子区域质心的行坐标从小到大排列。
5. 对枢纽内部每个像素计算其到枢纽边界的 Chebyshev 距离 d。将该像素涂为 P[d mod len(P)]。枢纽边界像素（d=0）涂为 P[0]。
6. 每条路径分支段重涂为其 4-邻接的那个种子区域的颜色。
7. 种子区域本身保持不变。

**关键洞察**：路径拓扑（每个种子被多少分支触碰）不是视觉元素，而是隐式编码了枢纽同心填充的调色板排列顺序——必须对比多个示例才能发现分支计数与调色板排序之间的对应关系。

## 新题 4：宽度决定穿透的标记推移与邻接传色

**组合逻辑**：[推移](已有) + [重力下落 × 穿透与停靠](创新：穿透/停靠逻辑不再是纯重力，而是由固定标记驱动的水平推移中遇到分隔墙时的行为) + [重涂色 × 邻接传色](创新：推移完成后精灵的新邻居决定其最终颜色)

**来源原语**：推移(push) ← 5623160b; 接触侧决定方向(contact_side_dir) ← 5623160b; 穿透与停靠(pass_through_or_stop) ← 84ba50d3; 宽度决定行为(width_determines_behavior) ← 84ba50d3; 分隔墙线(separator_wall) ← 3bd292e8; 邻接传色(adjacency_color_transfer) ← 800d221b; 固定标记(fixed_marker) ← 5623160b

**依赖链**：标记接触侧 → 推移方向 → 精灵宽度决定是否穿透分隔墙 → 最终停靠位置 → 邻接关系 → 传色。五步链中每一步的输入都依赖前一步的输出，且宽度判定与邻接传色形成非线性交互：穿透的精灵可能在墙另一侧遇到新邻居，从而继承完全不同的颜色。

精灵被固定标记沿接触方向推移，遇到分隔墙时窄精灵穿透、宽精灵停靠，最终位置的邻居颜色决定精灵的重涂色。

**输入结构**：约 16x20 的网格，背景黑(0)。一条红(2)垂直分隔墙（宽 1 像素）将网格分为左右两半。左半和右半各有 2~3 个 4-连通单色精灵（颜色取自蓝(1)、绿(3)、黄(4)、灰(5)、品红(6)），每个精灵 4~10 像素。每个精灵恰好在一个基数方向上 4-邻接一个栗(9)固定标记像素（标记位于精灵的左、右、上或下侧）。分隔墙两侧底部各有一个 2x2 的单色"锚块"（橙(7)或青(8)），锚块不移动。生成约束：精灵的推移方向至少有一个朝向分隔墙；每个精灵在推移方向上的"宽度"（垂直于推移方向的跨度）要么为 1 像素，要么 >=2 像素；推移路径上除分隔墙外无其他障碍。

**规则**：
1. 保留所有栗(9)标记像素和红(2)分隔墙像素不变。
2. 确定每个精灵的推移方向：从精灵中心指向远离标记的方向（标记在左则向右推，依此类推）。
3. 计算每个精灵在垂直于推移方向上的跨度 w。
4. 将每个精灵沿推移方向平移：
   - 若路径上遇到分隔墙且 w = 1：精灵穿透分隔墙（删除墙上对应的 1 个像素），继续前进直到碰到网格边界或锚块而停止。
   - 若路径上遇到分隔墙且 w >= 2：精灵在分隔墙前一格停靠。
   - 若路径上无分隔墙：精灵前进直到碰到网格边界或锚块而停止。
   - 处理顺序：离分隔墙近的精灵先处理。
5. 所有精灵停靠后，对每个精灵检查其是否有 4-邻接的非背景、非标记、非墙的邻居块（其他精灵或锚块）。若有，将该精灵整体重涂为面积最大的邻居的颜色；若有多个面积相同的最大邻居，取行坐标最小者的颜色。若无邻居，保持原色。

**关键洞察**：宽度不仅决定精灵能否穿墙，还间接决定了精灵在墙的哪一侧停靠——这改变了它的邻居集合，从而改变了最终重涂色的结果。穿墙与否导致同一精灵可能继承完全不同的颜色。

## 新题 5：极角描边与二部图交替着色

**组合逻辑**：[描边连线](已有) + [flood_fill × 交替着色](创新：连线围成的闭合区域不做简单填充，而是根据区域邻接图的二部图性质交替上色) + [忽略干扰项](创新：干扰点的判据不是模板匹配，而是能否参与形成有效闭合多边形)

**来源原语**：描边连线(outline_tracing) ← 35ab12c3; 极角排序(polar_angle_ordering) ← 35ab12c3; 忽略干扰项(ignore_distractors) ← 35ab12c3/652646ff; 二部图结构(bipartite_structure) ← 3bd292e8; 交替着色(alternating_coloring) ← 3bd292e8; 四邻接连通(four_neighbor_connect) ← 3bd292e8; flood_fill ← 13e47133

**依赖链**：极角排序 → 顶点连线形成闭合多边形 → 多边形围成的区域形成邻接图 → 二部图着色决定每个区域的填充色。干扰项识别依赖于能否形成有效闭合轮廓（几何约束），删除后无法正确建图；区域着色依赖于轮廓闭合（拓扑约束），删除后无区域可填。

同色顶点按极角连线围出闭合区域，这些区域按邻接关系做二部图交替着色，无法形成有效闭合轮廓的孤立点被忽略。

**输入结构**：约 18x18 的网格，背景黑(0)。网格中有 2~3 组颜色不同的顶点集合（蓝(1)、绿(3)、黄(4)），每组 3~5 个像素，散布在网格中。同组顶点按其质心的极角排序后，相邻顶点之间可以画水平、垂直或 45 度对角线段（路径上无非背景障碍），形成闭合多边形。另有 2~3 个"干扰"像素，颜色与某组顶点相同，但将其加入该组后无法形成全部边段都通畅的闭合多边形。网格右下角有两个相邻的色板像素：灰(5)和品红(6)，分别作为二部图着色的两种填充色。生成约束：每组有效顶点至少 3 个，形成的多边形互不交叉但可以嵌套或相邻（共享边或顶点）；所有多边形共同将网格划分为至少 3 个区域。

**规则**：
1. 对每组颜色，收集该色的所有像素。尝试按极角排序后连线：若加入某个像素后，形成的某条边段不是水平/垂直/45度，或边段内部有非背景像素阻挡，则该像素为干扰项，从集合中移除。重复直到剩余像素能形成有效闭合多边形。
2. 用每组的有效顶点按极角排序连线，绘制闭合多边形轮廓，线段颜色为该组顶点颜色。
3. 轮廓将网格分割为若干 4-连通区域。构建区域邻接图（两个区域若隔着轮廓线 4-邻接则相连）。
4. 对邻接图做二部图二着色。将包含网格 (0,0) 的外部区域标记为 A 类。A 类区域填充灰(5)，B 类区域填充品红(6)。
5. 轮廓像素保持其原有颜色不变。色板像素保持不变。干扰像素擦除为背景色。

**关键洞察**：干扰项不是随机噪声而是几何上"差一点可行"的顶点——必须通过尝试连线并检验路径通畅性来识别；轮廓的拓扑结构（而非颜色）决定了区域如何交替着色。

## 新题 6：嵌入修补计数驱动的边框方向位移

**组合逻辑**：[修补](已有：嵌入标记回填为主体色) + [平移 × 颜色匹配边](创新：孤立标记的位移方向由边框边颜色匹配决定，而非由边缘线方向决定) + [计数](创新：嵌入标记的修补总数编码孤立标记的位移距离)

**规则**：
1. 识别主体对象（橙(7)的最大 4-连通分量）。
2. 分类灰(5)像素：若至少 3 个 4-邻居为橙(7)则为"嵌入标记"，否则为"孤立标记"。
3. 将所有嵌入标记重涂为橙(7)（修补），记修补总数为 N。
4. 对每个孤立标记，找到与之同行或同列的品红(6)边框提示像素。该提示像素所在的边确定方向（顶边→向上，底边→向下，左边→向左，右边→向右）。
5. 将每个孤立标记沿该方向平移 N 格。若平移后超出边框内部区域则停在边框内侧。
6. 将品红(6)提示像素恢复为其所在边框边的原始颜色。

**关键洞察**：修补嵌入标记不仅是修复操作，其数量还隐式编码了另一组标记的位移距离——两个看似独立的标记群通过"修补计数=位移步数"这一隐藏关系绑定在一起。

## 新题 7：遮挡重建后按尺寸排序的循环轮换

**组合逻辑**：[堆叠 × 排序](创新：遮挡层序用于重建，但重建后的完整精灵按面积而非层序进行操作) + [循环轮换](创新：轮换的对象不是空间上围绕某中心的区域，而是按面积排序后的精灵颜色) + [补全](已有)

**来源原语**：堆叠(stacking) ← 652646ff; 遮挡层序(occlusion_order) ← 652646ff; 排序(sorting) ← 652646ff; 补全(complete/reconstruct) ← 652646ff/5751f35e; 可见像素定边框(visible_defines_bbox) ← 652646ff; 尺寸排序(size_ordering) ← 48634b99; 循环轮换(cyclic_shift) ← 880c1354

**依赖链**：可见碎片 → 遮挡拓扑排序 → 重建完整精灵 → 按完整精灵面积排序 → 按该顺序循环轮换颜色。遮挡重建是必要前提（不重建无法知道真实面积），面积排序产生的序列是循环轮换的骨架（不排序无法确定谁的颜色转给谁）。且循环轮换后需要按原始遮挡层序重新堆叠绘制，形成回路依赖。

从遮挡碎片重建完整精灵，按面积从小到大排列后将颜色循环右移一位，再按原遮挡层序从底到顶重绘。

**输入结构**：约 15x15 的网格，背景黑(0)。4~5 个不同颜色的精灵（蓝(1)、红(2)、绿(3)、黄(4)、品红(6)）部分重叠。每个精灵是同一个 5x5 空心矩形环模板（12 像素的边框环）的平移副本。因重叠，下层精灵的部分像素被上层遮挡。每个精灵至少有 4 个边框像素可见。精灵可能被网格边界裁剪。另有少量（1~2 个）噪声像素，颜色与某精灵相同但不在任何有效模板位置上。生成约束：精灵面积（完整 12 像素）可通过可见像素确定归属；每个精灵的面积排名唯一（不需要但允许有相同面积——此处所有精灵都是同模板，所以"面积"换成"可见像素数"来排序更合理）。

**规则**：
1. 忽略不在任何有效 5x5 环模板位移位置上的噪声像素。
2. 对每个颜色，找到其可见像素最佳拟合的 5x5 环模板位置（平移），确定每个精灵的完整环形状。
3. 建立遮挡关系：若精灵 A 的某个模板位置被精灵 B 的颜色占据，则 B 遮挡 A（B 在 A 之上）。对所有精灵做拓扑排序得到从底到顶的层序 L。
4. 统计每个精灵在输入中的可见像素数 V。按 V 从小到大排序得到序列 S = [s1, s2, ..., sn]。若 V 相同，按层序中较低者（更底层）排前。
5. 循环右移颜色：s1 获得 sn 的颜色，s2 获得 s1 的原色，s3 获得 s2 的原色，依此类推。
6. 在纯背景画布上按层序 L 从底到顶依次绘制每个精灵的完整 5x5 环，使用轮换后的新颜色。上层覆盖下层。

**关键洞察**：遮挡层序和面积排序是两个独立的序——层序决定绘制优先级，面积序决定颜色轮换方向。求解者必须同时维护这两条序才能得出正确输出。

## 新题 8：控制序列桥接后的桥内同心带填充

**组合逻辑**：[连线(bridge_drawing)](已有) + [flood_fill × 同心正方形层](创新：桥在两个方块之间围出矩形空腔，空腔内部做同心带填充) + [访问顺序编码](已有) + [距离决定调色板](创新：调色板不来自标记深度，而来自桥两端方块的内部填色)

**依赖链**：控制序列 → 确定桥接顺序和端点 → 桥绘制 → 桥与方块边框围成封闭矩形区域 → 区域内做同心矩形带填充 → 调色板 = [桥起点方块内色, 桥终点方块内色]。不画桥则无封闭区域可填；不知道端点则无法确定调色板颜色。

**输入结构**：约 22x22 的网格，背景黑(0)。4~5 个灰(5)边框的方块（每个 4x4，外框灰(5)，内部 2x2 为不同的纯色填充：蓝(1)、红(2)、绿(3)、黄(4)、品红(6)）散布在网格中。方块之间有行或列对齐关系（同行或同列）。网格底行有一排控制像素，从左到右颜色依次为某些方块的内填色，编码访问顺序。同一内填色可在控制行中出现多次。生成约束：控制序列中每对连续颜色对应的方块必须行或列对齐；对齐的方块之间无其他方块阻挡；方块间距至少 4 格以容纳同心带。

**规则**：
1. 从控制行左端第一个颜色 c0 对应的方块开始。
2. 对控制行中每对连续颜色 (ci, ci+1)，找到 ci+1 色内填的方块中与当前方块行或列对齐且距离最近的那个。
3. 在当前方块和目标方块之间画一条桥：桥的宽度为 2 像素（与方块内部等宽），颜色为 ci（当前方块的内填色），桥连接两个方块的边框外侧，不覆盖方块本身。
4. 桥画完后，桥的两条平行线段与两端方块的边框共同围出一个封闭矩形区域（桥的内部空间）。
5. 对每个封闭区域，定义双色调色板 P = [ci, ci+1]（桥起点方块内色和终点方块内色）。
6. 对区域内每个像素计算其到区域边界的 Chebyshev 距离 d，涂色为 P[d mod 2]。
7. 方块本身不变。控制行不变。

**关键洞察**：桥不只是连接线，它与方块边框共同构成了新的封闭几何区域；该区域的填充颜色由桥两端的方块身份决定——控制序列同时编码了桥的连接拓扑和填充配色方案。

2. 确定标记段占据的是其竖条的上半段还是下半段。
3. 将标记段（红色像素）还原为蓝(1)。
4. 找到排名为 2R 的竖条。将该竖条的对应半段（上半或下半，与原标记相同）重涂为红(2)。

**关键洞察**：跳跃目标不是"下一根更长的竖条"（+1），而是排名翻倍（x2）——必须对比多个示例中标记的起止排名才能发现这一乘法关系；对角线的垂直起点取决于半段位置，从而产生不同的射线图案。

## 新题 10：相对方位定位后的偏移复制阴影

**组合逻辑**：[定位 × 相对方位](创新：控制像素不再选择 3x3 内部的单个槽位，而是选择目标区域中的一个子图形) + [偏移复制](创新：被选中的子图形的相对位移被当作阴影偏移量，应用于整个目标区域)

**来源原语**：定位(locate) ← 18286ef8; 相对方位(relative_position) ← 18286ef8; 方位决定槽位(position_selects_slot) ← 18286ef8; 控制像素(control_pixel) ← 18286ef8; 目标区域(target_region) ← 18286ef8; 偏移复制(offset_copy) ← 35ab12c3; 阴影像素(shadow_pixel) ← 35ab12c3

**依赖链**：控制像素的相对方位 → 选择目标区域中的子图形 → 子图形相对于区域中心的偏移量 → 整个目标区域沿该偏移量做阴影复制。方位选择决定了偏移量的值，偏移量决定了阴影位置——两步之间信息发生了形态转换（从空间索引变为向量），不是简单传递。

控制像素的相对方位选出目标区域中的一个子图形，该子图形相对于区域中心的位移向量成为整个区域的阴影偏移。

**输入结构**：约 15x15 的网格，背景黑(0)。网格中有一个约 7x7 的目标区域，由灰(5)像素构成一个 3x3 的大格子结构（每格约 2x2 像素，格间有 1 像素间隔），共 9 个格子排列成 3x3。其中一个格子的像素被涂为红(2)（"选中标记"），其余 8 格为灰(5)。目标区域外有恰好一个品红(6)的控制像素。生成约束：控制像素与目标区域不在同一行也不在同一列（即相对方位不会落在"同行/同列"的歧义情况）；目标区域整体偏移后不超出网格。

**规则**：
1. 定位目标区域（灰(5)和红(2)像素的联合 bbox）和控制像素（品红(6)）。
2. 判断控制像素相对于目标区域 bbox 中心的方位：行方向（上/中/下）和列方向（左/中/右），组合成九宫格方位之一（如"左上"、"右下"等）。
3. 该方位对应目标区域 3x3 格子中的一个格子位置（左上=第0行第0列，右下=第2行第2列）。
4. 计算被选中格子的中心像素相对于整个目标区域中心像素的偏移向量 (dr, dc)。
5. 将控制像素重涂为红(2)。
6. 将整个目标区域沿 (dr, dc) 偏移复制一份作为"阴影"：阴影像素只画在背景像素上（不覆盖已有非背景像素），阴影颜色为青(8)。
7. 原始目标区域保持不变。红色选中格保持红色。

**关键洞察**：控制像素既不移动也不重涂目标——它的方位信息被"翻译"成目标区域内的一个几何位移向量，该向量又驱动了一个完全不同的操作（阴影复制）。信息的表征形式跨越了两次转换：空间方位 → 格子索引 → 位移向量 → 阴影位置。
