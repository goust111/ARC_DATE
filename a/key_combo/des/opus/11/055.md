## 新题 1：距离定序的方块重排

**组合逻辑**：[压缩重排(repack)](创新：排列依据从面积改为距离) + [排序(sort)](创新：排序键从大小改为欧氏距离) + [重涂色(recolor)](创新：目标色由最近标记决定) + [最近邻选择(nearest_neighbor_selection)](创新：同时决定排序和颜色)

**来源原语**：压缩重排/像素数定边长(8abad3cf), 排序/面积递增排列(8abad3cf), 重涂色/擦除/最近邻选择/欧氏距离最小(6df30ad6), 标记像素(0ca9ddb6)

**依赖链**：标记像素的空间位置同时决定两件事：(1) 每个色块到最近标记的距离成为排列顺序的键；(2) 最近标记的颜色成为该色块重排后的涂色。移动任何一个标记像素，排列顺序和颜色分配都会同时改变。像素总数决定方块边长这一环节不可省略，否则无法确定输出方块的尺寸。

将散布的不规则色块按距离标记的远近重新排列为实心方块，每个方块的颜色由其最近的标记像素决定。

**输入结构**：约 15x20 的黑(0)背景网格。网格中有 3~5 组不同颜色的灰(5)色块（每组的像素数是完全平方数：4、9、16 等，各组像素数互不相同），这些色块形状不规则（非矩形的 4-连通区域）。另外散布 3~5 个孤立的标记像素，颜色各不相同（从红(2)、蓝(1)、绿(3)、黄(4)、橙(7)中选取，每色最多一个）。标记像素与灰色块互不相邻。生成约束：每个灰色块到各标记像素的最小平方欧氏距离两两不等（无平局）。

**规则**：
1. 将每组灰(5)色块视为一个整体，计算其像素总数 P，得到边长 S = sqrt(P)。
2. 对每组色块，计算该组中每个像素到每个标记像素的平方欧氏距离，取该组到各标记的最小值，再取所有标记中的最小值，得到该组的"最近距离" D 和对应的"最近标记颜色" C。
3. 按 D 从小到大排列各组。
4. 在输出网格中（与输入同尺寸，黑(0)背景），从左到右依次放置实心方块：第一个方块的左下角在 (最底行, 第0列)，相邻方块间隔一列黑(0)背景。所有方块底部对齐于最底行。
5. 每个方块涂色为其对应的最近标记颜色 C，不再保留原来的灰(5)色。
6. 标记像素在输出中被擦除（不出现）。

**关键洞察**：排列顺序和输出颜色都由同一个空间关系（到标记的距离）决定，而方块尺寸由原色块像素数决定——三条独立信息在同一输出中交汇，仅凭单个示例无法区分"按距离排"和"按面积排"，必须对比多个示例。

## 新题 2：轴标引导的镜像补全与孔洞填色

**组合逻辑**：[镜像(mirror)](创新：镜像轴由外部标记位置编码而非引导线) + [填充(fill)](创新：填充目标是镜像后涌现的封闭孔洞) + [重涂色/擦除(recolor/erase)](创新：由孔洞存在性决定)

**来源原语**：镜像/轴线决定变换(4e7e0eb9), 填充/封闭孔洞/有孔触发重涂(aa4ec2a5), 标记像素(0ca9ddb6, 6df30ad6), 擦除(6df30ad6)

**依赖链**：轴标像素的位置编码镜像方向 → 镜像操作创造了新的形状 → 新形状可能产生封闭孔洞 → 孔洞存在时用轴标颜色填充，不存在时擦除轴标。镜像方向决定了孔洞是否涌现，而孔洞是否涌现反过来决定了轴标的命运（保留颜色还是被擦除）。

根据轴标像素的位置对每个前景对象做镜像补全；若补全后产生封闭孔洞，则用轴标颜色填充孔洞并保留轴标；否则擦除轴标。

**输入结构**：约 18x18 的黑(0)背景网格。网格中有 3~4 个互不相邻的 4-连通单色前景对象（每个对象一种颜色，从蓝(1)、绿(3)、灰(5)、青(8)中选取），每个对象占 6~15 像素，形状不规则但具有可沿某轴镜像补全的半对称结构。每个对象恰好有一个与之相邻（8-邻接）的"轴标像素"，颜色与该对象不同（从红(2)、黄(4)、橙(7)、品红(6)中选取）。轴标像素位于该对象边界框的某条边的中点位置：若在上边或下边中点 → 表示水平轴（上下镜像）；若在左边或右边中点 → 表示垂直轴（左右镜像）。生成约束：镜像补全后至少一个对象产生封闭孔洞、至少一个对象不产生封闭孔洞；各对象镜像补全后的区域互不重叠。

**规则**：
1. 对每个前景对象，找到与其 8-邻接的唯一轴标像素。
2. 根据轴标位置确定镜像轴：轴标在对象边界框上边或下边中点 → 以对象边界框水平中线为轴做上下镜像；轴标在左边或右边中点 → 以对象边界框垂直中线为轴做左右镜像。
3. 将镜像产生的新像素绘制到网格上（与原对象同色），形成补全后的完整对象。
4. 检查补全后的对象是否包含 4-连通的封闭黑(0)孔洞（完全被该对象像素包围的黑色连通区域）。
5. 若存在孔洞：用该对象的轴标颜色填充所有孔洞像素，轴标像素保留。
6. 若不存在孔洞：擦除该对象的轴标像素（变为黑(0)）。

**关键洞察**：轴标像素承担三重角色——编码镜像方向、提供孔洞填充颜色、自身根据孔洞是否涌现而保留或消失。仅看单个示例无法区分"轴标总是保留"和"轴标根据孔洞条件保留"，需要对比有孔和无孔的案例。

## 新题 3：坠落路径塑形后的最大空腔填充

**组合逻辑**：[重力下落(gravity_drop)] + [绕行(detour)](已有原语) → [搜索(search)](创新：搜索目标是坠落路径围成的空腔) + [填充(fill)](创新：填充的区域由坠落路径的拓扑决定)

**来源原语**：重力下落/绕行/遇障碍绕最近侧/源列/障碍线段(c87289bb), 搜索/填充/最大矩形填充/最小边长约束/空心矩形区域(3eda0437)

**依赖链**：源像素坠落路径遇到障碍后绕行 → 绕行方向改变路径走向 → 路径将背景切割为不同区域 → 在剩余背景中找到最大全黑矩形 → 对该矩形填色。障碍线段的位置和长度直接决定了绕行方向，进而决定了路径形状，最终决定了可填充的最大矩形在哪里。移动障碍会同时改变路径和填充目标。

将顶部色块下落并绕过障碍后，在剩余背景空间中找到最大的空矩形并填充。

**输入结构**：约 16x16 的黑(0)背景网格。第 0 行有 3~5 个青(8)像素作为源列（互不相邻）。网格中部有 2~3 条红(2)水平障碍线段（每条占连续 3~6 个像素，位于同一行，各线段不在同一行，不与源列正上方对齐的列重叠超过一个像素）。生成约束：所有源列从上向下坠落并完成绕行后，剩余背景中存在至少一个高和宽均不小于 2 的全黑矩形；各源列的绕行路径互不冲突（不会有两条路径需要占用同一个像素）。

**规则**：
1. 复制输入网格。
2. 从每个源列像素开始，向下延伸一条青(8)竖直线，逐行绘制，直到碰到障碍线段或到达底边。
3. 若竖直线碰到障碍线段：在障碍线段正上方一行，从源列位置向障碍线段的最近外侧端画一段青(8)水平线，然后从该外侧端继续向下延伸竖直线直到底边或下一个障碍。若源列恰好位于障碍线段的正中央（到两端距离相等），则绕向右侧。
4. 所有路径绘制完成后，在网格中搜索所有高和宽均不小于 2 的全黑(0)矩形区域。
5. 将面积最大的全黑矩形填充为灰(5)。若最大面积有多个矩形并列，选择左上角行号最小的；仍并列则选左上角列号最小的。
6. 红(2)障碍线段在输出中保持不变。

**关键洞察**：填充目标不是预设的固定区域，而是由坠落路径的绕行拓扑间接塑造出来的——改变任一障碍的位置会同时改变路径走向和可用空腔的形状与位置。需要对比多个示例才能确认"填充最大矩形"而非"填充路径围成的封闭区域"。

## 新题 4：面板差异图的形状频率着色

**组合逻辑**：[逐像素比较(pixel_comparison)](已有原语) → [形状匹配(shape_matching)](创新：匹配对象是比较后涌现的差异分量) + [重涂色(recolor)](创新：涂色依据是差异分量的形状频率而非来源面板)

**来源原语**：逐像素比较/面板/分隔列/差异分类着色(d47aa2ff), 形状匹配/唯一重复形分涂/连通分量/精灵体(b230c067)

**依赖链**：两面板逐像素比较 → 差异像素形成连通分量 → 将分量按归一化形状分组 → 形状出现次数决定该分量的最终颜色。比较步骤不可跳过（差异分量只存在于比较之后），形状分组也不可跳过（颜色由频率而非位置决定）。

比较两个面板，将差异像素按形状频率着色：形状唯一的差异分量涂红，形状重复的涂蓝。

**输入结构**：约 12x25（或 25x12）的网格，由一列（或一行）灰(5)分隔线分为左右（或上下）两个等大面板，每个面板约 12x12。两个面板的背景为黑(0)，各含若干绿(3)前景像素构成的图案。两面板的图案大部分重合，但各有若干 4-连通小区域（3~8 像素）不在对方面板中出现。生成约束：差异产生的 8-连通分量共 4~6 个，其中至少两个分量的归一化边界框形状相同（平移等价），至少一个分量的形状是唯一的；各差异分量互不 8-邻接。

**规则**：
1. 移除分隔线，将左右面板逐像素对齐比较。
2. 两面板同位置均为绿(3)的像素 → 输出为绿(3)。
3. 两面板同位置均为黑(0)的像素 → 输出为黑(0)。
4. 仅一侧为绿(3)的像素 → 标记为"差异像素"。
5. 将所有差异像素按 8-连通分量分组。
6. 对每个分量，裁剪到其边界框并提取二值掩码（差异像素为1，其余为0）作为归一化形状。
7. 将所有分量按归一化形状分组：形状相同（掩码完全一致）的分量归为一组。
8. 若某组只含一个分量（形状唯一），将该分量的所有像素涂为红(2)。
9. 若某组含多个分量（形状重复），将该组所有分量的所有像素涂为蓝(1)。
10. 输出为一个面板大小的网格（宽度和高度与单个面板相同）。

**关键洞察**：差异分量本身并不存在于任何一个面板中——它们只在比较后涌现。着色不是按"来自左面板/右面板"区分（那是原题的做法），而是按差异分量的几何形状频率区分，这要求求解者先完成比较、再做形状匹配、再做频率统计，三步环环相扣。

## 新题 5：射线网络围合区域的分级填色

**组合逻辑**：[射线延伸(ray_extend)] + [标记触发转向(marker_triggers_turn)](已有原语) → [填充(fill)](创新：填充对象是射线网络围成的封闭区域) + [面积排名(area_ranking)](创新：排名决定填充颜色)

**来源原语**：射线延伸/递归展开/正交转向/起点像素/标记像素/射线网络/标记触发转向/深度优先展开(b942fd60), 填充/封闭区域/面积排名/重涂色(a8d7556c)

**依赖链**：红色射线从起点出发遇标记转向 → 射线网络的拓扑在背景中围成若干封闭区域 → 对封闭区域按面积排名 → 不同名次填不同颜色。射线路径决定了封闭区域的数量、形状和面积，而面积排名又决定了填色方案。改变任一标记位置会重塑整个射线网络，从而改变所有封闭区域。

构建射线转向网络后，将网络围成的封闭背景区域按面积从大到小填上不同颜色。

**输入结构**：约 18x18 的黑(0)背景网格。左边缘第 0 列有一个红(2)起点像素。网格中散布 4~7 个孤立标记像素（绿(3)或品红(6)），位置使得射线网络能围成 2~4 个封闭的黑色区域。生成约束：射线按深度优先展开后，至少围成 2 个互不相连的 4-连通封闭黑色区域；各封闭区域面积互不相等；标记像素不在网格边缘。

**规则**：
1. 从红(2)起点像素开始，向右发射一条水平红(2)射线，逐像素填充黑(0)背景，直到碰到标记像素或网格边界。
2. 射线碰到标记像素时停止（不覆盖标记像素）。若该标记是第一次被碰到，则从射线停止前一格（最后一个红色像素）处向垂直方向（上和下）各发射一条新射线，新射线同样填充黑(0)背景为红(2)，碰到标记或边界时停止。
3. 新射线碰到标记时，若该标记也是第一次被碰到，则从停止前一格向水平方向（左和右）各发射新射线。如此递归展开，深度优先，标记只在第一次被碰到时触发新射线。
4. 所有射线绘制完成后，找出被红(2)射线像素和网格边界完全包围的 4-连通黑(0)封闭区域（不与网格外部黑色区域连通的黑色连通分量）。
5. 将封闭区域按面积（像素数）从大到小排列。
6. 面积最大的封闭区域填充为黄(4)，第二大的填充为蓝(1)，第三大的填充为橙(7)，第四大的（若存在）填充为灰(5)。
7. 标记像素在输出中保留其原始颜色。

**关键洞察**：封闭区域不是预设的，而是射线网络拓扑的副产品——求解者必须先完整构建射线网络才能知道哪些区域被围合。面积排名与填色的对应关系需要对比多个示例才能确定（单个示例可能让人误以为填色由区域位置决定）。

## 新题 6：距离分组后的紧凑堆叠

**组合逻辑**：[最近邻选择(nearest_neighbor_selection)](创新：选择结果决定分组而非着色) + [重涂色(recolor)](创新：涂色由标记决定) + [堆叠(stacking)] + [排序(sort)/位置排序(positional_ordering)](创新：排序键是原始空间位置而非颜色)

**来源原语**：重涂色/擦除/最近邻选择/欧氏距离最小/标记像素(6df30ad6), 堆叠/排序/位置排序/对齐紧凑排布/按颜色分组/单色前景对象(4acc7107)

**依赖链**：灰色对象 → 距离计算选择最近标记 → 用标记颜色重涂 → 重涂结果决定分组 → 组内按原始位置排序 → 堆叠输出。距离分析产出的颜色成为堆叠分组的依据，而组内的堆叠顺序来自对象在原始网格中的空间位置。

将灰色对象按到最近标记的距离分组着色，然后按颜色分组紧凑堆叠到输出底部。

**输入结构**：约 20x20 的黑(0)背景网格。网格中有 4~6 个互不相邻的 4-连通灰(5)对象（每个 4~12 像素，形状不规则），以及 2~3 个孤立标记像素（颜色各不相同，从红(2)、蓝(1)、绿(3)中选取）。生成约束：每个灰对象到各标记的最小平方欧氏距离不相等（无平局）；每个标记颜色至少是 1 个灰对象的最近标记；标记像素与灰对象互不 4-邻接。

**规则**：
1. 对每个灰(5)对象，计算其每个像素到每个标记像素的平方欧氏距离，取最小值。以该最小距离对应的标记颜色作为该对象的"目标色"，将该对象重涂为目标色。
2. 擦除所有标记像素（变为黑(0)）。
3. 按目标色将对象分组。组间排列顺序：按各组中所有对象的边界框最左列的最小值，从小到大从左到右排列。
4. 组内对象排列顺序：按各对象边界框左上角列号从大到小排列（右边的先放，靠上）。
5. 输出网格与输入同尺寸，黑(0)背景。对每个组：将组内对象依次裁剪为边界框大小，从上到下垂直堆叠（对象间隔一行黑(0)背景），整组底部对齐于输出网格最底行。各组的最左列从左到右排列，相邻组间隔一列黑(0)背景。第一组的最左列为第 0 列。

**关键洞察**：分组依据不是对象本身的颜色（输入中全是灰色），而是每个对象到最近标记的空间距离所隐式编码的颜色归属。仅看一个示例可能误以为分组由对象位置的聚类决定，需要对比多个示例才能发现标记像素是分组的真正决定者。

## 新题 7：边框裁剪后按标记方向镜像拼接

**组合逻辑**：[裁剪(crop)](已有原语) + [镜像(mirror)](创新：镜像轴由外部标记位置编码) + [拼接(concatenate)](创新：拼接方向与镜像轴耦合) + [重涂色(recolor)](创新：边框重涂为标记颜色)

**来源原语**：裁剪/空心矩形/单色边框/唯一完整边框/包含内部(c909285e), 镜像/拼接/整幅画布(6d0aefbc), 标记像素(0ca9ddb6), 重涂色(aa4ec2a5)

**依赖链**：唯一完整边框 → 裁剪出边框及内部内容 → 标记像素相对边框中心的方位决定镜像轴 → 镜像轴同时决定拼接方向 → 拼接前将边框像素重涂为标记颜色。边框检测、标记定位、镜像、拼接四步串联且每步输出被下一步使用。

找到唯一的完整矩形边框并裁剪，根据外部标记像素的位置做镜像拼接，并将边框重涂为标记颜色。

**输入结构**：约 15x15 的黑(0)背景网格，其上有各种散布的杂色前景像素。网格中恰好有一种颜色（如蓝(1)）的像素组成了一个完整的矩形边框（一像素宽的矩形周长，无断裂），该颜色不出现在边框之外。边框内部含有 2~3 种其他颜色的像素组成的非对称小图案。网格上还有恰好一个孤立标记像素（颜色为红(2)、绿(3)、黄(4)或橙(7)之一），位于边框外部。生成约束：标记像素不在边框的水平中线或垂直中线的延长线上（即标记相对于边框中心明确偏向某一侧）。

**规则**：
1. 找到唯一形成完整矩形边框的颜色，裁剪出该边框及其内部内容（包含边框本身），得到子网格 A。
2. 确定标记像素相对于边框中心的位置：
   - 若标记在边框中心的左方或右方（|列差| > |行差|）→ 镜像轴为垂直轴，拼接方向为水平。
   - 若标记在边框中心的上方或下方（|行差| > |列差|）→ 镜像轴为水平轴，拼接方向为垂直。
   - |行差| = |列差| 时，按垂直轴处理（水平拼接）。
3. 生成子网格 A 的镜像副本 B（按确定的轴做翻转）。
4. 将 A 的边框像素全部重涂为标记像素的颜色。B 的边框像素同样重涂为标记像素的颜色。
5. 将 A 和 B 沿拼接方向拼合：若水平拼接，A 在左 B 在右，共享边框的接合边（重叠的一列边框合并为一列）；若垂直拼接，A 在上 B 在下，共享接合行。
6. 输出为拼合后的网格（不含原输入中的其他杂色像素和标记像素）。

**关键洞察**：标记像素同时编码了两个信息：镜像/拼接方向（由其相对边框的方位决定）和边框的新颜色。裁剪步骤消除了输入中的干扰噪声，而拼接时的边框合并规则需要对比多个示例才能确认（单个示例可能误以为边框被保留两份）。

## 新题 8：色带翻转后的邻域标记扩展

**组合逻辑**：[镜像(mirror)](已有原语：色带翻转到对侧) → [描边(mark_neighbors)](创新：标记扩展仅在翻转副本中生效) + [标记色选邻域几何(marker_color_selects_neighborhood)](已有原语)

**来源原语**：镜像/色带行/色带翻转到对侧/画布边界(496994bd), 描边/标记像素/对角邻接/正交邻接/标记色选邻域几何(0ca9ddb6)

**依赖链**：原始色带翻转到底部 → 翻转副本中的红/蓝像素触发邻域标记 → 标记扩展被色带边界和已有像素双重约束。原始色带保持不变，标记扩展只在翻转后的底部色带中发生。色带的内容决定了翻转后哪些位置有红/蓝像素，而这些位置经过翻转后改变了行号，导致邻域标记的可用空间与原始位置不同。

将顶部色带翻转到底部后，在底部副本中对红像素做对角标记、对蓝像素做正交标记。

**输入结构**：约 14x14 的黑(0)背景网格。顶部 3~4 行为完整的色带（每行从第 0 列到最后一列全部填满），色带的主体颜色为灰(5)，其中夹杂若干红(2)和蓝(1)单像素（各 2~4 个，不在色带的第一行或最后一行的边缘位置）。色带以下全部为黑(0)背景。生成约束：色带行数 K 满足网格行数 >= 2K+1（翻转后的色带与原色带之间至少隔一行黑色背景）；色带中的红和蓝像素互不 4-邻接。

**规则**：
1. 保持原始色带（顶部 K 行）不变。
2. 将色带逐行倒序复制到网格底部 K 行（色带第一行 → 最底行，色带第二行 → 倒数第二行，依此类推）。
3. 在底部副本中（仅限底部副本），对每个红(2)像素：将其 4 个对角邻居（左上、右上、左下、右下）中属于底部副本区域且当前为灰(5)的像素涂为黄(4)。
4. 在底部副本中，对每个蓝(1)像素：将其 4 个正交邻居（上、下、左、右）中属于底部副本区域且当前为灰(5)的像素涂为橙(7)。
5. 若某个位置同时是某红像素的对角邻居和某蓝像素的正交邻居，涂为橙(7)（正交优先）。
6. 顶部原始色带、中间黑色背景区域均不受影响。

**关键洞察**：标记扩展只作用于翻转后的底部副本，不作用于原始顶部色带——这一不对称规则需要对比顶部和底部才能发现。此外，翻转导致行序颠倒，使得原本在色带内部的像素可能变为靠近色带边缘，影响邻域标记的可用空间。冲突解决规则（正交优先于对角）也需要出现冲突的示例才能归纳。

## 新题 9：描边网络中的最大空腔填充

**组合逻辑**：[描边(draw_outline)](已有原语) + [填充(fill)](创新：填充对象不是对象内部的孔洞，而是描边后背景中残留的最大矩形) + [重涂色(recolor)](创新：有孔对象的重涂改变了描边颜色分布) + [搜索(search)](创新：搜索空间被描边和重涂共同塑造)

**来源原语**：描边/填充/前景对象/封闭孔洞/有孔触发重涂/包含关系(aa4ec2a5), 搜索/填充/最大矩形填充/最小边长约束/空心矩形区域(3eda0437)

**依赖链**：前景对象 → 检测孔洞 → 有孔对象重涂为青+孔洞填品红 → 对所有对象（含重涂后的）画红色描边 → 描边和重涂共同减少了可用背景面积 → 在剩余背景中找最大全黑矩形 → 填充为黄色。孔洞填充和描边两步都会"吃掉"背景像素，它们的联合效果决定了最大空腔的位置和大小。

对前景对象做孔洞检测与描边，然后在剩余背景中找到最大的空矩形并填充。

**输入结构**：约 20x20 的黑(0)背景网格。网格中有 3~5 个互不 8-邻接的 4-连通前景对象，颜色各不相同（从蓝(1)、绿(3)、灰(5)、栗(9)中选取），每个对象占 8~25 像素。其中至少一个对象在其边界框内封闭了一个 4-连通的黑(0)孔洞（2~6 像素），至少一个对象没有封闭孔洞。生成约束：所有描边和孔洞填充完成后，剩余黑(0)背景中存在至少一个高和宽均不小于 3 的全黑矩形。

**规则**：
1. 对每个 4-连通前景对象，检查其边界框内是否存在被该对象完全包围的 4-连通黑(0)区域（封闭孔洞）。
2. 若存在封闭孔洞：将该对象的所有像素重涂为青(8)，将孔洞像素填充为品红(6)。
3. 若不存在封闭孔洞：保持该对象原色不变。
4. 对每个前景对象（包括重涂后的对象和品红孔洞作为整体），绘制一像素宽的 8-邻域红(2)描边：即对象区域（含已填充的孔洞）的每个像素的 8 个邻居中，凡是当前为黑(0)的像素均涂为红(2)。
5. 描边完成后，在整个网格中搜索所有高和宽均不小于 3 的全黑(0)矩形区域。
6. 将面积最大的全黑矩形填充为黄(4)。若有面积并列，选择左上角行号最小的；仍并列则选左上角列号最小的。

**关键洞察**：最大空腔的位置和大小取决于所有对象的形状、位置、孔洞状态和描边范围的联合效果——不能跳过任何一步。有孔对象的品红填充虽然填了内部空间，但其描边范围因包含了孔洞而变大，进一步侵蚀了周围的背景。需要对比有孔和无孔对象的示例才能理解重涂规则与描边范围的关系。

## 新题 10：形状频率决定缩放倍率的分色裁剪

**组合逻辑**：[形状匹配(shape_matching)] + [计数(counting)](创新：计数对象是不同的形状种类数而非对象数) → [缩放(scaling)](创新：缩放倍率由形状种类数编码) + [裁剪(crop)](创新：裁剪目标由形状频率决定) + [重涂色(recolor)](创新：涂色由频率类别决定)

**来源原语**：形状匹配/唯一重复形分涂/连通分量/精灵体(b230c067), 计数/像素放大/缩放/前景色数定倍率/编码映射(b91ae062), 裁剪(c909285e)

**依赖链**：对象形状归一化 → 按形状分组 → 计数不同形状的种类数 S → S 成为缩放倍率 → 从中选出唯一形状的对象裁剪其边界框 → 将裁剪结果缩放 S 倍 → 缩放图中原对象色涂红、背景涂黑。形状分析的两个产出（唯一形状的识别 + 种类计数）分别驱动裁剪目标选择和缩放倍率，形成分叉-汇合结构。

识别形状唯一的对象并裁剪，以形状种类数为倍率放大输出，唯一形状涂红、重复形状涂蓝。

**输入结构**：约 15x15 的黑(0)背景网格。网格中有 5~8 个互不 8-邻接的 8-连通灰(5)前景对象，每个对象占 3~8 像素。这些对象的归一化边界框形状（平移等价的二值掩码）共有 S 种（S 为 2 或 3），其中恰好一种形状只出现一次（唯一形状），其余形状各出现至少两次。生成约束：唯一形状对象的边界框不超过 5x5；S 值在不同示例中可以不同（有时 2 种形状，有时 3 种）。

**规则**：
1. 对每个灰(5)前景对象，提取其 8-连通像素集合，裁剪到边界框，生成归一化二值掩码。
2. 将所有对象按归一化掩码分组。统计不同形状的种类数 S。
3. 找到只出现一次的那个形状对应的对象（唯一形状对象），裁剪其边界框内容，得到一个小网格（灰(5)像素和黑(0)像素）。
4. 将小网格中的灰(5)像素重涂为红(2)，黑(0)保持不变。
5. 将该小网格做 S 倍像素放大：每个像素替换为 S x S 的同色方块。
6. 输出为放大后的网格。

**关键洞察**：缩放倍率不是固定的，而是由输入中存在多少种不同形状隐式编码——这要求求解者先完成形状分类才能知道输出尺寸。同时，裁剪目标也由形状频率分析决定（选唯一形状），形成分叉结构：同一个分析步骤的两个产出分别决定了"放大什么"和"放大多少倍"。仅凭单个示例可能误判缩放倍率的来源（以为是固定的 2 倍或由对象大小决定）。
