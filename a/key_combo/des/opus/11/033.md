## 新题 1：屏障区域计数驱动像素放大倍率

**组合逻辑**：[计数 counting](创新：计数结果不再直接构成输出像素列，而是参数化另一变换的倍率) + [像素放大 pixel_upscale](创新：放大倍率不再是固定整数，而是由空间拓扑动态决定)

**来源原语**：计数(counting)、连通分量(connected_component)、背景区域(bg_region)、前景屏障(fg_barrier) 来自 e872b94a；像素放大(pixel_upscale)、均匀整数倍缩放(uniform_integer_scaling) 来自 60c09cac

**依赖链**：左面板的屏障拓扑决定一个计数 N，N 成为右面板模板的像素放大倍率。两个面板各自提供不可替代的信息（一个编码数字，一个提供内容），合流产生输出。去掉计数则倍率未知；去掉模板则无内容可放大。

用一个分区网格中的背景连通区域数作为另一区域内模板图案的像素放大倍率，输出放大后的独立模板。

**输入结构**：
- 网格约 10x16，黑(0) 背景。
- 一列灰(5) 像素纵贯网格全高，将其分为左面板和右面板。
- 左面板：红(2) 前景路径（1 像素宽的 4-连通连线）构成屏障，将左面板的黑(0) 背景分割为 N 个 4-连通区域（N 在不同示例中为 2~4）。红路径在不同示例中形态不同（直线、折线、分叉等），但始终 1 像素宽且 4-连通。屏障至少有一端接触左面板的边界，保证分割出封闭的背景区域。
- 右面板：一个小型多色图案（边界框约 2x3 到 3x3，使用蓝(1)、绿(3)、黄(4) 像素，在黑(0) 背景上）位于右面板的左上角区域。右面板其余部分为黑(0)。不同示例中模板的形状和颜色组合不同。
- 生成约束：模板边界框尺寸乘以最大可能倍率（N=4）后不超过 16x16。

**规则**：
1. 识别灰(5) 分隔列。分隔列左侧所有列为左面板，右侧所有列为右面板。
2. 在左面板中，将红(2) 像素视为前景屏障，计算黑(0) 背景的 4-连通区域数量，记为 N。
3. 在右面板中，取所有非黑像素的最小轴对齐边界框作为模板（高 H、宽 W）。
4. 输出一个独立的 (H x N) x (W x N) 网格：模板中每个像素被替换为同色的 N x N 方块。黑(0) 像素同样扩展为 N x N 的黑方块。
5. 输出中不包含灰分隔列、红屏障或面板结构——仅包含放大后的模板。

**关键洞察**：左面板是一个空间编码器——它的拓扑结构编码了一个整数。右面板提供视觉内容。这两个信息源汇合产生输出，但单独看任一面板都无法确定结果。求解者必须发现"区域数 = 放大倍率"这一跨面板的参数化关系，而非直接从像素中读取倍率。

## 新题 2：多种子周期竖线与触发行选择性光环

**组合逻辑**：[连线 draw_line / 种子周期生成竖线](多个种子各自按固定周期生成竖线) → [邻接触发 adjacency_triggers](创新：触发效果从对角溅射改为光环扩展，且仅行位置恰好紧邻触发条的种子才激活) → [邻域扩展 neighborhood_expand / 光环 halo](激活种子的竖线底端扩展为 3x3 光环)

**来源原语**：连线(draw_line)、种子像素(seed_pixel)、竖线段(vertical_bar)、周期间隔(periodic_space)、种子周期生成竖线(seed_periodic_bars) 来自 8403a5d5；触发条(trigger_bar)、邻接触发对角溅射(adjacency_triggers_diagonal_splash) 来自 73c3b0d8；邻域扩展(neighborhood_expand)、光环区域(halo_region)、仅填背景格(only_fill_background) 来自 dc1df850

**依赖链**：每个种子的行位置决定它是否"够得到"触发条；种子的列位置和周期决定竖线分布在哪些列；只有激活种子的竖线底端产生光环。三层逻辑交织：种子的空间属性同时控制周期分布和激活判定。

多个种子像素各自按周期向右生成竖线，但只有行位置恰好在触发条正上方一行的种子被激活——激活种子的所有竖线底端扩展为灰色光环，其他种子的竖线保持原色不变。

**输入结构**：
- 网格约 14x20，黑(0) 背景。
- 一条横贯网格全宽的红(2) 水平条（1 像素高），位于网格下部（距底部约 2~3 行），作为触发条。
- 2~3 个种子像素分布在触发条上方不同位置。每个种子有不同颜色（从蓝(1)、绿(3)、橙(7) 中选用）。不同种子在不同行、不同列。其中恰好 1 个种子位于 trigger_row - 1 行（触发条正上方一行），其余种子在更高的行（距触发条 3 行以上）。
- 灰(5) 在输入中不出现，保留给光环输出。
- 生成约束：不同种子的周期竖线列集合互不重叠（种子列位置和间隔保证不产生同列冲突）。

**规则**：
1. 对每个种子像素，在种子所在列及其右侧每隔 3 列的列上绘制与种子同色的竖线。每条竖线从第 0 行延伸到种子所在行（包含种子像素本身），覆盖该列的 [0, seed_row] 行范围。超出网格宽度的列不绘制。
2. 判断每个种子是否被触发条激活：当且仅当种子所在行 == trigger_row - 1（即种子在触发条正上方一行）时，该种子被激活。
3. 对于被激活的种子：其所有竖线在 seed_row 行的像素（即竖线最底端的像素）各自扩展为 Chebyshev 距离 1 的 3x3 光环。光环中所有黑(0) 像素染为灰(5)。
4. 未被激活的种子：其竖线保持原色不变，不产生光环。
5. 灰(5) 光环不覆盖任何已有的非黑像素（种子色像素、红(2) 触发条像素均保留）。触发条保持不变。

**关键洞察**：存在多个种子，每个都生成周期竖线，但只有位于触发条正上方一行的种子被"激活"。未激活的种子是干扰项——它们的竖线出现在输出中但不产生光环。求解者必须同时理解周期竖线生成规则和基于行位置的激活条件，并从多个示例中区分激活种子与非激活种子的行为差异。

## 新题 3：镜像马赛克与标记编码槽位提取

**组合逻辑**：[镜像 mirror / 相邻槽位翻转 adjacent_slot_flip](概念性构建镜像马赛克) ⊗ [标记坐标编码槽位 marker_encodes_slot](标记位置选择输出槽位) → [擦除 erase](标记被消费)

**来源原语**：镜像(mirror)、平铺(tiling)、瓦片(tile)、阵列排布(array_layout)、相邻槽位翻转(adjacent_slot_flip) 来自 c48954c1；标记坐标编码槽位(marker_encodes_slot)、标记像素(marker_pixel)、复制(copy) 来自 6d0160f0；擦除(erase) 来自 a416fc5b

**依赖链**：镜像逻辑决定每个槽位的瓦片内容；标记位置解码出目标槽位；擦除移除标记。三者非线性依赖：镜像变换和标记解码各自独立贡献信息，合流确定唯一输出。去掉镜像则不知道槽位内容，去掉标记则不知道选哪个槽位。

从一个含标记的小瓦片出发，概念性构建 3x3 镜像马赛克，仅提取标记本地坐标所指示的那个槽位作为输出，并从结果中擦除标记。

**输入结构**：
- 一个 3x3 彩色网格。每个格子都有颜色填充，无黑(0) 背景。
- 恰好一个格子为黄(4)，作为标记像素。其余 8 个格子使用 2~3 种其他颜色（如蓝(1)、红(2)、绿(3)），颜色分布在不同示例中变化。
- 瓦片在行列翻转组合下不对称（即不存在非恒等的行/列翻转组合使瓦片映射到自身），保证 9 个马赛克槽位产生不同的视觉结果。
- 生成约束：黄(4) 标记不在中心位置 (1,1)，保证输出是某种翻转版本而非原始瓦片。

**规则**：
1. 概念性构建 3x3 镜像马赛克（9 个 3x3 槽位）：
   - 中心槽位（宏行 1、宏列 1）：原始瓦片不变。
   - 上方或下方槽位（宏行 0 或 2、宏列 1）：将原始瓦片的行顺序翻转（第 0 行与第 2 行互换）。
   - 左方或右方槽位（宏行 1、宏列 0 或 2）：将原始瓦片的列顺序翻转（第 0 列与第 2 列互换）。
   - 四角槽位（宏行 ∈ {0,2}，宏列 ∈ {0,2}）：同时翻转行和列。
2. 读取黄(4) 标记在瓦片内的本地坐标 (r, c)，其中 r, c ∈ {0, 1, 2}。
3. 选取马赛克中宏位置 (r, c) 处的槽位。
4. 在选取的 3x3 槽位中，找到黄(4) 标记经过翻转后所在的位置，将其替换为黑(0)。
5. 输出仅为该 3x3 槽位。

**关键洞察**：黄色标记具有双重角色——它既是瓦片的视觉内容的一部分（参与镜像变换），又编码了目标槽位的元数据（通过其位置坐标）。马赛克从不被完整构建，只有标记指示的那个槽位出现在输出中。标记在输出中被"消费"（擦除），防止循环推理。求解者必须理解坐标即指令这一隐含编码。

## 新题 4：十字投影射线被标记光环隐式阻挡

**组合逻辑**：[邻域扩展 neighborhood_expand / 光环 halo](不可见的中间步骤：计算阻挡区) → [射线延伸 ray_extend / 十字投影 cross_projection](射线从矩形发出，被光环阻挡区截停) → [重涂色 recolor](光环区最后渲染为可见蓝色)

**来源原语**：射线延伸(ray_extend)、十字投影(cross_projection)、实心矩形(solid_rectangle)、射线遇障停止(ray_stops_at_block)、特定色为墙壁(specific_is_wall) 来自 6ffe8f07；邻域扩展(neighborhood_expand)、光环区域(halo_region)、标记像素(marker_pixel)、仅填背景格(only_fill_background) 来自 dc1df850；印章(stamp)、标记像素(marker_pixel) 来自 a04b2602

**依赖链**：光环几何（从标记计算）决定射线的截停位置。射线基于矩形 + 光环的交互来绘制。光环最后才渲染为可见颜色。光环计算是不可见的中间步骤——它不直接出现在输入中，但控制着射线行为。

一个实心矩形发出十字形黄色射线，射线在到达红色标记像素周围的扩展光环区时截停；光环区本身最终显示为蓝色。

**输入结构**：
- 网格约 15x15，黑(0) 背景。
- 一个实心青(8) 矩形，约 2x3 到 3x4 像素大小。
- 2~4 个红(2) 标记像素散布在网格中，与青矩形保持一定距离（无红像素与青矩形相邻或重叠）。
- 蓝(1) 和黄(4) 在输入中不出现。
- 生成约束：任意两个红标记的 3x3 Chebyshev 邻域互不重叠，也不与青矩形重叠。

**规则**：
1. 对每个红(2) 标记像素，计算其阻挡区：以该标记为中心的 Chebyshev 距离 1 邻域内所有格子（3x3 区域）。此步仅计算，不立即绘制。
2. 从青(8) 矩形的每一行，分别向左和向右发射黄(4) 射线，直到射线到达以下任一情况时截停：(a) 射线的下一个格子属于任一阻挡区，或 (b) 射线的下一个格子属于青矩形本身，或 (c) 射线到达网格边界。射线截停在阻挡格之前——阻挡格本身不被染黄。
3. 从青矩形的每一列，分别向上和向下发射黄(4) 射线，截停规则相同。
4. 所有射线绘制完成后，渲染阻挡区：每个阻挡区中当前为黑(0) 的格子染为蓝(1)。红(2) 标记像素保持红色。蓝色不覆盖黄色或青色。
5. 青矩形保持不变。

**关键洞察**：输出中可见的阻挡物是蓝色光环，但射线截停的位置在蓝色光环的外边界——因为阻挡区从红标记向外扩展了 1 像素。求解者乍看会以为射线在红标记处停止，但仔细测量会发现射线终点与红标记之间总是有 1 格间距。这个间距来自不可见的光环扩展步骤。必须通过多个示例中不同标记位置的射线长度来归纳出扩展规则。

## 新题 5：点对称反射被网格分区占用状态过滤

**组合逻辑**：[点对称补全 point_symmetry / 绕中心点旋转对称 center_rotational](计算 180° 反射像素) ⊗ [网格分区 grid_partition + 占用过滤](空间掩模决定哪些反射像素存活) — 同时约束满足，非流水线

**来源原语**：点对称补全(point_symmetry)、中心标记(center_marker)、前景图案(foreground_pattern)、绕中心点旋转对称(center_rotational) 来自 e729b7be；网格分区(grid_partition)、分隔线(separator_line) 来自 6d0160f0；擦除(erase) 来自 a416fc5b；仅处理区域内标记(markers_inside_only)、忽略干扰项(ignore_distractors) 来自 a04b2602

**依赖链**：点对称决定反射像素的目标位置；网格分区的占用状态决定哪些目标位置被允许。输出既非纯反射亦非纯分区操作，而是两者的交集。

将一组彩色像素绕中心标记做 180° 点对称反射，但仅在无占用标记的网格分区内绘制反射像素；被占用分区中的反射像素被丢弃。

**输入结构**：
- 网格约 13x13，黑(0) 背景。
- 灰(5) 分隔行和分隔列以等间距排列（各 1 像素宽），将网格分成 3x3 阵列的 9 个等大矩形内部区域（每个内部区域约 3x3 到 4x4 像素）。
- 一个红(2) 中心标记像素位于网格的中心（即中央分隔行与中央分隔列的交叉点）。
- 一个 4-连通的蓝(1) 像素图案（3~6 像素，不对称形状）完全位于 9 个区域中的一个区域内。
- 1~3 个区域各含一个绿(3) "占用"标记像素（单像素）。占用标记不出现在源图案所在区域，也不出现在源图案经 180° 反射后的对称目标区域。其余未被占用且非源区域的区域为空（全黑）。
- 生成约束：蓝像素经 180° 反射后全部落在有效的区域内部（不落在分隔线上）。源区域的 180° 对称区域始终无占用标记，保证主体反射可见。

**规则**：
1. 对每个蓝(1) 像素 (r, c)，计算其关于红中心标记 (cr, cc) 的 180° 反射位置：(2*cr - r, 2*cc - c)。
2. 判断反射位置所落入的网格分区区域。
3. 如果该区域不含绿(3) 占用标记，则在反射位置绘制蓝(1) 像素。
4. 如果该区域含有绿(3) 占用标记，则丢弃该反射像素（该位置保持黑(0)）。
5. 原始蓝(1) 图案、所有灰(5) 分隔线、红(2) 中心标记、所有绿(3) 占用标记均保持不变。

**关键洞察**：几何反射本身是直接的，但占用掩模使反射图案看起来"残缺"——部分预期的反射像素消失了。求解者必须同时识别 180° 旋转规则和分区级别的占用过滤。绿标记不是干扰项——它们是主动的空间过滤器，选择性地压制反射图像的某些片段。需要对比多个示例（不同占用模式）来确认是分区级过滤而非像素级过滤。

## 新题 6：拉伸线条图后按后续面积排名填色

**组合逻辑**：[拉伸 stretch / 重绘 redraw / 边缘对齐控制点](几何变换改变区域比例) → [计数 counting / 连通分量 connected_component](统计拉伸后的封闭区域) → [填充 fill](按面积排名分配颜色)

**来源原语**：拉伸(stretch)、重绘(redraw)、直角线条图(rectilinear_drawing)、控制像素(control_pixel)、边缘对齐控制点(edges_align_control)、控制点定拉伸界(control_stretch_bound) 来自 baf41dbf；计数(counting)、连通分量(connected_component)、背景区域(bg_region) 来自 e872b94a；填充(fill) 来自 15660dd6；尺寸匹配(size_matching) 来自 e76a88a6

**依赖链**：拉伸改变封闭区域的面积比例（因为内部分隔条不移动而外框移动）。面积排名依赖于拉伸后的几何而非拉伸前。填色依赖排名。拉伸可能颠覆原始面积顺序，使求解者无法跳过拉伸步骤直接排名。

将一个带内部分隔的直角线条图拉伸到控制点位置，然后统计拉伸后的封闭区域面积，按面积从小到大分配不同颜色。

**输入结构**：
- 网格约 15x15，黑(0) 背景。
- 一个灰(5) 直角线条图：由 1 像素宽的水平和竖直条构成一个封闭的矩形外框，内部有 1~2 条 1 像素宽的分隔条（也是灰(5)），将外框内部分成 2~4 个互不连通的黑(0) 封闭区域。分隔条的两端连接到外框的对边。
- 2~4 个橙(7) 控制像素，各位于线条图外框外部 1 格处（与外框某边相邻但不重叠）。每个控制像素紧邻外框的一条外边（上、下、左或右），指示该边应移动到的目标位置。
- 蓝(1)、红(2)、绿(3)、黄(4) 在输入中不出现，保留给填色输出。
- 生成约束：控制像素始终将外框边缘向外推（拉伸，不压缩）。拉伸后内部分隔条保持原位不动。拉伸后封闭区域数量不变。不同示例中，拉伸前后的面积排名可能不同（这是核心考点）。

**规则**：
1. 对每个橙(7) 控制像素，确定它紧邻的外框边（上、下、左或右）。将该外框边移动到控制像素所在的行或列。
2. 外框边移动后，与之相连的两条垂直/水平外框边相应延伸以保持封闭矩形结构。内部分隔条保持原位不动，但其两端延伸到新的外框位置以保持连接。
3. 拉伸完成后，识别灰(5) 线条图内部的所有 4-连通黑(0) 封闭区域。
4. 按面积（像素数）升序排列这些区域。面积相同时，按区域最上方行号升序排列；仍相同则按最左列号升序排列。
5. 按排名依次将区域填充为：最小 → 蓝(1)，次小 → 红(2)，再次 → 绿(3)，最大 → 黄(4)。若区域数超过 4，继续循环使用蓝(1)、红(2)、绿(3)、黄(4)。
6. 灰(5) 线条图、橙(7) 控制像素、外框外部的黑(0) 背景均保持不变。

**关键洞察**：拉伸改变了区域面积的比例关系。由于外框边移动而内部分隔条不动，靠近外框的区域面积增加更多。一个拉伸前最小的区域在拉伸后可能变为最大，导致颜色分配完全不同。求解者不能依赖输入中的视觉面积直觉，必须先执行拉伸再重新测量面积。

## 新题 7：格点标记沿分隔线周期传播与奇偶碰撞变色

**组合逻辑**：[连线 draw_line / 沿分隔线传播](标记沿格线传播颜色) ⊗ [重涂色 recolor / 碰撞变色](两个传播波在同一格点碰撞时产生第三种颜色) — 多源交互，非流水线

**来源原语**：重涂色(recolor)、分隔行列(separator_row_col)、格点交叉(lattice_intersection)、行列交叉(row_col_intersection)、完整行列为分隔线(full_rows_cols_separators) 来自 95a58926；连线(draw_line) 来自 8403a5d5；列周期(column_periodicity)、周期列触发变色(periodic_column_triggers_recolor) 来自 ba26e723；噪声像素(noise_pixel) 来自 95a58926

**依赖链**：每个标记沿格线独立传播，传播是周期性的（隔一个交叉点画一个）。碰撞发生在两个传播波覆盖同一格点的位置。碰撞是否发生取决于两个标记之间的格线距离的奇偶性——这是组合涌现出的新规律，不存在于任何源题中。

格线交叉点上的标记沿各自的分隔行和分隔列传播颜色，每隔一个交叉点画一个（周期 2）；两个传播波覆盖同一交叉点时，该点变为特殊颜色。

**输入结构**：
- 网格约 13x13，黑(0) 背景。
- 绿(3) 分隔行和分隔列构成规则格线，各 1 像素宽。格线将网格分为 m x n 的矩形内部面板（每个面板约 2x2 到 3x3 像素）。
- 在 2~3 个格线交叉点处（分隔行与分隔列的交点），绿像素被替换为红(2) 或蓝(1) 标记像素。不同标记可有不同颜色。
- 黄(4) 在输入中不出现，保留给碰撞输出。
- 生成约束：任意两个标记不在同一分隔行上，也不在同一分隔列上（每个标记独占一行一列，传播路径不产生方向性歧义）。

**规则**：
1. 每个标记从自身位置出发，沿其所在的分隔行（向左和向右）以及分隔列（向上和向下）传播自身颜色。
2. 传播以格线交叉点为单位，周期为 2：从标记出发，跳过第 1 个交叉点，画第 2 个交叉点，跳过第 3 个，画第 4 个，依此类推。交叉点之间的非交叉分隔线像素（连接段）也被染为标记颜色，但仅在标记与其下一个被画的交叉点之间的连接段上（即跳过的交叉点两侧的连接段保持绿色）。
3. 传播替换绿(3) 像素为标记颜色。
4. 若两个不同标记的传播同时到达同一格线像素（交叉点或连接段），该像素染为黄(4)，而非任一标记的颜色。
5. 内部面板（非分隔线的像素）保持黑(0) 不变。
6. 标记像素本身保持原色，不被其他标记的传播覆盖，也不因自身位置可能被另一传播到达而变黄。

**关键洞察**：由于传播隔一个交叉点画一个，两个标记是否在同一分隔线上碰撞取决于它们之间的格线距离（以交叉点数计）的奇偶性。距离为偶数的标记会在中间某些交叉点碰撞；距离为奇数的标记永远不会碰撞——它们的传播波恰好交错。求解者必须从多个示例中归纳出这一奇偶规律，而不能仅凭距离远近判断。

## 新题 8：移动像素下移溅射被空心矩形框截停

**组合逻辑**：[平移 shift / 固定步长移动](像素下移一行) → [邻接触发对角溅射 adjacency_triggers_diagonal_splash](落在触发条正上方时发射对角射线) → [射线遇障停止 ray_stops_at_block](空心矩形框截停对角射线)

**来源原语**：平移(shift)、移动像素(moving_pixel)、触发条(trigger_bar)、固定步长移动(fixed_step_move)、邻接触发对角溅射(adjacency_triggers_diagonal_splash) 来自 73c3b0d8；射线延伸(ray_extend)、射线遇障停止(ray_stops_at_block) 来自 6ffe8f07；空心矩形(hollow_rectangle) 来自 a04b2602；擦除(erase) 来自 a416fc5b

**依赖链**：下移决定新位置；邻接判定决定哪些像素溅射；空心矩形的位置决定溅射的延伸范围。每步的输出约束下一步。去掉下移则不知道谁溅射；去掉空心矩形则溅射延伸到边界（退化为参考题 73c3b0d8）；去掉触发条则没有溅射。

彩色像素下移一行，落在触发条正上方的发射对角溅射射线，但射线被空心矩形框的边缘截停。

**输入结构**：
- 网格约 14x14，黑(0) 背景。
- 一条横贯网格全宽的绿(3) 水平条（1 像素高），位于网格下部约 1/3 处，作为触发条。
- 2~4 个红(2) 单像素分布在触发条上方不同列。每个红像素在触发条上方至少 2 行（确保有下移空间）。其中恰好 1~2 个红像素位于 trigger_row - 2 行（下移 1 行后恰好在触发条正上方 trigger_row - 1 行，触发溅射）。其余红像素在更高位置（下移后仍不相邻触发条，不触发溅射）。
- 1~2 个蓝(1) 空心矩形（仅边框，1 像素宽边框，内部为黑(0)），约 3x3 到 5x5 大小，位于触发条上方。空心矩形不接触触发条，不接触任何红像素。
- 黄(4) 在输入中不出现，保留给溅射射线输出。
- 生成约束：空心矩形的位置使得至少一条溅射射线在到达网格边界前被截停。

**规则**：
1. 清除每个红(2) 像素的原始位置（设为黑(0)）。
2. 在每个红像素的同列、下方一行的位置绘制红(2)（即下移一行）。
3. 判断每个下移后的红像素是否位于触发条正上方一行（即 trigger_row - 1 行）：
   - 是：从该像素向左上和右上两个对角方向各发射一条黄(4) 射线。射线逐像素延伸，每步行号 -1、列号 ±1，直到以下任一情况截停：(a) 下一个像素属于蓝(1) 空心矩形边框，(b) 下一个像素超出网格边界。射线截停在阻挡像素之前——蓝边框像素不被覆盖。
   - 否：该像素仅出现在新位置，不产生溅射。
4. 绿(3) 触发条和蓝(1) 空心矩形保持不变。黄射线不覆盖任何非黑像素。

**关键洞察**：空心矩形充当"盾牌"，截断对角溅射的延伸。不同矩形位置产生不同形状的溅射轮廓。求解者必须同时理解三个机制：下移、条件溅射、框阻挡。矩形的角色纯粹是遮挡性的——它们不移动也不变化，但决定了溅射的可见范围。

## 新题 9：交叉参照旋转瓦片补全

**组合逻辑**：[旋转 rotate / 旋转关系 rotation_relation](每个分区含同一瓦片的不同旋转版本) ⊗ [对称补全 symmetric_complete / 跨区域推理](各区域互相补充缺失像素) — 同时约束满足，需跨所有区域交叉推理

**来源原语**：旋转(rotate)、旋转关系(rotation_relation) 来自 a416fc5b；对称补全(symmetric_complete)、对侧互补(opposite_side_complement) 来自 8dab14c2；瓦片(tile)、网格分区(grid_partition)、分隔线(separator_line) 来自 6d0160f0；平铺(tiling)、阵列排布(array_layout) 来自 c48954c1

**依赖链**：旋转判定和像素补全相互依赖：要知道缺失什么像素，需先确定旋转角度；要确认旋转角度，需比对现有像素。四个区域形成同时约束——单独看任何一个区域都无法确定完整瓦片。

四个分区各含同一基础瓦片的不同旋转版本，每个版本被擦除了不同的像素；通过跨区域交叉参照重建完整信息并填补所有缺口。

**输入结构**：
- 网格约 9x9，黑(0) 背景。
- 灰(5) 分隔行和分隔列各 1 条（各 1 像素宽），将网格分成 2x2 阵列的 4 个 4x4 区域。
- 存在一个基础瓦片（4x4，使用 2~3 种颜色如蓝(1)、红(2)、绿(3)，在黑(0) 背景上，含 5~8 个非黑像素，形成 4-连通的不对称形状）。该基础瓦片在输入中不直接出现。
- 四个区域分别包含该基础瓦片的不同旋转版本：
  - 左上区域：0°（原始方向）
  - 右上区域：顺时针 90°
  - 左下区域：顺时针 270°（即逆时针 90°）
  - 右下区域：180°
- 每个区域中有 2~3 个非黑像素被擦除（设为黑(0)）。四个区域被擦除的像素不同，但保证：基础瓦片的每一个非黑像素至少在某一个区域的对应旋转版本中未被擦除（即四个区域合起来可以完全重建基础瓦片的所有信息）。
- 生成约束：基础瓦片在所有旋转下均不对称（不存在旋转使其映射到自身），保证每个区域的旋转角度可唯一确定。

**规则**：
1. 旋转约定固定为：左上 = 0°，右上 = 顺时针 90°，右下 = 180°，左下 = 顺时针 270°。
2. 对每个区域，将其可见（非黑）像素按该区域对应的逆旋转映射回基础瓦片坐标系。
3. 合并四个区域的贡献，重建完整的基础瓦片（每个像素至少被一个区域确认）。
4. 将完整基础瓦片分别按每个区域的旋转角度正向旋转，填入该区域中缺失的像素。
5. 灰(5) 分隔线保持不变。已有的非黑像素保持不变。

**关键洞察**：没有任何一个区域是完整的。一个在 0° 版本中被擦除的像素，可能在 90° 版本中可见——但它出现在旋转后的不同位置。求解者必须：(1) 发现旋转约定，(2) 将每个区域"反旋转"到统一坐标系以合并信息，(3) 再"正旋转"回来填补缺口。这需要同时处理所有四个区域，是真正的同时约束满足问题。

## 新题 10：宽度加倍平铺后接缝处触发对角射线

**组合逻辑**：[平铺 tile / 重复 repetition / 宽度加倍](网格向右复制一次) → [邻接触发对角溅射 adjacency_triggers_diagonal_splash](创新：触发条件不是固定触发条，而是平铺接缝处产生的新邻接关系) — 平铺创造了原始输入中不存在的拓扑条件

**来源原语**：平铺(tile)、整幅画布(full_grid)、重复(repetition) 来自 a416b8f3；射线延伸(ray_extend)、八方向发射(eight_dir_emit) 来自 fe9372f3；邻接触发对角溅射(adjacency_triggers_diagonal_splash) 来自 73c3b0d8；网格边缘(grid_edge)、画布边界(canvas_boundary) 来自 fe9372f3 / 8403a5d5

**依赖链**：平铺在接缝处创造新的像素邻接关系。这些新邻接成为对角射线的触发条件。没有平铺就没有接缝邻接；没有射线规则则平铺只是简单复制。平铺的输出改变了射线触发的前提条件——这是源题中不存在的结构关系。

将整个网格向右复制一次（宽度加倍），然后在接缝处——左半部分右边缘与右半部分左边缘的同行非背景像素对——发射向上的对角射线。

**输入结构**：
- 网格约 7x7，含若干彩色像素（蓝(1)、红(2)、绿(3)）在黑(0) 背景上。
- 网格的最右列和最左列各至少有 1 个非黑像素（确保平铺后接缝处存在邻接对）。
- 黄(4) 在输入中不出现，保留给射线输出。
- 网格的图案不具有左右对称性（保证平铺输出不是一个看起来宽度翻倍的对称图案，增加辨识难度）。
- 生成约束：最右列与最左列在同一行均有非黑像素的行数为 1~2 行（控制接缝触发对的数量，避免输出过于杂乱）。

**规则**：
1. 创建宽度加倍的输出网格：原始网格占据左半部分（列 0 到 W-1），完全相同的副本占据右半部分（列 W 到 2W-1）。
2. 识别接缝邻接对：对于每一行 r，如果左半部分的第 W-1 列（左半最右列）在第 r 行有非黑像素，且右半部分的第 W 列（右半最左列）在第 r 行也有非黑像素，则该行的这两个像素构成一个接缝邻接对。
3. 对接缝邻接对中的每个像素，向上发射黄(4) 对角射线：
   - 从左半部分的像素 (r, W-1) 向左上方发射：每步行 -1、列 -1，直到超出网格边界。
   - 从右半部分的像素 (r, W) 向右上方发射：每步行 -1、列 +1，直到超出网格边界。
4. 对角射线仅绘制在黑(0) 背景格上，不覆盖任何已有的非黑像素。
5. 所有原始内容和平铺副本保持不变。

**关键洞察**：在原始网格中，最右列的像素与最左列的像素并不相邻——它们之间隔着整个网格的宽度。但平铺后，左半的右边缘与右半的左边缘紧密相邻，创造了原本不存在的拓扑邻接关系。正是这种平铺引发的新邻接激活了对角射线。求解者必须理解：平铺不只是视觉上的复制，它创造了新的空间条件，从而触发了第二种变换。
