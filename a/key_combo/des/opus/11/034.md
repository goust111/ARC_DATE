## 新题 1：嵌套环指向射线

**组合逻辑**：[嵌套层序](已有) + [指示像素→罗盘方向](创新：指示像素的位置不再指示延伸侧，而是编码射线方向) → [射线延伸](已有，但从公共中心而非各自中心出发) → [重涂色](已有，但颜色由环层而非标记本身决定) + [嵌套层序决定绘制优先级](创新：外层先画、内层后画，交叉处内层覆盖外层)

**来源原语**：嵌套层序、色沿层序循环移(bda2d7a6)；指示像素、方向指示(b527c5c6)；射线延伸、罗盘方向、中心向外辐射(1d398264)；重涂色(673ef223)

**依赖链**：环的嵌套层序决定指示像素的读取顺序和射线绘制优先级；指示像素在其所在环上的位置编码射线方向；环的颜色决定射线颜色；射线之间的交叉由嵌套层序决定覆盖关系——三者互相依赖，缺一不可。

从同心环的指示像素读取方向，以最内环中心为起点射出彩色射线，外层环的射线先画、内层后画以决定交叉覆盖。

**输入结构**：黑(0)背景上有 3~5 层同心矩形环（约 15x15 网格），每层环一像素厚、各不同色（从蓝(1)、红(2)、绿(3)、黄(4)、灰(5)中取）。每层环的某一侧边（上/下/左/右）上恰好有一个像素被替换为橙(7)，作为该层的指示像素。各层指示像素所在的侧边互不相同或可重复（需从示例中归纳覆盖规则）。最内层环围出的中心区域为 1x1 或 2x2 的黑(0)空间。生成约束：各环颜色互不相同；每层恰好一个橙(7)指示像素。

**规则**：
1. 找到所有同心环并确定嵌套层序（最外层为第 1 层，最内层为第 N 层）。
2. 对每层环，找到其橙(7)指示像素。该像素在环的哪一侧决定射线方向：上侧→向上、下侧→向下、左侧→向左、右侧→向右。
3. 以最内层环围出的中心区域的中心像素为射线起点（若中心区域为 2x2，取左上角像素）。
4. 按**从外到内**的顺序依次绘制射线：从起点沿该层指示的方向画直线至网格边界，颜色为该层环的原色（非橙色）。后绘制的射线覆盖先绘制的射线（即内层射线优先）。
5. 擦除所有原始同心环和指示像素（置为黑(0)），只保留射线和起点。起点像素涂为橙(7)。

**关键洞察**：射线的绘制顺序由环的嵌套层序决定（外先内后），因此在同一方向上若多层环都指向该方向，最终可见的是最内层的颜色——必须对比多个示例才能确认"内层覆盖外层"而非相反。

## 新题 2：轮廓分区投票擦界

**组合逻辑**：[轮廓线→封闭区域划分](已有) → [多数投票→区域填充](创新：投票对象从分隔行上方区域变为轮廓围出的任意区域) → [擦除](创新：擦除条件不由标记像素决定，而由相邻区域投票结果的比较决定)

**来源原语**：轮廓线、外侧相邻(aa62e3f4)；多数投票、计数(27a77e38)；填充、封闭孔洞(e73095fd)；擦除(d255d7a7)

**依赖链**：轮廓线划分出封闭区域→每个区域内部像素的多数投票决定该区域的填充色→相邻区域的填充色比较决定轮廓线段是否保留。投票结果影响擦除判断，而擦除改变了最终的区域边界——三步形成不可跳过的推理链。

用轮廓线划分区域后，对每个区域内的散点做多数投票以填色，再擦除相邻同色区域之间的轮廓段。

**输入结构**：黑(0)背景约 14x14 网格。灰(5)像素构成若干闭合轮廓线（每条轮廓为一像素厚的 4-连通闭合环），将网格内部划分为 4~6 个不重叠的封闭区域。每个区域内散布 3~8 个单像素点，颜色取自红(2)、绿(3)、蓝(1)、黄(4)（每个区域内至少两种颜色，但某种颜色的像素数严格多于其他颜色）。轮廓线之间不共享像素。最外围（轮廓线外侧到网格边界的区域）也视为一个区域。生成约束：每个区域内恰好有一个颜色的像素数严格最多，不出现平局。

**规则**：
1. 识别灰(5)轮廓线划分出的所有封闭区域（包括轮廓线外侧到网格边缘的外围区域）。
2. 对每个区域，统计其内部所有非黑(0)非灰(5)像素的颜色。出现次数最多的颜色为该区域的"投票色"。
3. 将每个区域内的所有黑(0)像素（不含灰(5)轮廓）填充为该区域的投票色；原有散点保持不变（它们已经是某种颜色）。
4. 检查每一段灰(5)轮廓线：若该段两侧的区域投票色相同，则将该段轮廓擦除为该投票色（区域合并）；若两侧投票色不同，保留灰(5)轮廓。
5. 外围区域与网格边界相邻的轮廓线段始终保留。

**关键洞察**：轮廓线的去留不取决于轮廓本身的属性，而取决于它两侧区域各自独立投票后的结果比较——这一规则无法从单个示例中确认，必须对比多个区域对的保留/擦除情况才能归纳。

## 新题 3：梳状编码模板缩放

**组合逻辑**：[高度编码数量](已有) → [像素放大](创新：缩放因子不由全局色数决定，而由每个梳状结构独立编码) → [印章放置](创新：模板的放置位置由梳状结构的水平位置决定，而非由单像素布局决定) + [重涂色](已有，颜色来自梳状结构)

**来源原语**：高度编码数量、梳状结构、压缩(a1aa0c1e)；像素放大、色数决定缩放(469497ad)；印章放置、模板(a395ee82)；重涂色(221dfab4)

**依赖链**：梳状结构的实心行数编码缩放因子→缩放因子决定模板复制品的大小→梳状结构的水平位置决定放置列→梳状结构的颜色决定复制品的颜色。解码、缩放、定位、涂色四步全部依赖梳状结构的不同属性。

读取梳状结构的高度作为缩放因子，将模板精灵按此因子放大后放置在梳状结构的水平位置上，并涂为梳状结构的颜色。

**输入结构**：黑(0)背景约 20x20 网格。网格底部有一条完整宽度的灰(5)水平分隔条（1 像素厚）。分隔条上方有 2~4 个梳状结构，每个梳状结构占 3 列宽，由交替的"两侧像素行"和"实心三像素行"垂直堆叠而成，颜色各异（从红(2)、绿(3)、蓝(1)、黄(4)中取），底部对齐到分隔条。每个梳状结构的实心行数为 1~4，编码一个数值。梳状结构之间水平间距不等。分隔条下方左侧有一个小型单色模板精灵（品红(6)，约 2x2~3x3 像素，形状为 4-连通不规则图形）。生成约束：各梳状结构的实心行数互不相同；模板精灵的宽高均不超过 3 像素。

**规则**：
1. 识别灰(5)分隔条上方的每个梳状结构。每个梳状结构的"实心三像素行"数量即为该梳的编码数值 K。
2. 在分隔条下方找到品红(6)模板精灵，裁剪其最小边界框。
3. 对每个梳状结构：将模板精灵按因子 K 做像素级放大（每个像素变为 KxK 方块），得到放大后的模板。
4. 将放大后的模板涂为该梳状结构的颜色，放置到输出网格中：模板的水平中心与梳状结构的中心列对齐，模板的顶边紧贴分隔条下方。
5. 擦除原始梳状结构和原始模板精灵（置为黑(0)）。保留灰(5)分隔条。若多个放大模板在水平方向重叠，后处理的（即编码数值更大的）覆盖先处理的。

**关键洞察**：缩放因子不是一个全局常数，而是每个梳状结构独立编码的局部值——必须对比多个梳状结构在同一示例中产生的不同大小模板，才能确认"高度=缩放因子"的对应关系。

## 新题 4：种子分区镜像翻折

**组合逻辑**：[最近扩散→行分区](已有) + [镜像](创新：镜像轴不是预设的框架线，而是每个分区的种子条本身) + [等距异色为分隔](已有，但分隔行的处理从填单色变为填充混合标记)

**来源原语**：最近扩散、种子条、最近种子分区、等距异色为分隔(332202d5)；镜像、对称轴关系、框架为对称轴(f8a8fe49)；填充(93b581b8)

**依赖链**：种子条的位置决定最近分区→分区边界决定每段区域的范围→种子条同时充当该分区内内容的镜像轴→分区边界处等距于两个不同色种子的行需要特殊处理。分区与镜像通过种子条的双重角色（分区种子 + 对称轴）紧密耦合。

以彩色种子条为中心做最近分区，再在每个分区内将种子条一侧的图案镜像翻折到另一侧，等距异色边界行填为分隔色。

**输入结构**：黑(0)背景约 15x20 网格（高大于宽）。网格中有 2~3 条完整宽度的水平种子条，每条 1 像素厚，颜色互不相同（从红(2)、蓝(1)、绿(3)中取）。在每条种子条的上方紧邻区域（1~3 行），散布着若干橙(7)像素构成的小型不规则图案（4-连通，3~6 像素），这些图案只出现在种子条上方，种子条下方为纯黑(0)。种子条之间的间距不等（4~8 行）。生成约束：图案不跨越种子条；各种子条颜色互不相同。

**规则**：
1. 识别所有水平种子条及其颜色，按行位置排列。
2. 按最近种子条原则将所有非种子行分区：每一行归属于最近的种子条。
3. 对每个分区：找到该分区内种子条上方的橙(7)图案，以种子条所在行为镜像轴，将图案翻折到种子条下方对应位置（镜像复制）。原始图案保留不动。
4. 若某行到两条种子条的距离相等，且两条种子条颜色不同，则该行整行填充为灰(5)作为分隔行。
5. 若某行到两条种子条的距离相等，但两条种子条颜色相同（本题中不会发生，但规则需完备），则该行归属于上方的种子条。

**关键洞察**：种子条同时扮演两个角色——分区种子和镜像轴。仅看单个示例中一个种子条的行为，可能以为是简单的镜像；必须对比多个种子条的分区边界，才能归纳出"最近种子"分区规则以及等距异色行的分隔处理。

## 新题 5：框架交叉条纹网格

**组合逻辑**：[颜色匹配配对→标记交叉定位](已有) → [条纹传播](创新：条纹不从边界线段出发，而从框架内部的交叉点出发) + [颜色循环](已有) + [重叠区域重涂](创新：重叠的判断依据从模板副本重叠变为条纹交叉，重涂色由交叉点的标记数量决定)

**来源原语**：标记交叉定位、颜色匹配配对、框架标记(247ef758)；条纹传播、颜色循环、条纹范围差异(221dfab4)；重叠区域重涂(a395ee82)；计数(27a77e38)

**依赖链**：框架边缘标记的颜色配对确定交叉点位置→从交叉点向四个方向传播条纹→条纹使用颜色循环→两条或多条条纹在同一像素相交时，取拥有更多交叉点的那个颜色的条纹。标记配对、条纹传播、交叉冲突解决三步环环相扣。

在矩形框架上通过同色标记的行列交叉定位种子点，从种子点向四方传播颜色循环条纹，条纹交叉处取标记数量更多的颜色。

**输入结构**：黑(0)背景约 16x16 网格。灰(5)单像素线围成一个矩形框架（边距约 2~3 像素到网格边缘）。框架的上/下水平边和左/右垂直边上各有若干单像素标记，标记颜色取自红(2)和蓝(1)。同色标记在行（水平边上的标记对应行号）和列（垂直边上的标记对应列号）上的笛卡尔积定义框架内部的交叉点。框架内部初始为黑(0)。生成约束：红(2)标记在水平边和垂直边上各至少 1 个、至多 3 个；蓝(1)同理；两色标记产生的交叉点集互不重叠。

**规则**：
1. 对每种标记颜色 C（红(2)或蓝(1)），收集水平边上颜色为 C 的标记行号集合 R_C 和垂直边上颜色为 C 的标记列号集合 Col_C。交叉点集 = R_C x Col_C。
2. 从每个交叉点出发，沿上、下、左、右四个方向每隔 1 像素（即步长 2）画一个条纹像素，颜色为该交叉点的颜色 C，直到遇到框架边或已有的同色条纹。条纹像素之间的间隔像素保持黑(0)。
3. 若某像素同时被红(2)和蓝(1)的条纹覆盖（交叉冲突），取交叉点数量更多的颜色（即 |R_C x Col_C| 更大的颜色）。若两色交叉点数量相等，取红(2)。
4. 框架边和标记像素保持不变。框架外部保持黑(0)。

**关键洞察**：条纹的冲突解决不取决于哪条条纹先画或像素的空间位置，而取决于产生该条纹的颜色在全局拥有多少个交叉点——这是一个需要全局计数才能确定的隐蔽规则，仅看局部条纹无法推断。

## 新题 6：拉丁方对角约束补全

**组合逻辑**：[补全 + 拉丁方约束](已有) × [对角映射 + 标记块](创新：标记块不再直接提供填充色，而是为对角象限的拉丁方补全提供锚定约束——标记色指定哪个颜色在对角象限中已正确放置) → [行列唯一约束](已有，但作用范围从全局变为象限内)

**来源原语**：补全、拉丁方约束、行列唯一约束、色表(4cd1b7b2)；对角映射、标记块、象限区域、标记色填对角区(93b581b8)

**依赖链**：标记块的每个单元格颜色→通过对角映射指向对面象限→该颜色在对面象限中的已有位置不可移动（锚定）→象限内拉丁方补全必须在锚定约束下进行。标记块、对角映射、拉丁方补全三者形成不可分割的约束网络。

中央标记块通过对角映射为每个象限的拉丁方补全提供锚定色约束，补全时须同时满足行列唯一和锚定不可移动。

**输入结构**：约 11x11 网格（奇数边长）。网格正中央有一个 2x2 标记块，四格颜色各异，取自红(2)、蓝(1)、绿(3)、黄(4)。以标记块为中心，网格被分为四个象限（左上、右上、左下、右下），每个象限为一个 (n-1)/2 边长的正方形区域（约 4x4 或 5x5）。每个象限是一个部分填充的颜色网格：使用恰好 n 种颜色（等于象限边长，4 或 5 种），部分格子已填色，部分为黑(0)（表示空白待补全）。已填色格子满足行列无重复约束。生成约束：每个象限的拉丁方补全在锚定约束下有唯一解。

**规则**：
1. 识别中央 2x2 标记块及其四个单元格的颜色。
2. 对角映射：标记块左上格颜色 → 约束右下象限；标记块右上格颜色 → 约束左下象限；标记块左下格颜色 → 约束右上象限；标记块右下格颜色 → 约束左上象限。
3. 每个象限收到一个"锚定色"。在该象限中，所有已填入该锚定色的格子位置不可更改（这些位置是确定正确的参考点）。
4. 对每个象限，在锚定约束下完成拉丁方补全：每行每列恰好包含所有使用颜色各一次，黑(0)空白格被唯一确定地填入正确颜色。
5. 标记块本身保持不变。

**关键洞察**：标记块不是颜色图例（不直接告诉填什么色），而是通过对角映射远程指定哪些已有信息是可信锚点——必须对比多个象限的补全结果才能发现"对角映射锚定"这一隐蔽约束，否则可能误以为所有已填色格子都是锚点（实际上非锚定色的已填格子在某些示例中可能有多种补全方式，但锚定约束排除了歧义）。

## 新题 7：边缘字形路径描绘

**组合逻辑**：[解码 + 字形 + 顺序排列](已有，但字形不再编码管道方向，而是编码平移向量) → [平移](创新：平移对象从边缘带变为网格内精灵体，且为累积平移) → [连线](创新：轨迹不是射线而是逐步位移的路径，每段颜色由对应字形决定) + [擦除](已有)

**来源原语**：解码、字形、顺序排列、弯头决定偏移(e6de6e8f)；平移、边缘带、擦除(d255d7a7)；连线(b527c5c6)；重涂色(673ef223)

**依赖链**：字形的像素形状编码移动方向→字形的左右顺序决定执行序列→精灵体从当前位置按指令平移→每步留下该字形颜色的轨迹→前一步的终点位置是后一步的起点。路径是累积的，任何一步的解码错误都会导致后续所有步骤位置偏移。

将边缘字形条中的字形按序解码为移动指令，驱动网格内精灵体逐步平移并留下彩色轨迹。

**输入结构**：黑(0)背景约 15x15 网格。网格最左列为一列宽的灰(5)分隔条。分隔条左侧无内容（分隔条在第 0 列）。网格顶部两行（第 0~1 行）为字形条：包含 3~5 个字形，每个字形占 2 行 x 2 列，字形之间紧邻排列（无间隔），从左到右依次排列。每个字形由单色像素在 2x2 区域内构成 L 形图案（3 个像素亮、1 个像素黑(0)），每个字形颜色不同（从红(2)、蓝(1)、绿(3)、黄(4)、品红(6)中取）。L 形中缺失像素的位置编码移动方向：左上缺→向右下移动、右上缺→向左下移动、左下缺→向右上移动、右下缺→向左上移动（缺失角的对角方向）。在网格中部偏下位置有一个橙(7)起点标记（单像素）。生成约束：按字形序列移动后，精灵体始终不会离开网格边界；每步移动距离为 2 像素（对角方向即行列各移动 2）。

**规则**：
1. 在顶部两行中，按从左到右的顺序识别每个 2x2 字形及其颜色。
2. 对每个字形，检查其 2x2 区域中黑(0)像素的位置（左上/右上/左下/右下），确定移动方向为该位置的对角方向。
3. 从橙(7)起点标记开始，按字形顺序依次执行移动：每步沿指定对角方向移动 2 像素（行 +/-2，列 +/-2）。
4. 每步移动的路径（起点到终点之间的 2 个像素，包括终点但不包括起点）涂为该字形的颜色。若路径像素已有颜色，后画的覆盖先画的。
5. 擦除顶部两行的字形条（置为黑(0)）。起点标记橙(7)保留。

**关键洞察**：字形中缺失像素的位置与移动方向之间的映射关系（缺失角→对角方向移动）是隐蔽规则，单个字形的效果可能恰好与其他假设（如"朝缺失方向移动"）吻合，必须对比多个字形的效果才能排除错误假设。

## 新题 8：射线碰撞计数涂色

**组合逻辑**：[射线延伸](已有) + [计数](创新：计数对象不是颜色频率，而是"射线到达边界的方向数") → [重涂色 + 颜色循环](创新：颜色循环的索引不由嵌套层序决定，而由射线碰撞计数决定)

**来源原语**：射线延伸、中心向外辐射、罗盘方向(1d398264)；计数(27a77e38, 469497ad)；重涂色、颜色循环(221dfab4, bda2d7a6)

**依赖链**：每个方块的四方向射线是否被其他方块阻挡取决于所有方块的全局布局→阻挡统计产生每个方块的"自由度"计数→计数索引到颜色循环表决定输出色。任何一个方块的移除或增加都会改变其他方块的射线结果，形成全局耦合。

从每个色块中心向四个基本方向射出射线，统计未被其他色块阻挡而到达网格边界的方向数，按此计数通过颜色循环表重涂每个色块。

**输入结构**：黑(0)背景约 13x13 网格。散布 4~7 个单色实心方块，每个方块为 2x2 像素，全部为灰(5)。方块之间不相邻（任意两个方块之间至少间隔 1 像素）。方块分布使得不同方块有不同的"自由方向数"（0~4 的某个子集）。生成约束：至少存在 3 种不同的自由方向数值，以便求解者归纳颜色映射。

**规则**：
1. 对每个 2x2 灰(5)方块，从其中心（四格交汇点）向上、下、左、右四个方向各射一条虚拟射线。
2. 每条射线沿该方向检查：若到达网格边界前未碰到任何其他方块的像素，则该方向计为"自由"；若碰到其他方块的像素（包括仅触碰角），则该方向计为"阻挡"。
3. 统计每个方块的自由方向数 F（0~4）。
4. 按以下颜色映射重涂该方块：F=0→红(2)，F=1→蓝(1)，F=2→绿(3)，F=3→黄(4)，F=4→品红(6)。此映射为隐蔽规则，需从示例中归纳。
5. 方块形状和位置不变，仅颜色改变。背景保持黑(0)。

**关键洞察**：每个方块的输出颜色取决于全局布局中其他方块对它的遮挡关系，而非方块自身的任何局部属性——必须分析多个不同布局的示例才能确认"自由方向数→颜色"的映射表，且在同一示例内各方块的结果互相印证。

## 新题 9：稀疏精灵对称稠密补全

**组合逻辑**：[稠密化](已有) → [补全](创新：补全规则不是拉丁方约束，而是轴对称补全，且对称轴方向需从稠密化后的形状推断) + [轴对称](创新：对称轴不由框架线给定，而由精灵自身的几何属性隐式决定) → [加厚](已有)

**来源原语**：稠密化、稀疏精灵体、加厚(db615bd4)；补全、轴对称、对称轴关系(f8a8fe49)；填充(e73095fd)

**依赖链**：稀疏精灵体先稠密化才能确定真实边界框→边界框的长宽比决定对称轴方向→对称补全依赖正确的轴方向→加厚依赖补全后的完整形状。跳过稠密化则边界框错误，跳过补全则加厚形状不完整。

将稀疏精灵体稠密化后，根据边界框长宽比推断对称轴方向并补全为对称图形，最后向外加厚一像素。

**输入结构**：黑(0)背景约 16x16 网格。散布 2~4 个稀疏精灵体，每个精灵体的像素落在步长为 2 的栅格上（即像素行列坐标均为偶数或均为奇数），颜色各异（从红(2)、蓝(1)、绿(3)、黄(4)中取）。每个稀疏精灵体是某个对称图形的左半部分或上半部分（含对称轴上的像素）。精灵体之间不重叠且边界框不相交。生成约束：稠密化后（填充栅格间隙），每个精灵体的边界框要么宽 > 高（此时是左半部分，需向右镜像），要么高 > 宽（此时是上半部分，需向下镜像）；不出现宽 = 高的情况。加厚后的图形之间不重叠。

**规则**：
1. 对每个稀疏精灵体，进行稠密化：将栅格间隙中的黑(0)像素填充为该精灵体的颜色，使其变为连续实心区域。稠密化范围为该精灵体像素的最小边界框内所有像素。
2. 计算稠密化后精灵体的边界框宽 W 和高 H。
3. 若 W > H：精灵体是左半部分，以边界框右边缘为对称轴，将内容向右镜像补全。补全后宽度变为 2W - 1（对称轴列共享）。
4. 若 H > W：精灵体是上半部分，以边界框下边缘为对称轴，将内容向下镜像补全。补全后高度变为 2H - 1（对称轴行共享）。
5. 对补全后的每个精灵体，向外加厚 1 像素：在其所有 4-邻接的黑(0)像素上涂该精灵体颜色。
6. 各精灵体独立处理，互不影响。背景保持黑(0)。

**关键洞察**：对称轴方向不是固定的，而是由稠密化之后的边界框长宽比隐式决定的——这意味着必须先正确完成稠密化才能推断补全方向，且同一示例中不同精灵体可能有不同的对称轴方向，需要对比才能归纳出"宽>高→左半、高>宽→上半"的规则。

## 新题 10：框内裁剪计数排序拼接

**组合逻辑**：[裁剪](已有) + [计数](创新：计数对象不是全局色数，而是每个框内图案的非背景像素数) → [排序](已有，但排序键从梳状高度变为像素计数) → [拼接](已有，但拼接方向和间隔由框架线颜色决定)

**来源原语**：裁剪、框架线、内部图案(f8a8fe49)；计数(27a77e38, a1aa0c1e)；排序、压缩(a1aa0c1e)；拼接、画布加倍(c9e6f938)；位置顺序(db615bd4)

**依赖链**：框架线界定裁剪范围→裁剪出的图案进行像素计数→计数值决定排列顺序→排序后的图案拼接成新画布。计数依赖裁剪结果，排序依赖计数结果，拼接依赖排序结果——四步不可跳过。

识别网格中的多个矩形框，裁剪各框内图案，按非背景像素数排序后水平拼接。

**输入结构**：黑(0)背景约 18x12 网格（宽大于高）。网格中有 3~5 个灰(5)矩形框（一像素厚边框），大小不一（内部 3x3~5x5），框之间不重叠、不相邻。每个框内有用不同颜色绘制的小图案（4-连通，2~8 个非黑像素），颜色取自红(2)、蓝(1)、绿(3)、黄(4)、品红(6)（每个框内图案单色，不同框图案颜色可以相同）。生成约束：各框内非背景像素数互不相同（确保排序无平局）。

**规则**：
1. 识别所有灰(5)矩形框。
2. 对每个框，裁剪其内部区域（不含灰(5)边框），得到一个子网格。
3. 统计每个子网格中的非黑(0)像素数量。
4. 按像素数量从小到大排列所有子网格。
5. 构建输出网格：将排序后的子网格从左到右水平拼接，相邻子网格之间插入 1 列宽的灰(5)分隔列。输出网格的高度等于所有子网格中最大的高度，较矮的子网格垂直居中放置（上下补黑(0)），若无法精确居中则偏上。
6. 输出网格不含原始灰(5)边框（边框在裁剪时已去除，仅分隔列为灰(5)）。

**关键洞察**：排序的键不是框的位置、大小或颜色，而是框内图案的非背景像素数量——这一规则需要对比多个示例中框的顺序变化才能确认，尤其当框的空间位置顺序与像素数量顺序不一致时才能排除"按位置排序"的错误假设。
