## 新题 1：射线铸造开门与最短走廊连通

**组合逻辑**：[射线延伸](创新：射线命中处不是印标记，而是擦除墙壁形成门洞) → [擦除](创新：擦除对象由射线命中位置动态决定) → [连线/最小生成树](已有原语，但连通路径受限于动态生成的门洞)

**来源原语**：射线延伸(ray_extend) + 命中处印标记(stamp_at_hit) 来自 ecdecbb3；擦除(erase) + 空心矩形(hollow_rectangle) + 走廊(corridor) + 最小生成树连接(min_spanning_tree) 来自 b9630600；控制像素(control_pixel) + 投射(perpendicular_cast) 来自 ecdecbb3

**依赖链**：控制像素的射线投射决定了门洞在哪面墙上打开 → 门洞的存在约束了走廊的可用连接点 → 最小生成树在受限门洞上规划连通网络。删除射线步骤则门洞位置未知；删除连通步骤则门洞无意义。

从控制像素出发铸造射线，在命中的空心矩形墙壁上开出门洞，再通过这些门洞用最短走廊将所有矩形连成一棵生成树。

**输入结构**：约 22x22 的网格，背景为黑(0)。网格中有 4~5 个蓝(1) 一像素厚的空心矩形框，每个框的外边长在 4~7 像素之间，框与框之间至少间隔 3 个背景像素，互不接触。每个矩形框的某一条外壁的外侧（紧邻墙壁外一格）有恰好一个红(2)控制像素。每个控制像素仅紧邻一条墙壁（位于该墙壁的正交外侧）。生成约束：每个控制像素沿其朝外方向（垂直于所邻墙壁、远离所属框的方向）投射射线时，必定命中另一个矩形框的墙壁（不会射到网格边缘外或自身框体）。

**规则**：
1. 对每个红(2)控制像素，确定其紧邻的蓝(1)墙壁段及朝外方向（垂直于该墙壁、背离所属框的方向）。
2. 沿朝外方向逐格投射射线，直到命中另一个蓝(1)矩形框的墙壁像素。射线经过的背景像素暂不改变。
3. 在命中墙壁上，以命中点为中心擦除连续 3 个墙壁像素（将其变为黑(0)背景），形成一个 3 像素宽的门洞。若命中点距墙壁端点不足 1 格导致无法居中放置 3 像素门洞，则门洞向墙壁内侧偏移至刚好放下 3 像素。
4. 擦除该红(2)控制像素（变为黑(0)）。
5. 所有门洞开完后，将所有矩形框视为节点，两框之间的距离定义为"经由它们之间的门洞所需走廊长度"（门洞中心到门洞中心的曼哈顿距离）。仅当两框之间存在直接门洞对（一个框被射线开门、该射线来自另一个框的控制像素）时，才算有直接连边。
6. 在这些直接连边上选择最小生成树（若权重相同则优先选择连边中门洞中心行坐标较小的，仍相同则选列坐标较小的）。
7. 对最小生成树的每条边，沿两个门洞中心之间的正交路径绘制绿(3)走廊像素（先水平后垂直），走廊经过门洞本身时也涂绿(3)。走廊不覆盖蓝(1)墙壁像素。

**关键洞察**：门洞不是预设的，而是由射线动态铸造在其他框的墙壁上；走廊的可行拓扑完全由射线几何决定，必须先完成射线计算才能规划连通。

## 新题 2：直线遮挡层次决定围合区域填充色

**组合逻辑**：[层序推断](已有原语) + [洪水填充](创新：填充颜色不由轮廓色决定，而由围合边界线的遮挡层级最低者决定)

**来源原语**：排序(sort) + 层序推断(layer_infer) + 直线(straight_line) + 交叉点(crossing_point) + 遮挡层次(occlusion_order) + 唯一序链(unique_chain) 来自 22425bda；洪水填充(flood_fill) + 封闭背景区域(enclosed_bg_region) + 轮廓围合(contour_enclosure) + 小区域被填充(small_regions_filled) 来自 753ea09b

**依赖链**：多条彩色直线交叉形成可见遮挡 → 从交叉点的可见颜色推断唯一的底-到-顶层序 → 直线将背景分割成区域 → 每个封闭区域（不触边）的填充色取其边界线中层序最低（最底层）的那条线的颜色。删除遮挡推断则无法确定填充颜色；删除区域识别则遮挡序无用。

**输入结构**：约 15x15 的网格，背景为黑(0)。网格中有 4 条不同颜色的一像素厚完整直线，颜色分别为蓝(1)、红(2)、绿(3)、黄(4)。每条直线贯穿整个网格（水平、垂直或 45 度对角线），且每两条线至少有一个交叉点。在交叉点处，较高层的线遮挡较低层的线（即该像素显示较高层线的颜色）。4 条线的遮挡层序唯一（存在唯一的从底到顶的全序排列，且相邻层级的线在几何上相交）。生成约束：4 条线的交叉点足够多，使得遮挡层序可从可见颜色唯一确定；直线将网格分割出至少 2 个不触边的封闭背景区域。

**规则**：
1. 识别每条完整直线（从可见的共线同色像素集合恢复出完整直线，包括被遮挡的像素）。
2. 在每个交叉点，可见颜色属于层序更高的那条线。据此推断所有线的唯一底-到-顶层序。
3. 将所有直线像素视为障碍，对背景做 4-连通区域划分。
4. 对每个不接触网格边缘的封闭背景区域：找出所有与该区域 4-邻接的直线像素所属的线，取其中层序最低（最底层）的线的颜色，用该颜色填充该区域的所有背景像素。
5. 接触网格边缘的背景区域保持黑(0)不变。所有直线像素保持原色不变（包括交叉点处的可见色）。

**关键洞察**：填充色不是简单地取边界色或最多色，而是取遮挡层序中最底层的边界线颜色——这要求求解者先从交叉点可见性推断全局层序，再将该层序应用于空间填充决策。

## 新题 3：碎片互补拼合生成模板，变换匹配后印章覆盖

**组合逻辑**：[移动/互补拼合](已有原语) → [旋转/镜像 + 模式匹配](创新：匹配对象不是预设的源精灵体标记掩码，而是拼合后才出现的完整图案) → [印章覆盖](创新：印章内容由拼合结果动态生成)

**来源原语**：移动(move) + 互补拼合(complement_fit) + 碎片(fragment) + 锚定物体(anchor_object) + 碎片触边锚不触边(frag_edge_anchor) 来自 fe45cba4；旋转(rotate) + 镜像(mirror) + 模式匹配(pattern_match) + 掩码变换匹配则补(transform_match_fill) 来自 7df24a62；印章覆盖(stamp_overlay) 来自 f21745ec/ecdecbb3

**依赖链**：两个同色碎片必须先拼合成完整矩形 → 拼合后的矩形图案成为印章模板 → 网格其他位置的标记像素群如果与模板的某个旋转/镜像变换的非背景像素位置完全吻合，则在该位置盖章（用模板的填充色填充对应的背景位置）。删除拼合步骤则模板未知；删除匹配步骤则不知道往哪里盖章。

从左边缘碎片移动到锚定碎片处完成矩形拼合，拼合后的矩形图案作为印章模板，在网格中寻找与模板某个刚体变换的标记掩码匹配的位置并盖章填充。

**输入结构**：约 20x20 的网格，背景为黑(0)。网格中有一组蓝(1)像素分成两个 4-连通物体：一个触及左边缘（碎片），一个不触左边缘（锚定物体），二者可通过平移互补拼合成一个实心矩形（约 3x4 至 4x5 大小）。该矩形内部分布着若干红(2)标记像素（嵌在蓝(1)填充色中，占矩形面积的 20%~40%），这些标记像素构成一个不对称图案（在 8 种刚体变换下互不相同）。此外，网格其他区域（远离碎片和锚定物体）散布着 2~3 组红(2)像素群，每组恰好是矩形模板中红(2)标记掩码的某个刚体变换副本（旋转 0/90/180/270 度或镜像后的某一种），且对应矩形范围内的其余位置全为黑(0)背景。还有 1~2 个孤立的红(2)干扰像素不构成任何完整的变换匹配。生成约束：各标记群互不重叠，且与碎片/锚定物体不重叠。

**规则**：
1. 找到蓝(1)颜色的两个 4-连通物体，其中触左边缘的为碎片，不触左边缘的为锚定物体。
2. 将碎片水平平移至与锚定物体互补拼合形成一个填满蓝(1)的实心矩形。清除碎片原位置像素为黑(0)。
3. 记录拼合后矩形中红(2)标记像素的相对位置，作为模板标记掩码。
4. 枚举模板标记掩码的全部 8 种刚体变换（4 种旋转 x 是否水平镜像）。
5. 在网格中搜索所有候选位置：某个变换后的标记掩码恰好覆盖一组红(2)像素，且对应矩形范围内的其余位置全为黑(0)背景。
6. 对每个匹配位置，将对应矩形范围内的黑(0)背景像素涂为蓝(1)（即用填充色补齐矩形），保留红(2)标记像素不变。
7. 不匹配任何变换的孤立红(2)像素保持不变。

**关键洞察**：印章的模板不是直接给出的，而是通过碎片互补拼合才"合成"出来的——求解者必须先完成空间拼合才能获得匹配模式。

## 新题 4：颜色计数控制射线长度，射线轨迹形成轮廓围合

**组合逻辑**：[计数](已有原语) → [射线延伸](创新：射线不延伸到命中障碍物为止，而是延伸固定步数，步数由计数结果决定) → [洪水填充](创新：填充区域由射线轨迹围合而成，非预设轮廓)

**来源原语**：计数(counting) + 多色方块(multicolor_square) + 颜色数决定高度(color_count_height) 来自 fcc82909；射线延伸(ray_extend) + 控制像素(control_pixel) + 投射(perpendicular_cast) 来自 ecdecbb3；洪水填充(flood_fill) + 封闭背景区域(enclosed_bg_region) + 轮廓围合(contour_enclosure) + 小区域被填充(small_regions_filled) 来自 753ea09b

**依赖链**：多色方块中不同颜色的数量 → 决定从相邻控制像素射出的射线长度 → 射线轨迹在网格上绘制线段 → 多条线段围合出封闭区域 → 封闭区域被填充。删除计数步骤则射线长度未知；删除射线步骤则无围合轮廓；删除填充步骤则射线无用途。

从多色方块中计数不同颜色得到数值，该数值控制从相邻控制像素射出的十字射线长度，射线轨迹围合出的封闭区域被填充为方块中面积最大的颜色。

**输入结构**：约 20x20 的网格，背景为黑(0)。网格中有 3~4 个 2x2 的多色方块，每个方块由 2~4 种非黑颜色填充（颜色取自蓝(1)、红(2)、绿(3)、黄(4)中的若干种）。每个方块的 4-邻域外侧（上下左右各一格）恰好有一个灰(5)控制像素，且该控制像素不与其他方块或控制像素相邻。多色方块之间间距至少 6 个像素。生成约束：每个控制像素沿其四个正交方向中远离所属方块的那个方向，按计数结果的步数延伸射线后，至少有两个不同方块的射线轨迹会在某处构成闭合区域（多段射线首尾相连或交叉围合）。

**规则**：
1. 对每个 2x2 多色方块，计数其中不同非黑颜色的种数 K（K 在 2~4 之间）。
2. 找到该方块 4-邻域外的灰(5)控制像素，确定其远离方块的方向 D。
3. 从控制像素出发，沿方向 D 绘制恰好 K 个像素长的橙(7)射线段（包括控制像素位置本身变为橙(7)，再沿 D 方向延伸 K-1 格，共 K 格橙色）。若射线超出网格则在边缘截断。
4. 所有射线绘制完成后，将橙(7)射线像素视为障碍，对黑(0)背景做 4-连通区域划分。
5. 对每个不接触网格边缘的封闭背景区域：该区域被填充为品红(6)。
6. 多色方块、橙(7)射线段均保持不变。接触网格边缘的背景区域保持黑(0)。

**关键洞察**：射线长度不是固定的也不是延伸到碰撞，而是由关联方块的颜色多样性编码——颜色越多射线越长，围合面积越大。求解者必须先完成计数才能确定几何形状。

## 新题 5：标记滑动轨迹形成条纹种子，条纹周期由滑动距离决定

**组合逻辑**：[滑动](创新：滑动不只是移动一步，而是移动到目标位置，沿途留下轨迹) → [平铺/条纹填充](创新：轨迹的方向和长度成为条纹的方向和周期参数)

**来源原语**：滑动(slide) + 标记像素(marker_pixel) + 目标像素(target_pixel) + 共线对齐(collinear_aligned) + 趋近目标(approach_target) 来自 dc433765；平铺(tiling) + 填充(fill) + 种子像素(seed_pixel) + 条纹(stripe) + 种子定条纹周期(seed_sets_stripe_period) + 阵列排布(array_layout) 来自 0a938d79

**依赖链**：标记像素沿共线方向滑动到目标像素 → 滑动路径成为一条有色线段（轨迹种子） → 轨迹方向决定条纹方向（正交于轨迹） → 轨迹长度（滑动距离）决定条纹重复周期 → 用标记色和目标色交替填充条纹。删除滑动步骤则条纹参数未知；删除条纹步骤则滑动无后续效果。

每对标记-目标像素产生一条滑动轨迹，轨迹方向的正交方向上按滑动距离为周期绘制双色交替条纹，覆盖整个网格对应区域。

**输入结构**：约 16x16 的网格，背景为黑(0)。网格中有 2 对标记-目标像素对。第一对：绿(3)标记和黄(4)目标，位于同一行（水平共线），间隔 3~5 个像素。第二对：蓝(1)标记和红(2)目标，位于同一列（垂直共线），间隔 3~5 个像素。两对像素的行列范围不重叠（第一对占据网格上半部分，第二对占据网格下半部分），由一条灰(5)水平分隔线（贯穿整行）隔开。生成约束：两对像素分别在分隔线上方和下方；每对的标记和目标间隔不同（确保两组条纹周期不同）。

**规则**：
1. 对每一对标记-目标像素，将标记像素沿共线方向滑动到目标像素的相邻位置（距目标 1 格处停止），沿途所有经过的背景像素涂为标记颜色，形成轨迹线段。原标记位置也保留标记颜色。
2. 计算滑动距离 D（标记原位置到停止位置的像素数，含端点）。
3. 在该对所属的半区（分隔线上方或下方的所有行/列）中，沿垂直于轨迹方向每隔 D 个像素绘制一条贯穿该半区的完整条纹。条纹交替使用标记颜色和目标颜色：第一条（轨迹所在行/列）为标记颜色，距离 D 的下一条为目标颜色，再距离 D 为标记颜色，依此交替。
4. 条纹覆盖对应半区内的所有黑(0)背景像素。若条纹与轨迹线段重叠，保留轨迹线段颜色（标记颜色优先）。
5. 灰(5)分隔线、目标像素保持原色不变。

**关键洞察**：条纹的周期不是由两个种子的空间间距直接给出的（源题做法），而是由标记滑向目标后实际走过的步数决定——必须先模拟滑动才能知道周期。

## 新题 6：十字周期延伸构建栅栏墙，墙中缺口由尺寸匹配的空心框标定

**组合逻辑**：[平铺/周期延伸](已有原语，但创新：延伸结果形成功能性墙壁) + [尺寸匹配](创新：匹配对象从矩形框变为墙壁间距) → [路径绘制](已有原语，但路径受动态生成的墙壁和缺口约束)

**来源原语**：平铺(tile) + 十字图案(cross_pattern) + 周期序列(periodic_sequence) + 中心行列种子(center_seed) + 周期性延伸(periodic_extension) 来自 e21d9049；尺寸匹配(size_match) + 空心矩形(hollow_rect) 来自 f21745ec；寻路(pathfinding) + 路径绘制(path_drawing) + 门段(door_segment) + 穿越门中心(through_door_center) + 走廊正交路径(corridor_ortho_path) 来自 7e576d6e

**依赖链**：十字图案周期延伸后，其中心行和中心列的重复形成平行的水平和垂直色带（即栅栏墙壁） → 散布的空心矩形框的内部宽度或高度恰好与相邻两面墙壁间距匹配 → 匹配墙壁上框所在的列/行位置出现缺口（门洞） → 从起点到终点的正交路径必须穿过这些门洞。删除周期延伸则墙壁不存在；删除尺寸匹配则不知道哪些框标定门洞；删除寻路则结构无意义。

十字图案周期延伸形成平行栅栏墙壁，空心矩形框按尺寸匹配标定墙壁上的门洞位置，然后绘制从起点到终点穿越所有门洞的正交路径。

**输入结构**：约 21x21 的网格，背景为黑(0)。网格中央有一个由多色像素（蓝(1)和红(2)交替）组成的十字图案（约 5x5 像素，中心行全蓝(1)、中心列全红(2)、交叉中心为蓝(1)），其中心行和中心列各有一个明确的颜色序列。网格中另有 3~4 个黄(4)一像素厚空心矩形框（内部宽度或高度各不相同，范围 2~5 像素）。网格左上角有一个绿(3)起点像素，右下角有一个绿(3)终点像素。生成约束：十字图案周期延伸后形成的蓝(1)水平色带和红(2)垂直色带恰好产生若干平行墙壁段；空心矩形框中内部高度与相邻水平墙壁间距相等的框标定垂直墙壁门洞位置，内部宽度与相邻垂直墙壁间距相等的框标定水平墙壁门洞位置；至少存在一条从起点到终点穿越所有必要门洞的正交路径。

**规则**：
1. 裁剪十字图案，找到其中心行序列和中心列序列。
2. 将中心行序列沿水平方向周期重复、沿垂直方向在中心行的周期位置复制，形成水平色带（蓝(1)全行条纹）。同理将中心列序列形成垂直色带（红(2)全列条纹）。这些色带叠加到输出网格上（交叉处蓝(1)覆盖红(2)）。
3. 对每个黄(4)空心矩形框：计算其内部高度 H 和内部宽度 W。
   - 若 H 等于某对相邻水平色带之间的间距，则该框标定一个垂直色带上的门洞：在距框的列坐标中心最近的垂直色带上，擦除与该框同行范围的色带像素（形成 H 像素高的门洞）。
   - 若 W 等于某对相邻垂直色带之间的间距，则该框标定一个水平色带上的门洞：在距框的行坐标中心最近的水平色带上，擦除与该框同列范围的色带像素（形成 W 像素宽的门洞）。
4. 擦除所有黄(4)框像素（变为黑(0)）。
5. 从绿(3)起点到绿(3)终点，沿正交方向（先水平再垂直交替转弯）穿过每面墙壁的门洞中心，绘制橙(7)路径像素。路径在每个走廊（两面墙壁之间的区域）中走直线到下一面墙的门洞中心。起点和终点保持绿(3)。

**关键洞察**：墙壁是由十字图案的周期延伸"生长"出来的，而门洞位置则由空心框的内部尺寸与墙壁间距的匹配关系编码——求解者必须同时理解周期结构和尺寸匹配才能定位门洞。

## 新题 7：边缘源连线在分隔表格中穿行，交叉单元格被重涂色

**组合逻辑**：[连线/路径绘制](已有原语) + [重涂色](创新：重涂色的触发条件不是标记对齐，而是路径是否穿过表格单元格) ← [同色配对](已有原语，决定连线端点) + [分隔线网格](已有原语，提供表格结构)

**来源原语**：连线(line_drawing) + 路径绘制(path_drawing) + 边缘源像素(edge_source_pixel) + 同色端点(same_color_endpoint) + 同色配对(same_color_matching) + 有端点则转弯(endpoint_triggers_turn) 来自 29700607；重涂色(recolor) + 分隔线网格(separator_grid) + 掩码区域(mask_region) + 行列对齐(row_col_align) + 对齐标记定颜色(aligned_marker_color) 来自 ef26cbf6

**依赖链**：顶边源像素与同色端点配对 → 从顶边垂直向下画线、在端点行转弯水平连接 → 路径穿过分隔线网格的若干单元格 → 被路径穿过的单元格中的灰(5)掩码像素被重涂为该路径的颜色。同色配对决定了路径走向，路径走向决定了哪些单元格被重涂——两个逻辑通过空间穿越耦合。

顶边的彩色像素各自向下画线到同色端点处转弯，路径穿过的分隔表格单元格中的掩码像素被涂为路径颜色。

**输入结构**：约 18x18 的网格，背景为黑(0)。网格的顶行有一段连续的多色像素（3~4 个不同颜色，取自蓝(1)、红(2)、绿(3)、黄(4)），各占 1 像素，位于不同列。网格中下部有橙(7)分隔线构成的完整水平线和垂直线网格，将中下部划分为 3x3 或 4x4 的矩形单元格（每个单元格约 3x3 像素）。部分单元格内有灰(5)掩码像素（填满或部分填充该单元格的非分隔线区域）。在分隔表格区域内（不在掩码单元格中），每种顶边颜色恰好有一个同色端点像素。生成约束：每个端点像素位于某个空白单元格（无掩码）内部；从顶边源像素垂直向下到端点所在行、再水平到端点的 L 形路径至少穿过一个含灰(5)掩码的单元格；不同颜色的路径不在掩码单元格内交叉。

**规则**：
1. 识别顶行的每个非黑源像素及其颜色 C，记录其列坐标。
2. 在分隔表格区域中找到同色 C 的端点像素，记录其行列坐标。
3. 从源像素位置垂直向下画 C 色线段，直到端点所在行；再水平画 C 色线段，直到端点所在列（L 形路径）。线段覆盖经过的所有黑(0)背景像素，但不覆盖橙(7)分隔线像素（路径在视觉上"穿过"分隔线但不改变分隔线颜色）。
4. 路径绘制完成后，检查每个含灰(5)掩码的单元格：如果该单元格内部存在某条路径的像素，则将该单元格内所有灰(5)像素替换为该路径的颜色 C。若有多条路径穿过同一掩码单元格（生成约束保证不发生，但若发生则取列坐标较小的路径颜色）。
5. 未被任何路径穿过的掩码单元格保持灰(5)不变。顶行源像素、端点像素、分隔线均保持原色。

**关键洞察**：重涂色不由表格行列对齐决定（源题做法），而由路径是否空间穿越该单元格决定——必须先完成配对连线才能知道哪些掩码被重涂为哪种颜色。

## 新题 8：像素放大倍率由封闭区域面积比决定，放大后的图案互补拼合

**组合逻辑**：[洪水填充/区域识别](创新：区域面积用于计算放大倍率) → [像素放大](创新：倍率不是固定的 2 的幂次，而是由面积比动态确定) → [互补拼合](创新：放大后的图案需要平移拼合成一个无缝矩形)

**来源原语**：像素放大(pixel_scale) + 基元图案(motif) + 逐级展开(successive_placement) + 倍增缩放序列(power_of_two_scaling) 来自 762cd429；洪水填充(flood_fill) + 封闭背景区域(enclosed_bg_region) + 轮廓围合(contour_enclosure) 来自 753ea09b；平移(translate) + 互补拼合(complement_fit) + 无重叠拼合(non_overlap_pack) + 最密堆叠最小框(densest_minimal_bbox) 来自 681b3aeb

**依赖链**：轮廓线围合出大小不同的封闭区域 → 每个区域内有一个小图案 → 区域面积与图案面积的比值决定放大倍率（取整） → 将各图案按倍率像素放大 → 放大后的图案通过平移互补拼合成一个紧密矩形输出。删除面积比计算则倍率未知；删除拼合步骤则放大后的图案散落无序。

轮廓围合区域的面积与其内部图案的面积之比决定放大倍率，放大后的所有图案通过平移拼合成最紧密的矩形。

**输入结构**：约 20x20 的网格，背景为黑(0)。橙(7) 8-连通轮廓线形成 2~3 个互不嵌套的闭合区域。每个闭合区域内部有一个由某种非黑、非橙颜色（取自蓝(1)、红(2)、绿(3)中的一种，各区域颜色不同）构成的小型 4-连通图案（2~4 像素），图案形状不对称。每个区域的背景像素面积（不含轮廓线和图案本身）各不相同。生成约束：每个区域面积除以其图案像素数的商为整数且在 2~4 之间（作为放大倍率）；所有图案按各自倍率像素放大后，恰好可以通过平移（不旋转）互补拼合成一个无间隙的紧密矩形。

**规则**：
1. 将橙(7)像素视为障碍，对黑(0)背景做 4-连通区域划分。识别不接触网格边缘的封闭区域。
2. 对每个封闭区域，计算其背景像素面积 A（区域内黑(0)像素数量，不含区域内的图案像素和轮廓线像素）。
3. 找到该区域内的彩色图案（非黑、非橙的 4-连通像素集），计算图案像素数 P。
4. 放大倍率 S = A / P（保证为整数）。
5. 将图案按倍率 S 进行像素放大（每个像素变为 S x S 的同色块），保持图案颜色不变。
6. 输出为一个新画布（大小恰好容纳所有放大后图案的最紧密矩形排列）：将所有放大后的图案通过平移（不旋转不镜像）拼合成一个无间隙矩形，背景为黑(0)。拼合方式唯一：各图案在矩形内互不重叠，且矩形内无黑(0)间隙。放大后图案的放置顺序：按放大倍率从大到小放置，倍率相同时按图案颜色编号从小到大放置。

**关键洞察**：放大倍率不是预设的等比序列，而是由每个图案所在封闭区域的"空余空间"编码——区域越空旷（面积比越大），其中的图案放大越多。求解者必须理解面积比的含义才能得到正确的放大结果。

## 新题 9：控制标记重涂区域后形成平行墙壁，种子像素在墙间生成条纹

**组合逻辑**：[重涂色](已有原语) + [擦除](已有原语) → [填充/条纹生成](创新：条纹范围和方向由重涂后形成的墙壁几何决定) ← [标记形状决定操作](已有原语，决定重涂方向) + [种子定条纹周期](已有原语，但种子位置受重涂结果约束)

**来源原语**：重涂色(recolor) + 擦除(erase) + 控制标记(control_marker) + 单色区域(monochrome_region) + 标记指向目标(marker_points_to_target) + 标记形状决定操作(marker_shape_determines_operation) 来自 21897d95；填充(fill) + 种子像素(seed_pixel) + 条纹(stripe) + 种子定条纹周期(seed_sets_stripe_period) + 阵列排布(array_layout) 来自 0a938d79

**依赖链**：T 形控制标记的茎指向目标区域 → 目标区域被重涂为源区域颜色（形成新的单色条带/墙壁） → 重涂后的墙壁将网格分割成走廊 → 走廊内的种子像素对定义条纹方向和周期 → 条纹填充走廊空间。删除重涂步骤则墙壁拓扑不确定，种子不知在哪个走廊中；删除条纹步骤则重涂只是换色无几何后果。

T 形控制标记驱动区域重涂，重涂后的区域扩展为平行墙壁，墙壁间走廊中的种子像素对产生交替条纹填充。

**输入结构**：约 18x18 的网格。网格由 4~5 个大型单色矩形区域镶嵌而成（颜色取自蓝(1)、红(2)、灰(5)、青(8)），区域之间以 1 像素缝隙或直接邻接。其中 2 个区域边界上有栗(9)色的 T 形控制标记（3 像素的横杆 + 1 像素的茎），茎指向相邻的目标区域。在网格中另有 2 对非黑非区域色的种子像素：每对由绿(3)和黄(4)各一个像素组成，位于同一行或同一列，位于某个大型区域内部（非边界），两个种子之间间隔 2~4 像素。生成约束：T 形标记的重涂操作会使被重涂的区域与某个已有同色区域融合，形成贯穿若干行或列的连续色带（即墙壁效果）；重涂完成后，种子像素对所在的走廊（两面墙壁之间的条形空间）是明确的矩形区域。

**规则**：
1. 对每个栗(9)色 T 形控制标记：茎的方向指向一个目标区域。标记横杆背后（茎的反方向）两个对角位置落在源区域中。
2. 将目标区域的所有像素重涂为源区域的原始颜色。
3. 将控制标记的所有栗(9)像素重涂为源区域的颜色（标记融入源区域）。
4. 重涂完成后，识别由同色连续区域形成的平行墙壁结构（贯穿网格大部分行或列的连续色带，宽度至少 2 像素）。
5. 两面平行墙壁之间的背景区域为走廊。对走廊内的每对种子像素（绿(3)和黄(4)）：
   - 若走廊是水平走廊（上下被墙壁夹），则以两种子的列间距为周期，在走廊范围内绘制垂直条纹：经过绿(3)种子列的条纹为绿(3)，经过黄(4)种子列的条纹为黄(4)，以此周期交替覆盖走廊内所有像素。
   - 若走廊是垂直走廊（左右被墙壁夹），则以两种子的行间距为周期，在走廊范围内绘制水平条纹，同理交替。
6. 种子像素被条纹覆盖。墙壁和非走廊区域保持重涂后的颜色不变。

**关键洞察**：墙壁不是输入中预设的，而是控制标记驱动的重涂操作"焊接"出的——求解者必须先模拟标记操作才能知道走廊在哪里，然后才能在正确的走廊中生成正确方向的条纹。

## 新题 10：周期瓦片补全后残留标记定位碎片锚点，碎片滑入锚点拼合矩形

**组合逻辑**：[补全](已有原语) → [标记识别](创新：补全操作的副产品——无法被周期解释的像素——成为下一步操作的锚点) → [滑动/移动 + 互补拼合](已有原语，但目标位置由补全残留决定)

**来源原语**：补全(completion) + 周期瓦片(periodic_tile) + 行列周期(row_col_period) + 标记为缺失值(markers_missing_val) 来自 f823c43c；移动(move) + 互补拼合(complement_fit) + 碎片(fragment) + 锚定物体(anchor_object) + 同色碎片拼成矩形(same_color_join) 来自 fe45cba4；滑动(slide) + 共线对齐(collinear_aligned) 来自 dc433765

**依赖链**：品红像素既可能是周期瓦片的缺失值也可能是碎片锚点标记 → 先推断周期瓦片并补全所有可被周期解释的品红像素 → 补全后仍为品红的像素就是锚点标记 → 锚点标记的位置指示碎片应滑入的目标位置 → 碎片沿共线方向滑动到锚点处与同色锚定物体互补拼合成矩形。删除补全步骤则无法区分缺失值和锚点；删除滑动拼合步骤则锚点无意义。

补全周期瓦片后，无法被周期解释的品红像素暴露为碎片锚点，碎片沿共线方向滑入锚点位置与同色物体拼合成完整矩形。

**输入结构**：约 18x18 的网格。网格大部分区域由两种颜色（蓝(1)和灰(5)）构成的周期性棋盘状图案覆盖（最小周期瓦片为 2x2 或 3x2）。若干品红(6)像素散布在网格中，其中大部分替换了本应是蓝(1)或灰(5)的周期位置（即周期缺失值）。此外，网格中有 2 对红(2)色的 4-连通物体：每对中一个物体触及网格底边（碎片），另一个不触底边（锚定物体）。每对的碎片和锚定物体在同一列范围内（垂直共线），可通过垂直平移互补拼合成一个 3x3 或 4x3 的实心红(2)矩形。在每个碎片与其配对锚定物体之间的垂直路径上，恰好有 1~2 个品红(6)像素不在任何合法的周期位置上（即使推断出周期后这些像素也无法被周期颜色解释）——这些就是锚点标记。生成约束：锚点标记像素所在的行坐标恰好标示了碎片滑入后的目标行（碎片顶边对齐到该标记行时，碎片与锚定物体恰好互补拼合）；所有周期缺失值品红像素都可被最小周期瓦片唯一恢复；两对红(2)物体互不干扰。

**规则**：
1. 忽略红(2)像素和品红(6)像素，从剩余的蓝(1)和灰(5)像素推断最小面积的行列周期瓦片。
2. 对每个品红(6)像素，检查其网格坐标在周期瓦片中对应的颜色：若该坐标对应蓝(1)或灰(5)，则该品红像素是缺失值，用对应颜色替换之。
3. 补全后仍为品红(6)的像素即为锚点标记。
4. 对每对红(2)碎片和锚定物体（同一列范围内、碎片触底边、锚定物体不触底边）：
   - 找到该对之间路径上的锚点标记（品红(6)像素，位于碎片和锚定物体之间的列范围内）。
   - 将碎片从底边向上垂直滑动，使碎片顶边行对齐到锚点标记所在行。
   - 清除碎片原位置像素为该位置补全后的周期颜色（即恢复为周期瓦片应有的颜色）。
   - 在新位置绘制碎片的红(2)像素。此时碎片与锚定物体恰好互补拼合成一个实心红(2)矩形。
5. 擦除所有锚点标记像素（品红(6)），替换为该位置周期瓦片的应有颜色。

**关键洞察**：品红像素身兼两职——大部分是周期瓦片的遮蔽噪声，少数是碎片操作的定位信号——求解者必须先完成周期推断才能将两种品红像素区分开来，进而找到正确的滑动目标。
