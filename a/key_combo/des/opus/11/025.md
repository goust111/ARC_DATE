## 新题 1：频率驱动的叠加优先级

**组合逻辑**：[计数](创新：统计面板内非背景像素数) → [透明叠加](创新：叠加顺序由统计结果动态决定而非固定位置)

**来源原语**：计数(counting) ← f3cdc58f/bd283c4a；透明叠加(transparent_overlay) ← 281123b4；图层优先级(layer_priority) ← 281123b4；按频率降序(descending_freq) ← bd283c4a

**依赖链**：面板的图层优先级不再由固定的位置序决定，而由各面板前景像素密度（非背景像素数）决定——密度最高的面板位于最前层。计数结果直接改变了叠加操作的执行顺序，删除计数步骤则无法确定叠层序。

根据各面板的前景像素密度确定叠加优先级，将多面板透明叠合为一张输出图。

**输入结构**：约 5x23 的网格，由三条全高灰(5)分隔列将网格均分为四个 5x5 面板。每个面板以黑(0)为背景，各含一种不同的前景色（从蓝(1)、红(2)、绿(3)、黄(4)中各取一种），且各面板的前景像素数量互不相同（范围 3~10 像素）。四个面板的前景图案在空间上存在部分重叠位置（即至少有某些坐标在两个以上面板中都是非背景色）。

**规则**：
1. 统计每个面板中非背景(非 0)像素的数量。
2. 按像素数量从多到少排列面板，数量最多的面板为最前层（最高优先级），数量最少的为最后层。生成约束保证四个面板像素数量互不相同，不存在平局。
3. 创建一个 5x5 全黑输出网格。按从后层到前层的顺序依次叠加各面板：对每个位置，若当前面板该位置为非背景色，则覆盖输出网格该位置（后处理的面板覆盖先处理的）。
4. 最终输出 5x5 网格中，每个位置的颜色为在该位置有非背景色的所有面板中、前景像素总数最多的那个面板的颜色；若所有面板在该位置均为背景，则输出黑(0)。

**关键洞察**：面板的层序不由空间位置编码，而由面板自身的像素密度隐式编码——必须先统计再叠合，仅看单个示例难以区分"密度优先"与"位置优先"。

## 新题 2：对称类型路由的区域填充

**组合逻辑**：[洪泛填充](保留) + [对称类型决定颜色](创新：对称性判断的对象从前景物体变为封闭区域的边界形状) → [重涂色](由对称判断结果选择填充色)

**来源原语**：洪泛填充(flood_fill) ← 83302e8f；对称类型决定颜色(symmetry_det_color) ← a09f6c25；封闭背景区域(enclosed_bg) ← 83302e8f；重涂色(recolor) ← a09f6c25

**依赖链**：先识别封闭区域，再判断每个封闭区域的边界轮廓属于哪种反射对称类型，对称类型决定该区域应填充的颜色。删除对称判断则无法确定填充色；删除区域识别则无处可填。

判断每个封闭区域边界轮廓的对称类型，以此决定区域内部的填充颜色。

**输入结构**：约 15x15 的网格，黑(0)背景上有灰(5)像素构成的封闭边界轮廓，形成 3~5 个互不嵌套的封闭区域。每个封闭区域的边界轮廓恰好具有一种反射对称性：水平对称、垂直对称、或同时具有水平和垂直对称（即 180 度旋转对称）。区域内部全为黑(0)。不同示例中边界轮廓的具体形状不同（可以是不规则多边形轮廓、带凹凸的框等，像素数 10~30），但始终满足恰好一类对称性。各区域面积（内部黑像素数）在 4~20 之间。

**规则**：
1. 识别灰(5)像素围成的所有 4-连通封闭背景区域（仅考虑完全被灰像素包围、不与网格边界相连的黑色区域）。
2. 对每个封闭区域，提取其边界轮廓（围成该区域的全部灰像素集合），计算该轮廓的反射对称类型：
   - 仅水平对称 → 填充蓝(1)
   - 仅垂直对称 → 填充红(2)
   - 同时水平和垂直对称 → 填充绿(3)
3. 用对应颜色洪泛填充该封闭区域的全部内部像素。
4. 灰(5)边界像素和非封闭的背景黑(0)像素保持不变。

**关键洞察**：填充颜色不由区域大小或位置决定，而由围成该区域的边界轮廓的几何对称性决定——需要对比多个示例才能归纳出对称类型与颜色的映射关系。

## 新题 3：标记数控制放大倍率后印章

**组合逻辑**：[计数](统计标记数) → [像素放大](创新：倍率由标记数决定而非色数) → [印章覆盖](创新：放大后的图案印到指定插槽)

**来源原语**：计数(counting) ← 4852f2fa；像素放大(pixel_upscale) ← d4b1c2b1；印章覆盖(stamp) ← 92e50de0；标记数等于副本数(marker_count_equals_copy_count) ← 4852f2fa；色数决定倍率(color_count_scale) ← d4b1c2b1；目标插槽(target_slot) ← 9f27f097

**依赖链**：标记像素的数量决定精灵体的放大倍率，放大后的精灵体尺寸必须恰好匹配目标插槽的尺寸才能正确印入。三个操作环环相扣：删除计数则不知倍率，删除放大则尺寸不匹配目标，删除印章则无最终输出。

统计散落标记的数量作为放大倍率，将精灵体放大后填入尺寸匹配的目标插槽。

**输入结构**：约 12x12 的网格，黑(0)背景上有三类元素：(a) 一个 2x2 或 3x3 的多色精灵体（由 2~3 种非背景色组成，颜色从蓝(1)、红(2)、绿(3)中选取），位于网格左上区域；(b) 若干个橙(7)单像素标记，散布在网格各处，数量为 2 或 3（即放大倍率为 2 或 3）；(c) 一个全黄(4)填充的矩形目标插槽，其尺寸恰好等于精灵体尺寸乘以标记数量（如精灵体 2x2 且标记数为 3，则插槽为 6x6），位于网格右下区域。生成约束：标记数量乘以精灵体边长恰等于目标插槽边长。

**规则**：
1. 识别精灵体（由非黑、非橙、非黄颜色组成的连通多色小图形）并裁剪其最小边界框。
2. 统计网格中橙(7)单像素标记的数量 N。
3. 将精灵体进行 N 倍像素放大：每个像素替换为 NxN 的同色方块。
4. 识别黄(4)填充的矩形目标插槽。
5. 将放大后的精灵体覆盖到目标插槽的位置（左上角对齐），替换掉黄色像素。
6. 橙(7)标记像素在输出中擦除为黑(0)背景。原始精灵体位置保持不变。

**关键洞察**：放大倍率既不由精灵体自身属性决定，也不由目标插槽直接标注，而由散落在网格各处的标记像素数量隐式编码——需要对比不同示例中标记数与输出尺寸的关系才能归纳。

## 新题 4：射线碰撞构建格子后分类填充

**组合逻辑**：[射线延伸](从边界标记发射) → [碰撞停止](射线相交形成格子) → [洪泛填充](创新：填充由格子划分出的区域) + [完整与缺损区异色](根据区域是否为完整矩形分类填色)

**来源原语**：射线延伸(ray_extend) ← 2c608aff；碰撞停止(collision_stop) ← 2c608aff；边界标记对(border_marker_pair) ← 0d87d2a6；洪泛填充(flood_fill) ← 83302e8f；完整与缺损区异色(intact_broken_differ) ← 83302e8f；格子框架(lattice_frame) ← 83302e8f

**依赖链**：边界标记决定射线起点和方向；射线碰撞形成的格子框架划分出区域；区域的完整性（是否为完整矩形）决定其填充颜色。射线构建的框架具有不确定性（缺少某些标记会导致某些区域不封闭），因此填充分类与射线构建相互依赖。

从网格边界的标记对发射射线，射线交汇形成不完整格子，再根据所围区域是否为完整矩形进行差异化填充。

**输入结构**：约 13x13 的网格，黑(0)背景。网格的四条边界上分布着红(2)标记像素：左边界和右边界上各有 2~3 个标记，它们的行坐标成对匹配（同一行的左右边界各有一个标记，表示一条水平引导线）；顶边界和底边界上各有 2~3 个标记，列坐标成对匹配（表示垂直引导线）。但并非所有标记都成对——至少有 1~2 个标记在对面边界没有对应标记（即该方向的射线无法贯穿整个网格）。水平线和垂直线的数量总共 4~6 条（含不完整的）。

**规则**：
1. 识别边界标记对：左右边界同行的标记对定义水平引导线，上下边界同列的标记对定义垂直引导线。
2. 对每条完整的引导线（两端都有标记），用红(2)绘制贯穿整行或整列的直线。对仅有单端标记的，从该标记向对面方向发射红(2)射线，射线在碰到已有红色线段时停止（停止位置为碰撞点前一格，不覆盖已有线段）。
3. 绘制完所有线段后，识别被红线和网格边界完全包围的 4-连通黑色区域。
4. 对每个封闭区域，判断其形状是否为完整矩形（面积等于其边界框面积）：
   - 完整矩形区域 → 填充蓝(1)
   - 非矩形区域（因射线不完整导致多个本应分离的矩形格连通） → 填充黄(4)
5. 与网格边界相连的外部背景区域保持黑(0)不变。

**关键洞察**：不完整的标记对产生截断射线，截断射线无法将相邻格子分开，导致合并区域失去矩形性——分类填充的结果间接编码了哪些边界标记缺少配对。

## 新题 5：周期检测驱动的交替重涂

**组合逻辑**：[裁剪](提取最小周期单元) + [周期](创新：周期长度作为后续操作的参数) → [交替选取](创新：交替间隔等于检测到的周期长度) → [重涂色]

**来源原语**：裁剪(crop) ← 2dee498d；周期(period) ← 2dee498d；交替选取(alternating_selection) ← d406998b；重涂色(recolor) ← d406998b；奇偶位决定涂色(parity_position_recolor) ← d406998b

**依赖链**：先检测输入中重复图案的最小周期 P，然后将 P 作为交替选取的间隔参数——每隔 P 个位置选取一个对象进行重涂色。删除周期检测则不知交替间隔；删除交替选取则无法确定涂色目标。

检测重复图案的周期长度，以该长度为间隔交替选取网格中的前景对象进行重涂色。

**输入结构**：约 5x20 的网格分为上下两个区域：(a) 上方 2 行为一条水平方向重复的图案带，由灰(5)和黑(0)组成——灰像素形成一个宽 W 的基本单元（W 在 2~4 之间），沿水平方向重复若干次（可能包含镜像副本），总宽度等于网格宽度；(b) 下方 3 行为若干个绿(3)的 4-连通小图形（3~5 像素，形状各异），均匀分散在黑(0)背景上，图形之间至少间隔 1 列，总共 6~10 个图形，按从左到右排列。

**规则**：
1. 分析上方图案带，检测其最小水平重复周期 P（考虑镜像后仍算同一周期，与参考题 2dee498d 的周期定义一致）。
2. 识别下方所有绿(3)的 4-连通图形，按其边界框左边界从左到右编号为 1, 2, 3, ...
3. 从第 1 个图形开始，每隔 P 个选取一个图形（即选取编号为 1, 1+P, 1+2P, ... 的图形），将选中图形重涂为红(2)。
4. 未被选中的绿色图形保持绿(3)不变。上方图案带保持不变。

**关键洞察**：上方图案带不参与最终输出的变化，它的唯一作用是编码一个数值参数（周期长度）供下方对象的选取使用——必须对比多个示例中不同周期值导致的不同选取结果才能归纳。

## 新题 6：面积阈值筛选后的对角互补印章

**组合逻辑**：[计数](统计面积) + [面积超阈值则变色](创新：阈值不固定，由特殊标记编码) → [筛选](保留超阈值对象) → [对角互补](创新：仅对筛选后保留的对象执行对角补块)

**来源原语**：计数(counting) ← ae58858e；面积超阈值则变色(recolor_above_threshold) ← ae58858e；筛选(filtering) ← 29623171；对角互补(diagonal_complement) ← 22233c11；正方形块(square_block) ← 22233c11；标记像素(marker_pixel) ← ff2825db

**依赖链**：阈值由输入中特殊标记行编码，必须先解读标记行得到阈值数字 T；然后统计每个前景对象面积并与 T 比较进行筛选；最后仅对面积超阈值的对象执行对角互补印章操作。三者缺一不可：无标记行则阈值未知，无面积统计则无法筛选，无筛选则无法确定哪些对象参与互补。

解读标记行编码的阈值，筛选面积超过阈值的对象，仅对它们执行对角互补补块。

**输入结构**：约 15x15 的网格，黑(0)背景。最底行为阈值编码行：由连续的品红(6)像素组成，像素数即为面积阈值 T（范围 3~6）。网格上方分布着 4~6 个红(2)的 4-连通对象，每个对象的边界框为正方形且可被均分为 2x2 的等大方块区域，其中恰好两个对角方块被红色填充、另两个为黑色背景（与参考题 22233c11 结构一致）。各对象的方块边长不同（1~3 像素），因此面积（红色像素数）不同（范围 2~18）。各对象间互不相邻（边界框间距至少 2 像素）。

**规则**：
1. 读取最底行品红(6)像素的数量，得到面积阈值 T。
2. 识别所有红(2)的 4-连通对象，统计每个对象的像素面积。
3. 对面积 >= T 的对象：保留原始红色像素，并在其对角空位（边界框中未被红色填充的两个对角方块位置）的正外侧绘制绿(3)方块（方块大小与对象内的方块相同，位置为边界框角点向外延伸）。超出网格边界的部分裁剪。
4. 对面积 < T 的对象：从输出中完全擦除（变为黑(0)背景）。
5. 最底行品红像素在输出中保持不变。

**关键洞察**：阈值不是固定常数，而是由输入底行的像素数量动态编码——同一组对象在不同示例中因阈值不同会产生不同的保留/擦除结果和不同数量的绿色补块。

## 新题 7：引导线接触触发旋转印章

**组合逻辑**：[连线](从边界标记绘制引导线) + [接触判定](引导线是否接触对象) → [旋转](创新：接触方向决定旋转角度) → [印章覆盖](将旋转后的对象印回原位)

**来源原语**：连线(line_drawing) ← 0d87d2a6；边界标记对(border_marker_pair) ← 0d87d2a6；接触判定(contact_detection) ← 0d87d2a6；旋转(rotate) ← 99caaf76；印章覆盖(stamp) ← 264363fd

**依赖链**：引导线的方向（水平或垂直）和接触对象的哪一侧共同决定旋转角度——水平线从左侧接触则顺时针 90 度，从右侧接触则逆时针 90 度，垂直线从上方接触则 180 度，从下方接触则不旋转。删除引导线绘制则无接触；删除接触判定则不知是否旋转及方向；删除旋转则输出不变。

绘制引导线并判断其与前景对象的接触方位，以此决定对象的旋转角度。

**输入结构**：约 13x13 的网格，灰(5)背景上有 3~4 个蓝(1)的 4-连通小图形（4~8 像素，非对称形状，边界框为 2x3 或 3x3），彼此间距至少 3 像素。网格的左边界和右边界上各有 0~2 个红(2)标记像素，上边界和下边界上各有 0~2 个红(2)标记像素。左右边界同行的标记对定义水平引导线，上下边界同列的标记对定义垂直引导线。每个蓝色对象恰好被一条引导线接触（4-邻接），且接触仅发生在对象的一侧。生成约束：不存在对象被多条线同时接触的情况。

**规则**：
1. 识别边界标记对并绘制完整引导线（红(2)贯穿整行或整列）。
2. 对每个蓝(1)对象，判断引导线从哪个方向接触（引导线像素与对象像素 4-邻接，取引导线相对于对象质心的方位）：
   - 水平引导线从对象左侧接触 → 将对象顺时针旋转 90 度
   - 水平引导线从对象右侧接触 → 将对象逆时针旋转 90 度
   - 垂直引导线从对象上方接触 → 将对象旋转 180 度
   - 垂直引导线从对象下方接触 → 对象不旋转
3. 旋转以对象边界框中心为锚点进行，旋转后的对象印回以原边界框中心为中心的位置（覆盖原有蓝色像素，新位置用蓝(1)填充，原位置中不再被占据的像素恢复为灰(5)背景）。
4. 引导线在输出中保留为红(2)。若旋转后的对象像素与引导线重叠，引导线优先（保持红色）。

**关键洞察**：旋转角度不由对象自身形状编码，而由外部引导线与对象的相对空间关系（接触方位）决定——同一形状在不同位置因引导线方向不同会产生不同旋转。

## 新题 8：宏单元解码后按密度排序堆叠

**组合逻辑**：[粗模板精细替换](解码宏单元格为精细图案) → [计数](统计解码后各色密度) → [排序](创新：按密度排列) + [堆叠](创新：排序后的色块垂直堆叠为柱)

**来源原语**：粗模板精细替换(coarse_to_fine_substitution) ← 5833af48；计数(counting) ← f3cdc58f/bd283c4a；排序(sort) ← bd283c4a；堆叠(stack) ← bd283c4a；柱状条(histogram_bar) ← f3cdc58f；按频率降序(descending_freq) ← bd283c4a

**依赖链**：宏单元格需先用控制精灵体解码为精细图案，解码后才能统计各颜色的实际像素数量；排序依赖计数结果；堆叠格式依赖排序顺序。跳过解码则计数对象错误（宏单元格中每格代表一整块像素而非单个像素），跳过计数则无法排序。

将宏单元模式用控制精灵体解码为精细图案，统计解码结果中各色像素数，按频率降序堆叠为柱状条输出。

**输入结构**：约 10x10 的网格分为左右两部分，中间由一列灰(5)分隔：(a) 左侧为一个 3x3 的宏单元阵列，每个宏单元为 2x2 像素大小，宏单元颜色为黑(0)或青(8)，表示"空"或"激活"；(b) 右侧上方为一个 2x2 的控制精灵体，由红(2)和蓝(1)像素组成（2x2 中有 1~3 个蓝像素，其余为红像素）；(c) 右侧下方为一个 2x2 的第二控制精灵体，由红(2)和绿(3)像素组成（结构类似）。宏单元阵列中青(8)单元格在奇数行用第一控制精灵体替换，在偶数行用第二控制精灵体替换（行从 0 开始计数）。

**规则**：
1. 解码宏单元阵列：对 3x3 阵列中每个青(8)宏单元，根据其所在行的奇偶性选择对应控制精灵体进行替换（奇数行用蓝/红精灵体，偶数行用绿/红精灵体）；黑(0)宏单元替换为 2x2 全黑块。得到 6x6 的解码图案。
2. 统计解码图案中蓝(1)、绿(3)、红(2)各自的像素总数（黑(0)不计）。
3. 输出为一个 Nx3 的网格（N 为前景像素总数，3 列分别对应三种颜色）。将三种颜色按像素数从多到少排列为从左到右的三列，每列从底部向上填充该颜色，填充格数等于其像素数，其余格为黑(0)。
4. 若两种颜色像素数相同，左边界框列坐标小的颜色（在解码图案中最先出现的列位置）排在左边。

**关键洞察**：宏单元格本身不包含颜色频率信息——必须经过行奇偶性条件路由到不同精灵体、完成替换后，才能得到真正的颜色分布进行排序。单看宏单元阵列无法预测最终柱状图。

## 新题 9：镜像方向由包含关系决定

**组合逻辑**：[包含](判断标记像素在精灵体的哪一半) → [镜像](创新：镜像轴由包含位置决定——标记在左半则水平镜像，在上半则垂直镜像) → [印章覆盖](镜像后粘贴到目标插槽)

**来源原语**：包含(containment) ← 264363fd；镜像(mirror) ← 9f27f097/2dee498d；印章覆盖(stamp) ← 9f27f097；目标插槽(target_slot) ← 9f27f097；形状匹配(shape_match) ← 9f27f097；标记像素(marker_pixel) ← 264363fd

**依赖链**：标记像素在精灵体内的相对位置决定镜像方向；镜像方向决定目标插槽接收的图案朝向。删除包含判断则不知如何镜像；删除镜像则目标图案错误；删除印章则无输出变化。结构为同时约束满足型——镜像方向需同时考虑标记位置和目标插槽形状。

根据标记像素在源精灵体中的空间位置决定镜像方向，将变换后的精灵体填入目标插槽。

**输入结构**：约 11x11 的网格，黑(0)背景上有三类元素：(a) 一个 4x4 或 5x5 的多色精灵体（由蓝(1)和绿(3)像素组成的不对称图案，像素数 6~12），位于网格中部偏左；(b) 精灵体内部恰好有一个红(2)单像素标记，位于精灵体边界框的某一象限（左上、右上、左下、右下之一）；(c) 网格右侧有一个与精灵体相同尺寸的全黄(4)矩形目标插槽。

**规则**：
1. 裁剪精灵体的最小边界框（包含蓝(1)、绿(3)和红(2)像素）。
2. 确定红(2)标记像素相对于精灵体边界框中心的位置象限：
   - 标记在左半部（列坐标 < 边界框宽度/2）→ 对精灵体执行水平翻转（左右镜像）
   - 标记在右半部（列坐标 >= 边界框宽度/2）→ 对精灵体执行垂直翻转（上下镜像）
3. 翻转时，红(2)标记像素不参与翻转——从精灵体中移除标记后再翻转。
4. 将翻转后的图案（仅蓝和绿像素）粘贴覆盖到黄(4)目标插槽位置。
5. 原始精灵体位置（含标记）在输出中擦除为黑(0)背景。

**关键洞察**：镜像方向不由目标插槽的位置暗示，而由精灵体内部标记像素的空间归属（左半/右半）隐式指定——同一精灵体形状在标记位于不同侧时会产生不同方向的镜像输出。

## 新题 10：滑动距离由区域密度投票决定

**组合逻辑**：[洪泛填充](识别分区) + [计数](统计各区域密度) → [最密区域保留填充](创新：最密区域的密度值作为滑动距离) → [滑动](将指定对象沿方向移动该距离)

**来源原语**：洪泛填充(flood_fill) ← 29623171；计数(counting) ← 29623171；最密区域保留填充(densest_region_kept_filled) ← 29623171；分区区域(partitioned_region) ← 29623171；滑动(translate) ← 99caaf76；分隔线(separator_line) ← 29623171；标记指示方向(marker_indicates_dir) ← 99caaf76

**依赖链**：分隔线划分区域 → 各区域内标记像素计数得到密度 → 最大密度值 D 成为滑动距离 → 箭头标记指示方向 → 目标对象沿该方向滑动 D 格。计数结果同时执行两个功能：选出获胜区域（用于填充）和编码位移量（用于滑动），两者紧耦合。

分区密度投票决定滑动距离，将目标对象沿箭头方向移动最大密度对应的格数。

**输入结构**：约 13x13 的网格，黑(0)背景。一条全宽的灰(5)水平分隔线和一条全高的灰(5)垂直分隔线将网格分为四个矩形区域（近似等大）。每个区域内散布着若干橙(7)像素（数量 1~5，各区域不同且互不相等）。网格中另有一个蓝(1)的 4-连通小图形（3~5 像素）位于某个区域内。网格边界上恰好有一个红(2)像素作为方向标记，其位置在四条边界之一的中点附近（上边界表示向上、下边界表示向下、左边界表示向左、右边界表示向右）。

**规则**：
1. 识别灰(5)分隔线，将网格划分为四个矩形区域。
2. 统计每个区域内橙(7)像素的数量，找到数量最大的区域，记其橙色像素数为 D。生成约束保证最大值唯一。
3. 将数量最大的区域内所有橙(7)像素填充为橙色（保持不变），其他三个区域的橙(7)像素擦除为黑(0)。
4. 识别红(2)边界标记所在的边（上/下/左/右），确定滑动方向。
5. 将蓝(1)图形沿该方向平移 D 格。若平移后部分像素超出网格边界或落在灰色分隔线上，则裁剪超出部分。原位置的蓝色像素擦除为黑(0)。
6. 灰(5)分隔线和红(2)边界标记在输出中保持不变。

**关键洞察**：滑动距离不是显式数字，而是从四个分区的像素密度竞争中涌现——必须先识别分区、统计、比较最大值，才能得到位移量。同时橙色像素执行双重角色：既是密度投票的选票，也通过"最密区域保留、其余擦除"可视化地标记了获胜分区。
