## 新题 1：拓扑选角射线与碰撞计数重涂

**组合逻辑**：[内部包含](判定发射者/接收者角色) → [射线延伸](从空洞中心向外投射) → [重涂色](按碰撞计数决定目标颜色)

**来源原语**：射线延伸(ray_cast, 参考题13/18), 内部包含(interior_containment, 参考题8), 重涂色(recolor, 参考题8/11), 连通分量(connected_component, 参考题8), 封闭区域(enclosed_region, 参考题8), 尺寸分类(size_classification, 参考题11)

**依赖链**：拓扑分析(有洞/无洞)分配角色 → 有洞对象的洞位置决定射线起点 → 射线在空间中传播命中无洞对象 → 每个无洞对象被命中次数决定其最终颜色。删除拓扑判断则无法确定谁发射/谁接收；删除射线则无法建立发射者与接收者的空间对应；删除计数规则则无法确定最终颜色。

对每个有洞对象，从其内部空洞的质心位置出发，向四个基本方向发射射线；无洞对象根据被命中次数被重涂为不同颜色。

**输入结构**：黑(0)背景上约15x15网格。灰(5)色的4-连通单色连通分量若干（4~7个），每个分量为3~8像素的不规则形状。其中部分分量内部包含1个完整的黑(0)色4-连通封闭区域（即"有洞"分量），其余分量无洞。生成约束：有洞分量至少2个，无洞分量至少2个；所有分量互不相邻（最小间距2像素）；每个洞恰好1个像素大小（便于确定质心）。蓝(1)和红(2)不出现在输入中，作为输出标记色保留。

**规则**：
1. 检测所有灰(5)色4-连通分量，按是否包含封闭黑(0)背景区域分为"发射者"（有洞）和"接收者"（无洞）。
2. 对每个发射者，定位其内部封闭洞的唯一像素坐标(r,c)作为射线起点。
3. 从(r,c)向上、下、左、右四个方向各发射一条射线。射线沿该方向逐像素前进，跳过背景像素，遇到第一个属于"接收者"分量的像素时停止并记录命中。射线不穿过其他发射者（遇到发射者像素时也停止，但不计为命中）。
4. 统计每个接收者被命中的总次数：被命中恰好1次的接收者重涂为蓝(1)；被命中2次及以上的接收者重涂为红(2)；未被命中的接收者保持灰(5)不变。
5. 发射者保持灰(5)不变，洞保持黑(0)不变。

**关键洞察**：对象的拓扑属性（有洞/无洞）决定其在变换中扮演的角色，而非颜色或大小；最终颜色由全局射线碰撞的统计结果决定，仅看单个示例无法确定"1次=蓝/2次=红"的阈值规则。

## 新题 2：对角堆叠涌现轴与间隙镜像填充

**组合逻辑**：[堆叠+对角链排列](排列矩形形成隐式对角轴) → [镜像](跨涌现轴反射整体) → [填充](间隙区域涂分隔色)

**来源原语**：堆叠(stacking, 参考题3), 对角链排列(diagonal_chain_layout, 参考题3), 角点重叠(corner_overlap, 参考题3), 镜像(reflect, 参考题20), 填充(fill, 参考题20), 间隙带(gap_strip, 参考题20), 分隔色填充间隙(sep_color_fills_gap, 参考题20), 按左边缘排序(ordered_by_left_edge, 参考题3)

**依赖链**：矩形按左边缘排序后对角堆叠 → 堆叠链的主对角线方向自然形成一条隐式对称轴 → 整体关于该轴做镜像反射生成对称副本 → 原件与副本之间的三角形间隙区域用绿(3)填充 → 角点重叠位置保持原矩形颜色（优先级高于填充）。

将底部排列的矩形对角堆叠后，将堆叠体关于其对角线镜像，用绿色填充原件与镜像间的楔形间隙。

**输入结构**：黑(0)背景上约18x18网格。底行有3~4个不同颜色的实心矩形（可选颜色：红(2)、蓝(1)、黄(4)、品红(6)），每个矩形宽2~4像素、高3~5像素，均接触底行。矩形按左边缘从左到右排列，彼此间有1~3像素水平间距。绿(3)不出现在输入中，作为间隙填充色保留。生成约束：矩形数量为3或4个；所有矩形高度之和减去重叠行数后不超过网格高度。

**规则**：
1. 按左边缘从左到右排序所有前景矩形，编号为R1, R2, ..., Rn。
2. 清空画布为黑(0)。将R1放置在左上角(0,0)。对后续Ri，放置位置为前一个Ri-1的右下角偏移：行方向下移(Ri-1的高度-1)，列方向右移(Ri-1的宽度-1)，使Ri左上角恰好覆盖Ri-1右下角像素。后放置的矩形覆盖先放置的（角点像素取后者颜色）。
3. 确定堆叠链整体的包围盒对角线：从包围盒左上角到右下角的直线方向即为镜像轴方向（主对角线方向，斜率为包围盒高/宽）。
4. 将堆叠链中每个矩形关于该对角线做轴对称反射，生成镜像副本，放置在对应的对称位置。镜像副本保持原矩形颜色。若镜像像素与原始像素重叠，保留原始像素颜色。
5. 对于被原始堆叠链和镜像副本共同包围但两者都未覆盖的背景像素（即夹在原件和镜像之间的三角/楔形间隙区域），填充为绿(3)。
6. 其余背景像素保持黑(0)。

**关键洞察**：镜像轴不在输入中显式给出，而是由对角堆叠操作的输出几何形状隐式定义；需要对比多个示例才能确认轴的计算方式是包围盒对角线而非固定45度角。

## 新题 3：周期补全后标记位置编码选择性擦除

**组合逻辑**：[周期扩展](补全瓦片覆盖全网格) → [同色对应](标记色匹配瓦片中的颜色) → [擦除](仅擦除标记所在瓦片副本中对应颜色的像素)

**来源原语**：周期扩展(periodic_expand, 参考题5/9), 补全(complete, 参考题5), 擦除(erase, 参考题1/4), 重复瓦片(repeating_tile, 参考题5), 占位符区域(placeholder_region, 参考题5), 孤立标记(isolated_marker, 参考题1), 同色对应(same_color_match, 参考题1), 周期延拓(periodic_extension, 参考题5)

**依赖链**：从可见区域推断最小瓦片 → 周期扩展填满全网格 → 确定每个标记落在哪个瓦片副本中 → 在该副本中擦除与标记同色的所有像素 → 最后擦除标记本身。瓦片未补全则无法确定哪些像素属于哪个副本；没有标记位置则无法确定擦除范围；没有同色对应则无法确定擦除哪种颜色。

先周期补全瓦片铺满网格，再根据散布标记的位置和颜色，擦除标记所在瓦片副本中与其同色的全部像素。

**输入结构**：黑(0)背景上约12x12网格。左上角有一个3x3或4x4的完整最小瓦片（由红(2)、蓝(1)、黄(4)中的2~3种颜色组成的固定图案）。网格其余区域为灰(5)占位符色，表示瓦片尚未展开。另有2~4个橙(7)色孤立标记像素散布在占位符区域内。生成约束：每个标记位于不同的瓦片副本范围内（即将网格按瓦片尺寸划分为若干副本区域后，每个标记落在不同副本中）；橙(7)不出现在瓦片图案中；瓦片图案中至少包含2种非背景颜色。

**规则**：
1. 从左上角提取最小重复瓦片（尺寸由占位符区域边界确定：第一个全灰行/列之前的区域即为瓦片）。
2. 将该瓦片周期铺满整个网格（替换所有灰(5)占位符像素）。标记像素位置暂时保留为橙(7)不被覆盖。
3. 对每个橙(7)标记像素，确定它落在哪个瓦片副本区域内（将网格按瓦片尺寸划分为不重叠的矩形块，标记所在块即为目标副本）。
4. 查看该标记在瓦片副本内的局部坐标(lr, lc)，读取瓦片图案中(lr, lc)位置的颜色C。在该目标副本区域内，将所有颜色为C的像素擦除为黑(0)背景。
5. 最后将所有橙(7)标记像素本身也擦除为黑(0)。
6. 不在任何标记所在副本中的瓦片副本保持完整不变。

**关键洞察**：标记的作用不是指示"擦除该位置"，而是通过其在瓦片内的局部坐标来选择要擦除的颜色类别，且擦除范围仅限于该标记所在的瓦片副本而非全局——需要对比多个示例才能归纳出这种"位置编码颜色选择+局部作用域"的双重约束。

## 新题 4：推移碰撞后距离优先透明叠加

**组合逻辑**：[推移](按接触侧方向推至边界) → [透明叠加](到达相同区域的对象叠加) → [冲突优先级](按推移距离排定覆盖顺序)

**来源原语**：推移(push, 参考题4), 透明叠加(transparent_overlay, 参考题12/14), 接触侧决定方向(contact_side_dir, 参考题4), 推至边界停止(stop_at_boundary, 参考题4), 固定标记(fixed_marker, 参考题4), 前景对象(foreground_object, 参考题4), 网格边界(grid_boundary, 参考题4), 层叠顺序(layer_stack, 参考题14), 冲突优先级(conflict_priority, 参考题3)

**依赖链**：标记接触侧确定每个对象的推移方向 → 推移距离由起始位置到边界的距离决定 → 多个对象到达重叠区域时需要层叠规则 → 推移距离更大的对象拥有更高绘制优先级（后绘制覆盖先绘制）。不知道推移方向则无法确定终点位置；不知道终点位置则无法发现重叠；不知道距离排序则无法解决冲突。

各对象被固定标记弹射至网格边界，落点重叠时按推移距离排定覆盖优先级。

**输入结构**：黑(0)背景上约14x14网格。栗(9)色固定标记像素组成一个小十字形（约5像素）位于网格中央偏左位置。3~4个不同颜色的前景对象（红(2)、蓝(1)、黄(4)、绿(3)各一个）分布在标记周围，每个对象为3~6像素的4-连通不规则形状，且恰好有一条边（1~2像素长）与标记的某一基本方向侧相邻接触。生成约束：不同对象接触标记的不同侧（上/下/左/右各最多一个对象）；推移后至少有两个对象的最终位置存在像素重叠；所有对象推移前互不重叠。

**规则**：
1. 识别栗(9)色标记和所有非背景、非栗色的4-连通前景对象。
2. 对每个对象，判断它接触标记的方向侧（对象在标记的上/下/左/右方向上与标记相邻）。推移方向为背离标记的方向（接触标记上侧的对象向上推，接触左侧的向左推，以此类推）。
3. 将每个对象沿推移方向平移，直到对象的前缘像素抵达网格边界（贴边放置）。记录每个对象的推移距离（像素数）。
4. 清除所有对象原始位置的像素（设为黑(0)背景）。标记保持不变。
5. 在最终位置绘制所有对象：按推移距离从小到大的顺序依次绘制（距离小的先绘制，距离大的后绘制）。后绘制的像素覆盖先绘制的像素。
6. 若两个对象推移距离相同，按原始位置行坐标较小者先绘制。

**关键洞察**：层叠优先级不由颜色或输入中的空间位置决定，而是由推移操作本身产生的位移量来编码——旅途越远的对象越"强"，这一规则仅通过对比多个有重叠和无重叠的示例才能归纳。

## 新题 5：双面板局部翻转后叠加配合分隔行颜色映射

**组合逻辑**：[局部翻转](各面板独立反转像素段) → [透明叠加](翻转后的面板位置对齐叠加) → [重涂色](分隔行编码的颜色映射应用于叠加结果)

**来源原语**：局部翻转(local_reverse, 参考题15), 透明叠加(transparent_overlay, 参考题12), 重涂色(recolor, 参考题6/17), 面板(panel, 参考题12), 分隔行(separator_row, 参考题12), 像素段(pixel_segment, 参考题15), 位置对齐(positional_alignment, 参考题12), 颜色替换映射(color_sub_map, 参考题17), 各侧独立翻转(independent_side_reverse, 参考题15)

**依赖链**：分隔行将网格分为两面板 → 每面板中的各行独立翻转（首尾像素交换） → 翻转改变了哪些像素在相同列位置对齐 → 两面板叠加取非背景像素（都非背景时取上面板） → 分隔行中从左到右的非背景像素序列定义颜色映射（第k种出现的颜色映射为序列中第k个颜色） → 映射应用于叠加结果。删除翻转则叠加结果错误；删除叠加则无法合并信息；删除颜色映射则最终颜色不确定。

两面板各自行内翻转后叠加，再按分隔行编码的颜色映射重涂叠加结果。

**输入结构**：黑(0)背景上约11x11网格（奇数行数）。正中间一行为分隔行，由3~4个不同颜色的像素组成（如第1个为红(2)、第2个为蓝(1)、第3个为绿(3)），其余位置为黑(0)。分隔行上方为上面板（5行），下方为下面板（5行）。每个面板中每行包含1~3个非背景前景像素，前景颜色仅使用红(2)和蓝(1)两种。生成约束：两面板形状相同（均为5行N列）；翻转后至少有2列上下面板都有非背景像素（产生叠加冲突）；分隔行中出现的颜色种类数与面板中出现的前景颜色种类数相同。

**规则**：
1. 识别分隔行（唯一一行包含面板中未使用颜色的行）。将分隔行上方和下方分别作为上面板和下面板。
2. 对每个面板独立执行行内翻转：将每行的像素序列左右镜像（第j列像素移到第W-1-j列，W为网格宽度）。
3. 将翻转后的上面板与翻转后的下面板按位置对齐叠加：某位置若仅一个面板有非背景像素，取该像素颜色；若两者都有非背景像素，取上面板颜色；若都是背景，保持背景。
4. 读取分隔行中从左到右的非背景像素颜色序列，建立颜色映射：面板中出现的第1种颜色（按颜色编号升序）映射为分隔行序列中第1个颜色，第2种映射为第2个，以此类推。
5. 对叠加结果中的每个非背景像素应用该颜色映射，得到最终输出。输出网格尺寸与单个面板相同（不含分隔行）。

**关键洞察**：分隔行不仅是物理分隔符，它的像素颜色序列还编码了最终阶段的重涂映射规则——这个双重身份需要对比多个示例（分隔行颜色不同则输出颜色不同）才能发现。

## 新题 6：颜色门控射线方向配合聚合量决定镜像侧

**组合逻辑**：[射线延伸](颜色决定射向分隔线或射向边界) → [聚合统计](累计各半区射线总像素数) → [镜像](像素多的半区跨分隔线覆盖少的半区)

**来源原语**：射线延伸(ray_cast, 参考题13), 镜像(reflect, 参考题20), 分隔线(divider_line, 参考题13/20), 孤立像素(isolated_pixel, 参考题11/13), 画布边界(canvas_boundary, 参考题13), 朝向与背离(toward_and_away, 参考题13), 颜色决定射线方向(color_determines_ray_direction, 参考题13), 跨轴对称(cross_axis_symmetry, 参考题20), 最近边界方向(nearest_boundary_direction, 参考题19)

**依赖链**：颜色决定每个像素的射线方向（朝向分隔线或背离） → 射线长度由空间位置决定 → 所有射线绘制完毕后统计各半区总着色量 → 着色量多的半区整体镜像到另一半区。颜色规则决定射线拓扑；空间布局决定射线长度；长度总和决定镜像方向——三层逻辑逐层依赖。

红色像素射向分隔线、蓝色像素射向最近边界，射线绘制后着色量多的半区镜像覆盖另一半。

**输入结构**：黑(0)背景上约15x15网格。灰(5)色全宽水平分隔线位于网格中部（不一定正中，可偏上或偏下1~2行）。红(2)和蓝(1)孤立像素各2~4个，分布在分隔线两侧（两侧都有红和蓝）。生成约束：分隔线上无其他颜色像素；所有孤立像素互不相邻且不与分隔线相邻（至少间隔1像素）；两半区的射线总像素数不相等（保证镜像方向唯一确定）；绿(3)不出现在输入中。

**规则**：
1. 识别灰(5)色全宽水平分隔线。将分隔线上方定义为上半区，下方为下半区。
2. 对每个红(2)像素：从该像素出发，向分隔线方向（上半区的红向下，下半区的红向上）绘制红(2)色射线，直到射线碰到分隔线前一格停止（不覆盖分隔线本身）。
3. 对每个蓝(1)像素：从该像素出发，向最近的网格边界方向（上半区的蓝向上，下半区的蓝向下）绘制蓝(1)色射线，直到射线到达网格边缘（含边缘像素）。
4. 统计上半区所有非背景、非分隔线像素总数（含原始孤立像素和新绘制的射线像素）为U；下半区同理为D。
5. 若U > D：将上半区（含所有射线和原始像素）关于分隔线做垂直镜像，覆盖下半区。上半区保持不变。
6. 若D > U：将下半区关于分隔线做垂直镜像，覆盖上半区。下半区保持不变。
7. 分隔线始终保持灰(5)不变。

**关键洞察**：射线绘制是"投票"过程——每条射线为自己所在半区贡献像素权重，最终多数方获得镜像覆盖权。颜色不是用于标记最终输出，而是编码了射线方向策略，两种策略对半区像素贡献量的博弈决定了全局变换方向。

## 新题 7：嵌套框深度编码迭代次数的裁剪重涂

**组合逻辑**：[外框绘制/嵌套检测](计数嵌套层数N) → [裁剪](提取最内层图案) → [重涂色](将图例映射迭代应用N次)

**来源原语**：外框绘制(frame_draw, 参考题18), 裁剪(crop, 参考题17), 重涂色(recolor, 参考题17), 空心矩形(hollow_rect, 参考题2/16), 微型图例(micro_legend, 参考题17), 尺寸倍增嵌套(size_doubled_nesting, 参考题18), 颜色替换映射(color_sub_map, 参考题17), 图例色替换(legend_color_replace, 参考题17), 内部区域(interior_region, 参考题16)

**依赖链**：检测嵌套空心矩形的层数N → N决定颜色映射的迭代次数 → 裁剪最内层获得操作对象 → 图例定义单步映射 → 迭代N次后得到最终颜色（可能产生循环或回到原色）。删除嵌套检测则不知迭代次数；删除裁剪则不知操作对象；删除图例则不知映射规则。

嵌套空心框的层数决定颜色映射的迭代深度，对最内层图案执行相应次数的颜色替换。

**输入结构**：黑(0)背景上约17x17网格。中心区域有2~3层同心嵌套的单像素宽空心矩形框，每层框颜色相同为灰(5)，相邻框间距1像素（内层框的外边界与外层框的内边界间隔1像素背景）。最内层框内部有一个3x3~5x5的多色图案（使用红(2)、蓝(1)、绿(3)中的2~3种颜色）。网格左下角或右下角放置1~2个水平微型图例（2像素宽1像素高的颜色对）：左像素为替换色，右像素为被替换色。生成约束：嵌套层数在不同示例中不同（2或3层）；图例定义的映射可以形成循环（如红→蓝、蓝→红）；最内层图案不含灰(5)和黑(0)。

**规则**：
1. 检测所有灰(5)色单像素宽空心矩形框，计算嵌套层数N（从外到内依次编号，最外层为第1层）。
2. 读取所有微型图例：每个图例的右像素为源色S，左像素为目标色T，表示映射S→T。将所有图例合并为一个颜色替换函数f（每种源色映射到一个目标色）。
3. 裁剪最内层框的内部区域，得到核心图案P（不含框本身）。
4. 对P中每个像素的颜色，迭代应用映射f共N次：第1次将颜色C替换为f(C)，第2次将f(C)替换为f(f(C))，以此类推。若某颜色不在映射中（f未定义该色），则该颜色在该次迭代中保持不变。
5. 输出为经过N次迭代后的图案P（尺寸与最内层框内部相同），不含任何框和图例。

**关键洞察**：嵌套框的几何结构不参与最终输出的图形内容，而是编码了一个数值参数（迭代次数）；当映射形成循环（如2色互换）时，偶数层和奇数层产生不同结果——需要多个不同嵌套深度的示例才能归纳此规则。

## 新题 8：对角拼接涌现封闭区域内双色互换

**组合逻辑**：[拼接+对角排布](原图对角复制形成新拓扑) → [封闭区域检测](识别因拼接涌现的新封闭空间) → [双色互换](仅在新封闭区域内执行颜色交换)

**来源原语**：拼接(concatenate, 参考题7), 对角排布(diag_layout, 参考题7), 封闭区域(enclosed_region, 参考题8), 内部包含(interior_containment, 参考题8), 双色互换(two_color_swap, 参考题10), 仅交换两色(swap_two_colors_only, 参考题10), 对角副本(diag_copy, 参考题7), 分隔行(separator_row, 参考题7)

**依赖链**：原始图案对角拼接为2x2布局 → 拼接使原本开放的形状在接缝处形成新的封闭区域 → 检测这些仅因拼接才出现的封闭区域 → 在封闭区域内部执行指定的双色互换 → 非封闭区域像素保持不变。删除拼接则封闭区域不存在；不做封闭检测则无法确定交换范围；不做颜色交换则输出与简单拼接无区别。

对角复制原图后，在因拼接而新涌现的封闭区域内交换两种指定颜色。

**输入结构**：黑(0)背景上约8x8网格。红(2)和蓝(1)色像素组成若干不规则前景结构（总前景像素约15~25个）。关键约束：前景结构在原始8x8网格中不形成任何封闭黑色区域（所有黑色像素均可通过4-连通路径到达网格边界），但当网格被对角拼接为16x16画布后（左上和右下各放一份），两份副本在接缝处的前景像素恰好合围形成1~3个新的封闭黑(0)区域。生成约束：封闭区域面积各不少于2像素；封闭区域内同时包含因拼接产生的红(2)和蓝(1)相邻像素（保证交换可观察）。

**规则**：
1. 创建一个2H x 2W黑(0)画布（H、W为原始网格的高和宽）。
2. 将原始网格复制到左上角(0,0)~(H-1,W-1)区域，再复制到右下角(H,W)~(2H-1,2W-1)区域。其余区域保持黑(0)。
3. 在拼接后的画布上检测所有4-连通黑(0)封闭区域：即无法通过4-连通黑色路径到达画布边界的黑色连通分量。
4. 对每个封闭区域内的像素以及封闭区域边界上的前景像素（即与封闭区域4-邻接的非背景像素），执行颜色交换：红(2)→蓝(1)，蓝(1)→红(2)。
5. 不与任何封闭区域相邻的前景像素保持原色不变。

**关键洞察**：颜色交换的作用域不由输入中的任何标记定义，而是由拼接操作本身的几何后果决定——封闭区域是"涌现"的结构，单看原始网格完全无法预判哪些像素会被交换。

## 新题 9：三点定框后角点发射加帽射线

**组合逻辑**：[补全](三标记点定义空心矩形并绘制) → [射线延伸](从框的四角向最近边界发射对角射线) → [端帽](射线末端添加垂直帽标记) → [擦除](原始标记点涂回背景)

**来源原语**：补全(complete, 参考题2), 射线延伸(ray_extend, 参考题1/18), 端帽(cap, 参考题1), 擦除(erase, 参考题1), 标记像素(marker_pixel, 参考题2), 空心矩形(hollow_rect, 参考题2), 包围盒(bounding_box, 参考题2), 三点定矩形框(three_pts_define_rect, 参考题2), 投射到最近边界(projection_to_nearest_edge, 参考题19), 最近边界方向(nearest_boundary_direction, 参考题19)

**依赖链**：三标记点确定包围盒 → 绘制空心矩形框 → 框的四个角点各自确定其最近的网格角落方向 → 向该方向发射45度对角射线 → 射线到达边界时停止并在末端像素画3像素L形帽 → 最后擦除原始标记点恢复为背景。每步的输入都依赖前步的输出几何。

由三个标记点推断矩形框，框的四角各射一条对角线至最近网格角，射线末端加L形帽。

**输入结构**：黑(0)背景上约15x15网格。恰好3个红(2)色孤立像素作为标记点，它们的包围盒定义一个矩形（三点分别位于该矩形边界的三个不同边或角上）。蓝(1)不出现在输入中，作为矩形框颜色；绿(3)不出现在输入中，作为射线和帽颜色。生成约束：包围盒至少4x4大小；矩形框四角到各自最近网格角的对角路径上无其他前景像素遮挡；框的四角距最近网格角至少2像素（保证射线长度>=2）。

**规则**：
1. 计算三个红(2)标记点的包围盒（最小外接矩形）。
2. 用蓝(1)色绘制该包围盒的空心矩形边框（1像素宽），保留红(2)标记点在框上的位置（标记覆盖框）。
3. 确定矩形框的四个角坐标。对每个角(r,c)，确定离它最近的网格角落（左上(0,0)/右上(0,W-1)/左下(H-1,0)/右下(H-1,W-1)），以此确定对角射线方向（如框角在左上区域则射向左上，即行列各减1）。
4. 从每个框角出发，沿确定的对角方向逐像素绘制绿(3)色射线，直到射线像素到达网格边界行或边界列为止（含边界像素）。
5. 在每条射线的末端像素处，绘制一个绿(3)色3像素L形帽：保留末端像素，加上沿射线方向的水平反弹1像素和垂直反弹1像素（即从末端向两个正交方向各延伸1像素，形成L形）。若帽像素超出网格则忽略该像素。
6. 将三个原始红(2)标记点擦除为黑(0)背景。

**关键洞察**：标记点的作用在第一步就消耗完毕（确定矩形后被擦除），后续的射线方向完全由矩形角点在网格中的相对位置决定——需要对比不同位置的矩形示例才能归纳出"射向最近网格角"的方向规则而非固定的对角方向。

## 新题 10：推移后排序匹配调色板配合单像素异常重涂

**组合逻辑**：[推移](对象弹射到边界) → [顺序一一对应](按终点位置排序后匹配调色板) → [重涂色](按对应关系重涂) → [尺寸分类+异常处理](单像素对象使用特殊规则)

**来源原语**：推移(push, 参考题4), 重涂色(recolor, 参考题6/11), 调色板列(palette_column, 参考题6), 顺序一一对应(order_correspondence, 参考题6), 接触侧决定方向(contact_side_dir, 参考题4), 推至边界停止(stop_at_boundary, 参考题4), 固定标记(fixed_marker, 参考题4), 尺寸分类(size_classification, 参考题11), 单像素分量重涂(single_pixel_component_recolored, 参考题11), 按列段分组匹配(column_run_group_match, 参考题6)

**依赖链**：标记接触侧决定推移方向 → 推移确定各对象最终位置 → 最终位置的排列顺序建立与调色板的一一对应 → 对应关系决定重涂颜色 → 但单像素对象跳出正常队列使用调色板末位颜色。删除推移则排序无依据；删除调色板则重涂颜色不确定；删除尺寸异常规则则单像素对象的输出不确定。

对象弹射至边界后按落点排序匹配调色板颜色，但单像素对象统一取调色板末色。

**输入结构**：黑(0)背景上约14x16网格。左侧第0列为调色板列：从上到下依次有3~5个不同颜色像素（如绿(3)、黄(4)、品红(6)、橙(7)），每两个调色板像素之间间隔1~2行黑色。网格右侧区域有栗(9)色固定标记（约4~6像素的紧凑团块）。3~5个灰(5)色前景对象分布在标记周围，每个对象为2~6像素的4-连通形状，且每个对象恰有一侧与标记相邻。其中恰好有1个对象为单像素。生成约束：调色板颜色数 = 前景对象数（含单像素对象）；不同对象接触标记的不同侧面；推移后各对象互不重叠。

**规则**：
1. 读取左侧调色板列中从上到下的颜色序列P1, P2, ..., Pk。
2. 识别栗(9)标记和所有灰(5)前景对象。对每个对象判定其接触标记的方向侧，确定推移方向（背离标记）。
3. 将每个对象沿推移方向平移至网格边界（前缘贴边），记录最终位置。清除对象原始位置。标记保持不变。
4. 将非单像素的对象按最终位置的主轴坐标排序（若推移方向为水平则按最终位置列坐标升序；若为垂直则按行坐标升序；混合方向时统一按行优先、列次之排序）。
5. 排序后第1个非单像素对象重涂为P1，第2个为P2，...，依次对应。
6. 所有单像素对象（无论最终位置如何）统一重涂为调色板末位颜色Pk。
7. 调色板列在输出中擦除为黑(0)背景。

**关键洞察**：单像素对象不参与正常的位置排序队列，而是无条件绑定到调色板末位——这个尺寸异常规则打破了看似简单的"排序=对应"映射，只有在示例中出现单像素对象的位置在排序中"应该"对应非末位颜色时才能发现此例外。
