## 新题 1：嵌套框缺口渗透与穿墙着色

**组合逻辑**：[泛洪填充](创新：穿越有缺口的框架墙) + [重涂色](创新：填充色由最后穿越的墙色决定) ← 约束于 [嵌套层次] + [可达性]

**来源原语**：泛洪填充/flood_fill（b9e38dc0）、重涂色/recolor（8dae5dfc）、嵌套矩形层/nested_rect_layer（8dae5dfc）、封闭区域/enclosed_region（ac6f9922）、可达性/reachability（dd6b8c4b）、填充种子/fill_seed（b9e38dc0）

**依赖链**：泛洪填充确定每个封闭环形区域是否可达；可达区域的填充颜色取决于洪水最后穿越了哪层框架墙的颜色，两者缺一不可——没有泛洪则无法判断可达性，没有穿墙着色规则则无法确定颜色。

从种子像素出发泛洪穿越嵌套框架墙的缺口，每个被洪水抵达的环形区域用最后穿越的墙色填充。

**输入结构**：约 14x14 的黑(0)背景网格。中央有三层同心矩形框架，每层 1 像素厚，颜色各不相同（外层红(2)、中层绿(3)、内层蓝(1)）。每层框架恰有一个 1 像素的缺口（开口），三个缺口分布在不同的边上（例如外层缺口在顶边、中层缺口在左边、内层缺口在底边）。在最外层框架之外的黑色区域中放置一个黄(4)种子像素。生成约束：三层框架严格嵌套不相交；每层缺口位置保证从种子出发存在至少一条连通路径可达最内层。

**规则**：
1. 从黄(4)种子像素出发，对黑(0)背景像素执行 4-连通泛洪填充。洪水可以穿过框架墙上的 1 像素缺口进入内部区域，但不能穿过框架墙本身（非缺口的框架像素视为不可通行）。
2. 对每个被洪水抵达的封闭环形区域（两层相邻框架之间的黑色空间），将该区域的所有黑(0)像素重涂为洪水最后穿越的那层框架墙的颜色。"最后穿越"指：从种子到该区域的任意 4-连通最短路径上，最后经过的那个缺口所属框架的颜色。若最短路径不唯一但最后穿越的框架层相同，则颜色唯一确定（生成时保证此条件成立）。
3. 最内层框架围成的核心区域若被洪水抵达，同样使用最后穿越的框架墙（即内层蓝(1)框架）的颜色填充。
4. 框架墙像素本身保持不变。黄(4)种子像素保持不变。不可达的区域保持黑(0)。

**关键洞察**：洪水从外向内逐层渗透时，缺口在不同边上意味着洪水可能沿不同路径穿越不同数量的墙——有时外层和中层缺口在同侧导致洪水直接穿透两层，此时中间环形区域的"最后穿越墙"仍是外层墙（洪水是沿缺口直线进入的），而非中层墙。必须对比多个示例中缺口的不同排布才能归纳出"最后穿越"规则，而非简单的"第 N 层区域用第 N 层颜色"。

## 新题 2：对角印章的描边扩展与光晕碰撞

**组合逻辑**：[印章覆盖](已有) → [描边/拉伸](创新：对每个印章副本执行单层描边) → [擦除](创新：不同来源的描边光晕相交处消去为黑)

**来源原语**：印章覆盖/stamp（e619ca6e）、描边/outline+拉伸/extrude（49d1d64f）、擦除/erase（3bdb4ada）、实心矩形/solid_rect（e619ca6e）、对角偏移重复/diag_offset_repeat（e619ca6e）、尺寸决定步幅/size_determines_stride（e619ca6e）、边缘延伸角落留黑/edge_extrude_corner_black（49d1d64f）

**依赖链**：印章生成空间格点分布 → 描边在每个印章周围扩展一圈光晕 → 不同来源矩形的光晕在空间中产生干涉区，干涉区像素被擦除。三步紧耦合：没有印章就没有格点分布，没有描边就没有光晕碰撞的可能，没有擦除规则就无法处理光晕重叠。

两种不同尺寸的矩形各自沿对角线印章复制并加描边光晕，不同来源的光晕相交处消去为黑色。

**输入结构**：约 18x18 的黑(0)背景网格。包含两个实心矩形，颜色不同（例如红(2)矩形约 2x3，绿(3)矩形约 3x2），位置互不重叠。生成约束：两个矩形的对角印章轨迹至少存在一处光晕交叉区域；矩形本体和印章副本互不重叠（仅光晕可重叠）。

**规则**：
1. 对每个矩形，沿两条下行对角线方向印章复制自身：高度为 h、宽度为 w 的矩形，在偏移 (kh, -kw) 和 (kh, kw)（k=1,2,3,...）处各复制一份，超出网格的部分裁剪，完全出界后停止（与 e619ca6e 相同）。原始矩形保留。
2. 对每个印章副本（含原始矩形），执行 1 像素的向外描边：将该矩形四条边向外延伸 1 像素，用该矩形的颜色填充延伸的边缘像素；四个新角落像素保持黑(0)（与 49d1d64f 相同）。
3. 碰撞消去：若一个像素同时处于来自不同颜色矩形的描边光晕范围内（即该像素被两个不同来源的描边覆盖），则该像素擦除为黑(0)。矩形本体和印章副本的实心区域不参与消去——仅描边光晕像素可被消去。
4. 处理顺序：先完成所有印章和描边的计算（标记每个描边像素的来源），再统一执行消去。同一来源的多个副本的光晕互相重叠时不消去。

**关键洞察**：两个矩形的对角印章形成两个不同步长的空间格点，它们的描边光晕在空间中产生类似摩尔纹的干涉图案。碰撞消去的位置完全由两个矩形的尺寸差异和初始位置关系决定——改变任一矩形的尺寸或位置会导致完全不同的消去图案。需要对比多个示例才能确认消去规则是"不同来源光晕交叉"而非其他几何规则。

## 新题 3：签名匹配补全与象限约束消歧

**组合逻辑**：[模板提取](已有) + [旋转](已有) + [补全](创新：象限位置提供额外约束，解决签名匹配的多义性)

**来源原语**：模板提取/template_extraction（79369cc6）、旋转/rotate（ed98d772）、补全/completion（79369cc6）、矩形模板/rectangular_template（79369cc6）、变换副本/transformed_copy（79369cc6）、对齐签名匹配/alignment_signature_matching（79369cc6）、旋转反射等价/rotation_reflection_equivalence（79369cc6）、阵列排布/array_layout（ed98d772）

**依赖链**：模板提取获取完整双色模板 → 签名匹配在其他象限定位不完整副本的候选朝向 → 象限位置规则消除匹配歧义确定唯一朝向 → 补全缺失像素。签名匹配与象限约束同时作用于朝向判定，缺一不可。

提取模板后，利用品红签名定位各象限的不完整副本，当签名匹配存在多义时由象限位置规则消歧，最终补全缺失的黄色像素。

**输入结构**：约 16x16 的黑(0)背景网格，逻辑上分为 2x2 的四个象限（无显式分隔线，以网格中心为界）。一个象限包含完整的小型双色矩形模板（约 3x4），由黄(4)和品红(6)像素紧密排列组成，模板内两种颜色的分布不具有 90 度旋转对称性但具有某种反射对称性（使得至少存在两个不同的旋转/反射朝向产生相同的品红子图案）。其余三个象限各包含一份不完整副本：仅品红(6)像素可见，黄(4)像素缺失。生成约束：模板的品红子图案在至少一个旋转/反射朝向下与另一个朝向的品红子图案完全相同（制造歧义）；三个不完整副本的朝向两两不同。

**规则**：
1. 从包含黄(4)像素的象限提取完整模板（该象限是模板所在象限）。模板的边界框由所有黄(4)像素的最小包围矩形确定。
2. 对每个其他象限，将其中的品红(6)像素图案与模板的所有 8 种旋转/反射变体的品红子图案进行匹配，找出所有匹配的朝向。
3. 若某象限的品红图案匹配了多个朝向（歧义），则使用象限位置规则消歧：以模板所在象限为起点，按顺时针方向依次为相邻象限分配旋转角度——顺时针下一个象限为 90 度顺时针旋转，对角象限为 180 度旋转，逆时针下一个象限为 90 度逆时针旋转。在歧义候选中选择符合该象限指定旋转角度的那个朝向。
4. 确定朝向后，在对应位置补全缺失的黄(4)像素。超出网格边界的黄色像素直接丢弃。所有已有像素（品红和黑色背景中的非补全区域）保持不变。

**关键洞察**：品红签名匹配在大多数情况下能唯一确定朝向，但当模板具有部分对称性时会产生歧义；此时象限位置隐式编码了旋转角度，充当第二重约束。求解者必须同时掌握签名匹配和象限旋转规则才能正确补全所有副本——仅靠其中一条规则会在某些副本上出错。

## 新题 4：框内镜像触发走廊泛洪链

**组合逻辑**：[镜像](创新：镜像结果是否触及缺口决定后续泛洪) + [泛洪填充](创新：沿走廊链式传播) ← 约束于 [宽高比决定镜像轴] + [开口方向] + [链式连接]

**来源原语**：镜像/mirror（93c31fbe, 6855a6e4）、泛洪填充/flood_fill（b9e38dc0）、矩形框/rectangular_frame（93c31fbe）、内部图案/internal_pattern（93c31fbe）、走廊通道/corridor（3ad05f52）、链式连接/chain_linkage（84551f4c）、宽高比决定镜像轴/aspect_ratio_mirror_axis（93c31fbe）、开口方向/opening_direction（b9e38dc0）

**依赖链**：框架宽高比决定镜像轴方向 → 镜像操作生成新的蓝色像素 → 新像素是否触及框架墙上的缺口决定泛洪是否启动 → 启动的泛洪沿走廊传播到相邻框架内部。每一步的输出都是下一步的前提条件，形成条件触发链。

根据框架宽高比镜像内部蓝色图案，若镜像结果触及框架缺口则蓝色沿走廊泛洪传播至相邻框架。

**输入结构**：约 18x18 的黑(0)背景网格。包含三个不重叠的彩色矩形框架（各约 5x7 或 7x5，1 像素厚，每个框架颜色不同，例如红(2)、绿(3)、灰(5)），两两之间由 1 像素宽的黑色走廊连通（走廊从一个框架墙上的 1 像素缺口延伸到另一个框架墙上的 1 像素缺口）。每个框架内部有一组蓝(1)像素（3-6 个像素组成的 4-连通小图形），位于框架内部的一侧（不在中心线上，不触及任何框架墙）。生成约束：三个框架通过走廊形成一条链（A—B—C）；每个框架恰有参与走廊连接的缺口（链端框架 1 个缺口，链中框架 2 个缺口）；至少一个框架的镜像结果会触及缺口、至少一个不会触及。

**规则**：
1. 对每个框架独立执行镜像：宽度 > 高度的框架（宽框）将内部蓝(1)像素沿框架垂直中心线左右镜像；高度 > 宽度的框架（高框）将内部蓝(1)像素沿框架水平中心线上下镜像。镜像后保留原始蓝色像素和镜像副本。若框架为正方形，沿垂直中心线左右镜像。
2. 检查每个框架：镜像后的蓝色像素集合中是否存在至少一个像素与该框架墙上的某个缺口在 4-连通意义上相邻（即蓝色像素紧挨缺口的内侧）。
3. 若步骤 2 为"是"，则从该相邻蓝色像素出发，通过缺口沿走廊执行蓝(1)泛洪填充：走廊中的黑(0)像素被填充为蓝(1)，泛洪到达相邻框架的缺口后进入该框架内部，继续填充该框架内部的黑(0)像素（但不覆盖该框架已有的蓝色像素和框架墙像素）。泛洪在框架内部传播时遇到框架墙停止。
4. 若步骤 2 为"否"（镜像后蓝色像素不触及任何缺口），则该框架不向外泛洪，其内部仅保留镜像后的蓝色图案。
5. 泛洪的传播是链式的：如果框架 B 因接收了来自框架 A 的泛洪而内部被蓝色填充，那么框架 B 的蓝色像素（包括新填充的）同样检查是否触及框架 B 通往框架 C 的缺口，若触及则继续沿走廊向框架 C 传播。
6. 所有框架墙像素、走廊以外的黑色背景像素保持不变。

**关键洞察**：镜像操作本身不直接产生填充效果——它只改变蓝色像素的空间分布。但当镜像恰好把蓝色像素翻到了缺口旁边时，就"激活"了泛洪传播。哪些框架会被激活完全取决于其内部图案位置与缺口位置的镜像几何关系，而镜像轴又由宽高比决定。需要对比多个示例中不同宽高比和图案位置的组合才能归纳出完整规则。

## 新题 5：可达性筛选与链式旋转装配

**组合逻辑**：[聚集](创新：用泛洪可达性筛选候选条) + [旋转](创新：竖变横后按距离排序链式拼装) ← 约束于 [可达性] + [距离排序填充] + [链式连接] + [高度即宽度]

**来源原语**：聚集/gather（dd6b8c4b）、旋转/rotate（84551f4c）、擦除/erase（dd6b8c4b）、竖条/vertical_bar（84551f4c）、标记像素/marker_pixel（dd6b8c4b）、墙壁障碍/wall_barrier（dd6b8c4b）、链式连接/chain_linkage（84551f4c）、可达性/reachability（dd6b8c4b）、距离排序填充/distance_ranked_fill（dd6b8c4b）、高度即宽度/height_equals_width（84551f4c）

**依赖链**：泛洪可达性筛选出哪些竖条参与装配 → BFS 距离排序决定装配顺序 → 每根竖条旋转 90 度后链式拼接（高度变宽度）。可达性过滤、距离排序、几何旋转三者紧耦合：改变墙壁布局会改变可达集合和距离排序，进而改变最终装配结果。

从标记点出发泛洪筛选可达竖条，按距离排序后逐根旋转为横条并链式拼装在标记行上。

**输入结构**：约 16x16 的橙(7)背景网格。品红(6)像素构成若干段墙壁（水平或垂直的 1 像素厚线段，总计 10-20 个像素），将网格分为多个连通区域。网格中散布 4-6 根栗(9)色竖条（每根宽 1 像素，高 2-5 像素，底部对齐网格底边）。一个红(2)标记像素位于网格中部偏下。生成约束：至少 2 根竖条与红标记在同一连通区域（可达），至少 1 根不可达；可达竖条到红标记的 BFS 距离两两不同。

**规则**：
1. 在橙(7)背景上执行 4-连通泛洪，从红(2)标记像素出发，可通过橙(7)和栗(9)像素（即地板和竖条都可通行），品红(6)墙壁不可通行。记录所有被泛洪触及的栗(9)竖条为"可达竖条"。
2. 对每根可达竖条，计算其底部像素到红(2)标记的 4-连通 BFS 最短距离（通行规则同步骤 1）。按距离从小到大排序。
3. 擦除所有可达竖条的原始位置（替换为橙(7)背景）。不可达竖条保持原样不动。
4. 在红(2)标记像素所在行，从标记像素右侧第一个像素开始，按步骤 2 的排序依次将每根可达竖条旋转 90 度顺时针放置为横条：第一根竖条（最近）高度为 h1，则在标记行从起始列开始画 h1 个栗(9)像素向右延伸；第二根紧接第一根末尾继续画 h2 个像素；以此类推。若横条超出网格右边界则裁剪。
5. 红(2)标记像素保持不变。品红(6)墙壁保持不变。

**关键洞察**：墙壁不仅决定哪些竖条可达，还影响各竖条到标记的距离排序——绕墙路径可能让物理上较近的竖条在 BFS 距离上反而更远。最终链式拼装的段长序列编码了可达竖条的高度按距离排列的顺序，这个序列无法仅从竖条的空间位置直接推断。

## 新题 6：精灵宽高镜像与对角印章的面积优先叠印

**组合逻辑**：[镜像](已有：宽高比选轴) → [印章覆盖](已有：对角重复) + [重涂色](创新：重叠区域由源框面积决定优先级) ← 约束于 [宽高比决定镜像轴] + [尺寸决定步幅] + [最近邻归属]

**来源原语**：镜像/mirror（93c31fbe, 6855a6e4）、印章覆盖/stamp（e619ca6e）、重涂色/recolor（8dae5dfc）、矩形框/rectangular_frame（93c31fbe）、精灵体/sprite（ed98d772）、内部图案/internal_pattern（93c31fbe）、对角偏移重复/diag_offset_repeat（e619ca6e）、宽高比决定镜像轴/aspect_ratio_mirror_axis（93c31fbe）、尺寸决定步幅/size_determines_stride（e619ca6e）

**依赖链**：框架宽高比决定镜像轴 → 镜像生成完整对称图案 → 该图案作为印章精灵沿对角线以框架尺寸为步幅重复 → 不同框架来源的印章重叠时由框架面积（非印章面积）决定优先级。四个属性（宽高比、内部图案位置、框架尺寸、框架面积）分别控制不同环节，缺一不可。

各框架内精灵先按宽高比镜像成对称图案，再沿对角线以框架尺寸为步幅印章重复，重叠区域由面积更小的框架来源优先。

**输入结构**：约 18x18 的黑(0)背景网格。包含两个不重叠的单色矩形框架（1 像素厚），一个为宽框（例如红(2)，内部约 6x4，即宽 > 高），另一个为高框（例如绿(3)，内部约 4x6）。每个框架内部有一组蓝(1)像素（3-5 个像素的 4-连通小图形），放置在框架内部的一个象限中（不在中心线上）。生成约束：两个框架面积不同；对角印章轨迹至少有一处重叠。

**规则**：
1. 对每个框架，按宽高比确定镜像轴：宽框（内部宽度 > 内部高度）沿内部垂直中心线左右镜像蓝(1)像素；高框（内部高度 > 内部宽度）沿内部水平中心线上下镜像蓝(1)像素。镜像后得到框架内的完整对称蓝色图案。
2. 对每个框架，裁剪其内部区域（含对称后的蓝色图案和黑色背景，不含框架墙），得到一个矩形精灵。
3. 以每个框架的外边界框尺寸为步幅（高度 H、宽度 W），沿两条下行对角线方向印章复制该精灵：偏移 (kH, kW) 和 (kH, -kW)，k=1,2,...，超出网格部分裁剪，完全出界后停止。原始框架位置处也放置该精灵（覆盖框架墙）。
4. 重叠解决：当两个不同框架来源的印章在同一像素处重叠时，取源框架面积（外边界框面积）更小的那个来源的像素值。若两个框架面积相同（生成时避免此情况），取边界框左上角更靠近网格左上角的来源。
5. 非重叠区域直接绘制对应来源的像素值。背景像素（不被任何印章覆盖的区域）保持黑(0)。

**关键洞察**：宽高比决定了镜像方向，从而决定了精灵的对称结构——宽框产生左右对称图案、高框产生上下对称图案。但在印章重叠处，决定哪个图案"穿透"的不是图案本身的属性，而是源框架的面积——一个几何属性控制图案生成，另一个几何属性控制图案竞争，两者来自同一对象（框架）的不同维度。

## 新题 7：射线铺设墙壁后的受限寻路

**组合逻辑**：[射线延伸](创新：射线结果作为后续寻路的障碍物) → [寻路](创新：在射线修改后的空间中搜索最短路径) ← 约束于 [遇阻停止] + [最短路径] + [菱形框/框内填充]

**来源原语**：射线延伸/radiate（95755ff2）、寻路/pathfinding（3ad05f52）、菱形框/diamond_frame（95755ff2）、侧标记/side_marker（95755ff2）、阻挡像素/blocker_pixel（95755ff2）、最短路径/shortest_path（3ad05f52）、遇阻停止/stop_at_blocker（95755ff2）、框内填充/fill_inside_frame（95755ff2）

**依赖链**：侧标记的射线在菱形内部铺设彩色线段（遇阻挡像素停止） → 铺设的线段成为新的不可通行障碍 → 另一对侧标记之间的最短路径必须绕开这些新障碍。第一步的输出直接改变第二步的搜索空间拓扑，两步不可分离。

菱形框的一对侧标记射线铺设为新墙壁，另一对侧标记之间在修改后的菱形内部寻找最短路径。

**输入结构**：约 15x15 的黑(0)背景网格。一个完整的灰(5)菱形框（1 像素厚，顶点在边界框的四条边中点上）。菱形框外侧放置四个标记像素：左右两侧各一个红(2)标记（位于菱形边界框的水平中线与菱形边的交点外侧一格），上下两侧各一个绿(3)标记（位于菱形边界框的垂直中线与菱形边的交点外侧一格）。菱形内部有 2-3 个蓝(1)阻挡像素，分布在不同位置。生成约束：阻挡像素不在菱形框上、不在标记所在行或列的菱形内部入口处；红色射线被阻挡后留下的空隙足以让绿色路径通过（保证路径存在）。

**规则**：
1. 红(2)射线阶段：左侧红(2)标记向右发射水平射线，沿该行穿过菱形框进入菱形内部，将内部的黑(0)像素逐个涂为红(2)，遇到蓝(1)阻挡像素或菱形框像素时停止（不覆盖阻挡像素和框像素）。右侧红(2)标记向左发射水平射线，规则相同。两条红色射线可能在同一行相向而行——它们各自独立传播，直到各自遇到阻挡像素或框边界。
2. 空间更新：将步骤 1 中所有新涂的红(2)像素视为不可通行障碍（与蓝(1)阻挡像素和灰(5)菱形框像素同等对待）。
3. 绿(3)寻路阶段：从上方绿(3)标记出发，寻找到下方绿(3)标记的 4-连通最短路径。路径只能经过菱形严格内部的黑(0)像素（步骤 2 后剩余的未被占据的内部像素）。路径不经过菱形框、阻挡像素、红色射线像素或菱形外部。
4. 将最短路径上的所有像素涂为绿(3)。若存在多条等长最短路径，选择字典序最小的那条（将路径表示为 (row, col) 坐标序列，按序列的字典序比较）。
5. 所有其他像素（菱形框、阻挡像素、红色射线、标记像素、菱形外部背景）保持不变。

**关键洞察**：红色射线在菱形内部铺设的线段长度取决于阻挡像素的位置——阻挡像素离菱形边越远，射线越长，留给绿色路径的可通行空间越少。求解者必须先完成射线铺设（理解遇阻停止规则）才能确定寻路的搜索空间。两个操作共享同一组阻挡像素但以不同方式与之交互：阻挡像素停止射线（改变空间拓扑），同时也阻碍路径（作为路径障碍）。

## 新题 8：角落码对称展开与印章颜色调制

**组合逻辑**：[对称补全](已有：角落码展开同心框) + [印章覆盖](已有：对角重复) → [重涂色](创新：印章与展开后框架的空间交集决定印章像素颜色) ← 约束于 [对称展开] + [对角偏移重复] + [尺寸决定步幅]

**来源原语**：对称补全/symmetry_completion（9d9215db）、印章覆盖/stamp（e619ca6e）、重涂色/recolor（8dae5dfc）、角落编码/corner_code（9d9215db）、同心正方形层/concentric_square_ring（9d9215db）、实心矩形/solid_rect（e619ca6e）、对称展开/symmetric_unfolding（9d9215db）、对角偏移重复/diag_offset_repeat（e619ca6e）、尺寸决定步幅/size_determines_stride（e619ca6e）、角落码展开同心/corner_code_unfolds_concentric（9d9215db）

**依赖链**：角落码对称展开生成同心方形框架几何结构 → 实心矩形沿对角线印章生成重复图案 → 印章像素的最终颜色由其所在位置是否与同心框架像素重合决定（重合则吸收框架颜色，否则保持原色）。两个独立的图案生成过程通过空间交集产生耦合——单独看任一过程都无法预测最终输出。

角落码展开为同心方形框架，同时一个小矩形沿对角线印章重复；印章像素落在框架上时吸收框架颜色，产生颜色调制的重复图案。

**输入结构**：约 15x15 的奇数尺寸黑(0)背景网格。网格的一个角落区域（例如左上角）在奇数坐标格点上有稀疏的彩色前景像素（2-4 个像素，颜色各不相同，例如红(2)、绿(3)、蓝(1)），构成角落码（与 9d9215db 相同的编码方式）。另外，在远离角落码的位置（例如右下区域）有一个小的黄(4)实心矩形（约 2x2 或 2x3）。生成约束：角落码和实心矩形不重叠；角落码定义的同心框架数量为 2-3 层；矩形的对角印章轨迹与至少一层展开后的同心框架有空间交集。

**规则**：
1. 对称展开：按 9d9215db 的规则，从角落码的稀疏像素推断同心方形框架的颜色分配。对角线位置的像素定义该层四个角的颜色；水平/垂直方向的像素定义对应边的颜色。将角落码展开为完整的同心方形框架，框架像素绘制到网格上。
2. 对角印章：对黄(4)实心矩形执行对角印章——以矩形高度 h 和宽度 w 为步幅，在偏移 (kh, kw) 和 (kh, -kw)（k=1,2,...）处复制，超出网格裁剪，完全出界后停止。原始矩形保留。
3. 颜色调制：逐像素检查每个印章副本（含原始矩形）的每个像素位置。若该位置同时是步骤 1 中绘制的同心框架像素，则该印章像素的颜色替换为该框架像素的颜色（吸收框架色）。若该位置不是框架像素（为黑色背景或其他），则保持黄(4)不变。
4. 框架像素本身的显示规则：若某框架像素位置未被任何印章覆盖，则正常显示框架颜色。若被印章覆盖，则按步骤 3 规则显示（即该位置显示框架颜色——因为印章吸收了框架色，两者一致）。
5. 角落码的原始稀疏像素保持不变（它们同时也是展开后框架的一部分）。

**关键洞察**：同心框架和对角印章是两个独立的空间图案生成过程——框架从中心向外环形分布，印章沿对角线格点分布。它们的空间交集创造了颜色调制效果：重复的黄色印章在经过不同框架层时"染上"不同颜色，形成一种非均匀的周期图案。这个最终图案无法通过单独理解任一过程得出，必须同时理解两者并计算它们的空间叠加。
