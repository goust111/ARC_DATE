## 新题 1：重力堆叠生成行列十字射线

**组合逻辑**：[重力下落](创新：堆叠后每个落点变为十字射线源) → [行列交叉展开](创新：展开优先级由堆叠顺序决定) → [连线/射线延伸](已有)

**来源原语**：重力下落+碰撞停止+近墙优先结算(6ad5bdfd), 行列交叉+标记展为整行整列(8731374e), 连线(8731374e)

**依赖链**：重力堆叠决定各标记的最终位置和结算顺序 → 每个标记沿所在行和列展开成十字射线 → 结算顺序决定重叠区域的颜色优先级，三步缺一不可

将散落的彩色标记像素沿重力方向堆叠到边墙上，堆叠后每个标记展开为贯穿全行全列的十字射线，堆叠顺序决定射线重叠时的涂色优先级。

**输入结构**：约 15x12 的网格，黑(0)背景。底行为一条完整的红(2)边墙（占满底行所有列）。网格中散布 3~4 个孤立的单色标记像素，每个标记颜色互不相同，取自 {蓝(1), 绿(3), 黄(4), 橙(7)}。各标记分布在不同列、不同高度，互不共列。生成约束：任意两个标记不在同一列，各标记与红墙之间无其他非背景像素阻隔。

**规则**：
1. 所有标记像素沿垂直方向向红(2)边墙下落。按照各标记距边墙的距离由近到远依次结算——距墙最近的标记最先结算。每个标记垂直下移直到下方相邻格为红墙像素或已结算的标记像素时停止。记录结算顺序（第 1 个结算、第 2 个……）。
2. 所有标记结算完毕后，对每个标记像素进行行列展开：以该标记所在格为中心，将同一行的所有非红(2)非标记像素涂为该标记颜色，同时将同一列的所有非红(2)非标记像素涂为该标记颜色，形成贯穿网格的十字射线。
3. 展开按结算顺序执行：先结算的标记先展开。当后展开的标记的十字射线与先展开的射线在同一格重叠时，后展开的颜色覆盖先展开的颜色。
4. 红(2)边墙像素和标记像素本身始终保持原色，不被任何十字射线覆盖。

**关键洞察**：重力堆叠不只决定标记的终点位置——它隐式产生了一个结算时序，而这个时序恰好是十字射线重叠时的涂色优先级规则。距离墙最远（最后结算）的标记拥有最高的涂色优先级，因此其十字射线在所有交叉点处"赢"。需要对比多个示例才能区分"后结算者优先"和其他可能的优先级规则（如按颜色编号、按距离）。

## 新题 2：反弹射线分区 + 标记计数定周期填充

**组合逻辑**：[射线延伸+边界反射](已有) → [洪泛填充+排序](已有) → [计数匹配](创新：标记数量编码填充周期)

**来源原语**：射线延伸+边界反射+起点像素+反弹路径(e179c5f4), 洪泛填充+排序+区域排列顺序+等间隔采样填充(7447852a), 标记像素(8731374e), 计数匹配(6e4f6532)

**依赖链**：射线路径分割网格为多个封闭区域 → 区域按空间顺序编号 → 红色标记总数 K 定义填充周期 → 编号为 0, K, 2K, … 的区域被填充；射线决定分区拓扑，标记决定填充规则，缺一不可

从起点像素发出反弹对角射线将网格分区，统计散布的红色标记像素数量 K，每隔 K 个分区填充一次黄色。

**输入结构**：约 15x15 的网格，黑(0)背景。一个蓝(1)起点像素位于底行中的某一列（不在角落）。另有 K 个（K 为 2 或 3）孤立的红(2)标记像素散布在网格中，位置不在射线路径上。生成约束：起点位置保证射线在退出前至少产生 2 次反弹；K 值在不同示例中不同；红色标记不落在射线将经过的格上。

**规则**：
1. 从蓝(1)起点像素出发，沿右上方向（每步行 -1、列 +1）画蓝(1)对角线。当下一步列坐标越出网格左边界或右边界时，水平方向反转（列增量取反），继续前进。当下一步行坐标越出顶部边界时，射线停止（起点和路径上所有经过的格均标为蓝(1)）。
2. 蓝色射线路径将网格分割为若干 4-连通的黑(0)封闭区域（射线像素和红标记像素不属于任何区域）。将这些区域按各区域最左列排序，最左列相同时按最上行排序，依次编号 0, 1, 2, …。
3. 统计网格中红(2)标记像素的总数 K。
4. 对编号为 0, K, 2K, 3K, … 的区域（编号不超过总区域数），将该区域内所有黑(0)像素洪泛填充为黄(4)。
5. 蓝色射线像素、红色标记像素及未被选中的黑色区域保持不变。

**关键洞察**：红色标记像素的空间位置对输出无任何影响——它们的唯一作用是通过数量编码填充周期 K。求解者必须意识到标记的"有多少个"比"在哪里"重要。需要至少两个不同 K 值的示例才能确认周期由标记计数决定，而非固定常数。

## 新题 3：颜色配对选精灵 + 象限位置定旋转

**组合逻辑**：[标记颜色配对](创新：配对结果决定象限分配) → [旋转](创新：旋转角度由目标象限位置唯一确定) → [平移+印章覆盖](已有) → [擦除](已有)

**来源原语**：标记颜色配对+标记色匹配精灵(414297c0), 旋转+四象限各不同旋转+象限(cf5fd0ad), 平移+擦除(6e4f6532), 标记像素(8731374e)

**依赖链**：标记颜色匹配将每个精灵分配到唯一象限 → 象限位置决定旋转角度 → 旋转后的精灵印章覆盖到标记位置 → 原位擦除；配对决定去向，去向决定旋转，缺一不可

四个象限各含一个颜色标记，四个外部精灵各带一种标记色；按颜色配对将精灵送入对应象限，再按象限位置施加固定旋转后印章到标记处。

**输入结构**：约 16x16 的网格，黑(0)背景。一条灰(5)水平线和一条灰(5)垂直线交叉于网格中心，将网格均分为四个象限。每个象限内恰好有一个孤立的标记像素，四个标记颜色互不相同，取自 {蓝(1), 红(2), 绿(3), 黄(4)}。在网格的四个边缘区域（紧贴边界、不跨越灰线），各有一个由 3~6 像素组成的 4-连通单色小精灵体，每个精灵的颜色恰好等于某个象限内标记像素的颜色，形成一一对应。生成约束：四个精灵形状各不相同；精灵不与灰线相邻；每个精灵的边界框不超过 3x3。

**规则**：
1. 将每个精灵与颜色相同的象限标记配对——精灵的目标象限即为包含同色标记的象限。
2. 根据目标象限位置确定旋转角度：左上象限 → 180 度旋转，右上象限 → 顺时针 90 度旋转，左下象限 → 逆时针 90 度旋转，右下象限 → 不旋转（0 度）。
3. 将旋转后的精灵平移至目标象限，使精灵的边界框中心对齐到该象限标记像素所在位置。若对齐后精灵部分像素落在灰线上或越出象限边界，则向象限内部方向平移最小整数格数使精灵完全在象限内部且不覆盖灰线。
4. 在目标位置绘制旋转后的精灵（保持精灵原色），覆盖该位置原有的黑色背景。标记像素被精灵覆盖时，标记像素消失。
5. 擦除精灵原始位置的所有像素（恢复为黑(0)）。灰(5)十字线保持不变。

**关键洞察**：每个标记像素同时编码两个信息：通过颜色匹配决定哪个精灵来此象限，通过自身位置决定精灵的落点。象限位置隐式编码了旋转规则——求解者需要对比多个示例才能确认四个象限的旋转角度分配方案（180/90CW/90CCW/0），而非按颜色或其他属性分配旋转。

## 新题 4：障碍物阻断对称补全 + 残缺形态重力沉降

**组合逻辑**：[对称补全+标记定义双轴镜像](创新：障碍物选择性阻断反射) → [重力下落+邻接阻挡](创新：作用于不完整对称体)

**来源原语**：对称补全+标记方块+对称中心+标记定义双轴镜像(4938f0c2), 重力下落+障碍物+邻接阻挡(825aa9e9), 擦除(6e4f6532)

**依赖链**：尝试四折对称补全 → 障碍物阻断部分反射像素 → 产生不完整对称形态 → 对该残缺体施加重力 → 最终布局既非完全对称也非简单下落；对称规则和障碍分布共同决定中间形态，中间形态和重力共同决定终态

以 2x2 标记方块为中心尝试四折镜像补全前景像素，但障碍物像素所在位置阻止反射落点，产生残缺对称体后再对所有前景像素施加重力下落。

**输入结构**：约 14x14 的网格，黑(0)背景。网格中部偏上有一个绿(3) 2x2 实心方块作为对称中心标记。以该方块中心为原点，红(2)前景像素分布在一到两个象限区域内（3~8 个像素的 4-连通或分散排列，不与绿方块相邻）。在其他象限区域中散布若干橙(7)障碍物像素（2~4 个，孤立分布）。生成约束：至少一个红色像素的某个反射像素恰好落在障碍物所在格上；绿方块不在网格最底行附近（至少与底部间隔 4 行以上）。

**规则**：
1. 以绿(3) 2x2 方块的几何中心（四格交汇点）为对称中心，对每个红(2)像素计算其水平镜像、垂直镜像、180 度旋转镜像共三个反射位置。
2. 对每个反射位置：如果该位置为黑(0)背景，则放置红(2)像素；如果该位置已有橙(7)障碍物像素，则该反射被阻断，不放置任何像素；如果该位置已有红(2)像素，则保持不变。
3. 对称补全完成后，擦除所有橙(7)障碍物像素（恢复为黑(0)）。
4. 对网格中所有红(2)像素（原始 + 成功反射的）施加重力：逐列处理，每列中所有红像素向下滑动，在该列中紧密堆叠到网格底行。多个红像素在同列时彼此紧邻地堆叠。
5. 绿(3)方块保持原位不动，不参与重力。若有红像素下落路径经过绿方块所占格，该红像素停在绿方块正上方。

**关键洞察**：障碍物不是阻挡运动（与 825aa9e9 不同），而是阻挡对称反射——它在对称补全这一"生成"步骤中起到选择性删除的作用，导致中间形态并非真正四折对称。之后重力进一步打破残留的局部对称。最终输出既不能从纯对称推导，也不能从纯重力推导，必须理解"障碍阻断反射"这一非显然规则。需要多个示例（障碍物在不同位置）才能确认是"障碍位置阻断反射"而非"某些象限不参与反射"。

## 新题 5：框架尺寸定缩放 + 互补掩码印章

**组合逻辑**：[像素放大](创新：缩放倍数由外部框架决定而非固定) → [自身互补+前景位置放置瓦片](创新：互补掩码在非固定倍率下印章) → [裁剪+包含于框架内](已有)

**来源原语**：像素放大+框内尺寸决定缩放+空心矩形+包含于框架内(6b9890af), 自身互补+前景位置放置瓦片+互补掩码(0692e18c), 裁剪(8731374e)

**依赖链**：框架内边长 / 图案边长 → 缩放倍率 S → 前景像素位置选出 SxS 块 → 互补掩码（黑色位置）作为印章填入选中的块 → 裁剪到框架范围；框架几何、图案内容、互补逻辑三者共同决定输出

一个小 NxN 图案的前景像素位置选定输出中的大块，每个选中的大块内填入该图案的互补掩码（背景位置的形状），缩放倍率由红色空心框架的内部尺寸决定，输出裁剪到框架范围。

**输入结构**：约 20x20 的网格，黑(0)背景。网格中有一个红(2)空心正方形框架（单像素宽边框，内部全黑），框架内边长为 3S（S 为正整数，S >= 2）。网格其他位置（不与框架重叠）有一个 3x3 的小图案，由蓝(1)前景像素和黑(0)背景像素组成，蓝像素数量在 2~5 之间。生成约束：框架内边长是 3 的整数倍；3x3 图案至少有 2 个蓝像素和 2 个黑像素。

**规则**：
1. 计算缩放倍率 S = 框架内边长 / 3。
2. 提取 3x3 图案的互补掩码：将图案中黑(0)位置记为 1（印章内容），蓝(1)位置记为 0（空位）。互补掩码本身是一个 3x3 的二值模板。
3. 将框架内部划分为 3x3 = 9 个 SxS 子块（行优先，左上到右下）。
4. 对于 3x3 图案中每个蓝(1)前景像素所在位置 (i,j)，在框架内部对应的第 (i,j) 个 SxS 子块中，将互补掩码缩放 S 倍后以蓝(1)绘制（互补掩码中为 1 的位置画蓝，为 0 的位置留黑）。
5. 对于 3x3 图案中每个黑(0)位置 (i,j)，框架内部对应的 SxS 子块保持全黑。
6. 输出为框架及其内部区域的裁剪结果（包含红色边框）。

**关键洞察**：3x3 图案同时扮演三个角色——它是粗粒度的放置掩码（前景位置选块）、是细粒度的印章模板（互补掩码填充块内部）、也是缩放计算的参数之一。框架提供的不只是输出范围，更隐式编码了缩放倍率。求解者必须发现"前景选位 + 互补印章"这对自引用关系，同时从框架尺寸推断缩放因子。

## 新题 6：对齐比较分叉射线方向

**组合逻辑**：[对齐比较+颜色匹配定去向](创新：匹配结果不决定平移方向而决定射线延伸方向) → [射线延伸+同列传播](创新：向上或向下由条件分支选择)

**来源原语**：对齐比较+颜色匹配定去向+分隔线+参考像素+源像素(7d7772cc), 射线延伸+同列传播+沿列填至底(d037b0a7), 填充(d037b0a7)

**依赖链**：逐列比较源像素与参考像素的颜色 → 匹配结果（相同/不同）决定射线方向（向下/向上） → 每列独立执行单方向射线延伸；比较结果是方向选择的充要条件，缺少比较则方向不确定，缺少射线则比较无可见效果

分隔线将网格分为参考区和源区，每个源像素与同列参考像素比色：颜色相同则向下延伸射线填至底部，颜色不同则向上延伸射线填至分隔线。

**输入结构**：约 12x15 的网格，黑(0)背景。一条灰(5)水平分隔线横贯网格某一行（约在网格垂直方向 1/3 处），将网格分为上方较窄的参考区和下方较宽的源区。参考区中紧邻分隔线上方一行有若干彩色参考像素（颜色取自 {蓝(1), 红(2), 绿(3), 黄(4)}），每个占据不同列，其余位置为黑(0)。源区中在分隔线下方间隔 2~3 行处有一行彩色源像素，与参考像素一一对应占据相同列，颜色从相同色板中取（有些与对应参考匹配，有些不匹配）。生成约束：参考像素和源像素数量相同且占据完全相同的列集合；至少有一个匹配对和一个不匹配对。

**规则**：
1. 灰(5)分隔线和参考像素保持不变。
2. 对每个源像素，找到同列的参考像素，比较两者颜色。
3. 若颜色相同：该源像素向下延伸——从源像素所在行开始，向下（含源像素自身）将该列所有格涂为源像素颜色，直到网格底行（含）。
4. 若颜色不同：该源像素向上延伸——从源像素所在行开始，向上（含源像素自身）将该列所有格涂为源像素颜色，直到分隔线所在行的下一行（即不覆盖分隔线本身，停在分隔线正下方一格）。
5. 没有源像素的列保持不变。各列的射线互相独立，不存在列间覆盖冲突。

**关键洞察**：参考像素行是一张只读查找表，它不参与任何空间变换——它的唯一作用是为每列提供一个"目标颜色"以决定射线方向。求解者必须发现颜色相等性是一个条件分支（匹配→向下，不匹配→向上），而非过滤器或排序依据。需要多个示例才能排除其他可能的方向规则（如按颜色本身分组、按位置奇偶等）。

## 新题 7：间隙补填完成分区线 + 带内对称检测重涂色

**组合逻辑**：[填充(间隙补填)](创新：补填不是最终操作而是构建分区边界的前置步骤) → [洪泛填充(隐式分区)](创新：完成的线段定义封闭区域) → [镜像对称检测+重涂色](创新：对称性判断的作用域由动态生成的分区决定)

**来源原语**：填充+单像素间隙补填+虚线段+邻接(a699fb00), 洪泛填充+封闭区域+区域排列顺序(7447852a), 镜像对称+重涂色+镜像配对则涂色(ce039d91)

**依赖链**：虚线间隙补填 → 连续线段形成水平隔板 → 隔板划分出若干水平带 → 每带内独立判断灰色像素是否水平镜像对称 → 对称带内灰色重涂为绿色；间隙不补则隔板不完整导致带合并、对称判断域改变、输出错误

补填蓝色虚线的单像素间隙形成完整水平隔板，隔板将网格分为若干水平带，检测每带内灰色前景像素的水平镜像对称性：对称则重涂为绿色，不对称则保持灰色。

**输入结构**：约 13x13 的网格，黑(0)背景。2~3 条水平虚线由蓝(1)像素组成，横贯网格（从第 0 列到最后一列），虚线中蓝像素之间有单像素黑间隙（即蓝-黑-蓝-黑-蓝……的模式），不同虚线位于不同行。虚线之间（以及虚线与网格上下边界之间）形成水平带区域，每个带内散布若干灰(5)前景像素（每带 3~7 个像素），构成小型不规则图案。生成约束：每条虚线横贯整行（若间隙补满则成为完整横线）；至少一个带的灰色像素关于该带水平中线（即 (带最左列 + 带最右列) / 2 对应的垂直轴）构成镜像对称，至少一个带不对称。

**规则**：
1. 扫描每一行：对于任何黑(0)像素，若其左邻和右邻均为蓝(1)像素，则将该黑像素涂为红(2)。这一步将所有虚线的单像素间隙补填，使虚线成为连续的水平线段。
2. 补填后的完整蓝+红水平线将网格分为若干水平带（被线段隔开的连通黑色区域）。自上而下编号。顶部边界到第一条完整线之间为第一带，两条线之间为中间带，最后一条线到底部边界为最后一带。
3. 对每个水平带，提取该带内所有灰(5)像素的位置集合。计算该带的垂直对称轴：轴位于网格列范围 [0, W-1] 的中线处（即列 (W-1)/2.0，W 为网格宽度）。
4. 检验灰色像素集合是否关于该垂直轴呈镜像对称——即对每个灰像素 (r,c)，镜像位置 (r, W-1-c) 也必须是灰像素。
5. 若某带的灰色像素完全镜像对称：将该带内所有灰(5)像素重涂为绿(3)。
6. 若某带的灰色像素不对称：保持灰(5)不变。
7. 蓝(1)线段像素和红(2)补填像素保持不变。

**关键洞察**：虚线间隙看似只是视觉噪声，实际上它们是"未完成的分区边界"。如果不补填间隙，相邻的带会通过间隙连通，合并为一个更大的区域，导致对称判断的作用域错误。间隙补填是分区正确性的先决条件，分区正确性是对称判断的先决条件。三层操作通过"作用域"紧密耦合。

## 新题 8：计数配对对接 + 对接体镜像补全

**组合逻辑**：[计数匹配](已有) → [旋转+翻转+平移](创新：朝向由最近边界决定而非标记色) → [对称补全](创新：对称轴由对接位置动态决定) → [擦除](已有)

**来源原语**：计数匹配+精灵体+标记像素(6e4f6532), 旋转+翻转+平移+擦除+标记色定朝向(6e4f6532), 对称补全+对称中心+镜像(4938f0c2)

**依赖链**：精灵的耦合器数量匹配站点尺寸 → 对接确定精灵最终位置 → 位置所在区域的最近网格边界决定朝向 → 对接后的复合体以站点中心行/列为轴执行单轴镜像补全；计数→位置→朝向→补全，每步输出是下一步的输入参数

精灵通过耦合器数量与站点尺寸匹配后对接，旋转朝向由站点最近的网格边决定，对接后的复合体沿站点中心轴镜像补全。

**输入结构**：约 18x18 的网格，黑(0)背景。2~3 个"站点"：各为一组孤立的栗(9)像素簇（2~3 像素的 4-连通小块），站点之间距离较远且不与任何青色像素相邻。2~3 个"精灵"：各为一个由青(8)像素构成的 4-连通形状（4~8 像素），精灵边缘附带若干栗(9)"耦合器"像素（与青体 4-邻接但不与其他精灵相邻）。每个精灵上还有恰好一个绿(3)像素作为朝向标记（与青体 4-邻接）。每个精灵的耦合器数量恰好等于某一个站点的像素数量，形成一一配对。生成约束：各精灵的耦合器数量互不相同；站点位置保证对接后精灵不会超出网格边界；每个站点距某一条网格边明显更近（该边与其他边的距离差至少 3 格）。

**规则**：
1. 识别站点（不与任何青(8)像素相邻的栗(9)连通块）和精灵（包含青(8)的连通体，附带栗(9)耦合器和绿(3)标记）。
2. 对每个精灵，统计其耦合器（栗(9)像素）数量，与站点像素数量匹配，确定目标站点。
3. 确定目标站点距最近的网格边（上/下/左/右），旋转和/或翻转精灵使绿(3)标记朝向该边的方向（若最近边是底边，则绿标记在精灵朝下的位置）。
4. 平移精灵使其耦合器像素一一对齐到站点像素上。擦除精灵原始位置的所有像素（恢复为黑(0)）。
5. 对接完成后，对每个"精灵+站点"复合体执行单轴镜像补全：以站点像素簇中心所在行（若站点水平排列）或列（若站点垂直排列）为对称轴，将复合体中每个青(8)像素关于该轴镜像到对侧，若对侧为黑(0)则放置青(8)像素。绿(3)标记和栗(9)站点/耦合器不参与镜像。
6. 站点排列方向判定：若站点像素的行跨度 >= 列跨度则视为垂直排列，对称轴为站点中心列；否则视为水平排列，对称轴为站点中心行。

**关键洞察**：站点担任三重角色——通过像素数量决定配对（选哪个精灵来）、通过位置决定朝向（最近边 → 旋转角度）、通过排列方式决定镜像轴方向（水平/垂直）。单看一个示例可能猜出配对和朝向规则，但镜像轴方向规则（由站点排列方向决定而非由最近边方向决定）必须对比多个示例（站点排列方向与最近边方向不一致的情况）才能正确归纳。

## 新题 9：控制像素印章后重力坍缩

**组合逻辑**：[印章覆盖+控制色选中则印章+像素到块映射](已有) → [重力下落+堆叠](创新：作用于印章生成的副本矩阵而非原生对象)

**来源原语**：印章覆盖+控制像素+源图案+像素到块映射+控制色选中则印章(ad7e01d0), 重力下落+碰撞停止+堆叠(6ad5bdfd/825aa9e9)

**依赖链**：灰色控制像素的位置决定哪些输出块被印章 → 印章构建出包含多个图案副本的中间网格 → 重力逐列将所有非背景像素下沉到底部 → 最终密度分布取决于印章水平分布和重力垂直压缩的交互

小网格中的灰色控制像素选定输出大网格中放置整个图案副本的块位，印章完成后所有非背景像素逐列自由下落到底部堆叠。

**输入结构**：一个小网格（4x4 或 5x5），黑(0)背景上有若干彩色前景像素（颜色取自 {蓝(1), 红(2), 绿(3), 黄(4)}，2~4 个非黑非灰像素），以及若干灰(5)控制像素（2~4 个）。生成约束：灰色控制像素和前景像素不重叠；灰像素数量至少 2 个且不全在同一行；至少有一列包含多个被印章块（即同列有多个灰控制像素），以使重力后产生堆叠效果。

**规则**：
1. 设输入为 NxN 网格。构建输出网格尺寸为 (N*N) x (N*N)，即 N 行 N 列的 NxN 子块排列。初始化输出为全黑(0)。
2. 对输入中每个灰(5)控制像素位置 (i,j)：将整个输入网格（含前景色像素和黑背景，但将灰(5)像素视为黑(0)处理）复制到输出的第 (i,j) 子块中（子块左上角为 (i*N, j*N)）。
3. 对输入中每个非灰(5)位置 (i,j)：输出的第 (i,j) 子块保持全黑。
4. 印章完成后，对输出网格执行重力操作：逐列独立处理，每列中所有非黑(0)像素保持相对顺序不变地向下滑动，紧密堆叠到该列底行。列内像素从上到下的相对顺序在下落后保持不变，空出的上方格填为黑(0)。
5. 输出即为重力坍缩后的大网格。

**关键洞察**：灰色控制像素不只选择放置位置——它们间接决定了每列重力坍缩后的堆叠高度和颜色序列。同一列中多个被印章的子块会将各自的内容在重力后合并到同一列底部，形成源图案中不存在的新颜色序列。求解者需先理解印章机制（横向展开），再理解重力机制（纵向压缩），并意识到最终输出是两者的复合效果而非任一单独作用。

## 新题 10：条纹分区定独立缩放 + 位置决定镜像朝向

**组合逻辑**：[像素放大](创新：每个分区的缩放倍率由该分区自身宽度决定，各区独立) → [镜像](创新：是否镜像由分区在网格中的位置决定) → [分区条纹](创新：条纹同时编码分区边界和缩放参数)

**来源原语**：像素放大+框内尺寸决定缩放+图案(6b9890af), 镜像+对称(c35c1b4c/9ecd008a), 分区条纹(6e4f6532), 裁剪(8731374e)

**依赖链**：条纹位置 → 分区边界 + 各分区宽度 → 每区独立缩放倍率 → 角落种子图案放大填充分区 → 分区中心列与网格中线的位置关系 → 是否水平翻转；条纹既是几何分隔又是缩放参数编码器，位置关系是镜像判断的唯一依据

红色垂直条纹将网格分为若干宽度不等的竖带，每带左上角的 2x2 种子图案按带宽独立缩放填充该带，位于网格右半侧的带再水平翻转。

**输入结构**：约 20x16 的网格，黑(0)背景。若干条红(2)垂直单像素宽条纹从顶行贯穿到底行，将网格分为 3~4 个竖直带。每个带的宽度 W 为偶数（W = 2, 4, 6 或 8），不同带宽度可以不同。每个带的左上角 2x2 区域内有一个由蓝(1)和黑(0)组成的种子图案（即 2x2 格中部分为蓝、部分为黑）。带的其余区域为黑(0)。生成约束：每个带宽度为偶数；网格高度为偶数；至少有一个带中心列在网格水平中线左侧，至少一个在右侧。

**规则**：
1. 识别红(2)垂直条纹及其所分隔的各个竖直带。每个带宽 W 列，高 H 行（H = 网格高度）。
2. 提取每个带左上角的 2x2 种子图案。
3. 计算每个带的水平缩放倍率 Sw = W / 2，垂直缩放倍率 Sh = H / 2。将 2x2 种子图案中每个像素扩展为 Sw x Sh 的矩形块，用该像素的颜色填充，生成 W x H 的放大图案。
4. 判断每个带的位置：计算该带的中心列 = 带最左列 + W/2。计算网格水平中线 = (网格总列数 - 1) / 2.0。
5. 若带的中心列 > 网格水平中线（即该带位于网格右半侧）：将步骤 3 生成的放大图案水平翻转（左右镜像）后填入该带。
6. 若带的中心列 <= 网格水平中线（即该带位于网格左半侧或中线上）：直接将放大图案填入该带，不翻转。
7. 红(2)条纹保持不变。

**关键洞察**：红色条纹同时编码两层信息：其间距决定了每个带的独立缩放倍率（宽带放大多，窄带放大少），其位置将网格划分为左右两半以决定镜像朝向。两个宽度相同但分别位于左半和右半的带，输出内容互为水平镜像——求解者必须同时发现"宽度→缩放"和"位置→镜像"两条规则，仅凭单个示例中只有一侧的带无法区分"始终不翻转"和"左半不翻转右半翻转"。
