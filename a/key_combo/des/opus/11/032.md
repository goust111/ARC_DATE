## 新题 1：轮廓滑行距离决定印章缩放

**组合逻辑**：[滑动](沿视线到达障碍后转为轮廓追踪) → [像素放大](追踪距离作为缩放因子) → [印章覆盖](缩放后的模板印在落点) + [擦除](清除原模板)

**来源原语**：滑动、轮廓邻接、最长贴边路径 ← 97c75046；像素放大、缩放对应、边长定缩放因子、模板 ← 447fd412；擦除 ← 17b866bd；标记像素 ← 多题共有

**依赖链**：标记的滑动落点由障碍形状决定 → 落点处的局部轮廓长度编码了缩放因子 → 缩放因子决定印章大小和印章位置的覆盖范围。障碍体同时充当运动屏障和缩放参数表，三者经由同一几何体紧耦合。

将彩色标记沿视线滑向障碍体，在落点处沿障碍外轮廓追踪，追踪距离决定模板的缩放倍率，最后将缩放后的模板印在落点位置。

**输入结构**：约 18x18 黑(0)背景。网格中有一个不规则的 4-连通灰(5)障碍区域（15-25 像素，非凸，含至少两处凹弯）。网格某角落放置一个小型蓝(1)模板图案（4-连通，3-6 像素，包围盒不超过 3x3）。2-3 个单像素彩色标记（分别为红(2)、绿(3)、黄(4)），每个标记恰好有唯一一个基数方向（上/下/左/右之一）到障碍边界的无阻挡视线。各标记互不同行同列。生成约束：每个标记的两个轮廓追踪方向产生的长度不相等，以避免平局；各标记落点互相间距至少为最大缩放倍率乘以 3。

**规则**：
1. 每个彩色标记沿其唯一的基数视线方向滑向障碍体，停在障碍体前最后一个黑(0)像素（即落点）。
2. 从落点出发，沿障碍体的外 4-邻接边界向两个方向（顺时针和逆时针）追踪。追踪时每步移动到下一个与障碍体保持 4-邻接的背景像素，直到无法继续（没有既是背景又与障碍 4-邻接的未访问邻居）。分别记两个方向的追踪步数为 L1 和 L2，取 k = max(L1, L2)。
3. 将蓝(1)模板中的每个像素放大为 k x k 的色块，以落点为放大后图案的左上角绘制，颜色使用该标记的原色。超出网格边界的部分裁掉。
4. 所有标记处理完毕后，擦除蓝(1)模板原始位置（置为黑(0)）。
5. 若两个缩放印章的像素重叠，k 值较大的覆盖 k 值较小的。k 值相同时，按标记距网格左上角的曼哈顿距离升序排优先级，距离近的在上。

**关键洞察**：障碍体的局部曲率在不同入射点产生不同的顺/逆时针轮廓段长度差异，使同一障碍体为每个标记编码不同的缩放因子——障碍体既是空间屏障，又是逐标记的缩放查找表。需要多个示例才能将轮廓追踪规则与缩放规则分别归纳。

## 新题 2：互补拼合还原模板后按标记缩放填孔

**组合逻辑**：[补全](多个互补残缺副本对齐取并集) → [像素放大](孔洞尺寸决定缩放因子) → [平移](缩放模板移入孔洞) + [擦除](清除残缺副本)，其中孔洞边缘的标记像素将副本颜色映射到对应孔洞（创新：标记色桥接拼合与放置）

**来源原语**：补全、部分图案、模板掩码、对齐合并取并集、各副本互补缺失 ← f8cc533f；像素放大、缩放对应、边长定缩放因子 ← 447fd412；平移、孔洞、形状嵌合 ← 6a1e5592；标记像素 ← 多题共有

**依赖链**：残缺副本任一单独都不完整 → 必须全部取并集才能获得模板 → 孔洞大小独立决定缩放因子 → 孔洞边缘标记色决定使用哪个副本的颜色涂色。三条信息流（形状、缩放、颜色）汇聚于填充操作，缺一不可。

将多个互补残缺的彩色部分图案对齐合并还原出完整模板，然后将模板按孔洞尺寸缩放后填入灰色框架中的方形孔洞，每个孔洞的填色由其边缘标记像素指定。

**输入结构**：约 20x20 黑(0)背景。上半区域放置 3 个大小相同的部分精灵体（sprite），分别为红(2)、蓝(1)、绿(3)色，每个精灵体的包围盒为 3x3，内含 4-7 个同色像素，其余位置为黑(0)。三个副本在包围盒内的像素位置互补——任意两个副本的并集仍不完整，三个副本的并集恰好得到完整模板（5-8 个像素的 4-连通图形）。三个副本水平排列，间距至少 2 像素。下半区域有一个灰(5)实心矩形框架（约 12x8），框架内部有 3 个黑(0)方形孔洞，尺寸分别为 3x3、6x6、9x9（即缩放因子 k=1,2,3）。每个孔洞的左上角内侧有一个单像素标记，颜色为红(2)、蓝(1)或绿(3)之一，三个孔洞的标记颜色互不相同。生成约束：三个部分副本的缺失像素互补且各孔洞边长恰为 3 的正整数倍；三个孔洞之间、孔洞与框架边缘之间至少间隔 1 像素灰色。

**规则**：
1. 将上半区域的三个彩色部分副本分别裁剪到 3x3 包围盒，左上角对齐后取像素并集（OR），得到完整模板掩码。
2. 对每个孔洞，计算缩放因子 k = 孔洞边长 / 3。
3. 将模板按 k 缩放（每个模板像素变为 k x k 色块），以孔洞左上角为锚点绘入孔洞。缩放后的像素颜色使用该孔洞左上角标记像素的颜色。
4. 绘制完毕后，擦除该孔洞的标记像素（被缩放图案覆盖或置为该颜色）。
5. 擦除上半区域的三个部分副本（所有像素置为黑(0)）。
6. 灰色框架和框架外的黑色背景保持不变。

**关键洞察**：任何单个副本都无法还原出完整模板，强制求解者先完成拼合；而每个孔洞的标记色又指回某一个副本的颜色，将拼合过程（"这些是同一个模板的碎片"）与填色规则（"用哪个碎片的颜色"）绑定为同一推理链。

## 新题 3：短轴分割线延伸切割背景后锚点洪泛

**组合逻辑**：[连线/draw_line](标记沿矩形短轴展开为分割线) → [连线延伸](创新：分割线穿出矩形进入背景通道) → [洪泛填充](被分割线切割后的背景区域中，含锚点的区域被洪泛)

**来源原语**：连线、标记像素、矩形区域、标记沿短轴展分割、包含 ← 855e0971；洪泛填充、分隔墙、四连通分区、角落锚定 ← 782b5218；背景通道 ← b7f8a4d8

**依赖链**：矩形短轴决定分割线方向 → 分割线延伸穿过背景通道 → 延伸后的分割线将背景切割为多个 4-连通区域 → 锚点所在的区域被洪泛填充。分割线的全局效果无法从其局部规则（短轴方向）直接预测，因为延伸路径取决于矩形外的背景布局。

将矩形内的标记像素沿矩形短轴展开为分割线，该分割线穿出矩形延伸到背景中，将背景切割为多个区域，包含锚点像素的区域被洪泛填充为锚点颜色。

**输入结构**：约 16x16 黑(0)背景。3-4 个互不重叠的单色实心矩形（蓝(1)、红(2)、绿(3)、黄(4)，每个至少 4x3 或 3x4 像素），散布在网格中，矩形之间有黑色背景间隙。其中 1-2 个矩形内各含一个灰(5)标记像素。网格的一个角落（如左下角）放置一个橙(7)单像素锚点，位于黑色背景中而非任何矩形内部。生成约束：各矩形之间的背景间隙宽度至少 2 像素；标记像素不在矩形边缘行/列上（以确保分割产生两个非空子区域）；灰色分割线延伸后确实将背景分为多个 4-连通区域（至少 2 个）。

**规则**：
1. 对每个含灰(5)标记像素的矩形：若矩形宽度 > 高度，过标记所在列画一条灰(5)竖线，跨矩形全高；若高度 > 宽度，过标记所在行画一条灰(5)横线，跨矩形全宽；若宽高相等，画竖线。灰线覆盖矩形内原有像素。
2. 每条灰色分割线从矩形边界处向两个方向延伸进入黑色背景，沿同方向（竖线向上和向下、横线向左和向右）逐像素前进，直到碰到非黑(0)像素或网格边缘时停止（不覆盖非黑像素）。延伸段也设为灰(5)。
3. 所有分割线绘制完毕后，将网格中剩余的黑(0)像素按 4-连通性分为若干区域。
4. 找到包含橙(7)锚点的那个 4-连通黑色区域，将该区域所有黑(0)像素填充为橙(7)（锚点本身已经是橙(7)，保持不变）。
5. 其余黑色区域、所有矩形、灰色分割线均保持不变。

**关键洞察**：分割线在矩形内的朝向由局部短轴规则决定，但延伸进背景后的切割效果取决于矩形相对于网格边缘和其他矩形的全局布局。一条看似水平的短分割线延伸后可能恰好封堵两个矩形之间的窄通道，彻底改变背景的连通性。需要多个示例才能分别发现短轴方向规则和延伸后的洪泛规则。

## 新题 4：导线长度调制令牌形状周期后填入腔室

**组合逻辑**：[传输](令牌经导线到达远端腔室) + [形状变换](创新：导线像素数对 3 取模推进形状周期) → [填充](变换后的形状图案填入目标腔室)

**来源原语**：传输、形状变换、线路网络、令牌、端点配对、形状循环映射 ← a47bf94d；填充、封闭腔室、格点骨架、标记指定腔室 ← 17b866bd

**依赖链**：导线的空间路由决定其像素数 L → L mod 3 推进形状周期 → 推进后的形状填入目标腔室。同一个令牌经不同长度的导线传输会产生不同形状，导线的几何布局隐式编码了变换参数。

将格点骨架腔室中的令牌图案通过导线传输到远端空腔室，导线长度（像素数）对 3 取模推进形状周期（实心→X→菱形→实心...），变换后的图案以令牌颜色填入目标腔室。

**输入结构**：约 20x20 黑(0)网格。青(8)格点骨架将网格划分为若干 3x3 的黑(0)封闭腔室（每个腔室被青色边框完全围合）。部分腔室内含有 3x3 令牌图案，共三种形态：实心块（9 像素全填）、X 形（4 角 + 中心共 5 像素）、菱形（中心 + 上下左右 4 个共 5 像素）。令牌颜色各异（红(2)、蓝(1)、绿(3)、黄(4)等），每个令牌颜色唯一。部分腔室为空（全黑）。青(8)单像素宽的导线路径（4-连通，沿骨架外侧或利用骨架自身通道）连接某些有令牌的腔室与空腔室，每条导线恰好两端各连接一个腔室。不同导线像素数不同（范围约 3-15 像素）。生成约束：每条导线恰连接一个有令牌腔室和一个空腔室；导线之间不共用像素；所有导线长度 mod 3 的值在示例间有变化。

**规则**：
1. 识别每条导线：从有令牌腔室边框出发，沿 4-连通青(8)像素（不属于任何腔室边框的青色像素）追踪到另一个腔室边框为止。统计导线本身的青色像素数（不含两端腔室边框像素），记为 L。
2. 形状周期定义为：实心 → X → 菱形 → 实心（步长为 3 的循环）。从源令牌当前形状出发，前进 (L mod 3) 步，得到目标形状。
3. 在导线远端的空腔室中，以源令牌的颜色绘制目标形状。
4. 源令牌保持原位不变。

**关键洞察**：导线不只是路由通道——它的物理长度隐式编码了形状变换量。同一个实心令牌经长度 4 的导线变成 X 形（前进 1 步），经长度 6 的导线仍是实心（前进 0 步）。求解者必须同时发现导线路由规则和长度取模规则，且只有对比不同长度导线的输出才能归纳出周期关系。

## 新题 5：按标记数排序叠合后冲突像素挖洞

**组合逻辑**：[排序](按标记像素数决定叠合层序) → [透明叠加](灰底透明，标记不透明) → [擦除](创新：不同色标记冲突的位置挖为黑洞)

**来源原语**：排序、排列顺序、整块移动保持内容 ← f18ec8cc；透明叠加、填充矩形、共享底色、标记像素、同尺寸对齐、标记无冲突合并 ← 25e02866；擦除 ← 17b866bd

**依赖链**：标记数量决定排序 → 排序决定叠合顺序 → 叠合顺序决定哪些位置出现多色冲突 → 冲突位置被挖成黑洞。改变排序标准会改变冲突位置分布，从而改变最终图案——排序和冲突擦除通过叠合层序紧密耦合。

将多个同尺寸的灰底矩形按其标记像素数量升序排列后逐层叠合，标记像素覆盖下层，但任何位置如果被两种不同颜色的标记争夺过则挖为黑洞。

**输入结构**：约 12x18 黑(0)背景。3-4 个相同尺寸的矩形（如都是 5x4），每个矩形以灰(5)为底色，内含 2-4 个非灰标记像素（颜色从红(2)、蓝(1)、绿(3)、黄(4)中取，同一矩形内标记颜色可重复也可不同）。各矩形竖向排列，间隔至少 1 行黑色。每个矩形的标记总数互不相同。生成约束：至少存在 2 个位置（相对矩形左上角的坐标相同）在不同矩形中被不同颜色的标记占据，以产生冲突。

**规则**：
1. 统计每个矩形中非灰像素的总数。按总数升序排列矩形（最少的在底层，最多的在顶层）。若总数相同，按矩形左上角到网格左上角的曼哈顿距离升序排（距离近的在底层）。
2. 创建一个与矩形同尺寸的输出画布，初始填满灰(5)。
3. 按排序顺序从底层到顶层逐层叠合：每层中，非灰标记像素覆盖画布对应位置的当前内容。灰色像素透明（不改变画布）。同时记录每个位置被写入过的所有不同标记颜色。
4. 叠合完毕后，检查每个位置的颜色写入历史：若某位置被 2 种及以上不同颜色的标记写入过（无论最终显示哪种），将该位置置为黑(0)。
5. 输出仅为该合成矩形，原始多个矩形不保留。

**关键洞察**：排序将标记少的矩形放在底层，标记多的在顶层，这意味着顶层更容易覆盖底层——但覆盖不等于安全，被覆盖的冲突位置同样会被挖洞。求解者容易误以为顶层颜色总是最终结果，实际上冲突检测贯穿所有层。需要对比不同标记分布的示例才能发现冲突擦除规则独立于叠合优先级。

## 新题 6：分隔线网格平铺后象限决定镜像方向

**组合逻辑**：[平铺](将唯一有图案的单元格复制到所有空单元格) + [镜像](创新：单元格在分隔网格中的象限位置决定镜像方式——左右翻转、上下翻转或 180 度旋转)

**来源原语**：平铺、分隔线、瓦片图案、网格分区、已填瓦片填空槽 ← c444b776；镜像、象限、对称轴定义 ← 47c1f68c；奇偶定方向 ← 4364c1c4（改造：从奇偶变为象限）

**依赖链**：分隔线定义了单元格网格和网格中心 → 每个空单元格的象限位置决定它接收的图案朝向 → 填入的图案必须先经过象限对应的镜像变换。平铺和镜像通过网格坐标系统耦合——同一个图案在不同象限呈现不同朝向，求解者必须同时发现"复制同一图案"和"按象限翻转"两条规则。

找到分隔线网格中唯一有图案的单元格，将该图案复制到每个空单元格，但依据单元格相对于网格中心的象限位置对图案进行不同的镜像变换。

**输入结构**：约 15x15 网格。栗(9)分隔线（完整贯穿的等距行和列）将网格划分为 m x n 个等大的矩形单元格（m, n 均为奇数，如 3x3 或 5x5 个单元格，使网格有唯一中心单元格）。恰好一个单元格内含有蓝(1)非对称图案（4-连通，3-6 像素，上下和左右均不对称，以使各镜像结果可区分），其余单元格为黑(0)。生成约束：有图案的单元格不位于网格正中心的单元格（否则无法区分四种朝向）；图案上下翻转、左右翻转、180度旋转的结果互不相同。

**规则**：
1. 找到唯一含图案的单元格，记其在单元格网格中的坐标为 (r0, c0)。提取图案。
2. 计算单元格网格的中心坐标 (rc, cc) = ((m-1)/2, (n-1)/2)。
3. 对每个空单元格 (r, c)，根据其与中心的相对位置决定镜像方式：
   - 与有图案单元格在同一象限（两者相对于中心的行偏移和列偏移符号相同）：原样放置。
   - 行偏移同号、列偏移异号（水平翻转象限）：左右镜像。
   - 行偏移异号、列偏移同号（垂直翻转象限）：上下镜像。
   - 行偏移和列偏移均异号（对角象限）：180 度旋转。
   - 位于中心行 (r = rc)：仅根据列偏移符号——与源同号则原样，异号则左右镜像。
   - 位于中心列 (c = cc)：仅根据行偏移符号——与源同号则原样，异号则上下镜像。
   - 中心单元格 (r = rc, c = cc)：原样放置。
4. 保留所有栗(9)分隔线不变。

**关键洞察**：简单平铺只会复制相同图案，但此题中同一图案在不同象限有不同朝向，形成全局对称图案。变换的参考系不是网格的几何中心，而是源图案单元格相对于中心的位置——源单元格定义了"原样方向"，其他单元格的变换由其与源的象限关系推导。需要多个示例中源单元格位于不同位置才能排除"固定象限规则"的错误假设。

## 新题 7：坐标压缩定位占位符后图例重涂印章

**组合逻辑**：[坐标压缩](移除分隔线得到压缩坐标) → [图案印章](在压缩网格中按占位符位置印章精灵体) → [重涂色](按颜色图例将精灵体重涂为输出色) + [擦除](创新：灰色干扰像素被忽略并清除)

**来源原语**：坐标压缩、分隔线、块距离 ← 7d419a02；图案印章、占位符、精灵体、颜色图例、框架、编码映射 ← edb79dae；忽略干扰项 ← 782b5218；网格分区 ← c444b776

**依赖链**：分隔线移除后才能获得占位符的真实空间关系 → 精灵体形状与占位符颜色绑定 → 图例将占位符颜色映射到输出颜色 → 干扰像素必须在压缩前识别并排除。四条信息流（空间压缩、形状查找、颜色映射、干扰过滤）汇聚于印章操作。

移除分隔线对网格进行坐标压缩，在压缩后的网格中将占位符像素替换为对应颜色的精灵体图案，再按颜色图例重涂色，同时忽略灰色干扰像素。

**输入结构**：约 19x19 网格。黄(4)的完整贯穿行和列作为分隔线，将网格分为若干等大矩形单元格（如 4x4 个单元格）。每个单元格内大部分为黑(0)。2-3 个单元格中有一个彩色占位符像素（红(2)、蓝(1)或绿(3)），1-2 个单元格中有灰(5)干扰像素（不参与规则，需被忽略）。在网格最外圈的边缘区域（分隔线系统之外的空间），放置以下元素：(a) 2-3 个小精灵体（4-连通，3-5 像素，包围盒不超过 3x3），每个精灵体的颜色分别为红(2)、蓝(1)、绿(3)之一，与某个占位符颜色匹配；(b) 一组颜色图例——每对图例由两个上下相邻的像素组成，上方是占位符颜色，下方是输出颜色（如红(2)上 + 橙(7)下 表示红色占位符的印章应重涂为橙(7)）。生成约束：占位符颜色与精灵体颜色一一对应；图例颜色互不混淆；压缩后各占位符的位置保证精灵体印章互不重叠。

**规则**：
1. 识别所有完整贯穿的黄(4)行和列（分隔线）。
2. 移除分隔线行和列，将剩余像素紧缩排列得到压缩网格（尺寸变小）。每个原单元格在压缩后坍缩为相应的小区域。
3. 在压缩网格中，灰(5)干扰像素全部置为黑(0)。
4. 对每个占位符像素（红/蓝/绿），找到边缘区域中颜色匹配的精灵体，将该精灵体以占位符在压缩网格中的位置为左上角进行印章。
5. 查找颜色图例：对每个占位符颜色，找到对应的输出颜色。将印章后的精灵体像素重涂为该输出颜色。
6. 输出为压缩后的网格（不含分隔线和边缘区域元素）。

**关键洞察**：分隔线不是装饰——移除它们才能获得占位符之间的真实空间关系，而灰色干扰像素会误导朴素的"找最多非黑颜色"策略。求解者必须同时掌握三个独立映射（占位符色→精灵体形状、占位符色→输出色、分隔线→空间压缩）并串联应用。

## 新题 8：交替平移后连通性决定存亡

**组合逻辑**：[交替平移](奇偶排位决定左移/右移) → [重涂色](创新：碰撞像素变灰) → [擦除](创新：碰撞后丧失 4-连通性的物体整体擦除)

**来源原语**：交替平移、单色前景体、排列顺序、奇偶定方向 ← 4364c1c4；重涂色 ← 47c1f68c/60b61512；擦除 ← 17b866bd；连通分量、包围盒内部 ← 60b61512

**依赖链**：排位决定平移方向 → 平移后某些物体像素重叠产生碰撞 → 碰撞像素变灰使物体像素减少 → 剩余像素如果不再 4-连通则整个物体被擦除。物体的几何形状决定了它在碰撞后能否保持连通——紧凑物体更容易存活，细长物体容易被切断。

按包围盒顶行排序后，奇数位物体左移一列、偶数位右移一列；碰撞位置变灰；碰撞后剩余像素不再 4-连通的物体被整体擦除。

**输入结构**：约 15x15 黑(0)背景。4-6 个小型 4-连通单色前景物体（每个 3-6 像素），颜色互不相同（从蓝(1)、红(2)、绿(3)、黄(4)、橙(7)、品红(6)中选取）。各物体的包围盒顶行（最小行号）互不相同，形成唯一的从上到下排序。物体形状各异（有紧凑的也有细长的），不限定具体形状名。生成约束：按交替平移规则移动后，至少有 2 对物体产生像素重叠；至少有一个碰撞导致某物体剩余像素不再 4-连通（以触发擦除规则），且至少有一个碰撞后物体仍保持 4-连通（以对比存亡差异）。

**规则**：
1. 将所有前景物体按包围盒最小行号从小到大排序，排位 1, 2, 3, ...
2. 奇数排位（1, 3, 5, ...）物体整体左移 1 列；偶数排位（2, 4, 6, ...）物体整体右移 1 列。移出网格边界的像素丢弃。腾出的原始位置变为黑(0)。
3. 移动后，若两个不同物体的像素占据同一单元格，该单元格设为灰(5)，两个物体均失去该像素。
4. 处理完所有碰撞后，对每个物体检查其剩余（非灰）像素的 4-连通性：
   - 若剩余像素仍构成单个 4-连通分量（或物体无碰撞损失），保留其原色不变。
   - 若剩余像素分裂为 2 个及以上 4-连通分量，或剩余像素为 0 个，则将该物体所有剩余像素擦除为黑(0)。
5. 灰(5)碰撞像素保留在输出中。

**关键洞察**：交替平移方向仅取决于排位奇偶（与颜色、形状无关），但哪些物体存活取决于碰撞后的拓扑连通性——紧凑的 2x2 色块失去一个角像素后仍然连通，而 1 像素宽的细长条被切断则整体消亡。需要多个示例才能区分"碰撞=变灰"和"断连=擦除"两层规则。

## 新题 9：同色四角连线成框后按内含物条件补全或擦除

**组合逻辑**：[连线](同色四角单像素连成矩形框) → [补全](创新：框内不完整图案按包围盒补全，补全色为框色) → [擦除](创新：无内含物的框整体擦除)

**来源原语**：连线、同色四角矩形、沿通道绘制矩形边 ← b7f8a4d8；补全、连通分量、包围盒内部、缺失像素异色补 ← 60b61512；擦除 ← 17b866bd；角标记像素、边框、中心图案、角标色决定重涂、内部包含 ← 3de23699

**依赖链**：同色单像素分组 → 四像素连线成框 → 框是否含内部图案决定框的命运（补全 vs 擦除）→ 补全使用框色而非图案原色。框的绘制（连线）和框的存亡（条件擦除）通过内含物检测耦合；补全使用框色而非内容色，使连线结果直接参与补全的颜色决策。

将散布在网格中的同色单像素四元组连线成矩形框，框内若存在不完整图案则用框色补全其包围盒中的缺失像素，框内若无图案则将整个框擦除。

**输入结构**：约 18x18 黑(0)背景。若干颜色组，每组恰好 4 个同色单像素散布于网格中，颜色从蓝(1)、红(2)、绿(3)、黄(4)中选取（共 3-4 组，颜色各不相同）。每组的 4 个像素恰好构成一个轴对齐矩形的四个角（但它们之间没有连线，视觉上不易看出矩形关系）。部分矩形的内部（不含边界）存在若干橙(7)像素组成的 8-连通小图案（3-6 像素，包围盒不超过 3x3，包围盒严格在矩形内部），这些图案不完整（包围盒内有黑色缺口）。其余矩形内部全为黑色（无图案）。生成约束：各组矩形互不重叠（包括边界线）；含图案矩形的内部空间至少为 5x5（使图案及其补全有足够空间）；图案包围盒的每条边距矩形边框至少 1 像素。

**规则**：
1. 按颜色将单像素分组，每组 4 个。
2. 对每组，将 4 个角像素连线成矩形边框：绘制上下两条水平线（连接同行的两个角）和左右两条垂直线（连接同列的两个角），线宽 1 像素，颜色为该组颜色。
3. 对每个矩形，检查其严格内部（不含边框）是否存在非黑像素：
   - 若存在橙(7)图案：找到该图案的 8-连通分量，计算其最小包围盒。将包围盒内所有黑(0)像素设为该矩形的框色（蓝/红/绿/黄），橙(7)像素保持不变。
   - 若不存在任何非黑像素：将该矩形的整个边框擦除为黑(0)（包括刚绘制的 4 条边线和 4 个角像素）。
4. 不属于任何矩形框或图案的黑色背景保持不变。

**关键洞察**：四个散布的同色像素表面上毫无关联，实际上它们定义了矩形框的角点。框是否保留取决于一个与框本身颜色无关的条件（是否有橙色内含物），而补全操作反过来使用框的颜色（而非内含物的橙色），形成"连线→检测→条件分叉"的非线性推理结构。

## 新题 10：双尺度网格叠加生成复合腔室后标记选填

**组合逻辑**：[生成网格](两个不同边长的实心方块各自生成一套网格线) → [透明叠加](创新：两套网格线叠加，交叉处细网格色优先) → [填充](标记像素指定腔室，洪泛填充所在腔室)

**来源原语**：生成网格、实心方块、网格线、边长决定间距、等距参数化 ← 695367ec；透明叠加、同尺寸对齐 ← 25e02866（改造：从矩形叠加变为网格线叠加）；填充、封闭腔室、标记像素、标记指定腔室 ← 17b866bd

**依赖链**：两个方块的边长决定两套网格线的间距 → 两套网格叠加时产生的交叉点改变了腔室的边界 → 标记所在的腔室形状取决于双网格的叠加结果。粗网格的大腔室被细网格的线切割为更小的子腔室，标记可能落在某个子腔室中——填充范围取决于两套网格的共同作用。

输入中两个不同尺寸和颜色的实心方块各自参数化生成一套等距网格线，两套网格叠加在同一画布上形成复合分区，然后将标记像素所在的封闭腔室洪泛填充为标记颜色。

**输入结构**：约 15x15 黑(0)背景。画布左上角区域放置两个不重叠的实心方块：一个蓝(1)方块（边长 s1，如 2）、一个红(2)方块（边长 s2，如 3），s1 < s2。两个方块在同一行或相邻行水平排列。此外，网格中散布 2-3 个绿(3)单像素标记，位于将要生成的双网格的腔室内部（不在任何即将生成的网格线上）。生成约束：s1 和 s2 互不整除（如 2 和 3），以确保两套网格不完全重合；绿色标记不位于任何网格线将经过的行或列上。

**规则**：
1. 对蓝(1)方块（边长 s1）：从行 s1 开始，每隔 s1+1 行画一条贯穿全宽的蓝(1)水平线；从列 s1 开始，每隔 s1+1 列画一条贯穿全高的蓝(1)垂直线。
2. 对红(2)方块（边长 s2）：同理，从行 s2 开始，每隔 s2+1 行/列画红(2)线。
3. 两套网格线叠加在同一 15x15 画布上。若某像素同时被两条线覆盖，使用边长较小的方块（细网格）的颜色（蓝(1)优先于红(2)）。
4. 擦除两个实心方块的原始像素（置为黑(0)），但若方块位置恰在网格线上，则保留网格线色。
5. 网格线将画布划分为若干封闭的矩形腔室（全黑区域，被网格线四面围合）。对每个绿(3)标记像素，找到包含它的腔室（该标记与腔室内其他黑像素 4-连通），将整个腔室（含标记本身）填充为绿(3)。
6. 不含标记的腔室保持黑(0)。

**关键洞察**：两套网格的间距互不整除时，叠加产生的腔室尺寸不均匀——粗网格的大腔室在某些位置被细网格线切割为更小的子腔室，在其他位置则保持完整。标记落在哪种腔室中（大的还是被切割后的小的）决定了填充面积，但这只有在理解双网格叠加机制后才能预测。
