## 新题 1：对称门控的孔洞分类填充

**组合逻辑**：[对称检测symmetry_detection](创新：作用于外框而非独立图案) + [填充fill] + [面积分类area_classification → 重涂色recolor](创新：孔洞面积决定填充色而非外框面积)

**来源原语**：对称检测(44f52bb0), 填充(44d8ac46), 面积分类(d2abd087), 封闭区域(44d8ac46), 孔洞(44d8ac46), 内部包含(44d8ac46)

**依赖链**：对称检测筛选出哪些外框参与后续处理（门控），被选中外框的孔洞面积决定填充颜色（条件分支）。对称性决定"是否填"，面积决定"填什么色"，两个判断缺一不可。

一句话总结：检测每个灰色外框的垂直对称性，仅对对称外框内部的孔洞进行填充，填充颜色由孔洞像素面积决定。

**输入结构**：约 15x15 的黑(0)背景网格。散布 4~6 个灰(5)色的封闭外框（4-连通，壁厚1像素，每个外框的边界框约 4x4 至 6x6 不等）。每个外框内部有一块连续的黑(0)孔洞区域（面积在 2~8 像素之间）。部分外框沿垂直中轴对称，部分不对称。外框之间互不相邻（至少间隔1像素）。生成约束：对称外框至少2个；不同对称外框的孔洞面积至少覆盖两个不同的面积区间。

**规则**：
1. 检测每个灰(5)外框的垂直镜像对称性：将外框的边界框内容沿垂直中轴翻转，若与原内容逐像素相同则判定为对称。
2. 不对称的外框及其内部孔洞保持不变（不做任何修改）。
3. 对称外框内部的黑(0)孔洞区域按面积填充颜色：面积 2~3 像素填红(2)，面积 4~5 像素填蓝(1)，面积 6~8 像素填绿(3)。
4. 外框本身的灰(5)像素和黑(0)背景保持不变。

**关键洞察**：面积到颜色的映射规则（2~3→红, 4~5→蓝, 6~8→绿）无法从单个示例归纳，需要对比多个示例中不同面积孔洞的填充结果。对称检测是前置门控，面积分类是后置条件分支，两者缺一不可。

## 新题 2：射线分区内的散布标记蛇形压缩

**组合逻辑**：[射线延伸ray_extend](创新：射线从固定源点发出建立分区边界) + [蛇形填充boustrophedon_fill](创新：蛇形读取顺序限定在射线分区内) + [压缩compress]

**来源原语**：射线延伸(1190bc91), 射线遮挡分区(1190bc91), 散布标记(cdecee7f), 蛇形填充(cdecee7f), 列序排列(cdecee7f), 压缩(7837ac64)

**依赖链**：射线从源像素出发向四方向延伸建立空间分区 → 每个分区内的散布标记按蛇形顺序收集 → 分区按源像素在输入中从左到右的顺序排列，各分区的蛇形序列拼接输出。射线分区决定了哪些标记属于同组（分组），蛇形顺序决定了组内排列（排序），两步信息不可互换。

一句话总结：从顶行彩色源点向下发射射线将网格分为竖条区域，收集每个区域内散布标记的颜色并按蛇形顺序压缩为紧凑输出。

**输入结构**：约 12x12 的黑(0)背景网格。顶行（第0行）有 2~4 个不同颜色的像素作为射线源（颜色各不相同，从红(2)、蓝(1)、绿(3)、黄(4)中选取，位于不同列）。网格内散布 6~9 个单像素前景标记（颜色各异或部分重复，颜色来自品红(6)、橙(7)、青(8)、栗(9)），每个标记占一个独立位置，互不相邻。生成约束：每个射线分区内至少有2个散布标记；散布标记不在第0行；射线源像素之间至少间隔2列。

**规则**：
1. 每个顶行源像素向下发射一条垂直射线（即该列从第1行到底部全部标记为该射线的边界）。射线本身不绘制在输出中，仅用于逻辑分区。
2. 射线将网格分为若干竖条区域（最左射线左侧为第一区、相邻射线之间为中间区、最右射线右侧为最后区）。按区域从左到右编号。
3. 对每个区域内的散布标记，建立 3 列的虚拟子网格（列数 = 区域宽度对 3 取整，行数由标记的行范围决定），按蛇形顺序读取标记：偶数行从左到右，奇数行从右到左。蛇形行以标记实际所在行的相对行号（在该区域内从上到下编号，从 0 起）为准。
4. 将所有区域的蛇形序列按区域编号顺序拼接，输出为一行 Nx1 的紧凑网格（N = 散布标记总数），每格为对应标记的颜色。

**关键洞察**：射线位置决定分区宽度，分区宽度改变了蛇形读取中"换行"的位置，从而改变同一组标记的输出顺序。移动一个射线源的列位置会导致多个标记的输出顺序发生非局部变化。

## 新题 3：指示方向平铺与支撑匹配印章的遮挡叠加

**组合逻辑**：[平铺tiling](创新：方向由指示像素决定而非固定四方向) + [印章覆盖stamp_overlay] + [处理顺序决定遮挡order_determines_block](创新：平铺副本按距离排序决定遮挡优先级)

**来源原语**：平铺(e8dc4411), 指示像素/指示决定方向色(e8dc4411), 印章覆盖(e5062a87), 支撑签名匹配(e5062a87), 处理顺序决定遮挡(1190bc91), 邻接触碰(e8dc4411)

**依赖链**：指示像素同时编码平铺方向和印章颜色 → 模板沿指示方向重复平铺 → 当两个不同方向的平铺路径在同一像素重叠时，距各自源模板更近的副本优先（遮挡规则）。方向决定路径，路径决定重叠区域，距离决定遮挡胜负——三层逻辑紧密耦合。

一句话总结：根据多个指示像素的方向将同一模板分别沿不同方向重复平铺，重叠处由距源模板的曼哈顿距离决定哪条路径的颜色胜出。

**输入结构**：约 15x15 的灰(5)背景网格。中央有一个黑(0)色模板对象（4-连通，约 3x3 边界框，像素数 4~7）。模板外围有 2~3 个单像素指示物，每个指示物颜色不同（从红(2)、蓝(1)、绿(3)中选取），且各自位于模板的不同侧（上、下、左、右中的不同方位）。生成约束：至少有两个指示物的平铺路径会在某些像素上重叠；指示物与模板曼哈顿距离为 1（即 4-邻接）。

**规则**：
1. 识别背景色灰(5)、黑(0)模板和各彩色单像素指示物。
2. 对每个指示物，计算其相对于模板质心的方向（上/下/左/右取最接近的正方向）。该方向即为该指示物对应的平铺方向。
3. 对每个指示物：将模板形状以该指示物的颜色沿平铺方向重复绘制，每次平移量等于模板边界框在该方向上的尺寸，直到超出网格边界。第 k 个副本的距离编号为 k（k=1 为紧邻原模板的第一个副本）。
4. 原模板位置保持黑(0)不变。
5. 遮挡规则：若某像素被多条平铺路径覆盖，保留距离编号最小的那条路径的颜色；若距离编号相同，保留平铺方向为水平方向（左或右）的路径颜色。
6. 背景中未被任何平铺覆盖的像素保持灰(5)。

**关键洞察**：遮挡规则（距离近者优先、水平方向 tie-break）需要对比多个重叠区域的示例才能归纳，单个示例无法区分"近者优先"和"某颜色固定优先"。

## 新题 4：笛卡尔积选位后按孔洞几何决定印章内容

**组合逻辑**：[行列交叉row_col_intersection → 填充fill](创新：笛卡尔积不直接填色而是选出候选位置) + [孔洞几何决定填充hole_geometry_sets_fill](创新：几何判断作用于候选位置内已有结构) + [印章覆盖stamp_overlay](创新：印章内容取决于几何测试结果)

**来源原语**：行列交叉(2281f1f4), 边缘标记笛卡尔积(2281f1f4), 孔洞几何决定填充(44d8ac46), 仅正方形孔洞填充(44d8ac46), 印章覆盖(e5062a87), 标记像素(2281f1f4), 画布边界(2281f1f4)

**依赖链**：边缘标记的笛卡尔积确定候选单元格位置 → 每个候选位置内有一个小图形，检测其内部孔洞是否为正方形 → 正方形孔洞的单元格接收印章A（十字形），非正方形孔洞的单元格接收印章B（边框形）。位置选择 → 几何判断 → 差异化印章，三步构成完整推理链。

一句话总结：在行列标记笛卡尔积确定的交叉位置上，根据该位置已有图形内部孔洞的形状（正方形 vs 非正方形）盖上不同的印章图案。

**输入结构**：约 14x14 的黑(0)背景网格。顶行有 2~3 个黄(4)标记像素标示目标列，最右列有 2~3 个黄(4)标记像素标示目标行。在网格内部，每个行列交叉位置放置一个 4x4 的灰(5)色外框（壁厚1），框内有一个 2x2 的黑(0)孔洞区域。部分孔洞恰好是 2x2 正方形（完整填满内部），部分孔洞为不规则形状（L形缺角，仅占内部 2~3 像素）。非交叉位置也可能有灰色外框作为干扰物。生成约束：交叉位置至少4个；正方形孔洞和非正方形孔洞各至少出现一次。

**规则**：
1. 识别顶行和最右列的黄(4)标记像素，计算其行列笛卡尔积得到候选交叉位置集合（位置定义为该行该列对应的 4x4 区块的左上角）。
2. 对每个候选位置的 4x4 灰色外框，提取内部 2x2 区域，判断黑(0)孔洞是否恰好占满 2x2（即正方形孔洞）。
3. 正方形孔洞：在该 2x2 区域内盖红(2)十字印章（中心列2像素，上下各伸出0像素，即竖条2x1 + 横条1x2的交叉，共3像素），剩余1像素保持黑(0)。
4. 非正方形孔洞（L形等）：将该 2x2 区域内已有的黑(0)像素全部填蓝(1)，灰(5)像素不变。
5. 非候选位置的灰色外框（干扰物）不做任何修改。

**关键洞察**：必须先正确识别笛卡尔积位置（排除干扰物），再对选中位置做几何判断。仅看孔洞几何不知道哪些位置要处理；仅看笛卡尔积不知道盖什么印章。两个条件耦合产生最终输出。

## 新题 5：面积排序精灵体的颜色循环传递与对角装饰

**组合逻辑**：[排序sort + 面积排序area_ordering] + [重涂色recolor](创新：颜色不由面积直接映射，而是循环位移传递) + [描边decorate + 对角邻接diagonal_adjacency](创新：装饰色来自排序链中的下一个精灵体)

**来源原语**：排序(4df5b0ae), 面积排序(4df5b0ae), 描边/对角邻接(95990924), 角标记(95990924), 重涂色(d2abd087), 面积分类(d2abd087), 精灵体(4df5b0ae/a87f7484)

**依赖链**：面积排序建立精灵体的有序序列 → 有序序列决定颜色循环传递方向（每个精灵体获得排序中前一位的颜色）→ 装饰色取排序中后一位的原始颜色。排序同时驱动两个不同的颜色映射（重涂和装饰），且两个映射方向相反（前一位 vs 后一位），必须同时正确推断才能得到完整输出。

一句话总结：将精灵体按面积排序后，每个精灵体被重涂为序列中前一位的颜色，同时在四个对角位置用序列中后一位的颜色画角标记。

**输入结构**：约 12x12 的黑(0)背景网格。散布 4 个不同颜色的单色4-连通精灵体（颜色分别为红(2)、蓝(1)、绿(3)、黄(4)），像素面积各不相同（分别约 3、5、7、9 像素）。每个精灵体形状不规则但边界框不超过 4x4。精灵体之间至少间隔 2 像素（保证对角装饰不重叠）。生成约束：四个精灵体面积严格不等。

**规则**：
1. 按像素面积从小到大排序四个精灵体，记为 S1(最小)、S2、S3、S4(最大)，记各自原始颜色为 C1、C2、C3、C4。
2. 颜色循环传递重涂：S1 重涂为 C4（最大的颜色），S2 重涂为 C1，S3 重涂为 C2，S4 重涂为 C3。即每个精灵体获得排序序列中前一位的颜色（循环：S1 的前一位是 S4）。
3. 对角装饰：对每个精灵体的边界框，在其四个外角对角位置各画一个单像素标记。装饰色为排序序列中后一位的原始颜色：S1 的装饰色为 C2，S2 的装饰色为 C3，S3 的装饰色为 C4，S4 的装饰色为 C1（循环）。
4. 精灵体保持原位不移动。边界框的四个外角定义为：(top-1, left-1)、(top-1, right+1)、(bottom+1, left-1)、(bottom+1, right+1)。若外角超出网格边界则不绘制。

**关键洞察**：重涂色和装饰色都依赖面积排序，但方向相反（重涂取前一位，装饰取后一位），仅看单个精灵体无法推断循环方向。需要对比多个示例中所有精灵体的颜色变化才能确认循环规则。

## 新题 6：多数投票修复后的镜像方向由指示像素选择

**组合逻辑**：[修复异常repair + 多数投票共识majority_vote] + [镜像mirror](创新：镜像轴不固定，由指示像素的相对位置编码) + [重涂色recolor](创新：受损位置不标记而是从镜像版本取色)

**来源原语**：修复异常(e84fef15), 多数投票共识(e84fef15), 受损副本被标记(e84fef15), 镜像(3af2c5a8), 镜像轴(44f52bb0), 指示像素(e8dc4411), 邻接触碰(e8dc4411)

**依赖链**：多数投票恢复共识图块 → 定位受损图块 → 指示像素的位置选择镜像轴 → 将共识图块沿选定轴镜像 → 受损位置从镜像版本中取色填补。修复和镜像不是顺序独立的——镜像改变了"应该填什么色"的答案，使得最终输出既不是直接共识也不是简单标记。

**依赖链**：左边缘彩色像素按颜色滑到对应列 → 统计每列的着陆像素总数 → 该计数决定该列中封闭区域的填充颜色。滑动产生空间分布（中间态），计数将空间分布压缩为数值，数值驱动颜色选择——三步信息逐渐抽象化，不可跳步。

一句话总结：左边缘像素按颜色规则滑入指定列，每列累积的着陆数决定该列中预设封闭区域的填充颜色。

1. 将最左列的每个彩色像素滑动到其颜色对应的列（红→列3，蓝→列4，绿→列5），保持原行号不变。滑动后的像素在输出中不绘制（仅作逻辑中间步骤）。
2. 统计每个目标列（3、4、5）上的着陆像素总数，记为 count(col)。
3. 对每个灰(5)封闭区域，确定其内部空腔占据的列集合。取这些列的着陆计数之和 S。

**关键洞察**：从颜色到列的映射（红→3，蓝→4，绿→5）需要对比多个示例才能归纳。填充色不由区域自身属性决定，而由其所在列的"流量"（着陆计数）决定——这是滑动操作与填充操作之间的间接耦合。

一句话总结：每个小字形的形状编码一个射线方向，从字形位置发射射线直到碰到障碍，射线长度映射为输出中对应位置的颜色。

**规则**：
1. 识别所有 3x3 字形及其形状。形状到方向的解码规则：十字形（5像素）→ 向上，竖条形（3像素垂直排列）→ 向下，横条形（3像素水平排列）→ 向右，L形（3像素成直角）→ 向左。
2. 从每个字形的中心像素出发，沿解码方向发射射线（逐像素延伸），直到碰到红(2)障碍像素或网格边界时停止（不包含障碍像素本身）。记录射线长度 L（不含起点像素）。
3. 将所有字形按其中心位置从上到下、从左到右排序。
4. 输出为 1xN 的单行网格（N = 字形数量），每格颜色由对应字形的射线长度决定：L=1 → 蓝(1)，L=2 → 绿(3)，L=3 → 黄(4)，L=4 → 品红(6)，L=5 → 橙(7)。

**关键洞察**：形状到方向的解码规则（十字→上, 竖条→下等）和长度到颜色的映射都需要对比多个示例归纳。两层编码叠加使得仅看单个示例无法确定完整规则。

## 新题 10：边缘标记笛卡尔积中的多数投票去噪与蛇形读取

**组合逻辑**：[行列交叉row_col_intersection + 边缘标记笛卡尔积edge_marker_cartesian_product](选位) + [多数投票共识majority_vote](创新：投票不在重复图块间进行，而是在笛卡尔积选中的单元格之间进行) + [蛇形填充boustrophedon_fill + 压缩compress](创新：投票结果按蛇形顺序读出)

**依赖链**：边缘标记确定目标单元格位置 → 目标单元格中各有一个彩色像素（可能有噪声）→ 对所有目标单元格的同一局部坐标做多数投票去噪 → 去噪后的共识图案按单元格的蛇形行列顺序逐像素输出为紧凑序列。位置选择 → 投票去噪 → 顺序压缩，三步结构上不可跳步。

一句话总结：在行列标记选出的交叉单元格中通过多数投票得到共识颜色，再按蛇形顺序将各单元格的共识色压缩为一行输出。

**输入结构**：约 13x13 的黑(0)背景网格。顶行有 3 个橙(7)标记像素（在不同列），最右列有 3 个橙(7)标记像素（在不同行），形成 3x3 = 9 个交叉位置。每个交叉位置是一个 1x1 的彩色像素（颜色来自红(2)、蓝(1)、绿(3)、黄(4)）。9 个像素中大多数在"对应位置"颜色相同（因为它们本应是同一个 3x3 彩色图案的不同副本），但有 1~2 个像素被噪声改为了错误颜色。网格其余位置为黑(0)。生成约束：9 个交叉位置的颜色可视为 3x3 图案的 9 个像素，其中恰好有 1~2 个像素的颜色与该位置的多数投票结果不同。

**规则**：
1. 识别顶行和最右列的橙(7)标记，计算 3x3 = 9 个交叉位置坐标。按行从上到下、列从左到右编号为 (0,0) 至 (2,2)。
2. 将 9 个交叉位置视为 3x3 网格。对于每个局部坐标 (r,c)：该位置只有一个像素，无法直接投票。改为按行投票：同一行的 3 个像素取多数色作为该行的行色。
3. 修正规则：对每行 3 个像素取多数色（出现 2 次及以上的颜色）。若某行 3 个像素颜色各不相同，则保留中间列的颜色。
4. 每行得到一个行色后，形成 3x1 的色序列。但最终输出不按行序，而是将 9 个交叉位置的最终颜色按蛇形顺序读出：第0行从左到右，第1行从右到左，第2行从左到右。
5. 输出为 1x9 的单行网格（或 9x1 列），按蛇形顺序排列去噪后的颜色。对于未被多数投票修正的位置保留原色，被修正的位置替换为行多数色。

**关键洞察**：行多数投票的"多数"规则和蛇形读取的奇偶行翻转规则分别需要从示例中归纳。噪声像素的存在使得不做投票就无法得到正确的蛇形序列，而蛇形顺序使得即使正确去噪但顺序错误也会得到错误输出。
