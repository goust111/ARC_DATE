## 新题 1：分隔列标记编码相位偏移叠加与对角光晕

**组合逻辑**：[计数](创新：计数分隔列中标记像素确定偏移量) → [透明叠加](创新：叠加前对右面板做纵向相位偏移) → [描边 + 对角邻接](创新：对叠加并集而非原始像素做对角装饰)

**来源原语**：透明叠加、分隔列、前景掩码（e133d23d）；计数（37d3e8b2）；相位偏移、平移对称（caa06a1f）；描边、对角邻接（10fcaaa3）

**依赖链**：分隔列中红色标记的数量 K 决定右面板向下平移 K 行；平移后两面板取并集；并集像素产生对角光晕。计数结果改变叠加几何，叠加几何改变光晕分布，三者不可拆分。

按分隔列中标记数平移右面板后叠加两侧掩码，并在并集像素的对角方向涂装饰色。

**输入结构**：约 10x(2W+1) 的网格，W 约 5-7。背景黑(0)。正中一列为分隔列，大部分像素为青(8)，其中散布 K 个红(2) 标记像素（K 在 1-3 之间；不同示例中 K 不同）。分隔列左右各有一个 W 列宽的面板，面板中在黑(0) 背景上散布若干蓝(1) 前景像素（每侧 3-6 个像素，无特定形状，不构成连通块亦可）。两侧面板行数相同（等于网格总行数）。生成约束：两侧前景像素在零偏移下按位置配对时互不重叠；K 的取值使偏移后至少有一对像素在并集中重叠产生新的空间关系。

**规则**：
1. 去除分隔列（整列不进入输出）。统计分隔列中红(2) 像素的个数 K。
2. 将右面板整体向下平移 K 行：上方空出的 K 行补黑(0) 背景，下方超出面板边界的行裁掉。得到偏移后的右面板（大小与原面板相同）。
3. 将左面板与偏移后的右面板按位置逐像素取并集：任一侧为蓝(1) 则结果为蓝(1)，否则为黑(0)。输出网格宽度为 W，高度为原面板高度。
4. 对并集网格中每个蓝(1) 像素，检查其四个对角邻居（左上、右上、左下、右下）。若对角邻居在网格内且当前为黑(0)，将其涂为绿(3)。
5. 冲突解决：若某位置同时是蓝(1) 像素和应被涂绿(3) 的位置，保留蓝(1)。若某位置被多个蓝(1) 像素同时标记为对角邻居，只涂一次绿(3)（幂等操作）。

**关键洞察**：红色标记看似分隔列上的装饰，实际其数量编码了右面板的纵向平移量。平移改变并集形态，进而完全改变对角光晕的分布。仅看一个示例无法区分偏移量是 K 还是其他数值（如 K-1 或列中红色像素最低行号等），需要对比不同 K 值的示例才能确认"数量即偏移量"的规则。

## 新题 2：噪声分量计数驱动信号裁剪体的平铺

**组合逻辑**：[裁剪 + 面积比较](已有：裁剪最大连通分量) + [计数](创新：计数被滤除的噪声分量) → [平铺](创新：噪声数量作为平铺行列因子)

**来源原语**：裁剪、保留最大连通分量、面积比较、连通分量、噪声像素（1f85a75f, be94b721）；平铺、边长决定重复数（ccd554ac）；计数（37d3e8b2）

**依赖链**：面积比较筛出最大分量并裁剪，同一比较过程识别出剩余噪声分量；噪声分量数 N 作为平铺行列数；输出为 N x N 平铺的裁剪结果。噪声不是被丢弃的副产物，而是编码了输出尺寸的关键信息。

裁剪最大前景连通分量，然后按剩余噪声分量数量进行 N x N 平铺。

**输入结构**：约 15x15 网格。背景黑(0)。一个唯一最大的 4-连通单色前景对象（颜色任意，如蓝(1)，面积约 8-15 像素），形状为不规则的 4-连通区域（非矩形，可有内部孔洞）。另有 N 个较小的 4-连通前景分量（N 在 2-4 之间），颜色可各不相同（如红(2)、绿(3)、黄(4) 等），每个面积 1-3 像素，与最大分量空间不相连。不同示例中 N 不同、最大分量的形状不同。生成约束：最大分量面积严格大于所有其他分量面积之和，保证唯一性；N >= 2。

**规则**：
1. 找到所有非背景色的 4-连通连通分量，按像素面积降序排列。
2. 选取面积唯一最大的分量，裁剪至其最小边界框（边界框内非该分量的像素保留为黑(0)，如参考题 1f85a75f / be94b721）。
3. 统计剩余分量（所有面积小于最大分量的 4-连通前景分量）的数量 N（不计最大分量本身）。
4. 将裁剪结果作为瓦片，在水平方向重复 N 次、垂直方向重复 N 次，生成 N x N 的平铺网格。瓦片之间无间隔，像素直接拼接。

**关键洞察**：在参考题中，噪声分量是纯干扰项被丢弃，平铺倍率由网格自身边长决定。本题中噪声分量的数量成为输出尺寸的唯一决定因素——滤掉它们的过程本身产生了关键参数。求解者需要意识到"被排除的对象"仍然在规则中起作用。

## 新题 3：行键重涂色后颜色多样性驱动局部列擦除

**组合逻辑**：[重涂色 + 行首色决定填色](已有：按行控制色重涂) → [计数](创新：统计重涂后每个对象的颜色种数) → [擦除 + 按对象局部裁切](创新：擦除列数由颜色种数动态决定而非固定)

**来源原语**：重涂色、行首色决定填色、控制像素、占位像素、同行对应（c9f8e694）；擦除、按对象局部裁切、连通分量、相对自身定位（52364a65）；计数（37d3e8b2）

**依赖链**：控制像素为每行灰色像素重涂色；统计每个对象被涂了几种不同颜色（D 值）；D 值决定从对象局部左边界擦除几列。重涂色的输出（颜色多样性）成为擦除操作的输入参数，二者不可独立执行。

用行首控制色重涂每个灰色对象的每一行，然后按对象内颜色种数从其局部左侧擦除对应列数。

**输入结构**：约 12x10 网格。背景黑(0)。3-4 个灰(5) 的 4-连通前景对象，各自独立（互不相邻），每个对象跨 2-5 行、4-6 列，形状为不规则但紧凑的 4-连通区域。第 0 列（最左列）在每个与灰色对象相交的行上放置一个彩色控制像素（可用蓝(1)、红(2)、绿(3)、黄(4) 等），同一对象的不同行可以有相同或不同的控制色。所有对象的边界框最小列号 >= 1（不与第 0 列重叠）。不同示例中控制色的分布不同，使得同一对象的 D 值（颜色种数）在不同示例中可能不同。生成约束：每个对象的列跨度 >= 该对象的 D 值 + 1，保证擦除后仍有剩余像素可见。

**规则**：
1. 对每个灰(5) 对象，逐行将灰色像素替换为该行第 0 列控制像素的颜色（与参考题 c9f8e694 相同的逐行重涂逻辑）。
2. 对每个对象，统计重涂后该对象包含多少种不同颜色，记为 D。
3. 在该对象自身的边界框内，从该对象最左边界列起，擦除最左边 D 列中属于该对象的像素（将这些像素设为黑(0) 背景）。擦除仅针对对象的像素，不影响该区域内的背景像素。
4. 第 0 列的控制像素在输出中保留不变。
5. 各对象独立处理，互不影响。处理顺序不影响结果。

**关键洞察**：控制像素不仅决定对象最终的颜色分布，还隐式编码了对象被擦除的程度——控制色种类越多（D 越大）的对象被从左侧裁掉越多。仅观察重涂色步骤或擦除步骤都无法独立推断完整规则；必须发现"颜色多样性→擦除列数"这一非显然的反馈关系。

## 新题 4：实心条的三重角色——包络筛选区、镜像轴与异常值过滤

**组合逻辑**：[包络生成 + 逐步收缩](创新：不可见包络定义空间候选区) + [镜像 + 沿轴反射](创新：生成包络的同一几何体兼做镜像轴) + [异常值选择 + 最少像素颜色](创新：候选区内像素最少的群作为操作目标)

**来源原语**：包络生成、逐步收缩、实心条（c97c0139）；镜像、对称轴、沿轴反射（ad3b40cf）；异常值选择、最少像素颜色（ad3b40cf）；前景像素（ad3b40cf）

**依赖链**：实心条的长度决定菱形包络的范围；包络范围筛选出哪些像素群是候选者；候选者中像素数最少的被选中；该群沿实心条所在行做镜像反射。同一根条同时充当包络生成器、空间过滤器和镜像轴，三重角色不可分离。

水平条定义不可见菱形区域并作为镜像轴，区域内像素最少的彩色群被沿条镜像复制。

**输入结构**：约 15x15 网格。背景黑(0)。一条水平实心条，颜色为青(8)，长度 L（5-9 像素，厚度 1 像素），位于网格纵向中部某一行。4-6 个小型彩色像素群散布于网格各处（每群 2-6 个 4-连通像素，颜色互不相同，如红(2)、绿(3)、黄(4)、橙(7)、品红(6) 等）。部分像素群的几何中心（边界框中心，行列各取整）落在以条为中线的菱形区域内（菱形半径 = floor((L-1)/2)），部分落在区域外。生成约束：菱形区域内恰好有 2-3 个像素群，其中像素数最少的唯一（无平局）；所有像素群与青(8) 条不重叠。

**规则**：
1. 以青(8) 水平条为中线，计算菱形包络区域：条的每个像素向上、向下各延伸若干行，距条端点越远延伸越短（每远离端点一列，上下延伸减少 1 行），构成以条为水平中线的菱形边界。不在输出中绘制该菱形——它仅用于空间筛选。
2. 判断每个彩色像素群的几何中心（边界框中心行列各取 floor 值）是否落在菱形区域内（含菱形边界上的位置）。
3. 在区域内的候选像素群中，找到像素数量最少的那一个。
4. 将该像素群的每个像素 (r, c) 沿青(8) 条所在行 R 做上下镜像反射：映射到 (2R - r, c)。在反射位置涂与原像素相同的颜色。
5. 原像素群保留不变。反射像素若落在其他已有前景像素的位置上，反射像素覆盖原有像素。
6. 菱形区域外的像素群及青(8) 条均保持不变。

**关键洞察**：实心条不只是画面中的视觉分隔——它同时定义了候选范围（通过菱形包络的数学构造）和变换方式（作为镜像轴），而条的长度既决定包络大小也间接决定了哪些像素群有资格被选中。求解者必须发现这三重角色及"最少像素"的选择规则才能正确预测输出。

## 新题 5：格元内最近镜像对填充生成包络种子

**组合逻辑**：[连线/填充 + 最小间距对触发](创新：填充产生的线段不是最终输出而是中间几何体) → [包络生成 + 逐步收缩](创新：以填充线段为种子在格元内生成截断菱形包络) + [标记点阵 + 格元](创新：格元边界裁剪包络)

**来源原语**：连线、填充、最小间距对触发、对称标记对、间隔段、中轴对称（5ad8a7c0）；包络生成、逐步收缩、实心条（c97c0139）；标记点阵、格元、格元内居中（20981f0e）

**依赖链**：标记点阵划分格元；每个格元内有多对镜像标记，仅间距最小的一对被水平填充成线段；线段长度决定菱形包络大小；包络被格元边界裁剪。四层嵌套约束中每层的输出是下一层的输入。

在标记点阵的每个格元内，填充最近镜像对之间的间隔形成线段，再以该线段为种子生成被格元边界截断的菱形包络。

**输入结构**：约 19x19 网格。背景黑(0)。青(8) 像素形成规则笛卡尔点阵，行间距和列间距均为 6 像素，将网格划分为若干大小一致的格元（每个格元内部空间约 5x5，不含点阵标记本身）。每个格元内有 2 对红(2) 像素，每对关于格元的垂直中轴对称（镜像对），分布在格元内的不同行。同一格元内两对的水平间距互不相同（间距范围 1-3 像素，"间距"定义为两像素之间的空背景像素数）。不同格元中最小间距对的间距值可以不同。生成约束：每个格元至少有一对间距为 1 的镜像对；格元内部空间足够容纳最小间距对生成的菱形包络（即包络半径不超过格元半边长）。

**规则**：
1. 识别青(8) 标记点阵，确定格元边界：每个格元是相邻四个标记点围成的矩形的内部区域（不含标记点所在的行列）。
2. 在每个格元内，找出所有关于格元垂直中轴对称的红(2) 像素对，计算每对的水平间距（两像素之间的背景像素数）。
3. 选取间距最小的那一对（若间距平局，选行号较小的）。仅对该对执行水平填充：将两像素之间（不含两端点，端点本身已是红(2)）的所有背景像素涂为红(2)，形成一条水平线段。线段总长 = 间距 + 2（含两端点）。其余未选中的镜像对保持为孤立红(2) 像素不变。
4. 以填充后的线段为中线，生成菱形包络：线段中每个像素向上、向下各延伸若干行，距线段端点越远延伸越短（每远离端点一列，上下延伸减少 1 行），包络半径 = floor((线段长 - 1) / 2)。包络像素涂为绿(3)。
5. 菱形包络超出格元边界的部分不绘制（裁剪）。已有红(2) 像素不被绿(3) 覆盖。
6. 青(8) 标记点阵保持不变。

**关键洞察**：每个格元中的多对标记是干扰——只有间距最近的一对被激活形成线段。间距越小的对产生越短的线段和越小的菱形；而间距较大的未选中对看似更醒目却不参与任何操作。求解者必须理解"点阵→格元→间距选择→填充→包络→裁剪"的完整推导链。

## 新题 6：去遮挡镜像补全后按控制像素数进行像素放大

**组合逻辑**：[擦除 + 去遮挡后镜像还原](已有：去遮挡并镜像补全) → [对称补全](已有) → [计数](创新：统计控制行像素数量) → [像素放大 + 数量决定倍率](创新：控制像素数而非前景像素数作为放大系数)

**来源原语**：擦除、对称补全、镜像、填充矩形、遮挡、去遮挡后镜像还原（3345333e）；像素放大、数量决定倍率、前景数为放大系数（ac0a08a4）；控制像素（c9f8e694）；计数（37d3e8b2）

**依赖链**：去除遮挡矩形暴露缺失部分；检测对称轴并补全形状；统计底行控制像素数 K；将补全结果按 K 倍像素放大。遮挡决定需补全的部分，补全决定放大的形状，控制像素数决定放大倍率——三步严格有序。

去除遮挡矩形并镜像补全对称对象，然后按底行彩色控制像素数做像素级放大。

**输入结构**：约 9x8 的主体区域加底部 1 行控制行，总网格约 10x8。背景黑(0)。主体区域包含一个蓝(1) 单色 4-连通对象（面积约 8-16 像素，形状不规则但具有左右镜像对称性），被一个红(2) 实心矩形部分遮挡（矩形约 2x2 到 3x3，覆盖蓝色对象的一侧使该侧像素不可见）。最底行（第 9 行或最后一行）为控制行：黑(0) 背景上散布 K 个彩色像素（颜色互不相同，如绿(3)、黄(4)、橙(7) 等），K 在 2-3 之间。不同示例中 K 不同，蓝色对象形状不同，遮挡矩形位置不同。生成约束：遮挡矩形恰好覆盖蓝色对象的一个侧翼，使得去除遮挡后可用镜像对称唯一确定缺失像素；控制行像素与主体区域无空间重叠。

**规则**：
1. 在主体区域中，检测红(2) 实心矩形 4-连通分量，将其所有像素设为黑(0)（擦除遮挡物）。
2. 对剩余的蓝(1) 像素，检测左右镜像对称轴（在忽略缺失区域的前提下寻找使已有像素最对称的垂直轴线）。沿该轴将已有蓝(1) 像素镜像反射，在缺失位置填入蓝(1) 像素，完成对称补全。
3. 统计最底行（控制行）中非黑(0) 像素的数量 K。
4. 将补全后的蓝(1) 对象裁剪至其最小边界框（边界框内非对象像素保留为黑(0)）。
5. 对裁剪结果执行像素级放大：每个像素（包括黑(0) 背景）替换为 K x K 的同色像素块。输出网格尺寸为原边界框宽度乘以 K、高度乘以 K。
6. 控制行不包含在输出中。

**关键洞察**：控制行像素的颜色是干扰——它们的数量才编码了放大倍率。求解者容易误以为控制像素的颜色与蓝色对象有映射关系（如重涂色），但实际上只有"有几个控制像素"这一信息被使用。需要对比多个示例（不同 K 值对应不同放大倍率）才能排除颜色映射假说。

## 新题 7：条长环数与精灵体孔洞数的跨域匹配传送

**组合逻辑**：[包络生成](创新：不绘制包络，仅计算环数作为匹配键) + [计数 + 孔洞数映射颜色](创新：孔洞数不映射颜色而是映射目标位置) + [移动](创新：按匹配键将精灵体传送至对应条上方)

**来源原语**：包络生成、逐步收缩、实心条（c97c0139）；计数、孔洞数映射颜色、封闭背景区域、前景对象（37d3e8b2）；移动、精灵体（9aaea919）

**依赖链**：每根条的长度 L 通过菱形公式 floor((L-1)/2) 得到环数 R；每个精灵体的封闭背景孔洞数 H；当 H = R 时建立跨域匹配；匹配的精灵体被移至对应条的正上方。几何属性（条长→环数）与拓扑属性（孔洞数）通过数值相等建立全新的配对关系。

计算每根水平条的菱形包络环数和每个精灵体的内部孔洞数，将孔洞数等于环数的精灵体移至对应条的正上方。

**输入结构**：约 20x15 网格。背景黑(0)。3 条水平实心条，颜色为灰(5)，分布在网格下半部分的不同行（彼此不相邻，行间距 >= 3）。条的长度分别不同，如 3、5、7 像素，对应环数分别为 1、2、3。3 个小型前景精灵体，颜色各不相同（如红(2)、蓝(1)、绿(3)），分布在网格上半部分。每个精灵体是 4-连通单色区域（4-8 像素），其最小边界框内分别包含 1、2、3 个 4-连通的封闭背景孔洞（"封闭"指该背景区域完全被精灵体像素包围，不与边界框外的背景相连）。精灵体和条之间无空间重叠。生成约束：条的环数两两不同；精灵体的孔洞数两两不同；环数集合与孔洞数集合完全相同（{1, 2, 3}），保证一一匹配。

**规则**：
1. 对每条灰(5) 水平条，计算其像素长度 L，得到菱形包络环数 R = floor((L - 1) / 2)。不实际绘制包络。
2. 对每个彩色精灵体，在其最小边界框内统计 4-连通的封闭背景（黑(0)）区域数量 H。"封闭"指从该背景区域出发沿 4-连通方向无法到达边界框外部。
3. 将孔洞数 H 等于环数 R 的精灵体与对应条配对（一一映射）。
4. 清除每个精灵体在原位置的所有像素（设为黑(0)）。
5. 将每个精灵体重新绘制在其配对条的正上方：精灵体边界框的底边紧贴条的上方一行，水平方向上精灵体边界框中心与条的中点对齐（若无法精确居中则偏左一像素）。精灵体保留其原始颜色。
6. 灰(5) 条保持不变。精灵体像素若与条像素在新位置重叠，精灵体像素覆盖。

**关键洞察**：条的长度和精灵体的孔洞数看似无关——一个是一维的线段长度，一个是二维的拓扑属性——但通过菱形包络公式 floor((L-1)/2) 将两者统一到同一数值空间。求解者不能直接用条长匹配孔洞数（3!=1, 5!=2, 7!=3），必须发现中间的数学变换才能建立正确配对。

## 新题 8：遮挡物位置编码图案延伸方向

**组合逻辑**：[擦除 + 遮挡](创新：遮挡物不仅需要移除，其位置还编码延伸方向) + [补全 + 平移对称](创新：同一对称既用于修复缺失又用于延伸) + [相位偏移](创新：延伸方向由遮挡物相对位置隐式决定)

**来源原语**：擦除、填充矩形、遮挡（3345333e）；平铺、补全、平移周期图案、平移对称、相位偏移（caa06a1f）

**依赖链**：擦除遮挡矩形后暴露图案缺失区域；用平移对称修复缺失像素；遮挡物的水平位置（在图案左半还是右半）决定向反方向延伸一个完整周期。遮挡物不仅是干扰，还隐式编码了生长方向。

去除遮挡矩形后用平移对称修复缺失的图案，并向遮挡物对侧方向延伸一个周期。

**输入结构**：约 12x10 网格。背景为橙(7)（从边框最常见颜色推断）。红(2) 前景像素形成一个水平方向的平移周期图案（最小正周期 T 约 3-4 列），图案分布在网格中部若干行，不覆盖全画布。一个绿(3) 实心矩形（约 2x3 到 3x4 大小）遮挡了图案的一部分。不同示例中遮挡物位于图案的左半区域或右半区域。生成约束：去除遮挡物后图案至少完整显示两个完整周期，保证可唯一推断平移向量；遮挡物完全覆盖在图案范围内（其下方确实有被遮挡的红(2) 像素）。

**规则**：
1. 识别绿(3) 实心矩形 4-连通分量，记录其水平中心列号 C_occ，然后将其所有像素设为背景橙(7)。
2. 从剩余红(2) 像素中检测水平方向的最小正平移周期 T（即满足图案沿水平方向平移 T 列后与自身重合的最小正整数 T）。
3. 利用平移对称性，将被遮挡区域中缺失的红(2) 像素补回：对于被擦除区域内的每个位置，用该位置沿水平方向偏移 T 的整数倍处的已知像素值来填充。
4. 计算图案（所有红(2) 像素）的水平范围中心列号 C_pat。比较 C_occ 与 C_pat：
   - 若 C_occ < C_pat（遮挡物偏左），向右延伸：在网格最右侧追加 T 列，用平移对称填充追加区域中的红(2) 像素，其余为橙(7) 背景。
   - 若 C_occ >= C_pat（遮挡物偏右），向左延伸：在网格最左侧前插 T 列，用平移对称填充前插区域中的红(2) 像素，其余为橙(7) 背景。
5. 输出网格宽度 = 原网格宽度 + T，高度不变。

**关键洞察**：遮挡物的位置不仅决定了哪些像素需要修复，还隐含编码了图案应该向哪个方向生长——"遮挡物偏左则向右延伸"。这一条件规则需要对比多个示例中遮挡物位置与延伸方向的对应关系才能归纳出来，仅看一个示例无法确定延伸方向不是固定的。

## 新题 9：跨面板图案交换后像素计数驱动平铺

**组合逻辑**：[交换 + 成对交换 + 底色作为涂色源](已有：面板间图案掩码交换) → [计数](创新：统计交换后某面板的前景像素数) → [平铺](创新：一个面板的像素数决定另一个面板的水平平铺次数)

**来源原语**：交换、分隔面板、图案掩码、成对交换、底色作为涂色源（5a719d11）；平铺、边长决定重复数、阵列排布（ccd554ac）；计数（37d3e8b2）

**依赖链**：两面板之间交换图案掩码并按目标面板底色重涂；交换后统计上面板中前景像素总数 P；将下面板水平重复 P 次生成输出。交换改变了两个面板的内容，而交换后的一个面板的属性（像素数）驱动另一个面板的变换（平铺倍率），形成跨面板的因果链。

交换两面板的图案掩码后，按上面板前景像素数将下面板水平平铺。

**输入结构**：约 (2H+1) x W 的网格，H 约 4-5，W 约 6-8。背景黑(0)。一条水平分隔行（整行为灰(5)）将网格分为上下两个 H x W 的面板。每个面板有一个占主导的底色（上面板底色如蓝(1)，下面板底色如红(2)）和一个少数色的图案掩码（上面板图案色如黄(4)，下面板图案色如绿(3)）。每个面板中图案掩码为 3-6 个像素组成的不规则 4-连通区域。不同示例中图案形状和像素数不同。生成约束：交换后上面板的前景像素数 P 在 2-4 之间（保证平铺倍率合理）；两面板大小相同。

**规则**：
1. 识别灰(5) 水平分隔行，将网格分为上、下两个面板。记录每个面板的底色（面板中出现次数最多的颜色）和图案色（出现次数较少的非背景、非底色颜色）。
2. 交换图案掩码：将上面板清为其底色，然后在上面板中按下面板图案掩码的形状（相同的相对位置）涂上上面板的底色——即下面板的图案形状出现在上面板中，但颜色改为上面板的底色。对下面板做对称操作：清为下面板底色，将上面板的原始图案掩码形状涂为下面板的底色。
   - 更精确地说：上面板的每个像素要么是底色 B_up 要么是图案色。交换后，上面板中原本是图案色的位置变为底色 B_up，而下面板原本是图案色的位置的对应坐标在上面板中变为红(2)（下面板底色）。下面板同理。
3. 统计交换后上面板中前景像素（非底色 B_up 的像素）的总数 P。
4. 将交换后的下面板作为瓦片，水平方向重复 P 次（垂直不重复），生成宽度为 P x W 的下部输出。
5. 输出结构：交换后的上面板（原始大小，1 x W 宽）置于顶部，交换后并水平平铺 P 次的下面板置于底部。分隔行不包含在输出中。输出总尺寸为 H x W（上部）加 H x (P x W)（下部），两部分上下拼接。

**关键洞察**：交换操作不仅改变了面板内容，还通过改变上面板的前景像素数间接决定了下面板的平铺倍率。求解者必须先正确执行交换（理解底色与图案色的角色），才能得到正确的 P 值，再用 P 驱动平铺。若跳过交换直接数原始上面板像素数，将得到错误的平铺倍率。
