## 新题 1：投票恢复残缺精灵后以对称轴补全剩余空位

**组合逻辑**：[投票恢复/majority_vote_recovery](已有) → [对称补全/symmetry_completion](已有，创新：作用于投票无法决定的残余空位，而非直接作用于原始缺失) ← [密集带检测/dense_band_detection](已有) + [双轴镜像轨道/two_axis_orbit](已有，创新：对称轴从投票恢复的部分结果中推断，而非从完整图案推断)

**来源原语**：投票恢复/majority_vote_recovery(0607ce86), 对称补全/symmetry_completion(af22c60d), 密集带检测/dense_band_detection(0607ce86), 双轴镜像轨道/two_axis_orbit(af22c60d), 插槽阵列/slot_array(0607ce86), 缺失像素/missing_pixel(484b58aa/af22c60d), 忽略干扰项/ignore_distractors(0607ce86)

**依赖链**：密集带检测定位插槽阵列 → 投票恢复在各槽位间取逐像素多数色，但部分像素因腐蚀严重无法得到唯一多数色（平票） → 平票位置标记为未知 → 已恢复的像素揭示精灵具有单轴镜像对称性 → 用该对称轴的镜像轨道为每个未知像素找到已知的镜像伙伴 → 填入伙伴颜色完成恢复。投票与对称是两种独立的信息来源，在各自适用范围内互补，缺一不可。

用投票聚合多份噪声副本得到部分精灵，再用恢复出的对称性补全投票无法决定的残余空位，最后将干净精灵回写所有槽位并擦除槽外噪声。

**输入结构**：
- 网格约 20x25，背景黑(0)。
- 非背景像素形成密集的行带和列带，交叉处为矩形插槽（如 4 行 x 5 列的 4x4 插槽，槽间隔 1 像素背景）。每个插槽包含同一精灵的一份腐蚀副本。
- 精灵使用蓝(1)和红(2)两色在黑(0)背景上绘制，是一个 4-连通的不规则图形（约 8~12 像素）。精灵本身具有左右镜像对称性（以其边界框的垂直中轴为对称轴），但这一对称性在单份腐蚀副本中无法识别。
- 腐蚀方式：每个副本中 1~3 个像素被随机翻转（前景 → 背景或背景 → 前景、前景色互换）。在精灵的某些对称像素对上，腐蚀恰好使所有副本中该位置无唯一多数色（例如 10 个副本中 5 份为蓝(1)、5 份为红(2)）。
- 槽外散布少量噪声像素（蓝(1)或红(2)），密度远低于槽内密集带。
- 生成约束：精灵的对称轴将像素分为若干镜像轨道，每条轨道中至少有一个位置在投票中能确定唯一多数色；平票位置不超过精灵总像素数的 1/3。

**规则**：
1. 找到密集行带和密集列带的交集，确定插槽阵列的行列结构与每个槽的边界。
2. 对精灵的每个相对位置，统计所有槽内该位置出现的各颜色次数。若某颜色严格超过半数，则该位置恢复为此颜色；若无严格多数（含平票），标记为"未知"。
3. 从已恢复（非未知）像素中确定精灵边界框内的垂直镜像对称轴：找到列偏移量 c 使得所有已知像素对 (r, c-d) 与 (r, c+d) 颜色一致且支持数最多、无矛盾。
4. 对每个未知位置，取其关于对称轴的镜像位置。若镜像位置已知，则将未知位置填入镜像位置的颜色。若镜像位置也未知，则该对称对中必有第三步骤遗漏的间接证据——通过所有槽的颜色计数中取出现次数更多的颜色（非严格多数但相对最多）填入两个位置。
5. 将恢复完整的精灵回写到每个插槽。将所有不属于任何插槽的非背景像素设为黑(0)背景。

**关键洞察**：投票恢复和对称补全各自只能解决部分像素——投票处理随机噪声，对称处理系统性歧义——两者交汇才能完整重建精灵；对称轴本身也必须从投票的局部结果中推断，而非预先已知。

## 新题 2：拓扑内外分类决定标记点的对角射线发射方向

**组合逻辑**：[连通分量检测/connected_component_detection](已有) → [拓扑分类/topological_classification](已有，创新：分类结果不直接重涂色，而是决定后续操作的启用条件) → [射线延伸/ray_extend](已有，创新：发射方向由标记在封闭区域内的相对空间位置编码，而非由颜色或固定方位决定)

**来源原语**：连通分量检测/connected_component_detection(84db8fc4), 拓扑分类/topological_classification(84db8fc4), 边界可达性/edge_reachability(84db8fc4), 重涂色/recolor(84db8fc4/c1d99e64), 射线延伸/ray_extend(5c0a986e), 对角方向/diagonal_dir(5c0a986e), 单点标记/singleton_marker(09c534e7), 标记在分量内/marker_inside_component(09c534e7)

**依赖链**：连通分量检测将背景分区 → 边界可达性判断区分封闭区域与边缘可达区域 → 仅封闭区域内存在单点标记 → 标记在区域边界框内的象限位置编码射线方向（左上象限→左上对角，右下象限→右下对角，等） → 射线从标记出发沿该方向绘制至碰撞。拓扑分类是射线发射的门控条件，空间象限是方向编码。

根据背景区域的拓扑属性（封闭/开放）筛选有效标记，再由标记在封闭区域内的空间象限决定对角射线方向，仅从封闭区域的标记发射射线。

**输入结构**：
- 网格约 18x18，背景黑(0)。
- 绿(3)像素形成不规则的连通屏障网络（类似迷宫墙壁，宽度 1 像素，4-连通），将黑(0)背景分割为若干 4-连通区域。
- 部分区域触及网格边缘（边缘可达），部分被绿(3)屏障完全包围（封闭）。
- 每个封闭区域内恰好有一个单像素标记，颜色为红(2)或蓝(1)。边缘可达区域内无任何标记。
- 每个封闭区域面积至少 4 像素（含标记），边界框至少 2x2，使标记可被唯一分配到边界框的某一象限。
- 生成约束：标记不在边界框的中轴线上（若边界框宽或高为偶数，中轴在两列/行之间，标记自然落入某象限；若为奇数，标记不在正中行/列上）。

**规则**：
1. 将所有黑(0)像素按 4-连通划分为区域。
2. 一个区域若有任一像素位于网格第 0 行、最末行、第 0 列或最末列，则标记为"边缘可达"；否则标记为"封闭"。
3. 边缘可达区域内的所有黑(0)像素重涂为灰(5)。封闭区域保持黑(0)不变。
4. 对每个封闭区域，找到其唯一的单点标记。计算该区域所有黑(0)像素（含标记位置）的边界框。标记位于边界框的哪个象限决定射线方向：
   - 标记行 ≤ 边界框垂直中线 且 标记列 ≤ 边界框水平中线 → 左上对角（行-1, 列-1）
   - 标记行 ≤ 垂直中线 且 标记列 > 水平中线 → 右上对角（行-1, 列+1）
   - 标记行 > 垂直中线 且 标记列 ≤ 水平中线 → 左下对角（行+1, 列-1）
   - 标记行 > 垂直中线 且 标记列 > 水平中线 → 右下对角（行+1, 列+1）
5. 从标记位置出发，沿确定的对角方向逐像素前进。每步将当前位置涂为标记的颜色（红(2)或蓝(1)），覆盖任何已有颜色（包括绿(3)屏障和灰(5)）。射线在下一步超出网格边界时停止。
6. 绿(3)屏障中未被射线覆盖的像素保持绿(3)。

**关键洞察**：射线方向不是由标记颜色或全局方位决定的，而是由标记在其所属封闭区域边界框内的相对位置隐式编码——必须先完成拓扑分类才能确定哪些区域参与射线发射，再通过空间分析才能确定方向。

## 新题 3：图例控制重力溢出方向与级联变色

**组合逻辑**：[重力下落/gravity_drop](已有) → [溢出扩散/overflow_spread](已有，创新：溢出方向不再是双侧对称，而由图例编码的单侧规则控制) ← [编码映射/encoding_map](已有，创新：编码内容从转向角度变为溢出侧向) + [重涂色/recolor](已有，创新：溢出液体在经过每层架子时变色为架子颜色，形成级联变色链)

**来源原语**：重力下落/gravity_drop(36a08778), 溢出扩散/overflow_spread(36a08778), 级联分支/cascading_branch(36a08778), 架子/shelf(36a08778), 水源/water_source(36a08778), 碰撞停止/collision_stop(36a08778), 图例条/legend_bar(e87109e9), 编码映射/encoding_map(e87109e9/dbff022c), 重涂色/recolor(多题)

**依赖链**：水源颜色确定初始液体色 → 液体下落至架子 → 图例将架子颜色映射为溢出方向（左/右/双侧） → 液体从指定侧溢出 → 溢出液体变色为该架子的颜色 → 变色后的液体继续下落遇到下一层架子 → 再次查图例确定新的溢出方向 → 液体再次变色。每层架子同时改变液体的颜色和流向，形成颜色-路径的联动级联。

水源向下滴落，遇到彩色架子后按图例规定的方向溢出，且液体在每次溢出时变为架子颜色，形成逐层变色的瀑布树。

**输入结构**：
- 网格约 20x20，背景黑(0)。
- 顶部 1~2 行内有若干水源像素，颜色为蓝(1)，每个水源为 1~2 像素宽的色块紧贴顶行。
- 中部和下部散布若干水平架子，每个架子是同一颜色的水平线段（宽 3~7 像素，高 1 像素）。架子颜色取自红(2)、绿(3)、黄(4)、橙(7)，同一颜色可出现多个架子。
- 底部最末两行为图例区：倒数第 2 行列出所有架子颜色（每种颜色占 1 像素，间隔 1 像素黑(0)），倒数第 1 行在每种颜色的正下方放置一个灰(5)指示像素。指示像素相对于其上方颜色像素的水平偏移编码溢出方向：指示像素在颜色像素的左侧 1 格 → 仅从架子左端溢出；在右侧 1 格 → 仅从架子右端溢出；正下方（偏移 0）→ 从两端同时溢出。
- 生成约束：不同颜色的架子在垂直投影上不完全重叠（保证液体路径唯一可追踪）；每条液体流的所有级联路径最终不会有两条不同颜色的流汇入同一像素。

**规则**：
1. 从每个水源像素开始，液体以蓝(1)色向下逐行移动，将经过的黑(0)像素涂为当前液体颜色。
2. 液体碰到架子的某个像素时停止下落。液体在架子的整个水平跨度上方 1 行铺开（将该行中架子跨度范围内的黑(0)像素涂为当前液体颜色），然后从图例中查找该架子颜色对应的溢出方向。
3. 溢出规则：若图例指示"仅左侧"，液体从架子左端向左 1 格、架子所在行的位置出发向下继续滴落；若"仅右侧"，从右端向右 1 格出发向下滴落；若"两侧"，从左端左 1 格和右端右 1 格各出发一条新的向下液流。
4. 溢出的液体颜色变更为该架子的颜色（不再是之前的颜色），后续路径中涂色均使用新颜色。
5. 变色后的液体继续向下滴落，若再遇到新架子，重复步骤 2~4。若溢出位置已超出网格列范围，该方向的液流终止。液流到达网格底行时停止。
6. 输出中移除图例区（底部 2 行不出现在输出中，输出网格高度比输入少 2 行）。架子本身在输出中保持不变。

**关键洞察**：每层架子同时扮演两个角色——作为路径分支节点（溢出方向由图例决定）和作为颜色转换器（液体在此变色）。下游架子的溢出方向又取决于新颜色在图例中的映射，因此颜色变化反过来影响路径走向，形成颜色与路径的紧耦合级联。

## 新题 4：对称推断缺失锚点后连线并按边界锚点奇偶填色

**组合逻辑**：[对称补全/symmetry_completion](已有，创新：补全的不是像素颜色而是锚点的存在性) → [连线/connect](已有) → [洪泛填充/flood_fill](已有，创新：填充颜色由封闭区域边界上的锚点数量的奇偶性决定)

**来源原语**：对称补全/symmetry_completion(af22c60d), 连线/connect(60a26a3e), 空心十字标记/hollow_plus_marker(60a26a3e), 同行同列对齐/same_row_column_alignment(60a26a3e), 仅相邻锚点间连接/connect_only_between_adjacent_anchors(60a26a3e), 洪泛填充/flood_fill(00d62c1b), 封闭区域/enclosed_region(00d62c1b/89565ca0), 计数/counting(89565ca0), 仅填封闭内部/fill_enclosed_only(00d62c1b)

**依赖链**：观察已有锚点的排布发现其具有关于某轴的镜像对称性 → 对称推断出缺失锚点的位置并补全 → 对所有锚点（原有 + 补全）执行行列对齐连线 → 连线网络围出若干封闭区域 → 统计每个封闭区域边界上的锚点数量 → 奇数个锚点的区域填黄(4)，偶数个填橙(7)。任一步骤的错误都会导致区域结构和填色全部改变。

通过镜像对称补全缺失的十字标记，再在所有标记间连线，最后按每个封闭区域边界上标记数量的奇偶性决定填充颜色。

**输入结构**：
- 网格约 17x17，背景黑(0)。
- 散布若干红(2)空心十字标记，每个标记是 3x3 区域中仅上、下、左、右四个臂像素存在（中心和四角为黑(0)），共 4 像素。
- 所有标记的中心位置关于网格的一条垂直对称轴具有镜像对称关系，但有 2~4 个标记被移除（那些位置全为黑(0)），破坏了对称性。移除的标记位于对称轴的同一侧，使得该侧标记稀疏、另一侧完整。
- 标记中心之间的行列间距至少为 4（保证标记不相邻或重叠）。部分标记的中心共享行坐标或列坐标。
- 生成约束：对称轴为网格的垂直中轴线（列索引 = (宽度-1)/2，网格宽度为奇数）。补全缺失标记后，相邻对齐的标记对在行或列方向上之间没有第三个标记插入。补全后的连线网络至少形成 2 个封闭区域。

**规则**：
1. 确定对称轴：网格垂直中轴线（列索引 = (宽度-1)/2）。
2. 对每个现有标记中心 (r, c)，检查其镜像位置 (r, 宽度-1-c) 是否存在标记。若不存在，在镜像位置绘制一个完整的红(2)空心十字标记。对称轴上的标记（c = 中轴列）镜像为自身，无需处理。
3. 计算所有标记（原有 + 补全）的中心坐标。
4. 对共享同一行的标记中心，按列从左到右排序。相邻两个中心之间，沿该行将两个标记外臂之间的所有黑(0)像素涂为蓝(1)（连线）。具体地：从左标记中心列+2 到右标记中心列-2 之间该行的所有像素涂蓝(1)。
5. 对共享同一列的标记中心，按行从上到下排序。相邻两个中心之间，沿该列将两个标记外臂之间的所有黑(0)像素涂为蓝(1)。具体地：从上标记中心行+2 到下标记中心行-2 之间该列的所有像素涂蓝(1)。
6. 找到所有被红(2)标记和蓝(1)连线完全围合的 4-连通黑(0)区域（封闭区域：该区域的所有黑(0)像素均不能通过 4-连通路径到达网格边缘而不穿过非黑像素）。
7. 对每个封闭区域，统计其边界上（与该区域的黑(0)像素 4-邻接的所有非黑像素中）属于标记的像素所归属的不同标记数量。若该标记数量为奇数，将区域填充为黄(4)；若为偶数，填充为橙(7)。
8. 非封闭的背景区域保持黑(0)。所有红(2)标记和蓝(1)连线保持不变。

**关键洞察**：缺失标记的位置只能通过全局对称性推断；补全标记后连线网络的拓扑结构才确定；填色规则依赖于封闭区域与标记的局部接触关系，而非区域面积或位置——必须三步联动才能得到正确输出。

**输入结构**：
- 网格约 10x30（宽远大于高），背景黑(0)。

- 每个精灵内部恰好有一个像素位置满足其 3x3 邻域全在精灵占据的像素范围内。该位置上放置一个单点标记，颜色在面板间按固定循环变化，循环使用红(2)、绿(3)、黄(4)三色（如面板 1 为红(2)，面板 2 为绿(3)，面板 3 为黄(4)，面板 4 回到红(2)）。
- 生成约束：精灵形状保证恰好有一个内部像素（满足 3x3 全包含条件）。运动轨迹外推一帧后精灵不超出面板边界。循环长度为 3（固定使用红绿黄三色）。

**规则**：
1. 识别帧序列：各面板从左到右依次为第 1、2、3、…帧。
2. 测量精灵的垂直位移：记录每帧精灵边界框的顶行在面板局部坐标中的位置，得到等差数列 {y1, y2, …}，公差 dy = y2 - y1。
3. 记录每帧标记像素的颜色序列 {c1, c2, c3, …}，确定循环周期和下一帧应出现的颜色 c_next。
4. 输出为一个独立面板（与输入面板同高同宽，灰(5)边框，黑(0)填充），其中：
   - 精灵绘制在局部行位置 y_last + dy 处（列位置不变），颜色仍为蓝(1)。
   - 精灵中满足 3x3 邻域全包含条件的像素重涂为 c_next。
   - 其余精灵像素保持蓝(1)。

**关键洞察**：本题要求同时推断两个独立的外推序列（空间位移的等差数列和颜色的循环序列），并将两个预测结果交叉应用到同一输出中——仅正确外推位置或仅正确外推颜色都不能生成正确输出。

**规则**：
1. 从现有精灵的中心坐标集合中找到水平平移向量 (0, dx) 和垂直平移向量 (dy, 0)，使得沿这两个向量平移后与另一个现有精灵重合的次数最多且无位置矛盾。
2. 用平移向量生成完整的二维周期网格。凡完整网格中有位置但输入中该位置没有精灵的，标记为缺失。
3. 确定缺失精灵的边框色：对于缺失位置 P，在完整周期网格中找到与 P 在同一平移等价类中的现有精灵（即通过整数倍平移向量可达的现有精灵），取其边框色作为 P 的边框色。
4. 在每个缺失位置绘制对应边框色和形状的空心精灵（形状与现有精灵相同）。
5. 读取底部图例，建立边框色 → 填充色的映射。
6. 对所有精灵（原有 + 补全），将其封闭的黑(0)内部区域填充为图例中对应的填充色。
7. 输出中移除底部图例区（输出网格高度比输入少 2 行）。

**关键洞察**：周期恢复和图例填充在不同维度上提供信息——周期性告诉"在哪里放什么颜色的边框"，图例告诉"每种边框里填什么颜色"——两层信息在最终输出中交汇，缺失任一层都无法确定完整输出。

## 新题 9：三角朝向决定投射方向后在落点印章模板

**组合逻辑**：[投射发射/projectile_fire](已有，创新：投射物不产生碰撞变色，而是在落点触发印章操作) ← [朝向编码方向/orientation_encodes_direction](已有) → [印章覆盖/stamp_overlay](已有，创新：印章位置不是预设格子而是由投射物动态确定) + [擦除/erase](已有)

**来源原语**：投射发射/projectile_fire(409aa875), 三角精灵体/triangle_sprite(409aa875), 朝向编码方向/orientation_encodes_direction(409aa875), 碰撞变色规则/collision_recolor_rule(409aa875), 印章覆盖/stamp_overlay(5a5a2103), 模板掩码/template_mask(5a5a2103), 擦除/erase(d35bdbdc/0607ce86), 碰撞停止/collision_stop(e87109e9/36a08778)

**依赖链**：三角精灵的几何朝向编码发射方向 → 从三角顶点沿该方向发射投射物 → 投射物在碰到非背景像素或网格边缘前一格停止 → 在落点位置以三角的颜色印章模板掩码 → 多个印章重叠时近距离发射优先 → 擦除所有原始三角。朝向决定路径，路径决定落点，落点决定印章位置，颜色决定印章颜色。

读取三角精灵的朝向以确定发射方向，沿该方向发射投射物至碰撞停止，在落点处以该三角的颜色印章一个公共模板，最后擦除所有三角。

**输入结构**：
- 网格约 20x20，背景黑(0)。
- 3~5 个三角精灵分散在网格中。每个三角由 3 个同色像素组成，排列为直角 L 形：2 个像素沿某基本方向相邻排成一排，第 3 个像素在排头垂直方向偏移 1 格，三像素形成一个直角。每个三角颜色互不相同，取自红(2)、绿(3)、黄(4)、橙(7)、品红(6)。
- 直角的开口方向（缺失像素方向）就是该三角的发射方向：若 3 像素占据了 2x2 区域的三个角，缺失的那个角所在的方向即为发射方向。
- 网格某个角落（如左下角的 4x4 区域内）放置一个灰(5)模板掩码，由 3~5 个灰(5)像素组成的 4-连通小图形，形状不规则。
- 生成约束：每个三角的投射路径上在到达网格边缘之前不会碰到另一个三角（路径不穿越其他三角）；模板掩码位于角落，不在任何三角的投射路径上。所有落点位置使得印章的模板掩码（以落点为模板边界框的中心）完全在网格范围内。

**规则**：
1. 确定模板掩码：灰(5)像素构成的连通图形。记录其相对于自身边界框中心的像素偏移集合 S。
2. 对每个三角精灵，确定其发射方向：将三角的 3 个像素放入最小 2x2 边界框中，缺少的那个角的方向即为发射方向（上、下、左、右之一）。确定发射起点为三角直角顶点（离缺角最远的那个像素）。
3. 从发射起点沿发射方向逐像素前进。忽略模板掩码位置（灰(5)像素视为可穿越）。在碰到其他非背景非灰(5)像素或下一步超出网格边界时停止。落点 = 停止时的最后一个背景像素位置（即碰撞前一格；若到达网格边缘，落点为最后一个网格内像素）。
4. 在落点处印章模板：以落点坐标为中心，将偏移集合 S 中的每个偏移位置涂为该三角的颜色（覆盖黑(0)背景）。若某偏移位置超出网格范围，忽略该像素。
5. 若两个印章在某像素重叠（两个三角的落点使得模板覆盖了同一像素），该像素取发射距离更短（起点到落点的曼哈顿距离更小）的三角颜色。若距离相等，取发射起点行号更小的三角颜色；行号仍相等则取列号更小的。
6. 擦除所有原始三角精灵（将其 3 个像素设为黑(0)）。保留灰(5)模板掩码不变。

**关键洞察**：三角的几何结构（哪个角缺失）隐式编码了发射方向，而落点位置取决于路径上的障碍物分布——方向编码和空间布局共同决定模板印章的位置，使得同一模板以不同颜色出现在不同位置。

## 新题 10：双向射线可达性构建连通图后在图内传递中心色

**组合逻辑**：[射线延伸/ray_extend](已有，创新：射线不绘制在网格上，仅用于判断可达性) → 可达性构建无向图 → [颜色查找键/color_lookup_key](已有，创新：查找键从精灵边框色变为射线连通图中的邻居关系) → [重涂色/recolor](已有)

**来源原语**：射线延伸/ray_extend(5c0a986e/e87109e9), 碰撞停止/collision_stop(e87109e9/36a08778), 颜色查找键/color_lookup_key(d35bdbdc), 路径连通/path_connectivity(d35bdbdc), 端点决定目标/endpoint_determines_destination(d35bdbdc), 重涂色/recolor(d35bdbdc/09c534e7), 单点标记/singleton_marker(09c534e7), 标记在分量内/marker_inside_component(09c534e7)

**依赖链**：每个有框精灵向四方发射探测射线 → 射线碰到另一精灵的边框则建立"可达"边 → 可达关系必须双向（A 能射到 B 且 B 能射到 A）才建立连接 → 连接形成无向图 → 在图中，每个精灵将自己的中心色发送给距离最近的连接邻居（图论距离为 1 的邻居中曼哈顿距离最近的） → 接收者的中心色被替换 → 未连接的精灵保持不变。空间射线建立逻辑连接，逻辑连接决定颜色传递方向。

每个有框精灵向四方探测，与能双向直线到达的精灵建立连接，每个精灵将自己的中心色传递给最近的连接邻居，替换其中心色。

**输入结构**：
- 网格约 20x20，背景黑(0)。
- 4~6 个有框精灵分散在网格中。每个精灵为 3x3 矩形，外圈 8 个像素为统一的边框色，中心 1 个像素为不同于边框的中心色。不同精灵的边框色互不相同，取自红(2)、蓝(1)、绿(3)、黄(4)、橙(7)、品红(6)。中心色也互不相同，且与任何精灵的边框色都不同，取自灰(5)、青(8)、栗(9)等。
- 精灵之间的空间排布使得部分精灵对之间存在无障碍的水平或垂直直线视线（两精灵沿同一行或同一列，中间全为黑(0)背景），另一些精灵对之间视线被第三个精灵阻挡。
- 生成约束：不存在三个精灵在同一行或同一列上共线的情况（避免中间精灵同时阻挡和被阻挡的歧义）。每个精灵至少与一个其他精灵有双向可达连接。图中无孤立节点。每个精灵恰好有 1 个最近连接邻居（不存在距离并列）。

**规则**：
1. 对每个精灵 A，从 A 的边框的上、下、左、右四个边中心位置各发出一条探测射线（不绘制在网格上）。射线沿对应方向逐像素行进，在碰到任何非黑(0)像素时停止。若停止时碰到的像素属于某精灵 B 的边框，则记录"A 可达 B 于该方向"。
2. 对每对精灵 (A, B)，若 A 可达 B（从某方向）且 B 可达 A（从某方向，不要求方向相反），则建立无向边 (A, B)。若仅单向可达，不建立边。
3. 对每个精灵 A，在其所有连接邻居（图中与 A 有边的精灵）中，找到曼哈顿距离最近的邻居 N（距离定义为两精灵中心像素之间的曼哈顿距离）。A 将自己的当前中心色"发送"给 N。
4. 所有发送同时执行（使用输入时的原始中心色，而非传递过程中已更新的颜色）。每个精灵收到的颜色替换其中心像素。若一个精灵同时收到多个颜色（多个精灵都将它视为最近邻居），取所有发送者中边框色在网格中行优先-列次优先位置最靠左上的那个发送者的中心色。
5. 未被任何精灵指定为最近邻居的精灵，其中心色不被替换（但该精灵自己发送给别人的操作仍然执行）。
6. 边框色保持不变，背景保持不变。

**关键洞察**：空间上的直线可达性不等于逻辑上的连接——必须双向可达才构成连接边。连接图的拓扑结构决定了颜色传递的方向和目标，而空间距离在图的邻居中进一步筛选出唯一接收者；这种"空间 → 图 → 空间"的推理链是本题的核心。
