## 新题 1：高度排名驱动的印章色选择

**组合逻辑**：[排序/height_ranking] → [印章覆盖/stamp + 中心展开/center_expansion]（创新：印章颜色不固定，由排名位决定） → [循环填充/cycle_fill]（创新：色循环的索引来自高度排名而非空间位置）

**来源原语**：排序/高度排名(参考题13 a61f2674)、印章覆盖/中心展开(参考题1 b60334d2)、循环填充/色彩循环(参考题6 72207abc)

**依赖链**：必须先测量所有竖线高度并排名，才能确定每根竖线对应的色循环索引；排名结果决定印章颜色，两步不可跳过也不可互换。

将散布的单色竖线按高度排名，在每根竖线的顶端像素为中心印出 3x3 十字图案，图案颜色由该竖线在高度排名中的序位从固定色循环中取得。

**输入结构**：约 15x20 的黑(0)背景网格。前景为 4~7 根灰(5)色、宽度 1 像素的竖直线段，高度各不相同（范围 2~8 像素），水平间距至少 3 列（保证 3x3 印章互不重叠）。每根竖线顶端距网格顶边至少 1 行（为印章留空间）。无其他前景元素。生成约束：所有竖线高度互不相同。

**规则**：
1. 测量每根灰(5)竖线的高度（像素数），按高度从小到大排名，最矮的排名为 1，次矮为 2，依此类推。
2. 定义色循环为 [蓝(1), 红(2), 绿(3), 黄(4), 品红(6)]，长度为 5，循环索引从 1 开始。
3. 对排名为 k 的竖线，计算色循环索引 = ((k-1) mod 5) + 1，取对应颜色 C。
4. 擦除该竖线所有灰(5)像素为黑(0)。
5. 以该竖线原顶端像素为中心，画 3x3 十字图案：四个正交邻居涂颜色 C，四个对角邻居涂灰(5)，中心涂黑(0)。
6. 超出网格边界的印章像素舍弃。

**关键洞察**：印章颜色既不由竖线自身颜色决定也不由空间位置决定，而是由全局高度排名通过色循环间接决定——必须先完成全局排序才能确定每个局部印章的颜色。

## 新题 2：遮罩修复后的面积竞争生长

**组合逻辑**：[补全/infer_from_parallel]（修复十字遮罩） → [计数/面积计算]（创新：修复后才能计算真实面积） → [生长/grow + 面积最大者/largest_area]（创新：生长量由面积排名差驱动，非固定步数）

**来源原语**：补全/从平行行列推断(参考题7 b7955b3c)、计数(参考题15 d0f5fe59)、生长/面积最大者(参考题17 df978a02)

**依赖链**：遮罩破坏了对象的真实面积信息→必须先修复才能得到正确面积→面积排名决定生长量→生长结果依赖前两步的正确完成。三步形成严格信息依赖。

修复被灰色十字遮罩破坏的彩色对象，计算修复后的真实面积，然后让面积最大的对象向外生长，生长像素数等于最大面积与次大面积之差。

**输入结构**：约 15x15 的黑(0)背景网格。包含 3~4 个单色 8-连通对象，颜色互不相同，取自 [蓝(1), 红(2), 绿(3), 黄(4)]，每个对象面积在 6~15 像素之间，形状不规则（非矩形）。其中 1~2 个对象被灰(8)色 3x3 十字遮罩（中心+四正交邻居）部分覆盖，遮罩中心落在对象内部。非遮罩区域的网格由水平和垂直的颜色条带构成，使得被遮盖的像素可从同行或同列的未遮盖像素推断。生成约束：修复后各对象面积互不相同；面积最大的对象边界处有足够背景空间容纳生长。

**规则**：
1. 识别所有灰(8)像素为遮罩损伤。对每个灰(8)像素，从同行或同列的非灰像素中推断其原始颜色（优先使用完全匹配的平行行/列模板；若无，取该行/列中距离最近的同色邻居的颜色）。将灰(8)替换为推断颜色。
2. 修复完成后，计算每个彩色 8-连通对象的面积（像素数）。
3. 找到面积最大的对象 M 和面积次大的对象 S，计算差值 D = area(M) - area(S)。
4. 对对象 M，向外生长 D 个像素：从 M 的边界像素出发，逐层（BFS）向 8-连通的黑(0)背景像素扩展，共扩展 D 层，新像素涂 M 的颜色。
5. 其他对象保持不变。

**关键洞察**：遮罩同时破坏了多个对象的面积信息，修复结果可能改变面积排名——不修复就生长会导致错误的对象被选中或错误的生长量。

## 新题 3：瓷砖反转编码对角连线

**组合逻辑**：[反转填充/occupancy_inversion]（逐瓷砖执行） → [计数/counting]（创新：统计反转后每块瓷砖的前景像素数） → [连线/connect + 中心对角对齐/center_diagonal_alignment]（创新：连线条件由像素计数的相等关系决定）

**来源原语**：反转填充/瓷砖网格排列(参考题11 1c0d0a4b)、计数(参考题15 d0f5fe59)、连线/中心对角对齐(参考题19 55059096)

**依赖链**：必须先在每块瓷砖内执行反转填充，才能得到正确的前景像素数；只有像素数相同且中心对角对齐的瓷砖对才连线——两个条件缺一不可，且第一个条件依赖反转结果。

在分隔的瓷砖网格中执行占位反转，统计反转后各瓷砖的前景像素数，然后在像素数相同且中心共对角线的瓷砖对之间画红色对角连线。

**输入结构**：约 15x15 的黑(0)背景网格。绿(3)色的完整行和完整列将网格分割为 3x3 或 4x4 的瓷砖区域（瓷砖排列为 3 行 3 列共 9 块）。每块瓷砖内部有若干蓝(1)色前景像素（1~6 个不等），其余为黑(0)背景。生成约束：反转后至少存在两对瓷砖满足"像素数相同且中心共 45 度对角线"；不存在三块或更多瓷砖同时满足此条件（避免歧义）。

**规则**：
1. 保持绿(3)分隔线不变。
2. 在每块瓷砖内部独立执行占位反转：将蓝(1)像素擦为黑(0)，将黑(0)像素涂为红(2)。
3. 统计每块瓷砖内红(2)像素的数量 N_i。
4. 对所有瓷砖对 (i, j)，若 N_i = N_j 且瓷砖 i 的中心与瓷砖 j 的中心位于同一条 45 度对角线上（行差的绝对值等于列差的绝对值），则在两个中心之间的对角路径上所有经过的分隔线交叉点和背景像素涂为橙(7)。
5. 连线仅涂在分隔线像素和瓷砖间的间隙上，不覆盖瓷砖内部已有的红(2)像素。若连线路径经过的分隔线像素，将其从绿(3)改为橙(7)。

**关键洞察**：连线条件依赖反转后的像素计数而非原始图案——原始图案中前景像素多的瓷砖反转后前景反而少，直觉上的"相似瓷砖"判断会被反转颠覆。

## 新题 4：周期推断与象限镜像扩展

**组合逻辑**：[补全/periodic_translation + 周期偏移延续行]（推断并补全缺失行） → [镜像/四向对称扩展/four_way_symmetric_expansion]（创新：先补全再镜像，补全错误会被镜像放大四倍）

**来源原语**：补全/周期平移/周期偏移延续行(参考题20 53b68214)、镜像/四向对称扩展(参考题3 833dafe3)

**依赖链**：输入只给出不完整的周期行图案（缺失下半部分）；必须先推断周期和水平偏移量并补全，才能得到完整的矩形图案；然后将完整图案作为右下象限进行四向镜像扩展。补全的正确性直接决定最终四倍面积输出的正确性。

将一个不完整的周期行图案先补全为完整方块，再以该方块为基础进行四向镜像扩展。

**输入结构**：约 5x10 的黑(0)背景网格（宽 10，高 5）。前景为黄(4)像素，分布在前 3~4 行中形成水平行图案，每行的黄色像素位置相对上一行有固定水平偏移（周期 = 2~3 行，每周期水平偏移 1~2 列）。最底部 1~2 行为纯黑（这是需要补全的缺失行）。生成约束：补全后的图案恰好形成 5x10 的完整矩形；水平偏移量和垂直周期可从已有行唯一确定。

**规则**：
1. 从已有的前景行中推断垂直周期 P 和每周期的水平偏移量 S：找到最小的 P 使得第 r 行的图案等于第 r-P 行的图案向右平移 S 列（超出右边界的像素从左侧环绕）。
2. 对每个缺失行 r（纯黑行），用第 r-P 行的图案向右平移 S 列生成，超出边界的像素环绕到另一侧。
3. 得到补全后的 5x10 矩形图案，将其视为右下象限。
4. 生成左下象限：对右下象限做左右镜像。
5. 生成右上象限：对右下象限做上下镜像。
6. 生成左上象限：对右下象限做上下+左右双镜像。
7. 输出为 10x20 的网格，四个象限拼合。

**关键洞察**：周期偏移的环绕特性使得镜像后在拼接边界处图案可能不连续——求解者必须正确处理环绕才能得到看起来"对"的四向对称结果。

## 新题 5：并集识别驱动的弹性拉伸目标选择

**组合逻辑**：[像素并集/pixel_union + 双掩码并集等三/two_union_eq_third]（识别哪个精灵体是并集结果） → [弹性拉伸/elastic_stretching + 按目标尺寸调整/resize_to_target]（创新：并集结果作为模板被拉伸填入目标矩形）

**来源原语**：像素并集/双掩码并集等三(参考题14 fea12743)、弹性拉伸/模板填充/按目标尺寸调整(参考题4 40f6cd08)

**依赖链**：必须先通过穷举配对找到哪两个精灵体的并集等于第三个，才能确定哪个精灵体是"模板"；模板确定后才能执行弹性拉伸填入目标矩形。并集关系的识别是拉伸操作的前提。

从多个等尺寸小精灵体中找出像素并集关系确定模板，然后将该模板弹性拉伸填入网格中的大矩形目标区域。

**输入结构**：约 18x18 的黑(0)背景网格。上半区包含 6 个红(2)色 4x4 精灵体区域，排列为 2 行 3 列，间隔 1 列/行的黑色间距。每个精灵体区域内有不同的红色掩码图案（2~8 个像素）。其中恰好存在两个精灵体 A、B，其掩码的像素并集恰好等于第三个精灵体 C 的掩码。下半区有一个较大的纯红(2)实心矩形（约 6x8 至 8x12 大小）。生成约束：并集关系唯一（不存在多组满足条件的三元组）；目标矩形的行数和列数均大于 4（保证拉伸有意义）。

**规则**：
1. 在上半区的 6 个 4x4 精灵体中，穷举所有三元组 (A, B, C)，找到唯一满足 mask(A) OR mask(B) = mask(C) 的组合，且 A 和 B 各自至少贡献一个 C 中没有的独占像素（即 A 不是 B 的子集，反之亦然）。当存在相同掩码的精灵体时，按行优先位置选择靠前的。
2. 将精灵体 C 的 4x4 掩码视为多色模板：A 独占的像素涂蓝(1)，B 独占的像素涂绿(3)，A 和 B 共有的像素涂黄(4)，空白保持黑(0)。
3. 对模板执行弹性拉伸以匹配目标矩形的尺寸：对行和列分别进行拉伸，边界行/列（第一行、最后一行、第一列、最后一列）保持 1 像素宽度不变，内部行/列均匀拉伸以填满目标尺寸。
4. 将拉伸后的多色图案写入目标矩形的位置，替换原有的纯红像素。
5. 上半区所有精灵体保持原样不变。

**关键洞察**：并集关系不仅决定了哪个精灵体被选为模板，还隐含了模板内部的颜色分区——A 独占区、B 独占区和重叠区形成三色分区，这个分区信息在拉伸后被保留到大矩形中。

## 新题 6：色条对接后的排名重涂

**组合逻辑**：[对接/dock + 同色匹配/same_color_matching]（精灵体对接到匹配色条） → [排序/sorting + 高度排名/height_ranking]（创新：对接后的色条按其精灵体的高度排名） → [重涂色/recolor + 排位对应/rank_correspond]（创新：排名位映射到新颜色）

**来源原语**：对接/同色匹配(参考题16 7c66cb00)、排序/高度排名(参考题13 a61f2674)、重涂色/排位对应(参考题5 fafd9572)

**依赖链**：精灵体必须先对接到正确的色条（颜色匹配）→ 对接后根据精灵体的高度进行全局排名 → 排名结果决定每根色条的最终重涂颜色。三步形成信息流水线，每步的输出是下一步的必要输入。

将浮动精灵体按颜色对接到对应色条底部，然后根据精灵体高度对所有色条排名，最后按排名顺序用固定色序列重涂每根色条。

**输入结构**：约 20x15 的黑(0)背景网格。下半区有 4 根水平色条，每根占 1 行、跨越大部分列宽，颜色分别为蓝(1)、红(2)、绿(3)、黄(4)，垂直间隔 2~3 行。上半区有 4 个小精灵体（4-连通单色对象，3~7 像素，形状各异），颜色分别与四根色条一一对应。各精灵体的边界框高度（行数）互不相同。生成约束：每个精灵体的水平位置落在其对应色条的列范围内；精灵体之间互不接触。

**规则**：
1. 将每个精灵体与颜色相同的色条配对。
2. 将精灵体平移至其配对色条的正上方，底边紧贴色条顶边（保持水平位置不变）。擦除精灵体原始位置的像素。
3. 测量每个精灵体的边界框高度 H_i。按 H 从小到大排名（最矮排名 1，最高排名 4）。
4. 定义重涂色序列：排名 1 → 橙(7)，排名 2 → 品红(6)，排名 3 → 青(8)，排名 4 → 栗(9)。
5. 对每根色条及其上方已对接的精灵体，将所有像素统一重涂为该排名对应的新颜色。

**关键洞察**：对接步骤建立了精灵体-色条的归属关系，但最终颜色既不由原始精灵体颜色决定也不由色条颜色决定，而是由精灵体的几何属性（高度）经全局排名后间接映射——单独看任何一根色条都无法确定其输出颜色。

## 新题 7：分隔网格中的三角位填充与角落分色

**组合逻辑**：[填充/separator_grid + 表格行列位/table_row_col_pos]（识别网格单元格位置） → [循环填充/cycle_fill + 三角数位置/triangular_number_positions]（创新：在每个单元格内部按三角数列位置填色） → [角落与内部分色/corner_interior_differ]（创新：角落单元格和内部单元格使用不同的色循环）

**来源原语**：填充/分隔线网格/表格行列位(参考题12 e9c9d9a1)、循环填充/三角数位置(参考题6 72207abc)、角落与内部分色(参考题12 e9c9d9a1)

**依赖链**：必须先识别单元格在网格中的位置类别（角落/内部）→ 位置类别决定使用哪套色循环 → 然后在每个单元格内按三角数列位置用对应色循环填色。位置分类是色循环选择的前提，色循环选择是填色的前提。

在分隔线划分的网格中，根据每个单元格的表格位置（角落或内部）选择不同的色循环，然后在每个单元格内沿水平方向按三角数列位置填入循环颜色。

**输入结构**：约 17x17 的黑(0)背景网格。灰(5)色的完整水平线和垂直线将网格分割为 4 行 4 列共 16 个矩形单元格（每个单元格内部约 3x3）。所有单元格初始为纯黑。网格外围（第一行/列和最后一行/列的分隔线外）无额外内容。生成约束：每个单元格内部宽度至少 6 列（足以容纳三角数列的前几项 0,1,3,6...）。

**规则**：
1. 识别灰(5)分隔线构成的表格结构，确定每个单元格的行列位置 (r, c)，行列编号从 0 开始。
2. 分类：四个角落单元格 = {(0,0), (0,3), (3,0), (3,3)}；四个内部单元格 = {(1,1), (1,2), (2,1), (2,2)}；其余为边缘单元格。
3. 角落单元格使用色循环 A = [红(2), 蓝(1)]；内部单元格使用色循环 B = [绿(3), 黄(4), 品红(6)]；边缘单元格不填充，保持黑(0)。
4. 在每个需填充的单元格内部，沿该单元格的第一行（最上面一行），在三角数列位置（列偏移 = 0, 1, 3, 6, 10, ...）填入对应色循环的颜色，循环使用。三角数列位置超出单元格宽度的部分舍弃。
5. 灰(5)分隔线保持不变。

**关键洞察**：边缘单元格的空白不是"还没填"而是规则明确排除的——求解者必须同时归纳出三角数列规律和位置分类规则，仅看角落或仅看内部都无法获得完整规则。

## 新题 8：裁剪旋转后的周期延续

**组合逻辑**：[裁剪/crop + 旋转/rotate + 外部标记决定朝向/external_marker_orientation]（先裁剪并旋转到正确朝向） → [补全/complete + 周期偏移延续行/period_shift_rows]（创新：旋转后的图案作为周期种子向下延续）

**来源原语**：裁剪/旋转/外部标记决定朝向(参考题8 94133066)、补全/周期偏移延续行(参考题20 53b68214)

**依赖链**：外部标记决定裁剪矩形的正确旋转方向 → 旋转后的图案才具有正确的行周期结构 → 周期结构用于向下延续补全。如果旋转方向错误，行图案的周期规律将不成立，补全必然失败。

从带外部方向标记的矩形中裁剪并旋转出正确朝向的种子图案，然后根据种子图案中的行周期规律向下延续至目标高度。

**输入结构**：约 14x14 的黑(0)背景网格。中心区域有一个约 4x6 的绿(3)色实心矩形。矩形内部有若干红(2)像素形成行图案（每行 1~3 个红像素，相邻行之间红像素位置有固定水平偏移）。矩形外围有 2 个蓝(1)色孤立标记像素，位于矩形某两个角的对角方向 1 格处（如右上角外和左下角外）。网格右下角有一个橙(7)色的小矩形框（仅边框，内部为黑色），尺寸约 6x6，表示目标输出区域大小。生成约束：矩形内的行图案在正确旋转后呈现明确的垂直周期（周期 2~3 行）和水平偏移；两个外部标记像素的相对位置唯一确定一种旋转（0/90/180/270度）。

**规则**：
1. 识别绿(3)实心矩形及其内部的红(2)图案，裁剪出矩形内部（不含绿色边框）得到一个小网格 P。
2. 找到两个蓝(1)外部标记像素，计算它们相对于矩形中心的归一化位置向量。
3. 确定旋转角度：使裁剪图案 P 旋转后，其内部红色标记像素（取左上角和右下角各一个）的归一化相对位置与外部蓝标记的归一化位置匹配。对 P 应用该旋转得到 P'。
4. 从 P' 的行图案中推断垂直周期 T 和每周期的水平偏移 S（方法同参考题20）。
5. 读取橙(7)框的内部尺寸作为目标高度 H 和宽度 W。
6. 以 P' 的行图案为种子，按周期 T 和偏移 S 向下延续直至填满 H 行（宽度不足则裁剪，超出则环绕）。
7. 输出为 H x W 的网格（黑色背景 + 红色图案），替换橙色框的内部区域。橙色框本身、原始矩形和标记均不出现在输出中。

**关键洞察**：旋转方向的选择是后续一切推理的基础——四种旋转中只有一种能让行图案呈现合法周期结构，其余三种看起来像随机噪声。求解者必须尝试旋转并验证周期性才能确定正确方向。
