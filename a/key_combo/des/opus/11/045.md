## 新题 1：区域封闭射线与周期步长由邻域投票决定

**组合逻辑**：[洪泛填充](区域划分) + [区域邻接](构建邻接图) → [多数标记色涂色](跨区域投票) → [射线延伸 + 周期步长](投票结果决定射线周期)

**来源原语**：洪泛填充(e681b708)、区域邻接(e681b708)、多数标记色涂色(e681b708)、射线延伸(16de56c4/97999447)、周期步长(16de56c4)、孤立像素(e681b708/97999447)

**依赖链**：洪泛填充确定区域边界 → 区域邻接图确定哪些标记参与投票 → 投票结果决定射线颜色 → 同区域内孤立像素数量决定射线周期 → 射线在区域边界处截止

一句话总结：墙壁划分出封闭区域，每个区域中的孤立像素向四方射出周期条纹，条纹颜色由相邻区域的多数标记色决定，周期等于本区域孤立像素总数，射线在区域边界处停止。

**输入结构**：约 18x18 的网格，黑(0)为背景。蓝(1)像素组成多段水平/垂直墙壁线段（每段 3~7 像素长），将网格划分为 4~6 个不规则的 4-连通开放区域。每个区域内散布 1~4 个孤立的绿(3)像素（与墙壁和其他绿像素均不相邻）。在墙壁线段的端点或拐角处，有红(2)、黄(4)、橙(7)三种颜色的标记像素各若干个（每个标记恰好 8-邻域接触两个不同区域的边界）。生成约束：每个区域至少有 2 个相邻区域的标记可见；每个区域内的孤立像素数互不相同（取值 1~4）；标记颜色分布保证每个区域的邻域投票有唯一多数色。

**规则**：
1. 将蓝(1)墙壁和所有标记像素视为障碍，对剩余黑(0)+绿(3)像素做 4-连通洪泛填充，划分为若干封闭区域。
2. 对每个区域 R，找到所有 8-邻域同时接触 R 和另一区域的标记像素，统计这些标记中出现次数最多的颜色 C_R（唯一多数，无平局）。
3. 对区域 R 内每个孤立绿(3)像素 P，令 step = R 内孤立绿像素总数。从 P 向上/下/左/右四个方向逐格延伸：偏移量 d（从 1 开始）若 d mod step == 0 则涂 C_R，否则保持黑(0)。射线遇到蓝(1)墙壁、标记像素或网格边界时停止（不涂终点）。
4. 原有的绿(3)像素保留不变；墙壁和标记像素保留不变。

**关键洞察**：射线的颜色不由本区域内的任何元素决定，而由跨区域的邻域标记投票决定；同时射线的疏密由同区域内像素数量控制，两个机制耦合后使得每个区域的输出图案既依赖自身结构又依赖邻域信息。

## 新题 2：对称性分流重力与计数对角线编码

**组合逻辑**：[对称检测](分类) → [滑动/重力沉降](方向由对称性决定) + [计数](统计对称类) → [对角线编码](编码计数结果到输出子区域)

**来源原语**：对称检测(73ccf9c2)、唯一非轴对称/异常值选择(73ccf9c2)、滑动(3618c87e)、重力沉降(3618c87e)、计数(3b4c2228)、对角线编码(3b4c2228)、分隔行(bd4472b8)

**依赖链**：对称检测将对象分为两类 → 对称类型决定重力方向（左右对称→下沉，上下对称→右移） → 计数各类型对象数量 → 对角线编码将计数写入分隔行划出的计数区

一句话总结：小型前景对象按其对称轴方向被分流沉降到不同边，然后各类型的数量被编码为分隔线旁计数区域对角线上的着色单元。

**输入结构**：约 15x15 的网格，黑(0)为背景。网格中央有一条完整的灰(5)水平分隔行，将网格分为上半区（活动区）和下半区（编码区，初始全黑）。上半区散布 5~8 个互不相邻的单色 4-连通小对象（每个 3~6 像素），颜色为红(2)或蓝(1)。每个对象恰好具备以下对称性之一：仅左右镜像对称（竖轴）、仅上下镜像对称（横轴），不存在同时具备两种或无对称性的对象。生成约束：上下对称的对象数量与左右对称的对象数量不相等且各自在 2~4 之间；对象的具体形状（像素布局）各不相同，但对称类型可通过边界框内的前景掩码反射比对确定。

**规则**：
1. 识别上半区所有 4-连通前景对象，对每个对象检测其边界框内掩码的对称类型。
2. 左右对称（竖轴镜像 = 自身）的对象：整体向下平移直至碰到灰(5)分隔行上方或碰到已沉降的对象，保持原色不变。
3. 上下对称（横轴镜像 = 自身）的对象：整体向右平移直至碰到网格右边界或碰到已移动的对象，保持原色不变。处理顺序：按对象边界框左上角从右到左（避免右侧对象阻塞左侧对象路径）。
4. 统计左右对称对象总数 N_v，上下对称对象总数 N_h。
5. 下半区视为编码区。编码区的左半部分（列 0 至 列 floor(W/2)-1）用于编码 N_v：从编码区左上角沿主对角线填 N_v 个红(2)单元。编码区的右半部分（列 floor(W/2) 至 列 W-1）用于编码 N_h：从该子区域左上角沿主对角线填 N_h 个蓝(1)单元。
6. 灰(5)分隔行保持不变。

**关键洞察**：对称类型既决定了对象的物理运动方向（分流机制），又被计数后编码为输出的结构特征；如果不先正确检测对称性，既无法确定移动方向，也无法得到正确的编码数字。

## 新题 3：嵌套括号提取与深度驱动的字形印章

**组合逻辑**：[括号界定提取](识别嵌套层级) + [计数](嵌套深度) → [编码映射](深度→字形) → [图案印章](在提取位置印章)

**来源原语**：括号界定提取范围(505fff84)、堆叠(505fff84)、控制像素对(505fff84)、嵌套层(bd5af378)、计数(3b4c2228)、编码映射(dfadab01)、图案印章(dfadab01)、字形字典(dfadab01)

**依赖链**：括号对的嵌套关系决定每段的深度 → 深度值通过字形字典映射到特定 3x3 图案 → 提取的段被替换为对应深度的字形印章 → 堆叠时按深度从浅到深排列

一句话总结：从嵌套的彩色括号对中提取行段，按嵌套深度查字形字典印章到段的起始位置，然后按深度顺序从上到下堆叠输出。

**输入结构**：约 16x20 的网格，黑(0)为背景。网格分为两个区域：左侧 3x12 的字形字典区和右侧的主区域。字形字典区包含 3 个纵向排列的 3x3 图案（互不相同的非黑单色图案），从上到下分别对应深度 1、2、3，每个图案右侧紧邻一个灰(5)像素标注序号位置。主区域中有 6~8 行包含括号对：每行有一对同色像素作为左右括号（蓝(1)、红(2)、绿(3)三种颜色分别代表深度 1、2、3 的括号）。括号可嵌套：深度 2 的括号对完全位于某个深度 1 括号对的内部行范围中，深度 3 完全位于深度 2 内部。每对括号之间有 3~5 个黑(0)单元作为内容段。生成约束：同一深度的括号对不超过 2 对；括号颜色与深度的对应关系在所有示例中一致但需对比多个示例归纳（单个示例中可能只出现部分深度）。

**规则**：
1. 识别所有括号对：同一行中同色的两个非黑像素构成一对括号，括号颜色决定其深度（需从字典区旁的示例或多示例对比确定颜色→深度映射）。
2. 计算每对括号的嵌套深度 d（1/2/3）。
3. 从字形字典区读取深度 d 对应的 3x3 图案 G_d。
4. 对每对括号，提取其内部行段（括号之间的像素），将段的前 3 个单元替换为 G_d 的第一行，保留段的其余单元不变（若段长度 < 3 则裁剪图案）。
5. 将所有处理后的段按深度从小到大排序，同深度内按原始行号从上到下排序，依次堆叠为输出行。
6. 输出宽度等于最长段的长度，短段右侧补黑(0)。

**关键洞察**：括号的颜色并非直接标注深度数字，而是需要通过观察嵌套结构（哪种颜色被哪种颜色包含）来反推颜色-深度映射；这个映射又决定了选用哪个字形印章，形成两层间接推理。

## 新题 4：占位符形状归一化后旋转匹配决定填充方向

**组合逻辑**：[平移归一化 + 形状相同](形状分组) → [旋转匹配](确定每个实例相对模板的变换) → [射线延伸 + 边缘指示方向](变换决定射线朝向)

**来源原语**：占位符对象(ad38a9d0)、平移归一化(ad38a9d0)、形状相同(ad38a9d0)、旋转匹配(3a25b0d8)、二面体变换对应(64efde09)、射线延伸(97999447)、边缘指示方向(8886d717)、边缘线(8886d717)

**依赖链**：平移归一化识别同形状组 → 旋转匹配确定每个实例相对规范朝向的旋转角 → 旋转角决定射线发射方向 → 射线从对象边缘向外延伸至网格边界

一句话总结：同形状的占位符对象被分组，每个实例相对规范朝向的旋转量（0/90/180/270度）决定其向外射线的方向，射线颜色由对象所属形状组的颜色决定。

**输入结构**：约 20x20 的网格，黑(0)为背景。网格中散布 6~9 个灰(5)的 4-连通小对象（每个 4~7 像素，非矩形，非对称），它们属于 2~3 个形状组（同组对象平移归一化后为同一掩码的旋转变体）。每个形状组有一个"规范实例"：该实例的某一边（上/下/左/右）紧邻一个单独的彩色像素（红(2)、蓝(1)或绿(3)），该像素既标注了组颜色也标注了规范朝向（彩色像素相对对象的方位定义为"正前方"）。其余实例没有彩色邻接像素。生成约束：同组内各实例的旋转角度互不相同（从 0、90、180、270 中取）；不同组的规范朝向标记颜色不同；对象间距至少 3 格。

**规则**：
1. 对所有灰(5)对象做平移归一化，将其分为形状组（归一化掩码在 4 个旋转下匹配视为同组）。
2. 对每个组，找到具有彩色邻接像素的规范实例，记录其颜色 C 和规范朝向（彩色像素在对象的哪一侧 = "正前方"方向）。
3. 对组内每个非规范实例，确定其相对规范实例的旋转角 theta（0/90/180/270顺时针）。将规范朝向旋转 theta 度得到该实例的"正前方"方向。
4. 从每个非规范实例的边界框的"正前方"边中线位置起，沿"正前方"方向射出一条单像素宽的射线，颜色为 C，直至网格边界。
5. 规范实例本身不射出射线。彩色标记像素保留。灰(5)对象保留。射线不覆盖已有的非黑像素。

**关键洞察**：射线方向并非由对象自身的绝对位置决定，而是由对象相对其规范实例的旋转差异推导而出；必须同时完成形状分组、规范实例识别和旋转角计算三步才能确定射线朝向。

## 新题 5：分区填色由跨区瓦片排序结果间接编码

**组合逻辑**：[网格分区](识别区域) + [排序 + 前景数决定排序](瓦片排序) → [排序结果编码为位置→颜色映射] → [填充](对目标区域施加映射)

**来源原语**：网格分区(272f95fa)、分隔线(272f95fa/dc2aa30b)、瓦片(dc2aa30b)、排序(dc2aa30b)、前景数决定排序(dc2aa30b)、填充(272f95fa)、十字位固定涂色(272f95fa)、阵列排布(dc2aa30b)

**依赖链**：分隔线划分网格为 3x3 阵列 → 每个非中心区域含有不同数量的前景像素 → 按前景数排序得到区域排名 → 排名映射到固定颜色序列 → 中心区域按周围 8 个区域的排名颜色填充为 3x3 缩略图

一句话总结：3x3 网格阵列中每个外围区域含有不等数量的前景像素，对它们按数量排序后赋予排名颜色，中心区域输出一个 3x3 缩略图，每个像素对应其方位邻居的排名颜色。

**输入结构**：约 17x17 的网格。两条完整宽度的灰(5)行和两条完整高度的灰(5)列将网格分为 3x3 = 9 个矩形区域（每个约 5x5）。中心区域初始全黑(0)。其余 8 个外围区域各包含若干绿(3)前景像素（数量从 1 到 8，各不相同，散布于区域内任意位置），其余为黑(0)背景。生成约束：8 个外围区域的绿像素数量恰好为 1~8 的某个排列（无重复）。

**规则**：
1. 识别灰(5)分隔线，划分 9 个区域，标记位置为：左上(TL)、上中(TC)、右上(TR)、左中(ML)、中心(C)、右中(MR)、左下(BL)、下中(BC)、右下(BR)。
2. 统计 8 个外围区域各自的绿(3)像素数量。
3. 按数量升序排列，排名 1（最少）到排名 8（最多）。固定颜色序列为：排名1→蓝(1)、排名2→红(2)、排名3→绿(3)、排名4→黄(4)、排名5→灰(5)、排名6→品红(6)、排名7→橙(7)、排名8→青(8)。
4. 中心区域替换为一个 3x3 的彩色缩略图：缩略图的每个单元对应方位相同的外围区域的排名颜色。即缩略图[0][0]=TL 的排名颜色，缩略图[0][1]=TC 的排名颜色，缩略图[0][2]=TR 的排名颜色，缩略图[1][0]=ML 的排名颜色，缩略图[1][2]=MR 的排名颜色，缩略图[2][0]=BL 的排名颜色，缩略图[2][1]=BC 的排名颜色，缩略图[2][2]=BR 的排名颜色。缩略图[1][1]（中心的中心）填黑(0)。
5. 3x3 缩略图居中放置于中心区域（若中心区域大于 3x3，缩略图置于其左上角，剩余保持黑色）。外围区域和分隔线保持不变。

**关键洞察**：输出的颜色与输入的绿色像素完全无关——颜色来自一个隐式的排名-颜色映射表，而排名由空间上分散在不同区域的像素计数决定；求解者必须跨区域计数、排序、再映射回空间位置才能得到中心缩略图。

## 新题 6：行均匀性检测驱动括号提取范围的选择性堆叠

**组合逻辑**：[检测/单色行标记](行分类) → [括号界定提取](仅对标记行提取) → [堆叠](提取结果堆叠) + [重涂色](按原行色重涂)

**来源原语**：检测(25d8a9c8)、单色行标记否则黑(25d8a9c8)、括号界定提取范围(505fff84)、控制像素对(505fff84)、堆叠(505fff84)、行段(505fff84)、重涂色(ad38a9d0)

**依赖链**：行均匀性检测标记哪些行"活跃" → 仅在活跃行中寻找括号控制像素对 → 提取括号间内容 → 按原行单色颜色重涂提取段 → 堆叠输出

一句话总结：仅从满足单色条件的行中识别括号标记并提取段落，提取的段被重涂为该行原本的单一颜色后依次堆叠为输出。

**输入结构**：约 12x18 的网格，黑(0)为背景。网格包含 10~14 行，其中约半数行是"单色行"（该行除两个特殊标记像素外所有像素为同一非黑颜色），其余行包含混杂的多种颜色。每个单色行中恰好有一个品红(6)像素和一个青(8)像素作为左右括号标记（品红在青的左侧），其余像素为该行的单一颜色（红(2)、蓝(1)、黄(4)或绿(3)之一）。非单色行中也可能偶然出现品红或青像素，但这些是干扰。生成约束：单色行的单一颜色各行可能不同；品红和青标记之间至少有 2 个像素的间距；非单色行中品红/青像素不成对出现（至多出现一个）。

**规则**：
1. 逐行检测：若该行中除品红(6)和青(8)以外的所有像素颜色相同且非黑，则标记为"活跃行"，记录其单一颜色 C_row。
2. 对每个活跃行，找到品红(6)和青(8)的位置，提取两者之间（不含标记本身）的像素序列作为一个行段。
3. 将提取的行段中所有非黑像素重涂为 C_row（该活跃行的单一颜色）。黑(0)像素保持黑色。
4. 忽略所有非活跃行（不提取任何内容）。
5. 将所有提取并重涂后的行段按原始行号从上到下依次堆叠，组成输出网格。输出宽度等于最长段的长度，短段右侧补黑(0)。

**关键洞察**：非单色行中出现的品红/青像素是干扰项——只有先通过均匀性检测确认哪些行是活跃的，才能正确忽略干扰括号；提取后的重涂颜色也依赖于均匀性检测得到的行色信息，两个机制在同一步检测中同时获取。

## 新题 7：修补缺陷后对称补全，补全区域由孔洞面积编码颜色

**组合逻辑**：[修补](消除噪声标记) → [对称补全](利用修补后的干净形状) + [孔洞面积区分角色](孔洞面积→颜色) → [填充](补全区域的颜色由孔洞面积决定)

**来源原语**：修补(8886d717)、嵌入与孤立(8886d717)、对称补全(14754a24)、部分标记(14754a24)、孔洞(3a25b0d8)、孔洞面积区分角色(3a25b0d8)、填充(3a25b0d8)

**依赖链**：先修补嵌入缺陷恢复对象真实形状 → 检测修补后对象的对称性以确定补全模式 → 执行镜像补全 → 补全产生的新封闭孔洞按面积大小分配不同填充颜色

一句话总结：含有噪声标记的部分对称对象先被修补还原，再沿对称轴补全为完整形状，补全后产生的封闭孔洞按面积从小到大依次填入不同颜色。

**输入结构**：约 15x15 的网格，黑(0)为背景。网格中有 1~2 个蓝(1)的大型 4-连通对象（每个 20~40 像素）。每个对象大致呈现某条轴（水平或垂直）的半边形状——即对象主体位于对称轴的一侧，另一侧仅有少量像素暗示对称延伸方向。对象内部嵌入了 2~4 个红(2)噪声像素（嵌入定义：该红像素的 4 个邻居中至少 3 个是蓝(1)）。对象外部的黑色区域中还有 1~2 个孤立的红(2)像素（4-邻域全为黑色）。修补后的干净对象保证：以其边界框某条中线为轴，前景掩码的一半是另一半的子集（即一半完整，另一半是该半的部分残缺）。生成约束：补全后的完整形状保证产生 2~3 个大小不同的封闭孔洞（4-连通黑色区域被蓝像素完全围合）。

**规则**：
1. **修补**：将所有嵌入的红(2)像素（4-邻域中至少 3 个为蓝(1)）重涂为蓝(1)。孤立的红(2)像素（4-邻域全为黑(0)）保留不变。
2. **确定对称轴**：对修补后的蓝(1)对象，测试其边界框的水平中线和垂直中线，选择使一侧前景完全包含于另一侧镜像的那条轴。
3. **对称补全**：将较完整一侧的前景掩码镜像到较残缺一侧，填充缺失像素为蓝(1)。
4. **识别孔洞**：在补全后的蓝(1)对象内部，找到所有被蓝像素完全 4-连通围合的黑(0)区域（不与网格边界连通的黑色连通分量）。
5. **按面积填色**：将孔洞按面积（像素数）从小到大排序。最小孔洞填黄(4)，次小填绿(3)，第三小填橙(7)。面积相同时按孔洞左上角位置从左到右再从上到下排序。
6. 孤立红(2)像素、蓝(1)对象轮廓及其补全部分均保留。

**关键洞察**：修补和对称补全必须按严格顺序执行——若不先修补噪声，对称轴判断和补全方向都会出错；而孔洞只有在补全完成后才出现完整闭合形态，面积才能正确计算。三步之间存在严格的信息依赖。
