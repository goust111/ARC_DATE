## 新题 1：嵌套深度决定循环涂色

**组合逻辑**：[包含/containment](创新：用嵌套层数替代空间坐标排序) + [排序/sort](创新：按拓扑深度而非位置排序) + [重涂色/recolor] + [颜色循环分配/cyclic_color_assignment] + [有空洞则重涂/recolor_if_hole](创新：作为分层筛选门控)

**来源原语**：包含(containment, 参考题10)、排序(sort, 参考题1/12)、重涂色(recolor, 参考题1/10)、颜色循环分配(cyclic_color_assignment, 参考题1)、有空洞则重涂(recolor_if_hole, 参考题10)

**依赖链**：拓扑包含关系决定每个封闭区域的嵌套深度 -> 深度值作为排序键驱动循环颜色分配 -> 但只有自身包含空洞的区域才参与重涂（空洞检测门控颜色分配），无空洞区域保持原色

根据封闭区域的嵌套深度循环涂色，但仅对自身含空洞的区域执行涂色。

**输入结构**：约 18x18 的网格，背景为黑(0)。前景由蓝(1)像素构成多层嵌套的闭合边界（3~5 层嵌套，每层是一个不规则但完全闭合的 4-连通环，像素数 10~25，各层之间间隔 1~2 像素）。部分中间层的环内部还包含更小的闭合结构（即该层"有空洞"——其围起的区域内存在非背景的更深层结构），部分层是实心填充（围起区域全为背景，"无空洞"）。生成约束：每一层的闭合边界严格嵌套在外层之内；同一深度不会有多个并列的闭合区域；至少有 2 层"有空洞"且至少 1 层"无空洞"。

**规则**：
1. 将每个蓝(1)闭合边界视为一个对象，计算其嵌套深度（最外层深度=1，其内一层深度=2，依此类推）。
2. 判断每个闭合边界是否"有空洞"：如果该边界围起的内部区域包含任何非背景像素（即内部存在更深层的闭合边界），则判定为"有空洞"。
3. 仅对"有空洞"的闭合边界执行重涂色：按深度从小到大排列这些边界，循环分配红(2)、绿(3)、黄(4)三色（深度最小的有空洞边界涂红(2)，次小涂绿(3)，再次涂黄(4)，第四个再涂红(2)，依此循环）。
4. "无空洞"的闭合边界（最内层的实心层）保持蓝(1)不变。
5. 背景保持黑(0)不变。

**关键洞察**：颜色循环的排序键不是空间坐标而是拓扑嵌套深度，且只有"中间层"（既被包含又包含他物的层）才参与循环涂色——最内层虽有深度但因无空洞而被排除，需要对比多个示例才能区分"深度排序"和"有空洞门控"两条规则。

## 新题 2：分隔线射线穿越与颜色翻转

**组合逻辑**：[射线延伸/ray_extend] + [分隔线为对称轴/separator_as_reflection_axis](创新：分隔线作为颜色变换边界而非几何反射轴) + [颜色互换/color_swap](创新：穿越分隔线时触发) + [碰撞产生侧翼/collision_generates_side_wakes]

**来源原语**：射线延伸(ray_extend, 参考题6/13)、分隔线为对称轴(separator_as_reflection_axis, 参考题11)、颜色互换(color_swap, 参考题11)、碰撞产生侧翼(collision_generates_side_wakes, 参考题13)、障碍像素(obstacle_pixel, 参考题13)

**依赖链**：种子像素发射水平射线 -> 射线穿越分隔线时颜色翻转（分隔线作为变换边界而非反射轴） -> 射线撞击障碍时产生上下侧翼 -> 侧翼继承撞击时的当前颜色（已翻转或未翻转取决于障碍在分隔线哪一侧）

种子发射水平射线穿越垂直分隔线时颜色翻转，遇障碍产生侧翼，侧翼颜色取决于障碍位于分隔线哪侧。

**输入结构**：约 15x20 的网格，背景为黑(0)。一条灰(5)垂直完整列将网格分为左右两区。左区的最左列有 2~3 个红(2)种子像素（不在同一行）。网格中散布 3~5 个橙(7)障碍像素（单像素），部分在分隔线左侧、部分在右侧，且不在种子所在行的分隔线位置上。生成约束：每个种子的射线路径上至少有一个障碍；没有两个障碍在同一行且同侧；障碍不在分隔线列上。

**规则**：
1. 每个红(2)种子向右发射水平射线，逐格填充背景像素。
2. 射线在分隔线左侧时颜色为红(2)；穿越分隔线（跳过灰(5)列本身不绘制）后颜色变为绿(3)。
3. 射线遇到橙(7)障碍时停止（障碍保持不变），并在障碍的正上方和正下方各延伸 1 格侧翼（如果该格为背景）。侧翼颜色等于射线撞击时的当前颜色（分隔线左侧撞击 -> 红(2)侧翼；右侧撞击 -> 绿(3)侧翼）。
4. 分隔线列保持灰(5)不变，种子像素保持红(2)不变。
5. 若侧翼目标格为非背景像素（另一条射线、障碍或分隔线），则该侧翼不绘制。

**关键洞察**：分隔线不是几何反射轴，而是颜色变换的触发边界——射线穿过它后颜色翻转，需对比分隔线两侧的侧翼颜色差异才能归纳出"穿越变色"规则，而非简单的镜像复制。

## 新题 3：形状匹配驱动周期平铺方向

**组合逻辑**：[形状匹配/shape_matching] + [旋转反射等价/rotation_reflection_equivalence] + [周期平铺/periodic_tiling](创新：平铺方向由匹配结果决定) + [邻接侧决定方向/adjacency_side_determines_dir](创新：从"标记块邻接十字"改为"查询精灵邻接图例分隔线的方位")

**来源原语**：形状匹配(shape_matching, 参考题16)、旋转反射等价(rotation_reflection_equivalence, 参考题16)、周期平铺(periodic_tiling, 参考题5)、邻接侧决定方向(adjacency_side_determines_dir, 参考题5)、图例区域(legend_region, 参考题16)、分隔线(divider, 参考题16)、不覆盖源对象(preserve_source_object, 参考题5)

**依赖链**：形状匹配（含旋转反射）确定每个查询精灵对应图例中的哪个模板 -> 模板在图例中的排列位置编码了平铺方向（行位置=水平平铺，列位置=垂直平铺） -> 按该方向周期性重复查询精灵直到网格边界

将每个查询精灵匹配到图例模板（允许旋转反射），模板在图例中的行列位置编码平铺方向，据此周期延伸精灵。

**输入结构**：约 20x20 的网格，背景为黑(0)。左上角有一个由灰(5)构成的 L 形分隔线（从顶边向下延伸约 6 行，再向右延伸约 6 列），围出一个约 5x5 的图例区域。图例内有 2 个不同颜色的单色模板精灵（如一个红(2)的 3 像素 L 形、一个蓝(1)的 4 像素 T 形），一个位于图例的第 1 行（顶部），另一个位于图例的第 1 列（左侧）。图例外的网格中散布 3~4 个黄(4)单色查询精灵（各 3~5 像素，4-连通，形状与图例模板在旋转/反射下匹配），查询精灵之间互不相邻，各自到网格边缘在至少一个方向上有足够空间（>=2 倍精灵尺寸）。生成约束：每个查询精灵恰好匹配一个模板；查询精灵的周期平铺路径互不交叉。

**规则**：
1. 对每个黄(4)查询精灵，在所有旋转和反射下与图例模板比较形状（忽略颜色），找到匹配的模板。
2. 确定该模板在图例中的位置：若模板位于图例的顶部行区域，则平铺方向为水平（向左和向右）；若模板位于图例的左侧列区域，则平铺方向为垂直（向上和向下）。
3. 沿确定的方向，以查询精灵的边界框尺寸为周期，重复绘制该精灵（保持黄(4)色），直到网格边界。超出网格的部分裁剪。
4. 原始查询精灵保持不变（不被覆盖）。图例区域、分隔线和背景保持不变。
5. 若平铺过程中某格已有非背景像素，跳过该格不绘制。

**关键洞察**：平铺方向不是由精灵自身的几何属性决定，而是由其匹配到的图例模板的空间位置隐式编码——模板放在图例"行"上意味着水平平铺，放在"列"上意味着垂直平铺。需要对比多个示例才能归纳出这一位置-方向映射。

## 新题 4：路径滑动后触发同心填充

**组合逻辑**：[滑动/slide] + [门前停止/stop_at_gate] + [擦除/erase] + [同心层填充/concentric_fill](创新：填充中心由滑动终点决定) + [奇偶距离决定颜色/parity_distance_color](创新：奇偶颜色对由门的端色决定)

**来源原语**：滑动(slide, 参考题20)、门前停止(stop_at_gate, 参考题20)、擦除(erase, 参考题20)、同心层填充(concentric_fill, 参考题8)、奇偶距离决定颜色(parity_distance_color, 参考题8)、以控制点为中心(centered_on_control, 参考题8)、路径(path, 参考题20)、门结构(gate_motif, 参考题20)、封闭区域(enclosed_region, 参考题10)

**依赖链**：标记沿路径滑动至门前停止（确定填充中心坐标）-> 擦除路径 -> 门的端色决定奇偶颜色对（红/黄 或 蓝/绿）-> 以标记终点为中心，在门后方的封闭矩形区域内进行同心填充

标记滑动到门前停止，终点成为同心填充的中心，门的颜色决定填充用的奇偶色对。

**输入结构**：约 16x16 的网格，背景为黑(0)。包含 2 个独立的前景连通分量，每个分量由以下部分组成：一条绿(3)路径（4-连通的单像素宽折线，5~10 格长）、路径一端有一个灰(5)标记像素（4-邻接到路径端点）、路径另一端连接一个门结构（门中心为绿(3)、两端为红(2)或蓝(1)，构成直线三格端-中-端图案）、门后方（远离路径的一侧）有一个约 5x5 的空心矩形框（橙(7)单像素厚），框内全为背景。生成约束：两个分量互不接触；一个分量的门端色为红(2)，另一个为蓝(1)；矩形框的一边与门的中心格 4-邻接。

**规则**：
1. 在每个连通分量中，找到灰(5)标记和门结构（端-中-端三格直线图案，中心为绿(3)）。
2. 擦除标记像素和所有绿(3)路径像素（包括门中心），将它们变为背景黑(0)。门的两个端像素保留。
3. 将灰(5)标记放置在门中心原来的位置（即标记"滑动"到门前）。
4. 以该标记的新位置为中心，对门后方的矩形框内部（不含框本身）进行同心层填充：计算框内每个背景像素到标记的切比雪夫距离。
5. 颜色分配取决于门端色：若门端色为红(2)，则奇数距离填红(2)、偶数距离填黄(4)；若门端色为蓝(1)，则奇数距离填蓝(1)、偶数距离填绿(3)。
6. 矩形框保持橙(7)不变。标记最终显示为灰(5)。

**关键洞察**：同心填充的中心不是预置的控制像素，而是滑动操作的动态结果；填充的颜色方案也不是固定的，而是由门端色编码——需要对比两个分量的不同门色和不同填充结果才能归纳出颜色映射规则。

## 新题 5：类比推断对称修复类型

**组合逻辑**：[类比推理/analogy_inference] + [规则推断/rule_inference] + [对称补全/symmetry_completion](创新：对称类型本身需要从训练对中推断) + [可见副本恢复遮挡/visible_recover_occluded]

**来源原语**：类比推理(analogy_inference, 参考题7)、规则推断(rule_inference, 参考题7)、对称补全(symmetry_completion, 参考题3)、可见副本恢复遮挡(visible_recover_occluded, 参考题3)、训练对映射(training_pair_mapping, 参考题7)、二面体对称(dihedral_symmetry, 参考题3)、遮挡矩形(occluding_rect, 参考题3)、空心框(hollow_frame, 参考题7)、调色板匹配配对(palette_match_pairing, 参考题7)

**依赖链**：识别训练对（通过框色配对）-> 从训练对中推断使用了哪种对称类型（水平镜像/垂直镜像/90度旋转/180度旋转）-> 将推断出的对称类型应用于测试图案的遮挡区域修复

从训练对的"损坏-修复"示例中推断对称类型，再用该对称类型修复测试图案的遮挡区域。

**输入结构**：约 20x20 的网格，背景为黑(0)。包含 3 个彩色空心正方形框（边长 7~9，单像素厚，颜色各不同，如红(2)、蓝(1)、绿(3)）。每个框内有一个多色图案（使用黄(4)、橙(7)、灰(5)等非框色绘制，4~8 像素）。训练对的识别方式：两个框的内部图案使用完全相同的颜色集合（调色板匹配）。训练对中，一个框内图案具有某种对称性（如水平镜像对称），另一个框内图案是前者被一个 3x2 的品红(6)矩形遮挡后的样子（遮挡部分被品红覆盖）。第三个框（测试框）内图案也有一个品红(6)遮挡矩形，但其完整图案具有与训练对相同类型的对称性。生成约束：训练对中完整图案的对称类型在不同示例间可变（有的示例是水平镜像，有的是 180 度旋转等）；测试图案的对称类型与训练对相同。

**规则**：
1. 通过调色板匹配找到训练对：两个框内部使用完全相同的非黑非框色集合即为配对。剩余的框为测试框。
2. 在训练对中，找到无品红(6)遮挡的完整图案，分析其对称类型（水平镜像/垂直镜像/180度旋转/90度旋转对称）。
3. 验证：训练对中被遮挡的图案，用步骤2发现的对称类型修复品红区域后，应与完整图案一致。

## 新题 6：扫描序射线交叉的模运算着色

**组合逻辑**：[射线延伸/ray_extend] + [排序/sort] + [扫描序/scan_order] + [长轴决定扫描/longer_axis_determines_scan] + [行列交叉/row_col_intersection] + [交叉点特殊着色/intersection_colored](创新：交叉色由两条射线的序号模运算决定)

**来源原语**：射线延伸(ray_extend, 参考题6/18)、排序(sort, 参考题1)、扫描序(scan_order, 参考题1)、长轴决定扫描(longer_axis_determines_scan, 参考题1)、行列交叉(row_col_intersection, 参考题18)、交叉点特殊着色(intersection_colored, 参考题18)、孤立像素(isolated_pixel, 参考题1)、整行整列射线(full_row_column_ray, 参考题6)

**依赖链**：孤立像素的包围盒长轴决定扫描方向 -> 按该方向排序得到每个像素的序号 -> 每个像素发射全行全列射线 -> 射线颜色由序号循环分配 -> 两条射线交叉时，交叉格颜色由两者序号之和对 3 取模决定

多个孤立像素按长轴方向排序后循环着色发射十字射线，交叉点颜色由两条射线序号之和的模运算决定。

**输入结构**：约 15x15 的网格，背景为黑(0)。有 4~6 个灰(5)孤立像素（互不同行同列，4-连通孤立）。这些像素的整体包围盒（所有像素的最小外接矩形）的行列跨度不等。生成约束：任意两个像素不在同一行也不在同一列；像素数量为 4~6 个；包围盒行跨度与列跨度严格不等。

**规则**：
1. 计算所有灰(5)像素的整体包围盒。若行跨度 >= 列跨度，按行优先序（先按行从上到下，同行按列从左到右）排列像素；否则按列优先序（先按列从左到右，同列按行从上到下）排列。
2. 按排列顺序分配序号 0, 1, 2, 3, ...。每个像素的射线颜色由序号对 3 取模决定：模 0 为红(2)，模 1 为蓝(1)，模 2 为黄(4)。
3. 每个像素向其所在整行和整列发射射线（填充该行该列的所有背景格为对应颜色）。
4. 当两条射线交叉于同一格（即某格同时在像素 A 的行/列和像素 B 的行/列上），该格颜色由 (A 的序号 + B 的序号) 对 3 取模决定：模 0 为红(2)，模 1 为蓝(1)，模 2 为黄(4)。
5. 每个原始灰(5)像素位置保持灰(5)不变（像素本身的行列交叉点不算"两条射线交叉"，保留原色）。
6. 绘制顺序：先画所有射线，再用交叉规则覆盖所有交叉格。

**关键洞察**：交叉点颜色既不是任一条射线的颜色，也不是固定特殊色，而是两条射线序号的模运算结果——需要对比多个交叉点的颜色并关联到对应射线的排序位置才能归纳出此规则。扫描方向的确定（长轴规则）又是归纳序号分配的前提。

## 新题 10：封闭区域检测触发内部波形平铺

**组合逻辑**：[重涂色/recolor] + [有空洞则重涂/recolor_if_hole](创新：改为"无空洞则填充") + [周期平铺/periodic_tiling] + [交替翻转/alternating_flip] + [单行重叠拼接/one_row_overlap] + [颜色循环分配/cyclic_color_assignment](创新：按区域面积排序分配平铺颜色)

**来源原语**：重涂色(recolor, 参考题10)、有空洞则重涂(recolor_if_hole, 参考题10)、周期平铺(periodic_tiling, 参考题5)、交替翻转(alternating_flip, 参考题9)、单行重叠拼接(one_row_overlap, 参考题9)、颜色循环分配(cyclic_color_assignment, 参考题1)、连通分量(connected_component, 参考题10)、封闭区域(enclosed_region, 参考题10)、波形图案(wave_pattern, 参考题9)

**依赖链**：检测哪些蓝色边界是闭合的（拓扑检测）-> 闭合且内部无更深嵌套的实心封闭区域被选为填充目标 -> 按封闭区域面积从小到大排序 -> 循环分配填充颜色 -> 在每个目标区域内部进行交替翻转的水平条纹平铺

检测实心封闭区域，按面积排序循环分配颜色，在区域内部填充交替翻转的水平条纹。

**输入结构**：约 18x18 的网格，背景为黑(0)。蓝(1)像素构成 4~6 个不同的 4-连通前景对象，部分是闭合边界（完全围起一片黑色内部区域），部分是开放曲线（不围起任何区域）。闭合边界中，部分内部是纯黑(0)（实心封闭），部分内部还包含更小的蓝(1)结构（有空洞/嵌套）。各对象互不接触。封闭区域面积（内部黑色像素数）各不相同。生成约束：至少 3 个实心封闭区域（内部纯黑无嵌套）、至少 1 个开放曲线、至少 1 个有嵌套的闭合边界；实心封闭区域面积互不相等。

**规则**：
1. 找到所有蓝(1)的 4-连通分量，判断每个分量是否为闭合边界（其围起的内部区域不与网格外部背景连通）。
2. 对闭合边界，进一步判断其内部是否为"实心"（内部全为背景，无任何非背景像素）。只有实心封闭区域是填充目标。
3. 将所有实心封闭区域按其内部面积（内部黑色像素数）从小到大排序。
4. 循环分配填充颜色：排序后第 1 个区域用红(2)，第 2 个用绿(3)，第 3 个用黄(4)，第 4 个再用红(2)，依此循环。
5. 填充方式：在每个目标区域内部，从区域内部最顶行开始，逐行交替绘制：奇数行（从顶部起第 1、3、5...行）填充分配的颜色，偶数行（第 2、4、6...行）保持黑(0)背景。这形成水平条纹效果。
6. 开放曲线和有嵌套的闭合边界保持蓝(1)不变。它们的内部（如果有）也保持不变。

**关键洞察**：填充目标的选择需要同时满足两个拓扑条件（闭合 + 实心），颜色分配的排序键是面积而非位置——开放曲线和嵌套结构都是干扰项，需要对比多个示例才能排除"按位置排序"或"所有闭合区域都填充"等错误假设。
