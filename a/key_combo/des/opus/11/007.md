## 新题 1：滑动到站后按标记密度淘汰

**组合逻辑**：[滑动](已有) + [计数](已有，创新：计数对象从矩形内标记变为目的地处静态标记) → [擦除](已有，创新：擦除对象包含滑动轨迹)

**来源原语**：滑动、接触边缘、滑至对侧边缘(b25e450b)；计数、内部标记计数、最少标记者选中、擦除(54db823b)；稀疏标记(54db823b)

**依赖链**：滑动改变每个矩形的空间位置 → 到站后矩形覆盖的静态标记集与出发时完全不同 → 计数必须基于到站位置而非初始位置 → 计数最少者连同轨迹一起被擦除。删去滑动则无法得到正确计数；删去计数则无法选择淘汰对象。

在每个输入中，矩形滑动后覆盖的标记数量排序与其初始位置处的标记数量排序不同，迫使求解者先模拟滑动再计数。

**输入结构**：约 15x15 的黑(0)背景网格。3 个不同颜色的实心矩形（如红(2)约 2x3、蓝(1)约 3x2、绿(3)约 2x2），每个恰好接触一条外边界（上/下/左/右），矩形之间互不重叠。网格中散布 8-12 个灰(5)单像素标记，这些标记不在任何矩形内部，也不接触网格边界。生成约束：每个矩形滑到对侧后其覆盖区域内灰标记数各不相同，且该排序与初始位置处附近标记数的排序至少有一对逆序。

**规则**：
1. 所有矩形同时滑动。接触上边界的矩形沿相同列向下滑至下边界；接触下边界的向上滑至上边界；接触左边界的沿相同行向右滑至右边界；接触右边界的向左滑至左边界。
2. 每个矩形扫过的整列或整行条纹涂为橙(7)；矩形本身以原色印在目的端。
3. 统计每个矩形在目的位置覆盖区域内的灰(5)标记数量（被矩形覆盖的标记计入该矩形，被轨迹覆盖但不在矩形区域内的不计入）。
4. 灰标记数最少的那个矩形被淘汰：其目的位置矩形和整条橙色轨迹全部恢复为黑(0)背景。
5. 其余矩形及其轨迹保留；未被任何矩形或轨迹覆盖的灰标记保持灰(5)。

**关键洞察**：淘汰依据是到站后的标记密度，不是出发时的。必须先在脑中完成全部滑动，才能正确计数并决定淘汰对象。

## 新题 2：逐行填充后错切产生面积优先重叠

**组合逻辑**：[填充](已有，行跨度填充) + [错切](已有) → [面积优先冲突解决](创新：错切引发的重叠用填前面积裁决)

**来源原语**：填充、轮廓线、行内边界配对、逐行跨度填充(22168020)；错切、行偏移递变、行内容保持(3cd86f4f)

**依赖链**：轮廓线定义填充边界 → 行跨度填充生成实心区域并确定面积 → 错切将各行横向偏移，原本不重叠的区域可能交叠 → 重叠像素取填充面积更大者的颜色。删去填充则无实心区域可错切；删去错切则无重叠需要解决；删去面积规则则重叠区域颜色不确定。

**输入结构**：约 14x10 的黑(0)背景网格（14 行 10 列）。包含 2-3 个不同颜色的稀疏轮廓线（如红(2)、蓝(1)、绿(3)），每个轮廓线在其占据的每一行恰好有 2 个同色像素作为左右边界，不同轮廓线在垂直方向上不重叠（各自占据不同的行范围）。轮廓线在水平方向上有一定偏移，但在未错切时不重叠。生成约束：各轮廓线的填充面积（边界间像素总数）各不相同。

**规则**：
1. 对每个轮廓线执行行跨度填充：在轮廓线占据的每一行，将两个边界像素之间（含边界）的所有像素涂为该轮廓线的颜色。记录每个轮廓线的填充面积（填充像素总数）。
2. 对填充结果执行左向错切：在高度为 H 的网格中，第 r 行（从 0 开始）整体向左平移 r 个像素。输出网格宽度不变（仍为 W），超出左边界的像素被裁剪，右侧空出的位置填入黑(0)。
3. 错切后若某像素位置被两个不同颜色的填充区域覆盖，该像素取填充面积更大的那个区域的颜色。
4. 轮廓线的原始边界像素视为填充的一部分，参与错切和冲突解决。

**关键洞察**：错切量随行号线性增长，因此底部的区域比顶部偏移更多，重叠图案取决于各轮廓线的垂直位置和水平宽度。冲突解决需要回溯到错切之前的面积信息，不能仅从错切后的局部像素判断。

## 新题 3：角落环带配合图例交替换色

**组合逻辑**：[填充](创新：奇偶环带不再是"涂/不涂"，而是"涂原色/涂换色") + [重涂色](已有，图例行配对互换)

**来源原语**：角标记像素、同心环、最近归属、奇偶距离决定填色(d22278a0)；图例、图例行内配对、同行颜色互换、重涂色(0becf7df)

**依赖链**：角标记确定归属区域 → Chebyshev 距离奇偶性决定每个像素是"原色环"还是"换色环" → 图例提供配对换色表 → 奇数环像素查找图例得到替代色。删去角标记则无归属划分；删去奇偶判断则无法区分两类环；删去图例则奇数环颜色不确定。

**输入结构**：约 13x13 的黑(0)背景方形网格。2-3 个角落各有一个单像素标记，颜色各不相同（如红(2)在左上角、蓝(1)在右下角、绿(3)在左下角）。网格中央偏某侧放置一个 2 行 2 列的图例块，图例不在任何角落附近。图例每行包含两种颜色，构成一个配对：例如第一行为红(2)和黄(4)，第二行为蓝(1)和橙(7)。每个角标记的颜色恰好出现在图例的某一行中。生成约束：图例位置不与任何角标记的 Chebyshev 距离为 0 或 1 的区域重叠；至少有两个角标记的归属区域相邻（存在归属边界）。

**规则**：
1. 对每个非图例、非角标记的背景像素，计算其到每个角标记的平方欧氏距离，将其归属给距离最近的角标记。若到两个或以上角标记距离相等，则该像素保持黑(0)背景。
2. 对每个被归属的像素，计算其到归属角标记的 Chebyshev 距离 d。
3. 若 d 为偶数：该像素涂为归属角标记的原始颜色。
4. 若 d 为奇数：在图例中找到包含该角标记颜色的那一行，将该像素涂为同行的另一种颜色（即配对色）。
5. 图例块本身保持不变，覆盖在环带图案之上。

**关键洞察**：偶数环显示角标记本色，奇数环显示图例配对色，形成交替色带。图例不是装饰，而是控制交替色的指令表。仅看一个示例可能误以为所有环都是同一颜色或所有环都换色，必须对比多个角落的环带模式和图例内容才能归纳出奇偶分流规则。

## 新题 4：嵌套框架深度计数决定框架重涂色

**组合逻辑**：[包含树遍历](已有) → [计数](已有，创新：计数范围由包含层级严格限定) → [重涂色](创新：计数结果映射到标记颜色而非固定色表)

**来源原语**：嵌套框架、封闭区域、包含树、拓扑决定布局(2d0172a1)；计数、内部标记计数、稀疏标记(54db823b)；重涂色(0becf7df)

**依赖链**：包含树确定每个框架的直接子区域 → 在直接子区域中（排除更内层框架内部）计数标记像素 → 计数结果决定该框架的重涂颜色。删去包含树则无法正确划定计数区域（会把内层框架内的标记误算）；删去计数则无法选择颜色；删去重涂色则无输出变化。

**输入结构**：约 15x15 的黑(0)背景网格。包含 2-3 组相互独立的嵌套矩形框架结构（各组之间不嵌套）。每组有 2-3 层嵌套，每个框架都是灰(5)的单像素厚矩形边框。在各层之间的间隙区域中散布着小的单色标记像素（可能为红(2)、蓝(1)、绿(3)），每层间隙中的标记数量从 0 到 3 不等。标记只在框架之间的间隙中出现，不在框架边框像素上。生成约束：每个框架的直接内部区域（不含更内层框架内部）中的标记数量各不相同（0, 1, 2, 3 中的不同值）。

**规则**：
1. 构建包含树：确定哪些框架包含哪些更小的框架，以及每个标记像素被哪个最内层框架直接包含。
2. 对每个框架，统计其"直接内部"中的标记像素数——直接内部定义为该框架内部、但不在任何子框架内部的区域。
3. 重涂色规则：
   - 直接内部标记数为 0 → 框架保持灰(5)
   - 直接内部标记数为 1 → 框架涂为该唯一标记的颜色
   - 直接内部标记数 >= 2 → 框架涂为其直接内部中距框架左上角（框架边框左上角像素）最近的那个标记的颜色（使用曼哈顿距离，若相等则取行号更小者，行号也相同则取列号更小者）
4. 所有标记像素从输出中擦除（变为黑(0)背景）。

**关键洞察**："直接内部"的定义是解题关键——一个标记虽然在外层框架的包围盒之内，但如果它在更内层框架的包围盒之内，则不计入外层框架。必须正确构建包含树才能得到正确的计数。

## 新题 5：拉伸精灵体与行填充轮廓的布尔交叠

**组合逻辑**：[拉伸](已有) ⊕ [行跨度填充](已有) → [布尔区域合成](创新：两个独立空间操作在同一框架内的交集/差集决定输出)

**来源原语**：拉伸、精灵体、空心矩形、包围盒映射、线段连接再填充(465b7d93)；填充、轮廓线、行内边界配对、逐行跨度填充(22168020)

**依赖链**：精灵体拉伸生成形状 A → 轮廓线填充生成形状 B → 同一框架内 A 和 B 的空间布尔关系决定每个像素的最终颜色。两个操作独立计算但结果相互作用：仅 A → 精灵体色，仅 B → 轮廓色，A∩B → 第三种颜色，都无 → 背景。删去任一操作则布尔合成退化。

**输入结构**：约 14x14 的黑(0)背景网格。中央有一个红(2)单像素厚的空心矩形框架，内部约 8x8。框架外有一个蓝(1)的 4-连通精灵体（4-7 个像素，形状不对称，非矩形）。框架内部有一个绿(3)的稀疏轮廓线（在其占据的每一行恰好有 2 个绿像素作为左右边界，占据 3-5 行）。精灵体和轮廓线不接触框架边框。生成约束：精灵体拉伸后的形状与轮廓线填充后的形状存在非空交集，但都不完全包含对方。

**规则**：
1. 拉伸精灵体进入框架内部：将精灵体的包围盒四角映射到框架内部区域的四角，精灵体中相邻像素的映射位置之间用水平或垂直线段连接，再填充线段围成的封闭区域。拉伸结果记为区域 A。
2. 对框架内的绿色轮廓线执行行跨度填充：在轮廓线占据的每行，将两个绿色边界之间（含边界）的所有像素标记为区域 B。
3. 框架内部每个像素的输出颜色按以下规则确定：
   - 仅属于 A（不属于 B）→ 蓝(1)
   - 仅属于 B（不属于 A）→ 绿(3)
   - 同时属于 A 和 B → 黄(4)
   - 都不属于 → 黑(0)背景
4. 框架边框保持红(2)。精灵体原始位置清除为黑(0)。

**关键洞察**：黄(4)像素标记了两个独立变换的空间交集——这个颜色不在输入中出现。求解者必须分别计算两个操作的结果，然后逐像素比较，才能确定最终输出。

## 新题 6：引导边旋转后压缩为象限色图

**组合逻辑**：[旋转/镜像](已有) → [象限映射压缩](已有，创新：被压缩对象需先经过旋转对齐)

**来源原语**：旋转、镜像、引导边、边框控制、颜色匹配朝向、裁剪(fc7cae8d)；象限映射、压缩、实心矩形面板、彩色标记、标记在面板象限内、标记半区定输出(19bb5feb)

**依赖链**：引导边颜色与边框控制匹配确定旋转方式 → 旋转改变面板内 2x2 标记的象限归属 → 裁剪掉引导边后做象限压缩。旋转方向判断错误则标记落入错误象限，输出完全不同。删去旋转则标记象限归属不正确；删去压缩则无法得到 2x2 输出。

**输入结构**：约 12x12 的黑(0)背景网格。网格的两条不同边界（如上边和右边）各有一条纯色边（边框控制），颜色各不相同（如上边为橙(7)、右边为栗(9)）。网格中央有一个灰(5)填充的矩形面板（约 7x7），面板的两条边各有 1 像素宽的引导边，颜色分别为橙(7)和栗(9)，与两条边框控制颜色对应。面板内部（不含引导边的区域）含有 1-3 个 2x2 的单色标记块，颜色各不相同（如红(2)、蓝(1)、绿(3)），散布在不同象限。生成约束：引导边的初始位置与对应边框控制所在的边不同（需要非恒等的旋转/镜像才能对齐）。面板内 2x2 标记的分布使得旋转前后至少有一个标记的象限归属发生变化。

**规则**：
1. 确定旋转/镜像变换：找到唯一的二面体群变换（旋转 0/90/180/270 度和/或水平/垂直镜像的组合），使面板的橙(7)引导边朝向网格的橙(7)边框控制所在边，同时栗(9)引导边朝向栗(9)边框控制所在边。
2. 对面板整体（含引导边和内部标记）应用该变换。
3. 裁剪掉旋转后面板的两条引导边，剩余灰色面板内部作为压缩对象。
4. 将裁剪后的面板中线水平和垂直各分为上下左右两半，生成 2x2 输出网格，初始为黑(0)。
5. 每个 2x2 标记块的中心落入哪个半区，其颜色就填入输出的对应单元格。无标记的象限保持黑(0)。

**关键洞察**：不做旋转直接压缩会得到错误的象限映射。引导边颜色编码了"面板的正确朝向"，但引导边本身在压缩前必须被裁剪，因此它们的信息是一次性的——读取后即丢弃。

## 新题 7：镜像拼接后对角线段各自推进并标记碰撞

**组合逻辑**：[镜像拼接](已有) → [平移绘制](已有，对角线段推进加长) → [透明叠加](创新：碰撞检测取代占用补集)

**来源原语**：镜像、拼接、翻转后拼接、画布(6fa7a44f)；平移绘制、对角线段、同反对角线、擦除、长度递增(50c07299)；透明叠加、标记(66f2d22f)

**依赖链**：镜像拼接将单个对角线段变为一对上下对称的线段 → 两段各自沿反对角线推进并加长 → 推进后若两段在同一像素位置出现则该像素标记为碰撞色。删去镜像则只有一条线段无碰撞可言；删去推进则位置不变也无碰撞；删去碰撞标记则输出缺少关键信息。

**输入结构**：约 7x10 的黑(0)背景网格（7 行 10 列）。网格内有 1 条反对角线段（沿左下→右上方向），由单一前景色（如蓝(1)）组成，长度 2-4 像素。线段不接触网格上下边界。生成约束：镜像拼接后的 14x10 网格中，两条推进后的线段在至少 1 个像素位置重叠，且推进后线段不超出网格边界。

**规则**：
1. 将输入网格上下镜像，将镜像副本拼接在原始网格下方，形成高度翻倍的网格（若原始 H 行则输出 2H 行，宽度不变）。此时上半部分有原始线段，下半部分有其上下翻转的副本。
2. 对上半部分中的原始线段执行推进：擦除当前线段，沿同一反对角线方向、紧接在当前线段的右上端之后，绘制一条比原长度多 1 像素的新线段，保持蓝(1)色。
3. 对下半部分中的镜像线段执行相同的推进规则：擦除当前线段，沿其所在反对角线方向、紧接在当前线段的右上端之后，绘制一条比原长度多 1 像素的新线段，保持蓝(1)色。（注意镜像后的线段仍在反对角线上，但行坐标与原始线段对称。）
4. 推进完成后，检查两条新线段是否在任何像素位置重叠。重叠的像素涂为红(2)；不重叠的像素保持蓝(1)。
5. 其余所有像素为黑(0)背景。

**关键洞察**：原始线段和其镜像副本在各自的反对角线上独立推进，但镜像的对称性使两条推进后的线段可能在网格中部交汇。碰撞位置由原始线段的长度和位置共同决定——仅看一个示例可能误以为碰撞色总在固定位置，需对比多例归纳出"各自推进 + 碰撞标记"的组合规则。

## 新题 8：前景平移叠于奇偶环纹背景

**组合逻辑**：[平移](已有) + [奇偶距离填充](已有，创新：从角标记辐射的环纹替代均匀灰背景)

**来源原语**：平移、前景段、固定步长平移、背景替换(32e9702f)；角标记像素、同心环、奇偶距离决定填色(d22278a0)

**依赖链**：平移将前景移位并空出原始位置 → 原始背景不是简单替换为灰色，而是被角标记的奇偶环纹覆盖 → 环纹颜色取决于到角标记的 Chebyshev 距离奇偶性 → 前景像素在新位置覆盖环纹。两套空间逻辑（平移方向 / 环纹辐射）同时作用于每个像素，最终输出由二者的优先级叠加决定。

**输入结构**：约 10x10 的黑(0)背景网格。包含若干蓝(1)的水平前景段（每段为同一行上连续的蓝色像素，宽 2-5 像素，1 像素厚），共 3-5 段分布在不同行。网格的恰好一个角落有一个红(2)单像素标记。生成约束：所有前景段左移一格后不超出左边界（即每段最左像素不在第 0 列）。

**规则**：
1. 将每个蓝(1)前景像素向左平移一列（如在 32e9702f 中）。移出左边界的像素被裁剪。
2. 对网格中每个非前景位置（平移后不被蓝色像素占据的位置），计算其到红(2)角标记的 Chebyshev 距离 d：
   - d 为偶数 → 该像素涂为红(2)
   - d 为奇数 → 该像素涂为灰(5)
3. 平移后的蓝(1)前景像素保持蓝色，覆盖在环纹之上。
4. 红(2)角标记本身保持红色（其 Chebyshev 距离为 0，偶数，也是红色，与规则一致）。

**关键洞察**：背景不是均匀灰色，而是由角标记辐射的红灰交替方环。前景平移后"浮于"环纹之上。仅看一个示例可能误以为背景模式是固定的棋盘格或条纹，需对比角标记位置不同的多个示例才能归纳出环纹辐射规则。

## 新题 9：去噪标记缺陷后按象限生成缺陷热力图

**组合逻辑**：[去噪](已有) → [缺陷标记](已有，创新：标记结果不直接输出，而是聚合为象限统计) → [象限映射压缩](已有，创新：压缩依据从标记颜色变为缺陷存在性)

**来源原语**：去噪、缺陷标记、凹痕、邻域多数色、忽略干扰项(de809cff)；象限映射、压缩、标记在面板象限内(19bb5feb)；前景区域(de809cff)

**依赖链**：去噪分离真缺陷与噪声 → 缺陷检测确定缺陷位置 → 象限归属统计每个象限的缺陷数 → 压缩输出反映各象限的缺陷状况。噪声不去除则缺陷位置误判；缺陷不检测则无法按象限聚合；不做象限映射则无法生成 2x2 输出。

**输入结构**：约 14x14 的黑(0)背景网格，几乎被一个大矩形面板完全占据（面板边缘距网格边缘 1 像素）。面板由两种前景色（如红(2)和蓝(1)）构成两个大区域，两色区域的分界线大致沿面板中线（可以是水平或垂直中线，不同示例可不同），但分界线不完全平直。面板内有 2-5 个黑(0)小凹痕（每个 1-2 像素），分布在不同象限。面板内还有 1-3 个单像素噪声（颜色为另一种前景色的孤立像素，出现在本不该出现该色的区域）。生成约束：每个象限的（去噪后）真缺陷数不完全相同，确保输出非全同。

**规则**：
1. 去噪：在面板中，将每个 4-连通分量大小为 1 且颜色与其 3x3 邻域多数前景色不同的像素重涂为邻域多数前景色（消除噪声）。
2. 缺陷检测：去噪后，面板中仍为黑(0)的像素即为真缺陷。
3. 将面板的包围盒沿水平和垂直中线分为四个象限（左上、右上、左下、右下）。
4. 生成 2x2 输出网格：
   - 若该象限包含至少一个真缺陷 → 对应输出单元为青(8)
   - 若该象限无真缺陷 → 对应输出单元为黑(0)

**关键洞察**：去噪步骤至关重要——噪声像素周围可能有黑色间隙，如果不先去噪就直接检测黑色像素，会将噪声边缘的背景误判为缺陷。输出是一个极简的 2x2 缺陷热力图，将空间细节压缩为象限级别的有/无判断。

## 新题 10：自色匹配集群选择后拉伸入框

**组合逻辑**：[包围选择](已有，自色匹配条件) → [裁剪](已有) → [拉伸](已有，创新：被拉伸的对象由集群选择规则决定)

**来源原语**：角标记、中心对象、包围关系、标记色与对象同色、裁剪(da6e95e5)；拉伸、精灵体、空心矩形、包围盒映射、线段连接再填充(465b7d93)；擦除(54db823b)

**依赖链**：自色匹配规则在多个集群中选出目标 → 裁剪出目标中心对象 → 将其拉伸入框架内部。选错集群则拉伸结果完全不同；不拉伸则输出只是裁剪而非变形；不擦除集群则输出包含无关元素。

**输入结构**：约 17x17 的黑(0)背景网格。包含 3 个互不重叠的"集群"，每个集群由四个相同颜色的小标记对象（每个标记为 1x2 或 2x1 矩形，4-连通）围绕一个中心小精灵体（3-6 像素，4-连通，单色）组成。四个标记分别位于中心精灵体包围盒的左上、右上、左下、右下外侧，与中心精灵体不相邻但在同一局部区域内。三个集群的标记颜色各不相同（如红(2)、蓝(1)、绿(3)），中心精灵体颜色也各不相同。恰好有一个集群的中心精灵体颜色与其四个角标记颜色相同（自色匹配集群）。网格中另有一个独立的灰(5)单像素厚空心矩形框架，内部约 6x6，不与任何集群重叠。生成约束：自色匹配集群的中心精灵体形状不对称，拉伸后视觉上有明确的方向性。

**规则**：
1. 识别自色匹配集群：找到唯一的集群，其中心精灵体颜色等于其四个角标记颜色。
2. 提取该集群的中心精灵体，裁剪至其包围盒。
3. 将精灵体拉伸入灰色空心框架的内部区域：将精灵体包围盒的四角映射到框架内部的四角，精灵体中相邻像素的映射位置之间用水平或垂直直线段连接，再填充线段围成的封闭背景区域（使用精灵体颜色）。
4. 擦除所有集群（三个集群的所有标记和中心精灵体全部变为黑(0)背景）。
5. 保留灰色框架和框架内的拉伸结果。

**关键洞察**：三个集群外观相似，选择错误的集群会产生完全不同的拉伸形状。自色匹配是唯一的选择依据——不是最大、最亮或最居中的集群，而是标记色与中心色一致的那个。

## 新题 11：对称轨道约束与模板补全的双重修复

**组合逻辑**：[对称补全](已有) ⊗ [模板补全](已有) → [双约束交叉验证](创新：两套独立约束系统各自修复一部分缺失，且必须一致)

**来源原语**：对称补全、对称图案、掩码像素、对称轨道映射、全对称群轨道约束(47996f11)；补全、模板精灵体、形状匹配、完整图案推断缺失(72322fa7)

**依赖链**：完整模板精灵体提供"中心色→壳色+壳偏移"局部规则 → D4 对称约束提供全局位置规则 → 某些缺失像素只能由局部模板推断（对称轨道上的所有位置都缺失），另一些只能由全局对称推断（局部无完整模板参照），两套规则必须交替使用直到所有缺失修复。删去模板补全则仅靠对称无法处理全轨道缺失；删去对称补全则仅靠模板无法推断远处缺失位置应放哪种模板。

**输入结构**：约 13x13 的黑(0)背景方形网格。网格中分布着若干 3x3 模板精灵体（每个由 1 个中心像素 + 若干壳像素组成，壳像素在中心的 8-邻域中呈对称分布）。存在 2 种不同的模板类型（如类型 A：红(2)中心 + 黄(4)壳形成十字壳；类型 B：蓝(1)中心 + 绿(3)壳形成对角壳）。部分精灵体是完整的（中心和壳都在），部分是仅有中心缺壳，部分是仅有壳缺中心。所有模板精灵体的中心位置构成的图案具有 D4 对称性（关于网格中心的 4 重旋转和 4 条反射轴），但有 2-4 个对称位置上的精灵体完全缺失（中心和壳都不存在），这些位置全部为黑(0)背景。品红(6)像素标记部分缺失位置作为提示，但不是所有缺失位置都有品红标记。生成约束：至少有一个缺失精灵体的位置，其 D4 对称轨道上的其他位置也全部缺失或不完整，因此无法仅靠对称确定类型，必须先通过模板补全修复某个不完整精灵体后再传播。

**规则**：
1. 从完整的精灵体中提取模板规则：中心色 → (壳色, 壳偏移集合)。每种中心色对应唯一的壳色和壳形状。
2. 对仅有中心的精灵体：根据模板规则，在其 8-邻域的壳偏移位置填入壳色（若该位置为黑(0)背景则填入）。
3. 对仅有壳的精灵体：根据壳色反查模板规则，在壳包围的中心位置填入对应的中心色。
4. 对完全缺失的位置：利用 D4 对称性，找到该位置在对称轨道上的已知（已补全的）精灵体，确定应放置的模板类型（中心色），然后按模板规则绘制完整精灵体。
5. 品红(6)标记像素在补全过程中被覆盖为正确颜色。
6. 反复执行步骤 2-4 直到所有缺失修复（因为步骤 2-3 的补全结果可能使步骤 4 中之前无法确定的位置变得可确定）。

**关键洞察**：这是一个约束传播问题——模板规则和对称规则是两套独立的约束系统，某些缺失只能被其中一套解决，而该解决方案又解锁了另一套约束的新推断。求解者不能只用一种策略，必须交替运用两种规则。
