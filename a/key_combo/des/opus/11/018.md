## 新题 1：边缘接触链序决定空心框填充色

**组合逻辑**：[边缘像素匹配 + 链式连接排序](创新：应用于空心框而非精灵块) → [洪泛填充](创新：填充色由链序位置决定而非空间位置)

**来源原语**：边缘像素匹配、链式连接排序（78332cb0）；洪泛填充、位置决定填充色（941d9a10）；空心框（4c416de3）

**依赖链**：必须先通过边缘像素重叠关系将空心框链成有序序列，该序列的位次才能映射为填充颜色。链序决定颜色——无法独立完成任何一步。

将散布的空心矩形框通过边缘像素重叠关系链成唯一序列，再按链序位次对每个框的内部做洪泛填充。

**输入结构**：约 18x18 的黑(0)背景网格。上面散布 4~5 个灰(5)边框的空心矩形框（边框宽度 1 像素，内部为黑(0)，各框大小不同且互不重叠）。每个框的四条边上有若干前景色像素（非灰非黑，颜色统一为橙(7)），分布在边框的特定行/列偏移处。生成约束：存在唯一一种配对方式使所有框的相邻面边缘像素在同一行/列偏移处重叠，从而形成一条无分叉的完整链。

**规则**：
1. 对每对框，检查它们沿水平或垂直方向的最近相对边：如果 A 的右边缘与 B 的左边缘在相同行偏移处各有橙(7)像素（即两边在同一行位置都有前景像素），则 A-B 可连接。同理适用于上下方向（检查列偏移）。
2. 从只有一端有连接的框开始（链头），沿匹配关系依次串联所有框，形成唯一有序链。
3. 按链序位次为每个框的内部区域（框内所有黑(0)像素）洪泛填充颜色：第 1 位 = 蓝(1)，第 2 位 = 红(2)，第 3 位 = 绿(3)，第 4 位 = 黄(4)，第 5 位 = 品红(6)。
4. 灰(5)边框和橙(7)边缘像素保持不变。

**关键洞察**：框的空间位置（左上角坐标）不决定填充顺序——只有边缘像素重叠形成的拓扑链才决定；必须对比多个示例才能确认链位次到颜色的映射规则。

## 新题 2：象限归属决定延伸着色而非最近边

**组合逻辑**：[延伸 + 朝近端扩展](保留方向判定) + [象限对应](创新：象限归属决定延伸颜色而非方向)

**来源原语**：延伸、朝近端扩展、边缘条、控制像素（642248e4）；象限对应、象限决定目标格（d89b689b）；重涂色（48634b99）

**依赖链**：延伸方向取决于距离最近的边缘条（距离判断），但延伸颜色取决于控制像素所在的象限对应的边缘条颜色（象限判断）。两种独立的空间推理交织于同一操作的不同参数。

每个控制像素向距离最近的边缘条方向延伸一格，但延伸格的颜色由该控制像素所在象限对应的边缘条颜色决定。

**输入结构**：约 15x15 的黑(0)背景网格。四条完整边缘条分别位于网格的上、下、左、右边界（各占一整行/列），颜色各不相同——上=蓝(1)、右=红(2)、下=绿(3)、左=黄(4)。网格内部散布 5~7 个灰(5)控制像素，各自远离边界（与四边缘条的距离均 >= 2）。以网格中心为原点划分四象限：左上、右上、右下、左下。生成约束：每个控制像素的最近边缘条方向和其象限归属不完全一致（即存在至少一个像素距上边最近但位于右下象限等情况）。

**规则**：
1. 对每个灰(5)控制像素，沿行轴和列轴分别计算到四条边缘条的曼哈顿距离，确定距离最近的那条边缘条所在方向。
2. 在该方向上紧邻控制像素的下一格绘制一个新像素（延伸一格）。
3. 新像素的颜色不取决于最近边缘条，而取决于控制像素所在象限：左上象限 → 用上边缘条颜色蓝(1)，右上象限 → 用右边缘条颜色红(2)，右下象限 → 用下边缘条颜色绿(3)，左下象限 → 用左边缘条颜色黄(4)。
4. 控制像素本身保持灰(5)不变，四条边缘条不变。
5. 若延伸目标格已被边缘条占据，则该控制像素不做延伸（跳过）。

**关键洞察**：方向和颜色由两套独立的空间逻辑分别决定——必须同时正确推断"向哪延伸"（距离最近）和"用什么色"（象限归属）才能得出正确输出。仅看单个示例可能混淆这两个来源。

## 新题 3：角落对象顺时针复制并按尺寸等级旋转

**组合逻辑**：[复制 + 顺时针到下一角](保留角落检测和顺时针方向) + [旋转](创新：旋转角度由对象尺寸在全局排名中的位次决定)

**来源原语**：复制、平移、角落对象、接触两边缘、顺时针到下一角、忽略干扰项（bc93ec48）；旋转（4c416de3）；尺寸排序（48634b99）

**依赖链**：必须先识别角落对象并确定尺寸排名，再在顺时针复制过程中根据排名施加旋转。排名依赖全局比较，旋转依赖排名，放置依赖顺时针映射——三者构成不可跳步的推理链。

将贴合网格角落的单色对象顺时针复制到下一角落，复制时根据对象像素数从小到大的排名旋转 0/90/180/270 度。

**输入结构**：约 16x16 的黑(0)背景网格。恰好 4 个单色 4-连通前景对象，每个贴合一个网格角落（其边界框同时接触该角落的两条边界）。4 个对象颜色各不相同（从蓝(1)、红(2)、绿(3)、黄(4)中选取），像素数各不相同（范围 3~8 像素），形状不规则（非矩形）。网格内部可能有 1~2 个灰(5)干扰对象（不接触任何角落）。生成约束：4 个角落对象像素数严格不同，确保尺寸排名唯一。

**规则**：
1. 忽略所有不同时接触两条相邻边界的对象（干扰项）。
2. 对 4 个角落对象，按像素数从小到大排名：第 1 名（最小）、第 2 名、第 3 名、第 4 名（最大）。
3. 将每个对象的像素图案复制到顺时针方向的下一角落（左上→右上、右上→右下、右下→左下、左下→左上）。放置时将边界框对齐到目标角落。
4. 复制前，根据尺寸排名对图案施加顺时针旋转：排名第 1 = 不旋转(0°)、排名第 2 = 顺时针 90°、排名第 3 = 180°、排名第 4 = 顺时针 270°。
5. 源对象保持原位不清除。副本覆盖目标位置已有像素（后放置的覆盖先放置的）。干扰对象保持不变。

**关键洞察**：顺时针方向固定，但旋转角度并非由角落位置决定，而是由跨对象的尺寸全局排名决定——必须比较所有角落对象的像素数才能确定每个副本的旋转量。

## 新题 4：色带压缩序列作为空腔平铺种子

**组合逻辑**：[压缩 + 行主色压缩单像素](提取色带序列) → [平铺 + 保持种子相位](创新：压缩产物本身成为平铺种子而非预设在空腔中)

**来源原语**：压缩、色带、空间排列顺序、行主色压缩单像素（4be741c5）；平铺、种子图案、矩形空腔、墙壁、图案填满空腔、保持种子相位（a57f2f04）

**依赖链**：色带区域的压缩输出一个短颜色向量，该向量直接成为空腔区域的平铺种子。没有压缩就没有种子；没有空腔就无处平铺。两步操作通过"压缩产物即种子"这一共享数据结构紧耦合。

将网格上半区的宽色带压缩为一列颜色序列，再将该序列作为种子图案平铺到下半区的矩形空腔中。

**输入结构**：约 20x12 的黑(0)背景网格，被一条水平灰(5)分隔线（完整行）分为上下两区。上区（约 8 行）：被 3~4 种非黑非灰颜色的宽色带完全覆盖（无黑(0)背景），各行的主色形成从上到下的连续带，带边界参差不齐（同一行可能有少量非主色噪声像素）。下区（约 10 行）：灰(5)墙壁围成一个矩形空腔，空腔内部全为黑(0)，空腔高度等于上区色带数量，宽度 >= 色带数量的 2 倍。生成约束：上区每行恰好有一个出现次数严格超过半数的主色；色带数量等于空腔高度。

**规则**：
1. 对上区逐行取主色（该行出现次数最多的颜色），将相邻同色行归为一个色带，按从上到下顺序得到颜色序列（如 [红(2), 蓝(1), 绿(3)]）。
2. 将该序列视为一列（Nx1）的种子瓦片。
3. 在下区空腔中，以空腔左上角为相位起点，将种子瓦片沿水平方向周期性重复，直至铺满整个空腔。即空腔第 i 行第 j 列的颜色 = 序列第 i 项（行索引从 0 开始对应序列第 0 项）。
4. 灰(5)分隔线和墙壁不变，上区保持原样不变。

**关键洞察**：上区的色带顺序直接编码了下区的平铺图案——求解者必须先完成压缩识别色带序列，才能知道空腔该如何填充。色带的数量恰好等于空腔高度这一隐含对应关系需要跨示例对比才能确认。

## 新题 5：低频色掩码定位印章 + 印章内容由框内解码字形决定

**组合逻辑**：[低频色掩码 + 掩码选位放置](确定印章位置) + [解码 + 字形映射](创新：字形解码的结果不是颜色行而是选择哪个精灵体作为印章内容)

**来源原语**：低频色掩码、掩码选位放置、最低频色定位（48f8583b）；解码、字形图案、字形映射颜色行、位置映射（995c5fa3）；印章放置、精灵体（a251c730）

**依赖链**：低频色掩码决定"在哪里放"；字形解码决定"放什么"。两条独立推理路径汇聚到同一个印章操作——缺任何一条都无法完成输出。

在 3x3 控制网格中找出最低频色的位置作为印章目标位，同时解码网格边缘的字形图案确定印章内容，最终在目标位放置对应精灵体。

**输入结构**：约 15x15 的黑(0)背景网格，分为三个区域。左侧区（约 5x15）：包含 3 个竖向排列的 4x4 字形图案，每个字形由灰(5)和黑(0)像素组成不同的黑色掩码模式（3 种可区分的模式）。右上区（约 5x5）：一个 3x3 的彩色控制网格，其中 2 种颜色各占多数格，第 3 种颜色恰好占 2~3 格（最低频色）。右下区（约 8x8）：包含 3 个紧凑的单色精灵体（3~6 像素的 4-连通图形），颜色分别为红(2)、绿(3)、黄(4)，彼此间隔开。生成约束：3 种字形模式与 3 个精灵体之间存在固定一一映射关系（跨示例保持一致）。

**规则**：
1. 在右上区的 3x3 控制网格中，找出出现次数最少的颜色，记录其所在格的位置集合。
2. 在左侧区，识别 3 个 4x4 字形图案，按从上到下的顺序编号 1、2、3。根据每个字形的黑色像素掩码模式，将其映射到对应的精灵体：模式 A（黑像素集中在左上 2x2）→ 红(2)精灵体，模式 B（黑像素形成对角线）→ 绿(3)精灵体，模式 C（黑像素集中在底行）→ 黄(4)精灵体。
3. 构建 9x9 的黑(0)输出画布，将其视为 3x3 排列的 3x3 块。
4. 对于控制网格中最低频色所在的每个位置 (r,c)，将字形编号 = r+1 对应的精灵体（取精灵体的紧凑边界框，不足 3x3 则居中放入 3x3 块）复制到输出画布的第 (r,c) 块中。
5. 未被选中的块保持黑(0)。

**关键洞察**：位置和内容由完全不同的视觉线索决定——低频色掩码给出"哪些块被激活"，字形解码给出"激活块里放什么"，且字形的行位置与输出块的行位置绑定。必须同时破解两套编码才能得出正确输出。

## 新题 6：障碍门分段距离递变填充

**组合逻辑**：[距离递变 + 逐行宽度递变成楔](保留距离渐变扩展逻辑) + [障碍门处标记通道](创新：障碍门将连续渐变分割为多段，每段颜色不同)

**来源原语**：填充、距离递变、逐行宽度递变成楔、线段（a65b410d）；障碍段、障碍门处标记通道（fc10701f）；重涂色（48634b99）

**依赖链**：距离递变决定填充的几何形状（楔形展开），障碍门将楔形切割为多段并为每段分配不同颜色。没有障碍门则不知如何分色；没有距离递变则不知如何确定几何范围——两个逻辑在同一空间区域交叉作用。

从锚定线段出发做距离递变的楔形填充，但黑色障碍段将楔形区域分割成若干段，每段用不同颜色填充。

**输入结构**：约 18x18 的黑(0)背景网格。一条红(2)水平线段位于网格左侧中部（起于左边界，长度 4~6 像素）。线段上方和下方各有 1~2 条水平黑(0)背景中的灰(5)短障碍段（长度 >= 线段长度 + 该行距线段的距离，确保能完全横切楔形区域），沿水平方向放置。生成约束：障碍段将线段上方区域分为 2~3 个垂直段落，下方区域同理分为 2~3 个段落；上方段落数和下方段落数可能不同。

**规则**：
1. 保持红(2)线段不变。
2. 从线段出发，按照距离递变规则确定楔形填充区域：线段上方第 d 行填充宽度 = 线段长度 + d（向右扩展），左对齐；线段下方第 d 行填充宽度 = 线段长度 - d（向右收缩），左对齐。宽度 <= 0 时停止。
3. 灰(5)障碍段所在行不填充（保持障碍段原样）。障碍段将上方楔形区域从上到下分为若干连续段落（被障碍段夹在中间的连续行组）。
4. 对上方各段落，按从近（靠近线段）到远的顺序编号，第 1 段填绿(3)，第 2 段填蓝(1)，第 3 段填黄(4)。
5. 对下方各段落，同样从近到远编号，第 1 段填品红(6)，第 2 段填橙(7)，第 3 段填青(8)。
6. 填充时，每行的有效宽度仍遵循距离递变（线段长度 +/- 距离），只是颜色由段落编号决定。

**关键洞察**：楔形的几何轮廓完全由距离递变逻辑决定，但楔形内部的颜色分布由障碍段的位置切割决定——二者独立确定形状和色彩，必须同时掌握才能正确输出。段落编号规则（近段优先）需要跨示例对比不同障碍段配置才能归纳。

## 新题 7：半段标记推进 + 推进目标由边缘像素链决定

**组合逻辑**：[重涂色 + 半段位置保持](保留标记推进和半段逻辑) + [边缘像素匹配 + 链式连接排序](创新：推进目标不由尺寸+2决定，而由边缘接触链的下一个节点决定)

**来源原语**：重涂色、平移、竖条、标记段、尺寸排序、半段位置保持（48634b99）；边缘像素匹配、链式连接排序（78332cb0）

**依赖链**：必须通过边缘像素匹配建立竖条之间的链式顺序，才能确定标记应推进到哪根竖条；同时必须识别当前标记占据的是上半段还是下半段，以在目标竖条保持相同位置。链序和半段判断缺一不可。

将标记从当前竖条推进到边缘接触链中的下一根竖条，保持标记在上半段或下半段的位置不变。

**输入结构**：约 14x20 的黑(0)背景网格。包含 5~6 根绿(3)竖条（宽 1 像素，高度各不相同且均为偶数，范围 4~12 像素），分散在网格各列。其中恰好一根竖条的上半段或下半段被重涂为红(2)（标记段），其余部分仍为绿(3)。每根竖条的顶端或底端像素旁（水平相邻格）有 0~2 个橙(7)连接像素。生成约束：通过橙(7)连接像素的行对齐关系，所有竖条可被串成唯一无分叉链（若竖条 A 的底端连接像素与竖条 B 的顶端连接像素在同一行，则 A→B 相连）。

**规则**：
1. 识别所有绿(3)竖条及其顶端/底端的橙(7)连接像素。
2. 建立链：若竖条 A 的某个连接像素与竖条 B 的某个连接像素在同一行（水平对齐），则 A 与 B 相邻。按此关系将所有竖条串成有向链（从链头到链尾）。
3. 找到当前含红(2)标记段的竖条，确定标记占据其上半段还是下半段。
4. 将标记段恢复为绿(3)。
5. 在链中找到该竖条的下一个节点（下一根竖条），将其相同半段（上半或下半）重涂为红(2)。
6. 若当前标记在链尾，则推进到链头（环形）。
7. 所有橙(7)连接像素保持不变。

**关键洞察**：推进目标不是按高度排序的"下一根更高的竖条"（源题逻辑），而是由连接像素的行对齐形成的拓扑链决定——物理位置远近和高度大小都无法预测推进方向，只有破解链式连接规则才能求解。
