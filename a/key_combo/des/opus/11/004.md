## 新题 1：多锚阶梯碰撞与深度调色

**组合逻辑**：[连线/阶梯](创新：多源并行生长并相互碰撞) + [循环填充](已有原语，改作用于阶梯臂的步距深度) + [碰撞停止](创新：跨源碰撞检测决定生长终止)

**来源原语**：连线/阶梯图案(d06dbe63)、循环填充/层深度递增(b457fec5)、碰撞停止(195c6913)、调色板行(b457fec5)、锚点像素(d06dbe63)

**依赖链**：调色板行的长度决定阶梯步长（步长 = 调色板像素数）→ 各锚点同时以该步长生长阶梯臂 → 多源阶梯臂可能在空间上相遇，碰撞终止生长 → 每个阶梯像素的着色由其距所属锚的步数深度经调色板循环取色决定。调色板同时控制几何结构（步长）和颜色填充，两者不可分离。

从多个锚点按调色板长度为步长并行生长对称阶梯臂，跨源碰撞时终止，最后按步距深度循环调色板着色。

**输入结构**：约 15x20 的黑(0)背景网格。沿顶行有一段连续的水平调色板条（3~5 个相邻像素，各不同色，取自黄(4)、橙(7)、品红(6)、栗(9)等）。网格下方区域散布 2~4 个灰(5)单像素锚点，任意两锚点之间曼哈顿距离至少 6。生成约束：各锚点的阶梯臂在当前调色板步长下至少能生长 2 步后才可能碰撞或越界；至少存在一对来自不同锚点的阶梯臂会在网格内相遇。

**规则**：
1. 读取顶行调色板条的像素数 P（即调色板长度）。
2. 对每个灰(5)锚点，生长两条对称阶梯臂：一条先向上移动 P 格、再向右移动 P 格、再向上 P 格...交替进行；另一条先向下 P 格、再向左 P 格、再向下 P 格...交替进行。每次转向绘制 P 个像素为一"步"。
3. 按锚点从左到右（左边界框列坐标最小者优先；列坐标相同则行坐标小者优先）的顺序依次生长。每一步绘制前检查：若该步的任何像素会落在已有非背景像素上或越出网格边界，则该臂停止生长（不绘制该步），另一臂不受影响继续生长直到其自身碰撞或越界。
4. 所有阶梯臂绘制完毕后，对每个阶梯像素（不含锚点本身）重涂色：该像素所在的步序号为 d（从 1 开始，距锚点最近的步为第 1 步），取调色板第 (d-1) mod P 个颜色。
5. 锚点像素保留灰(5)不变。

**关键洞察**：调色板行承担双重角色——它既定义颜色循环序列，又通过其长度决定阶梯的几何步长。改变调色板长度将同时改变阶梯的形状和颜色分布，这一几何-着色耦合需要对比不同调色板长度的示例才能发现。

## 新题 2：分隔面板叠加与合并后组件重涂色

**组合逻辑**：[计数/连通分量](已有原语) → [透明叠加](创新：叠加优先级由组件计数决定) → [计数+重涂色](创新：在叠加合并后的新拓扑上二次计数并按合并尺寸着色)

**来源原语**：分隔行/等高面板/透明叠加(e98196ab)、连通分量/计数(aaecdb9a)、重涂色/像素数映射颜色(6e82a1ae)

**依赖链**：分隔行将网格切分为等高面板 → 统计每个面板内 4-连通前景组件数量 → 组件数决定面板的叠加层序（少在下多在上）→ 叠加合并前景像素 → 合并可能使不同面板的对象连接为更大组件 → 在合并后的拓扑上重新计数每个组件的像素数 → 按合并后的尺寸重涂色。两次计数作用于不同几何状态（叠加前 vs 叠加后），使逻辑不可跳步。

删除分隔行，按各面板前景组件数从少到多叠加，合并后按新组件像素数重涂色。

**输入结构**：约 17x10 的黑(0)背景网格。两条灰(5)实心水平行横贯全宽，将网格分为三个等高面板（每个面板约 5 行）。每个面板内有 1~4 个红(2)的 4-连通单色前景对象，每个对象 2~6 像素，形态不限（须为 4-连通，像素数在该范围内）。不同面板中的对象在列坐标上可能有重叠。生成约束：三个面板的组件数两两不同；至少一组来自不同面板的对象在叠加后同一局部坐标处有前景像素（产生冲突）；至少一次叠加合并导致两个原本独立的对象连为一个组件。

**规则**：
1. 删除两条灰(5)分隔行。
2. 统计每个面板内 4-连通红(2)组件的数量。
3. 将三个面板叠加到一个面板高度的画布上：组件数最少的面板作为底层，最多的在顶层。同一局部坐标 (r, c) 上若多个面板都有前景像素，保留最上层面板的像素。
4. 在叠加结果中，重新识别所有 4-连通前景组件，统计每个组件的像素数 S。
5. 按像素数重涂色：S <= 2 → 绿(3)；3 <= S <= 5 → 蓝(1)；S >= 6 → 黄(4)。

**关键洞察**：叠加优先级取决于叠加前各面板的组件计数，但最终颜色取决于叠加后合并组件的像素数——叠加改变了拓扑结构，使第二次计数的结果与第一次无直接对应关系，两步计数不可省略任一步。

## 新题 3：射线压缩后旋转对称筛选

**组合逻辑**：[压缩/紧缩至锚](已有原语) → [旋转](创新：不用于恢复遮挡而用于对称性谓词判断) → [擦除](创新：由对称性判断结果条件触发)

**来源原语**：压缩/射线像素紧缩至锚/锚块/同色射线归属锚块(f28a3cbb)、旋转/旋转对应/半周旋转恢复(ff805c23)、擦除(9f8de559)

**依赖链**：同色散射像素沿视线压缩回 3x3 锚块 → 压缩后的紧凑排列形成新的空间图案 → 以锚块中心为原点取 7x7 窗口检测 180 度旋转对称 → 对称者保留，不对称者连同锚块和射线一并擦除。压缩改变了空间排列，排列决定对称性，对称性决定存亡——三步紧耦合。

将散射的射线像素压缩回锚块后检测局部 180 度旋转对称，保留对称锚、擦除不对称锚。

**输入结构**：约 20x20 的黑(0)背景网格。含 3~4 个不同颜色的 3x3 实心方块（锚块），颜色取自红(2)、蓝(1)、绿(3)、黄(4)，每色至多一个锚块。每个锚块外有 2~5 个与其同色的孤立单像素，分布在经过锚块中心的水平、垂直或 45 度对角线上，距离锚块 2~8 格不等。生成约束：不同颜色的射线不相交；压缩后至少一个锚块的 7x7 邻域呈 180 度旋转对称，至少一个不是；射线像素压缩后不超出 7x7 窗口。

**规则**：
1. 对每种前景颜色，识别其 3x3 锚块和所有同色孤立像素。
2. 每个孤立像素位于经过锚块中心的某条直线（水平/垂直/45 度对角）上。沿该直线方向将像素向锚块滑动，直到紧贴锚块边缘或紧贴另一个已压缩到位的同色像素。按距锚块从近到远的顺序处理。
3. 所有颜色压缩完毕后，对每个锚块取以其中心像素为中心的 7x7 正方形窗口（超出网格边界的部分视为背景）。检测窗口内所有非背景像素的图案是否在 180 度旋转下不变（即将窗口旋转 180 度后，每个位置的颜色与旋转前相同）。
4. 通过对称测试的锚块：保留锚块及其压缩后的射线像素不变。
5. 未通过的锚块：将该锚块的所有像素（3x3 块 + 压缩后的射线像素）全部擦除为黑(0)。

**关键洞察**：压缩步骤不是装饰性的空间重排——它是将射线像素从分散状态聚拢到可检测的紧凑形态，只有在紧凑形态下 180 度旋转对称测试才有意义。对称性测试使用 7x7 固定窗口而非射线全域，这一窗口尺寸需要对比多个示例（不同射线长度但窗口大小不变）才能确认。

## 新题 4：贪心路径中标记朝向决定走廊颜色

**组合逻辑**：[贪心遍历](已有原语) + [路径绘制](已有原语) + [标记朝向编码颜色](创新：朝向不再编码对象自身的重涂色，而是编码通向该对象的走廊颜色) + [擦除](已有原语)

**来源原语**：贪心遍历/路径绘制/视线可见/同行同列对齐/最近未访问优先/视线遮挡判断(3490cc26)、标记朝向编码颜色/擦除(604001fa)

**依赖链**：从起始块出发按最近可见优先贪心访问目标块 → 每到一个目标块，读取其旁边 L 形标记的朝向 → 朝向编码出一种颜色 → 用该颜色绘制从前一站到当前站的走廊 → 擦除已读取的标记。遍历顺序决定走廊存在性，标记朝向决定走廊颜色，两者在每一步交织。

沿贪心最近可见路径逐站行走，每段走廊的颜色由目的站的 L 标记朝向编码决定。

**输入结构**：约 20x20 的黑(0)背景网格。一个红(2) 2x2 方块为起点。4~6 个青(8) 2x2 方块为目标站。每个青方块的正上方紧邻一个橙(7) L 形三联体（占据一个 2x2 框内的三个像素，缺失一角），L 的 2x2 框的列范围与其所属青方块的列范围重叠。各方块之间部分对共享同一双行或双列带（使视线可达），部分不共享。生成约束：从起点出发的贪心遍历至少访问 3 个目标站后才无可见未访问目标；每一步的最近可见目标唯一（无平局）；四种 L 朝向至少出现两种。

**规则**：
1. 从红(2)起始块出发。
2. 在所有未访问的青(8)目标块中，找与当前块共享双行或双列带（即两块在水平或垂直方向上有两行或两列重叠）且带内间隙中无非背景像素阻挡的目标块。从中选间隙像素数最少的那个（最近者）。
3. 读取该目标块上方橙(7) L 三联体的朝向——确定其 2x2 框中缺失角的位置。缺失角位置与走廊颜色的映射为：左上缺失 → 绿(3)；右上缺失 → 黄(4)；左下缺失 → 品红(6)；右下缺失 → 栗(9)。
4. 将当前块与该目标块之间的背景间隙像素全部涂为步骤 3 确定的颜色。
5. 将该目标块的橙(7) L 三联体擦除为黑(0)。
6. 以该目标块为当前块，重复步骤 2-5，直到无可见未访问目标块为止。

**关键洞察**：空间布局控制哪些站可达（视线 + 最近优先），而每个站旁微小的 L 标记几何细节控制到达该站的走廊被涂什么颜色。遍历结构和局部标记几何缺一不可——不走到某站就不知道该走廊颜色，不知道 L 朝向映射就无法着色。四种朝向到四种颜色的映射需要至少两个示例交叉验证。

## 新题 5：降采样掩码平铺与环形深度循环着色

**组合逻辑**：[降采样](已有原语) + [掩码裁剪](创新：裁剪后不用于叠加而用于平铺种子) → [平铺](创新：将二值掩码而非彩色图案平铺) → [循环填充](创新：不沿对角带而沿同心矩形环层深度着色)

**来源原语**：降采样/掩码裁剪/整数缩放对应(6ecd11f4)、平铺(3979b1a8)、循环填充/层深度递增/调色板行(b457fec5)

**依赖链**：大型单色块放大图案 → 降采样为 KxK 二值掩码 → 掩码 2x2 平铺为 2Kx2K 网格 → 在每个瓦片内按同心矩形环层深度对"亮"格循环调色板着色 → 调色板条独立提供颜色序列。掩码决定着色位置，瓦片坐标决定环层深度，深度选择调色板颜色——三层信息交织。

将块放大图案降采样为二值掩码，2x2 平铺后按瓦片内环形深度循环调色板着色。

**输入结构**：约 18x18 的黑(0)背景网格。在网格一侧有一个块放大的单色图案：一个 KxK（K=3 或 4）二值母题，每个元胞放大为 SxS（S=2 或 3）的灰(5)实心块（"亮"）或黑(0)块（"暗"），总尺寸 KS x KS。在网格另一侧有一段水平调色板条：2~4 个相邻的不同色像素（取自红(2)、蓝(1)、黄(4)、橙(7)等）。生成约束：母题至少有 3 个"亮"格和 2 个"暗"格；KS <= 12 以保证网格放得下；调色板颜色不含灰(5)。

**规则**：
1. 裁剪块放大图案至其边界框。计算缩放因子 S = 边界框宽度 / K（K 由列方向上相同灰度值的连续块数推断）。每 SxS 块取一个采样值，得到 KxK 二值掩码 M（1 = 灰, 0 = 黑）。
2. 读取调色板条，记颜色序列为 C[0], C[1], ..., C[P-1]，P 为调色板长度。
3. 将 M 按 2x2 平铺，构建 2K x 2K 的输出网格。每个瓦片是 M 的一份副本。
4. 对输出网格中每个"亮"格（M 对应值为 1），计算其在所属瓦片内的局部坐标 (r, c)（0-索引，瓦片左上角为原点）。计算环形层深度 d = min(r, c, K-1-r, K-1-c)。
5. 将该格涂色为 C[d mod P]。"暗"格保持黑(0)。
6. 输出 2K x 2K 网格。

**关键洞察**：同一掩码位置在四个瓦片中都出现，且因其瓦片内局部坐标相同而获得相同颜色——形成视觉上的四重周期对称。但层深度公式是同心矩形环（min(r, c, K-1-r, K-1-c)）而非简单的 min(r,c)，这一点需要在掩码包含远离左上角的亮格的示例中才能验证。

## 新题 6：镜像对称筛选与异形唯一精灵提取

**组合逻辑**：[镜像/翻转行序](创新：不用于生成输出而用于构造对称性谓词) → [提取](已有原语) + [去重筛选/图案仅出现一次](创新：在对称性筛选后的子集上运行唯一性过滤)

**来源原语**：镜像/翻转行序(68b16354)、提取/去重筛选/带框精灵体/图案仅出现一次/异常值选择(aee291af)

**依赖链**：识别所有同尺寸带框精灵体 → 对每个精灵体的内部图案做垂直镜像（行序翻转）→ 镜像后与原图案相同者为"对称型"，剔除 → 在剩余"非对称型"精灵体中比较内部图案 → 提取内部图案仅出现一次的那个精灵体。对称性过滤和唯一性过滤是两道独立的筛，作用于不同属性（几何对称 vs 图案重复），两道筛的交集才是答案。

先用垂直镜像对称性淘汰一批精灵体，再在幸存者中按内部图案唯一性提取最终答案。

**输入结构**：约 20x15 的黑(0)背景网格。含 5~7 个相同外框尺寸的矩形精灵体（如 5x4），每个精灵体有蓝(1)单像素厚边框，内部为红(2)像素在黑(0)背景上的图案。各精灵体之间至少间隔 2 格。生成约束：至少 2 个精灵体的内部图案关于水平中线上下对称（镜像后不变）；至少 3 个不对称；在不对称的精灵体中，恰好有一个的内部图案是唯一的（其余不对称精灵体的内部图案两两存在至少一个重复伙伴）。

**规则**：
1. 识别所有蓝(1)边框的最大完整矩形（边框一像素厚，内部不含黑(0)以外的背景连通到外部的通道——即边框完整封闭）。
2. 对每个精灵体，提取其边框内部的图案（不含边框本身），记为 P_i。
3. 将 P_i 的行序翻转得到 P_i'。若 P_i = P_i'（逐像素相同），则该精灵体为"垂直对称型"，从候选集中剔除。
4. 在剩余候选精灵体中，比较各 P_i。找到内部图案仅出现一次（无其他候选精灵体与之相同）的那个精灵体。
5. 输出该精灵体（含蓝(1)边框），裁剪至其边界框。

**关键洞察**：本题串联两种完全不同的选择标准——第一轮按几何属性（对称性）淘汰，第二轮按组合属性（唯一性）选择。仅凭一个示例可能无法分辨筛选用的是垂直对称还是水平对称，需要多个示例中不同对称方向的精灵体表现来确认是行翻转（垂直镜像）而非列翻转。

## 新题 7：周期条纹提取为克罗内克自积种子

**组合逻辑**：[提取](创新：从矩形边框内的周期条纹提取一维二值向量) → [印章覆盖/掩码克罗内克自积](创新：将一维向量先外积为二维掩码再自积) + [擦除](已有原语，擦除原始边框结构)

**来源原语**：周期条纹/矩形边框/标记条/周期掩码(6a980be1)、印章覆盖/掩码克罗内克自积/自相似嵌套/二值掩码/编码映射(80af3007)

**依赖链**：矩形边框内的周期条纹编码一维二值模式 → 提取一个周期得到长度为 P 的向量 V → V 与自身做外积得到 PxP 二维掩码 M → M 做克罗内克自积：M 的每个"亮"格替换为 M 本身，"暗"格替换为空白块 → 输出 P^2 x P^2 的自相似图案。一维周期模式是二维自相似结构的生成元，编码层级从 1D→2D→自相似三层递进。

从边框内周期条纹解码一维模式，外积为二维掩码，再克罗内克自积生成自相似分形。

**输入结构**：约 14x14 的黑(0)背景网格。网格中有一个红(2)像素构成的单像素厚矩形边框（宽约 8~12、高约 5~7）。边框内部有两条水平蓝(1)实心行（标记条），横贯内部全宽，将内部分为三个水平区域。中间区域（两条蓝行之间）中，某些列被绿(3)像素填满（从上蓝行到下蓝行），其余列保持黑(0)。绿列形成周期性分布，周期为 P（P = 3, 4 或 5），且 P 整除中间区域的列数。边框外全为黑(0)。生成约束：一个周期 P 内至少有 2 个绿列和 1 个黑列。

**规则**：
1. 定位红(2)矩形边框，识别内部两条蓝(1)水平标记条。
2. 在两条标记条之间的中间区域，逐列检查：绿(3)列记为 1，黑(0)列记为 0。提取最短重复周期，得到长度为 P 的二值向量 V。
3. 计算 PxP 二维掩码 M：M[r][c] = V[r] AND V[c]（V 与自身的外积）。
4. 构建 P^2 x P^2 输出网格（克罗内克自积）：对 M 中每个位置 (i,j)——若 M[i][j] = 1，在输出的对应 PxP 块中放置 M 的副本（"亮"格涂红(2)，"暗"格涂黑(0)）；若 M[i][j] = 0，对应 PxP 块全为黑(0)。
5. 输出 P^2 x P^2 网格。

**关键洞察**：输入中的一维列模式是整个二维分形输出的唯一生成元。二维掩码不是独立给定的，而是由同一个一维模式与自身外积得到——行方向和列方向使用相同的模式。这一"自外积"规则需要对比包含不同一维模式的示例才能确认，因为单个示例中行列对称可能被误认为巧合。

## 新题 8：角标记扩展与区域角色分类着色

**组合逻辑**：[像素放大/朝向对应角/扩展至外角](已有原语) → [局部位置分类/角边内部分别涂色](创新：对扩展后的 L 臂围成的矩形区域做角/边/内分类着色) + [重涂色](创新：L 臂像素覆写角色颜色)

**来源原语**：角落标记/像素放大/朝向对应角/扩展至外角(b745798f)、局部位置分类/角边内部分别涂色/矩形/重涂色(b6afb2da)

**依赖链**：小 L 标记的朝向决定对应外角 → 在该外角绘制放大的 L 臂 → L 臂的边界框定义一个矩形区域 → 该矩形区域内的每个像素按角/边/内部角色着色 → L 臂像素用原始标记颜色覆写角色颜色。朝向决定区域位置，区域几何决定角色分类，L 臂覆写又依赖朝向所确定的臂路径——三者循环依赖。

将小 L 标记扩展到对应外角，在扩展 L 的边界框内做角/边/内分类着色，然后 L 臂以原色覆写。

**输入结构**：奇数边长（11~17）的正方形黑(0)背景网格。含 1~3 个单色 4-连通 3 像素 L 形标记，每个标记占据一个 2x2 框内的三个像素（缺一角），颜色各不同，取自红(2)、绿(3)、蓝(1)。标记位于网格内部（不接触边缘）。生成约束：不同标记映射到不同外角（即缺失角方向各不相同）；当网格含 2 个以上标记时，至少有两个扩展 L 的边界框在角落处重叠。

**规则**：
1. 对每个 3 像素 L 标记，确定其 2x2 框中缺失角的位置。缺失角到网格外角的映射：左上缺失 → 网格左上角；右上缺失 → 网格右上角；左下缺失 → 网格左下角；右下缺失 → 网格右下角。
2. 清空网格为黑(0)。
3. 设 H = (网格边长 + 1) / 2。对每个标记，在其对应外角绘制一个角 L：两条臂各长 H 像素、宽 1 像素，从角点沿两边延伸，在角点处交汇。
4. 计算该角 L 的边界框（HxH 正方形，位于网格角落）。在此边界框内对每个像素做角色分类：位于边界框四角的像素 → 橙(7)；位于边界框边缘（非四角）的像素 → 灰(5)；位于边界框严格内部的像素 → 栗(9)。
5. 将角 L 臂的像素用该标记的原始颜色（红/绿/蓝）覆写，替代步骤 4 中的角色颜色。
6. 若多个标记的边界框存在重叠区域，按固定空间顺序处理：先左上角、再右上角、再左下角、最后右下角。后处理的角色颜色和 L 臂颜色覆写先处理的。

**关键洞察**：微小的 L 标记同时编码两层信息——它的朝向决定大型几何结构的位置（哪个角），它的颜色决定 L 臂的最终颜色（覆写角色颜色）。角色着色（橙/灰/栗）的映射规则在标记本身中不可见，只有在扩展后的大矩形中才显现，需要对比不同尺寸网格的示例来确认角色颜色与位置（角/边/内部）的对应关系。

## 新题 9：轨迹定向射线擦除与拓扑裂变重涂色

**组合逻辑**：[射线延伸/反向投射](已有原语) + [擦除/首个障碍](已有原语) → [计数/连通分量](创新：擦除导致对象拓扑裂变后重新计数) → [重涂色/像素数映射颜色](创新：按裂变后的组件尺寸着色)

**来源原语**：射线延伸/反向投射/轨迹/擦除/首个障碍/标记像素(9f8de559)、计数/连通分量(aaecdb9a)、重涂色/像素数映射颜色(6e82a1ae)

**依赖链**：粉色轨迹指示红色标记的来源方向 → 沿反方向射线命中第一个灰色像素并擦除 → 擦除可能将一个 4-连通对象断裂为多个组件 → 所有擦除完成后重新识别灰色组件 → 按组件像素数重涂色。射线定向和命中决定擦除位置，擦除改变拓扑，拓扑决定组件尺寸，尺寸决定颜色——四步紧耦合。

按轨迹反方向射线擦除障碍像素，裂变后的组件按像素数重涂色。

**输入结构**：约 15x15 的黑(0)背景网格。含 2~4 个灰(5)的 4-连通前景对象，每个对象 4~10 像素，形态不限但须为 4-连通。含 2~3 个红(2)单像素标记，每个标记旁有恰好 3 个品红(6)像素沿某方向（水平/垂直/45 度对角之一）形成直线轨迹，轨迹从标记向外延伸。生成约束：每个红标记沿轨迹反方向的射线上恰好命中一个灰(5)像素作为第一个非背景障碍；每条射线命中不同的灰像素；至少一次擦除导致某灰对象断裂为两个 4-连通组件；标记和轨迹不遮挡彼此的射线路径。

**规则**：
1. 对每个红(2)标记，确定其品红(6)轨迹的方向（从标记到最近品红像素的 8-连通方向向量）。
2. 从红标记出发，沿轨迹的正反方向（即方向向量取反）逐格前进，找到第一个非背景像素（必为灰(5)）。
3. 将该灰像素擦除为黑(0)。红标记和品红轨迹保留不变。
4. 所有标记的射线擦除全部执行完毕后，识别网格上所有 4-连通灰(5)组件，统计每个组件的像素数 S。
5. 按 S 重涂色：S = 1 或 2 → 绿(3)；S = 3 或 4 → 蓝(1)；S >= 5 → 黄(4)。

**关键洞察**：每条射线精确移除一个像素，但因被移除的像素可能是对象的拓扑关节点（articulation point），该移除能将一个对象断裂为多个独立组件。最终颜色取决于断裂后的组件尺寸而非原始对象尺寸，因此射线的命中位置间接但决定性地影响着色结果。像素数到颜色的映射阈值需要从多个示例中归纳。

## 新题 10：遮挡恢复模板驱动缩放补全

**组合逻辑**：[旋转/半周旋转恢复](已有原语，用于恢复遮挡) → [补全/缩放/对齐匹配](创新：恢复出的图块成为模板，用于异处的缩放补全) + [指示区域](创新：指示像素同时编码缩放比和对齐锚点)

**来源原语**：遮挡块/旋转/旋转对称图案/半周旋转恢复/裁剪(ff805c23)、补全/缩放/指示区域/对齐匹配/模板/指示色定缩放对位/精灵体(57aa92db)

**依赖链**：蓝色遮挡块覆盖旋转对称图案的一部分 → 180 度旋转恢复被遮挡区域得到模板 T → 网格他处有若干不完整的小对象，每个含红色指示像素 → 指示像素的间距编码缩放因子 → 将 T 按该因子缩放后与指示像素对齐 → 粘贴缩放模板补全不完整对象。遮挡恢复和缩放补全共享同一份几何内容（模板 T），前者不解决则后者无从进行。

恢复蓝色遮挡下的隐藏图块作为模板，按指示像素编码的缩放比补全网格他处的不完整对象。

**输入结构**：约 22x22 的黑(0)背景网格。网格左上区域有一块约 10x10 的多色旋转对称图案（使用绿(3)、黄(4)、灰(5)等颜色，不含蓝和红），其上有一个 4x4 蓝(1)实心遮挡块覆盖图案的某个局部。网格其余区域有 2~3 个不完整小对象，每个由若干红(2)像素和若干其他颜色像素（与模板中将出现的颜色一致）组成。红(2)像素构成的子图案在空间上与模板 T 的某个子区域（按整数因子缩放后）一一对应。非红像素是模板中对应位置的正确颜色，提供部分已知内容。生成约束：每个不完整对象的缩放因子唯一（1x 或 2x）；不完整对象中已有的非红像素与按正确缩放对齐后的模板内容一致（不冲突）；旋转对称图案确实在 180 度旋转下不变；模板 T 非平凡（至少包含 3 种颜色）。

**规则**：
1. 定位蓝(1)遮挡块的边界框 B 及其所在的大型图案区域。
2. 将整个大型图案区域旋转 180 度。从旋转后的图案中提取与 B 位置对应的子区域，得到模板 T。
3. 在大型图案区域中，将蓝(1)遮挡块替换为模板 T。
4. 对大型图案区域外的每个不完整对象：提取其红(2)像素的坐标集合 R。尝试缩放因子 S = 1, 2：将 T 放大 S 倍（最近邻插值），在放大后的 T 中找一个子区域，使得该子区域中与 R 的相对位置匹配的像素位置集合恰好覆盖 R（匹配时忽略颜色，只比对位置拓扑）。选择使匹配成功的 S 和对齐偏移。
5. 将缩放后的 T 按对齐偏移粘贴到不完整对象的位置。模板像素覆写红(2)指示像素和黑(0)背景像素；不完整对象中已有的非红非黑像素保持不变（它们与模板一致）。

**关键洞察**：蓝色遮挡下的内容既是"大图案修复"这一子问题的答案，也是"不完整对象补全"这一子问题的输入。两个子问题通过同一份几何内容（模板 T）桥接，使其不可拆分。红色指示像素在输入中标注对齐锚点而非内容——它们的角色（位置标记 vs 颜色内容）需通过观察它们总是被模板颜色覆写来推断。
