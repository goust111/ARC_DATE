## 新题 1：形状配对对角桥

**组合逻辑**：[形状匹配](创新：配对判据从颜色改为归一化形状) + [连线/对角连接](创新：连接对象由同色矩形改为异色同形精灵体) → 桥色由上方精灵体颜色决定

**来源原语**：形状匹配、归一化形状匹配(2a5f8217)；连线、对角线段、对角偏移、对角补全连接(342ae2ed)

**依赖链**：形状匹配的结果决定了哪些对象成对 → 配对关系决定了对角连线的两端点 → 端点的空间位置决定了连线方向。删除形状匹配则无法确定配对；删除连线则无输出变换。

将不同颜色但形状相同的精灵体配对，在配对的两者之间绘制对角桥线段。

**输入结构**：黑(0)背景网格，约 15x15。网格中散布 6~8 个小型 4-连通单色精灵体（每个 3~7 像素，形状各异——可以是不规则小块、带弯折的条状等），每个精灵体使用一种独立颜色，颜色取自 {红(2)、蓝(1)、绿(3)、黄(4)、橙(7)、青(8)}。形状成对出现：每种归一化形状恰好有两个精灵体实例，但这两个实例颜色不同。任意两个精灵体的包围盒互不重叠且至少间隔 2 个像素。同一形状的两个实例在空间上呈对角偏移关系（一个在另一个的左上方或右上方）。生成约束：保证每对形状匹配精灵体的包围盒对角面的最近角点之间存在不被其他精灵体遮挡的 45 度直线路径。

**规则**：
1. 对每个精灵体提取其包围盒内的像素掩码，作为归一化形状（仅平移归一化，不旋转、不翻转）。
2. 将归一化形状相同的两个精灵体配为一对。每个精灵体恰属一对。
3. 对每一对，确定"上方精灵体"（包围盒顶行行号较小者）和"下方精灵体"。
4. 找到上方精灵体包围盒底边与下方精灵体包围盒顶边之间最近的一对角点（上方取底侧角点，下方取顶侧角点；若上方在左上方则取上方的右下角和下方的左上角，反之取上方的左下角和下方的右上角）。
5. 在这两个角点之间沿 45 度方向逐像素绘制对角线段，不含两端点本身（端点已被精灵体占据）。线段颜色为上方精灵体的颜色。
6. 原有精灵体像素保持不变。

**关键洞察**：配对依据是归一化形状而非颜色——两个颜色完全不同的精灵体可能被配对，求解者必须跨颜色对比形状才能发现配对规则。

## 新题 2：左对齐涌现连通体重涂色

**组合逻辑**：[滑动/对齐](已有) → [连通检测](已有) → [重涂色](创新：重涂色条件由对齐后涌现的连通性决定)

**来源原语**：滑动、对齐、色段、同行排列、边界对齐(984d8a3e)；连通检测、单色连通体(2753e76c)；重涂色(d90796e8, 0d3d703e)

**依赖链**：对齐改变了色段的水平位置 → 新的位置关系使得原本不相邻的同色段产生垂直接触 → 接触形成的连通体大小决定是否重涂色。三步中任一步被跳过都会导致错误输出。

将每行的色段左对齐后，检测由此涌现的纵向同色连通体，多行连通体被重涂为新颜色。

**输入结构**：黑(0)背景网格，约 12x14（12 行 14 列）。每行恰好包含一段连续的单色水平色段（长度 3~8 像素不等），色段颜色取自 {红(2)、蓝(1)、绿(3)}，各行色段的水平起始位置不同（起始列在 0~6 范围内随机分布）。同一颜色可能出现在多行但不一定相邻。生成约束：对齐到列 0 后，至少存在两组由 2 行以上相邻同色段形成的 4-连通体，且至少有一组在对齐前并不 4-连通（因水平偏移导致列范围不重叠）。

**规则**：
1. 将每行的色段整体水平平移，使其左端对齐到列 0。行内色段长度和颜色不变，仅改变水平位置。
2. 在对齐后的网格中，对每种非背景颜色做 4-连通分量检测。
3. 若某连通分量覆盖 2 行或以上（即至少包含两个不同行中的像素），则将该连通分量的所有像素重涂为黄(4)。
4. 仅覆盖单行的连通分量（孤立色段）保留其原始颜色不变。
5. 未被色段覆盖的像素保持黑(0)。

**关键洞察**：对齐操作本身不改变颜色，但改变了空间邻接关系——原本因水平偏移而不接触的同色段在对齐后发生纵向接触，形成新的连通体。这种"涌现连通性"是对齐与连通检测耦合的核心。

## 新题 3：逐色自身镜像不对称标记

**组合逻辑**：[镜像/逐色独立变换](已有) + [逐像素比较](创新：比较对象从两个面板变为同一掩码的原始与镜像版本) → [差异标记](创新：方向性标记，区分上半多余和下半多余)

**来源原语**：镜像、单色掩码、包围盒、逐色独立变换、包围盒内翻转(e74e1818)；逐像素比较、差异标记、异或差异判定(34b99a2b)

**依赖链**：镜像变换生成参照基线 → 原始与镜像的逐像素比较产生三种状态（对称/上多余/下多余） → 每种状态映射到不同颜色。镜像定义了对称基准，若无镜像则无法判断"什么是对称的"；比较产出方向性差异，若无比较则输出仅为镜像结果（与参考题 e74e1818 相同）。

对每种前景色的掩码独立执行包围盒内垂直镜像，然后与原始掩码比较，输出一张不对称地图：对称部分保留原色，不对称部分按方向标记。

**输入结构**：黑(0)背景网格，约 12x12。包含 2~3 组前景色掩码，颜色取自 {红(2)、蓝(1)、绿(3)}。每组掩码由同色像素构成（可以 4-连通也可以分为多个连通体，但同色像素作为一个整体处理），每组约 8~15 个像素，散布在一个约 4x4 到 6x6 的包围盒内。各色掩码的包围盒互不重叠。每组掩码必须存在垂直不对称性（上下翻转后与原始不完全一致），即非完美垂直对称。生成约束：每组掩码至少有 2 个像素属于"对称部分"（原始与镜像重叠）、至少有 1 个像素属于"上半多余"（原始有镜像无）、至少有 1 个像素属于"下半多余"（镜像有原始无）。

**规则**：
1. 对每种非背景颜色 C，找到该颜色所有像素的包围盒（顶行 r0，底行 r1）。
2. 在包围盒内计算 C 的垂直镜像掩码：原始掩码中位于 (r, c) 的 C 像素，在镜像掩码中映射到 (r0 + r1 - r, c)。
3. 逐像素比较原始掩码与镜像掩码（仅在该色包围盒范围内）：
   - 位置同时在原始和镜像中有 C → 输出保持颜色 C（对称像素）。
   - 位置仅在原始中有 C、镜像中无 → 输出该位置为橙(7)（上半多余标记）。
   - 位置仅在镜像中有 C、原始中无 → 输出该位置为青(8)（下半多余标记）。
   - 位置在原始和镜像中都无 C → 保持黑(0)。
4. 所有颜色的包围盒之外的像素保持黑(0)。

**关键洞察**：输出不是简单的镜像结果，而是原始与镜像之间的"不对称地图"。对称部分保留原色证明对称性存在；橙(7)和青(8)的方向性标记揭示了不对称的具体位置和方向。求解者需要同时理解逐色包围盒镜像和方向性比较两个机制。

## 新题 4：对象计数排名填充空腔

**组合逻辑**：[连通检测 + 计数](已有) → [排序](已有) → [嵌入填充](创新：填充颜色不由尺寸匹配决定，而由计数排名与面积排名的对应关系决定)

**来源原语**：连通检测、计数、排序、按数量降序(2753e76c)；嵌入填充、矩形空腔、模板框架、尺寸匹配(5dbc8537)；面积比较(91714a58)

**依赖链**：连通检测确定各色对象数量 → 数量排名生成颜色优先级序列 → 空腔面积排名生成空间优先级序列 → 两个序列按位对应决定每个空腔的填充颜色。跳过计数则无法确定颜色排名；跳过面积比较则无法确定空腔排名；跳过填充则无输出变化。

统计框架外各色对象的数量，按数量排名与框架内各空腔的面积排名一一对应，以此决定每个空腔的填充颜色。

**输入结构**：黑(0)背景网格，约 16x16。网格中有一个灰(5)像素构成的单像素厚矩形框架（约 8x8 到 10x10），框架内部包含 3~4 个矩形空腔（即框架内部被灰(5)分隔线分割出的矩形区域，各空腔面积互不相同，面积范围约 4~20 像素）。框架外部散布着若干小型 4-连通单色对象（每个 2~5 像素），颜色取自 {红(2)、蓝(1)、绿(3)、黄(4)}。生成约束：使用的颜色种数等于空腔数量（3~4 种）；每种颜色的对象数量互不相同；各色对象分散在框架外部各处，互不接触。

**规则**：
1. 在框架外部，对每种非背景、非灰色的颜色做 4-连通分量检测，统计该颜色的对象数量。
2. 将颜色按对象数量从多到少排列，得到颜色排名序列（对象最多的排名第 1）。
3. 将框架内的空腔按面积从大到小排列，得到空腔排名序列（面积最大的排名第 1）。
4. 排名第 k 的颜色填入排名第 k 的空腔：用该颜色填充该空腔内部所有非灰像素。
5. 输出仅包含框架及其内部区域（裁剪到框架包围盒）。框架外的所有对象不出现在输出中。

**关键洞察**：颜色到空腔的映射不基于任何直接的空间关系或尺寸匹配，而是基于两个独立排名的"拉链式"对应——对象数量最多的颜色填入面积最大的空腔。求解者需要在多个示例中验证这一排名对应规则，因为仅凭单个示例可能将映射误归为其他关系（如颜色距离空腔的远近）。

## 新题 5：计数驱动的循环颜色置换

**组合逻辑**：[连通检测 + 计数](已有) → [排序](创新：排序结果动态定义置换映射) → [重涂色/颜色置换](创新：置换不是固定映射，而是由对象计数排名决定的输入相关循环置换)

**来源原语**：连通检测、计数、单色连通体(2753e76c)；排序(2753e76c)；重涂色、固定颜色置换映射(0d3d703e)

**依赖链**：连通检测给出各色对象数量 → 数量排序确定颜色的循环顺序 → 循环置换应用于全局像素。置换映射依赖于计数结果，因此不同输入（不同计数排列）产生不同的置换——删除计数步则置换无法确定；删除置换步则计数结果无用。

统计各色对象数量，按数量升序排列后定义一个循环颜色置换，将该置换应用于全局每个像素。

**输入结构**：黑(0)背景网格，约 10x10。网格中包含恰好 3 种前景色的 4-连通对象，颜色取自 {红(2)、蓝(1)、绿(3)、黄(4)、橙(7)} 中的任意 3 种。每种颜色有 1~5 个独立对象，每个对象由 2~5 个像素构成，形状各异（不规则小块）。生成约束：三种颜色的对象数量两两不同；各对象互不接触且不贴边。

**规则**：
1. 对每种非背景色做 4-连通分量检测，统计该颜色的对象数量。
2. 将三种颜色按对象数量升序排列：数量最少的记为 c1，中间的记为 c2，最多的记为 c3。
3. 定义循环置换：c1 → c2，c2 → c3，c3 → c1。
4. 将网格中每个前景像素的颜色按此置换替换。背景黑(0)不变。
5. 对象的位置和形状完全不变，仅颜色发生变化。

**关键洞察**：颜色置换不是固定的（不同于参考题 0d3d703e 中的硬编码颜色对换），而是由当前输入中各色对象的数量排名动态决定的。不同示例中，若各色的对象数量排名不同，则置换映射也不同。求解者必须对比多个示例才能发现"按数量排序定义循环"这一隐蔽规则。

## 新题 6：带反弹的对角连接器

**组合逻辑**：[连线/对角连接](已有) + [射线延伸 + 反弹](创新：对角连接不再是直线，而是可被墙壁反弹的折线路径) → [碰撞停止](创新：到达目标矩形或离开网格时停止)

**来源原语**：连线、同色矩形对、对角线段、对角偏移、对角补全连接(342ae2ed)；射线延伸、反弹、墙壁像素、颜色继承、碰撞停止(142ca369)

**依赖链**：同色矩形对确定连接的起止点 → 对角射线从起点发出 → 墙壁像素的位置决定反弹点和方向变化 → 反弹后的路径是否到达目标矩形决定连线是否保留。墙壁移除了直线连接的可能性，迫使路径经过反弹；若无墙壁则退化为普通对角连接（参考题 342ae2ed）；若无同色配对则射线无目标。

同色矩形对之间通过对角射线连接，射线遇到墙壁像素时发生反弹，只有成功到达目标矩形的路径才被保留。

**输入结构**：黑(0)背景网格，约 14x14。包含 2~3 对同色小矩形（每个矩形为 1x2 或 2x1 的单色块），每对使用不同颜色，取自 {红(2)、蓝(1)、绿(3)}。同一对的两个矩形呈对角偏移关系。网格中还散布若干灰(5)单像素墙壁。生成约束：每对矩形之间的 45 度直线路径上至少有一个灰色墙壁（保证必须反弹）；经过反弹后的路径能够到达目标矩形（保证至少有一对能成功连接）；不同对的连接路径不交叉。

**规则**：
1. 识别所有同色矩形对（每种前景色恰好出现两个矩形）。
2. 对每对矩形，从"上方矩形"（包围盒顶行较小者）朝"下方矩形"方向的 facing 角点发出一条 45 度对角射线。
3. 射线逐像素前进。遇到灰(5)墙壁像素时反弹：
   - 若射线从侧面接触墙壁（仅水平方向或仅垂直方向上与墙壁相邻），则翻转该方向分量（水平接触翻转水平分量，垂直接触翻转垂直分量）。
   - 若射线正面撞击墙壁（对角方向的下一个像素就是墙壁），则水平和垂直分量同时翻转（原路反弹方向改为垂直反弹：仅翻转垂直分量，使射线绕过墙壁继续前进）。实际处理：优先检查水平翻转是否可行（翻转后下一步不是墙壁或出界），可行则仅翻转水平；否则仅翻转垂直；若两者都不可行则射线停止。
4. 射线到达下方矩形的任一像素时，连接成功：保留整条路径，路径像素着该对矩形的颜色。
5. 射线离开网格边界或步数超过 50 步仍未到达目标，连接失败：不绘制该对的任何路径像素。
6. 处理顺序：按上方矩形包围盒左上角从左到右、从上到下依次处理各对。先处理的路径像素视为障碍物，后续射线遇到它们时也停止。
7. 原有矩形和灰色墙壁像素保持不变。

**关键洞察**：灰色墙壁像素将简单的直线对角连接变成了需要追踪反弹的折线路径问题。求解者不仅要识别同色配对，还要模拟反弹物理来判断连接是否成功。这是对角连接逻辑和射线反弹逻辑的深度融合，而非简单串联。

## 新题 7：噪声象限排除提取

**组合逻辑**：[裁剪 + 四向对称象限提取](已有) + [最大矩形检测](创新：检测目的不是保留最大矩形，而是定位"被污染"的象限) → [擦除](创新：擦除的不是噪声本身，而是包含噪声的象限，输出对角对面的干净象限)

**来源原语**：裁剪、前景面板、象限、四向反射对称、角落象限提取(73182012)；擦除、实心矩形、噪声像素、面积比较、仅保留最大矩形(91714a58)

**依赖链**：四向对称面板提供四个互为镜像的象限 → 最大噪声矩形检测确定哪个象限被污染 → 对角象限规则确定输出哪个象限 → 擦除清除输出象限中的零星噪声。删除对称识别则不知道有象限结构；删除噪声检测则不知道选哪个象限；删除擦除则输出含噪声。

在一个四向对称面板中，找到包含最大噪声矩形的象限，输出其对角对面的象限（清除残余噪声）。

**输入结构**：黑(0)背景网格，约 16x16。网格中央包含一个前景面板（偶数宽、偶数高，约 10x10 到 12x12），面板使用蓝(1)像素构成一个图案。面板的四个象限互为镜像（上左↔上右左右翻转，上左↔下左上下翻转，上左↔下右 180 度旋转）。在面板上叠加了若干红(2)噪声像素：其中一个象限包含一个明显的红(2)实心矩形块（至少 2x2），其他象限可能有零星的单个红(2)噪声像素（0~2 个）。生成约束：含最大红色矩形的象限唯一确定（不存在两个象限有相同面积的红色矩形）；对角象限中的零星噪声不影响前景图案的可辨认性。

**规则**：
1. 裁剪到前景面板的包围盒（包含所有蓝(1)像素和所有红(2)像素的最小矩形）。
2. 将裁剪后的面板分为四个象限（上左、上右、下左、下右，各占面板的四分之一）。
3. 在每个象限中搜索最大的红(2)实心矩形（所有像素均为红(2)的轴对齐矩形，面积 = 宽 x 高）。
4. 选中包含最大红色矩形的象限为"污染象限"。
5. 输出为污染象限的对角对面象限（上左↔下右，上右↔下左）。
6. 在输出的象限中，将所有红(2)像素替换为黑(0)（清除残余噪声），保留蓝(1)前景像素不变。

**关键洞察**：四个象限内容相同（互为镜像），因此选择哪个象限输出本质上无差异——差异在于噪声的分布。最大噪声矩形的检测不是为了保留它（与参考题 91714a58 相反），而是为了排除它所在的象限。求解者必须理解"找最脏的、取对角的"这一间接选择规则。

## 新题 8：螺旋遮挡下的瓦片恢复

**组合逻辑**：[螺旋绘制](创新：螺旋不是输出而是遮挡掩码的几何定义) + [平铺 + 补全](创新：补全的遮挡区域形状由螺旋几何决定，而非任意矩形) → 约束满足结构：螺旋假设与瓦片假设须同时成立

**来源原语**：螺旋绘制、正方形画布、路径、旋转方向、碰撞转向(28e73c20)；平铺、补全、重复瓦片、遮挡区域、可见像素约束推断(ca8f78db)

**依赖链**：螺旋路径定义了哪些像素被遮挡（设为黑色） → 仅非遮挡像素可用于推断瓦片 → 推断出的瓦片反过来填充螺旋路径位置。这不是线性流水线——求解者需要同时确认"黑色像素是螺旋路径"和"非黑像素构成周期瓦片"两个假设，两者相互约束。

一个周期性瓦片图案被沿顺时针螺旋路径擦除（设为黑色），求解者需识别螺旋遮挡结构并从剩余可见像素推断瓦片以恢复完整图案。

**输入结构**：正方形网格，尺寸约 8x8 到 10x10。底层是一个小型重复瓦片（2x2 或 3x3）在整个网格上的周期平铺，瓦片使用 2~3 种非黑颜色（如红(2)、绿(3)、蓝(1)）。在此平铺之上，从左上角 (0,0) 开始的顺时针螺旋路径上的像素被覆盖为黑(0)。螺旋规则与参考题 28e73c20 相同：从左上角出发向右移动；当下一步将越出网格边界或当前进方向上第二步的位置已为螺旋路径时，顺时针转向；当下一步将进入已为螺旋路径的格子时停止。生成约束：螺旋路径覆盖的像素数不超过网格总像素的 60%，确保剩余可见像素足以唯一确定瓦片图案（每个瓦片位置至少有一个可见实例）。

**规则**：
1. 识别网格中所有黑(0)像素构成顺时针螺旋路径（从左上角出发，遵循碰撞转向规则）。这些黑色像素是遮挡，不是瓦片图案的一部分。
2. 将螺旋路径上的像素标记为"未知"。
3. 从剩余的非螺旋像素中，推断最小的矩形重复瓦片周期（水平周期 pw、垂直周期 ph），使得所有可见像素满足：pixel(r, c) = tile(r mod ph, c mod pw)。
4. 用推断出的瓦片填充所有"未知"位置：unknown(r, c) ← tile(r mod ph, c mod pw)。
5. 输出为完整恢复的瓦片平铺网格，不含任何黑色遮挡。

**关键洞察**：黑色像素不是随机分布的矩形遮挡（与参考题 ca8f78db 不同），而是具有精确几何结构的螺旋路径。求解者必须同时识别两层结构——螺旋的遮挡几何和底层的瓦片周期——两者形成约束满足关系：只有正确识别螺旋才能正确分离遮挡与瓦片，只有正确推断瓦片才能验证螺旋假设。
