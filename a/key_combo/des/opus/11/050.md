## 新题 1：封闭区域面积排名染色

**组合逻辑**：[洪泛填充](识别封闭区域) + [计数](统计各区域面积) + [重涂色](创新：面积排名决定填充颜色，映射关系需从示例归纳)

**来源原语**：洪泛填充/封闭区域/内外分区(7b6016b9), 计数/频率排序(9af7a82c), 重涂色(多题共有)

**依赖链**：洪泛填充的结果决定了有哪些区域可供计数；计数得到面积排名后，排名值决定了重涂色的颜色选择——三步之间有信息变换而非简单传递，因为颜色映射规则（第几名对应什么颜色）是隐含的，必须从多个示例中归纳。

将线条对象围成的封闭区域按面积从大到小排序，依据排名填充不同颜色；外部区域保持背景色不变。

**输入结构**：约 15x15 黑(0)背景网格。一个由橙(7)像素构成的 4-连通线条对象作为"墙"，该线条分支弯折形成 3~5 个互不相通的封闭背景区域（各区域面积互不相等，范围 3~20 像素）。线条本身不形成闭合环但与画布边界配合围成封闭空间。不同示例中线条形态各异（直线、折线、T 形分支等），但始终满足：封闭区域数量为 3~5 个且面积互不相同。

**规则**：
1. 从网格四边边界出发进行黑(0)像素的 4-连通洪泛填充，标记所有与边界连通的黑色像素为"外部"。
2. 剩余未标记的黑色像素按 4-连通性分为若干独立区域，每个区域记录其像素数（面积）。
3. 将所有封闭区域按面积从大到小排序。面积最大的区域填充红(2)，第二大填充蓝(1)，第三大填充绿(3)，第四大填充黄(4)，第五大填充灰(5)。
4. 橙(7)线条像素保持不变，外部区域保持黑(0)。

**关键洞察**：面积排名到颜色的映射（大→红、次大→蓝...）无法从单个示例中确定具体对应关系，必须对比多个示例（观察不同面积大小的区域被赋予了哪种颜色）才能归纳出固定的排名-颜色映射表。

## 新题 2：镜像合并后的新生封闭区域检测

**组合逻辑**：[方向指示](标记像素决定镜像轴) → [镜像] → [逻辑或合并](原图与镜像图叠加) → [洪泛填充](创新：检测合并后新产生的封闭区域) → [填充]

**来源原语**：镜像/方向指示/标记像素(760b3cac), 逻辑或合并(195ba7dc), 洪泛填充/封闭区域/内外分区(7b6016b9), 填充(e760a62e)

**依赖链**：标记像素位置决定镜像轴方向→镜像结果取决于轴的选择→OR合并的形态取决于原图和镜像的具体叠加→新产生的封闭区域完全由合并形态决定（原图单独或镜像单独都不构成该封闭）。任何一环改变都使最终结果不同。

根据标记像素确定镜像轴，将精灵体镜像后与原始精灵体叠加合并，然后检测合并形态新产生的封闭区域并填充特定颜色。

**输入结构**：约 13x13 黑(0)背景网格。一个由蓝(1)像素构成的 4-连通不规则精灵体（8~15 像素），形态不对称（使得镜像后与原图不完全重合）。精灵体大致位于网格中心偏一侧。网格某角落有一个红(2)标记像素：若标记在左侧两角之一，表示以精灵体边界框的垂直中轴为镜像轴；若标记在右侧两角之一，表示以精灵体边界框的水平中轴为镜像轴。生成约束：确保按指定轴镜像并 OR 合并后，至少产生 1 个新的封闭黑色区域（该区域在原图和镜像图中单独看时均不是封闭的）。

**规则**：
1. 读取红(2)标记像素位置：若其列坐标 <= 网格宽度/2 则镜像轴为精灵体边界框的垂直中轴线，否则为水平中轴线。
2. 以该轴为中心镜像翻转所有蓝(1)像素，得到镜像副本。
3. 将原始蓝(1)像素与镜像副本进行 OR 合并（任一位置有蓝像素则结果为蓝）。
4. 在合并后的网格上，从四边边界进行黑(0)像素的 4-连通洪泛填充标记外部。
5. 剩余未标记的黑色像素区域即为封闭区域，全部填充为绿(3)。
6. 合并后的蓝(1)像素保持不变，外部保持黑(0)。红(2)标记像素在输出中擦除为黑(0)。

**关键洞察**：关键非显然规则在于封闭区域不是原图已有的——它是由原图和镜像图的"墙壁"共同围合出来的新区域，求解者必须先正确执行镜像合并才能发现哪些位置变成了新的封闭空间。

## 新题 3：列掩码约束下的周期生长与跨色碰撞

**组合逻辑**：[掩码映射](首行掩码定义有效列) + [种子周期生长](创新：生长仅在有效列内发生) + [跨色重叠变色](碰撞点变色)

**来源原语**：首行掩码/掩码映射/前景列涂新色(7e4d4f7c), 种子周期生长/孤立像素/对角偏移(3ac3eb23), 跨色重叠变色/周期性步长(58e15b12)

**依赖链**：首行掩码划定有效列集合→种子的周期对角生长路径若进入无效列则被截断→不同颜色种子的有效生长轨迹可能在同一有效列内相遇→相遇点变色为品红(6)。掩码改变了生长的空间可达性，进而改变了哪些碰撞会实际发生。

根据首行掩码确定哪些列允许生长，种子按周期对角模式向下扩展但仅在有效列内生效，不同色种子的轨迹交汇处变为品红。

**输入结构**：约 15x20（宽x高）黑(0)背景网格。第 0 行为灰(5)与黑(0)交替的掩码行——灰(5)位置表示该列为"有效列"。第 2~4 行散布 2~3 个不同颜色的孤立像素（可选颜色：蓝(1)、红(2)、绿(3)），它们之间水平间距 >= 3 列。各种子所在列必须是有效列。生成约束：至少存在一对不同色种子，其对角周期生长轨迹在某有效列内会相交。

**规则**：
1. 识别第 0 行中灰(5)像素所在的列集合 V（有效列）。
2. 对每个种子像素（非黑、非灰的孤立像素），生成 period-2 对角生长模式：从种子位置 (r,c) 出发，每隔 2 行在 (r+2k, c-k) 和 (r+2k, c+k)（k=1,2,3...）各放置一个同色像素，但仅当目标列属于 V 时才实际放置；超出网格范围的忽略。
3. 所有种子独立生成各自的轨迹像素集合后，逐像素检查：若某位置被两个或以上不同颜色的轨迹覆盖，则该像素设为品红(6)。
4. 仅被单色轨迹覆盖的像素保持该色。种子像素本身保留原色（不参与碰撞判定）。首行掩码保留灰(5)。

**关键洞察**：掩码行中有效列的分布决定了对角生长的哪些分支能存活——同一种子的左右对角臂可能因为某一侧缺少有效列而被完全截断，导致碰撞模式与无掩码时截然不同。求解者必须同时理解掩码约束和周期生长规则才能预测碰撞位置。

## 新题 4：吸附滑动后从终点发射射线

**组合逻辑**：[滑动](吸附移动到灰色体表面) + [累积影响后续停靠](创新：吸附结果改变后续射线的可达范围) + [射线延伸](从终位向标记方向发射) + [遇前景终止]

**来源原语**：滑动/吸附体/碰撞阻挡/最短基方向吸附/累积影响后续停靠(4093f84a), 射线延伸/遇前景终止(f8be4b64/e9bb6954), 方向指示(760b3cac)

**依赖链**：彩色像素先滑动贴附到灰色体上→贴附后灰色体体积增大，影响后续像素的停靠位置→所有滑动完成后，每个像素从其终位发射射线→射线遇到任何非背景像素（包括其他已滑动像素和灰色体）时终止。滑动的累积效应改变了射线的长度。

彩色像素先被灰色矩形吸附，累积堆叠后，每个像素从最终位置沿其原始方向标记发射射线直到遇阻。

**输入结构**：约 15x15 黑(0)背景网格。中央偏位一个灰(5)矩形（约 3x3 到 4x4）。矩形四周散布 3~5 个彩色像素（颜色各不相同，选自蓝(1)、红(2)、绿(3)、黄(4)、橙(7)）。每个彩色像素旁边紧邻一个栗(9)方向标记像素，标记位于彩色像素的上/下/左/右之一侧，指示射线发射方向（与彩色像素到灰色体方向无关）。处理顺序：按彩色像素到灰色体边缘的曼哈顿距离从小到大处理；距离相同时按从上到下、从左到右排序。生成约束：所有彩色像素沿最短基方向可以到达灰色体表面而不互相阻挡（初始时各自路径无交叉）。

**规则**：
1. 对每个彩色像素，找到其到灰(5)体（含已贴附像素）表面的最短基方向（上下左右之一）。
2. 按距离从近到远依次处理：将彩色像素沿该方向滑动直到紧贴灰色体表面，然后将该像素视为灰色体的一部分（后续像素的停靠要考虑它）。栗(9)标记像素随之移动保持相对位置。
3. 所有滑动完成后，擦除所有栗(9)标记像素。
4. 对每个彩色像素（现在位于终位），向其原始栗(9)标记所指方向发射同色射线：逐像素延伸，遇到任何非黑(0)像素时终止（终点像素不覆盖），遇到网格边界时终止。
5. 灰(5)矩形在输出中保留原色。

**关键洞察**：射线的长度取决于滑动完成后的整体布局，而非初始布局——因为累积吸附改变了障碍物分布。同一道题中改变处理顺序会得到不同结果，求解者需从示例中确认处理顺序规则（距离优先）。

## 新题 5：网格异常值提取后对齐求交

**组合逻辑**：[异常值选择](逐行提取唯一格) + [对齐](创新：以中位格内图案的质心为参考对齐各提取结果) + [布尔运算](创新：对齐后取 AND 交集)

**来源原语**：异常值选择/逐行比较/网格单元(38007db0), 对齐/中位线为参考(e376de54), 布尔运算/双掩码交集输出(6430c8c4)

**依赖链**：异常值提取决定了参与后续运算的图案集→对齐操作将各图案的非背景像素质心对齐到同一坐标→AND 运算仅保留所有图案共有的像素位置。若异常值提取错误，后续对齐和交集全部错误。

从网格的每行格子中提取异常格图案，将所有提取的图案按质心对齐后取像素交集，输出所有图案共享的公共子结构。

**输入结构**：约 19x19 网格，由青(8)网格线分为 3 行 x 4 列共 12 个 4x4 内部单元格（含网格线总尺寸 19x19）。每行 4 格中有 3 格内含相同的红(2)小图案（3~5 像素的 4-连通形状），1 格含不同的红(2)图案（异常格）。三行的异常格图案彼此不同，但共享部分像素位置（相对于各自质心有 1~3 像素位置重合）。生成约束：三个异常格图案按质心对齐后至少有 1 个像素位置完全重合。

**规则**：
1. 检测青(8)网格线，划分所有内部单元格。
2. 对每行的 4 个单元格，比较其内部红(2)像素构成的图案形状：出现 3 次的为常规格，出现 1 次的为异常格。提取异常格内的红(2)图案（相对于单元格左上角的坐标）。
3. 计算每个提取图案的非背景像素质心（向下取整）。
4. 将所有提取图案平移使质心对齐到同一位置。
5. 对齐后，逐像素取 AND：仅当所有图案在该相对位置都有红(2)像素时，输出该位置为蓝(1)；否则为黑(0)。
6. 输出为最小包围该交集图案的矩形网格，背景为黑(0)。

**关键洞察**：三个异常格图案看似完全不同，但对齐后存在隐藏的公共子结构——这个公共子结构就是输出。求解者必须意识到输出不是任何一个异常格本身，而是所有异常格共享的几何"公因子"。

## 新题 6：符号解码后的频率直方图生成

**组合逻辑**：[符号解码](面板掩码→颜色类型) + [计数](统计各类型出现次数) + [排序](创新：跳过最高频后降序排列) + [柱状图构建](创新：以解码颜色填充列)

**来源原语**：符号解码/符号掩码/面板/符号映射颜色(17cae0c1), 计数/频率排序/频率降序柱状图(9af7a82c), 跳过最高频(f8b3ba0a), 柱状图(9af7a82c)

**依赖链**：符号解码必须正确才能知道各面板代表什么颜色→计数依赖于解码结果→跳过最高频改变了参与排序的颜色集→直方图的列顺序和高度由过滤后的排序结果决定。解码错误导致全盘错误；跳过规则需从示例归纳。

将网格中的符号面板解码为颜色，统计各颜色出现频次，去掉最高频后按频次降序构建彩色直方图。

**输入结构**：约 3x21 网格（3 行高，7 个面板宽）。网格被划分为 7 个相邻的 3x3 面板，每个面板内由黑(0)和灰(5)像素构成一个二值符号掩码。符号编码表（需从训练示例归纳）：每种 3x3 掩码图案对应一种颜色（如"L形掩码"=红(2)、"十字掩码"=蓝(1)、"对角掩码"=绿(3)、"横线掩码"=黄(4)）。7 个面板中某些颜色类型出现多次（如红出现 3 次、蓝出现 2 次、绿 1 次、黄 1 次）。

**规则**：
1. 将输入划分为 3x3 面板，提取每个面板中灰(5)像素的位置构成二值掩码。
2. 用任务符号编码表将每个掩码解码为一种颜色（编码表需从多个训练示例中归纳建立）。
3. 统计每种解码颜色出现的面板数量。
4. 去除出现次数最多的颜色（若最多有并列，全部去除）。
5. 将剩余颜色按出现次数从多到少排列；次数相同时按颜色编号从小到大排列。
6. 构建输出：黑(0)背景，宽度 = 剩余颜色种数，高度 = 最大剩余频次。每列对应一种颜色，从顶部向下填充该颜色像素，填充行数 = 该颜色的出现次数。列顺序 = 排序结果从左到右。

**关键洞察**：双重隐含规则——符号编码表本身是第一个需要归纳的映射（哪种掩码图案代表哪种颜色），跳过最高频是第二个需要发现的规则（为什么输出中少了一种颜色）。两者必须同时正确才能得出正确输出。

## 新题 7：阶梯扩展与分隔行的侧选择染色

**组合逻辑**：[阶梯扩展](竖直条对向外步进) + [较长侧优先](创新：以分隔行为界比较上下扩展面积) + [重涂色](较长侧的扩展轨迹重涂为新色) + [跨色重叠变色]

**来源原语**：阶梯扩展/竖直条对/周期性步长(58e15b12), 较长侧优先/分隔行/边缘线段(770cc55f), 跨色重叠变色(58e15b12), 重涂色(多题共有)

**依赖链**：阶梯扩展确定了每对竖直条在分隔行两侧的完整轨迹→比较两侧面积选出较长侧→较长侧被重涂为黄(4)而较短侧保持原色→跨色重叠（不同原色条对的轨迹交汇处）仍变品红(6)但仅在保持原色的一侧发生（黄色侧的交汇点也变黄不变品红）。侧选择规则改变了碰撞变色的适用范围。

竖直条对向上下阶梯扩展，以分隔行为界比较两侧覆盖面积，面积较大侧统一重涂为黄色，较小侧保持原色且该侧的跨色重叠点变品红。

**输入结构**：约 21x11（高x宽）黑(0)背景网格。正中间有一条全宽红(2)分隔行。分隔行上方和下方各有 2~3 对同色竖直条（每对由两根同色等高短竖线组成，高度 2~3 像素，两根间距 2~4 列）。不同对使用不同颜色（蓝(1)、绿(3)、橙(7)）。各对的竖直条位于分隔行上方或下方不对称的位置（即某对条可能在分隔行上方距离 2 行处，意味着向上扩展空间小、向下扩展空间大）。生成约束：至少有一对不同颜色的竖直条的阶梯扩展轨迹在分隔行的同一侧存在列重叠。

**规则**：
1. 识别红(2)分隔行，将网格分为上半区和下半区。
2. 对每对同色竖直条，执行阶梯扩展：在条所在的原始行区间内保持原列不动；离开原始区间后，每经过条高度整数倍行数，左条左移一列、右条右移一列。向上和向下同时扩展直至网格边界。
3. 对每对条，分别统计其扩展轨迹在上半区和下半区的像素数。像素数较多的一侧为"长侧"，另一侧为"短侧"。
4. 将每对条的长侧轨迹全部重涂为黄(4)。短侧保持原色不变。
5. 在短侧：若某像素位置被两种或以上不同原色的轨迹覆盖，设为品红(6)。
6. 在长侧（已全部为黄色）：不做碰撞变色处理，保持黄(4)。
7. 红(2)分隔行保持不变。

**关键洞察**：较长侧优先规则使得碰撞变色具有不对称性——同一对条的两侧处理逻辑不同。求解者若不发现"长侧统一涂黄且豁免碰撞变色"这一隐含规则，将无法解释为何某些本应变品红的位置仍为黄色。

## 新题 8：杯形方向弹射后射线连线

**组合逻辑**：[弹射](内容像素沿尾刺方向射出) + [像素数守恒](弹射线段长度=内容像素数) + [连线](创新：同色弹射线段端点之间画连接线) + [遇前景终止](创新：连接线遇到其他弹射线段时终止)

**来源原语**：弹射/杯形框架/尾刺/内容像素/尾部朝向决定射出/像素数守恒(3dc255db), 射线延伸/遇前景终止(f8be4b64), 连线/共行或共列(e760a62e)

**依赖链**：杯形框架的尾刺方向决定弹射方向→内容像素数决定弹射线段长度→弹射完成后产生的线段端点位置取决于前两步→同色端点之间的连线需判断是否共行或共列→连线向对方延伸但遇到任何非背景像素（包括其他弹射线段）时终止。弹射结果改变了网格的前景分布，进而改变了连线可达的范围。

从杯形框架中弹射内容像素形成线段，然后在同色弹射线段的末端之间沿共享行或列画连接线，连接线遇阻停止。

**输入结构**：约 17x17 黑(0)背景网格。2~3 个杯形框架（空心框体，各用不同的边框色如灰(5)、青(8)），每个杯有一个尾刺（从杯体延伸出的 1~2 像素突起指示方向）和一个开口方向（与尾刺方向相反）。杯内有 2~4 个同色内容像素（颜色与边框色不同；同色框对应同色内容）。设计中同色内容出现在恰好两个杯中（如两个灰框杯各含蓝(1)内容，一个青框杯含绿(3)内容）。两个同色杯的尾刺方向使得弹射线段的末端恰好在同一行或同一列上。生成约束：同色弹射线段末端共享一行或一列，且之间存在至少一段空白可供连线。

**规则**：
1. 对每个杯形框架，识别其尾刺方向（尾刺所指基方向）。
2. 擦除杯内所有内容像素。
3. 从尾刺尖端向外（沿尾刺方向），画一条长度等于该杯内原内容像素数的同色线段。
4. 杯形框架本身（含尾刺）保留原色。
5. 弹射完成后，对每种内容颜色：若存在两条同色弹射线段，找到它们各自离对方更近的末端像素。
6. 若这两个末端像素共行，从各自末端向对方方向逐像素延伸同色像素，直到遇到任何非黑(0)像素或到达对方末端，不覆盖终点障碍物。若共列同理。若既不共行也不共列则不连线。
7. 连接线使用与弹射线段相同的颜色。

**关键洞察**：弹射线段的长度（由内容像素数决定）间接控制了末端位置，进而决定了连接线是否能画（是否共行/列）以及画多长（中间是否有其他弹射线段阻挡）。整道题的输出形态由杯内像素数、尾刺方向、杯的空间分布三者共同约束。
