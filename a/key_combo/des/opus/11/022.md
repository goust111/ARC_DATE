## 新题 1：折叠探测定印章位

**组合逻辑**：[折叠fold](创新：折叠不作为最终输出而作为中间探测步骤) + [印章覆盖stamp] + [源色决定模板涂色](已有) + [对称互补symmetric_complement](已有，但从判定互补变为定位命中)

**来源原语**：折叠(e3497940)、印章覆盖(b190f7f5)、源色决定模板涂色(b190f7f5)、对称互补(e3497940)、分隔线(e3497940)

**依赖链**：折叠操作确定哪些散点"命中"了模板位置 → 命中位置决定印章目标坐标 → 散点颜色决定印章着色 → 印章在散点原始坐标处展开

用一句话概括：将右侧散点折叠到左侧模板上以发现命中关系，然后在每个命中散点的原始位置印章出以该散点颜色着色的模板副本。

**输入结构**：约 15x31 的网格，背景为黑(0)。中央有一条灰(5)竖直分隔列贯穿全高。左半区(15x15)包含一个由蓝(1)像素组成的4-连通精灵体（约5~8像素，形状不规则，非对称），位于左半区中部。右半区(15x15)包含3~5个散落的单像素前景点，颜色各不相同（从红(2)、绿(3)、黄(4)、品红(6)中取），各点之间至少间隔3格。生成约束：将右半区各点水平镜像到左半区坐标后，其中至少2个点落在蓝色精灵体的像素上（"命中"），至少1个点不落在精灵体上（"未命中"）。

**规则**：
1. 将右半区水平镜像（以分隔列为轴），叠加到左半区坐标系。
2. 检查每个镜像后的散点是否落在蓝色精灵体的像素位置上。
3. 对每个"命中"的散点：以其在右半区的原始坐标为锚点（锚点对应精灵体中该像素的局部偏移），将蓝色精灵体的完整形状以该散点的颜色印章到输出网格中。
4. "未命中"散点不产生任何输出。
5. 分隔列和左半区不出现在输出中；输出尺寸为15x15（即右半区大小），背景为黑(0)。
6. 多个印章重叠时，按散点在右半区中从上到下、从左到右的顺序绘制，后绘制覆盖先绘制。

**关键洞察**：折叠不是最终变换，而是一个探测机制——它揭示哪些散点与模板有空间对应关系；真正的输出变换（印章）发生在折叠之前的坐标空间中。

## 新题 2：对齐后间隙奇偶着色

**组合逻辑**：[对齐align](已有) + [共享归一掩码shared_norm_mask](已有) + [间隙区域涂色gap_region_recolor](创新：间隙填充色由间隙宽度奇偶性和相邻体颜色共同决定) + [奇偶性parity](创新：从边长奇偶变为间距奇偶)

**来源原语**：对齐(e41c6fd3)、共享归一掩码(e41c6fd3)、间隙区域涂色(d6ad076f)、奇偶性(22806e14)、两体之间(d6ad076f)、锚点像素(e41c6fd3)

**依赖链**：锚点精灵确定对齐基准行 → 所有精灵垂直对齐改变相对位置 → 对齐后的水平间距决定间隙宽度 → 间隙宽度的奇偶性决定取左邻色还是右邻色填充

用一句话概括：将共享形状的彩色精灵垂直对齐到锚点精灵的顶行后，用相邻精灵的颜色填充它们之间的矩形间隙，填充色由间隙宽度的奇偶性选择左邻或右邻。

**输入结构**：约 12x25 的网格，背景为黑(0)。网格中有4~6个4-连通精灵体，均具有相同的归一化掩码（约4~6像素的不规则形状），各自颜色不同（从蓝(1)、红(2)、绿(3)、黄(4)、品红(6)、橙(7)中取）。其中一个为青(8)色，作为垂直对齐锚点。各精灵水平方向互不重叠（列范围不交叉），垂直方向各自随机偏移（顶行不同）。生成约束：对齐后任意相邻精灵对之间的水平间隙宽度至少为1列、至多为6列；相邻对中至少有一对间隙为奇数宽、至少有一对为偶数宽。

**规则**：
1. 识别青(8)色精灵为锚点，记录其顶行位置 R。
2. 将所有精灵（含锚点）保持原始列位置不变，垂直平移使其顶行均为 R。
3. 按列位置从左到右对精灵排序。对每对相邻精灵，计算它们边界框之间的水平间隙宽度 W（间隙 = 左精灵边界框右边界 +1 到右精灵边界框左边界 -1 之间的列数）。
4. 填充间隙区域：填充范围为行 R 到行 R + 精灵高度 -1、列为间隙列。如果 W 为奇数，填充色取左邻精灵的颜色；如果 W 为偶数，填充色取右邻精灵的颜色。
5. 输出网格尺寸与输入相同，背景为黑(0)，包含对齐后的精灵及填充后的间隙。

**关键洞察**：对齐操作改变了精灵间的相对水平距离（因为边界框宽度不变但列位置固定），间隙宽度在对齐前后不变——但仅在对齐后间隙才形成规整矩形区域可供填充；奇偶判断的对象是空间距离而非对象属性。

## 新题 3：嵌套框深度决定合成遮挡序

**组合逻辑**：[包含containment](已有) + [空心矩形hollow_rectangle](已有) + [透明叠加transparent_overlay](已有) + [前后遮挡front_back_occlusion](创新：嵌套层级即深度层级，而非面板顺序) + [裁剪crop](已有，最终提取最内框内部)

**来源原语**：空心矩形(1c786137)、包含(1c786137)、透明叠加(cf98881b)、前后遮挡(cf98881b)、裁剪(1c786137)、内部区域(1c786137)

**依赖链**：识别嵌套包含关系 → 嵌套深度建立遮挡优先级 → 各框内部图案按深度合成 → 裁剪到最内框尺寸输出

用一句话概括：多层嵌套的彩色空心矩形各自内部含有稀疏图案，按由内到外的嵌套层级作为前后遮挡顺序合成所有图案，输出为最内框内部尺寸的合成结果。

**输入结构**：约 20x20 的网格，背景为黑(0)。网格中有3层嵌套的单像素厚空心矩形框：最外框颜色为灰(5)，中间框颜色为红(2)，最内框颜色为蓝(1)。每层框严格包含在外层框内部，各框之间有至少1像素的间距。每层框的内部区域（框线内侧的矩形空间）包含若干稀疏前景像素（颜色为该框自身颜色），像素数量在2~5个之间，排布不规则。各层内部图案在坐标上可能重叠（当映射到同一参考系时）。生成约束：至少有2个坐标位置在不同层的内部图案中都有前景像素（构成实际遮挡冲突）。

**规则**：
1. 识别所有单像素厚的闭合矩形框，按包含关系确定嵌套层级（最外层深度=1，向内递增）。
2. 将每层框的内部图案（非框线、非背景的像素）提取出来，记录其相对于该框内部左上角的局部坐标。
3. 创建输出网格，尺寸等于最内框的内部区域大小，初始化为黑(0)。
4. 按深度从浅到深（外到内）的顺序，将各层内部图案映射到输出网格：各层图案的局部坐标需等比缩放到输出网格尺寸（取整到最近像素，向下取整）。
5. 后绘制的层（深度更大 = 更内层）覆盖先绘制的层。最内层图案始终可见。
6. 框线本身不出现在输出中。

**关键洞察**：嵌套的空间包含关系本身编码了合成的遮挡优先级——无需额外的顺序标记，几何拓扑即为渲染指令；且各层内部坐标需归一化到统一尺寸才能比较遮挡关系。

## 新题 4：面板像素计数决定角色分配

**组合逻辑**：[计数count](创新：计数结果用于决定面板角色而非位移) + [分隔列separator_column](已有) + [印章覆盖stamp](已有) + [源色决定模板涂色](已有) + [色彩面板color_panel](已有)

**来源原语**：计数(8e301a54)、分隔列(cf98881b)、色彩面板(cf98881b)、印章覆盖(b190f7f5)、源色决定模板涂色(b190f7f5)、分块对应(b190f7f5)

**依赖链**：三面板前景像素计数比较 → 计数排名决定"形状源/位置源/颜色源"角色 → 形状源提供精灵掩码 → 位置源的前景像素坐标提供印章位置 → 颜色源的主色提供印章颜色

用一句话概括：三个被分隔列隔开的面板各含不同前景图案，按前景像素数量多少分配"形状/位置/颜色"三种角色，然后将形状面板的掩码以颜色面板的色调印章到位置面板各前景点处。

**输入结构**：约 9x29 的网格，背景为黑(0)。两条橙(7)色竖直分隔列将网格分为三个等宽(9x9)面板。每个面板包含一种非黑非橙的前景色像素：一个面板内有一个4-连通不规则精灵体（5~8像素），一个面板内有3~4个分散的单像素点，一个面板内有一个紧凑的2x2或3x1色块（3~4像素）。三个面板的前景颜色互不相同（从蓝(1)、红(2)、绿(3)、黄(4)、品红(6)中取三种）。生成约束：三个面板的前景像素数必须互不相等（确保排名无歧义）。

**规则**：
1. 以橙(7)色分隔列为界分离三个面板。统计每个面板的非背景非分隔色像素总数。
2. 角色分配：像素数最多的面板为"形状源"（提供精灵掩码）；像素数最少的面板为"位置源"（其每个前景像素坐标为印章锚点）；像素数居中的面板为"颜色源"（其前景色为印章着色）。
3. 提取形状源面板中前景像素的归一化掩码（相对于其边界框左上角的偏移集合）。
4. 输出网格尺寸为9x9（单面板大小），初始化为黑(0)。
5. 对位置源面板中的每个前景像素位置（转换为面板内局部坐标），以该坐标为掩码左上角锚点，用颜色源的前景色绘制形状源的掩码。
6. 超出9x9输出范围的像素裁剪丢弃。多次印章重叠区域颜色相同（都是颜色源的色），无冲突。

**关键洞察**：面板内容的统计属性（像素计数排名）决定了各面板在变换中的功能角色——同样三个面板，若像素数量关系改变则角色互换，输出完全不同。这是一种隐式编码：几何统计量编码了处理指令。

## 新题 5：对象自生成网格线与位置决定膨缩

**组合逻辑**：[网格线绘制grid_line_drawing](创新：网格线位置由对象中心推导而非固定间隔) + [收缩shrink](已有) + [膨胀dilate](已有) + [行列索引奇偶性row_column_index_parity](创新：从像素索引变为格子索引) + [颜色决定操作color_det_operation](创新：位置决定操作)

**来源原语**：网格线绘制(332efdb3)、收缩(d753a70b)、膨胀(d753a70b)、行列索引奇偶性(332efdb3)、颜色决定操作(d753a70b)、连通分量检测(12eac192)

**依赖链**：检测对象边界框中心 → 中心坐标排序生成网格线位置 → 网格线划分出格子 → 格子行列索引奇偶性决定内含对象收缩或膨胀

用一句话概括：以所有对象的边界框中心为锚点绘制网格线将画布分格，然后根据每个对象所在格子的行列索引之和的奇偶性决定该对象收缩一层或膨胀一层。

**输入结构**：约 19x19 的网格，背景为黑(0)。网格中分布着6~9个单色4-连通对象，每个对象为一个实心形状（约6~12像素），颜色统一为红(2)。各对象之间至少间隔3像素（边界框不相交且不相邻）。生成约束：对象的边界框中心行坐标去重后恰好有3个不同值，中心列坐标去重后恰好有3个不同值（形成3x3的隐式网格布局）；收缩不会使任何对象消失（每个对象至少3像素厚）；膨胀不会使任何对象接触网格线或其他对象。

**规则**：
1. 检测所有非背景4-连通对象，计算每个对象边界框的中心坐标(行,列)。
2. 收集所有中心行坐标去重排序得到 R = [r0, r1, r2]，所有中心列坐标去重排序得到 C = [c0, c1, c2]。
3. 在输出网格中，以行坐标 r0, r1, r2 和列坐标 c0, c1, c2 绘制灰(5)色的完整横线和竖线（各一像素宽，贯穿全网格）。这些线将网格分为4x4区域（含边缘区域），但对象必然落在由相邻中心线围成的格子内。
4. 为每个对象确定其所在格子的索引：格子行索引 = 该对象中心在 R 中的排序位（0,1,2），格子列索引同理。计算行索引+列索引之和。
5. 若和为偶数：该对象收缩一层（剥去外圈一层像素），保持原色。若和为奇数：该对象膨胀一层（沿4-连通方向外扩一层像素），保持原色。
6. 网格线绘制后若与对象像素重叠，网格线覆盖对象（灰色优先）。膨胀后的对象像素若落在网格线上则被网格线覆盖。

**关键洞察**：网格线不是输入中预设的结构，而是从对象自身的几何属性（中心坐标）推导出来的——对象既是被变换的目标，又是定义变换规则（格子划分）的信息源，形成自指结构。

## 新题 6：十字折叠与偶距环过滤

**组合逻辑**：[十字前景foreground_cross](已有) + [交叉点中心intersection_center](已有) + [折叠fold](创新：四象限折叠而非二分折叠) + [透明叠加transparent_overlay](已有) + [偶数切比雪夫距离even_chebyshev_distance](创新：作为过滤条件而非填充规则)

**来源原语**：十字前景(759f3fd3)、交叉点中心(759f3fd3)、折叠(e3497940)、透明叠加(e3497940)、偶数切比雪夫距离(759f3fd3)、擦除(fbf15a0b)

**依赖链**：十字交叉点确定折叠中心和距离参考点 → 四象限镜像折叠到左上象限 → 叠加后得到合成图案 → 以交叉点为中心计算切比雪夫距离 → 仅保留偶数距离位置的像素

用一句话概括：以十字交叉点为中心将四象限镜像折叠叠加到左上象限，然后仅保留距交叉点切比雪夫距离为偶数位置处的合成像素。

**输入结构**：约 15x15 的奇数边长正方网格，背景为黑(0)。一行绿(3)色前景横贯全宽，一列绿(3)色前景纵贯全高，交叉于网格中心(7,7)。四个象限中各分布有2~4个黄(4)色散点（非十字位置），四象限的黄色像素排布不对称（各象限的散点位置不同）。生成约束：四象限折叠叠加后，至少有3个位置存在来自不同象限的重叠（同为黄色，重叠不产生颜色冲突）；折叠合成后，保留偶数距离像素可产生可辨识图案（不是全空）。

**规则**：
1. 定位绿(3)色横行和竖列的交叉点 O = (r0, c0)，即网格中心。
2. 将输入网格划分为以 O 为角点的四个象限（不含十字线本身）：左上、右上、左下、右下。每个象限尺寸为 (r0) x (c0)。
3. 将右上象限水平翻转、左下象限垂直翻转、右下象限旋转180度，分别叠加到左上象限。叠加规则：任一层为黄(4)则结果为黄(4)，全为黑(0)则为黑(0)。
4. 在合成后的左上象限中，对每个像素计算其到位置(0,0)的切比雪夫距离 d = max(row, col)。
5. 保留 d 为偶数位置（d=0,2,4,...）的像素值不变；d 为奇数位置的像素擦除为黑(0)。
6. 输出为该处理后的左上象限网格（尺寸 r0 x c0），不含十字线。

**关键洞察**：十字线同时充当两种角色——它既定义了折叠的轴线（将四象限镜像合并），又定义了距离过滤的原点；折叠聚合了分散信息，距离过滤则从聚合结果中提取规律性子集，两步缺一不可。

## 新题 7：连通体面积驱动菱形环绘制

**组合逻辑**：[连通分量检测connected_component_detection](已有) + [面积决定位移area_determines_displacement](创新：面积决定半径而非位移) + [菱形轮廓diamond_outline](已有) + [填充fill](已有) + [标注中心mark_center](创新：以质心为菱形中心)

**来源原语**：连通分量检测(12eac192)、面积决定位移(8e301a54)、菱形轮廓(d753a70b)、填充(d6ad076f)、标注中心(22806e14)

**依赖链**：检测连通体并计算面积 → 面积值成为曼哈顿菱形半径 → 以对象质心为中心绘制菱形轮廓 → 原对象擦除仅保留菱形

用一句话概括：检测每个前景连通体，以其质心为中心、像素面积为曼哈顿半径绘制该体颜色的菱形轮廓，同时擦除原始对象。

**输入结构**：约 21x21 的网格，背景为黑(0)。网格中有3~4个单色4-连通对象，颜色互不相同（从蓝(1)、红(2)、绿(3)、黄(4)中取），每个对象为紧凑的不规则形状（3~5像素）。各对象之间间隔较大（边界框间距至少8像素）。生成约束：每个对象的像素面积作为菱形半径后，绘制的菱形轮廓不超出网格边界，且不同对象生成的菱形轮廓互不相交；每个对象的质心取整后作为菱形中心（质心 = 所有像素行坐标均值和列坐标均值，四舍五入到整数）。

**规则**：
1. 检测所有非背景4-连通对象，记录每个对象的颜色、像素坐标集合。
2. 对每个对象计算面积 A（像素数）和质心 (cr, cc)（行坐标均值和列坐标均值，四舍五入取整）。
3. 初始化输出为全黑(0)网格。
4. 对每个对象，以 (cr, cc) 为中心、A 为曼哈顿半径，绘制该对象颜色的菱形轮廓：所有满足 |r - cr| + |c - cc| = A 的像素着色为该对象颜色。
5. 原始对象的像素不保留（已被背景覆盖或被菱形像素取代）。
6. 多个菱形绘制无交叉（由生成约束保证），按面积从大到小绘制。

**关键洞察**：对象的紧凑几何属性（面积）被"投射"为一个远大于自身的几何结构（菱形轮廓），对象自身消失而其统计指纹以曼哈顿距离的形式展现——面积与半径的对应需要从多个示例中归纳（不同大小的对象产生不同半径的菱形）。

## 新题 8：瓦片检测与跨尺度匹配定采样因子

**组合逻辑**：[重复瓦片repeated_tile](已有) + [跨尺度同形cross_scale_same_shape](已有) + [形状匹配shape_matching](已有) + [裁剪crop](创新：按采样因子降采样而非直接裁剪) + [轴向复制axial_dup](已有，用于验证瓦片性)

**来源原语**：重复瓦片(7b7f7511)、跨尺度同形(ce602527)、形状匹配(ce602527)、裁剪(7b7f7511)、轴向复制(7b7f7511)、缩放对象(ce602527)

**依赖链**：识别网格为瓦片重复结构 → 提取基础瓦片 → 在边框区域找到瓦片的放大版本 → 放大倍数确定降采样因子 → 对基础瓦片按因子降采样输出

用一句话概括：网格主体为瓦片阵列，边框处有该瓦片的放大版，放大倍数K决定对基础瓦片做KxK降采样（每K行K列取一个像素）得到输出。

**输入结构**：约 20x20 的网格，背景为黑(0)。网格由灰(5)色单像素厚的矩形边框围住。边框内部分为两部分：左上角有一个与边框相连的正方形隔间（尺寸为基础瓦片边长的K倍，K=2或3），其余区域为主体阵列。主体阵列由基础瓦片（正方形，边长3~4）在行和列方向各重复若干次（至少2x2次）拼成。基础瓦片由黑(0)和某前景色（从蓝(1)、红(2)、绿(3)中取）组成的二值图案。左上角隔间内包含该基础瓦片的K倍等比放大版本（每个像素变为KxK块），使用与基础瓦片相同的颜色。隔间与主体阵列之间由灰(5)色线条分隔。生成约束：基础瓦片不是纯色（至少含2个前景像素和2个背景像素）；K值在不同示例中不同（迫使求解者从跨尺度比较推断K）。

**规则**：
1. 识别灰(5)色边框和内部灰色分隔线，将网格分为左上隔间和主体阵列。
2. 在主体阵列中检测重复瓦片：找到最小正方形瓦片使阵列为其整数次复制。
3. 在左上隔间中检测放大图案，与基础瓦片进行跨尺度形状匹配：将隔间内图案每KxK块缩为1像素，验证是否与基础瓦片一致。确定缩放因子 K。
4. 对基础瓦片执行 K 倍降采样：从瓦片的(0,0)位置开始，每隔K行K列取一个像素值，组成输出网格。
5. 输出网格尺寸为 ceil(瓦片边长 / K) x ceil(瓦片边长 / K)。

**关键洞察**：放大版瓦片不是输出的一部分，而是一个"指令"——它通过与基础瓦片的尺度比值编码了降采样率K；求解者必须同时理解瓦片重复结构（发现基础图案）和跨尺度对应（推断K值），两步知识缺一则输出不确定。
