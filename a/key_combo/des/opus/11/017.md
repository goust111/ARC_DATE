## 新题 1：封闭区域内箭头射线

**组合逻辑**：[洪泛填充/区域封闭](识别封闭区域) + [横杆偏移定方向](确定箭头朝向) + [像素数决定长度](区域面积编码射线长度) + [射线延伸](执行延伸)

**来源原语**：洪泛填充/区域封闭(a5313dff), 横杆偏移定方向/箭头精灵(689c358e), 像素数决定长度(c61be7dc), 射线延伸(689c358e)

**依赖链**：封闭区域的边界确定了箭头的归属和面积计算范围；箭头的非对称结构决定射线方向；区域内背景像素数（去掉墙壁和箭头本身的像素后）决定射线长度；射线从箭头尖端出发穿透墙壁向外延伸。

将封闭区域中的箭头向外射出颜色射线，长度由该区域的空余面积决定。

**输入结构**：约 18x18 的黑(0)背景网格。红(2)像素构成一像素宽的封闭墙壁，将网格分割为 2~4 个互不相通的封闭区域（每个区域约 15~40 个背景像素的面积）。每个封闭区域内部恰有一个 6 像素的单色箭头精灵（由长度 4 的主杆和长度 3 的横杆组成，横杆偏向主杆的一端），不同区域的箭头颜色互不相同，从蓝(1)、绿(3)、黄(4)、橙(7)中选取。箭头主杆平行于水平或垂直方向。生成约束：每个箭头的尖端方向上，从箭头到最近的墙壁之间至少有 1 个像素的间隙；各射线的路径互不交叉。

**规则**：
1. 用洪泛填充从网格边界出发标记所有外部背景像素；剩余背景像素按 4-连通分组为封闭区域。
2. 对每个封闭区域，找到其中的箭头精灵。横杆偏向主杆哪一端，箭头就指向对侧（即横杆靠近的那端是尾部，远离的那端是尖端）。
3. 计算该封闭区域的"空余面积"：区域内所有非墙壁、非箭头的背景像素数量。
4. 从箭头尖端像素沿指向方向发射射线，射线颜色与箭头相同。射线穿透墙壁和外部空间，总长度恰好等于空余面积值。若射线到达网格边界则停止（截断）。
5. 保留所有墙壁、箭头和未被射线覆盖的像素不变。射线覆盖的像素（包括墙壁像素）被射线颜色覆盖。

**关键洞察**：射线长度不由箭头本身或任何可见标注决定，而由箭头所在封闭区域去除所有非背景像素后的剩余空间大小决定——需要先正确识别区域边界和归属，才能算出正确的射线长度。

## 新题 2：蛇形路径分段着色与区域投射

**组合逻辑**：[展直/遍历顺序](路径遍历) + [等分网格/分隔线](分割画布) + [计数](统计路径在各区域的像素数) + [重涂色](按比例决定颜色)

**来源原语**：展直/遍历顺序/蛇形路径(7b5033c1), 等分网格/分隔线(c3202e5a), 计数(ae4f1146), 重涂色(320afe60/e0fb7511)

**依赖链**：分隔线将画布划分为等大单元格；蛇形路径穿越多个单元格；路径遍历确定像素的读取顺序；每个单元格中路径所占像素数决定该段路径被重涂为何色；最终输出是一行按遍历序排列的重涂色像素序列。

将穿越网格分区的蛇形路径展直为一列，每段按所在分区的路径占比着色。

**输入结构**：约 15x15 的黑(0)背景网格。灰(5)像素构成完整的水平和垂直分隔线，将网格等分为 3x3 共 9 个大小相同的正方形单元格（每个约 4x4 的内部空间）。一条由青(8)像素组成的 4-连通蛇形路径从某个端点出发，穿越多个单元格（跨越分隔线处路径仍连续，分隔线位置也有路径像素）。路径恰好有两个端点（只有一个 4-邻居的像素）。路径总长 12~20 像素。生成约束：路径不分叉，是简单链；路径至少穿越 3 个不同的单元格。

**规则**：
1. 识别灰(5)分隔线，确定 9 个单元格的边界（分隔线本身不属于任何单元格）。
2. 找到蛇形路径的两个端点，选择行坐标更小的那个作为起点（若行坐标相同则选列坐标更小的）。从起点沿路径逐像素遍历。
3. 对路径上每个像素，判断它落在哪个单元格中（落在分隔线上的像素归属于遍历方向上即将进入的下一个单元格）。
4. 统计路径经过的每个单元格中的路径像素数量。将单元格按路径首次进入的顺序排列。对于路径经过的第 k 个单元格（从 1 开始），将该段所有路径像素重涂为颜色编号 k（1=蓝, 2=红, 3=绿, ...）。
5. 输出一个 Nx1 的单列网格（N=路径总像素数），按遍历顺序逐行填入每个路径像素的重涂后颜色。

**关键洞察**：颜色不由像素本身的位置决定，而由路径穿越网格分区的先后顺序决定——同一个单元格中的所有路径像素共享颜色，但该颜色取决于路径第几个到达该分区，需要同时理解分区结构和路径遍历序。

## 新题 3：对角标记的封闭区域填充与图例映射

**组合逻辑**：[对角配对](识别标记对定义矩形) + [洪泛填充/区域封闭](矩形内封闭区域检测) + [图例配色](颜色映射) + [冲突优先级/图例顺序决定层级](重叠解决)

**来源原语**：对角配对/角标记像素(f35d900a), 洪泛填充/区域封闭(a5313dff), 图例配色/图例顺序决定层级(305b1341), 冲突优先级(305b1341)

**依赖链**：对角标记对定义了若干矩形区域的四角；每个矩形内部被墙壁分割出的封闭子区域是填充目标；图例将标记颜色映射为填充颜色；当矩形区域重叠时，图例中靠前的颜色优先覆盖。

通过对角标记像素锁定矩形范围，在其中的封闭子区域内填入图例映射色，重叠处按图例顺序决定优先。

**输入结构**：约 16x16 的黑(0)背景网格。网格左上角有一个 2 列 N 行的图例区域（N=2~3），左列为源色，右列为填充色，源色从蓝(1)、绿(3)、橙(7)中选取，填充色从黄(4)、品红(6)、栗(9)中选取。网格其余区域中，红(2)像素构成若干一像素宽的线段（水平或垂直），作为内部墙壁但不完全封闭（不形成闭合回路）。同时存在 2~3 对对角标记像素：每对由相同颜色（与图例源色一致）的两个像素构成，位于某个轴对齐矩形的对角位置。不同对之间对应的矩形可以部分重叠。生成约束：每对标记像素对应的矩形内部至少存在一个被红墙壁和矩形边界共同围成的封闭区域（从矩形边界以内、墙壁以外的背景像素出发，无法 4-连通到达矩形的任何边像素）。

**规则**：
1. 读取图例：建立源色到填充色的映射，并记录图例中的行序（第 1 行优先级最高）。
2. 对每对同色标记像素，确定它们所定义的轴对齐矩形（两点为对角顶点）。
3. 在每个矩形内部，将红(2)墙壁和矩形的四条边视为不可通行的障碍，对内部背景像素做洪泛连通分析。将无法从矩形任何一条边的内侧像素 4-连通到达的背景像素集合标记为"封闭子区域"。
4. 将每个封闭子区域填充为该矩形对应的图例填充色。
5. 多个矩形重叠的区域：若某像素同时处于多个矩形的封闭子区域中，以图例行序靠前的颜色为最终颜色。
6. 保留所有红墙壁、标记像素、图例区域和未被填充的背景像素不变。

**关键洞察**：封闭区域不是由墙壁独立围成的，而是由墙壁与矩形边界共同围成的——同一段墙壁在不同矩形的语境下可能产生不同的封闭区域，因此必须先通过对角标记确定矩形范围，才能正确判断哪些区域是封闭的。

## 新题 4：骨架格子中瓦片旋转与环形铺设

**组合逻辑**：[骨架格子/空心小框](确定铺设网格) + [旋转/交替旋转换色](瓦片旋转规则) + [环形周期](沿格子边界环形铺设) + [标记像素](起始位置和旋转种子)

**来源原语**：骨架格子/空心小框(97239e3d), 旋转/交替旋转换色(fd4b2b02), 环形周期(30f42897), 标记像素/标记对齐格子边界(97239e3d)

**依赖链**：骨架格子定义了离散的格子位置系统；标记像素指示环形铺设的起始格子和初始瓦片朝向；沿格子外圈按顺时针环形遍历，每步将瓦片顺时针旋转 90 度并放入下一格子中心；旋转方向固定但初始朝向由标记决定。

在骨架格子的外圈中心位置环形铺设一个瓦片图案，每步顺时针旋转 90 度，起始朝向由标记确定。

**输入结构**：约 19x19 的黑(0)背景网格。灰(5)像素构成 5x5 的骨架格子（即 5 行 5 列的空心小框阵列，每个小框为 3x3 且中心为黑色，框间由一像素宽的灰线分隔）。外圈共 16 个格子位置。恰好一个外圈格子的中心像素为红(2)（标记像素），其余外圈格子中心为黑色。恰好一个外圈格子的中心位置放置了一个 3x3 的蓝(1)小图案（占据中心格子内部的非对称 L 形，3~4 个像素，4-连通），这个格子与红标记格子相邻（按环形顺序）。内圈 9 个格子的中心全部为黑色。生成约束：蓝色图案必须是非对称的（旋转 90/180/270 度后与原图案不同），且放置在红标记格子的顺时针方向下一格。

**规则**：
1. 识别 5x5 骨架格子结构，定位所有 25 个格子的中心坐标。
2. 确定外圈 16 个格子的顺时针遍历顺序（从左上角开始：顶行从左到右、右列从上到下、底行从右到左、左列从下到上）。
3. 找到红(2)标记像素所在格子作为环形铺设的起始参考点。蓝色图案所在格子是第一个铺设位置（即红标记的顺时针下一格）。
4. 从第一个铺设位置开始，沿顺时针方向继续遍历外圈。每到下一个格子，将当前图案顺时针旋转 90 度后放入该格子中心区域（3x3 范围内），颜色保持蓝(1)。
5. 铺设绕外圈一周直到回到红标记格子为止（红标记格子本身不铺设图案，保留红色中心像素）。
6. 保留所有灰色骨架结构和内圈格子不变。

**关键洞察**：铺设不是简单重复——每个格子中的图案是前一个格子图案旋转 90 度的结果，而起始朝向由唯一已存在的蓝色图案定义。要推断任意格子中的图案，必须从蓝色种子开始沿环形逐步旋转计数。

## 新题 5：等差矩形补全与桥接连线

**组合逻辑**：[等差递推/补全](推断缺失矩形位置) + [同色配对/对向间隙](识别可桥接的矩形对) + [连线/最短间隙优先连](绘制桥接) + [画布裁切可见](边界截断)

**来源原语**：等差递推/补全/矩形边框笔画(f8c80d96), 同色配对/对向间隙/最短间隙优先连(f3b10344), 连线/桥接条(f3b10344), 画布裁切可见(f8c80d96)

**依赖链**：可见的实心矩形按等差序列排列但有缺失；补全逻辑推断出完整序列中所有矩形的位置和尺寸；补全后的矩形与原有矩形一起参与桥接配对判断；同色且对向间隙最短的矩形对之间绘制桥接线。补全的矩形可能被画布裁切。

先补全等差序列中缺失的矩形，再在所有同色矩形间用最短间隙桥接连线。

**输入结构**：约 20x20 的黑(0)背景网格。存在两种前景色（如蓝(1)和绿(3)）的实心矩形，每种颜色 2~4 个矩形（尺寸均为 2x3 或 3x2）。同色矩形的中心坐标沿某个方向构成等差数列（公差相同），但序列中有 1~2 个位置的矩形缺失。所有可见矩形互不重叠，且与网格边界之间至少有 1 像素间距。生成约束：补全后的矩形可能部分超出画布边界（此时只显示画布内的部分）；补全后同色矩形中至少存在一对在行跨度或列跨度上有至少 3 像素重叠且间隙全为背景的配对。

**规则**：
1. 对每种前景色，提取其所有矩形的中心坐标，推断等差数列的公差（行方向公差和列方向公差）。
2. 根据公差补全缺失位置的矩形（尺寸与同色可见矩形相同）。若补全矩形部分超出网格边界，只绘制画布内可见的部分。补全矩形颜色与同色组一致。
3. 在所有矩形（包括原有和补全的）中，对每种颜色独立进行桥接判断：找到同色矩形对中行跨度或列跨度重叠至少 3 像素且间隙内全为背景像素的配对。
4. 对每组同色矩形，从所有候选配对中选择间隙最短的那对进行桥接。桥接线用青(8)绘制，宽度为 1 像素，位于重叠跨度的中央行或中央列，长度恰好填满两矩形之间的间隙。
5. 若存在环路（三个矩形两两可桥接），只保留使总桥接长度最小的两条桥。
6. 保留所有矩形（含补全）和背景不变，仅在间隙中添加青色桥接线。

**关键洞察**：桥接的候选对象不仅包括输入中可见的矩形，还包括通过等差推断补全的矩形——如果只看可见矩形可能找不到合法配对，必须先完成补全才能确定哪些矩形可以桥接。

## 新题 6：标记色选择性擦除与连通重组着色

**组合逻辑**：[按标记色选择同色/擦除](删除目标颜色像素) + [连通检测](分析擦除后新连通结构) + [面积大于一则涂/重涂色](按面积分类着色) + [保留标记本身](保护标记像素)

**来源原语**：按标记色选择同色/擦除/保留标记本身/角括号(1e81d6f9), 连通检测/连通性(e0fb7511), 面积大于一则涂/重涂色(e0fb7511), 唯一连通分量/最大面积选择(3194b014)

**依赖链**：角括号内的标记色指定要擦除的颜色；擦除后原本被该颜色连接的结构可能断裂为多个连通分量；对断裂后的每个非背景连通分量按面积重新着色；标记像素本身保留且不参与连通分析。

擦除标记指定颜色后，对因擦除而断裂的结构按连通分量面积重新分色。

**输入结构**：约 14x14 的黑(0)背景网格。存在一个由灰(5)像素构成的单像素宽 L 形角括号（两臂各 3~4 像素长）。角括号的包围盒内部（不含括号像素）恰有一个蓝(1)标记像素。网格中还有一个由多种颜色构成的大型 4-连通前景结构（约 20~35 像素），其中包含蓝(1)像素作为连接桥梁将若干橙(7)和绿(3)的子块连在一起。蓝像素在该结构中充当"胶水"——去除蓝像素后，结构会断裂为多个独立的 4-连通分量。生成约束：擦除蓝色后至少断裂为 3 个连通分量；各连通分量的面积互不相同。

**规则**：
1. 找到灰(5)角括号，读取其内部标记像素的颜色（蓝(1)）。
2. 将网格中所有蓝(1)像素（除标记像素本身外）擦除为黑(0)背景。
3. 对擦除后剩余的所有非背景像素做 4-连通分量分析（灰色角括号视为独立分量，不与其他颜色合并分析；标记像素视为孤立点，不参与）。
4. 将擦除后面积最大的连通分量重涂为红(2)，面积第二大的重涂为黄(4)，面积第三大的重涂为品红(6)，以此类推（按面积从大到小依次分配颜色序列：红、黄、品红、栗）。灰色角括号保持灰色不变。标记像素保持蓝色不变。
5. 连通分量内部原有的不同颜色统一替换为新分配的颜色。

**关键洞察**：擦除操作本身不是目标——它是改变连通结构的手段。哪些分量被分离、各自面积多大，完全取决于被擦除颜色在原结构中充当"桥梁"的具体位置，必须先执行擦除才能知道如何着色。

## 新题 7：边框段环形铺设与内部洪泛填充联动

**组合逻辑**：[边框段/环形周期/间隔等长重复](边框图案扩展) + [洪泛填充/区域封闭](识别内部封闭区域) + [计数](边框段覆盖的边像素数) + [纯色填充](按计数选色填充)

**来源原语**：边框段/环形周期/间隔等长重复(30f42897), 洪泛填充/区域封闭/孤立背景区域填充(a5313dff), 计数(ae4f1146), 纯色填充(3194b014)

**依赖链**：单个边框段按等间隔重复铺满矩形边界后，内部的墙壁线段与边框段共同围成封闭区域；每个封闭区域相邻的边框段像素数量决定该区域的填充颜色；填充颜色由邻接边框像素数通过映射规则确定。

先将边框段环形重复铺满边界，再根据每个内部封闭区域接触边框的像素数量选色填充。

**输入结构**：约 15x15 的黑(0)背景网格。矩形边界（最外圈一行一列）上有一段连续的绿(3)像素段（长度 3~5 像素），其余边界像素为黑色。网格内部（非边界区域）有若干红(2)一像素宽的直线段（水平或垂直，长度 3~8 像素），这些线段的两端不接触网格边界，但将内部空间部分分隔。生成约束：边框段长度 n 满足 2n 能整除边界周长（保证间隔等长重复能精确铺满）；红色内部线段与边框段配合后至少形成 2 个封闭区域（不同封闭区域邻接的边框像素数量互不相同）。

**规则**：
1. 识别边界上的绿(3)边框段，测量其长度 n。
2. 将该边框段沿矩形边界顺时针方向以周期 2n 重复铺设（铺 n 个像素，空 n 个像素，循环直到回到起点），所有新铺设的像素也着绿(3)。
3. 将铺设完成后的绿色边框像素和红色内部线段共同视为墙壁。从网格内部（不含边界行列）的背景像素出发做 4-连通洪泛分析：能够到达任何未被绿色覆盖的边界位置（黑色边界缝隙）的背景像素标记为"外部可达"。
4. 剩余无法外达的背景像素集合为封闭区域（可能有多个独立的封闭区域）。
5. 对每个封闭区域，计算其 4-邻居中绿色边框像素的数量（去重，即该区域所有像素的绿色 4-邻居的并集大小）。
6. 邻接绿色像素数最多的封闭区域填充蓝(1)；次多的填充黄(4)；第三多的填充橙(7)。相同数量时按封闭区域最上最左像素的位置排序（行优先）。
7. 保留所有绿色边框、红色线段和外部可达的背景像素不变。

**关键洞察**：封闭区域的形成依赖于边框段的环形铺设结果——铺设前边界全是缝隙，没有任何区域被封闭；只有铺设后的绿色段与内部红色线段协同才能围出封闭空间。同时，填充颜色取决于封闭区域与边框段的几何接触关系，而非区域面积或位置。
