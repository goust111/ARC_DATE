## 新题 1：方向精灵体控制矩形拉伸方向

**组合逻辑**：[质心偏移定向](从方向精灵体解码方向) → [拉伸](空心矩形沿解码方向扩展至边界) + [同色匹配](精灵体颜色决定控制对象)

**来源原语**：质心偏移定向(13f06aa5), 方向精灵体(13f06aa5), 拉伸(b548a754), 空心矩形(b548a754), 同色匹配(58f5dbd5)

**依赖链**：方向精灵体的体色与某个空心矩形的边框色相同，构成控制关系；精灵体内标记像素相对于体像素质心的偏移方向决定矩形的拉伸方向；拉伸距离由该方向上到网格边界的距离决定。若不先解码方向，则无法确定拉伸目标边。

从方向精灵体解码拉伸方向并按同色对应关系扩展空心矩形至网格边界。

**输入结构**：约 20x20 黑(0)背景网格。包含 3 个不同颜色的空心矩形（边框分别为蓝(1)、红(2)、绿(3)，内部为黑(0)，尺寸约 3x3 至 5x5 不等，矩形之间互不相邻且各距网格边界至少 3 格）。另有 3 个方向精灵体散布于空白区域，每个精灵体由 5~7 个灰(5)像素构成 4-连通的不规则形状，内部嵌入 1 个与某空心矩形边框同色的标记像素（蓝(1)、红(2)、绿(3)各一个）。每个精灵体的灰(5)像素质心相对于标记像素有明确的方向偏移（上、下、左、右四方向之一），即灰像素主要分布在标记像素的某一侧。生成约束：每个矩形在其对应拉伸方向上到网格边界的路径不经过其他矩形或精灵体。

**规则**：
1. 对每个方向精灵体，定位其内部的彩色标记像素，计算所有灰(5)像素的质心坐标。
2. 质心相对于标记像素的方向即为"体偏移方向"；拉伸方向为体偏移方向的反方向（体在标记左侧 → 拉伸向右）。
3. 根据标记像素颜色找到同色边框的空心矩形。
4. 将该矩形沿拉伸方向扩展：保持矩形的另外三边不动，将拉伸方向一侧的边框移至网格边界（边框到达网格最外行/列），中间填充同色边框围合的空心区域（内部保持黑(0)）。
5. 拉伸完成后擦除所有方向精灵体（灰像素和标记像素均设为黑(0)）。
6. 若多个矩形拉伸区域在角落重叠（仅可能在边框线相交处），保留后拉伸的颜色，处理顺序为蓝(1) → 红(2) → 绿(3)。

**关键洞察**：精灵体的几何不对称性编码了一个方向信号，但该信号指向的是拉伸的反方向——体像素"堆积在后方"暗示运动朝前方，需要反转解读。

## 新题 2：碎片补全后按孔洞数查表重涂色

**组合逻辑**：[补全](碎片锚定补全为完整模板) → [计数](统计每个补全体的封闭孔洞数) → [查表映射](孔洞数→颜色图例) + [重涂色]

**来源原语**：补全/碎片/碎片锚定放置位(fd096ab6), 模板精灵体(fd096ab6), 计数(e3721c99/7039b2d7), 封闭区域(e3721c99), 颜色图例/孔洞数映射颜色(e3721c99), 重涂色(9caf5b84)

**依赖链**：碎片必须先补全为完整模板才能计算孔洞数（碎片本身无封闭区域）；孔洞数决定查表结果；查表结果决定重涂色的目标颜色。三步之间有严格的信息依赖。

将散落碎片补全为完整模板，再根据每个完整体的孔洞拓扑结构查表重涂色。

**输入结构**：约 25x25 黑(0)背景网格。左下角有一个灰(5)的完整模板形状（8-连通、约 12~18 像素，内部含 1~3 个由黑(0)构成的封闭孔洞，模板本身不规则但连通）。网格右上区域有一个颜色图例区：2~3 个小型彩色形状（如红(2)、蓝(1)、绿(3)），每个形状为 2x2 至 3x3 的连通区域，分别含有不同数量的 1 像素封闭孔洞（0 个、1 个、2 个），作为"孔洞数→颜色"的映射表。网格中央散布着 4~6 组碎片，每组碎片用同一种非灰非图例的颜色（如黄(4)、橙(7)、栗(9)、品红(6)等），每组含 2~4 个像素，这些像素是灰(5)模板在某个平移位置下的子集。不同组碎片对应的平移位置互不重叠。生成约束：每组碎片唯一确定一个模板平移位置；补全后各模板副本互不重叠且不与图例、原始模板重叠。

**规则**：
1. 识别灰(5)的连通区域为模板 mask。
2. 对每组同色碎片，找到唯一的平移位置使得模板 mask 平移后覆盖该组所有碎片像素。
3. 在该平移位置绘制完整模板副本（用该组碎片的颜色）。
4. 对每个补全后的模板副本，计算其内部封闭孔洞数（被该颜色像素完全包围的黑(0)连通区域，不触及该副本边界框外部）。
5. 在图例区中找到孔洞数相同的图例形状，读取其颜色。
6. 将该模板副本的所有像素重涂为图例指示的颜色。
7. 灰(5)原始模板保持不变；图例保持不变。

**关键洞察**：碎片本身没有封闭区域（像素太少无法围合），只有补全后才能形成孔洞——但不同平移位置可能因为与网格边界的距离关系导致"看似封闭"的区域实际连通到外部，因此孔洞计数必须基于补全后的实际几何形状而非模板本身的固有孔洞数。

## 新题 3：分隔格内路径滑动汇合后压缩

**组合逻辑**：[网格分区](分隔线划分单元格) → [滑动/相向移动](每格内对侧像素相向滑动留迹) → [压缩/每区域折叠单像素](汇合点颜色决定输出像素)

**来源原语**：网格分区/分隔线(780d0b14), 滑动/相向移动留迹汇合(29c11459), 对侧配对(29c11459), 汇合点(29c11459), 压缩/每区域折叠单像素(780d0b14)

**依赖链**：分区确定了每个单元格的边界，决定了"对侧"的定义域；在每个格内对侧像素相向滑动产生汇合点及其颜色（灰(5)或留为原色取决于是否恰好在中心相遇）；压缩阶段读取每格汇合点的颜色作为输出像素。三步紧密耦合：没有分区则无法确定对侧，没有滑动则无法产生汇合点，没有压缩则无法得到最终输出。

在分隔线划分的每个单元格内执行对侧像素相向滑动留迹，然后将每格的汇合状态压缩为单像素输出。

**输入结构**：约 19x19 网格，背景为黑(0)。品红(6)的完整行和完整列将网格分割为 3x3 或 4x4 的矩形单元格（每格内部约 4x4 至 5x5 像素）。每个单元格内，恰好有两个不同颜色的非黑非品红像素，分别位于该格的对侧（一个在格内的左边缘行/列，另一个在对应的右边缘行/列；或一个在上边缘，另一个在下边缘），两者在共享的行或列上对齐。像素颜色从蓝(1)、红(2)、绿(3)、黄(4)中选取，每格内两个像素颜色不同。生成约束：每格内两像素在同一行或同一列上，中间无障碍物。

**规则**：
1. 找到所有品红(6)的完整行和完整列作为分隔线，确定每个矩形单元格的边界。
2. 在每个单元格内，定位两个非黑非品红像素，确认它们位于格内的对侧（共享行则为左右对侧，共享列则为上下对侧）。
3. 两像素沿共享的行/列相向移动，每步各前进一格，在经过的格子留下自身颜色的轨迹。
4. 当两像素相邻（距离为 1）时停止，二者之间无空格则不产生灰(5)汇合点，输出该格压缩为距格中心更近的那个像素的颜色；当两像素在同一格相遇（奇数距离时中间恰有一格）时，该格涂为灰(5)作为汇合点，输出该格压缩为灰(5)。
5. 输出网格尺寸 = 单元格的行列数（如 3x3 或 4x4），每个输出像素对应一个单元格的压缩颜色。

**关键洞察**：两像素间的原始距离奇偶性决定了是否存在灰色汇合点——偶数距离时无汇合格（两者相邻停止），奇数距离时有（两者在中间格重合）。这一奇偶判断只能通过分析格内几何推断，无法从颜色直接读出。

## 新题 4：镜像差异提取为挖孔模板

**组合逻辑**：[镜像](精灵体水平翻转) → [差异提取](原始与镜像的不一致像素集合) → [挖孔](差异集作为模板挖孔于同色块) + [同色匹配]

**来源原语**：镜像(80214e03/c9680e90), 挖孔/模板图案(58f5dbd5), 单色块(58f5dbd5), 同色匹配(58f5dbd5)

**依赖链**：必须先对精灵体做镜像变换得到镜像版，然后将原版与镜像版逐像素比较提取差异区域，该差异区域才是挖孔的模板——差异像素的空间模式取决于精灵体的不对称程度，无法跳过镜像步骤直接确定。

通过精灵体与其镜像的像素差异生成挖孔模板，再将该模板应用于同色单色块。

**输入结构**：约 18x18 黑(0)背景网格。包含 3 个 5x5 单色实心方块（颜色分别为蓝(1)、红(2)、绿(3)），位于网格下半区，互不相邻。网格上半区有 3 个不规则精灵体（4-连通，约 6~10 像素），颜色分别与三个方块同色（蓝(1)、红(2)、绿(3)各一个）。每个精灵体在水平方向上不完全对称（即左右翻转后至少有 2 个像素位置不同）。精灵体的边界框不超过 5x5（与方块尺寸匹配）。生成约束：每个精灵体的边界框与其对应方块的尺寸兼容（精灵体边界框 <= 5x5）；差异像素集合居中放置于 5x5 方块时不超出方块范围。

**规则**：
1. 对每个彩色精灵体，以其边界框为参考做水平镜像翻转（左右翻转）。
2. 将翻转结果与原始精灵体在同一边界框坐标内逐像素比较：原始有色但镜像为空的位置标记为"差异像素"。
3. 将差异像素集合的模式居中对齐到同色的 5x5 方块上。
4. 在方块中，差异像素对应位置的颜色设为黑(0)（挖孔），其余方块像素保持原色。
5. 精灵体在输出中被擦除（设为黑(0)）。
6. 若差异像素集合为空（完全对称，不应出现，生成时保证不对称），该方块保持不变。

**关键洞察**：挖孔模板不是直接给出的图案，而是通过精灵体与其自身镜像的"不对称度"隐式编码的——对称性越低的精灵体产生越多的孔洞，求解者必须自行执行镜像比较才能推导出模板。

## 新题 5：轨迹路径长度编码平铺重复次数

**组合逻辑**：[沿路径移动/轨迹路径](测量路径长度) → [平铺/纵向重复](路径长度决定行带重复次数) + [同色对应](路径颜色匹配行带颜色)

**来源原语**：沿路径移动/轨迹路径(c9680e90), 平铺/纵向重复/行带(8eb1be9a), 同色对应(1b59e163), 前景行带铺满画布(8eb1be9a)

**依赖链**：路径长度必须通过追踪轨迹像素计数得出；该数值直接决定对应行带的纵向重复次数；行带-路径的匹配通过颜色对应建立。不追踪路径则无法知道重复几次，不匹配颜色则无法知道哪条路径控制哪个行带。

测量每条彩色路径的像素长度，用该长度作为对应颜色行带的纵向重复次数来填充输出。

**输入结构**：约 20x15 网格，背景为黑(0)。网格被一条灰(5)完整竖列分为左右两半。左半区包含 2~3 条不同颜色的 4-连通路径（每条路径为单像素宽的蜿蜒线段，颜色从蓝(1)、红(2)、绿(3)中选取，长度各不相同，范围 3~7 像素）。右半区包含与左侧路径颜色一一对应的水平行带（每个行带为 1 行高、宽度等于右半区宽度的连续同色像素条），行带之间由黑(0)行分隔，行带在右半区的垂直位置不重要（仅需颜色对应）。生成约束：左侧路径长度均不同；右半区高度足够容纳所有行带按各自重复次数纵向堆叠后的总高度。

**规则**：
1. 识别灰(5)竖列为分隔线，确定左半区和右半区。
2. 在左半区，对每种颜色追踪其 4-连通路径，计算路径像素总数 = 该颜色的"重复因子"。
3. 在右半区，提取每种颜色的行带（1 行高的水平色条）。
4. 输出网格宽度 = 右半区宽度，高度 = 所有行带重复因子之和。
5. 按行带在输入右半区中从上到下的出现顺序，依次将每个行带纵向重复其重复因子次，堆叠形成输出。
6. 灰(5)分隔线和左半区内容不出现在输出中。

**关键洞察**：路径的空间形态（弯曲程度、方向）与规则无关，唯一有意义的信息是路径的像素计数——几何形状是噪声，拓扑长度才是信号。

## 新题 6：骨架对齐旋转后射线延伸碰撞涂色

**组合逻辑**：[骨架对齐 + 旋转](确定每个副本的朝向) → [射线延伸](从每个副本的标记像素沿解码方向射出) → [膨胀求交](射线交叉区域涂色)

**来源原语**：骨架对齐/旋转/完整标注传递副本(36d67576), 射线延伸/质心偏移定向(13f06aa5), 膨胀求交/两路径间隙重叠区(f1bcbc2c)

**依赖链**：必须先通过骨架对齐确定每个副本的旋转角度，才能知道其标记像素相对于骨架的朝向；朝向决定射线方向；射线必须全部延伸完毕后才能做膨胀求交找到碰撞区域。三步间信息严格单向流动且不可跳过。

通过骨架对齐确定多个精灵体副本的旋转状态，从每个副本的标记像素沿旋转后的方向发射射线，射线之间的交叉区域涂为特殊颜色。

**输入结构**：约 22x22 黑(0)背景网格。包含 1 个"完整模板"精灵体和 3~4 个"不完整副本"精灵体。模板由灰(5)骨架像素（约 5~8 像素，4-连通，不规则）和 1 个红(2)标记像素组成，标记像素与骨架 8-连通。每个副本仅有灰(5)骨架（与模板骨架形状相同但经旋转 0/90/180/270 度之一），不含红(2)标记。模板中红(2)标记相对于骨架的位置在旋转后映射到副本的对应位置。各精灵体之间距离 >= 5 格。生成约束：从每个副本的"虚拟标记位置"沿模板中标记相对骨架质心的反方向（即射线方向，旋转后）延伸的射线至少有两条相交；射线在遇到非黑像素前到达网格边界。

**规则**：
1. 识别包含红(2)标记的连通体为模板；其余灰(5)连通体为副本。
2. 对每个副本，找到唯一旋转角度（0/90/180/270 度）使模板骨架旋转后与副本骨架像素完全重合。
3. 将模板中红(2)标记的相对位置（相对于骨架像素集）做相同旋转，得到副本的"虚拟标记位置"。
4. 射线方向 = 虚拟标记位置相对于副本骨架质心的方向（上/下/左/右，取最近轴向）。
5. 从虚拟标记位置沿射线方向逐格延伸，用黄(4)涂色，直至网格边界（跳过已有非黑像素）。同时从模板的红(2)标记也发出射线（方向为红标记相对于模板骨架质心的方向）。
6. 对所有黄(4)射线路径做 1 像素 8-邻域膨胀，取所有膨胀区域的交集像素（被至少两条射线的膨胀区域共同覆盖的位置）。
7. 将交集像素涂为青(8)；黄(4)射线保留；骨架和标记保留原色。

**关键洞察**：副本没有标记像素，必须通过骨架对齐"还原"出标记应在的位置及其射出方向——方向信息被编码在骨架的旋转状态中，是隐式的而非显式给出。

## 新题 7：分区计数生成画布后按频率排序铺色

**组合逻辑**：[计数/分区数决定尺寸](统计分区数确定输出尺寸) → [生成网格](创建空白画布) → [频率排序 + 重涂色](按输入中各色频率从高到低依次填充输出行)

**来源原语**：计数/生成网格/分区数决定尺寸(7039b2d7), 分隔线(780d0b14/7039b2d7), 频率排序(9caf5b84), 重涂色(9caf5b84)

**依赖链**：必须先数清分隔线划分出的行区域数和列区域数才能确定输出网格尺寸；然后统计输入中各非分隔色的频率排名；输出网格的行数恰好等于非分隔色的种类数（由分区数保证），每行填一种颜色按频率从高到低排列。分区计数同时决定了画布尺寸和需要排列多少种颜色。

统计分隔线划分的分区数作为输出尺寸，然后按输入各色出现频率从高到低逐行填充纯色。

**输入结构**：约 15x15 网格。灰(5)完整行和完整列将网格分割为若干矩形区域（行分区数 R，列分区数 C，R 和 C 在 3~5 之间）。每个矩形区域内散布着单一颜色的非黑非灰像素（颜色从蓝(1)、红(2)、绿(3)、黄(4)、橙(7)中选取），不同区域可能使用相同颜色。共有 R 种不同颜色出现在输入中（生成约束保证）。背景为黑(0)。生成约束：恰好有 R 种不同的非黑非灰颜色出现；各颜色的总像素数互不相同（保证频率排名无平局）。

**规则**：
1. 找到所有灰(5)的完整行和完整列，计算行分区数 R（灰行之间及边界间的间隔数）和列分区数 C。
2. 输出网格尺寸为 R 行 x C 列。
3. 统计输入中所有非黑(0)非灰(5)像素的颜色及各色的总像素数。
4. 按像素数从多到少排列颜色，得到颜色序列 [c1, c2, ..., cR]。
5. 输出网格的第 i 行（从上到下，i=1 为最上行）全部填充颜色 ci。

**关键洞察**：分区的空间结构（哪个区域用什么颜色、区域大小差异）只是频率信息的载体——输出完全抛弃了空间布局，仅保留颜色的全局统计排名。列分区数 C 决定输出宽度但不携带颜色信息，是一个纯几何参数。

## 新题 8：端点互换连线后按格内判定提取有效段

**组合逻辑**：[颜色角色互换](精灵体锚点变为连线端点，线段端点变为精灵体放置点) → [连线](新端点之间绘制直线) → [格内判定/纯色即有效](只保留完全落在某纯色区域内的线段部分)

**来源原语**：颜色角色互换/端点对应(c6141b15), 连线/线段(c6141b15), 格内判定/纯色即有效(458e3a53), 分隔线网格(458e3a53), 精灵体/锚点(c6141b15)

**依赖链**：首先执行角色互换确定新的连线端点（原精灵体中心）和新的精灵体放置位（原线段端点）；然后在新端点之间绘制连线；最后将背景上的纯色区域作为有效掩码，只保留线段落在纯色区域内的部分。三步缺一不可。

将精灵体和线段的角色互换后重新连线，再用纯色区域作为掩码裁切线段。

**输入结构**：约 18x18 黑(0)背景网格。包含 1 条红(2)的直线段（水平或垂直，约 8~12 像素长）和 3 个蓝(1)的相同小精灵体（3x3 以内的 4-连通形状，中心像素为黄(4)作为锚点）。另有 2~3 个灰(5)填充的矩形纯色区域（约 4x4 至 6x6）散布在网格中。生成约束：三个精灵体中心两两连线后，每条连线至少部分穿过某个灰(5)区域；精灵体和线段不与灰区域重叠。

**规则**：
1. 识别红(2)直线段的两个端点坐标 P1、P2。
2. 识别每个蓝(1)精灵体的黄(4)锚点坐标 A1、A2、A3。
3. 角色互换：将蓝(1)精灵体（含黄(4)锚点）印章放置到 P1、P2 位置（锚点对齐端点，只取前两个精灵体的锚点到 P1 和 P2，按锚点到端点的曼哈顿距离最近配对）。
4. 以原始锚点 A1、A2、A3 为新端点，绘制红(2)直线连接所有锚点对（A1-A2、A2-A3、A1-A3，共 3 条线段，使用 Bresenham 直线算法）。
5. 对每条新线段，只保留落在灰(5)矩形区域内部的像素（灰区域像素坐标构成有效掩码），线段在灰区域外的部分不绘制。
6. 输出：黑背景 + 灰(5)区域保持 + 有效线段像素为红(2) + 放置在端点的精灵体为蓝(1)/黄(4)。原始线段和原始位置的精灵体被擦除。

**关键洞察**：连线的"可见性"不由端点位置决定，而由与端点无关的灰色区域掩码决定——线段可能两端都可见也可能只有中间穿越灰区域的部分可见，打破了"线段从端点画到端点"的直觉。

## 新题 9：分隔格内像素滑动后判定纯色有效性并紧凑排列

**组合逻辑**：[网格分区](分隔线划分单元格) → [滑动](格内像素向下滑动沉积) → [纯色即有效/格内判定](沉积后检测哪些格为纯色) → [紧凑排列/保持行列顺序](有效格紧凑排列为输出)

**来源原语**：网格分区/分隔线网格(458e3a53/780d0b14), 滑动(29c11459), 纯色即有效/格内判定(458e3a53), 紧凑排列/保持行列顺序(58f5dbd5)

**依赖链**：分区定义格边界 → 滑动改变格内像素分布 → 滑动后的分布决定格是否变为纯色 → 纯色格被选为有效并紧凑输出。任何一步的结果都依赖前一步：未滑动时可能无格为纯色；滑动后的纯色性取决于格内原始像素的颜色组成和数量。

格内像素重力沉积后，只保留变为纯色填充的单元格，按原始位置顺序紧凑排列输出。

**输入结构**：约 21x21 网格，背景为黑(0)。橙(7)完整行和完整列将网格分为 4x4 = 16 个矩形单元格（每格内部约 4x4 像素）。每格内散布 2~6 个非黑非橙的彩色像素（从蓝(1)、红(2)、绿(3)、黄(4)中选取），有些格内所有像素同色，有些格内含有 2 种颜色。像素在格内的行位置随机（不一定沉底）。生成约束：滑动（向下沉积）后，恰好有 4~8 个格变为"纯色"（即格内最底部若干行被同一颜色完全填满，且格内无其他颜色像素；具体说该格内所有像素本身就是同色的，滑动只改变它们的行位置不改变纯色判定结果）。实际上纯色判定 = 格内是否只含一种非背景色。滑动后沉积不影响这一判定，但影响另一个条件：沉积后像素必须恰好无间隙地填满格底部的连续若干行（即形成实心矩形块）。两个条件同时满足才算"有效纯色格"。

**规则**：
1. 识别橙(7)完整行/列为分隔线，划分 4x4 单元格。
2. 对每个格，将格内所有非黑像素向下移动直至碰到格底边或另一个像素（重力沉积，同列内从下往上逐个下落）。
3. 沉积后判定有效性：格内所有非黑像素必须 (a) 全部同色，且 (b) 形成从格底部开始的无间隙实心矩形（即填满底部 k 行 x 格宽度，无黑色空洞）。同时满足两条件的格为"有效格"。
4. 提取所有有效格的内容（沉积后的纯色矩形块），按它们在原始网格中的位置从左到右、从上到下排序。
5. 输出：将有效格的内容（各自为一个纯色小矩形）按排序顺序紧凑排列到输出网格中，行间无间隙，列方向左对齐，格与格之间有 1 像素黑(0)间隔。输出网格尺寸为刚好容纳所有有效格内容的最小矩形。

**关键洞察**：仅含单色像素的格不一定有效——若像素数量无法填满整行（如 4 格宽的格中只有 3 个像素），沉积后底部行有空洞，则不满足"实心矩形"条件。有效性同时取决于颜色一致性和数量的几何匹配。

## 新题 10：折线连接路径上印章精灵体并按封闭区域计数裁剪

**组合逻辑**：[折线连接/曼哈顿路径](绘制 L 形路径) → [印章覆盖](沿路径等距放置精灵体) → [计数/封闭区域](统计路径形成的封闭区域数) → [裁剪](按封闭数裁剪输出边界)

**来源原语**：折线连接/曼哈顿路径/起点终点标记(a2fd1cf0), 印章覆盖/精灵体/锚点(36d67576/1b59e163), 计数/封闭区域(e3721c99), 裁剪(80214e03/458e3a53)

**依赖链**：起点终点确定 L 形路径几何 → 沿路径等距印章放置精灵体 → 精灵体与路径共同构成的图形可能围出封闭区域 → 封闭区域数决定输出的裁剪边距。整条链中，路径形状决定精灵体位置，精灵体位置决定封闭拓扑，封闭拓扑决定裁剪参数。

绘制 L 形路径并沿路径放置精灵体，根据形成的封闭区域数确定输出裁剪量。

**输入结构**：约 20x20 黑(0)背景网格。包含 1 个红(2)起点像素和 1 个绿(3)终点像素，分别位于不同行不同列。网格某角落有一个蓝(1)小精灵体模板（3x3 以内，4-连通，约 4~6 像素，中心有 1 个黄(4)锚点像素）。生成约束：红绿像素间曼哈顿距离 >= 8；L 路径（水平优先）上每隔 3 格放置一个精灵体时，精灵体不超出网格边界；路径加精灵体的组合至少形成 1 个封闭区域。

**规则**：
1. 从红(2)像素出发，沿其所在行水平移动到绿(3)像素所在列，再从该拐点垂直移动到绿(3)像素所在行（不含绿像素本身），用灰(5)绘制 L 形路径像素。
2. 沿 L 路径从起点开始，每隔 3 个路径像素（即第 1、4、7...个路径格），以该格为锚点位置印章放置蓝(1)精灵体副本（锚点对齐路径格，覆盖已有像素）。
3. 统计当前网格中由非黑像素完全围合的黑(0)封闭区域数量 N（封闭 = 该连通黑区域不触及网格边界）。
4. 输出为以 L 路径拐点为中心、向四周各扩展 N 格的正方形裁剪区域（边长 = 2N+1）。若裁剪框超出网格则取网格边界内的部分。
5. 输出内容包含裁剪区域内的所有像素（路径、精灵体、背景均保留原样）。

**关键洞察**：裁剪范围不是预先给定的，而是由路径上精灵体的放置结果"涌现"出的封闭区域数量动态决定的——同样的起止点配上不同形状的精灵体会产生不同数量的封闭区域，从而输出不同大小的裁剪结果。
