## 新题 1：重力沉降驱动的同心环着色

**组合逻辑**：[重力沉降gravity_settling] → [排序sorting](创新：排序键来自重力后的列高度) → [同心层填充concentric_layer_filling](创新：层数和颜色由沉降高度决定)

**来源原语**：重力沉降(#17 1e0a9b12), 排序(#2 3ee1011a), 同心层填充(#2 3ee1011a)

**依赖链**：重力沉降改变像素的空间分布 → 沉降后每种颜色的堆叠高度成为排序键 → 排序结果决定同心环从外到内的颜色分配。删除重力步骤则无法得到高度信息；删除排序则层序不确定；删除同心填充则无输出结构。

将散落在网格中的多色像素下沉后，按各色堆积高度从高到低映射为同心方形环从外到内的层色。

**输入结构**：约 12x12 网格，背景黑(0)。3~5 种非背景色的像素各散布 2~6 个，分布在不同列中，每列最多有一个像素。各颜色的像素总数互不相同（保证排序无歧义）。网格底部无预置内容。

**规则**：
1. 对每一列，将该列中所有非背景像素沿列方向下沉至底部（保持列内相对顺序，即稳定重力）。
2. 沉降完成后，统计每种非背景色在底部堆积后所占据的总行数（即该颜色在所有列中的最大连续底部高度之和——不对，更精确地说：统计每种颜色的像素总数，即该颜色沉降后堆叠的总格数）。
3. 按像素总数从大到小排列颜色。
4. 生成一个 M x M 的输出网格（M = 像素总数最大的颜色的像素数 x 2 - 1），以黑(0)为底，从最外层到最内层依次填充排序后的颜色。每层为一圈完整的方形环，宽度为 1 像素。
5. 若颜色数量 K 小于可用层数，内部剩余层保持黑(0)。

**关键洞察**：像素的空间散布位置本身无意义——重力沉降只是将"每种颜色有多少像素"这个隐含计数显性化，该计数才是决定同心环层序的真正编码。

## 新题 2：印章覆盖的颜色随距离循环移位

**组合逻辑**：[印章覆盖stamp] + [循环移位cyclic_shift](创新：移位量由目标与范例的曼哈顿距离决定) + [最近距离nearest_distance](创新：作为移位量的编码来源)

**来源原语**：印章覆盖(#16 39e1d7f9), 循环移位(#11 2601afb7), 最近距离(#19 2204b7a8)

**依赖链**：范例标记的邻域模板提供印章形状和基础颜色 → 每个目标标记相对范例的曼哈顿距离决定颜色循环偏移量 → 最终每个目标标记处的印章具有距离相关的颜色变体。距离计算依赖位置，印章形状依赖范例，颜色偏移依赖距离——三者环环相扣。

将范例标记周围的多色邻域模板复制到同色标记处，但模板中的颜色按目标与范例的曼哈顿距离做循环移位。

**输入结构**：约 15x15 网格，背景黑(0)，有灰(5)分隔线将网格划分为 5x5 的格网（每个格子 3x3，分隔线宽 1 像素，非必须均匀但保证对齐）。格网中大部分格子为黑(0)。恰好一个格子为红(2)且其 8-邻域格子中有 2~4 个被涂上了不同的非背景非红色（如蓝(1)、绿(3)、黄(4)），这些构成邻域模板。另有 3~4 个格子也为红(2)但邻域为空（孤立标记）。

**规则**：
1. 识别唯一被装饰的红(2)格子（其邻域有非背景色）为范例。
2. 提取范例的邻域模板：记录每个非背景邻居相对于范例的方向偏移及其颜色。设模板中出现了 C 种不同颜色，按这些颜色在模板中从左上到右下首次出现的顺序排列为颜色序列 S。
3. 对每个孤立红(2)标记，计算其到范例的棋盘格距离 D（格网坐标的切比雪夫距离，即 max(|row差|, |col差|)）。
4. 将颜色序列 S 循环右移 D 位。用移位后的序列替换模板中对应位置的颜色，然后将修改后的模板印章到该标记的邻域。
5. 印章超出网格边界的部分裁剪。模板位置与分隔线重叠时，分隔线颜色不变（印章不覆盖分隔线）。

**关键洞察**：同一个印章形状在不同位置呈现不同颜色组合，求解者必须发现颜色变化的规律是距离驱动的循环移位，而非独立的颜色映射。

## 新题 3：射线交叉填充与图层优先级仲裁

**组合逻辑**：[射线延伸ray_extend] + [行列交叉row_column_crossing] + [洪泛填充flood_fill](创新：填充区域由射线围合而成) + [图层优先级layer_priority](创新：由射线源像素的空间位置决定)

**来源原语**：射线延伸(#18 45bbe264), 行列交叉(#18 45bbe264), 洪泛填充(#9 4e469f39), 图层优先级(#20 6a11f6da)

**依赖链**：标记像素发出十字射线 → 射线相交形成封闭区域 → 洪泛填充每个封闭区域 → 区域被多条射线围合时，用图层优先级（由射线源的行号决定）仲裁颜色。射线必须先画出才能形成围合；围合不存在则无区域可填；优先级规则需对比多个示例才能归纳。

多个彩色标记发出十字射线，射线围合形成的封闭区域按"行号最大的射线源优先"规则着色。

**输入结构**：约 11x11 网格，背景黑(0)。3 个非背景标记像素位于不同行和不同列，颜色各异（如蓝(1)、绿(3)、黄(4)）。标记像素不在网格边缘行/列上。

**规则**：
1. 每个标记像素向上、下、左、右四个方向发出射线，射线颜色与标记相同，延伸至网格边界。
2. 标记像素本身保留原色不变。
3. 两条不同来源的射线相交的像素涂红(2)。
4. 射线将网格分割为若干矩形区域。对每个完全被射线和/或网格边界围合的矩形区域，执行洪泛填充。
5. 填充颜色的选择规则：该区域的边界由哪些标记的射线构成，取这些标记中**行号最大者**的颜色作为填充色。若区域仅由一个标记的射线和网格边界围合，则用该标记的颜色。
6. 射线像素和交叉点像素不被填充覆盖（它们保持射线色或红色）。

**关键洞察**：表面上看每个区域被多条射线包围、颜色选择似乎任意，但规则是由射线源的行坐标仲裁——行号越大优先级越高。这个规则需对比多个区域的着色才能归纳。

## 新题 4：对称补全后的缺陷检测与环绕标记

**组合逻辑**：[对称补全symmetry_complete] + [模式匹配pattern_match](创新：匹配对称后应有的模式以检测缺陷) + [标记环绕surround_marking](创新：环绕标记的目标是对称性破坏点)

**来源原语**：对称补全(#10 60d73be6), 模式匹配(#5 d94c3b52), 标记环绕(#15 71e489b6), 异常值选择(#15 71e489b6)

**依赖链**：输入本应具有双轴对称但有若干像素被故意移除或改色 → 需通过对称补全推断"正确"图案 → 将推断结果与实际输入对比，找出不匹配的像素（缺陷） → 对缺陷像素执行 8-邻域环绕标记。对称补全提供预期基准，缺陷检测依赖该基准与实际的差异，环绕标记作用于检测结果。

检测并标记一个近似双轴对称图案中的对称性破坏点。

**输入结构**：约 13x13 网格，背景黑(0)。一条完整的灰(5)横行和一条完整的灰(5)竖列构成十字轴线（行列交叉处也为灰）。在四个象限中，蓝(1)像素构成一个近似关于十字轴双轴对称的图案（每个象限约 4~7 个蓝像素）。但其中 2~3 个蓝像素被故意替换为黑(0)（即被删除），另有 1~2 个黑(0)位置被替换为蓝(1)（即被添加）。生成约束：扰动不位于轴线上；理想对称图案（无扰动版本）确实是严格双轴对称的。

**规则**：
1. 识别十字轴线（完整灰行与完整灰列）。
2. 对于每个非轴线非背景像素，计算其关于水平轴、垂直轴、以及双轴的三个镜像位置。一个像素若在四个对称位置（含自身）中，蓝(1)的出现次数 >= 3，则该位置"应当"为蓝；若出现次数 <= 1，则"应当"为黑。
3. 缺陷像素 = 实际颜色与"应当"颜色不同的像素。
4. 输出 = 输入的副本，但在每个缺陷像素的 8-邻域中，所有背景(0)像素被涂为橙(7)。缺陷像素本身保持其实际颜色不变。轴线像素不受影响。

**关键洞察**：必须先利用多数投票原则从有噪声的对称图案中重建理想对称，然后才能识别哪些是缺陷——直接观察单个像素是否"对称"不够，因为可能有对称位置上的像素本身就是被扰动的。

## 新题 5：双列图例编码平铺镜像序列

**组合逻辑**：[平铺tiling] + [镜像mirror] + [双列图例two_col_legend](创新：图例编码的不是颜色替换而是平铺方向指令) + [编码映射encoding_map]

**来源原语**：平铺(#8 bc4146bd), 镜像(#8 bc4146bd), 双列图例(#6 e4888269), 编码映射(#4 cb2d8a2c), 奇偶位交替翻转(#8 bc4146bd)

**依赖链**：图例中的颜色对编码翻转指令（左列色=该位置用原瓦片，右列色=该位置用镜像瓦片） → 输出网格中每个瓦片位置的颜色由瓦片边缘的标记色确定属于"原/镜"哪一类 → 按类别放置原瓦片或镜像瓦片。图例解读依赖颜色映射，瓦片选择依赖图例，最终布局依赖瓦片选择。

根据双列图例的颜色指令决定平铺序列中每个位置使用原瓦片还是左右镜像瓦片。

**输入结构**：约 14x7 网格，背景黑(0)。左半部分为一个 4x4 的瓦片区域（含多色图案，至少 3 种前景色），瓦片与其余部分之间有 1 列黑色间隔。右上角有一个 2 列 N 行（N=3~5）的双列图例块，图例完全填满无背景间隔。图例下方有一行 N 个单独的彩色标记像素，从左到右排列，每个标记像素的颜色恰好是图例中某一行的左列色或右列色。

**规则**：
1. 识别左侧瓦片（4x4 区域）和右侧双列图例。
2. 图例编码规则：每行的左列颜色代表"使用原瓦片"，右列颜色代表"使用左右镜像瓦片"。
3. 读取图例下方的标记像素行，从左到右共 N 个标记。
4. 对于第 i 个标记：在图例中找到包含该标记颜色的行。若标记颜色 = 该行左列色，则第 i 个平铺位置使用原瓦片；若 = 右列色，则使用镜像瓦片。
5. 输出：将 N 个瓦片（原或镜像）从左到右水平拼接，形成 4 x (4N) 的输出网格。

**关键洞察**：图例的两列不是传统的颜色替换映射，而是编码了二元选择指令；标记行中每个像素的颜色是对图例的查询键，决定瓦片朝向。

## 新题 6：竖直条高度编码禁区半径的路径绕行

**组合逻辑**：[连线draw_path] + [避障obstacle_avoidance] + [像素计数编码半径pixel_count_encodes_radius](创新：由竖直条的高度而非蓝色像素数编码) + [竖直条vertical_bar] + [条高度bar_height]

**来源原语**：连线(#4 cb2d8a2c), 避障(#4 cb2d8a2c), 像素计数编码半径(#4 cb2d8a2c), 竖直条(#11 2601afb7), 条高度(#11 2601afb7)

**依赖链**：竖直条的高度编码其排斥半径 → 路径必须绕开每个竖直条的排斥区域 → 路径从起点到对边需要根据所有排斥区综合规划。高度测量决定禁区大小，禁区大小约束路径走向，两者紧耦合。

一条绿色路径从网格边缘延伸到对边，绕开由竖直条高度定义的禁区。

**输入结构**：约 15x15 网格，背景青(8)。2~4 个红(2)竖直条（宽 1 像素，高度各异，范围 2~5 像素），底部对齐于网格底边。一个绿(3)像素位于网格左边缘的某行。

**规则**：
1. 每个红色竖直条的禁区半径 = 该条的高度（像素数）。即路径上的任何像素到该条任意像素的切比雪夫距离必须 > 该条高度。
2. 绿色起点向右延伸，目标为到达网格右边缘。路径仅沿水平或垂直方向移动（曼哈顿路径），每一步移动一个像素。
3. 路径选择规则：在满足所有禁区约束的前提下，选择总长度最短的路径。若存在等长路径，选择转弯次数最少的；仍有平局则选择最终到达右边缘时行号更小的。
4. 路径像素全部涂为绿(3)。原有的红色竖直条保持不变。

**关键洞察**：竖直条越高，其排斥范围越大——高度不只是视觉属性，而是空间约束的编码。求解者必须先建立"高度→半径"映射，再在多个禁区的叠加约束下规划路径。

## 新题 7：格网分区内的重力沉降与跨区透明叠加

**组合逻辑**：[重力沉降gravity_settling](创新：在格网的每个分区内独立执行) + [透明叠加transparent_overlay](创新：叠加的对象是各分区沉降后的结果) + [分隔线划分separator_partition] + [中心对齐center_alignment]

**来源原语**：重力沉降(#17 1e0a9b12), 透明叠加(#1 c8cbb738, #20 6a11f6da), 分隔线划分(#16 39e1d7f9), 中心对齐(#1 c8cbb738)

**依赖链**：分隔线将输入划分为多个等大分区 → 每个分区内独立执行重力沉降 → 沉降后将所有分区中心对齐叠加为一个输出 → 叠加时非背景像素覆盖背景像素，多个非背景像素重叠时按分区从左到右的顺序决定优先级（右侧分区覆盖左侧）。

多个格网分区各自重力沉降后，中心对齐透明叠加为一幅输出，右侧分区优先。

**输入结构**：约 5x17 网格（5 行 17 列），背景黑(0)。2 条灰(5)竖直分隔线将网格等分为 3 个 5x5 的分区（分隔线各占 1 列，分区间距 = 分隔线宽 1）。每个分区内有 2~4 个散布的彩色像素（使用蓝(1)、红(2)、绿(3)、黄(4)中的若干色），各分区的颜色可能有重叠也可能不同。

**规则**：
1. 识别灰(5)竖直分隔线，将网格分为 3 个等大分区（不含分隔线列）。
2. 在每个 5x5 分区内，独立执行列内重力沉降：每列的非背景像素下落至底部，保持列内从上到下的相对顺序。
3. 生成 5x5 的输出画布，初始为全黑(0)。
4. 按从左到右的分区顺序（分区1、分区2、分区3），依次将每个沉降后的分区叠加到输出画布上：若分区像素为非背景色，则覆盖输出画布对应位置的值（无论之前是什么）。
5. 输出即为最终叠加结果。

**关键洞察**：分区内的重力沉降改变了像素的垂直分布，因此叠加时的遮挡关系不能直接从输入位置推断——必须先完成沉降再判断谁遮挡谁。同时，叠加优先级是空间序（左到右）而非颜色值。

## 新题 8：方向帽引导的循环填充与像素放大

**组合逻辑**：[射线延伸ray_extend] + [方向帽direction_cap](创新：帽的方向决定填充的循环方向) + [循环填充periodic_fill](创新：填充内容沿帽所指方向周期性重复) + [像素放大pixel_scaling]

**来源原语**：射线延伸(#9 4e469f39), 方向帽direction_cap(#9 4e469f39), 循环填充(#13 c1990cce), 像素放大(#12 f25fbde4), 帽向决定射线(#9 4e469f39)

**依赖链**：方向帽确定填充推进方向 → 循环填充沿该方向在框内部周期性铺色 → 填充完成后整体像素放大。帽的朝向决定周期方向（水平或垂直），周期模式决定内容，放大使细节可见。

根据矩形框顶部方向帽所指方向，用周期性颜色序列填充框内部，然后整体 2 倍放大。

**输入结构**：约 8x8 网格，背景黑(0)。1~2 个灰(5)空心矩形框（外壁宽 1 像素，内部为黑色，内部尺寸至少 3x3）。每个框的顶部外侧有一个 2 像素的方向帽（与框顶边相邻）：帽在左侧表示"向右填充"，帽在右侧表示"向左填充"。每个框的底部外侧有一行 2~3 个不同颜色的像素紧贴框底边，从左到右排列，构成颜色序列。

**规则**：
1. 对每个矩形框：
   - 读取方向帽位置（顶部左侧 or 右侧），确定填充方向（向右 or 向左）。
   - 读取底部颜色序列 S（长度为 L）。
   - 对框内部区域，沿填充方向以序列 S 做周期性列填充：若方向为"向右"，则内部第 1 列全部填 S[0]，第 2 列填 S[1]，...，第 k 列填 S[(k-1) mod L]；若方向为"向左"，则内部最右列填 S[0]，次右列填 S[1]，依此类推。
2. 填充完成后，将整个网格（含框、帽、底部序列）做 2 倍像素放大：每个像素变为 2x2 同色块。
3. 输出为放大后的网格。

**关键洞察**：方向帽看似只是装饰性的不对称标记，实际上编码了填充的起始边——同样的颜色序列在不同方向帽下产生镜像排列的内部图案。放大步骤使得仅看输出尺寸就能推断存在缩放关系。

## 新题 9：行列标签交叉表的链式颜色替换

**组合逻辑**：[填充fill based on row_col_intersection](创新：交叉填充的结果作为链式替换的输入) + [逐行顺序链式替换chain_replace] + [双列图例two_col_legend] + [行列交叉row_col_intersection]

**来源原语**：填充/行列交叉(#14 a406ac07), 链式替换(#6 e4888269), 双列图例(#6 e4888269), 行标签/列标签(#14 a406ac07)

**依赖链**：行/列标签确定交叉表的初始填充 → 图例定义链式颜色替换规则 → 对交叉表内容执行替换后输出最终颜色。初始填充产生的颜色是链式替换的输入，两步缺一不可。

先由行列标签生成颜色交叉表，再按双列图例对表中颜色做链式替换。

**输入结构**：约 8x8 网格，背景黑(0)。网格结构如下：右侧最后一列为行标签（每行一个非背景色），底部最后一行为列标签（每列一个非背景色），右下角(最后行最后列)为黑(0)。内部区域(7x7左上)初始全为黑(0)。使用的标签颜色有 3~4 种（如蓝(1)、红(2)、绿(3)、黄(4)）。在网格左上角有一个 2 列 2~3 行的双列图例块，颜色与标签颜色一致或相关。图例块占据内部区域的左上角位置。

**规则**：
1. 读取行标签（右边缘列，从上到下）和列标签（底边缘行，从左到右）。
2. 对内部区域中每个不被图例占据的单元格：若该格的行标签色 = 列标签色，则填充为该颜色；否则保持黑(0)。
3. 读取左上角图例（从上到下），每行表示一条替换规则：左列色 → 右列色。
4. 对步骤 2 填充后的所有内部单元格（含步骤 2 中已填充的），按图例行序从上到下逐条应用替换：若当前单元格颜色 = 当前规则的左列色，则替换为右列色，并继续检查后续规则（链式：同一像素可被多次替换）。
5. 图例本身在输出中被擦除为黑(0)。行列标签保持不变。

**关键洞察**：交叉表填充的"同色匹配"看似产生最终答案，但图例的链式替换会改变部分颜色——必须发现图例不是装饰而是后处理指令。特别是链式替换的顺序效应（A→B 后 B→C 使得原 A 最终变 C）需对比多示例才能识别。

## 新题 10：滑动波形与对称补全的联合约束

**组合逻辑**：[滑动shift/alternating_direction](创新：波形参数由对称轴位置决定) + [对称补全symmetry_complete] + [双轴对称biaxial_symmetry](创新：对称性约束与波形变换同时满足)

**来源原语**：滑动(#7 1c56ad9f), 逐行交替方向(#7 1c56ad9f), 对称补全(#10 60d73be6), 双轴对称(#10 60d73be6), 底行锚定(#7 1c56ad9f)

**依赖链**：输入仅在一个象限中有完整的波形图案（已应用交替行移位） → 需通过对称补全将该象限的像素反射到其他象限 → 但反射时必须对移位方向做相应翻转（水平反射后左移变右移，垂直反射后行序倒转）。对称补全和波形规则互为约束，不能独立执行。

将一个象限中的交替行移位图案通过双轴对称补全到整个网格，反射时正确翻转移位方向。

**输入结构**：约 11x11 网格，背景黑(0)。一条完整的灰(5)中间行（第 6 行）和一条完整的灰(5)中间列（第 6 列）构成十字轴线。左上象限（5x5 区域）包含一个蓝(1)前景图案：该图案是某个基础矩形形状经过"奇数行右移 1 像素"变换后的结果（形成锯齿状波形轮廓）。其他三个象限仅有背景色。

**规则**：
1. 识别十字轴线（中间灰行和灰列）。
2. 对左上象限中的每个蓝(1)像素 P(r, c)：
   - 水平反射到右上象限：P'(r, 10-c)。但因为反射翻转了水平方向，该像素所在行的移位方向也翻转（原本右移的行在右上象限对应位置需表现为左移效果——即直接反射坐标即可，因为镜像自然翻转了偏移方向）。
   - 垂直反射到左下象限：P''(10-r, c)。垂直反射后行序倒转，但波形锚定于轴线相邻行，所以从轴线向下数奇数行仍右移。
   - 双轴反射到右下象限：P'''(10-r, 10-c)。
3. 输出 = 输入 + 所有反射生成的蓝(1)像素。轴线保持灰(5)不变。

**关键洞察**：简单的坐标镜像在这里恰好正确处理了波形方向的翻转（因为镜像操作本身包含了方向反转），但求解者需要验证这一点——真正的难点是确认"对称补全"在有行偏移的图案上等价于直接坐标反射，而非先还原偏移再反射再重新偏移。
