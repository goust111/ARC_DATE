## 新题 1：膨胀光晕阻断射线

**组合逻辑**：[膨胀/dilation](作用对象从单色标记变为多色标记，光晕色由标记色决定) + [射线延伸/ray_extend](射线方向由标记色编码) + [颜色决定方向/color_determines_direction](复用) → 光晕作为射线终止条件（创新：膨胀产物成为另一操作的空间约束）

**来源原语**：膨胀(4258a5f9), 射线延伸(d968ffd4), 颜色决定方向(9b4c17c4), 标记像素(4258a5f9), 光晕(4258a5f9)

**依赖链**：膨胀为每个标记生成光晕边界 → 光晕边界成为其他标记射线的终止墙 → 射线方向由标记颜色编码 → 最终输出是光晕 + 射线的叠加图，射线长度取决于标记间的空间关系

[一句话总结：每个彩色标记先膨胀出光晕，再沿颜色指定的方向射出射线，射线遇到任意其他标记的光晕边界即停止]

**输入结构**：约 15x15 的黑(0)背景网格。散布 3~5 个孤立的单像素标记，颜色为红(2)、蓝(1)、绿(3)、黄(4)中的若干种（每个标记恰好一个像素）。标记之间的曼哈顿距离至少为 5（保证光晕互不重叠）。生成约束：每个标记沿其颜色指定方向的路径上，至少存在一个其他标记的光晕可达范围内（保证射线不会全部飞出网格）。

**规则**：
1. 对每个标记像素，将其 3x3 邻域（裁剪到网格边界内）涂为灰(5)，标记自身保持原色不变。
2. 确定每个标记的射线方向：红(2)向右，蓝(1)向上，绿(3)向下，黄(4)向左。
3. 从每个标记中心出发，沿该方向逐格延伸射线，将路径上的黑(0)背景像素涂为该标记的原色。
4. 射线在以下任一条件下停止（不含终止格）：遇到灰(5)像素（即另一标记的光晕）、遇到非黑非灰像素、到达网格边界。
5. 所有标记的光晕先绘制完毕，再同时绘制所有射线。射线之间若交叉（同一像素被两条射线覆盖），按标记在网格中从左上到右下的扫描顺序，先扫描到的标记的射线优先。

**关键洞察**：膨胀不仅是视觉装饰，它产生的灰色光晕充当了射线的物理障碍——标记的间距和方位共同决定每条射线的长度，需要对比多个示例才能确认"射线遇光晕即停"这一规则。

## 新题 2：对角复制遇障绕行

**组合逻辑**：[对角线偏移复制/diagonal_offset_copy](保留逐格偏移复制) + [绕行/detour](从直线路径绕行迁移到对角路径绕行，创新) + [障碍色决定绕行/obstacle_color_detour](复用蓝左绿右规则，但"左右"相对于对角方向重新定义)

**来源原语**：对角线偏移复制(d13f3404), 绕行(96a8c0cd), 障碍条(96a8c0cd), 障碍色决定绕行(96a8c0cd)

**依赖链**：前景图案沿右下对角逐格偏移复制 → 复制路径遇到障碍条时触发绕行 → 障碍颜色决定绕行偏转方向 → 绕行后恢复对角方向继续复制

[一句话总结：将前景图案沿右下对角逐格偏移复制到加倍画布上，途中遇蓝色横条向右平移一格绕过、遇绿色横条向左平移一格绕过，绕行后继续对角复制]

**输入结构**：约 8x8 的黑(0)背景网格。包含一个由橙(7)像素组成的稀疏前景图案（3~5 个像素，不构成规则几何形状）。网格中另有 1~2 条水平的蓝(1)或绿(3)单像素厚横条（宽度等于网格宽度，各占一整行）。横条不与前景图案所在行重叠。生成约束：横条位于前景图案下方（确保对角复制过程中会遇到障碍）。

**规则**：
1. 创建高度和宽度均为输入两倍的输出画布，填充黑(0)背景。
2. 将输入中的蓝(1)和绿(3)横条按原始行位置映射到输出画布（横条在输出中宽度也加倍，从第 0 列延伸到输出末列）。
3. 对前景图案的每个橙(7)像素 (r, c)，执行逐步对角复制：初始偏移量 k=0，当前横向漂移 d=0。对 k=0,1,2,...依次尝试放置该像素到 (r+k, c+k+d)：
   - 若目标行是蓝(1)横条行：不放置像素，d 增加 1（向右漂移），k 继续递增。
   - 若目标行是绿(3)横条行：不放置像素，d 减少 1（向左漂移），k 继续递增。
   - 若目标行为普通背景行且 (r+k, c+k+d) 在画布内：放置橙(7)像素。
   - 若超出画布边界：停止该像素的复制。
4. 横条像素始终保留，不被橙色像素覆盖。

**关键洞察**：对角复制不再是均匀平铺，而是被障碍条"折射"——每个前景像素的复制轨迹独立累积漂移量，需要对比多示例才能推断蓝条右偏、绿条左偏的规则。

## 新题 3：轨道滑动触发对齐填充

**组合逻辑**：[滑动/slide + 沿轨道进一槽位/advance_one_slot](保留轨道滑动机制) + [填充/fill + 同行列端点间填充/fill_between_aligned_endpoints](保留对齐填充) → 滑动结果决定哪些对象对齐从而触发填充（创新：运动产生的新空间关系触发后续操作）

**来源原语**：滑动(5168d44c), 轨道点(5168d44c), 等距排列(5168d44c), 填充(253bf280), 同行列端点间填充(253bf280), 行列对齐(253bf280)

**依赖链**：多个彩色对象沿各自轨道前进一槽位 → 滑动后检查哪些同色对象处于同行或同列 → 对齐的同色对象对之间填充连接线 → 填充颜色为该对象对的颜色

[一句话总结：多个彩色小方块沿各自的轨道滑动一步后，同色且对齐的方块之间画出同色连接线]

**输入结构**：约 15x15 的黑(0)背景网格。包含 2~3 条平行的灰(5)点轨道（水平或竖直方向，由等距灰点标记，间距 3 格）。每条轨道上有 1~2 个彩色小方块（2x2 像素，颜色为红(2)、蓝(1)、绿(3)之一），每个方块恰好覆盖一个轨道槽位。不同轨道上可能存在同色方块。生成约束：滑动一步后，至少存在一对同色方块处于同列（若轨道水平）或同行（若轨道竖直）对齐状态；滑动前该对不对齐。

**规则**：
1. 识别所有灰(5)点轨道及其方向（水平或竖直），和轨道上的彩色方块。
2. 将每个彩色方块沿其所在轨道方向前进一个槽位（即平移一个轨道间距的距离，方向为轨道点序号递增方向）。若前方无更多槽位，该方块不移动。
3. 移动完成后，检查所有同色方块对：若两个同色方块的中心处于同一行或同一列，则在它们之间（沿该行或列）将所有黑(0)背景像素涂为该颜色。
4. 灰(5)轨道点保持不变。填充线不覆盖非黑像素（若路径上有其他方块或灰点，跳过该像素继续）。
5. 若存在多对同色对齐方块，所有对均独立填充。

**关键洞察**：填充操作本身简单，但哪些对象对需要填充完全取决于滑动后的新位置——求解者必须先推断滑动规则，再发现"同色对齐即连线"的第二层规则，仅看单示例无法区分"滑动前已对齐"和"滑动后才对齐"。

## 新题 4：旋转态编码平移方向

**组合逻辑**：[形状匹配/shape_match + 含旋转反射变换/includes_rotation_reflection](识别形状及其变换态) + [平移/translate + 颜色编码位移/color_encoded_disp](将位移编码方式从颜色改为旋转态，创新) → 匹配结果的旋转态作为平移指令

**来源原语**：形状匹配(898e7135/50f325b5), 含旋转反射变换(50f325b5), 平移(342dd610), 颜色编码位移(342dd610), 八方向匹配(898e7135)

**依赖链**：识别网格中与模板匹配的对象 → 确定每个对象相对于模板的旋转角度 → 旋转角度编码平移方向 → 每个对象按其旋转态指定的方向平移固定距离

[一句话总结：网格中散布同一图形的旋转副本，每个副本相对模板的旋转角度决定它的移动方向，所有副本同时平移]

**输入结构**：约 14x14 的黑(0)背景网格。左上角有一个由青(8)像素组成的不对称小图形作为模板（4~6 像素，4-连通，无旋转对称性）。网格其余区域散布 3~5 个红(2)像素组成的图形，每个都是该模板在 0/90/180/270 度旋转下的精确副本（仅旋转，不含反射）。各副本互不接触，与模板也不接触。生成约束：所有副本平移后仍在网格内且互不重叠；模板图形无旋转对称性（确保旋转态唯一可判）。

**规则**：
1. 识别左上角的青(8)模板图形（最小包围框内的形状）。
2. 对网格中每个红(2)连通图形，确定它是模板的哪个旋转态：0度（原始方向）、90度顺时针、180度、270度顺时针。
3. 按旋转态确定平移方向和距离：0度 → 向右平移 2 格；90度 → 向下平移 2 格；180度 → 向左平移 2 格；270度 → 向上平移 2 格。
4. 擦除每个红色图形的原始位置（恢复为黑色），在新位置绘制该图形（保持红色和旋转态不变）。
5. 青(8)模板保持原位不动。所有红色图形同时移动（不存在移动顺序依赖）。

**关键洞察**：位移指令不来自颜色（所有可动对象同色），而是隐藏在对象相对于模板的旋转角度中——求解者必须先识别模板、再判断旋转态、最后推断旋转-方向映射，三层推理缺一不可。

## 新题 5：载体内滑动留痕补全

**组合逻辑**：[滑动/slide + 嵌入载体内/inside_carrier + 颜色决定方向/color_determines_direction](保留载体色编码方向) + [补全/completion + 缺口补另色/gaps_filled_other_color](将网格线补全改为载体缺口补全，创新) → 滑动产生的空缺触发补全操作

**来源原语**：滑动(9b4c17c4), 载体区域(9b4c17c4), 嵌入载体内(9b4c17c4), 颜色决定方向(9b4c17c4), 补全(4612dd53), 缺口补另色(4612dd53)

**依赖链**：识别载体色和嵌入对象 → 载体色决定对象滑动方向 → 对象滑动后在载体内留下空缺 → 空缺区域用第三种颜色填充标记运动轨迹

[一句话总结：嵌入彩色区域内的红色对象沿载体色指定方向滑动到边缘，滑动留下的空位用黄色填充以标记运动痕迹]

**输入结构**：约 12x12 的黑(0)背景网格。包含 2~3 个矩形载体区域（4-连通单色块，颜色为蓝(1)或绿(3)，尺寸约 3x8 或 8x3）。每个载体内嵌入一个红(2)的小型4-连通图形（3~5 像素，形状不规则）。红色图形完全被载体包围（不接触载体边界）。不同载体之间互不接触。生成约束：红色对象沿指定方向滑动到载体边缘时不会超出载体范围。

**规则**：
1. 识别每个红(2)连通对象及其所嵌入的载体区域（与红色对象 4-邻接的非红非黑色区域）。
2. 根据载体颜色确定滑动方向：蓝(1)载体内的红色对象向右滑动，绿(3)载体内的红色对象向左滑动。
3. 将红色对象沿指定方向平移，直到对象的包围框在该方向上紧贴载体区域的边界（对象形状和行不变，仅水平平移）。
4. 红色对象原始位置中，那些不与新位置重叠的像素（即对象"离开"的区域）用黄(4)填充。
5. 载体区域其余像素保持原色不变。

**关键洞察**：滑动和补全在源题中是完全无关的操作，这里通过"滑动产生空缺 → 空缺即为需补全的缺口"建立了因果耦合——黄色痕迹的形状完全取决于对象的原始位置与滑动距离的差，需要对比多示例确认痕迹色固定为黄色。

## 新题 6：分区压缩后列序重涂原图

**组合逻辑**：[压缩/compress + 分区采样/block_sampling](保留分区压缩提取颜色) + [重涂色/recolor + 列序映射颜色/column_rank_to_color](将列序映射从前景像素改为压缩结果驱动，创新) → 压缩产生的小网格编码了重涂规则

**来源原语**：压缩(5783df64), 分区采样(5783df64), 重涂色(575b1a71), 列归属(575b1a71), 列序映射颜色(575b1a71)

**依赖链**：将大网格 3x3 分区压缩为小网格 → 读取小网格每列中出现的非背景颜色种类数 → 列中颜色种类数决定该列对应的大网格列带的输出颜色 → 按种类数从少到多排列大网格列带并重涂

[一句话总结：将 3x3 分区网格压缩为 3x3 小图后，按每列颜色多样性从低到高的排序，将原大网格对应的列带分别涂为蓝、红、绿]

**输入结构**：约 12x9 的黑(0)背景网格（高 12 宽 9，可被 3 整除）。网格被隐式划分为 3x3 的等大矩形块（每块 4x3）。每个矩形块内恰好有一个非背景像素，颜色为红(2)、蓝(1)、绿(3)、黄(4)中的某一种。同一列的 3 个块中的颜色可能相同也可能不同。生成约束：三列的颜色多样性（去重后的颜色种类数）互不相同（分别为 1、2、3），确保排序无歧义。

**规则**：
1. 将输入网格按 3x3 分区压缩：每个 4x3 块提取其唯一非背景像素的颜色，得到一个 3x3 的颜色矩阵。
2. 对压缩后的 3x3 矩阵，计算每列的颜色多样性（该列 3 个颜色中去重后的种类数）。
3. 将三列按多样性从低到高排序，排名为 1、2、3。
4. 在输出中，将原始大网格中对应排名 1 列带（该列对应的所有 3 列像素宽的区域）的所有非背景像素涂为蓝(1)，排名 2 的涂为红(2)，排名 3 的涂为绿(3)。
5. 背景像素保持黑(0)不变。输出网格尺寸与输入相同。

**关键洞察**：压缩步骤不是最终输出，而是产生了一个"元数据层"，该元数据（列多样性排名）反过来指导对原始大网格的重涂色——必须对比多示例才能发现颜色多样性是排序依据而非颜色本身。

## 新题 7：连线膨胀叠加长度优先

**组合逻辑**：[连线/draw_line + 两点直线路径/straight_two_point](保留两点连线) + [膨胀/dilation + 邻域扩展/neighborhood_expand](从单像素膨胀改为线段膨胀，创新) + 按原色区分涂色(recolor_by_origin) → 线段长度决定膨胀叠加时的覆盖优先级（创新：几何属性编码优先级）

**来源原语**：连线(bcb3040b), 两点直线路径(bcb3040b), 膨胀(4258a5f9), 邻域扩展(4258a5f9), 按原色区分涂色(bcb3040b)

**依赖链**：识别同色标记对并连线 → 每条线段膨胀一格形成色带 → 色带重叠区域由线段长度决定优先色 → 短线段的色带覆盖长线段的色带

[一句话总结：同色标记对之间画线后每条线膨胀为宽带，重叠处由较短线段的颜色覆盖较长线段的颜色]

**输入结构**：约 15x15 的黑(0)背景网格。包含 3 对标记像素，每对同色（颜色分别为红(2)、蓝(1)、绿(3)）。每对标记处于同一行、同一列或同一 45 度对角线上。不同对的连线路径在膨胀后存在重叠区域。生成约束：三对标记的连线长度（含端点的像素数）互不相同；至少两对的膨胀带有重叠。

**规则**：
1. 识别三对同色标记像素（每种颜色恰好 2 个像素）。
2. 对每对标记，绘制包含端点的直线段（水平/竖直/45度对角），颜色为该对标记色。
3. 对每条线段，将线段上每个像素的 3x3 邻域（裁剪到网格内）涂为该线段颜色，形成膨胀带。线段像素本身也属于膨胀带。
4. 计算每条线段的长度（像素数）。当膨胀带重叠时（同一像素被多条线段的膨胀带覆盖），该像素取长度最短的线段的颜色。
5. 原始标记像素保持其颜色不变（即使被其他膨胀带覆盖）。

**关键洞察**：优先级不来自颜色编号或空间位置，而来自线段的几何长度——较短的线段"更强"，这需要对比多个重叠案例才能归纳出"短者优先"规则，而非更直觉的"后画覆盖前画"。

## 新题 8：角落裁剪分象限翻转平铺

**组合逻辑**：[角落图案/corner_pattern + 裁剪/crop + 角落对应/corner_correspondence](保留角落提取) + [交替翻转平铺/alternating_reflections_tiling](从单一精灵平铺改为四个不同角落各自平铺，创新) + [画布加倍/canvas_doubling](输出尺寸约束)

**来源原语**：角落图案(bc1d5164), 裁剪(bc1d5164), 角落对应(bc1d5164), 交替翻转平铺(8d5021e8), 画布加倍(d13f3404), 镜像(8d5021e8)

**依赖链**：从输入四角裁剪出四个不同图案 → 输出画布为输入的两倍大小并分为四象限 → 每个角落图案在其对应象限内做交替镜像平铺填满该象限

[一句话总结：输入四角各有一个不同的小图案，输出是加倍画布，每个象限由对应角落图案通过交替镜像平铺填满]

**输入结构**：约 8x8 的黑(0)背景网格（高宽均为偶数）。四个角落各有一个由不同颜色构成的小图案（每个占据 2x2 的角落区域）：左上角用红(2)，右上角用蓝(1)，左下角用绿(3)，右下角用黄(4)。每个 2x2 区域内至少有 1 个像素为该颜色、其余为黑(0)（即图案是稀疏的，不一定填满 2x2）。四个角落图案形状互不相同。网格中央区域全为黑色。

**规则**：
1. 裁剪输入四角的 2x2 区域作为四个图案块：左上(TL)、右上(TR)、左下(BL)、右下(BR)。
2. 创建输出画布，尺寸为输入的 2 倍（16x16），分为四个等大象限（各 8x8）。
3. 对每个象限，用其对应角落图案进行 2x2 交替镜像平铺填满：
   - 将象限划分为 2x2 的子块网格（4x4 个子块）。
   - 子块行列坐标 (i,j)：i 为偶数且 j 为偶数时放原图案；i 为偶数且 j 为奇数时放左右镜像；i 为奇数且 j 为偶数时放上下镜像；i 为奇数且 j 为奇数时放 180 度旋转。
4. 左上象限用 TL 图案平铺，右上象限用 TR 图案平铺，左下象限用 BL 图案平铺，右下象限用 BR 图案平铺。

**关键洞察**：与单精灵平铺不同，四个角落各有独立图案且平铺规则相同但素材不同——求解者需同时推断"角落对应象限"的映射关系和"交替镜像"的平铺规则，单看一个象限无法确定规则是平铺还是其他变换。

## 新题 9：重复色矩形射线相遇间隙分割

**组合逻辑**：[重复色才移动/repeated_color_moves](从识别移动对象改为识别射线发射者，创新) + [射线延伸/ray_extend](矩形向内射线) + [间隙对半分/gap_bisect + 奇数间隙留中线/odd_gap_midline](对射线间隙进行分割) + [贴边定位/border_aligned](保留边界矩形定位)

**来源原语**：重复色才移动(22208ba4), 贴边定位(22208ba4), 边界矩形(22208ba4), 射线延伸(d968ffd4), 间隙对半分(d968ffd4), 奇数间隙留中线(d968ffd4)

**依赖链**：识别哪种前景色出现多次（重复色） → 重复色矩形从各自贴边位置向网格内部射出射线 → 同轴相对的两条射线之间的间隙被对半分割各涂对应射线色 → 单例色矩形作为射线阻挡物

[一句话总结：贴边的重复色矩形各向内射出射线，两条相对射线之间的空隙对半分割并各涂半边，单例色矩形阻挡射线]

**输入结构**：约 13x13 的黑(0)背景网格。包含 4~5 个单色实心矩形（约 2x2 到 2x3），每个紧贴网格的某一边（上/下/左/右边缘）。其中一种颜色出现 2~3 次（重复色，如红(2)），其余颜色各出现一次（单例色，如蓝(1)、绿(3)）。生成约束：至少存在一对重复色矩形分别贴在相对的两边（如一个贴左边一个贴右边），且它们的行跨度有重叠；单例色矩形位于某对重复色矩形的射线路径上。

**规则**：
1. 统计各前景色的 4-连通对象数量，出现次数 >1 的颜色为重复色，出现次数 =1 的为单例色。
2. 每个重复色矩形从其不贴边的朝内面发射射线（与贴边方向相反），射线宽度等于矩形在垂直于射线方向上的跨度，颜色为该矩形颜色。
3. 射线逐格向内延伸，遇到以下情况停止：碰到任意非背景像素（包括单例色矩形或另一重复色矩形的射线），或到达网格对边。射线不含终止格。
4. 对于同一行带或列带上相向而行的两条重复色射线（来自贴相对边的同色矩形），它们之间的背景间隙进行对半分割：靠近左/上射线的一半涂为该射线颜色，靠近右/下射线的一半涂为另一射线颜色。若间隙像素数为奇数，正中间一行/列保持黑(0)背景。
5. 单例色矩形保持原位不变，其阻挡射线但不参与间隙分割。

**关键洞察**：重复色的身份判定（统计出现次数）是触发射线操作的前提，而单例色的功能从"不移动"变成了"射线障碍"——三层逻辑（身份判定 → 射线发射 → 间隙分割）严格顺序依赖，且奇偶间隙规则需要对比多示例才能确认。

## 新题 10：精灵环形拼接孔洞缩放自填充

**组合逻辑**：[精灵裁剪/sprite_crop + 环形拼接/ring_compose + 四方环排布/four_way_ring_layout](保留环形拼接生成框架) + [缩放对应/scale_correspondence + 孔洞槽位/hole_slot](从外部拼块匹配改为自身缩放匹配，创新) + [像素放大/pixel_upscale](缩放机制)

**来源原语**：精灵裁剪(2697da3f), 环形拼接(2697da3f), 四方环排布(2697da3f), 缩放对应(898e7135), 孔洞槽位(898e7135), 像素放大(898e7135), 中心空白区(2697da3f)

**依赖链**：裁剪前景精灵 → 环形拼接生成带中心空白的框架图 → 计算中心空白尺寸与精灵的缩放比 → 将精灵按比例缩小（像素采样）填入中心空白

[一句话总结：前景精灵经四方旋转/镜像拼接成环形框架后，中心空白区用精灵本身的缩小版填充]

**输入结构**：约 5x3 的黑(0)背景网格（小型输入）。包含一个由红(2)像素组成的不对称连通前景精灵（4~7 像素）。精灵不触及网格边界。精灵的包围框高 h 宽 w 满足 h=w+2 或类似关系（确保环形拼接后中心空白为正方形）。生成约束：精灵形状在缩小到中心空白尺寸后仍可辨识（即精灵的包围框尺寸是中心空白边长的整数倍）。

**规则**：
1. 裁剪前景精灵的最小包围框，得到高 h 宽 w 的精灵块。
2. 构建环形框架：创建边长为 h+2w 的正方形输出画布，填充黑(0)。
   - 左侧：在行 w 到 w+h-1、列 0 到 w-1 的区域放置原始精灵。
   - 上方：在行 0 到 w-1、列 w 到 w+h-1 的区域放置精灵顺时针旋转 90 度的版本。
   - 右侧：在行 w 到 w+h-1、列 w+h 到 h+2w-1 的区域放置精灵水平镜像的版本。
   - 下方：在行 w+h 到 h+2w-1、列 w 到 w+h-1 的区域放置精灵逆时针旋转 90 度的版本。
3. 中心空白区域为行 w 到 w+h-1、列 w 到 w+h-1，尺寸为 hxh。
4. 计算缩放因子 k = h/w（取整）。将原始精灵的每个像素缩放为 k 倍（每个前景像素变为 kxk 的色块），若缩放后的精灵尺寸恰好为 hxh，则直接填入中心；若不匹配，则将精灵以最近邻采样缩放到 hxh 后填入中心空白。
5. 填入中心的精灵颜色改为蓝(1)以区别于框架的红(2)。

**关键洞察**：环形拼接和孔洞填充在源题中来自完全不同的谜题，这里通过"拼接产生空洞 → 空洞由自身缩放版填充"构建了自指结构——精灵同时是框架的构件和填充物的来源，需要理解缩放对应关系才能确定中心内容。
