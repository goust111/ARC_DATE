## 新题 1：条件旋转与跨度连线

**组合逻辑**：[旋转/rotate](条件化：仅特定颜色的条旋转，创新) → [连线/connect + 首尾跨度填充/span_fill_between](作用于旋转后新涌现的行列对齐关系) → [重涂色/recolor](连接段使用第三色，已有)

**来源原语**：旋转+中心点不变+单像素宽条(#14 f0f8a26d), 连线+标记像素+同行列对齐+首尾跨度填充(#1 ded97339), 重涂色(#2 ce9e57f2)

**依赖链**：旋转改变条的朝向，从而创造出输入中不存在的行列对齐关系；连线操作依赖这些新对齐关系来确定连接位置。哪种颜色参与旋转是隐蔽规则，必须对比多个示例才能归纳。不旋转则无新对齐、无法产生正确连接；不连线则只有散落的旋转条。

将特定颜色的细条绕中心旋转 90 度，然后在旋转后同色且同行或同列的条端点之间画连接跨度。

**输入结构**：
- 约 12x12 的黑(0)背景网格。
- 散布着若干单像素宽的奇数长度直线段（3~7 像素），每段为 4-连通的水平或竖直细条。
- 细条有两种颜色：红(2)和蓝(1)，每种颜色至少 3 条。
- 任意两条的边界框互不相邻（至少间隔 1 格空行/列）。
- 生成约束：红(2)条旋转 90 度后，至少存在两对同色条共享同一行或同一列；这些对齐关系在旋转前不存在。蓝(1)条在原始位置也存在至少一对同行或同列对齐。

**规则**：
1. 识别所有单像素宽的直线段及其颜色。
2. 将所有红(2)条绕各自中心像素旋转 90 度（水平变竖直、竖直变水平），长度和中心位置不变。蓝(1)条保持原位不动。
3. 旋转后，对每一行：若该行包含至少两个同色条的像素，取同色像素中最左与最右之间的全部空白格（不含已有条像素的格），涂为绿(3)。对每种颜色分别独立执行此操作。
4. 对每一列执行相同逻辑：若该列包含至少两个同色条的像素，取同色像素中最上与最下之间的全部空白格，涂为绿(3)。
5. 若连接路径穿过另一种颜色的条，该条的像素保持原色不被覆盖。
6. 行连接和列连接的交叉点若均为空白格，涂为绿(3)。

**关键洞察**：只有红(2)条旋转而蓝(1)条不动——这一颜色条件在单个示例中无法唯一确定（可能恰好看似两色都旋转或都不旋转），必须对比多个示例中不同颜色条的行为差异才能归纳。旋转本身不是目的，而是为后续连线操作"制造"出新的对齐关系。

## 新题 2：镜像平铺后叶突射线切割

**组合逻辑**：[镜像+平铺/mirror+tiling](将输入做 2x2 反射平铺，已有) → [射线延伸/ray_extend](从平铺接缝处对向的叶突之间发射射线，创新：叶突配对由平铺涌现) → [擦除/erase](射线路径上的像素被清除为背景)

**来源原语**：镜像+平铺+双轴反射+象限排布+瓦片(#10 67e8384a), 射线延伸+叶状突起+突起定行列(#6 f1cefba8), 擦除(#9 54dc2872)

**依赖链**：镜像平铺使原本位于边缘的叶突在接缝处成对出现并指向内部；射线从这些成对内向叶突之间贯穿，切割平铺后的图案。没有平铺就没有成对内向叶突，没有叶突配对就没有切割线，没有切割就只是普通平铺。

将带有边缘叶突的图案做四象限镜像平铺，然后从接缝处相对的叶突对之间画贯穿线，擦除该线上的所有像素。

**输入结构**：
- 约 6x8 的黑(0)背景矩形网格（输出将扩展为约 12x16）。
- 网格内有一个蓝(1)像素组成的 4-连通图形，占据网格中央大部分区域，形状不规则但为单连通（无孔洞）。
- 图形某些靠近网格边缘的边界上有 2~4 个橙(7)单像素叶突，每个叶突从蓝色图形向外突出一格。叶突仅出现在网格的边缘行或边缘列（第 0 行、最后一行、第 0 列或最后一列）。
- 叶突分布在不同边（上、下、左、右各至多 1~2 个），使得镜像后叶突在接缝处能配对。
- 生成约束：每个叶突在网格的某一条边缘上，镜像后恰好与其镜像副本面对面。不同叶突对之间的切割线互不共线。

**规则**：
1. 将整个输入网格做 2x2 镜像平铺：左上象限放原图，右上象限放原图的左右镜像，左下象限放原图的上下镜像，右下象限放原图的水平和竖直双重镜像。
2. 平铺后，在竖直接缝处：原本位于右边缘列的叶突与其左右镜像副本面对面（两个橙色像素在同一行、相邻两列）。在水平接缝处：原本位于下边缘行的叶突与其上下镜像副本面对面（两个橙色像素在同一列、相邻两行）。
3. 对每对在接缝处相对的橙(7)叶突：沿它们的对齐方向（水平对则沿该行，竖直对则沿该列），将该行或该列上从输出网格左边界到右边界（或上边界到下边界）的所有像素替换为黑(0)背景。
4. 未在接缝处配对的叶突（位于输出网格外边缘的叶突）保持橙色不变。
5. 处理顺序：先处理所有水平方向的切割线（沿行），再处理竖直方向的切割线（沿列）。若两条切割线交叉，交叉点也为黑(0)。

**关键洞察**：叶突在输入中看似无关紧要的边缘小突起，平铺后因镜像对称而在接缝处形成面对面配对——这种配对关系是平铺操作的涌现产物，输入中完全不存在任何配对结构。切割线的数量和方向完全取决于叶突在输入中的边缘分布。

## 新题 3：精灵体对接与涌现腔室填充

**组合逻辑**：[对接拼合/docking + 连接点颜色匹配/connector_color_match](拼合两个精灵体，已有) → [填充/flood_fill + 邻接多数决/adjacent_majority_vote](对拼合后涌现的封闭腔室进行涂色，创新：腔室在对接前不存在) + [裁剪/crop](紧凑裁剪)

**来源原语**：对接拼合+连接点颜色匹配+连接点+精灵体(#16 20270e3b), 填充+连通腔室+分隔墙+正交邻接+邻接多数决(#7 7c8af763), 裁剪(#16 20270e3b)

**依赖链**：两个精灵体各自都有开口凹陷、不包含封闭腔室；对接后开口互补闭合，涌现出新的封闭区域。这些涌现腔室的填充颜色由邻接标记投票决定。不对接就没有腔室可填，不填充就不知道腔室颜色。

拼合两个开口互补的精灵体使其凹陷闭合形成腔室，然后根据相邻标记像素的多数颜色填充每个腔室。

**输入结构**：
- 约 15x10 的黑(0)背景网格。
- 两个灰(5)像素构成的 4-连通精灵体（每个约 8~15 像素），形状不规则，各自包含一个开口凹陷（类似 U 形或 C 形的局部缺口，使灰色边界不封闭）。
- 每个精灵体上有一个红(2)连接点像素，位于开口凹陷附近的边缘。
- 每个精灵体的灰色边界上另有若干单像素标记，颜色从蓝(1)、绿(3)、黄(4)中选取，每种颜色 1~2 个。标记像素替代该位置的灰色像素，属于精灵体边界的一部分。
- 两个精灵体在网格中分开放置，互不接触。
- 生成约束：当精灵体 B 平移使其红(2)连接点与精灵体 A 的红(2)连接点正交相邻时，两个精灵体的开口凹陷恰好互补闭合，形成 1~2 个被灰色（和标记色）像素完全包围的 4-连通黑色封闭腔室。每个腔室至少与 2 个不同颜色的标记像素正交相邻。

**规则**：
1. 识别两个精灵体及各自的红(2)连接点像素。
2. 选择边界框左上角更靠近网格左上角（按行优先、列次之）的精灵体为基座。
3. 将另一个精灵体整体平移，使其红(2)连接点位于基座红(2)连接点的正上方一格（同列、行号小 1）。
4. 将两个红(2)连接点都替换为灰(5)，融入精灵体主色。
5. 清除被平移精灵体在原位置留下的所有像素（恢复为黑(0)）。
6. 在合并后的图形中，识别所有被非黑像素完全包围的 4-连通黑(0)封闭区域（腔室）。
7. 对每个腔室：收集与该腔室正交相邻（上下左右）的所有非灰(5)非黑(0)的标记像素颜色。取出现次数最多的颜色填充该腔室的全部黑色像素。若两色平局，选择在整个合并图形中总出现次数更少的那种标记颜色。
8. 输出为合并后图形的紧凑裁剪——包围所有非黑像素的最小矩形。

**关键洞察**：每个精灵体单独看都是开口的、不包含封闭腔室——腔室是对接操作的涌现产物，求解者必须先推断对接规则并在脑中完成拼合，才能知道哪些区域需要填充以及填什么颜色。

## 新题 4：形状频次决定分裂方向与重涂

**组合逻辑**：[排序/sorting + 形状频次分组/shape_frequency_grouping + 旋转翻转不变/rotation_flip_invariant](按形状频次分组，已有) → [等分/equal_split + 重涂色/recolor](频次决定分裂轴向和目标色，创新：分裂方向不是全局固定而是由频次条件分支)

**来源原语**：排序+形状频次分组+旋转翻转不变+共享与唯一形状(#19 62593bfd), 重涂色+竖直条+等分+下半变色(#2 ce9e57f2), 颜色互换+前景对象+对象内双色配对+同对象内互换(#15 45737921)

**依赖链**：形状频次分组决定每个对象的分裂方向（水平还是竖直）而非全局固定方向。频次还决定重涂使用的目标颜色。不知道频次就不知道分裂方向，不知道方向就无法正确重涂。分组和分裂/重涂紧密耦合。

将对象按形状（旋转翻转不变的标准形式）分组，共享形状的对象水平等分后重涂下半部分，唯一形状的对象竖直等分后重涂右半部分。

**输入结构**：
- 约 14x14 的黑(0)背景网格。
- 散布着 5~7 个单色 4-连通前景对象，每个对象由 4~8 个像素组成，形状各异（不规则连通图形，不要求特定几何名称）。
- 每个对象有自己的颜色，从蓝(1)、红(2)、绿(3)、黄(4)、橙(7)中选取。不同对象可同色也可异色。
- 对象之间互不接触（边界框不重叠且间隔至少 1 格）。
- 生成约束：恰好有 2~3 个对象的归一化形状相同（旋转和翻转下的标准形式一致），构成"共享组"；其余对象的标准形状各自唯一。每个对象的边界框高度和宽度均 >= 2。

**规则**：
1. 计算每个对象的标准形状：取其二值掩码（仅看像素的有无，忽略颜色），枚举所有旋转（0/90/180/270 度）与翻转（原图和水平翻转各枚举 4 种旋转，共 8 种变体），取逐行拼接后字典序最小的掩码作为标准形式。
2. 统计每种标准形状的出现次数。出现 >= 2 次为"共享形状"，出现 1 次为"唯一形状"。
3. 对每个共享形状的对象：以其边界框为参照，将边界框沿水平中线分为上半和下半（上半取 ceil(h/2) 行，下半取 floor(h/2) 行，h 为边界框高度）。将下半区域内属于该对象的像素重涂为灰(5)，上半区域保持原色。
4. 对每个唯一形状的对象：以其边界框为参照，将边界框沿竖直中线分为左半和右半（左半取 ceil(w/2) 列，右半取 floor(w/2) 列，w 为边界框宽度）。将右半区域内属于该对象的像素重涂为品红(6)，左半区域保持原色。
5. 对象在网格中的位置不变。背景保持黑(0)。

**关键洞察**：分裂方向不是全局统一的，而是由每个对象的形状在全局中的出现频次动态决定——这一规则必须对比多个示例（观察不同频次分布导致的不同分裂方向）才能归纳。颜色不决定分裂方向，形状频次才决定。

## 新题 5：对角射线选择与颜色配对平移

**组合逻辑**：[射线延伸/ray_extend + 边界反射/boundary_reflection + 特定色反射射线/specific_reflects](对角射线遇红色镜面反弹，已有) → [颜色配对/color_pairing + 平移/translate + 锚点对齐目标/anchor_aligns](射线穿过的精灵体按嵌入标记颜色匹配孤立控制点并平移，创新：射线路径作为选择机制)

**来源原语**：射线延伸+对角射线种子+边界反射+反射镜段+特定色反射射线(#8 7e2bad24), 平移+多色精灵体+嵌入标记像素+孤立控制点+颜色配对+锚点对齐目标(#9 54dc2872), 擦除(#9 54dc2872)

**依赖链**：射线路径决定哪些精灵体被"选中"（射线穿过的才参与平移）。精灵体内嵌标记的颜色与孤立控制点颜色配对决定平移目标。射线提供选择、配对提供目标、平移执行移动——三者缺一不可。

从种子点发射对角射线并在红色镜面上反射，射线穿过的精灵体按嵌入标记颜色与孤立控制点匹配后平移到对应控制点。

**输入结构**：
- 约 16x16 的黑(0)背景网格。
- 一个蓝(1)对角射线种子：2~3 个蓝色像素沿对角线排列（如 (r,c), (r+1,c+1)），位于网格角落附近。
- 1~2 条红(2)水平或竖直线段（3~5 像素长），作为反射镜，位于网格中部区域。
- 3 个灰(5)像素构成的小型 4-连通精灵体（每个 3~5 像素），散布在网格不同区域。每个精灵体内含一个嵌入标记像素，颜色从绿(3)、黄(4)、橙(7)中选取，每个精灵体的标记颜色互不相同。
- 在网格边缘或角落处有与标记颜色一一对应的孤立单像素控制点：绿(3)、黄(4)、橙(7)各一个。
- 生成约束：射线从种子出发沿对角线延伸并在红色镜面反射后，恰好穿过其中 2 个精灵体（至少经过该精灵体的一个灰色像素），不穿过第 3 个。射线不穿过任何控制点。各精灵体的平移目标位置互不重叠。

**规则**：
1. 从蓝(1)种子像素序列的外端点出发（即远离其他种子像素的那一端），沿种子对角方向延伸射线，逐格前进。
2. 射线遇到红(2)镜面像素时反射：水平镜面（横向线段）翻转行移动方向（向下变向上或反之），竖直镜面（纵向线段）翻转列移动方向（向右变向左或反之）。红色像素本身不被射线覆盖。
3. 射线穿过的每个非红非蓝格染为蓝(1)，直到射线离开网格边界为止。
4. 识别射线路径上被穿过的精灵体——射线至少经过该精灵体的一个灰(5)像素即算穿过。
5. 对每个被穿过的精灵体：读取其嵌入标记颜色，找到网格中同颜色的孤立控制点。将该精灵体（全部像素含标记）整体平移，使嵌入标记像素的位置对齐到控制点位置。清除精灵体原位置的所有像素（恢复为黑色），消除已使用的控制点（该位置被精灵体的某个像素覆盖）。
6. 未被射线穿过的精灵体及其对应的控制点保持原位不动。
7. 平移按精灵体被射线首次穿过的先后顺序执行。若平移后精灵体部分超出网格边界，截断超出部分。

**关键洞察**：射线路径既是视觉线索也是选择机制——只有被射线"扫过"的精灵体才被激活并参与平移，其余精灵体留在原地。求解者必须先模拟射线的完整反射路径，才能知道哪些精灵体会移动、移向哪里。

## 新题 6：通道压缩驱动的路径交替涂色

**组合逻辑**：[滑动/sliding + 压缩到标记旁/compress_to_adjacent_marker](将走廊中的种子像素压缩到最近墙壁旁，已有原语但作用对象改为迷宫种子) → [洪泛填充/flood_fill + 路径奇偶交替涂色/alternating_color_by_path_parity](从压缩后的新位置开始交替涂色，已有但起点被滑动改变)

**来源原语**：滑动+孤立像素+行列对齐+压缩到标记旁(#12 ae3edfdc), 洪泛填充+迷宫走廊+种子像素+路径连通+路径奇偶交替涂色(#18 b782dc8a), 分隔墙(#7 7c8af763)

**依赖链**：滑动操作改变种子像素的位置（从走廊中段移到墙壁旁），种子位置的微小偏移直接改变了洪泛填充的起点，进而翻转了整条走廊的奇偶交替涂色模式。两步操作产生涌现效应——1~2 格的位移导致大面积颜色翻转。

将走廊中散布的彩色种子像素滑动压缩到最近的墙壁旁，然后从压缩后的位置开始沿走廊 BFS 交替涂色。

**输入结构**：
- 约 13x13 的网格，无统一背景色。
- 青(8)像素构成迷宫墙壁（单像素宽的连通结构），黑(0)像素构成走廊。
- 走廊中散布着 2 个非青非黑的种子像素：红(2)和黄(4)各一个。每个种子位于某条直线走廊的中段（非死胡同端点、非 T 字交叉口中心）。
- 每个种子在其所在走廊的延伸方向上，与最近的一面青(8)墙壁之间有 1~3 格黑色空隙。
- 生成约束：两个种子不在同一直线走廊段中。压缩后种子仍在走廊内（目标位置为黑色空格）。从压缩后的两个种子出发，通过走廊可到达所有黑色格。两个种子到网格中所有走廊格的 BFS 前沿至少存在一个碰撞格（同时被两个种子的前沿到达）。

**规则**：
1. 对每个种子像素（红(2)或黄(4)），沿其所在走廊的四个正交方向查找最近的青(8)墙壁像素。取距离最近的那面墙壁（若有多面距离相同，按上、右、下、左优先级选择）。
2. 将种子像素从原位清除（变为黑(0)），重新放置到紧贴该墙壁的相邻空格中（沿原方向移向墙壁，停在墙壁正交相邻的那一格）。
3. 从两个压缩后的种子同时开始 BFS 洪泛填充，步数从 0 开始计数（种子自身为步数 0）。
4. 种子自身保持原色（红或黄）不变。从步数 1 开始，每一步将当前前沿的黑(0)走廊格涂色：步数为奇数时涂该种子的原色，步数为偶数时涂另一个种子的颜色（红种子在偶数步涂黄、黄种子在偶数步涂红）。
5. 若两个种子的 BFS 前沿在同一步到达同一格，该格涂为灰(5)。若某格已被一个种子的前沿涂色，另一个种子的前沿不再覆盖该格。
6. 青(8)墙壁像素始终不变。BFS 只沿 4-连通方向扩展，不穿过墙壁。

**关键洞察**：种子压缩看似只是 1~2 格的微小位移，但由于交替涂色严格依赖 BFS 步数的奇偶性，起点的偏移导致从该种子出发的每条走廊的涂色模式整体翻转（奇偶互换）——这种"蝴蝶效应"式的结果差异是滑动与交替涂色组合后的涌现特性，单独看任一操作都不会产生。

## 新题 7：框内双色互换与嵌套压缩排序

**组合逻辑**：[颜色互换/color_swap + 框内限定/frame_interior_only](在每个矩形框的环形内部交换双色，已有) → [压缩/compress + 去噪取主色/denoise_majority](每层环形区域压缩为互换后的主色，创新：互换翻转了多数/少数关系) → [排序/sorting + 嵌套层次/nesting_hierarchy](按嵌套深度排列为一行颜色序列，创新：嵌套结构编码输出顺序)

**来源原语**：颜色互换+矩形边框+框内区域+框内限定(#20 7ee1c6ea), 压缩+去噪取主色(#4 996ec1f3), 排序+同心正方形层+嵌套层次+按边长降序排列(#5 c658a4bd)

**依赖链**：互换改变每层环形区域的主色（原少数色变为多数色）；压缩取主色时互换结果直接决定代表色；嵌套层次决定代表色在输出中的排列顺序。不互换则主色相反，不压缩则无代表色，不按嵌套排列则顺序错误。三步紧密耦合。

在每个嵌套矩形框的环形内部交换两色，然后用互换后的主色代表每层，最后按嵌套深度（外到内）输出一行颜色序列。

**输入结构**：
- 约 14x14 的黑(0)背景网格。
- 3~4 个灰(5)单像素宽矩形框，严格嵌套（每个框完全在外层框内部，框线不相交不接触，相邻框之间至少间隔 2 格）。
- 每个框与其内嵌框之间的环形区域（最内层框则为框内全部区域）填充着两种非黑(0)非灰(5)颜色的像素，形成不规则的棋盘状或随机马赛克图案。每层环形区域的两种颜色对各不相同。
  - 示例：最外层环形区域为蓝(1)和红(2)，次外层为绿(3)和黄(4)，最内层为橙(7)和品红(6)。
- 每层环形区域中，两种颜色的像素数量不相等，比例约 6:4 到 7:3（一种为多数色，另一种为少数色）。
- 生成约束：所有矩形框的边长互不相同。每层环形区域恰好包含两种非黑非灰颜色。

**规则**：
1. 识别所有灰(5)矩形框，按边界框面积从大到小排列，确定嵌套深度（最外层深度 1，次外层深度 2，最内层深度 N）。
2. 对每层：取该层的环形内部区域（该框内侧所有格减去下一层框及其包含的所有格；最内层框则取框内全部格）。
3. 在每层环形内部，交换该区域的两种非黑非灰颜色（A 的全部像素变为 B，B 的全部像素变为 A）。
4. 交换后，对每层环形内部统计两种颜色的像素数，取数量更多的颜色作为该层的"代表色"。
5. 输出为 1 行 N 列的网格（N 为框的数量），从左到右按嵌套深度 1 到 N 排列各层的代表色。

**关键洞察**：互换操作翻转了多数与少数的关系——原本在某层中占多数的颜色在互换后变为少数，原本的少数色成为新的多数色并成为代表色。求解者若跳过互换直接取主色，会得到完全相反的答案。

## 新题 8：标记跨度连线构建隐式分区与区域压缩

**组合逻辑**：[连线/connect + 首尾跨度填充/span_fill_between](同色标记像素行列连线，形成网格状分隔线，已有原语但功能从"连接"变为"分区") → [压缩/compress + 含标记涂标记色/marker_presence_color](连线划分出的区域按内含第二种标记的有无压缩为代表色，创新：连线结果作为隐式坐标系)

**来源原语**：连线+标记像素+线段+同行列对齐+首尾跨度填充(#1 ded97339), 压缩+粗粒度块+阵列排布+含标记涂标记色(#3 e57337a4), 去噪取主色+忽略干扰项(#4 996ec1f3)

**依赖链**：连线操作将散布的红色标记连成水平和竖直线段，这些线段将网格隐式划分为若干矩形区域；随后每个区域根据其中是否包含蓝色标记来确定输出颜色。连线决定分区方式，分区决定压缩结果——连线不是为了"画线"而是为了"建坐标系"。

将同色标记像素沿行列连线形成网格分隔线，然后将每个被分隔出的区域压缩为一个像素，颜色取决于区域内是否含有第二种标记色。

**输入结构**：
- 约 12x12 的黑(0)背景网格。
- 红(2)标记像素散布在网格中。这些红色像素的分布满足：某些像素共享同一行，某些共享同一列，使得行列连线后能形成完整的网格状分隔。每行至多 2 个红色像素，每列至多 2 个。
- 另有若干蓝(1)标记像素（3~6 个）散布在网格中，位置不与红色像素重合。
- 可能存在少量黄(4)干扰像素（0~2 个），它们不参与任何规则，输出中不体现。
- 生成约束：红色像素的行列连线将网格内部（连线范围之内）划分为 m x n 个矩形区域（m >= 2, n >= 2）。每个区域内至多一个蓝色标记。连线范围之外的区域不参与压缩。

**规则**：
1. 对每一行：若该行包含至少 2 个红(2)像素，则将从该行最左红色像素到最右红色像素之间（含端点）的所有格涂为红(2)。
2. 对每一列：若该列包含至少 2 个红(2)像素，则将从该列最上红色像素到最下红色像素之间（含端点）的所有格涂为红(2)。
3. 连线后，红色线段在网格内形成网格状结构，将其包围的区域划分为 m x n 个矩形子区域。红色线段本身不属于任何子区域。连线范围之外的边缘区域不参与后续处理。
4. 输出为 m x n 的小网格。对每个子区域：若该区域内包含至少一个蓝(1)像素，则输出格为蓝(1)；否则输出格为黑(0)。黄(4)干扰像素被忽略，不影响判断。
5. 输出网格的行列顺序与输入中子区域的空间位置一致（左上子区域对应输出左上格，依此类推）。

**关键洞察**：红色标记的连线既不是最终输出的一部分，也不是装饰——它们构成隐式的分区指令，将连续空间离散化为压缩网格的坐标系。蓝色标记的绝对位置在连线之前毫无意义，只有其相对于红色分区的归属才决定输出。黄色像素是干扰项，必须对比多个示例才能发现它们不参与任何规则。
