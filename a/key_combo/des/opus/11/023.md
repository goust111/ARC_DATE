## 新题 1：射线穿越嵌套层变色

**组合逻辑**：[射线延伸](从缺口发射) → [嵌套矩形](射线穿越边界时变色) → [重涂色](射线颜色由穿越层数决定)

**来源原语**：射线延伸(e12f9a14)、嵌套矩形(5751f35e)、重涂色(25094a63)、由外到内嵌套(5751f35e)、框架缺口(e12f9a14)

**依赖链**：射线的发射方向由缺口位置决定；射线每穿过一层嵌套矩形的边界，其颜色按固定映射切换一次；最终射线在画布上留下的是分段变色的线条，每段颜色编码了该段所处的嵌套深度。

输入中存在同心嵌套的矩形框和发射源，输出是从发射源出发的分段变色射线，每段颜色反映穿越了几层边界。

**输入结构**：约 18x18 网格，黑(0)背景。3~4 层同心嵌套的单像素宽矩形框，每层框颜色不同（外到内依次为绿(3)、蓝(1)、红(2)、黄(4)之一）。最外层框的某一边有一个 1 像素宽的缺口，缺口处放置一个灰(5)像素作为发射源。嵌套框之间间距 2~3 像素，框的边界框尺寸依次递减。每层框仅有完整四边，无其他缺口。生成约束：发射源所在边与缺口方向保证射线沿水平或垂直方向能依次穿过所有层。

**规则**：
1. 从灰(5)发射源出发，沿缺口朝内的基数方向（上/下/左/右）发射一条射线，射线延伸至网格边界。
2. 射线初始颜色为灰(5)。
3. 射线每穿过一层矩形框的边界像素时，从该边界像素的下一个像素开始，射线颜色切换为该层框的颜色。框边界像素本身不被射线覆盖（保持框原色）。
4. 射线穿出最内层后，颜色保持为最内层框的颜色直到网格边界。
5. 发射源像素保持灰(5)不变。
6. 输出仅改变射线路径上的背景像素，其余像素（框、发射源）保持不变。

**关键洞察**：射线的分段颜色不是预设的，而是由它实际穿越的每一层框的颜色动态决定——必须对比多个示例才能发现"射线颜色 = 最近穿越的框的颜色"这一规则，而非基于嵌套深度的固定映射。

## 新题 2：压缩符号后按碰撞距离重力堆叠

**组合逻辑**：[压缩](空心符号→单像素) → [重力下落](按标记方向下落) → [碰撞阻挡](先到者阻挡后到者)，其中碰撞顺序由压缩前符号的像素数决定

**来源原语**：压缩(afe3afe9)、空心符号(afe3afe9)、重力下落(afe3afe9)、碰撞阻挡(05f2a901)、边缘标记线(afe3afe9)、计数(1fad071e)

**依赖链**：压缩操作将空心符号简化为单像素后才能执行重力下落；重力方向由边缘标记线决定；多个像素落向同一列时的堆叠顺序由压缩前该符号的实际像素数（孔洞面积不同导致像素数不同）从大到小决定——像素数多的先落。

将散布的空心符号压缩为像素，按标记方向做重力堆叠，堆叠优先级由原符号的像素数决定。

**输入结构**：约 15x15 网格，黑(0)背景。顶边为完整的一行橙(7)像素作为边缘标记线。网格内散布 5~7 个 3x3 空心符号（外框8像素，中心1像素为背景），每个符号的颜色为蓝(1)、红(2)、绿(3)之一。同色符号可能有多个。关键区别：部分符号的外框有 1~2 个像素缺失（即像素数为 6 或 7 而非满 8），导致不同符号的实际前景像素数不同。符号之间互不接触，各符号中心位于不同的粗网格位置。生成约束：同一列（压缩后坐标）上至多 3 个符号，确保堆叠后不超出网格。

**规则**：
1. 将每个 3x3 空心符号替换为位于其中心格的一个像素，颜色与该符号相同。
2. 边缘标记线在顶边→重力方向为向上（即所有压缩像素向上滑动）。
3. 同一列中有多个像素时，按各像素对应的原符号前景像素数从大到小排序，像素数多的最先到达（最靠近标记边），像素数少的依次堆在其后。像素数相同时，保持原行坐标较小者更靠近标记边。
4. 像素堆叠从标记边下方第一行开始（即第 1 行），依次向远离标记边方向排列。
5. 标记线本身保留在输出中。

**关键洞察**：需要对比多个示例才能发现堆叠顺序不是由原位置决定，而是由压缩前符号的实际像素数（外框完整度）决定——缺口越少的符号优先级越高。

## 新题 3：十字分割后面板内计数决定叠加层序

**组合逻辑**：[裁剪](十字分割为四面板) → [计数](各面板前景像素数) → [透明叠加](计数结果决定图层优先级)

**来源原语**：裁剪/十字分隔线(e99362f0)、面板(e99362f0)、计数(1fad071e/794b24be)、透明叠加(e99362f0)、图层优先级(e99362f0)

**依赖链**：十字分割产生四面板是叠加的前提；但叠加的图层优先级不再由面板的象限位置决定（参考题 e99362f0 的做法），而是由每个面板内非背景像素数量决定——像素少的在底层、像素多的在顶层。计数结果改变了叠加行为。

去掉十字分隔线，按面板内前景像素数从少到多依次叠加四个面板。

**输入结构**：约 13x13 网格（奇数边长）。灰(5)像素形成一条完整的十字线（一条贯穿全宽的水平线 + 一条贯穿全高的垂直线），将网格分为四个大小相等的矩形面板。每个面板的背景为黑(0)，前景为单一颜色（四个面板颜色互不相同，从蓝(1)、红(2)、绿(3)、黄(4)中选取）。每个面板内的前景像素数互不相同（分别为 3、5、7、9 个像素），形成不规则的 4-连通小图形。生成约束：四个面板的前景像素数严格互不相同，确保层序唯一确定。

**规则**：
1. 移除灰(5)十字分隔线，将四个面板对齐到相同的局部坐标系（左上角对齐）。
2. 统计每个面板内非黑像素的总数。
3. 按像素数从少到多排列四个面板，像素最少的作为最底层，像素最多的作为最顶层。
4. 从底层到顶层依次绘制：后绘制的非黑像素覆盖先绘制的。
5. 输出尺寸等于单个面板尺寸。

**关键洞察**：层序不由面板的空间位置（象限）决定，而由面板内容的像素数量决定——必须数清每个面板的前景像素数才能确定哪个面板在最上层。

## 新题 4：裂缝分离后两半各按自身宽度平移

**组合逻辑**：[擦除](裂缝标记线) → [沿短轴分裂](分为两半) → [平移](每半按自身边界框宽度向外平移)

**来源原语**：擦除(2faf500b)、裂缝标记线(2faf500b)、沿短轴分裂(2faf500b)、平移(64a7c07e)、按自身宽度平移(64a7c07e)、两侧等距分离(2faf500b)

**依赖链**：裂缝的方向决定了分裂轴向（短轴分裂）；分裂后每一半成为独立对象，其边界框宽度决定了该半的平移距离。与参考题 2faf500b（固定分离1像素）和 64a7c07e（整体对象按自身宽度右移）都不同——这里是分裂产生的碎片各自按各自的宽度向外分离。

擦除裂缝后将对象分为两半，每半按自己的边界框宽度向外平移远离裂缝。

**输入结构**：约 16x20 网格，黑(0)背景。包含 2~3 个互不接触的 8-连通前景对象，每个对象由主体色（蓝(1)或绿(3)）和裂缝标记色红(2)组成。每个对象的边界框为非正方形（宽>高 或 高>宽）。裂缝标记像素沿对象短轴方向形成一条完整切割线（如宽对象中有一列红像素从上到下贯穿对象）。裂缝将对象分为左右两半（或上下两半），两半的宽度可能不同。生成约束：每个对象的两半在各自平移后不与其他对象重叠，网格有足够空间容纳平移后的结果。

**规则**：
1. 对每个对象，擦除所有红(2)裂缝标记像素（替换为黑(0)背景）。
2. 裂缝方向沿对象边界框的短轴：宽对象的裂缝为垂直线，高对象的裂缝为水平线。
3. 擦除裂缝后，对象被分为两个独立的 8-连通分量（左半和右半，或上半和下半）。
4. 计算每个分量自身的边界框宽度 W（对于垂直裂缝的情况）或高度 H（对于水平裂缝的情况）。
5. 垂直裂缝：左半向左平移其自身宽度 W_left 个像素，右半向右平移其自身宽度 W_right 个像素。水平裂缝：上半向上平移其自身高度 H_top 个像素，下半向下平移其自身高度 H_bottom 个像素。
6. 超出网格边界的像素直接丢弃。

**关键洞察**：分离距离不是固定的，而是取决于每个碎片自身的尺寸——两半如果宽度不同则移动距离不同，必须对比多个示例中不对称对象的行为才能归纳出"按自身宽度平移"而非"按固定量分离"。

## 新题 5：对角连线后触发点处描边扩展

**组合逻辑**：[连线](对角像素对连接) → [触发点分束](触发点改变连线行为) → [描边](触发点位置扩展为空心方框)

**来源原语**：连线(db695cfb)、对角像素对(db695cfb)、对角对齐(db695cfb)、触发像素(db695cfb)、触发点分束(db695cfb)、描边(913fb3ed)、中心扩展(913fb3ed)

**依赖链**：连线操作先在对角像素对之间画出对角线段；触发像素位于连线路径上，但不再发射垂直射线（参考题做法），而是以自身为中心向外扩展一个 3x3 空心描边框；描边框的颜色由触发像素颜色决定，且描边框会覆盖已绘制的对角连线。连线是描边的定位前提（只有位于连线路径上的触发像素才会被激活）。

先连接对角像素对，再对连线路径上的触发像素做中心描边扩展。

**输入结构**：约 14x14 网格，黑(0)背景。2~3 对蓝(1)像素，每对中两个像素位于同一条 45 度对角线上，间距 4~7 格。另有 2~4 个品红(6)像素散布在网格中，其中部分恰好位于某对蓝像素的对角连线路径上，部分不在任何连线路径上。生成约束：位于连线路径上的品红像素周围 3x3 区域内无其他非背景像素（确保描边框不冲突）；不在连线路径上的品红像素作为干扰项保持不变。

**规则**：
1. 对每对对角对齐的蓝(1)像素，绘制从一端到另一端的完整对角线段（颜色为蓝(1)），包含两端点。
2. 检查每个品红(6)像素：若其坐标恰好在某条已绘制的对角线段上（即属于该线段的像素集合），则该品红像素被"激活"。
3. 对每个被激活的品红(6)像素，以其为中心绘制 3x3 空心方框（8 个边界像素），颜色为黄(4)。品红像素本身保留为品红(6)。
4. 描边框覆盖其范围内已有的蓝色对角线像素（黄(4)覆盖蓝(1)）。
5. 未被激活的品红像素保持不变，不做任何扩展。

**关键洞察**：品红像素是否被激活取决于对角连线是否经过它——连线操作的结果决定了描边操作的目标集合，两个操作不可独立执行。未激活的品红像素是干扰项，需对比多个示例才能发现激活条件。

## 新题 6：边界色条滑动后交叉区拼接偏移

**组合逻辑**：[滑动](对象滑向匹配色边) → [交叉检测](滑动后对象重叠区域) → [拼接+偏移放置](交叉区提取并对角偏移放置)

**来源原语**：滑动(17829a00)、边界色条(17829a00)、同色滑向同色边(17829a00)、交叉(ba97ae07)、拼接(8618d23e)、对角偏移(8618d23e)

**依赖链**：滑动操作使不同颜色的对象分别移向上/下边界色条，滑动后原本不重叠的对象可能在中间区域形成交叉；交叉区域被识别后，从画布中裁出并以对角偏移方式拼接到一个新画布上。滑动的结果创造了交叉（原始输入中不存在），交叉区域的内容又决定了拼接的素材。

先滑动对象至匹配边界，识别滑动后形成的重叠区域，将所有重叠区域对角偏移拼接为输出。

**输入结构**：约 12x12 网格，黑(0)背景。顶行为完整的红(2)色条，底行为完整的蓝(1)色条。网格中有 2~3 个红(2)单色 4-连通对象和 2~3 个蓝(1)单色 4-连通对象（各 3~6 像素，不规则形状）。对象分布在网格中间区域，各对象间互不接触。生成约束：红对象向上滑动、蓝对象向下滑动后，恰好产生 2~3 个交叉区域（重叠像素），且交叉区域的边界框互不重叠。

**规则**：
1. 红(2)对象整体向上平移，直到其边界框顶边到达第 1 行（紧贴顶部色条下方）。蓝(1)对象整体向下平移，直到其边界框底边到达倒数第 2 行（紧贴底部色条上方）。水平位置不变。
2. 滑动完成后，找出所有被两个不同对象同时占据的像素位置，这些像素构成交叉区域。交叉区域中的像素颜色设为品红(6)。
3. 对每个 4-连通的交叉区域，计算其最小边界框并裁出（品红像素保留，其余为黑(0)）。
4. 将所有裁出的交叉区域块按其在原网格中从左上到右下的顺序排列，以对角偏移方式拼接：第一个块放在输出左上角，第二个块的左上角位于第一个块的右下角偏移 (1,1) 处，依此类推。块之间空隙填充黑(0)。
5. 输出仅包含拼接结果，不保留原始网格内容。

**关键洞察**：输入中不存在任何交叉——交叉是滑动操作的副产品。必须先正确执行滑动才能找到交叉位置，而交叉区域的数量和形状决定了最终拼接输出的结构。

## 新题 7：引导线定平铺带后噪声过滤显现隐藏矩形

**组合逻辑**：[平铺+引导线](确定输出带的位置) → [最大矩形检测](在平铺结果中寻找隐藏矩形) → [重涂色](将隐藏矩形重涂)

**来源原语**：平铺(15696249)、引导行或列(15696249)、引导线定填充带(15696249)、画布扩展(15696249)、最大矩形检测(25094a63)、最小边长过滤(25094a63)、重涂色(25094a63)、噪声背景(25094a63)

**依赖链**：输入瓦片中含有噪声和一个隐藏的单色矩形区域，但单个瓦片太小导致矩形被噪声淹没难以辨识；引导线确定平铺方向后，瓦片被复制多次形成长带——平铺使隐藏矩形在空间上重复出现，从而可以通过"同一相对位置多次出现同色像素"来确认矩形边界；最终对确认的矩形区域重涂色。

先按引导线平铺瓦片形成长带，再在平铺带中检测每个瓦片副本内的公共同色矩形区域并重涂。

**输入结构**：输入为 7x7 网格。大部分像素为多色噪声（从蓝(1)、红(2)、绿(3)、灰(5)中随机选取）。其中一行（或一列）所有像素为同一颜色橙(7)，形成引导线。在网格内存在一个 3x3 或 3x4 的隐藏纯色矩形区域（颜色为蓝(1)或红(2)或绿(3)之一），该矩形被噪声包围但不与引导线重叠。生成约束：隐藏矩形的颜色在噪声中也会零散出现（干扰），但矩形区域是唯一一个宽高都>=3 的纯色矩形。

**规则**：
1. 识别引导线（完整的纯色行或列，颜色为橙(7)）。
2. 创建扩展画布：若引导线为第 r 行，则输出为 7 行 x (7*7=49) 列，在块行 r 中水平平铺 7 份输入瓦片；若引导线为第 c 列，则输出为 (7*7=49) 行 x 7 列，在块列 c 中垂直平铺 7 份输入瓦片。其余位置为黑(0)。
3. 在平铺带的每一个瓦片副本中，找到宽>=3 且高>=3 的最大纯色矩形。
4. 将该矩形内所有像素重涂为黄(4)。对每个瓦片副本执行相同操作。
5. 引导线像素保持橙(7)不变。

**关键洞察**：平铺本身不是目的，而是使隐藏矩形在重复中变得可识别的手段——单个瓦片中矩形与噪声混淆，但平铺后同一位置反复出现同色块，求解者可利用重复确认矩形边界。规则本身是"找最大纯色矩形并重涂"，但难点在于需先完成平铺才能看清结构。

## 新题 8：空心符号像素数编码为对角射线长度

**组合逻辑**：[计数](空心符号的像素数) → [射线延伸](从符号中心发射对角射线) → [象限指示方向](符号内缺口位置决定射线方向)，射线长度 = 像素数

**来源原语**：计数(1fad071e/794b24be)、空心符号(afe3afe9)、射线延伸(db695cfb/252143c9)、象限指示方向(252143c9)、同色像素定角(252143c9)

**依赖链**：符号的像素数是计数操作的输出，直接作为射线长度参数；符号外框的缺口位置落在某个对角象限内，决定射线方向。两个信息必须同时提取才能确定输出：方向来自缺口位置（空间属性），长度来自像素数（数量属性）。

统计每个空心符号的前景像素数，从其中心沿缺口所指对角方向发射该长度的射线。

**输入结构**：约 15x15 网格，黑(0)背景。散布 3~5 个 3x3 空心符号，每个符号为单色（从蓝(1)、红(2)、绿(3)中选取），外框最多 8 像素。每个符号的外框恰好有 1 个像素缺失，缺口位于四角之一（左上、右上、左下、右下角像素）。不同符号的缺口位置和像素数可能不同（像素数范围 5~7）。符号之间间距>=5 像素。生成约束：从每个符号中心出发、沿缺口对角方向延伸其像素数步长后不超出网格边界，且不经过其他符号。

**规则**：
1. 对每个 3x3 空心符号，统计其非背景前景像素总数 N（范围 5~7）。
2. 确定缺口位置：缺口在左上角→射线方向为左上对角（-1,-1）；缺口在右上角→右上对角（-1,+1）；缺口在左下角→左下对角（+1,-1）；缺口在右下角→右下对角（+1,+1）。
3. 从符号中心像素出发（中心本身为背景色位置），沿确定方向画 N 个像素的对角线段，颜色为该符号的颜色。起点为中心的下一个对角位置（不含中心自身）。
4. 原符号像素保持不变。
5. 射线像素覆盖路径上的背景像素；若路径上遇到非背景像素则停止（不含该非背景像素）。

**关键洞察**：射线长度不是固定的，而是由源符号的具体像素数决定——缺口不仅指示方向，还通过减少像素数间接缩短了射线。必须对比多个缺口数量不同的符号才能归纳出"长度=像素数"的规则。

## 新题 9：图案迁移目标由边界框宽度排序决定

**组合逻辑**：[图案迁移](从带标记矩形提取图案) → [边界框决定偏移](目标矩形的放置) → [按自身宽度排序](迁移顺序由宽度决定，宽的图案覆盖窄的)

**来源原语**：图案迁移(57edb29d)、带标记矩形(57edb29d)、纯色矩形(57edb29d)、边距保持迁移(57edb29d)、边界框决定偏移(64a7c07e)、按自身宽度平移(64a7c07e)、大层先画小层覆盖(5751f35e)

**依赖链**：多个带标记矩形各携带一个图案，多个纯色矩形是迁移目标。迁移配对规则不由行范围重叠决定（参考题做法），而由宽度匹配决定——宽度相同的带标记矩形与纯色矩形配对。当一个纯色矩形匹配多个带标记矩形时，按带标记矩形的高度从小到大依次迁移（后迁移覆盖先迁移）。

将带标记矩形的图案迁移到宽度匹配的纯色矩形中，多源冲突时按高度排序覆盖。

**输入结构**：约 18x14 网格，黑(0)背景。左侧区域包含 3~4 个带标记矩形（底色为蓝(1)，标记像素为红(2)），宽度各异（3~6像素），高度各异（3~7像素）。右侧区域包含 2~3 个纯色矩形（全为绿(3)），宽度从左侧的矩形宽度中选取（允许多个左侧矩形与同一右侧矩形宽度相同）。所有矩形互不接触。生成约束：每个纯色矩形的高度>=所有与其宽度匹配的带标记矩形中最高者的高度，保证图案能完整迁移。

**规则**：
1. 对每个纯色绿(3)矩形，找到所有宽度与其相同的带标记矩形（蓝底红标记）。
2. 对匹配到的带标记矩形按高度从小到大排序。
3. 按排序顺序依次将每个带标记矩形的标记图案迁移到纯色矩形中：标记像素的相对位置（距左边界和距上边界的偏移）保持不变，标记色红(2)写入纯色矩形对应位置。
4. 后迁移的图案像素覆盖先迁移的（即高度最大的带标记矩形的图案最终在最上层）。
5. 纯色矩形中未被标记覆盖的像素保持绿(3)。
6. 左侧的带标记矩形在输出中保持不变。

**关键洞察**：配对规则基于宽度匹配而非空间邻近——看上去不相邻的矩形因宽度相同而关联。多源覆盖的顺序由高度决定，这需要对比存在冲突和不存在冲突的示例才能归纳。

## 新题 10：滑动碰撞位置编码为计数条形图

**组合逻辑**：[滑动](多对象向锚点滑动) → [碰撞阻挡](碰撞停止位置记录) → [计数+填充](碰撞像素总数编码为条形图)

**来源原语**：滑动(05f2a901)、碰撞阻挡(05f2a901)、锚点方块(05f2a901)、最短接触平移(05f2a901)、计数(1fad071e)、条形图(1fad071e)、计数编码为条长(1fad071e)、忽略干扰项(1fad071e)

**依赖链**：多个前景对象分别向各自的锚点滑动直到接触停止；滑动后统计所有发生了实际位移的对象中"与锚点接触的边界像素数"（接触面积）；该总数被编码为条形图输出。滑动结果决定了计数的对象（只有成功接触的才计数），计数结果决定了最终输出形态。

多个对象滑向锚点直到接触，统计所有接触边界像素总数，编码为条形图。

**输入结构**：约 14x14 网格，黑(0)背景。包含 1 个青(8)色 3x3 实心正方形作为中央锚点。锚点四周散布 3~5 个红(2)色 4-连通前景对象（各 3~6 像素，形状不规则），每个对象与锚点在水平或垂直方向上轴对齐（即存在共同的行区间或列区间使得基数方向滑动可接触锚点）。另有 1~2 个灰(5)像素作为干扰项散布在网格中。生成约束：每个红对象到锚点的滑动路径上无其他红对象阻挡；所有红对象滑动后接触像素总数<=9。

**规则**：
1. 忽略灰(5)干扰像素。
2. 对每个红(2)对象，确定其朝青(8)锚点的基数滑动方向（上/下/左/右中使其靠近锚点的方向）。
3. 将红对象沿该方向平移，直到其某一像素与锚点的某一像素 4-连通相邻（最短接触平移）。
4. 滑动完成后，对每个红对象统计其与锚点 4-连通相邻的像素数（接触面积）。
5. 将所有红对象的接触面积求和，得到总计数 C。
6. 输出为 1x9 的网格（1行9列）：从左起前 C 个像素填充红(2)，其余为黑(0)。

**关键洞察**：条形图的长度不是对象数量，而是所有对象接触锚点的总边界像素数——形状不同的对象接触面积不同，必须先完成滑动才能计算接触面积，而不能仅靠计数对象个数。

## 新题 11：标记方向观察后连通分量按距离重力堆叠

**组合逻辑**：[标记指定观察方向](边界标记确定重力方向) → [平移/重力下落](连通分量按该方向堆叠) → [碰撞阻挡+按自身宽度间距](堆叠间距等于各自宽度)

**来源原语**：标记指定观察方向(f341894c)、边界标记(f341894c)、重力下落(afe3afe9)、连通分量(64a7c07e)、碰撞阻挡(05f2a901)、按自身宽度平移(64a7c07e)

**依赖链**：边界标记确定"重力"方向（标记在哪一边，重力就指向哪一边）；所有连通分量沿该方向下落；但堆叠时相邻两个对象之间的间距不是 0（紧贴），而是等于后到者自身的边界框在垂直于重力方向上的宽度。这意味着宽的对象距离前一个对象更远，窄的对象更近。

边界标记定义重力方向，连通分量沿该方向下落，相邻对象间距等于后方对象的横向宽度。

**输入结构**：约 14x18 网格，黑(0)背景。某一边（上/下/左/右之一）有一整行或整列的栗(9)像素作为边界标记。网格内散布 4~6 个互不接触的 8-连通单色对象，颜色从蓝(1)、红(2)、绿(3)中选取，每个对象 3~8 像素，形状不规则。对象之间有充足的空间。生成约束：对象在重力方向堆叠后（含间距）不超出网格边界。

**规则**：
1. 边界标记在顶边→重力方向向上；在底边→向下；在左边→向左；在右边→向右。
2. 所有前景连通分量沿重力方向移动。按其在重力方向上的原始坐标排序（靠近目标边的先处理）。
3. 第一个（最靠近目标边的）对象移动到紧贴边界标记（间距0，即对象边缘在标记旁边一行/列）。
4. 后续每个对象依次堆叠：该对象与前一个已放置对象之间的间距（空行/列数）= 该对象自身在垂直于重力方向上的边界框尺寸。例如重力向下时，间距 = 该对象的边界框宽度。
5. 对象水平（或垂直，取决于重力方向）位置保持不变。
6. 边界标记保留在输出中。

**关键洞察**：间距不是固定值，而是依赖于每个对象自身的"横向"尺寸——宽对象间距大，窄对象间距小。需要对比不同宽度对象的堆叠结果才能归纳出此规则，仅看紧贴型堆叠会得出错误答案。
