## 新题 1：弹射计数决定缺口框填充色

**组合逻辑**：[射线延伸 + 碰撞反弹](射线在障碍间反弹) → [计数](统计弹射次数) → [洪泛填充 + 缺口矩形框](弹射数映射为填充颜色，射线终点选定目标框)

**来源原语**：射线延伸/碰撞反弹(508bd3b6)、计数(e48d4e1a/de1cd16c)、洪泛填充/缺口矩形框/缺口定射线向(292dd178)

**依赖链**：射线路径的弹射次数产生一个数值，该数值通过边缘图例映射为颜色；同时射线最终的行进方向与某缺口框的缺口朝向匹配，唯一确定哪个框被填充。弹射路径同时编码了"填什么色"和"填哪个框"。

一句话总结：一条对角射线在矩形障碍间反弹，弹射次数决定填充颜色，射线末段方向选中朝向匹配的缺口框进行内部填充。

**输入结构**：约 20x20 黑(0)背景网格。左下角有一个 2 像素的绿(3) 4-连通对角起点条，其中一端触及网格边缘。网格中散布 3~4 个红(2)单行或单列矩形障碍（宽或高为 1，长 3~5 像素）。网格右半区有 3 个橙(7)一像素厚的 5x5 缺口矩形框，每个框恰缺一个非角落边缘像素，三个框的缺口分别朝上、朝右、朝下（朝向各不相同）。网格顶边有一行 3 像素的颜色图例：从左到右依次为蓝(1)、黄(4)、品红(6)，分别对应弹射次数 1、2、3。生成约束：射线路径恰好经过 1~3 次弹射后进入某框的缺口，且射线末段方向与恰好一个框的缺口朝向一致。

**规则**：
1. 从绿起点条的边缘像素出发，沿穿过另一端点的对角方向发射射线（每步行/列各 +-1）。
2. 射线遇到红矩形障碍时，翻转撞击方向分量（水平撞翻转列增量，垂直撞翻转行增量），继续前进。将射线经过的所有背景像素涂为绿(3)。
3. 当射线进入某缺口框的缺口像素位置时停止（即射线下一步将进入框的内部区域）。
4. 统计射线从起点到终止所经历的弹射次数 N（1~3）。
5. 查顶边图例：第 N 个图例像素的颜色即为填充色 C。
6. 将射线终止处对应的缺口框的 3x3 内部区域全部填充为颜色 C。
7. 其他缺口框保持原样（内部仍为黑色背景）。

**关键洞察**：射线的物理模拟（弹射路径）同时编码了两个独立信息——弹射次数编码颜色，末段行进方向编码目标框——求解者必须完整追踪射线才能同时确定这两项。

## 新题 2：奇偶格点筛选后重力堆叠再计数渲染

**组合逻辑**：[坐标奇偶匹配](标记定义活跃格点) → [重力下落](活跃对象下落) → [计数渲染](每列堆叠高度渲染为计数条)

**来源原语**：坐标奇偶匹配/同奇偶背景涂色(d492a647)、重力下落(df9fd884)、计数渲染/标记数映射填充(c8b7cc0f)

**依赖链**：奇偶筛选决定哪些对象参与重力下落；下落后的堆叠结果决定每列的占用高度；高度值被渲染为底部计数条。删除奇偶筛选则所有对象都落下，结果不同；删除重力则无堆叠可计数；删除渲染则无最终输出形态变化。

一句话总结：仅让位于指定奇偶格点上的单像素对象做重力下落，然后在输出底部用计数条表示每列的堆叠数量。

**输入结构**：约 12x12 黑(0)背景网格。网格中散布约 12~16 个单像素前景对象，颜色均为青(8)。网格左上角(0,0)位置有一个红(2)标记像素。网格底部两行保留为空（作为计数渲染区）。生成约束：青像素随机分布在行 0~9、列 0~11 范围内，确保行列奇偶的分布大致均匀（奇偶各约一半）；底部两行（行 10、11）初始为空。

**规则**：
1. 红(2)标记像素位于 (0,0)：行奇偶=偶，列奇偶=偶。选中所有行列奇偶均为偶数的格点位置。
2. 保留红标记像素不动。对于每个青(8)像素：若其位于偶行且偶列（与红标记奇偶相同），标记为"活跃"；否则标记为"静止"。
3. 活跃像素执行重力下落：在各自所在列内向下移动直到碰到网格底边（行 9，即渲染区上方一行）或碰到该列中另一个已落定的活跃像素。静止像素从输出中擦除（消失）。
4. 落定后，统计每列中活跃像素的堆叠数量 K（0 到某正整数）。
5. 在输出的行 10~11（2 行高的渲染区）中，对每列：若 K>=1，将行 11 该列涂黄(4)；若 K>=2，将行 10 该列也涂黄(4)；K=0 则该列渲染区保持黑色。（即用底部 2 行做行主序计数渲染，最多表示 2）
6. 若某列堆叠数 K>2，仍只渲染 2 格（计数条高度上限为 2）。

**关键洞察**：静止像素在输出中完全消失而非保持原位，这意味着仅靠单个示例无法区分"奇偶筛选后下落"和"随机选择后下落"——必须对比多个示例中哪些位置的像素消失来归纳奇偶规则。

## 新题 3：旋转等价分组后按组内计数确定印章位置

**组合逻辑**：[形状匹配 + 旋转翻转等价](将精灵体分组) → [计数](组内成员数) → [印章覆盖 + 非重叠约束](组代表印章到计数决定的位置，大组优先)

**来源原语**：形状匹配/旋转翻转等价(6165ea8f)、计数(de1cd16c/e48d4e1a)、印章覆盖/最大重叠确定位置(d6542281)、非重叠约束/从大到小优先(31adaf00)

**依赖链**：等价分组决定哪些精灵体归为一类；组内成员数决定该组代表被印章到输出区的哪一列；大组优先的贪心顺序解决位置冲突。三者缺一则输出无法确定。

一句话总结：将散落的小精灵体按旋转/翻转等价分组，每组的成员数量决定其代表图案在输出区的水平放置列，组大者优先占位。

**输入结构**：约 18x18 黑(0)背景网格，分为上下两区。上区（行 0~11）散布 6~8 个 4-连通单色小图形（3~5 像素），每个图形颜色各异（使用蓝(1)、红(2)、绿(3)、黄(4)、灰(5)、品红(6)等），形状不规则但紧凑。下区（行 13~17）为 5 行高的空白输出区，行 12 为灰(5)水平分隔线。生成约束：上区图形按旋转/翻转等价关系恰好分为 2~3 组，每组 2~3 个成员；各图形的包围框不超过 3x3，互不重叠且间隔至少 1 像素。

**规则**：
1. 提取上区所有 4-连通前景图形，将每个图形归一化为其紧凑掩码（最小包围框内的二值模式）。
2. 比较所有图形对：若两个图形的归一化掩码在旋转 0/90/180/270 度或水平/垂直翻转后能完全重合，则它们属于同一等价组。
3. 对每个等价组，统计成员数量 K。
4. 每组选取一个代表（成员中包围框左上角行最小的那个；若行相同取列最小的），保留其原始颜色和形状。
5. 在下区放置代表图案：代表的包围框左上角行固定为 14（下区第二行），列位置 = (K-1) * 5（即成员数为 2 的组放在列 5，成员数为 3 的组放在列 10，成员数为 1 的放在列 0）。
6. 放置顺序：成员数多的组优先。若两组成员数相同，代表包围框面积大的优先。若后放置的代表与已放置的发生像素重叠，后者向右平移 1 列直到无冲突。
7. 上区所有原始图形在输出中擦除为背景色，灰分隔线保留。

**关键洞察**：等价判断必须穷举八种 dihedral 变换；成员数到列位置的映射规则（K*5 偏移）需要对比多示例才能确认，因为单示例中无法区分"按成员数"还是"按其他属性"排列。

## 新题 4：走廊路径长度编码括号框对象的平移量

**组合逻辑**：[射线延伸 + 碰撞转向](走廊路径追踪) → [计数](路径长度) → [平移 + 括号框/通道对齐](路径长度决定偏移，括号方向决定移动轴)

**来源原语**：射线延伸/碰撞转向/遇障碍直角转(6bcdb01e)、计数/计数决定偏移(e48d4e1a)、平移/括号框/通道对齐/目标底边对齐(df9fd884)

**依赖链**：走廊追踪产生路径长度数值；该数值编码平移距离；括号框的开口方向决定平移的轴向（水平或垂直）。不追踪路径则不知距离；不看括号方向则不知移动方向。

一句话总结：追踪由 blocker 像素定义的走廊路径，路径总长度决定将括号框内对象沿括号开口方向平移多少格。

**输入结构**：约 16x16 黑(0)背景网格。左半区有青(8) blocker 像素形成单像素宽走廊（总长约 8~14 格），走廊入口有一个 2 像素绿(3)起点条触及左边缘。右半区有一个红(2)括号框（U 形，3 像素高、开口朝右或朝下，由 5~6 个红像素组成）和一个蓝(1) 4-连通小图形（3~4 像素）位于括号内部。生成约束：走廊无分叉、无死胡同，从起点到出口（离开网格）有唯一路径；路径长度 L 满足 3 <= L <= 6；括号框内对象沿开口方向有足够空间移动 L 格而不出网格。

**规则**：
1. 从绿起点条的边缘像素出发，沿穿过另一像素的方向进入走廊。
2. 每步前进一格；若前方是 blocker，转向唯一可通行的垂直方向继续前进。将路径经过的每个背景像素涂绿(3)。
3. 当路径下一步离开网格边界时停止。统计路径总长度 L（含起点条的两个像素）。
4. 识别红(2)括号框的开口方向 D（开口缺失的那一侧：右/下/左/上）。
5. 将蓝(1)对象沿方向 D 平移 L 格。平移后擦除对象原位置（变为黑色背景）。
6. 括号框保持原位不动。

**关键洞察**：走廊的物理形态（弯折次数和方向）是干扰项——唯一有用的信息是总路径长度；而括号框的具体形状也是干扰项——唯一有用的是开口朝向。求解者需要同时忽略两种视觉干扰，提取各自的抽象属性。

## 新题 5：贪心正方形提取后缺口方向决定射线溢出与尺寸优先覆盖

**组合逻辑**：[区域提取 + 贪心选择 + 从大到小优先](提取非重叠最大正方形) → [缺口定射线向 + 射线延伸](每个被选正方形的外框缺口决定射线方向) → [冲突优先级](射线交叉时大方块的射线覆盖小方块的)

**来源原语**：区域提取/贪心选择/非重叠约束/从大到小优先/空白正方形区域(31adaf00)、缺口定射线向/射线延伸/洪泛填充(292dd178)、冲突优先级(d6542281)

**依赖链**：贪心选择确定哪些方块被选中（及其尺寸排名）；每个选中方块的缺口朝向决定射线方向；射线交叉时尺寸排名决定覆盖优先级。选择、方向、优先级三环缺一不可。

一句话总结：在灰色障碍中贪心提取最大非重叠黑色正方形区域，每个区域的外围灰框恰有一个缺口，从缺口向外射出射线并用该区域的尺寸等级色填充，射线交叉处大区域优先。

**输入结构**：约 22x22 黑(0)背景网格，灰(5)像素形成不规则的网状障碍结构，将黑色背景分割为大小不等的连通区域。其中 3~4 个黑色区域恰好是正方形（边长 2~5 不等），且每个正方形区域的灰色边框上恰好缺少一个非角落像素（形成缺口）。其余黑色区域为非正方形形状。生成约束：正方形区域互不重叠；每个正方形的缺口朝向使得射线路径不会立即碰到另一个正方形的边框（至少延伸 3 格才可能与其他射线交叉）。

**规则**：
1. 找出所有被灰色边框完全包围（除一个缺口外）的黑色正方形区域（边长 >= 2）。
2. 按边长从大到小排序选择（贪心）：若某候选正方形与已选正方形有像素重叠则跳过（本题生成约束保证不重叠，此步骤主要排除非正方形区域）。
3. 为每个选中的正方形分配颜色：最大的涂蓝(1)，第二大涂红(2)，第三大涂绿(3)，第四大涂黄(4)。用对应颜色填充该正方形内部。
4. 从每个正方形的缺口像素位置出发，沿缺口朝外的方向（垂直于缺失边所在的边）发射单像素宽射线，颜色与该正方形相同。射线逐格前进直到碰到灰色障碍或网格边缘停止。
5. 若两条射线经过同一像素，该像素取边长更大的正方形的射线颜色（大优先覆盖）。
6. 灰色障碍像素和未被选中的黑色区域保持不变。

**关键洞察**：非正方形黑色区域即使面积更大也不会被选中——选择条件是"正方形且有单缺口框"而非单纯面积最大；求解者容易误将最大连通区域当作候选。

## 新题 6：镜像模板深度由边界计数控制且控制像素定色

**组合逻辑**：[镜像 + 模板块](模板翻转到各象限) → [计数](象限边界的计数器像素决定激活深度) → [控制定颜色映射](控制像素为激活区着色)

**来源原语**：镜像/模板块/象限/翻转对应/控制定颜色映射/控制像素(cfb2ce5a)、计数/计数器像素/计数器消失(e48d4e1a)、标记数映射填充(c8b7cc0f)

**依赖链**：镜像确定每个象限中模板像素的位置分布；计数确定多少层被"点亮"；控制像素确定被点亮层的具体颜色。缺少镜像则不知道哪些位置属于模板；缺少计数则不知道显示多少；缺少控制像素则不知道显示什么颜色。

一句话总结：将模板翻转到四个象限，每个象限边框上的灰色计数器数量决定从外向内激活几层模板像素，被激活位置的颜色由该象限内的控制像素指定。

**输入结构**：约 15x15 黑(0)背景网格，被一像素宽的灰(5)十字线分为四个 7x7 象限（含边框则 15x15 总尺寸）。左上象限包含一个由橙(7)像素组成的完整模板图案（约 8~12 像素，形成一个有层次感的 4-连通图形，可分为外层和内层）。其余三个象限各含 1~2 个散落的控制像素（颜色为蓝(1)、红(2)或绿(3)中的一种，每象限内控制像素同色）。灰十字分隔线的每段（上、下、左、右四段，各长 7 像素）上有 0~3 个像素被替换为栗(9)色计数器像素。生成约束：模板图案可自然分为 2~3 个同心层（外层=与背景相邻的模板像素，内层=不与背景相邻的模板像素，若有第三层则为更内部）；每象限边框段上的栗色计数器数量 <= 模板层数。

**规则**：
1. 提取左上象限的橙(7)模板图案。对模板做层次分解：第 1 层 = 模板中与黑色背景 4-邻接的像素；第 2 层 = 去掉第 1 层后与背景 4-邻接的像素；以此类推。
2. 对每个非左上象限，执行对应翻转（右上=水平翻转，左下=垂直翻转，右下=双轴翻转），得到该象限的模板投影位置。
3. 对每个象限（含左上），统计与该象限相邻的两段灰色分隔线上的栗(9)计数器像素总数 K。左上象限计算上边框段+左边框段；右上计算上+右；左下计算左+下；右下计算右+下。
4. 每个象限仅激活前 K 层模板像素（从外到内：K=1 只显示第 1 层，K=2 显示第 1+2 层，K=0 则全部不显示）。
5. 被激活的模板像素位置：若该位置存在控制像素，取控制像素颜色；否则取该象限控制像素的颜色（同象限内所有控制像素同色，作为该象限的默认激活色）。左上象限若无控制像素则保持橙(7)。
6. 未被激活的模板位置变为黑色背景。栗(9)计数器像素在输出中恢复为灰(5)（计数器消失）。

**关键洞察**：同一个模板图案在四个象限中可能显示不同数量的层和不同颜色——必须同时读取分隔线上的计数器和象限内的控制像素颜色才能确定每个象限的最终呈现。

## 新题 7：柱状条算术决定边框方块排序模式

**组合逻辑**：[高度加减运算 + 颜色编码正负](计算算术结果) → [排序 + 颜色决定目标](算术结果决定排序依据) → [平移 + 行重叠内移](按排序结果重新放置方块)

**来源原语**：高度加减运算/柱状条/颜色编码正负/结果槽(37ce87bb)、排序/边框方块/颜色决定目标/距离优先排序/行重叠内移(b5ca7ac4)、平移(a1570a43)

**依赖链**：柱状条的算术结果产生一个有符号数值 N；N 的正负决定方块的排序方向（升序或降序）；|N| 的值决定排序键类型（按面积还是按距离）。算术结果既是模式选择器又是参数，单一环节的删除都导致排序规则不确定。

一句话总结：左区的彩色柱状条通过加减运算产生数值 N，N 的符号决定右区边框方块按距离升序或降序排列到目标边缘，|N| 决定目标是左边缘还是上边缘。

**输入结构**：约 20x25 黑(0)背景网格，垂直灰(5)分隔线将网格分为左区（列 0~7）和右区（列 9~24）。左区底部对齐有 4~5 根单像素宽柱状条：青(8)表示正值，红(2)表示负值，高度 1~6 不等。右区散布 3~4 个 5x5 边框方块（边框为蓝(1)或绿(3)，内部为黄(4)），各方块互不重叠且间距 >= 2。生成约束：算术结果 N = 总青高度 - 总红高度，满足 |N| 为 1 或 2 且 N != 0；方块位置保证按任何排序方式堆叠到边缘后不超出网格。

**规则**：
1. 计算左区算术：N = 所有青(8)柱状条高度之和 - 所有红(2)柱状条高度之和。
2. 确定目标边缘：若 |N| = 1，目标为右区的左边缘（列 9）；若 |N| = 2，目标为右区的上边缘（行 0）。
3. 确定排序方向：若 N > 0，按方块距目标边缘的距离从近到远排列（近者先放，贴边）；若 N < 0，按距离从远到近排列（远者先放，贴边）。
4. 距离定义：目标为左边缘时，距离 = 方块包围框左列 - 9；目标为上边缘时，距离 = 方块包围框顶行。
5. 按排序顺序依次将方块平移到目标边缘：第一个方块紧贴边缘；后续方块紧接前一个方块之后（水平堆叠或垂直堆叠，取决于目标边缘方向），间隔 0 像素。
6. 方块形状、边框色和内部色保持不变。左区柱状条和灰色分隔线保持不变。方块原位置擦除为黑色背景。

**关键洞察**：算术结果的绝对值和符号分别控制两个独立维度（目标边缘选择和排序方向），仅凭单个示例可能无法同时归纳这两条规则——需要对比 N 正负不同、|N| 不同的多个示例。

## 新题 8：奇偶格点与矩形框内部的交集填充

**组合逻辑**：[坐标奇偶匹配](标记定义格点) + [矩形框/框内包含](框定填充区域) → [洪泛填充](仅填充同时满足两条件的像素)——同时约束满足结构

**来源原语**：坐标奇偶匹配/同奇偶背景涂色/奇偶格点(d492a647)、矩形框/框内包含/忽略干扰项(c8b7cc0f)、洪泛填充/填充(292dd178/af902bf9)

**依赖链**：这不是流水线而是同时约束满足——输出的每个像素必须同时通过奇偶测试和框内测试。两个约束独立定义，取交集。单独一个约束不能确定输出。

一句话总结：只有同时位于标记像素的奇偶格点上且严格在矩形框内部的背景像素才被填充为标记色。

**输入结构**：约 13x13 黑(0)背景网格。网格中有一个由灰(5)像素组成的一像素厚矩形框（约 7x9 或 9x7 大小，不贴边，框内部全为黑色背景）。矩形框外部散布若干灰(5)干扰像素（3~5 个单像素，不与框相邻）。网格中有恰好一个红(2)标记像素，位于矩形框外部。生成约束：标记像素不在矩形框的边框上也不在框内；框的内部面积 >= 16 像素以确保交集非空且有明显图案。

**规则**：
1. 确定红(2)标记像素的行 r 和列 c。计算其行奇偶 P_r = r mod 2，列奇偶 P_c = c mod 2。
2. 定义奇偶格点集合：所有满足 (行 mod 2 = P_r) 且 (列 mod 2 = P_c) 的像素位置。
3. 确定灰(5)矩形框的内部区域（严格在框内，不含框边缘）。
4. 对每个黑(0)背景像素：若该像素同时属于奇偶格点集合且位于矩形框内部，则涂为红(2)。
5. 矩形框外部的格点位置、框内非格点位置、以及灰色像素（框和干扰像素）均保持不变。
6. 红标记像素本身保留。

**关键洞察**：框外的灰色干扰像素容易被误认为是第二个矩形或边界的一部分——实际上它们是纯干扰项，唯一的框是那个完整的闭合矩形；同时奇偶规则使得框内只有约 1/4 的像素被填充，形成棋盘格子状图案。

## 新题 9：角标记定义多矩形后按内部标记投票决定填充优先级

**组合逻辑**：[角标记 + 行列对齐](识别多个矩形) → [投票 + 标记归属区域 + 最多标记区胜出](每矩形内标记投票确定填充色) → [填充 + 距离优先排序](按距中心远近依次填充，后填覆盖先填)

**来源原语**：角标记/行列对齐/四角标记围定内部(af902bf9)、投票/标记归属区域/最多标记区胜出(de1cd16c)、填充(af902bf9)、距离(b8cdaf2b)、冲突优先级(d6542281)、忽略干扰项(c8b7cc0f/6165ea8f)

**依赖链**：角标记确定矩形边界；内部标记投票确定每个矩形的填充色；矩形中心到网格中心的距离确定填充顺序（即覆盖优先级）。矩形可能重叠，后填的覆盖先填的，因此距离排序实质性影响输出。

一句话总结：由角标记定义若干可重叠矩形，每个矩形内部散落的彩色标记投票决定其填充色，再按矩形中心距网格中心由远到近依次填充（近者后填，优先级高）。

**输入结构**：约 17x17 黑(0)背景网格。网格中有 3 组黄(4)角标记，每组 4 个像素定义一个矩形的四角（4 个黄像素共享两行两列）。三个矩形大小不同（约 4x4、5x6、6x5），允许部分重叠（重叠区域 2~6 像素）。每个矩形的内部（不含角标记行列上的像素）散布 2~4 个彩色标记像素，颜色为蓝(1)、红(2)、绿(3)中的一种，每个矩形内恰好有一个颜色出现次数最多（不出现平局）。矩形外部散布 3~5 个同样颜色的干扰标记像素。生成约束：三个矩形的填充色互不相同（投票结果各异）；至少有一对矩形存在非空重叠。

**规则**：
1. 找出所有黄(4)像素，将它们按行列对齐关系分为 3 组（每组 4 个像素恰好确定一个矩形的四角）。
2. 对每个矩形，确定其内部区域（严格在四角行列之间的像素）。
3. 统计每个矩形内部各颜色（非黄、非黑）的标记像素数量。出现次数最多的颜色为该矩形的填充色。忽略矩形外部的标记像素。
4. 计算每个矩形中心（行平均、列平均取整）到网格中心的曼哈顿距离。
5. 按距离从大到小排序。依次将每个矩形的内部区域填充为其对应填充色。后填充的覆盖先填充的像素。
6. 黄(4)角标记像素保留不变。矩形外部的干扰标记像素擦除为黑(0)。

**关键洞察**：重叠区域的最终颜色取决于哪个矩形离网格中心更近（后填充覆盖），而非取决于该区域本身的标记投票——这意味着求解者不能孤立地看每个重叠像素，必须先全局确定填充顺序。

## 新题 10：十字图案距离编码侧翼阶梯并用计数器选择保留方向

**组合逻辑**：[距离决定阶梯高度 + 侧翼列](距离生成阶梯) → [计数 + 计数器消失](计数器数量选择保留哪个方向的阶梯) → [擦除](删除未选中方向)

**来源原语**：距离决定阶梯高度/色条/侧翼列(b8cdaf2b)、计数/计数器像素/计数器消失(e48d4e1a)、十字图案(e48d4e1a)、擦除(1c02dbbe)

**依赖链**：十字图案提供中心参考和距离起点；距离计算生成四个方向的阶梯；计数器数量决定保留哪个方向（1=上、2=右、3=下、4=左）；未被选中的方向阶梯被擦除。距离产生形状，计数产生选择，两者合力才确定最终输出。

一句话总结：以十字图案为中心向四个方向生成距离递减的阶梯，灰色计数器的数量指定只保留其中一个方向的阶梯，其余方向擦除。

**输入结构**：约 15x15 黑(0)背景网格。中央有一个蓝(1)十字图案（一整行+一整列交叉，共占满该行和该列）。网格右上角区域有 1~4 个灰(5)计数器像素排成一列。生成约束：网格为奇数边长正方形以使十字中心恰在正中；计数器数量为 1~4 中的一个。

**规则**：
1. 确定蓝(1)十字图案所在的中心行 R 和中心列 C（行列交点）。
2. 对十字的四个方向生成阶梯：
   - 上方向：对行 R 上方的每一行 r（r < R），在列 C 两侧各放置一个红(2)像素，水平距离 = R - r（即越远离中心，两侧像素越靠外）。但只在该像素不超出网格范围时放置。
   - 右方向：对列 C 右方的每一列 c（c > C），在行 R 两侧各放置一个红(2)像素，垂直距离 = c - C。
   - 下方向：对行 R 下方的每一行 r（r > R），在列 C 两侧各放置一个红(2)像素，水平距离 = r - R。
   - 左方向：对列 C 左方的每一列 c（c < C），在行 R 两侧各放置一个红(2)像素，垂直距离 = C - c。
3. 统计灰(5)计数器像素数量 K（1~4）。
4. 方向映射：K=1 保留上方向，K=2 保留右方向，K=3 保留下方向，K=4 保留左方向。
5. 仅保留对应方向的红色阶梯像素，其他三个方向的阶梯像素不绘制（输出中不出现）。
6. 灰(5)计数器像素在输出中消失（变为黑色背景）。蓝(1)十字图案保留。

**关键洞察**：四个方向的阶梯形状由距离公式唯一确定（都是对称扩展），但只有一个方向出现在输出中——必须对比多示例中计数器数量与保留方向的对应关系才能归纳 K-方向映射规则。
