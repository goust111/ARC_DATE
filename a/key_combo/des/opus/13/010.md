## 新题 1：桥接决定填充还是镜像

**组合逻辑**：[连通判定](已有) + [洪泛填充](已有) + [镜像](已有)（创新：连通状态作为分支条件，将同一批标记像素路由到两种截然不同的用途）

**来源原语**：连通判定/桥接路径/连通性 ← 239be575；洪泛填充/封闭区域/标记像素/多数色决定填充 ← 4b6b68e5；镜像 ← 8d5021e8；轮廓框/包围 ← b9b7f026

**依赖链**：连通判定的结果决定每个框走哪条变换路径——镜像路径需要另一个框的标记布局作为空间模板，填充路径需要自身标记的颜色频次作为投票。删除连通判定则无法确定走哪条路径；删除标记像素则两条路径都缺少输入。

将封闭轮廓框中的标记像素，根据框之间的桥接连通状态，要么作为空间模板镜像复制到配对框中，要么作为颜色投票对本框进行洪泛填充。

**输入结构**：黑(0)背景，约 18x18 网格。散布 2~4 个灰(5)单色矩形轮廓框（1 像素宽边框，内部为背景色，各框不相邻，边界框尺寸约 4x4 至 6x6）。每个框内部有 2~4 个孤立标记像素（颜色各异，从红(2)、蓝(1)、绿(3)、黄(4)中取，同一框内可重复可不同）。部分框之间由青(8)色单像素宽的 4-连通路径相连（路径两端分别接触两个框的外边框像素，路径不分叉）。每条桥恰好连接两个框，同一个框至多被一条桥连接。生成约束：被桥连接的两个框的内部区域尺寸相同（宽高一致），以保证镜像可以精确对齐；未被桥连接的框内标记像素存在唯一众数颜色（无并列）。

**规则**：
1. 识别所有灰(5)矩形轮廓框及其封闭内部区域。
2. 通过青(8)桥接路径判断连通：若两个框的外边框像素被同一条 4-连通青路径连接，则它们构成"连通对"。
3. 对每个连通对中的两个框（按其边界框左上角的先行后列顺序记为"左框"和"右框"）：将左框内部标记像素的空间图案（保留各像素颜色）以内部区域的垂直中轴为对称轴水平镜像，写入右框内部对应位置。右框内原有的标记像素被覆盖。左框内部不变。
4. 对每个未被任何桥连接的孤立框：统计其内部标记像素的颜色频次，将整个封闭内部区域填充为频次最高的颜色。
5. 最终输出中，擦除所有青(8)桥接路径像素（设为背景色）并擦除所有孤立框内的原始标记像素（填充色已覆盖它们）。连通对中左框内的标记像素保留。

**关键洞察**：同一批标记像素在不同语境下扮演完全不同的角色——在被桥接的框中它们是空间几何模板（位置重要、颜色只是逐像素复制），在孤立框中它们是颜色投票（位置无关、只有颜色频次有意义）。这一双重角色无法从单个示例中看出，必须对比有桥和无桥的框才能归纳。

## 新题 2：重力落子创造封闭区域后按控制色填充

**组合逻辑**：[重力下落](已有) + [洪泛填充](创新：填充对象不是预存的框，而是重力落子与障碍物共同围合出的涌现区域) + [控制色定行为](创新：控制像素不再决定穿透/停靠，而是决定围合区域的填充颜色)

**来源原语**：重力下落/障碍物/控制像素/穿透或停靠 ← 963c33f8；洪泛填充/封闭区域/标记在封闭区域内 ← 4b6b68e5；控制色定行为 ← 963c33f8

**依赖链**：重力下落的着陆位置取决于障碍物分布 → 着陆后的像素与障碍物共同围合出封闭区域（涌现属性，单看障碍物或单看落子都不构成封闭）→ 每个封闭区域的填充颜色由落入该区域边界的控制像素颜色决定。删除重力则无封闭区域，删除控制色规则则无法确定填充颜色。

将顶部色条按重力下落到障碍物上，落子与障碍物围合出封闭区域，再根据边界上的控制像素颜色填充这些区域。

**输入结构**：黑(0)背景，约 15x20 网格。顶部两行为一条水平色条：第一行（最顶行）全部为栗(9)色像素，第二行每个像素为蓝(1)或红(2)，作为逐列控制像素。网格中下部散布灰(5)障碍像素，障碍像素排列为若干水平或竖直的短线段（2~5 像素长），彼此间留有间隙。障碍线段的排列方式使得：当色条各列下落并停靠在障碍上方后，停靠的色条像素与灰障碍物的组合恰好围合出若干矩形封闭背景区域（每个区域至少 2x2 大小）。生成约束：每个围合区域的上边界必定包含至少一个控制像素列的落点，且同一围合区域上边界的所有控制像素颜色相同（全蓝或全红），以保证填充颜色唯一确定。

**规则**：
1. 擦除顶部两行色条。
2. 将每列色条（上方栗(9)+下方控制色）视为一个 2x1 的竖直块，在该列沿重力方向（向下）下落，直到紧贴该列中第一个灰(5)障碍像素的正上方停靠。若该列无障碍像素，则停靠在网格最底行。
3. 所有列下落完毕后，识别由停靠的色条像素和灰(5)障碍像素共同形成的边界所围合的 4-连通背景(0)封闭区域。封闭区域定义：从该区域出发沿 4-连通方向无法到达网格边缘而不穿过栗(9)或灰(5)像素。
4. 对每个封闭区域：检查其上边界（紧邻该区域上方的栗色像素下方的控制像素）的颜色。若控制色为蓝(1)，将整个区域填充为蓝(1)；若控制色为红(2)，填充为红(2)。
5. 非封闭区域中的背景像素保持不变。

**关键洞察**：封闭区域不预先存在于输入中——它是重力下落后才涌现的几何属性。控制像素的"下落后位置"同时决定了它所在区域的边界形状和该区域的填充颜色，两个作用不可分割。求解者必须先在脑中模拟重力，再识别围合，最后查找控制色，三步紧密串联。

## 新题 3：补全被遮挡形状后按标尺匹配进行平铺

**组合逻辑**：[补全](已有) + [平铺](已有)（创新：补全操作恢复的真实边长成为标尺匹配的前提，标尺的附着图案成为平铺的内容源）

**来源原语**：补全/被遮挡形状/矩形足迹/前景遮挡/隐含区域重涂 ← 52df9849；平铺/标尺条/瓦片图案/端部附着/标尺长度决定重复 ← 9c1e755f

**依赖链**：被遮挡矩形的真实边长在补全前不可知 → 补全后暴露真实边长 → 标尺条长度与真实边长匹配决定配对 → 配对标尺的附着图案沿匹配边平铺填入矩形内部。删除补全步骤则真实边长未知、标尺无法正确配对；删除平铺步骤则矩形虽恢复但内部缺少图案。

先补全互相遮挡的矩形，再将边长匹配的标尺条上的图案平铺到对应矩形内部。

**输入结构**：黑(0)背景，约 18x20 网格。3~4 个不同颜色的实心矩形（颜色从蓝(1)、红(2)、绿(3)、黄(4)中取），部分矩形互相重叠（一个矩形的部分像素被另一颜色覆盖，但被遮挡矩形的完整矩形足迹内无背景像素——被遮挡的格子都被前景色占据）。在网格边缘（上边缘或右边缘），有 2~3 条灰(5)标尺条（水平或竖直的单像素宽直线段，长度各不相同），每条标尺的一端附着一个小的非灰非背景色矩形图案（2x2 或 2x3，图案由两种颜色组成，如橙(7)和青(8)的棋盘格或条纹）。生成约束：每个被遮挡矩形恢复后，其较长边的长度恰好等于某条标尺的长度（像素数），且此匹配唯一（不同矩形的较长边长度各不相同，各与不同标尺匹配）。未被遮挡的矩形没有匹配的标尺。

**规则**：
1. 识别所有被遮挡的矩形：对每种前景色，其边界框内全为前景像素（无背景）但含有其他前景色 → 该颜色的矩形被部分遮挡。
2. 补全每个被遮挡矩形：将其矩形足迹内所有非本色像素重涂为本色。所有矩形同时补全（各自恢复各自的足迹，按画家算法处理重叠：面积较小的矩形覆盖面积较大的）。
3. 补全后，测量每个矩形较长边的像素长度。
4. 将每个矩形与较长边长度相等的标尺条配对。
5. 对配对成功的矩形：取标尺附着的图案，沿矩形较长边方向周期性平铺，填满矩形的整个内部（矩形边框一像素宽保留原矩形颜色，内部区域被图案平铺覆盖）。平铺从矩形内部的左上角开始，图案在较长边方向重复，在较短边方向也重复。超出内部区域的图案截断。
6. 未配对的矩形保持补全后的纯色填充。
7. 擦除所有标尺条和附着图案。

**关键洞察**：标尺与矩形的配对依赖于"真实较长边长度"，但这个长度在输入中被遮挡掩盖了。必须先完成补全才能正确配对。如果跳过补全直接用可见边长配对，会得到错误的匹配关系——这是整道题的核心欺骗点。

## 新题 4：局部擦除制造断裂后选择性补线

**组合逻辑**：[擦除](已有) + [补线](已有)（创新：擦除的空间范围由对象局部坐标决定，制造出的间隙大小取决于直线段在对象中的相对位置，只有窄间隙被补线修复——擦除和补线之间通过间隙宽度产生非线性交互）

**来源原语**：擦除/连通分量/局部边界列/相对自身定位/按对象局部裁切 ← 52364a65；补线/直线段/间隙长度限制 ← 7b80bb43

**依赖链**：擦除操作按对象局部坐标删去两列像素 → 删除可能切断穿过该对象的直线段 → 切断产生的间隙宽度取决于直线段在对象内的水平位置（靠近右边缘则间隙窄，靠近左边缘则间隙宽）→ 补线仅修复 1 像素宽的间隙。删除擦除则无间隙；删除补线则所有间隙都保留。

擦除每个前景对象最左两列后，仅修复由此产生的单像素间隙，保留较宽间隙。

**输入结构**：黑(0)背景，约 15x15 网格。3~5 个蓝(1)色 4-连通前景对象（每个对象 6~12 像素，形状不规则，边界框宽度至少 3 列）。另有若干红(2)色水平或竖直直线段（1 像素宽，3~8 像素长），部分线段穿过蓝色对象（即线段的某些像素与蓝色对象像素在同一行/列方向上相邻或重叠）。红色线段和蓝色对象的重叠处，红色像素覆盖在蓝色像素之上（即重叠处显示为红色）。生成约束：至少一条红色线段穿过某蓝色对象的左侧两列（擦除后间隙为 2 像素，不会被修复）；至少一条红色线段穿过某蓝色对象的最右列或倒数第二列（擦除后间隙为 1 像素或 0 像素——线段在擦除范围之外）。

**规则**：
1. 识别每个蓝(1)色 4-连通前景对象的边界框。
2. 在每个对象的边界框中，将左起第 1 和第 2 列中属于该对象的蓝色像素设为背景色(0)。同列中的红色像素不受影响（它们不属于蓝色对象）。
3. 擦除后，检查所有红(2)色直线段。若某条线段因其下方/穿过的蓝色支撑被擦除而出现间隙（相邻红色像素之间有恰好 1 个背景像素的中断），则用红(2)色填补该 1 像素间隙。
4. 间隙宽度 >= 2 像素的断裂不修复。
5. 擦除后蓝色对象剩余部分保持不变。

**关键洞察**：间隙宽度不是随机的——它精确等于直线段穿过蓝色对象局部坐标中的列偏移量与被擦除的两列的重叠程度。穿过对象左侧的线段断成 2 像素间隙（不修复），穿过右侧的线段断成 1 像素或不断（修复或无需修复）。求解者必须理解"擦除范围是对象局部坐标"和"修复阈值是 1 像素"两条规则的交互效果。

## 新题 5：修复周期噪声后由瓦片色对驱动邻域重涂

**组合逻辑**：[修复噪声](已有) + [重涂色](已有)（创新：修复噪声不仅恢复视觉正确性，还提取出瓦片的颜色对，该颜色对成为相邻非周期区域的重涂映射规则——修复的结果不直接构成输出的一部分，而是作为元数据驱动另一个变换）

**来源原语**：修复噪声/周期瓦片/框架分区/周期重复/忽略干扰项 ← 135a2760；重涂色 ← 7d419a02；标记像素 ← 4b6b68e5

**依赖链**：周期区域的噪声像素可能是任意颜色 → 修复后确定瓦片恰好由两种非背景色构成 → 这两种颜色构成一个交换映射 → 该映射应用于相邻非周期区域的前景对象。删除修复则颜色对不确定（噪声可能引入第三种颜色导致歧义）；删除重涂则输出缺少对非周期区域的变换。

修复周期瓦片中的噪声像素，然后用瓦片的两种图案色作为交换映射，对相邻区域中的前景对象进行颜色互换。

**输入结构**：黑(0)背景，约 16x16 网格。灰(5)色框架线（完整行/列）将网格分为 4~6 个矩形区域。其中约一半区域（"周期区域"）含有由两种非背景色（如蓝(1)和红(2)）组成的周期性瓦片图案（最小重复单元 2x2 或 3x2），但有 1~3 个像素被噪声破坏（噪声像素颜色为周期区域中不应出现的颜色，如绿(3)或黄(4)）。另一半区域（"对象区域"）各含 1~2 个小型单色前景对象（3~6 像素的 4-连通图形），对象的颜色恰好是某个相邻周期区域的两种图案色之一。生成约束：每个对象区域恰好与一个周期区域共享一条框架边（4-连通相邻），且该周期区域的两种图案色唯一确定（修复后无歧义）。不同的周期区域可以有不同的颜色对。

**规则**：
1. 对每个周期区域：通过每个残差位置（row mod tile_h, col mod tile_w）的多数投票推断最小重复瓦片，将噪声像素替换为正确的瓦片颜色。修复后的瓦片恰好包含两种非背景色，记为 X 和 Y。
2. 对每个对象区域：找到与它共享框架边的周期区域，获取该周期区域修复后的颜色对 (X, Y)。
3. 将对象区域中所有颜色为 X 的前景像素重涂为 Y，所有颜色为 Y 的前景像素重涂为 X。
4. 周期区域本身在修复后保持不变（修复后的图案留在输出中）。
5. 框架线和背景像素不变。

**关键洞察**：重涂映射不是全局固定的——每个对象区域的映射由其相邻周期区域的瓦片颜色对决定，而不同周期区域可以有不同的颜色对。此外，噪声像素如果不修复，可能被错误地计入颜色频次，导致错误的颜色对识别（例如噪声色恰好是另一个周期区域的图案色之一）。修复是正确提取颜色对的前提。

## 新题 6：稠密化改变边缘轮廓后按边缘匹配链接排入框架

**组合逻辑**：[稠密化](已有) + [排序/链式连接](已有)（创新：稠密化操作改变精灵体的边缘像素分布，使得稀疏态下的边缘匹配关系在稠密化后完全不同——链接顺序由稠密化后的边缘决定，而非原始稀疏形态）

**来源原语**：稠密化/稀疏精灵体/稀疏边框/等距排列入框 ← db615bd4；排序/精灵体/分隔线/边缘像素匹配/链式连接排序 ← 78332cb0

**依赖链**：稀疏精灵体在两步格点上 → 稠密化将每个前景像素扩展为 2x2 块（填充格点间隙）→ 稠密化后的边缘轮廓与稀疏态不同 → 按稠密态的边缘匹配确定链接顺序 → 按链接顺序排入稠密化后的框架。删除稠密化则边缘轮廓错误、链接顺序错误；删除链接排序则精灵体顺序不确定。

先将稀疏精灵体和稀疏边框稠密化，再按稠密化后的边缘像素匹配关系链接排序，最后将精灵体按链接顺序等距排入稠密框架。

**输入结构**：黑(0)背景，约 20x20 网格，含一种格点色（如橙(7)，在偶数行偶数列出现的规律性底纹，可被前景覆盖）。一个大型稀疏矩形边框（青(8)色，像素仅出现在两步格点上，形成虚线矩形，约 14x14 范围）。边框外散布 3~4 个稀疏精灵体（每个精灵体一种颜色，从蓝(1)、红(2)、绿(3)、黄(4)中取，像素同样仅在两步格点上，每个精灵体 4~8 个像素，边界框约 5x5）。生成约束：稀疏态下精灵体的边缘像素分布使得任意两个精灵体之间不存在边缘匹配（左右边缘或上下边缘的前景像素在相同偏移处重叠），但稠密化（每个前景像素扩展为 2x2 块）后，精灵体恰好可以按某一唯一顺序首尾链接（A 的右边缘前景像素偏移集合与 B 的左边缘前景像素偏移集合有非空交集 → A 链接 B）。

**规则**：
1. 将稀疏边框稠密化：清除边框区域内所有像素，用青(8)画一个 1 像素宽的实心矩形边框（范围与原稀疏边框的外边界一致）。
2. 将每个稀疏精灵体稠密化：将每个前景像素扩展为以该像素为左上角的 2x2 实心块（同色）。
3. 对稠密化后的精灵体进行链式连接：比较每对精灵体的面对边缘（A 的右边缘 vs B 的左边缘）。若两个边缘在相同行偏移处都有前景像素，则 A 可链接到 B 的左侧。找出能将所有精灵体串成一条完整链的唯一排列。
4. 框架方向判定：若稠密化边框的宽度 > 高度，精灵体沿水平方向排列（左到右）；否则沿竖直方向排列（上到下）。
5. 将链接好的精灵体等距放入稠密边框内部。间距 = (框架内部可用长度 - 所有精灵体在排列方向上的总长度) / (精灵体数量 + 1)，向下取整。多余像素分配给首尾间距。
6. 清除框架外部的所有精灵体残留像素和格点底纹。

**关键洞察**：稀疏态下的边缘轮廓是离散的点，稠密化后变成连续的线段，前景像素的偏移分布发生质变。如果在稀疏态下尝试边缘匹配，会得到"无匹配"的结论；只有稠密化后才能找到有效的链接关系。这意味着稠密化不仅是视觉美化——它实质性地改变了对象之间的拓扑关系。

## 新题 7：翻转控制条决定射线颜色与方向选择

**组合逻辑**：[局部翻转](已有) + [射线延伸](已有) + [已知角点推断中心](创新：角点推断出的中心作为射线发射原点，而非缩小复制的目标)

**来源原语**：局部翻转/中心分隔像素/像素段/各侧独立翻转/中心对称 ← 833966f4；射线延伸/八方向发射/对角均匀色/基数方向循环填 ← fe9372f3；角点标记/角点定义正方形/已知角点推断中心/对角线位置 ← 11e1fe23

**依赖链**：三个角点标记推断出正方形中心 → 中心成为射线发射点。同时，5x1 控制条经局部翻转后改变颜色排列 → 翻转后的顶部像素色决定对角射线颜色，底部像素色决定基数方向射线颜色。两条链在射线发射步骤汇合。删除角点推断则射线无发射点；删除翻转则射线颜色错误。

从三个角点标记推断正方形中心作为射线发射点，同时翻转 5x1 控制条后的颜色分配决定对角线和基数方向射线的颜色。

**输入结构**：黑(0)背景，约 15x15 网格。恰好 3 个绿(3)色像素，分别位于某个轴对齐正方形的 3 个角上（正方形边长 4~8 像素，保证中心为整数坐标）。网格中另有一个 5x1 竖直控制条（5 个连续像素在同一列上，互不同色），中间（第 3 个）像素为灰(5)，其余 4 个像素从蓝(1)、红(2)、黄(4)、橙(7)中取，各不相同。控制条不与角点标记重叠，也不位于任何角点标记的同行同列上。生成约束：正方形中心不与控制条重叠。

**规则**：
1. 从 3 个绿(3)角点标记推断缺失的第 4 个角点位置和正方形中心位置。在缺失角点处画一个绿(3)像素。在中心处画一个灰(5)像素。
2. 对 5x1 控制条执行局部翻转：保持中间灰(5)像素不动，交换第 1 和第 2 像素的位置（上半段翻转），交换第 4 和第 5 像素的位置（下半段翻转）。控制条在输出中保留翻转后的状态。
3. 翻转后，控制条的第 1 像素（最顶部）颜色记为 D（对角色），第 5 像素（最底部）颜色记为 C（基数色）。
4. 从正方形中心向四个对角方向（左上、右上、左下、右下）各发射一条 D 色射线，逐像素延伸直到到达网格边缘。射线覆盖路径上的背景像素但不覆盖已有前景像素。
5. 从正方形中心向四个基数方向（上、下、左、右）各发射一条 C 色射线，逐像素延伸直到到达网格边缘。同样不覆盖已有前景像素。
6. 射线的绘制顺序：先对角后基数。交叉点处基数射线覆盖对角射线。

**关键洞察**：射线的颜色不能直接从控制条读取——必须先完成局部翻转，翻转后的第 1 和第 5 位才是正确的对角/基数色。如果直接用翻转前的第 1 和第 5 位颜色，输出会全错。这一规则在单个示例中可能恰好被某种颜色对称性掩盖，必须对比多个示例（不同控制条初始排列）才能发现翻转的必要性。

## 新题 8：坐标压缩揭示角点正方形后在中心缩小复制

**组合逻辑**：[坐标压缩](已有) + [缩小复制](已有)（创新：角点标记在原始网格中因分隔线扭曲而不构成正方形，压缩后才暴露正方形几何关系——压缩操作不是简单的预处理，而是实质性地改变对象间的空间关系使后续推断成为可能）

**来源原语**：坐标压缩/分隔线 ← 7d419a02；缩小复制/角点标记/已知角点推断中心/对角线位置/角点定义正方形/中心像素 ← 11e1fe23

**依赖链**：原始网格有不均匀分布的分隔行/列 → 3 个同色角点在原始坐标中不构成正方形的角点 → 压缩后移除分隔行/列后角点恰好构成正方形 3 角 → 推断第 4 角和中心 → 在中心周围缩小复制角点图案。删除坐标压缩则角点不构成正方形、推断失败；删除缩小复制则中心无输出。

移除分隔线进行坐标压缩后，三个角点标记才构成正方形的三角，进而推断中心并缩小复制角点图案。

**输入结构**：黑(0)背景，约 14x14 网格。若干完整的黑(0)行和黑(0)列作为分隔线（每条分隔线整行或整列全为黑色，共 2~4 条，分布不均匀）。在非分隔线的单元格中，背景为灰(5)。恰好 3 个像素为非灰非黑的同一颜色（如红(2)），位于网格中不同位置。这 3 个像素在原始坐标中不构成任何轴对齐正方形的三个角点（因为分隔线插入导致间距不等），但移除所有分隔行/列后（坐标压缩），这 3 个像素在压缩坐标中恰好位于某个轴对齐正方形的 3 个角上，且正方形中心为整数坐标。生成约束：压缩后正方形边长至少为 4（保证中心与角点之间至少有 1 个空位放置缩小复制结果），且正方形区域内（压缩坐标下）的其他位置均为灰(5)背景。

**规则**：
1. 识别所有全黑的完整行和完整列（分隔线）。
2. 移除这些行和列，将剩余行列紧凑排列（坐标压缩）。输出网格尺寸 = 原始网格尺寸减去分隔线数量。
3. 在压缩后的网格中，找到 3 个同色（红(2)）像素。它们恰好构成某个轴对齐正方形的 3 个角点。
4. 推断缺失的第 4 个角点位置。在该位置画一个红(2)像素。
5. 计算正方形中心位置。在中心画一个黑(0)像素。
6. 对于已有的 3 个角点标记中的每一个，在中心到该角点方向上距中心 1 步的对角线位置，画一个该角点颜色（红(2)）的像素（缩小复制：将角点图案在中心周围缩小一步重现）。
7. 缺失角点同样在其对应的缩小位置画红(2)像素。
8. 最终输出为压缩后的网格（不恢复分隔线）。

**关键洞察**：分隔线在视觉上让 3 个角点看起来间距不等（例如两个角点之间隔了 2 条分隔线而另一对之间只隔了 1 条），直觉上不像正方形的角。只有在脑中执行坐标压缩后，正方形结构才浮现。这一步是认知瓶颈——压缩不是清理噪声，而是揭示隐藏的几何关系。
