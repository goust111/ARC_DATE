## 新题 1：标记对棋盘矩形与面积优先叠层

**组合逻辑**：[标记对定义跨度](创新：同色孤立像素对定义矩形角点) + [编织填充](创新：以像素对为锚点的局部棋盘填充) + [尺寸分类](创新：矩形面积排序驱动重叠优先级) → 三者交织为同时约束满足结构

**来源原语**：标记对定义跨度(marker_pair_span, f3e14006), 编织填充(weave_fill, f3e14006), 奇偶交替颜色(parity_alt_color, f3e14006), 尺寸分类(size_classification, b27ca6d3), 矩形(rectangle, f3e14006/af902bf9)

**依赖链**：同色像素对的坐标决定矩形范围 → 矩形范围决定编织填充的锚点和区域 → 多矩形重叠时面积排序决定哪个矩形的编织花样可见。三层逻辑缺一不可：没有像素对就没有矩形；没有编织规则就不知道每个像素的颜色；没有面积优先级就无法解决重叠冲突。

同色像素对定义矩形区域，每个矩形内按奇偶校验填充棋盘编织花样，重叠区域由面积较小的矩形优先覆盖。

**输入结构**：黑(0)背景网格，约 12x12。网格上有 2~3 对同色孤立像素（每对颜色不同，如蓝(1)、红(2)、橙(7)）。每对两个像素不在同一行也不在同一列。各像素之间互不相邻（8-连通距离至少为 2）。生成约束：至少有两个矩形的投影区域存在重叠；各对颜色两两不同；每对恰好 2 个像素。

**规则**：
1. 对于每对同色像素 (r1,c1) 和 (r2,c2)，以它们为对角定义一个矩形区域：行范围 [min(r1,r2), max(r1,r2)]，列范围 [min(c1,c2), max(c1,c2)]。
2. 对矩形区域内的每个单元格 (r,c)，计算 (r - r_min + c - c_min)。若该值为偶数，填入该对的颜色；若为奇数，保持黑(0)。其中 r_min 和 c_min 分别是该矩形的最小行号和最小列号。
3. 两个像素对本身的位置始终显示为自身颜色（即使按奇偶校验该位置应为黑色，也强制保留）。
4. 当多个矩形在同一单元格重叠时：比较涉及的各矩形的总面积（面积 = 行数 x 列数），面积**较小**的矩形优先——使用其编织花样颜色。若面积相同，按矩形左上角行号较小者优先；行号也相同则列号较小者优先。
5. 不属于任何矩形的单元格保持黑(0)。

**关键洞察**：每个矩形的棋盘编织相位以自身左上角为锚点，不同矩形的编织相位互相独立——重叠区域的颜色不能通过全局棋盘推断，必须分别计算每个矩形的局部相位再按面积规则取舍。

## 新题 2：重力沉降进骨架捕获与行填充触发

**组合逻辑**：[重力沉降](创新：像素不落到底而是被骨架空心中心捕获) + [骨架格子 + 空心小框](创新：格子中心作为捕获容器) + [计数 + 扩展填充](创新：行满触发边界着色) → 结构解构型：先通过物理模拟（重力）改变分布，再由分布的统计属性（行完整性）触发第二阶段操作

**来源原语**：重力沉降(gravity_settling, 3618c87e), 同列对齐(same_col_align, 3618c87e), 骨架格子(scaffold_lattice, 97239e3d), 空心小框(hollow_cell_frame, 97239e3d), 扩展填充(expand_fill, 97239e3d), 标记跨度决定范围(marker_span_extent, 97239e3d), 计数(counting, 5582e5ca)

**依赖链**：散落像素的列位置决定它们进入哪列骨架 → 重力顺序决定哪个中心被占（同列先到先得）→ 占据结果决定哪些骨架行"满员" → 满员行的颜色统计决定边界涂色。四步之间每一步的输出都是下一步的必要输入。

散落在骨架上方的彩色像素受重力落入骨架空心框的中心，当某行框的中心全部被占时，该行框的灰色边界被涂成行内出现最多的颜色。

**输入结构**：黑(0)背景网格，约 15x15。网格下半部有一个由灰(5)空心 3x3 框排列成的规则骨架（例如 3 列 x 3 行，共 9 个框），框与框之间有 1 像素间隔。每个 3x3 框的中心（1x1）为黑(0)。网格上半部（骨架之上的区域）散落 5~8 个彩色像素（使用 2~3 种非灰非黑颜色，如蓝(1)、红(2)、绿(3)），各像素互不相邻。生成约束：每个彩色像素的列坐标必须恰好等于某个框中心的列坐标；至少有一行骨架框的所有中心列上方都有像素（保证至少触发一次行填充）；同一列上方的像素数不超过该列的框中心数。

**规则**：
1. 识别骨架格子：灰(5)像素构成的重复 3x3 空心框阵列。每个框中心坐标记为 (rc_i, cc_j)。
2. 每个彩色像素按列匹配到该列的框中心序列中。同一列有多个框中心时，按从上到下排列。
3. 对每列的彩色像素按照它们在输入中的行号从高（远离底部）到低（靠近底部）排序。最靠近底部的像素落入该列最上面一个空的框中心（即最接近顶部的尚未被占据的中心），依次向下填充。若所有中心已满，剩余像素被擦除。
4. 沉降完成后，检查骨架的每一行框。若某行的**所有**框中心都被占据，则该行被"激活"。
5. 对每个被激活的行：统计该行各中心所含颜色的出现次数。将该行所有框的灰(5)边界像素（3x3 框的 8 个边像素 + 框间间隔中属于该行的灰像素）重涂为出现次数最多的颜色。若平局，选择该行中最左侧中心所含的颜色。
6. 未被激活的行保持原样（灰边界 + 占据/空的中心）。骨架上方区域清空为黑(0)。

**关键洞察**：骨架不是装饰——其列对齐决定了哪些像素能被捕获，行完整性条件创造了阈值效应：增减一个像素可能导致某行从不激活变为激活，从而引发大面积边界重涂。

## 新题 3：路径方向编码模板旋转印章

**组合逻辑**：[印章覆盖](保留：复制模板到目标位置) + [路径网络](创新：路径的到达方向编码旋转参数，而非仅表示连接) + [二面体变换对应](创新：旋转角度由路径几何隐式决定，非预置在精灵体上) → 隐式编码结构：路径的几何形态本身编码了变换规则

**来源原语**：印章覆盖(stamp, 39e1d7f9), 邻域模板(neighborhood_template, 39e1d7f9), 示例邻域传递同色(exemplar_copied_to_same_color, 39e1d7f9), 路径网络(path_network, d35bdbdc), 路径连通(path_connectivity, d35bdbdc), 二面体变换对应(dihedral_correspondence, 64efde09), 模板单元映射(template_cell_mapping, 64efde09), 分隔线划分(separator_partition, 39e1d7f9)

**依赖链**：模板定义印章内容 → 路径是否到达决定目标是否接收印章 → 路径到达方向决定旋转角度 → 旋转后的模板被印在目标位置。没有路径方向信息就无法确定旋转；没有模板就无内容可印；两者缺一不可。

一个不对称的 3x3 模板通过灰色路径传播到各目标位置，路径到达目标的方向决定了模板在该位置的旋转角度。

**输入结构**：黑(0)背景网格，约 15x15。灰(5)分隔线将网格划分为规则的格网单元（每个单元约 3x3 到 5x5）。其中一个单元包含一个不对称的 3x3 彩色图案（模板），图案中心为红(2)像素，周围 8 个位置中有 2~3 个位置为非黑非红非灰的颜色像素（如蓝(1)、绿(3)），其余为黑(0)。模板必须在 90 度旋转下不对称（即 0/90/180/270 度旋转结果两两不同）。另有 3~5 个单元仅包含一个红(2)中心像素（目标单元）。在分隔线之外，存在灰(5)单像素路径段（不属于分隔线结构）连接模板单元与部分目标单元——路径沿格网单元间的间隙行走，形成直线或 L 形路径。生成约束：每条路径仅连接模板与一个目标；至少有一个目标没有路径连接；路径不分叉。

**规则**：
1. 识别模板单元（中心为红(2)且周围有其他颜色邻居的格网单元）。
2. 对每个红(2)中心的目标单元，检测是否有灰路径从模板单元到达它。
3. 若有路径到达，确定路径进入目标单元的最后一步方向：
   - 从左侧进入 → 模板保持原始方向（0 度）
   - 从上方进入 → 模板顺时针旋转 90 度
   - 从右侧进入 → 模板旋转 180 度
   - 从下方进入 → 模板顺时针旋转 270 度
4. 将旋转后的模板印在目标单元上，以红(2)中心对齐。若旋转后的模板像素超出该单元边界（被分隔线截断），超出部分舍弃。
5. 没有路径连接的目标单元保持原样（仅保留红(2)中心像素）。
6. 路径像素、分隔线、模板单元本身均保持不变。

**关键洞察**：灰色路径看似仅表示连接关系，但其真正作用是方向编码——只有路径的最后一步（进入目标的方向）才决定旋转角度。路径的长度和中间走向不影响结果，求解者必须通过对比多个示例才能发现"到达方向 = 旋转角度"这一隐蔽映射。

## 新题 4：角标记矩形与掩码选色的双向尺寸依赖

**组合逻辑**：[四角标记围定内部](保留：黄色角点定义矩形) + [掩码决定保留](创新：灰色掩码决定矩形内部哪些像素被着色) + [尺寸分类](创新：同一个面积度量同时驱动颜色分配和重叠优先级，且方向相反) → 同时约束满足结构：面积既决定颜色又决定优先级

**来源原语**：四角标记围定内部(four_corners_define_interior, af902bf9), 角标记(corner_marker, af902bf9), 填充(fill, af902bf9), 行列对齐(row_column_alignment, af902bf9), 掩码决定保留(mask_determines_keep, f76d97a5), 颜色替换(color_replacement, f76d97a5), 尺寸分类(size_classification, b27ca6d3), 矩形(rectangle, f3e14006/af902bf9)

**依赖链**：黄色角标记确定矩形几何 → 矩形面积排名同时决定填充颜色**和**重叠优先级 → 灰色掩码进一步筛选矩形内部的着色像素。面积排名做双重用途（颜色+优先级），且两个用途方向相反：最大矩形得到最显眼颜色但在冲突中优先级最低。

黄色角点定义多个矩形，矩形内灰色掩码处按面积排名着色，重叠区域由面积最小的矩形优先覆盖。

**输入结构**：黑(0)背景网格，约 14x14。黄(4)像素标记 2~3 个矩形的四角（每个矩形由 4 个黄像素定义，它们恰好共享两个行值和两个列值）。矩形内部（不含角点的区域）散布若干灰(5)像素作为掩码，每个矩形内有 3~8 个灰像素，灰像素之间可以不连通。生成约束：至少两个矩形的内部区域存在重叠；各矩形的内部面积（= (行数-2) x (列数-2)，即不含角点和边的纯内部）两两不等；重叠区域中两个矩形的掩码均有灰像素存在。

**规则**：
1. 从黄(4)像素中识别矩形：找到共享两行两列的四元组，每组定义一个矩形。
2. 计算每个矩形的内部面积（行数 x 列数，含角点行列）。按面积从大到小排名：最大 → 排名 1，次大 → 排名 2，最小 → 排名 3。
3. 按排名分配颜色：排名 1（最大）→ 红(2)，排名 2 → 蓝(1)，排名 3 → 绿(3)。
4. 对每个矩形的内部区域（不含黄色角点所在的像素）：仅在灰(5)掩码像素所在位置涂上该矩形的分配颜色，其余位置保持黑(0)。
5. 若某像素同时落在多个矩形的掩码区域内：面积**较小**的矩形优先——使用该矩形的颜色。
6. 黄(4)角标记像素在输出中保持不变。

**关键洞察**：面积排名承担双重职责且方向相反——最大的矩形获得视觉最突出的颜色（红），但在重叠冲突中反而让位于更小的矩形。求解者必须同时理解这两层映射关系，仅看颜色分配规则或仅看优先级规则都不足以完全确定输出。

## 新题 5：连通性筛选分流与操作交叉涌现

**组合逻辑**：[连通检测 + 唯一连通分量](保留：区分信号色与噪声色) + [射线延伸](创新：仅作用于面积为 1 的信号对象) + [描边](创新：仅作用于面积为 2 的信号对象) + [交叉点特殊着色](创新：射线与描边在空间交叉处产生第三种涌现颜色) → 分叉汇合结构：一个分类节点将对象分流到不同操作，两条操作分支在空间上重新汇合产生涌现特征

**来源原语**：连通检测(connected_component_detection, 3194b014), 唯一连通分量(unique_component, 3194b014), 忽略干扰项(ignore_distractors, 3194b014), 筛选(filtering, 3194b014), 射线延伸(ray_extend, 23581191), 十字图案(cross_pattern, 23581191), 描边(outline, b27ca6d3), 微型对象描边(micro_obj_outlined, b27ca6d3), 尺寸分类(size_classification, b27ca6d3), 交叉点特殊着色(intersection_colored, 23581191)

**依赖链**：连通检测将颜色分为信号/噪声 → 信号色内按面积分为两类 → 面积 1 的触发射线延伸，面积 2 的触发描边 → 射线和描边在空间上可能交叉 → 交叉处涌现出黄色。每一步都依赖前一步：没有连通检测就不知道保留谁；没有面积分类就不知道对谁做什么操作；没有两种操作的空间结果就没有交叉涌现。

筛除多连通噪声色后，单像素信号对象射出十字射线，双像素信号对象被描绿色边框，射线穿过边框处涌现为黄色。

**输入结构**：黑(0)背景网格，约 14x14。网格上有若干小型 4-连通单色对象（每个对象 1~4 像素），使用 3~4 种非黑颜色。部分颜色的像素形成多个不连通的碎片（噪声色），部分颜色的像素恰好构成一个 4-连通对象（信号色）。信号色中，有的对象仅 1 像素（孤立像素），有的恰好 2 像素（水平或竖直多米诺骨牌），有的 3 像素以上。生成约束：至少有 1 个单像素信号对象和 1 个双像素信号对象；至少有 1 个噪声色（其像素总数可能较多但分散为多个碎片）；至少有一个单像素对象的行或列射线会穿过某个双像素对象的描边区域。

**规则**：
1. 对每种非黑颜色，计算其 4-连通分量数。分量数恰好为 1 的颜色为"信号色"；分量数 > 1 的颜色为"噪声色"。
2. 将所有噪声色像素擦除为黑(0)。
3. 对每个信号色对象，按像素数分类：
   - 面积 = 1（单像素）：以该像素为中心，向上下左右四个方向延伸射线至网格边界，射线颜色为该对象的颜色。射线在遇到**其他信号色对象的原始像素**时停止（不含该像素），但可以穿过描边和其他射线。
   - 面积 = 2（多米诺骨牌）：计算其边界框，将边界框向上下左右各扩展 1 个像素（在网格范围内裁剪），在扩展框的周边绘制绿(3)边框（仅在当前为黑(0)的像素上绘制，不覆盖已有的信号色对象像素）。
   - 面积 >= 3：保持原样，不做任何变换。
4. 最终检查：任何同时被射线和绿(3)边框占据的像素（即射线穿过了描边位置），涂为黄(4)。
5. 处理顺序：先执行所有描边，再执行所有射线延伸，最后执行交叉着色。射线绘制时覆盖已有的绿(3)边框像素（变为射线颜色），然后在步骤 4 中将这些位置改为黄(4)。

**关键洞察**：黄色交叉像素不由任何单一输入特征指定——它们是两种独立变换（射线与描边）在空间上偶然重合的涌现产物。求解者必须先理解分流逻辑，再分别推断两种操作的空间范围，最后发现交叉规则。

## 新题 6：分隔栅格连线与邻域决定的半段变色

**组合逻辑**：[同色配对 + 连线](保留：同色端点沿行/列连接) + [等分 + 下半变色](创新：连接线段被等分后半段变色) + [颜色查找键](创新：变色目标颜色由栅格邻域隐式编码) → 隐式编码结构：分隔栅格的拓扑本身编码了颜色映射表

**来源原语**：分隔栅格(divider_grid, 06df4c85), 同色配对(same_color_pairing, 06df4c85), 连线(connect, 06df4c85), 沿行列填充间隙(fill_gap_along_row_col, 06df4c85), 等分(equal_split, ce9e57f2), 下半变色(lower_half_recolored, ce9e57f2), 颜色查找键(color_lookup_key, d35bdbdc), 分隔线划分(separator_partition, 06df4c85)

**依赖链**：同色像素对的位置决定连接方向和长度 → 连接产生的线段被等分 → 后半段需要变色，而变色目标颜色取决于该线段在栅格中的邻域里存在什么其他颜色 → 邻域关系由栅格拓扑决定。从连接到分割到查色，每步输出改变下步的参数。

在分隔栅格中连接同色端点对，将每条连接线段等分后，后半段变为与该线段在栅格中相邻的另一条线段的颜色。

**输入结构**：黑(0)背景网格，约 13x13。灰(5)满行和满列将网格分割为矩形单元（约 3~4 行 x 3~4 列的单元阵列）。部分单元中央有一个彩色像素（非灰非黑，如蓝(1)、红(2)、橙(7)、品红(6)等）。每种颜色恰好出现 2 次，且两次出现位于同一单元行或同一单元列（即沿栅格行对齐或列对齐）。至少有 3 对不同颜色。生成约束：至少有两对线段在连接后共享一条灰色分隔线（即一对的连接方向为水平，另一对也为水平，且它们位于相邻的单元行，中间隔一条水平灰线；或类似的垂直情形）。每对之间的间隔单元数至少为 1。

**规则**：
1. 识别灰(5)分隔线构成的栅格，确定单元划分。
2. 对每种非灰非黑颜色，找到同色的两个像素，它们位于同一单元行或同一单元列。
3. 沿该行或列方向，将两像素之间所有黑(0)单元填充为该颜色（灰分隔线像素不被覆盖，仅填充黑色单元区域）。
4. 每条连接线段（含两端点像素和填充区域）按像素总长度等分：前 ceil(长度/2) 个像素为前半段，后 floor(长度/2) 个像素为后半段。方向定义：水平线段从左到右为前→后；垂直线段从上到下为前→后。
5. 对每条线段的后半段确定变色颜色：在栅格拓扑中，查找与该线段共享一条灰分隔线的另一条线段。"共享灰分隔线"指两条线段分别位于该灰线两侧的相邻单元行（对于水平线段）或相邻单元列（对于垂直线段）。后半段变为该相邻线段的**原始颜色**。
6. 若一条线段有多个邻居，选择与该线段中点距离最近的邻居线段（按中点之间的曼哈顿距离）。若无邻居，后半段保持原色不变。
7. 灰分隔线在输出中保持不变。

**关键洞察**：栅格分隔线不仅组织了端点的配对，还隐式定义了线段之间的邻接关系——变色查找表不是显式给出的，而是从栅格拓扑中读取的。求解者必须发现"共享分隔线 = 颜色供体"这一隐蔽规则。

## 新题 7：交叉条编织与像素计数截断

**组合逻辑**：[交叉条 + 标记对定义跨度 + 编织填充](保留：双条交叉区域编织) + [像素数决定长度 + 压缩](创新：独立小对象的面积编码截断参数，删除编织矩形的末端行/列) → 线性流水线但含隐式参数编码：小对象的像素数是一个隐藏的数值参数

**来源原语**：编织填充(weave_fill, f3e14006), 交叉条(crossing_bar, f3e14006), 标记对定义跨度(marker_pair_span, f3e14006), 奇偶交替颜色(parity_alt_color, f3e14006), 压缩(compress, c61be7dc), 像素数决定长度(pixel_count_length, c61be7dc), 内部对象(inner_object, c61be7dc)

**依赖链**：交叉条和标记像素定义编织矩形 → 编织规则填充该矩形 → 小对象的像素数 N 决定截断量 → 矩形底部 N 行被删除。编织结果和截断参数由完全独立的输入元素提供，但共同决定最终输出。

两条交叉色条通过标记对定义编织矩形，矩形内按奇偶填充双色棋盘，然后根据一个独立小对象的像素数截去矩形底部若干行。

**输入结构**：黑(0)背景网格，约 12x15。一条完整的水平色条横贯网格（蓝(1)），一条完整的垂直色条纵贯网格（红(2)），两条在一个像素处交叉。水平条上有 2 个橙(7)标记像素（不在交叉处），定义列跨度 [c_left, c_right]。垂直条上有 2 个橙(7)标记像素（不在交叉处），定义行跨度 [r_top, r_bottom]。另有一个由绿(3)像素构成的小型 8-连通对象（3~7 像素），位于远离两条色条的空白区域，不与任何条或标记相邻。生成约束：行跨度高度 > 绿色对象像素数 + 1（保证截断后至少保留 2 行）；列跨度宽度 >= 3；绿色对象在不同示例中形状不同但像素数作为参数起关键作用。

**规则**：
1. 识别水平蓝(1)条和垂直红(2)条。在水平条上找到两个橙(7)标记，定义列范围 [c_left, c_right]（c_left < c_right）。在垂直条上找到两个橙(7)标记，定义行范围 [r_top, r_bottom]（r_top < r_bottom）。
2. 列范围和行范围的交集定义一个矩形区域。
3. 在该矩形内填充编织花样：单元格 (r, c) 的颜色由 (r - r_top + c - c_left) 的奇偶性决定——偶数用蓝(1)，奇数用红(2)。
4. 交叉单元格（水平条与垂直条相交处，若在矩形内）使用红(2)（垂直条覆盖水平条）。
5. 计算绿(3)对象的像素总数 N。
6. 从编织矩形中删除底部 N 行（即 r_bottom - N + 1 到 r_bottom 行的矩形部分被清除为黑(0)）。
7. 矩形外的色条、标记像素和绿色对象在输出中保持不变。

**关键洞察**：绿色小对象在视觉上与编织区域无关，看似装饰——但它的像素数量是截断参数。求解者必须对比多个示例（其中绿色对象形状不同、像素数不同）才能发现"像素数 = 删除行数"的隐蔽编码关系，而非通过对象形状或位置推断。

## 新题 8：图例位置匹配驱动镜像补全与重涂色

**组合逻辑**：[相对位置对应 + 最小距离匹配](保留：图例标记与外部对象的位置匹配) + [对称补全 + 控制标记指示源侧](保留：按黄色标记镜像补全半成品) + [重涂色](创新：补全后的对象按匹配结果着色) → 条件分支结构：匹配在补全之前进行（基于半成品几何），但着色在补全之后应用——求解者看到完整着色对象，必须反向拆解匹配逻辑

**来源原语**：相对位置对应(relative_position_correspondence, 1da012fc), 最小距离匹配(minimum_distance_matching, 1da012fc), 占位块(placeholder_object, 1da012fc), 图例矩形(legend_rectangle, 1da012fc), 对称补全(symmetric_completion, 5b692c0f), 控制标记指示源侧(control_marker_indicates_source, 5b692c0f), 镜像(mirror, 5b692c0f), 轴对称反射(axial_mirror_reflection, 5b692c0f), 重涂色(recolor, 多题)

**依赖链**：图例标记的相对位置 → 与半成品对象的边界框中心做最小距离匹配 → 匹配结果决定每个对象的目标颜色 → 对象通过黄色轴和控制标记进行镜像补全 → 补全后的灰色像素全部重涂为匹配到的颜色。匹配在补全前（用半成品的几何特征），着色在补全后——两步逻辑在时间上交错依赖。

图例矩形中的彩色标记与网格上的半成品灰色对象按相对位置一一匹配，每个对象先通过黄色轴镜像补全再整体重涂为匹配到的标记颜色。

**输入结构**：黑(0)背景网格，约 16x16。一个灰(5)实心矩形作为图例（约 4x4 到 6x6），内部嵌有 3~4 个单像素彩色标记（每个标记颜色不同，如蓝(1)、红(2)、绿(3)、橙(7)等），标记位置在图例矩形内各不相同。图例之外的区域有 3~4 个灰(5)的 8-连通半成品对象（每个 4~8 像素），每个对象包含一个黄(4)轴像素（形成单像素宽的水平或垂直对称轴）和一个偏离轴的黄(4)控制像素（指示可信侧）。每个半成品的可信侧有细节（灰像素），对称侧大部分为空（黑像素）。生成约束：半成品对象数量等于图例标记数量；各半成品的边界框中心到各标记的相对位置能形成唯一最小总距离的一一匹配；半成品对象之间互不接触（8-连通距离 >= 2）。

**规则**：
1. 识别图例矩形（最大的灰(5)连通体）及其内部的彩色标记像素。
2. 识别图例外的所有灰(5)8-连通对象作为半成品。
3. 计算每个半成品的边界框中心坐标。计算图例矩形的边界框。将每个图例标记的坐标归一化为其在图例边界框内的相对位置（行方向：(标记行 - 图例行min) / 图例高度；列方向类似）。将每个半成品的边界框中心归一化为其在所有半成品共同边界框内的相对位置。
4. 按最小总曼哈顿距离建立标记与半成品的一一匹配。
5. 对每个半成品：找到其黄(4)轴像素和偏离轴的黄(4)控制像素。控制像素所在的一侧为可信侧。
6. 将可信侧关于黄色轴做镜像反射，将反射的像素复制到对称侧（覆盖黑色像素；若对称侧已有非黑像素则保留反射结果）。
7. 补全后，将该对象中所有灰(5)像素和黄(4)像素统一重涂为其匹配到的图例标记颜色。
8. 图例矩形（含标记）在输出中保持不变。背景保持黑(0)。

**关键洞察**：匹配基于补全前的半成品几何（边界框中心），但输出显示的是补全后的着色对象——求解者看到的完整对象形状在匹配时并不存在。必须先理解"匹配用半成品、着色用补全品"的时序关系，才能逆向还原规则。
