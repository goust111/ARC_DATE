## 新题 1：杯口轴镜像补全内部图案

**组合逻辑**：[开口朝向检测] → [镜像(reflect)](创新：杯口边缘作为镜像轴，而非独立的框架线) → [填充(fill)](创新：仅填充镜像后仍为空的内部残余区域，颜色取自杯壁)

**来源原语**：镜像(reflect) ← f8a8fe49；填充(fill) ← aba27056；杯形容器(cup_shape) ← aba27056；开口朝向(opening_direction) ← aba27056；对称轴关系(symmetry_axis) ← f8a8fe49；内部包含(interior_containment) ← aba27056

**依赖链**：杯口方向决定镜像轴的朝向（开口在右 → 垂直轴），镜像操作依赖该轴将半侧图案翻转到另一半；填充操作仅作用于镜像后仍为背景色的内部像素，其颜色来自杯壁颜色。删除开口检测则轴不确定；删除镜像则图案不完整；删除填充则内部有空隙。

从杯口方向推断镜像轴，将内部半侧图案翻转补全，再用杯壁色填充剩余内部空隙。

**输入结构**：黑(0)背景，约 12x12 网格。包含 2-3 个杯形容器，每个杯由单色（蓝(1)、红(2)或橙(7)等）像素围成，形成三面封闭、一面开口的 U 形或旋转 U 形结构（杯壁厚度 1 像素，杯内部空间约 3x4 至 4x5 像素）。每个杯的开口朝向不同（上/下/左/右各一个方向，不同示例中方向组合不同）。杯内部的一半区域（以垂直于开口方向的中线为界，靠近杯底的一半）包含一个由绿(3)像素构成的小型 4-连通图案（2-4 像素），另一半为黑(0)。各杯互不相邻且不靠近网格边缘。生成约束：内部图案关于杯口方向中线不对称（否则镜像无意义）。

**规则**：
1. 识别每个杯形容器及其开口方向（开口方向为杯壁缺口所在侧）。
2. 确定镜像轴：取杯内部空间在垂直于开口方向上的中线。例如：开口朝右的杯，中线为杯内部空间的水平中线。
3. 将杯内部非背景像素关于该中线做镜像翻转，仅在目标位置为黑(0)时写入翻转后的颜色（不覆盖已有图案）。
4. 镜像完成后，杯内部仍为黑(0)的像素全部填充为杯壁的颜色。
5. 杯壁本身和杯外区域保持不变。

**关键洞察**：杯口方向不再是射线的出发方向（与 aba27056 不同），而是选择镜像轴的编码信号；仅凭一个示例无法确定"先镜像再填充"还是"直接按某种对称性填充"，必须对比多个开口方向的杯才能区分。

## 新题 2：周期种子射线遇壁反弹并继承壁色

**组合逻辑**：[射线延伸(ray_extend) + 种子周期生长(seed_periodic_growth)](创新：周期间隔使射线对墙壁产生"盲区") → [反弹(bounce) + 颜色继承(color_inheritance)](创新：反弹仅在射线步进点恰好命中墙壁时触发) → [碰撞停止(collision_stop)]

**来源原语**：射线延伸(ray_extend) ← 3ac3eb23；种子周期生长(seed_periodic_growth) ← 3ac3eb23；反弹(bounce) ← 142ca369；颜色继承(color_inheritance) ← 142ca369；碰撞停止(collision_stop) ← 142ca369；墙壁像素(wall_pixel) ← 142ca369；轨迹(trail) ← 3ac3eb23

**依赖链**：种子周期生长决定射线的落点序列（每隔一格），只有落点恰好与墙壁重合才触发反弹和颜色继承；若取消周期性（每格都落），射线会更早命中墙壁，路径完全不同；若取消反弹，射线直接终止而非改变方向。周期性和反弹的交互产生了"墙壁盲区"这一涌现效应。

种子发射隔行对角射线，仅当步进点命中彩色墙壁时反弹并变色，步进间的墙壁被"跨过"。

**输入结构**：黑(0)背景，约 15x15 网格。包含 2-3 个孤立彩色种子像素（各不同色，如蓝(1)、红(2)），以及 4-8 个彩色墙壁像素（颜色与种子不同，如绿(3)、黄(4)、橙(7)），散布于网格中。种子像素之间至少间隔 5 个像素。生成约束：每条射线路径上至少有一个墙壁恰好落在奇数步位置（确保至少一次反弹可观察），并且至少有一个墙壁落在偶数步位置（确保"盲区跨越"可观察）。

**规则**：
1. 从每个种子像素出发，向右下方发射对角射线，步进序列为 (r+1,c+1), (r+2,c+2), (r+3,c+3), ...，但仅在**奇数步**（第 1, 3, 5, 7... 步）放置轨迹像素。偶数步位置不放置像素也不检测碰撞。
2. 当某个奇数步位置恰好是一个墙壁像素时，触发反弹：射线的行方向取反（原来向下变为向上，或原来向上变为向下），列方向不变。反弹后射线颜色变为该墙壁像素的颜色。墙壁像素本身保留原色。
3. 反弹后步数计数器重置为 0，继续按新方向前进，同样仅在奇数步放置轨迹像素并检测碰撞。
4. 射线在以下情况终止：(a) 步进位置超出网格边界；(b) 奇数步位置是另一个种子像素。
5. 各射线独立处理，绘制顺序按种子在网格中从左上到右下的阅读顺序。后绘制的轨迹像素覆盖先绘制的。

**关键洞察**：周期性步进（隔行放置）使射线对偶数步位置上的墙壁"视而不见"，这一盲区效应在参考题中不存在——参考题的周期生长无反弹（3ac3eb23），参考题的反弹射线无周期间隔（142ca369）。

## 新题 3：形状匹配选色驱动嵌套框同心层填充

**组合逻辑**：[形状匹配(shape_match) + 掩码相同(mask_equality)](创新：匹配结果不是重涂色，而是选取调色板颜色) → [同心层填充(concentric_fill) + 嵌套层次(nesting_hierarchy)](创新：每层的颜色由匹配决定而非固定调色板)

**来源原语**：形状匹配(shape_match) ← 63613498；掩码相同(mask_equality) ← 63613498；同心层填充(concentric_fill) ← 99306f82；嵌套层次(nesting_hierarchy) ← 99306f82；空心矩形框(hollow_rect_frame) ← 99306f82；中心标记(center_marker) ← 00dbd492；精灵体(sprite) ← 4c177718

**依赖链**：形状匹配将每个框架内的标记图案与外部精灵配对，获得颜色；该颜色作为同心层填充的输入。嵌套层次决定填充从外到内的顺序。删除形状匹配则无法确定各层颜色；删除同心层填充则颜色无处使用；删除嵌套层次则填充顺序不确定。

嵌套空心框内各有一个小标记图案，通过形状匹配从外部精灵获取颜色，逐层向内填充。

**输入结构**：黑(0)背景，约 16x16 网格。网格中央有 3 个同心嵌套的单像素厚空心矩形框，均为灰(5)色，从外到内尺寸分别约 13x13、9x9、5x5（各框之间留出 2 像素宽的间隔带）。每两个相邻框之间的间隔带中央放置一个由品红(6)像素构成的小型 4-连通标记图案（2-4 像素，形状各不同，如水平二连、L 形三连、单像素等）。最内层框内部中央也有一个品红(6)标记图案。网格左上角或右上角区域放置 3-4 个彩色精灵体（如蓝(1)、红(2)、绿(3)、黄(4)各一个），每个精灵是一个小型 4-连通图案（2-4 像素），形状各不同但恰好与框间标记一一对应（归一化掩码相同）。精灵之间至少间隔 2 像素。生成约束：每个标记恰好匹配一个精灵，无歧义。

**规则**：
1. 识别所有空心矩形框并按面积从大到小排序，确定嵌套层次（最外层编号为 1，次外层为 2，最内层为 3）。
2. 提取每层间隔带（第 k 层与第 k+1 层框之间的区域）中的品红(6)标记图案，裁剪为最小边界框并归一化为二值掩码。最内层框内部的标记视为第 3 层的标记。
3. 对角落区域的每个彩色精灵做同样的裁剪和归一化。
4. 将每个标记的掩码与所有精灵的掩码比较，找到唯一匹配（掩码相同），记录该精灵的颜色作为对应层的填充色。
5. 从最外层开始向内执行同心层填充：第 1 层（最外框与次外框之间的间隔带）所有黑(0)像素填充为第 1 层匹配到的颜色；第 2 层同理；第 3 层（最内框内部）同理。
6. 所有灰(5)框线保留不变。所有品红(6)标记像素在填充后被覆盖（因为它们位于应被填充的区域内）。精灵所在的角落区域保持不变。

**关键洞察**：标记图案不是装饰而是形状查询键——只有通过与精灵的形状匹配才能确定每层的填充颜色。仅看一个示例可能误以为颜色由框的尺寸决定，必须对比多个示例（框尺寸相同但标记/精灵配对不同）才能排除该假设。

## 新题 4：双掩码逻辑交定位后按对角序列循环着色

**组合逻辑**：[逻辑交(logical_AND) + 位掩码(bitmask)](来自 0520fde7) → [对角线标记(diagonal_marker) + 顺序配对(ordered_pairing)](创新：对角序列不再驱动同心层填充，而是为离散位置提供循环色序) → [重涂色(recolor)]

**来源原语**：逻辑交(logical_AND) ← 0520fde7；位掩码(bitmask) ← 0520fde7；分隔列(separator_col) ← 0520fde7；对角线标记(diagonal_marker) ← 99306f82；顺序配对(ordered_pairing) ← 42f83767；重涂色(recolor) ← d2abd087

**依赖链**：逻辑交产生重叠位置集合（稀疏的像素点），对角线标记提供有序色序。位置集合按阅读顺序排列后与色序循环配对。删除逻辑交则无法确定哪些位置需着色；删除对角序列则无法确定用什么颜色。

计算左右双掩码的逐像素重叠，将重叠位置按阅读顺序用对角标记的色序循环涂色。

**输入结构**：黑(0)背景，约 11x15 网格（11 行 15 列）。一条灰(5)全高分隔列将网格分为左右两个 11x7 的面板。左面板和右面板各包含一个由蓝(1)像素构成的二值掩码（蓝=活跃，黑=非活跃），像素数约 8-15 个。网格左上角（分隔列左侧的前 3-4 行）有一条从 (0,0) 开始的连续右下对角线标记，由 3-5 个不同颜色的像素构成（如红(2)、绿(3)、黄(4)、橙(7)），每个像素占一个对角位置 (0,0),(1,1),(2,2),...。对角标记不与掩码重叠（掩码起始行在对角标记之下）。生成约束：左右掩码的重叠像素数 >= 3（确保循环可观察）。

**规则**：
1. 定位灰(5)分隔列，将左右面板的蓝(1)掩码对齐（去除分隔列后，左右面板同一行同一相对列的像素配对）。
2. 逐像素计算逻辑交：仅当左、右对应位置均为蓝(1)时，该位置标记为重叠。
3. 读取对角标记的颜色序列，按从左上 (0,0) 到右下的顺序记为 C1, C2, C3, ...（共 K 个颜色）。
4. 将所有重叠位置按阅读顺序（从上到下、从左到右）排列为 P1, P2, P3, ...。
5. 输出网格与左面板同尺寸（11x7）。在输出中，Pi 位置涂色为 C((i-1) mod K + 1)。所有非重叠位置为黑(0)。
6. 分隔列、对角标记和右面板不出现在输出中。

**关键洞察**：对角标记在参考题 99306f82 中驱动空间上连续的同心层填充，但此处它驱动的是离散位置的循环着色——同一组颜色被复用于完全不同的空间分配机制。仅看一个示例可能误以为颜色按行分配或按距离分配，必须对比多个重叠模式不同的示例才能确认循环配对规则。

## 新题 5：角标记区域内连通分量按面积排名重涂色

**组合逻辑**：[角标记像素(corner_marker) + 裁剪(crop)](来自 3de23699) → [计数(counting) + 面积分类(area_classification)](创新：面积不再是绝对分类而是同一区域内的相对排名) → [重涂色(recolor)](创新：排名第一继承角标色，排名第二固定色，其余删除)

**来源原语**：角标记像素(corner_marker) ← 3de23699；裁剪(crop) ← 3de23699；计数(counting) ← d2abd087；面积分类(area_classification) ← d2abd087；重涂色(recolor) ← d2abd087；连通分量(connected_component) ← d2abd087；内部包含(containment) ← aba27056；角标色决定重涂(corner_color_sets_recolor) ← 3de23699

**依赖链**：角标记定义区域边界（裁剪的前提），区域内连通分量的面积计数产生排名（局部竞争），排名决定重涂色规则且第一名的颜色来自角标。删除角标记则无法分区；删除面积排名则无法区分分量；删除重涂色则排名无意义。三者形成"空间分区 → 局部竞争 → 差异化着色"的推理链。

角标记像素框定多个区域，每个区域内的灰色连通分量按面积竞争：最大者继承角标色，次大者变红，其余消失。

**输入结构**：黑(0)背景，约 15x15 网格。包含 2-3 组角标记，每组由 4 个同色像素构成一个矩形的四角（如蓝(1)四角、绿(3)四角），各矩形区域不重叠不相邻，各区域边界框约 5x5 至 7x7。每个角标记矩形的内部（不含角标记像素所在的边界行列）包含 2-4 个灰(5)色 4-连通分量，面积各不相同（范围 1-6 像素），形状不规则且各不相同。同一区域内各分量互不相邻。不同区域的角标记颜色不同。生成约束：每个区域内至少有 2 个分量；同一区域内无面积并列。

**规则**：
1. 识别所有角标记组：4 个同色像素构成矩形四角。记录每组的颜色和边界框。

**关键洞察**：面积在参考题 d2abd087 中是绝对阈值（恰好为 6），此处变为区域内相对排名——同样面积的分量在不同区域中可能获得不同的名次和颜色。这种"局部竞争"机制需要对比多个区域才能排除"按绝对面积映射颜色"的假设。

## 新题 7：对称性与平铺双重约束恢复遮挡区域

**组合逻辑**：[对称补全(symmetry_completion) + 二面体对称(dihedral_symmetry)] ⊗ [平铺(tiling) + 精确覆盖按形着色(exact_cover_by_shape)] → [裁剪(crop)]（非流水线：两个约束同时满足）

**来源原语**：对称补全(symmetry_completion) ← f4081712；二面体对称(dihedral_symmetry) ← f4081712；平铺(tiling) ← 626c0bcc；精确覆盖按形着色(exact_cover_by_shape) ← 626c0bcc；遮挡矩形(occluding_rect) ← f4081712；裁剪(crop) ← f4081712；小型瓦片(small_tile) ← 626c0bcc

**依赖链**：这不是流水线而是同时约束满足。遮挡区域的每个像素必须同时满足：(1) 整体图案具有 4 重旋转对称性（C4）；(2) 非背景像素构成的前景掩码可被 2x2 正方形瓦片和 L-三连骨牌精确覆盖且按形状着色。单独的对称性约束可能在某些位置有歧义（对称对应点也被遮挡），此时平铺约束提供额外信息（边界处的部分瓦片只有一种合法补全方式）。反之，单独的平铺约束在远离边界的区域可能有多种合法拼法，对称性约束帮助消歧。

恢复被绿色矩形遮挡的区域，须同时满足全局旋转对称性和局部精确平铺两个约束。

**输入结构**：黑(0)背景，约 13x13 网格（奇数边长以保证旋转中心为整数坐标）。非背景像素构成一个关于网格中心具有 C4 旋转对称性的前景图案，该图案可被如下四种小型瓦片精确覆盖：(a) 2x2 实心正方形，蓝(1)；(b) 2x2 区域去掉左上角的 L-三连骨牌，红(2)；(c) 2x2 区域去掉左下角的 L-三连骨牌，黄(4)；(d) 2x2 区域去掉右上角的 L-三连骨牌，橙(7)。前景像素总数约 40-60 个。一个 3x4 至 4x5 的实心绿(3)矩形覆盖了图案的一部分（遮挡块），遮挡块的位置不在旋转中心上且不跨过中心（确保存在未被遮挡的对称对应区域）。生成约束：遮挡块下方的原始图案在仅使用对称性时至少有一个像素歧义（其 C4 对称对应点中至少一个也被遮挡或为背景），该歧义可通过平铺约束唯一解决。

**规则**：
1. 输出网格的尺寸等于遮挡块（绿(3)矩形）的尺寸。
2. 对遮挡块内的每个位置 (r,c)（相对于整个网格），计算其在 C4 旋转下的 4 个等价坐标（旋转 0/90/180/270 度）。
3. 在这 4 个坐标中，忽略所有被遮挡（绿(3)）的坐标。若剩余坐标中存在非背景像素，则该位置的颜色候选为这些非背景像素的颜色（对称性约束下它们应一致）。
4. 若步骤 3 无法确定颜色（所有等价坐标要么被遮挡要么为背景），则使用平铺约束：检查该位置周围已确定的像素，推断该位置属于哪个瓦片类型并确定其颜色。具体方法：从遮挡块边界处已确定的瓦片向内延伸，每个部分瓦片只有一种合法补全方式。
5. 输出仅包含遮挡块区域恢复后的像素。

**关键洞察**：参考题 f4081712 仅用对称性恢复遮挡，626c0bcc 仅做平铺着色。此处两个独立约束必须**协同**工作：对称性解决大部分像素，平铺解决对称性留下的歧义。这是约束满足结构而非流水线。

## 新题 10：框架线十字分区后按分量面积选择性镜像

2. 提取左上象限中所有非背景非红色的 4-连通分量，计算每个分量的面积。
3. 对面积 >= 3 的分量：将其关于垂直轴镜像到右上象限，关于水平轴镜像到左下象限，关于中心点（同时关于两轴）镜像到右下象限。三个镜像副本均重涂色为灰(5)。

**关键洞察**：参考题 f8a8fe49 中所有图案无差别地跨框架轴镜像，参考题 d2abd087 中面积仅决定颜色。此处面积成为**操作分支的控制条件**——它不改变"涂什么色"，而改变"做什么操作"（完整二面体镜像 vs 单轴镜像），这种"条件分支操作"结构在所有参考题中不存在。
