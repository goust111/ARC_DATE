## 新题 1：交叉层序定色的封闭区域填充

**组合逻辑**：[层序推断](从交叠条到交叠轮廓) + [洪泛填充](从外部边界到内部墙壁结构) → 层序决定填充色（创新：层序结果不是提取单一最高层，而是为每个封闭区域分配对应的填充色）

**来源原语**：层序推断(infer_layer_order) ← 1a2e2828；洪泛填充(flood_fill) ← a5313dff；正交交叉(orthogonal_crossing) ← 1a2e2828；区域封闭(region_enclosure) ← a5313dff

**依赖链**：洪泛填充需要知道哪些像素是墙壁（所有颜色的轮廓都是墙壁），但填充色的分配需要层序推断的结果；层序推断依赖交叉点处的可见色信息；两个分析必须同时进行才能确定最终输出。

将多条交叠的彩色闭合轮廓所围成的内部区域，按轮廓层序中最底层边界色进行填充。

**输入结构**：约 15x15 的黑(0)背景网格。3~5 条不同颜色的单像素宽闭合轮廓线分布在网格中，每条轮廓各使用一种非黑色（如红(2)、蓝(1)、绿(3)、黄(4)等）。轮廓线形成不规则的封闭环（4~8 个边的多边形轮廓，非严格矩形），部分轮廓之间存在正交交叉——即一条轮廓的水平段与另一条轮廓的垂直段相交。在交叉像素处，只有一种颜色可见（遮挡了另一种），由此编码层叠顺序。轮廓之间的交叠划分出若干封闭背景区域（黑色区域被轮廓包围，无法通过 4-邻域路径到达网格边界）。生成约束：每个封闭区域的边界至少由两条不同颜色的轮廓共同构成；所有轮廓完整闭合，不存在断口。

**规则**：
1. 将所有非黑像素视为墙壁。从网格四条边的所有黑(0)像素出发，沿 4-邻域方向进行洪泛填充标记所有可达的外部黑像素。未被标记的黑像素即为封闭区域。
2. 对每一对正交交叉的轮廓，观察交叉像素处可见的颜色：可见色为上层，被遮挡色为下层。汇总所有交叉点的约束，构建从底到顶的完整层叠顺序（保证无环）。
3. 对每个封闭区域，找出构成其边界的所有轮廓颜色，取其中层叠顺序最低（最底层）的那个颜色作为该区域的填充色。
4. 将每个封闭区域的所有黑像素涂为该填充色。外部黑像素和所有轮廓像素保持不变。

**关键洞察**：填充色不是最显眼的上层色，而是最底层的边界色——必须对比多个示例中不同层序配置下的填充结果才能排除"用最高层色填充"或"用最多边界色填充"等替代假设。

## 新题 2：控制像素双重身份——定框与自相似印章

**组合逻辑**：[描框](控制像素定义矩形边界) + [印章覆盖 + 自相似嵌套](控制像素相对位置构成印章图案，在框内自相似展开)（创新：控制像素既定义框架又定义印章内容，双重身份耦合）

**来源原语**：描框(draw_frame)、控制像素(control_pixel)、极值行列(extreme_row_col)、控制极值定矩形(ctrl_extremes_rect) ← e4075551；印章覆盖(stamp)、自相似嵌套(self_similar_nesting)、前景位置决定印章(foreground_positions_determine_stamp) ← 8f2ea7aa

**依赖链**：控制像素的绝对位置定义矩形框的范围；控制像素的归一化相对位置形成一个微型图案（印章）；该图案在矩形框内进行一次自相似展开——图案中每个前景位置放置一份完整图案的缩放副本。框的尺寸约束了展开层数。

用散布的彩色控制像素同时定义一个矩形边框和一个自相似展开的内部图案。

**输入结构**：约 12x12 的黑(0)背景网格。网格中恰好有 4 个灰(5)像素，它们分别具有所有控制像素中最上、最下、最左、最右的行列坐标，由此唯一确定一个矩形范围。在矩形内部（不含边框行列），还有若干红(2)像素分布在不同位置，数量 2~4 个。矩形外部无其他非黑像素。生成约束：矩形内部区域的行数和列数均为 3 或 4（使自相似展开恰好一层）；红(2)像素之间互不相邻（8-邻域）。

**规则**：
1. 找到 4 个灰(5)像素，取最上者的行、最下者的行、最左者的列、最右者的列，确定矩形框范围。用灰(5)画出该矩形的四条边（顶底为完整水平线段，左右为顶底之间的垂直线段）。
2. 将矩形内部区域（不含边框）视为一个 R 行 x C 列的子网格。将所有红(2)像素的坐标归一化为子网格内的局部坐标 (lr, lc)，形成一个二值图案 P（P[lr][lc]=1 表示该处有红像素）。
3. 自相似展开：创建一个 R*R 行 x C*C 列的虚拟画布（但实际输出仍为原网格大小，因此只取左上角 R x C 区域）。对图案 P 中每个值为 1 的位置 (lr, lc)，在虚拟画布的第 (lr*R) 到 (lr*R+R-1) 行、第 (lc*C) 到 (lc*C+C-1) 列的子块中，再次绘制图案 P（用红(2)标记前景位置）。
4. 将虚拟画布的前 R 行 x C 列裁剪出来，写回矩形内部区域。超出矩形内部的部分丢弃。

**关键洞察**：控制像素同时扮演"框架定位锚"和"印章内容源"两个角色——必须识别出同一组像素的双重功能，才能理解内部图案不是随机的，而是控制像素自身的递归展开。

## 新题 3：等价性门控的边距模式迁移

**组合逻辑**：[形状匹配](旋转翻转等价判断) → 门控 → [图案迁移](边距保持迁移)（创新：形状匹配的结果不是填充表格，而是决定哪些目标矩形接收迁移图案）

**来源原语**：形状匹配(shape_match)、归一化掩码(normalized_mask)、旋转翻转等价(dihedral_equiv) ← 6165ea8f；图案迁移(pattern_transfer)、纯色矩形(plain_rectangle)、带标记矩形(marked_rectangle)、边距保持迁移(edge_relative_transfer) ← 57edb29d

**依赖链**：首先对每个纯色矩形的外轮廓形状进行归一化，与带标记矩形的外轮廓形状做旋转翻转等价比较；仅当两者等价时，才将带标记矩形的内部标记图案按边距保持规则迁移到该纯色矩形中。等价判断决定了迁移是否发生，迁移内容依赖于匹配到的具体带标记矩形。

将带标记矩形的内部图案迁移到与其外轮廓形状旋转翻转等价的纯色矩形中。

**输入结构**：约 20x20 的黑(0)背景网格。网格中散布 4~6 个不同颜色的实心矩形（每个矩形由单一非黑色填充，颜色各不相同，如蓝(1)、红(2)、绿(3)、黄(4)、灰(5)、品红(6)）。矩形尺寸各异（宽高均在 3~7 之间），不互相接触。其中 1~2 个矩形内部含有橙(7)标记像素——标记像素以某种相对于矩形边缘的固定图案分布（如距顶边 1 行、距左边 1 列处有一个标记，距底边 1 行、距右边 2 列处有另一个标记）。其余矩形为纯色（无标记像素）。每个矩形的外轮廓形状定义为其行数和列数构成的有序对 (H, W)，旋转翻转等价意味着 (H, W) 和 (W, H) 视为等价。生成约束：至少有一个纯色矩形与某个带标记矩形外轮廓等价，至少有一个纯色矩形与任何带标记矩形都不等价。

**规则**：
1. 识别所有矩形，区分带标记矩形（内部含橙(7)像素）和纯色矩形（内部仅有单色）。
2. 对每个纯色矩形，将其尺寸 (H, W) 与每个带标记矩形的尺寸比较：若 (H, W) 相同或 (H, W) = 对方的 (W', H')（即旋转 90 度后匹配），则认为等价。
3. 对等价的纯色矩形，将带标记矩形中橙(7)标记的边距位置迁移过来：每个标记距其源矩形四条边的像素距离 (dt, db, dl, dr) 保持不变地映射到目标矩形中。若源矩形和目标矩形的行列互换（即 H=W', W=H'），则标记的行距映射为列距、列距映射为行距（等效于将标记图案旋转 90 度）。用橙(7)绘制迁移后的标记。
4. 不等价的纯色矩形保持不变。带标记矩形本身也保持不变。
5. 若多个带标记矩形都与同一个纯色矩形等价，按带标记矩形的边界框左上角从左到右、从上到下的顺序，后处理的标记覆盖先处理的。

**关键洞察**：图案迁移不是对所有纯色矩形统一执行的——只有外轮廓在旋转翻转意义下与带标记矩形匹配的纯色矩形才接收图案，且匹配涉及行列互换时标记图案也相应旋转。

## 新题 4：射线构墙后噪声过滤再封闭区域填充

**组合逻辑**：[射线延伸](从标记点沿引导线垂直方向发射射线构成新墙壁) → [擦除](移除孤立单像素噪声，可能打开或封闭区域边界) → [洪泛填充](识别并填充封闭区域)（创新：射线构造的墙壁和噪声像素共同影响区域封闭性，擦除噪声后封闭性可能改变）

**来源原语**：射线延伸(ray_extend)、标记环(marker_ring)、引导线(guide_line)、投射到引导线(projection_to_guide) ← ac3e2b04；擦除(erase)、孤立像素(isolated_pixel)、单像素分量移除(single_pixel_removed)、八连通判定(eight_connectivity) ← 42a50994；洪泛填充(flood_fill)、封闭区域(enclosed_region)、区域封闭(region_enclosure) ← a5313dff

**依赖链**：射线延伸创建新的墙壁线段，改变了网格的拓扑结构。噪声像素中有些恰好堵住了墙壁缺口——擦除它们后原本封闭的区域可能变为开放。洪泛填充的结果同时依赖于射线构建的新墙壁和噪声清除后的墙壁完整性。

从引导线上的标记发射射线构建新墙壁，清除单像素噪声后，填充所有仍然封闭的背景区域。

**输入结构**：约 15x15 的黑(0)背景网格。2~3 条红(2)全宽水平引导线贯穿网格。每条引导线上有 1~2 个绿(3)标记像素（单像素，不是环形）。网格中散布若干灰(5)单像素噪声点（孤立的，8-邻域内无其他灰像素），数量 3~6 个，部分灰像素恰好位于引导线之间的关键位置（若不擦除则会封闭某区域）。生成约束：射线发射后加上噪声像素至少形成 2 个封闭区域；擦除噪声后至少有 1 个原本封闭的区域变为开放（确保擦除步骤对结果有实质影响）；所有标记像素位于引导线上。

**规则**：
1. 对每个绿(3)标记像素，确定其所在的红(2)水平引导线。从标记像素所在列出发，向上和向下发射蓝(1)垂直射线，逐像素绘制，直到到达网格边界为止。射线仅覆盖黑(0)背景像素，遇到非黑像素时跳过该像素继续延伸（射线不中断）。
2. 将所有灰(5)像素按 8-连通分组。移除所有大小为 1 的灰色连通分量（将其涂回黑(0)）。大小大于 1 的灰色分量保留（本题生成约束保证所有灰像素均为孤立的，因此全部被移除）。
3. 将所有非黑像素（红(2)引导线 + 绿(3)标记 + 蓝(1)射线）视为墙壁。从网格四条边上的所有黑(0)像素出发做 4-邻域洪泛填充，标记所有可达的外部黑像素。
4. 将所有未被标记的黑(0)像素涂为黄(4)。所有其他像素保持不变。

**关键洞察**：某些看似封闭的区域之所以封闭，是因为灰色噪声像素恰好堵住了缺口——擦除噪声后缺口打开，该区域不再被填充。必须对比包含和不包含噪声的示例才能发现擦除步骤的存在。

## 新题 5：对角楔形碰壁后镜像反弹填充

**组合逻辑**：[填充 + 沿对角线传播](顶行色带向下生成收缩楔形) → [镜像](楔形尖端碰到障碍物后沿碰撞轴镜像反弹，继续生成扩张楔形)（创新：楔形不是简单地收缩到消失，而是碰到障碍后反弹，镜像规则由碰撞方向决定）

**来源原语**：填充(fill)、顶行色带(top_row_band)、收缩楔形(shrinking_wedge)、沿对角线传播(diagonal_propagate)、逐行交换双色(row_swap_bicolor) ← b5bb5719；镜像(mirror)、相邻槽位翻转(adjacent_slot_flip) ← c48954c1

**依赖链**：楔形的几何形态决定了它何时何处碰到障碍物；碰撞位置和障碍物方向决定了镜像轴；镜像后的扩张楔形的双色交替规则延续自碰撞前的楔形——必须追踪楔形的完整生成历史才能确定反弹后每个像素的颜色。

顶行双色色带向下生成收缩楔形，楔形尖端碰到水平障碍后镜像反弹为扩张楔形。

**输入结构**：约 14x14 的橙(7)背景网格。顶行（第 0 行）有一段连续的红(2)和灰(5)交替色带，宽度为奇数（5~9 像素），色带中红(2)和灰(5)按像素交替排列。在网格中间偏下的位置（约第 7~10 行）有一条完整的蓝(1)水平线段，宽度至少与色带等宽，作为障碍物。生成约束：楔形收缩到尖端时恰好到达障碍物上方（色带宽度的一半等于色带到障碍物的行距），使楔形尖端刚好触碰障碍物；障碍物下方有足够的行数容纳反弹后的扩张楔形。

**规则**：
1. 识别顶行色带的起止列 (L, R) 和色带中每个像素的颜色。
2. 收缩阶段：从第 1 行开始，每下移一行 r（r=1,2,...），填充列范围 [L+r, R-r]。对于该范围内的每一列 c，取顶行中列 c 的颜色，然后翻转 r 次（红(2)↔灰(5)每行翻转一次）：若 r 为奇数则红变灰、灰变红；若 r 为偶数则保持顶行原色。当 L+r > R-r 时停止收缩（仅剩一列或零列）。设最后一个有效行为第 T 行。
3. 如果第 T+1 行存在蓝(1)障碍物，则进入反弹阶段。蓝(1)障碍物本身不被修改。
4. 扩张阶段：从障碍物下方第一行开始，令反弹偏移 d=1,2,...。填充列范围 [L+(T-d+1), R-(T-d+1)]（即楔形从尖端重新扩张）。每个像素的颜色以反弹点为基准继续翻转——等效于取收缩阶段中对称行的颜色再做一次红灰互换。当列范围恢复到 [L, R] 或到达网格底边时停止。
5. 超出网格边界的部分丢弃。

**关键洞察**：反弹后的楔形不是收缩楔形的简单垂直镜像——每一行的双色交替延续了碰撞前的翻转计数，因此反弹区域的颜色模式与碰撞前并非镜像对称，而是翻转序列的延续。需要对比多个示例中不同色带宽度和障碍物位置的情况才能发现这一规律。

## 新题 6：位移向量解码驱动的精灵体裁剪嵌入

**组合逻辑**：[平移 + 位移向量推断](从部分副本推断位移方向) → [裁剪](沿位移方向裁剪精灵体得到适配形状) → [嵌入填充](将裁剪后的精灵体嵌入匹配的空腔)（创新：位移向量不是用于重复投射精灵体，而是指示裁剪方向——沿位移反方向裁去精灵体的一部分使其恰好适配目标空腔）

**来源原语**：平移(translate)、位移向量(displacement_vec)、部分副本(partial_copy)、副本指示方向与色(copy_dir_and_color) ← 045e512c；裁剪(crop) ← 57edb29d；嵌入填充(inlay_fill)、模板框架(template_frame)、矩形空腔(rectangular_cavity)、尺寸匹配(size_matching)、唯一槽位配对(unique_slot_pairing) ← 5dbc8537

**依赖链**：部分副本的偏移揭示位移向量；位移向量的方向指示裁剪方向（从精灵体的哪一侧裁去像素）；裁剪量由目标空腔的尺寸决定；裁剪后精灵体必须与某个空腔尺寸严格匹配才能嵌入。三个步骤互锁——不知道位移方向就不知道裁剪方向，不知道空腔尺寸就不知道裁剪量。

通过部分副本推断位移方向，沿该方向裁剪精灵体至目标空腔尺寸后嵌入。

**输入结构**：约 18x18 的黑(0)背景网格。网格中央有一个灰(5)大矩形模板框架（约 8x10），内部挖有 2~3 个矩形空腔（黑(0)区域），空腔尺寸各不相同。模板外散布 2~3 个彩色精灵体（每个 4~6 像素的 4-连通单色小图形，颜色各异如红(2)、蓝(1)、绿(3)）。每个精灵体旁边有一个同色的部分副本——副本是精灵体的一个连续子集（1~2 个像素），与精灵体沿某个基本方向（上/下/左/右）偏移若干格放置。精灵体的完整尺寸大于任一空腔的对应维度 1~2 个像素。生成约束：每个精灵体恰好有唯一一个裁剪方向和裁剪量使其匹配唯一一个空腔；各精灵体对应不同空腔。

**规则**：
1. 识别模板框架及其内部空腔，记录每个空腔的行数和列数。
2. 对每个精灵体，找到其同色的部分副本。将部分副本的像素坐标与精灵体的像素坐标对齐，确定使副本成为精灵体子集的最佳平移向量 (dr, dc)。该向量即为位移方向。
3. 位移方向指示裁剪侧：若位移向右 (dc>0)，从精灵体左侧裁去列；若向左 (dc<0)，从右侧裁去列；若向下 (dr>0)，从顶部裁去行；若向上 (dr<0)，从底部裁去行。裁剪量选取使裁剪后精灵体的边界框尺寸恰好匹配某个空腔的尺寸。
4. 将裁剪后的精灵体（保持其像素图案的相对位置）嵌入匹配的空腔，左上角对齐。精灵体像素覆盖空腔中的黑(0)像素。
5. 无法匹配任何空腔的精灵体不做处理。输出为模板框架区域的裁剪（含已嵌入的精灵体）。

**关键洞察**：部分副本不是用来指示射线延伸的方向（如参考题 045e512c），而是编码裁剪方向——精灵体必须沿位移的反方向被裁去多余部分才能适配空腔。

## 新题 7：墙壁缺口长度编码封闭区域填充色

**组合逻辑**：[洪泛填充](识别封闭区域) + [计数](测量边界墙壁的缺口总长度) → [重涂色](按固定编码表将缺口长度映射为填充色)（创新：封闭区域的存在性和填充色由两个不同的结构属性决定——区域是否封闭取决于墙壁拓扑，填充色取决于边界缺口的度量）

**来源原语**：洪泛填充(flood_fill)、封闭区域(enclosed_region)、墙壁线段(wall_segment)、区域封闭(region_enclosure)、孤立背景区域填充(unreachable_background_filled) ← a5313dff；计数(counting)、条形段(bar_segment)、长度映射颜色(length_maps_color)、固定编码表(fixed_encoding) ← e048c9ed；重涂色(recolor) ← e048c9ed

**依赖链**：洪泛填充确定哪些区域被封闭（只有被双层墙壁包围的区域才算封闭——外层墙壁可能有缺口但内层弥补）。缺口长度计数必须在确认封闭性之后进行，因为只有封闭区域的外层边界缺口才参与计数。填充色由编码表将缺口长度映射得到。

测量封闭区域外层边界墙壁的缺口像素总数，通过固定编码表将其映射为该区域的填充色。

**输入结构**：约 14x14 的黑(0)背景网格。若干红(2)线段（水平或垂直，长度 3~8 像素）构成近似封闭的矩形或多边形框架。每个框架的红(2)轮廓有 0~2 处缺口（缺口为轮廓上被黑(0)替代的 1~3 个连续像素），但框架内部还有一层蓝(1)线段补强——蓝(1)线段覆盖了缺口对应的内侧位置，使得即使红(2)外层有缺口，区域整体仍然封闭（从外部沿 4-邻域无法穿透红蓝双层墙壁到达内部）。网格中有 2~4 个这样的框架，互不相交。生成约束：每个框架的红(2)外层缺口总长度各不相同（如 0、1、2、3 像素），对应编码表中不同的颜色。

**规则**：
1. 将所有红(2)和蓝(1)像素视为墙壁。从网格边界所有黑(0)像素出发做 4-邻域洪泛填充，标记外部可达区域。未标记的黑(0)像素集合为封闭区域。
2. 对每个封闭区域，找到其边界上所有红(2)线段。沿每条红(2)线段的延伸方向检查连续性，每遇到一处断开的黑(0)段，累加该段的像素长度。将该区域所有红(2)边界线段的缺口长度求和，得到总缺口数 G。
3. 按固定编码表将 G 映射为填充色：G=0 → 黄(4)，G=1 → 绿(3)，G=2 → 品红(6)，G=3 → 橙(7)。
4. 用映射得到的颜色填充该封闭区域的所有黑(0)像素。红(2)和蓝(1)墙壁像素保持不变。

**关键洞察**：编码表是隐式的——题目不会给出映射关系，必须从多个示例中观察不同缺口数量的框架被填充了什么颜色来归纳出 G → 颜色的映射规则。

## 新题 8：分块主色选模板后逐像素模板膨胀

**组合逻辑**：[查表映射](分块内主色决定膨胀模板) + [像素放大](用所选模板替代每个前景像素)（创新：膨胀不是固定的 2x2 块，而是由分块内主色从编码表中选取的特定模板形状——不同分块中相同的前景像素会被膨胀为不同形状）

**来源原语**：查表映射(lookup_mapping)、主色决定输出模板(dominant_color_stencil)、忽略干扰项(ignore_distractors)、固定模板(fixed_stencil)、前景像素(foreground_pixel) ← 9110e3c5；像素放大(pixel_expand)、孤立像素(isolated_pixel)、局部膨胀再倍增(local_then_global_scale) ← 46f33fce；网格分块(grid_partitioning)、瓦片(tile) ← 5bd6f4ac

**依赖链**：网格分块决定了每个像素属于哪个分块；分块内的主色统计决定了该分块使用哪个膨胀模板；模板决定了每个非背景像素如何膨胀。改变分块边界会改变主色统计，进而改变膨胀形状。

将网格等分为若干分块，每个分块的主色选择一个膨胀模板，用该模板替换分块内每个非背景像素。

**输入结构**：12x12 的黑(0)背景网格，等分为 4 个 6x6 分块（2x2 排布）。每个分块内散布 3~5 个非黑前景像素，前景像素间互不 4-邻域相邻。每个分块的前景像素包含 1 种主色（出现 2~3 次）和 1 种干扰色（出现 1 次）。主色只使用红(2)、蓝(1)、绿(3) 三种之一，各分块主色可相同或不同。干扰色可以是任意其他非黑色。生成约束：每个分块内前景像素的 3x3 邻域内无其他前景像素（保证膨胀后不重叠）。

**规则**：
1. 将 12x12 网格等分为 4 个 6x6 分块（左上、右上、左下、右下）。
2. 对每个分块，统计各非黑颜色的像素数量，确定唯一最多的颜色为主色。
3. 按编码表选择膨胀模板（3x3 的二值掩码，1 表示填充、0 表示背景）：
   - 主色为蓝(1) → 模板为左下钩形：`[[0,0,0],[0,0,0],[1,1,0]]` 加 `[[0,0,0],[1,0,0],[1,0,0]]` 即 `{(1,0),(2,0),(2,1)}`
   - 主色为红(2) → 模板为中行横条：`{(1,0),(1,1),(1,2)}`
   - 主色为绿(3) → 模板为右上钩形：`{(0,1),(0,2),(1,2)}`
4. 对分块内每个非黑前景像素（包括主色和干扰色），以该像素为模板的中心 (1,1) 位置，将模板中值为 1 的位置用青(8)涂色。涂色仅在该分块范围内进行，超出分块边界的部分丢弃。原前景像素本身被涂为青(8)（因为模板中心可能在掩码内也可能不在）。
5. 干扰色的原始像素也被膨胀处理（使用该分块的模板），不做区别对待。干扰色仅影响主色统计，不影响膨胀行为。

**关键洞察**：主色不是被膨胀的颜色——所有前景像素（无论主色还是干扰色）都统一使用青(8)膨胀，主色仅起"选择模板"的作用。必须对比不同分块中相同颜色像素被膨胀为不同形状的情况才能发现模板选择机制。

## 新题 9：空心矩形内孔与外部精灵体的等价匹配门控填充

**组合逻辑**：[形状匹配 + 旋转翻转等价](精灵体掩码与矩形内孔掩码比较) → 门控 → [填充](仅匹配成功的矩形内部被填充)（创新：等价判断不是输出为表格，而是作为条件门控决定是否填充——且填充色由匹配到的精灵体的颜色决定，不是统一颜色）

**来源原语**：填充(fill)、空心矩形(hollow_rectangle)、封闭孔洞(enclosed_hole)、仅填矩形内部(fill_interior_only) ← e73095fd；形状匹配(shape_match)、归一化掩码(normalized_mask)、旋转翻转等价(dihedral_equiv) ← 6165ea8f；精灵体(sprite) ← 228f6490

**依赖链**：精灵体的归一化掩码与矩形内孔的归一化掩码必须在旋转翻转等价意义下匹配；匹配成功时用精灵体颜色填充该矩形内部。填充色不是预设的，而是由匹配关系动态确定的——换一个精灵体就换一个填充色。

若外部精灵体的形状与空心矩形的内孔在旋转翻转下等价，则用精灵体的颜色填充该矩形内部。

**输入结构**：约 16x16 的黑(0)背景网格。3~4 个灰(5)空心矩形分布在网格中（矩形轮廓为灰(5)，内部为黑(0)孔洞），矩形尺寸各异（外部 4x4 到 7x7，壁厚 1 像素，因此内孔为 2x2 到 5x5），不互相接触且不触碰网格边界。网格的边缘区域散布 3~5 个彩色小精灵体（每个 3~6 像素的 4-连通单色图形，颜色各异如红(2)、蓝(1)、绿(3)、黄(4)），精灵体间互不接触。每个精灵体的边界框尺寸与某些矩形内孔的尺寸可能匹配也可能不匹配。生成约束：至少 2 个矩形有匹配的精灵体，至少 1 个矩形无匹配精灵体，至少 1 个精灵体不匹配任何矩形内孔。

**规则**：
1. 识别所有灰(5)空心矩形，提取每个矩形的内孔区域（内部黑(0)像素的边界框），将内孔视为二值掩码 M_hole（黑=前景，灰=无关）。
2. 识别所有非灰、非黑的精灵体（4-连通单色分量）。将每个精灵体裁剪至其边界框，生成二值掩码 M_sprite（有色=前景，黑=背景）。
3. 对每对 (矩形内孔, 精灵体)，检查 M_hole 和 M_sprite 在 8 种旋转翻转变换下是否存在至少一种使两个掩码完全相同。若存在则记为匹配。
4. 对每个矩形，若恰好有一个精灵体与之匹配，用该精灵体的颜色填充矩形内部所有黑(0)像素。若有多个精灵体匹配同一矩形（生成时避免，但规则上：选边界框面积较小的精灵体）。若无匹配精灵体，矩形内部保持黑(0)不变。
5. 灰(5)轮廓和所有精灵体的原始像素保持不变。

**关键洞察**：填充色不是固定的黄色（不同于参考题 e73095fd 的统一黄色填充），而是由匹配到的精灵体动态决定——同一个矩形在不同示例中可能因匹配到不同精灵体而填充不同颜色，必须发现形状等价关系才能预测填充色。

## 新题 10：标记色编码距离的帧内方向性复制

**组合逻辑**：[描框](控制像素定义矩形帧) + [复制 + 填充](标记像素按颜色编码的距离沿方向复制并用帧色连接)（创新：复制方向不是固定的"向上"，而是由标记像素相对于帧内枢轴行的位置决定——枢轴行上方的标记向上复制，下方的向下复制；帧的边界限制了复制的最大距离）

**来源原语**：描框(draw_frame)、控制像素(control_pixel)、枢轴像素(pivot_pixel)、极值行列(extreme_row_col)、控制极值定矩形(ctrl_extremes_rect)、枢轴连四边(pivot_to_sides) ← e4075551；复制(copy)、填充(fill)、标记像素(marker_pixel)、全宽行(full_width_row)、同列对齐(same_column_aligned)、标记色编码距离(marker_color_encodes_distance) ← 72a961c9

**依赖链**：控制像素定义帧边界；帧内有一条水平枢轴行和其上的标记像素；标记像素的颜色编码复制距离；标记相对于枢轴行的位置编码复制方向（上/下）；帧边界限制了复制的最远距离（超出帧边界则截断）。每个要素都影响最终结果。

在控制像素定义的矩形帧内，将枢轴行上的彩色标记按颜色编码的距离向远离枢轴的方向复制，用帧色填充间隔。

**输入结构**：约 14x14 的黑(0)背景网格。4 个蓝(1)像素分别位于所有前景像素中最上、最下、最左、最右的位置，定义矩形帧的四个边界行列。帧内部有一条黄(4)水平全宽行（贯穿帧内左右边界之间所有列），位于帧高度的大致中间位置。该黄(4)行上有 2~4 个标记像素，颜色为红(2)或绿(3)，替换该位置原来的黄(4)。标记分布在枢轴行的上半区列和下半区列（即某些标记的列坐标靠近帧的左边界，另一些靠近右边界——但方向由行位置决定，见规则）。生成约束：枢轴行与帧顶边的距离和与帧底边的距离均 >= 4 行，保证所有编码距离的复制都不会超出帧边界。

**规则**：
1. 找到 4 个蓝(1)像素的极值行列，画出蓝(1)矩形帧（与参考题 e4075551 相同方式：顶底为水平线段，左右为连接顶底的垂直线段）。
2. 识别帧内黄(4)水平行为枢轴行。枢轴行将帧内部分为上半区和下半区。
3. 对枢轴行上每个非黄标记像素：
   - 读取颜色编码的距离：红(2) → 距离 3，绿(3) → 距离 4。
   - 确定复制方向：将帧内部按枢轴行分为上半区（枢轴行上方）和下半区（枢轴行下方）。若标记所在列更靠近帧左边界（列坐标 < 帧水平中点），方向为向上（远离枢轴向帧顶）；若更靠近帧右边界（列坐标 >= 帧水平中点），方向为向下（远离枢轴向帧底）。
4. 沿确定的方向，在标记所在列上，距枢轴行恰好"距离"行处复制一个与标记同色的像素。
5. 用黄(4)填充标记像素与复制像素之间该列上的所有黑(0)像素（不覆盖已有的蓝(1)帧边界像素）。
6. 枢轴行上未被标记替换的黄(4)像素保持不变。帧外所有像素保持不变。

**关键洞察**：复制方向不是统一向上——它取决于标记像素在帧内的水平位置（左半→向上，右半→向下）。仅凭单个示例可能误判方向规则为统一方向或按颜色决定方向，必须对比多个标记在不同水平位置的复制行为才能归纳出真正的方向规则。
