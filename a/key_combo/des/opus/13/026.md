## 新题 1：框内标记计数驱动精灵旋转

**组合逻辑**：[计数/counting](创新：计数结果不编码到输出网格，而是参数化后续旋转角度) + [旋转/rotate](创新：旋转角度由外部计数动态决定而非固定) + [包含/containment](已有) + [擦除/erase](已有)

**来源原语**：计数/counting ← 3b4c2228, d4c90558；旋转/rotate ← a416fc5b；包含/containment ← d4c90558；标记像素/marker_pixel ← d4c90558, dc1df850；空心矩形/hollow_rect ← d4c90558；精灵体/sprite ← e3721c99

**依赖链**：计数操作的输出（一个整数）直接参数化旋转操作的角度；包含关系决定哪些标记属于哪个框架，从而使每个精灵获得独立的旋转角度；擦除操作清除已完成使命的标记像素。三者缺一不可：无计数则旋转角度不确定；无包含则标记与框的归属模糊；无擦除则标记干扰输出。

统计每个空心矩形框内的灰色标记像素数量，以此决定框内精灵的旋转角度，然后清除标记像素。

**输入结构**：黑(0)背景上有 3~5 个单色空心矩形框（每个框的颜色各异，取自红(2)、蓝(1)、绿(3)、黄(4)、品红(6)），每个框的边界框尺寸在 7x7~10x10 之间。每个框的内部（框内空心区域）包含：(a) 一个由与框同色像素构成的 4-连通不对称小图形（3~6 像素），位于框内部的中心附近；(b) 0~3 个灰(5)标记像素，散布在框内部但不与精灵相邻。不同框之间互不重叠且至少间隔 1 像素。网格尺寸约 25x25。生成约束：每个精灵的边界框不超过 3x3 且不具有 90 度旋转对称性（保证不同旋转角度产生不同输出）。

**规则**：
1. 对每个空心矩形框，统计其边界框严格内部的灰(5)标记像素数量 N。
2. 以精灵的边界框中心为旋转锚点，将精灵顺时针旋转 N x 90 度。旋转后精灵保持在框内，新位置的像素用精灵颜色绘制，原位置清空为黑(0)。若旋转后精灵的某些像素落在框边界上或框外（因锚点偏移），则裁切到框内部范围内。
3. 移除所有灰(5)标记像素，替换为黑(0)。
4. 空心矩形框本身、背景像素保持不变。

**关键洞察**：灰色标记不是装饰——它们编码了旋转角度。必须按框逐一计数（非全局计数），每个精灵获得独立的旋转参数。需对比多个示例才能归纳出"标记数 x 90度"的映射规则，因为单个示例中仅能观察到一种映射关系。

## 新题 2：跨轴镜像后原件与镜像的棋盘相位对立

**组合逻辑**：[镜像/reflect](已有) + [填充/fill → 棋盘格](创新：棋盘相位由"原件/镜像"身份决定，而非由绝对坐标或固定规则决定) + [边框与内部分离/border_interior_split](已有) + [分隔色填充间隙/sep_color_fills_gap](已有)

**来源原语**：镜像/reflect ← 538b439f；棋盘格图案/checkerboard + 行列奇偶决定填充/parity_fill ← ba9d41b8；实心矩形/solid_rectangle ← ba9d41b8, 538b439f；分隔线/separator_line + 间隙带/gap_strip + 跨轴对称/cross_axis_symmetry ← 538b439f；边框与内部分离/border_interior_split ← ba9d41b8

**依赖链**：镜像操作创建反射副本并确定间隙带范围 → 棋盘填充分别作用于原件和镜像的内部，但原件用偶数相位、镜像用奇数相位 → 相位的选择依赖于"该矩形是原件还是镜像"这一身份信息，而身份信息由镜像步骤产生。跳过镜像则无镜像矩形可供差异化填充；跳过棋盘则输出仅是简单的镜像复制。

将实心矩形跨分隔线镜像，在间隙中填充分隔色，然后对所有矩形（原件与镜像）的内部施加棋盘掏空，但原件与镜像的棋盘相位互为反转。

**输入结构**：黑(0)背景，网格尺寸约 15x25（宽 x 高）。一条全宽水平橙(7)分隔线位于网格中部偏上（约第 8 行）。分隔线上方有 2~3 个单色实心矩形（每个至少 4x4，颜色各异，取自红(2)、蓝(1)、绿(3)），互不接触且不触碰分隔线（与分隔线至少间隔 1 行）。分隔线下方全为黑(0)背景。生成约束：每个矩形与分隔线之间的间距加上矩形高度不超过分隔线到网格底边的距离（保证镜像后不超出网格）。

**规则**：
1. 将每个原始矩形跨橙(7)分隔线做垂直镜像，生成颜色相同的镜像矩形。镜像锚轴为分隔线所在行。
2. 对每个原始矩形与其镜像之间的矩形带状区域（列范围与矩形相同，行范围从原始矩形底边+1 到镜像矩形顶边-1，含分隔线本身所在行），将该区域全部填充为橙(7)。
3. 对每个原始矩形（分隔线上方的）：保留其最外一圈边框不变；对其内部区域（去掉最外一圈后的矩形），以内部左上角为锚点，将行号+列号（相对于该内部左上角）为偶数的格子替换为黑(0)，其余格子保留原色。
4. 对每个镜像矩形（分隔线下方的）：同样保留最外一圈边框不变；对其内部区域，以内部左上角为锚点，将行号+列号（相对于该内部左上角）为**奇数**的格子替换为黑(0)，其余格子保留原色。
5. 背景、分隔线（已被间隙填充覆盖的部分除外）保持不变。

**关键洞察**：原件和镜像并非简单的几何镜像关系——它们的棋盘掏空相位相反。仅看一个示例可能误判为"所有矩形用同一相位"，必须对比包含不同尺寸矩形的多个示例，才能发现原件用偶数相位而镜像用奇数相位这一非对称规则。

## 新题 3：行列标签匹配定位后印章光环扩散

**组合逻辑**：[填充/fill](创新：填充结果不作为最终输出，而是作为后续印章操作的定位输入) + [印章覆盖/stamp_overlay](创新：印章中心不是预设的标记像素，而是由标签匹配动态产生) + [行列交叉/row_col_intersection](已有) + [邻域扩展/neighborhood_expand](已有) + [仅填背景格/only_fill_background](已有)

**来源原语**：填充/fill + 行标签/row_label + 列标签/column_label + 标签同色时填充/labels_match_fill + 行列交叉/row_col_intersection ← a406ac07；印章覆盖/stamp_overlay + 光环区域/halo_region + 邻域扩展/neighborhood_expand + 仅填背景格/only_fill_background ← dc1df850

**依赖链**：标签匹配决定哪些内部单元格被填色 → 被填色的单元格成为光环扩散的中心点 → 光环仅覆盖背景格，不覆盖已填色格和标签格。跳过标签匹配则光环无定位依据；跳过光环扩散则输出退化为参考题 a406ac07 的原样。两步之间的耦合在于：相邻匹配点的光环会融合，但匹配点本身的颜色不被覆盖，形成"彩色岛屿浮在灰色云层中"的结构。

根据行列标签是否同色来填充内部单元格，然后以每个填充格为中心向外扩散一层灰色光环，光环仅占据空白背景格。

**输入结构**：网格尺寸约 12x12。最右列为行标签列，每个格子填入一种非黑颜色（从红(2)、蓝(1)、绿(3)、黄(4)中选取），标记对应内部行的颜色标签。最底行为列标签行，每个格子同样填入一种非黑颜色，标记对应内部列的颜色标签。右下角格为黑(0)。内部区域（去掉最右列和最底行后的矩形）初始全为黑(0)。生成约束：行标签和列标签的颜色分布使得匹配格（同色交叉点）数量在 3~8 个之间，且至少存在两个相邻的匹配格（切比雪夫距离 = 1）以展示光环融合效果。

**规则**：
1. 对每个内部单元格 (r, c)，比较其行标签（第 r 行最右列的颜色）与列标签（最底行第 c 列的颜色）。若二者相同，将该格填充为该标签颜色。
2. 对每个在步骤 1 中被填充的格子，将其切比雪夫距离 = 1 的邻域（最多 8 个格子）中仍为黑(0)的格子填充为灰(5)。已被步骤 1 填色的格子、其他匹配格的灰色光环格子、以及标签行/列的格子均不被覆盖。
3. 当多个匹配格的光环区域在同一格重叠时，该格仍为灰(5)（灰色光环自然融合）。
4. 标签行、标签列和右下角格保持不变。

**关键洞察**：输出中彩色格子（匹配点）和灰色格子（光环）形成的图案隐式编码了行列标签序列的相等关系结构。仅看一个示例可能误以为"灰色是某种固定背景填充"，需要对比多个示例才能发现灰色仅出现在匹配点周围且不覆盖匹配点本身。

## 新题 4：贪心方块选取后按面积排名从调色板着色

**组合逻辑**：[贪心选择/greedy_selection](已有) + [排序/sorting](创新：排序的键不是预设的标记数而是贪心选取后的面积分组) + [重涂色/recolor](创新：颜色来源不是对象自身属性而是外部调色板的位置映射)

**来源原语**：贪心选择/greedy_selection + 空白正方形区域/blank_square_region + 障碍像素/obstacle_pixel + 从大到小优先/largest_first_priority + 非重叠约束/non_overlapping_constraint + 最小边长约束/minimum_side_length_constraint ← 31adaf00；排序/sorting + 按计数升序排列/sorted_by_count ← d4c90558；重涂色/recolor ← d4c90558

**依赖链**：贪心选取确定哪些方块存在及其尺寸 → 按尺寸分组排序得到排名 → 排名与调色板位置对应得到颜色 → 着色。障碍像素的布局决定了可用空间，进而决定哪些方块能被选中，再决定尺寸分布和排名分配。这条信息链中任一环节缺失都导致输出不确定。

在障碍像素之间贪心选取最大非重叠空白方块，然后按方块面积从大到小排名，使用输入左侧调色板列中对应排名的颜色为每组方块着色。

**输入结构**：网格尺寸约 20x22。最左列为调色板列：从第 0 行开始，依次填入 3~5 种不同颜色（如红(2)、蓝(1)、绿(3)、黄(4)、品红(6)），其余格为黑(0)。调色板中的第 k 个颜色（从上到下第 k 个非黑格）对应面积排名第 k 的方块组。从第 1 列到最右列的区域为搜索区域：黑(0)背景上散布灰(5)障碍像素（约 15~25 个），障碍像素形成不规则的空间分隔。生成约束：障碍布局保证搜索区域中至少存在 3 种不同边长的全黑正方形区域（边长 >= 2），且同一尺寸的正方形至少有 1 个、至多有 4 个能通过贪心选取存活。

**规则**：
1. 在搜索区域（第 1 列到最右列）中，枚举所有全黑(0)正方形候选区域，边长 >= 2。
2. 按边长从大到小处理候选方块。对于每个候选方块，若其区域与已选定的任何方块无像素重叠，则选定该方块。同一边长的候选方块按其左上角坐标从上到下、从左到右的顺序处理。
3. 将选定的方块按边长分组。边长最大的组排名 1，次大的排名 2，以此类推。
4. 读取调色板列：第 1 个非黑格的颜色赋给排名 1 的组，第 2 个非黑格赋给排名 2 的组，以此类推。
5. 将每组中所有方块的所有像素重涂为对应的调色板颜色。
6. 若不同边长的分组数多于调色板中的颜色数，多余的组（排名最后的最小方块组）保持黑(0)不着色。
7. 障碍像素和调色板列保持不变。

**关键洞察**：调色板的颜色顺序不能直接对应任何空间位置——它编码的是面积排名，而排名取决于贪心选取的结果。不同示例中障碍布局不同，产生不同的方块集合和尺寸分布，导致同一调色板位置映射到不同的绝对尺寸。必须对比多个示例才能归纳出"调色板位置 = 面积排名"的规则。

## 新题 5：反对角线等色填补后种子掩码打孔

**组合逻辑**：[填充/infill](已有) + [平铺/tile](创新：平铺掩码来自输入自身的种子区域，平铺操作不是复制颜色而是选择性擦除) + [反对角线等值/anti_diagonal_equivalence](已有) + [前景背景分别替换/fg_bg_separate](创新：前景保留实际颜色、背景替换为固定灰色，而非两种颜色互换)

**来源原语**：填充/infill + 反对角线等值/anti_diagonal_equivalence + 分区结构约束/partitioned_structure_constraint ← 4aab4007；平铺/tile + 种子掩码/seed_mask + 自相似替换/self_similar_sub + 前景背景分别替换/fg_bg_separate ← 58c02a16

**依赖链**：反对角线填补恢复缺失颜色 → 恢复后的完整色场才能被种子掩码正确打孔（否则黑洞会被误当作打孔结果）。种子区域同时承担两个角色：(a) 自身的反对角线色不被遮挡，提供填补所需的参考色；(b) 其前景/背景二值图案作为平铺掩码。这种双重角色使种子区域成为两步操作的共享锚点，跳过任一步都无法得到正确输出。

先用反对角线颜色一致性填补网格中的黑色缺失像素，再将左上角的种子区域二值图案作为掩码周期性平铺到已填补区域上，种子前景位置保留原色、种子背景位置替换为灰色。

**输入结构**：网格尺寸约 9x9 或 12x12。左上角有一个 3x3 的种子区域，包含绿(3)前景像素和黑(0)背景像素构成的二值图案（绿色像素 3~5 个）。种子区域内的每条反对角线（行号+列号 = 常数）上所有非黑像素颜色一致。种子区域之外的网格中，每条反对角线（行号+列号 = 常数）上的像素共享一种非黑颜色（不同反对角线的颜色不同，从红(2)、蓝(1)、黄(4)、品红(6)、橙(7)、青(8)中选取），但其中约 20%~30% 的像素被替换为黑(0)（遮挡缺失）。种子区域内的像素没有遮挡。生成约束：种子区域的反对角线颜色（绿(3)）与种子区域外任何反对角线的颜色不同。

**规则**：
1. 对种子区域之外的每个黑(0)像素，找到与其同在一条反对角线（行号+列号相同）上的任意非黑像素，将该黑像素替换为该颜色。由于每条反对角线在种子区域外所有非黑像素颜色一致，颜色唯一确定。
2. 在填补完成后的网格上，将种子区域的绿(3)/黑(0)图案视为二值掩码（绿 = 前景，黑 = 背景），以 3x3 为周期在种子区域之外的整个网格上平铺。
3. 对种子区域外的每个像素 (r, c)，计算其在种子掩码中的对应位置：(r mod 3, c mod 3)。若该对应种子位置为前景（绿(3)），保留像素的当前颜色不变；若为背景（黑(0)），将该像素替换为灰(5)。
4. 种子区域（左上角 3x3）本身保持不变，不受平铺操作影响。

**关键洞察**：种子区域有双重身份——它既是反对角线填补的可靠参考源（因为不含遮挡），又是平铺打孔掩码的模板。必须先完成填补才能执行打孔，否则原有的黑色遮挡像素会与打孔产生的灰色像素混淆。需要对比多个示例（不同的种子图案和不同的遮挡位置）才能分离出这两步逻辑。

## 新题 6：按封闭孔洞数确定叠加优先级的透明合成

**组合逻辑**：[计数/counting](创新：计数的对象是拓扑属性——孔洞数，而非离散标记) + [透明叠加/transparent_overlay](创新：叠加优先级不由空间位置固定，而由每层内容的拓扑分析动态决定)

**来源原语**：计数/counting ← 3b4c2228, e3721c99；透明叠加/transparent_overlay + 同坐标叠加/same_position_overlay + 图层优先级/layer_priority + 等高带/equal_height_band + 颜色掩码层/color_mask_layer ← 3d31c5b3；封闭区域/enclosed_region + 孔洞数映射颜色/hole_count_to_color_mapping ← e3721c99

**依赖链**：每个色带的孔洞数决定该带的叠加优先级 → 优先级决定冲突像素的最终颜色。这不是线性流水线而是"分析-汇聚"结构：先对每个带独立做拓扑分析（计数孔洞），再将分析结果汇总为全局优先级表，最后在叠加时统一应用。跳过拓扑分析则优先级不确定；跳过叠加则无冲突需要解决。

将等高水平色带按各自前景形状的封闭孔洞数排列优先级后做透明叠加，孔洞越少的带优先级越高。

**输入结构**：网格尺寸约 12x28（宽 x 高）。网格被 3 条单像素灰(5)水平线分成 4 个等高水平带（每带高约 6 行，宽 12 列）。每个带的背景为黑(0)，前景为一种唯一的非黑非灰颜色（从红(2)、蓝(1)、绿(3)、黄(4)中各取一种），前景像素组成一个 4-连通的单色形状。每个形状包含 0~3 个封闭孔洞（由背景色黑(0)像素构成的、被前景像素完全 4-连通包围的连通区域）。生成约束：四个带的孔洞数两两不同（如 0, 1, 2, 3），保证优先级排序唯一；各带的前景形状面积在 15~30 像素之间，且相互叠加时至少有 3 个位置产生多带冲突。

**规则**：
1. 移除所有灰(5)水平分隔线。
2. 对每个色带的前景形状，计算其封闭孔洞数。封闭孔洞定义为：在该带的局部坐标系中，被前景像素 4-连通完全包围的黑(0)背景连通区域（不包括接触带边界的背景区域）。
3. 按孔洞数从少到多赋予优先级：孔洞数最少的带优先级最高（排名 1），最多的最低（排名 4）。
4. 将四个带对齐到同一局部坐标系（每个带的左上角对齐），进行透明叠加。对每个像素位置：
   - 若只有一个带在该位置有前景像素，输出该颜色。
   - 若多个带在该位置有前景像素，输出优先级最高（孔洞数最少）的带的颜色。
   - 若所有带在该位置都是黑(0)，输出黑(0)。
5. 输出网格的尺寸为单个带的尺寸（高约 6、宽 12）。

**关键洞察**：与参考题 3d31c5b3 的固定位置优先级不同，这里的优先级由每个图层的拓扑复杂度（孔洞数）决定。仅看一个叠加冲突区域无法确定优先规则（可能误判为颜色编号决定或空间位置决定），必须同时分析各带的孔洞数并对比多个示例中不同带胜出的情况才能归纳出"孔洞越少越优先"的规则。

## 新题 7：颜色条件分支像素放大后边缘复制扩展

**组合逻辑**：[像素放大/pixel_upscaling + 图案替换/pattern_substitution](创新：不同颜色映射到不同的微结构图案，图案种类从 2 种扩展到 3 种) + [边缘填充/edge_pad + 复制扩展/outward_copy](创新：边缘填充的源不是单色像素而是已放大的微结构像素，形成结构化边缘)

**来源原语**：像素放大/pixel_upscaling + 图案替换/pattern_substitution + 按颜色条件分支/color_conditional_branch ← 2072aba6；边缘填充/edge_pad + 复制扩展/outward_copy + 角像素双向扩展/corner_extends_both + 边缘行列/border_row_col ← e633a9e5

**依赖链**：像素放大步骤决定了放大后网格边缘像素的具体颜色值 → 边缘填充将这些结构化的边缘像素向外复制一行/列。因为每种输入颜色产生不同的 2x2 微结构图案，边缘上的像素值取决于输入边缘像素的颜色，所以同一边缘位置在不同示例中可能有不同的填充颜色。跳过放大则无微结构可供边缘复制；跳过边缘填充则输出仅是放大图（与 2072aba6 无区别）。两步的耦合点在于：边缘填充复制的是微结构内的特定像素（取决于该像素在 2x2 块中的位置），非均匀的边缘复制是两步交互的涌现效应。

将输入的每个像素按颜色展开为不同微结构的 2x2 块，然后对放大后的网格做一圈边缘向外复制扩展。

**输入结构**：一个 3x3 或 4x4 的小网格，像素颜色从以下三种中选取：黑(0)、红(2)、蓝(1)。每个示例中三种颜色至少各出现一次。

**规则**：
1. 将输入每个像素放大为 2x2 块，规则按颜色分支：
   - 黑(0) → [[黑(0), 黑(0)], [黑(0), 黑(0)]]（全黑块）
   - 红(2) → [[红(2), 黄(4)], [黄(4), 红(2)]]（对角线条纹块）
   - 蓝(1) → [[蓝(1), 蓝(1)], [绿(3), 绿(3)]]（水平条纹块）
2. 对放大后的网格（尺寸为输入的 2 倍），做一圈边缘向外复制扩展：
   - 最上一行的每个像素向上复制一行。
   - 最下一行的每个像素向下复制一行。
   - 最左一列的每个像素向左复制一列（含已扩展的上下行）。
   - 最右一列的每个像素向右复制一列（含已扩展的上下行）。
   - 四个角的扩展像素取放大网格对应角像素的值（角像素同时参与行和列扩展，形成 2x2 角块）。
3. 输出网格尺寸为 (输入高 x 2 + 2) x (输入宽 x 2 + 2)。

**关键洞察**：边缘复制扩展在普通像素放大中只是简单的边框加粗，但当放大后的像素是微结构（2x2 内有不同颜色）时，边缘的上行和下行、左列和右列各自复制了微结构的不同子行/子列。例如一个红色像素在输入右下角，其 2x2 块为 [[红,黄],[黄,红]]，右列扩展复制的是 [黄, 红]（取块的右列），下行扩展复制的是 [黄, 红]（取块的下行），角点得到 红。这种非均匀边缘效应只有理解了微结构才能预测。

## 新题 8：完整与损伤方块双分支计数的对角线交叉编码

**组合逻辑**：[计数/counting](创新：同一操作分两条分支并行执行，计数对象由分类条件决定) + [编码/encoding + 对角线编码/diagonal_encoding](创新：两个计数结果分别编码在主对角线和反对角线上，共享同一输出网格) + [擦除/erase + 忽略干扰项/ignore_distractors](已有)

**来源原语**：计数/counting + 对角线编码/diagonal_encoding + 完整方块过滤/full_square_filter + 忽略干扰项/ignore_distractors ← 3b4c2228；编码/encoding + 计数决定填充位/count_sets_positions ← ff28f65a；擦除/erase ← a416fc5b, e3721c99

**依赖链**：这是分叉-汇合结构而非线性流水线。输入经两条独立分支处理——完整方块计数和损伤方块计数——然后两条分支的结果汇合到同一个输出网格的两条对角线上。主对角线和反对角线在中心格可能交叉，此时需要冲突解决规则。删除任一分支的计数，对应对角线就无法确定。

区分并分别计数完整的绿色 2x2 方块和被损伤的绿色方块，将两个计数分别编码为输出网格主对角线和反对角线上的有色格子数。

**输入结构**：黑(0)背景上的方形网格，尺寸约 12x12~15x15。网格中散布以下元素：
- **完整绿色方块**：恰好 2x2 的绿(3)实心方块，1~4 个，互不接触。
- **损伤绿色方块**：一个 2x2 区域中有恰好 3 个绿(3)像素和 1 个红(2)像素（红像素在四个位置之一），1~4 个，互不接触且不与完整方块接触。
- **干扰项**：若干孤立的蓝(1)单像素散布在网格中（不与任何方块相邻）。
生成约束：完整方块数 + 损伤方块数 <= 4（保证对角线编码不超出 4x4 输出网格）；完整方块数和损伤方块数各至少为 1。

**规则**：
1. 识别所有绿(3)的 4-连通前景对象。对每个对象判断类别：
   - 若对象恰好占据一个 2x2 区域且面积为 4（全绿），归为"完整"。
   - 若对象为 3 个绿(3)像素，且这 3 个像素加上一个相邻的红(2)像素恰好构成一个 2x2 区域，归为"损伤"。
   - 其余绿色对象（孤立像素等）归为干扰，忽略。
2. 蓝(1)孤立像素全部忽略（干扰项）。
3. 统计完整方块数 C_full 和损伤方块数 C_dmg。
4. 生成一个 4x4 黑(0)输出网格：
   - 在主对角线上（(0,0), (1,1), (2,2), (3,3)），从左上开始填入 C_full 个绿(3)格子。
   - 在反对角线上（(0,3), (1,2), (2,1), (3,0)），从右上开始填入 C_dmg 个红(2)格子。
   - 若主对角线和反对角线在某格交叉（即 C_full 和 C_dmg 都覆盖了该格），该格填绿(3)（完整优先于损伤）。
5. 输出仅为 4x4 编码网格，输入中的所有元素均不保留。

**关键洞察**：红色像素在输入中是"损伤标记"而非独立对象——它标记了一个方块的缺损位置。将红像素误判为干扰项会导致损伤计数为零。两条对角线在输出网格中心可能交叉，交叉处的优先规则（绿色覆盖红色）只有在 C_full >= 2 且 C_dmg >= 3（或反之满足交叉条件）的示例中才能被观察到，必须对比多个示例才能完整归纳规则。
