## 新题 1：墙壁洪泛筛选标记后受限路径连接

**组合逻辑**：[洪泛填充](将内外分区从"输出结果"创新为"中间筛选器") + [连线/桥绘制](将自由路径创新为"受墙壁拓扑约束的路径") + [重涂色](标记外区域)

**来源原语**：洪泛填充/内外分区/边界连通分内外(7b6016b9) + 连线/正交路径/先横后纵路由/经由中间点路由(0e671a1a) + 重涂色(7b6016b9) + 忽略干扰项(3ed85e70)

**依赖链**：蓝(1)线条对象构成墙壁 → 洪泛填充从网格边界出发区分外部与封闭区域 → 外部区域的标记像素被擦除（筛选淘汰）→ 仅封闭区域内幸存的标记像素参与连线 → 连线路径只能走封闭区域的背景单元格（墙壁同时约束"谁连"和"怎么连"）

一句话总结：蓝线墙壁将网格分为内外区域，仅保留封闭区域内的彩色标记，并在封闭区域内按行序用正交路径逐对连接。

**输入结构**：约 15x15 的黑(0)背景网格。蓝(1)像素形成一个 4-连通的正交线条对象，该线条将网格划分为若干区域——部分区域与网格边界 4-连通（外部区域），部分区域被蓝线完全包围（封闭区域，至少 2 个）。网格中散布 4~6 个单像素标记，每个标记使用互不相同的非蓝、非黑颜色（从红(2)、绿(3)、黄(4)、灰(5)、品红(6)、橙(7)中选取）。标记有的位于封闭区域，有的位于外部区域。生成约束：每个封闭区域最多包含 2 个标记；封闭区域内幸存标记的总数为偶数（保证可以两两配对）；各封闭区域之间不 4-连通。

**规则**：
1. 以蓝(1)像素为墙壁。从网格四条边界出发对黑(0)背景执行 4-连通洪泛填充，所有可达的背景单元格标记为"外部"。不可达的背景单元格标记为"封闭"。
2. 将所有外部背景单元格重涂为绿(3)。位于外部区域的标记像素同样重涂为绿(3)（即被擦除/淹没）。
3. 收集所有幸存标记（位于封闭区域内的标记），按其行坐标从小到大排序（行坐标相同则按列坐标从小到大）。
4. 将排序后的标记依次两两配对：第 1 与第 2 个配对，第 3 与第 4 个配对，依此类推。
5. 对每一对标记，绘制灰(5)正交路径连接它们：先沿水平方向移动到目标列，再沿垂直方向移动到目标行。路径仅覆盖黑(0)（封闭区域背景）单元格；若路径需经过蓝(1)墙壁或已有标记，则改为先垂直后水平。绘制路径时不覆盖标记像素本身（路径终止于标记的 4-邻居）。
6. 蓝(1)墙壁像素保持不变。

**关键洞察**：墙壁拓扑一体两用——既充当洪泛填充的屏障决定哪些标记存活，又充当路径绘制的物理阻挡约束路线走向。去掉墙壁则无法筛选标记，也无法约束路径；去掉洪泛填充则不知道哪些标记该连。配对顺序（按行坐标排序）需对比多个示例才能归纳——单个示例可能恰好只有一对标记。

## 新题 2：精灵体空洞分类驱动双向柱状条堆叠

**组合逻辑**：[分类](将"内部是否为背景"从矩形推广到不规则精灵体的"是否含封闭空洞") + [计数](像素面积) + [排序+堆叠](创新为分类结果决定堆叠方向而非列位置)

**来源原语**：分类/内部判定类型(2ba387bc) + 计数(37ce87bb) + 排序/堆叠/按类型分列(2ba387bc) + 填充/柱状条(37ce87bb) + 封闭区域(7b6016b9) + 洪泛填充(7b6016b9)

**依赖链**：对每个精灵体执行微型洪泛填充判断是否含封闭空洞 → 分类为"实心"或"空洞" → 分类结果决定柱状条堆叠方向（实心→向上，空洞→向下）→ 计数像素面积决定柱状条高度 → 按面积升序排列柱状条的水平位置

一句话总结：将散落的不规则精灵体按是否含封闭空洞分为两类，实心类向上生长、空洞类向下生长，高度等于像素面积，左右按面积排列。

**输入结构**：约 18x12 的黑(0)背景网格。包含 4~6 个互不相邻的 4-连通单色精灵体，每个精灵体使用不同颜色（从蓝(1)、红(2)、黄(4)、品红(6)、橙(7)、青(8)中选取），像素数在 3~8 范围内。"实心"精灵体的边界框内所有非精灵像素均 4-连通到边界框外部（无封闭空洞）。"空洞"精灵体的边界框内至少有一个黑(0)单元格不 4-连通到边界框外部（被精灵像素完全包围）。不同示例中同类精灵体的具体形状不同（例如"空洞"类可以是环形、C-形封口等任何含洞形状），迫使求解者依据结构属性而非特定外形归纳规则。生成约束：所有精灵体的像素面积互不相同。

**规则**：
1. 对每个精灵体，在其边界框内执行微型洪泛填充：从边界框的四条边上的黑(0)单元格出发向内填充。若填充后仍有黑(0)单元格未被触及，则该精灵体分类为"空洞"类；否则为"实心"类。
2. 计算每个精灵体的像素面积（该精灵体占据的非背景单元格总数）。
3. 输出网格宽度 = 精灵体数量，高度 = 所有面积中的最大值 × 2 + 1。输出网格的垂直中线行（第 max_area 行，从 0 计）为分界线。
4. 将所有精灵体按像素面积升序排列，从左到右分配列位置（列 0 为面积最小者）。
5. 实心类精灵体：从分界线行向上生长，填充该列的连续单元格，高度 = 其像素面积，使用该精灵体的原始颜色。
6. 空洞类精灵体：从分界线行向下生长，填充该列的连续单元格，高度 = 其像素面积，使用该精灵体的原始颜色。
7. 分界线行本身保持黑(0)。

**关键洞察**：分类不仅决定分组，还决定堆叠方向——这一规则仅凭单个示例无法区分"所有条都向上"还是"分类决定方向"。必须对比包含两类精灵体的多个示例才能发现方向翻转规则。同时，空洞判定本身就是一次嵌套的洪泛填充。

## 新题 3：周期修复揭示射线颜色与终止条件

**组合逻辑**：[补全/周期修复](修复结果不仅是输出，还为射线提供颜色参数和终止判据) + [射线延伸](将射线的颜色和终止条件绑定到周期结构上，而非来自固定规则)

**来源原语**：补全/周期瓦片/最小周期推断填补/缺失单元(29ec7d0e) + 射线延伸/对角射线种子(7e2bad24) + 重涂色(7e2bad24)

**依赖链**：推断最小周期瓦片并修复所有黑洞 → 红(2)单元格不属于周期图案，保留为射线种子 → 每个种子位置在周期瓦片中"应有"的颜色成为该射线的颜色 → 射线沿对角线延伸，遇到周期瓦片颜色与射线颜色不同的单元格时停止

一句话总结：修复周期图案中的缺失单元，然后从红色种子像素射出对角线射线，射线颜色由种子位置在周期中的"应有颜色"决定，遇到不同周期颜色时终止。

**输入结构**：约 12x12 的网格。大部分单元格构成一个可见的周期色彩图案（周期约 3x3 或 4x4），使用 2~3 种非黑、非红颜色（例如蓝(1)、黄(4)、绿(3)）。图案中有若干黑(0)单元格作为缺失孔洞（每个周期位置至少在网格中出现一次非零样本，保证修复可行）。另有 1~3 个红(2)单元格散布在网格中，它们不属于周期图案，是射线种子。生成约束：红(2)不出现在周期瓦片的任何位置中；每个红像素的右下对角方向至少有 2 格空间；不同红像素的射线路径互不交叉。

**规则**：
1. 忽略所有红(2)单元格，仅用非零且非红的单元格推断最小重复周期 p（行方向周期 p_r，列方向周期 p_c），使得所有非零非红单元格满足 color(r,c) = tile[r mod p_r][c mod p_c]。
2. 用推断出的 p_r × p_c 瓦片修复所有黑(0)孔洞：将每个黑单元格替换为 tile[r mod p_r][c mod p_c]。
3. 对每个红(2)单元格 (r0, c0)，计算其"应有颜色" C = tile[r0 mod p_r][c0 mod p_c]。
4. 从 (r0, c0) 出发，沿右下对角方向 (r+1, c+1) 逐步延伸射线。射线覆盖的每个单元格被涂为颜色 C，覆盖该位置原有的修复颜色。
5. 当射线的下一个目标单元格 (r_next, c_next) 满足 tile[r_next mod p_r][c_next mod p_c] != C 时，射线停止（不涂该单元格）。若下一个目标超出网格边界，射线也停止。
6. 红(2)种子像素本身保持红色，不被射线覆盖。

**关键洞察**：周期结构一体三用——它既是需要被修复的图案本体，又是射线颜色的隐式编码源（种子位置在周期中的映射），还是射线终止的判定依据（周期颜色边界）。不修复周期就无法确定射线颜色和停止位置；不识别红像素就无法区分种子与孔洞。射线颜色因种子位置不同而不同，需对比多个示例中不同位置的种子才能归纳出"查周期瓦片"这一规则。

## 新题 4：模板匹配与计数联合决定平铺印章

**组合逻辑**：[模板匹配/部分匹配](确定印章内容) + [计数](确定印章重复次数) → 两个独立分析的结果汇聚到同一个输出操作 [平铺印章]

**来源原语**：模板匹配/目录模板/目录区域/部分匹配识别(3ed85e70) + 印章覆盖/子精灵对齐(3ed85e70/bb52a14b) + 计数/计数器像素/计数器消失(e48d4e1a) + 平铺(c92b942c)

**依赖链**：目录区域提供完整模板 → 工作区中的部分副本通过像素匹配确定对应模板（"印什么"）→ 每个部分副本旁边的灰(5)计数器像素数量决定水平平铺次数（"印几遍"）→ 在部分副本位置按对齐方式印章，水平重复 N 次 → 计数器像素消失

一句话总结：在目录中查找与工作区部分副本匹配的模板，然后将完整模板水平平铺，重复次数等于副本旁边的灰色计数器像素数量。

**输入结构**：约 18x15 的网格。上方约 4 行为目录区域，以灰(5)为背景色，内含 2~3 个小型模板精灵体（每个约 3x3，使用不同的多色组合，如蓝(1)+红(2)、绿(3)+黄(4)等）。模板之间水平间隔至少 2 列。下方为黑(0)背景的工作区，包含 2~3 个部分副本——每个部分副本是某个模板的子集像素（至少保留模板一半以上的像素，且保留的像素唯一对应某个模板）。每个部分副本的 4-邻域（上下左右紧邻的黑(0)单元格位置）散布 1~4 个灰(5)像素作为计数器。生成约束：不同部分副本匹配不同的模板（一一对应）；部分副本之间水平间距足够容纳最大平铺展开；计数器像素不与部分副本的非零像素重叠。

**规则**：
1. 识别目录区域（连续的灰(5)背景区域），提取其中的模板精灵体（以各模板的边界框为范围，灰(5)背景视为透明）。
2. 对工作区中的每个部分副本，逐一与目录模板比对：将部分副本的非零像素与模板在所有可能对齐位置叠放，找到唯一一个模板使得副本的每个非零像素都与模板对应位置颜色一致。记录匹配的模板和对齐偏移。
3. 计算每个部分副本 4-邻域内的灰(5)像素数量 N。
4. 以部分副本的对齐位置为起点，将匹配到的完整模板水平平铺 N 次：第 1 次放在对齐位置，第 2 次紧接其右侧（列偏移 = 模板宽度），依此类推。模板中灰(5)背景位置视为透明，不覆盖工作区已有内容。
5. 擦除所有灰(5)计数器像素（变为黑(0)）。目录区域保持不变。

**关键洞察**：新题的核心创新在于两条独立的信息通道——"印什么"来自空间模式匹配，"印几遍"来自局部计数——汇聚到同一个平铺操作。源题中模板匹配只决定印章内容（一次），计数只决定偏移量；这里计数决定的是重复次数，与匹配结果构成乘法关系。需对比多个示例才能归纳出"灰像素数=平铺次数"这一隐蔽规则。

## 新题 5：双面板叠合构造墙壁再洪泛分区

**组合逻辑**：[透明叠加](两面板合成一个新的复合结构) → [洪泛填充](在叠合产生的复合墙壁上执行内外分区) → [重涂色](叠合方式编码墙壁来源，分区决定背景涂色)

**来源原语**：透明叠加/二值掩码/双侧对齐/占用补集(66f2d22f) + 洪泛填充/封闭区域/内外分区/边界连通分内外(7b6016b9) + 重涂色(7b6016b9) + 填充(7666fa5d)

**依赖链**：左右面板各自的前景形状不构成封闭区域 → 叠合后两组形状组合可能产生新的封闭拓扑 → 洪泛填充在叠合结构上执行，发现单面板中不存在的封闭区域 → 外部背景→灰(5)，封闭背景→黄(4) → 墙壁像素保留叠合编码色

一句话总结：左右面板叠合形成复合墙壁，在复合墙壁上执行洪泛填充区分内外，外部涂灰、封闭涂黄，墙壁颜色保留叠合来源信息。

**输入结构**：约 10x20 的网格，沿垂直中线分为左右两个 10x10 面板。两面板均为黑(0)背景。左面板包含蓝(1)前景像素，形成一条或多条 4-连通线段/折线，但左面板的蓝线不自行围成封闭区域（所有黑(0)单元格均可 4-连通到面板边界）。右面板包含红(2)前景像素，同样形成线段/折线且不自行封闭。生成约束：当两面板按位置叠合时，蓝(1)与红(2)线段的组合在至少一处形成封闭区域（包围若干背景单元格使其不 4-连通到面板边界）；蓝和红像素不重叠在同一相对位置（无冲突）。

**规则**：
1. 将左右面板按行列对齐叠合为一个 10x10 的输出网格：
   - 某位置仅左面板有前景 → 输出蓝(1)。
   - 某位置仅右面板有前景 → 输出红(2)。
   - 某位置两面板均为背景 → 暂时保留黑(0)。
   - （由生成约束保证不会出现两面板同一位置均有前景。）
2. 在叠合后的 10x10 网格中，以蓝(1)和红(2)像素均视为墙壁，从网格四条边界出发对黑(0)背景执行 4-连通洪泛填充。
3. 洪泛可达的背景单元格（外部区域）重涂为灰(5)。
4. 洪泛不可达的背景单元格（封闭区域）重涂为黄(4)。
5. 蓝(1)和红(2)墙壁像素保持不变。

**关键洞察**：创新的核心是"涌现封闭"——任一面板独立都不包含封闭区域，只有叠合才产生新的拓扑结构。洪泛填充作用的对象是叠合涌现的复合墙壁，而非任何源输入中已有的结构。求解者需要先理解叠合规则，再理解叠合结果上的洪泛分区——两步紧密耦合，删除任一步都无法得到正确输出。需对比多个示例才能发现"封闭来自叠合"这一非显然事实。

## 新题 6：计数器编码边权的加权最短路径

**组合逻辑**：[计数](将轨道上的灰像素数量重新解读为边权重) + [最短路径](从无权 BFS 创新为加权 Dijkstra) + [重涂色](沿最短路径着色)

**来源原语**：最短路径/图结构/节点方块/轨道段/终端节点/最短路径选择(7b0280bc) + 计数/计数器像素/计数器消失(e48d4e1a) + 重涂色(7b0280bc) + 颜色编码正负(37ce87bb, 创新为"颜色编码权重")

**依赖链**：灰(5)像素沿轨道段分布 → 计数每条轨道上的灰像素数 = 该边的权重 → 以权重构建加权图 → Dijkstra 或等价算法求两个终端节点间的最小权重路径 → 沿最短路径重涂节点和轨道 → 灰像素全部擦除

一句话总结：在方块-轨道图中，按轨道上灰色像素的数量作为边权重，找到两个红色终端之间的加权最短路径并着色。

**输入结构**：约 20x20 的黑(0)背景网格。包含 5~8 个 3x3 的单色实心方块作为图的节点，其中恰好 2 个为红(2)（终端节点），其余为蓝(1)（中间站节点）。节点之间通过橙(7)的 1 像素宽轨道段连接（水平或垂直直线，连接两个方块边缘）。每条轨道段上散布 1~5 个灰(5)像素，替换该位置原本的橙(7)像素。网格构成一个连通图，从任一终端节点可达另一终端节点。生成约束：存在至少两条从终端到终端的路径；空间上最短的路径（经过最少边数的路径）不是权重最小的路径（确保求解者不能用简单 BFS）。

**规则**：
1. 识别所有 3x3 单色方块为节点。红(2)方块为终端，蓝(1)方块为中间站。
2. 识别所有橙(7)轨道段为边。每条轨道连接恰好两个相邻节点（轨道端点 4-相邻于两个不同方块的边缘像素）。
3. 对每条轨道段，计算其上灰(5)像素的数量 W。将轨道中的灰(5)像素暂时视为橙(7)的一部分来确定连通性，但 W 值作为该边的权重记录。
4. 在加权图中，求两个红(2)终端节点之间权重之和最小的路径。若存在权重相同的多条路径，选择经过节点数最少的那条。
5. 将最短路径上的所有中间站蓝(1)方块重涂为绿(3)。
6. 将最短路径上的所有轨道段（含其上的灰像素位置）重涂为黄(4)。
7. 不在最短路径上的轨道和节点保持原色。所有灰(5)像素（无论是否在最短路径上）全部擦除——最短路径上的灰像素位置变为黄(4)，非最短路径上的灰像素位置恢复为橙(7)。

**关键洞察**：灰(5)像素的双重身份是核心创新——它们视觉上是轨道的一部分（不影响连通性判断），语义上却编码了边权重，使得空间最短路径不等于加权最短路径。源题(7b0280bc)使用无权最短路径，这里计数将其变为加权问题。需对比多个示例（尤其是空间短路径权重大、空间长路径权重小的对比案例）才能发现灰像素数=边权重这一隐蔽规则。

## 新题 7：精灵体分类决定射线反射还是穿透

**组合逻辑**：[分类](空心/实心判定) → 分类结果作为射线行为的**物理规则选择器** → [射线延伸+边界反射](遇空心框反射，遇实心块穿透) + [重涂色](被穿透的实心块变色)

**来源原语**：分类/空心矩形/实心方块/内部判定类型(2ba387bc) + 射线延伸/对角射线种子/边界反射/特定色反射射线(7e2bad24) + 重涂色(7e2bad24)

**依赖链**：逐个检测 4x4 方块的 2x2 内部是否为背景 → 空心（框）= 反射镜，实心 = 透明障碍 → 射线从种子出发沿对角线行进 → 遇到空心框的边缘像素时反射（水平边翻转行方向，垂直边翻转列方向）→ 遇到实心块时直接穿透（覆盖其像素）→ 射线结束后，被穿透的实心块整体重涂为红(2)

一句话总结：蓝色对角射线在网格中行进，遇到空心矩形框反射、遇到实心方块穿透并将其标红。

**输入结构**：约 18x18 的黑(0)背景网格。包含一个蓝(1)对角射线种子（2~3 个沿对角线排列的蓝像素）。网格中散布 4~6 个 4x4 的单色方块对象，每个使用不同颜色（从绿(3)、黄(4)、品红(6)、橙(7)、青(8)、栗(9)中选取）。其中部分为空心框（1 像素厚边框，2x2 内部为黑(0)背景），部分为实心方块（4x4 全部填充同色）。生成约束：射线从种子端点出发沿某个对角方向（由种子两端的延伸方向确定）行进时，至少击中 2 个方块对象；空心框和实心块至少各有 1 个被射线击中；射线在到达网格边界前至少经历一次反射。

**规则**：
1. 对每个 4x4 方块对象，检查其 2x2 内部（第 1~2 行、第 1~2 列的内部区域）：若内部全为黑(0)背景则分类为"空心框"，否则为"实心块"。
2. 确定射线种子的行进方向：种子像素沿对角排列，取种子远离网格边界的那一端作为起点，沿该对角方向延伸（例如种子在左上角附近，则向右下行进）。
3. 从起点开始，逐步沿对角方向 (dr, dc)（dr, dc 各为 +1 或 -1）移动：
   a. 若下一个单元格为黑(0)背景：涂为蓝(1)，继续前进。
   b. 若下一个单元格属于某实心块：涂为蓝(1)（穿透），标记该实心块为"已穿透"，继续前进方向不变。
   c. 若下一个单元格属于某空心框的边缘像素：不涂该像素（保留框色），执行反射——如果射线从水平方向撞上框边缘（即 dr 方向进入），翻转 dr 的符号；如果从垂直方向撞上，翻转 dc 的符号。若射线恰好撞击框角像素，则同时翻转 dr 和 dc。反射后从当前位置沿新方向继续。
   d. 若下一个单元格超出网格边界：射线结束。
4. 射线追踪完成后，将所有"已穿透"的实心块整体重涂为红(2)（该块所有 16 个像素都变为红(2)，包括被射线覆盖为蓝(1)的像素也改为红(2)）。
5. 未被射线击中的方块对象保持原样。射线种子像素保持蓝(1)。

**关键洞察**：分类不是用于分组或排序，而是作为"物理规则选择器"——同样的几何碰撞事件，因对象类别不同而产生截然不同的射线行为（反射 vs 穿透）。这一耦合方式在源题中不存在：源题中反射由固定颜色（红）决定，这里由结构属性（空心/实心）决定。需对比多个示例才能发现分类依据是内部是否有洞，而非颜色或位置。

## 新题 8：平行对角线段填充面积转化为排序柱状条

**组合逻辑**：[填充](对角段间平行四边形区域填充既是视觉输出又是面积度量) → [计数](填充面积) → [排序+堆叠](面积→柱状条高度，段色→柱色，面积升序排列)

**来源原语**：填充/对角线段/平行四边形区域/平行配对/段间区域填充(7666fa5d) + 计数(37ce87bb) + 排序/堆叠(2ba387bc) + 柱状条/高度加减运算(37ce87bb)

**依赖链**：识别平行反对角线段对 → 填充段对之间的平行四边形区域为红(2) → 计算每个平行四边形的红(2)像素数作为面积 → 面积决定柱状条高度 → 段对的原始颜色决定柱状条颜色 → 按面积升序在右侧结果区排列柱状条

一句话总结：填充平行对角线段对之间的区域，然后将填充面积转化为右侧结果区中按面积排序的彩色柱状条。

**输入结构**：约 15x22 的网格，沿垂直方向分为左区（约 15x15）和右区（约 15x7）。左区为黑(0)背景，包含 3~4 对平行反对角线段（每对由同色的 2 条短反对角线段组成，每段 3~5 像素长，两段平行且位于不同反对角线 r+c=k1 和 r+c=k2 上）。不同段对使用不同颜色（从蓝(1)、绿(3)、黄(4)、品红(6)、橙(7)中选取）。段对之间不交叉。右区为黑(0)背景的空白结果区域，底部有一条灰(5)水平基线（最后一行全灰）。生成约束：各段对形成的平行四边形面积互不相同。

**规则**：
1. 在左区中，按颜色分组识别反对角线段对。每对包含 2 条同色段，分别位于反对角线 r+c=k1 和 r+c=k2 上（k1 < k2）。
2. 对每对段，沿主对角线方向 (r-c = const) 在 k1 和 k2 之间填充：对于每条主对角线轴，若该轴上存在两段覆盖的行列范围，则将两段之间（不含段本身）的所有黑(0)背景单元格填充为红(2)。
3. 计算每个平行四边形区域内红(2)像素的总数，记为该段对的面积 A。
4. 将所有段对按面积 A 升序排列。
5. 在右区中，从左到右依次绘制柱状条（每条宽 1 列，相邻柱状条之间间隔 1 列空列）。第 i 个柱状条（从左起第 i 个奇数列）使用第 i 小面积的段对的原始颜色，高度 = A，从灰(5)基线向上生长（不含基线行）。
6. 左区的段和填充保持不变。

**关键洞察**：填充操作的一体两用是核心创新——它既是左区的视觉变换输出，又是右区柱状条高度的度量输入。源题中段间填充是最终结果，这里填充面积还驱动了后续的排序和堆叠。颜色从段对传递到柱状条而非使用填充的红色，需对比示例确认这一映射。

## 新题 9：控制序列决定叠加 Z 序而非连接路径

**组合逻辑**：[控制序列](语义从"路径顺序"创新为"图层 Z 序") + [透明叠加](按 Z 序逐层叠放同尺寸矩形) + [擦除](移除控制行和原始散布位置) + [标记无冲突合并](内部花纹跨层合并)

**来源原语**：控制序列/访问顺序编码(3e6067c3) + 透明叠加/填充矩形/同尺寸对齐/标记无冲突合并(25e02866) + 擦除(f21745ec) + 内部花纹(f21745ec) + 冲突优先级(c92b942c)

**依赖链**：控制行的颜色序列 → 确定图层叠放顺序（左起第一个颜色 = 最底层）→ 各矩形按 Z 序叠合：底色由顶层覆盖底层，花纹标记跨层合并（不冲突）→ 输出单个合成矩形 → 控制行和原始矩形位置被擦除

一句话总结：按底部控制像素的颜色序列确定叠放优先级，将散落的同尺寸矩形合并为一个，底层被顶层覆盖但花纹标记跨层保留。

**输入结构**：约 16x16 的黑(0)背景网格。包含 3~4 个同尺寸的填充矩形（约 4x4 或 5x5），散布在网格上半部分，彼此不重叠。每个矩形有一个主体底色（使用蓝(1)、绿(3)、品红(6)、青(8)等互不相同的颜色）和 1~2 个内部花纹像素（使用栗(9)，位于矩形内部不同的相对位置）。不同矩形的花纹像素在矩形内的相对位置互不相同（保证合并后不冲突）。网格最底行为控制行：包含 3~4 个单色像素，颜色分别对应各矩形的底色，从左到右排列。生成约束：控制行像素数 = 矩形数量；控制行的颜色顺序与矩形在网格中的空间位置顺序不同（否则 Z 序变得显然）。

**规则**：
1. 读取控制行（最底行）的非黑像素，从左到右记录颜色序列 [C1, C2, ..., Cn]。C1 对应最底层，Cn 对应最顶层。
2. 找到每个颜色 Ci 对应的矩形，提取其完整像素矩阵（包括底色和花纹标记）。
3. 创建一个与矩形同尺寸的空白输出画布（全黑(0)）。
4. 按 Z 序从底层到顶层（C1 先放，Cn 最后放）依次将矩形叠放到输出画布上：
   a. 对于底色像素：顶层覆盖底层（后放的覆盖先放的）。
   b. 对于花纹标记像素（栗(9)）：任何层的花纹标记直接写入输出，不被其他层的底色覆盖。即花纹标记具有最高优先级，无论该层在 Z 序中的位置。
5. 将合成后的矩形放置在网格中央（行方向居中、列方向居中，向下取整）。
6. 擦除控制行（变为黑(0)）和所有原始矩形位置（变为黑(0)）。

**关键洞察**：控制序列的语义转换是核心创新——在源题(3e6067c3)中，控制序列编码的是节点访问路径；在这里，相同形式的控制序列编码的是图层叠放优先级。同时，花纹标记的"穿透"优先级（不被底色覆盖）与普通底色的"覆盖"优先级形成双层冲突解决规则。需对比多个示例（尤其是改变控制行顺序后顶部底色变化的示例）才能归纳出 Z 序规则。

## 新题 10：计数器驱动中继点平移后受约束路径连接

**组合逻辑**：[计数](确定平移距离) + [平移](中继点位置由计数结果动态决定) + [连线/正交路径](经由平移后的中继点路由) → 计数间接控制路径几何形状

**来源原语**：计数/计数器像素/计数决定偏移/计数器消失(e48d4e1a) + 平移(e48d4e1a) + 连线/正交路径/经由中间点路由/先横后纵路由(0e671a1a) + 标记像素(0e671a1a/834ec97d)

**依赖链**：计数黄(4)中继点旁的灰(5)像素 → 灰像素数 K → 中继点向右平移 K 格 → 灰像素消失 → 从红(2)起点到平移后的中继点绘制正交路径（先横后纵）→ 从中继点到绿(3)终点绘制正交路径（先横后纵）→ 路径的折点位置完全由 K 决定

一句话总结：灰色计数器像素的数量决定黄色中继点的水平平移距离，然后从红色起点经由平移后的中继点到绿色终点绘制正交路径。

**输入结构**：约 12x12 的黑(0)背景网格。包含恰好 1 个红(2)像素（起点）、1 个绿(3)像素（终点）和 1 个黄(4)像素（中继点）。黄(4)像素的右侧紧邻 1~4 个灰(5)像素（在同一行上，连续排列）。生成约束：红(2)、绿(3)、黄(4)三点不共行也不共列；黄(4)平移 K 格后不会超出网格边界，也不会与红(2)或绿(3)重叠；中继点平移后，两段正交路径（起点→中继、中继→终点）不交叉（即不经过同一单元格）。

**规则**：
1. 计算黄(4)中继点右侧连续灰(5)像素的数量 K。
2. 将黄(4)中继点向右平移 K 列：清除原位置（变为黑(0)），在新位置放置黄(4)。
3. 擦除所有灰(5)像素（变为黑(0)）。
4. 从红(2)起点到平移后的黄(4)中继点，绘制灰(5)正交路径：先沿水平方向移动到中继点所在列，再沿垂直方向移动到中继点所在行。路径仅覆盖黑(0)单元格。
5. 从平移后的黄(4)中继点到绿(3)终点，绘制灰(5)正交路径：先沿水平方向移动到终点所在列，再沿垂直方向移动到终点所在行。路径仅覆盖黑(0)单元格。
6. 红(2)、绿(3)、黄(4)像素保持原色不变。

**关键洞察**：计数器不直接控制路径，而是间接通过平移中继点来改变路径几何形状。同样的起点和终点，不同的灰像素数量会产生完全不同的路径形状，因为折点位置随中继点移动而变化。源题中计数控制十字偏移、源题中中继点位置固定——这里两者交织：计数改变空间约束，空间约束决定路径。需对比多个灰像素数量不同的示例才能发现"灰数=平移距离"这一规则。
