## 新题 1：重力堆叠高度决定同心环半径

**组合逻辑**：[重力下落](已有) + [计数](已有) → [同心层填充](创新：环半径不由固定色板给出，而由堆叠高度动态决定) ← [种子像素](已有) + [边墙](已有)

**来源原语**：重力下落/堆叠/边墙/碰撞停止(6ad5bdfd), 同心层填充/切比雪夫距离索引/种子像素(9356391f), 计数(52fd389e)

**依赖链**：重力下落将散落的单色小物体堆向边墙，堆叠完成后每列的堆叠高度被计数；种子像素所在列的堆叠高度直接决定以该种子为中心的同心方环扩展半径；环的颜色取自该列中从靠近墙面到远离墙面的堆叠颜色顺序。删掉重力步骤则不知半径；删掉同心填充则堆叠结果无用途。

从散落在网格中的单色小物体出发，先将它们堆向底部边墙，然后以每个种子像素为中心、以该列堆叠高度为半径画同心方环，环色依堆叠顺序从内向外排列。

**输入结构**：约 15x15 的黑(0)背景网格。底部一整行为红(2)边墙。网格中散布 4~7 个单色 4-连通小物体（每个 2~4 像素，形状各异但保持连通），颜色从蓝(1)、绿(3)、黄(4)、橙(7)中选取，同一列可能有多个不同颜色的物体。另有 1~3 个灰(5)种子像素，每个位于不同列，且这些列中都有至少 2 个可堆叠的物体。生成约束：不同物体在水平方向可重叠的列中垂直方向不重叠；每个种子像素的列中堆叠高度不超过 4（以保证同心环不超出网格）。

**规则**：
1. 固定红(2)底部边墙不动。将所有非红、非灰的前景物体从其原位置擦除。
2. 每个物体沿垂直方向整体向下滑动，直到碰到边墙或已结算的其他物体。距边墙最近的物体先结算。物体保持原有形状不变形。
3. 堆叠完成后，对每个灰(5)种子像素：计算该种子所在列中堆叠物体占据的总行数 H。
4. 以种子像素为中心，画 H 层同心方环（切比雪夫距离 d=1,2,...,H）。第 d 层的颜色取自该列堆叠体从最靠近墙面的物体到最远处物体的颜色序列中的第 d 个颜色；若 d 超过颜色序列长度则循环重复。
5. 种子像素自身保持灰(5)不变。同心环超出网格边界的部分裁剪丢弃。同心环不覆盖堆叠后的前景物体——若环像素与已有堆叠物体冲突，堆叠物体优先保留。

**关键洞察**：重力堆叠不仅决定最终布局，还隐式编码了同心环的半径和颜色序列——堆叠高度=环数，堆叠顺序=颜色顺序，这层编码关系需要对比多个示例（不同列有不同堆叠高度和颜色顺序）才能归纳出来。

## 新题 2：对称补全后按形状频次分拣

**组合逻辑**：[对称补全](已有) → [形状频次分组](创新：分组依据不是原始形状而是补全后的完整形状) → [排序/平移](已有)

**来源原语**：对称补全/镜像/标记方块/对称中心(4938f0c2), 排序/平移/形状频次分组/旋转翻转不变(62593bfd)

**依赖链**：每个局部形状都有 2x2 标记方块作为对称中心，先做四向镜像补全得到完整形状。补全后再计算旋转翻转不变的规范形状进行频次分组——原本看起来不同的残片可能补全后变为相同的完整形状。频次>=2 的形状组平移到网格顶端，频次=1 的平移到底端。删掉对称补全则无法判断真实形状；删掉频次分组则不知如何分拣。

将散落的残缺形状先围绕各自的 2x2 标记方块做四向镜像补全，然后按补全后的规范形状频次分拣：重复出现的形状移至顶部，独特形状移至底部。

**输入结构**：约 20x20 的黑(0)背景网格。散布 4~6 个互不重叠的局部区域，每个区域包含：一个绿(3)的 2x2 实心标记方块，以及与之相邻的若干红(2)前景像素（3~8 像素），这些红像素仅出现在标记方块某一到两个象限方向上（即形状不完整）。不同区域中红像素的形状各异，但保证其中至少两个区域在经过四向镜像补全后会产生旋转/翻转等价的完整形状。生成约束：所有区域（包括补全后的完整形状）的边界框互不重叠，且距网格边界至少 2 行/列；补全后最大形状的边界框不超过 7x7。

**规则**：
1. 对每个区域，以其绿(3)2x2 标记方块的中心点为双轴镜像中心，将红(2)前景像素做水平反射、垂直反射和 180 度旋转反射，生成完整的四向对称形状。补全像素同为红(2)。
2. 对每个补全后的完整形状，提取其二值掩码（相对边界框的局部坐标），计算所有 4 种旋转 x 2 种翻转共 8 种变体中的字典序最小掩码作为规范形状。
3. 统计规范形状的出现频次。频次 >= 2 的形状为"共享形状"，频次 = 1 的为"独特形状"。
4. 将共享形状组的所有物体（包括补全像素和绿标记方块）平移至网格顶端（边界框顶行对齐 row 0），保持原始水平位置（左列不变），仅做垂直平移。
5. 将独特形状组的所有物体平移至网格底端（边界框底行对齐最后一行），同样保持水平位置不变。
6. 擦除原位置的所有像素，输出仅包含平移后的结果。

**关键洞察**：两个看起来完全不同的残缺碎片可能在四向补全后变成旋转等价的完整形状——分拣的真正依据是补全后的形状而非残片本身，这一隐蔽规则只有对比多个示例（看到不同残片被归为同组）才能发现。

## 新题 3：射线分区后按区域面积排序循环填充

**组合逻辑**：[射线延伸](已有) → [区域填充](创新：填充对象是射线分隔出的不规则区域而非预定义形状) ← [排序](创新：区域面积排序决定填充颜色分配) + [循环填充](创新：调色板循环应用于按面积排列的区域序列)

**来源原语**：射线延伸/射线遮挡分区/处理顺序决定遮挡(1190bc91), 循环填充/顺序排列/调色板列(e7b06bea), 排序(62593bfd), 区域填充(1190bc91)

**依赖链**：多色水平长线段的每个像素向四个 45 度方向发射射线（按从左到右顺序，先发射的遮挡后发射的），射线将网格分割为若干不规则连通区域。然后统计每个区域的面积并按面积从小到大排序，用右侧调色板列中的颜色按顺序循环分配给排序后的区域。删掉射线步骤则无区域可填；删掉排序则不知颜色如何分配；删掉调色板则无颜色来源。

从水平长线段发射对角射线将网格分割为不规则区域，然后按区域面积从小到大使用右边的调色板列循环着色。

**输入结构**：约 15x15 的黑(0)背景网格。一条水平多色长线段（4~8 像素）位于网格中部偏上位置（约 row 3~5），由 3~5 种不同非黑颜色的像素组成（如蓝(1)、红(2)、黄(4)、橙(7)等），每种颜色出现 1~2 次。网格最右列为调色板列，从上到下排列 2~4 种颜色的像素（如绿(3)、品红(6)、青(8)），其余位置为黑(0)。生成约束：多色线段不与调色板列相邻（中间至少隔 2 列黑色）；线段长度和位置保证射线能在网格内形成至少 4 个封闭或半封闭区域。

**规则**：
1. 在空白画布上，处理多色水平线段从左到右的每个像素：每个像素向四个 45 度方向（左上、右上、左下、右下）发射射线，射线以该像素的颜色着色。射线在碰到已有非黑像素或网格边界时停止（不覆盖该终点像素）。
2. 射线和线段像素将网格（不含调色板列所在的最右列）分割成若干 4-连通的黑色背景区域。计算每个区域的面积（像素数）。
3. 将所有区域按面积从小到大排序。面积相同的区域按其最上最左像素的位置排序（先比较行号小的优先，行号相同则列号小的优先）。
4. 读取调色板列从上到下的颜色序列 P。按排序后的区域顺序，第 i 个区域（从 0 开始）填充颜色 P[i mod len(P)]。
5. 输出网格中保留射线像素和线段像素不变，调色板列擦除为黑(0)。

**关键洞察**：射线的发射顺序造成遮挡差异，使得相同长度的线段在不同示例中可能产生不同数量和形状的区域——区域面积排序将这种不规则几何转化为有序序列，而调色板循环则将序列映射为颜色，三层逻辑缺一不可。

## 新题 4：十字分隔线兼作距离调色板的象限重涂色

**组合逻辑**：[裁剪](已有) ← [十字分隔线](创新：分隔线同时充当距离调色板的载体) → [同心层填充/切比雪夫距离索引](创新：调色板不来自独立行而来自分隔线本身) + [象限位置对应](已有)

**来源原语**：裁剪/十字分隔线/象限/象限位置对应(0bb8deee), 同心层填充/切比雪夫距离索引/色板按距离配色(9356391f)

**依赖链**：十字分隔线将网格分成四个象限，每个象限有一个单色精灵体——但分隔线不是纯色的，其交叉点向外辐射的像素带有不同颜色，构成调色板。裁剪出每个象限的精灵体后，以精灵体的质心（4-连通分量的几何中心取最近像素）为中心，用从对应方向的分隔线臂上读取的颜色序列按切比雪夫距离重涂色。十字线的双重身份（结构分隔+颜色编码）只有对比多个示例后才能识别。

十字分隔线既划分象限又在其四臂上编码颜色序列，裁剪出的象限精灵体按该序列进行切比雪夫距离重涂色。

**输入结构**：约 15x15 的黑(0)背景网格。灰(5)构成一条完整的水平行和一条完整的垂直列，它们交叉形成十字分隔线。但十字线不全是灰色：从交叉点出发，沿四个方向（上、下、左、右），每个方向的分隔线臂上嵌入 2~3 个不同颜色的像素（从交叉点向外依次排列，颜色从蓝(1)、红(2)、绿(3)、黄(4)、品红(6)、橙(7)、青(8)中选取），灰像素填充其余位置。四个象限中各有一个单色前景精灵体（4-连通，3~8 像素，形状各异），四个精灵体颜色互不相同且与分隔线上出现的颜色不同，使用栗(9)等未被占用的颜色。生成约束：每个精灵体的边界框完全在其象限内，距分隔线至少 1 像素；精灵体的切比雪夫距离最大层数不超过对应方向分隔线臂上的颜色数。

**规则**：
1. 识别十字分隔线：找到唯一一行全非黑行和唯一一列全非黑列，交叉点为 (cr, cc)。
2. 从交叉点向四个方向读取分隔线臂上的非灰(5)像素颜色，按距离交叉点从近到远排列，得到四个颜色序列：P_up, P_down, P_left, P_right。
3. 四个象限与颜色序列的对应关系：左上象限使用 P_left，右上象限使用 P_up，左下象限使用 P_down，右下象限使用 P_right。（即每个象限使用顺时针方向下一个臂的序列。）
4. 对每个象限中的精灵体：找到其所有像素的几何中心（行坐标平均值和列坐标平均值），取距该中心最近的精灵体像素作为种子点。
5. 将精灵体的每个像素按其与种子点的切比雪夫距离 d 重涂色：d=0 的像素保留原色不变，d>=1 的像素涂为对应颜色序列中的第 d 个颜色（序列从索引 1 开始）。
6. 输出仅包含四个重涂色后的精灵体（保持原位置），十字分隔线和背景像素全部变为黑(0)。

**关键洞察**：十字分隔线的双重身份是核心隐蔽规则——它既是结构性分割标记，又在四臂上编码了四个象限各自的重涂色调色板，而且象限与臂的对应关系不是直觉上的"最近的臂"而是顺时针旋转一位的臂，必须对比多个示例才能归纳出这一旋转映射。

## 新题 5：印章复制后内嵌标记计数决定膨胀厚度

**组合逻辑**：[印章覆盖/相对坐标复制](已有) → [计数/内嵌标记计数](创新：计数对象不是原始物体中的标记而是印章复制后才出现的标记) → [扩展填充/膨胀](已有)

**来源原语**：印章覆盖/相对坐标复制/控制像素/锚点像素/最强邻接为锚点(f5c89df1), 扩展填充/计数/膨胀/内嵌标记计数/计数决定扩展量(52fd389e)

**依赖链**：源精灵体通过锚点像素定义坐标系，被复制到多个目标控制像素位置。但每个目标控制像素颜色不同，印章完成后该颜色像素会嵌入到复制体中（替换复制体在目标位置处的像素），形成不同数量的"标记"。计数每个复制体中标记像素的数量，以此为厚度向外膨胀出同色光环。删掉印章则无复制体；删掉计数则不知膨胀厚度；删掉膨胀则计数无意义。

将源精灵体印章复制到各目标位置，每个目标处的控制像素颜色嵌入复制体中形成标记，标记数量决定该复制体的膨胀光环厚度。

**输入结构**：约 18x18 的黑(0)背景网格。包含以下元素：
- 一个蓝(1)的源精灵体（4-连通，5~10 像素，形状不规则但边界框不超过 4x4）。
- 一个红(2)锚点像素，4-邻域中与蓝(1)源精灵体接触的边数最多（若平局则取行号最小、再列号最小的）。
- 3~4 个分散的目标控制像素，颜色各不相同，从绿(3)、黄(4)、品红(6)、橙(7)中选取。每个目标像素所在位置恰好对应于源精灵体相对于锚点的某个非黑像素偏移位置——即如果将源精灵体以锚点为原点建立坐标系，目标像素在其目标位置处占据了源精灵体某个像素的对应位置。
- 生成约束：各目标位置的印章区域互不重叠，距网格边界至少 3 行/列（为膨胀留空间）；每个目标控制像素的颜色恰好出现 1 次。

**规则**：
1. 识别锚点：红(2)像素中 4-邻域接触蓝(1)像素数最多的那个为锚点。
2. 计算源精灵体相对于锚点的像素偏移集合 S = {(dr, dc) | 蓝像素位于 (锚点行+dr, 锚点列+dc)}。
3. 对每个目标控制像素 T（位于 (tr, tc)，颜色为 C_t）：在 (tr+dr, tc+dc) 处对所有 (dr,dc) in S 绘制蓝(1)像素——但如果 (tr, tc) 本身对应偏移集合中的某个 (dr0, dc0)，则该位置保留 C_t 颜色而非蓝色。
4. 擦除原始源精灵体和锚点像素。
5. 对每个印章复制体：统计其中颜色为 C_t 的像素数量 N（即嵌入标记数，始终为 1，但目标像素可能与精灵体的多个像素重合——此处 N 等于该控制像素颜色在复制体边界框内出现的总次数）。
6. 将每个复制体的边界框向上下左右各扩展 N 个像素，扩展区域填充颜色 C_t。扩展区域不覆盖复制体本身的蓝(1)像素和 C_t 标记像素——它们保持可见。不同复制体的膨胀区域若重叠，后处理的（按目标像素行号从小到大、行号相同则列号从小到大的顺序处理）覆盖先处理的。

**关键洞察**：目标控制像素不仅标记印章的放置位置，其颜色还会嵌入复制体成为标记——标记数量编码了膨胀距离，标记颜色编码了光环颜色，这种"位置信息转化为参数信息"的编码需要对比多个印章副本的不同膨胀结果才能归纳。

## 新题 6：压缩降噪后多数投票修复再小分量重涂色

**组合逻辑**：[压缩/降噪](已有) → [修复异常/多数投票共识](创新：投票发生在压缩后的低分辨率空间而非原始瓦片) → [连通分量检测 + 面积阈值筛选 + 重涂色](创新：修复后的共识图案中小连通分量被标记)

**规则**：
1. 将输入网格分为 3x3 的块阵列。对每个块，忽略灰(5)像素后统计剩余像素中出现次数最多的颜色作为该块的代表色（黑(0)也参与统计），得到低分辨率网格。

3. 对所有副本的每个局部坐标 (lr, lc)，取该位置上出现次数最多的颜色作为共识色，得到共识图案。
4. 在共识图案上执行 4-连通分量检测：找到所有非黑(0)的同色连通分量。
5. 面积 <= 2 像素的分量，其所有像素重涂为绿(3)。面积 >= 3 的分量保持原色。
6. 输出为重涂色后的共识图案（仅图案本身，不含重复副本或分隔线）。

**关键洞察**：压缩-修复-分量检测形成三级信息变换管道——压缩将噪声阵列还原为可比较的结构，多数投票从冗余副本中恢复真实信号，连通分量检测在纯净信号上才能正确运行。任何一步的缺失或错误都会导致后续步骤产生完全不同的结果。

## 新题 7：滑动聚合后的对称性决定镜像还是裁剪

**组合逻辑**：[滑动/同色系配对](已有) → {条件分支：[轴对称](创新：作为分支判据而非操作目标) ? [裁剪/沿重复轴取首半](已有) : [镜像/拼接/画布加倍](已有)}

**输入结构**：约 10x10 的黑(0)背景网格。每行至多有一对同色系前景像素（蓝(1)与青(8)为一组，黄(4)与橙(7)为一组——同组内的两个像素视为配对）。部分行包含不配对的干扰像素（红(2)或品红(6)，每行至多 1 个），不参与滑动。部分行为全黑空行。同一行中配对像素之间有 1~6 个黑色间隔。生成约束：在所有示例中，同一道题的不同示例滑动后有的产生对称图案、有的产生不对称图案，以便求解者归纳条件分支规则。

**规则**：
1. 识别同色系配对：同一行中蓝(1)+青(8)为一对，黄(4)+橙(7)为一对。每行至多一对。
2. 对每对：保持左侧像素（列号较小的）位置不变，将右侧像素向左滑动直到与左侧像素水平相邻（即列号差为 1）。擦除右侧像素的原位置。
3. 非配对的干扰像素（红(2)、品红(6)）保持原位不动。
4. 滑动完成后，检查整个网格（忽略全黑行）是否关于垂直中轴线左右镜像对称：对每个非黑像素 (r, c)，检查 (r, W-1-c) 处是否有相同颜色的像素（W 为网格宽度）。
5. 若对称：输出为网格的左半部分（列 0 到 W/2-1，W 为偶数时取前 W/2 列）。
6. 若不对称：输出为将网格向右镜像拼接，宽度加倍（原网格在左，列翻转副本在右）。

**关键洞察**：滑动操作本身不是目的，而是为了改变图案的对称性状态——初始像素对的间距在滑动后消失，可能恰好使图案变为对称或保持不对称。对称性作为条件分支的判据（而非操作目标）的用法在所有参考题中均未出现，需要对比至少两个示例（一个走裁剪分支、一个走镜像分支）才能归纳出规则。

**组合逻辑**：[颜色映射/匹配对推导映射](已有) ← [瓦片/带内三瓦片对齐](创新：映射对象不是瓦片本身而是放大后的块内子结构) → [像素放大/格位映射](创新：放大倍数由映射后的颜色种类数决定)

**依赖链**：三个同结构瓦片中两个构成颜色映射示例对，从中推导出颜色映射函数。但映射不直接应用于第三个瓦片的像素——而是先将第三个瓦片进行像素放大（每个像素扩展为 KxK 块），K 等于颜色映射中不同映射对的数量。放大后的每个 KxK 块内全部填充映射后的颜色。两步紧耦合：映射函数决定放大倍数和填充颜色，放大结构承载映射结果。

**规则**：
1. 识别灰(5)分隔行和分隔列，将网格分割为水平带，每带三个瓦片。
2. 对每个带：比较前两个瓦片的非黑像素布局。找到一个颜色置换函数 f 使得瓦片 1 的每个位置 (lr, lc) 的颜色 C 在瓦片 2 的相同位置变为 f(C)。黑(0)映射到黑(0)不计入有效映射对。
3. 统计有效映射对的数量 K（即 f 中满足 f(C) != C 的不同颜色 C 的数量——若某颜色映射到自身则不计入 K）。

5. 输出为第三个瓦片放大后的结果。若有多个带，每个带独立处理，输出按原带顺序垂直拼接（带之间无分隔行）。

**关键洞察**：颜色映射函数不仅定义了"怎么换色"，其中真正发生颜色变化的映射对数量还隐式编码了像素放大的倍率——映射越复杂（变化越多），放大倍率越大。这种"映射复杂度=几何缩放因子"的编码必须对比不同带（不同映射对数→不同放大倍率）才能归纳。

## 新题 10：边墙方向确定重力后堆叠体形状频次筛选

**组合逻辑**：[重力下落/墙面确定方向](已有) + [堆叠/碰撞停止](已有) → [连通分量检测](创新：在堆叠后的状态而非原始状态上检测分量) → [筛选/面积阈值筛选](创新：筛选阈值由堆叠前后面积变化决定) + [擦除](已有)

**依赖链**：边墙指示重力方向，所有散落物体堆向边墙。堆叠后原本分离的单色物体可能接触合并为更大的 4-连通分量，也可能保持独立。对堆叠后的状态做连通分量检测——若某分量的面积大于其中任何单个原始物体的面积（说明发生了合并），则保留该分量；否则（未合并的孤立物体）擦除。保留/擦除的判据取决于重力造成的合并，是原始状态不可预见的涌现效应。

物体堆向边墙后，因碰撞而合并成更大连通分量的保留，未合并的孤立物体被擦除。

**输入结构**：约 14x14 的黑(0)背景网格。一条边为完整的红(2)边墙（可能在任意一边：上/下/左/右，由示例决定），宽度为 1 像素。网格中散布 5~8 个单色 4-连通小物体（每个 2~4 像素），颜色从蓝(1)、绿(3)、黄(4)、橙(7)、青(8)中选取。同色物体可能有多个。生成约束：堆叠后至少有两个同色物体合并形成一个更大的连通分量，同时至少有一个物体堆叠后仍与所有其他物体不相邻（保持孤立）；不同物体在垂直于重力方向上可能占据相同的行/列。

**规则**：
1. 识别红(2)边墙所在的边，确定重力方向（物体朝该边滑动）。
2. 将边墙固定，擦除所有非红前景物体的原位置。
3. 按距边墙从近到远的顺序逐个结算每个物体：物体沿重力方向整体滑动，直到碰到边墙、另一个已结算物体或网格边界时停止。物体保持原形状不变。
4. 堆叠完成后，对所有非红(2)、非黑(0)的前景像素执行 4-连通同色连通分量检测。
5. 对每个检测到的连通分量 CC：如果 CC 的像素数严格大于组成它的任何一个原始物体的像素数（即 CC 由至少两个原始物体合并而成），则保留 CC。否则（CC 的面积等于某个原始物体的面积，说明该物体未与其他物体合并），将 CC 的所有像素擦除为黑(0)。
6. 边墙始终保留。输出中仅包含边墙和通过合并测试的连通分量。

**关键洞察**：重力堆叠产生涌现效应——原本分离的同色物体碰撞后可能合并为一个更大的连通分量，而合并与否取决于物体的初始位置、形状和重力方向的复杂交互。"保留合并体、擦除孤立体"这一筛选规则在堆叠前无法预判结果，必须对比多个示例中不同的合并情况才能归纳。
