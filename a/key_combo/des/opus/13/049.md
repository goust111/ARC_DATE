## 新题 1：邻接清洗后标记定向平铺

**组合逻辑**：[擦除/邻接过滤](已有) + [平铺/周期重复](已有) + [标记定方向](创新组合：标记编码平铺方向而非压缩方向)

**来源原语**：擦除/erase ← 7f4411dc；邻接/adjacency ← 7f4411dc；邻接不足则删除/delete_unsupported ← 7f4411dc；平铺/tile ← 9b30e358；周期重复/periodic_repeat ← 9b30e358；填满网格/fill_grid ← 9b30e358；边缘标记/edge_marker ← 5e6bbc0b；标记定方向/marker_sets_dir ← 5e6bbc0b

**依赖链**：噪声像素与图案像素同色，只能通过邻接支撑度区分——清洗改变了种子母题的内容。清洗后的图案才是真正的种子，而种子的平铺方向由远端标记像素的位置暗中编码。三个环节缺一不可：无清洗则平铺传播噪声，无标记则平铺方向不确定，无平铺则清洗后的图案没有用途。

在边缘图案带中清除邻接支撑不足的噪声像素，再沿标记所指方向将清洁图案平铺到全网格。

**输入结构**：
- 黑(0)背景网格，约 15x15。
- 四条边中的某一条（上/下/左/右）的相邻 3~5 行（或列）被一种非黑前景色（如绿(3)）填充形成图案带。图案带中包含背景色(0)间隙，构成周期性母题。
- 图案带中混入若干同色（绿(3)）孤立噪声像素。噪声像素的 4-邻域中同色像素不超过 1 个，而图案结构像素的同色 4-邻居至少为 2 个。
- 在与图案带相对的那条边上，有一个青(8)标记像素，标示平铺方向（从图案带向标记所在边平铺）。
- 生成约束：图案带所在边与标记所在边不同且相对；图案带去噪后的厚度（行数或列数）能整除网格在平铺方向上的跨度；噪声像素仅出现在图案带内，不出现在其他区域。

**规则**：
1. 对图案带中的每个前景像素，计算其 4-邻域中同色像素的数量。保留拥有至少 2 个同色 4-邻居的像素，将不足 2 个的像素设为黑(0)。
2. 清洗后的图案带（包括其中的背景间隙）即为种子母题。
3. 确定平铺方向：从图案带所在边指向青(8)标记所在边。
4. 沿该方向将种子母题逐段复制，每段保持行（或列）内容不变，仅在垂直于图案带的方向上平移，直到填满整个网格。
5. 移除青(8)标记像素（设为黑(0)）。输出网格尺寸与输入相同。

**关键洞察**：噪声像素与图案像素共享同一颜色，无法通过颜色区分——只有局部邻接支撑度才能把它们分开。平铺方向则由远离图案带的标记像素暗中编码，需对比多个示例（图案带在不同边、标记在对应的相反边）才能归纳出方向规则。

## 新题 2：框内对称性门控填充

**组合逻辑**：[镜像对称检测](创新：从全局水平镜像检测变为逐框局部对称判断，对称轴由框几何隐式定义) + [填充](已有) + [条件选色](创新：从面积阈值变为几何对称性决定颜色)

**来源原语**：镜像对称/mirror_symmetry ← ce039d91；镜像配对则涂色/recolor_if_mirror_pair ← ce039d91；矩形边框/rect_frame ← 84f2aca1；封闭内部/enclosed_interior ← 84f2aca1；填充/fill ← 84f2aca1；面积阈值决定颜色/area_threshold_determines_color ← 84f2aca1

**依赖链**：框的几何结构确定了分析区域和局部对称轴（框内部区域的垂直中线）；灰色图案是对称性检测的对象；检测结果（对称或不对称）决定填充颜色的二元选择。三者紧密耦合——框定义轴，图案是检测主体，检测结果驱动操作参数。

检测每个矩形框内灰色图案关于框自身垂直中线的水平对称性，对称则用蓝色填补内部空隙，不对称则用红色。

**输入结构**：
- 黑(0)背景网格，约 15x18。
- 3~5 个单像素厚矩形边框，各框颜色相同（如黄(4)），尺寸各异（内部面积从 3x3 到 6x6 不等），互不重叠，不接触网格边界。
- 每个框的内部有若干灰(5)像素构成的图案（占内部面积的 30%~60%），其余内部为黑(0)背景。
- 部分框的灰色图案关于该框内部区域的垂直中线严格水平对称（若内部宽度为偶数，中线在两列之间，对称要求对称的两像素分别在中线两侧对应列上）；其余框的灰色图案不对称。
- 生成约束：至少有一个对称框和一个不对称框；各框内灰色像素数量大致相当（差异不超过 2 个），不能通过像素数区分对称与否；灰色图案不接触框边（至少隔一个像素）。

**规则**：
1. 对每个矩形框，确定其内部区域（框边以内的矩形像素区域）和垂直中线（内部区域水平方向的中央；若内部宽度为偶数 W，中线在第 W/2 列与第 W/2+1 列之间）。
2. 对框内每个灰(5)像素（行 r、列 c），计算其关于垂直中线的镜像列 c'。检查位置 (r, c') 是否也是灰(5)。如果所有灰色像素的镜像位置也均为灰色，则该框标记为"对称"；否则标记为"不对称"。
3. 对称框：将内部所有黑(0)像素填充为蓝(1)。
4. 不对称框：将内部所有黑(0)像素填充为红(2)。
5. 保留所有框边像素（黄(4)）和灰(5)像素不变。输出网格尺寸不变。

**关键洞察**：填充颜色不由框的大小、位置、或自身颜色决定，而由内部灰色图案的几何对称性决定。每个框的垂直中线位置不同（因为框宽不同），是隐含的局部对称轴——解题者必须为每个框独立计算其对称参考线。

## 新题 3：孔洞计数编码像素放大倍率

**组合逻辑**：[计数/背景孔洞](已有) + [像素放大](已有) + [框内图案](已有)（创新：孔洞数量不再用于异常值筛选，而是直接编码放大倍率；框的内部尺寸充当隐式验证）

**来源原语**：计数/counting ← 358ba94e；背景孔洞/background_hole ← 358ba94e；像素放大/pixel_upscale ← e7a25a18；矩形边框/rect_frame ← e7a25a18；内部图案/interior_pattern ← e7a25a18；图案在框内/pattern_inside_frame ← e7a25a18

**依赖链**：必须先从种子图案的紧凑边界框中计数背景孔洞→该计数直接成为像素放大的倍率→放大后的图案恰好填满框的内部区域。三者形成循环约束：改变孔洞计数意味着改变放大率，而框的内部尺寸恰好容纳放大结果这一事实隐式验证了推理的正确性。

数出每个矩形框内种子图案紧凑边界框中的背景孔洞数，以该数为倍率像素放大种子图案，填满框内部。

**输入结构**：
- 黑(0)背景网格，约 20x20。
- 3~4 个单像素厚矩形边框，各框颜色不同（如蓝(1)、绿(3)、橙(7)），互不重叠，不接触网格边界。
- 每个框的内部有一个小型种子图案，由某种非框色、非背景色构成（如红(2)、品红(6)等），种子图案为 4-连通的 3~8 个像素，形状不规则，紧凑边界框约 2x2 至 3x3。种子图案位于框内部的左上角区域。
- 种子图案的紧凑边界框（tight bounding box）中，非种子色的黑(0)像素即为孔洞。每个框中种子图案的孔洞数量不同（如 2、3、4）。
- 每个框的内部尺寸（高 x 宽）恰好等于种子紧凑边界框尺寸乘以该框种子的孔洞数量。例如：种子紧凑边界框为 2x3，孔洞数为 3，则框内部为 6x9。
- 生成约束：种子紧凑边界框乘以孔洞数恰好等于框内部尺寸；种子图案是连通的且其紧凑边界框中至少有 2 个孔洞；不同框的孔洞数不同。

**规则**：
1. 对每个矩形框，识别内部的种子图案（非框色、非背景色的连通像素集合），提取其紧凑边界框（包含该图案所有像素的最小矩形）。
2. 计算该紧凑边界框中背景(0)像素的数量，记为 H。
3. 将种子图案的紧凑边界框按 H 倍像素放大：每个像素（无论是种子色还是背景色）变为 H x H 的同色方块。
4. 清空框内部为背景色(0)，然后将放大后的图案写入框内部（左上角对齐框内部左上角）。
5. 保留框边像素和框外区域不变。输出网格尺寸不变。

**关键洞察**：背景孔洞在参考题 358ba94e 中用于比较计数以筛选异常值，在这里却编码了一条变换指令——放大倍率。框的内部尺寸与种子边界框尺寸的整数比关系是一个隐含的验证手段：如果孔洞计数正确，放大结果恰好填满内部；如果计错，尺寸不匹配。需要对比多个框（不同孔洞数、不同放大率）才能归纳出计数→倍率的对应关系。

## 新题 4：异常值块图案成为平铺种子

**组合逻辑**：[计数/异常值提取](已有) + [平铺/周期重复](已有)（创新：异常值不是直接裁剪输出，而是被转化为平铺种子传播到独立的目标区域；孔洞结构从筛选特征变为视觉纹理）

**来源原语**：计数/counting ← 358ba94e；背景孔洞/background_hole ← 358ba94e；异常值提取/outlier_extraction ← 358ba94e；孔洞数量唯一/unique_hole_count ← 358ba94e；平铺/tile ← 9b30e358；周期重复/periodic_repeat ← 9b30e358；填满网格/fill_grid ← 9b30e358

**依赖链**：多个同形块中必须先通过孔洞计数识别异常值→异常值块的完整图案（包括其孔洞位置结构）成为平铺种子→种子被重复铺满独立的目标区域。改变异常值的判定意味着改变平铺内容，两步紧密耦合。

在多个相同大小的前景块中找出孔洞数量独特的异常块，将其完整图案平铺填满下方的目标区域。

**输入结构**：
- 黑(0)背景网格，约 20x25。
- 上半区包含 4~6 个大小相同的正方形前景块（如 5x5），颜色相同（如红(2)）。块之间互不接触，且不接触网格边界。每个块的边框为实心前景色，内部（3x3 区域）包含若干背景(0)像素作为孔洞，孔洞数量和位置各块不同。
- 恰好一个块的孔洞数量与其他所有块的孔洞数量都不同（异常值）。其余块的孔洞数量至少有一个重复伙伴（例如 4 个块的孔洞数分别为 2, 3, 2, 5，则 5 和 3 各出现一次，但 3 也只出现一次——需保证仅有一个唯一值。更严格地：其余块中每个孔洞数至少出现两次）。
- 下半区有一个由灰(5)单像素厚边框围成的大矩形目标区域，内部为黑(0)背景。目标区域内部尺寸（高 x 宽）是前景块尺寸（5x5）的整数倍，如 10x15（即 2x3 个块的大小）。
- 生成约束：恰好一个块为异常值；目标区域内部尺寸是块尺寸的正整数倍；上半区的块按从左到右、从上到下的顺序排列。

**规则**：
1. 对每个前景块，计算其内部区域（边框以内的 3x3 区域）中背景(0)像素的数量。
2. 找出孔洞数量在所有块中唯一出现（仅此一块具有该数量）的前景块，即异常值。
3. 裁剪该异常块为 5x5 图案（保留其前景色边框和内部孔洞结构）。
4. 将该 5x5 图案作为瓦片，从目标区域内部左上角开始，按从左到右、从上到下的顺序逐块复制，直到完全填满目标区域内部。
5. 保留灰(5)目标区域边框不变。上半区所有前景块保留原样。输出网格尺寸不变。

**关键洞察**：异常值的判定依赖于对比所有块的孔洞计数——不是固定阈值，每道题的异常值数量都不同。被选中的块不是简单裁剪输出（如参考题 358ba94e），而是成为空间传播的种子——块内的孔洞结构（原本仅作为筛选特征）成为平铺后的视觉纹理内容。

## 新题 5：对角射线激活框，射线朝向编码错切方向

**组合逻辑**：[射线延伸/角对角对齐](已有) + [错切/行偏移递变](已有) + [印章放置/颜色替换](已有)（创新：对角线射线不再是绘图工具而是无形的激活信号；射线的左右朝向编码印章的错切方向；框颜色决定印章重涂色）

**来源原语**：射线延伸/ray_extend ← ec883f72；角对角对齐/corner_diagonal_align ← ec883f72；经过框角才延伸/extend_past_corner ← ec883f72；实心矩形/solid_rectangle ← ec883f72；空心矩形/hollow_frame ← ec883f72；错切/shear ← 3cd86f4f；行偏移递变/row_offset_progress ← 3cd86f4f；行内容保持/row_content_preserved ← 3cd86f4f；印章放置/stamp ← abc82100；重涂色/recolor ← abc82100；模板图案/stencil_pattern ← abc82100

**依赖链**：实心矩形的四个外角决定射线路径→射线是否经过某空心框的角决定该框是否被激活→射线从左侧角还是右侧角发出决定印章的错切方向（左错切或右错切）→框颜色决定印章的重涂颜色。链中每个环节的输出直接改变下一环节的参数，且射线在输出中不留痕迹——它是纯粹的逻辑信号。

从实心矩形的外角发出对角线射线，若射线经过空心框的角则激活该框，将模板图案错切后印入框内，错切方向由射线的左右朝向决定，印章颜色取框色。

**输入结构**：
- 黑(0)背景网格，约 18x18。
- 一个小型实心矩形（2x3 或 3x2 像素），颜色为蓝(1)，位于网格中偏位置。
- 2~4 个单像素厚空心矩形框，各框颜色不同（如红(2)、绿(3)、黄(4)），框内部尺寸至少 4x4，分散在网格各处，互不重叠，也不与实心矩形重叠。
- 网格的一个角落区域有一个小型模板图案（3x3 的 8-连通非矩形图案，颜色为灰(5)），作为印章母版。模板不与任何框或实心矩形重叠。
- 生成约束：实心矩形的某些外角（四个中的部分）沿 45 度对角线方向恰好经过某些空心框的角像素（几何上严格对齐：射线上的像素逐步 +1/+1 或 +1/-1 等，其中一个恰好落在某框的角上）。未激活的射线不经过任何框角。每个框至多被一条射线激活。模板图案在最大错切（行数-1 列的偏移）后仍能放入被激活框的内部。

**规则**：
1. 从实心矩形的 4 个外角分别发出向外的 45 度对角线射线（右上角发向右上、左上角发向左上、右下角发向右下、左下角发向左下），逐像素沿对角线方向行进。
2. 沿每条射线，逐像素检查：若射线经过某空心框的角像素（该像素为框的颜色且位于框的角位置），则该框被"激活"，记录激活射线的来源角。射线在激活一个框后停止继续搜索。未遇到框角的射线被忽略。
3. 对每个被激活的框：
   a. 取模板图案（灰(5)母版，3x3 边界框）。
   b. 将模板中所有灰(5)像素重涂为该框的颜色。
   c. 确定错切方向：若激活射线从实心矩形的左侧角（左上角或左下角）发出，将重涂后的模板向左错切——第 r 行（r 从 0 开始）向左偏移 r 列；若从右侧角（右上角或右下角）发出，向右错切——第 r 行向右偏移 r 列。错切后的图案放在一个足够大的黑色画布上（高度 = 模板高度，宽度 = 模板宽度 + 模板高度 - 1）。
   d. 将错切后的图案印入框的内部区域：以框内部左上角为锚点对齐错切画布的左上角。仅将错切画布中非黑像素写入框内部对应位置；超出框内部的部分丢弃。
4. 未被激活的空心框保持原样（内部为黑(0)）。实心矩形、模板母版保持不变。输出网格尺寸不变。

**关键洞察**：对角线射线在参考题 ec883f72 中是沿对角线涂色的绘画工具，但这里变成不可见的激活信号——射线本身不在输出中留下任何痕迹。射线的左右朝向（取决于发出射线的是实心矩形的左侧角还是右侧角）隐式编码了错切方向，这层关系必须对比至少两个示例（不同角激活不同框、产生相反方向的错切）才能归纳出。

## 新题 6：周期偏差像素揭示隐藏图案

**组合逻辑**：[周期瓦片/最小周期推断](已有) + [重涂色](已有) + [擦除/补全](已有)（创新：周期分析不用于修复缺口，而用于检测与周期不一致的偏差像素；偏差像素不是要清除的噪声，而是隐藏信息的载体——概念完全反转）

**来源原语**：周期瓦片/periodic_tile ← e95e3d8e；周期对齐/periodic_align ← e95e3d8e；最小周期修复缺口/min_period_repair_gap ← e95e3d8e；重涂色/recolor ← ce039d91；擦除/erase ← 7f4411dc

**依赖链**：必须先从多数一致的像素中推断最小周期瓦片→用周期预期值逐像素比对全网格→区分两类异常：缺口（黑色像素）需要用周期值修复，偏差（非黑但与周期不符的像素）需要标记为新颜色→偏差像素的位置集合构成嵌入在周期载体中的隐藏图案。周期推断和偏差检测互相依赖——偏差太多会干扰推断，因此题目保证偏差占比低。

在一个近似周期的彩色网格中，推断最小周期、修复黑色缺口、并将不符合周期的偏差像素统一涂为蓝色以揭示隐藏图案。

**输入结构**：
- 网格约 12x12，完全填满（无背景边框区域，每个像素都有颜色）。
- 大多数像素（85%~90%）服从一个 2x2 或 2x3 的最小矩形周期瓦片，瓦片使用 2~3 种颜色（如红(2)、绿(3)、黄(4)）。
- 少量像素（约 10%~15%）的颜色被故意替换为与周期预期不同的合法颜色（仍为 0~9 中的某个值，但不是该位置周期应有的颜色，且非黑(0)色）。这些偏差像素的位置集合构成一个可辨识的 4-连通或近连通图案（如一条折线、一个简单封闭形状等）。
- 另有少量黑(0)像素（约 5%）作为缺口——这些位置的原始周期颜色被移除了（与偏差不同：缺口是"丢失数据"，偏差是"替换数据"）。
- 生成约束：偏差像素占比不超过 15%，确保从多数像素中可唯一确定周期瓦片；偏差像素的替换颜色与该位置的周期预期颜色不同且非黑色；缺口像素为黑(0)且不与偏差像素相邻（避免混淆）；蓝(1)不作为周期瓦片的颜色使用（留给输出标记）。

**规则**：
1. 从所有非黑像素中推断最小矩形周期瓦片（行周期 pH、列周期 pW）：对每个残差类 (r mod pH, c mod pW)，该类中出现次数最多的颜色为周期预期颜色。
2. 对每个黑(0)像素（缺口），用其残差类的周期预期颜色填充。
3. 对每个非黑像素，比对其颜色与残差类周期预期颜色：
   - 若一致，保持不变。
   - 若不一致，将该像素重涂为蓝(1)。
4. 输出网格尺寸不变。

**关键洞察**：参考题 e95e3d8e 中只有一类异常（黑色缺口），修复缺口即可完成任务。这里存在两类异常——缺口（缺失数据，需修复）和偏差（替换数据，需标记），必须区分对待。偏差像素的位置本身是答案的核心——它们不是噪声而是故意嵌入周期载体中的隐藏信号。解题者需要先"看穿"周期才能发现隐藏内容。

## 新题 7：V 形遮挡定义可见区，推断周期补全盲区

**组合逻辑**：[列遮挡/射线投射](创新：V 形从"激活下方填充"变为"定义信息可见窗口") + [周期瓦片/补全](已有) + [擦除](已有)（创新：周期推断只能使用被遮挡列的部分数据，未遮挡列是必须由推断结果外推填充的"盲区"）

**来源原语**：列遮挡/column_coverage ← 6d58a25d；前景对象/foreground_object ← 6d58a25d；遮挡列延伸至边/covered_col_to_edge ← 6d58a25d；周期瓦片/periodic_tile ← e95e3d8e；周期对齐/periodic_align ← e95e3d8e；补全/complete ← e95e3d8e/8a6d367c；擦除/erase ← 7f4411dc

**依赖链**：V 形结构的几何形状决定哪些列被遮挡→只有被遮挡的列中显示了周期图案的片段→从这些片段推断完整的最小周期瓦片→用推断出的瓦片填充未遮挡列中的空白→最终移除 V 形结构。V 形不是要变换的对象，而是一个"观察窗口"——它决定了求解者能看到什么信息，也决定了什么信息需要外推。

V 形结构遮挡下方部分列，被遮挡列中可见周期图案的片段；推断完整周期瓦片并补全未遮挡列的空白，然后移除 V 形。

**输入结构**：
- 黑(0)背景网格，约 15x15。
- 上半区（约上方 5~7 行）有一个 V 形（或倒 V 形，即人字形/chevron）前景结构，颜色为橙(7)。V 形由两条对角线像素段构成，顶点在某一行的某列，两翼沿对角线向下展开。V 形占据的列集合从顶点向下逐行变宽。
- 下半区（约下方 8~10 行）存在一个周期彩色图案，但只在"被 V 形遮挡的列"中可见。具体定义：取 V 形最宽一行（最底行）所覆盖的列集合 C；在下半区的每一行中，仅列属于 C 的位置显示周期图案的像素，列不属于 C 的位置为黑(0)。
- 周期图案使用 2~3 种非黑非橙颜色（如红(2)、绿(3)、黄(4)），最小周期为 2x2 或 3x2。
- 生成约束：V 形最宽处的列集合 C 至少覆盖一个完整的水平周期（pW 个连续列），以确保周期可唯一确定。V 形的橙(7)像素不出现在下半区。下半区中可见像素不使用橙(7)色。

**规则**：
1. 确定 V 形结构最底行所覆盖的列集合 C（该行中所有含橙(7)像素的列编号）。
2. 在下半区中，仅使用列集合 C 中非黑像素的数据，推断最小矩形周期瓦片（行周期 pH、列周期 pW）。
3. 对下半区中每个列不属于 C 的黑(0)像素，用其残差类 (r mod pH, c mod pW) 的周期颜色填充。
4. 移除上半区的 V 形结构：将所有橙(7)像素设为黑(0)。
5. 输出网格尺寸不变。

**关键洞察**：V 形在参考题 6d58a25d 中是"天花板"——覆盖的列触发下方的向下填充操作。在这里 V 形的角色完全反转：它是一个信息窗口，其几何形状决定了求解者能观察到的数据范围。未被遮挡的列是"盲区"，其内容只能通过从可见列中推断周期再外推得到。V 形越窄，可见信息越少，推理难度越高。

## 新题 8：格子提取驱动精灵射线涂色

**组合逻辑**：[提取/格内判定](已有) + [射线延伸/质心偏移定向](已有) + [重涂色](已有)（创新：格子提取产生的缩小网格不是最终输出，而是射线操作的目标空间；精灵体射线不再画到边界，而是精确命中缩小网格中的单元格；三个独立来源的机制交织成一个不可分割的推理链）

**来源原语**：提取/extract ← 458e3a53；分隔线网格/separator_lattice ← 458e3a53；纯色单元格/solid_cell ← 458e3a53；格内判定/cell_interior_test ← 458e3a53；纯色即有效/solid_is_valid ← 458e3a53；方向精灵体/directional_sprite ← 13f06aa5；质心偏移定向/centroid_bias_dir ← 13f06aa5；标记像素/marker_pixel ← 13f06aa5；射线延伸/ray_extend ← 13f06aa5；重涂色/recolor ← ce039d91

**依赖链**：分隔线网格中区分纯色单元格和杂色干扰单元格→提取纯色单元格组成缩小颜色网格→精灵体的方向由其体色像素的质心偏移决定→沿精灵方向发出的射线映射到缩小网格的行/列坐标→射线命中的单元格被涂为精灵的标记色→最终输出是修改后的缩小颜色网格。三个子系统（格子提取、方向解码、目标涂色）必须完整衔接才能产生答案。

从分隔线网格中提取纯色单元格组成缩小网格，由边缘精灵体的射线方向确定目标单元格并涂为精灵标记色，输出修改后的缩小网格。

**输入结构**：
- 黑(0)背景网格，约 20x20。
- 灰(5)分隔线将网格内部区域分割为 m x n 的单元格阵列（m 约 4~6 行，n 约 4~6 列）。分隔线为完整行和完整列，宽度为 1 像素。
- 一个连续的矩形子集的单元格是纯色的（每个格子内所有像素为同一种非灰非黑颜色，如红(2)、绿(3)、黄(4)、蓝(1)等），形成一个 p x q 的子阵列（p 约 3~4，q 约 3~4）。该纯色子阵列的位置在阵列中不一定居中。其余单元格内部填充多色重复图案（干扰，至少包含两种颜色）。
- 在分隔线网格外的网格边缘空白区域（分隔线不延伸到此），有 2~4 个方向精灵体。每个精灵体由一种体色（如栗(9)）的 5~7 个 8-连通像素组成，形状不对称以编码方向。每个精灵体中嵌有一个不同颜色的标记像素（如品红(6)、橙(7)等），标记像素被体色像素包围。
- 精灵体的射线方向为四个正交方向之一（上/下/左/右），由体色像素的质心相对于标记像素的位置决定：质心偏向的方向为"后方"，反方向为射线方向。
- 生成约束：每个精灵体的射线方向指向网格内部；射线沿其方向延伸后，其对应的行（水平射线）或列（垂直射线）恰好经过纯色子阵列中某一行或某一列的单元格区域。不同精灵体的射线命中不同行或不同列（不会两个精灵命中同一单元格）。精灵体的标记色与纯色子阵列中已有的颜色都不同。

**规则**：
1. 识别灰(5)分隔线的行和列，将网格分割为单元格阵列。对每个单元格，检测其内部是否为纯色（所有像素颜色相同且非灰非黑）。提取所有纯色单元格，按它们在阵列中的行列位置组成一个 p x q 的缩小颜色网格。
2. 对每个精灵体，计算其体色像素的质心坐标 (cy, cx) 和标记像素的坐标 (my, mx)。质心相对于标记的偏移方向为"后方"：若 cy < my（质心在上），射线向下；若 cy > my（质心在下），射线向上；若 cx < mx（质心在左），射线向右；若 cx > mx（质心在右），射线向左。
3. 从精灵体的标记像素出发，沿射线方向延伸。确定射线经过缩小网格的哪一行或哪一列（通过射线在原始网格中的行/列坐标映射到单元格阵列的行/列编号，再映射到纯色子阵列中的位置）。
4. 射线方向为水平时（左或右），确定射线对应缩小网格中的某一行——将该行中沿射线方向首先遇到的纯色单元格（从精灵体侧进入该行的第一个单元格）重涂为标记像素的颜色。射线方向为垂直时（上或下），同理处理对应的列。
5. 输出仅为修改后的 p x q 缩小颜色网格（裁剪到纯色子阵列的范围，不含分隔线和干扰单元格）。

**关键洞察**：分隔线网格在参考题 458e3a53 中仅用于数据提取，精灵体在参考题 13f06aa5 中仅用于向网格边界发射装饰性射线。这里两者被融合到一个全新的结构关系中：提取产生的缩小网格成为精灵射线的目标空间，精灵的方向编码决定了缩小网格中哪个具体单元格被修改。解题者必须先完成提取（否则不知道目标空间的布局），再解码精灵方向（否则不知道射线指向哪里），最后在缩小网格上执行定点涂色——三步不可互换也不可省略。
