## 新题 1：遮挡揭示后的对称补全决定腔室存亡

**组合逻辑**：[擦除](已有) → [对称补全](创新：作用于格点腔室内的碎片而非独立对象) → [计数](已有) → [筛选+填充](创新：计数结果作为腔室间的竞争判据)

**来源原语**：擦除/erase(3345333e), 对称补全/symmetry_completion(3345333e), 填充/fill(17b866bd), 计数/counting(d0f5fe59, 29623171), 筛选/filtering(29623171), 格点骨架/lattice_frame(17b866bd), 封闭腔室/enclosed_cavity(17b866bd), 填充矩形/filled_rectangle(3345333e), 遮挡/occlusion(3345333e)

**依赖链**：遮挡移除改变了腔室内的可见像素集 → 对称补全依赖移除后的像素集推断完整图案 → 完整图案的像素数是腔室间竞争的判据 → 竞争胜出决定哪些腔室被填充、哪些被清空。删除任一环节均无法独立求解：不移除遮挡则对称轴检测失败；不做对称补全则像素数不准确，竞争结果错误；不做竞争筛选则不知道保留哪些腔室。

从格点腔室中移除遮挡矩形、对称补全碎片图案，再以补全后像素数最多的腔室胜出并被洪泛填充，其余腔室清空。

**输入结构**：
- 约 17x17 的网格，灰(5)色像素构成周期性格点骨架（横竖各 1 像素宽的灰线），将内部分隔为若干矩形腔室（每个腔室内部约 4x4 至 5x5 像素）。
- 其中 3~4 个腔室包含单色碎片图案（每个腔室使用不同颜色，如蓝(1)、绿(3)、黄(4)等），碎片为 4-连通的不规则小图形（3~8 像素），具有潜在的左右镜像对称性。
- 每个含图案的腔室中有一个红(2)填充矩形（2x2 或 2x3），部分覆盖碎片图案，遮挡了图案的部分像素。被遮挡的部分恰好包含对称补全所需的关键像素。
- 其余腔室为纯黑(0)背景。
- 生成约束：每个碎片图案在其腔室中具有唯一的左右镜像对称轴；遮挡矩形的颜色（红(2)）与所有图案颜色不同；遮挡移除后的残余像素足以唯一确定对称补全结果；各腔室图案补全后像素数互不相同（保证筛选无歧义）。

**规则**：
1. 识别每个腔室内的红(2)填充矩形，将其像素擦除为黑(0)。
2. 对每个腔室内剩余的非黑、非灰像素集合，检测其左右镜像对称轴（轴为腔室内的某一竖直列或两列之间的中线）。将现有像素沿该轴镜像翻转，在对称位置补上缺失像素，颜色与源像素相同。
3. 统计每个腔室内补全后的图案像素总数。
4. 像素数最多的腔室胜出：将该腔室内所有黑(0)像素替换为该图案的颜色（即洪泛填充整个腔室内部）。所有其他含图案的腔室，将图案像素擦除为黑(0)。
5. 格点骨架和空腔室保持不变。

**关键洞察**：遮挡矩形的位置经过精心放置，使得不移除遮挡时，残余像素的朴素计数会指向错误的腔室；只有正确补全对称后，真实像素数最多的腔室才会被揭示。

## 新题 2：最短路径筛选色块后挖孔紧凑排列

**组合逻辑**：[寻路/最短路径](创新：路径不作为输出，而作为筛选判据) → [筛选](创新：路径经过与否决定色块存亡) → [挖孔/同色匹配](已有) → [紧凑排列](创新：排列顺序由路径上的遭遇顺序决定)

**来源原语**：寻路/pathfinding(3ad05f52), 最短路径/shortest_path(3ad05f52), 筛选/filtering(29623171), 挖孔/punch_holes(58f5dbd5), 同色匹配/same_color_matching(58f5dbd5), 紧凑排列/compact_packing(58f5dbd5), 模板图案/motif_stencil(58f5dbd5), 单色块/monochrome_block(58f5dbd5), 端点分量/endpoint_component(3ad05f52), 走廊通道/corridor(3ad05f52)

**依赖链**：最短路径决定哪些色块存活（路径未经过的色块被淘汰）→ 只有存活色块才执行挖孔操作 → 紧凑排列的顺序取决于路径首次经过各色块的先后。路径改变则存活集合和排列顺序都改变；挖孔依赖存活筛选；排列依赖路径顺序——三者环环相扣。

在迷宫中寻找两端点间的最短路径，保留路径经过的色块并用同色模板挖孔，按路径遭遇顺序紧凑排列。

**输入结构**：
- 约 20x20 的网格，黑(0)背景。
- 栗(9)色像素构成单像素宽的正交墙壁，形成迷宫走廊。
- 迷宫中散布 4~5 个 5x5 的单色实心方块（各用不同颜色：蓝(1)、绿(3)、黄(4)、品红(6)等）。方块占据走廊的一部分，但不阻断通路（方块周围至少有一条绕行通道）。
- 迷宫的两侧（如左上角和右下角）各有一个 2x2 的红(2)端点分量，标记路径的起止点。
- 在远离走廊的区域（如网格底部边缘外侧的留白行），放置与每个方块同色的小型模板图案（3~5 像素的 4-连通不规则图形），每个模板颜色唯一对应一个方块。
- 生成约束：两端点间存在唯一最短路径（无平局）；最短路径必经过部分但非全部色块的边界框内部；模板图案的边界框不超过 5x5，能居中放入方块内。

**规则**：
1. 将栗(9)墙壁像素视为阻塞，其余像素视为可通行。求两个红(2)端点分量之间的 4-连通最短路径（路径像素集合）。
2. 检查每个 5x5 单色方块：若最短路径至少经过该方块边界框内的一个像素，则该方块存活；否则淘汰。
3. 对每个存活方块，找到与其同色的模板图案，将模板居中对齐到方块上，模板覆盖的像素位置在方块中被擦除为黑(0)（挖孔）。居中方式：模板边界框的中心与 5x5 方块中心对齐（向左上取整）。
4. 按最短路径首次进入各存活方块边界框的先后顺序，将挖孔后的方块紧凑排列为一行，相邻方块间隔 1 列黑(0)像素，左侧留 1 列黑(0)边框。
5. 输出网格高度为 5+2（上下各 1 行边框），宽度为 存活方块数x5 + (存活方块数-1)x1 + 2（左右各 1 列边框）。

**关键洞察**：最短路径不是最终输出的一部分，而是充当"筛选器"和"排序器"的隐式中间结果——同一组色块和模板，在不同迷宫布局下会因路径不同而产出完全不同的排列。

## 新题 3：镜像轴方向解码滑动目标边

**组合逻辑**：[镜像轴检测](创新：轴方向不用于翻转，而编码滑动的坐标系) + [颜色编码方向](创新：异常像素的颜色在镜像轴确定的坐标系中才有意义) → [擦除](已有) → [滑动](已有) → [裁剪](已有)

**来源原语**：镜像/mirror(7468f01a, 3345333e), 颜色编码方向/color_coded_dir(f3e62deb), 滑动/slide(f3e62deb), 裁剪/crop(7468f01a), 擦除/erase(009d5c81), 前景矩形/foreground_rect(7468f01a), 空心矩形/hollow_rect(f3e62deb), 网格边界/grid_edge(f3e62deb)

**依赖链**：先检测前景图案的镜像对称轴方向（水平轴 vs 垂直轴），轴方向决定"平行/垂直"坐标系的含义 → 在该坐标系下，异常像素的颜色才能正确解码为具体的滑动方向 → 擦除异常像素恢复对称后，将完整图案滑向解码出的网格边。删除镜像轴检测则无法确定坐标系，颜色无法解码；删除颜色解码则不知道滑向哪条边。

检测前景图案的镜像对称轴方向，据此将破坏对称的异常像素颜色解码为滑动方向，擦除异常像素后将完整图案滑到指定网格边。

**输入结构**：
- 约 12x12 的黑(0)背景网格。
- 网格中央区域有一个由蓝(1)像素构成的 4-连通前景图案（6~12 像素），该图案几乎具有镜像对称性，但恰好有 1~2 个像素被替换为其他颜色（绿(3)或黄(4)），破坏了对称。
- 绿(3)编码"沿对称轴正方向"（垂直轴时向右，水平轴时向下）。黄(4)编码"沿对称轴负方向"（垂直轴时向左，水平轴时向上）。
- 若异常像素有多个且颜色不同，以出现次数多的颜色为准（投票机制）。
- 前景图案的对称类型：恰好有一条镜像对称轴（将异常像素还原为蓝(1)后）。该轴要么是垂直的，要么是水平的。
- 生成约束：图案与网格边界间有足够空间完成滑动；异常像素还原后对称轴唯一；投票无平局。

**规则**：
1. 找到所有非黑像素。将其中非蓝(1)的像素记为"异常像素"，记录其颜色。
2. 将异常像素临时替换为蓝(1)，检测整个蓝色图案的唯一镜像对称轴。
3. 确定滑动方向坐标系：
   - 若对称轴为垂直线：绿(3)→ 向右滑到右边界，黄(4)→ 向左滑到左边界。
   - 若对称轴为水平线：绿(3)→ 向下滑到下边界，黄(4)→ 向上滑到上边界。
4. 统计异常像素中绿(3)和黄(4)各自的个数，个数多者决定最终滑动方向。
5. 将异常像素正式擦除为蓝(1)，恢复完整对称图案。
6. 将图案整体平移，直到图案边界框在滑动方向上与网格边界齐平。图案原位置擦除为黑(0)。

**关键洞察**：绿(3)和黄(4)的含义不是固定的"左/右/上/下"，而是"沿对称轴的正/负方向"——必须先检测对称轴方向才能解码颜色含义，这使得镜像检测和方向解码不可分割。

## 新题 4：色带压缩序列作为间隙分段填色模板

**组合逻辑**：[压缩/色带/空间排列顺序](已有) → [射线延伸/间隙对半分](创新：间隙不再二分，而按压缩序列等分为 N 段) → [平铺](创新：压缩序列作为分段填色模板循环铺入间隙)

**来源原语**：压缩/compress(4be741c5), 色带/color_band(4be741c5), 空间排列顺序/spatial_order(4be741c5), 射线延伸/ray_extend(d968ffd4), 间隙对半分/gap_bisect(d968ffd4), 矩形/rectangle(d968ffd4), 平铺/tile(bd4472b8), 行主色压缩单像素/row_majority_to_pixel(4be741c5)

**依赖链**：色带压缩提取出颜色序列和带轴方向 → 序列长度决定间隙被切分为多少段（不再是简单二分）→ 序列颜色按顺序循环铺入各段 → 带轴方向还同时决定间隙的填充方向（横带→竖向填充，竖带→横向填充）。压缩结果同时编码了分段数、填色内容和填色方向三重信息。

提取一侧色带区域的压缩颜色序列，将另一侧两个对齐矩形之间的间隙按序列长度等分，用该序列循环填色。

**输入结构**：
- 约 16x20 的网格，黑(0)背景。
- 网格左半部分（约前 8 列）包含宽度不均匀的水平或垂直色带（3~5 种颜色，如蓝(1)、绿(3)、黄(4)、品红(6)），色带边界参差不齐（某些行/列有少量其他颜色像素混入），但每行/列的主色清晰。色带覆盖左半部分的全部行列。
- 网格右半部分包含两个同尺寸的单色灰(5)实心矩形（如 3x4），沿色带的正交方向对齐（若色带为水平带，则两矩形左右对齐，共享相同行范围，中间有黑色间隙；若色带为垂直带，则两矩形上下对齐，共享相同列范围，中间有黑色间隙）。
- 间隙宽度为色带压缩序列长度的整数倍（保证等分无余数）。
- 生成约束：色带压缩后颜色序列长度为 3~5；间隙宽度可被序列长度整除；两矩形完全相同且对齐无偏移。

**规则**：
1. 对左半部分的色带区域，逐行（或逐列）取主色，提取沿带轴方向的压缩颜色序列 S = [c1, c2, ..., cK]。
2. 确定带轴方向：若色带为水平带（行主色沿列方向变化），则带轴为垂直方向。
3. 在右半部分找到两个灰(5)矩形及其间的间隙。将间隙沿矩形对齐方向等分为 K 段。
4. 从距灰矩形 A 较近的一端开始，依次用 S 中的颜色填充各段：第 1 段填 c1，第 2 段填 c2，... 第 K 段填 cK。若间隙宽度超过 K 段一轮，则颜色循环使用。
5. 每段的填充范围在垂直于间隙方向上，跨越矩形的完整行范围（或列范围）。
6. 两个灰矩形及左半部分的色带区域保持原样不变。

**关键洞察**：色带区域不仅提供颜色信息，还通过带轴方向隐式编码了间隙的分段方向——水平色带意味着垂直分段，反之亦然。压缩操作同时提取了三重信息（颜色、数量、方向），驱动了间隙填充的三个维度。

## 新题 5：三连块缺角定位印章锚点并决定图案重涂色

**组合逻辑**：[对角偏移/缺角](创新：缺角方向不用于生成副本，而定位印章的锚点位置) → [印章覆盖/固定图案](创新：图案印在缺角对角处而非原位) → [重涂色](创新：三连块颜色编码印章图案的重涂色映射)

**来源原语**：对角偏移/diagonal_offset(1e5d6875), 三连块/triomino(1e5d6875), 缺角/missing_corner(1e5d6875), 印章覆盖/stamp(a9f96cdd), 锚点像素/anchor_pixel(a9f96cdd), 固定图案/fixed_pattern(a9f96cdd), 重涂色/recolor(a79310a0), 源色决定方向/source_color_decides(1e5d6875)

**依赖链**：三连块的缺角方向决定印章锚点在何处（缺角对角线方向偏移 2 步） → 三连块的颜色决定印章图案如何重涂色 → 印章操作在锚点处粘贴重涂后的图案。缺角方向、源色、印章位置三者紧耦合：改变缺角方向则锚点移位，改变颜色则图案配色改变，三者缺一不可。

每个 L 形三连块的缺角方向决定印章锚点的对角偏移位置，三连块颜色决定印章图案的重涂色方案。

**输入结构**：
- 约 15x15 的黑(0)背景网格。
- 散布 3~5 个 L 形三连块，每个占据 2x2 方框中的 3 个像素（缺少一个角），颜色各不相同（红(2)、绿(3)、黄(4)、品红(6)等）。三连块间互不相邻（边界框间至少间隔 5 像素）。
- 网格某个角落（如右下角）有一个 3x3 的橙(7)固定参考图案（8 像素的十字形或其他 4-连通图形，中心位置已知）。该图案是所有印章的母版。
- 颜色到重涂色的映射需对比多个示例才能确定，例如：红(2)三连块→印章图案重涂为蓝(1)；绿(3)三连块→印章图案重涂为栗(9)；黄(4)三连块→印章图案重涂为灰(5)。此映射在训练示例间保持一致。
- 生成约束：每个三连块的缺角对角方向偏移 2 步后的锚点位置在网格内；各印章图案间不重叠；印章图案不与三连块重叠；印章图案不与参考图案重叠。

**规则**：
1. 识别所有 L 形三连块（2x2 方框中缺一角的 3 像素连通体），记录每个三连块的颜色和缺角方向（左上/右上/左下/右下）。
2. 找到网格中的 3x3 橙(7)参考图案，记为母版 P。
3. 对每个三连块：
   a. 确定缺角方向。锚点 = 三连块中心像素沿缺角对角方向偏移 2 步的位置（如缺角在右下→锚点在三连块中心右下方 2 行 2 列处）。"中心像素"定义为 2x2 方框中与缺角对角的那个像素。
   b. 根据三连块颜色查找重涂色映射（需从训练示例中归纳），将母版 P 的所有橙(7)像素替换为映射后的颜色，得到重涂图案 P'。
   c. 将 P' 以锚点为中心粘贴到网格上。超出网格边界的部分裁剪丢弃。
4. 三连块本身保留在原位不变。参考图案保留在原位不变。
5. 若多个印章图案覆盖同一像素，按三连块中心到网格中心距离从远到近的顺序绘制（离网格中心远的先画，近的后画覆盖）。

**关键洞察**：颜色→重涂色的映射关系只能通过对比多个训练示例归纳，单个示例中看到的"红三连块→蓝图案"可能被误以为是固定规则，但实际上是颜色编码表的一条——必须收集足够多的颜色对才能确信映射关系。

## 新题 6：分区密度筛选后逐区降采样并紧凑拼接

**组合逻辑**：[分隔线/分区区域](已有) → [计数/筛选/最密区域保留](创新：密度筛选不再触发洪泛填充，而是选出待降采样的区域) → [降采样/矩形分区/网格采样](创新：降采样逐区域独立执行) → [紧凑排列](创新：降采样后的小矩阵按原空间位置排列)

**来源原语**：分隔线/separator_line(29623171), 分区区域/partitioned_region(29623171), 计数/counting(29623171), 筛选/filtering(29623171), 最密区域保留填充/densest_region_kept_filled(29623171), 降采样/downscale(90c28cc7), 矩形分区/rectangular_partition(90c28cc7), 网格采样/grid_sampling(90c28cc7), 紧凑排列/compact_packing(58f5dbd5), 保持行列顺序/preserve_row_col_order(58f5dbd5)

**依赖链**：分隔线定义区域 → 密度计数筛选出存活区域（决定哪些区域参与后续处理）→ 每个存活区域内部含有小矩形分区子结构，独立降采样为紧凑小矩阵 → 小矩阵按各区域在原网格中的行列位置紧凑排列为输出。筛选改变了参与降采样的区域集；降采样依赖区域内部结构；排列依赖原始空间关系。

用分隔线划分区域，筛选出像素密度最高的区域，对每个存活区域内部的矩形分区子结构独立降采样，按原空间顺序紧凑拼接为输出。

**输入结构**：
- 约 19x19 的网格，黑(0)背景。
- 橙(7)色的完整行和完整列将网格分隔为 2x2 或 2x3 个矩形区域（分隔线单像素宽）。
- 每个区域内部包含一个由多种颜色构成的"迷你棋盘"——若干大小不等的单色矩形子分区紧密排列（类似参考题 90c28cc7 的结构），但有部分分区被擦除为黑(0)。
- 各区域中非黑像素的密度（非黑像素数 / 区域总像素数）不同。
- 生成约束：恰好有 2 个区域的密度并列最高（这 2 个区域将存活）；每个存活区域的分区子结构可被唯一降采样（每个矩形分区对应一个像素）；两个存活区域降采样后的小矩阵尺寸可能不同。

**规则**：
1. 识别橙(7)分隔行和分隔列，划分出所有矩形区域。
2. 对每个区域计算非黑、非橙像素的总数。选出像素数并列最多的区域（可能有 2 个或更多），其余区域淘汰。
3. 对每个存活区域：
   a. 找到其中所有非黑连通矩形分区的左上角坐标。
   b. 提取排序后的唯一行坐标和唯一列坐标。
   c. 在每个（行坐标, 列坐标）处采样该像素的颜色，构成降采样后的小矩阵。
4. 将所有小矩阵按其原区域在大网格中的行列位置排列：原来在上方的排在上面，原来在左方的排在左边。相邻小矩阵间用 1 列（或 1 行）黑(0)像素分隔。输出外围无边框。
5. 输出网格仅包含存活区域的降采样结果，不包含分隔线或淘汰区域。

**关键洞察**：降采样不是全局操作而是逐区域执行的——不同区域内部分区结构不同，降采样结果也不同。密度筛选决定了哪些区域的内部结构被"读取"，形成了一个先筛选再解码的两层推理。

## 新题 7：标记半区裁剪后连通分量计数决定对角复制步数

**组合逻辑**：[标记对齐指定半区/裁剪](已有) → [计数/连通分量](创新：计数结果不决定边长，而决定对角平移步数) → [平移/对角偏移](创新：平移步数由前步计数动态决定) → [重涂色](已有)

**来源原语**：标记对齐指定半区/marker_selects_half(fbf15a0b), 裁剪/crop(fbf15a0b), 标记像素/marker_pixel(fbf15a0b), 计数/counting(d0f5fe59), 连通分量/connected_component(d0f5fe59), 数量决定边长/count_determines_side(d0f5fe59→创新为数量决定步数), 平移/translate(1e5d6875), 对角偏移/diagonal_offset(1e5d6875), 重涂色/recolor(1e5d6875)

**依赖链**：标记像素确定保留哪个半区 → 裁剪后计算保留半区中前景对象的连通分量数 N → N 决定对角复制的步数 → 对每个连通分量沿其重心到裁剪区中心的方向平移 N 步并重涂色。半区选择改变了连通分量集合；分量数改变了步数；步数改变了输出布局。

按标记像素裁剪出半个网格，数其中连通分量的个数 N，将每个分量沿其偏离中心的方向对角平移 N 步并重涂色。

**输入结构**：
- 约 14x14 的网格，黑(0)背景。
- 网格中散布若干蓝(1)色的 4-连通前景对象（2~6 像素的不规则小图形），共 4~8 个，分布在网格的两个半区（左半和右半，或上半和下半）中。
- 恰好有 2 个品红(6)标记像素位于同一行（或同一列），且都落在同一个半区中，标记该半区为保留半区。标记像素不属于任何前景对象。
- 生成约束：保留半区中蓝色连通分量数 N 在 2~4 之间；每个分量对角平移 N 步后仍在网格范围内（以保留半区为画布扩展到完整网格尺寸）；各分量平移后互不重叠。

**规则**：
1. 找到 2 个品红(6)标记像素。若它们共享同一行，则按它们所在的列范围确定保留左半还是右半；若共享同一列，则确定保留上半还是下半。保留包含两个标记像素的那个半区。
2. 在保留半区内，将品红(6)标记像素擦除为黑(0)。
3. 计算保留半区内蓝(1)连通分量（4-连通）的个数 N。
4. 计算保留半区的中心坐标 C（行中心, 列中心，向下取整）。
5. 对每个蓝(1)连通分量，计算其重心坐标 G（所有像素行坐标均值, 列坐标均值，四舍五入取整）。确定从 C 到 G 的方向向量 D = (sign(G_row - C_row), sign(G_col - C_col))，其中 sign 返回 -1/0/1。
6. 将该分量的每个像素坐标加上 N * D，得到新位置。新位置上的像素颜色设为绿(3)（重涂色）。原位置的蓝色像素保留不变。
7. 超出网格边界的像素丢弃。若新像素与原蓝色像素重叠，新绿色覆盖原蓝色。
8. 输出网格尺寸与原完整网格相同。被淘汰半区内的所有像素清为黑(0)。

**关键洞察**：连通分量数 N 既是被计数的对象数，又是每个对象移动的步数——增加一个对象会让所有对象（包括新增的）都多移动一步，形成"自指"式的数量-距离耦合。

## 新题 8：双约束同时满足——对称补全且路径连通

**组合逻辑**：[对称补全](创新：不是唯一确定的补全，而是约束之一) + [寻路/连通性](创新：连通性作为第二约束与对称同时满足) → 交集求解

**来源原语**：对称补全/symmetry_completion(3345333e), 寻路/pathfinding(3ad05f52), 最短路径/shortest_path(3ad05f52), 端点分量/endpoint_component(3ad05f52), 走廊通道/corridor(3ad05f52)

**依赖链**：这不是流水线结构，而是同时约束满足。输出必须同时满足：(A) 图案关于某轴镜像对称；(B) 图案通过 4-连通路径连接两个端点。单独的对称补全可能产生多种合法结果，单独的连通约束也有多种方案，只有同时满足两者的唯一方案才是正确输出。两个约束缺一不可——删除对称约束则连通方案不唯一，删除连通约束则对称补全不唯一。

在部分缺失的图案中填入像素，使图案同时满足镜像对称和端点间 4-连通两个约束。

**输入结构**：
- 约 11x11 的网格，黑(0)背景。
- 灰(5)像素构成固定的墙壁结构（单像素宽的正交线段），划分出可通行区域。
- 可通行区域中有若干蓝(1)像素，形成一个不完整的图案。该图案存在潜在的左右镜像对称轴（垂直线），但当前缺少一些像素导致对称性不成立。
- 网格的上边缘和下边缘各有一个红(2)端点像素，位于可通行区域内。
- 需要在可通行区域（黑(0)像素处）添加若干蓝(1)像素，使得：(A) 所有蓝(1)像素构成的图案关于某条垂直轴左右对称；(B) 两个红(2)端点通过蓝(1)像素形成的 4-连通路径相连（红端点视为路径的起止点，路径体为蓝像素）。
- 生成约束：恰好存在唯一一种添加方案同时满足两个约束；墙壁结构保证单独满足任一约束时有多种方案，但交集唯一；端点像素不要求对称。

**规则**：
1. 识别灰(5)墙壁（不可修改、不可通行）和红(2)端点（2 个，位于网格上下边缘）。
2. 在所有可通行的黑(0)像素位置中选择一个子集，将其填为蓝(1)。
3. 填充后的蓝(1)像素集合（加上已有的蓝(1)像素）必须关于网格中唯一的垂直对称轴左右镜像对称。
4. 从上方红(2)端点出发，仅经过蓝(1)像素（4-连通），必须能到达下方红(2)端点。
5. 在所有同时满足上述两个约束的方案中，选择添加蓝(1)像素数最少的方案。（生成保证该最少方案唯一。）
6. 红(2)端点像素保留原色不变。灰(5)墙壁保留不变。

**关键洞察**：对称性和连通性是两个独立的几何约束，各自允许大量合法补全方案；但墙壁结构精心设计，使得两者的交集恰好只有一个最小方案——求解者必须同时在两个维度上推理，而非先满足一个再调整另一个。

## 新题 9：嵌套形状面积排序后按环层射线延伸填色

**组合逻辑**：[排序/嵌套层次/面积序](已有) → [射线延伸](创新：射线不在原图上延伸，而在压缩后的方环结构中从中心向外辐射) → [填充](创新：射线经过的环层被填充为该环的颜色，未经过的保持背景色)

**来源原语**：排序/sorting(eb5a1d5d), 嵌套层次/nesting_hierarchy(eb5a1d5d), 面积序映射环/area_order_to_ring(eb5a1d5d), 方环/square_ring(eb5a1d5d), 射线延伸/ray_extend(d968ffd4, b942fd60), 填充/fill(17b866bd), 标记像素/marker_pixel(17b866bd, b942fd60)

**依赖链**：嵌套形状按面积排序确定环层分配 → 标记像素在中心区域的位置和朝向决定射线方向 → 射线从中心向外穿过各环层，只有被射线穿过的环层像素才被填色，其余环层保持黑色。排序决定了哪种颜色在哪一层；射线决定了哪些层可见——两者共同决定最终输出。

将嵌套形状按面积排序映射为方环骨架，再根据中心标记像素射出的射线方向选择性填色各环层。

**输入结构**：
- 约 15x15 的黑(0)背景网格。
- 网格中有 3~5 个不同颜色的单色嵌套形状（如蓝(1)、绿(3)、黄(4)、品红(6)），从大到小嵌套排列。每层形状为不规则但有明确边界框的 4-连通区域。
- 最内层形状的中心有一个红(2)标记像素。
- 标记像素的上、下、左、右四个相邻位置中，恰好有 1~3 个方向被最内层形状像素占据，其余方向为黑(0)。被占据的方向即为射线发射方向。
- 生成约束：各嵌套形状的边界框面积互不相同；标记像素恰好在最内层中心（边界框中心取整）；射线方向至少 1 个、至多 3 个。

**规则**：
1. 检测所有非黑、非红的单色连通区域，计算各自的边界框面积（宽 x 高），按面积从大到小排序。
2. 创建输出方环网格：设有 K 个形状，输出为 (2K-1) x (2K-1) 的网格。面积最大的颜色为最外层环（第 1 圈边框像素），次大的为第 2 层环，...，最小的为中心像素。
3. 检查红(2)标记像素的 4 个正交邻居：若邻居为非黑、非红像素，则该方向为射线方向。
4. 从方环网格的中心像素出发，沿每个射线方向延伸直线直到网格边缘。
5. 只有被至少一条射线穿过的像素才保留其环层颜色；未被任何射线穿过的像素设为黑(0)。中心像素始终保留其颜色。
6. 红(2)标记像素不出现在输出中。

**关键洞察**：嵌套形状的面积排序决定了环层颜色分配，但最终可见的环层取决于标记像素邻域的占据模式——一个在输入中看似无关紧要的局部特征（标记像素的邻居方向）控制了输出中哪些环层可见，这需要同时理解全局排序和局部方向编码。

## 新题 10：沿路径移动后镜像对应更新分隔行两侧

**组合逻辑**：[沿路径移动/轨迹路径](已有) → [计数](创新：移动后的终点位置数量触发下一步) → [间隙对半分](创新：分隔行两侧的间隙按终点数量分段) → [镜像对应](创新：上半区不再简单镜像下半区，而是只在移动终点的镜像位置放置标记)

**来源原语**：沿路径移动/path_move(c9680e90), 轨迹路径/trace_path(c9680e90), 分隔行/separator_row(c9680e90), 镜像对应/mirror_match(c9680e90), 计数/counting(d0f5fe59), 间隙对半分/gap_bisect(d968ffd4), 标记像素/marker_pixel(c9680e90), 源色由反射匹配/source_by_reflect(c9680e90)

**依赖链**：下半区源像素沿轨迹移动到终点（路径移动）→ 终点数量 N 决定分隔行上下各留 N 行的"显示窗口"→ 上半区只在窗口范围内、终点的镜像位置放置标记色 → 窗口外的行全部清为背景。移动改变终点位置、终点数量改变窗口大小、窗口大小改变镜像标记的可见范围——三者链式耦合。

下半区的源像素沿各自轨迹移动到终点，终点数量决定分隔行上下可见窗口的行数，上半区仅在窗口内显示终点的镜像标记。

**输入结构**：
- 约 15x17 的网格，黑(0)背景。
- 一条完整的灰(5)横行将网格分为等高的上半区和下半区（各约 7 行）。
- 上半区在黑背景上有若干绿(3)标记像素（3~5 个），位置散布。
- 下半区有两种非黑颜色：蓝(1)源像素和红(2)轨迹像素。蓝(1)源像素的位置恰好是上半区绿(3)标记像素关于灰(5)分隔行的镜像位置。每个蓝(1)源像素通过一条红(2) 4-连通轨迹连接到一个终点位置（轨迹的另一端，不与其他轨迹连通）。
- 生成约束：各轨迹互不相交；每条轨迹恰好连接一个蓝源像素到一个唯一终点；移动后各终点所在行均在分隔行下方的前 N 行内（N = 终点数）。

**规则**：
1. 在下半区，识别蓝(1)源像素（通过将其位置镜像到上半区并匹配绿(3)标记来确认）和红(2)轨迹。
2. 对每个蓝(1)源像素，沿其连接的红(2) 4-连通轨迹找到轨迹的另一端点（度为 1 的像素），记为终点坐标。
3. 计算终点总数 N（等于源像素数）。
4. 定义显示窗口：分隔行上方 N 行（紧邻分隔行的 N 行）为上窗口，分隔行下方 N 行为下窗口。
5. 清除所有旧元素：上半区的绿(3)标记清为黑(0)，下半区的蓝(1)源和红(2)轨迹全部清为黑(0)。
6. 在下窗口中，在每个终点位置放置蓝(1)像素。
7. 将每个终点位置关于灰(5)分隔行镜像到上半区，若镜像位置落在上窗口内，则在该位置放置绿(3)像素；若落在上窗口外，则不放置。
8. 上窗口外的上半区行、下窗口外的下半区行全部保持黑(0)。灰(5)分隔行保持不变。

**关键洞察**：移动终点的数量不仅决定了下半区的内容分布，还通过控制可见窗口的大小反向约束了上半区镜像标记的可见性——如果某个终点的镜像位置恰好在窗口外（在当前 N 值下），它就不会出现在上半区。这种"数量自约束可见性"在任何源题中都不存在。
