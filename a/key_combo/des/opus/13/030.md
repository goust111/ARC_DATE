## 新题 1：奇偶决定角移方向

**组合逻辑**：[洪泛填充](已有) + [面积奇偶](已有，创新：从仅决定颜色扩展为同时决定平移方向) + [对角固定步移](已有) + [角位指示方向](已有) → 奇偶同时控制填充色与移动方向

**来源原语**：洪泛填充/空心矩形/封闭区域/面积奇偶定填充色(868de0fa)，平移/控制像素/角位指示方向/对角固定步移(470c91de)

**依赖链**：必须先检测每个空心矩形的内部面积并判断奇偶 → 奇偶结果同时决定两件事：(1) 内部填充色，(2) 整个矩形的对角平移方向（朝向或远离控制角）。删除奇偶判断则既无法确定颜色也无法确定方向；删除角位检测则不知道参考方向。

根据空心矩形内部面积的奇偶性，同时决定其内部填充颜色和整体对角平移方向。

**输入结构**：约 18x18 的黑(0)背景网格。其上分布 3~5 个互不重叠的一像素厚蓝(1)空心矩形框（内部为黑(0)，各框尺寸不同，内部面积从 2 到 15 不等）。每个矩形框恰好有一个角像素被替换为青(8)控制像素（其余三角仍为蓝(1)）。不同矩形的青角位置各异（有的在左上，有的在右下等）。各矩形之间至少间隔 2 像素，且距网格边界至少 2 像素以保证平移后不出界。生成时保证：(1) 每个矩形的四个角中恰好一个为青(8)；(2) 平移后各矩形不重叠、不出界。

**规则**：
1. 对每个蓝(1)空心矩形框，将青(8)角像素视为该矩形缺失的角——即该角的真实位置应为蓝(1)，青(8)仅标记方向。
2. 计算该矩形内部（不含边框）的面积（即内部行数乘以内部列数）。
3. 若面积为偶数：将整个矩形（含边框）向青(8)角所在的对角方向平移 1 格，并将内部填充红(2)。
4. 若面积为奇数：将整个矩形（含边框）向青(8)角的对角反方向平移 1 格（即远离青角），并将内部填充橙(7)。
5. 平移后，将青(8)像素恢复为蓝(1)，使矩形边框完整。
6. 原位置的矩形痕迹（包括青像素位置）擦除为黑(0)。

**关键洞察**：面积奇偶不仅决定填充颜色，还反转了平移方向——偶数朝向控制角移动，奇数远离控制角移动。仅看一个示例可能误判方向规则，必须对比多个不同奇偶的矩形才能归纳。

## 新题 2：源像素计数决定旋转角度

**组合逻辑**：[旋转](已有，创新：角度不再固定为 90° 而由计数决定) + [计数](已有，创新：计数对象不再是连通分量而是共享枢轴的源像素) + [距离保持不变](已有) + [重涂色](已有，创新：目标颜色由计数映射而非固定)

**来源原语**：旋转/枢轴像素/源像素/同行或同列/距离保持不变(1a244afd)，计数/连通分量(aaecdb9a)，重涂色(1bfc4729)

**依赖链**：先为每个枢轴配对其同行或同列的源像素并计数 → 计数结果同时决定旋转角度和输出颜色 → 旋转生成新位置，并涂上对应颜色。删除计数则角度和颜色均不确定；删除旋转则位置不变。

统计每个蓝枢轴关联的品红源像素数量，该数量同时决定旋转角度和输出颜色。

**输入结构**：约 15x15 的黑(0)背景网格。网格上散布若干蓝(1)枢轴像素和品红(6)源像素（均为孤立单像素）。每个品红像素与恰好一个蓝像素处于同行或同列（行列对齐关系唯一）。不同蓝枢轴关联的源像素数量不同（1 个、2 个或 3 个）。生成时保证：(1) 每个品红像素的行列对齐匹配唯一；(2) 旋转后的目标位置在网格内且不与任何蓝枢轴重合；(3) 不同源像素旋转后不落在同一位置。

**规则**：
1. 对每个蓝(1)枢轴像素，找到所有与其同行或同列的品红(6)源像素，记该枢轴的关联数为 k。
2. 擦除所有品红(6)源像素。
3. 对每个源像素，以其匹配的蓝枢轴为中心，保持距离不变，按以下角度逆时针旋转：k=1 时旋转 90°，k=2 时旋转 180°，k=3 时旋转 270°。
4. 在旋转后的位置绘制像素，颜色由 k 决定：k=1 → 红(2)，k=2 → 绿(3)，k=3 → 黄(4)。
5. 蓝(1)枢轴像素保持不变。
6. 若旋转后位置落在网格外，该源像素消失（不绘制）。

**关键洞察**：共享同一枢轴的所有源像素旋转角度和颜色相同，因为它们由枢轴的关联计数统一控制。仅看一个枢轴无法确定 k→角度/颜色的映射表，必须对比不同 k 值的枢轴才能归纳。

## 新题 3：镜像辅助周期恢复

**组合逻辑**：[镜像](已有，创新：不用于产生最终输出，而作为数据恢复的预处理) + [周期推断](已有) + [间隙填充](已有) + [忽略缺失值推断](已有)

**来源原语**：镜像/双轴对称/镜像恢复遮挡区(de493100)，间隙填充/周期推断/周期瓦片/忽略缺失值推断(1d0a4b61)

**依赖链**：输入同时具有双轴对称性和周期性，但黑色遮挡过多 → 必须先利用双轴镜像恢复部分遮挡像素（增加可见数据量）→ 恢复后的数据仍不完整（镜像轨道全被遮挡的像素无法通过镜像恢复）→ 此时再用周期推断填补剩余缺失。两种恢复策略缺一不可：仅镜像不够（有些轨道全黑），仅周期推断不够（初始可见数据太稀疏无法唯一确定瓦片）。

对一个同时具有双轴对称和周期平铺特性的网格，先通过镜像恢复部分遮挡，再通过周期推断填补剩余缺口。

**输入结构**：约 12x12 的方形网格，使用 3~4 种非黑颜色（如红(2)、绿(3)、黄(4)）。网格的底层图案同时满足两个性质：(1) 关于网格中心具有双轴（水平+垂直）对称性；(2) 由一个 3x3 或 4x4 的最小周期瓦片平铺而成。部分像素被替换为黑(0)，表示遮挡/缺失。遮挡的设计使得：(a) 某些黑像素可通过镜像轨道中的可见同伴恢复（即其水平/垂直/180°镜像位置至少有一个非黑）；(b) 另一些黑像素的整个镜像轨道全为黑，无法仅靠镜像恢复；(c) 初始可见（非黑）像素不足以唯一确定周期瓦片的所有相位，但经过镜像恢复后，补充的数据足以唯一确定瓦片。生成时保证：两种恢复策略结合后能填满所有黑像素，无残留歧义。

**规则**：
1. 对每个黑(0)像素，检查其双轴对称轨道（水平镜像、垂直镜像、180°旋转镜像共 3 个对应位置）。若轨道中存在非黑像素，将该黑像素恢复为轨道中可见的颜色。
2. 经步骤 1 后仍为黑的像素，利用周期性恢复：在步骤 1 的结果上（忽略剩余黑像素），推断最小周期瓦片。
3. 用推断出的瓦片，将每个剩余黑像素替换为其对应瓦片相位处的颜色。
4. 输出完全无黑像素的恢复网格。

**关键洞察**：镜像恢复本身是不完整的（存在全黑轨道），周期推断本身也是不充分的（初始数据太稀疏）。两种策略必须按顺序配合——镜像为周期推断提供足够的采样点，周期推断填补镜像的盲区。这种"互补恢复"关系需要对比多个示例才能意识到。

## 新题 4：路径划分内部区域的差异填充

**组合逻辑**：[连线](已有，创新：路径不再是最终输出而是中间结构，用于划分空间) + [洪泛填充](已有，创新：填充区域由路径动态划分而非由固定边框定义) + [封闭区域](已有) + [面积比较](创新：从面积奇偶扩展为面积大小比较)

**来源原语**：连线/路径/起终点之间(992798f6)，洪泛填充/空心矩形/封闭区域(868de0fa)

**依赖链**：先在每个空心矩形内部从红标记画水平线段再画垂直线段到绿标记（形成 L 形路径）→ 路径与矩形壁共同将内部分割为恰好两个 4-连通区域 → 比较两区域面积决定各区域填充色。删除路径则无分割；删除面积比较则颜色不确定。

在空心矩形内部画标记间的 L 形路径，路径将内部一分为二，面积较大的区域与较小的区域分别用不同颜色填充。

**输入结构**：约 16x16 的黑(0)背景网格。其上分布 2~4 个互不重叠的一像素厚蓝(1)空心矩形框（内部至少 4x4）。每个矩形的上边框（非角点位置）恰好有一个像素为红(2)，下边框（非角点位置）恰好有一个像素为绿(3)。红与绿不在同一列（保证 L 形路径而非直线）。生成时保证：(1) 红在上边框、绿在下边框，列位置不同；(2) L 形路径将矩形内部（不含边框和路径本身）分为恰好两个 4-连通区域，面积不相等。

**规则**：
1. 对每个矩形，从红(2)标记的正下方一格开始，向下画一条垂直黄(4)线段，直到与绿(3)标记同行。
2. 从该垂直线段的底端，向绿(3)标记的正上方一格水平画一条黄(4)线段。
3. 上述垂直+水平线段构成一条 L 形黄(4)路径。该路径与蓝(1)矩形壁共同将矩形内部分割为两个 4-连通区域（路径像素和边框像素均不属于任何区域）。
4. 计算两个区域的像素数。面积较大的区域填充灰(5)，面积较小的区域填充橙(7)。
5. 蓝(1)边框、红(2)/绿(3)标记、黄(4)路径均保持不变。

**关键洞察**：路径不是最终输出，而是空间分割工具——红绿标记的列差距决定了 L 形路径的形状，从而决定了两个区域的面积比。必须理解路径的构造算法（先垂直后水平）才能正确预测分割结果。

## 新题 5：掩码压印后按阵列坐标打孔

**组合逻辑**：[像素放大/平铺](已有) + [掩码映射](已有) + [阵列坐标编码](已有，创新：坐标编码不再来自输入而是在输出中动态生成) + [孔洞位置等于坐标](已有，创新：孔洞打在生成的瓦片副本上而非预设的瓦片中)

**来源原语**：像素放大/平铺/控制精灵/多色瓦片/掩码映射/像素展开为瓦片(bf45cf4b)，瓦片阵列/位置孔洞/阵列坐标编码/孔洞位置等于坐标(9ddd00f0)

**依赖链**：先用控制精灵的掩码将瓦片压印成放大图案 → 每个压印的瓦片副本在阵列中有一个位置坐标 → 该坐标决定在该瓦片副本内部哪个像素被挖为背景色。删除压印则无瓦片阵列；删除坐标编码则不知道在哪里打孔。

将控制精灵按掩码放大为瓦片阵列后，在每个瓦片副本中根据其阵列坐标打一个背景色孔洞。

**输入结构**：约 20x20 的黑(0)背景网格。网格上有两个互不重叠的前景对象（8-连通）：(1) 一个单色矩形精灵（如红(2)，约 3x4 到 5x5，内部可有黑(0)孔洞），作为控制掩码；(2) 一个多色正方形瓦片（尺寸 n x n，n 与控制精灵的宽/高相匹配使得 n 等于精灵的行数或列数中的较大值，不超过 5，使用 2~3 种非黑非控制色）。生成时保证：(1) 瓦片尺寸 n 不超过精灵的行数和列数（否则阵列坐标可能越界瓦片内部）；(2) 精灵的填充像素数 ≥ 2。

**规则**：
1. 识别控制精灵（单色矩形区域，含黑洞）和多色正方形瓦片。设精灵在其边界框内的行数为 R、列数为 C，瓦片尺寸为 n x n。
2. 构造输出网格，尺寸为 (R x n) 行 x (C x n) 列。
3. 对精灵边界框内的每个单元格 (r, c)（r 从 0 开始，c 从 0 开始）：若该格为精灵色（非背景），在输出中对应位置压印一份瓦片副本；若为背景色，对应位置留为 n x n 的背景色区域。
4. 对每个已压印的瓦片副本，其在阵列中的坐标为 (r, c)。将该瓦片副本内部局部坐标 (r mod n, c mod n) 处的像素替换为黑(0)背景色（打一个孔）。
5. 未压印的背景区域保持全黑(0)。

**关键洞察**：每个瓦片副本内部的孔洞位置不同——它编码了该瓦片在阵列中的位置坐标。单看一个瓦片副本可能以为孔洞是瓦片自带的，必须对比多个副本才能发现孔洞位置随阵列坐标变化。

## 新题 6：压缩到标记旁后绕枢轴旋转

**组合逻辑**：[滑动/压缩](已有，创新：压缩不是最终输出而是为旋转创造前置条件) + [擦除](已有) + [旋转](已有，创新：旋转对象不是原始位置的像素而是滑动后的中间位置像素) + [重涂色](已有)

**来源原语**：滑动/擦除/孤立像素/标记点/行列对齐/压缩到标记旁(ae3edfdc)，旋转/枢轴像素/距离保持不变/同行或同列(1a244afd)，重涂色(1bfc4729)

**依赖链**：散布的前景像素先沿行/列滑动到各自的锚点旁（压缩步骤，确定中间位置）→ 滑动后的像素与蓝枢轴建立新的空间关系 → 以最近的蓝枢轴为中心旋转 90° 逆时针，并重涂为橙(7)。删除滑动步骤则旋转的起点位置错误；删除旋转则仅完成压缩而非最终变换。

先将散布像素滑向红锚点，再以蓝枢轴为中心旋转滑动后的像素。

**输入结构**：约 15x15 的黑(0)背景网格。网格上有：(1) 若干红(2)锚点像素（孤立单像素，2~3 个）；(2) 若干蓝(1)枢轴像素（孤立单像素，2~3 个）；(3) 若干散布的前景像素（使用绿(3)或黄(4)，各为孤立单像素，共 4~6 个）。每个散布像素与恰好一个红锚点同行或同列。每个红锚点与恰好一个蓝枢轴同行或同列。生成时保证：(1) 每个散布像素到其匹配红锚点的路径上无障碍（无其他前景像素阻挡）；(2) 滑动后每个散布像素落在红锚点的相邻格（上下左右之一）；(3) 滑动后的位置与某个蓝枢轴同行或同列；(4) 以该蓝枢轴为中心旋转 90° 逆时针后的目标位置在网格内且不冲突。

**规则**：
1. 保持所有红(2)锚点和蓝(1)枢轴不动。
2. 对每个散布前景像素（绿(3)或黄(4)），找到与其同行或同列的唯一红(2)锚点。
3. 擦除该散布像素的原位置，将其移动到该红锚点的相邻一格（沿射线方向，即同行则移到锚点左侧或右侧相邻格，同列则移到锚点上方或下方相邻格）。
4. 对每个移动后的像素，找到与其同行或同列的唯一蓝(1)枢轴。
5. 以该蓝枢轴为旋转中心，将移动后的像素逆时针旋转 90°（保持到枢轴的距离不变）。
6. 在旋转后的目标位置绘制橙(7)像素。移动后的中间位置不保留（仅最终旋转结果可见）。

**关键洞察**：这是一个两步空间变换的管道——压缩确定了中间位置，中间位置决定了旋转的起点和匹配的枢轴。跳过压缩步骤会使旋转的起点错误，导致完全不同的输出。必须识别出"先滑后转"的两步结构。

## 新题 7：锯齿链覆盖决定矩形框填充

**组合逻辑**：[平铺/旋转/对角锯齿排布](已有，创新：锯齿链不是最终输出而是几何判据) + [交替旋转换色](已有) + [洪泛填充](已有，创新：填充触发条件不再是面积奇偶而是外部图案的覆盖数) + [计数](已有，创新：计数对象从连通分量变为几何重叠段数)

**来源原语**：平铺/旋转/矩形条/对角锯齿排布/交替旋转换色(fd4b2b02)，洪泛填充/空心矩形/封闭区域(868de0fa)，计数(aaecdb9a)

**依赖链**：从种子矩形条生成覆盖全画布的对角锯齿链 → 统计每个空心矩形框的边框被锯齿链覆盖的段数 → 覆盖段数决定填充颜色。删除锯齿链生成则无法计数；删除覆盖计数则填充色不确定。

生成横跨画布的锯齿链图案后，根据链条覆盖每个空心矩形框边框的段数来决定内部填充颜色。

**输入结构**：约 20x20 的黑(0)背景网格。网格上有：(1) 一个绿(3)实心非正方矩形条（如 2x4 或 3x5），作为锯齿链的种子；(2) 3~5 个一像素厚灰(5)空心矩形框（内部为黑，各框尺寸不同，互不重叠）。灰框与种子矩形条不重叠。生成时保证：(1) 种子矩形条在网格中部附近；(2) 各灰框分布在不同位置，使得锯齿链覆盖它们边框的段数各不相同（范围 0~3）。

**规则**：
1. 以绿(3)矩形条为种子，沿两条 45° 对角线方向扩展锯齿链：在对角线上每隔 (种子高+种子宽) 个格放一个种子副本（绿(3)），在相邻副本之间放一个 90° 旋转的矩形条（品红(6)）。链条延伸到画布边界，超出部分裁剪。
2. 对每个灰(5)空心矩形框，统计其边框像素中有多少个被锯齿链的某个矩形条（绿或品红）覆盖。将连续覆盖的边框像素视为一"段"，统计总段数 s。
3. 根据 s 填充矩形框内部：s=0 → 内部保持黑(0)不变；s=1 → 填充红(2)；s=2 → 填充黄(4)；s≥3 → 填充蓝(1)。
4. 锯齿链的矩形条在灰框边框上方绘制（覆盖灰像素），但灰框的整体结构（包括被覆盖的边框像素位置）仍可识别。
5. 输出中同时保留锯齿链图案和填充后的矩形框。

**关键洞察**：锯齿链是全局图案，矩形框是局部结构；填充颜色取决于全局图案与局部结构的交叉程度。不同矩形框因位置不同而有不同的覆盖段数，这种交互关系需要对比多个框才能归纳。

## 新题 8：控制像素方位选择周期恢复轴

**组合逻辑**：[方位决定槽位](已有，创新：从选择 3x3 区域内的一个格扩展为选择全局的平移恢复方向) + [填充](已有) + [周期性格/平移等价](已有，创新：不再自动选最强平移向量，而由外部信号指定) + [重涂色](已有)

**来源原语**：重涂色/定位/控制像素/相对方位/方位决定槽位(18286ef8)，填充/周期性格/平移等价/平移向量决定填充(484b58aa)

**依赖链**：品红控制像素相对于周期图案区域的方位（上/下/左/右）→ 方位选择用于恢复的平移方向（水平或垂直）→ 沿选定方向传播颜色填补黑色缺口 → 控制像素被重涂为其所在位置在恢复后图案中应有的颜色。删除控制像素则不知道用哪个方向的平移；删除周期恢复则缺口无法填补。

品红控制像素的相对方位决定使用水平还是垂直平移来恢复周期图案中的缺失像素。

**输入结构**：约 12x12 的网格。网格主体是一个占据大部分面积的矩形周期性彩色图案区域（使用红(2)、绿(3)、黄(4)等 2~3 种颜色，周期约 3~4 格），其中部分像素被替换为黑(0)表示缺失。图案同时具有水平和垂直两个方向的平移周期性，但两个方向的周期向量不同。在图案区域外部（上方、下方、左方或右方的空白区域中），恰有一个品红(6)控制像素。生成时保证：(1) 黑色缺口的分布使得仅用水平平移或仅用垂直平移均能完全恢复所有缺失像素（两个方向各自独立可解）；(2) 但两个方向恢复的结果可能不同（因为某些缺失像素的水平轨道和垂直轨道给出不同的填充色——这正是需要控制像素来消除歧义的原因）。

**规则**：
1. 识别图案区域（非黑像素构成的矩形区域）和品红(6)控制像素。
2. 判断品红像素相对于图案区域的方位：若在图案区域的上方或下方，选择垂直平移方向；若在左方或右方，选择水平平移方向。
3. 在选定的方向上，找到非零平移向量 v 使得所有非黑像素在 v 方向上的重叠对一致（无颜色冲突），且 v 的支持度最大。
4. 利用该平移向量 v 将所有黑(0)缺失像素恢复为其平移等价类中可见的颜色。
5. 将品红(6)控制像素重涂为：若其位置恰在图案区域的平移延伸上，涂为对应相位的颜色；否则涂为栗(9)。

**关键洞察**：图案沿两个方向都有周期性，但某些缺失位置在不同方向上会恢复为不同颜色——控制像素的方位打破了这个歧义，指定使用哪个方向的周期。仅看一个示例可能碰巧两个方向结果相同，必须对比多个示例（控制像素在不同方位）才能发现方位选择规则。

## 新题 9：画线分区后各区施加不同变换组合

**组合逻辑**：[连线/描边](已有，创新：画出的线不是装饰而是空间分区工具) + [镜像/翻转列序](已有) + [颜色互换](已有) + [半区分色](已有，创新：从二分扩展为三分，且每个分区对应不同的操作组合)

**来源原语**：连线/描边/孤立像素/半区分色(1bfc4729)，镜像/翻转列序(67a3c6ac)，颜色互换/双色源图案(2b01abd0)

**依赖链**：两个孤立像素确定两条水平线 → 线将网格分为三个水平带 → 每个带内的双色图案受到不同操作：上带仅镜像、下带仅色换、中带镜像+色换。操作类型由带的位置决定，不可分离——删除线划分则不知道哪里施加什么操作；删除任一操作则某些带的输出错误。

两个标记像素画出的水平线将网格分为三个水平带，每带内的双色图案分别接受不同的变换组合。

**输入结构**：约 14x14 的黑(0)背景网格。网格上分布着一个由绿(3)和黄(4)两种颜色构成的稀疏图案（若干孤立像素或小连通块，分布在网格各处）。另有两个孤立标记像素：一个红(2)像素在网格上部（约第 3~4 行），一个蓝(1)像素在网格下部（约第 10~11 行），两者不在同一行。红和蓝像素不与任何绿/黄像素同行。生成时保证：(1) 红像素行号 < 蓝像素行号；(2) 三个水平带（红线上方、红蓝之间、蓝线下方）内均有绿/黄图案像素；(3) 各带内的绿/黄像素分布使得镜像和色换后不与标记线冲突。

**规则**：
1. 通过红(2)像素所在行画一条红(2)水平线（覆盖该行全部列）。通过蓝(1)像素所在行画一条蓝(1)水平线（同理）。
2. 这两条线将网格分为三个水平带：上带（红线上方的所有行）、中带（红线与蓝线之间，不含线本身的行）、下带（蓝线下方的所有行）。
3. 对上带内的所有绿(3)/黄(4)像素：执行左右镜像（以网格垂直中轴为对称轴翻转列位置），颜色不变。
4. 对下带内的所有绿(3)/黄(4)像素：执行颜色互换（绿(3)→黄(4)，黄(4)→绿(3)），位置不变。
5. 对中带内的所有绿(3)/黄(4)像素：同时执行镜像和颜色互换（先翻转列位置，再互换颜色）。
6. 红(2)和蓝(1)水平线保持不变。黑(0)背景不变。

**关键洞察**：中带的变换是上带和下带各自变换的组合（镜像 + 色换），这一规则不能从单个示例中完全确定——必须对比多个示例中三个带的变化模式才能发现中带是两种操作的叠加。

## 新题 10：裁剪标记区域后按嵌套计数填充

**组合逻辑**：[裁剪](已有) + [背景色空洞/四角围合](已有，创新：空洞标记不再直接对应最终裁剪区域，而是标记出工作区域的边界) + [洪泛填充](已有) + [包含/嵌套](已有，创新：不再判断奇偶而是计数嵌套层数) + [计数](已有，创新：计数对象从连通分量变为嵌套包含关系的层数)

**来源原语**：裁剪/网格线/缺失交叉点/四角围合/背景色空洞(a644e277)，洪泛填充/空心矩形/封闭区域/包含(868de0fa)，计数(aaecdb9a)

**依赖链**：四个背景色空洞标记裁剪区域 → 裁剪后在子区域中识别嵌套矩形框 → 统计每个框内被包含的框的数量 → 数量映射为填充颜色。删除裁剪则工作区域不确定（网格其他位置可能有干扰元素）；删除嵌套计数则填充色不确定。

通过四个背景色空洞标记裁剪出工作区域，在其中根据矩形框的嵌套包含层数决定内部填充颜色。

**输入结构**：约 18x18 的网格，由灰(5)单像素厚的规则网格线构成（水平线和垂直线间隔 3~4 格），格子之间为黑(0)背景。恰好四个网格线交叉点处的灰(5)像素被替换为黑(0)（背景色空洞），它们构成一个轴对齐矩形的四个角。在这四个角围成的矩形区域内部（含边界网格线），有若干红(2)一像素厚空心矩形框，部分框嵌套在其他框内部。区域外部也可能有一些红(2)矩形框作为干扰。生成时保证：(1) 四个空洞恰好构成矩形四角；(2) 裁剪区域内的红框嵌套层数从 0 到 2 不等（有的框不包含任何其他框，有的包含 1 个，有的包含 2 个）；(3) 嵌套的框之间有间隔（不共享边框像素）。

**规则**：
1. 找到灰(5)网格线上四个被替换为黑(0)的交叉点，确定它们构成的矩形区域。
2. 裁剪该矩形区域（含边界行列）作为输出。
3. 在裁剪区域中，识别所有红(2)空心矩形框。
4. 对每个矩形框，计算其内部（不含自身边框）直接包含的其他红框数量 d（只计直接包含，不递归）。
5. 按从最内层到最外层的顺序填充每个框的内部空间（不覆盖已有的红框边框和已填充的内层区域）：d=0（最内层，不包含任何其他框）→ 填充绿(3)；d=1 → 填充黄(4)；d≥2 → 填充蓝(1)。
6. 灰(5)网格线和红(2)框边保持不变。区域外的内容被裁剪丢弃。

**关键洞察**：裁剪步骤排除了区域外的干扰矩形框，使得嵌套计数仅在工作区域内进行。填充颜色由嵌套层数（而非面积奇偶）决定，必须正确识别包含关系才能计数。区域外的干扰框是解题陷阱，必须对比多个示例（有的示例中区域外框不影响结果）才能确认裁剪的必要性。
