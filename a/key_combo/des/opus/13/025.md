## 新题 1：缺口射线与幸存色填充

**组合逻辑**：[射线延伸](已有) → [命中即整体擦除](已有，创新：擦除结果反馈影响其他缺口的取色) → [条缺口填充](创新：填色来源从同列分段涂色改为幸存目标对象的颜色采样)

**来源原语**：射线延伸(ray_extend) / 射线命中(ray_intersection) / 命中即整体擦除(hit_erases_whole) ← 2f767503；条缺口(bar_gap) / 按行序分段涂色(color_by_row_order) ← cf133acc；目标对象(target_object) ← 2f767503

**依赖链**：每根横条的缺口位置决定了其纵向射线路径 → 射线路径决定了哪些目标对象被擦除 → 幸存对象的集合决定了每个缺口应采样到什么颜色。不同横条的射线可能擦除同一个对象（若对象横跨多列），因此所有射线必须同时结算后才能确定幸存集合，不可逐条独立处理。

从横条缺口向下发射射线以擦除命中的目标对象，再用缺口正下方首个幸存对象的颜色回填缺口。

**输入结构**：
- 黑(0)背景，约 12x15 网格。
- 上半区：3~4 根水平单色横条（每根占一整行，颜色各不相同，取自红(2)、蓝(1)、绿(3)、黄(4)等），相邻横条之间至少隔一行背景。每根横条恰好有一个单像素缺口（该位置为背景色），不同横条的缺口列号互不相同。
- 下半区：4~6 个单色 4-连通小图形（每个 3~6 像素，形状不规则且各不相同），颜色从红(2)、绿(3)、蓝(1)、橙(7)、品红(6)中取，每个图形颜色不与所在列的任何横条颜色相同。图形之间互不接触且不与横条接触。
- 生成约束：每个缺口列下方至少存在两个图形（确保擦除后仍有幸存者可供采色）；至少有一个图形横跨两个不同缺口列（使得两条射线可能同时命中它，产生交叉依赖）。

**规则**：
1. 从每根横条的缺口位置向下发射一条单像素宽的纵向射线，射线从缺口所在行的下一行开始，延伸到网格底边。
2. 同时考虑所有射线：任何 4-连通目标图形只要有至少一个像素被任意一条射线穿过，则该图形被整体擦除（所有像素设为背景色）。
3. 所有擦除结算完毕后，对每个缺口列，从缺口行向下逐行扫描：遇到的第一个非背景像素所属的幸存图形的颜色即为该缺口的填充色。将该颜色填入缺口位置。
4. 若某缺口列下方已无任何幸存图形像素，则该缺口保持背景色不变。
5. 射线本身不在输出中显示（不改变任何像素），仅用于判定擦除。横条其余像素、未被擦除的图形均保持不变。

**关键洞察**：缺口同时扮演两个角色——既是破坏性射线的发射源，又是需要从幸存者处采色的接收端。一根横条的射线可能擦除另一根横条赖以取色的图形，因此必须全局结算擦除后才能确定任何缺口的填充色，不可逐条独立求解。

## 新题 2：闭环分区的轮换着色

**组合逻辑**：[墙壁边界 + 洪泛填充 → 内外分区](已有，创新：墙壁不再分隔面板而是形成独立闭合区域) → [环形连接 + 顺时针轮换 → 重涂色](已有，创新：轮换对象从方框内遮罩变为洪泛填充确定的不规则区域)

**来源原语**：墙壁边界(wall_boundary) / 指示像素(indicator_pixel) / 内外分区(inside_outside_partition) / 填充(flood_fill) ← 7491f3cf；环形连接(ring_connection) / 顺时针轮换(clockwise_rotation) / 重涂色(recolor) / 连接线(connector_line) ← ad173014

**依赖链**：洪泛填充从指示像素出发，被墙壁边界阻挡，确定每个闭合墙壁内的精确区域范围 → 连接线确定墙壁闭环之间的环形拓扑顺序 → 按顺时针轮换将每个区域的指示色替换为环中下一个区域的指示色。没有洪泛填充就无法确定重涂范围；没有环形连接就不知道颜色轮换顺序。

按连接线定义的顺时针环序，将每个闭合墙壁区域内的填充色替换为环中下一个区域的填充色。

**输入结构**：
- 黑(0)背景，约 12x12 网格。
- 4~5 个灰(5)像素构成的闭合墙壁环路（每个环路是 4-连通的封闭曲线，围出一个不规则区域，面积约 4~10 像素）。各环路互不接触，且均不触及网格边缘。
- 每个闭合区域内部恰好有一个单像素指示像素，颜色各不相同，取自红(2)、蓝(1)、绿(3)、黄(4)、橙(7)。
- 灰(5)线段（宽 1 像素，水平或垂直）连接相邻的墙壁环路（从一个环路的外壁像素延伸到另一个环路的外壁像素），所有连接线段恰好形成一个经过每个环路恰一次的单环（哈密顿回路）。
- 生成约束：连接线段不穿过任何其他环路内部；各环路中心按连接线段可自然确定顺时针/逆时针遍历顺序。

**规则**：
1. 对每个闭合墙壁区域，从其内部指示像素出发做 4-连通洪泛填充，填充被灰墙壁阻挡，确定该区域包含的所有内部像素集合。
2. 沿灰色连接线段追踪环形拓扑：以所有环路中心的几何重心为参考点，将环路按连接顺序排成顺时针序列 R1, R2, ..., Rk, R1。
3. 对每个区域 Ri，将其所有内部像素（指示像素及洪泛覆盖的背景像素）重涂为 R(i+1) 的指示像素颜色（Rk 的下一个是 R1）。
4. 灰色墙壁和灰色连接线段保持不变。

**关键洞察**：区域的形状由墙壁几何决定（需要洪泛填充才能精确确定），而颜色轮换顺序由外部连接线拓扑决定（需要追踪环路）。两个完全不同维度的信息——空间几何与图论拓扑——必须同时参与才能确定每个像素的输出颜色。

## 新题 3：扫描线面积排序

**组合逻辑**：[逐行扫描 + 填充轮廓间区域](已有) → [列内计数 + 按计数升序排列](已有，创新：计数对象从嵌入二值矩阵列变为扫描线填充产生的面积) → [整块移动保持内容](已有，创新：移动单元从色块条带变为含轮廓与填充的复合列带)

**来源原语**：轮廓像素(outline_pixel) / 逐行扫描(row_scan) / 填充轮廓间区域(fill_between_outlines) ← aa18de87；排序(sorting) / 列内计数(intra_column_count) / 按计数升序排列(ascending_permutation_by_count) / 嵌入二值矩阵(embedded_binary_matrix) / 网格分隔符(grid_separator) ← 85b81ff1；整块移动保持内容(block_move_intact) ← f18ec8cc

**依赖链**：对角线轮廓像素需扫描线填充才能显现其围合面积 → 填充面积是排序的唯一依据 → 排序移动整个列带（轮廓 + 填充一起移动）。跳过填充步骤则无法计算面积；跳过排序则列带位置不变。

对每个列带内的对角线轮廓做扫描线填充以显现围合面积，再按面积升序重排所有列带。

**输入结构**：
- 黑(0)背景，约 11x16 网格。
- 灰(5)垂直分隔线将网格等分为 4~5 个列带（每个列带宽 3~4 列，分隔线宽 1 列）。
- 每个列带内有一组蓝(1)像素组成的对角线笔划，形成一个闭合或近似闭合的轮廓（如 V 形、菱形、三角形等），各列带的轮廓形状不同，围合的面积各不相同。
- 轮廓像素仅出现在列带内部，不跨越分隔线。
- 生成约束：每个列带的轮廓围合面积（扫描线填充后的红色像素数）互不相同，确保排序无歧义。

**规则**：
1. 在每个列带内独立执行逐行扫描填充：对每一行，从左到右找到该行中所有蓝(1)轮廓像素，将每对相邻轮廓像素之间的背景像素填充为红(2)。
2. 统计每个列带内红(2)像素的总数，作为该列带的"面积值"。
3. 将所有列带按面积值升序（最小面积在最左）重新排列。移动时保持列带内所有像素（蓝轮廓、红填充、黑背景）完整不变。
4. 灰色分隔线保持在原始位置（列带在分隔线之间滑动交换）。

**关键洞察**：各列带的对角线轮廓在视觉上看起来相似（都是若干斜线像素），其围合面积差异并不直观。必须先执行扫描线填充将隐含面积"显影"出来，才能获得排序所需的数值量，这一中间变换是整个推理链的关键环节。

## 新题 4：字形解密连线

**组合逻辑**：[编码字形 + 字形映射颜色](已有) → [配对](创新：配对依据从空间邻接变为解码后的颜色身份) → [连线 + 同行列端点间填充](已有，创新：端点不再是裸标记像素而是整个字形块) → [重涂色](已有，创新：字形自身被重涂为其解码颜色)

**来源原语**：编码字形(code_glyph) / 字形映射颜色(glyph_maps_color) / 配对(pairing) ← ed74f2f2；连线(draw_line) / 同行列端点间填充(fill_between_aligned_endpoints) / 标记像素(marker_pixel) / 行列对齐(row_col_align) ← 253bf280；重涂色(recolor) ← ad173014

**依赖链**：字形解密确定每个字形的颜色身份 → 同色身份建立配对关系 → 配对双方的空间位置确定连线方向（同行或同列）→ 连线颜色取自解码结果。解密、配对、连线三步紧密耦合：不解密就无法配对，不配对就不知道连哪两个端点，不知道颜色身份就不知道连线该涂什么色。

解码散布在网格上的加密字形以获取其隐藏颜色身份，将同色字形配对，并用该颜色沿行或列方向连接配对端点。

**输入结构**：
- 黑(0)背景，约 12x12 网格。
- 6~8 个 3x3 的灰(5)/黑(0) 字形图案，散布在网格中，各字形之间互不接触且不重叠。每个字形的灰色像素恰好 5 个，形成以下三种编码图案之一：
  - "顶T形"（顶行三像素 + 中列下延两像素）→ 编码蓝(1)
  - "右下折线"（左上起沿中列下行两像素 + 右转沿底行右行两像素，共 5 像素）→ 编码红(2)
  - "左下折线"（右上起沿中列下行两像素 + 左转沿底行左行两像素，共 5 像素）→ 编码绿(3)
- 每种编码颜色恰好出现偶数次（2 或 4 次），形成配对。
- 编码同一颜色的字形配对中，每对恰好满足：两个字形的 3x3 边界框中心在同一行或同一列上对齐（但不同时满足两者）。同色字形多于 2 个时，配对方式唯一（每个字形恰好与一个同色字形行或列对齐）。
- 生成约束：不同配对的连线路径互不交叉；同一行或同一列上不会出现三个及以上同色字形。

**规则**：
1. 解码每个字形：根据其灰色像素图案确定编码颜色（顶T→蓝(1)，右下折线→红(2)，左下折线→绿(3)）。
2. 将编码相同颜色的字形配对。若同色字形有 4 个，按行/列对齐关系唯一确定两组配对。
3. 对每对字形，确定它们的对齐方向（同行或同列），在两个 3x3 边界框之间的间隙中（严格在两个边界框之间、沿对齐轴的中线），将所有背景像素填充为该对的编码颜色。
4. 将每个字形内的灰(5)像素重涂为其编码颜色（黑色像素保持黑色）。

**关键洞察**：字形本身是"加密的端点标记"——外观上所有字形都是灰色的 5 像素图案，看不出颜色信息。必须先破译编码规则（需对比多个示例才能归纳出完整的字形-颜色映射表），才能建立配对关系并确定连线颜色。空间对齐约束提供了验证解码正确性的辅助信号，但单独依赖对齐无法确定配对（因为不同色字形也可能碰巧对齐）。

## 新题 5：十字边界与扫描线涌现

**组合逻辑**：[实心方块 → 十字图案](已有) + [交叉点重置背景](已有) → [逐行扫描 + 填充轮廓间区域](已有，创新：扫描边界不再是独立的轮廓像素，而是十字臂段；交叉重置产生的间隙改变了扫描线奇偶性，涌现出非直觉的填充结果)

**来源原语**：实心方块(solid_block) / 十字图案(cross_pattern) / 交叉点重置背景(intersect_reset_bg) ← e9bb6954；逐行扫描(row_scan) / 轮廓像素(outline_pixel) / 填充轮廓间区域(fill_between_outlines) / 跨度(span) ← aa18de87

**依赖链**：实心方块的位置决定十字臂的全局布局 → 交叉点重置在十字臂交汇处打出间隙 → 间隙改变了扫描线穿越边界的奇偶计数 → 奇偶计数决定哪些区域被填充。关键涌现效应：两个操作（十字生成 + 交叉重置）单独都不会产生填充结果，但组合后为扫描线创造了具有间隙的边界结构，使得填充结果取决于方块的精确排列。

由实心方块生成全幅十字并在交叉点留出间隙，再对十字臂段做逐行扫描线填充，间隙处的奇偶跳变涌现出非直觉的着色区域。

**输入结构**：
- 黑(0)背景，约 13x13 网格。
- 2~3 个蓝(1)实心 3x3 方块，放置于网格内部（不贴边），各方块中心行互不相同、中心列互不相同。
- 方块之间有足够间距（中心行差和中心列差均 >= 4），确保十字臂在方块之外有足够延伸空间。
- 除方块外，网格上不含其他前景像素。
- 生成约束：方块数量为 2 或 3。当方块数为 2 时，产生 1 个交叉重置点；当方块数为 3 时，最多产生 3 个交叉重置点。

**规则**：
1. 对每个 3x3 蓝色方块，将其中心行的所有像素（横跨整个网格宽度）和中心列的所有像素（横跨整个网格高度）设为蓝(1)，形成十字。方块自身的 3x3 区域保持蓝色不变。
2. 对于每个位置 (r, c)：若 r 是某方块 A 的中心行、c 是另一个不同方块 B 的中心列，则将 (r, c) 重置为背景色黑(0)。（即不同方块的十字臂交叉处变为间隙。）
3. 在上述结果上执行逐行扫描线填充：对每一行，从左向右扫描，维护一个"内外"状态（初始为"外"）。每当遇到一个蓝(1)像素且其正下方像素也是蓝(1)（即该蓝像素属于一条垂直臂段而非水平臂段），则翻转内外状态。
4. 当状态为"内"时，将当前行中的背景像素填充为红(2)。蓝色像素无论状态如何都保持蓝色。
5. 水平臂段上的蓝色像素不触发状态翻转，仅垂直臂段的像素触发。交叉重置点（已变为背景色）不触发翻转。

**关键洞察**：交叉重置点在垂直臂段上留下单像素间隙。由于扫描线仅在遇到垂直臂段像素时翻转内外状态，间隙导致该行的翻转次数比无间隙时少一次，从而反转了该行中某些区域的填充/不填充状态。这是十字生成与交叉重置两条规则组合后涌现的效果——单独看任一规则都不会预期到这种填充反转。

## 新题 6：双墙正交掩码

**组合逻辑**：[墙壁边界 A + 洪泛填充 → 水平分区掩码](创新：墙壁不再定义单一内外，而是提供一个维度的二值掩码) ⊗ [墙壁边界 B + 洪泛填充 → 垂直分区掩码](同上) → [掩码笛卡尔积 + 指示像素 → 四态着色](创新：两个掩码的组合产生四种状态，每种映射到不同颜色)

**来源原语**：墙壁边界(wall_boundary) / 洪泛填充(flood_fill) / 内外分区(inside_outside_partition) / 指示像素(indicator_pixel) / 掩码选择源面板(mask_selects_source_panel) ← 7491f3cf；行列对应(row_column_mapping) / 纯色色板(solid_swatch) / 色板决定填色(swatch_determines_fill) ← 15660dd6

**依赖链**：这不是流水线结构，而是同时约束满足。两个墙壁各自独立定义一个二值分区（内/外），输出的每个像素由其在两个分区中的状态组合（内内 / 内外 / 外内 / 外外）决定颜色。两个墙壁和颜色映射表必须同时参与计算，无法拆分为顺序步骤。

读取两个正交的墙壁分区，将网格每个像素按其在两个分区中的内/外状态组合映射到四种颜色之一。

**输入结构**：
- 黑(0)背景，约 11x11 网格，划分为 2x2 的四个象限：
  - 左上象限（约 5x5）：灰(5)像素构成的墙壁路径 A。该路径从象限的一条边延伸到对边，将象限分为两个区域。路径是 4-连通的，宽 1 像素。
  - 右上象限（约 5x5）：灰(5)像素构成的墙壁路径 B，结构与 A 独立，同样将象限分为两个区域。
  - 左下象限（约 5x5）：包含 3 个单像素色板，分别位于不同的行，颜色各不相同，取自红(2)、蓝(1)、绿(3)、黄(4)。从上到下依次编号为色板 1、色板 2、色板 3。
  - 右下象限（约 5x5）：全部为背景色，待填充。
- 四个象限之间由 1 像素宽的灰(5)分隔线分开。
- 生成约束：左上和右上的墙壁路径各自将其象限分成恰好两个 4-连通区域（即路径将象限一分为二，而非更多）。

**规则**：
1. 在左上象限中，从该象限左上角像素出发做 4-连通洪泛填充（被灰墙壁阻挡）。可达的像素标记为 A-外，不可达的非墙壁像素标记为 A-内。
2. 在右上象限中，同样从该象限左上角像素出发做 4-连通洪泛填充。可达的像素标记为 B-外，不可达的非墙壁像素标记为 B-内。
3. 右下象限的每个像素 (r, c) 与左上象限的对应位置 (r', c')、右上象限的对应位置 (r', c'') 一一对应（通过象限内的相对坐标映射）。根据对应位置的标记组合决定填充色：
   - A-内 且 B-内 → 填充色板 1 的颜色
   - A-内 且 B-外 → 填充色板 2 的颜色
   - A-外 且 B-内 → 填充色板 3 的颜色
   - A-外 且 B-外 → 保持背景色黑(0)
4. 左上、右上、左下象限及所有分隔线保持不变。

**关键洞察**：两个墙壁分区是完全正交的独立约束——它们各自将空间二分，其笛卡尔积产生四种状态。任何单一墙壁都无法独立决定输出颜色，必须同时读取两个分区才能确定每个像素的最终状态。这是同时约束满足而非顺序流水线：改变任一墙壁的形状都会影响所有四种状态区域的边界。

## 新题 7：块阵列重排与中心解码

**组合逻辑**：[色块条带 + 排序 → 块阵列重排](创新：排序目标从条带移动变为 3x3 块在阵列中的位置交换) → [边界像素编码 + 中心重建](已有，创新：编码的正确性依赖于排序结果，排序错误则解码出错误的中心)

**来源原语**：块阵列(block_array) / 空心中心(hollow_center) / 边界像素编码(border_pixel_encoding) / 中心重建(center_reconstruct) / 对称映射(opposite_slot_mapping) ← db0c5428；排序(sort) / 色块条带(color_stripe) / 整块移动保持内容(block_move_intact) / 标记行指示顺序(marker_row_order) ← f18ec8cc

**依赖链**：周围块的排列顺序决定了哪些像素与中心空洞相邻 → 相邻像素构成中心块的边界编码 → 编码决定中心块的内容。因此必须先将块排列到正确位置（通过排序），才能读取到正确的边界编码。排序和解码通过"边界邻接"这一空间关系紧密耦合。

将 3x3 块阵列中被打乱的周围块按其主色频率排序归位，使中心空洞的边界编码恢复正确，再据此重建中心块。

**输入结构**：
- 青(8)背景，网格大小恰好容纳一个 9x9 前景区域（即网格至少 11x11，前景区域居中或偏置）。
- 9x9 前景区域是一个 3x3 的块阵列，每个块为 3x3 像素。中心块（第 2 行第 2 列）为空（全部青色背景）。
- 周围 8 个 3x3 块各有一个主色（非青色的主导颜色，如红(2)、蓝(1)、绿(3)、黄(4)、橙(7)、品红(6)、灰(5)、栗(9)），以及若干辅助像素（颜色不同于主色且不同于青色）。8 个块的主色互不相同。
- 当前的 8 个块处于被打乱的位置（不是最终正确排列）。
- 在 9x9 区域外部，有一行 8 个单像素标记，颜色与 8 个块的主色一一对应，按从左到右的顺序给出正确的排列顺序提示。
- 生成约束：8 个块的正确排列是按主色在整个 9x9 区域中出现的总频率从高到低，沿顺时针方向从左上角开始排列（左上 → 上中 → 右上 → 右中 → 右下 → 下中 → 左下 → 左中）。标记行的左到右顺序与此顺时针顺序一致。

**规则**：
1. 统计每个 3x3 块的主色在整个 9x9 区域（不含中心块位置）中的出现总次数（包括该主色在其他块中作为辅助像素出现的次数）。
2. 按出现频率从高到低排序。频率相同时，按标记行中的左右顺序决定先后。
3. 将 8 个块按排序结果依次放入顺时针位置序列：左上(0,0)、上中(0,1)、右上(0,2)、右中(1,2)、右下(2,2)、下中(2,1)、左下(2,0)、左中(1,0)。移动时保持每个块的 3x3 内部像素完整不变。
4. 所有块归位后，读取与中心空洞（位置(1,1)）相邻的 8 个像素（空洞四边和四角的像素，来自周围四个块）。这 8 个像素构成中心块的边界编码。
5. 将中心块的 3x3 格填充为：四边像素直接填入对应边缘位置，四角像素填入对应角位置，中心像素取整个 9x9 区域中出现频率最高的非青色颜色。
6. 移除外部标记行。

**关键洞察**：中心块的重建完全依赖于周围块的排列——不同的排列会使不同的像素与中心空洞相邻，导致解码出完全不同的中心内容。排序规则（按主色频率）本身需要全局统计，而频率统计又包含了块间的辅助像素交叉引用，因此不可能通过局部分析确定正确排列。

## 新题 8：连接拓扑与条件描边

**组合逻辑**：[连接线 → 环形连接判定](创新：连接线不再必然形成单一环，而是形成一般图，需判定每个节点是否属于某个环) → [连通分量 + 孔洞检测](已有) → [描边 + 内外边界分色](已有，创新：是否执行内边界描边取决于图论属性而非几何属性) → [重涂色](创新：描边颜色由环成员身份决定)

**来源原语**：连接线(connector_line) / 环形连接(ring_connection) ← ad173014；连通分量(connected_component) / 孔洞(hole) / 封闭区域(enclosed_region) / 描边(outline) / 内外边界(inner_outer_bound) / 内外边界分色(boundary_diff_color) ← d931c21c；重涂色(recolor) ← ad173014

**依赖链**：连接线建立图结构 → 图结构中的环检测决定每个对象的类别（环成员 / 非环成员）→ 类别决定描边规则（环成员做完整内外描边，非环成员仅做外描边）→ 孔洞检测只对环成员执行（非环成员即使有孔也不做内描边）。图论属性与几何属性在描边规则的选择上产生交叉约束。

按连接线构成的图结构判定每个对象的环成员身份，对环成员做完整内外描边，对非环成员仅做外描边，描边颜色由身份决定。

**输入结构**：
- 黑(0)背景，约 15x15 网格。
- 4~6 个蓝(1) 4-连通图形，形状各不相同（每个 5~12 像素，部分图形围出 1~2 个黑色孔洞，部分无孔洞）。图形之间互不接触。
- 蓝(1)线段（宽 1 像素，水平或垂直，长度 >= 2）连接部分图形对——从一个图形的边缘像素延伸到另一个图形的边缘像素。每个图形连接 1~3 条线段。
- 连接结构形成一个连通图，其中至少包含一个环（3 个或更多图形首尾相连形成回路），同时至少有一个图形不属于任何环（是图的"树枝"部分，度为 1）。
- 生成约束：线段不穿过任何图形的内部（仅连接边缘）；线段之间不交叉；环的长度 >= 3。

**规则**：
1. 将每个蓝色图形视为图的一个节点，每条蓝色连接线段视为一条边，建立图结构。
2. 检测图中的所有简单环。标记属于至少一个简单环的节点为"环成员"，其余为"非环成员"。
3. 对每个"环成员"图形：
   - 外描边：在 8-邻域中与该图形相邻的背景像素（且不与任何连接线段相邻），涂为红(2)。
   - 内描边：若该图形围出孔洞，则在 8-邻域中与该图形相邻的孔洞内背景像素，涂为绿(3)。
4. 对每个"非环成员"图形：
   - 外描边：在 8-邻域中与该图形相邻的背景像素（且不与任何连接线段相邻），涂为黄(4)。
   - 即使该图形有孔洞，也不做内描边（孔洞保持黑色）。
5. 蓝色图形像素和蓝色连接线段保持蓝(1)不变。

**关键洞察**：同样是带孔洞的蓝色图形，如果它是环的一部分就会获得绿色内描边，如果它只是树枝末端就不会——描边规则不由图形自身的几何特征（有无孔洞）单独决定，而由其在连接图中的拓扑角色共同决定。这迫使求解者同时进行图论分析（环检测）和几何分析（孔洞检测），两者缺一不可。
