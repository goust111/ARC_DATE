## 新题 1：格子拓扑压缩

**组合逻辑**：[计数](创新：从"数孔洞→原地重涂"变为"数孔洞→决定压缩色") → [压缩](创新：压缩色不取前景色而取拓扑映射色)

**来源原语**：计数(counting)·封闭区域(enclosed_region)·按孔洞数映射颜色(hole_count_to_color_mapping) ← 0a2355a6；压缩(compress)·格子结构(lattice)·行列交叉(row_column_intersection) ← 80214e03

**依赖链**：格子结构界定了"哪些孔洞属于哪个单元"的边界 → 孔洞计数为每个单元生成拓扑指标 → 拓扑指标经映射表转换为输出颜色 → 压缩步骤将每个单元折叠为单像素。删去格子解析则无法分配孔洞归属；删去孔洞计数则无法确定输出颜色；删去压缩则不知道输出尺寸。

对格子中每个单元内的形状做拓扑孔洞计数，将计数映射为颜色后压缩成一张粗粒度小图。

**输入结构**：约 20x20 网格。灰(5) 的完整行和完整列构成分隔线，将内部划分为 3 行 x 4 列共 12 个矩形单元（每个单元约 5x5）。每个单元内有一个 4-连通单色前景形状（颜色在蓝(1)、红(2)、绿(3)、黄(4) 中取值，不同单元颜色可不同），像素数在 8-18 之间，形状轮廓各不相同。部分形状是实心的（无孔洞），部分形状内部封闭了 1-3 个由黑(0) 组成的 4-连通区域（孔洞）。生成约束：同一孔洞数的单元应使用不同的形状轮廓和不同的前景色，以确保颜色和形状均为干扰项。

**规则**：
1. 解析格子：找到所有横跨网格全宽的灰(5) 行和横跨全高的灰(5) 列，这些是分隔线。分隔线之间的矩形区域即为单元。
2. 在每个单元内，找到唯一的 4-连通非黑非灰前景形状。
3. 计算该形状内部 4-连通黑(0) 封闭区域的数量（即不穿过形状像素就无法到达单元边界的黑色连通区域数，记为孔洞数）。
4. 按映射表将孔洞数转换为输出颜色：0 个孔洞 → 黑(0)，1 个 → 蓝(1)，2 个 → 红(2)，3 个 → 绿(3)。
5. 输出一个 3x4 的粗粒度网格，每个像素对应一个单元，颜色为步骤 4 的映射结果。单元在粗粒度网格中的位置保持与格子中的行列对应关系。

**关键洞察**：形状的原始颜色和具体轮廓都是干扰项——输出完全由不可见的拓扑属性（孔洞数）决定，而格子结构隐式地规定了每个孔洞的归属边界。

## 新题 2：对称筛选列排序重涂

**组合逻辑**：[对称检测 + 筛选](已有原语) → [列归属 + 列序映射颜色](创新：排序域由筛选结果动态决定) → [擦除 + 重涂色](已有原语)

**来源原语**：对称检测(symmetry_detect)·唯一非轴对称(unique_asymmetric) ← 73ccf9c2；筛选(filter)·对称性筛选目标(symmetry_filter)·忽略干扰项(ignore_distractors) ← 72ca375d；重涂色(recolor)·列归属(column_membership)·列序映射颜色(column_rank_to_color) ← 575b1a71；擦除(erase) ← 98c475bf

**依赖链**：对称检测判定每个对象是否保留 → 筛选结果改变了"被占用的列集合" → 列排名在筛选后的列集合上计算 → 排名驱动重涂色。删去对称检测则无法区分保留与丢弃；删去列排名则无法确定目标颜色；改变任一被保留对象都会影响全局列排名。

在多个散布对象中，仅保留左右对称的对象，按它们所在列的从左到右排名赋予新颜色，丢弃不对称的干扰体。

**输入结构**：约 15x15 网格。黑(0) 背景。5-7 个灰(5) 单色 4-连通对象散布在不同位置，每个对象的紧边界框在 3x3 到 5x5 之间。部分对象在其紧边界框内关于垂直轴左右对称，部分不对称。对称对象的边界框左边缘列恰好覆盖 4 个不同的列值。生成约束：至少 2 个不对称干扰对象；允许多个对称对象共享同一左边缘列（它们将获得相同颜色）。

**规则**：
1. 对每个灰(5) 4-连通对象，计算其紧边界框裁剪图。
2. 将裁剪图的前景掩码与其左右翻转比较。若相等则该对象为"对称对象"，否则为"不对称对象"。
3. 将所有不对称对象的像素设为黑(0)（擦除）。
4. 收集所有对称对象的边界框左边缘列，去重后从小到大排序，依次标记为第 1、2、3、4 名。
5. 将每个对称对象的所有像素重涂色：第 1 名 → 蓝(1)，第 2 名 → 红(2)，第 3 名 → 绿(3)，第 4 名 → 黄(4)。
6. 背景和已擦除区域保持黑(0)。

**关键洞察**：列排名的计算域不是全部对象，而是对称筛选后的幸存者——任何一个干扰体被错误保留都会引入额外的列值，从而改变所有对象的排名映射。

## 新题 3：点对称端点生成与对角连线

**组合逻辑**：[点对称补全](创新：不是复制已有图案，而是生成缺失的配对端点) → [连线](已有原语，作用于生成的端点对)

**来源原语**：点对称补全(point_symmetry)·中心标记(center_marker)·绕中心点旋转对称(center_rotational) ← e729b7be；连线(line_drawing)·端点对(endpoint_pair)·同色配对(same_color_pairing)·对角线段连接(diagonal_segment_connect) ← 1f876c06

**依赖链**：输入中每种颜色仅一个像素，无法配对 → 点对称围绕中心标记生成第二个同色像素 → 现在每色恰好两个像素，且生成约束保证它们位于 45 度对角线上 → 对角连线填充它们之间的所有格子。删去点对称则无配对端点；删去连线则只有散点无线段。

先通过绕中心标记的 180 度旋转为每个孤立色点生成对称副本，再将每对同色像素以对角线段相连。

**输入结构**：13x13 或 15x15（奇数边长）网格。黑(0) 背景。网格正中心有一个黄(4) 像素作为中心标记。在网格的左上象限（中心行以上、中心列以左的区域）内分布 2-4 个彩色像素，每种颜色仅出现一次（颜色从红(2)、蓝(1)、绿(3)、品红(6) 中选取）。其余区域（除中心标记外）全为黑(0)。生成约束：每个彩色像素 (r, c) 的放置必须满足以下条件——以中心标记 (cr, cc) 为旋转中心计算其 180 度旋转像素 (2*cr - r, 2*cc - c) 后，原像素与旋转像素之间满足 |dr| = |dc|（即位于严格 45 度对角线上）。不同颜色的对角线段不得在非中心位置相交。

**规则**：
1. 定位黄(4) 中心标记，记其坐标为 (cr, cc)。
2. 对每个非黑、非黄像素（位于 (r, c)，颜色为 C），计算其 180 度旋转位置 (2*cr - r, 2*cc - c)，并在该位置绘制颜色 C。
3. 此时每种颜色恰好出现两次。对每种颜色，两个像素位于一条严格 45 度对角线上。
4. 对每种颜色，沿连接其两个像素的对角线段，将线段上所有中间格子（含两端点）填充为该颜色。
5. 若任一对角线段经过中心标记位置，该位置保持黄(4)（中心标记优先级最高）。
6. 背景保持黑(0)。

**关键洞察**：输入中不存在可配对的端点——端点对必须通过点对称"创造"出来，而非从输入中"发现"。旋转和对角连线的耦合在于：旋转中心的位置决定了生成端点的坐标，进而决定了对角线段的方向和长度。

## 新题 4：异常象限前缀延展

**组合逻辑**：[裁剪 + 异常值选择](已有原语) → [延伸](创新：延展目标不再是整张图，而是异常值选择的结果)

**来源原语**：裁剪(crop)·象限(quadrant)·分隔十字(separator_cross)·相等比较(equality_comparison)·异常值选择(outlier_selection)·输出唯一象限(output_unique_quadrant) ← 88a62173；延伸(extend)·封闭行段(closed_row_segment)·边界包围内部(boundary_encloses_interior)·前缀图案闭合延展(prefix_pattern_closure_extension) ← 62b74c02

**依赖链**：四象限比较确定哪个是异常值 → 裁剪出异常象限 → 异常象限的行具有特定的前缀结构 → 对每行执行闭合延展。删去异常值选择则不知道处理哪个象限；删去前缀延展则输出只是原始异常象限的裁剪（退化为参考题 88a62173）。

在四象限中找出唯一不同的那个，然后对该象限的每一行按闭合前缀规则向右延展。

**输入结构**：15x15（奇数边长）网格。灰(5) 填充中间行和中间列，形成分隔十字，将网格分为四个 7x7 象限。三个象限包含完全相同的多色图案（像素级一致）。第四个象限（异常象限）图案不同：该象限中每行从左边缘开始有一段连续的非黑前缀（至少 3 像素），前缀之后全为黑(0)。每段前缀的第一个像素和最后一个像素颜色相同（称为边界色），中间像素可以是不同颜色。前缀使用的颜色从蓝(1)、红(2)、绿(3)、黄(4)、橙(7) 中选取。生成约束：三个相同象限必须像素级一致；异常象限每行的前缀长度不超过象限宽度的一半（以确保延展后不超出象限宽度）。

**规则**：
1. 移除灰(5) 分隔十字的中间行和中间列，提取四个 7x7 象限。
2. 将六对象限两两比较（逐像素）。恰好有一个象限与其余三个都不同，即异常象限。
3. 裁剪出异常象限。
4. 对该象限的每一行：
   a. 从左边缘识别连续非黑前缀，记其长度为 L，边界色为前缀第一个（也是最后一个）像素的颜色。
   b. 将前缀末尾之后、行右端之前的所有黑(0) 格子填充为边界色。
   c. 将前缀去掉第一个像素后的子序列（长度 L-1）复制到行的最后 L-1 个格子中，保持原顺序。
5. 输出变换后的 7x7 象限。

**关键洞察**：异常值选择决定了"对什么操作"，前缀延展决定了"怎么操作"——两者缺一不可。仅凭单个示例无法同时确定异常象限的位置规律和延展规则，必须对比多个示例中异常象限出现在不同角落的情况。

## 新题 5：互补匹配门控移动

**组合逻辑**：[形状匹配](创新：匹配结果不是直接输出，而是确定移动目的地) + [移动](创新：路径上增加门控标记) + [填充](已有原语)

**来源原语**：形状匹配(shape_match)·互补形状(complementary_shape)·缺口形状唯一配对(unique_complement)·模板缺口(template_gap) ← 18447a8d；移动(move)·障碍段(barrier_segment)·障碍门处标记通道(barrier_gate_mark)·同轴对齐的矩形对(coaxial_rect_pair) ← fc10701f；填充(fill) ← 62b74c02

**依赖链**：形状匹配确定每个源形状的目的地模板（非位置邻近决定） → 移动操作沿水平路径将源形状推送到匹配的模板缺口 → 路径上的障碍门决定哪些位置被标记为栗(9) → 源形状填入模板缺口。删去形状匹配则不知道目的地；删去移动和门控标记则缺少路径信息；删去填充则模板不完整。

将右侧的彩色小形状通过带障碍门的水平通道移入左侧模板中轮廓匹配的缺口。

**输入结构**：约 20x20 网格。黑(0) 背景。一条绿(3) 竖线（单像素宽的完整列）将网格分为左右两半。左半区：3 个单色实心矩形模板（颜色分别为红(2)、蓝(1)、黄(4)），每个矩形约 5x5 到 7x7，内部各有一个由黑(0) 像素构成的连通缺口（缺口形状为 2-4 像素的 4-连通区域，三个缺口的归一化形状互不相同）。三个模板在垂直方向上不重叠，之间有至少 2 行黑(0) 间距。右半区：3 个小彩色形状（颜色分别为橙(7)、灰(5)、品红(6)），每个形状为 2-4 像素的 4-连通区域。在绿(3) 竖线与每个右侧形状之间，散布若干水平黑(0) 障碍段（每段至少 2 像素长，垂直于水平移动方向，位于移动通道的上下两侧）。生成约束：每个右侧源形状的归一化轮廓恰好与左侧某个模板缺口的归一化轮廓相同，且配对关系一一对应。

**规则**：
1. 在左半区，对每个模板矩形提取其缺口形状（矩形内部黑(0) 连通像素集合，归一化为相对坐标）。
2. 在右半区，提取每个源形状（归一化为相对坐标）。
3. 将每个源形状与唯一轮廓相同的模板缺口配对。
4. 对每个配对：
   a. 擦除源形状原始位置（设为黑(0)）。
   b. 将源形状的像素填入配对模板的缺口位置，颜色使用源形状的原色。
   c. 沿源形状原始位置到配对模板之间的水平通道（源形状所在行范围内），逐列检查：若该列的通道行范围紧邻上方和下方都存在黑(0) 障碍像素（即障碍段从两侧夹住通道形成"门"），则将该列通道内的格子涂为栗(9)。仅从一侧伸出的障碍段不算门，忽略。
5. 绿(3) 分隔列保持不变。

**关键洞察**：移动的目的地不由空间邻近性决定，而由形状互补匹配唯一确定——交换任意两个源形状的目的地会导致缺口形状不匹配。门控标记则揭示了移动路径上的结构信息，是匹配和移动都不会产生的第三层输出。

## 新题 6：孔洞双用——列排序与重涂色

**组合逻辑**：[计数](已有原语) → 分叉：{[列排序](创新：排序指标为列内孔洞总数) + [重涂色](创新：重涂色指标为单元格孔洞数)}

**来源原语**：列排序(column_sorting)·宏单元(macro_cell)·按填充数降序(desc_filled_count) ← 42a15761；计数(counting)·连通分量(connected_component)·封闭区域(enclosed_region)·按孔洞数映射颜色(hole_count_to_color_mapping)·重涂色(recolor) ← 0a2355a6

**依赖链**：孔洞计数在每个宏单元上执行 → 同一计数结果被两条路径使用：路径 A 对每列求孔洞总和并以此排序整列；路径 B 按每个单元格的个体孔洞数重涂色。两条路径共享同一分析结果但作用于不同粒度（列聚合 vs. 单元格个体），删去孔洞计数则两条路径都失效。

在宏网格中数每个单元形状的孔洞数，按各列孔洞总和降序排列整列，然后按各单元个体孔洞数重新着色。

**输入结构**：约 17x23 网格。青(8) 形状排列在宏网格布局中：3 行 x 4 列的 5x5 单元区域，单元之间由单像素宽的黑(0) 沟槽行和沟槽列分隔。每个 5x5 单元内包含一个 4-连通青(8) 形状（像素数 10-20），形状可能封闭 0-3 个黑(0) 4-连通孔洞。不同单元的形状轮廓各不相同。生成约束：四个宏列的孔洞总和两两不同（避免排序歧义）。每个单元的形状至少 10 像素以容纳孔洞。

**规则**：
1. 解析宏网格：识别由黑(0) 沟槽分隔的 5x5 单元区域，确定 3 行 x 4 列的宏布局。
2. 对每个单元，计算其青(8) 形状内部 4-连通黑(0) 封闭区域的数量（孔洞数 h）。
3. 对每个宏列，计算该列所有单元孔洞数的总和 H。
4. 将整个宏列（包含其右侧的沟槽列，最右列除外）按 H 降序重新排列。若 H 相同（生成时已避免），以原始从左到右顺序为先。
5. 排列完成后，对每个单元的青(8) 形状按其个体孔洞数 h 重涂色：h=0 → 灰(5)，h=1 → 蓝(1)，h=2 → 红(2)，h=3 → 绿(3)。
6. 沟槽行和沟槽列保持黑(0)。

**关键洞察**：同一拓扑属性（孔洞数）在两个不同粒度上被使用——列级聚合驱动空间重排，单元级个值驱动颜色映射。这是一个扇出结构：单一分析产生两条互不可替代的变换路径。

## 新题 7：对称筛选条棒拼框

**组合逻辑**：[对称检测 + 筛选](创新：对称性决定谁参与拼装而非谁被输出) → [计数 → 像素数定尺寸](已有原语) → [平移拼接](已有原语)

**来源原语**：对称检测(symmetry_detect)·筛选(filter)·对称性筛选目标(symmetry_filter)·忽略干扰项(ignore_distractors) ← 72ca375d, 73ccf9c2；平移拼接(translate_assemble)·线段条(bar_sprite)·矩形边框(rectangular_frame)·拼合覆盖(assembly_coverage)·像素数定尺寸(pixel_count_determines_size) ← 83b6b474

**依赖链**：对称检测筛选出合格的条棒（丢弃不对称的干扰体） → 合格条棒的总像素数决定目标矩形边框的周长 → 由周长反推最平衡的矩形尺寸 → 条棒通过平移精确铺满边框。删去筛选则干扰体的像素被错误计入，导致周长和尺寸都错；删去拼接则无边框输出。

先用对称性过滤掉干扰体，再将幸存的条棒按总像素数计算矩形框尺寸，最后平移拼装成恰好铺满的矩形边框。

**输入结构**：约 15x15 网格。黑(0) 背景。6-8 个单色 4-连通前景对象，颜色从蓝(1)、红(2)、绿(3)、橙(7) 中选取（不同对象颜色可不同）。对象分两类：(A) 直条棒——宽 1 像素的水平或垂直线段，长度 2-7 像素，这些对象天然具备镜像对称性（垂直条棒关于垂直轴对称，水平条棒关于水平轴对称）；(B) 不规则形体——宽和高均大于 1 的 4-连通形状，像素数 3-6，不具备任何轴对称性。生成约束：所有类型 A 对象的像素总数等于 2*(W+H)，其中 W >= 3，H >= 3，W 和 H 的差值在所有可行尺寸中最小（最平衡）。类型 A 对象的形状和颜色组合必须恰好能通过平移（不旋转）铺满 W x H 矩形边框（单像素厚）。

**规则**：
1. 对每个前景对象，计算其紧边界框裁剪图，检测是否关于垂直轴或水平轴镜像对称。
2. 丢弃所有不对称对象（设为黑(0)）。幸存对象均为直条棒。
3. 计算所有幸存条棒的像素总和 P。P 即为目标矩形边框的周长。
4. 找到满足 2*(W+H) = P 的所有整数对 (W, H)（W >= 3, H >= 3），从中选择 |W - H| 最小的一对。若有多对 |W - H| 相同，取 W <= H 的那对。
5. 将所有幸存条棒通过平移（不旋转、不翻转）放置到 W x H 矩形边框的边界像素上，使得每根条棒覆盖边框的一段连续边缘，所有条棒恰好无重叠无遗漏地铺满整个边框。
6. 边框内部填充黑(0)。输出拼装后的矩形边框网格（尺寸为 W x H）。

**关键洞察**：对称性在这里不是选择"哪个对象是答案"，而是选择"哪些对象是建材"——干扰体的像素数被排除后，总像素数才能正确指向目标边框尺寸。任何一个干扰体被误判为条棒，周长就会改变，导致整个拼装方案失效。

## 新题 8：镜像条件字形重建

**组合逻辑**：[补全](已有原语) + [镜像](创新：是否镜像由标记行的全局对称分布决定) + [擦除](已有原语)

**来源原语**：补全(reconstruct)·边框竖条(frame_bar)·字形模板(glyph_template)·端点标记(endpoint_marker)·颜色对应形状(color_to_shape)·锚点定位(anchor_position) ← 98c475bf；镜像(mirror)·镜像轴(mirror_axis)·对称否决定输出色(symmetric_vs_asym_color) ← 44f52bb0；擦除(erase) ← 98c475bf

**依赖链**：学习模板形状 → 擦除模板 → 分析所有标记对的行位置分布是否关于水平中线对称 → 对称位置的标记对重建正常字形，不对称位置的标记对重建水平翻转字形。删去模板学习则不知道画什么形状；删去镜像条件判断则所有字形方向相同（退化为参考题 98c475bf）；删去擦除则模板和重建字形重叠。

学习模板字形后擦除它，在每个标记行重建字形——若该行位置在标记群中有水平中线对称伙伴则正常绘制，否则水平翻转后绘制。

**输入结构**：20x20 网格。蓝(1) 填充第 0 列和第 19 列，形成两根满高边框竖条。内部区域（第 1-18 列）背景为黑(0)。内部有一个完整的红(2) 字形模板，占据连续 3-5 行、宽度 4-8 列的区域，形状关于水平轴不对称（即左右翻转后与原图不同）。另有若干端点标记对：每对由同色两个像素组成（颜色从绿(3)、黄(4)、橙(7)、品红(6)、灰(5) 中选取），同一行、分别位于第 1 列和第 18 列。不同对使用不同颜色。内部区域共有偶数个有效内容行（不计边框），存在一条清晰的水平中线。生成约束：至少一种标记颜色的行位置关于水平中线有同色对称伙伴（即同色另一对在中线对面的镜像行），至少一种标记颜色无对称伙伴。所有字形（正常和翻转）在各自锚定行重建后不会在垂直方向重叠。

**规则**：
1. 识别红(2) 字形模板：记录其所有像素相对于模板最上行的相对位置（即模板的形状）。
2. 将红(2) 字形的所有像素设为黑(0)（擦除）。
3. 确定内部区域的水平中线位置（内部行范围的中点）。
4. 收集所有端点标记对（同色、同行、分别在第 1 列和第 18 列的像素对），记录每对的行号和颜色。
5. 对每个标记对，检查是否存在同色的另一对标记对位于关于水平中线的镜像行。
   - 若存在对称伙伴：在该标记对的行位置以正常方向重建字形模板，使用该标记对的颜色。字形的水平锚点为模板在内部区域的原始列偏移。
   - 若不存在对称伙伴：在该标记对的行位置重建字形模板的水平翻转版本（左右镜像），使用该标记对的颜色。水平锚点取翻转后的对应列偏移。
6. 端点标记像素本身被字形重建覆盖（若字形覆盖到第 1 或第 18 列）；若未被覆盖则保留。
7. 边框竖条保持蓝(1)。

**关键洞察**：每个字形的朝向不是由该标记对自身决定的，而是由它在全局标记分布中是否有对称伙伴决定的——这是一个全局属性对局部变换的控制关系。仅看单个示例中某一对标记，无法判断它是否有伙伴（因为不知道中线位置和其他标记分布），必须对比多个示例才能归纳出对称性判据。
