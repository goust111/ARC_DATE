## 新题 1：印章轨迹生成 Voronoi 种子的奇偶填色

**组合逻辑**：[印章覆盖](创新：印章副本的中心像素被提取为种子) → [最近归属](已有原语) → [奇偶距离决定填色](创新：Chebyshev 距离奇偶作用于 Voronoi 区域内而非角落)

**来源原语**：印章覆盖/重叠停止/颜色匹配/中心像素(985ae207), 最近归属/奇偶距离决定填色(d22278a0)

**依赖链**：印章覆盖的路径长度决定种子点的空间分布 → 种子分布决定 Voronoi 分区的形状 → 分区内每个像素到其种子的 Chebyshev 距离奇偶决定是否着色。删除印章步骤则种子位置未知；删除 Voronoi 则不知像素归属；删除奇偶规则则不知哪些像素着色。

印章覆盖在路径上产生的副本中心点成为 Voronoi 分区的种子，每个分区内按 Chebyshev 奇偶距离选择性填色。

**输入结构**：约 18x18 的黑(0)背景网格。包含 2-3 个 3x3 精灵体，每个精灵体的 8 个边框像素为同一颜色（如蓝(1)或绿(3)），中心像素为另一颜色（如红(2)或黄(4)）；每种中心颜色在精灵体之外有且仅有一个同色的单像素目标点。精灵体与目标点在同一行或同一列上（保证存在唯一的基数方向路径）。不同精灵体的目标点颜色互不相同。精灵体之间、精灵体与目标点之间的距离至少为 6 像素（保证至少能放下一个印章副本）。生成约束：所有精灵体的印章路径互不交叉。

**规则**：
1. 将每个精灵体与颜色相同的目标点配对（精灵体中心像素颜色 = 目标点颜色）。
2. 从每个精灵体出发，沿朝向其目标点的唯一基数方向（上/下/左/右），每步移动 3 像素，复制整个 3x3 精灵体。持续复制直到某个副本的 3x3 边界框与目标点所在像素重叠为止（含该次副本）。每个副本绘制在网格上，后绘制的像素覆盖先绘制的。
3. 收集所有精灵体（含原始位置和所有副本）的中心像素坐标，将其作为"种子点"集合。每个种子点继承其所属精灵体的中心像素颜色。
4. 对网格上每个像素，计算该像素到每个种子点的欧氏距离平方。将该像素归属于距离最小的种子点；若存在到两个或多个种子的距离相等，则该像素保持黑(0)背景。
5. 对于有唯一归属的像素：计算该像素到其归属种子的 Chebyshev 距离（max(|dr|, |dc|)）。若该距离为偶数（含 0），则将该像素涂为归属种子的颜色；若为奇数，则保持黑(0)。
6. 所有精灵体副本的非中心像素（边框像素）保持原色不变，不被步骤 4-5 覆盖。目标点像素保持原色不变。

**关键洞察**：Voronoi 分区的种子不在输入中直接给出——它们是印章覆盖过程的副产品。求解者必须先模拟印章路径推断种子位置，才能确定分区几何形状和填色模式。不同精灵体到目标点的距离不同导致种子数量不同，进而产生不对称的 Voronoi 分区。

## 新题 2：对角射线划分区域后按标记计数条件填色

**组合逻辑**：[射线延伸/对角线激活](创新：射线构成分隔结构而非装饰) → [区域可达性](创新：对射线划分的区域做拓扑分析) → [计数](创新：统计封闭区域内标记像素数以决定是否填色) + [最近归属](创新：由标记到区域的最短距离决定填色颜色)

**来源原语**：射线延伸/对角线激活(d07ae81c, 140c817e), 区域可达性(543a7ed5), 洪泛填充(543a7ed5), 计数/内部标记计数(54db823b, 2c0b0aff), 最近归属(d22278a0)

**依赖链**：对角射线的位置决定区域划分 → 可达性分析区分封闭/开放区域 → 封闭区域内标记计数决定是否填色 → 最近标记决定填色颜色。四个步骤形成扇形依赖：射线同时影响区域几何和边界归属，计数和归属共同决定最终输出。

从标记像素发出的对角射线将网格划分为区域；封闭且含有灰色标签像素的区域被填上距其最近的标记颜色。

**输入结构**：约 13x13 的黑(0)背景网格。3-4 个有色标记像素，颜色各不相同，从红(2)、蓝(1)、绿(3)、黄(4)中选取。另外散布 4-8 个灰(5)标签像素。标记像素之间相距至少 3 像素。生成约束：标记位置保证至少存在 2 个封闭区域（即不与网格边界连通的背景连通域），且至少有 1 个封闭区域包含灰标签像素、至少有 1 个不包含。

**规则**：
1. 从每个有色标记像素出发，沿 NW-SE 和 NE-SW 两条对角方向延伸射线直至网格边缘。射线像素涂为该标记的颜色。若两条不同标记的射线交于同一像素，该像素取距离该交叉点更近的标记的颜色（欧氏距离）；若距离相等，取在行优先扫描序（先比较行号、再比较列号）中靠前的标记的颜色。
2. 射线绘制完毕后，将所有非黑(0)像素视为"墙壁"。对黑(0)像素做 4-连通洪泛填充检测：与网格边界相连的黑色连通域标记为"开放区域"；不与边界相连的标记为"封闭区域"。
3. 对每个封闭区域，统计其中灰(5)标签像素的数量。
4. 若灰标签数为 0，该封闭区域保持黑(0)不变。
5. 若灰标签数 >= 1，找到距该区域最近的标记像素——具体方法：计算区域内每个像素到每个标记像素的欧氏距离，取全局最小值对应的标记——将该区域所有黑(0)像素填为该标记的颜色。灰(5)标签像素保持灰色不变。
6. 开放区域保持黑(0)不变。所有标记像素和射线像素保持不变。

**关键洞察**：封闭区域的填色颜色不由区域内部的任何像素决定，而由区域边界外部的标记位置决定——求解者必须从边界结构反推归属。同时，灰标签像素是填色的"开关"，但不决定颜色——颜色由空间距离决定，两个判据完全独立又共同约束输出。

## 新题 3：按拓扑孔洞数排序重排并条件装饰

**组合逻辑**：[连通检测 + 区域可达性](创新：检测孔洞而非简单连通体) → [计数](创新：以拓扑属性而非面积/颜色作为排序键) → [排序/压缩重排](已有原语) → [洪泛填充 + 描边](创新：填孔颜色由排序后位序的奇偶决定)

**来源原语**：连通检测(2c0b0aff), 区域可达性(543a7ed5), 计数(2c0b0aff, 54db823b), 排序/压缩重排/面积递增排列(8abad3cf), 洪泛填充/孔洞填色轮廓描色(543a7ed5), 描边(543a7ed5, 928ad970)

**依赖链**：孔洞检测结果同时服务于两个下游：(a) 孔洞数量决定排序顺序，(b) 孔洞身份决定哪些区域需要填色。排序后位序的奇偶又反过来决定孔洞的填色颜色。这是一个分叉-汇合结构，非纯线性流水线。

检测每个前景对象封闭的孔洞数量，按孔洞数升序重排对象，奇数位对象的孔洞填绿色、偶数位填黄色，全部对象加灰色外轮廓。

**输入结构**：约 20x10 的黑(0)背景网格。3-4 个单色前景对象（每个颜色不同，从红(2)、蓝(1)、品红(6)、橙(7)中选取），每个对象为一个 4-连通的单色连通体，像素数在 10-25 之间，形状不规则（非简单矩形），可能封闭 0-3 个黑色孔洞（孔洞 = 被该对象完全包围的 4-连通背景区域）。不同对象之间至少间隔 1 列背景像素。不同对象的孔洞数保证互不相同。每个对象的边界框高度不超过 8、宽度不超过 7。

**规则**：
1. 识别所有 4-连通前景对象（每个对象由同一颜色的连通像素组成）。
2. 对每个对象，在其边界框内做 4-连通背景区域检测：从边界框外部边缘开始洪泛，无法到达的背景连通域即为孔洞。统计每个对象的孔洞数。
3. 按孔洞数从少到多排序全部对象（孔洞数保证互不相同，无需 tie-break）。
4. 裁剪每个对象的最小边界框，按排序顺序从左到右放置，底部对齐，相邻对象之间留 1 列黑(0)背景。输出网格高度 = 最高对象的边界框高度 + 2（上下各留 1 行给轮廓），宽度 = 所有边界框宽度之和 + 间隔列数 + 左右各 1 列给轮廓。
5. 从左到右，排序后第 1、3、... 位（位序从 1 开始，奇数位）的对象：将其封闭孔洞填充绿(3)。排序后第 2、4、... 位（偶数位）的对象：将其封闭孔洞填充黄(4)。没有孔洞的对象不受此步骤影响。
6. 对每个对象（含已填充的孔洞），在其外围 8-邻接的背景像素上绘制 1 像素宽的灰(5)轮廓线。轮廓仅画在背景像素上，不覆盖任何前景像素或已填色的孔洞像素。

**关键洞察**：孔洞数量既是排序的键又是装饰的对象——求解者必须先完成拓扑分析才能确定对象的位置，而位置反过来决定孔洞的填充颜色。仅看单个示例可能无法区分"孔洞数决定位序"和"原始左右顺序决定位序"，必须对比多个示例才能归纳出排序规则。

## 新题 4：镜像平铺涌现封闭区域的检测与分类

**组合逻辑**：[擦除](创新：去除噪声改变瓦片边缘结构) → [平铺/镜像/奇偶位交替翻转](已有原语，创新：从 1x5 扩展为 3x3 二维平铺) → [区域可达性 + 洪泛填充](创新：作用于平铺后的涌现结构) + [描边](创新：仅标记外部轮廓)

**来源原语**：擦除/噪声像素(91714a58), 平铺/镜像/奇偶位交替翻转/瓦片(bc4146bd), 区域可达性/孔洞填色轮廓描色(543a7ed5), 描边(543a7ed5)

**依赖链**：噪声擦除改变瓦片边缘像素 → 边缘像素决定相邻瓦片拼接处是否形成连续前景 → 连续前景决定哪些背景区域被封闭 → 封闭区域被填色。噪声像素的存在/缺失可以打开或关闭一个封闭区域，使擦除步骤不可跳过。

去除噪声后将瓦片做 3x3 镜像平铺，平铺后在相邻瓦片边界处涌现出的封闭背景区域被填色，外部接触前景的背景像素被描边。

**输入结构**：一个 5x5 的小网格作为瓦片。背景为黑(0)，前景使用红(2)，像素数在 8-14 之间，形成一个 4-连通的图形，至少有 2 个像素位于瓦片边缘（第 0 行/第 4 行/第 0 列/第 4 列）。另有 1-2 个灰(5)噪声像素，位于瓦片边缘，与红色前景 4-邻接。生成约束：去除灰(5)像素后，将瓦片做 3x3 镜像平铺（见规则）时，至少产生 1 个封闭背景区域；若保留灰(5)像素则封闭区域的数量或形状不同（保证噪声擦除步骤有实质影响）。

**规则**：
1. 将瓦片中所有灰(5)像素设为黑(0)（擦除噪声）。
2. 将清理后的 5x5 瓦片平铺为 3x3 的网格（输出尺寸 15x15）。平铺规则：位于 (r, c) 位置的瓦片（r, c 从 0 开始）——若 c 为奇数则左右镜像，若 r 为奇数则上下镜像，若 r 和 c 都为奇数则先左右再上下镜像（等价于 180 度旋转）。r 和 c 都为偶数时使用原始方向。
3. 在 15x15 的平铺结果上，对黑(0)背景像素做 4-连通洪泛填充检测。从网格四周边缘开始洪泛，可达的背景区域为"开放区域"，不可达的为"封闭区域"。
4. 将所有封闭区域的像素填充为绿(3)。
5. 对所有开放区域中 8-邻接前景（红(2)或绿(3)）的背景像素，涂为蓝(1)（外部轮廓描边）。
6. 红(2)前景像素保持不变。

**关键洞察**：封闭区域不存在于任何单个瓦片内——它们只在镜像翻转的相邻瓦片拼接处涌现。噪声像素位于瓦片边缘，去除后改变拼接处的连通性，从而改变封闭区域的存在与否。求解者必须先理解噪声对拼接连通性的影响，再预测涌现的封闭区域。

## 新题 5：选择器色块旋转角度由面积排名决定

**组合逻辑**：[颜色索引匹配 + 图例位置映射](已有原语) + [面积排名](创新：排名结果编码为旋转角度) → [旋转](创新：旋转角度不固定，由跨对象比较决定) → [复制放置](已有原语)

**来源原语**：复制放置/选择器块/象限/颜色索引匹配/图例位置映射(7d18a6fb), 旋转/拼接(ed98d772), 面积排名/裁剪/前景最多者选出(a87f7484)

**依赖链**：这是一个并行-汇合结构。两条独立信息流（颜色匹配→放置位置；面积排名→旋转角度）汇合于最终放置步骤。颜色匹配告诉"放在哪个象限"，面积排名告诉"旋转多少度"，缺少任一条信息流都无法得到正确输出。

将每个精灵体按颜色匹配放入选择器块的对应象限，但放入前需根据该精灵体在所有精灵体中的前景像素数排名决定顺时针旋转角度。

**输入结构**：约 17x17 的黑(0)背景网格。一个 7x7 的选择器块，主体填充灰(5)，在其四个 3x3 象限的中心位置各有一个不同颜色的标记像素（从红(2)、蓝(1)、绿(3)、黄(4)中选取 4 种）。选择器块之外有 4 个精灵体，每个精灵体的边界框为 3x3，使用单一前景颜色（与 4 个标记颜色一一对应）画在黑(0)背景上；4 个精灵体的前景像素数互不相同（范围 3-8 像素，保证排名唯一）。精灵体之间和精灵体与选择器块之间互不接触，至少间隔 1 像素。

**规则**：
1. 将每个精灵体与选择器块中同色标记配对（精灵体颜色 = 标记像素颜色）。
2. 统计每个精灵体边界框内的前景（非黑）像素数。按像素数从少到多排序，得到排名 1（最少）到排名 4（最多）。像素数保证互不相同，无需 tie-break。
3. 根据排名确定顺时针旋转角度：排名 1 → 0 度（不旋转），排名 2 → 90 度，排名 3 → 180 度，排名 4 → 270 度。
4. 对每个精灵体，裁剪其 3x3 边界框内容，按步骤 3 的角度顺时针旋转。
5. 构建 7x7 输出网格，背景为黑(0)。将其分为四个 3x3 象限：左上(行0-2, 列0-2)、右上(行0-2, 列4-6)、左下(行4-6, 列0-2)、右下(行4-6, 列4-6)，中间行(行3)和中间列(列3)保持黑(0)。
6. 将每个旋转后的精灵体放入其配对标记所在的象限。输出仅包含该 7x7 网格。

**关键洞察**：单个精灵体的旋转角度不取决于它自身的任何性质，而取决于它与其他所有精灵体的像素数比较结果。改变任意一个精灵体的形状都可能改变所有精灵体的排名，从而改变所有旋转角度——这是一个全局耦合。仅看一个示例，若恰好排名与位置顺序一致，可能误以为旋转由象限位置决定，必须对比多个示例才能归纳出排名规则。

## 新题 6：拼图填孔构建墙壁后做扫描线填充

**组合逻辑**：[形状嵌合/互补拼合](已有原语) → [重涂色](创新：拼入件变色后成为墙壁结构的一部分) → [墙壁界定范围/标记列为参考](创新：墙壁由拼图完成后的完整形状提供，而非预设) → [填充](已有原语)

**来源原语**：形状嵌合/互补拼合/精灵体/孔洞/拼块填孔洞后变色(6a1e5592), 重涂色(6a1e5592), 墙壁像素/墙壁界定范围/扫描线区间/单点标记/标记列为参考(78e78cff), 填充(78e78cff)

**依赖链**：拼图完成度决定墙壁完整性 → 墙壁完整性决定扫描线区间的左右端点 → 端点决定填色范围。若拼图未正确完成，墙壁有缺口，扫描线区间错误。这是一条严格的因果链，且拼图步骤的几何精确性直接传导到填色步骤的空间范围。

将灰色拼图块嵌入红色形状的孔洞中使其完整，完成后的形状作为墙壁约束扫描线填充，以蓝色标记的列为参考线填充黄色。

**输入结构**：约 15x15 的黑(0)背景网格。一个红(2)形状，约 40-60 像素，形成一个大致纵向的不规则图形（上下跨度大于左右跨度），内部有 2-3 个黑色孔洞（每个孔洞为 3-8 像素的 4-连通背景区域，被红色像素完全包围）。在红色形状之外，有 2-3 个灰(5)拼图块，每个为 4-连通的小图形（3-8 像素），形状恰好与一个孔洞互补（旋转 0 度即可精确填入）。一个蓝(1)单像素标记，位于红色形状的左侧或右侧（不在红色形状的边界框列范围内）。生成约束：每个孔洞有且仅有一个匹配的拼图块；拼图块的像素数和形状与对应孔洞完全互补；蓝色标记的列坐标使得在完成拼图后的某些行上，该列落在形状的左右墙壁之间。

**规则**：
1. 裁剪每个灰(5)拼图块的最小边界框。
2. 将每个拼图块平移到红(2)形状的孔洞中，使其恰好填满一个孔洞（拼图块像素覆盖孔洞的所有黑色像素，且不与红色像素重叠）。匹配规则：拼图块与孔洞的形状完全互补（像素一一对应），按边界框左上角从上到下的顺序依次匹配孔洞和拼图块。
3. 将已放置的拼图块像素从灰(5)重涂为橙(7)。原始位置的灰像素清除为黑(0)。
4. 现在红(2)+橙(7)组成一个完整的无孔形状。将所有红(2)和橙(7)像素视为"墙壁像素"。
5. 以蓝(1)标记的列坐标为参考列。对网格中每一行：若该行包含墙壁像素，找到参考列左侧最近的墙壁像素（列坐标 < 参考列且最大）和参考列右侧最近的墙壁像素（列坐标 >= 参考列且最小），将这两个墙壁像素之间（不含端点）的所有非墙壁像素涂为黄(4)。若参考列左侧无墙壁像素或右侧无墙壁像素，该行不填充。若该行无墙壁像素，该行不填充。
6. 蓝(1)标记像素保持不变。墙壁像素保持不变。

**关键洞察**：扫描线填充的墙壁边界不是直接给定的——它们是拼图完成后才出现的完整轮廓。拼图块的形状决定了哪些行的哪些位置有墙壁，进而决定了填色的精确范围。求解者必须先在心中完成拼图，才能推理出填色区域。

## 新题 7：按嵌套深度选择性擦除矩形框并向幽灵边界生长

**组合逻辑**：[深度排序](创新：嵌套深度而非同心层深度) → [擦除](创新：按深度奇偶条件选择性擦除) → [生长](创新：向被擦除框的原始边界生长，边界不可见但约束生长) + [面积比较](创新：碰撞解决由面积决定)

**来源原语**：描边/空心矩形(928ad970), 深度排序(85c4e7cd), 擦除(54db823b, 91714a58), 生长/同心方框层(5c2c9af4), 面积比较/仅保留最大矩形(91714a58)

**依赖链**：全局嵌套分析决定哪些框存活 → 存活框的空间位置和被擦除框的幽灵边界共同约束生长范围 → 不同框的生长前沿碰撞时由面积比较解决冲突。这是全局分析→选择性操作→约束交互的三阶段结构，且幽灵边界创造了一种"不可见约束"，使得删除步骤和生长步骤之间存在非显然的信息传递。

按嵌套深度的奇偶擦除矩形框，存活的框向外生长同心环直至碰到被擦除框的幽灵边界或网格边缘，碰撞区域归面积较小的框。

**输入结构**：约 17x17 的黑(0)背景网格。4-6 个矩形框（1 像素宽的空心矩形轮廓），每个框使用不同颜色（从红(2)、蓝(1)、绿(3)、黄(4)、品红(6)、橙(7)中选取）。框之间存在嵌套关系：某些框完全位于另一个框的内部（即内框的四条边都在外框的四条边内侧）。嵌套可以多层（如 A 包含 B，B 包含 C）。同一层级的框不会互相包含也不会重叠。每个框的边长至少为 3（保证内部可以容纳更小的框或生长空间）。生成约束：嵌套深度至少覆盖 0 和 1 两个层级；同一深度的不同框面积（边界框围成的总像素数）互不相同。

**规则**：
1. 计算每个矩形框的嵌套深度：不被任何其他框包含的框深度为 0；被恰好 1 个框包含的深度为 1；被恰好 2 个框包含的深度为 2；以此类推。"包含"定义：框 A 包含框 B 当且仅当 B 的四条边的行列坐标都严格在 A 的四条边内侧。
2. 擦除所有偶数深度（0, 2, 4...）的框：将其像素设为黑(0)。记录每个被擦除框的原始边界位置（四条边的行列坐标）作为"幽灵边界"。
3. 保留所有奇数深度（1, 3, 5...）的框，称为"存活框"。
4. 从每个存活框出发，向外逐层生长同心矩形环。每层环在上一层外侧扩展 1 像素（即 Chebyshev 距离递增）。环的颜色与该存活框相同。生长在以下条件时停止：(a) 环的像素到达网格边缘；(b) 环的像素到达某个幽灵边界所定义的矩形区域的边上（即该像素的行或列坐标等于某个被擦除框的某条边的坐标，且该像素在该被擦除框的行列范围内）。停止时，触发停止的那一层环仍然绘制。
5. 若两个存活框的生长环在同一像素碰撞（同一像素属于两个不同框的某一层环），该像素归属于面积更小的框（面积 = 该框原始边界框的宽 x 高）。面积保证互不相同，无需 tie-break。
6. 存活框的原始像素保持不变。幽灵边界不绘制任何像素（它们只作为生长的停止条件）。

**关键洞察**：被擦除的框在视觉上消失了，但它们的原始位置作为不可见的幽灵边界继续约束着存活框的生长范围。求解者必须记住哪些框被擦除以及它们曾在哪里，才能正确预测生长的停止位置。这创造了一种"记忆依赖"——输出的几何结构取决于已不存在的输入元素。
