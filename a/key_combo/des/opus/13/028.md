## 新题 1：对称修墙改变可达分区

**组合逻辑**：[对称补全](创新：作用于墙壁结构而非前景色层) + [洪泛填充](创新：在修正后的拓扑上执行) → [重涂色](由可达性结果驱动)

**来源原语**：对称补全(#5 8e5c0c38), 洪泛填充(#9 782b5218), 重涂色(#16 62ab2642), 分隔墙(#16 62ab2642), 角落锚定(#9 782b5218), 对称轴(#5 8e5c0c38)

**依赖链**：对称补全改变墙壁拓扑（封闭或打通通道）→ 洪泛填充在修正后的墙壁上执行 → 可达性结果与原始墙壁不同 → 重涂色依赖修正后的分区。删除对称补全步骤，洪泛填充结果完全不同；删除洪泛填充，无法确定哪些区域需要涂色。

修正墙壁的垂直对称性后，根据从角落出发的可达性将非墙区域分为两色。

**输入结构**：约 15×15 的网格，宽度为奇数。黑(0)背景。灰(5)像素构成一道从顶到底的墙壁结构，大致沿网格中心列排列，将黑色区域分为左右两半。该墙壁关于中心列几乎垂直对称，但有 2~4 个噪声像素破坏对称——具体表现为某侧有个别多余灰像素或缺失灰像素。墙壁中存在 1~2 个一像素宽的缺口（仅在原始墙壁中），使得左右两半通过缺口 4-连通可达。两侧各散布若干青(8)像素作为干扰物（与墙壁和背景均不同色）。生成约束：对称修正后至少有一个原始缺口被封闭（镜像位置原本为背景，修正后变为灰），使得修正前后从左上角出发的可达区域不同。

**规则**：
1. 对称轴为网格的中心列（列索引 = (宽度-1)/2）。
2. 对每对关于中心列对称的位置 (r, center-d) 和 (r, center+d)：若恰好一个为灰(5)、另一个为黑(0)背景，则将背景位置也涂为灰(5)。若非灰侧为青(8)或其他非背景色，则不添加灰像素（保留该像素，接受局部不对称）。两侧均灰或均非灰时不做改动。
3. 在修正后的网格上，以左上角 (0,0) 为种子执行 4-连通洪泛填充，遍历所有非灰单元格。
4. 将所有被洪泛填充到达的非灰单元格重涂为绿(3)。将所有未被到达的非灰单元格重涂为红(2)。灰(5)墙壁像素保持不变。

**关键洞察**：对称修正会封闭墙壁中的微小缺口，改变空间的连通拓扑——仅凭原始墙壁判断可达性会得到错误的分区结果。

## 新题 2：归一化形状匹配驱动面积排名涂色

**组合逻辑**：[形状匹配](保留归一化比对) + [排序](创新：按匹配目标的面积排名) → [重涂色](由排名结果映射)

**来源原语**：形状匹配(#10 2a5f8217), 排序(#2 694f12f3), 重涂色(#2 694f12f3), 占位符对象(#10 2a5f8217), 模板对象(#10 2a5f8217), 面积比较(#2 694f12f3), 归一化形状匹配(#10 2a5f8217), 面积排名映射色(#2 694f12f3)

**依赖链**：归一化形状匹配建立占位符与模板的一一对应 → 对应的模板面积用于全局排名 → 排名决定占位符的输出颜色。形状匹配和面积排名缺一不可：没有匹配则不知道每个占位符对应哪个模板的面积；没有排名则不知道该涂什么颜色。

将蓝色占位符按其匹配模板的面积从小到大排名，依次涂为红、绿、黄。

**输入结构**：约 20×20 的黑(0)背景网格。包含恰好 3 个灰(5)模板对象和恰好 3 个蓝(1)占位符对象，共 6 个 4-连通前景连通分量。每个模板是一个由灰像素组成的不规则 4-连通图形（4~8 像素，各自外接矩形不超过 4×4），三个模板的像素数互不相同。每个占位符是蓝色的 4-连通图形，其归一化掩码（将外接矩形内的像素位图平移至原点后的二值矩阵）与恰好一个模板相同（允许旋转和反射变换后匹配）。六个对象两两不重叠、不相邻（外接矩形间至少隔 1 个像素）。生成约束：三对匹配关系唯一确定。

**规则**：
1. 提取所有 4-连通前景连通分量。灰(5)分量为模板，蓝(1)分量为占位符。
2. 对每个占位符，计算其归一化掩码（外接矩形内的二值位图），枚举该掩码在 4 种旋转 × 2 种反射下的全部 8 个变体。找到唯一一个灰模板，其归一化掩码等于占位符的某个变体。
3. 记录每个占位符对应的模板的像素面积。按面积升序对三个占位符排名：排名 1（最小面积）、排名 2、排名 3（最大面积）。
4. 将排名 1 的占位符所有像素重涂为红(2)，排名 2 重涂为绿(3)，排名 3 重涂为黄(4)。模板和背景不变。

**关键洞察**：输出颜色既不取决于占位符自身的任何属性，也不取决于模板的颜色——而是取决于占位符所匹配模板在全局面积排名中的位次。仅看单个示例可能猜到"形状对应"，但排名-颜色映射需要对比多个示例才能确定。

## 新题 3：角括号选色后按连通分量尺寸分流处理

**组合逻辑**：[擦除](创新：仅作用于多像素分量) + [重涂色](创新：仅作用于孤立像素分量) ← [尺寸分类](决策节点) ← [按标记色选择同色](角括号选色)

**来源原语**：擦除(#7 1e81d6f9), 重涂色(#17 aedd82e4), 角括号(#7 1e81d6f9), 标记像素(#7 1e81d6f9), 连通分量(#17 aedd82e4), 孤立像素(#17 aedd82e4), 标记在括号内部(#7 1e81d6f9), 尺寸分类(#17 aedd82e4), 按标记色选择同色(#7 1e81d6f9), 保留标记本身(#7 1e81d6f9), 单像素分量重涂(#17 aedd82e4)

**依赖链**：角括号内的标记像素指定目标颜色 C → 在全网格中找到所有颜色为 C 的 4-连通分量 → 按分量尺寸分流：孤立单像素分量执行重涂色，多像素分量执行擦除。角括号选色和尺寸分类共同决定最终操作——删除选色步骤则不知道处理哪种颜色；删除尺寸分类则无法区分两种不同操作。

读取角括号中标记像素的颜色，将该颜色的孤立像素重涂为蓝色，将该颜色的多像素连通体擦除为背景。

**输入结构**：约 12×12 的黑(0)背景网格。网格中有一个由灰(5)像素构成的 4-连通角括号形结构（一个直角拐弯形状，约 5~7 像素，形成一个开口朝某方向的角）。在角括号外接矩形内部、角括号像素之外的区域，有恰好一个标记像素，颜色为 C（C 为红(2)、绿(3)、黄(4)中的某一种）。网格其余区域散布着若干颜色为 C 的 4-连通分量：其中 2~3 个是孤立的单像素，另有 1~2 个是包含 3~6 像素的多像素连通体。网格中还可能有少量其他非 C 颜色的前景像素作为干扰物。生成约束：标记像素颜色 C 在不同示例中不同；角括号和标记像素本身在输出中保持不变。

**规则**：
1. 定位灰(5)角括号结构。在其外接矩形内部、角括号像素之外，找到唯一的非黑非灰标记像素，读取其颜色 C。
2. 在整个网格中（角括号外接矩形之外），找到所有颜色为 C 的 4-连通分量。
3. 对每个分量判断尺寸：若分量仅含 1 个像素（孤立像素），将该像素重涂为蓝(1)；若分量含 2 个及以上像素，将该分量所有像素擦除为黑(0)背景。
4. 角括号、标记像素、以及所有非 C 颜色的像素保持不变。

**关键洞察**：角括号机制和尺寸分类机制来自不同源题，在此交织为一个决策图——先由角括号确定"操作什么颜色"，再由连通分量尺寸确定"对该颜色做什么操作"。两个决策节点缺一不可。

## 新题 4：分隔行编码列位移量后求双掩码交集

**组合逻辑**：[循环位移](创新：位移量由分隔行中的标记位置编码) + [布尔运算](在位移后的掩码间执行) → [裁剪](输出为单掩码尺寸)

**来源原语**：循环位移(#18 6d1d5c90), 布尔运算(#1 6430c8c4), 裁剪(#1 6430c8c4), 掩码区域(#1 6430c8c4), 分隔线(#1 6430c8c4), 标记像素(#18 6d1d5c90), 行偏移编码(#18 6d1d5c90), 标记位定位移量(#18 6d1d5c90), 双掩码交集输出(#1 6430c8c4)

**依赖链**：分隔行同时承担两个功能——作为上下掩码的物理分隔符，以及通过标记像素的列位置编码下方掩码的水平循环位移量。位移改变了下方掩码与上方掩码的逐列对齐方式，从而改变布尔运算的结果。三个步骤形成紧耦合：分隔行的双重身份（分隔+编码）将位移操作和布尔运算绑定在一起。

从分隔行中的标记位置读取列位移量，将下方掩码水平循环位移后，与上方掩码逐格求交集。

**输入结构**：约 11×7（11 行 7 列）的网格。黑(0)为背景色。网格被一条全宽分隔行分为上下两个尺寸相同的矩形掩码区域（例如各 5 行 7 列）。上方掩码包含若干黄(4)前景像素，其余为黑(0)。下方掩码包含若干蓝(1)前景像素，其余为黑(0)。分隔行本身全部为灰(5)，其中恰好有一个像素为红(2)标记。红标记的列索引（从 0 开始计数）即为位移量 s。生成约束：上下掩码尺寸相同；位移后的交集结果非空且与未位移时的结果不同；s >= 1 以保证位移实际发生。

**规则**：
1. 找到全宽的灰(5)/红(2)分隔行。分隔行将网格分为上方掩码 M_top 和下方掩码 M_bot（各自为分隔行上方/下方的所有行）。
2. 在分隔行中找到红(2)标记像素，读取其列索引 s。
3. 将 M_bot 整体水平循环右移 s 列：每个像素 (r, c) 移至 (r, (c+s) mod W)，其中 W 为掩码宽度。
4. 移除分隔行。逐格对齐 M_top 与位移后的 M_bot。
5. 输出与单个掩码相同尺寸的网格：在两个对齐位置均为背景(0)的格子涂绿(3)；其余涂黑(0)。

**关键洞察**：分隔行不仅是物理边界，其标记位置隐式编码了一个变换参数。求解者必须发现"标记列索引 = 位移量"这一隐蔽规则，否则布尔运算的对齐方式无法确定。

## 新题 5：对角连线生成洪泛填充屏障

**组合逻辑**：[连线](保留对角连接逻辑) → [洪泛填充](创新：将连线作为屏障而非装饰) → [重涂色](由可达性分区驱动)

**来源原语**：连线(#3 55059096), 洪泛填充(#9 782b5218), 重涂色(#16 62ab2642), 十字图案(#3 55059096), 中心对角对齐(#3 55059096), 无障碍通路(#3 55059096), 角落锚定(#9 782b5218), 墙分隔区域(#16 62ab2642), 极值面积决定颜色(#16 62ab2642)

**依赖链**：对角连线在十字对象之间生成新像素 → 这些新像素（连同十字对象本身）构成洪泛填充的屏障 → 屏障将空间分割为多个不连通区域 → 按区域面积排名涂色。连线步骤创造了原本不存在的屏障，改变了空间分区的拓扑——这不是两个独立操作的简单叠加，而是第一步的输出成为第二步的结构基础设施。

先在对角对齐的十字对象之间画连线，再将这些连线和十字对象作为墙壁执行洪泛填充，按分区面积涂色。

**输入结构**：约 17×17 的黑(0)背景网格。包含 4~6 个绿(3)十字图案对象，每个十字由中心像素加上下左右 4 个邻居共 5 个像素组成（外接矩形 3×3）。部分十字的中心在同一条 45 度对角线上（行间距等于列间距），且中心之间的对角路径上所有格子均为背景。十字之间除对角对齐外互不 4-连通。生成约束：对角连线画完后，所有连线和十字对象共同将网格分割为至少 3 个 4-连通的背景区域（以 8-连通的对角线像素作为 4-连通屏障——因为对角像素占据了格子本身，两侧的背景格子被切断）；这些区域的面积互不相同。

**规则**：
1. 保留所有输入像素不变。
2. 对每一对十字对象，若两者的中心行间距绝对值等于列间距绝对值（即中心在同一条 45 度对角线上），检查中心之间的对角段（不含两端中心）上所有格子是否均为背景(0)。若是，将这些格子涂为红(2)。处理顺序为按中心的行优先坐标从左上到右下扫描所有对。
3. 将所有非背景像素（绿十字 + 红连线）视为不可通行的墙壁。找到所有 4-连通的背景(0)区域。
4. 将面积最小的背景区域涂为橙(7)，面积最大的背景区域涂为青(8)。其余背景区域保持黑(0)。绿(3)十字和红(2)连线像素不变。

**关键洞察**：对角连线不是装饰性输出——它们是后续空间分区的结构性屏障。求解者必须先完成连线才能正确判断哪些区域是封闭的、面积是多少。

## 新题 6：循环位移后对称去噪再裁剪

**组合逻辑**：[循环位移](保留控制列逻辑) → [对称补全](创新：对位移后的图案执行去噪) → [裁剪](输出清理后图案的外接矩形)

**来源原语**：循环位移(#18 6d1d5c90), 对称补全(#5 8e5c0c38), 裁剪(#14 e9b4f6fc), 控制列(#18 6d1d5c90), 标记像素(#18 6d1d5c90), 色层(#5 8e5c0c38), 对称轴(#5 8e5c0c38), 标记位定位移量(#18 6d1d5c90), 忽略干扰项(#5 8e5c0c38)

**依赖链**：控制列中标记位置编码行位移量 → 位移后图案的像素排列改变 → 不同的排列下"哪些像素破坏对称"的判定不同 → 去噪结果因位移量而异 → 裁剪的外接矩形也随之改变。位移量是对称去噪的隐式参数——它通过重新排列像素来改变"噪声"的定义。

移除控制列并按标记位置循环下移图案，然后对每种颜色独立执行垂直对称去噪，最后裁剪至非背景像素的外接矩形。

**输入结构**：约 10×8 的网格（10 行 8 列）。最左列为控制列：品红(6)背景，其中恰好一个像素为红(2)标记。控制列右边 7 列为主图案区域，黑(0)背景上有蓝(1)和黄(4)两种前景色的像素，共约 12~18 个前景像素。主图案区域中蓝像素和黄像素各自构成一个几乎关于各自独立的垂直轴对称的图案，但各有 1~2 个噪声像素破坏对称。生成约束：对于正确的位移量 r（红标记行索引），循环下移后蓝和黄图案各自的最佳对称轴恰好是主图案区域的中心列；对于错误的位移量，对称轴不成立或去噪结果不同。去噪后至少仍有 6 个前景像素。

**规则**：
1. 读取控制列中红(2)标记的行索引 r。移除控制列，得到主图案区域（宽度减 1）。
2. 将主图案区域所有行循环下移 r 行：第 i 行移至第 (i+r) mod H 行，H 为主图案区域高度。
3. 对蓝(1)和黄(4)分别独立执行垂直对称去噪：对称轴为主图案区域的中心列（列索引 = (主区域宽度-1)/2）。对该色的每个像素 (row, col)，检查其镜像位置 (row, 2×center - col) 是否也为同色。若镜像位置不是同色，则移除该像素（涂为黑(0)背景）。注意：两个不同颜色的对称检测互不干扰——蓝色只和蓝色比，黄色只和黄色比。
4. 找到去噪后所有非背景像素的最小外接矩形，输出该矩形区域。

**关键洞察**：循环位移改变了像素的行位置，而对称检测依赖位置——因此位移量隐式决定了哪些像素是"噪声"。求解者必须先正确解码位移量，对称去噪才会产生有意义的结果。

## 新题 7：孔洞检测驱动间隙填充颜色选择

**组合逻辑**：[填充](创新：孔洞填充 + 间隙填充两种填充由同一检测结果驱动) + [描边](对空心对象执行) ← [包含关系](检测封闭孔洞作为决策节点)

**来源原语**：填充(#6 d6ad076f), 描边(#19 aa4ec2a5), 封闭孔洞(#19 aa4ec2a5), 间隙区域(#6 d6ad076f), 前景对象(#19 aa4ec2a5), 两体之间(#6 d6ad076f), 包含关系(#19 aa4ec2a5), 有孔触发重涂(#19 aa4ec2a5), 间隙区域涂色(#6 d6ad076f)

**依赖链**：检测两个对象中哪个包含封闭孔洞 → 孔洞信息同时驱动两个后续操作：(a) 对含孔对象执行描边 + 孔洞填充；(b) 间隙区域的填充颜色由含孔对象的相对位置决定。孔洞检测是分流点——它既触发局部操作（描边、填孔），又参数化全局操作（间隙颜色）。

检测哪个对象有孔洞，对有孔对象描边并填孔，然后根据有孔对象在左还是在右选择不同颜色填充两对象间的间隙。

**输入结构**：约 14×14 的黑(0)背景网格。包含恰好两个绿(3) 4-连通前景对象，水平方向分开放置（外接矩形不重叠，之间有至少 2 列宽的黑色间隙）。一个对象是实心的不规则 4-连通图形（6~10 像素，无封闭孔洞）。另一个是空心的——其 4-连通像素围成一个封闭区域，内部有 1~4 个被完全包围的背景(0)像素（封闭孔洞）。两个对象的外接矩形在行方向有重叠（即在垂直方向上有对齐部分）。生成约束：不同示例中含孔对象可能在左侧或右侧；两个对象之间的间隙区域定义为列范围在两个外接矩形之间、行范围为两个外接矩形行范围交集的矩形区域中的背景像素。

**规则**：
1. 找到两个绿(3) 4-连通连通分量。对每个分量检测封闭孔洞：在分量的外接矩形内，找到被分量像素完全 4-连通包围的背景(0)连通区域（即从该背景区域出发，仅沿背景像素 4-连通移动无法到达外接矩形的边界）。
2. 对含有封闭孔洞的对象（记为 H）：将其封闭孔洞中的所有背景像素涂为品红(6)。然后对 H 执行描边——将 H 所有像素（含已填充的品红像素）的 8-邻域中的背景(0)像素涂为红(2)。描边仅涂背景像素，不覆盖任何已有非背景像素。
3. 对不含孔洞的实心对象（记为 S）：不做任何改动。
4. 填充间隙区域：间隙定义为列范围严格在 H 外接矩形右边界和 S 外接矩形左边界之间（若 H 在左）或 S 右边界和 H 左边界之间（若 H 在右），行范围为 H 和 S 外接矩形行范围的交集。将该矩形区域内的所有背景(0)像素涂色——若 H 在 S 的左侧，涂青(8)；若 H 在 S 的右侧，涂橙(7)。
5. 所有其他像素保持不变。

**关键洞察**：孔洞检测不仅触发局部的描边和填孔操作，还决定了间隙填充的颜色——因为颜色取决于"有孔对象在左还是在右"。必须对比多个示例（有孔对象在左 vs. 在右）才能归纳出颜色选择规则。

## 新题 8：色条图例定优先级解决模板重叠冲突

**组合逻辑**：[模板匹配](含旋转反射变换) + [印章覆盖](创新：多个匹配实例可能重叠) ← [遮挡层次](创新：由色条图例的左右顺序定义而非由可见性推断)

**来源原语**：模板匹配(#20 50f325b5), 印章覆盖(#12 94be5b80), 色条图例(#12 94be5b80), 遮挡层次(#4 22425bda), 模板图案(#20 50f325b5), 含旋转反射变换(#20 50f325b5), 非重叠放置(#20 50f325b5 → 创新为允许重叠), 图例顺序对应插槽(#12 94be5b80 → 创新为对应优先级), 唯一序链(#4 22425bda)

**依赖链**：模板匹配找到所有颜色分组的模板实例位置 → 多组实例之间存在空间重叠 → 色条图例定义各颜色的优先级（左低右高）→ 重叠像素采用优先级最高的颜色。图例不再指示"哪些颜色填入哪些插槽"，而是指示"冲突时谁覆盖谁"——这是图例语义的创新。没有模板匹配就不知道哪些像素属于哪个实例；没有图例就无法解决重叠冲突。

按色条图例定义的优先级，在重叠区域中保留高优先级颜色的模板匹配结果。

**输入结构**：约 18×18 的黑(0)背景网格。网格顶部（第 0 行）有一个水平色条图例：由 3 个相邻的单像素色块组成，颜色各不相同，均为非黑前景色（例如从左到右为蓝(1)、红(2)、绿(3)）。色条下方为主区域。主区域中有一个灰(5) 4-连通小图形作为模板（3~5 像素，外接矩形不超过 3×3）。主区域中还有多个（4~6 个）与色条颜色相同的前景像素组，每组颜色对应色条中的一种颜色。每组内的像素构成模板在某种旋转/反射变换下的一个精确副本。不同颜色组的副本之间可能存在 1~3 个像素的空间重叠（即同一个格子被两个不同颜色的副本声称占据）。生成约束：每种色条颜色恰好有 1~2 个副本；灰色模板不与任何副本重叠；重叠仅发生在不同颜色的副本之间，同色副本之间不重叠。

**规则**：
1. 读取顶行色条图例中的颜色序列，从左到右优先级递增（最左优先级最低，最右最高）。
2. 提取灰(5)模板的归一化掩码。枚举全部 8 种旋转/反射变体。
3. 对每种色条颜色 C，在主区域中扫描所有位置，找到模板变体掩码上所有格子均为颜色 C 的放置位置。记录每个找到的副本的位置和颜色。同色副本按外接矩形左上角行优先从左上到右下的顺序扫描，发现即记录（同色副本保证不重叠）。
4. 处理重叠：对主区域中每个非背景、非灰像素，确定其属于哪些副本。若属于多个不同颜色的副本，保留色条图例中优先级最高的颜色，擦除其他颜色（涂为该最高优先级颜色）。若仅属于一个副本，颜色不变。
5. 灰色模板、色条图例、背景像素均保持不变。

**关键洞察**：色条图例的语义从"填充指引"变为"优先级序"——其左右顺序不再指定哪个颜色放在哪个位置，而是定义重叠冲突的解决规则。需要对比多个示例中图例顺序不同时重叠区域的输出颜色才能归纳此规则。

## 新题 9：粗粒度压缩结果与可达性双重约束筛选

**组合逻辑**：[压缩](保留 3×3 块检测) ∧ [洪泛填充](判断可达性) → [布尔运算](两个条件的交集决定输出)（同时约束满足结构）

**来源原语**：压缩(#13 e57337a4), 洪泛填充(#9 782b5218), 布尔运算(#1 6430c8c4), 粗粒度块(#13 e57337a4), 墙壁障碍(#11 dd6b8c4b), 标记像素(#13 e57337a4), 阵列排布(#13 e57337a4), 可达性(#11 dd6b8c4b), 含标记涂标记色(#13 e57337a4), 角落锚定(#9 782b5218)

**依赖链**：这不是线性流水线——压缩和可达性是两条并行分析路径，最终在布尔交集处汇合。压缩检测每个粗粒度块是否含标记 → 产生条件 A。洪泛填充从左上角出发判断每个粗粒度块是否可达 → 产生条件 B。输出格子为绿当且仅当 A 和 B 同时为真。单独满足任一条件都不足以确定输出。

将大网格压缩为 3×3 概览，同时标记只有既含标记像素又从角落可达的粗粒度块。

**输入结构**：约 15×15 的网格，高度和宽度均可被 3 整除（如 15×15 或 12×15）。黑(0)为主色（占多数像素）。网格中散布若干红(2)标记像素（约 6~10 个），分布在不同的 5×5 或 4×5 粗粒度块中。另有灰(5)像素构成一像素宽的墙壁线段（水平或垂直），墙壁可能跨越粗粒度块边界。生成约束：将网格等分为 3×3 共 9 个矩形块。至少 2 个块含红标记但不可从左上角块经过非墙像素 4-连通到达（被墙壁阻断）；至少 2 个块含红标记且可从左上角块到达；至少 1 个块可从左上角到达但不含红标记。墙壁不占据网格四角的像素（确保左上角块的角落像素为黑色背景，可作为洪泛填充种子）。

**规则**：
1. 将网格等分为 3×3 共 9 个矩形粗粒度块（各块尺寸 = 网格尺寸 / 3）。
2. 对每个块，检测是否包含至少一个红(2)标记像素。记录为布尔值 has_marker[i][j]。
3. 以网格左上角像素 (0,0) 为种子，在所有非灰(5)像素上执行 4-连通洪泛填充。对每个块，检测该块内是否有至少一个像素被洪泛填充到达。记录为布尔值 reachable[i][j]。
4. 输出一个 3×3 的网格：若 has_marker[i][j] 为真且 reachable[i][j] 为真，输出绿(3)；否则输出黑(0)。

**关键洞察**：含红标记但被墙壁封闭的块在输出中仍为黑色——单看"是否含标记"会得到错误答案。求解者必须同时发现压缩规则和可达性约束这两条独立线索，并理解输出是二者的交集。
