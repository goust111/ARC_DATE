## 新题 1：拓扑重力筛

**组合逻辑**：[包含/containment](创新：从"是否重涂"的判据升级为"重力行为"的判据) + [重力下落/gravity_drop](已有) + [重涂色/recolor](已有) + [穿透与停靠/pass_through_or_stop](创新：穿透条件从宽度替换为拓扑属性)

**来源原语**：重力下落、穿透与停靠（84ba50d3）；包含、封闭区域、有空洞则重涂、重涂色（810b9b61）；分隔行（84ba50d3）

**依赖链**：包含检测决定每个对象的重力规则类型 → 重力规则决定对象的最终位置 → 拓扑分类同时决定落地后的重涂色。三步之间环环相扣：不检测拓扑无法选择重力规则，不执行重力无法确定最终位置，不重涂色则无法区分两类对象。

将分隔行上方的前景对象按拓扑属性分流：空心对象穿透分隔行落至底部并变色，实心对象停靠在分隔行上方并保持原色。

**输入结构**：约 15x15 网格。黑(0)为背景。一条红(2)全宽水平分隔行位于网格中部偏下（约第 10-12 行）。分隔行上方散布 4-6 个蓝(1)的 4-连通单色对象（每个 4-10 像素），其中部分对象的像素完全包围了一个或多个黑(0)背景像素（空心对象），其余对象不包围任何背景像素（实心对象）。空心与实心对象的外部尺寸和像素数范围可以重叠，不能仅凭大小或宽度区分。各对象互不相邻且不接触分隔行。分隔行下方至网格底部全为背景。生成约束：不同对象的列范围互不重叠（确保下落路径不冲突）。

**规则**：
1. 对每个蓝(1)对象做 4-连通包含检测：若该对象的像素完全包围了至少一个黑(0)背景连通区域，则标记为"空心"；否则标记为"实心"。
2. 清除所有蓝(1)对象的原始像素（恢复为背景）。
3. 空心对象：将其整体向下平移，直至对象最底行到达网格最后一行。对象穿过红(2)分隔行时，删除被穿过的分隔行像素（即对象所占列上的分隔行像素设为背景）。落地后，将该对象所有像素重涂为绿(3)。
4. 实心对象：将其整体向下平移，直至对象最底行紧邻分隔行上方（即分隔行上方一行）。若移动后对象与分隔行有重叠列，对象覆盖分隔行（对象像素优先）。对象保持蓝(1)不变。
5. 未被删除的分隔行像素保持红(2)。

**关键洞察**：分隔行不是简单的地板——它是拓扑筛：能包围背景区域的空心对象穿透它落到底部，不能包围的实心对象被它拦住。宽度和面积不是判据，拓扑封闭性才是。

## 新题 2：投影遮挡筛选与同心环组装

**组合逻辑**：[投影/project](已有) + [计数/counting](已有) + [排序/sort + 面积排序/area_ordering](已有) + [同心环绘制/concentric_draw](已有)（创新：投影不只是标记输出，而是充当对象筛选机制；面积同时决定遮挡优先级和环序）

**来源原语**：投影、中心对齐、对象中心在边行标（54d82841）；同心环绘制、面积排序、面积决定嵌套序（5587a8d0）；计数（469497ad / b0039139）

**依赖链**：投影时的遮挡筛选（面积大者遮蔽面积小者）决定哪些对象存活 → 存活对象数量决定同心方环尺寸 → 存活对象面积排序决定各环颜色。面积在此承担双重角色（遮挡优先级 + 环序），不可拆分。

将多个前景对象向底行投影，共享投影列的对象中只有最大者胜出；胜出者按面积顺序组装为同心方环。

**输入结构**：约 18x18 网格。黑(0)为背景。散布 5-7 个单色对象，每个对象颜色各异（从红(2)、绿(3)、蓝(1)、黄(4)、灰(5)、品红(6)、橙(7)中选取），形状为不规则 4-连通图形（4-15 像素），各对象面积互不相同。对象之间互不接触。部分对象的边界框中心列与其他对象的边界框中心列相同（即投影列重叠），但每组重叠中各对象面积不同。底行（最后一行）全为背景。生成约束：至少存在一对投影列重叠的对象；存活对象数量 >= 3。

**规则**：
1. 对每个前景对象，计算其边界框的水平中心列（(左列 + 右列) / 2，向下取整）。
2. 若两个或更多对象共享相同的中心列，仅保留其中面积（像素数）最大的对象，其余对象标记为"被遮挡"并从后续步骤中排除。
3. 设存活对象总数为 N。构建一个边长为 2N-1 的正方形输出网格（替换原网格），背景为黑(0)。
4. 将存活对象按面积从大到小排序。面积最大者的颜色填充最外层环，面积次大者填充次外层环，以此类推，面积最小者的颜色填充中心像素。
5. 被遮挡的对象不出现在输出中。

**关键洞察**：投影不是展示性的——它是一个存活筛选器。共享投影列的对象中只有面积最大者存活。面积属性被双重使用：既决定遮挡竞争的胜负，又决定存活者在同心环中从外到内的排列。

## 新题 3：嵌套深度参数化环旋转

**组合逻辑**：[循环移色/color_cycle](已有) + [包含/containment](创新：包含关系不用于判断"是否操作"，而是计算嵌套深度作为操作参数) + [角与边中分组/corner_side_group](已有) + [反向循环/opposite_cycle](已有)

**来源原语**：循环移色、角与边中分组、反向循环、环形前景（46c35fc7）；包含（810b9b61）；嵌套方环（5587a8d0，提供同心嵌套结构概念）

**依赖链**：包含检测确定每个环的嵌套深度 → 嵌套深度直接作为该环的循环步数 → 角位和边中位分组决定循环方向。三者缺一不可：无深度则步数不定，无分组则方向不定，无循环则输出不变。

对同心嵌套的多层稀疏方环分别执行颜色循环，每层的循环步数等于其嵌套深度，角位顺时针、边中位逆时针。

**输入结构**：约 11x11 网格。黑(0)为背景。网格中央有一组 2-4 层同心稀疏方环，共享同一中心像素（中心像素为背景色）。每层方环是一个奇数边长正方形的骨架，仅保留 8 个像素：4 个角位像素和 4 条边各自的中点像素。从外到内各层边长以 4 为步长递减（例如三层时边长分别为 9、5、3；两层时为 7、3）。每个像素有各自的颜色，颜色取自红(2)、绿(3)、蓝(1)、黄(4)、灰(5)、品红(6)、橙(7)中的若干种，同一层内 8 个像素的颜色不全相同。各层之间无前景像素。

**规则**：
1. 识别各同心方环并确定其嵌套深度 D（最外层 D=1，向内递增）。
2. 对每层深度为 D 的方环：
   - 将 4 个角位像素的颜色沿顺时针方向循环移动 D 步（左上 → 右上 → 右下 → 左下 → 左上，循环 D 次）。
   - 将 4 个边中位像素的颜色沿逆时针方向循环移动 D 步（上中 → 左中 → 下中 → 右中 → 上中，循环 D 次）。
3. 背景像素和中心像素不变。

**关键洞察**：嵌套深度不只是结构描述——它直接编码了旋转量。内层环比外层环旋转更多步。仅看单个示例无法区分"深度决定步数"与"所有环固定步数"，因为可能恰好深度 1 的旋转看起来像固定 1 步。

## 新题 4：双模式格子填充与射线混色

**组合逻辑**：[射线延伸/ray_extend](已有) + [填充/fill](已有) + [共行或共列/shared_row_col](已有) + [双色交叉混合色/intersect_blend_color](创新：混色不再由两种标记色交叉产生，而是由两种填充模式交叉产生) + [行列对齐/row_col_alignment](已有) + [对齐标记连向锚点/marker_to_anchor](创新：锚点不仅是射线终点，还是标记分组的判据)

**来源原语**：射线延伸、锚定方块、行列对齐、对齐标记连向锚点（d43fd935）；填充、格子单元、共行或共列、双色交叉混合色（e760a62e）；网格线（e760a62e）

**依赖链**：锚点位置将标记分为两组（对齐 vs 不对齐） → 两组分别执行不同的填充规则（射线填充 vs 区间填充） → 两种填充在同一格子上叠加时产生混合色。分组机制和两种填充规则三者紧耦合。

标记像素被锚点分为两类：与锚点对齐的沿射线填充到锚点，不对齐的按同色共行/列区间填充；两类填充交叉处混色。

**输入结构**：约 15x15 网格。青(8)网格线将画布分割为均匀的矩形格子单元（每个格子约 3x3 内部区域，网格线宽 1 像素）。一个绿(3) 2x2 锚定方块占据某个格子单元的位置。红(2)和蓝(1)单像素标记分布在若干格子单元中（每个格子至多一个标记，标记位于格子中心）。部分标记与锚定方块处于同一格子行或同一格子列（"锚对齐标记"）；其余标记不与锚点对齐但与其他同色标记共享格子行或格子列（"互对齐标记"）。生成约束：至少有 2 个锚对齐标记和 2 对互对齐标记；至少有 1 个格子同时被两种填充模式覆盖。

**规则**：
1. 对每个与锚定方块处于同一格子行或格子列的标记（不分颜色），将该标记到锚定方块之间的所有格子单元填充为该标记的颜色（射线填充模式）。填充包含标记所在格子但不包含锚定方块所在格子。
2. 对不与锚点对齐的标记：若同色标记中有两个或更多共享一格子行，则将该行中从最左到最右标记之间的所有格子填充为该颜色；同理处理共享格子列的情况（区间填充模式，同 e760a62e）。
3. 若某个格子单元同时被射线填充和区间填充覆盖（无论颜色是否相同），该格子单元着色为品红(6)。
4. 青(8)网格线、绿(3)锚定方块和所有原始标记像素保持不变。

**关键洞察**：锚点不仅是射线的终点——它还隐式地将标记分为两个行为组。标记与锚点的对齐关系决定了它适用哪种填充规则，而两种规则在同一格子上的冲突产生了第三种颜色。求解者必须先识别分组机制，才能理解混色的来源。

## 新题 5：封闭面积槽位匹配与旋转嵌入

**组合逻辑**：[插入/insert](已有) + [包含/containment](创新：封闭区域面积取代外部尺寸作为匹配键) + [旋转/rotate](已有) + [重涂色/recolor](已有) + [尺寸匹配槽位/size_matches_slot](创新：匹配的"尺寸"来源从外部维度变为内部空洞面积)

**来源原语**：插入、旋转、平台槽位、尺寸匹配槽位、对齐且宽度匹配（67c52801）；包含、封闭区域（810b9b61）；重涂色（810b9b61 / b0039139）

**依赖链**：包含检测计算内部空洞面积 → 空洞面积作为键匹配槽位宽度 → 匹配确定放置位置 → 旋转调整朝向以适应槽位高度 → 放置后空洞重涂为平台色。无空洞的对象被丢弃（筛选功能），使拓扑检测成为不可跳过的第一步。

按前景对象内部空洞面积匹配平台槽位宽度，旋转后嵌入槽位，空洞填充为平台色；无空洞的对象被丢弃。

**输入结构**：约 15x18 网格。黑(0)为背景。最底行为灰(5)实心平台行。平台上方一行由灰(5)分隔段和黑(0)间隙交替组成，间隙即槽位，各槽位宽度互不相同（2-5 格）。平台上方散布 4-6 个不同颜色的 4-连通对象（每个 6-15 像素），颜色分别取自红(2)、绿(3)、蓝(1)、黄(4)、橙(7)等。其中部分对象的像素完全包围了若干黑(0)背景像素（有空洞），其余对象是实心的（无空洞）。有空洞的对象数量恰好等于槽位数量，且每个有空洞对象的空洞面积（被包围的背景像素数）恰好等于某个唯一槽位的宽度。每个有空洞的对象的边界框有一条边的长度为 2。各对象互不接触，且不接触平台区域。

**规则**：
1. 对每个前景对象做 4-连通包含检测，计算被完全包围的背景像素总数（空洞面积）。空洞面积为 0 的实心对象从输出中删除（不出现）。
2. 对每个有空洞的对象，裁剪到其边界框。
3. 将裁剪后的对象与槽位匹配：空洞面积 = 槽位宽度。每个对象恰好匹配一个槽位。
4. 若裁剪后的边界框宽度不等于匹配的槽位宽度，将其旋转 90 度使其宽度与槽位宽度一致（对象有一条边长为 2，旋转后高度为 2）。
5. 将旋转后的对象底部对齐平台行顶部，水平居中放入槽位。
6. 放置后，将该对象内部的空洞像素重涂为灰(5)（平台色），使空洞在视觉上与平台融合。

**关键洞察**：匹配的键不是对象的外部尺寸，而是内部空洞面积——两个外形完全不同的对象，只要内部空洞恰好包围相同数量的像素，就会争夺同一槽位（但生成约束保证不会发生）。无空洞的实心对象是干扰项，必须识别并丢弃。

## 新题 6：折叠合成环与条件循环移色

**组合逻辑**：[折叠/fold](已有) + [循环移色/color_cycle](已有) + [透明叠加/transparent_overlay](已有) + [角与边中分组/corner_side_group](创新：分组不再决定循环方向，而是决定折叠时从哪一侧取色) + [反向循环/opposite_cycle](已有)

**来源原语**：折叠、透明叠加、分隔线、对称互补、前景优先（e3497940）；循环移色、角与边中分组、反向循环、环形前景（46c35fc7）

**依赖链**：折叠将左右两侧的环合并为一个复合环（角取左侧色、边中取右侧色） → 仅合并产生的复合环执行循环移色 → 单侧独有的环保持原样。折叠结果决定了哪些环是"复合的"（即触发循环的条件），同时折叠中的取色规则依赖角/边中分组。

沿分隔线折叠网格，对称位置的两个环按角位/边中位分组合成为一个复合环，复合环执行一步颜色循环，非对称位置的单侧环保持不变。

**输入结构**：约 11x23 网格（宽大于高）。灰(5)垂直分隔列位于网格正中，将两侧分为等宽的左右面板（各约 11x11）。每个面板中放置 2-3 个 3x3 环形前景对象（8 像素围绕 1 个背景中心），各环的角位和边中位像素有不同颜色（取自红(2)、绿(3)、蓝(1)、黄(4)、橙(7)、品红(6)等）。部分环在左右面板中占据镜像对称位置（即以分隔列为轴，左侧某环的位置与右侧某环关于分隔列对称），部分环仅出现在一侧。生成约束：至少有 1 对对称环和 1 个单侧环。

**规则**：
1. 移除灰(5)分隔列。将右面板水平镜像翻转，叠加到左面板上，形成一个 11x11 输出网格。
2. 在镜像对称位置上同时存在左右两个环的情况下，合成一个复合环：复合环的 4 个角位像素取自左侧环对应位置的颜色，4 个边中位像素取自右侧环对应位置的颜色（镜像后的位置）。
3. 仅出现在一侧的环保持原始颜色不变，直接放入输出。
4. 对每个复合环执行一步颜色循环：角位颜色顺时针移动 1 步，边中位颜色逆时针移动 1 步。
5. 单侧环不执行颜色循环。
6. 背景像素保持黑(0)。

**关键洞察**：折叠不是简单的像素叠加——它是按像素在环中的角色（角 vs 边中）选择性地从两侧取色，生成一个全新的复合环。只有复合环才触发颜色循环，单侧环是静态的。求解者必须同时理解三个规则：折叠的取色策略、复合环的判定条件、循环的触发条件。

## 新题 7：压缩后按原始面积排序再印章

**组合逻辑**：[压缩/compress](已有) + [排序/sort](已有) + [印章放置/stamp](已有) + [标记指示方向/marker_indicates_dir](已有)（创新：压缩销毁了面积信息，但排序依赖压缩前的面积——信息必须跨越有损变换保存）

**来源原语**：压缩、滑动、空心符号、边缘标记线、标记指示方向、栅格对齐（afe3afe9）；排序、面积排序（5587a8d0 / 67636eac）；印章放置、模板（a395ee82）

**依赖链**：压缩前记录各符号的填充像素数（面积） → 压缩将 3x3 符号变为单像素（视觉上面积信息消失） → 边缘标记指示滑动方向，压缩像素沿该方向紧凑排列 → 按原始面积对压缩像素重新排序（面积大的靠近标记边） → 排序后的像素位置作为锚点，印章模板副本。信息在压缩这一有损步骤前后传递，是耦合的关键。

将格子中的 3x3 空心符号压缩为单像素，按边缘标记方向滑动紧凑后，以压缩前的填充面积排序，再以排序后的位置为锚点印章模板。

**输入结构**：约 18x18 网格，由蓝(1)分隔线分为两个区域。区域 A（较大，约 15x15）：黑(0)背景上分布 4-6 个 3x3 空心符号，每个符号是一个 3x3 区域中若干前景像素组成的图案（不同符号的颜色各异，取自红(2)、绿(3)、黄(4)、灰(5)、橙(7)等，每个符号 4-8 个前景像素不等）。符号按粗格子排列，符号之间隔若干行/列背景。区域 A 的某一条外边缘有一条品红(6)标记线。区域 B（较小，约 3x5 的角落区域）：一个红(2)单色模板图形（3-5 像素的 4-连通图形）。各符号的前景像素数（面积）互不相同。

**规则**：
1. 记录区域 A 中每个 3x3 符号的颜色和前景像素数（面积）。
2. 将每个 3x3 符号压缩为一个该颜色的单像素，放在对应粗格子坐标上。
3. 品红(6)标记线指示滑动方向（顶边 → 向右滑动，右边 → 向下滑动，底边 → 向左滑动，左边 → 向上滑动，按顺时针边界行进规则）。将所有压缩像素沿该方向滑动至最紧凑位置（消除空行/列）。
4. 沿滑动方向，将压缩像素按原始面积从大到小重新排列：面积最大的像素移到最靠近标记边的位置，面积最小的最远。同一行/列内多个像素按其垂直于滑动方向的原始坐标保持相对顺序。
5. 以每个重排后的压缩像素位置为锚点（左上角），放置区域 B 中模板的副本，副本着色为该压缩像素的颜色。
6. 从输出中移除分隔线和区域 B。若模板副本之间有重叠像素，后放置的（离标记边更远的）覆盖先放置的。

**关键洞察**：压缩是有损的——所有符号在压缩后都变成相同大小的单像素，面积信息在视觉上消失了。但排序步骤需要这个压缩前的面积信息。求解者必须在压缩前捕获面积差异，才能理解压缩后的排列顺序。

## 新题 8：对角射线长度由分量计数门控

**组合逻辑**：[射线延伸/ray_extend](已有) + [计数/counting](已有) + [重涂色/recolor](已有) + [对角射线/diagonal_ray](已有) + [连通分量计数/component_count](创新：计数结果不再决定重复次数，而是决定射线几何长度)

**来源原语**：射线延伸、对角射线、角点射对角至挡（469497ad）；计数、连通分量计数（b0039139）；重涂色（810b9b61 / b0039139）；标记像素（d43fd935 / 4258a5f9）

**依赖链**：连通分量计数确定射线长度 → 射线从正方形四角沿对角方向延伸 → 射线是否触及标记像素决定该标记是否被重涂色。计数和射线几何紧耦合：计数错则射线长度错，射线长度错则重涂目标错。

计算散布的红色连通分量数量 N，从中心正方形的四角各发射长度为 N 的对角射线，射线触及的标记像素被重涂色。

**输入结构**：约 15x15 网格。黑(0)为背景。一个蓝(1)实心正方形（3x3）位于网格中部附近。网格中散布 2-5 个红(2) 4-连通连通分量（每个 2-5 像素的不规则小图形），各分量互不接触，也不接触蓝(1)正方形。若干黄(4)单像素标记分布在网格各处，部分标记恰好位于蓝正方形某个角沿对角方向延伸 1-6 格的位置上，部分标记不在任何对角线上。生成约束：红色分量数量 N 满足 2 <= N <= 5；至少有 1 个黄色标记位于某条对角射线的第 N 格以内，且至少有 1 个黄色标记位于某条对角射线的第 N 格以外。

**规则**：
1. 计算红(2)连通分量的数量 N（每个 4-连通的红色像素团算一个分量）。
2. 从蓝(1)正方形的 4 个角像素各发射一条对角射线，方向为该角的自然对角方向（左上角 → 左上方，右上角 → 右上方，右下角 → 右下方，左下角 → 左下方）。
3. 每条射线恰好延伸 N 个像素（不是延伸到碰到障碍物，而是精确 N 步）。若射线在 N 步内到达网格边界，则在边界处截断。
4. 射线像素着色为蓝(1)（与正方形同色），绘制在输出上。
5. 若某条射线的路径上经过一个黄(4)标记像素，将该标记重涂为绿(3)。
6. 未被射线经过的黄(4)标记保持黄(4)不变。
7. 红(2)分量和蓝(1)正方形保持原样不变。

**关键洞察**：红色分量不参与任何空间变换——它们唯一的作用是被计数。计数结果门控了射线的几何范围，从而间接决定哪些标记会变色。求解者必须建立"分量数量 = 射线步数"这一非显然映射，才能预测哪些标记被触及。
