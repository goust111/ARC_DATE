## 新题 1：凸起计数排名驱动的分色传播

**组合逻辑**：[凸起/tab 分析](创新：从边界特征分析转为全局计数指标) → [排序/sorting](已有) → [重涂色/recolor](已有) → [邻接传色/adjacency_transfer](已有)

**来源原语**：凸起/tab（8dab14c2）、排序/sorting + 高度排名/height_ranking（a61f2674）、重涂色/recolor（a61f2674, c3fa4749）、邻接传色/adjacency_transfer + 标记接触即赋色/marker_touch_color（b7256dcd）、中性遮罩/neutral_mask（b7256dcd）

**依赖链**：边界凸起计数 → 全局排名确定哪个对象获得哪种颜色 → 重涂色改变对象颜色 → 邻接传色将新颜色传播到相邻中性区域。每一步的输出是下一步不可替代的输入：不计数就无法排名，不排名就不知道涂什么色，不涂色则中性区域无法获得正确传播色。

在黑(0)背景上有若干厚实的直角多边形前景对象和相邻的中性区域，通过分析每个对象的边界凸起数量进行全局排名，将极值排名对象分别涂为指定颜色，再将新颜色传播到各对象相邻的中性区域。

**输入结构**：约 18x18 的网格，背景为黑(0)。包含 3~5 个互不相邻的灰(5) 4-连通厚实直角多边形前景对象（每个对象约 8~20 像素，宽度至少 2 像素，形状各异——有的呈阶梯状、有的呈凹字形等）。每个对象的边界上有若干 1 像素凸起（凸起定义：仅有 1 个同色 4-邻居的边界像素）。每个对象的凸起数量互不相同（生成约束）。每个对象至少有一个边（可多个边）与一片橙(7)的中性遮罩区域 4-邻接，中性区域为 2~6 像素的 4-连通分量，彼此不相邻，且每个中性区域只与一个灰对象邻接（生成约束）。

**规则**：
1. 对每个灰(5)前景对象，计算其边界凸起数量（凸起 = 恰好有 1 个灰色 4-邻居的灰色像素）。
2. 将凸起数最多的对象重涂为蓝(1)，凸起数最少的对象重涂为红(2)，其余对象保持灰(5)不变。
3. 对每个橙(7)中性遮罩区域，找到与其 4-邻接的前景对象（经步骤 2 可能已变色），将该中性区域重涂为该对象当前的颜色。
4. 其余所有像素（背景、不与任何中性区域相关的像素）保持不变。

**关键洞察**：凸起不是需要补全的边界缺陷，而是全局排名的计数依据——必须遍历所有对象统计凸起后才能确定哪个对象获得哪种颜色，而颜色传播到中性区域又依赖排名结果，形成跨对象的信息聚合链。

## 新题 2：对称补全揭示隐藏连接器的拼装

**组合逻辑**：[对称补全/symmetry_completion](创新：补全的目的不是视觉修复而是揭示隐藏的连接信息) → [同色标记对齐对接/same_color_dock](已有) → [裁剪/crop](已有)

**来源原语**：对称补全/symmetry_completion + 双轴镜像轨道/two_axis_orbit + 缺失像素/missing_pixel（af22c60d）、同色标记对齐对接/same_color_dock + 连接标记/connector_marker + 标记侧面决定方向/marker_side_dir（e9fc42f2）、裁剪/crop（1990f7a8）

**依赖链**：每个物体有黑(0)缺失像素破坏了其二轴对称 → 对称补全恢复完整图案 → 补全后的像素中出现了之前被遮蔽的连接器标记颜色 → 用标记颜色匹配进行对接拼装 → 裁剪输出。对称补全不仅修复外观，更是"解密"步骤：不补全就看不到连接器，无法决定如何拼装。

将若干带有缺失像素的多色前景物体进行二轴对称补全以揭示隐藏的连接器标记颜色，然后按同色标记对接拼装所有物体，紧凑裁剪输出。

**输入结构**：约 20x20 的网格，背景为黑(0)。包含 3~4 个互不重叠的多色 4-连通前景物体，彼此间距至少 3 像素。每个物体主体为蓝(1)，约 5x5~7x7 像素，本身具有关于水平轴和垂直轴的二轴对称结构。但每个物体有 2~4 个像素被替换为黑(0)（缺失），破坏了对称性。在补全这些缺失像素后，部分恢复的像素颜色不是蓝(1)而是特定的连接器颜色（红(2)、绿(3)、黄(4)等），且这些连接器像素恰好位于物体边界上。每种连接器颜色恰好出现在两个不同物体上（生成约束），形成配对。连接器像素所在物体边界的朝向（上/下/左/右）决定了对接方向。

**规则**：
1. 对每个前景物体，确定其二轴对称的水平和垂直反射轴（从可见的非缺失像素推断）。
2. 对每个黑(0)缺失像素，收集其水平镜像、垂直镜像和双轴镜像位置上的已知颜色（仅考虑物体边界框内的镜像位置），将缺失像素填充为轨道内的唯一已知颜色。
3. 补全后，识别每个物体边界上的非主体色（非蓝(1)）像素作为连接器标记。
4. 对每对同色连接器标记，将两个物体平移对接：两个标记像素在各自物体边界的外露方向相对，平移后标记像素边对边接触。若标记在物体右边界则该物体从左侧靠近，若在上边界则从上方靠近，以此类推。
5. 当有多对连接器时，按连接器颜色在调色板中的编号从小到大依次对接（先对接红(2)、再绿(3)、再黄(4)等）。每次对接固定已对接的物体组，新物体向已对接组平移。
6. 对接完成后，输出所有物体的紧凑裁剪（最小包围框），背景填黑(0)。

**关键洞察**：黑色缺失像素不是随机破损——它们精确遮蔽了连接器标记的位置，使得不做对称补全就无法发现物体间的拼装关系。对称补全是一个"信息解密"步骤，而非纯粹的视觉修复。

## 新题 3：平移后的空位需要瓦片图案恢复

**组合逻辑**：[重复色才移动/repeated_color_moves + 平移/translate](已有) → [可见像素约束推断/infer_from_visible + 平铺/tiling](已有，创新：推断对象从"修复遮挡"变为"填补因平移产生的空位") → 渲染合成

**来源原语**：平移/translate + 重复色才移动/repeated_color_moves + 边界矩形/boundary_rectangle + 贴边定位/border_aligned（22208ba4）、平铺/tiling + 重复瓦片/repeating_tile + 遮挡区域/occluded_region + 可见像素约束推断/infer_from_visible（ca8f78db）

**依赖链**：首先识别哪些矩形需要平移（重复色条件）→ 平移后原位置变为"空洞" → 空洞区域的正确内容必须从剩余可见背景瓦片推断 → 同时新位置的矩形覆盖了部分瓦片。平移改变了可见瓦片像素的分布，瓦片推断必须在考虑所有矩形最终位置后进行。

在以重复瓦片图案为背景的网格中，将贴边的重复色矩形向内平移，然后用推断出的瓦片图案填充平移留下的空位。

**输入结构**：约 16x16 的网格。背景不是单色，而是由一个 2x2 或 3x3 的小瓦片重复平铺而成（瓦片使用蓝(1)、绿(3)两种颜色构成周期图案）。在网格的 2~3 个角落处，各有一个纯色实心矩形（约 3x4 像素），贴着网格边角放置。其中恰好有一种前景颜色出现了 2 次（即两个矩形同色，如红(2)），其余颜色各出现 1 次（如黄(4)出现 1 次）。矩形覆盖了其下方的瓦片图案。矩形颜色均不同于瓦片使用的颜色（生成约束）。矩形互不重叠，且平移后也互不重叠（生成约束）。

**规则**：
1. 识别前景矩形中出现多次的颜色（重复色）。同色出现一次的矩形为静止矩形，保持不动。
2. 将每个重复色矩形从其贴边位置沿对角方向（远离所贴的行边界和列边界）平移，平移距离等于矩形自身的高度（行方向）和宽度（列方向）。
3. 平移后，原位置和新位置都需要确定最终内容：
   - 原位置（矩形离开后的空白区域）：这些像素不再被矩形遮挡，用瓦片图案填充。
   - 新位置（矩形移入的区域）：矩形覆盖在瓦片之上，矩形颜色优先显示。
4. 从所有未被任何矩形（包括静止和平移后位置）覆盖的瓦片像素推断瓦片的最小重复单元和相位。
5. 用推断的瓦片填充所有空白区域（原位置的空洞）。静止矩形和平移后的矩形保持不变。

**关键洞察**：平移操作同时制造了需要填充的空洞和新的遮挡区域，而瓦片推断必须排除所有矩形（静止的和移动后的）占据的位置，仅从剩余的可见瓦片像素恢复完整图案。两个操作（平移与瓦片恢复）的约束域相互交叉。

## 新题 4：缺口方位编码反射轴的条件拼接

**组合逻辑**：[缺口/notch 方位检测](创新：缺口从"需要补全的缺陷"变为"编码变换指令的信号") → [镜像/reflect](已有) → [拼接/concatenate](已有)

**来源原语**：缺口/notch + 凸起/tab + 跨行列投射/cross_span_projection（8dab14c2）、镜像/reflect + 纵向拼接/vertical_stacking + 对称翻转追加/symmetric_appending_reversed_rows（8be77c9e）、拼接/concatenate（8be77c9e）

**依赖链**：分析前景对象边界上缺口的分布方位 → 方位决定沿哪个轴做镜像 → 将原图与镜像拼接。缺口不是需要修复的破损，而是隐式指令——其所在方位编码了应执行的反射操作。如果不正确读取缺口方位，就无法确定反射轴，输出尺寸和内容都会错误。

分析前景对象边界缺口所在的方位（上/下/左/右），将该方位解读为反射轴指令，沿对应轴镜像整个网格并拼接。

**输入结构**：约 8x8 的网格，背景为黑(0)。中央有一个灰(5)厚实直角多边形前景对象（约占网格面积的 40%~60%，宽度至少 3 像素，具体形状在不同示例中各异）。该对象的边界上有 1~2 个缺口（缺口定义：一个黑(0)像素，其 4-邻居中恰好有 3 个是灰(5)前景像素）。所有缺口都位于对象的同一侧边界上（如全在右侧边界、或全在底部边界）（生成约束）。对象边界上没有凸起（凸起 = 仅 1 个同色 4-邻居的边界像素）（生成约束，确保缺口是唯一的边界特征信号）。

**规则**：
1. 找到前景对象边界上所有缺口（黑(0)像素，4-邻居中恰好 3 个为前景色）。
2. 判断缺口所在的方位：若所有缺口的列坐标都等于对象包围框的最大列，则方位为"右"；若都等于最小列，则为"左"；若所有缺口的行坐标都等于对象包围框的最大行，则为"下"；若都等于最小行，则为"上"。
3. 根据方位执行反射拼接：
   - "右"：将整个网格水平镜像，拼接在原图右侧（输出宽度 = 原宽 x 2，高度不变）。
   - "左"：将整个网格水平镜像，拼接在原图左侧。
   - "下"：将整个网格垂直镜像，拼接在原图下方（输出高度 = 原高 x 2，宽度不变）。
   - "上"：将整个网格垂直镜像，拼接在原图上方。
4. 拼接后，原图在前（左/上），镜像在后（右/下）。对于"左"和"上"方位，镜像在前，原图在后。
5. 拼接缝处，缺口与其镜像中对应的凸出部分互相咬合，形成无缝对称图案。

**关键洞察**：缺口不是需要"对侧互补"修复的破损（与参考题 8dab14c2 的用法完全不同），而是变换指令的隐式编码——缺口的方位直接指定了镜像反射的轴向。求解者必须从多个示例中归纳出"缺口方位 = 反射方向"这一非显然映射。

## 新题 5：压缩介导的面板序列外推

**组合逻辑**：[压缩/compress + 分区采样/block_sampling](已有) → [序列外推/sequence_extrapolation](创新：外推发生在压缩表示上而非原始像素上) → [像素放大/pixel_upscale](已有，作为逆压缩的扩展回复)

**来源原语**：压缩/compress + 分区采样/block_sampling + 分区网格/partitioned_grid（5783df64）、序列外推/sequence_extrapolation + 面板帧/panel_frame + 分隔行/separator_row + 恒定偏移平移/constant_offset_translation（351d6448）、像素放大/pixel_upscale（c59eb873）

**依赖链**：将每个面板压缩为摘要网格 → 在压缩序列上识别外推规则（像素级规则在全尺寸面板上被噪声干扰，压缩后才可见） → 生成下一帧压缩摘要 → 将摘要扩展回全尺寸面板。压缩是"看见"规律的前提，外推是生成新帧的手段，扩展是还原尺度的必要步骤。

输入是一叠面板，每个面板是可按分区压缩的大网格；压缩后的摘要序列呈现出简单的平移规律，外推出下一帧摘要后再扩展回全尺寸输出。

**输入结构**：约 30x10 的网格（高远大于宽）。由灰(5)全宽分隔行分为 3 个等高面板，每个面板为 9x9（即 9 行 10 列中 9 列为面板内容，含左右各可能的边距）。实际面板内容区为 9x9。每个面板可视为 3x3 的分区网格（每个分区为 3x3 的子块）。背景为黑(0)。每个 3x3 子块中恰好有 1 个非黑前景像素（颜色为红(2)、蓝(1)、绿(3)等），其余为黑(0)。从面板 1 到面板 3，前景像素在各子块内的位置可能变化，但压缩后（每个子块取其唯一前景色）得到的 3x3 摘要网格呈现简单的空间变换规律：整个前景图案在 3x3 摘要中以恒定偏移平移（如每帧向右移 1 列，循环回绕）。不同示例中平移方向和步长不同（生成约束：平移规律在 3 帧内可唯一确定）。

**规则**：
1. 用灰(5)分隔行将输入切分为 3 个面板，每个面板是 9x9 网格。
2. 将每个面板按 3x3 分区压缩：每个 3x3 子块中的唯一非黑色成为对应摘要像素的颜色，得到 3x3 摘要网格。

5. 在所有精灵体中，找到唯一一个完整落在引导掩码包围框内的精灵体。

## 新题 8：跨轴就近填色后连线至匹配框边

**组合逻辑**：[填充/fill](创新：填色规则由跨轴最近框边决定，不是简单最近距离) → [连线/connect + 颜色对应边/color_to_side](已有) → 冲突解决

**来源原语**：填充/fill + 包含于/contained_in（c3fa4749）、连线/connect + 矩形框/rect_frame + 颜色对应边/color_to_side + 散落连接同色框边/scatter_connect_side（5daaa586）、封闭区域/enclosed_region（ac6f9922）

**依赖链**：分析每个空区域相对框边的位置 → 用"跨轴"规则确定填色（不是最近框边，而是最近的垂直方向框边） → 填色结果决定连线目标 → 连线路径受其他已填区域约束。填色规则本身需对比多个示例才能归纳（初看像最近距离，实则是跨轴规则）。

在矩形框内的空封闭区域中，用垂直于其主轴方向上最近的框边颜色进行填充，然后从每个填色区域向同色框边画直线连接。

**输入结构**：约 14x14 的网格，背景为黑(0)。网格内有一个矩形框，由 4 条不同颜色的单像素线段构成：顶边为蓝(1)，底边为红(2)，左边为绿(3)，右边为黄(4)。框内部（边框围成的区域）背景为黑(0)。框内有灰(5)像素构成 2~3 道直线隔墙（水平或垂直，宽 1 像素，两端连接到框边），将框内空间分隔成 3~5 个互不连通的封闭区域。每个封闭区域内初始全为黑(0)。隔墙将框内空间分为形状不同、位置各异的区域（生成约束：每个区域的中心到水平框边的最短距离与到垂直框边的最短距离不相等，确保主轴方向可唯一判定）。

**规则**：
1. 识别矩形框的 4 条边及其颜色：上蓝(1)、下红(2)、左绿(3)、右黄(4)。
2. 识别框内所有由灰(5)隔墙分隔出的封闭区域（每个区域为 4-连通的黑(0)分量，被灰(5)隔墙和/或框边完全包围）。
3. 对每个封闭区域，计算其质心（所有像素坐标的均值）到 4 条框边的曼哈顿距离。确定该区域的"主轴方向"——若到上/下框边的最小距离 < 到左/右框边的最小距离，则主轴为垂直方向（离水平边更近）；否则主轴为水平方向。
4. 跨轴填色：主轴为垂直方向的区域，取其到左/右框边中较近一侧的颜色进行填充；主轴为水平方向的区域，取其到上/下框边中较近一侧的颜色进行填充。即填色方向与主轴垂直（"跨轴"）。
5. 填色后，从每个区域的质心位置向同色框边画一条直线（沿水平或垂直方向，取能直达目标框边的方向）。直线颜色为该区域的填充色。
6. 直线仅覆盖黑(0)背景像素和灰(5)隔墙像素，不覆盖已填色的其他区域像素。若直线路径经过另一个已填色区域，直线在该区域边界处截止（不穿透）。
7. 绘制顺序：按区域质心行坐标从小到大（行相同则列坐标从小到大）依次处理。

**关键洞察**：填色规则不是"取最近框边颜色"的直觉答案，而是"跨轴"规则——离水平边更近的区域反而用垂直边（左/右）的颜色填充，离垂直边更近的区域反而用水平边（上/下）的颜色填充。这个反直觉的映射必须通过对比多个示例中不同位置区域的填色结果才能归纳。

## 新题 10：图例展开串按竖直线段高度排序堆叠

**组合逻辑**：[展开/expand + 图例锚定对齐/legend_anchored_alignment](已有) → [排序/sorting + 高度排名/height_ranking](创新：排序依据从竖直线段自身高度变为"与标记同色的竖直线段的高度") → [纵向拼接/vertical_stacking](已有)

**依赖链**：每个标记像素展开为图例串（确定内容行） → 每个标记的颜色关联到同色竖直线段 → 线段高度决定展开行的堆叠顺序。展开和排序使用同一组标记颜色但提取不同信息（展开用颜色在图例中的位置，排序用颜色对应线段的高度），两条信息流在堆叠步骤汇合。

**输入结构**：约 15x12 的网格，背景为黑(0)。结构分为三个区域：

顶部区域（第 0 行）：一行水平的边缘图例串，包含 K 种不同前景颜色（K 在 3~5 之间），如 [蓝(1), 红(2), 绿(3), 黄(4)]，从左侧开始连续排列，其余位置为黑(0)。

中部区域（第 2~6 行左右）：K 个孤立标记像素（单像素），每个标记颜色恰好是图例串中的某一种颜色，且每种颜色恰好一个标记。标记散落在中部区域的不同行和列上（每个标记在不同行，生成约束）。

底部区域（第 8 行至底部）：K 条竖直线段（每条宽 1 像素），颜色分别与图例串中的 K 种颜色一一对应。线段底端对齐（都在最后一行），高度各不相同（高度范围 2~6 像素），线段之间至少间隔 1 列。各线段高度互不相同（生成约束）。

各区域之间有至少 1 行黑(0)背景间隔。

**规则**：
1. 识别顶部图例串：第 0 行中所有非黑像素构成的水平颜色序列 L = [L0, L1, ..., L_{K-1}]。
2. 识别中部的 K 个孤立标记像素及其颜色和所在行。
3. 对每个标记，执行图例展开：将图例串 L 水平放置在标记所在行上，位移使得 L 中与标记同色的那个位置对齐到标记的列坐标上。展开结果超出网格左右边界的部分舍弃。
4. 识别底部的 K 条竖直线段及其颜色和高度。
5. 为每个标记赋予排序键：找到与标记同色的竖直线段，取其高度作为排序键。
6. 按排序键从大到小（最高线段对应的标记排在最上方）排列所有展开行。
7. 将排序后的 K 行展开结果紧密纵向堆叠（无间隔行），形成 K 行 x 网格宽度的输出。

**关键洞察**：图例串同时扮演两个角色——它是展开操作的模板（标记展开为完整图例），也通过颜色将标记与竖直线段关联起来。展开使用标记颜色在图例中的位置来对齐，排序使用标记颜色对应线段的高度来排名——两个操作从同一颜色中提取了完全不同的信息维度。
