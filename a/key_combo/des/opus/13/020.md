## 新题 1：引导条投射决定矩形内部填充色

**组合逻辑**：[投射到引导条/project_to_guide](创新：投射结果不是压缩到引导条旁，而是路由到对应矩形) + [投射落间隙则擦/erase_if_gap](已有) + [仅内部像素变色/only_interior_recolored](已有，创新：填充色不固定为红，而由投射的标记像素颜色决定)

**来源原语**：投射到引导条、引导条、散布像素、投射落间隙则擦（来自 f83cb3f6）；实心矩形、内部与边框、仅内部像素变色（来自 bb43febb）；填充（来自 3eda0437）

**依赖链**：引导条的间隙模式决定哪些散布像素有效 -> 有效像素的投射列决定其路由到哪个矩形 -> 被路由的像素颜色决定该矩形内部的填充色。删除引导条间隙过滤则无法区分有效/无效像素；删除列范围匹配则像素与矩形的对应关系不确定；删除内部/边框区分则重涂范围不确定。

引导条过滤散布像素的有效性，有效像素按列范围路由到对应矩形并决定其内部填充色。

**输入结构**：约 15x20 的网格，黑(0)背景。网格中有 2-4 个灰(5)实心轴对齐矩形（每个高 >= 3、宽 >= 3），互不重叠且互不接触。一条水平绿(3)引导条横跨网格全宽，位于某行，厚度一个像素，其中有 1-3 个间隙（间隙处为黑(0)而非绿(3)）。引导条上方和下方散布着若干孤立彩色像素（每个占一格，颜色取自 {蓝(1), 红(2), 黄(4), 橙(7)}），这些像素互不接触，也不接触任何矩形。生成约束：每个矩形的列范围内，引导条的非间隙列中至多有一个散布像素的投射落入，保证每个矩形至多获得一种填充色。

**规则**：
1. 对每个散布彩色像素，沿垂直方向向引导条投射（在引导条上方的向下投射，在下方的向上投射），找到引导条在同一列的单元格。
2. 若该列的引导条单元格为绿(3)（非间隙），则该像素"有效"——找到列范围包含该投射列的灰(5)矩形。
3. 若该列的引导条单元格为黑(0)（间隙），则该像素"无效"，对输出无影响。
4. 对每个有恰好一个有效投射像素落入其列范围的灰矩形：将该矩形的内部单元格（严格位于一格厚边框以内的所有单元格）重涂为该投射像素的颜色。矩形边框仍为灰(5)。
5. 没有有效投射像素的矩形保持全部灰(5)不变。
6. 所有散布像素留在原位不变。引导条保持不变。

**关键洞察**：引导条同时承担空间过滤器（间隙使标记失效）和位置路由器（引导条列将标记映射到矩形）的双重角色；矩形的填充色既非固定也非来自自身属性，而是由远处的散布像素经过引导条中介后间接决定的。

## 新题 2：镜像十字架的间隙擦除

**组合逻辑**：[镜像/mirror](已有) + [控制定颜色映射/ctrl_color_map](已有) + [擦除/erase](创新：擦除规则不是基于中轴列，而是基于十字架分隔线中的间隙位置，间隙所在行/列的所有象限内容被擦除)

**来源原语**：镜像、模板块、象限、控制像素、翻转对应、控制定颜色映射（来自 cfb2ce5a）；擦除（来自 d23f8c26）；引导条、投射落间隙则擦（来自 f83cb3f6）

**依赖链**：镜像翻转生成四象限内容 -> 控制像素重涂改变各象限颜色 -> 十字架间隙确定擦除的行/列 -> 擦除破坏镜像对称性。删除镜像步骤则象限内容不存在；删除间隙擦除则输出保持完美对称（与实际输出不符）；间隙的非对称分布使得两侧象限受到不同程度的破坏，必须对比多个示例才能归纳出"间隙行全擦"的规则。

镜像模板到四象限并用控制像素重涂，然后十字架分隔线的间隙选择性擦除对应行/列的象限内容。

**输入结构**：一个 (2K+1)x(2K+1) 的正方形网格（如 11x11 或 13x13），黑(0)背景。网格中央有一个绿(3)十字形结构（+），由一整行和一整列组成，将网格分为四个 KxK 象限。十字的交叉单元格始终为绿(3)，但十字的行部分或列部分中有 1-3 个间隙（该位置为黑(0)而非绿(3)）。左上象限包含一个由蓝(1)和红(2)两种颜色在黑(0)上构成的完整模板图案（4-连通的不规则图形片段，3-8 像素）。其余三个象限仅包含稀疏的控制像素（非黑、非绿的孤立像素），其余为黑(0)。

**规则**：
1. 将左上象限的模板翻转到其他三个象限：右上象限为水平翻转，左下象限为垂直翻转，右下象限为双轴翻转。
2. 在每个非左上象限中，对每个控制像素位置，将该位置翻转后的模板像素颜色替换为控制像素的颜色；没有对应控制像素的翻转模板位置变为黑(0)。左上象限保持不变。
3. 完成四象限后，处理绿(3)十字的间隙：
   - 对于中央列中的每个间隙（黑(0)单元格）：将该间隙所在行中、左右两个象限内的所有非绿像素擦除为黑(0)。
   - 对于中央行中的每个间隙（黑(0)单元格）：将该间隙所在列中、上下两个象限内的所有非绿像素擦除为黑(0)。
4. 绿(3)十字像素（包括交叉点）保持不变。已经为黑的单元格不受影响。

**关键洞察**：绿色十字架同时担当镜像对称轴（定义象限结构）和擦除引导条（其间隙选择性地破坏镜像结果）的双重角色。中央列中的一个间隙会擦除一整行的象限内容，但左右象限包含模板的不同翻转版本，因此同一个间隙对左右两侧产生了视觉上不对称的破坏效果。

## 新题 3：邻接投票决定逐分量重力方向

**组合逻辑**：[边邻接计数/edge_adjacency_count + 邻接多数决/adjacency_majority_rule](创新：投票结果不决定颜色，而决定物理运动方向) + [重力下落/gravity_drop + 碰撞停止/collision_stop](创新：重力方向不固定为向下，而由投票结果逐分量设定)

**来源原语**：边邻接计数、邻接多数决、标记像素、连通分量（来自 477d2879）；重力下落、碰撞停止、障碍物、沿路径滑动（来自 28a6681f）

**依赖链**：标记像素颜色编码方向 -> 邻接多数决为每个分量确定重力方向 -> 各分量按确定方向滑动直到碰撞停止 -> 先处理的分量沉积后成为后续分量的障碍。删除邻接投票则方向不确定；删除重力模拟则像素不移动；删除处理顺序则碰撞结果有歧义。

每个蓝色连通分量通过其侧邻标记像素的多数颜色投票获得独立的重力方向，然后按该方向滑动至碰撞停止。

**输入结构**：约 15x15 的网格，黑(0)背景。网格中有 2-4 个不相交的 4-连通蓝(1)分量（每个 3-8 像素，不规则形状——非矩形，可含弯折或分支结构）。分量周围放置若干孤立标记像素，颜色编码方向：红(2)代表向下、绿(3)代表向左、黄(4)代表向右、橙(7)代表向上。每个标记像素与恰好一个蓝分量有至少一条共享边（4-邻接）。灰(5)像素组成静态墙壁和表面，分布在网格中形成阻挡结构。生成约束：每个分量至少有 2 个侧邻标记像素；每个分量的多数标记颜色唯一（无平局）；各分量按其确定方向运动时的路径互不冲突（不会两个分量同时驶向同一区域）。

**规则**：
1. 对每个蓝(1)连通分量，统计与其边(side)邻接的标记像素中各颜色的数量（一个标记像素与分量共享的每条边各贡献一次计数）。
2. 计数最高的标记颜色确定该分量的重力方向：红(2)=下、绿(3)=左、黄(4)=右、橙(7)=上。
3. 按分量大小从大到小排序处理。大小相同时，按分量边界框左上角的行优先列次之排序。
4. 依次处理每个分量：将该分量所有像素同时沿确定方向逐格移动，直到分量中每个像素都被灰(5)墙壁、网格边缘或先前已沉积的其他分量像素阻挡而停止。
5. 沉积后的蓝像素保持蓝(1)。标记像素和灰墙保持不变。
6. 蓝像素移动前的原始位置变为黑(0)。

**关键洞察**：邻接多数决机制从"颜色分配"被重新用途为"物理方向分配"——同一网格上的不同分量可以拥有不同的重力方向。处理顺序（大分量先移动）意味着先沉积的分量会成为后续分量的障碍，产生涌现的堆叠效果。

## 新题 4：全局扫描序循环染色驱动矩形内部填充

**组合逻辑**：[扫描序/scan_order + 长轴决定扫描/longer_axis_determines_scan + 颜色循环分配/cyclic_color_assignment](创新：循环分配的颜色不是最终输出色，而是中间标记，作为后续邻接投票的候选色) + [边邻接计数/edge_adjacency_count + 邻接多数决/adjacency_majority_rule](创新：投票标记不是预设的静态像素，而是前一步骤动态生成的) + [仅内部像素变色/only_interior_recolored](已有)

**来源原语**：扫描序、长轴决定扫描、颜色循环分配、孤立像素（来自 9473c6fb）；边邻接计数、邻接多数决、标记像素（来自 477d2879）；实心矩形、内部与边框、仅内部像素变色（来自 bb43febb）

**依赖链**：前景像素包围框形状决定扫描方向 -> 扫描方向决定像素排序 -> 排序决定循环染色结果 -> 染色后的像素颜色作为标记参与矩形邻接投票 -> 投票结果决定矩形内部填充色。移动任一前景像素可能改变包围框形状从而翻转扫描方向，进而改变所有像素颜色和所有矩形填充。

散布像素按包围框长轴方向扫描排序后循环染为三色，然后各矩形按侧邻染色像素的多数色决定内部填充色。

**输入结构**：约 15x18 的网格，黑(0)背景。网格中有 2-4 个灰(5)实心轴对齐矩形（每个高 >= 3、宽 >= 3），互不重叠，彼此之间有间距。矩形外散布着 6-12 个孤立蓝(1)前景像素（每个占一格，互不相邻，也不接触任何矩形边框）。生成约束：经循环染色后（见下），每个矩形至少有一个染色后的像素与其边框 4-邻接；每个矩形的侧邻染色像素中多数颜色唯一（无平局）。

**规则**：
1. 计算所有蓝(1)前景像素的轴对齐包围框。
2. 若包围框高度 >= 宽度，按行优先序排列所有蓝像素（从上到下，同行从左到右）；否则按列优先序排列（从左到右，同列从上到下）。
3. 按排列顺序对像素循环染色：第 1 个变红(2)、第 2 个变青(8)、第 3 个变绿(3)、第 4 个变红(2)、第 5 个变青(8)，依次循环。
4. 对每个灰(5)矩形，考察所有与其边框单元格 4-邻接（共享一条边）的染色后像素（红/青/绿），统计各颜色的邻接数。
5. 邻接数最多的颜色成为该矩形的内部填充色：将矩形内部（严格在一格厚边框以内的单元格）重涂为该颜色。
6. 矩形边框保持灰(5)。没有任何邻接染色像素的矩形内部保持灰(5)。
7. 染色后的像素留在原位保持其新颜色不变。

**关键洞察**：全局决策（包围框形状 -> 扫描方向）影响所有像素的颜色分配，而这些颜色又局部地决定每个矩形的填充。移动一个像素可能改变包围框的长宽比，从而翻转扫描方向，导致所有像素颜色重新分配，继而所有矩形填充色全部改变——这种全局-局部耦合使得问题不可分解。

## 新题 5：引导条投射生成路径障碍

**组合逻辑**：[投射到引导条/project_to_guide + 投射落间隙则擦/erase_if_gap](创新：投射结果不是压缩显示，而是在引导条旁生成障碍物) + [路径绘制/path_drawing + 绕行/detour](创新：绕行方向不由障碍颜色决定，而由障碍相对于引导条的上下位置决定)

**来源原语**：投射到引导条、引导条、散布像素、投射落间隙则擦（来自 f83cb3f6）；路径绘制、绕行、边界标记、障碍条、阻挡、障碍色决定绕行（来自 96a8c0cd）

**依赖链**：引导条间隙决定哪些散布像素被过滤 -> 有效像素投射到引导条旁形成障碍 -> 障碍的上下位置（相对引导条）决定绕行方向 -> 红色轨迹绕过所有障碍画出路径。删除投射步骤则障碍不存在；删除间隙过滤则障碍过多或位置错误；删除路径绘制则无输出轨迹。引导条同时承担投射过滤器、障碍定位参考和绕行方向隐式决定者三重角色。

散布像素经引导条投射过滤后在引导条旁生成障碍，红色边界标记沿水平方向绘制轨迹，遇障碍时根据其位于引导条上方或下方决定绕行方向。

**输入结构**：约 12x20 的网格，黑(0)背景。一条水平绿(3)引导条位于网格垂直中部附近的某行，厚度一个像素，横跨网格大部分宽度，其中有 1-3 个间隙（黑(0)单元格）。4-8 个散布蓝(1)像素分布在引导条上方和下方（与引导条垂直距离至少 2 格），互不共列。一个红(2)标记像素位于网格左边界（第 0 列），所在行与引导条不同行。生成约束：无两个蓝像素共享同一列；每个蓝像素所在列要么有绿引导像素要么是间隙；投射后的障碍互不相邻列（保证绕行路径不重叠）。

**规则**：
1. 对每个蓝(1)像素，沿垂直方向向引导条投射：
   - 若蓝像素在引导条上方，检查其同列引导条单元格。若为绿(3)，在该列引导条正上方一格（guide_row - 1）放置一个蓝(1)障碍像素。若为间隙（黑(0)），不生成障碍。
   - 若蓝像素在引导条下方，同理：若同列引导条为绿(3)，在引导条正下方一格（guide_row + 1）放置蓝(1)障碍。若为间隙则不生成。
2. 擦除所有散布蓝像素的原始位置（投射消耗了它们），原位变黑(0)。
3. 红(2)标记从左边界沿其所在行向右开始绘制轨迹。
4. 当轨迹遇到同行的蓝(1)障碍像素时绕行：
   - 若障碍在引导条上方（位于 guide_row - 1）：轨迹向下绕行——依次向下一格、向右一格、向上一格，然后恢复向右行进。
   - 若障碍在引导条下方（位于 guide_row + 1）：轨迹向上绕行——依次向上一格、向右一格、向下一格，然后恢复向右行进。
5. 轨迹继续向右直到网格右边缘。仅轨迹经过的黑(0)单元格变为红(2)。
6. 引导条、障碍像素和其他非黑单元格不被轨迹覆盖。
7. 若绕行路径中某步会超出网格边界，轨迹在边界处停止。

**关键洞察**：引导条身兼三职——投射有效性过滤器（间隙使像素失效）、障碍定位参考（障碍固定在引导条上下一格）、绕行方向的隐式决定者（障碍在引导条上方则轨迹向下绕，下方则向上绕）。散布像素的位置与引导条的间隙模式共同决定障碍布局，障碍布局再决定轨迹形状。

## 新题 6：压缩区域色经偏移阴影合并后平铺

**组合逻辑**：[压缩/compress + 每区域折叠单像素/region_to_pixel](已有) + [偏移阴影/offset_shadow + 列环绕/column_wrapping](创新：阴影落在已有前景像素上时不覆盖也不忽略，而是合并为第三种颜色) + [平铺/tiling](已有，但平铺的瓦片内容是经过阴影合并标注后的压缩结果)

**来源原语**：压缩、分隔线、色块区域、网格分区、每区域折叠单像素（来自 780d0b14）；偏移阴影、列环绕、偏移、阴影像素、瓦片（来自 310f3251）；平铺（来自 310f3251）

**依赖链**：分隔线定位 -> 区域压缩为小网格 -> 偏移阴影叠加（含列环绕和合并判定）-> 合并后的小网格作为瓦片平铺。橙(7)合并标记只有同时知道压缩布局和阴影偏移规则才能确定；平铺后环绕阴影跨瓦片连接形成连续对角线的涌现效应需要理解列环绕。

黑线分隔区域压缩为小色块网格，对其施加左上偏移阴影（列环绕），前景与阴影重叠处合并为橙色，然后 3x3 平铺输出。

**输入结构**：约 15x15 的网格，由一格厚的全黑(0)行和全黑(0)列分隔成矩形区域，形成小型 NxM 布局（N, M >= 2，如 3x3 或 3x4）。每个区域内散布着同一种非黑颜色的若干像素（颜色取自 {蓝(1), 红(2), 绿(3), 黄(4), 灰(5), 青(8)}）。没有区域使用橙(7)或品红(6)。分隔线为单格厚的全黑行/列。生成约束：N 和 M 均 >= 2；压缩后的小网格中，至少有一个前景像素的左上偏移位置 (row-1, (col-1) mod M) 也是前景像素（保证至少出现一次合并）。

**规则**：
1. 找到所有水平和垂直黑色分隔线（全黑的行和列）。
2. 压缩：每个分隔线之间的矩形区域输出一个像素，颜色为该区域内的非黑颜色。生成 NxM 小网格。
3. 在压缩后的 NxM 小网格中，对每个前景（非黑）像素在位置 (r, c)，计算阴影位置 (r-1, (c-1) mod M)——上移一行、左移一列并在左边界环绕到最右列。
4. 在每个阴影位置：
   - 若该位置当前为黑(0)，放置品红(6)阴影像素。
   - 若该位置已有前景色（来自压缩结果），替换为橙(7)——表示前景与阴影的合并。
5. 未被阴影覆盖的前景像素保持其压缩颜色不变。
6. 将标注后的 NxM 小网格 3x3 平铺，生成 (3N)x(3M) 的输出网格。

**关键洞察**：列环绕使最左列前景像素的阴影出现在最右列；平铺后这些环绕阴影与相邻瓦片的阴影无缝衔接，形成跨瓦片边界的连续对角线效果。橙(7)合并标记揭示了压缩图案与其偏移阴影在空间上的重叠位置——这种重叠模式是压缩布局和偏移规则共同作用的涌现结果，不能从任一单独步骤预测。

## 新题 7：面板叠加几何与跨面板邻接投票染色

**组合逻辑**：[透明叠加/transparent_overlay + 位置对齐/positional_alignment](创新：叠加结果不是背景交集标记，而是前景交集——两面板都有灰的位置才保留为"确认"区域) + [边邻接计数/edge_adjacency_count + 邻接多数决/adjacency_majority_rule](创新：参与投票的标记像素来自两个面板的叠加，产生跨面板的标记-形状邻接关系)

**来源原语**：透明叠加、面板、分隔行、位置对齐、双面板背景交集（来自 0c9aba6e）；边邻接计数、邻接多数决、标记像素、连通分量（来自 477d2879）；重涂色（来自多题）

**依赖链**：面板叠加决定哪些形状区域存活（几何交集）-> 存活区域的 4-连通分量作为投票目标 -> 两面板的标记像素叠加到同一坐标系后参与邻接投票 -> 投票多数色决定各分量的最终颜色。面板 A 中远离灰形状的标记可能在对齐后恰好与来自面板 B 的灰像素相邻——这种跨面板中介只在叠加后出现。

两面板中灰色形状的位置交集形成确认区域，两面板标记像素叠加后对各确认分量进行邻接多数投票决定其颜色。

**输入结构**：约 (2H+1) x W 的网格（如 15x12），黑(0)背景。一整行黄(4)分隔行将网格分为上下两个相等的 HxW 面板。每个面板包含：1-3 个灰(5)的 4-连通形状（不一定是矩形，每个 4-12 像素，可包含弯折和不规则轮廓）；2-6 个孤立彩色标记像素（颜色取自 {蓝(1), 红(2), 绿(3), 橙(7)}），每个占一格，在本面板内不接触任何灰形状。生成约束：叠加后至少存在 2 个确认灰分量，每个分量的邻接标记中多数颜色唯一（无平局）；至少一个面板 A 的标记在对齐后与包含面板 B 灰像素的确认分量侧邻接（保证跨面板交互存在）。

**规则**：
1. 移除黄(4)分隔行。
2. 将上下两个面板按位置对齐到同一 HxW 坐标系。
3. 对每个位置 (r, c)：
   - 若两个面板在 (r, c) 都为灰(5)：输出"确认"灰像素。
   - 否则：输出黑(0)（包括仅一个面板有灰、标记位置、或两面板都为黑的情况）。
4. 找到所有确认灰像素的 4-连通分量。
5. 将两个面板的标记像素叠加到同一 HxW 坐标系（标记不出现在输出中，仅用于投票）。对每个确认灰分量，统计与其单元格 4-邻接的所有标记像素（来自任一面板）中各颜色的数量。
6. 邻接数最多的标记颜色成为该分量的填充色：将该分量所有单元格重涂为该颜色。
7. 标记像素不绘制在输出中（仅参与投票）。所有非分量单元格为黑(0)。

**关键洞察**：叠加决定了哪些形状存活（几何 AND 运算），但存活形状的颜色由跨面板邻接投票决定。面板 A 中远离所有灰形状的标记像素，在位置对齐后可能恰好与包含面板 B 灰像素的确认分量侧邻接——这种跨面板中介关系是叠加操作的涌现产物，在任一单独面板中均不存在。

## 新题 8：射线探测触发同心环选择性色移

**组合逻辑**：[射线延伸/ray_extend + 颜色决定运动方向/color_determines_motion + 轨迹交叉/trail_intersection](创新：射线不在外部空间延伸，而是穿透同心环结构向内探测) + [色沿层序循环移/colors_cycle_by_nesting](创新：不是所有环层统一循环移，而是只有包含射线交叉点的环层才发生色移)

**来源原语**：射线延伸、轨迹交叉、颜色决定运动方向、标记像素、轨迹线段（来自 ac605cbb）；同心正方形层、嵌套层序、色沿层序循环移、重涂色（来自 bda2d7a6）

**依赖链**：标记像素颜色决定射线方向 -> 射线从最外环穿透到内部各层 -> 射线交叉位置标识特定环层 -> 被标识的环层执行色序循环移、其余环层不变。射线路径取决于标记在最外环上的位置；交叉点取决于两条射线的几何相交；色移取决于交叉点落在哪个环层。

标记像素从最外环发射方向性射线穿透同心环结构，射线交叉点所在的环层执行色序循环移，其余环层保持不变。

**输入结构**：约 15x15 的网格，黑(0)背景。网格中央有一个同心矩形环结构，包含 4-6 个一格厚的同心矩形环层，由外到内各层颜色各不相同（取自 {蓝(1), 红(2), 绿(3), 黄(4), 青(8), 灰(5)} 的子集，但最外层不使用蓝(1)、红(2)、绿(3)、品红(6)以避免与标记颜色混淆）。2-4 个标记像素放置在最外环的边缘单元格上（覆盖该位置的环颜色）：蓝(1)标记射线向右延伸、红(2)标记射线向左、绿(3)标记射线向下、品红(6)标记射线向上。生成约束：至少存在一对射线（一条水平、一条垂直）在同心环结构内部交叉；标记颜色不与最外环颜色相同。

**规则**：
1. 从每个标记像素出发，沿其确定方向延伸射线。射线逐格覆盖经过的单元格为灰(5)，持续到射线离开同心环结构（到达黑背景或网格边缘）为止。
2. 若两条射线经过同一单元格，该单元格标记为黄(4)而非灰(5)。（生成约束保证至多两条射线共享一格。）
3. 确定每个黄(4)交叉单元格属于哪个同心环层（根据其位置相对于环边界判断）。
4. 记录同心环从外到内的原始颜色序列（忽略已被射线覆盖的格子），定义循环序：color_1 -> color_2 -> ... -> color_K -> color_1。
5. 对每个包含至少一个黄(4)交叉单元格的环层：将该环层中所有未被灰(5)或黄(4)覆盖的存活单元格重涂为循环序中的下一个颜色（即该环原色在序列中的后继色）。
6. 不包含交叉单元格的环层保持原色不变。
7. 灰(5)轨迹像素和黄(4)交叉像素保持不变，位于重涂后的环颜色之上。

**关键洞察**：标记的位置（在最外环上的具体单元格）和方向（由颜色决定）共同确定射线路径的几何形状。交叉点落在哪个环层是射线几何与同心结构的空间耦合结果。色序循环移是选择性的——只有"被射线交叉命中"的环层才参与变换——这使得输出要求同时推理射线几何和环层结构，缺一不可。
