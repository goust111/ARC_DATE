## 新题 1：对称修复揭示洪泛边界

**组合逻辑**：[对称补全/symmetry_completion](创新：补全结果不裁剪输出，而是就地恢复屏障拓扑) + [洪泛填充/flood_fill](已有原语) → 补全的像素充当洪泛屏障，决定扩散边界

**来源原语**：对称补全/symmetry_completion（来自 67b4a34d、b8825c91）、洪泛填充/flood_fill（来自 9edfc990）、标记色空洞/marker_color_hole（来自 b8825c91）、双轴镜像对称/bilateral_mirror_symmetry（来自 67b4a34d）、种子像素/seed_pixel（来自 9edfc990）、障碍物/blocker（来自 9edfc990）、遮挡由镜像恢复/occluded_recovered_by_mirror（来自 67b4a34d）、种子沿连通域扩散/spread_from_seed_through_connected（来自 9edfc990）

**依赖链**：对称补全恢复被灰色遮挡的红色屏障像素 → 屏障拓扑完整后洪泛填充才能正确划定扩散边界。若跳过对称补全，灰色区域留下虚假缺口，洪泛跨区泄漏；若跳过洪泛，仅补全对称不产生蓝色填充。

将双轴镜像对称图案中被标记色遮挡的屏障像素恢复后，从蓝色种子出发洪泛填充所有四邻连通的背景区域。

**输入结构**：约 13x13 的网格。背景为黑(0)。红(2)像素组成一个具有水平轴和垂直轴双重镜像对称性的连通图案，但其中一个矩形区域（约 3x4）被整体涂为灰(5)，灰色仅出现在此矩形中。灰色区域遮挡了若干红(2)像素和若干黑(0)像素——即该区域下方的"真实值"是红黑混合的。网格其余位置散布 2~4 个蓝(1)种子像素，位于黑色背景上，彼此不相邻。生成约束：红色图案在移除灰色矩形后严格满足双轴镜像对称（以网格中心为对称中心）；每个灰色像素的至少一个镜像对应位置是可见的（非灰色）；蓝色种子不位于灰色矩形内部。

**规则**：
1. 识别灰(5)实心矩形为标记区域。
2. 对于标记区域中的每个灰色像素，计算其关于水平中心线、垂直中心线及 180° 旋转的三个镜像位置；从这些镜像位置中取唯一可见的非灰颜色值（红(2)或黑(0)），替换该灰色像素。
3. 完成替换后，红色图案恢复完整的双轴镜像对称。
4. 从每个蓝(1)种子像素出发，沿四邻方向遍历所有相连的黑(0)像素，将它们涂为蓝(1)。
5. 红(2)像素（包括通过对称恢复的）充当屏障，洪泛不可穿越。
6. 蓝色种子像素、所有红色像素均保持不变。

**关键洞察**：灰色区域制造了屏障拓扑的虚假缺口。如果不先通过镜像恢复被遮挡的红色像素，洪泛会穿越本应封闭的屏障，导致两个本该独立的区域错误合并。只有在不同示例中灰色矩形遮挡不同位置时，求解者才能确认"先补全对称再洪泛"的执行顺序。

## 新题 2：同心奇偶区界定推移停止线

**组合逻辑**：[同心层填充/concentric_fill](创新：不绘制可见环，而是作为隐式坐标系定义奇偶区) + [推移/push](创新：停止条件从"到达网格边界"改为"跨越奇偶区边界") + [擦除/erase](已有原语，清除固定标记)

**来源原语**：同心层填充/concentric_fill（来自 b7fb29bc）、推移/push（来自 5623160b）、擦除/erase（来自 8cb8642d）、控制像素/control_pixel（来自 b7fb29bc）、同心正方形层/concentric_layer（来自 b7fb29bc）、固定标记/fixed_marker（来自 5623160b）、前景对象/foreground_object（来自 5623160b）、矩形边框/rectangular_frame（来自 b7fb29bc）、以控制点为中心/centered_on_control（来自 b7fb29bc）、接触侧决定方向/contact_side_dir（来自 5623160b）、奇偶距离决定颜色/parity_distance_color（来自 b7fb29bc，创新：决定停止而非涂色）、推至边界停止/stop_at_boundary（来自 5623160b，创新：边界从网格边界改为奇偶区边界）

**依赖链**：控制像素位置 → 定义每个格子的 Chebyshev 距离奇偶性 → 对象的起始奇偶区已知 → 推移方向由固定标记接触侧决定 → 对象沿该方向滑动直至前沿进入反奇偶区 → 擦除固定标记。控制像素移动一格即可改变所有对象的停止位置，三者缺一不可。

在矩形边框内部，小对象沿固定标记指示的方向推移，但不是滑到边框边界，而是滑到以控制像素为中心的 Chebyshev 距离奇偶区交界处停止。

**输入结构**：约 15x15 的网格。背景黑(0)。绿(3)像素构成一个 1 像素厚的矩形边框。边框内部有一个灰(5)控制像素。边框内部另有 2~3 个小的 4-连通单色对象（每个 2~4 像素，颜色各不相同，使用蓝(1)、红(2)、黄(4)等），每个对象恰好有一侧与一个栗(9)固定标记像素相邻（即该对象的某个像素与栗色像素四邻相接，且接触仅在一个基本方向上）。各对象之间不重叠、不相邻。生成约束：每个对象在推移方向上的可用空间至少跨越两个奇偶区交界，保证停止位置在边框内部而非边框边界上；灰色控制像素不与任何对象或栗色标记相邻。

**规则**：
1. 对于边框内部（不含边框像素）的每个格子，计算其到灰(5)控制像素的 Chebyshev 距离（即 max(|行差|, |列差|)）。距离为偶数的格子属于"偶区"，奇数属于"奇区"。
2. 对于每个非栗色的彩色对象，找到与其相邻的栗(9)标记像素，确定接触的基本方向（上/下/左/右）。推移方向为远离栗色标记的方向（例如标记在对象左侧，则推移方向为右）。
3. 确定对象的"起始奇偶性"：取对象中距栗色标记最近的那个像素（即直接与标记相邻的像素），其 Chebyshev 距离的奇偶性即为起始奇偶性。
4. 将对象沿推移方向逐像素平移。当对象的前沿（推移方向最前方的那一列或那一行像素）全部进入与起始奇偶性相反的区域时，对象停止（即前沿的所有像素的 Chebyshev 距离奇偶性都与起始奇偶性不同的那一刻停住）。
5. 将所有栗(9)标记像素擦除为黑(0)。
6. 保留边框、控制像素和背景不变。

**关键洞察**：推移距离因对象而异，取决于其起始位置相对于控制像素的 Chebyshev 距离奇偶性。同方向推移的两个对象可能走过截然不同的距离。求解者必须通过对比控制像素位于不同位置的多个示例，才能发现隐式的同心奇偶区坐标系。

## 新题 3：交替移位重塑形状驱动缺口转向

**组合逻辑**：[滑动/shift](创新：从作用于格子体改为作用于任意前景对象的逐行交替移位) → [缺口决定方向/notch_determines_dir](已有原语，但作用于移位后的形状) → [滑动/slide + 重涂色/recolor](已有原语)

**来源原语**：滑动/shift（来自 1c56ad9f）、滑动/slide（来自 320afe60）、重涂色/recolor（来自 320afe60）、前景对象/foreground_object（来自 320afe60）、像素行/pixel_row（来自 1c56ad9f）、边框缺口/border_notch（来自 320afe60）、底行锚定/bottom_row_anchored（来自 1c56ad9f）、靠边对齐/edge_aligned（来自 320afe60）、逐行交替方向/alternating_direction_per_row（来自 1c56ad9f）、缺口决定方向/notch_determines_dir（来自 320afe60）

**依赖链**：对象的每一行按交替方向移位 → 移位改变对象轮廓，可能创建或消除边界框上的缺口 → 缺口有无决定滑向左边缘（无缺口，涂红）还是右边缘（有缺口，涂绿）。原始形状上的缺口判断会给出不同的分类结果，因此移位步骤不可跳过。

对每个前景对象施加逐行交替移位以改变其轮廓，然后根据变形后是否存在边界框缺口，将对象滑至对应边缘并涂色。

**输入结构**：约 12x15 的网格。背景黄(4)。3~4 个蓝(1)的 4-连通前景对象，每个对象跨越 4~6 行、3~5 列。各对象的边界框互不重叠，且与网格边缘之间至少留有 1 像素间距。对象形状不规则（非简单矩形），每个对象至少有一行比边界框宽度窄（即存在内凹或不对齐的行）。生成约束：在所有对象中，至少有一个对象在交替移位前无缺口但移位后产生缺口，至少有一个对象在移位前有缺口但移位后消除缺口，以保证求解者不能绕过移位步骤。

**规则**：
1. 对每个对象独立操作：以该对象占据的最底行为锚定行（不动）。从锚定行向上，偶数距离（0, 2, 4...）的行保持不动，奇数距离（1, 3, 5...）的行整体向右平移 1 像素。
2. 移位后，重新计算每个对象的边界框。检查边界框四条边上是否存在缺口：缺口定义为该边上有一段连续的背景像素（至少 1 像素宽），且该段两侧各有至少一个属于该对象的像素。
3. 如果移位后的形状存在至少一个缺口：将整个对象（保持移位后的形状）水平滑动到网格右边缘对齐，并将所有像素涂为绿(3)。
4. 如果移位后的形状不存在缺口：将整个对象（保持移位后的形状）水平滑动到网格左边缘对齐，并将所有像素涂为红(2)。
5. 从纯黄(4)背景开始重绘。多个对象滑向同一边缘时，按其原始（移位前）最上行的行号从小到大排列，先出现的对象紧贴边缘，后出现的依次向内排列，各对象之间无重叠。

**关键洞察**：求解者不能直接在原始形状上判断缺口，因为交替移位会微妙地改变轮廓。一个原本边界整齐的对象在移位后可能因为奇数行右移而在左侧产生缺口；反之，一个原本有缺口的对象可能因为移位恰好填平了缺口。必须对比多个示例中"移位前后缺口状态翻转"的案例才能归纳出正确规则。

## 新题 4：环路弯折的距离分裂分类

**组合逻辑**：[环路追踪/trace_cycle + 分类涂色/classify_and_color](已有原语) × [奇偶距离决定颜色/parity_distance_color](创新：从同心层涂色改为对弯折像素做二次分类) → 凸弯折像素被距离奇偶性进一步分裂为两种颜色

**来源原语**：环路追踪/trace_cycle（来自 15663ba9）、分类涂色/classify_and_color（来自 15663ba9）、同心层填充/concentric_fill 的距离逻辑（来自 b7fb29bc）、闭合正交环路/closed_orthogonal_loop（来自 15663ba9）、弯折像素/bend_pixel（来自 15663ba9）、直行像素/straight_pixel（来自 15663ba9）、控制像素/control_pixel（来自 b7fb29bc）、以控制点为中心/centered_on_control（来自 b7fb29bc）、多数转向为凸/majority_turn_is_convex（来自 15663ba9）、少数转向为凹/minority_turn_is_concave（来自 15663ba9）、奇偶距离决定颜色/parity_distance_color（来自 b7fb29bc，创新：作用于弯折像素而非区域填充）

**依赖链**：环路追踪 → 区分直行/弯折 → 多数方向判定凸/凹 → 凸弯折再按与控制像素的 Chebyshev 距离奇偶性分裂为两色。三层分类嵌套：第一层（直行 vs 弯折）、第二层（凸 vs 凹）、第三层（偶距离 vs 奇距离）。缺少任意一层，输出颜色数减少且不正确。

追踪闭合正交环路并将弯折像素分为凸/凹后，凸弯折像素按其到环路内部控制像素的 Chebyshev 距离奇偶性进一步着色为两种不同颜色。

**输入结构**：约 15x15 的网格。背景黑(0)。1~2 个由蓝(1)像素组成的闭合正交环路（1 像素宽，每个前景像素恰好有 2 个四邻前景邻居）。每个环路内部（由环路围出的封闭区域中）恰有一个灰(5)控制像素，位于黑色背景上。环路的形状为不规则的正交多边形（既有凸角也有凹角）。生成约束：每个环路至少有 4 个凸弯折和 1 个凹弯折（凸弯折恰好比凹弯折多 4 个）；凸弯折中至少各有 1 个距离控制像素为偶数和 1 个为奇数的。

**规则**：
1. 对于每个环路，沿一个方向追踪整个闭合路径。在每个前景像素处，判断路径是否转弯 90°：不转弯→直行像素；转弯→弯折像素。
2. 在弯折像素中，统计左转和右转的数量。多数方向对应凸弯折，少数方向对应凹弯折。
3. 对于每个弯折像素，计算它到该环路内部灰(5)控制像素的 Chebyshev 距离。
4. 涂色规则：
   - 直行像素保持蓝(1)。
   - 凹弯折像素涂为红(2)，不论距离。
   - 凸弯折像素且 Chebyshev 距离为偶数 → 涂为黄(4)。
   - 凸弯折像素且 Chebyshev 距离为奇数 → 涂为绿(3)。
5. 灰(5)控制像素保持不变。

**关键洞察**：仅凭凸/凹分类无法解释为什么同为凸弯折的像素呈现两种颜色（黄和绿）。求解者必须发现控制像素的位置通过 Chebyshev 距离奇偶性对凸弯折做了二次分裂。将控制像素移动一格会交换所有凸弯折的黄/绿着色，这只有在对比不同控制像素位置的多个示例时才能归纳出。

## 新题 5：图例扩展矩形的同心距离优先级

**组合逻辑**：[填充/fill + 扩展/expand](已有原语) + [图例配色/legend_color_pair](已有原语) + [同心层填充/concentric_fill 的距离计算](创新：距离奇偶性不用于涂色而用于仲裁重叠冲突优先级)

**来源原语**：填充/fill（来自 305b1341）、扩展/expand（来自 305b1341）、散布点/sparse_dot（来自 305b1341）、图例/legend（来自 305b1341）、图例配色/legend_color_pair（来自 305b1341）、控制像素/control_pixel（来自 b7fb29bc）、以控制点为中心/centered_on_control（来自 b7fb29bc）、奇偶距离决定颜色/parity_distance_color（来自 b7fb29bc，创新：决定优先级而非涂色）、图例顺序决定层级/legend_order_layer（来自 305b1341，被替换为距离优先级）、冲突优先级/conflict_priority（来自 305b1341，创新：基于距离而非顺序）

**依赖链**：图例提供颜色映射 → 散布点按图例扩展为矩形并填充 → 扩展矩形可能重叠 → 重叠冲突不由图例行序仲裁，而由每组散布点的质心到控制像素的 Chebyshev 距离仲裁（奇距离优先于偶距离；同奇偶中距离小者优先）。三条信息源（图例、散布点、控制像素）各自不可缺少。

读取图例颜色映射后将散布点扩展为填充矩形，当矩形重叠时，以散布点群质心到控制像素的 Chebyshev 距离奇偶性和大小仲裁优先级。

**输入结构**：约 14x14 的网格。背景黑(0)。左上角有一个 2 列的图例区域，从第 0 行起向下排列 3~4 行，每行左列为源色（如蓝(1)、红(2)、绿(3)等），右列为该源色对应的填充色（如黄(4)、橙(7)、品红(6)等），各行颜色互不相同。网格中某个位置有一个灰(5)控制像素（不在图例区域内，不与任何散布点相邻）。图例区域外的网格中散布着若干前景像素，颜色为图例中的源色，每种源色有 2~4 个散布点。生成约束：至少有两组不同源色的散布点扩展后的矩形（含 1 像素外扩）存在重叠区域；各组散布点质心到控制像素的 Chebyshev 距离互不相等。

**规则**：
1. 读取图例：每行左列→右列构成"源色→填充色"映射。
2. 清除图例区域（设为黑(0)）。
3. 对于每种源色，计算其所有非图例散布点的边界框，将该边界框向上下左右各扩展 1 像素。
4. 在扩展后的矩形内，将所有黑(0)背景像素涂为该源色对应的填充色。保留所有原始非图例散布点不变。
5. 当两个扩展矩形在同一像素重叠时，按以下优先级决定颜色：
   a. 计算每组散布点的质心（所有该色散布点的行坐标平均值向下取整、列坐标平均值向下取整）。
   b. 计算每个质心到灰(5)控制像素的 Chebyshev 距离。
   c. Chebyshev 距离为奇数的组优先于偶数的组。
   d. 若两组同为奇数或同为偶数，Chebyshev 距离较小的组优先。
6. 灰(5)控制像素保持不变。

**关键洞察**：重叠优先级既非图例行序也非散布点数量，而是由控制像素位置隐式决定的距离奇偶性。移动控制像素可以翻转两组的优先级关系。求解者必须对比控制像素在不同位置的多个示例，才能排除"按图例行序"或"按面积"等错误假说。

## 新题 6：地形轮廓门控洪泛与极值列标记

**组合逻辑**：[洪泛填充/flood_fill](已有原语) + [地形轮廓极值列识别 + 重涂色/recolor](创新：极值列识别结果筛选种子像素的激活状态，未激活种子被擦除) → 地形同时充当洪泛屏障和极值判据

**来源原语**：洪泛填充/flood_fill（来自 9edfc990）、重涂色/recolor（来自 e45ef808）、地形轮廓/terrain_contour（来自 e45ef808）、分隔行/separator_row（来自 e45ef808）、种子像素/seed_pixel（来自 9edfc990）、障碍物/blocker（来自 9edfc990）、列高度极值/column_height_extreme（来自 e45ef808）、四邻连通/four_neighbor_connectivity（来自 9edfc990）、种子沿连通域扩散/spread_from_seed_through_connected（来自 9edfc990）、最深与最浅列唯一/unique_deep_shallow（来自 e45ef808）

**依赖链**：地形轮廓 → 双重角色：(a) 充当洪泛的屏障拓扑，(b) 定义列高度极值以筛选激活种子 → 仅极值列中的种子被激活，从激活种子洪泛填充 → 洪泛颜色由该种子所在极值类型（最深 vs 最浅）决定。地形不可缺（既定义屏障又定义激活条件），洪泛不可缺（激活种子需要扩散），极值识别不可缺（否则所有种子都激活或都不激活）。

分析地形轮廓的列高度极值以确定哪些列的种子像素被激活，然后仅从激活种子出发洪泛填充，洪泛颜色取决于极值类型。

**输入结构**：约 12x12 的网格。第 0 行是一整行灰(5)分隔行。第 1 行至最后一行：每列由上方的黑(0)空白区和下方的绿(3)地形后缀组成，最底行全为绿(3)。地形轮廓高低不一（各列的第一个绿色像素行号不同）。黑色空白区中散布 4~6 个蓝(1)种子像素，分布在不同列中。生成约束：最深列（第一个地形行最晚的列）唯一；最浅列（第一个地形行最早的列中最靠右的）唯一；最深列和最浅列中各有至少 1 个蓝色种子；至少有 2 个种子在非极值列中（这些是干扰种子）。

**规则**：
1. 对于每列（第 0 行分隔行以下），找到该列第一个绿(3)像素的行号。行号最大的列为"深列"；行号最小的列（若有多列并列则取最右侧的）为"浅列"。
2. 检查所有蓝(1)种子像素：仅保留位于深列或浅列中的种子（"激活种子"），将所有其他列中的蓝色种子擦除为黑(0)。
3. 从深列的激活种子出发，沿四邻方向洪泛填充所有相连的黑(0)像素，涂为栗(9)。灰(5)分隔行和绿(3)地形像素充当屏障。
4. 从浅列的激活种子出发，沿四邻方向洪泛填充所有相连的黑(0)像素，涂为黄(4)。
5. 若两个洪泛在同一像素相遇（即某黑色像素同时与深列洪泛区和浅列洪泛区四邻连通），栗(9)优先。
6. 保留分隔行、地形像素和原始激活种子的颜色（激活种子本身保持蓝(1)）。

**关键洞察**：大多数种子是陷阱——它们位于非极值列，必须被擦除而非激活。求解者需要先做地形剖面分析以确定哪两列是极值列，再判断哪些种子有效。如果跳过极值判断而激活所有种子，洪泛颜色和范围都会错误。

**组合逻辑**：[旋转/rotate + 补全/complete](已有原语) → [平铺/tiling + 镜像/mirror](已有原语，创新：平铺单元是补全后的 2x2 宏瓦片而非单个小瓦片) → 旋转补全的错误会在平铺和镜像中被放大

**规则**：
1. 提取四个 5x5 象限（忽略十字分隔线）。识别三个包含红色图案的象限和一个橙色占位象限。
2. 对任一红色图案生成全部四个 90° 旋转变体。找到不在已有三个图案中的那个旋转变体，将其填入占位象限位置（替换橙色）。

4. 构建 3 行 3 列的宏瓦片阵列，输出为 30x30 的网格。
5. 第 0 行和第 2 行的宏瓦片使用原始宏瓦片。第 1 行（中间行）的宏瓦片使用宏瓦片的水平镜像（左右翻转）。

**关键洞察**：占位象限的位置不固定——不同示例中可能在不同角落，因此求解者不能死记"右下角总是缺失的"。旋转补全的正确性通过平铺和镜像被放大验证：错误的旋转在 9 个重复中（特别是镜像行的 3 个变体中）会产生明显不一致。

## 新题 8：十字图案划区与行键涂色

**组合逻辑**：[擦除/erase + 连线/draw_lines](已有原语，在矩形内绘制 X 图案) × [同行对应/same_row_mapping + 行首色决定填色/row_key_color](创新：标记像素的行位置索引列-0 颜色键) → 标记像素同时提供 X 图案颜色和行键索引

**来源原语**：擦除/erase（来自 8cb8642d）、连线/draw_lines（来自 8cb8642d）、重涂色/recolor（来自 c9f8e694）、实心矩形/solid_rectangle（来自 8cb8642d）、标记像素/marker_pixel（来自 8cb8642d）、空心矩形/hollow_rectangle（来自 8cb8642d）、控制像素/control_pixel（来自 c9f8e694）、标记在矩形内/marker_inside_rect（来自 8cb8642d）、同行对应/same_row_mapping（来自 c9f8e694）、标记色绘交叉图案/marker_cross_pattern（来自 8cb8642d）、行首色决定填色/row_key_color（来自 c9f8e694）

**依赖链**：矩形内的标记像素 → 双重角色：(a) 标记颜色定义 X 图案线条颜色，(b) 标记所在行号索引列-0 颜色键以确定区域填充色 → X 图案将矩形内部划分为扇形区域 → 扇形区域用行键颜色填充 → 列-0 键被清除。标记像素同时驱动两个独立信息通道（线条颜色 + 填充颜色），缺少任一通道均无法确定完整输出。

将实心矩形掏空后绘制标记色 X 图案，用标记像素所在行的列-0 颜色键填充 X 图案之间的内部区域。

**输入结构**：约 15x15 的网格。背景黑(0)。第 0 列包含若干颜色键像素：在特定行放置非黑色像素（如行 3 放蓝(1)、行 7 放绿(3)、行 11 放黄(4)等），其余行的第 0 列为黑(0)。网格其余区域有 2~3 个实心彩色矩形（每个至少 5x5，使用不同的前景色如红(2)、品红(6)、橙(7)等），彼此不重叠。每个矩形内部严格包含一个灰(5)标记像素（不在矩形边框上）。生成约束：每个矩形内标记像素所在行的第 0 列恰好有一个非黑色键像素；不同矩形的标记像素在不同行，对应不同的键颜色。

**规则**：
1. 对于每个实心矩形：
   a. 保留 1 像素厚的边框（颜色不变），将内部全部清为黑(0)。
   b. 用灰(5)在矩形内部绘制 X 图案：从内部四个角点分别沿 45° 向中心画对角线，交汇于内部中心。若内部宽或高为偶数，中心交汇区为 2x2 区域，全部涂灰(5)；若为奇数，交汇于单像素。
2. X 图案将矩形内部分为上、下、左、右四个扇形区域（X 线条本身不属于任何扇形）。
3. 查找该矩形的标记像素所在行，读取第 0 列该行的颜色键值。
4. 将该矩形内部四个扇形区域中所有黑(0)像素涂为该键颜色。
5. 处理完所有矩形后，将第 0 列全部清为黑(0)。

**关键洞察**：标记像素承载双重功能——其颜色（灰色）定义了 X 图案的线条颜色，其行位置索引了一个独立的颜色查找表（列-0 键）。仅看矩形内部无法推断填充颜色；仅看列-0 键无法推断哪个矩形使用哪个键。两者通过标记像素的行坐标关联，这种"空间索引"关系需要对比多个示例（标记在不同行、对应不同键色）才能归纳。

## 新题 9：重复十字标记计数选定象限填充

**组合逻辑**：[图案识别/pattern_recognition + 计数/counting](已有原语) → [区域填充/region_fill](已有原语，创新：填充的象限由计数结果而非控制像素位置决定)

**来源原语**：图案识别/pattern_recognition（来自 642d658d）、计数/counting（来自 642d658d）、区域填充/region_fill（来自 87ab05b8）、十字标记/plus_marker（来自 642d658d）、象限/quadrant（来自 87ab05b8）、中心与臂颜色/center_and_arm_color（来自 642d658d）、所属象限/containing_quadrant（来自 87ab05b8）、重复色为答案/repeated_color_answer（来自 642d658d）、忽略干扰项/ignore_distractors（来自 642d658d）、干扰项忽略/distractor_ignored（来自 87ab05b8）

**依赖链**：在噪声中识别十字标记 → 统计各臂色出现次数 → 出现多于一次的臂色为"目标色" → 目标色十字标记的总数 N 选定第 N 象限 → 将第 N 象限整体填充为目标色。识别筛选了颜色，计数筛选了象限——两步产生的信息交叉决定输出，缺一不可。

从噪声网格中识别黄色中心十字标记，统计重复臂色以确定目标色，再以目标色标记的数量选定象限进行填充。

**输入结构**：约 14x14 的网格。背景黑(0)。网格上散布若干随机颜色的噪声像素（非黄色，非背景色，随机分布，约占网格的 10%~15%）。其中嵌有 4~6 个十字标记（plus-shaped marker）：每个由 1 个黄(4)中心像素和 4 个四邻方向的同色臂像素组成（臂色为非黑、非黄的某种颜色）。所有十字标记中，恰好有一种臂色出现 2~4 次（"目标色"），其余臂色各出现恰好 1 次。生成约束：目标色十字标记的数量 N 满足 1 <= N <= 4，且对应象限编号（左上=1, 右上=2, 左下=3, 右下=4）；十字标记之间不重叠且不与其他十字标记四邻相接；噪声像素不会恰好构成额外的十字标记。

**规则**：
1. 扫描网格，找到所有十字标记：一个黄(4)像素四邻方向各有一个非黑、非黄的同色像素。
2. 统计每种臂色对应的十字标记数量。唯一出现多于 1 次的臂色为"目标色"。
3. 令 N = 目标色十字标记的数量。象限编号：左上=1, 右上=2, 左下=3, 右下=4（网格按行中点和列中点分为四个象限；若网格尺寸为奇数，中点行/列不属于任何象限，保持黑色）。
4. 清除整个网格为黑(0)背景。
5. 将第 N 象限的所有像素填充为目标色。

**关键洞察**：求解者需要完成两步推理：首先通过"臂色重复性"筛选出目标色（忽略单次出现的干扰标记和所有噪声），然后通过"目标色标记的计数"映射到象限编号。仅识别目标色不能确定空间位置（目标色标记可能散布在多个象限中），仅计数不能确定填充颜色。两条信息通道必须同时正确才能产生正确输出。
