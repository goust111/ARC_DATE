## 新题 1：弹射射线划分重力车道

**组合逻辑**：[射线延伸/ray_cast](创新：射线路径不作为可见输出，而是充当空间分隔墙) + [重力下落/gravity_drop](创新：重力仅在射线划分的车道内独立生效) + [面积区分角色/area_determines_role](已有原语) + [擦除/erase](已有原语)

**来源原语**：射线延伸、反射弹回、对角遇边反射（a3df8b1e）；重力下落、触底停止、面积区分角色（6ca952ad）；擦除（fe45cba4）

**依赖链**：射线弹射路径决定了每个对象所属的空间车道 → 车道边界约束了重力下落的横向范围 → 面积判断决定了哪些对象下落、哪些作为固定平台 → 平台在车道内充当落地面。删除射线步骤则无法确定车道，删除重力则无变换，删除面积判断则无法区分角色。

从一个种子像素发射对角弹射射线将网格划分为竖向车道，每个车道内的大对象在重力作用下独立下落，小对象作为固定平台承接落物。

**输入结构**：网格约 15x15，背景黑(0)。网格底边正中有一个蓝(1)像素作为射线种子。网格中散布若干单色 4-连通前景对象（每个对象 2~8 像素不等），颜色各异（从红(2)、绿(3)、黄(4)、灰(5)中选取），互不接触。其中面积 <=2 的小对象固定不动（充当平台角色），面积 >=3 的大对象将受重力影响。生成约束：所有前景对象不与射线路径重叠；射线路径将网格划分为至少 3 个竖向车道；每个车道内至少有一个大对象和一个小对象。

**规则**：
1. 从蓝(1)种子像素出发，向右上方 45 度发射射线，遇到左右边界水平反射，遇到上边界停止。射线经过的所有像素记录为路径（但不绘制到输出中）。
2. 射线路径将网格分为若干竖向车道（路径像素本身不属于任何车道）。每个前景对象根据其边界框中心列所在车道归属该车道。
3. 在每个车道内独立执行重力下落：面积 >=3 的对象整体向下平移，直到其最低像素触及该车道内某个固定小对象（面积 <=2）的顶部、或触及网格底边。若同一车道有多个大对象，按原始位置从下到上依次下落（下方的先落）。
4. 擦除蓝(1)种子像素。所有小对象保持原位不动。输出中不包含射线路径。
5. 大对象下落后若其边界框超出车道横向范围，超出部分正常绘制（车道仅约束下落方向，不裁剪形状）。

**关键洞察**：射线路径本身不出现在输出中，求解者必须通过对比多个示例中对象的下落行为，推断出一条隐含的对角弹射分隔线决定了每个对象的独立下落通道。

## 新题 2：周期间距编码旋转角度的印章铺设

**组合逻辑**：[周期填充/periodic_fill → 周期步长/periodic_step](创新：周期步长不用于填充，而是编码旋转角度参数) + [旋转/rotate](已有原语) + [印章覆盖/stamp](已有原语) + [颜色匹配配对/color_match_pairing](已有原语) + [重涂色/recolor](已有原语)

**来源原语**：周期步长、边界点、同余对齐（16de56c4）；旋转、颜色匹配配对、对称消歧旋转（2c181942）；印章覆盖（760b3cac / a04b2602）；重涂色（b1948b0a）

**依赖链**：左边缘同色点对的间距 → 计算周期步长 → 步长映射为旋转角度 → 在网格中找到同色标记像素 → 将模板精灵体旋转该角度后印章到标记位置 → 重涂色为标记颜色。周期步长是旋转角度的唯一信息来源，删除它则无法确定旋转；标记像素是位置的唯一信息来源，删除它则无法确定放置位置。

左边缘同色点对的间距编码旋转角度，网格中同色标记指定印章位置，将灰色模板精灵体按编码角度旋转后印章到各标记位置并重涂色。

**输入结构**：网格约 14x14，背景黑(0)。左边缘（第 0 列）上有 2~3 种颜色的点对，每种颜色恰好 2 个像素，分布在不同行，颜色从红(2)、绿(3)、黄(4)中选取。网格右半区域有一个灰(5)模板精灵体（4-连通，4~8 像素，非矩形的不规则形状，无旋转对称性——即 0/90/180/270 度旋转结果各不相同）。网格中散布若干彩色标记像素（单像素），颜色与左边缘某种颜色匹配。每种颜色的标记像素 1~2 个。生成约束：各标记位置周围有足够空间容纳旋转后的精灵体且互不重叠；灰色模板不与任何标记或边缘点重叠。

**规则**：
1. 对每种出现在左边缘的颜色 C，找到其两个边缘像素的行号 r1 < r2，计算周期步长 S = r2 - r1。
2. 步长到旋转角度的映射：S=2 对应 0 度（不旋转），S=3 对应 90 度顺时针，S=4 对应 180 度，S=5 对应 270 度顺时针。
3. 在网格中找到所有颜色为 C 的标记像素（非左边缘上的）。
4. 对每个标记像素，以该像素位置为旋转后精灵体边界框的左上角，将灰(5)模板精灵体旋转对应角度后印章覆盖到网格上。
5. 将印章后的精灵体像素从灰(5)重涂为颜色 C。
6. 保留左边缘点对和标记像素本身不变。若印章区域与标记像素重叠，标记像素保持原色（标记优先）。
7. 多个印章之间若有重叠，按标记像素的行优先-列次优先顺序，后印章的覆盖先印章的。

**关键洞察**：左边缘点对的间距看似要用于周期填充，实际上是旋转角度的隐式编码。求解者需要对比不同颜色的间距与对应印章的旋转方向，才能归纳出间距-角度映射规则。

## 新题 3：缩略图颜色双重编码位置与镜像方向

**组合逻辑**：[缩放/scale + 坐标映射/coordinate_mapping](已有原语) + [镜像/mirror](创新：缩略图像素颜色不仅指定放置内容的颜色，还编码是否水平镜像) + [印章覆盖/stamp](已有原语) + [已有块确认对齐/existing_blocks_confirm_alignment](已有原语)

**来源原语**：缩略图、缩放、坐标映射、已有块确认对齐（c4d067a0）；镜像、方向指示、标记指示放置侧（760b3cac）；印章覆盖（a04b2602）

**依赖链**：缩略图像素位置 → 经坐标映射/缩放确定主区域放置坐标 → 缩略图像素颜色同时编码两个信息：（a）填充色和（b）镜像方向 → 灰色模板精灵体按方向镜像后以填充色印章到目标位置。已有块用于确认缩放比和偏移量。删除缩略图则无位置和方向信息；删除已有块则无法确定缩放参数；删除镜像规则则输出方向错误。

缩略图中每个像素的位置指定主区域的放置坐标，像素颜色的奇偶性决定模板精灵体是否水平镜像，然后以该颜色印章到目标位置。

**输入结构**：网格约 17x17，背景黑(0)。左上角有一个 3x3 或 4x4 的缩略图区域，其中若干像素为非背景色（从蓝(1)、红(2)、绿(3)、黄(4)中选取），其余为背景色。主区域（右下大部分）以规则网格排列着若干 NxN（N=3 或 4）的方块位置。部分位置已放置了彩色方块（由对应颜色的模板精灵体的原版或镜像版组成），用于确认缩放比和偏移。网格中还有一个灰(5)模板精灵体（NxN 大小，4-连通，左右不对称——水平镜像后与原版不同），位于缩略图下方或右侧的空闲区域。生成约束：缩略图中至少有 4 个非背景像素；已放置的方块至少 2 个，足以唯一确定缩放比和偏移；缩略图中使用的颜色至少包含一个奇数编号色和一个偶数编号色。

**规则**：
1. 从已放置方块的位置和缩略图中对应像素的位置，推断缩放因子 k 和偏移 (dr, dc)：主区域方块左上角 = 缩略图像素坐标 * k + (dr, dc)。
2. 对缩略图中每个非背景像素 P（颜色 C，位于缩略图坐标 (r, c)）：
   - 计算主区域目标左上角 = (r * k + dr, c * k + dc)。
   - 若 C 的颜色编号为奇数（1 蓝、3 绿）：将灰色模板精灵体**水平镜像**后放置。
   - 若 C 的颜色编号为偶数（2 红、4 黄）：将灰色模板精灵体**保持原样**放置。
   - 将放置的精灵体像素从灰(5)重涂为颜色 C。
3. 已放置的方块保持不变（它们与规则计算结果一致）。
4. 灰色模板精灵体在输出中擦除（置为背景色）。

**关键洞察**：缩略图像素颜色承担双重角色——既指定填充颜色，又通过颜色编号的奇偶性隐式编码镜像方向。求解者必须同时发现坐标映射关系和颜色-镜像对应规则，且两者耦合在同一个缩略图中，单看任何一个维度都无法完整求解。

## 新题 4：边缘标记笛卡尔网格筛选自平移对象

**组合逻辑**：[平移/translate + 按自身宽度平移/shift_by_own_width](已有原语) + [填充/fill + 行列交叉/row_col_intersection + 边缘标记笛卡尔积/edge_marker_cartesian_product](创新：笛卡尔积位置不再直接填色，而是充当"合法落点") + [擦除/erase](已有原语) + [重涂色/recolor](已有原语)

**来源原语**：平移、边界框决定偏移、按自身宽度平移（64a7c07e）；填充、行列交叉、边缘标记笛卡尔积（2281f1f4）；连线/draw_line、边界标记定贯穿线（6cdd2623）；重涂色（b1948b0a）；擦除（6ca952ad）

**依赖链**：顶边标记确定目标列集合、右边标记确定目标行集合 → 笛卡尔积生成合法落点网格 → 每个前景对象按自身宽度右移 → 判断移动后边界框左上角是否恰好落在某个合法落点上 → 命中则保留并重涂为该行标记的颜色，未命中则擦除。对象的宽度（几何属性）决定了它能否对齐到全局网格（空间结构），两者的交互是求解关键。

顶边和右边的标记像素定义笛卡尔合法落点网格，每个前景对象右移自身宽度后，仅保留落在合法位置的对象并重涂为对应行标记颜色。

**输入结构**：网格约 16x16，背景黑(0)。顶边（第 0 行）有若干橙(7)标记像素，标记特定列。右边（最后一列）有若干彩色标记像素（从红(2)、绿(3)、蓝(1)中选取），标记特定行，每行最多一个标记。网格内散布若干灰(5)的 8-连通前景对象（每个 3~9 像素），形状各异，互不接触。生成约束：每个对象的边界框宽度在 1~5 之间；恰好有一部分对象（不少于 2 个、不超过总数的一半）在右移自身宽度后其边界框左上角落在某个笛卡尔交叉点上；其余对象移动后不落在任何交叉点上。笛卡尔交叉点定义为：行号等于某个右边标记的行号，且列号等于某个顶边标记的列号。

**规则**：
1. 确定顶边所有橙(7)标记的列号集合 C_set，右边所有彩色标记的行号集合 R_set 及每行标记的颜色。
2. 合法落点集合 = { (r, c) | r 在 R_set 中且 c 在 C_set 中 }。
3. 对每个灰(5)前景对象，计算其边界框宽度 W，将对象整体右移 W 列。
4. 移动后，检查该对象边界框的左上角坐标 (r0, c0)：
   - 若 (r0, c0) 在合法落点集合中：保留该对象在移动后的位置，并将所有像素从灰(5)重涂为该行右边标记的颜色。
   - 若 (r0, c0) 不在合法落点集合中：擦除该对象（原位置和移动后位置均不保留）。
5. 顶边和右边的标记像素保持不变。

**关键洞察**：对象能否"存活"取决于其自身宽度与全局笛卡尔网格的对齐关系——这是对象局部几何属性与全局空间结构之间的隐含共振，求解者需要同时理解自平移规则和笛卡尔筛选机制才能预测输出。

## 新题 5：空心矩形边色配对走廊连接与碎片互补填充

**组合逻辑**：[连线/connect + 最短可见间距/shortest_gap + 重叠决定走廊宽度/overlap_corridor_width](创新：走廊连接不基于最小生成树，而是基于颜色匹配配对) + [互补拼合/complement_fit + 同色碎片拼成矩形/same_color_join](创新：走廊连通后的碎片合并体必须互补拼合为矩形) + [擦除/erase](已有原语)

**来源原语**：连线、最短可见间距、重叠决定走廊宽度、最小生成树连接（b9630600）；颜色匹配配对（2c181942）；互补拼合、同色碎片拼成矩形（fe45cba4）；擦除（fe45cba4）

**依赖链**：每对同色空心矩形通过颜色配对确定连接关系 → 走廊宽度由内部重叠范围决定 → 走廊连通后，每个矩形内部的碎片可以经走廊"看到"配对矩形内部的碎片 → 两个矩形内部碎片的形状并集恰好互补拼合为一个实心矩形 → 用互补色填充缺失部分。连接规则决定了哪两组碎片要互补，走廊的存在使空间上分离的碎片产生逻辑关联。

同色空心矩形框配对后用走廊连接，连通的两个矩形内部碎片形状互补，将各自缺失部分填充为对方碎片的颜色以完成实心矩形。

**输入结构**：网格约 18x18，背景黑(0)。网格中有 4 或 6 个空心矩形框，每个框由单色一像素宽边框构成（颜色从蓝(1)、红(2)、绿(3)中选取）。同色框恰好 2 个，构成一对。每对中两个框大小相同（内部区域尺寸相同，如都是 4x3）。每个框的内部包含一个品红(6)碎片（4-连通，不规则形状，占据内部区域的 40%~60% 面积），其余内部为背景。同一对中两个框的品红碎片形状互补——即将两个碎片叠放到同尺寸矩形中恰好无重叠地铺满整个矩形。不同对之间的框不相邻。生成约束：同色配对的两个框之间存在水平或垂直可见间距（中间无其他框阻挡）；每对框的内部行或列有重叠范围（用于确定走廊宽度）。

**规则**：
1. 按颜色将空心矩形框配对（同色为一对）。
2. 对每一对，在两个框之间建立走廊连接：
   - 走廊方向为两框之间的水平或垂直间距方向。
   - 走廊宽度 = 两框内部区域在垂直于走廊方向上的重叠行/列数。
   - 走廊绘制方式：沿重叠范围的两条边界行/列（走廊的"墙壁"）用该对的框颜色绘制，同时擦除两框面对走廊一侧的边框上、严格位于两条边界行/列之间的像素（打开通道）。
3. 对每一对中的两个框 A 和 B：
   - 框 A 内部品红(6)碎片占据的位置集合为 S_A，框 B 内部品红(6)碎片占据的位置集合为 S_B。
   - 在框 A 的内部，将所有非 S_A 的位置（即背景位置）填充为栗(9)。
   - 在框 B 的内部，将所有非 S_B 的位置填充为栗(9)。
4. 品红(6)碎片保持不变。走廊内部（两条墙壁之间）保持背景色。

**关键洞察**：框的颜色配对决定了哪两组碎片进行互补检验——这不是空间邻近关系，而是颜色编码的逻辑配对。求解者需要先识别同色配对关系，再理解配对框内碎片的互补结构，才能推断填充规则。走廊连接是视觉线索，帮助暗示配对关系，但颜色才是真正的配对依据。

## 新题 6：对角线段长度索引矩形框，被选框内容做象限旋转平铺

**组合逻辑**：[平移绘制/translate_draw + 长度递增/length_increment + 同反对角线/same_antidiagonal](创新：对角线段长度不仅推进自身，还作为选择索引) + [裁剪/crop + 完整边框检测/complete_border_check](已有原语) + [旋转/rotate + 平铺/tile + 四象限各不同旋转/quadrant_rotation](已有原语)

**来源原语**：平移绘制、长度递增、同反对角线（50c07299）；裁剪、矩形框、完整边框检测、最大面积选取（1a6449f1）；旋转、平铺、四象限各不同旋转、象限（cf5fd0ad）

**依赖链**：对角线段当前长度 L → 推进后新长度 L+1 → L+1 索引到按面积排序的矩形框列表中的第 (L+1) 个框 → 裁剪该框内部 → 对裁剪结果执行四象限旋转平铺生成输出。对角线段的几何属性（长度）同时驱动两个不同系统：自身的推进规则和框的选择逻辑。删除对角线段则无法确定选哪个框；删除四象限平铺则无法生成输出。

对角线段推进后的新长度作为索引选取对应矩形框，裁剪该框内部内容后做四象限旋转平铺生成输出。

**输入结构**：网格约 20x20，背景黑(0)。网格中有 3~5 个不同大小的完整单色矩形框（一像素宽边框，颜色各异，从蓝(1)、红(2)、绿(3)、黄(4)中选取）。每个框的内部包含由灰(5)和品红(6)组成的非平凡图案（非全空、非全满，至少 3 个非背景像素，图案本身无 4 重旋转对称性）。框的内部区域为正方形（宽=高）。网格角落区域有一条橙(7)对角线段，位于某条反对角线上，长度为 L（L 在 1~4 之间，且 L+1 不超过框的数量）。生成约束：各框互不重叠且不与对角线段重叠；将框按内部面积从小到大排序后，第 (L+1) 个框存在。

**规则**：
1. 识别橙(7)对角线段，计算其长度 L（像素数）。
2. 推进对角线段：擦除当前线段，在同一反对角线上、紧接当前线段右上端之后，绘制长度为 L+1 的新橙(7)线段（与参考题 50c07299 规则一致）。但此推进结果不出现在最终输出中——仅用于计算新长度 L+1。
3. 找到所有完整矩形框，按其内部面积从小到大排序，编号为 1, 2, 3, ...。
4. 选取编号为 (L+1) 的矩形框，裁剪其内部内容（不含边框），得到一个 MxM 的正方形图案 P。
5. 以 P 为基本单元，按四象限旋转规则生成 2Mx2M 的输出：
   - 左上象限：P 旋转 180 度。
   - 右上象限：P 顺时针旋转 90 度。
   - 左下象限：P 逆时针旋转 90 度。
   - 右下象限：P 保持不变。
6. 输出仅为 2Mx2M 的四象限平铺结果，不包含原始网格中的任何其他元素。

**关键洞察**：对角线段的长度是一个"指针"，其推进规则（长度+1）决定了指向哪个矩形框。求解者需要同时理解三个独立机制（对角线推进、面积排序索引、象限旋转平铺），并发现它们通过长度值这一隐含参数串联在一起。仅看单个示例可能混淆"选框依据"（不知道是按颜色、位置还是面积排序），需要对比多个示例中不同长度的对角线段与被选框的对应关系才能确定排序规则。
