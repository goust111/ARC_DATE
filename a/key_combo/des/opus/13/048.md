## 新题 1：对称性门控的最近种子分区

**组合逻辑**：[对称类型决定颜色](创新：对称类型不直接映射颜色，而是决定扩散优先级) + [最近扩散/nearest_fill](创新：加入优先级机制的最近分区) + [擦除/erase](已有) + [连通性/connectivity](已有)

**来源原语**：对称类型决定颜色(a09f6c25)、最近扩散(332202d5)、擦除(21897d95/3bdb4ada)、连通性(e0fb7511)、单像素为噪声(a09f6c25)

**依赖链**：首先需要识别各前景对象的4-连通性以过滤噪声 -> 然后分析每个非噪声对象的反射对称类型 -> 对称类型决定该对象作为种子的扩散优先级 -> 最近扩散按优先级分层执行，高优先级种子先占据空间 -> 低优先级种子只能填充剩余空间

根据前景对象的对称类型分配扩散优先级，按优先级分层执行最近种子分区，噪声像素被擦除。

**输入结构**：黑(0)背景上散布若干4-连通的单色前景对象（每个对象3~8像素，形状各异，不限于规则几何形），以及若干孤立的单像素噪声点。网格约15x15。所有非噪声对象颜色相同，使用红(2)。每个非噪声对象恰好具有一种反射对称类型：水平对称、垂直对称或对角对称（不会同时具备两种）。生成约束：各对象的边界框互不重叠，且各对象的最近扩散区域在去除噪声后覆盖整个网格。

**规则**：
1. 识别所有红(2)的4-连通对象。面积为1的孤立像素视为噪声，在输出中擦除为黑(0)。
2. 对每个非噪声对象，判断其反射对称类型：水平反射对称的对象优先级为1（最高），垂直反射对称的优先级为2，对角反射对称的优先级为3（最低）。
3. 执行分层最近扩散：先处理优先级1的所有对象，每个背景像素归属于曼哈顿距离最近的优先级1对象，被归属的像素重涂为蓝(1)；然后在剩余未被占据的背景像素中，处理优先级2的对象，被归属的像素重涂为绿(3)；最后处理优先级3的对象，重涂为黄(4)。
4. 同一优先级内若某像素到两个种子等距，则该像素保持黑(0)作为分隔线。
5. 原始的红(2)对象像素保持红(2)不变。

**关键洞察**：对称分析不是直接映射输出颜色，而是决定扩散执行的先后顺序；高优先级种子抢先占据空间，从而挤压低优先级种子的领地范围——同样的种子布局，仅改变对称类型就会产生完全不同的分区结果。

## 新题 2：旋转对齐次数编码填色

**组合逻辑**：[形状匹配/shape_matching](创新：匹配时考虑旋转等价性) + [旋转/rotate](创新：旋转次数成为编码参数) + [填充/fill](已有) + [封闭孔洞/enclosed_hole](已有)

**来源原语**：形状匹配(93b4f4b3)、形状对应(93b4f4b3)、旋转(412b6263/c074846d)、填充(93b4f4b3)、封闭孔洞(93b4f4b3)、模板(93b4f4b3)

**依赖链**：识别模板孔洞和候选形状 -> 尝试0/1/2/3次90度旋转来匹配每个孔洞 -> 匹配所需的旋转次数决定填充颜色（而非候选形状的原色） -> 用编码后的颜色填充对应孔洞

识别模板中的孔洞，将候选形状通过旋转与孔洞匹配，用旋转次数编码的颜色填充孔洞。

**输入结构**：网格约14x20，被灰(5)竖线等分为左右两个面板。左面板：一个橙(7)的连通模板占据大部分区域，模板内有3~4个被橙(7)完全包围的黑(0)背景孔洞区域，每个孔洞是一个不规则的4-连通区域（3~6像素）。右面板：与左面板孔洞数量相同的灰(5)小图形散布在黑(0)背景上，每个灰(5)图形的形状恰好是某个左面板孔洞经过k次顺时针90度旋转后的结果（k可以是0、1、2或3），且每个孔洞恰好有一个对应的右面板图形。生成约束：不同孔洞的归一化形状（含旋转等价）互不相同，保证匹配唯一。

**规则**：
1. 在左面板中提取所有被橙(7)包围的黑(0)孔洞区域，将每个孔洞的掩码归一化到其边界框。
2. 在右面板中提取所有灰(5)图形，将每个图形的掩码归一化到其边界框。
3. 对每个孔洞掩码，依次尝试顺时针旋转0次、1次、2次、3次，找到与某个右面板图形掩码完全吻合的旋转次数k。
4. 根据k值确定填充颜色：k=0（无需旋转）填红(2)，k=1填绿(3)，k=2填蓝(1)，k=3填黄(4)。
5. 输出仅包含左面板（不含灰(5)分隔线），橙(7)模板不变，每个孔洞填充对应的编码颜色。

**关键洞察**：右面板图形的原始颜色（统一灰色）是故意的干扰——真正决定填色的不是图形自身的颜色，而是它与目标孔洞之间的旋转距离。

## 新题 3：射线生长后的括号通道重力堆叠

**组合逻辑**：[射线延伸/ray_extend](已有) + [种子色决定延伸方向](已有) + [重力下落/gravity_drop](创新：作用于射线生成的条状对象) + [括号框/bracket_frame](创新：括号位置决定重力方向) + [碰撞停止/collision_stop](已有)

**来源原语**：射线延伸(178fcbfb)、种子色决定延伸(178fcbfb)、重力下落(df9fd884)、括号框(df9fd884)、碰撞停止(f0100645)、通道对齐(df9fd884)

**依赖链**：种子像素按颜色决定射线方向（水平或垂直） -> 射线延伸生成条状对象 -> 条状对象被视为可移动物体 -> 括号框的朝向决定该通道的重力方向 -> 条状对象在对应通道内沿重力方向滑动直到碰撞停止

种子像素先按颜色生长为整行或整列条纹，再将条纹作为刚体沿括号框指定的方向做重力下落并堆叠。

**输入结构**：黑(0)背景，网格约14x14。顶边有一个蓝(1)的向下开口括号框（占据顶部1~2行，宽度覆盖网格某个列区间），底边有一个蓝(1)的向上开口括号框（占据底部1~2行，宽度覆盖另一个列区间），两个括号的列区间互不重叠。网格内部散布2~4个种子像素：红(2)种子和绿(3)种子。红(2)种子的列坐标落在某个括号的列区间内，绿(3)种子的行坐标也在有效范围内。生成约束：每个种子延伸后的条纹至少有一部分落在某个括号的列区间内；同一括号通道内不同条纹初始位置不重叠。

**规则**：
1. 红(2)种子向上下延伸为整列红色条纹；绿(3)种子向左右延伸为整行绿色条纹。延伸时覆盖背景像素，但不覆盖蓝(1)括号框像素（遇到括号框停止）。
2. 条纹之间的交叉点保留后绘制的颜色（按种子从左到右、从上到下的顺序依次绘制）。
3. 将每个条纹视为刚体。对于顶部括号框（向下开口），其列区间内的所有条纹片段向下做重力下落，直到触碰括号框底边、网格底边或已堆叠的条纹。对于底部括号框（向上开口），其列区间内的所有条纹片段向上做重力下落（反向重力），直到触碰括号框顶边、网格顶边或已堆叠的条纹。
4. 落在括号列区间之外的条纹片段保持原位不动。
5. 同一通道内按距离目标边较近者先落。

**关键洞察**：射线延伸和重力下落作用于同一个对象的不同阶段——射线决定条纹的形状和位置，括号框决定条纹的哪个片段参与哪个方向的重力运动；同一条纹可能被两个括号通道分别作用于不同片段。

## 新题 4：缺损掩码驱动的条件平铺

**组合逻辑**：[差异提取/difference_extraction](已有) + [颜色反转/color_invert](创新：是否反转由缺损掩码的对称性决定) + [平铺/tiling](已有) + [对称类型决定颜色](创新：对称类型不决定颜色，而决定预处理操作)

**来源原语**：差异提取(2037f2c7)、对齐比较(2037f2c7)、缺失掩码(2037f2c7)、颜色反转(48131b3c)、平铺(48131b3c)、对称轴(a09f6c25)

**依赖链**：对比完整副本和缺损副本提取缺损掩码 -> 分析缺损掩码的对称性 -> 对称性决定是否对掩码做颜色反转 -> 反转或不反转后的掩码进行2x2平铺 -> 输出平铺结果

提取两个图案副本的差异掩码，根据掩码自身的对称性决定是否颜色反转，再将结果2x2平铺。

**输入结构**：黑(0)背景，网格约12x24或24x12（水平或垂直排列两个图案）。包含两个相同边界框尺寸的4-连通多色前景图案（每个图案使用2~3种非黑颜色，4x4到6x6像素区域），它们是同一母图案的两个副本。其中一个是完整副本，另一个是缺损副本——缺损副本在完整副本的基础上将若干前景像素变为黑(0)。缺损区域（即缺失的像素集合）构成一个小的二值图案（2~5像素）。生成约束：缺损掩码归一化到其边界框后，要么具有水平反射对称性，要么具有垂直反射对称性，要么不具有任何反射对称性（三种情况在不同示例中均出现）。

**规则**：
1. 将两个图案的边界框对齐，找出在完整副本中为前景而在缺损副本中为黑(0)的像素位置，形成缺损掩码。
2. 将缺损掩码裁剪到其自身的边界框，缺损像素标记为青(8)，其余为黑(0)。
3. 检测该裁剪后掩码的反射对称性：若具有水平反射对称性，将掩码中青(8)与黑(0)互换（颜色反转）；若具有垂直反射对称性，将掩码上下翻转后再颜色反转；若无任何反射对称性，保持掩码不变。
4. 将步骤3的结果在水平和垂直方向各重复2次，形成2x2平铺输出。

**关键洞察**：缺损掩码同时承担两个角色——它既是平铺的内容来源，其几何属性（对称类型）又控制了平铺前的预处理方式；求解者必须对比多个示例才能发现对称类型与预处理之间的映射关系。

## 新题 5：框内计数参数化网格生成与多层叠加

**组合逻辑**：[计数/counting](已有) + [忽略干扰项/ignore_distractors](已有) + [生成网格/generate_grid](创新：多个计数结果同时参数化同一网格) + [边长决定间距/side_length_determines_spacing](创新：间距由计数值而非物体尺寸决定) + [印章覆盖/stamp_overlay](创新：多层网格线叠加的冲突解决)

**来源原语**：计数(c8b7cc0f)、矩形框(c8b7cc0f)、标记像素(c8b7cc0f)、忽略干扰项(c8b7cc0f)、生成网格(695367ec)、边长决定间距(695367ec)、印章覆盖(e76a88a6)

**依赖链**：分别计算每个矩形框内的标记像素数 -> 每个计数值成为一组网格线的间距参数 -> 各组网格线使用对应框的颜色 -> 多组网格线叠加到同一画布上 -> 交叉点处按框面积小者优先解决冲突

分别计数多个矩形框内的标记像素，用各计数值作为间距生成对应颜色的网格线，多层网格叠加到统一画布上。

**输入结构**：黑(0)背景，网格约12x12。包含2~3个不同颜色的单像素厚矩形框（每个框一种颜色，使用蓝(1)、绿(3)、黄(4)中的2~3种），框之间不重叠不嵌套。网格中散布若干红(2)标记像素，有些在框内，有些在框外（框外的是干扰项）。生成约束：每个框内的红(2)标记数在2~5之间，且各框内标记数互不相同；输出网格固定为15x15。

**规则**：
1. 对每个矩形框，计算严格位于框内部（不含框边）的红(2)标记像素数量N，忽略框外的所有红(2)像素。
2. 生成一个15x15的黑(0)输出网格。
3. 对每个矩形框，以其计数值N作为间距，从第N列开始每隔N+1列画一条该框颜色的整列竖线，同时从第N行开始每隔N+1行画一条该框颜色的整行横线。
4. 当两组不同颜色的网格线在同一像素交叉时，该像素使用面积较小的矩形框的颜色（面积 = 框内部区域的像素数，不含框边本身）。
5. 仅有一组网格线经过的像素使用该组的颜色，无网格线经过的像素保持黑(0)。

**关键洞察**：计数结果不是直接渲染为视觉表示（如参考题中的3x3计数渲染），而是作为空间生成算法的参数；不同的计数值产生不同频率的网格线，它们的叠加干涉图案只有在正确计数所有框之后才能推导。

## 新题 6：交替打孔后连通分裂的条件重涂

4. 在副本B（仅擦除箭头、不执行重涂的干净版本）下方拼接副本A（执行了重涂的版本），形成垂直堆叠。
5. 用蓝(1)单像素边框包裹整个堆叠结果（上下左右各一行/列蓝色边框），两个副本之间也插入一行蓝(1)分隔线。

**关键洞察**：堆叠操作将"原始状态"和"变换结果"并置展示，求解者必须同时理解两层含义——上层是移除噪声标记后的原图，下层是执行了标记指令后的重涂结果；箭头标记在两层中都必须消失，这意味着箭头是元指令而非内容。

## 新题 12：尺寸匹配印章与连通性过滤的联合约束

**组合逻辑**：[尺寸匹配/size_matching](已有) + [印章覆盖/stamp_overlay](创新：印章前需要通过连通性检测筛选合格模板) + [连通性/connectivity](创新：作为印章资格的过滤条件) + [面积大于一则涂/recolor_if_area_gt_one](创新：面积条件用于排除碎片化模板) + [纯色矩形/solid_rectangle](已有) + [多色模板/multicolor_template](已有)

**来源原语**：尺寸匹配(e76a88a6)、同尺寸替换(e76a88a6)、印章覆盖(e76a88a6)、多色模板(e76a88a6)、纯色矩形(e76a88a6)、连通性(e0fb7511)、面积大于一则涂(e0fb7511)、重涂色(e0fb7511)

**依赖链**：识别所有多色模板和灰色目标矩形 -> 按尺寸匹配候选模板与目标矩形 -> 对每个候选模板做连通性分析 -> 仅当模板中最大连通分量的面积超过模板总面积一半时，该模板合格 -> 合格模板印章到匹配尺寸的目标矩形 -> 不合格模板对应的目标矩形填充为红色警示

识别尺寸匹配的模板和目标矩形，但只有连通性良好的模板才能被印章复制到目标位置，碎片化模板的目标填红色。

**输入结构**：黑(0)背景，网格约18x18。包含3~4个矩形区域作为"模板"，每个模板是一个HxW的边界框内由2~3种非黑非灰颜色绘制的图案（可能连通也可能碎片化）。另有3~4个灰(5)实心矩形作为"目标"，其中每个目标的尺寸(H,W)恰好与某个模板的边界框尺寸匹配。生成约束：每种尺寸至多出现一对（一个模板+一个目标）；部分模板的非黑像素构成一个主体连通分量（面积>总面积的50%），部分模板的非黑像素碎片化为多个小分量（无一分量面积>50%）。

**规则**：
1. 识别所有非灰(5)的多色矩形区域作为模板，记录其边界框尺寸(H,W)。
2. 识别所有灰(5)实心矩形作为目标，记录其尺寸。
3. 按尺寸将模板与目标一一匹配（相同H和W）。
4. 对每个模板，分析其边界框内所有非黑像素的4-连通分量。找出面积最大的分量，计算其面积是否超过模板内所有非黑像素总面积的50%。
5. 若超过50%（模板合格）：将该模板完整复制到匹配的灰色目标位置，替换灰色像素。
6. 若不超过50%（模板不合格/碎片化）：将匹配的灰色目标矩形整体填充为红(2)。
7. 所有原始模板和背景保持不变。

**关键洞察**：尺寸匹配是必要条件但不充分——模板还必须通过连通性质量检测才能被采用；碎片化的模板虽然尺寸正确，但在逻辑上被判定为"损坏"而拒绝复制，其目标矩形变红作为"警报"信号。
