## 新题 1：可达区域内的周期行补全

**组合逻辑**：[泛洪填充](从角落标记出发确定可达区域) + [补全 + 周期平移](在可达区域内延续周期行图案) + [擦除](创新：仅擦除不可达区域中的非结构性墙壁碎片)

**来源原语**：泛洪填充/flood_fill（8f3a5a89）、可达性/reachability（8f3a5a89）、墙壁障碍/wall_barrier（8f3a5a89）、边界连通区分结构/border_connected_distinguishes_structural（8f3a5a89）、补全/completion（53b68214）、周期平移/periodic_translation（53b68214）、行图案/row_pattern（53b68214）、擦除/erase（8f3a5a89）

**依赖链**：墙壁障碍的结构分类（边界连通 vs 装饰）同时决定两件事：(1) 泛洪填充时哪些墙壁是真正的阻隔、(2) 哪些墙壁碎片最终会被擦除。泛洪填充的可达区域掩码限定了周期补全的作用范围——补全只能发生在可达的背景单元中。周期规则必须从被墙壁打断的不完整可见行中归纳，因为墙壁遮挡了部分图案像素。

从角落标记泛洪填充确定可达区域，在可达区域内延续被墙壁截断的周期行图案，同时擦除不可达侧的装饰性墙壁碎片。

**输入结构**：约 15x15 网格。背景黑(0)。蓝(1) 墙壁线段散布于网格中，有些触及网格边界（结构性墙壁），有些完全悬浮在内部（装饰性碎片，每段 2~4 像素）。一个品红(6) 单像素标记位于网格的某个角落。网格上方约 3~5 行包含红(2) 前景图案：每行的红色像素掩码是上一行水平平移固定偏移 S 后的结果（S 需从示例中推断），形成周期序列。部分图案行的像素被蓝色墙壁遮盖（墙壁位置与图案位置重叠时，该处显示蓝色而非红色）。网格高度大于可见图案行数，下方为空白区域等待补全。生成约束：(a) 结构性墙壁将网格分为至少两个不互通的区域；(b) 标记所在角落的可达区域覆盖图案行的大部分列范围；(c) 装饰性碎片仅出现在不可达区域中。

**规则**：
1. 分类墙壁：蓝(1) 像素组成的 4-连通分量中，与网格边界相邻的为结构性墙壁，其余为装饰性碎片。
2. 从品红(6) 标记所在角落进行泛洪填充，仅结构性墙壁阻挡扩展，标记可达的所有黑(0) 背景单元。
3. 从可见的图案行推断周期参数：垂直周期 P 为相邻两行图案掩码经水平平移后完全匹配所需的最小行间距，水平偏移 S 为每隔 P 行的列偏移量。推断时忽略被蓝色墙壁遮盖的位置（这些位置的真实值未知，不参与匹配）。
4. 对每个缺失的行 r（从可见图案行下方开始直到网格底部），计算期望掩码：复制第 r-P 行的掩码并水平平移 S 列（超出网格边界的像素丢弃）。
5. 仅在步骤 2 标记为可达的单元中绘制期望掩码的红(2) 像素；不可达单元保持黑(0)。
6. 擦除所有装饰性墙壁碎片（将其改为黑(0)）。结构性墙壁保持不变。

**关键洞察**：墙壁同时扮演三重角色——阻挡可达性、遮蔽可见图案（增加周期推断难度）、以及作为需擦除的装饰噪声。求解者必须在墙壁打断的残缺证据中推断出周期规则，再用可达性掩码选择性地应用该规则。

## 新题 2：剪切变形后的距离分层遮挡

**组合逻辑**：[剪切变换](创新：多个独立对象各自以边缘条为锚进行剪切) + [遮挡覆盖](创新：遮挡优先级由原始距离而非剪切后位置决定)

**来源原语**：剪切变换/shear_transform（423a55dc）、偏移随行距增/offset_grows_with_distance（423a55dc）、遮挡覆盖/occlusion_overwrite（13713586）、按距离排序绘制/draw_ordered_by_distance（13713586）、边缘实心条/solid_edge_bar（13713586）、前景对象/foreground_object（多题）

**依赖链**：剪切变换使原本空间分离的对象产生像素重叠。重叠区域的颜色由遮挡覆盖规则决定——按对象原始底边到锚边的距离排序绘制，近者后画、覆盖远者。距离排序使用变换前的位置，而非变换后的位置，这使得遮挡关系不可从最终画面直接观察，必须回溯原始布局。

多个彩色对象以底部边缘条为锚进行左向剪切，剪切产生的重叠区域按对象原始距离分层绘制（近者覆盖远者）。

**输入结构**：约 12x15 网格。背景黑(0)。底行是灰(5) 实心边缘条，占满整行。上方散布 3~5 个单色 4-连通前景对象，每个对象使用不同颜色（从红(2)、绿(3)、蓝(1)、黄(4)、橙(7) 中选取），每个对象约 4~8 像素，形状各异（无需特定几何名称，只要求 4-连通且单色）。各对象在变换前互不接触、互不重叠。生成约束：(a) 对象的列范围有一定交集，使得剪切后必然产生重叠；(b) 不同对象的底边行坐标互不相同（保证距离排序无歧义）。

**规则**：
1. 令灰(5) 边缘条所在行为锚行 B。
2. 对每个前景对象，记录其所有像素坐标。对每个像素 (r, c)，剪切后新位置为 (r, c - (B - r))，即每行向左偏移该行到锚行的距离。超出网格左边界（列 < 0）的像素丢弃。
3. 计算每个对象的"原始距离"：该对象最底行的行坐标与锚行 B 之间的行数差（B - max_row）。距离值越小表示越靠近锚。
4. 按原始距离从大到小的顺序依次绘制剪切后的对象（距离最大的先画，距离最小的后画）。后画的覆盖先画的。
5. 灰(5) 边缘条保持不变。

**关键洞察**：剪切使多个对象的像素在水平方向上汇聚，创造出源题中不存在的遮挡冲突。遮挡优先级基于变换前的垂直距离而非变换后的位置，因此求解者必须在心中"撤销"剪切才能判断分层顺序。

## 新题 3：面积驱动的下落与碰撞截停变色

**组合逻辑**：[平移](位移量等于对象面积) + [接触停止](创新：对象间的碰撞截停，需考虑处理顺序) + [重涂色](创新：是否被截停决定最终颜色)

**来源原语**：平移/translate（b2bc3ffd）、位移等于面积/shift_equals_area（b2bc3ffd）、计数/counting（b2bc3ffd, a3325580）、接触停止/contact_stop（56dc2b01）、重涂色/recolor（56dc2b01）、全宽条纹/full_width_stripe（b2bc3ffd）、前景对象/foreground_object（多题）

**依赖链**：面积决定每个对象的目标位移量。处理顺序（面积从小到大）决定哪些对象先落位。先落位的对象占据空间，可能阻挡后续对象的下落路径，导致截停。截停与否决定最终颜色——完成全程的保持原色，被截停的变灰。这形成一个三层因果链：面积 -> 处理顺序 + 目标位移 -> 实际落点 -> 颜色。

每个对象向下平移其自身面积对应的行数，按面积从小到大依次处理；被已落位对象阻挡而提前截停的对象变色为灰。

**输入结构**：约 14x12 网格。背景黑(0)。底行是橙(7) 全宽条纹。条纹上方散布 3~4 个单色 4-连通前景对象，颜色互不相同（从红(2)、绿(3)、蓝(1)、黄(4) 中选取），每个对象约 2~6 像素。各对象的列范围可能部分重叠，但初始位置互不接触。生成约束：(a) 至少有一对对象的列范围重叠，使得按顺序处理时会发生截停；(b) 最小面积对象下落全程不受阻；(c) 各对象面积互不相同（保证处理顺序无歧义）。

**规则**：
1. 计算每个前景对象的面积（像素数）。
2. 按面积从小到大的顺序依次处理各对象。
3. 对当前处理的对象，计算目标位移：向下平移其面积对应的行数。
4. 沿下移路径逐行检测：如果对象在某行位置会与已落位的对象或橙(7) 底部条纹发生 4-邻接接触，则停在接触前的最后一行（即接触前一行）。
5. 将对象绘制在最终位置。如果对象完成了全部目标位移（未被截停），保持原色。如果被截停（实际位移 < 目标位移），将对象重涂为灰(5)。
6. 从原位置擦除对象（设为黑(0)）。橙(7) 条纹保持不变。

**关键洞察**：处理顺序本身是隐蔽规则——面积最小的先落位，必须对比多个示例才能归纳出这一顺序依据。顺序一旦改变，碰撞关系和最终颜色都会不同。

## 新题 4：面板叠合后的涌现孔洞几何判定

**组合逻辑**：[透明叠加](两面板合并产生新拓扑结构) + [填充](创新：对叠合后涌现的封闭区域进行几何判定填充)

**来源原语**：透明叠加/overlay（94f9d214, e98196ab）、逐像素比较/per_pixel_comparison（94f9d214）、分隔行/separator_row（e98196ab）、等高面板/equal_height_panel（e98196ab）、前景不冲突/no_fg_collision（e98196ab）、填充/fill（44d8ac46）、内部包含/containment（44d8ac46）、孔洞/hole（44d8ac46）、仅正方形孔洞填充/only_square_holes_filled（44d8ac46）、孔洞几何决定填充/hole_geometry_sets_fill（44d8ac46）

**依赖链**：两个面板的叠合创造出新的连通前景结构，这些结构中可能涌现出任何一个面板单独不存在的封闭孔洞。孔洞的几何形状（正方形 vs 非正方形）决定填充颜色。这意味着填充结果完全依赖于叠合后的拓扑，而叠合后的拓扑依赖于两个面板各自的形状——形成"双源信息汇聚 -> 涌现结构 -> 条件分支"的非线性推理图。

两个面板的灰色形状叠合后产生新的封闭区域，对涌现的正方形孔洞填红、非正方形孔洞填绿。

**输入结构**：约 25x10 网格（高大于宽）。上下两个等高面板（各约 12x10），由一条全宽绿(3) 分隔行分开。每个面板内背景为黑(0)，包含 2~3 个灰(5) 矩形轮廓（即只有边框，内部为黑）。轮廓厚度为 1 像素。两面板的灰色像素在局部坐标下不冲突（不存在两面板同一位置都是灰的情况）。生成约束：(a) 叠合后，部分来自不同面板的矩形轮廓会相互连接，形成更大的封闭区域；(b) 叠合后涌现的封闭区域中至少有一个边界框为正方形、至少有一个边界框为非正方形；(c) 每个面板中单独的矩形轮廓的内部孔洞在叠合后不再独立存在（被另一面板的轮廓打断或合并）。

**规则**：
1. 移除绿(3) 分隔行。
2. 将两个面板按局部坐标对齐叠合：输出网格大小为单面板大小。对每个位置，若任一面板在该位置为灰(5)，则输出灰(5)；否则输出黑(0)。
3. 在叠合后的灰(5) 结构中，找出所有被灰色完全包围（4-连通意义下，黑色区域无法通过黑色路径到达网格边界）的黑色封闭区域。
4. 对每个封闭区域：计算其边界框。若边界框为正方形且区域完全填满边界框（即区域本身是一个实心正方形块），则将该区域所有像素填为红(2)。否则将该区域所有像素填为绿(3)。
5. 非封闭的黑色区域（可以通过黑色路径到达网格边界）保持黑(0)。

**关键洞察**：孔洞几何判定的对象不是输入中直接可见的任何形状，而是两面板叠合后涌现的拓扑结构。求解者必须先完成叠合，再在新结构上执行封闭区域检测和几何分类——任何一步都不能跳过。

## 新题 5：主干分支结构上的定向条纹发射

**组合逻辑**：[连线/连接到主干](构建主干-分支骨架) + [条纹传播](创新：从每个分支端点沿远离主干的方向发射条纹，条纹颜色循环)

**来源原语**：连线/line_drawing（bf89d739）、连接到主干/connect_to_spine（bf89d739）、控制像素/control_pixel（bf89d739）、主干线段/spine_segment（bf89d739）、共行列定义主干/shared_row_col_spine（bf89d739）、条纹传播/stripe_propagation（221dfab4）、颜色循环/color_cycle（221dfab4）、条纹范围差异/stripe_scope_difference（221dfab4）

**依赖链**：主干构建确定了哪些控制像素是主干端点、哪些是分支端点。分支的正交方向同时确定了分支线段的绘制方向和条纹发射方向。条纹从分支端点向远离主干的方向传播，传播宽度等于该分支的长度（分支越长，条纹越宽）。这创造了"拓扑构建 -> 几何参数提取 -> 参数化条纹发射"的推理链，其中分支长度既是几何结果又是后续操作的参数。

从共行/共列的红色像素对构建绿色主干，其余红色像素通过正交分支连接到主干，然后从每个分支端点沿远离主干方向发射宽度等于分支长度的条纹。

**输入结构**：约 18x18 网格。背景黑(0)。5~7 个红(2) 单像素散布于网格中。其中恰好两个红像素共享同一行（或同一列），构成主干对。其余红像素的垂直（或水平）坐标落在主干的跨度范围内。生成约束：(a) 主干为水平时，分支像素分布在主干的上方和下方都有；(b) 各分支像素到主干的距离（即分支长度）互不完全相同，至少有两种不同长度；(c) 条纹发射空间足够，不会在网格内相互重叠。

**规则**：
1. 找到共享同一行（或同一列）的唯一红(2) 像素对，将二者之间（不含端点）的背景单元涂为绿(3)，形成主干。
2. 对每个非主干的红像素，从该像素向主干方向画正交绿(3) 线段，直到到达主干行/列（不含主干行/列上的像素，保留主干原有颜色）。记录该分支的长度 L = 该像素到主干的曼哈顿距离。
3. 从每个非主干红像素的位置出发，沿远离主干的方向（即分支延伸方向的反方向）发射条纹：
   - 条纹为一组与主干平行的线段，每条线段长度等于 L（以发射点为中心，沿主干方向两侧各延伸 floor(L/2) 格，总长为 2*floor(L/2)+1 像素）。
   - 条纹间隔：从发射点出发，每隔 1 行（列）放置一条条纹（条纹行与空白行交替）。
   - 条纹颜色按放置顺序循环：黄(4)、黄(4)、蓝(1)、黄(4)、黄(4)、蓝(1)...
   - 条纹持续到网格边界为止。超出网格的部分裁剪。
4. 所有红(2) 像素保持原色不变。

**关键洞察**：分支长度在构建阶段是一个几何度量，在条纹阶段变成了条纹宽度参数——同一个量在两个推理环节中扮演完全不同的角色。此外，条纹方向取决于分支相对于主干的朝向，这要求求解者对比多个分支的条纹方向才能归纳出"远离主干"这一规则。

## 新题 6：格子压缩后的射线穿透重涂

**组合逻辑**：[压缩/多数决](将格子中的填色块压缩为单色格) + [射线延伸](创新：从边缘指示像素向压缩后的小网格发射射线，穿透重涂)

**来源原语**：压缩/compress（af24b4cc）、多数决/majority_vote（af24b4cc）、格子格局/lattice_layout（af24b4cc）、分隔行列/separator_row_col（af24b4cc）、填色块/filled_block（af24b4cc）、每块取唯一多数色/majority_color_per_block（af24b4cc）、射线延伸/ray_extend（13713586）、正交投射到边缘/orthogonal_projection_to_edge（13713586）、标记像素/marker_pixel（多题）

**依赖链**：压缩产生一个小型颜色网格，但这不是最终输出——边缘指示像素向压缩网格发射射线，覆盖射线路径上的颜色。射线方向（水平或垂直）由指示像素所在的边缘决定（顶/底边缘 -> 垂直射线，左/右边缘 -> 水平射线）。射线在遇到与自身同色的单元时停止（被"吸收"），其余单元被重涂。这意味着压缩结果中的颜色分布反过来影响射线的穿透深度——两个操作通过颜色值双向耦合。

格子中每个填色块压缩为其多数色形成小网格，然后从边缘指示像素发射射线穿透小网格，重涂路径上的单元直到遇到同色单元被吸收。

**输入结构**：约 17x17 网格。灰(5) 分隔行和分隔列（各 1 像素宽）将内部分为 4x4 共 16 个大小相等的填色块（每块约 3x3 像素）。灰分隔线包括外边框。每个填色块内部填充两种颜色的混合像素，但存在唯一多数色（可能的颜色：红(2)、绿(3)、蓝(1)、黄(4)）。在网格的外边框灰色分隔线上，有 2~3 个单像素标记，颜色为上述四色之一，位于某些行带或列带对应的分隔线位置上。生成约束：(a) 每个填色块的多数色明确唯一；(b) 标记像素分布在至少两条不同的边上（如一个在顶边、一个在左边）；(c) 至少一条射线路径上存在与射线同色的单元（触发吸收停止）。

**规则**：
1. 找到灰(5) 分隔行和分隔列，确定行带和列带，识别 4x4 的填色块格子。
2. 对每个填色块，计算其内部像素的多数色，得到一个 4x4 的压缩颜色网格。
3. 构建输出：一个 6x6 网格（4x4 内容 + 1 像素灰边框上下左右各一行/列）。内容区域的每个单元初始为对应填色块的多数色。边框为灰(5)。
4. 对每个标记像素，确定其所在的边和对应的行带/列带索引：
   - 顶边或底边的标记：对应一个列索引 j，从该边向内发射垂直射线。
   - 左边或右边的标记：对应一个行索引 i，从该边向内发射水平射线。
5. 射线沿指定方向逐格推进。对路径上的每个内容单元：若该单元当前颜色与射线颜色不同，将其重涂为射线颜色，继续前进；若该单元当前颜色与射线颜色相同，射线被吸收，停止（该单元保持原色，不再继续）。
6. 若有多条射线经过同一单元，按标记像素在输入网格边框上顺时针方向（从左上角开始）的顺序依次处理。

**关键洞察**：压缩后的颜色分布决定射线能穿透多深——射线遇到"同色吸收"就停止。这意味着求解者不能独立完成压缩和射线两步，而必须用压缩结果来推断射线行为，形成真正的数据依赖。射线处理顺序也是隐蔽规则，需对比多个示例归纳。

## 新题 7：杯形内填充后按面积筛选输出柱状图

**组合逻辑**：[填充](创新：根据杯形轮廓的开口确定内部区域并泛洪填充) + [计数 + 面积筛选](面积相同的杯保留) + [排序 + 柱状图输出](创新：按水平位置排列为柱状图)

**来源原语**：填充/fill（d4f3cd78）、杯形轮廓/cup_outline（d4f3cd78）、开口/opening（d4f3cd78）、封闭区域/enclosed_region（d4f3cd78）、开口朝向/opening_direction（d4f3cd78）、计数/counting（a3325580）、排序/sort（a3325580）、面积筛选/area_filtering（a3325580）、连通分量/connected_component（a3325580）、柱状图/histogram_bar（a3325580）、最大面积输出条/largest_area_as_color_bars（a3325580）、忽略干扰项/ignore_distractors（a3325580）

**依赖链**：杯的开口位置和大小直接影响内部可填充区域的面积——开口越大，"泄漏"的面积越多（开口方向的像素行/列无法被围住），导致有效内部面积缩减。面积筛选使用填充后的内部面积（非轮廓面积），再转为柱状图输出。这意味着杯的几何结构（开口大小/位置）通过填充间接决定了筛选结果，而非直接可见。

多个不同颜色的杯形轮廓各自内部填充后计算填充面积，仅保留填充面积最大的杯，按水平位置输出等高柱状图。

**输入结构**：约 16x16 网格。背景黑(0)。3~5 个杯形轮廓，每个由不同颜色（红(2)、蓝(1)、黄(4)、绿(3)、橙(7) 中选取）的单像素厚矩形边框构成，边框上有一处连续缺口（开口），缺口宽度 1~3 像素。各杯大小可能不同（边框约 4x4 到 6x6 像素），开口朝向可能不同（上/下/左/右）。杯之间互不接触、互不重叠。另有 2~3 个孤立的单色像素（干扰项），颜色与某些杯相同。生成约束：(a) 至少两个杯的轮廓边框面积相同但开口大小不同，导致填充面积不同；(b) 填充面积最大的杯有且仅有一组（可能多个杯面积并列最大）；(c) 填充面积最大的杯有不同的左边缘列坐标（保证水平排序无歧义）。

**规则**：
1. 识别每个杯形轮廓（忽略孤立干扰像素——像素数 <= 1 的连通分量为干扰项）。
2. 对每个杯：找到其矩形边框的边界框，识别边框上的缺口（开口）。从边框内部（边界框严格内部的黑色区域）进行泛洪填充，但填充不能穿过开口扩展到外部——具体做法是：将开口视为边框的一部分临时封堵，对封堵后的内部进行泛洪填充，再移除封堵，得到有效内部区域。有效内部面积 = 封堵后的内部像素数 - 开口宽度对应的行/列像素数（开口处那些没有真正被围住的像素不计入面积）。
   - 简化等价描述：有效内部面积 = 边界框内部面积 - 开口暴露的行/列上不被三面边框包围的像素数。
3. 实际更简洁的计算方式：在边框内部做标准泛洪填充（从边框内部任一黑色像素开始，4-连通扩展，以边框颜色为墙壁），开口处的缺口允许泛洪"泄漏"到外部。只计算未泄漏到外部的封闭内部像素数作为有效面积。如果整个内部都泄漏了（开口导致内部与外部连通），则有效面积为 0。
4. 找到最大有效内部面积值 M。保留所有有效面积 = M 的杯。
5. 输出网格高度 = M，宽度 = 被保留的杯的数量。每列为一个实心垂直条，颜色为对应杯的轮廓颜色，列的排列顺序为杯在输入中的左边缘列坐标从小到大。

**关键洞察**：开口不仅是视觉特征——它决定了内部是否"泄漏"以及泄漏多少，从而直接影响有效面积。两个外形相似的杯可能因为开口大小差一个像素而产生截然不同的面积，进而影响筛选结果。求解者必须理解"泛洪泄漏"机制才能正确计算面积。

**关键洞察**：精灵模板在输入中不可见——它是两面板"共同空白"的逆向推导结果。求解者必须先理解"双面板比较产生精灵"这一生成机制，再将其应用于印章分发。精灵的形状完全由两面板的前景布局隐式编码。

## 新题 9：对角分解驱动的周期线段阵列

**组合逻辑**：[对角分解](将标记对的偏移向量分解为对角分量和轴向分量) + [补全/周期平移](创新：以对角分量为平移向量、轴向分量为线段方向，生成周期重复的平行线段阵列)

**来源原语**：对角分解/diag_decompose（cb227835）、标记像素/marker_pixel（cb227835）、标记为对顶点/markers_as_vertices（cb227835）、连线/line_drawing（cb227835）、补全/completion（53b68214）、周期平移/periodic_translation（53b68214）、行图案/row_pattern（53b68214）

**依赖链**：对角分解产生两个向量分量，但这两个分量的用途与源题完全不同：一个分量定义线段的方向和长度（画什么），另一个分量定义线段的周期平移步长（怎么重复）。标记对的位置决定分解结果，分解结果同时参数化绘制和平铺两个操作。三者形成"位置 -> 分解 -> 绘制参数 + 平铺参数"的分叉-汇合结构。

两个标记像素的偏移向量被分解为对角分量和轴向分量，轴向分量定义一条种子线段，对角分量作为平移步长将种子线段周期重复铺满网格。

**输入结构**：约 15x15 网格。背景黑(0)。恰好两个红(2) 标记像素，它们的行坐标和列坐标均不同（即不共行不共列）。两标记的行偏移和列偏移的绝对值不相等（保证对角分解唯一：对角分量取 min(|dr|, |dc|) 步的 45 度方向，轴向分量为剩余部分）。生成约束：(a) 分解后的轴向分量长度 >= 2（保证种子线段可见）；(b) 对角分量的步长使得周期平移后至少能在网格内放置 3 条线段；(c) 两个标记不相邻。

**规则**：
1. 计算两标记像素之间的偏移向量 (dr, dc)。
2. 对角分解：设 m = min(|dr|, |dc|)。对角分量 D 为沿 45 度方向走 m 步的向量：D = (m * sign(dr), m * sign(dc))。轴向分量 A 为剩余部分：A = (dr, dc) - D，即 A = ((|dr|-m)*sign(dr), 0) 或 A = (0, (|dc|-m)*sign(dc))，取决于 |dr| 和 |dc| 哪个更大。
3. 种子线段：从第一个标记像素出发，沿轴向分量 A 的方向画一条绿(3) 线段，长度等于 |A| 的曼哈顿距离 + 1 像素（包含起点和终点）。线段为水平或垂直（由 A 的非零分量决定）。
4. 周期平铺：将种子线段沿对角分量 D 的方向反复平移。每次平移一个完整的 D 向量。在每个平移位置画一条相同长度和方向的绿(3) 线段。平移同时向 D 方向和 -D 方向扩展，直到线段完全超出网格边界为止。超出边界的像素裁剪。
5. 红(2) 标记像素保持原色（覆盖在绿色之上）。

**关键洞察**：源题中对角分解用于画平行四边形的两条边，而这里同一个分解的两个分量分别充当"画什么"和"怎么铺"的角色——这种将几何分解结果路由到不同操作的做法在任何一道源题中都不存在。

**输入结构**：约 16x16 网格。背景黑(0)。主区域占据网格大部分空间，包含 3~5 个不同颜色的封闭矩形区域（实心填充的矩形，颜色从蓝(1)、红(2)、绿(3)、黄(4)、橙(7) 中选取），各矩形约 4x4 到 7x7 像素，互不重叠、互不接触。网格的某个角落（如右下角）有一个 3x3 或 3x5 的小型图例区域，由灰(5) 单像素边框包围。图例内部分为若干行，每行有两个像素：左像素颜色表示"源色"（与主区域某矩形颜色相同），右像素颜色表示"描边色"（该源色矩形应使用的内边颜色）。生成约束：(a) 图例中的源色覆盖了主区域中的部分颜色但不是全部——未列入图例的颜色的矩形不做任何操作；(b) 描边色不与任何矩形的填充色重复；(c) 图例行数 >= 2。

**规则**：
1. 识别灰(5) 边框包围的图例区域。读取图例：每行的左像素为源色 S，右像素为描边色 T，形成映射 {S -> T}。
2. 对主区域中的每个封闭矩形区域，检查其填充颜色是否在图例映射中：
   - 若在：在该矩形内部画一圈 1 像素宽的内边框，颜色为映射得到的描边色 T。即矩形边缘最外一圈像素保持原色，次外圈（距矩形边缘恰好 1 像素的内部像素）重涂为 T。若矩形太小（宽或高 <= 2，内部无空间画次外圈），则不做操作。
   - 若不在：保持原样。
3. 擦除图例区域：将灰色边框及其内部所有像素设为黑(0)。
4. 主区域中未被图例提及的矩形保持不变。

**关键洞察**：图例是一个自毁性的元信息源——它指导了哪些区域需要描边以及描边颜色，然后自身被擦除。求解者必须先解码图例再执行描边，且需要对比多个示例才能确定"内边框"的精确含义（是距边缘 1 像素的次外圈，不是最外圈）。
