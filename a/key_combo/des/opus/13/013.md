## 新题 1：投射标记划定瓦片修复区

**组合逻辑**：[投射/project] → [碰撞阻挡/collision_blocking](创新：射线终止条件从"碰到目标对象"改为"碰到任意非背景像素") → [周期推断/period_inference] → [补全/complete](创新：补全范围被射线路径限定，而非修复所有缺损)

**来源原语**：投射、标记像素、碰撞阻挡（参考题 1f642eb9）；周期推断、补全、缺损像素、非缺损像素一致性（参考题 c663677b）；画布边界（参考题 1f642eb9）

**依赖链**：边界标记投射产生射线路径 → 射线路径划定可修复区域 → 区域内的缺损像素依据瓦片周期推断取色 → 区域外的缺损像素保持黑色。射线的终止位置由碰撞阻挡决定，碰撞目标是非缺损瓦片像素，因此瓦片的完好部分反过来限制了射线长度。

将边界标记的投射射线作为空间掩码，仅修复射线路径覆盖到的缺损瓦片像素，射线之外的缺损保持不变。

**输入结构**：
- 网格约 18x18，背景 = 黑(0)
- 一个重复矩形瓦片图案覆盖大部分网格，瓦片周期约 3x3 或 4x4，使用颜色集合 {蓝(1), 红(2), 绿(3), 黄(4)} 中的 2-3 种
- 若干不规则区域（每块约 3-8 像素）被"损坏"为黑(0)，打断了瓦片图案。损坏区域之间不相邻
- 网格最外缘（第一行/最后一行/第一列/最后一列）上放置 2-4 个单像素彩色标记，颜色取自 {灰(5), 品红(6), 橙(7)}，与瓦片颜色不重叠。标记之间颜色可以相同也可以不同
- 生成约束：每个标记所在的行或列至少穿过一个损坏区域；每个损坏区域至少被一个标记的行或列穿过；标记不位于网格角上

**规则**：
1. 识别边界标记：网格最外缘上的非瓦片色、非背景色的单像素。位于第一行或最后一行的标记沿其所在列向网格内部投射；位于第一列或最后一列的标记沿其所在行向网格内部投射
2. 每条射线从标记相邻的内侧像素开始，沿投射方向逐像素前进，在遇到第一个非黑(0)像素时停止（不包含该非黑像素本身）。射线经过的所有像素位置构成该标记的"修复通道"
3. 从网格中所有未被射线覆盖、未被损坏的瓦片像素中，推断最小行周期和列周期，使得这些像素在该周期下按相位一致
4. 对于每个黑(0)像素：若它位于任意一条射线的修复通道内，则将其替换为由瓦片周期相位决定的颜色；若它不在任何修复通道内，保持黑(0)
5. 擦除所有标记像素（替换为黑(0)），擦除射线路径上非缺损的像素痕迹（射线仅作为逻辑标记使用，不在输出中显示）
6. 输出网格尺寸与输入相同

**关键洞察**：标记决定"在哪里修复"，瓦片周期决定"修复成什么颜色"——两个独立逻辑通过空间交集耦合。射线在碰到完好瓦片像素时终止，因此瓦片自身的完好结构反向限制了可修复范围，形成双向依赖。需要对比多个示例才能发现射线的碰撞终止规则（终止于非黑像素而非损坏区域边界）。

## 新题 2：自相似展开的异或差异图

**组合逻辑**：[印章覆盖/stamp_overlay + 前景位放自身副本/fg_position_copy](两个种子各自独立展开) → [逐像素比较/cell_by_cell_comparison + 异或差异判定/xor_difference](对两个展开结果取对称差)

**来源原语**：印章覆盖、前景位放自身副本、种子精灵、像素到块映射（参考题 5b6cbef5）；逐像素比较、差异标记、异或差异判定、面板对齐、分隔列、二值掩码（参考题 34b99a2b）

**依赖链**：两个种子面板各自按自相似规则展开为 N^2 x N^2 的二值图形 → 两个展开图逐像素异或比较 → 仅输出差异像素。展开规则和比较规则在逻辑上不可分离：不理解自相似展开就无法计算中间形态，不理解异或就无法从中间形态得到最终输出。

两个种子精灵各自进行自相似分形展开，输出仅保留两个展开图中恰好一个有前景的像素位置。

**输入结构**：
- 网格约 9x4（两个 4x4 面板中间夹一列灰(5)分隔列）或 7x3（两个 3x3 面板夹一列分隔列），具体尺寸取决于种子大小 N
- 左面板：NxN 网格，背景 = 黑(0)，前景 = 蓝(1)，前景像素 3-6 个，构成一个 4-连通的单色图形
- 右面板：NxN 网格，背景 = 黑(0)，前景 = 绿(3)，前景像素 3-6 个，构成一个不同于左面板的 4-连通单色图形
- 中间分隔列为灰(5)，宽 1 列
- 生成约束：两个种子的前景像素数量不必相同；两个种子的自相似展开结果之间存在非空的对称差（即不完全重合也不完全互补）

**规则**：
1. 将输入沿灰(5)分隔列拆分为左种子 S_L 和右种子 S_R，均为 NxN
2. 对每个种子执行自相似块展开：生成一个 N^2 x N^2 的网格，将其划分为 NxN 个 NxN 块。对于种子中位置 (r,c) 处的像素：若为前景色，则将整个种子图案（保留原色）复制到对应块 (r,c)；若为背景色，则对应块 (r,c) 全部填黑(0)
3. 将两个展开结果逐像素比较：对于 N^2 x N^2 输出网格中的每个位置 (i,j)，若恰好一个展开图在该位置有非黑前景像素，则输出红(2)；否则（两个都有前景或两个都是黑色）输出黑(0)
4. 输出为 N^2 x N^2 的红黑二值网格，不包含分隔列

**关键洞察**：输出中不直接显示任何一个展开图——仅展示它们的对称差。求解者必须心算两次自相似分形展开，再取异或，才能得到最终图案。由于展开是自相似的（分形结构），异或图案的结构并非简单的缩放叠加，需要对比多个示例才能区分自相似展开与简单最近邻放大。

## 新题 3：轮廓描边生成射线源，障碍物截断射线

**组合逻辑**：[轮廓描边/outline_trace + 最小色为画笔/smallest_as_paint](计算外轮廓并确定射线颜色) → [射线延伸/ray_extend](从每个轮廓像素向外发射射线) → [碰撞阻挡/collision_blocking + 障碍偏转绕行/obstacle_deflection](障碍物截断射线) → [擦除/erase](移除原始轮廓和内部)

**来源原语**：轮廓描边、外侧相邻、标记色、最小色为画笔、轮廓线（参考题 aa62e3f4）；射线延伸、障碍块、碰撞阻挡、障碍偏转绕行、边缘起始、源像素（参考题 69889d6e）；擦除（参考题 aa62e3f4, 7c66cb00）

**依赖链**：轮廓线的几何形状决定外轮廓像素的位置和数量 → 外轮廓像素成为射线发射源 → 射线方向由轮廓像素相对于轮廓质心的方位决定 → 障碍物截断射线长度 → 原始轮廓被擦除（射线源信息仅存在于中间步骤）。删除轮廓描边，则无法知道射线从哪里发射；删除射线延伸，则只剩一圈轮廓像素；删除障碍规则，射线会到达错误的长度。

对闭合轮廓形状求外轮廓，以内部标记色为画笔从每个外轮廓像素沿离心方向发射射线，射线遇到障碍物时截止，最后擦除原始轮廓。

**输入结构**：
- 网格约 15x15，背景 = 黑(0)
- 一个闭合的 8-连通轮廓形状，颜色为橙(7)，由约 12-20 个像素构成。轮廓围成一个中空区域（内部为黑色背景），轮廓自身不构成实心填充，而是类似线框
- 轮廓内部有 1-2 个品红(6)像素——这是标记色，为轮廓内部出现的像素数最少的非轮廓色
- 轮廓外部散布 2-4 个红(2)色的小障碍物，每个障碍物由 1-3 个 4-连通像素构成，各障碍物之间互不相邻，且没有障碍物直接 4-相邻于轮廓
- 生成约束：轮廓的质心在轮廓内部；每个外轮廓像素到质心的方向可以近似为一个唯一的主方位（上、下、左、右），不存在方位模糊的外轮廓像素

**规则**：
1. 识别轮廓：最大的非背景 8-连通分量（橙(7)）。识别标记色：轮廓内部像素数最少的颜色（品红(6)）
2. 计算轮廓的几何质心（所有轮廓像素坐标的算术平均）
3. 计算外轮廓：所有与轮廓像素 4-相邻的黑(0)背景像素
4. 对每个外轮廓像素 P，计算从质心到 P 的方向向量，选择与该向量夹角最小的基本方位（上/下/左/右）作为 P 的射线方向。若两个基本方位夹角相等（精确 45 度对角线），选择水平方向（左或右）
5. 从每个外轮廓像素 P 出发，沿其射线方向逐像素前进，将经过的每个像素涂为品红(6)。射线在以下任一条件下终止：(a) 下一个像素超出网格边界——射线涂到最后一个网格内像素后停止；(b) 下一个像素是红(2)障碍物——射线涂到障碍物前一格后停止，障碍物保持不变
6. 擦除所有橙(7)轮廓像素和品红(6)标记像素（即原始轮廓和内部标记被替换为黑(0)）。注意：步骤 5 新涂的品红像素保留（它们是射线路径上的新像素，不属于原始标记）
7. 红(2)障碍物像素保持不变
8. 输出网格尺寸与输入相同

**关键洞察**：轮廓自身在输出中完全消失——它仅用于定义射线发射源的位置和方向。标记色（由"内部最少色即画笔"规则确定）成为射线颜色。障碍物在射线前方投下"阴影"，使得障碍物背后没有射线到达。需要对比多个示例才能发现射线方向的确定规则（离心方向，而非四个方向全射，且对角线情况优先取水平方向）。

## 新题 4：拼图组装后按最近边重涂色

**组合逻辑**：[拼接/assemble + 连接配对/connector_pairing + 逐步拼合/incremental_assembly](散落精灵体经连接像素组装) → [重涂色/recolor + 最近边归属/nearest_side_assignment](组装后的结构按像素到边界框各边的距离重涂色)

**来源原语**：拼接、精灵体、锚点精灵、连接像素、连接配对、逐步拼合（参考题 cbebaa4b）；重涂色、空心矩形、前景掩码、最近边归属、最近边决定涂色（参考题 9aec4887）

**依赖链**：精灵体通过红色连接像素逐步拼合为一体 → 拼合后的整体形状决定了其边界框 → 每个非连接像素到边界框四边的 Manhattan 距离决定其重涂色目标 → 距离相等时保留原色（暴露了组装前的原始精灵色作为例外信息）。组装步骤决定最终形状，最终形状决定距离关系，距离关系决定颜色——因果链不可跳步。

将散落的带连接像素的精灵体拼装成完整结构，然后根据每个像素到组装体边界框四边的距离，将其重涂为对应边的颜色。

**输入结构**：
- 网格约 20x20，背景 = 黑(0)
- 一个锚点精灵体，包含一个 3x3 黄(4)实心块，周边带有若干红(2)连接像素，总像素数约 12-16
- 另有 3-5 个可移动精灵体散布在网格上，每个精灵体由一种独特的体色（取自 {蓝(1), 绿(3), 灰(5), 品红(6), 橙(7)} 中的不同颜色）加上红(2)连接像素构成，每个精灵体总像素数 4-8，形状为不规则的 4-连通图形
- 所有精灵体之间互不重叠、互不相邻
- 生成约束：连接配对无歧义——每个红(2)像素恰好与另一个红(2)像素配对（可通过空间位置唯一确定配对关系）；完成组装后的整体结构的边界框至少 6x6

**规则**：
1. 锚点精灵体保持原位。逐个将其余精灵体平移，使其某一红(2)连接像素与已组装体上一个未配对的红(2)像素重合。每次只添加一个精灵体，每个红(2)连接像素恰好与另一个配对
2. 组装完成后，计算整个拼合体的紧凑边界框（最小包围矩形）
3. 定义边界框四边的颜色：顶边 = 蓝(1)，右边 = 绿(3)，底边 = 橙(7)，左边 = 品红(6)
4. 对于拼合体中每个非红(2)的像素，计算其在边界框内部的 Manhattan 距离到四边的距离（顶边距离 = 该像素行号 - 边界框顶行，底边距离 = 边界框底行 - 该像素行号，左边距离和右边距离同理）
5. 若该像素到四边中最近的唯一一边距离严格最小，将该像素重涂为该边对应的颜色
6. 若最近距离存在平局（到两边或多边距离相同），保留该像素当前的颜色不变
7. 红(2)连接像素始终保持红(2)不变
8. 裁剪输出为边界框大小（含边界框最外行列）

**关键洞察**：组装前各精灵体的独特体色在输出中几乎完全被边距颜色覆盖——体色仅在到多边等距的像素上存活，成为间接暴露组装结构的"化石"。需要对比多个示例才能推断四边对应的固定颜色映射（顶→蓝、右→绿等），因为这一映射无法从输入结构直接推导。

## 新题 5：色彩互换对接后同色纵向连线

**组合逻辑**：[对接/dock + 同色匹配/same_color_matching + 色彩互换/color_swap](精灵体按颜色匹配对接到色条中并交换颜色) → [连线/connect + 同色邻接/same_color_adjacent](对接后产生的新色在相邻色条间建立纵向连接) → [间隙填充/gap_filling](连接线填充条间空隙)

**来源原语**：对接、色彩互换、双色精灵体、色条、同色匹配、颜色反转映射（参考题 7c66cb00）；连线、同色邻接、同色邻居连接、连接条（参考题 33067df9）；间隙填充（参考题 1e97544e）

**依赖链**：精灵体对接时发生色彩互换，产生新的颜色身份 → 新颜色身份决定哪些已对接精灵体之间建立纵向连接 → 连接线的水平位置由对接时确定的 x 坐标决定。色彩互换这一中间变换使得"匹配哪些精灵体"变成非显然推理——原始颜色 A 的精灵体在互换后可能变成颜色 B，与另一条色条中互换后恰好也变成 B 的精灵体产生连接。

双色精灵体按外色匹配对接到色条中并完成色彩互换，之后检查相邻色条中的已对接精灵体，若互换后颜色相同则用纵向连线填充它们之间的空隙。

**输入结构**：
- 网格约 16x20，背景 = 黑(0)
- 上方区域（前 4-5 行）：3-5 个双色精灵体，每个约 4-6 像素，具有外色和内色两种颜色（外色包裹内色，类似边框包芯）。各精灵体水平分散放置，互不重叠。外色和内色取自 {蓝(1), 绿(3), 黄(4), 灰(5), 品红(6), 橙(7), 青(8)}
- 下方区域（第 7 行起）：3-5 条水平色条，每条占一行，宽度覆盖大部分列。每条色条有一个填充色和一个边框色（左右两端各 1 像素为边框色，中间为填充色）。相邻色条之间间隔 2-3 行黑(0)背景
- 生成约束：每个精灵体的外色恰好匹配一条色条的填充色（唯一匹配）；完成所有对接和色彩互换后，至少存在一对纵向相邻色条中的两个已对接精灵体互换后的内色相同；不存在三条或更多色条中的精灵体互换后内色都相同的情况（只有成对连接）

**规则**：
1. 对接：将每个精灵体匹配到填充色等于该精灵体外色的色条。将精灵体平移到其原始水平位置（保持原始列坐标）、垂直对齐到该色条的底行
2. 色彩互换：对接后的精灵体执行颜色交换——精灵体的外色替换为色条的边框色，精灵体的内色替换为色条的填充色
3. 擦除上方区域中精灵体的原始位置（替换为黑(0)）
4. 连线判定：对于每对纵向相邻的色条（上方色条 A 和紧接其下的色条 B），检查 A 中已对接精灵体的互换后内色是否与 B 中某个已对接精灵体的互换后内色相同
5. 若存在这样的匹配对，在两条色条之间的空隙行中绘制一条纵向连接线：连接线的列位置取两个精灵体水平位置的中点列（向下取整），连接线颜色为该匹配的互换后内色，连接线从上方色条的下一行垂直绘制到下方色条的上一行
6. 若两个精灵体恰好在同一列，连接线为 1 像素宽的垂直线段；若不在同一列，连接线为 L 形——先从上方精灵体的列垂直向下到空隙的中间行，再水平到下方精灵体的列，再垂直向下到下方色条
7. 所有原始色条、边框、已对接精灵体保持不变（除了步骤 2 的色彩互换）

**关键洞察**：纵向连接的触发条件是"互换后的内色相同"——而互换后的内色实际上等于各自色条的填充色。这意味着只有对接到"填充色相同的两条色条"中的精灵体才会被连接，但由于精灵体的外色（而非内色）决定对接目标，求解者必须追踪完整的颜色交换链才能判断哪些精灵体最终会被连接。需要多个示例才能区分"连接基于互换前的内色"还是"互换后的内色"。

## 新题 6：端点拼接路径的周期相位着色

**组合逻辑**：[滑动/sliding + 端点匹配拼接/endpoint_match_concat](路径片段按端点对齐拼接成一条连贯链) → [周期推断/periodic_inference](从图例条推断颜色周期) → [重涂色/recolor + 按列周期取色/column_modular_phase](创新：相位不按列确定，而按路径行走步数确定)

**来源原语**：滑动、拼接、端点对齐、端点匹配拼接、路径片段、端点（参考题 d017b73f）；周期推断、按列周期取色（参考题 1e97544e）；重涂色（参考题 9aec4887, a740d043）；颜色图例、编码映射（参考题 edb79dae）

**依赖链**：路径片段的端点对齐决定各片段的垂直位移 → 拼接后形成一条连贯路径 → 路径的行走顺序决定每个像素的相位编号 → 图例条中推断出的颜色周期按相位编号为每个像素分配最终颜色。路径拼接顺序影响行走步序，步序影响相位，相位影响颜色——三步缺一不可。

将被空白列分隔的灰色路径片段按端点行对齐拼接成一条链，再沿链行走，按图例颜色周期逐像素着色。

**输入结构**：
- 网格约 8x22，背景 = 黑(0)
- 3-5 个灰(5)色路径片段，每段由 3-8 个 4-连通像素构成一条无分支路径（每个像素最多两个 4-邻居），各段占据不同的连续列区间，段间由全黑列分隔（至少 1 列宽）
- 每段在其最左列恰好有一个度为 1 的像素（左端点），在其最右列恰好有一个度为 1 的像素（右端点）
- 网格底部（与路径区域间隔 1-2 行黑色行）有一行图例条：一排连续的彩色像素，长度为 k * c（k >= 2，c 为颜色周期长度 2-4），使用 {蓝(1), 红(2), 绿(3), 黄(4)} 等颜色的某个子集按固定顺序重复排列
- 生成约束：相邻片段的右端点行和左端点行不同（需要垂直位移才能对齐）；拼接后路径无像素重叠；图例条中颜色周期可以被唯一推断（最短重复单元）

**规则**：
1. 识别所有路径片段（灰(5)连通分量）和底部图例条（非灰非黑的连续水平像素行）
2. 从图例条推断颜色周期：找到最短重复子序列 C = [c_0, c_1, ..., c_{p-1}]，使得图例条是 C 的若干次重复
3. 删除路径片段之间的全黑分隔列。保持第一段在原始垂直位置
4. 从左到右处理后续片段：将当前片段整体垂直平移，使其左端点行与前一段的右端点行对齐，然后水平紧贴前一段的最右列之后放置
5. 拼接完成后，从最终路径的最左端点出发，沿 4-连通路径逐像素行走到最右端点。步数从 0 开始编号
6. 将步数为 i 的像素重涂为 C[i mod p]（颜色周期的第 i mod p 个颜色）
7. 从输出中移除图例条。输出仅包含重涂后的路径（在黑色背景上），输出网格高度保持不变，宽度为去除分隔列后的总宽度

**关键洞察**：颜色相位跟随路径行走步序而非网格列坐标——同一列上的两个像素可能因在路径中的步序不同而获得不同颜色。需要对比多个示例才能发现"相位按行走步数递增"（而非"按列号递增"或"按行号递增"），因为在直线段上这两种规则产生相同结果，只有在路径弯折处才能区分。

## 新题 7：瓦片相位与最近框边的与门填充

**组合逻辑**：[周期推断/period_inference + 周期相位对应/periodic_phase_match](推断内部残存瓦片图案的周期) ∧ [最近边归属/nearest_side_assignment + 最近边决定涂色/recolor_by_nearest_frame_side](计算每个空白像素到四色框各边的距离归属) → [填充/fill](仅当瓦片相位颜色与最近框边颜色一致时才填充)——同时约束满足结构，非流水线

**来源原语**：周期推断、补全、重复瓦片、缺损像素、非缺损像素一致性、周期相位对应（参考题 c663677b）；最近边归属、最近边决定涂色、空心矩形（参考题 9aec4887）；填充（参考题 770cc55f）

**依赖链**：这不是流水线结构，而是同时约束满足——每个空白像素必须同时通过两个独立测试才被填充：(1) 瓦片周期相位测试给出该像素"应该是什么颜色"；(2) 最近框边测试给出该像素"被哪条边管辖"。只有当两者给出同一颜色时，像素才被填充。两条逻辑独立运算，交集决定输出。

在四色矩形框内部，残缺的重复瓦片图案有大量黑色空洞。仅当一个空洞像素的瓦片相位颜色恰好等于其最近框边颜色时，才将其填充，否则保持黑色。

**输入结构**：
- 网格约 14x14，背景 = 黑(0)
- 一个矩形框（1 像素宽边框），框的四边各有不同颜色：顶边 = 蓝(1)，右边 = 红(2)，底边 = 绿(3)，左边 = 黄(4)。框的四个角像素为黑(0)。框内部约 10x10
- 框内部有一个部分可见的重复瓦片图案，瓦片周期为 2x2 或 3x3，恰好使用与框边相同的四种颜色 {蓝(1), 红(2), 绿(3), 黄(4)}
- 框内部约 30%-50% 的像素为黑(0)空洞（缺损像素），其余为可见的瓦片像素
- 生成约束：可见瓦片像素足以唯一推断瓦片周期和相位；空洞中同时存在"瓦片相位色 = 最近框边色"和"瓦片相位色 ≠ 最近框边色"两种情况（确保规则可辨识）；不存在到两条框边等距的空洞像素（即每个空洞像素有唯一最近边，生成时保证框内部为奇数尺寸或空洞不在对角线上）

**规则**：
1. 识别矩形框及其四边颜色（顶、右、底、左）
2. 从框内部的非黑(0)像素推断重复瓦片图案的行周期 p_r 和列周期 p_c，使得所有可见像素满足：像素颜色 = tile[(row - frame_top - 1) mod p_r][(col - frame_left - 1) mod p_c]
3. 对于每个框内部的黑(0)像素：
   a. 计算其瓦片相位颜色：tile[(row - frame_top - 1) mod p_r][(col - frame_left - 1) mod p_c]
   b. 计算其到框四边的 Manhattan 距离（到顶边 = row - frame_top，到底边 = frame_bottom - row，到左边 = col - frame_left，到右边 = frame_right - col），取最小距离对应的边为"最近边"
   c. 若瓦片相位颜色 = 最近框边颜色 → 将该像素填充为该颜色
   d. 若瓦片相位颜色 ≠ 最近框边颜色 → 保持黑(0)
4. 所有原始可见瓦片像素和框边像素保持不变
5. 输出网格尺寸与输入相同

**关键洞察**：输出图案既不是完整的瓦片修复（许多本应修复的像素因为不在"正确"的框边管辖区而被留空），也不是简单的最近边着色（许多离某边最近的像素因为其瓦片相位不匹配该边颜色而被留空）。最终图案是两个独立空间逻辑的交集，产生一种视觉上既有周期性又有空间分区特征的涌现图案，无法从单一规则预测。需要对比多个示例才能排除"只做瓦片修复"或"只做最近边着色"的假设，发现两者必须同时满足。
