## 新题 1：频率角色驱动的射线分区与交替填色

**组合逻辑**：[射线延伸](从孤立像素发射十字射线，用于分区) + [重涂色/交替着色](对分区后的矩形区域按奇偶规则填色) ← [按频率分配](创新：频率不再决定十字图案中的角色，而是决定哪种颜色成为射线源、哪两种颜色成为交替填色的调色板)

**来源原语**：射线延伸(ray_extend) ← 9def23fe/99fa7670；重涂色(recolor) ← c8f0f002；按频率分配(freq_role_assignment) ← 3979b1a8；交替着色(alternating_coloring) ← 3bd292e8；孤立像素(isolated_pixel) ← 99fa7670；背景区域(background_region) ← 3bd292e8

**依赖链**：频率分配决定三种颜色的角色（射线/偶填/奇填）→ 射线源像素发射十字射线，划分画布为矩形区域 → 区域的行带-列带奇偶性决定使用哪种填色。三个环节紧耦合：不知道频率就无法分配角色，没有射线就没有分区，没有分区就没有奇偶位置。

将散落三色像素按频率分配为射线源与填色对，射线分割画布后用奇偶规则交替填入两种填色。

**输入结构**：约 12x12 的黑(0)背景网格。恰好包含 3 种非黑颜色的孤立单像素（互不相邻、不在同一行或同一列）。三种颜色的像素数量各不相同（例如 1、2、4 个），不同示例中充当各角色的具体颜色会变化。所有非黑像素均为孤立点（4-邻接无同色邻居）。生成约束：三色像素数量严格互不相等；射线源色的像素不共享行或列（保证射线不重叠）。

**规则**：
1. 统计三种非黑颜色各自的像素数量。像素数最少的颜色记为"射线色"，中间的记为"偶填色"，最多的记为"奇填色"。
2. 从每个射线色像素出发，沿上、下、左、右四个方向画射线直到网格边缘，将路径上的所有黑(0)像素涂为射线色。射线经过其他非黑像素时跳过该像素（保留原色），继续向后延伸。
3. 射线将黑色背景划分为若干 4-连通的矩形区域。以网格左上角所在区域为 (0,0)，按行带索引 r 和列带索引 c 编号各区域（行带从上到下递增，列带从左到右递增）。
4. 若 r+c 为偶数，将该区域内所有黑(0)像素涂为偶填色；若 r+c 为奇数，涂为奇填色。
5. 保留所有射线像素和原始非射线色的孤立像素不变。

**关键洞察**：同一颜色在不同示例中可能扮演射线源或填色角色——角色完全由像素数量的相对排名决定，需对比多个示例才能归纳出频率-角色映射规则。

## 新题 2：障碍阴影泛洪与图例查表重涂

**组合逻辑**：[泛洪填充](填充半封闭区域并穿过开口辐射) + [查表替换](创新：种子色不是输出色，而是图例中的查找键，输出色由图例决定) ← [障碍投射阴影](障碍物阻断辐射方向上的填充传播)

**来源原语**：泛洪填充(flood_fill) ← b9e38dc0；障碍投射阴影(obstacle_casts_shadow) ← b9e38dc0；半封闭墙(partial_enclosure) ← b9e38dc0；查表替换(lookup_replace) ← b20f7c8b；图例面板(legend_panel) ← b20f7c8b/58743b76

**依赖链**：泛洪填充确定每个区域的形状（受墙壁和障碍物约束）→ 种子颜色在图例中查找对应的输出颜色 → 将填充区域重涂为查表结果色。去掉泛洪填充则无区域形状；去掉障碍物则区域形状不同；去掉图例则无法确定最终颜色。

半封闭墙围出的区域通过开口泛洪外溢，障碍物在辐射方向投射阴影截断填充范围；填充完成后，种子颜色经图例查表替换为输出颜色。

**输入结构**：约 15x15 的黑(0)背景网格。顶部 2 行为图例区：由灰(5)分隔线隔开若干 1x2 色块对，每对左列为"输入色"、右列为"输出色"（例如红(2)→绿(3)、蓝(1)→黄(4)），图例中的颜色对数量与下方封闭区域数量一致。图例下方为主操作区，包含 2-3 个灰(5)的 U 形半封闭墙（每个由 3 段灰线围成，一侧留有 1-2 格宽的开口，开口朝向不同的基本方向）。每个封闭区域内部恰好有一个单色种子像素（颜色匹配图例的某个输入色），各封闭区域的种子颜色互不相同。主操作区中还散布 1-2 个橙(7)障碍物像素，位于某些封闭区域的开口辐射路径上。生成约束：每个种子色在图例中恰好出现一次；障碍物不在封闭区域内部也不在墙壁上。

**规则**：
1. 对每个半封闭区域，从其内部种子像素出发进行泛洪填充：先填满封闭区域内所有黑(0)像素，再沿开口方向向外辐射填充。
2. 辐射方向上的橙(7)障碍物阻断填充：障碍物所在位置不被填充，且障碍物沿辐射方向正后方的所有像素也不被填充（即障碍物投射"阴影"）。辐射在遇到网格边缘、另一个封闭区域的墙壁、或另一个已填充区域时停止。
3. 填充完成后，查找图例：将每个填充区域中所有像素的颜色从种子色替换为图例中对应的输出色。
4. 保留图例区、灰(5)墙壁、橙(7)障碍物及分隔线不变。

**关键洞察**：种子颜色是一个查找键而非最终颜色——仅看填充结果无法确定输出色，必须发现图例的映射关系；同时障碍物的阴影效应只在对比有无障碍的示例后才能归纳。

## 新题 3：轴分组镜像与对角堆叠冲突

**组合逻辑**：[堆叠/对角链排列](将矩形按对角链堆叠) + [镜像](创新：不是跨外部轴反射，而是根据矩形相对轴的分组决定是否自身水平镜像) ← [冲突优先级](创新：重叠区域的胜者不由绘制顺序决定，而由是否经过镜像变换决定)

**来源原语**：堆叠(stacking) ← 03560426；对角链排列(diagonal_chain_layout) ← 03560426；角点重叠(corner_overlap) ← 03560426；冲突优先级(conflict_priority) ← 03560426；镜像(mirror) ← 88207623；轴线段(axis_segment) ← 88207623；按左边缘排序(ordered_by_left_edge) ← 03560426

**依赖链**：轴线段将矩形分为左右两组 → 右组矩形进行水平自镜像（形状改变）→ 所有矩形按原始左边缘顺序沿对角链堆叠 → 重叠像素由镜像属性决定优先级。去掉轴则无法分组；去掉镜像则形状不对；去掉堆叠则无重叠；去掉冲突规则则重叠区不确定。

底部一排矩形被红色轴分为左右两组，右组做水平镜像后全体按左边缘顺序沿对角链堆叠，重叠处镜像组优先。

**输入结构**：约 10x18 的黑(0)背景网格。底部行上排列着 4-5 个互不重叠的单色实心矩形（每个矩形底边紧贴最底行，宽 2-4 格，高 2-4 格，各矩形颜色互不相同，均非黑(0)且非红(2)）。矩形之间有一条红(2)竖线段（高度至少与最高矩形相同，底端也紧贴最底行），将矩形分为左组和右组，每组至少有 1 个矩形。各矩形的左边缘列坐标互不相同。生成约束：矩形的宽高选择使得对角堆叠后不超出约 10x18 的输出画布；左组和右组中至少各有一个非对称矩形（宽 =/= 高），以使镜像效果可观察。

**规则**：
1. 识别红(2)竖线段的列位置，将其左侧的矩形归为"左组"，右侧归为"右组"。红线本身不参与后续堆叠。
2. 对右组的每个矩形，以其自身垂直中心线为轴进行水平镜像（即左右翻转该矩形内部像素图案）。左组矩形保持不变。（注：当矩形为纯色实心时镜像无可见变化，但若矩形含多色图案则效果可见。本题中矩形为实心单色，故此步对形状无影响，但影响冲突规则中的"镜像标记"属性。）
3. 清空画布为黑(0)。将所有矩形按其原始左边缘列坐标从小到大排序。将第一个矩形放置于画布左上角 (0,0)。对于每个后续矩形，其左上角放在前一个矩形左上角偏移 (前一高度-1, 前一宽度-1) 的位置（即角点重叠堆叠）。
4. 重叠像素冲突解决：若重叠的两个像素来自同一组（都是左组或都是右组），则后放置的覆盖先放置的；若来自不同组，则右组（已镜像）的像素始终优先覆盖左组的像素，无论放置顺序。
5. 输出堆叠后的画布（不含红线）。

**关键洞察**：冲突解决规则与绘制顺序不完全一致——跨组重叠时镜像组始终胜出，这需要对比存在跨组重叠与仅有同组重叠的不同示例才能归纳出该优先级规则。

## 新题 4：符号双重编码——颜色解码与位移方向

**组合逻辑**：[符号解码](从 3x3 掩码解码出颜色) + [平移](创新：位移方向不由固定颜色-方向映射表决定，而由同一符号掩码中灰像素的重心偏向编码) ← [颜色编码位移](保留"颜色分组移动"的思路，但方向来源从固定映射变为符号几何)

**来源原语**：符号解码(symbol_decoding) ← 17cae0c1；符号映射颜色(symbol_to_color_mapping) ← 17cae0c1；平移(translate) ← 342dd610；颜色编码位移(color_encoded_disp) ← 342dd610；颜色决定偏移(color_determines_offset) ← 342dd610

**依赖链**：符号掩码 → 解码出颜色（确定"移动谁"）+ 掩码几何重心偏向 → 确定位移方向（确定"往哪移"）→ 在下方操作区找到该颜色的像素并平移。符号同时承载颜色身份和运动指令，两个信息从同一输入元素中提取且缺一不可。

3x3 符号掩码同时编码目标颜色（通过二值图案查表）和位移方向（通过灰像素重心偏向），下方操作区中对应颜色的像素按该方向平移。

**输入结构**：约 10x15 的黑(0)背景网格。顶部 3 行为符号区，被分为若干相邻的 3x3 面板（2-4 个），每个面板内为黑(0)/灰(5)二值掩码图案。每个掩码的灰(5)像素数量在 3-5 个之间，形成非对称的 4-连通图形。底部区域（第 5 行起）散布若干单色像素点，颜色来自解码后的调色板（如蓝(1)、红(2)、绿(3)等），每种颜色 1-3 个像素点，点之间互不相邻。符号区与操作区之间有 1 行黑色空行分隔。生成约束：每个符号掩码解码出的颜色互不相同；掩码中灰像素的重心在 3x3 面板内明确偏向四个基本方向之一（上/下/左/右），即重心行坐标或列坐标偏离中心 (1,1) 至少 0.3 格；操作区中的像素平移后不超出网格边界。

**规则**：
1. 对每个 3x3 符号面板，将灰(5)像素视为 1、黑(0)视为 0，形成二值掩码。使用任务内置的符号-颜色码本将该掩码解码为一种颜色（码本需从多个示例中归纳）。
2. 计算该掩码中所有灰(5)像素相对于面板中心 (1,1) 的重心偏移 (dr, dc)。取绝对值较大的维度确定位移方向：若 |dr| > |dc|，dr < 0 为上、dr > 0 为下；若 |dc| >= |dr|，dc < 0 为左、dc > 0 为右。位移步长固定为 2 格。
3. 在底部操作区找到所有与该符号解码颜色相同的像素，将它们沿确定的方向平移 2 格。保留像素原色。
4. 如果平移后某像素落在已有非黑像素上，后移动的覆盖先到的。
5. 符号区和空行保持不变；操作区中被移走的原始位置恢复为黑(0)。

**关键洞察**：同一个 3x3 符号承担双重角色——其二值图案编码颜色身份，其灰像素空间分布编码运动方向——求解者必须同时提取这两层信息，单独理解任一层都无法完成变换。

## 新题 5：奇偶印章叠加与异或冲突消解

**组合逻辑**：[印章覆盖/同奇偶格接收副本](按奇偶规则将图案印入格子) + [异或](创新：异或不作用于两个分隔的二值掩码，而是用于解决两个图案在同一格子中的空间冲突)

**来源原语**：印章覆盖(stamp_overlay) ← 92e50de0；同奇偶格接收副本(same_parity_receive_copy) ← 92e50de0；种子图案(seed_motif) ← 92e50de0；单元格阵列(cell_array) ← 92e50de0；分隔线(separator_line) ← 92e50de0；异或(xor) ← 3428a4f5；逐像素异或输出(pixelwise_xor_output) ← 3428a4f5

**依赖链**：两个种子图案各自按奇偶规则确定目标格子 → 若两者奇偶类相同则所有目标格子重合，需用异或消解 → 若不同则各自独立印章。是否需要异或取决于源格子的奇偶关系，这构成一个隐式条件分支。

脚手架网格中两个不同图案分别按各自源格奇偶类印入目标格子；当两者奇偶类重合时，重叠位置用逐像素异或消解冲突。

**输入结构**：约 16x16 的网格。灰(5)像素构成完整的水平和垂直分隔线，将内部分为规则的开放格子阵列（约 4x4 至 5x5 个格子，每个格子约 3x3 像素）。恰好有两个格子各含一个小图案（2-4 个非黑非灰像素构成的 4-连通图形），两个图案颜色不同（如图案 A 为红(2)、图案 B 为蓝(1)），其余格子均为纯黑(0)。分隔线外侧可能有不完整的截断边缘格子。生成约束：两个图案的像素数相同或不同均可；两个源格子的奇偶类（行格索引%2, 列格索引%2）在不同示例中可能相同也可能不同（以便求解者归纳两种情况的处理差异）。

**规则**：
1. 识别灰(5)分隔线，将内部分为开放格子阵列。以最左上的完整格子为 (0,0)，按行列索引编号。
2. 找到包含图案 A 的格子 (rA, cA) 和包含图案 B 的格子 (rB, cB)。将图案记录为相对于格子左上角的像素偏移集合。
3. 将图案 A 印入所有满足 (行格索引%2 == rA%2 且 列格索引%2 == cA%2) 的格子中（使用图案 A 的颜色），在截断边缘格子处裁剪超出部分。
4. 将图案 B 印入所有满足 (行格索引%2 == rB%2 且 列格索引%2 == cB%2) 的格子中（使用图案 B 的颜色），同样裁剪。
5. 若某格子同时接收了图案 A 和图案 B（即两者奇偶类重合），对该格子内逐像素处理：仅有 A 标记的位置涂 A 色；仅有 B 标记的位置涂 B 色；A 和 B 均标记的位置涂黄(4)（第三种颜色，表示异或重叠）；均无标记的位置保持黑(0)。
6. 保留所有灰(5)分隔线不变。

**关键洞察**：两个源格子的奇偶类关系决定了是否发生重叠——若奇偶类不同，两组印章完全独立；若相同，每个目标格子都产生异或冲突。求解者需对比有重叠和无重叠的示例才能归纳出完整规则。

5. 将区域 Y 的图案掩码（像素偏移集合）印入区域 X，使用区域 Y 的底色作为印章颜色。
6. 将区域 X 的图案掩码印入区域 Y，使用区域 X 的底色作为印章颜色。
7. 所有其他区域、引导路径（包括干扰路径）、棋盘格保持不变。

**关键洞察**：多条引导路径可能存在，但只有与棋盘格相连的路径指示交换目标——其他路径是干扰项；求解者必须先识别棋盘格作为起点，再追踪正确路径，最后执行交换与重涂。

**关键洞察**：种子像素的位置承担三重角色——条纹相位起点、象限分割原点、初始条纹颜色——改变种子位置会同时改变条纹分布、象限边界和颜色分配。求解者需对比种子位置不同的示例才能发现象限-图例映射。

**关键洞察**：每个面板最终显示的填充形状是由对方面板的障碍物布局决定的——左面板的障碍塑造的形状出现在右面板中，反之亦然。求解者必须意识到形状来源于对面面板，而非本面板的障碍物。

**关键洞察**：引导行不仅选择平铺的行带位置，还锚定二部擦除的保留类——同一条引导行同时控制两个独立的决策维度，求解者须对比引导行在不同子区域的示例才能发现二部擦除规则。

**依赖链**：颜色决定位移方向 → 标记像素平移到新位置 → 新位置上的同色标记恰好构成矩形四角 → 沿背景通道绘制矩形边。平移前的标记不构成矩形（验证需对比输入），必须先平移才能连线。颜色同时编码"位移方向"和"分组键"，是双重耦合。

瓦片格中的彩色标记按颜色编码的方向位移后，同色标记恰好形成矩形四角，沿瓦片间的背景通道绘制矩形边框。

**输入结构**：约 15x15 的网格。灰(5)的单像素宽框线构成规则的瓦片格（约 3x3 至 4x4 个瓦片，每个瓦片约 3x3 像素的内部区域，瓦片之间和外围有 1 像素宽的灰(5)边框，边框之间为黑(0)背景通道）。部分瓦片内部包含单个彩色标记像素，标记颜色从以下四种中选取：橙(7)、红(2)、栗(9)、蓝(1)。每种出现的标记颜色恰好有 4 个像素（分布在不同瓦片中）。标记像素位于其所在瓦片内部的中心位置。生成约束：每种颜色的 4 个标记在经过颜色对应的位移后，恰好落在能构成轴对齐矩形四角的位置上；位移后的标记不落在灰(5)边框上（它们落入瓦片内部或背景通道中）。

**规则**：
1. 对每个标记像素，根据其颜色确定位移：橙(7)上移 1 格、红(2)左移 1 格、栗(9)下移 1 格、蓝(1)右移 1 格。将标记从原位置移除（原位置恢复为黑(0)），在新位置绘制该标记（保持原色）。若新位置是灰(5)边框像素，则标记覆盖边框。
2. 平移完成后，将同色的 4 个标记视为一个轴对齐矩形的四个角点。
3. 对每组四角点，沿它们定义的矩形的四条边绘制连线，使用该组的标记颜色。连线优先穿过黑(0)背景通道；若路径经过灰(5)边框像素，也正常覆盖绘制。连线不覆盖其他颜色的标记像素或其他颜色的连线。
4. 若两种颜色的矩形边在同一背景通道像素交叉，后绘制的覆盖先绘制的（绘制顺序按颜色编号从小到大：蓝(1) → 红(2) → 橙(7) → 栗(9)）。
5. 保留所有未被覆盖的灰(5)边框和瓦片内部未被标记占据的黑(0)像素。

**关键洞察**：输入中同色标记的原始位置并不构成矩形四角——必须先按颜色编码的方向位移后才能形成有效矩形；颜色同时作为位移指令和分组键的双重角色需要对比平移前后的几何关系才能发现。
