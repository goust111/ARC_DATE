## 新题 1：噪点修复后按面积排列为同心框

**组合逻辑**：[擦除/重涂色](邻接判定归并或删除) → [排序](按修复后边长降序) → [同心层填充](居中嵌套绘制)

**来源原语**：擦除+重涂色+邻接+merge_or_delete（7e0986d6）；排序+同心层填充+嵌套层次+descending_side_order（c658a4bd）；矩形+noise_pixel（7e0986d6）；concentric_layer（c658a4bd）

**依赖链**：噪点归并改变矩形边界框 → 修复后的边长决定同心嵌套顺序 → 嵌套顺序决定输出着色

将散布噪点的多个彩色矩形经邻接清洗后，按修复边长重建为居中同心正方形框。

**输入结构**：黑(0)背景网格，约 18x18。3~4 个互不相邻的实心单色矩形（每个至少 3x3），颜色各不相同，取自蓝(1)、绿(3)、黄(4)、品红(6)。橙(7)噪点以 1~3 像素的小簇散布于矩形表面及附近（每个噪点连通分量面积不超过 3）。生成约束：不同矩形的边界框互不相交（间距 >= 2），保证噪点归并后各矩形仍是矩形形状；每个矩形至少有 1 个噪点簇与之 4-邻接。

**规则**：
1. 识别所有橙(7)色 4-连通分量（面积 <= 3 的为噪点）。
2. 对每个噪点像素，统计其 4-邻居中属于矩形颜色的像素数。若 >= 2，将该噪点像素重涂为其中占多数的矩形颜色（若数量相同，取该噪点所在行上首先遇到的矩形颜色）；若 < 2，擦除为黑(0)。
3. 归并完成后，对每种矩形颜色计算其所有同色像素的边界框的较长边边长，记为该颜色的 side。
4. 创建正方形输出，边长等于所有颜色中最大的 side。
5. 按 side 从大到小排序。从最大开始，逐一在输出中央绘制对应颜色的正方形边框（1 像素厚），边长等于该颜色的 side。后绘制的覆盖先绘制的。最内层框的内部（若有）填充为最内层颜色。

**关键洞察**：噪点归并不只是清理——它改变了矩形的有效尺寸，直接影响同心嵌套的层序。仅凭清理前的边长无法得出正确排列。

## 新题 2：调色板多样性编码缩放倍率的分形印章

**组合逻辑**：[计数](前景色数) → [像素放大](以色数为倍率) + [印章覆盖](控制像素位置递归嵌入原图)

**来源原语**：计数+像素放大+前景色数定倍率+编码映射（b91ae062）；印章覆盖+控制像素+格位映射+递归印章（cce03e0d）

**依赖链**：前景色计数决定放大倍率 K → K 决定每个块的尺寸 → 控制像素对应的块被填入整个输入的 K 倍缩放副本；改变任一颜色同时改变 K 和递归副本的内容

自引用结构：小网格的前景色种类数编码了自身的放大倍率，红色像素标记的位置被递归地嵌入整图副本。

**输入结构**：小网格，约 3x3 至 4x4。黑(0)背景。前景由 K 种不同颜色组成（K 在 2~4 之间），其中一种必为红(2)，充当控制色。红(2)像素数量 1~3 个，分布在非背景图案中。其余前景颜色取自蓝(1)、绿(3)、黄(4)、灰(5)。生成约束：输入中至少存在 2 种非黑前景色（含红），且红像素不全聚在同一行或同一列。

**规则**：
1. 统计输入中不同的非黑(0)前景颜色数，记为 K。
2. 构建输出：每个输入像素对应一个 KxK 的输出块。
3. 对于红(2)像素：其对应的 KxK 块填入整个输入图案的精确副本（将输入缩放到 KxK）。副本中红像素保持红色，不再递归。
4. 对于非红前景像素和背景像素：其 KxK 块全部填充该像素本身的颜色。

**关键洞察**：缩放倍率不是显式给出的——它被隐式编码在输入调色板的多样性中。增减一种前景色不仅改变图案内容，还改变整个输出的几何尺寸。

## 新题 3：对侧配对滑动轨迹与偏移决定的垂直射线

**组合逻辑**：[滑动+连线](对侧配对相向移动留迹) → [射线延伸](会合点处按偏移不对称方向发射垂直射线)

**来源原语**：滑动+连线+孤立像素+汇合点+对侧配对+相向移动留迹汇合（29c11459）；射线延伸+方向帽+帽向决定射线+缺口不对称（4e469f39）

**依赖链**：对侧配对决定滑动方向和轨迹 → 轨迹确定会合点位置 → 配对中的位置偏移量决定会合点处垂直射线的发射方向 → 射线不覆盖已有轨迹颜色

配对边缘像素相向滑动留下彩色轨迹，会合点处根据配对的不对称偏移方向向垂直方向发射灰色射线。

**输入结构**：黑(0)背景网格，约 15x15。左右两侧边缘各有 3~4 个单色孤立像素（每个像素 1x1）。每对使用相同颜色，颜色取自蓝(1)、绿(3)、黄(4)、品红(6)。每对像素位于同一行（一左一右），但其中一个像素相对于精确对称位置向上或向下偏移了恰好 1 格。生成约束：不同对的行间距 >= 3，保证轨迹和射线不冲突；偏移方向（上或下）在不同对之间不必相同。

**规则**：
1. 按颜色将左右边缘的孤立像素配对。每对中两个像素位于相近但不完全相同的行（相差恰好 1）。
2. 将每对中的两个像素沿水平方向相向滑动。滑动路径为各自所在行的水平直线，留下该对颜色的轨迹。两条轨迹的水平投影重叠时，取两行的中间行作为会合行——在该会合列上，两条轨迹分别延伸到该列后停止，会合列上的会合行像素标记为灰(5)。
3. 在每个灰(5)会合点处，检查该对中哪个像素的行号更偏向上方（行号更小）。从会合点沿垂直方向向该偏移侧（即朝较小行号的方向）发射灰(5)射线，延伸到网格边缘。
4. 灰射线经过已有彩色轨迹像素时不覆盖——保留原轨迹颜色。

**关键洞察**：每对像素看似在"同一行"，实际有 1 格偏移——这个微小不对称不是噪声，而是编码了会合点处垂直射线的发射方向。

## 新题 4：骨架对齐印章后锚点播种距离环

**组合逻辑**：[印章覆盖+旋转/镜像](骨架对齐传递标注) ⟂ [填充+重涂色](锚点作为距离场中心)——两条逻辑通过锚点像素的双重角色汇合

**来源原语**：印章+旋转+镜像+精灵体+锚点像素+骨架对齐+完整标注传递副本（36d67576）；填充+重涂色+同心环+标记像素+距离映射+曼哈顿距离+循环色板（aaef0977）

**依赖链**：锚点像素同时承担两个角色——(a) 固定骨架朝向以确定印章的二面体变换；(b) 充当曼哈顿距离环的圆心。印章传递决定了哪些像素受距离环保护（不被覆盖），而锚点位置决定了距离环的几何形态。两条逻辑在锚点处交汇，缺一不可。

将标注从完整精灵体印章到所有骨架副本后，以每个锚点为圆心用循环色板填充背景的曼哈顿距离环。

**输入结构**：黑(0)背景网格，约 20x20。4~5 个 8-连通前景精灵体，彼此间距 >= 3。所有精灵体共享相同的灰(5)骨架结构（3~6 像素的不规则连通形状），每个精灵体内恰好有 1 个蓝(1)锚点像素。其中 1 个精灵体为"完整版"——除骨架和锚点外还包含红(2)和黄(4)的标注像素各 1~2 个；其余精灵体为"简版"——仅有骨架和锚点。生成约束：每个简版精灵体的骨架可通过唯一的旋转/翻转从完整版骨架映射得到（含锚点位置对应）；不同精灵体的边界框互不重叠。

**规则**：
1. 以完整版精灵体为源模板。对每个简版精灵体，找到唯一的旋转/翻转变换，使源骨架和锚点映射到目标骨架和锚点。
2. 通过该变换，将源模板的红(2)和黄(4)标注像素印章到目标精灵体上。骨架像素和锚点像素不变。
3. 印章完成后，对每个背景像素计算到最近锚点(蓝(1))的曼哈顿距离 d。
4. 用循环色板 [绿(3), 黄(4), 红(2)]，按 (d - 1) mod 3 索引为背景像素着色（d=1 → 绿(3), d=2 → 黄(4), d=3 → 红(2), d=4 → 绿(3)...）。
5. 所有非背景像素（骨架、锚点、印章标注）不被距离环覆盖。当距离环颜色与印章标注颜色冲突（相邻像素同色导致视觉混淆）时，不做特殊处理——非背景像素始终保持。

**关键洞察**：锚点像素承担双重角色——既是骨架对齐的定位基准，又是距离场的播种中心。移动一个锚点同时改变印章对齐方式和距离环几何形态，两个子系统不可分离。

## 新题 5：标记侧镜像扩展后内部涂色并组装风车

**组合逻辑**：[镜像](标记像素指示翻转轴) → [重涂色](合并形状的内外分离) → [旋转+拼接](四旋转风车拼贴)

**来源原语**：镜像+前景对象+标记像素+邻接+标记侧翻转且变色（2bcee788）；重涂色+前景矩形+矩形内部+内外分离+保留边框涂内部（50cb2852）；旋转+拼接+正方形画布+阵列排布+四旋转组成风车（7fe24cdd）

**依赖链**：标记位置 → 决定镜像轴 → 改变合并形状的轮廓 → 轮廓决定哪些像素是"内部" → 内部涂色后的画面被旋转成四象限 → 标记位置的微小变化在四个象限中被放大

红色标记指示镜像方向，将矩形沿该方向镜像翻转后为合并形状的内部涂色，最终组装成 2x2 风车拼贴。

**输入结构**：正方形网格，边长 N（7 <= N <= 10）。黑(0)背景。一个蓝(1)实心矩形（宽和高各至少 3，且宽 != 高），位于网格中不贴边的位置。一个红(2)单像素标记，与矩形的某一条边 4-邻接（只贴一条边）。生成约束：矩形加上其镜像后的合并形状完全在网格内；合并形状在两个维度上都至少 3 像素（以保证存在内部像素）。

**规则**：
1. 确定红(2)标记贴在矩形的哪条边。以该边为镜像轴，将整个矩形翻转一次。翻转副本与原矩形共享该边。红像素被翻转副本覆盖。
2. 合并原矩形和翻转副本为一个组合形状。计算组合形状的 1 像素内缩边界：将不在最外层边框上的所有内部像素重涂为青(8)，边框像素保持蓝(1)。
3. 将处理后的正方形网格作为基础瓦片，构建 2x2 风车拼贴输出：左上 = 基础瓦片原样，右上 = 顺时针 90° 旋转，左下 = 逆时针 90° 旋转，右下 = 180° 旋转。

**关键洞察**：红色标记在输出中完全不出现——它仅指示镜像方向，但其位置决定了合并形状的轮廓，进而决定了青色内部区域的形态，该形态在四个风车象限中以四种旋转呈现。

## 新题 6：逐行异常值提取后条纹对齐到中位基准

**组合逻辑**：[提取](逐行异常值选择) → [裁剪](提取条纹几何特征) → [对齐+裁剪](以中位条纹为参考归一化)

**来源原语**：提取+裁剪+网格单元+精灵体+逐行比较+异常值选择（38007db0）；对齐+裁剪+线段+平行共向+中位线为参考（e376de54）

**依赖链**：异常值检测决定哪些单元被选中 → 选中单元的内部条纹属性（长度、垂直位移）各不相同 → 中位条纹被选为参考 → 所有条纹对齐到中位参考的位置和长度。跳过异常值检测则无从获得条纹；跳过对齐则条纹参差不齐。

从网格每行中找出异常单元，提取其中的水平条纹，然后以中位条纹为基准对齐所有条纹的位置和长度。

**输入结构**：网格被品红(6)色分隔线划分为 MxN 的等大矩形单元（M 行 N 列，M 在 3~5 之间，N 在 3~5 之间），分隔线宽 1 像素。单元内部背景为黑(0)。每行 N 个单元中有 N-1 个共享完全相同的内部精灵图案，1 个是异常值——其内部图案与同行其他单元不同。每个异常值单元包含一条水平彩色条纹（1 像素高，长度 2~6 像素的连续同色水平段），颜色取自蓝(1)、绿(3)、黄(4)、红(2)，且不同行的异常值条纹颜色互不相同。不同行异常值的条纹长度和在单元内的垂直位置（距单元顶部的行偏移）各不相同。生成约束：M >= 3 以保证中位数唯一（M 为奇数）。

**规则**：
1. 对每行单元，逐对比较内部图案，找出出现恰好 1 次的异常值单元。
2. 从每个异常值单元中提取水平条纹：记录其颜色、像素长度 L、以及条纹在单元内的垂直偏移 V（从单元内部顶部第 0 行起计）。
3. 将所有提取的条纹按垂直偏移 V 排序，取中位条纹（第 ceil(M/2) 个）作为参考，记其垂直偏移为 V_ref、长度为 L_ref。
4. 对每条条纹，将其垂直偏移调整为 V_ref（上下平移），长度调整为 L_ref（从左端起保留 L_ref 像素；若原长度 < L_ref 则向右用同色延伸）。
5. 构建输出：单列网格（1 列 M 行），每个单元大小与原输入单元相同，用品红(6)分隔线分隔。每行放入对齐后的条纹，保持原条纹颜色。

**关键洞察**：参考基准不是最长或最短的条纹，而是按垂直偏移排序后的中位值——必须提取所有异常值后才能确定参考，然后才能执行对齐。

## 新题 7：断裂线网修复后按连通面积分级着色

**组合逻辑**：[修复+间隙填充](标记归属最近线，端点对向填补) → [计数](修复后连通分量面积) → [重涂色](面积分级决定颜色)

**来源原语**：修复+间隙填充+线段网络+标记像素+端点朝向+标记归属最近线（faa9f03d）；计数+连通分量+面积分级+面积决定颜色（e8593010）

**依赖链**：标记归属扩展线段 → 扩展改变端点朝向判定 → 间隙填充可能合并原本分离的线段 → 合并改变连通分量数量和面积 → 面积排名改变颜色分配。一个标记的归属可以导致两段线合并为一，彻底重排面积榜。

修复断裂的灰色线网后，按每个连通片段的面积大小分三级着色。

**输入结构**：黑(0)背景网格，约 14x14。灰(5)像素组成若干 1 像素宽的水平/垂直线段片段（每段长度 2~8 像素），片段之间有 1~3 像素的间隙。红(2)单像素标记散布于线段端点附近（与最近灰线端点在同一行或同一列上，之间无其他灰像素遮挡，距离 1~2 像素）。生成约束：每个红标记在行/列视线内恰好有一个最近灰端点；修复（归属+填隙）完成后，恰好形成 3~6 个灰色 4-连通分量，且面积互不相同。

**规则**：
1. 对每个红(2)标记，沿行/列视线找到最近的灰(5)线端点，将该标记重涂为灰(5)（视为该线段的延伸）。
2. 扫描所有灰(5)端点对：若同一行或同一列上有两个灰端点彼此面朝（中间全为黑(0)），且间距 <= 3，则用灰(5)填满两端点之间的间隙。
3. 计算修复后每个灰(5)4-连通分量的像素面积。
4. 按面积从小到大排名。将每个分量重涂色：排名第 1（最小面积）→ 绿(3)，排名第 2 → 红(2)，排名第 3 → 蓝(1)，排名第 4 → 绿(3)，排名第 5 → 红(2)，排名第 6 → 蓝(1)，依此循环。
5. 若两个分量面积相同（生成约束下不会出现），以边界框左上角像素更靠左上的分量排名靠前。

**关键洞察**：一个红标记的归属可以桥接两段原本独立的线段，使分量数减半，彻底重排面积分级和颜色分配——修复逻辑和着色逻辑通过拓扑变化紧密耦合。

## 新题 8：重叠碎片帧的噪点归属决定遮挡优先级与内层填充

**组合逻辑**：[擦除/重涂色](噪点邻接判定) ⟂ [排序](修复后边长定层序) → [同心层填充+洪泛填充](按优先级叠绘并填充最内层)——噪点归属同时影响帧边长和遮挡关系，形成隐式双重约束

**来源原语**：擦除+重涂色+矩形+噪点+邻接+merge_or_delete（7e0986d6）；排序+同心层填充+碎片帧+嵌套层次+descending_side_order（c658a4bd）；洪泛填充（4e469f39）；内外分离（50cb2852）

**依赖链**：噪点归属改变帧的有效边长 → 边长改变遮挡优先级（小帧在上）→ 优先级改变重叠处的可见颜色 → 最内层帧的身份取决于修复后谁最小 → 该帧内部被洪泛填充。噪点既影响几何尺寸又影响视觉层次，两条约束必须同时满足。

多个彩色正方形边框相互重叠且受噪点干扰，清除噪点后按修复边长确定遮挡顺序居中重绘，最内层框内部填充。

**输入结构**：黑(0)背景网格，约 16x16。3~4 个不同颜色的正方形边框（1 像素厚），颜色取自蓝(1)、绿(3)、黄(4)、品红(6)。边框大小各不相同（边长 4~12），中心点接近但不完全相同，因此部分边框像素相互重叠（重叠处仅显示一种颜色，具体哪种是输入的给定事实）。橙(7)噪点像素（单个或 2 像素簇）散布在边框上和边框附近。生成约束：每种颜色的边框像素（含被遮挡的隐藏像素）加上归属该颜色的噪点像素后，边界框为正方形；不同颜色修复后的边长互不相同。

**规则**：
1. 识别橙(7)噪点（4-连通分量面积 <= 2）。对每个噪点像素统计其 4-邻居中各边框颜色的数量。若总边框色邻居 >= 2，将噪点重涂为最多邻居对应的边框颜色（平局时取行号更小的邻居的颜色）；否则擦除为黑(0)。
2. 修复后，对每种边框颜色，计算其所有同色像素边界框的边长（应为正方形，取较大维度）。
3. 确定遮挡优先级：边长越小，优先级越高（画在最上层）。
4. 构建输出：以最大边长为输出网格边长。以输出中心为公共中心，从最大帧（最低优先级）到最小帧（最高优先级）依次绘制正方形边框，每帧颜色不变，后绘制的覆盖先绘制的。
5. 最内层（最小）帧的内部（边框以内的区域）用该帧颜色洪泛填充。

**关键洞察**：噪点归属同时改变两件事——帧的有效边长和哪个帧成为最内层被填充对象。一个噪点归入错误的帧会同时扭曲层序和填充目标，两条信息必须一致。
