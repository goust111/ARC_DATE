## 新题 1：安全路径选择性镜像

**组合逻辑**：[寻路/pathfinding](从轨道网络中提取唯一安全路径) + [镜像/mirror](对路径上的精灵体执行镜像，轴由指示像素决定) + [擦除/erase](移除不在安全路径上的精灵体) — 寻路结果决定哪些精灵体参与镜像操作，形成选择-变换耦合

**来源原语**：寻路/pathfinding(cc9053aa), 障碍物/obstacle(cc9053aa), 邻域禁区/neighbor_exclusion(cc9053aa), 镜像/mirror(b775ac94), 指示像素/indicator_pixel(b775ac94), 精灵体/sprite(3e980e27), 擦除/erase(9f8de559)

**依赖链**：寻路产出的安全路径像素集合充当筛选条件 -- 仅当精灵体的包围盒与安全路径上的某像素有 4-连通邻接时，该精灵体才被"激活"并执行镜像；未被激活的精灵体连同其指示像素一起擦除为背景色。镜像轴和镜像副本颜色由指示像素位置和颜色决定。因此删除寻路环节则无法确定哪些精灵体参与变换；删除镜像环节则激活的精灵体无变换可做。

将轨道网络上散布的精灵体按安全路径可达性筛选，对选中者执行指示像素驱动的镜像，擦除落选者。

**输入结构**：
- 约 18x18 的网格，黑(0)背景。
- 青(8)像素构成一个 4-连通的轨道网络（类似管道），网络中恰好有两个栗(9)端点像素。
- 1~3 个橙(7)障碍像素嵌入轨道附近；每个橙像素及其 8-邻域内的青像素视为禁区，被移除后轨道网络断裂为多条路径，其中恰好一条 4-连通简单路径连通两个栗端点。
- 3~5 个单色精灵体（每个 3~6 像素、4-连通、形状各异）分布在轨道两侧，颜色可为蓝(1)、红(2)、绿(3)中的任意一种；每个精灵体恰好有一个 1 像素的指示像素（颜色为黄(4)或灰(5)）与其 4-连通邻接。
- 生成约束：每个精灵体的包围盒与轨道至少有一条边相邻（即包围盒外扩 1 像素后与轨道像素重叠），但精灵体像素本身不占据轨道像素；至少一个精灵体不与安全路径邻接（保证筛选有意义）。

**规则**：
1. 按 cc9053aa 的方式确定唯一安全路径：将每个橙(7)像素及其 8-邻域内的青(8)像素标记为禁区，在剩余青/栗像素的 4-连通图中找到连接两个栗端点的唯一简单路径。
2. 对每个精灵体，检查其包围盒外扩 1 像素后是否与安全路径上的任一像素 4-连通邻接。若是，该精灵体被"激活"。
3. 对每个激活的精灵体：找到与其 4-连通邻接的唯一指示像素；以指示像素相对于精灵体包围盒中心的方位确定镜像轴（指示在左/右侧 -> 以精灵体包围盒的垂直中线为轴水平镜像；指示在上/下侧 -> 以水平中线为轴垂直镜像）；生成精灵体的镜像副本，副本颜色改为指示像素的颜色；副本放置在精灵体包围盒关于镜像轴的对侧、与原包围盒间隔 1 像素。超出网格的部分裁剪。
4. 未激活的精灵体及其指示像素全部擦除为黑(0)。
5. 轨道、端点、障碍像素保持不变。镜像副本仅绘制在黑(0)背景上，不覆盖已有非背景像素。

**关键洞察**：障碍物分割轨道网络后产生的唯一安全路径，充当了精灵体是否执行镜像变换的空间选择器——求解者必须先完成寻路，才能判断哪些精灵体该保留并镜像、哪些该擦除。

## 新题 2：溅射围栏与种子灌注

**组合逻辑**：[平移/shift + 对角溅射/diagonal_splash](移动像素下移并溅射) → [填充/flood_fill](溅射线围成的腔体被种子灌注) — 溅射几何体成为填充的围墙，两者间有因果结构依赖

**来源原语**：平移/shift(73c3b0d8), 邻接触发对角溅射/adjacency_triggers_diagonal_splash(73c3b0d8), 触发条/trigger_bar(73c3b0d8), 移动像素/moving_pixel(73c3b0d8), 填充/flood_fill(8b7bacbf), 种子像素/seed_pixel(8b7bacbf), 封闭腔体/enclosed_cavity(8b7bacbf)

**依赖链**：移动像素下移一行后，落在触发条正上方的像素向上发射两条对角线。这些对角线与触发条、网格边界共同围成封闭腔体。网格边界上的种子像素通过 8-连通到达这些腔体边界后，对腔体执行 flood_fill。删除平移/溅射则无腔体可填；删除填充则溅射线只是装饰。

移动像素下移后触发对角溅射形成围栏线，边界种子像素通过连通性标记并灌注被围栏围成的封闭区域。

**输入结构**：
- 约 15x20 的网格，黑(0)背景。
- 一行完整的灰(5)水平线横贯网格底部倒数第 3 行，作为触发条。
- 3~5 个蓝(1)移动像素散布在触发条上方（距触发条 1~6 行不等），每个占 1 像素。
- 1~3 个种子像素位于网格的上边界（第 0 行），颜色各不相同，从红(2)、绿(3)、黄(4)中选取，每种颜色最多出现一次。
- 生成约束：移动像素的列位置保证下移后恰好有部分像素落在触发条正上方（即距触发条恰好 1 行）、部分不落在正上方；从触发后溅射线实际围成的腔体来看，每个腔体的边界恰好 8-连通可达唯一一个种子像素（不存在一个腔体可达两个种子的情况）。

**规则**：
1. 将每个蓝(1)移动像素从原位置擦除，重绘在同列、下移一行的位置。
2. 下移后，若某蓝像素落在触发条正上方一行（即该像素的下方紧邻灰(5)触发条像素），则从该蓝像素位置向左上和右上两个方向各发射一条蓝(1)对角射线，直到射线到达网格边界为止。不与触发条正上方邻接的蓝像素仅下移，不溅射。
3. 所有溅射完成后，将溅射线像素、触发条像素、网格边界共同视为墙壁。在墙壁围成的区域中寻找不包含任何非背景像素的封闭黑(0)腔体（4-连通）。
4. 对每个封闭腔体，检查其 4-连通边界像素中是否有像素与某个种子像素通过非背景像素链（8-连通）可达（即种子像素所在的 8-连通前景连通分量的像素与腔体边界 4-邻接）。若可达，将该腔体内所有黑(0)像素填充为该种子像素的颜色。
5. 若一个腔体的边界不与任何种子像素的连通分量 4-邻接，则该腔体保持黑(0)不填充。
6. 触发条下方的区域（若存在）不算封闭腔体（它与网格下边界开放连通）。

**关键洞察**：对角溅射线不是最终装饰，而是构成封闭腔体的墙壁——求解者必须先模拟移动与溅射的几何结果，才能确定哪些区域被围合，再通过种子的连通可达性决定每个腔体的填充颜色。

## 新题 3：逐色对角检测驱动选择性翻转

**组合逻辑**：[对角线对齐检测/diagonal_alignment](逐色检查是否存在对角对齐的像素对) → [连线/draw_line](对齐则画对角线段) → [镜像/flip_within_bbox](画线后的颜色掩码在包围盒内垂直翻转) — 对角检测结果同时产出新几何（线段）并触发翻转，形成条件分支结构

**来源原语**：对角线对齐/diagonal_alignment(55783887), 连线/draw_line(55783887), 逐色独立变换/per_color_transform(e74e1818), 包围盒内翻转/flip_within_bbox(e74e1818), 单色掩码/mono_mask(e74e1818)

**依赖链**：对每种非背景色独立处理。若该颜色的像素中存在恰好一对主对角线对齐（行差 = 列差、方向为左上-右下）的像素，则在它们之间画一条该颜色的对角线段，画完后对该颜色的完整掩码（含新画的线段）在其包围盒内执行垂直翻转。若不存在这样的对齐对，该颜色的像素保持原样。删除对角检测则无法判断哪些颜色要翻转；删除画线则翻转后的形状错误（缺少线段像素）；删除翻转则画线只是连接。

对每种前景色独立检测对角对齐像素对，对齐则画连接线段并在包围盒内垂直翻转该颜色的全部像素，未对齐的颜色保持不变。

**输入结构**：
- 约 14x14 的网格，黑(0)背景。
- 3~5 种非背景前景色，每种颜色由 3~8 个像素构成一个单色掩码（4-连通或 8-连通均可、形状不规则）。
- 各颜色掩码的包围盒互不重叠（保证逐色操作不产生像素冲突）。
- 其中恰好有部分颜色（至少 1 种、至多比总颜色数少 1）的像素集合中存在恰好一对像素满足主对角线对齐（即 r2-r1 = c2-c1 > 0），其余颜色不存在这样的对。
- 生成约束：对角对齐的像素对之间的主对角线段上的所有中间像素位置在输入中均为黑(0)（以便画线）。

**规则**：
1. 对每种非背景颜色 C 独立执行以下判断与操作：
   a. 在颜色 C 的所有像素中，检查是否存在恰好一对 (r1,c1)、(r2,c2) 满足 r2-r1 = c2-c1 > 0（主对角线对齐）。若存在多于一对，选择行差最大的一对（保证唯一）。
   b. 若存在这样的对：用颜色 C 填充从 (r1,c1) 到 (r2,c2) 的主对角线段上所有中间像素。然后计算颜色 C 当前完整掩码（含原有像素和新画的线段像素）的包围盒 [r_top, r_bot] x [c_left, c_right]。将掩码内每个像素 (r, c) 映射到 (r_top + r_bot - r, c)，即在包围盒内垂直翻转。翻转后的像素若落在黑(0)位置则绘制颜色 C，原位置变为黑(0)。
   c. 若不存在对角对齐的对：颜色 C 的所有像素保持原位不变。
2. 所有颜色独立处理，结果叠加到同一网格上。由于包围盒互不重叠，不会产生冲突。

**关键洞察**：对角对齐检测既是画线的触发条件又是翻转的触发条件——同一个几何事实同时驱动两个操作；而画出的线段改变了掩码形状，导致翻转结果与仅翻转原始像素完全不同，两个操作通过共享几何紧密耦合。

## 新题 4：平铺冲突拉伸

**组合逻辑**：[平铺/tile](2x2 画布加倍) + [拉伸/stretch](每个副本向其标记像素拉伸) + 冲突解决（重叠区域由距标记更近的副本决定颜色） — 平铺产出多个独立拉伸目标，重叠区域产生源题中不存在的冲突仲裁

**来源原语**：平铺/tile(d13f3404), 画布加倍/canvas_doubling(d13f3404), 拉伸/stretch(b548a754), 空心矩形/hollow_rectangle(b548a754), 标记点/marker_pixel(b548a754), 标记决定拉伸终点/marker_determines_stretch_endpoint(b548a754)

**依赖链**：输入平铺为 2x2 后，每个象限内有一份空心矩形和标记像素的副本。每份副本根据自身标记像素独立拉伸。但相邻象限的拉伸可能使矩形侵入对方区域，产生重叠。重叠区域的颜色由距自身标记像素曼哈顿距离更近的那个矩形决定（距离相同时保留先绘制的，即按左上→右上→左下→右下顺序）。删除平铺则只有一份无冲突；删除拉伸则无变形；删除冲突规则则重叠区域不确定。

将含空心矩形与标记像素的小网格平铺为四份，每份独立拉伸后在重叠区域按距标记距离仲裁归属。

**输入结构**：
- 约 8x8 的网格，黄(4)背景。
- 一个蓝(1)边框、红(2)内部填充的空心矩形（边框宽 1 像素，内部区域至少 2x2），位于网格中偏离中心的位置。
- 一个绿(3)标记像素，位于矩形外部，与矩形在同一行或同一列对齐（即标记像素的行在矩形行范围内、或列在矩形列范围内），且距矩形最近边 2~4 像素。
- 生成约束：矩形和标记像素的位置保证平铺为 16x16 后，至少有两个象限的拉伸结果在中心区域产生 2x2 以上的重叠。

**规则**：
1. 将 8x8 输入平铺为 16x16 的 2x2 画布：左上象限 = 原始输入，右上象限 = 原始输入水平偏移 8 列，左下 = 垂直偏移 8 行，右下 = 对角偏移 (8,8)。背景色填充整个 16x16 后逐象限覆盖。
2. 对四个象限中的每份空心矩形和标记像素，独立执行拉伸：按 b548a754 的规则，若标记在矩形上方/下方且列在矩形列范围内，则矩形垂直拉伸至标记所在行；若标记在左方/右方且行在矩形行范围内，则矩形水平拉伸至标记所在列。拉伸后重绘蓝(1)边框和红(2)内部。
3. 按绘制顺序（左上→右上→左下→右下）逐象限将拉伸后的矩形绘制到 16x16 画布上。对于每个像素位置，若多个象限的拉伸矩形同时覆盖该位置，取该位置到各竞争矩形对应标记像素的曼哈顿距离，保留距离最小的矩形的颜色。若距离相同，保留绘制顺序更早的象限的颜色。
4. 标记像素本身被矩形边框消耗（若拉伸到达标记位置，标记变为蓝(1)边框色）。未被任何矩形覆盖的位置保持黄(4)背景。

**关键洞察**：平铺本身不改变逻辑，但它将一个无冲突的拉伸问题变成了四路冲突仲裁问题——求解者必须理解曼哈顿距离仲裁规则，而这条规则只有在多个示例的重叠区域对比后才能归纳出来。

## 新题 5：凸耳编码嵌套方位

**组合逻辑**：[排序/sort](按面积从大到小排列轮廓对象) + [嵌套/nest](大到小逐层嵌套) + [凸耳决定嵌套角/tab_determines_corner](凸耳位置编码嵌套的对齐角落) — 凸耳同时编码排序校验信息和嵌套方位，排序与嵌套通过凸耳紧耦合

**来源原语**：排序/sort(291dc1e1), 嵌套/nest(6cbe9eb8), 面积递减嵌套/area_descend_nest(6cbe9eb8), 轮廓/outline(dc2e9a9d), 凸耳/tab(dc2e9a9d), 凸耳决定镜像轴/tab_determines_axis(dc2e9a9d, 创新改造为凸耳决定嵌套角)

**依赖链**：每个轮廓对象有一个凸耳像素突出于包围盒的某条边。按包围盒面积从大到小排序后逐层嵌套，但嵌套时每个小轮廓放置在上一层轮廓内部的哪个角落，由该小轮廓自身凸耳的方位决定（凸耳在左 -> 放右侧、凸耳在上 -> 放下侧，即对侧放置逻辑）。删除排序则嵌套顺序不确定；删除凸耳解读则嵌套位置不确定。

多个带凸耳的轮廓按面积排序后逐层嵌套，每层的嵌套角落由该层轮廓凸耳的对侧方位决定。

**输入结构**：
- 约 20x20 的网格，黑(0)背景。
- 3~5 个不同颜色的 4-连通矩形轮廓（仅边框、内部为黑(0)），颜色从蓝(1)、红(2)、绿(3)、黄(4)、灰(5)中选取，每个轮廓颜色不同。
- 每个轮廓的边框宽度为 1 像素，包围盒尺寸各不相同（保证面积排序无并列）。最大轮廓的包围盒至少 10x10，最小至少 4x4。
- 每个轮廓恰好在其包围盒的一条边（上/下/左/右）的中点位置向外突出 1 个同色像素作为凸耳。不同轮廓的凸耳方向可以不同。
- 轮廓在输入中随意散布，互不重叠。

**规则**：
1. 识别所有矩形轮廓对象及其凸耳。每个轮廓的凸耳是唯一一个位于包围盒外部、且与包围盒边缘 4-连通邻接的同色像素。记录凸耳相对于轮廓包围盒的方位（上/下/左/右）。
2. 按各轮廓包围盒面积（宽x高）从大到小排序。
3. 在一个新的黑(0)画布上，首先绘制最大的轮廓（不含凸耳），放置在画布左上角对齐。
4. 对排序中的后续每个轮廓 F（从第二大开始），确定其嵌套位置：
   a. 取 F 的凸耳方位，计算对侧方位（左->右，右->左，上->下，下->上）。
   b. 在上一层已放置的轮廓的内部可用区域中，将 F（不含凸耳）放置到对侧角落。具体地：对侧为"右下"则 F 的包围盒右下角与可用区域右下角对齐；"左下"则左下对齐；"右上"则右上对齐；"左上"则左上对齐。凸耳方位为单一方向时，对侧角落取该方向的对侧 + 默认偏置（左/右凸耳时垂直方向取下，上/下凸耳时水平方向取右）。
   c. "上一层可用区域"定义为：上一层轮廓边框内部去除边框像素后的矩形区域。
5. 输出画布大小等于最大轮廓的包围盒尺寸。所有轮廓仅绘制边框（不含凸耳），后绘制的覆盖先绘制的。

**关键洞察**：凸耳在源题中决定镜像轴，但在本题中被重新编码为嵌套方位信号——求解者必须发现凸耳方位与嵌套角落之间的"对侧"映射关系，且这种映射只有对比多个示例中不同凸耳方位对应不同嵌套位置后才能归纳。

## 新题 6：对称修复后裁剪

**组合逻辑**：[对称补全/symmetry_completion](修复掩码像素) + [裁剪/crop](按竖直线段和角标记裁剪) — 裁剪边界标记本身可能被掩码损坏，必须先对称修复才能正确确定裁剪范围，形成环形约束

**来源原语**：对称补全/symmetry_completion(3631a71a), 掩码像素/masked_pixel(3631a71a), 对称轨道/symmetry_orbit(3631a71a), 裁剪/crop(3f7978a0), 竖直线段/vertical_segment(3f7978a0), 角标记像素/corner_marker(3f7978a0), 线段定裁剪列范围/lines_set_crop_columns(3f7978a0)

**依赖链**：网格具有关于垂直中轴的左右对称性，但部分像素被掩码色覆盖（损坏）。损坏的像素中可能包含裁剪所需的灰(5)竖直线段像素或青(8)角标记像素。必须先通过对称轨道中的可见伙伴恢复被损坏的像素（包括线段和角标记），然后才能正确识别两条竖直灰线段和四个角标记来确定裁剪范围。删除对称补全则裁剪边界不完整，裁剪结果错误；删除裁剪则修复后的网格无进一步变换。

在一个被局部损坏的左右对称网格中，先通过对称性修复损坏（含裁剪标记的损坏），再根据修复后的标记执行裁剪。

**输入结构**：
- 约 15x15 的网格，黑(0)背景，具有关于垂直中轴（列 = 7）的左右镜像对称性（对称性被掩码打破前）。
- 两条灰(5)竖直线段分布在中轴两侧对称位置，各自跨越 4~8 行，作为裁剪的左右边界。
- 四个青(8)角标记像素分别位于两条灰线段端点外扩一行的位置（按 3f7978a0 的结构）。
- 线段和角标记之间及周围有其他前景像素（蓝(1)、红(2)、绿(3)），也服从左右对称。
- 品红(6)像素为掩码色，覆盖了 3~6 个原始像素的位置（包括至少 1 个灰线段像素或角标记像素，以及若干其他前景像素）。这些位置的原始颜色被品红替换。
- 生成约束：每个被掩码覆盖的像素，其关于垂直中轴的对称伙伴未被掩码覆盖，保证对称补全可唯一恢复所有被损坏的像素。

**规则**：
1. 识别掩码色：品红(6)是唯一一种移除后能使所有对称轨道内部颜色一致的颜色。
2. 对称轴为网格的垂直中轴（列 = floor(width/2)）。
3. 对每个品红(6)像素 (r, c)，找到其关于垂直中轴的对称位置 (r, width-1-c)。将品红像素替换为对称位置的颜色。
4. 修复完成后，识别两条灰(5)竖直线段（同列连续灰像素，长度 >= 4）。按列位置排序，左侧线段定义裁剪左列，右侧线段定义裁剪右列。
5. 识别四个青(8)角标记像素，它们分别位于两条灰线段顶端上方一行和底端下方一行、同列位置。裁剪行范围 = 角标记的最小行到最大行。
6. 输出 = 从修复后的网格中裁剪出 [min_row, max_row] x [left_col, right_col] 的子网格。

**关键洞察**：裁剪标记本身参与了对称结构并可能被损坏——求解者不能跳过对称修复直接裁剪，因为损坏的灰线段会导致裁剪边界误判；必须先理解对称性质修复全部损坏像素，才能正确提取裁剪参数。

## 新题 7：模板匹配触发方向性平铺

**组合逻辑**：[归一化形状比对/normalized_shape_matching](识别与模板形状匹配的对象) + [平铺/tiling + 指示决定方向/indicator_dir](匹配对象沿指示方向重复平铺) + [重涂色/recolor](平铺副本颜色改为指示色) — 模板匹配是平铺的前提条件，指示像素同时编码方向和颜色

**来源原语**：归一化形状比对/normalized_shape_matching(4ff4c9da), 匹配模板则重涂/recolor_on_match(4ff4c9da), 模板对象/template_object(4ff4c9da), 平铺/tiling(e8dc4411), 指示像素/indicator_pixel(e8dc4411), 指示决定方向色/indicator_dir_color(e8dc4411)

**依赖链**：网格上有一个模板对象和多个候选对象。通过归一化形状比对，仅形状匹配模板的候选对象才被选中。每个选中对象旁有一个指示像素，指示像素的方位（相对于对象中心）决定平铺方向，指示像素的颜色决定平铺副本的颜色。未匹配的对象保持原样。删除模板匹配则无法筛选对象；删除平铺/方向编码则选中对象无变换可做。

以模板形状筛选候选对象，仅匹配者沿其指示像素方向重复平铺至网格边界，副本着指示色。

**输入结构**：
- 约 20x20 的网格，黑(0)背景。
- 一个青(8)模板对象（3~6 像素、4-连通、不规则形状），位于网格角落区域。
- 4~6 个灰(5)候选对象，每个 3~6 像素、4-连通。其中恰好 2~3 个的归一化形状（平移对齐后的像素集合）与青(8)模板相同，其余形状不同。
- 每个候选对象（无论是否匹配）旁边恰好有一个 1 像素的指示像素与其 4-连通邻接。指示像素颜色从红(2)、绿(3)、黄(4)、蓝(1)中选取。
- 生成约束：匹配对象的指示像素方位（上/下/左/右）在该方向上到网格边界之间无其他非背景对象阻挡（保证平铺路径畅通）。各匹配对象的平铺路径互不重叠。

**规则**：
1. 识别青(8)模板对象，提取其归一化掩码（平移至原点后的相对像素坐标集合）。
2. 对每个灰(5)候选对象，提取归一化掩码并与模板比对。若完全匹配，标记该对象为"选中"。
3. 对每个选中对象：
   a. 找到与其 4-连通邻接的唯一指示像素。
   b. 指示像素相对于对象包围盒中心的方位确定平铺方向（指示在右 -> 向右平铺；指示在左 -> 向左；指示在上 -> 向上；指示在下 -> 向下）。
   c. 以对象包围盒在平铺方向上的尺寸为步长，沿该方向逐步复制对象形状，副本颜色使用指示像素的颜色，直到副本的任一像素超出网格边界时停止（最后一个完整放入的副本保留，部分超出的不绘制）。
   d. 原对象保持灰(5)不变。指示像素保持原色不变。
4. 未选中的候选对象及其指示像素保持原样。青(8)模板保持原样。

**关键洞察**：模板匹配不直接产生视觉输出，而是充当平铺操作的"门控"——只有通过形状校验的对象才会被平铺展开，且平铺方向和颜色完全由指示像素编码，形成一个"筛选-编码-执行"三环节紧耦合的推理链。

## 新题 8：射线交汇印章

**组合逻辑**：[射线延伸/ray_extend](从精灵体沿轨迹反向投射射线) + [碰撞停止/collision_stop](射线遇到其他射线或障碍时停止) + [印章覆盖/stamp](在射线交汇点放置精灵体副本，颜色取自交汇对方) — 射线交汇创造源题中不存在的空间事件点，该事件点同时决定印章位置和颜色

**来源原语**：射线延伸/ray_extend(9f8de559), 反向投射/opposite_direction(9f8de559), 轨迹/trail(9f8de559), 碰撞停止/collision_stop(2c608aff), 印章覆盖/stamp(3e980e27), 精灵体/sprite(3e980e27), 颜色配对/color_pairing(3e980e27)

**依赖链**：每个精灵体有一条 2 像素的同色轨迹表明来向。从精灵体出发沿轨迹反方向投射射线，射线遇到另一条射线或网格边界时停止。当两条射线恰好在同一像素位置交汇（正面碰撞或交叉），在该交汇点以交汇点为锚放置一个精灵体的印章副本——副本使用的形状来自轨迹更长的精灵体（本题中长度相同时取行号更小的），颜色来自另一个精灵体。删除射线则无交汇点；删除印章则交汇无后果；删除碰撞规则则射线长度不确定。

从带轨迹的精灵体向对面射线投射，射线交汇处放置由交汇双方共同决定形状和颜色的印章副本。

**输入结构**：
- 约 18x18 的网格，黑(0)背景。
- 2~4 个精灵体，每个由 3~5 像素组成，4-连通，颜色各不相同（从蓝(1)、红(2)、绿(3)、黄(4)中选取）。
- 每个精灵体有一条由 2 个同色像素组成的轨迹，从精灵体的某个边缘像素向一个正交方向（上/下/左/右）延伸 2 像素，表明精灵体的"来向"。
- 生成约束：从每个精灵体出发沿轨迹反方向（来向的反方向）投射射线时，至少有一对精灵体的射线会在网格内交汇（即射线方向相对或垂直交叉且路径重合于某像素）。交汇点处及其以精灵体包围盒为范围的邻域全为黑(0)（保证印章可放置）。不交汇的射线延伸至网格边界。

**规则**：
1. 对每个精灵体，识别其 2 像素轨迹的方向。轨迹方向 = 从精灵体边缘像素到轨迹末端的方向。射线方向 = 轨迹方向的反方向。
2. 从每个精灵体的包围盒中心像素（取 floor）出发，沿射线方向逐像素延伸。射线用灰(5)绘制。射线在以下情况停止（不含停止位置的像素）：遇到非背景、非灰(5)像素；遇到另一条已绘制的灰(5)射线像素；到达网格边界。
3. 射线按精灵体的行号从小到大的顺序依次绘制（保证碰撞判定顺序确定）。
4. 检查所有射线的停止事件：若精灵体 A 的射线因碰到精灵体 B 的射线而停止（停止位置的下一像素是 B 的射线像素），则 A 和 B 形成一个"交汇对"，交汇点 = A 射线的最后一个灰(5)像素的位置。
5. 对每个交汇对 (A, B)：
   a. 选择轨迹更长的精灵体提供印章形状（本题轨迹均为 2 像素，故选行号更小的精灵体的形状）。
   b. 印章颜色使用另一个精灵体的颜色。
   c. 将印章放置在交汇点，以交汇点为印章形状的包围盒左上角。印章像素仅绘制在黑(0)背景上，不覆盖射线或其他非背景像素。
6. 轨迹像素保持原色不变。精灵体保持原样。

**关键洞察**：射线交汇是一个涌现事件——每条射线独立投射时不知道会在哪里停下，交汇点的位置由两条射线的共同几何决定；而交汇点处的印章同时从两个精灵体获取信息（形状和颜色分别来自不同方），构成一个需要全局推理的决策节点。

## 新题 9：连通种子标记与逐色包围盒翻转的交织

**组合逻辑**：[填充/flood_fill](种子像素通过连通可达性标记腔体) + [逐色独立变换/per_color_transform](填充后每种填充色的掩码独立翻转) + [描边/mark_neighbors](翻转后在对角邻接处标记新像素) — 填充产出的颜色分区决定翻转的分组，翻转改变形状后描边结果与翻转前不同

**来源原语**：填充/flood_fill(8b7bacbf), 种子像素/seed_pixel(8b7bacbf), 封闭腔体/enclosed_cavity(8b7bacbf), 连通可达/connectivity_reachable(8b7bacbf), 逐色独立变换/per_color_transform(e74e1818), 包围盒内翻转/flip_within_bbox(e74e1818), 描边/mark_neighbors(10fcaaa3), 对角邻接/diagonal_adjacency(10fcaaa3)

**依赖链**：灰(5)线条画围成多个封闭腔体。边界种子像素标记并填充可达腔体（每种种子色填充不同的腔体集合）。填充后，每种填充色形成一个单色掩码，对该掩码在其包围盒内执行垂直翻转（行反转）。翻转后，对每个非背景、非灰像素检查对角邻接，将黑(0)对角邻居标记为橙(7)。删除填充则无颜色分组供翻转；删除翻转则描边结果基于未翻转形状（不同）；删除描边则翻转后缺少最终装饰。

线条画围成的腔体被种子灌注着色，各色区域独立翻转后，在对角位置描边标记。

**输入结构**：
- 约 16x16 的网格，黑(0)背景。
- 灰(5)像素构成一幅 4-连通线条画，线条画内部围成 3~5 个互不相连的封闭腔体（每个腔体为 4-连通的黑(0)区域，被灰(5)像素完全包围）。
- 2~3 个种子像素位于网格边界（第 0 行、最后一行、第 0 列或最后一列），颜色从红(2)、绿(3)、蓝(1)中选取，每种颜色最多一个种子。
- 每个种子像素与灰(5)线条画通过 8-连通路径可达。
- 生成约束：每个封闭腔体的边界（灰像素）恰好与一个种子像素的 8-连通前景连通分量 4-邻接（不存在一个腔体可达两个种子的歧义）。至少两个腔体被不同颜色的种子填充（保证逐色翻转有意义）。各种填充色的掩码包围盒互不重叠。

**规则**：
1. 识别灰(5)线条画和边界种子像素。
2. 对每个封闭腔体（被灰(5)完全围合的 4-连通黑(0)区域），检查其灰(5)边界像素中哪些与某种子像素的 8-连通前景分量 4-邻接。将该腔体内所有黑(0)像素填充为对应种子的颜色。
3. 填充完成后，对每种非背景、非灰颜色 C 独立执行：提取颜色 C 的完整像素集合（即所有被填充为 C 的腔体像素），计算该集合的包围盒 [r_top, r_bot] x [c_left, c_right]，将集合内每个像素 (r, c) 映射到 (r_top + r_bot - r, c)。新位置若为黑(0)则写入颜色 C，原位置变为黑(0)。（灰像素不参与翻转，保持原位。）
4. 翻转完成后，遍历网格中每个非黑(0)、非灰(5)、非橙(7)像素，检查其 4 个对角邻居。若某对角邻居为黑(0)，将其标记为橙(7)。
5. 灰(5)线条画始终保持不变。若翻转后某填充像素落在灰(5)像素位置，该填充像素被丢弃（灰线条优先）。

**关键洞察**：填充赋予腔体颜色身份，颜色身份又决定了翻转的分组边界——翻转不是全局操作而是按填充色分区进行，因此填充结果直接塑造了翻转后的形状，进而影响描边的最终图案。三个操作形成严格的信息传递链。

## 新题 10：坐标轴距离排序与射线连接

**组合逻辑**：[距离排序/distance_ordering](孤立像素按到坐标轴线的距离排序) + [射线延伸/ray_extend + 碰撞停止/collision_stop](按排序顺序从每个像素向矩形投射射线) + [重涂色/recolor](射线颜色由排序名次决定) — 排序名次同时编码射线绘制顺序和颜色，顺序差异导致碰撞结果不同

**来源原语**：距离排序/distance_ordering(291dc1e1), 坐标轴线/coordinate_axis_line(291dc1e1), 射线延伸/ray_extend(2c608aff), 碰撞停止/collision_stop(2c608aff), 行列对齐/row_col_align(2c608aff), 矩形/rectangle(2c608aff), 孤立像素/isolated_pixel(2c608aff), 重涂色/recolor(4ff4c9da)

**依赖链**：一条坐标轴线将网格分为两侧。孤立像素分布在轴线同一侧，一个大矩形在另一侧。每个孤立像素按到轴线的曼哈顿距离排序（近的排前），按排名顺序依次向矩形投射正交射线（沿行或列对齐方向）。先投射的射线成为后续射线的碰撞障碍——后投射的射线若路径上遇到先前的射线则提前停止。每条射线的颜色按排名从预定义色序中取（第 1 名用蓝(1)、第 2 名用红(2)、第 3 名用绿(3)、第 4 名用黄(4)）。删除排序则射线顺序和颜色不确定；删除碰撞停止则射线长度不依赖于顺序；删除重涂色则射线无法区分。

孤立像素按到坐标轴的距离排名，按名次顺序向矩形投射射线并着色，先到的射线阻挡后到的射线。

**输入结构**：
- 约 18x18 的网格，黑(0)背景。
- 一条灰(5)水平线贯穿网格某行（不在第 0 行或最后一行），作为坐标轴线。
- 灰线上方有一个橙(7)实心矩形（至少 3x3，不接触灰线，矩形下边缘距灰线至少 2 行）。
- 灰线下方分布 3~5 个品红(6)孤立像素（各占 1 像素），每个孤立像素的列位于矩形列范围内（保证列对齐可投射）。
- 生成约束：各孤立像素到灰线的曼哈顿距离互不相同（保证排序无并列）。孤立像素之间的列位置不完全相同（至少有两个不同列）。

**规则**：
1. 识别灰(5)水平轴线、橙(7)矩形、品红(6)孤立像素。
2. 计算每个孤立像素到灰线的曼哈顿距离（= 像素行号 - 灰线行号）。按距离从小到大排序，得到投射顺序。排名从 1 开始。
3. 定义色序：排名 1 -> 蓝(1)，排名 2 -> 红(2)，排名 3 -> 绿(3)，排名 4 -> 黄(4)，排名 5 -> 青(8)。
4. 按排名顺序，对每个孤立像素执行：
   a. 从该像素出发向上（朝矩形方向）逐行延伸射线。
   b. 射线遇到以下情况停止：到达橙(7)矩形的像素（停止，不覆盖矩形像素）；到达先前已绘制的射线像素（停止，不覆盖已有射线）；到达灰(5)轴线像素（停止，不覆盖轴线）。
   c. 将射线路径上的所有黑(0)像素着色为该排名对应的颜色。
5. 孤立像素本身也重涂为其排名对应的颜色。
6. 灰线、矩形、其他元素保持不变。

**关键洞察**：排序名次同时编码了三种信息：射线绘制的时间顺序、射线的颜色、以及间接决定了射线的最终长度（先绘制的射线畅通无阻地到达矩形，后绘制的可能被先前射线截断）。求解者必须理解距离排序产生的顺序依赖效应才能正确预测每条射线的终点。
