## 新题 1：射线凿壁迷宫与奇偶洪泛

**组合逻辑**：[射线延伸](创新：射线击中迷宫墙壁时擦除墙壁像素而非绘制) → [擦除](射线贯穿墙壁使不连通走廊贯通) → [洪泛填充 + 路径奇偶交替涂色](创新：在被射线修改后的拓扑上执行，奇偶性由被凿开的捷径决定)

**来源原语**：射线延伸/碰撞停止(e12f9a14), 擦除(456873bc/6d0160f0), 洪泛填充/路径奇偶交替涂色(b782dc8a), 迷宫走廊/种子像素(b782dc8a), 带框块/框架缺口(e12f9a14)

**依赖链**：框架缺口位置决定射线方向 → 射线与迷宫墙壁的交点决定哪些墙壁被凿开 → 凿开后的拓扑连通性决定两个种子洪泛的交汇位置 → 从种子到每个走廊格子的 BFS 距离奇偶性决定涂色。删除射线凿壁步骤，走廊拓扑不变，洪泛结果完全不同；删除洪泛步骤，凿壁效果无处着色。

根据带框块的缺口位置发出对角射线凿穿迷宫墙壁，再用两色种子沿修改后的走廊网络做奇偶交替洪泛填充。

**输入结构**：
- 约 18x18 网格，黑(0)背景。
- 青(8)像素构成 1 像素宽的迷宫墙壁，墙壁之间的黑(0)像素为走廊。迷宫保证存在至少两个不连通的走廊连通分量。
- 2 个带框块：每个由绿(3)像素构成 4x4 外框，内含 2x2 单色块（一个红(2)、一个蓝(1)）。每个外框恰好有 1 个缺口像素（框上一个位置为黑(0)而非绿(3)）。带框块位于迷宫墙壁之间的走廊交叉处。生成保证每个带框块的 4x4 区域不与其他带框块或网格边界重叠。
- 2 个种子像素：一个红(2)、一个蓝(1)，各位于不同走廊连通分量中的走廊格子上。生成保证两个种子分属不同连通分量（在射线凿壁之前）。

**规则**：
1. 对每个带框块，从缺口像素出发向外发射对角射线。射线方向由缺口相对于 2x2 内块中心的方位决定：缺口在内块的右上方 → 射线向右上（行-1, 列+1）；缺口在左下方 → 射线向左下；以此类推四个对角方向。射线颜色为内块颜色。
2. 射线沿对角方向逐像素前进。遇到黑(0)走廊像素时跳过（不改变该像素）；遇到青(8)墙壁像素时**擦除该墙壁像素为黑(0)**（凿开通道），射线继续前进；遇到绿(3)框架像素或另一条射线已凿开的路径或非黑非青像素时停止；到达网格边界时停止。射线本身不留痕迹——它只擦除墙壁。
3. 所有射线处理完毕后，从红(2)种子像素出发，对所有 4-连通的黑(0)走廊格子执行 BFS 洪泛。BFS 距离为偶数的格子涂红(2)，奇数的涂蓝(1)。种子本身距离为 0（偶数），涂红(2)。
4. 同时从蓝(1)种子像素出发，对其所在连通分量的黑(0)走廊格子执行 BFS 洪泛。BFS 距离为偶数的涂蓝(1)，奇数的涂红(2)。
5. 若射线凿壁使两个种子的连通分量合并，则每个走廊格子取距离它更近的种子来决定奇偶（取到两个种子的 BFS 距离中较小者）。若距两个种子等距，取行号较小的种子（行号也相同则取列号较小的）。
6. 绿(3)框架、内块像素、剩余的青(8)墙壁像素保持不变。

**关键洞察**：射线不绘制而是擦除——它改变的是迷宫拓扑而非视觉外观。被凿开的墙壁产生捷径，捷径改变 BFS 距离，距离的奇偶性决定每个走廊格子的最终颜色。射线几何与迷宫结构的交互决定了哪些墙壁被打通，这是无法跳过的中间推理步骤。

## 新题 2：轮廓共界镜像印章

**组合逻辑**：[轮廓围合](识别区域对) → [形状匹配/旋转反射等价](在相邻区域间配对精灵体与占位体) → [镜像](创新：镜像轴由两区域共享的轮廓边界方向决定，而非由标记臂方向决定) → [印章覆盖](将镜像后的颜色印到占位体位置)

**来源原语**：轮廓围合/封闭背景区域(753ea09b), 形状匹配/旋转反射等价(845d6e51), 镜像(9bebae7a), 印章覆盖/掩码匹配(321b1fc6), 占位对象(321b1fc6)

**依赖链**：轮廓拓扑决定区域划分 → 区域的 4-邻接关系决定源-目标配对 → 共享轮廓段的方向决定镜像轴 → 形状匹配确定旋转/反射变换 → 镜像后的颜色模式印到占位体上。任何一步都不可跳过：没有轮廓就不知道配对，没有共界方向就不知道镜像轴，没有形状匹配就不知道如何对齐掩码。

根据轮廓线将网格分区，在共享轮廓边界的相邻区域间配对多色精灵体与灰色占位体，沿共享边界方向镜像精灵体的颜色后印到占位体上。

**输入结构**：
- 约 18x18 网格，黑(0)背景。
- 橙(7)像素构成 1 像素宽的闭合轮廓线，将网格内部划分为 4~6 个封闭区域。轮廓线全部 8-连通，且每条闭合回路至少围合一个区域。
- 区域成对出现（共 2~3 对）。每对中：一个"源区域"包含一个多色精灵体（3~6 像素的 4-连通图形，使用红(2)、蓝(1)、绿(3)中的 2~3 种颜色）；另一个"目标区域"包含一个灰(5)单色占位体。
- 每对源区域与目标区域共享至少一段连续的橙(7)轮廓边界（长度 >= 2 像素），该共享段要么是纯水平的，要么是纯垂直的。
- 每个占位体的形状（像素连通掩码）与其配对源精灵体的形状在旋转/反射等价意义下相同。
- 生成保证每个目标区域恰好与一个源区域相邻（不存在歧义配对），且不同对的区域互不相邻。

**规则**：
1. 用橙(7)轮廓线作为 barrier，将黑(0)背景分割为 4-连通的封闭区域。
2. 对每个含灰(5)占位体的目标区域，找到与它共享橙(7)轮廓段的源区域（含多色精灵体的区域）。
3. 确定共享轮廓段的方向：若该段是水平的（同一行上连续的橙像素），镜像轴为水平方向（即对精灵体做上下翻转）；若是垂直的（同一列上连续的橙像素），镜像轴为垂直方向（即对精灵体做左右翻转）。
4. 对源精灵体先执行步骤 3 确定的镜像翻转，再尝试 0°/90°/180°/270° 四种旋转，找到使翻转+旋转后的掩码与占位体掩码完全吻合的变换组合（保证唯一）。
5. 将该变换施加于精灵体的颜色像素，将结果逐像素印到占位体的位置上，替换灰(5)像素。
6. 源精灵体保持原样，橙(7)轮廓线和其余黑(0)背景不变。

**关键洞察**：轮廓线不仅划定区域边界和配对关系，还通过共享边界段的朝向（水平 vs 垂直）编码了镜像变换的具体方式。同一形状的占位体在不同位置可能得到不同的颜色排布，因为决定镜像轴的是它与源区域之间的物理分界线方向。

## 新题 3：排名驱动的循环色带重涂

**组合逻辑**：[排序/长度排名](按像素数排名色带) → [重涂色](创新：图例高度索引的是排名位次而非空间位置) → [填充/空缺借邻色](创新：借色沿排名序循环而非沿空间左右序循环)

**来源原语**：排序/长度排名/高度即排名索引(97d7923e), 重涂色(97d7923e), 填充/空缺借邻色/循环相邻(c4d1a9ae), 竖向色带(c4d1a9ae), 颜色图例/竖条(97d7923e)

**依赖链**：各色带的非黑像素总数 → 排名序 → 图例高度到排名的映射 → 色带重涂颜色确定 → 以排名邻接（而非空间邻接）确定间隙借色来源。跳过排名直接用空间邻接借色会得到错误结果；跳过重涂则借色颜色不对。

按像素数量排名垂直色带，用图例高度索引排名位次来重涂色带，再按排名循环顺序填充色带间隙。

**输入结构**：
- 约 14x20 网格，黑(0)背景。
- 4~5 条垂直色带，每条占据独立的列范围（列范围不重叠），使用互不相同的颜色（如红(2)、蓝(1)、绿(3)、黄(4)、灰(5)）。每条色带跨越网格的全部行，但带内有若干黑(0)间隙像素（该列范围内某些行的像素为黑色而非色带颜色）。
- 各色带的有色像素总数互不相同（保证排名无平局）。
- 网格左上角（行 0~5、列 0~2 的区域）放置图例：图例由若干单色矩形块竖向排列组成，每块宽 1 像素、高 h 像素（h 在 1~5 之间），颜色各不相同，且每种颜色恰好出现在某条色带中。不同图例块之间用 1 行黑(0)间隔。图例块的高度值互不相同。
- 图例区域不与任何色带的列范围重叠。

**规则**：
1. 统计每条色带的有色（非黑）像素总数，按总数从多到少排名：最多的为排名 1，次多为排名 2，以此类推。
2. 读取图例：每个图例块具有颜色 K 和高度 h。高度 h 表示排名位次。
3. 找到排名为 h 的色带，将该色带中所有有色像素重涂为颜色 K。（例如图例块高度为 3、颜色为红(2)，则排名第 3 的色带所有有色像素改为红(2)。）
4. 所有色带重涂完毕后，填充间隙：对每条色带内的黑(0)间隙像素，填充为排名序中下一位色带的（重涂后的）颜色。排名最末的色带借排名第 1 的颜色，形成循环。
5. 擦除图例区域（图例块所有像素置为黑(0)）。色带列范围外的黑(0)背景不变。

**关键洞察**：间隙借色的循环顺序基于像素数量排名而非色带在网格中的空间左右顺序。仅凭单个示例无法区分这两种循环顺序——必须对比空间顺序和排名顺序不一致的多个示例，才能归纳出正确规则。

## 新题 4：晶格双重约束下的螺旋生长与坐标标记

**组合逻辑**：[螺旋生长/优先转弯规则](从十字臂端生长) → [标记点阵](创新：晶格标记同时充当螺旋停止条件和标记坐标编码) → [标记/局部对应晶格坐标](创新：螺旋经过的每个格元内的标记位置由该格元的晶格坐标决定)

**来源原语**：螺旋生长/优先转弯规则/间距约束(da515329), 十字图案/臂端(da515329), 标记点阵/格元/格元内居中(20981f0e), 标记/局部对应晶格坐标(456873bc), 掩码定插槽占位(456873bc)

**依赖链**：晶格标记的位置决定螺旋在何处停止 → 螺旋的实际路径决定它经过了哪些格元 → 经过的格元的晶格坐标决定格元内标记像素的局部位置。删除晶格，螺旋无停止条件；删除坐标编码，无法确定标记位置；删除螺旋路径计算，不知道哪些格元需要标记。

从十字臂端发射螺旋路径，螺旋在接近晶格标记点时停止，并在所经过的每个晶格格元内按格元坐标放置标记像素。

**输入结构**：
- 约 21x21 网格，黑(0)背景。
- 青(8)像素构成一个十字图案，位于网格中心附近。十字的每个臂长 2~3 像素，共 4 个臂端。
- 红(2)像素构成规则晶格标记：网格被划分为 4x4 的等大正方形格元（每个格元约 5x5 像素），每个格元中心放置一个红(2)标记像素。十字图案占据中央的若干格元。
- 生成保证：十字完全落在中央格元内，不与任何红(2)标记重叠；网格尺寸恰好容纳 4x4 格元（含格元间可能的 1 像素间隔）。

**规则**：
1. 从十字的每个臂端向外发射一条螺旋路径，起始行进方向为臂端外向方向顺时针旋转 90°（与参考题 da515329 相同）。螺旋颜色为青(8)。
2. 行进优先级：右转 > 直行 > 左转。正常步长为 2 像素；刚转弯后的第一步步长为 1 像素。
3. 额外停止规则：螺旋的下一个目标像素若落在某个红(2)标记像素的 8-邻域内（与该标记的切比雪夫距离 <= 1），则螺旋立即停止（不绘制该目标像素）。螺旋也在到达网格边界或遇到已有非黑像素时停止。
4. 所有螺旋绘制完毕后，对每个被螺旋路径经过的格元（格元内至少有一个像素被螺旋涂为青(8)），在该格元的局部坐标 (r_local, c_local) = (该格元的晶格行号, 该格元的晶格列号) 处放置一个黄(4)标记像素。晶格行号和列号均从 0 开始计数（左上角格元为 (0,0)）。若该局部位置已被螺旋或十字占据，则黄(4)覆盖在最上层。
5. 未被螺旋经过的格元不放置黄(4)标记。红(2)晶格标记、黑(0)背景保持不变。

**关键洞察**：红色晶格标记扮演双重角色——它们既是螺旋生长的"力场边界"（接近即停止），又是坐标编码系统的锚点（格元地址决定标记的局部位置）。螺旋的具体路径依赖于转弯优先级和晶格力场的共同约束，而路径决定了哪些格元被"激活"从而获得黄色坐标标记。

## 新题 5：膨胀求交通道决定孔洞填色

**组合逻辑**：[膨胀求交](两路径膨胀交集得中间通道) → [填充](创新：通道的边缘连通属性决定孔洞填充颜色，而非直接涂通道自身) → [擦除](通道和路径在最终输出中消失，只留填色后的对象)

**来源原语**：膨胀求交/路径组件/通道/两路径间隙重叠区(f1bcbc2c), 连通至边缘的部分(f1bcbc2c), 填充/孔洞/裁剪(3a25b0d8), 孔洞面积区分角色(3a25b0d8), 擦除(456873bc/6d0160f0), 边界框推断(6d75e8bb)

**依赖链**：两路径的几何形状 → 膨胀交集得通道 → 通道分段的边缘连通属性（连上边 vs 连下边 vs 都不连）→ 通道段与孔洞的邻接关系 → 孔洞填色 → 擦除路径和通道后裁剪。路径几何决定通道，通道决定颜色映射，颜色映射决定孔洞填色。删除膨胀求交则无通道信息，删除填充则对象保持有洞，删除擦除则通道和路径遮盖对象。

用两条路径的膨胀交集确定中间通道，通道的边缘连通属性决定其附近孔洞的填充颜色，最后擦除路径只保留填色后的对象。

**输入结构**：
- 约 18x18 网格，黑(0)背景。
- 两条橙(7)的 4-连通单像素宽路径组件，各自蜿蜒穿过网格，互不接触但间距通常为 2~3 像素。两条路径大致平行走向。
- 2~3 个带孔洞的对象：每个对象由单色像素构成（分别使用绿(3)、蓝(1)等颜色），8-连通，内部包含 1~2 个黑(0)孔洞（被对象像素完全包围的 4-连通黑色区域）。对象位于两条路径之间或附近。
- 每个孔洞的边界至少有一个像素与膨胀交集通道的某个像素 4-相邻。
- 生成保证：两条路径的间距足够产生非空的 1 像素宽通道；每个孔洞至少邻接一段通道。

**规则**：
1. 对每条橙(7)路径，将其每个像素向 8-邻域膨胀 1 格（即每个路径像素扩展为 3x3 区域）。取两个膨胀结果的像素集合交集，得到中间通道（通道宽度约为 1 像素）。
2. 将通道按 4-连通性分割为若干通道段。判断每段的边缘连通属性：
   - 若该通道段中存在像素 4-连通延伸到网格顶边（行 0），标记为"上连通"。
   - 若延伸到网格底边（最后一行），标记为"下连通"。
   - 可同时具有上连通和下连通，也可都不具有。
3. 对每个孔洞，找到与该孔洞边界像素 4-相邻的所有通道段。若这些通道段中有"上连通"段，孔洞填充为红(2)；若只有"下连通"段（无上连通），填充为蓝(1)；若有同时上下连通的段，填充为灰(5)；若所有邻接段都不连通到任何边缘，孔洞保持黑(0)不填。若同时邻接"上连通"段和"下连通"段（来自不同通道段），填充为红(2)（上连通优先）。
4. 所有孔洞填充完毕后，擦除橙(7)路径像素和通道像素（均置为黑(0)）。
5. 输出整个网格（对象保留原色及填充后的孔洞，其余为黑(0)背景）。

**关键洞察**：通道本身在最终输出中消失——它是纯粹的中间几何量。孔洞的颜色完全由通道的全局连通属性（是否延伸到网格边缘）决定，而通道的形状取决于两条路径的平行走向和局部间距。仅看输出无法直接观察到通道的存在，必须从路径几何反推。

## 新题 6：射线碰撞物理选槽与瓦片复制

**组合逻辑**：[射线延伸 + 碰撞转向规则](多源射线按物理规则碰撞) → [标记分组](创新：射线经过的槽位按"被几种射线颜色覆盖"分类) → [复制](仅向恰好被单色射线覆盖的槽位复制源瓦片)

**来源原语**：射线延伸/碰撞停止/碰撞转向规则/带框块/框架缺口(e12f9a14), 射线交汇(e12f9a14), 网格分区/分隔线(6d0160f0), 瓦片/复制(6d0160f0), 标记坐标编码槽位(6d0160f0), 标记分组(b74ca5d1)

**依赖链**：缺口位置 → 射线方向 → 碰撞检测（90° vs 45°规则）→ 每条射线经过的像素集合 → 每个槽位被几种颜色的射线覆盖 → 仅单色覆盖的槽位接收瓦片副本。碰撞规则改变射线路径，路径决定覆盖模式，覆盖模式决定哪些槽位获得瓦片。

多个带框块发射对角射线，射线按碰撞物理规则交互，统计每个网格槽位被几种不同颜色的射线覆盖，仅将源瓦片复制到恰好被单一颜色射线覆盖的槽位。

**输入结构**：
- 约 21x21 网格，黑(0)背景。
- 灰(5)分隔线将网格分为 4x4 的等大槽位阵列（每个槽位约 5x5 像素，分隔线宽 1 像素）。
- 3 个带框块分布在不同槽位中：绿(3)像素构成 4x4 外框，内含 2x2 单色块，三个内块颜色互不相同（如红(2)、蓝(1)、黄(4)）。每个外框有 1~2 个缺口像素。
- 左上角槽位（行 0 列 0 的槽位）包含一个多色源瓦片（使用橙(7)和栗(9)两色构成的 4-连通图案，3~5 像素）。源瓦片不与任何带框块重叠。
- 生成保证：至少存在 3 个以上仅被单一颜色射线覆盖的槽位；至少存在 1 个被两种以上颜色射线覆盖的槽位。

**规则**：
1. 每个带框块的每个缺口发射一条对角射线，颜色为内块颜色，方向由缺口相对内块中心的方位决定（同参考题 e12f9a14 的方向规则）。
2. 射线逐像素沿对角方向行进，绘制经过的每个像素为射线颜色（覆盖黑(0)和灰(5)分隔线像素；不覆盖绿(3)框架、其他射线已绘制的像素、或源瓦片像素）。射线到达网格边界时停止。
3. 碰撞规则——当两条射线的下一步将占据同一像素或相邻像素时：
   - 90° 碰撞（两射线方向夹 90°）：两射线均停止，碰撞点像素保持黑(0)（留 1 像素间隙）。
   - 45° 碰撞（两射线方向夹 45° 或 135°）：两射线合并为锯齿形路径继续前进，碰撞点无间隙。
4. 所有射线绘制完毕后，对 4x4 阵列中的每个槽位，统计该槽位内（不含灰分隔线）被多少种不同颜色的射线像素覆盖（0 种、1 种、2 种或 3 种）。
5. 对覆盖颜色种数恰好为 1 的槽位：将源瓦片复制到该槽位中（源瓦片图案以槽位左上角为对齐基准绘制，覆盖该槽位内的现有像素，包括射线像素）。对覆盖种数为 0、2 或 3 的槽位：保持不变。
6. 源瓦片原始位置（左上角槽位）在复制完成后清除为黑(0)。绿(3)框架和未被覆盖的灰(5)分隔线保持不变。

**关键洞察**：90° 碰撞留间隙而 45° 碰撞不留间隙的物理规则，导致某些槽位只被单色射线穿过而另一些被多色覆盖——这一分布模式取决于射线方向的精确角度关系。45° 合并使两色射线进入同一个槽位（排除该槽位的复制资格），而 90° 间隙可能阻止射线进入某些槽位（使其保持零覆盖）。最终的瓦片分布是碰撞物理的涌现结果。

## 新题 7：区域级奇偶洪泛与面积排名屏障

**组合逻辑**：[排序](按面积排名封闭区域) → [洪泛填充](创新：洪泛以区域为单位而非以像素为单位推进，交替着色按区域边界穿越次数的奇偶性) → [重涂色](创新：最小面积区域成为屏障阻断传播，改变有效图距离)

**来源原语**：排序/长度排名(97d7923e), 洪泛填充/路径奇偶交替涂色(b782dc8a), 路径连通(b782dc8a), 重涂色(97d7923e), 轮廓围合/封闭背景区域/轮廓线(753ea09b), 小区域被填充(753ea09b), 连通分量(753ea09b)

**依赖链**：轮廓线 → 区域分割 → 面积计算 → 排名 → 最小区域成为屏障 → 区域邻接图（去除屏障节点后）→ 从种子区域 BFS → 区域图距离奇偶 → 涂色。面积排名改变图结构（删除屏障节点），图结构决定 BFS 距离，距离奇偶决定颜色。

轮廓线围合出多个区域后按面积排名，最小面积区域成为传播屏障，两色种子在区域邻接图上做 BFS，每穿过一个区域边界交替一次颜色。

**输入结构**：
- 约 16x16 网格，黑(0)背景。
- 橙(7)像素构成 1 像素宽的闭合轮廓线，将网格划分为 6~8 个大小不等的封闭背景区域（4-连通的黑(0)像素集合，以橙(7)像素和网格边界为 barrier）。
- 各区域面积（黑像素数）互不相同（保证排名无平局）。
- 一个红(2)种子像素位于某个封闭区域内。
- 一个蓝(1)种子像素位于另一个封闭区域内。
- 生成保证：种子所在区域不是最小面积区域；去除最小面积区域后，所有剩余区域仍 4-连通可达（即屏障不会将图完全分割成不可达部分）。两个种子在去除屏障后可通过区域邻接图相互到达。

**规则**：
1. 识别所有被橙(7)轮廓线围合的 4-连通黑(0)封闭区域。网格外侧的背景不算封闭区域。
2. 按像素数（面积）对封闭区域排名，面积最小的为排名 1。
3. 所有面积相同为最小值的区域（本题保证唯一）成为"屏障区域"：它们不参与洪泛传播，保持黑(0)不变。
4. 构建区域邻接图：若两个非屏障区域共享至少一个橙(7)轮廓像素作为公共边界（即两区域中各有一个像素与同一个橙像素 4-相邻），则这两个区域在图中有一条边。屏障区域不参与建图。
5. 在区域邻接图上从红(2)种子所在区域和蓝(1)种子所在区域各自做 BFS。每个非屏障区域的"图距离"定义为从种子区域到该区域在邻接图上经过的最少边数。
6. 对每个非屏障区域：取其到两个种子区域的图距离中较小值 d，以及对应的最近种子颜色 C。若 d 为偶数，该区域所有黑(0)像素涂为 C；若 d 为奇数，涂为另一种种子颜色。种子区域自身 d=0（偶数），涂为自身颜色。
7. 若某区域到两个种子的图距离相等（d 值相同），取种子区域面积更大的那个种子的颜色作为 C（面积大的优先）。
8. 橙(7)轮廓线和屏障区域保持不变。

**关键洞察**：颜色交替发生在区域边界穿越层面而非像素步进层面——一个大区域内所有像素颜色相同，因为它们距种子的"区域图距离"相同。最小面积区域作为屏障会迫使洪泛绕行，改变有效图距离从而翻转某些区域的奇偶性。仅看单个示例可能误以为是像素级洪泛或简单空间分区着色，需对比多示例中屏障位置不同导致奇偶翻转的情况才能归纳出正确规则。

## 新题 8：主对角线分治的形状匹配变换

**组合逻辑**：[形状匹配/旋转反射等价](创新：允许的变换集合由精灵体相对主对角线的位置决定) → [重涂色](匹配结果决定颜色) → [标记](创新：跨骑对角线的精灵体额外获得轮廓标记)

**来源原语**：形状匹配/旋转反射等价(845d6e51), 重涂色(845d6e51/97d7923e), 图例区域/分隔线(845d6e51), 精灵体(845d6e51/321b1fc6), 沿主对角线转置(74dd1130), 对角共线(f0afb749), 边界框推断(6d75e8bb)

**依赖链**：精灵体边界框中心的位置 → 与主对角线的关系（上方/下方/跨骑）→ 决定允许的变换子集（仅旋转 / 仅反射 / 全部 8 种）→ 在受限变换下做形状匹配 → 匹配到的图例颜色决定重涂色 → 跨骑精灵体额外画轮廓。位置决定变换空间，变换空间决定匹配结果，匹配结果决定颜色，位置还决定是否画轮廓——位置信息被多路使用。

正方形网格中，查询精灵体的边界框中心相对主对角线的位置决定形状匹配时可用的变换子集，匹配到图例后重涂色，跨骑对角线的精灵体额外获得轮廓标记。

**输入结构**：
- 正方形网格（如 15x15），黑(0)背景。
- 灰(5)像素构成 L 形分隔线：从网格顶边向下延伸若干行后向左转至左边，在左上角围出一个矩形图例区域。
- 图例区域内有 3~4 个模板精灵体，每个由不同的单一颜色构成（如红(2)、蓝(1)、绿(3)、黄(4)），形状为 3~5 像素的 4-连通图形，各模板形状在所有 8 种刚性变换（4 旋转 + 4 反射）下互不等价。
- 图例区域外（主网格）有 5~8 个查询精灵体，全部使用橙(7)色，形状各异但每个都与图例中的某个模板在某种刚性变换下等价。
- 查询精灵体分布在网格各处，有的边界框中心位于主对角线（r = c）上方（r < c），有的在下方（r > c），有的跨骑对角线（边界框同时包含 r < c 和 r > c 的像素）。
- 生成保证：在各自允许的变换子集内，每个查询精灵体恰好匹配唯一一个图例模板。

**规则**：
1. 从图例区域读取模板精灵体，建立"形状到颜色"的映射表。
2. 对每个查询精灵体，计算其边界框的中心坐标 (r_center, c_center)，其中 r_center = (min_row + max_row) / 2，c_center = (min_col + max_col) / 2（取实数值，不取整）。
3. 根据中心位置判断所属类别：
   - r_center < c_center → "上三角"精灵体：仅允许使用 4 种旋转变换（0°, 90°, 180°, 270°）进行形状匹配。
   - r_center > c_center → "下三角"精灵体：仅允许使用 4 种反射变换（水平翻转、垂直翻转、主对角线翻转、副对角线翻转）进行形状匹配。
   - r_center = c_center → "对角线"精灵体：允许使用全部 8 种变换进行形状匹配。
4. 在允许的变换子集下，将查询精灵体的掩码与图例模板逐一比较，找到匹配的模板。将该查询精灵体的所有橙(7)像素重涂为匹配模板的颜色。
5. 对"对角线"类别的精灵体（r_center = c_center），在重涂后额外绘制 1 像素宽的青(8)轮廓：将该精灵体边界框向外扩展 1 像素，在扩展区域中与精灵体像素 4-相邻的黑(0)背景像素涂为青(8)。轮廓不覆盖已有非黑像素。
6. 灰(5)分隔线、图例区域内的模板、以及黑(0)背景保持不变。

**关键洞察**：同一形状的查询精灵体在不同位置可能匹配到不同的图例模板——因为主对角线将变换空间分为"仅旋转"和"仅反射"两个不相交的子集。一个在上三角区域通过 90° 旋转匹配模板 A 的精灵体，若出现在下三角区域则可能因为反射变换而匹配到模板 B。仅凭单个示例无法发现这一位置依赖的变换限制，必须对比同形状精灵体在对角线两侧的不同着色结果才能归纳出规则。
