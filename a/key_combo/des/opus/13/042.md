## 新题 1：射线遇框即停，命中框体洪泛填色

**组合逻辑**：[射线延伸](从3x3块八方辐射，但遇到灰色框边界即停止而非到达网格边缘——创新改造) + [洪泛填充](被命中的框体内部按命中射线着色——创新改造：填充触发由射线碰撞决定，填色由最短射线决定) + [封闭区域/空心矩形](作为射线障碍物而非独立填充目标——创新角色)

**来源原语**：射线延伸/ray_extension(1d398264)、罗盘方向/compass_direction(1d398264)、排除中心像素/exclude_center_pixel(1d398264)、洪泛填充/flood_fill(c0f76784)、封闭区域/enclosed_region(c0f76784)、空心矩形/hollow_rectangle(c0f76784)、包围/enclosure(c0f76784)

**依赖链**：3x3块的非中心像素确定8条射线的方向和颜色 → 射线向外延伸时检测是否碰到灰色框边界（空间碰撞判定） → 碰撞截断射线长度，同时标记该框为"被命中" → 对每个被命中的框，比较所有命中射线的行进距离，选最短者的颜色 → 用该颜色洪泛填充框的封闭内部。删除碰撞检测则射线直达边缘且框体无法被触发填充；删除距离比较则多射线命中时填色不确定；删除洪泛填充则命中无效果。

将一个3x3色块的八方射线投射到含有若干灰色空心矩形框的网格中：射线遇框停止，被射线命中的框按最短命中射线的颜色填充其封闭内部。

**输入结构**：
- 约15x15的网格，黑(0)背景。
- 网格中有一个实心3x3色块：中心像素为一种颜色（如灰(5)），周围8个像素各有颜色（取自蓝(1)、红(2)、绿(3)、黄(4)，允许相邻像素同色但不全同色）。
- 网格中散布3~5个灰(5)色空心矩形框，每个框为1像素厚的封闭矩形边框，内部为黑(0)。框的内部尺寸在2x2到4x4之间。
- 各框互不重叠、互不相邻，且不与3x3色块重叠。
- 生成约束：至少有2个框位于某条射线的路径上（即从3x3块某非中心像素沿其罗盘方向延伸的直线能命中该框的边框像素）；至少有1个框不在任何射线路径上；至少有1个框被2条以上射线同时命中。

**规则**：
1. 确定3x3色块的中心像素位置。对其余8个非中心像素，根据其相对于中心的位置确定罗盘方向（正上方为N，右上为NE，正右为E，依此类推共8个方向）。
2. 从每个非中心像素出发，沿其罗盘方向逐像素向外绘制射线，射线颜色为该起始像素的颜色。
3. 射线碰撞规则：若射线下一个待绘制像素是灰(5)色框边框像素，则射线在当前像素停止（不覆盖框边框）。若射线到达网格边界仍未碰到任何框，则在边界处停止。
4. 对每个被至少一条射线命中的框（"命中"指有射线因碰到该框边框而停止）：计算每条命中射线从起始像素到停止像素的曼哈顿距离。选择距离最短的射线的颜色，将该框的封闭黑(0)内部全部填充为该颜色。
5. 若同一个框被多条射线命中且最短距离相同（平局），按罗盘方向顺时针排序（N, NE, E, SE, S, SW, W, NW），选排序在前的射线的颜色。
6. 未被任何射线命中的框保持不变（灰(5)边框，黑(0)内部）。
7. 3x3色块本身保持不变。

**关键洞察**：射线不总是延伸到网格边缘——灰色框的边框充当障碍物截断射线。一个框的填充颜色由"哪条射线最先到达它"决定，这将射线的几何路径与洪泛填充的触发和选色紧密耦合。一个框还可能"遮蔽"其身后的框，使后方的框不被该方向的射线命中。

## 新题 2：双面板并集生成隐形墙壁，阻断标记像素的十字射线

**组合逻辑**：[透明叠加/并集合并](两个面板合并生成墙壁图案——已有用法的角色转换：合并结果不是最终输出而是中间障碍物) + [射线延伸](从标记像素向四方发射射线，被合并墙壁阻断——创新：射线障碍来自并集涌现的几何结构) + [异源交叉特殊着色](不同标记的射线交叉处涂特殊色——保留原语但作用于受墙壁约束的截断射线)

**来源原语**：透明叠加/transparent_overlay(5d2a5c43)、并集合并/union_merge(5d2a5c43)、分隔列/divider_column(5d2a5c43)、双侧对齐/bilateral_alignment(5d2a5c43)、射线延伸/ray_extend(45bbe264)、标记像素/marker_pixel(45bbe264)、行列交叉/row_column_crossing(45bbe264)、异源交叉特殊着色/cross_source_special_color(45bbe264)

**依赖链**：蓝色分隔列将网格分为左右面板 → 移除分隔列、按行列对齐两面板 → 对齐后逐像素取并集：任一面板有绿色则该位置为墙壁 → 墙壁图案是两面板都不单独展示的涌现结构 → 红色标记像素从四个基本方向发射射线 → 射线遇墙壁停止 → 不同标记的射线交叉处涂黄色。墙壁图案只有合并后才存在，射线长度完全取决于这个涌现的墙壁布局。

移除蓝色分隔列，将左右两个含绿色散点的面板按位并集合并生成灰色墙壁图案；两个红色标记像素各自向四个基本方向发射射线，射线遇墙壁即停；不同标记的射线交叉处涂黄色。

**输入结构**：
- 约11x(2W+1)的网格（如11x11），黑(0)背景。W为每个面板的宽度。
- 网格正中有一条蓝(1)色满高度分隔列（从第0行到最后一行全为蓝(1)）。
- 分隔列左侧为左面板（宽W），右侧为右面板（宽W）。两面板形状相同。
- 每个面板中散布若干绿(3)像素（3~8个），其余为黑(0)。两面板的绿色像素分布不同。
- 每个面板中各有一个红(2)单像素标记。两个标记在各自面板中的行列位置不同。标记不与绿色像素重合，不在分隔列上。
- 生成约束：两面板合并后的墙壁图案（绿色并集）不会完全封死任何标记的四个射线方向（每个标记至少有一个方向的射线能延伸至少2像素）；两个标记合并后的位置不同行不同列（保证存在交叉机会）。

**规则**：
1. 移除蓝(1)分隔列，将左右面板按行列对齐到一个宽W、高不变的紧凑网格上。
2. 对紧凑网格的每个位置：若左面板或右面板在该位置有绿(3)像素，则该位置标记为灰(5)墙壁；否则为黑(0)。
3. 将两个红(2)标记映射到紧凑网格中对应位置（左面板标记保持列坐标不变；右面板标记的列坐标映射为其在右面板中的相对列坐标）。
4. 从每个红(2)标记向上、下、左、右四个方向逐像素发射射线，颜色为红(2)。
5. 射线遇到灰(5)墙壁像素时停止（墙壁像素保持灰色，射线不覆盖墙壁）。射线到达紧凑网格边界时停止。
6. 若一个标记的射线和另一个标记的射线占据同一像素位置，该像素涂为黄(4)。
7. 标记像素本身保持红(2)，即使另一标记的射线经过该位置。

**关键洞察**：墙壁图案在任一单独面板中都不存在——它是两个面板绿色像素的并集涌现出的几何结构。射线的可达范围完全由这个涌现的墙壁布局决定，因此射线交叉点的位置既取决于标记的位置，也取决于两面板的联合遮挡效果。

## 新题 3：分隔线表格的单元格位置决定差异化变换

**组合逻辑**：[填充](表格位置分类后对空单元格按角落/内部分别涂色——创新：位置不仅决定颜色还决定操作类型) × [生长](角落单元格的图形向外生长并加边框——创新：生长方向受单元格边界约束) × [洪泛填充](内部单元格整体用图形内色填满——创新改造) ← [表格行列位/角落与内部分色](作为决策节点选择操作分支——角色提升为推理图的分叉点)

**来源原语**：填充/fill(e9c9d9a1)、表格行列位/table_row_col_pos(e9c9d9a1)、角落与内部分色/corner_interior_differ(e9c9d9a1)、分隔线网格/separator_grid(e9c9d9a1)、生长/grow(3befdf3e)、同心正方形层/concentric_layer(3befdf3e)、洪泛填充/flood_fill(c0f76784)、封闭区域/enclosed_region(c0f76784)

**依赖链**：绿色分隔线 → 识别表格结构并分割单元格 → 对每个单元格判定表格位置（角落/边缘/内部） → 检测单元格内是否含有带边框的小方块 → 位置类型 AND 内容类型共同决定操作分支（2维决策矩阵） → 角落+有方块→生长并加边框；内部+有方块→洪泛填满；边缘+有方块→保持不变；角落+空→填红色；内部+空→填橙色；边缘+空→保持黑色。任何一个决策维度缺失都无法确定正确操作。

在绿色分隔线构成的表格中，每个单元格根据其表格位置（角落/边缘/内部）和内容（有无带边框小方块）接受不同的变换：角落方块外扩加框、内部方块洪泛扩展、边缘方块不变，空单元格按位置着色。

**输入结构**：
- 约20x20的网格，黑(0)背景。
- 绿(3)色完整行和完整列形成分隔线，将画布分割为至少3行3列的矩形单元格表格（如3x3或3x4）。每个单元格的内部尺寸至少6x6。
- 部分单元格内包含一个"带边框小方块"：一个2x2的单色内核（颜色取自蓝(1)、红(2)、黄(4)，各单元格内核颜色可不同），外围1像素厚的灰(5)边框（总尺寸4x4），居中放置于单元格内。
- 其余单元格为空（全为黑(0)）。
- 生成约束：四个角落单元格中至少2个含有带边框小方块、至少1个为空；内部单元格（非角落非边缘）中至少1个含有方块、至少1个为空；边缘单元格（非角落的边界格）中至少1个含有方块。

**规则**：
1. 识别绿(3)色分隔线（满宽行和满高列），确定表格结构，将每个单元格分类为角落、边缘（非角落的边界位置）或内部（不在边界行也不在边界列）。
2. 对每个单元格检测其是否包含带边框小方块（4x4的灰(5)边框包裹2x2单色内核）。
3. 根据位置和内容执行对应变换：
   - **角落 + 有方块**：将方块向外生长1像素（灰(5)边框四面各外扩1像素，扩展后总尺寸变为6x6），内核保持原色和原尺寸。然后在生长后的灰色区域最外圈再添加1像素厚的栗(9)色边框（总尺寸变为8x8）。若生长后超出单元格边界，则截断到单元格边界。
   - **角落 + 空**：将整个单元格内部填充为红(2)。
   - **内部 + 有方块**：用方块内核的颜色洪泛填充整个单元格内部（内核颜色扩展到充满单元格，灰色边框被覆盖）。
   - **内部 + 空**：将整个单元格内部填充为橙(7)。
   - **边缘 + 有方块**：保持不变（方块原样保留在黑色单元格中）。
   - **边缘 + 空**：保持黑(0)不变。
4. 绿(3)分隔线始终保持不变。

**关键洞察**：绿色分隔线的作用不仅是划分空间，更隐式地定义了每个单元格的"角色"（角落/边缘/内部），而角色与内容共同构成二维决策矩阵——必须同时推断两个维度的规则才能正确预测每个单元格的输出。单看任何一个单元格都无法区分位置规则与内容规则。

## 新题 4：边缘方块滑至对侧留下错切轨迹

**组合逻辑**：[滑动/slide](方块从接触边缘滑至对侧——保留) + [错切/shear](轨迹不是直线条纹而是逐行偏移的平行四边形——创新：shear作用于slide的副产物trail上，而非作用于物体本身) + [接触边缘](确定滑动方向——保留) + [逐行偏移](错切量随行递增——保留但应用场景全新)

**来源原语**：滑动/slide(b25e450b)、轨迹条纹/trail_stripe(b25e450b)、接触边缘/touching_edge(b25e450b)、滑至对侧边缘/slide_to_opposite(b25e450b)、边缘矩形/edge_rectangle(b25e450b)、错切/shear(9f41bd9c)、逐行偏移/row_offset_incr(9f41bd9c)、地面行/floor_row(9f41bd9c)

**依赖链**：每个方块接触哪条边缘 → 决定滑动方向（上→下、左→右等） → 方块移至对侧边缘并在原位清除 → 轨迹区域被涂色，但不是直线条纹 → 错切方向与滑动方向垂直，每行/列偏移1像素（row_offset_incr）→ 轨迹形成平行四边形。滑动方向决定错切的主轴，错切量决定轨迹的几何形状，两者紧耦合。

将接触网格边缘的彩色矩形方块滑至对侧边缘放置，其扫过路径留下错切轨迹——轨迹不是直线条纹而是逐行偏移一像素的平行四边形斜带。

**输入结构**：
- 约14x14的网格，黑(0)背景。
- 最底行为灰(5)地面行（全行灰色）。
- 2~3个彩色矩形方块（每个2~3行高、2~3列宽），每个方块为单一颜色（取自蓝(1)、红(2)、绿(3)，各方块颜色不同）。
- 每个方块恰好接触一条外边缘（顶边、左边或右边，不接触底部地面行）。接触意味着方块的一整行或一整列紧贴该网格边缘。
- 生成约束：各方块的滑动路径（含错切后的展开区域）互不重叠；至少有一个方块接触顶边、至少有一个接触左边或右边；方块与灰色地面行之间至少有3行间距。

**规则**：
1. 确定每个方块接触的边缘，决定其滑动方向：
   - 接触顶边 → 向下滑动（停在灰(5)地面行正上方一行）。
   - 接触左边 → 向右滑动（停在右边缘）。
   - 接触右边 → 向左滑动（停在左边缘）。
2. 将方块从原位清除为黑(0)，在目标位置用原色重新绘制方块。
3. 在方块原位与目标位之间的扫过区域绘制错切轨迹：
   - 对竖直滑动（从顶边向下）的方块：轨迹覆盖方块原位底边到目标位顶边之间的所有行。在这些行中，方块的每一行投影（宽度与方块同）按逐行偏移规则向右偏移：第1行偏移0像素，第2行偏移1像素，第3行偏移2像素……以此类推。轨迹颜色与方块同色。超出网格右边界的像素截断不画。
   - 对水平滑动（从左边向右或从右边向左）的方块：轨迹覆盖方块原位与目标位之间的所有列。方块的每一列投影按逐列偏移规则向下偏移：第1列偏移0像素，第2列偏移1像素，依此类推。超出网格底边界（地面行之上）的像素截断不画。
4. 若两条错切轨迹在某像素重叠，保留滑动距离更长（起始边缘到目标边缘的像素数更多）的方块的颜色。距离相同时，保留颜色编号更小的方块的颜色。
5. 轨迹像素不覆盖目标位置的方块本身。
6. 灰(5)地面行保持不变。

**关键洞察**：轨迹不是直线条纹，而是逐行（或逐列）偏移1像素的斜带——滑动方向决定了错切的主轴（竖滑→横向错切，横滑→纵向错切），两个原本独立的操作（slide和shear）通过"轨迹"这个中间对象紧密绑定。必须同时理解滑动方向和错切规则才能重建正确的轨迹几何。

## 新题 5：四旋转叠加多数表决生成近对称图案

**组合逻辑**：[旋转](生成0/90/180/270四个旋转版本——保留旋转操作但不拼接为2x2，而是叠加到同一画布) + [透明叠加](四个旋转版本逐像素叠加——创新：叠加不是二值并集而是多数表决) + [去噪取主色](叠加时多数颜色胜出——将denoise_majority从空间区域选色迁移到旋转分量选色)

**来源原语**：旋转/rotate(46442a0e)、四旋转变体组拼图/four_rotations_composite(46442a0e)、透明叠加/transparent_overlay(5d2a5c43)、并集合并/union_merge(5d2a5c43)、去噪取主色/denoise_majority(996ec1f3)、忽略干扰项/ignore_distractors(996ec1f3)

**依赖链**：原始方阵 → 生成4个旋转版本（0, 90CW, 180, 270CW） → 四版本对齐叠加到同一画布 → 逐像素收集4个颜色值 → 排除黑色后在非黑色值中做多数表决 → 多数色为输出色；全黑仍为黑；平局时0度版本的颜色优先。旋转决定叠加内容，叠加冲突由表决机制解决，表决的平局由原始方向打破——三个环节形成闭环依赖。

将一个方阵的四个旋转版本（0/90/180/270度）叠加到同一画布，每个像素位置取四个旋转中非黑色的多数颜色；平局时原始方向的颜色胜出。

**输入结构**：
- 一个NxN方阵（N在5~8之间），包含黑(0)背景和若干非黑色前景像素。
- 前景像素使用1~3种不同颜色（取自蓝(1)、红(2)、绿(3)、黄(4)、品红(6)）。
- 前景图案不具有4重旋转对称性（否则叠加无意义），但可以具有部分对称性（如仅关于一条轴对称）。
- 生成约束：四个旋转版本叠加后至少存在2个像素位置出现平局（2种非黑色各出现2次），以便展示平局规则；至少存在3个像素位置出现明确多数（3或4票同色），以便展示多数规则。

**规则**：
1. 以方阵中心为旋转中心，生成4个版本：原始（0度）、顺时针90度、180度、逆时针90度（等价于顺时针270度）。
2. 将4个版本对齐叠加到同一NxN画布。每个像素位置收集4个颜色值（来自4个旋转版本）。
3. 对每个像素位置：
   - 若4个值全为黑(0)：输出黑(0)。
   - 否则，忽略其中的黑(0)值，在剩余非黑值中统计每种颜色的出现次数。
   - 若某颜色出现次数严格最多：输出该颜色。
   - 若存在平局（两种非黑色各出现相同次数）：输出0度版本在该位置的颜色。若0度版本该位置为黑(0)，则依次检查90度、180度、270度版本，输出第一个非黑色。
4. 输出为单个NxN网格。

**关键洞察**：输出呈现近似的4重旋转对称性，但并非完美对称——0度方向在平局时享有优先权，这个微妙的不对称性只有通过对比多个示例（特别是观察平局位置的输出）才能归纳出来。输出的每个像素都是四个旋转视角"投票"的结果。

## 新题 6：标记继承最近边缘色后同色配对连线

**组合逻辑**：[重涂色/标记继承最近源色](绿色标记按曼哈顿距离继承最近边缘线的颜色——保留) → [连线/同色配对](重涂色后出现同色像素对，将行列对齐的同色对用线段连接——创新：配对关系是重涂色的涌现结果，非输入直接给出) + [异源交叉特殊着色](不同颜色线段交叉处涂特殊色——保留但交叉图案取决于前一步的着色结果)

**来源原语**：重涂色/recolor(2204b7a8)、标记继承最近源色/marker_inherits_nearest_color(2204b7a8)、最近距离/nearest_distance(2204b7a8)、边缘线/edge_line(2204b7a8)、连线/draw_line(40853293)、同色配对/same_color_pairing(40853293)、行列对齐/row_col_align(40853293)、竖线交叉优先/vertical_priority_at_cross(40853293)

**依赖链**：两条不同颜色的边缘线提供颜色源 → 每个绿色标记按最近距离继承一种边缘色 → 继承后部分标记变为同色 → 在同色标记中寻找共享行或列的配对 → 连接配对为线段 → 不同颜色的线段交叉处涂特殊色。边缘线的位置和颜色决定标记的着色分区，着色分区决定哪些标记能配对，配对决定线段走向，线段走向决定交叉位置——四级因果链环环相扣。

两条不同颜色的边缘线作为颜色源，散布的绿色标记各自继承最近边缘线的颜色；继承后同色且行列对齐的标记配对并用线段连接；不同颜色线段的交叉点涂为黄色。

**输入结构**：
- 约11x11的网格，黑(0)背景。
- 两条满边的边缘线位于网格的对侧（如顶行为蓝(1)满行、底行为红(2)满行；或左列为蓝(1)满列、右列为红(2)满列）。两条边缘线颜色不同。
- 网格内部（边缘线之间）散布6~10个绿(3)单像素标记，其余为黑(0)。
- 生成约束：重涂色后（每个绿色标记变为最近边缘线的颜色），至少存在2对同色且共享行或列的标记对（每种边缘色至少贡献1对）；至少存在1处不同颜色线段的交叉（一条水平线段与一条垂直线段相交）；同一颜色中不存在3个标记共线（避免歧义：同色共线时两两配对但线段重叠）。

**规则**：
1. 保留两条边缘线不变。
2. 对每个绿(3)标记像素，计算其到每条边缘线最近像素的曼哈顿距离，将该标记重涂为距离更近的边缘线的颜色。若距离相等，选择位于网格顶部或左侧的那条边缘线的颜色。
3. 重涂后，在所有同色的非边缘线像素中寻找配对：两个同色像素若共享同一行或同一列，则形成一对。每个像素最多参与一对；若一个像素可与多个同色像素配对，选择距离最近的（曼哈顿距离最小）；仍平局则选行号更小的（再平局选列号更小的）。
4. 对每对配对，用它们的共有颜色绘制连接线段（填充两像素之间包含端点的所有水平或垂直像素）。
5. 若一条水平线段和一条垂直线段交叉于同一像素，且它们颜色不同，将该交叉像素涂为黄(4)。
6. 若两条同色线段交叉，交叉像素保持该颜色不变。
7. 标记像素本身保持重涂后的颜色（不被线段覆盖为黄色，即使另一颜色线段经过该位置）。

**关键洞察**：边缘线不仅是视觉装饰——它们通过距离场隐式地将标记空间划分为两个颜色区域。配对关系是着色的涌现结果：同一个标记靠近不同边缘线时会获得不同的颜色，从而加入不同的配对组。交叉点的位置既取决于边缘线的几何布局（决定分区），也取决于标记的具体坐标（决定配对和线段方向）。

## 新题 7：最大边框内提取画布后循环对角填充

**组合逻辑**：[裁剪/最大边框内部提取](在噪声网格中找到最大矩形边框，提取其内部——保留) + [循环填充/同余类交错铺满](在裁剪后的画布中识别对角线种子并按模3偏移重复——保留但画布由裁剪结果决定) + [忽略干扰项](裁剪操作本身就是降噪——角色迁移：从颜色降噪变为空间降噪)

**来源原语**：裁剪/crop(1c786137)、最大边框内部提取/largest_frame_interior_extract(1c786137)、空心矩形/hollow_rectangle(1c786137)、内部区域/interior_region(1c786137)、包含/containment(1c786137)、循环填充/cyclic_fill(05269061)、对角线/diagonal(05269061)、同余类交错铺满/congruence_interlaced(05269061)、等距偏移/equidistant_offset(05269061)、忽略干扰项/ignore_distractors(996ec1f3)

**依赖链**：噪声网格中存在一个最大单色矩形边框 → 裁剪到边框严格内部，丢弃边框及外部一切噪声 → 内部画布中包含3条不同颜色的对角线（同一斜率方向），分别占据模3的不同同余类 → 每条对角线按间距3重复自身颜色填满整个裁剪画布 → 输出为填满后的裁剪画布。裁剪决定画布尺寸和对角线内容，对角线的同余类结构决定循环填充的模式——裁剪错误则对角线识别失败，同余类误判则填充图案错误。

在嘈杂的网格中找到最大的单色矩形边框并裁剪到其内部；内部画布中的三条同斜率对角线各属不同的模3同余类，将它们各自按间距3循环重复以填满整个裁剪画布。

**输入结构**：
- 约18x18的网格。
- 网格中有一个品红(6)色空心矩形边框（1像素厚封闭矩形边界），为网格中面积最大的单色矩形边框。边框内部尺寸至少7x7。
- 边框内部：黑(0)背景上有3条完整的对角线段，颜色各不同（取自蓝(1)、红(2)、绿(3)）。3条对角线斜率方向相同（全为左上→右下，或全为右上→左下）。每条对角线属于不同的模3同余类（即对角线上的像素(r,c)满足 (r-c) mod 3 或 (r+c) mod 3 为固定值，且三条线的固定值分别为0、1、2）。
- 边框外部：散布各种颜色的噪声像素（随机颜色，随机位置），作为干扰项。
- 生成约束：边框外部噪声中不包含任何其他封闭的单色矩形边框（确保最大边框唯一）；边框内部除3条对角线外无其他非黑像素。

**规则**：
1. 找到网格中面积最大的单色封闭矩形边框（即品红(6)色的1像素厚矩形边界），以内部面积为比较标准。
2. 提取该边框严格内部的子网格（不包含边框像素本身），作为工作画布。丢弃边框和边框外部的所有内容。
3. 在工作画布中识别3条对角线及其颜色。确定它们共同的斜率方向。
4. 对每条对角线，按间距3在该斜率方向上重复：即将该对角线的颜色复制到所有与其同余类相同的平行对角线位置上（同一斜率方向，偏移量为3的倍数）。
5. 3条对角线各自独立重复后，画布上每个像素恰好被一条重复对角线覆盖（因为3条线分别占据模3的3个同余类，间距3重复后覆盖所有位置）。
6. 输出为填充完毕的工作画布。

**关键洞察**：边框外部的噪声是纯粹的干扰项——裁剪操作是空间层面的"去噪"。裁剪后的画布尺寸和对角线位置共同决定了循环填充的效果：画布越大，每条对角线需要重复的次数越多，但模3结构保证了三种颜色恰好无缝交错铺满整个画布。
