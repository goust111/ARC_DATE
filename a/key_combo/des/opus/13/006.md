## 新题 1：箭头射线筛选可桥间隙

**组合逻辑**：[射线延伸](创新：射线不绘制到输出，仅作为空间筛选器标记候选间隙) + [连线/draw_line](已有) + [同色配对](已有) + [最短间隙优先连](已有，但作用域从全局缩小到被射线激活的子集)

**来源原语**：射线延伸、朝向推断、缺角指示方向（6e19193c）；连线、同色配对、对向间隙、最短间隙优先连（f3b10344）；实心矩形（f3b10344）；箭头精灵体（6e19193c）

**依赖链**：箭头缺角 → 推断朝向 → 射线穿越网格 → 射线与间隙的空间交叉判定筛选出候选间隙 → 在每个颜色组的候选间隙中取最短者绘桥 → 擦除箭头

将同色矩形对之间的空白间隙按是否被箭头射线穿过分为"激活"与"未激活"，仅在激活间隙中选最短者绘制青色桥。

**输入结构**：黑(0)背景，约 15x18。3-4 对同色实心矩形（每对使用一种独特前景色，如蓝(1)、红(2)、绿(3)等），每对的两个矩形沿水平或垂直方向面对面排列，中间隔着纯背景空白间隙；同一对可能存在多条候选间隙（矩形在行或列方向的重叠跨度允许多段连接）。另有 2-3 个灰(5)箭头精灵体，每个为 2x2 像素中缺少一个角像素的形状，缺角位置指示朝向（缺右上角 → 朝右上，但此处简化为四个正方向：缺顶行右列 → 朝右，缺顶行左列 → 朝上，缺底行右列 → 朝下，缺底行左列 → 朝左）。箭头精灵体放置在不与任何矩形重叠的位置。生成约束：每个箭头的射线至少穿过一条间隙；至少一个颜色组有多条间隙且并非全部被激活；不同箭头的射线不共线。

**规则**：
1. 对每个灰(5)箭头精灵体，根据其 2x2 区域中缺失像素的位置推断朝向（缺顶行右列→朝右，缺顶行左列→朝上，缺底行右列→朝下，缺底行左列→朝左）。
2. 从每个箭头的中心沿其朝向投射一条虚拟射线（不绘制在输出中），射线延伸直到网格边界。
3. 对每对同色矩形，枚举所有候选间隙（两矩形的行或列跨度重叠至少三个像素，且中间全为背景的连续区域）。若某候选间隙被任一射线穿过（射线经过间隙中至少一个像素），则标记该间隙为"激活"。
4. 对每个颜色组：若存在至少一条激活间隙，选择其中最短的一条（间隙长度 = 两矩形在连接方向上的距离），用青(8)填充该间隙，填充宽度为两矩形共享跨度向内各收缩一个像素后的范围。若无激活间隙，该颜色组不绘桥。
5. 将所有灰(5)箭头精灵体像素替换为黑(0)。其余所有矩形和背景保持不变。

**关键洞察**：箭头不产生可见的射线输出——它们是"隐形筛选器"，决定哪些间隙有资格参与桥选。求解者必须先完成射线-间隙交叉判定，再在被筛选的子集内运用最短优先规则，两步缺一不可。

## 新题 2：对接生成掩模后求逻辑 NOR

**组合逻辑**：[对接拼合](已有) + [逻辑运算/NOR](创新：NOR 的输入掩模不是预设的，而是由对接步骤动态生成) + [裁剪](已有，用于提取 NOR 结果)

**来源原语**：对接拼合、连接点颜色匹配、对接对齐（20270e3b）；逻辑运算、逐像素对应、逻辑或非合并（1b2d62fb）；精灵体、连接点、二值掩模（20270e3b, 1b2d62fb）

**依赖链**：连接点颜色匹配 → 精灵体配对 → 对接生成两个复合掩模 → 归一化到相同边界框 → 逐像素 NOR → 裁剪输出

四个精灵体通过连接点颜色配对并对接，形成两个复合体；对两个复合体的二值掩模做 NOR，输出仅在两者皆为空的位置绘青色。

**输入结构**：黑(0)背景，约 14x14。四个小型单色 4-连通精灵体（每个 3-6 像素），分别使用蓝(1)、红(2)、绿(3)、黄(4)中的不同颜色，散布在网格中。每个精灵体内恰好有一个像素为"连接点"颜色（不同于精灵体自身颜色）。连接点颜色成对匹配：例如两个精灵体的连接点为橙(7)，另两个为品红(6)。网格底部有一条灰(5)水平线段横跨网格宽度。生成约束：同一对内的两个精灵体对接后形成的复合体，其紧凑边界框尺寸与另一对对接后的复合体紧凑边界框尺寸相同；NOR 结果非空（至少 3 个像素为 1）。

**规则**：
1. 按连接点颜色将四个精灵体配对：共享同一连接点颜色的两个精灵体为一对。
2. 在每对中，以紧凑边界框左上角更靠近网格左上角（先比行再比列）的精灵体为"基座"，另一个为"插件"。
3. 平移插件，使其连接点像素恰好位于基座连接点像素的正下方一格。将插件的所有像素印到网格上（覆盖该位置的背景）。
4. 将两个连接点像素重涂为基座精灵体的颜色，完成对接。
5. 对每个对接复合体，提取其紧凑边界框内的二值掩模（非黑像素 = 1，黑像素 = 0）。两个掩模尺寸相同（由生成约束保证）。
6. 逐像素计算 NOR：当两个掩模在对应位置均为 0 时，输出青(8)；否则输出黑(0)。
7. 将 NOR 结果裁剪为其紧凑边界框，水平居中放置在灰(5)水平线上方一行处（底边与灰线之间隔一行背景）。
8. 擦除原始四个精灵体及其对接位置（替换为黑(0)），保留灰(5)线和放置后的 NOR 结果。

**关键洞察**：NOR 运算的两个掩模在输入中并不存在——它们只在对接完成后才涌现。连接点颜色编码了配对关系，对接对齐决定了掩模的精确形态，因此改变任一连接点颜色的匹配就会改变 NOR 的输出。

## 新题 3：格子完整性编码同心环配色

**组合逻辑**：[洪泛填充](创新：不用于涂色输出，而是用于提取区间完整性信息) + [填充/同心方环](创新：环色不由散落标记决定，而由格子区间的完整/缺损状态和内含标记联合决定) + [距离映射/切比雪夫](已有)

**来源原语**：洪泛填充、完整与缺损区异色、格子框架、封闭背景区域、包含（83302e8f）；填充、距离映射、切比雪夫距离、中心对齐、同心方环、标记像素（ac0c2ac3）

**依赖链**：洪泛填充识别封闭区间 → 完整性判定（面积 vs 边界框） → 切比雪夫距离将区间映射到环层 → 完整区间的标记色作为该环色，缺损区间强制黄色覆盖

格子框架将网格分割为若干矩形区间，每个区间的完整性状态（完整 vs 缺损）与其包含的标记像素颜色共同决定对应同心环层的颜色。

**输入结构**：黑(0)背景，11x11 奇数正方形。栗(9)色格子框架将网格划分为多个矩形区间。格子部分墙壁缺失（缺少若干栗色像素），导致某些相邻区间合并为更大的非矩形连通区域。部分区间内放置一个孤立标记像素（颜色各异，从蓝(1)、红(2)、绿(3)、橙(7)、品红(6)中选取），每个区间最多一个标记。生成约束：网格中心 (5,5) 落在某个区间内部；从切比雪夫距离 d=0 到 d=5，每个距离恰好有一个区间（以该区间中离中心最近的像素计算距离）；距离 d=0 的区间（含中心）必须包含标记且为完整区间。

**规则**：
1. 在栗(9)格子框架的间隙中，用洪泛填充识别所有 4-连通黑(0)区域（区间）。
2. 对每个区间判定完整性：若该区间的像素数等于其紧凑边界框的面积（即完美填充矩形），则为"完整"；否则为"缺损"（有格子缺口导致多个格元合并）。
3. 计算每个区间到网格中心 (5,5) 的切比雪夫距离（取区间中离中心最近像素的切比雪夫距离）。
4. 构建 11x11 同心方环输出：对每个距离 d（d=0,1,...,5），确定该距离对应区间的颜色：
   - 若该区间完整且包含标记像素：环 d 取该标记的颜色。
   - 若该区间缺损（无论是否含标记）：环 d 取黄(4)。
   - 若该区间完整但无标记：环 d 取灰(5)。
5. 输出网格中每个像素 (r,c) 取 max(|r-5|, |c-5|) 对应的环色。格子框架不出现在输出中。

**关键洞察**：格子框架在输出中被完全丢弃——它仅作为空间脚手架，通过其墙壁的完整或缺失来编码每个环层该取标记色还是被黄色覆盖。求解者需同时理解两套几何体系（格子分割 vs 同心环），并通过距离映射在它们之间建立桥梁。

## 新题 4：分割-互换色生成四种周期瓦片

**组合逻辑**：[分割](创新：分割产物不再滑动偏移，而是成为瓦片生成器的素材) + [重涂色/颜色互换](创新：互换不是一次性变换，而是周期性地交替应用生成四种瓦片变体) + [印章覆盖/周期排布](已有)

**来源原语**：分割、颜色互换且偏移、双色物体（fc4aaf52）；印章覆盖、周期排布、周期内指定位变色（d304284e）；对角邻接拼合（fc4aaf52）

**依赖链**：分割双色物体 → 上半U+下半L → 颜色互换生成U'+L' → 四种瓦片{U,L,U',L'}按2x2棋盘式排布 → 瓦片间对角邻接

将一个双色物体水平分割并颜色互换，产生四种瓦片变体，按 2x2 棋盘模式周期铺满网格。

**输入结构**：黑(0)背景，约 10x20。一个双色 4-连通前景物体位于网格左上角附近，由两种前景色组成（如蓝(1)和红(2)），紧凑边界框高度为偶数（如 4 行），宽度 3-6 列。物体的上半部分和下半部分形状不对称（像素分布不同）。生成约束：物体足够小，使得网格至少能容纳 3x3 个瓦片块（含间隙）；两种前景色各至少占物体总像素的 30%。

**规则**：
1. 在双色物体的边界框垂直中点处水平切割，得到上半 U（保留原色）和下半 L（保留原色）。
2. 生成颜色互换变体：U' 为 U 中两种前景色互换后的结果；L' 为 L 中两种前景色互换后的结果。背景像素不变。
3. 以原始物体的边界框左上角为起点，将网格划分为瓦片槽位。每个槽位的大小等于半高 x 原宽（即 U 或 L 的边界框大小），槽位之间水平间隔 1 列、垂直间隔 1 行。
4. 将槽位按行列编号 (i, j)（i 为行号从 0 起，j 为列号从 0 起），按以下棋盘规则填充：
   - (i, j) 均为偶数：放置 U（原色上半）
   - (i, j) 行偶列奇：放置 L'（互换色下半）
   - (i, j) 行奇列偶：放置 U'（互换色上半）
   - (i, j) 均为奇数：放置 L（原色下半）
5. 超出网格边界的瓦片截断保留可见部分。间隙行列保持黑(0)。

**关键洞察**：分割操作不是为了位移重组（如源题中的滑动拼合），而是为了生成形状不同的瓦片模块；颜色互换不是一次性外观变换，而是与分割联合生产四种视觉上有区别的瓦片变体。两个操作的组合创造了一个 2x2 周期单元，这在任何单一源题中均不存在。

## 新题 5：最近邻竞争选色驱动行递增堆叠

**组合逻辑**：[最近邻选择/欧氏距离](创新：距离竞争的结果不直接用于涂色，而是选出一个颜色"代表"驱动后续操作) + [计数](创新：对竞争胜出色的全局出现次数计数，而非对目标对象涂色) + [堆叠/逐行递增](已有) + [重涂色](已有) + [擦除](已有)

**来源原语**：最近邻选择、欧氏距离最小、前景对象、标记像素（6df30ad6）；计数、像素数转计数图、前景像素（794b24be）；堆叠、逐行递增、色段、每行递增扩展（bbc9ae5d）；擦除（6df30ad6）；重涂色（6df30ad6）

**依赖链**：各标记色到灰色对象的最小欧氏距离 → 距离竞争选出胜出色 → 计数胜出色的全局像素数 → 像素数决定堆叠行数 → 行递增扩展构建输出 → 灰色对象重涂为胜出色 → 擦除落选标记

标记像素按离灰色对象的距离竞争，胜出色的全局像素数决定行递增堆叠的高度，同时灰色对象被重涂为胜出色。

**输入结构**：黑(0)背景，约 12x12。顶行从左起有一段连续的品红(6)色段（如占 3 格），其余为黑色。网格中下部有一个灰(5) 4-连通前景对象（5-15 像素，形状不规则）。散布在网格中的孤立标记像素共使用 2-3 种颜色（如蓝(1)、红(2)、绿(3)），每种颜色可有 1-4 个标记像素，分布在不同位置。生成约束：各标记色到灰对象的最小平方欧氏距离互不相等（保证唯一胜出）；胜出色的像素总数不超过网格宽度的一半减去品红色段长度（保证堆叠后色段不超过网格宽度）；标记像素不与灰对象或品红色段重叠；灰对象不占据顶行。

**规则**：
1. 对每种标记颜色，计算该颜色所有标记像素到灰(5)对象所有像素之间的最小平方欧氏距离。
2. 平方距离最小的标记颜色为"胜出色"。
3. 统计胜出色在整个网格中的标记像素总数，记为 N。
4. 从顶行开始逐行构建堆叠：第一行保持输入的品红(6)色段不变；此后每一行在前一行的基础上向右扩展一个像素（新增像素也为品红(6)），共生成 N 行（含顶行本身作为第 1 行）。若色段已扩展到网格右边界则不再增长，但仍计入行数。
5. 将灰(5)对象的所有像素重涂为胜出色。
6. 擦除所有非胜出色的标记像素（替换为黑(0)）。胜出色的标记像素保留。堆叠区域之外的品红色段行和背景不变。

**关键洞察**：距离竞争和像素计数操作的对象相同（标记像素），但提取的信息维度不同——距离选出"谁赢"，计数告诉"赢了多少"。求解者必须先解决距离竞争（需要测量所有标记色到灰对象的距离），再对胜出色计数（不是距离值，而是像素个数），两步使用同一数据的不同属性。

## 新题 6：模板对 NOR 生成补全掩模并按指示缩放贴合

**组合逻辑**：[逻辑运算/NOR](创新：NOR 不作为最终输出，而是生成补全所需的形状模板) + [缩放](已有) + [补全](创新：补全的形状不直接来自任何单一模板，而是来自两个模板的联合否定) + [对齐匹配/指示色](已有)

**来源原语**：逻辑运算、逐像素对应、逻辑或非合并、二值掩模（1b2d62fb）；缩放、补全、指示区域、对齐匹配、指示色定缩放对位、模板（57aa92db）

**依赖链**：两模板二值掩模 NOR → NOR 掩模即"缺失形状" → 指示区域确定缩放倍率 → 缩放 NOR 掩模 → 对齐并补全局部对象

两个模板的 NOR（两者皆无前景的位置）定义了补全形状；该形状按指示区域确定的缩放倍率和对齐方式粘贴到每个局部对象上。

**输入结构**：黑(0)背景，约 16x16。网格上半部分有两个完整"模板"精灵体（各 4-8 像素，4-连通，分别用蓝(1)和红(2)），二者被一条垂直栗(9)分隔线隔开（各在分隔线一侧）。两模板的紧凑边界框尺寸相同（如 3x4）。网格下半部分有 1-2 个"局部对象"，每个由若干绿(3)像素和若干黄(4)"指示"像素组成，4-连通。黄(4)像素同时出现在模板（蓝或红模板内的对应位置有黄(4)像素标记）和局部对象中。生成约束：两模板的 NOR 掩模非空（至少 3 个像素为 1）；局部对象的指示像素集合与某一模板中的指示像素子集在形状上一致但可能等比缩放（缩放因子为正整数）；缩放后的 NOR 掩模叠加到局部对象后不超出网格边界。

**规则**：
1. 提取两个模板（栗(9)线左右各一个）的紧凑边界框，在各自边界框内建立二值掩模（非黑像素 = 1）。两掩模尺寸相同。
2. 逐像素计算 NOR 掩模：两模板对应位置均为 0 时输出 1，否则输出 0。NOR 掩模记录的是"两模板皆不覆盖的区域"。
3. 对每个局部对象，提取其中的黄(4)指示像素集合，与模板中黄(4)像素的位置进行比对。计算缩放因子 = 局部对象指示区域跨度 / 模板指示区域跨度（取水平或垂直方向，整数）。
4. 将 NOR 掩模按该缩放因子做最近邻缩放。
5. 对齐：将缩放后的 NOR 掩模叠加到局部对象上，使指示像素的位置对准。NOR 掩模中值为 1 的位置用绿(3)（局部对象自身颜色）填充。
6. 将局部对象中的黄(4)指示像素重涂为绿(3)。擦除栗(9)分隔线和两个模板（替换为黑(0)）。保留局部对象及其补全结果。

**关键洞察**：任何单个模板都无法直接提供补全形状——补全形状是两个模板的"联合空缺"，即两者都没有覆盖的区域。求解者需要意识到分隔线两侧的模板并非独立参考，而是共同编码一个隐含规则：缺失的部分恰好是它们的 NOR。

## 新题 7：完整方块检测决定桥接端点

**组合逻辑**：[标记/完整方块才标记](创新：角外标记像素不仅用于注释，还作为桥接线段的几何端点) + [连线/draw_line](创新：线段端点不是对象本体，而是标记操作产生的衍生像素) + [同色配对](已有，但配对对象从矩形变为完整方块)

**来源原语**：标记、完整方块才标记、完整方块、角外像素、角点邻接（14b8e18c）；连线、同色配对、共行或共列、轴对齐线段（f3b10344, 070dd51e）

**依赖链**：检测完整方块（排除非方块对象） → 在方块四角外侧标红 → 同色方块配对 → 在配对方块的红色标记之间选取最近一对 → 绘制青色连接线段

识别完整方块对象并在其四角外标红，然后在同色方块对的最近红色标记之间绘制连接线段。

**输入结构**：黑(0)背景，约 15x15。5-7 个单色 4-连通前景对象，使用 2-3 种颜色（如蓝(1)、绿(3)、橙(7)）。其中部分对象是"完整方块"：其紧凑边界框为正方形且边界框所有边缘像素均为该对象颜色（可以是 2x2、3x3、4x4 实心方块或空心方框，只要边界完整）。其余对象为非方块形态（水平/垂直条、L 形碎片、不规则连通体等），可能与方块同色。同色完整方块恰好成对出现（每种颜色 0 对或 1 对方块）。生成约束：每对同色方块之间至少存在一条轴对齐路径（共行或共列的红色标记对），路径上无其他前景对象阻挡；非方块对象不与方块的角外标记位置重叠。

**规则**：
1. 检测所有完整方块对象：紧凑边界框为正方形，且边界框四条边上所有像素均为该对象颜色。非方块对象（即使同色）不参与后续步骤。
2. 对每个完整方块，在其四个角像素的外侧，沿与角正交的两个方向各标记一个红(2)像素（共 8 个标记位，但仅在该位置为背景时标记；超出网格边界则跳过）。
3. 对每对同色完整方块 A 和 B：从 A 的所有红色标记中选一个、从 B 的所有红色标记中选一个，使这两个标记共行或共列（即行号相同或列号相同），且它们之间的曼哈顿距离在所有满足共行/共列条件的标记对中最小。
4. 在选中的标记对之间绘制一条青(8)轴对齐线段（水平或垂直，包含两端点上方/下方的连接但不覆盖红色标记本身——线段从一个标记的内侧邻格画到另一个标记的内侧邻格）。若两标记之间有其他红色标记或前景像素，线段仍然绘制并覆盖它们（青色覆盖）。
5. 不与任何方块配对的非方块前景对象保持原样不变。

**关键洞察**：角外红色标记同时承担注释和几何锚点的双重功能。非方块的同色对象是干扰项——它们可能看似应该被连接，但只有通过完整方块检测才能正确识别哪些对象参与桥接。标记步骤产生的红色像素既是视觉标注又是连线端点的候选集，两个用途不可分割。

## 新题 8：小方块编码计数与颜色双信息填充同心环

**组合逻辑**：[计数/像素数转计数图](创新：像素数不转为计数图输出，而是控制环周填充量) + [距离映射/切比雪夫距离](创新：距离不映射标记颜色，而是将区块索引映射到环层) + [填充](创新：不全环填充，而是沿环周读序部分填充)

**来源原语**：计数、像素数转计数图、前景像素（794b24be）；距离映射、切比雪夫距离、中心对齐、同心方环、标记像素（ac0c2ac3）；填充（bbc9ae5d）

**依赖链**：每个 3x3 区块内的像素计数 → 区块到网格中心的切比雪夫距离确定对应环层 → 像素数控制该环层的填充量 → 沿环周读序部分填充

散布的 3x3 区块各编码一种颜色和一个计数值；其到网格中心的距离决定它控制哪层同心环，其像素数决定该环被填充多少格。

**输入结构**：黑(0)背景，9x9 奇数正方形。网格中心 (4,4) 有一个孤立的品红(6)像素。在切比雪夫距离 d=1,2,3,4 处各放置一个 3x3 区域。每个 3x3 区域的内部包含 1-4 个同色前景像素（颜色互不相同，从蓝(1)、红(2)、绿(3)、橙(7)中选取），其余像素为黑(0)。生成约束：每个 3x3 区域的中心到网格中心 (4,4) 的切比雪夫距离恰好为对应的 d 值（d=1,2,3,4 各一个）；3x3 区域之间互不重叠；每个 3x3 区域内的前景像素数不超过对应环层 d 的周长（环 d 周长 = 8d）。

**规则**：
1. 对每个 3x3 区域，统计其中非黑前景像素的个数 C 和颜色 K。
2. 计算每个 3x3 区域中心到网格中心 (4,4) 的切比雪夫距离 d。
3. 构建 9x9 同心环输出。中心像素 (4,4) 保持品红(6)。
4. 对每个环层 d（d=1,2,3,4）：沿该环的周长按"读序"遍历（从环的左上角 (4-d, 4-d) 出发，先向右走顶边，再向下走右边，再向左走底边，再向上走左边），将前 C 个像素填充为颜色 K，其余环内像素保持黑(0)。
5. 擦除所有原始 3x3 区域（替换为对应环层填充结果或黑色——实际上 3x3 区域所在位置会被同心环覆盖）。

**关键洞察**：每个 3x3 区块同时编码了两个独立信息维度——颜色（由像素色决定）和数量（由像素数决定），而切比雪夫距离提供了第三个维度（该区块控制哪一层环）。求解者必须同时解码三个维度才能确定输出：距离→环层，颜色→填充色，数量→填充长度。
