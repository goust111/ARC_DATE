## 新题 1：稀有色双重身份的循环铺展

**组合逻辑**：[最低频色定位](创新：同一颜色既标记位置又充当母题内容) + [循环填充] + [遇障碍截断]

**来源原语**：最低频色定位(48f8583b), 标记界定母题(12422b43), 循环填充/cyclic_fill(12422b43), 遇障碍截断(212895b5), 障碍像素(212895b5)

**依赖链**：频率分析同时确定填充起点和母题内容中的组成色；循环填充从种子向下铺展母题；障碍像素截断铺展边界。最低频色在母题内是内容、在母题外是位置标记，形成自指耦合——去掉频率分析则不知在哪填，去掉循环填充则不知填什么，去掉障碍截断则不知何处停止。

以母题中最稀有颜色的外部散布位置为种子，向下循环铺展母题行，遇障碍停止。

**输入结构**：
- 约 15x18 的网格，背景为黑(0)。
- 网格左上角有一个矩形母题区域（约 3 行 x 4 列至 4 行 x 5 列），其左边界由灰(5)标记列界定（标记列占 1 列，与母题等高）。母题区域内包含 2-3 种前景色（如蓝(1)、绿(3)、黄(4)），其中恰好一种颜色 C_rare 的像素数严格最少（仅 1-2 个像素）。
- 母题区域外，在网格的中下部散布着 2-4 个颜色为 C_rare 的孤立单像素，它们是填充种子。种子之间互不相邻，也不与母题区域 4-连通相邻。
- 网格中另有若干红(2)障碍像素，散布在种子的下方各行。障碍像素不与种子同行。
- 生成约束：每个种子正下方在到达网格底边前至少有一个障碍像素。母题区域外 C_rare 的出现总数等于种子数。各种子所在列加上母题宽度后的列范围互不重叠。

**规则**：
1. 在母题区域（灰色标记列右侧、与标记列等高的矩形范围）中，统计每种非背景(0)、非灰(5)颜色的像素数，找到像素数严格最少的颜色 C_rare。
2. 清除灰(5)标记列为背景，提取标记列右侧等高的矩形作为母题 M（保留 M 中所有颜色，包括 C_rare 本身）。M 的尺寸为 H_m 行 x W_m 列。
3. 找到母题区域外所有颜色为 C_rare 的像素，记为种子集合。
4. 对每个种子 S（位于第 r 行、第 c 列），从 S 的下一行开始向下循环铺展母题：第 r+1 行铺展 M 的第 0 行、第 r+2 行铺展 M 的第 1 行、...、第 r+H_m 行铺展 M 的第 H_m-1 行、第 r+H_m+1 行再铺展 M 的第 0 行，以此类推。铺展时，种子所在列 c 对齐 M 的第 0 列，即第 c 列至第 c+W_m-1 列依次对应 M 的各列。
5. 逐行铺展过程中，若当前行中待写入范围内（第 c 列至第 c+W_m-1 列的任一位置）存在红(2)障碍像素，则该种子的整个铺展在上一行之后终止（当前行不写入任何像素）。
6. 种子像素本身保留 C_rare 颜色。障碍像素保持红(2)不变。母题区域（含原标记列位置）清除为背景。
7. 若两个种子的铺展区域有列重叠，按种子列号从小到大的顺序处理，先铺展的像素不被后铺展的覆盖。

**关键洞察**：C_rare 在母题内是图案的一部分（铺展时照常写入），在母题外却是空间定位标记——求解者必须识别出同一颜色的两种角色，并区分"作为种子的 C_rare"与"作为母题内容被铺展出的 C_rare"。

## 新题 2：同心环形棋盘的计数配色

**组合逻辑**：[同心嵌套](提供环形几何) + [计数](创新：在环形区域上数棋盘格) + [像素数匹配格数] + [填充]

**来源原语**：同心嵌套(3a301edc), 严格内嵌(3a301edc), 计数(df8cc377), 像素数匹配格数(df8cc377), 棋盘格图案(df8cc377), 填充(df8cc377), 擦除(df8cc377)

**依赖链**：同心矩形框定义了环形区域的几何边界；在每个环形区域上计算棋盘格"有色"单元数产生了与环几何相关的数值；该数值与外部标记像素的颜色群体配对；配对结果决定每层环的填充颜色。删去同心结构则无环形区域可数，删去计数则无法配对，删去配对则不知用什么颜色填。

将外部散布的彩色标记按其数量匹配到同心矩形框各层环形区域的棋盘格中。

**输入结构**：
- 约 15x15 的网格，背景为黑(0)。
- 网格中央有 2-3 层同心矩形框，从外到内依次编号为第 1、2、3 层。每层框宽 1 像素、颜色各不相同（如第 1 层蓝(1)、第 2 层红(2)、第 3 层黄(4)）。相邻框之间间隔至少 2 行 2 列（形成环形背景区域）。最内层框内部也是背景区域。
- 框外散布着若干孤立单像素标记，分为与环形区域数量相同的几种颜色（如绿(3)、橙(7)、品红(6)），每种颜色的像素总数各不相同。
- 生成约束：将每个环形区域（第 k 层框与第 k+1 层框之间，以及最内层框内部）视为矩形环或矩形区，其从左上角起始的棋盘格"有色"单元数恰好等于某一种标记颜色的总像素数，且这种对应无歧义（一一映射）。

**规则**：
1. 识别同心矩形框，从外到内编号。定义环形区域：第 k 个环形区域是第 k 层框内壁与第 k+1 层框外壁之间的背景像素集合；最后一个环形区域是最内层框内部的全部背景像素。
2. 对每个环形区域，从其左上角像素开始铺设棋盘格图案：左上角为"有色"，相邻格交替为"有色"和"无色"。统计"有色"单元总数 N_k。
3. 统计框外每种标记颜色的像素总数。
4. 将每个环形区域的 N_k 与某种标记颜色的总数配对（数值相等即匹配）。
5. 在每个环形区域内，将棋盘格的"有色"单元填充为配对到的标记颜色，"无色"单元保持背景。
6. 擦除所有框外标记像素为背景。同心框本身的颜色保持不变。

**关键洞察**：环形区域不是简单矩形——它是两个矩形之差，其棋盘格"有色"单元数取决于外框和内框的尺寸差，不同层环的计数值因几何差异而各不相同。求解者必须精确计算每层环的棋盘格容量才能正确配对。

## 新题 3：调色板索引式射线绕行

**组合逻辑**：[调色板行](创新：作为空间到颜色的查找表) + [射线延伸] + [绕行] + [遇障碍绕最近侧]

**来源原语**：调色板行(bae5c565), 以缺口为中心(bae5c565), 射线延伸(c87289bb), 绕行(c87289bb), 遇障碍绕最近侧(c87289bb), 障碍线段(c87289bb)

**依赖链**：调色板行的缺口定义射线起点（源自 bae5c565 的缺口机制），射线下行遇障碍线段后绕行到新列（源自 c87289bb 的绕行机制），而绕行水平段的颜色由新列上方的调色板格子决定——调色板既是起点定义者又是颜色查找表，射线路径动态索引调色板的不同位置。删去调色板则无起点也无颜色信息，删去射线则无路径，删去绕行则路径被障碍阻断。

从调色板行的缺口向下发射射线，遇障碍线段绕行，每段水平绕行的颜色由目标列对应的调色板颜色决定。

**输入结构**：
- 约 12x15 的网格（12 列、15 行），背景为黑(0)。
- 第 0 行是调色板行：12 个格子中 11 个各有前景色（可以有相同颜色，但至少用 3 种不同颜色），恰好 1 个格子为背景色（缺口）。缺口不在第 0 列或最末列。
- 第 1 行以下，散布着 2-4 条水平障碍线段，每条由灰(5)像素组成，宽度 2-5 像素，各条不在同一行，相邻障碍行间距至少 2 行。
- 生成约束：缺口所在列被至少一条障碍线段覆盖（确保至少发生一次绕行）。每次绕行后新列在到达下一条障碍线段前至少有 1 行垂直空间。绕行目标列不超出网格范围。

**规则**：
1. 读取调色板行（第 0 行），记录每列的颜色。找到缺口列 c_start（背景色的列）。射线的垂直段颜色 C_ray 定义为缺口左侧相邻列（第 c_start-1 列）的调色板颜色。
2. 从第 1 行、列 c_start 开始，向下逐行画垂直射线，颜色为 C_ray。
3. 当射线到达第 r 行，且第 r+1 行在当前列是障碍线段的一部分时：
   a. 确定该障碍线段的左端列 c_L 和右端列 c_R。
   b. 计算射线当前列到左外侧（c_L - 1）和右外侧（c_R + 1）的距离，选择距离更近的外侧列 c_new。若等距则选右侧。
   c. 在第 r 行，从射线当前列到 c_new 画一条水平线段。该水平线段的颜色为调色板行中第 c_new 列的颜色。
   d. 射线跳至列 c_new，从第 r+2 行（障碍线段下方一行）继续垂直下行，垂直段颜色仍为 C_ray。
4. 射线到达网格最后一行后停止（最后一行也画上颜色）。
5. 调色板行保留不变。障碍线段保留灰(5)不变。

**关键洞察**：每次水平绕行的颜色不是固定的，而是由绕行目标列在调色板行中的颜色决定——调色板是一张空间到颜色的映射表，射线路径决定了它"读取"调色板的哪些列。不同的障碍布局导致射线走不同路径、索引不同的调色板位置，产生不同的水平段颜色组合。

## 新题 4：字形解码的印章轨迹

**组合逻辑**：[解码](创新：解码为印章放置序列而非线条) + [印章覆盖] + [弯头决定偏移]

**来源原语**：解码(e6de6e8f), 连线/trace(e6de6e8f), 弯头决定偏移(e6de6e8f), 字形(e6de6e8f), 印章覆盖(48f8583b), 瓦片(48f8583b)

**依赖链**：字形条带编码路径指令（直行或转弯），解码后产生一系列坐标偏移；每个偏移位置印上瓦片图案。路径拓扑决定瓦片间的重叠关系，重叠处后印覆盖先印。删去解码则不知瓦片放在哪里，删去瓦片则不知放什么内容，删去弯头偏移规则则路径方向无法确定。

解码字形条带为行走路径，在路径的每一步位置印上小瓦片图案。

**输入结构**：
- 约 20x20 的网格，背景为黑(0)。网格分为两个区域：
- 左区域（第 0-1 行，约第 0-9 列）：红(2)像素组成的字形条带。每个字形占 2 行、宽 2 列，4-连通。字形有两种类型：垂直字形（仅中心列两行都有像素，形成竖直二像素段）和弯头字形（形成 2x2 区域中缺一角的 L 形，缺失角标示转弯方向）。条带中包含 3-5 个字形紧邻排列。
- 右上角（约 3x3 区域，左上角位于第 0 行、约第 12 列）：一个彩色瓦片 T，包含 2-3 种非黑(0)非红(2)颜色（如蓝(1)、绿(3)、黄(4)），无黑色像素。
- 左区域与右上角之间有至少 2 列背景间隔。
- 生成约束：字形数量 3-5 个。解码后的路径步数 = 字形数 + 1（含起始位置）。路径上每步移动 3 行或 3 列（一个瓦片边长），所有瓦片放置位置的 3x3 范围不超出网格的第 3 行以下、第 0 列到第 19 列的区域。

**规则**：
1. 读取右上角 3x3 瓦片 T。
2. 从左到右逐个解码字形条带中的字形：
   - 垂直字形（2 行 1 列的竖直段）：路径步进 = 下移 3 行、列不变。
   - 左弯字形（L 形，2x2 中右上角缺失）：路径步进 = 下移 3 行、左移 3 列。
   - 右弯字形（L 形，2x2 中左上角缺失）：路径步进 = 下移 3 行、右移 3 列。
3. 构造输出网格（20x20，全背景）。起始位置 P_0 = (第 3 行, 网格水平中央列 - 1)，将瓦片 T 的左上角放在 P_0 处。
4. 按解码顺序，依次将路径步进累加到当前位置，在每个新位置以左上角对齐放置瓦片 T。后放置的瓦片覆盖先放置的（后写入覆盖先写入）。
5. 输出中不包含字形条带和原始瓦片位置（左区域第 0-1 行和右上角的原始内容不出现在输出中，对应位置为背景）。

**关键洞察**：字形不是要复制的图案，而是路径指令——弯头缺失角的方向编码了水平位移的方向。相邻瓦片可能重叠（因为步进仅 3 个像素而瓦片也是 3x3），重叠区域的最终颜色取决于放置顺序，而放置顺序由字形的左到右阅读顺序决定。

## 新题 5：镜像涌现封闭口袋的洪泛填充

**组合逻辑**：[镜像] + [洪泛填充](创新：填充对象是镜像涌现的封闭区域，非输入中已有的) + [十字图案] + [对称轴定义]

**来源原语**：镜像(47c1f68c), 十字图案(47c1f68c), 对称轴定义(47c1f68c), 擦除(47c1f68c), 洪泛填充(a64e4611)

- 其余三个象限（除十字外）为纯背景。
- 生成约束：左上象限的蓝(1)图形经四向镜像并擦除十字后，在原十字交叉点附近产生至少一个完全被蓝(1)像素包围的 4-连通背景区域（不与网格边界连通）。不同示例中，左上象限的图形形状应不同（可以是弧形、钩形等不规则 4-连通图形）。

**规则**：
1. 将左上象限的蓝(1)图形水平翻转到右上象限（以第 k 列为轴：象限内第 j 列映射到第 2k-j 列，行号不变）。
2. 将左上象限的蓝(1)图形垂直翻转到左下象限（以第 k 行为轴：象限内第 i 行映射到第 2k-i 行，列号不变）。
3. 将左上象限的蓝(1)图形 180 度旋转到右下象限（行列同时翻转）。

5. 在结果网格中，识别所有不与网格边界 4-连通相连的背景（黑(0)）连通分量。
6. 将这些封闭背景区域洪泛填充为绿(3)。
7. 所有蓝(1)像素保持不变。

**关键洞察**：单个象限的图形位于角落，其周围的背景始终与网格边界连通，不会形成封闭区域。只有四份镜像副本在中心交汇后，才可能围出封闭口袋——封闭性是镜像操作的涌现效应，求解者必须先在脑中完成镜像，再判断哪些背景区域被围住。

## 新题 6：碎片拼合与对称性联合约束修复

**组合逻辑**：[平移拼合] + [对称补全](创新：拼合后的全局对称性回溯修复碎片中的遮挡像素) + [边缘匹配] + [通配色]

**来源原语**：平移拼合(446ef5d2), 边缘匹配(446ef5d2), 通配色(446ef5d2), 角标记(446ef5d2), 对称补全(f9d67f8b), 反射旋转定颜色(f9d67f8b), 遮挡像素(f9d67f8b), 对称轨道(f9d67f8b)

**依赖链**：碎片通过边缘匹配拼合为矩形（通配色降低匹配约束），但拼合存在歧义——多种排列的边缘匹配都通过。拼合后的矩形具有全局反射对称性，只有正确排列时非遮挡像素才满足对称；利用此对称性修复遮挡像素。拼合需要对称约束消歧，对称修复需要正确拼合才能获得全局对称轴——两步互为前提，形成约束满足结构而非线性流水线。

将带损坏像素的碎片拼合成矩形，利用拼合后的全局对称性同时解决排列歧义和损坏修复。

**输入结构**：
- 约 15x15 的网格，背景为黑(0)。
- 网格上散布着 4 块矩形碎片，每块约 3x4 至 4x5 像素，碎片之间 4-连通不相邻。
- 碎片像素由蓝(1)（通配色，出现频率最高）和其他 1-2 种颜色（如红(2)、绿(3)）组成。
- 其中 1-2 块碎片上有若干栗(9)像素，这些像素替代了原本应有的某种非蓝颜色（遮挡色）。
- 网格某个角落有一个品红(6)的 L 形角标记（3 像素，占 2x2 区域中的 3 格），缺角指示拼合矩形应放置的角位置。
- 生成约束：4 块碎片恰好可以无重叠、无间隙、不旋转地拼合为一个矩形。拼合后的矩形关于其中心具有水平和垂直反射对称性（忽略栗(9)像素后）。通配色蓝(1)出现在所有碎片的边缘位置。每个栗(9)像素在拼合后的矩形中，其水平反射、垂直反射或 180 度旋转对应位置至少有一个是非栗色的可见像素。

**规则**：
1. 识别通配色：统计所有碎片像素，出现次数最多的颜色即为通配色 C_w（蓝(1)）。
2. 将 4 块碎片平移（不旋转）拼合到 L 形角标记指示的角位置，拼成无间隙矩形。相邻边必须匹配：C_w 与任何颜色匹配（通配）；非 C_w 像素必须与对面的非 C_w 像素颜色相同。若存在多种合法排列，选择使所有非栗(9)、非 C_w 像素满足水平和垂直反射对称的那一种（唯一）。
3. 在拼合后的矩形中，推断水平和垂直反射轴（位于矩形中心）。
4. 对每个栗(9)像素，依次检查其水平反射、垂直反射、180 度旋转对应位置：取第一个非栗色的可见像素颜色，替换该栗色像素。
5. 输出仅包含修复后的矩形（放置在角标记指示的角位置），其余区域为背景。角标记本身不出现在输出中。

**关键洞察**：通配色使边缘匹配存在多种合法排列，但只有一种排列使非遮挡像素满足全局反射对称——对称约束同时解决了拼合歧义和损坏修复，两个问题是同一个约束方程的两个未知数。

## 新题 7：排名涂色的楔形扩展与逐行障碍截断

**组合逻辑**：[排序] + [逐行扩展楔形](创新：多条独立楔形、各有不同排名颜色) + [遇障碍截断](创新：逐行独立截断而非整体截断)

**来源原语**：排序(ea32f347), 长度排名(ea32f347), 排名决定颜色(ea32f347), 细条(ea32f347), 逐行扩展楔形(bae5c565), 以缺口为中心(bae5c565), 遇障碍截断(212895b5), 障碍像素(212895b5)

**依赖链**：排序为三条灰色条带分配颜色（排名映射），每条条带的缺口定义楔形中心，楔形逐行向下扩展。障碍像素在每行独立截断楔形的一侧或两侧。删去排序则颜色分配未知，删去楔形扩展则无空间形态，删去障碍截断则楔形无限扩展。三者之间的耦合使每条楔形的最终形状取决于自身颜色排名、缺口位置和障碍分布的共同作用。

三条灰色条带按长度排名涂色后，各自从中心缺口向下做楔形扩展，遇障碍逐行截断。

**输入结构**：
- 约 15x20 的网格（15 列、20 行），背景为黑(0)。
- 上部区域（第 0-2 行内各一行）有三条水平灰(5)条带，每条宽 1 像素、长度各不相同（如 3、5、7 像素，不含缺口）。每条条带中恰好有 1 个像素位置是背景色（缺口），缺口不在条带端点。三条条带分布在不同行。
- 第 4 行以下散布着若干橙(7)障碍像素（不形成连续线段，每个独立散布）。
- 生成约束：三条条带长度（含缺口位置在内的总占据列数）两两不同。各条带的楔形扩展在列方向上互不重叠（即任意两条条带的列范围不重叠）。每条楔形在到达网格底边前至少受到一个障碍像素的截断影响。

**规则**：
1. 测量三条灰色条带的长度（条带占据的连续列数，含缺口位置），按长度从长到短排名。
2. 颜色分配：最长 -> 蓝(1)，中等 -> 黄(4)，最短 -> 红(2)。
3. 将每条条带的灰(5)像素重涂为其排名颜色，缺口保持背景。
4. 对每条条带，以其缺口列为中心，从条带下一行开始向下逐行执行楔形扩展：
   a. 第 1 行（条带下方第 1 行）：仅缺口列填排名颜色。
   b. 第 n 行（条带下方第 n 行）：缺口列左右各 n-1 列范围内填排名颜色（共 2n-1 列），但不超出原条带的左端列和右端列的范围。
5. 在每一行的楔形像素写入前，逐个检查：若目标位置是橙(7)障碍像素，则该像素不写入，且该像素与楔形中心同侧的所有更远像素也不写入（单侧截断）。另一侧不受影响。下一行的楔形仍从完整宽度尝试，独立受障碍截断。
6. 若某一行楔形在左右两侧均被完全截断（该行无任何像素可写入），该条带的楔形扩展在此行终止。
7. 橙(7)障碍像素保持不变。

**关键洞察**：障碍像素逐行独立截断楔形的左右两侧——同一个楔形在不同行可能有不同的有效宽度，形成不规则的锯齿边缘。求解者不能把障碍视为全局阻断，必须逐行分别计算截断效果。

## 新题 8：标记方向旋转的循环母题填充

**组合逻辑**：[循环填充](创新：填充方向由外部标记决定) + [边界标记](创新：标记位置决定母题旋转角度) + [标记指定观察方向] + [标记界定母题]

**来源原语**：循环填充(12422b43), 标记界定母题(12422b43), 母题行(12422b43), 边界标记(f341894c), 标记指定观察方向(f341894c), 填充(6cf79266)

**依赖链**：灰色标记列界定母题内容，边界标记决定每个空白区域的填充方向。填充方向不同导致母题在每个区域中以不同旋转角度铺展。删去母题提取则无填充内容，删去方向判断则不知旋转角度，删去循环填充则无铺展机制。三者交织为：母题提供内容，标记提供旋转指令，循环填充提供铺展方式。

提取标记界定的母题，根据每个空白区域边缘标记的方向旋转母题后循环填充。

**输入结构**：
- 约 15x15 的网格，背景为黑(0)。
- 网格最左列（第 0 列）的前 N 行（N 约 2-4）为灰(5)标记像素，界定母题高度。第 1 至 M 列的前 N 行构成母题区域（M 约 3-5），包含蓝(1)、红(2)、绿(3)等前景色。母题是 N 行 x M 列的矩形图案。
- 网格中有 3-4 个由黄(4)色像素围成的封闭矩形边框（边框宽 1 像素），边框内部全为背景色。各边框尺寸各不相同，互不重叠，不与母题区域重叠。
- 每个封闭边框的外侧恰好有 1 个品红(6)色标记像素，紧贴边框某一条边的中点外侧一格（即该边中间位置向外偏移 1 格）。
- 生成约束：不同边框的品红标记分别位于不同方向（如一个在上方、一个在右方、一个在下方、一个在左方；若只有 3 个边框则 3 个方向各一个）。母题的行数和列数不等（确保旋转后形状变化可观察）。

**规则**：
1. 提取母题：清除灰(5)标记列（第 0 列前 N 行）为背景，读取第 1 至 M 列的前 N 行作为母题 M_pat（N 行 x M 列）。
2. 对每个黄色封闭边框：
   a. 确定品红(6)标记的位置——在边框的上方、下方、左方还是右方。
   b. 根据标记方向旋转母题：
      - 标记在上方（标记指向下方进入边框）：母题不旋转（0 度），保持 N 行 x M 列。
      - 标记在右方（标记指向左方进入边框）：母题顺时针旋转 90 度，变为 M 行 x N 列。
      - 标记在下方（标记指向上方进入边框）：母题旋转 180 度，保持 N 行 x M 列。
      - 标记在左方（标记指向右方进入边框）：母题顺时针旋转 270 度，变为 M 行 x N 列。
   c. 用旋转后的母题从边框内部左上角开始循环填充：先铺满第一个母题宽度的列，再右移一个母题宽度继续铺，列方向用尽后换行继续。超出边框内部区域的部分截断不写入。母题行用尽后从第一行重新循环。
3. 黄(4)边框保持不变。品红(6)标记保持不变。母题区域（第 0 列标记 + 母题内容行）清除为背景。

**关键洞察**：所有边框中的图案来源于同一个母题，但因标记方向不同而呈现为不同旋转角度的变体——求解者需要识别出它们是同一母题的旋转版本，并从标记位置推断旋转角度。仅看单个边框无法确定旋转规则（不知道 0 度是什么样），必须对比多个边框才能归纳出标记方向与旋转角度的对应关系。

## 新题 9：重力下落与平台计数决定形态变换

**组合逻辑**：[重力下落] + [形状变换](创新：变换次数由路径上的事件计数决定) + [形状循环映射] + [计数]

**来源原语**：重力下落(c87289bb), 形状变换(a47bf94d), 形状循环映射(a47bf94d), 计数(df8cc377), 障碍线段(c87289bb)

**依赖链**：重力决定像素的下落路径，路径上经过的平台缺口数决定形态变换次数，变换次数通过形状循环映射选定最终形态，最终形态在着陆位置展开。删去重力则不知落点，删去计数则不知变换几次，删去形状映射则不知变什么形态。三步形成：运动机制 -> 事件计数 -> 形态选择 的链式耦合。

彩色像素在重力下落过程中，每穿过一个平台缺口就经历一次形态变换，着陆时展开最终形态。

**输入结构**：
- 约 12x15 的网格（12 列、15 行），背景为黑(0)。
- 第 0 行有 2-4 个彩色前景单像素（颜色各不相同，如蓝(1)、红(2)、绿(3)、黄(4)），分布在不同列，是下落种子。
- 第 0 行以下有 1-3 条水平平台线，每条由灰(5)像素组成，跨越大部分网格宽度但含有若干单列缺口（缺口处为背景色）。不同平台线在不同行（行间距至少 4 行）。
- 生成约束：每个种子所在列在每条平台线上要么有灰(5)像素（阻挡）要么是缺口（通过），至少有一个种子的列上某条平台有缺口（确保有穿越发生）。穿越次数最多为 3 次。每个种子着陆后展开的 3x3 形态不超出网格边界，且不同种子的着陆形态互不重叠。

**规则**：
1. 每个种子像素从第 0 行所在列开始垂直下落（重力方向为向下）。
2. 下落过程中，若当前列在某条平台线上是灰(5)像素，则种子停在平台上方一行（着陆）。若当前列在平台线上是缺口（背景），则种子穿越该平台继续下落，穿越计数 +1。
3. 若种子穿越了所有平台（或无平台阻挡），则停在网格最后一行（着陆）。
4. 着陆时，根据穿越计数 P 决定形态：
   - P = 0（未穿越任何平台）：保持单像素，不变换。
   - P = 1（穿越 1 次）：展开为 3x3 实心方块，以着陆位置为中心。
   - P = 2（穿越 2 次）：展开为 X 形（中心 + 4 个对角方向各 1 像素，共 5 像素），以着陆位置为中心。
   - P = 3（穿越 3 次）：展开为菱形（中心 + 4 个基本方向各 1 像素，共 5 像素），以着陆位置为中心。
5. 所有展开形态使用该种子的原始颜色。超出网格边界的像素不绘制。
6. 原始种子像素位置（第 0 行）清除为背景。平台线保持灰(5)不变。
7. 若多个种子着陆位置的展开形态有重叠，按种子在第 0 行的列号从左到右依次处理，后处理的覆盖先处理的。

**关键洞察**：同一条平台对不同列的种子可能是阻挡（该列有灰色像素）或通过（该列是缺口），因此同一条平台同时决定了部分种子的着陆位置和另一部分种子的变换次数——平台既是"地面"又是"变换器"，具体角色取决于种子所在列是否恰好对准缺口。
