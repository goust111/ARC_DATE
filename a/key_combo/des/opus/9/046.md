## 新题 1：同心环深度奇偶决定标记射线方向

**组合逻辑**：[同心方框层 + 深度排序](已有) → [深度奇偶作为分支条件](创新) → [射线延伸 + 碰撞停止](已有，方向由深度决定)

**来源原语**：同心方框层(concentric_layer)、深度排序(depth_order) 来自 85c4e7cd；射线延伸(ray_cast)、碰撞停止(collision_stop)、端点发射(emit_from_endpoints) 来自 80a900e0；标记像素(marker_pixel) 来自 6cdd2623 / dc1df850

**依赖链**：必须先分解同心环结构以确定每层深度 → 深度奇偶值决定标记射出水平还是垂直射线 → 射线遇到非背景像素或网格边界停止。删除深度分析则无法确定射线方向；删除射线延伸则深度信息无处使用。

一句话总结：在同心矩形环上嵌入的标记像素根据所在环层深度的奇偶性射出水平或垂直射线，射线遇到非背景色停止。

**输入结构**：约 13x13 网格，黑(0)背景。3-4 层同心矩形环，各层颜色不同且取自蓝(1)、绿(3)、灰(5)、青(8)中的不重复颜色，最外层为深度 1。2-4 个红(2)标记像素分布在不同层的环像素上（标记替换该位置的环颜色）。各标记所在层的深度不全相同。生成约束：每个标记像素必须恰好落在某层环的像素位置上，不在环与环之间的间隙中；同一层上最多放置一个标记。

**规则**：
1. 识别所有同心矩形环，按从外到内的顺序编号为深度 1, 2, 3, ...（最外圈距网格边缘最近的一圈为深度 1）。
2. 对每个红(2)标记像素，确定它所在环的深度 D。
3. 若 D 为奇数，从该标记位置向左和向右发射水平射线，逐像素涂为黄(4)，直到碰到非黑(0)像素或到达网格边界时停止（不覆盖终止像素）。
4. 若 D 为偶数，从该标记位置向上和向下发射垂直射线，逐像素涂为黄(4)，直到碰到非黑(0)像素或到达网格边界时停止（不覆盖终止像素）。
5. 标记像素本身涂为黄(4)。
6. 所有原始环像素保持不变（射线不覆盖环像素）。
7. 若两条射线在某个黑(0)格相交，该格仍为黄(4)。

**关键洞察**：射线方向既不由标记在环上的物理位置（角/边中间）决定，也不由标记颜色决定，而是由标记所处环层的深度奇偶性决定——必须先完成同心环的结构分解才能确定每条射线的方向。

## 新题 2：精灵体对称类型同时决定目标槽位与反射轴

**组合逻辑**：[对称类型分类](已有) → [对称类型决定槽位](创新，替代标记选槽) + [跨轴反射](已有，轴由分类结果确定) → [印章覆盖](已有)

**来源原语**：对称类型决定颜色(symmetry_det_color)、单像素为噪声(singleton_noise) 来自 a09f6c25；印章覆盖(stamp)、槽位(slot)、分区(partition)、标记选槽接收精灵(marker_selects_slot_for_sprite) 来自 363442ee；镜像(mirror)、跨轴反射(reflection_across_axis) 来自 88207623

**依赖链**：对称类型分类 → 同时决定 (a) 精灵体被路由到哪个槽位、(b) 精灵体沿哪个轴进行反射。分类结果承载双重功能：路由键与变换指令。删除分类步骤，则既不知道目标槽位也不知道反射轴；删除反射或印章，则分类无下游用途。

一句话总结：将左侧面板中的精灵体按其反射对称类型路由到右侧对应槽位，并在放入前沿自身对称轴做一次反射。

**输入结构**：约 15x18 网格，黑(0)背景。一条灰(5)竖直分隔列将网格分为左右两个面板。左面板包含 3 个单色 4-连通精灵体（各 3-8 像素），颜色互不相同，分别取自红(2)、蓝(1)、绿(3)。右面板被两条灰(5)水平分隔行等分为三个高度相同的槽位（从上到下依次为槽 A、槽 B、槽 C），每个槽位初始为全黑(0)。生成约束：三个精灵体恰好具有三种不同的反射对称类型——水平轴对称、垂直轴对称、对角轴对称各一个；每个精灵体的边界框完全位于槽位的可容纳区域内。

**规则**：
1. 对左面板的每个精灵体，判定其唯一的反射对称类型：水平轴对称、垂直轴对称或对角轴对称。
2. 水平轴对称的精灵体 → 路由至槽 A（最上方）；垂直轴对称 → 槽 B（中间）；对角轴对称 → 槽 C（最下方）。
3. 将每个精灵体沿其自身的对称轴进行反射，得到反射后的图形。
4. 将反射后的精灵体印章到目标槽位中，水平和垂直均居中对齐于槽位区域。保留精灵体的原始颜色。
5. 保留灰(5)分隔列和分隔行。左面板的原始精灵体保持不变。

**关键洞察**：对称类型承担双重角色——它既是路由键（决定去哪个槽），又是变换指令（决定沿哪条轴反射）。求解者无法将分类与反射解耦为两个独立步骤，因为同一个分析结果同时驱动两个不同的下游效果。

## 新题 3：半区异或生成中间标记场，标记的边界状态决定扩展行为

**组合逻辑**：[异或合成](已有) → [中间标记场生成](创新) → [边界标记 → 连线 | 内部标记 → 光环扩展](创新分支，来自已有操作)

**来源原语**：异或合成(xor_compositing)、半区掩码(half_mask)、恰一为前景(exactly_one_foreground) 来自 31d5ba1a；连线(draw_line)、边界定位(boundary_pos)、边界标记定贯穿线(boundary_marker_span) 来自 6cdd2623；邻域扩展(neighborhood_expand)、光环区域(halo_region)、仅填背景格(only_fill_background) 来自 dc1df850

**依赖链**：异或合成是中间计算，产出标记场 → 每个标记的网格边界位置决定它的行为分支（贯穿线 vs. 光环扩展）。异或不是最终输出而是生成下一步操作的输入数据；没有异或就没有标记来源，没有边界/内部分支就不知道如何处理标记。

一句话总结：将上下两半区前景掩码做异或得到中间标记；位于输出网格边界上的标记投射贯穿线，其余标记展开光环。

**输入结构**：偶数行高的网格（例如 10x10 或 12x10），黑(0)背景。上半区包含一组蓝(1)前景像素组成的图案，下半区包含一组绿(3)前景像素组成的图案。两半区高度相同、宽度相同。两个图案各为若干不规则的 4-连通色块，有部分位置重叠、部分不重叠。生成约束：异或结果（恰一为前景的位置）中，至少有 1 个位于半区尺寸网格的边界上，至少有 2 个位于内部；异或结果的像素总数不超过 8 个。

**规则**：
1. 将上半区和下半区按位置对齐，计算对称差（异或）：位置 (r,c) 为"异或阳性"当且仅当上半区 (r,c) 和下半区 (r,c) 中恰好有一个为前景色。
2. 构建与半区同尺寸（宽同输入、高为输入高度的一半）的全黑(0)输出网格。在每个异或阳性位置放置一个红(2)标记像素。
3. 对每个处于输出网格边界上的红(2)标记（第 0 行、最后一行、第 0 列、最后一列）：若位于上/下边界，绘制一条贯穿该列全高的垂直线，颜色黄(4)；若位于左/右边界，绘制一条贯穿该行全宽的水平线，颜色黄(4)。若标记同时在角落（属于两条边界），则同时绘制水平和垂直两条线。
4. 对每个不在输出网格边界上的红(2)标记：将其 Chebyshev 距离为 1 的邻域（3x3 区域）内所有黑(0)格涂为橙(7)，不覆盖已有的红(2)标记或黄(4)线像素。
5. 所有红(2)标记像素保留。黄(4)线先于橙(7)光环绘制；光环不覆盖线。

**关键洞察**：异或不是答案而是中间产物——它生成一个标记场，每个标记的处理方式取决于它在输出网格中的空间位置类型（边界 vs. 内部），形成一个由位置驱动的行为分支。

## 新题 4：对角互补位置继承父图形的对角方向作为光环颜色

**组合逻辑**：[对角互补定位](已有) → [对角方向分析](创新，从对象类提升为条件类) → [邻域扩展 + 方向决定光环颜色](已有操作 + 创新条件)

**来源原语**：对角互补(diagonal_complement)、正方形块(square_block)、对角空位补块(complement_at_diagonal_vacancies) 来自 22233c11；邻域扩展(neighborhood_expand)、光环区域(halo_region)、仅填背景格(only_fill_background) 来自 dc1df850；对称类型决定颜色(symmetry_det_color) 来自 a09f6c25（概念迁移：对称类型→对角方向）

**依赖链**：分析前景对象的填充对角方向 → 决定互补块的放置位置 → 决定互补块及其光环的颜色。三步信息依次传递：对角方向同时编码了"在哪里补"和"用什么颜色补"，删除任一步都导致无法确定完整输出。

一句话总结：在每个对角填充图形的互补对角方向外侧放置补块，并以 1 像素光环扩展补块区域；光环颜色由原始图形的填充对角方向决定。

**输入结构**：约 14x14 网格，黑(0)背景。3-4 个绿(3) 4-连通前景对象，每个对象的边界框为偶数边长的正方形（如 4x4 或 6x6），可被等分为 2x2 的四个子方块。每个对象恰好有两个对角相对的子方块被绿(3)填满，另外两个子方块为黑(0)。同一网格中既有 NW+SE 填充模式的对象，也有 NE+SW 填充模式的对象。生成约束：各对象的边界框之间至少间隔 3 像素（确保互补块和光环不与其他对象重叠）。

**规则**：
1. 对每个绿(3)前景对象，识别其正方形边界框并划分为 2x2 子方块。
2. 确定填充模式：NW+SE 对角填充，或 NE+SW 对角填充。
3. 在边界框外侧的互补对角位置放置同尺寸的补块——NW+SE 填充的对象在 NE 外角和 SW 外角各放一个补块，NE+SW 填充的对象在 NW 外角和 SE 外角各放一个补块。
4. 颜色规则：NW+SE 填充模式 → 补块及光环涂蓝(1)；NE+SW 填充模式 → 补块及光环涂红(2)。
5. 对每个补块，将其边界向外扩展 1 像素（Chebyshev 距离 1 的光环）。光环仅填充黑(0)背景格，不覆盖绿(3)原始像素、已有补块像素或其他光环像素。
6. 光环超出网格边界的部分裁剪。
7. 保留所有原始绿(3)像素不变。

**关键洞察**：填充对角的方向不仅决定了补块在空间中的放置位置，还同时编码了整个互补区域（补块 + 光环）的颜色——对角方向是一个同时承载几何信息和色彩信息的隐式编码。

## 新题 5：颜色指引条定义矩形角-边-内部的涂色方案

**组合逻辑**：[色彩指引块读取](已有) → [局部位置分类](已有) → [查表替换：指引色映射分类角色](创新组合)

**来源原语**：局部位置分类(local_position_classification)、角边内部分别涂色(corner_border_interior_recolored)、矩形(rectangle) 来自 b6afb2da；色彩指引块(color_guide)、位置对应(pos_correspond)、指引色映射象限(guide_maps_quadrant) 来自 7c008303；查表替换(lookup_replace)、颜色映射符号(color_maps_symbol) 来自 d4469b4b

**依赖链**：指引条提供三种颜色的角色映射表（哪个颜色对应角、哪个对应边、哪个对应内部） → 矩形像素的局部位置分类确定每个像素的角色 → 查表替换将分类结果映射为指引条中的对应颜色。指引条和分类缺一不可：无指引条则不知道用什么颜色涂；无分类则不知道哪些像素是角/边/内部。

一句话总结：读取一个 3x1 颜色指引条获取角/边/内部三种角色的颜色分配方案，然后用该方案重涂网格中每个灰色矩形的角、边缘和内部像素。

**输入结构**：约 12x14 网格，黑(0)背景。网格左上角有一个 3x1（水平排列的三像素）颜色指引条，三个像素颜色各不相同，取自蓝(1)、红(2)、绿(3)、黄(4)、品红(6)、橙(7)、青(8)中的三种。网格其余区域分布着 2-3 个灰(5)实心矩形，每个矩形的宽和高均不小于 3（确保角、边、内部三种像素类型都存在）。矩形之间互不接触。生成约束：指引条与任何矩形之间至少间隔 1 像素。

**规则**：
1. 读取 3x1 颜色指引条：第 1 格（最左）= 角色颜色 C_corner，第 2 格（中间）= 边色颜色 C_edge，第 3 格（最右）= 内部颜色 C_interior。
2. 对每个灰(5)矩形，将其每个像素按局部位置分类：四个角点为"角"，除角点外位于矩形边缘的像素为"边"，完全被矩形内部包围的像素为"内部"。
3. 将角像素涂为 C_corner，边像素涂为 C_edge，内部像素涂为 C_interior。
4. 将指引条的三个像素替换为黑(0)背景（指引条在输出中消失）。
5. 其余黑(0)背景不变。

**关键洞察**：角/边/内部的涂色方案不是固定的（不同示例中指引条颜色不同），求解者必须从指引条的位置顺序推断出角色映射表——指引条的三个格位置（左/中/右）编码了分类角色（角/边/内部）。

## 新题 6：面积排序配对精灵体与框架实现分级缩放填充

**组合逻辑**：[排序 · 面积排序](已有) × 2（精灵体和框架各排一次）→ [平行配对](创新) → [像素放大 + 框内填充](已有)

**来源原语**：排序(sort)、面积排序(area_ordering)、拼接(concatenate)、基线对齐排列(baseline_aligned_pack) 来自 4df5b0ae；像素放大(pixel_upscale)、空心矩形(hollow_rect)、包含于框架内(in_frame)、框内尺寸决定缩放(frame_size_sets_scale) 来自 6b9890af；裁剪(crop) 来自 6b9890af

**依赖链**：精灵体和框架各自按面积排序 → 按秩次配对（最小配最小，次小配次小...） → 每对的缩放因子由框架内部尺寸与精灵体边界框尺寸之比决定 → 缩放后印章填入框架。排序步骤决定配对，配对决定缩放因子，缩放因子决定输出内容——三步紧耦合。

一句话总结：将散布在网格上的多个小精灵体按面积从小到大与同样按内部面积排序的空心框架一一配对，每个精灵体按整数倍缩放后填入配对框架的内部。

**输入结构**：约 20x20 网格，黑(0)背景。包含 K 个（K=2 或 3）不同颜色的空心矩形框架（每个框架由一种非黑颜色的单像素宽边框构成，如红(2)边框、蓝(1)边框、绿(3)边框），框架内部为黑(0)。每个框架的内部尺寸为 NxN 的正方形（N 在各框架间不同，如 3x3、6x6、9x9）。另有 K 个单色 4-连通精灵体（每个精灵体颜色与框架颜色均不同，如黄(4)、橙(7)、灰(5)），散布在框架之外的区域。每个精灵体的边界框为 MxM 正方形（M 在各精灵体间不同）。生成约束：排序后第 i 小的框架内部边长恰好是第 i 小精灵体边界框边长的整数倍；不同框架和精灵体之间互不接触。

**规则**：
1. 识别所有空心矩形框架（单像素宽的非黑色闭合矩形环），提取每个框架的内部面积。
2. 识别所有独立精灵体（不构成框架的 4-连通前景色块），提取每个精灵体的边界框面积。
3. 将框架按内部面积从小到大排序；将精灵体按边界框面积从小到大排序。
4. 按排序秩次一一配对：秩次最小的精灵体配秩次最小的框架，依次类推。
5. 对每对 (精灵体, 框架)，计算整数缩放因子 S = 框架内部边长 / 精灵体边界框边长。
6. 将精灵体的边界框区域按 S 倍均匀放大（每个像素变为 SxS 的同色方块），保持精灵体原始颜色。
7. 将放大后的图案填入配对框架的内部区域。框架边框保持原色不变。
8. 原始精灵体在其原位置被擦除（替换为黑(0)背景）。

**关键洞察**：精灵体和框架之间没有颜色对应关系，也没有空间邻近关系——唯一的配对线索是面积秩次的平行对应。求解者必须独立地对两组对象排序并推断秩次配对规则。

## 新题 7：奇偶棋盘过滤的克罗内克自展开与色彩翻转

**组合逻辑**：[二值掩码提取 + 克罗内克自积](已有) → [棋盘格奇偶过滤](创新条件) + [重涂色：奇偶决定颜色互换](创新)

**来源原语**：像素放大(pixel_scaling)、印章覆盖(stamp_overlay)、控制像素(control_pixel)、格位映射(cell_block_mapping)、递归印章(recursive_stamp) 来自 cce03e0d；二值掩码(binary_mask)、自相似嵌套(self_similar_nest)、掩码克罗内克自积(kronecker_self) 来自 80af3007；棋盘格图案(checkerboard_pattern) 来自 80a900e0；重涂色(recolor) 来自 a09f6c25 / 85c4e7cd

**依赖链**：掩码提取 → 克罗内克展开确定哪些宏块应有内容 → 棋盘奇偶过滤进一步筛选可活跃的宏块 → 偶位宏块保持原色、奇位宏块颜色互换。四步之间每一步的输出决定下一步的行为：掩码给出结构，克罗内克给出分形，棋盘给出筛选，奇偶给出色变——任意一步被删除都得到不同（错误的）输出。

一句话总结：将一个双色小精灵体做克罗内克自积展开，但只在宏块坐标和为偶数的位置放置原色副本、坐标和为奇数的位置放置双色互换副本，其余宏块留空。

**输入结构**：小网格（4x4 至 5x5），黑(0)背景。包含一个边界框恰好为 NxN（N=3 或 4）的精灵体，使用两种非背景色：红(2)和蓝(1)。精灵体边界框内至少有 3 个像素为红(2)、至少有 2 个像素为蓝(1)，其余为黑(0)。生成约束：精灵体边界框的位置位于输入网格的左上角对齐。

**规则**：
1. 提取精灵体的 NxN 边界框作为掩码 M，其中每个格为红(2)、蓝(1)或黑(0)。
2. 构建 (N*N) x (N*N) 的全黑(0)输出网格，划分为 NxN 个 NxN 大小的宏块。
3. 对宏块坐标 (i, j)（0-indexed），若 M[i][j] 不是黑(0)（即该格在掩码中是精灵体的一部分）：
   - 若 (i + j) 为偶数：将该宏块填入 M 的原色副本（红保持红，蓝保持蓝）。
   - 若 (i + j) 为奇数：将该宏块填入 M 的颜色互换副本（红(2) ↔ 蓝(1)互换，黑(0)仍为黑(0)）。
4. 若 M[i][j] 是黑(0)，则该宏块保持全黑(0)，无论 (i+j) 的奇偶性。

**关键洞察**：输出既不是纯克罗内克自积，也不是纯棋盘——而是两者的交集再叠加颜色翻转规则。求解者需要同时发现三层结构：哪些宏块被激活（由掩码决定）、激活的宏块中哪些保持原色/哪些互换（由坐标奇偶决定）、以及宏块内部的内容（掩码自身）。

## 新题 8：擦除单像素噪声后镜像补全空白半区

**组合逻辑**：[擦除 · 单像素为噪声](已有) → [清洗后的下半区](中间产物) → [镜像 · 对称补全 · 空白半区补全](已有，但输入经过清洗)

**来源原语**：擦除(erase)、单像素为噪声(singleton_noise) 来自 a09f6c25；镜像(mirror)、对称补全(symmetry_complete)、半区(half_panel)、翻转对称(flip_symmetry)、空白半区补全(fill_blank_half) 来自 f25ffba3

**依赖链**：擦除步骤移除单像素噪声 → 清洗后的下半区成为镜像的数据源 → 上半区由清洗结果的行序翻转填充。如果不擦除噪声，镜像会将噪声像素也复制到上半区，产生错误输出；如果不镜像，擦除本身无法填充空白半区。两步之间存在真实的数据依赖：擦除改变了镜像的输入内容。

一句话总结：先识别并移除下半区中的单像素噪声，再将清洗后的下半区翻转填入空白的上半区。

**输入结构**：偶数行高的网格（如 12x10 或 14x10），黑(0)背景。上半区（前一半行）完全为黑(0)。下半区包含若干多像素 4-连通前景色块（颜色取自蓝(1)、绿(3)、黄(4)、橙(7)等，可有多种颜色），以及 2-4 个孤立的单像素前景点（颜色可与多像素色块相同或不同），散布在下半区各处。生成约束：所有多像素色块的边界框位于下半区内部（不紧贴半区分界线），确保镜像后不会溢出上半区；单像素噪声不与任何多像素色块 4-连通相邻。

**规则**：
1. 在下半区中识别所有 4-连通前景分量。
2. 将像素数为 1 的分量（单像素噪声）设为黑(0)（擦除）。
3. 将清洗后的下半区按行序翻转（最后一行变为第一行、倒数第二行变为第二行...），生成上半区内容。
4. 将翻转结果填入上半区。下半区保持清洗后的状态（噪声已移除）。

**关键洞察**：空白上半区不是下半区的直接镜像——而是去噪后下半区的镜像。单像素噪声是陷阱：直接镜像会产生对称但错误的输出，求解者必须先识别噪声规则（单像素 = 噪声）再执行镜像。

## 新题 9：边界标记的双重角色——划分网格并按最近距离着色分区

**组合逻辑**：[连线 · 边界标记定贯穿线](已有) → [网格分区](创新涌现) → [重涂色 · 最近标记决定分区颜色](创新)

**来源原语**：连线(draw_line)、标记像素(marker_pixel)、画布边界(canvas_boundary)、边界定位(boundary_pos)、边界标记定贯穿线(boundary_marker_span) 来自 6cdd2623；生成网格(generate_grid)、网格线(grid_line)、等距参数化(uniform_parameterized_spacing) 来自 695367ec；重涂色(recolor) 来自 b6afb2da / 85c4e7cd

**依赖链**：边界标记 → 贯穿线将网格划分为矩形分区 → 每个分区由最近的边界标记"管辖"并被涂上该标记的颜色。标记同时承担几何功能（生成分割线）和语义功能（提供分区颜色）——这种双重角色在任何一道源题中都不存在。

一句话总结：网格边界上的彩色标记投射贯穿线将画布分割为矩形区域，每个区域被涂上距其中心最近的那个边界标记的颜色。

**输入结构**：约 11x11 网格，黑(0)背景。网格的四条边界上散布着若干彩色标记像素（2-4 个），每个标记颜色不同，取自蓝(1)、红(2)、绿(3)、黄(4)中的不重复颜色。上/下边界上的标记占据某列，左/右边界上的标记占据某行。生成约束：标记不在四个角落位置；没有两个标记在同一行或同一列上（确保分割线不重叠）；至少有一个标记在上/下边界，至少有一个在左/右边界（确保产生行列交叉分割）。

**规则**：
1. 对每个边界标记，绘制贯穿线：上/下边界标记 → 该列全高的垂直灰(5)线；左/右边界标记 → 该行全宽的水平灰(5)线。
2. 贯穿线（包括交叉点）将网格划分为若干矩形分区。
3. 对每个分区，计算其几何中心（行中心、列中心各取整数部分向下取整），找到距该中心曼哈顿距离最小的边界标记。
4. 将该分区内所有黑(0)格涂为该最近标记的颜色。
5. 灰(5)贯穿线保持灰色，覆盖在分区颜色之上。
6. 边界标记像素保持其原始颜色。
7. 距离相等时，选择边界标记中行号较小的；行号也相同时选列号较小的。

**关键洞察**：边界标记既不只是"线的端点"（如 6cdd2623），也不只是"颜色源"——它们同时生成空间分割结构和提供分区语义。求解者必须理解同一组标记在两个完全不同的维度上发挥作用。

## 新题 10：反转同心环颜色序列后以最内三层颜色作为矩形分类涂色方案

**组合逻辑**：[层色序内外翻转](已有) → [反转后的层色成为查表输入](创新) → [局部位置分类 + 查表替换](已有操作，但查表来源是反转结果)

**来源原语**：同心方框层(concentric_layer)、深度排序(depth_order)、层色序内外翻转(reverse_layer_colors)、重涂色(recolor) 来自 85c4e7cd；局部位置分类(local_position_classification)、角边内部分别涂色(corner_border_interior_recolored)、矩形(rectangle) 来自 b6afb2da；查表替换(lookup_replace)、颜色映射符号(color_maps_symbol) 来自 d4469b4b

**依赖链**：同心环颜色序列被反转 → 反转后从外到内的前三层颜色成为分类涂色的查表参数（第 1 层色 = 角色颜色，第 2 层色 = 边色颜色，第 3 层色 = 内部颜色） → 灰色矩形按局部位置分类并查表涂色。反转步骤不是装饰性的——它改变了查表参数的取值，从而改变最终涂色结果。

一句话总结：先将左侧同心矩形环的颜色序列内外翻转，再以翻转后的外三层颜色作为右侧灰色矩形的角/边/内部涂色方案。

**输入结构**：约 15x20 网格，黑(0)背景。左侧区域包含一组恰好 3 层的同心矩形环（从外到内颜色各不同，取自蓝(1)、红(2)、绿(3)、黄(4)、品红(6)、橙(7)、青(8)中的三种），环之间无间隙（外环的下一层紧邻内环的外边）。右侧区域包含 1-2 个灰(5)实心矩形，宽高均不小于 3。左右区域之间至少间隔 2 列黑(0)。生成约束：同心环区域和矩形区域不重叠；同心环恰好 3 层。

**规则**：
1. 识别左侧同心矩形环，按从外到内的顺序记录颜色序列 [C1, C2, C3]（C1 为最外层，C3 为最内层）。
2. 反转颜色序列：最外层重涂为 C3，中间层保持 C2，最内层重涂为 C1。即反转后从外到内为 [C3, C2, C1]。
3. 读取反转后的颜色序列作为分类涂色方案：反转后的第 1 层（最外，原 C3）= 角色颜色，第 2 层（中间，原 C2）= 边色颜色，第 3 层（最内，原 C1）= 内部颜色。
4. 对右侧每个灰(5)矩形，将其像素按局部位置分类为角、边、内部。
5. 将角像素涂为角色颜色（原 C3），边像素涂为边色颜色（原 C2），内部像素涂为内部颜色（原 C1）。
6. 左侧同心环保持反转后的状态。黑(0)背景不变。

**关键洞察**：同心环的颜色反转不是一个独立的视觉变换——其结果被右侧矩形分类操作消费为查表参数。求解者必须先执行反转才能知道正确的涂色方案，而仅看矩形的输出颜色无法直接推断规则（因为不同示例中同心环颜色不同，导致矩形涂色方案也不同）。
