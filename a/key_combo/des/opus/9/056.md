## 新题 1：重力沉降后的对角链判色

**组合逻辑**：[滑动/gravity_settling](保留) → [对角链式连接判定](创新：从静态拓扑分类变为对重力后构型的拓扑分类) → [重涂色](创新：由拓扑分类结果决定目标颜色)

**来源原语**：滑动/sliding（参考题 1e0a9b12、3618c87e）、对角链式连接/diagonal_chain（参考题 ecb67b6d）、重涂色/recolor（参考题 ecb67b6d）、列内独立/column_independent（参考题 1e0a9b12）、仅对角接触变色/diagonal_touch_recolor（参考题 ecb67b6d）

**依赖链**：重力沉降改变像素的空间位置 → 新位置产生了原始输入中不存在的 8-连通但非 4-连通邻接关系 → 对角链判定必须作用于沉降后的构型 → 判定结果决定哪些像素被重涂色。删除重力步骤，沉降后构型不存在；删除对角链判定，无法区分应重涂色的像素组。

给定散落的彩色像素，先按列独立重力沉降至底部，再将沉降后仅通过对角接触相连的同色像素组重涂为灰(5)。

**输入结构**：黑(0)背景，约 12x12 网格。网格中散布着多种前景颜色的单像素（每种前景颜色出现 4~8 个像素），像素之间互不相邻（4-连通意义下）。前景颜色使用红(2)、绿(3)、蓝(1)中的 2~3 种。像素分布保证：在列独立重力沉降后，某些同色像素会在底部堆叠时形成仅通过对角接触（8-连通但非 4-连通）相连的组，而另一些同色像素会形成 4-连通相连的组或保持孤立。生成约束：沉降后至少存在一个由 3 个以上同色像素组成的对角链组，且至少存在一个 4-连通的同色组，以确保两类结果都出现。

**规则**：
1. 对每一列，读取该列中所有非黑(0)像素，从上到下记录其颜色序列。
2. 将该列清空为黑(0)，然后将记录的颜色序列从该列最底行开始向上依次填入，保持读取顺序。（即列内重力沉降，各列独立处理。）
3. 沉降完成后，对每种前景颜色分别执行：将该颜色的所有像素按 8-连通分组。
4. 对每个 8-连通组，检查其内部是否存在任意两个像素是 4-连通邻居。若该组中**没有任何** 4-连通邻居对（即组内所有相邻关系均为纯对角接触），则将该组所有像素重涂为灰(5)。
5. 4-连通组和孤立像素保持原色不变。

**关键洞察**：对角链的判定对象不是原始输入，而是重力沉降后的构型——同一列中不同颜色像素的堆叠顺序决定了它们在底部的相对位置，从而决定了哪些同色像素恰好形成纯对角接触链。求解者必须先在脑中模拟重力，再判断沉降结果的连通拓扑。

## 新题 2：指示方向延伸至视线遮挡处

**组合逻辑**：[方向指示解码](保留) → [视线遮挡判断](创新：从遍历寻路变为延伸终止条件) → [延伸/extend](创新：终点由视线中第一个遮挡物决定，而非画布边界)

**来源原语**：延伸/extend（参考题 b527c5c6）、指示像素/indicator_pixel（参考题 b527c5c6）、方向指示/direction_indication（参考题 b527c5c6）、视线遮挡判断/line_of_sight_blocked（参考题 3490cc26）、矩形/rectangle（参考题 b527c5c6）、同行同列对齐/row_or_column_aligned（参考题 3490cc26）

**依赖链**：指示像素确定每个矩形的延伸方向 → 延伸射线沿该方向前进 → 视线遮挡判断确定射线在哪里停止（碰到第一个其他矩形的边缘即停止） → 延伸带的长度由遮挡距离决定。删除方向指示，不知道往哪个方向延伸；删除视线遮挡，延伸全部到达画布边界，输出不同。

每个带指示像素的绿色矩形沿指示方向延伸，直到撞上另一个矩形或画布边界。

**输入结构**：黑(0)背景，约 15x15 网格。网格中有 3~5 个绿(3)实心矩形（宽 2~4 像素、高 2~4 像素），彼此不重叠且不相邻。每个矩形的某一条边（上、下、左或右）的中间位置有一个红(2)像素，替换了该位置原本的绿(3)像素，标示延伸方向。矩形的排布保证：部分矩形在某个方向上与另一个矩形共享行带或列带（即延伸射线会碰到另一个矩形），部分矩形在指示方向上无遮挡（射线直达画布边界）。生成约束：不同矩形的延伸射线不会在延伸过程中互相交叉（各矩形的延伸带互不重叠）。

**规则**：
1. 对每个绿(3)矩形，定位其红(2)指示像素。指示像素所在的边决定延伸方向：位于上边 → 向上延伸；位于下边 → 向下延伸；位于左边 → 向左延伸；位于右边 → 向右延伸。
2. 从矩形的指示边出发，沿延伸方向逐像素扫描。延伸带的宽度等于矩形在垂直于延伸方向上的尺寸（例如向上延伸时，带宽等于矩形的列跨度）。
3. 延伸带遇到以下情况之一时停止：(a) 到达画布边界；(b) 延伸带的任一像素的下一步将进入另一个绿(3)矩形的像素位置。停止时不覆盖该阻挡矩形。
4. 将延伸带填充为绿(3)。同时，从红(2)指示像素出发，沿延伸方向画一条红(2)线，长度与延伸带相同（即红线从指示像素延伸到延伸带的末端）。
5. 各矩形的延伸独立处理，处理顺序不影响结果（因为生成约束保证延伸带互不重叠）。

**关键洞察**：延伸的终止条件不再是固定的画布边界，而是动态的——取决于其他矩形是否恰好挡在延伸路径上。求解者需要同时运用方向解码和视线扫描两套逻辑，仅靠其中任何一套都无法确定正确的延伸长度。

## 新题 3：贪心遍历产生访问序，奇偶序号决定涂色

**组合逻辑**：[贪心遍历/greedy_traversal](保留) → [序列索引/sequential_index](创新：由遍历顺序生成，而非空间位置预设) → [奇偶交替涂色/alternating_parity_recolor](创新：交替判据从对角线位置变为访问序号)

**来源原语**：贪心遍历/greedy_traversal（参考题 3490cc26）、连线/path_painting（参考题 3490cc26）、最近未访问优先/nearest_unvisited_first（参考题 3490cc26）、视线可见/line_of_sight_visible（参考题 3490cc26）、序列索引/sequential_index（参考题 a5f85a15）、奇偶交替涂色/alternating_parity_recolor（参考题 a5f85a15）、重涂色/recolor（参考题 a5f85a15）

**依赖链**：各目标块的空间位置 → 贪心遍历算法按最近可见优先确定访问顺序 → 每个目标块获得一个访问序号 → 奇数序号的目标块涂为一种颜色，偶数序号的涂为另一种颜色 → 走廊路径的颜色也由其终点目标块的奇偶性决定。删除贪心遍历，序号无法确定；删除奇偶涂色，遍历只产生路径而不区分目标块。

从起始块出发按最近可见优先遍历目标块，奇数次访问的目标块涂绿、偶数次涂黄，走廊路径颜色也随之交替。

**输入结构**：黑(0)背景，约 16x16 网格。一个红(2) 2x2 实心块作为起始块；5~7 个蓝(1) 2x2 实心块作为目标块。各块之间间隔至少 2 个像素。目标块的排布保证：从起始块出发，在共享的双行带或双列带中，每步恰好有唯一的最近未访问可见目标块（无距离平局）。非背景像素会阻挡视线。生成约束：遍历链恰好能访问所有目标块（不存在提前终止的情况）。

**规则**：
1. 从红(2)起始块出发，检查所有未访问的蓝(1)目标块中，哪些与当前块在同一双行带或双列带上且之间无其他非背景像素遮挡（视线可见）。
2. 从可见目标块中选择曼哈顿距离最近的那个（保证唯一），将其标记为已访问，访问序号从 1 开始递增。
3. 在当前块与被访问目标块之间的背景间隙中绘制走廊路径。
4. 将当前位置移动到刚访问的目标块，重复步骤 1-3，直到当前位置无可见的未访问目标块为止。
5. 遍历完成后执行重涂色：访问序号为奇数（1, 3, 5, ...）的目标块从蓝(1)重涂为绿(3)；访问序号为偶数（2, 4, 6, ...）的目标块从蓝(1)重涂为黄(4)。
6. 走廊路径的颜色由其**终点**目标块的序号奇偶性决定：通向奇数序号目标块的走廊涂为橙(7)，通向偶数序号目标块的走廊涂为灰(5)。
7. 起始块保持红(2)不变。

**关键洞察**：目标块的最终颜色不由其空间位置或自身属性决定，而由遍历算法赋予的访问序号的奇偶性决定。求解者必须先在脑中完整模拟贪心遍历过程，确定每个目标块的访问次序，才能推断其输出颜色。同一组目标块若起始块位置不同，会产生不同的访问序号分配，从而得到不同的涂色结果。

## 新题 4：面积异常值筛选定位遮挡物后对称修复

**组合逻辑**：[筛选/filter + 异常值选择/outlier_selection](创新：从颜色多样性异常值变为面积异常值) → [擦除/erase](保留) → [对称补全/symmetry_completion](保留)

**来源原语**：筛选/filter（参考题 9a4bb226）、异常值选择/outlier_selection（参考题 9a4bb226）、擦除/erase（参考题 3345333e）、遮挡/occlusion（参考题 3345333e）、对称补全/symmetry_completion（参考题 3345333e）、镜像/mirror（参考题 3345333e）、填充矩形/filled_rectangle（参考题 3345333e）

**依赖链**：输入中多个实心矩形看起来都可能是遮挡物 → 需要通过面积比较找到面积异常值（与其他矩形面积显著不同的那个） → 将该异常矩形识别为遮挡物并擦除 → 暴露出被遮挡的对称对象碎片 → 用镜像对称补全还原完整对象。删除面积筛选，不知道擦除哪个矩形；删除对称补全，擦除后的碎片无法还原。

在多个实心矩形中找出面积异常者作为遮挡物擦除，然后镜像对称补全被遮挡的图案。

**输入结构**：黑(0)背景，约 14x14 网格。网格中有一个用蓝(1)像素构成的单色对象，该对象具有左右镜像对称性（完整时）。此外有 3~4 个不同颜色的实心填充矩形（颜色从红(2)、绿(3)、黄(4)、品红(6)中选取，各不相同）。其中恰好一个矩形与蓝色对象重叠，遮挡了对象的一部分（重叠区域显示矩形颜色而非蓝色）。其他矩形不与蓝色对象重叠，它们是独立的前景元素。面积约束：作为遮挡物的那个矩形的面积与其他矩形的面积相差明显——要么它的面积是唯一最大的（比其余所有矩形都大至少 50%），要么是唯一最小的（比其余所有矩形都小至少 50%）。其他矩形之间的面积差异较小（互相在 30% 以内）。不同示例中异常值的方向（偏大或偏小）可能不同，需对比多个示例归纳"异常值"含义。

**规则**：
1. 识别输入中所有实心填充矩形（每个矩形是一种非黑、非蓝的纯色 4-连通区域，且边界框内全部填满该色或被蓝色对象遮挡处除外——但因为我们是在原图上识别矩形颜色的连通区域，遮挡物矩形本身是完整可见的，因为它画在蓝色对象之上）。
2. 计算每个矩形的面积（像素数）。找到面积异常值：该矩形的面积与所有矩形面积的中位数之差的绝对值在所有矩形中最大，且明显偏离（生成时保证唯一）。
3. 将异常值矩形的所有像素擦除为黑(0)。
4. 此时被遮挡的蓝(1)对象露出不完整的部分。检测蓝色像素集合的竖直对称轴（通过现有蓝色像素的边界框中线确定）。
5. 将每个蓝(1)像素关于对称轴镜像到对侧——若对侧位置为黑(0)，则填入蓝(1)；若对侧已有蓝(1)，保持不变。
6. 非异常值的矩形保持原样不动。

**关键洞察**：难点在于遮挡物的识别——所有矩形在视觉上同为实心色块，没有标记指示哪个是遮挡物。面积异常值是唯一的线索，且异常方向（偏大或偏小）需要对比多个示例才能归纳出"离中位数最远"这个规则，而非简单的"最大"或"最小"。

## 新题 5：重力沉降种子掩码的递归自相似展开

**组合逻辑**：[滑动/gravity_settling](创新：作用域从全画布缩小为种子区域内部) → [递归展开/recursive_expand](保留，但输入掩码来自重力沉降的结果)

**来源原语**：滑动/sliding（参考题 1e0a9b12）、重力沉降/gravity_settling（参考题 1e0a9b12）、列内独立/column_independent（参考题 1e0a9b12）、递归展开/recursive_expand（参考题 58c02a16）、种子掩码/seed_mask（参考题 58c02a16）、边界图例/border_legend（参考题 58c02a16）、前景背景分别替换/fg_bg_separate（参考题 58c02a16）、自相似替换/self_similar_sub（参考题 58c02a16）、平铺/tile（参考题 58c02a16）

**依赖链**：种子区域中的前景像素先经过列内重力沉降改变布局 → 沉降后的掩码作为递归展开的二值模板 → 展开时前景位置替换为主色掩码副本、背景位置替换为副色掩码副本 → 最终裁剪平铺至原网格。删除重力步骤，种子掩码不同，递归结果完全不同；删除递归展开，仅有沉降后的小掩码，无法产生全画布输出。

种子区域内的前景像素先下沉到底部，沉降后的掩码再进行自相似递归展开并平铺至全画布。

**输入结构**：黑(0)背景，约 12x12 网格。左上角有一个 NxN（N 为 3 或 4）的种子区域，其中含若干红(2)前景像素和黑(0)背景像素。种子区域的最右列和最底行被灰(5)像素完全填充，形成 L 形图例边框（与参考题 58c02a16 结构一致）。去掉灰(5)边框后的 (N-1)x(N-1) 区域即为种子。种子中的红(2)像素散布在不同行列，不全在底部（即重力沉降会改变其位置）。种子区域外（灰边框外）全为黑(0)。生成约束：种子中红(2)像素数量为 2~4 个，保证沉降前后掩码明显不同。

**规则**：
1. 定位左上角的种子区域：找到灰(5)像素构成的 L 形边框，去掉最右列和最底行的灰(5)像素后得到 (N-1)x(N-1) 的种子格。
2. 在种子格内部执行列独立重力沉降：每列中的红(2)像素落至该列最底行可用位置（仅在种子格的 (N-1)x(N-1) 范围内操作），上方空出的位置填为黑(0)。
3. 以沉降后的种子格为二值掩码（红(2) = 前景，黑(0) = 背景），执行递归展开：
   - 将掩码中每个红(2)位置替换为整个沉降后掩码的红(2)色副本。
   - 将掩码中每个黑(0)位置替换为整个沉降后掩码的灰(5)色副本。
4. 递归展开产生的图案裁剪为原始输入网格尺寸并输出。灰(5)边框不保留在输出中。

**关键洞察**：种子掩码并非输入中的原始布局，而是对原始布局进行重力沉降后的结果。求解者若直接将原始种子用于递归展开，会得到错误的输出。必须先识别出"种子需要先沉降"这一隐蔽的预处理步骤。

## 新题 6：标记像素的双重编码——目标槽位与环距调色板

**组合逻辑**：[标记坐标编码槽位/marker_encodes_slot](保留) + [切比雪夫距离 + 填充/concentric_ring_fill](创新：环的中心不是网格中心而是标记像素在源瓦片内的位置) → [复制/copy → 填充/fill]（创新：不是简单复制瓦片，而是将瓦片内容按距离展开为同心环）

**来源原语**：复制/copy（参考题 6d0160f0）、标记像素/marker_pixel（参考题 6d0160f0）、标记坐标编码槽位/marker_encodes_slot（参考题 6d0160f0）、网格分区/grid_partition（参考题 6d0160f0）、分隔线/separator_line（参考题 6d0160f0）、填充/fill（参考题 ac0c2ac3）、同心方环/concentric_ring（参考题 ac0c2ac3）、切比雪夫距离/chebyshev_distance（参考题 ac0c2ac3）、距离映射/distance_mapping（参考题 ac0c2ac3）

**依赖链**：黄色标记像素在源瓦片中的局部坐标 (r,c) 同时决定两件事：(1) 目标瓦片的宏位置 (r,c)；(2) 同心方环的中心点在目标瓦片内的位置。源瓦片中各像素到标记像素的切比雪夫距离提供调色板 → 目标瓦片被填充为以 (r,c) 为中心的同心方环，每环颜色取自该距离对应的源瓦片像素颜色。删除槽位编码，不知道往哪个瓦片写；删除距离调色板，不知道环填什么颜色。

标记像素同时编码目标槽位和环心位置，源瓦片中各像素到标记的切比雪夫距离映射为目标瓦片的同心方环配色。

**输入结构**：约 11x11 网格，由灰(5)分隔线划分为 3x3 阵列的等大正方形瓦片，每个瓦片为 3x3。分隔线为 1 像素宽的灰(5)行和列。恰好一个瓦片中有非黑(0)的彩色像素图案，且该瓦片中恰好有一个黄(4)标记像素。该源瓦片的 3x3 区域中，黄(4)标记像素处于某个位置 (r,c)（r,c 各为 0、1 或 2），其余位置为不同的非黑颜色或黑(0)。所有其他瓦片全为黑(0)。生成约束：源瓦片中，切比雪夫距离 0 处为黄(4)（标记本身），距离 1 处恰有一个非黑非黄的颜色像素，距离 2 处恰有一个不同的非黑非黄的颜色像素（即每个距离恰好对应一种颜色，以便映射无歧义）。

**规则**：
1. 找到包含黄(4)标记像素的源瓦片，记其在 3x3 宏阵列中的位置为 (R_src, C_src)。
2. 读取标记像素在该瓦片内的局部坐标 (r, c)（行从 0 开始，列从 0 开始）。目标瓦片的宏位置为 (r, c)。
3. 在源瓦片中，收集每个切比雪夫距离 d（从标记像素计算）对应的颜色：
   - d=0：黄(4)（标记本身的颜色）。
   - d=1：该距离处的唯一非黑像素的颜色。
   - d=2：该距离处的唯一非黑像素的颜色。
4. 在目标瓦片中，以局部坐标 (r, c) 为中心，将每个像素位置 (i, j) 的颜色设为 d = max(|i-r|, |j-c|) 对应的颜色。超出瓦片 3x3 范围的部分不处理。
5. 清除源瓦片中的所有非黑像素（将源瓦片恢复为全黑(0)）。
6. 保留所有灰(5)分隔线不变。其他未涉及的瓦片保持黑(0)。

**关键洞察**：黄色标记像素身兼三职——标识源瓦片、编码目标槽位、定义环心坐标——求解者必须意识到同一个像素的局部坐标在两个完全不同的语义层面上被使用：一次作为宏阵列地址，一次作为目标瓦片内的几何中心。

## 新题 7：水平重力沉降障碍物后规避路径绘制

**组合逻辑**：[滑动/slide + 碰撞阻挡/collision_blocking](保留) → [像素计数编码半径/pixel_count_encodes_radius](保留) → [连线/draw_path + 避障/obstacle_avoidance](保留，但避障对象是沉降后位置而非原始位置)

**来源原语**：滑动/slide（参考题 5ffb2104）、碰撞阻挡/collision_blocking（参考题 5ffb2104）、重力远近序处理/gravity_far_to_near（参考题 5ffb2104）、连线/draw_path（参考题 cb2d8a2c）、避障/obstacle_avoidance（参考题 cb2d8a2c）、像素计数编码半径/pixel_count_encodes_radius（参考题 cb2d8a2c）、路径起点/path_start（参考题 cb2d8a2c）、障碍条/obstacle_bar（参考题 cb2d8a2c）、编码映射/encoding_map（参考题 cb2d8a2c）、绕障碍最短路径/shortest_detour（参考题 cb2d8a2c）

**依赖链**：障碍条先通过水平重力右移至碰撞停止位置 → 停止位置决定了禁区的空间范围 → 每个障碍条的蓝色像素数编码其禁区半径 → 路径起点向对侧延伸时必须绕过所有禁区 → 最终蓝色像素重涂为红色。删除水平重力，障碍位置错误导致路径错误；删除像素计数编码，禁区半径未知；删除路径绘制，无法生成输出。

障碍条先受水平重力向右沉降，沉降后再根据各条的蓝色像素数确定禁区半径，绿色路径从一侧绕过所有禁区到达对侧。

**输入结构**：青(8)背景，约 15x18 网格。网格中有 2~4 个障碍条，每个障碍条为竖直方向的一列连续像素（高度 3~6），由红(2)和蓝(1)像素混合组成（蓝色像素数量 1~3 个，其余为红色）。障碍条初始时分布在网格的左半区和中间区域，各条不在同一列。网格左边界某一行有一个绿(3)像素作为路径起点。生成约束：障碍条之间有足够水平间距，保证右移沉降后不会全部挤在同一列；沉降后各禁区之间存在可通行间隙；路径可以从左侧到达右侧边界。

**规则**：
1. 将所有障碍条视为刚体对象（每个障碍条的像素保持相对位置不变）。按照原始位置从右到左的顺序处理（最右边的条先处理）。
2. 每个障碍条向右平移，每次移动一个像素，直到其右侧像素的下一步将超出网格右边界或与已放置的障碍条重叠为止。（水平重力，最右侧的先沉降成为阻挡物。）
3. 沉降完成后，对每个障碍条计算其蓝(1)像素的数量 k。该障碍条的禁区半径为 k：以障碍条的每个像素为中心、切比雪夫距离 <= k 的所有单元格均为禁区。
4. 从绿(3)起点像素向右延伸路径，路径为单像素宽。路径每步可向右、向上或向下移动一格（不回退向左）。路径必须避开所有禁区和障碍条本身的像素。路径采用贪心策略：尽量直行（向右），仅在前方被禁区阻挡时才转向（向上或向下），选择使路径更接近终点行（起点所在行）的方向；若上下等距则向上。绕过禁区后尽快回到起点行高度继续直行。路径到达网格右边界时停止。
5. 路径像素涂为绿(3)。
6. 将所有障碍条中的蓝(1)像素重涂为红(2)（在沉降后的位置上执行）。

**关键洞察**：路径规划的约束空间不是原始输入中的障碍位置，而是障碍经过水平重力沉降后的新位置。求解者必须先在脑中模拟所有障碍条的右移碰撞过程，确定最终位置，再计算每个障碍的禁区，最后才能规划路径。三步推理中任何一步出错都会导致完全不同的路径。

**依赖链**：识别精灵体和格点布局 → 在空缺格点位置印章补全新精灵体（青色） → 原始精灵体（绿色）上的红色指示像素决定延伸方向 → 延伸带从原件出发，遇到补全件（青色）或画布边界时停止 → 补全件既是补全的产物又是延伸的阻挡物。删除格点补全，延伸可能直达画布边界（错误）；删除延伸，格点补全独立可解但输出不同；两者通过"补全件充当阻挡物"紧耦合。

**输入结构**：黑(0)背景，约 18x18 网格。网格中有若干相同形状的绿(3)精灵体（每个精灵体为 4-连通的单色小图形，3~5 像素），排列在一个矩形格点上（行间距和列间距固定且相等，约 4~6 像素）。格点至少有一个完整行和一个完整列被占据，其余若干格点位置为空。每个绿(3)精灵体上恰有一个红(2)像素替换了精灵体某个边缘像素的位置，指示延伸方向：红像素在精灵体的上边缘 → 向上，下边缘 → 向下，左边缘 → 向左，右边缘 → 向右。不同精灵体的指示方向可以不同。生成约束：各精灵体的延伸方向保证其延伸带（宽度为精灵体在垂直于延伸方向上的投影宽度，即 1~2 像素）不会与另一个绿色精灵体的延伸带重叠；每个绿色精灵体的延伸方向上至少有一个空格点位置（即补全后会有青色精灵体出现在延伸路径上）。

**规则**：
1. 识别所有绿(3)精灵体的公共掩码形状（忽略红(2)指示像素——将红像素视为精灵体的一部分）。
2. 确定精灵体排列的矩形格点：提取所有现有精灵体的左上角行坐标集合和左上角列坐标集合。
3. 对格点的笛卡尔积中所有未被占据的位置，以青(8)颜色印章放置一份精灵体副本（副本不含红色指示像素，全部为青(8)）。
4. 对每个原始绿(3)精灵体，定位其红(2)指示像素，确定延伸方向。
5. 从精灵体的指示边出发，沿延伸方向逐行（或逐列）延伸一条绿(3)色带（宽度为精灵体在垂直方向上的投影跨度）。同时沿指示像素所在的行（或列）画一条红(2)线。
6. 延伸在以下情况停止：(a) 延伸带的任一像素的下一步将进入青(8)补全精灵体的任一像素位置；(b) 到达画布边界。停止时不覆盖阻挡物。
7. 各绿色精灵体的延伸独立处理（生成约束保证延伸带互不重叠）。

**关键洞察**：补全步骤产生的青色精灵体在第二阶段的角色完全翻转——从"被填入的缺失元素"变为"阻止延伸的障碍物"。求解者若不先完成格点补全，就无法知道延伸应该在哪里停止；若不理解延伸规则，也无法理解为什么补全件的位置至关重要。两套逻辑共享同一组格点位置信息，但各取所需、互相制约。

## 新题 9：裁剪区域由竖直导轨定界后镜像平铺

**组合逻辑**：[裁剪/crop + 线段定裁剪列范围](保留) → [平铺/tiling + 镜像/mirror + 中间行翻转](创新：瓦片来自裁剪结果而非直接给定；平铺行数由裁剪区域内前景颜色种类数决定)

**依赖链**：灰色竖直导轨和青色角标确定裁剪范围 → 裁剪得到一个小瓦片 → 统计瓦片中前景颜色的种类数 K → 输出为 K 行 x 3 列的瓦片阵列 → 奇数行（第 1、3、5...行，从 1 计）使用原瓦片，偶数行使用左右镜像的瓦片。删除裁剪，没有瓦片可用；删除颜色种类数计算，不知道平铺几行；删除镜像规则，输出图案错误。

**输入结构**：黑(0)背景，约 20x20 网格。网格中有大量散布的彩色像素（使用红(2)、蓝(1)、绿(3)、黄(4)中的若干种）。两条灰(5)竖直线段（每条高 4~8 像素，宽 1 像素）位于网格中，左右各一条，之间水平间隔 3~6 列。每条灰色线段的上方一行和下方一行各有一个青(8)角标记像素，位于该灰色线段所在列。灰色线段之间（含角标行）构成裁剪范围内的矩形区域。裁剪区域内有 2~4 种前景颜色的像素。生成约束：裁剪区域的尺寸保证输出（K行 x 3列的瓦片阵列）不超过 30x30。

**规则**：
1. 识别两条灰(5)竖直线段对象（每条为同一列中连续的灰色像素），按列坐标从小到大排序为左导轨和右导轨。

3. 裁剪行范围：从左导轨（或右导轨，取更靠上者）最顶端像素上方一行开始，到最底端像素下方一行结束（含两端）。这一行扩展使角标记像素被包含在裁剪区域内。行范围钳位到画布边界内。
4. 裁剪得到小瓦片 T。
5. 统计瓦片 T 中出现的前景颜色种类数 K（前景 = 非黑(0)、非灰(5)、非青(8)的颜色）。
6. 构造输出：K 行 x 3 列的瓦片阵列。
   - 阵列中第 n 行（n 从 1 开始）：若 n 为奇数，放置瓦片 T 的原始版本；若 n 为偶数，放置瓦片 T 的左右镜像版本。
   - 同一行内 3 列均使用相同版本的瓦片（奇数行全用原版，偶数行全用镜像版）。
7. 输出画布大小为 (K * 瓦片高度) x (3 * 瓦片宽度)。灰色导轨和青色角标作为裁剪区域内容的一部分保留在瓦片中。

**关键洞察**：平铺的行数不是固定常数，而由裁剪区域内容本身的颜色多样性编码。求解者必须先执行裁剪（确定瓦片），再分析裁剪结果（数颜色种类），最后用分析结论决定平铺规模。如果裁剪区域内颜色更多，输出就更高——瓦片内容和输出尺寸之间存在自指关系。

## 新题 10：同色分量链式连线绕周期性禁区

**组合逻辑**：[连线/connect + 同色分量依序连接](保留) → [控制条周期延伸/control_periodic](创新：从帧结构生成变为禁区生成) → [避障/obstacle_avoidance + 绕障碍最短路径](创新：障碍不是静态墙而是由控制条周期延伸出的虚拟禁区带)

**来源原语**：连线/connect（参考题 f8f52ecc）、同色连通分量/same_color_comp（参考题 f8f52ecc）、同色分量依序连接/same_color_chain（参考题 f8f52ecc）、障碍墙/obstacle_wall（参考题 f8f52ecc）、绕障碍最短路径/shortest_detour（参考题 cb2d8a2c）、避障/obstacle_avoidance（参考题 cb2d8a2c）、控制条/control_bar（参考题 34cfa167）、控制条周期延伸/control_periodic（参考题 34cfa167）

**依赖链**：控制条的间距定义周期 → 按该周期在整个网格中生成虚拟禁区行（或列） → 同色分量的连线路径必须绕过这些周期性禁区 → 禁区的周期和相位由控制条位置决定。删除控制条周期计算，不知道哪些行/列是禁区；删除同色连线，无需路径规划；两者通过"路径必须绕开周期禁区"紧耦合。

同色分量按行主序链式连线，但连线路径必须绕开由控制条间距定义的周期性禁区行。

**输入结构**：黑(0)背景，约 16x16 网格。网格中有若干前景颜色的 4-连通分量（使用红(2)和绿(3)两种颜色，每种颜色有 2~3 个分量，每个分量 2~5 像素）。网格左边界或上边界处有 2 个品红(6)的单像素控制标记，它们在同一列（或同一行）上，间隔若干行（或列）——该间隔即为禁区周期 P。此外网格中有若干青(8)的固定障碍墙像素（散布的单像素或短线段）。生成约束：P 的值为 3~5；同色分量的位置保证它们之间存在绕过禁区和障碍墙的有效 L 形路径；不同颜色的连线路径互不交叉。

**规则**：
1. 定位两个品红(6)控制标记。若它们在同一列，计算它们的行间距 P，禁区类型为"水平禁区行"；若在同一行，计算列间距 P，禁区类型为"竖直禁区列"。
2. 生成周期性禁区：以第一个控制标记的行（或列）为相位起点，每隔 P 行（或列）标记一条完整的禁区行（或列），覆盖整个网格宽度（或高度）。禁区行/列上的像素不可通行（路径不能经过）。品红(6)标记本身也位于禁区上。
3. 对每种前景颜色（红(2)和绿(3)），分别找到该颜色的所有 4-连通分量，按各分量边界框左上角像素的行主序（先行后列）排序。
4. 对排序后的连续分量对 (C_i, C_{i+1})，找到从 C_i 到 C_{i+1} 的最短 L 形路径（路径由一段水平线和一段竖直线组成，拐弯一次）。路径只能经过背景像素或同颜色像素，不能经过禁区行/列上的任何位置、青(8)障碍墙、或其他颜色的像素。
5. 若直接的 L 形路径被禁区阻挡，路径需增加额外拐弯来绕过禁区行/列：选择总曼哈顿距离最短的合法路径（允许最多 3 次拐弯）。当存在多条等长路径时，选择第一个拐弯点行号更小的（行号相同则选列号更小的）。
6. 将路径像素涂为对应的前景颜色。品红(6)控制标记和青(8)障碍墙保持不变。

**关键洞察**：禁区不是输入中直接可见的色块，而是由两个离散控制标记隐式编码的周期性虚拟结构。求解者必须先从控制标记的间距推断出禁区周期和相位，在脑中"画出"这些不可见的禁区行/列，然后才能正确规划连线路径。若忽略禁区直接连线，路径会穿越禁区行/列而得到错误输出。
