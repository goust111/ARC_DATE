## 新题 1：障碍禁区重算线段有效长度后排序堆叠

**组合逻辑**：[邻域禁区/neighbor_exclusion](创新：不再排除路径像素，而是标记线段像素为"失效") → [计数/counting](创新：计数每条线段中未被禁区覆盖的像素数，得到"安全长度") → [排序+堆叠/sort+stack](创新：按安全长度而非原始长度排序)

**来源原语**：邻域禁区(cc9053aa)、计数(b2bc3ffd/c3e719e8)、排序+堆叠(beb8660c)、线段(beb8660c)、障碍物(cc9053aa)、全宽条纹(beb8660c)

**依赖链**：障碍物的 8 邻域禁区叠加在线段之上 → 禁区覆盖情况决定每条线段的安全长度 → 安全长度决定排序顺序 → 排序顺序决定堆叠位置。删除障碍物则安全长度退化为原始长度（排序结果不同）；删除排序则无法确定堆叠位置。

将散布的水平线段按其"未被障碍禁区覆盖的有效像素数"从少到多排序，右对齐堆叠于底部条纹之上。

**输入结构**：约 15x15 的网格，黑(0) 背景。最底行为蓝(1) 全宽条纹。条纹上方散布 4-5 条水平单像素厚的单色线段，每条颜色各不相同（使用红(2)、绿(3)、黄(4)、灰(5)、品红(6) 等），长度在 3-8 像素之间且互不相同。线段之间不相邻、不重叠。另有 2-3 个橙(7) 孤立像素散布在网格中（不在任何线段上，不在底部条纹上），位置使得不同线段被禁区覆盖的像素数各不相同。生成约束：每条线段的安全长度互不相等；橙像素之间的 8 邻域互不重叠。

**规则**：
1. 将每个橙(7) 像素及其 8 邻域标记为"禁区"。
2. 对每条线段，计算其像素中不在任何禁区内的个数，记为该线段的"安全长度"。
3. 清除所有线段在原位置的像素（恢复为黑(0)）。
4. 按安全长度从小到大排序。若安全长度相同（生成时已排除），则按线段原始行号从上到下排。
5. 将排序后的线段依次放置于底部条纹正上方的连续行中：第一条（安全长度最小）紧贴条纹上方，后续依次向上。每条线段右端对齐网格右边缘，保持其原始颜色和原始像素长度（完整线段，不截去被禁区覆盖的部分）。
6. 橙(7) 像素和蓝(1) 条纹保持不变。

**关键洞察**：输出中放置的是原始完整线段（非截断版本），但它们的堆叠顺序由障碍物禁区对其覆盖程度决定——禁区不"切割"线段，只"重新度量"它们的排序权重。

## 新题 2：杯形开口方向远程决定精灵体镜像轴

**组合逻辑**：[开口朝向检测/opening_direction](原有) → 分叉 → { [填充/fill](原有：填充杯形内部), [镜像/mirror](创新：镜像轴不由标记像素给出，而由杯形开口方向远程决定) }

**来源原语**：开口朝向(aba27056)、填充(aba27056)、杯形容器(aba27056)、镜像(2bcee788)、标记像素(2bcee788)、精灵体(8f2ea7aa)、邻接(2bcee788)

**依赖链**：杯形结构分析得到开口方向 → 开口方向同时决定：(a) 从哪一侧灌入填充色，(b) 精灵体的镜像轴朝向。杯形和精灵体是独立对象，但共享同一方向信息，形成分叉耦合。删除杯形则镜像轴未知；删除精灵体则无镜像目标。

检测杯形容器的开口方向，用该方向既填充杯体内部，又决定远处精灵体的镜像反射轴。

**输入结构**：约 14x14 的网格，黑(0) 背景。左半区有一个灰(5) 杯形容器（5-8 像素，4-连通，呈"凹"字形变体，围成一个封闭的黑(0) 内部空腔，某一侧有 1-2 像素宽的缺口作为开口；开口可朝上/下/左/右中任一方向；不同示例中开口方向不同）。右半区有一个绿(3) 的小型非对称 4-连通精灵体（3-5 像素，无孔洞，位于远离杯形的位置，与杯形至少间隔 3 列）。生成约束：精灵体在镜像方向上有足够空间放置镜像副本而不超出网格边界且不与杯形重叠。

**规则**：
1. 找到杯形的开口方向（杯形边界框中没有灰像素封闭的那一侧）。
2. 将杯形内部的黑(0) 空腔像素填充为黄(4)。
3. 根据开口方向确定镜像轴方位：开口朝右 → 精灵体边界框右侧紧邻处放置垂直镜像轴；开口朝左 → 精灵体边界框左侧紧邻处放置垂直镜像轴；开口朝上 → 精灵体边界框上方紧邻处放置水平镜像轴；开口朝下 → 精灵体边界框下方紧邻处放置水平镜像轴。
4. 将精灵体沿该轴反射，生成镜像副本。副本涂为红(2)。原始绿(3) 精灵体保留。
5. 其余所有像素不变。

**关键洞察**：杯形和精灵体在空间上完全分离，看似无关，但杯形的几何缺口（开口方向）远程控制了精灵体的镜像行为——必须对比多个示例（不同开口方向）才能归纳出这层远程耦合。

## 新题 3：安全路径形状作为自相似展开的印章模板

**组合逻辑**：[寻路/pathfinding + 邻域禁区/neighbor_exclusion](原有：找到安全路径) → [裁剪/crop](原有：将路径裁至边界框) → [自相似嵌套/self_similar_nesting + 印章覆盖/stamp](创新：路径形状不是最终输出，而是被用作自展开的模板与内容)

**来源原语**：寻路(cc9053aa)、邻域禁区(cc9053aa)、端点(cc9053aa)、障碍物(cc9053aa)、自相似嵌套(8f2ea7aa)、前景位置决定印章(8f2ea7aa)、印章覆盖(8f2ea7aa)、裁剪(a251c730)

**依赖链**：障碍禁区筛选出唯一安全路径 → 路径裁剪为方形模板 → 模板的前景像素位置决定印章放置位，模板本身就是印章内容 → 自相似展开。删除寻路则模板未知；删除自相似展开则路径只是路径，无展开结构。

在障碍物禁区约束下找出两端点间的唯一安全路径，将路径形状裁剪为紧凑模板，再以该模板为基础做自相似展开。

**输入结构**：约 7x7 的网格（因为输出为模板尺寸的平方，需保持可控），黑(0) 背景。青(8) 像素构成一个 4-连通的轨道网络，轨道区域紧凑地分布在约 3x3 的范围内。网格中恰好有两个栗(9) 端点像素位于轨道上。1-2 个橙(7) 像素位于轨道附近（不在轨道上）。生成约束：橙像素的 8 邻域禁区移除部分轨道连接后，两端点之间仅存在唯一一条 4-连通简单路径；该路径裁剪至边界框后恰好填充一个 NxN 的正方形区域（N = 2 或 3），且输出网格尺寸为 NxN 的平方（即 4x4 或 9x9）。

**规则**：
1. 将每个橙(7) 像素及其 8 邻域标记为禁区。禁区内的青像素视为不可通行。
2. 在剩余可通行的青(8)/栗(9) 像素中，找到两个栗端点之间的唯一 4-连通简单路径。
3. 将路径（含两个栗端点）裁剪至其边界框，得到一个 NxN 的二值模板：路径像素为前景，其余为背景。前景统一标记为栗(9)。
4. 创建 N^2 x N^2 的输出网格，初始化为黑(0)。将输出划分为 NxN 个大小为 NxN 的块。
5. 对模板中每个前景像素位于局部坐标 (r, c) 处，将整个模板复制粘贴到输出的第 (r, c) 块中，前景像素涂为栗(9)。
6. 所有其他块保持黑(0)。

**关键洞察**：路径不是最终答案——它是被"发现"的中间产物，其形状既决定了自展开的印章内容，又决定了印章的放置掩模。谜题有两层结构推导：先寻路，再展开。

## 新题 4：对角线归属决定紧缩目标与涂色

**组合逻辑**：[对角朝向分类/diagonal_orientation + classify](创新：不是按自身朝向分类，而是按与哪个锚块共享对角线来分配归属) → [紧缩至锚/compact_to_anchor](创新：紧缩方向不再是正交射线而是对角射线) → [重涂色/recolor](创新：涂色取决于归属的锚块颜色而非多数朝向)

**来源原语**：对角朝向(1d61978c)、分类(1d61978c)、锚块(f28a3cbb)、射线像素(f28a3cbb)、紧缩至锚(f28a3cbb)、对角射线(2b9ef948)、重涂色(1d61978c)

**依赖链**：对角线分析 → 同时确定归属（属于哪个锚块）和紧缩方向（沿哪条对角线滑动） → 归属决定重涂色颜色。三者通过同一条对角线关系耦合：删除对角分析则无法确定归属和方向；删除紧缩则像素留在原位失去空间变换；删除涂色则丢失归属信息的视觉表达。

散布的灰色像素各自与某个锚块共享一条对角线——沿该对角线紧缩至锚块旁，并涂为锚块的颜色。

**输入结构**：约 14x14 的网格，黑(0) 背景。两个实心 2x2 的锚块，分别为青(8) 和红(2)，放置在网格的不同象限（如左上和右下），两锚块的行列坐标均不相同。散布 6-10 个灰(5) 孤立像素，每个灰像素恰好与两个锚块中的某一个处于同一条 45 度对角线上（即行差的绝对值等于列差的绝对值，相对于该锚块的 2x2 区域的某个角像素）。生成约束：没有灰像素同时与两个锚块共享对角线；灰像素之间不相邻；每个锚块至少有 2 个灰像素归属；紧缩后像素不超出网格且不重叠。

**规则**：
1. 对每个灰(5) 像素，判断它与哪个锚块的某角像素共享 45 度对角线（行差绝对值 = 列差绝对值）。该像素"归属"那个锚块。
2. 确定该像素相对于其锚块的对角方向（NE、NW、SE、SW 中的一个）。
3. 清除该灰像素原位。将它沿对角方向向锚块滑动，放置在该对角射线上紧邻锚块（或紧邻已紧缩的同方向像素）的第一个空位。即：同一方向多个像素从近到远依次排列在锚块角像素的对角延长线上。处理顺序：距其锚块最近的灰像素先处理。
4. 紧缩后的像素涂为其归属锚块的颜色：归属青(8) 锚块的涂青(8)，归属红(2) 锚块的涂红(2)。
5. 锚块本身不变。

**关键洞察**：灰像素不以颜色或邻近度确定归属，而以对角线几何关系确定——一个灰像素可能在空间上更靠近锚块 A，但对角线对齐的是锚块 B，因此它必须紧缩到 B。

## 新题 5：原型互换后以新面积为位移量上移

**组合逻辑**：[互换原型/toggle_to_alternate_prototype](原有：每个精灵切换为另一种原型) → [计数/counting](创新：计数切换后的新像素数而非原像素数) → [平移/translate](创新：位移量由新原型面积决定，形成因果倒挂——必须先切换才知道位移)

**来源原语**：互换原型(c7f57c3e)、原型精灵(c7f57c3e)、锚点区域(c7f57c3e)、位移等于面积(b2bc3ffd)、平移(b2bc3ffd)、全宽条纹(b2bc3ffd)、计数(b2bc3ffd)

**依赖链**：原型切换改变了精灵的形状与像素数 → 新像素数决定上移距离 → 必须先知道切换后的形状才能计算位移。这是因果倒挂耦合：位移量不来自输入的原始形状，而来自变换后的形状。删除切换则形状不变（位移也不同）；删除位移则只有切换（丢失空间变换）。

将每个精灵体切换为另一种原型模式，然后以新原型的像素数为距离向上平移。

**输入结构**：约 18x15 的网格，黑(0) 背景。最底行为蓝(1) 全宽条纹。条纹上方分布 3-4 个绿(3) 精灵体实例，每个是两种原型之一的等比例(scale=1)副本。原型 A：一个 4-连通非对称图形，4 像素，边界框 2x3。原型 B：一个 4-连通非对称图形，6 像素，边界框 2x3，与 A 连通结构不同。每个精灵体内部恰好有一个黄(4) 锚点像素，替换了绿(3) 中的一个位置，用于标记定位点。锚点在两种原型中的相对位置相同（如均在边界框左上角）。生成约束：精灵体之间水平间距至少 2 列；每个精灵体上移其新原型像素数后不超出网格上边界且不与其他精灵体的目标位置重叠；两种原型至少各出现一次。

**规则**：
1. 识别两种原型模式：从所有精灵体中提取最小面积的非锚点绿像素图案，得到两种不同模式。
2. 对每个精灵体，确定它匹配哪种原型，然后切换为另一种：A→B 或 B→A。切换时以黄(4) 锚点像素为对齐基准，锚点位置不变。
3. 清除原精灵体的所有像素（含锚点），在锚点位置绘制新原型（绿(3) 像素 + 黄(4) 锚点）。
4. 计算新原型的总像素数（含锚点）：A→B 后为 6 像素，B→A 后为 4 像素。
5. 将切换后的精灵体整体向上平移该像素数的行数（A→B 上移 6 行，B→A 上移 4 行）。
6. 蓝(1) 条纹不变。

**关键洞察**：位移量取决于切换后的新形状而非原始形状——A 型精灵切换为 B 后上移 6 行（B 的面积），B 型精灵切换为 A 后上移 4 行（A 的面积）。求解者必须先推断切换规则，再从新形状计算位移，二者不可独立求解。

## 新题 6：标记环投射交叉点处按邻近度印章锚块图案

**组合逻辑**：[投射到引导线/projection_to_guide](原有：标记环发射垂直引导线) → [交叉点定位](原有) → [距离排序/distance_ordering](创新：不用于排序矩形，而是为每个交叉点选择最近的锚块) → [印章覆盖/stamp](创新：印章内容不是环形而是锚块图案，由邻近度决定)

**来源原语**：标记环(ac3e2b04)、引导线(ac3e2b04)、投射到引导线(ac3e2b04)、交叉点印章环形(ac3e2b04)、锚块(f28a3cbb)、距离排序(291dc1e1)、印章覆盖(a251c730)、颜色匹配(a251c730)

**依赖链**：标记环投射产生引导线 → 引导线与红线交叉确定交叉点 → 每个交叉点以曼哈顿距离匹配最近的锚块 → 锚块图案印章到交叉位置。引导线投射系统产生"在哪里放"，锚块邻近度解决"放什么"，两个独立子系统在交叉点处汇合。删除投射则无交叉点；删除锚块则无印章内容。

绿色标记环投射垂直引导线，在引导线与红色水平导轨的交叉处，印章最近锚块的 3x3 图案。

**输入结构**：约 20x20 的网格，黑(0) 背景。2 条水平全宽红(2) 引导线（不相邻）。2 个绿(3) 3x3 空心环（中心为红(2)），每个环中心位于某条红引导线上，两个环分别在不同的红线上。2 个实心 3x3 锚块，颜色各不相同（如蓝(1) 和黄(4)），放置在网格中不在红引导线上的位置。生成约束：每条红引导线上最多一个绿环中心；每个交叉点到两个锚块的曼哈顿距离不相等（保证最近锚块唯一）；印章放置后各 3x3 区域不重叠，不覆盖绿环区域。

**规则**：
1. 每个绿(3) 环通过其中心列发射垂直蓝(1) 引导线：从该列的顶端到底端，仅将黑(0) 背景像素涂为蓝(1)（不覆盖红线、绿环、锚块）。
2. 标记每条蓝引导线与红引导线的交叉点（蓝列与红行的交叉坐标）。排除绿环中心本身所在的交叉（该交叉已被环占据）。
3. 对每个交叉点，计算它到每个锚块中心的曼哈顿距离，选择距离最小的锚块。
4. 以交叉点为中心，将所选锚块的 3x3 图案（含其颜色）印章到该位置。印章覆盖蓝引导像素和黑背景，但不覆盖红(2) 引导线像素（红线像素保留）。
5. 绿(3) 环保持原样不变。锚块保持原样不变。

**关键洞察**：绿环不携带印章内容——它们只是投射系统的"发射器"。实际印章内容来自空间上与交叉点最近的锚块，因此移动锚块的位置会改变哪些交叉点接收哪种图案，但不改变交叉点的位置。

## 新题 7：错切后障碍禁区重算面积排序堆叠

**组合逻辑**：[错切/shear + 贴墙移动/move_to_wall](原有：对象移到对面墙并逐行错切) → [邻域禁区/neighbor_exclusion](创新：不在路径上做排除，而是在错切后的新位置上标记失效像素) → [计数/counting](创新：计数错切后的安全面积) → [排序+堆叠/sort+stack](创新：按安全面积排序后重新堆叠)

**来源原语**：错切(9f41bd9c)、贴墙移动(9f41bd9c)、逐行偏移(9f41bd9c)、地面行(9f41bd9c)、障碍物(cc9053aa)、邻域禁区(cc9053aa)、排序(beb8660c)、堆叠(beb8660c)、按长度递增堆叠(beb8660c)

**依赖链**：错切改变对象形状与位置 → 新位置与障碍禁区的重叠关系不同于原位 → 禁区覆盖决定安全面积 → 安全面积决定堆叠顺序。这是三步交织耦合：错切决定空间位置，空间位置决定禁区影响，禁区影响决定排序权重。

将贴左墙的对象错切移动到右墙，然后按错切后的"障碍安全面积"排序堆叠。

**输入结构**：约 16x18 的网格，黑(0) 背景。最底行为灰(5) 地面行。3-4 个小型单色 4-连通对象（每个 4-6 像素，颜色各不相同，选自红(2)、绿(3)、黄(4)、品红(6)），每个紧贴网格左边缘，垂直排列在地面行之上的不同行段（对象之间有间距）。每个对象占据 2-3 行、1-3 列。网格右半区域散布 2-3 个橙(7) 孤立像素。生成约束：对象错切后不超出网格边界；不同对象的错切结果被禁区覆盖后的安全面积互不相同。

**规则**：
1. 对每个贴左墙的对象执行错切移动：清除原位，在右墙绘制新形状——对象的第 0 行和第 1 行（从上往下数）紧贴右边缘，第 2 行起每行向左偏移 1 像素（逐行递增偏移）。
2. 标记每个橙(7) 像素及其 8 邻域为禁区。
3. 对每个错切后的对象，计算其像素中不在禁区内的个数，记为"安全面积"。
4. 清除所有错切后的对象像素。按安全面积从小到大排序；若安全面积相同则按原始最高行从上到下排。
5. 将排序后的对象依次放置于地面行正上方的连续行段中（最小安全面积的紧贴地面行），每个对象右端对齐右边缘，使用错切后的形状，保持原始颜色。
6. 灰(5) 地面行和橙(7) 像素保持不变。

**关键洞察**：排序权重不取决于对象的原始位置或原始形状，而取决于错切后的新形状在新位置上被障碍禁区覆盖了多少——必须先做错切变形，才能计算有效面积，才能确定堆叠顺序。

## 新题 8：路径端点编码位移量、框体开口决定填充射线方向

**组合逻辑**：{ [端点编码位移/endpoints_encode_disp](原有：灰路径两端编码平移向量) + [空心框/hollow_frame](原有) } → [平移/translate](原有：框体平移) → [开口朝向/opening_direction](创新：不从杯形获取开口方向，而是从空心框的缺口获取) → { [填充/fill](创新：填充平移后的框体内部), [射线延伸/ray_extend](创新：从框体缺口处而非对角线处发射射线) }

**来源原语**：端点编码位移(2b9ef948)、空心框(2b9ef948)、对角射线(2b9ef948)、路径端点(2b9ef948)、填充(aba27056)、开口朝向(aba27056)、从开口发射(aba27056)、射线延伸(aba27056)、内部包含(aba27056)

**依赖链**：路径端点编码平移向量 → 平移框体到新位置 → 在新位置检测框体缺口方向 → 缺口方向同时决定内部填充的连通区域和射线发射方向。两个独立的输入特征（路径端点、框体缺口）分别控制输出的不同方面（位置、方向），在平移后的框体处汇合。

灰色路径的两个彩色端点编码平移向量，将带缺口的空心框平移后，填充其内部并从缺口处发射射线。

**输入结构**：约 15x15 的网格，黑(0) 背景。一个 5x5 黄(4) 空心框（外圈像素为黄、内部 3x3 为黑），且框的某一侧边正中缺少一个黄像素，形成 1 像素宽的缺口（开口方向在上/下/左/右之一，不同示例不同）。框内中心有一个绿(3) 像素。在网格其他位置，有第二个绿(3) 像素，通过一串灰(5) 路径像素 4-连通地连接到一个孤立的黄(4) 像素。生成约束：平移后的框体完全在网格内；平移后框体不与路径或原始位置重叠。

**规则**：
1. 识别两个绿(3) 像素：框内的为"框锚点"，框外的为"路径起点"。识别与路径连接的孤立黄(4) 像素为"路径终点"。
2. 计算位移向量 = 路径终点坐标 - 路径起点坐标（行差, 列差）。灰路径的具体走法不影响位移。
3. 将整个空心框（含缺口和框内绿锚点）按位移向量平移到新位置。
4. 将整个网格背景填充为绿(3)（原路径像素、路径起点、路径终点均被绿色覆盖）。
5. 在平移后的框体新位置：将框内部 3x3 区域中非黄像素填充为黄(4)。
6. 检测平移后框体缺口的方向。从缺口位置向外（缺口朝向方向）发射黄(4) 射线，直到到达网格边缘。同时从缺口两端的框角向缺口朝向方向的两个 45 度对角方向各发射黄(4) 射线至网格边缘。
7. 射线覆盖绿(3) 背景像素，不覆盖黄(4) 框像素。

**关键洞察**：灰路径的弯折完全不影响结果——只有两个端点的相对位置编码了平移向量。而框体的缺口位置与路径无关，它独立地控制了移动后的射线发射方向。两条独立的信息通道（位移 vs. 方向）在平移后的框体处交汇。

## 新题 9：镜像打破自相似——原始位图定位、反射位图填充

**组合逻辑**：[自相似嵌套/self_similar_nesting](创新：前景位置定位不变，但填充内容不再是自身而是自身的镜像) ← [镜像/mirror](创新：镜像不作用于空间对象，而是生成印章内容的变体) ← [标记像素/marker_pixel](原有：红像素指示镜像方向)

**来源原语**：自相似嵌套(8f2ea7aa)、前景位置决定印章(8f2ea7aa)、印章覆盖(8f2ea7aa)、镜像(2bcee788)、标记像素(2bcee788)、标记侧翻转且变色(2bcee788)

**依赖链**：红色标记确定镜像轴 → 模板被镜像产生变体 → 原始模板的前景位置决定"在哪里放"，镜像变体决定"放什么"。模板同时扮演定位掩模（原始版本）和内容来源（反射版本）两个角色，由红色标记将这两个角色劈开。删除镜像则退化为普通自相似展开（与参考题相同）；删除自相似展开则镜像无处放置。

以原始紧凑模板的前景像素为放置掩模，以该模板的镜像版本为印章内容，做非对称自相似展开。

**输入结构**：约 6x6 或 9x9 的网格（尺寸 = 模板尺寸 N 的平方），黑(0) 背景。网格中有一个占据 NxN 边界框（N=2 或 N=3）的紧凑单色前景模板，颜色为蓝(1)，非对称形状（这样镜像后与原始不同）。模板某一侧紧邻有 1-2 个红(2) 标记像素，指示镜像方向（与参考题 2bcee788 中的标记用法一致）。生成约束：模板至少有 2 个前景像素且非对称（镜像后形状不同）；红标记仅触碰模板的一条边。

**规则**：
1. 将前景蓝(1) 模板从边界框中裁剪出来（不含红像素），得到原始 NxN 位图 M。
2. 根据红(2) 标记触碰的边确定镜像轴：触碰右边 → 垂直轴（左右翻转）；触碰左边 → 垂直轴（左右翻转）；触碰上边 → 水平轴（上下翻转）；触碰下边 → 水平轴（上下翻转）。对 M 执行镜像，得到 M'。
3. 创建 N^2 x N^2 的输出网格，全部初始化为黑(0)。
4. 将输出划分为 NxN 个大小为 NxN 的块。对于原始位图 M 中每个前景像素位于局部坐标 (r, c)，将**镜像位图 M'** 复制粘贴到输出的第 (r, c) 块中，前景像素涂蓝(1)。
5. 所有其他块保持黑(0)。红(2) 像素不出现在输出中。

**关键洞察**：标准自相似展开中模板既是位置掩模又是印章内容（两者相同）。这里红色标记将两者解耦：原始模板做位置掩模，镜像模板做印章内容。由于模板非对称，镜像后内容不同于掩模，产生了非对称的嵌套结构——这在参考题 8f2ea7aa 的纯自相似展开中不可能出现。
