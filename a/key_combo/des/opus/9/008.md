## 新题 1：路径追踪选取对称填充目标

**组合逻辑**：[路径追踪/path_follow] → [对称图案选取/symmetric_selected](创新：对称性不再是选取输出对象，而是决定是否对路径源区域执行填充) → [填充/fill]

**来源原语**：路径追踪、引导像素、路径连接（来自 9ba4a9aa）；镜像、对称、对称图案选取（来自 d56f2372）；填充、封闭区域（来自 d4f3cd78）

**依赖链**：路径追踪确定每个封闭区域与哪个远端图形关联 → 对称性检测作为布尔门控：只有远端图形通过垂直镜像对称测试时，对应的封闭区域才被填充 → 填充颜色由远端图形的颜色决定。三步缺一不可：无路径则不知道谁关联谁，无对称检测则所有区域都会被填充（错误），无填充则无输出变化。

从封闭区域出发沿引导路径找到远端图形，仅当远端图形垂直对称时，用其颜色填充源区域。

**输入结构**：约 20x20 的黑(0)背景网格。包含 3~4 个灰(5)像素构成的封闭矩形轮廓（每个约 4x4 至 6x6，4-连通闭合，内部全黑），彼此相距至少 3 格。每个封闭轮廓的外侧恰好有一个相邻像素作为引导路径的起点，引导像素沿水平/垂直方向以间隔 2 格的栅格排列（与 9ba4a9aa 一致），每条路径使用与其他路径不同的非黑非灰颜色（如蓝(1)、红(2)、绿(3)、黄(4)）。每条引导路径的末端相邻一个由该路径颜色构成的小型单色图形（3~6 像素的 4-连通区域）。这些远端图形中，恰好部分的包围框裁剪是左右镜像对称的，其余不对称。生成约束：每条路径颜色唯一且路径之间不交叉；每个远端图形仅与一条路径关联。

**规则**：
1. 识别所有灰(5)封闭矩形轮廓及其内部黑色区域。
2. 对每个轮廓，找到其外侧唯一相邻的非黑非灰引导像素，确定引导颜色。
3. 沿该颜色的引导像素链（每步水平或垂直跳 2 格到下一个同色像素）追踪路径，直至路径末端。
4. 找到路径末端相邻的同色远端图形，裁剪其包围框。
5. 测试该裁剪是否等于其左右镜像翻转。若对称：用该颜色填充对应封闭轮廓的全部内部黑色像素。若不对称：该轮廓内部保持黑色不变。
6. 灰色轮廓、引导路径、远端图形在输出中保持原样不变。

**关键洞察**：引导路径不是装饰，它建立了封闭区域与远端图形之间的一一映射；远端图形的几何对称性是一个隐式布尔开关，决定对应区域是否被着色。仅看单个示例可能误以为"所有区域都填充"或"特定颜色才填充"，必须对比多个示例才能归纳出对称性才是真正的门控条件。

## 新题 2：多源射线碰撞与邻接支撑清洗

**组合逻辑**：[填充/fill] + [射线延伸/ray_extend] + [开口朝向/opening_direction] → 碰撞解决（创新：距离优先规则，源题中射线不存在多源碰撞） → [擦除/erase + 邻接不足则删除/delete_unsupported]

**来源原语**：填充、射线延伸、杯形轮廓、开口、开口朝向、开口决定延伸向（来自 d4f3cd78）；擦除、邻接、邻接不足则删除（来自 7f4411dc）

**依赖链**：填充标记出各杯体内部 → 射线从开口向外延伸形成多条射线 → 不同杯体射线在网格上交叉产生冲突 → 距离近者保留的碰撞规则产生不规则的射线截断 → 截断后的射线残段可能出现孤立像素 → 邻接支撑检测清理这些碎片。六步形成三阶段依赖（生成→冲突解决→清洗），删除冲突解决则不知道保留谁，删除清洗则残留噪点。

多个带开口的杯形结构向外发射同色射线，交叉区域按源距离裁决归属，残余孤立像素被擦除。

**输入结构**：约 18x18 的黑(0)背景网格。包含 2~3 个不同颜色的杯形轮廓（如蓝(1)、红(2)、绿(3)），每个杯体是近似封闭的矩形外框（约 3x3 至 5x5），恰有一条边的中央缺少 1~2 个像素形成开口。不同杯体的开口朝向不同（上、下、左、右）。杯体之间间距足够使射线可以延伸多格。生成约束：至少两个杯体的射线延伸方向存在交叉区域（即一个杯体的射线路径会穿过另一个杯体射线路径所在的行或列）；杯体本身不阻挡其他杯体的射线路径。

**规则**：
1. 对每个杯形轮廓，识别其开口方向（边框缺口所在边的外侧法线方向）。
2. 用该杯体的颜色填充其内部所有黑色像素。
3. 从开口处的每个缺口像素位置出发，沿开口方向向外逐像素延伸射线，直到到达网格边界。所有射线使用其所属杯体的颜色。
4. 碰撞解决：若某个像素被两条或更多来自不同杯体的射线覆盖，保留来自较近杯体（从该杯体开口像素到该碰撞点的曼哈顿步数较少者）的颜色；若距离相等，保留输入中杯体包围框左上角行坐标较小者的颜色（行相同则取列坐标较小者）。
5. 邻接清洗：在所有射线绘制和碰撞解决完成后，检查每个射线像素（不含杯体本身和填充像素）的同色 4-邻居数量。若同色 4-邻居少于 1 个，将该像素擦除为黑(0)。此清洗仅执行一轮，不迭代。

**关键洞察**：单个杯体的射线延伸规则与源题相同，但多杯体共存时射线必然碰撞，碰撞解决产生射线的不规则截断，截断边缘留下的孤立残点需要邻接支撑规则清除。需对比多个示例才能区分"距离优先"与"颜色优先"或"先到先得"等替代规则。

## 新题 3：周期行扩展后标记触发逐行反转

**组合逻辑**：[补全/completion + 周期平移/periodic_translation](保留) → [反转/invert + 逐行独立/row_independent](创新：反转的触发条件不再是"主色"而是"标记像素是否存在"，且标记本身随周期扩展传播)

**来源原语**：补全、周期平移、行图案、周期偏移延续行（来自 53b68214）；反转、逐行独立、主色与背景互换（来自 2de01db2）

**依赖链**：周期扩展将不完整的行图案向下延续 → 扩展过程同时传播了标记像素的位置 → 反转操作以标记像素存在与否为触发条件逐行执行 → 反转改变了行的前景/背景比例，但标记像素本身不参与反转。四步缺一不可：无扩展则下方行为空无法反转，无标记传播则不知道哪些扩展行该反转，无反转则标记无意义。

先按周期规律把行图案补全至满画布，然后含标记的行做前景-背景互换。

**输入结构**：宽 10 的网格，高度 4~6 行（不足 10 行）。背景黑(0)，前景蓝(1)。行中蓝色像素形成带有水平周期偏移的图案：存在一个垂直周期 P（2 或 3）和一个水平偏移量 S（1 或 2），使得第 r+P 行的蓝色像素是第 r 行蓝色像素整体右移 S 格（超出右边界的舍弃）的结果。此外，某些行中恰好有一个红(2)标记像素，位于该行某个黑色位置（不与蓝色重叠）。生成约束：至少一个标记位于原始行中，至少一个标记会通过周期扩展传播到新行中；每行最多一个标记。

**规则**：
1. 创建一个 10x10 的黑色画布，将输入行复制到画布顶部。
2. 从已有行推断垂直周期 P 和水平偏移量 S（方法：找到最小的 P 使得第 r 行蓝色像素右移 S 格后与第 r+P 行匹配）。
3. 对每个缺失行 r（r >= 输入高度），将第 r-P 行的所有像素（包括蓝色和红色标记）右移 S 格复制到第 r 行（超出右边界的像素舍弃，左侧新出现的位置为黑色）。
4. 画布填满后，逐行检查：若该行包含红(2)标记像素，则对该行执行反转——蓝(1)变黑(0)，黑(0)变蓝(1)，红(2)标记保持不变。
5. 不含红色标记的行保持原样不变。

**关键洞察**：红色标记像素看起来只是散落的点，但它随周期扩展规律一起传播，决定了扩展区域中哪些行会被反转。求解者必须先理解周期扩展机制，再意识到标记是反转的开关，最后注意标记自身也服从周期传播——三层逻辑交织在同一个行图案结构中。

## 新题 4：角标裁剪后边界凸缺互补对称化

**组合逻辑**：[裁剪/crop + 角标色决定重涂/corner_color_sets_recolor] → [对称补全/symmetric_complete + 对侧互补/opposite_side_complement](创新：对称补全不再作用于独立的厚实体边界，而是作用于裁剪后暴露的薄图案边缘，凸缺配对方向由角标颜色隐式编码)

**来源原语**：裁剪、角标记像素、边框、中心图案、内部包含、角标色决定重涂（来自 3de23699）；对称补全、凸起、缺口、边界、对侧互补、跨行列投射（来自 8dab14c2）

**依赖链**：角标定位裁剪区域 → 裁剪剥离边框暴露内部图案 → 重涂改变颜色使凸缺特征统一 → 对称补全在重涂后的图案上执行凸缺互补。缺裁剪则图案边缘被框遮蔽无法识别凸缺，缺重涂则双色图案干扰凸缺检测（凸起和缺口可能分属不同颜色），缺对称补全则边界不完整。

用角标定位并裁剪出内部图案，重涂为角标色后，在图案边界上执行凸缺互补对称化。

**输入结构**：约 15x15 的黑(0)背景网格。一个由灰(5)像素构成的单像素宽矩形边框（约 8x8 至 10x10），四角各有一个红(2)像素替代灰色作为角标。边框内部有一个蓝(1)的 4-连通单色图案（约 15~25 像素），该图案的边界上有 2~3 个凸起（向外突出 1 像素的前景点，仅有 1 个同色 4-邻居）和 2~3 个缺口（向内凹入 1 像素的背景点，有 3 个前景 4-邻居）。凸起和缺口不成对出现在对侧——即每个凸起在其行或列跨度的对侧没有对应缺口，每个缺口的对侧也没有对应凸起。生成约束：图案不接触边框；凸起和缺口的投射路径（穿过图案的行或列跨度到达对侧边缘）上没有歧义（每个凸起/缺口的跨度方向唯一确定）。

**规则**：
1. 找到四个红(2)角标像素，确定它们围成的矩形区域。
2. 裁剪该矩形内部区域（不含角标所在的边框行列），得到内部图案。
3. 将裁剪结果中所有非黑像素（蓝色图案）重涂为红(2)。
4. 在重涂后的图案上执行凸缺互补对称化：
   - 凸起处理：找到所有仅有 1 个红色 4-邻居的红色边界像素（凸起）。对每个凸起，确定其突出方向（远离唯一邻居的方向），沿反方向穿过图案的行或列跨度，到达对侧边缘外一格，将该位置设为黑(0)（制造对应缺口）。若对侧已经是黑色则不变。
   - 缺口处理：找到所有有 3 个红色 4-邻居的黑色像素（缺口）。对每个缺口，确定其凹入方向（缺少红色邻居的那一侧），沿该方向穿过图案的行或列跨度，到达对侧边缘外一格，将该位置设为红(2)（制造对应凸起）。
5. 凸起和缺口的处理互不干扰（先收集所有凸起和缺口位置，再统一修改）。
6. 输出为步骤 4-5 完成后的裁剪区域。

**关键洞察**：角标不仅定义裁剪范围，还决定重涂颜色——重涂是对称补全的前提，因为只有统一颜色后才能用邻居计数法正确识别凸起和缺口。凸缺互补的"对侧"是相对于图案自身的行列跨度而言，不是相对于网格边界，这需要对比多个示例（不同形状的图案）才能归纳。

## 新题 5：引导路径选取目标后按象限层序叠加

**组合逻辑**：[路径追踪/path_follow + 终点相邻/endpoint_adjacent](保留) → [裁剪/crop](保留) → [透明叠加/transparent_overlay + 象限位决定层序/quadrant_layer_order](创新：叠加对象不是面板本身，而是路径选取出的目标图形)

**来源原语**：路径追踪、引导像素、棋盘格、环形物体、路径连接、终点相邻（来自 9ba4a9aa）；透明叠加、面板、十字分隔线、图层优先级、象限位决定层序（来自 e99362f0）；裁剪（通用）

**依赖链**：十字分隔线将网格分为四象限 → 每个象限内通过路径追踪选出目标图形（四个象限各选出一个） → 裁剪四个目标图形到相同尺寸 → 按象限位置确定图层优先级叠加为一个画面。缺路径追踪则不知道每个象限选哪个图形（每象限有多个候选），缺象限层序则不知道重叠冲突如何解决。

在十字分割的四象限中各沿引导路径选出一个目标图形，裁剪后按象限层序叠合为输出。

**输入结构**：约 21x21 的网格（奇数尺寸以保证十字线居中）。一条灰(5)全行线和一条灰(5)全列线在网格中心交叉，将网格分为四个大小相等的矩形象限。每个象限内包含：一个 3x3 的棋盘格图案（用橙(7)和黑(0)交替填充），恰好与一个特定颜色的引导像素相邻；该颜色的引导像素以间隔 2 格的直线链延伸，终点相邻一个 3x3 的环形图案（外圈为某颜色，中心为黑(0)）。每个象限中还散布 1~2 个额外的 3x3 环形图案（不同颜色，不与引导路径相邻），作为干扰项。四个象限中被选中的环形图案尺寸相同（均为 3x3），但颜色和内部填充模式不同。生成约束：引导路径不跨越灰色十字线；每个象限内恰好只有一个环形图案与引导路径终点相邻。

**规则**：
1. 识别灰(5)十字分隔线，将网格分为左上、右上、左下、右下四个象限。
2. 在每个象限中，找到棋盘格图案（橙(7)和黑(0)交替的 3x3 区域）及其唯一相邻的引导像素。
3. 沿引导像素颜色链追踪路径（每步沿水平或垂直方向跳 2 格到下一个同色像素），直至路径终端。
4. 找到路径终端相邻的环形图案（3x3，外圈非黑单色，中心黑(0)），裁剪其 3x3 包围框。忽略不与路径终端相邻的其他环形图案。
5. 将四个裁剪结果叠加到一个 3x3 画布上。叠加层序从底到顶为：左下象限的选取结果（最底层）→ 右上 → 左上 → 右下象限的选取结果（最顶层）。
6. 叠加规则：从底层到顶层依次绘制，每层的非黑像素覆盖画布上对应位置的已有像素；黑色像素视为透明，不覆盖。

**关键洞察**：干扰环形图案使得无法跳过路径追踪步骤直接选取目标；象限位置决定图层优先级，但象限包含的是选取逻辑而非最终叠加对象本身——求解者必须先在每个象限内完成路径推理，再将结果汇聚到全局叠加规则中。叠加层序（左下→右上→左上→右下）需要对比多个示例才能排除其他排列。

## 新题 6：印章覆盖后按距离继承边缘线颜色

**组合逻辑**：[印章覆盖/stamp_overlay + 支撑签名匹配/support_match](保留形状匹配，创新：印章不带固有颜色) → [重涂色/recolor + 最近距离/nearest_distance + 标记继承最近源色/marker_inherits_nearest_color](创新：每个像素独立继承，不是整体重涂)

**来源原语**：印章覆盖、空槽位、支撑签名匹配、空位接受印章（来自 e5062a87）；重涂色、边缘线、最近距离、标记继承最近源色（来自 2204b7a8）

**依赖链**：支撑签名匹配确定哪些位置接受印章 → 印章放置在匹配位置创建新的"待着色"像素 → 每个待着色像素根据其到最近边缘线的曼哈顿距离继承颜色 → 同一个印章副本中不同像素可能继承不同颜色。缺印章则无新像素需着色，缺距离继承则不知道着色为何色。关键耦合：印章的空间位置（由支撑匹配决定）直接影响每个像素到边缘线的距离，从而改变着色结果。

在灰色支撑结构中找到匹配空位放置印章模板，每个印章像素按与最近边缘线的距离继承该线颜色。

**输入结构**：约 15x20 的黑(0)背景网格。网格最左列为蓝(1)全列边缘线，最右列为红(2)全列边缘线。网格中散布灰(5)支撑像素，形成若干局部结构。其中一处有一个绿(3)的模板印章图案（3~5 像素的 4-连通形状），紧邻灰色支撑像素；印章的包围框内的灰色像素构成支撑签名。网格其他位置有 2~3 个与该支撑签名匹配的空槽（包围框内灰色像素位置相同，绿色像素位置为黑色）。生成约束：空槽分布在网格的不同水平位置，使得同一印章副本中的不同像素到左右边缘线的最近距离可能不同；模板印章不位于网格正中间（确保其自身也有明确的距离归属）。

**规则**：
1. 识别绿(3)模板印章及其包围框内的灰(5)支撑签名。
2. 从左上到右下扫描候选位置：若候选包围框内每个绿色掩码位置当前为黑(0)，且每个支撑签名位置为灰(5)，则该位置为匹配空槽。
3. 在每个匹配空槽的掩码位置放置占位标记（临时标记为绿(3)）。
4. 对网格上所有绿(3)像素（包括原始模板和新放置的副本），逐像素计算到左边缘线（列 0 蓝色像素）和右边缘线（最右列红色像素）的最小曼哈顿距离。距离计算为该绿色像素到最近的边缘线像素的曼哈顿距离。
5. 若最近边缘线像素为蓝(1)，将该绿色像素重涂为蓝(1)；若为红(2)，重涂为红(2)。若距离相等，重涂为蓝(1)（左侧优先）。
6. 灰色支撑和边缘线保持不变。

**关键洞察**：印章的"颜色"不是预设的，而是由放置位置动态决定的——同一模板的不同副本因处于网格不同水平位置，最终呈现不同的颜色混合。求解者可能先误以为印章颜色固定为绿色，必须对比多个示例中不同位置的印章副本才能发现距离继承规则。

## 新题 7：同色端点行填充后周期铺展至分隔线以下

**组合逻辑**：[同色配对/same_color_pairing + 两端同色整行填充/full_row_fill_endpoints_match](保留) → [平铺/tile + 分隔行/separator_row](创新：平铺的模板不是预设的顶行色序，而是上一步填充操作动态生成的行色序列)

**来源原语**：标记像素、画布边界、同色配对、两端同色整行填充（来自 22eb0ac0）；平铺、顶行色序、分隔行、分隔下循环填色（来自 bd4472b8）

**依赖链**：边界标记的颜色匹配决定哪些行被填充 → 填充行按从上到下的顺序形成一个颜色序列 → 灰色分隔行以下的区域用该序列循环平铺。缺端点匹配则无法确定哪些行被填充（填错行则序列错误），缺平铺则分隔线以下为空。关键耦合：平铺模板是由填充步骤的结果隐式定义的，不是输入直接给出的。

上半区根据左右边界标记是否同色决定整行填充，被填充行的颜色序列成为下半区循环平铺的模板。

**输入结构**：约 15x10 的黑(0)背景网格。网格被一条灰(5)全宽行分为上半区和下半区。上半区有 5~7 行，其中若干行在最左列（列 0）和最右列各有一个前景标记像素；每行的两个标记颜色可能相同也可能不同，使用蓝(1)、红(2)、绿(3)、黄(4)中的颜色。上半区中未标记的行保持全黑。下半区有 4~6 行，全为黑色（待填充）。生成约束：上半区中至少有 2 行端点同色（会被填充），至少有 1 行端点不同色（不会被填充）；同色行的颜色不全相同，确保生成的序列包含至少两种颜色。

**规则**：
1. 找到灰(5)全宽分隔行，划分上半区和下半区。
2. 在上半区中，对每一行检查列 0 和最右列的标记像素颜色：
   - 若两端颜色相同，用该颜色填充该行所有像素（整行变为该颜色）。
   - 若两端颜色不同或该行无标记，保持原样不变。
3. 从上到下收集上半区中被填充的行的颜色，按顺序形成颜色序列 C（如 [蓝, 红, 蓝]）。
4. 在下半区中，从分隔行下方第一行开始，第 k 行（k 从 0 开始）的所有像素填充为 C[k mod len(C)]。
5. 灰色分隔行保持不变。上半区中未被填充的行（端点不同色的行）保持原样。

**关键洞察**：下半区的平铺模板并非直接可见——它由上半区的端点匹配结果间接产生。求解者必须先解出哪些行"通过了"同色测试，再将这些行的颜色按序排列才能得到铺展模板。单看一个示例可能猜出模板但无法确定模板的来源规则（是所有标记行？是同色行？按什么顺序？），需对比多个示例排除错误假设。

## 新题 8：互补拼合后由共享标记对齐粘贴到目标窗口

**组合逻辑**：[平移/translate + 无重叠拼合/non_overlap_pack + 最密堆叠最小框/densest_minimal_bbox](保留拼合逻辑) → [平移粘贴/translate_and_paste + 共享标记点/shared_marker_pixel + 标记点偏移对应/marker_offset_correspondence](创新：拼合结果不直接输出，而是作为精灵体粘贴到目标窗口中)

**来源原语**：平移、精灵体、无重叠拼合、互补拼合、最密堆叠最小框（来自 681b3aeb）；平移粘贴、精灵窗口、空白窗口、共享标记点、标记点偏移对应（来自 2f0c5170）

**依赖链**：两块拼图通过平移找到最密无重叠拼合 → 拼合结果中包含一个标记像素 → 目标窗口中也有同色标记像素 → 以标记像素为对齐锚点将拼合结果粘贴到目标窗口。缺拼合则不知道两块的相对位置（精灵体形状未定），缺标记对齐则不知道拼合结果放在目标窗口的哪个位置。关键耦合：拼合改变了标记像素在结果中的相对位置，从而影响最终的粘贴偏移量。

先将两块拼图件密堆拼合，再以拼合体内的标记像素为锚点对齐粘贴到目标窗口中。

**输入结构**：约 18x18 的灰(5)背景网格。包含三个区域：两个分离的单色拼图件（一个蓝(1)，一个红(2)，各约 4~8 像素的 4-连通不规则形状），以及一个由橙(7)像素填充的矩形目标窗口（约 7x7 至 9x9）。蓝色拼图件内恰好有一个像素被替换为绿(3)标记；目标窗口内也恰好有一个绿(3)标记像素。红色拼图件内无标记。三个区域互不相邻，各自被灰(5)背景隔开。生成约束：两个拼图件的最密无重叠拼合结果的包围框不超过目标窗口尺寸；拼合结果在标记对齐后完全落在目标窗口内部。

**规则**：
1. 分别裁剪蓝(1)拼图件（包含绿(3)标记）和红(2)拼图件到各自的包围框。绿(3)标记视为蓝色件的一部分（占据一个像素位置）。
2. 尝试所有可能的相对平移，找到两个裁剪件的无重叠放置方式中，包围框面积最小的放置（即最密拼合）。若面积相同，选包围框宽度较小的；仍相同则选蓝色件在左上方的放置。
3. 在拼合结果中定位绿(3)标记像素的坐标（相对于拼合包围框的左上角）。
4. 在目标窗口中定位绿(3)标记像素的坐标（相对于窗口左上角）。
5. 计算平移偏移量，使拼合结果中的绿色标记与窗口中的绿色标记重合。
6. 将拼合结果平移粘贴到目标窗口中：蓝(1)和红(2)像素覆盖窗口中对应位置的橙(7)像素；绿(3)标记位置也写入绿(3)。窗口中未被覆盖的位置保持橙(7)。
7. 输出为目标窗口区域的裁剪（不含窗口外的背景和拼图件原始位置）。

**关键洞察**：拼合步骤确定两块拼图的相对位置，但不确定它们在目标窗口中的绝对位置——绝对位置由标记像素的对齐关系决定。标记像素同时属于蓝色拼图件（参与拼合几何计算）和对齐系统（决定粘贴偏移），这种双重角色使两步推理不可分割。

## 新题 9：连线成三角后内部按距离渐变填色

**组合逻辑**：[连线/draw_line + 端点连接/endpoint_connection + 补斜边底边成三角/draw_edges_form_triangle](保留三角轮廓生成) → [填充/fill](创新：不是单色填充，而是按到各边的距离梯度填色) + [重涂色/recolor + 最近距离/nearest_distance](创新：距离度量从边缘线改为三角形的三条边)

**来源原语**：连线、竖条、画布边界、端点连接、补斜边底边成三角（来自 3bd67248）；填充、封闭区域（来自 d4f3cd78）；重涂色、最近距离、标记继承最近源色（来自 2204b7a8）

**依赖链**：竖条确定三角形的一条边 → 连线补全斜边和底边形成完整三角形轮廓 → 三条边各有不同颜色 → 三角形内部每个像素按到三条边的最近距离继承最近边的颜色。缺连线则三角不完整无法确定内部区域，缺距离重涂则内部为空。

将竖条补全为三色三角轮廓，再用每个内部像素到最近边的距离决定其填充颜色。

**输入结构**：约 12x12 的黑(0)背景方形网格。列 0 有一条蓝(1)全高竖条（从第 0 行到最后一行）。其余位置全为黑色。生成约束：网格为正方形（保证斜边为 45 度对角线，简化距离计算）。

**规则**：
1. 保留列 0 的蓝(1)竖条（三角形的左边）。
2. 从网格右上角 (0, W-1) 向左下角 (H-1, 0) 画一条红(2)对角线（每步行+1、列-1，经过的像素设为红(2)）。对角线与竖条共享的端点 (0,0) 和 (H-1,0) 保持原色（蓝(1)不被覆盖）。
3. 在最底行（行 H-1）从列 1 到列 W-1 画一条绿(3)底边。底边与对角线共享的端点 (H-1, W-1) 位置：如果对角线未经过该点则为绿(3)，否则保持红(2)（先画的不被覆盖——实际上对角线终点是 (H-1,0)，不会冲突）。
4. 识别三角形内部区域：所有被蓝色左边、红色斜边、绿色底边围成的黑色像素。
5. 对每个内部像素，计算它到三条边（蓝色左边、红色斜边、绿色底边）上所有像素的最小曼哈顿距离，分别记为 d_蓝、d_红、d_绿。
6. 将该内部像素涂为距离最小的那条边的颜色。若两条边距离相等，优先级为：蓝(1) > 红(2) > 绿(3)。
7. 三条边本身的颜色保持不变。

**关键洞察**：三角形的三条边不只是轮廓——它们是三个"颜色源"，内部形成类似 Voronoi 的分区。求解者必须先理解连线规则补全三角形，再发现内部填充遵循最近边继承而非单色填充。仅看一个示例可能误以为是按行或按列渐变，必须对比不同尺寸的网格示例才能确认是距离驱动的。

## 新题 10：棋盘格源沿路径抵达带孔对象后形状匹配填孔

**组合逻辑**：[路径追踪/path_follow + 引导像素/guide_pixel](保留路径机制) → [形状匹配/shape_matching + 归一化形状对应/normalized_match](创新：匹配的不是独立的标记形状，而是路径源对象的形状与目标孔洞的形状) → [填充/fill + 带孔对象/object_with_holes](保留孔洞填充)

**来源原语**：路径追踪、引导像素、棋盘格、路径连接、终点相邻（来自 9ba4a9aa）；形状匹配、归一化形状对应、带孔对象、填充、忽略干扰项（来自 42f14c03）；裁剪（通用）

**依赖链**：路径追踪确定哪个源对象与哪个带孔对象关联 → 源对象的形状裁剪后归一化 → 与目标对象的各孔洞形状做归一化匹配 → 匹配成功的孔洞用源对象的引导路径颜色填充。缺路径则不知道源和目标的配对关系（有多个源和多个目标），缺形状匹配则不知道填哪个孔（目标可能有多个孔），缺路径颜色信息则不知道填什么色。

沿引导路径将源图形与带孔目标关联，源图形的归一化形状决定填充目标的哪个孔洞，填充色为引导路径颜色。

**输入结构**：约 20x20 的黑(0)背景网格。包含 2~3 个灰(5)单色"源图形"（各为 3~6 像素的 4-连通不规则形状，形状各不相同），以及 1~2 个较大的橙(7)单色"目标对象"（约 5x5 至 7x7 包围框的 4-连通形状，内部有 2~3 个黑色孔洞，每个孔洞也是 4-连通区域）。每个源图形恰好与一个引导像素相邻，引导像素以间隔 2 格的直线链延伸至某个目标对象附近（终点与目标对象相邻）。不同的引导路径使用不同颜色（如蓝(1)、红(2)、绿(3)）。每个源图形的包围框裁剪经归一化（平移到原点）后，恰好与其路径所指向的目标对象的某一个孔洞的形状完全匹配。不匹配的孔洞保持黑色。网格中可能存在不与任何路径相连的额外灰色图形作为干扰项。生成约束：每个目标对象的各孔洞形状互不相同；每个源图形只匹配一个孔洞；不同源图形的路径可以指向同一个目标对象。

**规则**：
1. 识别所有灰(5)源图形和橙(7)目标对象。
2. 对每个源图形，找到其唯一相邻的引导像素，记录引导颜色，沿同色链追踪路径至终端。
3. 找到路径终端相邻的目标对象。
4. 裁剪源图形的包围框，将非黑像素位置归一化为相对坐标集合 S。
5. 在目标对象的包围框内，找到所有黑色孔洞连通区域。对每个孔洞，将其像素位置归一化为相对坐标集合 H。
6. 若 S == H（坐标集合完全相同），则用该源图形的引导路径颜色填充该孔洞。
7. 不匹配的孔洞保持黑色。未被任何路径连接的灰色图形（干扰项）不影响输出。
8. 输出为整个网格的副本，仅孔洞填充位置发生变化，其余所有元素（源图形、引导路径、目标对象、干扰项）保持原样。

**关键洞察**：路径追踪解决"谁配谁"，形状匹配解决"填哪个孔"，引导颜色解决"填什么色"——三个问题的答案分别来自三个不同的信息来源（路径拓扑、几何形状、颜色属性），必须全部正确推理才能得到输出。干扰项的存在迫使求解者只信任路径连接的源图形，而非所有灰色形状。
