## 新题 1：可达性门控的对角射线

**组合逻辑**：[泛洪填充](已有) + [射线延伸·对角](已有，创新：由可达性决定是否激活) + [擦除](已有，创新：擦除不可达标记) → 可达性判定充当射线激活的逻辑门

**来源原语**：泛洪填充/可达性/墙壁障碍/角落标记/边界连通区分结构(8f3a5a89)，射线延伸/对角邻接/对角标记(7ddcd7ec/d07ae81c)，擦除(252143c9/8f3a5a89)

**依赖链**：泛洪填充确定哪些区域可达 → 可达性判定筛选哪些标记像素被激活 → 被激活的标记根据对角方向指示像素发射射线 → 不可达标记被擦除。删除可达性判定则不知道哪些标记发射射线；删除射线延伸则可达性判定无处输出；删除对角指示则射线无方向。

从角落出发泛洪填充判定区域可达性，仅对可达区域内的标记像素按对角方向发射射线至网格边缘，擦除不可达区域的标记。

**输入结构**：约 15x15 的网格，背景为黑(0)。蓝(1)墙壁线段将网格分隔为若干不规则区域（墙壁为单像素宽的 4-连通线段，部分连接网格边界形成封闭或半封闭分隔）。网格某一角落有一个品红(6)单像素（起始标记）。在不同区域内各有一个彩色标记像素（取自红(2)、绿(3)、黄(4)中的不同颜色，每区域至多一个标记），每个标记像素恰好有一个同色的对角邻居像素（位于标记的四个对角方向之一），作为方向指示。生成约束：每个标记的方向指示像素也在同一区域内；不同区域的标记颜色互不相同；至少有一个区域被墙壁完全隔开（从角落不可达）。

**规则**：
1. 从品红(6)角落标记出发，对黑(0)背景像素做 4-连通泛洪填充，蓝(1)墙壁阻止扩散。标记所有可达的背景像素。
2. 判定每个彩色标记像素的可达性：若该标记的某个 4-邻居是可达背景像素，则该标记为"活跃"；否则为"不活跃"。
3. 对每个活跃标记，从标记位置沿其方向指示像素所指的对角方向（标记→方向指示像素的偏移方向继续延伸），逐像素绘制射线，将路径上的黑(0)像素涂为该标记的颜色，直至射线离开网格边界或遇到非黑(0)像素（遇到时停止，不涂该终点像素）。
4. 擦除所有不活跃标记及其方向指示像素（设为黑(0)）。
5. 擦除品红(6)角落标记（设为黑(0)）。活跃标记的方向指示像素保留。

**关键洞察**：墙壁同时承担两个角色——既定义泛洪填充的可达边界（决定哪些标记被激活），又充当射线的终止障碍。一个隐藏在墙壁后面的标记既不可达也不会发射射线，必须对比多个示例才能确认"不可达则擦除"这条规则。

## 新题 2：压缩解码隐藏字形折线

**组合逻辑**：[压缩](已有) → [解码指令·字形](已有，创新：字形被行列膨胀隐藏，须先压缩才可辨认) → [画折线](已有，创新：颜色来自字形颜色)

**来源原语**：压缩/重复行/重复列/相邻相同/相同行列合并(ce8d95cc)，解码指令/字形指令/顺序读取/起始标记/编码映射(136b0064)，画折线/连线(136b0064)

**依赖链**：原始网格中字形被行列重复膨胀至不可辨认 → 压缩还原真实尺寸后字形才可识别 → 按顺序读取字形的像素面积解码为移动指令 → 从起始标记画出折线。不压缩则字形失真无法解码；不解码则无移动方向；不画线则无输出。

对行列膨胀的网格做压缩以还原隐藏的 3x3 字形指令，再按字形面积编码画出彩色折线。

**输入结构**：约 20x20 的网格，背景为黑(0)。整个网格是一个较小网格（约 9x9）经行列重复膨胀得到的：每组连续相同行重复 2-4 次，每组连续相同列重复 2-4 次，不同区域的膨胀倍数可以不同。在膨胀前的小网格中，存在 3-4 个互不相邻的 3x3 彩色字形（每个字形为单一颜色的 4-连通图形，颜色取自红(2)、绿(3)、蓝(1)、橙(7)，各字形颜色互不相同），以及一个灰(5)单像素作为起始标记。字形的像素面积（着色像素数）在 3-6 之间，各不相同。生成约束：膨胀前的小网格中，字形之间至少间隔 1 行 1 列背景；起始标记不在任何字形的 3x3 区域内。

**规则**：
1. 从上到下扫描，将连续相同的行合并为一行；再从左到右扫描，将连续相同的列合并为一列。得到压缩后的小网格。
2. 在压缩后的小网格中，识别所有非黑(0)、非灰(5)的 4-连通组件，每个组件即为一个字形。
3. 按行优先顺序读取字形（以各字形边界框左上角坐标排序：先比较行号，行号相同则比较列号）。
4. 每个字形的像素面积编码一个移动指令：面积 3 = 向右移动 2 格，面积 4 = 向下移动 2 格，面积 5 = 向左移动 3 格，面积 6 = 向上移动 3 格。
5. 在一个与压缩后小网格同尺寸的纯黑(0)输出网格上，从灰(5)起始标记的压缩后位置开始，依次执行各字形的移动指令。每步移动时，将路径上经过的所有像素（含起点、含终点）涂为该指令对应字形的颜色。后绘制的颜色覆盖先绘制的。
6. 灰(5)起始标记在输出中不保留（被折线颜色覆盖，或若起始点无后续经过则保持为该点第一段的颜色）。

**关键洞察**：膨胀使字形在原始网格中被拉伸变形为不可识别的色块，压缩是解锁指令解码的前置条件而非装饰性操作。必须对比多个示例才能确定面积-方向的映射表。

## 新题 3：孔洞拓扑分流滑动，滑动距离编码重涂长度

**组合逻辑**：[滑动·拓扑分流](已有) + [重涂色](已有，创新：重涂长度由滑动距离决定) ← [有孔者升无孔者降](已有，提供分流条件) + [碰撞停止](已有)

**来源原语**：滑动/堆叠/封闭对象/开放对象/封闭孔洞/有孔者升无孔者降/碰撞停止/分离(ac2e8ecf)，重涂色/间距编码尾长(696d4842)，路径对象(696d4842)

**依赖链**：孔洞拓扑判定分流方向（上/下） → 滑动并碰撞停止确定最终位置 → 原位置与终位置的行差即滑动距离 → 从每个对象的尾端（滑动方向的反向端）起重涂该距离数量的像素为黄(4)。不做拓扑分类则不知方向；不滑动则无距离；无距离则不知重涂范围。

按孔洞拓扑将对象分流向上或向下滑动，再以每个对象的滑动行距决定从其尾端重涂多少像素。

**输入结构**：约 15x15 的网格，背景为黑(0)。散布 4-6 个单色 4-连通前景对象，每个对象 4-8 像素，颜色取自红(2)、蓝(1)、绿(3)、橙(7)、灰(5)，各对象颜色互不相同。部分对象为封闭框形（边界框内至少存在一个被该对象像素完全包围的黑(0)孔洞），其余为开放线形（无孔洞）。各对象互不相邻（任意两个对象的像素之间至少有 1 格黑(0)间隔）。生成约束：各对象在水平投影上至少有部分重叠，保证滑动时会发生至少一次堆叠碰撞；每个对象距其滑动方向的边界至少 2 行，保证都会产生非零滑动距离。

**规则**：
1. 判定每个对象的拓扑类型：若对象的边界框内存在被该对象像素完全 4-连通包围的黑(0)连通区域，则为"封闭"型；否则为"开放"型。
2. 封闭型对象向上滑动，开放型对象向下滑动。滑动时保持每个对象的形状、颜色和水平位置不变。
3. 在同一滑动方向内，按对象在原始输入中距目标边界的距离从近到远依次处理（即向上滑动的对象中，原始位置最靠上的先滑动）。每个对象沿其方向逐行移动，直至其任意像素接触网格边缘或已固定的其他对象像素的相邻行（碰撞停止，对象不重叠）。
4. 计算每个对象的滑动距离 D = 该对象边界框顶行在滑动前后的行号之差的绝对值。
5. 对每个对象，从其"尾端"开始重涂像素为黄(4)。尾端定义：向上滑动的对象的尾端为其最底行，向下滑动的对象的尾端为其最顶行。从尾端逐行向对象内部推进，将遇到的对象像素涂为黄(4)，直至已涂黄的像素总数达到 D 或该对象所有像素已全部涂黄。
6. 输出最终网格（背景保持黑(0)）。

**关键洞察**：重涂范围不是输入中显式标注的，而是从滑动距离涌现——滑动距离本身取决于所有对象的拓扑分类和空间排列，因此单个对象的重涂结果依赖于全局布局。需要对比多个示例才能发现"滑动行距 = 重涂像素数"的隐藏映射。

## 新题 4：对角射线分割区域，图例按面积排名上色

**组合逻辑**：[射线延伸·对角](已有，创新：射线充当分隔线) → [计数·面积](已有) → [面积比较·排名](已有，创新：排名映射到图例) ← [图例](已有，创新：图例颜色按排名分配而非按象限)

**来源原语**：射线延伸/对角线激活/标记像素(d07ae81c)，计数/面积比较/封闭区域/分隔线/极值区域分别涂色(6455b5f5)，图例/象限对应图例颜色(58743b76，创新为排名对应图例颜色)

**依赖链**：标记像素发射对角射线 → 射线成为分隔线将网格划分为若干区域 → 计算每个区域面积并排名 → 按排名从图例中取色填充对应区域。删除射线则无分隔；删除面积计数则不知排名；删除图例则无颜色分配。

标记像素发射对角射线将网格切割成区域，按各区域面积从小到大排名，依次从角落图例取色填充。

**输入结构**：约 14x14 的网格，背景为黑(0)。网格左上角有一个 1xK 的水平图例条（K = 3 或 4），每个像素为不同颜色，取自蓝(1)、绿(3)、橙(7)、品红(6)，从左到右排列。图例下方和右方为主区域。主区域内有 2-3 个红(2)标记单像素，位置互不在同一行、同一列或同一对角线上。生成约束：图例条紧贴左上角（第 0 行，第 0 列起），占据第 0 行的前 K 列；标记像素不在第 0 行也不在前 K 列内；标记像素的对角射线产生的区域数量恰好等于 K；各区域面积互不相等。

**规则**：
1. 从每个红(2)标记像素出发，沿 NW-SE 和 NE-SW 两条对角线方向延伸射线至网格边缘，将路径上的黑(0)像素涂为红(2)。射线遇到已有红(2)射线像素时继续穿过（射线可交叉）。射线不覆盖图例像素。
2. 红(2)射线与网格边缘共同将主区域（排除图例所占的第 0 行前 K 列）划分为若干封闭区域。每个区域由被红线和/或网格边缘包围的黑(0)连通分量定义（4-连通）。
3. 计算每个区域的面积（黑(0)像素数）。
4. 按面积从小到大排名：面积最小的区域排名 1，次小排名 2，以此类推。
5. 排名为 k 的区域，其所有黑(0)像素涂为图例条中第 k 个颜色（从左到右，第 1 个即最左）。
6. 红(2)射线像素和标记像素保持红(2)不变。图例条保持不变。

**关键洞察**：标记像素的位置同时决定了射线几何形状和区域划分拓扑——移动一个标记会同时改变所有区域的面积和排名，从而改变每个区域的颜色分配。图例的读取顺序是固定的（左到右），但它映射到的区域由面积排名动态决定，必须对比多个示例才能确认排名-图例映射关系。

## 新题 5：泛洪填充分区提取图案，面积优先级透明叠加

**组合逻辑**：[泛洪填充](已有，创新：用于分区提取而非描边) + [透明叠加](已有，创新：叠加优先级由区域面积决定) ← [面积比较](已有，提供优先级判据)

**来源原语**：泛洪填充/墙壁障碍/封闭区域/可达性(8f3a5a89)，透明叠加/标记像素/同尺寸对齐/标记无冲突合并/共享底色(25e02866)，面积比较/计数(6455b5f5)

**依赖链**：墙壁将网格分为若干封闭区域 → 泛洪填充识别各区域边界并提取内部图案 → 计算各区域面积确定叠加优先级 → 将所有图案按相对坐标对齐后透明叠加，冲突时面积大者胜。不分区则无法提取独立图案；不计面积则冲突无法解决；不叠加则图案分散无输出。

墙壁分隔的多个封闭区域各含一个小图案，将它们按区域面积决定的优先级透明叠加为单一输出图案。

**输入结构**：约 16x16 的网格，背景为黑(0)。灰(5)墙壁线段将网格分为 3-4 个矩形封闭区域，区域大小各不相同。每个区域内部有一个由彩色像素构成的小图案（3x3 至 5x5 的边界框），图案由若干非黑(0)、非灰(5)像素构成，颜色取自红(2)、蓝(1)、绿(3)、黄(4)、橙(7)。所有图案的边界框尺寸相同（如都是 4x4）。每个图案在其所在区域内的相对位置（图案左上角到区域左上角的偏移）相同。图案之间有部分像素位置重叠（同一相对坐标处，不同图案有不同颜色的非背景像素）也有部分互补（某图案有颜色而另一图案在该位置为背景）。生成约束：不存在三个或更多图案在同一相对坐标处都有非背景像素的情况（即冲突仅发生在两两之间）。

**规则**：
1. 识别灰(5)墙壁，通过 4-连通泛洪填充从每个区域的任意黑(0)像素出发，找到该区域内所有黑(0)连通像素，从而确定各封闭区域的范围。
2. 计算每个区域的面积（该区域内黑(0)像素总数，不含墙壁和图案像素；或等价地，该连通分量的像素数）。
3. 从每个区域中提取图案：找到区域内所有非黑(0)、非灰(5)像素，将它们的坐标归一化为相对于图案边界框左上角的局部坐标。
4. 创建一个与图案边界框同尺寸的纯黑(0)输出网格。
5. 按区域面积从小到大的顺序，依次将每个区域的图案绘制到输出网格上：将该图案的每个非背景像素写入输出网格的对应局部坐标，覆盖该位置的已有颜色。
6. 最终输出即为叠加完成的小网格。

**关键洞察**：面积最大的区域的图案拥有最高绘制优先级（因为最后绘制，覆盖先前的），但这一优先级规则隐含在区域几何中，不在图案本身。改变墙壁位置会改变区域面积比，从而翻转冲突像素的胜负——必须对比不同墙壁布局的示例才能归纳出面积优先规则。

## 新题 6：外部标记定朝向旋转后压缩提取核心图案

**组合逻辑**：[旋转·外部标记定朝向](已有) → [压缩](已有，创新：在旋转后的结果上执行，旋转与压缩不可交换) ← [裁剪](已有，前置步骤)

**来源原语**：旋转/裁剪/实心矩形/外部标记像素/内部标记像素/标记颜色对应/外部标记决定朝向(94133066)，压缩/重复行/重复列/相邻相同/相同行列合并(ce8d95cc)

**依赖链**：裁剪提取主矩形 → 外部标记与内部标记的相对位置决定旋转角度 → 旋转后矩形中行列重复结构才沿正确轴对齐 → 压缩去除重复行列得到最终小图案。不裁剪则背景干扰；不旋转则重复行列方向错误导致压缩结果错误（旋转与压缩不可交换）；不压缩则图案仍被膨胀。

裁剪主矩形、按外部标记旋转到正确朝向后，压缩去重行列提取隐藏的核心小图案。

**输入结构**：约 17x17 的网格，背景为黑(0)。网格中心偏移位置有一个单色实心矩形（蓝(1)填充，尺寸约 10x12 或 12x10 等非正方形），矩形内部有若干彩色像素作为内部标记（2-3 个，颜色取自红(2)、绿(3)，各标记颜色在矩形内出现恰好一次）。矩形外部有同样颜色的单像素外部标记（每种颜色恰好一个），散布在背景中。矩形内部的蓝(1)图案包含行列重复膨胀结构：某些连续行完全相同，某些连续列完全相同（膨胀倍数 2-3）。关键：这些重复结构仅在矩形被旋转到正确朝向后才表现为"连续相同行/列"；在错误朝向下，重复方向与行列轴不平行，压缩操作无法正确去重。生成约束：只有一个旋转角度（0/90/180/270 之一）能使内部标记的归一化相对位置与外部标记的归一化相对位置匹配；在该正确旋转下，裁剪后的矩形至少有 3 组连续相同行和 3 组连续相同列。

**规则**：
1. 在输入网格中找到蓝(1)实心矩形的边界框，裁剪出该矩形（含内部标记像素）。
2. 找到矩形内所有出现恰好一次的颜色像素（内部标记），以及网格外部同色的单像素（外部标记）。
3. 将内部标记像素的相对坐标（相对于内部标记集合的左上角）归一化，将外部标记像素的相对坐标（相对于外部标记集合的左上角）归一化。
4. 找到唯一的旋转角度（0°/90°/180°/270°），使得旋转后的内部标记归一化坐标与外部标记归一化坐标完全一致。
5. 对裁剪出的矩形施加该旋转。
6. 在旋转后的矩形上，从上到下扫描将连续完全相同的行合并为一行，再从左到右扫描将连续完全相同的列合并为一列。
7. 输出压缩后的小矩形。

**关键洞察**：旋转与压缩不可交换——在错误朝向下压缩会得到完全不同的结果，因为膨胀的重复方向只在正确朝向下与行列轴平行。外部标记提供的朝向信息是解锁正确压缩的钥匙。

## 新题 7：四向对齐检测生成射线锚点与方向

**组合逻辑**：[四向对齐·缺失中心检测](已有，创新：中心不仅标色，还成为射线锚点) + [射线延伸·对角](已有，创新：方向由额外指示像素给出) → 检测机制的输出作为射线机制的输入

**来源原语**：四向对齐/微型条/隐含十字/缺失中心(9f5f939b)，射线延伸/对角邻接/对角标记/锚角对角射线至边(7ddcd7ec)，重涂色(recolor)

**依赖链**：四向微型条对齐检测 → 定位隐含十字的缺失中心 → 中心成为射线锚点 → 对角方向指示像素决定射线方向 → 射线从锚点延伸至边缘。不做四向检测则不知锚点在哪；不知锚点则射线无起点；无方向指示则射线无方向。两个检测机制（十字检测 + 方向指示读取）交汇于锚点。

检测四向对齐微型条的隐含中心作为射线锚点，由独立的对角指示像素确定射线方向，从锚点向网格边缘画对角射线。

**输入结构**：约 15x15 的网格，背景为黑(0)。若干蓝(1)的两像素水平条和两像素垂直条散布在网格中。部分条构成四向对齐的隐含十字：在某个背景像素（中心）的上方 2-3 格有一个垂直条、下方 2-3 格有一个垂直条、左方 2-3 格有一个水平条、右方 2-3 格有一个水平条（即中心与每个条之间恰好有 1 格背景间隔）。另有一些蓝(1)条不构成完整十字（孤立条或仅有两三个方向有对齐条）。在每个真正的十字中心的四个对角邻居位置中，恰好有一个放置了红(2)单像素（方向指示）。生成约束：存在 2-3 个完整的隐含十字，它们之间距离足够远（边界框不重叠）；不完整的条组不会和任何十字共享条；每个十字的红(2)指示像素不与其他十字的条重叠。

**规则**：
1. 扫描所有黑(0)背景像素，检测四向对齐的隐含十字中心：一个黑(0)像素 P，若在其正上方偏移 2-3 行处有蓝(1)垂直两像素条、正下方偏移 2-3 行处有蓝(1)垂直两像素条、正左方偏移 2-3 列处有蓝(1)水平两像素条、正右方偏移 2-3 列处有蓝(1)水平两像素条，则 P 是隐含十字中心。（条的偏移量须满足：中心 P 与条的最近像素之间恰有 1 格黑(0)间隔。）
2. 将每个检测到的中心 P 涂为黄(4)。
3. 对每个中心 P，检查其四个对角邻居（右上、右下、左下、左上）中哪个为红(2)。该红(2)像素相对于 P 的偏移方向即为射线方向。
4. 从中心 P 出发，沿该对角方向逐像素延伸，将路径上的黑(0)像素涂为绿(3)，直至离开网格边缘。若路径上遇到非黑(0)像素（如蓝(1)条），跳过该像素继续延伸（射线穿透已有对象）。
5. 移除所有红(2)方向指示像素（设为黑(0)）。非十字的孤立蓝(1)条保持不变。

**关键洞察**：十字检测和方向指示是两个独立的信息来源，必须在锚点处交汇才能确定射线。蓝(1)条的双重角色——既构成十字结构（定位锚点），又作为网格中的障碍物被射线穿透——需要对比示例才能发现射线对蓝色像素的穿透规则。

## 新题 8：互补形状配对确定嵌套层序与层厚

**组合逻辑**：[形状匹配·互补](已有，创新：匹配结果决定嵌套分配而非填充) → [嵌套包裹·逐层构建](已有，创新：层厚由匹配到的源形状像素数决定) ← [计数](已有，提供层厚数值)

**来源原语**：形状匹配/模板缺口/源形状/互补形状/缺口形状唯一配对(18447a8d)，嵌套包裹/同心正方形层/逐层构建/色条/条高决定框厚(45a5af55)，计数(6455b5f5)

**依赖链**：模板缺口形状与源形状一一配对 → 配对确定每个源形状的颜色分配到哪一嵌套层（由模板从上到下的顺序决定） → 每个源形状的像素数决定其对应层的厚度 → 逐层从内到外构建同心方框。不配对则不知颜色-层映射；不计数则不知层厚；不构建则无输出。

模板缺口与源形状互补配对，模板的排列顺序决定嵌套层序，匹配到的源形状像素数决定每层厚度，最终构建同心方框。

**输入结构**：约 18x12 的网格，背景为黑(0)。左半区自上而下排列 3-4 个灰(5)填充的矩形模板（每个约 5x5），模板之间由至少 1 行背景分隔。每个模板内部有一个独特形状的黑(0)缺口（3-6 像素的 4-连通区域，形状各不相同，如 L 形缺口、线形缺口、角形缺口等）。右半区散布同样数量的彩色小图形（源形状），每个源形状为单一颜色的 4-连通区域（3-6 像素），颜色取自红(2)、蓝(1)、绿(3)、橙(7)，各源形状颜色互不相同，像素数也互不相同。每个源形状的归一化形状恰好与某个模板缺口的归一化形状完全一致（一一对应）。生成约束：源形状在右半区的垂直排列顺序与模板在左半区的顺序不同（打乱），以确保求解者必须通过形状匹配而非位置对应来配对。

**规则**：
1. 对每个模板，提取其缺口形状：模板边界框内所有黑(0)像素的坐标，归一化为相对于缺口边界框左上角的局部坐标集合。
2. 对每个源形状，提取其形状：所有该颜色像素的坐标，归一化为相对于边界框左上角的局部坐标集合。
3. 将每个源形状与归一化形状完全相同的唯一模板缺口配对。
4. 按模板在左半区从上到下的顺序（以模板边界框顶行从小到大排序），将配对的源形状排成序列。序列中第一个（最上方模板对应的源形状）为最内层，最后一个为最外层。
5. 最内层源形状的像素数 N1 决定中心实心正方形的边长为 N1（用该源形状的颜色填充）。
6. 后续每个源形状的像素数 Nk 决定该层同心方框的厚度为 Nk（用该源形状的颜色绘制）。每层方框紧贴包裹在前一层外部。
7. 输出仅包含构建好的同心方框结构，背景为黑(0)，尺寸由各层厚度之和决定（总边长 = N1 + 2*(N2 + N3 + ...)）。

**关键洞察**：源形状的像素数承担双重角色——几何形状决定它匹配哪个模板（从而确定嵌套层序），像素数量决定该层的厚度。一个 5 像素的 L 形和一个 5 像素的线形会产生不同的层分配但相同的层厚。

## 新题 9：可达性擦除伪装碎片后对称补全被遮挡区域

**组合逻辑**：[泛洪填充·可达性](已有) → [擦除·装饰碎片](已有，创新：擦除的目的是为后续对称检测清除干扰) → [对称补全](已有，创新：在擦除后的干净图案上执行) — 两种不同的"修复"机制串联，顺序不可交换

**来源原语**：泛洪填充/可达性/墙壁障碍/角落标记/装饰碎片/边界连通区分结构/擦除(8f3a5a89)，对称补全/双轴反射对称/标记矩形/标记遮挡区域(0934a4d8)

**依赖链**：角落泛洪填充确定可达性 → 不与边界连通的墙色碎片被识别为装饰并擦除 → 擦除后的图案恢复为（除标记矩形外的）双轴对称结构 → 利用对称性补全标记矩形覆盖的区域。不做可达性擦除则装饰碎片破坏对称性导致补全失败；不做对称补全则遮挡区域内容未知。两步修复的顺序不可交换（先补全后擦除会在仍有干扰的情况下做对称推断，结果错误）。

先通过可达性分析擦除伪装墙壁碎片以恢复对称结构，再利用双轴对称性补全被标记矩形遮挡的区域。

**输入结构**：约 13x13 的网格，背景为黑(0)。主体为一个由蓝(1)像素构成的图案，占据网格大部分区域，该图案本应具有水平和垂直双轴反射对称性。图案上有两种破坏：(a) 若干蓝(1)装饰碎片——它们是蓝(1)像素组成的小连通区域（2-4 像素），不与网格边界上的蓝(1)结构连通（即不是主体结构的一部分），散布在图案内部或边缘；(b) 一个品红(6)实心矩形（约 3x3 至 4x4）覆盖了图案的一部分，遮挡了下方的真实像素。网格某一角落有一个红(2)单像素（可达性起始标记）。生成约束：如果移除所有装饰碎片并将品红矩形下方恢复为正确像素，整个蓝(1)图案具有关于网格中心的水平和垂直反射对称性；装饰碎片的位置使得不擦除它们时，图案不具有任何轴的反射对称性；品红矩形不覆盖对称中心点。

**规则**：
1. 从红(2)角落标记出发，对黑(0)背景像素做 4-连通泛洪填充，蓝(1)像素阻止扩散。标记所有可达背景像素。
2. 识别所有蓝(1)连通分量。若一个蓝(1)连通分量的任何像素都不位于网格边界行/列上（即不与边界接触），则该分量为装饰碎片。将装饰碎片的所有像素擦除为黑(0)。
3. 移除红(2)角落标记（设为黑(0)）。
4. 现在网格中仅剩主体蓝(1)图案（含被品红(6)遮挡部分）和黑(0)背景。确定对称轴：找到使可见蓝(1)像素（忽略品红区域内的位置）满足水平反射对称的行号 r_axis，以及满足垂直反射对称的列号 c_axis。
5. 对每个品红(6)像素，找到其关于 r_axis 的水平反射位置和关于 c_axis 的垂直反射位置。若某个反射位置不被品红覆盖，则取该反射位置的颜色（蓝(1)或黑(0)）赋给当前品红像素。若水平和垂直反射位置都被品红覆盖，则取关于 (r_axis, c_axis) 的 180° 旋转对称位置的颜色。
6. 输出修复后的完整网格。

**关键洞察**：两种损伤需要两种不同的修复策略，且修复顺序严格固定——装饰碎片会打断对称性检测，必须先清除。可达性分析与对称补全在源题中是完全独立的操作，这里通过"碎片破坏对称→擦除碎片恢复对称→对称驱动补全"的因果链紧密耦合。

**组合逻辑**：[解码指令·字形面积](已有，创新：解码为滑动方向而非折线方向) + [滑动·区域内](已有，创新：滑动指令来自字形而非图例) ← [颜色关联区域](已有，连接字形与目标区域) + [顺序读取](已有，决定指令执行顺序)

**来源原语**：解码指令/字形指令/顺序读取/编码映射(136b0064)，重力下落/滑动/封闭区域/可移动像素/碰撞停止/颜色关联区域(88e364bc)

**依赖链**：按顺序读取字形 → 字形面积解码为移动方向 → 字形颜色关联到特定封闭区域 → 该区域内的可移动像素按解码方向滑动一步 → 下一条字形指令可能对同一区域再次操作，此时像素位置已被上一步改变。不解码则不知方向；不做颜色关联则不知指令作用于哪个区域；不按顺序执行则最终位置错误（中间状态依赖累积）。

读取字形指令序列，每条指令的颜色指定目标区域、面积编码滑动方向，按顺序逐条执行区域内像素滑动。

**输入结构**：约 18x14 的网格，背景为黑(0)。一条灰(5)垂直分隔线将网格分为左右两半。左半区：自上而下排列 4-6 个 3x3 的字形（每个字形为单一颜色的 4-连通图形），字形之间由至少 1 行背景分隔。字形颜色取自红(2)、蓝(1)、绿(3)（可重复——同一颜色可出现在多个字形中，表示对同一区域的多次操作）。每个字形的像素面积在 3-6 之间。右半区：由彩色墙壁线段围成 2-3 个封闭矩形区域，每个区域的墙壁颜色分别为红(2)、蓝(1)、绿(3)中的一种（与字形颜色对应）。每个区域内部有若干黄(4)可移动像素散布在黑(0)背景上。生成约束：每个区域的墙壁颜色唯一标识该区域；区域内黄(4)像素不紧贴墙壁（至少有 1 格移动空间）；字形面积-方向映射在所有示例中一致：面积 3 = 上，面积 4 = 右，面积 5 = 下，面积 6 = 左。

**规则**：
1. 在左半区，按从上到下的顺序（以字形边界框顶行排序）读取所有字形，形成指令序列。
2. 对每条指令：
   a. 字形颜色 C 确定目标区域——右半区中墙壁颜色为 C 的封闭区域。
   b. 字形像素面积解码为移动方向：3 = 上，4 = 右，5 = 下，6 = 左。
   c. 将目标区域内所有黄(4)像素同时沿该方向滑动 1 格。若某黄像素滑动后会碰到墙壁或另一个黄像素的当前位置，则该像素不移动（碰撞停止）。所有像素的碰撞判定基于本步开始时的状态，而非逐个像素移动后的中间状态。
3. 按顺序执行完所有指令后，输出仅右半区的内容（去除灰(5)分隔线和左半区），保留墙壁和最终位置的黄(4)像素。

**关键洞察**：字形不再绘制折线而是充当封闭区域内像素的移动遥控指令，同一颜色的多个字形意味着同一区域的多次操作——后续指令基于前序指令修改后的状态执行，导致顺序敏感的累积效应。必须对比多个示例才能建立面积-方向映射表和颜色-区域关联规则。
