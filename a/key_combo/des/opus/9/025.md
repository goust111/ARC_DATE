## 新题 1：多源对角射线的交叉计数驱动角落三角形

**组合逻辑**：[射线延伸/对角方向](创新：多源点同时发射双对角线，交叉点成为涌现的计数目标) + [轨迹交叉](创新：不同源射线的重叠产生交叉标记) → [计数/计数决定尺寸](创新：按象限统计交叉点数量) → [填充/三角区域](创新：交叉计数驱动对应角落的三角形边长)

**来源原语**：
- 射线延伸(ray_extend)、对角方向(diagonal_dir)、过像素画双对角线(both_diags_through_pixel)、孤立像素(isolated_pixel)、画布边界(canvas_boundary) -- 623ea044
- 轨迹交叉(trail_intersection) -- ac605cbb
- 计数(counting)、计数决定尺寸(count_determines_size)、三角区域(triangle_region)、角落控制点(corner_control) -- 902510d5
- 擦除(erase) -- 902510d5

**依赖链**：多个孤立像素各自向四个对角方向发射射线至边界 → 不同源像素的射线在空间上交叉产生交叉点（涌现现象，任何单源都无法产生）→ 以网格中心为分界将交叉点按四个象限统计 → 每个象限的交叉点计数成为对应角落三角形的边长 → 角落控制标记被擦除并替换为三角形

输入中散布的孤立像素各自画出双对角线；由此涌现的交叉点被按象限计数，每个象限的计数转化为对应角落的实心直角三角形的边长。

**输入结构**：
- 黑(0)背景，约15x15的正方形网格
- 散布3~5个孤立前景像素，每个像素颜色从蓝(1)、红(2)、绿(3)中选取（允许同色重复），彼此不在同一行、同一列、同一条对角线上
- 网格四角(即(0,0)、(0,W-1)、(H-1,0)、(H-1,W-1))各有一个灰(5)像素作为角落控制标记
- 生成约束：所有孤立像素距网格边界至少2格；各像素位置保证四个象限中至少有三个象限包含交叉点；网格高和宽均为奇数，使中心行和中心列唯一确定

**规则**：
1. 对每个孤立前景像素，沿四个对角方向（左上、右上、左下、右下）画射线至网格边界，射线颜色为该像素自身的颜色。射线覆盖经过的每个像素；若该像素已有颜色（来自其他射线），后绘制的覆盖先绘制的
2. 射线全部绘制完成后，标记交叉点：逐像素检查，若某个像素同时被来自两个或以上不同源像素的射线经过（不论最终显示什么颜色），则该像素为交叉点，将其重涂为黄(4)
3. 以网格中心行和中心列为分界线，将网格划分为四个象限（左上、右上、左下、右下）；中心行和中心列上的交叉点不计入任何象限
4. 分别统计四个象限内的黄(4)交叉点数量，记为 N_左上、N_右上、N_左下、N_右下
5. 擦除四角的灰(5)标记像素（恢复为黑(0)）
6. 在每个角落绘制边长为对应N值的实心直角三角形，颜色为橙(7)：直角顶点在角落像素处，两条直角边分别沿该角落的两条网格边界方向延伸。三角形区域定义为：从角落出发，行距离r与列距离c满足 r+c < N 的所有像素。若N=0则不绘制
7. 三角形像素覆盖该区域内已有的任何颜色（射线色、交叉点色）

**关键洞察**：交叉点不存在于输入中——它们是多条对角射线叠加后的涌现结构。求解者必须先绘制所有射线并追踪每个像素被哪些源经过，才能识别交叉点、完成象限计数、最终确定三角形尺寸。

## 新题 2：反弹射线穿越空心矩形激活方向敏感的棋盘格填充

**组合逻辑**：[射线延伸/反弹路径/边界反射](已有) → [包含判定](创新：射线是否穿过矩形内部作为激活条件) → [填充/棋盘格图案](创新：棋盘格的两色排列由射线进入矩形时的水平运动方向决定)

**来源原语**：
- 反弹路径(bouncing_path)、边界反射(boundary_reflection)、起点像素(start_pixel) -- e179c5f4
- 空心矩形(hollow_rect)、棋盘格图案(checkerboard)、包含(containment) -- df8cc377
- 填充(fill) -- a699fb00
- 重涂色(recolor) -- 7e02026e

**依赖链**：起点像素发射反弹对角射线 → 射线在网格边界间来回弹跳 → 射线路径穿过某些空心矩形的内部区域 → 被穿过的矩形被"激活"→ 射线首次进入每个矩形内部时的水平分量方向（向右或向左）决定棋盘格的起始颜色排列

一条从起点像素出发的反弹对角射线在网格边界间往复弹跳；射线穿过空心矩形内部即激活该矩形，在其内部填入棋盘格图案，棋盘的颜色排列由射线进入时的水平方向决定。

**输入结构**：
- 黑(0)背景，约20x20网格
- 一个蓝(1)像素作为起点，位于网格中不属于任何矩形的位置
- 3~4个不重叠的空心矩形，边框为灰(5)，边框厚度1像素，内部为黑(0)；每个矩形的内部高和宽均为奇数（3~7像素），保证存在中心格
- 生成约束：矩形之间至少间隔2格；起点不在任何矩形的内部或边框上；反弹射线路径至少穿过2个矩形的内部，且至少有1个矩形未被穿过

**规则**：
1. 从蓝(1)起点像素出发，初始方向为右上（行-1，列+1），逐步画蓝(1)射线
2. 射线到达网格左或右边界时水平方向反转；到达上或下边界时垂直方向反转；到达角落时水平和垂直方向同时反转。射线在经过的每个像素上画蓝(1)，但不改变灰(5)边框像素的颜色
3. 射线遇到灰(5)矩形边框像素时穿透继续（不视为反射壁），仅在网格四边反射
4. 射线行进至路径回到起点位置时停止；若路径长度超过200步仍未回到起点，也停止
5. 判定每个空心矩形是否被激活：若射线路径中至少有一个像素落在该矩形的内部（不含边框），则该矩形被激活
6. 对每个被激活的矩形，确定射线首次进入其内部时的水平运动方向：
   - 若该步水平分量向右（列坐标增大），则棋盘格A模式——内部左上角格为红(2)，与之行列坐标奇偶性相同的格为红(2)，不同的格为绿(3)
   - 若该步水平分量向左（列坐标减小），则棋盘格B模式——内部左上角格为绿(3)，与之行列坐标奇偶性相同的格为绿(3)，不同的格为红(2)
7. 棋盘格仅填充矩形内部中射线未经过的黑(0)像素；射线经过的内部像素保持蓝(1)
8. 未被激活的矩形保持原样（内部全黑）

**关键洞察**：反弹射线的几何轨迹同时编码了两类信息——"哪些矩形被激活"和"以什么颜色排列填充"——这两个判定不可分离，因为它们都取决于射线穿越矩形的具体路径段。

## 新题 3：十字标记臂色频次筛选生成桥接控制序列

**组合逻辑**：[图案识别/计数](创新：十字标记的臂色频次筛选出有效标记子集) → [重排](创新：有效标记按空间位置排列为控制序列) → [连线桥/bridge_drawing](创新：桥色由出发标记的臂色决定，非固定色)

**来源原语**：
- 十字标记(plus_marker)、图案识别(pattern_recognition)、计数(counting)、重复色为答案(repeated_color_answer)、忽略干扰项(ignore_distractors)、中心与臂颜色(center_and_arm_color) -- 642d658d
- 连线桥(bridge_drawing)、带框方块(framed_square)、控制序列(control_sequence)、访问顺序编码(visitation_order_encoding)、行列对齐(row_column_alignment)、最近优先(nearest_preferred) -- 3e6067c3
- 擦除(erase) -- df8cc377

**依赖链**：识别所有黄心十字标记并统计各臂色出现次数 → 出现次数>=2的臂色为有效色，对应标记被保留 → 保留标记按列坐标排序形成控制序列 → 按序列顺序在上半区的带框方块之间画桥 → 干扰标记被擦除

带框方块散布在网格上半部分，十字标记散布在下半部分；识别出臂色重复出现的十字标记后，按其列位置从左到右排列成控制序列，依次连接内部色匹配的带框方块。

**输入结构**：
- 黑(0)背景，约18x18网格
- 上半区（前9行）：4~5个带框方块，每个3x3像素（含边框），边框为灰(5)，内部1x1像素为各不相同的填充色，从蓝(1)、红(2)、绿(3)、橙(7)、栗(9)中选取；方块之间互不接触
- 下半区（后9行）：6~8个十字标记，每个由黄(4)中心像素和四个正交相邻的同色臂像素组成；臂色从蓝(1)、红(2)、绿(3)、橙(7)、栗(9)中选取（同色可出现在多个标记中）；标记之间互不重叠
- 生成约束：恰好有2~3种臂色出现在2个或以上十字标记中（有效色），其余臂色各只出现1次（干扰项）；每种有效色恰好匹配上半区一个带框方块的内部填充色；各十字标记的中心列坐标互不相同

**规则**：
1. 识别所有十字标记：黄(4)中心像素且四个正交邻居存在且颜色相同（非黑非黄）
2. 统计每种臂色出现在多少个十字标记中。出现次数>=2的臂色为"有效色"
3. 擦除所有臂色非有效色的十字标记（将其5个像素恢复为黑(0)）
4. 将保留的十字标记按中心列坐标从小到大排序，读取臂色形成控制序列 [c1, c2, ..., ck]
5. 按控制序列依次连接带框方块：对每对相邻颜色 (ci, ci+1)，找到内部填充色为 ci 的方块 Si 和内部填充色为 ci+1 的方块 Si+1
6. 在 Si 与 Si+1 之间画桥：比较两方块中心的行差和列差，选择差值较小的维度作为桥的延伸方向（若行差<=列差则画水平桥，否则画垂直桥）；桥为1像素宽的直线段，颜色为 ci，连接两方块边框之间的间隙部分
7. 若同一方块被多次访问，多条桥可连接到该方块的不同边

**关键洞察**：十字标记既是待识别的图案对象，又是隐式的控制指令编码器。干扰标记的存在迫使求解者先通过频次统计完成筛选，才能从保留标记的空间排列中读取桥接顺序——跳过识别步骤则无法确定控制序列。

## 新题 4：计数器编码旋转角度决定宏块图案与填充颜色

**组合逻辑**：[计数/计数器像素](已有) → [旋转/整体旋转](创新：旋转对象是宏块级布尔图案而非像素网格) → [填充/重涂色](创新：旋转后最靠左上的激活块行号索引填充颜色)

**来源原语**：
- 宏块格阵(macro_block_grid)、标记激活块(marker_activates_block)、中心标记触发(center_marker_trigger) -- ce22a75a
- 旋转(rotate)、整体旋转(whole_grid_rotate) -- ed36ccf7
- 计数器像素(counter_pixel)、计数(counting)、计数决定偏移(count_determines_offset)、计数器消失(counter_disappears) -- e48d4e1a
- 擦除(erase) -- 902510d5

**依赖链**：读取右侧计数器列的灰像素数量N → 将宏块激活图案视为4x4布尔矩阵 → 对该矩阵逆时针旋转N x 90度 → 旋转后扫描布尔矩阵找到最靠左上的激活位置 → 该位置的行索引决定填充色 → 按旋转后的图案重新绘制激活宏块

宏块网格中灰色中心标记定义了一个激活图案；右侧计数器的灰像素数量决定逆时针旋转角度；旋转后的激活图案被重新绘制，而填充颜色由旋转结果中最靠左上角的激活块的行位置索引决定。

**输入结构**：
- 黑(0)背景，12x15网格
- 左侧12x12区域是4x4的宏块格阵，每个宏块3x3像素。部分宏块的中心格（即宏块内坐标(1,1)处）为灰(5)表示"激活"，对应宏块其余8格为黑(0)；未激活的宏块全部为黑(0)
- 右侧3列（列12~14）是计数器区域：每列内容相同，从第0行开始连续若干格为灰(5)，其余为黑(0)；灰像素数量N取值1、2或3
- 生成约束：4x4宏块激活图案为非对称图案（90度/180度/270度旋转后至少有一种结果与原图案不同）；激活的宏块数量为3~6个

**规则**：
1. 读取右侧计数器区域中灰(5)像素的行数 N（只需计一列，三列内容相同）
2. 将左侧4x4宏块激活图案抽象为布尔矩阵B（4x4，激活=1，未激活=0）
3. 将B逆时针旋转 N x 90度，得到旋转后矩阵B'
4. 在B'中按行优先、列其次的顺序（从第0行第0列开始，逐行扫描），找到第一个值为1的位置(r, c)
5. 根据r的值确定填充颜色：r=0时蓝(1)、r=1时红(2)、r=2时绿(3)、r=3时黄(4)
6. 输出为12x12网格（右侧计数器区域去除）：对B'中值为1的每个位置，将对应的3x3宏块整体填充为步骤5确定的颜色；其余宏块保持全黑

**关键洞察**：计数器的值通过旋转角度间接影响填充颜色——不同的旋转将不同的激活块推到最靠左上的位置，改变行索引从而改变颜色。求解者不能跳过旋转直接确定颜色，因为颜色依赖于旋转后的空间布局。

## 新题 5：精灵体按尺寸嵌入空腔后标记像素的切比雪夫连接

**组合逻辑**：[嵌入填充/尺寸匹配/唯一槽位配对](已有) → [连线/切比雪夫最短路径](创新：连接端点是嵌入操作后重新定位的标记像素) → [重涂色](创新：每段路径颜色由出发端标记所在精灵体的主体色决定)

**来源原语**：
- 嵌入填充(inlay_fill)、模板框架(template_frame)、精灵体(sprite)、矩形空腔(rectangular_cavity)、尺寸匹配(size_matching)、唯一槽位配对(unique_slot_pairing) -- 5dbc8537
- 连线(connect)、路径(path)、起终点之间(between_endpoints)、切比雪夫最短路径(chebyshev_shortest) -- 992798f6
- 标记像素(marker_pixel) -- ac605cbb
- 重涂色(recolor) -- 7e02026e

**依赖链**：识别模板框架中的矩形空腔及外部精灵体 → 按尺寸一一匹配将精灵体嵌入空腔 → 嵌入改变了精灵体内标记像素的绝对坐标 → 以嵌入后的标记像素新坐标为端点，沿切比雪夫最短路径依次连线 → 每段路径颜色取自出发端标记所在精灵体的主体色

模板框架中的矩形空腔与外部精灵体按尺寸一一匹配后嵌入；每个精灵体内含一个黄色标记像素；嵌入后标记像素获得新坐标，依次以切比雪夫最短路径连接相邻标记，路径颜色取自出发端精灵体的主体色。

**输入结构**：
- 黑(0)背景，约18x20网格
- 网格中央偏左有一个灰(5)大型模板框架（约10x12的实心灰色区域），内部包含3个矩形空腔（黑(0)区域），尺寸各不相同（如2x3、3x2、2x4等，高x宽）
- 模板框架外侧（右方或下方）有3个矩形精灵体，每个由一种主体色填充（分别为蓝(1)、红(2)、绿(3)，各不相同），尺寸分别与三个空腔一一匹配
- 每个精灵体内恰好有1个像素为黄(4)（标记像素），其余像素为该精灵体的主体色
- 生成约束：精灵体与空腔的尺寸匹配唯一确定；三个空腔在模板内从上到下排列（上方空腔的最高行 < 下方空腔的最高行），保证连接顺序明确

**规则**：
1. 识别灰(5)模板框架的边界框（最小包围所有灰像素的矩形），以及框架内部的黑(0)矩形空腔（四连通黑色区域，且四周被灰色像素包围）
2. 识别模板外部的精灵体：框架边界框外的非黑非灰四连通区域，每个区域的边界框尺寸即为精灵体尺寸
3. 将每个精灵体与尺寸完全匹配的空腔配对，然后将精灵体的所有像素（含黄色标记）平移嵌入空腔的左上角对齐位置
4. 嵌入完成后，找到三个黄(4)标记像素的新坐标，按行坐标从小到大排序为 P1、P2、P3
5. 对每对相邻标记 (Pi, Pi+1) 画切比雪夫最短路径（king-move路径）：先沿对角方向（同时缩小行差和列差）移动 min(|delta_row|, |delta_col|) 步，再沿剩余轴直线移动补足差值
6. P1到P2的路径颜色为P1所在精灵体的主体色；P2到P3的路径颜色为P2所在精灵体的主体色
7. 路径像素仅绘制在黑(0)背景像素上；若路径需经过非背景像素（灰边框或精灵体内部像素），该像素颜色不变，路径跳过该像素继续绘制后续步
8. 输出保留完整的模板框架、嵌入后的精灵体及连接路径

**关键洞察**：精灵体嵌入空腔后标记像素的坐标发生了不可预测的变化，连接路径的走向完全依赖于嵌入结果——求解者不能在嵌入前预判路径，必须先完成匹配和嵌入才能确定标记的最终位置。

## 新题 6：并列面板的三类并集掩码驱动颜色分化的克罗内克自积

**组合逻辑**：[透明叠加/布尔并集](创新：并集不只区分前景/背景，还区分仅左/仅右/重叠三类) → [克罗内克积](创新：并集掩码作为自积核，但每个核像素的展开副本使用不同颜色) → [颜色互换](创新：颜色由核像素的来源类别决定而非统一前景背景互换)

**来源原语**：
- 透明叠加(transparent_overlay)、布尔并集合并(boolean_union)、并列面板(side_by_side_panel)、前景掩码(foreground_mask)、逐格对齐(cell_alignment) -- dae9d2b5
- 克罗内克积(kronecker_product)、二值掩码(binary_mask)、块阵列(block_array)、前景背景互换填充(fg_bg_inverted_fill) -- 8e2edd66

**依赖链**：左右并列面板各自的前景掩码逐格对齐 → 产生三类标记（仅左贡献、仅右贡献、双面板重叠）→ 三类标记的并集构成二值掩码 → 该掩码对自身做克罗内克积展开 → 展开时每个核前景像素的副本内前景色由该核像素的来源类别决定（三色分化）

两个并列面板的前景掩码做三类并集得到一个小型二值图案；该图案对自身做克罗内克积展开为大网格，展开时每个种子像素的来源类别（仅左/仅右/重叠）决定其副本中的前景颜色。

**输入结构**：
- 黑(0)背景，3x6网格，由两个3x3面板左右并列组成
- 左面板（列0~2）：部分像素为蓝(1)，其余为黑(0)；前景像素3~4个
- 右面板（列3~5）：部分像素为红(2)，其余为黑(0)；前景像素3~4个
- 生成约束：两面板在对应位置（列偏移3）至少有1格重叠（两侧都有前景），且至少各有1格仅单侧有前景；并集图案（3x3）中前景占3~6格

**规则**：
1. 将输入在列方向中点（列3）分为左右两个3x3面板
2. 逐格对齐两面板（左面板(r,c)对应右面板(r,c+3)），将3x3的每个位置标记为四类之一：
   - "仅左"(L)：左面板该位置有前景、右面板对应位置无前景
   - "仅右"(R)：右面板该位置有前景、左面板对应位置无前景
   - "重叠"(O)：两面板对应位置都有前景
   - "空"(E)：两面板对应位置都无前景
3. 构建3x3并集掩码U：L、R、O位置为前景(1)，E位置为背景(0)
4. 对U执行克罗内克自积，输出9x9网格。对U中每个位置(i,j)：
   - 若U(i,j)=0（背景），则输出中对应的3x3块全部为黑(0)
   - 若U(i,j)=1（前景），则输出中对应的3x3块放置U的一份副本，其中副本内前景像素的颜色由(i,j)的来源类别决定：类别L用蓝(1)、类别R用红(2)、类别O用品红(6)；副本内背景像素为黑(0)
5. 输出最终的9x9网格

**关键洞察**：两面板独立时各自只有简单的前景掩码，但它们的并集产生了一个涌现的二值结构，成为克罗内克积的核。更关键的是颜色不是均匀的——每个核像素的来源类别（仅左/仅右/重叠）赋予其展开副本不同的着色方案，使最终图案同时编码了结构信息和来源信息。

## 新题 7：格线缺失交叉点定位数据区后列像素计数构建金字塔

**组合逻辑**：[裁剪/背景色空洞/四角围合](已有) → [计数/提取](创新：裁剪区内前景像素按列统计，计数值编码金字塔参数) → [堆叠/居中金字塔/奇数宽度递增](创新：列计数拆解为1+3+5+...序列构建底部对齐的并排金字塔)

**来源原语**：
- 裁剪(crop)、网格线(lattice_line)、缺失交叉点(missing_intersection)、四角围合(four_corner_bound)、背景色空洞(background_hole) -- a644e277
- 堆叠(stack)、居中金字塔(centered_pyramid)、基线对齐(baseline_aligned)、奇数宽度递增(odd_width_increment)、前景列像素(column_pixels) -- 3d6c6e23
- 计数(counting) -- 642d658d
- 纯色单元格(solid_cell)、格内判定(cell_interior_test) -- 458e3a53

**依赖链**：在格线网格中找到四个背景色空洞交叉点 → 确定裁剪矩形 → 裁剪区内的格线单元格包含前景像素 → 按单元格列统计每列的前景像素总数（必须为完全平方数）→ 分解为1+3+5+...奇数行宽序列 → 在输出中底部对齐并排构建金字塔

格线网格中四个背景色空洞标定裁剪区域；区域内各列的前景像素总数为完全平方数，分解为奇数宽度行序列后在输出底部构建并排金字塔。

**输入结构**：
- 黑(0)背景，约17x17网格
- 灰(5)色格线形成规则网格：水平线和垂直线均为1像素宽，间距为3（即每两条相邻平行线之间有2像素宽的单元格空间）；格线将网格分割为多个2x2像素的单元格
- 大部分格线交叉点（水平线与垂直线的交汇像素）为灰(5)，但恰好4个交叉点为黑(0)（背景色空洞），这4个点构成一个轴对齐矩形的四角
- 该矩形围定区域内的部分单元格含有前景像素，颜色从蓝(1)、红(2)、绿(3)中选取；同一单元格列内所有前景像素颜色相同
- 生成约束：裁剪区域包含2~4列单元格；每列中前景像素的总数为完全平方数（1、4或9）；不同列可以有不同的平方数和不同的颜色

**规则**：
1. 识别灰(5)格线的所有交叉点：同时属于某条水平线和某条垂直线的灰像素
2. 找到其中4个为黑(0)的交叉点位置，确定它们围成的矩形的行范围和列范围
3. 裁剪该矩形（含边界格线）内的所有内容
4. 在裁剪区内，按单元格列逐列扫描（从左到右），统计每个单元格列j中所有前景像素（非黑非灰）的数量Nj和颜色Cj
5. 对每列计算金字塔层数 Lj = sqrt(Nj)（Nj保证为完全平方数）
6. 构建输出网格：
   - 输出高度 = max(Lj)（所有列中最高的金字塔层数）
   - 每个金字塔的最大底行宽度 = 2*Lj - 1；金字塔之间有1列黑(0)间隔
   - 输出宽度 = 所有金字塔底行宽度之和 + (列数-1) 个间隔列
7. 对第j列金字塔（Lj层），从底部第1行开始：底行宽度2*Lj-1居中绘制，第2行宽度2*Lj-3居中绘制，...，顶行宽度1；颜色为Cj
8. 所有金字塔底部对齐，按原始裁剪区中的列顺序从左到右排列

**关键洞察**：缺失交叉点不是视觉缺陷而是数据区域的定位标记；数据区域内的像素数量编码了金字塔的结构参数——这层编码关系只有在完成裁剪并统计后才能被发现和利用。

## 新题 8：完整对称图案的壳色远程决定虚线段间隙填充颜色

**组合逻辑**：[补全/形状匹配](创新：完整图案不再补全局部拷贝，而是作为颜色参数的远程提供者) → [填充/单像素间隙补填](创新：间隙填充颜色不固定，由最近完整图案的壳色动态指定) → [擦除](创新：完整图案完成颜色传递后从输出中移除)

**来源原语**：
- 补全(completion)、对称图案(symmetric_motif)、模板精灵体(template_sprite)、形状匹配(shape_match)、完整图案推断缺失(motif_infers_missing) -- 72322fa7
- 填充(fill)、虚线段(dashed_segment)、邻接(adjacency)、单像素间隙补填(single_gap_filled) -- a699fb00
- 擦除(erase) -- 902510d5
- 标记像素(marker_pixel) -- ac605cbb

**依赖链**：识别完整3x3对称图案（中心色+壳色+壳掩码）→ 每条水平虚线段寻找距自身最近的完整图案 → 取该图案的壳色作为间隙填充色 → 填充虚线段中的所有单像素间隙 → 最后擦除所有完整图案

水平虚线段中的单像素黑色间隙需要补填，但补填颜色不固定——每条虚线段取其最近的完整对称图案的壳色作为填充色；填充完成后所有图案从输出中消失。

**输入结构**：
- 黑(0)背景，约15x20网格
- 3~4条水平虚线段，每条由同一种颜色的前景像素水平排列组成（颜色从蓝(1)、绿(3)、橙(7)中选取），相邻同色像素之间间隔恰好1格黑(0)像素；不同虚线段颜色可相同也可不同；每条虚线段包含5~11个像素位置（含间隙）
- 2~3个完整的3x3对称图案散布在网格中，与虚线段不重叠不相邻：每个图案有1个中心像素和至少4个对称分布的壳像素（壳像素在中心的正交和/或对角邻居位置，满足四重旋转对称或双轴镜像对称）；中心色为灰(5)，不同图案的壳色各不相同，从红(2)、黄(4)、品红(6)中选取
- 生成约束：每条虚线段有唯一最近的完整图案（按虚线段中间像素到图案中心的曼哈顿距离，无平局）；壳色与任何虚线段自身颜色不相同

**规则**：
1. 识别所有完整3x3对称图案：灰(5)中心像素周围有至少4个同色非灰非黑壳像素，壳像素位置关于中心满足四重旋转对称或双轴镜像对称
2. 识别所有水平虚线段：同色非黑像素沿水平方向排列，相邻同色像素之间恰好间隔1格黑(0)像素，虚线段至少包含3个同色像素
3. 对每条虚线段，确定其中间像素的坐标（虚线段所有像素按列排序后取中间位置的像素），计算该坐标到每个完整图案中心的曼哈顿距离，取距离最小的图案
4. 读取该最近图案的壳色，将虚线段中所有单像素黑(0)间隙（左邻和右邻都是虚线段同色像素的黑像素）填为该壳色
5. 所有虚线段处理完毕后，擦除所有完整图案（将图案占据的9个像素全部恢复为黑(0)）
6. 输出保留虚线段原始像素、间隙填充像素及其他未涉及的背景像素

**关键洞察**：完整对称图案在输出中完全消失——它们的唯一作用是为附近的虚线段远程提供间隙填充颜色。图案是"一次性颜色指令"：求解者必须先识别图案并提取壳色，再通过距离匹配确定每条虚线段的归属，最后才能执行填充和擦除。
