## 新题 1：微缩蓝图指挥分区洪泛

**组合逻辑**：[洪泛填充](已有) + [自相似/少数图案为蓝图](创新：从网格单元级缩放改为区域级颜色指派) + [四连通分区/分隔墙](已有) + [忽略干扰项](已有)

**来源原语**：洪泛填充(a5313dff, 782b5218), 自相似/少数图案为蓝图(b99e7126), 四连通分区/分隔墙(782b5218), 忽略干扰项(782b5218, 494ef9d7)

**依赖链**：灰(5)墙将网格分割为若干四连通区域 → 面积最小的区域内含一个微缩色块矩阵，其行列数与非蓝图区域数量匹配 → 微缩矩阵中每个色块的颜色指定了对应区域的填充色 → 非蓝图区域内已有的散落干扰像素被填充色覆盖 → 蓝图区域自身在输出中被清为黑(0)

将灰墙分割出的各区域按其微缩蓝图中的颜色指派进行洪泛填充，蓝图区域自身清空。

**输入结构**：
- 网格约 15x15，黑(0)背景。
- 灰(5)像素构成单像素宽的连通墙壁，将网格分割为 5~7 个四连通区域（含一个蓝图区域）。墙壁可接触网格边界。
- 蓝图区域：面积最小的区域（边界框不超过 4x4），内部包含一个 KxL 的色块矩阵（K*L = 非蓝图区域数），每个色块恰好 1 像素，颜色取自 {蓝(1), 红(2), 绿(3), 黄(4), 品红(6), 橙(7), 青(8)}，不含灰(5)和黑(0)。色块之间无间隔，紧密排列于蓝图区域的左上角。
- 非蓝图区域：大部分像素为黑(0)，其中散落 1~3 个随机颜色的干扰像素（颜色可能与蓝图中指定的填充色不同）。
- 生成约束：每个非蓝图区域的面积至少 6 像素；蓝图区域严格为面积最小的区域；蓝图色块矩阵的行列由区域数分解决定（优先接近正方形的分解）。

**规则**：
1. 识别灰(5)墙壁像素，将所有非灰像素按四连通划分为若干区域。
2. 找到面积最小的区域作为蓝图区域。若多个区域面积并列最小，取边界框左上角行号最小的，再按列号最小的。
3. 将剩余区域按照其边界框左上角位置排序：先按行号升序，行号相同按列号升序，编号为 1, 2, ..., N。
4. 读取蓝图区域内的色块矩阵，按逐行从左到右的顺序读出 N 个颜色值 c1, c2, ..., cN。
5. 将区域 i 内的所有非灰像素（包括原有干扰像素）重涂为 ci。
6. 将蓝图区域内的所有非灰像素重涂为黑(0)。
7. 灰(5)墙壁像素保持不变。

**关键洞察**：面积最小的分区不是普通填充对象，而是一张微缩地图——它的色块序列编码了其余所有区域各自应当填充的颜色。必须对比多个示例才能发现蓝图区域的选取标准（面积最小）和色块到区域的映射顺序（左上角排序）。

## 新题 2：色系感知的对角射线碰撞

**组合逻辑**：[射线延伸](创新：从单方向延伸改为四对角方向同时发射) + [同色系配对](创新：从水平滑动配对改为射线穿透/阻挡判定) + [碰撞阻挡](创新：从竖条滑动碰撞改为射线交叉碰撞) + [重涂色](已有)

**来源原语**：射线延伸/对角方向(5c0a986e), 同色系配对(494ef9d7), 碰撞阻挡(3906de3d), 重涂色(a740d043)

**依赖链**：每个种子向四对角发射射线 → 同色系射线互相穿透 → 异色系射线首次交叉时双方停止 → 碰撞点颜色由行进距离较短的射线决定 → 未碰撞（抵达边界）的射线保留为其种子颜色

在黑背景上从彩色种子发射对角射线，同色系射线互不阻挡，异色系射线碰撞后双双截止并标记碰撞点。

**输入结构**：
- 网格约 13x13，黑(0)背景。
- 3~5 个孤立的彩色种子像素，颜色属于两个色系：暖色系 {红(2), 橙(7), 黄(4)} 和冷色系 {蓝(1), 绿(3), 青(8)}。每个色系至少有 1 个种子。
- 种子间距至少 3 像素（切比雪夫距离），保证射线有足够延伸空间。
- 无其他前景像素。
- 生成约束：任意两个异色系种子之间至少存在一条对角碰撞路径；不存在三条射线同时交于一点的情况。

**规则**：
1. 从每个种子像素向四个对角方向（左上、右上、左下、右下）各发射一条射线。射线逐像素延伸，每步行进距离 +1。
2. 按步数从小到大同步推进所有射线。在每一步中：
   a. 若一条射线的下一个像素已超出网格边界，该射线停止在当前位置。
   b. 若一条射线的下一个像素与另一条**不同色系**的射线的下一个像素重合，两条射线均停止，重合像素为碰撞点。
   c. 同色系的射线若路径重合，后到的射线覆盖先到的颜色（但双方均不停止，继续延伸）。
3. 碰撞点颜色规则：取两条碰撞射线中行进步数较少的那条射线的颜色。若步数相等，取暖色系射线的颜色。
4. 非碰撞射线路径上的像素涂为该射线的种子颜色。
5. 种子像素保持原色不变。
6. 处理顺序：所有射线同步推进；同一步内若发生多次碰撞，各碰撞独立处理。

**关键洞察**：射线的穿透或阻挡不取决于空间障碍物，而取决于射线来源的色系归属——这一隐式规则需要对比多个示例才能发现，因为单个示例可能只展示一种碰撞情形。

## 新题 3：叶状突起编码子区域镜像轴

**组合逻辑**：[镜像](创新：从整体双轴反射改为子区域沿叶片指定轴各自反射) + [叶状突起/突起定行列](创新：从选定射线延伸的行列改为选定镜像翻转的轴线) + [裁剪/边界框包围](已有) + [墙壁线段/区域封闭](创新：矩形内部的墙壁划分子区域)

**来源原语**：镜像(67e8384a, dc0a314f), 叶状突起/突起定行列(f1cefba8), 裁剪/边界框包围(a740d043), 墙壁线段/区域封闭(a5313dff)

**依赖链**：识别前景矩形及其边缘的叶状突起 → 叶的位置确定是行轴还是列轴 → 矩形内部的灰墙将其分割为子区域 → 每个子区域判断最近的叶片轴线 → 沿该轴线对子区域内容做镜像翻转 → 输出裁剪至矩形边界框

在一个被内部灰墙分割的彩色矩形上，每个叶状突起标记一条镜像轴线，各子区域沿其最近的叶片轴线独立翻转。

**输入结构**：
- 网格约 14x14，黑(0)背景。
- 一个由两种颜色构成的矩形前景区域（约 10x10）：外缘一圈为颜色 A（如红(2)），内部为颜色 B（如蓝(1)）的不规则图案（非全填充，含黑(0)空隙形成内部纹理）。
- 矩形边缘有 2~4 个叶状突起：颜色 B 的单像素突出到颜色 A 的边缘之外。上/下边缘的叶突起标记所在列为垂直镜像轴；左/右边缘的叶突起标记所在行为水平镜像轴。
- 矩形内部有灰(5)单像素宽的直线段（水平或垂直），将矩形内部分割为 2~4 个子区域。灰线段端点接触矩形外缘（颜色 A 边框）。
- 生成约束：每个子区域内有至少 3 个颜色 B 像素构成的非对称纹理；每个子区域恰好被一条最近的叶片轴线唯一支配（不存在等距的两条轴线）。

**规则**：
1. 定位前景矩形的边界框。识别颜色 A 的外缘和颜色 B 在外缘之外的突起像素（叶状突起）。
2. 对每个叶状突起：若它突出于矩形的上边缘或下边缘，则它标记列号 c 为一条垂直镜像轴；若突出于左边缘或右边缘，则标记行号 r 为一条水平镜像轴。
3. 识别矩形内部的灰(5)线段。灰线段将矩形内部（不含外缘 A 色边框）分割为若干四连通子区域。
4. 对每个子区域，计算其质心（所有像素坐标的算术平均）到各条叶片轴线的垂直距离，选取距离最小的轴线作为该子区域的镜像轴。
5. 沿该镜像轴对子区域内的所有非灰像素做反射：垂直轴 → 左右翻转子区域内容；水平轴 → 上下翻转子区域内容。翻转仅作用于子区域的边界框范围内，结果写回原位置。
6. 灰(5)分隔线和颜色 A 外缘保持不变。
7. 叶状突起像素在输出中擦除为黑(0)。
8. 输出裁剪至前景矩形的原始边界框。

**关键洞察**：叶状突起不是射线的发射源（如参考题 f1cefba8），而是镜像轴的定位标记；同时，内部灰墙决定了每个子区域的翻转范围——两者必须同时理解才能求解。

## 新题 4：重力下沉竖条形成封闭区域并继承填充色

**组合逻辑**：[滑动/碰撞阻挡](已有) + [洪泛填充/区域封闭](创新：封闭边界由动态滑动结果生成而非静态存在) + [墙壁线段](已有) + [频率比较](创新：从选取角落改为决定填充色继承逻辑)

**来源原语**：滑动/碰撞阻挡/滑动至目标旁(3906de3d), 洪泛填充/区域封闭/孤立背景区域填充(a5313dff), 墙壁线段(a5313dff), 频率比较(a6953f00)

**依赖链**：彩色竖条在重力作用下向下滑动 → 滑动遇到灰墙或网格底部停止 → 停止后的竖条与灰墙共同构成新的边界结构 → 检测边界结构中的封闭黑色区域 → 每个封闭区域的填充色取决于其边界上出现频率最高的竖条颜色

彩色竖条向下滑动直到撞上灰墙或底部，然后与灰墙共同围成的封闭区域被填充为边界上出现最多的竖条颜色。

**输入结构**：
- 网格约 14x16（略高），黑(0)背景。
- 灰(5)像素构成若干水平和垂直的单像素宽静态墙壁线段，分布在网格中下部。墙壁不完全封闭任何区域（初始状态下不存在封闭黑色区域）。
- 网格上部有 4~6 根彩色竖条，每根竖条为 1 像素宽、2~4 像素高的垂直连通块，颜色各不相同，取自 {蓝(1), 红(2), 绿(3), 黄(4), 品红(6), 橙(7)}。
- 每根竖条正下方的路径上没有其他竖条（竖条列号互不相同，或同列竖条间保持足够间距不会碰撞）。
- 生成约束：竖条下落并停止后，灰墙与停止后的竖条恰好形成 2~3 个四连通封闭黑色区域；每个封闭区域的边界上至少有 2 根不同颜色的竖条参与（使频率比较有意义）。

**规则**：
1. 将灰(5)墙壁视为固定障碍。将网格底边也视为障碍。
2. 对每根彩色竖条，在其所在列中将整根竖条向下平移，直到竖条的最底部像素的下一行是灰(5)墙壁像素或网格底边。清除竖条原始位置的颜色（置为黑(0)）。
3. 竖条按列号从左到右依次处理。若同列有多根竖条，从下方的先处理（先落位的成为后续竖条的障碍）。
4. 所有竖条落位后，将灰(5)像素和所有竖条像素均视为墙壁，识别所有无法通过四连通路径到达网格边界的黑(0)区域（封闭区域）。
5. 对每个封闭区域，检查其四连通边界上所有非黑非灰像素（即竖条像素）。统计各颜色出现的像素数量，出现最多的颜色作为该区域的填充色。若数量并列，取在网格中列号最小的那根竖条的颜色。
6. 用该填充色填充封闭区域内的所有黑(0)像素。
7. 灰(5)墙壁和竖条像素保持不变。

**关键洞察**：初始网格中没有封闭区域——封闭区域只有在竖条下落并与灰墙拼合后才出现；而填充颜色又由参与围合的竖条之间的数量竞争决定。这形成了一条三步依赖链：滑动 → 封闭检测 → 频率决策。

## 新题 5：射线交叉动态围合与来源染色

**组合逻辑**：[射线延伸](创新：射线从标记像素出发沿基数方向而非对角方向) + [封闭区域/区域封闭](创新：封闭边界由射线动态生成) + [洪泛填充](已有) + [擦除](已有) + [标记像素](已有)

**来源原语**：射线延伸(5c0a986e, f1cefba8), 封闭区域/区域封闭(a5313dff), 洪泛填充(a5313dff), 擦除(494ef9d7, 17b866bd), 标记像素(17b866bd)

**依赖链**：标记像素向四基数方向发射射线直到遇到灰墙或网格边界 → 射线本身成为新的墙壁 → 射线与灰墙共同界定出新的封闭区域 → 每个封闭区域的填充色由贡献了其最长边界射线的标记像素决定 → 未参与围合任何区域的标记像素被擦除

标记像素向四方发射射线形成新边界，由此围成的封闭区域被填充为贡献最长边界的标记颜色，无贡献的标记被擦除。

**输入结构**：
- 网格约 13x13，黑(0)背景。
- 灰(5)像素构成若干不完整的单像素宽墙壁线段（水平或垂直），留有缺口。
- 3~5 个彩色标记像素，分布在墙壁的缺口附近或开放区域内，颜色各不相同，取自 {蓝(1), 红(2), 绿(3), 黄(4), 橙(7)}。
- 标记像素不与灰墙直接相邻（四连通距离至少 2）。
- 生成约束：每个标记的射线至少有一条能连接到灰墙（不只是到达边界），使得射线能够与灰墙共同形成至少一个封闭区域。至少有一个标记的所有射线都不参与任何封闭（该标记将被擦除）。整体恰好形成 2~3 个封闭区域。

**规则**：
1. 从每个标记像素向上、下、左、右四个方向各发射一条射线。射线颜色与标记像素相同。
2. 每条射线逐像素延伸，遇到灰(5)墙壁像素或网格边界时停止（不覆盖灰墙像素；到达边界时最后一个像素在边界行/列上）。射线遇到另一条射线时不停止，后绘制的覆盖先绘制的颜色。
3. 射线的绘制顺序：按标记像素的行号升序处理，行号相同按列号升序，每个标记按上、右、下、左的顺序绘制四条射线。
4. 所有射线绘制完成后，将灰(5)像素和所有射线像素均视为墙壁。识别所有无法通过四连通路径到达网格边界的黑(0)区域（封闭区域）。
5. 对每个封闭区域，检查其四连通边界上的所有射线像素。对于边界上的每个标记来源（可通过颜色追溯），统计该标记的射线在此封闭区域边界上贡献的像素总数。贡献最多的标记的颜色作为填充色。若并列，取行号更小的标记的颜色。
6. 用填充色填充该封闭区域内的所有黑(0)像素。
7. 检查每个标记像素：若其四条射线中没有任何一条参与了某个封闭区域的边界，则将该标记像素及其所有射线像素擦除为黑(0)。
8. 灰(5)墙壁保持不变。标记像素（未被擦除的）保持原色。

**关键洞察**：射线不是最终输出的一部分装饰，而是构建封闭边界的建筑材料——封闭区域在输入中不存在，完全由射线的交叉与灰墙的拼合动态生成。需要同时理解射线延伸规则和封闭判定逻辑才能解题。

## 新题 6：轴向重复检测触发方向编码重涂色

**组合逻辑**：[轴向复制/沿重复轴取首半](创新：从全局单瓦片提取改为逐对象分类判定) + [方向编码/色块决定输出位置](创新：从排布精灵体位置改为决定重涂色方向) + [重涂色](已有) + [裁剪/边界框包围](已有)

**来源原语**：轴向复制/沿重复轴取首半(7b7f7511), 方向编码/色块决定输出位置(a8c38be5), 重涂色(a740d043), 裁剪/边界框包围(a740d043)

**依赖链**：识别网格中的多个矩形对象 → 判定哪些对象内部存在轴向重复（左右半相同或上下半相同）→ 对重复对象提取不重复的首半 → 首半中含有一个着色标记像素，其相对于首半中心的方位编码一个方向 → 沿该方向对最近的非重复对象做逐行/逐列渐进重涂色

识别具有轴向重复的矩形对象，提取其首半中的方向标记，沿标记方向对最近的非重复对象执行渐变重涂。

**输入结构**：
- 网格约 16x16，黑(0)背景。
- 4~6 个互不相邻的矩形前景对象（边界框不重叠），每个对象由灰(5)边框和内部彩色图案组成。矩形宽高为 4~8 像素。
- 其中约一半对象是"重复对象"：其内部图案（不含灰边框）沿某一轴两半完全相同（左右或上下）。重复对象的首半（左半或上半）中恰好有一个像素颜色与其余内部像素不同，作为着色标记。
- 另一半为"普通对象"：内部图案不对称，无轴向重复。
- 着色标记的颜色与普通对象中的某一颜色相同（每个标记颜色对应恰好一个普通对象）。
- 生成约束：每个重复对象的方向标记位于首半的四个象限之一（左上/右上/左下/右下），分别编码上、右、下、左四个方向。标记位于左上象限 → 上方向，右上 → 右方向，右下 → 下方向，左下 → 左方向。沿该方向，重复对象到其对应普通对象之间的路径上无其他对象。

**规则**：
1. 识别所有由灰(5)边框围成的矩形对象，提取各自的内部图案（不含边框）。
2. 对每个对象判断是否存在轴向重复：将内部图案沿水平中线或垂直中线分为两半，检查是否有某轴两半完全相同（像素逐一对应）。若内部行数/列数为奇数，中间行/列不参与比较。
3. 对每个重复对象，提取首半（水平重复取左半，垂直重复取上半）。在首半中找到颜色唯一的像素作为着色标记。
4. 确定标记在首半中的象限位置：以首半中心为原点，左上象限 → 方向"上"，右上象限 → 方向"右"，右下象限 → 方向"下"，左下象限 → 方向"左"。若标记恰好在中心线上，按先行后列的正方向偏移（中心行 → 视为上方，中心列 → 视为左方）。
5. 找到与着色标记颜色相同的普通对象。沿步骤 4 确定的方向，对该普通对象的内部图案做渐进重涂色：将对象内部非黑像素按该方向逐行（上/下方向）或逐列（左/右方向）替换为着色标记的颜色。替换深度 = 重复对象首半中标记所在行/列的索引（从方向端起算，0-indexed）+ 1。例如方向为"上"且替换深度为 2，则从普通对象内部的顶部起前 2 行的非黑像素被重涂为标记色。
6. 灰(5)边框和黑(0)背景保持不变。

**关键洞察**：轴向重复不是用于提取瓦片的整体操作，而是用于分类对象的判定依据——重复对象是"指令源"，其首半中的标记编码了对另一个对象施加重涂的方向和深度。

**组合逻辑**：[频率比较/重复色或稀有色](创新：从选取角落裁剪改为选取周期生长的种子) + [种子周期生长/对角偏移](已有) + [象限排布](创新：从平铺反射改为生长范围限制) + [裁剪](已有)

**输入结构**：
- 网格为偶数边长的正方形（如 12x12 或 14x14），便于等分象限。
- 四个角像素各有一种颜色，颜色取自 {蓝(1), 红(2), 绿(3), 黄(4)}，四角颜色互不相同。
- 网格内部散布着一些彩色像素作为"频率填充"：大多数像素使用某 2~3 种角颜色，使得各角颜色的全网格频率明显不同。
- 生成约束：恰好有一种角颜色的全网格频率严格最低（无并列）。频率填充像素不出现在种子象限内（种子象限在输入时仅含种子角像素和黑(0)背景）。

**规则**：
1. 读取四个角的像素颜色。统计每种角颜色在整个网格中出现的总次数（含角像素本身和内部填充像素）。
2. 频率最低的角颜色所在的角像素成为种子。
3. 以网格中心为原点将网格分为四个等大象限（左上、右上、左下、右下），种子位于其中一个象限的角上。
4. 从种子位置开始进行周期-2 对角生长：初始发射点为种子位置及其四个对角邻居共 5 个起点。从每个起点开始，每隔 2 行向下（远离种子所在边界的方向）放置一个同色像素。同时每隔 2 列向内（远离种子所在角的侧方向）也放置像素。即生长方向始终从角向象限内部扩展。
5. 所有生长像素必须严格落在种子所属的象限范围内（含边界行/列），超出象限的像素不绘制。
6. 输出为种子所属象限的裁剪（网格宽高各取一半）。

**关键洞察**：角像素的颜色频率决定了哪个角是种子，进而决定了生长发生在哪个象限——必须对比多个示例才能发现"频率最低"这个选取标准，因为单个示例无法排除按位置或颜色名选取的假说。

## 新题 8：模板匹配定位遮挡区并用对称邻域恢复内容

**组合逻辑**：[模式匹配/形状相同](创新：从寻找 3x3 副本改为识别被遮挡区域的位置) + [镜像对称/反射恢复遮挡](创新：从全局对称恢复改为局部邻域对称推断) + [描框](已有) + [擦除](已有)

**依赖链**：网格中有多个形状相同但颜色不同的图案（模式匹配识别同形组）→ 其中恰好一个图案被单色方块遮挡了部分内容 → 遮挡方块的位置通过与同形图案的像素比较来定位（模式匹配找到差异区域）→ 遮挡区域的原始内容通过图案的局部镜像对称恢复 → 恢复后在遮挡区域周围描灰框标记

在多个同形但异色的图案中定位被单色方块遮挡的那个，通过图案的局部对称性恢复隐藏内容并描框。

**输入结构**：
- 网格约 15x15，黑(0)背景。
- 3~4 个形状完全相同（像素占位相同）但颜色不同的前景图案，每个图案为 4~6 像素的四连通单色图形。图案互不相邻，周围有至少 1 像素的黑色间距。
- 其中恰好一个图案被一个 2x2 的品红(6)单色方块部分遮挡。遮挡方块覆盖了该图案的 1~3 个像素，同时覆盖了部分黑色背景。
- 被遮挡的图案具有关于某条轴的局部镜像对称性（垂直轴或水平轴），且对称轴不穿过遮挡区域——即被遮挡的像素可以通过轴对称找到未被遮挡的对称像素。
- 其余图案完整无遮挡。
- 生成约束：遮挡方块的品红(6)颜色不出现在任何图案中；被遮挡图案的对称轴唯一。

**规则**：
1. 识别所有前景图案（非黑、非品红的四连通单色组件）。记录每个图案的形状（像素相对位置集合，平移归一化）。
2. 找到形状出现 ≥2 次的同形组（颜色可以不同）。
3. 定位品红(6)的 2x2 遮挡方块。找到与遮挡方块有像素重叠或四连通相邻的图案——该图案即为被遮挡图案。
4. 将被遮挡图案与同形组中的完整图案比较，确定缺失的像素位置（完整图案有但被遮挡图案因被覆盖而缺失的位置）。
5. 在被遮挡图案中寻找局部镜像对称轴（水平或垂直）。尝试两种轴，选取使现有可见像素对称匹配数最多的轴。
6. 对于步骤 4 确定的每个缺失像素位置，计算其关于对称轴的镜像位置。若镜像位置是被遮挡图案的可见像素，则确认缺失位置应恢复为该图案的颜色。
7. 将品红(6)遮挡方块擦除（恢复为黑(0)），在确认的缺失位置绘制被遮挡图案的颜色。
8. 在恢复后的遮挡区域原始范围（2x2 方块位置）外围描一圈灰(5)单像素宽矩形框（即 4x4 的灰框包围原 2x2 区域），不覆盖已有的前景图案像素。
9. 其余图案和背景保持不变。

**关键洞察**：遮挡区域的识别不依赖遮挡块本身的特殊颜色（品红只是定位辅助），而是依赖同形图案之间的差异比较——只有同时理解"形状相同"和"对称恢复"两个逻辑，才能确定恢复哪些像素。

## 新题 9：控制像素矩形框内的精灵体按锚点滑动并平铺

**组合逻辑**：[控制像素/极值行列/控制极值定矩形](已有) + [滑动对齐/颜色匹配锚点](创新：从边界锚点改为框内锚点) + [平铺](创新：从四象限反射改为在对齐后的精灵体周围进行填充式平铺) + [描框](已有)

**依赖链**：四个控制像素的极值行列确定矩形框 → 框内有多色精灵体和孤立锚点像素 → 精灵体的标记色与锚点颜色匹配 → 精灵体沿锚点的行或列方向滑动对齐 → 对齐后，精灵体图案在矩形框内沿两个方向平铺填满 → 绘制控制像素定义的矩形框

在控制像素定义的矩形区域内，精灵体按颜色匹配滑向锚点对齐后，其图案被平铺填满整个矩形区域。

**输入结构**：
- 网格约 15x15，黑(0)背景。
- 4 个不同颜色的控制像素分别位于网格中的四个极值位置：行号最小（最上）、行号最大（最下）、列号最小（最左）、列号最大（最右）。颜色取自 {红(2), 绿(3), 黄(4), 橙(7)}，每个控制像素颜色互不相同。它们定义一个矩形区域（上边 = 最上控制像素的行，下边 = 最下的行，左边 = 最左的列，右边 = 最右的列）。
- 矩形区域内部有：1 个多色精灵体（3x3 至 4x4 像素的四连通多色图形，使用蓝(1)和青(8)两种颜色），以及 1 个孤立的蓝(1)像素作为锚点。精灵体中有恰好 1 个蓝(1)像素（标记像素）。
- 锚点像素与精灵体不相邻，位于矩形区域内。
- 生成约束：精灵体的边界框宽高能够整除矩形区域的宽高（矩形宽 = 精灵体宽 * k，矩形高 = 精灵体高 * m，k, m >= 2）。锚点与精灵体标记像素在同一行或同一列（决定滑动轴）。

**规则**：
1. 识别四个极值控制像素（行最小、行最大、列最小、列最大各一个）。用它们的行列定义矩形框的上下左右边界。
2. 在矩形区域内找到多色精灵体（蓝(1)+青(8)的四连通多色组件）和孤立的蓝(1)锚点（四邻居均为黑(0)的蓝像素）。
3. 精灵体中的蓝(1)像素即为标记像素。确定标记像素与锚点的位置关系：若同行不同列，精灵体水平滑动使标记像素对齐锚点列；若同列不同行，精灵体垂直滑动使标记像素对齐锚点行。
4. 滑动后，精灵体的标记像素覆盖锚点位置。记录精灵体在滑动后的位置及其完整图案（含黑背景的边界框矩形）。
5. 以精灵体滑动后的边界框为瓦片单元，在矩形框内进行无间隙平铺。平铺从矩形区域的左上角开始，按行优先逐个放置瓦片，直到填满整个矩形区域。每个瓦片是精灵体边界框的精确副本。
6. 用控制像素各自的颜色在矩形框的四边绘制单像素宽的边框线：顶边用最上控制像素的颜色，底边用最下的，左边用最左的，右边用最右的。边框覆盖平铺内容。
7. 矩形框外部和控制像素本身保持不变。

**关键洞察**：控制像素不只是"画框"——它们定义了平铺的空间范围；而锚点不只是"目标位置"——对齐操作确定了瓦片的起始相位。两者联合决定了平铺图案在矩形内的具体排布方式。

- 网格约 13x13，黑(0)背景。
- 红(2)像素构成一个封闭的单像素宽多边形墙壁（矩形或 L 形），围成一个面积约 8x8 至 10x10 的内部区域。墙壁完全封闭，内部与外部不四连通。
- 封闭区域内有 1~2 个孤立的彩色种子像素，颜色各不相同，取自 {蓝(1), 绿(3), 黄(4), 橙(7)}。种子与墙壁不相邻（距红墙至少 2 像素）。
- 封闭区域外为黑(0)背景，无其他前景像素。
- 生成约束：封闭区域足够大，使种子的反射生长至少能发生 2 次反射后才停止。区域内在生长完成后存在至少一个 2x2 的全黑矩形区域。

**规则**：
1. 识别红(2)墙壁围成的封闭区域（红墙内侧的四连通黑色区域）。
2. 找到封闭区域内的孤立彩色种子像素。按行号升序、列号升序处理种子。
3. 对每个种子，从种子位置开始向四个对角方向（左上、右上、左下、右下）各发射一条周期生长射线。射线每步移动 1 像素（沿对角方向），每隔 1 步绘制一个像素（即步数为奇数时绘制，偶数时跳过——与种子位置的曼哈顿距离奇偶性匹配时绘制）。
4. 当射线的下一步将进入红(2)墙壁像素或离开封闭区域时，射线发生反射：
   - 若碰到水平方向的墙壁（上方或下方为红像素），行方向取反，列方向不变。
   - 若碰到垂直方向的墙壁（左方或右方为红像素），列方向取反，行方向不变。
   - 若碰到墙壁角落（对角方向的下一步为红像素，且相邻的水平和垂直方向也有红像素），行列方向同时取反（原路反弹）。
   射线从反射点继续按新方向生长，保持周期-2 的绘制间隔不重置。
5. 射线在以下情况停止：a) 反射后的下一步仍为墙壁（被困在角落）；b) 下一步的像素已被当前种子的射线绘制过（形成闭环）；c) 总步数超过封闭区域面积的 2 倍（防止无限循环）。
6. 所有种子的生长完成后，在封闭区域内寻找最大面积的全黑(0)矩形（宽和高均至少为 2）。将其填充为灰(5)。若面积最大的矩形不唯一，取左上角行号最小的，再取列号最小的。
7. 红(2)墙壁和封闭区域外部保持不变。

**关键洞察**：种子的周期生长不是在开放空间中无限扩展，而是被墙壁约束并通过反射改变方向——生长轨迹的最终形态取决于墙壁的几何形状。最后的灰色填充找到的是"生长盲区"，即射线反射模式恰好覆盖不到的最大矩形空白区。

- 网格约 15x15，由青(8)像素构成周期性格点骨架（类似 17b866bd 的网格结构），骨架将网格分割为 3x3 或 4x4 的等大封闭腔室。每个腔室为 3x3 的黑色内部空间。

- 恰好一个格点交叉点的间隙位置有一个红(2)标记像素，该标记紧邻模板腔室的左上角（标记位于模板腔室的西北方向 1 格处）。
- 其余所有腔室为全黑(0)（空腔室）。
- 生成约束：模板腔室不在网格角落的腔室位置，保证四个象限方向上都有空腔室可填充。模板腔室内的图案关于水平轴和垂直轴均不对称（使翻转结果可区分）。

**规则**：
1. 识别青(8)格点骨架和所有封闭腔室。
2. 找到红(2)标记像素。标记的东南方向紧邻的腔室即为模板腔室。
3. 提取模板腔室的 3x3 内部图案作为瓦片 T。
4. 将红(2)标记像素擦除为黑(0)。
5. 对每个空腔室，计算其行列位置相对于模板腔室的偏移（行偏移 dr，列偏移 dc，以腔室为单位）：
   - dr < 0 且 dc < 0（左上方）：将 T 同时做水平翻转和垂直翻转后填入。
   - dr < 0 且 dc = 0（正上方）：将 T 做垂直翻转后填入。
   - dr < 0 且 dc > 0（右上方）：将 T 做垂直翻转后填入。
   - dr = 0 且 dc < 0（正左方）：将 T 做水平翻转后填入。
   - dr = 0 且 dc > 0（正右方）：将 T 原样填入。
   - dr > 0 且 dc < 0（左下方）：将 T 做水平翻转后填入。
   - dr > 0 且 dc = 0（正下方）：将 T 原样填入。
   - dr > 0 且 dc > 0（右下方）：将 T 原样填入。
   总结规则：若目标在模板上方（dr < 0），垂直翻转；若目标在模板左方（dc < 0），水平翻转。两者独立叠加。
6. 模板腔室自身内容保持不变。青(8)骨架保持不变。

**关键洞察**：标记像素的作用不是"填充指定腔室"（如参考题 17b866bd），而是"标记哪个腔室是源模板"——模板的内容向外扩散填充，且翻转规则取决于空间位置关系，形成以模板为中心的镜像对称平铺图案。需要对比多个示例才能归纳出上/左方向翻转的规则。

## 新题 12：双色矩形内叶片标记行列交叉处的最大空白填充

**组合逻辑**：[叶状突起/突起定行列](已有) + [双色矩形](已有) + [搜索/最大矩形填充/最小边长约束](创新：搜索范围不是整个网格而是叶片行列交叉切割后的子区域) + [填充](已有) + [重涂色/内外色互换延伸](创新：互换范围限定在交叉格内)

**来源原语**：叶状突起/突起定行列/双色矩形/内外色互换延伸(f1cefba8), 搜索/最大矩形填充/最小边长约束(3eda0437), 填充(3eda0437)

**依赖链**：叶状突起标记若干行和列 → 标记行列将双色矩形内部切割为一个网格状分区 → 在标记行列的交叉处，内外色互换 → 互换后寻找矩形内部最大的全内色矩形子区域 → 将其填充为第三种颜色

叶状突起标记行列，将矩形内部切割成棋盘式的内外色分区，交叉格互换颜色后，最大的纯色矩形区域被填充为新颜色。

**输入结构**：
- 网格约 14x14，黑(0)背景。
- 一个大矩形前景区域（约 10x12）由外色 A（如红(2)）的单像素宽边框和内色 B（如蓝(1)）的实心内部组成。
- 矩形的上/下边缘有 2~3 个内色 B 的单像素叶状突起（标记列），左/右边缘有 1~2 个内色 B 的单像素叶状突起（标记行）。
- 矩形内部除了纯色 B 外无其他元素。
- 生成约束：标记行列将矩形内部分割为至少 3x3 个子区域；存在一个面积最大（宽高均 >= 2）的"交叉格"（行列均被标记的子区域），使得互换后的最大纯色搜索有唯一解。

**规则**：
1. 识别矩形前景区域。外色 A = 矩形四角的颜色，内色 B = 矩形内部主色。
2. 识别叶状突起：上/下边缘外的内色 B 像素标记其所在列；左/右边缘外的内色 B 像素标记其所在行。
3. 标记行和标记列将矩形内部（不含 A 色边框）分割为一个行列网格。将子区域分为两类：
   - "交叉格"：行索引（从上到下，0-indexed）和列索引（从左到右，0-indexed）奇偶性相同的子区域。
   - "非交叉格"：行列索引奇偶性不同的子区域。
   其中行列索引的计算以标记行列为分隔线：第一条标记行/列之前的区域索引为 0，之间为 1，以此类推。
4. 在矩形内部，将所有交叉格的像素从内色 B 重涂为外色 A，同时将标记行和标记列上的像素（在矩形内部的部分）从内色 B 重涂为外色 A。非交叉格保持内色 B。
5. 重涂后，在矩形内部（含边框内侧）搜索最大面积的全内色 B 矩形区域（宽和高均 >= 2）。
6. 将该最大区域填充为绿(3)（若 A 或 B 已经是绿(3)，则填充为黄(4)）。
7. 叶状突起像素在输出中擦除为黑(0)。外色 A 边框保持不变。

**关键洞察**：叶状突起不是直接生成射线或切割线（如参考题 f1cefba8 的外延），而是将矩形内部划分为棋盘格式的交叉分区——交叉格的颜色互换改变了内部的颜色分布，使得"最大矩形搜索"的结果完全取决于叶片位置。两个操作（互换 + 搜索）在同一空间域上交织，缺一不可。

- 网格边界上有 2~3 个孤立的边界锚点像素（非黑，四邻居中其他非黑邻居均为黑色或网格外），每个锚点颜色与某个精灵体的标记色匹配。
- 上/下边缘的锚点驱动水平滑动，左/右边缘的锚点驱动垂直滑动。
- 生成约束：每个精灵体恰好匹配一个锚点；滑动后精灵体不重叠；精灵体的标记像素与匹配锚点在滑动轴方向上相距至少 3 像素（留出翻转拼接空间）；滑动方向上，精灵体和其翻转副本拼接后不超出网格边界。

**规则**：
1. 识别边界锚点：网格四边上的非黑孤立像素（四连通邻居中非背景像素仅有网格外的边界）。
2. 识别内部多色精灵体（四连通的多色非黑组件）。在每个精灵体中找到出现恰好 1 次的颜色像素作为标记像素。
3. 将每个精灵体与颜色相同的边界锚点配对。
4. 确定滑动轴：锚点在上/下边缘 → 水平滑动（调整精灵体列位置使标记列 = 锚点列）；锚点在左/右边缘 → 垂直滑动（调整精灵体行位置使标记行 = 锚点行）。若锚点在角落，按垂直滑动处理。
5. 执行滑动：将精灵体整体平移使标记像素对齐锚点的对应行或列。清除原位置。
6. 对滑动后的精灵体，沿滑动轴方向做镜像翻转生成副本：
   - 水平滑动的精灵体 → 做左右翻转。
   - 垂直滑动的精灵体 → 做上下翻转。
7. 将翻转副本拼接在精灵体的远离锚点一侧。拼接时副本紧贴精灵体的边界框（间距为 0，共享边界框的一条边）。
8. 若拼接后的像素位置已有其他内容（其他精灵体的像素），后处理的精灵体覆盖先处理的。处理顺序：按锚点的边缘位置，上→右→下→左，同边按行/列号升序。
9. 边界锚点在输出中保持不变。

**关键洞察**：滑动不是最终目标——它确定了精灵体的对齐位置和滑动方向，而这个方向同时决定了镜像翻转的轴向和拼接的方位。单看一个精灵体无法确定是整体翻转还是局部翻转，需要对比多个精灵体的不同滑动方向来归纳翻转-拼接规则。

## 新题 14：遮挡方块定位后以象限对称恢复并裁剪为棋盘式输出

**组合逻辑**：[反射恢复遮挡](已有) + [象限排布](创新：从平铺结构改为确定反射来源的象限) + [裁剪](创新：裁剪区域不由边界框决定而由恢复内容的象限数决定) + [缩放](创新：恢复后的区域缩放为标准尺寸以形成棋盘排列)

**来源原语**：反射恢复遮挡/遮挡块/被遮区域/镜像对称(dc0a314f), 象限排布(67e8384a), 裁剪(a740d043, a6953f00), 缩放(b99e7126)

**依赖链**：识别场景中的遮挡方块 → 将场景分为四个象限 → 遮挡方块所在象限为"损坏象限"→ 从其他象限中找到可用的镜像对称源 → 恢复损坏象限的内容 → 将四个象限按 2x2 排列裁剪输出 → 输出中损坏象限的位置放置恢复后的内容，其他象限放置原内容

在四象限对称的场景中定位遮挡方块所在象限，用对称象限的内容恢复后按 2x2 排列输出四个象限。

**输入结构**：
- 网格为偶数边长的正方形（如 14x14），以中心分为四个等大象限。
- 场景具有双轴镜像对称性（关于水平和垂直中心线对称），但其中一个象限被一个 3x3 至 4x4 的品红(6)单色遮挡方块部分破坏。
- 场景使用 2~3 种颜色（如蓝(1)、红(2)、灰(5)）在黑(0)背景上绘制。品红(6)不出现在正常场景中。
- 遮挡方块完全落在一个象限内部，不跨越中心线。
- 生成约束：遮挡方块不覆盖中心线上的像素；三个未损坏象限至少有一个与损坏象限关于某轴对称且自身无遮挡。

**规则**：
1. 以网格的水平和垂直中心线将网格分为四个象限：左上(TL)、右上(TR)、左下(BL)、右下(BR)。
2. 找到品红(6)遮挡方块的位置，确定其所在象限（损坏象限）。
3. 确定恢复来源：优先使用关于垂直中心线对称的象限（左↔右）。若该象限也被遮挡（本题保证不会），则使用关于水平中心线对称的象限。
4. 将来源象限的内容关于对应的对称轴做镜像翻转。
5. 用翻转后的内容替换损坏象限中品红(6)遮挡方块覆盖的像素，恢复原始场景。
6. 输出为一个 2x2 排列的网格：每个象限缩放为 (原象限宽/2) x (原象限高/2)（缩小到一半，最近邻采样），按原始位置排列。即输出网格大小为原网格的 1/2 x 1/2 = 1/4 面积。
7. 缩放规则：每 2x2 的像素块取左上角像素的颜色作为缩放后的像素。

**关键洞察**：遮挡恢复不是最终输出——恢复只是中间步骤，最终输出是整个场景（含恢复部分）的缩小版。需要同时理解对称恢复逻辑和缩放输出格式，仅看对称性或仅看缩放都无法得到正确答案。
