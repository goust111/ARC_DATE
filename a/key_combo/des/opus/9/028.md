## 新题 1：墙壁分区下的空心框面积竞标

**组合逻辑**：[可达性 reachability](创新：用于分组框体而非移动像素) → [面积比较 area_comparison] → [重涂色 recolor](创新：颜色取决于局部分组内的排名而非全局排名)

**来源原语**：可达性 reachability、墙壁障碍 wall_barrier（dd6b8c4b）；空心矩形 hollow_rectangle、封闭区域 enclosed_region、面积比较 area_comparison、最大内部面积胜出 largest_interior_wins（445eab21）；重涂色 recolor、连通分量 connected_component（e8593010）

**依赖链**：墙壁障碍将背景切分为连通区 → 每个区内的空心框构成局部竞争组 → 组内按内部面积排名 → 排名决定框的最终颜色。去掉可达性则退化为全局比较（不同结果）；去掉比较则分组无用；去掉重涂色则比较结果不可见。

将空心矩形框按墙壁隔断的背景连通性分组，组内面积最大的框获得蓝色标记，其余为红色，独占一组的框为黄色。

**输入结构**：
- 网格约 15x15，背景黑(0)。
- 4~6 个灰(5) 空心矩形框，每个框边宽 1 像素，外轮廓尺寸从 3x3 到 7x7 不等，各框互不重叠且不相邻（间距至少 1 像素）。每个框的内部全为背景色。
- 栗(9) 墙壁像素形成若干水平或竖直连续线段（每段 2~5 像素长），散布于网格中，不与任何框体相交。墙壁将背景区域分割为 2~3 个连通区。
- 每个连通区至少包含 1 个框。至少 1 个连通区包含 2 个以上内部面积互不相同的框。
- 生成约束：在任何包含多框的连通区内，内部面积严格最大的框唯一。

**规则**：
1. 通过背景(0) 单元格进行 4-连通洪泛填充（不穿越灰(5) 框边和栗(9) 墙壁），确定各连通区。两个框属于同一连通区，当且仅当它们的外侧背景像素通过背景路径相连。
2. 在每个连通区内，计算各框的内部面积（框边内部严格包含的背景单元格数）。
3. 若连通区内仅 1 个框：将该框的边框像素重涂为黄(4)。
4. 若连通区内有 2 个以上框：将内部面积严格最大的框边框重涂为蓝(1)，该区内所有其他框的边框重涂为红(2)。
5. 各连通区独立处理，处理顺序不影响结果。墙壁像素和背景像素保持不变。

**关键洞察**：看似仅做装饰的墙壁实际上创建了连通分区，使同一框在不同墙壁配置下可能"赢"也可能"输"——两个面积相近的框若被墙隔入不同区，则各自为王；若同处一区，则小者必输。

## 新题 2：周期铺排遭遇对角射线擦除

**组合逻辑**：[平铺 tile] → [射线延伸 ray_extension](创新：射线不是从正方形角出发，而是从散布的障碍像素出发沿四对角线方向擦除铺排内容) → [擦除 erase]

**来源原语**：平铺 tile、最小周期单元 minimal_period、局部图案 partial_motif、列周期重复 column_period、最小周期扩展 minimal_period_extend（d8c310e9）；射线延伸 ray_extension、障碍像素 blocker_pixel、角射线 corner_ray、角对角辐射 corner_diagonal_radiate、遇障碍截断 truncate_at_blocker（212895b5）；擦除 erase（d255d7a7）

**依赖链**：左侧局部图案确定最小列周期 → 周期铺满全网格 → 障碍像素沿四对角方向发射擦除射线 → 射线经过的铺排单元被清除为背景。铺排提供被擦除的基底；射线提供擦除位置；两者的几何交互产生周期性干涉图案，单独任一步均无法产生最终输出。

将左侧局部图案按最小列周期铺满全网格，再由散布的障碍像素沿四条对角线擦除铺排内容，形成周期与射线的干涉图案。

**输入结构**：
- 网格约 12x15，背景黑(0)。
- 最左 3~4 列包含由蓝(1) 和红(2) 像素构成的彩色图案（黑(0) 为底），该图案在可见部分内具有列周期 P（P = 2 或 3）。
- 网格右侧区域（超出可见图案之外）散布 3~5 个绿(3) 障碍像素，任意两个障碍像素不在同一行也不在同一列。

**规则**：
1. 确定可见左侧图案的最小列周期 P：使得每个前景像素 (r, c) 的颜色等于 (r, c mod P) 处颜色的最小正整数 P。
2. 将该周期铺满全网格：对每个单元格 (r, c)，将其颜色设为图案在 (r, c mod P) 处的颜色。
3. 从每个绿(3) 障碍像素 (r0, c0) 出发，沿四个对角方向（东北、西北、东南、西南）各发射一条射线。每条射线逐格延伸直至离开网格边界。
4. 射线经过的每个已铺排单元格被擦除为背景(0)。障碍像素本身保持绿(3) 不被擦除。
5. 处理顺序：先完成全部铺排，再统一执行全部擦除。擦除不影响障碍像素，也不影响本身就是背景的单元格。

**关键洞察**：对角射线在周期铺排上制造了 X 形擦除带。由于铺排是周期性的，擦除带与周期结构产生规则的干涉图案——视觉上既非纯铺排也非纯射线，而是两种几何结构的叠加涌现。

## 新题 3：对称偏差的三色诊断

**组合逻辑**：[镜像 mirror] → [比较 compare](创新：逐像素对比镜像版与实际版) → [分类 classification](创新：三路分类而非二元 AND) → [裁剪 crop]

**来源原语**：对称补全 symmetry_completion、对称轴 symmetry_axis、镜像 mirror、缺失区域 missing_patch（9ecd008a）；逻辑交 logical_AND、逐像素对齐 pixel_align、双掩码重叠标记 both_mask_overlap（0520fde7）；分类 classification（27a28665）；裁剪 crop（e7a25a18）

**依赖链**：确定对称轴 → 左半镜像到右半位置 → 逐像素比对镜像左半与实际右半 → 三路分类（一致/右独有/左独有）→ 各类别映射不同颜色 → 裁出右半输出。镜像提供比较基准；比较产生分类依据；分类决定颜色。去掉镜像则无参照；去掉分类则退化为简单 AND。

将近似左右对称图案的右半部分输出为三色诊断图：蓝表示与左侧镜像一致，红表示右侧独有，绿表示左侧独有的"投影"。

**输入结构**：
- 网格约 11x13（列数为奇数以确保中心轴清晰），背景黑(0)。
- 蓝(1) 前景图案跨越网格两半，大体关于竖直中心列对称。中心列本身可含蓝像素。
- 有 3~5 个像素偏离完美对称：部分仅出现在右半（右独有），部分仅出现在左半（左独有，其右半镜像位置为背景）。
- 输入中仅包含蓝(1) 和黑(0) 两种颜色。
- 生成约束：对称偏差的数量和位置保证三种分类都出现在输出中。

**规则**：
1. 确定竖直中心列：列索引 center = (width - 1) / 2。
2. 对右半的每个单元格 (r, c)（c > center）：
   a. 计算其镜像位置 (r, 2 * center - c)。
   b. 若 (r, c) 和镜像位置均为蓝(1)：该单元格保持蓝(1)——一致。
   c. 若 (r, c) 为蓝(1) 但镜像位置为黑(0)：该单元格重涂为红(2)——右独有。
   d. 若 (r, c) 为黑(0) 但镜像位置为蓝(1)：该单元格重涂为绿(3)——左独有投影。
   e. 若两者均为黑(0)：该单元格保持黑(0)。
3. 输出仅包含右半（列 center+1 到 width-1），中心列和左半被丢弃。

**关键洞察**：单个示例中的绿色像素看似"凭空出现"——它们来自左半存在但右半不存在的像素经镜像投射。必须对比多个示例才能归纳出三路分类规则，尤其是区分红（右独有，源位置有色）和绿（左独有，源位置无色但镜像有色）。

## 新题 4：种子计数分类决定填充算法

**组合逻辑**：[填充 fill] ← 由 [分类 classification](创新：分类结果不映射标签，而是调度不同的操作算法) 决定 ← 由 [计数 counting] 驱动

**来源原语**：分类 classification、计数 counting（27a28665）；填充 fill、模板掩码 template_mask（15660dd6）；墙壁障碍 wall_barrier、可达性 reachability（dd6b8c4b）；封闭区域 enclosed_region（445eab21）；中心邻域 center_neighborhood（f0df5ff0）

**依赖链**：墙段划分封闭区域 → 计数每区内种子数 → 分类为 0/1/2 → 各类别触发不同填充规则（0 种子无动作，1 种子全填，2 种子比较邻域后择优填充）。分类是操作分派的决策节点——同一个"填充"操作因分类结果不同而表现为三种完全不同的行为。

墙段围成的区域按其内部种子像素数量分类，不同类别适用不同的洪泛填充规则。

**输入结构**：
- 网格约 15x15，背景黑(0)。
- 灰(5) 墙段（每段宽 1 像素）形成连通的栅栏网络，将网格划分为 4~6 个封闭区域。每个区域是由墙壁和/或网格边界完全包围的 4-连通非墙单元格集合。
- 每个区域包含 0、1 或 2 个"种子"像素。种子为单个前景像素，颜色取自 {蓝(1), 红(2), 绿(3), 黄(4)}。同一区域内两个种子颜色不同。
- 每个区域至少有 4 个背景单元格（保证填充效果可见）。
- 生成约束：三种种子数量的区域各至少出现一个。每个双种子区域中两个种子的 4-连通背景邻居数严格不等。

**规则**：
1. 通过非墙单元格的 4-连通洪泛识别所有封闭区域。
2. 计数每个区域内的种子像素数。
3. 按种子数分类并执行对应填充规则：
   - **0 种子**：整个区域保持背景(0) 不变。
   - **1 种子**：用该种子的颜色洪泛填充区域内所有背景单元格。种子自身颜色不变（已一致）。
   - **2 种子**：对每个种子，计算其 4-连通邻居中属于本区域且为背景(0) 的单元格数量。背景邻居数严格更多的种子"胜出"——用胜者颜色洪泛填充整个区域（包括覆盖败者种子的位置）。
4. 墙壁像素始终保持灰(5)。
5. 各区域独立处理，处理顺序不影响结果。

**关键洞察**：种子计数不仅是数值标签——它调度了质变的算法。理解 1 种子规则的求解者在遇到 2 种子区域时会失败，因为此时需要额外的局部空间分析（邻居比较）来决定填充色，而这在 0/1 种子情况下完全不存在。

## 新题 5：可达性过滤的频率柱状图

**组合逻辑**：[可达性 reachability](创新：用作数据过滤器而非移动路径) → [计数 counting] → [排序 sort] → [计数渲染柱状图 counts_as_histogram]

**来源原语**：聚集 gather、可达性 reachability、墙壁障碍 wall_barrier、标记像素 marker_pixel、距离排序填充 distance_ranked_fill（dd6b8c4b）；计数 counting、排序 sort、前景像素 fg_pixel、柱状条 histogram_bar、频率排序 frequency_ranking、频率降序柱状图 descending_frequency_histogram（9af7a82c）；调色板顺序 palette_order、计数渲染柱状图 counts_as_histogram（f3cdc58f）

**依赖链**：从标记出发的洪泛确定可达像素集 → 仅对可达像素按颜色计数 → 按频率降序排列 → 渲染为底对齐柱状图。墙壁改变可达性 → 可达性改变计数 → 计数改变柱状图。同一网格若标记位于不同区域，柱状图完全不同。

仅统计从标记像素出发可达（不穿墙）的彩色像素频率，渲染为降序柱状图。

**输入结构**：
- 网格约 12x12，背景橙(7)。
- 品红(6) 墙壁像素形成连续屏障，将网格分割为 2~3 个互不连通的地板区域。
- 散布的彩色像素（取自 {蓝(1), 红(2), 绿(3), 黄(4)}）分布在橙(7) 地板上，跨越多个区域。每种颜色在全网格中至少出现 2 次。
- 一个栗(9) 标记像素位于其中一个区域内。
- 生成约束：至少有一种颜色仅出现在标记不可达的区域中（使该颜色被完全过滤掉）。可达区域内各颜色计数互不相等。

**规则**：
1. 从栗(9) 标记像素出发，通过橙(7) 地板和彩色像素单元格进行 4-连通洪泛（不穿越品红(6) 墙壁），确定所有可达单元格。
2. 在可达单元格中，统计每种前景颜色（蓝、红、绿、黄）的像素数。不可达区域中的彩色像素完全忽略。
3. 按频率降序排列可达颜色。频率为零的颜色（全部不可达或不存在）不参与排列。
4. 构建输出网格：宽度 = 参与排列的颜色数，高度 = 最大频率值，背景黑(0)。
5. 从左到右按降序频率分配颜色列。每列从底行起向上填充该颜色的可达频率数个单元格。
6. 标记像素和墙壁不出现在输出中。

**关键洞察**：墙壁不仅分隔空间——它们隐式决定了"哪些数据参与统计"。同一输入若标记移到另一区域，柱状图的列数、高度甚至颜色顺序可能全部改变。求解者必须先理解可达性过滤，才能解释为何某些显然存在的颜色未出现在柱状图中。

## 新题 6：邻域扩张后按合并面积重涂色

**组合逻辑**：[印章覆盖 stamp](创新：扩张产生的连通分量因障碍和间距不同而面积各异) → [计数 counting] → [重涂色 recolor](创新：颜色由扩张后合并面积的档次决定)

**来源原语**：印章覆盖 stamp_overlay、标记像素 marker_pixel、邻域块 neighborhood_block、中心邻域 center_neighborhood、仅填背景格 only_bg_filled（f0df5ff0）；计数 counting、连通分量 connected_component、面积分级 area_ranking、面积决定颜色 area_determines_color（e8593010）；障碍像素 blocker_pixel、遇障碍截断 truncate_at_blocker（212895b5）

**依赖链**：每个标记扩张 3x3 → 障碍阻断部分扩张 → 相邻标记的扩张区合并为更大连通分量 → 连通分量面积决定最终颜色。障碍位置同时影响单个标记的扩张形状和多个标记之间是否合并，使面积计算成为空间布局的涌现结果。

蓝色标记各自扩张 3x3 邻域（仅填背景），灰色障碍阻断扩张；扩张后的 4-连通分量按面积大小分三档重涂色。

**输入结构**：
- 网格约 12x12，背景黑(0)。
- 5~8 个蓝(1) 标记像素散布于网格内部（不触及网格边缘）。部分标记对的间距为 2~3 格（其 3x3 扩张区可能重叠合并），部分间距较远（扩张后独立）。
- 4~6 个灰(5) 障碍像素散布于网格中，部分位于标记的 3x3 邻域内（阻断该方向的扩张），部分不在任何标记邻域内。
- 生成约束：扩张合并后至少产生三种不同面积档次的连通分量。

**规则**：
1. 对每个蓝(1) 标记像素，检查以其为中心的 3x3 邻域。
2. 将该邻域中每个黑(0) 背景单元格涂为蓝(1)。已有颜色的单元格（蓝(1) 或灰(5)）保持不变。
3. 所有标记完成扩张后，识别所有蓝(1) 的 4-连通分量。
4. 根据每个分量的面积（蓝(1) 像素总数）重涂色：
   - 面积 1~4：重涂为绿(3)。
   - 面积 5~7：重涂为黄(4)。
   - 面积 8 及以上：重涂为红(2)。
5. 灰(5) 障碍像素和黑(0) 背景保持不变。

**关键洞察**：两个相邻标记合并后面积翻倍，可能从低档跃入高档并改变颜色。障碍像素若恰好阻断两个标记之间的连接路径，则阻止合并、保持低档——同一对标记在有无障碍时颜色完全不同。障碍的功能不是"遮挡"而是"阻断面积等级跃迁"。

## 新题 7：面积竞标分配角色的双框放大

**组合逻辑**：[比较 compare](创新：比较结果不选择胜者颜色，而是分配功能角色) → [像素放大 pixel_upscale] → [裁剪 crop]

**来源原语**：比较 compare、空心矩形 hollow_rectangle、封闭区域 enclosed_region、面积比较 area_comparison、最大内部面积胜出 largest_interior_wins、输出纯色小块 output_solid_block（445eab21）；像素放大 pixel_upscale、矩形边框 rect_frame、内部图案 interior_pattern、图案在框内 pattern_inside_frame、图案倍增填框 pattern_doubled_fill（e7a25a18）；裁剪 crop（e7a25a18）

**依赖链**：比较两框内部面积 → 大框成为输出容器 → 小框内部图案被提取 → 图案 2 倍放大 → 填入大框内部 → 裁切至大框边界。比较不产生颜色输出，而是分配"容器"与"内容源"这两个功能角色——去掉比较则不知哪个框是容器，去掉放大则无法填充，去掉裁剪则输出尺寸不对。

两个不同大小的矩形框，面积较大者成为输出容器，较小者内部的图案被 2 倍放大后填入容器。

**输入结构**：
- 网格约 15x20，背景黑(0)。
- 两个不重叠的空心矩形框，一个蓝(1)、一个红(2)，各 1 像素宽。框互不接触。
- 每个框的内部包含一组绿(3) 像素构成的小图案（2~4 个像素的紧凑排列），图案以黑(0) 为底。
- 大框的内部尺寸（高 H、宽 W）恰好是小框内部尺寸（高 h、宽 w）的 2 倍：H = 2h，W = 2w。
- 绿(3) 图案的紧凑边界框（tight bounding box）尺寸不超过小框内部尺寸。
- 生成约束：两个框的内部面积严格不等。

**规则**：
1. 计算每个框的内部面积（边框内部严格包含的行数 x 列数）。
2. 内部面积较大的框是"容器"，较小的框是"内容源"。
3. 从内容源框的内部提取绿(3) 图案的紧凑边界框（包含所有绿像素的最小矩形区域）。
4. 将该图案按 2 倍缩放：每个像素变为 2x2 的同色方块。黑(0) 背景像素同样放大。
5. 将放大后的图案放置于容器框的内部，左上角与容器内部左上角对齐。未被图案覆盖的容器内部单元格保持黑(0)。
6. 输出：裁切至容器框的边界框（包含其边框像素）。容器框保留其原色。内容源框及其内容被丢弃。

**关键洞察**：两个框看似对称结构，实际上扮演截然不同的功能角色——由面积比较决定。大框不是"赢家"而是"空容器"；小框不是"输家"而是"内容提供者"。颠倒两框大小即颠倒角色分配，完全改变输出的外框颜色和内容。

## 新题 8：分支终端计数反向着色追踪树

**组合逻辑**：[射线延伸 ray_extend + 分支 branch] → [计数 counting](创新：计数对象是图论意义上的叶节点而非像素频率) → [重涂色 recolor](创新：颜色反向应用于产生该叶节点数的整棵追踪树)

**来源原语**：射线延伸 ray_extend、分支 branch、边缘标记 edge_marker、墙段 wall_segment、从边缘推进 advance_from_edge、墙段开口分支 branch_at_opening（f9a67cb5）；计数 counting（27a28665, e8593010）；重涂色 recolor、面积决定颜色 area_determines_color（e8593010）

**依赖链**：标记向内发射射线 → 遇到墙段在其开口处分支 → 分支逐层深入 → 射线到达底边或死胡同则终止 → 统计每棵追踪树的终端数 → 终端数决定该追踪树的统一重涂色。前向追踪确定树结构，后向计数确定颜色——求解者必须先完成整棵树的追踪才能确定根部的颜色。

顶边标记向下追踪并在墙段开口处分支，统计每棵追踪树的终端节点数，再按终端数将整棵树统一重涂色。

**输入结构**：
- 网格约 15x15，背景黑(0)。
- 顶边（第 0 行）有 2~3 个单像素标记，颜色各不同（如蓝(1)、红(2)、绿(3)），作为追踪起点。顶边其余位置为背景(0)。
- 灰(5) 墙段沿水平方向排列，形成 2~4 层平行的断续横墙（平行于顶边）。每层墙由若干不连续的灰(5) 线段组成，线段之间留有 1~2 像素宽的间隙（开口）。
- 不同标记的追踪树互不交叉（生成约束：各标记的分支路径和开口不会让两棵树共用同一开口或同一列路径）。
- 生成约束：至少产生三种不同终端数（如 1、2、3），使三种重涂色全部出现。

**规则**：
1. 从每个顶边标记像素 (0, c) 出发，向下（行号增大方向）逐格延伸射线，将路径上的背景(0) 单元格涂为该标记的原始颜色。
2. 当射线到达某行 r 且 (r, c_current) 是灰(5) 墙壁像素时：
   a. 找到包含 (r, c_current) 的最大水平连续灰段，其左端为 c_left，右端为 c_right。
   b. 检查 (r, c_left - 1) 和 (r, c_right + 1)：若在网格内且为背景(0)，则该位置为开口。
   c. 从每个开口位置 (r, c_opening) 的下一行 (r+1, c_opening) 开始一条新的向下射线分支。
3. 射线到达网格最底行或遇到无开口的墙段时终止。终止位置即为"终端节点"。
4. 每棵追踪树完全构建后，统计其终端节点数量 T。
5. 将整棵追踪树（所有被涂色的非墙单元格）统一重涂色：
   - T = 1：重涂为黄(4)。
   - T = 2：重涂为橙(7)。
   - T >= 3：重涂为栗(9)。
6. 每个标记像素（顶边第 0 行）保留其原始颜色作为标识，不参与重涂色。
7. 墙壁像素始终保持灰(5)。

**关键洞察**：追踪树的颜色不取决于其起点标记的颜色（那只是标识），而取决于树的拓扑复杂度（终端数）。求解者必须完成整棵树的前向追踪和分支后，才能"回溯"确定应使用的颜色——这是一个前向计算、后向着色的推理结构。

## 新题 9：形状唯一性决定操作类型

**组合逻辑**：[形状匹配 shape_matching + 计数 counting](创新：匹配结果不映射颜色，而是决定对该分量施加何种操作) → [印章覆盖 stamp](创新：仅对唯一形状分量执行邻域扩张) | [重涂色 recolor](对重复形状分量执行简单重涂)

**来源原语**：重涂色 recolor、连通分量 connected_component、精灵体 sprite、形状匹配 shape_matching、唯一重复形分涂 unique_vs_repeated_recolor（b230c067）；印章覆盖 stamp_overlay、标记像素 marker_pixel、邻域块 neighborhood_block、中心邻域 center_neighborhood、仅填背景格 only_bg_filled（f0df5ff0）

**依赖链**：提取所有连通分量 → 归一化形状并分组 → 判定唯一/重复 → 唯一分量获得邻域扩张操作（空间结构改变），重复分量仅获得简单重涂色（空间结构不变）。形状频率分析是操作分派的门控节点，而非颜色选择器。

前景图形按归一化形状分组；唯一形状的图形被扩张为红色邻域块，重复形状的图形仅被重涂为蓝色。

**输入结构**：
- 网格约 12x12，背景黑(0)。
- 4~6 个灰(5) 前景图形，每个为 4-连通分量，像素数 3~6。
- 恰好一个图形的归一化边界框掩码（平移至原点后的形状）与其他所有图形都不同（唯一形状）。其余图形分为 1~2 组，同组图形归一化形状相同（重复形状）。
- 各图形之间至少间隔 2 个背景像素（保证唯一图形扩张后不会与重复图形的扩张区域立即合并）。

**规则**：
1. 提取所有灰(5) 的 4-连通分量。
2. 对每个分量，计算其归一化形状：将其边界框平移至原点 (0,0)，得到像素位置集合。
3. 按归一化形状分组。
4. **重复形状分量**（组内成员数 >= 2）：将分量内所有像素从灰(5) 重涂为蓝(1)。不做空间修改。
5. **唯一形状分量**（组内成员数 = 1）：
   a. 将分量内所有像素重涂为红(2)。
   b. 对分量中每个像素，检查以其为中心的 3x3 邻域。将邻域中每个黑(0) 背景单元格涂为红(2)。
   c. 若扩张单元格的位置恰好是蓝(1)（已重涂的重复分量像素），则保留蓝(1) 不覆盖。
6. 其余背景单元格保持黑(0)。

**关键洞察**：在参考题 b230c067 中，形状唯一性仅决定颜色（红 vs 蓝）；在参考题 f0df5ff0 中，所有标记都获得相同的扩张操作。本题的创新在于：唯一性不只改变颜色，还决定是否执行空间扩张——唯一图形"绽放"为红色邻域块而重复图形保持紧凑蓝色轮廓，形成操作类型的条件分派。

## 新题 10：镜像修补启用周期检测后铺满

**组合逻辑**：[对称补全 symmetry_completion](创新：修补不是最终目的，而是为周期检测提供完整数据) → [平铺 tile + 补全 complete]

**来源原语**：对称补全 symmetry_completion、缺失区域 missing_patch、对称轴 symmetry_axis、镜像 mirror、镜像补缺并裁出 mirror_fill_missing_crop（9ecd008a）；平铺 tile、补全 complete、最小周期单元 minimal_period、局部图案 partial_motif、列周期重复 column_period、最小周期扩展 minimal_period_extend（d8c310e9）

**依赖链**：发现缺失区域 → 利用左右对称性镜像修补 → 修补后的完整图案呈现出可检测的最小列周期 → 按该周期铺满全网格宽度。对称修补是周期检测的前提条件——缺失块恰好跨越周期边界，使得不修补时周期不可识别或被误判为更大值。

先用左右对称性修补黑色缺失区域，再从修补后的完整图案中提取最小列周期并铺满全网格。

**输入结构**：
- 网格约 8x20（宽型），背景黑(0)。
- 最左 8~10 列包含由蓝(1) 和红(2) 像素构成的彩色图案（黑(0) 为底）。该图案在其横向跨度内具有左右镜像对称性。
- 图案内部有一个 3x3 的全黑(0) 矩形区域——缺失块。其关于对称轴的镜像对应区域完全有色（蓝或红像素，无黑色）。
- 网格的右侧剩余列全为黑(0) 背景。
- 生成约束：修补后的完整图案具有列周期 P（P = 3 或 4）。缺失块至少横跨一个周期副本的 2 列，使得修补前无法正确确定周期（缺失块使表观周期为 P 的倍数或不可检测）。

**规则**：
1. 在左侧有色区域内定位 3x3 的全黑(0) 矩形块（恰好一个）。
2. 确定左侧图案的垂直对称轴：图案水平跨度的中心列。
3. 对缺失块中的每个单元格 (r, c)，从其镜像位置 (r, 2 * axis - c) 复制颜色，完成修补。
4. 在修补后的完整图案上确定最小列周期 P：满足所有前景像素 (r, c) 的颜色等于 (r, c mod P) 处颜色的最小正整数 P。
5. 将该周期铺满全网格宽度：对每个单元格 (r, c)（从第 0 列到最后一列），将其颜色设为修补后图案在 (r, c mod P) 处的颜色。
6. 输出完整网格。

**关键洞察**：缺失块不是随意放置的破损——它被精心设置在周期边界处，使得不经修补就无法检测到真实周期。对称修补和周期铺排在参考题中各自独立，此处它们因果串联：修补使周期浮现，周期使铺排成为可能。若直接尝试从带缺口的图案寻找周期，会得到错误的铺排结果。
