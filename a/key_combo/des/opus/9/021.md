## 新题 1：选择器导航的镜像精灵体装配

**组合逻辑**：[颜色索引匹配](已有) + [标记几何定类型](创新：原用于决定外部对象的反射方式，此处嵌入精灵体内部决定自身变换) → [镜像](已有) → [图例位置映射 + 复制放置](已有，但放置的是变换后的结果而非原件)

**来源原语**：颜色索引匹配(7d18a6fb)、复制放置(7d18a6fb)、图例位置映射(7d18a6fb)、象限(7d18a6fb)、镜像(7ed72f31)、标记几何定类型(7ed72f31)、反射轴标记(7ed72f31)、精灵体(7d18a6fb/7ed72f31)

**依赖链**：颜色匹配把精灵体绑定到选择器象限 → 嵌入的红(2)标记几何决定镜像类型 → 镜像变换产生新形态 → 变换后结果放入对应象限。三条信息（颜色→位置、标记几何→变换类型、精灵体像素→变换输入）必须同时解析才能得到最终输出。

根据选择器的颜色标记将精灵体按颜色匹配到对应象限，同时根据每个精灵体内嵌红(2)像素的几何形态决定镜像方式，将变换后的精灵体放入输出象限。

**输入结构**：黑(0)背景上，约 15x15 网格。
- 网格中心偏位置有一个 7x7 选择器块：以灰(5)填满，四个 3x3 象限（左上、右上、左下、右下）的中心像素各为一种不同的前景色（从蓝(1)、绿(3)、黄(4)、品红(6)中选四种），其余像素均为灰(5)。象限之间由灰(5)的中间行和中间列分隔。
- 网格其余区域散布四个小精灵体，每个精灵体是一个 4-连通的单色前景区域（3~6 像素），边界框不超过 3x3。每个精灵体的非红像素颜色与选择器中某个象限标记颜色一一对应（无重复）。
- 每个精灵体内恰好包含一个红(2)像素。红像素的局部几何分为两种情况：
  - (a) 红像素位于精灵体内一条 3 像素直线（水平或垂直）的中心——该直线的方向即为反射轴方向（水平线→水平轴，垂直线→垂直轴）。
  - (b) 红像素在精灵体中不构成任何 3 像素直线的中心——此时做以红像素为中心的 180 度点反射。
- 生成约束：每个精灵体及其镜像结果均可容纳在 3x3 区域内；四个精灵体的红像素几何类型不全相同（至少出现两种类型）。

**规则**：
1. 将每个精灵体的非红像素颜色与选择器中同色的象限标记匹配，确定该精灵体对应的输出象限位置。
2. 检查每个精灵体中红(2)像素的局部几何：若红像素是精灵体内一条水平 3 像素线段的中心，则沿穿过红像素的垂直轴镜像所有非红像素；若红像素是垂直 3 像素线段的中心，则沿穿过红像素的水平轴镜像所有非红像素；若红像素不构成任何 3 像素线段的中心，则以红像素为中心对所有非红像素做 180 度点反射。镜像/反射产生的新像素保持原精灵体颜色；红像素本身保留为红(2)。
3. 构建 7x7 输出网格：灰(5)填底，中间行和中间列为灰(5)分隔。将步骤 2 得到的变换结果（非原件）放入步骤 1 确定的象限 3x3 区域，以红像素对齐象限中心。超出 3x3 区域的像素丢弃（生成时保证不会超出）。

**关键洞察**：精灵体并非直接复制到象限——它先经过由自身红像素几何编码的镜像变换。选择器只决定"放在哪里"，红标记决定"怎么变"，两者缺一不可。求解者需要同时解码颜色匹配、标记几何和位置映射三条逻辑链。

## 新题 2：单侧链式替换后的面板差异映射

**组合逻辑**：[图例行序决定替换 + 逐行顺序链式替换](已有) → [逐像素比较 + 差异分类着色](创新：替换只施加于单侧面板，差异映射增加"双方不同前景"的第三类分类)

**来源原语**：双列图例(e4888269)、图例行序决定替换(e4888269)、逐行顺序链式替换(e4888269)、面板(d47aa2ff)、分隔列(d47aa2ff)、面板对齐(d47aa2ff)、逐像素比较(d47aa2ff)、差异分类着色(d47aa2ff)、擦除(a78176bb)

**依赖链**：图例读取 → 链式替换改变左面板的颜色分布 → 替换后的左面板与未变的右面板逐像素比较 → 差异类型决定输出颜色。替换结果改变了比较的输入，因此最终差异映射既编码了原始差异，也编码了图例引入的变化。

读取左面板中的双列图例对左面板执行链式颜色替换，然后将替换后的左面板与原始右面板逐像素比较，按差异类型着色输出。

**输入结构**：约 10x21 的网格。
- 左面板和右面板宽度相同（各约 10 列），中间由一列灰(5)分隔列隔开。两面板高度相同。
- 两面板的背景为黑(0)，各有若干彩色前景像素构成的图案（4-连通小区域，3~8 像素，使用蓝(1)、绿(3)、黄(4)、品红(6)等颜色）。两面板图案大部分相似但有局部差异。
- 左面板左上角嵌有一个双列图例：宽 2 列、高 2~3 行的全填充小块，每行左列为替换源色、右列为替换目标色。图例与左面板其余图案之间至少隔一行和一列的黑(0)背景。图例中使用的颜色均来自面板中实际出现的前景色。
- 生成约束：图例的链式替换至少使左面板中某些像素颜色发生改变；替换后左面板与右面板既有匹配像素也有不匹配像素；至少存在一处"左右均有前景但颜色不同"的位置。

**规则**：
1. 从左面板左上角提取双列图例，按行从上到下读取：每行左列颜色为源色，右列为目标色。
2. 对左面板中图例以外的所有非背景像素执行链式替换：从图例第一行开始，若像素当前颜色等于该行源色，将其替换为该行目标色；然后继续检查后续行（用替换后的颜色继续匹配）。上行替换结果可触发下行替换。
3. 将图例区域像素设为背景色黑(0)（擦除图例）。
4. 移除分隔列，将变换后的左面板与原始右面板逐像素对齐比较：
   - 双方均为背景 → 输出黑(0)。
   - 双方均为相同前景色 → 输出该颜色。
   - 仅左面板有前景 → 输出红(2)。
   - 仅右面板有前景 → 输出蓝(1)。
   - 双方均有前景但颜色不同 → 输出黄(4)。
5. 输出尺寸等于单个面板的尺寸。

**关键洞察**：图例的链式替换仅作用于左面板——它可能将原本与右面板不同的像素"修正"为相同（差异消失），也可能将原本相同的像素改成不同（差异产生）。求解者必须意识到替换的不对称性，且链式顺序会级联改变颜色。

## 新题 3：同步生长碰撞与标记投票边界裁定

**组合逻辑**：[生长](已有) + [连通检测](创新：生长区域即连通体) → [标记归属区域 + 投票 + 最多标记区胜出](创新：标记投票不是决定输出颜色，而是决定边界像素归属)

**来源原语**：生长(758abdf0)、逐步推进(758abdf0)、连通检测(2753e76c)、投票(de1cd16c)、标记像素(de1cd16c)、标记归属区域(de1cd16c)、最多标记区胜出(de1cd16c)、擦除(a78176bb)

**依赖链**：种子位置决定生长方向 → 同步扩展产生碰撞边界 → 灰(5)标记像素被生长覆盖后归属于某个区域 → 各区域内标记计数 → 最多标记的区域"赢"→ 赢家吸收其邻接边界像素。生长的空间结构决定标记归属，标记归属反过来改变最终的空间结构（边界重划）。

多个彩色种子同步向外生长直到互相碰撞形成边界，然后根据各生长区域内灰色标记像素的数量投票，票数最多的区域吸收其邻接边界。

**输入结构**：约 14x14 黑(0)背景网格。
- 3~5 个小型种子对象，每个由 2~3 个 4-连通像素组成，各自为不同颜色（从蓝(1)、红(2)、绿(3)、黄(4)、品红(6)中选取）。种子之间互不相邻，最近曼哈顿距离至少为 4。
- 4~8 个灰(5)单像素标记，散布在网格中，不与任何种子 4-相邻。标记在各种子的潜在生长区域内分布不均匀。
- 生成约束：种子数量为奇数或各区域标记数互不相同（保证投票无平局）；所有标记最终均被某个区域的生长覆盖（无标记恰好落在边界上）。

**规则**：
1. 所有种子同步向外生长：每一步，每个种子区域的所有 4-邻接背景像素（包括灰(5)标记像素）同时被染为该种子的颜色。灰(5)标记像素被覆盖时记录其归属区域。
2. 若某个背景像素在同一步被两个或更多种子同时到达，该像素成为边界像素，标记为橙(7)，不归属任何区域。
3. 生长持续直到网格中无可染的背景像素（所有像素非种子色即边界色）。
4. 统计每个生长区域内覆盖的灰(5)标记数量。标记数最多的区域为"赢家"。
5. 所有与赢家区域 4-相邻的橙(7)边界像素被重涂为赢家颜色（赢家吸收邻接边界）。其余橙(7)边界像素保持不变。

**关键洞察**：同步生长形成类似 Voronoi 图的空间划分，但边界的最终归属不由几何对称决定，而由标记投票打破对称——灰色标记像素是"选票"，被哪个区域覆盖就为哪个区域投票，票数最多的区域扩张边界。标记在生长过程中被消耗（覆盖），但它们的空间位置（最终归属哪个区域）决定了边界重划。

## 新题 4：过滤计数驱动的模板印章直方图

**组合逻辑**：[计数 + 忽略干扰项](已有) → [排序 + 按数量降序](已有) → [颜色到模板映射 + 印章覆盖](创新：模板不是用于替换宏单元格，而是作为直方图的"刻度单位"被重复印章)

**来源原语**：计数(1fad071e)、忽略干扰项(1fad071e)、正方形块(1fad071e)、干扰体(1fad071e)、排序(2753e76c)、按数量降序(2753e76c)、印章覆盖(5833af48)、模板遮罩(42f83767)、颜色到模板映射(42f83767)

**依赖链**：过滤干扰体后精确计数 → 计数结果决定模板印章的重复次数 → 颜色匹配决定使用哪个模板 → 排序决定行顺序。四条信息互相耦合：漏掉干扰过滤则计数错误导致印章次数错，模板匹配错则形状错，排序错则行序错。

统计上方区域中各颜色实心 2x2 方块的数量（忽略单像素干扰），按数量降序排列，用下方对应颜色的模板遮罩重复印章构建直方图。

**输入结构**：约 18x15 黑(0)背景网格，分上下两区。
- 上方区域（约占上方 10 行）：散布若干彩色对象。其中"有效对象"为实心 2x2 正方形块（每个块内 4 像素同色），使用 2~3 种颜色（如蓝(1)、红(2)、绿(3)）。另有同色的单像素干扰体随机散布，不与任何 2x2 块 4-相邻。每种颜色的 2x2 块数量互不相同，范围 1~4。
- 下方区域（与上方区域间隔至少 2 行背景）：水平排列若干 3x3 模板遮罩，模板之间隔 1 列背景。每个模板由一种前景色在 3x3 区域内绘制一个不规则连通图案（3~7 像素为前景，其余为黑(0)），每种颜色恰好对应一个模板，模板颜色与上方区域使用的颜色一一对应。
- 生成约束：各颜色的 2x2 块数量互不相同；模板图案互不相同且均为 4-连通。

**规则**：
1. 在上方区域中扫描所有 2x2 窗口，统计完全由同色前景填满的窗口数量，按颜色分组计数。单像素干扰体不构成 2x2 窗口，自动被忽略。
2. 将下方区域的每个 3x3 模板按其绘制颜色与上方区域颜色匹配。
3. 按 2x2 块数量从多到少排序各颜色。
4. 构建输出：每种颜色占 3 个像素行（一个模板的高度）。在每行中，将该颜色的 3x3 模板从左到右重复印章 N 次（N = 该颜色的 2x2 块数量），模板间无间隔。模板中的前景像素使用对应颜色，模板中的黑(0)像素保持黑(0)。行与行之间无间隔，按降序从上到下排列。
5. 输出尺寸：高 = 3 x 颜色数，宽 = 3 x 最大块数量。

**关键洞察**：输出不是简单的彩色条形图——每个"条形段"是一个具有特定形状的模板遮罩副本。求解者需要同时理解三件事：(a) 只有 2x2 块计入计数，单像素不算；(b) 每种颜色有自己独特的模板形状；(c) 计数决定模板的重复次数，排序决定行的上下顺序。

## 新题 5：对称修复格子后的封闭性差异填充

**组合逻辑**：[推断对称轴 + 对称补全](已有) → [洪泛填充 + 完整与缺损区异色](创新：对称补全的修复程度决定哪些格子单元仍有缺口，缺口的持续性成为填充分类的依据)

**来源原语**：对称补全(981571dc)、推断对称轴(981571dc)、镜像对应(981571dc)、修复(981571dc)、格子框架(83302e8f)、封闭背景区域(83302e8f)、洪泛填充(83302e8f)、完整与缺损区异色(83302e8f)、包含(83302e8f)

**依赖链**：从残存格子像素推断双轴对称 → 对称补全修复可修复的缺口 → 修复后重新分析封闭性 → 完全封闭的单元格与仍然连通的多单元区域获得不同颜色。对称补全的程度直接改变拓扑连通性，而连通性决定填充颜色——这是"修复改变条件"的典型耦合。

修复一个被破坏的双轴对称格子框架，然后根据修复后各背景区域是否被完全封闭在单个格子单元内来差异化填色。

**输入结构**：约 13x13 黑(0)背景网格。
- 灰(5)像素构成一个矩形格子框架，本应形成规则的网格线（如将网格分为 3x3 或 4x3 个矩形单元，线宽 1 像素）。该格子本应关于网格的水平中轴和垂直中轴双轴对称。
- 格子中若干灰(5)像素被擦除为黑(0)，造成缺口。缺口分两类：
  - 非对称缺口：该位置被擦除，但其关于某条对称轴的镜像位置仍完好——可通过对称补全修复。
  - 对称缺口：该位置及其关于两条轴的所有镜像位置均被擦除——无法通过对称补全恢复。
- 部分格子单元内可能有红(2)或蓝(1)的标记像素（1~2 个/单元），这些标记像素不属于格子框架，不参与对称分析，仅作为后续填充的保留元素。
- 生成约束：至少有 2 个非对称缺口（可修复）和 1 个对称缺口（不可修复）；对称缺口使至少两个相邻单元的背景连通。

**规则**：
1. 从残存的灰(5)格子像素中推断水平和垂直对称轴位置（通常为网格的中间行和中间列）。
2. 对每个缺失的灰(5)格子位置（当前为黑(0)且根据格子规则应为灰(5)的位置），检查其关于任一对称轴的镜像位置：若镜像位置为灰(5)，则将该位置恢复为灰(5)。两条轴均尝试。
3. 修复完成后，识别所有 4-连通的黑(0)背景区域。
4. 对每个背景区域计算其面积和其最小包围矩形面积：
   - 若区域面积等于其包围矩形面积（即区域恰好填满一个矩形，说明它是一个完整的单格子单元内部），填充为绿(3)。
   - 若区域面积小于其包围矩形面积（区域形状不规则，说明通过未修复的缺口连通了多个单元），填充为黄(4)。
5. 区域内原有的红(2)或蓝(1)标记像素保留原色，不被填充覆盖。格子框架保持灰(5)。

**关键洞察**：对称缺口（出现在两个对称位置上的缺口）无法通过镜像修复，成为持久的连通通道。一个单元是否被完全封闭，取决于它周围的缺口是否全部被修复——对称补全的"能力边界"直接决定了填充分类。求解者必须先理解对称修复的局限性，再推导拓扑后果。

## 新题 6：射线命中与全局尺寸门槛的双重过滤擦除

**组合逻辑**：[射线延伸 + 射线命中](已有) → [连通检测 + 计数](创新：连通体的像素面积构成全局统计量) → [命中即整体擦除](创新：擦除条件不仅是"被射线命中"，还需通过全局面积门槛的筛选)

**来源原语**：射线延伸(2f767503)、标记条(2f767503)、控制像素(2f767503)、射线命中(2f767503)、命中即整体擦除(2f767503)、连通检测(2753e76c)、计数(1fad071e)、目标对象(2f767503)、单色连通体(2753e76c)

**依赖链**：标记条+控制像素 → 射线方向 → 射线命中筛选出空间候选集 → 全局连通体尺寸中位数提供门槛 → 仅尺寸低于门槛的命中对象被擦除。空间过滤（射线）和属性过滤（面积门槛）缺一不可。

从标记条发射射线，命中的蓝色对象中只有面积小于所有蓝色对象面积中位数的才被擦除，其余保留。

**输入结构**：约 14x14 黑(0)背景网格。
- 一个红(2)标记结构，由三部分组成：一条 3 像素直线（水平或垂直）的红(2)标记条，加上一个红(2)控制像素，该控制像素与标记条中心像素 4-相邻且垂直于标记条方向。整体形成 T 字形。
- 5~7 个蓝(1)的 4-连通目标对象，面积（像素数）各不相同，范围 2~10 像素，形状为任意 4-连通图形（非特定几何名称）。对象间互不接触，也不与红(2)标记接触。
- 生成约束：对象总数为奇数（保证中位数唯一）；射线路径上至少命中 2 个对象，其中至少 1 个面积低于中位数、至少 1 个面积不低于中位数；至少有 1 个未被命中的对象。

**规则**：
1. 确定射线方向：从标记条中心像素出发，沿远离控制像素的方向（即控制像素指示的反方向）发射一条无限长射线。
2. 找出射线路径上经过的所有蓝(1)像素，将包含这些像素的 4-连通蓝色对象标记为"命中对象"。
3. 计算所有蓝(1)对象（无论是否命中）的像素面积，求中位数 M（奇数个对象时取中间值）。
4. 在命中对象中，擦除（设为黑(0)）面积严格小于 M 的对象的全部像素。面积大于等于 M 的命中对象保留不变。
5. 未被射线命中的对象无论面积大小均保留不变。红(2)标记结构保留不变。

**关键洞察**：擦除需要同时满足两个条件——空间条件（被射线命中）和属性条件（面积小于全局中位数）。仅靠射线位置无法确定哪些对象消失，仅靠面积大小也无法确定——两者的交集才是擦除目标。全局中位数的计算包括未命中对象，因此远离射线的对象也间接影响哪些命中对象被擦除。

## 新题 7：引导体生成平行对角线以启用十字体连线

**组合逻辑**：[引导体定新对角线 + 射线延伸 + 擦除](已有) → [中心对角对齐 + 无障碍通路 + 连线](创新：新对角线创造了原本不存在的对齐路径) → [重涂色](创新：连通性结果决定重涂)

**来源原语**：射线延伸(a78176bb)、对角线段(a78176bb)、引导体(a78176bb)、平行偏移(a78176bb)、引导体定新对角线(a78176bb)、擦除(a78176bb)、连线(55059096)、十字图案(55059096)、中心对角对齐(55059096)、无障碍通路(55059096)、重涂色(c9f8e694)

**依赖链**：引导体远端顶点 → 生成平行对角线 → 对角线重塑"对齐地形" → 十字体对检查对角对齐（含新旧对角线）→ 通路畅通则连线 → 参与连线的十字体变色。引导体的建设性操作是连线操作的前提条件——没有新对角线，部分十字体对永远无法对齐。

从引导体生成平行对角线后擦除引导体，然后在所有（新旧）对角线上寻找对角对齐的十字体对，畅通路径上画连线，被连线的十字体变色。

**输入结构**：约 16x16 黑(0)背景网格。
- 一条绿(3)对角线从网格一角或边附近延伸至另一侧，占据连续的 45 度像素序列（每步行列各变化 1）。
- 2~3 个灰(5)直角三角形引导体（每个由 3~6 个灰(5)像素组成，构成一个直角三角形轮廓或实心），一条直角边紧贴绿(3)对角线。每个三角形有一个"远端顶点"——距离绿对角线最远的像素。
- 4~6 个蓝(1)十字图案对象（5 像素：中心 + 四个正交邻居，边界框 3x3），散布在网格中，不与对角线或引导体重叠。
- 生成约束：至少存在一对十字体中心沿某条新生成的对角线对角对齐（沿原始对角线不对齐），且路径上无非背景/非对角线像素阻挡；至少有一个十字体不参与任何连线。

**规则**：
1. 对每个灰(5)引导体，找到距绿(3)对角线最远的顶点像素。通过该顶点画一条与原始绿对角线平行的绿(3)对角线，向两端延伸至网格边缘。然后擦除所有灰(5)像素（设为黑(0)）。
2. 检查所有十字体中心的两两组合：若两个中心的行差绝对值等于列差绝对值（即位于同一 45 度线上），则它们"对角对齐"。
3. 对每对对角对齐的十字体，检查连线路径：从一个中心到另一个中心的 45 度直线上的每个中间像素（不含两端中心），若全部为黑(0)背景或绿(3)对角线像素，则路径"畅通"。
4. 对路径畅通的对，将路径上所有黑(0)中间像素涂为红(2)（绿(3)对角线像素保持不变）。
5. 任何参与了至少一条红(2)连线的十字体，将其全部 5 个像素从蓝(1)重涂为橙(7)。未参与连线的十字体保持蓝(1)。

**关键洞察**：引导体不只是装饰——它们生成的平行对角线创造了新的对齐通道。某些十字体对在原始对角线上并不对齐，但在新生成的平行对角线方向上恰好对齐。求解者必须先构建所有对角线，再判断哪些十字体对因此获得了连接条件。这是一个典型的"建设使能连接"涌现模式。

## 新题 8：格子路由的标记滑动与多源投票填充

**组合逻辑**：[滑动 + 碰撞停止](创新：滑动路径不是朝向自由空间中的锚点，而是沿格子框架的线路) → [标记归属区域](创新：归属由滑动终点与格子单元的空间关系决定，而非由标记的原始位置决定) → [投票 + 洪泛填充](创新：同一单元可收到多个不同颜色标记，需多数投票决定填充色)

**来源原语**：滑动(a48eeaf7)、碰撞停止(a48eeaf7)、射线对齐(a48eeaf7)、格子框架(83302e8f)、封闭背景区域(83302e8f)、投票(de1cd16c)、标记归属区域(de1cd16c)、最多标记区胜出(de1cd16c)、洪泛填充(83302e8f)、标记像素(a48eeaf7/de1cd16c)、填充块(a48eeaf7)

**依赖链**：格子框架提供路由线路 → 标记沿格子线滑向锚点 → 碰撞停止于锚点邻环 → 停靠位置关联特定格子单元 → 同一单元的多标记投票 → 投票结果决定填充颜色。标记的原始位置、格子结构、锚点位置三者共同决定标记的终点和归属。

将格子线上的彩色标记像素沿格子路由滑向中央锚点，停在锚点邻环后归属到相邻格子单元，每个单元按收到标记的多数颜色洪泛填充。

**输入结构**：约 14x14 黑(0)背景网格。
- 灰(5)格子框架将网格分为规则的矩形单元（如 4x4 单元，每单元约 3x3 像素大小），格子线宽 1 像素。
- 蓝(1)的 2x2 锚点块放置在格子的某个十字交叉点上（覆盖四个单元共享的角区域）。
- 若干彩色标记像素（红(2)、绿(3)、黄(4)），每个放置在格子线上（即灰(5)像素位置，标记颜色覆盖灰色）。每个标记与锚点块中心处于同行或同列。
- 生成约束：每个标记沿格子线到锚点的路径是连续灰(5)像素（无中断）；至少有一个单元接收到 2 个以上不同颜色的标记；各标记颜色总数不完全相同，确保投票有结果差异。

**规则**：
1. 每个标记像素沿其所在行或列的格子线朝蓝(1)锚点滑动。标记沿灰(5)格子像素逐步移动，到达与锚点块任一像素 4-相邻的格子像素时停止。标记滑过的原位置恢复为灰(5)。
2. 每个标记的停靠位置恰好与锚点块的一侧相邻，同时也与恰好一个格子单元（停靠位置与锚点之间的那个单元）相邻。将该标记关联到这个单元。
3. 对每个关联了标记的单元：统计其收到的各颜色标记数量。颜色数最多的为"赢色"，将该单元的黑(0)背景区域洪泛填充为赢色。若出现平局，选择从更远处滑来的标记（即原始位置距锚点曼哈顿距离最大的那个标记）的颜色。
4. 未收到任何标记的单元保持黑(0)。锚点块保持蓝(1)。格子框架保持灰(5)（含标记滑过后恢复的灰色）。

**关键洞察**：格子框架不仅是空间分隔，更是标记的"铁轨"——标记只能沿格子线移动。锚点是所有标记的目的地，但格子结构将来自不同方向的标记路由到锚点的不同侧面，从而分配到不同的单元。两个从不同方向到达同一侧的标记会竞争同一个单元的填充权。

## 新题 9：条形图输入作为选择性描边的门槛

**组合逻辑**：[计数 + 忽略干扰项](已有) → 与 [条形图解码](创新：条形图从输出角色变为输入角色，编码门槛值而非结果) → [比较后条件触发描边](创新：描边不在交叉点执行，而是对满足数量条件的对象执行)

**来源原语**：计数(1fad071e)、忽略干扰项(1fad071e)、正方形块(1fad071e)、干扰体(1fad071e)、条形图(1fad071e)、计数编码为条长(1fad071e)、描边(67a423a3)、交叉邻域环涂色(67a423a3)

**依赖链**：解码条形图获得各颜色的门槛值 → 独立计数各颜色的有效对象数量 → 逐颜色比较计数与门槛 → 超过门槛的颜色的所有对象被描边。条形图解码和对象计数是两条独立的信息流，必须汇合比较后才能确定描边目标。

解读输入中的条形图获得各颜色的计数门槛，独立统计上方的 2x2 方块数量，超过门槛的颜色的所有方块获得黄色描边环。

**输入结构**：约 16x14 黑(0)背景网格，分上下两区。
- 上方区域（约 10 行）：散布若干 2x2 实心正方形块和单像素干扰体。使用 3 种颜色（如蓝(1)、红(2)、绿(3)）。每种颜色的 2x2 块数量范围 1~5。单像素干扰体与 2x2 块颜色相同但独立散布，不与任何块 4-相邻。
- 下方区域（与上方区域间隔至少 2 行背景）：一个条形图结构。条形图由灰(5)单像素宽的矩形边框包围。框内每行高 1 像素、宽度可变（1~5 像素），每行颜色为上方区域使用的颜色之一，行与颜色一一对应。条形从左侧起始对齐，条长代表该颜色的门槛值。行顺序为：按颜色在上方区域从左到右、从上到下首次出现的位置排列。
- 生成约束：至少一种颜色的 2x2 块数量严格大于其门槛值；至少一种颜色的 2x2 块数量等于其门槛值；至少一种颜色的 2x2 块数量严格小于其门槛值。

**规则**：
1. 从下方条形图中读取每种颜色的门槛值 T：该颜色条形的像素长度即为 T。
2. 在上方区域中扫描每个 2x2 窗口，统计每种颜色的完全填充的 2x2 块数量 C。单像素干扰体不构成 2x2 块，被忽略。
3. 对每种颜色，比较 C 和 T：
   - 若 C > T：对该颜色的每个 2x2 块绘制黄(4)描边环——即将该块四周所有 4-相邻的像素（不属于块本身的位置）涂为黄(4)。若描边位置已有其他前景色（另一个块的像素或另一个描边），则黄(4)覆盖之。
   - 若 C <= T：该颜色的所有块不做任何修改。
4. 条形图及其灰(5)边框保持不变。干扰体像素保持不变。

**关键洞察**：条形图不是输出而是输入——它编码的是门槛值，不是计数结果。求解者需要同时进行两个独立的信息提取（解码条形图 + 计数方块），然后交叉比较以决定哪些对象获得描边装饰。仅分析条形图或仅计数方块都无法确定最终输出。
