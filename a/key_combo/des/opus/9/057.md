## 新题 1：同心方框生长与交叉遮挡分层

**组合逻辑**：[生长/grow + 同心方框层/concentric_layer](已有) → [遮挡层次/occlusion_order + 排序/sort](已有，创新：遮挡序由种子的跨组空间侵入关系决定) → [重涂色/recolor](已有，创新：重叠区按分层序上色)

**来源原语**：生长/grow、同心方框层/concentric_layer、种子像素/seed_pixel、等距对角排列/equi_diag_array（参考题 5c2c9af4）；排序/sort、层序推断/layer_infer、遮挡层次/occlusion_order、交叉点/crossing_point、唯一序链/unique_chain（参考题 22425bda）

**依赖链**：每组种子生长出的同心方框面积取决于种子间距，而某组方框是否覆盖另一组的种子像素位置决定了遮挡的上下关系——种子同时充当生长参数和遮挡判据，两个操作通过种子位置的双重角色紧耦合。

从多组等距对角种子分别生长同心方框，再根据方框对他组种子的空间侵入关系确定分层顺序，渲染重叠区的可见颜色。

**输入结构**：约 20x20 的黑(0)背景网格。其上散布 3-4 组种子像素，每组由 3 个同色像素组成，三点位于同一条 45 度对角线上且间距相等（不同组间距可不同）。不同组使用不同颜色，可选蓝(1)、红(2)、绿(3)、黄(4)等。各组的对角线方向和间距在不同示例中有所变化。生成约束：不同组的中心种子像素之间的曼哈顿距离至少为 4，保证方框有交叠但种子本身不重合。

**规则**：
1. 对每组 3 个同色种子像素，找到中间点（中心种子）和两端点之间的间距 d。
2. 以中心种子为中心，在间距 d 的整数倍处画同心空心方框边框（与参考题 5c2c9af4 相同），直到方框完全超出网格边界。方框使用该组颜色绘制。
3. 判定遮挡顺序：若 A 组的任意方框边框覆盖了 B 组的某个种子像素的位置（以初始种子位置为准，非生长后），则 A 在 B 之下（B 遮挡 A）。沿此关系传递排序，构成一条从底到顶的唯一序链。生成约束保证此关系无环且形成唯一全序。
4. 按从底到顶的顺序依次渲染各组方框：后渲染的覆盖先渲染的。非重叠区域保留各组颜色，重叠区域显示层次更高组的颜色。
5. 种子像素本身保留在输出中，颜色不变。

**关键洞察**：种子像素的位置同时决定了方框的生长中心/尺寸和跨组遮挡顺序——删掉遮挡逻辑则重叠区颜色不确定，删掉生长逻辑则无方框可供分层。遮挡方向需要对比多个示例才能归纳（侵入 vs 被侵入的上下关系不靠直觉可判断）。

## 新题 2：重力下落触发条件性镜像反射

**组合逻辑**：[重力下落/gravity_drop + 填充/fill](已有) → [条件分支：已填充 vs 未填充](创新) → [镜像/reflect + 跨标记线反射](已有，创新：仅对已填充容器执行反射，反射色由稀疏标记线颜色决定)

**来源原语**：重力下落/gravity_drop、填充/fill、标记像素/marker_pixel、容器/container、列对齐落入/column_fall_in、无容器则铺满底行/no_container_floor（参考题 db7260a4）；镜像/reflect、稀疏标记线/sparse_marker_line、平行对称轴/parallel_axes、跨标记线反射/reflect_across_markers（参考题 66ac4c3b）

**依赖链**：重力下落的结果（哪些容器被填充）成为镜像反射的触发条件——只有被标记色填充的容器才参与反射，未填充容器及底行泼溅保持不变。反射操作的输入依赖于填充操作的输出。

标记像素从顶行下落进入 U 形容器并填充，随后仅将已填充容器跨稀疏标记行反射到网格另一侧，以标记行颜色重涂反射副本。

**输入结构**：约 18x15 的黑(0)背景网格。顶行有 2-3 个单像素标记，颜色各异（如蓝(1)、绿(3)）。网格中有 3-4 个灰(5)色 U 形容器（两根竖条 + 底部横段，内部空），分布在不同列位置。一条水平的橙(7)色稀疏标记行位于网格中部偏下（标记行上有若干等距的橙(7)像素，其余为黑(0)），将网格分为上下两区。所有容器均在上区。生成约束：至少有一个标记的列不在任何容器的水平覆盖范围内（保证"无容器则铺满底行"的分支至少触发一次），至少有一个标记对应一个容器。

**规则**：
1. 对每个顶行标记像素，擦除其原位置。
2. 将标记沿列方向下落：若该列在某个 U 形容器的水平覆盖范围内，则用标记颜色填满该容器的空心内部。若该列不在任何容器覆盖范围内，则用标记颜色填满"底行"——即稀疏标记行正上方的那一行（而非网格最底行）。
3. 填充完成后，对每个被填充的容器，将其（包括容器壁和填充色）沿稀疏标记行做镜像反射到下区对称位置。反射得到的容器壁保持灰(5)不变，但反射得到的内部填充色替换为橙(7)（稀疏标记行的颜色）。
4. 未被填充的容器和底行泼溅（如果有）不参与反射，保持原样。
5. 稀疏标记行本身保持不变。

**关键洞察**：填充操作的结果决定了哪些容器参与后续反射——这不是一个固定的两步流水线，而是"重力下落的结果充当条件门控"。需要对比多个示例才能归纳出"仅填充容器反射、底行泼溅不反射"的选择规则。

## 新题 3：轮廓滑动终点确定扫描线填充参考列

**组合逻辑**：[滑动/slide + 轮廓邻接/contour_adjacency + 最长贴边路径/longest_adjacent_path](已有) → [填充/fill + 墙壁界定范围/wall_bounds_span + 标记列为参考/marker_col_ref](已有，创新：参考列不是标记原始位置，而是轮廓滑动的终点列)

**来源原语**：滑动/slide、障碍轮廓/obstacle_contour、轮廓邻接/contour_adjacency、最长贴边路径/longest_adjacent_path（参考题 97c75046）；填充/fill、墙壁像素/wall_pixel、扫描线区间/scanline_interval、墙壁界定范围/wall_bounds_span、标记列为参考/marker_col_ref（参考题 78e78cff）

**依赖链**：标记像素先沿障碍轮廓滑动至终点，该终点的列坐标成为扫描线填充的参考列。障碍的形状决定滑动路径，进而决定参考列，进而决定填充范围——三步之间信息逐级变换而非简单传递。

标记沿障碍轮廓滑到尽头，用终点列作为参考列，再根据墙壁像素的扫描线区间做填充。

**输入结构**：约 16x16 的黑(0)背景网格。包含：一个红(2)色 4-连通不规则障碍区域（约 8-15 像素，非矩形，有凹凸边缘）；一个蓝(1)色单像素标记，位于障碍附近但不与障碍相邻，且与障碍之间有且仅有一条水平或垂直的直线视线；若干黄(4)色墙壁像素，分散在网格的多行上，每行 0-2 个墙壁像素。生成约束：标记沿轮廓滑动后终点列必须位于某些墙壁像素行的左右墙壁之间，保证填充有效。标记与障碍之间的视线方向在不同示例中变化。

**规则**：
1. 找到蓝(1)标记到红(2)障碍之间唯一的水平或垂直视线。
2. 沿视线找到障碍前最后一个背景像素。从该像素出发，尝试沿障碍外轮廓的两个对角方向转弯。
3. 选择能保持与障碍 4-邻接距离最长的那个方向，将标记移至该路径的终点。擦除标记原位。
4. 以标记终点所在的列为参考列。在每个含有黄(4)墙壁像素的行上，找到参考列严格左侧最近的墙壁和参考列处或右侧最近的墙壁，将两者之间的背景像素填充为蓝(1)。若某行仅有一侧墙壁，则从该墙壁填充到对侧网格边缘。
5. 在最上方墙壁行与最下方墙壁行之间、无墙壁像素的空行，整行填充蓝(1)。
6. 在墙壁行带之外的空行，复用最近端墙壁行的填充区间。
7. 保留墙壁像素、障碍像素和终点处标记像素的颜色不变。

**关键洞察**：参考列并非标记的初始位置，而是经轮廓滑动后才确定的——障碍形状间接控制了填充图案。删掉滑动步骤则参考列错误，删掉填充步骤则无输出图案。需要对比示例才能归纳"终点列 = 参考列"而非"起点列 = 参考列"。

## 新题 4：去噪条纹颜色驱动对角线段配对填充

**组合逻辑**：[去噪/denoise + 主色占优/dominant_color + 主色覆盖全行列/dominant_fills_line](已有) → [配对判据传递](创新：去噪后的条纹颜色决定对角线段的配对) → [填充/fill + 平行配对/parallel_pairing + 段间区域填充/fill_between_segments](已有)

**来源原语**：去噪/denoise、条纹行列/stripe_line、噪声像素/noise_pixel、主色占优/dominant_color、主色覆盖全行列/dominant_fills_line（参考题 e26a3af2）；填充/fill、对角线段/diagonal_segment、平行四边形区域/parallelogram_region、平行配对/parallel_pairing、段间区域填充/fill_between_segments（参考题 7666fa5d）

**依赖链**：条纹方向的推断和去噪是获取正确条纹颜色的前提；去噪后每条对角线段所在条纹的干净颜色成为配对键——同一干净条纹颜色上的平行线段配对。去噪改变了颜色信息，颜色信息改变了配对方式，配对方式改变了填充区域。三步之间存在信息变换链，不是简单传递。

先去噪恢复条纹底色，再用干净的条纹颜色将散落的对角线段两两配对，最后填充每对平行线段之间的平行四边形区域。

**输入结构**：约 18x18 的网格，整体为水平或垂直条纹图案（3-5 条条纹，每条占 3-5 行/列），使用蓝(1)、绿(3)、黄(4)等颜色。条纹上散布少量噪声像素（约占条纹面积的 10-15%），噪声像素可能使用其他条纹颜色或灰(5)等额外颜色，导致条纹边界模糊。在条纹之上，叠加有若干橙(7)色短对角线段（每段 2-4 像素，位于反对角线 r+c=const 上）。这些线段总是成对出现，每对位于同一条纹内且互相平行（r-c 轴常数不同但 r+c 方向平行）。生成约束：每条条纹上有 0 或 2 条对角线段（即要么无段，要么恰好一对）；噪声不会覆盖对角线段像素。

**规则**：
1. 判断条纹方向：分别计算按行解释和按列解释时，每行/列的主色像素占比之和，选择总占比更高的方向（忽略橙(7)对角线段像素后统计）。
2. 按选定方向去噪：将每行（或列）中所有非橙(7)像素替换为该行（或列）的主色。
3. 对每条橙(7)对角线段，记录其所在条纹去噪后的颜色。
4. 将去噪条纹颜色相同的平行对角线段配对。对每一对，沿主对角线方向（r-c = const）扫描，填充两段之间的所有背景像素为红(2)。
5. 条纹颜色、橙(7)线段像素和已填充的红(2)像素共存于输出中。

**关键洞察**：噪声使条纹颜色模糊，去噪前无法确定哪些线段该配对——例如两条相邻条纹被噪声"混色"后看似同色，去噪后实为不同色，其上的线段不应配对。需要对比多个示例才能归纳出"去噪后条纹颜色 = 配对键"的规则。

## 新题 5：路径端点拼接后恢复周期缺损

**组合逻辑**：[滑动/sliding + 端点对齐/endpoint_align + 端点匹配拼接/endpoint_match_concat](已有) → [几何重排改变周期结构](创新：拼接后的垂直对齐产生新的像素排列) → [补全/completion + 周期重复/periodic_repeat + 前景残留推断周期/residue_infers_period](已有)

**来源原语**：滑动/sliding、路径片段/path_segment、端点/endpoint、端点对齐/endpoint_align、端点匹配拼接/endpoint_match_concat（参考题 d017b73f）；补全/completion、周期瓦片/periodic_tile、缺损像素/erased_pixel、周期重复/periodic_repeat、前景残留推断周期/residue_infers_period（参考题 ea959feb）

**依赖链**：路径片段的端点拼接改变了各片段的垂直位置，这直接影响拼接后图案的周期结构。正确推断周期需要正确的拼接对齐，而正确的拼接需要识别端点——两个操作通过几何对齐关系耦合，而非数据的顺序传递。

将分隔的路径片段按端点对齐拼接成连续链，拼接后的图案呈现带缺损的周期结构，推断最小周期并补全缺损像素。

**输入结构**：约 8x20 的黑(0)背景网格（矮而宽）。包含 3-4 组路径片段，每组占据连续的若干非背景列，组间由全背景列分隔。每组使用多种前景色（如蓝(1)、红(2)、绿(3)），形成类似路径的图案。每组在其左边缘和右边缘各有一个度为 1 的前景端点像素（即仅有一个前景邻居的前景像素）。拼接后的完整图案应具有行列周期性，但部分前景像素被擦除为黑(0)。生成约束：拼接后的图案的最小行周期和最小列周期均不超过 4；被擦除的像素数不超过拼接后前景总像素数的 30%。

**规则**：
1. 识别由全背景列分隔的路径片段组。
2. 删除全背景分隔列。保持第一组的垂直位置不变。
3. 从左到右逐组拼接：将当前组垂直平移，使其左端点与前一组的右端点位于同一行，然后紧贴前一组右侧放置。
4. 拼接完成后，忽略黑(0)像素，从剩余前景像素中推断最小行周期 pr 和最小列周期 pc，使得每个前景像素的颜色与同一残差类 (r mod pr, c mod pc) 中其他前景像素颜色一致。
5. 对每个残差类，若该类中有前景像素，则将该类中所有黑(0)像素补全为该类的前景颜色。无前景证据的残差类保持黑(0)。

## 新题 9：同心方框生长与周期色彩缺损修复

**组合逻辑**：[生长/grow + 等距对角排列/equi_diag_array + 间距决定同心重复/spacing_concentric_repeat](已有) → [层归属判定](创新：将生长后的像素按距离中心的切比雪夫距离分层) → [补全/completion + 周期重复/periodic_repeat + 前景残留推断周期/residue_infers_period](已有，创新：周期作用在同心层序号上而非行列坐标上)

**依赖链**：同心方框的层归属由生长几何决定（每个像素属于第几层方框），而层颜色由周期规律决定（第 k 层的颜色 = 调色板[k mod period]）。两者必须联合求解：部分层上有像素被擦除为背景色，区分"真正的背景像素"和"被擦除的方框像素"需要同时知道层边界和颜色周期。

从对角种子生长同心方框，方框各层按周期循环涂色，部分层的像素被擦除，需要推断颜色周期并修复缺损。

**输入结构**：约 19x19 的黑(0)背景网格。包含 3 个同色像素（如红(2)），位于同一条 45 度对角线上且等距，标记同心方框的中心和间距。以中心种子为圆心，已绘制若干层同心方框边框，每层使用不同颜色。层颜色按周期 P（P = 2 或 3）循环，使用从蓝(1)、绿(3)、黄(4)、灰(5)中选取的 P 种颜色。但某些层中有部分边框像素被擦除为黑(0)——擦除分散而非整层消失，使得每层至少保留 30% 的像素。生成约束：种子像素不被擦除；至少每种周期颜色在某层中有可见像素（保证周期可推断）；方框至少有 4 层。

**规则**：
1. 找到 3 个红(2)种子像素，确定中心种子和间距 d。
2. 以中心种子为中心，计算每个非黑像素到中心的切比雪夫距离（max(|dr|, |dc|)），除以 d 并四舍五入，得到该像素的层编号 k（k = 1, 2, 3, ...）。
3. 收集所有可见（非黑）方框像素的 (层编号 k, 颜色) 对。对每个层编号，统计其可见像素的主色。
4. 从这些 (k, 主色) 数据中，推断最小颜色周期 P：找到最小的 P 使得对所有有可见像素的层 k，颜色 = palette[k mod P]，其中 palette 是长度为 P 的颜色序列。
5. 对每个层编号 k，确定该层应覆盖的完整像素集合：所有切比雪夫距离四舍五入为 k*d 的网格位置上、位于方框边框上的像素（即 max(|dr|, |dc|) 恰好在 [(k-0.5)*d, (k+0.5)*d) 范围内且位于该层方框的四条边之一上）。
6. 将这些位置中为黑(0)的像素恢复为 palette[k mod P] 的颜色。
7. 种子像素保持红(2)不变。

**关键洞察**：周期不是作用在行列坐标上（如参考题 ea959feb），而是作用在同心层序号上——必须先从几何关系推断每个像素属于哪一层，才能应用周期着色规则。被擦除的像素与真正的背景像素在视觉上相同，只有通过层几何才能区分。

**规则**：

3. 识别缺损帧：精灵体蓝(1)像素数明显少于其他帧的那一帧。
4. 根据缺损帧的序号和 delta，计算该帧中精灵体应处的正确顶行位置，在该位置放置完整精灵体模板，得到参考帧图像。
5. 将参考帧与缺损帧逐像素比较：找出参考帧中为蓝(1)而缺损帧中为黑(0)的像素位置。
6. 将这些缺失位置构成的掩码裁剪到其自身的最小边界框，缺失像素重涂为红(2)，其余为黑(0)。
7. 输出即为裁剪后的缺失掩码。

## 新题 11：连线路径交叉颜色编码驱动层序排列

**组合逻辑**：[连线/draw_line + 两点直线路径/straight_two_point + 按原色区分涂色/recolor_by_origin](已有，创新：多组标记对产生多条交叉线) → [交叉颜色产生遮挡约束](创新：连线相交处的可见色与被覆盖色给出上下关系) → [排序/sort + 层序推断/layer_infer + 唯一序链/unique_chain](已有，创新：排序对象不是预存在的线而是刚画出的线)

**来源原语**：连线/draw_line、标记像素/marker_pixel、线段/line_segment、两点直线路径/straight_two_point、按原色区分涂色/recolor_by_origin（参考题 bcb3040b）；排序/sort、层序推断/layer_infer、直线/straight_line、交叉点/crossing_point、遮挡层次/occlusion_order、唯一序链/unique_chain（参考题 22425bda）

**依赖链**：连线操作生成了线段实体，这些线段的交叉产生了遮挡信息，遮挡信息驱动层序排序。连线的"按原色区分涂色"规则在交叉处产生了双色冲突，冲突解决方式（后画的覆盖先画的）本身编码了绘制顺序——但输出要求的是与绘制顺序无关的、由空间关系决定的层序。两个逻辑形成对抗性耦合。

多对同色标记画出直线段，线段在交叉处产生颜色覆盖，从覆盖关系推断唯一的层序链并输出颜色序列。

**输入结构**：约 15x15 的黑(0)背景网格。包含 3-4 对标记像素，每对同色，可用蓝(1)、红(2)、绿(3)、黄(4)等颜色。每对标记位于同一水平线、垂直线或 45 度对角线上。另有少量灰(5)色前景像素散布在网格中（作为"原有前景"）。各对标记之间的连线路径至少两两有一个交叉点。生成约束：所有交叉点处的遮挡关系构成一条无矛盾的唯一全序链（即不存在 A 在 B 上方且 B 在 A 上方的环）；每条线至少与另一条线交叉一次。

**规则**：
1. 对每对同色标记，画出包含两端点的直线路径。路径上每个像素：若原为灰(5)则变为橙(7)，若原为黑(0)或为标记色则变为该对标记的颜色。
2. 当多条线的路径经过同一个像素时，该像素显示最后一条线的颜色（按线的颜色在输入中标记像素从左上到右下的扫描顺序决定先后，靠后的覆盖靠前的）。
3. 从交叉处的可见颜色推断遮挡关系：在交叉像素处，可见颜色的线在被覆盖颜色的线之上。
4. 将所有线的颜色排成一条从底到顶的唯一序链，要求相邻颜色在序链中对应的线几何上有交叉。
5. 输出为一行 1xK 的网格（K 为线的数量），从左到右排列层序链中从底到顶的颜色。

**关键洞察**：连线操作不仅生成了视觉线段，还通过覆盖规则隐式编码了绘制顺序，而绘制顺序正是遮挡关系的来源。需要对比多个示例才能归纳绘制顺序规则（扫描序而非其他顺序）以及层序链的输出方向（底到顶从左到右）。

## 新题 12：镜像拼接构建参考后提取移动轨迹

**组合逻辑**：[镜像/mirror + 拼接/concatenate + 翻转后拼接/flip_append](已有，创新：拼接后的双倍画布是对称参考而非直接输出) → [移动/move + 标记在矩形外侧/marker_outside_rect](已有，创新：移动操作产生的痕迹成为差异来源) → [差异提取/difference_extraction + 对齐比较/aligned_comparison](已有，创新：参考是自构建的镜像体，而非输入中的另一个对象)

**来源原语**：镜像/mirror、拼接/concatenate、画布/canvas、翻转后拼接/flip_append（参考题 6fa7a44f）；移动/move、标记像素/marker_pixel、矩形/rectangle、标记在矩形外侧/marker_outside_rect、擦除/erase、重涂色/recolor、相对顺序决定出口/order_determines_exit（参考题 e4941b18）；差异提取/difference_extraction、对齐比较/aligned_comparison、缺失掩码/missing_cell_mask（参考题 2037f2c7）

**依赖链**：输入画布本身是一个经过标记移动操作"打乱"的镜像拼接体。解题者需要：(1) 认出画布的上半部分应与下半部分互为镜像，(2) 通过镜像重建"无扰动"的参考画布，(3) 比较实际画布与参考画布的差异来提取标记移动的轨迹。三个操作形成"构建参考 → 比较 → 提取"的推理链，其中构建参考本身需要理解镜像对称。

输入是一幅上下本应镜像对称的彩色画布，但若干像素被标记移动操作扰动，输出扰动像素的差异掩码。

**输入结构**：约 12x8 的彩色密集画布（无黑色背景，所有像素均非黑(0)），高度为偶数。画布的上半部分是一个多色图案（使用蓝(1)、红(2)、绿(3)、黄(4)等 3-4 种颜色），下半部分"几乎"是上半部分的垂直镜像，但有 2-4 个像素被扰动：这些像素的颜色被替换为灰(5)（画布中未出现的颜色）。生成约束：扰动像素仅出现在下半部分；扰动像素互不 4-邻接（避免形成连通块歧义）；上半部分严格无扰动。

**规则**：
1. 将画布沿水平中线分为上半部分 U 和下半部分 D。
2. 将 U 垂直翻转（上下颠倒）得到参考下半 R。
3. 逐像素比较 R 与 D：找出 R 与 D 颜色不同的像素位置。这些位置在 D 中的颜色为灰(5)，在 R 中的颜色为原本应有的颜色。
4. 将这些差异位置构成的掩码裁剪到最小边界框。在掩码中，差异位置涂为灰(5)，其余位置涂为黑(0)。
5. 输出即为裁剪后的差异掩码。

**关键洞察**：参考图像不是输入中的独立对象，而是由输入自身的上半部分经镜像构建出来的——解题者必须认出"上下镜像对称"这一结构性质，才能构建参考并提取差异。需要对比多个示例才能归纳出"扰动只在下半部分"和"扰动色固定为灰(5)"的规则。
