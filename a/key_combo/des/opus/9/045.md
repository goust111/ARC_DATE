## 新题 1：阶梯射线的碰撞变色

**组合逻辑**：[连线/阶梯生成](从锚点出发画阶梯) → [射线延伸+反射](阶梯臂遇矩形障碍后反弹，步长模式保持) → [重涂色](反弹后的射线段继承障碍物颜色)

**来源原语**：连线+阶梯图案+锚点像素+点对称+步长固定(d06dbe63)、射线延伸+反射+碰撞反弹+矩形障碍+射线遇障碍翻转(508bd3b6)、重涂色(多题共有)

**依赖链**：锚点位置决定阶梯臂的起始方向和路径 → 阶梯的步长几何决定碰撞点（与直线对角射线不同的碰撞位置）→ 碰撞的矩形颜色传递给后续射线段 → 反弹后阶梯步长模式保持不变，决定后续路径。删除阶梯生成则碰撞点无法确定；删除碰撞反弹则颜色继承无从触发；删除颜色继承则输出不完整。

从锚点发出的阶梯形射线遇到彩色矩形后反弹并继承矩形的颜色，阶梯步长在反弹后保持不变。

**输入结构**：约 15x15 的黑(0)背景网格。包含一个青(8)像素作为锚点，以及 2~3 个不同颜色的实心矩形（如红(2)、蓝(1)、绿(3)，每个矩形约 2x3 或 3x2 像素），分散放置于网格中。生成约束：矩形之间互不相邻且不与锚点相邻；每条阶梯臂在网格范围内至少能碰到一个矩形。

**规则**：
1. 从青(8)锚点出发，沿两个相反的对角方向生成灰(5)阶梯臂，步长为 2：每个阶梯步先水平走 2 格再垂直走 2 格（一个方向向右上延伸，另一个方向向左下延伸），形成点对称的双臂阶梯。
2. 当一条阶梯臂的某个像素即将落在某个彩色矩形的像素上时，该臂在矩形边界处发生反弹：若碰到矩形的水平边（上边或下边），垂直方向分量翻转；若碰到竖直边（左边或右边），水平方向分量翻转。碰撞像素本身不绘制（即阶梯臂不覆盖矩形）。
3. 反弹后，阶梯臂继续以相同的步长 2 延伸，但颜色变为所碰矩形的颜色（不再是灰(5)）。
4. 若阶梯臂在反弹后再次碰到另一个矩形，重复步骤 2-3（颜色更新为新矩形的颜色）。
5. 阶梯臂延伸到网格边界外时停止。
6. 青(8)锚点和所有彩色矩形保持不变。

**关键洞察**：阶梯形路径的碰撞点与直线对角射线不同——步长为 2 的阶梯在矩形的不同位置碰撞，导致反弹后的路径产生非直觉的偏移。求解者必须追踪阶梯的逐步几何才能确定反弹后的走向和颜色。

## 新题 2：L折线肘点的排序决定镜像轴方向

**组合逻辑**：[连线/L折线](画L形曼哈顿路径) → [排列顺序+奇偶定方向](肘点按纵坐标排序，奇偶决定镜像类型) → [镜像](以肘点为锚做水平或垂直反射)

**来源原语**：连线+起点标记+终点标记+曼哈顿路径+折线连接(a2fd1cf0)、排列顺序+奇偶定方向(4364c1c4)、镜像+共行列对齐+对齐决定镜像轴(963f59bc)

**依赖链**：标记对位置决定 L 折线几何 → L 折线几何决定肘点位置 → 肘点按纵坐标排序产生奇偶性 → 奇偶性选择水平/垂直镜像轴 → 最近灰对象被以该轴反射 → 反射副本着色为标记颜色。删除L折线则肘点不存在；删除排序则无法确定轴方向；删除镜像则输出无新对象。

每对同色标记生成L折线，折线肘点的纵向排序奇偶性决定临近灰色对象被水平还是垂直反射，副本着标记色。

**输入结构**：约 15x18 的黑(0)背景网格。3~4 对同色单像素标记（每对颜色唯一，使用红(2)、蓝(1)、黄(4)、橙(7)等），每对中两个标记不同行不同列。每对标记附近有一个灰(5)的 4-连通小前景对象（3~6 像素），形状在不同示例中不同（不固定为特定形状名称）。生成约束：不同标记对的 L 折线互不交叉；每个灰对象距其最近的肘点明显近于其他肘点（无歧义归属）。

**规则**：
1. 对每对同色标记，从行号较小的标记出发画青(8) L 形路径：先水平延伸到另一标记所在列，再垂直延伸到另一标记。路径包含起止标记之间的所有中间格（不覆盖标记本身）。
2. 记录每条 L 折线的肘点（水平段与垂直段的交汇格）。按肘点的行号从小到大排序，赋予排名 1, 2, 3, ...。
3. 对每个肘点，找到包围框中心与该肘点欧氏距离最近的灰(5)对象，将其关联到该肘点。
4. 排名为奇数的肘点：以肘点所在列为垂直轴，将关联的灰对象水平反射，生成副本。排名为偶数的肘点：以肘点所在行为水平轴，将关联的灰对象垂直反射，生成副本。
5. 反射副本着色为对应标记对的颜色。原始灰对象保留。

**关键洞察**：镜像轴的类型不由标记或对象本身决定，而是由 L 折线的肘点在全局纵向排序中的奇偶性决定。求解者必须先画所有 L 折线、提取肘点、排序，才能知道对哪些对象施加何种反射——肘点的排序是涌现于多条折线的全局属性。

## 新题 3：X 图案折叠编码卫星精灵体的推移方向

**组合逻辑**：[折叠/压缩](将 5x5 X 图案折叠为 3x3 边框) → [计数/摘要生成](对 3x3 每条边做颜色多数投票) → [推移](投票结果编码推移方向，应用于边缘精灵体) + [擦除](不匹配的精灵体被清除)

**来源原语**：折叠+压缩+对角线像素+对角到边映射(ca8de6ea)、计数+分类计数(5289ad53)、推移+前景对象+网格边界+推至边界停止(5623160b)、擦除(多题共有)

**依赖链**：X 图案上 9 个像素的颜色 → 折叠映射到 3x3 边框的 4 条边 → 每条边的多数色投票 → 多数色编码推移方向 → 方向应用于对应边的精灵体 → 方向与精灵体所在边相同时触发擦除（而非推移）。折叠步骤将分散的对角信息汇聚到边框，计数步骤提取决策信号，推移/擦除步骤执行动作——三者不可缺一。

网格中央的 X 形彩色图案经折叠和多数色投票后，编码出四个方向指令，驱动四个边缘精灵体的推移或擦除。

**输入结构**：约 15x15 的黑(0)背景网格。网格中央有一个 5x5 区域，其中恰好 9 个位于两条对角线上的格子被涂色（构成 X 形），每个格子的颜色为蓝(1)、红(2)、绿(3)、黄(4)之一（中心格也是这四色之一）。其余格均为黑(0)。网格的上、右、下、左四个边各有一个 4-连通单色小精灵体（3~5 像素），紧贴该边（即精灵体的某些像素位于网格的第 0 行/最后一行/第 0 列/最后一列），颜色各不相同且不同于背景和 X 图案中使用的颜色（使用灰(5)、品红(6)、橙(7)、栗(9)）。生成约束：每条对角臂的两个非中心像素颜色相同，保证折叠后每条 3x3 边上有明确多数色。

**规则**：
1. 将 5x5 X 图案折叠为 3x3 边框图案（参照 ca8de6ea 的折叠规则）：西北臂 → 顶边（从左到中心），东北臂 → 右边（从上到中心），西南臂 → 左边（从中心到下），东南臂 → 底边（从中心到右），中心像素保持在 3x3 的中心。
2. 读取 3x3 结果的四条边，每条边包含 2 个来自折叠的像素。取这 2 个像素的颜色；若相同则该颜色即为该边指令色；若不同则取中心像素颜色作为该边指令色。
3. 指令色编码推移方向：蓝(1)=向上，红(2)=向右，绿(3)=向下，黄(4)=向左。
4. 将指令应用于对应边的精灵体：顶边指令应用于贴顶边的精灵体，右边指令应用于贴右边的精灵体，以此类推。精灵体沿指令方向平移直到触碰网格边界。
5. 特殊情况：若某精灵体所贴的边与推移方向相同（如贴顶边的精灵体被指令向上推），则该精灵体被擦除而非推移。
6. 擦除中央 5x5 区域的 X 图案。3x3 折叠结果不出现在最终输出中（仅为中间计算）。

**关键洞察**：X 图案不是装饰而是压缩的指令集。折叠将分散在对角线上的颜色信息汇聚到 3x3 边框的四条边，每条边的多数色编码一个方向指令。求解者必须理解折叠映射关系、完成多数投票、再将方向与精灵体位置对应，才能确定最终输出。

## 新题 4：分隔线定位触发选择性旋转与面积仲裁

**组合逻辑**：[重涂色+全空行列检测](检测分隔线并标记) ← [旋转+面积比较](面积较小的子区域被 180 度旋转) — 双向约束：分隔线定位决定哪些区域被比较，面积比较结果决定变换方式

**来源原语**：重涂色+分隔行列+包围框+包围框内部+全空行列检测(da2b0fe3)、旋转+整图半周旋转(6150a2bd)、擦除+实心矩形+面积比较+仅保留最大矩形(91714a58，改造：从"保留最大"改为"旋转最小")

**依赖链**：前景包围框 → 内部分隔线检测 → 将图案分为两个子区域 → 计算每个子区域的前景像素面积 → 面积较小者被 180 度旋转，面积较大者保持不变 → 分隔线本身跨全画布重涂为绿(3)。删除分隔线检测则无法确定旋转哪部分；删除面积比较则无法决定哪侧旋转；删除旋转则输出与输入无区别（仅差一条绿线）。

包围框内的空白分隔线将前景分为两个子区域，面积较小的子区域被 180 度旋转，分隔线跨全画布重涂为绿色。

**输入结构**：约 12x12 的黑(0)背景网格。包含一个由多种非黑颜色像素组成的前景图案，占据网格的中央偏大区域（包围框约 8x8 到 10x10）。前景图案的包围框内部恰好有一条完全为黑(0)的行或列（即分隔行或分隔列），将前景分为两个子区域。两个子区域的前景像素总数不同（生成约束）。子区域内的像素颜色多样（可含红(2)、蓝(1)、黄(4)、橙(7)等），形成不规则的连通或非连通图案。生成约束：分隔线严格位于包围框内部（不与包围框边界重合）；两侧面积不相等。

**规则**：
1. 找到前景（所有非黑像素）的最小包围框。
2. 在包围框内部定位唯一的全黑行或全黑列——这是分隔线。
3. 分隔线将包围框内的前景像素分为两个子区域（分隔线两侧）。
4. 计算两个子区域各自的前景像素总数。
5. 将前景像素总数较少的子区域围绕其自身中心（子区域包围框的中心）做 180 度旋转。旋转后的像素仍落在该子区域原有的范围内。
6. 前景像素总数较多的子区域保持不变。
7. 将分隔行/列在输出中跨整个网格宽度/高度重涂为绿(3)。
8. 若两侧面积恰好相等（生成时已排除此情况），则两侧均旋转 180 度。

**关键洞察**：分隔线同时扮演两个角色——它既是区域划分的结构特征（决定哪些像素属于哪侧），又是最终输出中的视觉标记（绿色横/竖线）。求解者必须先空间分割再做数量比较，最后对不同侧施加不同变换，三步推理环环相扣。

## 新题 5：角标记装饰驱动射线反弹与颜色传播

**组合逻辑**：[装饰](给方块加四角标记) → [射线延伸+反射](射线碰到角标记后反弹) → [重涂色](反弹后射线段染角标记色) → [投影](射线终点投影到底行)

**来源原语**：装饰+前景方块+角标记+对角邻接+四角固定配色装饰(95990924)、射线延伸+反射+碰撞反弹+射线遇障碍翻转(508bd3b6)、投影+边行+中心对齐+对象中心在边行标(54d82841)、重涂色(多题共有)

**依赖链**：灰方块位置 → 角标记装饰（蓝/红/绿/黄固定位置）→ 射线路径遇角标记时，标记的角位置（NW/NE/SW/SE）决定反弹几何 → 角标记的颜色传递给后续射线段 → 射线最终离开网格或耗尽反弹次数时，终点列投影到底行。装饰步骤为射线提供反弹点和颜色源；投影步骤需要完整追踪射线路径。

灰色方块被加上四色角标记后成为射线的反弹障碍，射线段颜色随反弹目标变化，射线终点投影到底行。

**输入结构**：约 18x18 的黑(0)背景网格。包含 3~5 个灰(5) 2x2 实心方块，分散于网格中（方块之间至少间隔 2 格）。一个橙(7)单像素作为射线源。底行（最后一行）全部为黑(0)。生成约束：射线源位于网格上半部分；每个灰方块的四个对角外角位置（NW/NE/SW/SE）在网格范围内且为黑背景（确保角标记可放置）；射线路径至少经过 2 次反弹。

**规则**：
1. 对每个灰(5) 2x2 方块，在其四个对角外角放置彩色标记：西北角蓝(1)、东北角红(2)、西南角绿(3)、东南角黄(4)。
2. 从橙(7)射线源出发，沿 45 度对角方向发射射线（初始方向：向右下）。射线路径上每经过一格涂灰(5)。
3. 当射线即将进入一个角标记像素时，发生反弹：
   - 碰到方块的 NW 或 SE 角标记（蓝或黄）：水平和垂直方向分量均翻转（等效于 180 度回弹后偏移一格）。具体地，若射线从左上方来碰到 SE 角的黄标记，射线改为向右上继续。
   - 碰到方块的 NE 或 SW 角标记（红或绿）：仅翻转射线的一个方向分量。若碰到 NE 角（红）：水平分量翻转（射线从向右变为向左，垂直方向不变）。若碰到 SW 角（绿）：垂直分量翻转（射线从向下变为向上，水平方向不变）。
4. 反弹后，射线段的颜色变为所碰角标记的颜色（蓝/红/绿/黄），直到下一次反弹。
5. 射线最多反弹 5 次。第 5 次反弹后或射线到达网格边界时，射线停止。
6. 记录射线停止时最后一个像素的列坐标，在底行的该列涂黄(4)。
7. 橙(7)射线源保持不变。方块和角标记保持不变。

**关键洞察**：角标记不仅是视觉装饰——它们的位置（方块的哪个角）决定了反弹的物理行为（翻转哪个方向分量），而它们的颜色则传播到后续射线段。不同角标记产生不同的反弹模式，使得射线路径高度依赖方块的精确布局。

## 新题 6：三连块对角副本生成字形重建锚点

**组合逻辑**：[平移/对角副本](三连块按缺角方向生成偏移副本) → [擦除](清除原始字形和三连块) → [补全/重建](副本像素作为端点标记锚定字形重建位置) — 三连块是中间计算而非最终输出

**来源原语**：平移+三连块+缺角+对角偏移+源色决定方向(1e5d6875)、擦除+补全+边框竖条+端点标记+字形模板+颜色对应形状+锚点定位(98c475bf)

**依赖链**：三连块的形状（缺角方向）+ 颜色 → 对角副本的偏移方向和颜色 → 副本是否落入边框内部 → 落入边框的副本提供端点标记行 → 端点标记颜色查找对应字形模板 → 在锚定行重建字形。删除三连块副本则无端点标记可用；删除字形重建则副本无意义；删除擦除则新旧字形混叠。

L形三连块的对角副本落入边框内部后充当端点锚点，驱动字形的擦除与重建。

**输入结构**：20x20 的黑(0)背景网格。左右各有一条相同颜色的全高竖直边框条（如栗(9)，各 1 列宽，分别位于第 2 列和第 17 列）。边框内部（第 3~16 列）包含：一个完整的单色字形（如蓝(1)，占据约 5~7 行 x 4~6 列的连通图案）；2~3 个 L 形三连块，部分为红(2)部分为灰(5)，每个三连块占 2x2 区域中的 3 个像素（有一个缺角）。三连块可位于边框内部或外部。生成约束：至少一个三连块的对角副本能完全落入边框内部区域；红三连块副本为绿(3)，灰三连块副本为黄(4)；字形模板保证绿和黄版本可区分（例如绿版为原始字形，黄版为原始字形的水平镜像）。

**规则**：
1. 对每个三连块，确定其 2x2 包围框中缺失的角位置。
2. 灰(5)三连块：生成黄(4)副本，向缺角方向对角平移 1 格。红(2)三连块：生成绿(3)副本，向缺角的相反方向对角平移 1 格。
3. 检查每个副本的所有像素是否完全位于边框内部区域（第 3~16 列之间）。丢弃任何有像素落在边框上或边框外的副本。
4. 对于保留的每个副本，找到其所有像素中处于同一行的最左和最右像素——这构成一个端点标记对。若副本跨多行，取像素最多的那一行。
5. 擦除边框内部区域中的完整字形和所有三连块（无论内外），仅保留边框竖条。
6. 对每个端点标记对，按其颜色查找字形模板（黄(4) → 原始字形的水平镜像；绿(3) → 原始字形的原样），将字形锚定在端点标记所在行（字形的中间行对齐端点标记行），水平居中于边框内部。
7. 边框竖条保持不变。

**关键洞察**：三连块不是最终输出的组成部分——它们是中间计算装置。三连块的几何属性（缺角方向）和颜色共同决定副本的偏移方向和目标颜色，副本是否有效取决于它是否落入边框内。求解者必须追踪从三连块形状到字形重建位置的完整间接编码链。

## 新题 7：路径连通筛选驱动计数反馈的阶梯扩展

**组合逻辑**：[路径连通](灰路径筛选哪些竖直条对参与扩展) + [计数](连通对的数量作为全局参数) → [阶梯扩展](以连通对计数为步长进行扩展) → [重涂色](跨色重叠区域变色) — 非线性结构：路径同时充当过滤器和参数源

**来源原语**：路径连通+路径网络+端点决定目标(d35bdbdc)、阶梯扩展+竖直条对+周期性步长+跨色重叠变色(58e15b12)、计数+分类计数(5289ad53)、擦除(多题共有)

**依赖链**：灰路径的连通性 → 筛选哪些竖直条对参与扩展（过滤作用）→ 被选中条对的总数 N → N 作为全局步长参数 → 步长控制所有被选条对的扩展几何 → 不同色扩展区域重叠时变为品红。路径同时扮演两个角色：过滤器和参数源。新增一条路径连接会改变 N，从而改变所有已连通对的扩展形态——全局-局部反馈。

灰色路径网络筛选哪些竖直条对参与阶梯扩展，连通对的总数决定扩展步长，不同色扩展重叠变为品红。

**输入结构**：约 20x20 的黑(0)背景网格。包含 4~5 对同色竖直条（每对两根等高竖直线段，颜色各异，如红(2)、蓝(1)、黄(4)、绿(3)等，每根竖线高 2~4 格）。一条灰(5)路径网络在网格上蜿蜒（8-连通，宽度 1 像素），路径的某些分支末端触碰某些竖直条对中的某一根竖线。生成约束：恰好有 2~3 对竖直条通过灰路径连通（路径的一个末端触碰对中一根线，另一个末端或分支触碰另一对中的一根线，形成间接连通）；至少 1~2 对竖直条未被路径触碰；所有竖直条对的条高相同。

**规则**：
1. 通过 8-连通遍历灰(5)路径网络，确定哪些竖直条对被路径连通。一对竖直条被视为"连通"，当且仅当该对的两根竖线都能通过灰路径（可经由其他竖线中转）到达。
2. 擦除所有未连通的竖直条对。
3. 计算连通条对的数量 N。
4. 对每对连通的竖直条，执行阶梯扩展：在条高范围内保持原列位置；在条高范围之上或之下，每隔 N 行，左条向左偏移 1 列、右条向右偏移 1 列（N 替代了原始规则中"以条高为步长"的设定）。
5. 所有扩展产生的像素如果在网格边界内，均被涂上对应颜色。
6. 若两种或更多不同颜色的扩展区域产生的像素重叠在同一格，该格涂为品红(6)。
7. 灰(5)路径网络保留在输出中。

**关键洞察**：灰路径网络具有双重功能——它既是过滤器（决定哪些条对存活），又是全局参数的间接来源（连通对的总数 N 控制扩展步长）。这意味着改变一条路径的连接会同时影响参与者集合和所有参与者的扩展形态，产生非局部耦合效应。

## 新题 8：边缘拉伸编码卫星对象的推移指令

**组合逻辑**：[拉伸/描边](中央图案边缘向外拉伸一层) → [推移](卫星对象根据最近边缘格颜色确定推移方向) + [镜像](特定颜色触发局部镜像而非推移) — 边缘拉伸层是空间编码的指令地图

**来源原语**：描边+拉伸+画布边界+边缘行列+边缘延伸角落留黑(49d1d64f)、推移+前景对象+网格边界+接触侧决定方向+推至边界停止(5623160b)、镜像+翻转列序(67a3c6ac)

**依赖链**：中央图案的边缘像素颜色 → 拉伸复制到外层 → 卫星对象与最近边缘格的曼哈顿距离 → 最近格颜色 → 颜色编码决定动作类型和方向 → 推移或镜像执行。中央图案的边缘结构直接控制外部对象的行为。

中央图案的边缘颜色被拉伸为一层边框后，形成空间指令地图；卫星对象依据最近边框格的颜色被推向边界或就地镜像。

**输入结构**：约 14x14 的黑(0)背景网格。中央有一个约 6x6 的彩色图案（使用蓝(1)、红(2)、绿(3)、黄(4)中的 2~3 种颜色，形成不规则但连通的多色图案）。图案四周至少有 2 格黑色间距。在间距之外，4 个小型单色卫星对象（每个 3~5 像素，4-连通），分别大致位于网格的四个象限，颜色为灰(5)、品红(6)、橙(7)、栗(9)（各不相同，且不同于中央图案使用的颜色）。生成约束：中央图案的边缘像素颜色分布使得四个方向的拉伸层颜色不完全相同（至少两种不同颜色出现在不同边）。

**规则**：
1. 将中央图案向外拉伸一层（如 49d1d64f）：新增两行两列包裹中央图案。上边缘行的每个像素复制中央图案顶行对应列的颜色，下边缘行复制底行颜色，左边缘列复制左列颜色，右边缘列复制右列颜色。四个新角格保持黑(0)。
2. 对每个卫星对象，计算其包围框中心到拉伸边框层每个非黑格的曼哈顿距离，取最小距离对应的边框格。若有多个等距格，取行号最小的；仍平局取列号最小的。
3. 根据最近边框格的颜色确定动作：
   - 蓝(1)：将卫星对象向上推移，直到对象的某个像素到达网格第 0 行。
   - 红(2)：向右推移，直到对象的某个像素到达网格最后一列。
   - 绿(3)：向下推移，直到对象的某个像素到达网格最后一行。
   - 黄(4)：将卫星对象就地水平镜像（反转其每一行的列顺序，包围框位置不变）。
4. 推移时，卫星对象离开原位后原位置变为黑(0)。镜像操作不改变对象位置，只改变其内部结构。
5. 中央图案及拉伸边框层保持不变。

**关键洞察**：拉伸层不是装饰性边框——它将中央图案的边缘颜色信息转换为空间上的指令地图。每个卫星对象的命运取决于它距哪个边框像素最近，而该像素的颜色又来自中央图案的边缘结构。求解者必须同时理解拉伸映射和颜色-动作编码，两者交织不可分。

## 新题 9：交替平移涌现分隔行触发邻域比较重涂

**组合逻辑**：[交替平移](奇偶排名决定平移方向，物理地制造空行) → [全空行列检测](检测平移后新产生的分隔行) → [计数+面积比较](分隔行两侧对象像素数比较) → [重涂色](比较结果决定分隔行颜色) — 涌现结构：分隔行在输入中不存在，由平移创造

**来源原语**：交替平移+单色前景体+排列顺序+奇偶定方向(4364c1c4)、全空行列检测+分隔行列(da2b0fe3)、计数+分类计数(5289ad53)、面积比较(91714a58)、重涂色(多题共有)

**依赖链**：对象的纵向排序 → 奇偶排名决定左移/右移 → 平移后某些行变为全空（这些行在平移前不是全空的）→ 检测新分隔行 → 分隔行上下相邻对象的像素数比较 → 比较结果决定分隔行颜色。平移步骤制造分隔行，分隔行是后续比较和重涂的对象——第一步的副作用是第二步的前提。

对象按纵向排序后交替左右平移，平移副作用产生的空白行被检测为分隔线，每条分隔线根据上下对象面积比较结果着色。

**输入结构**：约 12x15 的黑(0)背景网格。包含 5~7 个小型 4-连通单色前景对象（每个 4~8 像素），每个对象使用不同的非黑非绿非红非蓝颜色（如黄(4)、灰(5)、品红(6)、橙(7)、青(8)、栗(9)中选取）。各对象的包围框顶行互不相同（保证纵向排序无歧义）。对象按纵向排列，相邻对象之间有 1~2 行间距，但这些间距行上可能有对象的像素延伸（因此平移前这些行不全为空）。生成约束：交替平移后至少产生 2 条全空行作为分隔行；对象大小有差异（不全相同），使得面积比较结果不平凡。

**规则**：
1. 将所有前景对象按其包围框顶行行号从小到大排序，赋予排名 1, 2, 3, ...。
2. 排名为奇数的对象整体向左平移 1 列；排名为偶数的对象整体向右平移 1 列。对象离开的原位置变为黑(0)。超出网格边界的像素丢弃。
3. 平移完成后，检测所有完全为黑(0)的行。仅保留那些位于某两个对象的行范围之间的全空行（即上方有对象、下方有对象的全空行）。这些是"分隔行"。
4. 对每条分隔行，找到其正上方最近的对象和正下方最近的对象（按包围框底行/顶行的距离）。
5. 比较上方对象和下方对象的前景像素总数：
   - 若上方对象像素更多，将该分隔行全部涂红(2)。
   - 若下方对象像素更多，将该分隔行全部涂蓝(1)。
   - 若两者相等，将该分隔行全部涂绿(3)。
6. 非分隔的全空行（如网格顶部或底部的空行）不做任何处理。

**关键洞察**：分隔行在原始输入中不存在——它们是交替平移的几何副作用。求解者必须先执行平移（需要排序和奇偶判断），然后才能发现这些涌现的空行，再基于空行两侧的对象属性做出颜色决策。整个推理链中，每一步的输出是下一步的前提条件。

## 新题 10：标记双重角色——生成镜像副本并用副本作为射线障碍

**组合逻辑**：[镜像](标记决定镜像轴，生成前景副本) → [射线延伸](从标记出发的射线以刚生成的副本为障碍) → [投影](射线终点投影到底行) — 自引用依赖：标记生成的对象反过来约束标记发出的射线

**来源原语**：镜像+前景对象+单像素标记+共行列对齐+对齐决定镜像轴(963f59bc)、射线延伸+反射+碰撞反弹+射线遇障碍翻转(508bd3b6)、投影+边行+中心对齐+对象中心在边行标(54d82841)

**依赖链**：标记与前景对象的行/列对齐 → 确定镜像轴 → 生成镜像副本（着标记色）→ 副本放置在网格上 → 从标记出发的对角射线将副本视为障碍 → 射线碰到副本反弹 → 射线终点列投影到底行。标记的第一个角色（镜像锚点）的输出（副本位置）是其第二个角色（射线源）的输入（障碍位置）。

单像素标记先作为镜像锚点生成前景对象的彩色副本，再作为射线源发射对角射线；射线将自己生成的副本当作反弹障碍，终点投影到底行。

**输入结构**：约 15x15 的黑(0)背景网格。一个多像素青(8)前景对象（5~8 像素，4-连通，形状不规则）。2 个单像素标记，颜色分别为红(2)和黄(4)。每个标记与青对象恰好共享一行或一列（即标记所在行有恰好一个青像素，或标记所在列有恰好一个青像素）。底行（最后一行）全部为黑(0)。生成约束：两个标记分别与青对象的不同像素对齐；镜像副本不超出网格边界；从标记出发的对角射线（方向：向网格中心最近的对角方向）能碰到对方标记产生的镜像副本。

**规则**：
1. 对每个标记，判断其与青(8)对象的对齐方式（参照 963f59bc）：若标记与恰好一个青像素共行，则以标记和该青像素之间的垂直中线为轴，将整个青对象水平反射；若共列，则以水平中线为轴垂直反射。
2. 将反射副本涂为标记的颜色（红标记 → 红副本，黄标记 → 黄副本）。原始青对象保留。
3. 从每个标记位置出发，向网格中心方向发射 45 度对角射线（若标记在左上象限则向右下，在右上则向左下，以此类推）。射线路径涂灰(5)。
4. 当射线碰到任何非黑、非灰的像素（包括青对象、另一标记的副本、或自身标记的副本）时，发生反弹：射线的垂直方向分量翻转（水平分量保持）。
5. 反弹后射线继续延伸。若射线再次碰到障碍，再次反弹（水平分量翻转）。最多反弹 3 次。
6. 射线到达网格边界或耗尽反弹次数时停止。记录射线最后一个像素的列坐标，在底行该列涂对应标记的颜色。
7. 两个标记各独立产生一个底行标记。若两者投影到同一列，该列涂品红(6)。

**关键洞察**：每个标记身兼两职：首先作为镜像锚点决定副本的位置，然后作为射线源发射的射线必须与这些副本交互。求解者不能独立求解镜像和射线——必须先完成镜像才能知道射线的障碍物在哪里，而射线的路径又取决于所有副本（包括另一个标记生成的副本）的位置，形成跨标记的间接依赖。
