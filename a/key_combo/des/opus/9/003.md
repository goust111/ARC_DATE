## 新题 1：标记三角化建框与缺口射线洪泛

**组合逻辑**：[补全(complete)](创新：缺失角变为缺口而非补齐) + [洪泛填充(flood_fill)] + [射线延伸(ray_extend)](创新：射线颜色由内部填充色决定) — 三者通过"缺失标记位置"这一结构节点紧耦合

**来源原语**：补全/三点定矩形框(e7639916), 洪泛填充/边框缺口/缺口方向决定射线(551d5bf1), 标记像素/包围盒(e7639916)

**依赖链**：三个同色标记的包围盒定义矩形框 → 缺失第四角的位置既决定了框的形状又决定了缺口所在 → 缺口的存在使洪泛填充后的内容可以沿缺口方向发射射线 → 射线颜色取决于框的标记色而非固定色，因此不同框的射线相交时需要冲突解决

用一句话概括：将散布的同色三点组扩展为带缺口的矩形框，填充框内并从缺口发射有色射线，交叉点按框面积优先级着色。

**输入结构**：黑(0)背景，约 20×20 网格。网格中散布 2~4 组标记像素，每组恰好 3 个像素且同色（如红(2)、绿(3)、黄(4)等，各组颜色不同）。每组的三个标记像素恰好位于它们共享包围盒的边界上（即至少有一个坐标等于包围盒的某条边），且三个标记不共线。各组的包围盒互不重叠。生成时保证：每组的三个标记落在包围盒四个角中的三个上（第四个角空缺）；不同组的包围盒之间至少间隔 2 个像素；射线路径上不存在其他组的框体（射线可以自由延伸到网格边缘或另一条射线）。

**规则**：
1. 对每组同色标记像素，计算其三点的最小包围盒，得到一个矩形区域。
2. 沿包围盒的四条边绘制一像素宽的边框，颜色为该组的标记色。第四个角（无标记的那个角）所在的边框像素不绘制，形成一个单像素缺口。
3. 将每个框严格内部（不含边框）的所有黑(0)像素洪泛填充为灰(5)。
4. 从每个缺口像素出发，沿缺口所在边框侧的法线方向向外发射一条射线（例如缺口在顶边则射线向上，缺口在左边则射线向左）。射线逐像素延伸，将经过的黑(0)像素涂为该框的标记色，直到遇到网格边缘或非黑像素时停止（不覆盖终点处的非黑像素）。
5. 若两条不同颜色的射线路径存在交叉（即某个像素同时处于两条射线的路径上），则该像素着色为包围盒面积较小的那个框的标记色（面积 = 包围盒宽 × 高）。生成时保证不存在两个面积相同的框。
6. 恢复所有原始标记像素（标记像素覆盖在边框之上，保持原色）。

**关键洞察**：第四个角的缺失不是需要修补的缺陷，而是同时编码了两条信息——框的几何完形方式和射线的发射方向。必须对比多个示例才能确定射线交叉时的面积优先级规则。

## 新题 2：引导条周期过滤与对称裁决

**组合逻辑**：[压缩(compress)] + [周期填充(periodic_fill)](创新：周期结构作为引导条的过滤掩码) + [镜像(mirror)](创新：对称性测试作为最终裁决而非变换操作) — 周期结构决定哪些压缩结果被保留，保留结果的对称性决定最终着色

**来源原语**：压缩/引导条/投射到引导条/投射落间隙则擦(f83cb3f6), 周期填充/边界点/周期步长/同余对齐(16de56c4), 镜像/镜像对称/镜像配对则涂色(ce039d91)

**依赖链**：散布像素向引导条压缩 → 引导条自身的周期间隙决定哪些压缩像素被擦除 → 压缩后存活的像素在引导条两侧形成上下两行图案 → 上下图案的逐列镜像对称检测决定最终涂色

用一句话概括：将散布像素压缩到带周期间隙的引导条旁，再根据上下两侧压缩结果的逐列对称性进行红绿裁决着色。

**输入结构**：黑(0)背景，约 18×18 网格。网格正中有一条水平引导条，由灰(5)像素组成，宽度等于网格宽度但其中有若干单像素间隙（间隙位置为黑(0)）。引导条上方和下方各散布若干有色像素（颜色为蓝(1)或橙(7)），每个有色像素恰好占一个单元格。同时，在引导条所在行的左右两端各有 2 个品红(6)像素，它们之间的间距定义了一个周期步长（例如两个品红像素位于列 2 和列 5，则步长为 3）。生成时保证：引导条的间隙位置恰好落在周期步长的非对齐列上（即间隙列 mod 步长 != 品红像素列 mod 步长）；散布像素不与引导条同行；引导条上下各至少有 4 个散布像素。

**规则**：
1. 识别引导条（灰(5)像素组成的水平行，可能有间隙）及其所在行号 R。
2. 识别引导条同行两端的品红(6)像素对，计算它们的列间距作为周期步长 S，取较左品红像素的列号 mod S 作为偏移量 P。
3. 对引导条上方（行号 < R）的每个有色像素，将其沿所在列向下投射到行 R-1（引导条正上方一行）。对引导条下方（行号 > R）的每个有色像素，将其沿所在列向上投射到行 R+1（引导条正下方一行）。同一列若有多个同侧像素投射到同一位置，保留离引导条最近的那个的颜色。
4. 周期过滤：对于投射后落在行 R-1 或 R+1 的每个像素，检查其所在列 C 是否满足 C mod S == P。不满足的像素擦除为黑(0)。
5. 间隙过滤：投射后列号对应引导条间隙位置的像素也擦除为黑(0)。
6. 经过双重过滤后，行 R-1 和 R+1 各有一行存活像素。逐列比较这两行：若某列两行都有非黑像素且颜色相同（镜像对称匹配），则将该列的两个像素都重涂为绿(3)；若某列两行都有非黑像素但颜色不同，则都重涂为红(2)；若某列仅一行有非黑像素，保持原色不变。
7. 输出网格仅保留引导条、品红标记和行 R-1 与 R+1 的最终像素，其余全部为黑(0)背景。

**关键洞察**：周期步长不由引导条本身编码，而由引导条同行的品红标记对编码——必须对比多个示例才能发现品红像素定义了周期过滤条件，且过滤先于对称判断执行。

## 新题 3：级联印章与接触侧重涂色反馈环

**组合逻辑**：[印章覆盖(stamp)] + [重涂色(recolor)](创新：重涂后的颜色可触发新一轮印章) + [级联激活(cascade_activation)](创新：级联的触发条件不是射线碰撞，而是颜色匹配) — 印章→接触侧涂色→新颜色匹配→再印章，形成闭环

**来源原语**：印章覆盖/锚点标记/目标标记/同色对应/锚点定位复制(1b59e163), 重涂色/侧边标记/接触侧定色/包含于(c3fa4749), 级联激活/链式反应传播(5961cc34), 擦除/忽略干扰项(1b59e163/9bebae7a)

**依赖链**：面板内的精灵体通过锚点色匹配被印章到独立标记位置 → 印章副本若接触到面板边界，由接触侧决定其重涂色 → 重涂后的颜色若恰好等于另一个面板的锚点色，则该副本成为新的印章源 → 级联持续直到无新匹配产生 → 无源匹配的孤立标记为干扰项，最终擦除

用一句话概括：将面板内的精灵体印章到同色标记处，接触面板边界的副本按接触侧重涂色，重涂色若匹配新锚点则触发连锁印章，直至颜色平衡。

**输入结构**：黑(0)背景，约 22×22 网格。网格中有 2~3 个单色矩形面板区域（面板颜色各不同，如灰(5)、青(8)等，每个面板为 6×6 至 8×8 的实心矩形）。每个面板内部包含一个 4-连通的小型单色精灵体（3~5 像素，颜色与面板不同）和一个单像素锚点标记（颜色与精灵体和面板都不同）。面板外部散布若干孤立的单像素标记，颜色各异。部分孤立标记的颜色与某个面板的锚点标记色相同（目标标记），部分颜色与任何锚点色都不匹配（干扰标记）。生成时保证：每个面板的四条边各有唯一确定的颜色标签（由该面板内精灵体最靠近该边的像素颜色决定，但实际规则见下）；级联深度不超过 3 轮；不同面板的锚点色互不相同。

**规则**：
1. 对每个面板 P，识别其内部的精灵体 S 和锚点标记 A。记录 A 的颜色为 Ca。
2. 在面板外部找到所有颜色为 Ca 的孤立标记像素，这些是精灵体 S 的目标位置。
3. 以面板内 A 相对于 S 的偏移为锚点，将 S 印章覆盖到每个目标位置（目标标记像素本身保留在印章之上）。
4. 检查每个新印章副本：若副本的任何像素与某个面板的边界（面板矩形的外边缘向外一圈）4-相邻，则确定接触的是面板的哪一侧（上/下/左/右）。面板四侧的指定色为：上=红(2)，下=蓝(1)，左=黄(4)，右=绿(3)。将该副本的所有像素重涂为对应侧的颜色。若副本同时接触多侧，取接触像素数最多的那一侧。若副本不接触任何面板，保持原色。
5. 级联检查：重涂后的副本颜色若等于某个面板的锚点色 Ca'（且该面板尚未被该轮级联处理过），则该副本视为新的锚点标记，该面板的精灵体将被印章到所有颜色为 Ca' 的剩余孤立标记处。重复步骤 3-5。
6. 级联终止：当一轮中没有任何新印章副本的重涂色匹配到未处理面板的锚点色时，级联结束。
7. 清理：擦除所有原始面板内的精灵体和锚点标记（面板本身保留）；擦除所有干扰标记（颜色从未匹配到任何锚点色的孤立像素）。

**关键洞察**：重涂色不是终态操作——它改变了副本的颜色身份，可能使其成为下一轮印章的触发器。接触面板的哪一侧决定了重涂色的结果，而重涂结果是否恰好等于另一面板的锚点色，取决于面板的空间布局。必须对比多个示例才能发现四侧固定的颜色映射规则。

## 新题 4：裁剪内部作为查表键值的边框重涂

**组合逻辑**：[裁剪(crop)] + [查表匹配(table_lookup)](创新：裁剪出的内容不是最终输出，而是查表的键) + [重涂色(recolor)] — 三者形成"提取→查找→变换"的紧耦合链，裁剪产物的语义从"答案"变为"问题"

**来源原语**：裁剪/空心矩形/内部区域/包含/最大边框内部提取(1c786137), 查表匹配/字形单元格/参考表/对齐判定结果(d8e07eb2), 重涂色/填充(c3fa4749)

**依赖链**：多个矩形框的内部被裁剪出来 → 每个裁剪内容在参考表中查找匹配单元格 → 匹配单元格所在的行或列位置编码了一种颜色 → 用该颜色重涂对应框的边框 → 若所有匹配单元格恰好构成参考表的完整一行或一列，则额外将所有框的内部统一填充为绿(3)，否则填充为红(2)

用一句话概括：裁剪矩形框内部图案作为键在参考表中查找，用匹配位置编码的颜色重涂框边，并根据匹配是否构成完整行列给出全局裁决填充。

**输入结构**：黑(0)背景，约 24×20 网格。网格分为左右两区，由一列灰(5)分隔列分开。左区有 3~4 个不重叠的单色空心矩形框（边框颜色各为灰(5)，框大小约 5×5 至 7×7），每个框内部有一个由单色像素构成的小型图案（3×3，颜色各不同，如红(2)、蓝(1)、黄(4)等）。右区有一个参考表：由品红(6)分隔线划分为 3×3 或 4×3 的单元格网格，每个单元格内有一个 3×3 图案（颜色和形状各异）。参考表的每一行的左侧有一个单像素颜色标签（如第一行标签为红(2)、第二行为蓝(1)、第三行为绿(3)）。生成时保证：左区每个框的内部图案恰好与参考表中某一个单元格的图案完全相同（颜色和形状都匹配）；参考表中无重复图案；每个框匹配到不同的单元格。

**规则**：
1. 识别左区的所有空心矩形框，裁剪出每个框严格内部的 3×3 图案。
2. 在右区的参考表中逐单元格比较，找到与每个裁剪图案完全匹配（逐像素颜色相同）的单元格。
3. 每个匹配单元格所在行的行标签颜色即为该框边框的新颜色。将对应左区框的灰(5)边框重涂为该行标签色。
4. 全局裁决：检查所有匹配到的单元格是否恰好构成参考表中完整的一行或完整的一列。
   - 若构成完整行或完整列：将所有左区框的内部图案统一替换为绿(3)填充。
   - 若不构成完整行也不构成完整列：将所有左区框的内部图案统一替换为红(2)填充。
5. 右区参考表保持不变。分隔列保持不变。

**关键洞察**：框内部的图案不是要保留的内容（与源题 1c786137 相反），而是用于查表的一次性键值——查表结果同时驱动局部操作（边框重涂）和全局裁决（内部填色）。必须对比多个示例才能区分行标签着色规则和行列完整性裁决规则。

## 新题 5：滑动对齐后位移量编码为居中线段

**组合逻辑**：[对齐(align)/滑动(slide)](已有) + [计数(counting)](创新：计数的不是像素面积，而是对齐操作的位移量) + [拉直(straighten)](创新：拉直的不是前景掩码，而是位移量的可视化编码) — 对齐操作的副产品（位移量）成为下游几何生成的输入

**来源原语**：滑动/对齐/色段/同行排列/边界对齐(984d8a3e), 计数/拉直/前景掩码/居中放置/保留颜色与面积(dce56571)

**依赖链**：每行的色段右边缘被对齐到全局最左的右边缘 → 每行的滑动位移量被计算出来 → 每个位移量被编码为一条水平线段（长度=位移量），在输出网格的下半区居中放置 → 线段的颜色由原行的侧色决定

用一句话概括：对齐各行色段的右边缘后，将每行的位移距离编码为下半区的居中水平线段，线段颜色继承原行的左侧填充色。

**输入结构**：黑(0)背景，约 14×20 网格（高 14 行，宽 20 列）。网格上半区（前 7 行）每行包含三种颜色的连续色段：左侧若干像素为颜色 A（如蓝(1)），中间若干像素为颜色 B（如灰(5)），右侧若干像素为颜色 C（如红(2)）。颜色 B 是三色中占比最大的，在每行形成一个连续水平色段。各行的 B 色段宽度相同，但起始列不同（即各行的左侧 A 色填充宽度不同），导致 B 色段的右边缘列号各不相同。网格下半区（后 7 行）初始全为黑(0)。生成时保证：每行 B 色段的右边缘列号互不相同；B 色段宽度至少为网格宽度的 1/3；位移量（各行右边缘列号 - 最小右边缘列号）范围在 1~10 之间。

**规则**：
1. 在上半区识别每行的中间色段 B（每行中连续像素数最多的颜色），记录其右边缘列号。
2. 计算全局最小右边缘列号 Cmin。
3. 在上半区，将每行的内容整体左移，使得该行 B 色段的右边缘对齐到列 Cmin。左移后行首空出的位置用该行的左侧色 A 填充，行尾超出网格的部分裁剪。
4. 计算每行的位移量 D = 该行原始右边缘列号 - Cmin。
5. 在下半区，第 i 行（i 从 0 开始）的位移量 D_i 被编码为一条长度为 D_i 的水平线段。线段颜色为上半区第 i 行的左侧色 A。
6. 每条线段在下半区对应行内水平居中放置：线段左端列号 = floor((网格宽度 - D_i) / 2)。
7. 下半区未被线段覆盖的像素保持黑(0)。

**关键洞察**：对齐是一个有副作用的操作——位移量本身携带了信息。下半区不是上半区的变体，而是上半区变换过程中丢失的位移信息的可视化重建。必须对比多个示例才能发现位移量与线段长度的对应关系以及颜色继承规则。

## 新题 6：射线路径围合与缺口二次发射

**组合逻辑**：[射线延伸(ray_extend)] + [转向(turn)](创新：转向规则编码在障碍物自身的形状中而非外部图例) + [洪泛填充(flood_fill)] + [缺口方向决定射线(gap_direction_determines_ray)](创新：缺口出现在射线路径围成的区域边界上) — 射线路径创造几何边界，边界围合区域被填充，边界缺口触发二次射线

**来源原语**：射线延伸/转向/障碍块/碰撞停止/图例编码转向(e87109e9), 洪泛填充/空心矩形/边框缺口/缺口方向决定射线(551d5bf1), 连通分量/封闭区域(6e453dd6)

**依赖链**：发射源发出射线 → 射线遇障碍块转向（转向方向由障碍块的形状编码：宽>高则顺时针，高>宽则逆时针）→ 射线路径加上网格边缘可能围成封闭区域 → 封闭区域被洪泛填充 → 若围合边界上恰好有一个像素未被射线覆盖（缺口），则从缺口向外发射二次射线

用一句话概括：从发射源射出的射线遇障碍物按其宽高比转向，射线路径围成的封闭区域被填充，围合边界上的单像素缺口触发二次射线发射。

**输入结构**：黑(0)背景，约 20×20 网格。网格中有一个 2×2 的青(8)发射源方块。散布 2~4 个不同颜色的矩形障碍块（每个障碍块为实心单色矩形，尺寸约 2×3 或 3×2 等非正方形，颜色如红(2)、蓝(1)、黄(4)等）。生成时保证：从发射源沿四个基本方向中至少两个方向发射的射线能在不超过 2 次转向后与网格边缘或其自身路径围成封闭区域；障碍块互不相邻且不接触网格边缘；围合边界上恰好有一个单像素缺口（由射线路径的转弯处产生）。

**规则**：
1. 从青(8)发射源方块的四条边分别向外发射一条青(8)射线（射线宽度为 1 像素，从边的中心像素出发）。射线逐像素延伸，将经过的黑(0)像素涂为青(8)。
2. 射线遇到障碍块时停止（不覆盖障碍块像素），并发生转向：
   - 若障碍块的宽度 > 高度：射线顺时针转 90 度继续前进。
   - 若障碍块的高度 > 宽度：射线逆时针转 90 度继续前进。
   - 转向后的射线从障碍块侧面的相邻像素开始延伸（具体为：沿转向后方向，从障碍块接触面的末端像素旁开始）。
3. 转向后的射线继续延伸，直到遇到网格边缘、另一个障碍块（再次转向）、或已有青(8)像素（停止）。
4. 所有射线绘制完成后，检测由射线路径 + 网格边缘 + 障碍块共同围成的封闭区域（4-连通的黑(0)像素集合，其边界完全由青(8)/障碍块/网格边缘包围）。
5. 将每个封闭区域内的所有黑(0)像素洪泛填充为灰(5)。
6. 检查每个封闭区域的边界：若边界上恰好有一个像素位置既不是青(8)也不是障碍块也不是网格边缘（即一个单像素缺口），则从该缺口向外（远离封闭区域的方向）发射一条灰(5)射线，延伸到网格边缘或非黑像素为止。
7. 无封闭区域或无缺口的情况下，不执行步骤 5-6。

**关键洞察**：障碍块的宽高比不是装饰属性，而是隐式编码了转向方向（替代了源题中的外部图例）。射线路径不仅仅是视觉输出——它们创造了新的几何边界，使得洪泛填充和缺口检测成为可能。必须对比多个示例才能发现宽高比与转向方向的对应关系。

## 新题 7：镜像臂编码建框侧与锚点图案印章

**组合逻辑**：[镜像(mirror)](创新：镜像方向不用于复制精灵体，而是决定在精灵体的哪一侧建造矩形框) + [补全(complete)] + [印章覆盖(stamp)](创新：印章的图案不是预设的，而是由镜像操作产生的新像素构成) — 十字标记的臂编码建框侧，建框产生锚点，锚点触发印章

**来源原语**：镜像/十字标记/相邻拼接/最长臂决定镜像侧(9bebae7a), 补全/标记像素/包围盒/三点定矩形框(e7639916), 印章覆盖/锚点像素/固定图案/锚点粘贴固定图案(a9f96cdd), 擦除(9bebae7a)

**依赖链**：十字标记的最长臂确定方向 → 该方向不用于镜像复制，而是指定精灵体该侧要建造矩形框 → 框的三个角由精灵体边界决定，第四角的位置由臂长度编码 → 框内部若存在特定颜色的锚点像素，则以锚点为中心印章一个固定图案（图案来源于精灵体本身的缩略形状）→ 十字标记被擦除

用一句话概括：十字标记的最长臂指定精灵体旁建框的方向和尺寸，框内锚点处印章精灵体的缩略图案，最终擦除标记。

**输入结构**：黑(0)背景，约 18×18 网格。网格中有一个由颜色 A（如蓝(1)）构成的 4-连通前景精灵体（5~8 像素，形状不规则）。另有一个由颜色 B（如橙(7)）构成的十字标记——一个单像素交叉点向四个方向各延伸若干像素形成臂，其中恰好一个臂明显最长（比其他臂至少多 2 像素）。精灵体和十字标记不相邻（间距至少 2 像素）。在精灵体附近（但不在精灵体内部）有 1~2 个红(2)锚点像素。生成时保证：十字标记最长臂指向的方向（上/下/左/右）对应精灵体包围盒的某一侧；最长臂的长度 L（从交叉点到臂端，不含交叉点）在 3~6 之间；精灵体包围盒在最长臂指向侧的外侧有足够空间容纳一个宽度或高度为 L 的矩形框；锚点像素位于该矩形框将要覆盖的区域内。

**规则**：
1. 识别十字标记（颜色 B 的像素组成的十字形），找到其交叉点和四条臂。确定唯一最长臂及其方向 D。
2. 确定精灵体（颜色 A 的 4-连通分量）的包围盒。
3. 在精灵体包围盒方向 D 所指的那一侧，构建一个矩形框：
   - 框的与精灵体平行的边长等于精灵体包围盒在该方向的垂直维度上的长度。
   - 框的与精灵体垂直的边长（即框向外延伸的深度）等于最长臂长度 L。
   - 框的内侧边与精灵体包围盒的 D 侧边相邻（间距 1 像素）。
   - 框用颜色 A 绘制单像素宽边框。
4. 在矩形框严格内部查找红(2)锚点像素。对每个锚点像素：
   - 将精灵体的形状缩略为一个 3×3 的简化图案：取精灵体包围盒的 3×3 等分网格，每个等分区域中若有任何颜色 A 像素则对应位置为颜色 A，否则为黑(0)。
   - 以锚点像素为中心，将该 3×3 图案印章到网格上（覆盖已有内容，超出网格边界的部分裁剪）。
5. 擦除十字标记的所有像素（涂为黑(0)）。保留精灵体、矩形框和印章图案。

**关键洞察**：十字标记的最长臂同时编码了两个独立信息——方向（建框在精灵体的哪一侧）和数值（框的深度尺寸）。精灵体既是保留的前景对象，又是印章图案的生成来源（通过缩略）。必须对比多个示例才能推断出臂长度与框深度的对应关系以及 3×3 缩略规则。

## 新题 8：周期边界点定位平铺与旋转角度隐式编码

**组合逻辑**：[平铺(tile)] + [周期填充(periodic_fill)](创新：周期结构不用于逐行填色，而是定义平铺的放置网格) + [旋转(rotate)](创新：旋转角度不由时钟指针显式编码，而是由每个放置点的局部邻域隐式编码) — 周期点阵定义放置位置，局部结构编码旋转，单元精灵在每个位置旋转后平铺

**来源原语**：平铺/旋转/单元精灵/框架模板/锚点对齐/标记编码位置/时钟指针编码角度(a32d8b75), 周期填充/边界点/周期步长/同余对齐(16de56c4), 放置(a32d8b75)

**依赖链**：边界点对定义水平和垂直两个周期步长 → 两个步长的笛卡尔积生成一个 2D 放置网格 → 每个放置点周围的 1-邻域中若有一个伴随点，则伴随点相对于放置点的方位编码旋转角度（上=0度，右=90度，下=180度，左=270度）→ 单元精灵按该角度旋转后以放置点为锚点平铺 → 无伴随点的放置位置不放精灵

用一句话概括：用两对边界点的间距定义平铺网格，每个网格点旁的伴随点方位编码旋转角，将单元精灵旋转后铺设到对应位置。

**输入结构**：黑(0)背景，约 22×22 网格。网格分为上下两区，由一行灰(5)分隔行分开。上区（约 4 行高）包含：一个由颜色 A（如蓝(1)）像素构成的 3×3 或 4×4 单元精灵图案（非对称，使旋转后的结果可区分）。下区为主画布。主画布的左边缘有 2 个红(2)边界点（同列不同行），它们的行间距定义垂直周期步长 Sv。主画布的上边缘（紧接分隔行下方）有 2 个红(2)边界点（同行不同列），它们的列间距定义水平周期步长 Sh。以左上角的红(2)边界点为起点，在主画布中以 (Sh, Sv) 为步长生成一个 2D 网格的放置点（行列坐标分别为起点行 + k×Sv、起点列 + j×Sh，k,j=0,1,2,...，不超出主画布范围）。部分放置点的 4-邻域中有一个绿(3)伴随点（与放置点相邻的上/下/左/右某一格）。生成时保证：每个伴随点恰好与一个放置点 4-相邻；单元精灵足够小使得相邻放置位置的精灵不重叠；至少有 3 个放置点有伴随点；无伴随点的放置位置至少有 1 个。

**规则**：
1. 识别上区的单元精灵（颜色 A 的连通分量，记录其相对于自身包围盒左上角的形状）。
2. 在主画布中识别红(2)边界点：
   - 左边缘同列的 2 个红点，行间距 = Sv（垂直步长）。
   - 上边缘同行的 2 个红点，列间距 = Sh（水平步长）。
3. 以最靠近主画布左上角的红(2)边界点的 (行, 列) 为起点 (R0, C0)，生成放置网格：所有 (R0 + k×Sv, C0 + j×Sh)，其中 k, j 为非负整数，且位置不超出主画布范围。
4. 对每个放置点，检查其上/下/左/右四个邻格中是否有绿(3)伴随点：
   - 伴随点在上方 → 旋转角 = 0度（不旋转）。
   - 伴随点在右方 → 旋转角 = 90度（顺时针）。
   - 伴随点在下方 → 旋转角 = 180度。
   - 伴随点在左方 → 旋转角 = 270度（顺时针）。
   - 无伴随点 → 该位置跳过，不放置精灵。
5. 将单元精灵按确定的角度顺时针旋转后，以放置点为精灵包围盒左上角的锚定位置，绘制到主画布上。精灵像素覆盖已有背景像素；若精灵超出网格边界，裁剪超出部分。
6. 输出中保留分隔行和上区精灵模板。擦除所有红(2)边界点和绿(3)伴随点（涂为黑(0)）。

**关键洞察**：源题 a32d8b75 用显式的时钟指针图案编码旋转角度，此题中旋转角度被压缩为单个伴随点的方位——这是一种极简的隐式编码。同时，平铺网格不由模板显式给出，而是由边界点对的间距隐式定义。必须对比多个示例才能同时推断出边界点定义周期和伴随点编码旋转这两条独立规则。
