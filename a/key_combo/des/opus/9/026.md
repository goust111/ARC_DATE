## 新题 1：枢轴方向编码的印章旋转

**组合逻辑**：[印章覆盖](已有) + [旋转](创新：由枢轴像素相对方向编码旋转角度，而非逐槽位累加) + [枢轴像素](创新：不再定义点对称中心，而是作为方向编码器) → [分块对应](已有)

**来源原语**：印章覆盖/分块对应/模板面板(b190f7f5), 旋转(8e5a5113), 枢轴像素(90347967)

**依赖链**：枢轴像素的方位决定旋转角度 → 旋转角度决定模板朝向 → 朝向后的模板印入对应分块。三者环环相扣：不识别枢轴方位就无法确定旋转；不旋转就印错模板；不做分块映射则无法定位输出。

将每个源像素周围的灰色枢轴像素的相对方位解码为旋转角度，把模板面板的掩码旋转后印入对应的分块位置。

**输入结构**：约 15x15 的网格。由一条灰(5)分隔列将网格分成左右两个大小相同的面板（各约 15x7）。左面板为"源网格"：黑(0)背景上散布 2-4 个不同颜色的前景像素（颜色取自蓝(1)、红(2)、绿(3)、黄(4)中的不同色），每个前景像素恰好有一个灰(5)像素与之 4-邻接（上、下、左、右之一），且不同前景像素的灰色枢轴方位可以不同。右面板为"模板面板"：黑(0)背景上有一个由栗(9)像素构成的 4-连通掩码图形（3-5 像素，非对称形状，以便旋转后可区分朝向）。生成约束：左面板中各前景像素（含其灰色枢轴）互不相邻，保证枢轴归属无歧义；模板掩码在四种 90 度旋转下形状互不相同。

**规则**：
1. 将左面板视为 N x N 的逻辑源格（N 由面板行列数与模板面板尺寸共同确定），每个源格对应输出中一个与右面板等大的分块。
2. 对每个非背景源像素，确定其灰(5)枢轴像素在源像素的哪个 4-邻接方位：上方 → 0 度，右方 → 顺时针 90 度，下方 → 180 度，左方 → 顺时针 270 度。
3. 将右面板的栗(9)掩码按该角度顺时针旋转，然后将掩码中所有栗(9)像素重涂为该源像素的颜色。
4. 将重涂并旋转后的掩码印入输出网格中对应分块的位置，其余分块保持黑(0)背景。
5. 输出网格大小为 N x N 个分块拼成的方阵，每个分块大小等于右面板的行列数。

**关键洞察**：灰色枢轴像素不是对称中心，而是方向指针——它相对于源像素的位置隐式编码了模板的旋转角度，必须跨多个示例才能确认这一编码规则。

## 新题 2：连接杆方向决定旋转后的凹槽匹配

**组合逻辑**：[连接杆](创新：方向编码旋转指令而非滑动距离) → [旋转](创新：不试遍所有方向，由连接杆唯一确定) → [形状匹配](已有) → [重涂色](已有)

**来源原语**：连接杆/滑动/碰撞阻挡(98cf29f8), 形状匹配/凹槽/重涂色/旋转平移嵌入(1acc24af), 旋转(8e5a5113)

**依赖链**：连接杆的延伸方向唯一确定候选块的旋转角度 → 旋转后的形状与凹槽做匹配 → 匹配成功的候选块被重涂色。去掉连接杆就不知道旋转多少度；不旋转就无法正确匹配凹槽；不匹配就不知道该涂哪个。

读取每个候选块所附连接杆的方向作为旋转指令，将候选块旋转后检验是否恰好覆盖蓝色结构中的某个凹槽，若匹配则在原位将该候选块重涂为红色。

**输入结构**：约 18x18 的网格，黑(0)背景。上半区有一个蓝(1)的 4-连通结构体，占据一个宽约 12 列、高 3-4 行的带状区域；结构体内部有 2-3 个黑(0)的 4-连通凹槽（各凹槽触及结构体边界框的底边）。下半区有 3-4 个灰(5)的 4-连通候选块（各 3-6 像素，不规则形状），每个候选块恰好有一条一像素宽的灰(5)连接杆沿四个基本方向之一延伸 1-3 格。连接杆从候选块的某一边缘像素出发，笔直向外延伸。生成约束：每个凹槽恰好有一个候选块在正确旋转后能完全覆盖它（不重叠蓝色像素且不超出网格），至少一个候选块旋转后不匹配任何凹槽（干扰项）。

**规则**：
1. 对每个灰(5)候选块，识别其连接杆的延伸方向：向上 → 0 度、向右 → 顺时针 90 度、向下 → 180 度、向左 → 顺时针 270 度。
2. 将候选块（不含连接杆）绕自身边界框中心按该角度顺时针旋转。
3. 对旋转后的形状，尝试所有平移位置：若该形状恰好覆盖某个凹槽的每一个像素，且不与蓝(1)像素重叠，也不超出网格，则匹配成功。
4. 匹配成功的候选块在其原始位置（含连接杆所有像素）整体重涂为红(2)。
5. 不匹配的候选块（含连接杆）保持灰(5)不变。

**关键洞察**：连接杆不是滑动路径，而是旋转指令——它的方向取代了穷举试转，必须对比多个示例才能发现"方向-角度"的对应关系。

## 新题 3：对称性分支决定象限填充或颜色互换

**组合逻辑**：[对称检测](创新：对任意精灵体做水平镜像检测，而非只对 3x3 图案) → 条件分支{对称 → [区域填充](创新：由控制像素选定象限，填充色来自精灵体), 非对称 → [重涂色](创新：精灵体与控制像素互换颜色)}

**来源原语**：对称检测/镜像轴(44f52bb0), 区域填充/控制像素/象限/所属象限(87ab05b8), 重涂色(1acc24af), 精灵体(465b7d93)

**依赖链**：对称检测的布尔结果决定走哪条分支 → 对称分支中控制像素的象限归属决定填充范围 → 非对称分支中精灵体颜色和控制像素颜色互换。对称检测是不可绕过的决策节点；不做检测则两条分支的选择无据。

对每个精灵体检测水平镜像对称，对称者触发其控制像素所在象限的区域填充，非对称者触发精灵体与控制像素之间的颜色互换。

**输入结构**：约 16x16 的网格，黑(0)背景。网格中散布 3-4 个小型单色 4-连通精灵体（各 3-6 像素，各用不同颜色，取自红(2)、绿(3)、黄(4)、品红(6)），其中一部分精灵体关于自身边界框的水平中线具有镜像对称，另一部分不对称。每个精灵体恰好有一个灰(5)控制像素与之 4-邻接。各精灵体（含其控制像素）的边界框互不重叠，且各精灵体不跨越网格的行中线或列中线。生成约束：对称精灵体至少 1 个、非对称精灵体至少 1 个；不同对称精灵体的控制像素分属不同象限。

**规则**：
1. 将网格按行中线和列中线划分为四个象限（行中线 = floor(H/2)，列中线 = floor(W/2)）。
2. 对每个精灵体，检测其像素集合关于自身边界框水平中线的镜像对称性（即上半部分翻转后是否与下半部分重合）。
3. 若对称：擦除该精灵体和其控制像素；确定控制像素所在的象限；将该象限内所有像素填充为该精灵体的原始颜色。按精灵体边界框左上角从上到下、从左到右的顺序依次处理，后处理的覆盖先处理的。
4. 若非对称：将精灵体所有像素重涂为灰(5)，将控制像素重涂为该精灵体的原始颜色（即精灵体和控制像素互换颜色）。
5. 象限填充不覆盖非对称精灵体已完成互换后的像素（非对称精灵体的处理结果视为固定）。处理总顺序：先处理所有非对称精灵体的颜色互换，再按上述顺序处理对称精灵体的象限填充。

**关键洞察**：同一种灰色控制像素在对称精灵体旁是象限选择器，在非对称精灵体旁是颜色互换的对象——同一视觉元素因对称性检测结果不同而承担完全不同的语义角色。

## 新题 4：嵌套层数驱动反序柱状图

**组合逻辑**：[层序反转](创新：不改变原矩形外观，而是把层序反转后的颜色序列输出为柱状图条) → [计数](创新：计层数而非计对象数) → [排序](已有，按水平位置) → [堆叠/柱状图](已有)

**来源原语**：层序反转/嵌套矩形层/嵌套层次/颜色序列逆转(8dae5dfc), 计数/排序/柱状图/面积筛选(a3325580), 堆叠/嵌套遮罩/按数量排序(b1986d4b)

**依赖链**：嵌套层剥离提供层数和各层颜色 → 层数决定柱状图高度，逆序颜色决定柱状图各行填色 → 水平位置排序决定柱的左右顺序。三步互相依赖：不剥层就不知道颜色和数量；不计数就不知道输出尺寸；不排序就不知道柱的排列。

将每个嵌套矩形的层数作为对应柱状图柱的高度，柱内颜色从底到顶按层序反转（最内层色在底、最外层色在顶），柱的左右顺序由矩形在输入中的水平位置决定。

**输入结构**：约 20x20 的网格，黑(0)背景。3-5 个填充矩形散布在网格中，互不重叠。每个矩形由若干层向内嵌套的单色矩形层构成（每层为均匀的矩形边框，最内层可以是实心矩形），层数在 2-5 层之间，不同矩形的层数可以不同。每层颜色取自蓝(1)、红(2)、绿(3)、黄(4)、品红(6)、橙(7)、青(8)、栗(9)，同一矩形内各层颜色两两不同。各矩形的水平位置（边界框左边缘列号）两两不同。生成约束：至少两个矩形的层数不同。

**规则**：
1. 对每个矩形，从最外层向内逐层剥离：每次移除当前最外圈的均匀颜色边框，记录该层颜色，直到无法再剥为止。记层数为 L_i，外到内颜色序列为 [c_1, c_2, ..., c_{L_i}]。
2. 设最大层数 L_max = max(L_i)。输出网格高度 = L_max，宽度 = 矩形个数。
3. 按各矩形边界框左边缘列号从小到大排序，依次对应输出的第 1 列、第 2 列……
4. 对第 j 个矩形（排序后），其对应输出列从底行（第 L_max 行）开始向上填色：底行填最内层颜色 c_{L_j}，次底行填 c_{L_j - 1}，……顶部填最外层颜色 c_1。若 L_j < L_max，则该列最上方 (L_max - L_j) 个像素保持黑(0)。

**关键洞察**：层序反转不体现在原矩形的重涂上，而是体现在输出柱状图的颜色排列中——最内层变成柱底、最外层变成柱顶，必须对比多个示例中层数不同的矩形才能归纳出这一反转规则。

## 新题 5：镜像验证筛选标记后填充楔形

**组合逻辑**：[镜像](创新：不生成镜像副本，而是用镜像对应关系做真伪验证) → [忽略干扰项](已有) → [填充](已有) + [三角楔形区域](已有) + [标记像素](已有) + [对角线边界](已有)

**来源原语**：镜像/分隔行/镜像对应/源色由反射匹配(c9680e90), 填充/三角楔形区域/标记像素/对角线边界/标记定义楔形范围(896d5239), 忽略干扰项(35ab12c3)

**依赖链**：镜像对应筛选出真标记 → 真标记的空间分布定义楔形几何 → 楔形几何确定填充区域。去掉镜像验证则干扰标记混入，楔形范围错误；去掉楔形构建则空有真标记无法生成填充。

利用分隔线两侧的镜像对应关系区分真标记与干扰像素，仅用通过验证的真标记在上半区构建 45 度三角楔形并填充。

**输入结构**：约 20x15 的网格，黑(0)背景。正中间有一整行灰(5)像素构成的水平分隔行，将网格分为等高的上半区和下半区。上半区散布若干绿(3)像素，其中一部分是"真标记"，另一部分是"干扰像素"。下半区也有若干绿(3)像素，它们的位置恰好是某些上半区真标记关于分隔行的镜像位置（即：真标记在 (r, c)，其镜像在 (separator_row + (separator_row - r), c)）。下半区没有多余绿像素。上半区干扰像素在下半区没有对应镜像。生成约束：上半区的真标记中，存在 1-2 个楔形尖端像素，每个尖端像素沿两个 45 度对角方向各有至少一个真标记作为边界线索，且距离尖端相同；干扰像素不落在任何真标记楔形的内部或边界上。

**规则**：
1. 对上半区每个绿(3)像素 (r, c)，计算其关于分隔行的镜像位置 (r', c)。若下半区 (r', c) 也是绿(3)像素，则该上半区像素为真标记；否则为干扰项。
2. 擦除所有干扰项（上半区无镜像对应的绿像素清为黑(0)）。擦除下半区所有绿像素和灰(5)分隔行（清为黑(0)）。
3. 在上半区剩余的真标记中，识别楔形尖端：若一个真标记像素在两个互补的 45 度方向（如左上+左下、右上+右下、左上+右上、左下+右下）上各有至少一个其他真标记，且在两个方向上最近真标记的距离（切比雪夫距离）相同，则该像素为楔形尖端。
4. 对每个尖端，楔形高度 = 该尖端沿两条对角射线方向上连续存在真标记的最远距离。在尖端与两条射线围成的三角区域内，将所有非绿像素填充为青(8)。
5. 保留所有真标记的绿(3)像素不变。

**关键洞察**：下半区不是输出的一部分，而是一张"验证底片"——仅通过跨分隔行的镜像匹配才能区分真标记和干扰像素，这一筛选步骤必须先于楔形构建。

## 新题 6：多精灵体拉伸入框后按内部面积定优先级

**组合逻辑**：[拉伸/包围盒映射](已有) × 多实例 → [碰撞阻挡](创新：不是滑动碰撞，而是拉伸后区域重叠时的优先级仲裁) ← [内部面积](创新：不决定填充颜色，而是决定重叠优先级)

**来源原语**：拉伸/包围盒映射/空心矩形/精灵体/线段连接再填充(465b7d93), 内部面积/封闭内部/矩形边框(84f2aca1), 碰撞阻挡(98cf29f8)

**依赖链**：多个精灵体各自拉伸进各自的框 → 框的内部区域可能空间重叠 → 内部面积比较决定重叠区域的颜色归属。若不拉伸则无重叠问题；若不比较面积则重叠区域颜色不确定。

将多个精灵体分别拉伸映射到各自配对的空心矩形框内部，重叠区域按框内部面积较大者优先绘制。

**输入结构**：约 22x22 的网格，黑(0)背景。3 个单像素厚的空心矩形框，颜色分别为蓝(1)、红(2)、绿(3)，大小各不相同（边界框从 5x5 到 10x10 不等），框的内部为黑(0)。部分框的内部区域在空间上有重叠（框的边框像素不重叠，但去掉边框后的内部矩形区域有交集）。每个框在网格中另一处有一个同色的小型 4-连通精灵体（3-6 像素），该精灵体不与任何框重叠。生成约束：至少两个框的内部区域有非空交集；三个框的内部面积（内部行数 x 内部列数）两两不同；精灵体的形状使得拉伸后在重叠区域产生非背景像素。

**规则**：
1. 对每个颜色，配对同色的精灵体和空心矩形框。
2. 对每对配对：将精灵体的边界框四个极值映射到框内部区域的四个极值，使用与参考题 465b7d93 相同的拉伸规则——将精灵体像素间的连接关系沿行列方向线性映射到内部区域，在映射位置之间画直线段，然后填充封闭的背景区域。
3. 计算每个框的内部面积（= (框内部行数) x (框内部列数)）。
4. 绘制顺序：按内部面积从小到大依次绘制拉伸结果。面积大的框对应的拉伸结果后绘制，在重叠区域覆盖先绘制的内容。
5. 保留所有框的边框像素不变。擦除精灵体的原始位置（清为黑(0)）。

**关键洞察**：框的内部面积在参考题中决定填充颜色（灰或橙），而在此处决定绘制优先级——面积更大的框"赢得"重叠区域的所有权。必须对比多个示例中不同重叠配置才能归纳出"大面积优先"的规则。

## 新题 7：周期补全后极角连线成封闭轮廓

**组合逻辑**：[补全/平移等价](已有，用于填补缺失顶点) → [描边连线/极角排序](已有，将完整顶点集连成轮廓) ← 互相依赖：需要部分完整簇确定周期向量，周期向量又用于补全不完整簇

**来源原语**：补全/周期性格/缺失像素/平移等价/平移向量决定填充(484b58aa), 描边连线/轮廓顶点/极角排序/路径需通畅(35ab12c3)

**依赖链**：完整顶点簇提供周期平移向量 → 平移向量补全缺失顶点 → 完整簇的顶点按极角排序后连线。去掉周期补全则缺失簇无法描边；去掉描边则补全后的顶点没有最终呈现形式；且周期向量的发现依赖于已有完整簇的模式。

在一个周期性排布的顶点格阵中补全缺失的顶点，然后将每个完整簇的顶点按极角排序连成封闭多边形轮廓。

**输入结构**：约 20x20 的网格，黑(0)背景。红(2)像素标记轮廓顶点，分布为若干"簇"，每簇 4-6 个顶点围绕一个共同质心。各簇按某个二维平移向量 (dr, dc) 周期排列（即簇 i 的质心 + k*(dr,dc) = 簇 j 的质心）。部分簇保持完整（所有顶点都存在），部分簇有 1-2 个顶点缺失（对应位置为黑(0)）。每个完整簇的顶点按极角排序后，相邻顶点之间可以用水平、垂直或 45 度线段连接。生成约束：至少 2 个完整簇和至少 1 个不完整簇；平移向量 (dr, dc) 使得各簇互不重叠；不完整簇的缺失顶点在补全后不与其他簇的顶点位置冲突。

**规则**：
1. 在所有可见红(2)像素中，找到使重叠可见像素数量最大且无颜色矛盾的非零平移向量 (dr, dc)（与参考题 484b58aa 相同的方法）。
2. 利用 (dr, dc) 及其逆向量，将同一平移等价类中的像素聚合。若等价类中某些位置为黑(0)但等价类中其他位置为红(2)，则将黑(0)位置补全为红(2)。
3. 将所有红(2)像素（含补全的）按空间邻近性分为各簇（每簇为一组距离某质心较近的顶点）。
4. 对每个簇，计算其顶点的质心，按各顶点相对质心的极角从 0 度开始逆时针排序。
5. 按排序顺序，在相邻顶点之间（包括最后一个与第一个之间）画橙(7)线段，仅沿水平、垂直或 45 度方向画直线。若两相邻顶点之间无法用单条水平/垂直/45 度直线连接，则不画该段（保留间隙）。
6. 保留所有红(2)顶点像素不变，橙(7)线段像素不覆盖红(2)像素。

**关键洞察**：周期补全和极角连线相互依赖——不补全就有的簇缺顶点导致轮廓缺边，但不识别已有完整簇的轮廓模式就难以发现周期向量。解题者需要同时利用两种结构信息。

## 新题 8：滑动触发锚定物嵌套层反转

**组合逻辑**：[滑动](已有，沿连接杆方向) → 接触事件 → [层序反转](创新：不是全局执行，而是由滑动接触事件有条件触发于锚定物上)

**来源原语**：滑动/连接杆/锚定物/碰撞阻挡/矩形体/沿杆滑至锚定物(98cf29f8), 层序反转/嵌套矩形层/嵌套层次/颜色序列逆转(8dae5dfc)

**依赖链**：滑动决定哪些锚定物被接触 → 被接触的锚定物执行层序反转，未被接触的保持不变。若不滑动，不知道哪些锚被触发；若不做层反转，滑动本身无法产生完整输出变化。

将矩形体沿连接杆方向滑动至锚定物旁，被滑动体接触的嵌套层锚定物执行层颜色反转，未被接触的锚定物保持原样。

**输入结构**：约 18x18 的网格，黑(0)背景。网格中有 3 个"锚定物"：每个锚定物是一个填充矩形（约 4x4 到 6x6），由 2-3 层向内嵌套的单色矩形层构成，各层颜色不同（取自蓝(1)、红(2)、绿(3)、黄(4)、品红(6)、橙(7)中的不同色）。另有 2 个"滑动体"：每个滑动体由一个灰(5)的实心小矩形（2x2 或 2x3）加一条灰(5)的一像素宽连接杆构成，连接杆从矩形体某边缘像素向某基本方向（上/下/左/右）笔直延伸 2-5 格。每个滑动体的连接杆方向上恰好有一个锚定物。生成约束：2 个滑动体指向不同的锚定物（即有 2 个锚被接触、1 个锚不被接触）；滑动路径上无其他障碍物；滑动体滑到终点后与锚定物 4-邻接但不重叠。

**规则**：
1. 对每个滑动体，擦除其连接杆像素（清为黑(0)）。
2. 将滑动体的矩形部分沿连接杆方向平移，移动距离等于连接杆长度（像素数），使矩形体最终与连接杆方向上最近的锚定物 4-邻接。
3. 对被滑动体接触（4-邻接）的锚定物：从外向内逐层剥离，记录颜色序列 [c_1, c_2, ..., c_L]（c_1 最外），然后将第 k 层重涂为 c_{L+1-k}（即最外层涂原最内层色，最内层涂原最外层色）。
4. 未被任何滑动体接触的锚定物保持原样不变。
5. 滑动体矩形保持灰(5)不变。

**关键洞察**：滑动不只是物理位移——它是层序反转的触发器。同一种嵌套矩形锚定物，被接触的和未被接触的输出完全不同。解题者必须同时理解滑动机制和层反转规则，且需要对比有接触和无接触的锚定物才能归纳出条件触发的逻辑。

## 新题 9：并集检测定角色后拉伸入框

**组合逻辑**：[像素并集/双掩码并集等三](已有，检测角色) → 角色分配 → [拉伸/包围盒映射](创新：对并集中的操作数精灵体执行拉伸入框，而非简单重涂色) + [重涂色](已有，对并集结果精灵体)

**来源原语**：像素并集/双掩码并集等三/重涂色(fea12743), 拉伸/包围盒映射/空心矩形/精灵体(465b7d93)

**依赖链**：并集检测识别出两个操作数和一个结果 → 操作数各自拉伸入指定框 → 结果精灵体重涂色。不做并集检测就不知道哪个精灵体扮演什么角色；角色错误则拉伸对象和重涂对象全乱。

在六个精灵体中找到满足"两个操作数的像素并集等于第三个"的三元组，将两个操作数分别拉伸映射进两个空心矩形框内，将结果精灵体重涂色。

**输入结构**：约 22x18 的网格，黑(0)背景。上部有 6 个等大的 4x4 区域排成 3 列 2 行阵列，区域间隔 1 列和 1 行的黑色间距。每个区域内有一个非空的红(2)像素掩码（1-8 个红像素）。其中恰好存在一组三元组：两个操作数区域的红像素掩码取并集后恰好等于第三个结果区域的红像素掩码（每个操作数至少贡献一个结果中不被另一操作数覆盖的独有像素）。下部有两个空心矩形框（单像素厚边框），一个蓝(1)、一个绿(3)，大小不同（内部区域从 3x3 到 6x6 不等），框内部为黑(0)。生成约束：两个操作数在六个区域中的行优先位置有先后（第一操作数位置靠前，第二操作数位置靠后）；两个框互不重叠且与上部阵列不重叠；剩余三个非角色区域的掩码不与任何其他两个区域构成并集关系。

**规则**：
1. 在 6 个区域中搜索三元组 (A, B, D)，使得 A 的红像素集合与 B 的红像素集合的并集恰好等于 D 的红像素集合，且 A 和 B 各自至少有一个像素不被对方覆盖。若存在多个候选三元组（因重复掩码），选行优先位置最靠前的 A。
2. 将第一操作数 A 的红(2)掩码拉伸映射进蓝(1)框内部：A 掩码的边界框四极值对应蓝框内部四极值，映射相邻像素间画直线段，填充封闭区域，拉伸后像素颜色为蓝(1)。
3. 将第二操作数 B 的红(2)掩码拉伸映射进绿(3)框内部：方法同上，拉伸后像素颜色为绿(3)。
4. 将结果 D 区域内的红(2)像素重涂为黄(4)。
5. 剩余三个无角色的区域保持原样（红(2)不变）。
6. 保留两个框的边框像素不变。

**关键洞察**：并集检测不再只是重涂色的前置判断——它决定了哪些精灵体将经历几何拉伸变换以及拉伸到哪个框中。角色分配（操作数 vs 结果）和目标分配（蓝框 vs 绿框）都依赖于并集关系和位置排序的联合判断。

## 新题 10：沿路径移动后对齐到锚点行

**组合逻辑**：[沿路径移动](创新：沿轨迹路径将精灵体移至路径终点，而非沿连接杆滑动矩形体) → [对齐](已有，垂直对齐到锚点精灵体的顶行) ← [共享归一掩码](创新：用归一掩码验证移动后的精灵体是否与锚点同形，不同形的为干扰项不参与对齐)

**来源原语**：沿路径移动/轨迹路径/标记像素(c9680e90), 对齐/锚点像素/共享归一掩码/对齐到锚点(e41c6fd3), 忽略干扰项(35ab12c3)

**依赖链**：路径移动确定精灵体的新位置 → 归一掩码比较筛选出与锚点同形的精灵体 → 同形精灵体垂直对齐到锚点顶行，不同形的被擦除。去掉移动则精灵体位置错误；去掉掩码验证则干扰项混入对齐；去掉对齐则移动后的布局不是最终输出。

每个精灵体沿附着的彩色轨迹路径移动到路径终点，然后检查移动后的精灵体是否与青色锚点精灵体共享归一掩码，同形者垂直对齐到锚点顶行，异形者擦除。

**输入结构**：约 18x20 的网格，黑(0)背景。有一个青(8)精灵体作为锚点（4-连通，4-7 像素，不规则形状）。另有 3-4 个不同颜色的精灵体（颜色取自红(2)、绿(3)、黄(4)、品红(6)，各不相同），每个精灵体同样为 4-连通、4-7 像素。其中 2-3 个精灵体的归一掩码（将精灵体平移使边界框左上角在原点后的像素集）与青(8)锚点的归一掩码相同；其余 1-2 个精灵体的归一掩码与锚点不同（干扰项）。每个非锚点精灵体有一条同色的一像素宽轨迹路径从其某个边缘像素出发，沿 4-连通方向延伸若干格后终止于一个孤立端点。轨迹路径不分叉、不成环。各精灵体（含路径）互不接触，与锚点也不接触。生成约束：每个精灵体沿路径移动到端点后，其边界框不与其他移动后的精灵体或锚点重叠；所有精灵体在不同列（边界框左边缘列号两两不同）。

**规则**：
1. 对每个非锚点精灵体，识别其附着的同色轨迹路径：从精灵体边缘出发的一像素宽 4-连通同色像素链。找到路径的端点（链中仅有一个 4-邻居的像素，且不属于精灵体本身）。
2. 计算从精灵体出发像素到路径端点的位移向量 (delta_r, delta_c)。将精灵体所有像素平移该向量。
3. 擦除原精灵体位置和整条路径（清为黑(0)）。
4. 对移动后的每个精灵体，计算其归一掩码，与青(8)锚点的归一掩码比较。
5. 若归一掩码相同（同形）：保留该精灵体，但将其垂直平移使其边界框顶行等于青(8)锚点的边界框顶行（水平位置保持移动后的列不变）。
6. 若归一掩码不同（异形/干扰项）：擦除该精灵体（清为黑(0)）。
7. 青(8)锚点保持原位不变。

**关键洞察**：路径移动、掩码验证、垂直对齐三步形成递进过滤链——路径终点决定精灵体的候选位置，归一掩码比较过滤掉异形干扰项，最终只有通过双重验证的精灵体才参与对齐。单看任意一步都无法确定最终输出。
