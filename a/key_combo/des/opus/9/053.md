## 新题 1：槽内方位旋转印章

**组合逻辑**：[控制色查找图例](已有) → [旋转](创新：由控制像素在槽内的方位决定旋转角度，而非固定排列) → [重涂色](创新：控制像素颜色决定输出着色，与方位解耦) → [印章覆盖](已有)

**来源原语**：控制色查找图例(c64f1187), 旋转(ed98d772), 重涂色(c64f1187), 印章覆盖(c64f1187), 控制像素(c64f1187/ad7e01d0), 图例模板(c64f1187), 插槽阵列(c64f1187), 阵列排布(ed98d772)

**依赖链**：模板提供"印什么"；控制像素的颜色决定"涂成什么色"；控制像素在槽内的角落位置决定"旋转多少度"——三条信息来自不同来源，在印章写入时汇聚。任缺其一，输出无法确定。

将一个参考模板按控制像素的槽内角落位置旋转并以控制像素颜色重涂后，印入对应槽位；非角落控制像素的槽位输出为空。

**输入结构**：
- 黑(0)背景网格，约 15x17。
- 上部区域：一个 3x3 的模板图案，由灰(5)像素组成，形态为一个非旋转对称的 4-连通小图形（3~6 个灰像素，确保 0/90/180/270 度旋转后图案互不相同）。模板位于上部区域的左侧，右侧为空。
- 下部区域：一个由 3x3 灰(5)格子组成的 M x N 插槽阵列（M, N 各 2~4），槽与槽之间有 1 列/行黑(0)间隔。每个 3x3 槽内全部填充灰(5)，其中若干槽内恰好有一个像素被替换为非灰非黑的前景色（红(2)、绿(3)、蓝(1)、黄(4)中的一种）。该前景像素即为控制像素。
- 控制像素在槽内的位置分两类：角落位置（左上、右上、左下、右下四个角之一）或非角落位置（边中点或中心）。
- 生成约束：模板图案在四个旋转角度下产生四种不同的图案；每个槽内最多一个控制像素。

**规则**：
1. 读取上部模板的 3x3 图案，记为 T。
2. 对下部阵列的每个 3x3 槽逐一处理（按从左到右、从上到下的顺序）：
   a. 若槽内无控制像素，该槽在输出中变为 3x3 全黑(0)。
   b. 若控制像素位于非角落位置（边中点或中心），该槽在输出中同样变为 3x3 全黑(0)。
   c. 若控制像素位于角落位置，根据角落确定旋转角度：左上角 = 0 度，右上角 = 顺时针 90 度，右下角 = 180 度，左下角 = 顺时针 270 度。将模板 T 旋转该角度，然后将旋转后图案中所有灰(5)像素替换为控制像素的颜色，黑(0)像素保持不变。将结果写入该槽位。
3. 输出仅包含下部阵列区域（含槽间间隔），裁剪掉上部模板区域。

**关键洞察**：控制像素的颜色和位置分别编码两个独立维度（着色与旋转），求解者必须从多个示例中分离这两个维度才能归纳完整规则；非角落位置的控制像素是干扰项，需要对比示例才能发现"仅角落触发"这一隐蔽条件。

## 新题 2：负空间涌现滑件

**组合逻辑**：[透明叠加/逐像素比较](已有) → [共同背景标前景](创新：标出的前景不是最终输出，而是产生新的可滑动对象) → [滑动](创新：滑动对象不是输入中的原有图形，而是叠加运算涌现的负空间碎片) → [颜色匹配/同色滑向同色边](已有)

**来源原语**：透明叠加(94f9d214), 逐像素比较(94f9d214), 共同背景标前景(94f9d214), 滑动(17829a00), 颜色匹配(17829a00), 同色滑向同色边(17829a00), 碰撞停止(17829a00), 边界色条(17829a00), 掩码(94f9d214)

**依赖链**：叠加比较产生"共同空白区"对象——这些对象在任一输入半区中都不存在，只在比较后涌现。涌现对象的形状决定了滑动后的最终布局。若跳过叠加，无从知道哪些像素构成滑件；若跳过滑动，只得到中间掩码而非最终输出。

将上下两个掩码的共同空白区域标记为新对象，再将这些对象按颜色规则滑向匹配的边界色条。

**输入结构**：
- 黑(0)背景网格，约 14x14。
- 第一行：全宽的蓝(1)色条（边界色条）。
- 最后一行：全宽的红(2)色条（边界色条）。
- 中间区域被一条全宽的黄(4)分隔行分为上半区和下半区，上半区和下半区行数相同。
- 上半区：黑(0)背景上有若干绿(3)前景像素组成一个 4-连通图形。
- 下半区：黑(0)背景上有若干绿(3)前景像素组成另一个 4-连通图形，与上半区形状不同但占据的行列范围有重叠。
- 生成约束：两个半区的形状叠加后，"双方都是黑(0)"的区域能形成至少两个互不相邻的 4-连通区块，每个区块面积在 2~8 像素之间。

**规则**：
1. 将上半区和下半区逐像素比较（位置对应）。标记出两半区在同一位置都是黑(0)背景的单元格集合，称为"共同空白集"。
2. 将共同空白集中的像素按 4-连通性分为独立区块。
3. 对每个区块：计算其质心行坐标（所有像素行号的算术平均，四舍五入到最近整数）。若质心在该半区上半部分（质心行 < 半区行数 / 2），该区块被标记为蓝(1)；否则标记为红(2)。
4. 在一个与单个半区同尺寸的空白黑(0)画布上放置所有标记后的区块（保持各像素的原始相对位置）。
5. 蓝(1)区块整体向上滑动，直到其最上方像素到达画布第一行（紧贴上边界）。红(2)区块整体向下滑动，直到其最下方像素到达画布最后一行（紧贴下边界）。若多个同色区块滑动后会重叠，按原始质心距目标边界的距离从近到远依次放置，后放置的区块在碰到已放置区块时停止。
6. 输出该画布（不含边界色条和分隔行）。

**关键洞察**：可滑动的对象在输入中根本不存在——它们是两个掩码的"共同缺失"，只有通过逐像素比较才能发现。求解者需要先做减法（找负空间），再做物理运动（滑动），两步之间有因果依赖。

## 新题 3：标记方块定标风车再色数平铺

**组合逻辑**：[边长定缩放因子](已有) → [像素放大](已有) → [旋转+拼接/四旋转组成风车](创新：对放大后的图案而非原始图案做风车排列) → [色数决定重复次数](创新：从原始精灵体的色数而非平铺目标的色数决定风车的重复次数) → [平铺](已有)

**来源原语**：边长定缩放因子(447fd412), 像素放大(447fd412/33067df9), 旋转(ed98d772), 拼接(ed98d772), 平铺(a59b95c0), 色数决定重复次数(a59b95c0), 标记方块(447fd412), 精灵体(ed98d772), 缩放对应(447fd412), 阵列排布(ed98d772)

**依赖链**：标记方块的边长 → 缩放因子 → 放大精灵体 → 四旋转风车 → 精灵体的色数 → 风车平铺次数。删除标记方块则缩放因子未知；删除旋转则无风车；删除色数计数则平铺次数未知。三步串联，每步输出实质性改变下一步输入。

根据标记方块边长放大精灵体，将放大结果组装为四旋转风车，再按精灵体的不同颜色数平铺整个风车。

**输入结构**：
- 黑(0)背景网格，约 18x18。
- 一个小正方形精灵体，尺寸为 3x3，位于网格左上区域。精灵体由 2~3 种非黑前景色组成（如蓝(1)和红(2)，或蓝(1)、红(2)、绿(3)），图案不具备旋转对称性（确保四个旋转角度产生四种不同图案）。
- 一个实心单色正方形（标记方块），尺寸为 k x k（k = 2 或 3），颜色为灰(5)，位于网格右下区域，与精灵体不相邻。
- 生成约束：精灵体必须非旋转对称；标记方块必须为正方形；两者在网格中不重叠不相邻。

**规则**：
1. 读取灰(5)标记方块的边长 k。
2. 将精灵体的每个像素放大为 k x k 的色块，得到一个 (3k) x (3k) 的放大图案 S。
3. 将 S 与其三个旋转副本组装为 2x2 风车：
   - 左上 = S 原图
   - 右上 = S 逆时针旋转 90 度
   - 左下 = S 旋转 180 度
   - 右下 = S 顺时针旋转 90 度
   得到一个 (6k) x (6k) 的风车块 W。
4. 统计原始 3x3 精灵体中不同颜色的数目 C（包括黑(0)，如果精灵体中有黑色像素的话；若精灵体无黑色像素则不计入黑色）。
5. 将风车块 W 在水平和垂直方向各平铺 C 次，得到最终输出，尺寸为 (6kC) x (6kC)。

**关键洞察**：缩放因子和平铺次数分别由两个不同的输入特征（标记方块边长、精灵体色数）独立控制，但它们共同决定输出尺寸。求解者必须同时识别这两个独立的数值来源，仅从输出尺寸无法唯一推断任一参数。

## 新题 4：投影重叠与标尺联合约束区域平铺

**组合逻辑**：[列投影重叠](已有) → [较长侧优先](已有) → [标尺长度决定重复](创新：标尺不控制自身附着图案的平铺，而是控制由投影重叠确定区域内的平铺行数) → [平铺](创新：平铺区域的列范围由投影重叠决定，行范围由较长侧+标尺长度共同决定)

**来源原语**：列投影重叠(770cc55f), 较长侧优先(770cc55f), 边缘线段(770cc55f), 分隔行(770cc55f), 标尺条(9c1e755f), 标尺长度决定重复(9c1e755f), 端部附着(9c1e755f), 瓦片图案(9c1e755f), 平铺(9c1e755f)

**依赖链**：投影重叠确定平铺的列范围和活动侧（上或下）；标尺长度确定瓦片重复行数；瓦片图案来自标尺端部。三个约束缺一不可——没有投影重叠则不知道填哪些列，没有较长侧判断则不知道填哪一侧，没有标尺则不知道重复几次。

两条边缘线段的列投影重叠确定填充的列范围，较长线段选择活动半区，标尺条的长度决定在该半区内将端部瓦片图案重复几行。

**输入结构**：
- 黑(0)背景网格，约 15x18。
- 第一行（顶行）：一条连续的蓝(1)水平线段，长度 L1（3~8 像素），起始列不固定。
- 最后一行（底行）：一条连续的蓝(1)水平线段，长度 L2（3~8 像素，L1 != L2），起始列不固定。
- 顶行与底行的列范围有部分重叠（重叠宽度至少 2 列）。
- 中间某一行是全宽红(2)分隔行，将上半区和下半区分开。
- 网格左侧或右侧边缘：一条垂直灰(5)标尺条，长度 R（2~5 像素）。在标尺条的一端（上端或下端）紧邻一个小矩形瓦片图案（1~3 行 x 重叠宽度列），由非黑非灰非红非蓝颜色组成（如绿(3)或黄(4)）。
- 生成约束：瓦片图案的列数等于顶行与底行的列投影重叠宽度；标尺长度 R 乘以瓦片行数不超过活动半区的可用行数。

**规则**：
1. 计算顶行线段与底行线段的列投影重叠区间 [c_left, c_right]。
2. 判断哪条线段更长：若 L1 > L2，活动半区 = 上半区（从顶行下方到分隔行上方）；若 L2 > L1，活动半区 = 下半区（从分隔行下方到底行上方）。L1 = L2 的情况不会出现（生成约束保证）。
3. 读取标尺条长度 R 和端部附着的瓦片图案 P。
4. 在活动半区内，沿重叠列范围 [c_left, c_right]，从靠近活动线段的一侧开始，将瓦片图案 P 沿行方向重复 R 次（每次紧接上一次，无间隔）。具体地：若活动半区在上方，从紧邻顶行线段的下一行开始向下铺 R 次 P；若在下方，从紧邻底行线段的上一行开始向上铺 R 次 P。
5. 活动半区内重叠列范围之外、以及非活动半区，均保持黑(0)背景不变。保留顶行线段、底行线段、分隔行、标尺条和原始瓦片图案不变。

**关键洞察**：平铺操作的三个参数（列范围、起始侧、重复次数）分别由三个不同的输入特征提供，没有一个特征能独立确定平铺结果；求解者必须同时归纳出三条子规则并将它们整合。

## 新题 5：非对称体充当印章控制器

**组合逻辑**：[对称检测](已有) → [唯一非轴对称/异常值选择](创新：异常值不是被提取的答案，而是充当控制信号) → [印章覆盖](创新：印章的放置图由异常值精灵体的像素图案决定) → [像素放大/像素到块映射](已有)

**来源原语**：对称检测(73ccf9c2), 唯一非轴对称(73ccf9c2), 异常值选择(73ccf9c2), 印章覆盖(ad7e01d0), 像素到块映射(ad7e01d0), 控制色选中则印章(ad7e01d0), 前景对象(73ccf9c2), 控制像素(ad7e01d0), 源图案(ad7e01d0)

**依赖链**：对称检测将精灵体分为两类角色——对称体充当印章模板，非对称体充当放置控制器。没有对称检测则不知道谁是模板谁是控制器；没有控制器的像素图案则不知道在哪些块位印章；没有对称体模板则不知道印什么。角色分配与印章操作紧密耦合。

在多个同色精灵体中，用对称性检测找出唯一的非对称体作为放置图，将对称体作为模板印章到放置图指定的块位。

**输入结构**：
- 黑(0)背景网格，约 15x15。
- 网格中散布若干绿(3)的 8-连通小精灵体，每个精灵体的紧凑边界框为 3x3。
- 精灵体数量为 3~5 个，彼此不相邻（边界框之间至少隔 1 行 1 列）。
- 其中恰好一个精灵体在其 3x3 边界框内不具备左右镜像对称性（即将边界框内的前景掩码左右翻转后与原掩码不同）。
- 所有对称精灵体的形状完全相同（边界框内前景掩码一致）。
- 非对称精灵体的 3x3 边界框内，前景像素数量在 3~6 之间。
- 生成约束：对称精灵体至少 2 个且形状相同；非对称精灵体恰好 1 个。

**规则**：
1. 将所有绿(3)前景像素按 8-连通性分组，得到若干精灵体。
2. 对每个精灵体裁剪到其 3x3 紧凑边界框，提取前景掩码（绿像素=1, 黑像素=0）。
3. 检测每个掩码是否左右镜像对称（将掩码每行左右翻转后与原掩码逐像素比较）。
4. 恰好一个精灵体不对称——将其 3x3 掩码记为控制图 C。其余对称精灵体形状相同——取任意一个的 3x3 边界框图案记为模板 T。
5. 构建输出网格，尺寸为 (3x3) x (3x3) = 9x9。控制图 C 的每个像素对应输出中一个 3x3 块位：
   - 若 C 在 (i, j) 处为前景（绿），将模板 T 完整复制到输出的第 (i, j) 块位（行范围 [3i, 3i+2]，列范围 [3j, 3j+2]）。
   - 若 C 在 (i, j) 处为背景（黑），该块位保持全黑(0)。
6. 输出即为该 9x9 网格。

**关键洞察**：在参考题中，非对称精灵体是需要被"提取"的答案；而在本题中，非对称体的角色被颠覆——它是指挥放置位置的控制信号，对称体才是被复制的内容。求解者必须打破"异常值=输出"的思维定式。

## 新题 6：间隙分治场影响下落射线变色

**组合逻辑**：[间隙对半分](创新：对半分不直接产生可见填充，而是在逻辑上建立左右两个"影响域") → [射线延伸/沿列填至底](创新：射线穿过影响域时改变颜色，而非保持源色) → [奇数间隙留中线](创新：中线列上的射线保持原色不变色，成为唯一可区分的线索)

**来源原语**：间隙对半分(d968ffd4), 奇数间隙留中线(d968ffd4), 矩形(d968ffd4), 射线延伸(d037b0a7), 同列传播(d037b0a7), 沿列填至底(d037b0a7), 前景源像素(d037b0a7)

**依赖链**：两个矩形的位置和间隙宽度确定影响域的分界；源像素的列位置决定它落入哪个影响域（或中线）；影响域决定射线变色为哪种颜色。三层信息逐级约束最终输出，且影响域本身不可见——它只通过射线的颜色变化间接体现。

两个同行对齐矩形之间的间隙被逻辑对半分为两个影响域；从间隙上方落下的射线穿过左域变左色、穿过右域变右色，中线列射线保持原色。

**输入结构**：
- 黑(0)背景网格，约 14x16。
- 网格中部偏下：两个同高度、同行范围的实心单色矩形，水平并列，中间有宽度为 G（3~7）的黑色间隙。左矩形颜色为蓝(1)，右矩形颜色为红(2)。两个矩形高度相同（2~4 行），宽度相同（2~4 列）。
- 间隙上方（矩形上边界之上至少 3 行的区域）：散布若干黄(4)的孤立前景像素，每列最多一个。这些像素的列坐标全部落在间隙的列范围 [gap_left, gap_right] 之内。
- 生成约束：间隙列范围内至少有 3 个黄(4)源像素，分布在间隙的左半、右半和中线（若 G 为奇数）上各至少一个。G 为偶数时无中线列。

**规则**：
1. 确定左矩形的右边界列 c_L 和右矩形的左边界列 c_R。间隙列范围为 [c_L+1, c_R-1]，宽度 G = c_R - c_L - 1。
2. 将间隙列范围逻辑对半分：
   - 左半域 = 列 [c_L+1, c_L + floor(G/2)]（包含 floor(G/2) 列）。
   - 右半域 = 列 [c_R - floor(G/2), c_R-1]（包含 floor(G/2) 列）。
   - 若 G 为奇数，正中列 c_mid = c_L + 1 + floor(G/2) 既不属于左域也不属于右域，为中线列。
3. 对每个黄(4)源像素 (r_src, c_src)，向下延伸一条垂直射线，从 r_src 行开始一直到网格最后一行（包含 r_src 本身），规则如下：
   - 从 r_src 到矩形上边界行的前一行：射线颜色为黄(4)（保持源色）。
   - 从矩形上边界行开始到网格最后一行：
     - 若 c_src 在左半域内，射线颜色变为蓝(1)。
     - 若 c_src 在右半域内，射线颜色变为红(2)。
     - 若 c_src 在中线列上（G 为奇数时），射线颜色保持黄(4)不变。
   - 射线在经过矩形所在行时，不覆盖矩形本身的像素（矩形像素优先保留）。
4. 保留两个矩形的所有原始像素不变。

**关键洞察**：间隙的逻辑对半分在视觉上完全不可见——没有分隔线、没有填充色——它只通过射线在穿过矩形高度后的颜色突变来间接表达。求解者必须从射线颜色的规律反推出隐藏的空间分区规则。奇数间隙时中线射线不变色，是验证分区规则的关键线索。

## 新题 7：标记交叉分区内对角色带同心填充

**组合逻辑**：[连线/标记展为整行整列](已有) → [行列交叉](创新：交叉线不仅是绘制对象，还将区域分割为子矩形) → [同心层填充](创新：不是填充整个框体，而是逐子矩形独立填充) → [对角序映射色环](创新：对角标记不是全局的，而是按空间归属分配给不同子矩形)

**来源原语**：连线/draw_line(8731374e), 标记展为整行整列(8731374e), 行列交叉(8731374e), 标记像素(8731374e), 矩形(8731374e), 同心层填充(99306f82), 对角序映射色环(99306f82), 嵌套层次(99306f82), 对角线标记(99306f82), 空心矩形框(99306f82), 裁剪(8731374e)

**依赖链**：标记像素的行列展开产生分割线 → 分割线将工作区切成子矩形 → 每个子矩形内部的对角单色点提供该区的色带调色板 → 色带按对角序从外到内填充。删除展开则无分区；删除对角点则无调色板；删除同心填充则无最终图案。分区结构同时决定了对角点的归属——同一个对角点落在不同分区中会产生不同结果。

标记像素展开为整行整列形成网格分区，每个分区内部按其包含的对角标记点的颜色序列进行同心层填充。

**输入结构**：
- 黑(0)背景网格，约 18x18。
- 一个灰(5)实心矩形占据网格的中央区域（约 14x14），作为工作区。
- 工作区内有 2~3 个标记像素，颜色为橙(7)，彼此不同行不同列。
- 工作区内另有若干单色单像素点（每个点颜色不同，从蓝(1)、红(2)、绿(3)、黄(4)、品红(6)中选取），这些点沿若干条从左上到右下的对角线排列（每条对角线上的点行号递增、列号递增、相邻点行差=列差=1）。不同对角线上的点颜色互不相同。
- 生成约束：橙(7)标记像素将工作区分割后，每个子矩形内至少有一条对角线上的 1~3 个单色点；每个子矩形的最短边至少 4 像素（确保能形成至少一层同心带）。对角线上的点不与橙(7)标记像素同行或同列。

**规则**：
1. 对每个橙(7)标记像素，将其所在的整行和整列（在工作区范围内）全部涂为橙(7)。这些橙色行/列将工作区分割为若干子矩形。
2. 对每个子矩形（由橙色行/列围成的区域，不含橙色行/列本身）：
   a. 收集该子矩形内部的所有对角标记点。
   b. 按对角方向排序：行号小的排前面；行号相同则列号小的排前面。
   c. 从外到内逐层填充同心矩形带：第一个点的颜色填最外层环，第二个点的颜色填次外层环，依此类推。最后一个点的颜色填充剩余的中心区域。
   d. 若对角点数量少于可填充的层数（层数 = min(子矩形半宽, 子矩形半高)，其中半宽 = ceil(宽/2)，半高 = ceil(高/2)），则最内层颜色向中心延伸填满。
   e. 若对角点数量多于可填充层数，多余的点忽略（只使用前"层数"个点的颜色）。
3. 保留所有橙(7)行/列像素不变。工作区外部保持黑(0)不变。
4. 对角标记点本身被同心填充覆盖（它们只是调色板信息，不保留在输出中）。

**关键洞察**：标记像素的行列展开同时完成两件事——绘制可见的橙色网格线，以及将空间分割为独立填充区域。对角标记点的空间归属由分割结果决定，同一组对角点在不同分割方案下会分配到不同子矩形、产生不同的填充结果。求解者必须先理解分区，再理解每个区的独立调色板。
