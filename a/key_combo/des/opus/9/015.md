## 新题 1：对角射线分区内的最近邻重涂色

**组合逻辑**：[射线延伸ray_extend](已有) → [射线遮挡分区ray_partition](创新：用对角射线而非逐像素射线来划分扇区) → [重涂色recolor + 最近邻选择nearest_neighbor_selection](创新：最近邻匹配被限制在同一扇区内，而非全局)

**来源原语**：射线延伸ray_extend(ea786f4a), 对角放射diagonal_radiation(ea786f4a), 重涂色recolor(6df30ad6), 最近邻选择nearest_neighbor_selection(6df30ad6), 欧氏距离最小minimum_euclidean_distance(6df30ad6), 射线遮挡分区ray_partition(1190bc91), 擦除erase(6df30ad6), 标记像素marker_pixel(6df30ad6), 孤立像素isolated_pixel(ea786f4a)

**依赖链**：对角射线产生的四个扇区边界限定了"哪些标记像素可以为哪些前景对象投票"——没有射线分区，最近邻匹配会跨区选中错误的标记；没有最近邻重涂色，射线分区只是装饰性线条。射线构造了一个局部化的约束空间，重涂色在这个空间内执行，两者通过"空间可达性"紧耦合。

从一个锚点发射四条对角线将画布切成四个扇区，每个灰(5)前景对象被重涂为其所在扇区内距它最近的标记像素的颜色。

**输入结构**：
- 网格约 15x15，背景蓝(1)。
- 恰好一个黑(0)像素，位于网格内部（不在边缘行/列上），作为射线锚点。
- 3-5 个小型单色灰(5)前景对象，每个是 4-连通的不规则图形（3-6 像素），分散在不同扇区中，不与锚点同行同列，互不相邻。
- 若干孤立标记像素，颜色为红(2)、绿(3)、黄(4)、橙(7)等（每种颜色只出现一次），每个含有灰(5)对象的扇区内至少有一个标记像素。标记像素不在对角射线路径上，不与灰(5)对象相邻。
- 生成约束：每个灰(5)对象在其所在扇区内有唯一最近标记像素（不会出现等距平局）。

**规则**：
1. 定位唯一的黑(0)像素。从该像素向四个对角方向（左上、右上、左下、右下）画射线，射线延伸至网格边界，沿途所有像素涂为黑(0)。
2. 四条射线将网格划分为四个扇区：上方（锚点正上方的三角区域）、下方、左方、右方。射线上的像素不属于任何扇区。对于每个非射线、非锚点的像素 (r, c)，若锚点在 (R, C)：若 |r-R| < |c-C| 且 c > C 则属于右扇区；若 |r-R| < |c-C| 且 c < C 则属于左扇区；若 |r-R| > |c-C| 且 r < R 则属于上扇区；若 |r-R| > |c-C| 且 r > R 则属于下扇区。
3. 对每个灰(5)对象，找到与该对象在同一扇区内的所有标记像素。计算该对象的每个像素到每个候选标记像素的欧氏距离平方，取最小值。将整个灰(5)对象重涂为距离最近的那个标记像素的颜色。
4. 擦除所有标记像素（替换为背景蓝(1)）。
5. 保留黑(0)锚点和四条对角射线。

**关键洞察**：对角射线是隐形的"防火墙"——两个灰(5)对象即使全局距离最近的标记颜色相同，也可能因为分属不同扇区而被涂成不同颜色。求解者必须先发现扇区边界的存在，才能正确预测重涂色结果。

## 新题 2：端点连线穿越封闭区域的灌色

**组合逻辑**：[连线draw_line](已有) → [区域填充flood_fill](创新：填充色不是标记本身的颜色，而是穿过该区域的连线颜色) → [冲突优先级conflict_priority](创新：多条线穿过同一区域时，以区域内线段长度最长者为准)

**来源原语**：连线draw_line(253bf280), 同行列端点间填充fill_between_aligned_endpoints(253bf280), 行列对齐row_col_align(253bf280), 区域填充flood_fill(1190bc91), 标记像素marker_pixel(253bf280), 矩形框架rect_frame(fcb5c309), 冲突优先级conflict_priority(03560426)

**依赖链**：连线的路径决定了哪些颜色"穿过"哪些封闭区域——没有连线，区域没有颜色来源；没有封闭区域，连线只是视觉连接。当多条不同色连线穿过同一区域时，"区域内最长线段"这一规则引入了隐蔽的信息——必须对比多个示例才能排除"第一条线优先"或"颜色编号小的优先"等替代假设。

在含有灰(5)围栏封闭区域的网格上，同色对齐标记之间画连线；每个被连线穿过的封闭区域被灌注该连线的颜色，多线穿越时取区域内线段最长者的颜色。

**输入结构**：
- 网格约 18x18，背景黑(0)。
- 3-5 个封闭区域，由灰(5)像素围成闭合边界（每个区域的边界为单像素厚的简单矩形或 L 形围栏，内部包含 6-15 个黑(0)背景像素），区域之间互不相邻。
- 6-10 个标记像素，颜色为红(2)、绿(3)、蓝(1)、黄(4)，放置在所有封闭区域的**外部**。每一行恰好有 0 或 2 个同色标记，每一列恰好有 0 或 2 个同色标记（保证配对唯一）。
- 至少 2 条连线会穿过封闭区域；至少 1 个区域会被 2 条不同色连线穿过。
- 生成约束：穿越同一区域的不同色线段在该区域内部的长度（像素数）不相等，保证无平局。

**规则**：
1. 对每一行，若恰好有两个同色标记像素，在二者之间的所有背景黑(0)像素上画一条该颜色的水平线段（不覆盖灰(5)边界，不覆盖已有连线像素）。
2. 对每一列，若恰好有两个同色标记像素，在二者之间的所有背景黑(0)像素上画一条该颜色的垂直线段（不覆盖灰(5)边界，不覆盖已有连线像素）。
3. 连线按行优先、列其次的顺序绘制（即先处理所有行连线，再处理所有列连线）。若两条线在同一像素交叉，先绘制的保留。
4. 对每个灰(5)封闭区域，统计其内部各种连线颜色的像素数量。若有连线穿过该区域，将该区域内部所有黑(0)背景像素（不包括连线像素本身和灰(5)边界）灌注为区域内线段最长的那种颜色。
5. 没有连线穿过的封闭区域保持原样（内部为黑(0)背景）。
6. 保留所有标记像素、连线像素和灰(5)边界。

**关键洞察**：连线同时充当"颜色传输管道"和"投票权重"——穿过区域的线段越长，该颜色越有可能赢得区域。求解者不能仅看"是否穿过"，还需比较穿越长度，这一隐蔽规则需要对比多个示例才能归纳。

## 新题 3：重叠堆叠矩形的镂空透视

**组合逻辑**：[堆叠stacking + 冲突优先级conflict_priority](已有：后叠覆盖先叠) → [挖孔punch_holes + 同色匹配same_color_matching](已有) → 两者交互产生**透视效果**（创新：镂空的洞暴露下层矩形颜色而非背景，这一效果在源题中均不存在）

**来源原语**：堆叠stacking(03560426), 实心矩形solid_rectangle(03560426), 按左边缘排序ordered_by_left_edge(03560426), 冲突优先级conflict_priority(03560426), 挖孔punch_holes(58f5dbd5), 模板图案motif_stencil(58f5dbd5), 同色匹配same_color_matching(58f5dbd5)

**依赖链**：堆叠产生多层遮挡关系，决定了每个像素位置的"颜色栈"。挖孔在最顶层挖出洞时，暴露的不是背景而是下一层矩形的颜色——这要求求解者同时理解堆叠顺序和挖孔位置，缺一不可。挖孔的形状来自同色模板匹配，堆叠的顺序来自左边缘排序，二者在"同一像素被谁占据"这一问题上交织。

将底部排列的彩色矩形按左边缘顺序水平偏移堆叠，再用同色模板在每个矩形上镂空——镂空处透出下层矩形的颜色而非背景。

**输入结构**：
- 网格约 16x20，背景黑(0)。
- 3-4 个实心单色矩形，颜色分别为红(2)、绿(3)、蓝(1)、黄(4)，每个约 5x5 到 7x7 像素，沿底行排列且接触底边，各矩形左边缘互不相同（定义从左到右的顺序）。
- 对每种矩形颜色，网格顶部区域有一个同色的小型模板图案（motif），2-4 像素，呈不规则形状（如 L 形、对角线等），各模板互不重叠且远离底部矩形。
- 矩形的宽度和间距使得堆叠后相邻矩形水平重叠 2-3 列。

**规则**：
1. 清空画布为背景黑(0)。
2. 按左边缘从左到右的顺序放置矩形：第 i 个矩形（0-索引）的左上角放在 (行0, 列 i*offset)，其中 offset = 第一个矩形的宽度 - 2（使相邻矩形重叠 2 列）。后放置的矩形覆盖先放置的。
3. 记录每个像素位置的完整颜色栈（从底层到顶层）。
4. 对每个已放置的矩形，找到输入中同色的模板图案。将模板居中放置在该矩形的边界框内（若无法完美居中，向右、向下各偏移 1 像素）。
5. 在模板覆盖的位置执行镂空：移除该矩形在这些位置的颜色层。若该位置下方有其他矩形的颜色层，显示下一层的颜色；若下方无其他层，显示背景黑(0)。
6. 擦除模板图案原始位置的像素（替换为背景）。

**关键洞察**：镂空不是简单的"变为背景"——它是"剥去当前层"。当两个矩形重叠且上层被镂空时，该像素显示下层矩形的颜色。求解者必须在脑中同时维护堆叠层次和镂空位置，才能推断每个像素的最终颜色。

## 新题 4：笛卡尔积定位 + 象限旋转复制模板

**组合逻辑**：[填充fill / 边缘标记笛卡尔积edge_marker_cartesian_product](已有：定位交叉点) → [图案复制pattern_replication + 旋转rotation](已有：复制并旋转模板) → [象限位置对应quadrant_correspondence](创新：旋转角度由交叉点所在象限决定，而非由源角决定)

**来源原语**：填充fill(2281f1f4), 边缘标记笛卡尔积edge_marker_cartesian_product(2281f1f4), 行列交叉row_col_intersection(2281f1f4), 标记像素marker_pixel(2281f1f4), 图案复制pattern_replication(4c416de3), 旋转rotation(4c416de3), 象限位置对应quadrant_correspondence(0bb8deee), 各角独立着色per_corner_coloring(4c416de3), 模板template(1e32b0e9)

**依赖链**：笛卡尔积确定 WHERE（模板放在哪），象限确定 HOW（旋转几度），行标记颜色确定 WHAT COLOR（模板涂什么色）。三条独立信息流在每个交叉点汇聚：移除笛卡尔积则无放置位置；移除旋转则无法解释不同交叉点的模板朝向差异；移除颜色映射则无法确定每个副本的颜色。

边缘标记定义行列交叉点，在每个交叉点放置一个小模板的旋转副本——旋转角度取决于交叉点在网格中的象限位置，颜色取决于选中该行的标记颜色。

**输入结构**：
- 网格约 20x20，背景黑(0)。
- 顶行有 3-4 个灰(5)标记像素，标示选中的列。
- 最右列有 3-4 个彩色标记像素（红(2)、绿(3)、蓝(1)等，每行标记颜色不同），标示选中的行及该行对应的颜色。
- 左下角有一个 3x3 的模板精灵体，由灰(5)像素绘制，包含不对称图案（如仅占据 3x3 中的 4 个像素，形成非对称的连通图形），使得 0°/90°/180°/270° 旋转后的形状各不相同。
- 网格中心行和中心列将网格分为四个象限（上左、上右、下左、下右）。

**规则**：
1. 收集顶行的灰(5)标记像素位置作为选中列集合 S_col；收集最右列的彩色标记像素位置和颜色作为选中行集合 S_row（每个元素为 (行号, 颜色)）。
2. 对 S_row 和 S_col 的笛卡尔积中的每个交叉点 (r, c)，放置一份 3x3 模板的副本，以 (r, c) 为中心。
3. 副本的颜色为选中该行的标记像素的颜色。
4. 副本的旋转角度由 (r, c) 所在的象限决定：上左象限 = 0°（原始朝向）；上右象限 = 顺时针 90°；下左象限 = 顺时针 270°；下右象限 = 顺时针 180°。象限边界（中心行、中心列）上的点归入上方/左方的象限。
5. 交叉点按行优先、列其次的顺序处理。若副本之间有像素重叠，后处理的覆盖先处理的。
6. 保留所有原始标记像素和模板精灵体。

**关键洞察**：单看一个示例，可能误以为旋转角度是随机的或由颜色决定的。必须对比多个示例、将交叉点位置映射到象限，才能归纳出"旋转角度由象限决定"这一隐蔽规则——而非由颜色或处理顺序决定。

## 新题 5：格子路径模拟中的分区变向

**组合逻辑**：[路径模拟path_simulation + 颜色循环color_cycle](已有) ⊗ [分区涂色zone_coloring / 内部与外部沟槽interior_vs_exterior_gutter](创新：分区不用于涂色，而用于决定粒子转向方向——内区左转、外区右转) → 两者同时约束每一步行为，非线性流水线

**来源原语**：路径模拟path_simulation(195c6913), 颜色循环color_cycle(195c6913), 碰撞停止collision_stop(195c6913), 交替转向alternating_turn(195c6913), 格子单元lattice_cell(e760a62e), 网格线lattice_line(e760a62e), 分区涂色zone_coloring(137f0df0), 内部与外部沟槽interior_vs_exterior_gutter(137f0df0), 边界框bounding_box(137f0df0)

**依赖链**：粒子每走一步都要查询"当前所在分区"来决定碰壁时的转向方向——分区信息不是预处理结果，而是在运行时逐步影响路径。路径模拟的轨迹又决定了哪些格子被涂色，而涂色反过来构成碰撞障碍（已涂格子阻挡后续运动）。分区规则和路径模拟形成实时交互的状态机，而非先后两步。

粒子在格子中行走，每步涂一色（循环）；碰到格子边界时转向——转向方向取决于粒子当前处于内区（左转）还是外区（右转），直到碰到已涂格子停止。

**输入结构**：
- 网格约 17x17，由灰(5)网格线将画布分为 5x5 的格子（每个格子内部为 2x2 的黑(0)背景区域，网格线宽 1 像素）。
- 内区标记：5x5 格子阵列中，中间 3x3 的子阵列（行 2-4、列 2-4 的格子）的外围网格线上叠加了橙(7)像素，标示内区边界。内区 = 这 9 个格子；外区 = 外围 16 个格子。
- 一个起始标记：某个外围格子内部有一个红(2)像素，位于该格子内部 2x2 区域的某条边上（上/下/左/右边），标记位置指示初始运动方向（如像素在格子内部右边缘 → 粒子向右运动）。
- 左上角格子内有 3 个小色块（各 1 像素），颜色为蓝(1)、绿(3)、黄(4)，从左到右排列，定义颜色循环顺序。

**规则**：
1. 粒子从起始标记所在格子出发，沿标记指示方向运动，每步移动一个格子。
2. 粒子每进入一个格子，将该格子内部（2x2 区域）涂为当前循环颜色，然后循环推进到下一种颜色。起始格子涂第一种循环颜色，起始标记被覆盖。
3. 当粒子的下一步会离开 5x5 格子阵列（碰到外边界）时，粒子必须转向：若粒子当前所在格子属于内区 → 逆时针转 90°（左转）；若属于外区 → 顺时针转 90°（右转）。
4. 转向后，粒子沿新方向继续运动。若转向后的下一个格子仍然越界或已被涂色，粒子停止。
5. 若粒子的下一步是一个已被涂色的格子（不论颜色），粒子停止。
6. 网格线（灰(5)和橙(7)）保持不变。

**关键洞察**：内区和外区的转向规则相反，导致粒子在穿越内外区边界时路径发生突变——在外区倾向于贴壁顺时针螺旋，在内区倾向于贴壁逆时针螺旋。求解者必须同时追踪粒子位置和区域归属，才能预测路径形状。

## 新题 6：重力下落精灵体被尺寸匹配的框架捕获

**组合逻辑**：[滑动sliding + 重力沉降gravity_settle](已有) → [空心框hollow_frame](已有对象，创新用法：框架作为"捕获器"，只有尺寸匹配的精灵体能进入) → [重涂色recolor](创新：框架边框被重涂为捕获到的精灵体颜色，反转了通常"标记涂对象"的方向)

**来源原语**：滑动sliding(d282b262), 重力沉降gravity_settle(d282b262), 碰撞阻挡collision_block(d282b262), 空心框hollow_frame(4c416de3), 矩形框架rect_frame(fcb5c309), 前景对象foreground_object(d282b262), 重涂色recolor(6df30ad6), 面积最大选取largest_area_select(fcb5c309)

**依赖链**：重力下落决定精灵体的运动轨迹；框架的内部尺寸决定哪些精灵体能被捕获（尺寸匹配）；处理顺序（从上到下）决定"谁先占据框架"。三者交织：改变精灵体初始位置会改变到达框架的顺序，改变框架大小会改变匹配关系，改变处理顺序会改变谁被捕获。最终框架的边框颜色反映了捕获结果——这是一个反向信息编码。

小型彩色精灵体从上方下落，被尺寸匹配的灰(5)空心框架捕获并落入框内底部；框架边框变为捕获到的精灵体颜色，未被捕获的精灵体落到网格底部。

**输入结构**：
- 网格约 20x15，背景黑(0)。
- 3-4 个灰(5)空心矩形框架，单像素边框，内部尺寸各不相同（如 3x3、4x3、5x4 内部像素），放置在网格下半部分的不同高度和列位置，框架之间互不重叠、互不相邻。
- 3-4 个小型实心单色精灵体，颜色分别为红(2)、绿(3)、蓝(1)、黄(4)，每个是 4-连通的不规则图形（3-8 像素），放置在网格上半部分。每个精灵体的边界框宽高 <= 某个框架的内部宽高。
- 每个精灵体的列跨度与至少一个框架的内部列跨度有重叠（使精灵体有可能落入该框架）。
- 生成约束：每个框架至多与一个精灵体尺寸匹配（边界框能放入内部），保证无歧义。

**规则**：
1. 按精灵体顶行从小到大排序（高的精灵体先下落）。若顶行相同，左边的先处理。
2. 每个精灵体保持形状和列位置不变，逐行向下移动。
3. 当精灵体的边界框与某个空框架的内部区域在列方向上完全重叠，且精灵体的边界框宽 <= 框架内部宽、边界框高 <= 框架内部高时，该精灵体被"捕获"：精灵体停在框架内部的底边上（边界框底行对齐框架内部底行），列方向居中于框架内部（若无法完美居中，偏左 1 像素）。
4. 若精灵体的下落路径上没有可捕获它的空框架（尺寸不匹配或框架已被占据），精灵体落到网格底行（边界框底行对齐网格最后一行）。
5. 每个捕获了精灵体的框架，其灰(5)边框像素全部被重涂为该精灵体的颜色。
6. 未捕获精灵体的框架保持灰(5)不变。

**关键洞察**：框架是"陷阱"——精灵体能否被捕获取决于边界框与框架内部的尺寸比较，这在视觉上并不直观。再加上从上到下的处理顺序，一个框架可能因为更早到达的精灵体（即使不是最佳匹配）已将其占据而错过"本该属于它的"精灵体。

## 新题 7：连接标记对接拼合后按连接色填补缺口

**组合逻辑**：[拼合stitch + 同色标记对齐对接same_color_dock](已有：按标记组装碎片) → [补全completion](创新：补全的参照不是外部模板，而是拼合结果的边界框矩形——任何边界框内未被碎片覆盖的像素即为缺口) → [间隙填充gap_fill](创新：缺口填充色由最近的连接缝决定，连接标记从"空间定位"转为"颜色源")

**来源原语**：拼合stitch(e9fc42f2), 同色标记对齐对接same_color_dock(e9fc42f2), 连接标记connector_marker(e9fc42f2), 标记侧面决定方向marker_side_dir(e9fc42f2), 补全completion(1e32b0e9), 间隙填充gap_fill(137f0df0), 缺失用分隔色填充missing_filled_with_divider_color(1e32b0e9)

**依赖链**：对接组装确定碎片的相对位置 → 位置确定后才能识别边界框内的缺口 → 缺口的填充色来自最近的连接缝位置。连接标记承担三重角色：（1）指示哪些碎片对接、（2）指示对接方向、（3）其原始位置成为填充颜色的锚点。移除对接则碎片无法组装；移除填充则缺口无法修复；移除连接标记则两者皆不可行。

将多个碎片按同色连接标记对接组装，组装后边界框内的空缺像素用曼哈顿距离最近的连接缝颜色填充。

**输入结构**：
- 网格约 20x20，背景黑(0)。
- 3-4 个前景碎片，每个由栗(9)像素构成主体（4-连通，8-15 像素的不规则图形），边界上带有 1-2 个彩色连接标记像素（红(2)、绿(3)、蓝(1)），每种连接色恰好出现两次（分布在两个不同碎片上）。碎片之间互不相邻。
- 连接标记位于碎片主体的边界像素的外侧邻接位置（即标记紧贴碎片边缘但不属于碎片主体），标记的朝向指示对接方向。
- 碎片正确对接后，组合体的边界框内大部分区域被碎片覆盖，但有 3-6 个像素的小缺口（背景色区域）。
- 生成约束：每个缺口像素到各连接缝位置的曼哈顿距离有唯一最小值（无平局）。

**规则**：
1. 识别连接标记对（同色出现两次的非主体色像素），每对标记连接两个碎片。
2. 对每对连接标记，平移其中一个碎片，使两个同色标记在相邻像素上对齐（标记的外露方向面向对方）。各对接约束同时满足。
3. 对接完成后，移除所有连接标记像素（替换为背景），记录每个连接标记的原始组装后坐标作为"缝合点"。
4. 计算组装后所有碎片主体的最小边界框。
5. 边界框内每个未被碎片主体覆盖的黑(0)像素为"缺口"。对每个缺口像素，计算它到每个缝合点的曼哈顿距离，将该缺口涂为距离最近的缝合点的颜色。
6. 输出为裁剪到边界框的结果。

**关键洞察**：连接标记消失后，它们的**位置记忆**作为颜色梯度的锚点继续影响输出。求解者必须先完成空间拼合（确定标记的最终坐标），才能计算缺口的填充色——"标记位置编码了颜色信息"这一规则在标记本身被擦除后才显现。

## 新题 8：控制条引导平铺并镂空模板图案

**组合逻辑**：[平铺tiling + 沿控制条重复repeat_along_bar + 跨度对齐span_alignment](已有) → [挖孔punch_holes + 同色匹配same_color_matching](已有) → [擦除erase](已有：擦除控制条和模板原件) → 三者在同一组像素上交互：平铺决定"什么被复制"，镂空决定"什么被删去"，控制条决定"复制到哪里"

**来源原语**：平铺tiling(c62e2108), 沿控制条重复repeat_along_bar(c62e2108), 跨度对齐span_alignment(c62e2108), 控制条control_bar(c62e2108), 精灵体sprite(c62e2108), 擦除erase(c62e2108), 挖孔punch_holes(58f5dbd5), 模板图案motif_stencil(58f5dbd5), 同色匹配same_color_matching(58f5dbd5)

**依赖链**：控制条确定平铺方向和范围 → 平铺产生多个精灵体副本 → 每个副本被同色模板图案镂空。镂空的效果只在副本存在时才有意义（无平铺则只有一份原件），而平铺的可视结果被镂空改变（镂空使副本从实心变为镂空图案）。控制条决定有多少副本，模板决定每个副本长什么样——两者共同决定最终输出。

擦除控制条后，将匹配的精灵体沿控制条方向周期平铺，每个副本内部用同色模板图案镂空。

**输入结构**：
- 网格约 18x18，背景黑(0)。
- 2-3 个实心矩形精灵体（solid_rectangle），颜色分别为红(2)、蓝(1)、绿(3)，每个约 4x4 到 5x5 像素。
- 每个精灵体有一根同色的控制条（1 像素厚），水平或垂直放置。水平控制条与精灵体的列跨度相同；垂直控制条与精灵体的行跨度相同。控制条与精灵体之间有 2-6 像素的间距。
- 每种精灵体颜色对应一个同色的小型模板图案（motif，2-4 像素，不规则形状），放置在网格中远离精灵体和控制条的位置。
- 生成约束：平铺后的副本不会超出网格边界，不同精灵体的平铺区域互不重叠。

**规则**：
1. 对每根控制条，通过颜色和跨度对齐找到其匹配的精灵体：控制条颜色 = 精灵体颜色，且（水平控制条的列跨度 = 精灵体的列跨度，或垂直控制条的行跨度 = 精灵体的行跨度）。
2. 擦除所有控制条（替换为背景黑(0)）。
3. 从精灵体原始位置开始，沿朝向其控制条的方向（控制条在精灵体的哪一侧，就向哪个方向平铺），以精灵体的高度（向上/下平铺时）或宽度（向左/右平铺时）为周期，重复放置精灵体副本，直到到达控制条原始位置或网格边界。副本只绘制精灵体的非背景像素。
4. 对每个精灵体颜色，找到同色的模板图案。在每个副本（包括原件）的边界框内，将模板图案居中放置（若无法完美居中，向控制条方向偏移 1 像素）。模板覆盖的位置从该副本中移除（设为背景黑(0)）。
5. 擦除所有模板图案的原始位置（替换为背景黑(0)）。

**关键洞察**：平铺产生了视觉上的"墙纸"效果，但镂空在每个平铺单元中打出相同的洞，打破了重复的单调性。求解者必须分别识别三个要素（控制条的方向、平铺的周期、镂空的图案），才能重建完整的变换链。
