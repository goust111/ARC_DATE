## 新题 1：轮廓围合反转十字扩展方向

**组合逻辑**：[contour_enclosure](已有) + [expand + ortho_diag_role_split](创新：围合状态反转正交/对角的角色分配) + [flood_fill](已有，但填充依赖扩展后的剩余空间)

**来源原语**：contour_line、enclosed_bg_region、contour_enclosure（753ea09b）；expand、cross_pattern、ortho_diag_role_split、arm_center_split_growth（0962bcdd）；flood_fill、small_regions_filled（753ea09b）

**依赖链**：轮廓围合检测 → 围合状态决定扩展角色分配方向 → 扩展后的像素改变围合区域的剩余背景形状 → 剩余背景被填充。围合判定改变扩展的语义，扩展结果改变填充的范围，三者循环约束。

输入中的十字图案根据是否处于轮廓围合区域内，以相反的方式扩展；扩展后围合区域内的剩余背景被填充为轮廓色。

**输入结构**：黑(0)背景，约 20x20 网格。灰(5)像素组成若干 8-连通闭合轮廓线（每条轮廓围成一个 6x6 至 8x8 的封闭区域）。网格中散布若干 3x3 十字图案，每个十字的臂色为橙(7)、中心色为黄(4)。部分十字位于灰色轮廓围合的封闭区域内部，部分位于外部。十字之间互不相邻（任意两个十字的 5x5 扩展足迹不重叠）。生成约束：每个封闭区域内恰好有一个十字，且十字的 5x5 扩展足迹完全落在封闭区域内部。

**规则**：
1. 将所有前景像素（灰色轮廓 + 十字像素）作为屏障，对背景做 4-连通分量分析。面积最大的两个背景分量视为"外部"，其余为"围合内部"。
2. 对于位于围合内部的十字（其中心像素属于某个围合区域）：**反转角色**——中心色黄(4)沿正交方向（上下左右）各延伸一格，臂色橙(7)沿四个对角方向各延伸一格，形成 5x5 足迹。
3. 对于位于外部的十字：**标准角色**——臂色橙(7)沿正交方向各延伸一格，中心色黄(4)沿四个对角方向各延伸一格，形成 5x5 足迹。
4. 扩展完成后，重新对背景做 4-连通分量分析。将仍处于灰色轮廓围合内部（不与外部连通）的所有背景像素填充为灰(5)。

**关键洞察**：同一个十字图案的两种颜色在扩展时的生长方向并非固定——它取决于十字是否被轮廓线围住。必须对比围合内外的十字扩展结果才能归纳出角色反转规则。

## 新题 2：流动路径充当屏障划分区域并编码计数

**组合逻辑**：[flow_draw + step_deflection](已有) → [counting + connected_component](创新：流动路径作为结构性屏障参与连通分量分析) → [compress + region_count_as_col](已有，但计数对象由流动路径动态决定)

**来源原语**：flow_draw、edge_source_pixel、deflector_pixel、step_deflection、deflect_when_aligned（f15e1fac）；counting、connected_component、bg_region、fg_barrier、region_count_as_col（e872b94a）

**依赖链**：偏移控制像素的位置决定流动路径的弯折形状 → 流动路径将背景切分为不同的连通区域 → 区域数被编码为输出列。偏移像素既是流动绘制的参数，又间接决定了计数结果。

从边缘像素出发画出被偏移像素弯折的流动路径，路径作为屏障将背景划分为区域，最终输出一列像素表示区域数量。

**输入结构**：黑(0)背景，约 12x12 网格。青(8)像素分布在网格左边缘（第 0 列）的若干行上，每行至多一个。红(2)像素分布在网格顶边缘（第 0 行）的若干列上，每列至多一个。网格内部无其他前景像素。生成约束：青像素数量为 2~4 个，红像素数量为 2~5 个；流动路径之间不会合并到同一像素（即不同源点的路径不交叉）。

**规则**：
1. 从每个青(8)像素出发，向右逐列绘制流动路径。每前进一列，若该列的第 0 行有红(2)像素，则路径同时向下偏移一行；否则保持当前行。路径像素涂为青(8)，直到到达网格右边缘。
2. 绘制完成后，将所有青(8)路径像素和红(2)像素视为前景屏障。
3. 对黑(0)背景做 4-连通分量分析，计算背景连通区域的数量 N。
4. 输出一个 Nx1 的网格，每个像素为黑(0)。

**关键洞察**：流动路径不是最终图案——它们的唯一功能是作为屏障切割背景空间。红色偏移像素的排列决定了路径弯折方式，从而间接控制了背景被分成多少块。

## 新题 3：形状匹配确定对称修复的替换色

**组合逻辑**：[symmetry_completion + two_axis_orbit](已有) × [recolor + shape_match + containment](创新：对称轨道中的替换色不由轨道内已有像素决定，而由形状匹配外部参考模板决定)

**来源原语**：symmetry_completion、placeholder_marker、symmetric_pattern、two_axis_orbit、unique_color_in_orbit（903d1b4a）；recolor、shape_match、hollow_rect、containment、boxed_color_to_match（776ffc46）

**依赖链**：双轴对称确定绿色占位符应被填补的位置 → 但轨道内无可见色（整个轨道全为绿色占位），需从灰色框中的参考精灵体查找与占位区域形状匹配的模板 → 匹配模板的颜色即为替换色。对称性决定"哪些位置一起替换"，形状匹配决定"替换成什么颜色"。

双轴对称网格中的绿色占位区域，通过与灰框内参考精灵体的形状匹配来确定其正确颜色。

**输入结构**：黑(0)背景，约 16x16 网格。网格中有一个大致占据中央 12x12 区域的多色图案，该图案在水平和垂直方向上具有反射对称性，但部分像素被替换为绿(3)占位符。绿色占位符以"簇"形式出现——每个簇是一组 4-连通的绿色像素（2~5 像素），且每个簇的所有对称轨道伙伴（水平镜像、垂直镜像、中心对称位置）也全部为绿色。网格四个角落各有一个灰(5)空心矩形框（3x3 至 5x5），每个框内包含一个小的单色精灵体（颜色各不相同，如蓝(1)、红(2)、黄(4)、橙(7)），精灵体的形状（2~5 像素的 4-连通图形）各不相同。生成约束：绿色簇的数量与灰框内精灵体的数量相同；每个绿色簇的形状（以其最小边界框内的相对像素布局衡量）恰好与某个框内精灵体的形状一致，且这种对应是一一映射。

**规则**：
1. 识别所有绿(3)占位簇（4-连通分量）。
2. 识别所有灰(5)空心矩形框，提取每个框内部的精灵体及其颜色。
3. 对每个绿色簇，计算其最小边界框内的相对像素布局（形状掩码）。
4. 将该形状掩码与所有灰框内精灵体的形状掩码进行匹配（允许旋转和翻转）。匹配成功的精灵体颜色即为该簇的替换色。
5. 将该绿色簇及其所有双轴对称轨道位置全部替换为匹配到的颜色。
6. 移除四个角落的灰色框和框内精灵体（涂为背景色黑(0)）。

**关键洞察**：与标准对称修复不同，这里的绿色簇整个轨道都是绿色，无法从轨道内部推断颜色。替换色必须通过将簇的几何形状与外部灰框中的参考精灵体匹配来确定——对称性告诉你"哪些位置一起变"，形状匹配告诉你"变成什么"。

## 新题 4：切比雪夫方块内容按提示精灵体旋转

**组合逻辑**：[fill + chebyshev_dist + blocker_dist_size](已有) × [rotate + pixel_count_encodes_rotation](创新：方块不是纯色填充，而是填充后内部图案按提示编码旋转)

**来源原语**：fill、marker_pixel、blocker_pixel、square_region、chebyshev_dist、blocker_dist_size（ff72ca3e）；rotate、cue_sprite、same_color_matching、pixel_count_encodes_rotation（6ffbe589）

**依赖链**：切比雪夫距离决定方块大小 → 方块内填入标记色对应的种子图案 → 提示精灵体的像素数决定图案旋转角度。方块尺寸约束了图案的可用空间，旋转改变了图案朝向，两者在同一区域内交叉作用。

在每个黄色标记周围画出由灰色阻挡像素限定的最大方块，方块内填入种子图案，图案的旋转角度由对应颜色的外部提示精灵体编码。

**输入结构**：黑(0)背景，约 18x18 网格。网格中有 2~3 个黄(4)标记像素和若干灰(5)阻挡像素（与 ff72ca3e 类似的布局）。网格的一条边缘（如底边）有 2~3 个小的单色提示精灵体，颜色分别为蓝(1)、红(2)、绿(3)等，每个提示精灵体是一个 4-连通图形（1~7 像素）。网格中还有对应数量的"种子图案"，每个种子图案是一个 3x3 的非对称单色小图形（颜色与某个提示精灵体相同），位于远离标记和阻挡的位置。生成约束：每个黄色标记的切比雪夫距离到最近灰色阻挡 >= 4（确保方块内能容纳 3x3 种子图案）；黄色标记数量等于种子图案数量，且按从左到右的顺序一一对应；种子图案颜色各不相同。

**规则**：
1. 对每个黄(4)标记，计算到最近灰(5)阻挡的最小切比雪夫距离 d。以标记为中心，画一个半径为 d-1 的正方形区域（即边长 2(d-1)+1），仅改变背景像素，填充为栗(9)作为方块底色。
2. 将黄色标记按从左到右排序，种子图案也按从左到右排序，建立一一对应。
3. 对每个种子图案，找到与其同色的提示精灵体，计算提示精灵体的像素数 p。旋转角度 = (p mod 4) x 90°（顺时针）。
4. 将种子图案的 3x3 边界框内容顺时针旋转上述角度后，放置在对应方块的中心位置（方块中心即黄色标记位置，种子图案的 3x3 边界框中心对齐标记位置）。种子图案像素覆盖方块底色。
5. 擦除原始种子图案位置（涂为背景色）和提示精灵体（涂为背景色）。黄色标记和灰色阻挡保留。

**关键洞察**：方块的尺寸由空间距离决定，方块内图案的朝向由外部提示精灵体的像素数量编码决定——两个看似独立的属性（大小和旋转）分别由不同机制控制，但在同一输出区域交汇。

## 新题 5：标记选半后平铺并描边检测孔洞

**组合逻辑**：[crop + marker_selects_half](已有) → [tile + periodic_repeat](已有) → [draw_outline + hole_presence_triggers_recolor](创新：单次平铺不产生孔洞，但多次平铺的拼接处可能围合出新孔洞，触发差异化描边)

**来源原语**：crop、marker_pixel、marker_selects_half、keep_marked_half（fbf15a0b）；tile、seed_motif、periodic_repeat、fill_grid（9b30e358）；draw_outline、foreground_object、enclosed_hole、hole_presence_triggers_recolor（aa4ec2a5）

**依赖链**：标记选半确定裁剪内容 → 裁剪结果作为种子图案平铺 → 平铺产生的重复图案在拼接处围合出原始种子中不存在的孔洞 → 孔洞存在性触发差异化描边和重涂色。每一步的输出实质性改变下一步的行为。

裁剪出标记所在半区后将其平铺填满网格，对平铺结果描边，拼接处围合出的新孔洞触发特殊重涂。

**输入结构**：黑(0)背景，约 10x20（宽x高）网格。两个红(2)标记像素位于同一列，且都位于左半区或右半区。左半区和右半区各有一些蓝(1)前景像素组成的 4-连通图形（3~8 像素）。标记所在半区的蓝色图形具有特殊设计：单个图形本身无孔洞，但当该半区在垂直方向上下拼接时，相邻副本的图形边缘会围合出 4-连通背景孔洞。生成约束：标记所在半区的宽度为 5 列，高度为 h 行（h 可被网格高度整除或取余后仍可平铺）；蓝色图形不触碰半区的上下边缘（确保平铺时有接缝空间）。

**规则**：
1. 两个红色标记共享一列。保留标记所在的那个半区（左半或右半），裁剪为 5 列宽的子网格。擦除红色标记像素（涂为黑(0)）。
2. 将裁剪结果作为种子图案，在垂直方向上周期性重复，向上向下平铺直到填满原始网格的高度。水平方向也重复平铺直到填满原始网格的宽度。
3. 对平铺后的网格中每个蓝(1)的 4-连通前景分量，检测其边界框内是否存在被该分量完全围合的 4-连通背景孔洞。
4. 无孔洞的分量：画一圈红(2)的 8-邻域描边（仅覆盖背景像素），分量本身保持蓝(1)。
5. 有孔洞的分量：将分量本身重涂为青(8)，孔洞填充品红(6)，然后画一圈红(2)的 8-邻域描边（描边覆盖范围包含孔洞区域的外围）。

**关键洞察**：种子图案中的图形本身没有孔洞，但平铺拼接后相邻副本的图形边缘可能围合出新的孔洞。必须对比单副本和多副本平铺的结果，才能发现孔洞是拼接的涌现效应而非原始属性。

## 新题 6：调色板序列按交替翻转层分配给波形堆叠

**组合逻辑**：[stacking + alternating_flip + one_row_overlap](已有) × [recolor + order_correspondence](创新：每层堆叠的波形从调色板中取不同颜色，翻转层的调色板读取方向也翻转)

**来源原语**：mirror、stacking、wave_pattern、alternating_flip、one_row_overlap（eb281b96）；recolor、palette_column、target_column_run、order_correspondence、column_run_group_match（9b365c51）

**依赖链**：调色板列提供颜色序列 → 波形堆叠决定层数和翻转状态 → 翻转状态决定调色板的读取方向（正序/逆序） → 读取方向决定每层中各列段的颜色。调色板映射和几何翻转形成双向耦合。

将波形图案交替翻转堆叠，每层的颜色由调色板列按对应方向分配——正常层正序读取调色板，翻转层逆序读取。

**输入结构**：黑(0)背景，约 20x8（宽x高）网格。网格左侧有 3~5 个相邻的满高度调色板列（每列单一颜色，颜色各不相同，如蓝(1)、红(2)、绿(3)、黄(4)等）。网格右侧有一个灰(5)的波形图案，高度为 h 行（约 4~5 行），宽度与调色板列数相同。波形图案中每列有一个连续的灰色垂直段（列段），不同列的段起止行不同，形成波浪形轮廓。生成约束：调色板列的数量等于波形图案的列数；波形图案的相邻列段至少共享一行（确保一行重叠拼接时有公共像素行）。

**规则**：
1. 读取调色板列从左到右的颜色序列：P = [P1, P2, ..., Pk]。
2. 提取波形图案（灰色区域）的边界框作为种子波形。
3. 将种子波形堆叠 4 次（原始、垂直翻转、原始、垂直翻转），每相邻两层共享一行重叠（重叠行取非背景像素）。
4. 对第 i 层（从上到下，i=0,1,2,3）的波形，将其各列段按从左到右的顺序与调色板对应重涂色：
   - 若 i 为偶数（原始层）：第 j 列段涂为 P[j]。
   - 若 i 为奇数（翻转层）：第 j 列段涂为 P[k-1-j]（调色板逆序）。
5. 擦除原始调色板列（涂为背景色）。重叠行若有两层颜色冲突，上层覆盖下层。

**关键洞察**：翻转层不仅几何翻转，调色板的读取方向也同步翻转。仅看单层无法发现逆序规则，必须对比正常层和翻转层的颜色分配才能归纳出方向耦合关系。

## 新题 7：排序拼接模板中孔洞触发前景背景互换

**组合逻辑**：[sort_and_concatenate + markers_share_row_or_column](已有) × [draw_outline + enclosed_hole + hole_presence_triggers_recolor](创新：模板是否有孔洞决定每份拷贝的前景/背景色是否互换)

**来源原语**：sort_and_concatenate、multi_pixel_template、single_pixel_marker、markers_share_row_or_column、sort_markers_by_position（12997ef3）；draw_outline、foreground_object、enclosed_hole、hole_presence_triggers_recolor（aa4ec2a5）

**依赖链**：标记排序决定拷贝顺序和颜色 → 模板是否含孔洞决定该拷贝是正常涂色还是反转涂色 → 反转涂色改变了哪些像素是前景，从而改变描边的位置。孔洞这一拓扑属性作为全局开关影响所有拷贝的渲染方式。

将模板按标记顺序拼接成多色副本，但模板中的孔洞触发前景/背景互换——有孔洞的模板在每份副本中以"反相"形式呈现。

**输入结构**：黑(0)背景，约 15x15 网格。网格上方有一个灰(5)的多像素模板（一个 4-连通的 4x4 至 5x5 图形）。该模板可能包含被自身像素完全围合的背景孔洞（0 或 1 个孔洞，由不同示例呈现不同情况）。网格下方有一行（共享同一行）上的 3~5 个单像素标记，颜色各不相同（如蓝(1)、红(2)、绿(3)、黄(4)、橙(7)），位于不同列。生成约束：标记数量为 3~5 个；模板边界框为正方形或接近正方形。

**规则**：
1. 裁剪灰(5)模板到其最小边界框，得到模板掩码 M（前景=灰色像素位置，背景=边界框内非灰色位置）。
2. 检测模板掩码 M 中是否存在被前景完全围合的 4-连通背景孔洞。记录孔洞状态 H（有/无）。
3. 将标记像素按从左到右排序，得到颜色序列 [C1, C2, ..., Cn]。
4. 对每个颜色 Ci 生成一份模板副本：
   - 若 H=无孔洞：将 M 中前景位置涂为 Ci，背景位置保持黑(0)。
   - 若 H=有孔洞：**反相**——将 M 中背景位置（含孔洞）涂为 Ci，前景位置保持黑(0)。
5. 将所有副本从左到右水平拼接（副本之间无间隔），组成输出网格。

**关键洞察**：模板的拓扑属性（是否有孔洞）作为全局二值开关，决定所有副本采用正相还是反相渲染。仅凭一个示例中模板无孔洞的情况，无法预测有孔洞时的行为——必须对比两种情况才能归纳出互换规则。

## 新题 8：色带镜像边界限定精灵体对齐范围

**组合逻辑**：[mirror + band_flip_opposite](已有，色带镜像建立上下对称边框) × [align + coordinate_aligned_to_template + shape_matching](创新：对齐的目标坐标不来自同形模板，而来自镜像色带的颜色分段边界)

**来源原语**：mirror、colored_row_band、canvas_boundary、symmetry、band_flip_opposite（496994bd）；align、sprite、template、shape_matching、coordinate_aligned_to_template（1caeab9d）

**依赖链**：色带镜像到对侧形成上下框架 → 色带中的颜色分段定义水平区间 → 精灵体按颜色匹配被归入对应区间 → 在区间内执行水平居中对齐。色带不只是装饰框——其颜色分段结构编码了精灵体的目标位置。

顶部色带镜像到底部形成框架，色带中各色段定义水平区间，同色精灵体水平居中对齐到对应区间内。

**输入结构**：黑(0)背景，约 20x12 网格。顶部 1~2 行是满宽度的色带，由若干连续的同色列段组成（如：前 5 列蓝(1)、中间 7 列红(2)、后 8 列绿(3)），颜色数量为 3~4 种。网格中部（第 3 行至倒数第 3 行）散布若干小的 4-连通单色精灵体（3~6 像素），每个精灵体的颜色与色带中的某一种颜色相同。同色精灵体的形状可能不同。底部行为空（全背景色）。生成约束：每种色带颜色对应 1~2 个同色精灵体；精灵体初始位置的水平范围可能跨越其对应色段的边界；不同色的精灵体可能在垂直方向上有重叠行。

**规则**：
1. 将顶部色带垂直翻转后复制到底部对应行，形成上下对称的色带框架。中间内容区保持不变。
2. 读取色带的颜色分段：从左到右扫描，将连续同色列归为一段，记录每段的颜色、起始列和结束列。
3. 对网格中部的每个精灵体，根据其颜色找到色带中对应的分段区间 [col_start, col_end]。
4. 将该精灵体水平平移，使其边界框在水平方向上居中于 [col_start, col_end] 区间。垂直位置不变。平移时仅移动精灵体像素到新位置，原位置清为背景色。
5. 若同一色段内有多个精灵体，按其初始行位置从上到下依次处理，确保互不重叠（若居中后会重叠，后处理的精灵体向下偏移一行直到不重叠）。

**关键洞察**：色带的颜色分段不只是视觉框架——它编码了同色精灵体的目标水平区间。镜像操作让框架结构在上下两端可见，暗示色带具有功能性意义，但分段边界与对齐的关系需要对比多个示例才能确认。

## 新题 9：散布标记蛇形压缩后填入切比雪夫方块

**组合逻辑**：[sort + compress + boustrophedon_fill](已有) × [fill + chebyshev_dist](创新：蛇形压缩的结果不是独立输出，而是作为图案嵌入到由距离场确定的方块内)

**来源原语**：sort、compress、scattered_marker、column_order、boustrophedon_fill、odd_row_reversed（cdecee7f）；fill、blocker_pixel、square_region、chebyshev_dist、blocker_dist_size（ff72ca3e）

**依赖链**：散布标记的列序排序确定蛇形填充的颜色序列 → 切比雪夫距离确定目标方块的尺寸 → 蛇形颜色序列按方块尺寸截断并填入方块 → 标记数量与方块面积的关系决定了填充密度。排序结果的长度和方块的容量形成约束匹配。

散布标记按列序排列后，以蛇形顺序逐像素填入由灰色阻挡限定的切比雪夫方块中。

**输入结构**：黑(0)背景，约 15x15 网格。网格中有一个黄(4)中心标记像素和若干灰(5)阻挡像素。另有 N 个散布的单像素前景标记（颜色各不相同，如蓝(1)、红(2)、绿(3)、橙(7)、品红(6)等），每个占据不同的列。生成约束：黄色标记到最近灰色阻挡的最小切比雪夫距离 d 满足 (2(d-1)+1)^2 >= N（方块面积能容纳所有标记颜色）；N 为 4~9，确保蛇形填充至少占两行。

**规则**：
1. 对黄(4)标记，计算到最近灰(5)阻挡的最小切比雪夫距离 d。方块半径 r = d-1，方块边长 s = 2r+1。
2. 将所有非黄、非灰的散布标记按其列位置从左到右排序，得到颜色序列 S = [S1, S2, ..., SN]。
3. 以黄色标记为中心，在 sxs 方块内按蛇形顺序填入颜色：第 0 行（方块最上行）从左到右填 S1, S2, ...；第 1 行从右到左继续填；第 2 行再从左到右，以此类推。每个像素填一个颜色，直到 S 用完。方块内剩余位置保持黑(0)。
4. 擦除所有散布标记的原始位置（涂为背景色）。黄色标记被方块内容覆盖。灰色阻挡保留。

**关键洞察**：方块的尺寸由空间距离场决定，方块的内容由散布标记的列序决定，两个完全不同的信息源（几何距离和空间排列）在同一输出结构中交汇。蛇形填充顺序是隐蔽规则，需要对比多个示例中标记排列和方块内容的对应关系才能发现。

## 新题 10：轮廓围合区域的种子图案按区域面积比缩放平铺

**组合逻辑**：[contour_enclosure + flood_fill](已有，检测围合区域) × [tile + periodic_repeat](创新：平铺周期不是固定的，而是由围合区域面积与种子面积的比值决定) × [erase + ignore_distractors](已有)

**来源原语**：flood_fill、contour_line、enclosed_bg_region、connected_component、contour_enclosure、small_regions_filled、ignore_distractors（753ea09b）；tile、seed_motif、periodic_repeat、fill_grid（9b30e358）；erase（fbf15a0b）

**依赖链**：轮廓围合检测划分出封闭区域 → 每个封闭区域内有一个种子图案 → 种子图案在其所属封闭区域内平铺填满 → 干扰色像素被忽略（不参与平铺计算但保留在输出中）。围合区域的几何形状限定了平铺的范围和裁剪方式。

灰色轮廓围成的每个封闭区域内，种子图案被周期性平铺直到填满整个区域，干扰色保持不动。

**输入结构**：黑(0)背景，约 20x20 网格。灰(5)像素组成若干 8-连通闭合轮廓线，围成 2~3 个不规则封闭区域（每个面积约 25~60 像素）。每个封闭区域内，左上角有一个小的矩形种子图案（2x2 至 3x3，由某种颜色组成，如蓝(1)、红(2)等，不同区域不同颜色）。每个封闭区域内还散布着 1~3 个栗(9)干扰像素。轮廓线外部（非封闭区域）也可能有零星前景像素作为干扰。生成约束：种子图案的边界框不超过封闭区域的最小包围矩形的 1/4 面积；种子图案紧贴封闭区域内部的左上角位置（以区域边界框的左上角为参考）。

**规则**：
1. 将灰(5)轮廓线和所有非背景像素作为屏障，对背景做 4-连通分量分析。面积最大的背景分量为"外部"，其余为"围合内部"。
2. 对每个围合区域，识别其内部的种子图案：种子是该区域内部左上角连续的非背景、非灰、非栗色的矩形色块。
3. 以种子图案的宽高为周期，从种子的左上角位置开始，向右和向下周期性重复种子图案。
4. 平铺仅在当前围合区域的边界内进行：超出区域边界（触碰灰色轮廓或跨入其他区域）的像素不绘制。
5. 平铺时跳过栗(9)干扰像素的位置（干扰像素保持原色不被覆盖）。
6. 轮廓线外部的任何干扰像素也保持不变。

**关键洞察**：每个围合区域独立平铺自己的种子图案，平铺范围严格受限于轮廓边界。种子图案在区域左上角的位置暗示了平铺的起始相位——这不是简单的全局平铺再裁剪，而是每个区域有自己的相位原点。干扰像素穿透平铺层保留在最终输出中。
