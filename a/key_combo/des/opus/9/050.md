## 新题 1：孔洞数决定旋转角度后紧密拼排

**组合逻辑**：[计数(counting)](创新：孔洞数映射为旋转角度) + [旋转(rotate)](创新：旋转角度由拓扑属性驱动而非固定) + [裁剪(crop)] + [拼接(concatenate)]

**来源原语**：计数(counting) ← d2abd087/8698868d；旋转(rotate) ← 2013d3e2/f0f8a26d；裁剪(crop) ← f25fbde4/67636eac；拼接(concatenate) ← 67636eac；封闭区域(enclosed_region) ← 810b9b61；连通精灵(connected_sprite) ← 67636eac；按位置紧密排列(tight_packing_by_position) ← 67636eac；连通孔洞数为键(connected_hole_count_is_key) ← 8698868d

**依赖链**：孔洞拓扑分析提供旋转角度参数 → 旋转改变精灵形态 → 裁剪提取旋转后的紧凑形态 → 按原始位置排序后拼接为最终输出。删除拓扑分析则旋转角度无法确定；删除旋转则拼接结果与输入形态一致（错误）；删除排序则拼接顺序错误。

精灵的封闭孔洞数编码了其旋转角度，旋转后的精灵按原始水平位置紧密拼排。

**输入结构**：约 18x22 的网格，黑(0)为背景。网格上散布 4 个单色精灵体，每个精灵体使用不同的非黑颜色（从红(2)、绿(3)、黄(4)、蓝(1)中选取）。每个精灵体是一个 4-连通的单色区域，像素数在 6~10 范围内，具体形状在不同示例中不同（不固定为特定字母或几何形状）。精灵体的包围框互不重叠，且沿水平方向大致排成一行（包围框中心的 y 坐标相近，x 坐标各不相同）。每个精灵体可能在其内部封闭 0、1、2 或 3 个黑(0)背景色的连通孔洞区域（孔洞使用 4-连通判定：即完全被该精灵体的像素包围、无法沿上下左右到达网格边界的黑色连通区域）。生成约束：4 个精灵体的孔洞数互不相同（分别为 0、1、2、3），且每个精灵体的包围框是正方形（保证旋转后包围框尺寸不变）。

**规则**：
1. 对每个精灵体，计算其封闭的 4-连通黑色孔洞区域数量 h（0、1、2 或 3）。
2. 将该精灵体绕其包围框中心顺时针旋转 (h x 90) 度：0 个孔洞 → 不旋转；1 个孔洞 → 顺时针 90 度；2 个孔洞 → 180 度；3 个孔洞 → 顺时针 270 度。
3. 将每个旋转后的精灵体裁剪至其紧凑包围框（去掉包围框外的所有行列）。
4. 按各精灵体**原始**包围框左边缘的列索引从小到大排序。
5. 将排序后的裁剪块从左到右水平拼接，顶部对齐，相邻块之间无间隙。若各裁剪块高度不同，短的块底部补黑(0)至等高。
6. 输出为拼接后的矩形网格。

**关键洞察**：旋转角度由拓扑属性（孔洞数）编码，而非颜色或形状，求解者需要对比多个示例才能发现"孔洞数 x 90度"的映射规则——因为不同示例中同一孔洞数的精灵体形状完全不同，排除了形状匹配的可能。

## 新题 2：三角点推断中心后射线触发框架填充

**组合逻辑**：[填充(fill)/缩小复制(shrink_copy)中的角点推断逻辑](创新：推断出的中心成为射线发射源) + [射线延伸(ray_extension)](创新：射线被障碍物截断) + [填充(fill)](创新：填充条件由射线接触判定驱动)

**来源原语**：角点标记(corner_marker) ← 11e1fe23；已知角点推断中心(infer_center_from_known_corners) ← 11e1fe23；射线延伸(ray_extension) ← 1d398264；中心向外辐射(radiate_from_center) ← 1d398264；空心框架(hollow_frame) ← 8698868d/e73095fd；接触判定(contact_detection) ← 0d87d2a6；填充(fill) ← af902bf9/e73095fd；仅填矩形内部(fill_interior_only) ← e73095fd

**依赖链**：3 个角点确定正方形 → 推断中心位置 → 中心发射 8 方向射线 → 射线被障碍物（角点像素、框架轮廓）截断 → 射线与框架轮廓的 4-邻接关系决定哪些框架被填充。删除角点推断则无射线源；删除射线则无接触信息；删除填充则框架不变。

三个角点标记隐式定义一个正方形的中心，从该中心发射的罗盘射线触碰到的空心框架被填充。

**输入结构**：约 20x20 的网格，黑(0)为背景。网格上有 3 个单像素的角点标记，每个标记使用不同的颜色（从蓝(1)、绿(3)、黄(4)中选取）。这 3 个标记位于同一个轴对齐正方形的 3 个角上（第 4 个角缺失）。该正方形的边长为偶数（保证中心落在整数坐标上），边长至少为 6。此外，网格上散布 3 个灰(5)色的空心矩形框架，每个框架是单像素厚的矩形轮廓（宽和高均至少为 3），框架内部为黑(0)。框架彼此不重叠，也不与角点标记或推断出的正方形区域重叠。生成约束：至少 1 个框架能被从中心发射的射线触及（4-邻接），至少 1 个框架不能被任何射线触及。

**规则**：
1. 找到 3 个非背景单像素标记。它们位于某个轴对齐正方形的 3 个角上。根据 3 个角的行列坐标推断第 4 个角位置和正方形的中心坐标 (cr, cc)。
2. 在中心位置 (cr, cc) 画一个红(2)像素。
3. 从中心向 8 个罗盘方向（北、东北、东、东南、南、西南、西、西北）各发射一条射线，射线颜色为红(2)。每条射线沿该方向逐像素延伸，当下一个像素位置已被非背景色占据（角点标记像素或框架轮廓像素）或超出网格边界时，射线停止（不覆盖该阻挡像素）。
4. 射线绘制完成后，对每个灰(5)空心框架进行判定：若该框架的轮廓像素中至少有一个与某条射线像素 4-邻接（上下左右共享边），则该框架被"触及"。
5. 将所有被触及的框架的封闭内部（轮廓围住的黑色区域）填充为黄(4)。未被触及的框架保持不变（内部仍为黑色）。
6. 输出为与输入同尺寸的网格，包含原始角点标记、中心像素、射线、以及条件填充后的框架。

**关键洞察**：中心位置必须通过三点几何推断获得，射线的传播范围受障碍物限制，因此框架是否被填充取决于一条从推断中心出发、受障碍物约束的射线路径能否到达框架附近——这是几何推断、传播截断和空间接触三重耦合。

## 新题 3：周期修复后拓扑分类重涂

**组合逻辑**：[补全(inpaint)](原有用法) + [重涂色(recolor)](创新：涂色判据由修复后的拓扑属性驱动) + [计数(counting)](创新：孔洞检测作为中间决策节点)

**来源原语**：补全(inpaint) ← 0dfd9992；平移对称(translational_symmetry) ← 0dfd9992；轨道可见色填缺失(orbit_color_restores_missing) ← 0dfd9992；重涂色(recolor) ← 810b9b61；封闭区域(enclosed_region) ← 810b9b61；有空洞则重涂(recolor_if_hole) ← 810b9b61；连通分量(connected_component) ← d2abd087

**依赖链**：周期修复还原被破坏的图案 → 在完整图案上执行拓扑分析（检测孔洞） → 拓扑分类结果驱动重涂色。修复前黑色破损区域打断了部分形状的边界，使得空心形状看起来像开放形状、实心形状看起来像断裂碎片——必须先修复才能正确判断拓扑属性。

破损的周期图案被对称性修复后，空心图形涂绿、实心图形涂红。

**输入结构**：约 12x12 的网格。网格呈现一个彩色周期平铺图案，平铺周期为 3x3 或 4x4。图案使用 2~3 种非黑颜色（例如蓝(1)和橙(7)），这些颜色构成的连通区域中，一部分在完整图案中是拓扑空心的（内部封闭了黑(0)背景孔洞），另一部分是拓扑实心的（无封闭孔洞）。图案中有若干位置的像素被替换为黑(0)（"破损"），破损的位置经过设计，使得至少一个空心形状的孔洞边界被打断（如果不修复，该形状看起来像开放的、没有封闭孔洞），同时至少一个实心形状也被打断（看起来像两个小碎片）。非黑像素足以唯一确定平移周期。生成约束：破损区域不超过总像素的 30%；修复后每个前景连通分量至少有 3 个像素。

**规则**：
1. 从所有非黑像素中检测最小平移周期向量（行周期 pr，列周期 pc）。
2. 对每个黑(0)像素，沿平移轨道 (r + k*pr, c + l*pc) 收集所有非黑颜色值。若轨道中恰好有一种非黑颜色，将该黑像素修复为该颜色。（生成保证每个破损像素的轨道中至少有一个可见的非黑副本。）
3. 在完全修复的网格上，识别所有 4-连通的单色前景连通分量（即颜色相同且 4-连通的像素集合，排除黑(0)背景）。
4. 对每个连通分量，检测其是否封闭了至少一个 4-连通的黑色孔洞区域（完全被该分量像素包围的黑色区域）。
5. 将所有空心分量（含至少一个孔洞的）重涂为绿(3)；将所有实心分量（无孔洞的）重涂为红(2)。背景像素保持黑(0)。
6. 输出为与输入同尺寸的网格。

**关键洞察**：拓扑分类（空心 vs 实心）在修复前无法正确完成——破损恰好位于空心形状的孔洞边界上，使其在修复前表现为开放形状。周期修复与拓扑检测之间存在不可跳过的因果依赖。

## 新题 4：罗盘射线划分象限后按区内计数奇偶重涂

**组合逻辑**：[射线延伸(ray_extension)](创新：射线的功能从装饰转为空间分区工具) + [计数(counting)](创新：计数在射线划出的分区内独立进行) + [重涂色(recolor)](创新：涂色取决于分区内的计数奇偶性)

**来源原语**：射线延伸(ray_extension) ← 1d398264；中心向外辐射(radiate_from_center) ← 1d398264；排除中心像素(exclude_center_pixel) ← 1d398264；计数(counting) ← d2abd087；面积分类(area_classification) ← d2abd087；面积决定颜色(area_determines_color) ← d2abd087；重涂色(recolor) ← 810b9b61；连通分量(connected_component) ← d2abd087

**依赖链**：中心块发射十字射线 → 射线将网格分为 4 个象限 → 统计每个象限内的前景对象数 → 奇偶性决定该象限所有对象的输出颜色。射线同时是可见输出和分区工具（双重用途）。删除射线则无法分区；删除计数则无涂色依据；删除重涂则对象不变。

中心方块发射十字射线将网格分为四象限，每象限内前景对象依据该象限对象总数的奇偶性统一重涂。

**输入结构**：约 15x15 的网格，黑(0)为背景。网格中心偏近位置有一个 3x3 的灰(5)实心方块。方块周围散布 8~12 个小型前景对象，每个对象是一个 4-连通的单色区域，像素数在 2~5 范围内，颜色从蓝(1)、绿(3)、黄(4)、橙(7)中选取（同一网格中可有多个对象同色）。所有对象的像素不与灰方块相邻，也不位于灰方块中心行或中心列上（确保射线路径上无障碍物）。生成约束：4 个象限中至少 1 个象限含奇数个对象、至少 1 个象限含偶数个对象（保证两种涂色结果都出现）。

**规则**：
1. 找到灰(5) 3x3 实心方块，确定其中心像素位置 (cr, cc)。
2. 从中心向 4 个基本方向（北、南、东、西）发射射线：每条射线沿该方向逐像素延伸至网格边缘，颜色为灰(5)。射线包括中心行/列上的所有像素（从方块边缘延伸到网格边缘）。
3. 射线和灰方块将网格划分为 4 个象限：左上（行 < cr 且列 < cc）、右上（行 < cr 且列 > cc）、左下（行 > cr 且列 < cc）、右下（行 > cr 且列 > cc）。射线所在行/列上的像素不属于任何象限。
4. 统计每个象限中 4-连通前景对象（非黑、非灰的连通分量）的数量 n。
5. 若 n 为奇数，将该象限中所有前景对象重涂为红(2)；若 n 为偶数，重涂为蓝(1)。每个对象的所有像素统一重涂，不改变形状。
6. 灰方块和灰射线保持不变。背景保持黑(0)。
7. 输出为与输入同尺寸的网格。

**关键洞察**：射线的双重身份——既是绘制到输出的可见元素，又是定义计数边界的空间分区工具。求解者需从多个示例中归纳出"象限内对象数的奇偶性"这一非显然的分类标准（而非按颜色、形状或位置分类）。

## 新题 5：引导线穿过空心框架则填充内部

**组合逻辑**：[连线(draw_line)](创新：引导线的判定对象从实心物体变为空心框架的内部空间) + [填充(fill)](创新：填充由线-框穿越关系驱动) + [接触判定(contact_detection)](创新：从表面接触改为穿透内部)

**来源原语**：边界标记对(border_marker_pair) ← 0d87d2a6；引导线(guide_line) ← 0d87d2a6；连线(draw_line) ← 0d87d2a6/29c11459；空心矩形(hollow_rectangle) ← e73095fd；封闭孔洞(enclosed_hole) ← e73095fd；仅填矩形内部(fill_interior_only) ← e73095fd；接触判定(contact_detection) ← 0d87d2a6

**依赖链**：边界标记对确定引导线方位 → 引导线在网格上绘制 → 引导线是否穿过框架内部空间（而非仅接触外壁）决定填充与否。判定标准是"穿透"而非"邻接"——引导线必须有像素落在框架轮廓围住的内部区域中，而非仅与轮廓 4-邻接。

边界标记对定义的引导线穿透空心框架内部时，该框架被填充。

**输入结构**：约 18x18 的网格，黑(0)为背景。网格的左右边缘或上下边缘上有若干蓝(1)标记像素，成对出现——每对标记分布在相对的两条边上，且共享同一行（左右对）或同一列（上下对）。网格内部散布 3~4 个黄(4)色空心矩形框架，每个框架是单像素厚的矩形轮廓（宽和高均至少 4），内部为黑(0)。框架彼此不重叠。标记对数量为 2~3 对。生成约束：至少 1 条引导线穿过某框架的内部空间（即引导线上至少有一个像素落在框架轮廓严格围住的内部区域内），至少 1 个框架不被任何引导线穿过（引导线可能从框架外侧经过或不经过该区域）。

**规则**：
1. 识别所有蓝(1)边界标记对：在网格左边缘和右边缘同一行上各有一个蓝像素，则构成一个水平对；在上边缘和下边缘同一列上各有一个蓝像素，则构成一个垂直对。
2. 对每个标记对，在其共享的行（水平对）或列（垂直对）上画一条贯穿整行/整列的蓝(1)引导线。引导线覆盖该行/列的所有像素，但不覆盖黄(4)框架轮廓像素（黄色优先于蓝色）。
3. 对每个黄(4)框架，检查其内部区域（轮廓严格围住的黑色矩形区域）中是否包含至少一个蓝(1)引导线像素。"内部"指轮廓向内缩进一圈后的矩形区域。
4. 若框架内部包含引导线像素，将该框架的整个内部区域填充为绿(3)（覆盖内部的蓝色引导线像素和黑色像素）。
5. 未被引导线穿过的框架保持内部为黑(0)不变。
6. 输出为与输入同尺寸的网格，包含蓝引导线（在背景区域可见）、黄框架轮廓和条件填充结果。

**关键洞察**：引导线与框架的关系不是表面接触，而是空间穿透——引导线必须有像素落入框架内部才触发填充。一条从框架外侧擦过（仅与轮廓邻接但不穿过内部）的引导线不会触发填充，求解者需对比"被穿过但被填充"和"被擦过但未填充"的示例才能区分。

## 新题 6：邻接矩形孔洞总数奇偶控制细条旋转

**组合逻辑**：[旋转(rotate)](创新：旋转决策由外部空间环境的拓扑属性驱动) + [计数(counting)](创新：计数对象是邻居的孔洞而非自身属性) + [接触判定(contact_detection)](创新：从触发重涂改为触发旋转)

**来源原语**：单像素宽条(thin_bar) ← f0f8a26d；中心点不变(center_fixed) ← f0f8a26d；朝向交换长度保持(orient_swap_keep) ← f0f8a26d；空心矩形(hollow_rectangle) ← e73095fd；封闭孔洞(enclosed_hole) ← e73095fd；计数(counting) ← d2abd087/8698868d；包含(containment) ← 810b9b61；接触判定(contact_detection) ← 0d87d2a6

**依赖链**：每根细条需找到与其 4-邻接的所有矩形 → 统计这些矩形的封闭孔洞总数 → 孔洞总数的奇偶性决定该细条是否旋转 90 度。细条自身无拓扑信息，决策完全来自空间邻居的拓扑属性，构成"跨对象拓扑推理"。

细条是否旋转 90 度取决于与其相邻的矩形中封闭孔洞的总数奇偶。

**输入结构**：约 17x17 的网格，黑(0)为背景。网格上有 3~4 个彩色矩形区域（每个矩形使用不同颜色，从蓝(1)、绿(3)、黄(4)、橙(7)中选取），每个矩形是实心填充的单色区域（宽 3~5、高 3~5 像素），其中一些矩形内部挖去了若干黑(0)像素形成封闭孔洞（每个矩形有 0~2 个 4-连通孔洞）。此外，网格上有 3~4 根品红(6)色细条（1 像素宽、奇数长度 3~7 像素），水平或垂直放置。每根细条至少与一个矩形 4-邻接（即细条的某个像素与某个矩形的某个像素上下或左右相邻）。细条不与其他细条重叠或邻接。生成约束：至少 1 根细条的邻接矩形孔洞总数为奇数，至少 1 根为偶数，保证两种旋转结果都出现。旋转后细条不会越出网格边界，也不会与任何矩形或其他细条重叠。

**规则**：
1. 识别所有品红(6)细条（1 像素宽、奇数长度的水平或垂直连通分量）和所有彩色矩形区域。
2. 对每根细条，找出所有与其 4-邻接的矩形（细条的至少一个像素与矩形的至少一个像素共享上下或左右边）。
3. 对每个邻接矩形，计算其内部封闭的 4-连通黑色孔洞区域数量。将该细条所有邻接矩形的孔洞数求和得到 S。
4. 若 S 为奇数，将该细条绕其中心像素旋转 90 度（水平变垂直，垂直变水平），保持长度和颜色不变。若 S 为偶数（包括 0），保持原朝向不变。
5. 矩形保持原样不变（含孔洞）。
6. 输出为与输入同尺寸的网格。

**关键洞察**：细条的旋转不由自身的任何属性决定，而由其空间邻居（矩形）的拓扑属性（孔洞数）的聚合结果驱动。求解者需要跨越对象边界进行推理：先识别邻接关系，再分析邻居内部的拓扑结构，最后将聚合结果映射到几何变换。

## 新题 7：分割线编码缩放因子驱动配对精灵放大

**组合逻辑**：[连线(draw_line)/分裂(split)](创新：分割线的数量被重新解读为数值编码) + [像素放大(pixel_scaling)](创新：放大倍率由外部编码结构决定) + [裁剪(crop)] + [排序(sort)]

**来源原语**：标记像素(marker_pixel) ← 855e0971/6d1d5c90；标记沿短轴展分割(marker_short_axis_div) ← 855e0971；矩形区域(rect_region) ← 855e0971；像素放大(pixel_scaling) ← f25fbde4；含间隙等比放大(scale_with_gaps) ← f25fbde4；裁剪(crop) ← f25fbde4/67636eac；连通精灵(connected_sprite) ← 67636eac；编码映射(encoding_map) ← 65b59efc

**依赖链**：矩形中的标记像素展开为分割线 → 分割线数量确定该矩形的段数 → 段数作为缩放因子传递给配对精灵 → 精灵按该因子像素放大。分割线的空间意义（切割矩形）与数值意义（编码倍率）被同时使用——空间效果可见于输出左半部，数值效果体现在输出右半部。

矩形中的标记分割线数量编码了配对精灵的像素放大倍率。

**输入结构**：约 20x15 的网格，黑(0)为背景。网格左半区包含 3 个灰(5)色实心矩形区域（每个宽 4~6、高 3~5 像素），沿纵向排列（由上到下分别为第 1、2、3 个矩形，互不重叠）。每个矩形内部有 0~2 个红(2)色标记像素，位于矩形内部（非边缘行列上的位置）。网格右半区包含 3 个小型单色精灵体（每个使用不同颜色，从蓝(1)、绿(3)、黄(4)中选取），每个精灵体 3~5 像素，4-连通，具体形状在不同示例中不同。精灵体也沿纵向排列，由上到下的垂直顺序与左半区矩形一一对应（第 1 个精灵对应第 1 个矩形，以此类推）。生成约束：3 个矩形的标记像素数互不相同（分别为 0、1、2 个），对应缩放因子分别为 1、2、3。

**规则**：
1. 在左半区每个灰色矩形中，将每个红(2)标记像素沿矩形的短轴方向展开为一条贯穿矩形该维度的分割线：若矩形宽 > 高，则沿整列（垂直方向）画分割线；若高 > 宽，则沿整行（水平方向）画分割线；若宽 = 高，则沿整列画线。分割线颜色为红(2)，覆盖该行/列中矩形内的所有像素。
2. 统计每个矩形中的分割线数量 d（等于该矩形中红色标记像素的数量）。缩放因子 f = d + 1。
3. 按纵向位置（包围框上边缘行索引从小到大），将左半区第 k 个矩形与右半区第 k 个精灵体配对。
4. 将每个精灵体裁剪至紧凑包围框，然后进行 f 倍像素放大：将裁剪后的每个像素替换为 f x f 的同色像素块。
5. 输出仅包含放大后的精灵体：按配对顺序从上到下垂直排列，顶部对齐于输出网格左上角，相邻放大精灵之间有 1 行黑(0)间隔。输出网格宽度等于所有放大精灵中的最大宽度（较窄的精灵右侧补黑），高度等于所有放大精灵高度之和加上间隔行。

**关键洞察**：分割线在矩形内的空间作用（将矩形切为若干段）与其在精灵处的数值作用（编码放大倍率）完全不同——标记数量被从一种语义（空间分区工具）转化为另一种语义（数值参数），求解者需要发现这种跨结构的编码关系。

## 新题 8：对向轨迹汇合点落入框架内则填充该框架

**组合逻辑**：[连线(draw_line)/滑动(sliding)](创新：轨迹的终点——汇合点——成为另一操作的空间判据) + [填充(fill)](创新：填充条件由汇合点的几何位置与框架的包含关系决定) + [接触判定(contact_detection)](创新：从面邻接改为点包含)

**来源原语**：孤立像素(isolated_pixel) ← 29c11459；对侧配对(opposite_pairing) ← 29c11459；相向移动留迹汇合(inward_trails_meet_mark) ← 29c11459；汇合点(meeting_point) ← 29c11459；空心框架(hollow_frame) ← 8698868d/e73095fd；封闭孔洞(enclosed_hole) ← e73095fd；填充(fill) ← af902bf9/e73095fd；包含(containment) ← 810b9b61

**依赖链**：对侧像素配对 → 双向轨迹汇合 → 汇合点坐标确定 → 检查汇合点是否落在某空心框架的封闭内部 → 是则填充该框架。轨迹几何运算决定了一个关键坐标（汇合点），该坐标与框架拓扑结构的包含关系驱动填充操作。

对向边缘像素对的轨迹汇合点若落入空心框架内部，则该框架以汇合点颜色填充。

**输入结构**：约 17x17 的网格，黑(0)为背景。网格的左右或上下对向边缘上有 2~3 对彩色孤立像素，每对使用相同颜色但不同对使用不同颜色（从红(2)、绿(3)、橙(7)中选取）。每对像素分布在相对的两条边缘上，共享同一行（左右对）或同一列（上下对）。网格内部散布 3~4 个灰(5)色空心矩形框架（单像素厚轮廓，宽和高均至少 4，内部为黑(0)）。框架彼此不重叠，也不占据网格边缘。生成约束：至少 1 个汇合点落在某框架的内部区域中，至少 1 个汇合点落在所有框架之外，至少 1 个框架内部不含任何汇合点。每对像素到中间汇合位置的距离相等（即两像素到汇合点的曼哈顿距离相同），保证汇合点唯一。

**规则**：
1. 识别所有对向边缘像素对：同色、分布在相对边缘、共享同一行或同一列的两个像素构成一对。
2. 对每对像素，从两端同时向对方方向逐像素移动，每步各移动一个像素，留下与该像素同色的轨迹。当两条轨迹在同一像素位置相遇时，该位置为汇合点。
3. 若两像素之间的距离为奇数（中间有唯一的中心像素），汇合点恰为该中心像素；若为偶数（两条轨迹相邻但不重叠），汇合点取靠近网格中心的那个像素。汇合点颜色定为该对像素的颜色。
4. 绘制所有轨迹和汇合点后，对每个灰(5)框架检查：其内部区域（轮廓严格围住的矩形区域内的所有像素位置）中是否存在至少一个汇合点。
5. 若框架内部包含至少一个汇合点，将该框架内部所有像素填充为该汇合点的颜色。若内部包含多个汇合点（来自不同对），以包围框中心距框架中心较近的那个汇合点的颜色填充。
6. 框架内部不含汇合点的框架保持原样（内部为黑色，轨迹若从框架外经过不影响填充判定）。
7. 灰色框架轮廓保持不变。轨迹穿过框架轮廓时不覆盖灰色轮廓像素（灰色优先）。
8. 输出为与输入同尺寸的网格，包含轨迹、汇合点和条件填充后的框架。

**关键洞察**：轨迹本身是可见的装饰输出，但真正驱动填充操作的是轨迹的"终产物"——汇合点的精确坐标。填充与否取决于一个点（汇合点）是否在一个区域（框架内部）之内，这是轨迹运动学和空间包含关系的耦合。求解者必须先计算汇合点位置，再判断其与框架的几何包含关系。
