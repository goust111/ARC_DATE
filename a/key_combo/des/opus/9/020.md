## 新题 1：交叉条决定对称修复轴

**组合逻辑**：[交叉/crossing] + [对称补全/symmetry_completion](创新：对称轴由交叉检测动态决定，而非图案本身固有) + [重涂色/recolor] — 交叉检测结果作为决策节点选择对称轴，再执行修复

**来源原语**：交叉/crossing、横条/h_bar、竖条/v_bar、交叉区换前景色（来自 ba97ae07）；对称补全/symmetry_completion、二面体对称/dihedral_symmetry、可见副本恢复遮挡（来自 f4081712）；重涂色/recolor（多题共有）

**依赖链**：交叉区域的颜色 → 判定哪条条带在上层 → 在上层条带的方向上建立对称轴 → 利用该轴反射可见像素恢复被遮挡区域 → 同时交叉区域的颜色翻转为另一条带的颜色

在交叉的双条带网格中，交叉区颜色既暴露了图层顺序，又隐式编码了用于修复被遮挡图案的对称轴方向。

**输入结构**：网格约 15x15，黑(0) 背景。一条水平条带（前景色 A，如蓝(1)）跨满网格全宽，占据连续 1-2 行，行内无黑(0) 像素。一条垂直条带（前景色 B，如红(2)）跨满网格全高，占据连续 1-2 列，列内无黑(0) 像素。两条带必定交叉，交叉矩形的所有像素统一为 A 或 B 之一，指示哪条带在上层。两条带将网格划分为四个矩形区域，其中用额外颜色（如绿(3)、黄(4)）绘制装饰图案。该图案相对于"在上层"的那条带具有双侧对称性——若水平条带在上层，则图案关于该水平条带上下对称；若垂直条带在上层，则关于该垂直条带左右对称。其中一个区域内有一个灰(5) 实心矩形遮挡了部分图案。生成约束：灰色遮挡矩形完全位于一个区域内部；对称轴另一侧的对应位置全部可见（不被遮挡）；不同示例中在上层的条带可以不同。

**规则**：
1. 找到交叉矩形——即全前景行与全前景列的交集区域。交叉颜色若为 A（水平条带色），则水平条带在上层；若为 B（垂直条带色），则垂直条带在上层。
2. 以在上层的条带为对称轴。水平在上 → 对称轴为该条带所在的行带，反射方向为上下；垂直在上 → 对称轴为该条带所在的列带，反射方向为左右。
3. 对灰(5) 遮挡区域内的每个像素，计算其关于所选对称轴的镜像坐标，将镜像位置的颜色复制过来，替换灰色。生成保证镜像位置始终可见。
4. 将交叉矩形内所有像素重涂为另一条带的颜色（若原为 A 则改为 B，反之亦然）。

**关键洞察**：交叉区颜色承担双重功能——它既是图层遮挡顺序的直接表达，又间接编码了装饰图案的对称轴方向。仅凭单个示例可能误认为对称轴是固定的（如"总是水平反射"），需要对比不同条带在上层的多个示例才能归纳出真正的规则。

## 新题 2：孔洞数调谐周期印章节律

**组合逻辑**：[计数/counting](已有) + [印章覆盖/stamping](已有) + [重涂色/recolor via 周期变色](创新：周期由拓扑属性决定而非固定常数) — 拓扑属性（孔洞数）设定空间-色彩的周期参数

**来源原语**：计数/counting、封闭背景区域/enclosed_bg_region、孔洞面积决定输出（来自 8ba14f53）；印章覆盖/stamping、周期排布/periodic_layout、周期内指定位变色（来自 d304284e）；重涂色/recolor（多题共有）

**依赖链**：计算精灵体内封闭孔洞数 H → H 设定颜色循环的模周期为 H+1 → 向右周期印章精灵体副本 → 每组 H+1 个副本中最后一个变为品红(6)，其余保持原色

精灵体被周期性向右印章复制，其封闭孔洞数决定了每隔多少个副本出现一次品红变色。

**输入结构**：网格约 10x25（窄高、宽长），黑(0) 背景。一个 4-连通单色前景精灵体（3-8 像素，颜色因示例而异，如蓝(1)、红(2) 或绿(3)）位于网格最左侧。精灵体的紧包围框约 3x3 至 5x5。在其包围框内存在 H 个封闭黑(0) 像素——即不通过黑色像素 4-连通到包围框边界的黑色区域。H 因示例不同而取 1、2 或 3。网格右侧有足够空间容纳多个印章副本。生成约束：每个示例中 H >= 1；精灵体形状因示例而异但始终有封闭孔洞；网格上无其他前景元素。

**规则**：
1. 识别精灵体，计算其紧包围框（宽 W、高 T）。
2. 计算 H = 包围框内不与包围框边界通过黑像素 4-连通的黑(0) 像素数量（即封闭孔洞像素总数）。
3. 以精灵体包围框左列为起点，向右放置印章槽位 k = 0, 1, 2, ...，每个副本的左列位于 original_left + k * (W + 1)。当副本右边界超出网格宽度时停止。
4. k = 0 为原始精灵体，保持不变。k >= 1 的每个槽位印章精灵体的掩码（与原始相同形状）。
5. 颜色规则：对于副本 k，若 k mod (H + 1) == H，则该副本着色为品红(6)；否则着色为精灵体的原始前景色。k = 0 始终保持原色。
6. 超出网格右边界的副本部分被裁剪。

**关键洞察**：品红变色的周期不是固定常数——它等于孔洞数加一。H=1 时每两个副本出现一次品红（k=1,3,5,...），H=2 时每三个出现一次（k=2,5,8,...），H=3 时每四个出现一次（k=3,7,11,...）。仅从单个示例观察到周期印章，可能误认为周期是固定的；需对比不同孔洞数的示例才能发现周期与拓扑结构的关联。

## 新题 3：密度排序的透明层合成

**组合逻辑**：[计数/counting](已有) + [排序/sorting](已有) + [透明叠加/transparent_overlay](创新：合成优先级由像素密度动态决定，替代固定带序) — 逐带计数 → 密度排序 → 动态优先级合成

**来源原语**：计数/counting、排序/sorting、频率排序/frequency_ordering（来自 f8b3ba0a）；透明叠加/transparent_overlay、等高带/equal_height_band、颜色掩码层/color_mask_layer、同坐标叠加/same_position_overlay、固定优先合成/fixed_priority_compositing（来自 3d31c5b3）

**依赖链**：统计每个带的前景像素数 → 按像素数升序排列确定优先级 → 以稀疏优先的规则叠加所有带 → 每个位置输出最高优先级的非黑像素

四层等高色彩掩码按各自前景像素密度排序后叠加为一层，像素最稀疏的掩码拥有最高合成优先级。

**输入结构**：网格约 4N 行 x N 列（如 20x5 或 24x6），纵向等分为 4 个等高水平带。每个带在黑(0) 背景上有一组单色前景像素（掩码），四个带分别使用四种不同颜色（如蓝(1)、红(2)、绿(3)、黄(4)）。各带的前景像素数互不相同（无平局）。各带的掩码在局部坐标系中可能部分重叠。生成约束：四个像素计数严格不等；不同示例中同一颜色的像素数量可不同，因此优先级顺序会随示例变化；至少存在两个局部位置有多于一个带的前景像素重叠。

**规则**：
1. 将每个带视为共享同一局部坐标系的透明层（每个位置映射为带内行号、列号）。
2. 统计每个带的非黑前景像素总数，记为 C1、C2、C3、C4。
3. 按像素数从少到多排序。像素最少的带获得最高优先级（rank 1），最多的获得最低优先级（rank 4）。
4. 生成 N 行输出。对于每个局部位置，按优先级从高到低扫描各带：输出遇到的第一个非黑像素的颜色。若四个带在该位置均为黑(0)，则输出黑(0)。

**关键洞察**：合成优先级不是跨示例固定的——它随各带的前景像素密度变化而变化。单个示例可能暗示某种固定顺序（如"蓝总是在最上层"），但对比密度分布不同的多个示例后才能发现真正的排序依据是像素稀疏程度。

## 新题 4：点状射线在对角线段上刻蚀间隙

**组合逻辑**：[连线/line_drawing](已有) + [射线延伸/ray_extend](已有) + [擦除/erase](创新：擦除条件由周期射线与线段的几何交点决定) — 两种独立绘制的几何结构在空间中交互，交点处发生擦除

**来源原语**：连线/line_drawing、端点对/endpoint_pair、同色配对/same_color_pairing、对角线段连接（来自 1f876c06）；射线延伸/ray_extend、标记像素/marker_pixel、网格边界/grid_edge、间隔涂色至边界（来自 13f06aa5）；擦除/erase（来自 7b80bb43、7c66cb00）

**依赖链**：绘制同色端点对之间的对角线段 → 从边界标记发射点状射线（隔一像素着色一次）贯穿网格 → 在射线像素与对角线段像素重合的位置擦除线段像素 → 射线的周期性间隔决定了哪些交叉点被擦除、哪些幸存

同色端点对用对角线段连接后，从网格边界射出的点状灰色射线在与线段交叉处刻蚀出间隙，间隙的分布由射线的周期相位决定。

**输入结构**：网格约 15x15，黑(0) 背景。3-4 种前景色，每种恰好出现两次，构成端点对。每对的两个像素位于严格 45 度对角线上（行差绝对值等于列差绝对值）。另有 2-3 个灰(5) 单像素位于网格边界上（第 0 行、最后一行、第 0 列或最后一列）。生成约束：灰标记的位置保证至少有一条点状射线会穿越至少一条对角线段；端点对像素与灰标记不重合；不同示例中灰标记可位于不同边。

**规则**：
1. 对每种前景色，在其两个端点之间的 45 度对角线段上的所有像素着该色。保留原始端点像素。
2. 对每个灰(5) 边界标记，确定射线方向：从标记所在边界向内垂直射入（顶边标记 → 向下，底边标记 → 向上，左边标记 → 向右，右边标记 → 向左）。
3. 沿射线方向，从标记自身开始（距离 0），每隔一个像素着灰(5)：距离 0、2、4、6、... 处着色，距离 1、3、5、... 处跳过。射线延伸至离开网格为止。
4. 若某个灰色射线像素与某条已绘制的对角线段像素重合，则擦除该线段像素为黑(0)，灰色射线像素保留。
5. 若某个灰色射线像素与某个原始端点像素重合，端点像素不被擦除（端点受保护），灰色像素不绘制在该位置。

**关键洞察**：射线的"隔一着色"周期性创造了一个空间滤波器——仅与标记距离为偶数的位置才有灰色像素，才可能擦除交叉点处的线段。对角线段与射线的几何交点是否恰好落在偶数距离上，取决于标记位置与线段位置的相对关系。这种周期性过滤使得部分交叉点被擦除而另一些幸存，产生的间隙图案无法脱离两者的几何关系独立预测。

## 新题 5：分割滑移距离门控断线补全

**组合逻辑**：[分割/split + 滑动/slide + 色彩互换/color_swap](已有) + [补线/line_completion](已有) — 几何操作产生的位移量成为独立操作的阈值参数（共享参数耦合）

**来源原语**：分割/split、滑动/slide、双色物体/bicolor_object、对角邻接拼合/diagonal_adj_join、颜色互换且偏移（来自 fc4aaf52）；补线/line_completion、直线段/straight_line_segment、间隙长度限制/gap_length_constraint（来自 7b80bb43）；色彩互换/color_swap（来自 7c66cb00）

**依赖链**：双色物体沿水平中线分割 → 两半各自颜色互换 → 上半部分向右滑移至与下半部分对角邻接 → 滑移距离 D 直接作为断线补全的最大间隙阈值 → 仅间隙长度 <= D 的断线被修复

双色物体被分割、换色、滑移后重新对角拼合，其滑移距离同时充当网格中断线可修复间隙的长度上限。

**输入结构**：网格约 18x18，黑(0) 背景。上半区域有一个双色 4-连通物体，使用两种前景色（如红(2) 和绿(3)），包围框高度为偶数。下半区域有 2-4 条水平或垂直直线段，颜色为第三种前景色（如蓝(1)），每条线段内部有一段连续间隙（缺失像素）。各间隙长度不同（如 1、2、3、4 像素）。生成约束：双色物体的形状因示例而异，导致不同的滑移距离 D；至少有一条线段的间隙 <= D，至少有一条 > D；线段与双色物体不接触且不在同一行/列带中。

**规则**：
1. 识别双色物体，找到其包围框的水平中线（包围框高度的一半处）。
2. 沿中线将物体分为上半部分和下半部分。
3. 在两个半部分中互换两种前景色（所有 A 色像素变 B 色，所有 B 色像素变 A 色）。
4. 下半部分保持原位不动。上半部分向右滑移，直到上半部分的左下边界像素与下半部分的右上边界像素形成对角邻接（上一行、右一列）。记水平位移量为 D。
5. 对下半区域的每条断线段，测量其间隙长度 G（两段线段碎片之间连续缺失像素的数量）。
6. 若 G <= D，用该线段的颜色填充间隙。若 G > D，间隙保持不变。

**关键洞察**：滑移距离不是任意给定的参数——它由双色物体的几何形状决定。不同示例中物体形状不同，D 随之改变，导致不同组合的断线间隙被修复或保留。仅观察单个示例可能认为"所有间隙都被填充"或"间隙阈值是固定常数"，需对比多个示例才能发现阈值来自物体分割的滑移距离。

## 新题 6：层叠折叠涌现缺角补全

**组合逻辑**：[折叠/collapse](已有) + [补全/completion](已有) — 折叠合成使原本不存在的 L 形结构涌现，补全颜色由层来源追溯决定（涌现 + 溯源耦合）

**来源原语**：折叠/collapse、透明叠加/transparent_overlay、等高带/equal_height_band、颜色掩码层/color_mask_layer、同坐标叠加/same_position_overlay、固定优先合成/fixed_priority_compositing（来自 3d31c5b3）；补全/completion、前景对象/foreground_object、包围框内部/inside_bbox、缺角补全正方形/missing_corner_completes_square（来自 3aa6fb7a）

**依赖链**：三个等高带按固定优先级叠加折叠为一层 → 折叠结果中涌现出 L 形前景连通体 → 每个 L 形的缺角需要补全 → 补全颜色由该 L 形三个已填像素中贡献最少的那个带的颜色决定

三层色彩掩码折叠后涌现出不完整的 2x2 方块，缺角用贡献像素最少的那层颜色补全。

**输入结构**：网格约 3H 行 x W 列（如 15x5 或 12x4），纵向等分为 3 个等高水平带。每个带在黑(0) 背景上有单色前景掩码：带 1 = 红(2)，带 2 = 蓝(1)，带 3 = 绿(3)。各带的掩码图案不同。当三个带按局部坐标叠加时，某些位置有多个带的前景像素重叠。生成约束：以带 1 > 带 2 > 带 3 的优先级合成后，至少两个 4-连通前景连通体（跨颜色视为连通）恰好占据某个 2x2 区域中的三个像素，形成 L 形；每个 L 形的三个像素至少由两个不同的带贡献；不存在合成后自然形成完整 2x2 方块的情况。

**规则**：
1. 按固定优先级折叠三个带为一个 H x W 的输出层：对每个局部位置，输出最高优先级带的前景像素（带 1 > 带 2 > 带 3）。若三个带在该位置均为黑(0)，输出黑(0)。
2. 在折叠结果中，找到所有 4-连通前景连通体（判断连通时忽略颜色差异，所有非黑像素视为前景）。
3. 对于恰好占据某个 2x2 包围框内三个像素的连通体（L 形），找到缺失的第四个角像素。
4. 对每个 L 形，检查其三个已填像素各来自哪个带（红 → 带 1，蓝 → 带 2，绿 → 带 3）。统计各带的贡献次数。将缺失角填充为贡献次数最少的那个带的颜色。
5. 若出现贡献次数平局，选择优先级较低的带的颜色。
6. 非 L 形的前景连通体保持不变。

**关键洞察**：L 形结构不存在于任何单独的带中——它们仅在多层折叠后涌现。而补全颜色的确定又需要回溯每个像素的层来源，形成"折叠产生结构 → 结构需要补全 → 补全依赖折叠前的层信息"的循环依赖。任何一步都无法脱离其他步骤独立完成。

## 新题 7：交叉反转压缩图

**组合逻辑**：[压缩/compress](已有) + [重涂色/recolor via 反转](创新：输出不是交叉区可见色而是被遮挡色) + [填充/fill](已有) — 结构检测 → 压缩 → 反转输出

**来源原语**：压缩/compress（来自 7e4d4f7c）；重涂色/recolor（多题共有）；填充/fill（来自 54d9e175）；横条/h_bar、竖条/v_bar、交叉/crossing、交叉区换前景色（来自 ba97ae07）

**依赖链**：识别多条水平条带和多条垂直条带 → 在每个交叉区域判定哪条带的颜色被可见（即哪条带在上层）→ 将整个网格压缩为一个小矩阵（每行对应一条水平带，每列对应一条垂直带）→ 每个压缩格填充该交叉处不可见（被遮挡）的那条带的颜色

多条不同色水平带和垂直带交叉形成的网格被压缩为小矩阵，每格显示对应交叉处被遮挡的那条带颜色而非可见色。

**输入结构**：网格约 15x15，黑(0) 背景。3-4 条水平条带，每条占据连续 1-2 行，各使用不同前景色（如红(2)、绿(3)、黄(4)），跨满网格全宽。3-4 条垂直条带，每条占据连续 1-2 列，各使用不同前景色（如蓝(1)、品红(6)、橙(7)），跨满网格全高。每对水平-垂直条带都会交叉，交叉矩形内的像素统一为两条带颜色之一，指示哪条带在上层。不同交叉处，在上层的条带可以不同。生成约束：水平带颜色集合与垂直带颜色集合互不重叠；每个交叉的遮挡关系是独立确定的（不存在全局固定的"水平总在上"或"垂直总在上"规则）。

**规则**：
1. 识别所有水平条带（全前景行的连续行组）和所有垂直条带（全前景列的连续列组）。
2. 对每对水平-垂直条带的交叉矩形，读取其统一颜色。该颜色属于哪条带（水平或垂直），那条带即为上层。
3. 构建压缩矩阵：行数 = 水平条带数，列数 = 垂直条带数。水平条带从上到下编号，垂直条带从左到右编号。
4. 压缩矩阵中第 i 行第 j 列的颜色 = 第 i 条水平带与第 j 条垂直带交叉处**被遮挡**的那条带的颜色（即不是交叉区可见色，而是另一条带的颜色）。
5. 输出即为该压缩矩阵。

**关键洞察**：输出执行了双重变换——既压缩了空间结构（多行多列的网格变为小矩阵），又反转了信息（从可见色变为被遮挡色）。仅做压缩不做反转，或仅做反转不做压缩，都无法得到正确输出。单个示例中可能误认为输出就是交叉区的可见色，需对比多个示例（特别是同一交叉处遮挡关系不同的情况）才能发现反转规则。

## 新题 8：镜像扩展中的定向印章

**组合逻辑**：[镜像/mirror + 拼接/assembly](已有) + [印章覆盖/stamping](已有) — 标记位置随镜像复制到四个象限，但印章内容不随镜像翻转（对称性中的不对称）

**来源原语**：镜像/mirror、拼接/assembly、画布/canvas、象限/quadrant、四象限排布/four_quadrant_layout、翻转形成对称铺展（来自 62c24649、833dafe3）；印章覆盖/stamping、精灵体/sprite、模板掩码/template_mask（来自 d304284e、5a5a2103）

**依赖链**：镜像扩展将整个网格（含精灵体和标记像素）复制到四个象限 → 标记像素的位置随镜像出现在四处 → 在每个标记位置处印章精灵体 → 但印章始终保持原始方向（不随象限的翻转方向变化）→ 叠加处印章覆盖镜像图案

小网格被镜像扩展为四象限对称图案，其中的标记像素也被复制到四处，但在每个标记位置印章的精灵体始终保持原始方向而不随象限翻转。

**输入结构**：网格约 5x6 至 7x7（小尺寸），黑(0) 背景。包含一个小型前景精灵体（3-6 像素，单色，如绿(3)），形状不对称（不具备水平或垂直对称性，确保翻转后外观可区分）。另有 1-2 个标记像素，颜色与精灵体不同（如红(2)），位于网格中非精灵体占据的位置。生成约束：精灵体形状在不同示例中不同但始终不对称；标记像素与精灵体不相邻（至少间隔 1 个像素）；精灵体的包围框足够小，使得在标记位置印章时不会超出扩展后网格的边界。

**规则**：
1. 将原始网格镜像扩展为 2x2 四象限图案：左上 = 原始；右上 = 左右镜像；左下 = 上下镜像；右下 = 左右 + 上下镜像。扩展后网格尺寸为原始的两倍（2H x 2W）。
2. 在扩展后的网格中，原始的标记像素出现在四个对称位置（每个象限一个）。
3. 在每个标记位置，以标记像素为锚点（精灵体包围框左上角对齐到标记位置），印章精灵体的掩码。印章始终使用精灵体的**原始方向**（不随所在象限的翻转方向做镜像变换）。印章颜色使用标记像素的颜色（如红(2)）。
4. 印章覆盖该位置已有的任何像素（包括镜像产生的图案）。
5. 四个标记位置的印章均独立执行，若多个印章重叠，后处理的覆盖先处理的（处理顺序：左上 → 右上 → 左下 → 右下）。

**关键洞察**：镜像操作使整个网格（包括背景图案和标记位置）都产生了对称翻转，但印章操作打破了这种对称——四个象限的印章内容完全一致、方向相同，而非随象限翻转。求解者必须注意到背景图案是对称的而印章不是。若精灵体本身碰巧对称，单个示例无法暴露方向规则，需对比使用不对称精灵体的示例才能确认印章不跟随翻转。
