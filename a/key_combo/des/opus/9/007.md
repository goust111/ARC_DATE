## 新题 1：反射平铺的轴型色置换

**组合逻辑**：[平铺/tiling + 镜像/reflect](已有) + [固定颜色置换映射/fixed_color_permutation](已有) → [反射类型决定置换对](创新耦合)

**来源原语**：平铺/tiling、镜像/reflect、交替翻转平铺/alternating_reflections_tiling（参考题 8d5021e8）；重涂色/recolor、固定颜色置换映射/fixed_color_permutation（参考题 0d3d703e）；接触边界定轴/touching_border_determines_axis（参考题 6f473927）

**依赖链**：精灵体所在象限决定原图位置，水平反射和垂直反射各自绑定一组独立的颜色对换——水平反射触发对换 A，垂直反射触发对换 B，对角象限（同时经历两种反射）则先后施加 A 和 B。反射类型与颜色置换不可分离：不知反射类型就无法确定颜色映射，不知颜色映射则反射后的色彩错误。

将一个多色精灵体按 2x2 镜像平铺至四倍画布，每种反射轴独立触发一组颜色对换，使四个象限呈现四种不同的配色方案。

**输入结构**：
- 网格大小 2H x 2W（如原精灵体 5x7 则网格 10x14），约 10~16 行列。
- 背景：黑(0)。
- 一个多色精灵体（4-连通，8~20 像素，使用 3 种非黑颜色，如蓝(1)、绿(3)、黄(4)）占据网格的某一个象限，其边界框包含该象限的角像素。
- 其余三个象限全部为黑(0)。
- 生成约束：精灵体至少使用 3 种非黑色以保证两组对换均可见；不同示例中精灵体可在不同象限角落，但形状各异（4-连通，非矩形，含不规则轮廓）。

**规则**：
1. 识别精灵体所在象限 Q1（非黑像素所在区域）。以 Q1 为原图。
2. 水平翻转 Q1 得到 Q2（与 Q1 共享一条垂直边）。对 Q2 中每个像素执行颜色对换 A：绿(3) <-> 黄(4)，其余颜色不变。
3. 垂直翻转 Q1 得到 Q3（与 Q1 共享一条水平边）。对 Q3 中每个像素执行颜色对换 B：蓝(1) <-> 灰(5)，其余颜色不变。
4. 对 Q1 同时做水平和垂直翻转得到 Q4（对角象限）。对 Q4 中每个像素依次执行对换 A 再执行对换 B（即绿(3) <-> 黄(4) 且蓝(1) <-> 灰(5)）。
5. Q1 保留原色不变。
6. 将四个象限组装为 2x2 输出网格。Q1 在其原始角落位置，其余三象限按反射关系排列。

**关键洞察**：颜色对换对 A 和 B 各自绑定到哪种反射轴上，不会在题面中标注——求解者必须对比原象限与各反射副本中的对应像素颜色，才能发现水平反射和垂直反射各自独立控制一组颜色交换。单个示例可能无法排除其他映射假设，需要对比多个示例（不同精灵体、不同初始象限）才能确认。

## 新题 2：环路弯折分类重塑迷宫拓扑

**组合逻辑**：[环路追踪/trace_cycle + 分类涂色/classify_and_color](已有) → [弯折分类改变墙体拓扑](创新) → [寻路/pathfinding](已有)

**来源原语**：环路追踪/trace_cycle、分类涂色/classify_and_color、闭合正交环路/closed_orthogonal_loop、弯折像素/bend_pixel、直行像素/straight_pixel、多数转向为凸/majority_turn_is_convex、少数转向为凹/minority_turn_is_concave（参考题 15663ba9）；寻路/pathfinding、重涂色/recolor、端点像素/endpoint_pixel、障碍像素/blocker_pixel、最短路径/shortest_path、四邻接连通/four_neighbor_connect、最短路径唯一/unique_shortest_path（参考题 b15fca0b）

**依赖链**：环路追踪确定每个弯折像素是凸还是凹 → 凸弯折被擦除（变为可通行背景），凹弯折和直行像素保留为墙体 → 擦除凸弯折在环路上打开通道 → 寻路利用这些通道穿越环路。不追踪环路就无法辨别凸凹，不擦除凸弯就没有通道，不寻路则分类本身无意义。三步紧密串联且信息逐级转化。

追踪闭合环路的弯折方向，擦除凸弯折以打开环路上的通道，然后在改造后的迷宫中寻找两端点间的最短路径。

**输入结构**：
- 网格大小约 15x15。
- 背景：黑(0)。
- 一个由绿(3)像素构成的闭合正交环路（一像素宽，4-连通，每个前景像素恰好有 2 个前景邻居）。环路将网格分为内部区域和外部区域。
- 蓝(1)障碍像素散布在环路外部或内部（但不与环路相邻），充当额外墙体。
- 恰好两个红(2)端点像素，一个位于环路内部，一个位于环路外部。
- 生成约束：环路必须同时包含凸弯折和凹弯折；擦除全部凸弯折后恰好在环路上产生足够的缺口使内外连通；经过这些缺口且绕过蓝(1)障碍的最短路径唯一；环路至少 20 像素以保证凸凹弯折数量足够区分多数与少数。

**规则**：
1. 追踪闭合正交环路：沿 4-连通前景像素行走，记录每个像素处的转向方向。
2. 统计环路中全部弯折像素的转向方向。多数方向对应凸弯折，少数方向对应凹弯折。直行像素（无转向）保持不变。
3. 将所有凸弯折像素擦除为黑(0)背景。凹弯折像素保留绿(3)。直行像素保留绿(3)。
4. 当前网格中，绿(3)像素和蓝(1)像素均视为不可通行的墙体。黑(0)像素为可通行空间。红(2)端点像素为可通行的起终点。
5. 寻找从一个红(2)端点到另一个红(2)端点的唯一最短 4-邻接路径（仅穿过可通行像素）。
6. 将路径上除两个红(2)端点外的所有像素涂为黄(4)。
7. 其余所有像素保持不变。

**关键洞察**：环路的凸弯折在结构上保证为多数类型（简单直角多边形的凸角恰好比凹角多 4 个），因此擦除凸弯折总是比擦除凹弯折移除更多像素、打开更大的缺口。求解者必须理解弯折分类不是装饰性着色而是一个改变迷宫连通性的结构操作——凸弯折的消失才使内外区域连通，从而使寻路成为可能。

## 新题 3：异或相似度驱动精灵体重排

**组合逻辑**：[异或叠加/xor_overlay](已有，创新用法：作为度量而非输出) + [排序/sorting + 堆叠/stacking](已有，创新用法：排序键来自异或面积)

**来源原语**：异或叠加/xor_overlay、分隔行/separator_row、前景掩码/foreground_mask、对齐/alignment、前景不一致处涂色/disagreement_cells_painted（参考题 99b1bc43）；排序/sorting、翻转顺序/reverse_order、堆叠/stacking、精灵体/sprite、顺序反转/order_reversed（参考题 e21a174a）

**依赖链**：异或计算出每个精灵体与参考掩码的"不一致面积" → 不一致面积作为排序键 → 排序结果决定垂直堆叠顺序。异或不是最终输出（区别于源题 99b1bc43 中异或即结果），而是一个测量工具；排序不基于几何长度（区别于源题 3ee1011a），而是基于异或面积。两个操作通过"面积即排序键"这一新结构关系耦合。

计算每个精灵体与底部参考掩码的异或面积，按相似度从高到低重新垂直堆叠所有精灵体。

**输入结构**：
- 网格大小约 (4H+1) 行 x W 列（H 为单个精灵体的高度，如 H=4 则约 17 行），约 15~20 行。
- 一条单行水平分隔行使用唯一颜色灰(5)，将网格分为上面板和下面板。
- **下面板**（H 行 x W 列）：一个栗(9)色前景形状（参考掩码）在黑(0)背景上，占据 H x W 边界框。4-连通，5~15 像素，非矩形不规则形状。
- **上面板**（3H 行 x W 列，由 3 个高度为 H 的区段垂直堆叠构成）：3 个精灵体，每个占据一个 H x W 区段。每个精灵体使用不同的单色（如蓝(1)、绿(3)、红(2)），在黑(0)背景上各自为 4-连通的不规则形状（5~15 像素）。
- 生成约束：所有精灵体和参考掩码共享相同的 H x W 边界框尺寸。每个精灵体与参考掩码的异或面积（对位单元中恰好一方为前景的单元数）互不相同，保证排序无歧义。上面板中精灵体的初始垂直顺序任意。

**规则**：
1. 识别分隔行：找到颜色仅出现在一整行中的那一行，即灰(5)分隔行。
2. 提取参考掩码：裁剪下面板中的栗(9)前景至其 H x W 边界框。
3. 提取精灵体：上面板包含 3 个垂直堆叠的精灵体，每个占据 H 行高的区段。按区段从上到下提取，各自裁剪至 H x W 边界框。
4. 对每个精灵体计算异或面积：将该精灵体与参考掩码逐单元对比，统计恰好一方为前景（非黑）的单元数。
5. 按异或面积升序排列精灵体（异或面积最小 = 与参考掩码最相似 = 排在最上方）。
6. 输出：将排好序的精灵体从上到下垂直堆叠，每个保持其原始颜色和形状。输出不含分隔行，不含参考掩码。输出高度为 3H，宽度为 W。

**关键洞察**：下面板中的参考掩码不是输出的组成部分，也不是装饰——它是一把"相似度标尺"。异或操作在源题中是最终输出（涂绿色），在此处被重新定位为一个测量手段：它产生一个数值（面积），而这个数值驱动了排序，排序又决定了空间布局。求解者必须识别出参考掩码的功能角色——定义"相似"的基准——而非将其视为需要变换的对象。

## 新题 4：修复线段网络构建滑动边界

**组合逻辑**：[间隙填充/gap_fill + 修复/repair](已有) → [修复后线段成为墙体](创新耦合) → [滑动/slide + 对接/dock](已有，创新触发条件)

**来源原语**：修复/repair、间隙填充/gap_fill、线段网络/line_network、标记像素/marker_pixel、端点朝向/endpoint_facing、标记归属最近线/marker_assigned_to_nearest_line（参考题 faa9f03d）；对接/dock、滑动/slide（推广自参考题 8b9c3697）；可移动组件/movable_component、射线方向推断/ray_inferred_direction、轨迹涂黑/trail_painted_black（参考题 8b9c3697）

**依赖链**：红色标记像素填充线段间隙 → 修复后的线段形成完整墙体 → 可移动对象沿射线方向滑行直到撞上修复后的墙体 → 对象留下黑色轨迹。如果不修复间隙，对象会穿过断裂处滑到错误位置；如果不滑动，修复本身无法产生最终输出。修复步骤通过改变墙体拓扑实质性影响滑动终点。

用红色标记像素修补断裂的线段网络，修补后的完整线段成为墙壁，可移动对象沿射线方向滑向最近的墙壁并留下黑色轨迹。

**输入结构**：
- 网格大小约 15x15。
- 背景：黑(0)。
- 2~3 条一像素宽的水平或垂直线段碎片，使用不同颜色（如蓝(1)、绿(3)），每条线段有 1~2 个单像素宽的间隙（间隙处为黑(0)背景）。
- 红(2)单体标记像素：每个间隙中恰好有一个红(2)像素，位于间隙的某个单元格内（与两侧断端同行或同列）。
- 2~3 个小型单色可移动对象（4-连通，3~6 像素，使用黄(4)、橙(7)等与线段颜色不同的颜色），分布在线段附近，与某条线段在同一行或同一列上对齐。
- 生成约束：每个红(2)标记在同行或同列的视线范围内恰好有一个线段端点。每个可移动对象在修复后恰好面对一条完整线段（在对象的某个正交方向上，射线首先遇到的非背景像素属于某条修复后的线段）。不同对象的滑动路径互不交叉。对象与目标线段之间没有其他非背景像素阻挡（修复后的间隙像素除外）。

**规则**：
1. 识别线段颜色：非背景、非红色的颜色，其 4-连通分量为一像素宽的水平或垂直线段碎片。
2. 识别标记像素：红(2)的孤立单体像素（4-邻域内无其他红色像素）。
3. 对每个红(2)标记，沿其所在行和列做视线搜索，找到最近的线段断端（线段颜色的端点像素）。将该红(2)标记替换为该线段的颜色，完成间隙填充。若间隙跨多个单元格，则沿行/列从标记向两侧断端方向依次填充该线段颜色，直至两侧断端相连。
4. 间隙修复完成后，线段网络中所有线段均为连续无断裂的直线。
5. 对每个可移动对象，从其各像素向上、下、左、右四个方向做射线投射。选择首先命中修复后线段的方向作为滑动方向。
6. 将对象沿该方向整体平移，直到对象的某个像素与目标线段正交相邻（间距为 1）时停止。
7. 对象离开的原始位置上的所有像素涂为黑(0)（轨迹涂黑）。如果对象的某些像素在滑动前后位置重叠，重叠部分保留对象颜色。
8. 修复后的线段像素保持不变。

**关键洞察**：红色标记看起来像是散落的噪声点，但它们是连接断裂墙壁的关键——如果不修复间隙，对象会滑过断裂处到达网格边缘或错误位置。修复步骤和滑动步骤通过墙体拓扑产生顺序依赖：修复改变了"墙在哪里"，墙的位置决定了"对象停在哪里"。

## 新题 5：遮挡层序编码周期色彩表的循环序列

**组合逻辑**：[补全/reconstruct + 遮挡层序/occlusion_order](已有，创新用途：层序 = 色彩循环顺序) + [周期推断/periodic_inference + 间隙填充/gap_fill](已有，创新用途：循环顺序来自外部编码)

**来源原语**：补全/reconstruct、遮挡层序/occlusion_order、遮挡碎片/occluded_fragment、可见像素定边框/visible_defines_bbox、忽略干扰项/ignore_distractors（参考题 652646ff）；周期推断/periodic_inference、间隙填充/gap_fill、表格/table、空白单元格/blank_cell、对角线相位偏移/diagonal_phase_shift、按列周期取色/column_modular_phase（参考题 1e97544e）

**依赖链**：左侧区域的重叠菱形片段 → 根据遮挡关系推断从上到下的层序 → 层序定义颜色循环的排列顺序（最上层颜色 = 循环位置 0） → 右侧区域的周期表使用该循环 + 对角相位偏移填充空白格。两个子问题单独均不可解：表格中的空白太多使得仅凭可见格无法唯一确定循环顺序；菱形的遮挡排名本身只是一个列表，没有应用场景。

从重叠的彩色菱形碎片推断遮挡层序，将层序作为色彩循环的顺序，填充右侧周期表中的空白单元格。

**输入结构**：
- 网格大小约 15x20。
- 背景：黑(0)。
- **左侧区域**（约 15 行 x 8 列）：3~4 个菱形（旋转 45 度的正方形轮廓，每个约 4x4 边界框，8~12 像素，共享同一几何模板，仅做平移）部分重叠。每个菱形使用不同单色（如蓝(1)、绿(3)、红(2)、黄(4)）。重叠区域只显示上层菱形的颜色，下层像素被遮挡。另有少量孤立单体像素（与任何菱形模板平移副本不吻合）为噪声，应忽略。
- **右侧区域**（约 15 行 x 12 列）：一个 S x S 方形子网格充当周期表（S 约 8~12）。部分单元格填有与菱形相同的颜色（蓝(1)、绿(3)、红(2)、黄(4)），遵循带对角相位偏移的周期模式；其余单元格为灰(5)表示空白。
- 两个区域之间无显式分隔线，但互不重叠。
- 生成约束：菱形间的遮挡关系构成全序（无环、无并列）。周期表中至少 40% 的单元格为空白。仅凭可见（非灰）单元格能验证循环但无法唯一确定循环顺序（至少存在两种循环排列与可见格兼容），必须依赖遮挡层序来消歧。

**规则**：
1. **识别菱形**：在左侧区域，找出所有非背景、非噪声颜色。菱形模板是某个固定形状（旋转正方形轮廓），各颜色的像素必须完全落在该模板的某个平移副本上。不符合任何平移副本的孤立像素为噪声，忽略。
2. **推断遮挡层序**：对每个菱形颜色 C，检查其模板副本中缺失的像素位置——该位置当前被另一颜色 D 占据，说明 D 在 C 之上。收集所有这样的"D 在 C 之上"关系，拓扑排序得到从上到下的全序。
3. **读取色彩循环**：将遮挡全序从上到下映射为循环位置：最上层颜色 = 位置 0，第二层 = 位置 1，依此类推。设共 N 个菱形颜色，循环周期为 N。
4. **填充周期表**：在右侧区域的 S x S 方形子网格中（以子网格左上角为原点，行索引 r、列索引 c 从 0 开始）：若 r <= c（在主对角线上方或上），该单元格的颜色 = cycle[c mod N]；若 r > c（在主对角线下方），该单元格的颜色 = cycle[(c+1) mod N]。
5. 仅将灰(5)空白单元格替换为上述规则计算出的颜色。已有颜色的单元格和左侧区域的所有像素保持不变。

**关键洞察**：左侧的重叠菱形不是装饰或独立子题——它们的遮挡关系是右侧表格唯一的"图例"。表格中的可见格故意设计得太稀疏，使得多种循环排列均兼容，只有菱形的层序能消除歧义。求解者必须跨越网格的两个视觉区域建立联系：一侧编码顺序，另一侧使用顺序。

## 新题 6：锯齿平铺构建腔室后标记投票填色

**组合逻辑**：[平铺/tiling + 旋转/rotate](已有) → [平铺产生封闭腔室](创新涌现) → [填充/fill + 邻接多数决/adjacent_majority_vote](已有，创新作用对象：腔室由平铺动态生成)

**来源原语**：平铺/tiling、旋转/rotate、矩形条/rect_bar、对角锯齿排布/diag_zigzag、交替旋转换色/alt_rotate_recolor（参考题 fd4b2b02）；填充/fill、连通腔室/connected_chamber、标记像素/marker_pixel、正交邻接/orthogonal_adjacency、邻接多数决/adjacent_majority_vote（参考题 7c8af763）

**依赖链**：单个矩形条通过锯齿平铺 + 交替旋转展开为覆盖整个画布的条纹网络 → 条纹之间自然形成封闭的背景腔室 → 标记像素对邻接腔室投票 → 每个腔室按邻接标记的多数色填充。不平铺就没有腔室边界，不投票填充则腔室为空。关键涌现效应：平铺操作本身不涉及腔室概念，但其结果在空间上围出了封闭区域，使得填充操作有了作用对象——这种"容器"是平铺的副产物而非设计目标。

将一个矩形条沿对角锯齿路径平铺并交替旋转 90 度，铺出的条纹围出若干封闭腔室，然后根据每个腔室邻接的标记像素的多数颜色填充该腔室。

**输入结构**：
- 网格大小约 18x18（需足够大以容纳至少 2~3 个完整腔室）。
- 背景：黑(0)。
- 一个实心非正方形矩形条（如 2x5），使用绿(3)或品红(6)中的一种颜色，位于网格中某处。该矩形条是锯齿平铺的种子。
- 若干标记像素（单体像素，4-邻域内无同色像素），使用 2~3 种颜色（如红(2)、蓝(1)、黄(4)），散布在网格的背景区域中。每个标记像素不与种子矩形条重叠。
- 生成约束：矩形条的高度和宽度均 >= 2 且互不相等。标记像素的位置保证平铺完成后每个标记恰好落在某个封闭腔室内部或其正交边界上（不被平铺条纹覆盖）。每个腔室至少有 1 个邻接标记。每个腔室的邻接标记中存在唯一多数色（无平票）。

**规则**：
1. 以输入中的矩形条为种子，确定其高度 h 和宽度 w（h != w）。
2. 沿两条 45 度对角线方向扩展平铺：在同一对角线上，每隔 (h+w) 个像素的行偏移和列偏移放置一个与种子相同朝向和颜色的矩形条副本。
3. 在每两个相邻的同对角线副本之间，放置一个旋转 90 度的矩形条（宽 h 高 w），使用配对颜色（若种子为绿(3)则配对色为品红(6)，反之亦然）。旋转副本的位置使得它恰好填入两个原始副本之间的锯齿拐角。
4. 平铺扩展至覆盖整个画布边界，超出边界的部分裁剪。
5. 平铺完成后，网格中的黑(0)背景像素被条纹网络分隔为若干 4-连通腔室。
6. 对每个腔室，收集所有与该腔室正交相邻（上下左右）的标记像素（标记像素本身不在腔室内部，而是在腔室边界外侧或恰好在腔室与条纹的接触面上——若标记落在腔室内部，则视为属于该腔室并同样参与投票）。
7. 统计每个腔室邻接标记中各颜色的出现次数，选取唯一多数色。
8. 将该腔室的所有背景像素填充为该多数色。标记像素本身保留原色不变。
9. 没有邻接标记的腔室（若存在）保持黑(0)不变。所有平铺条纹像素保持不变。

**关键洞察**：矩形条的锯齿平铺是一个几何扩展操作，其直接产物是条纹图案，但其副作用是在条纹之间围出了封闭腔室——这些腔室不是显式定义的对象，而是平铺的拓扑涌现。求解者必须先识别出平铺规则（种子尺寸决定步长和旋转），然后才能确定腔室边界在哪里，最后才能正确应用多数投票填色。条纹的尺寸直接控制腔室的大小和数量，使得平铺参数和填充结果紧密耦合。
