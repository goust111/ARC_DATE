## 新题 1：标记计数选矩形 — 十字线环形填充

**组合逻辑**：[计数](counting) + [标记最多者选取](rectangle_with_most_markers_selected) → [连线/画布全长十字线](draw_line, canvas_spanning_cross) → [填充/偶数切比雪夫距离](fill, even_chebyshev_distance) → [原对象遮挡叠加](object_occludes_overlay)。计数与连线来自不同源题，这里计数结果决定十字线的唯一中心点，是源题中不存在的因果关系。

**来源原语**：计数(counting) ← 8efcae92；标记最多者选取(rectangle_with_most_markers_selected) ← 8efcae92；连线/画布全长十字线(draw_line, canvas_spanning_cross) ← 41e4d17e；偶数切比雪夫距离(even_chebyshev_distance) ← 759f3fd3；填充(fill) ← 759f3fd3；原对象遮挡叠加(object_occludes_overlay) ← 41e4d17e；空心矩形(hollow_rectangle) ← 41e4d17e；标记像素(marker_pixel) ← 8efcae92；中心对齐(center_alignment) ← 41e4d17e；交叉点中心(intersection_center) ← 759f3fd3

**依赖链**：标记计数从多个矩形中选出唯一目标 → 目标中心确定十字线位置 → 十字线交叉点成为切比雪夫距离原点 → 距离奇偶性决定哪些背景像素被填充 → 所有矩形轮廓层叠在填充和十字线之上。去掉计数步骤则中心点无法确定；去掉十字线则距离原点缺失；去掉遮挡规则则矩形被环形覆盖。

在所有蓝色空心矩形中，找到包含最多红色标记的那个，以其中心画出全幅十字线，再以该交叉点为圆心画出切比雪夫距离偶数环，最后将所有矩形轮廓绘制在最顶层。

**输入结构**：约 15x15 的网格。背景为青(8)。网格上散布 3~5 个蓝(1)空心矩形（单像素宽边框、内部为青(8)背景，尺寸在 3x3 到 6x6 之间，互不重叠且互不相邻）。部分矩形的内部含有若干红(2)标记像素（每个矩形内 0~4 个，分布不均）。生成约束：恰好有一个矩形的红色标记数严格最多（无平局）。

**规则**：
1. 对每个蓝(1)空心矩形，计数其内部（不含矩形边框本身）所含红(2)标记像素的数量。
2. 选出红色标记数最多的唯一矩形，将其边界框中心（向下取整）作为十字线中心 (cr, cc)。
3. 以中心 (cr, cc) 画一条贯穿整个网格的粉(6)水平线（占满该行所有列）和一条贯穿整个网格的粉(6)垂直线（占满该列所有行）。
4. 对每个非十字线、非蓝色矩形边框的像素 (r, c)，计算其到中心的切比雪夫距离 d = max(|r - cr|, |c - cc|)。若 d 为正偶数且该像素当前为青(8)背景，则将其重涂为黄(4)。
5. 将所有蓝(1)矩形轮廓像素和红(2)标记像素重新绘制在最顶层（覆盖下方的黄色填充和粉色十字线）。

**关键洞察**：环形填充的中心并非预先给定的几何特征，而是由分散在多个矩形内部的标记像素计数竞争产生的；必须先完成跨矩形的统计比较，才能确定几何变换的参数。

## 新题 2：前景十字定距 — 贪心方块距离分色

**组合逻辑**：[十字前景/交叉点中心](foreground_cross, intersection_center) → [贪心选择/从大到小优先/非重叠约束](greedy_selection, largest_first_priority, non_overlapping_constraint) + 距离排名分色（创新：将切比雪夫距离从环形填充重新用作方块排序和着色依据）。十字交叉点在源题中仅作为环形填充的圆心，这里被重新用作贪心排序的距离参考点，产生新的结构关系。

**来源原语**：十字前景(foreground_cross) ← 759f3fd3；交叉点中心(intersection_center) ← 759f3fd3；空白正方形区域(blank_square_region) ← 31adaf00；障碍像素(obstacle_pixel) ← 31adaf00；贪心选择(greedy_selection) ← 31adaf00；从大到小优先(largest_first_priority) ← 31adaf00；非重叠约束(non_overlapping_constraint) ← 31adaf00；最小边长约束(minimum_side_length_constraint) ← 31adaf00；填充(fill) ← 759f3fd3

**依赖链**：十字前景的交叉点提供全局距离参考 → 贪心选择按边长从大到小处理方块 → 同边长方块间按距离从近到远排序 → 处理顺序编号决定填充颜色 → 非重叠约束过滤冲突方块。去掉十字交叉点则排序和颜色均无依据；去掉贪心选择则方块可重叠；去掉距离排名则同尺寸方块的颜色分配无法确定。

在被障碍像素隔开的黑色区域中，找到所有极大全黑正方形口袋，以前景十字交叉点为距离参考，按边长降序、同边长按距离升序的综合排名为每个不重叠的方块分配循环色。

**输入结构**：约 16x16 的网格。背景为黑(0)。一行绿(3)像素贯穿整个网格的某一行，一列绿(3)像素贯穿整个网格的某一列，两者交叉形成一个十字前景（交叉点位于非边缘位置）。其余区域散布若干灰(5)障碍像素（单像素或短线段，总数 10~20 个），将黑色背景分割成大小不等的连通区域。生成约束：至少存在 4 个边长 >= 2 的极大全黑正方形口袋（仅由黑(0)像素构成，不含绿色十字线像素和灰色障碍像素），且不存在边长相同且到交叉点切比雪夫距离也相同的两个方块。

**规则**：
1. 找出绿(3)十字前景的交叉点坐标 (cr, cc)。
2. 枚举所有由纯黑(0)像素组成的极大全黑正方形区域（边长 >= 2），将绿(3)十字线像素和灰(5)障碍像素均视为阻挡。
3. 将所有候选方块按主键"边长降序"、次键"方块中心到 (cr, cc) 的切比雪夫距离升序"排列。
4. 按此排列顺序依次处理：若当前方块与任何已选方块不重叠，则选中它并赋予颜色。第 1 个选中的方块填充蓝(1)，第 2 个填充红(2)，第 3 个填充黄(4)，第 4 个填充橙(7)，第 5 个回到蓝(1)，以此四色循环。
5. 绿(3)十字线和灰(5)障碍像素保持不变。

**关键洞察**：贪心选择中同一尺寸层级的方块之间，其处理先后（进而颜色分配）不是由方块自身属性决定的，而是由方块到一个外部参考点——十字交叉点——的距离决定的；移除十字前景会导致同尺寸方块的颜色分配退化为不可解。

## 新题 3：面板标记双义 — 选取与旋转编码

**组合逻辑**：[等分网格/面板](equal_partition, panel) + [计数/标记包含于对象](counting, marker_in_object) → 面板选取 → [旋转](rotate)（创新：标记像素的空间位置编码旋转角度，同一个标记同时承担"选取判据"和"变换参数"双重角色，这是源题中不存在的双义结构） → [裁剪](crop)

**来源原语**：等分网格(equal_partition) ← c3202e5a；面板(panel) ← 337b420f；计数(counting) ← 8efcae92/a934301b；标记像素(marker_pixel) ← 8efcae92；标记包含于对象(marker_in_object) ← a934301b；连通分量(connected_component) ← 337b420f/a934301b；按面积筛选(size_filtered) ← 337b420f；保留最大分量(keep_largest) ← 337b420f；旋转(rotate) ← a416fc5b；裁剪(crop) ← 8efcae92；旋转关系(rotation_relation) ← a416fc5b

**依赖链**：网格分区隔离各面板 → 每个面板内对标记像素计数 → "恰好一个标记"的面板被选中 → 该面板内标记相对精灵体中心的方位编码旋转角 → 提取精灵体并旋转后输出。标记在此承担双义：其数量决定选取，其位置决定旋转。去掉任一角色，题目均不可解。

从被分隔线划分的四个面板中，选出恰含一个红色标记的面板，根据标记在精灵体中心哪一侧来确定旋转角度，输出旋转后的精灵体裁剪图。

**输入结构**：约 15x15 的网格，被一条水平灰(5)分隔线和一条垂直灰(5)分隔线分成四个大小相等的矩形面板（2x2 排列）。每个面板内部背景为黑(0)，包含一个单色前景精灵体（4-连通、3~6 像素的不规则形状，颜色为蓝(1)、绿(3)、黄(4)或橙(7)中的一种，四个面板颜色各不相同）。每个面板内还散布 0~3 个红(2)标记像素（与精灵体不相邻、不重叠）。生成约束：恰好有一个面板含有 1 个红色标记，其余面板含有 0 个或 2~3 个。该唯一标记与其所在面板精灵体的边界框中心不在同一行也不在同一列（即方位关系非模糊）。

**规则**：
1. 沿灰(5)分隔线将网格切分为四个面板。
2. 在每个面板中，计数红(2)标记像素的数量。选出恰好包含 1 个红色标记的唯一面板。
3. 在该面板中，找到最大的 4-连通非红、非黑前景连通分量作为精灵体。计算精灵体边界框的中心 (sr, sc)（向下取整）。
4. 确定红色标记 (mr, mc) 相对于精灵体中心的主方位：若 |mr - sr| >= |mc - sc|，则按垂直方向判断（mr < sr 为"上"，mr > sr 为"下"）；否则按水平方向判断（mc < sc 为"左"，mc > sc 为"右"）。
5. 方位到旋转角度的映射：上 → 0°（不旋转）；右 → 顺时针 90°；下 → 180°；左 → 顺时针 270°。
6. 提取精灵体（仅其像素，不含标记和背景），按上述角度顺时针旋转，输出旋转后精灵体的紧凑边界框裁剪（背景为黑(0)）。

**关键洞察**：红色标记在题目中扮演双重角色——它的数量是面板筛选的判据（恰好一个），它的空间位置是旋转角度的编码器（上/右/下/左 → 0°/90°/180°/270°）；仅看单个示例时，无法区分标记的"选取"功能和"方位编码"功能，必须对比多个示例才能同时归纳这两条规则。

## 新题 4：栅格印章奇偶镜像与重叠变色

**组合逻辑**：[栅格偏移](lattice_offset) → [印章放置/平移](stamp, translate) + [列周期](column_periodicity)（创新：周期性不再触发重涂色，而是触发镜像翻转，使得同一模板在不同栅格列产生不同的像素覆盖图案） → [镜像](mirror) → [重叠区域重涂](overlap_recolor)。列奇偶性在源题中控制重涂色，这里控制镜像，进而改变重叠图案，最终影响重涂色——形成"奇偶 → 镜像 → 重叠 → 重涂色"的四步因果链。

**来源原语**：印章放置(stamp) ← a395ee82；平移(translate) ← a395ee82；模板(template) ← a395ee82；单像素布局(singleton_layout) ← a395ee82；栅格偏移(lattice_offset) ← a395ee82；重叠区域重涂(overlap_recolor) ← a395ee82；列周期(column_periodicity) ← ba26e723；周期列触发变色(periodic_column_triggers_recolor) → 改造为"周期列触发镜像"；镜像(mirror) ← b10624e5/2dee498d

**依赖链**：单像素标记确定栅格 → 栅格偏移量定位每个印章副本 → 列偏移的奇偶性决定是否水平翻转模板 → 翻转改变实际覆盖像素 → 相邻副本因翻转差异产生不同的重叠图案 → 重叠像素被重涂为第三色。去掉栅格则印章位置不确定；去掉奇偶镜像则所有副本相同、重叠图案单调；去掉重叠重涂则翻转效果无可见输出差异。

将一个不对称模板按栅格偏移印章到每个标记位置，列偏移为奇数的副本水平翻转，所有重叠像素重涂为红色。

**输入结构**：约 18x18 的网格。背景为黑(0)。左上角区域放置一个蓝(1)的不对称模板（4-连通、非水平对称的形状，例如 L 形或阶梯形，约 3x3 像素区域内占 4~6 个像素）。网格其他位置散布若干单像素标记：恰好一个绿(3)像素（原点标记）和 3~6 个黄(4)像素（副本标记），所有标记（含绿色原点）排列在一个等间距的二维栅格上（水平间距和垂直间距均 >= 模板宽度 + 1 且 >= 模板高度 + 1）。生成约束：模板关于水平中心轴不对称（镜像后与原图不同）；栅格中至少有一对水平相邻的标记（列偏移差为 1），以确保奇偶翻转产生可见效果。

**规则**：
1. 识别绿(3)像素为栅格原点 (or, oc)。计算栅格的水平步长 dx 和垂直步长 dy（由相邻标记间距确定）。
2. 对每个标记（含原点），计算其栅格坐标：col_offset = (mc - oc) / dx，row_offset = (mr - or) / dy。
3. 以每个标记的像素坐标为锚点，将模板的边界框中心对齐到该锚点，生成一份模板副本。
4. 原点处的副本用绿(3)替代蓝(1)绘制。其余副本用蓝(1)绘制。
5. 对 col_offset 为奇数的副本（含正负奇数），在放置前将模板水平翻转（沿垂直中心轴镜像）。col_offset 为偶数（含 0）的副本保持原始朝向。
6. 将所有副本绘制到画布上。若任意像素被两个或更多副本覆盖（无论颜色是否相同），将该像素重涂为红(2)。
7. 单像素标记本身被所在副本覆盖（不单独保留）。

**关键洞察**：同一批印章副本中，列偏移的奇偶性静默地翻转了模板朝向；由于模板不对称，翻转使得相邻副本的像素覆盖区域发生错位，从而在特定位置产生（或消除）重叠——重叠像素的红色标记是镜像规则存在的唯一视觉线索；不对比多个示例中不同栅格布局下的红色分布，无法归纳出奇偶镜像规则。

## 新题 5：象限方位推导 — 片段近远端重涂

## 新题 6：嵌套深度反转控制标记含义的对称补全

**组合逻辑**：[由外到内嵌套](outer_to_inner) + [包含](containment) → 嵌套深度计算 → 深度奇偶翻转（创新：将"控制标记指示源侧"改造为条件性规则——嵌套深度的奇偶性反转控制标记的语义，偶数深度标记指示源侧、奇数深度标记指示目标侧） → [对称补全/镜像](symmetric_completion, mirror)。源题中控制标记含义固定不变，这里控制标记的含义被嵌套结构动态修改，形成"空间层次 → 语义反转"的涌现效应。

**来源原语**：对称补全(symmetric_completion) ← 5b692c0f/47996f11；对称轴(symmetry_axis) ← 5b692c0f；控制标记(control_marker) ← 5b692c0f；控制标记指示源侧(control_marker_indicates_source) ← 5b692c0f；轴对称反射(axial_mirror_reflection) ← 5b692c0f；嵌套矩形(nested_rectangle) ← 5751f35e；由外到内嵌套(outer_to_inner) ← 5751f35e；包含(containment) ← 8efcae92；大层先画小层覆盖(large_first_small_over) ← 5751f35e；镜像(mirror) ← b10624e5/2dee498d

**依赖链**：检测各对象的空间包含关系 → 计算每个对象的嵌套深度 → 深度奇偶性反转控制标记的语义（偶数深度：标记指向正确侧；奇数深度：标记指向错误侧） → 根据重新解释后的源侧执行镜像对称补全 → 从外到内依次处理，内层覆盖外层。去掉嵌套分析则所有标记按统一语义处理、奇数深度对象被错误补全；去掉控制标记则源侧无法确定；去掉对称补全则无输出变换。

对每个含黄色对称轴和控制标记的彩色对象执行对称补全，但嵌套深度为奇数的对象，其控制标记的含义被反转（指向目标侧而非源侧）。

**输入结构**：约 15x15 的网格。背景为黑(0)。网格上有 2~3 个不同颜色的对象（例如蓝(1)、红(2)、绿(3)），部分对象的边界框嵌套在其他对象的边界框内部（即存在至少一个深度为 1 的对象）。每个对象包含：
- 一组前景色像素构成的不完整图案（左右或上下一半有清晰图案，另一半为空或不同）。
- 一条由黄(4)像素组成的连续直线段穿过该对象，作为对称轴（水平或垂直）。
- 一个偏离对称轴的黄(4)单像素（控制标记），位于对称轴的某一侧。
生成约束：每个对象的前景图案在对称轴一侧完整、另一侧不完整或缺失。外层对象的边界框至少比内层对象的边界框每方向大 2 个像素。不存在深度 >= 3 的嵌套。

**规则**：
1. 对每个对象，计算其嵌套深度：若其边界框不在任何其他对象的边界框内部，则深度为 0；若在恰好一个对象的边界框内部，则深度为 1；以此类推。
2. 对嵌套深度为偶数（0, 2, ...）的对象：控制标记所在的一侧为源侧（正确侧）。将源侧的图案沿对称轴镜像到另一侧，覆盖该侧原有的所有像素（含前景和背景）。
3. 对嵌套深度为奇数（1, 3, ...）的对象：控制标记所在的一侧为目标侧（错误侧）。将对面一侧（非标记侧）的图案沿对称轴镜像到标记侧，覆盖标记侧原有像素。
4. 处理顺序：从嵌套深度最小（最外层）到最大（最内层）依次处理。内层对象补全后的像素覆盖外层对象在同一位置的像素。
5. 黄(4)对称轴和控制标记像素保持不变，不被镜像操作覆盖。

**关键洞察**：控制标记的语义不是全局固定的"标记 = 源侧"，而是被嵌套深度的奇偶性动态反转——外层对象中标记指向正确的一半，内层对象中标记反而指向需要被覆盖的一半；这一反转规则只能通过对比嵌套与非嵌套对象的补全结果才能发现。

## 新题 7：引导掩码选纵条 — 障碍墙截断不对称延伸

**组合逻辑**：[引导掩码/包围框包含/唯一被框选对象](guide_mask, bbox_containment, uniquely_enclosed) → [延伸填充/距离控制高度/不对称递变](extension_fill, distance_controls_height, asymmetric_gradient) + 障碍截断（创新：将"障碍像素"从空间阻挡重新用作延伸的硬边界墙，其他纵条充当隐式障碍物）。源题中延伸填充无任何阻挡地向两侧生长，这里引入了选择性障碍和方向性截断，延伸形状由种子高度和障碍位置共同决定。

**来源原语**：引导掩码(guide_mask) ← bf699163；包围框包含(bbox_containment) ← bf699163；唯一被框选对象(uniquely_enclosed) ← bf699163；延伸填充(extension_fill) ← 5207a7b5；纵条(vertical_bar) ← 5207a7b5；距离控制高度(distance_controls_height) ← 5207a7b5；不对称递变(asymmetric_gradient) ← 5207a7b5；障碍像素(obstacle_pixel) ← 31adaf00

**依赖链**：引导掩码的包围框从多根纵条中选出种子纵条 → 种子高度 h 确定延伸公式 → 向左延伸 h+2d、向右延伸 h-2d → 非种子纵条充当墙壁，在其所在列截断延伸（该方向不再向更远处延伸） → 最终形状由种子属性和墙壁位置共同决定。去掉引导掩码则种子不确定；去掉延伸公式则变换消失；去掉墙壁截断则所有示例输出形状可由简单公式预测、无需推理阻挡。

从多根纵条中用引导掩码选出种子纵条，以其高度为基准向两侧不对称延伸，但延伸在遇到其他纵条时被截断。

**输入结构**：约 15x20 的网格。背景为黑(0)。从网格顶部边缘向下延伸 4~6 根灰(5)纵条，每根宽 1 像素，高度各不相同（3~10 像素），彼此间隔至少 3 列。若干黄(4)引导像素散布在网格中（不与任何纵条同列），它们的集体包围框恰好包含一根灰色纵条（不包含其他纵条）。生成约束：被选中的种子纵条左右两侧各至少有一根其他纵条作为墙壁；种子纵条不在网格最左列或最右列。

**规则**：
1. 收集所有黄(4)像素，计算其集体包围框。在该包围框内恰好有一根灰(5)纵条——此为种子纵条，高度 h，位于列 c0。
2. 向左延伸：对种子纵条左侧每一列（距离种子 d = 1, 2, 3, ...），从第 0 行向下涂青(8)色，涂满 min(h + 2d, 网格行数) 个像素。逐列向左扩展，直到遇到最近的一根灰(5)纵条所在列——该列本身不涂色，且不继续向更左延伸。
3. 向右延伸：对种子纵条右侧每一列（d = 1, 2, 3, ...），从第 0 行向下涂粉(6)色，涂满 max(h - 2d, 0) 个像素（结果为 0 时该列不涂色）。同样在遇到最近的灰(5)纵条时停止（该列不涂色，不继续向更右延伸）。右侧延伸也会因 h - 2d 递减到 0 而自然终止，两个终止条件取先到达的那个。
4. 所有灰(5)纵条保持不变（绘制在延伸色之上）。黄(4)引导像素在输出中保留。

**关键洞察**：延伸的最终轮廓不仅取决于种子纵条的高度（控制基础梯形形状），还取决于相邻纵条的位置（控制截断边界）——两者缺一不可；必须同时推断出不对称增长公式和墙壁截断规则才能正确预测输出。

## 新题 8：干扰分量过滤后锚比缩放叠印母题

**组合逻辑**：[连通分量/按面积筛选/保留最大分量/忽略干扰项](connected_component, size_filtered, keep_largest, ignore_distractors) → [尺寸比编码缩放](size_ratio_encodes_scale) → [缩放](scale) → [叠加](overlay)。源题中缩放因子由预设的锚点方块直接给出，过滤与缩放无关。这里过滤是缩放的前置必要步骤——若不滤除干扰分量，目标方块的边长会被错误估算，导致缩放因子错误。过滤与缩放之间形成因果依赖。

**来源原语**：连通分量(connected_component) ← 337b420f/a934301b；按面积筛选(size_filtered) ← 337b420f；保留最大分量(keep_largest) ← 337b420f；忽略干扰项(ignore_distractors) ← 337b420f/c3202e5a；缩放(scale) ← b10624e5；尺寸比编码缩放(size_ratio_encodes_scale) ← b10624e5；图案母题(motif) ← b10624e5；锚点方块(anchor_block) ← b10624e5；叠加(overlay) ← 337b420f

**依赖链**：在每个目标区域中分离连通分量 → 按面积滤除干扰小分量，保留最大分量（即真正的目标方块） → 目标方块边长 / 锚点方块边长 = 缩放因子 → 将母题按此因子最近邻缩放 → 缩放后的母题叠印到目标方块上，母题像素覆盖方块像素。去掉过滤则干扰分量污染面积测量；去掉锚点则无缩放基准；去掉叠印则无输出变换。

滤除每个绿色区域中的干扰小分量后，取最大分量为目标方块，以其与红色锚方块的边长比缩放蓝色母题，再将缩放后的母题叠印到目标方块上。

**输入结构**：约 18x18 的网格。背景为黑(0)。左上角区域有一个蓝(1)的不规则母题图案（4-连通、约 3x3 边界框内占 4~7 个像素）。母题下方或右方有一个红(2)实心正方形锚点方块（边长 2 或 3）。网格其他位置有 3~4 个绿(3)实心正方形作为目标方块，边长各不相同（从 3 到 8），彼此间隔 >= 3 个像素。每个绿色目标方块附近（距离 1~2 像素处）有 1~2 个由绿(3)像素组成的微小干扰分量（1~2 个像素的小点或短线，与目标方块不 4-连通）。生成约束：每个目标方块的边长能被锚点方块边长整除（保证缩放因子为正整数）；母题边界框不超过锚点方块的尺寸（保证缩放后母题不超过目标方块）。

**规则**：
1. 将所有绿(3)像素按 4-连通性分成连通分量。在每一簇（空间上相邻的一组分量中），保留面积最大的分量作为"目标方块"，丢弃其余小分量（干扰项）。两个分量属于同一簇当且仅当它们的边界框之间的切比雪夫距离 <= 2。
2. 识别红(2)像素构成的实心正方形为锚点方块，边长记为 a。
3. 识别蓝(1)像素构成的图案为母题。
4. 对每个目标方块（边长 t），计算缩放因子 k = t / a。
5. 将母题按因子 k 做最近邻缩放：母题中的每个像素扩展为 k x k 的方块。
6. 将缩放后的母题对齐到目标方块的左上角，绘制在目标方块之上。缩放母题中蓝(1)像素覆盖对应位置的绿(3)像素；缩放母题中对应于母题边界框内黑(0)背景的位置不改变目标方块的绿(3)像素。
7. 锚点方块和原始母题在输出中保持不变。已被丢弃的干扰小分量在输出中消失（恢复为黑(0)背景）。

**关键洞察**：干扰分量不只是视觉噪声——它们会改变绿色连通区域的整体面积或边界框尺寸；只有先正确识别并过滤掉干扰分量，才能获得真正的目标方块边长，进而计算出正确的缩放因子；过滤步骤是缩放步骤的前置因果依赖。

2. 对每个矩形，计数其内部红(2)标记像素的数量。
3. 擦除所有含 2 个或更多红色标记的矩形——将其全部像素（含蓝和红）恢复为黑(0)背景。保留含 0 或 1 个标记的矩形（其红色标记像素在幸存矩形中也保留）。
4. 对每个幸存矩形，归一化其朝向：若高度 > 宽度，将矩形顺时针旋转 90°（使其变为宽度 > 高度）。若已经是宽 >= 高，保持不变。旋转时矩形内部的红色标记像素一同旋转。
5. 按幸存矩形在输入中的原始位置从左到右排序（依据矩形边界框左上角的列坐标升序；列坐标相同时按行坐标升序）。
6. 在新的输出画布上，将排序后的归一化矩形从左到右依次排列，每两个矩形之间间隔 1 列黑(0)背景，所有矩形顶部对齐于第 0 行。输出画布高度 = 所有归一化矩形中的最大高度，宽度 = 所有归一化矩形宽度之和 + (矩形数 - 1) 个间隔列。

**关键洞察**：标记像素在本题中也承担双重角色——其数量决定矩形是否被擦除（过滤功能），而幸存矩形内部的标记像素又作为纹理细节被保留到最终输出中（内容功能）；擦除步骤改变了参与排列的矩形集合，进而改变了输出画布的尺寸和内容排布，两者不可分割。
