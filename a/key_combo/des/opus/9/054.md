## 新题 1：弹射轨迹划分区域的交替填色

**组合逻辑**：[射线延伸](从路径绘制创新为区域划分边界) + [反射弹回](已有) + [填充](从轮廓内填创新为区域分类填色) + [二部图结构](从墙体分隔创新为轨迹分隔) + [交替着色](已有)

**来源原语**：射线延伸/反射弹回/画布边界/对角遇边反射(a3df8b1e), 填充/二部图结构/四邻接连通/交替着色(3bd292e8)

**依赖链**：射线的弹射轨迹将画布分割为若干 4-连通区域——区域之间通过轨迹相邻构成二部图——种子像素所在区域确定二部图的起始着色侧——对侧区域着另一色。轨迹形态、区域拓扑、种子位置三者共同决定最终着色。

将蓝(1)像素的对角弹射轨迹当作区域分隔墙，依据种子像素所在侧对分隔出的二部区域交替填色。

**输入结构**：黑(0)背景网格，约 15x20（高大于宽以保证足够弹射次数）。底部某一行有一个蓝(1)像素作为射线起点。网格中另有一个红(2)孤立像素作为种子标记，位于远离底行的位置。除此之外全为黑(0)。生成约束：蓝(1)像素不在最左或最右列（保证首步不立即弹回）；红(2)像素不在蓝(1)像素所在列（保证种子不被轨迹直接覆盖）；网格宽度为奇数（保证弹射轨迹不在同一列重叠）。

**规则**：
1. 从蓝(1)像素出发，沿对角线向右上方移动（每步行 -1、列 +1）。到达左/右边界时水平方向反转（列增量变号），垂直方向始终向上。将每个经过的格子标记为绿(3)。射线离开顶部边界时停止（最后一个在网格内的格子也标记为绿(3)）。
2. 绿(3)轨迹像素视为墙体。将所有非绿(3)的格子按 4-连通分组为若干区域。
3. 这些区域通过轨迹相邻关系构成二部图（轨迹两侧的区域属于不同类）。确定二部图的两个类集合 A 和 B。
4. 红(2)种子像素所在区域归入类 A。类 A 的所有区域填充灰(5)，类 B 的所有区域填充黄(4)。红(2)像素被其所在类的颜色灰(5)覆盖。
5. 绿(3)轨迹像素和蓝(1)起点像素保持不变。

**关键洞察**：弹射轨迹不再是装饰性路径——它的几何形态直接决定了区域的拓扑划分，而种子像素的位置决定了二部图哪一侧获得哪种颜色。仅看单个示例无法区分"种子侧为灰"和"左侧为灰"等替代规则，需对比种子在轨迹不同侧的多个示例才能归纳。

## 新题 2：颜色频率驱动同心方块尺寸与重叠遮挡

**组合逻辑**：[计数](已有) + [缩放](从边长循环创新为频率决定边长) + [裁剪](已有) + [同心定位](已有) + [频率唯一性](从筛选创新为尺寸编码)

**来源原语**：计数/频率唯一性/孤立像素(31aa019c), 缩放/奇数边正方形/中心点/同心定位/边长循环变换(522fdd07), 裁剪(67b4a34d/72ca375d)

**依赖链**：每种颜色的出现次数编码了以该颜色像素为中心绘制的正方形边长——同色像素产生同尺寸方块——多个方块在空间上重叠时小方块覆盖大方块——最终裁剪到所有方块的最小外接矩形。频率统计→尺寸映射→重叠遮挡三者构成不可跳步的推理链。

统计每种颜色的像素频率，以频率决定以每个像素为中心绘制的实心奇数边正方形边长，重叠时小方块优先，最后裁剪。

**输入结构**：黑(0)背景网格，约 20x20。网格上散布若干孤立的有色像素（每个像素与同色或异色像素的 4-连通距离至少为 2，保证在输入中它们是孤立的）。使用 3-4 种颜色，例如红(2)、蓝(1)、绿(3)、黄(4)。每种颜色出现的次数互不相同且在 1-5 范围内。像素位置不靠近网格边缘（距边界至少 5 格），保证最大方块不超出网格。生成约束：不同颜色的出现次数两两不同。

**规则**：
1. 对每种非黑色颜色 c，统计输入中颜色 c 的像素总数，记为 freq(c)。
2. 对输入中每个非黑像素 p（颜色为 c），以 p 为中心绘制一个边长为 2*freq(c)-1 的实心正方形，颜色为 c。freq(c)=1 时方块为 1x1（即像素本身），freq(c)=2 时 3x3，freq(c)=3 时 5x5，以此类推。
3. 所有方块按边长从大到小依次绘制到一个与输入同尺寸的空白黑(0)画布上。边长相同的方块（必定同色）按其中心像素在输入中从上到下、从左到右的顺序依次绘制。后绘制的覆盖先绘制的。
4. 输出为该画布中所有非黑像素的最小外接矩形裁剪。

**关键洞察**：颜色的统计频率不是筛选条件而是几何尺度的编码——频率越低的颜色产生的方块越小，但因为小方块最后绘制，它们反而在视觉上覆盖大方块。求解者需对比多个示例才能确认频率→边长的映射公式，以及"小覆盖大"的遮挡规则。

## 新题 3：拼图组装受同心环约束后循环换色

**组合逻辑**：[平移拼合](已有) + [边缘匹配](已有，但增加环形验证约束) + [重涂色/循环轮换](已有) + [嵌套层序](从已知结构创新为组装后涌现的结构) + [通配色](已有)

**来源原语**：平移拼合/矩形碎片/角标记/边缘匹配/通配色(446ef5d2), 重涂色/同心环/嵌套层序/色沿层序循环移(bda2d7a6)

**依赖链**：碎片通过边缘匹配进行平移拼合——匹配允许多种排列——只有形成完美同心矩形环的那种排列是正确的——确定正确排列后提取嵌套层序——循环移动环色。组装的正确性依赖环形结构验证，环形结构又决定换色映射，形成双向约束。

将散落矩形碎片拼合为大矩形，正确组装由同心环完整性唯一确定，然后将环色按嵌套序循环移位。

**输入结构**：灰(5)背景网格，约 22x22。网格上散布 4-6 块互不重叠的矩形碎片，每块碎片是一个实心的多色矩形区域（内部像素非灰(5)）。网格某角有一个 L 形标记（3 个橙(7)像素构成 2x2 缺一格的 L 形），缺口位置指示目标矩形的角点。碎片之间不 4-连通相邻。每块碎片的边缘行/列中，最常见的颜色为蓝(1)，蓝(1)在边缘匹配时充当通配色。生成约束：恰好存在一种平移组装方式使拼成的大矩形呈现完美的同心矩形环结构（每环恰好一格厚、单色）；其余排列方式会导致至少一环不单色。

**规则**：
1. 识别 L 标记，缺口格为目标大矩形的角点。
2. 蓝(1)为通配色：在边缘匹配中，当两块碎片的接触边上某位置至少有一侧为蓝(1)时视为匹配成功。
3. 尝试将碎片平移（不旋转）拼合到以 L 标记角点为一角的大矩形中。选择使拼合结果呈现完美同心矩形环的唯一排列方式——即每一层环（从外到内，每层恰好一格厚）内所有非蓝(1)像素颜色相同。
4. 在正确组装的大矩形中，将蓝(1)通配像素替换为其所在环的非蓝颜色。
5. 记录从最外层到最内层各环的颜色序列（去重后保留首次出现顺序）。将每个颜色替换为该序列中前一个颜色（第一个颜色被序列中最后一个颜色替换，形成循环）。
6. 输出为换色后的大矩形（不含 L 标记和灰(5)背景）。

**关键洞察**：边缘匹配的通配机制允许多种组装可能，但只有一种能产生完美同心环——同心环结构不是输入中可以直接看到的，而是通过正确组装"涌现"出来的。求解者必须将组装问题和环形验证同时求解，而非先拼后验。

## 新题 4：墙体区域分类决定矩形框色的交叉图案绘制

**组合逻辑**：[擦除](已有) + [连线/draw_lines](已有，绘制 X 图案) + [填充](从区域填充创新为框色指定) + [二部图结构/交替着色](从纯背景填色创新为对象属性赋值) + [标记在矩形内](已有)

**来源原语**：擦除/连线/实心矩形/标记像素/空心矩形/标记在矩形内/标记色绘交叉图案(8cb8642d), 分隔墙线/背景区域/四邻接连通/二部图结构/交替着色(3bd292e8), 填充(22168020)

**依赖链**：墙体将画布分隔为 4-连通区域——区域构成二部图——二部图着色决定每个区域的类别色——区域内的实心矩形取该区域的类别色作为框色——矩形内嵌标记像素提供 X 图案的颜色。全局拓扑结构（墙体划分）决定了局部对象属性（框色），局部对象属性（标记色）决定了内部图案。

红(2)墙线将网格分为二部区域，区域的二部类别决定其中矩形的框色，矩形内嵌标记像素的颜色决定内部 X 图案色。

**输入结构**：黑(0)背景网格，约 18x18。红(2)像素形成若干 4-连通的一格厚墙段，将网格分隔为多个 4-连通的黑(0)背景区域。在其中 2-4 个区域内各有一个实心单色矩形（颜色如橙(7)、青(8)等非红非黑），每个矩形内部嵌有恰好一个不同色的标记像素（如绿(3)、蓝(1)等）。标记像素严格在矩形边界内部（不在边界行/列上）。不含矩形的区域保持黑(0)。生成约束：墙体分隔出的区域图是二部图（即不含奇数环的区域邻接关系）；最左下方的区域不含矩形（用于确定着色起始侧）。

**规则**：
1. 所有红(2)墙体像素保持不变。
2. 识别墙体分隔出的所有 4-连通背景区域。构建区域邻接图（两个区域在同一段墙体两侧时相邻），该图为二部图。
3. 包含网格左下角像素的区域归入类 A，与之相邻的区域归入类 B，以此交替。类 A 对应灰(5)，类 B 对应黄(4)。
4. 对每个含实心矩形的区域：擦除矩形内部所有像素（设为黑(0)），重新绘制矩形的一格厚边框，边框颜色为该区域的类别色（灰(5)或黄(4)），而非矩形原色。
5. 在每个重绘边框的矩形内部，用该矩形的标记像素颜色绘制 X 图案：从内部四个角向中心画 45 度对角线，在中心位置连通（若内部宽高为偶数则中心区域 2x2 全填）。
6. 不含矩形的区域保持黑(0)不变。

**关键洞察**：矩形框色并非来自矩形本身的颜色——矩形原色在输出中完全消失，框色完全由该矩形所处的墙体分区在二部图中的类别决定。求解者需先理解全局墙体拓扑才能确定局部框色，再用标记色画 X 图案。仅看单个示例可能误以为框色等于矩形原色或标记色。

## 新题 5：对称性筛选精灵体并按对称类型定向对接

**组合逻辑**：[筛选](已有) + [对接拼合](已有，但对接方向由新条件决定) + [裁剪](已有) + [对称性筛选目标](从纯选择创新为选择+方向编码) + [连接点颜色匹配](已有)

**来源原语**：筛选/精灵体/干扰体/对称性筛选目标/忽略干扰项(72ca375d), 对接拼合/精灵体/连接点/对接对齐/连接点颜色匹配(20270e3b), 裁剪(67b4a34d)

**依赖链**：多个候选精灵体中只有一个具备对称性——对称性的具体类型（水平/垂直/旋转）编码了对接方向——被选中的精灵体通过连接点与基座精灵体对接——对接方向由对称类型唯一确定——裁剪输出。筛选结果和对接参数由同一属性（对称性）同时决定。

从多个候选精灵体中筛出唯一对称者作为对接件，其对称类型决定对接到基座的方向。

**输入结构**：黑(0)背景网格，约 20x18。网格中有一个较大的蓝(1)基座精灵体（4-连通单色不规则形状，约 10-15 像素），其边缘有一个红(2)连接点像素。另有 3-4 个较小的候选精灵体（各为不同颜色如绿(3)、黄(4)、橙(7)、青(8)，均为 4-连通单色不规则形状，4-8 像素），每个候选精灵体边缘也各有一个红(2)连接点像素。候选精灵体之间以及与基座之间互不 4-连通相邻。生成约束：恰好一个候选精灵体（裁剪为最小外接矩形后）具备明确的对称性（水平反射对称、垂直反射对称或 180 度旋转对称中的恰好一种），其余候选不具备任何对称性。

**规则**：
1. 识别基座精灵体（面积最大的非黑连通分量，不计连接点颜色）。
2. 将每个候选精灵体裁剪为最小外接矩形（包含连接点），测试其对称性。
3. 选出具备对称性的唯一候选作为"对接件"，丢弃其余候选。
4. 根据对接件的对称类型确定对接方向：
   - 水平反射对称（左右对称）→ 将对接件平移，使其连接点位于基座连接点的正右方一格处。
   - 垂直反射对称（上下对称）→ 将对接件平移，使其连接点位于基座连接点的正下方一格处。
   - 180 度旋转对称 → 将对接件平移，使其连接点位于基座连接点的正上方一格处。
5. 将对接件印到画布上，与基座合并。所有红(2)连接点像素重涂为对接件的主色。
6. 输出为合并后所有非黑像素的最小外接矩形裁剪。

**关键洞察**：对称性在本题中承担双重角色——既是筛选哪个精灵体的判据，又是确定对接方向的编码。求解者必须对比多个示例来区分"选择哪个"和"如何放置"两个子问题，而两者的答案都来自同一个对称性属性。单个示例无法区分"水平对称→向右"还是"恰好在右边"。

## 新题 6：轮廓填充色由内含标记频率决定

**组合逻辑**：[填充](已有，行跨度填充) + [计数](已有) + [擦除](已有) + [行内边界配对](已有) + [频率唯一性](从全局统计创新为区域内局部统计) + [包含](从缩放对齐创新为几何域约束统计)

**来源原语**：填充/轮廓线/封闭区域/行内边界配对/逐行跨度填充(22168020), 计数/孤立像素/频率唯一性/最低频色定位目标(31aa019c), 擦除(8cb8642d), 包含(8a004b2b)

**依赖链**：轮廓的行边界配对确定各轮廓的封闭内域——内域中散布的标记像素按颜色分组计数——最高频标记色成为该轮廓的填充色——填充覆盖标记像素——未被任何轮廓包围的孤立标记像素被擦除。几何结构（轮廓）定义统计域，统计结果反过来决定该域的填充颜色。

多个单色轮廓各自包围一片区域，区域内散布不同色的标记像素，标记的颜色频率决定该轮廓的填充色。

**输入结构**：黑(0)背景网格，约 20x18。网格上有 2-3 个互不重叠的单色 8-连通轮廓，每个轮廓使用不同颜色（如红(2)、蓝(1)、绿(3)）。每个轮廓在其所占的每一行上恰好有两个前景像素（左右边界），中间为黑(0)或标记像素。轮廓的封闭内域（行跨度内部）散布着若干孤立的标记像素，使用 2-3 种颜色（如黄(4)、灰(5)、橙(7)），这些标记色与轮廓色不同。不同轮廓内部的标记颜色组合可以不同，且最高频标记色也不同。轮廓外部也可能有少量孤立标记像素（干扰项）。生成约束：每个轮廓内部的标记像素中，恰好有一种颜色的出现次数严格最多（无平局）。

**规则**：
1. 识别每个单色轮廓。对每个轮廓，逐行找到该轮廓色的两个边界像素，它们之间的格子构成该行的内域。
2. 收集每个轮廓内域中所有非黑(0)、非轮廓色的标记像素，按颜色分组统计出现次数。
3. 出现次数最多的标记颜色成为该轮廓的填充色。
4. 将该轮廓的整个内域（每行两个边界之间的所有格子）填充为该填充色，覆盖原有的标记像素。轮廓边界像素本身保持原色不变。
5. 擦除所有不在任何轮廓内域中的孤立标记像素（设为黑(0)）。

**关键洞察**：轮廓不仅是视觉上的边界——它精确定义了一个统计采样区域，标记频率的"最高频"规则只在该几何域内成立。轮廓外的标记是干扰项，必须忽略。仅看单个示例可能误以为填充色等于标记中"全局最多"的颜色或某个固定映射。

## 新题 7：奇偶环掩码筛选模板印章的可见像素

**组合逻辑**：[像素放大](已有，模板压缩) + [印章覆盖](已有) + [填充](从区域填充创新为奇偶环生成) + [角标记像素](已有) + [奇偶距离决定填色](从独立环图案创新为印章的空间掩码) + [面板对应](已有)

**来源原语**：像素放大/印章覆盖/模板区/掩码标记/分隔行/面板对应/标记位置接收模板(b4a43f3b), 角标记像素/同心环/最近归属/奇偶距离决定填色(d22278a0)

**依赖链**：上方模板区压缩为小瓦片——下方掩码标记确定印章位置——但角标记产生的奇偶距离环形成一张"可见性掩码"——印章像素仅在切比雪夫距离为偶数的位置才实际显示——奇数位置保持黑色。模板内容、印章位置、角标记几何三者同时约束输出的每个像素。

将上方模板印到下方标记位置，但仅角标记奇偶环中偶数距离的格子可见，奇数格子被遮蔽。

**输入结构**：黑(0)背景网格，约 18x20。一条灰(5)水平满行将网格分为上下两部分。上方区域为模板区：由若干 2x2 同色块组成的图案（使用红(2)、蓝(1)、绿(3)等颜色和黑(0)），宽高均为偶数。下方区域与上方区域尺寸相同，其中：两个对角的角格子为黄(4)角标记像素（如左上角和右下角）；散布若干橙(7)单像素作为掩码标记；其余为黑(0)。生成约束：下方区域的尺寸为模板压缩后小瓦片尺寸的整数倍（保证瓦片恰好对齐粗网格）；黄(4)角标记恰好位于下方区域的两个对角格子。

**规则**：
1. 将上方模板区的每个 2x2 同色块压缩为一个像素，得到一个小瓦片（尺寸为模板区宽高各除以 2）。
2. 下方区域构成一个粗网格，粗网格每个格子的尺寸等于小瓦片尺寸。
3. 对下方区域每个像素，计算它到最近的黄(4)角标记像素的切比雪夫距离。距离为偶数的像素为"可见位"，奇数为"遮蔽位"。
4. 构建与下方区域同尺寸的输出画布（初始全黑(0)）。对每个含橙(7)掩码标记的粗网格格子，将小瓦片写入对应的输出区域——但仅写入那些落在"可见位"上的瓦片像素；"遮蔽位"上的像素保持黑(0)。
5. 灰(5)分隔行、黄(4)角标记、橙(7)掩码标记均不出现在输出中。输出仅包含下方区域大小的画布。

**关键洞察**：模板印章和奇偶环是两个独立的空间图案，但它们通过像素级的"与"操作耦合——模板决定"印什么颜色"，奇偶环决定"哪些位置可见"。角标记的位置改变环的几何形态，从而改变同一模板在不同位置印出的可见部分。这不是简单的先印后裁，而是逐像素的双重条件判定。

## 新题 8：同心环层数编码输出尺寸，环色序列异或填充输出

**组合逻辑**：[计数](从分区计数创新为环层计数编码维度) + [异或](已有，但作用于抽象颜色序列而非空间掩码) + [嵌套层序](已有) + [分隔行](已有) + [同心环](已有)

**来源原语**：计数/分隔栅格/分区数定输出尺寸(1190e5a7), 异或/分隔行/掩码/对齐/逐像素异或输出(3428a4f5), 同心环/嵌套层序/色沿层序循环移(bda2d7a6)

**依赖链**：上下两半各含同心环——上半环层数 R 和下半环层数 C 编码输出网格的行数和列数——上半各环颜色映射到输出的各行、下半各环颜色映射到输出的各列——每个输出格 (r,c) 由第 r 个上半环色和第 c 个下半环色的"异同"决定颜色。环的几何结构同时编码了维度信息和内容信息。

上下两组同心环的层数决定输出尺寸，环色序列逐对比较——相同为黑(0)、不同为绿(3)——生成输出矩阵。

**输入结构**：黑(0)背景网格，约 16x16（保证上下两半各 7-8 行）。一条黄(4)水平满行将网格分为上下两半，上下两半行数相同。上半部分由同心矩形环填满（每环恰好一格厚、单色，从最外层到最内层可使用红(2)、蓝(1)、绿(3)、灰(5)等颜色，颜色可重复）。下半部分同样由同心矩形环填满（结构类似但环层数和颜色可不同）。生成约束：上半和下半的同心环均为完整的矩形环（最内层可以是单格或一条线段）；环层数各自在 2-5 之间。

**规则**：
1. 定位黄(4)分隔行。将网格分为上半和下半。
2. 在上半中，从最外层到最内层依次读取每个同心矩形环的颜色，得到颜色序列 T = [t1, t2, ..., tR]，共 R 层。
3. 在下半中，同样从最外层到最内层读取颜色序列 B = [b1, b2, ..., bC]，共 C 层。
4. 创建一个 R 行 C 列的输出网格。
5. 对输出的每个格子 (r, c)（r 从 1 到 R，c 从 1 到 C）：若 T[r] 与 B[c] 颜色不同，则该格输出绿(3)；若相同，则输出黑(0)。
6. 输出仅为该 R x C 小网格，不包含分隔行或原始环结构。

**关键洞察**：同心环的几何结构承担了双重编码角色——环的层数决定输出的维度（这在 1190e5a7 中由栅格分区完成），环的颜色序列决定输出的内容（这在 3428a4f5 中由空间掩码完成）。求解者必须同时理解"层数→尺寸"和"颜色异同→输出值"两条规则，且两者均依赖正确识别嵌套层序。仅看单个示例无法区分"颜色异同→绿/黑"和"颜色相同→绿"等替代规则。
