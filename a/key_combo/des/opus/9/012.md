## 新题 1：四象限镜像涌现封闭区域填充

**组合逻辑**：[镜像+拼接](来自0c786b71，保留四象限镜像) → [洪泛填充](来自00d62c1b，创新：作用于镜像后涌现的封闭区域而非输入中已有的封闭区域)

**来源原语**：镜像/拼接/四象限对称(0c786b71)、洪泛填充/封闭区域/拓扑内外(00d62c1b)

**依赖链**：输入中的绿(3)曲线并不自封闭，无法独立产生封闭区域；四象限镜像拼接后，曲线在对称轴处对接形成闭合边界，洪泛填充才有可操作的拓扑内部。删除镜像步骤则无封闭区域可填；删除填充步骤则输出与单纯镜像无法区分。

从一组不封闭的绿色曲线出发，通过四象限镜像使曲线在对称轴拼合成闭合边界，再将涌现出的封闭黑色内部填充为黄色。

**输入结构**：约 7x9 的黑(0)背景网格。绿(3)像素构成 1~3 条不自封闭的曲线段（4-连通，每条 4~10 像素），每条曲线至少有一个端点位于网格的边缘行或边缘列上。曲线之间互不相邻。生成约束：将网格进行四象限镜像拼接后（原始位于右下象限，左右翻转位于左下，上下翻转位于右上，180度旋转位于左上），至少存在一个被绿色边界完全4-连通封闭的黑色连通域，且该连通域不与拼接后网格的外部黑色区域4-连通相通。

**规则**：
1. 构造一个高度为原始行数x2、宽度为原始列数x2 的输出网格。
2. 将原始网格放入右下象限。
3. 将原始网格左右翻转后放入左下象限。
4. 将原始网格上下翻转后放入右上象限。
5. 将原始网格旋转180度后放入左上象限。
6. 在拼接结果中，从输出网格的四条外边界向内做洪泛标记（4-连通），标记所有与外边界4-连通相通的黑(0)像素为"外部"。
7. 将所有未被标记为"外部"的黑(0)像素重涂为黄(4)。绿(3)像素保持不变。

**关键洞察**：封闭区域在输入中并不存在——它们是镜像拼接的涌现结果；求解者必须先在心中完成镜像，才能判断哪些区域会被封闭。

## 新题 2：角括号选色定向周期图案恢复

**组合逻辑**：[角括号+标记像素→选色](来自1e81d6f9，创新：选出的颜色不用于擦除，而是指定要恢复的遮挡物颜色) → [周期平铺图案恢复](来自abbfd121，创新：仅对被选中颜色的遮挡物执行恢复，其余遮挡物保留)

**来源原语**：角括号/标记像素/按标记色选择同色(1e81d6f9)、周期平铺图案/矩形遮挡物/被遮挡(abbfd121)、擦除(1e81d6f9/abbfd121)

**依赖链**：角括号内的标记像素颜色决定哪些矩形遮挡物需要被移除并恢复底层周期图案；未被选中颜色的遮挡物必须原样保留。不读取标记颜色就不知道恢复哪些遮挡物；不执行周期图案推断就无法恢复被遮挡区域的内容。

读取角括号内标记像素的颜色，仅移除该颜色的矩形遮挡物并用推断出的周期平铺图案填补，其余遮挡物和角括号本身均保留。

**输入结构**：约 15x15 的网格。背景是一个行列周期为 2~3 的小图案平铺（使用蓝(1)和青(8)两色交替）。网格上散布 3~5 个不同颜色的实心矩形遮挡物（每个遮挡物为单色，颜色各不相同，使用红(2)、绿(3)、黄(4)、橙(7)中的若干种；每个遮挡物宽高均>=2，互不重叠，完全覆盖其下的周期图案）。网格中有一个灰(5)像素构成的单色 4-连通角括号对象（L形，3~4像素，开口朝向不定），角括号的包围盒内部（不含角括号自身像素）恰好有一个前景标记像素，该标记像素的颜色与某一种遮挡物颜色相同。角括号位于不被任何遮挡物覆盖的区域。

**规则**：
1. 找到灰(5)角括号对象，读取其包围盒内部非灰非背景图案色的那一个标记像素的颜色，记为 C。
2. 从网格中所有未被遮挡的区域（不含遮挡物和角括号区域）推断周期平铺图案的最小重复单元。
3. 找到所有颜色为 C 的矩形遮挡物，将其每个像素替换为该位置对应的周期图案颜色。
4. 颜色不为 C 的遮挡物像素保持原样不变。
5. 角括号和标记像素保持原样不变。

**关键洞察**：角括号不再是"擦除指令"而是"恢复指令"——它指定的颜色不是要从全局删除的颜色，而是要揭开的遮挡层；求解者必须对比多个示例才能发现标记颜色与被恢复遮挡物颜色的对应关系，因为仅凭单个示例可能误以为是按位置或面积选择遮挡物。

## 新题 3：字形解码驱动空心矩形定向拉伸

**组合逻辑**：[字形图案→解码](来自995c5fa3，创新：解码结果不映射为颜色行，而映射为拉伸方向) + [位置映射](来自995c5fa3，创新：字形相对于矩形的方位决定拉伸作用的边) → [拉伸+重绘](来自b548a754/baf41dbf，创新：拉伸量由解码值决定而非由标记点位置决定)

**来源原语**：字形图案/解码/位置映射(995c5fa3)、拉伸/重绘/空心矩形(b548a754/baf41dbf)、包围盒(e74e1818)

**依赖链**：字形解码得到拉伸量（1~4格），字形相对于矩形的方位（上/下/左/右）决定拉伸的边，两者共同确定拉伸参数。不解码则不知拉伸多远；不判断方位则不知拉伸哪条边。

解码空心矩形四周的灰色字形块，获得拉伸量，再根据字形相对于矩形的方位确定拉伸方向，将矩形的对应边向外推移相应格数并重绘。

**输入结构**：约 18x18 的黑(0)背景网格。中心区域有一个红(2)边框、黄(4)内部的空心矩形（边框宽1像素，内部至少 3x3）。矩形的上方、下方、左方、右方各有 0 或 1 个灰(5)/黑(0)组成的 3x3 字形块（灰为底色，黑像素构成掩码图案）。共出现 2~4 个字形块。每个字形块的掩码图案是四种预定义图案之一，分别编码拉伸量 1、2、3、4（图案定义：全灰无黑=1；中心一个黑像素=2；中心行三个黑像素=3；四角各一个黑像素=4）。每个字形块与矩形的最短轴向距离为 1~2 格，且其中心与矩形的对应边中点在该边的垂直方向上对齐（允许+-1像素偏移）。不存在两个字形块位于矩形同一侧的情况。

**规则**：
1. 找到红(2)边框的空心矩形，记录其上、下、左、右四条边的位置。
2. 找到所有 3x3 灰(5)字形块。对每个字形块，根据其黑色掩码图案解码得到拉伸量 D（全灰=1，中心黑=2，中心行三黑=3，四角黑=4）。
3. 判断每个字形块相对于矩形的方位：字形块中心在矩形包围盒上方→控制上边；下方→控制下边；左方→控制左边；右方→控制右边。
4. 对每条被控制的边，向外移动 D 格（上边向上、下边向下、左边向左、右边向右）。未被任何字形块控制的边保持原位。
5. 用红(2)重绘扩展后矩形的边框（宽度仍为1像素），内部填充黄(4），矩形外部为黑(0)背景。字形块在输出中被擦除（变为黑(0)背景）。

**关键洞察**：字形块既是方向指示器（通过空间位置）又是数值编码器（通过掩码图案），两层信息缺一不可；求解者必须对比多个示例中不同掩码与不同拉伸量的对应关系，才能归纳出编码规则。

## 新题 4：封闭孔洞计数决定镜像轴向与半区重涂

**组合逻辑**：[洪泛填充→封闭区域检测→计数](来自00d62c1b+b0c4d837，创新：计数的不是液面高度而是封闭孔洞数量) → [计数奇偶→决定镜像轴](创新的条件分支：奇数→垂直镜像，偶数→水平镜像) → [包围盒内镜像](来自e74e1818) + [半区重涂色](来自e7dd8335，创新：半区的切分方向随镜像轴联动)

**来源原语**：洪泛填充/封闭区域/拓扑内外(00d62c1b)、计数(b0c4d837)、镜像/包围盒/逐色独立变换(e74e1818)、半区/重涂色(e7dd8335)

**依赖链**：必须先用拓扑分析找到每个前景对象内部的封闭孔洞并计数；计数的奇偶性决定镜像轴方向；镜像结果再按对应方向的半区进行重涂。三个环节形成链式依赖：删除计数则无法确定镜像轴，删除镜像则半区重涂无意义，删除半区重涂则输出与纯镜像无法区分（需多示例对比才能发现重涂规则）。

对每个前景对象，统计其内部封闭孔洞的数量；孔洞数为奇数时垂直镜像该对象并将下半区重涂为红色，孔洞数为偶数（含零）时水平镜像该对象并将右半区重涂为红色。

**输入结构**：约 20x20 的黑(0)背景网格。散布 2~4 个互不相邻的蓝(1)前景对象（各为一个 4-连通的单色像素集合，每个对象 10~25 像素，包围盒的高和宽均为偶数）。部分对象内部存在被蓝色像素完全包围的黑色孔洞（4-连通封闭的黑色连通域，不与外部背景相通），每个对象的孔洞数为 0~3 个（每个孔洞 1~4 像素）。不同对象的孔洞数不完全相同（至少有一个奇数和一个偶数，以保证两种镜像轴都出现）。

**规则**：
1. 对每个蓝(1)前景对象独立处理（按包围盒左上角行优先、列次优先的顺序逐个处理）：
   a. 用洪泛填充从对象包围盒外部标记所有与外部4-连通相通的黑色像素，剩余的黑色像素即为该对象内部的封闭孔洞。统计孔洞的连通域个数 H。
   b. 若 H 为奇数：在该对象的包围盒内，将所有蓝(1)像素关于包围盒的水平中线做垂直镜像（像素列坐标不变，行坐标 r 映射为 r0+r1-r，其中 r0、r1 为包围盒的顶行和底行）。镜像后，包围盒上半区（顶行到中线，不含中线以下）的蓝色像素保持蓝(1)，下半区（中线及以下）的蓝色像素重涂为红(2)。
   c. 若 H 为偶数（含 0）：在该对象的包围盒内，将所有蓝(1)像素关于包围盒的垂直中线做水平镜像（像素行坐标不变，列坐标 c 映射为 c0+c1-c，其中 c0、c1 为包围盒的左列和右列）。镜像后，包围盒左半区（左列到中线，不含中线右侧）的蓝色像素保持蓝(1)，右半区（中线列及右侧）的蓝色像素重涂为红(2)。
2. 背景像素和孔洞像素在输出中均为黑(0)。

**关键洞察**：孔洞数量不直接出现在输出中，它仅通过奇偶性隐式地控制镜像方向和重涂分割线——求解者必须对比多个对象在不同示例中的变换方式，才能归纳出孔洞计数→奇偶→轴向的隐藏逻辑。

## 新题 5：图层合成后按频率排序输出色条

**组合逻辑**：[透明叠加+图层优先级](来自6a11f6da，保留三层合成逻辑) → [计数+频率统计+排序](来自81c0276b，创新：频率统计的对象不是预设表格中的色块，而是合成后的像素)

**来源原语**：透明叠加/等高面板/图层优先级/底层最优先(6a11f6da)、计数/排序/频率统计/按计数升序(81c0276b)

**依赖链**：三面板合成决定每个位置的最终颜色（图层冲突由优先级规则解决），合成结果改变了各颜色的像素频率分布，频率统计和排序必须基于合成后的结果。不做合成则频率分布不确定；不做排序则输出格式不确定。

将三个等高面板按图层优先级合成为一个面板，统计合成结果中每种非背景色的像素数量，输出按数量升序排列的左对齐色条。

**输入结构**：约 15x9 的网格（宽15、高9）。黑(0)背景上纵向排列三个等高面板（每个面板高3行、宽与网格同宽），面板之间无间隔。每个面板内包含若干非背景色像素（每个面板使用 1~2 种前景色，从红(2)、绿(3)、蓝(1)、黄(4)、橙(7)中选取；不同面板可使用相同颜色）。三个面板中各颜色的像素位置存在部分重叠（即同一列同一相对行位置在多个面板中都有非背景像素）。生成约束：合成后至少出现 3 种不同的非背景色，且各颜色的像素计数互不相同（避免排序歧义）。

**规则**：
1. 将三个面板视为从上到下分别为顶层面板、中层面板、底层面板，每个面板高 3 行。
2. 合成规则：从中层面板开始作为基底，将顶层面板的每个非黑像素覆盖到相同相对位置上，再将底层面板的每个非黑像素覆盖到相同相对位置上（底层优先级最高，最后覆盖）。合成结果为一个 3 行 x 宽的面板。
3. 统计合成面板中每种非黑(0)颜色的像素总数。
4. 按像素总数从小到大排序。输出网格的行数等于颜色种数，列数等于最大像素计数。第 i 行（从上到下，i=0 为最少的颜色）为第 i 种颜色的左对齐色条（前 count 列为该颜色，其余列为黑(0)）。

**关键洞察**：频率统计的输入不是直接可见的——三个面板中同一位置可能有不同颜色的像素相互覆盖，合成优先级改变了最终的颜色分布，求解者不能简单地数每种颜色在输入中出现了多少次。

## 新题 6：图例指导半区条件重涂

**组合逻辑**：[微型图例→颜色替换映射](来自e9b4f6fc，保留图例读取逻辑) + [裁剪](来自e9b4f6fc) → [半区+重涂色](来自e7dd8335，创新：重涂不是统一变红，而是按图例映射变色，且仅作用于下半区)

**来源原语**：微型图例/颜色替换映射/裁剪(e9b4f6fc)、半区/重涂色/包围盒(e7dd8335)

**依赖链**：图例提供颜色映射规则但不指定作用区域；半区规则限定映射仅在下半区生效。不读取图例则不知道怎么重涂；不应用半区约束则整个对象都会被重涂（与原题 e9b4f6fc 无法区分）。求解者必须对比多个示例发现上半区不变、下半区才应用图例替换。

裁剪多色目标对象，按图例的颜色映射仅对下半区执行颜色替换，上半区保持原色不变。

**输入结构**：约 14x14 的黑(0)背景网格。一个多色矩形目标对象（由 2~3 种非背景色构成，如蓝(1)和绿(3)，包围盒高度为偶数，宽 4~7、高 4~8），位于网格中央偏左。1~2 个水平二像素图例色块（domino）散布在目标对象的右侧或下方，与目标对象不相邻（至少间隔2格）。每个图例 domino 的右像素颜色出现在目标对象中，左像素颜色不出现在未替换的目标对象中。生成约束：各图例 domino 的右像素颜色互不相同；图例映射关系在上半区和下半区都有可替换像素（以使半区限制效果可观测）。

**规则**：
1. 找到多色矩形目标对象，裁剪其包围盒区域作为输出基底。
2. 读取每个图例 domino：左像素为替换色 R，右像素为源色 S，构成映射 S→R。
3. 计算裁剪区域包围盒的水平中线：中线位于第 H/2 行（H为包围盒高度，0-indexed，即中线以上为行 0 到 H/2-1，中线及以下为行 H/2 到 H-1）。
4. 对裁剪区域的下半区（行 H/2 到 H-1）中的每个像素：若其颜色为某映射的源色 S，则替换为对应的 R。
5. 上半区（行 0 到 H/2-1）的所有像素保持原样。

**关键洞察**：图例映射在全对象范围内都是合法的，但变换只在下半区生效——这一空间限制在单个示例中可能被误解为"只有下半区碰巧有该颜色"，需要对比多个示例（上半区也有该颜色但未被替换）才能确认规则。

## 新题 7：格子结构中对角周期填色与边缘覆写

**组合逻辑**：[格子结构→单元格阵列位置](来自8a371977) + [对角线同余→周期填色](来自c3f564a4，创新：周期填色的单位不是像素而是格子单元格) → [边缘与内部区分→边缘覆写](来自8a371977，创新：边缘单元格不是简单变红，而是覆写为特定颜色，与对角周期色不同)

**来源原语**：格子结构/单元格区域/行列阵列位置/边缘与内部区分(8a371977)、对角周期图案/对角线同余/补全(c3f564a4)、重涂色(c8f0f002)

**依赖链**：格子结构确定单元格的行列阵列坐标；对角线同余规则（行索引+列索引）mod K 为每个内部单元格指定颜色；边缘/内部区分决定哪些单元格按对角周期涂色、哪些按边缘规则覆写。三个环节各自提供不可替代的信息。

在格子结构划分的单元格阵列中，内部单元格按对角线同余规则循环涂色，边缘单元格统一涂为灰色。

**输入结构**：约 17x17 的网格。栗(9)像素构成格子结构（lattice）：栗色填满外边框的一行/一列，并在内部形成等间距的行条和列条（每条宽1像素），将网格分割为至少 4x4 的单元格矩形阵列（每个单元格为 2x2 或 3x3 的等大矩形区域）。部分单元格已被填充为非背景色（从蓝(1)、红(2)、绿(3)、黄(4)中选取），部分单元格仍为黑(0)。已填充的单元格均位于阵列的内部位置（非边缘行/列），且其颜色符合对角线同余规则：设单元格在阵列中的行索引为 r、列索引为 c（均从 0 开始），令 K 为使用的前景色种数（K=3 或 4），颜色按 (r+c) mod K 映射到一个固定的颜色序列。部分内部单元格的颜色被替换为黑(0)（作为需要补全的"空洞"）。所有边缘单元格（阵列第一行/最后一行/第一列/最后一列的单元格）均为黑(0)。

**规则**：
1. 识别栗(9)格子结构，确定单元格阵列的行数 R 和列数 C，以及每个单元格的阵列坐标 (r, c)。
2. 从已着色的内部单元格推断对角线同余映射：确定颜色种数 K 和 (r+c) mod K 到颜色的映射表。
3. 对每个内部单元格（1 <= r <= R-2, 1 <= c <= C-2）：若为黑(0)，则根据 (r+c) mod K 查表填充对应颜色。若已有颜色，保持不变。
4. 对每个边缘单元格（r=0 或 r=R-1 或 c=0 或 c=C-1）：统一填充为灰(5)。
5. 栗(9)格子像素保持不变。

**关键洞察**：内部单元格的涂色规则是对角线同余（而非行列独立），但边缘单元格被统一覆写为灰色，打破了对角周期——求解者需对比多个示例，分离"边缘覆写"和"对角周期"两条并行规则。

## 新题 8：精灵体旋转匹配嵌入后按面积排序输出

**组合逻辑**：[精灵体+孔洞+形状匹配+旋转→拼合](来自97a05b5b，保留旋转匹配嵌入逻辑) → [计数各孔洞面积+排序](来自81c0276b，创新：排序的不是颜色频率而是嵌入后各孔洞区域的面积) → [裁剪+生成网格](来自7039b2d7，创新：输出不是均匀色网格而是按面积排序的精灵体裁剪行)

**来源原语**：精灵体/孔洞/形状匹配/旋转/拼合/裁剪(97a05b5b)、计数/排序/频率统计(81c0276b)、生成网格(7039b2d7)

**依赖链**：必须先完成形状匹配和旋转才能确定每块精灵体嵌入哪个孔洞；嵌入后每个孔洞区域的面积（=精灵体像素数）决定排序顺序；裁剪和排列依赖排序结果。三个阶段层层依赖。

将多色精灵体旋转匹配嵌入红色对象的孔洞中，然后按各精灵体的像素面积从小到大裁剪输出为纵向排列的行。

**输入结构**：约 20x20 的黑(0)背景网格。一个红(2)大对象位于网格左侧或中央（4-连通，约 40~60 像素），内部有 2~4 个黑(0)孔洞（每个孔洞为一个 4-连通的黑色连通域，面积 3~8 像素，完全被红色像素包围，各孔洞形状互不相同且面积互不相同）。网格右侧或下方散布 2~4 个多色精灵体（每个精灵体由 1~2 种非红非黑颜色构成，如蓝(1)、绿(3)、黄(4)、橙(7)；精灵体之间互不相邻，且与红色对象不相邻）。每个精灵体的形状经过 0/90/180/270 度旋转后恰好与某一个孔洞形状匹配（像素位置一一对应），精灵体与孔洞之间一一对应。

**规则**：
1. 找到红(2)对象中的所有黑(0)孔洞，记录每个孔洞的形状（相对像素坐标集合）和面积（像素数）。
2. 找到所有散布在外的多色精灵体。对每个精灵体，尝试 0/90/180/270 度旋转，找到与某孔洞形状匹配的旋转方式和对应孔洞。
3. 将每个精灵体按匹配的旋转方式旋转后，记录其颜色像素。
4. 按孔洞面积从小到大排序所有已匹配的精灵体。
5. 输出网格：计算所有精灵体包围盒的最大宽度 W；输出高度为所有精灵体包围盒高度之和，宽度为 W。从上到下依次放置每个精灵体（已旋转）的裁剪包围盒，左对齐，右侧空余部分填充黑(0)。精灵体之间无间隔行。

**关键洞察**：输出的排列顺序不由精灵体在输入中的空间位置决定，也不由精灵体自身颜色决定，而由其匹配孔洞的面积决定——求解者必须先完成形状匹配才能确定排序键。

## 新题 9：分隔面板图案交换后逐色包围盒内镜像

**组合逻辑**：[分隔面板+图案掩码→成对交换+底色涂色](来自5a719d11，保留掩码交换和底色重涂逻辑) → [逐色独立变换→包围盒内垂直镜像](来自e74e1818，创新：镜像的对象不是原始前景掩码而是交换后的掩码)

**来源原语**：分隔面板/图案掩码/成对交换/底色作为涂色源(5a719d11)、镜像/单色掩码/包围盒/逐色独立变换/包围盒内翻转(e74e1818)

**依赖链**：交换改变了每个面板中图案掩码的形状和颜色，镜像必须基于交换后的结果执行。不做交换则镜像对象错误；不做镜像则输出与单纯交换无法区分（需多示例确认存在镜像步骤）。

在两个分隔面板之间交换图案掩码（用各自底色重涂），然后对交换结果中的每种非背景色掩码在其自身包围盒内做垂直镜像。

**输入结构**：约 12x20 的网格（高12、宽20）。灰(5)像素构成分隔结构：一条灰色满列将网格分为左右两个等大面板（每个面板约 12x9）。每个面板有一个占据大部分面积的底色（左面板底色为蓝(1)，右面板底色为绿(3)）和一种少数派图案色（左面板图案色为红(2)，右面板图案色为黄(4)）。图案色像素构成一个 4-连通的掩码形状（5~12像素，非矩形，非垂直对称，以使镜像效果可观测）。每个面板中其余非灰像素均为该面板的底色。

**规则**：
1. 识别灰(5)分隔列，将网格分为左面板和右面板。
2. 对每个面板，确定底色（占多数的非灰颜色）和图案掩码（少数派颜色像素的相对坐标集合）。
3. 交换：将左面板清空为蓝(1)底色，在对应位置绘制右面板的图案掩码形状，颜色使用右面板底色绿(3)。将右面板清空为绿(3)底色，在对应位置绘制左面板的图案掩码形状，颜色使用左面板底色蓝(1)。
4. 对交换后的结果，对每种非灰非底色的颜色掩码独立处理：找到该颜色所有像素的包围盒，将每个像素的行坐标 r 映射为 r0+r1-r（r0、r1 为该颜色包围盒的顶行和底行），列坐标不变。
5. 灰(5)分隔像素保持不变。

**关键洞察**：交换后左面板出现的绿(3)掩码和右面板出现的蓝(1)掩码分别是对方的原始图案形状，但经过垂直镜像后形状发生了上下翻转——求解者仅凭单个示例可能无法判断是"交换后镜像"还是"镜像后交换"（两者结果不同），需要对比多个示例中镜像前后包围盒位置的一致性来确定操作顺序。

## 新题 10：U形框架液面高度编码为分区数网格

**组合逻辑**：[U形框架+内部包含→计数空行](来自b0c4d837，保留液面高度读取) → [空行数→生成分隔线网格](来自7039b2d7+272f95fa，创新：空行数不映射为螺旋填充量，而决定生成网格的分区维度) + [分区→十字位固定涂色](来自272f95fa，保留十字位涂色逻辑)

**来源原语**：U形框架/内部包含/空行数映射填充量(b0c4d837)、计数(b0c4d837)、分隔线/分区区域/网格分区/十字位固定涂色(272f95fa)、生成网格/分区数决定尺寸(7039b2d7)

**依赖链**：U形框架的液面空行数 N 决定输出分区网格的维度（NxN 的单元格阵列）；分区网格建立后才能应用十字位固定涂色。不读取液面高度则分区维度不确定；不做十字位涂色则输出仅是空白网格（丢失了涂色信息）。

读取 U 形框架内的空行数 N，生成一个 NxN 单元格的分区网格，并将其十字位（上中、左中、中心、右中、下中）的单元格按固定颜色填充。

**输入结构**：约 10x6 的黑(0)背景网格。一个橙(7)像素构成的 U 形框架（宽3~5列、高6~8行，顶部开口，三面封闭，壁厚1像素），框架内底部有若干行被青(8)像素填充（表示液面，青色像素从框架底部连续向上填充若干行），液面上方的框架内部行为黑(0)空行。生成约束：空行数 N 的取值为 3、4 或 5（以保证 NxN 网格至少 3x3，十字位涂色规则可完整应用）。

**规则**：
1. 找到橙(7)U 形框架，确定其内部列范围和行范围。
2. 在内部区域中，从顶部向下数，统计连续黑(0)空行的数量，记为 N。
3. 生成一个 (N*2+1) x (N*2+1) 的输出网格（每个单元格占 1x1 像素，单元格之间有1像素宽的栗(9)分隔线，最外圈也有栗(9)边框），形成 NxN 的单元格阵列。所有单元格初始化为黑(0)。
4. 对 NxN 阵列的十字位单元格进行固定涂色（阵列坐标从 0 开始，中心行 M=floor(N/2)，中心列 M=floor(N/2)）：
   - 上中 (0, M)：红(2)
   - 左中 (M, 0)：黄(4)
   - 中心 (M, M)：品红(6)
   - 右中 (M, N-1)：绿(3)
   - 下中 (N-1, M)：蓝(1)
5. 其余单元格保持黑(0)。栗(9)分隔线保持不变。

**关键洞察**：U 形框架的空行数并不直接出现在输出中——它被编码为输出网格的维度，而输出网格中的颜色信息完全由固定的十字位规则决定；求解者必须同时归纳出维度映射和涂色模式两条独立但都必需的规则。
