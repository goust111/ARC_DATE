## 新题 1：模板蒙版筛选坐标编码瓦片

**组合逻辑**：[补全(completion)] + [降采样(downsample) → 掩码裁剪(mask_crop)]（补全产出完整瓦片阵列，降采样将单色模板缩放到阵列尺度后作为蒙版，两条路径在蒙版筛选处汇合）

**来源原语**：补全、瓦片阵列、位置孔洞、孔洞位置等于坐标 ← 9ddd00f0；降采样、掩码裁剪、单色图案、整数缩放对应 ← 6ecd11f4

**依赖链**：位置孔洞编码规则决定缺失瓦片的内容（补全）→ 单色模板的尺度必须恰好整数缩放到瓦片阵列的行列数（整数缩放对应）→ 降采样后的二值蒙版逐瓦片决定保留或清除（掩码裁剪）。不完成补全，蒙版作用在不完整阵列上会丢失信息；不降采样模板，无法得到与阵列等尺寸的蒙版。

将一个由坐标孔洞编码的不完整瓦片阵列先补全，再用一个整数缩放的单色模板降采样为蒙版，保留蒙版前景处的瓦片、清除蒙版背景处的瓦片。

**输入结构**：约 15×15 的网格。背景色为黑(0)，前景色为蓝(1)。
- 网格被单像素宽的黑(0)分隔行和分隔列划分为 n×n（n=3 或 4）的瓦片阵列，每个瓦片也是 n×n 像素。总边长为 n*n + n - 1。
- 部分瓦片已填入：瓦片内所有像素为蓝(1)，仅位于本瓦片阵列坐标 (tile_row, tile_col) 处的那个像素保持黑(0)——即"位置孔洞"。其余瓦片完全为黑(0)（缺失）。已填入的瓦片至少有 3 个，保证足以归纳孔洞编码规则。
- 在阵列的右侧或下方，隔至少 2 列/行黑(0)背景，放置一个单色图案对象：用红(2)像素在黑(0)背景上构成一个 8-连通图形。该图形的边界框面积恰好是 n×n 的某个完全平方数倍（如 (2n)×(2n) 或 (3n)×(3n)），使其可整数降采样到 n×n。图形中红(2)像素分布不规则，降采样后在 n×n 分辨率上约有一半位置为前景、一半为背景。
- 生成约束：缺失瓦片中至少有一个在降采样后蒙版为前景处（即补全后仍需保留），也至少有一个在蒙版为背景处（即补全后仍会被清除），以保证两个步骤都不可省略。

**规则**：
1. 补全所有缺失瓦片：对于阵列中每个瓦片位置 (r, c)（0-索引），将该瓦片的所有像素填为蓝(1)，然后将瓦片内本地坐标 (r, c) 处的像素设为黑(0)。分隔行列保持黑(0)不变。
2. 将红(2)单色图案对象裁剪到其边界框，然后按整数因子降采样到 n×n 分辨率：降采样时，每个 k×k 块（k 为缩放因子）只要包含至少一个红(2)像素，则该位置为前景；否则为背景。
3. 用降采样结果作为蒙版逐瓦片筛选：蒙版第 (r, c) 个位置为前景时，保留阵列中 (r, c) 处的完整瓦片及其相邻分隔行列不变；蒙版第 (r, c) 个位置为背景时，将该瓦片的所有像素清为黑(0)。分隔行列本身始终保持黑(0)。
4. 红(2)单色图案对象在输出中被清除为黑(0)（不出现在输出里）。

**关键洞察**：模板不是直接叠加在瓦片阵列上的——它必须先经过整数降采样才能与阵列对齐，而瓦片必须先补全才能被有意义地筛选。两个独立输入元素通过"尺寸匹配"这一隐含约束联结。

## 新题 2：压缩伪装网格后角标投票染色

**组合逻辑**：[去重/压缩(deduplicate/compress)]（改变网格拓扑）→ [重涂色(recolor)]（依据压缩后的角标投票）。压缩改变了哪些像素是"角"，投票结果完全依赖压缩后的结构。

**来源原语**：压缩、去重、相邻重复、合并相同行列 ← e1baa8a4；重涂色、分隔网格、顶点标记、角标一致性、四角同色定区域色 ← 7837ac64

**依赖链**：相邻重复行列的存在使得直接在输入上做角标投票会得到错误的区域邻接关系 → 必须先去重压缩到规范网格 → 压缩后的分隔网格才能正确标定区域边界和角标位置 → 角标投票决定区域颜色。

将一个被行列重复膨胀的分隔网格先压缩回规范尺寸，再根据每个区域四角顶点标记是否同色来决定区域填色。

**输入结构**：约 14×14 的网格（压缩后约 7×7）。
- 灰(5)分隔线把网格分成若干矩形区域，区域内部为黑(0)。
- 部分区域的四个对角交叉点处各有一个非灰(5)非黑(0)的小像素（顶点标记），颜色为红(2)、绿(3)、蓝(1)或黄(4)之一。一个区域如果四角标记全部存在且颜色相同，称为"一致区域"。
- 整张网格沿行和列方向做了若干次整行/整列复制：某些相邻行像素完全相同，某些相邻列像素完全相同——使原本 7×7 的网格膨胀到约 14×14。复制的行列分布不均匀且在不同示例中不同，因此不能靠固定比例推测。
- 生成约束：至少存在 2 个一致区域和 1 个非一致区域（某些角标缺失或颜色不统一），以保证投票规则有区分度。膨胀前每个区域至少 2×2 像素（不含分隔线），保证存在独立的角标位置。

**规则**：
1. 压缩网格：找到所有相邻完全相同的行组，每组只保留第一行；找到所有相邻完全相同的列组，每组只保留第一列。行压缩和列压缩独立执行，最终得到规范网格。
2. 在规范网格中识别灰(5)分隔线围成的矩形区域。
3. 对每个区域，检查其四个对角像素（即与区域共享角的分隔线交叉点的四个对角方向邻居中落在区域角上的像素）。若四个角标全部存在且颜色相同，则将整个区域填充为该颜色。
4. 若四角标记不全存在或颜色不一致，区域保持黑(0)。
5. 灰(5)分隔线在输出中保持不变。

**关键洞察**：行列重复使输入网格中"角"的位置被复制和移位，直接在膨胀网格上做投票会把复制出来的行列误认为独立区域的边界。必须先压缩才能恢复真实的区域拓扑。

## 新题 3：种子射线穿墙反射入框

**组合逻辑**：[射线延伸(ray_extend)]（种子向框射线）→ [镜像/反射(mirror)]（穿过框壁后方向翻转继续延伸）。框壁同时充当射线终点和反射面，一个几何元素承担双重角色。

**来源原语**：射线延伸、种子像素、种子色决定延伸、边缘指示方向 ← 178fcbfb, 8886d717；镜像、空心矩形、最近邻归属、跨框中线反射入内 ← 6855a6e4

**依赖链**：最近邻归属决定种子属于哪个框 → 种子与框壁的相对位置决定射线的初始方向（边缘指示方向）→ 射线到达框壁后反射入框（镜像），反射方向由撞击的壁面朝向决定 → 框内反射段的颜色使用种子原色，框外段使用灰(5)。删除任一环节：无归属则射线无目标；无反射则射线止于框壁（退化为简单延伸）；无颜色切换则无法区分内外段。

种子像素向其最近的空心矩形框射出灰色射线，射线撞击框壁后以反射方向穿入框内，用种子原色继续延伸直到对面墙壁。

**输入结构**：约 18×18 的黑(0)背景网格。
- 2~3 个空心矩形框，每个框由红(2)像素构成单像素宽的闭合矩形环。框的尺寸各异（短边 4~7 像素），框之间互不重叠且至少间隔 3 个像素。
- 框外散布 3~5 个单像素种子，颜色为绿(3)、蓝(1)或黄(4)（不使用红(2)以免与框混淆）。每个种子与其最近框的某条框壁严格同行或同列对齐（即种子与该框壁之间的连线是水平或垂直的），且种子到最近框之间没有其他框或种子阻挡。
- 生成约束：每个框至少接收一个种子的射线；不同种子的反射段在框内不相交（保证无冲突）。

**规则**：
1. 对每个种子，计算到每个框的曼哈顿距离（种子到框上最近像素的距离），将种子分配给最近的框。距离相同时分配给边界框左上角行号更小的框；仍相同则列号更小的框。
2. 种子沿与其对齐的框壁方向射出射线（若种子与框的某水平壁同行，则水平射向框；若与竖直壁同列，则竖直射向框）。射线从种子出发，逐像素延伸，到达框壁外侧的前一个像素为止。这一段（种子到框壁外侧）涂为灰(5)，种子本身保持原色不变。
3. 射线穿过框壁进入框内后方向翻转 90°：若射线水平到达竖直壁，则在壁内侧像素处转为竖直方向（朝框内部中心方向）继续延伸；若射线竖直到达水平壁，则在壁内侧像素处转为水平方向（朝框内部中心方向）继续延伸。框内段逐像素涂为种子的原始颜色，延伸直到碰到对面框壁（含框壁像素本身则停止，不覆盖框壁像素）。
4. 框壁（红(2)像素）在输出中保持不变。
5. 若反射方向存在歧义（种子对齐于框的角点），则按顺时针方向选择反射方向（即从撞击点顺时针旋转 90° 的方向）。

**关键洞察**：框壁不仅是射线的终止障碍物，更是改变射线方向的反射面。外段灰色和内段彩色的颜色切换是判断求解者是否理解"穿墙反射"的关键线索——仅看一个示例可能误以为是两段独立射线，必须对比多例才能发现反射规律。

## 新题 4：双重计数驱动的精灵选取与缩放

**组合逻辑**：[计数(counting)·类型数] → [像素放大(pixel_upscale)]（类型数做倍率） ＋ [计数(counting)·实例频率] → [裁剪(crop)]（最高频类型做选取对象）。两次计数作用于同一数据集但提取正交信息，交汇于输出。

**来源原语**：计数、裁剪、精灵体、形状相同、最高频精灵输出 ← 39a8645d；像素放大、前景色数定倍率、编码映射 ← b91ae062

**依赖链**：形状+颜色 → 精灵类型划分 → 类型计数得到 K（放大倍率） ＋ 实例计数得到最高频类型 T → 选取 T 的一个实例裁剪到 3×3 → 以 K 为倍率像素放大 → 输出。K 和 T 来自同一精灵种群的不同统计维度。

对网格中的多色小精灵做两种计数：不同类型的总数 K 决定缩放倍率，每种类型的实例数决定选哪个类型；输出为最高频类型放大 K 倍。

**输入结构**：约 15×15 的黑(0)背景网格。
- 散布 8~15 个小精灵，每个精灵为单色的 8-连通前景体，边界框为 3×3。精灵颜色来自 {蓝(1), 红(2), 绿(3), 黄(4), 灰(5)}。
- 精灵的"类型"由形状（3×3 边界框内的前景掩码）和颜色共同定义。相同形状但不同颜色视为不同类型。
- 存在至少 3 种不同类型（K ≥ 3），且恰好有一种类型的实例数严格最多。
- 精灵之间至少间隔 1 个像素（边界框不相邻），保证 8-连通分量识别无歧义。
- 生成约束：K ≤ 5（保证输出尺寸合理，最大 15×15）。

**规则**：
1. 提取所有 8-连通前景体，将每个裁剪到 3×3 边界框，得到其掩码和颜色。掩码+颜色共同定义精灵类型。
2. 统计不同精灵类型的数量 K。
3. 统计每种类型的出现次数，选择出现次数严格最多的那种类型 T（唯一最高频）。
4. 取类型 T 的任意一个实例的 3×3 掩码（所有实例掩码相同）。
5. 将该 3×3 掩码以倍率 K 进行像素放大：每个像素变为 K×K 的同色块。输出网格大小为 3K × 3K。

**关键洞察**：同一组精灵上进行两种不同维度的计数——"有多少种"决定缩放比例，"哪种最多"决定被选对象。输出同时编码了种群多样性（通过尺寸）和种群优势（通过形状），两者缺一不可。

## 新题 5：字形路径解码划分区域后种子染色

**组合逻辑**：[解码(decode)]（字形 → 路径边界）→ [填充(fill)]（种子像素决定区域颜色），路径拓扑决定区域划分，种子位置决定颜色归属，颜色映射增加隐蔽规则层。

**来源原语**：解码、字形、起点标记、弯头决定偏移 ← e6de6e8f；填充、画布、最高频色覆盖全图 ← 5582e5ca（填充概念）；标记色决定描边色（颜色配对映射）← 913fb3ed

**依赖链**：字形序列 → 解码为红色路径线 → 路径将网格划分为若干 4-连通背景区域 → 种子像素落在特定区域内 → 种子颜色经配对映射后确定该区域的填充色。删除解码则区域未定义；删除种子则颜色未定义；删除颜色映射则输出颜色错误。

将两行红色字形条解码为一条折线路径，该路径把输出网格分割成若干区域，再由散布的种子像素经颜色配对映射为各区域染色。

**输入结构**：网格分为上下两个区域，中间隔 2 行黑(0)。
- 上区域（2 行）：红(2)字形编码条。字形从左到右排列，每个字形占据两行。竖直字形：上下两格均为红(2)，位于同一列。弯头字形：占据 2×2 区域中的 3 格，缺失的那个上行格指示弯转方向（缺左上则右转，缺右上则左转）。字形数量 4~7 个。
- 下区域（约 8 列宽）：一列黑(0)空白网格，高度等于字形数量加 2。在这片空白的第一行正中放置一个绿(3)起点标记。另外在此区域的空白处散布 2~3 个单像素种子，颜色为蓝(1)、黄(4)或灰(5)。种子位于路径解码后会形成的不同区域内（生成时确保）。
- 生成约束：路径解码后恰好将下区域分割为种子数 +1 个 4-连通背景区域（其中一个区域无种子），每个有种子的区域恰好包含一个种子。

**规则**：
1. 解码字形条：创建一个宽度为字形条宽度一半加一、高度为字形数量加 2 的黑(0)输出网格。在第一行的中间列放置绿(3)起点标记。
2. 从起点标记正下方开始，逐字形向下追踪路径：竖直字形在当前列画两个红(2)像素（向下两行）；弯头字形画一个红(2)像素后水平移动一格（左或右取决于弯头方向），再画一个红(2)像素。
3. 路径画完后，识别输出网格中所有 4-连通黑(0)背景区域（不含路径像素和起点标记）。
4. 将种子像素放置到输出网格中对应的位置（根据输入下区域中种子的相对坐标映射到输出网格）。
5. 对每个包含种子的区域，将该区域所有黑(0)像素填充为种子颜色的配对色：蓝(1) → 红(2)，黄(4) → 品红(6)，灰(5) → 栗(9)。种子像素本身保持原色。
6. 不含种子的区域保持黑(0)。路径像素（红(2)）和起点标记（绿(3)）保持不变。

**关键洞察**：字形编码的是分隔边界而非填充区域——求解者需要理解字形是"墙壁指令"。而种子的颜色不直接出现在填充中，必须经过一层颜色配对映射，这只有对比多个示例后才能归纳。

## 新题 6：缺陷双重编码——修复外观并指引位移方向

**组合逻辑**：[修补(repair)]（缺陷像素归色）＋ [计数(counting) → 编码映射(encoding_map)]（缺陷数编码方向）→ [平移(translate)]（自身高度为距离，编码方向为朝向）。缺陷像素同时是需要修复的噪声和编码位移方向的信号，一物两用。

**来源原语**：修补、主体对象、标记像素、嵌入与孤立 ← 8886d717；平移、实心矩形、移动自身高度、无重叠间距 ← 5521c0d9；编码映射 ← b91ae062

**依赖链**：识别矩形中的缺陷像素 → 修复（重涂为矩形主色）→ 同时计数缺陷个数 → 个数模 4 编码位移方向（0=上, 1=右, 2=下, 3=左）→ 以矩形自身高度为距离沿编码方向平移已修复的矩形。不修复则外观错误且无法正确计数（因为缺陷定义依赖嵌入判断）；不计数则方向未知；不平移则位置不变。

每个实心矩形内的缺陷像素先被修复（重涂为主色），同时缺陷的个数模 4 编码了该矩形的位移方向，最后矩形沿该方向移动自身高度的距离。

**输入结构**：约 20×20 的黑(0)背景网格。
- 3~4 个单色实心矩形，颜色各不相同（从蓝(1)、绿(3)、黄(4)、灰(5)中选取），高度 2~4 像素，宽度 3~5 像素。矩形之间至少间隔自身最大高度的两倍（保证平移后不重叠）。
- 每个矩形内部含有 1~4 个"缺陷"像素，颜色为橙(7)。缺陷像素 4-邻域中至少有 3 个方向是矩形主色（即缺陷嵌入在矩形内部，不在边缘角落——严格说：缺陷的 4-邻域中属于矩形主色的邻居数 ≥ 3）。
- 矩形在每个方向上都留有至少等于自身高度的空白空间，保证任一方向的平移都不会超出网格边界。
- 生成约束：不同矩形的缺陷数模 4 的值互不相同（保证方向多样性，至少展示两个不同方向，有助于求解者发现编码规则）。

**规则**：
1. 对每个矩形，找到其内部颜色为橙(7)的缺陷像素。统计缺陷数量 D。
2. 将所有缺陷像素重涂为该矩形的主色（修复）。
3. 计算位移方向：D mod 4 的值映射为方向——0 → 上，1 → 右，2 → 下，3 → 左。
4. 以矩形自身高度 H 为位移距离，沿步骤 3 确定的方向平移整个矩形（包含已修复的像素）。
5. 清除矩形原始位置的所有像素为黑(0)。
6. 多个矩形的平移相互独立，按边界框左上角从左到右、从上到下的顺序依次处理（先移开的腾出空间，但由间距约束保证不会冲突）。

**关键洞察**：缺陷像素是需要被消除的"噪声"，但同时也是编码位移方向的"信号"——修复和读取必须在同一步完成。仅看单个示例无法确定缺陷数与方向的映射关系，必须对比多个矩形的缺陷数和实际位移方向才能归纳出模 4 编码规则。

## 新题 7：最少前景精灵的异色补全与描边输出

**组合逻辑**：[计数(counting) → 面积排名(area_ranking)]（按前景像素最少选取）→ [补全(completion) + 缺失像素异色补(missing_diff_color_fill)]（补全选中瓦片的缺失像素为不同色）→ [描边(outline)]（以原始精灵色描边）。三个阶段使用三种不同颜色身份：原色用于选取和描边，补全色标识缺失部分，描边色回指原始身份。

**来源原语**：计数、裁剪、精灵体、面积排名、前景最多者选出 ← a87f7484；补全、连通分量、包围盒内部、缺失像素异色补 ← 60b61512；描边、中心扩展、标记色决定描边色 ← 913fb3ed

**依赖链**：面积计数 → 最少前景者被选中（与参考题的最多者相反，需多例归纳） → 被选中瓦片的黑(0)缺失部分补全为橙(7)（异色补全） → 对补全后的 3×3 结果以原始精灵颜色画 5×5 空心描边 → 输出 5×5。删除面积选取则不知道选哪个；删除补全则缺失部分仍为黑，被描边覆盖后无法区分；删除描边则丢失原色信息。

从一条精灵瓦片带中选出前景像素最少的那个，用橙色补全其 3×3 框内的缺失像素，再用原始精灵颜色画一圈 5×5 空心描边输出。

**输入结构**：3×N 或 N×3 的一维瓦片带（N 为 3 的倍数，通常 9 或 12），黑(0)背景。
- 瓦片带由 3~4 个首尾相接的 3×3 瓦片组成。每个瓦片内有一种非黑前景色（从蓝(1)、红(2)、绿(3)、黄(4)中选取），前景像素数量各不相同（如 3、5、7、8 个），以保证唯一最少者。
- 每个瓦片内的前景像素构成一个 8-连通体，形状不规则（不限于特定几何名称），其余位置为黑(0)。
- 生成约束：前景最少的瓦片至少有 2 个前景像素且至少有 2 个黑(0)缺失像素（保证补全操作有意义）。不同瓦片的前景色互不相同。

**规则**：
1. 将瓦片带按行方向（水平带）或列方向（竖直带）分割成 3×3 瓦片。
2. 统计每个瓦片中非黑(0)像素的数量。
3. 选择前景像素数量唯一最少的那个瓦片。记录其前景色为 C。
4. 对选中瓦片的 3×3 边界框：将所有黑(0)像素填充为橙(7)，原有颜色 C 的像素保持不变。得到一个 3×3 的双色块。
5. 在该 3×3 块外围画一圈单像素宽的空心描边，描边颜色为 C（原始前景色）。输出为 5×5 网格：外圈是 C 色描边，内部 3×3 是补全后的双色块。

**关键洞察**：选取标准是"最少"而非常见的"最多"——需要对比多例才能发现这一反直觉规则。补全用橙(7)（而非原色）标记缺失部分，而描边却用原色 C，使得输出中同时存在三层颜色信息：原色（精灵身份+描边）、橙色（缺失标记）、黑色（无，因为补全已填满）。

## 新题 8：精灵像素数编码旋转角且阻挡种子射线

**组合逻辑**：[计数(counting) → 旋转(rotate)]（精灵前景数编码旋转量）＋ [射线延伸(ray_extend)]（种子按色延伸）。精灵同时是旋转编码器和射线障碍物——旋转改变精灵的空间位置，进而改变它阻挡射线的方式。双重角色产生涌现交互。

**来源原语**：旋转、象限、四旋转变体组拼图 ← 46442a0e；射线延伸、种子像素、条纹、种子色决定延伸 ← 178fcbfb；计数、精灵体、前景像素 ← 39a8645d, b91ae062

**依赖链**：精灵前景像素数 N → N mod 4 确定整网格旋转角度 → 旋转后种子和精灵的相对位置改变 → 种子按颜色规则射出射线 → 射线碰到精灵像素时停止。精灵的像素数同时决定了旋转量（改变布局）和自身形状（影响阻挡模式）。改变精灵的一个像素会同时改变旋转角度和阻挡轮廓——这是涌现效应。

一个小精灵的前景像素数决定整个网格的旋转角度，旋转后各种子像素按颜色规则射出行/列射线，而旋转后的精灵像素则作为射线的阻挡物。

**输入结构**：约 10×10 的黑(0)背景网格。
- 网格中央附近有一个单色精灵（灰(5)），4-连通，像素数 3~8 个，边界框不超过 4×4。精灵形状不对称（非旋转对称），以保证旋转后阻挡模式可辨别地改变。
- 网格中散布 2~4 个单像素种子，颜色为红(2)、绿(3)或蓝(1)。种子不与精灵相邻（至少间隔 1 像素）。
- 生成约束：旋转后种子不会落在精灵像素上（保证种子在旋转后仍然存在）。至少有一条射线会被旋转后的精灵阻挡（产生可观察的截断效果），至少有一条射线不被阻挡（产生对比）。

**规则**：
1. 统计灰(5)精灵的前景像素数量 N。
2. 计算旋转量：N mod 4 = R，对应 R × 90° 顺时针旋转。R=0 不旋转，R=1 旋转 90°，R=2 旋转 180°，R=3 旋转 270°。
3. 将整个网格（包括精灵和所有种子）以网格中心为旋转中心旋转 R × 90° 顺时针。
4. 在旋转后的网格上，对每个种子执行射线延伸：
   - 红(2)种子：向上和向下延伸，填满所在列（整列涂红(2)）。
   - 绿(3)种子：向左和向右延伸，填满所在行（整行涂绿(3)）。
   - 蓝(1)种子：向左和向右延伸，填满所在行（整行涂蓝(1)）。
5. 射线逐像素延伸。当射线像素碰到灰(5)精灵像素时，射线在该位置停止（不覆盖精灵像素，射线终止于精灵相邻的前一个像素）。
6. 种子像素本身被射线覆盖（射线包含种子位置）。若两条射线交叉，交叉像素取竖直射线（红(2)）的颜色。精灵像素保持灰(5)不变。

**关键洞察**：精灵身兼两职——其像素数编码旋转指令，其旋转后的形状决定射线的截断方式。这意味着改变精灵的任何一个像素，都会同时改变网格旋转角度和射线阻挡轮廓，产生非线性的输出变化。求解者不能独立理解旋转和阻挡，必须把它们作为同一对象的两个面来推理。

## 新题 9：图例高度双重编码：排名索引与描边尺寸

**组合逻辑**：[计数(counting) → 排序(sort)/长度排名(length_ranking)]（统计标记数并排名）→ [查表(lookup)]（图例高度 k 索引排名第 k 的颜色）→ [描边(outline) · 中心扩展(center_expansion)]（以图例色画 (2k+1) 的描边）。图例条目的高度 k 同时是排名索引和描边尺寸参数——一个数字编码两条独立信息。

**来源原语**：排序、颜色图例、竖条、长度排名、高度即排名索引 ← 97d7923e；描边、孤立像素、中心扩展、标记色决定描边色 ← 913fb3ed；计数、前景最多者选出 ← a87f7484

**依赖链**：统计各色标记数 → 排名（最多=排名1）→ 图例条目 (K, k) 的高度 k 索引到排名第 k 的颜色 C → 在所有颜色 C 的标记周围画 (2k+1)×(2k+1) 空心描边，描边色为 K。删除计数则排名不存在；删除排名则 k 无法映射到颜色；删除描边则无几何输出。k 的双重角色（索引+尺寸）是核心耦合点。

网格中散布的彩色标记像素按颜色统计数量并排名，顶部色条图例的每个条目 (K, k) 以高度 k 同时指定"选排名第 k 的标记颜色"和"画 (2k+1) 大小的描边"，描边颜色为 K。

**输入结构**：约 16×16 的黑(0)背景网格。
- 顶部区域（前 1~3 行）：颜色图例。图例由 2~3 个单色竖条紧贴第 0 行排列，竖条之间间隔至少 1 列黑(0)。每个竖条颜色 K 不同（从品红(6)、橙(7)、栗(9)中选取），宽度固定 1 像素，高度 k 为 1~3 像素。不同竖条高度互不相同。
- 主区域（图例下方隔 2 行黑(0)）：散布若干孤立单像素标记。标记颜色来自图例颜色之外的一个集合（如红(2)、绿(3)、蓝(1)），且标记使用的颜色种类数与图例条目数相同。每种标记颜色的出现次数互不相同，保证排名无歧义。
- 生成约束：每个标记的以 (2k_max+1) 为半径的正方形邻域内没有其他标记或图例像素（k_max 为图例中最大的 k 值），保证描边框不重叠。图例高度 k 的取值恰好覆盖 1 到图例条目数（如 3 个条目则高度为 1、2、3）。

**规则**：
1. 解析顶部图例：识别每个竖条的颜色 K 和高度 k（像素行数）。得到图例列表 [(K1, k1), (K2, k2), ...]。
2. 统计主区域中每种标记颜色的出现次数。按出现次数从多到少排名：最多 = 排名 1，次多 = 排名 2，依次类推。
3. 对每个图例条目 (K, k)：查找排名为 k 的标记颜色 C。
4. 对每个颜色为 C 的标记像素，以该像素为中心画 (2k+1)×(2k+1) 的空心描边框，框色为 K。标记像素本身保持颜色 C 不变。描边框内标记与框之间的像素保持黑(0)。
5. 图例区域在输出中清除为黑(0)（不出现在输出里）。

**关键洞察**：图例条目的高度 k 不是直接指定哪种颜色或描边大小——它是一个排名索引，必须先统计标记数量建立排名后才能解引用。同时，同一个 k 又决定了描边框的边长 (2k+1)，使得排名靠后（出现次数少）的颜色反而获得更大的描边框。这种"高度=索引=尺寸"的三合一编码必须对比多个示例才能拆解。
