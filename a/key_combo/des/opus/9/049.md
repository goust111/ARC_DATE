## 新题 1：角框宽高比双路分流——镜像轴与图例行的几何共决

**组合逻辑**：[角标记定位矩形框] → [宽高比决定镜像轴](创新：同时决定图例读取行) → [镜像] + [重涂色] → [擦除]

**来源原语**：镜像(mirror, 93c31fbe), 角标记/矩形框(corner_marker/rectangular_frame, 93c31fbe), 宽高比决定镜像轴(aspect_ratio_mirror_axis, 93c31fbe), 重涂色(recolor, fafd9572), 颜色图例(color_legend, fafd9572), 边框色映射填充色(border_to_fill_mapping, dbff022c), 擦除(erase, 93c31fbe)

**依赖链**：角标记的空间位置→确定框的边界矩形→宽高比同时决定两件事：(1) 内部图案的镜像轴、(2) 从双行图例中读取哪一行的填充色→镜像后用查得的填充色替换蓝色像素→框外蓝色像素擦除。单一几何属性同时控制空间操作和颜色查询，两者不可分离。

用一句话概括：根据各矩形框的宽高比选择镜像方向并从对应图例行读取填充色，将框内蓝色图案镜像补全后重涂为查得的颜色，擦除框外所有蓝色像素。

**输入结构**：
- 黑(0)背景网格，约 16x16。
- 2-3 个矩形框，每个框由四个同色 L 形三连块（2x2 缺一角的 triomino）定义四角，每个框使用不同的标记色（如红(2)、绿(3)、橙(7)）。框之间互不重叠，各框宽高比不同——有的宽度大于高度（"宽框"），有的高度大于等于宽度（"高框"）。
- 每个框的边界矩形内部含有一小簇蓝(1)像素（3-6 像素的 4-连通不规则形状），偏居框内的一侧（宽框中偏左或偏右，高框中偏上或偏下），留出另一侧的空间用于镜像。
- 框外散布少量蓝(1)噪声像素（1-3 个孤立蓝点）。
- 网格底部边缘有一个 2 行 x N 列的图例块（N = 框的数量）。图例上行和下行各列分别存放不同的填充色。图例的列顺序与框的标记色一一对应：每列的标记色在图例中以某种方式标注（图例每列两像素，分属两行，构成一个颜色对）。具体地，图例第一行为"宽框对应的填充色"，第二行为"高框对应的填充色"；列的标记色通过列的左右排列与框的标记色从左到右对应——即图例各列按其所对应框的边界矩形左上角的列坐标从小到大排列。
- 生成约束：每个框内蓝色图案关于该框的镜像轴对称后不超出框的边界矩形；图例中不出现蓝(1)或黑(0)。

**规则**：
1. 识别所有 L 形三连块角标记，按颜色分组，每组四个角确定一个矩形框的边界矩形（四个 L 的外接矩形）。
2. 计算每个框的宽高比：宽度 > 高度为"宽框"，高度 >= 宽度为"高框"。
3. 对宽框：将框内蓝色像素关于框的垂直中线做左右镜像，镜像副本填入框内。对高框：将框内蓝色像素关于框的水平中线做上下镜像，镜像副本填入框内。镜像仅添加新像素，不删除原有蓝色像素。
4. 读取图例：将图例各列按列坐标从小到大排列，依次对应各框按边界矩形左上角列坐标从小到大的排列。对于宽框，取该列第一行（上行）的颜色作为填充色；对于高框，取该列第二行（下行）的颜色。
5. 将每个框内所有蓝色像素（原始 + 镜像）重涂为步骤 4 中查得的填充色。
6. 擦除所有不在任何框内部的蓝(1)像素（将其置为黑(0)）。角标记和图例保持不变。
7. 输出修改后的完整网格。

**关键洞察**：宽高比是一个双重开关——它同时决定镜像是左右还是上下、以及从图例的哪一行读取颜色。仅看单个示例可能无法区分这两种路径，必须对比含有不同宽高比框的多个示例才能归纳出规则。

## 新题 2：对称重建地面上的重力沉降

**组合逻辑**：[对称补全](恢复缺失区域) → [重力下落 + 碰撞停止]（令牌在重建后的地形上沉降）

**来源原语**：对称补全(symmetry_completion, e66aafb8), 对称图案(symmetric_pattern, e66aafb8), 缺失矩形区域(missing_rect, e66aafb8), 对称轨道(symmetry_orbit, e66aafb8), 重力下落(gravity_drop, 2b83f449), 令牌(token, 2b83f449), 碰撞停止(collision_stop, 2b83f449)

**依赖链**：输入中缺失区域使得部分"地面"不可见→对称补全恢复这些不可见的非黑像素，它们成为令牌的着陆面→令牌逐个下落，遇到重建的或原始的非黑像素即停止→最终输出是重建后的完整网格加上落定的令牌。重力模拟的结果完全取决于重建出的地形。

用一句话概括：先用 D4 对称性恢复方形网格的缺失矩形区域，然后让悬浮的彩色令牌在重建后的地形上做重力下落并着陆。

**输入结构**：
- 一个正方形网格（约 11x11），其像素图案在缺失区域以外满足 D4 对称性（水平、垂直、两条对角线反射下值不变）。图案使用 2-3 种非黑前景色（如蓝(1)、灰(5)、栗(9)），黑(0)为背景。
- 一个矩形区域（约 3x4）的像素全部为黑(0)，打破了对称性——这是待恢复的缺失区。缺失区位于网格的中下部。
- 3-5 个令牌像素散布在网格的上半区，每个令牌为一个独立的单像素，颜色为不同于图案色的前景色（如红(2)、绿(3)、黄(4)）。每个令牌所在列下方至少存在一个非黑像素（可能是原始图案，也可能需要重建后才出现）。
- 生成约束：每个令牌正下方最终一定有着陆面（重建后保证）；不同令牌不在同一列（简化碰撞）；令牌颜色与图案颜色互不相同。

**规则**：
1. 定位缺失矩形区域（连通的全黑矩形块，其 D4 对称位置包含非黑像素）。
2. 对缺失区内的每个黑(0)像素，计算其在 D4 对称群下的轨道（最多 8 个位置）。从轨道中找到唯一的非黑值，将该值填入缺失像素。完成后整个网格恢复完整的 D4 对称图案。
3. 识别令牌（颜色不属于对称图案使用的颜色集的孤立单像素）。
4. 按令牌的行坐标从大到小（底部的令牌先处理）依次执行重力下落：令牌在其所在列逐行向下移动，直到下方紧邻的像素非黑（属于对称图案或已落定的令牌）或到达网格底边，令牌停在最后一个可用位置。
5. 令牌原位置恢复为该处的对称图案值（若该位置在缺失区内则用重建值，否则为原始值）。
6. 输出完整的网格（重建图案 + 落定令牌）。

**关键洞察**：缺失区域的黑像素在重建前和令牌在同一列中共存——不重建就无法判断令牌是否会穿过缺失区继续下落还是在某处被挡住。重建出的"隐形地面"是重力模拟的关键输入。

## 新题 3：条纹排序后的同余对角交错填充

**组合逻辑**：[排序](条纹按位置排列) → [裁剪](提取灰色方块) → [循环填充 + 等距偏移](创新：用排序序号作为同余相位)

**来源原语**：排序(sort, 8e1813be), 裁剪(crop, 8e1813be), 条纹(stripe, 8e1813be), 正方形区域(square_region, 8e1813be), 顺序对应(ordinal_correspondence, 8e1813be), 循环填充(cyclic_fill, 05269061), 对角线(diagonal, 05269061), 等距偏移(equidistant_offset, 05269061), 同余类交错铺满(congruence_interlaced, 05269061)

**依赖链**：条纹的空间位置→排序产生序号→序号同时决定输出列号和对角线相位偏移→循环填充在裁剪出的方块画布上按同余相位绘制对角条纹→不同列的相位交错产生完整的菱格铺满。排序既决定列映射又决定相位，构成单入口双出口的信息流。

用一句话概括：将散布的彩色竖条纹按列位置排序后，用各条纹的颜色在灰色方块内按照排序序号偏移的对角同余类绘制交错条纹。

**输入结构**：
- 黑(0)背景网格，约 14x14。
- 一个灰(5)实心正方形区域，边长 S（S = 条纹数量，范围 3-5），位于网格的右下区域。
- S 条竖直条纹段散布在网格的其他区域。每条条纹为 1 像素宽、3-5 像素高的同色竖直线段，各条纹颜色互不相同（使用红(2)、绿(3)、蓝(1)、橙(7)、品红(6)中的 S 种）。条纹之间不共享列坐标。
- 生成约束：S 条条纹的列坐标互不相同；灰色方块与条纹不重叠。

**规则**：
1. 识别灰(5)正方形区域并裁剪为 SxS 输出画布（初始化为黑(0)）。
2. 识别所有非灰、非黑的竖直条纹段（1 像素宽的同色 4-连通竖直线段）。
3. 按各条纹所在列坐标从小到大排序，赋予序号 k = 0, 1, ..., S-1。
4. 对每个序号 k 及其对应的条纹颜色 c：在输出画布的第 k 列中，仅在满足 (row + k) mod S == 0 的行 row 处填入颜色 c，其余位置保持黑(0)。（row 从 0 开始计数，0 为方块顶行。）
5. 输出 SxS 画布。

**关键洞察**：每条条纹的列位置不仅决定它映射到输出的第几列（空间映射），还决定其对角相位偏移（(row+k) mod S）。由此产生的输出是一个对角交错铺满图案，其中每种颜色恰好覆盖一个对角同余类。仅看单个示例可能误以为是简单的列填充，必须对比不同条纹数量或位置的多个示例才能发现同余相位规则。

## 新题 4：镜像错切对与楔形间隙填充

**组合逻辑**：[镜像](创建对称副本) + [错切](两份反向行偏移) → [填充 + 两体之间](创新：间隙形状由错切与原始图案共同决定)

**来源原语**：错切(shear, 3cd86f4f), 行偏移递变(row_offset_progress, 3cd86f4f), 行内容保持(row_content_preserved, 3cd86f4f), 镜像(mirror, 93c31fbe), 填充(fill, d6ad076f), 间隙区域(gap_region, d6ad076f), 两体之间(between_two_objects, d6ad076f), 间隙区域涂色(gap_region_recolor, d6ad076f)

**依赖链**：原始图案→镜像产生对称副本→两份分别做反向错切→错切后两份向彼此倾斜，各行的边缘位置不同→每行的间隙宽度 = 两份在该行的最近像素之间的距离，由原始图案的行宽和错切偏移共同决定→间隙填充。间隙的形状既不是矩形也不是简单的三角形，而是由图案轮廓和错切量共同决定的不规则楔形。

用一句话概括：将一个小图案及其水平镜像分别向内做反方向错切，然后用青色填充两个倾斜副本之间逐行变化的楔形间隙。

**输入结构**：
- 黑(0)背景网格，约 6x15（高 6、宽 15）。
- 网格中央偏左有一个彩色矩形图案（H 行 x W 列，如 4x3），不含黑色像素，使用 2-3 种前景色（如蓝(1)、红(2)、绿(3)）。图案的各行宽度相同（矩形），但行内的颜色分布不对称（使镜像后可区分方向）。
- 生成约束：H >= 3, W >= 2；画布宽度 >= 2W + 2H - 1（足够放置两个错切副本和间隙）；图案左右两侧有足够黑色空间。

**规则**：
1. 将原始图案记为 P（H x W 矩阵）。创建其水平镜像 P'（每行像素左右翻转）。
2. 在输出画布上放置 P 的错切版：P 的第 r 行（r = 0 为顶行）起始列为 c_left + r，其中 c_left 为画布最左可用位置。即逐行向右偏移 1 列（下行右移的错切）。
3. 在输出画布上放置 P' 的错切版：P' 的第 r 行起始列为 c_right - r，其中 c_right 确保顶行时 P' 最左像素与 P 最右像素之间恰好有 H-1 列的间隔。即逐行向左偏移 1 列（下行左移的错切）。
4. 两个错切副本向彼此倾斜。对每一行 r，找到左副本在该行的最右像素列 R_L(r) 和右副本在该行的最左像素列 L_R(r)。将 R_L(r)+1 到 L_R(r)-1 之间的所有黑色像素填充为青(8)。
5. 若某行左副本与右副本之间没有黑色间隙（已紧邻或重叠），则该行不填充。
6. 输出画布。

**关键洞察**：间隙区域不是固定形状，而是由错切偏移和原始图案的逐行宽度共同雕刻而成。顶行间隙最宽（H-1 列），底行间隙最窄甚至消失——这个楔形渐变是错切操作的涌现效应，源题中的间隙填充（两个静态矩形之间的固定间隙）和错切（单个对象的行偏移）都无法单独产生这种效果。

## 新题 5：面积排序的同心环配以图例变色

**组合逻辑**：[面积排序](确定环嵌套序) ⊕ [图例映射](确定环颜色) → [同心环绘制]（两条独立信息流汇合）

**来源原语**：排序(sort, 5587a8d0), 同心环绘制(concentric_draw, 5587a8d0), 连通分量(connected_component, 5587a8d0), 面积排序(area_ordering, 5587a8d0), 面积决定嵌套序(area_nesting_order, 5587a8d0), 重涂色(recolor, fafd9572), 颜色图例(color_legend, fafd9572), 排位对应(rank_correspond, fafd9572), 图例位映射色(legend_pos_color, fafd9572), 边框色映射填充色(border_to_fill_mapping, dbff022c)

**依赖链**：前景对象的像素数→面积排序→决定每种颜色在同心环中的径向位置（从外到内）；同时图例提供颜色映射→每个对象的原始颜色被替换为图例指定的输出颜色。两条信息流在绘制同心环时汇合：位置来自面积，颜色来自图例。去掉任一条都无法确定输出。

用一句话概括：将散布的前景对象按面积排序确定同心方环的由外到内顺序，但每个环的颜色不是对象原色而是通过角落图例映射后的新颜色。

**输入结构**：
- 黑(0)背景网格，约 14x14。
- 3-5 个单色 4-连通前景对象（每个对象形状不规则、像素数 3-15 不等，各自颜色互不相同，如蓝(1)、红(2)、绿(3)、橙(7)），散布在网格中，互不接触。各对象的像素数（面积）互不相同。
- 网格右上角有一个 2xN 的图例块（N = 对象数量）。图例上行依次列出各对象的原始颜色（按列坐标从左到右排列），下行对应位置列出映射后的输出颜色。图例颜色不使用黑(0)或任何对象已有的颜色。
- 生成约束：图例上行的颜色集 = 对象颜色集；图例下行的颜色互不相同；对象面积互不相同。

**规则**：
1. 识别所有前景对象（排除图例块；图例可通过其位于右上角且为严格的 2xN 矩形来识别）。
2. 计算每个对象的像素数（面积），按面积从大到小排序，赋予序号 k = 0, 1, ..., N-1（0 = 最大）。
3. 读取图例：对每种对象颜色 c_obj，在图例上行找到该颜色所在列，取下行同列的颜色作为 c_out。
4. 创建正方形输出画布，边长 = 2N - 1。
5. 按 k 从 0 到 N-1 绘制同心方环：k=0 的对象对应最外层环，使用其映射后的颜色 c_out 填充；k=1 对应次外层环；...；k=N-1 对应中心像素。每一层"环"是边长为 (2N-1-2k) 的方形边框（1 像素宽），中心像素视为边长 1 的"环"。
6. 输出画布。

**关键洞察**：每个对象同时携带两个正交维度的信息——像素数编码径向位置（哪一层环），颜色编码外观（通过图例映射到输出色）。仅看面积或仅看图例都无法独立确定输出。必须从多个示例中同时归纳面积排序规则和图例颜色映射规则。

## 新题 6：射线交叉事件的提取与压缩堆叠

**组合逻辑**：[射线延伸](横竖段各自延伸) → [交叉 + 交叉点标记新色](检测交叉事件) → [裁剪 + 排序 + 堆叠](将交叉事件提取为紧凑表格)

**来源原语**：射线延伸(ray_extend, 99fa7670/bdad9b1f), 横条段(h_bar_segment, bdad9b1f), 竖条段(v_bar_segment, bdad9b1f), 交叉(crossing, bdad9b1f), 交叉点标记新色(crossing_cell_marked_new_color, bdad9b1f), 堆叠(stacking, 4acc7107), 排序(sort, 4acc7107), 位置排序(positional_ordering, 4acc7107), 行列对齐(row_column_alignment, 99fa7670)

**依赖链**：横条段和竖条段的位置→射线延伸到全行/全列→交叉检测产生交叉点集合→每个交叉点记录两种颜色（横色 + 竖色）→按交叉点的空间位置排序→堆叠为紧凑的三列输出表格。射线几何决定交叉数量和位置，位置决定排序，排序决定输出行序。信息从几何空间流向紧凑编码。

用一句话概括：将散布的横竖短条段延伸为全跨射线后，检测所有交叉点，将每个交叉记录为（横色-黄-竖色）三元组，按空间位置排序堆叠为压缩表格输出。

**输入结构**：
- 黑(0)背景网格，约 12x12。
- 2-4 条水平短条段：每条 1 像素高、3-5 像素宽的同色线段，各自颜色互不相同（如红(2)、品红(6)），各条占不同行。
- 2-4 条垂直短条段：每条 1 像素宽、3-5 像素高的同色线段，各自颜色互不相同（如蓝(1)、绿(3)），各条占不同列。
- 水平段和垂直段的颜色集互不相交。
- 生成约束：输入中没有两条段共享行（水平段之间）或列（垂直段之间）；水平段与垂直段当前不重叠（延伸后才可能交叉）。

**规则**：
1. 将每条水平段延伸为覆盖其所在行全部列的射线（保持该段颜色）。
2. 将每条垂直段延伸为覆盖其所在列全部行的射线（保持该段颜色）。
3. 检测所有交叉点：交叉点是某水平射线和某垂直射线同时覆盖的像素。记录每个交叉点的行列坐标、水平射线颜色 c_h、垂直射线颜色 c_v。
4. 将交叉点按行坐标从小到大排序；行坐标相同则按列坐标从小到大排序。
5. 创建输出网格：高度 = 交叉点数量 K，宽度 = 3。第 i 个交叉点（排序后第 i 个）对应输出第 i 行，三列分别填入 c_h、黄(4)、c_v。
6. 输出 Kx3 网格。

**关键洞察**：输出不是射线交叉图本身，而是对交叉事件的压缩编码。输入中的短条段暗示了射线方向，但交叉的数量和顺序只有在射线完全延伸后才能确定。紧凑表格的行数和颜色内容都是输入几何的衍生物。

## 新题 7：奇偶门控——方块滑动或中心标注的分流决策

**组合逻辑**：[奇偶性](边长奇偶分流) →分支A [标注中心] / 分支B [滑动 + 碰撞停止]（两组对象相互约束）

**来源原语**：标注中心(mark_center, 22806e14), 实心正方形(solid_square, 22806e14), 奇偶性(parity, 22806e14), 奇偶性才标注(odd_side_marked, 22806e14), 滑动(sliding, 25ff71a9), 前景对象(foreground_object, 25ff71a9), 方向(direction, 25ff71a9), 碰撞停止(collision_stop, 2b83f449), 擦除(erase, 1c02dbbe)

**依赖链**：每个实心正方形的边长→奇偶判断→奇数边长方块执行中心标注（成为固定障碍物），偶数边长方块根据箭头方向滑动→滑动方块在遇到固定方块（奇数）或画布边界时停止→最终布局取决于两类方块的相互空间关系。奇数方块是"锚"，偶数方块是"滑块"，锚的位置决定滑块的停靠点。

用一句话概括：边长为奇数的实心方块原地不动并在中心标上标记色，边长为偶数的方块按方向指示器滑动直到撞上奇数方块或边界后停止，方向指示器随后擦除。

**输入结构**：
- 黑(0)背景网格，约 12x12。
- 4-6 个实心正方形，各自单色，颜色互不相同（如蓝(1)、红(2)、绿(3)、橙(7)、栗(9)），边长在 2-5 之间，混合包含奇数和偶数边长。方块之间初始不重叠，不相邻。
- 每个偶数边长方块的某一条外边（上、下、左、右之一）紧邻一个灰(5)单像素，作为方向指示器：灰像素在方块上方表示向上滑动，在下方表示向下，在左侧表示向左，在右侧表示向右。
- 奇数边长方块旁边没有灰像素。
- 一个品红(6)的十字标记（3x3 的加号形状，5 像素）位于网格的某个角落，提供中心标注要使用的颜色。
- 生成约束：每个偶数方块沿其滑动方向上一定存在一个奇数方块或画布边界可以拦停它（保证不滑出边界）；滑动路径上不存在其他偶数方块（避免级联碰撞的歧义）；各方块初始位置互不重叠。

**规则**：
1. 识别所有实心正方形（同色填满的矩形区域且宽 = 高）及其边长。识别十字标记及其颜色（品红(6)）。
2. 边长为奇数的方块：在其正中心像素涂上品红(6)。方块不移动。
3. 边长为偶数的方块：找到紧邻它的灰(5)像素，确定滑动方向。将整个方块沿该方向逐像素平移，直到方块的前沿紧邻一个非黑非灰像素（即碰到奇数方块或另一个已停止的偶数方块的边缘）或到达画布边界。方块停在碰撞前的最后一个合法位置（不重叠）。
4. 擦除所有灰(5)像素（方向指示器）为黑(0)。
5. 若十字标记的中心像素落在某个奇数方块中心标注的范围内（即十字中心与某方块中心重合），则保留十字标记；否则擦除十字标记为黑(0)。
6. 输出修改后的完整网格。

**关键洞察**：奇偶性将方块分为两个角色——"锚"和"滑块"。锚的存在和位置决定了滑块的终点，而哪些是锚取决于边长的奇偶性。仅看一个示例可能无法确定奇偶是关键条件（可能误以为是颜色或面积决定），必须对比包含不同边长组合的多个示例才能锁定规则。

## 新题 8：平铺后重力沉降与对角邻接装饰

**组合逻辑**：[平铺](复制空间结构) → [重力下落 + 碰撞停止](重新排列) → [描边 + 对角邻接](装饰沉降后的新布局)

**来源原语**：平铺(tiling, 10fcaaa3), 种子像素(seed_pixel, 10fcaaa3), 描边(mark_neighbors, 10fcaaa3), 对角邻接(diagonal_adjacency, 10fcaaa3), 平铺后对角涂色(diagonal_marked_after_tiling, 10fcaaa3), 重力下落(gravity_drop, 2b83f449), 碰撞停止(collision_stop, 2b83f449)

**依赖链**：小网格平铺为 2x2→种子像素在四个象限中各有一份副本→重力使所有种子在各列中下落并堆叠→不同象限的种子副本可能落入同一列形成紧密堆叠→对角邻接装饰在沉降后的新布局上执行，堆叠导致种子间产生源网格中不存在的新对角邻接关系。三步操作串联，每步的输出实质改变下一步的输入。

用一句话概括：将含种子和墙的小网格 2x2 平铺后，所有种子像素在平铺网格中做重力沉降，最后在沉降后的位置对黑色对角邻居涂青色。

**输入结构**：
- 一个小黑(0)背景网格（3 行 x 4 列）。
- 网格中有 2-3 个彩色种子像素（颜色各不相同，如红(2)、绿(3)、蓝(1)），分布在网格的中上部。
- 网格底行有 1-2 个灰(5)墙像素，作为种子下落的固定阻挡。
- 生成约束：种子不在底行（留出下落空间）；种子不与墙相邻（初始状态下无接触）。

**规则**：
1. 将 3x4 的输入网格 2x2 平铺，生成 6x8 的网格。所有像素（种子、墙、黑色背景）均复制到四个象限。
2. 在平铺后的 6x8 网格中执行重力下落：所有种子像素（非黑、非灰、非青的彩色像素）在各自所在列中向下移动。灰(5)墙像素不移动。种子遇到墙像素、已落定的种子或网格底边时停止。同一列中从底部开始依次处理（最低的种子先落定）。
3. 种子的原始位置恢复为黑(0)。
4. 对平铺网格中每个已落定的种子像素，检查其四个对角邻居（左上、右上、左下、右下）。若对角邻居为黑(0)，则将其涂为青(8)。若对角邻居为非黑色（种子、墙或已有的青色），则不覆盖。
5. 输出 6x8 网格。

**关键洞察**：平铺创造了原始网格中不存在的种子-种子空间关系（不同象限的同一种子副本出现在新的列中）。重力将这些副本压缩到列底部，导致不同颜色的种子可能紧密堆叠，产生新的对角邻接对。对角装饰揭示了这种堆叠结构——装饰图案的形状是平铺和重力共同作用的涌现结果。

## 新题 9：空心精灵体内的面积编码同心环填充

**组合逻辑**：[封闭区域检测](定位空心体内腔) ⊕ [面积排序 + 同心环绘制](外部对象编码环的颜色序列) → [填充](创新：同心环裁剪至非矩形内腔)

**来源原语**：填充(fill, dbff022c), 空心精灵体(hollow_sprite, dbff022c), 封闭区域(enclosed_region, dbff022c), 同心环绘制(concentric_draw, 5587a8d0), 连通分量(connected_component, 5587a8d0), 面积排序(area_ordering, 5587a8d0), 面积决定嵌套序(area_nesting_order, 5587a8d0), 嵌套方环(nested_square_ring, 5587a8d0)

**依赖链**：空心精灵体的边框→封闭区域检测定位内腔（可能非矩形）→外部独立小对象的像素数→面积排序确定颜色由外到内的层级→同心方环按面积序绘制并裁剪到内腔边界→裁剪后的环形只在内腔中可见。内腔形状和对象面积是两条独立的约束流，在绘制时汇合。

用一句话概括：识别空心精灵体的内腔，将网格上散布的小对象按面积排序后，以其颜色由外到内绘制同心方环填充到内腔中（超出内腔的部分裁剪掉）。

**输入结构**：
- 黑(0)背景网格，约 15x15。
- 一个大型空心精灵体：由单一颜色（如蓝(1)）的像素构成一个封闭的环状边框，边框内部包围着一个连通的黑(0)区域（内腔）。内腔不接触网格边界。内腔大致为矩形但可以有缺角或凸出（4-连通封闭即可），面积约 20-40 像素。
- 2-4 个小型单色 4-连通前景对象散布在精灵体外部，颜色互不相同（如红(2)、绿(3)、橙(7)、品红(6)），各对象像素数互不相同（范围 2-10），与精灵体边框不接触。
- 生成约束：小对象数量 N 满足 2N-1 <= 内腔的最短边（确保同心环能在内腔中可见至少一部分）；所有颜色互不相同。

**规则**：
1. 识别空心精灵体（与网格边界 4-连通的非黑最大连通分量即为边框，或根据颜色唯一性识别）。定位其封闭的黑(0)内腔（不接触网格边界的黑色 4-连通区域）。
2. 识别精灵体外部的所有小型前景对象（非黑、非精灵体颜色的 4-连通分量）。
3. 按像素数从大到小排序，赋予序号 k = 0, 1, ..., N-1。
4. 计算内腔的边界矩形。以该边界矩形的中心为同心环中心。
5. 绘制同心方环：k=0（面积最大）的颜色绘制最外层环（边长 = 2N-1 的方框），k=1 绘制次外层（边长 = 2N-3），...，k=N-1 绘制中心像素。
6. 将同心环图案裁剪到内腔：仅保留内腔区域内的像素，内腔外的环部分丢弃。
7. 精灵体边框和外部小对象保持不变。输出完整网格。

**关键洞察**：外部小对象是内腔填充的"颜色指令"——它们的面积编码径向位置，颜色编码外观，但它们自身不出现在内腔中。内腔的非矩形边界会裁剪同心环，产生不完整的环形图案，使得求解者需要同时理解环的生成规则和裁剪规则。

## 新题 10：条纹几何编码变换指令——旋转或镜像的参数化选择

**组合逻辑**：[条纹方向检测](选择操作类型：旋转/镜像) + [条纹计数](参数化操作次数) → [旋转 或 镜像] → [裁剪 + 擦除]

**来源原语**：旋转(rotate, 3c9b0459), 整体半周旋转(half_turn_rotation, 3c9b0459), 镜像(mirror, 93c31fbe), 条纹(stripe, 8e1813be), 条纹决定填充轴(stripe_determines_fill_axis, 8e1813be，创新改造为条纹决定变换类型), 裁剪(crop, 8e1813be), 擦除(erase, 22806e14)

**依赖链**：条纹方向（横/竖）→决定操作类型是旋转还是镜像→条纹数量 K →参数化操作幅度（旋转 K*90度 或 镜像轴选择）→对前景对象执行变换→擦除条纹。条纹既是操作选择器又是参数编码器，几何结构本身编码了变换规则——这是隐式编码结构。

用一句话概括：根据指示条纹的方向选择旋转或镜像操作，根据条纹数量确定操作参数，对前景对象执行变换后擦除条纹。

**输入结构**：
- 黑(0)背景网格，约 10x10。
- 一个前景对象：由红(2)像素构成的不规则 4-连通图形（5-10 像素），形状不对称（旋转和镜像后可区分），位于网格中部。
- 1-3 条绿(3)的短条纹段，位于网格的上边缘或左边缘区域（不与红色对象接触）。所有条纹平行——要么全是水平段（每段 1 像素高 x 2-3 像素宽），要么全是垂直段（每段 2-3 像素高 x 1 像素宽）。
- 生成约束：条纹数量 K 在 1-3 之间；所有条纹方向一致；不同条纹不共享行（水平时）或列（垂直时）。

**规则**：
1. 识别绿(3)条纹段，判断其方向：水平或垂直。计数条纹数量 K。
2. 将红(2)对象裁剪为其最小边界矩形。
3. 若条纹为水平方向：将裁剪后的对象顺时针旋转 90°×K（K=1 旋转 90°，K=2 旋转 180°，K=3 旋转 270°）。
4. 若条纹为垂直方向且 K 为奇数：将裁剪后的对象做左右镜像。若 K 为偶数：做上下镜像。
5. 擦除所有绿(3)条纹像素为黑(0)。
6. 将变换后的对象放回其原始边界矩形的左上角位置（即左上角坐标不变，对象尺寸可能因旋转而改变）。若变换后的对象超出网格边界，超出部分裁剪掉。
7. 输出修改后的网格。

**关键洞察**：条纹不是装饰或待处理的数据——它们是一套几何指令集。方向编码操作类型（旋转 vs 镜像），数量编码操作参数。这个规则无法从单个示例推断，因为同一个示例可以被解释为多种变换的结果；必须对比不同条纹配置的多个示例才能锁定"方向→操作类型、数量→参数"的双重编码。
