## 新题 1：螺旋扫描筛选连通分量

**组合逻辑**：[螺旋绘制/spiral_draw](创新：不画螺旋，而是用螺旋路径作为空间扫描器) → [连通分量/connected_component + 面积比较/area_comparison](已有) → [保留最大连通分量/keep_largest_component](已有) → [裁剪/crop](已有)

**来源原语**：螺旋绘制 ← e5c44e8f；连通分量、面积比较、保留最大连通分量 ← 1f85a75f；裁剪 ← 1f85a75f；遇障碍停止 ← e5c44e8f

**依赖链**：螺旋路径的可达范围（受障碍截断）决定了哪些连通分量被"触及"→ 仅在被触及的分量中进行面积比较 → 面积最大者被保留并裁剪输出。障碍位置改变螺旋可达范围，间接改变面积比较的候选集，进而改变最终输出的分量身份。

将螺旋路径作为不可见扫描臂，筛选其可达范围内面积最大的连通分量并裁剪输出。

**输入结构**：约 15×15 的黑(0)背景网格。网格中散布 4~6 个单色 4-连通前景分量，每个分量由 3~8 个像素组成，形状不规则（不限于矩形，可为L形、T形、弯折等任意连通形态），颜色互不相同，可用红(2)、蓝(1)、绿(3)、黄(4)、品红(6)等。一个橙(7)种子像素位于网格中部偏离中心的位置。2~3 个灰(5)障碍像素散布于网格中，位置使得螺旋路径在到达某些分量前被截断。生成约束：至少有一个面积较大的分量位于螺旋被截断后无法到达的区域（使得全局最大分量不一定是输出结果）；螺旋可达范围内至少触及 2 个分量。

**规则**：
1. 从橙(7)种子像素出发，按方向序列"上→右→下→左"循环，步长序列为 2, 2, 4, 4, 6, 6, 8, 8, ...（每个方向走对应步数），在概念上追踪一条螺旋路径。此路径不在输出中绘制，仅用于判定哪些网格位置被"扫过"。
2. 逐步追踪螺旋路径。若下一步将踏入的网格位置是灰(5)障碍像素，则在踏入前停止追踪，螺旋终止。超出网格边界的步骤跳过但仍消耗步数计数。
3. 收集螺旋路径经过的所有网格位置（含种子像素自身）。对网格中的每个 4-连通单色前景分量（不含种子和障碍），若该分量至少有一个像素位于螺旋路径经过的位置上，则标记该分量为"被触及"。
4. 在所有被触及的分量中，选取像素数最多的那一个。若存在面积相同的平局，选取边界框左上角更靠左的；仍相同则选更靠上的。
5. 输出为该选中分量的边界框裁剪：边界框内属于该分量的像素保持原色，其余位置填黑(0)。

**关键洞察**：螺旋不是绘图工具而是空间过滤器——障碍像素截断螺旋后，全局面积最大的分量可能恰好落在不可达区域内，从而被排除在候选集之外。求解者需要同时理解螺旋的几何轨迹和面积筛选规则，且仅从单个示例无法确定螺旋的方向约定和步长模式。

## 新题 2：图例串编程螺旋着色

**组合逻辑**：[边缘图例串/edge_legend_string](创新：从位置模板改为颜色程序序列) + [螺旋绘制/spiral_draw](已有) + [颜色位置匹配/color_position_matching](创新：匹配从"锚定"改为"循环索引") + [遇障碍停止/stop_at_blocker](已有)

**来源原语**：边缘图例串、颜色位置匹配 ← 5af49b42；螺旋绘制、遇障碍停止 ← e5c44e8f；种子像素 ← e5c44e8f

**依赖链**：图例串的颜色顺序决定了螺旋每一步的着色 → 螺旋的几何路径决定哪些位置被涂上图例中的哪种颜色 → 障碍像素截断螺旋，决定着色终止点。图例内容、螺旋轨迹、障碍位置三者共同决定输出图案，缺一不可。

用边缘图例串作为颜色程序，沿螺旋路径循环涂色，遇障碍停止。

**输入结构**：约 13×13 的黑(0)背景网格。顶行（第 0 行）从最左列开始有一段水平图例串，由 3~5 个紧邻的不同颜色像素组成（如 红(2)-蓝(1)-绿(3)-黄(4)），图例串右侧至行末为黑(0)。网格内部（非顶行）有一个品红(6)种子像素。另有 1~2 个灰(5)障碍像素。种子像素与图例串颜色均不同，障碍像素与图例串颜色均不同。生成约束：种子像素距最近障碍至少 4 步螺旋距离（保证至少绘制一圈以上的有效螺旋）；图例串长度在不同示例中可不同（用以验证求解者能归纳循环规则而非记忆固定序列）。

**规则**：
1. 识别顶行的水平图例串：从第 0 行最左列起，连续读取非黑(0)像素，直到遇到黑(0)或行末。记录颜色序列 C = [c_0, c_1, ..., c_{k-1}]，共 k 种颜色。
2. 从品红(6)种子像素出发，按方向序列"上→右→下→左"循环，步长序列 2, 2, 4, 4, 6, 6, ...，逐步追踪螺旋路径。维护一个全局步数计数器 i（从 0 开始）。
3. 对螺旋路径上的每一步：
   - 若该位置超出网格边界，跳过该步但 i 仍递增。
   - 若该位置是灰(5)障碍像素，在涂色前停止，螺旋终止。
   - 若该位置在网格内且不是障碍，将其涂为 C[i mod k]（图例序列的第 i mod k 个颜色），i 递增。
4. 种子像素本身保留品红(6)不变（不被螺旋覆盖）。图例串和障碍像素在输出中保持不变。
5. 所有未被螺旋涂色的黑(0)位置保持黑(0)。

**关键洞察**：图例串不是用于空间展开的模板，而是螺旋着色的"程序指令"——其颜色顺序被循环索引为每一步的涂色参数。同一图例串在不同种子位置或不同障碍布局下会产生完全不同的视觉图案，因为步数计数器 i 跟随螺旋的实际绘制进程（含越界跳过），不同示例中的 i 推进节奏不同。求解者必须同时理解螺旋几何和循环颜色映射才能还原规则。

## 新题 3：图例位置编码射线长度与交叉着色

**组合逻辑**：[边缘图例串/edge_legend_string](创新：位置编码几何参数而非用作模板) + [射线延伸/ray_extend](已有) + [行列交叉/row_col_intersection → 交叉点特殊着色/intersection_colored](已有原语新关系：交叉产生于不同长度射线的重叠) + [擦除/erase + 无匹配色则删除/unmatched_deleted](已有)

**来源原语**：边缘图例串、颜色位置匹配 ← 5af49b42；射线延伸、行列交叉、交叉点特殊着色 ← 23581191；擦除、无匹配色则删除 ← 1a07d186；碰撞停止 ← 2c608aff

**依赖链**：图例串的空间位置赋予每种颜色一个射线长度参数 → 每个像素的射线可达范围由此确定 → 不同颜色射线的交叉位置取决于各自的可达范围 → 无匹配色的像素被擦除。图例的排列顺序直接决定哪些射线能相交、在何处相交。

用边缘图例串中的颜色位置作为射线长度参数，每个匹配像素向四方延伸对应长度的射线，不同色射线交叉处标红，无图例匹配的像素被擦除。

**输入结构**：约 14×14 的黑(0)背景网格。顶行从最左列开始有一段水平图例串，由 3~4 个紧邻的不同颜色像素组成（如位置 0 为蓝(1)、位置 1 为绿(3)、位置 2 为黄(4)），图例串右侧至行末为黑(0)。网格内部（非顶行）散布 5~8 个孤立单像素，颜色各异——其中一些颜色出现在图例串中，另一些不出现。红(2)不在图例串和孤立像素中使用（保留给交叉标记）。孤立像素之间至少间隔 3 个像素。生成约束：至少存在两个不同颜色的匹配像素，其射线在各自允许长度内能在某个位置交叉（即存在一个位置同时在两个不同颜色像素的行射线和列射线的可达范围内）。

**规则**：
1. 识别顶行的图例串，记录颜色序列及每种颜色的从左起位置索引（1-起始：最左为 1，第二为 2，第三为 3...）。
2. 对每个孤立像素：
   - 若其颜色出现在图例串中，获取该颜色的位置索引 p。该像素向上、下、左、右四个方向各延伸恰好 p 个像素的射线，用该像素的颜色涂色。射线遇到网格边界时截断（不涂越界部分），遇到已有非黑(0)非图例行的像素时停止（不覆盖该像素，射线在其前一格终止）。
   - 若其颜色不在图例串中，擦除该像素（置为黑(0)）。
3. 所有匹配像素的射线同步计算（概念上同时画出）。若两条不同颜色的射线需要涂同一个位置，将该位置标记为红(2)。
4. 图例串本身在输出中保持不变。孤立像素原始位置保持其原色（射线从其相邻格开始，不覆盖像素自身）。

**关键洞察**：图例串在此题中不是用于复制的模板，而是一张"颜色→射程"查找表——位置靠后的颜色射线更长，能覆盖更远的区域。交叉标红的位置完全取决于图例中的位置编码：若交换图例串中两种颜色的顺序，同样的像素布局会产生不同的交叉图案。求解者需要对比不同示例中图例串长度和颜色顺序的变化，才能归纳出"位置 = 射程"这一非显然的编码规则。

## 新题 4：角标记编码瓦片旋转

**组合逻辑**：[平铺/tile](已有) + [旋转/rotate](创新：旋转角度由标记像素的角位置编码) + [印章覆盖/stamp_overlay](已有) + [分隔线/separator_line + 网格分区/grid_partition](已有) + [朝向映射/orientation_mapping](创新：从L形缺角映射改为标记角位置映射)

**来源原语**：平铺、分隔线、网格分区 ← c444b776；旋转、朝向映射 ← a25697e4；印章覆盖 ← 92e50de0；标记像素 ← 3e980e27；缺角决定目标象限 ← a61ba2ce

**依赖链**：分隔线确定单元格阵列 → 已填充单元格提供瓦片图案 → 空单元格中标记像素的角位置编码旋转角度 → 旋转后的瓦片覆盖印章至空单元格，标记像素保持原色覆盖在最上层。标记角位置与旋转角度的映射必须从多个示例中归纳，不同示例中标记位置不同，产生不同旋转。

识别分隔网格中唯一的已填瓦片，将其旋转后印章到每个空单元格中，旋转角度由空单元格角落中的标记像素位置决定。

**输入结构**：约 15×15 的黑(0)背景网格。灰(5)的满行和满列形成分隔线，将网格分割为 3×3 或 4×4 的等大矩形单元格（每个单元格约 3×3 至 4×4 像素）。恰好一个单元格包含一个由 2~3 种前景色组成的非对称图案（瓦片），该图案不具备 90 度旋转对称性（旋转 90/180/270 度后与原始均不同）。其余单元格为空（全黑(0)），但每个空单元格在其四个角位置之一（左上、右上、左下、右下）恰好有一个栗(9)标记像素。同一行的空单元格标记角位置可以不同。生成约束：瓦片图案在 4 个旋转态下视觉可区分；每个示例中至少出现 3 种不同的角标记位置。

**规则**：
1. 用灰(5)满行/满列分隔线将网格切分为矩形单元格。
2. 找到唯一包含非黑(0)非灰(5)图案的单元格，提取其中的图案作为基准瓦片（以单元格左上角为锚点的相对坐标）。
3. 对每个空单元格，定位其中的栗(9)标记像素，判断其位于单元格的哪个角（左上 / 右上 / 右下 / 左下）。
4. 根据角位置确定旋转角度：左上角 = 不旋转(0°)，右上角 = 顺时针 90°，右下角 = 顺时针 180°，左下角 = 顺时针 270°。
5. 将基准瓦片按确定的角度旋转后，印章覆盖到该空单元格中。旋转以单元格中心为旋转中心。
6. 栗(9)标记像素保持原色，覆盖在印章图案之上（即标记像素所在位置的颜色为栗(9)，不被瓦片颜色覆盖）。
7. 所有灰(5)分隔线在输出中保持不变。

**关键洞察**：标记像素的角位置同时扮演两个角色——既标记了"此单元格需要填充"，又编码了"用哪个旋转角度填充"。求解者无法从单个示例确定四个角位置与四个旋转角度之间的对应关系，必须对比至少 2~3 个不同角标记的单元格才能归纳映射规则。瓦片的非对称性是规则可区分的前提。

## 新题 5：最大分量框架拦截滑动物体

**组合逻辑**：[面积比较/area_comparison → 外框绘制/frame_draw](创新：面积排名决定哪个对象获得外框) + [滑动/sliding + 碰撞阻挡/collision_blocking](已有) + [重涂色/recolor](已有) + [尺寸倍增嵌套/size_doubled_nesting](已有)

**来源原语**：面积比较 ← 1f85a75f；外框绘制、尺寸倍增嵌套 ← db93a21d；滑动、碰撞阻挡 ← 1a07d186/4093f84a；重涂色 ← b94a9452；吸附体 ← 4093f84a

**依赖链**：面积比较在所有非吸附体分量中选出最大者 → 为最大分量绘制倍增外框（绿(3)） → 其余分量向吸附体滑动 → 滑动路径上若碰到绿(3)框则被框拦截、重涂为绿(3) → 未被拦截的分量到达吸附体、重涂为吸附体颜色。外框的位置取决于最大分量的位置，而外框反过来作为物理屏障改变其余分量的滑动终点和最终颜色。

找到面积最大的前景分量并为其绘制双倍外框，其余分量向灰色吸附体滑动，被外框拦截的分量变绿，到达吸附体的分量变灰。

**输入结构**：约 16×16 的黑(0)背景网格。包含以下元素：
- 一个灰(5)实心矩形吸附体（约 2×4 至 3×5 像素），位于网格的一侧（如右侧或底部）。
- 4~6 个单色 4-连通前景分量，大小从 2 像素到 10 像素不等，颜色互不相同且不为灰(5)或绿(3)，使用红(2)、蓝(1)、黄(4)、品红(6)、橙(7)等。形状不规则（可为线段、L形、块状等任意连通形态）。其中一个分量的面积严格大于其他所有分量（确保最大分量唯一）。
- 最大分量与吸附体之间有足够空间（至少 4 格）放置倍增外框且不与吸附体重叠。
- 部分小分量的滑动路径会穿过最大分量的倍增外框区域，部分不会（保证两种结局都出现）。
- 生成约束：任意两个非吸附体分量之间不共享行或列（避免滑动路径冲突）。

**规则**：
1. 识别灰(5)矩形为吸附体。在其余前景分量中，找到像素数最多的作为"锚分量"。
2. 以锚分量的边界框为基准，绘制一个尺寸为边界框两倍（宽和高各乘 2）的绿(3)空心矩形框，中心与锚分量的边界框中心对齐。锚分量本身保持原色不变（位于绿色框内部）。
3. 对除锚分量外的每个前景分量，计算其到灰(5)吸附体的最短基方向（上/下/左/右）距离，选择距离最短的方向作为滑动方向。
4. 按滑动距离从小到大的顺序依次处理每个分量（最近的先滑动）：
   - 将分量沿其滑动方向逐格移动。
   - 若分量的任何像素的下一步位置与绿(3)框的任何像素相邻（4-连通邻接），则分量停止，所有像素重涂为绿(3)。
   - 若分量到达吸附体（任何像素的下一步位置与灰(5)吸附体像素相邻），则分量停止，所有像素重涂为灰(5)。
   - 已停止的分量（无论变绿还是变灰）成为后续分量的碰撞障碍。
5. 输出保留吸附体、锚分量（原色）、绿色外框、以及所有滑动后停靠的分量（已重涂色）。

**关键洞察**：绿色外框既是视觉输出的一部分，又是影响其他分量命运的物理屏障——它拦截了部分滑向吸附体的分量。哪个分量生成外框由面积决定，而外框的空间位置又决定了谁被拦截。这形成了一个"面积→位置→命运"的因果链，任何一环缺失都无法预测最终输出。

## 新题 7：奇偶过滤的同色桥接

**组合逻辑**：[连线/draw_line](已有) + [同色配对/same_color_pairing](已有) + [同奇偶格接收副本/same_parity_receive_copy](创新：奇偶性从"接收副本"的条件改为"允许桥接"的过滤条件) + [分隔线/separator_line + 网格分区/grid_partition](已有) + [对向间隙/facing_gap + 最短间隙优先连/shortest_gap_first](已有)

**来源原语**：连线、同色配对、对向间隙、最短间隙优先连 ← f3b10344；同奇偶格接收副本 ← 92e50de0；分隔线、网格分区 ← c444b776

**依赖链**：分隔线定义单元格阵列及每个单元格的行列索引 → 行列索引确定奇偶性 → 同色像素对仅在双方均处于同奇偶单元格时才允许桥接 → 桥接路径通过最短间隙绘制。奇偶性是桥接的隐性门控条件，仅凭颜色匹配不足以预测输出。

在分隔网格中，仅连接位于同奇偶单元格中的同色像素对，通过最短间隙绘制桥接线。

**输入结构**：约 15×15 的黑(0)背景网格。橙(7)满行和满列形成分隔线，将网格切分为 4×4 或 5×5 的等大矩形开放单元格（每个约 2×2 至 3×3 像素）。部分单元格包含一个孤立前景像素（使用红(2)、蓝(1)、绿(3)、黄(4)等颜色）。每种前景色恰好出现 2 次（形成配对）。在所有配对中：至少一对的两个像素分别位于同奇偶单元格（行索引奇偶相同且列索引奇偶相同），至少一对的两个像素位于不同奇偶单元格。青(8)不在输入中使用（保留给桥接线）。生成约束：同奇偶配对的两个像素所在单元格在水平或垂直方向上对齐（共享行索引或列索引），且中间间隔的单元格（含分隔线）全为空（保证桥接路径无障碍）。

**规则**：
1. 用橙(7)满行/满列将网格切分为单元格，为每个单元格分配行索引 (row_idx) 和列索引 (col_idx)，均从 0 开始。
2. 定义奇偶性：单元格的奇偶类型为 (row_idx mod 2, col_idx mod 2)。两个单元格"同奇偶"当且仅当它们的奇偶类型完全相同。
3. 对每种前景色，找到其两个像素所在的单元格。
4. 若两个单元格同奇偶，则该对被标记为"可桥接"。否则该对不做任何操作。
5. 对每个可桥接的配对：
   - 确定两个像素之间的最短纯间隙路径（水平或垂直方向，路径经过的所有像素在输入中必须为黑(0)或橙(7)分隔线）。
   - 沿该路径绘制青(8)桥接线，从一个像素的相邻格画到另一个像素的相邻格（不覆盖像素自身），穿过分隔线时也涂为青(8)（覆盖橙(7)分隔线像素）。
6. 不可桥接的配对保持原样，其像素不变。所有其他分隔线和空单元格保持不变。

**关键洞察**：同色是桥接的必要条件但不充分——奇偶性是一个隐性过滤器，必须对比多个示例（有的同色对被连接、有的未被连接）才能发现奇偶规则。单个示例中可能恰好所有同色对都同奇偶（或都不同奇偶），只有对比多个示例才能确认奇偶性的筛选作用。

1. 识别精灵体：找到最大的多色连通前景区域（含标记像素），提取其边界框内的图案。记录标记像素的颜色（红(2)或绿(3)）。
2. 从品红(6)种子像素出发，按方向序列"上→右→下→左"循环，步长序列 2, 2, 4, 4, 6, 6, ...，追踪螺旋路径。记录每个方向切换的位置为"拐角"，拐角从 1 开始编号。

   - 若标记为红(2)：在偶数编号拐角（2, 4, 6, ...）处，先将精灵体水平镜像（左右翻转），再印章。奇数编号拐角不镜像。

5. 当螺旋路径连续 2 个拐角均因越界而跳过时，停止生成更多拐角（螺旋终止）。
6. 种子像素在输出中保持品红(6)。精灵体原始位置保持不变。多个印章若有像素重叠，后印的覆盖先印的。

## 新题 9：双向滑动累积与侧面竞赛

**组合逻辑**：[滑动/sliding](已有) + [碰撞阻挡/collision_blocking + 累积影响后续停靠/mass_affects_stops](已有) + [计数/counting](已有) + [满行列条/full_span_bar](已有) + [重涂色/recolor](创新：重涂色由双侧累积数量的比较结果决定)

**来源原语**：滑动、碰撞阻挡、累积影响后续停靠、最短基方向吸附 ← 4093f84a；满行列条 ← 1a07d186；计数 ← aa300dc3；重涂色 ← b94a9452

**依赖链**：满行列条将空间分为两侧 → 两侧的像素分别向条滑动并累积 → 累积质量影响后续像素的停靠位置 → 滑动结束后计数双侧累积像素总数 → 数量多的一侧所有累积像素重涂为条的颜色，少的一侧保持各自原色。计数结果决定重涂色对象，而累积顺序影响最终形态——两个逻辑交织。

两侧像素向中央横条滑动累积，滑动结束后累积数量多的一侧整体变色。

**输入结构**：约 14×14 的黑(0)背景网格。一条灰(5)满宽水平条（1 像素高）横贯网格中部（如第 6 行或第 7 行），将网格分为上半区和下半区。上半区散布 3~5 个孤立单像素，颜色各不相同（使用红(2)、蓝(1)、绿(3)、黄(4)、品红(6)等）。下半区散布 3~5 个孤立单像素，颜色各不相同且与上半区像素颜色不重复。灰(5)和黑(0)不用于孤立像素。生成约束：上半区和下半区的像素总数不相等（避免平局）；同一列中上下两侧最多各一个像素（避免列冲突）；每个像素与灰条之间无其他像素阻挡（初始状态下的直线路径畅通）。

**规则**：
1. 识别灰(5)满宽水平条及其行号 R。
2. 上半区像素（行号 < R）向下滑动，下半区像素（行号 > R）向上滑动。
3. 处理顺序：按像素到灰条的距离从小到大排列（距离 = |pixel_row - R| - 1）。距离相同时，上半区像素先于下半区像素处理。
4. 每个像素沿垂直方向逐格滑动。当像素的下一格是灰(5)条、或已停靠的其他像素时，像素停止在当前格。
5. 已停止的像素成为后续像素的障碍。如果同一列上方和下方各有一个像素，先处理的那个会靠近灰条，后处理的会被先到者阻挡在更远处。
6. 所有像素停止后，计数灰条上方（含紧贴灰条的像素）和下方分别累积了多少个像素。
7. 累积像素更多的一侧：该侧所有停靠像素重涂为灰(5)。累积像素更少的一侧：该侧所有停靠像素保持各自原色不变。
8. 灰条本身保持不变。未涉及的黑(0)区域保持黑(0)。

**关键洞察**：滑动的处理顺序创造了一种"先到先得"的竞争——距离近的像素占据了靠近灰条的位置，距离远的像素被推到外围。但最终决定命运的不是距离而是数量：人多的一侧被吸收（变灰），人少的一侧保持独立（保持原色）。这是一个"过程决定形态、结果决定颜色"的双层逻辑，且处理顺序的规则只有通过对比多个示例（不同距离配置下的不同停靠结果）才能确认。

**依赖链**：周期推断从非黑像素中恢复最小重复瓦片 → 瓦片预测每个黑色缺失位置应有的颜色 → 但实际填入的是该颜色的互换色（两种图案色互换后的对应色） → 填补后的区域与原始区域形成视觉上的"色反"对比。推断结果必须先正确得出，才能对其取反填入——推断和互换紧密耦合。

推断出周期瓦片后，用瓦片双色互换后的版本填充黑色缺失区域，使填补处呈现反色图案。

**输入结构**：约 10×10 至 12×12 的网格，无黑(0)大面积背景——整个网格被一个周期性壁纸图案覆盖。该壁纸图案恰好使用两种颜色（如红(2)和蓝(1)），形成棋盘格、条纹、或其他周期性二色图案。最小重复瓦片为 2×2 至 3×3 像素。网格中有若干区域的像素被替换为黑(0)（"缺失"），缺失区域形状为不规则连通块，总共占网格面积的 20%~40%。生成约束：缺失区域不完全覆盖瓦片的任何一个相位（即对于重复瓦片中的每个位置 (r mod tile_h, c mod tile_w)，至少有一个非黑像素在该相位上可观测，保证瓦片可唯一推断）；每个示例中使用的两种图案色可以不同（但同一示例内固定为两种）。

**规则**：
1. 将黑(0)视为缺失数据，忽略所有黑(0)像素。
2. 从剩余的非黑像素中推断最小面积的重复瓦片 T（即找到最小的 (tile_h, tile_w) 使得所有非黑像素满足 grid[r][c] == T[r mod tile_h][c mod tile_w]）。
3. 识别瓦片 T 中使用的两种颜色 A 和 B。
4. 对每个黑(0)位置 (r, c)：
   - 查找瓦片预测的颜色：predicted = T[r mod tile_h][c mod tile_w]。
   - 将该位置填入 predicted 的互换色：若 predicted == A，填入 B；若 predicted == B，填入 A。
5. 所有原始非黑像素保持不变。

**关键洞察**：直觉上，缺失区域应该被"修复"为瓦片预测的颜色（直接填入 predicted），但实际规则是填入反色。这意味着填补后的区域与周围的原始区域形成颜色反转的视觉对比，看上去像是壁纸在缺失区域"翻面"了。仅看单个示例时，求解者可能误认为填补区域使用的是一个不同的瓦片周期——只有对比多个示例中不同缺失位置的填补结果，才能发现"推断正确瓦片然后取反"这一规则，而非"使用不同的瓦片"。
