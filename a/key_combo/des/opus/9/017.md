## 新题 1：通道拓扑着色

**组合逻辑**：[膨胀求交](已有) → [计数·封闭背景区域](创新：计数对象从前景实体改为通道区域内的空洞) → [孔洞数映射颜色](已有) + [连通至边缘](已有，作为额外过滤条件)

**来源原语**：膨胀求交(f1bcbc2c)、通道(f1bcbc2c)、连通至边缘(f1bcbc2c)、计数(37d3e8b2)、封闭背景区域(37d3e8b2)、孔洞数映射颜色(37d3e8b2)、重涂色(多题)

**依赖链**：膨胀求交定义通道的几何范围 → 通道内封闭背景空洞的数量决定该通道段的输出颜色 → 但只有不连通至网格边缘的通道段才被着色，边缘连通的通道段保持不变。三步缺一不可：无膨胀求交则通道不存在，无空洞计数则颜色无据，无边缘连通判定则着色范围错误。

在黑色网格上，多组路径组件对的膨胀交集形成中间通道；通道被隔板分割成若干段，每段内的封闭空洞数决定着色，但只有不连通至网格边缘的段才被涂色。

**输入结构**：约 18x18 网格，背景黑(0)。橙(7)色像素形成 3~4 对 4-连通单像素宽路径组件，每对路径组件之间间距恰好 2 个像素（使膨胀求交产生恰好 1 像素宽的通道）。每条通道内，部分位置被灰(5)色像素占据形成"隔板"，将通道分割为若干段；其中一些段的背景像素被通道壁和灰隔板完全围住形成封闭空洞，另一些段的背景像素连通至网格边缘。网格大致尺寸保证每条通道长度在 6~12 像素之间。生成约束：每对路径产生的通道至少有 1 个、至多 4 个封闭空洞；不同对的通道互不相交；灰隔板仅出现在通道内部。

**规则**：
1. 对每对路径组件，将各自在 8-邻域膨胀一格，取两个膨胀结果的交集得到中间通道像素集合。
2. 在通道像素集合中，识别灰(5)像素为隔板；将隔板从通道中移除后，对剩余通道像素做 4-连通分量分解，得到若干通道段。
3. 对每个通道段，判断其是否有像素位于网格边界行或边界列：若是，标记为"边缘连通"，保持不变。
4. 对每个非边缘连通的通道段，计算该段像素与灰隔板共同包围的 4-连通封闭背景连通体数量（即封闭空洞数，不含连通至网格外部的背景）。按映射重涂该段所有像素：1 个空洞 → 蓝(1)，2 个 → 红(2)，3 个 → 绿(3)，4 个 → 黄(4)。
5. 灰隔板、橙路径、边缘连通通道段及所有背景像素保持不变。

**关键洞察**：通道不是直接给出的对象，而是两条路径膨胀求交的几何产物；通道的着色不取决于其长度或位置，而取决于其内部拓扑——封闭空洞数——这一信息只有结合隔板的分割效果才能获得。

## 新题 2：反转镜像补全

**组合逻辑**：[对称补全](创新：补全规则从同色复制变为反转映射) + [反转填充](创新：反转范围从固定瓷砖扩展到由对称轨道推导的镜像位置) + [面板对齐·分隔列](已有，定义左右面板)

**来源原语**：对称补全(af22c60d)、双轴镜像轨道(af22c60d)、反转填充/occupancy_inversion(1c0d0a4b)、分隔列(34b99a2b)、面板对齐(34b99a2b)

**依赖链**：分隔列将网格分为左右面板 → 右面板是左面板的水平镜像但占据关系反转（左侧前景对应右侧背景，左侧背景对应右侧前景色）→ 右面板中品红色损坏标记处需同时运用镜像位置对应和反转规则来恢复正确值。缺少对称分析则不知道位置对应关系，缺少反转规则则填错颜色。

右面板是左面板的"负片镜像"——镜像决定位置对应，反转决定颜色翻转；修复被损坏标记覆盖的像素。

**输入结构**：约 15x13 网格（奇数列宽），背景黑(0)。中间一列为黄(4)分隔线。左半区包含红(2)色像素构成的不规则图案（一个 4-连通形状，占据半区 30%~50% 的格子），其余为黑(0)。右半区大部分已正确填充：左半为红(2)的镜像位置在右半为黑(0)，左半为黑(0)的镜像位置在右半为蓝(1)。右半中有 4~6 个像素被替换为品红(6)（"损坏标记"），这些位置的正确值可能是黑(0)也可能是蓝(1)。生成约束：损坏标记中至少各有 1 个正确值应为黑(0)和应为蓝(1)的情况，使求解者必须同时理解镜像和反转两条规则。

**规则**：
1. 识别黄(4)分隔列，将网格分为宽度 W 的左半 L 和右半 R（不含分隔列）。
2. 左半 L 和右半 R 通过水平镜像对应：R 的第 j 列对应 L 的第 W-1-j 列。
3. 反转镜像规则：L[r, W-1-j] 为红(2) 时，R[r, j] 应为黑(0)；L[r, W-1-j] 为黑(0) 时，R[r, j] 应为蓝(1)。
4. 将右半所有品红(6)像素按上述规则替换为正确颜色。
5. 分隔列、左半、右半中非品红像素均不变。

**关键洞察**：右面板不是左面板的简单镜像复制，而是镜像加占据反转加颜色变换的三重叠加。蓝色图案恰好是红色图案的"负片"——必须同时把握镜像轴和反转关系才能修复损坏像素。仅从右面板自身的蓝色分布无法推断损坏像素的值，必须参照左面板。

## 新题 3：循环框架着色

**组合逻辑**：[框内包含·计数](创新：统计口径从全部标记改为少数色标记) → [循环相邻](创新：循环关系从色带间移至框架间) → [重涂色](创新：着色目标从框内对象改为框架边框本身)

**来源原语**：矩形框/inside_frame(c8b7cc0f)、计数(c8b7cc0f)、标记数映射填充(c8b7cc0f)、忽略干扰项(c8b7cc0f)、循环相邻(c4d1a9ae)、重涂色(多题)

**依赖链**：先识别各框架并确定循环顺序 → 在每个框架内部分别统计两种标记颜色的像素数并取少数色计数 → 将少数色计数映射为颜色 → 应用到循环顺序中下一个框架的边框上。计数必须发生在框内（需框架检测），映射结果应用到别的框架（需循环顺序），少数色判定需比较两种颜色的数量（需计数先完成）。

统计每个框内少数色标记的数量，映射为颜色后涂到循环顺序中下一个框的边框上。

**输入结构**：约 16x16 网格，背景黑(0)。包含 3~4 个不重叠的单像素厚矩形框，每个框至少 5x5，框色为灰(5)。每个框的严格内部散布红(2)和蓝(1)两色标记像素（每个框内两色都存在，各 1~4 个，且数量不等）。框外可能有额外的红或蓝干扰像素。框架按各框左上角列坐标从小到大排列形成循环顺序（最后一个的下一个是第一个）。生成约束：每个框内少数色数量在 1~4 之间；不同框的少数色数量至少有两个不同值（以便区分映射规则与固定颜色）。

**规则**：
1. 识别所有灰(5)单像素厚矩形框。
2. 按各框左上角列坐标从小到大排列，确定循环顺序 F_1, F_2, ..., F_n（F_n 的下一个是 F_1）。
3. 对每个框 F_i，统计其严格内部（不含边框像素）的红(2)像素数 R_i 和蓝(1)像素数 B_i。框外的同色像素为干扰项，忽略。
4. 取少数色计数 M_i = min(R_i, B_i)。
5. 将 M_i 映射为颜色：1 → 绿(3)，2 → 黄(4)，3 → 橙(7)，4 → 品红(6)。
6. 将框 F_{i+1} 的灰(5)边框像素全部重涂为 M_i 对应的映射颜色（即 F_i 的少数色计数决定 F_{i+1} 的边框色）。
7. 框内标记像素、背景、框外干扰像素均不变。

**关键洞察**：每个框的边框颜色不由自身内容决定，而由循环顺序中前一个框的内部统计量决定——必须全局分析所有框后才能着色任何一个。"少数色计数"而非"总标记数"是隐蔽的统计口径，需对比多个示例才能排除"总数""多数色""颜色差值"等替代假设。

## 新题 4：异或差异驱动的精灵印章

**组合逻辑**：[逐像素比较·异或差异判定](已有) → [图案印章](创新：印章位置由 XOR 差异确定而非预置占位符) + [编码映射·颜色图例](已有，来源面板身份决定印章种类和输出色)

**来源原语**：逐像素比较(34b99a2b)、异或差异判定(34b99a2b)、面板对齐(34b99a2b)、分隔列(34b99a2b)、图案印章(edb79dae)、编码映射(edb79dae)、精灵体(edb79dae)、颜色图例(edb79dae)、重涂色(多题)

**依赖链**：面板比较找出差异像素的位置及其来源面板 → 来源面板身份决定从精灵字典中取哪个精灵体 → 在输出网格的差异位置以该像素为锚点印章 → 精灵体的输出颜色由图例决定。XOR 定义"在哪里"印，来源侧定义"印什么"，图例定义"用什么色"，三者缺一不可。

比较两面板的异或差异，在差异位置按来源面板选取精灵体并印章，颜色由图例映射。

**输入结构**：约 17x19 网格，背景黑(0)。由上至下分三个区域：上部两面板区——左面板用红(2)绘制一个二值掩码图案，灰(5)分隔列居中，右面板用蓝(1)绘制另一个二值掩码图案，两面板各约 7x8 大小、大部分重叠、有 3~5 处差异（一侧有前景而另侧无）。下部精灵字典区（2~3 行高）：一个 3x3 边界框内的红(2)色不对称 4-连通小图形（3~5 像素），间隔后一个 3x3 边界框内的蓝(1)色不对称 4-连通小图形（3~5 像素，与红色图形形状不同）。字典区右侧为颜色图例：一个 1x2 格子对——左格红(2)右格绿(3)，表示红 → 绿；一个 1x2 格子对——左格蓝(1)右格黄(4)，表示蓝 → 黄。生成约束：差异位置彼此间距至少 4 格（使 3x3 印章范围互不重叠）；印章范围不超出面板区域；差异中至少各有 1 处来自左面板和右面板。

**规则**：
1. 识别灰(5)分隔列，分离左面板 L（红色掩码）和右面板 R（蓝色掩码）。
2. 逐像素对齐比较 L 和 R：找出所有异或差异位置——L[r,c] 为前景但 R[r,c] 为背景，或 R[r,c] 为前景但 L[r,c] 为背景。
3. 输出网格大小与单个面板相同，初始为全黑(0)；先将 L 和 R 共有前景位置（两侧都有前景）涂为灰(5)。
4. 从精灵字典区提取红色精灵体 S_R 和蓝色精灵体 S_B 的形状。从图例提取颜色映射。
5. 按差异位置从上到下、从左到右的顺序处理每个差异位置 (r, c)：若 (r,c) 在 L 中为前景，以 (r,c) 为精灵体边界框左上角将 S_R 印章到输出网格，印章颜色按图例从红(2)映射为绿(3)。若 (r,c) 在 R 中为前景，以 (r,c) 为锚点将 S_B 印章到输出网格，印章颜色按图例从蓝(1)映射为黄(4)。
6. 后印章的像素覆盖先印章的像素（但生成约束保证实际不发生重叠）。

**关键洞察**：差异位置不仅标记"哪里不同"，还标记"谁有而谁无"——来源面板的身份决定了印章的形状和最终颜色，形成从比较到查字典到颜色映射的三级推理链。输出中不存在原始的红或蓝色——所有颜色都经过图例变换。

## 新题 5：拓扑排序交替着色重排列

**组合逻辑**：[连通分量检测 → 计数·封闭背景区域](创新：孔洞数用作排序键而非直接映射颜色) → [排序](创新：排序键从水平位置改为拓扑属性) → [奇偶交替选择 → 重涂色](在排序后的序列上交替) → [滑动·沿轴排列](按排序顺序紧密排成一行)

**来源原语**：连通分量检测(12eac192)、计数(37d3e8b2)、封闭背景区域(37d3e8b2)、排序(817e6c09)、沿轴排列(817e6c09)、奇偶交替选择(817e6c09)、滑动(dd2401ed)、重涂色(多题)

**依赖链**：先检测前景连通体并计算各自封闭孔洞数 → 按孔洞数升序排列 → 排好序后在序列上做交替选择 → 被选中对象重涂一色、未选中的重涂另一色 → 所有对象按排序顺序紧密排列到输出网格的一行。排序依赖孔洞计数结果，交替选择依赖排序结果，输出的空间排列依赖排序顺序。

按封闭孔洞数排序前景对象，在排序后的序列上交替着色，然后紧密排列为一行输出。

**输入结构**：约 18x18 网格，背景黑(0)。包含 5~7 个互不相邻的红(2)色 4-连通前景对象，每个对象为不规则填充形状（约 8~15 像素），内含 0~3 个被该对象像素完全包围的 4-连通黑(0)封闭区域（孔洞）。对象散布在网格各处，无特定排列规律。生成约束：至少两个对象的孔洞数相同（同孔洞数时按对象边界框左上角的行坐标升序排列作为次序）；孔洞数 0~3 各至少出现一次。

**规则**：
1. 检测所有红(2)色 4-连通前景对象。
2. 对每个对象，找其边界框内被该对象像素完全包围的 4-连通黑(0)背景连通体数量（封闭孔洞数 H_i）。
3. 按 H_i 升序排列所有对象；H_i 相同时按边界框左上角行坐标升序排列。
4. 在排好的序列中，从第 0 个开始做交替选择：第 0, 2, 4, ... 个对象重涂为蓝(1)，第 1, 3, 5, ... 个保持红(2)。
5. 输出网格高度 = max(各对象边界框高度) + 2，宽度 = sum(各对象边界框宽度) + (对象数 - 1)（对象间留 1 列间距），背景黑(0)。将每个对象（保留内部结构和孔洞）按排序顺序从左到右依次放置，各对象在输出网格中纵向居中对齐。
6. 对象内部的孔洞保持黑(0)不变。

**关键洞察**：对象在输入中的空间位置是干扰项——真正的排列顺序由每个对象的内部拓扑（孔洞数）决定；而颜色不取决于孔洞数本身，而取决于排序后的序列位置奇偶性。必须先做拓扑分析，再排序，再着色——三步无法跳过或乱序。

## 新题 6：射线定义的动态对称轴补全

**组合逻辑**：[切割·射线分割](创新：射线不用于切割分离物体，而用于定义对称轴的位置) + [对称补全·双轴对称·四象限镜像](创新：对称轴不是固定中心线而是由控制像素动态定义)

**来源原语**：切割(4a21e3da)、控制像素(4a21e3da)、射线分割区域(4a21e3da)、对称补全(60d73be6)、双轴对称(60d73be6)、稀疏标记(60d73be6)、十字轴线(60d73be6)、四象限镜像填充(60d73be6)

**依赖链**：控制像素的位置决定射线方向 → 射线在网格中形成十字，定义对称轴的行索引和列索引 → 稀疏标记只出现在一个象限 → 按双轴对称将标记反射到其他三个象限。射线路径依赖控制像素位置，对称轴依赖射线路径，补全依赖对称轴——不能跳步。

由边缘控制像素发射的射线构成十字形对称轴，将一个象限内的稀疏标记反射补全到其他三个象限。

**输入结构**：约 15x15 网格，背景黑(0)。网格边缘有恰好 2 个绿(3)色控制像素：一个位于顶部边缘某列（非角落），一个位于左侧边缘某行（非角落）。从顶部控制像素向下延伸一条贯穿整列的垂直线（涂为绿(3)），从左侧控制像素向右延伸一条贯穿整行的水平线（涂为绿(3)），两线在网格内交叉形成绿色十字。十字将网格分为四个大小不等的象限。其中一个象限（如左上象限）内散布 3~5 个单像素的彩色标记，颜色从红(2)、蓝(1)、黄(4)、橙(7)中选取（每个标记可不同色）。其他三个象限无标记（仅背景）。生成约束：控制像素不在角落（使四象限大小不对称）；标记不在绿色十字线上；每个标记关于十字的三个反射位置均在网格内且不落在十字线上。

**规则**：
1. 识别网格边缘的绿(3)控制像素，一个在顶边（确定列索引 C_axis），一个在左边（确定行索引 R_axis）。
2. 沿 C_axis 列和 R_axis 行绘制绿(3)十字线（输入中已存在）。
3. 对十字划分出的四个象限中含有彩色标记的象限，逐一处理每个标记像素 (r, c)，计算其三个反射位置：
   - 水平轴反射：(2 * R_axis - r, c)
   - 垂直轴反射：(r, 2 * C_axis - c)
   - 双轴反射：(2 * R_axis - r, 2 * C_axis - c)
4. 在每个反射位置涂上与原标记相同的颜色。
5. 绿色十字、原标记、背景其余部分保持不变。

**关键洞察**：对称轴不是网格的几何中心线，而是由边缘控制像素动态定义的——改变控制像素位置就改变四个象限的大小比例和反射映射。求解者必须先从控制像素推导轴的实际位置，而非假设轴在网格正中。

## 新题 7：面积分流——小对象镜移，大对象借色

**组合逻辑**：[连通分量检测 → 面积阈值筛选](分流决策节点) → {小对象分支：[平移·镜像位置](创新：不标记而是物理移动)} + {大对象分支：[重涂色](创新：颜色来源不是固定映射而是最近小对象移动前的颜色)}

**来源原语**：连通分量检测(12eac192)、面积阈值筛选(12eac192)、平移(8ee62060)、镜像位置(8ee62060)、内部朝向不变(8ee62060)、重涂色(多题)

**依赖链**：连通分量检测得到所有对象及面积 → 面积阈值将对象分为大小两类，两类执行完全不同的操作 → 小对象平移到水平镜像位置（原位擦除）→ 大对象根据移动前的小对象位置计算最近邻，取最近小对象的颜色作为自身新颜色。大对象的重涂色依赖小对象的颜色和移动前位置，是一个顺序敏感的耦合：如果先移动再算距离，结果会不同。

小前景对象镜移到对称位置，大前景对象重涂为移动前距其最近的小对象的颜色。

**输入结构**：约 16x16 网格，背景黑(0)。包含 6~8 个互不相邻的单色 4-连通前景对象，颜色可为红(2)、蓝(1)、绿(3)、黄(4)中的任一种（不同对象颜色可不同）。面积分布：3~4 个"小对象"（面积 1~3 像素），3~4 个"大对象"（面积 >= 5 像素），无面积为 4 的对象。生成约束：每个小对象水平镜像后的位置不与任何大对象或其他小对象的镜像位置重叠；每个大对象有唯一的最近小对象（用边界框中心的曼哈顿距离衡量，无平局）。

**规则**：
1. 检测所有非背景 4-连通单色对象，记录各自颜色、像素集合、边界框中心坐标、面积。
2. 面积 <= 3 的为小对象集合 S，面积 >= 5 的为大对象集合 L。
3. 记录每个小对象 s 的原始边界框中心位置 center_s 和颜色 color_s。
4. 将每个小对象平移到水平镜像位置：保持行不变，新列起点 = 网格宽度 - 原边界框宽度 - 原列起点。保持内部像素排列不变（不做水平翻转）。原位像素擦为黑(0)。
5. 对每个大对象 l，计算其边界框中心到各小对象**原始**（步骤 3 记录的、移动前的）边界框中心的曼哈顿距离，取距离最小的小对象 s*。
6. 将大对象 l 的所有像素重涂为 color_{s*}。
7. 背景不变。

**关键洞察**：大对象的最终颜色取决于移动前的小对象位置而非移动后——求解者必须意识到距离计算发生在空间重排之前。如果用移动后的小对象位置计算最近邻，大对象将获得不同的颜色，导致错误输出。

## 新题 8：框内排序交替选择——奇偶锚由总数决定

**组合逻辑**：[框内包含 + 忽略干扰项](筛选范围) → [排序](创新：排序键从水平位置改为面积) → [计数](框内对象总数) → [奇偶交替选择](创新：起始相位由总数奇偶性动态决定) → [重涂色]

**来源原语**：矩形框/inside_frame(c8b7cc0f)、忽略干扰项(c8b7cc0f)、排序(817e6c09)、沿轴排列(817e6c09)、奇偶交替选择(817e6c09)、计数(c8b7cc0f/8597cfd7)、重涂色(多题)

**依赖链**：框界定目标区域并排除干扰 → 对框内对象按面积排序 → 统计框内对象总数 n → n 的奇偶性决定交替选择的起始相位 → 按该相位做交替选择并重涂。总数和排序都依赖框内检测，起始相位依赖总数，选择结果依赖排序和相位——环环相扣。

在矩形框内按面积排序对象，根据对象总数的奇偶性决定交替选择的起始相位，被选中对象重涂色。

**输入结构**：约 16x16 网格，背景黑(0)。一个灰(5)色单像素厚矩形框（至少 12x12）。框内包含 5~7 个互不重叠的红(2)色 4-连通小对象（每个面积 2~8 像素，形状不规则且各不相同）。框外散布若干红(2)色干扰像素（单像素或两像素小体）。生成约束：框内所有对象面积互不相同（保证排序无歧义）；不同示例中框内对象总数的奇偶性不同（以使起始相位规则可被归纳）。

**规则**：
1. 识别灰(5)矩形框。仅考虑严格位于框内部的红(2)色 4-连通对象。框外同色像素为干扰项，忽略。
2. 按面积从小到大排序框内对象，得到序列 O_0, O_1, ..., O_{n-1}。
3. 统计 n = 框内对象总数。
4. 若 n 为奇数，起始索引为 0（选第 0, 2, 4, ... 个）；若 n 为偶数，起始索引为 1（选第 1, 3, 5, ... 个）。
5. 被选中的对象重涂为蓝(1)，未选中的保持红(2)。
6. 灰框、干扰像素、背景不变。

**关键洞察**：交替选择的起始相位不是固定的——它由框内对象总数的奇偶性动态决定。若框内有 5 个对象（奇数），选第 0, 2, 4 个；若另一示例有 6 个（偶数），选第 1, 3, 5 个。这个相位翻转规则必须通过对比奇偶不同的多个示例才能发现。

## 新题 9：增长信号驱动的差异化色带填充

**组合逻辑**：[两区域比较·最大增长差](选出全局信号色) → [填充](创新：上下两半采用完全不同的填充策略) + [空缺借邻色填充·循环相邻](仅用于下半) + [横分隔线](区域定义)

**来源原语**：两区域比较(8597cfd7)、最大增长差(8597cfd7)、横分隔线(8597cfd7)、竖向色带(c4d1a9ae)、填充(c4d1a9ae)、空缺借邻色填充(c4d1a9ae)、循环相邻(c4d1a9ae)

**依赖链**：分隔线将网格分为上下两半 → 在两半中分别统计各色带的像素数 → 找出增长差最大的色带颜色作为信号色 → 上半区所有色带的空缺统一用信号色填充 → 下半区按循环邻色规则填充空缺。信号色的确定依赖跨区域比较，上半区填充依赖信号色，下半区填充依赖色带循环顺序——两半的填充规则不同且各自依赖不同前置分析。

比较分隔线上下各色带的增长量，增长最大的色带颜色成为上半区统一填充色；下半区则按循环邻色规则各自填充。

**输入结构**：约 16x20 网格，背景黑(0)。中间一行为灰(5)水平分隔线。上下两半各包含 3~4 条竖向色带，颜色从红(2)、蓝(1)、绿(3)、黄(4)中选取（每条色带一种颜色），每条色带占据固定的列范围（上下半对应的色带占相同列范围，颜色相同）。每条色带内部分像素为该色带颜色，部分为黑(0)背景（空缺）。上半区各色带的非空像素整体较少，下半区较多（体现"增长"）。生成约束：恰好一个颜色的增长差（下半像素数减去上半像素数）严格最大；上半区每条色带至少有 1 个空缺像素；色带列范围互不重叠；色带外的区域全为背景。

**规则**：
1. 识别灰(5)水平分隔行，分离上半 U 和下半 D。
2. 确定所有非背景、非灰的颜色及其列范围（色带定义）。
3. 对每种色带颜色 C，统计 U 中颜色 C 的像素数 U_C 和 D 中颜色 C 的像素数 D_C，计算增长差 G_C = D_C - U_C。
4. 取 G_C 最大的颜色为信号色 S。
5. 上半区填充：在 U 中，所有色带列范围内的黑(0)空缺像素统一涂为信号色 S。
6. 下半区填充：按色带从左到右排列确定循环顺序。每条色带内的黑(0)空缺像素涂为右邻色带的颜色（最右色带的空缺涂为最左色带的颜色，循环）。
7. 分隔线、色带外背景保持不变。

**关键洞察**：上下两半的空缺填充遵循完全不同的规则——上半区用全局信号色（由跨区域比较确定，所有色带一视同仁），下半区用局部循环邻色（每条色带借用右邻色带的颜色）。求解者必须发现上下规则的不对称性，而非假设存在一条适用于全局的统一填充规则。

## 新题 10：连线构造对称轴的选择性反射

**组合逻辑**：[连线·仅相邻锚点间连接](已有) → [对称补全](创新：对称轴不是预设结构而是由连线动态生成) + [面积阈值筛选](创新：决定哪些对象参与反射、哪些保持不动)

**来源原语**：连线(60a26a3e)、空心十字标记(60a26a3e)、同行同列对齐(60a26a3e)、仅相邻锚点间连接(60a26a3e)、对称补全(af22c60d/60d73be6)、面积阈值筛选(12eac192)、连通分量检测(12eac192)、重涂色(多题)

**依赖链**：识别空心十字标记并在同行对齐的相邻标记间连线 → 连线所在行成为水平对称轴 → 检测非标记的前景对象并按面积分类 → 小对象跨对称轴反射到镜像位置 → 大对象保持不动。连线定义轴（缺少则不知反射方向），面积判定决定哪些对象被反射（缺少则不知操作范围），两者结合才确定"什么对象反射到哪里"。

连接同行对齐的标记后，将连线作为对称轴，仅把小面积对象反射到轴另一侧。

**输入结构**：约 18x18 网格，背景黑(0)。包含 2 个红(2)色空心十字标记（3x3 边界框中仅上下左右四个臂像素存在、中心为黑），两标记中心位于同一行但相距若干列（中间全为黑背景）。网格中还散布若干蓝(1)色 4-连通前景对象：3~4 个小对象（面积 1~2 像素）和 1~2 个大对象（面积 >= 4 像素），全部位于标记连线所在行的上方（即轴的一侧）。生成约束：每个小对象关于连线行反射后的位置不与任何现有对象重叠且在网格内；大对象不跨越连线所在行；两标记之间无其他标记或前景对象。

**规则**：
1. 识别红(2)空心十字标记（3x3 中上下左右有像素、中心为空的结构），计算各标记中心位置。
2. 两标记中心在同一行 R_axis。在两标记中心之间的该行背景像素上涂红(2)，形成水平连线段。R_axis 即为对称轴。
3. 检测所有蓝(1)色 4-连通前景对象，计算各自面积。
4. 面积 <= 2 的为小对象：将其每个像素关于 R_axis 行反射（新行 = 2 * R_axis - 原行），在反射位置涂蓝(1)。原像素保留不变。
5. 面积 >= 4 的为大对象：保持不变。
6. 背景、标记、连线不变。

**关键洞察**：连线不只是视觉连接——它定义了反射轴的具体行位置；而面积阈值控制了哪些对象参与反射。大对象作为位置参照保持不动，小对象则被"投影"到轴的另一侧。没有连线就无法确定轴在哪里，没有面积判定就不知道反射范围——两条信息分别来自不同的视觉线索。
