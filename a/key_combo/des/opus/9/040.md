## 新题 1：路径穿裂分离

**组合逻辑**：[路径生长(path_grow)](创新：路径不仅导航还具有破坏性) + [擦除(erase) + 滑动(slide)](创新：由路径的穿越动态触发，而非预设裂缝) + [障碍偏转(obstacle_deflection)](创新：分裂产生的位移碎片成为其他路径的新障碍)

**来源原语**：路径生长 ← d9f24cd1/712bf12e; 擦除+滑动+沿短轴分裂 ← 2faf500b; 障碍偏转 ← 712bf12e

**依赖链**：路径向上生长遇到前景对象时触发分裂滑动（操作A的空间推进激活操作B）；分裂滑动改变了空间布局，被推开的碎片可能占据其他路径的前进列，导致后续路径需要停止或到达不同高度（操作B的输出反向约束操作A的其他实例）。路径的处理顺序决定了最终布局——这是操作间的交叉耦合而非线性传递。

从底行种子向上生长路径，路径穿过前景对象时将其沿穿越列一分为二并向两侧推开一格，路径穿过空隙继续上行；先处理的路径产生的碎片位移影响后续路径的行进空间。

**输入结构**：约 15x15 黑(0)背景网格。底行有 2-3 个红(2)种子像素，彼此水平间距不小于 5 列。网格中散布 2-3 个蓝(1)4-连通单色对象（每个 6-12 像素，形状不规则但边界框为宽度不小于 3 的非正方形矩形），对象之间互不相邻，不在底行或顶行。生成约束：每个对象的边界框列范围至多被一条路径的列穿过；对象分裂后的碎片左移或右移一格后不会与其他对象重叠；至少一个对象的分裂碎片位移后会占据另一条路径所在列的某个位置。

**规则**：
1. 按种子从左到右的顺序，依次处理每条路径。
2. 从当前红(2)种子位置开始，逐格向上生长路径（将经过的黑(0)像素绘为红(2)）。
3. 若路径的下一格（正上方一格）为蓝(1)对象像素：识别该像素所属的整个 4-连通蓝色对象，沿路径所在列将该对象切割——位于切割列严格左侧的所有对象像素整体左移一格，位于切割列严格右侧的所有对象像素整体右移一格，切割列上的对象像素全部擦除为黑(0)。
4. 切割完成后，路径穿过已清空的切割列继续向上生长。
5. 若路径的下一格为红(2)（已被另一条先前路径占据），当前路径停止。
6. 路径到达网格顶行（行 0）后自然终止。
7. 碎片位移后超出网格边界的像素丢弃。

**关键洞察**：路径同时是导航和破坏——每次穿越对象不仅画线还改变空间布局。路径间通过"分裂碎片占据后续路径前方空间"产生间接耦合，使得种子的左右处理顺序成为影响最终图案的隐蔽规则。必须对比多个示例才能确认是从左到右的顺序而非其他规则。

## 新题 2：缺角射线交汇染色

**组合逻辑**：[缺角定位(missing_corner_pos)](已有) → [射线延伸(ray_extend)](创新：射线方向由缺角的几何位置编码，而非固定方向) → [碰撞检测+重涂色(recolor)](创新：两条独立射线的空间交汇涌现出第三种颜色)

**来源原语**：缺角定位 ← ac0c5833/1478ab18; 射线延伸 ← 73c3b0d8/c87289bb/9772c176; 重涂色 ← d6e50e54

**依赖链**：缺角的几何位置编码了射线的发射方向（缺角定位→射线参数），各射线独立延伸后在空间上交汇，交汇像素改色（射线输出→碰撞判断→重涂色）。输出的红色像素不可直接从输入读取，必须经过"推断方向→生成射线→检测交汇"三步推理。

从每个三角标记框的缺角向外发射两条轴对齐射线，射线交汇处涌现出新的颜色标记。

**输入结构**：约 18x18 黑(0)背景网格。3-4 组黄(4)标记像素，每组恰好 3 个像素，构成一个边长 3-5 格正方形边界框的三个角（即正方形四角中的三个有黄(4)像素，一个角无像素）。不同组的缺角位置各不相同（分别在左上/右上/左下/右下四个象限方位）。各组标记互不重叠且各组边界框之间至少间隔 2 格。生成约束：各组射线的延伸路径在网格内至少产生 2 处交汇（即至少 2 个像素同时位于两条不同组的射线上）。

**规则**：
1. 保留所有输入像素不变。
2. 对每组三标记，确定其边界框四角中无黄(4)标记的那一个角的坐标，记为缺角位置 (r, c)。
3. 从缺角位置分别发射水平和垂直两条射线，方向为远离该组边界框中心的外侧：若缺角在边界框左侧则水平射线向左，右侧则向右；若在上侧则垂直射线向上，下侧则向下。
4. 每条射线从缺角位置的相邻一格开始（不含缺角位置本身），沿对应方向逐格绘制绿(3)像素，直到遇到非黑(0)像素或到达网格边界为止（不含终止位置的像素）。
5. 射线绘制完成后检查：若某个像素被两条或以上来自不同标记组的射线同时覆盖（即该位置在两次独立射线绘制中都被标记），将该像素改为红(2)。
6. 仅被一条射线覆盖的像素保持绿(3)。

**关键洞察**：红(2)像素不是输入中标记的，而是两组独立射线在空间上的交汇涌现。要预测红色位置，必须先从缺角几何推断每组射线的方向和范围，再检测重叠。缺角方位编码射线方向这一规则需对比多组标记才能归纳。

## 新题 3：跨面板周期种子扩展

**组合逻辑**：[双面板(dual_panel) + 标记模式匹配(marker_pattern_match)](创新：匹配关系从精灵体标记变为周期图案的颜色匹配) → [周期(period) + 平铺(tiling)](创新：周期参数从源面板读取但相位由目标面板种子位置决定)

**来源原语**：双面板+标记模式匹配 ← e6721834; 种子像素 ← 8403a5d5; 周期+平铺 ← 963e52fc; 周期间隔 ← 8403a5d5

**依赖链**：源面板提供周期图案（参数来源），目标面板的种子提供颜色匹配键（配对依据）和列位置（相位编码）。颜色匹配确定"用哪个图案"，种子列位置确定"从周期的哪个相位开始"——两个信息缺一不可，且来自不同面板。

参照源面板中完整周期图案的周期和颜色，将目标面板中的种子像素扩展为对应颜色的周期条纹，种子的列位置决定条纹的相位偏移。

**输入结构**：约 10x21 网格。中间第 10 列为灰(5)分隔列，将网格分为左面板（列 0-9，10 列宽）和右面板（列 11-20，10 列宽），两面板等宽。左面板（源）：黑(0)背景上有 3 个完整的水平周期条纹，每个条纹占据一行，使用不同颜色（蓝(1)、红(2)、绿(3)），每个条纹由该颜色像素按固定周期 T（T 在 2-4 之间，各条纹周期可不同）排列，周期内非该颜色的位置为黑(0)。右面板（目标）：黑(0)背景上仅有 3 个孤立种子像素，颜色分别为蓝(1)、红(2)、绿(3)，每种颜色恰好一个种子，种子所在行位置与源面板中同色条纹的行位置不同。生成约束：三种颜色在源面板中各出现在恰好一个条纹行中；种子的列位置各不相同。

**规则**：
1. 保留左面板和灰(5)分隔列不变。
2. 对右面板中的每个种子像素（颜色为 C，位于行 r、列 c）：
   a. 在左面板中找到使用颜色 C 的条纹行。
   b. 读取该条纹行的最短水平周期 T 和周期内的颜色序列 P（长度为 T 的序列，由颜色 C 和黑(0)组成）。
   c. 计算种子在右面板内的本地列号 lc = c - 11（面板内偏移）。
   d. 在右面板的行 r 上，对每个列位置 j（j 从 11 到 20）：绘制颜色 P[(j - c) mod T]，即以种子列 c 为相位零点，向左右延伸周期序列 P。
3. 种子像素本身属于其条纹的一部分（P[0] 必为颜色 C）。

**关键洞察**：种子像素同时编码了三个信息——颜色（选择哪个源图案）、行（条纹输出在哪行）、列（周期的相位起点）。其中颜色→图案选择通过对比多个示例容易归纳，但列位置→相位偏移是隐蔽规则：如果只看一个示例，无法区分"种子列决定相位"和"条纹总是从面板左端开始"。

## 新题 4：双重约束路径路由

**组合逻辑**：[射线延伸+重力下落(gravity_drop)](已有) + [绕行(detour) + 遇障碍绕最近侧(detour_nearest_side)](已有) + [填充(fill) + 标记框内保护(marker_bbox_protect)](创新：保护区作为第二种异质障碍与实体障碍同时约束路径)

**来源原语**：射线延伸+绕行+遇障碍绕最近侧 ← c87289bb; 源列+障碍线段 ← c87289bb; 填充+标记框内保护+空心矩形+标记像素 ← d37a1ef5; 内部区域 ← d37a1ef5

**依赖链**：路径向下延伸时同时受两种独立约束——实体障碍段（碰撞绕行）和保护区域（区域禁入绕行）。两种约束的绕行机制相同但触发条件不同（接触像素 vs 进入区域），且一次绕行可能导致路径偏移到另一种约束的影响范围内，产生连锁绕行。路径的最终轨迹是两种约束交互作用的结果，无法通过单独考虑任一种约束得到。

源列向下延伸时绕过红色实体障碍段并避开蓝色标记定义的保护区域，两种性质不同的约束同时生效并可能产生连锁绕行。

**输入结构**：约 18x18 黑(0)背景网格。顶行（行 0）有 3-4 个青(8)源像素。网格中部有 2-3 段红(2)水平障碍线段（每段 3-5 像素宽，占据一行中连续的若干列），各段不在同一行。网格中另有 1-2 个黄(4)一像素宽空心矩形框（约 4x4 到 6x6），框内部散布有蓝(1)标记像素（2-3 个），蓝标记像素的边界框定义了保护区域。生成约束：红色障碍段不与黄色空心矩形重叠；至少一条源列的自然延伸路径会先遇到一种障碍绕行后再进入另一种障碍的影响范围；各源列间距足够大使路径不会互相阻塞。

**规则**：
1. 复制输入到输出。
2. 从每个青(8)源像素向下逐格延伸竖线（绘青(8)），直到网格底行。
3. 实体障碍绕行：若竖线的下一格为红(2)障碍段像素，在障碍段正上方一行从当前列画一条青(8)水平连线到该障碍段最近的外侧端点列（即障碍段左端列-1 或右端列+1，选距离当前列更近的一侧；距离相等时选右侧），然后从该外侧列继续向下延伸。
4. 保护区绕行：若竖线的下一格的列位置落在保护区域内部（蓝标记像素边界框严格内部，不含边界框边缘），在保护区上边界行从当前列画一条青(8)水平连线到保护区边界框最近的外侧列（左边界列-1 或右边界列+1，选距离当前列更近的一侧；距离相等时选右侧），然后从该外侧列继续向下延伸。
5. 两种绕行按路径从上到下推进时遇到的先后顺序依次处理。一次绕行偏移后的新列位置如果在继续下行时再次触发任一种障碍，则再次绕行。
6. 青(8)竖线和水平连线均只绘制在黑(0)背景像素上，不覆盖已有的红(2)、黄(4)或蓝(1)像素。

**关键洞察**：红色障碍段是"接触即绕行"（实体碰撞），蓝色保护区是"进入即绕行"（区域禁入）——同一条路径上两种不同性质的约束交替出现，绕行一种障碍可能使路径偏入另一种障碍的范围，产生不可预见的连锁效应。单独理解任一种障碍的绕行规则无法正确预测最终路径。

## 新题 5：频率角色驱动的分裂与重涂

**组合逻辑**：[角色分配(role_assignment) + 按频率分配(freq_role_assignment)](创新：频率排序不决定图案布局而决定操作类型分派) → [擦除(erase) + 滑动(slide) + 沿短轴分裂(split_along_short)](条件性触发) + [重涂色(recolor)](条件性触发)

**来源原语**：角色分配+按频率分配 ← 3979b1a8; 擦除+滑动+沿短轴分裂+裂缝标记线 ← 2faf500b; 重涂色 ← d6e50e54/0becf7df

**依赖链**：全局统计（像素频率排序）决定每种颜色在变换中的角色——哪种颜色的像素被擦除、哪种颜色的对象被分裂、哪种颜色的对象被重涂。这不是线性流水线，而是一个条件分支结构：先做全局分析（频率排序），然后根据分析结果将不同的操作分派给不同的颜色。操作 A（擦除裂缝标记）的执行使操作 B（分裂滑动）成为可能——裂缝线消失后才能沿切口推开两半。

按全局像素频率给三种前景色分配角色：最稀有色标记裂缝线并被擦除，中间频率色的对象沿裂缝分裂两半各推开一格，最常见前景色的对象整体重涂为最稀有色。

**输入结构**：约 14x14 黑(0)背景网格。三种非背景前景色（如蓝(1)、红(2)、绿(3)）的像素分布如下：中间频率色构成 2-3 个 4-连通单色对象（每个 8-14 像素），每个对象的边界框为非正方形矩形，对象内部含有最稀有颜色的像素，这些最稀有色像素在每个对象内构成一条沿对象短轴的完整横切线（即裂缝线——若对象边界框宽>高则为一完整垂直列，若高>宽则为一完整水平行）。最常见前景色构成 2-3 个 4-连通单色对象（每个 10-18 像素），这些对象内部不含其他颜色。最稀有色仅以裂缝线形式出现在中间频率色对象内部，不单独成对象。生成约束：三种颜色的总像素数互不相等且差距不小于 5 像素；各对象互不相邻。

**规则**：
1. 统计三种前景色在整个网格中的总像素数，确定最稀有色 Cr（总数最少）、中间频率色 Cm（总数居中）、最常见前景色 Cf（总数最多）。
2. 擦除所有 Cr 像素——将它们改为黑(0)背景。
3. 对每个 Cm 色对象：该对象现在有一条沿短轴的空缺带（原裂缝线位置已被擦除）。将空缺带一侧的 Cm 像素沿垂直于空缺带的方向外移一格，另一侧同样外移一格（两半分离）。具体地：若空缺带为垂直列，左侧像素整体左移一格，右侧整体右移一格；若空缺带为水平行，上侧像素整体上移一格，下侧整体下移一格。
4. 对每个 Cf 色对象：将其所有像素重涂为 Cr 色。
5. 背景像素不变。位移超出网格边界的像素丢弃。

**关键洞察**：颜色的全局统计频率决定了每种颜色在变换中的角色分派——同样的三种颜色在不同示例中可能因像素数量不同而扮演不同角色。单看一个示例只能观察到操作结果，必须对比多个示例中颜色角色的变化才能归纳出"按频率排序分配角色"这一隐蔽规则。

## 新题 6：印章形状驱动的递减外扩

**组合逻辑**：[印章覆盖(stamp_overlay) + 标记锚定精灵(marker_anchors_sprite)](已有) → [递减填充(shrinking_fill) + 边缘行程(side_run) + 四方外扩(four_way_expansion)](创新：递减填充的参数由被印章的精灵体形状决定，形状信息在操作间传递)

**来源原语**：印章覆盖+标记锚定精灵+标记模式匹配+精灵体 ← e6721834; 递减填充+边缘行程+四方外扩+逐步缩短行程 ← 9772c176; 外推 ← 9772c176

**依赖链**：印章操作将精灵体复制到多个位置（操作A），每个副本的边缘行程由精灵体的形状决定。递减外扩（操作B）的几何参数（条纹的初始长度和缩减速率）完全取决于边缘行程——即操作A传递给操作B的不仅是位置信息，还有形状信息。改变精灵体的形状会改变所有副本的外扩效果。

**输入结构**：约 18x18 黑(0)背景网格。网格中有一个蓝(1)4-连通精灵体（边界框约 4x4 到 6x6，不规则形状，至少在上、下、左、右四边各有长度不小于 3 像素的连续边缘行程），精灵体内含 2-3 个红(2)标记像素。网格其他区域散布 2-3 组红(2)标记像素，每组的红标记相对位置与精灵体内红标记的相对位置完全匹配。生成约束：各标记组间距足够大（边界框间至少间隔 8 格），使得印章后的递减外扩不会越过其他精灵体副本的边界框；精灵体的四边边缘行程长度不全相同（至少有两边长度不同）。

**规则**：
1. 找到蓝(1)精灵体内所有红(2)标记像素，记录其相对于精灵体边界框左上角的坐标偏移集合 M。
2. 在网格中搜索所有红(2)标记像素组，使得某组标记的相对坐标偏移集合与 M 完全匹配。
3. 对每个匹配的标记组：以标记对齐的方式将蓝(1)精灵体印章到该位置——精灵体的蓝(1)像素绘制到目标位置，精灵体边界框内的黑(0)像素不绘制（即背景透明）。
4. 对每个已印章的精灵体副本（包含原始精灵体），检测其四边（上、下、左、右）的边缘行程：上边行程 = 精灵体最上行中连续蓝(1)像素的最长段长度；下边行程 = 最下行中同理；左边行程 = 最左列中连续蓝(1)像素的最长段长度；右边行程 = 最右列中同理。
5. 从每条边向外发射递减条纹（颜色黄(4)）：以该边行程为初始长度，每向外多一行/列，条纹长度减少 2 像素（两端各缩进 1 像素，保持居中），条纹在长度减至 0 时停止。具体地：上边向上延伸，第 k 层（k=1,2,...）的条纹长度为 max(0, 上边行程 - 2k)，条纹居中于上边行程的中心列位置；其余三边类似。
6. 递减条纹只绘制在黑(0)背景像素上，不覆盖已有的蓝(1)或红(2)像素。

**关键洞察**：递减外扩的几何形状不是固定的——它完全由精灵体的边缘轮廓决定。精灵体的不规则形状导致四边行程不同，从而四个方向的递减条纹高度各异。印章复制了形状，形状编码了递减参数，这种"形状即指令"的关系是两个操作的核心耦合。

## 新题 7：网格补全后种子区域填充

**组合逻辑**：[补全(completion) + 相邻像素标有效线(adjacent_marks_line)](已有) → [填充(fill)](创新：填充的区域边界由补全操作动态构建而非预先给定) + [种子像素(seed_pixel)](创新：种子不生成周期图案而是驱动区域洪水填充)

**来源原语**：补全+相邻像素标有效线+网格线+缺口 ← 4612dd53; 填充+内部区域 ← d37a1ef5; 种子像素 ← 8403a5d5

**依赖链**：网格补全（操作A）构建了封闭的矩形区域边界，种子区域填充（操作B）依赖这些边界来限定填充范围。若不先补全网格，缺口将导致区域不封闭，种子颜色会错误扩散到相邻区域。两个操作紧密耦合：A 的输出（完整网格线）是 B 的前提条件（封闭边界），且 A 的具体补全位置直接决定了 B 的填充范围大小。

先补全断裂的蓝色正交网格线（用蓝色填补缺口），再将每个被网格围成的封闭区域洪水填充为其内部唯一种子像素的颜色。

**输入结构**：约 14x14 黑(0)背景网格。蓝(1)像素构成一个不完整的正交网格：若干水平线和垂直线交叉形成格子，但部分线段有 1-3 像素的缺口（即该行/列上某些位置是黑(0)而非蓝(1)）。蓝像素的整体边界框约 10x10 到 12x12。网格有效水平线和有效垂直线各 3-5 条（有效线的定义：该行/列内存在至少一对水平/垂直相邻的蓝(1)像素）。补全后的网格将整体边界框内部划分为若干矩形区域。其中部分区域（3-5 个）内恰好有一个非蓝非黑的彩色种子像素（颜色取自红(2)、绿(3)、黄(4)、品红(6)等，同色种子可出现在不同区域），其余区域无种子。生成约束：每个有种子的区域恰好一个种子；补全后每个种子确实被封闭在一个矩形区域内；种子不在网格线上。

**规则**：
1. 在蓝(1)像素的边界框范围内，识别所有有效水平线行（行内存在至少一对水平相邻的蓝(1)像素）和所有有效垂直线列（列内存在至少一对垂直相邻的蓝(1)像素）。
2. 将有效行和有效列上的所有黑(0)像素改为蓝(1)，完成网格补全。
3. 补全后的蓝色网格线将边界框内部划分为若干矩形区域（区域不含网格线像素本身）。
4. 对每个矩形区域：检查其内部是否恰好有一个非蓝(1)非黑(0)的种子像素。
5. 若有恰好一个种子，将该区域内所有黑(0)像素填充为种子的颜色。种子像素本身保留。
6. 无种子的区域保持黑(0)不变。
7. 蓝(1)网格线像素不被填充覆盖。

**关键洞察**：网格补全不是最终目标而是必要的中间步骤——它构建了后续填充操作所需的封闭边界。未补全的网格无法正确划分区域，种子颜色将通过缺口错误扩散。"有效线"的判定规则（相邻像素对标记）需对比输入中有缺口和无缺口的行/列才能归纳出。

## 新题 8：递减外扩碰撞边界

**组合逻辑**：[递减填充(shrinking_fill) + 四方外扩(four_way_expansion) + 逐步缩短行程(progressively_shortened)](已有，多实例并行) → [碰撞检测 + 重涂色(recolor)](创新：两个独立递减填充的空间重叠涌现出边界标记色)

**来源原语**：递减填充+四方外扩+边缘行程+逐步缩短行程+外推+圆润对象 ← 9772c176; 最近距离 ← d6e50e54; 重涂色 ← d6e50e54

**依赖链**：每个对象独立生成递减外扩条纹（操作A的多个并行实例），但输出不是简单叠加——两组条纹空间重叠的像素必须标记为碰撞色（操作B）。碰撞色的位置无法从单个对象的属性推断，只有同时计算所有对象的外扩范围并检测交集才能确定。这是并行生成后的涌现效应。

多个圆润对象各自向四方发射递减条纹，来自不同对象的条纹重叠处涌现出红色碰撞边界。

**输入结构**：约 20x20 黑(0)背景网格。3-4 个青(8)4-连通圆润对象，每个对象 8-16 像素，形状近似对称（上下左右边缘行程各不少于 3 像素），不同对象的形状和大小可以不同。对象间距不小于 6 格。生成约束：至少两对对象的递减外扩条纹在某些像素位置重叠（即存在像素同时位于两个不同对象的外扩范围内）；对象足够远使得它们的蓝色本体互不接触。

**规则**：
1. 保留所有输入青(8)像素不变。
2. 对每个青(8)对象，提取其四边（上、下、左、右）的边缘行程长度：上边行程 = 对象最上行中连续青(8)像素的最长段长度；下/左/右类似。
3. 从每条边向外发射递减条纹：第 k 层（k=1,2,...）条纹长度为 max(0, 该边行程长度 - 2k)，条纹居中于该边行程的中心位置，方向向外（上边向上、下边向下、左边向左、右边向右）。条纹在长度减至 0 时停止。
4. 为每个背景像素记录有多少个不同对象的递减条纹覆盖了它：
   - 恰好被 1 个对象的条纹覆盖：绘为黄(4)。
   - 被 2 个及以上不同对象的条纹覆盖：绘为红(2)（碰撞边界）。
5. 递减条纹不覆盖已有的青(8)对象像素。
6. 未被任何条纹覆盖的背景像素保持黑(0)。

**关键洞察**：红(2)碰撞边界不是预设的——它是两组独立递减填充在空间中的重叠涌现。要预测碰撞边界，必须先分别计算每个对象的完整递减外扩范围（取决于各自的形状），再检测重叠区域。对象形状的差异导致四方外扩的不对称，使碰撞边界呈现非直观的曲折形态。

2. 擦除所有栗(9)标记像素的原始位置（改为橙(7)背景）。
3. 确定全局最近标记——到矩形最近边的曼哈顿距离最小的那个标记。
4. 全局最近标记沿其对齐方向（水平或垂直）移动，穿过矩形外侧边界进入矩形内部一格位置，绘为栗(9)。
5. 其余所有标记沿其对齐方向移动，停在矩形外侧紧邻的一格位置（即矩形边界外相邻一格），绘为栗(9)。
6. 检查每个标记的最终位置：若该标记所在行恰好等于触发条所在行减 1（即紧邻触发条正上方），则从该标记位置向左上和右上两个对角方向各发射一条栗(9)射线，射线逐格延伸直到离开网格边界。
7. 触发条灰(5)像素保持不变。射线绘制在橙(7)背景像素上，不覆盖已有的红(2)、灰(5)或其他栗(9)像素。

**关键洞察**：对角溅射不是所有标记的默认行为——只有滑动后恰好停在触发条正上方的标记才发射射线。标记的最终停止位置取决于它到矩形的距离和方向，而是否触发溅射取决于停止位置与触发条的空间关系。这构成了"滑动距离→停止位置→触发条件判断→溅射"的链式推理，其中任何一环的改变都影响最终输出。
