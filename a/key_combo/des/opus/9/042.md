## 新题 1：缺口框内计数决定填色与射线

**组合逻辑**：[计数/count](创新：计数结果不决定位移距离而决定填充颜色) + [洪泛填充/flood_fill](已有) + [射线延伸/ray_extend](已有) + [缺口定射线向/gap_determines_ray](已有)

**来源原语**：计数/count(8e301a54), 面积决定位移/area_determines_displacement(8e301a54)→创新为"数量决定颜色", 洪泛填充/flood_fill(292dd178), 射线延伸/ray_extend(292dd178), 缺口矩形框/one_gap_rect_frame(292dd178), 缺口定射线向/gap_determines_ray(292dd178)

**依赖链**：对每个缺口矩形框，先计数框内部非背景像素数量 → 计数结果通过映射表转换为特定填充颜色 → 该颜色洪泛填充框的整个内部 → 同时从缺口向外发射同色射线。射线颜色来自计数结果，射线方向来自缺口朝向，两条信息通道汇聚为最终输出，缺一不可。

根据每个缺口矩形框内部散布的非背景像素数量查表得到填充颜色，用该颜色充满框内部并沿缺口方向向外延伸同色射线。

**输入结构**：
- 黑(0)背景网格，约 18x18
- 3~4 个蓝(1)像素构成的矩形边框（每个约 5x5 到 7x7 不等），每个边框的边界上恰有一个非角位置的像素缺失（缺口）。边框为标准矩形轮廓（单像素宽度），缺口仅缺一个像素
- 各边框之间不重叠、不 4-连通相邻
- 每个边框内部（不含边框像素）散布 1~4 个前景像素，颜色为非黑(0)非蓝(1)的任意色（这些像素的颜色本身不编码规则，仅作为被计数的标记）；不同边框的内部像素数量互不相同
- 每个边框的缺口朝向（上/下/左/右）可以不同
- 生成约束：从任意边框缺口向外延伸的直线射线在到达网格边界之前不穿过另一个边框；各边框内部像素数量取值覆盖 {1,2,3} 或 {1,2,3,4}（保证映射表可从示例中归纳）

**规则**：
1. 对每个蓝(1)矩形边框，计数其内部区域（边框围成的矩形去掉边框像素本身）中所有非黑(0)像素的数量 N
2. 将 N 映射为填充颜色：N=1 → 红(2)，N=2 → 绿(3)，N=3 → 黄(4)，N=4 → 灰(5)
3. 用步骤 2 得到的颜色填充该边框的整个内部区域（覆盖原有的散布像素，全部变为该颜色）
4. 将缺口像素填回蓝(1)，使边框闭合
5. 从原缺口位置的外侧邻居开始，沿缺口朝外方向（远离边框中心）逐像素绘制射线，颜色与步骤 2 所得的填充颜色相同，直到到达网格边界为止（含边界像素）
6. 各边框独立处理，处理顺序不影响结果（生成约束保证射线不互相干涉）

**关键洞察**：计数在源题(8e301a54)中决定物体的位移距离，此处创新为决定填充颜色——N→颜色的映射表必须对比多个示例才能归纳；缺口方向控制射线的延伸朝向，这两条独立的信息通道（框内内容 → 颜色；框边界缺口 → 方向）汇聚于同一输出，删除任一逻辑则另一条无法独立求解。

## 新题 2：字形编码旋转角驱动模板补全

**组合逻辑**：[按形状映射颜色/shape_to_color_mapping](创新：形状不映射颜色而映射旋转角度) + [旋转/rotate](已有) + [补全/completion](已有) + [擦除/erase](已有)

**来源原语**：按形状映射颜色/shape_to_color_mapping(009d5c81)→创新为"按形状映射旋转", 标记字形/marker_glyph(009d5c81), 擦除/erase(009d5c81), 旋转/rotate(fc7cae8d), 补全/completion(57aa92db), 指示区域/indicator_region(57aa92db), 对齐匹配/alignment_match(57aa92db)

**依赖链**：识别每个部分副本旁的标记字形 → 解码字形形状为旋转角度 → 将完整模板以其指示色子区域为锚点旋转该角度 → 对齐旋转后模板与部分副本的指示像素 → 填补缺失像素 → 擦除标记字形。字形决定旋转角度，旋转角度决定模板朝向，朝向决定与指示像素的对齐方式，对齐方式决定补全内容——四环紧扣。

根据每个部分副本旁小型标记字形的形状确定旋转角度，将完整模板旋转后与部分副本的指示像素对齐，补全缺失的主体像素。

**输入结构**：
- 黑(0)背景网格，约 20x20
- 一个完整的多色模板对象（4-连通，约 8~12 像素），由两种颜色构成：主体色蓝(1)和指示色红(2)。指示色像素是模板的有机组成部分，形成一个 2~3 像素的连通子区域，位于模板的某个边缘或角落
- 2~3 个部分副本散布在网格其他位置，每个部分副本只保留红(2)指示色像素（与模板中指示色子区域形状相同但可能经过 90 度倍数的旋转），蓝(1)主体色像素完全缺失
- 每个部分副本旁（与部分副本的边界框 4-邻接但像素不重叠）有一个灰(5)像素组成的标记字形（恰好 2 个像素）。字形有三种可能形态：水平相邻两像素（横杠）、垂直相邻两像素（竖杠）、对角相邻两像素（斜杠）
- 各部分副本之间不重叠，各标记字形之间不重叠，部分副本与完整模板不重叠
- 生成约束：每个部分副本的红(2)像素确实是模板红(2)子区域经过某个 90 度整数倍旋转后的结果；旋转以指示色子区域的质心为中心；补全后的完整副本不会超出网格边界，也不与其他对象重叠

**规则**：
1. 识别完整模板：同时包含蓝(1)和红(2)像素的 4-连通对象
2. 识别各部分副本：仅包含红(2)像素的 4-连通区域（每个对应模板指示色子区域的某个旋转形态）
3. 识别每个部分副本的相邻灰(5)标记字形
4. 解码标记字形形状为旋转角度：横杠（水平两像素）→ 0 度（不旋转），竖杠（垂直两像素）→ 顺时针 90 度，斜杠（对角两像素）→ 180 度
5. 将完整模板以指示色子区域的质心为锚点，按解码的角度顺时针旋转
6. 将旋转后的模板平移，使其指示色子区域与该部分副本的红(2)像素完全重合
7. 在网格上绘制旋转后模板的蓝(1)主体像素（补全缺失部分），红(2)指示像素保留部分副本原有位置不变
8. 擦除所有灰(5)标记字形像素（替换为黑(0)）
9. 原始完整模板保留不动

**关键洞察**：标记字形在源题(009d5c81)中编码替换颜色，此处创新为编码几何变换（旋转角度）——求解者必须同时掌握字形形状→旋转角度的解码规则（需对比多个示例归纳）和旋转后对齐→补全的空间逻辑，二者通过指示色像素紧密耦合：字形决定旋转，旋转决定对齐，对齐决定补全内容。

## 新题 3：面积排序滑动与级联碰撞阻挡

**组合逻辑**：[计数/count](创新：面积不决定位移距离而决定处理优先级) + [滑动/slide](已有) + [碰撞阻挡/collision_blocking](已有) + [重涂色/recolor](创新：首个直接接触锚点的对象变色)

**来源原语**：面积决定位移/area_determines_displacement(8e301a54)→创新为"面积决定处理优先级", 计数/count(8e301a54), 滑动/slide(05f2a901), 碰撞阻挡/collision_blocking(05f2a901), 最短接触平移/minimal_contact_shift(05f2a901), 锚点方块/anchor_square(05f2a901), 重涂色/recolor(a85d4709)

**依赖链**：计算每个对象的像素面积 → 面积升序决定处理顺序 → 最小对象最先向锚点滑动并占据最近位置 → 后续对象依次滑动但被先到者阻挡 → 唯一直接 4-连通接触锚点的对象（必为面积最小者）被重涂为锚点色。每个对象的最终位置取决于所有比它小的对象的最终位置，形成级联空间依赖。

按面积从小到大依次将各彩色对象向固定锚点水平滑动至接触停止，先到者阻挡后到者，唯一直接贴住锚点的对象被重涂为锚点颜色。

**输入结构**：
- 黑(0)背景网格，约 15x15
- 一个固定的黄(4) 2x2 方块作为锚点，位于网格右半部分
- 4~5 个不同颜色的 4-连通单色对象（每个 2~6 像素不等，形状不规则，非矩形），全部位于锚点左侧，且每个对象至少有一行与锚点的某一行水平对齐（使得水平右滑可以达成 4-连通接触）
- 各对象之间不 4-连通相邻，面积互不相同
- 对象颜色从 {蓝(1), 红(2), 绿(3), 灰(5), 品红(6), 橙(7), 青(8)} 中选取，均不与锚点色黄(4)重复
- 生成约束：所有对象水平右滑到锚点一侧时，可以在 1~10 列范围内找到接触位置（不会全挤在一起或全够不到）；面积最小的对象离锚点不是最远的（确保面积排序和距离排序不一致，迫使求解者识别出是面积而非距离决定处理顺序）

**规则**：
1. 计算每个非锚点前景对象的像素面积
2. 按面积升序排列所有对象（面积最小的优先处理）；若面积相同（生成约束保证不会），则按对象边界框左上角的行优先列次优先排序
3. 依次处理每个对象：将该对象整体向右水平平移，直到其某个像素的右邻像素是锚点像素或已放置对象的像素（即达成 4-连通接触），然后固定在此位置
4. 全部处理完毕后，检查哪个对象直接与黄(4)锚点 4-连通相邻（不经由其他对象中转）——将该对象的所有像素重涂为黄(4)
5. 其余对象保持原色不变
6. 锚点保持原位不动

**关键洞察**：面积在源题(8e301a54)中决定位移距离，此处创新为决定处理优先级——面积最小的对象最先滑动并占据最靠近锚点的位置，阻挡后续更大的对象。最终被重涂的一定是面积最小的那个，但求解者必须推演完整的级联碰撞过程（依赖每一步的空间占据）才能确认所有对象的最终位置和颜色。需对比多个示例才能区分"面积决定优先级"和"距离决定优先级"。

## 新题 4：反对角线填充与缺口射线传播

**组合逻辑**：[填充/infill](已有) + [反对角线等值/anti_diagonal_equivalence](已有) + [射线延伸/ray_extend](已有) + [缺口定射线向/gap_determines_ray](已有)

**来源原语**：填充/infill(4aab4007), 反对角线等值/anti_diagonal_equivalence(4aab4007), 遮挡空洞/occlusion_hole(4aab4007), 射线延伸/ray_extend(292dd178), 缺口定射线向/gap_determines_ray(292dd178), 缺口矩形框/one_gap_rect_frame(292dd178)

**依赖链**：每个缺口矩形框内部已有的彩色像素位于同一条反对角线上 → 利用反对角线等值规律填补框内该反对角线上的黑色空洞 → 填充完成后确定该框的"代表色" → 从缺口向外发射该代表色的射线。填充逻辑确定颜色，缺口逻辑确定射线方向，二者分别来自不同参考题，通过"框内颜色"这一中间变量耦合。

用反对角线等值规律填补每个缺口矩形框内的黑色空洞，再从缺口向外延伸同色射线。

**输入结构**：
- 黑(0)背景网格，约 16x16
- 3 个蓝(1)像素构成的矩形边框（每个约 5x5 到 7x7），每个边框的边界上恰有一个非角位置的像素缺失（缺口）
- 每个边框内部（去掉边框像素后的区域）包含若干彩色像素和若干黑(0)空洞。同一边框内的所有彩色像素颜色相同（如红(2)、绿(3)、黄(4)——不同边框颜色不同），且这些彩色像素恰好位于网格全局坐标下同一条反对角线上（即所有彩色像素的 row+col 值相同）
- 该反对角线在框内部分可能还有一些黑(0)空洞像素（需要被填充）；不在该反对角线上的框内像素全部为黑(0)
- 每个边框内的反对角线上至少有 2 个已可见的彩色像素（确保颜色和反对角线位置均可推断）
- 生成约束：各边框不重叠不 4-连通相邻；从任意边框缺口延伸的射线在到达网格边界之前不穿过另一个边框的边界像素

**规则**：
1. 对每个蓝(1)缺口矩形框，找到其内部所有非黑(0)非蓝(1)像素，确认它们的颜色 C 和所在反对角线（所有这些像素的 row+col 值相同，记为 D）
2. 将该边框内部在反对角线 D 上的所有黑(0)像素填充为颜色 C（反对角线等值填充）
3. 该边框内部不在反对角线 D 上的黑(0)像素保持黑(0)不变
4. 将缺口像素填回蓝(1)，封闭边框
5. 从原缺口位置的外侧邻居开始，沿缺口朝外方向逐像素绘制射线，颜色为 C，直到到达网格边界为止（含边界像素）
6. 各边框独立处理，处理顺序不影响结果

**关键洞察**：反对角线等值规律（来自 4aab4007 的结构约束）决定框内"填什么颜色"和"填哪些位置"，而缺口方向（来自 292dd178 的空间关系）决定该颜色向外传播的路径——两条规律各自独立于源题，在此通过"框内代表色"耦合为一个不可分割的推理链。求解者必须同时识别反对角线模式和缺口方向规则才能完整求解。

## 新题 5：印章覆盖后标记导向的局部翻转

**组合逻辑**：[印章覆盖/stamp](已有) + [模板匹配/template_matching](创新：匹配时考虑旋转反射以确定对应关系) + [局部翻转/local_reverse](创新：从 1D 扩展到 2D，翻转轴由外部标记决定而非固有中心线) + [擦除/erase](已有)

**来源原语**：印章覆盖/stamp(321b1fc6), 源色覆盖占位副本/source_colors_onto_placeholders(321b1fc6), 掩码匹配/mask_matching(321b1fc6), 模板匹配/template_matching(50f325b5), 含旋转反射变换/includes_rotation_reflection(50f325b5), 局部翻转/local_reverse(833966f4), 各侧独立翻转/independent_side_reverse(833966f4), 擦除/erase(009d5c81)

**依赖链**：通过模板匹配（含旋转/反射）识别各占位对象与源精灵体的对应关系 → 按对应关系将源精灵体的颜色印章覆盖到每个占位对象上 → 读取每个占位对象旁标记像素的相对位置以确定翻转轴 → 对印章后的副本执行沿翻转轴的局部翻转 → 擦除标记像素。印章覆盖提供颜色内容，标记位置提供翻转指令，二者的效果在同一像素区域上叠加，缺一不可。

将源精灵体的颜色印章覆盖到每个灰色占位副本上（含旋转/反射匹配），然后根据旁边标记像素的方位对每个副本执行局部翻转。

**输入结构**：
- 黑(0)背景网格，约 16x16
- 一个多色源精灵体（4-连通，约 6~10 像素），由 2~3 种非黑非灰颜色构成（如蓝(1)和红(2)），位于网格某区域。精灵体形状不规则（非矩形、非对称），边界框约 3x3 到 4x4
- 2~3 个灰(5)占位对象散布在网格其他位置，每个占位对象的形状掩码与源精灵体相同（但可能经过 90 度整数倍旋转或水平/垂直反射）
- 每个占位对象旁（与占位对象的边界框 4-邻接但像素不重叠）有恰好一个橙(7)标记像素。标记像素位于占位对象边界框的上方、下方、左方或右方
- 各占位对象之间不重叠，各标记像素不与任何对象重叠
- 生成约束：每个占位对象经过印章和翻转后不超出网格边界，不与其他对象重叠；至少两个占位对象的标记位置不同（上下 vs 左右），以便从示例中区分翻转规则

**规则**：
1. 识别源精灵体（包含多种非黑非灰颜色的 4-连通对象）和各灰(5)占位对象
2. 对每个占位对象，在源精灵体的 8 种二面体变换（4 次旋转 x 2 次反射）中找到与该占位对象形状掩码一致的那个变换
3. 将源精灵体按该变换旋转/反射后，将其各像素颜色覆盖到占位对象的对应位置上（灰色被替换为源精灵体对应位置的颜色）
4. 对每个已印章的副本，读取其橙(7)标记像素相对于副本边界框中心的方位：
   - 标记在上方或下方 → 翻转轴为水平中线：将副本边界框内的像素关于水平中线上下翻转（第一行与最后一行交换，第二行与倒数第二行交换，依此类推）
   - 标记在左方或右方 → 翻转轴为垂直中线：将副本边界框内的像素关于垂直中线左右翻转（第一列与最后一列交换，依此类推）
5. 擦除所有橙(7)标记像素（替换为黑(0)）
6. 擦除原始源精灵体（所有像素替换为黑(0)）

**关键洞察**：印章覆盖（来自 321b1fc6）提供"填什么颜色"，但印章后的颜色排列立即被局部翻转（来自 833966f4，从 1D 扩展为 2D）打乱——翻转轴不是精灵体固有的对称线，而由外部标记像素的方位决定（创新点）。求解者必须先理解印章的旋转/反射匹配，再叠加理解标记导向的翻转，两层变换作用于同一区域，仅从单个示例无法分离两种效果。

## 新题 6：障碍物偏折螺旋与段着色

**组合逻辑**：[螺旋绘制/spiral_draw](创新：障碍物像边界一样触发转向，改变螺旋几何) + [重涂色/recolor](创新：障碍物颜色决定其终结的螺旋段颜色) + [洪泛填充/flood_fill](已有：封闭区域填灰)

**来源原语**：螺旋绘制/spiral_draw(28e73c20), 碰撞转向/turn_on_collision(28e73c20), 旋转方向/rotation_dir(28e73c20), 路径/path(28e73c20), 重涂色/recolor(a85d4709), 洪泛填充/flood_fill(292dd178)

**依赖链**：螺旋路径生长时遇到障碍物触发转向（障碍物改变螺旋几何）→ 每段螺旋（两次转向之间的直线段）的颜色由终结该段的转向原因决定：若因障碍物而转向则该段着色为障碍物的颜色，若因边界或自身轨迹而转向则保持绿(3) → 螺旋绘制完成后，被螺旋路径和障碍物共同围成的黑(0)封闭区域洪泛填充为灰(5)。障碍物既改变螺旋形状又决定段颜色，螺旋形状又决定封闭区域——三者不可分割。

在含有彩色障碍物的正方形网格上绘制顺时针螺旋，障碍物像边界一样触发转向并将自身颜色传递给被终结的螺旋段，最后将螺旋围成的封闭区域填灰。

**输入结构**：
- 黑(0)背景的正方形网格，约 12x12 到 15x15
- 网格上散布 2~4 个小型障碍物块，每个障碍物是单色的 1~2 像素（4-连通），颜色为非黑(0)非绿(3)的前景色（如红(2)、蓝(1)、黄(4)等），不同障碍物可同色也可异色
- 障碍物不位于网格的 (0,0) 位置（螺旋起点）
- 障碍物之间不 4-连通相邻
- 生成约束：障碍物的位置使得螺旋在生长过程中确实会遇到至少 2 个障碍物（即障碍物不全在螺旋无法到达的区域）；至少有一段螺旋是因边界而转向（保持绿色），至少有一段因障碍物而转向（着障碍物色）

**规则**：
1. 从网格左上角 (0,0) 开始，初始方向向右，开始逐像素绘制螺旋路径，默认颜色为绿(3)
2. 在每一步，检查当前方向的下一个像素：
   - 若下一个像素在网格外 → 顺时针转 90 度，不前进，继续检查新方向
   - 若下一个像素已是螺旋路径的一部分（非黑(0)且非障碍物原色） → 停止绘制（螺旋结束）
   - 若下一个像素是障碍物 → 顺时针转 90 度，不前进，不覆盖障碍物
   - 若下一个像素的前方第二个像素已是螺旋路径的一部分 → 顺时针转 90 度（前瞻规则，同 28e73c20）
   - 否则 → 前进一步，将该像素涂为当前段颜色
3. 段颜色规则：每当发生转向时，一个"段"结束。该段的着色取决于触发本次转向的原因：
   - 因碰到障碍物而转向 → 将该段（从上一个转向点到当前位置之间所有已绘制的像素）重涂为该障碍物的颜色
   - 因碰到网格边界或自身轨迹而转向 → 该段保持绿(3)不变
4. 螺旋绘制完毕后，找到所有被螺旋路径像素和障碍物像素共同围成的 4-连通黑(0)区域（该区域无法通过 4-连通黑色路径到达网格边界），将这些区域填充为灰(5)
5. 障碍物像素本身保持原色不变

**关键洞察**：在源题(28e73c20)中，螺旋仅因边界和自身轨迹转向；此处障碍物作为第三种碰撞源，同时改变螺旋几何形状和引入颜色信息——障碍物颜色"感染"它所终结的螺旋段，这是源题中不存在的信息流方向。螺旋最终形状决定哪些区域被封闭并填灰，而这个形状本身受障碍物位置控制。三层逻辑（碰撞偏折 → 段着色 → 封闭填充）环环相扣。

## 新题 7：转置后缺口朝向决定填充颜色

**组合逻辑**：[沿主对角线转置/diag_transpose](已有) + [洪泛填充/flood_fill](已有) + [缺口定射线向/gap_determines_ray](创新：缺口朝向不用于射线方向，而用于查表决定填充颜色)

**来源原语**：沿主对角线转置/diag_transpose(74dd1130), 镜像/mirror(74dd1130), 正方形画布/square_canvas(74dd1130), 洪泛填充/flood_fill(292dd178), 缺口矩形框/one_gap_rect_frame(292dd178), 缺口定射线向/gap_determines_ray(292dd178)→创新为"缺口朝向决定填充颜色", 内部区域/interior_region(292dd178)

**依赖链**：输入的正方形网格包含缺口矩形框 → 对整个网格执行主对角线转置 → 转置改变了每个缺口的朝向（原来朝上的变成朝左，原来朝右的变成朝下，等等）→ 转置后缺口的朝向查表得到填充颜色 → 用该颜色填充框内部。转置是理解最终输出的前置条件，缺口朝向在转置后才有意义，填充颜色由转置后朝向决定——三步形成不可跳跃的推理链。

将含有缺口矩形框的正方形网格沿主对角线转置，然后根据转置后每个缺口的朝向查表确定颜色，填充各框内部。

**输入结构**：
- 黑(0)背景的正方形网格，约 13x13 到 15x15
- 3~4 个青(8)像素构成的矩形边框（每个约 4x4 到 6x6），每个边框恰有一个非角位置的缺口（缺少一个像素）
- 边框内部全为黑(0)（转置前无填充内容）
- 各边框不重叠不相邻
- 不同边框的缺口朝向不同（至少覆盖 3 种朝向），且经过转置后的朝向分布至少覆盖 3 种（确保映射表可从示例归纳）
- 生成约束：网格为正方形（行数 = 列数），保证转置后尺寸不变；各边框在转置后仍为有效矩形且不重叠不超出边界

**规则**：
1. 将整个网格沿主对角线转置：将位置 (r,c) 的像素移到 (c,r)
2. 转置后，对每个青(8)矩形边框，确定其缺口像素的朝向（缺口位于框的上边、下边、左边还是右边）
3. 根据转置后的缺口朝向映射填充颜色：上 → 蓝(1)，右 → 红(2)，下 → 绿(3)，左 → 黄(4)
4. 用映射颜色洪泛填充该边框的内部区域（缺口像素本身不填充，保持黑(0)作为开口）
5. 边框的青(8)像素保持不变

**关键洞察**：在源题(74dd1130)中，转置是独立的最终操作；在源题(292dd178)中，缺口朝向决定射线方向。此处将两者耦合为一条推理链：转置改变了缺口的空间朝向（原朝上 → 转置后朝左，原朝右 → 转置后朝下，等等），而填充颜色由转置后的朝向决定。求解者必须先意识到发生了转置（对比输入输出的框形状变化），再推断转置后朝向到颜色的映射——两套规则缺一则输出不确定。

## 新题 8：字形解码偏移量的变步距拼接

**组合逻辑**：[按形状映射颜色/shape_to_color_mapping](创新：字形形状不映射颜色而映射垂直偏移量) + [拼接/stitch + 偏移放置/offset_placement](已有) + [擦除/erase](已有)

**来源原语**：按形状映射颜色/shape_to_color_mapping(009d5c81)→创新为"按形状映射偏移量", 标记字形/marker_glyph(009d5c81), 擦除/erase(009d5c81), 拼接/stitch(8618d23e), 偏移放置/offset_placement(8618d23e), 对角偏移/diagonal_offset(8618d23e), 分隔填充/separator_fill(8618d23e)

**依赖链**：识别各面板右上角的标记字形 → 解码字形形状为垂直偏移量 → 擦除所有字形 → 从左到右拼接面板，每个面板相对于前一个施加解码的垂直偏移 → 偏移产生的空白用栗(9)分隔色填充。字形决定偏移量，偏移量决定拼接几何，拼接后的空白需要特定填充——三者串联且不可跳步。

根据每个面板角落小型标记字形的形状确定垂直偏移量，将面板从左到右以变化的垂直步距拼接成一个整体。

**输入结构**：
- 黑(0)背景网格，约 20x8（宽大于高）
- 网格被 2~3 列栗(9)像素的垂直分隔线等宽切分为 3~4 个矩形面板（每个面板约 5x6 到 5x8，高度相同）
- 每个面板内包含非黑非栗非灰颜色的图案像素（如蓝(1)、红(2)、绿(3)等构成的小图形）
- 除第一个面板外，每个面板的右上角 2x2 区域内有一个灰(5)标记字形（恰好 2 个像素），字形有三种可能形态：
  - 水平相邻两像素（横杠）→ 偏移 0 行
  - 垂直相邻两像素（竖杠）→ 向下偏移 1 行
  - 对角相邻两像素（斜杠）→ 向上偏移 1 行
- 第一个面板无标记字形（它是拼接的起始基准）
- 生成约束：三种字形形态至少各出现一次（若面板数允许）；偏移累加后所有面板内容不超出合理输出高度（输出高度 = 原面板高度 + 偏移绝对值之和）

**规则**：
1. 识别栗(9)垂直分隔线，将网格切分为从左到右排列的面板序列 P1, P2, ..., Pk
2. 对 P2 到 Pk 中的每个面板，找到其右上角 2x2 区域内的灰(5)标记字形并解码：横杠 → 偏移 0，竖杠 → 偏移 +1（向下），斜杠 → 偏移 -1（向上）
3. 擦除所有灰(5)标记字形像素（替换为黑(0)）
4. 构建输出网格：
   - 输出宽度 = 所有面板宽度之和（不含分隔线）
   - 输出高度 = 面板高度 + 所有偏移绝对值之和的最大可能跨度（具体值：从 P1 的顶部到最低面板底部的距离）
   - 初始填充为栗(9)
5. 将 P1 放置在输出的顶部左端（起始行 = 0）
6. 对后续每个面板 Pi：其起始行 = P(i-1) 的起始行 + Pi 的解码偏移量；水平位置紧接上一个面板的右侧（无间隙）
7. 将各面板的内容（擦除字形后的像素）复制到输出的对应位置。面板中的黑(0)像素保持黑(0)，覆盖栗(9)背景

**关键洞察**：标记字形在源题(009d5c81)中编码替换颜色，此处创新为编码空间偏移量——字形形状决定面板间的垂直错位，这一信息在源题(8618d23e)中是由灰色接缝像素的位置隐式给出的固定偏移，此处变为由字形显式编码的可变偏移。求解者需同时解码字形含义（需多个示例对比）和理解累加偏移的拼接逻辑，两套规则共同决定每个面板在输出中的精确位置。
