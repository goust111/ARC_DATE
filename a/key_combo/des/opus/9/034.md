## 新题 1：射线长度决定排序的柱状条重分配

**组合逻辑**：[射线延伸](创新：射线长度作为排序键) + [排序] + [重分配] + [重涂色]（均为已有原语，创新在于"射线模拟产生隐式排序键"这一跨源题结构关系）

**来源原语**：射线延伸/行传播/碰撞产生侧翼(79fb03f4)，排序/重分配/高度排序/槽位保持颜色(31f7f899)，障碍像素(79fb03f4)，种子像素(79fb03f4)，柱状条/基线(31f7f899)

**依赖链**：种子发射射线 → 障碍截断射线 → 截断长度成为排序键 → 排序决定柱状条的高度重分配。障碍的空间位置间接编码了排序顺序，删除射线模拟则无法获得排序键，删除排序则射线结果无法驱动重分配。

将左侧种子像素发出的水平射线被障碍截断后的自由长度作为隐式排序键，重新排列底部柱状条的高度。

**输入结构**：约 15x15 的网格，背景为黑(0)。最左列（第 0 列）有 4 个不同颜色的种子像素（如蓝(1)、红(2)、绿(3)、黄(4)），分布在不同行上，彼此不相邻。每个种子所在行恰好有一个灰(5) 障碍像素，位于该行的某一列（列号各不相同，范围在 3~12 之间）。最底行为一条橙(7) 水平基线，横跨网格全宽。基线上方紧贴 4 根单列宽的柱状条，分别位于固定的 4 个列位置（如第 2、5、8、11 列），颜色各不相同（品红(6)、青(8)、栗(9)、灰(5)），高度各不相同（2~6 像素之间）。生成约束：每个种子行与每根柱状条的列不重合；4 个障碍的列互不相同；4 根柱状条高度互不相同。

**规则**：
1. 每个种子像素沿其所在行向右发射一条水平射线，射线颜色为种子颜色。射线逐格向右绘制，遇到灰(5) 障碍像素时停止（不绘制障碍所在格），到达网格右边界时也停止。
2. 记录每条射线的自由长度 L（射线实际绘制的像素数，不含种子本身也不含障碍）。
3. 将 4 条射线按自由长度从小到大排列，获得排序序列。
4. 将 4 根柱状条的高度值（像素数）也从小到大排列。
5. 将排序后第 i 短射线对应的高度值赋给从左到右第 i 个柱状条槽位。即：射线最短的种子对应的高度放入最左柱状条槽位，射线最长的种子对应的高度放入最右柱状条槽位。
6. 每个槽位保留其原始列位置和原始颜色，仅更新高度（柱状条从基线向上延伸新高度个像素，填充该槽位的原始颜色）。
7. 射线、种子和障碍在输出中被擦除（恢复为背景）；基线保持不变。

**关键洞察**：障碍像素的列位置是隐式排序指令——距种子越近，射线越短，对应的高度排名越低。排序键不是任何可见属性的直接读取，而是通过射线模拟"计算"出来的。

## 新题 2：矩形边框编码周期掩码控制泛洪填充形态

**组合逻辑**：[泛洪填充] + [周期掩码](创新：掩码由空间分离的边框内条纹编码) + [擦除]（泛洪填充为已有原语，创新在于"空间分离的编码器控制填充输出"这一结构关系）

**来源原语**：泛洪填充/半封闭墙/填充种子/开口方向/障碍投射阴影(b9e38dc0)，矩形边框/周期条纹/周期掩码/条纹延伸全行列(6a980be1)，擦除(f45f5ca7)

**依赖链**：边框内部的条纹间距定义周期掩码 → 泛洪填充产生连续填充区域 → 周期掩码裁剪填充区域为条纹形态 → 边框被擦除。边框是"控制结构"而非输出元素；填充区域的最终形态同时取决于墙体几何和边框条纹，二者缺一不可。

用一个空间上远离的矩形边框内部的条纹图案，作为泛洪填充结果的行掩码，使填充区域呈现周期性条纹而非实心块。

**输入结构**：约 18x18 的网格，背景为黑(0)。网格右上区域有一个蓝(1) 单像素宽矩形边框（约 6x6），边框内部在每隔 2 行（即第 1、4、7... 行，以边框内部顶行为第 0 行计）绘有红(2) 水平条纹，每条条纹横跨边框内部全宽。网格左下区域有一个绿(3) U 形墙体（3 面封闭，1 面开口朝右），墙体围成的内部区域约 4x4，内部有一个黄(4) 填充种子像素。开口方向的外侧可能有 1~2 个灰(5) 障碍像素。生成约束：边框和墙体在空间上不重叠且不相邻；墙体开口方向的外部空间足够容纳射出的填充区域；障碍像素仅出现在开口方向的射出路径上。

**规则**：
1. 从矩形边框内部提取周期行掩码：记录边框内部哪些行有红(2) 条纹。将该行间距模式推广到整个网格坐标系——以边框内部第一条条纹的全局行号为锚点，每隔相同间距的全局行标记为"活跃行"。
2. 从黄(4) 种子像素开始泛洪填充：用黄(4) 填充种子所在的封闭区域全部黑(0) 格；填充穿过墙体开口向外辐射，沿开口方向扩展到网格边界或遇到非背景像素停止。灰(5) 障碍像素沿开口方向投射阴影——障碍像素保持不变，障碍正后方（沿开口方向）的所有格不被填充。
3. 对泛洪填充结果施加周期行掩码：仅保留"活跃行"上的黄(4) 填充像素；非活跃行上的黄(4) 像素恢复为黑(0)。
4. 擦除矩形边框及其内部所有内容（蓝(1) 框线和红(2) 条纹全部恢复为黑(0)）。
5. 绿(3) 墙体和灰(5) 障碍保持不变。

**关键洞察**：矩形边框不出现在输出中——它是一个纯粹的"规则编码器"，其内部条纹的行间距决定了泛洪填充的最终形态。两个空间上完全分离的结构（边框和墙体）通过抽象的周期规则产生耦合。

## 新题 3：逐区域计数决定各自放大倍率的提取堆叠

**组合逻辑**：[裁剪] + [计数](创新：每个提取区域独立计数作为各自放大系数) + [像素放大] + [堆叠]（均为已有原语，创新在于"区域内计数 → 区域级放大"的逐实例参数化）

**来源原语**：裁剪/堆叠/标记块/行对齐配对/按顺序堆叠/忽略干扰项(aab50785)，计数/像素放大/前景数为放大系数/数量决定倍率(ac0a08a4)

**依赖链**：标记块定界提取 → 区域内计数 → 计数值成为该区域的放大系数 → 放大后的区域堆叠。每个区域的放大系数不同，导致堆叠输出中各层尺寸不一。删除提取则无区域可数；删除计数则无法确定放大倍率；删除放大则堆叠尺寸无法统一到正确值。

提取标记块之间的图案，每个图案的前景像素数决定自身的放大倍率，放大后垂直堆叠。

**输入结构**：约 20x12 的网格，背景为黑(0)，散布少量灰(5) 噪声像素（干扰项）。红(2) 像素组成若干 2x2 方块，这些方块按行对齐配对（同一两行跨度内恰好有左右两个红方块），共 3 对。每对红方块之间有一个小图案（由蓝(1)、绿(3)、黄(4) 等颜色的 4-连通非背景像素组成，像素数范围 2~4，形状各不相同）。3 对标记块从上到下排列，相邻对之间至少隔 2 行。生成约束：每个提取区域的非背景像素数互不相同（如分别为 2、3、4）；提取区域的宽度相同（等于两个红方块内侧之间的距离）；高度均为 2（与红方块的行跨度相同）。

**规则**：
1. 识别所有红(2) 2x2 方块，按行对齐配对（共享相同两行跨度的左右两个方块为一对）。
2. 对每一对标记块，裁剪出两个方块内侧边之间的矩形区域（不含标记块本身），忽略区域外的灰(5) 噪声像素。
3. 对每个裁剪出的区域，计数其中非黑(0) 像素的数量 K。
4. 将该区域进行 K 倍像素放大：区域中每个像素替换为 KxK 的同色方块。
5. 按源位置从上到下的顺序，将所有放大后的区域垂直堆叠（第一对的放大区域在最上方，紧接第二对，依此类推，中间无间隔）。
6. 输出网格的宽度等于最大放大区域的宽度（较窄的放大区域左对齐，右侧补黑(0)）；高度等于所有放大区域高度之和。

**关键洞察**：同一组前景像素同时决定了"放大什么"和"放大多少"——像素越多的区域反而被放大得更多，形成自参照式的尺寸膨胀。不同示例中前景像素数不同，导致放大倍率不同，仅凭单个示例无法确认"计数 = 放大倍率"这一规则。

## 新题 4：缺失区域补全后按指示像素方向镜像并重涂色

**组合逻辑**：[补全](创新：补全的形状影响镜像结果) + [镜像] + [重涂色]（均为已有原语，创新在于"补全恢复的几何体成为镜像的正确输入"这一依赖关系）

**来源原语**：补全/不完整矩形/边界框推断/缺失像素补新色(6d75e8bb)，镜像/指示像素/邻接/指示定镜像与色(b775ac94)，重涂色(31f7f899)

**依赖链**：边界框推断 → 缺失像素补全 → 补全后的完整形状作为镜像输入 → 指示像素决定镜像轴和重涂色 → 镜像副本放置在指示像素侧。不补全就镜像会得到错误形状；没有指示像素就无法确定镜像方向和颜色。

先用新颜色补全不完整精灵的边界框内缺失像素，再按邻接指示像素的位置方向镜像整个补全结果，并将镜像副本重涂为指示像素的颜色。

**输入结构**：约 14x14 的网格，背景为黑(0)。网格中有 2~3 个不完整的单色精灵（每个精灵是一组 4-连通的同色像素，颜色各不相同，如蓝(1)、绿(3)、黄(4)；每个精灵有 4~8 个像素）。每个精灵的边界框内存在 1~3 个黑(0) 空洞（缺失像素）。每个精灵恰好有一个指示像素（颜色不同于精灵颜色且不同于其他指示像素，如红(2)、品红(6)、橙(7)）通过 4-邻接（上下左右）恰好接触精灵的边界框外侧的一条边（上边、下边、左边或右边的某个位置）。生成约束：不同精灵及其指示像素在空间上互不重叠；每个精灵的边界框加上其镜像副本的空间不超出网格边界且不与其他精灵冲突；每个精灵至少有一个缺失像素使得补全前后形状不同。

**规则**：
1. 对每个精灵，计算其所有像素的边界框（最小包围矩形）。
2. 将边界框内的黑(0) 空洞像素填充为红(2)，完成矩形补全。原精灵颜色像素保持不变。
3. 确定每个精灵的指示像素位置：指示像素在边界框的哪一侧（上→水平轴镜像放在上方；下→水平轴镜像放在下方；左→垂直轴镜像放在左方；右→垂直轴镜像放在右方）。
4. 以边界框的对应边为镜像轴，将补全后的整个边界框区域（含原始颜色和红(2) 补全像素）做镜像翻转。
5. 将镜像副本中所有非黑像素重涂为指示像素的颜色（不区分原始像素和补全像素，统一涂为指示色）。
6. 将镜像副本放置在原始精灵的指示像素侧，紧贴边界框外边（镜像副本的近边与原始边界框的对应边相邻，中间无间隔）。指示像素被镜像副本覆盖。
7. 处理顺序：按精灵边界框左上角的行列坐标排序（行优先，行相同则列小的优先），依次处理。若镜像副本与已放置的其他元素重叠，后放置的覆盖先放置的。

**关键洞察**：补全步骤看似简单的"填洞"，但它决定了镜像结果的形状——精灵缺失的像素在镜像副本中变为可见的指示色块，使得补全和镜像产生紧密的几何依赖。指示像素同时编码镜像轴方向和输出颜色，单个示例无法确定这一双重编码规则。

## 新题 5：前景计数决定颜色反转图案的平铺重复次数

**组合逻辑**：[颜色反转] + [平铺] + [计数](创新：计数值决定平铺重复次数而非像素放大倍率)（颜色反转和平铺为已有组合(48131b3c)，但原题固定 2x2 平铺；计数(ac0a08a4) 原用于像素放大；创新在于计数→平铺次数这一新映射关系）

**来源原语**：颜色反转/平铺/二值图案/阵列排布/反转后再平铺(48131b3c)，计数/前景像素/数量决定倍率/前景数为放大系数(ac0a08a4)

**依赖链**：计数前景像素 → 得到 N → 颜色反转 → 将反转后的图案 NxN 平铺。同一组前景像素既是被反转的对象又是决定平铺次数的编码源，形成自参照闭环。

统计前景像素数 N，交换前景色与背景色，然后将反转后的图案在水平和垂直方向各重复 N 次。

**输入结构**：一个小型网格（3x3 至 5x5），恰好包含两种颜色：黑(0) 作为背景和一种前景色（如蓝(1)）。前景像素形成一个连通或非连通的图案，像素数 N 在 2~4 之间。不同示例中网格尺寸可相同但前景像素数 N 不同。生成约束：N >= 2 且 N <= 4，以保证输出网格尺寸合理。

**规则**：
1. 计数网格中所有非黑(0) 前景像素的数量，记为 N。
2. 颜色反转：将所有黑(0) 像素替换为前景色，将所有前景色像素替换为黑(0)。
3. 将反转后的网格作为瓦片，在水平方向重复 N 次、垂直方向重复 N 次，拼成 NxN 瓦片阵列。
4. 输出网格尺寸为 (N * 输入高度) x (N * 输入宽度)。

**关键洞察**：前景像素数同时控制了"瓦片内容"（反转后前景变少、背景变多）和"瓦片数量"（N 越大重复越多）。改变一个前景像素会同时改变瓦片形态和阵列大小，产生非线性的输出变化。仅凭单个示例无法区分"固定 NxN 平铺"和"计数决定平铺次数"。

## 新题 6：散布对象计数重写柱状条高度并按新高度重分配

**组合逻辑**：[计数] + [填充图例] + [排序] + [重分配]（均为已有原语，创新在于"计数结果同时更新图例和驱动柱状条高度重写"这一多目标耦合）

**来源原语**：计数/填充图例/图例框/前景对象/颜色索引行/计数映射点序列(58490d8a)，排序/重分配/柱状条/基线/高度排序/槽位保持颜色(31f7f899)

**依赖链**：散布对象计数 → 计数值填入图例 → 同一计数值覆写对应颜色柱状条的高度 → 新高度排序后重分配柱状条到槽位。图例既是计数的输出可视化也是高度重写的"转发器"——删除计数则无高度值，删除排序则柱状条不重排，删除图例则丢失颜色到计数的映射。

统计网格中各颜色散布对象的数量，将计数值填入图例框，并用这些计数值替换底部柱状条的高度，最后按新高度从矮到高重新排列柱状条。

**输入结构**：约 20x20 的网格，背景为黑(0)。底部有一条灰(5) 水平基线横跨全宽。基线上方紧贴 4 根单列宽柱状条，分布在第 3、7、11、15 列，颜色分别为红(2)、蓝(1)、绿(3)、黄(4)，初始高度各不相同（3~7 像素之间）。右上角有一个灰(5) 边框的图例框（约 5x9），内部背景为黑(0)，左列第 2 行起依次有红(2)、蓝(1)、绿(3)、黄(4) 键色像素，每个键色占一行，行间隔 1 行。网格左上区域散布若干独立的同色小对象（每个对象为 3~6 个 4-连通像素的不规则形状），颜色仅限红(2)、蓝(1)、绿(3)、黄(4)，每种颜色的对象数量在 1~6 之间且互不相同。生成约束：散布对象之间互不接触且不与图例框、柱状条重叠；每种颜色的对象数量互不相同。

**规则**：
1. 对每种键色（红、蓝、绿、黄），在图例框和柱状条之外的区域计数该颜色的独立 4-连通对象数量，记为 C。
2. 在图例框中，从每个键色像素向右每隔一格（跳一格画一格）绘制 C 个该键色的点，不超出图例框右边界。
3. 用计数值 C 作为该键色对应柱状条的新高度（柱状条从基线向上延伸 C 个像素）。
4. 将 4 根柱状条按新高度从小到大排序。
5. 将排序后的柱状条轮廓（高度）重新分配到从左到右的 4 个槽位：最矮的柱状条轮廓放入最左槽位（第 3 列），最高的放入最右槽位（第 15 列）。
6. 每个槽位保留其原始列位置和原始颜色——仅改变高度。即第 3 列槽位仍为红(2) 色，但其高度可能变为原先属于其他颜色的计数值。
7. 擦除所有散布对象（恢复为黑(0)）。图例框保留（含新填入的点序列）。基线保留。

**关键洞察**：散布对象不与柱状条直接交互——它们通过"计数"这一抽象中介改变了柱状条的高度。输入中柱状条的原始高度是干扰项，最终高度完全由远处散布对象的数量决定。需要多个示例才能确认"计数值 = 新高度"而非"计数值 = 高度增量"或其他映射。

## 新题 7：十字形滑动旋转后按落点位置做选择性臂投射

**组合逻辑**：[滑动] + [旋转](创新：旋转改变臂朝向从而影响后续投射方向) + [射线延伸](创新：仅从朝向最近边界的臂发射)（三个操作两两之间存在依赖：滑动→位置→最近边界判断；旋转→臂朝向→投射方向选择）

**来源原语**：滑动/旋转/十字形/标记精灵/标记指示方向/抵达边界(99caaf76)，射线延伸/网格边缘/投射到最近边界/最近边界方向(705a3229)

**依赖链**：标记精灵确定滑动方向 → 滑动到边界 → 十字体旋转 180 度（臂颜色互换方位） → 落点位置决定最近的水平和垂直边界 → 仅旋转后朝向这两个最近边界的臂发射射线。旋转改变了哪条臂朝向哪个边界，因此改变了射线颜色和方向组合。

将带标记精灵的十字形对象滑动到边界并旋转，然后从旋转后朝向最近水平和垂直边界的两条臂各发射一条射线。

**输入结构**：约 15x15 的网格，背景为黑(0)。网格中有 2~3 个十字形对象，每个由一个 5 像素的加号（中心 + 上下左右各一个像素）构成，中心为一种颜色（如灰(5)），四条臂各有自己的颜色（从蓝(1)、红(2)、绿(3)、黄(4) 中选取，四条臂颜色可相同或不同，但同一十字体内至少有两种不同臂色）。每个十字体的一侧（上、下、左或右）紧贴一个 2x2 的品红(6) 标记精灵（标记精灵的位置指示滑动方向的反方向，即十字体将向远离标记精灵的方向滑动）。生成约束：十字体初始位置距网格边缘至少 3 格；不同十字体的滑动方向不同或滑动后不重叠；十字体四臂颜色排列使得旋转前后至少有一条臂的最近边界投射颜色发生改变。

**规则**：
1. 对每个十字体，确定其标记精灵在哪一侧。十字体将向标记精灵的对侧滑动（标记在左→向右滑，标记在上→向下滑，依此类推），直到十字体的边界框触及网格对应边缘。标记精灵随十字体一同移动，保持相对位置不变。
2. 滑动过程中，将十字体的 3x3 加号区域（不含标记精灵）旋转 180 度：中心不变，上臂与下臂互换，左臂与右臂互换。标记精灵不旋转。
3. 滑动结束后，确定十字体中心像素到网格四条边界的距离。找出距中心最近的水平边界（上或下）和最近的垂直边界（左或右）。
4. 从旋转后十字体的朝向最近水平边界的臂（如最近水平边界是上边界，则取上臂）的末端像素开始，沿该方向延伸射线至网格边界，射线颜色为该臂颜色。
5. 从旋转后十字体的朝向最近垂直边界的臂的末端像素开始，沿该方向延伸射线至网格边界，射线颜色为该臂颜色。
6. 每个十字体只发射两条射线（一条水平方向，一条垂直方向）。
7. 处理顺序：按十字体中心滑动后的行列坐标排序（行优先），依次处理。射线遇到已绘制的非背景像素时停止（不覆盖）。

**关键洞察**：180 度旋转使臂颜色互换了方位，而滑动到边缘使十字体的"最近边界"变为触及的那条边。因此射线的颜色取决于旋转后的臂排列，射线的方向取决于滑动后的位置——两者共同决定输出。若不旋转，射线颜色会不同；若不滑动，最近边界判断会不同。

## 新题 8：面板序列中的镜像-平移交替外推

**组合逻辑**：[序列外推](创新：序列中交替出现平移和镜像两种变换) + [镜像] + [重涂色]（序列外推为已有原语，创新在于"需要同时推断两个独立周期模式（空间变换 + 颜色循环）并在下一帧叠加"这一复合外推结构）

**来源原语**：序列外推/面板帧/分隔行/前景精灵/等距堆叠/恒定偏移平移(351d6448)，镜像/邻接/指示定镜像与色(b775ac94)，重涂色(31f7f899)

**依赖链**：面板分割 → 逐帧分析精灵变化 → 同时推断平移偏移序列和镜像交替模式 → 识别指示像素颜色循环 → 叠加三种模式外推第 5 帧。仅分析平移无法解释偶数帧的左右翻转；仅分析镜像无法解释逐帧位移；不追踪颜色循环则指示像素颜色出错。

解析四帧面板动画中精灵的恒定平移和交替水平镜像，同时追踪指示像素的颜色循环，外推输出第五帧。

**输入结构**：约 30x8 的网格。4 个相同尺寸的面板（每个约 6x8）垂直堆叠，相邻面板之间由一行灰(5) 分隔行隔开。每个面板背景为黑(0)，包含一个不对称的小精灵（3~5 像素的 4-连通图形，颜色为蓝(1)），精灵在每帧之间做恒定偏移平移（如每帧向右移 1 列、向下移 1 行）。同时，精灵在奇数帧（第 1、3 帧）保持原始朝向，在偶数帧（第 2、4 帧）做水平镜像翻转。每个面板中，精灵的某一侧（左或右，与镜像状态对应）紧贴一个单像素的指示像素，颜色按固定循环排列（如第 1 帧红(2)、第 2 帧绿(3)、第 3 帧黄(4)、第 4 帧品红(6)）。生成约束：精灵不对称（使镜像翻转可辨识）；平移偏移量保证第 5 帧精灵仍在面板范围内；指示像素在精灵未翻转时出现在左侧，翻转时出现在右侧（或反之，但规则在所有示例中一致）。

**规则**：
1. 将输入按灰(5) 分隔行切分为 4 个面板。
2. 在每个面板中定位精灵（蓝(1) 连通区域）和指示像素（非蓝(1)、非黑(0)、非灰(5) 的单像素）。
3. 推断恒定平移偏移：比较相邻帧中精灵边界框左上角的坐标差（相对于面板内坐标），每步偏移应相同，记为 (dr, dc)。
4. 推断镜像交替模式：比较第 1 帧和第 2 帧的精灵形状——如果第 2 帧是第 1 帧的水平镜像，则确认"奇数帧原始，偶数帧水平镜像"模式（或反之）。验证第 3、4 帧符合该模式。
5. 推断指示像素颜色循环：记录 4 帧中指示像素的颜色序列，确认其为某种循环（如固定序列的第 5 项，或模 4 循环的下一项）。
6. 生成第 5 帧：
   - 面板尺寸与前 4 帧相同，背景为黑(0)。
   - 精灵位置 = 第 4 帧位置 + (dr, dc)。
   - 精灵朝向：第 5 帧为奇数帧，采用与第 1、3 帧相同的朝向（原始或镜像）。
   - 指示像素颜色为循环中的第 5 个值；位置在精灵对应侧（与朝向匹配）。
7. 输出仅为第 5 帧（一个面板大小的网格），不含分隔行。

**关键洞察**：这不是简单的平移动画——精灵在偶数帧翻转，在奇数帧还原。解题者需同时推断三个独立模式（平移偏移、镜像交替、颜色循环），仅观察两帧不足以区分"平移 + 交替镜像"与"平移 + 使用两种不同精灵"。需要至少 3 帧建立镜像的周期性。

## 新题 9：同色四角矩形连线后用远处模板条纹填充内部

**组合逻辑**：[连线] + [平铺](创新：平铺图案从空间分离的模板区域提取) + [填充] + [擦除]（连线和平铺为已有原语，创新在于"边界由连线确定、填充内容由模板编码"的分离式控制）

**来源原语**：连线/同色四角矩形/背景通道/沿通道绘制矩形边(b7f8a4d8)，平铺/周期条纹/周期掩码/条纹延伸全行列(6a980be1)，填充(72a961c9)，擦除(f45f5ca7)

**依赖链**：四角标记像素确定矩形范围 → 连线绘制矩形边 → 远处模板区域提供填充瓦片 → 瓦片平铺填充矩形内部 → 模板区域擦除。矩形几何由标记像素决定，填充纹理由模板决定，二者独立编码、联合决定输出。

将四个同色标记像素连成矩形边框，提取远处模板区域的条纹图案作为瓦片平铺填充矩形内部，最后擦除模板。

**输入结构**：约 16x16 的网格，背景为黑(0)。网格中有 4 个红(2) 标记像素，分布在不同行列，恰好构成一个轴对齐矩形的四个角（行列坐标分别为 (r1,c1), (r1,c2), (r2,c1), (r2,c2)，其中 r1<r2, c1<c2）。网格角落（不与矩形范围重叠的区域）有一个小的模板区域：一个青(8) 单像素宽边框围成的约 3x3 或 4x4 矩形，内部含有绿(3) 和黄(4) 交替排列的条纹图案（如棋盘格或水平条纹）。四个红标记像素之间的路径上可能有灰(5) 障碍像素（位于矩形边上的某些位置）。生成约束：四个红标记像素构成的矩形内部面积至少为模板内部面积的 2 倍；模板区域与矩形范围不重叠；灰障碍仅出现在矩形边路径上（不在内部）。

**规则**：
1. 识别 4 个红(2) 标记像素，确定它们构成的矩形的四角坐标。
2. 沿矩形四条边绘制红(2) 连线：从一个角到相邻角，逐像素绘制。若路径上有灰(5) 障碍像素，保留障碍不覆盖，连线跳过障碍继续。
3. 识别青(8) 边框的模板区域，提取边框内部的条纹图案（不含青(8) 边框本身）作为瓦片。
4. 将提取的瓦片在矩形内部（四条边以内的区域）进行平铺：从矩形内部左上角开始，将瓦片反复水平和垂直排列直到覆盖全部内部区域。超出内部边界的瓦片部分裁剪丢弃。
5. 平铺时仅覆盖黑(0) 背景像素；矩形边上的红(2) 连线和灰(5) 障碍保持不变。
6. 擦除模板区域（青(8) 边框和内部条纹全部恢复为黑(0)）。
7. 红(2) 标记像素保留（它们已成为矩形边的一部分）。

**关键洞察**：矩形的几何形状和填充纹理由两个空间上完全分离的结构独立编码——标记像素给出"在哪里画"和"画多大"，模板区域给出"用什么填充"。模板在输出中被擦除，说明它是纯粹的编码器。改变模板条纹图案会改变矩形内部的纹理，但不改变矩形大小；反之亦然。
