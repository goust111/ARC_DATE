## 新题 1：封闭区域门控的碎片补全

**组合逻辑**：[洪泛填充/flood_fill] + [补全/completion]（创新：flood_fill 的内外分区结果作为补全操作的条件门控） + [内外分区/in_out_partition] + [碎片锚定放置位/fragment_anchor_place]

**来源原语**：洪泛填充、内外分区、封闭区域、线条对象（P19 7b6016b9）；补全、模板精灵体、碎片、碎片锚定放置位（P2 fd096ab6）

**依赖链**：线条对象将网格分为内部封闭区域与外部区域 → 只有位于封闭区域内的碎片才被补全为完整模板副本，外部区域的碎片被擦除为背景。flood_fill 决定哪些碎片"有效"，completion 决定有效碎片如何扩展。两步缺一不可：没有 flood_fill 则无法判断哪些碎片应补全；没有 completion 规则则无法生成输出图案。

从线条对象的内外分区中筛选有效碎片，仅对封闭区域内的碎片执行模板补全，外部碎片擦除。

**输入结构**：约 18x18 的网格，背景为黑(0)。一个由绿(3)像素组成的 4-连通正交线条对象横贯网格，将背景分割成若干区域——部分区域与网格边界 4-连通（外部），部分被线条完全包围（内部封闭区域，通常 1~3 个）。网格中还有一个由蓝(1)像素组成的完整单色模板掩码（约 3x3~4x4 的连通图形，如不规则的 4-连通块），以及若干由其他颜色（红(2)、黄(4)、品红(6)等）组成的碎片。每个碎片至少 2 像素，每种碎片颜色的像素是模板掩码的某个平移副本的子集。碎片散布在内部和外部区域中。所有补全后的模板副本不超出网格边界且不与绿(3)线条或蓝(1)模板重叠。生成约束：每个碎片颜色的像素唯一确定一个平移位置。

**规则**：
1. 以绿(3)线条对象为墙壁，从网格四条边界出发执行 4-连通洪泛填充，标记所有与边界连通的背景像素为"外部"。
2. 未被标记的背景像素属于"内部封闭区域"。
3. 对每种非背景、非绿(3)、非蓝(1)的碎片颜色，检查该颜色的所有像素是否全部位于内部封闭区域：
   - 若全部在内部：找到模板掩码的唯一平移位置使得该颜色的现有像素是平移后模板的子集，将平移后模板的所有像素位置涂上该碎片颜色。
   - 若任一像素在外部：将该颜色的所有像素擦除为背景黑(0)。
4. 绿(3)线条对象和蓝(1)模板保持不变。

**关键洞察**：线条对象同时扮演两个角色——flood_fill 的"墙壁"和补全操作的"有效性边界"。求解者必须先完成空间分区，才能决定对哪些碎片执行补全，二者在同一空间结构上紧密耦合。

## 新题 2：计数驱动的非对称生长

**组合逻辑**：[计数/counting]（创新：计数结果不决定条长而决定生长量） + [生长/grow] + [收缩/shrink] + [两侧计数决定长度/side_counts_length → 创新为"计数决定生长方向与幅度"]

**来源原语**：生长、收缩、中心间隙、前景对象、面积最大者、最大外扩余内缩（P1 df978a02）；计数、控制像素、计数像素、同行对齐、两侧计数决定长度（P18 2a28add5）

**依赖链**：每个前景对象所在行的计数像素数量 → 编码该对象的生长幅度 → 计数最多者向外生长该数量的像素层，其余对象收缩同等层数。计数和生长/收缩之间形成量化耦合：计数不仅决定"谁生长"，还决定"生长多少"，而收缩幅度也由最大计数值联动确定。

通过每个方向的计数像素数量决定对应前景对象的生长或收缩幅度。

**输入结构**：约 15x15 的网格，背景为黑(0)。四个不同颜色的 4-连通单色前景对象（蓝(1)、红(2)、绿(3)、黄(4)）分布在网格四个象限，各自面朝中心区域的一个公共背景间隙。每个对象呈尖端指向中心的楔形或箭头状（3~8 像素的不规则连通块）。在每个对象的尖端所在行（或列，取决于对象朝向中心的方向——水平朝中心则取行，垂直朝中心则取列），散布着灰(5)计数像素，每个灰(5)像素与该行/列上的前景对象不相邻且不重叠。各对象对应行/列上的灰(5)像素数量互不相同，范围 1~4。生成约束：生长后的对象不超出网格边界，不与其他对象重叠。

**规则**：
1. 识别四个前景对象及其朝向中心间隙的方向（上方对象朝下、下方对象朝上、左方对象朝右、右方对象朝左）。
2. 对每个对象，找到其尖端像素（距中心间隙最近的像素）所在的行（若水平朝向）或列（若垂直朝向），统计该行/列上灰(5)像素的数量，记为 k。
3. 拥有最大 k 值的对象执行向外生长（远离中心方向）：在该对象远离中心一侧，沿该对象的宽度方向，添加 k 层该对象颜色的像素（每层宽度等于对象在生长方向垂直截面的宽度）。
4. 其余三个对象各收缩 1 层：擦除每个对象中距中心最近的 1 个像素（该像素变为背景色）。
5. 灰(5)计数像素在输出中全部擦除为背景。

**关键洞察**：源题 P1 中"谁生长"由面积最大决定，此题中改由散布的计数像素决定——计数像素既编码了"谁是赢家"（最多者），又量化了"赢多少"（生长层数），将两种本不相关的机制融合成单一决策通道。

## 新题 3：局部裁切开墙后的迷宫寻路

**组合逻辑**：[擦除/erase + 按对象局部裁切/local_bbox_crop]（创新：裁切不用于简化对象而用于打通墙壁） + [寻路/pathfinding] + [填充/fill] + [最短路径/shortest_path]

**来源原语**：擦除、连通分量、局部边界列、相对自身定位、按对象局部裁切（P15 52364a65）；寻路、填充、端点分量、走廊通道、最短路径、路径及相交房间（P9 3ad05f52）

**依赖链**：每个墙壁对象自身边界框内最左两列被擦除 → 原本封闭的墙壁出现缺口 → 这些缺口构成迷宫中的通道 → 在修改后的迷宫中寻找两个端点之间的最短路径 → 绘制路径。擦除操作直接改变了寻路的拓扑结构，两步紧密耦合。

先对每个墙壁对象执行局部左侧裁切以打开通道，再在修改后的地图中求解端点间最短路径。

**输入结构**：约 16x16 的网格，背景为黑(0)。灰(5)像素构成若干 4-连通的矩形墙壁块（每块约 3~6 像素宽、4~8 像素高的实心矩形），分布在网格中形成迷宫式布局，相互之间以及与网格边缘之间形成狭窄通道（1~2 像素宽）。两个红(2)像素分别位于网格的左上区域和右下区域，作为端点标记，不与灰(5)墙壁相邻。在初始状态下，由于墙壁的阻挡，两个端点之间不存在 4-连通的背景路径。但对每个灰(5)墙壁对象执行局部裁切后，路径将被打通。生成约束：裁切后恰好存在唯一最短路径连接两个端点。

**规则**：
1. 识别所有灰(5)的 4-连通墙壁对象。
2. 对每个墙壁对象，计算其边界框，将该边界框内最左侧 2 列中属于该对象的像素擦除为背景黑(0)。
3. 在修改后的网格中，以灰(5)剩余像素为不可通行障碍，找到两个红(2)端点之间的 4-连通最短路径（仅经过背景像素）。
4. 将路径上的所有背景像素涂为蓝(1)。两个红(2)端点保持不变，灰(5)剩余墙壁保持不变。

**关键洞察**：墙壁裁切的方向（每个对象自身的最左两列）是相对于对象自身边界框的局部操作，而非全局坐标——求解者必须逐个识别每个墙壁对象并独立计算其局部裁切位置，才能正确重建迷宫拓扑。裁切和寻路在空间上完全交织：改变任一墙壁的裁切结果都会改变路径。

## 新题 4：射线覆盖后的双面板占用补集

**组合逻辑**：[射线延伸/ray_extend + 重涂色/toggle_recolor]（创新：射线不在单一网格操作，而是分别修改两个面板的占用状态） + [透明叠加/transparent_overlay] + [标记/mark] + [占用补集/occupancy_complement]

**来源原语**：射线延伸、重涂色、控制像素、同列对齐、颜色匹配（P5 981add89）；透明叠加、标记、二值掩码、双侧对齐、占用补集（P7 66f2d22f）

**依赖链**：顶行控制像素在各自面板内发射向下的切换射线 → 射线改变每个面板的占用分布 → 叠加两个面板 → 在两个面板中都为背景的位置标记灰色。射线修改了占用分布，从而改变了哪些位置属于"双空"补集——射线和补集检测在空间上相互约束。

在左右两个面板中分别执行射线切换，然后叠加判定双面板占用补集并标记。

**输入结构**：约 12x24 的网格（高 12、宽 24），背景为黑(0)。网格沿宽度中线分为左右两个 12x12 的面板。左面板包含若干蓝(1)前景像素构成的散布图案（约 8~15 个像素，不构成规则形状）；右面板包含若干红(2)前景像素构成的散布图案（约 8~15 个像素）。左面板的第 0 行（顶行）有 2~3 个绿(3)控制像素；右面板的第 0 行有 2~3 个黄(4)控制像素。控制像素的位置在两个面板中不相同。生成约束：射线操作后，至少存在 3 个"双空"位置。

**规则**：
1. 将网格分为左面板（列 0~11）和右面板（列 12~23），按列对齐（右面板的列 12 对应左面板的列 0，依此类推）。
2. 对左面板：每个绿(3)控制像素向下发射射线至面板底部。射线沿该列逐格处理——若遇到蓝(1)像素则擦除为黑(0)背景，若遇到黑(0)背景则涂为蓝(1)。绿(3)控制像素本身保持不变。
3. 对右面板：每个黄(4)控制像素向下发射射线至面板底部。射线沿该列逐格处理——若遇到红(2)像素则擦除为黑(0)背景，若遇到黑(0)背景则涂为红(2)。黄(4)控制像素本身保持不变。
4. 射线处理完成后，将两个面板按行列对齐叠加。输出为单个 12x12 网格（不含顶行控制像素行，即输出为第 1~11 行对齐后的 11x12 网格）：
   - 对齐后某位置在左面板和右面板中都是背景黑(0) → 输出灰(5)。
   - 其他所有位置 → 输出黑(0)背景。

**关键洞察**：控制像素发射的射线以"切换"方式改变各面板的前景分布——一个原本被占用的位置可能被射线擦空，一个原本空白的位置可能被射线填满。因此"双空"补集的结果无法仅从原始面板读出，必须先完成射线切换才能判断。射线位置和面板图案共同约束最终的补集结果。

## 新题 5：遮挡层序投射为对角索引网格

**组合逻辑**：[排序/sorting + 遮挡层序/occlusion_order]（创新：排序结果不输出为一列颜色序列，而作为对角索引投射的头序列输入） + [平铺/tiling + 对角索引映射/diag_index_map] + [循环头序列倍增/cyclic_header_doubled]

**来源原语**：排序、空心矩形、重叠层、遮挡层序、重叠定先后（P6 68bc2e87）；平铺、头序列、对角索引映射、循环头序列倍增（P3 539a4f51）

**依赖链**：重叠空心矩形框的遮挡关系 → 推断从底到顶的颜色排列顺序 → 该顺序直接成为对角索引投射的头序列 → 按 max(row, col) 规则生成输出方阵并循环倍增。遮挡分析的输出（有序颜色序列）成为对角投射的输入（头序列），缺任一步都无法确定输出。

从重叠矩形框的遮挡层序中提取颜色序列，将其作为头序列按对角索引规则投射为倍增方阵。

**输入结构**：约 14x14 的网格，背景为黑(0)。网格中有 3~5 个一像素厚的空心矩形框，每个框的颜色互不相同（从蓝(1)、红(2)、绿(3)、黄(4)、品红(6)中选取）。矩形框大小不同（最小约 3x3，最大约 8x8），部分矩形框相互重叠——重叠位置仅显示最上层框的颜色。每个框至少有一段边与另一个框重叠，使得遮挡关系可被推断。生成约束：遮挡关系产生唯一的全序（无二义性）。

**规则**：
1. 从每种前景颜色的可见像素重建其完整矩形框（即该颜色边界框的一像素厚边框）。
2. 在多个重建框覆盖同一像素的位置，可见颜色的框在该位置位于其他框之上。收集所有这样的局部约束，推断从底到顶的唯一全序。
3. 将该全序（从底到顶）作为头序列 H，长度为 n（等于矩形框数量）。
4. 将 H 循环重复至长度 2n，构建一个 2n x 2n 的方阵，其中位置 (r, c) 的颜色为 H[max(r, c) mod 2n]（行列从 0 开始计数）。
5. 输出该 2n x 2n 方阵。

**关键洞察**：遮挡分析在源题 P6 中输出为单列颜色序列即结束；对角索引投射在源题 P3 中从头序列直接读取。此题中，遮挡分析的输出恰好成为对角投射的生成参数——两个机制通过"有序颜色序列"这一中间表示紧密胶合，形成一条从空间推理到几何生成的推理链。

## 新题 6：形状跨尺度匹配驱动的框体内部填色

**组合逻辑**：[形状匹配/shape_matching + 跨尺度同形/cross_scale_same_shape]（创新：匹配结果不用于裁剪返回，而建立"框-精灵体"的颜色映射） + [填充/fill] + [空心矩形/hollow_rectangle] + [颜色匹配/color_match → 创新为"跨尺度匹配建立颜色对应"]

**来源原语**：裁剪、形状匹配、缩放对象、干扰对象、跨尺度同形、返回较小者（P4 ce602527）；排序、空心矩形、遮挡层序（P6 68bc2e87）；填充（P9 3ad05f52）

**依赖链**：多个空心矩形框 + 多个小型精灵体 → 将每个精灵体的掩码缩放后与各矩形框的边框掩码比较 → 匹配成功则该框的内部填充精灵体的颜色 → 无匹配的框内部保持背景色。匹配操作产生"谁填谁"的对应关系，填充操作执行空间着色——缺少匹配则不知道用什么颜色填，缺少填充则匹配结果无处落地。

通过精灵体与矩形框边框的跨尺度形状匹配，确定每个框内部的填充颜色。

**输入结构**：约 20x20 的网格，背景为黑(0)。网格中有 3~4 个不同颜色的一像素厚空心矩形框（颜色从蓝(1)、红(2)、绿(3)、黄(4)中选取），大小各异（最小 4x4，最大 10x10），互不重叠。另有 3~4 个小型单色精灵体（颜色为橙(7)、青(8)、品红(6)等，与框颜色不同），每个精灵体为 2x2~3x3 范围内的不规则 4-连通图形（3~6 像素），放置在远离所有框的位置。每个精灵体的掩码经 2 倍或 3 倍整数缩放后，恰好与某一个矩形框的边框像素掩码在形状上一致（忽略颜色）。恰好有一个精灵体是干扰项——其缩放后不匹配任何框。生成约束：每个框至多匹配一个精灵体，匹配关系无歧义。

**规则**：
1. 识别所有空心矩形框（每种前景色的边界框一像素厚边框）和所有小型精灵体（与框颜色不同的连通分量）。
2. 对每个精灵体，尝试 2 倍和 3 倍缩放其掩码（每个像素扩展为 2x2 或 3x3 块），将缩放后的掩码与每个矩形框的边框像素掩码逐位比较（平移对齐到框的边界框左上角）。
3. 若精灵体缩放后的掩码与某框的边框掩码完全一致，则该框与该精灵体匹配。
4. 对每个有匹配精灵体的框，将框内部（不含边框本身）的所有像素填充为匹配精灵体的颜色。
5. 无匹配的框内部保持黑(0)背景。干扰精灵体保留在原位。所有框边框颜色不变。

**关键洞察**：源题 P4 中跨尺度匹配用于选出并裁剪返回较小对象；此题中匹配不是为了选取，而是为了建立"框与精灵体之间的颜色映射"——这一映射驱动后续的填充操作，将几何推理（形状比对）的结论转化为着色指令。

## 新题 7：分割线双重角色——格元对称补全受迷宫路径约束

**组合逻辑**：[对称补全/symmetry_completion + 镜像/mirror]（保留） + [寻路/pathfinding]（创新：分割线同时作为格元分界和迷宫墙壁） + [三存一缺推断/infer_missing_from_three] + [最短路径/shortest_path]

**来源原语**：对称补全、镜像、分割线、格元、精灵图、块内对称、三存一缺推断（P14 2546ccf6）；寻路、填充、走廊通道、最短路径（P9 3ad05f52）

**依赖链**：分割线划分格元并形成迷宫结构 → 分割线上的缺口构成格元间的通道 → 从指定起始格元出发，只有通过缺口可达的 2x2 格元块中的缺失格元才被补全 → 不可达块的缺失格元保持为空。分割线的双重角色（格元分界 + 迷宫墙壁）让对称补全和路径可达性在同一物理结构上产生约束交织。

分割线同时定义格元边界和迷宫通道；仅对从起点可达的格元块执行对称补全。

**输入结构**：约 19x19 的网格，背景为黑(0)。灰(5)像素组成完整的水平和垂直分割线，将网格划分为 4x4 或 5x5 的等尺寸格元阵列（每个格元约 3x3~4x4 像素）。部分分割线段上有 1 像素宽的黑(0)缺口（缺口是分割线上被擦除为背景的像素），这些缺口构成相邻格元之间的"门"。格元中的内容：部分 2x2 格元块中有 3 个格元包含同色精灵图（每个精灵图为 2~4 像素的 4-连通图形），第 4 个格元为空（全黑背景）——这样的"三存一缺"块有 3~5 个，分布在网格各处，使用不同颜色（蓝(1)、红(2)、绿(3)、黄(4)等）。一个格元中包含一个品红(6)标记像素作为"起始格元"。生成约束：从起始格元出发，通过缺口可达的"三存一缺"块有 2~3 个，不可达的有 1~2 个；可达判断基于格元级别的 4-连通（从一个格元通过缺口到达相邻格元）。

**规则**：
1. 识别灰(5)分割线及其上的黑(0)缺口。缺口允许在两个相邻格元之间通行。
2. 从品红(6)标记所在的格元出发，沿缺口执行格元级别的 4-连通可达性搜索（从一个格元出发，若该格元与相邻格元之间的分割线段上存在缺口，则可达相邻格元）。标记所有可达的格元。
3. 对每个"三存一缺"的 2x2 格元块，若其所有 4 个格元均可达，则执行对称补全：根据 3 个已有精灵图的镜像关系推断第 4 个格元的精灵图，将其绘制在空格元中，颜色与该块的其他 3 个精灵图相同。
4. 若"三存一缺"块中任一格元不可达，则该块的空格元保持为空。
5. 品红(6)标记像素在输出中擦除为背景。分割线和缺口保持不变。

**关键洞察**：分割线在源题 P14 中纯粹是格元分界；此题中分割线上的缺口赋予其迷宫属性。同一物理结构同时承载两种语义（分界和通行），迫使求解者在一次分析中同时提取两套信息——格元布局和可达性拓扑。

## 新题 8：缺口分类后按类别分组重排为面积递增方阵

**组合逻辑**：[形状匹配 → 创新为"缺口检测作为二分类器"] + [压缩重排/repack] + [缺口决定方向/notch_determines_dir → 创新为"缺口决定分组"] + [面积递增排列/area_ascending_order] + [像素数定边长/pixel_count_determines_side]

**来源原语**：滑动、重涂色、边框缺口、靠边对齐、缺口决定方向（P8 320afe60）；排序、压缩重排、色块、正方形、面积递增排列、像素数定边长（P17 8abad3cf）

**依赖链**：检测每个对象边界框边框上是否有背景缺口 → 有缺口的对象归为 A 组，无缺口的归为 B 组 → 每组内部按像素数从小到大排列 → 每个对象转换为边长等于 sqrt(像素数) 的实心方块 → A 组方块底部对齐从左到右排列，B 组方块在 A 组右侧隔一列后同样排列。缺口检测为分组提供依据，分组结果决定重排的空间布局。

根据对象边框是否有缺口将其分为两组，每组内按面积递增重排为实心方块并列输出。

**输入结构**：约 16x16 的网格，背景为黄(4)。网格中有 5~7 个不同颜色（蓝(1)、红(2)、绿(3)、灰(5)、品红(6)、橙(7)等）的 4-连通单色前景对象，每个对象的像素数为完全平方数（4、9 或 16 像素），形状各异（不是实心方块，而是不规则的连通形状）。部分对象的边界框边框上存在至少一个背景缺口——即边界框的某条边上，该对象在边框位置有像素缺失，且缺失位置两侧的边框位置都有该对象的像素（与 P8 的缺口定义一致）。其余对象的边界框边框完整无缺口。生成约束：每种颜色只有一个对象；各对象像素数可以重复（如两个对象都是 9 像素），但同组内按像素数排序后再按颜色在输入中边界框左上角的行坐标从小到大打破平局。

**规则**：
1. 识别背景色黄(4)和所有非背景的 4-连通前景对象。
2. 对每个对象，计算其边界框。检查边界框的四条边上是否存在缺口：若边界框某条边上有该对象的像素，但该边上存在一个背景像素且该背景像素的左右（或上下，取决于边的方向）相邻的边框位置都有该对象的像素，则该对象"有缺口"。
3. 将有缺口的对象归入 A 组，无缺口的归入 B 组。
4. 每组内按对象像素数从小到大排序。像素数相同时，按该对象边界框左上角在输入网格中的行坐标从小到大排序。
5. 将每个对象转换为实心方块，边长 = sqrt(像素数)，颜色保持该对象的原色。
6. 输出网格：A 组的方块底部对齐从左到右排列，相邻方块间隔 1 列黄(4)背景；隔 1 列黄(4)背景后，B 组方块同样底部对齐从左到右排列。输出网格高度等于最大方块边长，宽度刚好容纳所有方块和间隔列。

**关键洞察**：缺口检测在源题 P8 中决定滑动方向；重排在源题 P17 中对所有对象统一处理。此题中缺口检测被重新定义为分类器——它不控制运动方向，而是将对象划分为两个独立的重排组，使得同一形状特征在不同上下文中扮演截然不同的结构角色。

## 新题 9：平铺扩展后连接最近镜像标记对

**组合逻辑**：[平铺/tiling + 平移周期/translate_period]（创新：平铺不仅扩展图案，还引入新的标记对） + [连线/connect] + [对称标记对/mirrored_marker_pair] + [最小间距对触发/min_gap_triggered] + [补全至指定跨度/complete_to_span]

**来源原语**：平铺、重涂色、精灵体、平移周期、补全至指定跨度（P11 017c7c7b）；连线、填充、对称标记对、间隔段、中轴对称、最小间距对触发（P20 5ad8a7c0）

**依赖链**：输入中的精灵体图案按平移周期铺展至目标跨度 → 铺展后出现多行镜像标记对（原始行和新生成行都包含） → 在所有行中找到水平间距最小的标记对 → 连接这些最小间距标记对。平铺改变了标记对的集合，从而改变了"最小间距"的判定结果——铺展程度直接影响连接目标。

将镜像标记图案按周期铺展至指定跨度后，连接铺展结果中间距最小的标记对。

**输入结构**：约 6x9 的网格（高 6，宽 9），背景为黑(0)。网格中有蓝(1)前景像素组成的图案，该图案沿垂直方向具有平移周期（周期约 2~3 行）。每一个非空行上恰好有 2 个蓝(1)像素，关于网格垂直中轴对称分布（构成镜像标记对），但不同行上标记对的水平间距不同（有的间距大，有的间距小）。可见图案占据网格的上半部分（约 3~4 行），下半部分为空白背景。生成约束：平铺至垂直跨度 9 后，最小间距标记对由新生成的行产生（即单看原始输入部分并非最小间距行），保证至少对比原始和新增行才能确定。

**规则**：
1. 从蓝(1)像素的垂直重复中推断平移周期 p（即每隔 p 行图案重复）。
2. 将图案的一个周期切片沿垂直方向循环铺展，直到网格垂直跨度达到 9 行，宽度保持不变。
3. 将铺展后的所有蓝(1)像素重涂为红(2)。
4. 在重涂后的 9x9 网格中，检查每一行上两个红(2)标记像素之间的水平间距（即两标记列号之差减 1）。
5. 找到间距最小的行（若有多行并列最小，全部选中）。
6. 对每一选中行，将两个红(2)标记之间的所有背景像素填充为红(2)，形成完整的水平连线。
7. 其余行的标记对保持为孤立的两个红(2)像素，不连接。

**关键洞察**：原始输入中的标记对间距可能都较大，平铺生成的新行可能引入更小间距的标记对。求解者必须先完成平铺才能确定"谁是最近对"——这使得平铺和连接操作不可分割：不铺展则无法知道该连哪行，不连接则铺展后的图案缺少最终变换。

## 新题 10：象限异常色选择后提取精灵体作为模板瓦片

**组合逻辑**：[裁剪/crop + 颜色异常值选择/outlier_color_selection]（创新：异常象限不是最终输出，而是中间步骤提取模板） + [平铺/tiling + 双层图案叠加/two_level_pattern] + [像素数决定尺寸/pixel_count_sets_size]

**来源原语**：裁剪、象限、分隔行列、颜色异常值选择（P16 0b148d64）；计数、平铺、四象限、控制区域、模板瓦片、像素数决定尺寸、双层图案叠加（P13 f931b4a8）

**依赖链**：四象限中三个共享同一前景色，一个拥有异常色 → 裁剪出异常象限的内容作为模板瓦片 → 其余三个同色象限中的像素总数决定输出尺寸 → 将模板瓦片平铺至该尺寸。异常象限的裁剪提供了"铺什么"，同色象限的计数提供了"铺多大"——两者分别来自不同的象限判断。

从四象限中识别异常色象限并裁剪为模板，用其余象限的像素总数确定尺寸后平铺。

**输入结构**：约 15x15 的网格（奇数边长，如 15x15 或 13x13），背景为黑(0)。中间有一整行和一整列的灰(5)像素作为分隔线，将网格分为四个大小相等的象限（不含分隔线本身，每个象限约 7x7 或 6x6）。三个象限中各有若干蓝(1)稀疏像素（每个象限 3~8 个蓝(1)像素，分布位置各象限不同）。第四个象限中有若干红(2)像素构成一个小型 4-连通图形（约 2x3 范围内的 3~5 像素）。三个蓝(1)象限中蓝(1)像素的总数为一个完全平方数（如 9 或 16），该数值的平方根为整数 s。红(2)图形的边界框不超过 s x s。生成约束：模板瓦片平铺后恰好填满 s x s 的输出网格（即模板的边界框尺寸能整除 s）。

**规则**：
1. 找到灰(5)分隔行和分隔列，将网格分为四个象限。
2. 统计每个象限中非背景、非灰(5)像素的颜色。三个象限共享同一颜色（蓝(1)），一个象限拥有不同颜色（红(2)）——该象限为异常象限。
3. 裁剪异常象限中红(2)像素的边界框范围，得到模板瓦片 T（保留红(2)像素和黑(0)背景）。
4. 统计三个蓝(1)象限中蓝(1)像素的总数 N，计算 s = sqrt(N)。
5. 构建 s x s 的输出网格，将模板瓦片 T 从左上角开始按行列循环平铺，直到填满 s x s。平铺时模板中的红(2)像素保持红(2)，模板中的黑(0)背景保持黑(0)。
6. 输出为该 s x s 网格。

**关键洞察**：源题 P16 中异常象限被直接裁剪输出即完成；源题 P13 中模板和尺寸信息分别来自下半区的两个象限。此题打破了这两种分工——异常色检测提供模板来源，而"正常"象限的统计量提供尺寸参数，两种判断在同一四象限结构上交叉进行，形成非流水线的同时约束满足。
