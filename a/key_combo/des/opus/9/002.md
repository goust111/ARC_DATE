## 新题 1：旋转补全揭示隐藏区域并按面积分级着色

**组合逻辑**：[对称补全](创新：补全的目的不是标记缺失，而是形成封闭边界) + [洪泛填充](已有) + [重涂色](创新：由面积排名驱动而非固定映射) ← 搭配 [封闭区域] + [面积排名] + [旋转对称]

**来源原语**：对称补全/旋转对称（1b60fb0c）、洪泛填充/封闭区域（7447852a）、面积排名/重涂色（a8d7556c）

**依赖链**：对称补全的输出决定了哪些封闭区域存在（补全前存在缺口，区域不封闭）；洪泛填充依赖补全后的边界结构来识别区域；面积排名依赖洪泛填充识别出的区域集合来分配颜色。删除补全步骤，则无封闭区域可填充；删除填充步骤，则无法确定区域面积；删除排名步骤，则无法确定颜色。

将一个旋转对称缺失一角的蓝(1)边界补全，使缺口闭合形成若干封闭区域，再按封闭区域面积从小到大分级着色。

**输入结构**：黑(0)背景网格，约 15x15。蓝(1)像素构成一个近似 4 重旋转对称（绕网格中心点）的连通边界图案，该图案由宽度为 1 像素的蓝(1)线段组成，在完整状态下可将网格内部分割为 2~4 个互不相连的黑(0)封闭区域（不与网格边界相通的 4-连通区域），各区域面积互不相同。但边界图案有一个象限（约四分之一区域）的部分线段被擦除为黑(0)，导致该象限的封闭区域通过缺口与外部连通。生成约束：擦除的线段数量足以打破至少一个封闭区域的封闭性，但不超过一个象限；完整边界补全后各封闭区域面积互不相等。

**规则**：
1. 确定蓝(1)边界图案的旋转对称中心（网格中心像素）。
2. 将所有蓝(1)像素分别绕中心旋转 90、180、270 度。每个旋转后的位置若为黑(0)，则将其设为蓝(1)。此步骤完成后，边界图案恢复 4 重旋转对称，所有缺口被封闭。
3. 在补全后的网格中，识别所有被蓝(1)像素完全包围的 4-连通黑(0)区域——即不与网格任一边界行/列相通的黑(0)连通分量。
4. 按面积（像素数）从小到大排序这些封闭区域。面积相同时（生成约束保证不会发生），按区域质心的行坐标升序、再按列坐标升序排。
5. 将排序后第 1 个区域（最小）填充为红(2)，第 2 个填充为绿(3)，第 3 个填充为黄(4)，第 4 个填充为灰(5)，以此类推。
6. 蓝(1)边界像素（含补全新增的）和外部黑(0)区域保持不变。

**关键洞察**：补全操作不是装饰性的——它创造了先前不存在的封闭结构。求解者必须先完成旋转补全才能知道有哪些封闭区域，再通过面积排名确定颜色映射。仅看单个示例无法确定面积到颜色的映射顺序是升序还是降序。

## 新题 2：对角标记定义矩形，奇偶织出交替色网

**组合逻辑**：[连线/draw_line](创新：由对角配对的标记隐式定义矩形边界，而非直接画线) + [编织填充/weave_fill](创新：织入模式由距矩形边的曼哈顿距离奇偶决定，而非预设交叉条) ← 搭配 [对角配对] + [奇偶交替颜色] + [角标记像素]

**来源原语**：对角配对/角标记像素/连线（f35d900a）、编织填充/奇偶交替颜色（f3e14006）

**依赖链**：对角配对确定了矩形的几何范围和两种编织颜色；编织填充的奇偶规则锚定在矩形边界上，离开矩形定义则奇偶无从计算。反过来，矩形边界的绘制方式（虚线 vs 实线）取决于编织规则的外推。两者在矩形边界处耦合。

四个前景标记像素分两色对角配对，隐式定义一个矩形；矩形内部按距边界的奇偶规则编织两色交替图案，矩形边界本身用灰(5)虚线绘制。

**输入结构**：黑(0)背景网格，约 18x18。恰好有 4 个非背景前景像素，分属两种颜色（如红(2)和蓝(1)），每种颜色各 2 个。两个红(2)像素位于一个隐含轴对齐矩形的一对对角（如左上和右下），两个蓝(1)像素位于另一对对角（如右上和左下）。四个标记像素之间的行距和列距均不小于 5，保证矩形内部有足够空间。

**规则**：
1. 由四个标记像素确定轴对齐矩形的边界行/列范围：行范围 [r_min, r_max]，列范围 [c_min, c_max]，其中 r_min、r_max、c_min、c_max 分别为四个标记像素行列坐标的最小/最大值。
2. 矩形边界上的像素（位于 r_min 行、r_max 行、c_min 列、c_max 列但不是四个角的像素）用灰(5)绘制，但仅在该像素到最近角的切比雪夫距离为偶数时绘制；距离为奇数时保持黑(0)，形成虚线效果。四个角处保留原有标记颜色不变。
3. 矩形严格内部（r_min < r < r_max 且 c_min < c < c_max）的每个像素 (r, c)，计算 d_r = min(r - r_min, r_max - r) 和 d_c = min(c - c_min, c_max - c)，即该像素到矩形最近水平边和最近竖直边的距离。
4. 若 (d_r + d_c) 为偶数，填充该像素为与 (r_min, c_min) 角同色的标记颜色；若 (d_r + d_c) 为奇数，填充为另一种标记颜色。
5. 矩形外部所有像素保持黑(0)。

**关键洞察**：对角配对同时决定了矩形几何和编织双色。编织的奇偶锚点是矩形边界本身，而非全局坐标。求解者必须识别对角配对关系、推断矩形范围、理解基于边距的奇偶着色规则，三者缺一不可。需要多个示例才能确认奇偶规则是基于 d_r + d_c 而非 d_r * d_c 或其他组合。

## 新题 3：旋转模板匹配驱动遮挡层补全

**组合逻辑**：[模板匹配](创新：需考虑 0/90/180/270 度旋转匹配，源题只考虑平移) + [旋转](已有) + [补全](创新：补全依据不是形状自身的几何暗示，而是匹配到的模板内容) ← 搭配 [前景遮挡] + [面积排序叠加] + [目录模板]

**来源原语**：模板匹配/目录模板/部分匹配识别（3ed85e70）、旋转（1b60fb0c）、补全/前景遮挡（52df9849）、面积排序叠加（83eb0a57）

**依赖链**：补全需要知道被遮挡形状的完整形态，而完整形态只能通过将可见部分与目录模板做旋转匹配来获得——模板匹配和旋转操作共同确定了补全的目标。面积排序确定遮挡层序（前景在上），这又影响哪些像素被视为"被遮挡"。四个操作形成环形约束：匹配→确定完整形→确定遮挡关系→确定哪些像素需匹配。

在目录区域查找模板，在工作区将旋转且互相遮挡的部分可见精灵与模板匹配，用匹配到的模板内容补全被遮挡的部分。

**输入结构**：黑(0)背景网格，约 20x20。网格左侧有一个灰(5)背景的目录区域（约 6 列宽），目录区域内排列着 2~3 个多色模板精灵，每个模板占据 3x3 到 5x5 的紧凑边界框，模板内部各像素颜色互不全同，模板之间不重叠且被灰(5)像素分隔。网格右侧黑(0)工作区内散布着 2~4 个前景对象，每个对象是某个目录模板经 0/90/180/270 度旋转后的副本，但部分对象之间存在空间重叠——重叠处只显示"在上层"那个对象的颜色。每个工作区对象至少有 60% 的像素可见（未被遮挡）。生成约束：每个模板至多被使用两次；不同工作区对象的可见部分足以唯一确定其对应模板和旋转角度。

**规则**：
1. 从灰(5)目录区域中提取所有模板精灵：每个模板是目录内一个 4-连通非灰(5)前景连通分量的紧凑边界框裁剪（灰(5)像素视为透明）。
2. 对工作区中每个 4-连通前景连通分量，尝试将其可见像素与每个模板的 0/90/180/270 度旋转版本做子图匹配：找到唯一一个模板和旋转角度，使得模板旋转后的非透明像素集合包含该连通分量的所有可见像素，且颜色逐像素一致。记录匹配结果（模板编号、旋转角度、平移偏移）。
3. 确定遮挡层序：按工作区对象的面积（匹配到的模板旋转后的总像素数）从大到小排列。面积最大的在最底层，面积最小的在最顶层。面积相同时，边界框左上角行坐标小的在下层。
4. 从最底层开始，依次将每个对象的完整旋转模板绘制到输出网格上（绘制时灰(5)像素透明，不覆盖已有内容）。上层对象覆盖下层对象的像素。
5. 目录区域及其灰(5)背景原样保留。工作区中不属于任何对象完整模板的黑(0)像素保持黑(0)。

**关键洞察**：与源题 52df9849 不同，这里被遮挡形状的完整形态无法从自身几何推断（不是简单矩形或对角线），必须从目录中找到匹配模板。与源题 3ed85e70 不同，匹配需要考虑旋转。模板匹配、旋转识别和遮挡补全三者相互依赖，形成非线性推理结构。

## 新题 4：膨胀探测邻近性以决定同色连通与孔洞豁免

**组合逻辑**：[膨胀/dilate](创新：膨胀不是为了画光晕，而是作为邻近性检测器) + [连线/connect](创新：连线条件由膨胀后的接触判定，而非预设配对) + [填充/fill](已有) ← 搭配 [同色配对] + [封闭孔洞] + [孔洞保留不填]

**来源原语**：膨胀/封闭孔洞/孔洞保留不填（5adee1b2）、连线/同色配对/填充（06df4c85）、连通分量（a8d7556c）

**依赖链**：膨胀操作的输出决定了哪些同色对象"足够近"可以连通——这一判断在膨胀之前无法做出。连通操作反过来受到孔洞豁免规则的约束：连通路径上的像素若属于某个对象的封闭孔洞内部，则该像素不被填充。孔洞的判定又依赖于对象膨胀后的边界。三者形成紧密耦合。

将同色对象各膨胀一圈，若膨胀后彼此接触则用该色填充两对象之间的最短轴对齐路径，但路径中属于任何对象封闭孔洞内部的像素豁免不填。

**输入结构**：黑(0)背景网格，约 16x16。网格中散布 4~6 个单色 4-连通前景对象，使用 2~3 种非背景颜色（如红(2)、蓝(1)、绿(3)）。同色对象之间的最小间距为 1~3 个黑(0)像素（即膨胀 1 像素后某些同色对象会接触，某些不会）。部分对象包含封闭孔洞——对象内部被该对象颜色完全包围的黑(0)像素区域（至少 1 个像素）。不同颜色的对象之间间距不小于 3 个像素（保证不同色对象膨胀后不会接触）。每个对象是不规则形状（3~12 像素的 4-连通分量），不预设为特定几何形。

**规则**：
1. 识别所有 4-连通前景连通分量及其颜色。
2. 对每个连通分量做 1 像素膨胀：将该分量边界上每个像素的 4-邻域中的黑(0)像素标记为该分量的"膨胀区"（仅做标记，不实际绘制膨胀区到输出）。
3. 检查同色连通分量对：若分量 A 和分量 B 颜色相同，且 A 的膨胀区与 B 的膨胀区存在公共像素或 A 的膨胀区与 B 的原始像素存在重叠（反之亦然），则 A 和 B 构成"可连通对"。
4. 对每个可连通对 (A, B)，找到 A 边界框与 B 边界框之间的最短轴对齐连线路径：取 A 中距 B 最近的像素 p_A 和 B 中距 A 最近的像素 p_B（曼哈顿距离最短；平局时取行坐标较小的，再取列坐标较小的）。若 p_A 和 p_B 同行，则沿该行在两者之间填充；若同列，则沿该列填充；若既不同行也不同列，先水平走到 p_B 的列，再竖直走到 p_B 的行（L 形路径，先水平后竖直）。
5. 路径上的每个黑(0)像素填充为该对的共享颜色，**但**若该像素位于任何前景对象的封闭孔洞内部（即被某个同色连通分量的像素在 4-连通意义下完全包围的黑(0)区域），则该像素不填充，保持黑(0)。
6. 所有原始前景像素保持不变。不可连通的对象保持原样。膨胀区标记不出现在输出中。

**关键洞察**：膨胀操作在此不是装饰目的（与源题 5adee1b2 不同），而是作为"足够近"的判定机制。孔洞豁免规则使得连通路径在孔洞处"绕行"（实际上是跳过），求解者必须理解三层逻辑：膨胀判邻近 -> 连通填路径 -> 孔洞区豁免。单个示例无法确定膨胀半径（是 1 还是 2）。

## 新题 5：双层栅格多数决后经图例重映射着色

**组合逻辑**：[压缩/compress](创新：两级嵌套分割而非单级) + [多数决/majority_vote](已有) + [重涂色/recolor](创新：由图例映射驱动，而非直接保留多数色) ← 搭配 [格子格局] + [颜色图例] + [图例映射] + [分隔行列]

**来源原语**：压缩/格子格局/多数决（af24b4cc）、颜色图例/图例映射/重涂色（5adee1b2）、分隔行列（af24b4cc）

**依赖链**：两级分割结构决定了多数决的粒度——粗级分割定义大块，细级分割定义大块内的子块，多数决在子块级执行后再在大块级聚合。图例映射作用于聚合结果，将多数色转换为输出色。删除任一层级的分割或图例映射，输出都无法确定。

双层栅格将网格分成大块和子块，每个子块内多数决得到一个颜色，每个大块再对其子块颜色多数决，最后用图例将多数色映射为输出色。

**输入结构**：黑(0)背景网格，约 20x20。灰(5)实线（整行或整列）将网格分成 3x3 或 4x4 的粗级大块。每个大块内部，蓝(1)细线（宽 1 像素的整行/整列片段，仅跨越该大块内部）将大块进一步分成 2x2 或 3x3 的细级子块。每个子块内填有一种主色（红(2)、绿(3)、黄(4)、橙(7)中的一种），但混有少量其他色像素作为噪声（噪声不超过子块面积的 30%）。网格左上角有一个 2~4 行的图例区域，不被栅格分割覆盖：图例由若干 1x2 色块组成，每个色块左列为"输入色"、右列为"输出色"，表示映射关系（如红(2)->橙(7)、绿(3)->黄(4)等）。生成约束：每个大块内各子块的多数色不完全相同（至少有一个子块的多数色与其他子块不同），保证大块级多数决有意义；图例包含所有可能出现的大块级多数色。

**规则**：
1. 识别灰(5)分隔线确定的粗级大块边界，和蓝(1)分隔线确定的细级子块边界。图例区域不参与分块（图例区域为灰(5)线条包围的左上角矩形区域）。
2. 对每个细级子块，统计非灰(5)、非蓝(1)、非黑(0)的前景颜色出现次数，取出现次数最多的颜色作为该子块的"代表色"。平局时取在输入中首次出现位置（按行优先扫描序）最靠前的颜色。
3. 对每个粗级大块，统计其所有子块代表色的出现次数，取出现次数最多的颜色作为该大块的"聚合色"。平局时取子块代表色中在输入中首次出现位置最靠前的颜色。
4. 读取图例映射：将每个聚合色替换为图例中对应的输出色。
5. 输出网格尺寸等于粗级大块的行数 x 列数。每个输出像素的颜色为对应大块的映射后聚合色。
6. 图例区域不出现在输出中。

**关键洞察**：两级多数决是新结构——源题 af24b4cc 只有单级压缩，源题 5adee1b2 的图例用于膨胀着色而非多数决后映射。求解者必须识别两种不同宽度的分隔线代表不同层级，并理解多数决在两个尺度上逐级聚合后还要经过图例重映射。单个示例无法区分是"子块多数决后直接输出"还是"两级多数决后映射输出"。

## 新题 6：镜像候选位叠加需标记像素吻合方可生效

**组合逻辑**：[镜像/mirror](创新：不是全局镜像，而是逐对象计算镜像候选位) + [透明叠加/transparent_overlay](创新：叠加不是无条件的，需标记吻合才触发) + [重涂色/recolor](已有) ← 搭配 [标记对齐] + [中心对齐] + [共享标记]

**来源原语**：镜像（80214e03）、透明叠加/中心对齐/前景掩码（c8cbb738）、标记对齐/共享标记（83eb0a57）、重涂色（多个源题）

**依赖链**：镜像操作确定了每个精灵的候选叠加位置，但叠加是否实际发生取决于标记像素是否在候选位置吻合——这是一个条件分支。叠加后的重涂色标记了哪些精灵被成功配对。三个操作形成决策树结构：计算候选位 -> 检查标记吻合 -> 条件叠加 + 标记重涂。

每个精灵沿对称轴镜像后，若镜像位上另一精灵的灰(5)标记像素恰好与之重合，则将镜像副本透明叠加到该精灵上；成功配对的精灵标记像素变为黄(4)。

**输入结构**：黑(0)背景网格，约 18x18。网格中央有一条竖直的灰(5)像素列（从第一行到最后一行，宽 1 像素），作为对称轴。对称轴两侧各散布 2~4 个小型多色精灵（3~8 像素的 4-连通分量，不含黑(0)和灰(5)），每个精灵内部恰好有一个灰(5)像素作为标记。精灵之间互不接触，且任何精灵的镜像位不会超出网格边界。部分精灵被刻意放置为：镜像后其标记像素恰好落在对称轴另一侧某精灵的标记像素位置上（"可配对"）；其余精灵镜像后标记不与任何精灵标记重合（"不可配对"）。生成约束：可配对精灵成对出现，每对中两个精灵分居轴两侧。

**规则**：
1. 识别灰(5)竖直对称轴（唯一一列全为灰(5)的列）。
2. 对对称轴两侧的每个前景精灵 S，计算其关于对称轴的水平镜像位置：每个像素 (r, c) 镜像为 (r, 2*axis_col - c)。
3. 检查镜像后 S 的标记像素（灰(5)像素的镜像位）是否与另一个精灵 T 的标记像素（灰(5)像素的原始位）坐标完全一致。
4. 若吻合（S 和 T 构成配对）：将 S 的镜像副本透明叠加到 T 的位置——S 的镜像中每个非黑(0)像素覆盖 T 位置处对应坐标的像素（若该坐标原本为黑(0)，则写入 S 的镜像颜色；若已有 T 的颜色，则 S 的镜像颜色覆盖）。叠加完成后，将配对中双方的标记像素（S 原始位和 T 原始位）均重涂为黄(4)。对 T 也同样做镜像叠加到 S 的位置（双向叠加）。
5. 若不吻合（S 不可配对）：S 保持原样，不做任何叠加或重涂。
6. 对称轴像素列从输出中移除：输出网格列数比输入少 1，对称轴右侧所有像素左移一列。

**关键洞察**：镜像操作产生了候选叠加位置，但只有标记吻合时才执行叠加——这一条件判断是源题中不存在的新结构关系。源题 c8cbb738 的叠加是无条件的全部居中叠加；源题 83eb0a57 的标记对齐用于定位而非门控叠加决策。求解者需多个示例才能确认"不配对则不叠加"的规则。

## 新题 7：符号解码距离驱动射线延伸长度

**组合逻辑**：[符号解码/symbol_decoding](创新：解码输出不是颜色而是距离参数) + [延伸/extend](创新：延伸长度由解码值参数化，而非固定 1 格) + [射线延伸/ray_cast](已有) ← 搭配 [边缘条] + [控制像素] + [符号掩码] + [标记在两边之间]

**来源原语**：符号解码/符号掩码（17cae0c1）、延伸/边缘条/控制像素/标记在两边之间（642248e4）、射线延伸（673ef223）

**依赖链**：符号解码产生的距离值直接参数化了射线延伸的长度——延伸操作无法独立确定自己该延伸多远。同时，每个控制像素必须找到"最近"的符号面板，而"最近"的定义取决于控制像素和面板的空间关系。删除符号解码，延伸长度无从确定；删除延伸规则，解码结果无处使用。

每个控制像素读取最近的 3x3 符号面板，解码得到一个距离值，然后向其较近的边缘条方向发射该长度的射线。

**输入结构**：黑(0)背景网格，约 18x20。网格顶行和底行各有一条完整的彩色边缘条——顶行为红(2)，底行为绿(3)。在两条边缘条之间的区域内，散布着 3~5 个橙(7)的控制像素（孤立单像素）。此外，在该区域内还嵌入了 3~5 个 3x3 的符号面板，每个面板由灰(5)和黑(0)像素组成二值图案。符号面板之间互不重叠，与控制像素不重叠，且面板边界与控制像素的最小曼哈顿距离不小于 2。每个符号面板中灰(5)像素的数量在 1~7 之间（不为 0 也不为 9）。生成约束：每个控制像素有唯一最近的符号面板（以控制像素到面板中心的曼哈顿距离度量，不存在平局）。

**规则**：
1. 识别顶行红(2)边缘条和底行绿(3)边缘条。
2. 对每个 3x3 符号面板，计算其中灰(5)像素的数量 d（1 <= d <= 7），此为该面板编码的"距离值"。
3. 对每个橙(7)控制像素 P：
   a. 找到距离 P 曼哈顿距离最近的符号面板（以面板中心像素为参考点），读取其距离值 d。
   b. 计算 P 到顶行边缘条的距离 d_top = P.row - 0 和到底行边缘条的距离 d_bot = (max_row) - P.row。
   c. 若 d_top <= d_bot，P 朝上方发射射线：从 P 的上方相邻像素开始，沿列方向向上连续填充 d 个黑(0)像素为红(2)（较近边缘条的颜色）。若射线在到达 d 个像素之前遇到非黑(0)像素（包括边缘条或符号面板像素），则射线在该像素之前停止，不覆盖已有像素。
   d. 若 d_top > d_bot，P 朝下方发射射线：从 P 的下方相邻像素开始，沿列方向向下连续填充 d 个黑(0)像素为绿(3)。遇到非黑(0)像素时提前停止。
   e. d_top = d_bot 时（P 在正中间），朝上方发射（红(2)）。
4. 控制像素 P 本身保持橙(7)不变。符号面板保持原样。边缘条保持原样。

**关键洞察**：源题 642248e4 的延伸固定为 1 格，方向由距离决定；本题中距离值来自符号解码——一个空间参数由另一种视觉编码提供，形成跨模态耦合。符号面板的灰(5)像素计数规则（而非图案形状映射到颜色）需要多个示例对比才能归纳出。

## 新题 8：去噪恢复种子后自相似印章展开并周期性重涂

**组合逻辑**：[降噪/denoise](创新：去噪不是终点，其结果成为印章模板) + [印章覆盖/stamp_overlay](创新：印章内容不是输入直接给出，而是从噪声中恢复) + [重涂色/recolor](创新：按印章展开后块位置的周期编号决定颜色替换) ← 搭配 [网格分块] + [种子精灵] + [等间隔采样填充] + [忽略标记取主色]

**来源原语**：降噪/网格分块/忽略标记取主色/瓦片（5614dbcf）、印章覆盖/种子精灵/前景位放自身副本/像素到块映射（5b6cbef5）、重涂色/等间隔采样填充（7447852a）

**依赖链**：降噪的输出就是印章覆盖的输入模板——不做降噪则无法得到正确的种子图案。印章展开后的块位置决定了周期重涂的对象——不做印章展开则无法确定哪些块需要重涂。三个操作串联但每一步的输出都被后续步骤以非平凡方式消费：降噪产生种子（种子既是印章内容也是印章掩码），展开产生块阵列，周期重涂改变特定块的颜色。

输入是一个含噪声的放大种子图案；去噪压缩恢复种子后，将种子作为自相似印章展开为更大的网格，再对展开后的每第三个块做颜色替换。

**输入结构**：黑(0)背景网格，恰好为 (N*K) x (N*K) 大小（如 12x12 = 4x3 x 4x3，其中 N=4 为种子边长，K=3 为瓦片缩放因子）。网格被隐式分为 N x N 个大小为 K x K 的瓦片块。每个瓦片块内有一种主色（蓝(1)或黑(0)），但混入了若干灰(5)噪声像素（每个 K x K 块中灰(5)像素不超过 K-1 个）。去噪后，每个瓦片块的主色构成一个 N x N 的二值种子图案（蓝(1)为前景，黑(0)为背景）。种子图案中蓝(1)像素数量在 3~N*N-3 之间。生成约束：种子图案不全为前景也不全为背景；K 在 2~4 之间。

**规则**：
1. 将输入网格分为 N x N 个大小为 K x K 的瓦片块（N 和 K 由输入尺寸和块内一致性推断）。
2. 对每个瓦片块，忽略灰(5)像素，统计剩余像素中蓝(1)和黑(0)的数量，取多数色作为该块的代表色。
3. 将 N x N 的代表色矩阵作为"种子图案"S。
4. 执行自相似印章展开：创建一个 (N*N) x (N*N) 的全黑(0)输出网格，划分为 N x N 个大小为 N x N 的输出块。对种子 S 中每个前景（蓝(1)）位置 (i, j)，将整个种子 S 复制到输出网格中第 (i, j) 个输出块中（蓝(1)像素保持蓝(1)）。对种子中黑(0)位置的输出块，保持全黑(0)。
5. 周期重涂：按行优先顺序（从左到右、从上到下）对所有包含种子副本的输出块编号为 0, 1, 2, 3, ...。编号模 3 余 0 的块（即编号 0, 3, 6, ...），将该块内所有蓝(1)像素替换为红(2)。其余块中蓝(1)像素保持不变。
6. 输出网格中所有黑(0)像素保持黑(0)。

**关键洞察**：输入并未直接给出种子图案——种子藏在噪声中，必须先去噪才能恢复。恢复的种子同时充当印章内容和放置掩码（如源题 5b6cbef5 的自引用结构），但叠加了噪声层（源题 5614dbcf 的挑战）。周期重涂规则（每第三个块变色）需要对比多个示例才能确认周期是 3 而非 2 或 4。

## 新题 9：分隔栅格内同色端点连线路径受遮挡形状阻断与改道

**组合逻辑**：[连线/connect](创新：连线路径不再是直线填充，遇到障碍物需改道) + [补全/complete](创新：遮挡形状的完整足迹作为不可穿越障碍物，而非补全目标) + [填充/fill](已有) ← 搭配 [分隔栅格] + [同色配对] + [矩形足迹] + [前景遮挡] + [沿行列填充间隙]

**来源原语**：连线/分隔栅格/同色配对/沿行列填充间隙（06df4c85）、补全/矩形足迹/前景遮挡（52df9849）、填充（多个源题）

**依赖链**：遮挡形状的矩形足迹决定了哪些像素是不可穿越的障碍，连线路径必须绕过这些区域。但遮挡形状的"完整足迹"只能通过分析可见部分推断出来（如矩形被其他前景遮挡了一部分）。连线的路径规划依赖于障碍的完整范围，而障碍范围依赖于遮挡补全的推断。

在分隔栅格中连接同色端点，但连线路径不能穿过隐含矩形障碍物的完整足迹——即使障碍物部分被其他前景遮挡，其完整矩形范围仍作为不可穿越区域。

**输入结构**：黑(0)背景网格，约 16x16。灰(5)实线（整行和整列）形成分隔栅格，将网格分为 4x4 或 5x5 的矩形格子。大部分格子为全黑(0)。部分格子中有彩色端点像素（如红(2)、蓝(1)），同色端点恰好成对出现且位于同一行或同一列的不同格子中（两个格子之间可能间隔若干空格子）。另有 1~2 个橙(7)的实心矩形障碍物跨越若干格子——这些矩形可能被路过的灰(5)栅格线穿过但其足迹仍为连续矩形。部分矩形障碍物的边缘可能被端点像素部分遮挡（端点像素画在障碍物之上），但障碍物的完整矩形范围可从可见部分推断。生成约束：每对同色端点之间至少存在一条不穿过障碍物完整足迹的轴对齐路径（允许走 L 形）。

**规则**：
1. 识别灰(5)栅格分隔线。
2. 识别橙(7)障碍物：找到所有橙(7)像素的 4-连通分量，对每个分量计算其能被包含的最小轴对齐矩形（边界框）。该边界框即为该障碍物的"完整足迹"，即使边界框内某些像素不是橙(7)（被遮挡为其他颜色），整个矩形区域仍视为不可穿越。
3. 对每对同色端点 (P1, P2)，规划连线路径：
   a. 若 P1 和 P2 同行且该行上两者之间没有障碍物足迹像素，则沿该行直线连接——将两者之间的所有黑(0)像素（不含灰(5)栅格线像素）填充为该对颜色。
   b. 若 P1 和 P2 同列且该列上两者之间没有障碍物足迹像素，则沿该列直线连接。
   c. 若直线路径被障碍物阻断，则走 L 形路径：从 P1 先水平走到 P2 所在列（若该水平段无障碍），再竖直走到 P2；若水平段有障碍，则从 P1 先竖直走到 P2 所在行，再水平走到 P2。取两种 L 形中不经过障碍物足迹的那一条（生成约束保证至少有一条可行）。
4. 连线只填充黑(0)像素，不覆盖灰(5)栅格线、橙(7)障碍物或其他颜色端点。
5. 所有未被连线的像素保持原样。

**关键洞察**：与源题 06df4c85 不同，连线路径不再总是直线——障碍物迫使路径改道。与源题 52df9849 不同，遮挡形状的完整足迹不是被补全到输出中，而是作为连线规划的不可见约束。求解者必须同时理解三层信息：栅格结构（连线通道）、障碍物完整足迹（不可穿越区域，需推断）、同色端点配对（连线目标）。仅看一个示例可能无法确定"障碍物足迹是实际可见范围还是完整矩形边界框"。

## 新题 10：封闭区域内的瓦片模式决定该区域的膨胀方向

**组合逻辑**：[洪泛填充/flood_fill](创新：用于识别封闭区域，但填充内容不是单色而是保留原有模式) + [膨胀/dilate](创新：膨胀方向不是全向，而是由区域内部的瓦片模式编码决定) + [压缩/compress](已有) ← 搭配 [封闭区域] + [分隔线] + [网格分块] + [瓦片] + [包围]

**来源原语**：洪泛填充/封闭区域/分隔线（7447852a）、膨胀（5adee1b2）、压缩/网格分块/瓦片（5614dbcf）

**依赖链**：封闭区域的边界结构和内部瓦片模式必须同时分析——边界告诉你区域在哪里，瓦片模式告诉你该区域的膨胀行为。膨胀操作的参数（方向）不是全局固定的，而是由每个区域自身的内容编码。这形成了"结构解构"模式：输入的几何特征（区域形状）和纹理特征（瓦片模式）编码了不同维度的信息。

红(2)分隔线将网格分成若干封闭区域，每个区域内部有规律的瓦片条纹编码了该区域应向哪个方向膨胀一格。

**输入结构**：黑(0)背景网格，约 15x15。红(2)像素构成连通的分隔线网络（类似 7447852a），将网格分成 3~5 个不规则封闭区域（不与网格边界相通的黑(0)区域）和一个外部区域。每个封闭区域内部用一种前景色（蓝(1)、绿(3)、黄(4)、橙(7)中的一种，各区域颜色可不同）绘制条纹模式：水平条纹（该颜色像素填充区域内的偶数行，奇数行保持黑(0)）或竖直条纹（该颜色像素填充区域内的偶数列，奇数列保持黑(0)）。条纹的行/列编号以该区域边界框左上角为原点。生成约束：每个封闭区域至少 3 行 3 列大，保证条纹方向可辨认；各区域之间由至少 1 像素宽的红(2)分隔线隔开。

**规则**：
1. 识别红(2)分隔线网络，找到所有被红(2)完全包围的 4-连通封闭区域。
2. 对每个封闭区域，判断其内部条纹方向：
   a. 若区域内前景色像素仅出现在相对于区域边界框左上角行号为偶数的行上（列上则有和没有均可），则为"水平条纹"。
   b. 若前景色像素仅出现在相对于区域边界框左上角列号为偶数的列上，则为"竖直条纹"。
3. 膨胀方向由条纹方向决定：
   a. 水平条纹的区域向上膨胀 1 格：将该区域边界框最上一行紧邻上方的那一行中，与区域边界水平范围对应的红(2)像素替换为该区域的前景色。
   b. 竖直条纹的区域向右膨胀 1 格：将该区域边界框最右一列紧邻右方的那一列中，与区域边界竖直范围对应的红(2)像素替换为该区域的前景色。
4. 若膨胀方向上的目标像素不是红(2)（如已被另一区域膨胀占据或为网格边界外），则该像素不变。
5. 区域内部的条纹模式保持不变。未被膨胀影响的红(2)分隔线保持不变。外部区域（与网格边界相通的黑(0)区域）不参与任何操作。

**关键洞察**：输入的视觉纹理（条纹方向）不只是装饰——它编码了变换参数。求解者必须同时理解空间结构（封闭区域的位置和形状）和纹理编码（条纹方向→膨胀方向），两者缺一不可。这是"隐式编码"结构：几何形状告诉你"在哪里操作"，纹理告诉你"怎么操作"。单个示例可能无法区分"条纹方向决定膨胀方向"和"区域形状决定膨胀方向"。
