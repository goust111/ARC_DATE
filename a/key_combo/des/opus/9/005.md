## 新题 1：桥接网络决定同心填充模式

**组合逻辑**：[连通判定](创新：从二元连通测试扩展为连通分量大小分析) → [同心层填充](创新：填充模式由外部图结构决定而非固有属性) / [纯色填充](孤立帧的替代输出)

**来源原语**：连通判定(connectivity_test, #239be575), 桥接路径(bridge_path, #239be575), 同心层填充(concentric_fill, #a3f84088), 按距离循环配色(distance_color_cycling, #a3f84088), 空心矩形(hollow_rectangle, #917bccba / #a3f84088 / #c0f76784), 连通性(connectivity, #239be575)

**依赖链**：桥接路径决定帧之间的连通关系 → 连通分量大小决定每个帧的填充模式（同心循环 vs 纯色）→ 同心填充在被激活的帧内部按距离着色。删除连通判定则无法区分两种填充模式；删除同心填充则被激活帧的输出无法确定。

将散布于网格上的空心矩形帧按桥接路径分组，连通分量内帧数 >= 2 的帧做同心层填充，孤立帧做纯色填充，桥接路径本身在输出中被擦除。

**输入结构**：约 22x22 的黑(0)背景网格。网格上散布 4-6 个灰(5)一像素厚的空心正方形帧，边长各不相同（范围 5-11 像素），帧之间无重叠，彼此间距至少 2 像素。部分帧对之间由 1 像素宽的青(8)桥接路径连接——桥接路径是从一个帧外壁的某像素出发，沿水平或垂直方向延伸到另一个帧外壁的像素的直线段。每个帧最多参与 2 条桥接路径。生成约束：至少存在一个包含 2 个以上帧的连通分量，且至少存在一个孤立帧（不参与任何桥接路径）。

**规则**：
1. 以灰(5)帧为节点、青(8)桥接路径为边，构建无向连通图。计算每个连通分量包含的帧数。
2. 对于所在连通分量帧数 >= 2 的帧：保留灰(5)外框不变，在其严格内部区域按曼哈顿距离（从内壁向内计算，最外一层内部像素距离为 0）循环填充颜色序列 [红(2), 蓝(1)]——距离 0 填红(2)，距离 1 填蓝(1)，距离 2 填红(2)，依此类推，直到中心。
3. 对于孤立帧（所在连通分量帧数 = 1）：保留灰(5)外框不变，内部全部填充黄(4)。
4. 擦除所有青(8)桥接路径像素（置为黑(0)）。
5. 其余黑(0)背景像素不变。

**关键洞察**：桥接路径在输出中完全消失——它们的唯一功能是编码帧之间的连通关系。求解者必须先识别桥接网络的拓扑结构，才能确定每个帧该用哪种填充模式。仅看单个示例时，可能误以为填充模式由帧的大小或位置决定，必须对比多个示例才能归纳出"连通分量大小"这一真正的判断条件。

## 新题 2：图例匹配驱动边缘定向滑动

**组合逻辑**：[形状匹配](已有) → [重涂色](创新：匹配结果同时编码颜色和运动方向) → [平移](创新：颜色决定滑动方向) + [排序](创新：同向冲突时按距离优先排序)

**来源原语**：形状匹配(shape_matching, #845d6e51), 旋转反射等价(rotation_reflection_equivalence, #845d6e51), 图例区域(legend_region, #845d6e51), 分隔线(divider, #845d6e51), 重涂色(recolor, #845d6e51), 平移(translate, #b5ca7ac4), 排序(sort, #b5ca7ac4), 颜色决定目标(color_determines_destination, #b5ca7ac4), 距离优先排序(distance_priority_ordering, #b5ca7ac4), 行重叠内移(row_overlap_shifts_inward, #b5ca7ac4)

**依赖链**：形状匹配确定每个查询精灵体对应的模板 → 模板颜色赋予查询精灵体新身份 → 新颜色（红 vs 蓝）决定滑动方向（左 vs 右）→ 同方向同行的多个精灵体按离目标边缘的距离排序以避免碰撞。四步中任一步被跳过均无法正确生成输出。

将查询精灵体通过形状匹配获得模板颜色，颜色决定滑动方向，同向冲突者按距离排序依次贴靠边缘。

**输入结构**：约 20x25 的橙(7)背景网格。灰(5)水平分隔线（1 像素厚，横跨整个网格宽度）将网格分为上下两半。上半区为图例区：包含 2-4 个小型模板精灵体，每个模板是一个 4-连通的单色图形（3-6 像素），颜色仅使用红(2)和蓝(1)。不同模板的形状在所有旋转和反射下互不等价。下半区为查询区：包含与模板数量相同的青(8)查询精灵体，每个查询精灵体的形状在旋转/反射等价意义下恰好匹配一个模板（一一对应）。查询精灵体之间互不相邻，且不接触网格边缘。生成约束：至少有一对查询精灵体匹配到相同颜色（即至少两个模板同色），且它们位于下半区的相同行范围（边界框在行方向有重叠），以触发碰撞解决机制。

**规则**：
1. 对每个青(8)查询精灵体，在所有旋转和反射下与上半区各模板的形状进行比较，找到唯一匹配的模板。
2. 将匹配的查询精灵体重涂为其对应模板的颜色（红(2)或蓝(1)）。
3. 红(2)精灵体向左滑动至网格左边缘（精灵体边界框的最左列对齐到列 0）；蓝(1)精灵体向右滑动至网格右边缘（精灵体边界框的最右列对齐到最后一列）。精灵体保持其原始行位置不变。
4. 碰撞处理：若两个同色精灵体滑向同一边缘且行范围有重叠（边界框在行方向有交集），则按以下规则处理——离目标边缘更近的精灵体（以边界框到目标边缘的列距离计算）优先贴靠边缘；较远的精灵体紧贴在前者后方（红色方向：较远者的最左列 = 前者的最右列 + 1；蓝色方向：较远者的最右列 = 前者的最左列 - 1）。若列距离相同，则边界框上方（行号较小）的优先。
5. 灰(5)分隔线和上半区模板保持不变。查询精灵体原始位置的像素置为橙(7)背景色。

**关键洞察**：形状匹配的结果不只是一个标签——它同时编码了颜色（视觉输出）和运动方向（空间变换）。仅看单个示例可能以为滑动方向由位置决定，必须对比多个示例中匹配到不同颜色的精灵体的运动方向才能归纳出"颜色决定方向"这一规则。

## 新题 3：菱形膨胀重塑迷宫拓扑

**组合逻辑**：[膨胀](创新：膨胀对象不是变换目标，而是改变另一结构的拓扑) → [洪泛填充](创新：在被膨胀改变后的拓扑上执行) + [路径奇偶交替涂色](创新：填充颜色由修改后拓扑中的路径距离决定)

**来源原语**：膨胀(dilate, #d753a70b), 菱形轮廓(diamond_outline, #d753a70b), 半径微调(radius_adjust, #d753a70b), 洪泛填充(flood_fill, #b782dc8a), 迷宫走廊(maze_corridor, #b782dc8a), 种子像素(seed_pixel, #b782dc8a), 路径连通(path_connectivity, #b782dc8a), 路径奇偶交替涂色(alternating_color_by_path_parity, #b782dc8a)

**依赖链**：菱形轮廓膨胀物理性地阻断部分迷宫走廊 → 走廊拓扑改变导致种子像素的可达范围变化 → 洪泛填充在修改后的拓扑上执行，按 BFS 步数奇偶交替着色 → 因膨胀而不可达的走廊保持黑色。删除膨胀则迷宫拓扑不同（可达区域更大）；删除洪泛填充则无输出着色。

在迷宫中膨胀一个菱形轮廓以阻断走廊，然后从种子出发在改变后的迷宫中按路径距离奇偶交替涂色。

**输入结构**：约 19x19 的黑(0)背景网格。青(8)像素构成迷宫墙壁，形成多条 1 像素宽的走廊（黑(0)像素）。迷宫内部某区域有一个灰(5)曼哈顿菱形轮廓（1 像素厚，半径 2-4），菱形的像素覆盖在走廊上（即菱形所在位置原本是走廊的一部分）。迷宫中有一个红(2)种子像素，位于菱形轮廓外部的某条走廊中。生成约束：膨胀前种子可通过走廊到达菱形两侧的区域；膨胀后（半径 +1）菱形的新像素恰好阻断至少一条连接种子与菱形另一侧走廊的路径，使得膨胀后部分走廊从种子不可达。

**规则**：
1. 将灰(5)菱形轮廓膨胀一层：保持相同中心，半径加 1，新增的轮廓像素也设为灰(5)。原半径处的像素保留（形成双层菱形）。若新增像素位置是青(8)墙壁，则灰(5)覆盖墙壁。若新增像素位置是黑(0)走廊，则灰(5)填入该走廊格。
2. 从红(2)种子像素出发，在膨胀后的迷宫中执行 BFS 洪泛填充。填充目标是所有通过 4-连通走廊（黑(0)像素）可达的格子。填充颜色按 BFS 步数（从种子出发的最短路径长度）的奇偶性决定：奇数步填绿(3)，偶数步（不含种子本身）填黄(4)。
3. 种子像素保持红(2)不变。
4. 因菱形膨胀而变得不可达的走廊格子保持黑(0)。
5. 青(8)墙壁和灰(5)菱形像素不变（已被灰色覆盖的原墙壁位置显示为灰色）。

**关键洞察**：菱形膨胀本身不是最终变换的目标——它是一个拓扑修改操作，通过阻断走廊来改变后续洪泛填充的可达集。求解者必须先执行膨胀以确定哪些走廊被封锁，然后在新拓扑上计算路径距离。仅看膨胀结果或仅看填充结果都无法还原完整逻辑。

## 新题 4：隐藏图像提取后按精灵体像素数平铺并叠印

**组合逻辑**：[提取](已有：行列乘积法提取隐藏子图) → [计数](创新：精灵体前景像素数编码平铺份数) → [平铺](创新：平铺单元来自提取结果) + [透明叠加](创新：计数源同时充当叠加印章)

**来源原语**：提取(extract, #b71a7747), 行列乘积完整(row_col_product, #b71a7747), 双色图像(bicolor_image, #b71a7747), 平铺(tile, #91413438), 计数(counting, #91413438), 像素数定尺寸数(pixel_count_sets_size_copies, #91413438), 精灵体(sprite, #91413438 / #845d6e51), 透明叠加(transparent_overlay, #e133d23d), 对齐(alignment, #e133d23d)

**依赖链**：行列乘积法确定隐藏子图 → 提取得到平铺单元 → 精灵体前景像素计数确定平铺份数 → 平铺生成重复排列 → 精灵体自身作为印章透明叠加到每份副本中心。精灵体同时承担"计数器"和"印章"双重角色，任一功能被跳过都导致输出错误。

从网格中提取隐藏的双色子图，将其按小精灵体的前景像素数平铺，再把精灵体本身叠印到每份副本的中心。

**输入结构**：约 14x14 的网格。网格中混合了多种颜色的像素。其中恰好存在一对颜色（如红(2)和蓝(1)），其像素占据了它们所在行和所在列的完整笛卡尔积——即删除不含这两种颜色的行和列后，剩余子网格的每个格子都是这两种颜色之一。其他颜色为填充物或分隔符。另外，网格的某个角落区域（不与双色图像区域重叠）包含一个 3x3 的小精灵体：该精灵体由黑(0)背景和一种非双色图像颜色的前景色（如绿(3)）组成，前景像素为 2-4 个，形成一个 4-连通图形。生成约束：提取的双色子图至少为 4x4（确保精灵体能居中叠加），精灵体前景像素数 F 满足 2 <= F <= 4。

**规则**：
1. 找到唯一的颜色对，使其像素恰好覆盖其活跃行与活跃列的完整笛卡尔积。保留这些行和列，提取出 MxN 的双色子网格。
2. 定位 3x3 精灵体，计算其前景（非黑色）像素数 F。
3. 将提取的 MxN 子网格水平排列 F 份，形成 Mx(N*F) 的输出网格。
4. 在每份 MxN 副本的中心位置叠加 3x3 精灵体：精灵体的中心像素对齐到副本的中心像素（行 M//2，列 N//2 处）。叠加时黑(0)像素透明（不改变底层），前景像素覆盖底层。
5. 输出仅包含平铺+叠加后的 Mx(N*F) 网格，不包含原网格的其他部分。

**关键洞察**：精灵体在此题中扮演双重角色——其前景像素的数量决定了平铺份数，其形状本身作为印章叠加到每份副本上。求解者需要从多个示例中归纳出"像素计数 = 副本数"和"精灵体 = 叠加模板"这两个同时成立的规则，任一规则单独都无法解释所有示例。

## 新题 5：轴对齐连线与触发点垂直射线分割区域

**组合逻辑**：[连线](创新：从对角线对齐改为轴对齐像素对的连线) → [射线延伸](创新：触发像素在连线上发射垂直方向的射线) → [填充](创新：射线和连线共同分割空间，区域面积决定填充色)

**来源原语**：连线(connect, #db695cfb), 射线延伸(ray_extend, #db695cfb), 触发像素(trigger_pixel, #db695cfb), 触发点分束(trigger_splits_beam, #db695cfb), 填充(fill, #44d8ac46 / #c0f76784), 面积决定填充色(area_determines_fill_color, #c0f76784), 封闭区域(enclosed_region, #44d8ac46 / #c0f76784)

**依赖链**：连线生成水平/垂直线段 → 触发像素在线段上发射垂直射线 → 线段和射线共同构成分割边界 → 分割后的区域面积决定每个区域的填充颜色。射线的位置取决于触发像素在连线上的坐标，移动触发像素会改变所有相邻区域的面积和颜色。

将轴对齐的同色像素对连线，线上的触发像素发射垂直射线，线段与射线将网格分割为区域，按区域面积着色。

**输入结构**：约 20x20 的橙(7)背景网格。网格上有 2-4 对蓝(1)像素，每对中的两个像素位于同一行或同一列（轴对齐），对之间不共享行或列。品红(6)触发像素分布在各像素对之间的连线路径上（即在同行的两个蓝像素之间的某列，或同列的两个蓝像素之间的某行）。每条连线上有 1-2 个触发像素。生成约束：蓝像素对的连线互不交叉；所有线段和射线共同将网格分割为至少 4 个 4-连通区域。

**规则**：
1. 对每对蓝(1)像素，画一条蓝(1)直线段连接它们（水平对画水平线，垂直对画垂直线），包含端点。
2. 对每个品红(6)触发像素：若它位于水平蓝线段上，则向上和向下各发射一条垂直的品红(6)射线，延伸到网格边界为止；若它位于垂直蓝线段上，则向左和向右各发射一条水平的品红(6)射线，延伸到网格边界为止。射线像素覆盖路径上的橙(7)背景像素；若射线穿过另一条蓝线段，射线在该蓝像素处停止（不包含该蓝像素，不覆盖蓝色）。
3. 蓝(1)线段和品红(6)射线共同构成分割边界。找到所有由非边界像素（橙(7)）构成的 4-连通区域。
4. 对每个区域，计算其面积（像素数）。面积 <= 12 的区域填充红(2)；面积 13-35 的区域填充绿(3)；面积 > 35 的区域填充黄(4)。
5. 蓝(1)线段和品红(6)射线像素在输出中保持不变。

**关键洞察**：触发像素是"分束器"——它将一条连线的分割能力扩展到垂直方向，从而将简单的线性分割变为网格状分割。面积阈值的具体数值需要对比多个示例才能归纳。一个触发像素位置的微小变化会同时改变多个相邻区域的面积和颜色。

## 新题 6：连通分量筛选决定旋转拼接的边框宽度

**组合逻辑**：[连通检测](已有) → [筛选](创新：连通分量唯一性既用于过滤内容又用于计算几何参数) → [旋转](已有) + [拼接](创新：边框宽度由筛选阶段的副产物决定)

**来源原语**：连通检测(connected_component_detection, #3194b014), 筛选(filtering, #3194b014), 唯一连通分量(unique_component, #3194b014), 忽略干扰项(ignore_distractors, #3194b014), 旋转(rotate, #412b6263), 拼接(concatenate, #412b6263), 边框(frame, #412b6263), 副本堆叠(copy_stacking, #412b6263)

**依赖链**：连通分量检测识别干扰色与有效色 → 筛选擦除干扰色像素（改变内容）→ 同时，有效色的数量 K 作为边框宽度参数 → 旋转清理后的网格生成四份副本 → 以宽度 K 的边框拼接四份旋转副本。K 同时控制内容（哪些颜色保留）和几何（边框多宽），这是单一分析步骤的双重输出。

统计每种前景色的 4-连通分量数，保留恰好只有一个分量的颜色并擦除其余，用保留颜色的种类数作为旋转四拼图的边框宽度。

**输入结构**：约 8x8 的黑(0)背景网格。网格中有 3-5 种非黑前景色，每种颜色由若干像素组成。部分颜色的像素形成恰好 1 个 4-连通分量（"有效色"），其余颜色的像素碎片化为多个分量（"干扰色"）。生成约束：有效色数量 K 满足 1 <= K <= 3；干扰色至少 1 种；每种有效色的分量像素数至少为 3。

**规则**：
1. 对每种非黑(0)颜色，计算其 4-连通分量的数量。
2. 保留恰好只有 1 个 4-连通分量的颜色（有效色），将所有干扰色（分量数 > 1）的像素擦除为黑(0)。记清理后的网格为 G'。
3. 记有效色的种类数为 K。
4. 将 G' 分别旋转 0、90、180、270 度（顺时针），生成四份副本。
5. 将四份副本排列为 2x2 布局：左上 = 0 度，右上 = 90 度，左下 = 270 度，右下 = 180 度。在四份副本之间和外围添加宽度为 K 像素的灰(5)边框/分隔带。输出网格尺寸为 (2*8 + 3*K) x (2*8 + 3*K)，即 (16+3K) x (16+3K)。
6. 边框全部填灰(5)，副本区域填入对应旋转后的 G' 内容。

**关键洞察**：连通分量分析的输出具有双重角色——它既决定哪些颜色被保留（内容过滤），又通过有效色的数量 K 决定边框的几何尺寸。求解者需要同时归纳出"单分量 = 保留"的过滤规则和"有效色数 = 边框宽度"的几何规则，两者来自同一个分析但作用于完全不同的维度。

## 新题 7：障碍条件分支的滑动轨迹与条形复制

**组合逻辑**：[滑动](已有) → [条件分支：障碍 vs 条形接触](创新：同一滑动操作的终止原因触发完全不同的后续处理) → [复制](条件激活) + [重涂色](条件选择)

**来源原语**：滑动(sliding, #56dc2b01), 接触停止(contact_stop, #56dc2b01), 条形障碍(bar_obstacle, #56dc2b01), 碰触后对侧放副本(touch_copy_opposite, #56dc2b01), 复制(copy, #56dc2b01), 重涂色(recolor, #56dc2b01), 路径奇偶交替涂色(alternating_color_by_path_parity, #b782dc8a)

**依赖链**：滑动方向由对象与条形的相对位置决定 → 滑动过程中是否遇到障碍决定分支：遇障碍则擦除障碍 + 对象变色 + 轨迹纯色；未遇障碍则对象保色 + 生成条形副本 + 轨迹交替涂色。分支结果影响输出中的三个独立方面（对象颜色、轨迹图案、是否有副本），且只有理解分支条件才能统一解释所有示例。

将绿色对象沿基本方向向红色条形滑动；若被灰色障碍拦截则擦除障碍、对象变色、轨迹纯色；若无障碍触达条形则保色、放置条形青色副本、轨迹交替着色。

**输入结构**：约 15x15 的黑(0)背景网格。包含以下元素：一个绿(3)小对象（4-连通，3-6 像素），一个红(2)水平或垂直条形（1 像素宽，4-8 像素长），以及 0-2 个灰(5)单像素障碍。绿对象和红条形沿某个基本方向（上/下/左/右）对齐，即沿该方向平移绿对象可以使其到达红条形。灰障碍如果存在，位于绿对象与红条形之间沿滑动方向的路径上（即障碍像素所在行/列与绿对象在滑动方向上的投影有交集）。生成约束：部分示例有障碍，部分示例无障碍，以展示两个分支。

**规则**：
1. 确定滑动方向：从绿(3)对象指向红(2)条形的基本方向（取对象边界框中心到条形边界框中心的主轴方向）。
2. 沿该方向逐像素平移绿对象。若对象的前沿碰到灰(5)障碍像素（即平移后对象的某个像素与障碍像素重合）：
   a. 对象停在碰撞前的最后合法位置。
   b. 擦除所有灰(5)障碍像素（置为黑(0)）。
   c. 将停止位置的对象重涂为青(8)。
   d. 对象从起始位置到停止位置之间经过的空格（对象不再占据的原始位置 + 滑动路径上的空格）全部填黄(4)。
3. 若对象前沿碰到红(2)条形（无障碍阻挡）：
   a. 对象停在紧贴条形的位置，保持绿(3)。
   b. 在对象的另一侧（远离条形的方向），放置一份红条形的副本，颜色改为青(8)，与对象紧贴（副本位置与对象之间无间隙，对称于条形-对象的接触方式）。
   c. 对象从起始位置到停止位置之间经过的空格按步数奇偶交替填色：第一个空格（离起始位置最近）填黄(4)，第二个填橙(7)，第三个填黄(4)，依此类推。
4. 红(2)条形始终保持原位不变。

**关键洞察**：同一个滑动操作因终止条件不同（碰障碍 vs 碰条形）而分裂为两个完全不同的后处理分支。求解者不能把两种情况当作不同的题目——必须识别出"障碍的存在与否"是唯一的分支判据，统一解释所有示例中轨迹颜色模式、对象颜色和副本有无的差异。

## 新题 8：像素放大后涌现封闭区域并按计数着色

**组合逻辑**：[像素放大](创新：放大不是最终变换，而是为后续检测创造条件) → [连通检测](创新：检测的是放大涌现出的封闭区域) → [计数](创新：封闭区域总数决定填充规则的选择) → [填充](创新：填充规则本身由计数结果参数化)

**来源原语**：像素放大(pixel_upscale, #9172f3a0), 每像素扩展为色块(each_pixel_expanded_to_block, #9172f3a0), 填充(fill, #44d8ac46 / #c0f76784), 封闭区域(enclosed_region, #44d8ac46 / #c0f76784), 面积决定填充色(area_determines_fill_color, #c0f76784), 连通检测(connected_component_detection, #3194b014), 内部包含(containment, #44d8ac46)

**依赖链**：像素放大将每个像素扩展为 3x3 色块 → 在放大后的网格中，原本不相邻的有色像素可能形成连续边界，涌现出放大前不存在的封闭区域 → 检测并计数这些封闭区域 → 区域总数 E 决定采用哪套填充颜色规则 → 按规则填充每个封闭区域。放大是检测的前提，计数是规则选择的前提，三层依赖不可跳步。

将小网格像素放大 3 倍，检测放大后涌现的封闭黑色区域，按区域总数选择填充规则，按面积着色。

**输入结构**：一个 4x4 或 5x5 的网格，包含黑(0)背景和 2-3 种非黑色前景色的像素。前景像素在原始分辨率下不一定形成封闭边界，但在 3 倍放大后（每个像素变为 3x3 同色块），扩展后的色块之间可以形成完整的封闭围栏，将部分黑(0)区域完全包围。生成约束：放大后至少存在 1 个、至多 4 个被前景色块完全包围的黑(0) 4-连通区域（不接触放大后网格的边界）。

**规则**：
1. 将输入网格进行 3 倍最近邻放大：输入位置 (r, c) 的颜色复制到输出的 (3r..3r+2, 3c..3c+2) 区域，形成一个 (3H)x(3W) 的网格。
2. 在放大后的网格中，找到所有由黑(0)像素构成的 4-连通区域。将不接触网格边界的区域标记为"封闭区域"。
3. 计算封闭区域的总数 E。
4. 按 E 选择填充规则：
   - E = 1：将该唯一封闭区域填充为红(2)。
   - E = 2：面积较大的封闭区域填红(2)，较小的填蓝(1)。面积相同时，边界框左上角行号较小的填红(2)。
   - E >= 3：所有封闭区域统一填充为绿(3)。
5. 接触网格边界的黑(0)区域和所有前景色块保持不变。

**关键洞察**：原始小网格中的像素排列看似简单，但 3 倍放大后几何关系质变——不相邻的像素变为相邻的色块，可能围出新的封闭区域。求解者必须先在脑中执行放大，才能看到这些涌现的封闭结构。此外，填充规则不是固定的——它由封闭区域的总数参数化，需要对比包含不同 E 值的示例才能完整归纳。

## 新题 9：对称补全与菱形收缩的交叉空间分类

**组合逻辑**：[对称补全](创新：补全改变精灵体的空间范围，影响后续分类) + [收缩](创新：收缩改变分类边界，而非改变被分类对象) → [空间分类](创新：分类结果取决于两个独立几何变换后的交叉关系) → [重涂色/擦除](条件执行)

**来源原语**：对称补全(symmetric_complete, #e8686506), 镜像对称(mirror_symmetry, #e8686506), 碎片(fragment, #e8686506), 收缩(shrink, #d753a70b), 菱形轮廓(diamond_outline, #d753a70b), 半径微调(radius_adjust, #d753a70b), 重涂色(recolor, #845d6e51 / #56dc2b01), 擦除(erase, #917bccba), 内部包含(containment, #44d8ac46), 包围(enclosure, #c0f76784)

**依赖链**：对称补全扩展精灵体的空间占用 → 收缩减小菱形的内部区域 → 每个补全后精灵体与收缩后菱形内部的空间关系决定其类别（完全内部 / 完全外部 / 跨越边界）→ 类别决定重涂色或擦除。两个独立的几何变换（补全和收缩）各自改变交叉判定的一方，任一变换被跳过都会导致分类结果不同。

对散布的半对称精灵体做镜像补全，同时将菱形轮廓收缩一层，然后根据补全后精灵体与收缩后菱形内部的包含关系做三类处理。

**输入结构**：约 21x21 的黑(0)背景网格。网格中心附近有一个红(2)曼哈顿菱形轮廓（1 像素厚，半径 5-7），菱形完整可见（不被网格边界裁剪）。网格上散布 4-6 个灰(5)精灵体，每个精灵体具有左右镜像对称性，但右半部分被部分擦除（1-3 个像素被置为黑(0)），使精灵体看起来不完整。精灵体的完整形态（补全后）为 3-7 像素的 4-连通图形。精灵体分布在菱形内部、外部和边界附近。生成约束：补全后，至少 1 个精灵体完全位于收缩后菱形内部，至少 1 个完全位于外部，至少 1 个跨越收缩后菱形边界（部分像素在内，部分在外）。注意：补全前某精灵体可能完全在收缩后菱形内部，但补全后新增像素可能超出边界，改变其分类。

**规则**：
1. 对每个灰(5)精灵体执行左右镜像补全：找到精灵体的垂直对称轴（完整左半部分的镜像轴），将左半部分的像素镜像复制到右半部分缺失的位置，补全为完整的左右对称图形。新增像素也为灰(5)。
2. 将红(2)菱形轮廓收缩一层：保持相同中心，半径减 1。原轮廓像素中属于新半径轮廓的保留为红(2)，不属于新轮廓的原像素擦除为黑(0)。收缩后菱形的"内部"定义为：到菱形中心的曼哈顿距离严格小于新半径的所有像素位置。
3. 对每个补全后的精灵体，判断其与收缩后菱形内部区域的空间关系：
   - 完全内部（精灵体所有像素都在菱形内部区域内）：将精灵体重涂为蓝(1)。
   - 完全外部（精灵体所有像素都不在菱形内部区域内，也不在菱形轮廓上）：将精灵体重涂为绿(3)。
   - 跨越边界（精灵体的部分像素在内部，部分在外部或轮廓上）：将该精灵体完全擦除为黑(0)。
4. 收缩后的红(2)菱形轮廓保持不变。所有黑(0)背景保持不变。

**关键洞察**：两个独立的几何变换——精灵体的对称补全（扩大对象）和菱形的收缩（缩小参考边界）——从相反方向改变空间包含关系的判定结果。一个补全前看似在菱形内部的精灵体，补全后可能因新增像素超出了收缩后的较小菱形范围而变为"跨越边界"类，从而被擦除而非重涂色。求解者必须同时执行两个变换后才能正确分类。
