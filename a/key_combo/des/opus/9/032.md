## 新题 1：镜像补全母题充当射线障碍

**组合逻辑**：[镜像/mirror](宽高比决定轴向) + [射线延伸/ray_extend](从边缘标记向内投射) + [重涂色/recolor](创新：射线终止于镜像像素时吸收射线颜色)

**来源原语**：镜像(18419cfa) + 宽高比决定镜像轴(18419cfa) + 射线延伸(1f0c79e5/891232d6) + 边缘标记(891232d6) + 矩形框架(18419cfa) + 内部母题(18419cfa) + 重涂色(09c534e7)

**依赖链**：镜像补全在框架内生成新的前景像素 → 这些新像素改变了射线的行进路径和终止位置 → 射线终止于镜像像素时触发特殊重涂色规则（原始母题像素则正常阻挡射线）。删除镜像步骤，射线路径完全不同；删除射线步骤，镜像像素与原始像素无法区分。

将矩形框架内的不对称母题按框架宽高比镜像补全，然后从网格边缘标记发射射线，射线遇到镜像生成的像素时将其吸收为射线颜色，遇到原始母题像素时正常停止。

**输入结构**：约 15x20 的黑(0)背景网格。网格中散布 2~4 个灰(5)矩形框架（边框宽 1 像素，内部尺寸 3x5 至 5x7 不等，部分宽大于高、部分高大于宽）。每个框架内部有一个红(2)不对称小图形（3~5 像素，4-连通，位于框架内的一侧——宽框架中偏左或偏右，高框架中偏上或偏下）。网格的四条外边缘上（不在任何框架内）散布 3~6 个单像素标记，颜色取自蓝(1)、绿(3)、黄(4)，每个标记位于某条边缘的不同位置。生成约束：各框架互不相邻（边界框间距至少 2 格）；每个边缘标记沿其投射方向至少能到达一个框架。

**规则**：
1. 对每个灰(5)矩形框架，判断其内部区域的宽高比：宽 > 高则以垂直中轴做左右镜像，高 > 宽则以水平中轴做上下镜像，宽 = 高则以垂直中轴做左右镜像。将框架内原有红(2)母题像素关于该轴镜像，镜像副本涂为橙(7)。原始红(2)像素保留不变。
2. 从每个边缘标记出发，沿垂直于该边缘的方向向网格内部逐格投射一条射线，射线颜色与标记颜色相同。射线经过的每个空白（黑(0)）格涂为该标记颜色。
3. 射线前进时遇到的第一个非黑(0)像素为终止像素。射线在终止像素前一格停止（不覆盖终止像素），但有一个例外：若终止像素为橙(7)（镜像生成的像素），则该橙(7)像素被重涂为射线的标记颜色，射线仍在其前一格停止。若终止像素为灰(5)框架边框或红(2)原始母题像素，则不做任何重涂。
4. 若射线在到达对面边缘前未遇到任何非黑像素，则整条路径正常涂色直到边缘。
5. 多条射线可能经过同一个空白格或击中同一个橙(7)像素。空白格：后投射的射线覆盖先投射的颜色（处理顺序：先处理上边缘的标记从左到右，再右边缘从上到下，再下边缘从右到左，再左边缘从下到上）。橙(7)像素：第一条命中的射线将其重涂，之后该像素视为已重涂的非橙颜色，后续射线正常停止于其前一格。

**关键洞察**：镜像生成的橙(7)像素和原始红(2)像素对射线的阻挡行为不同——橙像素会被射线"吸收"并变色，而红像素只是静默阻挡；这使得框架的宽高比（决定镜像轴）间接控制了射线在哪些位置发生颜色覆写。

## 新题 2：嵌套深度驱动剪切与重涂色

**组合逻辑**：[规范化/canonicalize → 包含树/containment_tree](提取嵌套深度) + [剪切变换/shear_transform](创新：剪切量由嵌套深度决定) + [重涂色/recolor](深度映射颜色) + [擦除/erase](移除框架)

**来源原语**：规范化+包含树(2d0172a1) + 剪切变换+偏移随行距增(423a55dc) + 重涂色+尺寸分类(aedd82e4) + 擦除(edcc2ff0)

**依赖链**：包含树确定每个精灵体的嵌套深度 → 深度同时决定剪切量和输出颜色（双输出属性）→ 框架在剪切过程中充当裁剪边界，剪切完成后被擦除。删除包含树分析则无法确定剪切量和颜色；删除剪切则深度信息无几何表达；删除框架擦除则输出包含多余结构。

根据嵌套框架层次确定每个内部精灵体的深度，对精灵体施加深度倍数的剪切变换并按深度重涂色，最后移除所有框架只留精灵体。

**输入结构**：约 20x20 的黑(0)背景网格。2~3 层嵌套的灰(5)矩形框架（边框宽 1 像素），最外层框架约 16x16，中层约 10x10，最内层约 6x6。每层框架内（在该层与下一层之间的空间）放置 1~2 个小型单色精灵体（4-连通，3~6 像素，形状各异——有的像不规则团块，有的像弯折线段）。每个精灵体使用不同颜色（取自红(2)、绿(3)、黄(4)、橙(7)、品红(6)），各精灵体间互不接触。生成约束：最深层不超过 3 层；每个精灵体的边界框完全在其直接所属层内；嵌套框架严格居中或近似居中。

**规则**：
1. 构建包含树：最外层框架深度为 1，被深度 d 框架直接包围的框架或精灵体深度为 d+1。
2. 对每个精灵体，以其最底行为锚点行，对其每个像素 (r, c) 施加剪切变换：新位置为 (r, c - depth * (bottom - r))，其中 depth 是该精灵体的嵌套深度，bottom 是该精灵体最底行的行号。
3. 若剪切后的像素位置超出该精灵体直接所属框架的内部区域，则裁剪掉（不绘制）。
4. 将剪切后的精灵体重涂色：深度 2 → 蓝(1)，深度 3 → 红(2)，深度 4 → 绿(3)。深度 1 的精灵体（在最外层框架内但不在任何子框架内）保持原色。
5. 擦除所有灰(5)框架边框像素（设为黑(0)），输出仅保留剪切并重涂色后的精灵体。

**关键洞察**：嵌套深度是一个不可直接观测的拓扑属性，它同时控制两个独立的输出维度——几何形变（剪切倍数）和颜色映射；框架在剪切过程中是必要的裁剪边界，但最终被擦除，属于"用后即弃"的辅助结构。

## 新题 3：指示条匹配计数筛选点对称反射

**组合逻辑**：[计数/counting](统计各色物体数) ↔ [条长等于物体计数/bar_equals_count](创新：反转为"条长作为期望值，计数作为实际值"进行匹配筛选) → [擦除/erase](移除未通过的物体) → [点对称补全/point_symmetry](仅对通过物体执行)

**来源原语**：计数+指示条+标记色筛选(edcc2ff0) + 点对称+中心标记(e729b7be) + 擦除(edcc2ff0/a680ac02)

**依赖链**：计数得到各色物体实际数量 → 与指示条长度比较筛选"合格色" → 合格色的物体被保留并做点对称反射，不合格色的物体被擦除 → 指示条本身也根据筛选结果更新。删除计数则无法确定哪些颜色通过筛选；删除点对称则通过筛选的物体无变换输出；删除擦除则不合格物体仍存在干扰输出。

统计左半区各色物体数量，只有数量与顶部指示条长度匹配的颜色通过筛选，通过的物体绕中心标记做 180 度旋转映射到右半区，其余物体被擦除。

**输入结构**：约 15x17 的黑(0)背景网格。第 0 行为指示条区域：从第 0 列开始有 2~4 条水平色条，每条占一行（若多条则占第 0~3 行），颜色各不相同（取自蓝(1)、绿(3)、黄(4)、橙(7)），每条长度 1~4 格。指示条下方为主区域。主区域中央有一条黄(4)垂直分隔线从第一个非指示条行延伸到底部。分隔线正中位置有一个红(2)中心标记像素（替换该位置的黄像素）。分隔线左侧散布 4~8 个小型 4-连通物体（每个 2~5 像素），颜色与指示条颜色对应，每种颜色 1~4 个物体。分隔线右侧为空（全黑）。生成约束：至少有一种颜色的物体数量与其指示条长度相等，至少有一种不相等；各物体互不接触且不接触分隔线。

**规则**：
1. 对每种出现在指示条中的颜色，统计分隔线左侧该颜色的 4-连通物体数量。
2. 若该颜色的物体数量恰好等于其指示条的长度（像素数），则该颜色"通过筛选"。
3. 将所有未通过筛选的颜色的物体像素设为黑(0)（擦除）。
4. 对每个通过筛选的物体中的每个像素 (r, c)，计算其关于红(2)中心标记 (cr, cc) 的 180 度旋转位置 (2*cr - r, 2*cc - c)，在该位置涂上与原物体相同的颜色。原物体像素保留不变。
5. 在指示条区域中，将未通过筛选的颜色对应的条擦除（设为黑(0)）。通过筛选的条保持不变。
6. 分隔线和中心标记保持不变。

**关键洞察**：指示条不是对物体数量的描述（如参考题 edcc2ff0 中的计数摘要），而是反转为"期望值"——只有实际物体数量恰好匹配条长的颜色才通过筛选参与反射；这层比较逻辑需要对比多个示例才能归纳。

## 新题 4：种子射线远程指定分量内部涂色源

**组合逻辑**：[射线延伸/ray_extend](对角线方向由红角控制) → [标记在分量内/marker_inside_component](射线命中建立"远程锚定"关系) → [重涂色/recolor](创新：内部涂色源不是分量自身的标记，而是命中它的种子的颜色)

**来源原语**：射线延伸+种子块+角位控制射线(1f0c79e5) + 连通分量+单点标记+实心内部+邻域全包含(09c534e7) + 重涂色(09c534e7)

**依赖链**：种子的红角位置决定射线方向 → 射线方向决定命中哪个分量（空间选择）→ 被命中的分量的内部涂色源来自种子而非分量自身的标记 → 未被命中的分量则使用自身标记涂色（默认行为）。删除射线则无法建立种子-分量对应关系；删除内部检测则无法确定涂色区域；两条规则的涂色源不同，缺一不可。

从 2x2 种子块沿红角指定的对角线发射射线，射线命中的大型连通分量的内部区域被涂为种子颜色，未被命中的分量使用自身标记颜色。

**输入结构**：约 20x20 的黑(0)背景网格。网格中有 2~3 个 2x2 种子块，每个种子块中 3 个像素为同色（取自蓝(1)、绿(3)、黄(4)中的一种，各种子颜色不同），1 个像素为红(2)且位于四个角之一。另有 3~5 个较大的单色 4-连通分量（每个 12~30 像素，颜色为灰(5)），形状不规则（包含宽厚区域和窄路径），每个分量内部恰好包含一个不同颜色的单点标记像素（取自品红(6)、橙(7)、青(8)中的一种）。生成约束：每个种子块的对角射线方向上恰好有一个灰色分量可被命中（射线沿对角方向延伸 2x2 区域直到其任一像素接触灰色分量）；不同种子命中不同分量；至少有一个灰色分量不被任何种子命中。

**规则**：
1. 对每个 2x2 种子块，识别红(2)像素所在的角位：左上角→射线方向为左上对角（行-1, 列-1），右上角→右上对角（行-1, 列+1），左下角→左下对角（行+1, 列-1），右下角→右下对角（行+1, 列+1）。
2. 将种子块中的红(2)像素替换为该种子的非红颜色。
3. 沿射线方向，从种子块的对应角开始，每次行列各移动一步，检查该位置是否与某个灰(5)分量的像素重合。第一个重合的分量即为该种子"命中"的目标分量。射线本身不绘制任何痕迹。
4. 对每个灰(5)分量，检测其"厚实内部"像素：一个分量像素的 3x3 邻域（8 个邻居）全部属于同一分量时，该像素为内部像素。
5. 被种子命中的分量：将其内部像素重涂为命中它的种子的非红颜色。分量边缘和路径像素保持灰(5)。
6. 未被任何种子命中的分量：将其内部像素重涂为该分量自身单点标记的颜色。分量边缘和路径像素保持灰(5)。标记像素本身保持其原色。

**关键洞察**：分量自身的标记颜色是"默认涂色源"，但种子的对角射线可以从远处"劫持"一个分量的内部涂色权——被命中的分量用种子颜色而非自身标记颜色填充内部；必须同时理解射线命中机制和双源涂色规则。

## 新题 5：镜像补全后像素量竞争决定间隙填充

**组合逻辑**：[镜像/mirror](宽高比决定轴向) → [填充/fill](创新：间隙区域的填充色由相邻两侧补全后的像素数量比较决定) ← [行列跨度重叠/row_span_overlap + 无遮挡才填充/fill_if_unobstructed]

**来源原语**：镜像+宽高比决定镜像轴+内部母题(18419cfa) + 填充+行列跨度重叠+间隙区域+无遮挡才填充(ef135b50) + 矩形框架(18419cfa)

**依赖链**：镜像补全改变每个框架内母题的像素总数 → 间隙填充的优先色取决于两侧框架补全后在共享行跨度内的像素数量比较 → 由于不同框架的宽高比不同导致镜像轴不同，两个相同大小的原始母题补全后可能产生不同的像素分布，从而改变竞争结果。删除镜像则像素数量不变，竞争结果不同；删除填充则镜像无后续效应。

将多个矩形框架内的母题按各自宽高比镜像补全，然后在行跨度重叠且无遮挡的框架对之间的间隙区域填充"像素更多方"的母题颜色。

**输入结构**：约 18x18 的黑(0)背景网格。3~5 个矩形框架，边框颜色为灰(5)，边框宽 1 像素，内部尺寸从 3x5 到 6x4 不等（有的宽大于高，有的高大于宽）。每个框架内部有一个不对称的单色母题（3~6 像素，4-连通），各框架的母题颜色不同（取自蓝(1)、红(2)、绿(3)、黄(4)、橙(7)）。母题偏向框架内的一侧。框架水平排列，彼此之间有 2~5 列的间隙。生成约束：至少存在两对框架的行跨度有重叠（重叠至少 2 行）；不存在第三个框架的边界框同时穿越某一对框架之间的间隙和共享行跨度。

**规则**：
1. 对每个框架，判断内部区域宽高比并镜像补全母题：宽 > 高则垂直中轴左右镜像，高 > 宽则水平中轴上下镜像，宽 = 高则垂直中轴左右镜像。镜像副本使用与原始母题相同的颜色。
2. 对每一对框架 (A, B)，若它们的列跨度不重叠且行跨度有重叠，计算共享行跨度（两者行范围的交集）。
3. 检查间隙区域是否"无遮挡"：A 与 B 之间的列范围内、共享行跨度内，不存在第三个框架的边界框像素。若有遮挡则跳过该对。
4. 对无遮挡的框架对 (A, B)，统计 A 在共享行跨度内的补全后母题像素数 countA，以及 B 在共享行跨度内的补全后母题像素数 countB。
5. 将 A 与 B 之间的间隙矩形（列范围：A 右边框+1 到 B 左边框-1，行范围：共享行跨度）填充为像素更多方的母题颜色。若 countA = countB，则填充为栗(9)。
6. 所有原始框架边框、母题像素和镜像像素保持不变。

**关键洞察**：镜像轴方向（由框架宽高比决定）间接影响间隙的填充色——一个宽框架做左右镜像可能在共享行跨度内增加更多像素，而一个高框架做上下镜像可能在不同行跨度上增加像素；因此相同原始母题在不同形状的框架中会产生不同的竞争力。

## 新题 6：孤立像素激活精灵模板交换

**组合逻辑**：[尺寸分类/size_classification](区分精灵与孤立像素) → [图案替换/pattern_swap](创新：仅被孤立像素"激活"的精灵参与交换) + [重涂色/recolor](孤立像素变为交换后的新颜色) + [同步替换/simultaneous_replacement]

**来源原语**：图案替换+精灵模板+同步替换+同尺寸边界框+按颜色区分模板(3391f8c0) + 重涂色+孤立像素+尺寸分类+单像素分量重涂(aedd82e4) + 连通分量(09c534e7)

**依赖链**：尺寸分类区分精灵（>1 像素）和孤立像素（1 像素）→ 孤立像素的空间邻近关系决定哪些精灵被"激活" → 仅激活的精灵参与模板交换 → 交换后孤立像素也跟随变色。删除尺寸分类则无法识别激活标记；删除交换则激活机制无效；删除同步约束则结果取决于处理顺序。

两种颜色的精灵副本散布在网格中，但只有边界框附近存在孤立单像素的精灵才参与模板交换，未被激活的精灵保持原样。

**输入结构**：约 16x16 的黑(0)背景网格。恰好两种前景颜色（如蓝(1)和绿(3)），每种颜色形成 2~4 个同一模板的精灵副本（4-连通，4~8 像素，边界框大小两种颜色相同，如 3x3）。精灵副本之间互不接触且边界框不重叠。部分精灵的边界框外 1~2 格曼哈顿距离处有同色的孤立单像素（恰好 1 个像素的 4-连通分量）。不是所有精灵都有相邻孤立像素——每种颜色至少有一个精灵没有、至少有一个有。生成约束：孤立像素到其最近精灵边界框的曼哈顿距离不超过 2 格；一个孤立像素只与一个精灵关联（不处于两个精灵的 2 格范围交集中）。

**规则**：
1. 检测所有 4-连通分量，按像素数分为精灵（>1 像素）和孤立像素（=1 像素）。
2. 对每个精灵，检查是否存在同色孤立像素其曼哈顿距离到该精灵边界框 ≤ 2。若存在，该精灵被标记为"已激活"。
3. 所有已激活的精灵同步执行模板交换：在各自的边界框位置，用另一种颜色的模板形状绘制，颜色也换为另一种颜色。同步意味着先清除所有已激活精灵的边界框区域为黑(0)，然后在每个位置绘制替换模板。
4. 未激活的精灵保持原样不变。
5. 每个激活孤立像素被重涂为交换后的新颜色（即另一种前景色）。未关联到任何精灵的孤立像素（距离所有精灵边界框 > 2）保持原色不变。

**关键洞察**：孤立像素看起来像噪声，实际是选择性激活开关——只有被"标记"的精灵参与交换，产生局部而非全局的模板互换；同步约束确保两个已激活精灵相互交换时不会出现顺序依赖。

## 新题 7：对称恢复揭示隐藏种子的射线方向

**组合逻辑**：[补全/completion](平移对称恢复被遮挡区域) → [射线延伸/ray_extend](创新：恢复后才能看到完整的种子块及其红角方向) + [裁剪/crop](输出仅为原遮挡区域)

**来源原语**：补全+平移对称图案+遮挡矩形+对称轨道+对称恢复遮挡(f9012d9b) + 射线延伸+种子块+角位控制射线+对角方向(1f0c79e5) + 裁剪(f9012d9b/2d0172a1)

**依赖链**：对称恢复填补被遮挡的像素 → 恢复出的像素中包含部分或完整的 2x2 种子块（含红角方向信息）→ 从这些种子块发射对角射线 → 射线仅在原遮挡区域内绘制（裁剪到遮挡范围）。删除对称恢复则种子块不完整、方向不可知；删除射线则恢复后无额外变换；删除裁剪则输出包含无关区域。

在平移对称图案中，黑色遮挡矩形覆盖了部分种子块；先用对称性恢复被遮挡的图案（包括隐藏的种子），再从完整种子发射对角射线，最后裁剪输出为遮挡区域。

**输入结构**：约 16x16 的网格，无真正背景色，由 3~4 种颜色（取自蓝(1)、绿(3)、黄(4)、灰(5)）构成的平移重复图案填充整个网格。图案的最小平移周期约 4x4 至 6x6。在图案的特定重复位置上嵌入 2x2 种子块：种子块的 3 个像素融入图案颜色（与周围图案像素一致），1 个像素为红(2)，位于四角之一。整个网格中有 2~4 个这样的种子块（在不同的重复单元中）。一个黑(0)矩形（约 5x5 至 8x8）遮挡了网格的某个区域，该矩形覆盖了至少一个种子块的部分或全部。生成约束：至少一个种子块被完全遮挡或其红角被遮挡（使得不恢复就无法确定方向）；遮挡区域外至少有一个完整可见的种子块（提供种子的存在线索）；平移对称周期与种子位置兼容。

**规则**：
1. 将黑(0)像素视为遮挡掩膜。忽略黑像素，检测剩余像素的平移对称性（最小平移向量）。
2. 对每个黑(0)像素，从其对称轨道中找到一个非黑的等价像素，用该像素的颜色填充。
3. 恢复完成后，在整个网格中扫描所有 2x2 区域，找出恰好包含 1 个红(2)像素和 3 个非红同色像素的块，这些是种子块。
4. 对每个种子块，根据红角位置确定对角射线方向（同新题 4 规则 1），将红像素替换为种子的非红颜色，然后沿对角方向逐步绘制 2x2 同色方块直到超出网格边界。射线像素覆盖原有图案像素。
5. 裁剪输出：仅保留原始黑色遮挡矩形所覆盖区域的内容（恢复 + 射线叠加后的结果）。

**关键洞察**：遮挡不仅隐藏了图案，还隐藏了种子块的存在和方向信息；只有先完成对称恢复，才能发现哪些 2x2 块是种子以及射线应该朝哪个方向发射——恢复步骤是射线步骤的信息前提而非简单的数据传递。

## 新题 8：空心框架过滤后按边长填色再排序拼接

**组合逻辑**：[擦除/erase](忽略实心干扰项) + [填充/fill](创新：按边长映射内部填充色) + [排序/sorting + 拼接/concatenate](按边长排列)

**来源原语**：擦除+空心矩形+实心方块+仅保留空心对象+忽略干扰项(a680ac02) + 填充+按边长映射颜色+标记在框内居中(00dbd492) + 排序+拼接+沿主轴排列(a680ac02)

**依赖链**：干扰项过滤确定哪些框架参与后续处理 → 框架边长同时决定填充颜色和排序位置（双输出属性）→ 填充后的框架按边长排序拼接为条带。删除过滤则干扰项混入；删除填充则排序后的框架无内部色彩区分；删除排序则布局无序。

从混合的空心框架和实心方块中过滤出空心框架，根据边长映射颜色填充内部，保留居中标记，然后按边长从小到大排列为水平条带。

**输入结构**：约 20x15 的黑(0)背景网格。散布 5~8 个单色正方形物体（边长 4~8 像素），颜色均为灰(5)。其中部分是空心正方形框架（边框宽 1 像素，内部为黑），部分是实心正方形（全部填满）。每个空心框架的几何中心位置有一个红(2)标记像素（若边长为偶数，标记在中心偏左上的位置）。实心方块内无标记。物体间互不接触，边界框不重叠。生成约束：空心框架至少 3 个，边长至少有两种不同值；实心方块至少 2 个；不同边长的空心框架数量不超过 5 种。

**规则**：
1. 检测所有灰(5) 4-连通分量。判断每个分量是空心框架（内部有黑像素洞且包含红(2)标记）还是实心方块（无内部洞且无红标记）。
2. 丢弃所有实心方块（不出现在输出中）。
3. 对每个空心框架，测量其外边长 S，根据 S 填充内部空白区域（边框内的非红非灰像素位置）：S=4 → 蓝(1)，S=5 → 青(8)，S=6 → 黄(4)，S=7 → 橙(7)，S=8 → 品红(6)。灰(5)边框和红(2)标记保持不变。
4. 将所有填充后的空心框架按外边长从小到大排序。边长相同时，按原始位置列坐标从小到大排序（列坐标指边界框左上角的列号）。
5. 将排序后的框架从左到右紧密拼接为一行水平条带（相邻框架边框共用），输出网格的高度等于最大框架的边长，较小框架顶部对齐，底部以黑(0)填充至等高。

**关键洞察**：实心方块是形状匹配的干扰项，必须通过内部洞检测（而非颜色或大小）来区分；空心框架的边长是唯一的关键属性，同时决定了内部填充色和排列顺序——两个本质不同的输出维度由同一个输入特征驱动。

## 新题 9：格子通道连线后按列压缩堆叠

**组合逻辑**：[连线/connect](同色端点沿格子行/列连接) → [压缩/compress](创新：连线产生的新像素改变各列的像素计数，压缩至底部边缘) + [重涂色/recolor](压缩后黄色标记变绿)

**来源原语**：连线+格子瓦片+端点标记+同行列对齐+同色同子格位置(a096bf4d) + 压缩+通道+压缩至远端边界(05a7bcf2) + 重涂色(05a7bcf2/aedd82e4)

**依赖链**：端点连线在格子中添加新像素 → 新像素改变每列通道内的非背景像素总数 → 压缩将每列的所有非背景像素堆叠到底部 → 堆叠后特定颜色（黄）被重涂（绿）。删除连线则像素数不变、压缩结果不同；删除压缩则连线像素保持在原位无堆叠效果；删除重涂则无法区分原始端点与连线产生的填充。

在格子瓦片中完成同色端点的行列连线，然后将每列瓦片通道中的所有非背景像素压缩堆叠到底部，最后将堆叠中的黄色像素重涂为绿色。

**输入结构**：约 17x17 的网格。灰(5)分隔线将网格划分为 4x4 的瓦片阵列（每个瓦片 3x3 内部 + 1 像素分隔线，即瓦片含分隔线后为 4x4 周期）。瓦片内部 3x3 区域以黑(0)为底。部分瓦片的 3x3 内部特定子格位置（如左上、右下等 9 个子格之一）有彩色端点标记（取自蓝(1)、红(2)、橙(7)），每种颜色恰好出现 2~3 次。另有部分瓦片的内部散布 1~2 个黄(4)像素（位于随机子格位置）。生成约束：同色端点中至少有一对共享瓦片行或瓦片列；黄像素不出现在端点标记所在的子格位置；每列瓦片至少有一个非背景像素。

**规则**：
1. 将同色端点标记按子格位置分组。在同一组内，若两个端点共享瓦片行（在同一行瓦片中），则在它们之间所有中间瓦片的相同子格位置填充该颜色。若共享瓦片列（在同一列瓦片中），同理纵向填充。若一组有 3 个端点，两两之间若满足共行或共列条件均连线。
2. 连线完成后，对每一列像素（pixel column，非瓦片列），收集该列中所有非灰(5)、非黑(0)的像素（即端点标记、连线填充、黄色像素），记录它们的颜色。忽略灰(5)分隔线像素。
3. 清空该列中所有非灰像素位置为黑(0)。
4. 从该列的最底部非灰行开始，向上依次放置收集到的像素（保持收集时从上到下的颜色顺序，但堆叠到底部），即最上面收集到的颜色放在堆叠的最上面位置。灰(5)分隔线行跳过（不放置、不计数），像素只放在非分隔线行上。
5. 堆叠完成后，将所有黄(4)像素重涂为绿(3)。

**关键洞察**：水平方向的连线操作增加了垂直通道中的像素数量，导致压缩后的堆叠高度改变——连线是"横向"操作，但其效果通过压缩"纵向"地体现出来，创造了跨维度的因果链。

## 新题 10：印章轨迹碰撞计数生成指示条

**组合逻辑**：[印章覆盖/stamp](沿方向标记重复印制精灵) + [计数/counting](创新：统计碰撞格数而非物体数) → [指示条/indicator_bar](碰撞计数编码为条长) + [重涂色/recolor](碰撞区域特殊着色)

**来源原语**：印章覆盖+方向指示+标记指示放置侧(760b3cac) + 计数+指示条+条长等于物体计数(edcc2ff0) + 重涂色(09c534e7/aedd82e4) + 精灵体(760b3cac)

**依赖链**：方向标记决定印章轨迹方向 → 各精灵的轨迹在空间中展开 → 轨迹间的碰撞（同一像素被多个轨迹覆盖）产生碰撞区域 → 碰撞格数被统计并编码为顶部指示条长度 → 碰撞区域本身被重涂为特殊颜色。删除印章则无轨迹；删除碰撞检测则无法统计冲突；删除指示条则碰撞信息丢失。

多个精灵体沿各自方向标记连续印章形成轨迹带，轨迹重叠的像素被标记为碰撞并涂特殊色，每个精灵的碰撞像素数编码为顶部指示条长度。

**输入结构**：约 18x16 的黑(0)背景网格（第 0 行保留为指示条输出区，初始全黑）。第 1 行起的区域中有 3~5 个小型精灵体（每个 3~5 像素，4-连通，形状各异），颜色各不相同（取自蓝(1)、红(2)、绿(3)、黄(4)、橙(7)）。每个精灵的边界框某一条边的外侧（上、下、左或右，距边界框 1 格）有一个品红(6)方向标记像素，标记所在的边指示印章延伸方向（标记在精灵上方→向上印章，标记在右侧→向右印章，以此类推）。生成约束：精灵间互不接触；至少有两个精灵的轨迹会在空间中重叠（沿各自方向延伸时路径有交叉）；轨迹不会覆盖其他精灵的原始位置。

**规则**：
1. 对每个精灵，识别其品红(6)方向标记的位置（在精灵边界框的上/下/左/右外侧 1 格），确定印章方向。擦除品红(6)标记像素（设为黑(0)）。
2. 沿印章方向，从精灵的边界框边缘开始，每隔精灵边界框在该方向上的尺寸（即紧密排列，无间隙），重复印制精灵模板的完整副本，直到副本的任一像素超出网格边界（第 1 行到底部的区域）为止。每个副本使用精灵的原始颜色。所有精灵的印章同时展开（先计算所有轨迹，再处理碰撞）。
3. 碰撞检测：一个像素位置若被两个或更多不同精灵的轨迹（含原始精灵）覆盖，则为碰撞像素。将碰撞像素涂为栗(9)，覆盖原有颜色。
4. 非碰撞像素保持其轨迹颜色。若一个像素仅被一个精灵的轨迹覆盖，保持该精灵颜色。
5. 对每个精灵，统计其轨迹中涉及碰撞的像素总数（即：该精灵的原始位置或印章副本中，有多少像素位置最终变成了栗(9)）。
6. 在第 0 行生成指示条：对每个精灵，从第 0 列开始、在该精灵对应的行（按精灵原始位置的列坐标从小到大排序，第一个精灵在第 0 行第 0 列起绘制）——由于只有一行空间，改为：在第 0 行中，按精灵原始边界框左上角列坐标从小到大的顺序，依次放置各精灵颜色的水平色条，每条长度等于该精灵的碰撞像素数；相邻两条之间空 1 格黑(0)。若碰撞数为 0 则不绘制该颜色的条。

**关键洞察**：方向标记不仅决定印章的几何轨迹，还间接决定了哪些精灵会发生碰撞——两个精灵只有轨迹在空间中交叉才产生碰撞像素；碰撞计数既在网格内以颜色变化体现（栗色），又在指示条中以长度编码，形成双通道信息表达。
