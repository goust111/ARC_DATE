## 新题 1：重力落种同心扩展

**组合逻辑**：[重力下落](创新：落点决定扩展中心) + [同心层填充](创新：多源扩展竞争) + [冲突优先级](创新：切比雪夫距离最近者胜)

**来源原语**：重力下落(963c33f8), 障碍物(963c33f8), 同心层填充(9356391f), 种子像素(9356391f), 切比雪夫距离索引(9356391f), 色板行(9356391f), 分隔行(9356391f), 冲突优先级(c92b942c)

**依赖链**：障碍物的空间分布决定种子像素的落点位置 → 落点位置决定同心扩展的中心坐标 → 多个扩展中心同时生长时，切比雪夫距离提供冲突仲裁 → 色板行提供距离到颜色的映射。重力模拟与同心填充之间存在不可跳过的位置传递：不完成重力计算就无法确定环心，不确定环心就无法判断距离冲突。

将悬浮的彩色种子像素在障碍物约束下自由下落，以各自落点为圆心用色板行进行切比雪夫距离同心环扩展，多环碰撞时距离更近的种子获得该像素。

**输入结构**：约 16x16 网格，黑(0)背景。第 0 行为色板行：从左边缘起连续排列若干非黑像素，颜色各异，作为距离 d=0,1,2,...的调色板（色板内可包含黑(0)像素表示该距离环为背景色）。第 1 行为灰(5)分隔行（整行灰色）。第 2 行至最后一行为工作区域：散布若干灰(5)障碍像素（单独散落，不形成连通大块），以及 2-4 个彩色种子像素（颜色均与色板行第 0 项 palette[0] 相同），种子像素悬浮在空中（其正下方至少有一行为空或有障碍物）。生成约束：任意两个种子不在同一列；每个种子正下方至少存在一个灰障碍像素或底边。

**规则**：
1. 保留色板行、分隔行和所有灰(5)障碍像素不变。
2. 每个种子像素从其初始位置竖直下落：逐行向下移动，在遇到的第一个灰障碍像素的正上方一格停止；若该列无障碍像素，则落在工作区域最底行。种子原始位置清除为背景。
3. 读取色板行：从第 0 行左边缘开始，依次读取像素颜色，直到遇到第一个处于色板最右侧非黑项之后的位置为止，得到调色板序列 palette[0], palette[1], ...。
4. 以每个落定种子为中心，对工作区域中的每个背景像素计算到该种子的切比雪夫距离 d。若 d < len(palette)，该像素候选颜色为 palette[d]。
5. 多源冲突解决：若某像素处于多个种子的扩展范围内，取切比雪夫距离最小的种子的候选颜色。距离相等时，取种子所在列号较小的种子的颜色。
6. 同心环不覆盖灰障碍像素和分隔行。距离 d 处若 palette[d] 为黑(0)，该环位置保持背景不变。

**关键洞察**：种子的最终位置完全由其下方障碍物的分布决定，而非由其初始位置决定。同一组障碍物在不同列有不同的"地形高度"，导致种子落在不同高度，进而使同心环图案在竖直方向错位、在水平方向交错。求解者必须先完成重力模拟才能确定环心，再处理多源环的空间竞争。

## 新题 2：镜像拓扑变色

**组合逻辑**：[镜像](创新：镜像合并改变拓扑) + [洪泛填充/连通分量检测](创新：在合并形状上检测孔洞) + [孔洞数映射颜色](创新：拓扑属性而非几何属性决定重涂色)

**来源原语**：镜像(ad3b40cf), 对称轴(ad3b40cf), 沿轴反射(ad3b40cf), 洪泛填充(543a7ed5), 封闭区域(543a7ed5, e3721c99), 孔洞数映射颜色(e3721c99), 颜色图例(e3721c99), 连通分量检测(84db8fc4)

**依赖链**：镜像操作改变了形状的拓扑结构（原始形状无孔洞或少孔洞，合并后可能产生新孔洞） → 孔洞数量需要在合并后的形状上重新计算 → 孔洞数映射到图例颜色完成重涂色。关键耦合在于：镜像不只是几何复制，它与原始形状的并集创造了新的拓扑属性，而这个新属性才是决定颜色的依据。

将灰色精灵体沿蓝色轴线镜像后，统计原始与镜像合并体的封闭孔洞数，按图例将合并体整体重涂为对应颜色。

**输入结构**：约 15x15 网格，黑(0)背景。一条竖直的蓝(1)像素线贯穿网格中央列（从第 0 行到最后一行，整列为蓝色），作为反射轴。轴线左侧分布 2-4 个灰(5)精灵体（4-连通，各 4-8 像素，形状不规则且不对称，各精灵体互不接触，不触碰轴线，且与轴线之间至少间隔 1 列背景）。精灵体的设计使得部分精灵体镜像合并后会产生新的封闭孔洞（如 C 形镜像后闭合成 O 形），部分则不会（如线性形状镜像后仍无孔洞）。网格右下角区域放置 2-3 个小型彩色图例形状（非灰、非蓝、非黑的颜色，各图例颜色不同，如红(2)、绿(3)、黄(4)），每个图例形状自身具有不同数量的封闭孔洞（分别为 0、1、2 个孔洞），且图例形状互不接触、不触碰网格外边界。生成约束：灰精灵体的镜像位置不与图例形状重叠；各灰精灵体合并后的孔洞数均能在图例中找到对应。

**规则**：
1. 保留蓝(1)轴线和所有图例形状不变。
2. 将每个灰(5)精灵体沿蓝色轴线做左右镜像反射，在轴线右侧对应位置绘制灰(5)镜像副本。
3. 对每个灰精灵体，取其原始像素与镜像像素的并集，作为一个合并形状。
4. 在合并形状上检测封闭孔洞：以 4-连通方式从网格边界对背景像素做洪泛填充，合并形状内部无法被该洪泛到达的背景连通区域即为孔洞。统计每个合并形状的孔洞数。
5. 查阅图例映射：找到孔洞数与该合并形状相同的图例形状，读取其颜色。
6. 将合并形状的所有像素（原始 + 镜像）重涂为对应图例颜色。

**关键洞察**：单独看左侧的灰精灵体可能没有孔洞，但镜像后与自身合并会"闭合"出新的封闭空间。求解者必须先在脑中完成镜像操作并构建合并体，然后才能判断拓扑变化（孔洞数增减），最后才能确定颜色。仅看原始形状的几何外观无法直接得出答案。

## 新题 3：控制色分支——填充或射线

**组合逻辑**：[控制色定行为](创新：同类对象因控制像素不同而执行完全不同的操作) + [洪泛填充](已有) + [射线延伸](创新：从被擦除对象的控制位置发射) + [擦除](创新：擦除是射线操作的前置步骤)

**来源原语**：控制像素(ddf7fa4f, 963c33f8), 控制色定行为(963c33f8), 穿透或停靠(963c33f8), 洪泛填充(543a7ed5), 封闭区域(543a7ed5), 射线延伸(b942fd60, 45bbe264), 擦除(f76d97a5, e3721c99), 前景形状(543a7ed5)

**依赖链**：控制像素颜色决定操作分支 → 蓝控制触发内部孔洞填充（形状保留并增强） → 栗控制触发形状擦除 + 从控制位置发射十字射线 → 处理顺序产生交互：先执行填充使被填充的形状成为实体，再执行射线时射线会被这些实体阻挡。删除任一分支，另一分支的空间结果都会改变。

根据橙色精灵体内部控制像素的颜色（蓝或栗），对蓝控制的精灵体填充孔洞，对栗控制的精灵体擦除后从其位置发射红色十字射线，射线被已填充的实体阻挡。

**输入结构**：约 15x18 网格，黑(0)背景。分布 4-6 个橙(7)精灵体（4-连通，各 6-12 像素，部分含有 1-2 个封闭背景孔洞，部分无孔洞）。每个精灵体内部恰有一个控制像素：蓝(1)或栗(9)，替代该位置原本的橙色像素。网格左边缘第 0 列某一行有一个红(2)单像素。生成约束：含蓝控制的精灵体至少有 1 个封闭孔洞；含栗控制的精灵体可有可无孔洞；各精灵体互不接触且不触碰网格边界；红像素不在任何精灵体内部；至少有一个栗控制精灵体的控制像素与某个蓝控制精灵体处于同行或同列。

**规则**：
1. 识别每个橙(7)精灵体及其内部的控制像素颜色。
2. **第一阶段——填充**：对每个蓝(1)控制的精灵体，找出其封闭的背景孔洞（4-连通背景区域被该精灵体的橙像素完全包围），将孔洞像素填充为黄(4)。精灵体的橙像素和蓝控制像素保持不变。
3. **第二阶段——擦除与射线**：对每个栗(9)控制的精灵体，将其所有橙像素和栗控制像素擦除为背景黑(0)。记录栗控制像素原来所在的位置(r, c)。
4. 从每个被擦除的栗控制位置(r, c)向上、下、左、右四个方向发射红(2)射线。每条射线逐像素延伸，将经过的背景像素涂为红(2)，直到遇到第一个非背景像素或到达网格边缘时停止（不覆盖该非背景像素）。
5. 网格左边缘的原始红(2)像素向右发射一条水平红射线，规则同上。
6. 处理顺序固定为先第一阶段后第二阶段。若第二阶段的射线经过第一阶段已填充的黄色区域，射线在黄色像素前停止。

**关键洞察**：两种操作之间存在空间因果依赖——填充操作将孔洞变为实体，改变了射线的传播环境。如果交换处理顺序（先射线后填充），射线会穿过孔洞而非被阻挡，结果完全不同。求解者需要通过对比示例发现处理顺序，而非仅理解各分支的独立规则。

## 新题 4：重建框架计数房间排序同心重绘

**组合逻辑**：[重建](已有) + [计数](创新：统计重建后的封闭房间数) + [排序](创新：按房间数排列) + [重绘](创新：以同心方框形式输出排序结果) + [忽略干扰项](已有)

**来源原语**：重建(89565ca0), 分隔框架(89565ca0), 封闭区域(89565ca0), 忽略干扰项(89565ca0, e3721c99), 区域数映射长度(89565ca0), 排序(89565ca0, c920a713), 同心方框(c920a713), 重绘(c920a713)

**依赖链**：噪声干扰 → 需要重建墙壁才能正确计数 → 房间数量决定排序 → 排序结果决定同心嵌套顺序 → 同心框的几何结构由排序后的颜色数决定。每个阶段的输出是下一阶段不可替代的输入：不重建则计数错误，不计数则无排序依据，不排序则无嵌套顺序。

将被噪声损坏的多色分隔框架重建后，按各框架封闭房间数从少到多排序，输出为同心嵌套方框（最外层为房间最少者，最内层为房间最多者）。

**输入结构**：约 20x20 网格，黑(0)背景。3-5 种非黑颜色各绘制一个轴对齐的矩形分隔框架（1 像素宽的矩形外框加若干水平或竖直内部隔墙，将框内分为 1-4 个背景房间）。各框架可部分重叠。另有一种散布的噪声颜色（非黑，与所有框架颜色不同），其像素随机散落在网格各处，覆盖部分框架像素造成损坏。生成约束：每个真实框架颜色在其完整矩形边框和隔墙上至少有 60% 的像素存活（未被噪声覆盖）；不同框架的房间数互不相等；噪声颜色的像素在做直线段重建后不封闭任何背景区域。

**规则**：
1. 识别噪声颜色：对每种非背景颜色，尝试用密集行/列证据进行直线墙壁重建（若某行或某列中该颜色像素数量占该行/列在其边界框范围内长度的 50% 以上，则该行/列段为一面墙）。重建后不封闭任何背景区域的颜色即为噪声色。
2. 擦除所有噪声颜色像素。
3. 对每种非噪声颜色，用上述重建规则恢复完整的矩形外框和内部隔墙。
4. 在每种颜色的重建框架中，统计被墙壁完全封闭的 4-连通背景区域数量（即房间数）。
5. 按房间数从小到大排序各颜色。若房间数相等（生成约束保证不会发生），以重建边界框面积较小者排前。
6. 生成输出网格：尺寸为 (2N-1) x (2N-1)，其中 N 为非噪声框架颜色数。以排序后第 1 种颜色（房间最少）画最外层 1 像素宽方框，第 2 种颜色画次外层，以此类推，最内层为房间最多的颜色。各层同心嵌套，中心为单像素。

**关键洞察**：噪声不仅遮盖了颜色像素，还可能伪造出看似合理的墙壁段——求解者必须通过密度阈值判断哪些线段是真实墙壁的残留、哪些是噪声恰好排成的直线。房间数这一拓扑特征对噪声具有鲁棒性（重建后稳定），因此是可靠的排序依据。

## 新题 5：完整方块角标驱动对角印章

**组合逻辑**：[标记](创新：标记结果改变印章精灵体的边界框尺寸) + [完整方块才标记](已有) + [印章覆盖](创新：印章精灵体包含标记像素) + [对角偏移重复](已有) + [裁剪](已有)

**来源原语**：标记(14b8e18c), 完整方块(14b8e18c), 角外像素(14b8e18c), 角点邻接(14b8e18c), 完整方块才标记(14b8e18c), 印章覆盖(e619ca6e), 对角偏移重复(e619ca6e), 裁剪(e619ca6e)

**依赖链**：完整方块检测确定哪些对象参与后续操作 → 角标标记扩大了对象的有效边界框 → 扩大后的边界框尺寸(h', w')成为对角印章的步幅 → 步幅改变导致印章间距与原始方块尺寸不同。标记操作不是装饰性的，它实质性地修改了后续印章操作的参数。

检测前景中的完整方块并标记其角外像素，再将"方块+角标"作为整体精灵体沿两条对角线方向反复印章，非完整形状不参与印章。

**输入结构**：约 16x16 网格，黑(0)背景。分布 3-5 个绿(3)前景对象（4-连通单色）：其中 1-3 个是完整方块（边界框为正方形，且边界框边缘所有位置都有绿色像素，即填满的正方形或正方形框），其余为非方形条状或不规则碎片。各对象互不接触，周围至少有 2 行/列的空白间距。完整方块的尺寸在 2x2 到 4x4 之间。生成约束：完整方块的位置保证沿对角方向至少能放下 2 个完整副本再超出网格。

**规则**：
1. 保留所有输入对象不变（包括非完整形状）。
2. 识别每个完整方块：4-连通绿(3)对象，其边界框为正方形且边界框一像素宽的边框上所有位置均为绿色。
3. 对每个完整方块，在其四个角的正外侧各标记 2 个红(2)像素——即角像素正交方向（上下或左右）相邻的两个背景位置。具体地：对于方块左上角像素(r,c)，标记(r-1,c)和(r,c-1)；右上角像素(r,c')，标记(r-1,c')和(r,c'+1)；左下角像素(r',c)，标记(r'+1,c)和(r',c-1)；右下角像素(r',c')，标记(r'+1,c')和(r',c'+1)。若标记位置超出网格则跳过。
4. 将每个完整方块及其 8 个红色角标作为一个复合精灵体，计算该复合体的边界框高度 h' 和宽度 w'（方块本身为 s x s 则 h' = s+2, w' = s+2）。
5. 沿两条对角线方向反复印章：从方块原始位置出发，在偏移量 (+h', +w'), (+2h', +2w'), ... 和 (+h', -w'), (+2h', -2w'), ... 处放置复合精灵体的副本，直到副本完全超出网格。超出网格边界的部分裁剪丢弃。
6. 印章副本不覆盖已有的非背景像素（包括原始的绿色对象和其他方块的印章）。若副本的某个像素位置已被占据，该像素跳过不绘制。

**关键洞察**：角标使复合精灵体的边界框比方块本身每边大 1 像素，因此对角印章的步幅为 (s+2, s+2) 而非 (s, s)。不同大小的方块产生不同的步幅，它们的印章轨迹在网格上可能交错。如果忽略角标直接用方块做印章，结果会明显不同——这迫使求解者理解标记操作对后续步幅的影响。

## 新题 6：射线网格分区的边界可达性着色

**组合逻辑**：[射线延伸](创新：射线构造网格线而非信号传播) + [行列交叉](创新：交叉点标红后射线成为分区边界) + [连通分量检测](创新：在射线网格的间隙中检测区域) + [拓扑分类](创新：按边界可达性分类着色)

**来源原语**：射线延伸(45bbe264), 行列交叉(45bbe264), 标记像素(45bbe264), 异源交叉特殊着色(45bbe264), 边界可达性(84db8fc4), 拓扑分类(84db8fc4), 重涂色(84db8fc4), 连通分量检测(84db8fc4), 连通区域(84db8fc4), 网格边界(84db8fc4)

**依赖链**：标记像素的位置决定射线的行列 → 射线交叉点被标红 → 射线 + 交叉点将网格分割为若干矩形背景区域 → 区域是否接触网格外边界决定其分类 → 分类结果决定重涂颜色。标记像素的数量和位置同时影响分区数量和各区域的边界可达性——增减一个标记会同时改变两个层面。

将散布的彩色标记像素的整行整列涂为引导线，交叉点涂红，然后将被引导线分割出的背景矩形区域按是否触碰网格外边界分别涂为绿色或灰色。

**输入结构**：约 14x14 网格，黑(0)背景。3-5 个孤立的彩色标记像素（每个标记颜色不同，颜色从蓝(1)、黄(4)、橙(7)、青(8)、品红(6)中选取，不使用红(2)、绿(3)、灰(5)）。任意两个标记不在同一行也不在同一列。标记不在网格边界行/列上（即行号和列号都不为 0 或最大值）。

**规则**：
1. 对每个标记像素，将其所在整行和整列的所有背景像素涂为该标记的颜色。
2. 保留原始标记像素的颜色不变。
3. 当某个位置同时处于两个不同标记的行线和列线交叉处时，将该位置涂为红(2)。注意：标记像素本身虽处于自己的行列交叉处，但保持原色不变。
4. 步骤 1-3 完成后，网格中的彩色线条和红色交叉点将黑(0)背景分割成若干 4-连通的矩形区域。
5. 对每个背景矩形区域进行分类：若该区域中任何像素位于网格第 0 行、最后一行、第 0 列或最后一列，则标记为"外部区域"；否则标记为"内部区域"。
6. 将所有"外部区域"的背景像素涂为绿(3)。将所有"内部区域"的背景像素涂为灰(5)。

**关键洞察**：标记像素的行列位置决定了网格被切割的方式。N 个标记（行列均不同）将网格切割成 (N+1)x(N+1) 个矩形区域。其中，位于最外一圈的 4N 个区域触碰边界（外部），内部的 (N-1)x(N-1) 个区域不触碰边界（内部）。但求解者需要从具体示例中验证这个规律，而不能仅靠公式——因为标记恰好在极端位置时可能改变计数。

## 新题 7：平铺涌现孔洞的分级填充

**组合逻辑**：[平铺](创新：无孔形状平铺后在间隙处涌现孔洞) + [描边](创新：对平铺后的形状做外轮廓以定义边界) + [洪泛填充](创新：在描边后的封闭区域中执行) + [计数](创新：按孔洞面积分级着色)

**来源原语**：平铺(c92b942c), 描边(543a7ed5), 洪泛填充(543a7ed5), 封闭区域(543a7ed5), 外部邻接区域(543a7ed5), 孔洞填色轮廓描色(543a7ed5), 计数(878187ab), 计数映射尺寸(878187ab)

**依赖链**：原始小形状无封闭孔洞 → 3x3 平铺后副本之间的间隙可能形成封闭区域 → 描边操作区分了外部轮廓与内部空隙 → 孔洞面积计数将封闭区域分为两类 → 不同面积类别对应不同填充颜色。涌现效应：单个形状不具备的拓扑特征（孔洞），在平铺后由多个副本之间的空间关系产生。

将一个无孔洞的小前景形状 3x3 平铺，在平铺画布上为前景像素描绿色外轮廓，然后将平铺间隙中涌现的封闭区域按面积分为两级，最小面积级填黄色，其余填红色。

**输入结构**：约 5x5 至 7x7 的小网格，黑(0)背景。恰有一种非黑前景颜色（如橙(7)），前景像素形成一个 4-连通的单色形状（3-6 像素），该形状无封闭孔洞（即形状的背景补集通过 4-连通可完全到达网格边界）。形状不完全填满网格（至少有 40% 的像素为背景）。生成约束：形状的设计使得 3x3 平铺后，相邻副本之间的间隙中至少存在两种不同面积的封闭背景区域（例如角落间隙较小、边缘间隙较大）。

**规则**：
1. 将输入网格在水平和竖直方向各重复 3 次，生成一个 3 倍宽、3 倍高的平铺画布（若原始网格为 H x W，画布为 3H x 3W）。
2. 在平铺画布上，识别所有橙(7)前景像素。
3. 描绿色外轮廓：将画布上每个与任意橙(7)像素 8-邻接（含对角）的背景像素标记为绿(3)。
4. 识别封闭背景区域：在画布上，从网格四边出发，对所有未被橙(7)或绿(3)占据的背景像素做 4-连通洪泛填充，标记为"可达边界"。剩余未标记的背景像素（既非前景、非轮廓、又不可达边界）形成若干 4-连通封闭区域。
5. 统计每个封闭区域的面积（像素数）。找出所有封闭区域中的最小面积值 A_min。
6. 将面积等于 A_min 的封闭区域填充为黄(4)。
7. 将面积大于 A_min 的封闭区域填充为红(2)。
8. 将步骤 4 中标记为"可达边界"的背景像素保持黑(0)不变。

**关键洞察**：原始小形状完全没有封闭孔洞，但平铺后多个副本在空间上彼此靠近，它们之间的背景间隙被四周的前景像素和轮廓围合形成新的封闭区域。不同位置的间隙（角落处四个副本汇合 vs 边缘处两个副本相邻）面积不同，由此产生分级着色。求解者必须先在脑中完成平铺，再识别涌现的封闭区域，最后按面积分级。

## 新题 8：掩码与对角印章格子的交集过滤

**组合逻辑**：[印章覆盖](创新：生成规则的对角格子图案) + [掩码决定保留](创新：不规则掩码截取格子图案的局部) + [擦除](创新：掩码和未命中像素同时清除) + [颜色替换](创新：幸存像素统一变色标记)

**来源原语**：印章覆盖(e619ca6e), 对角偏移重复(e619ca6e), 实心矩形(e619ca6e), 裁剪(e619ca6e), 掩码像素(f76d97a5), 掩码决定保留(f76d97a5), 擦除(f76d97a5), 颜色替换(f76d97a5)

**依赖链**：小矩形的尺寸决定对角印章格子的间距和覆盖位置 → 掩码形状决定哪些格子位置的像素被保留 → 两者的空间交集才是最终输出 → 颜色替换标记哪些像素通过了双重过滤。印章图案和掩码形状是两个独立输入，必须同时正确推断才能得到输出——单独理解任一个都无法预测结果。

将蓝色小矩形沿四个对角方向反复印章形成规则格子，然后仅保留与灰色掩码区域重合的印章像素并变色为红色，其余全部清除。

**输入结构**：约 15x15 网格，黑(0)背景。一个蓝(1)实心小矩形（2-3 行，2-4 列），位于网格上半部分。一个灰(5)不规则连通区域（4-连通，8-15 像素，形状不对称），位于网格中部偏下。蓝矩形与灰区域不重叠，且间隔至少 2 个像素。生成约束：蓝矩形的对角印章轨迹中至少有 3 个副本与灰掩码区域存在像素重合。

**规则**：
1. 以蓝(1)矩形为原型，设其高度为 h、宽度为 w。从矩形左上角位置出发，在四个对角方向 (+h,+w), (+h,-w), (-h,+w), (-h,-w) 及其整数倍偏移处放置矩形副本。保留原始矩形本身。
2. 超出网格边界的副本部分裁剪丢弃；完全超出的副本不绘制。
3. 所有印章副本均为蓝(1)色，形成一个规则的对角格子图案。
4. 将灰(5)掩码区域视为过滤器：遍历网格每个像素，仅当该位置同时是蓝(1)印章像素且原始输入中为灰(5)掩码像素时，该像素保留。
5. 保留的像素从蓝(1)重涂为红(2)。
6. 清除所有其他非背景像素：未保留的蓝印章像素、剩余的灰掩码像素，均设为黑(0)背景。
7. 输出：仅有红(2)像素留在黑(0)背景上。

**关键洞察**：输出是两个独立空间模式的交集——一个是由小矩形尺寸决定的严格规则对角网格，一个是输入中给定的不规则掩码形状。求解者必须先在脑中展开完整的对角格子（这需要正确提取矩形的 h 和 w 作为步幅），再将格子与掩码叠加，才能定位存活像素。单独看掩码或单独看矩形都无法预测哪些位置变红。
