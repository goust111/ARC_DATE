## 新题 1：对向泛洪的障碍阴影裁决

**组合逻辑**：[flood_fill + radiate](两个填充源对向辐射) → [gap_bisect](间隙平分作为冲突裁决) → [obstacle_casts_shadow](障碍阴影打破对称，允许对侧侵入)

**来源原语**：flood_fill / radiate / partial_enclosure / obstacle / fill_seed / opening_direction（来自 b9e38dc0）；gap_bisect / odd_gap_midline / rectangle（来自 d968ffd4）

**依赖链**：两个半封闭墙各自的泛洪填充在间隙中碰撞，由间隙平分规则裁决归属；障碍物投射的阴影使一方的填充在某些行/列上提前终止，让对方的填充越过中线侵入阴影区域，因此最终边界不是直线而是锯齿状——阴影形态反向塑造了平分的结果。

两个半封闭墙各自泛洪填充后向对方辐射，在共享间隙中碰撞；间隙按平分规则分配，但障碍阴影使局部边界偏移，输出为非直线的交错填充带。

**输入结构**：约 18x18 的网格，背景为黑(0)。网格中有两个灰(5)半封闭墙（例如 U 形或 C 形，各约 5-7 像素高、3-4 像素宽的开口壁），开口彼此面对（例如左墙开口朝右、右墙开口朝左），两墙之间有 4-8 列的黑(0)间隙。左墙内部有一个蓝(1)像素（填充种子），右墙内部有一个红(2)像素（填充种子）。间隙区域中有 1-2 个绿(3)单像素或小块（2-3 像素的 4-连通体）作为障碍物，位于间隙中不同的行上。生成约束：两墙的开口行范围完全重叠（即辐射路径在行方向上完全对齐）；障碍物不接触任何墙壁；间隙宽度至少为 4。

**规则**：
1. 分别对两个半封闭墙内部进行泛洪填充：左墙内部填蓝(1)，右墙内部填红(2)。
2. 每个填充从各自开口向对方辐射，沿水平方向（开口轴）逐列扩展到间隙中，扩展范围覆盖开口所跨的所有行。
3. 间隙平分规则：在无障碍的行上，间隙左半部分（含中点左侧）归蓝(1)，右半部分归红(2)。若间隙列数为奇数，正中列保持黑(0)。
4. 障碍阴影规则：每个障碍物向两侧各投射阴影——以障碍物所在列为中心，向左方向的阴影阻挡红(2)填充（红色在该行上不能到达障碍物左侧），向右方向的阴影阻挡蓝(1)填充（蓝色在该行上不能到达障碍物右侧）。在障碍物所在行上，被一侧阻挡而空出的格子由对侧颜色填充（但对侧自身也可能被其他障碍阻挡）。
5. 若某格同时被两侧阻挡（两个障碍分别从两侧投射阴影到该格），该格保持黑(0)。
6. 障碍物自身保持绿(3)不变。灰(5)墙壁不变。

**关键洞察**：障碍物的阴影不是简单地挡住填充——它创造了对侧可以越界侵入的真空带，使得"平分"从几何中线变成了依赖障碍布局的逐行裁决。需要对比多个示例才能归纳出阴影让对侧侵入（而非简单留空）的规则。

## 新题 2：噪声清洗后的二值掩码驱动克罗内克展开

**组合逻辑**：[erase + eight_connectivity](8-连通噪声清洗) → [kronecker_product](清洗后掩码作为外层布局) ← [panel_as_palette](调色板面板提供颜色)

**来源原语**：erase / isolated_pixel / connected_component / single_pixel_removed / eight_connectivity（来自 42a50994）；stamp_overlay / binary_mask / kronecker_product / panel_as_palette（来自 c803e39c）；color_panel（来自 c803e39c）

**依赖链**：8-连通噪声清洗改变了掩码的前景拓扑，而掩码拓扑直接决定克罗内克积输出的每一个瓦片位置，因此清洗结果与展开结果之间是乘法关系而非加法关系——一个噪声像素的存留会影响输出中一整块瓦片区域。

对一个含噪声的二值掩码做 8-连通孤立像素清除，再以清洗后掩码为外层、小色块瓦片为内层做克罗内克积展开，调色板面板指定两种输出颜色。

**输入结构**：约 20x20 的网格，背景为黑(0)。网格被两条竖直的灰(5)分隔列分成三个面板（宽度比约为 6:3:2）。左面板：在黑(0)背景上用白/灰(5)前景色构成一个二值图案，其中包含若干 8-连通簇（每簇 2-6 像素）和若干孤立前景像素（与任何其他前景像素的 8-邻域均无接触）；左面板约 6x6 至 8x8。中面板：一个 2x2 或 3x3 的小色块瓦片，由两种非黑非灰颜色（如蓝(1)和红(2)）构成的图案填满，无黑(0)像素。右面板：上下排列两个单像素，分别为黄(4)和绿(3)，它们是调色板指示器。生成约束：左面板中至少有 2 个孤立像素和至少 2 个多像素簇；中面板瓦片的行列数与左面板行列数的乘积不超过 30x30。

**规则**：
1. 对左面板中的前景像素做 8-连通标记。将所有大小为 1 的连通分量（孤立像素）替换为黑(0)，得到清洗后的二值掩码 M。
2. 以 M 为外层掩码、中面板的色块瓦片 T 为内层，执行克罗内克积展开：M 中每个前景格对应输出中一个 T 大小的块，该块内容为 T 本身；M 中每个黑(0)格对应输出中一个同尺寸的纯色块。
3. 调色板映射：T 中的第一种颜色（按 T 中从左到右、从上到下首次出现的颜色）映射为右面板上方的颜色（黄(4)），T 中的第二种颜色映射为右面板下方的颜色（绿(3)）。M 中黑(0)格对应的纯色块使用右面板下方的颜色（绿(3)）。
4. 输出尺寸 = M 的行数 x T 的行数（高）乘以 M 的列数 x T 的列数（宽）。

**关键洞察**：孤立噪声像素看似微不足道，但每个孤立像素的存留会在输出中造成一整块瓦片的差异（从纯色块变为图案块或反之），因此清洗操作对输出有放大效应。需要对比示例确认是 8-连通（而非 4-连通）以及清洗方向（删除孤立点而非保留孤立点）。

## 新题 3：包含深度决定重涂色与角标记颜色

**组合逻辑**：[containment_tree](嵌套结构分析) → [recolor](按深度赋色) → [marking + corner_adjacency](仅对完整方块做角标记，标记颜色由深度决定)

**来源原语**：nested_frame / containment_tree / topology_determines_layout（来自 2d0172a1）；recolor（来自 0d3d703e / ce9e57f2）；marking / complete_square / corner_outside_pixel / corner_adjacency / only_complete_marked（来自 14b8e18c）

**依赖链**：包含树深度同时决定两件事——框架自身的重涂色和角标记的颜色。角标记操作依赖重涂色的结果来确定标记颜色，而重涂色依赖包含树分析的结果来确定目标颜色。三者形成链式依赖：拓扑分析 → 重涂色 → 角标记颜色。同时，"完整方块"筛选条件独立于深度，与深度信息交叉决定最终输出。

分析多层嵌套框架的包含深度，按深度重涂色，然后仅对其中的完整方块框架做角外标记，标记颜色取该方块的深度颜色。

**输入结构**：约 20x20 的网格，背景为黑(0)。网格中有 4-6 个灰(5)空心框架（即矩形边框，内部为黑(0)），部分框架嵌套在其他框架内部。框架可以是正方形或长方形。嵌套深度最多 3 层（最外层深度 0，其内一层深度 1，再内一层深度 2）。同一深度可有多个并列的框架。所有框架初始均为灰(5)。生成约束：至少有 2 个框架是完整方块（边界框为正方形且所有边框格都被填满）；至少有 1 个框架是非方形矩形；嵌套的框架之间至少有 1 格间距；至少存在深度 0 和深度 1 两层。

**规则**：
1. 对所有灰(5)框架建立包含树：若框架 A 的内部区域完全包含框架 B，则 B 是 A 的子节点。最外层（不被任何框架包含）的框架深度为 0。
2. 按深度重涂色：深度 0 → 蓝(1)，深度 1 → 红(2)，深度 2 → 绿(3)。每个框架的所有像素都改为对应深度的颜色。
3. 在重涂色后的网格上，识别哪些框架是完整方块（边界框为正方形，且该正方形边框上的所有格子都被该框架的颜色填满）。
4. 对每个完整方块框架，在其四个角的外侧各画两个标记像素：每个角的外侧正交方向（上下或左右）各一个，标记颜色与该方块重涂色后的颜色相同。标记只画在背景格(黑(0))上；若该位置已有其他框架像素或超出网格，则不画。
5. 非完整方块的框架仅做重涂色，不做角标记。

**关键洞察**：角标记的颜色不是固定的红色或某个预设颜色，而是取决于该方块在包含树中的深度——同样是完整方块，外层的标蓝(1)、内层的标红(2)。求解者必须先完成拓扑分析和重涂色，才能确定标记颜色。仅看单个示例可能误以为标记颜色固定，需对比多个示例（不同深度的方块有不同标记色）才能归纳。

## 新题 4：竖直条分裂构建渗透屏障控制泛洪路径

**组合逻辑**：[recolor + equal_split](竖直条上下半分裂为两色) → [flood_fill](泛洪填充，颜色决定可穿越性) ← [partial_enclosure + opening_direction](半封闭墙定义填充区域)

**来源原语**：recolor / vertical_bar / equal_split / lower_half_recolored（来自 ce9e57f2）；flood_fill / partial_enclosure / fill_seed / opening_direction（来自 b9e38dc0）；obstacle_casts_shadow（来自 b9e38dc0，创新改造为颜色选择性阻挡）

**依赖链**：竖直条的高度决定上下分裂的位置；分裂位置决定哪些行是红色屏障、哪些行是青色可渗透段；可渗透段的位置决定泛洪填充能否穿过该条进入相邻区域。因此条的高度间接编码了区域间的连通性拓扑。

多根不同高度的红色竖直条被上下半分裂为红和青两色；泛洪填充被红色像素阻挡但可穿过青色像素，从而条的高度决定了填充能否跨越该条到达相邻封闭区域。

**输入结构**：约 15x20 的网格，背景为黑(0)。网格中有 3-4 根红(2)竖直条（每根占一列，高度各不相同，范围 4-10 像素，顶端对齐于不同行）。条与条之间有灰(5)半封闭墙形成的 U 形或 C 形围合区域（开口朝向某根竖直条）。每个围合区域内有一个彩色填充种子像素（使用蓝(1)、黄(4)、绿(3)等不同颜色，每个区域颜色不同）。竖直条恰好位于某些围合区域的开口处，充当潜在屏障。生成约束：每根竖直条至少与一个围合区域的开口相邻；围合区域的开口高度不超过对应竖直条的高度；至少有一根条足够高使得其青色段落在开口范围之外（填充无法穿越），至少有一根条足够短使得其青色段覆盖了开口的部分行（填充可部分穿越）。

**规则**：
1. 对每根红(2)竖直条做上下分裂：上方 ceil(h/2) 个像素保持红(2)，下方 floor(h/2) 个像素变为青(8)。h 为该条的像素高度。
2. 对每个半封闭区域，从其填充种子开始泛洪填充（4-连通），填充色为种子颜色。
3. 填充传播规则：填充可以覆盖黑(0)背景格；填充被灰(5)墙壁和红(2)像素阻挡（不可穿越）；填充可以穿过青(8)像素——当填充到达青(8)格时，该格被覆盖为填充色，填充继续向该格的 4-邻域传播。
4. 若两个不同颜色的填充可以到达同一个青(8)格，则先到者（种子到该格的最短 4-连通路径更短者）占据该格；若距离相同，则该格保持青(8)不变。
5. 灰(5)墙壁始终不变。

**关键洞察**：竖直条的高度看似只是视觉属性，但分裂操作将其转化为功能属性——高度决定红/青分界线的行位置，而分界线的行位置决定了哪些行上的屏障可被穿越。求解者必须逐条计算分裂位置，才能判断哪些填充路径是通的。需对比多个示例才能确认"红色阻挡、青色可穿"的规则（而非直觉上的"所有条都阻挡"或"所有条都可穿"）。

## 新题 5：对称体尺寸编码周期，修复残缺瓦片图案

**组合逻辑**：[symmetry_completion → axis_borrowed](识别对称体并提取其尺寸) → [translational_symmetry + orbit_color_restores_missing](以对称体尺寸为周期修复残缺) ← [periodic_tile](周期图案自身提供轨道颜色)

**来源原语**：symmetry_completion / symmetric_object / axis_borrowed（来自 4c5c2cf0）；inpaint / periodic_tile / translational_symmetry / orbit_color_restores_missing（来自 0dfd9992）

**依赖链**：对称体的边界框尺寸是修复周期图案的必要参数——没有它就无法确定平移向量；而平移向量错误会导致轨道匹配失败。对称体既是视觉元素又是参数编码器，求解者必须将两个角色分离。

网格中一个具有双轴镜像对称的单色物体的边界框尺寸编码了周围周期图案的平移周期；用此周期修复图案中被黑色遮挡的缺失格。

**输入结构**：约 18x18 的网格，背景为黑(0)。网格中央偏左有一个灰(5)单色物体，具有水平和垂直双轴镜像对称（如十字形、菱形、方环等，边界框约 3x3 至 5x5）。该物体周围的网格区域被一个彩色周期图案覆盖，使用 2-3 种非黑非灰颜色（如蓝(1)、红(2)、绿(3)）。该周期图案的平移周期恰好等于对称体边界框的高度 h 和宽度 w——即图案在垂直方向以 h 为周期重复，水平方向以 w 为周期重复。图案中有 5-10 个格被替换为黑(0)，表示遮挡缺失。对称体所占的格不属于周期图案（对称体"挡住"了图案的对应位置）。生成约束：每个缺失格在其平移轨道中至少有一个可见（非黑、非灰）的同轨道格；对称体的边界框尺寸在两个维度上不相等（h != w），以帮助区分两个平移方向；至少在 2 个不同的轨道上有缺失格。

**规则**：
1. 识别灰(5)物体，验证其具有水平和垂直双轴镜像对称。测量其边界框高度 h 和宽度 w。
2. 定义周期图案的平移向量为 (h, 0) 和 (0, w)。
3. 对每个黑(0)缺失格（不在对称体边界框内的），计算其在 h x w 周期单元内的位置 (r mod h, c mod w)。
4. 在所有具有相同周期位置的格中，找到非黑(0)且非灰(5)的可见格，它们应共享同一颜色。用该颜色填充缺失格。
5. 对称体自身保持灰(5)不变。对称体边界框内被图案覆盖的格不做修改。

**关键洞察**：对称体不参与周期图案，但它的尺寸是解码图案周期的唯一线索。如果误将对称体也当作图案的一部分，会得到错误的周期；如果忽略对称体的尺寸，无法确定平移向量。求解者需要对比多个示例来确认"对称体尺寸 = 图案周期"这一非显然映射。

## 新题 6：对角印章轨迹穿越分隔区域时变色

**组合逻辑**：[flood_fill + positional_ordering](按位置为分隔区域赋色) ⊕ [stamp + diag_offset_repeat + size_determines_stride](对角印章轨迹) → 轨迹格的颜色由其所在区域的填充色替换（交叉约束）

**来源原语**：flood_fill / divider_line / bounded_region / positional_ordering / position_determines_fill_color（来自 941d9a10）；stamp / solid_rect / diag_offset_repeat / size_determines_stride / clip（来自 e619ca6e）

**依赖链**：区域填充确定了每个格的区域归属色；印章轨迹的落点分布在多个区域中；落在已填充区域的印章格被强制变色为该区域色。两个操作不是先后执行——区域色影响印章外观，而印章是在区域之上绘制的。最终输出需要同时考虑区域填充和印章覆盖。

灰色分隔线将网格划分为若干区域并按位置赋色；小矩形沿对角线生成印章轨迹，轨迹格落在哪个已赋色区域就呈现该区域的颜色。

**输入结构**：约 18x18 的网格，背景为黑(0)。灰(5)水平线和竖直线将网格分割成 4-6 个矩形区域。在所有区域中，恰好有 3 个区域各包含一个单像素种子（分别为蓝(1)、红(2)、绿(3)），其余区域无种子。另外，网格上有 1-2 个小实心矩形（使用黄(4)或橙(7)，每个矩形约 2x2 或 2x3），位于某个区域内部（不跨越分隔线）。生成约束：三个种子所在区域互不相邻（不共享分隔线边界）；小矩形的对角轨迹路径至少穿过 2 个不同的已赋色区域；小矩形不与任何种子像素重叠。

**规则**：
1. 对每个含种子的区域做泛洪填充，将该区域所有黑(0)背景格填为种子颜色。填充不穿越灰(5)分隔线。种子像素本身也保持其颜色。无种子的区域保持黑(0)。
2. 灰(5)分隔线保持不变。
3. 对每个小实心矩形（高 h、宽 w），以该矩形为起始位置，沿左下对角方向（偏移 (+h, -w)）和右下对角方向（偏移 (+h, +w)）重复印章，直到整个印章完全超出网格。超出网格的部分裁剪丢弃。
4. 印章格的颜色规则：若该格位于一个已填充区域内（非黑非灰），则该印章格呈现该区域的填充色（覆盖矩形原色）；若该格位于黑(0)未填充区域或恰好在灰(5)分隔线上，则该印章格保持矩形的原始颜色。
5. 原始小矩形自身保持不变（不受区域填充影响，始终保持原色）。
6. 多个印章格重叠时，后生成的覆盖先生成的（按先左下方向、再右下方向、从近到远的顺序）。

**关键洞察**：对角轨迹是"探针"——同一条轨迹上的印章格可能穿越多个不同颜色的区域，每个格呈现其所在区域的颜色，使得轨迹变成一串变色的色块序列。求解者必须同时理解区域填充规则和印章轨迹规则，二者缺一不可。需对比示例确认印章在已填充区域上变色（而非覆盖区域色或被区域色阻挡）。

## 新题 7：计数选面板 + 周期修复图案 + 镜像校正后嵌入

**组合逻辑**：[counting + max_marker_panel](红色标记计数选目标面板) ⊕ [inpaint + translational_symmetry](修复残缺图案) → [mirror + color_match + mismatch_flip](边色匹配校正) → [crop](嵌入并裁剪输出)

**来源原语**：counting / rect_panel / marker_pixel / marker_in_panel / max_marker_panel（来自 e50d258f）；inpaint / periodic_tile / translational_symmetry / orbit_color_restores_missing（来自 0dfd9992）；mirror / motif / color_match / mismatch_flip（来自 846bdb03）；crop（来自 e50d258f / 846bdb03）

**依赖链**：计数操作选定目标面板（决定输出框架和边色参考）；周期修复操作恢复图案完整形态（不修复就无法判断边色）；镜像校正依赖已修复图案的边色与已选定面板的边色比对结果。三条独立分析线（计数、修复、校正）必须汇合才能确定输出。

多个面板中按红色标记数选出目标面板；一个残缺的双色周期图案被修复后，根据其边色与目标面板侧边色的匹配情况决定是否镜像翻转，最终嵌入面板输出。

**输入结构**：约 20x15 的网格，背景为黑(0)。网格中有 3 个矩形面板（每个约 5x5 至 7x7），各由一种主色（如蓝(1)、绿(3)、黄(4)）填充的实心矩形，面板之间用黑(0)背景隔开。每个面板内部嵌有若干红(2)标记像素（数量不同：如 2 个、4 个、3 个）和若干橙(7)标记像素。每个面板的左右两条竖边（最左列和最右列）各用不同颜色——左边和右边的颜色在面板间不同。在网格下方或右侧，有一个独立的双色矩形图案块（尺寸恰好可嵌入最多红标记面板的内部），使用与面板侧边相同的两种颜色。该图案块中有 2-4 个格被黑(0)替代（遮挡）。图案块具有平移周期性（至少沿一个轴方向）。生成约束：恰好一个面板的红(2)标记数严格最多；图案块的周期至少为 2（即不是全同色）；图案块修复后其左右边色恰好是某种两色排列，与最多红标记面板的侧边色要么匹配要么恰好左右相反。

**规则**：
1. 统计每个面板内部红(2)标记像素的数量。选出红标记最多的面板作为目标面板。
2. 对独立图案块检测平移对称性。利用可见（非黑）像素的平移轨道，恢复所有黑(0)遮挡格——每个遮挡格填入其轨道中可见格的唯一颜色。
3. 取目标面板内部区域（去掉左右侧边后的矩形区域）作为嵌入区。
4. 比较修复后图案块的左边缘主色与目标面板左侧边颜色、右边缘主色与右侧边颜色。若均匹配，直接嵌入。若左右恰好相反，先将图案块水平镜像，再嵌入。
5. 输出为目标面板的精确边界框裁剪——面板主色的竖侧边保留，图案块替换掉面板内部。

**关键洞察**：图案块被故意破坏，使得修复前无法判断其边色方向——求解者必须先完成周期修复才能做镜像判断。同时，目标面板的选择决定了边色参考标准。三步操作（选面板、修复图案、镜像校正）缺任何一步都无法得到正确输出。需对比示例区分"面板选择依据红标记而非橙标记"。

## 新题 8：完整方块筛选后按路径位移平移，非方块体充当射线障碍

**组合逻辑**：[only_complete_marked](完整方块检测，分类为"行动者") ⊕ [endpoints_encode_disp](路径端点编码位移向量) → [translate](方块平移) → [diagonal_ray](从平移后方块的角发射对角射线) ← 非方块体作为射线障碍（分类的副产物）

**来源原语**：complete_square / only_complete_marked / corner_adjacency（来自 14b8e18c）；path_endpoint / endpoints_encode_disp / diagonal_ray / hollow_frame（来自 2b9ef948）；translate（来自 25ff71a9 / 2b9ef948）

**依赖链**：完整方块检测将物体分为两类——方块（行动者）和非方块（障碍）。这一分类的两个产物分别馈入不同操作：方块接受平移和射线发射，非方块留在原位充当射线终止器。路径端点编码的位移向量应用于所有方块。分类操作的两面（通过/不通过）同时活跃，缺一则输出不完整。

检测哪些前景物体是完整方块，将它们按路径端点编码的位移向量平移，再从平移后方块的四角发射对角射线；未通过方块检测的物体留在原位，阻挡射线传播。

**输入结构**：约 18x18 的网格，背景为黑(0)。网格中有 2-3 个蓝(1)单色 4-连通前景物体，其中恰好 1-2 个是完整方块（边界框为正方形且所有边框格被蓝(1)填满，大小 3x3 或 4x4），其余为非方形物体（如 L 形、条形、不规则块，3-8 像素）。另外，网格中有一条灰(5)路径（由相邻灰(5)像素连成的 4-连通链），路径的两端各有一个红(2)像素（路径端点标识）。路径可以拐弯但两端的红(2)像素是唯一的红色像素。生成约束：位移向量（从第一个红像素到第二个红像素）使得平移后的方块不超出网格边界且不与任何非方块物体重叠；平移后方块的对角射线路径上至少有一条会遇到非方块物体；两个红(2)端点分别位于路径的两端（路径拓扑上的度为 1 的节点）。

**规则**：
1. 识别所有蓝(1) 4-连通前景物体。对每个物体判断是否为完整方块：其边界框为正方形，且该正方形边框上每个格子都是蓝(1)。
2. 找到两个红(2)像素。计算从第一个红像素（行号较小者；若行号相同则列号较小者）到第二个红像素的位移向量 (dr, dc)。
3. 将每个完整方块沿 (dr, dc) 平移：原位置的蓝(1)像素变为黑(0)，新位置画上蓝(1)方块。
4. 从每个平移后方块的四个角像素出发，分别沿四个对角方向（左上、右上、左下、右下，每角一个朝外的方向）发射蓝(1)射线，逐像素延伸。
5. 射线终止条件：(a) 到达网格边界；(b) 遇到非方块的蓝(1)物体像素——射线在该像素的前一格停止（不覆盖非方块物体）。
6. 灰(5)路径和红(2)端点在输出中被擦除（变为黑(0)）——它们仅用于编码位移，不出现在输出中。
7. 非方块物体保持不变。

**关键洞察**：物体分类不是简单的筛选丢弃——未通过方块检测的物体不被丢弃，而是转变角色成为射线的障碍。同一个分类操作同时产生"行动者"和"障碍者"，两类产物在后续操作中交互。需对比示例才能确认射线遇到非方块物体时停止（而非穿过或覆盖）。
