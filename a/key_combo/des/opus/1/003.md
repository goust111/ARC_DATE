## 新题 1：端口驱动的环形接力网络

**组合逻辑**：[循环移色](创新：循环改变端口朝向而非纯视觉变换) + [射线延伸](创新：射线方向由循环后的端口位置决定) + [级联激活](创新：激活触发循环，循环改变射线方向，射线传递激活)

**来源原语**：循环移色(46c35fc7) + 射线延伸(5961cc34, 8d510a79) + 级联激活(5961cc34) + 端口编码射线(5961cc34) + 反向循环(46c35fc7) + 角与边中分组(46c35fc7)

**依赖链**：激活触发环上的角/边中双向循环 → 循环使端口像素移动到新的边中位置 → 新的端口位置决定射线发射的方向 → 射线命中另一个环则触发下一轮激活。三个操作形成闭合回路：循环改变方向，方向决定射线目标，命中触发循环。

在黑色网格上散布若干 3x3 环形对象，每个环的四个边中像素中恰好一个颜色不同（充当端口），一个起始标记激活第一个环后引发级联：每次激活使边中色逆时针旋转、角色顺时针旋转，端口移至新位置后从环中心沿新方向发射射线，射线命中下一个环则继续级联。

**输入结构**：
- 背景：黑(0)，网格约 15x15
- 散布 3-5 个 3x3 环形对象，每个环由 8 个前景像素围绕一个黑(0)中心组成
- 每个环的 4 个角位像素为统一的基底色灰(5)，4 个边中像素中有 3 个也为灰(5)，恰好 1 个边中像素为独特的"端口色"（可以是红(2)、蓝(1)、绿(3)或黄(4)中的一种，不同环的端口色可以不同）
- 端口所在的边中位置（北N/南S/东E/西W）因环而异
- 网格中有 1 个黄(4)起始标记像素，紧邻（4-连通）某个环的外侧，且位于该环端口所指方向的对侧（即起始标记在端口背面）
- 生成约束：各环的放置保证每个被激活环的射线（沿循环后端口新方向）要么命中另一个尚未激活的环，要么到达网格边界；不会有两条射线同时命中同一个环

**规则**：
1. 起始标记激活与之相邻的环，随后擦除起始标记（该像素变为黑(0)）。
2. 当一个环被激活时，依次执行：
   - a. 四个边中像素的颜色逆时针旋转一步（北→西→南→东→北），即原来北边中的颜色移到西边中，西到南，南到东，东到北。端口色随之移动到新位置。
   - b. 四个角位像素的颜色顺时针旋转一步（左上→右上→右下→左下→左上）。
   - c. 从环的中心格向端口色的**新位置方向**发射一条射线：端口在北边中则射线向上，南则向下，东则向右，西则向左。
3. 射线从中心格的相邻格开始，沿确定方向逐格延伸，将经过的黑(0)格涂为端口色。射线遇到非黑(0)像素或网格边界时停止（不包含终点处的非黑像素）。
4. 若射线到达了另一个环的 8 个像素之一，则该环在下一步被激活（执行步骤 2）。
5. 级联持续进行直到某一步没有新环被激活。已激活过的环不能被再次激活。
6. 最终输出中：被激活的环显示循环后的颜色，射线保留可见，未被激活的环保持原样。

**关键洞察**：边中像素的逆时针循环使端口移动到新的基数方向——级联路径不是由静态连线决定的，而是由每个环被激活前的端口位置和固定的循环规则共同决定。同一个网络在不同的起始环处启动会产生完全不同的级联路径。

## 新题 2：同心深度控制射线长度

**组合逻辑**：[循环填充](已有原语，用于计算深度并可视化) + [射线延伸](创新：射线长度由矩形同心深度参数化，而非固定延伸到障碍物/边界)

**来源原语**：循环填充(516b51b7) + 边距深度(516b51b7) + 射线延伸(8d510a79) + 分隔线(8d510a79) + 奇偶交替着色(516b51b7)

**依赖链**：矩形的几何尺寸决定每行的同心深度值 → 深度值参数化对应行的射线长度 → 射线能否到达分隔线取决于深度与距离的关系。矩形的形状属性（而非颜色或位置）成为射线操作的控制信号。

在网格左侧放置一个实心矩形，右侧放置一条灰色竖直分隔线，两者之间散布若干孤立彩色像素。矩形按同心深度重涂为交替色层，每个孤立像素向右发射一条射线，射线长度等于该像素所在行在矩形中的最大同心深度值。

**输入结构**：
- 背景：黑(0)，网格约 15x15
- 网格左半部分有一个实心矩形，由黄(4)像素填充，高约 5-7 格、宽约 5-7 格
- 网格右侧有一条竖直的灰(5)分隔线，宽 1 像素，从顶到底贯穿网格
- 矩形右边缘与分隔线之间有 3-5 个孤立彩色像素，颜色为红(2)或蓝(1)，每个像素占据不同的行，且该行必须与矩形的行范围有交集（即像素的行坐标落在矩形的上下边界之间，含边界）
- 孤立像素与矩形右边缘之间至少有 1 格间距
- 生成约束：矩形中心行的最大深度值不超过孤立像素与分隔线之间的距离，保证中心行的射线不会超出分隔线

**规则**：
1. 计算矩形中每个格的"同心深度"：矩形外边界上的格深度为 1，向内一层深度为 2，依此类推直到最内层。对于宽 W、高 H 的矩形，某格的深度 = min(该格到矩形四条边的距离) + 1。
2. 重涂矩形：深度 1 的格保持黄(4)不变；深度为奇数且大于 1 的格涂为红(2)；深度为偶数且大于 1 的格涂为绿(3)。
3. 对每个孤立像素，找到该像素所在行上矩形内所有格的同心深度最大值，记为 D。
4. 从每个孤立像素出发，向右画一条水平射线。射线长度恰好为 D 格（即涂色 D 个连续的格，从该像素右侧的下一格开始）。若射线会超过分隔线，则在分隔线处截断（不覆盖分隔线）。射线颜色 = 该孤立像素的颜色。
5. 若射线恰好到达分隔线的左邻格（即 D 格后的下一格就是分隔线），则将分隔线在该行的格重涂为该射线的颜色。否则分隔线保持灰(5)。

**关键洞察**：矩形中心行处同心深度最大、边缘行处深度最小，因此对齐中心行的射线最长、对齐边缘行的射线最短——射线群在空间上呈锥形扇面展开，其轮廓编码了矩形的几何形状。同心深度不再只是着色规则，而是控制另一个操作的空间参数。

## 新题 3：标记数量决定嵌套边框顺序

**组合逻辑**：[计数](已有原语) → [绘制边框](创新：边框的嵌套层级由全局计数排名决定，而非由单个标记位置决定) + [擦除](已有原语)

**来源原语**：计数(df8cc377, 37ce87bb) + 绘制边框(fc754716) + 擦除(df8cc377) + 标记色定边框色(fc754716)

**依赖链**：统计每种颜色的标记数量 → 数量排名决定颜色到嵌套层级的映射（全局排序，非局部匹配） → 按排名从外到内绘制同心边框 → 擦除所有原始标记。计数结果不是直接选择目标对象（如 df8cc377 中匹配格数），而是决定颜色的空间层级关系——一种从数值到几何拓扑的映射。

将网格上散布的多色标记像素按颜色计数并排名，然后在网格中央绘制嵌套的同心矩形边框，最外层边框使用数量最多的颜色，依次向内，最内层使用数量最少的颜色，最后擦除所有原始标记。

**输入结构**：
- 背景：黑(0)，网格为奇数 x 奇数，约 13x13
- 网格上散布孤立的标记像素，共 3-4 种颜色（例如红(2)、蓝(1)、绿(3)、黄(4)）
- 每种颜色出现的次数各不相同（例如红 4 次、绿 3 次、蓝 2 次、黄 1 次）
- 同色标记之间不共享行或列
- 颜色种数不超过网格能容纳的最大嵌套边框层数（对于 13x13 网格，最多 4 层，每层 1 格厚，层间 1 格黑色间隔）

**规则**：
1. 统计每种颜色的标记数量。按数量从多到少排名。若两种颜色数量相同，比较各自最靠上的标记像素的行号，行号更小（更靠上）的优先排名更高。
2. 以网格中心为中心，从外向内绘制嵌套矩形边框：
   - 第 1 层（最外层）：占据网格的最外一圈（第 0 行、最末行、第 0 列、最末列）。颜色 = 排名第 1 的颜色。
   - 第 2 层：从第 1 层向内隔 1 格黑色间隔后的矩形环。颜色 = 排名第 2 的颜色。
   - 依此类推，直到所有排名颜色都分配了边框层。
3. 擦除所有原始标记像素：若标记所在格没有被边框覆盖，则变为黑(0)；若已被边框覆盖，则保持边框颜色。

**关键洞察**：标记像素的空间位置与边框绘制完全无关——只有颜色的出现次数有意义。数量多寡构成一个优先级序列，而这个序列被编码为从外到内的几何嵌套层级，将离散的数值属性转化为连续的空间深度结构。

## 新题 4：虚拟滑动距离选择棋盘格目标

**组合逻辑**：[滑动](创新：不实际移动对象，仅计算假设滑动的距离作为数值) + [计数](已有原语) + [填充·棋盘格](已有原语) + [擦除](已有原语)

**来源原语**：滑动(17829a00) + 同色滑向同色边(17829a00) + 计数(df8cc377) + 像素数匹配格数(df8cc377) + 棋盘格图案(df8cc377) + 空心矩形(df8cc377) + 边界色条(17829a00) + 擦除(df8cc377)

**依赖链**：边界色条确定每个对象的滑动方向 → 计算虚拟滑动距离（不实际移动） → 距离值作为匹配键与空心矩形的棋盘格格数配对 → 匹配成功后用对象颜色填充对应矩形的棋盘格 → 擦除原始对象。滑动操作被重新诠释为"测量工具"而非"运动操作"，其输出是一个数值而非一个位置。

网格顶行和底行分别为两种颜色的边界色条，内部散布同色的小型单色对象和若干灰色空心矩形。每个对象假设向其同色边界滑动，计算出滑动距离，该距离恰好等于某个空心矩形内部棋盘格的格数，以此配对后用对象颜色填充该矩形的棋盘格。

**输入结构**：
- 背景：黑(0)，网格约 15x15
- 第 0 行：全宽红(2)色条
- 最末行：全宽蓝(1)色条
- 内部有 2-3 个小型 4-连通单色对象（每个 3-6 像素），颜色为红(2)或蓝(1)，每种颜色至多出现一个对象
- 内部有 2-3 个灰(5)边框的空心矩形（边框 1 格厚，内部为黑(0)），各矩形内部尺寸不同
- 每个空心矩形内部的"棋盘格格数"定义为：以内部左上角为起点，所有满足 (行偏移 + 列偏移) 为偶数的内部格的数量。各矩形的棋盘格格数互不相同
- 生成约束：对每个彩色对象，其滑动距离（定义见规则）恰好等于某个矩形的棋盘格格数，且不同对象匹配不同矩形

**规则**：
1. 确定每个彩色对象的匹配色条：红(2)对象匹配顶行红色条，蓝(1)对象匹配底行蓝色条。
2. 计算每个对象的滑动距离：
   - 红(2)对象：该对象边界框最上行的行号减去 1（即到顶行色条的行距离）。
   - 蓝(1)对象：(网格高度 - 2) 减去该对象边界框最下行的行号（即到底行色条的行距离）。
3. 计算每个灰色空心矩形内部的棋盘格格数：内部区域中满足 (r - r_interior_top + c - c_interior_left) 为偶数的格的总数，其中 r_interior_top 和 c_interior_left 分别为内部区域的最上行和最左列。
4. 将每个对象与棋盘格格数等于其滑动距离的矩形配对。
5. 在配对矩形的内部，将所有棋盘格位置（步骤 3 中计数的那些格）涂为该对象的颜色，其余内部格保持黑(0)。
6. 擦除所有彩色对象（对象占据的格变为黑(0)）。色条和矩形灰色边框保持不变。

**关键洞察**：边界色条不是物理目的地——它们是计算距离的参照线，滑动距离是一个虚拟测量值而非可见的位移。这个数值被重新诠释为棋盘格选择键，将空间度量转化为组合匹配问题。

## 新题 5：邻接感知的像素放大

**组合逻辑**：[像素放大](已有原语) + [图案替换](创新：替换模板不再是固定的，而依赖于原始网格中的邻接关系) + [循环填充](创新：用于单个放大块内的分层着色，而非整个矩形)

**来源原语**：像素放大(2072aba6) + 图案替换(2072aba6) + 按颜色条件分支(2072aba6) + 循环填充(516b51b7) + 前景遮挡(52df9849)

**依赖链**：每个像素的颜色决定其放大块的基础图案（条件分支） → 原始网格中同色像素之间的 4-连通邻接关系修改相邻放大块的共享边界（邻接覆盖基础图案） → 最终每个块的外观由自身颜色和邻居数量共同决定。像素放大从纯局部操作变为上下文相关操作。

将小网格中的每个像素放大为 3x3 块，黑色像素变为全黑块，灰色像素变为灰色外环+绿色中心，红色像素变为红色外环+蓝色中心。但如果两个同色前景像素在原始网格中 4-连通相邻，它们对应的 3x3 块之间的共享边界列（或行）被重涂为黄色，形成"桥接"效果。

**输入结构**：
- 背景：黑(0)，网格约 5x5 至 7x7（较小，因为要放大 3 倍）
- 前景像素有两种颜色：灰(5)和红(2)
- 前景像素形成稀疏图案（非密集填充），部分前景像素与同色像素 4-连通相邻，部分孤立
- 整体前景像素约占网格面积的 30%-50%

**规则**：
1. 创建输出网格，尺寸为输入的 3 倍（每个输入像素对应 3x3 输出块）。
2. 黑(0)输入像素 → 3x3 全黑(0)块。
3. 灰(5)输入像素（无同色邻居时的基础图案）→ 3x3 块：外围 8 格为灰(5)，中心 1 格为绿(3)。
4. 红(2)输入像素（无同色邻居时的基础图案）→ 3x3 块：外围 8 格为红(2)，中心 1 格为蓝(1)。
5. 邻接桥接规则：若输入中两个同色前景像素在水平方向 4-连通相邻（左右紧邻），则左侧像素对应块的最右列（3 格）和右侧像素对应块的最左列（3 格）均重涂为黄(4)。若两个同色前景像素在垂直方向 4-连通相邻（上下紧邻），则上方像素对应块的最下行（3 格）和下方像素对应块的最上行（3 格）均重涂为黄(4)。
6. 桥接重涂优先于基础图案：若一个像素有多个同色邻居，则每个方向的桥接独立应用。中心格可以被桥接覆盖（例如某像素的上下左右都有同色邻居时，中心格所在的行和列都会被涂为黄(4)，中心格最终为黄(4)）。
7. 不同颜色的前景像素之间不产生桥接（红与灰相邻时不桥接）。

**关键洞察**：孤立的前景像素放大后呈现"同心环+彩色核心"的标准图案，但同色相邻像素的放大块通过黄色桥接融合边界——观察者必须从输出的桥接模式反推输入中的邻接拓扑，而非仅仅识别逐像素的固定替换。

## 新题 6：中点十字阻断笛卡尔射线网格

**组合逻辑**：[放置·中点定位](已有原语) + [射线延伸](已有原语) + [行列交叉·笛卡尔积](创新：射线被十字障碍截断，导致部分交叉点不存在)

**来源原语**：放置(e9614598) + 中点定位(e9614598) + 中点居中放置(e9614598) + 行列交叉(2281f1f4) + 边缘标记笛卡尔积(2281f1f4) + 射线延伸(8d510a79, db93a21d) + 原对象遮挡叠加(41e4d17e)

**依赖链**：两个绿色像素的中点位置决定红色十字的放置位置 → 十字占据的格成为射线障碍 → 边缘蓝色标记发出的射线遇到十字时截断 → 被截断的射线减少了有效交叉点的数量。放置操作的输出通过物理遮挡改变了笛卡尔积操作的结构——两个独立系统（几何放置 + 组合网格）通过空间占用产生交互。

在网格顶行和最右列放置蓝色标记像素定义行列射线，网格内部两个绿色像素的中点处放置一个红色十字。蓝色标记发出的射线被十字阻断，只有未被阻断的射线之间才能产生交叉点。

**输入结构**：
- 背景：黑(0)，网格约 13x13
- 第 0 行（顶行）：2-4 个蓝(1)标记像素分布在不同列位置，其余格为黑(0)
- 最右列（第 W-1 列）：2-4 个蓝(1)标记像素分布在不同行位置（不含角点(0, W-1)，避免与顶行标记重叠），其余格为黑(0)
- 网格内部（非第 0 行、非最右列）有恰好 2 个绿(3)像素，它们水平或垂直对齐，中点坐标为整数，且中点距网格任意边缘至少 2 格
- 生成约束：红色十字放置后不与任何蓝色标记重叠；至少有一条射线被十字截断（否则十字无功能效果）

**规则**：
1. 计算两个绿(3)像素的中点坐标 (mr, mc) = ((r1+r2)/2, (c1+c2)/2)。
2. 以中点为中心放置一个红(2)十字精灵体（加号形状）：中心格 (mr, mc) 及其上下左右 4 个邻格，共 5 格。仅覆盖黑(0)格；绿色像素若与十字重叠则保持绿色。
3. 从顶行每个蓝(1)标记像素出发，向下画一条竖直灰(5)射线。射线从该标记正下方一格开始，逐格向下延伸。若遇到红(2)十字像素，则射线在该像素的前一格停止（不包含红色格）。若未遇到红色像素，射线延伸到网格底部边缘（最末行）。
4. 从最右列每个蓝(1)标记像素出发，向左画一条水平灰(5)射线。射线从该标记正左方一格开始，逐格向左延伸。若遇到红(2)十字像素，则射线在该像素的前一格停止。若未遇到红色像素，射线延伸到网格左边缘（第 0 列）。
5. 在所有竖直射线格和水平射线格的交叉位置（同一格既属于某竖直射线又属于某水平射线），将该格涂为黄(4)（覆盖灰色）。
6. 所有蓝色标记、绿色像素和红色十字在最终输出中保持不变。

**关键洞察**：红色十字充当"阴影屏障"——它截断经过的射线，使原本应出现的某些笛卡尔交叉点消失。移动两个绿色像素的位置就改变十字的位置，从而改变哪些交叉点存活。求解者必须先完成中点放置，再分析射线截断效果，最后才能确定交叉点集合。

## 新题 7：路径分割区域差异填充

**组合逻辑**：[连线·两点路径](已有原语) + [重涂色·按原色区分](已有原语) + [填充](创新：填充目标不是预先存在的区域，而是由路径切割产生的新子区域) + [棋盘格图案](已有原语)

**来源原语**：连线(bcb3040b) + 重涂色(bcb3040b) + 按原色区分涂色(bcb3040b) + 两点直线路径(bcb3040b) + 填充(df8cc377) + 棋盘格图案(df8cc377) + 包含(df8cc377) + 空心矩形(df8cc377, 41e4d17e)

**依赖链**：红色标记对定义路径 → 路径穿过空心矩形时将蓝色边框格变绿、黑色内部格变红 → 红色路径格将矩形内部切分为两个子区域 → 两个子区域的面积大小决定各自的填充方式（大区域棋盘格填充，小区域纯色填充）。连线操作物理地修改了空间拓扑，创造出填充操作所依赖的新区域——先画线再分析结果是不可跳过的。

在蓝色空心矩形外放置成对的红色标记像素，每对标记的直线路径恰好穿过一个矩形。路径将蓝色边框格变为绿色、黑色格变为红色，由此在矩形内部产生两个被路径分隔的子区域，面积较大的子区域填充灰色棋盘格，面积较小的子区域填充纯黄色。

**输入结构**：
- 背景：黑(0)，网格约 13x13
- 2-3 个蓝(1)空心矩形（边框 1 格厚，内部全黑），各矩形之间互不接触且留有足够间隔
- 对于每个矩形，有恰好一对红(2)标记像素位于矩形外部，两者在水平、垂直或 45 度对角线上对齐，使得它们之间的直线段穿过该矩形
- 每对标记的路径仅穿过一个矩形，不同对的路径穿过不同矩形
- 生成约束：每条路径恰好穿过其目标矩形的两个边框格和若干内部格，将矩形内部分为两个 4-连通子区域（以路径上的红色格为边界），两个子区域面积不相等

**规则**：
1. 对每对红(2)标记像素，画出两者之间的包含端点的直线段（使用 Bresenham 直线或精确的女王移动路径）：
   - 路径上原来为蓝(1)的格（矩形边框）变为绿(3)。
   - 路径上原来为黑(0)的格（背景或矩形内部）变为红(2)。
   - 路径上原来为红(2)的格（标记本身）保持红(2)。
2. 所有路径画完后，分析每个被穿过的矩形内部：路径上的红(2)格将内部分割为两个 4-连通子区域（子区域中的格与路径红格和矩形边框蓝/绿格均不连通）。
3. 比较两个子区域的面积（格数）：
   - 面积较大的子区域为"主区域"。
   - 面积较小的子区域为"次区域"。
   - 若面积相等，以包含行号更小的格的子区域为主区域；若仍相等，以包含列号更小的格的子区域为主区域。
4. 主区域填充灰(5)棋盘格：以该子区域中行号最小、列号最小的格为起点，满足 (r - r_start + c - c_start) 为偶数的格涂为灰(5)，其余保持黑(0)。
5. 次区域全部填充为黄(4)。
6. 矩形边框（蓝(1)和绿(3)格）、路径（红(2)格）和矩形外部的所有格保持不变。

**关键洞察**：路径既是视觉元素又是拓扑工具——它同时完成两件事：将穿过的蓝色边框格标记为绿色（记录穿越点），以及用红色格在矩形内部创建一条物理分界线。求解者无法在画线之前确定子区域的形状和面积，因为分界线的几何取决于标记对的位置和矩形的交叉方式。
