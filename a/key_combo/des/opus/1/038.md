## 新题 1：同心环异或选层与深度反转着色

**组合逻辑**：[异或/xor](创新：逐层比较两组同心环的颜色异同，而非像素级异或) + [深度排序/depth_order] + [层色序内外翻转/reverse_layer_colors](创新：仅对"异"层取反转深度读色) + [重涂色/recolor]

**来源原语**：异或/xor(3428a4f5), 同心方框层/concentric_layer(85c4e7cd), 深度排序/depth_order(85c4e7cd), 层色序内外翻转/reverse_layer_colors(85c4e7cd), 分隔行/separator_row(3428a4f5), 重涂色/recolor(85c4e7cd)

**依赖链**：层深度识别为异或比较提供逐层配对 -> 异或结果划分"同层/异层" -> 异层从左侧面板取反转深度对应色 -> 最终涂色同时依赖异或结果和深度反转映射，二者缺一不可

将两组同心矩形环按深度逐层异或比较，同色层清空、异色层从左侧面板的镜像深度取色，输出一组新的同心环。

**输入结构**：约 11x23 的网格。中央有一列黄(4)分隔线，将网格分为左右两个等大面板（各约 11x11）。每个面板由同心矩形环组成——所有距最近边缘相同曼哈顿距离的像素共享同一颜色，形成 N 层嵌套环（N 约 4-6 层）。两个面板的层数相同，但各层颜色不同。两面板使用的颜色从红(2)、蓝(1)、绿(3)、灰(5)、品红(6)、橙(7)、青(8) 中选取，保证除黄(4)外无颜色冲突。生成约束：两面板至少有 2 层颜色不同、至少 1 层颜色相同，以确保异或结果非平凡。

**规则**：
1. 定位黄(4)分隔列，将网格拆为左面板和右面板（不含分隔列）。
2. 对每个面板，按距最近边缘的曼哈顿距离识别深度层：depth 0 为最外环，depth N-1 为最内层。记录左面板色序 L[0..N-1] 和右面板色序 R[0..N-1]。
3. 逐层比较：若 L[d] == R[d]，标记 depth d 为"同层"；若 L[d] != R[d]，标记为"异层"。
4. 输出为一个与单面板等大的同心环结构（不含分隔列）：
   - "同层"深度 d 的所有像素涂为黑(0)。
   - "异层"深度 d 的所有像素涂为 L[N-1-d]（即左面板中深度镜像位置的颜色）。
5. 输出尺寸等于单面板尺寸。

**关键洞察**：异或比较仅决定哪些层被激活，但被激活层的着色不来自原始深度，而来自左面板的反转深度——求解者必须同时发现异或筛选规则和深度反转映射规则，仅看单个示例容易把反转映射误读为直接取色。

## 新题 2：形状频率编码旋转角度

**组合逻辑**：[连通分量检测/connected_component_detection] + [形状匹配/shape_matching] + [计数/counting](创新：计数同形对象的出现次数) -> [旋转/rotate](创新：旋转角度由频率值 mod 4 决定)

**来源原语**：连通分量检测/connected_component_detection(12eac192, b230c067), 形状匹配/shape_matching(b230c067), 计数/counting(e681b708, b230c067), 旋转/rotate(6ffbe589, f0f8a26d), 中心点不变/center_fixed(f0f8a26d)

**依赖链**：连通分量检测提取对象 -> 形状归一化后分组 -> 组内计数得频率 -> 频率 mod 4 映射为旋转量 -> 围绕边界框中心旋转；删去形状匹配则无法得到频率，删去频率则无法确定旋转角度

检测所有同色前景对象，按归一化形状分组计数，每个对象以组内成员数 mod 4 乘 90 度绕自身中心顺时针旋转。

**输入结构**：约 20x20 的黑(0)背景网格。散布 6-10 个灰(5)前景对象，均为 8-连通单色区域，各对象互不相邻（边界框间至少留 1 像素空隙）。每个对象占 3-7 像素，具备不同几何结构（连通性、对称类型各异）。其中若干对象具有相同的归一化边界框掩码（平移到左上角后像素位置完全一致），形成 2-4 个形状组，每组 1-4 个成员。生成约束：至少存在一个成员数为 1 的组（旋转 90 度）和一个成员数为 2 的组（旋转 180 度），以确保不同旋转量均出现；每个对象旋转后的边界框不超出网格边界。

**规则**：
1. 检测所有灰(5) 8-连通前景对象，为每个对象记录其像素集合和边界框。
2. 将每个对象的像素相对于其边界框左上角归一化，得到归一化掩码。
3. 按归一化掩码分组，统计每组成员数 G。
4. 对每个对象，以其边界框中心为旋转中心，顺时针旋转 (G mod 4) x 90 度。旋转后像素坐标取整（边界框中心为旋转锚点，非整数坐标四舍五入到最近整数）。
5. 将旋转后的像素绘制在干净的黑(0)背景上。
6. 若两个旋转后的对象发生像素重叠（生成时已保证此情况极罕见），重叠像素保留来自成员数更多的组的颜色；若成员数相等，保留原始边界框左上角在阅读序（先行后列）中靠前者。

**关键洞察**：旋转角度不由任何可见标记编码，而隐含在形状频率中——只有将所有对象归一化并交叉比较才能发现分组，进而推断每个对象的旋转量。单个示例中可能存在多种合理的分组假设，需要对比多个示例才能确认"归一化掩码完全一致"这一严格匹配标准。

## 新题 3：区域宽高比条件分支——镜像或多数色填充

**组合逻辑**：[洪泛填充/flood_fill] + [区域邻接/region_adjacency] -> [宽高比决定镜像轴/aspect_ratio_mirror_axis](创新：宽高比不仅决定镜像轴，还在相等时切换为完全不同的操作) -> 分支A [镜像/mirror] | 分支B [多数标记色涂色/majority_marker_color + 计数/counting + 重涂色/recolor]

**来源原语**：洪泛填充/flood_fill(e681b708), 区域邻接/region_adjacency(e681b708), 宽高比决定镜像轴/aspect_ratio_mirror_axis(93c31fbe), 镜像/mirror(93c31fbe), 多数标记色涂色/majority_marker_color(e681b708), 计数/counting(e681b708), 重涂色/recolor(e681b708), 标记像素/marker_pixel(e681b708)

**依赖链**：洪泛填充划分区域 -> 区域边界框决定宽高比 -> 宽高比分支为三种操作模式（水平镜像 / 垂直镜像 / 多数色填充）-> 镜像分支需要标记像素位置，填充分支需要标记颜色计数；三条分支共享同一套标记像素但以完全不同的方式使用它们

蓝色线段分隔网格为多个区域，每个区域包含散落的彩色标记像素；宽区域将标记水平镜像，高区域将标记垂直镜像，正方形区域用多数标记色填充全部背景格。

**输入结构**：约 18x18 的黑(0)背景网格。蓝(1)像素形成单像素宽的水平和垂直线段，将网格分割为若干不规则的封闭区域（4-连通背景区域被蓝色线段隔开）。每个含标记的区域内散布 2-5 个孤立标记像素，颜色从红(2)、绿(3)、黄(4)、灰(5)、品红(6)中选取。生成约束：至少存在一个宽区域（bbox宽度 > 高度）、一个高区域（bbox高度 > 宽度）、一个正方形区域（bbox宽度 == 高度），以展示三种分支；标记像素不与蓝色线段 4-邻接（即标记至少离墙 1 格）；镜像后的标记像素落在同一区域内（不越过蓝色墙壁），且不与原始标记重合。

**规则**：
1. 将蓝(1)像素视为墙壁。对黑(0)像素做 4-连通洪泛填充，识别所有封闭区域。
2. 对每个区域，计算其边界框（包含该区域所有像素的最小矩形）的宽度 W 和高度 H。
3. 条件分支：
   - W > H（宽区域）：对区域内每个标记像素，计算其关于区域边界框水平中轴的镜像位置（y' = bbox_top + bbox_bottom - y, x 不变）。在镜像位置放置一个同色像素副本。原始标记保留不变。
   - H > W（高区域）：对区域内每个标记像素，计算其关于区域边界框垂直中轴的镜像位置（x' = bbox_left + bbox_right - x, y 不变）。在镜像位置放置一个同色像素副本。原始标记保留不变。
   - W == H（正方形区域）：统计区域内各标记颜色的出现次数，找到出现次数最多的颜色（若平局，取在该区域中最先出现的标记——按从上到下、从左到右扫描序）。将该区域内所有黑(0)背景像素重涂为该多数颜色。标记像素本身保持不变。
4. 无标记像素的区域保持不变。蓝(1)墙壁像素保持不变。

**关键洞察**：同一批标记像素在不同区域中触发完全不同的操作——空间操作（镜像）或颜色操作（填充），且切换条件是区域几何形状而非标记本身的任何属性。求解者必须同时发现分支条件和每条分支的规则，只看单一区域形状的示例无法区分三种模式。

## 新题 4：射线分支扩散计数驱动区域着色

**组合逻辑**：[射线延伸/ray_extend] + [分支/branch] + [墙段开口分支/branch_at_opening] -> [洪泛填充/flood_fill] + [区域邻接/region_adjacency] -> [计数/counting](创新：计数射线路径与区域边界的接触数) -> [重涂色/recolor]

**来源原语**：射线延伸/ray_extend(f9a67cb5), 分支/branch(f9a67cb5), 墙段开口分支/branch_at_opening(f9a67cb5), 从边缘推进/advance_from_edge(f9a67cb5), 洪泛填充/flood_fill(e681b708), 区域邻接/region_adjacency(e681b708), 计数/counting(e681b708), 重涂色/recolor(477d2879), 墙壁线段/wall_segment(e681b708), 边缘标记/edge_marker(f9a67cb5)

**依赖链**：边缘标记定起点和初始方向 -> 射线穿越空隙并在墙段开口处分支 -> 分支路径的拓扑分布决定了每个区域被多少条路径接触 -> 接触数映射为颜色；射线路径是区域着色的唯一信息来源，而射线路径本身取决于墙段的开口位置

从网格边缘的标记像素发射射线，射线在墙段开口处分支扩散，最终以每个封闭区域边界被射线接触的次数决定该区域的着色。

**输入结构**：约 17x17 的黑(0)背景网格。灰(5)像素形成 3-5 条水平或垂直的墙段（每条墙段为连续的一像素宽直线，长度 5-12 像素），墙段之间不相连。每条墙段中间有 1-2 个单像素宽的缺口（开口）。墙段与网格边缘共同围成若干封闭区域。红(2)标记像素恰好 1 个，位于网格四条边之一的边缘行或列上（即在第 0 行、最后一行、第 0 列或最后一列），且该标记位置面向网格内部方向没有紧邻的墙段像素（射线至少能前进 1 格）。生成约束：射线从标记出发后经过所有分支最终至少接触 3 个不同的封闭区域；不同区域的接触数至少有两种不同取值。

**规则**：
1. 从红(2)标记像素出发，向网格内部方向（垂直于标记所在边缘）发射一条射线。
2. 射线逐格前进，将经过的黑(0)像素涂为红(2)。
3. 当射线的下一格是灰(5)墙段像素时：
   a. 将该墙段像素涂为红(2)。
   b. 沿墙段方向（垂直于射线前进方向）扫描整条连续墙段，找到所有缺口（墙段中的黑(0)间断点）。
   c. 从每个缺口位置沿原射线前进方向发射新的分支射线。
   d. 如果缺口之外（沿射线方向的下一格）是网格边界或另一面墙段，则该分支终止。
4. 每条分支射线遵循相同规则：遇墙则扫描、分支、继续。射线遇到网格边界时终止。射线遇到已涂红的像素时也终止（不重复路径）。
5. 所有射线终止后，对网格中仍为黑(0)的像素做 4-连通洪泛填充，识别封闭区域。
6. 对每个封闭区域，统计其边界（4-邻接的非黑像素）中红(2)像素的数量 C。
7. 着色规则：
   - C = 0：该区域保持黑(0)。
   - C = 1 或 2：该区域所有黑(0)像素涂为蓝(1)。
   - C = 3 或 4：涂为绿(3)。
   - C >= 5：涂为黄(4)。
8. 灰(5)墙段像素和红(2)射线像素保持不变。

**关键洞察**：射线在墙段开口处的分支是一个树状扩散过程，其拓扑结构完全由墙段的开口位置和排列决定；区域的最终颜色不是由其自身属性决定，而是由射线树中哪些分支恰好经过其边界这一全局拓扑关系决定的。

## 新题 5：降采样蒙版筛选色块后四重对称补全

**组合逻辑**：[降采样/downsample] + [整数缩放对应/int_scale_correspond] -> [掩码裁剪/mask_crop] -> [对称补全/symmetry_completion] + [角标记/corner_marker] + [包围框内/inside_bounding_box]

**来源原语**：降采样/downsample(6ecd11f4), 整数缩放对应/int_scale_correspond(6ecd11f4), 掩码裁剪/mask_crop(6ecd11f4), 单色图案/mono_pattern(6ecd11f4), 多色正方形/multicolor_square(6ecd11f4), 对称补全/symmetry_completion(4290ef0e), 角落补全四重对称/corners_to_fourfold_symmetry(4290ef0e), 角标记/corner_marker(93c31fbe), 包围框内/inside_bounding_box(93c31fbe)

**依赖链**：大图案降采样得蒙版 -> 蒙版裁剪多色方块得"种子图案" -> 角标记定义对称框架 -> 种子图案在框架内四重对称补全；缺少降采样则不知道保留哪些像素，缺少角标记则不知道对称范围

一个大尺度单色图案降采样为二值蒙版，筛选多色方块的像素后得到种子图案，再在角标记定义的方框内做四重对称补全。

**输入结构**：约 22x22 的黑(0)背景网格，包含三类元素：(a) 一个大型灰(5)单色图案，占据约 8x8 至 12x12 的区域，是某个 4x4 或 5x5 二值掩码的整数倍放大（放大因子 2 或 3），图案由灰(5)和黑(0)像素构成。(b) 一个密集的多色正方形（约 4x4 或 5x5，与降采样后的蒙版尺寸相同），位于大图案之外，每个像素颜色各不相同，从红(2)、蓝(1)、绿(3)、黄(4)、橙(7)、青(8)中选取。(c) 四个品红(6) 2x2 L 形三联骨牌（triomino），分别位于网格中某个矩形区域的四个角落，定义一个对称框架，该框架内部区域为 2W x 2H（其中 W、H 分别等于多色正方形的宽和高）。三类元素互不重叠，间距至少 1 像素。生成约束：蒙版中至少有 40% 的像素为灰(5)（非全空），保证种子图案有足够内容。

**规则**：
1. 分离三类元素：裁剪大灰(5)图案的边界框、裁剪多色正方形的边界框、定位四个品红(6)角标记的边界框以确定对称框架。
2. 将大灰(5)图案降采样到多色正方形的尺寸（即除以放大因子），得到一个与多色正方形等大的二值蒙版（灰=1, 黑=0）。
3. 将蒙版叠加到多色正方形：蒙版为 1 的位置保留多色正方形对应像素颜色，蒙版为 0 的位置设为黑(0)。得到"种子图案"。
4. 将种子图案放置在对称框架内部区域的左上象限（左上角与框架内部区域的左上角对齐）。
5. 做四重对称补全：将左上象限的种子图案水平翻转填入右上象限，垂直翻转填入左下象限，同时水平和垂直翻转填入右下象限。
6. 品红(6)角标记保持不变。框架外的区域保持黑(0)。大灰(5)图案和原始多色正方形在输出中被擦除（设为黑(0)）。

**关键洞察**：大图案不是装饰性背景而是一个二值编码器，它降采样后成为筛选多色方块的掩模；掩模筛选结果再由角标记框架控制的四重对称展开，三个独立输入元素各提供变换链的一个环节，缺一则输出不可确定。

## 新题 6：条棒旋转后按标记色着色与长度优先重叠裁决

**组合逻辑**：[旋转/rotate] + [朝向交换长度保持/orient_swap_keep] + [中心点不变/center_fixed] -> [重涂色/recolor](创新：由端点标记色决定整条棒的新颜色) -> [计数/counting](创新：长度比较解决重叠冲突) + [擦除/erase]

**来源原语**：旋转/rotate(f0f8a26d), 朝向交换长度保持/orient_swap_keep(f0f8a26d), 中心点不变/center_fixed(f0f8a26d), 单像素宽条/thin_bar(f0f8a26d), 标记像素/marker_pixel(e681b708, 477d2879), 重涂色/recolor(477d2879), 计数/counting(e681b708), 擦除/erase(93c31fbe)

**依赖链**：标记像素标识每根棒并指定新颜色 -> 旋转改变棒的朝向和占据的像素 -> 旋转后产生的重叠需要比较棒长度来裁决 -> 长度信息来自原始棒（旋转不改变长度）；删去标记则不知道着色，删去旋转则不产生冲突，删去长度比较则重叠像素颜色不确定

每根单色棒在端点有一个彩色标记；所有棒绕各自中心旋转 90 度后，整条棒着为其标记色，重叠处由较长棒胜出。

**输入结构**：约 19x19 的黑(0)背景网格。5-8 根灰(5)单像素宽条，每根为水平或垂直直线，奇数长度（3、5、7 或 9 像素）。每根棒的一个端点处（4-邻接的下一格，不是棒本身的像素）放有一个标记像素，颜色从红(2)、蓝(1)、绿(3)、黄(4)、橙(7)、青(8)中选取，不同棒的标记颜色可以相同也可以不同。生成约束：棒的原始位置互不重叠；每根棒旋转后的边界框不超出网格边界；至少有两对棒在旋转后会产生像素重叠，且这两对中至少一对涉及不同标记颜色和不同长度。

**规则**：
1. 识别所有灰(5)的 4-连通单像素宽条及其长度和中心点（奇数长度的正中像素）。
2. 对每根棒，找到其某个端点 4-邻接的非灰非黑标记像素，记录该标记颜色为这根棒的"目标色"。
3. 清空画布至全黑(0)。擦除所有原始标记像素。
4. 对每根棒，保持中心点不变、长度不变，交换朝向（水平变垂直，垂直变水平），计算旋转后的像素坐标集合。
5. 将每根旋转后的棒以其目标色绘制到画布上。
6. 若某像素被多根棒覆盖（重叠）：
   - 取这些棒中长度最大者的目标色。
   - 若长度最大者有多根且目标色不同，取其中原始中心点在阅读序（先行后列）中最靠前者的目标色。
7. 输出画布。

**关键洞察**：标记像素既是棒的身份标签又是目标着色指令，而旋转操作创造了原始布局中不存在的空间冲突；冲突的裁决依赖于棒的长度属性，而该属性在旋转后虽然不变但需要回溯到原始棒来测量——三个信息层（标记色、旋转位置、原始长度）必须同时协调。

## 新题 7：对角错位拼接后连通分量重叠区的面积裁决着色

**组合逻辑**：[拼接/stitch] + [偏移放置/offset_placement] + [对角偏移/diagonal_offset] -> [连通分量检测/connected_component_detection] -> [计数/counting](创新：比较重叠处两个原始分量的面积) -> [重涂色/recolor]

**来源原语**：拼接/stitch(8618d23e), 偏移放置/offset_placement(8618d23e), 对角偏移/diagonal_offset(8618d23e), 分隔行/separator_row(3428a4f5), 半区域/half_region(8618d23e), 连通分量检测/connected_component_detection(12eac192), 计数/counting(e681b708), 面积阈值筛选/area_threshold_filter(12eac192), 重涂色/recolor(12eac192)

**依赖链**：分隔行划分上下半区 -> 对角错位拼接创造空间重叠 -> 重叠像素需追溯原始连通分量 -> 原始分量面积比较决定着色；重叠关系只在拼接后才产生，但面积比较必须基于拼接前的原始分量

上下两半区以对角偏移拼接到更大画布上，重叠处像素由原始面积较小的分量决定颜色。

**输入结构**：约 14x12 的网格（偶数行数）。中间一行为黄(4)分隔行，将网格分为上半区和下半区（各约 6x12 或 7x12，不含分隔行）。上半区和下半区各包含 3-5 个单色 4-连通前景对象，散布在黑(0)背景上。上半区对象使用红(2)、蓝(1)、绿(3)中的颜色；下半区对象使用灰(5)、橙(7)、青(8)中的颜色（两半区无共用颜色）。生成约束：对角偏移拼接后（下半区相对上半区右移 1 列、下移 1 行），至少有 2 处不同颜色的对象像素发生重叠；上下半区中各对象面积（像素数）各不相同，避免面积平局。

**规则**：
1. 定位黄(4)分隔行。提取上半区 T 和下半区 B（不含分隔行）。
2. 在上半区和下半区中分别做 4-连通分量检测，记录每个分量的颜色和面积（像素数）。
3. 创建输出画布，尺寸为 (T_height + B_height + 1) 行 x (max(T_width, B_width) + 1) 列，全部填充黄(4)。
4. 将上半区 T 复制到画布左上角 (0, 0)。
5. 将下半区 B 复制到画布偏移位置 (T_height + 1, 1)（即下移 T_height+1 行、右移 1 列）。
6. 对于重叠像素（同一画布位置被上半区和下半区的非黑像素同时覆盖）：
   - 找到上半区中该像素所属的原始分量 C_T 和下半区中该像素所属的原始分量 C_B。
   - 比较 C_T 的面积和 C_B 的面积。
   - 该像素取面积**较小**的分量的颜色。
7. 非重叠的前景像素保持原色。未被任何前景像素覆盖的画布位置保持黄(4)。

**关键洞察**：对角拼接是创造重叠的唯一机制，但裁决重叠的依据是原始半区中各分量的面积——一个全局属性（面积）解决一个局部问题（像素归属），求解者必须回溯到拼接前的分量划分才能正确着色。

## 新题 8：逐列填充后线路网络按色彩复杂度定向传输

**组合逻辑**：[逐列填充/column_fill] + [传播/propagate] + [底行标记选定列/bottom_marker_selects_column] -> [计数/counting](创新：计数每列的色彩种类数) -> [传输/transmit] + [端点配对/endpoint_pairing](创新：传输方向由色彩复杂度差异决定)

**来源原语**：逐列填充/column_fill(17b80ad2), 传播/propagate(17b80ad2), 底行标记像素/bottom_row_marker_pixel(17b80ad2), 底行标记选定列/bottom_marker_selects_column(17b80ad2), 线路网络/wire_network(a47bf94d), 端点配对/endpoint_pairing(a47bf94d), 传输/transmit(a47bf94d), 计数/counting(e681b708)

**依赖链**：底行标记选定活跃列 -> 逐列向上填充产生色带 -> 线路网络将活跃列两两配对 -> 每列色带中不同颜色种类数决定传输方向（少色列 -> 多色列） -> 传输覆盖目标列特定行的颜色；填充结果是传输方向判断的输入，二者不可分离

标记列先向上传播填色形成色带，然后通过线路网络将色彩种类较少的列的内容传输到较多的列上。

**输入结构**：约 15x15 的黑(0)背景网格。底行（最后一行）有 4-6 个彩色标记像素（非黑），标记着活跃列。标记颜色从红(2)、蓝(1)、绿(3)、黄(4)中选取。每个活跃列中散布 2-4 个非背景色像素（颜色与底行标记相同或不同，从上述四色中选取），分布在不同行高。橙(7)像素形成 2-3 条线路网络（单像素宽的连续路径，可弯折但不分支），每条线路连接恰好两个活跃列（线路的两个端点分别 4-邻接某个活跃列的某个像素）。线路不经过活跃列内部（不穿过活跃列的任何像素）。生成约束：每个活跃列至少被一条线路连接；配对后每对列在填充后的色彩种类数不相同（保证传输方向确定）。

**规则**：
1. 识别底行的非黑标记像素，确定活跃列集合。
2. 对每个活跃列，从下往上扫描。维护当前色 = 底行标记色。遇到非黑像素时更新当前色为该像素颜色。遇到黑(0)像素时将其替换为当前色。扫描结束后，每个活跃列成为从下到上的连续色带。
3. 对每个活跃列，统计其色带中不同颜色的种类数 D（不含黑色，因为填充后无黑色）。
4. 对每条橙(7)线路，确定其连接的两个活跃列 A 和 B。比较 D_A 和 D_B。
5. 设 D_A < D_B（A 是"简单列"，B 是"复杂列"）。对线路上每个橙(7)像素所在的行 r：将 B 列第 r 行的像素颜色替换为 A 列第 r 行的像素颜色。
6. 若 D_A == D_B（生成约束已排除此情况）。
7. 橙(7)线路像素保持不变。非活跃列保持黑(0)。底行标记像素保持不变。

**关键洞察**：逐列填充不是最终目标，而是为后续传输方向判断提供数据——填充结果的色彩多样性成为线路网络传输方向的隐式编码。求解者必须先完成填充才能判断传输方向，而传输又反过来修改了填充结果。

## 新题 9：平铺跨边界连通分量检测与频率分涂

**组合逻辑**：[平铺/tiling] + [引导线定填充带/guide_determines_band] + [画布扩展/canvas_expansion] -> [连通分量检测/connected_component_detection](创新：在平铺后的画布上检测跨瓦片边界的新连通分量) -> [形状匹配/shape_matching] + [唯一重复形分涂/unique_vs_repeated_recolor]

**来源原语**：平铺/tiling(15696249), 引导线定填充带/guide_determines_band(15696249), 引导行或列/guide_row_or_column(15696249), 画布扩展/canvas_expansion(15696249), 连通分量检测/connected_component_detection(12eac192, b230c067), 形状匹配/shape_matching(b230c067), 唯一重复形分涂/unique_vs_repeated_recolor(b230c067), 输入瓦片/input_tile(15696249)

**依赖链**：引导行/列选定输出带 -> 平铺在该带上复制瓦片 -> 跨瓦片边界产生新的连通拓扑 -> 连通分量归一化后分组 -> 唯一形状与重复形状分别着色；平铺改变了分量形状，形状分组的结果完全依赖于平铺产生的跨边界连接

将输入瓦片平铺到引导线选定的带状区域后，检测跨瓦片边界形成的新连通分量，按形状频率分涂：唯一形状涂红，重复形状涂蓝。

**输入结构**：一个 n x n 的瓦片（n 约 5-7），包含若干 8-连通的单色前景对象，背景为黑(0)，前景统一为灰(5)。瓦片中恰好有一整行或一整列被绿(3)填满（引导线）。瓦片中的前景对象有些接触瓦片边缘（可能在平铺时与相邻副本连接），有些不接触边缘。生成约束：至少有一个前景对象接触引导线方向对应的那条边缘（保证平铺后跨边界连接一定发生）；瓦片中各前景对象的归一化形状至少有两种不同的形状。

**规则**：
1. 识别瓦片中的引导行或引导列及其索引 k。
2. 创建 n x n 个瓦片大小的方块画布（总尺寸 n^2 x n^2），全部填充黑(0)。
3. 若引导线为行：将瓦片复制到方块画布的第 k 个方块行（共 n 个方块列位置，每个位置放一份瓦片副本），其余方块行保持黑(0)。若引导线为列：类似地复制到第 k 个方块列。
4. 在存活的带状区域中，将所有绿(3)引导线像素替换为灰(5)（与前景统一颜色，使引导线不干扰分量检测）。
5. 对带状区域中所有灰(5)像素做 8-连通分量检测。由于平铺，原本不同的瓦片内对象可能通过边缘接触合并为更大的跨瓦片分量。
6. 对每个检测到的连通分量，将其像素相对于自身边界框左上角归一化，得到归一化掩码。
7. 按归一化掩码分组，统计每种形状的出现次数。
8. 着色：出现次数为 1（唯一形状）的分量涂为红(2)；出现次数 >= 2（重复形状）的分量涂为蓝(1)。
9. 黑(0)背景保持不变。

**关键洞察**：同一瓦片内对象在单独看时可能形状各不相同，但平铺后接触边缘的对象与相邻副本合并成新形状——一个原本"唯一"的对象可能因跨边界连接变为"重复"的，反之亦然。求解者必须理解平铺机制如何改变连通拓扑，才能正确预测频率分涂结果。
