## 新题 1：重力沉积量决定同心环嵌套序

**组合逻辑**：[重力下落](从竖直扩展为含斜向滑动的沉积模拟) + [计数](统计各盆地沉积量，创新：计数结果作为几何构造参数) + [同心环绘制](创新：环序不由预设面积决定，而由物理模拟结果动态决定)

**来源原语**：重力下落(gravity_drop, #1-28a6681f), 盆地(basin, #1), 碰撞停止(collision_stop, #1), 沿路径滑动(slide_along_path, #1), 计数(counting, #14-1190e5a7), 同心环绘制(concentric_draw, #7-5587a8d0), 面积排序→沉积量排序(area_ordering, #7), 连通分量(connected_component, #7)

**依赖链**：盆地几何形状决定能接住多少下落像素 → 各盆地的沉积量必须通过完整的重力模拟才能得到 → 沉积量的降序排列决定同心环从外到内的颜色分配 → 环的总层数等于有效盆地数。删除重力模拟则无法得到沉积量；删除计数排序则无法确定环序；删除环绘制则无输出。

将散落的彩色像素模拟重力沉入多个盆地，按各盆地收集的像素数量从多到少绘制同心方环。

**输入结构**：背景黑(0)，网格约 15x15。网格中下部有若干由不同颜色（非黑非蓝）障碍像素围成的"盆地"结构——每个盆地是一个上方开口、底部和两侧封闭的凹槽，由同色像素构成槽壁（各盆地颜色互不相同，如红(2)、绿(3)、橙(7)等）。盆地宽度各不相同（2~5 列宽），深度也不同（2~4 行深）。网格上部散布若干蓝(1)水像素，每个水像素占一个单元格，水像素之间互不相邻。水像素的水平位置使得每个盆地上方至少有一个水像素。生成约束：各盆地的沉积量互不相等；盆地数量在 3~5 之间。

**规则**：
1. 每个蓝(1)水像素向下做重力下落：逐格向下移动，穿过黑(0)背景格。
2. 若正下方被阻挡（非黑像素或网格底边），水像素尝试左下或右下的唯一可通行方向滑入；若两侧均被阻挡则停在当前位置。若左下和右下均可通行，优先选择左下。
3. 重复步骤 1-2 直到所有水像素不再移动。处理顺序：从最底行的水像素开始向上逐行处理，同行从左到右。
4. 统计每个盆地内部（槽壁围成的凹区域内）最终沉积的蓝色像素数量。
5. 按沉积量从大到小对盆地排序。绘制同心方环：层数 = 盆地数量 N，输出网格边长 = 2N - 1。沉积量最多的盆地的槽壁颜色涂最外环，次多的涂次外环，依此类推，沉积量最少的盆地颜色涂中心像素。
6. 输出仅包含同心方环图案，不保留原始网格内容。

**关键洞察**：盆地的槽壁颜色不直接映射到环的位置——它的宽度和相对于水像素源的位置共同决定了能接住多少水，这个物理模拟的结果才是嵌套顺序的依据。仅看盆地的大小或颜色无法确定最终环序。

## 新题 2：推移至边界后射线对接同行列着陆点

**组合逻辑**：[推移](保留原始方向语义) + [射线延伸/连线](创新：在推移后的着陆位置之间按行列对齐关系画连接线) + [碰撞停止](创新：发射推移的栗色标记同时充当射线阻挡物)

**来源原语**：推移(push, #20-5623160b), 接触侧决定方向(contact_side_dir, #20), 推至边界停止(stop_at_boundary, #20), 固定标记(fixed_marker, #20), 射线延伸(ray_extend, #5-99fa7670 / #12-9def23fe), 连线(draw_line, #6-8403a5d5), 行列对齐(row_column_alignment, #5), 碰撞停止(collision_stop, #1-28a6681f)

**依赖链**：栗色标记的接触侧决定推移方向 → 推移方向决定着陆位置 → 着陆位置的行列对齐关系决定哪些对象对之间可以连线 → 连线是否实际绘制取决于路径上有无栗色标记阻挡。栗色标记同时承担"推力来源"和"连线阻断"双重角色，形成自相矛盾的设计张力。

将前景对象按栗色标记方向推至网格边界，然后在同行或同列的着陆对象之间画连接线，但栗色标记本身阻断连接线。

**输入结构**：背景黑(0)，网格约 15x15。若干小型单色前景对象（每个 3~6 像素的 4-连通单色图形，颜色各不相同，从蓝(1)、红(2)、绿(3)、橙(7)中取），分布在网格内部（不贴边）。每个对象恰好有一侧紧邻栗(9)标记像素（1~2 个栗色像素构成标记，与对象在一个基本方向上相邻）。栗色标记不与其他对象或其他标记相邻。生成约束：推移后至少有两对对象落在同行或同列上；至少有一对被栗色标记阻断。

**规则**：
1. 保持所有栗(9)标记像素不动。
2. 对每个非背景、非栗色的前景对象，确定其栗色接触侧（上/下/左/右），向相反方向平移整个对象直至对象边缘触及网格边界。清除对象原位置为黑(0)。
3. 所有对象推移完毕后，检测着陆对象对之间的行列对齐关系：若两个着陆对象的边界框在同一行区间（行范围有交集）或同一列区间（列范围有交集）内，则该对为"对齐对"。
4. 对每个对齐对，尝试在两个对象最近边缘之间画一条黄(4)直线段（沿共享的行或列方向，从一个对象的近边到另一个对象的近边）。若共享行区间，取行区间中位行画水平线；若共享列区间，取列区间中位列画竖直线。
5. 若该线段路径上经过任何栗(9)标记像素，则不画该线段（跳过此对）。
6. 黄色线段不覆盖已有的对象像素或栗色像素；若线段某格已被占据则该格跳过但线段其余部分照画。

**关键洞察**：推移一个对象到左边界的栗色标记，可能恰好挡住了另两个被推到上下边界的对象之间的连线通道——同一个标记既是推力的来源又是连接的阻断者。需要综合所有标记的空间位置才能判断最终连线图案。

## 新题 3：多模板面积决定印章遮挡层序

**组合逻辑**：[印章放置](创新：不再是单一模板的重复印章，而是多种不同模板各由匹配颜色的单例像素定位) + [面积排序→遮挡层序](创新：将参考题#7的面积排序语义从"决定同心环位置"转化为"决定印章叠放的前后关系") + [重涂色](保留：重叠区域的颜色由胜出层决定)

**来源原语**：印章放置(stamp, #4-a395ee82), 模板(template, #4), 单像素布局(singleton_layout, #4), 栅格偏移(lattice_offset, #4), 排序(sort, #7-5587a8d0), 面积排序(area_ordering, #7), 遮挡层序(occlusion_order, #17-652646ff), 重叠区域重涂(overlap_recolor, #4)

**依赖链**：单例颜色→匹配模板（确定"印什么"）→ 单例位置→印章中心（确定"印在哪"）→ 模板像素数比较→遮挡优先级（确定"谁盖谁"）→ 每个像素取最高优先级颜色。三个决策节点交织：位置选择、模板选择、冲突仲裁缺一不可。

在多个单例标记位置分别印上颜色匹配的模板副本，重叠处由模板像素数量大者覆盖小者。

**输入结构**：背景黑(0)，网格约 18x18。网格左侧或顶部有一个"模板展示区"（以灰(5)竖线或横线分隔），展示区内并排放置 3~4 个模板，每个模板是一个不同颜色的 4-连通单色小图形（3~8 像素），各模板像素数互不相同。模板颜色从蓝(1)、红(2)、绿(3)、橙(7)中取，各不相同。灰线右侧（或下方）为"放置区"，放置区内散布若干单例像素，每个单例像素的颜色与某个模板颜色相同（每种颜色的单例可出现 1~3 次）。生成约束：至少有两对印章副本在放置后发生像素重叠；模板展示区与放置区不重叠。

**规则**：
1. 识别灰(5)分隔线，将网格分为模板区和放置区。提取模板区中每个 4-连通单色图形作为模板，记录其形状（相对于其边界框左上角的像素偏移集合）和颜色。
2. 对放置区中的每个单例像素，找到颜色匹配的模板，将模板副本的边界框左上角对齐到该单例像素所在位置。
3. 按模板像素数量从小到大的顺序依次绘制所有副本（先画小的，后画大的覆盖上去）。这样像素数最多的模板在最上层。
4. 若两个模板像素数相同（生成时已排除此情况，但作为规则完备性说明），则在输入中单例像素列坐标更小的先画（更靠左的先画，被后画的覆盖）。
5. 超出网格边界的模板像素丢弃。模板区和灰分隔线在输出中清除为黑(0)，仅保留放置区的印章结果。

**关键洞察**：一个小模板即使位置极佳，也会被像素更多的邻近大模板完全覆盖——面积不是"自身属性"而是"对抗他者的资本"。需要对比所有模板大小才能确定每个重叠像素的最终归属。

## 新题 4：迷宫路径是否穿越边框决定填充色

**组合逻辑**：[寻路](保留最短路径语义) + [填充](创新：填充颜色不由边框自身面积决定，而由全局路径是否经过该边框内部来决定) + [射线延伸→边框开口](创新：边框缺口同时是迷宫通道和填充激活条件的载体)

**来源原语**：寻路(pathfinding, #18-b15fca0b), 四邻接连通(four_neighbor_connect, #18), 障碍像素(blocker_pixel, #18), 端点像素(endpoint_pixel, #18), 最短路径唯一(unique_shortest_path, #18), 填充(fill, #3-84f2aca1), 矩形边框(rectangular_frame, #3), 封闭内部(enclosed_interior, #3), 面积阈值决定颜色(area_threshold_determines_color, #3)

**依赖链**：迷宫拓扑 + 边框缺口位置共同决定最短路径走向 → 路径是否穿过某边框内部取决于缺口朝向和迷宫阻塞情况 → "是否穿过"这个二值判定决定该边框内部的填充颜色。路径选择是全局最优化的结果，不能通过单独分析某个边框来预测。

找到两个端点之间穿越迷宫的最短路径，路径穿过其内部的边框填灰色，路径绕过的边框填其自身边框色。

**输入结构**：背景黑(0)，网格约 18x18。蓝(1)像素形成迷宫墙壁（分布在网格各处，形成连通或不连通的障碍结构）。网格中有 3~4 个不同颜色的单像素厚空心矩形边框（颜色从红(2)、绿(3)、橙(7)、品红(6)中取，边框尺寸 4x4 到 6x6 不等）。每个边框在其上下左右四条边中的两条对边上各有恰好一个缺口（缺失一个边框像素），形成两个出入口。两个红(2)端点像素分别位于网格的相对两侧（如左上区域和右下区域），不在任何边框内部。生成约束：存在唯一最短路径；该路径穿过至少一个边框的内部且绕过至少一个边框；蓝色墙壁不封死任何边框的两个缺口。

**规则**：
1. 将蓝(1)像素和完整的边框像素（非缺口位置）视为不可通行障碍。缺口位置和黑(0)背景格可通行。
2. 寻找从一个红(2)端点到另一个红(2)端点的唯一最短 4-邻接路径。
3. 将路径上的所有黑(0)格涂为黄(4)。
4. 对每个矩形边框判断：路径是否从该边框的一个缺口进入、经过其内部、从另一个缺口离开。
5. 若路径穿过该边框内部：将边框内部未被路径占据的黑(0)格填充为灰(5)。
6. 若路径未穿过该边框内部：将边框内部的黑(0)格填充为该边框自身的边框颜色。
7. 蓝色墙壁、边框像素、红色端点、黄色路径均保持不变。

**关键洞察**：每个边框的填充颜色并非由它自身的几何属性决定，而取决于全局最优路径是否"选择"经过它——这是一个涌现属性，改变远处一块蓝色墙壁可能导致路径改道，从而翻转某个边框的填充颜色。

## 新题 5：裁剪最大边框后按内部分区数缩放子图案

**组合逻辑**：[裁剪](保留最大面积选取语义) + [计数](创新：分区数不输出为网格尺寸，而是转化为子图案的缩放因子) + [像素放大](创新：放大倍率不是固定值而由前序计数步骤动态确定)

**来源原语**：裁剪(crop, #13-1a6449f1), 最大面积选取(largest_area_selection, #13), 完整边框检测(complete_border_check, #13), 边框包围内容(border_encloses_content, #13), 忽略干扰项(ignore_distractors, #13), 计数(counting, #14-1190e5a7), 分隔栅格(divider_grid, #14), 分区数定输出尺寸(partition_sets_size, #14), 像素放大(pixel_scaling, #15-0692e18c)

**依赖链**：完整边框检测→选取最大边框→裁剪得到工作区 → 识别灰色分隔条→计数子区域→得到缩放因子 → 提取每个子区域中的小图案→按缩放因子逐像素放大→拼接输出。裁剪结果决定了可见的分隔条数量，分隔条数量决定了缩放倍率，缩放倍率决定了输出尺寸——三步之间有数值传递的实质依赖。

从最大完整边框中裁剪内容，统计内部被灰色条分割的子区域数，将每个子区域的小图案按子区域总数倍放大后拼接输出。

**输入结构**：背景黑(0)，网格约 20x20。网格中有 2~3 个不同颜色的完整单像素厚矩形边框（如红(2)和绿(3)），其中一个面积明显最大。最大边框外有若干噪声像素（随机颜色散点作为干扰）。最大边框内部被灰(5)全行条和全列条（在边框内部从左壁到右壁或从顶壁到底壁贯穿）分割为若干等大矩形子区域。子区域数量为 R_row x R_col（如 2x2=4 个或 2x3=6 个），其中 R_row 是行方向区域数，R_col 是列方向区域数。每个子区域内包含一个蓝(1)小图案（2~4 像素的 4-连通图形），或者为空（全黑）。生成约束：至少有两个子区域包含非空图案；各非空子区域内图案形状不完全相同。

**规则**：
1. 检测所有完整同色矩形边框。选取内部面积最大的边框。
2. 裁剪该边框的严格内部（去掉边框本身），得到工作区。
3. 在工作区中识别灰(5)全行条和全列条，计算行方向区域数 R_row 和列方向区域数 R_col。令缩放因子 S = R_row + R_col。
4. 提取每个子区域内的图案（相对于子区域左上角的坐标集合）。空子区域图案为空集。
5. 对每个图案做 S 倍像素放大（每个原始像素变为 S x S 的像素块，保持蓝(1)颜色）。
6. 将放大后的图案按其在子区域中的相对位置排列（去掉灰色条，子区域间无间隔直接拼接），空子区域对应全黑块。输出为拼接后的完整网格。

**关键洞察**：分区越多意味着子区域越小、图案越微小，但同时缩放因子也越大——分隔条数量同时压缩了"原始信息"并放大了"输出表现"，二者恰好由同一个参数控制，需要对比多个示例才能归纳出 S = R_row + R_col 这一非显然的缩放公式。

1. 识别青(8) L 型角标记，确定拼合目标角（缺口所在位置）。

5. 仍有支撑的蓝色像素保持不动。灰色结构保持不动。
6. 输出拼合并重力沉积后的完整矩形网格。

**关键洞察**：拼合不仅改变了碎片的空间排列，更改变了内部的支撑拓扑——某些碎片边缘的灰色像素在拼合时被对面碎片的黑色内部取代，导致原本稳定的蓝色像素突然悬空。需要同时理解边缘匹配规则和重力规则才能预测最终状态。

1. 识别灰(5)标记像素。找出其中构成正方形三个角的三个标记（其两两距离满足正方形对角/边长关系），忽略剩余的干扰标记。

**关键洞察**：三角形的腿指向的方向恰好是矩形不能延伸的方向——缺角的位置编码的不是"往哪画三角形"而是"往哪不延伸矩形"。需要理解"缺角方向 = 允许延伸方向"这个反直觉的等式。

## 新题 9：重叠边框的相互投票决定填充色

**组合逻辑**：[填充](创新：填充颜色不由自身面积决定，而由空间邻居的"投票"集体决定) + [计数](创新：统计的不是分区数而是重叠邻域中的投票像素) + [面积排序→冲突仲裁](创新：面积不决定嵌套序，而是在重叠区域发生颜色冲突时充当仲裁权重)

**来源原语**：填充(fill, #3-84f2aca1), 封闭内部(enclosed_interior, #3), 面积阈值决定颜色(area_threshold_determines_color, #3), 计数(counting, #14-1190e5a7), 内部面积(interior_area, #3), 矩形边框(rectangular_frame, #3/#13), 边框包围内容(border_encloses_content, #13)

**依赖链**：各边框的空间重叠关系构成一张"邻接图"→ 每个边框收集自己和所有重叠邻居的投票 → 投票多数决定填充颜色 → 重叠区域由内部面积最大的边框"拥有"。这是一个同时约束满足结构：每个边框的填充取决于其邻居，不存在固定的线性处理顺序。

多个部分重叠的空心矩形边框各含一个投票像素，每个边框的填充色由自身及所有与它重叠的边框的投票多数决定。

**输入结构**：背景黑(0)，网格约 16x16。3~5 个不同颜色的单像素厚空心矩形边框（颜色从红(2)、绿(3)、蓝(1)、橙(7)、品红(6)中取，尺寸 5x5 到 8x8 不等），部分边框的内部区域在空间上有重叠（边框可以交叉，即一个边框的内部区域与另一个边框的内部区域共享若干像素）。每个边框内部（非重叠的部分）恰好有一个"投票像素"，颜色为灰(5)或青(8)。生成约束：所有边框都是完整的（无缺口）；每个边框至少与一个其他边框的内部区域有重叠；灰色和青色投票的数量不全相同（存在多数方）。

**规则**：
1. 识别每个完整同色矩形边框及其严格内部区域（边框像素不属于内部）。
2. 确定边框间的重叠关系：若两个边框的内部区域共享至少一个像素，则它们"重叠相邻"。
3. 对每个边框 F，收集 F 自身的投票像素颜色，以及所有与 F 重叠相邻的边框的投票像素颜色，形成投票集合。
4. 统计投票集合中灰(5)票数 vs 青(8)票数。若灰票 > 青票，将 F 的内部非重叠区域填充为灰(5)。若青票 > 灰票，填充为青(8)。若票数相等，填充为灰(5)（灰色平局优先）。
5. 对于重叠区域（属于两个或以上边框内部的像素）：由内部面积最大的边框"拥有"该区域，使用该边框的填充颜色涂色。若面积相同，由边框左上角更靠左上的边框拥有。
6. 投票像素本身保留原色不变。边框像素保留不变。

**关键洞察**：一个边框的填充色不由自身属性独立决定，而是由它的空间邻居"投票"集体决定——移动一个边框使其不再与某邻居重叠，可能改变双方的投票集合，导致两个边框的填充色同时翻转。这是一个非局部的、互相耦合的约束满足问题。

3. 对输入中每个黑(0)位置，输出对应的 3x3 块保持全黑。
4. 印章完成后，在 9x9 网格的第 0 行（最顶行）中，将每个黑(0)格放置一个红(2)水像素。
5. 模拟重力下落：每个红(2)水像素逐格向下移动穿过黑(0)格，遇到蓝(1)墙壁像素、其他已沉积的红(2)像素、或网格底边时停止。处理顺序：从最底行的红色像素开始向上逐行处理，同行从左到右。
6. 输出包含蓝(1)墙壁和红(2)沉积水像素的最终 9x9 网格。

**关键洞察**：互补关系产生了一个精妙的自矛盾——在某个 3x3 块中是墙壁的位置，在另一个块的对应位置恰恰是空隙（水源或通道）。3x3 图案越"满"（蓝色越多），印章模板越"空"（墙壁越少），导致水更容易流到底部；反之图案越"空"，墙壁越密，水被截留在高处。同一个图案的密度同时控制了两个相反的效果。

## 新题 11：种子周期竖线与端点拼接的交织约束

**组合逻辑**：[种子周期生成竖线](创新：多个种子各生成一组周期竖线段，段组之间不独立而需对齐拼接) + [端点匹配拼接](创新：拼接对象不是预存的路径片段，而是种子动态生成的竖线段组) + [滑动/平移](保留竖直位移语义，用于对齐)

**来源原语**：连线(draw_line, #6-8403a5d5), 种子像素(seed_pixel, #6), 竖线段(vertical_bar, #6), 周期间隔(periodic_space, #6), 种子周期生成竖线(seed_periodic_bars, #6), 拼接(concatenation, #8-d017b73f), 端点对齐(endpoint_align, #8), 端点匹配拼接(endpoint_match_concat, #8), 路径片段(path_segment, #8), 滑动(sliding, #8)

**依赖链**：每个种子的行位置和颜色→决定其竖线段组的高度分布和颜色→段组的左右边缘竖线的顶端像素作为"端点"→相邻段组通过端点行匹配来决定竖直位移量→位移后拼接。种子的行位置同时控制了"自身图案"和"与邻居的对接方式"。

每个种子像素生成一组周期竖线段，然后按端点高度匹配将各段组竖直对齐后水平拼接为连续图案。

**输入结构**：背景黑(0)，网格约 6x20。网格中有 3~4 个不同颜色的种子像素（颜色从蓝(1)、红(2)、绿(3)、橙(7)中取），分布在不同列且不同行上。种子之间由全黑列分隔（每两个种子之间至少隔 3 个空列）。生成约束：各种子行位置互不相同；每个种子右侧至少有 4 列空间用于生成竖线段。

**规则**：
1. 按列坐标从左到右排列种子像素。
2. 对每个种子，从种子所在列开始，每隔 2 列向右生成一条竖线段（共 3 条），颜色为种子颜色。每条竖线从种子所在行向上延伸至网格顶行（第 0 行）。在竖线之间的列上放置灰(5)标记像素，交替放在第 0 行和最底行。
3. 每个段组的"右端点"定义为其最右竖线的顶端像素行号（即种子所在行，因为竖线从该行向上延伸到第 0 行）。每个段组的"左端点"定义为其最左竖线的顶端像素行号（同理）。
4. 去除段组之间的全黑分隔列。从最左段组开始，保持其竖直位置不变。对后续每个段组：将其整体竖直平移，使其左端点行与前一个段组的右端点行相同。
5. 水平拼接所有段组（直接左右相邻，无间隔列）。若平移后某竖线超出网格上方，则截断超出部分；若竖线不足以到达第 0 行（平移向下），则竖线在其新起始行终止。
6. 输出为拼接后的网格。输出高度等于输入高度，输出宽度等于所有段组宽度之和。

**关键洞察**：种子所在行的差异不仅决定了各自竖线段的长度，还决定了段组之间的竖直位移量——一个种子在第 2 行、邻居在第 4 行意味着拼接时后者要上移 2 行。种子行位置同时编码了"图案高度"和"对接偏移"两层信息。

## 新题 12：噪声中检测大矩形后按侧边标记重涂区域

**组合逻辑**：[最大矩形检测/最小边长过滤](创新：检测出的矩形不是统一涂黄而是根据各自的侧边标记分别重涂为不同颜色) + [接触侧定色](创新：颜色不由矩形自身决定，而由紧贴其某侧的小标记像素决定) + [重涂色](保留语义但目标选择逻辑完全改变)

**来源原语**：重涂色(recolor, #2-c3fa4749 / #16-25094a63), 纯色实心矩形(solid_mono_rect, #16), 噪声背景(noisy_background, #16), 最小边长过滤(min_side_filter, #16), 最大矩形检测(max_rect_detection, #16), 侧边标记(side_marker, #2), 接触侧定色(contact_side_color, #2), 面板区域(panel_region, #2), 包含于(contained_in, #2)

**依赖链**：噪声过滤→检测大矩形→每个矩形恰好一侧有标记→标记颜色决定该矩形的重涂颜色。矩形检测提供"在哪里操作"，侧边标记提供"涂什么颜色"，两个信息来源缺一不可。

在噪声网格中找出所有边长>=4的纯色实心矩形，每个矩形按其紧邻一侧的标记像素颜色重涂。

**输入结构**：背景由多色噪声像素组成（随机分布的各色像素，但不含黄(4)），网格约 18x18。噪声中隐藏 2~4 个纯色实心矩形（每个矩形所有像素同色，颜色各不相同，如蓝(1)、绿(3)、品红(6)等），每个矩形的高和宽均 >= 4。每个矩形恰好一条边的外侧紧邻位置有一个黄(4)标记像素（标记像素在矩形边界外一格，与矩形边上某一像素 4-邻接），且该标记像素紧邻的边上只有这一个标记。标记像素不在任何矩形内部。每个矩形的标记所在侧不全相同（如一个在上侧，一个在左侧）。生成约束：矩形之间不重叠、不相邻；黄色标记不出现在噪声中；各矩形的边长互不完全相同（至少一个维度不同）。

**规则**：
1. 在噪声网格中检测所有最大同色矩形，且高和宽均 >= 4。"最大"指不能在四个方向中任何一个方向扩展（扩展后不再同色）。
2. 对每个检测到的矩形，找到其四条边外侧紧邻的所有黄(4)像素。每个矩形恰好有一个这样的黄色标记。
3. 确定标记在矩形的哪一侧（上/下/左/右）。
4. 根据标记所在侧确定重涂颜色：上侧标记 → 重涂为红(2)；下侧标记 → 重涂为橙(7)；左侧标记 → 重涂为灰(5)；右侧标记 → 重涂为青(8)。
5. 将该矩形的所有像素重涂为上述颜色。
6. 黄(4)标记像素保留。噪声背景和非矩形区域保持不变。

**关键洞察**：矩形的重涂颜色不由其自身颜色决定，而由标记在矩形哪一侧这个空间关系来决定——同一颜色的矩形如果标记在不同侧，会被涂成不同颜色。需要对比多个示例才能归纳出"侧→色"的映射规则（而非"原色→新色"的映射）。
