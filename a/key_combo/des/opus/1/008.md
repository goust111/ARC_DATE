## 新题 1：矩形格阵压缩与拉丁方补全

**组合逻辑**：[压缩compress + 筛选filter](已有) → [拉丁方约束latin_square_constraint + 补全completion](已有，创新：从物理矩形格阵中抽取抽象拉丁方，补全后反向映射回物理网格)

**来源原语**：压缩(compress), 筛选(filter), 填充矩形(filled_rectangle), 包围盒行列分组(bbox_row_column_grouping), 最小尺寸过滤(minimum_size_filtering), 忽略干扰项(ignore_distractors) ← 0a1d4ef5；补全(completion), 色表(color_table), 空白单元(blank_cell), 行列唯一约束(row_column_uniqueness_constraint), 拉丁方约束(latin_square_constraint) ← 4cd1b7b2

**依赖链**：必须先通过尺寸过滤排除干扰像素并识别有效的填充矩形，再按包围盒分组压缩为抽象色表，才能发现拉丁方约束结构。拉丁方补全后需将颜色反向映射回原始网格中的黑色矩形。若跳过筛选，干扰项混入格阵导致结构错误；若跳过压缩，无法看到行列唯一约束；若跳过补全，黑色矩形无法着色。

将散布在网格中的有效填充矩形压缩为抽象色表，补全其中的黑色空缺使之满足拉丁方约束，再将补全的颜色写回对应的原始矩形位置。

**输入结构**：网格约 20x20，背景为黑(0)。网格中散布着若干单色填充矩形（每个至少 3x3，4-连通，恰好填满其包围盒），共 K 种非黑前景色（K=4 或 5，颜色取自蓝(1)、红(2)、绿(3)、黄(4)、灰(5)），排列成 K x K 的格阵——同行矩形的包围盒垂直区间重叠，同列矩形的水平区间重叠。格阵中有 1~3 个位置的矩形颜色为黑(0)，表示空缺。已有颜色的矩形满足同行不重色、同列不重色。此外，网格中散布着若干面积小于 9 像素的杂色小块或孤立像素（干扰项），位于格阵矩形之间的空隙中。生成约束：空缺位置保证拉丁方补全唯一。

**规则**：
1. 识别所有 4-连通单色前景区域，仅保留恰好填满其包围盒且面积 >= 9 的区域作为有效填充矩形；其余视为干扰项忽略。
2. 按有效矩形的包围盒垂直中心分组为行，水平中心分组为列，得到 K x K 的抽象色表。
3. 黑(0)矩形在色表中对应空白单元。对色表执行拉丁方补全：每行每列恰好包含全部 K 种非黑前景色各一次，由此唯一确定每个空白单元的颜色。
4. 将补全得到的颜色填入原始网格中对应位置的黑色矩形区域（矩形的包围盒尺寸与相邻格阵成员对齐：宽度取同列有色矩形的宽度，高度取同行有色矩形的高度）。
5. 干扰像素保持原样不变。

**关键洞察**：物理网格中散乱的矩形和干扰项需要经过尺寸筛选和空间压缩后，才能暴露出隐含的拉丁方代数结构；补全在抽象层面进行，结果反投射到物理空间——这是两个不同表征层面之间的信息往返。

## 新题 2：路径色序反转生成滑动坐标映射

**组合逻辑**：[端到端遍历endpoint_traversal + 颜色序列反转reverse_color_seq](已有，创新：反转后的序列不写回路径而是作为空间坐标映射表) → [滑动slide + 颜色编码列color_coded_col](已有，创新：目标列由外部反转序列逐行指定)

**来源原语**：单像素宽路径(one_pixel_path), 端点像素(endpoint_pixel), 端到端遍历(endpoint_traversal), 颜色序列反转(reverse_color_seq), 形状不变仅反色序(shape_fixed_reversed) ← 5792cb4d；边缘像素(edge_pixel), 滑动(slide), 颜色编码列(color_coded_col), 颜色决定目标列(color_determines_col) ← f45f5ca7

**依赖链**：路径的颜色序列必须先被遍历并反转，反转后的序列才能充当逐行的列地址映射表。路径方向决定了遍历顺序，反转改变了映射内容。若跳过反转，滑动目标全部错位；若没有路径，无法生成映射；若路径未被擦除，输出中会残留多余像素。

沿路径遍历并反转其颜色序列，将反转后的序列作为逐行的列地址，把顶行前景像素滑动到对应行列交叉点。

**输入结构**：网格约 10x10，背景为黑(0)。左侧第 0 列有一条垂直的单像素宽 4-连通路径（从第 1 行到第 N 行，N <= 8），路径像素由 K 种不同颜色组成（K >= 3，颜色取自蓝(1)、红(2)、绿(3)、黄(4)），每种颜色在路径中至少出现一次，路径恰好有两个端点（顶端和底端），无分支。顶行（第 0 行）在第 1 至第 K 列各有至多一个前景像素（颜色各异，与路径中出现的颜色集合相同）。颜色与目标列的固定对应关系：颜色编号等于目标列号（蓝(1) 对应列 1，红(2) 对应列 2，以此类推）。生成约束：路径长度等于顶行前景像素数量；路径中出现的颜色集合与顶行前景像素的颜色集合完全相同。

**规则**：
1. 沿路径从顶端（行号最小的端点）到底端遍历，记录颜色序列 S = [c1, c2, ..., cN]。
2. 反转序列得到 S' = [cN, ..., c2, c1]。
3. 对路径的第 i 个位置（从顶端起计，i = 1..N），读取 S'[i] 的颜色值 c，该颜色对应目标列号（列号 = 颜色编号）。
4. 将顶行中颜色为 S'[i] 的前景像素移动到第 i 行、第 c 列（列号 = S'[i] 的颜色编号）。
5. 擦除路径所有像素（变为背景黑(0)）。
6. 擦除顶行原位置的已移走前景像素。

**关键洞察**：路径本身不是输出的一部分——它是一段被读取后丢弃的指令序列；反转操作改变的不是路径上的颜色（源题 5792cb4d 中反转后写回路径），而是另一组独立对象的空间目的地，使得同一个"颜色序列反转"原语产生了完全不同的语义。

## 新题 3：精灵体镜像后由边界标记邻接传色

**组合逻辑**：[镜像位置mirrored_position + 平移translate](已有) → [邻接传色adjacency_transfer + 标记接触即赋色marker_touch_color](已有，创新：邻接关系仅在镜像后才存在) + [擦除erase](已有)

**来源原语**：精灵体(sprite), 镜像位置(mirrored_position), 平移(translate), 内部朝向不变(orientation_preserved) ← 8ee62060；标记像素(marker_pixel), 中性遮罩(neutral_mask), 邻接传色(adjacency_transfer), 标记接触即赋色(marker_touch_color), 擦除(erase) ← b7256dcd；边界矩形(boundary_rectangle), 贴边定位(border_aligned) ← 22208ba4

**依赖链**：精灵体必须先被镜像到新位置，才能判断哪个边界标记与哪个精灵体 4-邻接。邻接关系在镜像前不存在——输入中精灵体在左半区、标记在最右列，两者距离很远。标记的颜色决定了精灵体的最终颜色，但标记自身在传色后被擦除。若跳过镜像，传色无法发生；若跳过传色，精灵体保持中性色无法区分。

将灰色精灵体水平镜像到网格对侧，通过与右边界上的彩色标记像素的邻接关系获取颜色，然后擦除原始精灵体和标记。

**输入结构**：网格约 12x12，背景为黑(0)。网格左半区有 2~4 个小型 4-连通精灵体（每个 3~6 像素，形状为不规则连通块——非简单矩形，可能有凸起或缺角），全部为灰(5)色，精灵体之间互不相邻。每个精灵体的包围盒为 2x2 或 2x3。网格最右列（第 W-1 列）上有若干彩色单像素标记（颜色各异，取自蓝(1)、红(2)、绿(3)、黄(4)），每个标记占一个单元格。标记的行位置经过精心放置：当精灵体水平镜像后（new_col = grid_width - 1 - old_col），恰好有一个标记与镜像后的精灵体 4-邻接。生成约束：镜像后每个精灵体恰好与一个标记邻接，每个标记恰好对应一个精灵体，标记不出现在精灵体镜像后的占位区域内，各精灵体镜像后互不重叠。

**规则**：
1. 对每个灰(5)色精灵体，保持其内部像素布局不变，将其包围盒水平镜像到网格对侧：每个像素的新列号 = grid_width - 1 - 原列号，行位置不变。
2. 对每个镜像后的精灵体，检查其所有像素的 4-邻居中是否有最右列上的彩色标记像素。若有，将该精灵体的所有像素重涂为该标记的颜色。
3. 擦除所有标记像素（变为背景黑(0)）。
4. 擦除原始位置（左半区）的灰色精灵体像素（变为背景黑(0)）。

**关键洞察**：标记像素在输入中与精灵体相距甚远，只有执行镜像操作后两者才形成 4-邻接关系——邻接是镜像的"涌现副产品"而非输入中预先存在的空间关系，这使得两个独立原语产生了结构依赖。

## 新题 4：嵌套空心框深度编码精灵体放大倍率

**组合逻辑**：[包含containment + 空心矩形hollow_rectangle](已有) → [裁剪crop](已有) + [像素放大pixel_upscale](已有，创新：倍率不是色数而是嵌套深度) + [计数counting](已有，创新：计数对象是层级关系而非颜色种类)

**来源原语**：空心矩形(hollow_rectangle), 内部区域(interior_region), 包含(containment), 裁剪(crop), 最大边框内部提取(largest_frame_interior_extract) ← 1c786137；空心矩形(hollow_rectangle), 中心标记(center_marker), 填充(fill), 按边长映射颜色(size_to_color_mapping), 标记在框内居中(marker_centered_inside_frame) ← 00dbd492；像素放大(pixel_upscale), 计数(counting), 整体缩放(uniform_scale), 色数决定倍率(color_count_scale) ← d4b1c2b1

**依赖链**：必须先建立框的包含层级才能算出嵌套深度 D；D 直接决定放大倍率；被放大的内容是最内层框的内部图案。若跳过层级分析，无法获得倍率；若跳过裁剪，不知道放大什么；若跳过放大，输出尺寸错误。三个环节的信息依赖不可跳过。

检测同心嵌套的空心矩形框的层数，裁剪最内层框的内容，以嵌套层数为倍率进行像素放大输出。

**输入结构**：网格约 20x20，背景为黑(0)。网格中有一组同心嵌套的空心矩形框（2~4 层），每层框的边框颜色各不相同（从蓝(1)、红(2)、绿(3)、黄(4)中选取）。框均为单像素厚的闭合矩形边框。最外层框不一定居中于网格。各层框之间有 >= 1 像素的黑色间距。最内层框的严格内部区域包含一个小型多色图案（2x2 或 3x3 像素，颜色各异，取自灰(5)、品红(6)、橙(7)、青(8)等，不与框色重复）。生成约束：框严格嵌套——每层框完全在外层框的内部区域内，内外层框不共享像素。

**规则**：
1. 识别所有闭合的单像素厚空心矩形框（4-连通边框像素，包围盒内非边框像素为内部）。
2. 建立包含层级：若框 A 的所有像素均在框 B 的内部区域内，则 A 被 B 包含。计算嵌套深度 D = 从最外层到最内层的总层数（例如 3 层嵌套则 D = 3）。
3. 裁剪最内层框的严格内部区域（不含边框像素），得到小型图案 P。
4. 将图案 P 进行像素放大：每个像素替换为 D x D 的同色实心方块，得到放大后的图案 P'。
5. 输出 P'（尺寸为原图案宽度 x D 乘以原图案高度 x D）。

**关键洞察**：嵌套空心框不是装饰——其层数编码了一个数值参数（放大倍率），而被放大的内容藏在最深层框的腔室中；源题 d4b1c2b1 中倍率来自色数，源题 00dbd492 中框的边长映射颜色，这里层级深度替代了两者的角色，在包含关系和缩放操作之间建立了新的结构依赖。

## 新题 5：指示像素定向边界矩形对角平移与重叠冲突着色

**组合逻辑**：[边界矩形boundary_rectangle + 贴边定位border_aligned](已有) + [象限指示方向quadrant_indicates_dir](已有，创新：指示像素决定矩形移动方向而非射线方向) → [平移translate](已有，创新：方向由外部指示像素决定而非固定向内) + [异源交叉特殊着色cross_source_special_color](已有，创新：重叠区域而非线交叉点着色)

**来源原语**：边界矩形(boundary_rectangle), 重复色对象(repeated_color_obj), 贴边定位(border_aligned), 平移(translate), 重复色才移动(repeated_color_moves) ← 22208ba4；中心像素(center_pixel), 对角象限(diagonal_quadrant), 象限指示方向(quadrant_indicates_dir), 同色像素定角(same_color_corner) ← 252143c9；标记像素(marker_pixel), 射线延伸(ray_extend), 行列交叉(row_column_crossing), 异源交叉特殊着色(cross_source_special_color) ← 45bbe264

**依赖链**：必须先找到每个边界矩形的同色指示像素，由指示像素相对于矩形中心的象限确定对角移动方向。平移后可能产生重叠，重叠区域需要特殊着色。若没有指示像素，方向不可知（源题 22208ba4 中方向由贴边位置隐含决定，这里被解耦了）；若跳过重叠检测，两个矩形共占的区域颜色不确定。

每个贴边彩色矩形根据其同色指示像素所在象限的方向做对角平移，重叠区域涂为红色。

**输入结构**：网格约 15x15，背景为黑(0)。网格的四角或四边各有一个单色填充矩形（共 2~4 个，每个约 2x3 或 3x3 像素），每个矩形的颜色互不相同（从蓝(1)、绿(3)、黄(4)、橙(7)中选取），且至少一条边紧贴网格边界。对每个边界矩形 R，网格中另有一个同色的单像素（指示像素 P），位于 R 的包围盒中心的某个对角方向上（左上、右上、左下、右下之一），不与任何矩形重叠，也不在网格边界上。生成约束：每个矩形恰有一个同色指示像素；各矩形按指示方向平移后，至少有一对矩形产生重叠区域（面积 >= 1 像素）；平移距离分别为水平方向等于矩形宽度、垂直方向等于矩形高度。

**规则**：
1. 对每个贴边矩形 R，找到与其同色的唯一单像素 P。
2. 确定 P 相对于 R 包围盒中心的对角象限（左上、右上、左下、右下）。
3. 将 R 沿该对角方向平移：水平位移 = R 的宽度（象限在左侧则向左，右侧则向右），垂直位移 = R 的高度（象限在上方则向上，下方则向下）。擦除 R 的原始位置。

5. 擦除所有指示像素（变为背景色）。

**关键洞察**：源题 22208ba4 中矩形总是向内移动（方向由贴边位置隐含决定），本题将方向编码解耦为独立的指示像素——同一个"象限→方向"映射机制从源题 252143c9 的射线语境移植到矩形平移语境中，且重叠冲突着色创造了源题中不存在的多对象交互。

1. 将灰(5)像素视为遮蔽标记。利用所有非灰像素检测底层图案的平移对称性（最小水平周期 Px 和垂直周期 Py）。

**关键洞察**：框的内部可以直接看到一部分颜色，但仅凭可见内部像素无法确定色种计数是否完整——边框覆盖的像素在恢复后可能引入内部不存在的新颜色，因此必须先通过对称恢复透视边框下的图案才能正确计数。这使得"恢复"不是为了获取内容本身（内容最终被填充覆盖），而是为了获取一个统计属性。

**规则**：

4. 从起点沿路径遍历到终点，依次将路径像素重涂为序列 C 中的颜色——第 1 个路径像素涂 c1，第 2 个涂 c2，...，第 M 个涂 cM，第 M+1 个回到 c1 循环，以此类推直到路径末端。
5. 擦除所有贴边矩形（变为背景黑(0)）。干扰像素保持不变。

**关键洞察**：矩形和路径在空间上完全独立——矩形在边界、路径在中央。它们通过一个抽象的信息通道连接：矩形的面积属性决定了颜色的排列顺序，路径的拓扑结构决定了这个顺序被写到哪些位置。两者缺一则信息链断裂。
