## 新题 1：叶突选行列 + 周期修缺口

**组合逻辑**：[突起定行列](已有) → [选择性补全](创新：原"补全"作用于全局，现仅作用于叶突选中的行/列) → [擦除](已有)

**来源原语**：突起定行列/leaf_selects_row_col（参考题 f1cefba8）、补全/complete + 周期对齐/periodic_align + 最小周期修复缺口/min_period_repair_gap（参考题 e95e3d8e）、擦除/erase（参考题 f1cefba8）、叶状突起/leaf_protrusion（参考题 f1cefba8）、双色矩形/bicolor_rectangle（参考题 f1cefba8）、周期瓦片/periodic_tile（参考题 e95e3d8e）

**依赖链**：叶突的朝向决定选中哪些行/列 → 只有位于选中行或选中列上的黑色缺口才执行周期修复 → 其余缺口保持黑色；叶突在输出中被擦除。周期分析和叶突检测互相独立，但两者缺一不可：缺少叶突检测则不知修复哪些位置，缺少周期分析则不知填什么颜色。

将叶突标记的行列选择功能与周期瓦片修复结合：叶突选中行/列上的缺口被周期瓦片填补，未选中位置的缺口保持不变，叶突本身被擦除。

**输入结构**：约 14x14 网格，黑(0)背景。网格中有一个约 8x10 的矩形区域，其 1 像素厚的边框为橙(7)色。矩形内部存在由蓝(1)和红(2)两色构成的二维周期图案（最小周期矩形约 2x2 或 2x3），但部分内部像素为黑(0)（缺口）。矩形边框外侧有 2~4 个橙(7)色叶状突起像素，每个突起恰好 4-邻接矩形边框的一个像素且不与其他突起相邻。生成约束：每个叶突在边框内侧的唯一非背景 4-邻居决定它选行还是选列（该邻居在突起的正上方或正下方 → 选列；在正左方或正右方 → 选行）；不同示例中叶突数量和位置不同，且至少有一个缺口既不在任何选中行也不在任何选中列上（用于区分"全修复"和"选择性修复"）。

**规则**：
1. 识别矩形边框外的所有橙(7)叶状突起像素。对于每个突起，检查其在矩形边框内侧的唯一 4-邻居方向：若该邻居在突起的正上方或正下方，则该突起选中其所在列；若在正左方或正右方，则选中其所在行。
2. 计算矩形内部非黑像素的最小面积周期矩形（行周期 pr、列周期 pc）。对每个非黑内部像素 (r, c)，其颜色 = tile[r mod pr][c mod pc]。
3. 对矩形内部的每个黑(0)像素 (r, c)：若 r 所在的行被某个叶突选中，或 c 所在的列被某个叶突选中，则将该像素替换为 tile[r mod pr][c mod pc]。否则保持黑(0)不变。
4. 将所有叶状突起像素重涂为黑(0)。
5. 其余像素（边框、背景、已有非黑内部像素）保持不变。

**关键洞察**：叶突不是标记要切割或延伸的行列（如参考题 f1cefba8），而是充当周期修复的空间门控——只有被叶突"点名"的行或列上的缺口才能获得修复，这在任何单一参考题中都不存在。

## 新题 2：噪点邻接过滤 + 双轴对称补全

**组合逻辑**：[邻接够归并否则删](已有) → [对称补全](已有，但输入形状经噪点过滤改变) ← 噪点分类结果实质性改变了待镜像的形状（创新耦合点）

**来源原语**：重涂色/recolor + 擦除/erase + 噪点/noise_pixel + 邻接/adjacency + 邻接够归并否则删/merge_or_delete（参考题 7e0986d6）、对称补全/symmetry_completion + 标记方块/marker_square + 对称中心/symmetry_center + 标记定义双轴镜像/marker_biaxial_mirror（参考题 4938f0c2）

**依赖链**：噪点过滤改变前景形状的边界像素 → 被吸收的噪点在镜像阶段参与反射（出现在四个象限）→ 被删除的噪点不参与反射（对应位置保持空白）。过滤和镜像不可分离：跳过过滤则噪点被错误镜像，跳过镜像则形状不完整。

噪点像素根据前景邻居数量被吸收为前景或被删除，过滤后的形状以绿色标记方块中心为轴做双轴对称补全。

**输入结构**：约 13x13 网格，黑(0)背景。网格中有一个绿(3)色实心 2x2 标记方块。红(2)色前景像素分布在标记方块周围的一个或两个象限中，形成一个不规则的 4-连通单色区域（3~10 像素）。另有 3~6 个黄(4)色噪点像素散落在红色形状附近：部分噪点的 4-邻居中有 2 个或更多红(2)像素（紧贴形状边缘），其余噪点的红色 4-邻居少于 2 个（远离形状或仅单点接触）。生成约束：至少有一个噪点被吸收、至少有一个噪点被删除，以使两种情况在示例中均可观察；红色前景不覆盖绿色标记方块的任何像素；不同示例中噪点位置不同，使得吸收/删除的决策可被归纳。

**规则**：
1. 对每个黄(4)像素，统计其 4-邻居中红(2)像素的数量。
2. 若红色邻居数 >= 2，将该黄像素重涂为红(2)（吸收入前景形状）。
3. 若红色邻居数 < 2，将该黄像素重涂为黑(0)（删除）。
4. 以绿(3) 2x2 标记方块的几何中心（四个格子的交点）为水平和垂直镜像轴，对每个红(2)像素进行双轴反射：绘制其水平镜像、垂直镜像和 180 度旋转镜像，均涂红(2)。反射像素落在绿色标记方块上时不覆盖标记（绿色保留）。
5. 输出网格尺寸与输入相同，保留绿色标记方块，黑色背景不变。

**关键洞察**：噪点过滤不是一个独立的预处理步骤——被吸收的噪点像素会出现在最终四个象限中（通过镜像放大），而被删除的噪点不会，因此噪点分类的每一个决策都被镜像操作放大为四倍的视觉差异。

## 新题 3：条计数驱动同心层深度

**组合逻辑**：[计数](已有) → [同心层填充](创新：原同心填充铺满整个内部，现由外部条的像素计数限制填充层数) + [按距离循环配色](已有) + [擦除](已有)

**来源原语**：计数/counting + 条形段/bar_segment + 相邻接触/adjacent_touch + 像素数转为条纹/pixels_to_stripes（参考题 d93c6891）、同心层填充/concentric_fill + 空心矩形/hollow_rectangle + 同心正方形层/concentric_layer + 嵌套层次/nesting_hierarchy + 按距离循环配色/distance_color_cycling（参考题 a3f84088）、擦除/erase（多题）

**依赖链**：灰色条的像素计数 N 不再转化为条纹宽度，而是限制空心矩形内部同心层的绘制深度——从外向内只画 N 层，其余保持黑色。同一个 N 在大矩形上只涂外围几层（大部分内部仍空），在小矩形上可能填满整个内部。计数和同心填充的交互产生了"部分填充"这一在任何参考题中都不存在的模式。

灰色条触碰空心矩形框，其像素数量决定框内部从外向内绘制多少层同心方环；未被条触碰的框保持中空。

**输入结构**：约 18x18 网格，黑(0)背景。网格中有 3~4 个灰(5)色空心矩形框（每个框为 1 像素厚的矩形边框，框尺寸各异，最小约 5x5，最大约 11x11，框之间互不重叠且不相邻）。部分框的外侧有灰(5)色一像素粗的条形段（水平或垂直），每条恰好 4-邻接一个框的外边缘像素。每个框至多被一条触碰，至少有一个框不被任何条触碰。生成约束：条的像素数量范围为 2~5；至少有一个框足够大使得条计数小于其可容纳的最大层数（产生部分填充），以及一个框足够小使得条计数大于或等于其最大层数（产生满填充），以便区分两种情况。

**规则**：
1. 识别所有灰(5)空心矩形框和所有灰(5)条形段。条形段定义为不属于任何框边缘的灰色 4-连通线段（水平或垂直）。
2. 对每条灰色条，找到其 4-邻接的框，统计该条的像素数 N。
3. 将所有条形段重涂为黑(0)（擦除）。
4. 对每个被条触碰的框，保留其灰色边框，从边框向内逐层绘制同心方环。第 k 层（k 从 1 开始计，k=1 是紧贴边框的最内层）的颜色按循环 [灰(5), 红(2), 灰(5), 黑(0)] 确定，即 color = cycle[(k-1) mod 4]，其中 cycle = [5, 2, 5, 0]。只绘制 k = 1 到 k = N 的层；k > N 的层保持黑(0)。
5. 未被任何条触碰的框保持原样（空心，内部黑色）。
6. 若 N 大于框能容纳的最大层数 M（M = min(框宽, 框高) / 2 - 1，因为边框本身占一层但不计入 N），则只绘制到第 M 层为止（多余的 N 值无效果）。

**关键洞察**：条的像素计数不是铺设条纹（如参考题 d93c6891），而是控制同心层的绘制深度——同一个计数 N 在不同尺寸的框中产生截然不同的填充比例，因此求解者必须同时理解"计数 → 层数"和"层数与框尺寸的交互"两层逻辑。

## 新题 4：象限编码旋转 + 图例模板扩展

**组合逻辑**：[象限对应](已有) ← 决定放置位置与旋转角度（创新：原象限仅决定位置，现同时编码旋转） → [颜色到模板映射](已有) → [像素放大/pixel_expand](已有)

**来源原语**：锚定方块/anchor_square + 散落单像素/singleton_pixel + 象限对应/quadrant_correspondence + 象限决定目标格/quadrant_target_cell（参考题 d89b689b）、色卡/color_swatch + 模板遮罩/stencil_mask + 颜色到模板映射/color_stencil_map + 顺序配对/ordered_pairing + 像素放大/pixel_expand（参考题 42f83767）

**依赖链**：单像素的颜色通过图例查找配对的模板遮罩 → 单像素相对于锚定方块的象限同时决定两件事：(a) 该模板放在输出 2x2 布局的哪个格子，(b) 模板按该象限对应的角度旋转。颜色和象限是同一个单像素携带的两个独立信息通道，缺少任一通道都无法确定输出。

散落在锚定方块四象限的单色像素，其颜色在图例中查找配对的非对称模板遮罩，其象限同时决定模板在输出中的放置位置和顺时针旋转角度，最终拼成一个 2x2 模板组合。

**输入结构**：约 16x16 网格，黑(0)背景。网格中心偏下区域有一个灰(5)色实心 2x2 锚定方块。四个不同颜色的单像素分别位于锚定方块的四个象限（左上、右上、右下、左下），每个象限恰好一个，颜色从 {蓝(1), 红(2), 绿(3), 黄(4)} 中取四个不同值。网格上方有一个图例面板：图例由 4 行组成，每行包含左侧一个 1x1 色卡像素（颜色为蓝/红/绿/黄之一）和右侧间隔 1 列的一个 3x3 非对称模板遮罩（模板中活跃像素为品红(6)，非活跃像素为黑(0)；每个模板在 0/90/180/270 度旋转下形状均不同，即无旋转对称性）。每行色卡颜色与 4 个单像素颜色一一对应。生成约束：4 个模板互不相同且均无旋转对称性；每个示例中 4 个单像素的象限分配不同，以便归纳象限-旋转映射规则。

**规则**：
1. 对每个单像素，确定其相对于锚定方块中心的象限：左上(UL)、右上(UR)、右下(LR)、左下(LL)。
2. 在图例中查找该单像素颜色对应的 3x3 模板遮罩。
3. 根据象限旋转模板：UL → 0 度（不旋转）；UR → 顺时针 90 度；LR → 180 度；LL → 顺时针 270 度。
4. 将旋转后的模板放置在输出 6x6 网格（2x2 个 3x3 块）的对应位置：UL 象限的单像素 → 左上 3x3 块，UR → 右上，LR → 右下，LL → 左下。模板中品红(6)像素重涂为该单像素的颜色，黑(0)像素保持黑色。
5. 输出为拼合后的 6x6 网格。原始输入中的锚定方块、单像素和图例均不出现在输出中。

**关键洞察**：象限不仅仅决定"把什么放在哪里"（如参考题 d89b689b），还同时编码了模板的旋转角度——同一个颜色的模板在不同象限产生不同的朝向，使得输出的四个块形成围绕中心的旋转协调。这种"位置即旋转参数"的双重编码在两道参考题中均不存在。

## 新题 5：种子周期生长 + 标记邻接选裁

**组合逻辑**：[射线延伸/种子周期生长](已有) → 生长创建新的空间邻接 → [标记选中邻接体](创新：标记不接触原始种子，而是接触生长出的轨迹像素) → [裁剪](已有)

**来源原语**：射线延伸/ray_extend + 孤立像素/isolated_pixel + 轨迹/trail + 对角偏移/diagonal_offset + 种子周期生长/seed_periodic_growth（参考题 3ac3eb23）、裁剪/crop + 标记像素/marker_pixel + 邻接接触/adjacency_contact + 标记选中邻接体/marker_selects_neighbor（参考题 48d8fb45）

**依赖链**：种子生长在网格中创建不存在于输入中的轨迹像素 → 灰色标记像素 4-邻接某个轨迹像素而非种子本身 → 被接触的轨迹确定来源种子 → 裁剪该种子的完整轨迹图案输出。生长步骤创建了标记选择所依赖的邻接关系——不做生长则标记不接触任何对象，不做选择则不知输出谁的轨迹。

多个种子像素向下生长出周期-2 对角轨迹图案；一个灰色标记像素接触某条轨迹（非种子本身），标记所接触轨迹的来源种子的完整图案被裁剪输出。

**输入结构**：约 15x20 网格（高 > 宽），黑(0)背景。顶部 1~3 行散布 3~4 个孤立的不同颜色单像素作为种子（如蓝(1)、红(2)、绿(3)、黄(4)），种子之间水平间隔至少 4 列以避免轨迹重叠。网格中部偏下某处有一个灰(5)像素作为标记。生成约束：种子生长出的轨迹（从种子位置及其四个对角邻居起，每隔 2 行向下延伸一个像素）在到达灰色标记行时，恰好有一个种子的轨迹像素与灰色标记 4-邻接；其余种子的轨迹在标记行附近均不与标记 4-邻接。不同示例中标记位置不同，选中不同种子。

**规则**：
1. 识别所有孤立的非灰非黑单像素作为种子。
2. 对每个种子 (sr, sc)，生长轨迹：初始 5 个起点为 (sr, sc)、(sr-1, sc-1)、(sr-1, sc+1)、(sr+1, sc-1)、(sr+1, sc+1)。对每个起点 (r0, c0)，向下每隔 2 行放置一个同色像素：(r0, c0), (r0+2, c0), (r0+4, c0), ...，直到超出网格边界。所有轨迹像素使用种子颜色绘制。
3. 找到与灰(5)标记像素 4-邻接的轨迹像素，确定该轨迹像素的种子来源。
4. 计算该种子所有轨迹像素（含种子本身）的最小边界框，裁剪该边界框区域作为输出。裁剪区域中不属于该种子轨迹的像素（包括其他种子的轨迹和灰色标记）均置为黑(0)。
5. 输出为裁剪后的矩形网格。

**关键洞察**：灰色标记不接触任何输入中已存在的对象——它只与生长过程中产生的轨迹像素相邻。因此选择操作依赖于一个"尚不存在"的邻接关系，只有完成所有种子的生长后才能确定灰色标记选中了谁。

## 新题 6：L 标记放大 + 缺角印章级联

**组合逻辑**：[像素放大](创新：L 标记不扩展到网格外角，而是按三角标记框的边长缩放) → 扩展结果充当印章原型 → [印章覆盖 + 缺角决定翻转](已有)

**来源原语**：像素放大/pixel_scale + 角落标记/corner_marker + 朝向对应角/facing_corner + 扩展至外角/expand_to_corner（参考题 b745798f）、印章覆盖/stamp + 精灵体/sprite + 三角标记框/three_corner_frame + 缺角定位/missing_corner_pos + 缺角决定翻转/flip_by_missing_corner + 镜像/mirror（参考题 ac0c5833）

**依赖链**：3 像素 L 标记的朝向确定"基准角"（源象限方向） → L 被缩放为与三角框边长匹配的角 L 形状（臂长 = 框边长 - 1） → 该角 L 成为精灵体原型 → 对每个三角框，在其缺角位置放置精灵体，根据缺角象限相对于基准角的关系进行反射。L 标记既是方向种子又是形状原型，三角框既提供放置位置又决定缩放比例。

一个 3 像素 L 标记按三角标记框的尺寸缩放为角 L 精灵体，然后以该精灵体为原型，在每个三角框的缺角位置放置反射副本。

**输入结构**：约 17x17（奇数正方形）网格，黑(0)背景。网格中有一个红(2)色 3 像素 L 形标记，占据一个 2x2 区域中的三个像素（如左上角缺失则 L 朝右下）。另有 2~4 个黄(4)色三角标记框，每个框由三个黄色单像素组成，标记同一正方形的三个角（正方形边长 S 一致，约 5~7；所有框相同边长）。每个三角框恰好缺一个角，缺角位置各不相同（有的缺左上，有的缺右下等）。框之间互不重叠，且有足够空间容纳放置的精灵体。生成约束：红色 L 标记的位置远离所有三角框（不与任何框的缺角区域重叠）；L 标记的臂长为 1 像素（原始 3 像素），缩放后臂长为 S-1。

**规则**：
1. 识别红(2)色 3 像素 L 标记，确定其朝向（L 的"开口"方向对应其在 2x2 盒中的缺失角，即源象限方向：若缺左上角 → 开口朝左上 → 源角为左上）。
2. 确定三角框的统一边长 S。将红色 L 标记按比例缩放：臂长从 1 变为 S-1，形成一个占据 S x S 区域中一个角落的角 L 形状（沿两条边各 S-1 个像素加上角顶点，总像素 = 2*(S-1)-1）。此缩放 L 的朝向与原始 L 一致，颜色为红(2)。
3. 对每个三角框，确定其缺角位置（左上/右上/左下/右下）。
4. 将缩放 L 放置在缺角位置的 S x S 区域内，使 L 的角顶点与缺角重合。若缺角象限与源象限相同，直接放置；若水平翻转，则水平反射 L；若垂直翻转，则垂直反射；若对角翻转（180 度），则水平+垂直反射。放置颜色为红(2)。
5. 擦除原始红色 L 标记（重涂为黑(0)）。黄色三角标记像素保留。
6. 放置区域中若有黄色标记像素，红色覆盖黄色（红色优先）。

**关键洞察**：小 L 标记不是被放大到网格角落（如参考题 b745798f），而是被缩放到与三角框匹配的尺寸后充当印章原型——L 的朝向决定"默认姿态"，每个三角框缺角的方向决定该处副本需要哪种反射，因此同一原型在不同框产生不同朝向的副本。

## 新题 7：重叠框交叉深度推断 + 分层填充

**组合逻辑**：[嵌套层次](创新：从嵌套改为部分重叠的深度推断) ← 边框交叉点的可见颜色揭示前后关系 → [填充](已有) + [冲突优先级](已有，但优先级来源从图例顺序改为几何推断)

**来源原语**：空心矩形/hollow_rectangle + 嵌套层次/nesting_hierarchy（参考题 a3f84088）、填充/fill + 冲突优先级/conflict_priority + 图例顺序决定层级/legend_order_layer（参考题 305b1341）、重涂色/recolor（多题）

**依赖链**：多个空心矩形框部分重叠 → 边框交叉点处只有一个颜色可见（前景框遮住背景框） → 从交叉点可见色推断所有框的前后深度全序 → 按深度从后到前填充框内部 → 前方框的填充覆盖后方框的填充。这不是流水线——深度推断是一个图上的拓扑排序，需要汇总所有交叉点的证据才能得出全序。

多个不同颜色的空心矩形框部分重叠，通过观察边框交叉处哪个颜色可见来推断框的前后深度顺序，然后按从后到前的顺序用各框颜色填充其内部。

**输入结构**：约 15x15 网格，黑(0)背景。网格中有 3~4 个 1 像素厚的空心矩形框，每个框使用不同颜色（如蓝(1)、红(2)、绿(3)、黄(4)），框尺寸各异（约 5x5 到 9x9）。框之间部分重叠：每对重叠的框的边框至少共享一个网格单元（即两个框的边框经过同一个像素位置）。在每个这样的共享位置，只显示"前方"框的颜色（后方框的边框像素被遮挡，该位置只有前方颜色）。每个框的非重叠边框部分正常显示该框颜色。生成约束：所有框对之间的深度关系构成一个无环全序（即存在唯一的从最前到最后的排列）；每对相邻深度的框至少有一个边框交叉点可供观察（保证深度可推断）；框的内部在输入中均为黑(0)。

**规则**：
1. 识别所有空心矩形框。每个框由其颜色、边界框坐标定义。注意：某些边框像素位置被其他框的颜色覆盖（该位置的颜色不是本框颜色，但该位置在本框的几何边框上）。
2. 对每个边框共享位置（两个或更多框的边框经过同一像素），该位置的可见颜色属于"前方"框。据此建立框对之间的"A 在 B 前方"有向关系。
3. 对所有框进行拓扑排序，得到从最后（最深）到最前（最浅）的唯一全序。
4. 按深度从后到前依次处理每个框：将框的内部区域（边框围成的矩形内所有非边框像素）填充为该框的颜色。后处理的框（更前方）的填充覆盖先处理的框（更后方）的填充。
5. 所有框的边框保持原样（前方框的边框颜色覆盖后方框的边框颜色，与输入一致）。
6. 不属于任何框的内部或边框的背景像素保持黑(0)。

**关键洞察**：深度顺序不是由外部图例或颜色编号给出的——它隐含在边框重叠的遮挡关系中，求解者必须检查多个交叉点并传递性地推断出全序。这是一个"输入结构本身编码规则参数"的约束满足问题，而非线性流水线。

## 新题 8：精灵体对接改变条周期 + 周期填缺

**组合逻辑**：[对接 + 色彩互换](已有) → 对接改变条的色彩序列 → [补全/周期修缺](创新：周期分析的输入包含对接引入的新像素，周期因此改变) + [擦除](已有)

**来源原语**：对接/dock + 色彩互换/color_swap + 双色精灵体/two_tone_sprite + 色条/color_bar + 同色匹配/same_color_matching + 颜色反转映射/inverted_color_mapping（参考题 7c66cb00）、补全/complete + 周期瓦片/periodic_tile + 周期对齐/periodic_align + 缺失像素/missing_pixel + 最小周期修复缺口/min_period_repair_gap（参考题 e95e3d8e）、擦除/erase（多题）

**依赖链**：精灵体按颜色匹配对接入色条并完成色彩互换 → 对接后的色条包含互换后的新颜色，改变了条的一维周期结构 → 用新周期填充条中剩余的黑色缺口。对接和填充不可独立运行：不做对接则条的周期是原始的（缺少精灵体引入的颜色），填出的结果错误；不做填充则条有缺口，输出不完整。

双色精灵体按外色匹配对接入对应水平色条并进行色彩互换，对接后色条的颜色序列形成新的一维周期，用该周期修复条上的黑色缺口。

**输入结构**：约 12x18 网格（宽 > 高），黑(0)背景。下半区有 2~3 条水平色条，每条占一行，跨越大部分列（约 12~16 列），每条有一个填充色和一个边框色（两端各 1~2 像素为边框色，中间为填充色），部分中间像素为黑(0)（缺口）。上半区有 2~3 个双色精灵体（每个为 1x2 或 2x1 的小图形，外色 1 像素 + 内色 1 像素）。每个精灵体的外色等于某条色条的填充色（一一匹配，不重复）。生成约束：对接并色彩互换后（精灵体外色 → 条边框色，精灵体内色 → 条填充色），每条色条的非黑像素构成一个一维周期序列（周期长度 2~4），且该周期在对接前（没有精灵体引入的像素）是不同的或不完整的（缺少确定周期所需的样本数）；每条至少有 1 个黑色缺口需要用对接后的周期填充。

**规则**：
1. 识别上半区的双色精灵体和下半区的水平色条。
2. 将每个精灵体匹配到填充色等于精灵体外色的色条。
3. 将精灵体放置到其匹配色条的行上，列位置与精灵体在上半区的原始列位置相同（水平不移动，垂直下移到色条行）。放置时执行色彩互换：精灵体的外色像素重涂为色条的边框色，精灵体的内色像素重涂为色条的填充色。
4. 擦除上半区的原始精灵体（重涂为黑(0)）。
5. 对每条色条（现在包含原始像素 + 对接引入的像素），分析其非黑像素的一维周期：找到最小周期长度 P，使所有非黑像素 (col) 的颜色满足 color(col) = tile[col mod P]。
6. 对色条行中每个黑(0)缺口像素 col，替换为 tile[col mod P]。
7. 输出网格尺寸与输入相同。

**关键洞察**：精灵体不只是装饰性地嵌入色条——它们引入的互换后颜色参与了周期计算，改变了周期的结构（例如原条可能看起来周期为 2，但对接后精灵体在特定位置引入新颜色，暴露出真实周期为 4）。因此对接操作实质性地改变了填充操作的数学基础。

## 新题 9：标记间距编码菱形尺寸 + 移动后包络生成

**组合逻辑**：[移动](已有) + [相对顺序决定出口](已有) ← 标记原始间距被移动"销毁"但编码了条长度 → [包络生成 + 逐步收缩](已有，但条长度由外部参数决定) → 两个菱形包络在不同位置生成（创新耦合点）

**来源原语**：移动/move + 标记像素/marker_pixel + 矩形/rectangle + 标记在矩形外侧/marker_outside_rect + 相对顺序决定出口/order_determines_exit（参考题 e4941b18）、包络生成/envelope_generation + 实心条/solid_bar + 菱形轮廓/diamond_outline + 中心对称/center_symmetry + 逐步收缩/stepwise_shrink（参考题 c97c0139）

**依赖链**：两个标记的原始水平间距 D 编码了后续条的长度 → 标记按方向规则移动（红到青的方向决定青的出口侧） → 移动后间距信息"消失"（标记已不在原位）→ 在各标记的最终位置绘制长度为 D 的水平条 → 围绕条生成菱形包络。间距信息只在移动前可读取，但在移动后才被使用——这种"信息先读后销毁再用"的时序耦合在任何参考题中不存在。

两个标记的水平间距决定后续条的长度；标记按方向规则重新定位后，在各自最终位置生成以该长度为中心的条及其菱形包络。

**输入结构**：约 15x15 网格，黑(0)背景。网格中央有一个实心灰(5)矩形（约 5x7）。矩形正上方一行有两个标记像素：一个红(2)和一个青(8)，两者均位于矩形列范围内，互不相邻，水平间距 D 在 3~6 之间。网格中无其他前景像素。生成约束：D 为奇数（使条以标记为中心对称）；矩形足够大使得条和菱形不超出矩形列范围；不同示例中 D 不同，且红与青的左右顺序可能不同（红在左或红在右），以便归纳方向规则。

**规则**：
1. 记录红(2)标记和青(8)标记的原始列位置，计算水平间距 D = |col_red - col_teal|。
2. 执行标记移动：
   - 清除红(2)标记（重涂为黑(0)）。
   - 将原青(8)位置重涂为红(2)。
   - 确定红到青的水平方向：若 col_teal > col_red，方向为右；否则为左。
   - 在矩形底行外侧（矩形底行的下一行），沿该方向放置青(8)标记：若方向为右，放在矩形右边框右侧 1 列、矩形底行的行位置；若为左，放在矩形左边框左侧 1 列同行。
3. 在红(2)标记的最终位置（即原青(8)位置），绘制一条水平红(2)条，以该位置为中心、总长度 D（向左 (D-1)/2 像素，向右 (D-1)/2 像素）。超出网格边界的部分截断。
4. 在青(8)标记的最终位置，绘制一条水平青(8)条，同样以该位置为中心、总长度 D。超出网格边界的部分截断。
5. 对每条水平条，生成同色菱形包络：条所在行保持不变；条上方每远离一行，两端各缩进 1 像素，直到缩为 1 像素宽；条下方同理。包络像素不覆盖灰色矩形像素（灰色优先）。
6. 灰色矩形保持不变。若菱形包络与矩形重叠，重叠区域保留矩形灰色。

**关键洞察**：标记的原始间距 D 在移动步骤中被"销毁"（标记离开原位），但 D 是后续条长度和菱形尺寸的唯一决定因素。求解者必须在移动之前提取间距信息，理解它在移动之后被"消费"为几何参数。这种信息的时序生命周期（产生 → 销毁 → 使用）在任何单一参考题中都不存在。
