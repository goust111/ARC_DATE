## 新题 1：反射定位门控滑行

**组合逻辑**：[镜像/mirror](创新：反射的不是图案本身，而是门结构的位置信息) + [滑动/slide] + [擦除/erase]（三者耦合：镜像确定停止位置，路径拓扑约束滑行路线，擦除消除已走过的路径）

**来源原语**：镜像 ← 2b01abd0/538b439f；滑动+门前停止 ← 182e5d0f；擦除 ← 182e5d0f/6e4f6532；分隔线 ← 2b01abd0；路径+四邻接连通 ← 182e5d0f

**依赖链**：分隔线定义反射轴 → 门结构经反射投射到路径侧 → 反射后的门位置决定每条路径上标记的停止点 → 标记沿路径滑行到该点并擦除经过的路径段

将分隔线另一侧的门结构反射到路径侧，以此确定标记像素在路径上的停止位置，标记沿路径滑行到位后擦除已走过的路径段。

**输入结构**：约 15x15 的黑(0)背景网格。一条贯穿全宽的水平黄(4)分隔线将网格分为上下两半。上半区：2-3 条由绿(3)像素构成的 4-连通路径，每条路径有且仅有一个灰(5)标记像素位于路径的一端；路径可弯折但不分叉，不同路径互不相邻。下半区：在若干列位置放置门结构，每个门结构为同一列上下相邻的三个像素，顶部和底部为黑(0)、中间为蓝(1)，即"黑-蓝-黑"纵向三联体（门结构不与分隔线相邻，与分隔线之间至少隔一行黑像素）。生成约束：每条路径恰好经过一个门结构的反射位置所在列，且该列上路径恰好只有一个绿像素；不同路径对应不同的门结构。

**规则**：
1. 将每个门结构以黄(4)分隔线为轴做水平镜像反射，得到其在上半区的镜像位置（行坐标关于分隔线对称，列坐标不变）。
2. 对每条绿(3)路径，找到与该路径相交的镜像门位置（镜像门中心所在列上的绿路径像素即为停止目标格）。
3. 将灰(5)标记像素沿其所在的绿(3)路径向停止目标格滑行。标记最终落在目标格上。
4. 标记经过的所有绿(3)像素（不含最终停止格）置为黑(0)。停止格本身变为灰(5)（即标记颜色），其后方未经过的绿路径段保持绿(3)不变。
5. 分隔线、下半区所有门结构均保持不变。
6. 若路径上有多个可能的行进方向，标记始终选择沿路径朝停止目标格前进的唯一方向（路径不分叉保证方向唯一）。

**关键洞察**：门结构全部位于分隔线的对侧，求解者必须先通过反射推算出门在路径侧的位置，才能确定每个标记的停止点——这一"跨侧定位"是题目的核心非显然步骤。

## 新题 2：对称补全揭示印章锚点

**组合逻辑**：[对称补全/symmetry_completion](已有) → [印章覆盖/stamp_overlay](创新：锚点位置由补全结果决定，非直接给出) + [方位决定颜色/direction_color](已有，但从单一标记扩展为全局锚点群)

**来源原语**：对称补全+八重对称轨道+遮罩像素+轨道内唯一可见色 ← 929ab4e9；印章覆盖+十字图案+方位决定颜色 ← d364b489

**依赖链**：遮罩像素隐藏了部分锚点色像素 → 对称补全恢复完整图案 → 恢复后的锚点色像素位置成为印章中心 → 在每个锚点处叠加方位着色的十字图案

在具有 8 重对称但被部分遮罩的正方形网格中，先补全对称以揭示所有蓝色锚点的位置，再在每个锚点处印方位着色的四邻十字。

**输入结构**：11x11 的正方形网格。背景黑(0)。可见像素（非遮罩）构成一个在忽略遮罩后满足 8 重对称（4 次旋转 + 4 条反射轴）的图案，使用红(2)、绿(3)、蓝(1)三种前景色。若干像素被栗(9)遮罩覆盖（遮罩像素总数约 8-15 个），部分遮罩像素恰好覆盖了蓝(1)锚点。非遮罩的可见像素中已有若干蓝(1)像素可见。生成约束：每个 8 重对称轨道中至少有一个非遮罩的可见像素，使得补全唯一确定；蓝(1)像素的位置保证其四邻十字臂互不重叠（任意两个蓝像素的曼哈顿距离大于 2）。

**规则**：
1. 对每个栗(9)遮罩像素，找到它在 8 重对称群（沿水平轴、垂直轴、主对角线、副对角线的反射以及 90/180/270 度旋转）下的全部轨道成员；取轨道中唯一的非遮罩可见颜色替换该遮罩像素。
2. 补全后，收集网格中所有蓝(1)像素位置作为印章锚点。
3. 在每个锚点处叠加一个四邻十字：上方邻格涂红(2)，左方邻格涂橙(7)，右方邻格涂品红(6)，下方邻格涂青(8)。
4. 十字臂超出网格边界的部分裁剪不画。十字臂不覆盖其他蓝(1)像素（蓝像素优先级最高）。十字臂覆盖所有其他非蓝颜色。
5. 所有非蓝、非遮罩的像素若未被十字臂覆盖则保持原色不变。

**关键洞察**：部分蓝色锚点被遮罩隐藏，仅凭可见蓝像素印章会遗漏锚点；必须先完成对称补全才能获得完整的锚点集合，且补全后新出现的蓝像素会在周围产生新的十字覆盖，改变原本可见区域的颜色。

## 新题 3：反射变形后的精灵体凹槽装配

**组合逻辑**：[镜像/reflect](创新：反射改变精灵体形状以匹配凹槽) + [拼接/assemble](已有) + [擦除/erase]（三者耦合：反射是匹配的前提，匹配驱动装配，装配后擦除原件）

**来源原语**：镜像/reflect ← 2b01abd0/538b439f；拼接/assemble+凹槽/notch+中心条/central_bar+形状匹配/shape_matching ← 16b78196；擦除 ← 6e4f6532；忽略干扰项 ← 538b439f

**依赖链**：精灵体的原始形状与凹槽不匹配 → 必须经过分隔线反射得到镜像形状 → 镜像形状才能通过形状匹配选中对应凹槽 → 成功匹配的精灵体装入凹槽 → 原位置擦除 → 未匹配的精灵体为干扰项保持不变

将分隔线一侧的精灵体反射后，以镜像形状匹配另一侧中心条上的凹槽并装入，擦除原件，忽略无法匹配的干扰精灵体。

**输入结构**：约 15x20 的黑(0)背景网格。一条贯穿全高的垂直黄(4)分隔线将网格分为左右两半。左半区：一根水平走向的灰(5)中心条（宽度 2-3 像素、长度接近左半区宽度），中心条边界上开有 2-3 个凹槽（凹槽为背景色的连通孔洞，每个凹槽 3-5 像素，形状各异且非矩形——例如 L 形、T 形的 4-连通区域）。右半区：3-5 个小型单色精灵体（每个 3-5 像素的 4-连通区域，颜色各不同，从红(2)、绿(3)、蓝(1)、橙(7)、品红(6)中取），散布在分隔线右侧。生成约束：恰好有 2-3 个精灵体经左右镜像后形状精确匹配某个凹槽（一一对应，无重复匹配）；其余精灵体为干扰项，其镜像不匹配任何凹槽。

**规则**：
1. 以垂直黄(4)分隔线为反射轴，计算每个右侧精灵体的左右镜像形状（列坐标关于分隔线对称，行坐标不变；只取形状轮廓，不考虑绝对位置）。
2. 对每个镜像形状，在左侧中心条的凹槽中寻找形状完全匹配的凹槽（像素数相同且连通区域形状全等，允许平移对齐）。
3. 将匹配成功的精灵体以其镜像形状填入对应凹槽，颜色保持精灵体的原始颜色。
4. 擦除匹配成功的精灵体在右侧的原始位置（置为黑(0)）。
5. 未匹配的干扰精灵体保持原位不变。分隔线保持黄(4)不变。中心条灰(5)部分不变。

**关键洞察**：凹槽的形状是精灵体的镜像而非原形——直接用原始形状匹配会全部失败；求解者必须意识到分隔线是反射轴，先将精灵体翻转才能找到匹配关系。

## 新题 4：补全驱动的像素放大自掩码

**组合逻辑**：[对称补全/symmetry_completion](已有) → [像素放大/pixel_scale + 掩码映射/mask_mapping](已有，但全局掩码依赖补全结果，形成信息耦合)

**来源原语**：对称补全+八重对称轨道+遮罩像素+轨道内唯一可见色 ← 929ab4e9；像素放大+掩码映射+自身色选掩码+全局掩码+块单元 ← 973e499e

**依赖链**：遮罩像素使全局颜色分布不完整 → 对称补全恢复被遮盖的像素 → 恢复的像素改变了每种颜色的全局掩码 → 像素放大时每个块的内部图案由更新后的全局掩码决定 → 若不先补全就放大，所有包含该颜色的块的内部图案都会出错

先补全正方形网格的旋转对称以恢复被遮盖的像素，再将补全后的网格做像素放大自掩码展开——每个像素展开为一个与原网格同形的块，块中仅在同色位置写入该色、其余写黑。

**输入结构**：5x5 的正方形网格。使用红(2)、绿(3)、蓝(1)三种前景色和黑(0)背景。该网格在忽略遮罩后具有 4 次旋转对称（90 度旋转不变）。其中 3-5 个像素被栗(9)遮罩覆盖。生成约束：每个旋转轨道（4 个位置一组，中心点自成一组）中至少有一个非遮罩像素，保证补全唯一确定；至少有一个遮罩像素覆盖的是非黑前景色，使得补全真正改变全局掩码。

**规则**：
1. 对每个栗(9)像素，找到它在 4 次旋转群（0/90/180/270 度旋转，中心为网格中心）下的全部轨道成员，取轨道中唯一的非遮罩颜色替换之。
2. 对补全后的 5x5 网格做像素放大：输出为 25x25。对每个位置 (r,c) 处颜色为 c_val 的像素，生成一个 5x5 的块放置在输出的第 (r*5) 到 (r*5+4) 行、第 (c*5) 到 (c*5+4) 列。
3. 块内部规则：在块的第 (i,j) 位置，若补全后的原网格在 (i,j) 处的颜色也等于 c_val，则写 c_val；否则写黑(0)。
4. 黑(0)背景像素的块全为黑(0)（因为黑不算前景色，不参与掩码选择）。

**关键洞察**：像素放大中每个块的内部图案是该颜色在全网格中的分布掩码——如果不先补全对称，被遮盖的像素会使掩码残缺，导致所有同色块都缺少对应位置的像素。补全操作看似只改了几个像素，实则通过全局掩码影响了输出中的每一个块。

## 新题 5：字形解码指导射线方向

**组合逻辑**：[解码/decode](已有) → [射线延伸/ray_extension](创新：射线方向不由空间位置预定，而由解码结果动态分配) + [重涂色/recolor]（射线相遇处产生颜色混合）

**来源原语**：解码+字形+弯头决定偏移+顺序排列 ← e6de6e8f；射线延伸+通道 ← 05a7bcf2；重涂色 ← 多题；标记像素 ← 多题

**依赖链**：字形编码方向指令 → 解码得到方向序列 → 方向序列按空间顺序分配给标记像素 → 每个标记按分配到的方向发射射线 → 射线交叉处重涂色 → 方向序列改变则交叉点完全不同

解码顶部字形条获得方向指令序列，将方向分配给网格中的标记像素，每个标记沿分配方向发射射线，射线在交叉处产生特定颜色。

**输入结构**：约 14x14 的黑(0)背景网格。最顶部两行构成一个红(2)字形编码条（与参考题 e6de6e8f 格式相同）：每个字形占据两行，字形之间以一列黑(0)间隔。字形分两类——"直行字形"：两行同一列各一个红像素构成垂直二联体；"弯头字形"：底行有两个相邻红像素（水平二联体），顶行在其中一端正上方有一个红像素，缺失的那一端指示转向方向。在第 3 行以下的主区域中，散布 N 个蓝(1)标记像素（N 等于字形个数），标记像素互不同行且互不同列。生成约束：字形个数与标记像素个数相等（3-5 个）；所有射线在网格内至少产生一个交叉点；标记像素的位置保证任意两条射线至多交叉一次。

**规则**：
1. 从字形编码条中从左到右解码每个字形：直行字形解码为"向下"；左弯头（顶行红像素在右侧，左侧缺失）解码为"向左"；右弯头（顶行红像素在左侧，右侧缺失）解码为"向右"。得到一个长度为 N 的方向序列。
2. 将主区域中的蓝(1)标记像素按行号从小到大排序（行号相同则按列号从小到大），得到一个长度为 N 的标记序列。
3. 将方向序列按顺序一一分配给标记序列：第 1 个方向分配给第 1 个标记，第 2 个方向分配给第 2 个标记，依此类推。
4. 从每个标记像素出发，沿其分配的方向发射绿(3)射线（逐像素延伸），直到碰到网格边界或碰到另一条已有的射线像素（含其他标记像素）时停止（不包含终点——终点本身不被涂色）。
5. 若两条射线交叉（一条水平一条垂直、或方向不同使得路径在某个像素重合），交叉像素涂黄(4)。
6. 字形编码条（顶部两行）在输出中擦除为黑(0)。蓝(1)标记像素保持蓝(1)不变。

**关键洞察**：每个标记的射线方向不是由其空间位置决定的，而是由顶部字形条编码的指令序列动态分配的——同样的标记布局搭配不同的字形序列会产生完全不同的射线图案和交叉点。

## 新题 6：计数匹配配对后旋转并重涂内部

**组合逻辑**：[计数匹配/count_matching](创新：匹配的是矩形内部面积与散点簇大小) + [旋转/rotate](创新：旋转角度由标记像素在边框上的方位决定) + [重涂色/recolor](创新：内部颜色由匹配的散点簇颜色决定)（三者并行约束：计数匹配选定配对，标记方位选定旋转，匹配色选定内部重涂——三条信息缺一不可）

**来源原语**：计数匹配 ← 6e4f6532；旋转+标记色定朝向 ← 6e4f6532/1a244afd；重涂色+内部与边框+仅内部像素变色 ← bb43febb；实心矩形 ← bb43febb

**依赖链**：计算每个矩形的内部像素数 → 与散点簇大小匹配确定配对 → 配对的簇颜色决定内部重涂色 → 标记在边框哪一侧决定旋转角度 → 旋转后再执行内部重涂

统计每个灰色矩形的内部面积并与散点簇大小匹配，由匹配簇的颜色决定内部重涂色，由矩形边框上标记像素的方位决定旋转角度。

**输入结构**：约 18x18 的黑(0)背景网格。包含 2-3 个灰(5)实心矩形，尺寸各不同（每个至少 4x4，保证内部面积互不相等）。每个矩形的边框上恰好有一个像素被替换为特殊标记色——该标记色为红(2)、绿(3)、黄(4)、蓝(1)之一，且标记位于矩形某一边的中点位置（即位于顶边中点、右边中点、底边中点或左边中点之一）。在网格的空白区域散布 2-3 个单色散点簇（每个簇由同色像素构成的 4-连通区域，像素数 3-12 不等，颜色从橙(7)、品红(6)、青(8)中取，各簇颜色互不相同）。生成约束：每个矩形的内部面积（即 (宽-2)*(高-2)）恰好等于某个散点簇的像素数，且此匹配为一一对应（无两个矩形内部面积相同）。

**规则**：
1. 对每个灰(5)矩形，计算其内部像素数 = (宽-2)*(高-2)。找到像素数相等的散点簇，建立一一配对。
2. 根据标记像素在矩形边框上的位置确定旋转角度：标记在顶边中点 → 不旋转（0 度）；标记在右边中点 → 顺时针旋转 90 度；标记在底边中点 → 旋转 180 度；标记在左边中点 → 顺时针旋转 270 度。旋转以矩形中心为轴，旋转后矩形的位置可能改变（但保证旋转后仍在网格内且不与其他矩形重叠）。
3. 在旋转后的矩形中，将所有内部像素（非边框的灰像素）重涂为配对散点簇的颜色。边框保持灰(5)，标记像素保持其原色并随旋转移动到新的边框位置。
4. 擦除所有已配对的散点簇（置为黑(0)）。
5. 未配对的散点簇（如果有）保持原位不变。

**关键洞察**：三条独立的信息通道同时决定输出——内部面积匹配散点簇（决定颜色来源），标记方位决定旋转角度（决定空间变换），内部与边框分离决定重涂范围（决定着色区域）——删去任何一条都无法得出正确输出。

## 新题 7：障碍门控通道的选择性压缩

**组合逻辑**：[射线延伸/ray_extension](创新：射线穿越障碍门时被标记) + [压缩/compress](创新：仅压缩被门标记过的通道) + [每隔N选取/every_nth_selection](创新：N 由障碍门数量决定)

**来源原语**：射线延伸+通道+分隔线两侧+压缩至远端边界 ← 05a7bcf2；障碍段+障碍门处标记通道 ← fc10701f；每隔N选取+按位置排序 ← 22a4bbc2；重涂色 ← 多题

**依赖链**：射线从源像素穿过障碍门到达分隔线 → 穿越障碍门的数量 N 被记录 → N 决定该通道在分隔线另一侧的压缩选取间隔 → 仅被选取的像素被压缩到远端

统计每条通道中射线穿越的障碍门数量 N，然后在分隔线另一侧的同通道中每隔 N 个像素选取一个，将选取的像素压缩到远端边界。

**输入结构**：约 12x20 的黑(0)背景网格。一条贯穿全宽的水平灰(5)分隔线居中。上半区：每列（通道）可能包含若干绿(3)像素和若干黑(0)-红(2)-黑(0)横向三联体作为障碍门（门的红(2)中心像素位于该通道列上，两侧黑像素在相邻列上）。部分通道底端（紧挨分隔线上方）有一个蓝(1)源像素。下半区：每列中有若干黄(4)像素散布，其余为黑(0)背景。生成约束：有蓝(1)源像素的通道数为 2-4 条；每条有源像素的通道中障碍门数量为 1-3 个且各通道门数不全相同；下半区每条对应通道中的黄(4)像素数量足够多（至少 6 个），保证选取后至少有 2 个像素被压缩。

**规则**：
1. 对每条含有蓝(1)源像素的通道，从源像素向上发射射线（逐像素延伸），直到碰到网格顶部边界。沿途将经过的黑(0)像素涂为绿(3)。
2. 统计该射线穿越的障碍门数量（即射线路径上红(2)像素的个数），记为 N。
3. 在分隔线下方的同一通道中，将所有黄(4)像素按行号从上到下排序，编号为 1, 2, 3, ...。
4. 选取编号为 1, 1+N, 1+2N, ... 的黄(4)像素（即从第 1 个开始每隔 N 个选取一个）。
5. 将选取的黄(4)像素压缩到该通道的底部边界：从网格最后一行起向上连续放置选取的像素（保持黄(4)颜色），其余原黄(4)位置置为黑(0)。
6. 未被选取的黄(4)像素置为黑(0)。无蓝(1)源像素的通道不做任何处理。

**关键洞察**：障碍门的数量不只是标记通道（如参考题 fc10701f），而是编码了一个选取间隔参数 N——不同通道的 N 值不同，导致同样数量的黄像素被选取出不同的子集再压缩，使每条通道的输出长度和内容都不同。

## 新题 8：转置后的链式镜像填充

**组合逻辑**：[沿主对角线转置/diag_transpose](已有) + [链式填充/chain_fill](创新：链的方向和宽度由转置后的形状轮廓决定) + [分隔色填充间隙/sep_color_fills_gap](创新：间隙带颜色取自转置前后差异区域)

**来源原语**：沿主对角线转置 ← 74dd1130；链式填充+固定条带宽度+精灵体+凹槽 ← 16b78196；分隔色填充间隙+间隙带 ← 538b439f；镜像 ← 2b01abd0

**依赖链**：将输入网格转置得到新布局 → 转置改变了精灵体的宽高比 → 转置后的精灵体宽度成为链式填充的固定条带宽度 → 在原形和转置形之间的差异区域填入间隙色 → 链式填充从转置形出发沿其较长维度方向延伸

将正方形网格沿主对角线转置，转置后精灵体的形状确定链式填充的条带宽度，链沿转置后的较长维度延伸，原形与转置形之间的差异像素用灰色填充。

**输入结构**：8x8 的正方形网格，背景黑(0)。包含 2-3 个小型单色精灵体（每个 3-6 像素的 4-连通区域，颜色各不同，从红(2)、蓝(1)、绿(3)中取），形状非正方形（宽度和高度不相等，保证转置后形状发生变化）。每个精灵体的边界框不与网格边缘相邻（四周至少留 1 像素黑边距），且不同精灵体边界框互不重叠且互不相邻。生成约束：每个精灵体转置后仍在网格内且各精灵体转置后的边界框互不重叠；网格中有足够空间容纳至少 2 节链式填充。

**规则**：
1. 对整个 8x8 网格做主对角线转置：将像素 (r, c) 移到 (c, r)。输出仍为 8x8。
2. 对每个精灵体，比较其转置前后的像素集合：
   - 转置后新增的像素位置（转置后有色、转置前为黑）标记为"新增区"。
   - 转置后消失的像素位置（转置前有色、转置后为黑）标记为"消失区"。
3. 将所有"消失区"像素填为灰(5)。
4. 从每个转置后的精灵体出发，沿其边界框较长维度的方向（若边界框宽 > 高则向右延伸，若高 > 宽则向下延伸；宽高相等时向右）进行链式填充：以精灵体转置后的边界框在延伸方向上的跨度为固定条带宽度，在垂直于延伸方向上保持精灵体的形状掩码，在延伸方向上逐块复制精灵体图案，直到碰到网格边界或碰到另一个精灵体/灰像素时停止。
5. 链式填充的每一节使用该精灵体的原始颜色。

**关键洞察**：转置改变了精灵体的宽高比，从而改变了链式填充的延伸方向——一个原本"宽矮"的精灵体转置后变成"窄高"，链的方向从水平翻转为垂直。消失区的灰色填充既标记了变换痕迹，也可能阻挡其他精灵体的链式延伸。

## 新题 9：对称裁剪后颜色互换

**组合逻辑**：[对称补全/symmetry_completion](创新：利用四象限对称而非八重对称) + [裁剪/crop](创新：裁剪区域由遮罩矩形定义) + [颜色互换/color_swap](创新：互换的是裁剪区域内的两种图案色)（三者链式耦合：补全恢复遮罩下的信息，遮罩范围定义裁剪输出，互换确保输出不是简单复制）

**来源原语**：对称补全+双轴反射对称+标记遮挡区域+标记矩形 ← 0934a4d8；裁剪/crop ← 0934a4d8；颜色互换+原位颜色互换+双色源图案 ← 2b01abd0；四象限对称 ← 0c786b71

**依赖链**：栗色遮罩矩形遮挡了双色图案的一部分 → 利用四象限对称（水平+垂直反射）从其他象限恢复遮罩下的图案 → 以遮罩矩形的边界框作为裁剪范围提取子网格 → 在裁剪出的子网格中互换两种图案颜色

在具有水平和垂直反射对称的双色图案中，用四象限对称补全被栗色矩形遮盖的区域，以遮罩范围裁剪出子网格，并在裁剪结果中互换两种图案色。

**输入结构**：约 13x13 的黑(0)背景网格。前景由红(2)和蓝(1)两种颜色构成的图案组成，该图案在忽略遮罩后具有水平轴和垂直轴的双反射对称（即四象限对称）。一个实心栗(9)矩形（约 3x4 到 5x6 大小）覆盖在图案的某个区域上，完全位于某一个象限内（不跨越对称轴）。生成约束：遮罩矩形覆盖的区域可以通过至少一个对称轴的反射从可见像素完全恢复（即被遮盖像素的对称伙伴均未被遮盖）；图案中红(2)和蓝(1)的像素数量均大于 0。

**规则**：
1. 找到唯一的实心栗(9)矩形，记录其边界框范围（行范围 r1..r2，列范围 c1..c2）。
2. 确定图案的水平对称轴（行）和垂直对称轴（列）。对每个栗(9)像素 (r, c)，通过水平反射 (r, c) → (axis_r*2 - r, c) 或垂直反射 (r, c) → (r, axis_c*2 - c) 找到一个可见的非遮罩像素，取其颜色替换遮罩像素。若水平和垂直反射位置都被遮罩，则使用双重反射（对角象限）的像素颜色。
3. 以遮罩矩形的边界框裁剪补全后的子网格，得到一个 (r2-r1+1) x (c2-c1+1) 的小网格作为输出。
4. 在输出小网格中，将所有红(2)像素改为蓝(1)，将所有蓝(1)像素改为红(2)。黑(0)背景像素不变。

**关键洞察**：遮罩矩形同时扮演两个角色——它既标记了需要通过对称补全恢复的区域，又定义了裁剪输出的范围。颜色互换使得输出不是对称伙伴的直接拷贝，必须同时理解补全和互换两步才能得出正确答案。
