## 新题 1：区域奇偶决定镜像轴

**组合逻辑**：[洪泛填充/flood_fill](已有) → [计数/counting](已有) → [面积奇偶定填充色/parity_sets_fill](创新：奇偶不决定颜色而决定镜像轴方向) → [镜像/mirror](已有) + [相邻拼接/adjacent_placement](已有)

**来源原语**：
- 洪泛填充、四连通分区、分隔墙 ← 782b5218
- 计数、面积奇偶定填充色 ← 868de0fa
- 镜像、相邻拼接、精灵体 ← 9bebae7a

**依赖链**：洪泛填充确定每个区域的边界 → 计数得到区域面积 → 奇偶性决定该区域内精灵体的镜像轴（水平翻转或垂直翻转） → 镜像操作生成副本并拼接到原件旁。删除任一环节：不知道区域边界、不知道面积、不知道镜像方向、无法生成副本。

将红色墙壁划分出的各个区域内的精灵体，按区域面积的奇偶性选择镜像轴方向，生成镜像副本并拼接到原件旁。

**输入结构**：约 15x15 的网格，背景为黑(0)。红(2) 像素构成一像素宽的分隔墙，将网格分为若干个 4-连通区域（每个区域约 8~30 个单元格）。每个区域内恰好包含一个单色 4-连通小图形（3~6 像素，颜色各异，可为蓝(1)、绿(3)、黄(4)、橙(7) 等，不同区域颜色不同），其余单元格为黑(0)。每个小图形的边界框不超过 3x3。生成约束：每个区域足够大，使得小图形及其镜像副本可以在区域内并排放置而不超出区域边界或覆盖红墙；不同区域的面积应有奇有偶，且至少各出现 2 次。

**规则**：
1. 以红(2) 像素为墙，找出所有 4-连通的非红区域，计算每个区域的单元格总数（含黑色背景格和图形像素格）。
2. 若区域面积为偶数，将该区域内的小图形沿其边界框的垂直中轴做左右镜像，将镜像副本紧贴原件边界框右侧放置（副本左边缘紧邻原件边界框右边缘的下一列）。
3. 若区域面积为奇数，将该区域内的小图形沿其边界框的水平中轴做上下镜像，将镜像副本紧贴原件边界框下方放置（副本上边缘紧邻原件边界框下边缘的下一行）。
4. 红(2) 分隔墙保持不变。各区域互不干涉，处理顺序不影响结果。

**关键洞察**：决定镜像方向的是区域的总面积奇偶性，而非精灵体自身的像素数或形状属性；从单个示例对中可能误判为由精灵体大小决定，需要多个示例对比区域面积才能归纳出真正的判据。

## 新题 2：十字检测触发对角射线

**组合逻辑**：[模式检测/pattern_detection](已有) → [射线延伸/ray_extend](创新：射线源不是边缘像素而是检测到的十字中心) + [障碍偏转绕行/obstacle_deflection](创新：非十字前景像素充当天然障碍)

**来源原语**：
- 模式检测、十字图案、邻域全匹配、前景对象 ← 1818057f
- 射线延伸、对角方向、障碍偏转绕行、源像素 ← 69889d6e

**依赖链**：十字模式检测识别射线发射源 → 非十字前景像素构成障碍拓扑 → 射线从每个十字中心出发沿对角线延伸并在障碍前停止。删除检测步骤则不知道从哪里发射；删除射线步骤则只剩检测无输出变换；去掉障碍逻辑则射线路径无法确定。

在单色前景中检测出所有 '+' 十字图案，从每个十字中心发射四条对角射线，射线遇到其他前景像素时停止。

**输入结构**：约 18x18 的网格，背景为黑(0)。黄(4) 像素构成各种前景形状：其中若干处（2~4 个）形成标准 '+' 图案（一个中心像素加上下左右四个邻居，共 5 像素），其余为散布的非规则前景块（4-连通，3~8 像素）。十字图案之间至少间隔 3 格。生成约束：十字图案的 5 个像素的 8-邻域内不存在其他黄(4) 像素（确保检测无歧义）；每个十字的至少 2 条对角射线会被某个非规则前景块截止（不是全部射线都直达边界）。

**规则**：
1. 检测所有 '+' 十字图案：中心像素及其上下左右四个正交邻居均为黄(4)。将这 5 个像素重涂为青(8)，标记为已检测。
2. 从每个已检测的十字中心出发，沿四个对角方向（右上、右下、左上、左下）各发射一条射线，射线颜色为红(2)。
3. 射线逐像素沿对角线延伸。若下一个像素为黄(4)（未被检测的前景障碍）或青(8)（另一个已检测十字的像素），射线在该像素之前停止（不覆盖障碍/十字像素）。若到达网格边界，停止。
4. 射线像素仅覆盖黑(0) 背景格。所有射线颜色相同（红(2)），若两条射线路径交叉，交叉点保持红(2)，无冲突。
5. 处理顺序：按十字中心行优先、列次优先（从上到下、从左到右）逐个发射。由于射线仅覆盖背景格且颜色统一，顺序不影响最终结果。

**关键洞察**：十字检测不是最终目的——检测结果决定了射线发射的拓扑源点，而未被检测的前景块既不被标记也不被移除，它们充当射线的天然障碍物；需要多个示例才能确认射线终止条件是"遇到任何非背景像素"而非"遇到边界"。

## 新题 3：标记臂方向编码旋转的嵌入填充

**组合逻辑**：[嵌入填充/inlay_fill](已有) + [旋转/rotate](已有) + [擦除/erase](已有)，其中 [最长臂决定镜像侧/longest_arm_mirror_side](创新：臂方向不再编码镜像侧，而编码旋转角度)

**来源原语**：
- 嵌入填充、模板框架、孔洞、形状匹配孔洞、旋转翻转不变 ← 67e490f4
- 最长臂决定镜像侧、十字标记、擦除 ← 9bebae7a
- 旋转、标记定输出朝向 ← 7b3084d4
- 精灵体 ← 67e490f4

**依赖链**：形状匹配确定精灵体属于哪个孔洞 → 十字标记的最长臂方向确定旋转角度 → 旋转精灵体后嵌入对应孔洞 → 擦除所有标记。形状匹配和旋转编码缺一不可：没有形状匹配不知道精灵体填哪个孔洞；没有标记不知道旋转几度（同一形状可能在多种旋转下都能"大致"匹配某个孔洞，但只有标记指定的旋转才精确匹配）。

将框架外的精灵体按形状匹配孔洞，旋转角度由每个精灵体旁的十字标记的最长臂方向编码，旋转后嵌入对应孔洞。

**输入结构**：约 20x20 的网格，背景为黑(0)。一个灰(5) 单色大框架占据网格中央区域（约 12x12），框架宽度为一像素，框架内部有 3~4 个形状各异的孔洞（非灰连通区域，每个孔洞 4~8 像素，4-连通，形状不规则且互不相同）。框架外部散布着与孔洞数量相同的单色小精灵体（每个精灵体颜色不同：蓝(1)、绿(3)、黄(4)、红(2) 等，像素数 4~8，4-连通）。每个精灵体旁（间距 1~2 格）有一个橙(7) 十字标记（一像素宽的十字形，四臂中恰好一臂明显最长，其余三臂等长且较短）。生成约束：每个精灵体的形状恰好匹配一个孔洞（在唯一一种旋转下精确吻合），且该旋转由对应十字标记的最长臂方向编码（最长臂指向上 → 旋转 0 度；指向右 → 顺时针 90 度；指向下 → 180 度；指向左 → 顺时针 270 度）。不同精灵体的颜色互不相同。

**规则**：
1. 裁剪到灰(5) 框架的边界框范围，框架外的区域不出现在输出中。
2. 将框架边界框内全部填充为灰(5)，覆盖所有孔洞。
3. 对每个框架外的精灵体，在框架内找到形状匹配的孔洞（允许旋转匹配，但正确的旋转由标记指定）。
4. 读取该精灵体旁十字标记的最长臂方向，将精灵体顺时针旋转对应角度（上→0°，右→90°，下→180°，左→270°）。
5. 用旋转后精灵体的颜色填充对应孔洞的所有像素。
6. 所有十字标记和框架外精灵体不出现在输出中（输出仅包含框架边界框范围）。

**关键洞察**：标记不指示放置位置或镜像方向，而是编码旋转角度——同一精灵体在多种旋转下可能形状近似匹配某个孔洞，但只有标记指定的旋转才产生精确吻合；需要多个示例才能确认臂方向与旋转角度的映射关系（上=0°、右=90°、下=180°、左=270°）。

## 新题 4：分区面积奇偶决定循环填充方向

**组合逻辑**：[网格分区/grid_partition](已有) → [计数/counting](已有) → [面积奇偶定填充色/parity_sets_fill](创新：奇偶不决定颜色而决定填充方向) → [循环填充/cyclic_fill](创新：填充方向由外部条件动态决定)

**来源原语**：
- 分隔线、网格分区 ← 6773b310, 7039b2d7
- 计数、面积奇偶定填充色 ← 868de0fa
- 循环填充、循环重复、种子图案 ← 12422b43, 9b30e358
- 封闭区域 ← 868de0fa

**依赖链**：分隔线划定区域 → 计算区域面积 → 奇偶性决定填充方向（向下或向右） → 以区域内已有的种子图案为母题执行循环填充。删除分区则不知道区域边界；删除计数则不知道方向；删除填充则无输出变换。

在由分隔线划定的每个区域中，以区域左上角的小种子图案为母题循环填充该区域，但填充方向由区域面积的奇偶性决定。

**输入结构**：约 17x17 的网格，背景为黑(0)。灰(5) 像素构成完整的水平和垂直分隔线（一像素宽，贯穿整个网格宽度或高度），将网格分为 3x3 共 9 个矩形区域（区域大小不完全相同，宽度范围 3~7 列，高度范围 3~7 行）。每个区域的左上角有一个小种子图案：占据 1~2 行 x 1~2 列，由某种非黑非灰颜色绘制（如蓝(1)、红(2)、绿(3) 等，不同区域颜色可不同）。种子图案所占的行列数不超过区域对应维度的一半。区域其余位置为黑(0)。生成约束：各区域面积（区域内行数 x 列数，不含分隔线像素）有奇有偶，且至少各出现 2 次。

**规则**：
1. 识别灰(5) 分隔线，将网格划分为矩形区域。计算每个区域的面积 = 区域内行数 x 区域内列数。
2. 识别每个区域左上角的种子图案：从区域左上角像素开始，找到连续的非黑像素块，其占据的行数为 H_s、列数为 W_s。
3. 若区域面积为偶数：以种子图案为母题，在区域内沿垂直方向（向下）循环填充。即从种子所在的起始行开始，每隔 H_s 行重复绘制一次种子图案的全部行内容，直到区域底部边缘。每次重复的水平位置与种子相同（仅覆盖种子宽度 W_s 列）。超出区域底部的部分截断。
4. 若区域面积为奇数：以种子图案为母题，在区域内沿水平方向（向右）循环填充。即从种子所在的起始列开始，每隔 W_s 列重复绘制一次种子图案的全部列内容，直到区域右边缘。每次重复的垂直位置与种子相同（仅覆盖种子高度 H_s 行）。超出区域右边的部分截断。
5. 灰(5) 分隔线保持不变。各区域独立处理。

**关键洞察**：同样的种子图案在不同区域中可能呈现完全不同的填充方向——关键在于区域面积的奇偶性，而非种子的形状或颜色；如果单个示例中所有可见区域恰好面积同奇偶，则无法确定方向规则，需要多个示例才能确认方向与面积奇偶的关联。

## 新题 5：重叠框深度与角落色彩图例

**组合逻辑**：[计数/counting](创新：计数对象为重叠深度而非像素面积) + [重涂色/recolor](已有) + [角标色定象限涂色/corner_sets_quadrant](创新：角标不映射到象限而映射到深度层级) + [编码映射/encoding_map](已有)

**来源原语**：
- 空心矩形、边框、封闭区域、包含 ← 868de0fa
- 角标像素、编码映射 ← 77fdfe62
- 重涂色 ← 77fdfe62, 1818057f
- 计数 ← 6773b310, 868de0fa

**依赖链**：多个空心矩形重叠产生不同深度 → 角落像素提供深度到颜色的映射 → 根据每个位置的重叠深度重涂色。三者同时约束：不知道重叠结构则无法计算深度；不知道角落图例则无法确定颜色；两者组合才能生成输出。这是同时约束满足结构，非线性流水线。

统计多个重叠空心矩形框在每个位置的叠加层数，然后根据网格四角的色彩图例将边框像素按其深度重涂色。

**输入结构**：约 14x14 的网格，背景为黑(0)。3~5 个灰(5) 一像素宽空心矩形框散布在网格中，部分框彼此重叠（边框线交叉或重合）。每个框大小约 4x4 至 8x8，均为灰(5) 绘制。框的内部为黑(0)（除非被其他框的边框穿过）。网格的四个角各有一个单独的彩色像素（不与任何框的边框接触），分别为：左上角像素颜色 C1、右上角 C2、左下角 C3、右下角 C4，四色互不相同，取自 {蓝(1), 红(2), 绿(3), 黄(4)}。生成约束：框的排列使得网格中出现深度 1、2、3、4 的边框像素（分别被 1/2/3/4 个框的边框覆盖）；四个角落像素不被任何框覆盖。

**规则**：
1. 还原每个空心矩形框的原始边界：每个框由灰(5) 像素构成一像素宽的完整矩形边框（四条边）。通过分析灰像素的空间分布，识别出所有独立的矩形框（可能需要拆分重叠区域）。
2. 对网格中每个灰(5) 像素，计算它被多少个矩形框的边框覆盖，记为重叠深度 d（范围 1~4）。
3. 建立深度到颜色的映射：深度 1 → 左上角像素颜色 C1，深度 2 → 右上角像素颜色 C2，深度 3 → 左下角像素颜色 C3，深度 4 → 右下角像素颜色 C4。
4. 将每个灰(5) 像素重涂为其深度对应的颜色。
5. 黑(0) 背景保持不变。四个角落的图例像素在输出中擦除为黑(0)。

**关键洞察**：角落像素不是空间标记——它们是深度层级的颜色图例，按固定的位置编码（左上=深度1, 右上=深度2, 左下=深度3, 右下=深度4）映射到重叠深度；求解者必须先还原每个框的原始完整边界以计算真实深度，而非仅看当前像素的颜色值（输入中所有框边框都是灰色，深度信息是隐式的）。

1. 通过密集带检测识别灰(5) 分隔线位置，确定 3x3 格阵结构和每个格子的内部范围。
2. 对格阵中每个格内局部坐标位置 (r, c)，统计 9 个格子在该位置的像素颜色，取出现次数最多的颜色作为恢复值（多数投票）。将所有 9 个格子的该位置替换为恢复值。此步消除随机噪声，恢复干净底图。
3. 恢复后，识别每个格子中不属于恢复底图的额外像素——即颜色既非蓝(1)、也非黑(0)、也非灰(5) 的像素。这些是标记像素。
4. 对每种标记颜色 M 和每个格内局部坐标 (r_m, c_m)，找出所有在 (r_m, c_m) 位置拥有颜色 M 的格子。若这些格子在格阵中处于同一行，则在该行中从最左到最右的标记格之间，所有中间格的 (r_m, c_m) 位置像素重涂为 M（覆盖恢复后的基色）。若处于同一列，则在该列中从最上到最下的标记格之间，所有中间格的 (r_m, c_m) 位置像素重涂为 M。
5. 灰(5) 分隔线保持不变。

**关键洞察**：噪声和标记在视觉上都是"不属于主图案的异常像素"，但投票恢复能消除随机噪声（因为噪声在不同格子中位置随机不一致），而标记在同色同位置的格子中一致保留，从而在恢复后凸显出来。求解者必须先理解投票恢复机制才能在恢复后的干净底图上正确识别和连接标记。

## 新题 11：面积位移决定着陆区洪泛填充

**组合逻辑**：[滑动/slide](已有) + [面积决定位移/area_determines_displacement](已有) → [洪泛填充/flood_fill](创新：填充目标不由墙直接划定，而由分量着陆位置间接确定) + [四连通分区/four_connected_partition](已有)

**来源原语**：
- 滑动、连通分量、面积决定位移、超界裁剪 ← 8e301a54
- 洪泛填充、分隔墙、封闭区域、四连通分区 ← 782b5218
- 忽略干扰项 ← 782b5218
- 擦除 ← 9bebae7a

**依赖链**：计算每个连通分量的像素面积 → 按面积决定向下滑动距离 → 滑动后分量着陆在某个下区分区内 → 以分量颜色洪泛填充其着陆分区。面积信息同时控制两件事：位移距离（物理运动）和填充目标（着陆位置决定填充哪个分区）。两步紧耦合：改变面积则着陆分区改变；改变分区布局则同一面积的分量着陆不同区域。

将上方的彩色连通分量按各自面积向下滑动，每个分量所落入的下方分区被洪泛填充为该分量的颜色。

**输入结构**：约 15x15 的网格，背景为黑(0)。一条红(2) 水平墙（贯穿全宽，一像素厚，位于网格约 1/3 高度处，如第 5 行）将网格分为上下两区。上区：3~4 个单色 4-连通小分量（每个 2~5 像素，颜色互不相同：蓝(1)、绿(3)、黄(4)、橙(7) 等），散布在不同行列位置，互不接触。下区：红(2) 水平墙下方有若干条红(2) 垂直短墙段（不贯穿全高，仅覆盖下区的 2~4 行，从水平墙向下延伸），将下区分为 3~4 个大小不等的 4-连通非红区域（矩形子分区）。生成约束：每个上区分量按其面积像素数向下滑动后（穿过水平墙），其最底行像素恰好落入不同的下区分区（不同分量着陆在不同分区中）；至少一个分量因面积较大而完全滑出网格底部边界（该分量被丢弃，其对应的潜在着陆分区不被填充）。

**规则**：
1. 识别红(2) 水平墙上方的所有 4-连通单色分量。计算每个分量的像素面积 A。
2. 将每个分量从其原始位置向下平移 A 行（分量整体下移，保持形状和水平位置不变）。清除上区该分量原始位置的像素为黑(0)。红墙对滑动不构成阻碍（分量穿越红墙移动，红墙像素保持不变）。
3. 若平移后分量的任何像素超出网格底部边界，该分量整体丢弃（不绘制到输出中，不触发填充）。
4. 对未丢弃的分量，确定其最底行像素所在的下区分区（由红色水平墙、红色垂直墙段和网格边缘围成的 4-连通非红区域）。
5. 将该分区内所有非红像素洪泛填充为该分量的颜色。分量本身的像素不在输出中单独绘制（仅保留填充结果）。
6. 未被任何分量着陆的分区保持黑(0)。红(2) 墙结构（水平墙和垂直墙段）全部保持不变。

**关键洞察**：连通分量既是颜色信息的载体又是隐式寻址工具——它们的面积决定了向下滑动的距离，而滑动的终点决定了哪个分区被填充为该颜色；分量本身在输出中消失，只有它们"投递"的颜色留在着陆分区中。需要多个示例才能确认位移量等于面积（而非其他属性如边界框尺寸）。
