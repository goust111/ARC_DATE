## 新题 1：对称性分流射线

**组合逻辑**：[筛选/filter](对称性判断) + [射线延伸/ray_extend](从对称体边界辐射) + [擦除/erase](清除非对称体) — 对称性检测不再用于裁剪输出，而是决定对象的空间角色（发射器 vs 障碍物），发射器的射线被障碍物阻断，最终障碍物本身被移除

**来源原语**：筛选(filter) ← 72ca375d；对称性筛选(symmetry_filter) ← 72ca375d；射线延伸(ray_extend) ← 1d398264；擦除(erase) ← 952a094c；阻挡像素(blocker_pixel) ← ff72ca3e

**依赖链**：对称性检测的结果将对象分为两个角色——发射器和障碍物；射线延伸依赖角色分配（只从发射器出发）并依赖障碍物位置确定终点；擦除依赖射线完成后才能移除障碍物。三个环节环环相扣：不做对称性检测则不知道谁发射谁阻挡；不做射线延伸则擦除后无法复原射线路径；不擦除障碍物则输出不正确。

从散布在网格中的若干单色小图形中，识别出具有对称性的图形作为射线发射源，沿其边界向外辐射射线直到碰到非对称图形或网格边缘，然后擦除所有非对称图形，留下发射源和射线。

**输入结构**：约 20x20 的黑(0)背景网格。网格中散布 4~6 个互不相邻的单色前景图形（每个图形为 4-连通、3~7 像素、各占一种非背景色，颜色互不相同）。其中恰好 2 个图形具有某种对称性（水平对称、垂直对称或 180 度旋转对称均可），其余图形无任何对称性。每个图形的边界框不超过 4x4。生成约束：对称图形的 4 个罗盘主方向（上下左右）上，至少有一个方向上存在非对称图形可作为阻挡。

**规则**：
1. 检测每个前景图形：将其裁剪为边界框内的掩码，测试水平反射对称、垂直反射对称、180 度旋转对称。满足其中任一者标记为"发射器"，全不满足标记为"障碍物"。
2. 对每个发射器，从其边界框的每条边的中心像素（若边长为偶数则取靠左/靠上的那个）出发，沿该边的法线方向（上边→向上、下边→向下、左边→向左、右边→向右）逐格延伸射线，逐像素绘制为该发射器的颜色。射线在以下任一条件时停止（不包含停止点）：(a) 到达网格边缘外；(b) 下一个像素属于任何障碍物图形的像素。
3. 擦除所有障碍物图形——将其所有像素重置为黑(0)。
4. 发射器图形本身保持不变；射线保留在输出中。

**关键洞察**：对称性检测并非为了选出唯一目标进行裁剪（参考题 72ca375d 的做法），而是将所有对象分为功能上互补的两类——发射器和障碍物——它们的空间关系决定了射线的长度；障碍物在完成阻挡功能后被擦除，这意味着求解者必须先推断出哪些图形曾经存在才能理解射线为何在特定位置截断。

## 新题 2：折叠对齐孔洞填色

**组合逻辑**：[折叠/fold](跨分隔线镜像叠加) + [填充/fill](孔洞填色，创新：填色源不是预设而是折叠对齐的结果) + [裁剪/crop](输出为填充后的左面板)

**来源原语**：折叠(fold) ← e3497940；透明叠加(transparent_overlay) ← e3497940；前景优先(foreground_priority) ← e3497940；填充(fill) ← 3a25b0d8；孔洞(hole) ← 3a25b0d8；裁剪(crop) ← 72ca375d

**依赖链**：折叠决定了右面板上的彩色标记像素落在左面板的哪个位置——只有折叠后恰好落入孔洞内部的标记才被采用来填充该孔洞；裁剪依赖于填充完成后的左面板。孔洞的填色颜色完全由折叠后的空间对齐决定，而不是由某种固定映射给出。

将网格沿垂直分隔线折叠，利用右面板上散布的彩色标记像素来填充左面板中形状内的孔洞，最终输出填充后的左面板。

**输入结构**：约 15x(2W+1) 的网格（W 约 7~9），中间有一列纯灰(5)的垂直分隔线贯穿全高。左面板（W 列）：黑(0)背景上有一个蓝(1)的单连通封闭形状（4-连通、约 20~30 像素），该形状内部有 2~3 个互不相邻的矩形孔洞（孔洞为黑(0)背景色，每个孔洞 2~4 像素）。右面板（W 列）：黑(0)背景上散布着若干单像素的彩色标记（使用红(2)、绿(3)、黄(4)等颜色，每个孔洞对应一种颜色）。生成约束：每个孔洞在折叠后恰好有且仅有一个标记落入其内部；落在非孔洞区域的标记至少存在 1 个（作为干扰）。

**规则**：
1. 识别灰(5)垂直分隔列，将网格分为等宽的左面板和右面板。
2. 将右面板水平镜像后叠加到左面板上。叠加规则：右面板的非背景像素投射到左面板对应位置。
3. 对左面板中蓝(1)形状的每个孔洞（连通的黑(0)背景区域，被蓝(1)完全包围）：检查叠加后是否有标记像素落在孔洞内部。若有，将整个孔洞填充为该标记的颜色。若孔洞内无标记落入，孔洞保持黑(0)不变。
4. 叠加到非孔洞位置（蓝色形状本身或形状外部背景）的标记像素被忽略（不改变任何内容）。
5. 输出为左面板（不含分隔列和右面板），保留蓝(1)形状和已填充的孔洞。

**关键洞察**：折叠不是为了将两个互补面板合并成完整图案（参考题 e3497940 的做法），而是提供了一种空间寻址机制——右面板上标记的位置经镜像映射后决定它填充哪个孔洞。求解者需要理解折叠是颜色到孔洞的路由方式，而非图案补全方式。

## 新题 3：走廊导航分段染色

**组合逻辑**：[射线延伸/ray_extend + 转弯/turn](走廊导航，路径经过散布的彩色标记) → [计数/counting](统计路径上经过的各色标记数量) → [重涂色/recolor](路径按经过标记的颜色分段重新着色)

**来源原语**：射线延伸(ray_extend) ← 6bcdb01e；转弯(turn) ← 6bcdb01e；碰撞转向(collision_turn) ← 6bcdb01e；遇障碍直角转(right_turn_at_block) ← 6bcdb01e；标记像素(marker_pixel) ← 253bf280；重涂色(recolor) ← 9565186b；计数(counting) ← 39a8645d

**依赖链**：走廊导航生成路径的空间轨迹和穿越标记的序列——没有路径就无法知道经过了哪些标记、以什么顺序经过；标记的颜色和出现位置决定了路径如何分段；分段规则依赖路径上标记的实际遭遇顺序而非它们在网格中的绝对位置。

在由障碍像素构成的走廊中导航路径，路径沿途穿过散布的彩色标记像素；路径最终按照标记的遭遇顺序被分段染色——每段采用最近经过的标记的颜色。

**输入结构**：约 18x18 的橙(7)背景网格。青(8)像素构成走廊壁（一格宽的通道，有若干 90 度弯角，总路径长度约 25~40 格）。一个 2 像素的绿(3) 4-连通起点条位于网格边缘（恰好一个像素在网格边界上）。走廊通道内（背景色位置）散布 3~5 个单像素彩色标记，使用红(2)、蓝(1)、黄(4)等颜色，每个标记颜色不同。走廊的另一端通向网格边缘（出口）。生成约束：走廊内两个相邻标记之间至少间隔 3 格路径距离；标记不紧邻走廊壁。

**规则**：
1. 从起点条的边界像素出发，沿起点条方向进入走廊，逐格前进。
2. 遇到走廊壁（青(8)像素）时，转向唯一可通行的垂直方向继续前进（走廊保证每个转弯处恰好有一个合法的 90 度转向）。到达网格外时停止。
3. 路径经过标记像素时，记录该标记的颜色和路径上的位置索引（从起点开始计数，起点=0）。标记像素本身保留原色不变。
4. 路径染色：将路径分段——从起点到第一个标记之间的路径段染为绿(3)（起点条颜色）；第 i 个标记到第 i+1 个标记之间的路径段染为第 i 个标记的颜色；最后一个标记到路径终点之间的路径段染为最后一个标记的颜色。
5. 走廊壁、标记像素和背景保持不变。仅路径上的非标记背景像素被染色。

**关键洞察**：走廊导航本身不产生颜色信息（参考题 6bcdb01e 中路径全部用起点颜色绘制），这里路径是颜色信息的载体——标记的空间位置沿路径被线性化为一个序列，该序列的顺序决定了每段路径的颜色。必须先完成导航才能确定染色方案。

## 新题 4：模板定位锚定风车旋转相位

**组合逻辑**：[模式匹配/pattern_match](用灰色 L 模板定位样本及其副本) + [旋转/rotate + 拼接/concatenate](组装风车，创新：风车的旋转起始相位由样本到副本的罗盘方向决定)

**来源原语**：模式匹配(pattern_match) ← e2092e0c；标记模板(stencil_marker) ← e2092e0c；形状相同(shape_match) ← e2092e0c；旋转(rotate) ← ed98d772；拼接(concatenate) ← ed98d772；四旋转组成风车(four_rot_pinwheel) ← ed98d772；罗盘方向(compass_direction) ← 1d398264

**依赖链**：模板匹配找到样本和副本两个位置——没有匹配就不知道副本在哪里；样本与副本的相对罗盘方向编码了风车的旋转相位偏移——方向检测依赖两个位置的坐标差；风车组装的四个象限中哪个放原图取决于方向值，因此三个环节紧密耦合。

用灰色 L 模板标记的样本找到其在网格中的唯一副本，根据样本到副本的罗盘方向确定风车旋转起始象限，将样本裁剪后组装为 2x2 四旋转风车。

**输入结构**：约 15x15 的黑(0)背景网格。一个 3x3 的彩色小图案（使用 2~3 种非背景非灰色的前景色，如红(2)、蓝(1)、绿(3)），紧邻其右侧和下方有灰(5)像素构成 L 形标记（右侧 3 个像素竖排、下方 3 个像素横排，共 5 个灰像素，角落共享一个）。该 3x3 图案在网格中恰好有一个完全相同的副本（无灰色标记）。副本与样本之间的相对位置满足四种罗盘方向之一：副本在样本的正右方、正左方、正上方或正下方（以边界框中心的行列差判断，差值较大的轴决定方向）。生成约束：副本周围至少有 1 格空白间距；样本和副本不重叠。

**规则**：
1. 找到灰(5) L 形标记，读取其左上方的 3x3 样本区域。
2. 在网格中搜索与该 3x3 样本完全相同的另一个位置（副本），忽略灰色标记区域。
3. 计算样本中心到副本中心的罗盘方向 D：若列差绝对值 >= 行差绝对值，列差>0 则 D=右，列差<0 则 D=左；否则行差>0 则 D=下，行差<0 则 D=上。
4. 构建 6x6 的输出风车（2x2 排列的 3x3 块）。四个象限按以下规则放置样本的旋转版本：
   - D=右：左上=原图，右上=逆时针90度，左下=180度，右下=顺时针90度。
   - D=下：左上=顺时针90度，右上=原图，左下=逆时针90度（即 270 度），右下=180度。（即整体顺时针旋转一个象限位）
   - D=左：左上=180度，右上=顺时针90度，左下=原图（即逆转两位），右下=逆时针90度。
   - D=上：左上=逆时针90度，右上=180度，左下=顺时针90度，右下=原图。（即逆转三位）
5. 输出仅为 6x6 风车，不包含原网格。

**关键洞察**：灰色 L 模板在参考题 e2092e0c 中用于定位样本并框选副本，风车在参考题 ed98d772 中的旋转起始相位是固定的。这里模板匹配产生的副本位置不是用来框选的，而是编码了一个方向参数，该参数改变风车的旋转相位——求解者必须对比多个示例（方向不同导致输出不同）才能归纳出方向→相位的映射规则。

## 新题 5：滑动计数驱动图案缩放

**组合逻辑**：[滑动/slide + 靠近障碍停止/stop_at_barrier](可移动色块向障碍物靠拢) → [计数/counting](统计每行停靠的色块数量) → [像素放大/pixel_upscale](行内种子图案按该行计数值进行缩放)

**来源原语**：滑动(slide) ← 9c56f360；固定障碍(fixed_barrier) ← 9c56f360；靠近障碍停止(stop_at_barrier) ← 9c56f360；计数(counting) ← 39a8645d；像素放大(pixel_upscale) ← e7a25a18；图案在框内(pattern_inside_frame) ← e7a25a18

**依赖链**：滑动操作改变了色块的空间位置——色块停靠后在每行的数量才能被正确统计（滑动前色块散布在右侧，计数无意义）；每行的计数值成为该行种子图案的缩放因子——没有滑动就没有正确的计数，没有计数就不知道缩放倍数。

网格左侧每行有一个小种子图案，右侧有可移动色块和固定障碍；色块向左滑动靠拢障碍后，统计每行紧靠障碍停下的色块数量，该数量作为该行种子图案的像素缩放倍数。

**输入结构**：约 12x20 的黑(0)背景网格，逻辑上分为左右两个区域（无显式分隔线，左区约占 5 列，右区约占 15 列）。左区：每行有一个 1x1 或 1x2 的种子图案（使用蓝(1)），位于该行最左侧的 1~2 列。右区：每行有 0~3 个红(2)可移动像素，它们各自形成单像素或短水平连续段，均位于行的右侧部分。每行至多有一个灰(5)固定障碍像素，位于行的中间偏左位置。生成约束：网格恰好 4 行高（简化为 4 行便于演示）；每行都有种子图案和至少一个障碍；每行的移动色块数量 N 在 1~3 之间，且不同行的 N 不全相同。

**规则**：
1. 识别三种前景元素：蓝(1)种子图案（每行最左侧）、灰(5)固定障碍、红(2)可移动色块。
2. 在每行中，将所有红(2)可移动色块向左滑动：清除原位置，将每个色块依次放置在该行灰(5)障碍右侧紧邻的第一个空位上（多个色块从左到右紧密排列在障碍右侧）。若该行无障碍，则色块紧贴左区右边界排列。
3. 统计每行停靠完成后红(2)像素的数量 N_r（r 为行号）。
4. 取每行的蓝(1)种子图案，将其做 N_r 倍像素缩放（每个像素扩展为 N_r x N_r 的方块）。将缩放后的图案绘制在该行种子图案原始位置的左上角对齐处（向右向下扩展），覆盖背景像素。若缩放后图案超出网格边界，截断超出部分。
5. 输出网格中保留灰(5)障碍、停靠后的红(2)色块、缩放后的蓝(1)图案。原始种子被缩放结果覆盖。

**关键洞察**：滑动操作在参考题 9c56f360 中是最终输出，像素放大在参考题 e7a25a18 中的倍率是固定常数。这里滑动是中间步骤——它产生的空间分布被量化为计数值，计数值再驱动另一个操作的参数。求解者需要先理解滑动规则，再发现停靠数量与缩放倍数的对应关系。

## 新题 6：网格线双重角色——裁剪边界兼连线调色

**组合逻辑**：[裁剪/crop](由缺失交叉点界定裁剪区域) + [连线/draw_line](同行列标记对之间填充连线，创新：连线颜色取决于路径是否穿越网格线)

**来源原语**：裁剪(crop) ← a644e277；网格线(lattice_line) ← a644e277；缺失交叉点(missing_intersection) ← a644e277；背景色空洞(background_hole) ← a644e277；连线(draw_line) ← 253bf280；标记像素(marker_pixel) ← 253bf280；行列对齐(row_col_align) ← 253bf280；同行列端点间填充(fill_between_aligned_endpoints) ← 253bf280

**依赖链**：缺失交叉点确定裁剪边界——不做裁剪则标记对的作用域不明确；裁剪后区域内的网格线不仅是视觉结构，还作为连线颜色的判定条件——连线是否穿越网格线改变其颜色，所以连线规则依赖网格线的精确位置；两套规则共享网格线这一结构但用途完全不同。

在有规则网格线的画布中，先用缺失交叉点裁剪出目标区域，然后在区域内连接同行同列的标记像素对；连线颜色由路径是否穿越网格线决定——穿越则用一种颜色，不穿越则用另一种。

**输入结构**：约 19x19 的黑(0)背景网格，其上绘有规则的品红(6)网格线（水平和垂直各 3~4 条，间距均匀，每条线 1 像素宽）。网格线的 4 个交叉点为黑(0)背景色（缺失交叉点），这 4 个点构成一个矩形的四角。网格线围成的若干单元格内散布着若干红(2)标记像素，每个标记为单像素。在裁剪区域内，任意一行或一列中至多有 2 个标记像素（0 个或 2 个）。生成约束：裁剪区域内至少有 3 对标记对，其中至少 1 对的连线穿越品红网格线，至少 1 对不穿越。

**规则**：
1. 找到品红(6)网格线中 4 个缺失交叉点（本应为品红但实际为黑色的网格交汇处），它们的行列坐标界定一个矩形区域。
2. 裁剪该矩形区域（含边界行列）作为输出的基底。
3. 在裁剪后的区域内，对每行检查：若该行恰好有 2 个红(2)标记像素，则在两者之间的所有背景像素上画连线。对每列同理。
4. 连线颜色判定：若两个标记之间的直线路径（水平或垂直）穿越了至少一条品红(6)网格线，则连线颜色为绿(3)；若路径不穿越任何网格线（两标记在同一单元格内），则连线颜色为黄(4)。
5. 连线不覆盖品红(6)网格线像素——遇到网格线像素时跳过，继续在网格线另一侧绘制。标记像素本身保留红(2)不变。

**关键洞察**：网格线在参考题 a644e277 中仅用于定位裁剪区域的缺失交叉点，在参考题 253bf280 中连线颜色是固定的。这里网格线同时承担两个功能：(1) 其缺失交叉点界定裁剪区域；(2) 其位置决定连线颜色。求解者必须认识到同一结构在两个不同逻辑层中各扮演角色。

## 新题 7：频率指定印章模板与印章位点

**组合逻辑**：[计数/counting + 频率排序/frequency_ranking](确定精灵体出现频率) → [印章覆盖/stamp_overlay](最高频精灵作为印章模板，最低频精灵的位置作为印章中心) + [擦除/erase](清除中间频率的干扰精灵)

**来源原语**：计数(counting) ← 39a8645d；频率排序(frequency_ranking) ← 9565186b；最高频精灵输出(most_frequent_sprite_output) ← 39a8645d；印章覆盖(stamp_overlay) ← 8719f442；前景掩码(foreground_mask) ← 8719f442；擦除(erase) ← 952a094c；忽略干扰项(ignore_distractors) ← 494ef9d7

**依赖链**：计数将精灵分为三个频率等级——不计数则无法分配角色；最高频精灵的形状成为印章模板——模板选择依赖计数结果；最低频精灵的位置成为印章中心点——不知道谁是最低频就无法确定在哪里盖章；中间频率的精灵是干扰项需擦除——角色分配完全由频率决定。

网格中有多种形状的小精灵体，每种出现不同次数；出现最多的精灵类型作为印章模板，印章被盖在出现最少的精灵类型的位置上，其余中间频率的精灵被擦除。

**输入结构**：约 20x20 的黑(0)背景网格。包含 3 种不同形状的单色前景精灵体（每种精灵所有实例颜色相同，不同种类颜色不同，使用红(2)、蓝(1)、绿(3)三种颜色）。每种精灵为 4-连通、3~6 像素、边界框不超过 3x3。三种精灵的出现次数严格不同（如 4 次、2 次、1 次），出现次数两两不等。各精灵实例之间互不相邻（至少 2 格间距）。生成约束：最低频精灵的每个实例周围有足够空间容纳最高频精灵的边界框（以该实例中心对齐后不超出网格且不与其他非背景像素重叠）。

**规则**：
1. 检测所有前景精灵体，将每个裁剪为边界框掩码（含颜色）。按形状+颜色相同分组。
2. 统计每组的实例数量。确定三个角色：最高频组=模板提供者，最低频组=位点标记者，中间频率组=干扰项。
3. 取模板提供者的掩码形状 T（3x3 边界框内的非背景像素分布）。
4. 对每个位点标记者的实例：以其边界框中心为对齐点，将模板 T 以模板提供者的颜色印章覆盖到该位置（模板中心对齐位点中心）。印章只覆盖背景像素，不覆盖已有非背景像素。
5. 擦除所有干扰项实例（像素置为黑(0)），擦除所有位点标记者的原始像素（被印章图案取代）。
6. 保留所有模板提供者的原始实例不变。

**关键洞察**：参考题 39a8645d 中频率最高的精灵被直接输出，参考题 8719f442 中印章模板来自输入本身的固定图案。这里频率排序不是选择输出对象，而是分配三种不同的功能角色（模板、位点、干扰）——同一个"计数"操作的结果驱动了三个不同的后续操作，形成多源汇聚结构。

## 新题 8：角标记发射切比雪夫方块

**组合逻辑**：[空心矩形/rectangular_frame + 角标记/corner_marker](结构识别) → [切比雪夫距离/chebyshev_dist](标记到最近框边的距离作为方块半径) → [填充/fill](以标记为中心画实心方块) + [擦除/erase](移除矩形框)

矩形框内四角有标记像素，每个标记以其到最近框边的切比雪夫距离为半径向外发射实心彩色方块，然后矩形框自身被擦除。

1. 识别品红(6)空心矩形框及其内部四角的 4 个彩色标记像素。
2. 对每个标记，计算其到矩形框最近边（上边、下边、左边、右边）的切比雪夫距离 d。由于标记在角落，d = min(到两条相邻框边的距离) = 1（标记紧邻框边）... 不，让我重新设计位置。标记不一定紧邻框边——它们位于框内部区域的四个角落像素位置：左上角标记在 (top+1, left+1)，右上角在 (top+1, right-1)，左下角在 (bottom-1, left+1)，右下角在 (bottom-1, right-1)。这里 top/bottom/left/right 是框的行列坐标。每个标记到最近框边的切比雪夫距离均为 1。这不够有趣。

   重新设计：标记不在角落，而是在框内部的任意位置，但恰好 4 个。

**输入结构**（修正）：约 18x18 的黑(0)背景网格。一个品红(6)单像素厚的空心矩形框（如 12x14）。框内部散布 4 个彩色标记像素（分别为红(2)、蓝(1)、绿(3)、黄(4)），位置各异，不在同一行或同一列。生成约束：矩形框非正方形；每个标记到矩形框四条边的最小切比雪夫距离互不全相同（至少产生 2 种不同的距离值）；以各标记为中心、以其距离值为半径画出的实心方块不超出网格边界。

1. 识别品红(6)空心矩形框。
2. 找到框内部的 4 个彩色标记像素。
3. 对每个标记像素 M，计算 d(M) = M 到矩形框四条边中最近那条边的曼哈顿距离（即 min(M.row - top, bottom - M.row, M.col - left, right - M.col)，其中 top/bottom/left/right 为框的内边界坐标）。

**关键洞察**：参考题 952a094c 中角标记被平移到框外对称位置，参考题 ff72ca3e 中方块半径由灰色阻挡像素的切比雪夫距离决定。这里矩形框既不是被保留的结构也不是阻挡物，而是一个隐式的距离标尺——它的边界决定了每个标记的方块大小，然后自身消失。求解者需要对比多个示例才能发现方块大小与标记到框边距离的对应关系。

## 新题 9：折叠重叠点触发罗盘射线

**组合逻辑**：[折叠/fold + 透明叠加/transparent_overlay](两面板折叠，检测前景重叠点) → [射线延伸/ray_extend + 罗盘方向/compass_direction](从每个重叠点向四个基本方向延伸射线) + [对称互补/symmetric_complement](非重叠前景像素界定射线终点)

**来源原语**：折叠(fold) ← e3497940；透明叠加(transparent_overlay) ← e3497940；前景优先(foreground_priority) ← e3497940；对称互补(symmetric_complement) ← e3497940；射线延伸(ray_extend) ← 1d398264；罗盘方向(compass_direction) ← 1d398264；中心向外辐射(radiate_from_center) ← 1d398264

**依赖链**：折叠产生两类特殊位置——重叠点（两侧均有前景）和单侧前景点；重叠点是射线发射源，单侧前景点是射线阻挡物——两类位置的角色都依赖折叠结果；射线从重叠点出发，在遇到单侧前景点或网格边缘时停止——射线行为同时依赖发射源和阻挡物的位置。

将网格沿分隔线折叠后，两面板前景像素重叠的位置成为射线发射点，仅单侧有前景的位置成为射线阻挡物；从每个发射点向四个基本方向延伸射线直到遇到阻挡物或边界。

**输入结构**：约 13x(2W+1) 的网格（W 约 6），黑(0)背景，中间有一列品红(6)垂直分隔线贯穿全高。左面板和右面板各有若干红(2)前景像素（每面板 5~10 个像素，形成不规则分布）。两面板的前景像素构成互补图案，但并非完全互补——存在 2~4 个位置两侧都有前景（折叠后重叠），以及若干位置仅一侧有前景。生成约束：重叠点至少 2 个且不在同一行或同一列；从每个重叠点的 4 个基本方向中，至少 2 个方向上存在单侧前景像素作为阻挡。

**规则**：
1. 识别品红(6)分隔列，将网格分为等宽左右面板。
2. 将右面板水平镜像后与左面板对齐。分类每个位置：
   - "重叠点"：左右两侧该位置均有红(2)前景像素。
   - "单侧点"：仅一侧该位置有红(2)前景像素。
   - "空位"：两侧均为背景。
3. 以左面板尺寸创建输出网格，背景为黑(0)。保留所有单侧点，颜色为红(2)。
4. 对每个重叠点，向上、下、左、右四个方向逐格延伸射线，颜色为绿(3)。射线在以下条件停止（不包含停止点）：(a) 到达网格边缘外；(b) 下一格是单侧点（红(2)像素）。
5. 重叠点本身绘制为黄(4)（与射线颜色不同，以标识发射中心）。

**关键洞察**：参考题 e3497940 的折叠是为了将互补的两半合并为完整图案，重叠像素只是验证一致性。这里折叠不产生完整图案，而是产生一种空间分类——同一个折叠操作的结果被解读为两种对立角色（发射器 vs 阻挡器）。求解者必须先理解折叠如何将像素分类，再理解分类结果如何驱动射线行为。

## 新题 10：可达性筛选后按面积排序聚集

**来源原语**：可达性(reachability) ← dd6b8c4b；墙壁障碍(wall_barrier) ← dd6b8c4b；聚集(gather) ← dd6b8c4b；距离排序填充(distance_ranked_fill) ← dd6b8c4b；裁剪(crop) ← 72ca375d；精灵体(sprite) ← 72ca375d；计数(counting) ← 39a8645d

**依赖链**：可达性判断过滤掉被墙壁阻隔的精灵——不做洪水填充就不知道哪些精灵是候选者；对候选精灵按像素面积排序——排序结果决定它们在目标区域中的放置顺序；裁剪将每个精灵提取为独立的边界框——聚集操作需要裁剪后的精灵作为输入。三个环节必须依次完成。

网格中有墙壁和散布的彩色精灵体，通过洪水填充判断哪些精灵可从目标区域到达；将可达的精灵按像素面积从小到大裁剪后拼入目标区域。

**输入结构**：约 18x18 的橙(7)背景网格。品红(6)像素构成若干墙壁段（1 像素厚的水平或垂直线段，总共 3~5 段，将网格分隔为若干连通区域）。4~6 个彩色精灵体散布在不同区域中（每个精灵为 4-连通、3~8 像素、各一种颜色，使用红(2)、蓝(1)、绿(3)、黄(4)、灰(5)等，颜色互不相同）。一个 红(2)单像素标记目标区域的锚点。目标区域为锚点所在的一块空闲橙(7)区域（锚点右下方的一个矩形空间，大小恰好容纳所有可达精灵的边界框水平排列）。生成约束：至少 1 个精灵因墙壁阻隔而不可达；可达精灵的像素面积两两不同；目标区域右下方有足够空间排列所有可达精灵。

**规则**：
1. 找到红(2)锚点像素。
2. 从锚点出发，通过橙(7)背景像素和精灵像素（不穿越品红(6)墙壁）进行洪水填充（4-连通），标记所有可达像素。
3. 精灵体若其任意像素被标记为可达，则该精灵为"可达精灵"；否则为"不可达精灵"。
4. 将每个可达精灵裁剪为其最小边界框（保留颜色和形状，背景填充为橙(7)）。
5. 按像素面积（精灵中非背景像素数量）从小到大排序。
6. 在锚点右侧 1 格开始，将排序后的精灵边界框从左到右水平排列（相邻精灵之间间隔 1 列橙(7)背景），垂直方向与锚点行顶部对齐。
7. 擦除可达精灵在原位置的像素（置为橙(7)）。不可达精灵保持原位不动。墙壁保持不变。锚点保留。

**关键洞察**：参考题 dd6b8c4b 中聚集的排序标准是距离（到目标的路径长度），目标是固定大小的 3x3 区域。这里排序标准变为精灵自身的面积属性——一个内在属性而非外在空间关系；目标区域的大小是动态的，取决于可达精灵的数量和尺寸。求解者需要同时理解两个独立的筛选/排序维度：可达性（空间约束）和面积（内在属性）。
