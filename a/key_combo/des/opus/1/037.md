## 新题 1：枢轴反射生成射线交叉

**组合逻辑**：[点对称/point_symmetry](创新：从整体掩码反射改为逐点生成新种子位置) + [射线延伸/ray_extend](已有) + [交叉点特殊着色/intersection_colored](创新：仅对称配对之间的交叉才标红，而非所有交叉)

**来源原语**：点对称(point_symmetry)、枢轴像素(pivot_pixel) from 90347967；射线延伸(ray_extend)、交叉点特殊着色(intersection_colored)、重涂色(recolor) from 23581191；标记像素(marker_pixel) from 97c75046

**依赖链**：枢轴定义反射映射，为每个标记生成其对称孪生种子 → 所有种子（原始+反射）各自发射全行全列射线 → 仅当原始标记的射线与其自身反射体的射线交叉时才标红。枢轴不存在则无反射种子；射线不存在则无交叉几何；配对规则不存在则红色标记无法确定。

将彩色标记通过灰色枢轴作 180 度反射，从所有标记（原始与反射）画满行满列十字线，仅在每对原始-反射标记的射线交叉处涂红。

**输入结构**：约 15x15 的黑(0)背景网格。网格中有一个灰(5)单像素作为枢轴。另有两到三个单像素彩色标记，每个标记颜色互不相同，取自 {蓝(1), 绿(3), 橙(7)}。约束：任意两个标记（含反射后生成的）不共行也不共列；所有反射位置落在网格内；没有标记与枢轴共行或共列。

**规则**：
1. 对每个彩色标记 (r, c)，通过灰色枢轴 (pr, pc) 计算 180 度反射位置：(2*pr - r, 2*pc - c)。在反射位置绘制与原标记相同颜色的像素。
2. 对每个标记（原始和反射共 2N 个），绘制一条横跨整行的水平线和一条纵贯整列的垂直线，颜色为该标记的颜色。
3. 绘制顺序：先绘制全部水平线（水平线之间顺序不影响结果），再绘制全部垂直线（垂直线覆盖同位置的水平线）。
4. 所有线绘制完毕后，检查每个单元格：若该单元格同时位于某原始标记的行线与该标记对应反射体的列线的交叉处，或位于某原始标记的列线与其反射体的行线的交叉处，则将该单元格重涂为红(2)。不同底色标记之间的交叉不涂红。
5. 枢轴像素若被线覆盖，保留线绘制步骤赋予的颜色。

**关键洞察**：每对原始-反射标记与枢轴构成一个以枢轴为中心的矩形。红色单元格总是出现在该矩形中不被任何标记占据的另外两个角上——这一矩形结构在输入中不可见，只有将枢轴的反射角色与射线的交叉几何结合才能推断。

## 新题 2：格子多数决压缩与少数派驱动的逐行循环位移

**组合逻辑**：[多数决/majority_vote + 压缩/compress](已有：逐块取多数色压缩) → [计数/counting](创新：计数每块少数派像素数而非面积) → [循环位移/cyclic_roll](创新：每行独立位移量由该行最左块的少数派像素数决定，而非由外部控制列决定)

**来源原语**：多数决(majority_vote)、压缩(compress)、格子格局(lattice_layout)、分隔行列(separator_row_col)、填色块(filled_block) from af24b4cc；循环位移(cyclic_roll) from 6d1d5c90；计数(counting)、位移等于面积(shift_equals_area) from b2bc3ffd

**依赖链**：分隔线定义格子块 → 每块取多数色得到压缩图，同时记录少数派像素数 → 压缩图的每一行按该行最左块的少数派数循环右移。多数决同时产出"压缩图像"和"位移参数"，二者不可分离——去掉多数决则无压缩图，去掉少数派计数则无位移量，去掉循环位移则压缩图与输出不符。

将分隔线划分的格子按多数决压缩为小网格，再将每行按其最左块中被丢弃的少数派像素数循环右移。

**输入结构**：约 15x18 的网格。灰(5)背景形成完整的分隔行和分隔列（含外边框），将内部划分为 R x C 的等大矩形块格子（例如 3 行 x 4 列，每块约 3x3 像素）。每个块内部全部填满非灰非黑的像素，每块恰好包含两种颜色，其中一种严格占多数（至少占块面积的 60%）。不同块的两种颜色和多数色可以不同。生成约束：同一压缩行内各块的多数色互不相同（保证输出无歧义）；每行最左块的少数派像素数在 0 到 C-1 之间（保证循环位移有意义且不超出列数）。

**规则**：
1. 识别分隔行和分隔列（全灰的行/列），确定格子结构。
2. 对格子位置 (i, j) 的每个块，确定其唯一多数色 M(i,j)，并计算少数派像素数：min_count(i,j) = 块面积 - 多数色像素数。
3. 构建压缩网格：R x C 的小网格，单元格 (i, j) 颜色为 M(i, j)。
4. 对压缩网格的每行 i，令 shift_i = min_count(i, 0)，即该行最左块的少数派像素数。
5. 将压缩网格第 i 行循环右移 shift_i 个位置（右端移出的像素从左端重新进入）。
6. 输出为位移后的压缩网格，外围加一圈灰(5)边框。

**关键洞察**：多数决表面上丢弃了少数派像素，但少数派的数量恰恰是输出最终排列的关键。求解者必须同时提取两层信息：(a) 每块的多数色构成压缩图像，(b) 最左块被"丢弃"的少数派数量决定该行的偏移。只看多数色或只数少数派都不够——二者必须从同一组块中一起提取。

## 新题 3：异常精灵体作缩放印章模板与无重叠门控

**组合逻辑**：[异常值选择/outlier_selection + 裁剪/crop](创新：异常精灵体不再直接输出，而是成为后续印章操作的模板) → [像素放大/pixel_scaling + 边长定缩放因子/side_sets_scale](已有：标记方块边长定缩放) → [印章覆盖/stamp + 无重叠时叠加/overlay_no_overlap](创新：在逐步演化的画布上动态检查重叠，而非两个固定面板间的静态比较)

**来源原语**：异常值选择(outlier_selection)、唯一图案选取(unique_pattern_selected)、裁剪(crop)、连通分量(connected_component) from cd3c21df；像素放大(pixel_scaling)、印章覆盖(stamp)、标记方块(marker_square)、边长定缩放因子(side_sets_scale) from 447fd412；无重叠时叠加(overlay_no_overlap) from bbb1b8b6

**依赖链**：异常值检测确定哪个精灵体是模板 → 每个绿色方块的边长决定缩放因子 → 缩放后的模板逐个印章到方块位置，但仅当缩放模板完全落入空白区域时才执行。先处理的小方块印章成功后占据画布空间，可能阻断后续大方块的印章。去掉异常值检测则无模板；去掉方块边长则无缩放因子；去掉重叠检查则所有印章无条件成功。

找出唯一不重复的蓝色精灵体作为模板，按每个绿色方块的边长缩放后印章到该方块位置，仅在缩放模板完全不与已有内容重叠时才执行。

**输入结构**：约 20x20 的黑(0)背景网格。散布五到七个 4-连通蓝(1)精灵体（每个 3-6 像素），精灵体之间互不接触。精灵体以精确的重复对出现——相同边界框裁剪（含内部黑色像素）的精灵体恰好出现两次——唯独一个精灵体的裁剪图案独一无二（异常模板）。此外有两到三个实心绿(3)方块，边长各不相同（如 2 和 3），散布在网格中不同位置，与任何蓝色精灵体不 4-邻接。生成约束：异常模板的边界框足够小（即使以最大方块边长缩放后不超过 9x9）；至少一个绿色方块周围有足够空间容纳其缩放印章，至少一个没有（保证门控规则可被观察到）。

**规则**：
1. 找到所有 4-连通蓝色精灵体，将每个裁剪为其边界框（含内部黑色像素）。
2. 比较所有裁剪图案：找到恰好只出现一次的唯一裁剪图案，该精灵体即为模板 T。
3. 将绿色方块按边长升序排列。边长相同时按左上角位置排序：先行后列，从上到下从左到右。
4. 按顺序处理每个绿色方块 S（边长 k，左上角 (rs, cs)）：
   a. 将模板 T 按因子 k 放大：T 中每个像素扩展为 k x k 的块。放大后的模板左上角对齐 (rs, cs)。
   b. 检查放大模板中所有非背景像素将要覆盖的位置。若任一位置当前为非黑色（蓝色精灵体、绿色方块、或先前印章的红色），则跳过此方块——保留绿色方块不变，继续下一个。
   c. 若放大模板的任何像素落在网格外，也视为重叠，跳过此方块。
   d. 否则，在计算出的位置将放大模板的非背景像素涂为红(2)，并移除该绿色方块（其位置涂为黑色）。
5. 所有原始蓝色精灵体保持不变。未被处理的绿色方块保持绿色。

**关键洞察**：异常值检测与重叠门控通过画布状态交互——模板的形状（由哪个精灵体是异常值决定）直接影响哪些绿色方块有足够空间接收印章。不同的异常模板形状可能导致不同的方块成功。此外，小方块优先处理并可能阻断大方块，因此处理顺序影响最终结果。

## 新题 4：沿障碍轮廓滑动，面积即行程

**组合逻辑**：[滑动/slide + 轮廓邻接/contour_adjacency](创新：从单标记单次滑动改为多对象各自沿轮廓滑动) + [计数/counting + 位移等于面积/shift_equals_area](创新：面积不再控制直线平移距离，而是控制沿曲线轮廓的行走步数)

**来源原语**：滑动(slide)、轮廓邻接(contour_adjacency)、障碍轮廓(obstacle_contour) from 97c75046；计数(counting)、平移(translate)、位移等于面积(shift_equals_area)、前景对象(foreground_object) from b2bc3ffd

**依赖链**：每个小对象的像素数给出行程距离 → 每个对象沿直线视线找到障碍入口点 → 从入口点沿障碍外轮廓顺时针走该行程步数到达目的地 → 对象被移动到目的地外侧。障碍形状决定路径弯曲程度，面积决定走多远。去掉面积计数则距离不确定；去掉轮廓则路径不确定；两者缺一则输出位置无法确定。

将每个彩色小对象沿中央障碍的外轮廓顺时针滑动，滑动步数等于该对象自身的像素数。

**输入结构**：约 15x15 的黑(0)背景网格。网格中心附近有一个大型连通灰(5)区域（约 5x5 到 7x7 像素，形状不规则，无孔洞）作为障碍。障碍周围散布三到四个小型单色 4-连通对象（每个 2-5 像素，颜色互不相同，取自 {蓝(1), 红(2), 绿(3), 黄(4)}）。每个对象至少有一个像素与灰色障碍 4-邻接（紧贴障碍外侧），但自身不含灰色像素。每个对象到障碍有唯一明确的邻接方向（对象整体位于障碍的某一侧）。生成约束：所有对象滑动后不会相互碰撞；障碍轮廓足够长使得没有对象环绕一整圈；每个对象与障碍的邻接关系无歧义。

**规则**：
1. 对每个彩色对象，计算其面积 A（像素数）。
2. 确定对象的入口点：该对象 4-邻接的障碍边界像素。若对象与多个障碍边界像素邻接，取对象质心最近的那个障碍像素作为入口点。
3. 从入口点出发，沿障碍的外轮廓顺时针追踪恰好 A 步。每步移动到下一个轮廓单元格（顺时针方向上相邻的灰色像素，该像素至少有一个 4-邻接的黑色像素，即始终在障碍边缘行走）。
4. 到达目的地轮廓单元格后，将整个对象（保持形状、颜色和朝向不变）平移，使得对象中原本与入口点邻接的像素现在与目的地轮廓单元格 4-邻接，位于障碍外侧。
5. 清除对象原始位置（涂为黑色）。
6. 按面积从小到大处理对象。若面积相同，按对象质心行坐标从小到大、再按列坐标从小到大排序。若某对象移动后会与已完成移动的对象重叠，则该对象在轮廓上回退一步（取 A-1 步的位置），直到不重叠为止；若回退到 0 步仍重叠则保持原位。
7. 灰色障碍保持不变。

**关键洞察**：对象的面积既是静态属性（像素数）又是动态行为参数（轮廓行程距离）。由于障碍形状不规则，轮廓是弯曲的——相同面积的对象在不同起点出发会到达完全不同的相对位置。求解者必须同时数像素、描摹轮廓几何、并将二者结合才能确定终点。

## 新题 5：灰轨裁剪与角标编码的旋转对称补全

**组合逻辑**：[裁剪/crop + 竖直线段/vertical_segment + 角标记像素/corner_marker](已有：灰轨定裁剪范围) → [角标记像素 → 旋转方向编码](创新：角标不再仅标记边界，其对角占位模式编码旋转方向) → [对称补全/symmetry_completion + 旋转/rotate](创新：旋转方向不再固定为顺时针，而由输入几何特征动态决定)

**来源原语**：裁剪(crop)、竖直线段(vertical_segment)、角标记像素(corner_marker)、线段定裁剪列范围(lines_set_crop_columns)、扩展含角标行(row_includes_corner_markers)、边界(boundary) from 3f7978a0；对称补全(symmetry_completion)、旋转(rotate)、缺失部分标记新色(missing_marked_new_color)、旋转对称(rotational_symmetry) from 1b60fb0c；忽略干扰项(ignore_distractors) from cd3c21df

**依赖链**：灰轨 + 青角标定义裁剪区域（crop）→ 两个青角标占据裁剪矩形四角中的哪条对角线编码旋转方向 → 裁剪区域内的蓝色形状按推断方向旋转 90 度补全缺失部分。去掉裁剪则干扰像素使对称中心不可判断；去掉角标解读则旋转方向未知；去掉对称补全则形状不完整。角标像素同时服务于空间定界和参数编码，单一几何特征承担双重角色。

裁剪灰轨之间（含青色角标标定范围）的区域，再按角标对角占位所编码的方向补全内部蓝色形状的旋转对称性。

**输入结构**：约 16x16 的黑(0)背景网格，网格中散布 5-10 个青(8)干扰像素（随机位置，全部位于灰轨区域外部）。两根竖直灰(5)线段（每根 4-8 像素高，严格竖直排列）分别作为左轨和右轨。在灰轨顶端上方一行和底端下方一行，各有若干青(8)角标像素位于灰轨对应的列位置——恰好两个角标占据裁剪矩形四角中的一条对角线：要么 {左上, 右下}，要么 {右上, 左下}。灰轨之间（含角标行）的区域内有一个蓝(1)形状，该形状具有近似 4 重旋转对称性，但缺少约四分之一的像素（缺失部分为黑色）。形状的对称中心位于裁剪区域的几何中心。生成约束：裁剪区域为正方形或近正方形（行数与列数差不超过 1）；蓝色形状的三个象限部分存在且互相通过 90 度旋转吻合；缺失象限明确可辨。

**规则**：
1. 检测两根竖直灰色线段，按列位置从左到右排序。裁剪区域的列范围为左轨列到右轨列（含），行范围为较长线段顶端上方一行到底端下方一行（夹紧至网格边界）。
2. 在裁剪矩形的四个角位置中找到恰好两个青色像素（它们位于同一条对角线上）。
3. 确定旋转方向：
   - 若青标位于左上角和右下角：补全旋转方向为顺时针 90 度。
   - 若青标位于右上角和左下角：补全旋转方向为逆时针 90 度。
4. 在裁剪区域内，以蓝色形状边界框的几何中心作为对称中心。
5. 将每个蓝色像素绕对称中心按确定方向旋转 90 度。
6. 若旋转后的位置在裁剪区域内且当前为黑色（空），则涂为红(2)。若该位置已有蓝色像素，则保持蓝色不变。
7. 输出仅为裁剪区域（包含灰轨、青角标、蓝色形状和红色补全像素）。裁剪区域外的一切（含青色干扰像素）被丢弃。

**关键洞察**：青色角标像素表面上只是边界标记（如参考题 3f7978a0），但它们的对角占位模式隐含了旋转补全的方向信息。灰轨外的青色像素是纯干扰项。求解者必须同时在空间维度（定义裁剪边界）和符号维度（解读旋转方向）使用角标——单一几何特征承担双重语义。

## 新题 6：几何自适应折线连接与有序覆盖

**组合逻辑**：[同色配对/same_color_pairing](已有：同色标记成对) → [曼哈顿路径/manhattan_path + 折线连接/L_path_connection](创新：折线弯折方向不再固定为"先水平后垂直"，而由标记对自身的空间长宽比动态决定) + [处理顺序决定遮挡/order_determines_block](创新：按曼哈顿距离排序处理，而非按颜色索引或固定的水平/垂直优先级)

**来源原语**：连线(draw_line/line_drawing)、同色配对(same_color_pairing)、共行或共列(shared_row_or_column)、纵线覆盖横线(vertical_over_horizontal_priority) from 070dd51e；曼哈顿路径(manhattan_path)、折线连接(L_path_connection)、起点标记(start_marker)、终点标记(end_marker) from a2fd1cf0；处理顺序决定遮挡(order_determines_block) from 1190bc91

**依赖链**：同色配对确定哪些标记相连 → 每对标记的水平距离与垂直距离之比决定折线弯折方向（较大轴优先）→ 按曼哈顿距离从小到大处理，后画的覆盖先画的。去掉配对则连接关系不明；去掉几何规则则弯折方向不确定；去掉处理顺序则交叉处颜色有歧义。

将每对同色标记以 L 形折线连接，折线弯折方向取决于该对标记的主导分离轴，按曼哈顿距离从短到长依次绘制，后绘制的路径在交叉处覆盖先绘制的。

**输入结构**：约 12x12 的黑(0)背景网格。三到四种前景色，每种颜色恰好出现两个单像素标记。每对同色标记不共行也不共列（因此每对需要 L 形折线而非直线段）。不同颜色的标记不重叠。生成约束：至少一对标记的水平距离严格大于垂直距离，且至少一对标记的垂直距离大于等于水平距离（确保两种弯折方向都出现）；至少两条路径存在交叉（使处理顺序规则可被观察）。

**规则**：
1. 按颜色将标记配对。
2. 对每对标记 (r1, c1) 和 (r2, c2)，计算：
   - 水平距离 dH = |c1 - c2|
   - 垂直距离 dV = |r1 - r2|
   - 曼哈顿距离 D = dH + dV
3. 确定每对的弯折方向：
   - 若 dH > dV：先画水平段（从一个标记沿其行画到另一标记的列），再画垂直段（从该拐点沿列画到另一标记）。即"水平优先"。
   - 若 dV >= dH：先画垂直段（从一个标记沿其列画到另一标记的行），再画水平段（从该拐点沿行画到另一标记）。即"垂直优先"。
   - 具体选择哪个标记作为起点：以行坐标较小的标记作为起点；行坐标相同时以列坐标较小的作为起点。
4. 按曼哈顿距离 D 升序排列所有配对。D 相同时，取起点标记行坐标较小者优先；仍相同则取起点列坐标较小者优先。
5. 按此顺序依次绘制每对的 L 形路径，颜色为该对标记的颜色。两段线均包含端点。每个新绘制的像素覆盖该位置先前的任何颜色（包括之前配对的路径）。
6. 最后，确保所有原始标记像素恢复为其原始颜色（标记像素不被路径覆盖）。

**关键洞察**：L 形折线的弯折方向不是固定的（不像参考题 a2fd1cf0 中始终水平优先），而取决于每对标记自身的空间构型——"宽"的对先水平再垂直，"高"的对先垂直再水平。仅凭一个只含单一长宽比类型的示例无法推断完整规则——求解者必须观察到两种构型并归纳出"主导轴优先"的通用法则。覆盖顺序增添了第二层推理：短路径先画可能被长路径部分覆盖，交叉处的颜色揭示了处理次序。
