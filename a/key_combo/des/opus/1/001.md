## 新题 1：互补拼合后对称筛选裁剪

**组合逻辑**：[形状匹配/互补形状](已有) → [填充/模板缺口](已有) → [镜像/对称图案选取](创新：对称检测作用于拼合后的复合对象，而非原始对象) → [裁剪](已有)

**来源原语**：形状匹配(shape_match)、互补形状(complementary_shape)来自 18447a8d；对称(symmetry)、对称图案选取(symmetric_selected)来自 d56f2372；裁剪(crop)来自 d56f2372/2c0b0aff

**依赖链**：互补匹配确定哪块填充片嵌入哪个框架 → 嵌入后产生完整矩形 → 对称检测作用于拼合结果（非原始输入）以筛选唯一目标 → 裁剪提取该目标。删除匹配步骤则无法构造完整矩形，删除对称检测则不知道裁剪谁，删除裁剪则无法得到输出。

将散落的填充片与带缺口的矩形框架一一匹配并拼合，从所有拼合结果中选出唯一具有左右镜像对称性的完整矩形，裁剪输出。

**输入结构**：约 15x15 网格，黑(0)背景。一条竖直灰(5)分隔列将网格分为左右两区。左区：3~4 个不同颜色的矩形框架（每个框架是一个由单一前景色构成的矩形，但内部被挖去一个不规则缺口，缺口处露出黑(0)背景；框架颜色各不相同，取自蓝(1)、红(2)、绿(3)、黄(4)）。每个框架约 4x5 至 6x7 像素，缺口面积 3~6 像素，缺口形状为不规则的 4-连通区域。右区：与左区框架数量相同的青(8)小形状，每个 3~6 像素，4-连通。每个青色形状的像素掩码（平移归一化后）恰好与某一个框架的缺口形状相同。各框架与各填充片之间是一一映射。生成约束：恰好有一对框架-填充片拼合后形成的矩形在左右镜像翻转下不变；其余拼合结果均不满足左右对称。

**规则**：
1. 对右区每个青(8)形状，将其像素掩码平移归一化（左上角对齐至原点），对左区每个框架的缺口区域同样归一化，找到掩码完全相同的唯一配对。
2. 将每个青色形状嵌入其匹配框架的缺口中（青色像素填充缺口位置），形成一个完整的矩形（无黑色孔洞）。
3. 对每个完成的矩形，裁剪至其包围框，测试该裁剪结果是否在左右翻转下逐像素不变。
4. 选出唯一满足左右对称的完成矩形。
5. 输出 = 该矩形的裁剪结果。缺口区域的像素为青(8)，框架区域的像素保持框架原色。灰色分隔列和其他所有内容被丢弃。

**关键洞察**：对称性检测既不能直接施加于框架（有缺口，不对称），也不能施加于填充片（形状太小，对称与否无意义）——只有拼合后的复合矩形才是对称测试的对象。拼合步骤是对称检测的前提，对称检测是裁剪目标选取的前提。

## 新题 2：十字轴象限内封闭区域的对角互染

**组合逻辑**：[十字轴线/象限划分](已有) → [封闭区域/内部包含](已有，创新：检测对象非杯形而是任意闭合环) → [重涂色](创新：填色来源不是本象限而是对角象限的形状颜色)

**来源原语**：十字轴线(cross_axis)、双轴对称(biaxial_symmetry)来自 60d73be6；封闭区域(enclosed_region)、内部包含(interior_containment)来自 aba27056；重涂色(recolor)来自 e8dc4411/e9ac8c9e

**依赖链**：十字轴线定义四象限 → 每个象限内的闭合形状独立进行内部检测 → 填充颜色由对角象限的形状颜色决定（跨象限引用）。删除十字轴线则无法划分象限，删除内部检测则不知道填什么区域，删除对角映射则不知道用什么颜色。四个象限之间存在两两交叉引用的同时约束关系，而非线性流水线。

在被十字轴线分割的四个象限中，每个闭合形状的内部空腔用对角象限形状的颜色填充。

**输入结构**：约 15x15 网格，黑(0)背景。灰(5)十字轴线：恰好一行和一列全部为灰(5)，二者相交于网格内部（不必在正中心，但将网格分为四个非空象限）。四个象限各含恰好一个闭合形状——一个由单一前景色构成的 4-连通环形区域（环宽 1 像素，内部有 2~6 个黑色空腔像素，环的外部也是黑色）。四个形状的颜色互不相同，取自蓝(1)、红(2)、绿(3)、黄(4)。形状不触碰十字轴线，不触碰网格边界，各形状之间无接触。生成约束：每个形状至少封闭 2 个内部像素。

**规则**：
1. 识别十字轴线：找到全灰(5)的完整行和完整列，其交点为轴心。
2. 以轴心为原点，将网格划分为四个象限：左上(TL)、右上(TR)、左下(BL)、右下(BR)。
3. 在每个象限中检测闭合形状，并找到其封闭的内部像素（即无法通过黑色像素路径到达象限边界的黑色像素集合）。
4. 建立对角映射：TL <-> BR，TR <-> BL。
5. 将每个形状的内部像素填充为其对角象限形状的颜色。例如：若 TL 象限形状为蓝(1)、BR 象限形状为黄(4)，则 TL 形状的内部填充黄(4)，BR 形状的内部填充蓝(1)。
6. 十字轴线、形状轮廓、所有非内部像素保持不变。

**关键洞察**：填充颜色不来自形状自身、不来自邻接象限，而来自对角象限——必须同时识别全部四个形状的颜色和位置后，才能确定任何一个形状的填充色。这是一个同时约束问题，非流水线可解。对角映射关系（而非顺时针或邻接）需要对比多个示例才能归纳。

## 新题 3：奇偶平移边界裁切与面积淘汰压缩

**组合逻辑**：[排列顺序/奇偶定方向](已有) → [交替平移](已有，创新：超出网格的像素被裁切，导致面积变化) → [计数/指定面积筛选](创新：面积不是输入的固有属性，而是平移裁切后的派生属性) → [压缩/空行丢弃](已有)

**来源原语**：交替平移(alternating_shift)、排列顺序(ordering)、奇偶定方向(parity_determines_dir)来自 4364c1c4；连通检测(connected_component_detection)、计数(counting)、指定面积筛选(specific_area_filter)来自 2c0b0aff；压缩(compress)、空行丢弃(empty_rows_discarded)来自 25c199f5

**依赖链**：排序确定奇偶 → 奇偶决定平移方向 → 靠近边界的对象平移后像素被裁切 → 裁切改变面积 → 面积低于阈值的对象被淘汰 → 淘汰后产生空行 → 压缩消除空行。关键耦合点：平移方向（由排序奇偶决定）与对象靠近哪个边界共同决定了裁切量，裁切量决定了存活与否。这在任何一道参考题中均不存在。

按空间顺序排列前景对象，奇数位左移、偶数位右移各一列（超出网格则裁切），淘汰裁切后面积不足的对象，最后压缩去除空行。

**输入结构**：约 14x16 网格，橙(7)背景。6~8 个单色 4-连通前景对象，颜色取自蓝(1)、红(2)、绿(3)、黄(4)、灰(5)（同色对象允许出现多个）。每个对象 3~8 像素，形状不规则（非矩形），用连通性和像素数描述而非具体形状名。各对象的包围框最高行互不相同（保证排序唯一）。部分对象紧贴网格左边界或右边界（即含有列坐标为 0 或列坐标为 grid_width-1 的像素），其余对象远离边界。对象之间互不接触。

**规则**：
1. 按各对象包围框最高行从小到大排序（最高行 = 最靠近顶部的行号），得到排名 1, 2, 3, ...。
2. 奇数排名对象（第 1、3、5...）的所有像素列坐标减 1（左移一列）。偶数排名对象的所有像素列坐标加 1（右移一列）。
3. 平移后列坐标小于 0 或大于等于网格宽度的像素被丢弃（边界裁切）。被移走的原位置恢复为橙(7)背景。
4. 对每个对象重新计算其剩余像素数（面积）。若面积严格小于 4，则该对象被整体淘汰（所有剩余像素也恢复为背景）。
5. 淘汰完成后，删除所有全为背景色的行，将剩余行向网格底部靠拢（保持行之间的相对顺序），顶部用背景行填充至原始网格高度。

**关键洞察**：平移方向由排名奇偶决定，但裁切效果取决于对象是否靠近被推向的那一侧边界。一个靠近左边界的奇数排名对象会被左移推出边界而丢失像素；如果同一对象排名是偶数则右移远离左边界，像素完好。因此，对象的存活不仅取决于自身大小，还取决于排名奇偶与位置的组合。面积阈值（4）和奇偶方向分配需对比多个示例归纳。

## 新题 4：指示像素定向平铺后象限折叠与动态分层

**组合逻辑**：[指示像素/指示决定方向色](已有) → [平铺](已有，创新：平铺范围限制在象限内而非整个网格) → [计数](创新：统计平铺副本数作为排序依据) → [透明叠加/层叠顺序](创新：层序由平铺副本数动态决定，而非固定象限位置)

**来源原语**：指示像素(indicator_pixel)、指示决定方向色(indicator_dir_color)、平铺(tiling)来自 e8dc4411；透明叠加(transparent_overlay)、层叠顺序(layer_stack)、四象限折叠同画布(quadrants_fold_one)来自 75b8110e；计数(counting)来自 2c0b0aff

**依赖链**：指示像素决定平铺方向 → 方向与象限几何共同决定能放多少副本 → 副本数决定折叠时的层序 → 层序决定重叠区域保留谁的颜色。指示方向的几何后果（副本数量）成为分层规则的输入——这是一条"几何→数量→优先级"链，源题中不存在。

在四象限各含一个模板和一个指示像素的网格上，按指示方向在象限内平铺模板，然后将四个象限折叠到同一画布上，平铺副本最多的象限位于最顶层。

**输入结构**：约 16x16 网格，灰(5)背景。网格被概念性地等分为四个象限（无可见分隔线——以第 8 行第 8 列为中心划分 TL/TR/BL/BR）。每个象限内有一个黑(0)的小模板对象（3~5 像素，不规则 4-连通形状）和恰好一个单像素指示像素与该模板 4-邻接。四个指示像素颜色互不相同，取自红(2)、蓝(1)、绿(3)、黄(4)。模板和指示像素均不跨越象限边界。模板在象限内的位置各异（有的靠近象限中心，有的靠近象限边角），使得不同方向的平铺能产生不同数量的副本。生成约束：四个象限的平铺副本数互不相同。

**规则**：
1. 对每个象限，识别黑色模板及其邻接的指示像素。平铺方向 = 从模板质心指向指示像素的方向（8 方向之一：上、下、左、右、四个对角）。
2. 将模板重涂为指示像素的颜色，然后沿平铺方向在象限范围内反复放置模板的平移副本（每次平移量 = 模板在该方向上的包围框尺寸），直到下一个副本会超出象限边界为止。统计每个象限的副本总数（含原始模板本身）。
3. 将四个象限折叠到一个象限大小的画布上（所有象限坐标映射到 TL 象限的坐标系）。折叠时 TR 象限左右翻转、BL 象限上下翻转、BR 象限双向翻转。
4. 层叠顺序由副本数决定：副本数最少的象限为最底层，最多的为最顶层。层叠时上层像素覆盖下层像素（仅覆盖非灰像素，灰(5)视为透明）。若两个象限副本数相同（生成时已排除），按 TL < TR < BL < BR 排序。
5. 输出 = 该象限大小的画布。

**关键洞察**：指示像素的方向不仅决定平铺的视觉图案（与参考题相同），更通过与模板在象限中的位置交互，决定了能放多少副本——而副本数又控制了折叠时的视觉优先级。指向象限远端的模板比指向近端的模板产生更多副本、获得更高层级。这条"方向→数量→优先级"链在任何单一参考题中均不存在。

## 新题 5：对角连线与十字轴反射标记的交汇染色

**组合逻辑**：[连线/对角对齐](已有) + [对称补全/双轴对称](已有) → [逐像素比较/差异标记](创新：比较对象不是两幅面板，而是两种独立构造在同一画布上的重叠位置)

**来源原语**：连线(connect)、对角对齐(diagonal_alignment)来自 db695cfb；对称补全(symmetry_complete)、十字轴线(cross_axis)、双轴对称(biaxial_symmetry)来自 60d73be6；差异标记(mark_differences)来自 34b99a2b

**依赖链**：对角连线在网格上建立第一套结构（线段）→ 十字轴反射在网格上建立第二套结构（对称标记）→ 两套结构在同一像素重叠时产生交汇标记（第三种颜色）。两套构造独立进行，但输出取决于它们的空间交集。这是"双源汇聚"结构，非流水线。

在同一网格上，先画对角线连接同色像素对，再将稀疏标记沿十字轴反射到全部象限；对角线与反射标记重叠处标为特殊颜色。

**输入结构**：约 14x14 网格，黑(0)背景。绿(3)十字轴线：一整行和一整列全为绿(3)。2~3 对蓝(1)像素，每对内两个像素位于同一条对角线上（即行号之差等于列号之差的绝对值）。蓝色像素不位于十字轴线上。另有 2~4 个红(2)标记像素，全部位于十字轴线定义的某一个象限内（如左上象限），不位于轴线上，不与蓝色像素重合。生成约束：至少一个反射后的红色标记（或其原始位置）会落在某条蓝色对角线上。

**规则**：
1. 连线：对每对蓝色像素，沿共享对角线方向填充二者之间所有像素为蓝(1)（含端点）。
2. 反射：对每个红(2)标记像素，计算其关于十字轴行的反射位置、关于十字轴列的反射位置、关于两轴同时反射的位置。在这三个反射位置放置红(2)像素（原始位置也保留）。反射位置超出网格边界的部分丢弃。
3. 交汇着色：在最终网格上，逐像素检查——
   - 若某像素同时属于蓝色对角线和红色标记（原始或反射），该像素变为黄(4)。
   - 若红色标记落在绿色十字轴线上，该像素变为红(2)（红色覆盖绿色）。
   - 若红色标记落在黑色背景上，该像素变为红(2)。
   - 其余像素（纯蓝线、纯绿轴、纯黑背景）保持不变。
4. 绘制顺序等价说明：先画蓝色对角线和绿色十字轴线，再放置红色标记；红色与蓝色重叠处变黄(4)，红色与绿色重叠处红色胜出，红色与黑色重叠处放置红色。

**关键洞察**：黄(4)像素是两种独立几何构造（对角连线和轴对称反射）的交汇信号——它们既不属于连线逻辑也不属于反射逻辑，只在二者空间重叠时才涌现。求解者必须同时理解连线规则和反射规则，才能预测黄色像素的位置。交汇颜色为黄(4)（而非蓝或红）需要对比多个示例才能确定。

## 新题 6：角落对象顺时针复制后标记计数驱动重涂

**组合逻辑**：[复制/顺时针到下一角](已有) → [连通检测/计数](创新：计数对象包含复制带来的新增标记，使计数结果依赖于复制步骤) → [重涂色](创新：重涂颜色由计数结果查表决定，映射关系需从示例推断)

**来源原语**：复制(copy)、顺时针到下一角(clockwise_next)、忽略干扰项(ignore_distractors)来自 bc93ec48；连通检测(connected_component_detection)、计数(counting)来自 2c0b0aff；重涂色(recolor)来自 e8dc4411/e9ac8c9e

**依赖链**：顺时针复制将角落对象（含标记像素）搬运到新角落 → 目标角落现在同时拥有原有对象和复制来的对象 → 标记计数在复制后进行，计数结果因复制而改变 → 计数值查表映射为颜色 → 以该颜色重涂该角落的所有非标记前景像素。三步操作中，每一步的输出都是下一步的必要输入。

将角落对象顺时针复制到下一角，然后统计每个角落区域内的绿色标记连通体数量，依据数量将该角落的蓝色像素重涂为对应颜色。

**输入结构**：约 14x14 网格，橙(7)背景。四个角落各有一个前景对象——以蓝(1)像素为主体（5~10 像素，不规则 4-连通形状），其中嵌有 1~3 个绿(3)单像素标记（绿色像素与蓝色像素 4-邻接或被蓝色包围，但绿色像素之间不互相 4-邻接，即每个绿色像素是一个独立的 1 像素连通体）。每个角落对象的包围框触碰两条相邻网格边界（即对象锚定于角落）。网格中央区域有 1~2 个红(2)干扰对象（不触碰任何角落边界），它们不参与任何操作。生成约束：顺时针复制后，四个角落的绿色标记连通体数量互不相同（通过各角落原有标记数和复制来源标记数的组合保证）。

**规则**：
1. 忽略所有非角落对象（红色干扰物不移动、不修改）。
2. 对每个角落对象，将其像素集合（蓝色 + 绿色）整体复制到顺时针方向的下一个角落：TL→TR、TR→BR、BR→BL、BL→TL。复制时保持对象形状不变，将包围框对齐到目标角落。复制像素覆盖目标位置的已有像素。原始角落的对象保留不变。
3. 复制完成后，对每个角落区域（以网格中心为界划分的四个象限），统计该区域内绿(3)像素的 4-连通独立连通体数量。
4. 根据绿色连通体数量，将该区域内所有蓝(1)像素重涂为指定颜色。映射关系固定但须从示例推断，例如：数量 2 → 黄(4)、数量 3 → 灰(5)、数量 4 → 红(2)、数量 5 → 品红(6)。
5. 绿色标记像素、橙色背景、红色干扰物保持不变。

**关键洞察**：复制步骤不仅改变了角落的视觉内容，更引入了新的绿色标记，使目标角落的标记计数不同于复制前。如果不执行复制就计数，得到的数量（和重涂颜色）会是错误的。计数-颜色映射表是隐蔽规则，需对比多个示例的角落标记数与输出颜色来推断。

## 新题 7：弹性拉伸对齐后逐像素差异提取

**组合逻辑**：[弹性拉伸/内部行程/按目标尺寸调整](已有) + [逐像素比较/异或差异判定](已有) → [差异标记](创新：比较对象不是两幅同尺寸面板，而是一幅拉伸后的模板与一幅原始面板——拉伸是比较的前提条件)

**来源原语**：弹性拉伸(elastic_stretching)、多色范例矩形(multicolor_exemplar_rect)、内部行程(interior_run)、按目标尺寸调整(resize_to_target)来自 40f6cd08；逐像素比较(cell_by_cell_comparison)、异或差异判定(xor_difference)、面板对齐(panel_alignment)、分隔列(separator_column)来自 34b99a2b

**依赖链**：分隔列划分两个面板 → 弹性拉伸将小面板的范例矩形调整为大面板矩形的尺寸 → 拉伸结果与大面板逐像素比较 → 差异位置标记为特殊颜色。如果不做拉伸，两个面板尺寸不同，无法逐像素比较。如果不做比较，拉伸结果本身不是最终答案。

将分隔面板中较小的范例矩形弹性拉伸至较大矩形的尺寸，然后逐像素对比两者，输出差异位置标记图。

**输入结构**：约 12x22 网格（宽大于高），黑(0)背景。一条竖直灰(5)分隔列将网格分为左右两个面板。左面板包含一个较小的多色范例矩形（约 4x5），其四条边框为同一颜色（如蓝(1)），内部包含 2~3 种其他颜色形成条带图案。右面板包含一个较大的矩形（约 4x8 或 6x5），与范例矩形具有相同的边框颜色，内部也包含类似但不完全相同的条带图案（相当于"弹性拉伸范例矩形后再修改了若干像素"的结果）。两个矩形的行数相同但列数不同（或列数相同但行数不同），且恰好一个维度的边框行/列数相同，差异仅在内部行程的长度上。生成约束：右面板矩形可被视为范例矩形的弹性拉伸版本加上 2~5 个像素的修改（改变了某些像素的颜色）。

**规则**：
1. 识别灰(5)分隔列。提取左面板的范例矩形和右面板的目标矩形。
2. 对范例矩形进行弹性拉伸以匹配目标矩形的尺寸。拉伸算法：对行和列分别进行行程编码，保持所有边框行程（首行程和末行程）的长度不变，仅拉伸唯一的内部行程（在行/列两个方向上，选择包含最多不同颜色的行程为内部行程；若颜色数相同则选择原始长度较短的行程）使总长度匹配目标。
3. 将拉伸后的范例矩形与目标矩形逐像素比较。
4. 输出 = 一个与目标矩形等大的网格。两者颜色相同的像素输出为黑(0)；颜色不同的像素输出为该位置在目标矩形中的颜色。
5. 分隔列和其他区域全部丢弃。

**关键洞察**：弹性拉伸不是最终变换（如参考题 40f6cd08 那样用拉伸结果替换实心矩形），而是一个中间步骤——它将两个不同尺寸的对象变为可比较的同尺寸对象。逐像素比较也不是在两个天然等大的面板上进行（如参考题 34b99a2b），而是在人工对齐后的对象上进行。拉伸算法本身（哪个行程是内部行程）需要对比多个示例来确认。

## 新题 8：模板匹配激活指示像素定向射线

**组合逻辑**：[形状匹配/归一化形状比对/匹配模板则重涂](已有) → [指示像素/邻接触碰](创新：指示像素的激活与否取决于其邻接对象是否通过了形状匹配测试) → [射线延伸](已有，创新：射线仅从被激活的指示像素发出)

**来源原语**：形状匹配(shape_match)、归一化形状比对(normalized_shape_matching)、匹配模板则重涂(recolor_on_match)来自 4ff4c9da；指示像素(indicator_pixel)、邻接触碰(adjacency_touch)来自 e8dc4411；射线延伸(ray_extend)来自 db695cfb/aba27056

**依赖链**：模板匹配筛选出哪些对象是"匹配对象" → 匹配对象被重涂为模板色 → 匹配对象旁的指示像素被"激活"，开始发射射线 → 非匹配对象旁的指示像素保持惰性（被清除）。匹配结果控制了哪些指示像素有效，进而控制了射线图案。如果不做匹配，所有指示像素看起来一样，无法区分激活与惰性。如果不做射线，匹配结果只是重涂（与参考题 4ff4c9da 相同，无创新）。

在含有模板对象和多个候选对象的网格上，匹配模板形状的对象被重涂并激活其邻接指示像素发射射线；不匹配的对象旁的指示像素被清除。

**输入结构**：约 15x15 网格，黑(0)背景。包含 5~7 个单色 4-连通前景对象，分布在网格各处。其中一个为青(8)对象（3~6 像素），作为形状模板。其余对象颜色为蓝(1)或红(2)（两种颜色的对象各至少 2 个）。仅有一种颜色（如蓝(1)）的对象中，部分对象的平移归一化形状与青(8)模板相同，其余形状不同。另一种颜色（如红(2)）的对象形状均不与模板匹配。每个非模板对象恰好有一个品红(6)单像素指示像素与其 4-邻接（指示像素不与其他任何对象邻接）。青(8)模板对象也有一个品红(6)指示像素与其邻接。生成约束：各对象互不接触（除了各自与其指示像素的邻接）；射线路径上无歧义（每条射线在碰到其他对象或网格边界前为直线路径）。

**规则**：
1. 以青(8)对象为模板，提取其平移归一化的像素掩码（4-连通）。
2. 对每个非黑、非青、非品红的对象，将其像素掩码平移归一化后与模板比较。归一化使用 4-连通。
3. 找到唯一的"匹配源色"——即存在与模板形状匹配的对象的那种颜色。将所有该源色中形状匹配的对象重涂为青(8)。
4. 对每个青(8)对象（含原始模板和新重涂的对象），其邻接的品红(6)指示像素被"激活"：从该指示像素出发，沿从对象质心（取所有像素坐标均值并四舍五入到最近整数）指向指示像素的方向（8 方向之一），发射一条青(8)射线，直到碰到网格边界或任何非黑像素为止（不包含终止位置的像素）。
5. 对每个不匹配的对象（无论哪种颜色），其邻接的品红(6)指示像素被"清除"：将该品红像素恢复为黑(0)背景。不匹配的对象本身保持其原有颜色不变。
6. 射线覆盖的黑色像素变为青(8)。射线碰到已有非黑像素则停止。多条射线的绘制顺序按射线起点的行号升序、行号相同则列号升序处理。先绘制的射线像素成为后续射线的障碍。

**关键洞察**：指示像素在视觉上对所有对象看起来完全相同（都是品红单像素），但其功能由邻接对象是否通过形状匹配测试来决定——匹配者的指示像素激活为射线发射器，不匹配者的指示像素被清除。这种"条件激活"是模板匹配和指示像素两个原语之间的新结构关系：匹配结果不仅改变对象颜色（如参考题 4ff4c9da），更控制了指示像素的行为模式（如参考题 e8dc4411 中指示像素总是激活的，而此题中激活是有条件的）。
