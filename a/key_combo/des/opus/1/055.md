## 新题 1：按嵌套深度排序并反转层色的矩形拼列

**组合逻辑**：[层序反转/layer_order_reversal](已有) + [计数/counting](已有，创新为计数嵌套深度而非标记像素) + [排序/sorting](已有，创新为按深度排序整个对象) + [拼接/concatenate](已有，创新为按排序结果水平拼列)

**来源原语**：层序反转(8dae5dfc)、嵌套层次(8dae5dfc)、排序(85b81ff1/beb8660c)、拼接(412b6263)、计数(8efcae92)、实心矩形(8efcae92)

**依赖链**：嵌套深度分析同时提供两项信息——层反转所需的层序列和排序所需的深度值；层反转改变每个矩形的视觉内容，排序改变矩形之间的空间排列；拼接消费排序结果和反转结果，缺任何一项都无法生成输出。

将多个独立的嵌套矩形按各自的嵌套层数从少到多排成一行，每个矩形内部的颜色层序同时被反转。

**输入结构**：黑(0)背景，约 12x18 的网格。散布 3-4 个互不重叠的实心矩形对象，每个矩形由同心嵌套的矩形颜色层组成（类似洋葱剖面：最外层一种颜色，内缩一圈换色，再内缩再换色……），不同矩形的尺寸、层数（2-4 层）和用色各不相同。每层厚度至少 1 像素，层厚可不均匀。所有矩形使用的颜色从红(2)、蓝(1)、绿(3)、黄(4)、灰(5)、品红(6)中选取，每个矩形内各层颜色互不相同。生成约束：各矩形的嵌套层数互不相等，保证排序无歧义。

**规则**：
1. 对每个矩形对象，从最外层向内逐层剥离，识别所有嵌套层及其颜色序列 [C_1, C_2, ..., C_k]（C_1 为最外层），其中 k 为该矩形的嵌套深度。
2. 在每个矩形内部，将第 i 层的颜色替换为第 (k+1-i) 层的颜色，即最外层和最内层互换、次外层和次内层互换，以此类推。各层的几何形状（厚度和范围）保持不变，仅颜色改变。
3. 按嵌套深度从小到大对所有矩形排序。
4. 将排序后的矩形（已完成层色反转）从左到右水平排列，相邻矩形之间隔 1 列黑(0)。所有矩形底部对齐。输出高度等于最高矩形的高度，较矮的矩形上方以黑(0)填充。

**关键洞察**：嵌套深度既是层反转操作的结构参数（决定哪些层互换），又是排序的依据——同一次结构分析同时驱动两种不同变换，删除深度分析则反转和排序都无法进行。

## 新题 2：边缘拉伸加对称补全修复缺损角

**组合逻辑**：[拉伸/extrude](已有) + [对称补全/symmetry_completion](已有，创新为在拉伸后的扩大网格上执行补全，修复原始缺损和拉伸产生的新缺损)

**来源原语**：拉伸/extrude(49d1d64f)、边缘行列(49d1d64f)、边缘延伸角落留黑(49d1d64f)、对称补全(981571dc)、双轴对称图案(981571dc)、推断对称轴(981571dc)、缺失像素(981571dc)

**依赖链**：拉伸操作复制边缘像素到新边框，但边缘上的缺损（黑像素）也被一并复制，在扩大网格中制造了更多空缺；对称补全在扩大网格上推断双轴对称并填充所有空缺；拉伸的结果直接决定了对称补全需要修复的像素集合和可用的参照点。

将一个边缘有像素缺损的双轴对称图案向外拉伸一圈，再利用对称性同时填补原始缺损和拉伸产生的新空缺。

**输入结构**：约 8x8 的网格，使用 2-3 种非黑颜色（如红(2)、蓝(1)、绿(3)）组成一个双轴对称图案（关于水平中轴和垂直中轴均对称），但边缘行或边缘列上有若干像素被擦除为黑(0)，破坏了局部对称。被擦除的像素数量不超过总边缘像素的 1/3，且分布使得从剩余非黑像素仍能唯一推断出两条对称轴。生成约束：每个被擦除的像素在至少一条对称轴的另一侧有对应的非黑像素存活。

**规则**：
1. 将输入网格向外扩展一圈（高度 +2，宽度 +2）：将原网格放置在输出的中央，四条边的每个像素向外复制一格到新边框位置。四个新角落单元格初始设为黑(0)。
2. 在扩展后的网格上，从所有非黑像素推断水平和垂直对称轴（轴位于扩展后网格的中心行和中心列）。
3. 对扩展后网格中每个黑(0)像素（包括：原始输入中被擦除的像素、从被擦除像素复制产生的新边框黑像素、四个角落的黑像素），通过对称轴映射找到对应位置。若对应位置为非黑色，则将该黑像素恢复为对应颜色。若通过两条轴分别映射得到不同非黑颜色，使用垂直轴映射的结果。
4. 输出完整的、无缺损的扩展对称图案。

**关键洞察**：拉伸操作不仅扩大了画布，还将边缘缺损"传播"到了新边框——一个缺损的边缘像素会在拉伸后产生两个黑像素（原位和新边框位），而对称补全必须在拉伸后的更大画布上工作才能同时修复所有空缺，包括角落。

## 新题 3：受损图块定位象限并标记修复

**组合逻辑**：[修复异常/repair](已有，创新为每个象限独立执行多数投票) + [裁剪/crop](已有，创新为由受损检测结果决定裁剪哪个象限) + [重涂色/recolor](已有，创新为将修复像素标记为特殊颜色)

**来源原语**：修复异常/repair(e84fef15)、多数投票共识(e84fef15)、受损副本被标记(e84fef15)、裁剪/crop(88a62173)、象限(88a62173)、分隔十字(88a62173)、异常值选择(88a62173)、重涂色(5a5a2103)

**依赖链**：多数投票在每个象限内部独立执行以识别受损图块 → 受损图块的存在标记出唯一的"异常象限" → 裁剪操作提取该象限 → 修复与标记操作在裁剪结果上完成最终输出；投票结果同时驱动了"选哪个象限"和"修什么像素"两个决策。

在四个象限中找出包含受损图块的那个象限，将其裁剪出来，修复受损图块并用蓝色标记被修复的位置。

**输入结构**：约 21x21 的网格。灰(5)的十字分隔线（中间行和中间列）将网格分成 4 个等大的矩形象限。每个象限内部用橙(7)的细分隔条进一步划分为 2x2 排列的 4 个小图块单元。四个象限各有不同的基础图案（图案使用红(2)、绿(3)、黄(4)、品红(6)中的一种颜色绘制在黑(0)背景上，每个图案为 4-连通的不规则形状，3-8 像素）。在三个象限中，4 个图块完全一致。在恰好一个象限中，某一个图块有 1-3 个像素被擦除为黑(0)。蓝(1)在输入中不出现。生成约束：受损象限中未受损的三个图块足以通过多数投票恢复出完整图案。

**规则**：
1. 对四个象限分别执行：在该象限的 4 个图块之间逐像素多数投票，得到该象限的共识图案。
2. 在每个象限中检查是否存在与共识图案不一致的图块。恰好一个象限包含不一致的图块，称该象限为"受损象限"。
3. 裁剪出受损象限（不含灰色十字分隔线，但保留象限内部的橙色细分隔条）。
4. 将受损图块中与共识不一致的像素位置恢复为共识颜色，并将这些位置改涂为蓝(1)作为标记。其余所有像素保持不变。
5. 输出裁剪后的受损象限（含标记）。

**关键洞察**：多数投票的结果承担双重角色——它既是"哪个象限异常"的检测器（宏观选择），又是"哪些像素需修复"的定位器（微观操作），两个尺度的判断由同一次投票同时得出。

## 新题 4：周期续延后按指示像素方向镜像并重涂

**组合逻辑**：[平铺/tiling](已有，创新为先在带状区域内续延截断的周期图案) + [镜像/reflect](已有，创新为对续延后的完整带状图案执行镜像，而非单个精灵体) + [重涂色/recolor](已有，创新为镜像副本的颜色由指示像素颜色决定)

**来源原语**：平铺/tiling(963e52fc)、周期(963e52fc)、周期图案(963e52fc)、宽度加倍延续周期(963e52fc)、镜像/reflect(b775ac94)、指示像素(b775ac94)、指示定镜像与色(b775ac94)、邻接(b775ac94)、重涂色(b775ac94)

**依赖链**：周期检测→续延产生完整的水平带→指示像素的位置决定镜像轴方向→镜像操作复制续延后的完整带（而非截断版本）→指示像素的颜色决定副本的重涂色；如果跳过续延，镜像副本的内容会缺失右侧部分而出错。

检测水平带的周期并续延至全宽，然后根据贴附的指示像素在上方或下方生成镜像副本，副本重涂为指示像素的颜色。

**输入结构**：约 10x15 的网格，黑(0)背景。网格中部有一条水平带（高 2-3 行），使用红(2)和黄(4)两种颜色形成截断的水平周期图案（周期长度 3-5 像素，带的右侧被画布边界截断，仅显示部分周期）。1-3 个单像素指示点分别贴附在水平带的上方或下方边缘，每个指示像素与带的某个像素正交相邻。指示像素使用互不相同的颜色，从蓝(1)、绿(3)、灰(5)、品红(6)中选取。生成约束：各指示像素在水平方向上彼此间隔足够远，使得镜像副本之间不会重叠；每个镜像副本完全在网格范围内。

**规则**：
1. 识别水平带中最短的水平重复周期，将截断的周期图案续延至与网格同宽（右侧填充周期的后续列）。
2. 对每个指示像素：
   - 若指示像素在水平带上方：以水平带的上边缘为轴，将续延后的完整带向上做垂直镜像，得到一个翻转的带状副本，放置在指示像素上方紧邻位置开始的若干行。
   - 若指示像素在水平带下方：以水平带的下边缘为轴，将续延后的完整带向下做垂直镜像，放置在指示像素下方紧邻位置开始的若干行。
3. 每个镜像副本整体重涂为对应指示像素的颜色（副本中原本为黑(0)的像素保持黑色，仅非黑像素被替换）。
4. 原始水平带（已续延）保持其原始颜色不变。

**关键洞察**：镜像副本使用的是续延后的完整带图案，而非输入中可见的截断版本——如果不先完成周期续延就直接镜像，副本右侧会出现不该有的空缺，只有对比多个示例中不同截断位置的输入才能确认这一点。

## 新题 5：按长度排序堆叠线段后用楔形填充间隙

**组合逻辑**：[排序/sorting](已有) + [滑动/sliding](已有，创新为按排序结果重新放置线段) + [填充/fill](已有，创新为在相邻线段间按长度差递变生成楔形) + [距离递变/distance_gradient](已有，创新为递变宽度由两线段的长度差决定)

**来源原语**：排序/sort(beb8660c)、按长度递增堆叠(beb8660c)、线段/segment(beb8660c/a65b410d)、条带/stripe(beb8660c)、对齐/alignment(beb8660c)、填充/fill(a65b410d)、三角楔形(a65b410d)、距离递变(a65b410d)、逐行宽度递变成楔(a65b410d)

**依赖链**：排序确定线段的上下邻接关系 → 邻接关系决定哪两条线段之间需要楔形填充 → 楔形的形状由相邻线段的长度差决定 → 楔形的颜色由下方（较长）线段的颜色决定；排序结果同时驱动了空间布局和楔形参数。

将散布的水平线段按长度排序堆叠到底部条带上方，再用三角楔形填补相邻线段之间的长度差。

**输入结构**：约 12x12 的网格，黑(0)背景。底部一整行为灰(5)条带。在条带上方散布 3-5 条水平线段，每条线段高 1 像素、长度各不相同（2-8 像素），颜色互不相同，从红(2)、蓝(1)、绿(3)、黄(4)、品红(6)、橙(7)中选取。线段在输入中的位置随意（不需要右对齐，不需要按长度排列）。生成约束：所有线段长度互不相同，保证排序无歧义。

**规则**：
1. 将所有线段按长度从短到长排序。
2. 清除线段原始位置的像素。将排序后的线段从底部条带正上方开始逐行向上放置（最长线段紧邻条带，最短线段在最上方），每条线段右对齐至网格右边缘。
3. 对每对上下相邻的线段（上方较短、下方较长），计算长度差 D = L_lower - L_upper。从上方线段所在行开始，向下逐行扩展楔形：第 1 行（上方线段行）的楔形宽度为 0（无额外像素），第 2 行宽度为 1，第 3 行宽度为 2，……直到抵达下方线段所在行。楔形像素从上方线段的左端点起向左延伸。楔形颜色使用下方（较长）线段的颜色。若楔形像素会超出网格左边界，则截断。
4. 线段自身像素和底部灰色条带保持不变，楔形像素不覆盖已有的线段像素。

**关键洞察**：楔形的颜色来自下方较长的线段而非上方较短的线段——这一规则并不显然，需要对比多个示例中不同颜色组合才能确认；同时楔形的存在本身依赖排序结果（排序改变了谁与谁相邻），删除排序步骤则楔形无法定义。

## 新题 6：框架嵌套层反转生成色表映射放大图案

**组合逻辑**：[像素放大/pixel_upscale](已有) + [层序反转/layer_order_reversal](已有，创新为从框架的层序提取颜色映射表而非在原地反转) + [重涂色/recolor](已有，创新为用反转映射表对放大后的图案重涂)

**来源原语**：像素放大(6b9890af)、包含于框架内(6b9890af)、框内尺寸决定缩放(6b9890af)、空心矩形/frame(6b9890af)、图案/pattern(6b9890af)、层序反转(8dae5dfc)、嵌套矩形层(8dae5dfc)、嵌套层次(8dae5dfc)、颜色序列逆转(8dae5dfc)、重涂色(5a5a2103)

**依赖链**：框架的嵌套层结构提供两项独立信息：(a)内部尺寸决定放大倍率，(b)层色序列反转生成颜色映射表；放大操作使用 (a)，重涂操作使用 (b)，二者从同一结构的不同属性分叉获取参数，最终在框架内部汇合；删除层分析则映射未知，删除框架则倍率未知。

从嵌套多层的矩形框架读取颜色层序并反转为映射表，同时用框架内部尺寸放大小图案，再按映射表重涂放大后的图案并填入框架内部。

**输入结构**：约 15x15 的网格，黑(0)背景。网格中有一个由嵌套矩形层构成的框架结构：从外到内依次为 3-4 种不同颜色的矩形环（如从外到内：红(2)、蓝(1)、绿(3)），最内层是一个空心区域（全黑），其尺寸为某个小整数 S 乘以小图案尺寸。在框架外的网格某处有一个小图案（如 3x3），使用与框架相同的那几种颜色的子集绘制在黑背景上。生成约束：框架内部尺寸恰好是小图案尺寸的整数倍（即 S 为正整数）；小图案使用的颜色是框架层颜色的子集。

**规则**：
1. 识别框架的嵌套层颜色序列，从最外层到最内层记为 [C_1, C_2, ..., C_k]。
2. 构建颜色映射表：C_i 映射到 C_{k+1-i}（即序列反转映射）。例如若层序为 [红, 蓝, 绿]，则映射为 红→绿, 蓝→蓝, 绿→红。
3. 计算放大倍率 S = 框架最内层空心区域的边长 / 小图案的对应边长。
4. 将小图案等比放大 S 倍（每个像素变为 SxS 的色块）。
5. 对放大后的图案应用步骤 2 的颜色映射表：将每个非黑像素的颜色替换为其映射颜色。黑(0)像素保持不变。
6. 将重涂后的放大图案放入框架内部空心区域。框架的嵌套层保持不变。

**关键洞察**：框架结构身兼二职——它的几何尺寸提供放大倍率，它的层色序列提供颜色映射规则；两项信息来自同一个对象的不同属性，在单个示例中可能误以为颜色映射是固定的，必须对比框架层序不同的多个示例才能归纳出反转规则。

## 新题 7：双面板叠加冲突由标记密度裁决

**组合逻辑**：[透明叠加/transparent_overlay](已有，创新为冲突像素的裁决不是取交集而是由标记密度决定) + [计数/counting](已有，创新为计数矩形内标记像素以裁决叠加冲突) + [裁剪/crop](隐含在面板提取中)

**来源原语**：透明叠加(0c9aba6e)、面板/panel(0c9aba6e)、分隔行(0c9aba6e)、位置对齐(0c9aba6e)、计数(8efcae92)、标记像素(8efcae92)、实心矩形(8efcae92)、包含(8efcae92)、标记最多者选取(8efcae92)

**依赖链**：面板分离和位置对齐是叠加的前提 → 叠加产生冲突位置 → 冲突裁决需要计数每个面板中封闭矩形区域内的标记像素 → 计数结果决定该位置由哪个面板的颜色胜出；叠加操作和计数操作互相依赖（需先知道哪里有冲突才知道要比较什么，需要比较结果才能完成叠加）。

将两个面板按位置叠加，在两者都有颜色的冲突位置，取包含更多标记像素的面板一方的颜色。

**输入结构**：约 15x8 的网格，黑(0)背景。一条灰(5)的水平分隔行将网格分为上下两个等大的面板（各约 6x15 或类似比例）。每个面板中有 2-3 个互不重叠的单色实心矩形（矩形使用红(2)、蓝(1)、绿(3)、黄(4)中的颜色，两面板可以使用不同颜色）。部分矩形内部散布着品红(6)的标记像素（替换了矩形原色的若干位置），不同矩形内标记数量不同（0-4 个）。两面板的矩形在位置上有部分重叠区域，也有只出现在一个面板的区域。生成约束：在每个冲突位置，上面板包含该位置的矩形和下面板包含该位置的矩形的标记数量不相等，保证裁决无歧义。

**规则**：
1. 移除灰色分隔行，将上面板和下面板按位置对齐。
2. 逐像素处理：
   - 若该位置两个面板都是黑(0)：输出黑(0)。
   - 若仅一个面板在该位置有非黑像素：输出该非黑颜色（包括品红标记像素原样输出）。
   - 若两个面板在该位置都有非黑像素（冲突）：找到上面板中包含该位置的矩形 R_top 和下面板中包含该位置的矩形 R_bot，分别计数 R_top 和 R_bot 内的品红(6)标记像素数量。标记数量更多的面板胜出，输出该面板在该位置的颜色。
3. 输出与单个面板同大的网格。

**关键洞察**：叠加的冲突裁决规则不是固定的"上优先"或"下优先"，而是由各矩形区域内的标记像素密度动态决定——同一个面板在不同冲突区域可能胜出也可能落败，取决于局部标记计数，这需要对比多个示例中标记分布不同的情况才能归纳。

## 新题 8：异常象限图案反向印章覆盖多数象限

**组合逻辑**：[相等比较/equality_comparison](已有) + [异常值选择/outlier_selection](已有，创新为异常者不是被输出而是被提取为模板) + [印章覆盖/stamp_overlay](已有，创新为将异常图案印入多数象限) + [重涂色/recolor](已有，创新为每个目标象限用自身原色重涂印章)

**来源原语**：相等比较(88a62173)、异常值选择(88a62173)、象限(88a62173)、分隔十字(88a62173)、印章覆盖(5a5a2103)、模板掩码(5a5a2103)、重涂色(5a5a2103/12997ef3)

**依赖链**：象限间的形状比较（忽略颜色）→ 找出唯一异常者 → 异常者的形状掩码成为印章模板 → 模板被印入另外三个象限 → 每个目标象限的原始颜色决定印章的重涂色；异常检测同时标记了模板来源和印章目标，二者缺一不可。

在四个象限中找出形状独特的异常者，用它的形状作为模板，印章覆盖到其余三个象限中，每个象限用自己原有的颜色重涂该印章。

**输入结构**：约 11x11 的网格。灰(5)的十字分隔线（中间行和中间列）将网格分为 4 个等大矩形象限。每个象限在黑(0)背景上有一个单色图形（4-连通、不规则、4-10 像素）。四个象限的图形各用不同颜色：红(2)、蓝(1)、绿(3)、黄(4)。其中三个象限的图形形状完全相同（仅颜色不同），第四个象限的图形形状不同。生成约束：每个象限的图形在其象限内的局部坐标位置相同（即图形相对于象限左上角的偏移一致），以便形状比较。

**规则**：
1. 将每个象限的图形提取为二值掩码（忽略颜色，只看形状），以象限左上角为局部原点。
2. 比较四个掩码：三个掩码相同，一个不同。不同的那个象限为"异常象限"。
3. 将异常象限的图形掩码作为印章模板。
4. 对三个非异常象限的每一个：清除其原有图形，将印章模板放置在相同的局部坐标位置，重涂为该象限原来的图形颜色。
5. 异常象限保持不变。灰色十字分隔线保持不变。
6. 输出完整网格。

**关键洞察**：异常象限的角色被反转——通常"异常者"是被选出或输出的对象，但这里异常者反而成为改造其他象限的工具（模板），而多数者被改造；识别异常只是中间步骤，真正的输出变换作用于多数者。

## 新题 9：对角扫描生成轨迹后裁剪含最多轨迹像素的矩形区域

**组合逻辑**：[滑动/slide](已有，创新为稀疏线的对角扫描覆盖全网格) + [计数/counting](已有，创新为计数落入各矩形内的扫描轨迹像素) + [裁剪/crop](已有，创新为按轨迹计数选取裁剪区域)

**依赖链**：对角扫描产生遍布网格的轨迹像素 → 每个矩形内的轨迹像素数取决于矩形位置与扫描方向的几何关系 → 计数结果选出裁剪目标 → 裁剪仅保留选中矩形内的轨迹片段；扫描结果决定了计数值，计数值决定了裁剪目标，三步形成不可跳越的依赖链。

**输入结构**：约 15x15 的网格，黑(0)背景。网格左列或底行有一条单像素宽的垂直或水平稀疏线段（长度等于网格一条边），线段中部分像素着色（使用红(2)和蓝(1)，其余为黑(0)）。网格中散布 3-4 个互不重叠的灰(5)空心矩形框（仅边框，内部为黑色），大小各不相同（内部面积从 3x3 到 6x6 不等），位于网格的不同位置。生成约束：对角扫描后各矩形框内的非黑轨迹像素数量互不相同，保证选取无歧义。稀疏线中非黑像素至少有 2 个。

2. 对每个灰色矩形框，计数其内部（不含边框）的非黑轨迹像素数量。
3. 选择轨迹像素数量最多的矩形框。
4. 裁剪输出该矩形框的内部区域（不含灰色边框），其中包含落在此区域内的扫描轨迹像素，其余位置为黑(0)。

**关键洞察**：矩形框的位置决定了它能"捕获"多少条对角扫描轨迹——靠近对角线方向的矩形框捕获更多轨迹，但具体数量还取决于稀疏线中非黑像素的分布，因此无法仅凭矩形框的面积或位置直接判断哪个框包含最多轨迹，必须实际执行扫描后计数。

## 新题 10：精灵体掩码并集关系决定腔室初始色并多数传播

**组合逻辑**：[像素并集/pixel_union](已有，创新为并集关系用于识别特殊腔室而非标记颜色) + [填充/fill](已有，创新为先由并集关系确定种子色再通过多数投票传播) + [邻接多数决/adjacent_majority_vote](已有，创新为种子来自并集分析而非输入中已有的标记)

**来源原语**：像素并集(fea12743)、双掩码并集等三(fea12743)、精灵体/sprite(fea12743/b775ac94)、填充/fill(7c8af763)、连通腔室(7c8af763)、分隔墙(7c8af763)、正交邻接(7c8af763)、邻接多数决(7c8af763)

**依赖链**：提取各腔室中精灵体的二值掩码 → 发现并集关系（A∪B=C）→ 操作数腔室和结果腔室分别获得不同的初始填充色 → 未参与并集关系的腔室通过邻接多数投票从已填充邻居获取颜色 → 最终所有腔室被填满；并集分析产生的"种子色"通过空间传播影响远处腔室的颜色，形成因果链。

在墙壁分隔的腔室中找到精灵体掩码满足并集关系的三个腔室，分别着色后，通过邻接多数投票将颜色传播到其余腔室。

**输入结构**：约 15x15 的网格。灰(5)的墙壁将网格分割为 6-8 个不规则形状的 4-连通腔室。部分腔室（至少 4 个）内含一个小型单色精灵体（红(2)、4-连通、3-7 像素的不规则形状），精灵体在腔室内的位置不固定。其余腔室为空（纯黑(0)背景）。在所有含精灵体的腔室中，恰好存在三个腔室 A、B、C，使得 A 的精灵体掩码与 B 的精灵体掩码的逐像素 OR（以各自腔室左上角为局部原点对齐）恰好等于 C 的精灵体掩码。其余含精灵体的腔室不参与任何并集关系。蓝(1)和绿(3)在输入中不出现。生成约束：满足并集关系的三元组唯一；A、B 各自至少贡献一个 C 中没有的反向独有像素（即 A 和 B 的掩码都不是 C 的子集的真子集以外的情况——A 和 B 各有至少一个像素是对方没有的）。

**规则**：
1. 提取每个含精灵体腔室的精灵体二值掩码（以腔室边界框左上角为原点）。
2. 在所有含精灵体的腔室对中搜索：找到唯一的三元组 (A, B, C)，使得 mask_A OR mask_B = mask_C，且 A、B 各自贡献了至少一个独有像素。
3. 将腔室 A 和 B 整体填充为绿(3)（精灵体像素也被覆盖），将腔室 C 整体填充为蓝(1)。
4. 对每个尚未填色的腔室（无论是否含精灵体），收集其所有通过墙壁正交相邻的已填色腔室的颜色。将该腔室填充为出现次数最多的邻居颜色。若存在平局，使用在网格中（按从上到下、从左到右扫描顺序）最先出现的邻居颜色。
5. 重复步骤 4 直到所有腔室都被填色。墙壁像素保持灰(5)不变。

**关键洞察**：并集关系检测产生的"种子着色"不仅标记了三个特殊腔室，还通过墙壁邻接的空间拓扑向远处传播——不同的腔室布局会导致相同的并集关系产生完全不同的全局填充结果，因此空间结构和逻辑关系深度耦合。
