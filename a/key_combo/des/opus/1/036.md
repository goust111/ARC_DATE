## 新题 1：蛇形路径折叠填充封闭孔洞

**组合逻辑**：[展直/遍历(创新：反向使用——将1D序列折叠回2D)] + [拼合填充(创新：填充内容由蛇形遍历色序决定，而非刚性形状拼合)] + [擦除]

**来源原语**：蛇形路径(snake_path)、端点(endpoint)、遍历顺序(traversal_order)、保留像素序(preserve_pixel_order) ← 参考题 7b5033c1；封闭孔洞(enclosed_hole)、大型单色对象(large_monochrome_object)、拼合填充(tiling_fill) ← 参考题 184a9768；标记噪声(marker_noise)、擦除(erase) ← 参考题 184a9768

**依赖链**：蛇形路径的遍历顺序决定颜色序列 → 颜色序列按行主序映射到孔洞的二维空间 → 像素数匹配决定蛇与孔洞的配对。三者缺一不可：不遍历蛇则无色序，不知孔洞形状则无法行主序填充，不匹配像素数则不知哪条蛇填哪个洞。

将多色蛇形路径按遍历顺序展开为一维色序，再按行主序折叠填入大型对象的封闭矩形孔洞，同时擦除原始蛇和灰色标记。

**输入结构**：黑(0)背景网格，约 18x18。网格中有 2-3 个蓝(1) 大型 4-连通单色对象（每个约 25-45 像素），每个对象内部包含一个由背景色(0)构成的封闭矩形孔洞（宽 2-4、高 2-5 像素，孔洞面积各不相同）。网格中另有 2-3 条多色蛇形路径：每条蛇是一条 4-连通链，恰好有 2 个端点（仅 1 个 4-连通邻居的链端像素），每个像素可为不同的非黑(0)非蓝(1)颜色（如红(2)、绿(3)、黄(4)、灰(5)、品红(6)、橙(7)等），每条蛇的像素数恰好等于某一个孔洞的面积。蛇形路径之间互不相邻，也不与大型对象相邻。网格中还散布着若干孤立的灰(5)标记噪声像素（与蛇和大型对象均不 4-连通）。生成约束：每个孔洞面积唯一，每条蛇的像素数唯一，蛇与孔洞之间存在唯一的像素数匹配。

**规则**：
1. 识别蓝(1)大型对象内部的所有封闭矩形背景孔洞，记录每个孔洞的宽 W 和高 H。
2. 识别所有蛇形路径（非黑非蓝的 4-连通链，恰有 2 个端点）。
3. 将每条蛇与像素数相等的孔洞配对（像素数 = W x H）。
4. 对每条蛇，找到其两个端点中行号更小的那个（行号相同则取列号更小的），作为起始端点。从起始端点沿唯一路径遍历至另一端点，依次记录每个像素的颜色，得到长度为 W x H 的色序列 S。
5. 将色序列 S 按行主序填入配对孔洞：S[0] 填入孔洞左上角，S[1] 填入孔洞左上角右邻...每行从左到右填满后换到下一行，直至 S[W x H - 1] 填入孔洞右下角。
6. 擦除所有蛇形路径像素（设为背景黑(0)）和所有灰(5)标记噪声像素（设为背景黑(0)）。大型蓝对象保持不变。

**关键洞察**：蛇形路径是一维编码的二维色彩图案——遍历方向（从"更靠左上"的端点出发）与孔洞的行主序共同构成一个唯一的一维到二维映射。仅看一个示例无法确定遍历起点的选择规则（两个端点都可能是起点），需对比多个示例才能归纳出"行号更小、行号相同取列号更小"的起点选择法则。

## 新题 2：遮挡层级决定线条膨胀厚度

**组合逻辑**：[层序推断] → [阶梯扩展(创新：膨胀厚度由推断出的层级序号参数化，而非固定周期)] + [排序(创新：排序结果不输出为列表，而是反馈为几何参数)]

**来源原语**：直线(straight_line)、交叉点(crossing_point)、遮挡层次(occlusion_order)、层序推断(layer_infer)、唯一序链(unique_chain)、排序(sort) ← 参考题 22425bda；阶梯扩展(stepped_expansion)、竖直条对(vertical_bar_pair)、周期性步长(periodic_step_length)、跨色重叠变色(cross_color_overlap_recolor) ← 参考题 58e15b12

**依赖链**：交叉点可见颜色 → 唯一层序推断 → 层级序号决定膨胀厚度 → 膨胀区域按层序绘制（底层先画、顶层后画覆盖）。删掉层序推断则无法确定各线厚度；删掉膨胀则层序信息无处呈现；绘制顺序本身也依赖层序。

根据交叉遮挡推断直线的层级顺序，每条线按其层级序号膨胀为对应厚度的宽带，底层先绘、顶层后绘覆盖。

**输入结构**：黑(0)背景网格，约 15x18。网格中有 3-4 条全跨度直线（水平线占满整行或垂直线占满整列），每条线 1 像素宽，各自不同颜色（如红(2)、绿(3)、黄(4)、橙(7)）。线之间存在交叉：水平线与垂直线在交叉格处重叠，交叉格只显示一个颜色（即位于更高层的线的颜色）。每条线至少与另一条线交叉。所有线的交叉可见颜色恰好确定一个唯一的从底到顶的全序（即交叉图上存在唯一的哈密顿链）。生成约束：线的数量为 3 或 4；交叉图连通且唯一序链存在。

**规则**：
1. 从可见的共线像素恢复每条完整直线（交叉处被遮挡的线段补全）。
2. 对每个交叉格，可见颜色的线在该交叉处位于所有其他穿过该格的线之上。收集所有这样的"A 在 B 之上"约束。
3. 找到满足所有约束的唯一全序，从底到顶编号为 1, 2, ..., N（底层 = 1）。
4. 每条线沿其垂直方向膨胀：层级编号为 K 的线，总厚度变为 2K-1 像素（即向两侧各扩展 K-1 像素）。水平线向上下膨胀，垂直线向左右膨胀。超出网格边界的部分丢弃。
5. 按层级从底到顶依次绘制膨胀后的线带：先绘制 K=1 的线（最薄，1 像素），再绘制 K=2（3 像素宽），以此类推。后绘制的颜色覆盖先绘制的颜色。
6. 背景色保持黑(0)不变（仅未被任何膨胀带覆盖的格子保持背景色）。

**关键洞察**：层级编号同时控制两件事——膨胀厚度和绘制优先级。顶层线最厚且最后绘制，视觉上占据最大面积；底层线最薄且最先绘制，几乎被完全覆盖。需对比多个示例才能发现厚度与层级的 2K-1 公式（而非简单的等宽膨胀或按交叉数决定厚度）。

## 新题 3：逐对象压缩后按压缩高度排序拼接

**组合逻辑**：[裁剪] + [压缩(创新：不是全局压缩整个网格，而是逐对象独立压缩)] → [排序(创新：排序键是压缩后高度，非原始高度或位置)] → [拼接]

**来源原语**：压缩(compression)、重复行(dup_row)、相邻相同(adjacent_identical)、相同行列合并(merge_identical) ← 参考题 ce8d95cc；连通精灵(connected_sprite)、裁剪(crop)、排序(sort)、拼接(concatenate)、按位置紧密排列(tight_packing_by_position)、布局轴方向(layout_axis_direction) ← 参考题 67636eac

**依赖链**：裁剪提取每个精灵 → 逐对象纵向压缩改变各精灵高度 → 压缩后高度作为排序键 → 拼接顺序由排序决定。删掉压缩步骤则排序键不存在（原始高度不能区分精灵）；删掉排序则拼接顺序不确定。

裁剪各精灵后逐个纵向压缩（合并相邻相同行），以压缩后高度升序排列后水平拼接。

**输入结构**：黑(0)背景网格，约 14x22。网格中有 4-5 个 8-连通单色精灵，每个精灵使用不同颜色（如红(2)、蓝(1)、绿(3)、黄(4)、橙(7)），沿水平方向分散排列（各精灵边界框互不重叠）。所有精灵的边界框宽度相同（均为 3-4 列），但高度不同（5-9 行）。关键特征：每个精灵内部存在若干连续相同行（即某些相邻行的像素图案完全一致），不同精灵的重复行模式不同。生成约束：所有精灵的原始边界框高度相同（如都是 8 行），但压缩后高度各不相同（3-6 行不等）；这迫使求解者必须压缩后才能区分排序键。

**规则**：
1. 识别所有 8-连通单色前景精灵，将每个精灵裁剪为其边界框。
2. 对每个裁剪结果，从上到下扫描行：将每组连续的完全相同行合并为一个代表行（保留该组中的第一行）。得到压缩后的精灵裁剪块。
3. 按压缩后高度升序排列所有精灵裁剪块。若两个精灵压缩后高度相同（生成时保证不会出现），以其原始边界框左上角列号小者在前。
4. 将排好序的压缩裁剪块从左到右水平拼接，底部对齐，相邻裁剪块之间无间隔。高度不足最大压缩高度的裁剪块上方填充背景黑(0)。

**关键洞察**：所有精灵原始高度相同，无法用原始尺寸排序——必须先执行逐对象压缩才能获得可区分的排序键。压缩结果取决于每个精灵内部的行重复模式，这是隐藏在"外观相似"精灵内部的结构差异。需对比多个示例才能发现排序键不是位置、不是颜色、不是原始高度，而是压缩后高度。

## 新题 4：双规则源色分流重涂与标记擦除

**组合逻辑**：[重涂色(行控制键)] + [重涂色(最近距离继承)](创新：两种重涂色规则并行作用于同一空间区域，由像素原始颜色决定适用哪条规则) + [擦除]

**来源原语**：占位像素(placeholder_pixel)、控制像素(control_pixel)、同行对应(same_row_mapping)、行首色决定填色(row_key_color)、重涂色(recolor) ← 参考题 c9f8e694；标记像素(marker_pixel)、边缘线(edge_line)、最近距离(nearest_distance)、标记继承最近源色(marker_inherits_nearest_color)、重涂色(recolor) ← 参考题 2204b7a8；擦除(erase) ← 参考题 184a9768

**依赖链**：灰(5)像素和绿(3)像素空间交织在同一区域内 → 像素原始颜色决定它适用行控制规则还是边缘距离规则 → 两条规则的输出在空间上交错形成最终图案。仅用一条规则会导致另一类像素颜色错误；规则选择依赖于对像素原始颜色的判断，而非其空间位置。

灰色占位像素按同行控制键重涂色，绿色标记像素按最近边缘线颜色重涂色，最后擦除控制键和边缘线。

**输入结构**：黑(0)背景网格，约 12x12。第 0 列包含若干控制像素（每行至多一个，颜色为红(2)、蓝(1)或黄(4)），仅在包含灰(5)或绿(3)像素的行出现。网格内部有灰(5)占位像素和绿(3)标记像素，两者混合排列——在同一个空间区域内，相邻的灰像素和绿像素形成复杂的交织图案（例如一个由灰和绿混合构成的连通斑块，其中部分像素是灰(5)、部分是绿(3)），灰和绿之间可以4-连通相邻。第 0 行（最上行）为整行橙(7)边缘线。最后一行为整行栗(9)边缘线。包含灰/绿像素的行都有对应的第0列控制像素。生成约束：绿像素数量约占灰+绿总像素的 30%-50%；每行最多一个控制像素颜色。

**规则**：
1. 对每个灰(5)像素：将其重涂为该行第 0 列控制像素的颜色。
2. 对每个绿(3)像素：计算该像素到最近的橙(7)边缘线像素的曼哈顿距离 D1，和到最近的栗(9)边缘线像素的曼哈顿距离 D2。若 D1 < D2，重涂为橙(7)；若 D2 < D1，重涂为栗(9)；若 D1 = D2，重涂为橙(7)（上边缘优先）。
3. 擦除第 0 列所有控制像素（设为黑(0)），擦除第 0 行橙色边缘线和最后一行栗色边缘线（设为黑(0)）。
4. 其他所有像素（背景黑(0)）保持不变。

**关键洞察**：灰像素和绿像素在空间上交织，视觉上像同一个对象的一部分，但适用完全不同的重涂色规则。需对比多个示例才能发现：决定重涂规则的不是像素的位置或所属连通区域，而是像素的原始颜色（灰 vs 绿）。这种"同一区域内两套规则并行"的模式在单个示例中容易被误解为单一复杂规则。

## 新题 5：逐象限奇偶滤选后四面板透明叠加

**组合逻辑**：[排序 + 奇偶交替选择(创新：在每个象限内独立执行，而非全局)] → [透明叠加 + 象限位决定层序](创新：叠加内容已被各象限独立滤选修改，叠加结果取决于滤选后的内容差异)

**来源原语**：面板(panel)、十字分隔线(cross_separator)、透明叠加(transparent_overlay)、图层优先级(layer_priority)、象限位决定层序(quadrant_layer_order) ← 参考题 e99362f0；小方块(small_square)、沿轴排列(axis_arrangement)、排序(sort)、奇偶交替选择(alternating_parity_selection)、忽略干扰项(ignore_distractors)、重涂色(recolor) ← 参考题 817e6c09

**依赖链**：每个象限内独立排序小方块 → 独立执行奇偶滤选重涂色 → 移除十字后四象限叠加。滤选改变了叠加输入——不同象限因方块数量和位置不同，滤选保留的方块不同，叠加冲突的解决方式也因此不同。删掉象限内滤选则叠加内容是原始方块（全红）；删掉叠加则四个象限无法合成。

在被十字分隔的四个面板中各自对红色小方块做奇偶交替重涂色，然后按象限层序叠加为一个面板。

**输入结构**：黑(0)背景网格，约 15x15（奇数边长）。一条灰(5)全宽水平线和一条灰(5)全高垂直线构成十字分隔线，将网格分为四个大小相等的矩形面板（每个面板约 7x7）。每个面板内包含 3-5 个互不相邻的 2x2 红(2)方块，分布在不同位置。部分面板中可能包含 1-2 个单像素品红(6)干扰点。生成约束：各面板内红方块数量可不同（3-5个）；所有红方块完全在面板内部，不接触十字线。

**规则**：
1. 在每个面板内部，忽略所有单像素干扰对象（品红(6)点，设为背景黑(0)）。
2. 在每个面板内部，按红(2)方块的边界框左上角列号从左到右排序（列号相同则行号小者在前）。
3. 在每个面板内部，从排序后最右边的方块开始，将排序名次 0, 2, 4, ...（即最右、右起第三、...）的方块重涂为青(8)，排序名次 1, 3, 5, ... 的方块保持红(2)。
4. 移除灰(5)十字分隔线。将四个面板按局部坐标对齐到同一画布。
5. 按以下层序从底到顶叠加：左下面板（最底层）→ 右上面板 → 左上面板 → 右下面板（最顶层）。非背景像素从高层覆盖低层。

**关键洞察**：奇偶滤选是逐象限独立进行的——同一全局列位置的方块在不同象限中可能被选为不同的奇偶名次（因为各象限的方块总数和排列不同），从而获得不同颜色。叠加后的冲突区域颜色取决于"哪个象限的方块恰好在该局部位置，且该象限层序更高"。需对比多个示例才能发现奇偶规则是逐象限独立执行的，而非全局统一。

## 新题 6：边缘距离排序后交替远近源重涂

**组合逻辑**：[排序(创新：排序键是对象到最近边缘线的距离)] + [重涂色 + 奇偶交替选择(创新：偶数名次继承最近边缘色，奇数名次继承最远边缘色——同一对象属性的两种对立解读交替使用)]

**来源原语**：边缘线(edge_line)、最近距离(nearest_distance)、标记继承最近源色(marker_inherits_nearest_color)、重涂色(recolor) ← 参考题 2204b7a8；连通精灵(connected_sprite) ← 参考题 67636eac；排序(sort)、奇偶交替选择(alternating_parity_selection) ← 参考题 817e6c09；忽略干扰项(ignore_distractors) ← 参考题 817e6c09

**依赖链**：计算每个精灵到两条边缘线的距离 → 按最近距离排序 → 奇偶名次决定使用最近色还是最远色 → 重涂。排序结果决定奇偶划分，而奇偶划分决定使用哪个距离源。删掉距离计算则无法排序也无法确定源色；删掉奇偶逻辑则无法区分两种重涂规则。

灰色精灵按到最近边缘线的距离排序，偶数名次继承最近边缘色，奇数名次继承最远边缘色。

**输入结构**：黑(0)背景网格，约 12x16。第 0 列为整列红(2)边缘线。最后一列为整列蓝(1)边缘线。网格内部（第1列到倒数第2列之间）散布 5-7 个互不相邻的灰(5) 4-连通小精灵（每个 3-6 像素，形状各异——非矩形、非正方形的不规则连通体）。可能存在 1-2 个单像素黄(4)干扰点（忽略）。生成约束：每个精灵的质心（所有像素行列坐标的算术平均）到最近边缘线的距离互不相同，以保证排序无歧义。

**规则**：
1. 忽略所有单像素黄(4)干扰对象。
2. 对每个灰(5)精灵，计算其质心到第 0 列红(2)边缘线的曼哈顿距离（质心列坐标即为到第 0 列的距离）和到最后一列蓝(1)边缘线的曼哈顿距离（网格宽度 - 1 - 质心列坐标）。取两者中较小值作为"最近边缘距离"。
3. 按最近边缘距离从小到大排序（距离最小 = 最靠近某条边缘 = 名次 0）。
4. 名次为偶数（0, 2, 4, ...）的精灵：重涂为其最近边缘线的颜色（距红更近则涂红(2)，距蓝更近则涂蓝(1)）。
5. 名次为奇数（1, 3, 5, ...）的精灵：重涂为其最远边缘线的颜色（距红更近则涂蓝(1)，距蓝更近则涂红(2)——即最近的反义）。
6. 红(2)和蓝(1)边缘线保持不变。背景不变。

**关键洞察**：奇数名次的精灵获得与其空间位置"直觉相反"的颜色——明明靠近红边缘却被涂蓝，反之亦然。仅看单个示例时，会以为所有精灵都按最近边缘着色（偶数名次恰好如此），需要多个示例中出现"反常着色"的精灵并发现其名次规律，才能归纳出交替规则。

## 新题 7：形状分组后组内奇偶交替重涂

**组合逻辑**：[平移归一化 + 形状相同(创新：形状分组不是为了统一着色，而是为了建立组内排序空间)] → [排序(组内按位置)] → [重涂色 + 奇偶交替选择(创新：在每个形状组内独立执行交替)]

**来源原语**：占位符对象(placeholder_obj)、形状相同(same_shape)、平移归一化(translate_normalize)、重涂色(recolor) ← 参考题 ad38a9d0；排序(sort)、奇偶交替选择(alternating_parity_selection)、沿轴排列(axis_arrangement) ← 参考题 817e6c09

**依赖链**：形状归一化 → 按归一化掩码分组 → 组内按位置排序 → 组内交替着色。形状分组决定了哪些对象共享一个排序空间，进而决定每个对象在组内的奇偶名次。删掉形状分组则所有对象混排，奇偶结果完全不同；删掉排序则组内无名次可言。

灰色对象按平移归一化形状分组，组内按水平位置排序后交替涂为两种颜色。

**输入结构**：黑(0)背景网格，约 15x15。网格中散布 8-12 个灰(5) 4-连通对象，每个对象 3-6 像素。这些对象的平移归一化掩码恰好属于 2-3 种不同形状，每种形状出现 3-5 次（在网格不同位置，朝向一致——无旋转/翻转，仅平移）。同一形状的不同实例之间不相邻。生成约束：同种形状的各实例边界框左上角列号互不相同（保证组内排序无歧义）；不同种形状的实例在空间上交错分布（不按形状聚类）。

**规则**：
1. 对每个灰(5) 4-连通对象，计算其平移归一化掩码（将边界框左上角平移到原点后的像素坐标集合）。
2. 按归一化掩码分组：掩码完全相同的对象归为一组。
3. 在每个组内，按对象边界框左上角的列号从左到右排序。
4. 在每个组内，从排序后最右边的对象开始，将名次 0, 2, 4, ...（右起第一、第三、...）的对象重涂为红(2)，名次 1, 3, 5, ...（右起第二、第四、...）的对象重涂为蓝(1)。
5. 背景保持不变。

**关键洞察**：不同形状的对象使用相同的交替规则但独立执行——同一种形状有 4 个实例时，交替结果为红蓝红蓝（从右到左）；有 3 个实例时，交替结果为红蓝红。形状分组是隐式的（对象全是灰色，外观上看不出分组），需要对比多个示例发现：只有形状相同的对象之间才参与交替，跨形状的对象互不影响。这与参考题 ad38a9d0（同形状同颜色）和参考题 817e6c09（全局交替）都不同。

## 新题 8：像素计数嵌套正方形与对角线轨迹

**组合逻辑**：[计数 + 像素数定边长(创新：不是水平排列，而是向心嵌套)] → [堆叠(创新：嵌套层方式堆叠，大在外小在内)] + [对角线轨迹绘制]

**来源原语**：色块(color_group)、正方形(square)、压缩重排(repack)、面积递增排列(area_ascending_order)、像素数定边长(pixel_count_determines_side) ← 参考题 8abad3cf；实心正方形(solid_square)、嵌套遮罩(nested_mask)、忽略非正方形(ignore_non_square)、堆叠(stack)、计数(counting) ← 参考题 b1986d4b；嵌套层(nested_layer)、对角线轨迹(diagonal_trail) ← 参考题 bd5af378

**依赖链**：各颜色的像素总数 → sqrt 得到边长 → 按边长从大到小嵌套为同心左上对齐正方形 → 最内层剩余矩形绘制对角线。像素计数决定边长（决定嵌套层厚度），嵌套顺序决定各颜色的可见区域形状（L形边框），对角线连接最外层与最内层的几何中心。

将每种非背景颜色的散落像素按总数还原为正方形，然后同心嵌套（最大在外、最小在内，左上对齐），最内层留白区域画最外层颜色的对角线。

**输入结构**：黑(0)背景网格，约 18x18。网格中有 3-4 种非背景非黑颜色（如红(2)、蓝(1)、绿(3)、黄(4)），每种颜色的像素散布在网格各处，形状任意（不一定是正方形），但每种颜色的像素总数是一个完全平方数（如 4、9、16、25）。各颜色的像素总数（即边长）互不相同。网格中可能有若干灰(5)噪声像素（与任何颜色的像素都不 4-连通，忽略）。生成约束：所有非噪声颜色的像素总数均为完全平方数；边长为 2-5；最大边长的颜色恰好 1 种。

**规则**：
1. 忽略所有灰(5)噪声像素。
2. 对每种非背景颜色，计算其像素总数 P，令边长 S = sqrt(P)。
3. 按边长从大到小排序颜色。设排序后颜色为 C1（最大，边长 S1）, C2, ..., Cn（最小，边长 Sn）。
4. 构建输出网格（大小 S1 x S1）：
   a. 填充整个 S1 x S1 网格为颜色 C1。
   b. 在左上角覆盖一个 S2 x S2 的颜色 C2 正方形。
   c. 在左上角覆盖一个 S3 x S3 的颜色 C3 正方形。
   d. 以此类推直到 Cn。
5. 在最内层正方形（Cn）的内部区域中，沿主对角线（从左上到右下）绘制颜色 C1（最外层颜色）的像素。具体地：对 Sn x Sn 范围内坐标 (r, c)（0-indexed），若 r == c 则设为 C1。
6. 输出仅为 S1 x S1 的网格（原始网格被完全替换）。

**关键洞察**：输入中各颜色的空间分布完全无关紧要——只有像素总数决定输出。但输出不是简单的并排排列（区别于参考题 8abad3cf），而是同心嵌套结构，每种颜色的可见区域是一个 L 形边框（除最内层为完整正方形）。对角线轨迹用最外层颜色穿透最内层正方形，创造视觉上的"内外连接"。需多个示例确认嵌套方向是左上对齐（而非居中或右下）。

## 新题 9：控制色双效——裁切深度与填充色

**组合逻辑**：[列范围包含(定位控制像素)] → [擦除/裁切(创新：裁切深度由控制像素颜色编码，而非固定值)] + [重涂色(创新：重涂颜色也由同一个控制像素决定)]

**来源原语**：控制像素(control_pixel)、单色矩形(monochrome_rect)、列范围包含(column_span_contains)、控制色决定填色(control_fill_color)、重涂色(recolor) ← 参考题 ddf7fa4f；连通分量(connected_component)、局部边界列(local_bounding_col)、按对象局部裁切(local_bbox_crop)、擦除(erase)、相对自身定位(self_relative_pos) ← 参考题 52364a65

**依赖链**：列范围匹配找到每个对象对应的控制像素 → 控制像素颜色同时编码裁切深度和填充色 → 裁切改变对象形状，填充色改变对象颜色。同一个控制信号驱动两个效果，无法分解为独立的裁切后再查色两步（因为控制色在裁切前就已确定，且裁切深度本身来自颜色编码）。

每个灰色矩形由其列范围内的控制像素着色，同时该控制颜色决定裁掉矩形左侧多少列。

**输入结构**：黑(0)背景网格，约 12x16。顶行（第 0 行）包含若干单像素控制像素，颜色为红(2)、蓝(1)、绿(3)或黄(4)中的某几种，分布在不同列。网格中有 4-6 个灰(5) 4-连通矩形对象（每个宽 4-6 列，高 2-4 行），各矩形互不相邻、不接触顶行。每个矩形的列范围内恰好有一个控制像素的列。生成约束：每种控制颜色至少出现一次；不同矩形可以对应不同颜色的控制像素；所有矩形宽度不小于 4（确保裁切后仍有剩余像素）。

**规则**：
1. 对每个灰(5) 4-连通矩形，找到其边界框列范围 [c_left, c_right] 内的唯一控制像素，记其颜色为 K。
2. 根据颜色 K 确定裁切深度 D：红(2) → D=1，蓝(1) → D=2，绿(3) → D=3，黄(4) → D=0（不裁切）。
3. 擦除该矩形边界框内最左侧 D 列的灰色像素（设为背景黑(0)）。
4. 将该矩形剩余的灰色像素全部重涂为颜色 K。
5. 背景和控制像素保持不变。

**关键洞察**：控制像素的颜色同时编码两个信息——裁切多少和涂什么色。红色控制意味着"切 1 列，涂红"，蓝色意味着"切 2 列，涂蓝"。这种双重编码在任何单个参考题中都不存在：参考题 ddf7fa4f 中控制色只决定填充色，参考题 52364a65 中裁切深度固定为 2。需对比多个示例（尤其是黄色控制像素不裁切、绿色裁切 3 列的对比）才能归纳出颜色→深度的映射表。

## 新题 10：双区域共色链接——像素计数定尺寸，遮挡序定排列

**组合逻辑**：[像素数定边长(上区域)] + [层序推断 + 唯一序链(下区域)](创新：两个区域通过共享颜色建立链接，分别提供不同维度的信息——尺寸与顺序) → [压缩重排]

**来源原语**：色块(color_group)、正方形(square)、压缩重排(repack)、面积递增排列(area_ascending_order)、像素数定边长(pixel_count_determines_side) ← 参考题 8abad3cf；直线(straight_line)、交叉点(crossing_point)、遮挡层次(occlusion_order)、层序推断(layer_infer)、唯一序链(unique_chain)、排序(sort) ← 参考题 22425bda

**依赖链**：上区域各颜色像素数 → sqrt 得边长（决定正方形大小）；下区域线条遮挡 → 推断层序（决定排列顺序）。两个区域通过共享颜色关联。只看上区域能知道大小但不知道排列顺序（不是按面积排——需对比示例发现）；只看下区域能知道顺序但不知道大小。

上区域的散落色块按像素数还原为正方形，下区域的交叉线遮挡决定这些正方形的水平排列顺序。

**输入结构**：黑(0)背景网格，约 18x20。一条灰(5)全宽水平分隔线将网格分为上下两个区域。上区域（约 8-10 行）：3-4 种非黑非灰颜色（如红(2)、蓝(1)、绿(3)、橙(7)）的像素散布其中，形状任意，每种颜色的像素总数为完全平方数（4、9、16、25 等），各颜色边长互不相同。下区域（约 8-10 行）：与上区域使用完全相同的 3-4 种颜色，每种颜色画一条 1 像素宽的全跨度直线（水平或垂直），线之间有交叉，交叉处可见颜色揭示遮挡层次。生成约束：下区域的线交叉图连通且存在唯一哈密顿序链（底到顶全序）；上下区域使用的颜色集合完全相同。

**规则**：
1. 在上区域，对每种非黑非灰颜色计算像素总数 P，令边长 S = sqrt(P)。
2. 在下区域，从交叉点可见颜色推断唯一的从底到顶层序：底层颜色（被所有其他线遮挡）到顶层颜色（遮挡所有其他线）。
3. 构建输出：按层序从底到顶（即从左到右），依次放置对应颜色的 S x S 实心正方形，底部对齐，相邻正方形之间留一列黑(0)背景间隔。
4. 输出仅为重排后的正方形行（忽略灰(5)分隔线和原始网格的其他内容）。输出高度 = 最大边长，宽度 = 所有边长之和 + 间隔列数。

**关键洞察**：排列顺序不是按面积递增（参考题 8abad3cf 的规则），而是由下区域的遮挡层序决定。仅看上区域会自然猜测按面积排序，但对比多个示例会发现：面积最小的颜色不一定在最左边——它在层序中的位置才决定水平排列。两个视觉上无关的区域通过共享颜色形成隐式链接，这是需要跨区域推理才能发现的非显然关系。
