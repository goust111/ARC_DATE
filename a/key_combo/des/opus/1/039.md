## 新题 1：拓扑驱动的双向重力

**组合逻辑**：[内部包含/enclosed_region](创新：拓扑属性决定运动方向而非涂色) → [重力下落/gravity_drop](创新：方向由拓扑判定，非固定向下) → [重涂色/recolor](已有原语)

**来源原语**：interior_containment/enclosed_region(参考题8-b2862040)、gravity_drop/collision_stop/adjacency_blocking/obstacle(参考题5-825aa9e9)、recolor(参考题8-b2862040)

**依赖链**：拓扑检测（有洞/无洞）→ 确定每个对象的运动方向 → 对象按方向落位 → 落位后根据拓扑结果重涂色。拓扑判定同时控制两个下游操作（运动方向和颜色），删除拓扑检测则运动方向和涂色均无法确定。

根据每个浮空对象是否含有封闭空洞，决定其向上飘还是向下落，最终按拓扑类别重涂色。

**输入结构**：黑(0)背景，约15x15网格。顶行为灰(5)天花板横条，底行为灰(5)地板横条。中间散布3~5个蓝(1)的4-连通单色对象（每个3~8像素），形状各异（不限于矩形，可含弯折、分支）。其中部分对象的像素围成至少一个封闭的黑(0)背景空洞（空洞至少1像素），其余对象为实心（无封闭空洞）。各对象的列范围互不重叠（生成约束），且与天花板、地板均不相邻（至少间隔2行）。输入中不出现红(2)。

**规则**：
1. 对每个蓝(1)的4-连通对象，检查其是否包含封闭的4-连通背景空洞（空洞被该对象像素完全围住，不与网格边界背景连通）。
2. 含空洞的对象标记为"重"，无空洞的对象标记为"轻"。
3. "重"对象向下移动：每次整体平移一行，直到对象的某像素与地板或已落地的重对象的某像素4-邻接时停止。处理顺序：按对象最底行行号从大到小（离地板近的先落）。
4. "轻"对象向上移动：每次整体平移一行，直到对象的某像素与天花板或已升顶的轻对象的某像素4-邻接时停止。处理顺序：按对象最顶行行号从小到大（离天花板近的先升）。
5. 所有对象落位后，将"重"对象的所有像素重涂为红(2)，"轻"对象保持蓝(1)。
6. 天花板和地板保持灰(5)不变。

**关键洞察**：对象的移动方向不由位置或大小决定，而由其拓扑属性（是否含空洞）决定——需要对比多个示例才能排除"按位置/大小分组"的假设，锁定"含洞则重、无洞则轻"的规则。

## 新题 2：骨架对齐驱动的前缀色映射补全

**组合逻辑**：[骨架对齐/skeleton_alignment + 旋转/rotate](已有原语) → [前缀色映射/prefix_map_complete](创新：从空间对齐后的局部着色推断映射，而非从行前缀) → [印章覆盖/stamp](创新：填充颜色由映射决定，而非直接复制)

**来源原语**：skeleton_alignment/rotate/complete_anno_to_copies(参考题12-36d67576)、prefix_map_complete/encoding_map(参考题1-82819916)、stamp/anchor_pixel(参考题11-a9f96cdd, 参考题12-36d67576)

**依赖链**：骨架对齐确定旋转变换 → 变换后的局部着色与模板对应位置配对 → 配对推断出色映射 → 色映射指导补全剩余位置。去掉骨架对齐，无法配对；去掉色映射推断，无法确定补全颜色。

通过骨架旋转对齐找到局部着色与模板的对应关系，由此推断每个副本独有的色映射，再用映射补全整个副本。

**输入结构**：黑(0)背景，约20x20网格。散布4~5个精灵体副本，每个副本由灰(5)骨架像素（6~10像素的4-连通结构，形状含弯折或分支，各示例间形状不同）加一个红(2)锚点像素组成。各副本的骨架形状相同但可能经过90/180/270度旋转或水平/垂直翻转。恰好一个副本是"模板"——除骨架和锚点外，还有额外的彩色注解像素（占据骨架围成或邻接的若干固定位置，使用2~3种非灰非红非黑颜色，如蓝(1)、绿(3)、黄(4)）。其余"不完整"副本各自仅有1~2个注解像素（位于模板注解位置的子集），颜色可能与模板不同（每个副本有自己的色映射）。各副本的边界框互不重叠（生成约束）。

**规则**：
1. 找到注解像素最多的副本，作为模板。
2. 对每个不完整副本，穷举8种二面体变换（4个旋转 x 是否翻转），找到唯一一种变换使其骨架和锚点像素与模板的骨架和锚点像素逐像素匹配（平移后）。
3. 在该变换下，将不完整副本已有的注解像素映射到模板的对应位置。每个不完整副本的注解色与模板注解色形成一对一色映射（如：该副本的黄(4)对应模板的蓝(1)，该副本的橙(7)对应模板的绿(3)）。
4. 用推断出的色映射，将模板中所有注解位置的颜色映射为该副本的颜色，填入该副本缺失的注解位置。填充位置通过逆变换转回该副本的实际坐标。
5. 超出网格边界的像素丢弃。骨架和锚点像素保持原色不变。

**关键洞察**：每个副本的已有注解像素既固定了旋转方向，又定义了该副本独有的色映射——两个信息从同一组像素中提取，但服务于不同步骤。需对比多个示例才能确认是色映射而非固定色替换。

## 新题 3：分区射线滑动后或合并

**组合逻辑**：[滑动/sliding + 射线对齐/ray_alignment](已有原语) → [逻辑或合并/logical_or_merge](创新：合并的不是原始掩码，而是滑动后的结果) → [重涂色/recolor](已有原语)

**来源原语**：sliding/ray_alignment/collision_stop(参考题14-a48eeaf7)、separator_column/logical_or_merge(参考题2-195ba7dc)、filled_block(参考题14-a48eeaf7)、recolor(参考题2-195ba7dc)

**依赖链**：两个半区各自独立执行射线滑动 → 滑动结果进行或合并 → 合并结果统一重涂色。滑动改变了像素位置，合并的图案因此与原始掩码截然不同；删除滑动步骤则输出完全不同。

将分隔线两侧的标记分别向各自的中心块滑动收拢，再将两半的滑动结果进行逻辑或合并，输出联合图案。

**输入结构**：黑(0)背景，约15x12网格。正中有一条全高红(2)分隔列。左半区：一个蓝(1)的实心2x2方块，以及3~4个绿(3)标记像素，每个标记与方块处于同一行、同一列或45度对角线上（射线对齐）。右半区：同样一个蓝(1)的实心2x2方块（位置与左半区不必对称），以及3~4个绿(3)标记像素，同样射线对齐于该方块。两半区的方块和标记均不与分隔列相邻。标记像素互不重叠。

**规则**：
1. 在左半区中，将每个绿(3)标记沿其与蓝(1)方块的对齐射线（水平/垂直/对角线）向方块方向滑动，直到标记进入方块周围的邻接环（与方块某像素4-邻接的那一圈位置中，位于该射线延长线上的那个位置）。原位置清为背景。
2. 在右半区中，对标记执行同样操作。
3. 删除红(2)分隔列。
4. 将左半区和右半区按对应位置进行逻辑或合并：输出网格宽度为单个半区的宽度；对于每个位置，若左半区或右半区中任一为非背景像素，则输出蓝(1)；两边均为背景则输出黑(0)。
5. 合并时若两侧同一位置都有非背景像素，仍输出蓝(1)（不叠加）。

**关键洞察**：合并发生在滑动之后而非之前——标记先收拢到各自方块周围，再叠加出联合图案。最终图案的形状取决于两个方块在各自半区中的相对位置差异，无法从原始标记分布直接预测。

## 新题 4：最大连通分量定心的距离调色环

**组合逻辑**：[筛选/filter + 面积比较/area_comparison](已有原语) → [擦除/erase](已有原语) → [切比雪夫距离/chebyshev_distance + 距离映射/distance_mapping](创新：调色板由筛选后的小分量提供，中心由最大分量定位) → [填充/fill + 同心方环/concentric_ring](已有原语)

**来源原语**：filter/area_comparison/keep_largest_component/connected_component/noise_pixel(参考题4-1f85a75f)、chebyshev_distance/distance_mapping/concentric_ring/center_aligned(参考题13-ac0c2ac3)、erase(参考题4-1f85a75f)、fill(参考题13-ac0c2ac3)

**依赖链**：面积筛选确定最大分量 → 最大分量的质心成为方环中心 → 最大分量被擦除 → 剩余小分量按切比雪夫距离指定环色 → 填充同心方环。最大分量同时提供中心位置和筛选阈值，删除该步则中心和调色板均无法确定。

找到面积最大的连通分量作为中心锚点，用其余小分量的颜色和距离填充以该锚点为中心的同心方环。

**输入结构**：黑(0)背景，奇数边长正方形网格（如15x15或17x17）。一个灰(5)的较大4-连通分量（10~20像素，不规则形状，无特定对称性），位于网格中部偏心位置。另有3~5个较小的4-连通单色分量（每个2~4像素），各用不同颜色（如蓝(1)、红(2)、绿(3)、黄(4)、橙(7)），散布于网格各处。还有若干单像素噪声点（颜色任意），与上述分量不相邻。每个小分量到灰(5)分量质心的切比雪夫距离互不相同（生成约束）。小分量数量等于从灰(5)分量质心到网格边界的最大切比雪夫距离减去无分量占据的距离层数后的值——即并非每个距离层都有分量，无分量占据的距离层保持背景色。

**规则**：
1. 找到所有4-连通单色分量。丢弃面积为1的分量（噪声）。
2. 在剩余分量中找到面积最大的唯一分量（灰(5)分量），计算其质心：所有像素行坐标的算术平均（四舍五入取整）为中心行，列坐标同理为中心列。
3. 擦除灰(5)分量（所有像素设为背景）。
4. 对每个剩余小分量，计算其最近像素到步骤2所得中心的切比雪夫距离 d。
5. 构造输出：以中心为原点，对网格上每个像素计算其到中心的切比雪夫距离 D。若距离 D 处存在一个小分量（步骤4中 d = D），则该像素涂为该小分量的颜色；否则保持黑(0)背景。
6. 小分量自身的像素不保留在输出中——它们仅作为调色板参考，输出中只有方环。

**关键洞察**：最大分量在输出中完全消失——它只是一个指向中心的指针。小分量也不保留原位——它们的空间距离编码了调色信息。需要多个示例才能确认中心由最大分量决定（而非网格几何中心）。

## 新题 5：边框平铺计数控制内部印章数量

**组合逻辑**：[平铺/tile + 环形周期/cyclic_period](已有原语) → [计数/counting](创新：计数的对象是平铺产生的副本数，非输入中已有的) → [图案印章/stamp_glyph](创新：印章次数由计数结果决定，非占位符数量)

**来源原语**：tile/cyclic_period/repeat_equal_gap/border_segment/rectangular_border(参考题3-30f42897)、counting(参考题19-e3fe1151)、stamp_glyph/frame/placeholder/sprite(参考题17-edb79dae)

**依赖链**：边框段平铺 → 计算铺满后的副本总数 N → 在内部印章 N 个精灵体。删除平铺步骤则 N 未知；删除计数则印章数量未知；删除印章则输出不完整。

边框彩色段沿矩形边界周期平铺后，其副本总数决定了框内精灵体的印章数量。

**输入结构**：黑(0)背景，约18x18网格。一圈黄(4)矩形框架占据网格边界向内1像素的位置（即行1、行H-2、列1、列W-2构成的矩形环，行0/列0/行H-1/列W-1为背景）。框架的顶边上有一段连续的红(2)像素替换了对应位置的黄(4)像素（段长2~4像素，位于顶边的某个位置）。框架内部（被框架围住的区域）的左上角有一个红(2)占位符像素。框架内部的右下角附近有一个蓝(1)的小精灵体（3~5像素的4-连通图形，形状各示例不同）。框架内部其余为黑(0)背景。

**规则**：
1. 将框架边界展开为顺时针周期路径（从左上角开始，沿顶边→右边→底边→左边）。
2. 令红(2)段长为 n。沿路径每隔 2n 个位置放置一个红(2)段副本（即段长 n，间隔 n，周期 2n），覆盖原有的黄(4)像素。第一个副本在原始段位置。计算路径上总共能放下的红(2)段副本数 N（含原始段）。不完整的末尾副本不计入。
3. 在框架内部，从占位符像素位置开始，向右依次印章 N 个蓝(1)精灵体副本。相邻副本之间水平间隔1列背景。每个副本的左上角对齐到上一个副本的右边界再偏移1列处。
4. 若印章过程中某个副本的任何像素超出框架内部右边界，则从下一行的框架内部左边界继续放置（左上角对齐到该行的框架内部左列），行间垂直间隔1行背景。
5. 若所有行都放满仍有剩余副本需放置，则丢弃多余副本。
6. 占位符像素被第一个精灵体副本覆盖（占位符仅标记起始位置）。

**关键洞察**：边框上的红色段不是装饰——它的平铺副本数是一个编码在周长中的数值参数，控制了一个完全不同空间域（框架内部）中的操作。需对比不同示例中段长与印章数量的关系才能归纳出"副本数=印章数"的规则。

## 新题 6：镜像合并涌现封闭区域后洪泛填充

**组合逻辑**：[镜像/reflect + 纵向拼接/vertical_stacking](已有原语) → [逻辑或合并/logical_or_merge](创新：合并的是原图与自身镜像，而非两个独立掩码) → [洪泛填充/flood_fill](创新：填充的封闭区域仅在合并后才存在) → [擦除/erase](已有原语)

**来源原语**：reflect/vertical_stacking/symmetric_appending_reversed_rows(参考题7-8be77c9e)、logical_or_merge(参考题2-195ba7dc)、flood_fill/background_corridor/region_containment(参考题15-a64e4611)、enclosed_region/interior_containment(参考题8-b2862040)、erase(参考题9-f76d97a5)

**依赖链**：镜像产生对称副本 → 与原图或合并 → 合并后出现原图中不存在的封闭区域（涌现效应！） → 洪泛填充封闭区域 → 擦除墙壁像素。删除镜像则无封闭区域；删除合并则墙壁不完整；删除洪泛填充则输出为空。

将半封闭的墙壁结构与其垂直镜像合并，涌现出完整的封闭区域，再洪泛填充这些区域。

**输入结构**：黑(0)背景，约15x15网格。灰(5)像素构成若干互不相连的线段或弧形片段（每段3~8像素，4-连通），分布于网格上半部和下半部。关键约束：这些灰(5)片段在原图中不围成任何封闭的背景区域（即所有背景像素均与网格边界背景连通），但当整个网格沿水平中轴（行 H/2）上下翻转后与原图叠加（像素取或），叠加后的灰(5)墙壁围成至少1个且不超过4个封闭的4-连通背景区域。输入中不出现绿(3)。各封闭区域面积至少4像素。

**规则**：
1. 构造镜像网格：将原输入沿水平中轴上下翻转（第 r 行映射到第 H-1-r 行）。
2. 逻辑或合并：对每个位置 (r, c)，若原输入或镜像网格中任一为灰(5)，则合并结果为灰(5)；否则为黑(0)。输出网格尺寸与输入相同。
3. 在合并结果中，找到所有4-连通的黑(0)背景区域。将与网格边界相邻（区域中存在像素位于第0行、最后一行、第0列或最后一列）的背景区域标记为"外部"。
4. 对每个非外部的背景区域（即封闭区域），将其所有像素洪泛填充为绿(3)。
5. 将所有灰(5)像素擦除为黑(0)。
6. 输出：黑(0)背景上仅保留绿(3)的填充区域。

**关键洞察**：原图中没有任何封闭区域——封闭性完全是镜像合并后的涌现效果。求解者必须先想到"镜像叠加"这一构造步骤，才能理解绿色区域从何而来。这是典型的 A+B 涌现：单独的原图或单独的镜像都不产生封闭区域，合并后才出现。

## 新题 7：标记选半后跨半区多重集补全

**组合逻辑**：[标记对齐指定半区/marker_selects_half + 裁剪/crop](已有原语) → [颜色多重集相同/same_color_multiset + 各区域缺像素/region_miss_pixel](创新：参照来自被丢弃的半区而非相邻区域) → [填充/fill](已有原语) → [擦除/erase](已有原语)

**来源原语**：marker_selects_half/keep_marked_half(参考题18-fbf15a0b)、crop(参考题18-fbf15a0b)、same_color_multiset/region_miss_pixel(参考题19-e3fe1151)、fill(参考题19-e3fe1151)、erase/marker_pixel(参考题18-fbf15a0b)

**依赖链**：标记像素选择输出半区 → 被丢弃半区提供参照多重集 → 与选中半区对比找出缺失颜色 → 填充缺失色 → 擦除标记。选择和参照来自对立半区，形成反相依赖：选中哪一半决定了参照来源。

用标记像素选出一半网格作为输出，但需参考被丢弃的另一半来补全选中半区缺失的颜色。

**输入结构**：黑(0)背景，约12x20网格（宽大于高）。两个红(2)标记像素位于同一行，且都位于左半区（列号 < W/2）。左半区和右半区各自包含若干彩色像素（非背景、非红），使用相同的颜色集合（如蓝(1)、绿(3)、黄(4)），但各半区恰好缺少一个颜色的一个像素位置（该位置为黑(0)背景）。两个半区的缺失颜色不同。两个半区的完整多重集应相同（即：若补上各自缺失的那个颜色像素后，两半区的非背景颜色计数完全一致）。彩色像素的具体空间排列在两半区中不同（不是镜像关系）。

**规则**：
1. 两个红(2)标记像素在同一行且均在左半区 → 选择左半区为输出。
2. 统计右半区（被丢弃半区）的非背景、非红颜色多重集 M_right。
3. 统计左半区（选中半区）的非背景、非红颜色多重集 M_left。
4. 对每种颜色 c，完整多重集中 c 的计数 = max(M_left[c], M_right[c])。
5. 左半区缺失的颜色 c* 满足：M_left[c*] < 完整多重集中 c* 的计数。在左半区中，找到唯一一个被黑(0)背景占据但在对应空间结构中应属于内容区域的位置（即该位置的上下左右至少有两个非背景邻居），将其填充为 c*。
6. 将两个红(2)标记像素擦除为黑(0)。
7. 输出：左半区（宽度为 W/2 的子网格），包含补全和擦除后的结果。

**关键洞察**：标记像素告诉你输出哪一半，但你必须读取另一半才能知道缺什么颜色。被丢弃的半区不是废料，而是补全信息的来源——选择和参照形成反向耦合。

## 新题 8：前缀色映射驱动的封闭区域棋盘填充

**组合逻辑**：[前缀色映射/prefix_map_complete + 编码映射/encoding_map](创新：映射结果不用于补全行，而用于指定填充颜色) → [封闭区域/enclosed_region + 内部包含/interior_containment](已有原语) → [填充/fill](创新：填充颜色和图案由映射决定) → [擦除/erase](已有原语)

**来源原语**：prefix_map_complete/encoding_map/template_row/prefix_segment/col_alignment(参考题1-82819916)、enclosed_region/interior_containment(参考题8-b2862040)、fill(参考题13-ac0c2ac3)、erase(参考题1-82819916)

**依赖链**：模板行定义双色序列 → 每个前缀行推断色映射 → 色映射的两色成为该行对应封闭区域的棋盘填充用色 → 按棋盘图案填充区域内部。删除模板则无法推断映射；删除封闭区域检测则无处可填。

每行的左端前缀与模板行配对推断出一组色映射，该映射的两种颜色以棋盘图案填充该行所关联的封闭矩形区域。

**输入结构**：黑(0)背景，约18x18网格。正中有一条完整的非背景横行（"模板行"），使用两种颜色（如蓝(1)和绿(3)）交替排列成某种图案（不一定严格交替，但每种颜色至少出现2次）。模板行上方和下方各有2~3行"前缀行"——每行从第0列开始有一段连续的非背景像素（2~4像素），其余为背景。每个前缀使用两种颜色，与模板行中相同列位置的颜色配对后，可推断出一一映射（如：前缀中黄(4)对应模板蓝(1)，前缀中橙(7)对应模板绿(3)）。每个前缀行的同一行（或相邻行，由生成确定）上还有一个灰(5)像素构成的封闭矩形框（3x3到5x5大小，壁厚1像素），框内全为背景。每个矩形框与其对应前缀行处于相同的行范围内（框的某一行与前缀行行号相同）。矩形框不与模板行重叠。不同前缀行的矩形框互不重叠。

**规则**：
1. 识别模板行（唯一一条全宽非背景行）。
2. 对每个前缀行，将前缀的第 k 个像素颜色与模板行第 k 列的颜色配对，推断该前缀行的色映射 M：M 将模板的两种颜色分别映射到前缀的两种颜色。
3. 找到与该前缀行行号相同的灰(5)封闭矩形框。
4. 用该前缀行的色映射 M 对矩形框内部进行棋盘填充：框内位置 (r, c) 的颜色为 M(模板色A) 若 (r+c) 为偶数，M(模板色B) 若 (r+c) 为奇数。其中模板色A是模板行中出现在更靠左位置的颜色，模板色B是另一种。
5. 擦除前缀行的像素（设为背景）和模板行的像素（设为背景）。灰(5)矩形框保留。
6. 输出：保留灰(5)框和框内的棋盘填充，其余为黑(0)背景。

**关键洞察**：前缀不是用来补全行的——它是一个解码器，将模板的抽象双色序列翻译成该区域专用的填充色对。模板行在输出中消失，前缀也消失，它们的唯一作用是建立色映射关系。

## 新题 9：空洞中心连线与拓扑重涂色

**组合逻辑**：[封闭区域/enclosed_region + 内部包含/interior_containment](已有原语) → [连线/draw_line + 端点连接/endpoint_connection](创新：连线端点为空洞中心而非画布边界) → [射线对齐/ray_alignment](创新：作为连线的过滤条件而非滑动条件) → [重涂色/recolor](已有原语)

**来源原语**：enclosed_region/interior_containment/objects_with_holes_recolored(参考题8-b2862040)、draw_line/endpoint_connection(参考题10-3bd67248)、ray_alignment(参考题14-a48eeaf7)、recolor(参考题8-b2862040)、connected_component(参考题4-1f85a75f)

**依赖链**：空洞检测确定哪些对象参与连线 → 空洞中心计算确定端点位置 → 射线对齐过滤确定哪些端点对可连 → 绘制连线 → 拓扑属性决定重涂色。空洞检测同时驱动连线资格和涂色两个下游操作。

找到含空洞的对象，在射线对齐的空洞中心之间画线，并将含洞对象重涂色。

**输入结构**：黑(0)背景，约16x16网格。散布5~7个蓝(1)的4-连通单色对象（每个5~12像素），形状各异（含弯折、分支，非矩形）。其中2~4个对象各自围成恰好一个封闭的4-连通背景空洞（空洞2~4像素）。其余对象为实心（无封闭空洞）。各对象边界框互不重叠（生成约束）。至少有一对含洞对象的空洞中心处于同行、同列或45度对角线上（射线对齐）。输入中不出现红(2)和绿(3)。

**规则**：
1. 找到所有蓝(1)的4-连通对象。对每个对象检测其是否包含封闭的4-连通背景空洞。
2. 对每个含洞对象，计算其空洞的中心像素：空洞所有像素的行坐标算术平均（四舍五入取整）和列坐标算术平均（四舍五入取整）。若中心恰好落在对象像素上，则取空洞中距该计算点最近的像素（若有多个等距像素，取行号最小的，再取列号最小的）。
3. 对所有含洞对象的空洞中心两两配对。若两个中心处于同行（行号相同）、同列（列号相同）或45度对角线上（行差绝对值等于列差绝对值），则在这两个中心之间画一条直线，颜色为红(2)。直线包含两个端点和之间的所有像素（Bresenham直线）。
4. 不满足射线对齐条件的中心对不画线。
5. 将所有含洞对象的蓝(1)像素重涂为绿(3)。实心对象保持蓝(1)不变。
6. 绘制顺序：先重涂色，再画线。红(2)线覆盖在绿(3)和蓝(1)像素之上（线优先）。背景空洞保持黑(0)不变。

**关键洞察**：连线不是连接对象本身，而是连接对象内部空洞的中心——端点隐藏在对象内部的负空间中。需要多个示例才能排除"连接对象中心"或"连接边界框中心"等替代假设。

## 新题 10：序列外推与拓扑门控涂色

**组合逻辑**：[序列外推/sequence_extrapolation + 恒定偏移平移/constant_offset_translation](已有原语) → [封闭区域/enclosed_region + 内部包含/interior_containment](创新：检测的是外推后的形态，非原始输入) → [重涂色/recolor](创新：涂色条件取决于外推结果的拓扑属性)

**来源原语**：sequence_extrapolation/constant_offset_translation/panel_frame/separator_row/foreground_sprite(参考题16-351d6448)、enclosed_region/interior_containment/objects_with_holes_recolored(参考题8-b2862040)、recolor(参考题8-b2862040)

**依赖链**：面板序列定义运动和生长规律 → 外推得到第5帧的对象形态 → 检测外推形态是否含空洞 → 根据空洞有无决定输出颜色。外推步骤的结果直接决定了拓扑检测的输入，拓扑检测的结果决定了涂色——三步紧密串联，跳过任一步无法求解。

外推动画序列中持续生长的对象到下一帧，若外推后的形态首次围成封闭空洞则变色输出。

**输入结构**：黑(0)背景，约24x7网格（宽矮）。四个等高的面板纵向堆叠，由黄(4)全宽分隔行隔开。每个面板高度相同（如5行），宽度相同（如7列）。每个面板中有一个蓝(1)的4-连通对象。从第1帧到第4帧，该对象逐帧平移（每帧整体偏移固定的 (dr, dc)，dr和dc为-1/0/1之一）并且逐帧生长——每帧恰好新增1个像素（新像素与前一帧对象的某个边界像素4-邻接），使对象保持4-连通。四帧中的生长位置遵循一个可归纳的规律（如：每帧在对象当前形态的最右下角边界处新增一个像素，或沿某个固定方向延伸）。在前4帧中，对象均不含封闭空洞。

**规则**：
1. 识别四个面板及其分隔行。提取每帧中蓝(1)对象的形态和位置。
2. 确定逐帧平移偏移 (dr, dc)：对比相邻帧中对象（去除新增像素后）的位置变化。
3. 确定逐帧生长规律：对比相邻帧，找到每帧新增的像素相对于平移后的前帧对象的位置，归纳新增像素的选择规则。
4. 外推第5帧：将第4帧对象平移 (dr, dc)，按生长规律新增1个像素，得到第5帧对象形态。
5. 检测第5帧对象是否含有封闭的4-连通背景空洞。
6. 若含空洞：将第5帧对象重涂为红(2)输出。若不含空洞：保持蓝(1)输出。
7. 输出为单个面板大小的网格，包含第5帧的对象（可能重涂色后），背景为黑(0)。

**关键洞察**：前4帧的对象都不含空洞，但生长规律可能使第5帧恰好围成一个空洞——拓扑属性的变化点正好在需要外推的那一帧。求解者必须实际执行外推并检查结果的拓扑，而不能从前4帧的拓扑状态简单外推颜色。
