## 新题 1：条纹定向重力灌注

**组合逻辑**：[denoise 方向评分](创新：从决定重涂方向改为决定物理重力轴) → [gravity_drop] → [flood_fill]（三者串联但每步输出类型不同：方向 → 空间着陆 → 区域着色）

**来源原语**：denoise / dominant_color / dominant_fills_line（e26a3af2）；gravity_drop / collision_blocking / gravity_far_to_near（5ffb2104）；flood_fill / enclosed_region / area_determines_fill_color（c0f76784）

**依赖链**：条纹方向评分输出一个轴向（水平或垂直），该轴向决定标记像素的重力滑动方向；重力滑动决定每个标记最终着陆在哪个框架的边界上；着陆对应关系决定每个封闭区域被灌注何种颜色。删除条纹评分则重力方向未知，删除重力则标记无法到达框架，删除灌注则无可见输出。

将噪声条纹的主导方向转化为重力轴，让彩色标记沿该轴滑向空心框架并灌注其内部。

**输入结构**：约 15x18 的网格，背景黑(0)。网格中充满噪声条纹提示：若为水平条纹主导，则大部分行各自拥有一个主导前景色（从灰(5)、蓝(1)、绿(3) 中选），每行含 1-3 个噪声像素；若为垂直条纹主导则每列如此。仅一个方向明显占优。网格的一半区域（与重力目标边相邻的一侧）放置 3-4 个橙(7) 色空心矩形轮廓，每个围出不同尺寸的黑色内部（如 2x2、2x3、3x3），框架之间至少间隔 2 格。另一半区域散布 3-4 个单像素彩色标记，颜色各不相同，取自红(2)、黄(4)、品红(6)、栗(9)。生成约束：每个标记沿重力方向的轨迹恰好经过一个框架的边界像素上方，且不同标记对应不同框架，保证一一映射。

**规则**：
1. 评分水平条纹解释：对每行找出最频繁的非黑颜色并累加其出现次数，得到水平总分。同理对每列求垂直总分。
2. 总分更高的方向即为条纹方向；重力轴垂直于条纹方向。若水平条纹得分高，重力向下（标记从上方落向下方框架）或向上（若标记在框架下方则向上）；若垂直条纹得分高，重力向右或向左，方向由标记与框架的相对位置自然确定（标记朝框架所在的一侧滑动）。
3. 每个彩色标记沿重力方向逐格滑动，保持单像素形态，直到下一格与某个橙色框架边界像素正交相邻时停止（即"着陆"在框架上）。处理顺序：离重力目标边最近的标记先处理、先着陆（gravity_far_to_near 的反向：近者先定）。
4. 每个框架被分配着陆在其重力面边界上的标记颜色。若同一框架边界上着陆了多个标记（生成约束下不会发生），取更靠近框架水平/垂直中心的标记。
5. 对每个框架的封闭黑色内部执行洪泛填充，颜色为其被分配的标记色。
6. 输出：条纹全部移除（替换为黑色），标记像素移除，橙色框架轮廓保留，框架内部被填充。

**关键洞察**：条纹图案在输出中完全不可见——它的唯一作用是编码重力轴向；真正决定输出颜色分布的是标记与框架之间的空间对齐关系，而这种对齐只有在确定重力方向之后才能计算。

## 新题 2：标记定向对角射线与距离优先交叉

**组合逻辑**：[ray_extend](创新：射线方向不再固定为"蓝左上红右下"，而由外部方向标记像素决定) + [recolor](创新：交叉像素的颜色由两条射线到各自源方块的距离差决定，不由图层序或颜色编号决定)

**来源原语**：ray_extend / diagonal_dir / square / canvas_boundary（5c0a986e）；recolor / marker_pixel / nearest_neighbor_matching（50aad11f）；collision_blocking（5ffb2104）

**依赖链**：方向标记决定每个方块的射线发射角 → 所有射线同步逐格生长，距离相等时同步推进 → 两条射线同步到达同一格时，距离更短者占据该格 → 射线网络形成一种对角 Voronoi 分割。射线方向、生长规则、交叉裁决三环节缺一不可。

每个彩色方块从其标记角发射对角射线；射线同步生长，交叉处归距源更近的射线。

**输入结构**：约 15x15 黑(0) 网格。3-5 个彩色 2x2 方块，颜色各不相同（如蓝(1)、红(2)、绿(3)、黄(4)、品红(6)）。每个方块在其四个外角之一的对角邻位（距方块角 1 格的对角位置）放置一个灰(5) 单像素方向标记。生成约束：至少有两对方块的射线会在网格内交叉；灰色标记不会位于任何其他方块或标记的邻域内。

**规则**：
1. 对每个方块，找到其灰色方向标记。标记指示射线从方块最近的那个角出发，朝远离方块中心的对角方向延伸。例如标记在方块左上角的左上对角位 → 射线从方块左上角向左上延伸。
2. 所有射线同步生长：每一步，每条仍在延伸的射线向其方向前进一格，将该格涂为源方块的颜色。射线在下一格超出网格时终止；射线在下一格碰到另一方块的本体（2x2 区域）时终止于当前格（不覆盖方块本体）。
3. 若两条（或更多条）射线在同一步到达同一格：该格归属于从源方块角到该格的切比雪夫距离更小的射线。若距离相等，归属于源方块左上角行坐标更小的射线；行坐标也相同则列坐标更小者胜。
4. 若一条射线到达的格已被先前步骤中另一条射线占据，该射线在该格前终止（不覆盖已占据的格）。
5. 输出中移除所有灰色方向标记（还原为黑色）。方块本体和射线保留。

**关键洞察**：同步生长加距离优先裁决产生了一种对角 Voronoi 分割——交叉边界线的位置取决于方块之间的对角距离和各自的射线方向。仅看单个示例可能误以为射线互不干涉或简单覆盖；需对比多个交叉事件才能归纳距离优先规则。

## 新题 3：螺旋路径采样条纹色板

**组合逻辑**：[denoise / dominant_color](条纹清洁 → 构建逐行颜色查找表) + [spiral_grow / turn_priority_rule](螺旋路径提供采样几何) → 两者交集产生输出（创新：条纹不直接输出，而是作为隐式色板被螺旋路径按位置索引）

**来源原语**：denoise / stripe_line / noise_pixel / dominant_color / dominant_fills_line（e26a3af2）；spiral_grow / path_draw / cross_pattern / arm_tip / turn_priority_rule / spacing_constraint（da515329）

**依赖链**：条纹清洁确定每行的主导色 → 螺旋路径确定哪些格被访问 → 每个螺旋格取其所在行的主导色 → 输出仅含着色后的螺旋路径。条纹单独只给颜色无几何，螺旋单独只给几何无颜色，二者缺一则输出不确定。

清洁噪声条纹获得逐行色板，从十字图案生长螺旋路径，每个螺旋像素着色为其所在行的条纹主导色。

**输入结构**：约 17x17 网格（奇数边长以便十字居中），背景黑(0)。网格被噪声水平条纹充满：每行有一个主导前景色（取自红(2)、绿(3)、黄(4)、蓝(1)、品红(6) 共 4-5 种颜色），行内含 1-3 个噪声像素（取其他条纹色或黑色）。相邻行的主导色不全相同，保证色板有变化。一个青(8) 十字图案（中心像素加四个臂各 1-2 格，共约 5-9 像素）放置在网格大致中心位置，覆盖其下的条纹像素。生成约束：十字臂足够短，螺旋有空间生长；十字所在行的主导色仍可从该行剩余非青像素中判定。

**规则**：
1. 确定每行的主导色：统计该行中每种非黑、非青(8) 颜色的像素数，最多者即为主导色。若某行全为黑色或无法判定（如十字占据整行），该行主导色记为黑(0)。
2. 从青色十字的每个臂端，启动一个"海龟"，初始朝向为臂的外向方向顺时针旋转 90 度。移动优先级：右转 > 直行 > 左转（仅当非边界时才可左转）。常规步长 = 2 格；紧接转弯后的第一步步长 = 1 格。每个新占据的格必须与除前驱外的所有已有路径像素保持至少 1 格正交间隔。
3. 每个螺旋访问的格被着色为该格所在行的主导色（第 1 步结果）。
4. 输出：纯黑背景上仅绘制螺旋路径像素（按第 3 步着色）。原始条纹、噪声像素和青色十字均被移除。

**关键洞察**：条纹在输出中完全不可见——它纯粹充当按行索引的颜色查找表。螺旋几何决定了哪些行位置被采样以及采样的空间排布；条纹色板决定了每个位置的颜色。两个完全不同的结构（条纹 vs. 螺旋）在像素级别交汇，产生单独看任何一方都无法预测的输出图案。

## 新题 4：轴侧翻转精灵体的象限组装

**组合逻辑**：[mirror / reflect_along_axis](创新：镜像不产生副本，而是作为二元分类器——轴一侧的精灵体翻转、另一侧不翻转) + [copy_place / legend_position_mapping]（象限组装）

**来源原语**：mirror / symmetry_axis / reflect_along_axis / foreground_pixel（ad3b40cf）；copy_place / selector_block / sprite / quadrant / color_index_matching / legend_position_mapping（7d18a6fb）

**依赖链**：对称轴将网格分为两侧 → 精灵体按所在侧被标记为"保持原样"或"需要翻转" → 选择器块的标记颜色指定哪个精灵体放入哪个象限 → 放入时根据侧别标记决定是否翻转。轴位置改变则翻转分组改变，精灵体位置改变则象限分配改变。

根据精灵体相对于对称轴的位置决定是否翻转，再按选择器块的颜色标记将精灵体放入对应象限。

**输入结构**：约 18x18 黑(0) 网格。一种前景色（灰(5)）形成一条完整行或完整列——即对称轴。轴的一侧（"近侧"，即轴与网格中心之间的区域）放置 2 个小型单色 4-连通精灵体，每个边界框 3x3，颜色各不相同（如红(2)、蓝(1)）。轴的另一侧（"远侧"）同样放置 2 个精灵体，边界框 3x3，颜色各不相同（如黄(4)、绿(3)）。四个精灵体形状互不相同（不存在旋转/镜像等价对）。远处放置一个 7x7 选择器块，内部填充栗(9)，四个 3x3 象限的中心各有一个单像素标记，标记颜色恰好是四个精灵体的四种颜色。近侧/远侧的判定依据：精灵体边界框中心到轴的曼哈顿距离，距离较小者为近侧。生成约束：四个精灵体到轴的距离互不相等，不存在近远判定歧义。

**规则**：
1. 识别灰色轴线，判断其为行（水平轴）还是列（垂直轴）。
2. 按精灵体边界框中心到轴的曼哈顿距离分组：距离较小的 2 个为近侧，较大的 2 个为远侧。
3. 近侧精灵体保持原始朝向不变。
4. 远侧精灵体执行翻转：若轴为水平行，则上下翻转（垂直镜像）；若轴为垂直列，则左右翻转（水平镜像）。
5. 构建 7x7 输出画布，分为四个 3x3 象限，中间行和中间列填充栗(9)。
6. 对选择器块中每个象限的标记颜色，找到对应颜色的精灵体（经过第 3/4 步处理后），将其放入该象限。

**关键洞察**：对称轴不产生任何镜像副本——它仅充当一个空间分类器，决定哪些精灵体在组装前需要翻转。同一精灵体在轴的不同侧会产生不同的象限内容。这种"轴作为条件开关"的用法与参考题中"轴作为反射生成器"完全不同。

## 新题 5：嵌套矩形补全后的对角射线探测

**组合逻辑**：[complete / large_first_small_over](稀疏嵌套矩形补全建立层叠结构) + [ray_extend / diagonal_dir](创新：从最内层矩形四角发射对角探测射线，射线碰到的外层被"吸收"为内层颜色)

**来源原语**：complete / sparse_rect_layer / nested_rectangle / outer_to_inner / large_first_small_over（5751f35e）；ray_extend / canvas_boundary / diagonal_dir（5c0a986e）；recolor（50aad11f）

**依赖链**：稀疏像素补全确定各层矩形的完整边界 → 补全后的边界成为射线的碰撞障碍 → 最内层四角各发一条对角射线 → 射线碰到的外层整体被重涂为内层色 → 未被射线碰到的外层保持原色。补全步骤必须先完成，否则射线无障碍可碰；射线必须在补全之后，否则不知从哪四个角出发。

补全稀疏嵌套矩形后，从最内层四角发射对角射线，将射线首先碰到的外层整体重涂为内层颜色。

**输入结构**：约 15x15 黑(0) 网格。3-4 种前景色（如红(2)、蓝(1)、绿(3)、黄(4)），每种颜色标记一个轴对齐矩形区域的部分像素。矩形严格嵌套（每个完全包含在下一个更大的矩形内），边界框面积严格递增。最内层矩形完整绘制（所有边界和内部像素均存在）。外层矩形仅有稀疏的边界像素可见（每条边有 1-3 个采样点）。关键约束：最内层矩形不居中于外层——它在水平和垂直方向上都有偏移，使得四个角到最近外层边界的对角距离互不相等。

**规则**：
1. 对每种前景色，从其可见像素推断边界框。按面积从大到小补全矩形：先画最外层的完整填充矩形，再画次外层（覆盖外层），最后画最内层（覆盖所有外层），即大层先画、小层后画覆盖。
2. 补全完成后，从最内层矩形的四个角各发射一条对角射线：左上角 → 左上方向，右上角 → 右上方向，左下角 → 左下方向，右下角 → 右下方向。射线以最内层矩形的颜色绘制。
3. 每条射线逐格延伸，直到碰到一个颜色不同于最内层的像素（即某个外层矩形的边界）或超出网格。射线终止于碰到的那个像素之前（不覆盖外层边界像素本身）。
4. 当射线碰到某个外层矩形时，该外层矩形的所有像素（边界和内部中属于该层可见的部分——即补全后该层未被更内层覆盖的像素）全部重涂为最内层的颜色。
5. 若射线未碰到任何外层（直接飞出网格），则该方向不触发重涂。
6. 不同角的射线可能碰到不同的外层（因偏移），因此部分外层被吸收、部分保持原色。

**关键洞察**：最内层的偏移位置是核心变量——它决定了哪些对角方向"够得到"外层、哪些直接飞出网格。补全步骤构建了射线的碰撞环境，而射线结果反过来修改了补全产生的层叠着色。需对比多个示例（不同偏移量）才能归纳出"射线碰到即吸收整层"的规则。

## 新题 6：角标记房间的贪心遍历与渐进遮挡

**组合逻辑**：[greedy_traversal / path_painting](最近可见优先走廊绘制) + [fill / four_corners_define_interior](创新：角标记定义的矩形在被访问后填充为实体，成为后续视线的障碍物，使遍历图在过程中动态变化)

**来源原语**：path_painting / greedy_traversal / start_block / target_block / corridor_path / line_of_sight_visible / row_or_column_aligned / line_of_sight_blocked / nearest_unvisited_first（3490cc26）；fill / corner_marker / rectangle / row_column_alignment / four_corners_define_interior（af902bf9）

**依赖链**：角标记定义隐藏矩形 → 贪心遍历从起始块出发寻找最近可见的矩形中心 → 抵达后矩形内部被填充为实心 → 实心矩形阻挡后续视线 → 下一步可见的目标集合因此改变。每次填充都改变了遍历图的拓扑，使得遍历顺序是空间布局的涌现结果，而非预定义序列。

从起始块贪心遍历角标记定义的矩形，每到达一个矩形就填充其内部；填充后的实心矩形阻挡后续视线。

**输入结构**：约 20x20 黑(0) 网格。一个红(2) 2x2 起始块。4-5 组角标记，每组由 4 个同色单像素构成一个轴对齐矩形的四个角（四个标记恰好共享两个行值和两个列值）。各组颜色互不相同，取自蓝(1)、绿(3)、黄(4)、品红(6)、青(8)。角标记定义的矩形内部为空（黑色），矩形之间不重叠，尺寸在 3x3 到 6x6 之间。生成约束：起始块与至少一个矩形中心共享行或列；遍历过程中至少有一个矩形因前序矩形的填充而变得不可见（从而展示遮挡机制）；至少能访问 3 个矩形后遍历终止。

**规则**：
1. 从每组 4 个同色角标记推断其定义的矩形：行范围为 4 个标记的最小行到最大行，列范围同理。
2. 每个矩形的"中心"定义为其边界框中心像素（行列各取 (min+max)//2，向下取整）。
3. 从红色起始块出发（以其左上角像素为当前位置），搜索最近的可见未填充矩形中心。"可见"定义：当前位置与目标中心在同一行或同一列上，且两者之间的直线路径上没有任何已填充矩形的像素或其他非背景像素（角标记像素不阻挡视线，仅已填充的实心矩形体阻挡）。"最近"定义：当前位置到目标中心的曼哈顿距离最小。若距离相等，选行坐标更小者；行也相等则选列坐标更小者。
4. 将当前位置到目标中心之间的直线路径上所有黑色背景格涂为橙(7)——即走廊。走廊不覆盖角标记像素。
5. 到达目标矩形中心后，将该矩形内部（四个角标记围成的区域，不含角标记本身）填充为该组角标记的颜色。
6. 填充后的矩形成为实心障碍物。从该矩形中心出发，重复步骤 3-5，寻找下一个最近可见的未填充矩形。
7. 当没有任何未填充矩形从当前位置可见时，遍历终止。未被访问的矩形保持原状（仅有角标记，内部仍为黑色，无走廊通达）。

**关键洞察**：遍历顺序不是预设的——它从空间布局中涌现，因为每次填充都改变后续的可见性图谱。相同的矩形集合中仅移动一个矩形的位置，就可能导致完全不同的遍历路径和不同的矩形被遗弃。需对比多个示例才能发现"填充即遮挡"的状态突变机制。

## 新题 7：块条展开后的稀有象限轴向镜像

**组合逻辑**：[unfold_nest / reverse_order_read](2x2 块条展开为四象限嵌套图案) + [mirror / reflect_along_axis](创新：展开结果中最稀有外层色的象限被选中，沿轴指示器方向镜像覆盖对侧象限)

**来源原语**：unfold_nest / block_cell / quadrant / nested_layer / block_order_maps_layer / reverse_order_read（8fff9e47）；mirror / symmetry_axis / reflect_along_axis / min_pixel_color / outlier_selection（ad3b40cf）

**依赖链**：块条被展开为四个嵌套象限图案 → 统计四个象限外层颜色的全局像素数以找出最稀有者 → 轴指示器行/列决定镜像方向 → 最稀有外层色所在的象限被沿该轴反射，覆盖对侧象限。展开决定象限内容，像素统计决定选哪个象限，轴指示器决定镜像方向——三个独立信息源汇聚为一个操作。

展开块条为四象限嵌套图案，将外层色最稀有的象限沿轴指示器方向镜像覆盖其对侧。

**输入结构**：输入为一个矩形块条（短边 4 像素，如 4x8、4x10、10x4 等），由 2x2 块精确分割。块条一边（上/下/左/右）附加一行或一列均匀前景色像素作为"轴指示器"，使总输入比纯块条多一行或一列。块像素使用 4-6 种不同前景色（如红(2)、蓝(1)、绿(3)、黄(4)、品红(6)、橙(7)）。轴指示器使用其中一种颜色。生成约束：展开后四个象限的外层（最外圈）颜色中，恰好有一个象限的外层色在全输出中总像素数最少（唯一最稀有），其余三个象限的外层色有重复或像素数更多。

**规则**：
1. 分离轴指示器行/列与块条主体。记录轴指示器位于哪条边——这决定反射方向：若为行（上或下边）→ 垂直方向反射（上下翻转）；若为列（左或右边）→ 水平方向反射（左右翻转）。
2. 将块条展开为方阵输出，含四个象限嵌套图案：按反向行主序读取 2x2 块（右下块最先，向左移动，再向上行），将每个块的左上、右上、左下、右下像素分别送入左上、右上、左下、右下象限的对应层（如 8fff9e47 所述）。
3. 展开完成后，检查每个象限的最外层（第一层）颜色。统计这四种外层颜色各自在整个展开输出中的总像素数。找到总像素数最少的那个外层颜色所对应的象限（唯一确定）。
4. 将该象限的内容沿步骤 1 确定的方向反射到输出的对侧象限位置，覆盖对侧象限原有内容。具体地：若垂直反射，则上半部分的选中象限内容上下翻转后覆盖下半对应象限（或反之）；若水平反射，则左半选中象限左右翻转后覆盖右半对应象限（或反之）。
5. 输出：修改后的展开方阵。

**关键洞察**：展开步骤决定四个象限的内容，但哪个象限"胜出"并覆盖对侧取决于两个独立因素——轴指示器（决定反射方向：上下还是左右）和全局像素统计（决定选哪个象限）。改变轴指示器方向而不改变块条内容，会改变被覆盖的是哪个象限；改变块序而不改变轴，会改变哪个象限被选为源。需对比多个示例才能同时归纳出稀有性选择和轴向反射两条规则。
