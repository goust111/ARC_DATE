## 新题 1：可达性门控的周期瓦片修复

**组合逻辑**：[泛洪填充/flood_fill](从角标记出发判定可达区域) + [补全/repair](对可达区域内缺失单元执行周期推断填补) + [擦除/erase](不可达区域和装饰性墙壁被清除)

**来源原语**：泛洪填充、可达性、边界连通区分结构（来自 8f3a5a89）；补全、周期瓦片、缺失单元、最小周期推断填补（来自 29ec7d0e）；擦除（来自 009d5c81）；墙壁障碍、装饰碎片（来自 8f3a5a89）

**依赖链**：泛洪填充的可达性结果决定哪些区域有资格进行周期修复——不可达区域被整体擦除而非修复，因此修复算法的作用域完全由空间连通性控制；同时，结构性墙壁与装饰性墙壁的区分既影响可达性判定，也影响最终哪些像素被保留。

从角落标记出发泛洪，仅修复可达区域内的周期瓦片缺损，不可达区域及装饰性墙壁被擦除。

**输入结构**：约 18x18 的网格，背景为黑(0)。蓝(1) 像素构成墙壁障碍，将网格内部分割为若干互不连通的区域。墙壁分两类：结构性墙壁（其 4-连通分量至少有一个像素位于网格边界行或边界列）和装饰性墙壁（其 4-连通分量完全不接触网格边界）。网格的一个角落（如左上角第 (0,0) 格）放置一个品红(6) 像素作为起始标记。每个被墙壁分隔出的区域内部，存在一个周期性颜色图案的不完整样本：部分像素显示为非黑、非蓝、非品红的颜色（从红(2)、绿(3)、黄(4)、灰(5)、橙(7) 中选用），其余位置为黑(0)（即缺失单元）。每个区域的周期图案可能不同（周期大小 p 为 2 或 3），但在该区域内所有可见的非零像素按 (row mod p, col mod p) 取值一致。生成约束：每个区域内可见像素足以唯一确定其最小周期瓦片；品红标记仅占一个像素且位于网格角落；至少存在一个不可达区域和一个装饰性墙壁分量。

**规则**：
1. 识别墙壁类型：将蓝(1) 像素按 4-连通分量聚类；若分量中至少一个像素位于网格边界行（第 0 行或最后一行）或边界列（第 0 列或最后一列），则该分量为结构性墙壁，否则为装饰性墙壁。
2. 从品红(6) 标记像素出发，对黑(0) 像素做 4-连通泛洪填充，蓝(1) 像素（无论结构性还是装饰性）均阻挡泛洪。所有被泛洪到达的黑(0) 像素及与其同属一个背景连通分量的非黑、非蓝像素所在的区域标记为"可达区域"。
3. 对每个可达区域：收集该区域内所有非黑(0)、非蓝(1)、非品红(6) 的像素，按 (row mod p, col mod p) 推断最小周期 p 及对应的 p x p 瓦片，将该区域内所有黑(0) 缺失像素替换为瓦片对应位置的颜色。
4. 对每个不可达区域：将该区域内所有非蓝像素（包括可见的图案像素和黑像素）全部设为黑(0)。
5. 擦除所有装饰性墙壁分量（将其像素设为黑(0)）；保留所有结构性墙壁。
6. 将品红(6) 标记像素设为黑(0)。

**关键洞察**：装饰性墙壁在泛洪阶段充当了有效障碍（阻止可达性扩散），但在最终输出中被擦除——求解者必须识别出墙壁的"阻挡-但-消失"双重角色：它影响了哪些区域被修复，但自身不出现在结果中。

## 新题 2：拓扑空洞检测选择对角射线源

**组合逻辑**：[重涂色/recolor](基于拓扑属性条件性重涂) + [射线延伸/ray_extend](从合格对象的角出发沿对角延伸) + [擦除/erase](不合格对象被移除)

**来源原语**：重涂色、封闭区域、包含、有空洞则重涂（来自 810b9b61）；射线延伸、角对角对齐、经过框角才延伸（来自 ec883f72）；空心矩形/hollow_frame（来自 ec883f72）；擦除（来自 009d5c81）

**依赖链**：空洞检测结果（拓扑属性）直接决定哪些对象成为射线发射源——没有空洞的实心对象不发射射线而是被擦除；射线的颜色取决于发射源对象的颜色，射线的激活方向取决于其角是否在对角线上经过灰框角。空洞检测与射线延伸在"哪些对象参与变换"这一层面耦合。

仅从包含封闭空洞的前景对象的角发射对角射线穿过灰框角，实心对象被擦除。

**输入结构**：约 20x20 的网格，背景为黑(0)。网格中有一个灰(5) 的单像素厚正交矩形框（hollow_frame），以及 3~5 个非黑、非灰的单色 4-连通前景对象（每个对象颜色互不相同，从红(2)、绿(3)、黄(4)、橙(7)、青(8) 中选取）。部分对象是"空心的"——即其像素完全包围了一块或多块黑(0) 内部区域（封闭空洞），空洞大小不定但至少 1 个像素；其余对象为"实心的"——4-连通区域内无被完全包围的黑像素。所有对象的边界框互不重叠，且与灰框不重叠。生成约束：至少有 1 个空心对象和 1 个实心对象；每个空心对象的边界框至少有一个角与灰框的某个角位于同一条对角线上（即从该角沿 45 度方向追踪能到达灰框的某个角），且灰框角与对象角之间的对角线上无其他非背景像素。

**规则**：
1. 对每个非灰前景对象，检测其是否为空心：将其像素视为屏障，检查被完全包围的黑(0) 4-连通区域是否存在。存在则标记为"空心"，否则为"实心"。
2. 擦除所有实心对象：将其像素全部设为黑(0)。
3. 对每个空心对象，取其边界框的四个外角 (top-left, top-right, bottom-left, bottom-right)。
4. 从每个外角出发，沿向外的对角方向逐像素追踪。"向外"定义：top-left 角向左上 (-1,-1)，top-right 角向右上 (-1,+1)，bottom-left 角向左下 (+1,-1)，bottom-right 角向右下 (+1,+1)。
5. 若追踪到的第一个非黑像素恰好是灰框的一个角像素，则该方向"激活"：继续沿同一对角方向前进，将经过的每个黑(0) 像素涂为该空心对象的颜色，直到超出网格边界。灰框角像素本身不改变颜色。
6. 若追踪到的第一个非黑像素不是灰框角，或射线在到达灰框角之前超出网格边界，则该方向不激活，不做任何绘制。
7. 空心对象本身（含其空洞）保持不变。灰框保持不变。

**关键洞察**：实心对象看起来和空心对象一样是前景要素，但它们是需要被识别并移除的干扰项——决定因素是纯拓扑性质（是否封闭了内部区域），而非颜色、大小或位置。

## 新题 3：干扰项去除后边缘链序决定叠加深度

**组合逻辑**：[裁剪/crop + 忽略干扰项/ignore_distractors](每面板保留最大分量) → [重排序/reorder + 链式连接排序/chaining_by_edge_contact](按边缘像素匹配建立链) → [叠加/overlay](链序即 z-序深度叠加到共享画布)

**来源原语**：裁剪、面板、按面积筛选、保留最大分量、忽略干扰项（来自 337b420f）；重排序、精灵体、分隔线、边缘像素匹配、链式连接排序（来自 78332cb0）；叠加/overlay（来自 337b420f）

**依赖链**：干扰项去除是链排序的前提——小分量可能在边缘产生假匹配，导致错误的链序；而链序又决定叠加的遮挡优先级（后序覆盖先序），形成三步不可跳过的推理链：去噪 → 排序 → 合成。

从分面板中各取最大前景分量，按边缘像素匹配链接排序，链序即 z-深度叠加到一个共享画布上。

**输入结构**：约 5x29 的网格（5 行高、29 列宽），由四个 5x5 面板组成，面板之间以单列黑(0) 分隔。所有面板共享同一背景色灰(5)。每个面板包含恰好一种非背景前景色（四个面板分别使用红(2)、绿(3)、蓝(1)、橙(7)，各面板颜色互不相同），且该前景色被分为恰好两个 4-连通分量：一个较大（4~8 像素），一个较小（1~2 像素，即干扰项）。较大分量的形状为不规则连通图形；较小分量为与较大分量不相邻的孤立像素或双像素。生成约束：去除干扰项后，四个大分量可按边缘像素匹配建立唯一的完整水平链——即存在唯一排列使得相邻两块的对接边（前一块右边缘 vs 后一块左边缘）在相同行偏移处均有前景像素；若保留干扰项则存在至少一处假匹配使链序不唯一。四个大分量在 5x5 画布上叠加时至少有一对存在像素重叠。

**规则**：
1. 将输入沿黑(0) 分隔列切分为四个 5x5 面板。
2. 在每个面板中，找到该面板前景色的所有 4-连通分量，保留像素数最多的分量，擦除其余分量（将干扰项像素设为灰(5) 背景）。
3. 对四个保留的大分量，建立水平边缘匹配关系：分量 A 可接在分量 B 左侧，当且仅当 A 在其 5x5 格内的最右列（第 4 列）的前景像素行坐标集合与 B 在其 5x5 格内的最左列（第 0 列）的前景像素行坐标集合存在非空交集。
4. 从无左前驱的分量开始，沿匹配关系建立唯一链序（生成保证唯一）。
5. 创建一个 5x5 的灰(5) 背景输出画布。按链序从先到后依次将分量绘制到画布上：每个分量保持其在原面板中的行列坐标，后绘制的像素覆盖先绘制的像素（包括覆盖背景和覆盖先前分量的颜色）。

**关键洞察**：干扰项的去除不是可选的预处理——它直接影响链序正确性。若不先去噪，边缘匹配会因小分量制造出多余的匹配候选，导致链序歧义或错误，从而叠加出错误的遮挡结果。

## 新题 4：字形解码颜色受表格位置调制

**组合逻辑**：[填充/fill + 重涂色/recolor](按字形解码颜色填充单元格) x [擦除/erase](按表格位置决定字形是否保留) —— 两套规则交叉作用于同一网格

**来源原语**：填充、分隔线网格、网格单元格、表格行列位、角落与内部分色（来自 e9c9d9a1）；重涂色、擦除、标记字形、形状编码颜色、按形状映射颜色（来自 009d5c81）

**依赖链**：字形的形状解码产生颜色值，表格位置产生处理类别（角落/内部/边缘），两者交叉决定三种不同的输出行为——不是"先解码再分位"的线性流程，而是同一个单元格的最终状态由两个独立维度（形状 x 位置）的笛卡尔积联合决定。

每个表格单元格含一个字形，字形形状解码为颜色；角落单元格用该颜色填充并移除字形，内部单元格用该颜色填充但保留字形（反色显示），边缘单元格不填充且移除字形。

**输入结构**：约 15x15 的网格，背景为黑(0)。绿(3) 像素构成完整的水平和垂直分隔线，将画布均匀分割为至少 4x4 的单元格阵列（每个单元格内部约 3x3）。每个单元格的 3x3 内部区域中央放置一个灰(5) 的小字形（3x3 以内的连通图案，像素数 3~5），字形背景为黑(0)。字形有若干种形状类别（由训练示例归纳），每种形状对应一个唯一的目标颜色：例如"十字形"(中心+上下左右共 5 像素) 对应红(2)，"下横杠"(底行 3 像素) 对应蓝(1)，"左竖杠"(左列 3 像素) 对应橙(7)，"对角线"(主对角线 3 像素) 对应黄(4)。具体映射需通过对比多个训练示例才能确定（单个示例无法覆盖所有形状类别）。生成约束：每种字形形状在整个网格中至少出现两次且分布在不同的位置类别（角落/内部/边缘）中，以便求解者通过对比推断映射规则。

**规则**：
1. 保留所有绿(3) 分隔线不变。
2. 确定每个单元格在表格中的位置类别：若同时处于首行/末行带且首列/末列带，则为"角落"；若既不在首行/末行带也不在首列/末列带，则为"内部"；其余为"边缘"。
3. 对每个单元格，识别其灰(5) 字形的形状，根据形状-颜色映射表解码出目标颜色 C。
4. 角落单元格：将整个 3x3 内部区域填充为颜色 C（字形像素和黑像素均变为 C，字形被淹没消失）。
5. 内部单元格：将 3x3 内部区域中原本为黑(0) 的像素填充为颜色 C，同时将字形像素从灰(5) 重涂为黑(0)（字形以黑色显示在彩色背景上，形成反色效果）。
6. 边缘单元格：将字形像素擦除为黑(0)，内部区域保持全黑（不填充任何颜色）。

**关键洞察**：形状-颜色映射对所有单元格是全局统一的，但三种位置类别导致同一解码结果产生截然不同的视觉输出——角落看不到字形（被颜色淹没），内部能看到反色字形，边缘什么都看不到。求解者必须同时推断两套独立规则（形状映射 + 位置规则）并理解它们如何交叉。

## 新题 5：重力累积构建印章模板

**组合逻辑**：[滑动/sliding + 碰撞阻挡/collision_blocking](彩色像素向灰体滑动累积，保留原色) → [印章覆盖/stamp_overlay + 尺寸匹配/size_matching](累积体作为模板印章到目标矩形)

**来源原语**：滑动、前景对象、吸附体、碰撞阻挡、邻接、最短基方向吸附、累积影响后续停靠（来自 4093f84a）；印章覆盖、多色模板、纯色矩形、尺寸匹配、同尺寸替换（来自 e76a88a6）

**依赖链**：滑动累积的物理过程构建出一个多色模板——这个模板在输入中不以完整形态存在，必须通过模拟重力过程才能获得；随后该模板被用作印章覆盖目标矩形。如果跳过滑动直接尝试印章，则无法确定模板内容；如果只做滑动不做印章，则无法解释目标矩形的存在。

散布的彩色像素向灰色核心滑动累积成多色模板，该模板被印章覆盖到网格其他位置的同尺寸灰色矩形上。

**输入结构**：约 16x16 的网格，背景为黑(0)。网格分为上下两个区域（无显式分隔线，由空间位置区分）。上半区包含：一个灰(5) 的小实心矩形（约 3x4 或 4x3），以及散布在其四周的若干单像素彩色点（颜色从红(2)、绿(3)、蓝(1)、黄(4)、橙(7) 中选取，可重复），彩色点与灰矩形之间可能隔着若干黑像素。下半区包含：1~2 个灰(5) 实心矩形，每个矩形的尺寸与"灰核心 + 所有彩色点累积后的边界框"完全相同。生成约束：每个彩色点沿其最短基方向（上/下/左/右中距灰体最近的那个方向）滑动时，路径上无其他非黑像素阻挡（但先滑动的像素落位后会影响后续像素的停靠位置）；所有像素累积完成后，结果的边界框恰好等于下半区灰矩形的尺寸；滑动顺序为按距灰体的曼哈顿距离从小到大处理（距离相同时按从上到下、从左到右的扫描序）。

**规则**：
1. 识别上半区的灰(5) 矩形为"核心"，以及所有非黑、非灰的单像素点为"浮动像素"。
2. 按浮动像素到核心的曼哈顿距离从小到大排序（距离相同时按行优先、列次优先的扫描序）。
3. 依次处理每个浮动像素：确定其到当前累积体（初始为灰核心，后续包含已落位的像素）的最短基方向（上/下/左/右中曼哈顿距离最短的方向），沿该方向滑动直到下一步将与累积体碰撞，将像素放置在该位置并保留其原始颜色（不重涂为灰）。该像素成为累积体的一部分，影响后续像素的碰撞判定。
4. 所有浮动像素处理完毕后，取累积体的边界框区域作为"模板"。
5. 将模板精确复制到下半区每个灰(5) 矩形的位置：模板中的每个像素颜色覆盖灰矩形对应位置的灰(5)。
6. 上半区的灰核心和浮动像素原始位置全部擦除为黑(0)（上半区变为纯黑背景）。

**关键洞察**：模板不是直接给出的，而是通过重力模拟"组装"出来的——像素的落位顺序和方向共同决定模板的最终图案。改变任何一个像素的位置都会改变滑动路径和累积形态，从而改变所有目标矩形的印章结果。

## 新题 6：对象计数编码缩放因子驱动对称补全

**组合逻辑**：[计数/counting](小对象数量 = 缩放因子 k) → [像素放大/pixel_upscale](将半成品对象按 k 倍放大) → [对称补全/symmetric_completion](在放大后的网格上沿轴镜像补全)

**来源原语**：计数、连通分量、面积筛选（来自 f8b3ba0a / a3325580）；像素放大、均匀倍率缩放（来自 c59eb873）；对称补全、对称轴、控制标记、控制标记指示源侧、轴对称反射（来自 5b692c0f）

**依赖链**：对象数量编码了缩放因子，缩放改变了对称轴的绝对位置和模式的像素粒度——对称补全必须在放大后执行，因为放大前的轴坐标无法正确对应放大后的像素边界。三步形成严格的因果链：计数→放大→补全，任一步缺失都无法得到正确结果。

统计散布小对象的数量作为缩放因子，将半成品图案像素放大后沿黄色轴镜像补全。

**输入结构**：约 12x18 的网格，背景为黑(0)。网格分为左右两个空间区域（由黑背景自然分隔，无显式分隔线）。左侧区域包含 2~4 个互不相邻的单色小对象（4-连通，每个 2~4 像素，颜色均为品红(6)），它们的唯一作用是被计数。右侧区域包含一个较大的不完整图案，该图案由两种颜色构成：一种非黑非品红的主体颜色（如蓝(1) 或红(2)），以及黄(4) 像素。黄(4) 像素中有一条连续的水平或垂直直线段充当对称轴，另有 1 个离轴的黄(4) 像素作为控制标记（指示轴的哪一侧是可信源侧）。可信源侧包含主体颜色的完整半图案，另一侧主体颜色残缺或为空。该图案的边界框约 4x4 至 6x6。生成约束：左侧品红对象的数量 k 为 2 或 3；右侧图案设计时考虑了 k 倍放大后对称补全能产生完整的、视觉上有意义的结果；放大后图案的边界框不超出网格范围。

**规则**：
1. 计数左侧区域中品红(6) 的 4-连通分量数量，记为 k。
2. 将右侧图案（包含主体色和黄(4) 像素）的边界框区域进行 k 倍像素放大：每个像素变为 k x k 的同色块。放大后的图案放置在输出网格中，左上角与原边界框左上角对齐（输出网格尺寸相应扩大）。
3. 在放大后的图案中，识别黄(4) 的连续水平或垂直直线段为对称轴，识别离轴黄(4) 像素块（放大后变为 k x k 块）为控制标记。控制标记所在侧为可信源侧。
4. 将可信源侧的整个矩形半区（从轴到边界框边缘）的所有像素镜像反射到另一侧，逐像素覆盖（包括黑背景像素也被复制过去）。轴本身的黄像素保持不变。
5. 擦除左侧区域的所有品红(6) 对象（设为黑(0)）。

**关键洞察**：如果先尝试补全再放大，轴的镜像位置会出错（因为放大改变了轴到边缘的像素距离）；如果不计数就直接放大，无法确定倍率。三步的顺序是唯一正确的执行路径，且顺序本身需要从示例中归纳。

## 新题 7：包含层级深度驱动角落三角堆叠

**组合逻辑**：[计数/counting + 包含/containment](构建嵌套层级并计算深度) → [填充/fill + 擦除/erase](按深度绘制同心角三角并擦除原始对象)

**来源原语**：填充、角落控制点、三角区域、计数决定尺寸、最大分量保留（来自 902510d5）；包含、封闭区域、有空洞则重涂（来自 810b9b61）；计数、连通分量（来自 e872b94a / a3325580）；擦除（来自 009d5c81）

**依赖链**：包含关系的拓扑分析产生嵌套深度值，深度值直接决定三角的边长和颜色分层——二维空间中的包含嵌套被线性化为一维的深度序列，再映射为角落处同心三角的几何堆叠。包含分析与三角绘制之间有不可跳过的"拓扑→数值→几何"变换链。

分析嵌套封闭区域的包含层级，每层深度对应一个角落三角的同心层，最终在标记角绘制彩色同心三角堆叠。

**输入结构**：约 16x16 的网格，背景为黑(0)。网格中有若干个不同颜色的封闭环形对象（4-连通像素构成闭合边界，内部包围黑(0) 区域），这些环形对象按层嵌套——最外层环完全包围次外层环，次外层又包围更内层，形成 2~4 层的嵌套结构。每层环的颜色互不相同（从红(2)、蓝(1)、绿(3)、橙(7)、青(8) 中选取）。环的形状为不规则闭合曲线（非矩形，像素数 8~20，宽度 1 像素），嵌套层之间保持至少 1 像素的黑间距。网格的一个角落（如右下角）放置一个栗(9) 的单像素标记，该标记不在任何环内部。生成约束：嵌套层级唯一确定（不存在同级的并列环）；最大嵌套深度 d 不超过 4；标记所在角落到网格边缘有足够空间绘制 d 层同心三角（三角最大边长 = d）。

**规则**：
1. 识别所有非黑、非栗的前景像素，按颜色和 4-连通性聚类为独立对象。
2. 构建包含层级：对象 A "包含" 对象 B 当且仅当 B 的所有像素都位于 A 的封闭内部区域中。找到直接包含关系（A 直接包含 B 意味着不存在 C 使得 A 包含 C 且 C 包含 B）。
3. 为每个对象计算嵌套深度：最外层（不被任何其他对象包含的）深度为 1，被深度 n 的对象直接包含的对象深度为 n+1。记最大深度为 d。
4. 确定栗(9) 标记所在的角落方位（左上/右上/左下/右下）。
5. 在该角落绘制 d 层同心直角三角形：最外层三角形的两条直角边各长 d 像素，紧贴角落的两条网格边缘；第 i 层（i=1 为最外层）三角形的直角边长为 d - i + 1，其直角顶点与角落重合。绘制规则：像素 (r, c) 属于第 i 层三角形当且仅当该像素到角落两条边缘的距离之和 < d - i + 1 且 >= d - i（即恰好构成一个环形三角带），其中距离从 0 计起。
6. 第 i 层三角形的颜色 = 嵌套深度为 i 的对象的颜色。
7. 擦除所有原始封闭环形对象和栗(9) 标记（将其像素设为黑(0)）。

**关键洞察**：嵌套关系是纯拓扑的（哪个环在哪个环里面），与环的大小、形状、位置无关——两个训练示例中环的形状和位置可以完全不同，但只要嵌套层级相同，角落三角的输出就相同。求解者必须识别出"空间包含→线性深度→角落几何"这一抽象映射。

## 新题 8：背景区域计数决定图案复制缩放

**组合逻辑**：[计数/counting](屏障分割出的背景区域数 = 缩放因子) + [图案复制/pattern_replication + 旋转/rotation](源角图案按缩放因子放大后复制到目标角) + [擦除/erase](屏障在输出中被移除)

**来源原语**：计数、背景区域、前景屏障、区域数编码像素列（来自 e872b94a，创新为区域数编码缩放因子）；图案复制、旋转、空心矩形、角落标记、源角到目标角映射、各角独立着色（来自 4c416de3）；擦除（来自 8f3a5a89）

**依赖链**：蓝屏障同时扮演两个角色——它们分割背景产生区域计数值，而这个计数值又作为图案复制的缩放因子。屏障既是"信息编码器"（编码缩放参数），又是将在最终输出中被擦除的临时结构。图案复制依赖计数结果，计数依赖屏障识别，而屏障在完成使命后消失。

框内蓝色屏障分割出的背景区域数量即为图案复制的缩放因子，源角图案按该倍率放大并旋转复制到其他标记角，屏障随后被擦除。

**输入结构**：约 18x18 的网格，背景为黑(0)。一个灰(5) 的单像素厚空心正交矩形框占据网格中央大部分区域。框的四个角像素中：一个角已绘制了完整的角图案（即从该角的灰像素向框外延伸的一组同色像素，形成约 2x2 至 3x3 的 L 形或阶梯形图案，颜色为该角的专属色如红(2)）；其余 1~3 个角各有一个单像素的彩色标记（每个标记颜色不同，从绿(3)、黄(4)、橙(7)、青(8) 中选取），位于该角的内对角线方向第 1 格（即框角的斜内侧）。框的内部区域中，有蓝(1) 的屏障线段（水平或垂直，宽 1 像素），将框内的黑背景分割为若干个 4-连通区域。生成约束：蓝屏障将框内背景分割为恰好 2 或 3 个 4-连通背景区域（该数量即为缩放因子 k）；源角图案的形状在 k 倍放大后仍能适配目标角的可用空间（不超出网格边界）；源角图案关于其角的内对角线轴对称。

**规则**：
1. 识别灰(5) 框、蓝(1) 屏障、以及框四角的状态（哪个角有完整图案=源角，哪些角有单像素标记=目标角）。
2. 计算框内部（不含框边像素）被蓝(1) 屏障分割出的黑(0) 4-连通背景区域数量，记为 k。
3. 提取源角图案：取源角的灰框角像素为原点，收集从该原点向框外对角方向延伸的所有同色非背景非灰像素，将其坐标转换为相对于角原点的偏移量，得到标准化的角图案模板 P。
4. 对模板 P 进行 k 倍像素放大：每个像素偏移 (dr, dc) 扩展为 k x k 块，覆盖偏移 (dr*k .. dr*k+k-1, dc*k .. dc*k+k-1)。
5. 对每个目标角：将放大后的模板旋转到该角的方位（左上角不旋转，右上角水平翻转，左下角垂直翻转，右下角旋转 180 度），使用该角标记像素的颜色替换模板颜色，以该角的灰框角像素为原点绘制到网格上。超出网格边界的部分舍弃。
6. 擦除框内部所有蓝(1) 屏障像素（设为黑(0)）。
7. 擦除所有目标角的单像素标记（设为黑(0)）。
8. 灰框和源角的原始图案保持不变。

**关键洞察**：蓝屏障是一次性使用的参数编码器——它通过分割空间来"表达"一个数值（区域数），这个数值控制了图案复制的尺寸，但屏障本身在输出中完全消失。求解者必须发现屏障的信息编码功能而非将其视为持久的空间结构。
