## 新题 1：孔洞计数参数化旋转角度的印章放置

**组合逻辑**：[计数](创新：孔洞数不用于筛选异常值，而是参数化旋转角度) + [旋转](创新：从固定 90° 改为由孔洞数决定的可变角度) + [印章放置](保留颜色匹配定位)

**来源原语**：计数/counting ← de1cd16c, 358ba94e；旋转/rotate ← c074846d；印章放置/stamp ← a251c730；背景孔洞/background_hole ← 358ba94e；锚点标记/anchor_marker ← a251c730；颜色匹配/color_matching ← a251c730；边框矩形/bordered_rectangle ← a251c730

**依赖链**：每个精灵的背景孔洞数量参数化该精灵的顺时针旋转次数，旋转后的精灵通过颜色匹配定位并印入目标框架。孔洞计数不是筛选异常值（如 358ba94e），而是作为旋转操作的参数；旋转角度不是固定的（如 c074846d 的 90°），而是由孔洞数动态决定。同时，印章的空间定位依赖颜色匹配（来自 a251c730），但印章的内容依赖旋转结果——两条独立信息流在印章操作处汇合。

数每个精灵的孔洞数来决定旋转几个 90°，再按颜色匹配把旋转后的精灵印入目标框架。

**输入结构**：
- 黑(0)背景网格，约 18x18。
- 网格右半区有一个灰(5)边框矩形（边框一像素厚，内部为黑(0)），内部尺寸约 10x10。
- 框架内部散布 3 个单像素锚点标记，颜色分别为红(2)、蓝(1)、绿(3)，彼此间距至少 5 像素。
- 网格左半区有 3 个小型单色精灵（各为 4-连通的单色像素集合，3~6 像素，紧边界框约 3x3），颜色分别为红(2)、蓝(1)、绿(3)，彼此不相邻（紧边界框间距至少 2 像素）。
- 每个精灵内部有不同数量的背景孔洞（紧边界框内被精灵像素完全 4-连通包围的黑(0)像素区域）：一个有 0 个孔洞，一个有 1 个孔洞，一个有 2 个孔洞。不同示例中三种孔洞数分配给不同颜色的精灵。
- 生成约束：每个精灵在任何旋转角度下以其匹配锚点为中心放置时均不超出框架内部边界。不同精灵放置区域可以重叠。

**规则**：
1. 对每个精灵，计算其紧边界框内被精灵像素完全 4-连通包围的黑(0)像素数量，记为 h。
2. 将该精灵的紧边界框裁剪（含背景），绕其边界框中心顺时针旋转 h 个 90°（h=0 不旋转，h=1 旋转 90°，h=2 旋转 180°）。
3. 在目标框架中找到与该精灵同色的唯一锚点标记。
4. 将旋转后的精灵裁剪平移，使其边界框中心对齐锚点位置，写入框架内部。只写入精灵像素（非黑(0)像素），黑(0)位置不覆盖已有内容。
5. 精灵按其在左半区的位置从上到下依次处理；后处理的精灵像素覆盖先处理的精灵像素（若重叠）。
6. 框架边框保持灰(5)，左半区的原始精灵保持不变，框架外背景保持黑(0)。

**关键洞察**：孔洞不是用来筛选异常值，而是编码了每个精灵所需的旋转角度——数量属性直接参数化几何变换，且哪种颜色对应几个孔洞在不同示例中不同，必须对比多个示例才能确认"孔洞数=旋转次数"这一规则。

## 新题 2：对称性测试逻辑选择递归展开种子

**组合逻辑**：[对称检测](保留左右镜像判定) → [裁剪](提取非对称精灵为种子) → [递归展开](创新：种子由对称性逻辑选出而非空间位置指定)

**来源原语**：对称检测/symmetry_detect ← 73ccf9c2；裁剪/crop ← 73ccf9c2；递归展开/recursive_expand ← 58c02a16；前景对象/foreground_object ← 73ccf9c2；种子掩码/seed_mask ← 58c02a16；边界图例/border_legend ← 58c02a16；唯一非轴对称/unique_asymmetric ← 73ccf9c2；自相似替换/self_similar_sub ← 58c02a16；前景背景分别替换/fg_bg_separate ← 58c02a16

**依赖链**：对称检测在多个候选精灵中找到唯一非左右对称者，该精灵的紧边界框掩码成为递归展开的种子，递归展开使用边界图例提供的第二颜色将种子的前景/背景像素分别替换为主色/次色种子副本。在 73ccf9c2 中非对称精灵仅被裁剪输出，在 58c02a16 中种子由空间位置（左上角）固定指定——这里两者通过"逻辑选择种子"这一新结构关系耦合，改变哪个精灵不对称就改变整个递归图案。

在多个候选精灵中找到唯一不具左右对称性的，以其掩码为种子进行递归自相似展开。

**输入结构**：
- 黑(0)背景网格，约 20x20。
- 网格上半区散布 4 个绿(3)的 8-连通小精灵（每个 4~8 像素），彼此不相邻（紧边界框不重叠且间距至少 2 像素）。其中 3 个精灵在其紧边界框内具有左右镜像对称性，恰好 1 个不具有。所有精灵的紧边界框尺寸相同（均为 3x3）。不同示例中，不对称精灵的位置和具体形状均不同。
- 网格下半区左侧有一个蓝(1)的实心 L 形边界图例：一条水平线（宽度 = 种子边界框宽度 + 1 = 4 像素）和一条垂直线（高度 = 种子边界框高度 + 1 = 4 像素），共享一个角像素，形成直角。
- 生成约束：L 形图例与上半区精灵不重叠。展开后的 9x9 矩阵可容纳于网格中。

**规则**：
1. 将上半区绿(3)像素按 8-连通分组为独立精灵，取每个精灵的紧边界框裁剪（背景为黑(0)）。
2. 对每个 3x3 裁剪结果，检查其绿(3)像素掩码是否左右镜像对称（将掩码水平翻转，与原始比较）。选出唯一不对称的精灵裁剪作为种子掩码 S。
3. 读取 L 形图例确认次色为蓝(1)。
4. 对种子掩码 S 执行一级递归展开：S 中每个绿(3)像素替换为一份 3x3 的绿(3)种子副本（保持 S 的图案），S 中每个黑(0)像素替换为一份 3x3 的蓝(1)种子副本（S 的图案用蓝(1)绘制）。得到 9x9 的展开矩阵。
5. 输出该 9x9 展开矩阵。上半区精灵和图例不出现在输出中。

**关键洞察**：种子不是由位置指定而是由对称性测试从多个候选者中逻辑选出——不同示例中不对称精灵形状不同，导致展开图案完全不同，必须先正确执行对称判定才能得到正确的种子。

## 新题 3：长度排名同时决定重涂颜色与射线循环相位

**组合逻辑**：[排序](保留长度排名) ⟹ 扇出至 [重涂色](保留排名映射颜色) 和 [射线延伸 + 周期推断](创新：排名参数化循环起始相位)

**来源原语**：排序/sorting ← ea32f347；射线延伸/ray_extend ← fe9372f3, d037b0a7；重涂色/recolor ← ea32f347；细条/thin_bar ← ea32f347；长度排名/length_ranking ← ea32f347；排名决定颜色/rank_determines_color ← ea32f347；基数方向循环填/cardinal_cyclic_fill ← fe9372f3；网格边缘/grid_edge ← fe9372f3

**依赖链**：比较三条细条的长度得到排名，排名同时决定两件事：(a) 每条细条的重涂颜色，(b) 从每条细条端点发出的射线的颜色循环起始相位。排名是同时影响两个不同操作的共享决策节点，不是线性流水线。在 ea32f347 中排名仅决定颜色；在 fe9372f3 中循环从固定中心出发且相位固定。这里排名同时参数化颜色和相位是源题中不存在的结构关系。

按长度给三条灰条排名，排名决定重涂颜色，同时决定从端点发出的循环色射线的起始相位。

**输入结构**：
- 黑(0)背景网格，约 15x20（15 列 20 行）。
- 3 条灰(5)水平细条（各一像素厚），位于不同行，长度互不相同（如分别为 3、5、7 像素）。
- 每条细条的右端紧邻位置（右端 + 1 列）有一个红(2)像素作为端点标记。红像素不属于灰条本身。
- 生成约束：红像素下方到网格底部的距离至少 6 像素，保证射线有足够长度展示循环。三条细条的行间距至少 3 行。三条细条均不位于网格最底 2 行。

**规则**：
1. 测量每条灰(5)条的长度（像素数），得出排名：最短为第 1 名，中等为第 2 名，最长为第 3 名。
2. 重涂每条灰条：第 1 名（最短） → 红(2)，第 2 名 → 黄(4)，第 3 名（最长） → 蓝(1)。
3. 从每条细条的红(2)端点标记处正下方一格开始，向下发出一条垂直射线直至网格底部边缘（含底部像素）。
4. 射线使用三色循环：蓝(1)、黄(4)、绿(3)，逐像素重复。起始相位由该条细条的排名决定：第 1 名从索引 0 开始（即蓝、黄、绿、蓝、...），第 2 名从索引 1 开始（即黄、绿、蓝、黄、...），第 3 名从索引 2 开始（即绿、蓝、黄、绿、...）。
5. 红端点标记本身保持红(2)不变。
6. 保留所有其他背景像素。

**关键洞察**：排名不仅是颜色映射的键（与 ea32f347 相同的部分），还同时作为循环相位偏移量——同一个排名结果扇出到两个不同操作，形成非线性依赖图。需要对比多个示例才能同时确认"排名→颜色"和"排名→相位"两条映射规则。

## 新题 4：标记像素逐框投票决定封闭区域填充色

**组合逻辑**：[计数/投票](创新：从全局单输出改为逐框独立投票) + [填充](创新：从向下列填改为区域洪泛填) + [标记归属区域](创新：标记归属于空心框封闭区域而非实色区域)

**来源原语**：计数/counting、投票/vote ← de1cd16c；填充/fill ← d037b0a7；标记像素/marker_pixel ← de1cd16c；空心矩形/hollow_rectangle ← 445eab21；封闭区域/enclosed_region ← 445eab21；标记归属区域/marker_in_region ← de1cd16c；最多标记区胜出/max_marker_wins ← de1cd16c

**依赖链**：每个标记像素通过其位置归属于某个空心框的内部，逐框统计两种标记颜色的数量，多数色洪泛填充该框内部，不同框可能被填充不同颜色。在 de1cd16c 中投票产生全局 1x1 输出；在 445eab21 中框按面积比较但不涉及标记。这里投票是逐框独立进行的，且投票结果驱动空间填充而非 1x1 输出，形成"归属判定 + 分布式投票 + 局部填充"的组合结构。

两种颜色的标记像素散布在多个空心矩形框内部，每个框内按标记的多数颜色填充其封闭区域。

**输入结构**：
- 黑(0)背景网格，约 18x18。
- 3 个空心矩形框，每个由不同颜色构成：红(2)、蓝(1)、绿(3)，各一像素厚边框，内部为黑(0)。框的尺寸不同（内部面积分别约为 4x4、5x3、3x6 像素），彼此不重叠且间距至少 2 像素。
- 框内部散布若干单像素标记，颜色仅为黄(4)或橙(7)。每个框内至少有 1 个标记。标记不在框边界上，严格位于框内部的黑(0)区域。
- 生成约束：每个含标记的框内黄(4)与橙(7)的数量不相等（保证投票无平局）。不同示例中各框内的多数色可能不同（如示例 1 中红框内黄多、蓝框内橙多；示例 2 中反过来）。

**规则**：
1. 对每个空心矩形框，确定其内部区域（严格在边框之内的所有像素位置）。
2. 将内部区域中的标记像素按颜色分组：黄(4)一组，橙(7)一组。
3. 选出数量较多的颜色，将该框内所有黑(0)像素填充为该颜色。标记像素本身保持原色不变。
4. 框边框颜色不变。框外背景不变。
5. 若某个框内部无标记像素，则该框内部保持黑(0)不变。
6. 各框独立处理，互不影响。处理顺序不影响结果（因为框不重叠）。

**关键洞察**：投票不是全局汇总为单一输出，而是逐框独立执行——不同框可因各自的标记分布而被填充不同颜色，使得同一条投票规则在空间上产生分化结果。仅看单个示例中的一个框无法排除"总是填黄色"等简单假设，必须对比多个框和多个示例才能归纳出投票机制。

## 新题 5：压缩揭示隐藏象限结构后镜像补全

**组合逻辑**：[压缩/去重](保留行列去重) → [对称补全](创新：在压缩后的紧凑矩阵上执行，压缩是揭示对称结构的前置步骤) + [三存一缺推断](保留对角镜像)

**来源原语**：压缩/compress、去重/deduplicate ← e1baa8a4；对称补全/symmetry_completion ← 2546ccf6；相邻重复/adjacent_repeat ← e1baa8a4；合并相同行列/merge_identical_row_col ← e1baa8a4；块内对称/symmetry_within_block ← 2546ccf6；三存一缺推断/infer_missing_from_three ← 2546ccf6；镜像/mirror ← 2546ccf6

**依赖链**：输入网格是一个被行列拉伸的矩阵，压缩去重后得到紧凑矩阵，紧凑矩阵呈 2x2 象限结构（三个象限有图案、一个为纯填充色），通过对角象限的双轴镜像推断缺失象限内容。在 e1baa8a4 中压缩就是最终答案；在 2546ccf6 中格子结构直接可见。这里压缩是前置操作——移除它则行列重复打散了象限之间的镜像关系，对称结构不可见，补全无法执行。

先压缩去除重复行列揭示隐藏的 2x2 象限结构，再通过镜像补全缺失的象限。

**输入结构**：
- 一个全填充的彩色网格（无黑(0)背景），约 12x12。网格中不存在黑(0)像素。

- 一个绿(3)实心矩形（约 3x4 像素），位于网格中部偏上。

7. 其余标记各自沿对齐方向滑动到距目标区域边界外侧 1 像素处停下。
8. 若多个标记距离相同且均为最短，按行号从小到大、行号相同按列号从小到大的顺序选出唯一进入者。

**关键洞察**：延伸操作不仅是视觉上的填充——它改变了目标区域的几何形状，导致某些标记被吸收、剩余标记的距离关系被重构，使得延伸方向的选择对最终滑动结果产生非平凡的连锁影响。

4. 从 (R, C) 向下逐格传播：
   - 第 1 步，(R+1, C) 格元：清除该格元原有绿(3)像素，写入 P 的垂直翻转（上下翻转）版本，颜色仍为绿(3)。
   - 第 2 步，(R+2, C) 格元（若存在）：清除原有内容，写入 P 的原始版本。
   - 以此交替：奇数步写入翻转版，偶数步写入原始版。
5. (R, C) 格元本身保持不变（保留原始不对称精灵）。
6. 列 C 中行号 < R 的格元保持不变。
7. 列 C 以外的所有格元保持不变。分割线保持灰(5)。背景保持黑(0)。

**关键洞察**：非对称性不仅是选择标志，还决定了传播内容的信息量——正因为精灵不对称，其垂直翻转版本才与原始不同，使得交替翻转传播产生可辨识的变化模式；若精灵对称则翻转等于原始，传播链退化为简单复制，交替规则不可观测。因此对称检测既选出了源头，又保证了传播变换的可观测性。
