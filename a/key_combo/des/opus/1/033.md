## 新题 1：错切周期修补

**组合逻辑**：[错切/shear]（创新：从可见对角边缘反推行偏移量） + [补全/complete]（创新：在错切坐标系下利用周期性修补损坏像素） — 两者构成联立约束：偏移量决定周期对齐方式，周期对齐方式反过来验证偏移量

**来源原语**：错切/shear（3cd86f4f）、行偏移递变/row_offset_progress（3cd86f4f）、周期平铺图案/periodic_tile（abbfd121）、被遮挡/occluded（abbfd121）、标记像素/marker_pixel（8886d717）

**依赖链**：要修补损坏像素，必须知道该位置在原始周期图案中的坐标；要推算原始坐标，必须知道该行的错切偏移量；而偏移量只能从可见像素的周期一致性反推——三者环形耦合

一句话总结：在一幅被逐行错切的周期图案上，将损坏标记像素还原为其在错切坐标系下对应的周期图案颜色。

**输入结构**：
- 网格约 12~18 行、15~22 列，背景为黑(0)。
- 网格中可见一个由 2~4 种非黑颜色组成的周期平铺图案，但该图案已被逐行错切：第 r 行（从 0 开始）相对于第 0 行向右平移了 r 个像素，右侧溢出部分裁剪，左侧空出部分为黑(0)。因此左侧呈现一条从左上到右下的黑色对角阶梯边缘。
- 图案的基本周期瓦片为一个 W_t x H_t 的小矩形（W_t, H_t 各在 2~4 之间），在行列方向上重复铺满（错切前的虚拟网格）。
- 在错切后的图案上，散布着若干品红(6)标记像素（3~8 个），它们替换了原本的图案颜色。标记像素不出现在黑色对角边缘区域内，只出现在可见图案区域中。
- 生成约束：基本周期瓦片中不含品红(6)；每个标记像素的周期轨道上至少存在一个未被标记的可见像素，保证修补信息充分。

**规则**：
1. 观察左侧对角阶梯边缘，推断错切规则：第 r 行向右偏移 r 列（即偏移量等于行号）。
2. 对每个非标记的可见像素 (r, c)，计算其在错切前虚拟网格中的列坐标 c' = c - r。利用所有可见像素的 (r, c') 值，推断最小周期瓦片的尺寸 W_t x H_t 及内容：像素颜色 = tile[r mod H_t][c' mod W_t]。
3. 对每个品红(6)标记像素 (r, c)，计算 c' = c - r，查表 tile[r mod H_t][c' mod W_t] 得到应恢复的颜色，将该像素替换为此颜色。
4. 黑色对角边缘区域和所有非标记可见像素保持不变。
5. 输出网格尺寸与输入相同。

**关键洞察**：错切使得周期图案的行列对齐关系被打乱，标记像素无法通过简单的行列取模直接对应到瓦片位置——必须先从对角边缘推断出逐行偏移量，才能将每个像素映射回周期坐标系进行修补。

## 新题 2：孔洞拓扑排名驱动晶格带重涂

**组合逻辑**：[计数/counting]（创新：计数对象不是像素面积而是拓扑孔洞） + [排序/sorting]（创新：排序依据为孔洞数而非高度） + [重涂色/recolor]（创新：重涂范围为晶格行列带，且多标记的带交叉需冲突消解）

**来源原语**：计数/counting（0a2355a6）、封闭区域/enclosed_region（0a2355a6）、按孔洞数映射颜色/hole_count_to_color_mapping（0a2355a6）、排序/sorting（08ed6ac7）、高度排名映射颜色/height_rank_to_color（08ed6ac7）、晶格网格/lattice_grid（4f537728）、标记块/marker_block（4f537728）、标记行列选择/marker_row_column_selection（4f537728）

**依赖链**：孔洞计数决定排名 → 排名决定分配给每个标记的颜色 → 标记位置决定哪些晶格带被选中 → 带交叉处需用排名优先规则消解冲突 → 而排名本身来自孔洞计数。删去计数则无法排名，删去排名则无法分配颜色，删去带选择则不知涂哪些像素，删去冲突规则则交叉处颜色不确定

一句话总结：在晶格中嵌入的多个标记各自包围不同数量的孔洞，按孔洞数排名分配颜色后重涂穿越各标记的晶格带，交叉处高排名优先。

**输入结构**：
- 网格约 15~20 行列，背景为黑(0)。
- 蓝(1)像素构成一个规则的正交晶格（等间距的水平线和垂直线交叉），晶格线宽为 1 像素，线间距为 2~4 像素。
- 晶格中嵌入 3~5 个标记，每个标记是一个由单一非蓝非黑颜色构成的 4-连通区域，占据晶格的一个或多个格子。每个标记的颜色互不相同（从红(2)、绿(3)、黄(4)、灰(5)、橙(7)中选取）。
- 每个标记区域的边界框内部包含若干个完全被标记像素包围的黑(0)孔洞（4-连通黑色区域，不与外部黑色背景连通）。不同标记的孔洞数量互不相同（范围 0~4）。
- 生成约束：任意两个标记的行范围和列范围不同时重叠（即不存在两个标记在同一行同一列都有像素，但它们各自的行带和列带可以交叉）。不同标记的孔洞数互不相等。

**规则**：
1. 对每个标记，计算其边界框内被标记像素完全包围的 4-连通黑(0)区域数量（即孔洞数）。
2. 按孔洞数从多到少排序，孔洞最多的排名为 1。将排名映射为输出颜色：排名 1 → 红(2)，排名 2 → 绿(3)，排名 3 → 黄(4)，排名 4 → 灰(5)，排名 5 → 橙(7)。
3. 对每个标记，找到其占据的所有行和所有列。将这些行和列中所有蓝(1)晶格像素重涂为该标记的排名颜色。
4. 若两个标记的行列带在某像素处交叉（同一像素属于两个标记的带），则该像素涂为排名更高（数字更小）的标记的排名颜色。
5. 标记自身的像素保持原色不变。黑(0)背景像素不变。不在任何标记带内的蓝(1)像素保持蓝色。

**关键洞察**：标记的拓扑属性（孔洞数）决定了一个全局排名，该排名同时控制颜色分配和空间冲突消解——两个看似独立的输出特征（颜色和优先级）实际共源于同一个拓扑度量。

## 新题 3：频率排名重定义循环填充顺序

**组合逻辑**：[计数/counting]（沿用：统计各色带前景像素数） + [排序/sort]（创新：排序结果不直接映射颜色，而是重定义色带之间的循环邻接关系） + [填充/fill]（创新：填充时借用的邻色由频率排名循环序决定，而非空间左右邻接）

**来源原语**：计数/counting（9af7a82c）、频率排序/frequency_ranking（9af7a82c）、竖向色带/vertical_band（c4d1a9ae）、循环相邻/cyclic_adjacent（c4d1a9ae）、空缺借邻色填充/gap_borrows_neighbor（c4d1a9ae）

**依赖链**：像素计数决定频率排名 → 频率排名定义循环邻接序 → 循环邻接序决定每条色带的缺口应借用哪种颜色填充。删去计数则不知顺序，删去循环规则则不知借哪个邻居的颜色，删去填充则无输出变化

一句话总结：统计各竖向色带的前景像素数，按数量降序建立循环序列，每条色带的背景缺口用该序列中下一条色带的颜色填充。

**输入结构**：
- 网格约 10~16 行、12~18 列，背景为黑(0)。
- 网格中有 3~5 条竖向色带，每条色带由一种独有颜色的前景像素和若干黑(0)背景缺口像素组成。每条色带占据连续的若干列（由该颜色的最小列到最大列定义），不同色带的列范围互不重叠。
- 每条色带内，前景像素数量互不相同（保证排名无并列）。色带在空间上从左到右的排列顺序与按前景像素数量降序排列的顺序不同（否则两种序等价，规则不可区分）。
- 色带颜色从蓝(1)、红(2)、绿(3)、黄(4)、灰(5)、品红(6)、橙(7)中选取。
- 生成约束：至少有一条色带的空间左邻和频率序左邻不同，以保证空间序和频率序确实产生不同的填充结果。

**规则**：
1. 对每条色带，统计其前景像素总数（不含缺口处的黑色像素）。
2. 按像素数从多到少排序，建立循环序列：最多 → 次多 → ... → 最少 → 回到最多。
3. 对每条色带，将其列范围内的黑(0)缺口像素填充为该循环序列中紧随其后的色带的颜色。即：若色带 A 在频率序中的下一个是色带 B，则 A 的缺口填充 B 的颜色。最少像素的色带的缺口填充最多像素色带的颜色（循环回绕）。
4. 所有原始前景像素保持不变。色带列范围之外的黑色背景像素不变。

**关键洞察**：空间上相邻的色带并不一定是填充规则中的"邻居"——真正的邻接关系由像素频率排名隐式定义，求解者必须先统计再排序才能确定借色来源，仅观察空间位置会得到错误答案。

## 新题 4：宏格D4对称补全与局部瓦片传播

**组合逻辑**：[平铺/tile]（创新：不是均匀复制单一瓦片，而是按宏格位置从对称伙伴格中复制） + [对称补全/symmetry_completion]（创新：对称不作用于像素级而是作用于宏格级，每个格子整体是一个"宏像素"）

**来源原语**：平铺/tile（c444b776）、网格分区/grid_partition（c444b776）、分隔线/separator_line（c444b776）、对称补全/symmetry_completion（47996f11）、对称轨道映射/symmetry_orbit_mapping（47996f11）、掩码像素/masked_pixel（47996f11）、已填瓦片填空槽/filled_tile_to_empty_slots（c444b776）

**依赖链**：分隔线定义宏格结构 → 宏格排列形成 D4 对称 → 空白宏格的内容由其对称伙伴宏格决定 → 含掩码像素的宏格需从对称伙伴的对应像素位置取值。删去分隔线分析则不知宏格边界，删去对称推断则不知空白格该填什么，删去像素级传播则含掩码格无法修复

一句话总结：用分隔线将网格切分为 N x N 宏格阵列，发现宏格阵列具有 D4 对称性，据此将完整宏格的内容传播到空白或含掩码的对称伙伴宏格中。

**输入结构**：
- 网格约 15~25 行列，背景为黑(0)。
- 灰(5)像素构成等间距的水平和垂直分隔线（线宽 1 像素），将网格内部切分为 N x N 个相同尺寸的矩形宏格（N 为 3 或 5，保证存在中心格和对称轴）。
- 宏格阵列在宏观层面具有 D4 对称性（关于中心格的水平、垂直、两条对角线翻转后，宏格内容对应相等——需对旋转/翻转后的宏格内容做相应的几何变换）。
- 部分宏格被完整填充了一个由 2~3 种非黑非灰颜色组成的图案。
- 部分宏格完全为黑(0)（空白）。
- 部分宏格大部分像素已填充，但含有若干品红(6)掩码像素（1~3 个），标记缺失位置。
- 生成约束：每个 D4 对称轨道（包含 1、2 或 4 个宏格位置）中至少有一个宏格是完整填充的（无品红、非空白），保证所有信息可恢复。中心格（若存在）可以是完整的、含掩码的或空白的，但其对称伙伴是自身，所以若含掩码，掩码位置必须能从同格内的 D4 像素级对称推断。

**规则**：
1. 识别灰(5)分隔线，将网格切分为 N x N 宏格阵列。记录每个宏格的行列索引 (i, j)，其中 0 <= i, j < N。
2. 推断宏格阵列的 D4 对称关系。对于 N x N 阵列中心为 ((N-1)/2, (N-1)/2)，D4 群的 8 个操作（恒等、90/180/270 度旋转、水平/垂直/两条对角翻转）将宏格 (i, j) 映射到其对称伙伴位置。
3. 对每个空白宏格 (i, j)：在其对称轨道中找到一个完整填充的伙伴宏格 (i', j')，将 (i', j') 的内容经过从 (i', j') 到 (i, j) 的对称变换（相应的旋转或翻转）后复制到 (i, j) 中。
4. 对每个含品红(6)掩码的宏格 (i, j)：在其对称轨道中找到一个完整填充的伙伴宏格 (i', j')，将变换后伙伴格对应位置的颜色复制到品红像素位置。非品红像素保持不变。
5. 分隔线像素保持灰(5)不变。已完整填充的宏格保持不变。

**关键洞察**：对称性不在像素层面而在宏格层面——求解者必须先理解分隔线定义的宏格结构，再在宏格阵列上推断 D4 对称关系，最后将对称伙伴的内容经几何变换后传播。这是两级推理的嵌套：宏观识别对称轴，微观执行像素变换。

## 新题 5：孔洞数参数化印章缩放与着色

**组合逻辑**：[计数/counting]（沿用：数封闭孔洞） + [拉伸/stretch]（创新：拉伸倍率由孔洞数决定，而非由骨架锚点间距决定） + [印章覆盖/stamp]（创新：同一模板在不同矩形内以不同尺寸和颜色印出）

**来源原语**：计数/counting（0a2355a6）、封闭区域/enclosed_region（0a2355a6）、按孔洞数映射颜色/hole_count_to_color_mapping（0a2355a6）、印章覆盖/stamp（264363fd）、十字模板/crosshair_template（264363fd）、以标记为中心印章/stamp_on_marker_center（264363fd）、矩形/rectangle（264363fd）、标记像素/marker_pixel（264363fd）、内部包含/containment（264363fd）、拉伸/stretch（b0f4d537）

**依赖链**：孔洞计数决定缩放因子和颜色 → 缩放因子决定印章尺寸 → 印章尺寸决定印章能否在矩形内完整印出 → 印章在标记中心印出时需检查边界裁剪。删去计数则不知缩放和颜色，删去缩放则所有矩形印章相同（无法区分），删去印章则无输出变化

一句话总结：对每个矩形计数其边框包围的内部孔洞数，以此决定印章模板的缩放倍率和颜色，在矩形内每个标记像素中心印出缩放后的印章。

**输入结构**：
- 网格约 20~28 行列，背景为黑(0)。
- 网格中有 2~4 个由同一颜色（如蓝(1)）边框构成的矩形，矩形内部为黑(0)背景。矩形尺寸各不相同（最小约 7x7，最大约 13x13）。矩形互不重叠、互不相邻。
- 每个矩形的边框内部包含若干（0~3 个）由边框像素完全包围的 4-连通黑(0)封闭区域（孔洞）——这些孔洞是边框上的缺口形成的内部隔间，即矩形边框并非完整的实心框，而是在某些位置有 1 像素宽的缺口，将矩形内部分割为若干不与外部连通的封闭子区域。不同矩形的孔洞数互不相同。
- 每个矩形内部有 1~2 个橙(7)标记像素，位于矩形内部的黑色区域中。
- 网格中另有一个独立的小型十字模板精灵（3x3 的加号形状，由绿(3)像素组成，仅含上下左右 4 个臂像素，中心为黑(0)），位于所有矩形之外。
- 生成约束：每个矩形足够大，使得最大缩放后的印章（以最多孔洞数为倍率）仍可在矩形内以标记为中心完整印出而不超出矩形边框。孔洞数范围为 1~3（0 孔洞的矩形不参与印章操作，保持不变）。

**规则**：
1. 识别所有矩形（蓝(1)边框的 4-连通分量）及其内部结构。
2. 对每个矩形，计算其边框像素完全包围的 4-连通黑(0)封闭区域数量（孔洞数 H）。孔洞数为 0 的矩形跳过后续步骤，保持原样。
3. 根据孔洞数确定该矩形的印章颜色：H=1 → 红(2)，H=2 → 黄(4)，H=3 → 品红(6)。
4. 将十字模板按因子 H 等比缩放（原始模板 3x3，H=1 时保持 3x3，H=2 时缩放为 5x5 即臂长从 1 增至 2，H=3 时缩放为 7x7 即臂长从 1 增至 3）。缩放后的十字形状保持加号结构：中心为空，四个臂各向外延伸 H 个像素。
5. 对每个矩形内的每个橙(7)标记像素，以其坐标为中心，将缩放后的十字模板印在矩形内部：将十字臂像素位置处的黑(0)像素涂为步骤 3 确定的颜色。若印章的某个臂遇到矩形的蓝(1)边框像素，则该臂在边框前一个像素处截断（不覆盖边框）。
6. 橙(7)标记像素本身保持不变。十字模板精灵在输出中被擦除为黑(0)背景。

**关键洞察**：同一个十字模板在不同矩形中表现为不同尺寸和颜色——缩放倍率和着色并非由模板自身决定，而是由目标矩形的拓扑属性（孔洞数）参数化。求解者必须将"矩形结构分析"与"模板几何变换"关联起来。

## 新题 6：L形补全揭示锚点后连线

**组合逻辑**：[补全/completion]（沿用：补全 2x2 缺角） + [连线/connect]（创新：连线锚点不是预先给定的标记，而是补全操作生成的新像素位置）

**来源原语**：补全/completion（3aa6fb7a）、前景对象/foreground_object（3aa6fb7a）、包围框内部/inside_bbox（3aa6fb7a）、缺角补全正方形/missing_corner_completes_square（3aa6fb7a）、连线/connect（60a26a3e）、线段/line_segment（60a26a3e）、同行同列对齐/same_row_column_alignment（60a26a3e）、仅相邻锚点间连接/connect_only_between_adjacent_anchors（60a26a3e）

**依赖链**：L 形补全生成蓝色新像素 → 新像素的位置成为连线锚点 → 锚点间的对齐关系决定哪些锚点对被连线 → 连线仅在相邻锚点之间。删去补全则无锚点可连，删去连线则输出不完整，删去相邻约束则连线图案错误

一句话总结：将每个 3 像素 L 形补全为 2x2 正方形（缺角填蓝），然后将所有蓝色缺角位置作为锚点，在同行或同列相邻锚点之间画红色连线。

**输入结构**：
- 网格约 12~18 行列，背景为黑(0)。
- 网格中散布 4~8 个由青(8)像素构成的 4-连通前景对象，每个对象恰好有 3 个像素，占据一个 2x2 边界框中的 L 形位置（即 2x2 中缺少一个角）。
- 各 L 形对象互不相邻（任意两个对象之间至少有 2 个像素的间隔）。
- L 形的缺角朝向各不相同（有的缺左上角，有的缺右下角等）。
- 生成约束：至少有 3 对缺角位置共享同一行或同一列（以保证连线步骤有足够的连接可画）。不存在两个缺角位置完全相同。

**规则**：
1. 对每个青(8) L 形对象，找到其 2x2 边界框中唯一的黑(0)像素（缺角位置），将其涂为蓝(1)。此步骤后每个 L 形变为完整的 2x2 青蓝正方形。
2. 收集所有蓝(1)像素的坐标，作为锚点集合。
3. 对所有锚点按行分组：同一行内的锚点按列坐标从小到大排序。对每对相邻锚点（即它们之间同行内没有其他锚点），在两者之间的所有黑(0)像素位置画一条水平红(2)线段（不覆盖锚点本身和任何非黑像素）。
4. 对所有锚点按列分组：同一列内的锚点按行坐标从小到大排序。对每对相邻锚点（即它们之间同列内没有其他锚点），在两者之间的所有黑(0)像素位置画一条垂直红(2)线段（不覆盖锚点本身和任何非黑像素）。
5. 若一条线段的路径上遇到非黑像素（例如穿过某个 L 形对象），则该线段在非黑像素前一个位置截断，不覆盖非黑像素。
6. 所有原始青(8)像素保持不变。

**关键洞察**：连线的锚点并非输入中直接可见的标记，而是隐含在 L 形对象的几何缺陷中——只有先完成补全操作才能确定锚点位置，而锚点的空间对齐关系进一步决定了连线图案。L 形的朝向编码了锚点位置。

## 新题 7：正方形遮挡物的奇偶三分支恢复

**组合逻辑**：[补全/complete]（沿用：从可见周期推断被遮挡图案） + [标注中心/mark_center]（创新：中心标注色为遮挡物原色而非外部标记色） + [擦除/erase]（创新：擦除条件由形状分类和奇偶性联合决定）

**来源原语**：补全/complete（abbfd121）、周期平铺图案/periodic_tile（abbfd121）、矩形遮挡物/rect_occluder（abbfd121）、被遮挡/occluded（abbfd121）、最大矩形区域/max_rect_region（abbfd121）、标注中心/mark_center（22806e14）、实心正方形/solid_square（22806e14）、奇偶性/parity（22806e14）、奇边长才标注/odd_side_marked（22806e14）、擦除/erase（1c02dbbe）

**依赖链**：形状分类将遮挡物分为"非正方形矩形"和"正方形"两类 → 正方形进一步按边长奇偶分为两小类 → 三个分支各有不同的变换：非正方形保留不动、偶数正方形完全恢复底层图案、奇数正方形恢复图案并标注中心。删去周期推断则无法恢复，删去形状分类则不知哪些该恢复，删去奇偶判断则无法区分标注与否

一句话总结：在被多个矩形遮挡物覆盖的周期图案上，非正方形遮挡物保持不变，偶边长正方形遮挡物被底层图案替换，奇边长正方形遮挡物被底层图案替换后在中心额外标注遮挡物原色。

**输入结构**：
- 网格约 14~20 行列。
- 底层为一个行列周期平铺的彩色图案，基本瓦片为 2x2 或 3x3，由 2~3 种颜色组成（如蓝(1)和绿(3)交替）。
- 在周期图案上方叠加了 4~6 个单色实心矩形遮挡物，每个遮挡物由一种非图案颜色构成（从红(2)、黄(4)、灰(5)、品红(6)、橙(7)中选取），颜色互不相同。遮挡物互不重叠。
- 遮挡物中：至少 1 个是非正方形矩形（如 3x5 或 2x4），至少 1 个是偶边长正方形（如 2x2 或 4x4），至少 1 个是奇边长正方形（如 3x3 或 5x5）。
- 生成约束：周期图案的可见部分（遮挡物之外）足以唯一推断出基本瓦片的内容和对齐方式。

**规则**：
1. 从所有遮挡物之外的可见区域推断底层周期图案的最小平铺瓦片及其行列对齐相位。
2. 对每个遮挡物进行形状分类：
   - (a) 非正方形矩形（宽 =/= 高）：保持不变，遮挡物像素留在原处。
   - (b) 偶边长正方形（宽 = 高 且边长为偶数）：将遮挡物区域的所有像素替换为底层周期图案在该位置的颜色（完全恢复）。
   - (c) 奇边长正方形（宽 = 高 且边长为奇数）：先将遮挡物区域的所有像素替换为底层周期图案在该位置的颜色，然后将正方形中心像素（第 (边长/2) 行、第 (边长/2) 列，0-indexed）涂为该遮挡物的原始颜色。
3. 所有遮挡物之外的周期图案像素保持不变。

**关键洞察**：同为遮挡物，命运却由几何属性决定——求解者必须对每个遮挡物做两级分类（正方形与否、边长奇偶），才能确定它是被保留、被恢复、还是被恢复加标注。奇边长正方形中心的标注色来自遮挡物自身而非外部模板，这一点需对比多个示例才能归纳。

## 新题 8：双色对象分裂重组为对角邻接框架

**组合逻辑**：[分割/split + 重涂色/recolor]（创新：分割和色彩互换后的半块成为独立精灵） + [平移拼接/translate_assemble]（创新：拼接目标为矩形框架，且来自同一原对象的两半必须保持对角邻接）

**来源原语**：分割/split（fc4aaf52）、重涂色/recolor（fc4aaf52）、颜色互换且偏移/color_swap_offset（fc4aaf52）、双色物体/bicolor_object（fc4aaf52）、对角邻接拼合/diagonal_adj_join（fc4aaf52）、平移拼接/translate_assemble（83b6b474）、矩形边框/rectangular_frame（83b6b474）、拼合覆盖/assembly_coverage（83b6b474）、像素数定尺寸/pixel_count_determines_size（83b6b474）

**依赖链**：分割将双色对象切为上下两半 → 色彩互换使两半的颜色关系变为互补标记 → 精灵总像素数决定框架尺寸 → 框架拼接要求所有精灵恰好覆盖框架 → 同源约束要求原对象的两半对角邻接。删去分割则无精灵可拼，删去色彩互换则无法识别同源对，删去对角约束则拼接不唯一，删去像素数约束则不知框架尺寸

一句话总结：将多个双色对象水平切半并互换颜色，然后将所有半块平移拼成一个矩形框架，其中来自同一原对象的两半必须保持对角邻接。

**输入结构**：
- 网格约 14~20 行列，背景为黑(0)。
- 网格中有 2~4 个 4-连通双色对象，互不相邻。每个对象恰好包含两种非黑前景颜色，边界框高度为偶数（4~8 像素），宽度为 2~4 像素。
- 每个对象内部两种颜色的分布不特定，但以边界框水平中线为分界，上半和下半各自的像素分布形成两个条状或块状精灵。
- 所有对象使用的颜色集合为同一对颜色（如全部由红(2)和蓝(1)组成），保证色彩互换后的颜色仍在调色板内。
- 生成约束：所有对象的总前景像素数恰好等于某个矩形框架的周长像素数（即 2*(W+H)-4，其中 W 和 H 均 >= 3）。所有半块能恰好覆盖该框架的每一个像素。每个原对象分裂后的两半在框架中存在一种放置方式使得对角邻接成立。

**规则**：
1. 对每个双色对象，在其边界框水平中线处切为上半和下半，得到两个独立精灵。
2. 对每个精灵内部的两种前景颜色执行互换：原来是红(2)的变为蓝(1)，原来是蓝(1)的变为红(2)（对所有精灵统一操作）。
3. 统计所有精灵的总像素数 P，计算满足 2*(W+H)-4 = P 且 W 与 H 之差最小的正整数框架尺寸 (W, H)，其中 W >= H >= 3。
4. 将所有精灵仅通过平移（不旋转、不翻转）排列到一个 W x H 的一像素厚矩形框架上，使得：(a) 每个精灵的像素恰好覆盖框架的某段边缘，(b) 所有框架像素恰好被覆盖一次，(c) 来自同一个原对象的上半精灵和下半精灵在框架上对角邻接（即一个的右下角像素与另一个的左上角像素 8-连通相邻，或一个的左下角像素与另一个的右上角像素 8-连通相邻）。
5. 框架内部为黑(0)背景。输出网格尺寸为 W x H。

**关键洞察**：色彩互换后，同源两半的颜色与原始对象相反——求解者必须通过颜色互补关系反推哪些精灵源自同一对象，再用对角邻接约束确定唯一的拼接方案。框架尺寸不是直接给出的，而是由总像素数隐式编码。
