## 新题 1：形状等价驱动的定向重力

**组合逻辑**：[形状匹配/shape_match](已有) → [重力下落/gravity_drop](创新：不是列内自由下落，而是朝配对伙伴方向坠落) → [重涂色/recolor](创新：着陆时吸收伙伴颜色)

**来源原语**：shape_match + dihedral_equiv（来自 6165ea8f）、gravity_drop + collision_stop（来自 1e0a9b12、2b83f449）、recolor（来自 a8610ef7、ae58858e）、foreground_object + connected_component（来自 ae58858e）、normalized_mask（来自 6165ea8f）

**依赖链**：形状匹配的输出（配对关系）决定了哪些对象成为重力下落的目标以及下落方向；重力下落的着陆位置决定了重涂色的触发条件和目标颜色。删除形状匹配则无法确定配对，重力无目标；删除重力则对象不移动，无法着陆；删除重涂色则丢失配对信息的视觉表达。

将散落在网格中的小图形按旋转/翻转等价关系配对，配对中较高的图形向下坠落至伙伴旁并吸收伙伴颜色。

**输入结构**：约 15x15 网格，黑(0)背景。散布 6~8 个小型 4-连通单色图形（每个 3~6 像素），每个图形使用不同颜色（从蓝(1)、红(2)、绿(3)、黄(4)、灰(5)、品红(6)、橙(7)、青(8)中选取）。这些图形以配对方式存在：每对中两个图形的归一化掩码在二面体群 D4（旋转 0/90/180/270 度 + 水平/垂直/对角翻转）下等价，但颜色不同。每对中一个图形的最小行坐标严格小于另一个（即一高一低）。不同对的图形所占列范围互不重叠，保证下落路径不冲突。可能存在 0~1 个无配对的孤立图形作为干扰项。

**规则**：
1. 对每个图形计算其归一化掩码（以边界框左上角为原点的相对像素坐标集合）。
2. 两个图形配对当且仅当其中一个的归一化掩码可以通过 D4 群中某个变换映射为另一个的归一化掩码。每个图形至多属于一对。
3. 对每对配对图形，最小行坐标较小的（在网格中位置较高的）是"坠落者"，另一个是"锚定者"。
4. 坠落者整体向下平移（所有像素同时下移相同行数），直到坠落者的任意像素与锚定者的任意像素在 4-连通方向上相邻（即到达锚定者正上方紧贴的位置）。坠落者保持其原始形态不变，不旋转。
5. 坠落者着陆后，其所有像素重涂为锚定者的颜色。
6. 锚定者保持位置和颜色不变。
7. 无配对的孤立图形保持位置和颜色不变。

**关键洞察**：必须先解决形状等价匹配（这要求识别旋转/翻转等价而非仅形状相同），才能知道哪些对象移动、移向何处。等价判断需要对比多个示例中不同旋转姿态的配对来确认使用的是 D4 等价而非仅平移等价。坠落者的最终颜色泄露了配对关系，但颜色变化规则（吸收伙伴色）需要多个示例才能归纳。

## 新题 2：隐形权重驱动的瓦片重力排序

**组合逻辑**：[计数/counting](已有) → [排序/sorting](创新：排序对象是整个瓦片而非数值) → [重力下落/gravity_drop](创新：不是像素级下落，而是瓦片级整体重排) + [擦除/erase](创新：排序依据在输出中被抹去)

**来源原语**：counting + sorted_by_count（来自 d4c90558）、gravity_drop + gravity_settling（来自 1e0a9b12）、separator_grid + cell_array（来自 e734a0e8、9ddd00f0）、marker_pixel + containment（来自 d4c90558）、erase（来自 e98196ab 中删除分隔行的思路）

**依赖链**：计数产生每个瓦片的"权重"值，该值作为排序的关键字。排序决定瓦片在列中的最终位置（等效于带权重的重力沉降）。擦除使权重信息从输出中消失，迫使求解者从输入的标记数量和输出的位置变化中反向推断规则。三者缺一不可：无计数则无排序依据，无排序则瓦片不动，无擦除则规则一目了然失去谜题性。

在分隔网格的瓦片阵列中，按每个瓦片内红色标记像素的数量进行列内重力排序，然后抹去所有标记。

**输入结构**：约 18x18 网格。灰(5)单像素宽的分隔行和分隔列将网格划分为规整的瓦片阵列（如 3x3 阵列，每个瓦片约 5x5）。每个瓦片内部以黑(0)为底色，包含一个小型单色前景图形（2~5 像素的 4-连通区域，颜色从蓝(1)、绿(3)、黄(4)、品红(6)、橙(7)、青(8)中选取，各瓦片颜色可不同）。部分瓦片额外包含 1~3 个红(2)单像素标记点，放置在不与前景图形重叠的位置上。生成约束：同一列瓦片中，任意两个瓦片的红色标记数量互不相同（保证排序无歧义）。至少有一列瓦片中存在非平凡排序（即标记数不是从上到下已经递增）。

**规则**：
1. 对每个瓦片，计算其内部红(2)标记像素的数量（0 也是合法数量）。
2. 在瓦片阵列的每一列中，按标记数量升序（从少到多）对瓦片进行重新排列：标记最少的瓦片移至该列最顶部的瓦片位置，最多的移至最底部。
3. 排序时瓦片的前景图形随瓦片一起移动，保持形状和颜色不变。
4. 排序完成后，删除所有红(2)标记像素（在输出中不出现）。
5. 灰(5)分隔线保持不变。各列独立排序，不同列之间无交互。

**关键洞察**：红色标记是"隐形权重"——它们在输入中决定排序顺序，但在输出中完全消失。求解者必须注意到输入中标记数量与输出中瓦片位置变化之间的对应关系，并且需要多个示例确认排序方向（升序）和排序范围（列内独立）。

## 新题 3：奇偶仲裁的面板透明叠加

**组合逻辑**：[透明叠加/transparent_overlay](创新：引入冲突处理机制) + [重涂色/recolor](创新：由列奇偶性决定冲突胜者)，以 [列奇偶交替/column_parity_swap] 作为决策节点

**来源原语**：transparent_overlay + same_position_overlay（来自 e98196ab、3d31c5b3）、recolor + intersection_diff_colored（来自 a8610ef7）、equal_height_panel + separator_row（来自 e98196ab）、column_parity_swap + parity_swap（来自 e9afcf9a）

**依赖链**：透明叠加将两个面板合并到同一坐标系，产生碰撞位置。列奇偶性作为决策节点决定碰撞位置的胜者（选择哪个面板的颜色），这既非简单的分层优先级也非简单的颜色映射。删除叠加则无碰撞问题；删除奇偶判断则碰撞无解。两个操作通过碰撞事件紧耦合。

移除水平分隔线后将上下面板叠加，碰撞位置由列奇偶性决定保留哪个面板的颜色。

**输入结构**：约 13x13 网格（奇数行高，使两面板等高），黑(0)背景。一条完整的橙(7)纯色行横贯网格全宽，将网格分为上下两个等高面板。上面板包含蓝(1)前景像素（若干散布的单像素或小型 2~3 像素的 4-连通区域）。下面板包含绿(3)前景像素（类似分布）。关键设计：部分本地坐标位置上下面板均有前景像素（刻意制造碰撞），碰撞位置同时覆盖偶数列和奇数列（每种至少 3 处），以便求解者从示例中归纳奇偶规则。非碰撞位置也同时包含偶数列和奇数列的前景像素，作为对照。

**规则**：
1. 删除橙(7)分隔行。
2. 将下面板按本地坐标对齐覆盖到上面板上，生成与单面板等高等宽的输出网格。
3. 对输出网格中的每个位置 (r, c)：
   - 若仅上面板在该本地坐标有前景像素：输出蓝(1)。
   - 若仅下面板在该本地坐标有前景像素：输出绿(3)。
   - 若两面板均有前景像素（碰撞）：若 c 为偶数（0, 2, 4, ...），输出蓝(1)（上面板胜）；若 c 为奇数（1, 3, 5, ...），输出绿(3)（下面板胜）。
   - 若两面板均无前景像素：输出黑(0)。

**关键洞察**：叠加规则不是简单的"先到先得"或固定优先级——碰撞解决取决于列索引的奇偶性。这只能通过对比多个碰撞位置的列坐标来发现：偶数列总是保留上面板颜色，奇数列总是保留下面板颜色。非碰撞位置的行为与标准透明叠加一致，容易误导求解者认为规则就是简单叠加。

## 新题 4：锚点射线借色于最近大型分量

**组合逻辑**：[射线延伸/ray_extend](已有) + [重涂色/recolor](创新：射线颜色不来自自身标记，而来自空间上最近的合格分量) + [计数/counting](创新：面积阈值过滤决定哪些分量有资格借色)

**来源原语**：ray_extend + marker_to_anchor + row_col_alignment（来自 d43fd935）、recolor + recolor_above_threshold（来自 ae58858e）、counting（来自 3b4c2228、d4c90558）、anchor_square + marker_pixel + line_segment（来自 d43fd935）、connected_component（来自 ae58858e）、nearest_preferred（来自 3e6067c3）

**依赖链**：射线的几何方向由标记-锚点对齐关系决定（空间分析 A）。射线的颜色由标记到最近合格分量的距离决定（空间分析 B）。分量是否合格由面积阈值过滤决定（计数操作）。三条分析链独立产生信息，但在最终射线绘制时必须同时使用。删除射线则无视觉输出；删除借色则射线颜色不确定；删除面积过滤则借色对象错误。

从对齐标记向锚点方块延伸射线，但射线颜色来源于距标记最近的、面积达标的前景分量。

**输入结构**：约 16x16 网格，黑(0)背景。一个红(2)的 2x2 锚定方块位于网格中部偏离中心的位置。3~5 个灰(5)单像素标记散布在网格中，每个标记与锚定方块共享至少一行或一列（即标记的行坐标等于锚定方块占据的某行，或列坐标等于锚定方块占据的某列）。另有 4~6 个小型彩色 4-连通前景对象（每个 2~7 像素，使用蓝(1)、绿(3)、黄(4)、品红(6)、橙(7)、青(8)中的不同颜色），散布在网格中与锚定方块不对齐的位置。生成约束：每个标记有唯一的最近合格分量（按标记像素中心到分量质心的欧氏距离）；至少一个彩色分量面积 < 3（作为不合格干扰项），至少两个面积 >= 3。

**规则**：
1. 对每个灰(5)标记像素，判断其与红(2)锚定方块的对齐关系：若共享行，则射线水平延伸；若共享列，则射线垂直延伸。射线从标记像素出发，朝锚定方块方向延伸，终止于锚定方块相邻的那个像素位置（不覆盖锚定方块本身）。
2. 确定射线颜色：计算标记像素中心到每个彩色前景分量质心的欧氏距离。仅面积 >= 3 的分量有资格作为"借色源"。选取距离最近的合格分量，以其颜色作为射线颜色。
3. 若最近合格分量存在距离相等的平局，选取面积较大的分量。
4. 若某标记附近不存在任何合格分量（所有彩色分量面积均 < 3），则该标记的射线用灰(5)（标记自身颜色）绘制。
5. 锚定方块、所有原始标记像素、所有彩色前景对象在输出中保持不变。
6. 同时共享行和列的标记（即位于锚定方块 2x2 范围正上/下/左/右紧邻位置）：射线长度为 0，不绘制。

**关键洞察**：射线方向和射线颜色来自两套独立的空间分析：方向由标记-锚点几何对齐决定，颜色由标记到最近大分量的距离决定。面积阈值是隐蔽规则——小分量看似应该借色但实际被排除，必须对比不同示例中"小分量在标记旁但射线颜色跳过它"的情况才能归纳出面积过滤条件。

## 新题 5：控制序列驱动的印章覆盖与前驱借色链

**组合逻辑**：[印章覆盖/stamp_overlay](已有) + [重涂色/recolor](创新：印章颜色来自序列中前一个被访问的帧的标记色，形成颜色传递链) + [控制序列/control_sequence + 访问顺序编码/visitation_order_encoding] 作为决策流

**来源原语**：stamp_overlay + template_tile + marker_position + only_marked_cover（来自 e734a0e8、92e50de0）、recolor（来自 a8610ef7）、control_sequence + visitation_order_encoding（来自 3e6067c3）、framed_square（来自 3e6067c3）

**依赖链**：控制序列决定访问顺序和哪些帧被印章覆盖。每帧印章的颜色取决于序列中前一个被访问帧的标记色——这是一条时序依赖链，第 N 步的颜色由第 N-1 步的身份决定。删除控制序列则不知道访问谁；删除印章则无覆盖动作；删除前驱借色规则则颜色分配无法解释。

读取底边控制序列依次访问标记帧，将模板图案印入被访问帧，印章颜色为序列中前一帧的标记色。

**输入结构**：约 16x16 网格，黑(0)背景。网格中散布 5~7 个灰(5)空心矩形框（每个外部尺寸约 4x4 或 5x5，边框宽 1 像素），彼此不重叠不相邻。每个框的内部中心位置放置一个单像素标记，标记颜色各不相同（从蓝(1)、红(2)、绿(3)、黄(4)、品红(6)、橙(7)中选取）。其中一个框被指定为"源框"：其内部不是单像素标记，而是一个 2~3 像素的小型图案（"模板"），使用青(8)绘制，形状为非对称的 4-连通区域（如 L 形、阶梯形），使其在旋转下可辨别方向。网格底边最后一行放置一行控制序列：3~5 个彩色像素从左到右排列，每个颜色对应某个框的标记色（源框的标记色不出现在控制序列中）。控制序列不重复使用同一颜色。

**规则**：
1. 识别源框（内部包含多像素图案而非单像素标记的那个框）。源框内的图案即为模板。
2. 从左到右读取底边控制序列中的颜色。每个颜色指向拥有同色标记的目标框。
3. 按序列顺序依次访问目标框，对每个被访问框执行印章操作：将模板图案的形状复制到该框内部（以框内部左上角为参考点对齐），覆盖原有的标记像素。
4. 印章的颜色规则：
   - 序列中第 1 个被访问的框：印章颜色为源框模板的原始颜色，即青(8)。
   - 序列中第 k 个被访问的框（k >= 2）：印章颜色为第 k-1 个被访问框的原始标记颜色（访问前的标记色，非印章覆盖后的颜色）。
5. 未被控制序列访问的框保持原样（灰框 + 内部标记不变）。源框保持原样。
6. 控制序列像素保留在输出中不变。

**关键洞察**：每个印章的颜色不是来自自身的标记，而是来自访问链中前一个帧的标记色，形成一条"颜色位移链"。第一个帧用模板原色，第二个帧用第一个帧的标记色，以此类推。求解者容易误以为印章颜色就是目标帧自身的标记色或固定颜色，需要仔细对比多个被访问帧的印章颜色与序列中前一帧的对应关系才能归纳出前驱借色规则。

## 新题 6：对齐判定选择连接方式

**组合逻辑**：[连线-桥梁/bridge_drawing](已有) + [连线-对角线/line_drawing](已有) → 由 [行列对齐/row_column_alignment] 作为决策节点选择连接方式（创新：两种连接模式共存于同一谜题，由空间关系决定）

**来源原语**：bridge_drawing + row_column_alignment（来自 3e6067c3）、line_drawing + diagonal_segment_connect + same_color_pairing（来自 1f876c06）、framed_tile + interior_marker + background_channel（来自 b7f8a4d8）、draw_rect_via_channel（来自 b7f8a4d8）

**依赖链**：同色配对确定哪些瓦片需要连接（配对逻辑）。行列对齐检测决定每对使用何种连接方式（决策逻辑）。对齐的对使用沿背景通道的正交桥梁（需要避开框架障碍），不对齐的对使用穿越式对角线段（无视障碍）。连接方式的选择不是预设的，而是从空间关系中涌现的。删除配对则不知道连谁；删除对齐检测则不知道用哪种连接方式。

同色内部标记配对后，行列对齐的配对通过背景通道画正交桥梁，不对齐的配对画穿越式 45 度对角线。

**输入结构**：约 18x18 网格，黑(0)背景。灰(5)单像素宽框架形成规则的带框瓦片格子（如 4x4 阵列，每个瓦片内部约 3x3）。大多数瓦片内部包含一个栗(9)色的 1~2 像素块（默认内部标记）。4~6 个瓦片的内部标记使用其他颜色（蓝(1)、红(2)、绿(3)、黄(4)），每种非默认颜色恰好出现 2 次（配对）。生成约束：至少一对同色瓦片位于同一瓦片行（行对齐），至少一对位于同一瓦片列（列对齐），至少一对既不同行也不同列（不对齐）。瓦片之间的背景通道（框架线之间的黑色间隙）宽 1 像素。

**规则**：
1. 识别所有非默认色的内部标记对（每种颜色恰好 2 个瓦片）。
2. 对每一对，检测两个瓦片在瓦片阵列中的位置关系：
   a. **行对齐**（同一瓦片行）：沿两个标记所在行，通过背景通道（瓦片间的黑色间隙）画一条水平桥梁连接两个标记。桥梁颜色为该对的标记颜色。桥梁仅经过背景通道像素，不覆盖任何框架线或其他瓦片内部。
   b. **列对齐**（同一瓦片列）：类似地画垂直桥梁。
   c. **不对齐**（既不同行也不同列）：画一条 45 度对角线段连接两个标记像素的中心位置。对角线经过的所有格子（包括框架线和其他瓦片内部）均被覆盖为该对的标记颜色。
3. 绘制顺序：先画所有正交桥梁，后画所有对角线段。后绘制的覆盖先绘制的。
4. 默认色(栗(9))内部标记、框架线（除被对角线覆盖的部分）、背景（除被桥梁或对角线覆盖的部分）保持不变。

**关键洞察**：同一谜题中存在两种完全不同的连接机制，选择哪种取决于配对瓦片的阵列位置关系。正交桥梁是"守规矩"的（只走通道），对角线是"破坏性"的（穿越一切）。求解者需要对比对齐与不对齐的配对在输出中的不同表现，才能归纳出这一分支规则。绘制顺序（对角线在后）也需要从重叠区域推断。

## 新题 7：旋转开闸后的颜色选择性重力

**组合逻辑**：[旋转/rotate](创新：不是旋转整个网格，而是旋转闸门部件以改变通道结构) → [重力下落/gravity_drop](已有) + [碰撞停止/collision_stop]，以颜色匹配作为隐蔽的通过条件

**来源原语**：rotate + gate（来自 2b83f449）、gravity_drop + collision_stop + token（来自 2b83f449、1e0a9b12）、pipe_network（来自 2b83f449）、recolor 概念中的颜色条件判断

**依赖链**：旋转改变了通道的物理结构（闸门从水平阻断变为垂直侧柱，释放出通行空间）。重力驱动令牌下落，但旋转后的闸门残余结构（垂直柱）对不匹配颜色的令牌仍然构成阻挡。颜色匹配是隐蔽条件——同色令牌视闸门为透明，异色令牌视之为实体。删除旋转则所有闸门关闭、无令牌可移动；删除重力则令牌不动；删除颜色匹配则所有令牌行为相同，无法解释差异化结果。

闸门旋转 90 度打开通道后，令牌在重力下落过程中仅能穿过与自身同色的闸门残柱，异色闸门仍构成阻挡。

**输入结构**：约 16x20 网格（高大于宽），黑(0)背景。灰(5)墙壁像素形成 3~4 条垂直通道（每条通道宽 3 像素，左右各有 1 像素灰墙，中间 3 列为通道空间）。每条通道内部有 1~2 个水平闸门：每个闸门是一条橙(7)的 1x3 水平线段，完全横跨通道宽度，阻断通道。每个闸门的最左端像素被替换为一种特定颜色（蓝(1)、红(2)、绿(3)或黄(4)），称为闸门的"钥匙色"。每条通道顶部（第 0 行或第 1 行）放置一个彩色令牌单像素，颜色从蓝(1)、红(2)、绿(3)、黄(4)中选取。生成约束：至少一条通道中令牌颜色与其下方某闸门的钥匙色相同，至少一条通道中令牌颜色与闸门钥匙色不同。

**规则**：
1. 对每个闸门，执行以钥匙色像素为旋转中心的 90 度顺时针旋转：闸门原来占据的 3 个水平像素位置中，钥匙色像素不动，其余 2 个橙(7)像素旋转到钥匙色像素的正上方和正下方（形成 3x1 垂直柱）。原来被闸门占据但旋转后空出的位置变为黑(0)（开放通道）。
2. 令牌从其初始位置开始逐行向下移动（重力下落）。
3. 令牌在下落过程中遇到以下情况停止：
   a. 到达通道底部（网格最后一行）：停在该行。
   b. 到达灰(5)墙壁或另一个已停止的令牌的正上方：停在其上方一行。
   c. 到达旋转后闸门垂直柱的正上方：若令牌颜色与该闸门钥匙色相同，令牌穿过该柱继续下落（视为透明）；若颜色不同，令牌停在柱的正上方（视为实体障碍）。
4. 输出保留灰(5)墙壁、旋转后的闸门结构（垂直柱）、以及最终位置的令牌。

**关键洞察**：旋转操作物理上打开了通道（移除水平阻断），但在钥匙色像素处留下了垂直残柱。这些残柱是"颜色选择性障碍"——同色令牌视之为透明通过，异色令牌被阻挡。求解者必须先理解旋转的几何效果，再从令牌的差异化最终位置推断出颜色匹配这一隐蔽条件。

## 新题 8：邻居反射补全与坐标孔洞双重约束

**组合逻辑**：[补全/complete](创新：补全来源不是自身规律而是邻居瓦片的反射) + [镜像/mirror](创新：不是检测对称性，而是用反射操作生成缺失内容) + [填充/fill](已有：坐标孔洞编码)，三者构成同时约束满足结构

**来源原语**：complete + tile_array + separator_row_col + position_hole + hole_equals_coordinate + array_coord_encoding（来自 9ddd00f0）、mirror + reflection_symmetry（来自 a8610ef7）、fill（来自 e9afcf9a、9ddd00f0）

**依赖链**：补全操作需要确定"补什么"，这依赖于镜像操作（从正确的邻居反射得到完整图案）。镜像操作需要确定"反射谁"以及"用哪个轴"，这依赖于对部分瓦片现有像素与相邻完整瓦片的比较。补全后还要叠加坐标孔洞约束（不能简单复制邻居，因为孔洞位置不同）。三条规则必须同时满足：形状来自邻居反射，孔洞来自自身坐标。这不是线性流水线，而是约束满足问题。

在分隔瓦片阵列中，通过反射相邻完整瓦片的图案来补全不完整瓦片，补全后在自身坐标位置打孔。

**输入结构**：约 17x17 网格（如 3*5+2 = 17，形成 3x3 阵列，每个瓦片 5x5）。绿(3)单像素分隔行和分隔列将网格划分为 n x n 的瓦片阵列（n = 3 或 4），每个瓦片 m x m（m = 4 或 5）。瓦片分为两类：
- "完整瓦片"（约占 60~70%）：整个 m x m 区域填满蓝(1)，仅在本地坐标 (tile_row, tile_col) 处有一个黑(0)像素孔洞（即坐标编码孔洞，与 9ddd00f0 相同）。
- "不完整瓦片"（约占 30~40%）：内部约一半像素为蓝(1)，另一半为黑(0)。蓝色像素的分布不是随机的——它们是某个相邻完整瓦片图案（含孔洞）经水平或垂直反射后的一部分（被截断或部分擦除）。
生成约束：每个不完整瓦片至少有一个 4-方向相邻的完整瓦片，且该完整瓦片的图案经某种反射（水平或垂直）后能生成一个超集包含该不完整瓦片的所有蓝色像素。每个不完整瓦片的蓝色像素至少覆盖反射后图案的 40%，以提供足够线索。

**规则**：
1. 识别不完整瓦片（蓝(1)像素数明显少于 m*m - 1 的瓦片）。
2. 对每个不完整瓦片，检查其 4-方向相邻的完整瓦片（上/下/左/右，不含对角）：
   a. 对于左/右方向的邻居：尝试将邻居图案水平反射（左右翻转），检查反射结果是否为不完整瓦片现有蓝色像素的超集。
   b. 对于上/下方向的邻居：尝试将邻居图案垂直反射（上下翻转），检查反射结果是否为超集。
   c. 选择满足超集条件的那个邻居及对应的反射轴。
3. 用选定邻居的反射图案填充不完整瓦片（替换其全部内容）。
4. 在补全后的瓦片上，将本地坐标 (tile_row, tile_col) 处的像素设为黑(0)（坐标孔洞），无论该位置原来是什么。注意：这个孔洞位置与反射来源邻居的孔洞位置通常不同（因为坐标不同）。
5. 已完整的瓦片和分隔线保持不变。

**关键洞察**：补全规则不是简单地"把空位填满蓝色"（那样无法解释孔洞位置的差异），也不是简单地"复制邻居"（因为内容是反射过的）。求解者需要同时发现三件事：(1) 内容来自邻居而非自身规律；(2) 内容经过了反射变换；(3) 反射轴由邻居方向决定（左右邻居用水平反射，上下邻居用垂直反射）。坐标孔洞的存在增加了额外约束——完成补全后还必须在正确位置打孔，这排除了"直接复制邻居"的简单假设。

## 新题 9：东南支撑滑动引发的邻接吞噬

**组合逻辑**：[滑动/slide](已有) → [重涂色/recolor](创新：由滑动后涌现的新邻接关系触发，大面积吞噬小面积) + [邻接传色/adjacency_color_transfer](创新：不是沿路径传色，而是因物理接触引发的大鱼吃小鱼式吞噬)

**来源原语**：slide + shift_if_pixel_beyond + support + contour_bound（来自 025d127b）、recolor + adjacency_color_transfer（来自 800d221b）、foreground_object + connected_component（来自 ae58858e）、adjacency_count_determines_color 的思路（来自 800d221b）

**依赖链**：滑动改变对象的像素位置，使原本不相邻的对象可能变为相邻（涌现效应）。新邻接关系触发吞噬式重涂色（面积大的对象将面积小的对象染成自己的颜色）。吞噬具有传递性——如果 A 吞噬 B 后与 C 相邻，且合并后的 A+B 面积大于 C，则继续吞噬 C。删除滑动则对象不接触（初始间距足够大），无邻接发生；删除重涂色则滑动结果无后续效果。

对每个对象执行东南支撑滑动后，因位移而新产生 4-邻接的对象之间发生面积吞噬式重涂色。

**输入结构**：约 14x14 网格，黑(0)背景。散布 4~6 个小型 4-连通单色对象（每个 3~6 像素），使用不同颜色（蓝(1)、红(2)、绿(3)、黄(4)、品红(6)、橙(7)）。对象初始彼此间距至少 2 像素（在任何方向上均无 4-邻接）。每个对象至少有一个像素具有"东南支撑"（即同对象中存在另一个像素同时位于更大的行和更大的列）。对象的形状为不规则的 4-连通区域（非矩形），如阶梯形、弯折形等。生成约束：执行滑动操作后，至少有两对原本不相邻的对象变为 4-邻接；至少有一对在滑动后仍不相邻（作为对照）。至少有一次吞噬涉及面积不等的对象对。

**规则**：
1. 对每个对象独立执行滑动操作（与 025d127b 相同）：对于该对象中的每个像素 (r, c)，若同对象中存在另一个像素 (r', c') 满足 r' > r 且 c' > c（东南方向有支撑），则将该像素向右移动一列变为 (r, c+1)；否则像素不动。所有对象的滑动同时执行（基于原始位置判断），滑动后更新位置。
2. 滑动后，检测所有对象对之间是否存在新的 4-邻接（即滑动前不相邻但滑动后某个像素与另一对象的某个像素在上下左右方向紧邻）。
3. 对每对新邻接的对象，执行吞噬：像素数较多的对象保持颜色不变，像素数较少的对象所有像素重涂为较多对象的颜色。若两对象像素数相等，则最小行坐标较小（位置更高）的对象保持颜色，另一个被吞噬。
4. 吞噬具有传递性：完成一轮吞噬后，若合并后的大对象与新的对象产生了 4-邻接，继续执行吞噬规则，直到不再有新的邻接产生。处理顺序：每轮中按被吞噬对象的面积从小到大处理。
5. 滑动后仍不与任何其他对象相邻的对象保持滑动后的位置和原始颜色。

**关键洞察**：滑动操作本身是确定性的几何变换（东南支撑像素右移一列），但它产生了输入中不存在的空间邻接关系。这些涌现的邻接关系触发了大鱼吃小鱼式的颜色吞噬。求解者必须先理解滑动规则（需要对比多个不同形状的对象的滑动结果），再理解吞噬规则（需要对比面积不等和面积相等的邻接对），最后理解传递性（需要至少一个涉及链式吞噬的示例）。整个推理链是：几何变换 → 涌现邻接 → 条件触发的颜色传播。
