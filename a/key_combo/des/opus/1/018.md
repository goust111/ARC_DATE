## 新题 1：锚点叠合涌现孔洞

**组合逻辑**：[透明叠加](创新：叠加顺序由锚点输入位置的行列序决定) → [封闭区域检测](创新：孔洞仅在多精灵叠合后涌现，单精灵无孔洞) → [洪泛填充](创新：仅填充叠合涌现的封闭孔洞) → [裁剪]

**来源原语**：透明叠加、锚点像素、锚点对齐、锚点重合叠加（参考题 137eaa0f）；封闭区域、区域可达性、洪泛填充（参考题 543a7ed5、9edfc990）；裁剪（参考题 137eaa0f）

**依赖链**：叠加顺序决定哪些像素被覆盖 → 覆盖结果决定合成边界的拓扑形状 → 拓扑形状决定是否存在封闭孔洞以及孔洞位置 → 孔洞检测结果决定填充区域。删除叠加步骤则无合成体、无孔洞可检测；删除孔洞检测则无法区分内外背景；删除填充则输出不完整。

将多个开放形状的精灵按锚点叠合成一个复合体，在复合边界围出的封闭孔洞中填入指定颜色，然后裁剪输出。

**输入结构**：约 18x18 的黑(0)背景网格。网格中散布 3~4 个互不接触的小型精灵体，每个精灵由 4~8 个像素组成（4-连通的单色区域加上恰好一个灰(5)锚点像素）。不同精灵的非灰颜色各不相同，分别取自 {蓝(1)、红(2)、绿(3)、品红(6)} 中的不同值。每个精灵本身是开放形状（其像素不围成任何封闭黑色区域）。生成约束：当所有精灵按锚点对齐叠合后，合成体的非黑像素必须围出至少一个 4-连通封闭黑色区域（即孔洞），且至少有两个精灵在叠合中存在像素重叠。

**规则**：
1. 裁剪每个精灵至其最小外接矩形（包含该精灵所有非黑像素的最小矩形）。
2. 按精灵锚点在原始输入网格中的位置排序：先按行坐标升序，行坐标相同时按列坐标升序。此排序决定绘制顺序。
3. 创建一块足够大的黑色画布。依绘制顺序逐个放置精灵：将每个精灵的灰(5)锚点对齐到画布的同一固定点（画布中心）。放置时，精灵的非黑像素覆盖画布上的已有内容（后放置的覆盖先放置的）。
4. 在合成画布上，找出所有 4-连通的黑(0)区域。若某黑色区域没有任何像素位于画布边界行/列上，则该区域为"封闭孔洞"。
5. 将每个封闭孔洞内的所有像素填充为黄(4)。
6. 将画布上所有灰(5)像素设为黑(0)（擦除锚点标记）。
7. 裁剪画布至包含所有非黑像素的最小外接矩形，作为输出。

**关键洞察**：每个精灵自身没有封闭孔洞——孔洞仅在多精灵叠合后涌现。叠合顺序影响哪些像素被覆盖，从而改变合成边界的形状和孔洞的存在与位置。需要对比多个示例才能确认叠合排序规则（按锚点输入位置的行列序）。

## 新题 2：射线弹射计数决定矩形着色

**组合逻辑**：[射线投射](已有) → [碰撞反弹/反射](创新：反射次数作为计数输入) → [计数](创新：统计每个矩形被射线反射的次数) → [重涂色](创新：颜色由命中次数的等级映射决定)

**来源原语**：射线投射、碰撞反弹、射线遇障碍翻转、对角线段（参考题 508bd3b6）；计数、频率统计（参考题 81c0276b）；重涂色、相对位置决定颜色（参考题 639f5a19）；矩形障碍（参考题 508bd3b6）

**依赖链**：对角线段确定射线初始方向 → 射线在矩形表面反射产生路径 → 路径与矩形的接触事件数是计数输入 → 计数结果决定每个矩形的重涂色方案。删除射线投射则无反射事件；删除计数则无法确定颜色映射；删除重涂色则输出不完整。

从对角线段的两端发射射线，射线遇矩形反射弹回，每个矩形依据被射线命中的总次数获得对应的新颜色。

**输入结构**：约 20x20 的黑(0)背景网格。网格中有一条青(8)对角线段（3~5 个像素，沿 NE/NW/SE/SW 某一对角方向连续排列）和 3~5 个实心单色矩形（每个 2x2 至 3x4 大小），矩形彼此不接触、不接触对角线段，每个矩形的颜色互不相同且不使用黑(0)、青(8)、绿(3)。生成约束：至少两个矩形位于射线的可达路径上（即射线经过反射后能触及它们）。

**规则**：
1. 识别青(8)对角线段的两个端点及其外延方向（沿线段方向从两端分别向外延伸的对角方向）。
2. 从每个端点出发，沿其外延方向逐像素绘制绿(3)射线。
3. 射线每步前进一个对角像素。若下一步将进入某矩形的边界像素：射线不进入该像素，而是在当前位置发生反射——翻转速度分量中与所接触矩形边垂直的那个分量（若同时接触矩形角点的两条边，则翻转两个分量），然后继续绘制。该矩形的"命中计数"加 1。
4. 射线在离开网格边界时终止。
5. 统计每个矩形的总命中次数（两条射线的命中累加）。
6. 重涂色规则：命中 0 次 → 保持原色不变；命中恰好 1 次 → 重涂为蓝(1)；命中 2 次及以上 → 重涂为红(2)。
7. 青(8)对角线段保持不变。绿(3)射线路径保留在输出中。射线像素与青线段像素重叠时，青(8)优先显示。

**关键洞察**：矩形的输出颜色不取决于其自身属性（位置、大小、原色），而取决于一个动力学属性——射线弹射过程中与它接触的总次数。这只能通过完整追踪射线路径来确定。命中次数到颜色的映射规则需要对比多个示例才能归纳。

## 新题 3：网格字形频率排名着色

**组合逻辑**：[网格分块](已有) → [解码/形状识别](创新：按像素位置模式识别字形，忽略颜色) → [计数](创新：跨单元统计同一形状的出现频率) → [排序](已有) → [重涂色](创新：颜色由频率排名映射决定，与原色无关)

**来源原语**：网格分块、网格分隔线（参考题 5bd6f4ac）；解码、字形图案、字形映射颜色行（参考题 995c5fa3）；计数、频率统计、按计数升序（参考题 81c0276b）；排序（参考题 995c5fa3）；重涂色（参考题 639f5a19）

**依赖链**：网格分块提取单元 → 形状识别将单元归类（忽略颜色） → 频率统计得出每种形状的出现次数 → 排序建立排名 → 排名映射到输出颜色。删除形状识别则无法分组；删除频率统计则无法确定排名；删除排序则颜色分配无依据。

将网格表格中的单元按字形形状分组，统计各形状的出现频率，按频率排名为每组分配统一的新颜色。

**输入结构**：约 16x16 的网格，由灰(5)水平线和垂直线划分为 4x4 共 16 个 3x3 单元格。每个单元格内包含一个由单一非黑、非灰颜色在黑(0)背景上绘制的小图案（2~5 个像素的 4-连通区域）。整个网格中存在 3~4 种不同的图案形状（按非黑像素的相对位置定义），每种形状在不同单元格中可能以不同颜色出现。同一形状在所有单元格中的像素相对位置完全一致。生成约束：各种形状的出现频率互不相同。

**规则**：
1. 提取每个单元格的 3x3 内容区域（分隔线之间的区域）。
2. 对每个单元格，记录其非黑像素的坐标集合（相对于单元格左上角）。若两个单元格的非黑像素坐标集合完全相同，则它们属于"同一形状"，不论像素颜色是否一致。
3. 按形状分组，统计每种形状的出现频率（包含该形状的单元格数目）。
4. 按频率升序排名：最少的为排名 1，其次为排名 2，以此类推。
5. 按排名分配输出颜色：排名 1 → 红(2)；排名 2 → 绿(3)；排名 3 → 蓝(1)；排名 4 → 黄(4)。
6. 在输出中保留灰(5)分隔线结构。将每个单元格内的所有非黑像素统一替换为该单元格所属形状对应的排名颜色，黑色背景保持不变。

**关键洞察**：单元格的输出颜色与其输入颜色完全无关——决定因素是该单元格所含形状在整个网格中出现了多少次。识别形状时必须忽略颜色、仅看像素位置模式；频率排名到颜色的映射需对比多个示例才能确定。

## 新题 4：镜像去噪后拓扑分析双标记

**组合逻辑**：[镜像](创新：用于去噪而非显示) → [擦除](创新：通过双半区交集识别噪声) → [封闭区域检测](创新：依赖去噪结果的正确拓扑) → [洪泛填充](创新：仅填孔洞) + [描边](创新：仅标记外轮廓)

**来源原语**：镜像、镜像对应、分隔列（参考题 dd2401ed、c9680e90）；擦除、邻接不足则删除（参考题 7f4411dc）；封闭区域、区域可达性、孔洞填色轮廓描色、描边、洪泛填充（参考题 543a7ed5）；前景形状、外部邻接区域（参考题 543a7ed5）

**依赖链**：镜像对齐 → 交集去噪得到干净形状 → 干净形状决定正确的拓扑结构（哪些区域封闭、哪些开放） → 封闭区域填黄 + 外轮廓描绿。噪声若不去除，可能堵塞真实孔洞入口（使封闭区域误判为开放）或在空旷处制造虚假封闭，导致填充和描边均出错。

利用左右半区互为镜像的冗余信息去除单侧噪声，在干净的前景形状上正确检测封闭孔洞并填色、对外轮廓描边。

**输入结构**：约 12x25 的网格（宽大于高）。正中央有一整列灰(5)垂直分隔列。左半区：蓝(1)像素构成一个前景形状（10~20 像素的 4-连通区域，可能围成 1~2 个封闭孔洞），加上 5~10 个散布的红(2)噪声像素，全部在黑(0)背景上。右半区：与左半区蓝(1)前景形状完全相同的水平镜像副本（也用蓝(1)绘制），无噪声，黑(0)背景。生成约束：(a) 前景形状至少有一个封闭孔洞（由蓝像素完全围合的黑色区域）；(b) 至少一个红色噪声像素位于某孔洞的边界附近（与围合该孔洞的蓝像素 4-邻接），使得若不去噪、该噪声像素会影响孔洞的封闭性判断。

**规则**：
1. 将右半区（不含分隔列）水平翻转（左右镜像），使其与左半区空间对齐。
2. 逐像素比较左半区与翻转后的右半区：若某位置在两者中均为蓝(1)，则保留为蓝(1)；否则设为黑(0)。此交集操作产生"去噪形状"，画布大小等于一个半区。
3. 在去噪画布上，找出所有 4-连通的黑(0)区域。
4. 若某黑色区域没有任何像素位于画布的边界行或边界列上，则为"封闭孔洞"→ 将该区域所有像素填充为黄(4)。
5. 对于非封闭的黑(0)区域中的每个像素，若它与至少一个蓝(1)像素 8-邻接（8 个方向之一相邻），则将它涂为绿(3)（外轮廓）。
6. 输出该半区大小的画布（不含分隔列和右半区）。

**关键洞察**：单独看左半区，噪声像素可能恰好位于孔洞的缺口处，使原本封闭的区域看起来与外部相通（红像素打通了封闭边界）；也可能在开阔处制造虚假的微小围合。只有通过镜像交集去噪后，才能获得正确的拓扑结构进行孔洞检测和外轮廓描边。去噪方式（交集而非并集）需对比多个示例确认。

## 新题 5：种子扭曲螺旋分区着色

**组合逻辑**：[螺旋绘制](创新：种子像素作为额外墙壁扭曲螺旋路径) → [区域分割](创新：螺旋路径将网格划分为若干 4-连通黑色区域) → [洪泛填充](创新：仅填充被唯一种子认领的区域)

**来源原语**：螺旋绘制、碰撞转向、正方形画布、路径、旋转方向（参考题 28e73c20）；种子像素、洪泛填充、四邻连通、种子沿连通域扩散、障碍物（参考题 9edfc990）；区域可达性（参考题 543a7ed5）；重涂色（参考题 639f5a19）

**依赖链**：种子位置 → 影响螺旋转向（种子是墙壁） → 螺旋路径决定区域划分 → 区域与种子的邻接关系决定认领 → 认领结果决定填充颜色。种子同时扮演两个角色（螺旋障碍 + 区域认领者），形成紧密的双重耦合。

在包含若干彩色种子的方格上绘制顺时针螺旋，种子像素充当额外墙壁扭曲螺旋路径；螺旋将黑色背景分割成若干区域，被唯一种子 4-邻接的区域填入该种子的颜色。

**输入结构**：约 13x13 的黑(0)正方形网格。网格中分布 3~5 个彩色种子像素（各占 1 个像素，颜色互不相同，取自 {蓝(1)、红(2)、黄(4)、品红(6)、橙(7)}，不使用绿(3)）。种子不位于网格的四角或边角上的第一行/列。生成约束：(a) 螺旋完成后，产生至少与种子数相同的黑色区域；(b) 至少有一个区域被两个种子同时 4-邻接（即存在"争议区域"，不会被填色）。

**规则**：
1. 从网格左上角 (0,0) 开始，方向为"向右"，绘制顺时针螺旋路径，每步将当前像素涂为绿(3)。
2. 移动规则：尝试沿当前方向前进一步。若下一个像素满足以下任一条件则"转向"——(a) 超出网格边界，(b) 该像素已为绿(3)，(c) 该像素为种子像素（非黑非绿），(d) 沿当前方向再前进第二步的像素已为绿(3)（两步前瞻防止路径过早贴合自身）。转向时，方向顺时针旋转 90 度，然后重新尝试前进。若旋转后仍无法前进（所有四个方向都被阻挡），则螺旋终止。
3. 种子像素永远不被螺旋覆盖（螺旋路径跳过种子所在的格子）。
4. 螺旋绘制完成后，识别网格中所有 4-连通的黑(0)区域（不含绿色螺旋像素、不含种子像素的纯黑连通分量）。
5. 对每个黑色区域，检查哪些种子像素与该区域 4-邻接（种子像素的上下左右四个方向中至少一个属于该区域的像素）。若恰好有一个种子与该区域 4-邻接，则该种子"认领"该区域。
6. 将被认领的区域内所有黑色像素填充为认领种子的颜色。
7. 未被认领的区域（0 个或 2 个以上种子邻接）保持黑(0)。种子像素保持原色。绿(3)螺旋像素保持绿色。

**关键洞察**：种子像素身兼两职——既是螺旋的障碍（改变螺旋路径走向），又是区域的认领者。移动一个种子不仅改变它与区域的邻接关系，还会改变螺旋本身的形状和区域划分。两者紧密耦合，无法分别独立求解。两步前瞻规则和"唯一认领"规则均需对比多个示例才能归纳。

## 新题 6：箭头朝向解码射线抢占着色

**组合逻辑**：[解码/横杆偏移定方向](创新：解码结果决定射线发射方向) → [射线延伸](创新：射线沿基数方向而非对角方向) → [碰撞阻挡](创新：射线遇障碍/其他射线终止，产生先到先得的空间竞争) → [重涂色](创新：障碍的最终颜色由首个到达的射线决定)

**来源原语**：箭头精灵、横杆偏移定方向、朝向对齐（参考题 689c358e）；射线延伸、射线路径（参考题 55783887、508bd3b6）；碰撞阻挡（参考题 05f2a901）；重涂色、边框端点（参考题 689c358e）；障碍物（参考题 9edfc990）

**依赖链**：横杆偏移 → 解码方向 → 射线路径 → 射线间的空间交叉和对障碍的先到关系 → 障碍着色和交叉点标记。多条射线形成空间竞争网络，每个障碍的颜色取决于所有射线的路径拓扑，而非单一射线。

读取每个 T 形箭头精灵的横杆偏移以确定指向方向，从箭头尖端发射射线，射线遇到障碍方块后将其染为射线颜色（先到先得），射线交叉点标记为特殊色。

**输入结构**：约 17x17 的黑(0)背景网格。网格中有 3~4 个 T 形箭头精灵，每个精灵由 6 个像素组成：一条 4 像素长的主杆和一条 3 像素长的横杆。横杆与主杆垂直，且横杆沿主杆方向偏移一个像素——偏向箭头的"尖端"方向。每个精灵使用互不相同的非黑颜色，取自 {蓝(1)、绿(3)、黄(4)、品红(6)、橙(7)}，不使用红(2)和灰(5)。另有 2~3 个灰(5) 2x2 实心方块作为障碍物，与精灵互不接触。生成约束：每个精灵的射线方向上至少有一个障碍或另一个精灵的射线路径可达。

**规则**：
1. 对每个 T 形精灵，确定指向方向：横杆相对于主杆中心偏移的那一侧就是箭头尖端方向。例如，主杆水平、横杆偏左 → 箭头指向左。
2. 确定每个精灵的"尖端像素"：主杆在指向方向上的端点像素。
3. 从每个精灵的尖端像素出发，沿指向方向（基数方向之一）逐像素发射射线，颜色为该精灵的颜色。
4. 射线终止条件（按优先级）：(a) 下一像素超出网格边界 → 终止；(b) 下一像素属于某灰(5)障碍 → 终止，该障碍被"命中"；(c) 下一像素已被另一条射线占据 → 终止，当前像素标记为红(2)（射线交叉）。
5. 射线同时发射（逻辑上按像素距离同步推进）：所有射线的第 1 步同时处理，再处理所有射线的第 2 步，以此类推。若同一步中两条射线到达同一像素，该像素标记为红(2)，两条射线均终止。
6. 障碍着色：若一个灰(5)障碍在整个过程中被命中过，将整个障碍（2x2）重涂为命中它的射线的颜色。若同一障碍被多条射线在同一步命中，重涂为其中颜色在输入网格中出现位置最靠左上（行优先列次之）的精灵颜色。未被命中的障碍保持灰(5)。
7. 精灵自身保持不变。

**关键洞察**：每个精灵的内部几何结构（横杆偏移方向）编码了射线发射方向；多条射线在空间中形成竞争网络——障碍的最终颜色取决于哪条射线先到达它，而"先到"取决于所有射线的路径长度和方向。精灵 A 的射线可能被精灵 B 的射线挡住，从而永远到达不了某个障碍。需对比多个示例确认同步发射机制和交叉标记规则。

## 新题 7：对称差异异或掩码循环着色

**组合逻辑**：[镜像](创新：用于空间对齐而非显示) → [异或合成](创新：提取两形状的对称差异作为填色画布) → [循环填充](创新：沿行主序对异或掩码像素循环着色，run-length 由灰色标记高度决定)

**来源原语**：镜像、镜像对应、分隔列（参考题 dd2401ed、c9680e90）；异或合成、半区掩码、恰一为前景、对齐（参考题 31d5ba1a）；循环填充、调色板列、长度标记段、标记高度决定长度、顺序排列（参考题 e7b06bea）

**依赖链**：镜像对齐 → 异或运算确定掩码形状（哪些像素构成画布） → 灰色标记段高度确定 run-length → 调色板确定颜色序列 → 循环填充将颜色按 run-length 铺到掩码像素上。异或结果的形状决定了循环填充的总量和分布；run-length 影响颜色切换频率。

将左右半区的前景形状对齐后取对称差异作为画布，用从灰色标记段读取的 run-length 和调色板颜色对画布像素进行循环着色。

**输入结构**：约 14x25 的网格（宽大于高）。正中有一列灰(5)垂直分隔列。左半区：蓝(1)像素构成一个不规则前景形状（15~30 像素，4-连通），黑(0)背景。右半区：绿(3)像素构成另一个不规则前景形状，黑(0)背景。灰色分隔列的顶部连续 h 个像素为灰(5)（h 取值 1~4，不同示例不同），其下方像素为黑(0)。两个形状水平镜像后部分重叠、部分不重叠（即它们既非完全相同也非完全不相交）。生成约束：对称差异（异或）掩码至少有 8 个像素。

**规则**：
1. 将右半区（不含分隔列）水平翻转，使其与左半区空间对齐。
2. 逐像素分类：若某位置仅在左半区为前景（蓝）且翻转后右半区为背景 → "左独有"；仅在翻转右半区为前景（绿）且左半区为背景 → "右独有"；两者均为前景或均为背景 → 排除。被分类为"左独有"或"右独有"的像素共同构成"异或掩码"。
3. 读取调色板为 [蓝(1), 绿(3)]（即左半区和右半区各自的前景色，按左先右后的顺序）。
4. 读取灰色分隔列顶部连续灰(5)像素的数量 h，作为循环填充的 run-length。
5. 将异或掩码中的像素按行主序排列（第 0 行从左到右，然后第 1 行从左到右，依次类推）。按此顺序，依次为每个掩码像素分配颜色：前 h 个像素着蓝(1)，接下来 h 个着绿(3)，再 h 个着蓝(1)，如此循环直至所有掩码像素着色完毕。
6. 输出一个半区大小的画布，包含着色后的异或掩码像素，其余位置为黑(0)。

**关键洞察**：输出画布的形状由两个前景形状的对称差异决定（既非并集也非交集），而每个像素的颜色由其在掩码中的行主序位置和 run-length 参数共同决定。异或选择规则（而非并集或交集）需对比多个示例才能确认；灰标记段高度编码 run-length 也需对比确认。

## 新题 8：循迹迁移入仓后洪泛比面积

**组合逻辑**：[沿路径移动](创新：路径终点决定种子进入哪个封闭仓室) → [洪泛填充](创新：种子在新位置向仓室内部扩散) → [计数](创新：统计每个种子的填充面积) → [重涂色](创新：面积最大者获得特殊颜色)

**来源原语**：沿路径移动、轨迹路径、标记像素（参考题 c9680e90）；洪泛填充、种子像素、四邻连通、种子沿连通域扩散、障碍物（参考题 9edfc990）；计数、频率统计（参考题 81c0276b）；重涂色（参考题 639f5a19）

**依赖链**：路径追踪 → 种子迁移到仓室内部 → 洪泛填充确定每个种子的领地面积 → 面积比较确定最大者 → 最大者整片重涂为特殊色。路径终点决定种子位于哪个仓室，仓室大小决定填充面积，面积决定重涂。删除路径移动则不知道种子在哪里；删除洪泛则不知道面积；删除面积比较则不知道谁获胜。

每个彩色种子沿灰色轨迹移入对应仓室，在仓室内洪泛扩散，面积最大的种子连同其领地被重涂为青色。

**输入结构**：约 16x16 的黑(0)背景网格。网格中有橙(7)像素构成的墙壁，将网格内部分隔为 3~5 个互不相通的封闭仓室（每个仓室是被橙色墙壁和网格边界围合的 4-连通黑色区域，面积各不相同，范围约 6~25 像素）。在仓室外部（墙壁和网格边界之间的区域或网格边缘处），有 3~4 个彩色种子像素（各占 1 像素，颜色互不相同，取自 {蓝(1)、红(2)、绿(3)、黄(4)}），每个种子通过一条 4-连通灰(5)轨迹路径连向某个仓室的入口。灰色轨迹的每个像素最多有 2 个灰色 4-邻居，形成无分叉的单一路径。轨迹的一端与种子 4-邻接，另一端与某仓室内部的黑色像素 4-邻接（即轨迹穿过墙壁的缺口通向仓室内部）。生成约束：(a) 每个种子的轨迹通向不同的仓室；(b) 仓室面积互不相同。

**规则**：
1. 对每个种子像素，从种子出发沿其 4-连通灰(5)轨迹行进（每步选择灰色邻居中未访问过的那个），直到到达轨迹末端——即与仓室内黑色像素 4-邻接的灰色像素。该灰色末端像素的 4-邻居中唯一的黑色仓室像素即为"目标位置"。
2. 将种子移至目标位置（目标位置涂为种子颜色）。擦除种子原位置（设为黑(0)）和整条灰色轨迹（所有灰色像素设为黑(0)）。
3. 从每个已迁移种子的新位置出发，在其所在仓室内进行洪泛填充：沿 4-连通方向扩散，将可达的黑(0)像素涂为该种子颜色。橙(7)墙壁阻止扩散。
4. 统计每个种子填充的总面积（包括种子自身所在的那个像素）。
5. 面积最大的种子及其全部填充区域被重涂为青(8)。其他种子及其填充区域保持各自的原色不变。
6. 橙(7)墙壁保持不变。

**关键洞察**：轨迹将种子"导航"到不同的仓室中——哪个种子去哪个仓室完全由轨迹决定，不能从颜色或位置直接推断。仓室面积决定"获胜者"，但仓室面积只有在洪泛填充后才能确定（因为仓室形状不规则）。最大面积→青色的规则需对比多个示例归纳。
