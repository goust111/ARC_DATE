## 新题 1：空腔约束折叠拼图

**组合逻辑**：[折叠/fold](创新：折叠方向由目标空腔尺寸反向决定，而非空间大侧) + [嵌入填充/inlay_fill] + [尺寸匹配/size_matching](创新：匹配发生在折叠后而非原始尺寸)

**来源原语**：fold、hinge_marker、fixed_vs_free、fold_toward_space（来自 230f2e48）；inlay_fill、template_frame、rectangular_cavity、size_matching、unique_slot_pairing（来自 5dbc8537）

**依赖链**：折叠方向无法仅靠铰接标记和空间关系确定——必须先枚举两种折叠方向，再检查哪个方向的折叠结果在包围盒尺寸上恰好匹配某一空腔；匹配完成后才能执行嵌入填充。折叠操作的参数由尺寸匹配约束反向确定，三者形成同时约束满足关系而非线性流水线。

将带铰接标记的 L 形碎片折叠后嵌入模板空腔，折叠方向由空腔尺寸唯一确定。

**输入结构**：
- 网格约 20x20，背景黑(0)。
- 网格中央有一个绿(3)大型模板形状（单色 4-连通区域，占网格约 40%-50%），模板内部含 3-4 个矩形空腔（黑(0)背景的矩形区域，宽高比各不相同，如 2x5、4x3、3x3 等）。
- 模板外围分散着 3-4 个蓝(1)的碎片，每个碎片是由 6-10 个蓝(1)像素构成的 4-连通不规则形状（非矩形，呈 L 形或 T 形弯折结构），碎片之间互不相邻。
- 每个碎片的弯折处恰好有一个红(2)铰接标记像素，标记两臂的交汇点。碎片的一臂末端有一个灰(5)端点标记像素，表示固定臂。另一臂无端点标记，为自由臂。
- 生成约束：每个碎片恰好存在一种折叠方向（顺时针或逆时针 90 度），使折叠后碎片的包围盒尺寸匹配恰好一个空腔的尺寸，且这种配对在所有碎片-空腔之间构成一一映射。

**规则**：
1. 对每个碎片，灰(5)端点标记所在的臂为固定臂，保持不动。红(2)铰接标记为旋转中心。
2. 将自由臂（铰接标记另一侧的所有蓝(1)像素）绕铰接标记旋转 90 度。旋转方向（顺时针或逆时针）选择使折叠后碎片包围盒（包含所有蓝(1)像素和红(2)铰接像素、不含灰(5)端点标记）的宽x高恰好匹配某一空腔尺寸的方向。
3. 将折叠后的碎片（蓝(1)像素和红(2)铰接像素）放入与其包围盒尺寸匹配的唯一空腔中，左上角对齐空腔左上角。灰(5)端点标记不参与放置。
4. 输出为模板的包围盒区域：绿(3)模板像素保留，所有空腔被填入对应碎片，未被碎片覆盖的空腔像素保持黑(0)。

**关键洞察**：折叠方向不是由周围空间决定（源题逻辑），而是由目标空腔的几何尺寸反向约束——求解者必须同时考虑折叠几何和空腔匹配，形成一道约束满足问题而非顺序执行。

## 新题 2：逻辑或非生成密度种子的区域筛选

**组合逻辑**：[逻辑运算/logical_op](NOR) → [计数/counting] → [筛选/filtering] + [洪泛填充/flood_fill]（创新：NOR 输出作为密度度量的输入，而非最终结果）

**来源原语**：logical_op、binary_mask、pixelwise_correspond、logical_NOR_combine（来自 1b2d62fb）；counting、flood_fill、filtering、partitioned_region、separator_line、densest_region_kept_filled（来自 29623171）

**依赖链**：NOR 运算的结果不是最终输出，而是中间掩模；对该掩模做逐区域计数才能决定哪些区域存活；存活区域的填充颜色由其内部两个掩模中像素较少的那个颜色决定。三步之间信息层层变换：逻辑运算→统计度量→空间筛选。

在分隔线划分的区域内，对每个区域的两色掩模做 NOR，以 NOR 空穴数最多的区域为胜者，用其少数色填充。

**输入结构**：
- 网格约 15x15，背景黑(0)。
- 黄(4)全宽行和全高列各 1 条，将网格分为 4 个矩形区域（2x2 布局）。黄(4)行列在交叉处重合。
- 每个区域内散布着恰好两种前景色的像素（从红(2)、蓝(1)、绿(3)、橙(7)中取两种，四个区域可使用不同的颜色对）。每种颜色在区域内有 3-8 个散布像素，形成一个二值掩模。同一区域内两种颜色的像素不重叠。
- 生成约束：四个区域的 NOR 空穴数（区域内两色掩模均为 0 的非背景内格数量）互不相同，保证唯一最大值。

**规则**：
1. 识别黄(4)分隔行/列，提取 4 个矩形区域（不含分隔线本身的像素）。
2. 对每个区域：取其两种前景色分别形成二值掩模 M_a 和 M_b（前景色位置为 1，其余为 0）。
3. 逐像素计算 NOR(M_a, M_b)：当且仅当该位置 M_a=0 且 M_b=0 时结果为 1。统计每个区域的 NOR=1 像素总数 N_nor。
4. 保留 N_nor 最大的区域（唯一）；其余三个区域所有像素清为黑(0)。
5. 对存活区域：统计其两种前景色的像素数，将整个区域（包括原黑(0)背景位置）填充为像素数较少的那种颜色。原两种前景像素均被覆盖。
6. 黄(4)分隔行/列保持不变。

**关键洞察**：NOR 空穴多意味着该区域"两色覆盖最稀疏"——但稀疏不等于颜色少，而是两色在空间上留下的联合空白最大。选出该区域后，填充色取决于区域内的少数色，又引入一次统计判断。必须对比多个示例才能确认存活条件是 NOR 最大而非简单的"前景像素最少"。

## 新题 3：碎片合并后缺口定向镜像补全

**组合逻辑**：[合并对齐碎片/merge_aligned_fragments] → [镜像/reflect](创新：反射轴由缺口方位动态确定) → [射线延伸/ray_extend]

**来源原语**：complete、fragmented_rectangle、connected_component、span_overlap、merge_aligned_fragments（来自 8fbca751）；reflect、mono_mask、bounding_box、per_color_transform、flip_within_bbox（来自 e74e1818）；ray_extend、one_gap_rect_frame、gap_pixel、gap_determines_ray（来自 292dd178）

**依赖链**：碎片合并确定矩形框的完整边界→完整边界暴露唯一缺口→缺口所在侧确定镜像轴（垂直于缺口侧的框中心线）→镜像操作补全框内图案→缺口同时确定射线方向。前一步的几何输出是后一步的参数，不可跳过。

将分散碎片合并还原为带缺口的矩形框，缺口方位同时决定内部图案的镜像轴和向外射线方向。

**输入结构**：
- 网格约 18x18，背景黑(0)。
- 青(8)像素形成 2-3 组碎片。每组碎片在合并后构成一个矩形框边界（宽高均>=5），但每个框被断裂为 2-3 个 4-连通碎片。同组碎片的包围盒在行跨度或列跨度上有重叠，不同组的碎片包围盒在行列跨度上均无重叠。
- 每个合并后的矩形框恰好有一个非角落边界像素缺失（缺口）。
- 每个框的内部（框边界所围区域，不含边界本身），在缺口对面一侧的半区包含一个由红(2)像素构成的小型不对称图案（2-4 像素，4-连通）；缺口同侧的半区为空（黑(0)）。"半区"以垂直于缺口所在侧的框中心线为界。
- 不同框的缺口位于不同侧（上/下/左/右），不同示例中同一框的缺口位置可能变化。

**规则**：
1. 找到所有青(8)4-连通碎片。
2. 当两个碎片的包围盒在行跨度或列跨度上有重叠时，将它们归为同组；传递合并直到无法继续。
3. 对每组碎片，计算包含所有碎片像素的最小包围盒，该包围盒的边界像素集即为理想矩形框边界。
4. 在理想边界像素中找到唯一缺失的非角落像素——即缺口。记录缺口所在侧（上/下/左/右）。
5. 确定镜像轴：穿过框中心、垂直于缺口所在侧的直线。若缺口在上或下侧，则镜像轴为水平中心线；若缺口在左或右侧，则镜像轴为垂直中心线。
6. 将框内部的红(2)图案沿该镜像轴反射到对侧半区，生成镜像副本（同为红(2)）。原图案保留。
7. 将缺口像素填为橙(7)，并从缺口位置向框外沿缺口法线方向（指向远离框内部的方向）延伸一条橙(7)射线，直到网格边缘（含边缘像素）。
8. 青(8)框边界（含合并后的完整边界）保持不变。

**关键洞察**：碎片在空间上断裂，必须先通过行列跨度重叠关系还原出完整框的形状，才能发现缺口的位置。而缺口同时承担两个角色：它决定了内部图案的镜像轴方向（用于补全框内内容），也决定了外部射线的延伸方向（用于标记框与边界的连接）。

## 新题 4：嵌入计数驱动的印章重复与奇偶重涂色

**组合逻辑**：[计数/counting](创新：计数结果决定印章重复次数而非膨胀距离) → [印章覆盖/stamp_overlay] → [重涂色/recolor + 交替选取/alternating_selection]

**来源原语**：stamp_overlay、sprite、control_pixel、anchor_pixel、relative_coord_copy、strongest_adj_anchor（来自 f5c89df1）；counting、embedded_marker_count、count_determines_expansion（来自 52fd389e）；recolor、alternating_selection、parity_position_recolor（来自 d406998b）

**依赖链**：控制像素的计数决定印章重复次数 N→印章操作在每个目标处生成 N 个副本→副本的序号奇偶性决定其重涂色方案。计数结果既参数化了空间操作（重复次数），又间接参数化了颜色操作（奇偶交替的周期由 N 隐式界定）。

统计精灵体内嵌控制像素数 N，在每个目标位置沿最大空间方向印章 N 次，奇数副本保持原色、偶数副本涂为控制色。

**输入结构**：
- 网格约 20x20，背景黑(0)。
- 网格左上角区域有一个蓝(1)4-连通精灵体（4-7 个蓝(1)像素，不规则形状）。精灵体内部混有 1-3 个绿(3)控制像素（与蓝(1)像素 4-邻接，属于同一连通体的一部分）。
- 精灵体外部紧邻一个红(2)锚点像素：在所有与精灵体 4-邻接的非精灵体像素中，红(2)锚点像素是唯一一个与最多蓝(1)像素 4-相邻的像素。
- 网格其余位置分散有 2-3 个孤立的橙(7)目标标记像素，彼此及与精灵体之间的距离 >= 精灵体包围盒的最大边长 x 3。
- 生成约束：每个目标像素至少在一个基本方向（上/下/左/右）上，到网格边缘的距离 >= 精灵体包围盒对应维度 x N（N 为绿色控制像素数量），以保证有足够空间放置 N 个副本。

**规则**：
1. 统计精灵体内绿(3)控制像素数量，记为 N。
2. 计算精灵体所有蓝(1)和绿(3)像素相对于红(2)锚点的坐标偏移集合 S。
3. 对每个橙(7)目标标记：
   a. 检查目标像素在上/下/左/右四个基本方向上到网格边缘的距离，选距离最大的方向为印章延伸方向。若两个方向距离相同，优先选列方向（上或下），再按上优先于下、左优先于右的顺序决定。
   b. 沿该方向依次放置 N 个精灵体副本。第 k 个副本（k=1,2,...,N）的锚点位置 = 目标像素位置 + (k-1) x 精灵体包围盒在延伸方向上的尺寸 x 延伸方向单位向量。
   c. 第 1、3、5...（奇数序号）副本中，蓝(1)像素保持蓝(1)、绿(3)像素保持绿(3)。
   d. 第 2、4、6...（偶数序号）副本中，蓝(1)像素重涂为绿(3)、绿(3)像素保持绿(3)（即整个副本变为全绿）。
4. 擦除原精灵体（蓝(1)和绿(3)）、红(2)锚点和所有橙(7)目标标记。背景保持黑(0)。
5. 若不同副本发生像素重叠，后放置（序号更大）的副本覆盖先放置的。

**关键洞察**：绿(3)控制像素承担双重角色——其数量决定印章重复次数，其颜色定义偶数副本的重涂色目标。不统计控制像素就无法知道重复次数，不识别其颜色就无法确定偶数副本的涂色方案。印章延伸方向由目标点的空间位置动态决定（非固定方向），需对比多个示例中不同目标的延伸方向才能归纳规则。

## 新题 5：三点框补全后标记位置编码膨胀距离

**组合逻辑**：[补全/complete + 三点定矩形框/three_pts_define_rect] → [计数/counting](创新：统计标记落在补全后框的角位还是边位) → [扩展填充/expansion_fill]

**来源原语**：complete、marker_pixel、hollow_rect、bounding_box、three_pts_define_rect（来自 e7639916）；counting、embedded_marker_count、count_determines_expansion（来自 52fd389e）；expansion_fill、dilate（来自 52fd389e）

**依赖链**：三点标记的包围盒定义矩形框→补全框后才能判断每个标记是在角位还是边位→角位标记的数量 C 成为膨胀距离→膨胀操作的参数由补全结果和计数结果共同确定。存在隐式循环依赖：补全框需要标记位置，而标记位置的语义（角/边）又依赖于补全后的框形状。

以三个同色标记像素确定矩形框，补全后统计落在角位的标记数，以此为膨胀距离向外扩展灰色外框。

**输入结构**：
- 网格约 16x16，背景黑(0)。
- 网格中有 2-3 组标记像素，每组恰好 3 个同色标记（如一组红(2)、一组蓝(1)、一组绿(3)）。
- 每组的 3 个标记像素位于它们共享包围盒的边界上（即每个标记的行坐标等于包围盒的顶行或底行，或列坐标等于包围盒的左列或右列，或两者皆是）。
- 不同组的包围盒互不重叠，且在各方向上间隔至少 4 像素（为膨胀留出空间）。
- 生成约束：同组 3 个标记中，落在包围盒角位（行坐标为顶或底 且 列坐标为左或右）的数量 C 在 0-3 之间，不同组的 C 值可以不同。

**规则**：
1. 对每种前景色，找到该色的 3 个标记像素，计算它们的最小包围盒。
2. 沿包围盒四边画该前景色的空心矩形框（单像素宽），同时保留原始 3 个标记像素（它们已在框边界上，不需额外处理）。
3. 检查原始 3 个标记像素各自是否在包围盒的角位（行坐标 = 顶行或底行，且列坐标 = 左列或右列）。统计角位标记数量 C。
4. 若 C >= 1，在已画好的前景色框外围，向四边各扩展 C 像素，画一个灰(5)空心矩形框（单像素宽）。灰框的上边 = 前景色框上边 - C，下边 = 前景色框下边 + C，左边同理，右边同理。
5. 若 C = 0，不画灰(5)外框。
6. 前景色内框和灰(5)外框之间的区域保持黑(0)背景。

**关键洞察**：仅靠三个标记无法直接判断它们是角位还是边位——必须先补全矩形框得到完整边界，再回头检查每个标记在框上的位置类型。同样的三点配置在不同尺寸的包围盒下角位/边位判定完全不同，求解者必须对比多个示例才能确认"角位数量 = 膨胀距离"这一编码规则。

## 新题 6：种子条纹在标记线处分裂与颜色互换镜像

**组合逻辑**：[平铺/tiling + 种子定条纹周期/seed_sets_stripe_period] → [镜像/reflect + 跨标记线反射/reflect_across_markers](创新：标记线同时充当条纹裁剪边界、反射轴和颜色互换触发器) → [重涂色/recolor]

**来源原语**：tiling、seed_pixel、stripe、array_layout、seed_sets_stripe_period（来自 0a938d79）；reflect、sparse_marker_line、foreground_motif、parallel_axes、reflect_across_markers（来自 66ac4c3b）；recolor、parity_position_recolor（来自 d406998b）

**依赖链**：种子像素确定条纹周期和方向→条纹在整个网格生成→标记列将网格一分为二→种子侧保留原始条纹→另一侧为条纹的镜像加颜色互换。标记列的三重角色（裁剪边界、反射轴、颜色互换触发）在任何源题中都不存在。

两个种子像素生成周期条纹图案，稀疏标记列将网格一分为二：种子侧保留原色条纹，另一侧为条纹的镜像并交换两种种子色。

**输入结构**：
- 网格约 15x20（15 行 20 列），背景黑(0)。
- 网格左边缘（第 0 列）上有两个种子像素：一个红(2)、一个蓝(1)，位于不同行（如第 3 行和第 7 行）。两个种子之间行间距 d >= 2。
- 网格中部偏右有一条稀疏灰(5)标记列（某固定列 c，其中 c 约在第 10-14 列之间）：该列中每隔一行有一个灰(5)像素（如行号为偶数的位置为灰(5)，行号为奇数的位置为黑(0)），形成稀疏分布。
- 除种子像素和灰标记像素外，其余全为黑(0)。

**规则**：
1. 两个种子像素确定水平条纹图案：过红(2)种子所在行画一条全宽红(2)行，过蓝(1)种子所在行画一条全宽蓝(1)行。
2. 条纹周期 = 2 x |红种子行 - 蓝种子行|。以红蓝两行为起始，沿垂直方向以此周期重复：每个周期内，与红种子同相位的行为红(2)，与蓝种子同相位的行为蓝(1)，其余行保持黑(0)。
3. 以灰(5)标记列为分界：标记列左侧（含标记列所在列）保留步骤 1-2 生成的原始条纹。
4. 标记列右侧：将左侧条纹图案以标记列为轴左右镜像，同时将红(2)和蓝(1)互换——即原红(2)条纹行在右侧变为蓝(1)，原蓝(1)条纹行在右侧变为红(2)。
5. 灰(5)标记列上的灰(5)像素保持不变，该列中原为黑(0)的位置保持黑(0)（不受条纹影响）。
6. 条纹仅画在非灰标记位置上——若某位置原为灰(5)标记像素，该位置保持灰(5)不被条纹覆盖。

**关键洞察**：灰标记列不是简单的分隔线——它同时扮演三个角色：(1) 条纹的空间裁剪边界，(2) 镜像操作的对称轴，(3) 颜色互换的触发分界。种子间距决定条纹周期，标记列位置决定对称结构。必须看多个示例（种子位置和标记列位置不同）才能归纳出"右侧 = 镜像 + 换色"的完整规则。

## 新题 7：最近种子分区决定逐区域翻转轴

**组合逻辑**：[最近扩散/nearest_fill](创新：分区结果不用于填色，而用于选择变换类型) → [镜像/reflect + 逐色独立变换/per_color_transform](创新：翻转轴由所属种子方位决定而非固定)

**来源原语**：nearest_fill、seed_bar、marker_column、nearest_seed_part、equidist_diff_sep（来自 332202d5）；reflect、mono_mask、bounding_box、per_color_transform、flip_within_bbox（来自 e74e1818）；majority_vote、two_partitions（来自 27a77e38）

**依赖链**：种子条的位置决定最近种子分区→每个区域被分配到其最近的种子条→所属种子条的方向（水平或垂直）决定该区域内图案的翻转轴方向→翻转操作在每个区域内独立执行。分区结构直接控制几何变换的参数，这种"分区选变换"的关系在源题中不存在。

水平和垂直种子条将网格分为若干区域，每个区域内的图案按其最近种子条的方向翻转：近水平条者垂直翻转，近垂直条者水平翻转。

**输入结构**：
- 网格约 16x16，背景黑(0)。
- 一条水平红(2)种子条（全宽单行），位于网格上方约 1/4 处。
- 一条垂直蓝(1)种子条（全高单列），位于网格左方约 1/4 处。
- 两条种子条交叉于一个像素位置，该交叉像素为黄(4)。
- 两条种子条将网格大致分为 4 个象限区域（左上较小，右下较大）。
- 每个象限内有一个由绿(3)像素构成的小型不对称图案（3-5 个 4-连通像素，上下不对称且左右不对称），图案完全在该象限内部，不触及种子条。
- 生成约束：每个图案的包围盒在翻转后仍在其所在象限内部。

**规则**：
1. 对网格中每个非种子条像素，计算其到水平红(2)条的曼哈顿距离 d_h 和到垂直蓝(1)条的曼哈顿距离 d_v。
2. 若 d_h < d_v，该像素属于水平条的势力范围；若 d_v < d_h，属于垂直条的势力范围；若 d_h = d_v，该像素变为黄(4)分界像素。
3. 属于水平红(2)条势力范围的区域：将其中的绿(3)图案在图案自身的包围盒内做垂直翻转（上下翻转，即行坐标 r 变为 r_top + r_bottom - r）。
4. 属于垂直蓝(1)条势力范围的区域：将其中的绿(3)图案在图案自身的包围盒内做水平翻转（左右翻转，即列坐标 c 变为 c_left + c_right - c）。
5. 保留所有红(2)种子条像素、蓝(1)种子条像素、黄(4)交叉和分界像素。
6. 翻转后的绿(3)像素若与原绿(3)像素位置不同，则原位置清为黑(0)，新位置画绿(3)。

**关键洞察**：变换不是全局统一的——同一网格中不同区域的图案分别做不同方向的翻转，翻转方向由其"所属种子条"决定。等距分界线不只是视觉装饰，而是两种变换规则的真实边界。在种子条位置变化的不同示例中，同一象限可能归属不同种子条，导致翻转方向改变——必须对比才能归纳。

## 新题 8：等距分界驱动的分区多数投票压缩

**组合逻辑**：[最近扩散/nearest_fill + 等距异色为分隔/equidist_diff_sep](创新：等距行成为压缩网格的分隔线而非仅标记色) → [多数投票/majority_vote](创新：投票在动态分区内执行而非预定义区域) → [压缩/compress]

**来源原语**：nearest_fill、seed_bar、nearest_seed_part、equidist_diff_sep（来自 332202d5）；majority_vote、two_partitions、most_freq_color_to_center（来自 27a77e38）；compress、tile、grid_partitioning、ignore_marker_dominant（来自 5614dbcf）

**依赖链**：种子条的位置和间距决定最近分区和等距分界行→等距分界行将网格切为不等高的条带→每个条带内做多数投票得出一个颜色→压缩为每条带一行输出。分区边界由种子条动态生成（非预设网格），投票区域由分区边界定义（非预设分区），压缩比由条带高度隐式决定（非固定倍率）。三者环环相扣，任一步的结果都是下一步的输入前提。

种子条的最近分区产生不等高条带，等距异色行成为分界，每条带内多数投票得出一个颜色，最终压缩为每条带一行。

**输入结构**：
- 网格约 20x12（20 行 12 列），背景黑(0)。
- 3-4 条水平种子条（全宽单行），分别为不同颜色（从红(2)、蓝(1)、绿(3)、橙(7)中选取），不等距分布在网格各行（如第 2 行、第 8 行、第 15 行）。
- 种子条之间的行中散布着各色像素（从红(2)、蓝(1)、绿(3)、橙(7)、品红(6)中随机选取，每行 1-4 个前景像素），这些散布像素不包含种子条使用的颜色。
- 生成约束：相邻种子条若颜色不同，则其间存在唯一一行等距行（到两条种子条行距相等）；若颜色相同，等距行归入分区，不成为分界。每个非分界条带内，散布像素中恰有一种颜色出现次数最多（无平局）。

**规则**：
1. 找到所有种子条（全宽单色非黑行）。
2. 对每个非种子行，计算到最近种子条的行距。若最近的两条种子条颜色不同且行距相等，该行成为灰(5)分界行。否则该行属于最近种子条的分区。
3. 灰(5)分界行和种子条行共同将网格切分为若干条带。每个条带由连续的非分界、非种子行组成。
4. 对每个条带，统计其内所有非黑散布像素的颜色频率，取出现次数最多的颜色作为该条带的投票结果颜色。
5. 输出为压缩网格：每个条带压缩为一行，该行全部填充投票结果颜色。每条种子条压缩为一行，保留其原色。每条灰(5)分界行压缩为一行灰(5)。条带从上到下的顺序保持不变。
6. 输出网格的列数与输入相同（等于 12），行数 = 条带数 + 种子条数 + 分界行数。

**关键洞察**：压缩的"块"不是固定的 NxN 网格分块，而是由种子条位置和等距规则动态生成的不等高条带。等距分界行仅在相邻种子颜色不同时出现，这意味着种子颜色既影响分区归属，也影响分界线的产生。求解者必须对比种子颜色相同和不同的情况才能归纳分界规则。
