## 新题 1：射线路径交集掩码

**组合逻辑**：[射线延伸 + 反弹](已有) → [逐像素比较](已有，创新：比较对象从静态掩码变为动态生成的路径掩码) → [逻辑交](已有，创新：输入不是预设的两半掩码而是射线追踪的结果)

**来源原语**：射线延伸/ray_cast、反弹/bounce、碰撞停止/collision_stop（来自 142ca369）；逻辑交/logical_AND、逐像素比较/per_pixel_comparison、双掩码重叠标记/both_mask_overlap（来自 0520fde7）；墙壁像素/wall_pixel（来自 142ca369）

**依赖链**：射线追踪生成两条动态路径掩码 → 逐像素比较取交集 → 只有双路径重叠处着色。射线的反弹改变路径几何，间接决定交集的形状和位置；不追踪完整路径就无法计算交集，不做交集则无法确定输出颜色。

从两个箭头发射对角射线并沿墙壁反弹，输出仅保留两条射线路径的像素级交集。

**输入结构**：约 15x15 的黑(0)背景网格。恰好两个不同颜色的 2x2 缺角 L 形箭头精灵体（3 像素，各占 2x2 边界框的三个角；两个箭头颜色分别为蓝(1)和绿(3)）。网格上散布 3-6 个单像素墙壁，每个墙壁像素有各自的颜色（红(2)、黄(4)、灰(5)等，不与箭头颜色重复）。两个箭头的缺角方向不同，使射线朝不同对角方向发射。墙壁的位置保证两条射线的完整路径（含反弹段）至少有 2 个像素位置重合。箭头之间、箭头与墙壁之间互不相邻。

**规则**：
1. 对每个箭头，确定其缺角方向，从缺角相邻的对角方向发射射线。射线逐格沿对角方向前进，将经过的背景格记录为"已访问"。
2. 射线碰到墙壁像素时按 142ca369 的规则反弹（正面碰撞翻转两轴，侧面碰撞翻转被接触的轴），射线继续前进。反弹不改变"已访问"记录方式，碰撞点本身也计入该射线的已访问集合。
3. 射线在离开网格边界、或碰到另一个箭头精灵体的任一像素时停止。
4. 分别得到两条射线的已访问像素集合 S1 和 S2。
5. 输出与输入同尺寸的网格：S1 与 S2 的交集像素（同时被两条射线访问的格子）着红(2)色，其余所有格子（包括箭头、墙壁、仅被单条射线访问的格子）保持黑(0)背景。

**关键洞察**：输出不是射线的可见路径，而是两条路径的几何交集；墙壁位置通过改变反弹角度间接控制交集区域的形状，需要完整追踪两条路径后才能确定哪些像素同时被访问。

## 新题 2：拓扑驱动的重力分拣

**组合逻辑**：[计数·孔洞](已有) → [重力下落](已有，创新：下落/穿透行为由孔洞数而非宽度决定) + [重涂色](已有，创新：颜色来源是拓扑属性而非静态图例)

**来源原语**：重力下落/gravity_drop、分隔行/divider_row、穿透与停靠/pass_through_or_stop、宽度决定行为/width_determines_behavior（来自 84ba50d3）；计数/counting、重涂色/recolor、封闭区域/enclosed_region、颜色图例/color_legend、孔洞数映射颜色/hole_count_to_color_mapping（来自 e3721c99）

**依赖链**：对每个精灵体计数孔洞 → 孔洞数同时决定两件事：(a) 该精灵体是穿透分隔行落到底部还是停在分隔行上方，(b) 该精灵体的最终颜色。两个决策共享同一个拓扑属性，删除计数环节则既无法确定位置也无法确定颜色。

统计每个悬浮精灵体的孔洞数，据此决定它在重力下落时穿透还是停靠，并依图例重涂颜色。

**输入结构**：约 18x12 的黑(0)背景网格。一条完整的橙(7)水平分隔行横跨网格中下部。分隔行上方散布 3-5 个灰(5)的 4-连通精灵体（各 8-20 像素，形状各异——有的实心无孔，有的包围 1 个背景孔洞，有的包围 2 个背景孔洞）。网格左下角或右下角有一个小的颜色图例区域：2-3 个小色块（如蓝(1)、红(2)、绿(3)），每个色块自身分别包围 0、1、2 个孔洞，以此表示"孔洞数 → 颜色"映射。各精灵体互不相邻，精灵体与分隔行之间至少有 1 行间隔。生成时保证无两个精灵体在同一列范围内上下重叠（避免下落路径冲突）。

**规则**：
1. 从图例区域识别颜色映射：统计每个图例色块的孔洞数 h，建立映射 h → 颜色。
2. 对每个灰色精灵体，统计其内部封闭的背景孔洞数（孔洞定义：不与精灵体边界框外部黑色区域 4-连通的背景连通分量）。
3. 孔洞数为 0 的精灵体穿透分隔行，整体向下平移直到精灵体最低行抵达网格底行；穿透时擦除被精灵体覆盖的分隔行像素。
4. 孔洞数 >= 1 的精灵体不穿透，整体向下平移直到精灵体最低行紧贴分隔行上方一行停止。
5. 所有精灵体到达最终位置后，按步骤 1 的映射将灰色重涂为对应颜色。图例区域在输出中擦除为背景。
6. 分隔行中未被穿透精灵体擦除的像素保持橙(7)不变。

**关键洞察**：精灵体的空间去向（穿透 vs 停靠）和最终颜色都由同一个拓扑属性——孔洞数——决定，而非其宽度或面积；图例色块自身的孔洞数即为映射键，需要对比多个示例才能确认这一编码方式。

## 新题 3：贪心方块提取排序条

**组合逻辑**：[区域提取 + 贪心选择](已有) → [裁剪](已有) → [排序 + 拼接](已有，创新：排序对象不是预存精灵体而是从空间贪心过程涌现的方块集)

**来源原语**：区域提取/region_extract、贪心选择/greedy_selection、非重叠约束/non_overlapping_constraint、从大到小优先/largest_first_priority、最小边长约束/minimum_side_length_constraint（来自 31adaf00）；排序/sort、面积排序/area_ordering、基线对齐排列/baseline_aligned_pack、拼接/concatenate（来自 4df5b0ae）；裁剪/crop（来自 ae4f1146, bc1d5164）

**依赖链**：贪心选择确定哪些方块存活 → 裁剪将方块从空间中提取 → 按面积排序并底部对齐拼接成输出条。贪心的遮挡顺序决定小方块能否存活，直接影响排序结果的元素集合；不做贪心选择就不知道有哪些方块可排序，不排序拼接就无法生成最终输出。

在障碍物之间贪心选取最大不重叠黑色方块，再将选中方块按面积升序底部对齐排成一行输出。

**输入结构**：约 16x16 的黑(0)背景网格，其上散布 15-25 个灰(5)单像素障碍物，形成不规则屏障。障碍物的布局保证至少存在 4 个边长 >= 2 的全黑正方形区域，且其中至少两个在空间上部分重叠（共享若干黑色格子），使得贪心选择顺序影响最终集合。

**规则**：
1. 扫描网格，枚举所有全黑（不含障碍物）的正方形区域，要求边长 >= 2。
2. 按边长从大到小排序候选方块。边长相同时，按左上角坐标从上到下、从左到右排序（行优先）。
3. 依次选取候选方块：若该方块与已选中的任何方块没有像素重叠，则选中它；否则跳过。
4. 对每个选中的方块，裁剪其边界框区域，将内部全部填充为蓝(1)色，生成一个边长 x 边长的蓝色小方块图块。
5. 将所有图块按边长从小到大排列。边长相同的图块按它们在输入网格中左上角的列坐标升序排列。
6. 从左到右拼接，每个图块底边对齐到同一行。图块之间无间隔。输出网格的高度等于最大图块的边长，宽度等于所有图块边长之和。空余位置为黑(0)。

**关键洞察**：输出完全丢弃了方块在输入中的绝对位置信息，仅保留大小序列；但大小序列本身由贪心遮挡过程决定——大方块先选中后，与之重叠的小方块被淘汰，因此改变一个障碍物的位置可能让某个大方块无法成立，从而让被它遮挡的小方块存活，改变整个输出序列。

## 新题 4：去偏移复原对称表

**组合逻辑**：[平移·逆向](创新：将 fixed_step_shift 变为按行递增的循环偏移，且需求解者自行推断偏移量) → [补全](已有，创新：补全的前提是先去偏移恢复对称结构)

**来源原语**：平移/shift、固定步长平移/fixed_step_shift（来自 32e9702f）；补全/completion、对称图案/symmetric_pattern、坐标表/coordinate_table、循环对称/cyclic_symmetry、已有推断缺失像素/existing_infer_missing（来自 73251a56）

**依赖链**：输入是一张被逐行循环偏移打乱的对称表，部分格子缺失（黑色）。求解者必须：(a) 从可见像素推断每行的偏移量（通过发现主对角线应当同色但当前不同色），(b) 逆转偏移恢复对齐，(c) 在恢复后的结构上用循环对称规则补全缺失格。三步紧耦合：不知偏移量就无法对齐，不对齐就无法识别对称规则，不识别规则就无法补全。

先推断并还原一张被逐行循环偏移打乱的对称色表，再利用循环对称规则补全缺失像素。

**输入结构**：一个 7x7 的网格。底层逻辑是一张关于主对角线对称的颜色表：对角线上所有格子同色（如红(2)），距对角线距离相同的格子同色，颜色按固定调色板循环（如红(2)、蓝(1)、绿(3)、黄(4) 循环）。在呈现给求解者之前，每行 i（0-indexed）被循环右移了 i 列（即第 0 行不动，第 1 行右移 1 列，第 2 行右移 2 列……溢出部分环绕到行首）。之后随机将约 30%-40% 的格子替换为黑(0)表示缺失。保证：第 0 行完整不缺失（提供调色板信息），每行至少保留 2 个非黑像素（提供偏移线索）。不同示例中调色板的颜色种类和循环长度可能不同（3-5 种颜色），但同一示例内循环规则一致。

**规则**：
1. 观察第 0 行（未偏移）：从中提取调色板循环。第 0 行的格式为：[对角色, 近对角色, 循环色1, 循环色1, 循环色2, 循环色2, ...]，其中"循环色"以每两列一组重复。
2. 推断偏移规则：对于第 i 行，将该行循环左移 i 列。验证方法：还原后 (i, i) 位置应等于对角色。
3. 对整个网格执行逆偏移：第 i 行循环左移 i 列。
4. 在逆偏移后的网格上补全黑色缺失格：对格子 (r, c)，令 near = min(r, c)，dist = |r - c|。dist = 0 时填对角色；dist > 0 时，根据 near 和 dist 的值查阅调色板循环确定颜色（具体索引规则：对角色占 dist=0，近对角色占 1 <= dist <= near+1 的区间，之后以 near+2 为块宽循环遍历调色板）。
5. 输出补全后的 7x7 网格（不含偏移——即已还原的状态）。

**关键洞察**：偏移使得对称结构在视觉上完全被打乱，主对角线不再同色；求解者需从第 0 行（未偏移）的完整调色板和其他行的残存像素中推断"逐行递增循环偏移"这一隐藏变换，才能恢复可供补全的对称结构。

## 新题 5：反射入框叠加冲突着色

**组合逻辑**：[镜像·反射入内](已有) + [最近邻归属](已有) → [透明叠加 + 逐像素比较](已有，创新：比较的不是两个预设面板而是多个反射结果在同一框内的覆盖情况) → [重涂色·冲突标记](创新：单覆盖保留框色，双覆盖变为冲突色)

**来源原语**：镜像/mirror、最近邻归属/nearest_assign、跨框中线反射入内/reflect_centerline_in（来自 6855a6e4）；透明叠加/overlay、逐像素比较/per_pixel_comparison（来自 94f9d214）；重涂色/recolor（来自多个参考题）

**依赖链**：每个灰色精灵体先根据最近邻归属确定目标框 → 反射进入目标框内部 → 同一框内多个反射结果叠加时产生冲突 → 冲突像素重涂为黄色。镜像决定像素落点，叠加检测产生冲突信息，两者共同决定最终颜色。

将灰色精灵体反射进最近的红色框内，同一框内多个反射重叠处标记为冲突色。

**输入结构**：约 20x20 的黑(0)背景网格。包含 2-3 个红(2)空心矩形框（单像素厚，内部为黑色，尺寸各异但不重叠，水平或垂直排列成一行）。框外散布 3-5 个灰(5)的 4-连通精灵体（各 3-8 像素，形状各异）。每个精灵体与框沿同一对齐轴排列（若框横向排列，则精灵体在框的上方或下方）。至少有一个框的最近邻精灵体数量 >= 2，使得该框内会出现反射重叠。每个精灵体的反射像不会超出其目标框的内部范围。精灵体之间互不相邻，精灵体与框之间至少有 1 格间距。

**规则**：
1. 对每个灰色精灵体，找到与其曼哈顿距离最近的红色框（距离计算：精灵体每个像素到框边界每个像素的最短曼哈顿距离的最小值）。
2. 根据精灵体相对于目标框的方位确定反射轴：精灵体在框的上方或下方时，反射轴为框的水平中线；在左方或右方时，为垂直中线。
3. 将精灵体的每个像素沿反射轴映射到框内部对应位置。
4. 对每个框，统计其内部每个格子被多少个反射像覆盖：
   - 覆盖次数 = 0：保持黑(0)。
   - 覆盖次数 = 1：着红(2)色（继承框的颜色）。
   - 覆盖次数 >= 2：着黄(4)色（冲突标记）。
5. 框的边界像素保持红(2)不变。框外的灰色精灵体全部擦除为黑(0)。输出网格与输入同尺寸。

**关键洞察**：单独看某个精灵体的反射结果，无法判断该像素最终是红色还是黄色——必须知道同一框内所有其他精灵体的反射结果才能确定冲突。框的空间位置决定了哪些精灵体归属于它，精灵体的形状决定反射像的落点，两者的交叉才产生冲突模式。

## 新题 6：标记色选择精灵体拉伸入框

**组合逻辑**：[计数·形状内色频 + 标记色最多者选中](已有，创新：选中的精灵体不是直接裁剪输出，而是作为拉伸模板) → [擦除标记色](创新：标记色仅用于选择，不参与最终形状) → [拉伸 + 线段连接再填充](已有，创新：拉伸源不是预设的外部小精灵体而是选择过程的输出)

**规则**：
1. 统计每个精灵体中橙(7)像素的数量。选择橙色像素最多的那个精灵体。若平局，选择精灵体边界框左上角更靠上（行号更小）的那个；仍平局则选更靠左（列号更小）的。
2. 在选中精灵体中，擦除所有橙(7)像素为黑(0)，仅保留主色像素。记录剩余像素在精灵体边界框内的相对坐标集合 P。

5. 连接完成后，在框内部对所有被线段封闭的背景区域进行洪水填充，填充色为主色。

**关键洞察**：标记色的功能是双重的——既是选择标准（数量最多的被选中），又是形状干扰（擦除后精灵体的骨架发生变化）；拉伸的源图案不是肉眼直接可见的任何精灵体，而是经过"选择 + 擦除"两步处理后的中间产物。

## 新题 7：重力反弹染色轨迹

**组合逻辑**：[重力下落](已有) → [反弹 + 颜色继承](已有，创新：反弹发生在重力着陆点而非射线行进中，颜色来源是地板像素而非墙壁) → [连线·绘制轨迹](已有，创新：线段方向是重力反弹后的垂直回弹，不是自由射线)

**来源原语**：重力下落/gravity_drop、分隔行/divider_row、宽度决定行为/width_determines_behavior、穿透与停靠/pass_through_or_stop（来自 84ba50d3）；反弹/bounce、颜色继承/color_inheritance（来自 142ca369）；连线/draw_line（来自 b7249182）；擦除/erase（来自 e41c6fd3）

**依赖链**：精灵体下落至分隔行 → 着陆格的颜色决定反弹后轨迹的颜色 → 窄精灵体反弹画出上升轨迹并消耗着陆格，宽精灵体停靠不反弹。宽度决定是否反弹，分隔行颜色决定反弹轨迹颜色，两者在着陆瞬间交汇。

单列精灵体下落撞击彩色地板后反弹回升并继承地板颜色画出轨迹，多列精灵体则停靠不反弹。

**输入结构**：约 15x12 的黑(0)背景网格。底部倒数第 2 行有一条水平分隔行，但该行不是单色的——每个格子可以是不同颜色（红(2)、蓝(1)、绿(3)、黄(4)等，不含黑色），形成一条多色地板。分隔行上方分布 4-6 个精灵体：部分是单列垂直条（宽度 1，高度 1-3 像素，颜色为灰(5)），部分是多列精灵体（宽度 2-3，高度 1-2，颜色为灰(5)）。各精灵体水平不重叠（占据不同的列范围）。每个单列精灵体正下方的分隔行格子保证存在且有颜色。精灵体与分隔行之间有 2-6 行空间。

**规则**：
1. 清除所有精灵体原始位置为黑(0)。
2. 对每个精灵体，判断其宽度（水平跨越的列数）：
   - **宽度 = 1**（单列精灵体）：整体向下移动直到最低像素到达分隔行正上方一行。然后反弹——从该列的分隔行格子获取颜色 C，将分隔行该格擦除为黑(0)。精灵体从着陆位置开始向上，逐格绘制颜色 C 的像素，直到回到精灵体的原始起始行（最高像素的原始行号）为止。反弹轨迹覆盖原精灵体区域和上方空间。精灵体自身像素也被重涂为 C。
   - **宽度 >= 2**（多列精灵体）：整体向下移动，直到精灵体最宽水平行（像素最多的行）紧贴分隔行上方一行。精灵体保持灰(5)不变。若移动后精灵体覆盖了分隔行的某些格子，则精灵体覆盖分隔行（精灵体优先）。
3. 处理顺序不影响结果（生成约束保证不同精灵体的列范围不重叠）。
4. 输出网格与输入同尺寸。分隔行中未被擦除或覆盖的格子保持原色。

**关键洞察**：分隔行不只是障碍——它是颜色源；单列精灵体的反弹轨迹颜色完全取决于它落在哪个地板格上，而地板的颜色在输入中是可见但不显眼的。宽度决定物理行为（反弹 vs 停靠），地板颜色决定轨迹外观——这两条规则在着陆点交汇，缺一不可。

## 新题 8：角落裁剪拓扑着色重组

**组合逻辑**：[裁剪·角落提取 + 角落对应](已有) → [计数·孔洞 + 孔洞数映射颜色](已有，创新：被计数的不是散布的灰色精灵体而是角落提取物) → [拼接·最小包围框收缩](已有，创新：拼接前进行了拓扑分析和重涂色)

**依赖链**：角落裁剪得到四个图案 → 分别统计孔洞 → 查图例获取颜色映射 → 重涂色 → 按角落对应关系重新拼入缩小的输出框。裁剪确定分析对象，拓扑决定颜色，角落位置确定拼接位置——三条信息链在最终输出处汇合。

从四角裁剪灰色图案，按各图案孔洞数查图例重涂颜色，再组装到最小方框中。

**输入结构**：约 15x15 的黑(0)背景网格。四个角落各有一个灰(5)图案，每个图案占据约 3x3 到 5x5 的区域，形状各异（有的是实心块无孔，有的有 1 或 2 个黑色孔洞）。四个图案至少存在 3 种不同的孔洞数。网格中央偏下有一个小颜色图例：2-3 个并排的微型色块（如蓝(1)包围 0 个孔、红(2)包围 1 个孔、绿(3)包围 2 个孔），每个色块约 2x2 至 3x3，用品红(6)边框分隔。角落图案之间的空间全为黑色。

**规则**：
1. 识别四个角落区域：将每个灰色前景像素归属到最近的网格角（左上、右上、左下、右下），以曼哈顿距离到角点计算。
2. 对每个角落的灰色图案，裁剪其最小边界框。
3. 识别图例：找到非角落区域、非黑非灰的色块，统计每个色块的孔洞数，建立映射（孔洞数 → 颜色）。

6. 确定四个裁剪图案中最大的边长 S。输出一个 (S+1) x (S+1) 的网格。将每个角落图案（已重涂色）放入输出的对应角落（左上图案放左上，依此类推），图案的角落像素紧贴输出的角点。不足 S x S 的图案在远离角点的方向留黑(0)。
7. 图例不出现在输出中。

**关键洞察**：每个角落图案的空间位置（决定它在输出中的角落）与其拓扑属性（孔洞数，决定它的颜色）是两条独立的信息；仅凭位置无法确定颜色，仅凭拓扑无法确定放置位置。图例的孔洞编码需对比多个示例才能确认。

## 新题 9：自编码复制精灵体

**组合逻辑**：[平移复制](已有，创新：偏移量不来自外部锚点，而是编码在精灵体内部的特殊像素位置中) + [擦除·标记色](创新：标记色像素既是偏移编码又是应被擦除的非输出部分) → 隐式编码结构（精灵体同时是操作对象和操作指令）

**来源原语**：平移复制/translate_and_copy、锚点偏移对应/anchor_offset_correspondence、源锚点/source_anchor_marker（来自 2c737e39）；擦除/erase（来自 e41c6fd3）；标记色像素/marker_color_pixel（来自 ae4f1146）

**依赖链**：精灵体内部的红色像素位置 → 被解读为复制偏移量 → 在对应偏移位置放置精灵体的净形状（去除红色后的版本）。偏移量编码在精灵体自身中，删除编码就无法确定复制位置，删除复制操作就不知道编码的用途——精灵体同时是数据和指令。

精灵体内部的红色像素编码了复制偏移向量，将去红后的净形状复制到各偏移位置。

**输入结构**：约 15x15 的黑(0)背景网格。中央附近有一个 4-连通精灵体，由一种主色（如蓝(1)，4-8 个像素）和 1-3 个红(2)像素组成。红色像素与主色像素 4-连通（红色像素是精灵体的一部分，不是孤立的）。精灵体在边界框内有一个明确的参考点：边界框的左上角。红色像素相对于精灵体边界框左上角的行列偏移量 (dr, dc) 即为复制偏移向量。网格足够大，使得所有偏移复制都不会超出边界。不同红色像素给出的偏移向量互不相同。生成约束：各偏移副本之间以及副本与原始精灵体之间不重叠。

**规则**：
1. 定位精灵体的边界框，记其左上角为参考点 (R0, C0)。
2. 找出精灵体中所有红(2)像素，计算每个红色像素相对于 (R0, C0) 的偏移量 (dr_k, dc_k)。
3. 生成精灵体的"净形状"：将精灵体中所有红(2)像素替换为主色，得到一个纯主色图案。记录净形状中每个像素相对于 (R0, C0) 的坐标集合 S。
4. 对每个偏移量 (dr_k, dc_k)，在位置 (R0 + dr_k, C0 + dc_k) 为新参考点，绘制净形状的副本：对 S 中每个相对坐标 (sr, sc)，将 (R0 + dr_k + sr, C0 + dc_k + sc) 涂为主色。
5. 原始精灵体的位置也替换为净形状（红色像素变为主色）。
6. 若副本之间或副本与原始精灵体之间发生重叠，重叠像素仍为主色（无变化——同色覆盖）。
7. 输出网格与输入同尺寸，其余位置为黑(0)。

**关键洞察**：精灵体既是被复制的对象，又通过红色像素的空间位置编码了复制指令——这是一种隐式编码结构，求解者需在第一个示例中猜测红色像素的角色，通过多个示例确认"红色位置 = 偏移向量"这一非显然映射。

## 新题 10：射线路径长度排序摘要

**组合逻辑**：[射线延伸 + 反弹](已有) → [计数·路径长度](创新：计数对象从静态物体变为射线路径上的动态像素数) → [排序 + 压缩](已有，创新：排序依据是射线追踪的数值结果，压缩格式为颜色行)

**来源原语**：射线延伸/ray_cast、反弹/bounce、碰撞停止/collision_stop、箭头精灵体/arrow_sprite、墙壁像素/wall_pixel、颜色继承/color_inheritance（来自 142ca369）；计数/counting（来自 58490d8a, 8ba14f53）；排序/sort、面积排序/area_ordering（来自 4df5b0ae）；压缩/compression、顺序排列/ordered_arrangement（来自 8ba14f53）

**依赖链**：射线追踪确定每条路径的长度 → 按长度排序各箭头 → 压缩为按排序顺序逐行输出颜色点的摘要网格。路径长度只有追踪完反弹后才能确定，排序和压缩依赖长度数值。输出完全丢弃了路径的空间形状，只保留长度的序关系。

追踪各箭头射线含反弹的完整路径，按路径长度升序压缩成行式摘要输出。

**输入结构**：约 14x14 的黑(0)背景网格。包含 3-4 个不同颜色的 2x2 缺角 L 形箭头精灵体（颜色从蓝(1)、绿(3)、黄(4)、品红(6)中取）。散布 4-8 个单像素墙壁（红(2)或灰(5)，不与箭头同色）。箭头的缺角方向各异。墙壁位置保证各箭头射线的路径长度互不相同（避免排序平局）。各箭头互不相邻，箭头与墙壁互不相邻。

**规则**：
1. 对每个箭头，按 142ca369 的规则追踪其对角射线（含反弹、颜色继承、碰撞停止）。记录该射线经过的背景格总数 L（不含箭头自身像素，不含墙壁像素，只计射线涂过的空背景格数；同一格被多次经过只计一次）。
2. 将所有箭头按 L 值从小到大排序。
3. 输出一个 N x Lmax 的网格（N 为箭头数，Lmax 为最大路径长度）。第 k 行（0-indexed，k=0 为最短路径的箭头）从左起连续填充 L_k 个该箭头原始颜色的像素，其余格子为黑(0)。
4. 输出网格仅包含颜色摘要，不包含任何箭头形状、墙壁或路径几何信息。

**关键洞察**：输出的空间结构（哪一行、多长的色条）完全由射线追踪的动态过程决定，但输出本身不包含任何路径痕迹——它是一个纯粹的统计摘要。墙壁的微小移动可能通过改变反弹次数大幅改变某条路径的长度，从而改变排序顺序和输出的行分配。
