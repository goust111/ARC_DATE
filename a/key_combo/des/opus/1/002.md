## 新题 1：屏障色控制精灵体反射方向

**组合逻辑**：[填充/fill](创新：匹配端点行填充后成为结构性屏障) + [镜像/reflect](创新：屏障颜色编码反射轴方向) + [分类/classify](隐式：屏障色→反射方向的映射)

**来源原语**：fill / full_row_fill_endpoints_match（22eb0ac0）, mirror/reflect（6f473927, 8d5021e8）, same_color_pairing / canvas_boundary / marker_pixel（22eb0ac0）, sprite（8d5021e8）

**依赖链**：边界标记颜色匹配判断 → 整行填充生成屏障 → 屏障颜色分类 → 分类结果决定精灵体反射轴向 → 反射副本放置。填充步骤的输出（屏障行及其颜色）直接决定反射步骤的行为方向，删除填充则无法确定反射轴，删除反射则填充行无后续变换意义。

将端点匹配行填充为彩色屏障，再根据每个精灵体下方屏障的颜色决定其反射方向（水平或垂直），输出原始精灵体及其反射副本。

**输入结构**：黑(0)背景网格，约14x14。最左列和最右列包含标记像素，颜色为红(2)或蓝(1)。每个有标记的行在左右边界各有恰好一个标记像素；部分行无标记。网格内部散布若干小型单色精灵体，颜色为绿(3)，每个由3-6个像素组成（4-连通）。每个精灵体的边界框完整地位于两个"可匹配行"（左右边界标记颜色相同的行）之间——即上方和下方各有一个可匹配行。生成约束：每个精灵体上方和下方各恰好有一个可匹配行（两端颜色一致），且精灵体之间互不重叠。

**规则**：
1. 对每个有左右边界标记的行：若两端标记颜色相同，将该行所有像素填充为该颜色；若颜色不同，该行保持不变。
2. 每个绿(3)精灵体现在被上下两个填充屏障行夹住。找到该精灵体正下方最近的填充屏障行。
3. 若下方屏障为红(2)：将精灵体沿其边界框的垂直中轴做水平翻转，翻转副本颜色为黄(4)，原始保持绿(3)。副本放置于原始精灵体的右侧紧邻位置（副本最左列 = 原始最右列 + 1）。
4. 若下方屏障为蓝(1)：将精灵体沿其边界框的水平中轴做垂直翻转，翻转副本颜色为黄(4)，原始保持绿(3)。副本放置于原始精灵体的下方紧邻位置（副本最上行 = 原始最下行 + 1）。
5. 若翻转副本的任何像素会落在屏障行上或超出网格边界，该像素被裁剪（不绘制）。
6. 屏障行像素、未匹配的边界标记像素保持不变。

**关键洞察**：填充行不是最终产出——它们是反射操作的基础设施，且其颜色隐式编码了反射方向。必须对比多个示例（不同屏障颜色下精灵体产生不同方向的反射）才能归纳出颜色-方向映射。

## 新题 2：奇偶选择性洪水填充穿越嵌套框架缺口

**组合逻辑**：[分类/classify](创新：按环编号奇偶分类种子) → [填充/flood_fill](创新：仅填充奇偶匹配的可达环)

**来源原语**：flood_fill / seed_pixel / enclosed_cavity / connectivity_reachable / seed_color_labels_fill（8b7bacbf）, concentric_square_layers / distance_determines_palette / cyclic_color_bands（13e47133）, rectangular_frame（256b0a75）

**依赖链**：嵌套框架结构 → 环编号计算 → 种子所在环的奇偶分类 → 缺口连通路径分析 → 仅填充奇偶匹配的可达环。分类步骤决定填充范围，填充步骤依赖分类结果和框架拓扑。

种子像素位于嵌套矩形框架形成的环中，通过框架缺口向其他环扩散，但仅填充与自身环编号奇偶性相同的可达环。

**输入结构**：黑(0)背景网格，约15x15。灰(5)像素形成3-4个嵌套的矩形框架（大致同心，每个框架1像素厚）。每个框架有1-2个单像素缺口（边框上缺失的一个像素）。相邻框架之间的空间称为"环"，从外到内编号：网格边缘与最外框架之间 = 环0，最外与次外框架之间 = 环1，依此类推，最内框架的内部 = 最高编号环。其中2-3个环各包含恰好一个种子像素（单个非黑非灰的像素），每个种子颜色不同，从红(2)、蓝(1)、绿(3)中选取。其余环不含种子。生成约束：至少一个偶数编号环和一个奇数编号环含有种子；缺口分布使得并非所有环都相互可达。

**规则**：
1. 从外到内对环编号：环0, 环1, 环2, ...。种子的奇偶类别 = 其所在环编号 mod 2。
2. 若相邻两环（环i与环i+1）之间的框架有至少一个缺口，则这两环"缺口连通"。
3. 一个环从种子所在环"可达"，当且仅当存在一条由缺口连通的相邻环组成的链连接两者（此判断不考虑奇偶性）。
4. 种子填充所有可达且环编号奇偶性与自身相同的环中的黑(0)像素，使用种子自身的颜色。奇偶不匹配的环虽然可被穿越（计算可达性时视为可通行），但不被填充。
5. 若两个种子可填充同一个环（同奇偶且都可达），环编号较小（更靠外）的种子优先。
6. 灰(5)框架像素保持不变。种子像素保持其原始颜色。

**关键洞察**：框架缺口决定了连通路径，但奇偶过滤决定了哪些可达环真正被填充。种子可以"穿过"异奇偶环而不填充它们，产生不连续的填充图案——必须对比不同种子位置和缺口配置的示例才能发现奇偶规则。

## 新题 3：标记像素的对角邻居计数编码象限精灵体旋转角度

**组合逻辑**：[分类/classify](创新：对角邻居计数作为分类指标) → [旋转/rotate](创新：旋转角度由计数值决定，非固定)

**来源原语**：rotate / quadrant / quadrant_rotation（cf5fd0ad）, diagonal_neighbor（140c817e）, classify / diagonal_orientation（1d61978c）, sprite（8d5021e8）, cross_divider（0bb8deee）

**依赖链**：标记像素定位 → 对角邻居计数 → 计数映射为旋转角度 → 精灵体旋转 → 象限重组。计数步骤的输出直接参数化旋转步骤，两者不可分离。

每个象限内精灵体的旋转角度由其内部标记像素拥有的对角邻居数量编码：0个邻居=不旋转，1个=90度，2个=180度，3个=270度。

**输入结构**：黑(0)背景网格，约14x14，由一条1像素灰(5)水平线和一条1像素灰(5)垂直线（形成十字分隔线）分为四个等大象限。每个象限包含一个小型精灵体，由绿(3)像素组成（4-8像素，4-连通）。每个精灵体内恰好有一个像素为红(2)而非绿(3)——即标记像素。该标记像素的四个对角邻居位置（NW、NE、SW、SE）中，有0到3个是绿(3)精灵体像素。生成约束：四个精灵体的对角邻居计数分别为0、1、2、3，各不相同；每个精灵体的形状不对称（旋转后可见差异）。

**规则**：
1. 对每个象限，定位其精灵体中的红(2)标记像素。计算该标记像素四个对角邻居（NW、NE、SW、SE）中属于绿(3)精灵体像素的数量D。
2. 将红(2)标记像素替换为绿(3)，使精灵体变为纯绿色。
3. 将精灵体以其边界框中心为圆心，顺时针旋转 D x 90 度（D=0：不旋转；D=1：顺时针90度；D=2：180度；D=3：顺时针270度）。
4. 将旋转后的精灵体放回其所在象限，以象限中心为基准居中放置。灰(5)十字分隔线保持不变。

**关键洞察**：旋转角度不由象限位置固定决定（与参考题cf5fd0ad不同），而是从每个精灵体的内部微观结构（标记像素的对角邻居数）中读取。必须对比多个示例，观察不同对角邻居数与旋转结果的对应关系，才能归纳出D-to-rotation映射。

## 新题 4：方向精灵体射线触发镜像标记对间隙填充

**组合逻辑**：[射线延伸/ray_extend](创新：方向由质心偏移决定) → [连线/connect + 填充/fill](创新：射线终点触发镜像对之间的间隙填充)

**来源原语**：ray_extend / directional_sprite / centroid_bias_dir / dotted_ray_to_edge（13f06aa5）, connect / mirrored_marker_pair / center_axis_symmetry / min_gap_triggered（5ad8a7c0）, stop_at_fg（f8be4b64）, marker_pixel（13f06aa5）

**依赖链**：精灵体质心计算 → 射线方向确定 → 射线发射 → 射线命中镜像标记像素 → 触发该标记对之间的水平间隙填充。射线方向决定命中哪个镜像对，命中事件触发填充，两步紧密耦合。

不对称精灵体通过质心偏移编码射线方向；射线命中一个镜像标记对中的一端后，该对之间的间隙被填充为射线颜色。

**输入结构**：黑(0)背景网格，约16x16。2-3个小型方向精灵体，每个由灰(5)像素组成（恰好7个像素，形状相同但经旋转以编码不同方向）。每个精灵体内嵌入一个标记像素，颜色各不相同，从红(2)、蓝(1)、绿(3)中选取。此外，网格中有3-4对黄(4)单像素，每对关于网格垂直中轴对称（同一行内，两像素到中心列距离相等）。生成约束：每个精灵体的射线方向为四个基本方向之一（上、下、左、右），且每条射线路径上恰好有一个黄(4)像素会被命中。不同精灵体的射线不会命中同一个黄(4)像素。

**规则**：
1. 对每个精灵体，计算其灰(5)像素（不含标记像素）的质心C = (行均值, 列均值)。计算从质心C到标记像素M的偏移向量：dr = M行 - C行，dc = M列 - C列。射线方向为该偏移向量的主导基本方向：若 |dr| > |dc|，射线向下(dr>0)或向上(dr<0)；若 |dc| > |dr|，射线向右(dc>0)或向左(dc<0)；若 |dr| = |dc|（平局），取垂直方向（dr>0则向下，dr<0则向上）。
2. 从标记像素M出发，沿射线方向逐像素发射连续射线，将路径上的每个黑(0)像素涂为标记像素的颜色。
3. 射线遇到黄(4)像素时停止（该黄像素也被涂为标记颜色）。若路径上无黄像素，射线延伸至网格边界。
4. 当一个黄(4)像素被射线命中时，找到它的镜像伙伴（同一行中关于垂直中轴对称的另一个黄像素）。将该行中两个黄像素之间（含两端）的所有背景像素填充为射线的标记颜色。
5. 未被任何射线命中的黄(4)像素对保持黄(4)不变。灰(5)精灵体像素保持不变。

**关键洞察**：精灵体的不对称形体是方向天线——质心偏移编码射线发射方向。射线的落点决定激活哪个镜像对，连接颜色来自射线的源标记。删除方向分类则射线方向不定，删除镜像对连接则射线只是线段无后续效果。

## 新题 5：频率角色分配与最稀有色计数编码同心带宽度

**组合逻辑**：[角色分配/role_assignment](创新：频率决定功能角色) + [填充/fill](创新：角色参数化同心带绘制) + [对称补全/frame_completion](隐式：补全不完整框架)

**来源原语**：role_assignment / freq_role_assignment（3979b1a8）, fill / concentric_square_layers / cyclic_color_bands / distance_determines_palette（13e47133）, rectangular_frame / frame_completion（256b0a75, 34cfa167）

**依赖链**：颜色频率统计 → 角色分配（框架色/填充色/参数色） → 框架补全 → 参数色像素计数 → 计数值作为同心带宽度 → 同心带绘制。角色分配决定谁是框架、谁是填充、谁编码参数，三者缺一不可。

三种非背景色按频率分配角色：最多的画框架，最少的用像素计数编码带宽度，中间的填充同心带。

**输入结构**：黑(0)背景网格，约12x12。三种非背景色，各色像素数量严格不同（无并列）。最常见色的像素形成一个近完整的矩形边框（1像素厚，有1-2个单像素缺口），围出一个内部区域。最稀有色出现为1-3个孤立像素，位于框架某一角附近。中间频率色的像素散布在框架内部（3-6个像素，不构成特定图案）。颜色从蓝(1)、红(2)、绿(3)、黄(4)、灰(5)、品红(6)、橙(7)、青(8)、栗(9)中选取，具体颜色因示例而异。生成约束：框架内部区域足够大，能容纳至少2条完整的同心带（带宽度 = 最稀有色像素数量P）。

**规则**：
1. 统计每种非背景色的总像素数。分配角色：最常见色 = 框架色，中间频率色 = 填充色，最稀有色 = 参数色。
2. 用框架色填充框架边框上的缺口，使矩形框架完整。
3. 统计参数色像素的数量P。P即为同心带的宽度（像素数）。
4. 在补全后的框架内部，从框架内边缘向内绘制同心矩形带，每带宽度P像素。交替使用填充色和黑(0)：最外带 = 填充色，次外带 = 黑(0)，第三带 = 填充色，依此类推。
5. 框架内部所有原始像素（包括散布的中间频率色像素和参数色像素）均被同心带图案覆盖。框架边框像素保持为框架色。

**关键洞察**：最稀有色像素不是装饰——它们的数量是隐式数值参数，控制同心带的宽度。必须对比包含不同数量参数色像素的示例，才能发现"计数即带宽"的编码规则。频率角色分配是前置条件，不先确定角色就无法进行后续操作。

## 新题 6：接触边界决定镜像轴，深度交替色重映射

**组合逻辑**：[镜像/reflect](已有：接触边界定轴) + [重涂色/recolor](创新：按距反射缝距离交替使用两套色映射)

**来源原语**：mirror / concatenate / foreground_shape / touching_border_determines_axis / negative_color_remap（6f473927）, concentric_square_layers / distance_determines_palette / cyclic_color_bands（13e47133）

**依赖链**：形状接触边界检测 → 反射轴确定 → 水平镜像 → 镜像半区逐列距离计算 → 距离奇偶决定色映射方案 → 拼接输出。镜像步骤产生几何结构，重涂色步骤依赖该结构的列距离信息，两者交织。

将接触一侧边界的形状镜像到另一侧，但镜像半区的颜色映射按到反射缝的距离交替变化：偶数距离用一套映射，奇数距离用另一套，形成条纹效果。

**输入结构**：黑(0)背景网格，约8x12（较窄较高）。红(2)前景像素形成一个连通图形（8-连通，6-15像素），该图形接触且仅接触一侧垂直边界（最左列或最右列），不接触对侧垂直边界。图形从接触的边界向内延伸至少3列。

**规则**：
1. 确定红(2)图形接触哪一侧垂直边界（左或右），该边界所在列为反射缝。
2. 将整个网格做水平镜像，生成镜像副本。
3. 对镜像副本中的每个像素，计算其所在列到反射缝列的水平距离D（反射缝列本身D=0，相邻列D=1，依此类推）。
4. 对镜像副本施加深度交替色重映射：
   - D为偶数（0, 2, 4, ...）：红(2) → 青(8)；黑(0) → 黑(0)不变。
   - D为奇数（1, 3, 5, ...）：红(2) → 蓝(1)；黑(0) → 灰(5)。
5. 水平拼接：若图形接触左边界，镜像副本在左、原图在右；若接触右边界，原图在左、镜像副本在右。
6. 原始半区保持不变。输出网格宽度为输入的两倍。

**关键洞察**：镜像半区并非统一色替换（不同于参考题6f473927的简单负片），而是产生与反射缝距离相关的垂直条纹。条纹图案只有在对比不同宽度形状的示例后才能辨认——宽形状产生更多条纹，揭示距离-颜色的交替规律。

## 新题 7：对角互补印章叠加控制条编码的二维周期平铺

**组合逻辑**：[印章覆盖/stamp](创新：互补对角位置填充新色) + [平铺/tile](创新：平铺周期由控制条间距编码)

**来源原语**：stamp / foreground_object / square_block / diagonal_complement / complement_at_diagonal_vacancies（22233c11）, tile / control_bar / control_periodic（34cfa167）, array_layout（8d5021e8）

**依赖链**：对角占位检测 → 互补位置印章 → 形成完整瓦片 → 控制条间距读取 → 二维周期平铺。印章步骤生成瓦片内容，控制条步骤决定瓦片排布，两个操作协同产出最终图案。

在对角方块对的空缺对角位置印章新色方块，形成完整瓦片，然后以控制条间距为周期进行二维平铺。

**输入结构**：黑(0)背景网格，约20x20。一个前景对象由两个等大的绿(3)正方形块组成（每块KxK，K为2或3），占据一个隐含2x2块布局的一条对角线（例如NW+SE位置有绿块，NE+SW位置为空，或反之）。两块之间在水平和垂直方向各间隔K个像素（即2x2布局中相邻块间隙为0，整个布局为2Kx2K）。一条红(2)垂直控制条（1像素宽，K像素高）位于该对象右侧，其左边缘与对象右边缘的水平距离 = H像素（H在1-4之间）。一条蓝(1)水平控制条（K像素宽，1像素高）位于该对象下方，其上边缘与对象下边缘的垂直距离 = V像素（V在1-4之间）。生成约束：网格足够大，能容纳至少2x3的瓦片排布。

**规则**：
1. 识别两个绿(3)块占据的对角线方向（NW+SE或NE+SW）。在2x2块布局的另外两个互补对角位置放置同样大小的青(8)方块。此时形成一个2Kx2K的完整瓦片（2块绿+2块青）。
2. 该2Kx2K图案成为瓦片单元。
3. 读取水平周期：从瓦片右边缘到下一个瓦片左边缘的水平间距 = H（即控制条水平距离）。因此水平重复周期为2K + H。
4. 读取垂直周期：从瓦片下边缘到下一个瓦片上边缘的垂直间距 = V。因此垂直重复周期为2K + V。
5. 从原始瓦片位置开始，向右和向下以上述周期平铺该瓦片，直到网格边界。超出网格边界的部分裁剪。
6. 删除红(2)和蓝(1)控制条（输出中不保留控制条像素）。

**关键洞察**：控制条具有双重功能——它们的距离编码平铺周期，而对角互补规则生成瓦片内容。没有印章步骤，瓦片不完整；没有控制条，平铺间距未知。两个独立来源的原语通过"构造瓦片-设定周期"产生了源题中不存在的生成关系。

## 新题 8：类比推理发现射线延伸变换规则

**组合逻辑**：[类比推理/analogy_inference](已有：训练对→规则发现) + [射线延伸/ray_extend](创新：被类比发现的变换规则恰好是射线行为)

**来源原语**：analogy_inference / rule_inference / training_pair_mapping / palette_match_pairing（4c7dc4dd）, hollow_frame / sprite（4c7dc4dd）, ray_extend / emit_from_arm_end / stop_at_fg（f8be4b64）, marker_pixel（13f06aa5）

**依赖链**：框架颜色匹配 → 训练对识别 → 比较训练对输入输出推断射线规则（方向、终止条件） → 将推断的规则应用于测试精灵体 → 裁剪输出。类比推理步骤确定变换类型和参数，射线延伸步骤执行该变换，两者共同约束最终输出。

从一对同色框架围住的精灵体中，推断射线延伸的变换规则（方向、终止条件），然后将该规则应用于另一个框架中的测试精灵体。

**输入结构**：黑(0)背景网格，约20x20。三个彩色空心正方形框架（每个7x7，1像素厚边框），彼此间隔至少2像素。框架A的边框为红(2)，框架A'的边框也为红(2)（训练对）。框架B的边框为绿(3)（测试用例）。框架A内部（5x5区域）：一个由蓝(1)像素组成的小型精灵体（3-5像素，4-连通），其中嵌入1-2个橙(7)标记像素（4-连通地连接于精灵体或与精灵体相邻）。框架A'内部：与A相同的蓝(1)精灵体布局，但每个橙(7)标记像素沿某个基本方向（上/下/左/右之一）延伸出橙(7)射线，射线在遇到蓝(1)精灵体像素或框架边框前停止（不含终止像素）。框架B内部：一个不同形状的蓝(1)精灵体（3-5像素），含有橙(7)标记像素，但无射线。生成约束：训练对中所有标记像素的射线方向一致（同一个基本方向）；训练对的边框色相同，测试框架边框色与训练对不同。

**规则**：
1. 通过匹配框架边框颜色识别训练对：两个边框色相同的框架为训练对（A和A'），边框色唯一的为测试用例（B）。
2. 比较A和A'的内部：从每个橙(7)标记像素出发，确定在A'中射线延伸的基本方向（即在哪个方向出现了A中没有的新橙色像素）。确认终止条件（射线在蓝像素前一格停止，还是在框架边框前一格停止——取先到者）。
3. 将推断的射线规则应用于框架B的内部：从B中每个橙(7)标记像素出发，沿同一方向延伸橙(7)射线，遵循相同的终止条件。
4. 输出：框架B内部经变换后的内容，裁剪为5x5（框架内部尺寸）。不含框架边框。

**关键洞察**：这是双重挑战——首先识别类比结构（哪些框架构成训练对），然后从训练对中精确推断射线参数（方向和终止规则）。射线方向在不同题目实例中可能不同（有时向右，有时向下等），必须从训练对的具体示范中读取，而非记忆固定规则。
