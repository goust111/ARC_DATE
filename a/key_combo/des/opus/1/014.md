## 新题 1：旋转补全涌现封闭区域并按面积周期填充

**组合逻辑**：[重涂色(recolor)](用于过滤噪声) + [对称补全(symmetry_complete)](四次旋转闭合) → 涌现封闭区域 → [排序(sorting)](按面积) + [洪泛填充(flood_fill)](等间隔采样)

**来源原语**：symmetry_complete / rotational_symmetry / four_fold_closure (e40b9e2f), flood_fill / periodic_fill / region_order (7447852a), recolor / connectivity / recolor_if_area_gt_one (e0fb7511), area_ranking (a8d7556c)

**依赖链**：连通性过滤去除噪声像素后才能正确定位旋转对称的种子方阵；旋转补全产生的闭合图案围出封闭区域，这些区域在补全前不存在；区域面积排名和周期选择规则共同决定哪些区域被填充——移除任一环节都无法确定最终输出。

输入中散布着噪声和部分图案像素，先过滤噪声、再旋转补全产生闭合图案，最后按面积周期规则填充涌现出的封闭区域。

**输入结构**：约 15x15 的网格，黑(0)背景。一种前景色（如蓝(1)）的像素分布在网格上。其中一部分蓝像素以 4-连通方式构成一个多像素连通分量（3~8 像素），占据某个隐含正方形区域（约 7x7~9x9）的一个象限角落附近；另有 2~4 个孤立蓝像素（4-连通分量面积 = 1）散布在网格其他位置，充当噪声。生成约束：多像素分量关于隐含正方形中心做 90/180/270 度旋转后不与自身冲突（即旋转后的位置要么为黑，要么已有同色像素）。

**规则**：
1. 对所有蓝(1)像素做 4-连通分量分析。面积 = 1 的分量为噪声，将其擦除为黑(0)。面积 > 1 的分量保留。
2. 找到包含所有保留蓝像素的最小正方形（边长为奇数或偶数均可，由像素分布决定），使得在该正方形中心做 0/90/180/270 度旋转闭合时不产生颜色冲突。
3. 对正方形内每个保留的蓝像素，计算其关于正方形中心的 90、180、270 度旋转位置，将这些位置也涂为蓝(1)。
4. 补全后的蓝图案与正方形边界（以及网格边缘）围出若干黑(0)封闭区域。封闭区域定义：正方形内部的 4-连通黑色分量，其所有像素均被蓝像素或正方形边界包围、无法通过 4-连通路径到达正方形外部。
5. 计算每个封闭区域的面积（像素数）。按面积降序排列；面积相同时，按区域中最上方像素的行号升序排列，行号仍相同则按最左方像素的列号升序排列。
6. 在排序后的列表中，位于索引 0、3、6、...（每隔 3 个取一个，从第 0 个开始）的区域被洪泛填充为红(2)。其余封闭区域保持黑色。正方形外部的一切不变。

**关键洞察**：封闭区域在旋转补全之前根本不存在——它们是补全操作的涌现产物。哪些区域被填充取决于补全后区域的全局面积排名，而排名又依赖旋转方向（由种子像素位置决定），形成跨步骤的信息依赖。

## 新题 2：字形解码旋转角度填入模板槽位

**组合逻辑**：[网格分块(grid_partitioning)] → [字形解码](编码字形 → 旋转角度，而非颜色) + [旋转(rotate)](按解码角度旋转模板) → 填入对应槽位

**来源原语**：rotate / sequential_order / successive_rotation_per_slot (8e5a5113), code_glyph / glyph_maps_color (ed74f2f2), grid_partitioning (5ad4f10b), divider_line / slot / template (8e5a5113), pairing (ed74f2f2)

**依赖链**：字形的形状决定旋转角度，旋转角度决定模板在对应槽位中的朝向——不解码字形就无法确定旋转，不旋转就无法填槽。字形编码方案需对比多个示例才能归纳。

每个空槽中有一个字形编码旋转角度，将模板按解码角度旋转后填入槽位。

**输入结构**：约 5x21 的网格（或类似窄长比例），黑(0)背景。灰(5)完整列线将网格分为 4 个等宽矩形区域（1 行 x 4 列布局）。第一个区域（最左）包含一个多色模板图案（使用 2~3 种非黑非灰颜色，如蓝(1)和红(2)，占据区域大部分空间，4-连通，非对称以便区分旋转方向）。后续 3 个区域各包含一个 3x3 灰(5)/黑(0)字形图案，居中放置于该区域内，其余位置为黑。生成约束：模板的宽和高与区域尺寸匹配（模板可正好放入区域）；模板不具备 90 度旋转对称性（以确保不同旋转角度产生可区分的输出）。

**规则**：
1. 识别灰(5)完整列分隔线，划定 4 个等宽区域的边界。
2. 第一个区域为模板区域，提取其中的非黑非灰图案作为模板。
3. 第 2~4 个区域各包含一个 3x3 字形。根据字形的形状查阅编码表，得到旋转角度。编码表需从多个训练示例中归纳，示例形式如下（具体映射每题可变，但同一题内一致）：
   - 字形 A 的形状 → 0 度（不旋转）
   - 字形 B 的形状 → 顺时针 90 度
   - 字形 C 的形状 → 180 度
   - 字形 D 的形状 → 顺时针 270 度
4. 将模板按解码得到的角度顺时针旋转，然后放入对应区域，左上角与区域内容起始位置对齐。原有字形像素被覆盖。
5. 灰色分隔线保持不变。

**关键洞察**：旋转角度不像 8e5a5113 那样由槽位的序号递增决定（第 1 槽 90 度、第 2 槽 180 度...），而是由每个槽内的字形形状独立编码。同一位置的槽在不同示例中可能对应不同的旋转角度。编码表必须通过对比多个示例对中字形形状与模板朝向的对应关系来归纳。

## 新题 3：镜像匹配门控间隙桥接

**组合逻辑**：[行列跨度重叠检测] → [镜像(mirror)](形状匹配检验) ⊕ [填充(fill)](条件门控) — 镜像检验结果决定是否执行填充

**来源原语**：fill / row_span_overlap / gap_region / fill_if_unobstructed (ef135b50), mirror / reflection_across_axis (88207623), shape_matching / normalized_match (42f14c03)

**依赖链**：行列跨度重叠识别候选对；镜像匹配作为几何谓词门控填充——不做镜像检测就不知道哪些间隙该填，不检查间隙就不知道在哪些对象对上做镜像检测。两个判断交织成单一决策。

判断每对水平相邻且行跨度重叠的前景对象是否互为水平镜像，是则用桥色填充它们之间的重叠行间隙。

**输入结构**：约 18x15 的网格，黑(0)背景。4~6 个绿(3)单色前景对象，均为 4-连通不规则形状（每个 5~12 像素），水平分散分布，任意两个对象的列跨度不重叠。对象之间水平间距约 2~5 列。生成约束：其中恰好 2~3 对相邻对象互为精确水平镜像（限于它们行跨度重叠的部分），其余相邻对不满足镜像关系。不存在第三个对象的边界框横跨任何一对镜像匹配对象之间的间隙。

**规则**：
1. 对每一对列跨度相邻（中间无其他对象的列跨度介入）且行跨度有重叠的绿色对象 (A, B)：
   a. 提取 A 和 B 在行跨度重叠区间内的子形状（仅保留重叠行中的像素，列坐标相对化）。
   b. 检查 A 的子形状水平翻转后是否与 B 的子形状逐像素一致。
   c. 若一致（镜像匹配），且在 A 与 B 的列跨度之间、重叠行范围内没有第三个绿色对象的边界框穿过，则将该间隙区域（A 的最右列 +1 到 B 的最左列 -1，行范围为重叠行）中所有黑色像素填充为栗(9)。
   d. 若子形状不满足镜像关系，不填充，间隙保持黑色。
2. 所有原始绿色像素保持不变。
3. 非重叠行的间隙部分不填充。

**关键洞察**：与 ef135b50 不同，填充的门控条件不仅是空间上的"无遮挡"，还包含一个几何对称性检验——两侧对象的重叠部分必须互为水平镜像。空间邻接确定候选对，镜像检验决定是否执行，两者缺一不可。

## 新题 4：标记像素双重角色——选择门控与旋转补全种子

**组合逻辑**：[选择(selection)](按标记数最少选取) → [对称补全(symmetry_complete)](标记位置为旋转种子) + [裁剪(crop)]

**来源原语**：selection / minimum_marker_count / foreground_rectangle (7bb29440), symmetry_complete / rotational_symmetry / four_fold_closure (e40b9e2f), crop (7bb29440/42f14c03), marker_pixel (7bb29440/3e980e27)

**依赖链**：标记像素的数量决定选哪个方块（最少标记者胜出），而同一批标记像素的空间位置又作为旋转补全的种子。改变任一标记像素都同时影响选择判断和补全结果，两个逻辑通过同一组数据紧耦合。

从多个正方形区域中选出标记最少的那个，然后将其内部的标记像素图案做四次旋转补全后裁剪输出。

**输入结构**：约 18x18 的网格，黑(0)背景。3~4 个等大的单色实心正方形（边长 5~7），颜色互不相同（如蓝(1)、绿(3)、黄(4)），彼此不重叠，间距 >= 2。每个正方形内部有若干红(2)标记像素（1~4 个不等），它们替换了正方形填充色的对应位置。生成约束：恰好一个正方形的标记数严格最少（无并列）；标记最少的正方形中，标记像素关于正方形中心做 90/180/270 度旋转后落在的位置当前为该正方形的填充色（即旋转不冲突——不会旋转到另一个标记像素上或正方形外）。

**规则**：
1. 识别所有非黑色实心正方形区域。每个正方形有一个主导填充色和若干红(2)标记像素。
2. 统计每个正方形中红色标记像素的数量。选出标记数严格最少的那个正方形。
3. 在被选正方形中，以正方形的几何中心为旋转中心，对每个红色标记像素计算其 90、180、270 度顺时针旋转位置。将这些旋转位置也涂为红(2)（如果该位置已经是红色则不变）。
4. 裁剪被选正方形的边界框，输出该裁剪区域（包含填充色底色和旋转补全后的红色图案）。

**关键洞察**：标记像素承担双重角色——作为计数指标决定"选哪个对象"，又作为空间种子决定"补全出什么图案"。增删一个标记像素可能同时改变被选对象的身份和补全输出的形态，这种双重敏感性是本题核心。

## 新题 5：恢复遮挡揭示隐藏指示符后印章覆盖

**组合逻辑**：[镜像(mirror)](反射恢复遮挡) → 揭示隐藏指示符 → [印章覆盖(stamp)](指示符颜色配对目标 + 触发镜像)

**来源原语**：mirror / mirror_symmetry / reflection_recovers / occluder / occluded_region (dc0a314f), stamp / color_pairing / marker_color_matches_dest / marker_triggers_mirror (3e980e27), crop (dc0a314f)

**依赖链**：遮挡恢复产出完整精灵体；精灵体内部的指示符像素（在恢复前不可见）同时编码目标匹配色和是否镜像翻转。不恢复就看不到指示符，看不到指示符就不知道往哪里印、是否翻转。

先恢复被遮挡的图案以获取完整精灵体及其内部隐藏的指示符像素，然后根据指示符颜色匹配目标位置并决定是否翻转后印章覆盖。

**输入结构**：约 20x20 的网格，黑(0)背景。左侧区域（约占网格左半部分）包含一个关于自身垂直中轴线左右对称的多色图案（使用蓝(1)、黄(4)等 2~3 种颜色，整体约 8x8~10x10 像素）。图案中有一个灰(5)实心正方形遮挡块（3x3 或 4x4），覆盖了图案的一部分。灰色仅出现在该遮挡块中。被遮挡部分（恢复后可见）包含一个红(2)或绿(3)的单像素指示符。右侧区域散布着若干孤立的红(2)和绿(3)单像素点（各 1~3 个），作为印章目标位置。生成约束：遮挡块不骑跨对称轴（即其关于垂直轴的镜像区域完全不与遮挡块重叠，保证可完整恢复）；恢复后的精灵体中恰好包含一个指示符像素。

**规则**：
1. 在左侧图案中定位灰(5)实心正方形遮挡块（唯一出现灰色的正方形区域）。
2. 确定左侧图案的垂直对称轴。将遮挡块区域关于该轴做水平反射，得到镜像区域。
3. 将镜像区域的像素内容复制回遮挡块位置，替换灰色像素，完成遮挡恢复。
4. 裁剪恢复后的完整图案（最小边界框），得到精灵体。
5. 在精灵体中找到唯一的红(2)或绿(3)指示符像素。记录其颜色 C 和在精灵体内的相对位置 (dr, dc)。
6. 若 C = 红(2)：将精灵体水平镜像翻转后作为印章模板。若 C = 绿(3)：直接使用精灵体作为印章模板。翻转后指示符的相对位置随之变化，记翻转后位置为 (dr', dc')。
7. 对右侧区域中每个颜色为 C 的孤立像素，将印章模板放置在网格上，使模板中指示符位置 (dr', dc') 与该孤立像素重合。模板像素覆盖对应位置的黑色背景（非黑像素不被覆盖）。
8. 颜色不为 C 的孤立像素不作为目标，保持不变。

**关键洞察**：指示符像素被故意藏在遮挡块之下，在恢复操作完成之前完全不可见。恢复操作不仅修复了图案外观，还揭示了控制后续印章行为的关键信息（目标颜色和翻转决策），形成"信息解锁"式的跨步骤依赖。

## 新题 6：对角射线分割空间后按面积周期填充

**组合逻辑**：[射线延伸(ray_cast)](从锚点对角发射) → 空间分割为区域 → [排序(sorting)](按面积) + [洪泛填充(flood_fill)](等间隔采样)

**来源原语**：ray_cast / diag_adjacency / anchor_diag_to_edge / solid_square / diag_marker (7ddcd7ec), flood_fill / sorting / region_order / periodic_fill / enclosed_region (7447852a), area_ranking (a8d7556c)

**依赖链**：射线的数量和方向由种子像素的对角邻接位置决定；射线完成后才形成空间分割；分割产生的区域面积排名才决定周期填充目标。改变任一种子像素的位置，射线方向变化 → 分割形态变化 → 所有区域面积和排名变化 → 填充目标完全不同。

从 2x2 方块的对角邻接种子发射对角射线至网格边缘，射线将背景分割为若干区域，按面积排名周期性填充。

**输入结构**：约 15x15 的网格，黑(0)背景。一个蓝(1)单色前景对象，包含：一个实心 2x2 蓝色方块（位于网格中部偏离中心处），以及 2~4 个额外蓝色像素，每个恰好位于该 2x2 方块某个角的对角邻接位置（如方块左上角的左上对角位置）。不同角最多各有一个对角邻接像素。生成约束：对角射线延伸到网格边缘的路径上不与其他射线交叉于同一像素点（保证分割区域的唯一性）；产生的黑色区域数量 >= 4。

**规则**：
1. 保留所有原始蓝(1)像素不变。
2. 对每个对角邻接于 2x2 方块角落的额外蓝色像素，确定其相对于方块的方向（左上、右上、左下、右下），然后沿该方向延伸对角射线：从该像素出发，每步行列各 +1 或 -1（取决于方向），将经过的每个黑色背景像素涂为蓝(1)，直到射线离开网格边界。
3. 射线绘制完成后，蓝色结构（原始对象 + 所有射线）将剩余黑色背景分割为若干 4-连通黑色区域。
4. 计算每个黑色区域的面积。按面积降序排列。面积相同时，比较区域中行号最小的像素的行号，行号小的排前面；行号也相同则比较列号最小的像素的列号，列号小的排前面。
5. 在排序列表中，索引为 0, 3, 6, ...（从 0 开始每隔 3 个）的区域被洪泛填充为黄(4)。
6. 其余黑色区域保持黑色。蓝色结构保持蓝色。

**关键洞察**：射线方向完全由种子像素与 2x2 方块的几何关系决定，而射线产生的分割是全局的——一条射线的改变会重新划分整个网格的区域结构。周期填充的目标是面积排名的函数，不是空间位置的函数，因此无法从局部判断某区域是否被填充。

## 新题 7：连通性分类同时决定放大块颜色与对角标记资格

**组合逻辑**：[连通性分析](分类前景像素) → 同时门控 [像素放大(pixel_upscale) + 重涂色(recolor)] 和 [连线(draw_line)](对角标记)

**来源原语**：pixel_upscale / draw_line / diag_collinear / bg_diag_marked / fg_pixel (f0afb749), recolor / connectivity / recolor_if_area_gt_one / connected_component / isolated_pixel (e0fb7511)

**依赖链**：同一个连通性判断同时控制两个独立输出维度：前景块颜色（红 vs 绿）和背景对角标记（有 vs 无）。一个像素从孤立变为非孤立会同时改变其自身块颜色和一整条对角线上所有背景块的标记状态——两个效应通过连通性判断紧耦合。

将网格双倍放大，前景像素按连通性分类涂色，背景像素仅在与非孤立前景像素共对角线时获得对角标记。

**输入结构**：约 8x8 的网格，灰(5)背景。若干蓝(1)前景像素散布在网格上。部分蓝像素以 4-连通方式相连形成连通分量（面积 >= 2），其余为孤立蓝像素（4-连通面积 = 1）。生成约束：至少存在一个面积 >= 2 的连通分量和至少 2 个孤立像素；至少存在一个背景像素与某个非孤立像素处于同一条 NW-SE 对角线上、但不与任何孤立像素处于同一条 NW-SE 对角线上（用以验证区分规则）。

**规则**：
1. 对每个蓝(1)像素，判定其 4-连通分量面积。面积 >= 2 为"群组像素"，面积 = 1 为"孤立像素"。
2. 创建高度和宽度各为原网格 2 倍的输出网格，全部填充灰(5)。
3. 每个群组蓝像素在输出中对应一个 2x2 纯色块，颜色为红(2)。
4. 每个孤立蓝像素在输出中对应一个 2x2 纯色块，颜色为绿(3)。
5. 对每个输入中的背景像素（灰(5)），检查它是否与至少一个群组像素处于同一条 NW-SE 对角线上（NW-SE 对角线定义：行号 - 列号 = 常数）。若是，在输出中对应的 2x2 块中，仅将主对角线位置（左上格和右下格）涂为蓝(1)，反对角线位置（右上格和左下格）保持灰(5)。
6. 与群组像素不共享任何 NW-SE 对角线的背景像素（包括仅与孤立像素共享对角线的），其对应 2x2 块保持全灰(5)。

**关键洞察**：一个蓝像素若获得一个 4-连通邻居（从孤立变为群组），其自身的输出块颜色从绿变红，同时该像素所在的整条 NW-SE 对角线上的所有背景块都会获得蓝色对角标记。单个像素的连通状态变化引发一条对角线上的级联效应——这种"一处变化、对角线广播"的机制是本题的核心。

## 新题 8：压缩瓦片马赛克生成对接选择掩码

**组合逻辑**：[压缩(compress)](左区瓦片马赛克 → 3x3 摘要) → 摘要作为 [对接(dock)] 的选择掩码（右区结构的哪些槽位接收组件）

**来源原语**：compress / grid_partitioning / tile / filled_gets_marker (5ad4f10b), dock / interior_socket / movable_component / structure / ray_inferred_direction / trail_painted_black (8b9c3697), marker_pixel (5ad4f10b)

**依赖链**：左区的瓦片布局编码了右区的操作选择——不压缩马赛克就不知道哪些槽位是激活的；不知道激活槽位就不知道将哪些组件对接到哪里。两个空间区域通过抽象的二值掩码产生跨区域逻辑耦合。

左区的瓦片马赛克压缩为 3x3 二值摘要，其中"已填充"位置指定右区结构中哪些槽位接收可移动组件的对接。

**输入结构**：约 25x12 的网格。一条灰(5)完整竖线将网格分为左右两半。
- 左半（约 12x12）：黑(0)背景上，蓝(1)实心等大正方形瓦片按 3x3 格点排列。每个格点位置要么有一个蓝色瓦片（"已填充"），要么为黑色（"空"）。已填充位置数量在 3~6 之间。另有少量红(2)散点噪声像素（1~3 个）随机分布在左半区域。
- 右半（约 12x12）：一个黄(4)大型单色结构体（不规则但包含若干内部矩形空腔），空腔为黑(0)（即槽位）。结构体的边界框内恰好有 3 个大小相近的矩形内部槽位（黑色，与结构体像素 4-邻接），按从上到下排列。结构体外部有 3 个红(2)小型可移动组件（每个 2~4 像素的 4-连通块），分散在右半区域。
- 生成约束：左半已填充位置 >= 3；每个可移动组件与恰好一个槽位在同一行或同一列上，使得从槽位向该方向射线可达该组件。

**规则**：
1. **左半压缩**：忽略红(2)噪声像素。识别蓝(1)瓦片的 3x3 格点布局（通过瓦片的边界框均分方式确定格点坐标）。对每个格点位置，判定为"已填充"（含完整蓝色瓦片）或"空"。生成一个 3x3 二值摘要。
2. **摘要映射为槽位选择**：将 3x3 摘要按行优先顺序（从左到右、从上到下）展平为长度为 9 的序列。提取其中"已填充"位置的索引。取前 3 个已填充索引（按序号从小到大），分别对应右半区域的第 1、第 2、第 3 个槽位（从上到下）。
3. **对接**：对第 k 个被选中的槽位（k = 1, 2, 3），从该槽位中心向上、下、左、右四个方向投射射线，找到第一个碰到红色可移动组件的方向。沿该方向将组件滑入槽位，组件的形状填入槽位内部。组件滑动经过的路径上的黑色像素涂为黑(0)（若路径上有黄色结构体像素则保持不变，组件从结构体边缘开口进入）。
4. 若已填充位置不足 3 个，只对接前 N 个（N = 已填充数）；多余的可移动组件保持原位不变。
5. 灰色分隔线保持不变。左半区域保持原样（含噪声）。

**关键洞察**：左区的几何布局（哪些格点有瓦片）是一个空间编码的控制信号，经压缩后跨越分隔线作用于右区的操作选择。这不是两个独立任务的串联——左区的任何瓦片变动都会改变右区的对接方案。

## 新题 9：半侧轮廓生成实心形状后扩展至网格角落

**组合逻辑**：[擦除(erase) + 填充(fill)](半侧轮廓 → 实心内部形状) → [平移(translate)](2x2 位置映射到网格四角)

**来源原语**：fill / erase / half_outline / symmetry_axis / fill_interior_spans / symmetry (bf32578f), translate / foreground_block / grid_corner / block_position_maps_to_corner / relative_position_preserved_expansion (66e6c45b)

**依赖链**：半侧轮廓本身不是最终要移动的对象——它们仅仅是形状的编码；填充操作"实例化"出真正的形状。平移操作作用于填充产出的形状，而非输入中可见的轮廓。删除填充步骤，就没有形状可移动；删除平移步骤，实例化的形状就留在中央无法到达角落。

中央四个半侧轮廓各自隐含一个对称实心形状，填充实例化后分别平移至网格的四个角落。

**输入结构**：约 16x16 的网格，黑(0)背景。在网格中央区域（约 8x8 范围内），4 个绿(3)半侧轮廓图形按 2x2 布局排列，相邻轮廓之间至少间隔 2 行 2 列。每个半侧轮廓是一个水平对称闭合轮廓的左半部分（高 3~5 像素，宽 2~3 像素），由绿色像素勾勒，不同轮廓的具体形状各异。每个半侧轮廓的最右列紧邻其隐含的垂直对称轴（轴本身不画出）。生成约束：每个半侧轮廓的对称展开 + 内部填充后产生的实心形状不超过 5x5 像素，以确保放入角落时不超出网格边界；4 个实心形状互不全等（至少有一个与其余不同）。

**规则**：
1. 识别 4 个绿(3)半侧轮廓，确定每个的边界框和其在 2x2 中央布局中的位置（左上、右上、左下、右下）。
2. 对每个半侧轮廓：
   a. 取其最右列为对称轴左边界。对称轴位于最右列右侧 0.5 像素处（即镜像时，最右列的像素映射到最右列 +1 的位置）。
   b. 擦除原始轮廓像素（设为黑(0)）。
   c. 对轮廓原来占据的每一行，找到该行最右边的绿色像素位置 c_right。其镜像位置为 c_mirror = c_right + 1 +（c_right + 1 - c_right - 1）= 最右列 + 1 +（最右列 - c_right）。简化：镜像位置 = 2 * (最右列 + 1) - c_right - 1。
   d. 填充该行中 c_right 与 c_mirror 之间（不含两端）的所有像素为绿(3)。若 c_right 与 c_mirror 相邻（间距 <= 1），该行无内部填充。
   e. 结果是一个实心绿色形状（不含原始轮廓线，仅含内部填充区域）。
3. 将 4 个实心形状按其在 2x2 布局中的位置平移至网格对应角落：
   - 左上位置的形状：移至网格左上角（形状的左上角像素对齐网格 (0,0)）。
   - 右上位置的形状：移至网格右上角（形状的右上角像素对齐网格 (0, W-1)，W 为网格宽度）。
   - 左下位置的形状：移至网格左下角（形状的左下角像素对齐网格 (H-1, 0)，H 为网格高度）。
   - 右下位置的形状：移至网格右下角（形状的右下角像素对齐网格 (H-1, W-1)）。
4. 中央区域清空为黑(0)（所有原始轮廓和中间产物均不保留）。

**关键洞察**：输入中可见的轮廓不是最终对象——它们是形状的"编码"。轮廓需经过擦除-镜像-填充三步才能变为实心形状，然后实心形状再按空间位置映射到角落。这种"编码 → 实例化 → 放置"的推理链中，轮廓的几何含义（它编码的是哪个实心形状）需要对比多个示例才能归纳出镜像填充规则。

## 新题 10：跨轴反射配合字形解码确定涂色

**组合逻辑**：[镜像(mirror)](跨轴反射生成副本) + [重涂色(recolor)](字形解码确定颜色) — 字形同时占据反射落点并编码涂色

**来源原语**：mirror / reflection_across_axis / axis_segment / sprite (88207623), recolor / code_glyph / glyph_maps_color / pairing (ed74f2f2), marker_color_paint (88207623)

**依赖链**：反射操作确定副本的位置和形状，字形解码确定副本的颜色——两者缺一不可。字形既是空间标记（占据反射目标区域，表明"这里需要放置反射副本"）又是颜色编码（其形状决定副本涂什么色）。

将黄色对象跨红色轴段反射，反射落点处的灰色字形的形状编码了反射副本的涂色。

**输入结构**：约 15x18 的网格，黑(0)背景。1~2 条红(2)垂直线段（各为连续的同列红色像素，长 3~6 像素）作为镜像轴。每条红色线段的一侧（左或右）有一个 8-连通黄(4)不规则对象（4~8 像素）紧邻红线。在红线的另一侧，与黄色对象的反射落点区域重叠的位置，有一个 3x3 灰(5)/黑(0)字形图案。字形的非黑像素均为灰(5)。生成约束：每个字形的 3x3 范围完全落在对应黄色对象的反射落点区域内部；不同红线旁的字形形状可以不同；字形的形状与颜色之间的映射关系在同一题的所有示例中保持一致，但需对比多个示例才能归纳。

**规则**：
1. 识别每条红(2)垂直线段及其一侧的黄(4)对象。
2. 将黄色对象的每个像素关于红线所在列做水平反射，得到反射副本的像素位置。
3. 在反射落点区域内定位 3x3 灰色字形。根据字形形状查阅编码表得到一个目标颜色（编码表需从多个训练示例中归纳，例如：某字形 → 蓝(1)，另一字形 → 绿(3)，另一字形 → 橙(7)）。
4. 将反射副本的所有像素涂为解码得到的目标颜色，放置在反射位置。
5. 保留原始黄色对象、红色轴段。字形像素被反射副本覆盖（反射副本优先级高于字形）。
6. 若反射副本的某个像素落在网格外，则舍弃该像素。

**关键洞察**：与 88207623 不同（那里是单个标记像素直接提供颜色），本题的颜色需通过字形形状间接解码获得。字形承担双重功能：其存在和位置标识了"此处需要反射副本"，其形状编码了"副本涂什么颜色"。解码规则必须通过对比多个示例中字形形状与最终副本颜色的对应关系来归纳。
