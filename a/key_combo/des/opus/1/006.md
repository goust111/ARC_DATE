## 新题 1：射线建墙与交替洪泛走廊

**组合逻辑**：[射线延伸](创新：射线不再是输出装饰，而是创建中间墙体结构) + [碰撞停止](已有) → [洪泛填充](创新：填充的不是预设迷宫，而是射线动态构建的走廊) + [路径奇偶交替涂色](创新：双种子竞争式BFS，由距离近者着色)

**来源原语**：射线延伸、碰撞停止 ← e12f9a14；洪泛填充、路径奇偶交替涂色 ← b782dc8a；孤立像素 ← 2c608aff

**依赖链**：灰色像素发射四方向射线 → 射线交汇形成墙体网格 → 墙体将画布分割为走廊区域 → 两个种子像素分别从各自位置发起BFS洪泛 → 每个走廊格按最近种子的BFS奇偶性交替着色

射线构建的墙体决定了走廊的拓扑结构；走廊拓扑决定了BFS洪泛的路径与距离；双种子竞争使最终涂色取决于相对距离而非绝对距离。

**输入结构**：
- 网格约 15x15，背景为黑(0)。
- 4-8 个灰(5)孤立单像素，散布于网格中，彼此不在同一行或同一列。
- 2 个种子像素，分别为红(2)和蓝(1)，各占一个单像素位置。
- 种子不在任何灰像素的同行或同列上（确保种子始终位于走廊区域内）。
- 生成约束：两个种子位于同一连通走廊区域内（射线建墙后，两种子通过黑色走廊4-连通可达）。

**规则**：
1. 每个灰(5)像素向上、下、左、右四个方向各发射一条射线。射线沿直线逐格将黑(0)格涂为灰(5)，遇到以下情况停止：下一格超出网格边界，或下一格已为非黑色（即已有灰墙或种子）。终止条件格本身不被涂色，射线包含发射像素自身。
2. 所有射线绘制完毕后，灰(5)格构成墙体；剩余的黑(0)格与种子格构成走廊区域。
3. 从红(2)种子和蓝(1)种子同时发起多源BFS（4-连通，仅通过黑(0)格扩展）。每个走廊格被指派给BFS距离更近的种子；若距离相等，该格涂为黄(4)。
4. 被指派给红种子的走廊格：BFS距离为偶数 → 涂红(2)，奇数 → 涂蓝(1)。被指派给蓝种子的走廊格：BFS距离为偶数 → 涂蓝(1)，奇数 → 涂红(2)。距离0即种子本身，保持原色。
5. 灰(5)墙体格保持不变。

**关键洞察**：走廊并非预制迷宫——它完全由灰像素的位置关系动态决定；不同的灰像素布局生成截然不同的走廊拓扑，进而改变双种子竞争的BFS图案。

## 新题 2：嵌套框缺口连通与种子洪泛重涂

**组合逻辑**：[严格包含](已有) + [框架缺口](创新：缺口不再发射射线，而是充当洪泛的通道) → [洪泛填充](创新：填充穿越多层框架缺口传播) → [重涂色](创新：涂色由拓扑可达性决定而非包含层级)

**来源原语**：严格包含、最外层颜色继承 ← 7d1f7ee8；框架缺口 ← e12f9a14；洪泛填充、路径连通 ← b782dc8a；保留边框涂内部 ← 50cb2852

**依赖链**：识别嵌套矩形框层级 → 定位每个框的单像素缺口 → 从外部种子发起4-连通洪泛 → 洪泛仅能通过缺口穿透框边界 → 缺口朝向与嵌套层级共同决定哪些内部区域可达 → 可达区域重涂为种子颜色

内部区域的颜色不是由包含它的最外层框决定（与参考题 7d1f7ee8 不同），而是由哪个外部种子能通过缺口链路到达它来决定。外框有缺口不意味着内框可达——内框本身也必须有朝向正确方向的缺口。

**输入结构**：
- 网格约 18x18，背景为黑(0)。
- 2-4 个矩形边框，每个边框为单像素宽的单色边界，颜色各不相同（如绿(3)、品红(6)、橙(7)、青(8)），部分框严格嵌套在其他框内部。
- 每个矩形边框恰好有一个1像素缺口：边框的某个边界位置为黑(0)背景色而非框色。
- 2-3 个种子像素位于所有框的外部，颜色各不相同（如红(2)、蓝(1)、黄(4)），各占单像素。
- 每个框至少 6x6（保证有非空内部区域）。
- 生成约束：每个最内层可达区域仅能被一个种子的洪泛到达（不存在两个种子同时可达同一最内层区域的情况）。不同种子可到达不同的框内部区域。至少存在一个框的内部区域不被任何种子到达。

**规则**：
1. 识别所有矩形边框及其严格包含层级关系。
2. 定位每个边框的唯一缺口像素（边框上颜色为黑(0)的位置）。
3. 从每个种子像素发起4-连通洪泛填充，仅通过黑(0)格扩展。洪泛不能穿越边框像素（非黑的边框格），只能通过缺口（边框上的黑色位置）进入框内部。
4. 对于被某个种子洪泛到达的框内部区域，将该区域内所有黑(0)像素重涂为该种子的颜色。
5. 未被任何种子到达的框内部区域保持黑(0)不变。
6. 所有边框像素保持原色不变。种子像素保持原色。

**关键洞察**：外层框的缺口开启了通往内层的可能性，但内层框自身的缺口位置决定了洪泛是否真正能渗透——缺口必须面向洪泛已到达的区域。缺口朝向与嵌套结构共同构成了一个隐式的可达性拓扑。

## 新题 3：瓦片前景计数驱动同心环色板

**组合逻辑**：[计数](已有) + [排序](已有) → [距离映射](创新：距离场的颜色不来自固定色板，而由瓦片计数排序动态生成) + [曼哈顿距离](已有)

**来源原语**：计数、排序、前景数决定排序、阵列排布、瓦片 ← dc2aa30b；同心环、距离映射、曼哈顿距离、循环色板 ← aaef0977；分隔线 ← dc2aa30b；标记像素 ← aaef0977

**依赖链**：在3x3瓦片阵列中计数每个周边瓦片的前景像素 → 按计数排序得到8个瓦片的排名 → 每个瓦片的主色（非黑非前景的颜色）按排名顺序排列成色板 → 以中心瓦片的标记像素为圆心，在与输入同尺寸的输出网格上绘制曼哈顿距离同心环 → 环k使用色板第k个颜色（循环）

两种完全不同的几何结构——瓦片阵列和同心环——通过计数排序这个桥梁连接。阵列在输出中完全消失，被环结构取代。

**输入结构**：
- 11x11 网格，由两条黑(0)横行（第3、7行，0起始索引）和两条黑(0)纵列（第3、7列）将网格分割为3x3阵列的3x3瓦片。
- 中心瓦片（第1行第1列，0起始索引）包含一个标记像素（灰(5)），其余格为黑(0)。灰像素的位置即为同心环圆心在整个网格中的坐标。
- 8个周边瓦片各有若干蓝(1)前景像素和一个独特的底色（从红(2)、绿(3)、黄(4)、品红(6)、橙(7)、青(8)、栗(9)、灰(5)中选取，每个瓦片底色不同）。瓦片内非蓝非黑的格均为该瓦片底色。
- 8个周边瓦片的蓝(1)像素计数互不相同（各为1-8中的某个值，无平局）。
- 生成约束：8个瓦片的蓝像素数恰好覆盖1到8各一次。

**规则**：
1. 计数每个周边瓦片（排除中心瓦片）中蓝(1)像素的数量。
2. 按蓝像素数从小到大排序8个瓦片，得到排名1-8。
3. 构建色板序列：色板[k] = 排名为k的瓦片的底色（即该瓦片中非蓝非黑的颜色）。
4. 构建与输入同尺寸（11x11）的输出网格。以中心瓦片标记像素的全局坐标(r0, c0)为圆心。
5. 输出网格中每个位置(r, c)的曼哈顿距离 d = |r - r0| + |c - c0|。距离0处涂灰(5)（标记色）。距离d处涂色板[(d-1) mod 8]（1起始循环）。
6. 输出网格中原黑色分隔线位置也按曼哈顿距离涂色，不保留分隔线。

**关键洞察**：瓦片阵列仅用于编码色板——它在输出中被完全替换为以标记点为中心的同心环图案。仅看环形输出无法得知色板来源；仅看瓦片阵列无法得知环的形状。必须跨越两种几何理解才能求解。

## 新题 4：十字擦除改变缺口状态决定滑动方向

**组合逻辑**：[十字擦除](已有) + [特定色像素豁免](已有) → [缺口决定方向](创新：缺口的有无不是输入固有属性，而由十字擦除动态产生或消除) → [滑动](已有) + [重涂色](已有)

**来源原语**：十字擦除、标记块、特定色像素豁免 ← 319f2597；滑动、缺口决定方向、靠边对齐、重涂色 ← 320afe60；前景对象、边框缺口 ← 320afe60

**依赖链**：定位2x2黑色标记 → 标记的两行两列构成十字擦除区 → 十字区内非红像素被擦除为背景，红像素豁免 → 擦除可能切断对象使其分裂为多个连通分量 → 擦除可能在对象边框上新增缺口或恰好因红色豁免保住边框完整性 → 重新分析每个4-连通分量的边框缺口状态 → 有缺口者滑向右边并涂绿，无缺口者滑向左边并涂栗

十字擦除作用于对象的结构本身，改变了用于判断滑动方向的形状属性。同一个对象在擦除前后可能从"无缺口"变为"有缺口"（因为十字切掉了边框像素）或保持不变（因为红色像素恰好保护了边框完整性）。

**输入结构**：
- 网格约 15x20，背景为黄(4)。
- 5-7 个灰(5)4-连通单色对象，每个3-8像素，形状各异（非特定命名形状，通过连通性和像素数描述）。部分对象的某些像素为红(2)而非灰(5)（红像素与灰像素共同构成该对象的4-连通体）。
- 一个2x2黑(0)标记块。
- 标记块的十字区域（其占据的两行和两列的全部格）穿过至少3个对象。
- 生成约束：至少一个对象在擦除前无缺口但擦除后产生缺口（灰像素被擦除导致边框出现间隙）；至少一个对象在擦除前有缺口但因红像素保护了关键位置而在擦除后仍保持缺口（或失去缺口）；至少一个对象完全不在十字区域内（不受擦除影响）。擦除后不同连通分量的滑动路径互不冲突（它们位于不同行段）。

**规则**：
1. 定位唯一的2x2黑(0)标记块。选取标记块占据的两行和两列，它们的并集构成十字区域。
2. 十字区域内的每个非红、非黄（即非保护色、非背景色）的像素被擦除为黄(4)背景色。红(2)像素和黄(4)背景不受影响。
3. 移除2x2标记块本身（涂为黄(4)背景）。
4. 对擦除后的网格重新检测所有4-连通非背景对象（灰(5)和红(2)像素组成的连通分量）。一个原始对象可能因擦除而分裂为多个独立分量，各分量独立处理。
5. 对每个分量：计算其边界框。检查边界框的四条边（上、下、左、右边缘行/列）上是否存在"缺口"——即该边缘上有连续的背景色(4)间隙，且间隙两侧（沿该边缘方向）有该分量的像素。
6. 有缺口的分量：整体平移到网格右边缘（保持行位置不变，最右像素贴齐网格右边界），所有像素重涂为绿(3)。无缺口的分量：整体平移到网格左边缘（最左像素贴齐网格左边界），所有像素重涂为栗(9)。
7. 滑动在空白背景画布上进行——先清空所有非背景内容，再按上述规则放置。

**关键洞察**：对象的滑动方向不是其固有属性——十字擦除动态改变了对象形状，使得方向判断依赖于擦除结果。红像素的保护作用创造了"同在十字区内但命运不同"的差异化效果。

## 新题 5：重叠框遮挡推断绘制顺序与深度涂色

**组合逻辑**：[严格包含](创新：不是真正的包含关系而是重叠遮挡关系，需逆向推断) + [计数](创新：计数的不是前景像素而是遮挡事件) → [重涂色](创新：涂色依据不是框自身颜色而是推断出的深度排名)

**来源原语**：矩形边框、严格包含 ← 7d1f7ee8；重涂色、最外层颜色继承 ← 7d1f7ee8；保留边框涂内部、矩形内部 ← 50cb2852；前景矩形 ← 50cb2852

**依赖链**：识别多个互相重叠的矩形边框 → 从可见边框像素重建每个框的完整边界框 → 分析重叠区域的遮挡关系（上层框的像素覆盖下层框的像素） → 推断从底到顶的绘制顺序(z-order) → 按z-order排名为每个框的内部涂上对应颜色

本题的推理核心是逆向工程：观察到的遮挡模式编码了绘制顺序，而绘制顺序又决定了输出的内部填色。没有空间包含层级，只有平面上的遮挡关系。

**输入结构**：
- 网格约 18x18，背景为黑(0)。
- 3-5 个矩形边框（单像素宽边界），颜色互不相同（从绿(3)、黄(4)、品红(6)、橙(7)、青(8)中选取）。
- 框与框之间存在部分重叠（边框交叉）。在重叠区域，后绘制（更高层）的框的边框像素覆盖了先绘制（更低层）的框的边框像素。
- 每个框至少 5x5，有非空的内部区域。
- 没有框完全嵌套在另一个框的内部——所有框都是在同一平面上部分重叠。
- 生成约束：从可见像素可以唯一确定每个框的完整边界框（每个框至少有两个对角位置或足够的边段可见）。遮挡关系可以唯一确定一个全序的z-order（即任意两个有重叠的框之间都能判定谁在上）。

**规则**：
1. 从可见的边框像素出发，重建每个矩形边框的完整边界框（包括被遮挡而不可见的部分）。每个颜色对应一个框。
2. 对于每一对有重叠区域的框A和B：如果在重叠区域中，A色像素被B色像素遮盖（即应出现A色的位置显示了B色），则B在A之上。
3. 建立从底到顶的z-order全序。最底层为排名1，最顶层为排名N。
4. 对排名为k的框，将其完整边界框内部（不含边框本身）所有像素涂为对应颜色：排名1→蓝(1)，排名2→红(2)，排名3→绿(3)，排名4→黄(4)，排名5→灰(5)。
5. 所有框的边框像素保持其原始颜色不变。若多个框的内部区域有重叠，排名高（更上层）的框的内部填色覆盖排名低的。
6. 背景保持黑(0)。

**关键洞察**：内部填充颜色与框的边框颜色无关——它完全由重叠遮挡推断出的深度位置决定。求解者必须先完成空间推理（重建被遮挡的边框，判断遮挡方向），再将推理结果映射到与原始颜色无关的新色方案。

## 新题 6：射线搭台与重力沉降

**组合逻辑**：[连线/射线延伸](已有) + [行列对齐](已有) → [重力沉降](创新：重力的着陆面不是预设的基线行，而是射线动态创建的水平线段) + [碰撞停止](创新：碰撞对象是先前步骤生成的射线，不是原始输入中的物体)

**来源原语**：连线、射线延伸、行列对齐、对齐像素投射矩形、碰撞停止 ← 2c608aff；重力沉降、同列对齐、前景像素、基线行 ← 3618c87e；矩形 ← 2c608aff

**依赖链**：识别与矩形行列对齐的像素 → 对齐像素向矩形发射射线形成固定线段 → 射线线段成为网格中的固定障碍物 → 非对齐像素在重力作用下逐列下落 → 下落像素被射线线段、矩形顶面或网格底边拦截而停止

射线的功能从"连接标记"变为"搭建着陆平台"。对齐像素创造的水平射线充当悬浮平台，截住其他下落的像素。同一根射线可能同时拦截多个下落像素。

**输入结构**：
- 网格约 15x18，背景为黑(0)。
- 一个绿(3)填充矩形（约 4x6）位于网格中部偏下。
- 6-10 个孤立单像素，颜色各异（从红(2)、蓝(1)、黄(4)、品红(6)、橙(7)、栗(9)中选取），散布在网格各处。
- 部分像素与矩形共享行或列（"对齐像素"），其余不共享任何行列（"自由像素"）。
- 对齐像素位于矩形的同一行或同一列，但不与矩形相邻（之间至少隔1格黑色空间）。
- 生成约束：没有两个对齐像素在同一行同时列对齐，也没有在同一列同时行对齐（避免射线重叠歧义）。自由像素不在矩形的任何行或列上。自由像素的初始位置均在其最终着陆位置之上（即有下落空间）。

**规则**：
1. 识别背景色（黑(0)）和最大前景连通体（绿(3)矩形）。所有其他单像素为操作对象。
2. 对于每个与矩形共享行的像素：从该像素位置向矩形方向沿水平方向绘制一条线段，使用灰(5)颜色。线段从像素位置（含）延伸到矩形边缘的前一格（含），即线段不覆盖矩形本身。该像素被灰(5)线段吸收（成为线段的一部分）。
3. 对于每个与矩形共享列的像素：从该像素位置向矩形方向沿垂直方向绘制一条线段，使用灰(5)颜色。线段从像素位置（含）延伸到矩形边缘的前一格（含）。该像素被灰(5)线段吸收。
4. 灰(5)线段和绿(3)矩形现在都是固定障碍物。
5. 对剩余的自由像素（未发射射线的像素），逐列从下到上处理：每个像素在其列内向下移动，直到碰到以下任一阻挡物的上一格为止——网格底边、绿(3)矩形顶面、灰(5)线段的上表面、或同列中已着陆的另一个像素的上方。像素保持原始颜色。
6. 着陆顺序：同一列内多个自由像素按初始行号从大到小（最靠下的先落）依次着陆。

**关键洞察**：对齐像素牺牲自身位移能力来构建着陆平台——它们画出的射线成为"架子"，改变了自由像素的着陆位置。移除射线步骤则所有像素直接落到底部或矩形顶面；移除重力步骤则自由像素悬空不动。两步之间的依赖是单向因果但结构上紧密耦合。

## 新题 7：嵌套框内逐层镜像铺展

**组合逻辑**：[严格包含](已有) + [面积递减嵌套](创新：面积排序不再用于重新组装，而用于确定铺展的处理顺序) → [镜像](创新：镜像不再作用于整幅网格，而是对每层框内的角落种子图案分别进行四象限铺展) + [平铺](创新：铺展范围被框的内部区域限定)

**来源原语**：严格包含、矩形边框、面积递减嵌套 ← 6cbe9eb8, 7d1f7ee8；镜像、四象限排布、翻转形成对称铺展 ← 62c24649；平铺 ← 48f8583b；裁剪 ← ce602527

**依赖链**：识别嵌套矩形框层级 → 按面积从小到大排序确定处理顺序 → 对每个框提取其左上角内部的种子图案 → 对种子图案进行四象限镜像铺展填充该框内部 → 从内到外处理保证内层框的边框和已铺展内容不被外层覆盖

每层框的种子图案、框的尺寸、框的嵌套关系三者共同决定最终的分层铺展效果。内层铺展结果被外层铺展视为已有结构而保留。

**输入结构**：
- 网格约 20x20，背景为黑(0)。
- 2-3 个嵌套矩形边框，各框颜色不同（如绿(3)、橙(7)、品红(6)），各为单像素宽边界。框之间严格嵌套（每个内框完全位于外框内部）。
- 每个框的内部左上角区域（紧贴框的上边界和左边界的内侧）有一个小的种子图案：由2x2或3x3的彩色像素组成，使用与所有框边框色都不同的颜色（如蓝(1)、红(2)、黄(4)等）。不同框的种子颜色不同。
- 每个框内部除种子图案和更内层的框之外，其余均为黑(0)。
- 每个框的内部区域（不含边框）在宽和高上至少是其种子图案尺寸的2倍（确保铺展至少覆盖2x2个镜像瓦片）。
- 生成约束：种子图案不触碰内层框的边框（种子在左上角，内层框不在左上角附近）。

**规则**：
1. 识别所有矩形边框并建立严格包含的嵌套层级。
2. 按边框围成面积从小到大排序（最内层框最先处理）。
3. 对当前处理的框F：
   a. 提取F内部左上角的种子图案P（从F上边框内侧第一行、左边框内侧第一列开始，取最大的非黑矩形区域）。
   b. 构建四象限镜像瓦片：将P水平翻转得到P'，拼接[P | P']为上半行；再将上半行垂直翻转得到下半行；拼接为一个2W x 2H的对称瓦片T（W、H为P的宽和高）。
   c. 用T重复铺满F的整个内部区域（不含F的边框像素）。铺展从F内部左上角开始，向右向下重复T，超出F内部边界的部分裁剪。
   d. 铺展不覆盖已有的非黑像素（即内层框的边框和内层已铺展的内容被保留）。
4. 从最内层到最外层依次处理所有框。
5. 所有框边框保持原色不变。框外部区域保持黑(0)。

**关键洞察**：处理顺序（从内到外）是关键——它确保内层的精细图案不被外层的铺展覆盖。每层的视觉效果都是在前一层结果之上叠加的，形成由内而外的分层镜像纹理。

## 新题 8：跨尺度形状匹配提取壁纸周期

**组合逻辑**：[形状匹配](创新：匹配不再用于选择返回对象，而用于提取数值参数——尺度比例) + [跨尺度同形](已有) → [周期推断](创新：瓦片尺寸不再通过自身周期搜索确定，而由外部形状匹配比例给定) + [间隙填充](已有)

**来源原语**：形状匹配、跨尺度同形、返回较小者、缩放对象、干扰对象 ← ce602527；周期推断、间隙填充、忽略缺失值推断、周期瓦片、缺失像素 ← 1d0a4b61；裁剪 ← ce602527

**依赖链**：右半区域三个小对象进行形状匹配 → 识别出同形对的尺度比S → 左半区域的壁纸用SxS作为瓦片尺寸 → 忽略黑洞推断唯一最小SxS周期瓦片 → 用推断出的瓦片填补所有黑洞 → 裁剪输出为左半区域

形状匹配和周期推断分属不同空间区域，通过一个提取出的数值参数（尺度比）连接。这种跨区域的参数传递在任何参考题中都不存在。

**输入结构**：
- 网格约 15x20，由一条灰(5)纵向分隔线（单像素宽，贯穿整个网格高度）分为左右两个区域。
- 左半区域（约 15x9）：一个由若干非黑颜色（如红(2)、蓝(1)、绿(3)）构成的周期性壁纸图案，部分格被替换为黑(0)（缺失数据）。壁纸的真实最小重复瓦片为 SxS（S=2或3）。每种瓦片相位在非黑格中至少出现一次。
- 右半区域（约 15x10）：黑(0)背景上有三个小型单色对象，颜色互不相同（如黄(4)、橙(7)、品红(6)），各自4-连通。其中两个对象形状相同但尺度不同（如一个3像素、另一个12像素，尺度因子S=2，含义为较大者的宽高都是较小者的S倍）。第三个对象是干扰项，与前两者形状不同。
- 生成约束：两个同形对象的尺度因子S等于左半区域壁纸的最小重复瓦片的边长。左半区域在给定SxS瓦片尺寸下存在唯一的最小周期瓦片。

**规则**：
1. 在右半区域中，按颜色分离三个对象。对每对对象进行形状匹配：将较小者的掩码按整数因子（2或3）放大后与较大者的掩码比较。找到唯一的同形对，记录尺度因子S。忽略干扰对象。
2. 在左半区域中，以SxS为瓦片尺寸，从所有非黑像素中推断唯一的最小周期瓦片。黑(0)格视为缺失数据，不参与推断约束。瓦片的每个相位(r mod S, c mod S)的颜色由该相位位置上的非黑像素一致确定。
3. 用推断出的瓦片填充左半区域中的所有黑(0)格：每个位置(r, c)涂为瓦片在相位(r mod S, c mod S)处的颜色。
4. 输出为左半区域的填充结果（裁剪掉灰分隔线和右半区域）。

**关键洞察**：壁纸的周期长度不是通过自动搜索所有可能瓦片尺寸找到的——它被编码在另一个区域的形状尺度比中。求解者必须先在右侧完成形状匹配以获得S，才能在左侧正确推断瓦片。若S猜错，推断出的瓦片将与可见像素矛盾。

## 新题 9：洪泛可达性约束下的分区周期推断

**组合逻辑**：[洪泛填充](创新：洪泛不直接产生输出颜色，而是定义"哪些像素参与推断") + [路径连通](已有) → [周期推断](创新：推断的证据集被洪泛可达性过滤) + [间隙填充](创新：仅填充可达区域的缺失格)

**来源原语**：洪泛填充、路径连通、迷宫走廊、种子像素 ← b782dc8a；周期推断、间隙填充、忽略缺失值推断、周期瓦片、缺失像素 ← 1d0a4b61

**依赖链**：从种子像素发起洪泛标记可达走廊格 → 可达区域中的非黑像素构成周期推断的证据集 → 仅从该证据集推断最小周期瓦片 → 仅填充可达区域内的黑洞 → 不可达区域完全保持原状

洪泛可达性同时约束了两件事：(1)参与推断的证据来源，(2)接受填充的目标区域。如果将不可达区域的像素也纳入推断，可能得到错误的瓦片（因为不同连通区域可能包含不同的周期图案）。

**输入结构**：
- 网格约 15x15，青(8)像素构成迷宫墙壁。
- 黑(0)格构成迷宫走廊。走廊中部分格包含非黑非青的彩色像素（如红(2)、蓝(1)、绿(3)），这些彩色格是一个周期性壁纸图案的可见部分。
- 走廊中其余为黑(0)的格是壁纸的缺失像素（黑洞）。
- 1个种子像素（黄(4)）位于某个走廊入口处。
- 迷宫将走廊分为至少2个互不连通的区域（4-连通不可达）。种子仅位于其中一个区域内。
- 每个连通区域内的彩色像素各自构成一个一致的周期图案，但不同区域的图案可能不同（瓦片颜色或排列不同）。
- 生成约束：种子所在区域内的非黑彩色像素足以唯一确定该区域的最小周期瓦片。不可达区域内也有彩色像素，但若与可达区域的像素合并推断，会产生矛盾或不同的瓦片。

**规则**：
1. 从黄(4)种子像素发起4-连通洪泛填充，通过黑(0)格和非青彩色格扩展（青(8)墙壁阻断）。标记所有可达格。
2. 收集可达区域内的所有非黑、非青、非黄像素作为周期推断的证据。
3. 在可达区域的空间范围内，以这些证据像素的颜色和位置推断最小周期瓦片（忽略黑洞和种子格）。瓦片相位以网格左上角(0,0)为基准对齐。
4. 用推断出的瓦片填充可达区域内所有黑(0)格：位置(r, c)涂为瓦片相位(r mod H, c mod W)处的颜色（H、W为瓦片高宽）。
5. 种子像素(黄(4))也被瓦片相位颜色替换。
6. 不可达区域的所有格（包括其中的彩色像素和黑洞）保持原状不变。
7. 青(8)墙壁保持不变。

**关键洞察**：不同连通区域可能暗藏不同的周期图案——如果不通过洪泛划定证据边界就直接推断，将混入不可达区域的"干扰证据"导致推断失败。洪泛可达性不仅是空间划分工具，更是保证推断正确性的逻辑前提。
