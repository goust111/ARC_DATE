## 新题 1：光晕触碰计数生成框内点阵

**组合逻辑**：[膨胀/光晕](创新：光晕作为空间探测范围) + [同色匹配](已有) + [计数](创新：以物理接触而非纯色匹配为计数条件) + [绘点](已有)

**来源原语**：膨胀/光晕(4258a5f9)、同色匹配(8f215267)、计数/绘点(8f215267)、空心框架(8f215267)、标记保留原色(4258a5f9)

**依赖链**：标记像素膨胀产生光晕 → 光晕是否物理接触框架边界决定该标记是否被该框架计入 → 每个框架的触碰计数决定其内部绘制的点数 → 绘点完成后擦除所有标记和光晕

一句话总结：每个空心框架内绘制的点数等于同色标记像素中光晕能触及该框架的个数。

**输入结构**：黑(0)背景，约 15x15 网格。网格中有 3-4 个空心矩形框架（仅边框像素，内部为背景），每个框架的边框颜色互不相同，可选自蓝(1)、红(2)、绿(3)、黄(4)。框架大小约 4x4 至 6x6，彼此不重叠且不相邻（间距至少 2 格）。网格中另有若干单像素标记点（每个标记点颜色与某个框架颜色相同），散布在框架外部的不同位置。标记点到同色框架的 Chebyshev 距离有些为 1（光晕恰好触碰），有些大于 1（光晕无法触碰）。每种颜色的标记点数量为 1-4 个。生成约束：不同颜色的标记点不会出现在同一位置；同色标记点的光晕（3x3 邻域）互不重叠。

**规则**：
1. 对每个标记像素，生成其 3x3 Chebyshev 邻域（即光晕），颜色与标记相同，超出网格边界的部分舍弃。
2. 对每个颜色为 C 的空心框架 F，扫描所有颜色为 C 的标记像素：若该标记的光晕（含标记自身位置）中至少有一个像素与 F 的边框像素在同一位置（即光晕与框架物理接触），则该标记被 F 计入。
3. 统计 F 的被计入标记数 N。
4. 在 F 的内部区域，沿内部中间行（若内部高度为偶数则取偏上的一行），从最右侧内部列开始，每隔 1 列绘制一个颜色为 C 的点，共绘 N 个点。若内部宽度不够容纳所有点，则从中间行下移一行继续从右往左绘制剩余点。
5. 从输出中移除所有标记像素和光晕像素（恢复为背景色）。框架边框保持不变。

**关键洞察**：不是所有同色标记都被框架计入——只有光晕在空间上触及框架边界的才算。需要对比多个示例来确认是物理接触（Chebyshev 距离 <= 1）而非简单的同色关系决定计数。

## 新题 2：封闭区域奇偶性决定镜像补全方向

**组合逻辑**：[计数](创新：计数结果的奇偶性作为控制流分支条件) + [镜像](创新：镜像轴由计数奇偶决定而非几何宽高比) + [擦除](已有)

**来源原语**：计数/封闭区域/分隔框架(89565ca0)、镜像/内部母题/矩形框架(18419cfa)、擦除(758abdf0)、重建(89565ca0)

**依赖链**：识别框架内的分隔墙 → 计数封闭背景区域 → 区域数奇偶性选择镜像轴（奇=左右，偶=上下）→ 沿选定轴镜像补全母题 → 擦除分隔墙保留补全结果

一句话总结：每个带内部隔墙的框架中，隔墙划出的封闭区域数的奇偶性决定其内部半完成母题是水平还是垂直镜像补全，随后隔墙被移除。

**输入结构**：黑(0)背景，约 18x18 网格。网格中有 2-3 个矩形框架，框架边框颜色为灰(5)，大小约 7x7 至 9x9，彼此不重叠（间距至少 1 格）。每个框架内部存在同为灰(5)的直线段隔墙（水平或垂直各一到两条，将内部空间分成 2-4 个封闭的背景区域）。每个框架还包含一组橙(7)像素构成的母题图案（4-连通、3-8 像素、不规则形状）。母题仅占据框架内部的一半区域——对于奇数个封闭区域的框架，母题位于左半部分（右半为空）；对于偶数个封闭区域的框架，母题位于上半部分（下半为空）。母题不与隔墙重叠。生成约束：每个框架的封闭区域数互不相同且均在 2-4 之间；框架的宽高比接近 1:1（排除通过宽高比猜测镜像轴的可能）。

**规则**：
1. 对每个灰(5)框架，识别其内部所有灰(5)隔墙线段（与边框同色、位于框架内部的直线段）。
2. 计算框架边框 + 隔墙共同围出的 4-连通背景封闭区域数 N。
3. 若 N 为奇数：以框架内部的垂直中轴为对称轴，将所有橙(7)母题像素左右镜像到对面位置。
4. 若 N 为偶数：以框架内部的水平中轴为对称轴，将所有橙(7)母题像素上下镜像到对面位置。
5. 镜像产生的新像素若落在隔墙位置，仍然绘制母题色（覆盖隔墙）。
6. 最后，擦除框架内部所有残余的灰(5)隔墙像素（恢复为背景色）。框架边框保留。

**关键洞察**：镜像轴不由框架的几何宽高比决定（框架刻意设计为近正方形），而由内部隔墙划分出的封闭区域数的奇偶性决定。必须对比不同框架的隔墙结构与镜像方向才能归纳此规则。

## 新题 3：边界标记朝向决定色条周期延伸方向

**组合逻辑**：[边界标记/标记指定观察方向](创新：标记的边界位置编码延伸方向而非片段朝向) + [周期延伸](创新：延伸方向由外部标记指定而非固定的分隔列定义) + [长度即周期](已有) + [近者优先](已有)

**来源原语**：边界标记/标记指定观察方向(f341894c)、周期延伸/色条/长度即周期(1ae2feb7)、近者优先(1ae2feb7)

**依赖链**：识别边界标记所在的网格边 → 边的方位映射为向内延伸方向 → 同色色条的长度确定周期 → 沿标记指定方向周期延伸色条 → 多条延伸路径冲突时近者优先

一句话总结：网格边界上的彩色标记点指定方向，网格内部的同色水平或垂直色条沿该方向周期性延伸，色条长度为周期。

**输入结构**：黑(0)背景，约 12x12 网格。网格内部散布 3-4 条短色条（水平或垂直连续同色像素段，长度 2-4 格），每条色条颜色互不相同，可选自蓝(1)、红(2)、绿(3)、黄(4)。网格的四条外边界上各有若干单像素标记点，每个标记点的颜色恰好匹配某一条内部色条的颜色。同一颜色最多有一个边界标记。部分色条没有对应的边界标记（无标记的色条不做任何延伸）。生成约束：色条之间不相邻（间距至少 2 格）；边界标记的向内投射方向与同色色条的朝向平行（例如：水平色条对应左边界或右边界上的标记，使延伸方向沿水平轴）；各色条的延伸路径互不交叉。

**规则**：
1. 识别网格四条外边界上的单像素标记。标记所在的边决定延伸方向：上边界 → 向下、下边界 → 向上、左边界 → 向右、右边界 → 向左。
2. 对于颜色为 C 的边界标记，找到网格内部颜色为 C 的色条。该色条的长度 L 即为延伸周期。
3. 沿标记指定的方向，从色条出发，每隔 L 格（空出 L-1 格背景后）重复绘制一段长度为 L 的同色像素段，直到触及网格边界为止。延伸保持色条的行或列位置不变。
4. 无同色边界标记的色条保持原样，不做延伸。
5. 若两条延伸路径在某像素位置冲突（生成约束保证正常情况下不会发生，此规则仅作安全兜底），则保留源色条距离该像素更近的那条颜色。
6. 边界标记像素保留在输出中。

**关键洞察**：色条的延伸方向不是由分隔列的位置决定，而是由网格边界上同色标记点所在的边来指定。需要对比多个示例（标记在不同边、不同色条方向）才能归纳出边界位置→延伸方向的映射。

## 新题 4：对称性筛选后按位置排序输出色条

**组合逻辑**：[对称检测](创新：作为筛选门控而非选择单个瓦片) + [排序](创新：排序键为水平位置而非垂直最高行) + [裁剪/压缩](已有) + [擦除](已有)

**来源原语**：对称检测/瓦片/选无对角对称瓦片(662c240a)、排序/顺序排列/色条行(668eec9a)、裁剪(662c240a)、堆叠排列(662c240a)

**依赖链**：逐个检测瓦片的对角对称性 → 擦除所有对称瓦片 → 收集剩余非对称瓦片 → 按各瓦片边界框最左列排序 → 将各瓦片前景色压缩为 1x3 实心色条行 → 自下而上堆叠输出

一句话总结：在一组散布的两色瓦片中，过滤掉对角对称的瓦片，将剩余非对称瓦片按水平位置排序，输出为自下而上堆叠的色条。

**输入结构**：黑(0)背景，约 15x15 网格。网格中散布 5-6 个 3x3 两色瓦片（每个瓦片由背景色和一种前景色构成），彼此不重叠且间距至少 1 格。每个瓦片的前景色互不相同，可选自蓝(1)、红(2)、绿(3)、黄(4)、灰(5)、品红(6)。瓦片中有些是对角对称的（cell[r,c] == cell[c,r]，相对于瓦片自身左上角）、有些不是。非对称瓦片数量为 2-4 个。各瓦片的边界框最左列值互不相同。生成约束：对称与非对称瓦片混合出现，数量不固定（需从示例中推断筛选规则）。

**规则**：
1. 对每个 3x3 瓦片，测试对角（转置）对称性：对瓦片内所有位置 (r, c)，检查 cell[r,c] 是否等于 cell[c,r]（坐标相对于瓦片左上角）。
2. 丢弃所有对角对称的瓦片。
3. 收集剩余的非对称瓦片。按每个瓦片边界框的最左列值从小到大排序（即从左到右）。若最左列相同（生成约束保证不会），则按最上行从小到大排序。
4. 输出一个宽 3、高 5 的网格，背景为黑(0)。从最底行开始，按排序结果依次向上放置每个非对称瓦片的前景色实心 1x3 色条行。未使用的行保持黑(0)。

**关键洞察**：筛选依据是对角（转置）对称而非左右或旋转对称——仅看一个示例可能无法区分对称类型。排序键是水平位置而非垂直位置或颜色属性，这也需要多个示例来确认。

## 新题 5：周期填充后跨分隔叠加揭示交集

**组合逻辑**：[周期延伸](创新：两侧各自独立周期填充而非单侧填充) + [透明叠加/并集合并](创新：叠加后额外区分「仅一侧前景」与「双侧前景」) + [分隔行](已有) + [重涂色](创新：交集区域获得第三种颜色)

**来源原语**：周期延伸/长度即周期/色条(1ae2feb7)、透明叠加/分隔行/并集合并/逐格对齐(ce4f8723)、重涂色(25d8a9c8)

**依赖链**：分隔行将网格一分为二 → 上下两半各含短色条 → 各色条按自身长度为周期在所属半区内水平周期延伸 → 移除分隔行后上下两半逐格对齐叠加 → 仅单侧前景保持原色、双侧前景交集处重涂为第三色

一句话总结：分隔行两侧的短色条各自周期延伸填满半区，再叠加——单侧有色保持原色，双侧叠加处变为绿色。

**输入结构**：黑(0)背景，约 15x10 网格（15 行 10 列）。正中间一行为品红(6)分隔行（该颜色仅出现在此行）。分隔行将网格分成等高的上半区和下半区（各 7 行 10 列）。上半区包含若干短水平色条，颜色均为蓝(1)，长度 2-3 格，分布在不同行的不同列位置。下半区包含若干短水平色条，颜色均为红(2)，长度 2-4 格，分布在不同行的不同列位置。每个半区内同一行最多一条色条。生成约束：上下两半区至少各有 3 条色条；周期延伸后上下半区必须存在至少 2 处列位置和对应行重合（即延伸后有交集），也必须存在仅一侧有前景的位置。

**规则**：
1. 在上半区内，对每条蓝(1)色条，以其长度 L 为周期，在色条所在行内向左右两侧周期延伸：从色条左端起每隔 L 格绘制一段长 L 的蓝色段（向左），从色条右端起每隔 L 格绘制一段长 L 的蓝色段（向右），直至触及半区左右边界（超出边界部分舍弃）。色条自身位置保留。
2. 对下半区内的每条红(2)色条执行相同的周期延伸操作。
3. 移除分隔行。将上半区与下半区逐格对齐（上半区第 k 行对应下半区第 k 行）。
4. 对于对齐后的每个位置 (r, c)：
   - 若仅上半区该位置为蓝(1)前景：输出蓝(1)。
   - 若仅下半区该位置为红(2)前景：输出红(2)。
   - 若上下两半区该位置均为前景：输出绿(3)。
   - 若两半区该位置均为背景：输出黑(0)。
5. 输出网格尺寸为 7x10（单个半区大小）。

**关键洞察**：输出中的绿(3)像素不在输入中出现——它是两侧周期图案重合的产物。必须先正确理解周期延伸（周期 = 色条长度），再理解叠加规则（交集 → 绿色），两者缺一不可。对比多个示例才能确认交集色为绿(3)而非其他颜色。

## 新题 6：行均匀性反向门控跨面板内容选取

**组合逻辑**：[检测/单色行](创新：均匀性不再标记自身行，而是作为「通行证」让对侧内容通过) + [透明叠加](创新：叠加逻辑由逐行条件动态选择而非全局合并) + [分隔列](已有) + [重涂色](已有)

**来源原语**：检测/行/单色行标记否则黑(25d8a9c8)、透明叠加/分隔列/前景掩码/对齐(e133d23d)、重涂色(e133d23d)

**依赖链**：分隔列将网格分为左右两面板 → 对每行分别检测左半和右半的均匀性 → 均匀侧充当「空白通行证」，让对侧非均匀内容通过 → 双均匀行取并集 → 双非均匀行清空 → 输出宽度为单面板宽度

一句话总结：分隔列两侧面板中，每行的均匀一侧让位给对侧的丰富内容；两侧都均匀则合并，两侧都不均匀则输出空行。

**输入结构**：黑(0)背景，约 10x11 网格（10 行 11 列）。正中间一列为灰(5)分隔列（该颜色仅出现在此列）。分隔列将网格分为等宽的左面板和右面板（各 10 行 5 列）。左面板中部分行的所有 5 个像素为同一非背景色（均匀行），其余行为多色混合（非均匀行）。右面板同理。可选前景色包括蓝(1)、红(2)、绿(3)、黄(4)、橙(7)。每面板内均匀行不超过一半。生成约束：至少存在一行左均匀右非均匀、一行左非均匀右均匀、一行双均匀、一行双非均匀。

**规则**：
1. 移除灰(5)分隔列。对每行 r，分别检查左面板第 r 行和右面板第 r 行的均匀性（该行内所有像素是否为同一颜色，包括全背景色也视为均匀）。
2. 若仅左侧第 r 行均匀（右侧非均匀）：输出第 r 行取右面板第 r 行的内容。
3. 若仅右侧第 r 行均匀（左侧非均匀）：输出第 r 行取左面板第 r 行的内容。
4. 若两侧第 r 行均为均匀：逐格取并集——对每个列位置，若任一侧为非背景色则输出该颜色；若两侧均为非背景色（生成约束保证这种情况下两侧颜色相同），输出该颜色；若两侧均为背景色则输出背景色。
5. 若两侧第 r 行均为非均匀：输出第 r 行全部为黑(0)背景。
6. 输出网格尺寸为 10x5。

**关键洞察**：均匀侧并非被保留到输出中，恰恰相反——均匀意味着「该侧无有效信息，采用对侧」。这与直觉相反（通常均匀行被标记为「特殊」），需要对比多个示例中均匀/非均匀行与输出的对应关系才能发现这一逆向门控规则。

## 新题 7：车道均匀性门控标记条循环推进

**组合逻辑**：[检测/单色行](创新：均匀性判断从行级改为列级，且作为门控而非标记) + [生长/擦除/循环迁移](创新：循环迁移仅在通过均匀性检测的车道中发生) + [边缘满条](已有)

**来源原语**：检测/单色行标记否则黑(25d8a9c8)、生长/擦除/边缘满条/标记条/逐步推进/循环迁移(758abdf0)

**依赖链**：识别边缘满条及其方向 → 对每条垂直车道检测均匀性（排除边缘满条行后该列像素是否均为同色）→ 均匀车道中标记条执行一步循环推进（单像素生长或双像素擦除并迁移到对侧）→ 非均匀车道中标记条保持不动

一句话总结：底部满条定义推进方向，但只有背景色均匀的车道中标记条才实际执行一步循环前进，混杂车道中的标记条被冻结。

**输入结构**：黑(0)背景，约 10x8 网格（10 行 8 列）。最底行为红(2)实心满条（宽度等于网格宽度，高度 1 行）。在满条上方的 9 行中，每列（车道）的情况分两类：(a) 均匀车道——该列中除最底行外所有像素为同一颜色（全黑(0)背景或全为某单色），车道内可能有蓝(1)标记条（1-2 个垂直相邻像素，紧邻满条或距满条 1 格）；(b) 非均匀车道——该列中存在至少两种不同颜色的像素（含背景），也可能有蓝(1)标记条。蓝(1)标记条的朝向为垂直，即同列中 1-2 个连续像素。生成约束：至少有 2 条均匀车道含标记条、2 条非均匀车道含标记条；均匀车道中至少有一条含 1 像素标记、一条含 2 像素标记（紧贴满条上方前两格）。

**规则**：
1. 识别边缘满条：最底行全部为红(2)，确定推进方向为从底部向上。
2. 对每列 c，检查第 0 行至第 8 行（排除最底行第 9 行）的均匀性：该列所有非蓝(1)像素是否全为同一颜色。
3. 对于通过均匀性检查的车道（均匀车道）：
   - 若该车道有一个蓝(1)像素紧贴满条上方（第 8 行）：该像素向上生长一格（在第 7 行新增一个蓝(1)像素）。
   - 若该车道有两个蓝(1)像素占据第 8 行和第 7 行（紧贴满条上方的两格）：擦除这两个蓝(1)像素（恢复为背景色），同时在该车道最顶部两格（第 0 行和第 1 行）绘制两个红(2)像素（满条颜色）。
4. 对于未通过均匀性检查的车道（非均匀车道）：该车道所有像素保持不变，标记条不执行任何操作。
5. 满条本身保持不变。

**关键洞察**：循环推进机制并非无条件应用于所有车道——只有背景均匀的「干净」车道才允许标记条前进。需要对比包含均匀车道和非均匀车道的多个示例，观察到标记条在部分车道移动而在另一些车道静止，才能归纳出均匀性门控规则。

## 新题 8：距离取模决定精灵体旋转角度

**组合逻辑**：[距离](创新：距离值经取模运算映射为旋转角度) + [旋转](创新：旋转角度不由旋转族缺失成员决定，而由空间距离动态计算) + [图案精灵体](已有) + [提取](创新：参考点像素被提取移除)

**来源原语**：距离(b8cdaf2b)、旋转/旋转族成员(be03b35f)、图案精灵体(8f215267)、提取(d9fac9be)、标记像素(4258a5f9)

**依赖链**：识别参考点标记 → 计算每个精灵体质心到参考点的 Manhattan 距离 → 距离对 4 取模映射为旋转角度 → 每个精灵体绕自身中心旋转对应角度 → 擦除参考点

一句话总结：每个精灵体根据其到中心参考点的 Manhattan 距离对 4 取模的结果旋转 0/90/180/270 度。

**输入结构**：黑(0)背景，约 15x15 网格。网格中心附近有一个灰(5)单像素参考点标记。网格中散布 4-6 个小型单色精灵体（4-连通，3-5 像素，不规则形状——非矩形、非直线），每个精灵体颜色互不相同，可选自蓝(1)、红(2)、绿(3)、黄(4)、橙(7)、青(8)。精灵体的形状都不具有 90 度旋转对称性（即旋转后形状可观察到变化）。精灵体彼此不重叠、不相邻（间距至少 2 格），且与参考点不相邻。生成约束：各精灵体到参考点的 Manhattan 距离（质心到参考点的距离，取整）对 4 取模后的结果不全相同（至少覆盖 3 个不同的余数值）。

**规则**：
1. 识别灰(5)单像素参考点 P。
2. 对每个精灵体 S，计算其质心 C_S（所有像素坐标的算术平均，四舍五入取整）到参考点 P 的 Manhattan 距离 D = |C_S.row - P.row| + |C_S.col - P.col|。
3. 计算 R = D mod 4。
4. 将精灵体 S 绕其质心 C_S 顺时针旋转：R=0 → 不旋转、R=1 → 90度、R=2 → 180度、R=3 → 270度。旋转后的像素位置四舍五入取整，若超出网格边界则舍弃。
5. 从输出中移除灰(5)参考点（恢复为背景色）。

**关键洞察**：旋转角度不是固定的，也不是由精灵体自身的几何属性决定——而是由其空间位置（到参考点的距离）动态决定。需要对比多个精灵体在不同距离处的旋转结果，才能归纳出「距离 mod 4 → 角度」的编码规则。

## 新题 9：重叠框架的遮挡序解构与序列输出

**组合逻辑**：[提取](创新：从重叠可见性中反向提取隐藏的堆叠顺序) + [排序](创新：排序键不是几何位置或频率，而是遮挡关系推断出的深度序) + [空心框架](创新：框架发生重叠遮挡而非独立分布) + [压缩](已有)

**来源原语**：提取(d9fac9be)、排序/顺序排列(668eec9a)、空心框架(8f215267)、透明叠加(e133d23d)、忽略干扰项(d9fac9be)

**依赖链**：识别多个重叠的空心矩形框架 → 在框架边界交叉处观察哪种颜色覆盖哪种颜色 → 从所有局部遮挡关系推断全局堆叠顺序（底→顶）→ 将颜色按堆叠顺序从底到顶排列为单行输出

一句话总结：多个不同颜色的空心矩形框架相互重叠，通过分析交叉点的可见颜色推断堆叠层次，输出从底到顶的颜色序列。

**输入结构**：黑(0)背景，约 14x14 网格。网格中有 3-5 个空心矩形框架（仅绘制边框，内部和外部为背景），每个框架颜色互不相同，可选自蓝(1)、红(2)、绿(3)、黄(4)、橙(7)。框架大小不同（短边 3-6 格，长边 4-8 格），位置使得每对相邻层框架的边界至少有 1 处交叉（在交叉像素处，上层框架的颜色覆盖下层）。网格中另有若干灰(5)单像素散布作为干扰项（不属于任何框架）。生成约束：堆叠顺序是一个全序（不存在两个框架完全不重叠的情况，即每对框架至少有一处边界交叉可观察遮挡关系）；交叉处的遮挡关系全局一致（不存在 A 遮挡 B 且 B 遮挡 A 的矛盾）。

**规则**：
1. 识别并忽略所有灰(5)散布像素（干扰项）。
2. 对于网格中每个非背景、非灰的像素，确定它属于哪个框架（根据颜色）。重建每个颜色的完整矩形框架边界（包括被其他框架遮挡而不可见的部分——通过同色可见像素的行列对齐推断矩形的四边位置）。
3. 在两个不同颜色框架的边界交叉位置，观察实际可见的颜色。若位置 (r,c) 同时属于框架 A 的重建边界和框架 B 的重建边界，而该位置实际显示颜色 A，则 A 在 B 之上。
4. 从所有成对遮挡关系中构建全局堆叠顺序（拓扑排序）。
5. 输出一个 1 行 N 列的网格（N = 框架数量），从左到右按照堆叠顺序从底层到顶层排列各框架颜色。

**关键洞察**：输出不反映框架的空间位置、大小或任何几何属性，而是纯粹反映遮挡层次——一个需要从局部交叉点线索反向推理出的全局排序。灰色散布像素是干扰项，必须识别并忽略。需要分析多处交叉才能确定完整顺序，且必须对比多个示例才能确认规则确实是遮挡序而非其他排序依据。
