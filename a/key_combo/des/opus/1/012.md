## 新题 1：旋转对称门控色对调与象限压缩

**组合逻辑**：[对称检测](从44f52bb0提取，创新为180度旋转对称检测而非镜像对称) → 门控 [颜色互换](从45737921提取，创新为由对称结果有条件触发) → [压缩](从996ec1f3提取，创新为压缩对调后的主色)

**来源原语**：对称检测(symmetry_detection, 44f52bb0), 颜色互换(color_swap, 45737921), 压缩(compress, 996ec1f3), 十字分隔线(cross_separator, 996ec1f3), 四象限(quadrant, 996ec1f3/b10624e5), 对象内双色配对(bicolor_pairing_within_object, 45737921), 对称否决定输出色(symmetric_vs_asym_color, 44f52bb0), 主色代表区域(dominant_per_region, 996ec1f3)

**依赖链**：对称检测的结果作为布尔门控条件决定是否执行颜色互换；颜色互换改变了象限内的主色分布；主色分布的改变直接影响压缩输出的颜色值。三者环环相扣：移除对称检测则不知道哪些象限需要互换，移除互换则压缩结果回退为原始主色，移除压缩则无法生成最终输出格式。

对每个象限内的双色对象检测180度旋转对称性，对称者互换双色，最终将四个象限的后处理主色压缩为3x3网格。

**输入结构**：约20x20网格，黑(0)背景。一条完整的灰(5)行和一条完整的灰(5)列构成十字分隔线，将网格分为四个非空矩形象限。每个象限包含恰好一个由两种非黑非灰颜色组成的4-连通前景对象（5~12像素，形态不限——可以是紧凑块、弯曲条、带分支的连通体等）。每个对象的两种颜色像素数不等（一种多、一种少）。不同象限的对象使用不同的颜色对。生成约束：至少一个象限的对象关于其边界框中心具有180度旋转对称形状，至少一个象限不具有；保证4-连通性和两色不等数条件。

**规则**：
1. 找到唯一的灰(5)整行和灰(5)整列，确定十字分隔线。
2. 对每个象限，提取其中唯一的前景对象，识别该对象使用的两种非背景颜色（记为 A、B）。
3. 将对象的像素模式（仅看形状，忽略颜色）关于其边界框中心做180度旋转，检测旋转后是否与原形状完全重合。
4. 若重合（180度旋转对称）：将该对象中所有 A 色像素改为 B 色、所有 B 色像素改为 A 色。若不重合：保持原样。
5. 对调完成后，统计每个象限中对象像素的主色（像素数较多的颜色）。
6. 输出3x3网格：中间行和中间列填灰(5)（分隔线色），四个角格分别填对应象限的主色。

**关键洞察**：对称检测不是直接决定输出颜色，而是通过门控色对调间接改变哪种颜色成为主色——一个对称的对象互换双色后，原本的少数色变成了多数色，从而翻转了该象限的压缩输出。需要对比多个示例才能发现"对称→互换→主色翻转"这条隐含因果链。

## 新题 2：精灵体对称性决定对角连线颜色

**组合逻辑**：[对称检测](从44f52bb0提取，创新为对形状的水平镜像对称检测) → 三值条件映射 → [连线](从342ae2ed提取，创新为连线颜色由对称结果决定而非继承端点颜色) + [重涂色](从234bbc79提取，创新为连线颜色基于对称性重涂)

**来源原语**：对称检测(symmetry_detection, 44f52bb0), 连线(connect, 342ae2ed), 重涂色(recolor, 234bbc79), 对角偏移(diagonal_offset, 342ae2ed), 前景对象(foreground_object, 45737921), 镜像轴(mirror_axis, 44f52bb0), 对角补全连接(diagonal_fill, 342ae2ed), 对称否决定输出色(symmetric_vs_asym_color, 44f52bb0)

**依赖链**：对角连线的绘制位置由精灵体对的空间偏移决定（来自connect原语），但连线颜色既不是背景色也不是精灵体本身的颜色——它由精灵体形状的对称属性决定。移除对称检测则无法确定线的颜色；移除连线则对称检测结果无处承载；移除重涂色则线只能用端点颜色，无法表达对称信息。

检测每对同色精灵体的形状对称性，在对角偏移的精灵体对之间绘制连线，连线颜色由精灵体形状的水平镜像对称结果三值映射决定。

**输入结构**：约15x15网格，黑(0)背景。有3~4种前景颜色，每种颜色恰好出现两个独立的4-连通小精灵体（3~6像素），形状各异——有的关于其边界框水平中轴上下对称，有的不对称。同色的两个精灵体形状相同（平移关系），且存在对角偏移：一个在另一个的左上或右上方向，两者最近的对角对齐角之间恰好在45度线上。不同颜色的精灵体对互不遮挡、互不相邻。生成约束：至少包含一对水平对称形状和一对不对称形状；同色两个精灵体之间的对角间距至少3个像素。

**规则**：
1. 按颜色分组，识别每种前景色的两个精灵体。
2. 对每一对，取任一精灵体的形状（在其边界框内的像素模式），检测是否关于边界框水平中轴（上下翻转）对称。
3. 确定每对精灵体中上方那个的下对角角（面向另一个精灵体的角）和下方那个的上对角角（面向另一个精灵体的角）。
4. 在两个对角角之间绘制45度对角线段，仅画两端点之间的中间像素（不含端点本身）。
5. 对角线段的颜色规则：若精灵体形状水平对称 → 蓝(1)；若不对称 → 红(2)。
6. 原有精灵体像素保持不变。

**关键洞察**：连线颜色与精灵体自身颜色完全无关，而是由精灵体形状的几何对称属性编码。求解者需要对比多个示例中对称精灵体（蓝线）与不对称精灵体（红线）的差异，才能归纳出"形状对称性→连线颜色"这条非显然规则。

## 新题 3：充能计数排序堆叠

**组合逻辑**：[逐步充能](从271d71e2提取，创新为全充能以擦除排序线索) → [排序](从4acc7107提取，创新为排序键来自充能前的灰格数) → [堆叠](从4acc7107提取，创新为按充能前容量而非空间位置排序)

**来源原语**：逐步充能(incremental_charge, 271d71e2), 排序(sorting, 4acc7107/b5ca7ac4), 堆叠(stacking, 4acc7107), 带边框容器(bordered_container, 271d71e2), 按颜色分组(group_by_color, 4acc7107), 对齐紧凑排布(aligned_compact_layout, 4acc7107), 能量上限步数(energy_caps_steps, 271d71e2)

**依赖链**：充能过程将所有灰(5)格转为橙(7)，从而擦除了灰格计数信息；但堆叠的顺序恰恰取决于被擦除的灰格原始数量。排序键只存在于输入状态中，输出中不再可见——求解者必须从输入中提取排序键，然后在输出中验证。移除充能则灰格仍在、排序键可见但输出不匹配；移除排序则堆叠顺序未定；移除堆叠则排好序也无处摆放。

将各容器全部充能（灰转橙），按充能前灰格数量升序排列，从上到下紧凑堆叠于输出网格左侧。

**输入结构**：约18x18网格，品红(6)背景。散布着3~5个黑(0)边框矩形容器，各容器大小不同（内部面积约4~15格）。每个容器内部由灰(5)和橙(7)两种颜色填充：靠近某一边的若干格已经是橙(7)（已充能），其余为灰(5)（未充能）。橙格总是从容器的某一侧连续排列，灰格在对侧。不同容器的已充能比例各不相同。各容器在输入网格中散布，彼此不相邻、不重叠。生成约束：每个容器的灰格数量互不相同（保证排序无歧义）。

**规则**：
1. 识别所有黑(0)边框矩形容器。
2. 对每个容器，计算其内部灰(5)格的数量，记为该容器的"原始容量"C。
3. 将每个容器完全充能：把所有灰(5)内部格替换为橙(7)，使整个内部变为橙色。边框保持黑(0)不变。
4. 按原始容量 C 升序排列所有容器（C 最小的排最上方）。
5. 将排好序的容器从上到下紧凑堆叠在输出网格中：第一个容器的边框上缘对齐网格第0行、左缘对齐第0列；后续容器紧接上一个容器的下缘放置，左缘同样对齐第0列，容器之间无间隔行。
6. 输出网格宽度 = 最宽容器的宽度，高度 = 所有容器高度之和。其余区域填品红(6)背景。

**关键洞察**：充能操作在视觉上"销毁"了排序依据——输出中所有容器内部全是橙色，无法直接看出哪个容器原来灰格多。求解者必须从输入中读取各容器的灰格数，才能预测输出中的堆叠顺序。这种"操作擦除自身触发条件"的结构需要对比多个示例才能发现。

## 新题 4：周期条纹计数定维度的镜像拼贴

**组合逻辑**：[周期掩码分析](从6a980be1提取，创新为既提取母题内容又提取重复次数) → [裁剪](从ff805c23/9ba4a9aa提取) + [镜像](从67a3c6ac提取，创新为棋盘式交替镜像) → [平铺](从7fe24cdd提取，创新为拼贴维度由周期次数决定)

**来源原语**：裁剪(crop, ff805c23), 镜像(reflect, 67a3c6ac), 平铺(tile, 7fe24cdd), 周期条纹(periodic_stripe, 6a980be1), 标记条(marker_bar, 6a980be1), 周期掩码(periodic_mask, 6a980be1), 阵列排布(array_layout, 7fe24cdd), 翻转列序(column_reversal, 67a3c6ac)

**依赖链**：周期条纹分析同时产出两个信息：（a）母题内容——标记条之间的图案，供裁剪提取；（b）条纹重复次数N——决定输出拼贴的维度。裁剪结果和重复次数共同输入平铺操作，缺少任一则拼贴无法完成。镜像规则在拼贴矩阵中按棋盘格交替应用，使输出不是简单重复。

从周期条纹中提取一个周期的母题并计数总周期数N，以N x N的棋盘式交替镜像拼贴生成输出。

**输入结构**：约16x16网格，黑(0)背景。网格中有水平排列的周期条纹结构：蓝(1)色整行作为分隔条纹，等间距重复出现（例如每隔4行出现一条蓝行）。相邻两条蓝行之间的区域包含由红(2)和绿(3)像素构成的图案（4-连通，2~8像素的不规则形状）。所有周期的图案完全相同（平移复制）。另有两条黄(4)色整行作为标记条，恰好框住其中一个完整周期（一条在该周期上方、一条在下方，紧邻蓝色分隔行外侧）。网格中有2~4个完整周期。生成约束：周期数 N >= 2；母题在其周期区间内非对称（上下和左右均不对称），以使镜像可辨。

**规则**：
1. 识别所有蓝(1)色整行（分隔条纹），确定周期间距 P（相邻蓝行间的行数）。
2. 识别两条黄(4)色标记条行，它们之间夹着的区域即为一个完整周期。提取该区域中非蓝非黄的像素模式作为母题，裁剪为其最小边界框（宽 W、高 H）。
3. 统计输入中蓝色分隔行划出的完整周期总数，记为 N。
4. 构建 N x N 的拼贴输出网格（尺寸 N*H 行 x N*W 列）：
   - 对于拼贴坐标 (i, j)（0-indexed），在该位置放置母题的一个副本。
   - 若 j 为奇数：对该副本做水平镜像（左右翻转）。
   - 若 i 为奇数：对该副本做垂直镜像（上下翻转）。
   - 若 i 和 j 均为奇数：先水平后垂直镜像（等效于180度旋转）。
   - 若 i 和 j 均为偶数：放置原始母题，不做变换。
5. 输出仅包含拼贴内容，不包含分隔条纹和标记条。

**关键洞察**：同一次周期分析既提供了"拼什么"（母题内容）又提供了"拼多大"（N x N维度）。棋盘式交替镜像是隐蔽规则——仅看一个示例中的2x2拼贴可能误以为是简单旋转，需要对比不同N值的示例才能确认是按坐标奇偶性独立控制水平/垂直镜像。

## 新题 5：环路弯折计数驱动同心扩展层数

**组合逻辑**：[环路追踪](从15663ba9提取) → [分类涂色](从15663ba9提取，创新为分类结果不仅涂色还输出计数) → 计数→参数化 → [同心扩展](从3a301edc提取，创新为扩展层数由凹弯折数决定)

**来源原语**：环路追踪(trace_cycle, 15663ba9), 分类涂色(classify_and_color, 15663ba9), 同心扩展(concentric_expansion, 3a301edc), 闭合正交环路(closed_orthogonal_loop, 15663ba9), 弯折像素(bend_pixel, 15663ba9), 同心嵌套(concentric_nesting, 3a301edc), 多数转向为凸(majority_turn_is_convex, 15663ba9), 少数转向为凹(minority_turn_is_concave, 15663ba9), 内尺寸定扩展量(inner_size_sets_expansion, 3a301edc)

**依赖链**：环路追踪识别每个像素的转向类型，分类涂色将凸弯折染黄、凹弯折染红；凹弯折的计数K直接成为同心扩展的层数参数。扩展层数不是输入中直接可见的数字，而是从环路的几何结构中推导出来的。移除环路追踪→无法分类弯折→无法计数；移除计数→扩展层数不确定；移除扩展→凹弯折计数无用。

追踪闭合正交环路的弯折类型并涂色，以凹弯折数量作为环路外围同心扩展的层数。

**输入结构**：约15x15网格，黑(0)背景。一种前景色（如蓝(1)）形成恰好一条4-连通、像素宽度为1的闭合正交环路（每个前景像素恰好有2个正交前景邻居）。环路大致呈矩形但带有若干矩形凹陷（向内凹入的缺口），使得环路既有凸弯折也有凹弯折。环路不自交。生成约束：凹弯折数量 K 在 2~6 之间（保证扩展层数适中）；环路边界框距网格边缘至少 K+1 像素（保证扩展不超出网格）。

**规则**：
1. 追踪闭合正交环路，按行优先顺序选择起点和初始方向，逐像素判断每个前景像素的类别：
   - 直行像素：前后方向相同（不转弯），保持原前景色蓝(1)。
   - 弯折像素：前后方向形成90度转弯。统计整条环路中所有弯折像素的转向方向（顺时针或逆时针），多数方向为凸弯折，少数方向为凹弯折。
2. 将凸弯折像素涂为黄(4)，凹弯折像素涂为红(2)，直行像素保持蓝(1)。
3. 统计凹弯折像素的总数 K。
4. 以环路的边界框为基准，向外逐层扩展 K 层同心矩形环：
   - 第1层（紧贴环路边界框外侧）至第K层，每层宽1像素。
   - 所有扩展层均涂为黄(4)。
5. 扩展层仅填充背景(0)像素，不覆盖已有的环路像素。

**关键洞察**：凹弯折数量在视觉上不显眼（环路上只有少量红色像素），但它精确地决定了外围扩展的厚度。求解者需要对比不同凹陷数量的环路示例，发现"红像素数=黄色外围层数"这个数值对应关系。这是环路几何分析结果直接参数化另一种空间操作的紧耦合。

## 新题 6：引导路径选择目标环用于象限压缩

**组合逻辑**：[路径追踪](从9ba4a9aa提取，创新为在象限框架内独立运行) → 目标选择 → [裁剪](从9ba4a9aa提取，创新为仅提取颜色属性而非裁剪物体) → [压缩](从996ec1f3提取，创新为压缩对象由路径选择而非去噪统计决定)

**来源原语**：路径追踪(path_follow, 9ba4a9aa), 压缩(compress, 996ec1f3), 裁剪(crop, 9ba4a9aa), 棋盘格(checkerboard, 9ba4a9aa), 环形物体(ring_object, 9ba4a9aa), 引导像素(guide_pixel, 9ba4a9aa), 十字分隔线(cross_separator, 996ec1f3), 四象限(quadrant, 996ec1f3), 路径连接(path_connected, 9ba4a9aa), 主色代表区域(dominant_per_region, 996ec1f3), 终点相邻(endpoint_adjacent, 9ba4a9aa), 忽略干扰项(ignore_distractors, 996ec1f3)

**依赖链**：每个象限中存在多个环形物体（干扰项），路径追踪从棋盘格出发沿引导像素找到唯一目标环，目标环的颜色成为该象限的代表色并输入压缩。路径是选择机制——不同输入中路径通向不同环，直接改变压缩输出。移除路径追踪→不知选哪个环→压缩颜色不确定；移除压缩→选出的颜色无处输出；移除干扰环→路径无选择作用。

在十字分割的每个象限中沿引导路径从棋盘格出发选出目标环，将四个目标环的颜色压缩为3x3网格。

**输入结构**：约22x22网格，黑(0)背景。一条完整的灰(5)行和一条完整的灰(5)列构成十字分隔线，将网格分为四个象限。每个象限包含：(a)恰好一个3x3棋盘格对象（由两种颜色交替构成标准棋盘图案），(b)2~3个3x3环形物体（外圈8格同色、中心1格为背景色），每个环不同颜色，(c)一条由同色像素构成的引导路径，沿正交两步格点延伸（每两格一个像素）。棋盘格的某一侧恰好有一个引导像素与之正交相邻，该引导像素的颜色确定该象限的路径颜色。引导路径沿水平或垂直方向延伸，终点恰好与某一个环形物体正交相邻。各象限的路径颜色和目标环颜色各不相同。生成约束：引导路径不穿过其他环或棋盘格；路径至少经过2个中间引导像素。

**规则**：
1. 识别灰(5)十字分隔线，确定四个象限。
2. 在每个象限中：
   a. 找到3x3棋盘格对象（中心格颜色与角格颜色不同、边格颜色与角格颜色不同的3x3区域）。
   b. 找到与棋盘格正交相邻的引导像素，记其颜色为 G。
   c. 从该引导像素出发，沿同色(G)像素以正交两步跳跃追踪路径（每次水平或垂直移动2格到达下一个G色像素）。
   d. 路径终点像素恰好与某个3x3环形物体正交相邻。该环即为本象限的目标环。
   e. 记录目标环的外圈颜色，作为本象限的代表色。
3. 输出3x3网格：中间行和中间列填灰(5)，四个角格分别填对应象限的代表色。

**关键洞察**：每个象限有多个环形物体作为干扰项，唯有通过追踪引导路径才能确定哪个环代表该象限。路径是信息选择器而非空间变换——它的作用是在多个候选中做出选择，选择结果再送入一个完全不同的操作（压缩）。求解者必须在多个示例中观察到路径终点总是指向输出中对应角格的颜色，才能推断出这个选择-压缩链。

## 新题 7：正交连线划分区域与上界填色

**组合逻辑**：[连线](从342ae2ed/cb227835提取，创新为正交连线而非对角连线) → 区域划分 → [填充](从3a301edc提取，创新为填充色由区域上边界线颜色决定)

**来源原语**：连线(line_drawing, cb227835/342ae2ed), 填充(fill, 3a301edc), 标记像素(marker_pixel, cb227835), 画布边界(canvas_boundary, a3df8b1e), 位置排序(positional_ordering, 4acc7107), 颜色决定目标(color_determines_destination, b5ca7ac4)

**依赖链**：标记像素对的连线在网格上划出正交线段，这些线段将网格分割成若干矩形区域。每个区域的填充颜色取决于它的上边界是哪条线（哪种颜色），因此连线的空间位置和颜色同时决定了区域的形状和颜色。移除连线→无分割→无区域可填；移除填充→线段存在但区域为空；改变任意一条线的位置→区域形状改变→填充结果改变。

在同色标记像素对之间画正交线段，利用线段将网格分割成矩形区域，每个区域填充其上方最近水平线段的颜色。

**输入结构**：约14x14网格，黑(0)背景。网格中散布着若干标记像素对：每对由两个相同颜色的像素组成，且同一对的两个像素必定共享同一行或同一列（正交对齐）。使用2~3种不同颜色，每种颜色恰好一对标记像素。所有水平对齐的标记对在不同行上（行号互不相同），所有垂直对齐的标记对在不同列上。生成约束：标记对的连线不相交（即水平线段和垂直线段不在同一像素点交叉）；至少有2对水平对齐的标记对（确保有水平线段可充当区域上边界）；所有标记像素距网格边缘至少1格。

**规则**：
1. 识别所有标记像素对（同色且共行或共列的两个像素）。
2. 对每一对，在两个标记像素之间（含端点）画一条直线段，颜色与标记像素相同。水平对齐则画水平线，垂直对齐则画垂直线。
3. 绘制完所有线段后，网格被线段和网格边缘共同分割成若干矩形区域（线段像素本身不属于任何区域）。
4. 对每个矩形区域，从该区域内任意像素向上寻找最近的水平线段（同列上方最近的属于某条水平线段的像素）。将该区域内所有背景像素填为该水平线段的颜色。
5. 若一个区域上方没有任何水平线段（即该区域的上边界就是网格顶部边缘），则该区域保持黑(0)背景不变。
6. 垂直线段作为区域的左右边界参与分割，但不直接决定任何区域的填充颜色。

**关键洞察**：线段承担双重角色——既是区域边界，又是颜色来源。但只有水平线段向下"投射"颜色，垂直线段仅起分隔作用而不赋色。这种方向不对称的规则需要对比包含水平线段和垂直线段的多个示例才能归纳。

## 新题 8：对角弹射轨迹为容器充能并决定平移距离

**组合逻辑**：[射线延伸/弹射](从a3df8b1e提取，创新为弹射轨迹穿过容器时对内部充能) → [逐步充能](从271d71e2提取，创新为充能数量由轨迹穿过路径长度决定) → [平移](从271d71e2/b5ca7ac4提取，创新为平移距离由充能量参数化)

**来源原语**：射线延伸(ray_cast, a3df8b1e), 逐步充能(incremental_charge, 271d71e2), 平移(translate, 271d71e2/b5ca7ac4), 孤立像素(isolated_pixel, a3df8b1e), 带边框容器(bordered_container, 271d71e2), 画布边界(canvas_boundary, a3df8b1e), 反射弹回(reflection_bounce, a3df8b1e), 对角遇边反射(diagonal_with_wall_reflection, a3df8b1e), 能量上限步数(energy_caps_steps, 271d71e2)

**依赖链**：弹射轨迹的空间路径决定了哪些容器的哪些灰格被"击中"而充能——轨迹的几何形状直接映射为各容器的充能量；充能量又参数化了各容器的平移步数。三个操作之间是严格的信息流：轨迹形状→充能分布→移动距离。改变弹射起点→不同容器被击中→不同充能量→不同移动结果。

孤立像素发射对角弹射轨迹，轨迹穿过容器时将灰格充能为橙色，每个容器向下平移的距离等于其被充能的格数。

**输入结构**：约18x18网格，黑(0)背景。有2~3个黑(0)边框矩形容器散布在网格中，内部填灰(5)，大小各异（内部面积约4~12格）。在网格底部区域有恰好一个栗(9)色孤立像素（不与任何容器或其他前景相邻）。容器之间互不相邻、互不重叠。生成约束：孤立像素发出的对角弹射轨迹至少穿过2个不同容器的内部；各容器被穿过的灰格数互不相同；每个容器向下平移后不超出网格底部边界，也不与其他容器在平移后的最终位置重叠（先处理平移量较小的容器）。

**规则**：
1. 找到栗(9)色孤立像素作为弹射起点。
2. 从该像素出发，沿右上45度方向逐像素移动。遇到网格左右边缘时水平方向反转（反射），始终保持向上移动。到达网格顶部边缘时轨迹终止。在轨迹经过的每个像素位置画栗(9)色（含起点，不含超出网格的终点外像素）。
3. 检查轨迹路径中哪些像素位于某个容器的内部（边框以内的灰(5)格位置）。将这些灰格改为橙(7)（充能）。
4. 对每个容器，统计其中被充能的格数（灰转橙的数量），记为 E。
5. 将每个容器整体（含边框）向下平移 E 行。按 E 值从小到大的顺序依次处理平移（平移量小的先移，以避免移动冲突）。
6. 容器原位置上被移走的像素恢复为黑(0)背景。弹射轨迹像素保留栗(9)色（即使容器移走后轨迹悬空也保留）。

**关键洞察**：弹射轨迹看似只是一条装饰线，实际上它与每个容器的交集长度精确地决定了该容器的移动距离。一条轨迹可能穿过多个容器不同长度的内部区域，产生不同的充能量和不同的平移距离——轨迹几何同时编码了多个容器各自的运动参数。

## 新题 9：双序排列产生重涂色置换

**组合逻辑**：[路径追踪](从9ba4a9aa提取，创新为路径长度作为排序键而非选择机制) → 长度量化 → [排序](从4acc7107/b5ca7ac4提取，创新为建立两种独立排序) → 置换构造 → [重涂色](从234bbc79提取，创新为重涂色映射由置换决定)

**来源原语**：路径追踪(path_follow, 9ba4a9aa), 排序(sorting, 4acc7107/b5ca7ac4), 重涂色(recolor, 234bbc79), 引导像素(guide_pixel, 9ba4a9aa), 精灵体(sprite, 234bbc79), 位置排序(positional_ordering, 4acc7107), 路径连接(path_connected, 9ba4a9aa), 位置顺序(position_order, db615bd4)

**依赖链**：两种独立的排序——路径长度排序和空间位置排序——各自为精灵体分配一个秩。当两种排序不一致时，产生一个非平凡的置换，该置换定义了精灵体之间的颜色重映射。移除路径追踪→无长度排序→无置换；移除空间排序→置换的另一半缺失；移除重涂色→置换无处施加。核心结构不是线性流水线，而是两条独立信息流汇合后产生映射。

从中心枢纽出发的引导路径长度定义一种排序，精灵体的空间位置定义另一种排序，两种排序的不一致构成颜色重映射置换。

**输入结构**：约16x16网格，黑(0)背景。网格中心区域有一个灰(5)枢纽像素。从枢纽向不同方向延伸3~4条引导路径，每条路径由等间距排列的同色像素构成（颜色与其目标精灵体相同，每两格一个像素，沿正交方向延伸）。每条路径的末端相邻处有一个4-连通小精灵体（3~6像素），颜色与该路径颜色相同。不同精灵体颜色各不相同。各路径长度（从枢纽到对应精灵体的引导像素数量）互不相同。生成约束：路径不相交、不穿过其他精灵体；各精灵体的边界框中心横坐标互不相同（保证空间排序无歧义）；路径长度排序与空间位置排序至少在两个位上不同（保证置换非恒等）。

**规则**：
1. 找到灰(5)枢纽像素。
2. 识别从枢纽出发的每条引导路径：从与枢纽正交相邻的非黑非灰像素开始，沿同色像素以两步间距追踪到路径终端。
3. 识别每条路径末端相邻的精灵体，记其颜色。
4. 建立长度排序 L：按路径长度（路径包含的引导像素数量）升序排列精灵体，得到序列 L = [s_L1, s_L2, ..., s_Ln]。
5. 建立位置排序 P：按精灵体边界框中心的横坐标从小到大排列，得到序列 P = [s_P1, s_P2, ..., s_Pn]。
6. 构造颜色映射：位置排序中第 k 个精灵体获得长度排序中第 k 个精灵体的颜色。即 s_Pk 的新颜色 = s_Lk 的原始颜色。
7. 对每个精灵体及其对应引导路径的所有像素，统一重涂为该精灵体的新颜色。枢纽像素保持灰(5)不变。

**关键洞察**：输出中每个精灵体的颜色既不由其位置直接决定，也不由其路径长度直接决定，而是由两种独立排序的"错位"产生的置换决定。求解者需要同时发现两种排序规则，并理解它们的组合才能预测重涂色结果。这是一个需要同时满足两条约束的非流水线结构。
