## 新题 1：重力封口洪泛

**组合逻辑**：[重力下落](已有，作用对象从"封闭区域内可移动像素"变为"墙体缺口上方的散落像素") → [洪泛填充 + 内外分区](已有，但拓扑结构由重力结果动态决定) → [重涂色](已有，填充色由封口像素颜色决定，而非固定映射)

**来源原语**：重力下落/gravity_drop(88e364bc), 洪泛填充/flood_fill(7b6016b9), 内外分区/in_out_partition(7b6016b9), 碰撞停止/collision_stop(88e364bc), 边界连通分内外/border_in_out(7b6016b9), 封闭区域/enclosed_region(7b6016b9), 重涂色/recolor

**依赖链**：重力下落改变了散落像素的位置 → 某些像素恰好落入墙体缺口，将开放轮廓变为封闭轮廓 → 洪泛填充依赖这一新拓扑来划分内外 → 封闭区域的填充色取决于哪个像素完成了封口——三步之间有真正的信息变换，而非简单传递。

散落像素在重力作用下坠落并堵住墙体缺口，由此形成的封闭区域以封口像素的颜色进行洪泛填充。

**输入结构**：约 15x15 网格，黑(0)背景。网格中有 2-4 个不同颜色的墙体对象（每个墙体是一个 4-连通的单色多像素对象，5-15 像素，呈开放的 U 形、C 形或类似缺口结构——即单像素宽度的壁面围成一个近乎封闭的区域但留有恰好一个单像素宽的缺口）。每个墙体的缺口正上方若干行处悬浮着一个散落的单像素，颜色与该墙体颜色不同、与其他散落像素颜色也不同（颜色取自 1-9 中未被墙体占用的值）。此外可能有 0-2 个额外的散落单像素位于非缺口列的上方（干扰项）。生成约束：每个缺口正上方恰好有一个散落像素（同列），且该列上方无其他墙体或像素阻挡；不同墙体的封闭区域（封口后）互不重叠；干扰像素下落后不会堵住任何缺口。

**规则**：
1. 识别所有散落单像素（不与任何多像素对象 4-相邻的非背景单像素）。
2. 每个散落像素沿竖直方向向下移动，逐行检查：遇到非背景像素（墙体像素或已落定的其他散落像素）或网格底行时停止，占据障碍物正上方一格的位置（若障碍是底行，则占据底行本身）。处理顺序：按原始行号从大到小（最靠近底部的先落）。
3. 落定后，将每个散落像素视为与其 4-相邻的墙体对象同色墙壁的一部分（虽然颜色不同，但在连通性计算中视为不可穿越的"墙"）。具体判定：对所有非背景像素（墙体 + 落定散落像素）构成的集合，从网格四条边出发对背景像素做 4-连通洪泛。无法被洪泛到达的背景像素即为封闭区域。
4. 对每个封闭区域，找到导致该区域从开放变为封闭的那个散落像素——即该区域的边界上唯一的散落像素（它填补了缺口）。将该封闭区域内所有背景像素填充为该散落像素的颜色。
5. 未封口任何区域的散落像素（干扰项）保留在落定位置不变。
6. 所有墙体像素保持原色不变。散落像素本身也保持原色不变（它们是墙壁的一部分，不被填充覆盖）。

**关键洞察**：重力不只是移动像素——它改变了网格的拓扑结构。哪些区域成为封闭区域完全取决于重力的结果，而封闭区域的填充色又取决于具体是哪个像素完成了封口。仅看静态网格无法确定输出；必须模拟重力过程。

## 新题 2：残缺瓦片推断后印章扩展

**组合逻辑**：[补全/completion](已有，作用对象不变) + [印章覆盖/stamp](已有，但源图案不是原始输入而是推断修复后的网格) ← 两步共享同一网格，灰(5)像素同时扮演"排除在周期推断之外的噪声"和"印章放置指令"两个角色（创新：同一像素的双重语义）

**来源原语**：补全/completion(f823c43c), 周期瓦片/periodic_tile(f823c43c), 行列周期/row_col_period(f823c43c), 标记为缺失值/markers_missing_val(f823c43c), 印章覆盖/stamp(ad7e01d0), 控制像素/control_pixel(ad7e01d0), 像素到块映射/pixel_block_mapping(ad7e01d0), 控制色选中则印章/stamp_where_control(ad7e01d0)

**依赖链**：周期推断时必须排除灰(5)和品红(6)像素 → 推断出的周期用于修复品红像素 → 修复后的网格（灰像素仍在）成为印章源图案 → 灰像素的位置决定输出中哪些块被印章。品红修复和灰控制是两个独立的语义层，但共存于同一网格中，推断过程必须同时处理两者。

从一个含周期性图案腐蚀和灰色控制像素的小网格中推断并修复周期图案，然后以修复后的网格为源、灰像素位置为掩码进行印章扩展。

**输入结构**：一个较小的矩形网格（约 4x4 至 6x6）。网格中存在三类像素：(a) 两种图案色（如蓝(1)和绿(3)），它们构成一个具有明确最小矩形周期的重复图案（如 2x2 棋盘、2x1 条纹等）；(b) 品红(6)腐蚀像素，替换了部分图案单元格；(c) 灰(5)控制像素，占据 1-3 个位置。生成约束：去除品红和灰像素后，剩余图案像素足以唯一确定最小矩形周期（至少覆盖一个完整周期的所有余数类）；灰像素的位置与周期无关（不构成图案的一部分）；品红像素不与灰像素重叠。

**规则**：
1. 将灰(5)和品红(6)像素都标记为"未知"。从剩余的图案像素中推断最小矩形重复周期 (pr, pc)：对每个余数类 (r mod pr, c mod pc)，所有已知像素颜色一致，且不存在更小的 (pr', pc') 满足此条件。
2. 对每个品红(6)像素位于 (r, c) 处，将其替换为 tile[r mod pr][c mod pc]（推断出的图案色）。
3. 灰(5)像素保持不变——修复后的网格 S 包含图案色和灰像素。
4. 构建输出网格，尺寸为 (input_rows x input_rows) 行、(input_cols x input_cols) 列，初始化为黑(0)。
5. 对 S 中每个灰(5)像素位于 (i, j)：将整个 S 复制到输出网格中以 (i x input_rows, j x input_cols) 为左上角的块中。复制时灰像素也被复制（输出中可见灰色）。若多个印章块重叠（多个灰像素的印章区域有交集），按阅读顺序（从上到下、从左到右）处理灰像素，后处理的覆盖先处理的。
6. 非灰像素对应的输出块保持黑(0)。

**关键洞察**：灰像素具有双重身份——在周期推断阶段它是"非图案噪声"需要被排除，在印章阶段它是"放置指令"决定输出布局。求解者必须同时理解这两层语义才能正确求解。品红和灰在推断时都被排除，但修复只针对品红、不针对灰——这一不对称性需要对比多个示例才能归纳。

## 新题 3：引导线异或反转棋盘

**组合逻辑**：[连线/line_drawing](已有，从边界标记对画引导线) → [反转/invert](创新：不再逐行独立反转主色，而是沿引导线所在行/列反转棋盘双色) → 交叉处异或抵消（涌现规则：两次反转等于不反转，这一规则不存在于任何源题中）

**来源原语**：连线/line_drawing(0d87d2a6), 边界标记对/border_marker_pair(0d87d2a6), 引导线/guide_line(0d87d2a6), 反转/invert(2de01db2), 逐行独立/row_independent(2de01db2→创新为行列联合), 主色与背景互换/native_bg_swap(2de01db2→创新为棋盘双色互换), 棋盘格图案/checkerboard_pattern(80a900e0), 正交交叉/orthogonal_crossing(1a2e2828)

**依赖链**：边界标记对确定引导线位置 → 引导线的行/列触发棋盘反转 → 水平引导与垂直引导在交叉点产生双重反转 → 双重反转相互抵消（异或逻辑）——这一涌现规则将简单的"画线+反转"提升为全局奇偶性推理。

在两色棋盘网格上，根据边界标记对画出横向和纵向引导线；引导线经过的行和列各自反转棋盘双色，交叉处两次反转互相抵消。

**输入结构**：约 12x12 网格。底层是严格的两色棋盘图案——两种颜色（如蓝(1)和红(2)）交替填充，满足同一行相邻像素颜色不同、同一列相邻像素颜色不同。网格四条边界上放置若干黄(4)标记像素：左边界和右边界各若干个，当某行 r 的左边界 (r,0) 和右边界 (r,W-1) 同时为黄(4)时，该行为水平引导行；上边界和下边界各若干个，当某列 c 的上边界 (0,c) 和下边界 (H-1,c) 同时为黄(4)时，该列为垂直引导列。生成约束：至少有 1 条水平引导行和 1 条垂直引导列（确保存在交叉）；引导行和引导列各不超过 3 条；边界上的非标记像素保持原棋盘色。

**规则**：
1. 识别所有水平引导行和垂直引导列（判定规则如输入结构所述）。
2. 对每个网格内部像素 (r, c)（不含四条边界行/列），计算经过该像素的引导线数量 K：若 r 是水平引导行则 +1，若 c 是垂直引导列则 +1，K 的取值为 0、1 或 2。
3. 若 K 为奇数（= 1）：反转该像素的棋盘色（蓝(1)变红(2)，红(2)变蓝(1)）。
4. 若 K 为偶数（= 0 或 2）：保持该像素原色不变。
5. 对所有位于引导行或引导列上的内部像素（包括交叉点），覆盖涂为黄(4)。此步在反转之后执行，即这些位置的反转结果被黄色覆盖。
6. 边界像素保持不变（黄标记保留，非标记保留原棋盘色）。

**关键洞察**：引导线本身被涂为黄色，遮住了交叉点处的反转结果，因此求解者无法直接观察交叉点的行为。必须观察引导线两侧但不在引导线上的内部像素来推断反转规则，再通过比较有交叉和无交叉的区域归纳出异或抵消逻辑。这一奇偶性规则是行反转和列反转组合后的涌现效应。

## 新题 4：轮廓框双重角色——封闭填充与形状匹配传色

**组合逻辑**：[洪泛填充](已有) + [多数色决定填充](已有) → [形状匹配](已有，但匹配对象从"灰框内精灵体"变为"轮廓框本身的几何形状") → [重涂色](已有，但颜色来源从"框内参考色"变为"洪泛填充推导出的多数色") + [擦除](已有)——轮廓框同时充当洪泛填充的边界和形状匹配的模板（创新：同一结构的双重角色）

**来源原语**：洪泛填充/flood_fill(4b6b68e5), 轮廓框/outline_frame(4b6b68e5), 封闭区域/enclosed_region(4b6b68e5), 标记在封闭区域内/marker_in_enclosed_region(4b6b68e5), 多数色决定填充/majority_color_fill(4b6b68e5), 擦除/erase(4b6b68e5), 形状匹配/shape_match(776ffc46), 精灵体/sprite(776ffc46), 重涂色/recolor(776ffc46), 包含内部/containment(776ffc46)

**依赖链**：轮廓框的几何形状决定封闭区域的边界 → 封闭区域内标记像素的多数色决定填充色 → 填充色成为待传递的目标色 → 轮廓框的几何形状（同一个框！）同时作为形状模板与自由精灵体匹配 → 匹配成功的精灵体获得对应框的填充色。信息从标记像素→填充色→精灵体颜色经过两跳传递，桥梁是轮廓框的双重角色。

网格中的封闭轮廓框先以内部标记像素的多数色填充，然后框的几何形状作为模板匹配外部自由精灵体，将填充色传递给匹配的精灵体。

**输入结构**：约 18x18 网格，黑(0)背景。包含 2-3 个单像素厚度的封闭轮廓框，每个框使用不同的非背景色（如灰(5)、青(8)、栗(9)），框的形状各不相同（一个可能是矩形，另一个可能是不规则的 4-连通闭合环路，像素数 10-20）。每个框的封闭内部散布着若干单像素标记（2-5 个），标记颜色取自 {蓝(1), 红(2), 绿(3), 黄(4)}，每个框内部有 2-3 种标记色，其中一种数量严格最多。框外部散布 2-4 个自由精灵体（4-连通单色小图形，3-8 像素），每个精灵体使用不同颜色（可与标记色重复但与框色不同）。部分精灵体的形状（平移不变的相对像素位置集）与某个轮廓框的形状完全一致，部分不一致。生成约束：每个框内的多数标记色唯一（无并列）；每个自由精灵体至多匹配一个框；至少一个精灵体无匹配（用于展示擦除规则）。

**规则**：
1. 识别所有多像素封闭轮廓框对象（4-连通、单色、像素数 > 1、围成至少一个内部背景像素的闭合环路）。
2. 对每个轮廓框，确定其封闭内部：从框的外接矩形边缘向内做 4-连通洪泛，无法穿越框像素到达的背景像素即为封闭内部。
3. 统计每个封闭内部中所有单像素标记的颜色频次，确定多数色 M（频次最高的颜色；若并列则取在框内部最左最上位置出现的颜色）。用 M 填充该封闭内部的所有背景像素。
4. 将网格中所有单像素标记（无论在框内还是框外）擦除为黑(0)。
5. 对每个自由精灵体，提取其形状掩码（相对像素位置集，平移归一化）。将此掩码与每个轮廓框的形状掩码（轮廓框像素的相对位置集，平移归一化）逐一比较。若完全匹配某个框 F，则将该精灵体的所有像素重涂为框 F 的填充色 M_F。
6. 若自由精灵体的形状与所有框都不匹配，则将该精灵体擦除为黑(0)。
7. 处理顺序：精灵体按外接矩形左上角从左到右、从上到下依次处理（本题中此顺序不影响结果，因为不同框的填充色互不相同，各精灵体至多匹配一个框）。
8. 轮廓框本身保持原色不变。

**关键洞察**：轮廓框承担了两个完全不同的角色——作为洪泛填充的物理边界决定哪些像素被填充，同时作为形状模板决定哪些自由精灵体获得传色。填充色的来源（内部标记的多数色）经由框的形状匹配传递到外部精灵体，形成"标记→填充色→精灵体颜色"的两跳信息流。删除任一环节都无法求解：无洪泛填充则不知道传什么色；无形状匹配则不知道传给谁。

## 新题 5：分隔线邻接数编码菱形扩展半径

**组合逻辑**：[坐标压缩](已有，删除分隔线) → [扩展](创新：不是将标记扩展为横带，而是将像素扩展为菱形，且半径由删除前的空间信息编码) ← 分隔线的邻接数在压缩前提取、在压缩后使用（创新：被删除的结构仍然携带信息影响后续操作）

**来源原语**：坐标压缩/coordinate_compression(7d419a02), 分隔线/separator_line(7d419a02), 单像素标记/single_pixel_marker(0f63c0b9), 扩展/expand(0f63c0b9→创新为菱形扩展), 块距离/block_distance(7d419a02→创新为曼哈顿距离菱形), 碰撞停止/collision_stop(80a900e0→创新为菱形重叠优先级)

**依赖链**：分隔线的 4-邻域信息被提取为各像素的半径参数 → 分隔线被删除、坐标压缩改变像素间距 → 压缩后的新坐标上以提取的半径画菱形 → 菱形之间的重叠由半径大小决定优先级。分隔线在被删除前贡献了关键参数，删除后改变了空间布局——两步都不可省略。

删除全行/全列分隔线进行坐标压缩，同时利用分隔线对每个彩色像素的邻接数作为菱形扩展半径，在压缩后的网格中画出对应大小的实心菱形。

**输入结构**：约 13x13 网格，黑(0)背景。若干条完整的灰(5)全行和灰(5)全列作为分隔线，将网格划分为矩形单元格。在部分单元格中各放置一个彩色单像素（颜色取自 {蓝(1), 红(2), 绿(3), 黄(4), 橙(7)}，各像素颜色可相同或不同）。每个彩色像素的 4-邻域中灰(5)分隔线像素的数量为 0-4 不等（取决于像素是否紧贴分隔线交叉点、单条分隔线旁或远离分隔线）。生成约束：至少有 2 条全行和 2 条全列分隔线；至少一个像素的邻接数为 0（不与任何分隔线相邻）、至少一个邻接数 >= 2；压缩后各像素的菱形（以各自半径）不会超出压缩后的网格边界（可以紧贴边界）。

**规则**：
1. 对每个非背景、非灰的彩色像素 P 位于 (r, c)，计算其 4-邻域中灰(5)像素的数量 R_P。这就是该像素的菱形半径。
2. 删除所有完全为灰(5)的整行和整列。将剩余像素的坐标重新编号：保持相对顺序不变，行号和列号各自重新从 0 开始连续编号。每个彩色像素获得新的压缩坐标 (r', c')。
3. 构建输出网格，尺寸等于压缩后的行数 x 列数，初始化为黑(0)。
4. 对每个彩色像素 P（压缩坐标 (r', c')，半径 R_P，颜色 C_P）：若 R_P = 0，仅在 (r', c') 处画一个 C_P 像素。若 R_P > 0，画一个以 (r', c') 为中心、半径 R_P 的实心菱形——即所有满足 |dr| + |dc| <= R_P 的位置 (r'+dr, c'+dc) 都涂为 C_P，超出网格边界的部分裁剪忽略。
5. 重叠处理：若两个菱形覆盖同一像素，半径 R_P 较大者优先。若半径相同，压缩坐标按阅读顺序（先比较行号、再比较列号）靠前者优先。

**关键洞察**：分隔线在被删除之前已经将关键信息（邻接数）编码给了各彩色像素。删除分隔线后，这些信息作为半径参数驱动菱形扩展。求解者必须在分隔线还存在时提取信息，然后在分隔线消失后的新空间中使用这些信息——一个"先读后删"的推理结构。

## 新题 6：图例编码方向 + 标记计数限制堆叠深度

**组合逻辑**：[编码映射/border_legend](已有，解码滑动方向) + [重力下落](已有) → [像素数决定长度](创新：不再决定"线段长度"而是决定"堆叠深度上限") + [擦除](创新：溢出的可移动像素被删除而非保留)

**来源原语**：重力下落/gravity_drop(88e364bc), 边界图例/border_legend(88e364bc), 编码映射/encoding_map(88e364bc), 颜色关联区域/color_links_to_region(88e364bc), 碰撞停止/collision_stop(88e364bc), 封闭区域/enclosed_region(88e364bc), 可移动像素/movable_pixel(88e364bc), 像素数决定长度/pixel_count_length(c61be7dc), 擦除/erase(4b6b68e5)

**依赖链**：图例的填充色关联区域边界色 → 图例的方向编码决定滑动方向 → 区域内橙(7)标记像素的计数决定堆叠深度上限 → 黄(4)像素按该方向滑动，在上限深度处截断 → 超出上限的黄像素被擦除。方向（来自图例）和深度限制（来自标记计数）共同约束重力行为——缺少任一条件都无法确定输出。

在带有方向图例的封闭区域中，黄色像素按图例指定方向滑动堆叠，但堆叠深度受区域内橙色标记像素数量的限制，超出限制的黄色像素被擦除。

**输入结构**：约 16x16 网格，黑(0)背景。2-3 个封闭区域由不同颜色的单像素厚度边界围成（边界色如蓝(1)、红(2)、绿(3)）。每个区域内部散布若干黄(4)可移动像素和若干橙(7)标记像素，均位于黑(0)内部背景上。网格边缘（最外 2-3 行/列）有小矩形图例结构（约 3x3），每个图例的填充色匹配一个区域的边界色，图例内部有一个中心点（与填充色相同）和一个指示点（白或其他对比色），中心点→指示点的偏移编码一个正交方向（上/下/左/右）。生成约束：每个区域恰好对应一个图例；每个区域内部宽度/高度足以容纳堆叠；不同区域的内部互不连通。

**规则**：
1. 对每个封闭区域，识别其边界色 C，找到边缘处填充色为 C 的图例，解码方向 D（中心点→指示点的偏移方向）。
2. 统计该区域内部橙(7)标记像素的总数，记为 L（堆叠深度上限）。
3. 沿方向 D 定义"车道"：若 D 为水平方向（左或右），每一行是一条车道；若 D 为垂直方向（上或下），每一列是一条车道。"远端墙"指沿 D 方向最远处的边界像素。
4. 对该区域内每条车道独立处理：收集车道内所有黄(4)像素，将它们沿 D 方向推向远端墙依次堆叠（最先到达远端墙的像素紧贴墙壁，第二个紧贴第一个，以此类推）。堆叠完毕后，若该车道内堆叠的黄像素超过 L 个，仅保留最靠近远端墙的 L 个，将其余的擦除为黑(0)。
5. 所有橙(7)标记像素擦除为黑(0)。
6. 边界像素和图例结构保持不变。

**关键洞察**：橙色标记像素的计数不是用于填充颜色（与 4b6b68e5 中的多数色逻辑完全不同），而是编码了一个数值——堆叠深度上限。方向由图例提供，堆叠容量由标记计数提供，两者缺一不可。求解者需要对比不同区域（标记数不同 → 堆叠上限不同 → 部分黄像素被擦除 vs 全部保留）来归纳出"计数=上限"这一隐蔽规则。

## 新题 7：标记分带后逐带地形极值列高亮

**组合逻辑**：[扩展 → 横带](已有，单像素标记按中点划分产生横带) + [列高度极值](已有，但不再全局计算而是逐带独立计算——创新：空间分区改变极值结果) → [边框绘制/frame_drawing](已有，高亮列段作为视觉标记) + [重涂色](已有，高亮色由标记色决定)

**来源原语**：单像素标记/single_pixel_marker(0f63c0b9), 横带/horizontal_band(0f63c0b9), 按行排序/sorted_by_row(0f63c0b9), 中点划分归属/midpoint_band_assignment(0f63c0b9), 扩展/expand(0f63c0b9), 地形轮廓/terrain_contour(e45ef808), 列高度极值/column_height_extreme(e45ef808), 最深与最浅列唯一/unique_deep_shallow(e45ef808), 重涂色/recolor(e45ef808)

**依赖链**：标记行位置决定带边界 → 带边界截取地形的不同高度段 → 同一地形在不同带中呈现不同的局部极值 → 极值列获得对应带标记的颜色。全局看地形的最浅/最深列可能只有一对，但分带后每个带各有自己的一对——空间分区改变了统计结果。

在含地形轮廓的网格中，单像素标记按行排序分割出横带，每个带独立找出地形的最浅和最深列，分别以该带标记的颜色和固定辅助色高亮对应列段。

**输入结构**：约 16x20 网格，黑(0)背景。底部有灰(5)地形轮廓：每列从最后一行向上有连续的灰(5)像素，高度（灰像素数）在 2-12 之间变化，形成不规则地表。地形之上的空间中散布 2-4 个单像素彩色标记（颜色互不相同，取自 {蓝(1), 红(2), 绿(3), 橙(7)}），每个标记位于不同行、不在地形内部。生成约束：标记行互不相同；相邻标记之间的行间距 >= 4（确保每个带包含足够地形信息）；每个带内存在唯一最浅列（地形最高处，即灰像素数最多、最早到达高行）和唯一最深列（地形最低处，灰像素数最少），不存在并列（若有并列，最浅取最右、最深取最左）。

**规则**：
1. 将所有标记按行号从小到大排序。
2. 在相邻标记行之间取中点（floor((r_i + r_{i+1}) / 2)）作为带边界。最顶部的带从第 0 行到第一个中点（不含），最底部的带从最后一个中点到最末行（含）。每个标记属于包含其行号的带。
3. 对每个带 B（标记颜色为 C_B）：
   a. 考察该带行范围内每一列的地形高度——即该列中位于带行范围内的灰(5)像素数量。
   b. 找到带内地形高度最大的列（最浅列——地形填满程度最高的列，灰像素占据了最多行）。若并列取最右列。
   c. 找到带内地形高度最小（但 > 0）的列（最深列——地形最稀疏的列）。若并列取最左列。若某列在该带范围内无灰像素则忽略（不参与极值比较）。
   d. 将最浅列中位于该带行范围内、地形表面之上（非灰像素）的所有黑(0)背景像素涂为 C_B（标记色）。
   e. 将最深列中位于该带行范围内、地形表面之上的所有黑(0)背景像素涂为黄(4)（固定辅助色）。
4. 标记像素本身被涂色覆盖（它们位于被高亮的列段内）。
5. 灰(5)地形像素保持不变。其他未被高亮的背景像素保持黑(0)。

**关键洞察**：同一列可能在不同带中扮演不同角色——在上带是最浅列，在下带却不是，因为带边界截取了地形的不同段。求解者必须意识到极值分析是逐带独立的，而非全局的。对比不同带的高亮结果可以验证这一点：全局最浅列不一定是每个带的最浅列。

## 新题 8：面板透明叠加后框内填充与跨层标记保护

**组合逻辑**：[透明叠加](已有，三面板合成) → [填充](已有，框内区域填充) + [标记框内保护](创新：保护区域由叠加后的存活标记决定，而非原始面板中的标记——叠加改变了哪些标记存活) + [擦除](已有，最后清除标记)

**来源原语**：透明叠加/transparent_overlay(6a11f6da), 等高面板/equal_height_panel(6a11f6da), 图层优先级/layer_priority(6a11f6da), 底层最优先/bottom_panel_highest_priority(6a11f6da), 填充/filling(d37a1ef5), 空心矩形/hollow_rectangle(d37a1ef5), 内部区域/interior_region(d37a1ef5), 标记像素/marker_pixel(d37a1ef5), 标记框内保护/marker_bbox_protect(d37a1ef5), 擦除/erase

**依赖链**：三面板叠加决定每个像素的最终归属 → 叠加可能覆盖某些面板中的标记像素（底层优先，底层非背景像素覆盖上层所有内容，包括标记） → 存活的标记像素定义保护区域 → 框内填充跳过保护区域。叠加结果同时改变了"框内有什么"和"哪些标记存活"，两者共同决定填充行为。

三个等高面板按底层优先叠加合成后，对合成结果中的空心矩形框执行内部填充，但跳过存活标记像素所张成的矩形保护区域。

**输入结构**：网格高度为 3H（H 约为 6-8），宽度约 10-12。三个等高面板（各 H 行）从上到下排列：顶部面板、中间面板、底部面板。所有面板共享黑(0)背景。每个面板包含：(a) 一个空心矩形框（单像素厚度，框色各面板不同，取自蓝(1)、红(2)、绿(3)）；(b) 框内部可能有品红(6)标记像素（0-3 个）；(c) 框外可能有一些非背景色的装饰像素。三个面板中的框在对应位置可以部分重叠或错开。生成约束：叠加后至少有一个框的内部包含存活的品红标记（未被更高优先级面板的非背景像素覆盖），且该标记的外接矩形严格小于框的内部区域（确保保护区域不覆盖整个内部）；至少有一个面板中的标记被底层面板的非背景像素覆盖而消失。

**规则**：
1. 将三个面板叠加为一个 H 行 x W 列的合成面板。叠加优先级：先放置中间面板所有非背景像素，再放置顶部面板所有非背景像素（覆盖中间面板），最后放置底部面板所有非背景像素（覆盖前两者）。即底部面板优先级最高。
2. 在合成面板中识别所有空心矩形框对象（4-连通、单色、形成完整矩形边框的对象）。一个面板的框可能在叠加后被另一面板的像素部分遮挡；若框不再完整（缺失像素），则不视为有效框，跳过处理。
3. 对每个有效空心矩形框，确定其严格内部区域（框像素围成的矩形内部，不含框本身）。
4. 在该内部区域中找到所有品红(6)标记像素。若存在标记，计算它们的外接矩形（最小包围所有标记的矩形）。该外接矩形内的所有像素为"保护区域"。
5. 将框内部区域中、保护区域之外的所有背景像素(0)涂为框的颜色。保护区域内的像素保持叠加后的原样（无论是背景还是其他颜色）。
6. 清除所有品红(6)标记像素（将其设为黑(0)），无论在保护区域内外。
7. 框像素及其他非背景、非标记像素保持不变。

**关键洞察**：叠加操作不仅改变了框内的视觉内容，还决定了哪些标记像素存活——底层面板的非背景像素可能覆盖上层面板中的标记，使其消失。消失的标记不参与保护区域计算，因此保护区域的大小和位置取决于叠加结果。求解者必须先正确叠加，才能知道哪些标记存活、保护区域在哪，进而确定填充范围。这种"叠加→标记存活性→保护→填充"的因果链是跨越两道源题逻辑的新结构关系。
