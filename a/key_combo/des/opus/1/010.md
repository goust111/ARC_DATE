## 新题 1：修补断口闭合轮廓后逐行填充

**组合逻辑**：[间隙填充gap_fill](创新：目的不是恢复线路连通性而是创建几何闭合，使后续填充成为可能) + [逐行跨度填充row_span_fill](已有) + [端点朝向endpoint_facing](已有)

**来源原语**：间隙填充gap_fill、端点朝向endpoint_facing、线段网络line_network → faa9f03d；逐行跨度填充row_span_fill、行内边界配对row_boundary_pairing、轮廓线outline、封闭区域enclosed_region → 22168020

**依赖链**：间隙填充的输出决定了哪些轮廓变为封闭——只有封闭轮廓才满足逐行跨度填充的前提条件（每行恰好两个边界点）；若不先修补间隙，轮廓未闭合，行跨度填充无法正确执行。

将断裂的不规则轮廓补完间隙使其闭合，再对闭合轮廓逐行填充形成实心区域。

**输入结构**：
- 约 15×15 的黑(0)背景网格。
- 2~3 组单色一像素宽线段片段（每组一种颜色，分别使用红(2)、绿(3)、蓝(1)等不同颜色），散布在网格中。
- 每组线段在空间上近似一个不规则的封闭轮廓（如斜边菱形、弧形凸包等，由对角线像素和直线段组成），但每组恰好有 1~2 处间断——即两个朝向彼此的端点之间存在 1~3 像素的轴对齐空缺。
- 端点定义：某像素在其同色 8-连通邻域中恰好只有一个同色邻居，则为端点。每个端点恰好有一个轴对齐方向（上/下/左/右）正对同组另一个端点（即沿该方向直线前进可抵达另一端点，中间全为黑色背景）。
- 不同颜色的轮廓互不接触（8-连通意义上不相邻）。
- 生成约束：每组线段在间隙修补后恰好构成一个闭合轮廓，且每行上该轮廓恰好有 0 或 2 个边界像素（保证行跨度填充定义良好）。

**规则**：
1. 对每种前景颜色，找到该颜色线段中所有端点像素（仅一个同色 8-连通邻居的像素）。
2. 在同一行或同一列上、同色的两个面对面端点之间，用该颜色填充间隙（将两端点之间的所有背景像素涂为该色）。处理顺序：按端点对的行号从小到大，行号相同时按列号从小到大。
3. 间隙修补完成后，对每种颜色的闭合轮廓执行逐行跨度填充：在该轮廓占据的每一行上，找到最左和最右的轮廓像素，将两者之间（含端点）的所有像素涂为该颜色。
4. 若不同颜色的填充区域在某像素重叠（极少出现），保留行号较小的轮廓的颜色；若行号也相同，保留列号较小的轮廓的颜色。生成时保证此情况至多涉及 1~2 个像素。
5. 所有原有轮廓像素和间隙填充像素保留不变。

**关键洞察**：间隙填充的目的不是恢复线段网络的电路连通性（如 faa9f03d 中的修复），而是使断裂的几何轮廓达到闭合——这是逐行跨度填充能正确执行的必要前提。两步操作通过"闭合性"这一拓扑属性紧密耦合。

## 新题 2：矩形框缺口射线交叉触发颜色翻转

**组合逻辑**：[射线延伸ray_extend + 洪泛填充flood_fill + 缺口方向决定射线gap_direction_determines_ray](已有) + [颜色互换color_swap + 配对间像素互换toggle_between_pairs](创新：互换不再作用于静态线段上的现有像素，而是由射线空间交叠的奇偶性触发)

**来源原语**：射线延伸ray_extend、空心矩形rectangular_frame、边框缺口border_gap、缺口方向决定射线gap_direction_determines_ray、洪泛填充flood_fill → 551d5bf1；颜色互换color_swap、配对间像素互换toggle_between_pairs → d2acf2cb

**依赖链**：缺口位置决定射线方向 → 多条射线在网格中延伸 → 射线覆盖计数决定每个像素是否翻转颜色。删除任何一个框都会改变交叉图案，进而改变翻转位置。

多个带缺口矩形框各自向外射出青色射线，被偶数条射线覆盖的像素翻转为橙色。

**输入结构**：
- 约 20×20 的黑(0)背景网格。
- 3~4 个蓝(1)色空心矩形框（4-连通，宽高各 3~6 像素），散布在网格中互不重叠且不接触。
- 每个框恰好有一个非角落的边框像素缺失（缺口）。不同框的缺口分布在不同方向的边上（如一个在上边、一个在右边等）。
- 生成约束：至少有两对射线相交（即至少存在一个像素被两条射线同时覆盖）；所有矩形框不位于同一行或同一列上（避免射线方向过于规律）。

**规则**：
1. 对每个矩形框，将其边界框严格内部的所有像素涂为青(8)。
2. 从每个缺口出发，沿缺口所在边的外法线方向逐像素绘制射线，颜色初始为青(8)。射线覆盖缺口像素本身及路径上所有黑色背景像素，直到到达网格边缘。若射线路径遇到蓝(1)色框边像素，在该像素前停止（不覆盖蓝色像素，不穿透其他框）。
3. 对每个被射线覆盖的像素，计算覆盖它的射线条数 K（来自不同框的射线各计一次）。
4. 颜色翻转规则：K 为奇数的像素保持青(8)；K 为偶数且 K ≥ 2 的像素翻转为橙(7)。
5. 蓝(1)色框边保持不变。未被任何射线覆盖的背景像素保持黑(0)。框内部填充的青色像素不参与射线覆盖计数（它们始终为青(8)）。

**关键洞察**：交叉位置无法从单个框的缺口预测——必须同时推断所有框的射线路径，计算每个像素的覆盖次数，再依据奇偶性决定颜色。覆盖奇偶性是多条射线空间交互的涌现属性，将射线延伸和颜色翻转通过计数奇偶性耦合在一起。

## 新题 3：格子单元级同心扩展与重叠混合

**组合逻辑**：[同心层填充concentric_fill + 切比雪夫距离索引chebyshev_index](创新：距离度量从像素级切换为格子单元级，整个格子单元作为一个距离原子) + [填充fill + 双色交叉混合色intersect_blend_color](创新：混合不再发生在轴对齐的标记 run 之间，而是发生在两个同心扩展的重叠区域)

**来源原语**：同心层填充concentric_fill、切比雪夫距离索引chebyshev_index、种子像素seed_pixel、色板按距离配色palette_color_by_distance → 9356391f；填充fill、格子单元lattice_cell、网格线lattice_line、共行或共列shared_row_col、双色交叉混合色intersect_blend_color → e760a62e

**依赖链**：格子结构定义了距离度量的原子单位 → 每个种子独立按格子切比雪夫距离进行同心扩展 → 两个扩展在同一格子单元重叠时触发混合色规则。距离计算、扩展范围和混合规则三者通过格子结构耦合。

在格子网络中以格子单元为距离单位，多个种子各自同心扩展并使用色板着色，重叠的格子单元自动混合为品红色。

**输入结构**：
- 约 19×19 的网格。灰(5)色一像素宽格子线将画布分割为规则的矩形单元阵列（如 4 行 × 4 列或 5 行 × 5 列的单元格，每个单元内部约 3×3 像素）。
- 网格最顶部一行（在格子线上方）是色板行：从左起依次排列 3~4 个非背景色像素（如蓝(1)、红(2)、绿(3)），其余为黑(0)背景。色板中第 i 个非背景像素（i 从 0 开始）对应切比雪夫距离 i 的填充色。
- 2~3 个种子像素分布在不同的格子单元中（每个种子占据所在单元的中心像素），每个种子的颜色与色板第 0 项一致。种子颜色全部相同。
- 生成约束：至少有两个种子的同心扩展在某些格子单元处重叠（即存在某格子单元到两个种子的格子切比雪夫距离都在色板长度范围内）。

**规则**：
1. 格子切比雪夫距离定义：两个格子单元的坐标为 (gr, gc)（格子行号, 格子列号，从 0 开始），距离为 max(|gr1−gr2|, |gc1−gc2|)。
2. 对每个种子，从其所在格子单元 (gr0, gc0) 开始，将格子切比雪夫距离为 d 的所有格子单元标记为该种子的 d 层。d = 0 处为种子自身所在单元。
3. 对于仅被一个种子覆盖（d < 色板长度）的格子单元，将整个单元内部像素（不含格子线）涂为 palette[d]。
4. 若某格子单元被两个或更多种子的扩展同时覆盖（对每个种子的距离 d 都在色板范围内），该单元涂为品红(6)，无论各自色板颜色是什么。
5. d 超出色板长度的格子单元不填充（保持黑(0)）。格子线（灰(5)）保持不变。色板行保持不变。

**关键洞察**：距离度量在格子坐标系中而非像素坐标系中——每个格子单元是距离计算的不可分割的原子单位，整个单元同步着色。品红混合区域的位置取决于种子间的格子距离和色板长度的关系，需同时分析所有种子的扩展范围才能确定。

## 新题 4：区分噪声与标记——去噪、裁剪、按标记计数重复

**组合逻辑**：[去噪denoise + 忽略干扰项ignore_distractors](创新：干扰项与有效标记在形态上完全相同——均为孤立单像素，仅颜色区分角色) + [裁剪crop + 边界框包围bounding_box_enclosure](已有) + [计数counting + 重复repeat + 标记计数驱动重复marker_count_drives_repetition](已有)

**来源原语**：去噪denoise、忽略干扰项ignore_distractors、前景区域foreground_region → de809cff；裁剪crop、边界框包围bounding_box_enclosure、裁剪区背景替换background_within_crop_replaced、前景掩模foreground_mask → a740d043；计数counting、重复repeat、单像素标记singleton_marker、标记计数驱动重复marker_count_drives_repetition、标记数等于副本数marker_count_equals_copy_count → 4852f2fa

**依赖链**：孤立单像素按颜色分为两类——与主体同色的是噪声（影响裁剪边界），异色的是标记（驱动重复次数）。去噪改变裁剪边界；标记计数决定重复次数。两条支路共享同一输入特征（孤立单像素），必须同时正确区分才能得到正确输出。

去除与主体同色的噪声孤立像素后裁剪主体，再按异色标记像素的数量水平重复裁剪结果。

**输入结构**：
- 约 15×18 的黑(0)背景网格。
- 一个由蓝(1)像素组成的 4-连通多像素前景图形（6~15 像素，形状不规则，非矩形，可能含内部孔洞）。
- 2~4 个蓝(1)色孤立单像素散布在图形外部（噪声干扰项），与主体不 4-连通。其中至少一个位于主体边界框之外（使去噪前后裁剪范围不同）。
- 1~4 个红(2)色孤立单像素散布在网格中（重复标记），与主体和噪声均不 4-连通，且不在主体边界框内。
- 生成约束：去噪后主体的边界框严格小于去噪前（含噪声时）的边界框；红色标记像素数量 N ≥ 2。

**规则**：
1. 识别主体：非背景的最大 4-连通分量即为主体（此处为蓝(1)色）。
2. 去噪：将所有与主体颜色相同但不属于该最大 4-连通分量的孤立单像素变为黑(0)背景。
3. 裁剪：取去噪后所有蓝(1)色像素（即仅主体像素）的紧凑轴对齐边界框，将框内背景像素保留为黑(0)，保留所有蓝色像素不变，得到裁剪瓦片。
4. 计数：统计输入中红(2)色孤立单像素的数量 N。
5. 输出：将裁剪瓦片水平拼接 N 份，每两份之间无间隔，无额外边距。

**关键洞察**：噪声和标记在形态上完全相同（都是 1 像素的孤立点），只有颜色区分它们的角色——同色单像素是需要删除的噪声，异色单像素是需要计数的标记。错误分类任何一个都会同时影响裁剪边界和重复次数。

## 新题 5：推断周期恢复壁纸缺失像素，但恢复色取反

**组合逻辑**：[补全complete + 前景残留推断周期residue_infers_period](已有) + [重涂色recolor + 反色填充opposite_color_fill](创新：反色填充不再标记缺陷中心的邻域补丁，而是标记被擦除后恢复的周期位置——恢复像素不使用"正确的"周期色而使用对调的另一种前景色)

**来源原语**：补全complete、周期瓦片periodic_tile、周期重复periodic_repeat、前景残留推断周期residue_infers_period、缺损像素erased_pixel → ea959feb；重涂色recolor、缺陷标记defect_mark、反色填充opposite_color_fill、前景区域foreground_region → de809cff

**依赖链**：从前景残留推断周期 → 确定哪些位置被擦除 → 恢复被擦除位置但使用反转的前景色。恢复操作依赖周期推断结果，而颜色选择依赖该位置在原图案中"应有"的颜色的对映关系。

推断双色周期壁纸的最小重复单元，恢复被擦除的像素，但恢复像素使用与原色对调的另一种前景色。

**输入结构**：
- 约 12×12 的黑(0)背景网格。
- 壁纸由两种前景色组成（红(2)和绿(3)），形成周期性图案（行周期 Pr 约 3~5，列周期 Pc 约 3~5）。
- 壁纸中约 20%~40% 的前景像素被擦除（变为黑(0)背景色）。擦除位置分散分布。
- 定义前景色对映关系：红(2) ↔ 绿(3)。
- 生成约束：每个前景残差类（周期内同一相对位置 (r mod Pr, c mod Pc)）至少保留一个未擦除像素，保证周期和颜色分配可唯一确定；两种前景色在壁纸中均出现。

**规则**：
1. 忽略黑(0)背景像素，从剩余前景像素中推断最小行周期 Pr 和列周期 Pc，使得所有可见前景像素按 (row mod Pr, col mod Pc) 分组后组内颜色一致。
2. 对每个残差类 (r mod Pr, c mod Pc)，记录其前景色 C（红(2)或绿(3)）。不包含任何前景像素证据的残差类视为背景类。
3. 对网格中每个位置 (r, c)：

   - 若该位置在输入中已有前景像素（未被擦除），保持原色 C 不变。
   - 若该位置在输入中为黑(0)但其残差类为前景类（被擦除），涂为 C 的对映色（红→绿，绿→红）。

**关键洞察**：恢复的像素不是用"正确的"周期颜色填回，而是用对调的前景色——输出中原始像素和恢复像素视觉上明显不同但空间位置遵循同一周期。仅看单个示例容易误以为壁纸本身就是双色交替图案（类似棋盘），必须对比多个示例才能发现恢复位置总是取反色。

## 新题 8：对边标记的互换对隐式定义同心扩展的交替色板

**组合逻辑**：[颜色互换color_swap + 对边配对opposite_edge_pair + 配对间像素互换toggle_between_pairs](创新：互换规则不再应用于线段上的静态像素翻转，而是生成同心扩展所需的无限交替色板) + [同心层填充concentric_fill + 切比雪夫距离索引chebyshev_index](创新：色板不是显式给出的一行像素，而是由互换对隐式定义的交替序列 A, B, A, B, ...)

**输入结构**：
- 约 15×15 的黑(0)背景网格。
- 网格左边缘和右边缘各有 1~2 个黄(4)标记像素，构成 1~2 个对边配对（同一行的左边缘标记与右边缘标记配对）。

- 灰(5)分隔行横跨全宽，将上方的互换对定义区与下方的种子扩展区分隔。
- 下方区域有 1~2 个种子像素，每个种子的颜色等于某个互换对的 A 色（即左侧色）。每个种子所在行与某个互换对定义行的行号差最小（以此确定关联——每个种子关联与其行号最近的互换对定义行）。

1. 识别互换对：对每行，若左边缘和右边缘都有黄(4)标记，则该行严格内部的两个相邻非背景像素定义一个互换对 A ↔ B（左为 A，右为 B）。
2. 种子关联：每个种子关联行号距离最近的互换对。若距离相等则关联行号较小的互换对。
3. 色板生成：令种子的互换对为 A ↔ B，则色板为无限交替序列 palette[d] = A（d 为偶数）或 B（d 为奇数）。
4. 同心填充：以种子像素位置为中心，将切比雪夫距离为 d 的所有像素涂为 palette[d]。填充范围不超出网格边界，不覆盖分隔行（灰(5)）及其上方区域。距离 0（种子自身）涂为 A。
5. 黄(4)标记、互换对定义像素、分隔行（灰(5)）保持不变。

**输入结构**：
- 约 20×20 的黑(0)背景网格。

- 每个框恰好有一个非角落的边框像素缺失（缺口）。不同框的缺口分布在不同方向的边上（保证射线方向多样）。
- 一个由橙(7)像素组成的 3×3 小精灵体（3~5 个非背景像素，其余为黑(0)背景，精灵体 4-连通），位于网格角落的 3×3 区域内，不与任何框重叠或相邻。
- 生成约束：恰好存在 1~3 个射线交叉点（某像素被两条来自不同框的射线同时覆盖）；每个交叉点周围有足够空间放置 3×3 精灵体（精灵体不超出网格边界，不覆盖蓝(1)色框边——若超出或覆盖，则不放置该精灵体，但本题生成时保证不出现此情况）。

**规则**：
1. 对每个矩形框，用青(8)填充其边界框严格内部的所有像素。
2. 从每个缺口出发，沿缺口所在边的外法线方向逐像素绘制青(8)射线，覆盖缺口像素本身及路径上所有黑色背景像素，直到网格边缘。若路径遇到蓝(1)色框边像素，在该像素前停止（不含该蓝色像素，不穿透其他框）。
3. 标记交叉点：若某像素被两条或更多来自不同框的射线同时覆盖，标记该位置为交叉点。
4. 精灵体印章：在每个交叉点，以该点为中心粘贴 3×3 精灵体模板——模板中橙(7)像素覆盖该位置原有的颜色，模板中黑(0)像素不覆盖（保留底层颜色）。若多个印章重叠，按交叉点从左到右、从上到下的顺序依次粘贴（后粘贴的覆盖先粘贴的）。
5. 移除角落的原始精灵体（其占据的位置变为黑(0)背景）。
6. 蓝(1)色框边保持不变。

**关键洞察**：印章的放置位置不是直接编码在输入中的——它由多条射线的空间交互涌现而来。求解者必须先推断所有射线路径，再确定交叉点坐标，最后才能定位印章位置。单看任何一个矩形框都无法确定是否产生交叉，必须全局分析所有射线。
