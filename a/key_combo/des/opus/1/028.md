## 新题 1：禁区引力场

**组合逻辑**：[重力下落](已有) + [像素计数编码半径](创新：从路径避障上下文迁移到刚体滑动上下文，蓝像素数编码的不再是路径禁区而是物理碰撞的扩展边界) + [重涂色](已有，蓝色归并为障碍色)

**来源原语**：重力下落/多米诺骨牌/边墙/近墙优先结算/碰撞停止(#16 6ad5bdfd), 像素计数编码半径/禁区/障碍条(#6 cb2d8a2c), 重涂色(#1 e509e548)

**依赖链**：蓝像素计数 → 禁区半径计算 → 滑动碰撞判定 → 落点确定 → 蓝色统一重涂。删除半径计算则碰撞判定错误；删除重力则无运动；删除蓝色重涂则输出颜色错误。

多米诺骨牌向边墙滑动时，灰色障碍周围的蓝像素数量定义了不可进入的隐形禁区半径，多米诺在禁区边界即停。落定后蓝像素统一变为灰色。

**输入结构**：
- 约 15x15 网格，背景黑(0)。
- 网格某一完整边缘（如最底行）全部填充红(2)，形成一格厚的边墙，其余位置不出现红(2)。
- 散布 4-6 个单色 4-连通多米诺骨牌（各恰好 2 像素），颜色从绿(3)、黄(4)、品红(6)、橙(7)中各取，每个多米诺颜色互不相同。多米诺方向可以是水平或垂直。
- 散布 2-3 个障碍簇。每个障碍簇由若干灰(5)像素组成一个 4-连通区域（2-4 像素），另有 1-3 个蓝(1)像素与该簇的灰像素 4-相邻。不同障碍簇的蓝像素数量不同。
- 生成约束：多米诺与障碍簇互不接触；边墙方向上各多米诺的投影互不重叠（保证滑动路径无歧义）；禁区扩展后不会完全封锁任何多米诺的滑动路径。

**规则**：
1. 边墙所在边确定引力方向：所有多米诺向该边滑动（如底边→向下滑动）。
2. 对每个障碍簇，计算其蓝(1)像素数 R。该簇中每个灰(5)像素的曼哈顿距离 <= R 范围内的所有格子均标记为禁区（包括灰像素自身所占格子）。禁区格子视为不可通行。
3. 清除所有多米诺的原始位置（设为背景）。
4. 按距边墙从近到远的顺序逐个结算多米诺。每个多米诺沿引力方向刚体平移，直到下一步会使其任何像素落在边墙、另一已结算的多米诺或禁区格子上时停止。
5. 所有多米诺落定后，将网格中全部蓝(1)像素重涂为灰(5)。
6. 边墙与障碍簇的灰像素保持不变。

**关键洞察**：蓝像素本身不是障碍，而是编码周围灰障碍的隐形力场半径。两个灰像素数相同但蓝像素数不同的障碍簇，对同一多米诺的拦截位置完全不同。仅看单个示例可能无法区分"蓝像素扩展禁区"和"蓝像素本身就是障碍"，必须对比多个示例中不同蓝像素数量的障碍簇来归纳半径规则。

## 新题 2：弯折数驱动膨胀深度

**组合逻辑**：[计数/弯折数分类](已有) → [填充/同心膨胀](创新：弯折数不再直接映射颜色，而是控制膨胀层数) → [循环填充/调色板取色](已有，但作用于膨胀层而非对角带) + [碰撞优先级](创新：弯折数同时决定膨胀深度和空间冲突优先权)

**来源原语**：计数/弯折数分类/弯折数决定颜色(#1 e509e548), 循环填充/调色板行/层深度递增/层深模色板取色(#11 b457fec5), 填充(#8 d6ad076f)

**依赖链**：弯折数检测 → 膨胀层数确定 → 逐层膨胀并循环取色 → 膨胀冲突时以弯折数裁决。弯折数同时控制两个下游机制（深度和优先级），删除计数步骤整个流程崩溃；删除膨胀则退化为单色重涂；删除优先级规则则重叠区域不确定。

每个绿色对象的弯折数决定其向外膨胀的层数，每层颜色按调色板循环取色；膨胀重叠时弯折数高者优先占据像素。

**输入结构**：
- 约 15x15 网格，背景黑(0)。
- 散布 4-6 个绿(3) 4-连通单色对象，每个 4-8 像素，形状各异（不规则弯折路径），包含 1-3 个 L 形 2x2 弯折模式（含旋转变体）。生成约束：至少包含弯折数为 1、2、3 的对象各一个。
- 网格最底行放置一个水平调色板：从左到右依次排列 3 个相邻像素，颜色分别为蓝(1)、红(2)、黄(4)。调色板像素彼此 4-相邻，与其他对象不相邻。
- 各绿色对象之间至少间隔 2 个空格子（确保低弯折数对象的膨胀不会碰撞，同时高弯折数对象的膨胀可能重叠，以测试优先级规则）。

**规则**：
1. 对每个绿(3)对象，在其所有 4 种旋转下检测 L 形 2x2 弯折模式，计数去重后得到弯折数 B。
2. 以该对象自身像素为第 0 层，向外做 B 次同心膨胀：第 k 层（k=1,...,B）由所有与第 k-1 层 4-相邻且当前为黑(0)、不属于任何原始绿对象的像素组成。
3. 第 k 层（k=0,...,B）涂色为调色板的第 (k mod 3) 个颜色。第 0 层（原始绿像素）涂为调色板第 0 色（蓝(1)）。
4. 若两个对象的膨胀层同时声称同一像素，该像素归弯折数更高的对象。若弯折数相同，归最上方像素行号更小的对象；若行号也相同，归最左方列号更小的对象。
5. 调色板行在输出中清除为背景黑(0)。

**关键洞察**：弯折数在源题中仅用于选择一个颜色，此处它同时控制膨胀深度（决定光晕大小）和冲突优先级（决定谁覆盖谁）——同一测量值驱动两个不同机制。单个示例中，弯折数高的对象可能恰好不与他者重叠，需要对比多个示例才能归纳出"弯折数=优先级"的隐蔽规则。

## 新题 3：包含关系决定交换或擦除

**组合逻辑**：[包围框包含](已有) → [计数/包含数量](创新：包含数量作为决策节点，不再是直接触发擦除) → {2个→[交换/位置互换+重涂色], 1个→[擦除]}(分支结构) + [处理顺序保护](创新：从图例处理迁移到嵌套容器处理)

**来源原语**：包围框包含/异色包含则删/擦除/连通分量(#3 9720b24f), 交换/成对交换/底色作为涂色源(#2 5a719d11), 处理顺序保护(#14 9385bd28)

**依赖链**：包含关系检测 → 每个容器的被包含对象计数 → 计数为2时触发交换、为1时触发擦除 → 内层容器先处理保护嵌套结构。删除包含检测则无法确定操作对象；删除计数则无法确定操作类型；删除处理顺序则嵌套结构结果错误。

根据每个容器内被包含对象的数量决定操作类型：恰好包含两个异色对象则互换位置并涂为容器色，仅包含一个则擦除。由内而外逐层处理。

**输入结构**：
- 约 16x16 网格，背景黑(0)。
- 3-4 个不同颜色的 8-连通单色"容器"对象，每个是一个不规则的粗框或 U 形轮廓（5-15 像素），颜色从红(2)、蓝(1)、黄(4)、橙(7)中选取。容器彼此不接触，不嵌套（所有容器处于同一层级）。
- 每个容器的包围框内部包含 1 或 2 个更小的 8-连通单色对象（3-6 像素），颜色与容器不同也互不相同（从绿(3)、灰(5)、品红(6)、栗(9)、青(8)中选取）。被包含对象之间不接触，且它们的包围框严格在容器包围框内部。
- 生成约束：至少有一个容器包含恰好 2 个对象，至少有一个容器包含恰好 1 个对象。不存在包含 0 个或超过 2 个对象的容器。每个被包含对象的包围框尺寸不超过容器包围框的一半（确保交换后有足够空间放置）。

**规则**：
1. 找到所有 8-连通非黑单色分量及其包围框。
2. 构建直接包含关系：若分量 B 的包围框严格在分量 A 的包围框内部，且 A 与 B 颜色不同，且不存在分量 C 使得 B 在 C 内、C 在 A 内（即 A 直接包含 B），则 A 是 B 的容器。
3. 按容器包围框面积从小到大排序处理（内层优先）。
4. 对每个容器 A：
   - 若 A 直接包含恰好 2 个对象 X 和 Y：清除 X 和 Y 的原始像素为黑(0)。将 X 的像素模式（相对于 X 包围框左上角的偏移集合）平移到 Y 原始包围框的左上角位置绘制，颜色涂为 A 的颜色。将 Y 的像素模式平移到 X 原始包围框的左上角位置绘制，颜色涂为 A 的颜色。
   - 若 A 直接包含恰好 1 个对象 Z：将 Z 的所有像素设为黑(0)。
5. 容器自身的像素始终保持不变。

**关键洞察**：包含关系在源题(#3)中直接触发擦除，此处它先产生一个"计数"中间结果，再由计数分支决定执行交换还是擦除。同一空间关系驱动不同操作的选择，而非固定触发一种操作。对比至少两个容器（一个含 2 对象、一个含 1 对象）才能推断出数量-操作映射规则。

## 新题 4：多标记阵列平铺与条件循环位移

**组合逻辑**：[平铺/阵列排布](已有) + [循环位移/双轴偏移](创新：从单标记单偏移扩展为多标记多偏移，每个瓦片副本有独立偏移量) + [镜像/条件反射](创新：偏移量奇偶性决定是否镜像，与源题的固定中间行翻转不同)

**来源原语**：平铺/瓦片/阵列排布(#19 00576224), 循环位移/控制行/控制列/标记像素/双轴偏移编码/标记位定位移量(#20 79cce52d), 镜像/中间行翻转(#19 00576224)

**依赖链**：控制行列标记位解析 → 阵列尺寸确定 + 每副本偏移量计算 → 偏移量奇偶判断 → 条件镜像 → 循环位移 → 阵列组装。删除标记位解析则不知道阵列尺寸和偏移量；删除条件镜像则奇偶位置的瓦片朝向错误；删除循环位移则瓦片内容不正确。

控制行和控制列各有多个标记，标记数量决定平铺阵列的尺寸，标记位置编码每个瓦片副本的独立循环位移量，位移量之和的奇偶性决定该副本是否额外镜像翻转。

**输入结构**：
- 约 12x12 方形网格。
- 第 0 行为控制行：以青(8)填充为底色，包含 3 个栗(9)标记像素，分布在不同列位置（零基索引）。
- 第 0 列为控制列：以青(8)填充为底色，包含 3 个栗(9)标记像素，分布在不同行位置。控制行和控制列在 (0,0) 位置共享一个青(8)像素（非标记）。
- 第 1 行至末行、第 1 列至末列构成载荷方块（约 (N-1)x(N-1)，N 约 4），使用的颜色均不含青(8)和栗(9)。载荷图案不对称（上下翻转或左右翻转后与原图不同），以便镜像效果可辨。

**规则**：
1. 移除第 0 行（控制行）和第 0 列（控制列），得到载荷瓦片 T。
2. 控制行中的 3 个栗(9)标记按列号从小到大排列，零基列位置记为 c0, c1, c2（减 1 后在载荷坐标系中的列位置）。
3. 控制列中的 3 个栗(9)标记按行号从小到大排列，零基行位置记为 r0, r1, r2（减 1 后在载荷坐标系中的行位置）。
4. 构造 3x3 阵列。阵列位置 (i, j)（i=0,1,2 行；j=0,1,2 列）的瓦片副本生成方式：
   a. 取载荷瓦片 T 的一份拷贝。
   b. 若 (ri + cj) 为奇数，先将该拷贝做左右镜像翻转。
   c. 将该拷贝向下循环位移 ri 行，再向右循环位移 cj 列。
5. 将 3x3 阵列的 9 个瓦片副本拼接为输出网格（输出尺寸为 3*(N-1) x 3*(N-1)）。

**关键洞察**：源题 #20 只有单标记单偏移，源题 #19 只有固定的中间行翻转。此处多标记生成多偏移的二维参数空间，且镜像条件不由阵列行号固定决定，而由两轴偏移量之和的奇偶性决定——这产生了一个非规则的棋盘式镜像图案，必须同时理解偏移编码和奇偶条件才能重构输出。

## 新题 5：形状匹配触发分层口袋填充

**组合逻辑**：[形状匹配/旋转平移嵌入](已有) → [循环填充/层深度递增](创新：匹配后的剩余空间决定膨胀层数，而非固定深度) → [调色板取色](已有，但层数由口袋-候选的尺寸差决定) + [完全覆盖/无重叠](已有，作为匹配前提)

**来源原语**：形状匹配/旋转平移嵌入/凹槽/候选块/结构体/完全覆盖/无重叠(#5 1acc24af), 循环填充/调色板行/层深度递增/层深模色板取色(#11 b457fec5), 填充(#15 d4f3cd78)

**依赖链**：口袋检测 + 候选匹配 → 匹配对确定 → 口袋内剩余空间计算 → 以匹配体为种子向外膨胀至口袋边界 → 逐层循环取色。删除匹配则不知道哪个候选填哪个口袋；删除膨胀则只有匹配体本身被填色（与源题无异）；删除调色板取色则无颜色信息。

候选对象旋转匹配进入蓝色结构的口袋后，从匹配体向外逐层膨胀直到口袋边界，每层按调色板循环涂色。口袋越大、候选越小，可见层数越多。

**输入结构**：
- 约 18x18 网格，背景黑(0)。
- 上半区：一个蓝(1) 4-连通结构体，占据约第 0-8 行的一个水平带状区域。结构体内部有 3-4 个黑(0) 4-连通口袋（腔体），每个口袋 4-10 像素，形状各异（不规则连通区域）。口袋触及结构体包围框的底边。
- 下半区：3-4 个灰(5) 4-连通候选对象，每个 3-7 像素，形状各异。候选对象的数量与口袋数量相同。每个候选经某种旋转（0/90/180/270度）后可以精确覆盖恰好一个口袋中的某个子区域（至少覆盖口袋面积的 40%），且不超出网格也不与蓝像素重叠。
- 网格最底行：3 个相邻像素组成水平调色板，颜色分别为红(2)、绿(3)、黄(4)。
- 生成约束：每个口袋恰好有一个候选可以匹配（一一对应）；口袋面积严格大于其对应候选面积（确保至少有 1 层膨胀空间）。

**规则**：
1. 识别口袋：蓝(1)结构体包围框内的黑(0) 4-连通区域中，触及包围框底边的那些区域。
2. 对每个灰(5)候选，尝试 4 种旋转和所有平移。候选匹配一个口袋当且仅当：候选经变换后的每个像素都落在该口袋的某个像素上，且不与蓝(1)像素重叠，且不超出网格边界。选择候选能完全覆盖的最大连续子区域作为匹配区（若候选比口袋小，候选覆盖自身全部像素即可，不要求覆盖整个口袋）。
3. 对每个匹配成功的口袋：以匹配体占据的像素集为第 0 层，在口袋范围内逐层向外膨胀。第 k 层 = 口袋内所有与第 k-1 层 4-相邻、尚未被任何层占据的像素。膨胀直到口袋内无剩余像素为止。
4. 第 k 层涂色为调色板第 (k mod 3) 个颜色（第 0 层涂红(2)，第 1 层涂绿(3)，第 2 层涂黄(4)，第 3 层涂红(2)，依此类推）。
5. 未匹配的候选保持灰(5)不变。未匹配的口袋保持黑(0)不变。
6. 调色板行清除为背景黑(0)。灰(5)候选对象在原始位置保持灰(5)不变（不移动到口袋中，只是口袋内的填充模式由匹配决定）。

**关键洞察**：形状匹配确定了"种子"的位置和形状，种子形状反过来决定了膨胀的几何模式——同一个口袋若与不同形状的候选匹配，其层状着色图案完全不同。匹配操作和填充操作通过种子几何紧密耦合，不可独立求解。

## 新题 6：对齐创造可填充间隙

**组合逻辑**：[对齐/中位线为参考](已有) + [裁剪](已有) → [填充/间隙区域涂色](创新：间隙不存在于输入中，由对齐操作创造出来) + [条件取色：对齐前原始长度](创新：填充颜色取决于对齐前的测量值而非对齐后的状态)

**来源原语**：对齐/裁剪/线段/平行共向/中位线为参考(#4 e376de54), 填充/间隙区域/两体之间/间隙区域涂色(#8 d6ad076f)

**依赖链**：中位线选取 → 各线段对齐到中位线起止位置 → 相邻线段间矩形间隙出现 → 各间隙两侧线段原始长度比较 → 间隙涂色。删除对齐则间隙不存在；删除间隙填充则只是线段位移（与源题无异）；删除原始长度比较则填充颜色不确定。

平行线段对齐到中位线后，相邻线段之间产生矩形间隙，每个间隙的填充颜色由其两侧线段在对齐前的原始长度决定。

**输入结构**：
- 约 15x15 网格，背景黑(0)。
- 5-7 条平行竖直线段，每条为不同颜色（从蓝(1)、红(2)、绿(3)、黄(4)、品红(6)、橙(7)、栗(9)中选取），宽度均为 1 像素。
- 各线段位于不同列，列间距至少 2。各线段的起始行和长度各不相同（长度范围 3-10 像素）。
- 生成约束：线段数量为奇数（确保中位线唯一）。无孤立单像素。

**规则**：
1. 检测所有非黑竖直线段，记录每条线段的列位置、起始行、结束行和长度。
2. 按列位置排序后，取中位列位置的线段 M 作为参考线。
3. 对每条线段（包括 M 自身）：沿竖直方向平移使其起始行与 M 的起始行对齐，然后裁剪或延伸使其长度与 M 相同。延伸时补充的像素与该线段颜色相同。裁剪时从远离起始行的一端截断。
4. 对齐后，按列位置从左到右遍历相邻线段对。每对相邻线段 (L, R) 之间的矩形间隙定义为：列范围 [L.col+1, R.col-1]，行范围 [M.start_row, M.end_row]。
5. 间隙填充颜色的确定：比较 L 和 R 在对齐前的原始长度。取原始长度更长者的颜色填充该间隙。若原始长度相等，取左侧线段 L 的颜色。
6. 孤立单像素不参与对齐，保留在原位。

**关键洞察**：间隙在输入中不存在，是对齐操作的副产物；填充颜色却取决于对齐之前的属性（原始长度）。求解者必须同时追踪变换前后的信息：变换后的几何确定"在哪里填"，变换前的测量确定"填什么颜色"。这种前后信息的交叉依赖是两道源题单独都不具备的新结构。

## 新题 7：射线采样修复后的周期图案

**组合逻辑**：[修复噪声/周期重复](已有) → [射线延伸/开口决定延伸向](创新：射线不再单色，而是逐像素采样底层修复后的周期图案) + [填充/封闭区域](已有，杯形内部填充)

**来源原语**：修复噪声/周期瓦片/周期重复/忽略干扰项(#12 135a2760), 射线延伸/杯形轮廓/开口/开口决定延伸向(#15 d4f3cd78), 填充/封闭区域(#15 d4f3cd78)

**依赖链**：周期图案修复 → 修复后图案作为射线颜色来源 → 杯形开口确定射线方向和起点 → 射线逐像素从修复图案取色。删除修复则噪声像素导致射线颜色错误；删除射线则只有修复结果（与源题无异）；删除杯形检测则不知道从哪里射出射线。

修复左侧的噪声周期图案后，从右侧杯形结构的开口向左发射射线，每条射线的每个像素采样修复后图案在该位置的颜色，形成彩色条纹射线。

**输入结构**：
- 约 20x15 网格，背景黑(0)。
- 左半区（约列 0-9）：一个周期重复的彩色图案，基本瓦片约 3x3，使用蓝(1)、红(2)、绿(3)三种颜色在黑(0)背景上排列。图案中有 3-5 个像素被随机改为错误颜色（噪声）。
- 右半区（约列 11-19）：2-3 个杯形轮廓，每个由黄(4)像素构成近似矩形框（约 4x3），每个框缺少左侧一边（开口朝左）。杯形之间不重叠，不接触。
- 列 10 为灰(5)分隔线，贯穿整个网格高度。
- 生成约束：杯形开口所在行与周期图案在该行的像素一一对应（确保射线可采样）。

**规则**：
1. 在左半区，找到最小的周期重复瓦片（至少在两个轴向各重复 2 次），用每个残差位置的多数投票修复噪声像素。
2. 对右半区的每个杯形轮廓，识别其开口侧（缺失边所在方向，此题中均为左侧）。
3. 用杯形自身的颜色（黄(4)）填充每个杯形的封闭内部（开口以外、被轮廓三面包围的黑像素）。
4. 从每个杯形开口的每个像素出发，向左发射水平射线。射线穿过灰(5)分隔线进入左半区，继续延伸直到到达网格左边缘（列 0）。
5. 射线中每个像素的颜色 = 修复后的左半区在该 (行, 列) 位置的颜色。若该位置原本是黑(0)背景（周期图案中的背景部分），射线像素也为黑(0)（即视觉上该位置无射线痕迹）。射线像素覆盖灰(5)分隔线和左半区原有内容。
6. 左半区中不在任何射线路径上的像素保持修复后的状态。

**关键洞察**：修复噪声不是最终目的而是为射线提供正确的颜色源。射线的视觉效果是周期图案在特定行的横截面，只有先修复才能获得正确的截面颜色。如果不修复就发射射线，噪声位置的射线颜色会与周围周期不一致——对比多个示例可以发现，射线颜色总是呈现干净的周期重复，从而推断出修复在先的规则。

## 新题 8：印章扩展后的包含裁汰

**组合逻辑**：[印章覆盖/分块对应](已有) → [包围框包含/异色包含则删](创新：包含关系不存在于输入中，由印章扩展的几何效应产生) + [计数](辅助，用于确认擦除结果)

**来源原语**：印章覆盖/模板面板/前景像素/分块对应/源色决定模板涂色(#10 b190f7f5), 包围框包含/异色包含则删/擦除/连通分量(#3 9720b24f)

**依赖链**：源网格像素 + 模板 → 印章扩展为 N^2 x N^2 → 扩展后检测连通分量的包围框包含关系 → 被包含的异色分量擦除。删除印章步骤则无扩展图案可检测；删除包含检测则所有印章均保留（与源题无异）。源像素的空间布局通过模板形状的放大效应决定了哪些印章的包围框嵌套，这在印章前无法预判。

将每个源像素按模板印章扩展为大图案后，检测扩展结果中的包围框包含关系，擦除被更大异色图案包围的小图案。

**输入结构**：
- 输入由两个相邻的 N x N 方形面板组成（N 约 4-5），水平排列，中间无分隔（共占 N x 2N）。
- 左面板（源网格）：背景灰(5)，散布 3-5 个非灰前景像素，使用 2-3 种颜色（如红(2)、蓝(1)、绿(3)）。不同颜色的像素在源网格中的相对位置有讲究——某些不同色像素的位置会导致印章后一个颜色的图案包围另一个颜色的图案。
- 右面板（模板）：背景灰(5)，使用单一标记色橙(7)绘制一个 4-连通小图案（3-5 像素），形状不对称。
- 生成约束：源网格中至少存在一对不同色像素，使得其中一个的印章包围框严格包含另一个的印章包围框。至少存在一对不被包含的像素（作为对照）。

**规则**：
1. 识别左面板为源网格、右面板为模板。两面板共享的最多色为背景色灰(5)。模板中的橙(7)像素集合为标记掩码。
2. 创建 N^2 x N^2 的输出网格，初始化为灰(5)。
3. 对源网格中每个非灰像素 P（位于源位置 (r, c)，颜色 C）：将模板的橙(7)掩码重涂为颜色 C，印章到输出网格的第 (r, c) 块（即行区间 [r*N, (r+1)*N-1]，列区间 [c*N, (c+1)*N-1]）。
4. 印章全部完成后，在输出网格中找到所有 8-连通非灰单色分量，计算各自包围框。
5. 若分量 B 的包围框严格包含在分量 A 的包围框内，且 A 与 B 颜色不同，则将 B 的所有像素设为灰(5)（擦除）。
6. 若存在多层包含（A 包含 B，B 包含 C），从最内层开始擦除：先擦除 C，再检查 B 是否仍被 A 包含（若 C 被擦除后 B 的包围框可能缩小——但由于只擦除 C 的像素而不改变 B 的像素，B 的包围框不变），若仍被包含则继续擦除 B。
7. 同色分量之间不触发擦除（即使包围框存在包含关系）。

**关键洞察**：输入中的源像素之间没有任何包含关系——它们只是散布在小网格上的点。包含关系完全是印章扩展的几何副产物：模板形状决定了每个印章的占地范围，源像素间距决定了印章之间的相对位置，两者共同涌现出输入中不存在的嵌套结构。求解者需要先完成印章、再检测包含，而非在输入层面直接判断。
