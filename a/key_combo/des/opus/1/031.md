## 新题 1：计数平移十字与幽灵遮蔽距离环

**组合逻辑**：[计数/counting] → [平移/translate](创新：平移后旧位置留灰色幽灵) → [填充/fill](创新：Chebyshev 距离环被幽灵轨迹遮断)

**来源原语**：计数/counting、计数器像素/counter_pixel、平移/translate、计数决定偏移/count_determines_offset、计数器消失/counter_disappears（来自 e48d4e1a）；填充/fill、交叉点中心/intersection_center、偶数切比雪夫距离/even_chebyshev_distance（来自 759f3fd3）；擦除/erase（来自 d687bc17）

**依赖链**：计数器像素数量决定十字平移距离 → 平移改变交叉中心坐标 → 旧位置幽灵轨迹占据部分背景 → 新中心的 Chebyshev 距离环只能绘制在既不被新十字也不被幽灵占据的背景像素上 → 幽灵轨迹在距离环中打出不规则缺口

用一行描述：根据计数器像素平移十字后，在旧位置留下灰色幽灵痕迹，再以新交叉点为中心绘制偶数 Chebyshev 距离环，幽灵痕迹处不绘制。

**输入结构**：约 12x12 黑(0)背景网格。有一条完整的蓝(1)横行和一条完整的蓝(1)纵列，交叉形成十字。最右列的顶部连续放置 1~3 个灰(5)像素作为计数器（生成约束：灰像素数量保证平移后十字仍完全在网格内）。网格中无其他非黑像素。不同示例中十字的初始交叉位置不同，计数器数量也不同。

**规则**：
1. 数灰(5)像素的个数 N。将灰像素全部擦除为黑(0)。
2. 将蓝(1)十字整体平移：横行下移 N 行，纵列左移 N 列。原位置的蓝像素擦除为黑(0)，新位置绘制蓝(1)。
3. 平移后，将所有"原十字占据但新十字不占据"的像素涂灰(5)，形成幽灵轨迹。（新旧重叠处保留蓝色。）
4. 确定新十字的交叉点坐标 (r, c)。对网格中每个既非蓝(1)也非灰(5)的黑(0)像素，计算其到 (r, c) 的 Chebyshev 距离 d = max(|row-r|, |col-c|)。若 d 为正偶数，将该像素涂黄(4)。
5. 灰(5)幽灵像素和蓝(1)十字像素均保持不变，不被黄色覆盖。

**关键洞察**：幽灵轨迹不是纯装饰——它遮断了距离环，使得同一环在不同方向上出现缺口。求解者必须同时推断平移量（从计数器）和幽灵遮蔽规则（旧位置不画环），缺少任一条件都无法还原输出。

## 新题 2：按内部分类堆叠后跨列桥接同色对

**组合逻辑**：[分类/classify](已有) → [排序+堆叠/sort+stack](已有) → [连线/draw_line](创新：桥接目标由分类-堆叠后的空间关系决定，而非原始位置)

**来源原语**：分类/classify、排序/sorting、堆叠/stack、空心矩形/hollow_rectangle、实心方块/solid_square、按类型分列/type_determines_column、内部判定类型/interior_determines_type（来自 2ba387bc）；连线/draw_line、实心矩形/solid_rect、桥接条/bridge_bar、同色配对/same_color_pair、对向间隙/facing_gap、最短间隙优先连/shortest_gap_first（来自 f3b10344）

**依赖链**：内部状态决定分类 → 分类决定左右列分配 → 分配决定同色对是否面对面 → 面对状态决定是否可桥接以及桥的行跨度 → 分类错误则列位置错误，同色对无法正确配对

用一行描述：将散落的 4x4 方块按空心/实心分左右列堆叠，然后在同色的空心-实心对之间用青色桥接线连通。

**输入结构**：约 18x20 黑(0)背景网格。散布 6~8 个互不相邻的 4x4 方块对象，每个对象为单色（从红(2)、绿(3)、蓝(1)、橙(7)中取色）。方块分两种类型：空心方块（1 像素宽彩色边框，内部 2x2 为黑(0)）和实心方块（4x4 全部填充一种颜色）。同一颜色恰好出现两次：一次为空心，一次为实心（生成约束）。不同示例中方块颜色组合、数量（3~4 对）和散布位置均不同。

**规则**：
1. 对每个 4x4 方块检查其内部 2x2 区域：若 2x2 全为黑(0)则判为空心（frame），否则判为实心（solid）。
2. 按原始输入中边界框左上角的行坐标从小到大排序。空心方块依序在输出左半区从上到下堆叠（第 k 个空心放在行 4k 起、列 0~3），实心方块依序在输出右半区堆叠（第 k 个实心放在行 4k 起、列 5~8）。列 4 为空列间隔。输出宽度为 9，高度为 4 x max(空心数, 实心数)，不足部分用黑(0)填充。
3. 堆叠完毕后，对每种颜色找到其空心方块和实心方块。它们分别在左列和右列，中间隔 1 列空隙。在二者共享的行跨度内（取交集行范围，然后上下各缩进 1 行），将空隙列（列 4）中对应行的像素涂青(8)作为桥接。
4. 若某对的共享行跨度缩进后不足 1 行（即二者行范围完全不重叠或仅重叠 1~2 行），则该对不绘制桥接。

**关键洞察**：桥接能否出现、跨几行，完全取决于堆叠后左右两侧同色对的行对齐程度——而对齐由所有方块的原始输入行排序共同决定。改变任何一个方块的输入位置都可能改变多对桥接的存亡。

## 新题 3：标记像素展开为迷宫墙壁，门框间寻路

**组合逻辑**：[裁剪/crop + 连线/draw_line](创新：标记像素展开为行列墙壁形成迷宫) → [路径填充/path_fill](创新：在展开生成的迷宫中寻找单调最短路径并集)

**来源原语**：裁剪/crop、连线/draw_line、矩形/rectangle、标记像素/marker_pixel、行列交叉/row_col_cross、标记展为整行整列/marker_to_row_col（来自 8731374e）；路径填充/path_fill、门框/doorway_frame、走廊路径/corridor_path、门洞朝向/doorway_orientation、最短路径并集/monotone_shortest_path_union（来自 692cd3b6）

**依赖链**：标记像素位置决定墙壁网格 → 墙壁网格划分出可通行单元格 → 两个门框的门洞位置决定路径起止点 → 墙壁布局约束所有可行的单调最短路径 → 路径并集绘制在可通行单元格上

用一行描述：将矩形内稀疏标记展开为整行整列的墙壁生成迷宫，再在迷宫中标出两个门洞之间所有单调最短路径的并集。

**输入结构**：约 15x15 黑(0)背景网格。网格中央有一个约 11x11 的蓝(1)底色矩形，矩形内部散布 2~4 个红(2)标记像素（生成约束：标记像素不在同一行也不在同一列，且展开后至少存在一条从左门洞到右门洞的通路）。矩形外侧左边和右边各有一个 3x3 绿(3)门框（1 像素宽框，中心为绿(3)，中心的左侧或右侧 4-邻居中恰好一个为黑(0)背景——即门洞朝向矩形方向）。不同示例中标记位置、矩形精确尺寸、门框行位置均不同。

**规则**：
1. 裁剪出蓝(1)矩形的范围。在该范围内，以蓝(1)为底色，对每个红(2)标记像素将其所在整行和整列全部涂红(2)（行列交叉处也为红(2)）。这构成一个蓝底红墙的网格迷宫。
2. 确定两个绿(3)门框的门洞位置——每个门框中心向矩形方向的第一个黑(0)像素即为门洞。门洞外侧紧邻矩形边界的那个蓝(1)像素为"外部门洞单元格"。
3. 以两个外部门洞单元格为起止点。在蓝(1)矩形内部，将红(2)像素视为不可通过的墙壁。仅允许向目标门洞方向的单调移动（行步或列步必须缩小与目标的曼哈顿距离中至少一个分量）。
4. 找出所有满足单调约束的最短路径（步数最少），将这些路径经过的蓝(1)像素全部涂黄(4)。两个门洞像素也涂黄(4)。
5. 输出保留完整网格（含门框和矩形外背景），仅改变路径上的蓝(1)→黄(4)和门洞→黄(4)。

**关键洞察**：标记像素的位置同时编码了迷宫的水平和垂直墙壁——每个标记像素产生一行一列两道墙，少量标记就能切割出复杂的迷宫拓扑。路径并集不是一条路，而是所有等长最短路的联合区域，其形状完全由墙壁切割决定。

## 新题 4：嵌套层次编码调色板，孔洞数索引调色板重涂

**组合逻辑**：[压缩/compress + 排序/sorting](创新：嵌套排序结果不输出为方环而是作为运行时调色板) → [计数/counting + 重涂色/recolor](创新：孔洞数不再映射固定颜色而是索引嵌套调色板)

**来源原语**：压缩/compress、排序/sorting、嵌套形状/nested_shape、嵌套层次/nesting_hierarchy、面积序映射环/area_order_to_ring（来自 eb5a1d5d）；计数/counting、重涂色/recolor、前景对象/foreground_object、封闭背景区域/enclosed_background_region、孔洞数映射颜色/hole_count_to_color_mapping（来自 37d3e8b2）；擦除/erase（来自 aa62e3f4）

**依赖链**：嵌套形状的面积排序生成颜色序列（调色板）→ 右侧对象的孔洞数作为调色板索引 → 索引选出的颜色用于重涂右侧对象 → 左侧嵌套形状擦除后调色板信息消失 → 必须先解码嵌套才能确定任何重涂结果

用一行描述：左半部嵌套彩色轮廓按面积排序形成调色板，右半部灰色对象按各自孔洞数从调色板中取色重涂，左半部随后擦除。

**输入结构**：约 18x18 黑(0)背景网格。左半区（约列 0~7）放置 3~4 层嵌套的单色轮廓形状（每层为一种不同颜色的 4-连通闭合环，从红(2)、蓝(1)、绿(3)、黄(4)中取色；外层包围内层；各层边界框面积严格递减）。右半区（约列 10~17）放置 3~4 个互不相邻的灰(5)4-连通实心对象（各约 15~30 像素），每个对象内部有 1~4 个不同的黑(0)封闭背景连通分量（孔洞）。生成约束：右侧对象的孔洞数互不相同，且最大孔洞数不超过嵌套层数。不同示例中嵌套颜色顺序不同（即同一嵌套深度在不同示例中使用不同颜色）。

**规则**：
1. 在左半区检测所有嵌套轮廓层。按边界框面积从大到小排序，得到颜色序列 P = [c1, c2, c3, ...]，其中 c1 是最外层颜色，c2 是次外层，以此类推。
2. 在右半区，对每个灰(5)对象，计算其内部的 4-连通黑(0)封闭区域数量 H。
3. 将每个灰(5)对象重涂为 P[H]（序列 P 的第 H 个颜色，从 1 开始索引，即 H=1 取 c1，H=2 取 c2 等）。对象形状不变，仅颜色从灰(5)变为 P[H]。
4. 将左半区所有嵌套轮廓擦除为黑(0)背景。

**关键洞察**：调色板不是固定的——它编码在输入本身的嵌套空间结构中，必须通过面积比较解码。不同示例的嵌套颜色顺序不同，因此单看一个示例无法确定"1 个孔洞对应什么颜色"，必须对比嵌套结构和重涂结果才能归纳出索引规则。

## 新题 5：散落前景拉直为色序行，分隔下循环填充

**组合逻辑**：[计数/counting + 拉直/straighten](创新：多组不同色前景分别拉直后按长度排列成色序行) → [填充/fill](创新：色序行作为循环模板填充分隔行以下)

**来源原语**：计数/counting、拉直/straighten、前景掩码/foreground_mask、线段/line_segment、居中放置/center_placed、保留颜色与面积/keep_color_area（来自 dce56571）；填充/fill、顶行色序/top_row_color_sequence、分隔行/separator_row、分隔下循环填色/below_separator_cycle_fill（来自 bd4472b8）

**依赖链**：各色前景像素数决定拉直后线段长度 → 线段按长度排序决定色序行的颜色排列 → 色序行模式决定分隔下每行的循环填色内容 → 改变任何一组前景的像素数都会改变排序，进而改变整个填充图案

用一行描述：将分隔行以上多组不同色散落前景按像素数拉直排序拼成色序行，再以该行为模板循环填充分隔行以下。

**输入结构**：约 12x15 黑(0)背景网格。上半区（分隔行以上）有 3~4 组不同颜色的前景像素，每组为同一种颜色的 4-连通或多连通不规则形状（如红(2)散布 5 个像素、蓝(1)散布 3 个像素、绿(3)散布 7 个像素等）。网格中间有一整行灰(5)分隔行。分隔行以下全为黑(0)。不同示例中各色像素数量和散布位置均不同。生成约束：各色像素数互不相等，且所有色段长度总和加上色段间间距不超过网格宽度。

**规则**：
1. 对上半区每种非黑非灰前景颜色，计算其像素总数 n_i。
2. 将每种颜色拉直为一条长度 n_i 的水平线段，颜色保持不变。
3. 按线段长度从短到长排序（生成约束保证长度互不相等）。将排序后的线段从左到右依次拼接在分隔行上方第一行，相邻线段之间插入 1 个黑(0)像素间隔。这条拼接后的行即为"色序行"。
4. 擦除上半区除色序行和灰(5)分隔行以外的所有像素（变为黑(0)）。
5. 对分隔行以下的每一行，按色序行的颜色模式从左到右循环填充：色序行中的非黑像素按原色填入对应列，黑像素位置保持黑色；若行宽超过色序行宽度则从头循环。

**关键洞察**：散落前景的具体形状完全无关紧要——只有像素数量决定输出。但像素数同时控制两件事：线段长度（决定色序行中该色占多宽）和排序位置（决定该色在色序行中的左右顺序），两者共同塑造循环填充图案。

## 新题 6：补全缺失像素后按孔洞拓扑重涂，再桥接同色对

**组合逻辑**：[补全/completion](已有) → [计数/counting + 重涂色/recolor](创新：补全后的拓扑决定颜色而非原色) → [连线/draw_line](创新：重涂结果决定哪些对象成为同色对)

**来源原语**：补全/completion、连通分量/connected_component、缺失像素异色补/missing_diff_color_fill（来自 60b61512）；计数/counting、重涂色/recolor、封闭背景区域/enclosed_background_region、孔洞数映射颜色/hole_count_to_color_mapping（来自 37d3e8b2）；连线/draw_line、同色配对/same_color_pair、对向间隙/facing_gap、最短间隙优先连/shortest_gap_first（来自 f3b10344）

**依赖链**：补全操作改变对象形状 → 形状变化改变孔洞拓扑 → 孔洞数决定重涂颜色 → 重涂结果决定哪些对象"同色" → 同色配对决定桥接位置。关键涌现：原本不同颜色的对象可能因孔洞数相同而被重涂为同色，从而产生意外的桥接连接。

用一行描述：补全散落的不完整彩色对象，按补全后孔洞数统一重涂颜色，再在同色对之间画桥。

**输入结构**：约 18x18 黑(0)背景网格。散布 5~6 个 8-连通前景对象，各自颜色不同（取自红(2)、绿(3)、蓝(1)、黄(4)、橙(7)、品红(6)），每个对象的边界框为 5x5，但对象本身是不完整的——边界框内有 2~5 个黑(0)缺失像素。每个对象的 5x5 边界框内部，补全后会形成 0~3 个黑(0)封闭孔洞（这些孔洞是有意设计的，非缺失像素）。生成约束：至少有两对对象补全后孔洞数相同（从而会被重涂为同色）；这些同色对中至少一对在水平或垂直方向隔空相对且行/列跨度重叠至少 3 像素。

**规则**：
1. 对每个 8-连通前景对象，找到其 5x5 边界框，将框内所有黑(0)缺失像素涂为灰(5)进行补全。（注意：有些黑(0)像素是有意的孔洞，不是缺失——区分方法见下一步。）
2. 补全判定：边界框内，与对象 8-连通但原为黑(0)的像素为"缺失"，涂灰(5)；与对象不连通的黑(0)连通分量为"孔洞"，保持黑(0)。具体做法：将边界框内所有黑(0)像素做 4-连通分量分析，与边界框边缘 4-连通的黑(0)分量为"外部"（涂灰(5)补全），完全被前景包围的黑(0)分量为"孔洞"（保留）。
3. 计算每个补全后对象内部的孔洞数 H。按固定调色板重涂对象的所有非黑像素（包括原色和灰(5)补全色统一替换）：H=0 → 蓝(1)，H=1 → 红(2)，H=2 → 绿(3)，H=3 → 黄(4)。
4. 重涂完毕后，找所有同色对象对。对每对检查是否在水平或垂直方向上通过纯黑(0)背景隔空相对，且行/列跨度重叠至少 3 像素。
5. 对满足条件的同色对，在其对向间隙中绘制青(8)桥接条：桥占据共享行/列跨度去掉首尾各 1 像素后的范围，宽度为间隙列/行数。若多对桥接候选，全部绘制；若桥接区域重叠，后绘制的覆盖先绘制的（按间隙长度从长到短绘制，即短桥在上层）。

**关键洞察**：原本每个对象颜色不同，不存在"同色对"。同色对完全由补全后的拓扑分析涌现而出——两个外观完全不同的对象可能因恰好有相同数量的孔洞而变成同色，从而产生桥接。求解者必须先补全、再数孔、再重涂，才能知道哪些对象最终会被连接。

## 新题 7：双轴镜像拼合后轮廓融合描边

**组合逻辑**：[镜像/mirror + 平铺/tiling](已有) → [轮廓描边/outline_trace](创新：对镜像拼合后融合的新形状描外轮廓，而非对单个瓦片描边)

**来源原语**：镜像/mirror、平铺/tiling、瓦片/tile、双轴反射四象限/both_axes_four_quadrants（来自 3af2c5a8）；轮廓描边/outline_trace、擦除/erase、轮廓线/outline、标记色/marker_color、外侧相邻/outer_adjacent、最小色为画笔/smallest_as_paint（来自 aa62e3f4）

**依赖链**：镜像方式决定四个象限的图案 → 相邻象限在拼合边界处可能产生新的连通（四个独立形状融合为一个更大的连通体）→ 融合后的连通体形状决定外轮廓 → 外轮廓使用标记色绘制 → 单看一个象限无法预测融合后的轮廓走向

用一行描述：将含有彩色图案和标记色的小网格做双轴镜像拼成四象限大网格，擦除拼合后的融合图案并沿其外轮廓用标记色描边。

**输入结构**：约 5x5 黑(0)背景小网格。网格中有一个 8-连通的前景图案，使用某种主色（如蓝(1)，约 6~10 像素）。图案触及网格的至少一条边（保证镜像后相邻象限的图案在边界处相邻从而融合）。网格中另有 1~2 个标记像素使用另一种颜色（如红(2)），像素数严格少于主色。不同示例中前景图案形状、触边方式和标记色位置均不同。

**规则**：
1. 确定主色（像素数最多的非背景色）和标记色（像素数最少的非背景非主色颜色）。
2. 将小网格做双轴镜像，构建 2H x 2W 的大网格：左上放原图，右上放水平镜像，左下放垂直镜像，右下放 180 度旋转。
3. 在大网格中，将所有主色像素视为一个整体（可能因边界融合而成为一个大的 8-连通分量）。将所有主色和标记色像素全部擦除为黑(0)。
4. 对擦除前主色分量的外轮廓进行描边：将大网格中每个与已擦除主色像素 4-相邻的黑(0)背景像素涂为标记色。（标记色像素的位置也已被擦除，不参与轮廓计算。）
5. 输出为大网格，仅含黑(0)背景和标记色外轮廓。

**关键洞察**：单个象限中的图案可能是不连通的碎片或者是贴边的半形状——只有四象限镜像拼合后，跨边界的像素相邻才能形成完整的融合连通体。轮廓描边作用于这个融合体而非四个独立副本，因此输出的轮廓形状无法通过对单个象限描边再镜像得到。

## 新题 8：像素计数决定平铺阵列，象限位置决定旋转角度

**组合逻辑**：[计数/counting](已有) → [平铺/tiling](已有) → [旋转/rotation](创新：旋转角度由副本在阵列中的象限位置决定，而非固定)

**来源原语**：计数/counting、平铺/tiling、精灵体/sprite、阵列排布/array_layout、像素数定尺寸数/pixel_count_sets_size_copies（来自 91413438）；旋转/rotation、拼接/assembly、象限/quadrant、逐象限旋转排布/quadrant_rotation_layout（来自 7953d61e）

**依赖链**：前景像素数 F 决定副本数量 → 黑像素数 B 决定阵列边长 → 每个副本在 BxB 阵列中的槽位坐标决定其所处象限 → 象限决定旋转角度 → 像素计数同时控制了"放多少个"和"每个怎么旋转"

用一行描述：根据 3x3 精灵体的前景/背景像素数决定平铺阵列的大小和副本数，每个副本按其在阵列中的象限位置做不同角度旋转。

**输入结构**：一个 3x3 网格，包含黑(0)背景像素和一种非黑前景色的像素（如红(2)）。前景像素数 F 为 2~5，黑像素数 B = 9 - F 为 4~7。不同示例中前景图案形状和颜色不同。生成约束：精灵体不是旋转对称的（即 90 度旋转后与原图不同），保证不同象限的副本视觉可区分。

**规则**：
1. 计算前景像素数 F 和黑像素数 B。
2. 构建一个 (3B) x (3B) 的全黑输出画布，划分为 BxB 个 3x3 槽位。
3. 按行优先顺序，将前 F 个槽位填入精灵体副本，其余槽位保持全黑。
4. 每个被填充的槽位根据其在 BxB 阵列中的象限位置决定旋转角度：将 BxB 阵列在行和列方向各二等分（若 B 为奇数，中间行/列归入左上象限）。左上象限 → 0 度（原图），右上象限 → 逆时针 90 度，左下象限 → 180 度，右下象限 → 逆时针 270 度。
5. 将旋转后的精灵体放入对应槽位。

**关键洞察**：像素计数同时编码了两种信息——阵列规模和填充数量。阵列规模又决定了象限边界的位置，进而决定每个副本的旋转角度。因此增加一个前景像素不仅多一个副本，还缩小了阵列（B 减 1），改变了所有副本的象限归属和旋转。

## 新题 9：相位解码生成周期格点作为寻路障碍

**组合逻辑**：[解码/decode + 平铺/tiling](创新：解码出的周期格点不用于视觉输出而是作为障碍物布局) → [寻路/pathfinding](创新：在周期性障碍中执行受约束的转向寻路)

**来源原语**：解码/decode、平铺/tiling、轮廓字形/contour_glyph、周期格点/periodic_lattice、相位编码/phase_encoding（来自 eee78d87）；寻路/pathfinding、连线/draw_line、障碍像素/barrier_pixel、起止标记/start_end_marker、路径/path、障碍触发转向/barrier_triggers_turn（来自 2dd70a9a）

**依赖链**：3x3 轮廓字形编码周期相位 → 解码后平铺到大画布形成周期性障碍格点 → 障碍布局决定寻路时何处必须转向 → 起止标记位置决定路径走向 → 不同字形产生完全不同的障碍拓扑和路径

用一行描述：将小轮廓字形解码为周期相位，在大画布上平铺该相位作为障碍，再从起点到终点在障碍间寻路（障碍触发转向）。

**输入结构**：一个 6x6 橙(7)背景网格。网格中有一个 3x3 范围的轮廓字形，使用青(8)像素（3~5 个像素组成的连通图案，如十字、H形、X形、四角等）。网格中另有一个绿(3)像素和一个红(2)像素，位于轮廓字形的 3x3 边界框之外（作为起止标记）。不同示例中字形形状和起止标记位置均不同。

**规则**：
1. 提取 3x3 轮廓字形。将字形中青(8)的位置记为 1，橙(7)的位置记为 0，得到 3x3 二值相位模板。
2. 构建 15x15 黑(0)画布。将相位模板在画布上做周期平铺（每 3 行 3 列重复），模板中 1 的位置涂青(8)作为障碍，0 的位置保持黑(0)。
3. 将绿(3)和红(2)起止标记从 6x6 网格映射到 15x15 画布：映射公式为 (row, col) → (row * 2 + 1, col * 2 + 1)（取中心偏移使标记落在黑色可通行区域内；若映射位置恰好为障碍，则向下和向右各偏移 1 像素直到找到黑(0)像素）。
4. 从绿(3)起点出发寻路到红(2)终点。移动规则：每步沿当前方向前进一格；若下一格为青(8)障碍或网格边界，则当前位置原地顺时针转 90 度（不移动），再尝试前进；若转了 4 次仍无法前进则停止。初始方向：若终点在起点右侧则初始向右，否则初始向下。
5. 将路径经过的所有黑(0)像素涂绿(3)（不覆盖障碍）。起点和终点分别保持绿(3)和红(2)。

**关键洞察**：轮廓字形的几何形状看似是一个视觉符号，实际上它精确编码了障碍物的周期性空间分布。不同的字形——即使只差一个像素——会产生截然不同的障碍格点，导致完全不同的路径。求解者必须理解字形→相位→平铺→障碍这条解码链。

## 新题 10：颜色匹配边框方向移动补全后的对象

**组合逻辑**：[补全/completion](已有，创新：补全对象为非正方形、需识别连通结构) → [移动/move](创新：移动目标由边框侧色与对象原色的匹配关系决定，且移动的是补全后的完整体)

**来源原语**：补全/completion、连通分量/connected_component、缺失像素异色补/missing_diff_color_fill（来自 60b61512）；移动/move、擦除/erase、边框/frame、标记像素/marker_pixel、颜色匹配边/color_matches_side、颜色决定目标边/color_determines_side（来自 d687bc17）

**依赖链**：对象的缺失像素需要补全才能确定完整形状 → 对象的原色（非补全色）与边框某侧颜色匹配 → 匹配关系决定移动方向 → 补全后的完整形状被整体移动到目标边框侧 → 不补全则形状不完整，移动后留下碎片；不识别边框色则不知方向

用一行描述：在彩色四边框内补全散落的不完整对象，根据每个对象的原色与框边颜色的匹配将补全后的完整体推向对应边框侧。

**输入结构**：约 13x13 黑(0)背景网格。网格有一个 1 像素宽的矩形边框，四边各为不同颜色：上边红(2)、下边蓝(1)、左边绿(3)、右边黄(4)（框角像素随意取相邻边颜色之一）。框内有 3~4 个 8-连通前景对象，每个对象使用的颜色恰好与某一边框侧颜色相同（如一个红(2)对象、一个蓝(1)对象等）。每个对象占据约 4~8 个像素，其 4x4 边界框内有 1~3 个黑(0)缺失像素。不同对象的边界框互不重叠。不同示例中对象形状、位置、以及边框四边的颜色分配均不同。生成约束：每种边框颜色最多对应一个内部对象；对象移动到目标边后不与其他已移动的对象重叠。

**规则**：
1. 对每个框内 8-连通前景对象，找其 4x4 边界框。在框内将不属于该对象 8-连通分量但被其包围（4-连通不触及边界框边缘）的黑(0)像素保留为孔洞，其余黑(0)像素涂灰(5)进行补全。
2. 确认每个对象的原色 C（非灰(5)的前景色）。找到边框上颜色为 C 的那一侧（上/下/左/右）。
3. 将补全后的完整对象（含灰(5)补全像素）整体平移，使其边界框的对应边紧贴目标边框侧内侧（如目标为上边则对象上边紧贴框上边下方 1 格处）。平移时保持对象在正交方向的坐标不变（如目标为上边，则列坐标不变，仅行坐标变化）。
4. 清除对象原位置的所有像素（原色和灰(5)均变黑(0)）。
5. 在新位置绘制补全后的对象：原色像素保持原色，灰(5)补全像素保持灰(5)。

**关键洞察**：补全和移动不可交换顺序——必须先补全才能得到完整的移动体（否则缺失像素处会在移动后留下断裂）。而移动方向由颜色匹配决定，这又依赖于正确识别对象的原色。灰(5)补全色在输出中起标记作用：它使求解者可以区分对象的"原始部分"和"补全部分"，从而反向推断规则。
