## 新题 1：拓扑封闭性决定填充模式

**组合逻辑**：[连通分量检测] + [边界可达性 → 拓扑分类](决策节点) → [同心层填充 | 均匀重涂色](条件分支)

**来源原语**：
- 连通分量检测、边界可达性、拓扑分类 ← 84db8fc4
- 同心层填充、以控制点为中心、奇偶距离决定颜色 ← b7fb29bc
- 重涂色 ← 84db8fc4/aedd82e4

**依赖链**：连通分量检测将背景分为若干区域，边界可达性判断产生拓扑分类，拓扑分类的结果决定使用哪种填充算法——封闭区域触发以控制像素为中心的同心环填充，边界可达区域触发均匀灰色填充。删掉拓扑分类则无法选择填充模式；删掉同心层填充则封闭区域输出未定义。

根据区域是否被前景屏障完全包围，选择同心环填充或均匀色填充。

**输入结构**：约 18x18 的网格，背景为黑(0)。蓝(1)和绿(3)像素构成不规则屏障网络（各屏障为 4-连通的单像素宽线条或小型块状结构，总像素数约 40~60），将黑色背景分割为若干 4-连通区域。部分黑色区域触及网格外边界（至少一个像素在第 0 行、最后一行、第 0 列或最后一列），部分被屏障完全包围。每个黑色区域内恰好有一个红(2)控制像素。生成约束：封闭区域数量为 2~3 个，边界可达区域数量为 2~3 个；每个封闭区域的边界框至少 5x5（保证同心环可辨）；控制像素与屏障的 4-连通距离 >= 2（不紧贴屏障）。

**规则**：
1. 保留所有蓝(1)和绿(3)屏障像素不变。
2. 将所有黑(0)像素按 4-连通分为若干区域（红色控制像素所在格视为属于该区域，但控制像素本身颜色保留）。
3. 对每个区域判断是否触及网格外边界。
4. 触及边界的区域：将该区域内所有黑色像素重涂为灰(5)，红色控制像素保持红色不变。
5. 不触及边界的封闭区域：以该区域内的红(2)控制像素为中心，计算区域内每个黑色像素到控制像素的切比雪夫距离（max(|dr|, |dc|)）。偶数距离（不含 0）涂红(2)，奇数距离涂黄(4)。控制像素本身（距离 0）保持红色。
6. 仅填充属于该区域的黑色像素，不跨越屏障。

**关键洞察**：同一种"区域内有控制像素"的输入结构，因拓扑封闭性不同而触发完全不同的填充算法——仅看单个封闭区域可能误以为所有区域都做同心环填充，需要对比边界可达区域才能归纳出条件分支。

## 新题 2：涌现主干与垂直连接

**组合逻辑**：[对侧配对 + 滑动 → 汇合轨迹](涌现主干) → [连接到主干](利用涌现结构)

**来源原语**：
- 对侧配对、滑动、相向移动留迹汇合、汇合点 ← 29c11459
- 连接到主干、共行列定义主干 ← bf89d739
- 连线 ← dbc1a6ce

**依赖链**：上下边缘的配对标记相向滑动产生竖直轨迹线段，这些涌现的轨迹构成"主干网络"——在输入中并不存在。然后内部的孤立像素沿水平方向连接到最近的主干线段。删掉滑动则主干不存在；删掉连接则内部像素悬空无意义。

对侧标记相向滑动形成竖直主干，内部孤立像素水平连线到最近主干。

**输入结构**：约 15x15 的网格，背景为黑(0)。网格上边缘（第 0 行）和下边缘（最后一行）各有 2~3 个红(2)标记像素，上下标记按列一一配对（同列恰好上下各一个）。网格内部散布 3~5 个蓝(1)孤立像素（互不相邻，每个蓝像素的 8-邻域内无其他前景像素）。生成约束：上下配对红标记的行距 >= 6；蓝色像素严格在配对红标记之间的行范围内（不在第 0 行或最后一行）；每个蓝像素左右方向至少有一条竖直主干线段（即至少存在一对红标记其列坐标与蓝像素列坐标不同）；蓝像素与最近主干的水平距离 >= 2。

**规则**：
1. 对每对同列红标记（上边缘一个、下边缘一个），两者同时向对方滑动。上方的向下移动，下方的向上移动，每步各移动一格，沿途将经过的黑色背景像素涂为红(2)。两者相遇于同一格（列间距为奇数时不会发生，由生成约束排除）或相邻格时停止。若两者相邻停止，将它们之间无像素（已经相邻），标记汇合点为两者中间行（取上方的那个位置）涂灰(5)；若相遇于同一格则该格涂灰(5)。
2. 滑动完成后，每列的红色竖直线段（含原始端点标记）构成一条"主干"。
3. 对每个蓝(1)内部像素：沿水平方向向左和向右搜索，找到最近的主干像素（红色或灰色像素，且该像素属于某条竖直主干）。选择距离更近的方向；若左右距离相同，选向左。
4. 从蓝像素出发向选定方向画绿(3)水平线段：起始位置（蓝像素本身）保持蓝色不变，蓝像素与主干之间的所有黑色背景像素涂绿(3)，到达主干像素前一格为止（不覆盖主干的红色/灰色像素）。
5. 所有其他像素保持不变。

**关键洞察**：主干是滑动操作的产物而非输入预设的结构——内部像素的连接方向完全取决于滑动结束后主干的位置，两步操作通过这个涌现的中间结构紧密耦合。等距时选左的规则需要对比多个示例才能归纳。

## 新题 3：分量计数驱动对角印章阵列

**组合逻辑**：[连通分量检测 + 计数](提取几何参数) → [印章覆盖 + 对角线输出](参数驱动的布局生成)

**来源原语**：
- 连通分量检测、连通分量 ← 84db8fc4/aedd82e4
- 计数、数量决定边长、对角线标记 ← d0f5fe59
- 印章覆盖、模板区、分隔行 ← b4a43f3b/c3e719e8

**依赖链**：连通分量计数值 N 同时决定输出画布大小（N*H x N*W 的宏格网格）和对角线上的印章位置。模板区提供印章图案的像素内容。删掉计数则输出大小和放置位置均未定义；删掉模板印章则对角线位置无内容可填。

计数输入中的前景连通分量，以计数值构造宏格网格，沿主对角线印章模板图案。

**输入结构**：约 20x20 的网格，背景为黑(0)。网格由一条灰(5)水平分隔行分为上下两个区域。上方区域左上角有一个紧凑的彩色模板图案（大小为 3x3 或 4x4，由红(2)、蓝(1)、绿(3)等 2~3 种颜色构成一个非对称图案），模板四周与灰分隔行及网格边界之间有黑色间距。下方区域散布若干黄(4)前景连通分量：每个分量为 4-连通的单色小图形（3~8 个像素，形状各异——可以是线段、弯折、小块等），分量之间 8-连通距离 >= 2（确保可分离）。分量数量 N 为 3~5。生成约束：上方模板图案不含黄(4)或灰(5)；模板为非对称图案（旋转 90 度后与自身不同）。

**规则**：
1. 识别灰(5)分隔行。提取分隔行以上区域中所有非黑(0)非灰(5)像素的最小边界框，记为模板，大小 H x W。
2. 检测分隔行以下区域中所有黄(4)像素的 4-连通分量，计数为 N。
3. 构造输出网格：大小为 (N * H) x (N * W)，全部填充黑(0)。
4. 将输出视为 N x N 的宏格网格，每个宏格大小为 H x W。宏格 (i, j) 对应输出区域 [i*H .. (i+1)*H-1, j*W .. (j+1)*W-1]。
5. 在主对角线的 N 个宏格位置（第 i 行第 i 列，i = 0, 1, ..., N-1），将模板图案逐像素复制到对应宏格中。
6. 非对角线宏格保持黑色。

**关键洞察**：下方散布的黄色图形仅作为计数令牌——其具体形状、大小和位置不影响输出，只有数量 N 决定输出的网格维度；上方模板的像素内容完整保留但被复制了 N 份。

## 新题 4：对角链堆叠框架与同心环填充的遮挡冲突

**组合逻辑**：[堆叠 + 对角链排列 + 角点重叠](空间布局) x [同心层填充 + 奇偶距离决定颜色](内部填充) → [冲突优先级](重叠区域裁决)

**来源原语**：
- 堆叠、对角链排列、角点重叠、冲突优先级 ← 03560426
- 同心层填充、以控制点为中心、奇偶距离决定颜色、矩形边框、控制像素 ← b7fb29bc
- 按左边缘排序(改造为按面积排序) ← 03560426

**依赖链**：多个矩形框按面积排序沿对角线排列，相邻框角点重叠一格。每个框内部以控制像素为中心做同心环填充。重叠的角点格同时属于两个框的填充范围——必须根据绘制顺序（后绘制覆盖先绘制）裁决颜色。删掉对角排列则无空间重叠；删掉同心填充则重叠区域无颜色冲突需要解决；删掉冲突优先级则重叠格颜色不确定。

将散布的矩形框按面积排序沿对角线堆叠，框内做同心环填充，重叠处后叠的覆盖先叠的。

**输入结构**：约 20x20 的网格，背景为黑(0)。网格中有 3~4 个不同颜色的单像素宽矩形边框（可选颜色：蓝(1)、绿(3)、橙(7)、品红(6)），每个边框内部（边框围成的矩形去掉边框本身的区域）全为黑色，且恰好包含一个与边框同色的控制像素。各边框在输入中互不重叠，散布在网格各处。边框大小互不相同（如 5x5、7x5、6x8 等，最小边长 >= 4）。生成约束：控制像素不在边框的几何中心（行或列偏离中心至少 1 格）；所有边框面积（高 x 宽）互不相等。

**规则**：
1. 检测输入中所有矩形边框（单像素宽的非黑矩形环）。对每个边框，记录其颜色、高 H、宽 W、以及内部控制像素在框内的相对坐标 (cr, cc)（以边框左上角为原点）。
2. 按边框面积（H x W）从小到大排序。
3. 计算输出画布大小：设 N 个框的高分别为 H1..HN、宽分别为 W1..WN（按排序后顺序），则输出高 = H1 + H2 + ... + HN - (N-1)，输出宽 = W1 + W2 + ... + WN - (N-1)。画布填充黑(0)。
4. 按排序顺序依次放置每个边框。第 1 个框的左上角在 (0, 0)；第 k 个框的左上角在（前 k-1 个框的高之和 - (k-1)，前 k-1 个框的宽之和 - (k-1)），使相邻框的角点恰好重叠一格。
5. 放置每个框时，先绘制边框像素（用该框颜色），再填充内部：以框内控制像素的绝对位置为中心，对框内部每个非边框像素计算到控制像素的切比雪夫距离 d。d 为偶数（含 0）涂红(2)，d 为奇数涂黄(4)。控制像素本身（d=0）涂红(2)。
6. 按顺序绘制意味着后放的框的像素（边框 + 填充）覆盖先放的框在同一位置的像素。

**关键洞察**：重叠角点的最终颜色同时取决于两层信息：哪个框后绘制（由面积排序决定）以及该框的同心环在重叠位置的距离奇偶性——仅看单个重叠角点的颜色无法区分是来自边框色、红色偶数环还是黄色奇数环，必须还原完整的堆叠和填充逻辑。

## 新题 5：射线网络围合区域的平铺填充

**组合逻辑**：[射线延伸 + 标记触发转向 + 正交转向](生成网络) → [连通分量检测 + 边界可达性](识别围合区域) → [平铺 + 平移对称](区域内填充)

**来源原语**：
- 射线延伸、标记触发转向、正交转向、起点像素、射线网络 ← b942fd60
- 连通分量检测、连通区域、边界可达性 ← 84db8fc4
- 平铺、平移对称 ← caa06a1f
- 模板区 ← b4a43f3b

**依赖链**：射线从起点沿标记转向形成网络，网络将画布分割为若干区域。连通分量检测 + 边界可达性找出被射线完全围合的区域。围合区域内用模板图案平铺填充。删掉射线则无区域分割；删掉连通分量检测则无法判断哪些区域被围合；删掉平铺则围合区域为空。

射线从起点出发沿标记转向形成网络，被网络完全围合的区域以模板图案平铺填充。

**输入结构**：约 18x18 的网格，背景为黑(0)。左边缘中部有一个红(2)起点像素。网格内散布 4~6 个绿(3)标记像素，位于不同行不同列。网格右下角（距右边缘和下边缘各 1~2 格）有一个 2x2 的模板图案，由蓝(1)和黄(4)组成（如左上蓝右上黄下左黄下右蓝的棋盘格，或其他两色 2x2 图案）。生成约束：标记像素的位置经过安排，使射线网络能围合出 1~2 个矩形区域（即某些标记在同一行或同一列上对齐，射线经过转向后能形成封闭回路）；标记像素距网格边缘 >= 3 行/列；模板图案与射线路径和标记像素不重叠。

**规则**：
1. 从红(2)起点像素向右发出水平射线，将沿途黑色像素涂红(2)。
2. 射线遇到第一个绿(3)标记时停止于标记前一格（不覆盖标记）。若该标记是首次被到达，从停止位置向标记的正交方向（垂直于当前射线方向的两个方向）各发出一条新射线。若该标记已被之前的射线到达过，仅停止，不发出新射线。
3. 每条新射线同样涂红(2)，遇到标记时按相同规则处理（首次触发转向，非首次仅停止）。射线遇到网格边界时停止。射线遇到已有红色像素时也停止（不重复绘制）。
4. 所有射线处理完毕后（广度优先：同一轮新生成的射线按从左到右、从上到下的顺序处理），将剩余黑(0)像素按 4-连通分区。
5. 不触及网格边界的黑色区域为"围合区域"。读取右下角 2x2 模板图案（非黑像素的最小 2x2 边界框）。
6. 对每个围合区域：以该区域边界框左上角为锚点，用模板图案按 2x2 周期平铺——位置 (r, c) 处的颜色 = 模板[(r - 锚点行) mod 2][(c - 锚点列) mod 2]。仅填充属于该围合区域的黑色像素，不覆盖射线、标记或其他已有颜色。
7. 触及边界的黑色区域保持黑色。模板图案原始位置保持不变。

**关键洞察**：射线网络的拓扑形状完全由标记的空间分布决定，被围合的区域是射线路径的副产品；模板图案独立于射线逻辑，只在围合区域涌现后才参与填充——三步操作分别贡献区域边界、区域识别和区域内容。

## 新题 6：金字塔堆叠与标记色驱动的轮廓描边

**组合逻辑**：[重排 + 基线对齐 + 奇数宽度递增](堆叠金字塔形状) → [描边 + 中心扩展](金字塔外轮廓) ← [标记色决定描边色](被覆盖标记的颜色映射)

**来源原语**：
- 重排、基线对齐、奇数宽度递增、前景列像素、居中金字塔 ← 3d6c6e23
- 描边、中心扩展、标记色决定描边色 ← 913fb3ed
- 控制像素(改造为列底标记) ← b7fb29bc

**依赖链**：列像素先堆叠为底部对齐的居中金字塔（形状由像素数的平方根分解决定），金字塔建成后其外轮廓需要描边，而描边颜色由列底标记像素的颜色决定——该标记被金字塔底行覆盖，其颜色信息在空间上消失但已被逻辑消费。删掉金字塔堆叠则无形状可描边；删掉标记色映射则轮廓颜色未定义。

将每列散布的前景像素堆叠为底部对齐的居中金字塔，再根据被覆盖的列底标记色为金字塔描轮廓线。

**输入结构**：约 15x20 的网格，背景为黑(0)。网格有 2~3 个"源列"（列坐标不同），源列之间间隔 >= 6 列。每个源列中有 n^2 个橙(7)前景像素（n = 2 或 3，即 4 或 9 个像素）纵向连续排列（从某一行开始向下连续，中间无间断）。每个源列的前景像素正下方紧邻一行有一个标记像素，颜色为红(2)、绿(3)或青(8)之一（不同源列的标记颜色可相同或不同）。生成约束：金字塔底行宽度（2n-1）不超出网格列范围；不同源列的金字塔描边区域互不重叠。

**规则**：
1. 对每个源列，识别其中从上到下连续的橙(7)像素序列（共 K 个），以及紧接其下方的标记像素颜色 C。令 n = sqrt(K)（K 保证为完全平方数）。
2. 清除该列的橙色像素和标记像素。
3. 在同列底部重建居中金字塔：以网格最后一行为底，从底往上依次放置宽度为 2n-1, 2n-3, ..., 3, 1 的水平行。每行以源列为中心左右对称，颜色为橙(7)。
4. 确定描边颜色映射：红(2) → 蓝(1)，绿(3) → 品红(6)，青(8) → 黄(4)。根据标记颜色 C 得到描边色 D。
5. 为该金字塔描外轮廓：扫描金字塔中每个橙(7)像素的 4-邻域（上、下、左、右），若邻域像素为黑(0)背景，则将该背景像素涂为描边色 D。仅涂背景像素，不修改金字塔本体或网格边界外的位置。
6. 所有源列处理完毕后输出。处理顺序为源列从左到右。

**关键洞察**：标记像素在空间上被金字塔底行覆盖而消失——它在输出中不可见，但它的颜色信息已被消费用于决定描边色。求解者必须注意到输入中的标记与输出中的轮廓颜色之间的对应关系，而这个对应需要对比多个源列（尤其是不同标记色的源列）才能归纳出颜色映射表。

## 新题 7：模式匹配条件分支的精细替换

**组合逻辑**：[模式匹配 + 原型](识别目标宏单元) ⊗ [粗模板精细替换 + 控制精灵体](执行替换) ← [匹配/不匹配 → 选择不同精灵体](条件分支)

**来源原语**：
- 模式匹配、符号槽位、原型、匹配槽位重涂 ← d94c3b52
- 粗模板精细替换、控制精灵体、宏单元格模式 ← 5833af48
- 印章覆盖 ← b4a43f3b/c3e719e8

**依赖链**：宏单元网格中每个单元先与原型做模式匹配，匹配结果决定该单元在精细输出中被替换为哪个精灵体图案——匹配单元用精灵体 A 替换，不匹配单元用精灵体 B 替换。删掉模式匹配则无法区分宏单元；删掉精细替换则匹配结果无法映射到输出。

将宏单元网格中与原型匹配的单元替换为精灵体 A 的精细图案，不匹配的替换为精灵体 B。

**输入结构**：约 22x22 的网格，背景为黑(0)。网格左侧有两个 3x3 精灵体，垂直排列间隔 2 行，均位于网格左边缘起始列：精灵体 A 由红(2)和蓝(1)像素组成的非对称图案（如 L 形或不规则分布，3~6 个非黑像素），精灵体 B 由绿(3)和黄(4)像素组成的不同非对称图案。网格右侧有一个由灰(5)单像素分隔线划分的宏单元网格：网格为 3x3 或 4x4 个单元格，每个单元格为 2x2 像素，分隔线将它们隔开（含外边框分隔线）。每个单元格内有 2x2 的单色图案。其中一个单元格的全部 4 像素为青(8)色，标记为原型。生成约束：恰好有 2~4 个非原型单元格的 2x2 图案与原型完全相同（全青）；其余单元格为其他颜色的 2x2 图案（如全红、全橙等，各不相同且都非全青）；精灵体 A 和 B 的非黑像素掩码（哪些位置有非黑像素）不同。

**规则**：
1. 识别宏单元网格中的原型单元格：全部 2x2 像素为青(8)的那个。
2. 扫描所有单元格，将 2x2 图案与原型逐像素比较。全部 4 像素颜色匹配则为"匹配单元"，否则为"不匹配单元"。原型单元格本身算匹配。
3. 读取左侧精灵体 A（上方的 3x3）和精灵体 B（下方的 3x3）。
4. 构造输出网格：若宏单元网格为 MxN 个单元格，则输出大小为 (M*3) x (N*3)，全部填充黑(0)。输出视为 MxN 的宏格，每宏格 3x3。
5. 对每个匹配单元格 (i, j)：将精灵体 A 逐像素复制到输出宏格 (i, j) 对应的 3x3 区域。
6. 对每个不匹配单元格 (i, j)：将精灵体 B 逐像素复制到输出宏格 (i, j) 对应的 3x3 区域。

**关键洞察**：模式匹配的结果不是像参考题那样直接重涂颜色，而是选择不同的精细替换图案——匹配关系从"颜色标记"转移到了"图案选择"。需要对比多个示例才能确认：(a) 匹配条件是完全颜色一致而非形状相似；(b) 哪个精灵体对应匹配、哪个对应不匹配。

## 新题 8：对角偏移复制涌现对齐与标记连线

**组合逻辑**：[对角线偏移复制 + 画布加倍](生成多副本) → [同行列对齐检测 + 相邻标记间填充](涌现对齐的连线)

**来源原语**：
- 对角线偏移复制、画布加倍、前景图案 ← d13f3404
- 同行列对齐、相邻标记间填充、标记像素、线段 ← dbc1a6ce
- 连线 ← dbc1a6ce/bf89d739

**依赖链**：对角偏移复制在加倍画布上产生前景像素的多个对角副本，其中特定颜色的"标记"像素在不同副本之间涌现出同行或同列的对齐关系（输入中不存在这种对齐）。连线操作利用这些涌现的对齐关系在标记间画线段。删掉对角复制则标记不存在于加倍画布上；删掉连线则各副本之间无交互。

将前景图案沿对角线偏移复制到加倍画布上，然后在不同副本的同行同列标记像素之间画连线。

**输入结构**：约 8x8 的网格，背景为黑(0)。前景由两种颜色组成：红(2)像素为"标记像素"（2~3 个），蓝(1)像素为"结构像素"（3~5 个）。所有前景像素组成一个稀疏图案（不要求连通）。生成约束：红色标记像素在图案中互不同行互不同列；标记像素位置经过安排，使得对角偏移复制后，来自不同偏移量 k 的红色标记副本中恰好有若干对（至少 2 对）落在同行或同列上；蓝色像素的对角副本不会恰好对齐（避免蓝色连线干扰）。

**规则**：
1. 创建输出画布：高 = 2 * 输入高度，宽 = 2 * 输入宽度，填充黑(0)。
2. 对输入中每个前景像素 (r, c, color)：遍历 k = 0, 1, 2, ...，将该颜色涂到输出位置 (r+k, c+k)，直到 (r+k, c+k) 超出输出画布范围。若多条对角线在同一输出位置重叠，颜色一致（由生成约束保证）。
3. 对角复制完成后，在输出画布上识别所有红(2)像素。
4. 对每一行：将该行中的红色像素按列坐标排序。对每对相邻红色像素之间的所有黑(0)背景像素，涂绿(3)。已有非黑像素（蓝色结构像素等）保持不变，不被覆盖。
5. 对每一列：将该列中的红色像素按行坐标排序。对每对相邻红色像素之间的所有黑(0)背景像素，涂绿(3)。已有非黑像素保持不变。
6. 红(2)和蓝(1)像素保持原色不变。

**关键洞察**：输入中孤立的红色标记在对角复制后产生了同行/同列的对齐关系——这种对齐在原始 8x8 输入中不存在，是偏移复制的几何副产品。连线操作利用的正是这个涌现的空间关系，两步操作在"副本间对齐"这个涌现属性上紧密耦合。
