## 新题 1：投射碰撞与距离优先涂色

**组合逻辑**：[投射](已有) + [碰撞阻挡](已有) → [重涂色·距离优先](创新：将碰撞阻挡从"射线遇障停止"改造为"多投射碰撞时距离近者优先涂色")

**来源原语**：投射(1f642eb9)、碰撞阻挡(1f642eb9)、边界像素投射目标(1f642eb9)、目标对象(1f642eb9)、标记像素(1f642eb9)、重涂色(bda2d7a6 等)、射线遇障停止(6ffe8f07)

**依赖链**：边界标记投射方向由位置决定 → 多条投射路径可能命中目标对象的同一像素 → 碰撞解决依赖行进距离（短优先） → 目标对象表面被分区涂色

将画布四边的彩色标记沿行或列投射到中央目标对象表面，碰撞时距离近的标记优先涂色，形成类似 Voronoi 的分区。

**输入结构**：
- 约 15x15 黑(0)背景网格。
- 中央偏中位置有一个灰(5)目标对象，由 8~15 个 4-连通灰像素组成的不规则单色连通域（非矩形，不同示例形状不同）。
- 网格四条边各分布 2~4 个单像素彩色标记（颜色从红(2)、绿(3)、黄(4)、蓝(1)、橙(7)中选取，每个标记颜色可重复也可不同）。
- 每个标记恰好与目标对象的某个像素在同一行或同一列（即其投射路径能到达目标）。
- 生成约束：不存在恰好与目标等距的两个标记同时命中同一目标像素（即不存在距离平局）。

**规则**：
1. 对每个边界标记，沿其所在行（若在左/右边界）或列（若在上/下边界）向网格内部投射，直到命中目标对象的第一个灰像素为止。记录该命中像素坐标和行进距离（标记到该像素的曼哈顿距离）。
2. 若目标对象的某个像素仅被一个标记命中，则该像素涂为该标记的颜色。
3. 若同一目标像素被多个标记命中（来自不同方向），取行进距离最短的标记为赢家，该像素涂赢家的颜色。
4. 目标对象中未被任何投射命中的像素保留灰(5)。
5. 边界标记本身在输出中保留，背景保持黑(0)。

**关键洞察**：多标记共同争夺同一目标像素时，不是简单的方向优先或颜色优先，而是物理距离决定涂色权——相当于在目标表面做了一次距离驱动的区域划分。需要对比多个示例才能排除"方向优先"或"先到先得扫描序"等替代假设。

## 新题 2：引导条间隙过滤与幸存配对连线

**组合逻辑**：[压缩·投射到引导条](已有) + [擦除·投射落间隙则擦](已有) → [连线·同色配对填充](创新：将"同色配对连线"的对象从分隔栅格中的标记改为经引导条过滤后的幸存像素)

**来源原语**：引导条(f83cb3f6)、散布像素(f83cb3f6)、投射到引导条(f83cb3f6)、投射落间隙则擦(f83cb3f6)、同色配对(06df4c85)、沿行列填充间隙(06df4c85)、连线(06df4c85)

**依赖链**：散布像素投射到引导条旁 → 引导条间隙决定哪些像素被擦除 → 幸存的同色像素对决定连线图案

将散布在引导条上方的彩色像素向下投射到紧邻引导条的位置，落在间隙列的像素被擦除，幸存的同色像素对沿该行彼此连线。

**输入结构**：
- 约 14x14 黑(0)背景网格。
- 一条水平灰(5)引导条位于网格中部（如第 7 行），厚度 1 像素，跨越多列但有 2~3 个单像素宽的间隙（间隙处为黑色）。
- 引导条上方（第 0 行到引导条上方）散布 8~12 个单像素彩色标记，每种非背景、非灰颜色恰好出现 2 次（即构成配对），颜色从红(2)、绿(3)、蓝(1)、黄(4)、橙(7)中选取，共 4~6 对。
- 每对同色像素位于不同列。
- 引导条下方无标记。
- 生成约束：至少有一对的两个像素中恰好一个位于间隙列（使该对只剩一个幸存者，无法连线），至少有一对的两个像素都不在间隙列（可以连线），至少有一对的两个像素都在间隙列（被完全擦除）。

**规则**：
1. 每个彩色标记沿其所在列垂直向下投射，落在紧邻引导条上方的那一行（即引导条行号减 1 的那行），列号不变。
2. 若该标记所在列对应引导条的间隙位置（该列引导条行为黑色），则该标记被擦除（不出现在输出中）。
3. 投射并过滤后，对幸存标记按颜色配对。若某颜色仍有两个幸存标记，则沿它们所在行（引导条上方一行）将两者之间的所有黑色像素填充为该颜色，形成一条水平连线（两端标记保留）。
4. 若某颜色仅剩一个幸存标记（配对的另一个被间隙擦除），则该标记保留在投射位置但不连线。
5. 引导条本身保留在输出中，其余区域为黑(0)背景。

**关键洞察**：引导条同时承担两个角色——投射目标和过滤器。间隙不仅擦除像素，还间接决定了哪些颜色对能够连线。需要对比多个示例才能确认"只有两个都幸存的同色对才连线"这一规则（而非"任何幸存标记都向最近同色连线"等替代假设）。

## 新题 3：极角排序驱动的逐步消除路径

**组合逻辑**：[极角排序](已有) → [逐步移动+消除](已有，但触发条件从"朝向决定搜索线"创新为"极角序决定下一目标") → [重涂色](已有)

**来源原语**：极角排序(35ab12c3)、逐步移动(5545f144)、消除(5545f144)、标记像素(5545f144)、重涂色(多源)

**依赖链**：灰锚点定义极角中心 → 极角排序确定标记消除顺序 → 精灵体按该顺序逐步移动并吸收各标记颜色 → 最终位置与颜色由全过程决定

一个小精灵体按照各标记相对于灰锚点的极角顺序，逐个移动并吞噬标记，每次吞噬后精灵体变为该标记的颜色，最终输出精灵体的末态。

**输入结构**：
- 约 13x13 黑(0)背景网格。
- 一个灰(5)锚点像素（单像素），位置不固定但不在网格边缘。
- 一个红(2)小精灵体：由 3~5 个 4-连通像素组成的单色不规则连通域，位于网格中某处。
- 4~6 个单像素彩色标记，每个颜色不同（从蓝(1)、绿(3)、黄(4)、橙(7)、品红(6)、栗(9)中选取），散布于网格各处。
- 生成约束：以灰锚点为原点、正上方为 0 度顺时针测量，所有标记的极角两两不同（无角度平局）。精灵体的初始位置不与任何标记重叠。

**规则**：
1. 以灰(5)锚点为中心，将正上方定义为 0 度，顺时针方向为角度增加方向，计算每个标记像素相对于锚点的极角。
2. 将所有标记按极角从小到大排序，得到消除序列。
3. 精灵体从初始位置出发，依次向序列中的第一个标记移动：将精灵体整体平移，使精灵体的质心（各像素坐标的算术平均，四舍五入取整）对齐到该标记位置。
4. 到达后，该标记被消除（从网格移除），精灵体所有像素重涂为该标记的颜色。
5. 继续向序列中下一个标记移动，重复步骤 3-4，直到所有标记被消除。
6. 输出：黑(0)背景上仅保留灰锚点和精灵体的最终位置及最终颜色。

**关键洞察**：消除顺序不由精灵体的朝向或与标记的距离决定，而由标记相对于锚点的极角决定——锚点是理解消除顺序的关键参照物。需要多个示例来区分"极角排序"和"距离排序""输入行优先扫描序"等竞争假设。

## 新题 4：射线碰撞框架后按腔室数涂色

**组合逻辑**：[射线延伸](已有) + [射线遇障停止](已有，障碍从"特定色"创新为"空心框架边界") → [计数·腔室数](创新：从"连通孔洞数作为匹配键"改造为"腔室数决定射线颜色") → [重涂色](已有)

**来源原语**：射线延伸(6ffe8f07)、实心矩形(6ffe8f07)、射线遇障停止(6ffe8f07)、十字投影(6ffe8f07)、空心框架(8698868d)、孔洞(8698868d)、连通孔洞数为键(8698868d)、计数(794b24be)、重涂色(多源)

**依赖链**：实心矩形发射十字射线 → 射线遇空心框架外边界停止 → 被命中框架的内部腔室数决定射线段的涂色

从中央实心矩形向四方发射射线，射线遇空心框架停止，根据被命中框架内部的腔室数量给射线段涂上不同颜色。

**输入结构**：
- 约 18x18 黑(0)背景网格。
- 中央有一个青(8)实心矩形（约 3x3 到 4x4）。
- 围绕矩形分布 4~6 个空心框架，每个框架是一种非黑、非青颜色的 1 像素厚矩形外边框（如蓝(1)、绿(3)、橙(7)等），内部为黑色。
- 部分框架内部有与框架同色的水平或垂直内墙（1 像素厚），将框架内部空间分隔为多个 4-连通黑色区域（称为"腔室"）。一个无内墙的简单空心框架有 1 个腔室；有 1 道内墙的框架有 2 个腔室；有 2 道内墙的框架有 3 个腔室。
- 各框架的腔室数覆盖 1、2、3 中的至少两种。
- 生成约束：青矩形的每一行和每一列向外的射线至少命中一个框架。不同框架之间不重叠、不相邻。

**规则**：
1. 从青(8)矩形的每一行向左和向右发射水平射线，从每一列向上和向下发射垂直射线。
2. 每条射线沿途遇到某个空心框架的外边界像素时停止（不含该边界像素本身）。射线经过的所有黑色像素将被涂色。
3. 对每条射线命中的框架，计算该框架的腔室数（框架内部 4-连通黑色区域的个数）。
4. 根据腔室数涂色：腔室数为 1 → 射线段涂红(2)；腔室数为 2 → 射线段涂黄(4)；腔室数为 3 → 射线段涂品红(6)。
5. 青矩形保持不变，所有框架保持原色不变。未被射线覆盖的黑色像素保持黑(0)。

**关键洞察**：射线的颜色不由射线的方向、长度或框架的边框颜色决定，而由其终点处框架的内部拓扑结构（腔室数）决定。这要求求解者先理解射线机制，再识别框架内部分隔结构与射线颜色之间的映射关系。单个示例可能不足以区分"腔室数决定色"与"框架原色决定射线色"等替代假设。

## 新题 5：种子平铺后边界色匹配溶解分隔线

**组合逻辑**：[平铺·保持种子相位](已有) → [同色配对](创新：从"分隔栅格中标记配对"改造为"平铺结果中跨分隔线的像素配对") → [填充·溶解分隔](创新：配对成功则擦除分隔像素)

**来源原语**：平铺(a57f2f04)、种子图案(a57f2f04)、矩形空腔(a57f2f04)、保持种子相位(a57f2f04)、墙壁(a57f2f04)、分隔栅格(06df4c85)、同色配对(06df4c85)、填充(06df4c85)

**依赖链**：每个空腔的种子图案决定平铺结果 → 平铺结果在分隔线两侧产生特定颜色 → 分隔线两侧颜色是否匹配决定该分隔像素是否溶解

先将每个矩形空腔用其种子图案平铺填满，然后检查相邻空腔在共享分隔线两侧的颜色——匹配处分隔线像素被替换为该颜色，不匹配处保留。

**输入结构**：
- 约 15x15 网格。
- 红(2)分隔线（1 像素厚的水平和垂直完整条）将网格分为 4~6 个矩形空腔。
- 每个空腔的背景为黑(0)，其中包含一个小的种子图案（2~4 个像素，由一种非红非黑颜色组成，如蓝(1)、绿(3)、黄(4)、橙(7)等），种子在空腔内的位置决定平铺相位。
- 不同空腔的种子颜色可以相同也可以不同。
- 生成约束：平铺后，至少有一对相邻空腔在共享分隔线的某些位置颜色匹配（产生溶解），至少有一对不匹配（分隔线保留）。

**规则**：
1. 对每个空腔，取其种子图案像素的边界框作为平铺单元。以种子当前位置为相位基准，将该单元周期性地铺满整个空腔。单元周期覆盖的位置若对应种子色像素则涂种子色，否则保持黑(0)。
2. 平铺完成后，检查每个红色分隔线像素（不含分隔线交叉点，即同时属于水平和垂直分隔线的像素）。
3. 对于水平分隔线上的非交叉像素：查看其正上方和正下方的像素。若两者颜色相同且均非黑(0)，则该分隔线像素替换为该匹配颜色（溶解）；否则保持红(2)。
4. 对于垂直分隔线上的非交叉像素：查看其正左方和正右方的像素。若两者颜色相同且均非黑(0)，则该分隔线像素替换为该匹配颜色（溶解）；否则保持红(2)。
5. 分隔线交叉点（水平与垂直分隔线的公共像素）始终保持红(2)。

**关键洞察**：分隔线的命运由平铺结果决定——同一个种子图案在不同空腔中因相位和空腔尺寸不同而产生不同的边界像素序列。求解者必须先完成平铺（需理解周期性和相位），再判断边界匹配（需同时考虑两侧空腔的平铺结果）。连通性从平铺中涌现，而非预设。

## 新题 6：角标记扩展为字形后同色配对虚线连接

**组合逻辑**：[放置·角标记扩展为环绕字形](已有) + [同色配对·轴对齐](创新：从分隔栅格的格子配对改为字形中心配对) + [连线·奇偶虚线](已有) → [碰撞阻挡·交叉优先](创新：水平线优先规则)

**来源原语**：角标记像素(f35d900a)、环绕字形(f35d900a)、奇偶决定虚线(f35d900a)、同色配对(06df4c85)、轴对齐(06df4c85)、沿行列填充间隙(06df4c85)、碰撞阻挡(1f642eb9)

**依赖链**：角标记扩展为 3x3 字形 → 同色字形对确定连线端点 → 端点间绘制奇偶虚线 → 线段交叉时适用覆盖优先规则

每个彩色像素扩展为 3x3 字形（中心保持原色、外圈灰色），然后同色字形对之间用奇偶虚线连接，交叉处水平线优先。

**输入结构**：
- 约 17x17 黑(0)背景网格。
- 6~10 个单像素彩色标记，每种颜色恰好出现 2 次（3~5 对）。颜色从蓝(1)、绿(3)、黄(4)、橙(7)、品红(6)中选取。
- 每对同色标记要么同行（水平对齐）要么同列（垂直对齐），不存在既不同行也不同列的配对。
- 标记之间间距至少 5 个像素（保证字形扩展后不重叠且连线有足够空间）。
- 生成约束：至少存在一处两条连线（一水平一垂直）交叉。

**规则**：
1. 每个标记像素扩展为 3x3 字形：中心像素保持标记原色，周围 8 个像素涂灰(5)。
2. 对每对同色标记（它们的字形中心同行或同列），在两个字形之间画一条连线。连线沿两个中心之间的直线方向（水平或垂直）绘制，仅覆盖两个字形灰色边缘之间的空白间隔区域（不覆盖字形本身）。
3. 连线使用奇偶虚线模式：从靠近第一个字形的一端开始计数（距离 = 0，即紧邻字形灰色边缘的第一个像素），距离为偶数的像素涂该对的颜色，距离为奇数的像素保持黑(0)。
4. 若一条水平连线和一条垂直连线在某像素交叉：该像素涂水平连线的颜色（水平优先）。
5. 字形的灰(5)像素不受连线影响，始终保持灰色。

**关键洞察**：字形扩展不仅是装饰——灰色边缘定义了虚线的起始参考点，从而决定奇偶相位。交叉优先规则需要至少两个包含交叉的示例才能确认是"水平优先"而非"后绘制优先"或"特定颜色优先"等替代规则。

## 新题 7：像素计数匹配选择模板后像素放大印章

**组合逻辑**：[计数](已有) + [面积比较·匹配](创新：从"极值区域涂色"改为"计数相等作为匹配选择键") → [像素放大·印章覆盖](已有，但模板由匹配结果动态选择)

**来源原语**：计数(794b24be)、像素数转计数图(794b24be)、面积比较(6455b5f5)、像素放大(007bbfb7)、自身为模板(007bbfb7)、印章覆盖(007bbfb7)、非背景处印章(007bbfb7)、精灵体(007bbfb7)

**依赖链**：左区多个候选模板各有不同像素数 → 右区印章精灵体的像素数作为选择键 → 匹配的模板被选出作为印章放大的空间布局 → 模板的非背景位置放置印章副本

通过像素计数匹配从多个候选模板中选出与右侧印章精灵体像素数相同的那个，然后用该模板作为空间布局模板、右侧精灵体作为印章进行像素放大。

**输入结构**：
- 约 20x10 网格（宽大于高），或等效尺寸。
- 一条垂直灰(5)分隔线将网格分为左区和右区。
- 左区包含 3~4 个互不接触的小型单色精灵体（4-连通连通域），每个颜色不同（如红(2)、蓝(1)、绿(3)），像素数各不相同（如分别为 3、4、5、6 个像素）。这些是候选模板。
- 右区包含 1 个单色精灵体（4-连通连通域，颜色为黄(4)），作为印章。其像素数与左区某个候选模板的像素数相同。
- 生成约束：右区精灵体的像素数恰好与左区某一个候选模板的像素数相等，与其余候选模板都不等。

**规则**：
1. 分别计算左区每个候选模板的前景像素数和右区印章精灵体的前景像素数。
2. 在左区中找到像素数与右区印章相等的那个候选模板（该模板被选中）。
3. 以选中模板的边界框为单位构建输出网格：输出高度 = 模板边界框高度 x 印章边界框高度；输出宽度 = 模板边界框宽度 x 印章边界框宽度。
4. 将输出划分为与印章边界框等大的块，每块对应模板边界框中的一个像素位置。
5. 模板边界框中的非背景像素位置 → 对应输出块填入印章精灵体的完整副本（保持印章原色）。模板边界框中的背景像素位置 → 对应输出块全部为黑(0)。
6. 输出中不包含灰分隔线、左区其他模板和右区原始印章。

**关键洞察**：必须通过像素计数匹配来确定使用哪个模板——模板的几何形状直接决定输出的块布局。单看一个示例可能无法确认选择机制是"像素数匹配"还是"颜色位置匹配"或"边界框大小匹配"，需要多个示例排除替代假设。

## 新题 8：空行列分隔检测与较小半区旋转合并

**组合逻辑**：[全空行列检测](已有) → [面积比较](已有) → [旋转·半周](创新：从整体旋转改造为仅对较小半区做 180 度旋转后与较大半区合并)

**来源原语**：全空行列检测(da2b0fe3)、包围框内部(da2b0fe3)、分隔行列(da2b0fe3)、面积比较(6455b5f5)、旋转(ed36ccf7)、整体半周旋转(3c9b0459)

**依赖链**：检测前景包围框内的全空行或列 → 该行列将前景分为两个半区 → 比较两半区的非背景像素数 → 像素数较少的半区做 180 度旋转 → 旋转结果与另一半区合并，分隔行列移除

找到前景图案包围框内唯一的全空行或列，将图案分为两半，对像素数较少的那半做 180 度旋转后与另一半拼合，移除分隔行列。

**输入结构**：
- 约 11x11 黑(0)背景网格。
- 一个多色前景图案占据网格中部区域。前景由 2~3 种非背景颜色（如红(2)、蓝(1)、绿(3)）组成的像素构成，不要求连通。
- 前景图案的最小包围框内部恰好有一条完全为黑的行或列（即分隔行或分隔列），将前景分为两个半区。
- 两个半区的非背景像素数不相等。
- 生成约束：较小半区做 180 度旋转后，其包围框尺寸不超过原位置范围（确保旋转后不越界）。分隔行列的方向在不同示例中不同（有时是行，有时是列）。

**规则**：
1. 找到所有非背景像素的最小包围框。
2. 在该包围框内部，定位唯一的全空行（包围框内该行所有像素均为背景色）或全空列（包围框内该列所有像素均为背景色）。
3. 该空行或列将包围框内的前景分为两个半区（上/下或左/右）。
4. 计算每个半区的非背景像素数。像素数较少的半区为"旋转半区"。
5. 对旋转半区执行 180 度旋转：以该半区自身包围框的中心为旋转原点，将半区内所有非背景像素映射到关于该中心的对称位置。
6. 输出：在黑(0)背景上，将未旋转的较大半区保持原位，旋转后的较小半区放置在其旋转后的位置。分隔行或列被移除（输出在分隔方向上缩小 1 行或 1 列，两半区紧邻拼合）。

**关键洞察**：哪一半被旋转由像素数决定，而非固定的空间位置（不是"上半总旋转"或"左半总旋转"）。求解者需要多个示例来确认选择标准是像素数而非位置、面积或颜色。分隔线的方向（行或列）在不同示例间切换，进一步增加了归纳难度。
