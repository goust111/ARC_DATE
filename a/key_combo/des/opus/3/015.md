## 新题 1：对角射线穿越分区变色

**组合逻辑**：[射线延伸/ray_extend + 对角方向/diagonal_dir](来自 623ea044) + [等分网格/equal_partition + 分隔线/separator_line](来自 c3202e5a) + [重涂色/recolor](创新：射线颜色随穿越分区而改变，源题中射线保持种子色不变)

**来源原语**：射线延伸、对角方向、孤立像素（623ea044）；等分网格、分隔线、网格单元（c3202e5a）；重涂色（多题共有）

**依赖链**：分区结构赋予每个单元格一个背景色身份 → 射线从种子出发沿四对角线延伸 → 射线每进入一个新单元格时，颜色切换为该单元格的背景色 → 种子位置决定了射线穿越哪些单元格，从而决定了射线的分段颜色序列。分区与射线缺一不可：去掉分区则射线无法变色；去掉射线则分区只是静态色块。

根据种子像素的位置，沿四条对角线射出射线，射线每穿越一个分区单元格就变为该单元格的背景色，形成分段变色的对角线。

**输入结构**：约 15x15 的网格。灰(5)分隔线将网格分为 3x3 共 9 个等大正方形单元格（每格约 4x4，不含分隔线）。每个单元格内部有一个均匀的纯色背景填充（从蓝(1)、红(2)、绿(3)、黄(4)、品红(6)、橙(7)中选取，各单元格颜色可不同，但至少有 3 种不同颜色），背景填充之上无其他像素。其中恰好一个单元格的背景为黑(0)，该单元格正中央有一个青(8)孤立种子像素。生成约束：种子像素不位于分隔线上；9 个单元格的背景色中至少出现 3 种不同颜色。

**规则**：
1. 从种子像素出发，沿四个对角方向（左上、右上、左下、右下）逐像素延伸射线，直至到达画布边界。
2. 射线穿越分隔线时直接跳过分隔线像素（分隔线像素不被射线覆盖，保持灰(5)不变）。
3. 射线在某个单元格内部的所有像素，颜色为该单元格的原始背景色（即射线"吸收"所在单元格的颜色）。
4. 射线在种子所在单元格（黑(0)背景）内的部分，颜色为种子色青(8)。
5. 种子像素本身保持青(8)不变。
6. 所有非射线、非分隔线、非种子的像素保持原样（即单元格背景色不变）。

**关键洞察**：种子在 3x3 单元格阵列中的位置决定了每条对角线穿过哪些单元格，而这些单元格的背景色直接控制射线的分段着色。必须同时理解分区的空间色彩布局和对角线的几何路径，才能确定输出。

## 新题 2：光晕障碍场偏转流动路径

**组合逻辑**：[膨胀/dilation + 光晕/halo](来自 4258a5f9) + [流动绘制/flow_draw + 逐步偏移/step_deflection](来自 f15e1fac，创新：偏移触发条件从"与边缘像素行列对齐"改为"遭遇光晕障碍") + [仅填背景格/only_bg_filled](来自 f0df5ff0)

**来源原语**：膨胀、光晕、标记像素、标记保留原色（4258a5f9）；流动绘制、逐步偏移、边缘起点像素（f15e1fac）；仅填背景格（f0df5ff0）

**依赖链**：标记像素膨胀生成光晕 → 光晕占据网格空间形成障碍 → 流动路径从顶部边缘向下行进 → 路径遇到光晕像素时发生水平偏移绕行 → 最终流动轨迹的形状由光晕的空间分布决定。删除膨胀步骤则无障碍可偏转；删除流动步骤则光晕只是静态图案。

顶部边缘的青(8)像素向下流动，途中遇到由灰(5)标记膨胀生成的蓝(1)光晕时自动偏转绕行，形成弯曲的流动轨迹。

**输入结构**：约 12x12 的黑(0)背景网格。顶部边缘（第 0 行）有 2~4 个青(8)像素作为流动源，它们互不相邻（列间距至少为 3）。网格内部散布 2~4 个灰(5)标记像素，标记像素不在第 0 行或最后一行，彼此之间的曼哈顿距离至少为 5（确保光晕互不重叠）。生成约束：每个流动源的正下方路径上至少经过一个标记像素的光晕范围；标记像素的 3x3 邻域不超出网格边界。

**规则**：
1. 对每个灰(5)标记像素，将其 3x3 邻域中的所有黑(0)像素涂为蓝(1)。灰(5)标记像素本身保持灰(5)不变。
2. 从每个青(8)源像素出发，逐行向下移动（初始列为源像素所在列）。
3. 移动到下一行时，检查目标位置（当前列，下一行）：
   - 若为黑(0)（背景），正常进入，涂为青(8)。
   - 若为蓝(1)或灰(5)（光晕或标记），则水平偏移：检查该光晕所属标记像素的列位置；若流动路径当前列在标记列的左侧或正对标记列，则向右偏移一列；若在标记列的右侧，则向左偏移一列。偏移后若目标位置仍为非背景像素或超出网格边界，则该流动路径终止。
4. 流动路径到达最后一行或终止前，持续向下推进。
5. 流动路径只涂染黑(0)背景像素，不覆盖任何已有的蓝(1)或灰(5)像素。

**关键洞察**：光晕的空间布局构成一个隐式的偏转力场——偏转方向取决于流动路径相对于光晕中心（标记像素）的左右位置，而非固定方向。同一个光晕可以将不同路径分别偏向两侧，产生分流效应。

## 新题 3：控制点计数决定膨胀半径与叠层优先级

**组合逻辑**：[计数/counting + 内嵌标记计数/embedded_marker_count](来自 52fd389e) + [膨胀/dilation + 邻域扩展/neighborhood_expand](来自 4258a5f9，创新：膨胀半径可变，由计数决定) + [冲突优先级/conflict_priority](来自 9344f635，创新：优先级由计数反向编码而非朝向)

**来源原语**：计数、控制像素、计数决定扩展量（52fd389e）；膨胀、邻域扩展、光晕（4258a5f9）；冲突优先级（9344f635）；擦除（952a094c）

**依赖链**：计数控制点 → 确定膨胀半径 → 膨胀生成不同大小的色块 → 色块可能重叠 → 重叠区域的颜色由计数反向决定的优先级裁定。计数同时编码了两个参数（半径和优先级），删除计数步骤则既无法确定膨胀大小也无法解决冲突。

每个彩色核心像素周围的红(2)控制点数量同时决定膨胀半径和叠层优先级：控制点越少，膨胀越小但优先级越高，在重叠区域胜出。

**输入结构**：约 14x14 的黑(0)背景网格。网格中有 3~4 个"核心组"，每组包含：一个彩色核心像素（从蓝(1)、绿(3)、黄(4)、品红(6)中选取，各组颜色不同）和紧邻核心像素（8-连通邻域内）的若干红(2)控制点。不同核心组的控制点数量互不相同，分别为 1、2、3（若有第 4 组则为 4）。各核心组之间的距离足够近以使膨胀后的区域有重叠（核心像素间距约 4~6 格），但控制点本身不与其他核心组的控制点或核心像素相邻。生成约束：每组的控制点严格位于其核心像素的 8-连通邻域内（即 3x3 范围内的非核心位置）。

**规则**：
1. 对每个核心组，计数其红(2)控制点数量 k。
2. 以核心像素为中心，向四个方向各扩展 k 个像素，形成一个边长为 (2k+1) 的正方形区域，将该区域内所有像素涂为核心像素的颜色。扩展区域超出网格边界的部分裁剪丢弃。
3. 若多个膨胀区域重叠，按控制点数量从少到多的顺序确定优先级——控制点最少的核心组颜色覆盖控制点多的核心组颜色（即小膨胀覆盖大膨胀）。实际绘制顺序：先绘制控制点最多（k 最大）的核心组，最后绘制控制点最少（k 最小）的核心组，从而保证小膨胀在最上层。
4. 绘制完成后，将所有红(2)控制点擦除为黑(0)（即控制点不出现在输出中）。
5. 核心像素本身保持其原色不变（即使被更大膨胀覆盖，核心像素仍显示自身颜色）。

**关键洞察**：控制点数量是一个双重编码——它既决定膨胀的空间范围，又反向决定叠层优先级。膨胀最小的核心反而在重叠区胜出，形成"小而强"的反直觉规律。求解者必须同时推断计数-半径映射和计数-优先级映射，两者共用同一个参数但效果相反。

## 新题 4：周期十字延伸遇框架终止并采样填色

**组合逻辑**：[平铺/tile + 周期序列/periodic_sequence + 周期性延伸/periodic_extension](来自 e21d9049) + [空心矩形/rectangular_frame](来自 952a094c，创新：框架从角标记载体变为射线终止器和颜色采样容器) + [洪泛填充/flood_fill](来自 83302e8f，创新：填充色不由连通区域完整性决定，而由周期序列在该位置的采样值决定)

**来源原语**：平铺、十字图案、周期序列、中心行列种子、周期性延伸（e21d9049）；空心矩形（952a094c）；洪泛填充（83302e8f）

**依赖链**：十字图案的中心行/列提供周期色序列 → 序列向四方延伸 → 延伸射线遇到框架边缘时停止 → 框架内部用射线在框架中心位置的周期采样色进行洪泛填充 → 框架的位置决定了采样到周期序列的哪个颜色。去掉十字则无序列可延伸；去掉框架则延伸到边界无填充效果；去掉填充则框架内部为空。

多色十字图案的中心行和中心列向外周期延伸，延伸到达矩形框架边缘时停止；框架内部用延伸射线在框架几何中心处的周期采样颜色洪泛填充。

**输入结构**：约 17x17 的黑(0)背景网格。中心区域有一个多色十字图案（约 5x5 裁剪框，中心行和中心列各含 5 个不同颜色的像素，颜色从蓝(1)、红(2)、绿(3)、黄(4)、橙(7)中选取）。网格中另有 2~3 个灰(5)像素构成的单像素宽空心矩形框架，框架内部为黑(0)，框架尺寸各异（内部约 3x3 到 5x5），分布在十字图案的不同方向上（如一个在右上方，一个在左下方）。框架互不重叠，且不与十字图案重叠。生成约束：每个框架的几何中心沿水平或垂直方向与十字中心对齐（即每个框架要么在十字的行延伸线上，要么在列延伸线上，不会在纯对角方向上）。

**规则**：
1. 确定十字图案的中心像素位置，提取中心行的颜色序列 S_row 和中心列的颜色序列 S_col。
2. 从十字中心向左和向右，以 S_row 的长度为周期，重复铺设 S_row 的颜色序列，覆盖对应行上的黑(0)像素。
3. 从十字中心向上和向下，以 S_col 的长度为周期，重复铺设 S_col 的颜色序列，覆盖对应列上的黑(0)像素。
4. 当行延伸或列延伸的下一个像素位置遇到某个框架的边框像素时，该方向的延伸立即停止（不覆盖框架像素）。
5. 对每个框架，计算其内部几何中心位置 (cr, cc)。查询该位置在周期序列中对应的颜色：若框架在十字的行延伸线上，颜色为 S_row[(cc - 十字中心列) mod len(S_row)]；若在列延伸线上，颜色为 S_col[(cr - 十字中心行) mod len(S_col)]。
6. 用步骤 5 确定的颜色洪泛填充该框架内部所有黑(0)像素。
7. 框架边框保持灰(5)不变。十字图案本身保持不变。

**关键洞察**：框架在十字延伸路径上的位置决定了它"截获"的周期颜色值。同一个周期序列在不同距离处被不同框架采样，产生不同的填充色。求解者必须同时理解周期延伸的色彩规律和框架位置的采样效应。

## 新题 5：缺口列位定位模板印章行

**组合逻辑**：[填充/filling + 条缺口/bar_gap + 列对齐/col_align](来自 cf133acc，创新：缺口不再用于纵向填色，而是标定水平印章位置) + [印章覆盖/stamp_overlay + 多色模板/multicolor_template + 尺寸匹配/size_matching](来自 e76a88a6) + [擦除/erase](来自 952a094c)

**来源原语**：条缺口、列对齐、标记（cf133acc）；印章覆盖、多色模板、尺寸匹配（e76a88a6）；擦除（952a094c）

**依赖链**：水平条中的缺口列位置 → 确定印章的水平放置坐标 → 缺口所在行确定印章的垂直放置坐标 → 模板通过尺寸匹配选定 → 模板被印到每个缺口位置 → 原始水平条和缺口被擦除。缺口位置编码了印章坐标这一信息，是两步操作的桥梁。

水平彩色条中的一像素缺口标定了多色模板的印章放置位置；每个缺口处印上尺寸匹配的模板副本，原始条被擦除。

**输入结构**：约 15x20 的黑(0)背景网格。网格上半区有 3~5 条水平彩色条（每条为同一种非黑颜色，从蓝(1)、红(2)、绿(3)、黄(4)中选取，不同条颜色可相同或不同），每条宽 1 像素、横跨大部分列，各条位于不同行且行间距至少为 4。每条水平条恰好有 1 个一像素缺口（该位置为黑(0)）。网格下半区有一个多色模板（一个 3x3 的由多种非黑颜色构成的连通图案，不含黑(0)像素）。模板与水平条不接触。生成约束：所有缺口的列位置互不相同；模板尺寸为 3x3；每个缺口位置周围 3x3 范围内不与其他水平条重叠（即印章放置后不会与其他条冲突）。

**规则**：
1. 识别所有水平条及其缺口位置。每个缺口定义一个锚点 (gap_row, gap_col)。
2. 识别下半区的 3x3 多色模板，裁剪提取。
3. 对每个缺口锚点，将模板副本以锚点为中心放置（模板中心对齐缺口位置），即模板占据 (gap_row-1, gap_col-1) 到 (gap_row+1, gap_col+1) 的 3x3 区域。仅覆盖黑(0)背景像素；若模板某像素落在非背景位置（如另一条水平条上），该像素不被覆盖（保留原有非背景色）。
4. 放置顺序按缺口行从上到下依次处理。
5. 擦除所有原始水平条像素（将其涂为黑(0)），但已被模板覆盖的位置保留模板颜色。
6. 擦除原始模板所在位置（将其涂为黑(0)）。

**关键洞察**：水平条本身不出现在输出中——它们的唯一作用是通过缺口位置编码印章坐标。缺口从"需要填充的空洞"（源题 cf133acc 的语义）被重新解读为"放置目标的定位标记"，与模板印章形成全新的结构关系。

## 新题 6：分区异常值提取后按朝向标记定向平铺

**组合逻辑**：[等分网格/equal_partition + 唯一单色单元/unique_mono_cell + 异常值选择/outlier_selection + 裁剪/crop](来自 c3202e5a) + [朝向决定方向/orientation_determines_direction + 微型标记/micro_marker](来自 9344f635，创新：朝向不再决定行/列条延伸方向，而是决定平铺方向) + [平铺/tile](来自 e21d9049/58c02a16)

**来源原语**：等分网格、唯一单色单元、异常值选择、裁剪（c3202e5a）；朝向决定方向、微型标记（9344f635）；平铺（e21d9049）

**依赖链**：分区 + 异常值检测 → 裁剪出异常值单元格内容 → 该内容成为平铺种子 → 同时从非异常值单元格中寻找 2-像素 domino 标记 → domino 朝向决定其所在单元格内平铺种子的排列方向 → 平铺结果替换该单元格内容。异常值选择提供"铺什么"，朝向标记提供"怎么铺"，二者必须同时成立才能完成输出。

在等分网格中找到唯一单色异常值单元格并提取其图案作为平铺种子；其余单元格中的 domino 标记的朝向决定该单元格内种子图案的平铺方向。

**输入结构**：约 13x13 的网格。橙(7)分隔线将网格分为 3x3 共 9 个等大正方形单元格（每格内部 3x3）。8 个单元格包含多色噪声像素（至少 2 种非黑颜色的前景像素），其中部分单元格（2~4 个）在噪声之外还包含一个由品红(6)构成的 2-像素 domino（水平排列或垂直排列）。恰好 1 个单元格（异常值）的所有非黑前景像素均为同一种颜色（非品红(6)、非橙(7)），且不含 domino。生成约束：含 domino 的单元格中，domino 像素与噪声像素不相邻（8-连通）；异常值单元格的前景像素构成一个有意义的小图案（3~5 个像素的 4-连通形状）；至少有一个水平 domino 和一个垂直 domino。

**规则**：
1. 识别分隔线，将网格拆分为 9 个等大单元格。
2. 找到唯一单色前景的异常值单元格，裁剪其 3x3 内容作为平铺种子 P（保留黑(0)背景和前景色）。
3. 对每个含品红(6) domino 的单元格：
   a. 判断 domino 朝向：水平 domino 表示"水平平铺"，垂直 domino 表示"垂直平铺"。
   b. 水平平铺：将种子 P 沿水平方向铺满该单元格（若单元格宽度是种子宽度的整数倍则恰好铺满，否则裁剪右侧多余部分），垂直方向居中对齐。
   c. 垂直平铺：将种子 P 沿垂直方向铺满该单元格，水平方向居中对齐。
   d. 平铺结果替换该单元格的全部内容（原有噪声和 domino 被覆盖）。
4. 不含 domino 的非异常值单元格保持原样不变。
5. 异常值单元格本身保持原样不变。
6. 分隔线保持橙(7)不变。

**关键洞察**：异常值检测和朝向解读分别提供了平铺操作的两个必要参数——"铺什么"和"往哪铺"。这两个信息分布在不同的单元格中，求解者必须跨单元格关联信息才能完成输出。仅看异常值单元格无法知道怎么铺；仅看 domino 单元格无法知道铺什么。

## 新题 7：尺寸阶梯框架间角标记级联迁移

**组合逻辑**：[平移/translate + 角标记/corner_marker + 内外对角/interior_exterior_diagonal](来自 952a094c，创新：角标记不再在同一框架的内外角之间迁移，而是跨框架按尺寸排序迁移) + [尺寸排序/size_ordering](来自 48634b99) + [擦除/erase](来自 952a094c)

**来源原语**：平移、角标记、内外对角、空心矩形（952a094c）；尺寸排序（48634b99）；擦除（952a094c）

**依赖链**：多个框架 → 按边长排序建立尺寸阶梯 → 找到带角标记的框架 → 该框架角标记的相对位置（左上/右上/左下/右下）被保持 → 标记从当前框架擦除 → 标记出现在尺寸阶梯中下一个更大框架的对应角位置（紧贴外角）。尺寸排序建立了框架间的逻辑邻接关系；角标记位置的保持提供了空间映射规则。两者缺一不可。

多个不同尺寸的矩形框架按边长排序；带角标记的框架将其标记迁移到尺寸阶梯中下一个更大框架的对应外角位置。

**输入结构**：约 18x18 的黑(0)背景网格。网格中有 3~5 个蓝(1)像素构成的单像素宽空心矩形框架，各框架尺寸互不相同（外边长分别为如 3x3、5x5、7x7、9x9 等奇数尺寸），框架之间互不重叠且不相邻。恰好一个框架的四个内角位置（紧贴框架内侧的四个对角像素）有红(2)角标记像素（4 个红像素）。其余框架内部和外部均为黑(0)。生成约束：所有框架均为正方形；框架之间至少间隔 2 个黑像素；带标记的框架不是最大的框架。

**规则**：
1. 识别所有蓝(1)空心矩形框架，计算每个框架的外边长。
2. 按外边长从小到大排序，建立尺寸阶梯序列。
3. 找到带红(2)角标记的框架（源框架），确定其在尺寸阶梯中的位置 i。
4. 找到尺寸阶梯中位置 i+1 的框架（目标框架，即下一个更大的框架）。
5. 将源框架四个内角的红(2)标记擦除为黑(0)。
6. 在目标框架的四个外角位置（紧贴框架外侧的四个对角像素）放置红(2)标记像素。具体位置：目标框架外边界框向外扩展一像素后的四个角点。
7. 所有框架的蓝(1)边框保持不变。

**关键洞察**：框架的空间位置无关紧要——决定标记迁移目标的是尺寸排序而非空间邻近。最小框架的标记可能迁移到空间上距离很远但尺寸恰好大一级的框架。求解者必须先建立尺寸阶梯，再确定迁移方向和目标角位置。

## 新题 8：周期种子生长被印章模板阻断

**组合逻辑**：[射线延伸/ray_extend + 种子周期生长/seed_periodic_growth + 对角偏移/diagonal_offset](来自 3ac3eb23) + [印章覆盖/stamp_overlay + 纯色矩形/solid_rectangle + 同尺寸替换/same_size_replace + 多色模板/multicolor_template](来自 e76a88a6，创新：印章替换先于种子生长执行，替换结果构成生长障碍)

**来源原语**：射线延伸、种子周期生长、对角偏移、孤立像素、轨迹（3ac3eb23）；印章覆盖、多色模板、纯色矩形、同尺寸替换（e76a88a6）

**依赖链**：灰(5)矩形被多色模板替换 → 替换后的模板像素占据网格空间 → 种子像素启动周期对角生长 → 生长轨迹遇到模板像素时该方向终止 → 最终图案取决于模板位置对生长路径的截断效果。模板替换创造了空间障碍；种子生长与障碍的交互产生涌现图案。去掉替换则灰矩形不阻挡生长（因为灰色也是非背景色——但规则是只阻挡非背景像素）；去掉生长则模板只是静态图案。两步操作的输出相互约束。

灰(5)纯色矩形先被多色模板替换形成障碍物；随后种子像素向下周期生长对角轨迹，轨迹遇到模板障碍时终止，形成被截断的稀疏下落图案。

**输入结构**：约 16x16 的黑(0)背景网格。网格上方（第 1~2 行）有 2~3 个孤立彩色种子像素（从蓝(1)、红(2)、绿(3)中选取，颜色互不相同），种子之间列间距至少为 4。网格中部和下部散布 2~3 个灰(5)纯色矩形（每个约 3x3），矩形之间互不重叠。网格中另有一个多色模板（与灰矩形同为 3x3），由多种非黑、非灰颜色构成（如黄(4)、品红(6)、橙(7)的组合），位于网格中不与灰矩形和种子重叠的位置。生成约束：至少一个灰矩形位于某个种子的对角生长路径上（即生长轨迹会与替换后的模板相交）；多色模板不在任何种子的生长路径上。

**规则**：
1. 识别多色模板（唯一一个非纯色的非黑前景矩形区域）和所有灰(5)纯色矩形。
2. 将每个灰(5)纯色矩形替换为多色模板的精确副本（尺寸匹配，直接覆盖）。
3. 擦除原始多色模板所在位置（涂为黑(0)）。
4. 对每个种子像素，从种子位置出发，在 5 个起始偏移（种子本身、左上、右上、左下、右下各偏移 1 格）各启动一条向下的轨迹。
5. 每条轨迹每隔 2 行向下放置一个种子色像素（即在 row, row+2, row+4, ... 处），保持列不变。
6. 若轨迹的下一个目标位置已被非黑(0)像素占据（包括替换后的模板像素或其他种子的轨迹），该条轨迹在此方向终止（不覆盖已有像素，终止前的像素保留）。
7. 轨迹超出网格边界时终止。
8. 种子像素本身保持原色。

**关键洞察**：模板替换并非为了展示模板图案本身，而是为了在生长路径上制造几何障碍。模板的内部颜色分布无关紧要——任何非黑像素都会终止轨迹。关键在于灰矩形的位置决定了哪些生长路径被截断以及截断的长度，从而塑造最终的稀疏图案。
