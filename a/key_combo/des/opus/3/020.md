## 新题 1：重力合并改变像素计数与着色

**组合逻辑**：[重力下落](已有) → [连通分量检测](创新：检测落地后的合并体而非原始对象) → [计数→重涂色](已有映射规则，但输入来自合并后的新分量)

**来源原语**：重力下落(gravity_drop, 825aa9e9)、计数(count, 6e82a1ae)、重涂色(recolor, 6e82a1ae)、连通分量检测(connected_component_detection, 84db8fc4)、可动对象(movable_object, 825aa9e9)、障碍物(obstacle, 825aa9e9)、缓冲行间距(cushion_row_gap, 825aa9e9)、像素数映射颜色(count_to_color, 6e82a1ae)

**依赖链**：重力下落改变对象的空间位置 → 落地后原本不相邻的对象可能变为 4-连通相邻从而合并成更大的连通分量 → 合并后的像素数与原始对象的像素数不同 → 按合并后的像素数执行颜色映射

一句话总结：灰色小对象在重力作用下落到障碍物上方（保留一行缓冲），落地后相邻的对象合并为新连通体，根据合并后的像素总数重新着色。

**输入结构**：约 12x10 的网格，黑(0) 背景。底部有栗(9) 色障碍物像素（不规则分布，不一定连续，但至少部分触碰底边）。网格上半区散布若干灰(5) 色 4-连通小对象（每个 2~4 像素，形状各异，如竖条、横条、弯折碎片等）。对象之间在初始位置互不 4-连通，但部分对象在同一列或相邻列上垂直分布，使得下落后可能相邻合并。生成约束：下落后至少有一对原本独立的对象合并为一个连通分量，且合并后像素数仍在 2~6 范围内。

**规则**：
1. 栗(9) 色像素和黑(0) 色背景保持不变。将栗色像素、栗色像素正上方一行的单元格、以及网格最底行标记为"阻塞"。
2. 将每个灰(5) 色 4-连通对象视为刚体，整体向下移动，直到其任一像素的下一行位置为阻塞单元格或另一个已静止的灰色对象时停止。处理顺序：按对象最低像素行号从大到小（最接近底部的先落）。
3. 所有对象静止后，重新检测所有灰色像素的 4-连通分量（此时某些原本独立的对象可能已合并）。
4. 按合并后的像素数重涂色：2 像素→绿(3)，3 像素→红(2)，4 像素→蓝(1)，5 像素→黄(4)，6 像素→品红(6)。

**关键洞察**：重力下落不只是移动对象——它会改变连通性，使原本独立的小对象合并为更大的连通体，从而改变像素计数和最终颜色。求解者不能先着色再移动，必须先完成所有重力模拟才能确定正确的像素计数。

## 新题 2：菱形包络构建寻路迷宫

**组合逻辑**：[包络生成](已有，从实心条生成菱形) → [寻路](创新：菱形包络像素作为转向触发障碍，而非预设的独立障碍点)

**来源原语**：包络生成(envelope_generation, c97c0139)、寻路(pathfinding, 2dd70a9a)、实心条(solid_bar, c97c0139)、菱形轮廓(diamond_outline, c97c0139)、障碍像素(barrier_pixel, 2dd70a9a)、起止标记(start_end_marker, 2dd70a9a)、路径(path, 2dd70a9a)、逐步收缩(stepwise_shrink, c97c0139)、障碍触发转向(barrier_triggers_turn, 2dd70a9a)

**依赖链**：实心条的长度和位置决定菱形包络的形状与范围 → 菱形包络像素成为寻路时的转向触发障碍 → 路径的可行性和形态完全取决于包络几何 → 不同长度的条产生不同大小的菱形，其遮挡交叠会改变可通行区域

一句话总结：先围绕彩色实心条生成菱形包络，再在包络像素构成的障碍场中寻找从起点到终点的受限路径。

**输入结构**：约 18x18 的网格，黑(0) 背景。2~3 根蓝(1) 色实心条（水平或垂直，长度 3~7 像素，单像素宽）。一个绿(3) 色短线段（2 像素，水平或垂直）标记路径起点和初始行进方向。一个红(2) 色短线段（2 像素）标记路径终点。条、起点、终点互不重叠，且不在同一行或同一列。生成约束：在生成菱形包络后，起点到终点存在至少一条合法路径（仅在碰到包络像素时转向 90 度，在黑色空间中直行）。

**规则**：
1. 保留所有蓝(1) 色实心条像素不变。
2. 对每根实心条，按包络生成规则在其周围绘制青(8) 色菱形包络：从条的中轴线向外逐行（对水平条）或逐列（对垂直条）扩展，每远离一行/列则包络线段两端各缩短一个像素，直到缩为零。包络仅覆盖黑色背景单元格，不覆盖条本身、起止标记或其他已有包络像素（多根条的包络若重叠，先绘制的保留，先绘制顺序为条的边界框左上角从左到右、从上到下）。
3. 将所有青色包络像素视为转向触发障碍。使用广度优先搜索（状态 = 位置 + 当前行进方向）寻找从绿色起点到红色终点的路径：在黑色单元格中沿当前方向直行；当下一个单元格是青色障碍时，在当前位置尝试左转和右转两个方向，选择可行的方向继续（若两者都可行，选择使状态空间中路径最短的；若都不可行，回溯）。
4. 当路径的下一个单元格为红色终点线段的一部分时停止。将路径上所有经过的黑色单元格涂为绿(3) 色。

**关键洞察**：输入中没有显式的障碍点——迷宫的墙壁是从实心条的长度和位置隐式生成的菱形包络。条越长，菱形越大，阻挡范围越广。求解者必须先完成包络构建才能规划路径。

## 新题 3：双面板叠加后的拓扑分类着色

**组合逻辑**：[透明叠加](已有) → [连通分量检测 + 边界可达性分析](创新：对叠加结果而非原始输入做拓扑分析) → [重涂色](由拓扑分类决定颜色)

**来源原语**：透明叠加(transparent_overlay, 506d28a5)、连通分量检测(connected_component_detection, 84db8fc4)、重涂色(recolor, 84db8fc4)、分隔行(divider_row, 506d28a5)、二值掩码(binary_mask, 506d28a5)、连通区域(connected_region, 84db8fc4)、双面板对齐(dual_panel_alignment, 506d28a5)、边界可达性(edge_reachability, 84db8fc4)、任一前景即输出(either_foreground_yields_output, 506d28a5)、拓扑分类(topological_classification, 84db8fc4)

**依赖链**：上下两个面板各有不完整的屏障图案 → 叠加后屏障的并集可能形成完整的封闭围墙 → 被围墙封闭的背景区域与触碰网格边缘的背景区域需区分着色 → 单独看任一面板都无法判断哪些区域是封闭的

一句话总结：将分隔行两侧的前景屏障叠加合并，然后根据合并后的背景区域是否触碰网格边缘分别着色。

**输入结构**：约 9x15（高x宽）的网格，黑(0) 背景。正中间有一整行灰(5) 色分隔行（第 4 行，0-indexed）。上半区（第 0~3 行，共 4 行）包含蓝(1) 色前景像素，形成部分屏障图案（线段和折线，不完全封闭任何黑色区域）。下半区（第 5~8 行，共 4 行，与上半区等高等宽）包含红(2) 色前景像素，也形成部分屏障图案。两个半区的前景图案有重叠部分但不完全相同。生成约束：上下半区前景的并集至少封闭一个内部黑色区域，且至少有一个黑色区域仍触碰输出网格边缘。

**规则**：
1. 移除灰色分隔行。将上下两个半区逐单元格对齐。
2. 输出网格的形状等于单个半区的形状（4 行 x 15 列）。对于每个位置：若上半区或下半区（或两者）在该位置有前景像素，则输出该位置为绿(3) 色（前景并集）；否则为黑(0) 色。
3. 在输出的绿色屏障图案下，检测所有黑(0) 色 4-连通区域。
4. 若某黑色区域的任一像素位于输出网格的边缘行或边缘列，则该区域着色为黄(4) 色（边缘可达）。
5. 若某黑色区域完全被绿色像素包围、不触碰任何网格边缘，则该区域着色为品红(6) 色（封闭）。
6. 绿色屏障像素保持不变。

**关键洞察**：单独看上半区或下半区的屏障都不构成封闭区域——只有叠加后的并集才可能形成封闭围墙。求解者必须先完成叠加才能判断哪些区域是真正封闭的。

## 新题 4：嵌套压缩以孔洞数定环色

**组合逻辑**：[嵌套层次分析](已有) + [孔洞计数](创新：对每层嵌套形状独立计算孔洞数) → [压缩为方环](已有环结构) + [按孔洞数映射颜色](创新：环色不继承原色，而由孔洞数决定)

**来源原语**：压缩(compress, eb5a1d5d)、计数(count, 0a2355a6)、重涂色(recolor, 0a2355a6)、嵌套形状(nested_shape, eb5a1d5d)、方环(square_ring, eb5a1d5d)、封闭区域(enclosed_region, 0a2355a6)、嵌套层次(nesting_hierarchy, eb5a1d5d)、面积序映射环(area_order_to_ring, eb5a1d5d)、按孔洞数映射颜色(hole_count_to_color_mapping, 0a2355a6)

**依赖链**：多个形状按面积嵌套排列 → 嵌套层级决定输出方环的从外到内排列顺序 → 每个形状包含不同数量的内部孔洞 → 孔洞数决定对应方环的颜色（而非继承原始颜色） → 原始颜色是干扰项

一句话总结：将嵌套的多色形状压缩为同心方环，每个环的颜色不取自原始形状颜色，而由该层形状包含的黑色孔洞数决定。

**输入结构**：约 15x15 的网格，黑(0) 背景。3~4 个单色形状（每个形状一种颜色，如蓝(1)、红(2)、绿(3)、黄(4)），按边界框面积从大到小嵌套排列（最大的包围其余，最小的在最内层）。每个形状是一个不规则的闭合轮廓（4-连通，厚度 1~2 像素），其内部可能包含 0~3 个黑(0) 色孔洞（孔洞是被该形状像素完全包围的 4-连通黑色区域，不包括形状与下一层内嵌形状之间的间隙空间）。生成约束：不同层的形状包含不同数量的孔洞（以保证颜色映射不退化为位置映射）；形状的原始颜色与孔洞数映射的目标颜色不同（确保原色是干扰项）。

**规则**：
1. 检测所有非黑色的 4-连通形状，按边界框面积从大到小排序，确定嵌套层级（最大为第 1 层/最外层）。
2. 对每个形状，计算其轮廓内部被该形状像素完全包围的黑色 4-连通孔洞数量（不计与外部背景相通的黑色区域，也不计被内层形状占据的区域——只计纯黑色的封闭孔洞）。
3. 输出一个 (2N-1) x (2N-1) 的方阵（N 为形状数量），绘制 N 层同心方环。第 1 层为最外环，第 N 层为最内层中心像素。
4. 从最外环到最内环，每个环的颜色由对应层形状的孔洞数决定：0 个孔洞→灰(5)，1 个孔洞→蓝(1)，2 个孔洞→红(2)，3 个孔洞→绿(3)。
5. 原始形状的颜色在输出中不使用。

**关键洞察**：原始形状的颜色是纯干扰项。输出方环的排列顺序来自嵌套层级（空间分析），但颜色来自孔洞计数（拓扑分析）——求解者必须同时完成两种独立分析才能确定输出。仅看一个示例时，无法排除"颜色按嵌套层级固定分配"的假设，必须对比多个示例才能发现孔洞数才是决定因素。

## 新题 5：射线交叉分区后按面积排序填色

**组合逻辑**：[射线延伸](已有，十字射线) → [洪泛填充](创新：对射线划分出的区域做填充) → [排序](创新：按区域面积排序) → [重涂色](由面积排名决定颜色)

**来源原语**：射线延伸(ray_extend, 23581191)、洪泛填充(flood_fill, 941d9a10)、排序(sort, 941d9a10)、重涂色(recolor, 941d9a10)、孤立像素(isolated_pixel, 23581191)、封闭区域(bounded_region, 941d9a10)、行列交叉(row_col_intersection, 23581191)、位置排序(positional_ordering, 941d9a10)、位置决定填充色(position_determines_fill_color, 941d9a10)

**依赖链**：孤立像素的位置决定十字射线的走向 → 多条射线在网格中交叉，将空间划分为矩形区域 → 区域的面积由射线的相对位置隐式决定 → 面积排序决定每个区域的填充颜色

一句话总结：从多个孤立像素发射全行全列十字射线，射线将网格切割为若干矩形区域，按区域面积从小到大排序并依次着色。

**输入结构**：约 14x14 的网格，黑(0) 背景。3~4 个孤立像素，颜色各不相同（如橙(7)、蓝(1)、红(2)），互不在同一行且互不在同一列。生成约束：像素位置使得射线将网格划分出的矩形区域面积互不相同（避免平局）。

**规则**：
1. 对每个孤立像素，将其整行和整列都涂为灰(5) 色（像素自身也变为灰色）。灰色射线是分隔线。
2. 灰色射线将网格分割为若干矩形区域（不含射线本身的像素）。
3. 计算每个矩形区域的面积（像素数）。
4. 按面积从小到大排序。面积最小的区域填充蓝(1)，第二小的填充红(2)，第三小的填充绿(3)，第四小的填充黄(4)，第五小的填充品红(6)，第六小的填充橙(7)，以此类推。若区域数超过 6，多余的区域填充青(8)。
5. 灰色分隔线保持不变。

**关键洞察**：输入中只有几个孤立像素，但它们的精确位置决定了整个网格的分区方式和每个区域的面积。求解者需要理解射线分区的几何效应，才能预测面积排序并确定颜色分配。像素的原始颜色是干扰项，最终全部被灰色覆盖。

## 新题 6：形状等价分组决定重力后着色

**组合逻辑**：[形状匹配/旋转翻转等价](已有) + [重力下落](已有) → [重涂色](创新：颜色由等价分组身份决定，分组需在重力之前完成但着色效果在重力之后呈现)

**来源原语**：形状匹配(shape_match, 6165ea8f)、重力下落(gravity_drop, 825aa9e9)、重涂色(recolor, 6165ea8f)、归一化掩码(normalized_mask, 6165ea8f)、可动对象(movable_object, 825aa9e9)、障碍物(obstacle, 825aa9e9)、旋转翻转等价(dihedral_equiv, 6165ea8f)、邻接阻挡(adjacency_blocking, 825aa9e9)、等价涂指定色(equiv_colored, 6165ea8f)、缓冲行间距(cushion_row_gap, 825aa9e9)

**依赖链**：所有精灵体先做旋转翻转等价分组 → 每组分配一个代表色（由组内最上方成员的列位置决定：最左列→第一个颜色，次左→第二个颜色，以此类推） → 然后所有精灵体执行重力下落（含一行缓冲） → 精灵体着色为其所属等价组的代表色

一句话总结：将散落的灰色精灵体按旋转翻转等价分组并着色，然后所有精灵体在重力作用下落到底部障碍物上方。

**输入结构**：约 16x12 的网格，黑(0) 背景。底部有一整行栗(9) 色障碍物。网格中散布 6~8 个灰(5) 色 4-连通精灵体（每个 3~5 像素，形状各异但存在旋转翻转等价对）。精灵体初始位置在障碍物上方至少 3 行，互不 4-连通。生成约束：精灵体恰好分为 2~3 个等价组，每组 2~3 个成员；同组成员的归一化掩码在 8 种旋转/翻转变换下至少有一种相同但初始朝向不同。

**规则**：
1. 提取每个灰色精灵体的紧凑边界框掩码。对每对精灵体，检查其掩码是否在 8 种旋转/翻转变换（0/90/180/270度旋转，及其水平翻转）下相同。相同则归为同一等价组。
2. 对每个等价组，找到组内最上方（行号最小）的成员；若行号相同则取边界框左上角列号最小的成员。该成员的边界框左上角列号决定组的排序位置。
3. 按列号从小到大，依次为各组分配颜色：第一组→蓝(1)，第二组→红(2)，第三组→绿(3)。
4. 将每个精灵体的所有像素重涂为其所属组的颜色。
5. 将所有精灵体视为刚体，执行重力下落：向下移动直到底部像素的下一行为栗色障碍物的正上方一行（保留一行黑色缓冲）或为另一个已静止精灵体的像素。按精灵体最低行号从大到小依次处理。
6. 栗色障碍物保持不变。

**关键洞察**：精灵体的颜色不由其像素数或初始位置直接决定，而由形状等价分组决定。求解者需要先识别出哪些形状是旋转/翻转等价的（忽略朝向差异），才能确定着色规则。重力是第二个独立变换，必须在理解着色逻辑之后才能正确预测最终布局。

## 新题 7：排序后柱高编码印章选择掩码

**组合逻辑**：[排序](已有，柱状条按高度排序) → [二值化编码](创新：排序后的柱高序列被二值化为选择掩码) → [印章覆盖](已有，但印章位置由掩码决定)

**来源原语**：排序(sort, 31f7f899)、印章覆盖(stamp, ad7e01d0)、像素放大(pixel_upscale, ad7e01d0)、柱状条(vertical_bar, 31f7f899)、基线(baseline, 31f7f899)、源图案(source_pattern, ad7e01d0)、控制像素(control_pixel, ad7e01d0)、高度排序(height_ordering, 31f7f899)、像素到块映射(pixel_block_mapping, ad7e01d0)、槽位保持颜色(slot_retains_color, 31f7f899)、控制色选中则印章(stamp_where_control, ad7e01d0)

**依赖链**：柱状条按高度排序后重排 → 排序后的高度序列被二值化（高于中位高度→激活，否则→未激活） → 激活位置决定输出中哪些块槽位接收源图案的印章 → 源图案来自输入中独立的小模板区域 → 每个印章采用对应柱的原始颜色

一句话总结：将柱状条按高度排序，高于中位数的柱定义印章位置，在对应的输出块中印入输入角落的小模板图案并采用该柱的颜色。

**输入结构**：约 10x16 的网格，黑(0) 背景。底部有一整行橙(7) 色基线。基线上方有 4~6 根单列宽的柱状条，各自高度不同（1~6 像素），各自颜色不同（取自蓝(1)、红(2)、绿(3)、黄(4)、品红(6)、青(8)）。网格右上角有一个 3x3 的区域包含一个小图案（源模板），由栗(9) 色和黑色像素组成（非全黑、非全栗），与柱状条不相邻且不重叠。生成约束：柱的数量为偶数（保证中位数明确，取第 N/2 根的高度为中位数）；各柱高度互不相同。

**规则**：
1. 识别基线上的所有柱状条，记录每根柱的高度（前景像素行数）、水平位置（列号）和颜色。提取右上角的 3x3 源模板。
2. 按高度从小到大排序所有柱。计算中位高度 M（N 根柱时取排序后第 N/2 根柱的高度，1-indexed）。
3. 对每根柱：若其高度 > M，标记为"激活"；否则标记为"未激活"。
4. 输出网格为 3 行 x (3*N) 列（N 为柱的数量），由 N 个 3x3 块从左到右排列。块的顺序对应柱的排序后顺序（从矮到高 = 从左到右）。
5. 对"激活"的柱对应的块：将源模板完整印入该块，并将模板中的栗(9) 色像素替换为该柱的原始颜色，黑色像素保持黑色。
6. 对"未激活"的柱对应的块：该块保持全黑。

**关键洞察**：输入看起来像一个需要排序的柱状图加一个装饰性小图案，但排序不是最终目的——排序后的高度序列被二值化为一个选择掩码，决定哪些位置接收模板印章。求解者需要先完成排序，再理解中位数阈值规则，最后才能确定输出。模板的存在和柱状图的排序看似无关，实则通过二值化紧密耦合。

## 新题 8：周期补全后按行带奇偶交替着色

**组合逻辑**：[补全](已有，恢复被占位符遮盖的周期图案) → [行带检测](创新：在完整图案中识别纵向重复的行带单元) → [奇偶交替重涂色](创新：按行带重复的奇偶周期交替改变某些颜色)

**来源原语**：补全(completion, 50a16a69)、平铺(tile, 8eb1be9a)、重涂色(recolor, 97999447)、重复瓦片(repeating_tile, 50a16a69)、占位符区域(placeholder_region, 50a16a69)、行带(row_band, 8eb1be9a)、周期延拓(periodic_extension, 50a16a69)、纵向重复(vertical_repetition, 8eb1be9a)、奇偶交替(parity_alternation, 97999447)、交替填充至边界(alternating_fill_to_edge, 97999447)

**依赖链**：输入中部分区域被占位符遮盖 → 必须先从可见部分推断瓦片周期并补全完整图案 → 补全后的图案呈纵向重复的行带结构 → 对行带的奇偶周期交替处理：奇数次重复保持原色，偶数次重复中将所有非背景像素替换为灰(5)

一句话总结：先用周期延拓补全被占位符遮盖的重复图案，然后将纵向重复的行带按奇偶交替着色——奇数周期保持原色，偶数周期变灰。

**输入结构**：约 12x8 的网格。左上角区域（约 6x5）包含一个由 2~3 种非黑颜色（如红(2)、蓝(1)）和黑(0) 背景组成的重复瓦片图案（至少纵向重复 2 次完整可见）。其余区域（右侧列和/或底部行）被黄(4) 色占位符像素完整填充。生成约束：瓦片的纵向周期 H 能整除完整网格高度（补全后恰好纵向重复整数次）；瓦片内的图案不具有纵向自对称性（否则奇偶交替效果不可见）。

**规则**：
1. 识别黄(4) 色占位符区域和可见的瓦片区域。
2. 从可见区域推断最小重复瓦片（宽度 = 网格宽度，高度 = 纵向最小周期 H）。
3. 用该瓦片周期性延拓，覆盖所有占位符区域，得到完整的重复图案。
4. 将完整图案按行带分组：第 0~(H-1) 行为第 1 个行带（奇数），第 H~(2H-1) 行为第 2 个行带（偶数），第 2H~(3H-1) 行为第 3 个行带（奇数），以此类推。
5. 奇数行带（第 1、3、5...个）：保持所有像素颜色不变。
6. 偶数行带（第 2、4、6...个）：将所有非黑像素替换为灰(5) 色，黑色背景保持不变。

**关键洞察**：占位符隐藏了图案的完整延拓，但补全后并非直接输出——还要对纵向重复的周期做奇偶交替处理。求解者只看到部分图案和占位符时，无法直接判断奇偶规则；必须先补全，再观察不同示例中完整图案行带的交替着色模式才能归纳规则。

## 新题 9：分隔区域内按引导色印章精灵体后擦除引导

**组合逻辑**：[连通分量检测](已有) + [引导像素色转移](创新：引导像素不是直接重涂前景，而是为印章提供颜色) → [印章覆盖](创新：将精灵体印章到引导像素所在区域的中心) → [擦除](已有，引导像素消失)

**来源原语**：印章覆盖(stamp, e8dc4411)、擦除(erase, aabf363d)、连通分量检测(connected_component_detection, 84db8fc4)、重涂色(recolor, aabf363d)、精灵体(sprite, fafd9572)、引导像素(guide_pixel, aabf363d)、分隔线(divider_line, 941d9a10)、封闭区域(bounded_region, 941d9a10)、邻接触碰(adjacency_touch, e8dc4411)、角落色转移后消(corner_color_transfer_vanish, aabf363d)

**依赖链**：灰色分隔线将网格分为多个矩形区域 → 每个区域内有一个彩色引导像素 → 网格左上角区域内有一个小精灵体模板 → 将模板印章到每个区域的中心位置，印章颜色采用该区域引导像素的颜色 → 引导像素被擦除为背景色

一句话总结：将左上角的精灵体模板印章到每个分隔区域的中心，颜色取自区域内的引导像素，引导像素随后消失。

**输入结构**：约 13x13 的网格，黑(0) 背景。灰(5) 色的水平线和垂直线将网格分为 4~6 个矩形区域（类似不均匀的井字格）。每个矩形区域内部恰好有一个孤立的彩色引导像素（颜色各不相同，取自蓝(1)、红(2)、绿(3)、黄(4)、品红(6) 等）。网格左上角区域的左上角处有一个由橙(7) 色像素组成的小精灵体（3~5 像素，4-连通，不规则形状），紧贴该区域的左上角。生成约束：每个区域的尺寸至少 5x5（足够容纳精灵体边界框居中放置时不与分隔线重叠）；左上角区域的引导像素不与精灵体重叠。

**规则**：
1. 检测灰(5) 色分隔线（完整的水平线和垂直线），识别所有被分隔线划分的矩形区域。
2. 提取左上角区域内的橙(7) 色精灵体作为印章模板（记录其相对于自身边界框左上角的掩码形状）。
3. 对每个矩形区域（包括左上角区域）执行以下操作：
   a. 找到该区域内唯一的引导像素，记录其颜色 C。
   b. 计算区域的中心位置：中心行 = 区域顶行 + (区域高度 - 模板高度) // 2，中心列 = 区域左列 + (区域宽度 - 模板宽度) // 2。
   c. 将精灵体模板以左上角对齐到 (中心行, 中心列) 的方式印入该区域，模板中所有橙(7) 色像素替换为颜色 C。
4. 擦除所有引导像素（将其位置设为黑(0) 色）。若引导像素的位置被步骤 3 的印章覆盖，则印章覆盖后的颜色优先（引导像素已不可见）。
5. 擦除左上角区域中原始精灵体模板的橙色像素（设为黑(0) 色），被印章覆盖的位置保持印章颜色。
6. 灰色分隔线保持不变。

**关键洞察**：精灵体模板和引导像素各自承担不同角色——模板提供形状，引导像素提供颜色和定位区域——两者缺一不可。引导像素在完成色彩转移后消失，所以输出中不含任何孤立彩色点，只有统一形状但不同颜色的精灵体副本居中于各区域。

**组合逻辑**：[分离](已有，从紧凑排列中分离出精灵体) → [排位对应](创新：分离后按精灵体前景面积排位) → [图例位映射色](创新：用独立图例的空间位置为排位分配颜色) → [重涂色](由图例决定最终颜色)

**输入结构**：约 8x8 的网格，黑(0) 背景。中心区域有一个由灰(5) 色像素组成的紧凑前景图案，该图案可被恰好 4 个形状各异的 2x2 精灵体掩码的平移副本无间隙、无重叠地完全覆盖。每个 2x2 掩码中的前景（灰色）像素数各不相同（分别为 1、2、3、4 个），从而前景面积互不相同。网格的右下角有一个 2x2 的颜色图例块（与中心图案不相邻），图例的四个像素按从左到右、从上到下的顺序依次为不同颜色（取自蓝(1)、红(2)、绿(3)、黄(4)），分别对应排位 1（面积最小）到排位 4（面积最大）。

**规则**：
1. 从中心灰色图案中推断 4 个 2x2 精灵体掩码，使它们的平移副本恰好覆盖所有灰色像素（无重叠、无间隙）。
2. 计算每个精灵体掩码的前景像素数（面积），按面积从小到大排位为 1~4。
3. 读取右下角 2x2 图例：左上像素→排位 1 的颜色，右上像素→排位 2 的颜色，左下像素→排位 3 的颜色，右下像素→排位 4 的颜色。
4. 输出为 5x5 网格。将 4 个精灵体分别放置到四个 2x2 角落区域，放置位置由面积排位决定：排位 1（最小面积）→左上角(行0-1,列0-1)，排位 2→右上角(行0-1,列3-4)，排位 3→左下角(行3-4,列0-1)，排位 4→右下角(行3-4,列3-4)。
5. 每个精灵体掩码中的灰色前景像素替换为其排位对应的图例颜色，黑色像素保持黑色。
6. 输出的第 2 行和第 2 列（0-indexed）为全黑间隔行/列。
7. 图例不出现在输出中。

**关键洞察**：分离本身不够——精灵体放置在哪个角落不由其初始空间位置决定，而由前景面积排位决定。同时，颜色不由位置或原色决定，而由图例映射决定。求解者需要同时理解分离规则（掩码推断）、排位规则（面积排序）和图例映射（空间位置编码颜色）三者的交互才能求解。
