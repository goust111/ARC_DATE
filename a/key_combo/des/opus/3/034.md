## 新题 1：射线受阻的列重叠填充

**组合逻辑**：[边缘线段 + 列投影重叠 + 较长侧优先](已有) → [射线投射 + 视线可达](创新：射线不再寻找源区域，而是沿填充方向检测障碍物以截断填充高度) → [忽略干扰项](创新：单像素对象被射线穿透而非阻挡，多像素对象才截断)

**来源原语**：边缘线段/列投影重叠/较长侧优先/填充(770cc55f)、射线投射/视线可达/忽略干扰项(3d588dc9)

**依赖链**：列投影重叠确定哪些列需要填充 → 较长侧优先确定填充方向（从哪侧向分隔行推进） → 射线投射确定每列的填充终点（遇到多像素障碍停止） → 干扰项过滤决定射线是否穿透某个对象。四层约束共同决定每个填充像素的存在与否。

根据两条边缘线段的列重叠范围和长度差异决定填充方向，再用射线检测障碍物来截断每列的填充高度，单像素干扰项被射线穿透不计为障碍。

**输入结构**：约 15x20 的网格，黑(0)背景。第一行和最后一行各有一条同色（非红）水平连续线段（边缘线段），两条线段颜色相同但长度和起始列不同。网格中间有一行完整的红(2)分隔行横贯全宽。在分隔行与较长线段之间的区域内，散布着若干多像素（2~5 像素）的 4-连通单色障碍物（颜色各异，非红非黄），以及若干孤立的单像素彩色点（干扰项）。生成约束：两条边缘线段的列范围有交集但不完全重合；障碍物不接触分隔行也不接触边缘线段行；每列至多有一个多像素障碍物。

**规则**：
1. 计算顶部边缘线段和底部边缘线段的列范围交集，得到待填充的列集合。
2. 比较两条线段的长度（像素数）。较长的那条所在侧为填充侧。
3. 在填充侧，对每一个交集列，从边缘线段行的内侧相邻行开始，沿朝分隔行方向逐行推进，构建一条射线。
4. 射线前进时，若当前行的当前列有一个属于多像素 4-连通对象的像素，射线在该行之前停止（不含该行）。若该像素是孤立的单像素对象，射线穿透它——该单像素被擦除为背景，射线继续前进。
5. 射线到达分隔行（不含分隔行）也停止。
6. 将射线扫过的所有行在该列的像素涂为黄(4)。
7. 保留所有原始非背景像素不变（边缘线段、分隔行、多像素障碍物均不被覆盖）。被穿透的单像素干扰项已在步骤 4 中擦除。

**关键洞察**：单像素噪声与多像素障碍物在视觉上都是彩色前景，但只有多像素对象才截断填充射线——求解者必须从多个示例中归纳出"连通分量大小决定是否阻挡"这一隐蔽判据。

## 新题 2：弯折数决定镜像方向

**组合逻辑**：[计数/弯折数分类](已有) → [镜像 + 对齐决定镜像轴](创新：弯折数不再映射到颜色，而是决定镜像是水平翻转还是垂直翻转) + [单像素标记 + 共行列对齐](已有) → [重涂色](创新：原件按弯折数重涂，而非镜像副本)

**来源原语**：计数/弯折数分类/弯折数决定颜色(e509e548)、镜像/共行列对齐/对齐决定镜像轴/单像素标记(963f59bc)、重涂色(e509e548, 963f59bc)

**依赖链**：弯折数分类产生拓扑属性 → 该属性决定镜像方向（奇数=水平，偶数=垂直），同时决定原件重涂颜色 → 单像素标记与源对象的行列对齐确定镜像轴位置 → 镜像副本涂为标记颜色。弯折数同时驱动几何变换类型和颜色映射两条分支。

统计每个形状的弯折数，弯折数的奇偶性决定镜像方向，标记点决定镜像轴位置，原件按弯折数重涂颜色。

**输入结构**：约 20x20 的网格，黑(0)背景。网格中有 3~5 个绿(3)的 4-连通小图形（3~8 像素，形态各异），每个含有不同数量的 L 形 2x2 弯折。另有若干孤立的单像素标记，每个标记颜色各不相同（非绿非黑），且每个标记恰好与某一个绿色图形共享一行或一列（但不同时共享行和列）。每个绿色图形恰好关联一个标记。生成约束：图形间互不相邻，图形与标记间距至少 2 像素；弯折数覆盖 1、2、3 三种情况。

**规则**：
1. 检测每个绿(3)图形，计算其 L 形 2x2 弯折数量（在所有四种旋转下统计唯一弯折位置）。
2. 对原件重涂色：1 个弯折 → 蓝(1)，2 个弯折 → 品红(6)，3 个弯折 → 红(2)。
3. 为每个图形找到其关联的单像素标记。如果标记与图形中恰好一个像素共享同一行，则计算该像素与标记之间的垂直中线作为镜像轴。如果共享同一列，则计算水平中线。
4. 弯折数为奇数（1 或 3）的图形执行水平翻转（沿垂直中线反射整个图形 mask），弯折数为偶数（2）的图形执行垂直翻转（沿水平中线反射）。
5. 但镜像轴的位置始终由步骤 3 的标记对齐方式决定——即如果弯折数指定水平翻转，但标记与源共享的是同一列（对应水平中线），则以标记对齐所决定的中线为轴做水平翻转；翻转类型由弯折数定，轴位置由标记-源对齐关系定。
6. 镜像副本涂为标记的颜色。保留原件（已重涂）和标记。

**关键洞察**：形状的拓扑属性（弯折数奇偶）决定应用哪种几何变换，而标记的空间对齐决定变换的精确参数——求解者必须同时推断拓扑-变换映射和空间-轴映射两套规则。

## 新题 3：周期印章的容器捕获

**组合逻辑**：[印章覆盖 + 周期排布](已有) → [周期内指定位变色](已有) → [重力下落 + 列对齐落入](创新：印章副本不是保留在原位，而是按列下落) → [容器捕获 vs 无容器铺底](创新：下落结果取决于下方是否有封闭容器)

**来源原语**：印章覆盖/周期排布/周期内指定位变色(d304284e)、重力下落/列对齐落入/容器/无容器则铺满底行(db7260a4)

**依赖链**：周期排布确定印章出现的列位置 → 周期位置决定印章颜色（原色 or 品红） → 每个印章的列范围决定其下方是否有容器 → 有容器则填充容器内部（颜色由周期位置决定），无容器则铺底行。周期布局决定颜色，空间布局决定目的地，两者交叉产生最终图案。

在顶部按周期排列精灵体副本（每第三个变为品红），然后每个副本按列下落，被下方的 U 形容器捕获并填充容器内部，未被捕获的则铺满底行。

**输入结构**：约 20x25 的网格，黑(0)背景。顶部区域（前 4~5 行）有一个 4-连通单色小精灵体（非黑非品红，3~6 像素，边界框约 3x3 至 4x4）。下方区域（第 8 行以下）有 2~4 个红(2)的 U 形容器（由两条垂直侧壁和一条水平底边构成，内部为空的矩形区域，宽度 3~5 列，高度 3~5 行），容器之间水平间隔不等。容器不接触网格底行。生成约束：精灵体边界框宽度 + 1 为周期步长；网格宽度足以容纳至少 5 个周期位置；至少一个容器的列范围与某个周期位置的列范围有完整包含关系，至少一个周期位置下方无容器。

**规则**：
1. 以精灵体的边界框左上角为起点，向右每隔（精灵体宽度 + 1）列放置一个槽位。
2. 对槽位按 0 起编号。编号 mod 3 == 2 的槽位（即第 3、6、9... 个）将精灵体 mask 涂为品红(6)，其余槽位保留原色。
3. 擦除原始精灵体（仅保留槽位副本的逻辑位置信息，不在顶部绘制副本）。
4. 对每个槽位，检查其列范围（精灵体边界框宽度的列区间）是否完整落入某个 U 形容器的水平范围内（含侧壁列）：
   - 若是：将该容器的内部矩形区域填充为该槽位对应的颜色（原色或品红）。如果多个槽位对应同一容器，后编号的覆盖先编号的。
   - 若否：将该槽位列范围内的网格最底行像素涂为该槽位对应的颜色。
5. 保留所有容器的红(2)结构像素不变。

**关键洞察**：顶部精灵体从未直接出现在输出中——它只是一个"种子"，通过周期展开确定列位置和颜色，再通过容器的空间布局决定最终图案形态。求解者需同时推断周期着色规则和容器捕获逻辑。

## 新题 4：掏空后按重叠优先级提取摘要

**组合逻辑**：[掏空/保留边擦除内部](已有) → [列投影重叠](创新：不再比较边缘线段，而是比较边框的水平范围) → [内部面积 → 面积阈值决定颜色](创新：面积不决定填充色，而是决定重叠优先级) → [提取摘要/压缩](创新：将二维重叠关系压缩为一维优先级序列)

**来源原语**：掏空/保留边擦除内部/实心矩形(4347f46a)、列投影重叠(770cc55f)、内部面积/面积阈值决定颜色(84f2aca1)、提取摘要/压缩/封闭区域(ac6f9922)

**依赖链**：掏空产生边框和内部空腔 → 内部面积由空腔大小决定 → 列投影重叠判断哪些边框在水平方向有交叉 → 面积大的边框在重叠列拥有优先权 → 提取一行摘要，每列像素颜色为该列优先权最高的边框颜色。掏空结果同时影响面积计算和边框可视结构，面积又反过来决定重叠区的可视结果。

将多个实心矩形掏空为边框，按内部面积大小确定重叠列的归属优先级，最后将整个网格的列归属信息压缩为一行颜色摘要。

**输入结构**：约 18x18 的网格，黑(0)背景。包含 3~5 个不同颜色的单色实心轴对齐矩形（每个至少 3x3），颜色互不相同且非黑。矩形可以在列方向有重叠（即它们的水平范围有交集），但不能在空间上物理重叠（行范围不交叉）——它们在不同行区间内，只是列范围有共享。生成约束：至少两对矩形有列重叠；各矩形内部面积（(宽-2)x(高-2)）互不相等。

**规则**：
1. 对每个实心矩形执行掏空：保留其一像素厚的边框，将严格内部的像素设为背景黑(0)。
2. 计算每个掏空后边框的内部面积 = (宽-2) x (高-2)。
3. 对于每一列（0 到 grid_width-1），收集所有边框水平范围覆盖该列的边框集合。若集合非空，该列归属于集合中内部面积最大的边框，颜色为该边框的颜色。若集合为空，该列颜色为黑(0)。
4. 在输出网格的最底行，按上述归属为每列涂上对应颜色，构成一行摘要。
5. 输出网格的其余部分保留掏空后的边框结构不变。

**关键洞察**：矩形的外观大小同时决定两件事——掏空后的视觉结构和列优先级权重。面积更大的边框在摘要行中"占据"更多列，但这个面积只有在掏空之后才能精确计算。

## 新题 5：去噪共识后按对称性重涂修复

**组合逻辑**：[单像素为噪声 → 擦除](创新：噪声过滤不是最终目的，而是共识投票的前置清洗) → [重复图块 + 多数投票共识 → 修复异常](已有) → [对称类型决定颜色 → 重涂色](创新：共识形状的对称性决定输出颜色，而非原色) + [受损副本被标记](已有)

**来源原语**：单像素为噪声(a09f6c25)、擦除(a09f6c25)、重复图块/分隔网格/多数投票共识/修复异常/受损副本被标记(e84fef15)、对称类型决定颜色/重涂色(a09f6c25)

**依赖链**：噪声过滤清洗每个图块 → 清洗后的图块参与多数投票 → 投票产生共识形状 → 共识形状的反射对称类别决定输出颜色 → 与共识不同的单个受损图块的损坏位置标记为灰(5)。噪声若未清除会污染投票，进而改变共识形状，进而改变对称分类和输出颜色——这是一条跨越三步的因果链。

从包含噪声和一个受损副本的重复图块阵列中，滤除噪声后投票恢复共识形状，根据共识形状的对称性分类决定输出颜色，并标记受损位置。

**输入结构**：约 20x20 的网格。一种分隔色（如灰(5)）形成单像素宽的横竖分隔线，将网格划分为 3x3 或 4x3 的等大图块阵列（每个图块约 4x4 至 6x6）。每个图块内部有一个由同一种非背景、非分隔色的颜色（如红(2)）组成的 4-连通图形，背景为黑(0)。所有图块是同一母图的副本，但：(a) 恰好一个图块有损坏——若干母图像素被覆盖为背景色；(b) 若干图块（含或不含受损图块）内散布了 1~2 个孤立单像素的随机彩色噪声点（颜色各异，与母图色不同）。生成约束：母图形具有恰好一种反射对称类别（水平/垂直/对角之一）；噪声像素不与母图像素 4-连通相邻；受损图块至少有 2 个像素被擦除。

**规则**：
1. 在每个图块内，删除所有孤立单像素（4-连通邻居中无同色像素的非背景像素），将其还原为背景。
2. 对清洗后的图块阵列执行多数投票：在每个图块局部坐标 (r, c) 处，取所有图块该位置颜色的众数作为共识颜色。
3. 找到与共识不同的唯一受损图块。
4. 判断共识形状的反射对称类别：
   - 仅有水平对称轴 → 输出颜色为蓝(1)
   - 仅有垂直对称轴 → 输出颜色为绿(3)
   - 有对角对称轴（含 90 度旋转对称等非正交反射） → 输出颜色为品红(6)
   - 同时有水平和垂直对称轴 → 输出颜色为黄(4)
5. 输出为单个图块大小的网格：用步骤 4 确定的颜色绘制共识形状，但在受损图块中被擦除的那些局部坐标位置改涂为灰(5)。

**关键洞察**：噪声看似无害（都是孤立像素），但如果不清除就投票，噪声像素可能恰好出现在多数图块的同一位置，伪造出"共识"——这会改变形状的对称性分类，导致输出颜色完全错误。

## 新题 6：归一化形状匹配驱动的括号通道缩放传送

**组合逻辑**：[形状匹配 + 归一化形状对应](创新：不是匹配孔洞，而是匹配通道内的对象与外部模板) → [括号框 + 通道对齐 + 平移](已有) → [像素放大](创新：放大倍率不由标记位置决定，而是由匹配到的模板的边界框面积比决定) → [目标底边对齐](已有)

**来源原语**：形状匹配/归一化形状对应/标记形状(42f14c03)、括号框/通道对齐/平移/目标底边对齐(df9fd884)、像素放大(4522001f)

**依赖链**：括号通道标识出待传送对象 → 归一化形状匹配将对象与外部模板配对 → 模板的边界框与对象边界框的面积比确定放大倍率 → 放大后的对象传送到目标括号通道并底边对齐。形状匹配不仅决定颜色映射，还决定几何变换的参数。

将下括号通道中的小对象与散布在网格中的模板形状做归一化匹配，用模板与对象的面积比作为放大倍率，将放大后的对象传送到上括号通道并底边对齐。

**输入结构**：约 20x25 的网格，黑(0)背景。一种边框色（如蓝(1)）在网格顶部边缘形成一个向下开口的括号框（上括号），在底部边缘形成一个向上开口的括号框（下括号），两个括号的内部列跨度不同。下括号的内部列范围内有一个小型 4-连通单色对象（2~4 像素，非边框色非黑），位于下括号内部某处。网格中另有 2~3 个与该对象颜色不同的独立模板形状（各自单色，4-连通，4~16 像素），其中恰好一个的归一化形状（将 mask 缩放到最小边界框后的二值形态）与下括号中对象的归一化形状相同。生成约束：匹配的模板边界框面积是对象边界框面积的整数倍（4 倍或 9 倍，即线性放大 2 倍或 3 倍）；放大后的对象宽度不超过上括号的内部列跨度。

**规则**：
1. 识别下括号内部的小对象及其边界框。
2. 对网格中每个独立的非括号、非通道内对象（模板候选），计算其归一化 mask（在最小边界框内的二值形态）。
3. 找到与下括号对象归一化 mask 相同的唯一模板。
4. 计算放大倍率 k = sqrt(模板边界框面积 / 对象边界框面积)，结果为整数（2 或 3）。
5. 将对象的每个像素放大为 k x k 的方块，颜色改为匹配模板的颜色。
6. 从原始位置擦除该对象。
7. 将放大后的对象放置在上括号的内部列范围中，水平居中（若不能精确居中，偏左），边界框底边对齐到网格底边。
8. 保留括号框结构和所有模板形状不变。

**关键洞察**：形状匹配是归一化的（忽略大小和颜色），因此匹配逻辑与放大逻辑互为前置——你必须先匹配才能知道放大多少倍，而放大比例恰好是匹配对暗示的面积比。

## 新题 7：交替翻转展开后的原型匹配与区间涂色

**组合逻辑**：[波形图案 + 交替翻转 + 单行重叠拼接](创新：翻转展开不是最终输出，而是用来构造匹配判据) → [模式匹配 + 匹配槽位重涂](创新：匹配的不是原始 mask 而是展开后的 mask) → [夹间区域 + 匹配间槽位另色](已有)

**来源原语**：波形图案/交替翻转/单行重叠拼接/堆叠(eb281b96)、模式匹配/符号槽位/原型/匹配槽位重涂/夹间区域/匹配间槽位另色/分隔线(d94c3b52)

**依赖链**：每个槽位的小图案经交替翻转展开后生成一个"展开签名" → 以青色原型的展开签名为目标 → 展开签名匹配的槽位重涂青色 → 行/列内连续匹配槽位之间的夹间槽位涂橙色。匹配判据依赖于一个看不见的中间表示（展开后的形态），使得视觉上不同的原始图案可能产生相同的展开签名。

将符号表格中每个槽位的图案做一次"原件+垂直翻转"的单行重叠展开，用展开后的形态代替原始形态与青色原型比对，匹配的槽位涂青色，行列间连续匹配槽位的夹间槽位涂橙色。

**输入结构**：约 22x22 的网格。黑(0)单像素线将网格分割为 4x4 或 5x5 的符号槽位表格，每个槽位为 4x4 像素。每个槽位内可能为空（全黑）或包含一个由某种非黑颜色绘制的小图案（2~3 行高、2~4 列宽的连续或近连续形状）。恰好一个槽位的图案是青(8)色，为原型。其余占用槽位的图案各自使用不同的非黑非青颜色。生成约束：至少 2 个非青槽位的图案经"原件 + 垂直翻转 + 单行重叠"展开后，其二值 mask 与青色原型的展开 mask 相同（虽然原始图案可能视觉上与原型不同）；表格中至少有一行或一列包含两个匹配槽位且之间夹有非空槽位。

**规则**：
1. 对每个非空槽位的图案 P（高 h 行），构造其展开形态：将 P 垂直翻转得到 P'，将 P 和 P' 以最后一行与第一行重叠的方式拼接，得到高为 2h-1 的展开图案 E(P)。取 E(P) 的二值 mask（忽略颜色）。
2. 对青(8)原型执行相同展开，得到 E(proto) 的二值 mask。
3. 任何槽位若 E(P) 的 mask 与 E(proto) 的 mask 相同（在最小边界框内逐像素比对），将该槽位的图案像素全部重涂为青(8)。
4. 在表格的每一行中，找到所有匹配槽位（含原型自身）。对于同一行内两个相邻匹配槽位之间的所有非空槽位（严格在两者之间，不含端点），将其图案像素重涂为橙(7)。
5. 在表格的每一列中执行相同操作。
6. 空槽位始终保持为空。分隔线始终保持黑色。若某槽位同时被行规则和列规则涂为橙(7)，不冲突（均为橙色）。

**关键洞察**：两个视觉上截然不同的小图案，经交替翻转展开后可能具有完全相同的二值轮廓——匹配判据藏在一个看不见的中间变换中，求解者必须从示例中反推出"先展开再比对"这一非直觉步骤。

## 新题 8：骨架对齐传播标注到镂空体内部

**组合逻辑**：[矩形镂空体 + 擦除](创新：尾部擦除不是最终操作，而是为暴露内部骨架做准备) → [骨架对齐 + 锚点像素 + 旋转/镜像](已有) → [印章覆盖 + 完整标注传递副本](创新：印章区域被镂空体的矩形边界裁剪) → [视线可达](创新：标注像素只在镂空体开口方向一侧可见，另一侧被墙壁遮挡而不绘制)

**来源原语**：矩形镂空体/擦除(3d588dc9)、骨架对齐/锚点像素/旋转/镜像/精灵体/印章覆盖/完整标注传递副本(36d67576)、视线可达(3d588dc9)

**依赖链**：尾部擦除暴露镂空体内部的完整骨架 → 骨架对齐在镂空体之间建立旋转/翻转映射 → 标注从完整标注的镂空体传播到其他镂空体 → 但标注像素受镂空体矩形壁约束：只有从开口方向可见的标注位置才被绘制，被内壁遮挡的位置丢弃。空间容器（镂空体）同时是标注传播的载体和裁剪器。

擦除每个矩形镂空体的尾部后，利用内部骨架的锚点像素对齐各镂空体间的旋转关系，将完整标注体的装饰色传播到其他镂空体，但每个标注像素仅在从镂空体开口方向"可见"时才保留。

**输入结构**：约 25x25 的网格，背景为占主导的浅色（如灰(5)）。网格中有 3~4 个黑(0)的矩形镂空体——每个由一个实心黑色矩形（约 6x6 至 8x8）加上一条 2 像素的黑色尾巴构成，尾巴从矩形的某一边中央向外延伸（表示开口方向的反面，即尾巴所在侧为封闭侧，对侧为开口侧）。每个镂空体的矩形内部挖空为背景色，内部绘有一个由蓝(1)像素组成的小型骨架图案（3~5 像素，4-连通）和一个红(2)锚点像素。恰好一个镂空体在骨架上还附加了其他颜色的标注像素（如绿(3)、黄(4)），这是完整标注体。其余镂空体只有骨架和锚点。生成约束：所有镂空体内的骨架是同一图案的旋转/翻转变体（dihedral 群）；锚点在骨架中的局部位置固定；标注像素不与矩形内壁相邻。

**规则**：
1. 擦除每个镂空体的 2 像素尾巴（将尾巴像素改为背景色）。尾巴原来所在的侧为封闭侧，对侧为开口侧。
2. 以完整标注体为源模板。对每个非标注镂空体，找到唯一的旋转/反射变换使得源模板的蓝(1)骨架和红(2)锚点与目标镂空体的骨架和锚点重合。
3. 将源模板中所有非骨架、非锚点的标注像素位置通过该变换映射到目标镂空体的局部坐标系中。
4. 对每个映射后的标注位置 (r, c)，判断它是否位于目标镂空体矩形内部。若不在内部，丢弃。
5. 若在内部，进一步判断：从该位置沿开口方向（水平或垂直）到矩形边界之间是否有骨架像素阻挡。若无阻挡（视线畅通到开口边），绘制该标注像素。若有阻挡，丢弃。
6. 保留所有骨架、锚点和矩形边框。完整标注体自身保持不变。

**关键洞察**：骨架对齐和镂空体开口方向形成双重约束——对齐告诉你标注"应该"在哪里，但镂空体的开口方向过滤掉被自身骨架遮挡的标注位置，使得同一套标注在不同朝向的镂空体中呈现不同的可见子集。
