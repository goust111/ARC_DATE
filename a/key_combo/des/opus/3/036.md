## 新题 1：对角射线命中计数选腔

**组合逻辑**：[射线延伸·对角线激活](创新：从源像素出发沿对角方向射线) → [计数](创新：统计射线穿过各轮廓内腔的命中数) → [面积匹配→命中匹配](创新：选择标准从面积相等改为命中数相等) → [填充 + 擦除]

**来源原语**：射线延伸/对角线激活(d07ae81c), 计数(7acdf6d3/d631b094), 轮廓对象/行内腔/面积匹配(7acdf6d3), 填充/擦除(7acdf6d3)

**依赖链**：对角射线路径决定了哪些轮廓内腔被命中，命中计数提供了选择目标轮廓的判据（替代原始的面积匹配），被选中的轮廓才执行填充。删除射线步骤则无法确定目标轮廓，删除计数则退化为无选择标准的填充。

将源像素群的对角射线穿透各轮廓内腔，以命中总数等于源像素数量为条件锁定唯一目标轮廓，擦除源像素并将目标内腔涂为源色。

**输入结构**：黑(0)背景，约 20x20 网格。网格中有 3~5 个不同颜色的 8-连通轮廓对象（如蓝(1)、绿(3)、橙(7)的闭合框），每个轮廓是单色的闭合边界，内部为黑(0)背景像素，各轮廓的行内腔面积互不相同（约 3~12 像素）。另有一簇红(2)源像素（3~8 像素的 4-连通小图形），位于所有轮廓之外，与任何轮廓不相邻。生成约束：恰好一个轮廓的内腔被源像素的全部对角射线命中的次数等于源像素总数，其余轮廓的命中数均不等于源像素总数。

**规则**：
1. 识别所有 8-连通单色轮廓对象及其行内腔（每行中最左与最右轮廓像素之间的背景像素）。
2. 识别红(2)源像素集合，记录其总数 N。
3. 从每个红(2)源像素出发，沿四条对角方向（NE、NW、SE、SW）向网格边界延伸射线，射线仅用于计数，不改变任何像素颜色。
4. 对每个轮廓对象，统计其行内腔中被对角射线经过的像素总次数（同一像素被多条射线经过则累加计数）。
5. 选出行内腔命中总次数恰好等于 N 的唯一轮廓作为目标。
6. 将所有红(2)源像素擦除为黑(0)。
7. 将目标轮廓的行内腔全部填充为红(2)。

**关键洞察**：目标轮廓不是通过面积直接匹配选出的，而是由源像素的空间位置通过对角射线间接编码的——移动源像素群的位置会改变命中模式，从而可能改变目标轮廓。

## 新题 2：角标编码旋转的格点补全

**组合逻辑**：[格点对齐](已有) → [角落对应·编码映射](创新：角标位置编码旋转角度而非象限颜色) → [旋转](已有) → [补全·笛卡尔积缺位填充](创新：填充物是旋转变体而非同形副本)

**来源原语**：同形精灵体/行列格点/格点对齐/笛卡尔积缺位填充(5b526a93), 角落对应/标记色映射象限(e9ac8c9e), 旋转/四旋转变体组拼图(46442a0e), 编码映射(67c52801)

**依赖链**：格点对齐确定哪些槽位缺失，但填充内容不是简单复制——每个槽位需要特定旋转角度的精灵体。旋转角度由已有精灵体的角标像素位置编码（角标在精灵体包围盒的哪个角），需从已有槽位归纳出"行递增列递增"的旋转规律，才能推断缺失槽位的旋转角度。删除角标解读则无法确定旋转，删除格点对齐则不知道哪些槽位缺失。

在不完整的精灵体格点阵列中，根据已有精灵体角标像素所编码的旋转状态归纳行列旋转规律，将缺失槽位补全为正确旋转角度的精灵体副本。

**输入结构**：黑(0)背景，约 18x18 网格。一种前景色（如蓝(1)）构成若干形状相同的 4-连通精灵体（3~6 像素，非矩形），排列在一个 3x3 或 4x3 的矩形格点上，部分格点槽位为空（缺失 2~4 个槽位）。至少有一整行和一整列是完整的。每个已有精灵体的包围盒四角之一恰好有一个灰(5)标记像素（位于精灵体包围盒外侧对角方向 1 格处）。灰(5)标记所在的角位置在同一行内按固定步进递增（如左上→右上→右下→左上...循环），同一列内也按固定步进递增。生成约束：行步进和列步进均为 0、1、2、3 中的某个值（代表 0/90/180/270 度旋转增量），且行步进与列步进的组合使得整个格点中不出现矛盾。

**规则**：
1. 从已有精灵体中提取精灵体掩模（以任一精灵体为基准取 0 度形态）。
2. 定义角标位置到旋转角度的映射：左上角 = 0 度，右上角 = 顺时针 90 度，右下角 = 180 度，左下角 = 逆时针 90 度。
3. 读取已有精灵体的角标位置，确定各槽位的旋转角度。
4. 沿行方向和列方向分别归纳旋转增量（相邻槽位旋转角度之差 mod 360）。
5. 对每个空槽位，由其行列坐标通过行增量和列增量推算旋转角度。
6. 在空槽位放置精灵体掩模的对应旋转版本（用青(8)着色以区分原有精灵体），并在对应角位置放置灰(5)标记。

**关键洞察**：角标像素不是装饰而是旋转状态的空间编码；行列方向各有独立的旋转增量，必须从多个已有精灵体联立推断才能确定缺失槽位的旋转角度。

## 新题 3：间隙二分后的局部位置重涂色

**组合逻辑**：[射线延伸·间隙对半分](已有) → [局部位置分类](创新：作用于间隙填充产生的新矩形而非原有矩形) → [重涂色](创新：颜色方案由间隙奇偶性决定)

**来源原语**：射线延伸/间隙对半分/奇数间隙留中线(d968ffd4), 局部位置分类/角边内部分别涂色(b6afb2da), 重涂色(b6afb2da/a8d7556c)

**依赖链**：间隙二分决定了填充半块的形状（宽度取决于间隙的一半），而局部位置分类（角/边/内部）的结果取决于这个形状。间隙宽度不同则分类结果不同。进一步，间隙奇偶性（是否存在中线）决定了角/边/内部映射到哪种颜色。删除二分步骤则无几何体可分类，删除分类步骤则退化为简单的均匀填充。

将对齐矩形对之间的间隙二分填充后，对每个填充半块按角/边/内部分类重涂色，涂色方案由间隙宽度的奇偶性切换。

**输入结构**：黑(0)背景，约 20x15 网格。包含 3~4 对同色同尺寸实心矩形（高度和宽度均至少 2），每对共享相同的行区间或列区间，两矩形之间有黑(0)间隙。不同对的间隙宽度不同，有奇有偶（宽度范围 3~8）。不同对使用不同颜色（如蓝(1)、绿(3)、橙(7)），各对之间不重叠、不相邻。矩形对的方向（水平排列或垂直排列）在同一题内可不同。

**规则**：
1. 识别每对同色、同尺寸、共享行区间或列区间的矩形。
2. 计算每对之间的间隙宽度 G（沿对齐方向上两矩形内侧边之间的距离）。
3. 按间隙对半分规则填充：沿垂直于对齐方向的全跨度，将间隙的前半填充为靠近第一个矩形的颜色，后半填充为靠近第二个矩形的颜色。当 G 为奇数时，中间一行/列保留黑(0)。
4. 对每个填充半块（视为独立的矩形区域），执行局部位置分类：
   - 若 G 为偶数：四角像素涂蓝(1)，剩余边缘像素涂黄(4)，严格内部像素涂红(2)。
   - 若 G 为奇数：四角像素涂红(2)，剩余边缘像素涂蓝(1)，严格内部像素涂黄(4)。
5. 原始矩形及间隙外的像素保持不变。
6. 若填充半块的某维度为 1（即半块为一行/列宽），该半块全部视为边缘，无内部像素。

**关键洞察**：涂色方案不是固定的，而是由间隙奇偶性切换——必须对比多个不同间隙宽度的示例才能发现这一隐蔽规则。

## 新题 4：过滤干扰后的条段延伸与长度优先交叉

**组合逻辑**：[筛选·忽略干扰项](创新：过滤标准从矩形尺寸改为条段连通长度) → [射线延伸](已有) → [交叉·重涂色](创新：交叉优先级由原始条段长度而非固定规则决定)

**来源原语**：筛选/忽略干扰项/最小尺寸过滤(0a1d4ef5), 射线延伸(bdad9b1f), 交叉/交叉点标记新色(bdad9b1f), 横条段/竖条段(bdad9b1f), 重涂色(bdad9b1f)

**依赖链**：过滤步骤决定哪些条段是真实的（改变了后续射线延伸的输入集合）；射线延伸产生交叉点；交叉点的着色需要回溯到过滤后各条段的原始长度做比较。三步形成环形依赖——过滤结果影响交叉集合，原始长度信息又必须在过滤步骤中保留以供后续使用。

过滤掉短于阈值的干扰条段，将剩余横条段和竖条段分别延伸至网格边界，交叉点的颜色由原始较长条段决定。

**输入结构**：黑(0)背景，约 15x15 网格。包含 2~3 条不同颜色的横条段（1 像素高、长度 2~6 像素的水平连通前景像素）和 2~3 条不同颜色的竖条段（1 像素宽、长度 2~6 像素的垂直连通前景像素）。另有若干单像素或 2 像素的零散干扰点（颜色可与条段相同或不同）分布在网格中。所有横条段的行坐标互不相同，所有竖条段的列坐标互不相同。任意横条段与竖条段的行列交叉点在输入中为黑(0)。生成约束：任意两条真实条段（过滤后保留的）原始长度互不相等，从而交叉点着色无歧义。

**规则**：
1. 识别所有 4-连通的水平和垂直前景线段。
2. 过滤：移除长度小于 3 像素的线段（视为干扰），保留长度 >= 3 的线段作为真实条段。
3. 记录每条真实条段的原始长度 L。
4. 将每条横条段沿其所在行延伸至网格左右边界，填充为该条段颜色。
5. 将每条竖条段沿其所在列延伸至网格上下边界，填充为该条段颜色。
6. 在横条段行与竖条段列的交叉像素处：取两条相交条段中原始长度 L 更大的那条的颜色。
7. 干扰点（已过滤的短线段和单像素）从输出中擦除为黑(0)。

**关键洞察**：交叉点的颜色不是由任意一方固定决定的，而是由两条相交条段的原始长度（延伸前）比较决定——延伸改变了条段的视觉长度，但优先级依据的是原始长度，需要在延伸前记住。

## 新题 5：对称恢复的隐藏模板用于排序拼接

**组合逻辑**：[对称补全·可见副本恢复遮挡](已有) → [裁剪](已有) → [排序拼接·按位置排序标记](创新：被拼接的模板不是输入中显式给出的，而是从遮挡下恢复的)

**来源原语**：对称补全/二面体对称/遮挡矩形/可见副本恢复遮挡(f4081712), 裁剪/排序拼接/单像素标记/标记共行或共列/按位置排序标记(12997ef3), 重涂色(12997ef3)

**依赖链**：模板不是直接给出的，必须先通过二面体对称恢复被遮挡区域才能获得；恢复出的区域裁剪后成为拼接的基本单元；标记像素决定拼接顺序和重涂色颜色。删除对称恢复则模板未知，删除标记排序则拼接顺序未知。

从二面体对称图案中恢复被遮挡的矩形区域作为模板，按共行/共列标记像素的位置顺序，拼接该模板的多份重涂色副本。

**输入结构**：黑(0)背景，约 15x15 网格。网格中心有一个在旋转和反射下具有二面体对称性的彩色图案（使用 2~3 种前景色，如蓝(1)和橙(7)），图案占据约 9x9~11x11 区域。图案上有一个绿(3)实心矩形遮挡区域（约 3x4 像素），遮盖了图案的一部分。图案外围（不与图案相邻）有 2~4 个单像素标记，颜色各不相同（如红(2)、黄(4)、灰(5)），且这些标记共享同一行或同一列。生成约束：被遮挡区域的每个像素至少有一个对称等价位置未被遮挡。

**规则**：
1. 识别绿(3)矩形遮挡区域的包围盒。
2. 对遮挡区域内每个像素，检查其在二面体对称群（4 次旋转 + 4 次反射）下的所有等价坐标，取未被遮挡的等价位置的颜色作为恢复色。
3. 将恢复后的遮挡区域裁剪为独立的矩形色块，作为模板 T。
4. 识别图案外围的单像素标记，判断它们共享行还是共享列。
5. 共享行时按列坐标从左到右排序，共享列时按行坐标从上到下排序。
6. 对每个排序后的标记，生成一份模板 T 的副本，将副本中所有非黑(0)像素重涂为该标记的颜色。
7. 按排序顺序将这些重涂副本水平拼接（共享行时）或垂直拼接（共享列时），输出拼接结果。

**关键洞察**：拼接的模板在输入中是不可见的——它藏在遮挡之下，只有先完成对称恢复才能获取；这使得"排序拼接"不再是对显式模板的简单操作，而是与空间推理深度耦合。

## 新题 6：等差递推的缩放锚点印章

**组合逻辑**：[等差递推](创新：控制的不是边框笔画而是锚点位置和缩放倍率) → [缩放·尺寸比编码缩放](已有) → [印章放置](已有) → [裁剪·画布裁切可见](已有)

**来源原语**：等差递推/等差序列/画布裁切可见(f8c80d96), 缩放/尺寸比编码缩放/锚点方块/图案母题/印章放置(b10624e5)

**依赖链**：等差递推同时决定了新锚点的位置和缩放倍率（两者耦合在同一个递推关系中），缩放倍率决定印章大小，位置决定印章放置处，画布边界决定是否可见。删除等差递推则无法预测新锚点，删除缩放则印章尺寸错误。

从已有的若干不同缩放倍率的母题副本中归纳锚点位置和缩放倍率的等差规律，沿递推方向继续放置新的缩放副本，直到下一个副本完全超出画布。

**输入结构**：黑(0)背景，约 25x25 网格。包含同一母题的 3 份副本，母题是一个约 3x3 像素的非对称单色小图形（如品红(6)）。每份副本附着于一个红(2)实心正方形锚点块，锚点块的边长分别为 1、2、3（或 2、3、4 等连续整数）。母题相对于锚点的位置固定（如始终在锚点的右上方），母题的缩放倍率等于锚点边长与最小锚点边长之比（即 1x、2x、3x）。三个锚点的中心坐标形成等差数列（行坐标差和列坐标差分别恒定）。生成约束：沿等差方向至少还能再放 1 个副本（部分或全部在画布内），但再下一个副本必须完全在画布外。

**规则**：
1. 识别所有红(2)正方形锚点块，按边长从小到大排序，记录其中心坐标序列和边长序列。
2. 验证中心坐标形成等差数列（行差 dr、列差 dc 恒定），边长形成等差数列（公差 ds 恒定，通常 ds=1）。
3. 从最小锚点的副本中提取母题掩模（锚点周围的非背景、非红(2)像素相对于锚点中心的偏移）。
4. 沿等差方向逐步外推：下一个锚点中心 = 最后一个中心 + (dr, dc)，下一个边长 = 最后边长 + ds。
5. 对每个外推位置，按当前边长与最小边长之比缩放母题掩模（最近邻缩放），将缩放后的母题和新锚点绘制到网格上。
6. 仅绘制落在网格内的像素，超出边界的部分裁切。
7. 当某一步的锚点块和缩放母题完全位于网格外时停止。
8. 同方向的反向也检查一次：如果反向外推可以产生边长 >= 1 的锚点且至少部分在画布内，也绘制之。

**关键洞察**：位置递推和尺寸递推共享同一个等差结构，求解者必须同时从空间坐标和锚点大小两个维度归纳出同一条等差规律——单看位置或单看尺寸都无法确定完整的外推参数。

## 新题 7：十字臂穿越间隙时的二分填充

**组合逻辑**：[补全·十字图案](创新：十字臂不再仅涂基底色，而是在穿越间隙时触发二分填充) → [间隙对半分](创新：二分操作由十字臂激活，沿十字臂中心线进行) → [填充](已有)

**来源原语**：补全/十字图案/标记推断十字涂底/行列对齐(50846271), 射线延伸/间隙对半分/奇数间隙留中线(d968ffd4), 矩形(d968ffd4), 填充(7acdf6d3)

**依赖链**：十字臂的补全方向和长度决定了十字臂是否穿越矩形对之间的间隙；只有被十字臂穿越的间隙才执行二分填充；二分填充的跨度等于十字臂的宽度（1 像素）乘以间隙在十字臂垂直方向的全跨度。删除十字补全则不知道哪些间隙需要填充，删除二分规则则间隙填充方式不确定。

补全不完整的十字图案臂，当十字臂穿过一对对齐矩形之间的间隙时，沿十字臂将间隙二分填充为两侧矩形的颜色。

**输入结构**：黑(0)背景，约 18x18 网格。灰(5)基底像素覆盖网格的大部分区域（但不是全部，有些黑(0)区域）。若干红(2)标记像素分布在灰(5)区域中，定义了 2~3 个不完整的等臂十字图案（共享同一半径 R，约 2~3）。另有 2~3 对同色同尺寸实心矩形（颜色如蓝(1)和绿(3)），各对共享行区间或列区间，两矩形之间有灰(5)或黑(0)间隙（宽度 3~7）。十字臂的行/列恰好穿过某些矩形对的间隙区域。生成约束：每个十字至少穿过一个间隙，每个间隙至多被一个十字臂穿过。

**规则**：
1. 从红(2)标记像素归纳十字半径 R（最大的完整臂跨度的一半，向下取整）。
2. 在灰(5)区域中寻找半径 R 的十字掩模——掩模的全部非越界像素均为非黑(0)，且该掩模的行和列各含有红(2)证据。
3. 选取能解释全部红(2)标记的最小十字集合，将这些十字掩模中的灰(5)像素涂为青(8)（十字补全步骤）。
4. 对每个已补全的十字臂（水平或垂直），检查该臂所在行/列是否穿过某对矩形之间的间隙。
5. 若穿过：沿十字臂方向将间隙一分为二，靠近第一个矩形的半侧填充为第一个矩形的颜色，靠近第二个矩形的半侧填充为第二个矩形的颜色。填充仅在间隙区域内进行，沿垂直于十字臂方向覆盖矩形的全行区间/全列区间。间隙宽度为奇数时中间一行/列保留原色。
6. 十字臂像素本身不被间隙填充覆盖（十字臂优先）。

**关键洞察**：十字补全和间隙填充不是独立的两步——十字臂既是补全的对象，又是间隙填充的触发器和空间定位器。间隙是否被填充、填充的方向，全部由十字臂的空间位置隐式决定。

## 新题 8：压缩色格的颜色计数匹配内腔填充

**组合逻辑**：[筛选·最小尺寸过滤 + 压缩·包围盒行列分组](已有) → [计数](创新：计数对象从前景像素改为压缩色格中的同色单元) → [面积匹配·像素数等于腔面积](创新：匹配的一端来自压缩结果) → [填充](已有)

**来源原语**：筛选/最小尺寸过滤/忽略干扰项/填充矩形/包围盒行列分组/压缩(0a1d4ef5), 计数/填充/擦除/轮廓对象/行内腔/面积匹配/像素数等于腔面积(7acdf6d3)

**依赖链**：压缩步骤将散落的矩形格子聚合为紧凑色格，色格中每种颜色的单元数成为后续匹配的关键参数；轮廓内腔面积与色格颜色计数匹配才决定填充目标和颜色。删除压缩则无法得到颜色计数，删除面积匹配则无法确定哪个内腔填充哪种颜色。

先将大矩形格子（过滤干扰后）压缩为紧凑色格，再统计色格中每种颜色出现的次数，将次数与各轮廓对象的内腔面积配对，匹配成功的内腔填充为对应颜色。

**输入结构**：黑(0)背景，约 22x22 网格。分为两个区域（上半区和下半区，或左半区和右半区）。一个区域包含若干单色填充矩形（每个至少 3x3），排列成行列格子，其中穿插一些小于 3x3 的零散干扰像素。填充矩形使用 3~4 种颜色（如蓝(1)、绿(3)、黄(4)、橙(7)），排列为 2x3 或 3x3 格子。另一区域包含若干不同颜色（灰(5)或品红(6)）的 8-连通轮廓框（闭合边界），各框的行内腔面积互不相同。生成约束：压缩色格中每种颜色的出现次数恰好与某一个轮廓框的内腔面积相等，且这种匹配是一一对应的（无歧义）。干扰像素的颜色可以与矩形颜色相同，但尺寸小于 3x3 且不能恰好填满其包围盒。

**规则**：
1. 在矩形区域中，保留所有至少 3x3 且恰好填满其包围盒的单色 4-连通矩形，移除其余像素（干扰）。
2. 将保留的矩形按包围盒的行区间和列区间分组，相同行区间归为同一输出行，相同列区间归为同一输出列，形成紧凑的 M x N 色格。
3. 统计色格中每种颜色出现的单元数：color_count(c) = 色格中颜色 c 的单元数。
4. 在轮廓区域中，识别所有 8-连通轮廓框，计算每个框的行内腔面积 A（每行中最左与最右轮廓像素之间的非轮廓像素数之和）。
5. 对每种颜色 c，若存在唯一一个轮廓框的 A = color_count(c)，则将该框的行内腔全部填充为颜色 c。
6. 无法匹配的轮廓框保持不变。

**关键洞察**：填充颜色不是由轮廓框自身的属性决定的，而是由远处的矩形格子压缩后的颜色统计决定的——两个空间上分离的结构通过数值匹配产生了跨区域的信息传递。

## 新题 9：镜像反射后的对角线射线涂底

**组合逻辑**：[镜像·镜像对应](创新：反射标记位置到对侧) → [射线延伸·对角线激活](已有) → [重涂色·底色决定涂色](已有) → [擦除](已有)

**来源原语**：镜像/镜像对应/分隔列/反射跨度匹配重涂(dd2401ed), 射线延伸/对角线激活/基底色区域/底色决定涂色(d07ae81c), 重涂色(d07ae81c), 擦除(dd2401ed), 标记像素(d07ae81c/dd2401ed)

**依赖链**：标记像素需要先经过镜像反射才能确定对角射线的发射位置；对角射线的路径穿越不同的底色区域，底色区域的颜色决定了射线经过处的涂色；镜像位置与底色区域的交集决定了最终哪些像素被改变。删除镜像则射线位置错误，删除底色判断则涂色规则退化为单一颜色。

将标记像素镜像反射到分隔线对侧，从反射后的位置发射对角射线，射线经过的底色像素按底色-标记色配对规则重涂色。

**输入结构**：黑(0)背景，约 16x16 网格。一条灰(5)全高垂直分隔线将网格分为左右两半。左半区域被两种底色（如蓝(1)和绿(3)）大面积填充，形成不规则的色块分界。右半区域同样被两种底色填充（可以与左半相同或不同的分区方式）。左半区域中有 2~3 个单像素标记（颜色为红(2)、黄(4)等），嵌入在底色中。每个标记的颜色与其所在位置的底色形成固定配对（如标记红(2)总在蓝(1)底色上，标记黄(4)总在绿(3)底色上），配对关系只能通过多个示例归纳。右半区域无标记。生成约束：每种底色恰好与一种标记色配对。

**规则**：
1. 识别灰(5)分隔线的列坐标 k。
2. 对每个左半区域中的标记像素 (r, c)，计算其镜像位置 (r, 2k - c)（关于分隔线对称）。
3. 从每个镜像位置出发，沿四条对角方向（NE、NW、SE、SW）向网格边界延伸射线。
4. 射线路径上的每个像素，若其原始颜色为两种底色之一，则重涂为该底色所配对的标记色。
5. 射线路径上的非底色像素（包括分隔线灰(5)、其他标记、黑(0)背景）保持不变。
6. 原始标记像素保持不变，不被擦除。
7. 不同标记的射线路径重叠时，后处理的覆盖先处理的（按标记从上到下、从左到右的顺序处理）。

**关键洞察**：对角射线的发射点不在标记本身的位置，而在其镜像位置——求解者必须先完成空间反射变换才能确定射线路径；而射线的涂色规则又取决于底色-标记色配对，这一配对关系本身需要从标记所在的底色环境归纳得出。
