## 新题 1：对称缺陷定向滑移与补全

**组合逻辑**：[对称补全](创新：缺陷方位不再用于去噪而用于编码运动方向) + [滑动](创新：滑动方向由对象自身的对称缺陷决定，而非外部缺口) + [逐色独立变换](已有)

**来源原语**：对称补全(8e5c0c38)、滑动(320afe60)、逐色独立变换(e74e1818)、包围盒(e74e1818)

**依赖链**：对称分析 → 确定缺陷方位 → 缺陷方位决定滑动方向 → 滑动改变对象位置 → 在新位置上用对称补全填补缺失像素。三步紧耦合：不分析对称就不知道往哪滑，不滑就没有空间放补全像素，不补全则对象残缺。

逐色独立地将每个近对称对象滑向其完好一侧对应的网格边缘，再在新位置补全缺失的对称像素。

**输入结构**：约 15x15 的黑(0)背景网格。散布 3-4 个互不相邻的单色前景对象，每个对象使用不同的非黑颜色（如红(2)、蓝(1)、绿(3)、黄(4)），每个对象由 4-8 个 4-连通像素组成，形状不规则但在其包围盒内近似关于一条轴（水平或垂直）对称——仅有 1-2 个像素缺失导致对称不完美。不同对象的对称轴方向和缺陷方位各异。生成约束：各对象的包围盒互不重叠；对象离其将滑往的边缘方向上有足够空间（至少 2 格），且滑动后各对象及其补全像素不会互相重叠或超出网格。

**规则**：
1. 对每个非背景颜色独立处理：找到该颜色所有像素的包围盒，检测包围盒内最佳对称轴（水平或垂直，取镜像匹配像素数最多的轴）。
2. 确定"缺陷侧"——对称轴某一侧存在的像素在另一侧缺少镜像对应像素，缺少对应像素的那一侧即为缺陷侧。
3. 将整个对象沿缺陷侧的**反方向**滑动，直到对象包围盒的非缺陷侧边缘紧贴网格边界。保持垂直于滑动方向的坐标不变。
4. 在新位置上执行对称补全：对每个有对称对应位置但缺少对应像素的位置，填入该颜色的像素。
5. 多个对象的处理顺序：按包围盒左上角坐标排序（行优先，行相同则列优先）。

**关键洞察**：对象自身的对称缺陷既是运动的指令（编码方向）又是修复的蓝图（编码补全位置），两个操作共享同一个分析结果但各取所需。

## 新题 2：锚点像素引导旋转嵌入

**组合逻辑**：[嵌入填充](已有) + [旋转](创新：旋转角度不由全局对称性决定，而由锚点的相对位置对齐决定) + [尺寸匹配](已有) + [唯一槽位配对](已有)

**来源原语**：嵌入填充(5dbc8537)、旋转(2013d3e2/0e206a2e)、锚点像素(0e206a2e)、尺寸匹配(5dbc8537)、唯一槽位配对(5dbc8537)

**依赖链**：尺寸匹配将精灵体与空腔配对 → 但尺寸匹配可能对非方形腔允许 0 度和 90 度两种朝向 → 锚点的相对位置唯一确定旋转角度 → 用正确旋转后的精灵体填充空腔。尺寸匹配缩小候选、锚点消除歧义，两者联合才能唯一确定放置方式。

将带有锚点标记的精灵体旋转至锚点对齐后嵌入模板中尺寸匹配的矩形空腔。

**输入结构**：约 18x18 的网格。一个大面积的灰(5)模板区域占据网格中心偏左或偏上，模板内含 3 个矩形空腔（背景色黑(0)区域），尺寸各不相同（如 3x4、4x4、3x5），其中至少一个非方形。每个空腔的内边缘恰好有 1 个橙(7)像素（"腔锚点"），位于该空腔某条边上。模板外的黑(0)背景区域散布 3 个多色精灵体（每个精灵体由 2-3 种非黑、非灰颜色组成，4-连通，像素数 8-20），每个精灵体内部恰好有 1 个橙(7)像素（"体锚点"）。三个精灵体的包围盒尺寸（可能需旋转后）分别与三个空腔的尺寸一一匹配。生成约束：每对精灵体-空腔的锚点相对位置唯一确定一个旋转角度（0/90/180/270度）；旋转后锚点相对位置对齐是指：锚点在精灵体包围盒内的(行偏移, 列偏移)经旋转变换后等于锚点在空腔内的(行偏移, 列偏移)。

**规则**：
1. 对每个空腔，测量其高度 H 和宽度 W。
2. 对每个精灵体，测量其包围盒高度 h 和宽度 w。
3. 尺寸匹配配对：若 (h,w)=(H,W) 或 (h,w)=(W,H)，则该精灵体可填入该空腔。生成保证每个空腔恰好匹配一个精灵体。
4. 对每对匹配的精灵体和空腔，计算腔锚点在空腔内的相对坐标 (ar, ac)（相对于空腔左上角）。尝试 0/90/180/270 度旋转精灵体，计算旋转后体锚点的相对坐标。选择使体锚点旋转后相对坐标等于 (ar, ac) 的旋转角度。
5. 将旋转后的精灵体逐像素粘贴进空腔，覆盖空腔内原有内容（包括腔锚点本身被精灵体对应位置的像素覆盖）。
6. 输出为填充完成后的整个网格。

**关键洞察**：非方形空腔看似只有两种旋转选择（0度和90度），但锚点的相对位置进一步区分了它们；方形空腔有四种旋转可能，更依赖锚点定位。尺寸匹配和锚点对齐是两个独立的约束维度，缺一则有歧义。

## 新题 3：逐色镜像后涌现邻接标记

**组合逻辑**：[镜像/包围盒内翻转](已有) + [描边/mark_neighbors](创新：不再由标记色触发，而由镜像操作涌现的新空间关系触发) + [逐色独立变换](已有)

**来源原语**：镜像(e74e1818)、逐色独立变换(e74e1818)、包围盒内翻转(e74e1818)、描边(0ca9ddb6)、正交邻接(0ca9ddb6)

**依赖链**：逐色镜像改变各色层的空间布局 → 原本互不相邻的色层可能变为相邻 → 在新邻接位置生成标记像素。镜像是空间变换，标记是拓扑检测——前者的输出是后者的输入条件，且涌现效应无法通过单独的任一操作预测。

对每个颜色独立执行包围盒内垂直翻转，再在翻转导致的新异色正交邻接位置标记橙色。

**输入结构**：约 14x14 的黑(0)背景网格。含 3 种非黑前景颜色（如红(2)、蓝(1)、绿(3)），每种颜色形成一个连通或非连通的掩码图案（每色 6-12 像素）。关键约束：在输入中，任意两种不同前景颜色之间**不存在**正交邻接（4-连通方向上相邻的两个非黑像素必然同色）。各颜色掩码的包围盒可以重叠（即不同颜色的像素可以在同一行/列出现，但被黑像素隔开）。每个颜色掩码关于其包围盒内某条水平或垂直轴近似对称，但无需完美对称。

**规则**：
1. 对每种非背景颜色，独立执行包围盒内垂直翻转：找到该颜色所有像素的包围盒（顶行 r0、底行 r1），将每个像素的行坐标 r 映射为 r0 + r1 - r，列坐标不变。
2. 所有颜色翻转完毕后，扫描整个网格：若某个像素的颜色 A（非黑）与其某个正交邻居（上下左右）的颜色 B（非黑、非 A）不同，则该对 (A, B) 构成一个"新邻接"。
3. 对于每个新邻接对 (A, B)：找到所有同时与颜色 A 的像素正交相邻且与颜色 B 的像素正交相邻的**黑(0)背景像素**，将其涂为橙(7)。
4. 若某个应被涂橙(7)的位置已被非黑前景色占据，则前景色优先保留，不涂橙。
5. 输出包含翻转后的各色层和新增的橙(7)标记。

**关键洞察**：输入中各色层被精心分隔以确保无异色邻接，但垂直翻转重排了像素位置后，原本的间隔可能消失。求解者需要先对所有颜色独立做翻转的心理模拟，才能判断哪些位置会出现新的跨色邻接，进而确定橙色标记的位置。

## 新题 4：带边框反弹的面板序列外推

**组合逻辑**：[序列外推](创新：外推不再是简单平移延续，而受边框几何条件修改) + [镜像](创新：不作用于图案本身，而作用于运动矢量的分量) + [缺口决定方向](创新：缺口不决定滑动方向，而决定哪个方向不反弹)

**来源原语**：序列外推(351d6448)、面板帧(351d6448)、恒定偏移平移(351d6448)、镜像(93c31fbe)、缺口决定方向(320afe60)、边框缺口(320afe60)

**依赖链**：前四帧确定恒定偏移矢量 → 第五帧的目标位置由外推得到 → 边框几何（哪些边封闭、哪条边有缺口）决定是否发生反弹 → 反弹修改目标位置和/或精灵朝向。外推提供初始预测，边框提供边界条件，两者联合才能得到正确的第五帧。

从四帧动画序列中外推下一帧，但精灵体遇到封闭边框会反弹，通过缺口则自由通过。

**输入结构**：约 9x35 的竖长网格。由 4 个等高（约 9x9）面板上下堆叠，面板之间由单行灰(5)分隔行隔开。每个面板内部：黑(0)背景，沿 3 条边各有一行蓝(1)像素构成的边框（第 4 条边无边框，即"缺口"），以及 1 个小的红(2)精灵体（2x2 的 4-连通小图形）位于面板内部。四帧中的边框形状完全相同（缺口始终在同一条边）。精灵体在四帧之间以恒定偏移 (dr, dc) 平移。生成约束：精灵体在前四帧中均未接触任何边框像素；但按恒定偏移继续平移时，精灵体在第五帧会碰到某条封闭边框边。

**规则**：
1. 识别四个面板及其分隔行。提取每帧中精灵体的位置（以精灵体包围盒左上角在面板内的坐标表示）。
2. 计算相邻帧之间的恒定偏移量 (dr, dc)。验证三个间隔的偏移一致。
3. 将偏移量施加于第四帧精灵体位置，得到第五帧的"候选位置"。
4. 检查候选位置是否导致精灵体的任何像素落在封闭边框上或超出封闭边框之外：
   - 若碰到上方或下方封闭边框：将 dr 取反（反弹），重新计算精灵体行坐标为边框内侧行 +/- 溢出距离的镜像值。
   - 若碰到左方或右方封闭边框：将 dc 取反（反弹），重新计算精灵体列坐标为边框内侧列 +/- 溢出距离的镜像值。
   - 若碰到缺口方向的边界：精灵体自由通过，不反弹，直接截断超出面板范围的部分（保留面板内的像素）。
5. 输出为单个面板大小的网格，包含第四帧的边框布局和反弹/通过后的精灵体。

**关键洞察**：仅凭前四帧的恒定平移可以外推出一个候选位置，但这个候选位置是错的——边框结构修改了运动规则。缺口决定哪个方向"不设防"，封闭边则触发反弹。求解者必须同时理解运动模式和边界条件。

## 新题 5：三层掩码频率加权叠加

**组合逻辑**：[透明叠加](创新：从二层扩展到三层，合并规则从简单并集变为频率加权仲裁) + [频率比较](创新：不再选择裁剪区域，而用于解决叠加冲突) + [裁剪](已有，用于分离面板)

**来源原语**：透明叠加(ce4f8723)、分隔行(ce4f8723)、前景掩码(ce4f8723)、并集合并(ce4f8723)、频率比较(a6953f00)、重复色或稀有色(a6953f00)、裁剪(a6953f00)

**依赖链**：三层掩码逐格对齐 → 重叠分类（0/1/2/3层前景）→ 双层重叠需要频率仲裁 → 频率统计来自整个输入网格 → 仲裁结果决定输出颜色。叠加的拓扑结构决定何时需要频率仲裁，频率仲裁决定叠加的输出——两个逻辑交织在每个像素的决策中。

三个分隔行分开的等高掩码逐格对齐叠加，单层保留、双层冲突由全局颜色稀有度仲裁、三层全交则变黑。

**输入结构**：约 7x20 的竖长网格。两条单行品红(6)分隔行将网格分为三个等高的区域（每个约 7x6）。三个区域共享同一背景色黑(0)，每个区域各有一种独特的非黑前景色（如红(2)、蓝(1)、绿(3)），形成不规则的连通掩码图案（每色 8-15 像素）。三种前景色互不相同。生成约束：存在至少 2 处双层重叠（两种前景色在对齐后的同一位置都有前景像素）和至少 1 处三层重叠；三种前景色在整个输入网格中的总像素数各不相同，以确保频率比较无平局。

**规则**：
1. 移除两条品红(6)分隔行。将三个区域逐格对齐（它们具有相同的行列尺寸）。
2. 统计整个输入网格（含分隔行）中三种前景颜色各自的总像素数。
3. 对于对齐后的每个格位 (r, c)：
   - 若三个区域在该位置均为背景：输出背景色黑(0)。
   - 若恰好一个区域在该位置为前景：输出该区域的前景色。
   - 若恰好两个区域在该位置为前景：比较这两种前景色的全局像素数，输出像素数**更少**（更稀有）的那种颜色。
   - 若三个区域在该位置均为前景：输出黑(0)。
4. 输出网格尺寸等于一个区域的尺寸。

**关键洞察**：单层和三层的结果是确定性的，不需要额外信息；但双层冲突的解决方案隐含在全局颜色频率中——相同的两色冲突在不同位置总是以同一方式解决。求解者必须发现"稀有色优先"这一隐蔽规则，且仅从单个示例无法区分它与"按颜色编号排序"等替代假设。

## 新题 6：角标记区域宽高比编码旋转角度

**组合逻辑**：[旋转](创新：旋转角度不由全局对称性决定，而由包围区域的宽高比隐式编码) + [擦除](已有) + [角标记](创新：角标记不再用于确定镜像轴，而定义独立区域并通过区域几何编码旋转参数)

**来源原语**：旋转(2013d3e2)、角标记(93c31fbe)、矩形框(93c31fbe)、包围框内(93c31fbe)、宽高比决定镜像轴(93c31fbe，创新为宽高比决定旋转角)、擦除(93c31fbe)

**依赖链**：角标记定义区域边界 → 区域宽高比计算 → 宽高比决定旋转角度 → 旋转作用于区域内部图案 → 擦除角标记。角标记同时承载空间定义和参数编码双重职能，缺少角标记则既无法定位区域也无法得知旋转角度。

用 L 形角标记定义多个矩形区域，按每个区域的宽高比决定其内部图案的旋转角度，然后擦除角标记。

**输入结构**：约 22x22 的黑(0)背景网格。含 3 组角标记，每组使用不同颜色（如红(2)、蓝(1)、绿(3)）。每组由 4 个 L 形双像素角标（每个角标由 2 个同色像素组成，呈 L 形排列，分别朝向四个角方向）构成一个矩形区域的四个角。三个区域互不重叠。区域内部（角标围成的矩形范围内，不含角标本身）有一个多色图案（由 2-3 种非黑、非角标颜色的像素组成，4-连通，5-12 像素）置于黑(0)背景上。三个区域的宽高比各不相同：一个宽 > 高，一个高 > 宽，一个宽 = 高（正方形）。生成约束：宽 > 高的区域中图案经 90 度顺时针旋转后仍可放回区域（因为旋转交换了宽高，区域的 H 和 W 恰好容纳旋转后的图案包围盒）；类似地，高 > 宽的区域容纳逆时针 90 度旋转后的图案；正方形区域自然容纳 180 度旋转。

**规则**：
1. 对每种角标记颜色，找到该颜色的 4 个 L 形角标，确定它们定义的矩形区域（角标位于四角，区域为角标所围矩形的内部）。
2. 计算每个区域的宽度 W 和高度 H（内部区域的列数和行数，不含角标本身所占的行列）。
3. 旋转规则：
   - W > H（扁宽区域）：将内部图案顺时针旋转 90 度。
   - H > W（窄高区域）：将内部图案逆时针旋转 90 度。
   - W = H（正方形区域）：将内部图案旋转 180 度。
4. 将旋转后的图案放回其所属区域的中心位置（若旋转交换了图案的宽高，旋转后的包围盒在区域内居中；若区域内无法完全居中，偏向左上角）。
5. 擦除所有角标记像素（替换为黑(0)）。
6. 未被区域覆盖的网格部分保持不变。

**关键洞察**：角标记的双重角色——它们既是区域的空间界标（定义哪些像素属于哪个区域），又通过其围成的矩形几何形状（宽高比）隐式编码了作用于内部图案的旋转角度。不同于直接给出旋转指令，参数被"藏"在结构本身的几何属性中。

## 新题 7：格阵异常检测与跨瓦片连线及环绕标记

**组合逻辑**：[连线](创新：连线不在原始网格坐标系，而在瓦片格阵坐标系中按局部偏移对齐) + [标记环绕](创新：环绕标记不应用于前景区域的缺陷，而应用于格阵中的异常瓦片的偏差像素) + [异常值选择](创新：不选择单个像素异常，而选择整个瓦片级别的异常)

**来源原语**：连线(cbded52d/070dd51e)、分隔线格阵(cbded52d)、同行列对齐(cbded52d)、局部偏移保持(cbded52d)、标记环绕(71e489b6)、异常值选择(71e489b6)、邻域包围(71e489b6)

**依赖链**：瓦片多数表决 → 确定共识图案 → 识别异常瓦片 → 在异常瓦片中定位偏差像素 → 对偏差像素施加环绕标记 → 跨瓦片检查同局部偏移的偏差像素对 → 在格阵坐标系中连线。异常检测是标记和连线的共同前提，标记和连线分别处理偏差像素的局部和全局关系。

在分隔线瓦片格阵中找出偏离共识图案的异常瓦片，用橙色环绕标记其偏差像素，并在共享同一局部偏移且同行列的异常瓦片之间画连线。

**输入结构**：约 17x17 的网格，由单像素宽的灰(5)分隔线划分为 3x3 的瓦片阵列，每个瓦片约 5x5。每个瓦片内有一个红(2)图案（3-6 像素的 4-连通小图形）置于黑(0)背景上。9 个瓦片中的 6-7 个共享完全相同的图案（"共识图案"），另外 2-3 个是"异常瓦片"——它们的图案与共识图案相比，多了 1-2 个红(2)像素（"偏差像素"）位于共识图案中为黑(0)的位置。生成约束：至少存在一对异常瓦片，它们在同一瓦片行或同一瓦片列中，且各自的某个偏差像素具有相同的瓦片内局部偏移坐标。

**规则**：
1. 对 9 个瓦片按多数表决确定共识图案（出现次数最多的瓦片图案）。
2. 对每个异常瓦片，逐像素与共识图案对比，找出偏差像素（在共识图案中为黑(0)但在异常瓦片中为红(2)的位置）。
3. 对每个偏差像素，在其 8-邻域内的黑(0)像素位置涂橙(7)。橙(7)不覆盖红(2)像素和灰(5)分隔线。
4. 对每对异常瓦片，若它们处于同一瓦片行（相同的瓦片行索引）或同一瓦片列（相同的瓦片列索引），且各自拥有相同局部偏移坐标 (lr, lc) 处的偏差像素：从一个偏差像素到另一个，沿直线经过中间瓦片在同一局部偏移 (lr, lc) 处画绿(3)线段。线段经过的分隔线像素也被涂为绿(3)。绿(3)覆盖黑(0)和灰(5)，但不覆盖红(2)和橙(7)。
5. 若同一像素同时是橙(7)标记候选和绿(3)连线候选，绿(3)优先。

**关键洞察**：偏差像素在局部产生环绕标记，在全局产生跨瓦片连线——同一份异常检测的结果被两种不同的空间操作消费。连线发生在瓦片格阵坐标系中，不是原始像素坐标系中的直线，必须先理解分隔线-瓦片结构才能正确连线。

## 新题 8：缺口形态编码拼接排列与区域内滑动

**组合逻辑**：[拼接/偏移放置](创新：拼接的左右排列不是固定的，而由对象形状编码) + [滑动](创新：滑动发生在拼接后的复合画布内，方向同样由缺口决定) + [缺口决定方向](创新：缺口同时编码两个操作的参数——拼接排列和滑动方向)

**来源原语**：拼接(8618d23e)、偏移放置(8618d23e)、半区域(8618d23e)、分隔填充(8618d23e)、滑动(320afe60)、缺口决定方向(320afe60)、边框缺口(320afe60)、对角偏移(8618d23e)

**依赖链**：分析每个半区域中对象的缺口方位 → 缺口方位决定该半区域在拼接中的左/右位置 → 执行对角偏移拼接 → 在拼接后的复合画布中，将每个对象向其缺口方向滑动至区域边界。缺口这一几何特征同时参数化了宏观布局（拼接排列）和微观定位（区域内滑动），两次使用同一信息但用途不同。

根据每半区域中对象的缺口朝向决定拼接的左右排列，再将对象向缺口方向滑动到区域边缘。

**输入结构**：约 10x10 的网格，由行数恰好为偶数。上半区和下半区各含一个蓝(1)前景对象（5-10 像素的 4-连通形状）置于黑(0)背景上。每个对象的包围盒有一条边上存在背景色缺口——该边上有一段连续的黑(0)像素被对象像素从两侧夹住（如同一个凹口）。上半区对象的缺口在左侧或右侧，下半区对象的缺口也在左侧或右侧。两个对象的缺口不在同一侧。生成约束：对象在各自半区中有足够的滑动空间。

**规则**：
1. 将网格分为上下两个等高的半区域。
2. 对每个半区域中的前景对象，检测其包围盒四条边上的缺口位置：
   - 缺口在右侧：该半区域分配到拼接布局的**右侧**位置。
   - 缺口在左侧：该半区域分配到拼接布局的**左侧**位置。
3. 创建输出画布：宽度 = 原宽 + 1，高度 = 原高 + 1，填充栗(9)色作为分隔填充色。
4. 将被分配到左侧的半区域复制到输出画布的左上角 (0, 0)。
5. 将被分配到右侧的半区域复制到输出画布的 (半区高度 + 1, 1) 位置（向下偏移一个半区高度加一行分隔，向右偏移一列）。
6. 在拼接完成后的画布中，将每个前景对象向其缺口方向滑动，直到对象的该侧边缘与其所在半区域的边界对齐（对象像素紧贴半区域的左边界或右边界）。滑动仅沿水平方向，行坐标不变。
7. 输出拼接并滑动后的画布。

**关键洞察**：缺口既是宏观布局指令（决定两个半区在拼接中的相对位置），也是微观定位指令（决定对象在半区内的最终水平位置）。同一个几何特征被两个不同层级的操作消费，不理解其中任何一层都无法得到正确输出。

## 新题 9：缺陷环绕标记与对称修复后的空腔嵌入

**组合逻辑**：[嵌入填充](已有) + [标记环绕](创新：环绕标记不标注前景区域的缺陷，而标注精灵体的对称缺陷位置) + [对称补全](创新：不清除噪声像素，而修复精灵体的对称缺陷) + [尺寸匹配](已有)

**来源原语**：嵌入填充(5dbc8537)、尺寸匹配(5dbc8537)、矩形空腔(5dbc8537)、模板框架(5dbc8537)、标记环绕(71e489b6)、邻域包围(71e489b6)、缺陷像素(71e489b6)、对称补全(8e5c0c38)、对称轴(8e5c0c38)

**依赖链**：精灵体对称分析 → 定位缺陷像素 → 对缺陷像素执行 8-邻域环绕标记（橙色） → 对缺陷像素执行对称补全（填入镜像像素） → 将修复并标记后的精灵体嵌入尺寸匹配的空腔。三个操作形成约束满足结构：标记和补全共享缺陷检测的结果，且必须在嵌入之前完成；标记改变精灵体的外观，补全改变精灵体的形状，两者同时作用于同一精灵体后才能嵌入。

找出精灵体中破坏对称性的缺陷像素，用橙色环绕标记并修复缺陷，再将修复后的精灵体嵌入匹配的空腔。

**输入结构**：约 20x20 的网格。一个蓝(1)模板区域占据网格中心，含 2-3 个矩形空腔（黑(0)区域），尺寸各不相同（如 5x4、4x6、5x5）。模板外的黑(0)背景区域散布 2-3 个精灵体，每个精灵体由单一非黑、非蓝颜色的像素构成（如红(2)、绿(3)、黄(4)），4-连通，像素数 10-20。每个精灵体的包围盒尺寸恰好匹配一个空腔的尺寸。每个精灵体在其包围盒内关于一条轴（水平或垂直）近似对称，但有 1-2 个像素缺失（即对称轴另一侧有对应像素但该侧没有，这些缺失位置目前为黑(0)）——这些就是"缺陷"。生成约束：缺陷像素的 8-邻域中的黑(0)位置在修复和标记后不会超出精灵体包围盒范围；各精灵体的包围盒尺寸与各空腔的尺寸一一匹配，无歧义。

**规则**：
1. 对每个模板外的精灵体，找到其包围盒并检测最佳对称轴（水平或垂直，取镜像匹配数最多的轴）。
2. 找出缺陷位置：对称轴一侧存在精灵体颜色像素，但另一侧对应的镜像位置为黑(0)。这些黑(0)位置即为缺陷位置。
3. 对每个缺陷位置，将其 8-邻域中所有在精灵体包围盒范围内且当前为黑(0)的像素涂为橙(7)。若该邻域位置已有精灵体颜色像素，不覆盖。
4. 对称补全：将每个缺陷位置填入精灵体的颜色（修复缺陷）。
5. 按包围盒尺寸将每个精灵体（现已包含橙(7)标记和修复后的像素）与空腔一一配对，将精灵体整个包围盒（含橙(7)标记、精灵体颜色像素和剩余的黑(0)背景）粘贴进匹配的空腔。
6. 输出为填充完成后的整个网格。

**关键洞察**：环绕标记和对称修复是两个不同的操作，但它们共享同一个缺陷检测步骤。标记在缺陷周围画橙色光环以"记录"缺陷曾经的位置，修复则消除缺陷本身——两者必须同时进行，因为修复后缺陷位置已不可辨识。最终嵌入的精灵体同时携带修复痕迹（橙色标记）和修复结果（补全的像素），展示了"既标记又修复"的双重处理。
