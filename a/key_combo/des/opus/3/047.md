## 新题 1：对角链拓扑门控重力下落

**组合逻辑**：[对角链式连接](已有) → [仅对角接触变色](创新：从"变色标记"改为"通行性分类") → [重力下落](已有) → [重涂色](创新：根据是否穿越门来决定落点颜色)

**来源原语**：对角链式连接/仅对角接触变色(ecb67b6d), 重力下落(afe3afe9), 重涂色(9565186b), 同列传播(d037b0a7), 八连通区域(ecb67b6d), 障碍像素(6bcdb01e)

**依赖链**：灰色区域的 4-连通拓扑决定其角色（墙壁 vs 门）→ 门/墙分类决定彩色像素的下落路径（穿越 vs 阻挡）→ 是否穿越门决定落点像素的最终颜色（保持原色 vs 变为青色）

识别灰色区域的内部连接拓扑（纯对角链 vs 4-连通块），将对角链分类为可穿越的门、4-连通块分类为墙壁，然后让上方彩色像素在重力作用下沿列下落，被墙壁阻挡或穿过门到达更低位置，穿越门的像素变为青色。

**输入结构**：约 15x15 的黑(0)背景网格。网格中散布若干灰(5)的 8-连通区域（每个区域 4~8 像素），部分区域的内部连接全部通过对角角点（即拆成 4-连通子块后各子块仅对角相邻），另一部分区域是紧凑的 4-连通整体。在灰色区域的上方散布若干彩色单像素（红(2)、蓝(1)、黄(4)等），每个彩色像素所在列下方至少有一个灰色区域。生成约束：同一列中不会同时出现两个灰色区域；每个彩色像素与其下方最近的灰色区域之间至少间隔 2 行空白。

**规则**：
1. 对网格中所有灰(5)像素做 8-连通区域分割。对每个 8-连通区域，进一步做 4-连通分割。若该 8-连通区域包含多个 4-连通子块且所有子块之间仅通过对角角点接触（无共享边），则该区域为"门"；若该区域是单个 4-连通块，则为"墙"。
2. 将所有"门"区域的像素从灰(5)重涂为青(8)，作为视觉提示。"墙"区域保持灰(5)。
3. 每个彩色像素沿其所在列向下做重力下落：向下逐行移动，遇到"墙"像素时停止在墙的正上方一格；遇到"门"像素时穿过整个门区域（跳过该区域在此列中的所有像素），继续向下直到遇到下一个障碍或网格底部。
4. 最终落定的彩色像素：若它在下落过程中未穿过任何门，保持原色；若穿过了至少一个门，重涂为青(8)。
5. 原始位置的彩色像素被移除（变为黑(0)背景）。

**关键洞察**：外观相似的灰色区域因内部连接拓扑不同而表现为完全不同的物理行为——对角链形成的区域是可穿透的门，4-连通块是不可穿透的墙。必须分析区域的微观连接结构才能确定宏观的重力路径。

## 新题 2：正交路径分域的奇偶距离环

**组合逻辑**：[连线/先横后纵路由](已有) → [经由中间点路由](已有) → [最近归属](创新：路径本身成为领地分界) → [奇偶距离决定填色](创新：距离测量对象从角标像素改为路径)

**来源原语**：连线/先横后纵路由/经由中间点路由(0e671a1a), 最近归属/奇偶距离决定填色/同心环/角标记像素(d22278a0), 标记像素(0e671a1a)

**依赖链**：三个标记像素的位置决定路径几何形状 → 路径将网格分为不同的最近归属区域 → 每个区域内部按到路径的 Chebyshev 距离奇偶性进行填色。路径既是可见结构也是领地划分边界。

从起点标记经中继点标记到终点标记画正交路径，然后以这条路径为骨架，将网格中的非路径像素按最近路径段归属分为两个领地，每个领地内以到路径的 Chebyshev 距离的奇偶性决定是否填入该领地的颜色。

**输入结构**：约 17x17 的黑(0)背景网格。恰好三个彩色标记像素：一个红(2)像素位于网格的某个角附近（距角点 0~2 格），一个黄(4)像素位于网格中部偏离中心处（不在任何行或列的正中间），一个绿(3)像素位于与红像素不同的角附近。三个标记不共行也不共列。生成约束：红到黄的水平-垂直路径与黄到绿的水平-垂直路径不重叠（可共享黄像素本身）。

**规则**：
1. 以红(2)像素为起点、黄(4)像素为中继、绿(3)像素为终点。从红到黄画正交路径：先沿水平方向移动到黄所在列，再沿垂直方向移动到黄所在行；从黄到绿同理。路径像素涂为灰(5)。三个标记像素保持原色不变。
2. 将路径视为一条连续折线，将其分为两段：红-黄段（含红像素到黄像素之间的所有路径像素）和黄-绿段（含黄像素到绿像素之间的所有路径像素）。黄像素同属两段。
3. 对网格中每个非路径、非标记的像素，计算它到红-黄段所有像素的最小 Chebyshev 距离 d1，以及到黄-绿段所有像素的最小 Chebyshev 距离 d2。若 d1 < d2，该像素属于红领地；若 d2 < d1，属于绿领地；若 d1 = d2，该像素保持黑色背景。
4. 属于红领地的像素：若其 d1 为偶数（含 0），涂为红(2)；否则保持黑(0)。属于绿领地的像素：若其 d2 为偶数（含 0），涂为绿(3)；否则保持黑(0)。
5. 路径像素（灰色）和标记像素保持不变。

**关键洞察**：路径不只是连接标记的视觉线条，它同时是两个颜色领地的分界线。移动中继点会改变路径走向，从而重塑领地边界和整个环形填充图案。领地的形状由路径几何决定，而非由标记像素本身的 Voronoi 区域决定。

## 新题 3：人字形遮罩下的对角色带传播

**组合逻辑**：[列遮挡](创新：从"激活垂直填充"改为"选通对角传播") → [沿对角线传播](已有) → [逐行交换双色](已有) → [遮挡列延伸至边](创新：从"填至底"改为"对角传播深度受限")

**来源原语**：列遮挡/遮挡列延伸至边/前景对象(6d58a25d), 沿对角线传播/逐行交换双色/顶行色带/收缩楔形(b5bb5719), 标记像素(6d58a25d)

**依赖链**：人字形对象的列覆盖范围决定哪些列参与传播 → 顶行色带提供传播源色 → 对角传播沿主对角线向右下展开，每行交换红灰 → 未被人字形覆盖的列阻断传播（对角线进入未覆盖列时终止）。

在顶行色带下方，沿对角线向右下传播颜色，每行红灰交替，但仅在人字形对象覆盖的列中进行——传播路径进入未覆盖列时立即中断。

**输入结构**：约 15x18 的橙(7)背景网格。顶行（第 0 行）有一段连续的前景色带，由红(2)和灰(5)像素交替排列组成（长度为 7~11 像素的奇数），色带两端与网格边缘之间有橙色空隙。网格中部偏下（第 4~8 行附近）有一个蓝(1)的人字形（倒 V 形）对象，宽度约 9~13 像素，高度约 3~5 行，左右对称。人字形的列跨度与顶行色带的列跨度部分重叠但不完全一致。生成约束：色带至少有 3 列被人字形覆盖，至少有 2 列不被覆盖，以产生可见的中断效果。

**规则**：
1. 确定人字形覆盖的列集合 C：对每一列，若该列中存在至少一个蓝(1)像素，则该列属于 C。
2. 对顶行色带中的每个像素 p（位于第 0 行第 c 列，颜色为红(2)或灰(5)），沿主对角线方向传播：第 r 行的传播目标为第 (c + r) 列。
3. 传播规则：在第 r 行（r >= 1），若目标列 (c + r) 属于覆盖集 C 且目标位置当前为橙(7)背景，则填入经过 r 次红灰交换后的颜色。交换规则：红(2)变灰(5)，灰(5)变红(2)，每下降一行交换一次（即第 r 行的颜色 = 原色经 r 次交换 = r 为偶数时原色，r 为奇数时互换色）。
4. 若目标列 (c + r) 不属于覆盖集 C，则该传播路径在此行永久终止，后续行不再传播。
5. 若目标位置已被之前的传播路径填入了非背景色，后来的传播覆盖前者（后传播覆写先传播）。
6. 传播持续到目标列超出网格右边界或行超出网格下边界为止。
7. 人字形本身的蓝(1)像素和顶行色带像素均保持不变。

**关键洞察**：人字形不是简单的"全覆盖或全不覆盖"——它的不规则形状在列维度上创建了一个二值掩码，对角传播路径每当穿越到掩码外的列就被切断。这使得输出中的对角条纹呈现不规则的断裂图案，断裂位置直接对应人字形的列覆盖边界。

## 新题 4：精灵体像素自编码的错切平铺

**组合逻辑**：[像素数定尺寸数](已有) → [平铺/阵列排布](已有) → [错切/行偏移递变](创新：错切量由网格维度决定，而网格维度又来自像素计数)

**来源原语**：像素数定尺寸数/平铺/阵列排布/精灵体(91413438), 错切/行偏移递变/行内容保持(3cd86f4f), 计数(91413438)

**依赖链**：3x3 精灵体中的前景/背景像素数同时编码了输出阵列的维度和副本数量 → 平铺操作使用这两个数值生成阵列 → 错切操作将每行右移 r 列（r 为行号对阵列边长取模），而阵列边长正是背景像素数 → 精灵体既是平铺内容也是尺寸编码器也是错切参数源。

将 3x3 精灵体按其自身的前景/背景像素数平铺成方阵，然后将整个方阵按行做等差错切，错切周期等于方阵的槽位边长。

**输入结构**：一个 3x3 的小网格，包含黑(0)背景像素和恰好一种非黑前景色的像素。前景像素数 F 在 2~5 之间，背景像素数 B = 9 - F 在 4~7 之间。生成约束：F < B（保证副本数小于总槽位数）。

**规则**：
1. 计数：统计 3x3 输入中前景像素数 F 和背景（黑色）像素数 B。
2. 构建输出画布：大小为 (3B) x (3B + B - 1)，即 B 行槽位，每行 B 个槽位宽度加上最大错切量。初始化为全黑。（注：由于错切，画布宽度需要额外的 B-1 列。）
3. 平铺：在画布上按行优先顺序放置 F 个 3x3 精灵体副本。第 i 个副本（i 从 0 开始）放在槽位行 floor(i/B)、槽位列 i mod B 处。每个槽位为 3x3 像素，槽位 (sr, sc) 的左上角像素坐标为 (3*sr, 3*sc)。
4. 错切：对输出画布的每个像素行 r，将该行的所有像素整体右移 (r mod (3*B)) / 3 取整 = floor(r / 3) 列。即每 3 个像素行共享相同的偏移量，偏移量随槽位行号线性增长。空出的左侧位置填黑(0)。
5. 超出画布右边界的像素丢弃。

**关键洞察**：精灵体的像素组成是一个自指编码——前景像素数决定"画多少个"，背景像素数决定"画布多大"以及"错切多剧烈"。改变精灵体中哪怕一个像素的颜色，会同时改变平铺数量、画布尺寸和错切周期，产生截然不同的输出。

## 新题 5：十字臂长决定射线距离的频率竞争

**组合逻辑**：[从臂端发射/射线延伸](已有) → [计数/频率排序](创新：计数的不是输入频率，而是射线覆盖面积) → [最高频保留余替](创新：保留面积最大的色系，其余变灰)

**来源原语**：从臂端发射/射线延伸/遇前景终止/十字图案/中心像素(f8be4b64), 计数/频率排序/最高频保留余替(9565186b), 颜色数决定高度(fcc82909), 射线覆盖交叉点(f8be4b64)

**依赖链**：每个十字的臂长决定其射线可达距离（几何属性编码射程）→ 射线从臂端发射后按限定距离传播 → 所有射线绘制完毕后统计每种中心色的总覆盖面积 → 覆盖面积最大的色系保留原色，其余色系的射线和中心像素全部变灰。大十字天然有更长射线和更大面积，但拥挤的位置会因遇前景终止而缩短射程。

根据每个绿臂十字的臂长限定其射线传播距离，射线以中心色绘制；然后统计各中心色的总覆盖面积，保留面积最大者，其余变灰。

**输入结构**：约 20x20 的黑(0)背景网格。网格中散布 4~6 个绿(3)臂的十字图案（加号形），每个十字的四条臂等长，但不同十字的臂长不同（1~4 像素）。每个十字的中心像素为非绿、非黑的彩色（红(2)、蓝(1)、黄(4)、品红(6)等），允许不同十字有相同的中心色。生成约束：任意两个十字的臂端之间至少间隔 2 个像素；至少存在两种不同的中心颜色；至少有一个十字的某条射线会因遇到另一个十字的绿臂而提前终止。

**规则**：
1. 识别所有绿(3)臂的十字图案，记录每个十字的中心坐标、中心颜色和臂长 L。
2. 从每个十字的四个臂端向外发射射线（上臂端向上、下臂端向下、左臂端向左、右臂端向右），射线颜色为该十字的中心色。每条射线最多传播 L 个像素（与该十字的臂长相同），遇到非黑、非背景的像素时提前停止（不覆盖终止点）。
3. 先处理射线绘制的冲突：若两条射线覆盖同一像素，按以下优先级决定：垂直方向射线优先于水平方向射线（即后绘制的垂直射线覆盖先绘制的水平射线）。同方向冲突时，臂长更长的十字优先。
4. 绘制完所有射线后，统计每种中心颜色的总像素面积（包括该颜色所有十字的中心像素 + 绿臂像素 + 对应射线像素）。
5. 找到总面积唯一最大的中心颜色，称为"优胜色"。保持所有属于优胜色系的十字（中心 + 绿臂 + 射线）不变。
6. 所有非优胜色系的十字：将其中心像素和射线像素全部重涂为灰(5)，绿臂像素保持绿(3)不变。

**关键洞察**：臂长同时控制十字的物理尺寸和射线射程，形成正反馈——更大的十字发射更远的射线，覆盖更多面积。但位置密集的大十字可能因射线被相邻十字截断而面积不如预期，使得一个位置优越的小十字有可能逆转面积排名。

## 新题 6：旋转叠加的象限着色

**组合逻辑**：[旋转](创新：从"恢复缺失"改为"创造叠加体") → [象限归属](创新：从"裁剪后重涂"改为"叠加体的逐像素着色") → [角标色定象限涂色](已有) → [描边](已有，但描的是叠加体轮廓)

**来源原语**：旋转/旋转对称/前景对象(11852cab), 象限归属/角标色定象限涂色/角标像素/象限(77fdfe62), 描边(1bfc4729), 旋转恢复缺失像素(11852cab)

**依赖链**：不规则前景形状经 4 次旋转生成叠加体（旋转创造内容而非恢复缺失）→ 叠加体的每个像素根据其所在象限着色（象限由角标决定）→ 多次旋转在同一像素重叠时，按贡献旋转次数的多数所在象限决定颜色 → 叠加体整体做一像素灰色描边。

将一个不规则前景形状绕网格中心做四次 90 度旋转取并集，根据每个像素所属象限涂上对应角标颜色，重叠区域由贡献旋转的象限多数决定，最后对整个叠加体描边。

**输入结构**：约 15x15 的黑(0)背景正方形网格（边长为奇数，保证有唯一中心）。网格四角各有一个彩色标记像素（四角颜色互不相同，从红(2)、蓝(1)、黄(4)、品红(6)中选取），分别位于 (0,0)、(0,W-1)、(H-1,0)、(H-1,W-1)。网格中有一个单色（橙(7)）的 4-连通不规则前景形状（5~12 像素），完全位于某一个象限内（不跨越网格的水平或垂直中线）。生成约束：该形状不具有 90 度旋转对称性（保证四次旋转产生四个不同的像素集合）；形状距网格中心至少 2 格；四次旋转后的并集中存在至少 2 个被多于一次旋转覆盖的像素。

**规则**：
1. 以网格中心为旋转中心，将前景形状旋转 0°、90°、180°、270°，得到四个像素集合 R0、R90、R180、R270。取并集 U = R0 ∪ R90 ∪ R180 ∪ R270。
2. 定义四个象限（以网格中心行 cr = (H-1)/2 和中心列 cc = (W-1)/2 为分界）：左上象限 = 行 < cr 且 列 < cc；右上象限 = 行 < cr 且 列 > cc；左下象限 = 行 > cr 且 列 < cc；右下象限 = 行 > cr 且 列 > cc。中心行或中心列上的像素归入其上方或左方的象限。
3. 对 U 中的每个像素 p：找出 p 属于哪些旋转集合（R0、R90、R180、R270），记录这些旋转的"源象限"——即产生该像素的原始形状所在象限经旋转后的对应象限。若 p 仅被一次旋转覆盖，直接使用 p 所在象限的角标颜色。若 p 被多次旋转覆盖，统计各贡献旋转的源象限，取出现次数最多的象限的角标颜色；若平手，使用 p 自身所在象限的角标颜色。
4. 对并集 U 的外轮廓做 1 像素描边：对 U 中每个像素，若其 4-邻域中存在不属于 U 的像素，则将那个不属于 U 的邻居位置涂为灰(5)。
5. 原始的四角标记像素保持不变。原始的橙色前景形状被并集着色覆盖。

**关键洞察**：输入只有一个不规则形状和四个角标，但输出是一个具有 4 重旋转对称外形的复合图案，内部颜色却不对称——因为象限着色打破了旋转的颜色对称性。重叠区域的颜色由"谁贡献了这个像素"的多数投票决定，这需要追溯每个像素的旋转来源。

## 新题 7：压缩-排序-印章的三级联动

**组合逻辑**：[压缩/栅格对齐](已有) → [排序/距离优先排序](创新：排序键从"距边距离"改为"栅格列位置") → [图案印章](创新：印章副本数和排列方式都由压缩结果决定) → [编码映射/颜色图例](已有，但映射的是压缩后像素的颜色)

**来源原语**：压缩/栅格对齐/空心符号/边缘标记线(afe3afe9), 排序/距离优先排序(b5ca7ac4), 图案印章/编码映射/精灵体/颜色图例/占位符(edb79dae), 阵列排布(91413438)

**依赖链**：空心符号被压缩为单像素，丢失形状但保留颜色和位置 → 位置决定排序顺序 → 排序后的颜色序列通过图例映射为输出色 → 映射后的颜色序列逐一涂到精灵体副本上 → 空栅格位的数量决定相邻印章之间的间距。

将粗栅格上的空心符号压缩为像素，按栅格位置排序后通过颜色图例重映射，再依序印章到精灵体副本上，空栅格位数量编码输出中相邻副本之间的间隔。

**输入结构**：约 18x18 的黑(0)背景网格，分为两个区域。左侧区域（约占 2/3 宽度）包含一个 3x3 或 4x4 的粗栅格（通过等间距行列线隐式定义），栅格的部分单元格中放有空心 3x3 符号（即 3x3 方框，外圈为某色、中心为背景色），共 3~5 个，颜色各异（从红(2)、蓝(1)、黄(4)、品红(6)、橙(7)中选取）；其余单元格为空。右侧区域包含两部分：(a) 一个实心的单色小精灵体（3x3 或 4x4，非矩形的 4-连通形状，绿(3)色，3~6 像素），位于右上角；(b) 一个颜色图例，位于右下角，由若干 2x1 竖直色块对组成，每对的上格为输入中某空心符号的颜色，下格为对应的输出颜色（从青(8)、灰(5)、栗(9)等选取）。生成约束：图例覆盖所有空心符号颜色，每种颜色恰好出现一次。

**规则**：
1. 在左侧粗栅格中识别所有空心 3x3 符号，将每个符号压缩为位于其栅格单元中心的单个像素，颜色取符号的外圈色。记录每个压缩像素的栅格坐标 (gr, gc)。同时统计栅格中空单元格的数量 E。
2. 将压缩像素按栅格位置排序：先按栅格列 gc 升序，gc 相同时按栅格行 gr 升序。得到有序颜色序列 [c1, c2, ..., cN]（N 为符号数量）。
3. 用右下角的颜色图例将序列中的每个颜色映射为对应的输出色，得到映射后序列 [m1, m2, ..., mN]。
4. 构建输出：将右上角的精灵体作为模板，创建 N 个副本。第 i 个副本的所有前景像素涂为 mi。副本在一行中从左到右排列，相邻副本之间间隔 E 列黑色空白（E 为空栅格单元数）。输出画布高度等于精灵体高度，宽度 = N * 精灵体宽度 + (N-1) * E。
5. 精灵体模板中的背景像素在输出中保持黑(0)。

**关键洞察**：空心符号同时编码了三种信息——颜色（决定输出着色）、栅格位置（决定输出顺序）、空缺数量（决定输出间距）。这三者分别来自符号的色彩属性、空间属性和栅格占用率，必须同时提取并交叉使用。

## 新题 8：边缘标记压缩构建走廊的路径追踪

**组合逻辑**：[压缩/栅格对齐](已有) → [标记指示方向/滑动](已有) → [碰撞转向/遇障碍直角转](创新：障碍物本身是压缩+滑动的产物) → [路径绘制](已有)

**来源原语**：压缩/栅格对齐/空心符号/边缘标记线/标记指示方向(afe3afe9), 碰撞转向/遇障碍直角转/起点条/障碍像素/走廊路径(6bcdb01e), 滑动(afe3afe9), 路径绘制(da515329)

**依赖链**：空心符号被压缩为像素 → 边缘标记线指示重力方向 → 压缩后的像素沿该方向滑动堆叠形成墙壁 → 起点条在压缩后的网格中发射路径 → 路径沿走廊前进，遇墙壁（即滑动后的压缩像素）转弯 → 走廊的形状完全取决于压缩和滑动的结果。

将粗栅格中的空心符号压缩为像素并按边缘标记方向滑动堆叠，压缩像素成为走廊墙壁，然后从起点条出发在走廊中追踪路径直到离开网格。

**输入结构**：约 15x15 的黑(0)背景网格。网格的一条完整边（上、下、左或右之一）被蓝(1)像素填满，作为边缘标记线。网格内部按 3x3 粗栅格排布（共 5x5 = 25 个栅格位，每个栅格位 3x3 像素），其中 6~10 个栅格位放有空心 3x3 符号（黄(4)色外框，中心黑色），其余栅格位为空。网格的某条非标记边上有一个绿(3)色的 2 像素 4-连通起点条（水平或垂直相邻的两个绿像素），其中恰好一个像素位于网格边界。生成约束：蓝色标记线所在边与起点条所在边不同；压缩并滑动后形成的墙壁构成至少包含两个转弯的走廊；起点条的方向使其初始运动方向指向网格内部。

**规则**：
1. 压缩：将每个空心 3x3 符号替换为位于其栅格中心的单个黄(4)像素，同时将粗栅格收缩为每栅格位 1 像素的紧凑网格（5x5）。蓝色标记线收缩为紧凑网格对应边的一行/列蓝像素。起点条收缩为紧凑网格对应位置的 2 像素条。
2. 滑动：根据蓝色标记线的位置确定滑动方向——顺时针读边：上边 → 向右滑动，右边 → 向下滑动，下边 → 向左滑动，左边 → 向上滑动。将紧凑网格中所有黄(4)像素沿该方向滑动，直到撞到网格边界或另一个黄像素。蓝色标记线像素从输出中移除（它仅作为方向指示器）。
3. 路径追踪：从起点条的边界像素出发，沿穿过另一个起点像素的方向进入网格。逐格前进，每前进一格将该格涂为绿(3)。当下一格为黄(4)像素（墙壁）时，检查左右两个垂直方向：选择不是墙壁且不超出网格的方向转弯 90°（恰好有唯一选择，因为走廊保证只有一个可行转向）。当下一格超出网格边界时停止。
4. 起点条的两个像素都保持绿(3)。黄色墙壁像素保持黄(4)。路径像素为绿(3)。其余为黑(0)背景。

**关键洞察**：空心符号、边缘标记和起点条在原始输入中看似独立的三组元素，在压缩后协同构建了一个完整的走廊迷宫系统——符号变成墙壁，标记决定墙壁的堆叠方式（从而决定走廊形状），起点条发射路径。改变标记线所在的边会完全重组墙壁布局，产生完全不同的路径。
