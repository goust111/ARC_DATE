## 新题 1：自身比例决定镜像轴的对称核提取

**组合逻辑**：[镜像/mirror](创新：镜像轴由每个对象自身bbox宽高比决定，而非外部框架) + [异或差异判定/xor_difference](创新：在单个对象内部比较原始与镜像副本，而非两个面板间比较) → [擦除/erase](擦除非对称像素)

**来源原语**：镜像 ← 18419cfa；宽高比决定镜像轴 ← 18419cfa；异或差异判定 ← 34b99a2b；擦除 ← 52364a65；连通分量 ← 52364a65；相对自身定位 ← 52364a65

**依赖链**：每个对象的bbox宽高比决定了它的镜像轴（宽>=高则左右镜像，高>宽则上下镜像）→ 镜像结果与原始像素做异或 → 仅保留原始与镜像重合的像素（对称核），擦除不重合像素。三步不可拆：不知宽高比则轴错，不做异或则不知哪些像素对称，不擦除则输出不对。

将输入中每个不规则前景对象缩减为其在自身宽高比所决定的对称轴下的对称核心部分。

**输入结构**：黑(0)背景，约 20x20 网格。散布 3-5 个单色 4-连通前景对象，每个对象使用不同颜色（从蓝(1)、红(2)、绿(3)、黄(4)、灰(5)中选取）。每个对象是不规则形状（5-12 像素），不是矩形。不同对象的 bbox 宽高比有差异——有的 bbox 宽度大于等于高度，有的高度大于宽度。对象之间互不接触，且每个对象的 bbox 互不重叠。生成约束：每个对象在其自身宽高比所决定的镜像轴下都有至少 2 个像素既属于原始形状也属于镜像形状（即对称核非空），同时至少有 1 个像素是不对称的（即对称核严格小于原始形状）。

**规则**：
1. 识别每个 4-连通前景对象，计算其最小外接矩形（bbox）。
2. 若 bbox 宽度 >= 高度，在 bbox 内对该对象做左右镜像（以 bbox 的垂直中轴为对称轴）；若 bbox 高度 > 宽度，做上下镜像（以 bbox 的水平中轴为对称轴）。镜像仅作用于该对象自身的像素，不影响其他对象。
3. 逐像素比较原始对象与其镜像副本：像素在原始和镜像中都存在（即该位置在原始中是前景且镜像后仍是前景）→ 保留为原色；像素仅在原始或仅在镜像中存在 → 设为黑(0)背景。
4. 对每个对象独立执行上述步骤，输出保留所有对象的对称核。背景和对象间空白不变。

**关键洞察**：镜像轴不是全局共享的，而是每个对象根据自身形状比例独立决定——宽扁的对象做左右对称检测，高瘦的对象做上下对称检测。需对比多个示例中不同宽高比对象的不同处理方式才能归纳出此规则。

## 新题 2：拓扑孔洞数双重编码射线方向与颜色

**组合逻辑**：[计数/counting](统计每个精灵体的封闭孔洞数) → [射线延伸/ray_extend](创新：孔洞数同时编码射线方向) + [重涂色/recolor](创新：同一个孔洞数同时编码精灵体的目标颜色) + [轨迹交叉/trail_intersection](创新：交叉点产生特定标记色而非对角线)

**来源原语**：计数 ← e3721c99；封闭区域 ← e3721c99；孔洞数映射颜色 ← e3721c99；射线延伸 ← ac605cbb, 2c608aff；轨迹交叉 ← ac605cbb；碰撞停止 ← 2c608aff；精灵体 ← e3721c99

**依赖链**：孔洞计数同时输出两个信号——射线方向和精灵体新颜色。方向决定射线路径，路径之间的交叉产生标记像素。不计孔洞则方向和颜色都未知；不发射线则无交叉可检测；两条编码通道耦合在同一个拓扑测量上，不可分离。

统计每个灰色精灵体的孔洞数，据此同时重涂精灵体颜色并发射特定方向的射线，射线交叉处标记为橙色。

**输入结构**：黑(0)背景，约 22x22 网格。3-4 个灰(5)精灵体（4-连通，每个 8-20 像素），形状各异。每个精灵体有不同数量的封闭孔洞（0、1、2 或 3 个），封闭孔洞定义为精灵体内部被精灵体像素完全包围的黑(0)背景连通区域。精灵体之间互不接触，且任意两个精灵体的最小外接矩形不共享同一行或同一列（即没有两个精灵体的 bbox 在水平或垂直方向上对齐，保证射线不会在发射后立即碰到另一个精灵体）。生成约束：至少存在两条射线在网格内交叉。

**规则**：
1. 识别每个灰(5) 4-连通精灵体，计算其封闭孔洞数 H。
2. 根据 H 确定射线方向：H=0 → 向右，H=1 → 向上，H=2 → 向左，H=3 → 向下。
3. 从精灵体 bbox 的射线方向侧中点出发（例如向右则从 bbox 右边中行的右侧一格开始），沿该方向逐格延伸灰(5)射线，直到碰到网格边界或另一个精灵体的像素（碰撞停止，不覆盖碰到的像素）。
4. 将每个精灵体自身（不含射线）重涂色：H=0 → 蓝(1)，H=1 → 红(2)，H=2 → 绿(3)，H=3 → 黄(4)。射线保持灰(5)不变。
5. 检查所有射线：两条不同精灵体的射线在同一格交叉时，将该格涂为橙(7)。

**关键洞察**：单一拓扑测量（孔洞数）同时编码了两种不同性质的输出——空间运动方向和颜色身份。需对比多个示例才能分离出孔洞数与方向的固定映射关系（0=右/1=上/2=左/3=下），以及孔洞数与颜色的映射关系。

## 新题 3：指示像素编码旋转角度的碎片补全

**组合逻辑**：[旋转/rotate](创新：旋转角度由指示像素在碎片哪一侧决定，而非全局固定) + [补全/completion](创新：补全的不是原始模板而是模板的旋转版本) + [指示像素/indicator_pixel](创新：编码旋转量而非延伸方向)

**来源原语**：补全 ← fd096ab6；碎片 ← fd096ab6；模板精灵体 ← fd096ab6；碎片锚定放置位 ← fd096ab6；旋转 ← 3c9b0459；指示像素 ← b527c5c6；方向指示 ← b527c5c6

**依赖链**：指示像素的位置编码了旋转角度 → 必须先解码旋转量才能知道模板应以哪个朝向参与补全 → 补全必须用旋转后的模板对齐碎片像素 → 碎片像素同时充当旋转验证锚点和位置锚点。去掉指示像素则旋转未知（碎片本身可能匹配多种旋转），去掉旋转则碎片无法与模板对齐，去掉补全则输出不完整。

根据每个彩色碎片旁边指示像素所编码的旋转角度，将唯一模板旋转至对应朝向后补全碎片。

**输入结构**：黑(0)背景，约 20x20 网格。一个完整的绿(3)模板形状（4-连通，10-15 像素，非矩形，无旋转对称性——即 0/90/180/270 度旋转后形状互不相同）。2-3 个彩色碎片，每个碎片使用不同颜色（蓝(1)、红(2)、黄(4)中选取），每个碎片是模板某个旋转版本（0/90/180/270 度顺时针）的一个连通子集（3-6 像素）。每个碎片紧邻一个橙(7)指示像素，指示像素位于碎片 bbox 的某一侧外缘（上/右/下/左），与碎片 bbox 该侧某像素 4-邻接。碎片之间互不接触，碎片与模板互不接触。生成约束：每个碎片的像素在对应旋转后的模板上位置唯一确定一个平移放置，且补全后的完整形状不超出网格边界、不与其他前景对象重叠。

**规则**：
1. 识别模板：像素数最多的单色前景连通分量（绿(3)）。
2. 对每个非绿色碎片，找到与其 4-邻接的橙(7)指示像素。指示像素在碎片 bbox 的哪一侧决定旋转角度：上方 → 0 度，右方 → 90 度顺时针，下方 → 180 度，左方 → 270 度顺时针。
3. 将模板按该角度顺时针旋转，得到旋转模板。
4. 寻找唯一的平移量使旋转模板的像素集合完全覆盖碎片已有的所有像素。
5. 将旋转模板中碎片尚未覆盖的像素用碎片的颜色填充，完成补全。
6. 移除所有橙(7)指示像素（设为背景）。模板本身保持不变。

**关键洞察**：指示像素在此处不是指示延伸方向（参考题 b527c5c6 的用法），而是编码旋转量——它在碎片的哪一侧等价于模板被旋转了多少度。需对比多个示例中指示像素位置与碎片朝向的对应关系才能归纳出此编码规则。

## 新题 4：逐对象局部旋转后的面板异或比较

**组合逻辑**：[旋转/rotate](创新：不是整体旋转画布，而是右面板中每个对象在其自身 bbox 内独立做 180 度旋转) → [逐像素比较/cell_by_cell_comparison] + [差异标记/mark_differences](创新：比较的不是两个原始面板，而是左面板与局部旋转后的右面板)

**来源原语**：旋转 ← 3c9b0459；整体半周旋转 ← 3c9b0459（创新为局部半周旋转）；逐像素比较 ← 34b99a2b；差异标记 ← 34b99a2b；异或差异判定 ← 34b99a2b；分隔列 ← 34b99a2b；面板对齐 ← 34b99a2b；连通分量 ← 52364a65；相对自身定位 ← 52364a65

**依赖链**：右面板的每个前景对象必须先在自身 bbox 内做 180 度旋转 → 旋转改变了右面板的像素分布 → 逐像素比较在旋转后的右面板与原始左面板之间进行 → 差异位置标为红色。删除旋转步骤则比较对象错误（退化为普通 XOR），删除比较步骤则无法得到差异掩码。180 度对称的对象在旋转后不变、差异为零，而非对称对象产生非零差异——对称性检测涌现于旋转+比较的组合。

将右面板中每个前景对象在其自身范围内旋转 180 度，再与左面板逐像素异或，输出差异掩码。

**输入结构**：约 11x23 网格（奇数宽度）。中间一列为灰(5)分隔列，贯穿全高。左面板和右面板各约 11x11。两面板的背景为黑(0)。每个面板内有 2-4 个单色前景对象（使用蓝(1)、绿(3)等颜色），左右面板使用相同颜色集合。左面板每个对象与右面板同色对象占据相同的 bbox 位置（相对于各自面板原点）。对象为不规则 4-连通形状（3-8 像素），部分对象关于其 bbox 中心 180 度旋转对称，部分不对称。对象之间互不接触，bbox 互不重叠。生成约束：左右面板至少各有一个对称对象和一个不对称对象。

**规则**：
1. 识别灰(5)分隔列，将网格分为等宽的左面板和右面板。
2. 在右面板中，识别每个 4-连通前景对象及其 bbox。将每个对象在其 bbox 内做 180 度旋转（像素映射到关于 bbox 中心的对称位置）；旋转后超出原始对象像素的位置填入该对象颜色，原始像素位置若旋转后无像素覆盖则设为背景。
3. 将旋转后的右面板与原始左面板逐像素比较：
   - 两侧都是背景 → 输出背景黑(0)。
   - 两侧都是相同颜色的前景 → 输出背景黑(0)。
   - 恰好一侧是前景（另一侧是背景或不同颜色） → 输出红(2)。
4. 输出网格为面板大小（去除分隔列），仅包含黑(0)和红(2)。

**关键洞察**：比较发生在左面板与"局部旋转后的"右面板之间，而非两个原始面板之间。180 度旋转对称的对象旋转后不变，与左面板完全匹配，产生零差异；而不对称对象旋转后像素位置改变，与左面板产生差异——因此输出的红色像素恰好标识了右面板中各对象的旋转不对称部分。

## 新题 5：图例解码生成瓦片后奇偶交替镜像铺设

**组合逻辑**：[解码/decode](从标记母题中读取颜色映射) → [平铺/tiling](创新：平铺的内容来自解码结果而非输入原样) + [镜像/mirror](创新：镜像不是对单个对象做，而是对瓦片格中奇数位置的瓦片做左右翻转)

**来源原语**：解码 ← 1be83260；重复图案 ← 1be83260；内部槽位 ← 1be83260；图例映射 ← 1be83260；槽位决定颜色 ← 1be83260；平铺 ← 310f3251；瓦片 ← 310f3251；镜像 ← 18419cfa；序列索引 ← a5f85a15；奇偶交替涂色 ← a5f85a15（创新为奇偶交替镜像）

**依赖链**：解码确定瓦片内容（不解码则不知道铺什么）→ 平铺确定瓦片阵列布局 → 奇数位置瓦片做左右镜像（不知道瓦片内容则镜像无意义）。解码和镜像通过平铺紧密关联：解码的输出就是镜像的操作对象，且镜像是否执行取决于瓦片在阵列中的位置索引。

解码母题中的色彩槽位得到一个基础瓦片，将其在网格中重复铺设，行优先编号从 0 开始，奇数编号的瓦片做左右镜像。

**输入结构**：黑(0)背景，约 15x15 至 21x21 网格。左上角有一个 (2R+1)x(2C+1) 大小的"母题块"（R 和 C 为 2 或 3），母题块由栗(9)色边框构成 1 像素宽的网格线，形成 RxC 个内部槽位。每个槽位为 1x1 像素，填有某种颜色（可以是栗(9)本身或其他颜色如蓝(1)、红(2)、绿(3)等）。母题块之外的网格全部为黑(0)背景。生成约束：网格剩余空间恰好能容纳整数个 RxC 瓦片的阵列（瓦片之间无间隔），瓦片阵列至少 2 行 3 列；母题块的槽位填色不左右对称（保证镜像后瓦片视觉可区分）。

**规则**：
1. 识别母题块：找到栗(9)色网格线构成的 (2R+1)x(2C+1) 结构，读取其 RxC 个内部槽位的颜色，得到一个 RxC 的基础瓦片。
2. 在输出网格中，用基础瓦片铺满整个网格（从左上角开始，行优先排列，无间隔）。母题块区域也被瓦片覆盖。

## 新题 6：指示像素定向带状延伸与面积逆序叠加

**组合逻辑**：[延伸/extend](创新：不是矩形整体延伸，而是不规则精灵体沿指示方向做带状投影延伸) + [计数/counting](统计每个精灵体原始像素数) + [透明叠加/transparent_overlay](创新：叠加优先级由面积反序决定——面积小者在上，而非面积大者在上)

**来源原语**：延伸 ← b527c5c6；指示像素 ← b527c5c6；方向指示 ← b527c5c6；指示侧扩展至边界 ← b527c5c6；计数 ← f3cdc58f, bd283c4a；面积排序叠加 ← 83eb0a57（创新为面积逆序）；画布边界 ← b527c5c6

**依赖链**：指示像素的位置确定延伸方向 → 延伸产生带状投影，不同精灵体的投影可能空间重叠 → 计数确定每个精灵体的原始面积 → 面积决定重叠时的绘制优先级（小面积精灵体的投影覆盖大面积精灵体的投影）。去掉方向指示则不知延伸方向，去掉计数则无法确定叠加顺序，去掉延伸则无重叠可解决。

每个精灵体沿其指示像素所指方向做带状延伸直到画布边界，延伸区重叠时面积较小的精灵体覆盖面积较大的。

**输入结构**：黑(0)背景，约 20x20 网格。3-4 个单色 4-连通前景精灵体，每个使用不同颜色（蓝(1)、红(2)、绿(3)、黄(4)），每个 4-10 像素，形状不规则。每个精灵体有一个栗(9)指示像素，该像素位于精灵体 bbox 的某一侧外缘（上/右/下/左），与精灵体的该侧至少一个像素 4-邻接。每个精灵体的原始像素数互不相同。生成约束：至少有两个精灵体的延伸带在空间上重叠。

**规则**：
1. 识别每个前景精灵体及其紧邻的栗(9)指示像素。
2. 指示像素在精灵体 bbox 的哪一侧决定延伸方向：上方 → 向上延伸，右方 → 向右延伸，下方 → 向下延伸，左方 → 向左延伸。
3. 对每个精灵体，沿延伸方向做带状投影：将精灵体在垂直于延伸方向的轴上的所有像素列（或行）沿延伸方向复制，从精灵体的该侧边缘开始延伸直到网格边界。延伸带使用该精灵体的颜色。精灵体自身像素保留。
4. 统计每个精灵体的原始像素数（不含延伸带）。
5. 按原始像素数从大到小的顺序绘制各精灵体及其延伸带（即先绘面积最大的，后绘面积较小的）。后绘制的覆盖先绘制的，因此面积最小的精灵体的延伸带在最上层。
6. 移除所有栗(9)指示像素（设为对应精灵体的颜色，若指示像素位置被延伸带覆盖则为延伸带颜色）。

**关键洞察**：延伸方向由指示像素的局部空间关系决定（参考题 b527c5c6 中指示像素决定矩形生长方向），但此处作用于不规则精灵体产生的带状投影宽度不均匀。叠加优先级与参考题 83eb0a57 相反——小面积在上而非大面积在上——需要对比包含不同重叠情况的多个示例才能归纳出此逆序规则。

## 新题 8：对角线交替重涂色触发方向延伸

**组合逻辑**：[重涂色/recolor](创新：奇偶交替涂色产生的新颜色像素成为后续操作的触发源) → [延伸/extend](创新：延伸方向由对角线走向决定而非指示像素) + [连线/draw_line](从重涂像素沿对角线方向画线至边界)

**来源原语**：重涂色 ← a5f85a15；对角线段 ← a5f85a15；奇偶交替涂色 ← a5f85a15；序列索引 ← a5f85a15；连线 ← 2c608aff, b527c5c6；延伸 ← b527c5c6；画布边界 ← b527c5c6

**依赖链**：对角线段中的奇偶交替重涂色产生黄色像素（操作 A 的输出）→ 黄色像素成为延伸操作的起点（触发操作 B 的条件）→ 每个黄色像素沿其所在对角线段的走向延伸至网格边界。重涂色决定了哪些像素被选中，延伸方向由对角线走向隐式编码。两者耦合点在于：改变交替规则会改变哪些像素产生延伸线，改变延伸方向规则会改变线的走向。

对角线段中被交替涂为黄色的像素各自沿所在对角线方向延伸一条线至网格边界。

**输入结构**：黑(0)背景，约 15x15 网格。一种非黑非黄的前景色（如蓝(1)或红(2)）构成若干像素，这些像素排列为若干条互不相连的右下对角线段（每条段沿 row+1/col+1 方向延伸，长度 3-6 像素）。不同对角线段之间不 8-邻接。黄(4)色在输入中不出现。生成约束：至少有 2 条对角线段，且至少有一个被重涂为黄(4)的像素的延伸线在到达边界之前不会经过其他前景像素。

**规则**：
1. 识别每条最大右下对角线段（沿 row+1/col+1 方向的连续前景像素链）。
2. 在每条对角线段内，将像素按右下方向编号（从段的左上端点开始，编号 1, 2, 3, ...）。将编号为偶数的像素重涂为黄(4)，奇数编号像素保持原色不变。
3. 对每个被涂为黄(4)的像素，从该像素出发沿右下方向（row+1/col+1）画一条黄(4)直线，逐格延伸直到到达网格边界（行或列超出网格范围时停止）。延伸线不覆盖已有的非背景像素——若下一格已有非背景色则停止（不包含该格）。
4. 同时，从该黄(4)像素出发沿左上方向（row-1/col-1）画一条黄(4)直线，同样延伸至网格边界或碰到非背景像素停止。
5. 原前景像素和已有黄(4)像素不被延伸线覆盖（原始像素优先级高于延伸线）。

**关键洞察**：交替重涂色（参考题 a5f85a15）在原题中是最终输出，但此处它是中间步骤——涂出的黄色像素成为延伸操作的触发源。延伸方向并非由外部指示像素给出，而是由像素所在对角线段的几何走向隐式决定。需要对比多个示例才能确认"只有偶数位的像素产生延伸线"以及"延伸方向与对角线走向一致"这两条规则。

1. 识别最大 8-连通前景对象为底图，裁剪至其 bbox。
2. 对每个小精灵体，找到其与底图共享的标记色，将精灵体平移使其标记色像素与底图中同色标记像素对齐。

## 新题 10：平移对称补全后按图例对遮挡区域重涂色

**组合逻辑**：[补全/completion](利用平移对称性恢复遮挡区域) + [重涂色/recolor](创新：仅对恢复出的遮挡区域按外部图例做颜色映射，非遮挡区域保持不变) + [解码/decode](创新：图例不嵌入在重复图案中，而是作为独立小块存在)

**来源原语**：补全 ← f9012d9b；平移对称图案 ← f9012d9b；遮挡矩形 ← f9012d9b；对称轨道 ← f9012d9b；对称恢复遮挡 ← f9012d9b；重涂色 ← 1be83260, e3721c99；色彩图例 ← 1be83260, e3721c99；图例映射 ← 1be83260

**依赖链**：平移对称检测 → 填充遮挡区域（必须先补全才知道遮挡区域的原始颜色）→ 识别图例中的颜色映射 → 仅对遮挡区域内的像素应用颜色映射（补全结果决定了重涂色的输入，图例决定了映射规则，作用范围限定于遮挡区域）。补全和重涂色通过"仅遮挡区域"这一共享作用域紧密耦合：不补全则不知道遮挡区域的内容，不知内容则无法正确映射颜色；不做重涂色则补全只是简单恢复，无法产生输出中遮挡区域与非遮挡区域颜色风格不同的效果。

恢复被遮挡的平移对称图案内容，但仅对恢复出的区域按独立图例将每种颜色映射为另一种颜色。

**输入结构**：约 18x18 至 22x22 网格。网格主体为一个无背景的平移重复彩色图案（使用蓝(1)、红(2)、绿(3)等 2-3 种颜色，平移周期约 3x3 至 5x5）。图案中有一个矩形区域（约 4x4 至 6x6）被黑(0)遮挡。在网格的某个角落（不与图案重叠），有一个小的颜色图例块：由 2-3 行组成，每行两个像素，左侧像素为图案中的某种颜色，右侧像素为目标映射颜色（从黄(4)、灰(5)、品红(6)等图案中未使用的颜色中选取）。图例块用栗(9)色边框包围以与图案区分。生成约束：图例覆盖图案中所有出现的颜色（每种图案色在图例中恰好出现一次），且映射后的目标颜色互不相同、与原图案颜色无交集。

**规则**：
1. 识别黑(0)遮挡矩形的位置和范围。
2. 在图案的非遮挡区域检测平移对称性（忽略图例块区域）。
3. 对遮挡区域内每个黑(0)像素，从其平移对称轨道中找到一个非遮挡的等价像素，用该像素的颜色填充。
4. 识别栗(9)边框包围的图例块，读取每行的颜色映射：左像素颜色 → 右像素颜色。
5. 对遮挡区域内刚被恢复的每个像素，按图例映射将其颜色替换为对应的目标颜色。遮挡区域外的图案像素保持原色不变。
6. 移除图例块及其栗(9)边框（设为所在位置的图案颜色，通过平移对称推算；若图例块位于图案范围外则设为黑(0)）。

**关键洞察**：补全和重涂色看似可以独立执行，但它们的作用域被"遮挡区域"这一空间约束严格绑定——只有被补全的像素才被重涂色，而补全必须先于重涂色完成以确定要映射的颜色。输出中遮挡区域使用映射后的颜色、非遮挡区域使用原始颜色，形成一种"修复痕迹"效果——遮挡区域在内容上正确恢复，但在颜色上被转换，标识出哪些部分是被修复的。需对比多个示例才能确认重涂色仅作用于遮挡区域这一非显然的作用域限制。
