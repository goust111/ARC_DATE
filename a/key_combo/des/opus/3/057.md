## 新题 1：射线穿越杯口触发内部填充

**组合逻辑**：[射线延伸](创新：从边界标记向内发射，非从对象向外) + [填充](创新：由射线穿越事件触发，非预设) + [开口朝向](创新：作为方向过滤器，决定射线能否进入) + [擦除]

**来源原语**：射线延伸(ray_extend) ← d4f3cd78/ea786f4a；填充(fill) ← d4f3cd78；开口朝向(opening_direction) ← d4f3cd78；杯形轮廓(cup_outline) ← d4f3cd78；标记像素(marker_pixel) ← 3e980e27/56ff96f3；接触判定(contact_detection) ← 0d87d2a6

**依赖链**：边界标记位置决定射线方向 → 杯口朝向过滤射线能否进入 → 射线穿越杯内空间的事实触发填充 → 杯壁对射线的阻断影响后方杯是否可达。四步之间形成空间交互网络：一个杯的壁可以阻断射线，从而间接决定另一个杯是否被填充。

输入网格中有若干杯形轮廓和边界标记像素；输出中被射线穿越的杯内部获得填充色，其余杯保持空心。

**输入结构**：约 15x15 网格，黑(0)背景。网格中散布 3-4 个杯形轮廓，每个杯由单一非黑颜色的像素构成矩形环（边界框约 4x5 至 5x6），其中恰好一侧的边框像素全部缺失形成开口。不同杯的轮廓颜色互不相同，从 {红(2), 绿(3), 蓝(1)} 中取用。各杯边界框互不重叠，且最近杯对之间至少间隔 2 行/列。每个杯的开口朝向不同的基本方向（上、下、左、右各至多一个杯）。在网格的左边界和上边界各有 1-2 个橙(7)像素作为标记：左边界的标记发射水平向右的射线，上边界的标记发射竖直向下的射线。所有标记行/列互不重复。生成约束：每条射线的路径上至少经过一个杯的区域（可能被壁阻挡或穿越开口）。

**规则**：
1. 从每个橙(7)边界标记像素出发，沿其入射方向（左边界 → 向右；上边界 → 向下）逐格绘制橙(7)像素。射线在黑(0)背景格上正常绘制。
2. 当射线到达某杯轮廓的外边界时，判断射线行进方向与该杯开口朝向的关系：
   - 若射线从开口侧进入（例如射线向右行进，杯的左侧缺失为开口），射线穿越杯内部区域，在内部黑(0)格上也绘制橙(7)像素，然后从杯对面的闭合壁内侧最后一个黑格之后停止（射线不覆盖杯壁像素本身）。射线在穿越一个杯后终止，不再继续。
   - 若射线撞到杯的闭合壁（非开口侧），射线停止于壁外侧紧邻的最后一个黑格（不覆盖杯壁像素）。
3. 射线绘制全部完成后，检查每个杯内部（杯轮廓围成的封闭矩形区域减去轮廓像素本身，再补上开口那一侧的虚拟边界内侧）：若内部存在任何橙(7)像素，则将该杯内部所有仍为黑(0)的格子填充为该杯轮廓自身的颜色。
4. 未被任何射线穿越的杯，其内部保持黑(0)不变。
5. 擦除所有边界标记像素（将其恢复为黑(0)）。射线留下的橙(7)像素和杯壁像素均保留。

**关键洞察**：杯的开口同时扮演两个角色——它既是射线的入口（方向匹配时放行），又隐含了填充触发条件（有射线穿越 = 填充）。一个杯的闭合壁可以阻断射线，间接保护其身后的另一个杯不被填充，由此产生杯与杯之间的空间遮挡依赖。

## 新题 2：重复体计数决定异常体的嵌套外框层数

**组合逻辑**：[计数](创新：统计重复对的数量作为构造参数) + [异常值选择] + [裁剪] + [外框绘制](创新：层数和颜色由其他对象的统计属性决定) + [图案匹配] + [擦除]

**来源原语**：计数(counting) ← cd3c21df；异常值选择(outlier_selection) ← cd3c21df；图案匹配(pattern_match) ← cd3c21df；裁剪(crop) ← 28bf18c6；外框绘制(frame_draw) ← db93a21d；尺寸倍增嵌套(size_doubled_nesting) ← db93a21d；颜色配对(color_pairing) ← 3e980e27；擦除(erase) ← bae5c565

**依赖链**：图案匹配将精灵体分为重复组与异常体 → 重复对的数目 N 决定外框嵌套层数 → 各重复对的颜色按空间顺序映射为各层外框的颜色 → 异常体的裁剪结果成为嵌套中心内容。四条信息流（分类、计数、颜色序列、中心图案）汇聚于最终输出，缺少任何一条都无法确定结果。

统计重复精灵体对的数目 N，将唯一的异常精灵体作为中心，围绕它绘制 N 层同心外框，每层颜色取自一个重复对。

**输入结构**：约 15x15 网格，黑(0)背景。网格中散布 5-7 个小型 4-连通单色精灵体，每个精灵体由 3-6 个像素组成，边界框不超过 3x3。这些精灵体分为若干组：2-3 组重复对（同组两个精灵体的边界框裁剪图案完全相同，颜色相同，位置不同）以及恰好 1 个无配对的异常精灵体。每个重复对使用唯一颜色，从 {红(2), 蓝(1), 绿(3)} 中取用；异常精灵体使用黄(4)。各精灵体的边界框互不重叠，且异常精灵体位于网格中央区域（距离四边至少留出 N+1 格，N 为重复对数量），以保证外框有足够空间绘制。

**规则**：
1. 对每个 4-连通精灵体，裁剪其边界框（含框内黑(0)像素）作为标准图案。
2. 将图案完全相同（像素逐格比较）的精灵体配对。拥有唯一图案（无配对）的精灵体为异常体。
3. 统计重复对的数量 → N。
4. 将所有重复对按其两个精灵体的边界框中心的平均列坐标从小到大排序（列坐标相同则按平均行坐标从小到大）。排序后第 k 对（k 从 1 开始）对应第 k 层外框。
5. 以异常体的边界框为中心区域，向外逐层绘制 N 个同心矩形外框。第 k 层外框紧贴第 k-1 层外框外侧（k=1 时紧贴异常体边界框外侧），框宽 1 像素。第 k 层外框颜色为第 k 对重复对的颜色。
6. 擦除所有重复对精灵体（恢复为黑(0)）。保留异常体及其周围的嵌套外框。

**关键洞察**：重复精灵体不是干扰项——它们的数目编码了嵌套深度，它们的颜色编码了各层外框的色彩，它们的空间位置编码了颜色的排列顺序。异常精灵体则是嵌套的几何中心。所有精灵体共同携带构造输出所需的全部信息。

## 新题 3：对角标记区覆盖逐行控制色

**组合逻辑**：[重涂色-逐行控制](原有机制) ⊕ [重涂色-区域覆盖](创新：对角标记对定义的矩形区域形成优先重涂区) + [擦除]（两套重涂机制以优先级共存，非顺序串联）

**来源原语**：重涂色(recolor) ← c7d4e6ad/36fdfd69；占位像素(placeholder_pixel) ← c7d4e6ad；行控制色(row_control_color) ← c7d4e6ad；同行对齐(same_row_align) ← c7d4e6ad；对角配对(diagonal_pairing) ← 56ff96f3；同色对定义矩形(pair_defines_rect) ← 56ff96f3；包围框内部(inside_bbox) ← 36fdfd69；擦除(erase) ← 604001fa

**依赖链**：两套规则并行作用于同一组占位像素——逐行控制色提供默认重涂方案，而对角标记区提供局部覆盖方案。求解者必须同时识别两套系统并发现区域覆盖优先于逐行控制的层级关系。这是同时约束满足结构：没有固定的执行先后顺序，只有优先级规则。

灰色占位像素的最终颜色由两套竞争规则决定：在对角标记对定义的矩形区域内取标记色，区域外取同行控制色。

**输入结构**：约 12x12 网格，黑(0)背景。网格中有一片由灰(5)像素构成的连通区域，占据网格约 40-60% 的面积，形态不规则（非矩形）。在最左列，每一个包含灰像素的行恰好有一个非黑、非灰的控制像素，颜色从 {红(2), 绿(3), 蓝(1)} 中取用（不同行可不同）。不含灰像素的行在最左列无控制像素。此外，在灰色区域范围内（不在最左列），散布 2-3 对标记像素对：每对由 2 个同色像素组成，颜色从 {橙(7), 黄(4), 青(8)} 中取用（每对颜色唯一，且不与任何行控制色重复）。每对的两个像素不在同一行也不在同一列（确保定义非退化矩形）。不同对定义的矩形区域可以重叠。生成约束：至少有一个灰像素同时位于某个标记区域内且其所在行有不同的控制色，以确保两套规则冲突可观测。

**规则**：
1. 对每对同色标记像素，以它们为对角顶点确定一个轴对齐矩形区域（含边界行列）。
2. 对每个灰(5)像素判定其归属：
   - 若该像素位于一个或多个标记矩形区域内部，则取所在矩形中面积最小者的标记颜色（面积相同时取标记对中行坐标较小的那个像素所属的对的颜色）。
   - 若该像素不在任何标记矩形区域内，则取该行最左列控制像素的颜色。
3. 将每个灰(5)像素重涂为其归属规则确定的颜色。
4. 擦除所有标记像素（将标记对像素恢复为黑(0)）。
5. 最左列的控制像素保持不变。

**关键洞察**：两套重涂机制在空间上重叠竞争——逐行控制色是全局默认值，对角标记区是局部覆盖层。求解者仅从单个示例可能只观察到一套规则；必须对比多个示例（其中标记区位置不同）才能发现优先级层级关系。

## 新题 4：L 标记编码对角方向，射线接触触发重涂

**组合逻辑**：[标记朝向编码](创新：编码对角方向而非颜色) → [射线延伸-对角](创新：方向由外部标记决定而非固定四向) → [接触判定 + 重涂色](创新：射线接触判定替代引导线接触判定)

**来源原语**：标记朝向编码颜色(marker_orientation_encodes_color) ← 604001fa（创新为编码方向）；射线延伸(ray_extend) ← ea786f4a；对角放射(diagonal_radiation) ← ea786f4a；接触判定(contact_detection) ← 0d87d2a6；接触则重涂(recolor_on_contact) ← 0d87d2a6；标记体(marker) ← 604001fa；孤立像素(isolated_pixel) ← ea786f4a；前景对象(foreground_object) ← 0d87d2a6；擦除(erase) ← 604001fa

**依赖链**：L 标记的缺角位置编码对角方向 → 方向决定射线的空间轨迹 → 射线轨迹与前景对象的空间接触关系决定哪些对象被选中 → 被选中对象的重涂颜色取自射线源点的颜色。四步中，方向编码、射线传播、接触检测、颜色传递逐级依赖，且射线的空间路径是连接"编码"与"选择"的不可省略的中间结构。

L 形标记的缺角编码一个对角方向，从相邻的彩色孤立像素沿该方向发射射线，被射线触及的蓝色前景对象重涂为射线的颜色。

**输入结构**：约 14x14 网格，黑(0)背景。网格中有 3-4 个"发射单元"，每个发射单元由一个彩色孤立像素和一个紧邻的橙(7) L 形三连块组成。具体地，每个 L 形三连块占据一个 2x2 方块的三个格子（均为橙(7)），剩余第四格恰好是该孤立像素的位置。孤立像素的颜色互不相同，从 {红(2), 绿(3), 黄(4), 品红(6)} 中取用。各发射单元之间至少间隔 3 格。另外，网格中散布 2-4 个蓝(1) 4-连通前景对象（3-8 像素，形态各异，非矩形），各对象之间互不相邻。生成约束：每个蓝色对象至少被一条对角射线 4-邻接触及；至少有一个蓝色对象不被任何射线触及（以形成对照）。

**规则**：
1. 对每个发射单元，确定 L 形三连块在 2x2 方块中缺失的角位置。缺角位置编码对角方向：
   - 缺左上角 → 射线方向为左上（NW，行减列减）
   - 缺右上角 → 射线方向为右上（NE，行减列增）
   - 缺左下角 → 射线方向为左下（SW，行增列减）
   - 缺右下角 → 射线方向为右下（SE，行增列增）
2. 从每个孤立像素出发，沿编码的对角方向逐步（行列各加减 1）绘制射线像素，颜色为该孤立像素的颜色。射线在碰到网格边界时停止（最后一个像素位于网格内的最远合法格）。射线像素绘制在黑(0)格上；若射线路径经过非黑像素（包括其他射线、蓝色对象、其他发射单元），射线在该像素之前的最后一个黑格处停止，不覆盖已有像素。
3. 射线全部绘制完成后，检查每个蓝(1)前景对象：若该对象的任何像素与任何射线像素 4-邻相邻（上下左右紧邻），则该对象被"选中"。
4. 被选中的蓝色对象整体重涂为触及它的射线的颜色。若多条不同颜色的射线同时触及同一对象，取触及像素数较多的射线的颜色；若触及像素数相同，取源孤立像素行坐标较小的射线的颜色。
5. 未被任何射线触及的蓝色对象保持蓝(1)不变。
6. 擦除所有橙(7) L 形三连块像素（恢复为黑(0)）。孤立像素和射线像素保留。

**关键洞察**：L 形标记在源题中编码颜色，这里被创新为编码对角方向——同一几何结构（2x2 缺角）承载了完全不同语义的信息。求解者必须先解读方向编码，再追踪射线空间轨迹，最后通过接触判定确定重涂目标。

## 新题 5：杯口方向发射内含碎片至边界堆叠

**组合逻辑**：[开口朝向](创新：编码推移方向而非填充出口) + [推移](创新：推移对象嵌套在容器内，由容器几何决定方向) + [擦除] + [无重叠拼合](创新：推移终点受先到碎片约束)

**来源原语**：推移(push) ← 5623160b；开口朝向(opening_direction) ← d4f3cd78；接触侧决定方向(contact_side_dir) ← 5623160b；推至边界停止(stop_at_boundary) ← 5623160b；杯形轮廓(cup_outline) ← d4f3cd78；开口(opening) ← d4f3cd78；多连块碎片(polyomino_fragment) ← b7cb93ac；无重叠拼合(non_overlap_packing) ← b7cb93ac；擦除(erase) ← bae5c565

**依赖链**：杯的开口朝向决定碎片的推移方向 → 碎片沿该方向平移，终点由网格边界或先到碎片决定 → 处理顺序影响各碎片的最终位置（先处理的碎片成为后处理碎片的障碍）。杯作为"发射器"同时编码了方向和内容，推移距离是碎片之间的全局空间约束。

每个杯形轮廓内含一个多连块碎片，碎片沿杯口方向被弹射出去直到碰到网格边界或另一个已落位的碎片为止。

**输入结构**：约 16x16 网格，黑(0)背景。网格中有 3-4 个杯形轮廓，每个由灰(5)像素构成矩形环（边界框约 5x5 至 6x6），其中恰好一侧的像素全部缺失形成开口。不同杯的开口分别朝向不同基本方向。每个杯内部（轮廓围成的区域）包含一个 4-连通单色多连块碎片（3-5 像素），碎片颜色互不相同，从 {红(2), 蓝(1), 绿(3), 黄(4)} 中取用。碎片与杯壁之间至少有 1 格黑色间隙（碎片不接触壁）。各杯边界框互不重叠，杯之间至少间隔 2 格。生成约束：在推移处理顺序下，任意两个碎片的最终位置不会重叠；至少有两个碎片被推向同一侧边界以产生堆叠效果。

**规则**：
1. 对每个杯形轮廓，识别开口所在侧（缺失壁的方向）。该方向即为其内含碎片的推移方向。
2. 按阅读顺序（从上到下、从左到右，以杯边界框左上角坐标为准）依次处理各杯。
3. 处理某杯时：
   a. 将碎片从杯内沿推移方向平移。平移以整像素为步长，碎片保持形状不变。
   b. 碎片停止于以下两个条件中先满足的那一个：碎片的某个像素到达网格边界（该方向上碎片最前端像素的下一步将越出网格）；或碎片的某个像素的下一步位置已被先前落位的碎片占据（4-邻接触即停止，碎片最终位置与障碍碎片紧邻但不重叠）。
   c. 在碎片的最终位置绘制碎片像素。
4. 所有碎片推移完成后，擦除全部灰(5)杯形轮廓像素（恢复为黑(0)）。
5. 输出只包含黑(0)背景和各碎片在其最终位置的彩色像素。

**关键洞察**：杯不是被填充或被变换的目标——它是一个"发射器"，其开口方向编码了碎片的弹射轨迹。多个碎片共享同一侧边界时产生堆叠约束，使得处理顺序成为决定最终布局的关键因素。

## 新题 6：引导线交叉点处印章覆盖，交叉色门控镜像

**组合逻辑**：[连线-引导线](生成交叉网格) × [印章覆盖](创新：在交叉点而非标记位置印章) × [镜像](创新：由交叉点处线色匹配关系触发) + [擦除]

**来源原语**：连线/引导线(line_drawing/guide_line) ← 0d87d2a6；边界标记对(border_marker_pair) ← 0d87d2a6；印章覆盖(stamp) ← 3e980e27；镜像(mirror) ← 3e980e27/59341089；颜色配对(color_pairing) ← 3e980e27；标记色匹配目标位(marker_color_matches_dest) ← 3e980e27；特定标记触发镜像(marker_triggers_mirror) ← 3e980e27；精灵体(sprite) ← 3e980e27/cd3c21df；擦除(erase) ← 604001fa

**依赖链**：边界标记对决定引导线的行/列位置和颜色 → 引导线交叉创造印章坐标点 → 每个交叉点的水平/竖直线色分别与模板精灵体内嵌指示色做匹配 → 匹配结果独立决定是否沿对应轴镜像 → 最终在该点印章（可能经过 0/1/2 次镜像的）模板副本。引导线提供"在哪里"，颜色匹配提供"怎么变换"，模板提供"印什么"——三者交织不可分。

边界标记对绘制引导线，在每个引导线交叉点处印章模板精灵体的副本；交叉点处的水平线色和竖直线色分别决定是否对模板做左右或上下镜像。

**输入结构**：约 16x16 网格，黑(0)背景。网格四侧边界上有若干标记像素，同色标记总是成对出现在对侧边界的同行或同列：例如左边界第 4 行有红(2)、右边界第 4 行也有红(2) → 定义一条水平红色引导线；上边界第 7 列有绿(3)、下边界第 7 列也有绿(3) → 定义一条竖直绿色引导线。共有 2-3 条水平引导线和 2-3 条竖直引导线，颜色从 {红(2), 绿(3), 蓝(1)} 中取用（不同引导线可同色或不同色）。在网格的某个角落区域（不被任何引导线穿过），有一个小型模板精灵体（4-连通，3-5 像素，边界框不超过 3x3），由橙(7)像素构成。模板中恰好有一个像素被替换为指示色，该指示色为红(2)或绿(3)（与某条引导线同色）。生成约束：模板精灵体不关于水平轴对称或不关于竖直轴对称（使镜像结果可视觉区分）。各引导线交叉点之间至少间隔 3 格（保证印章不重叠）。

**规则**：
1. 对每对同色对侧边界标记，画一条贯穿网格全宽（水平线）或全高（竖直线）的引导线，颜色为该标记对的颜色。引导线像素覆盖在黑(0)格上。
2. 找出所有水平引导线与竖直引导线的交叉格子。每个交叉格拥有两个属性色：水平线色 H 和竖直线色 V。
3. 对每个交叉点，准备模板精灵体的一个副本，然后按以下规则变换：
   - 若 H 等于模板中指示像素的颜色，则将副本做左右镜像（以模板边界框竖直中轴翻转）。
   - 若 V 等于模板中指示像素的颜色，则将副本做上下镜像（以模板边界框水平中轴翻转）。
   - 若 H 和 V 均匹配，则先左右再上下（等价于 180 度旋转）。
   - 若均不匹配，不做变换。
4. 将变换后的副本以交叉格为中心印章到网格上。印章像素覆盖引导线像素和黑(0)像素。多个印章不会重叠（由生成约束保证）。
5. 擦除原始模板精灵体（角落区域恢复为黑(0)/引导线色）。

**关键洞察**：每个引导线交叉点是一条"条件印章指令"——水平和竖直方向的线色各自独立地门控一个镜像轴，因此同一模板在不同交叉点可呈现最多四种不同朝向。求解者必须同时掌握引导线生成规则、交叉点定位、颜色匹配门控三层逻辑。

## 新题 7：含噪象限主色填注杯体，射线跨界变色

**组合逻辑**：[压缩/去噪](提取象限主色) + [填充](创新：填充色来自宏观区域分析而非局部标记) + [射线延伸](创新：射线穿越象限边界时变色) + [擦除]

**来源原语**：压缩(compress) ← 996ec1f3；去噪取主色(denoise_majority) ← 996ec1f3；十字分隔线(cross_separator) ← 996ec1f3；四象限(quadrant) ← 996ec1f3；主色代表区域(dominant_per_region) ← 996ec1f3；填充(fill) ← d4f3cd78；杯形轮廓(cup_outline) ← d4f3cd78；开口朝向(opening_direction) ← d4f3cd78；射线延伸(ray_extend) ← d4f3cd78/ea786f4a；开口决定延伸向(opening_extend_dir) ← d4f3cd78；擦除(erase) ← bae5c565

**依赖链**：十字分隔线划定四个象限 → 对各象限去噪获得主色 → 主色决定各象限内杯的填充色和射线初始色 → 射线跨越十字线进入另一象限时，颜色切换为目标象限的主色 → 射线遇到另一象限的杯壁时停止。宏观区域分析（去噪）与微观空间操作（杯填充、射线传播）通过十字线的双重身份（区域边界 + 变色触发器）紧密耦合。

十字线将网格分为四个含噪象限，提取各象限主色后填注象限内的杯体，并从杯口发射射线——射线越过十字线时变为目标象限的主色。

**输入结构**：约 15x15 网格。一条完整行和一条完整列的栗(9)像素形成十字分隔线，将网格分为四个矩形象限（各象限至少 5x5）。每个象限内：大部分非栗、非黑格子填充为该象限的主色（主色从 {红(2), 绿(3), 蓝(1), 黄(4)} 中取用，四象限主色互不相同），并混入少量其他颜色的噪声像素（噪声色也取自上述四色，但在该象限中数量远少于主色，主色占该象限非栗非灰像素的 70% 以上）。每个象限中恰有一个由灰(5)像素构成的小型杯形轮廓（边界框约 3x4），有一侧开口。四个杯的开口方向互不相同。杯内部初始为黑(0)。生成约束：每个杯的开口朝向使得从该杯口发出的射线会穿越十字线进入相邻象限（例如位于左上象限的杯开口朝右或朝下）。

**规则**：
1. 确定十字分隔线的位置（栗(9)色贯穿整行/整列的唯一行列对）。
2. 对每个象限，统计其中所有非栗(9)、非黑(0)、非灰(5)像素的颜色出现频次，频次最高者为该象限的主色。
3. 构建输出网格：以黑(0)为背景，保留栗(9)十字线和灰(5)杯形轮廓。
4. 将每个杯的内部（杯轮廓围成的封闭区域的黑(0)格）填充为该杯所在象限的主色。
5. 从每个杯的开口处，沿开口方向发射射线。射线起点为开口外侧紧邻的第一格，颜色为该杯所在象限的主色。射线逐格延伸：
   - 在同一象限内，射线保持发射时的颜色。
   - 当射线到达栗(9)十字线时，射线像素覆盖该栗(9)格（该格变为射线颜色）并继续前进。进入新象限后，射线颜色切换为新象限的主色，后续像素均使用新色。
   - 射线在以下情况停止：到达网格边界（最后一个像素在边界格）；或碰到灰(5)杯壁像素（射线停止于壁外侧紧邻格，不覆盖杯壁）。
6. 输出中不保留象限内的原始填充色和噪声（步骤 3 已清除）。

**关键洞察**：十字分隔线身兼三职——区域划分器、去噪边界、射线变色触发器。射线携带的颜色不是固定的：它在每次跨越十字线时重新获取目标象限的主色，因此一条射线可以呈现两种颜色。求解者必须先完成宏观的象限去噪分析，才能确定微观的杯填充色和射线变色规则。
