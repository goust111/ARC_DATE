## 新题 1：碰撞优先的重力滑落

**组合逻辑**：[滑动](已有) x [重涂色](已有) — 面积同时决定位移量和碰撞时的颜色优先级（创新耦合）

**来源原语**：滑动(slide) — 8e301a54；重涂色(recolor) — ba97ae07；连通分量(connected_component) — 8e301a54；面积决定位移(area_determines_displacement) — 8e301a54；交叉(crossing) — ba97ae07；超界裁剪(clip_beyond_edge) — 8e301a54

**依赖链**：每个对象的面积同时充当两个角色——它决定了该对象向下滑落多少行，也决定了当着陆区域与其他对象重叠时谁的颜色胜出。面积的"位移"角色创造了碰撞机会，面积的"优先级"角色解决了碰撞冲突，两者不可分拆。

将每个前景对象按自身像素面积向下滑落，着陆后若发生重叠则保留面积更大者的颜色。

**输入结构**：
- 约 12x12 的黑(0)背景网格。
- 3~5 个 4-连通单色前景对象，颜色互不相同，每个对象由 3~8 个像素构成，形状为任意 4-连通形态（不限定具体外形）。
- 所有对象分布在网格上半部（行索引 < 网格高度的一半），彼此不相邻（最近像素间至少隔 1 个背景像素）。
- 生成约束：至少有两个对象在各自滑落后的着陆区域会产生至少 1 个像素位置的重叠；所有对象的面积两两不同。

**规则**：
1. 清空画布为黑(0)。
2. 计算每个前景对象的面积 A（像素数）。
3. 将每个对象整体向下平移 A 行，列坐标不变。
4. 超出网格底部边界的像素直接舍弃。
5. 若多个对象着陆后有像素重叠，重叠位置取面积更大的对象的颜色。
6. 处理顺序：先绘制面积最小的对象，再逐步绘制面积更大的对象（大面积后绘覆盖小面积），从而自然实现面积优先。
7. 非重叠像素保留各自对象的原色。

**关键洞察**：面积不仅决定"移动多远"，还决定"碰撞时谁赢"——同一属性在位移和优先级两个逻辑环节中扮演不同角色。需要对比多个示例（有碰撞 vs 无碰撞）才能归纳出优先级规则。

## 新题 2：淘汰计数决定放大倍率

**组合逻辑**：[筛选·对称性](已有) → [计数](已有) → [像素放大](已有) — 被淘汰的干扰体数量成为放大系数（创新耦合）

**来源原语**：筛选(filter) — 72ca375d；像素放大(pixel_scale) — ac0a08a4；计数(counting) — ac0a08a4；精灵体(sprite) — 72ca375d, ae4f1146；干扰体(distractor) — 72ca375d；对称性筛选目标(symmetry_filter) — 72ca375d；数量决定倍率(count_determines_scale) — ac0a08a4

**依赖链**：对称性检测将精灵体分为目标和干扰两组，干扰组的数量 N 成为放大系数，目标精灵体按 N 倍像素放大。筛选结果和放大系数是同一步分类的两个产物——不做筛选就不知道放大多少，不知道总数就无法确认筛选是否正确。

从多个精灵体中找出唯一对称的那个，将其按被淘汰精灵体的数量进行像素放大。

**输入结构**：
- 约 15x15 的黑(0)背景网格。
- 4~6 个单色 4-连通精灵体，颜色互不相同，每个精灵体由 3~6 个像素构成。
- 恰好一个精灵体具有某种对称性（垂直反射、水平反射或 180 度旋转对称），其余精灵体均无任何对称性。
- 精灵体彼此不相邻，不接触网格边界。
- 生成约束：精灵体总数至少为 4（保证放大系数 >= 3，使放大效果明显）。

**规则**：
1. 裁剪每个 4-连通前景对象为最小边界框精灵体。
2. 对每个精灵体做对称性检测：测试垂直反射、水平反射和 180 度旋转对称。
3. 选出唯一具有对称性的精灵体作为目标。
4. 计算被淘汰的精灵体数量 N = 总精灵体数 - 1。
5. 将目标精灵体做 N 倍像素放大：每个像素替换为 N x N 的同色方块。
6. 输出仅包含放大后的目标精灵体，背景为黑(0)，输出尺寸为原精灵体边界框的 N 倍。

**关键洞察**：放大系数不来自目标自身的像素数（与参考题 ac0a08a4 不同），而来自被淘汰对象的数量——必须先完成筛选才能确定放大倍率，两个步骤通过"分类结果的互补计数"耦合。

## 新题 3：图例定义的选择性布尔运算

**组合逻辑**：[布尔运算](已有) x [擦除·图例过滤](已有) — 图例重新定义哪些颜色被视为"前景"参与布尔运算（创新耦合）

**来源原语**：布尔运算(boolean_op) — 6430c8c4；擦除(erase) — d59b0160；填充(fill) — e9c9d9a1；掩码区域(mask_region) — 6430c8c4；分隔线(divider_line) — 6430c8c4；图例区域(legend_region) — d59b0160；对齐(alignment) — 6430c8c4；包含全部目标色(contains_all_target_colors) — d59b0160；双掩码交集输出(bg_intersection_out) — 6430c8c4

**依赖链**：图例指定"活跃色集合" → 两掩码中非活跃色像素被视为背景 → 仅活跃色像素参与逐位对齐的布尔交集 → 输出交集图案。图例改变活跃色定义就会改变整个布尔结果，而布尔运算的输入依赖于图例的过滤。

用图例指定哪些颜色算"前景"，然后在两个被分隔线隔开的掩码间做布尔交集，仅输出双方均有活跃色前景的位置。

**输入结构**：
- 约 11x7 的黑(0)背景网格。
- 左上角有一个小图例区：一个 2x1 或 1x2 的区域，内含 1~2 个非背景色像素，这些颜色即为"活跃色"。图例区域用灰(5)单像素边框围住（边框为 L 形，仅在图例的右侧和下方各一像素）。
- 图例下方，一条全宽的绿(3)分隔行将剩余区域分为上下两个等高等宽的矩形掩码（如各 4x7）。
- 每个掩码中散布 2~3 种非背景颜色的像素，其中包含活跃色和非活跃色。
- 生成约束：两掩码尺寸相同；活跃色在两掩码中均有出现；至少存在一个位置上下掩码都有活跃色像素。

**规则**：
1. 读取图例区内部的颜色集合，记为活跃色集合 S。
2. 在上掩码和下掩码中，将不属于 S 的非背景色像素视同背景（忽略它们）。
3. 移除绿(3)分隔行，将上下掩码逐像素对齐。
4. 输出与单个掩码同尺寸。
5. 对于每个位置：若上掩码在该位置有活跃色像素，且下掩码在该位置也有活跃色像素，则输出红(2)；否则输出黑(0)。

**关键洞察**：图例不是过滤整个连通分量（与参考题 d59b0160 不同），而是在像素级别重新定义"前景"概念——同一对掩码搭配不同图例会产生完全不同的布尔交集结果，必须通过示例确认图例的过滤粒度。

## 新题 4：拉伸后空心化画叉

**组合逻辑**：[拉伸](已有) → [擦除+连线·X 图案](已有) — 拉伸改变矩形内部尺寸，从而改变 X 图案的臂长和几何形态（创新耦合）

**来源原语**：拉伸(stretch) — b548a754；擦除(erase) — 8cb8642d；连线(draw_lines) — 8cb8642d；实心矩形(solid_rectangle) — 8cb8642d；空心矩形(hollow_rectangle) — b548a754；标记像素(marker_pixel) — b548a754, 8cb8642d；标记在矩形内(marker_inside_rect) — 8cb8642d；标记决定拉伸终点(marker_determines_stretch_endpoint) — b548a754

**依赖链**：外部标记像素 → 确定拉伸方向和终点 → 矩形扩展为新尺寸 → 新尺寸决定内部空间 → 内部空间决定 X 图案的对角线长度和交叉点位置。三个操作通过矩形的几何尺寸链式耦合。

将实心矩形拉伸到外部标记像素处，然后空心化并在扩展后的内部绘制嵌入标记色的 X 图案。

**输入结构**：
- 约 12x14 的黑(0)背景网格。
- 一个蓝(1)实心矩形（约 3x3 到 4x5），内部有一个嵌入的红(2)标记像素，严格在矩形边框内部（不在边界行列上）。
- 矩形外部有一个黄(4)孤立像素，位于矩形的正上方、正下方、正左方或正右方（与矩形的某条边在行或列上对齐）。
- 生成约束：黄(4)像素与矩形最近边之间至少隔 3 行或 3 列，保证拉伸后内部空间足够绘制 X 图案（内部至少 3x3）。

**规则**：
1. 确定黄(4)标记像素相对于矩形的方向（上/下/左/右）。
2. 将矩形的对应边拉伸到黄(4)标记所在的行或列。黄标记像素被拉伸后的蓝(1)边框覆盖。矩形的其他三条边不动。
3. 保留拉伸后矩形的蓝(1)外边框（一像素宽的矩形环）。
4. 将边框围住的内部区域清空为黑(0)。
5. 从内部区域的四个角像素出发，分别沿 45 度对角线方向画红(2)线段，直到线段相遇或到达对角方向的内部边界。
6. 若内部宽度或高度为奇数，中心行列的交汇像素也填红(2)以连通 X 的四臂。

**关键洞察**：外部标记决定拉伸方向和距离，从而改变矩形内部尺寸，最终影响 X 图案的几何形态——若不先完成拉伸，就无法确定 X 的绘制范围。嵌入标记像素在拉伸前标识颜色角色、在拉伸后被空心化消除，其信息仅通过 X 的颜色传递。

## 新题 5：形状归一化重色后对角平铺

**组合逻辑**：[重涂色·平移归一化](已有) x [拼接·对角排布](已有) — 重涂色结果中的空行既是"不操作区"又是对角平铺的结构分割标记（创新双重角色）

**来源原语**：重涂色(recolor) — ad38a9d0；拼接(concatenate) — fb791726；占位符对象(placeholder_obj) — ad38a9d0；对角副本(diag_copy) — fb791726；分隔行(separator_row) — fb791726；形状相同(same_shape) — ad38a9d0；对角排布(diag_layout) — fb791726；平移归一化(translate_normalize) — ad38a9d0；空行填分隔色(blank_row_separator) — fb791726

**依赖链**：占位符对象的平移归一化掩码 → 形状到颜色的映射 → 重涂色 → 识别全黑空行 → 空行在对角平铺中变为全宽分隔色行。重涂色是按对象局部执行的，但空行的位置是全局结构，它同时服务于两个逻辑：在重涂色阶段它是"无对象"的留白，在平铺阶段它是分块标记。

先按形状归一化给占位符对象重涂色，然后将整个结果沿主对角线平铺两份，原空行在两份副本中均填充分隔色。

**输入结构**：
- 约 8x8 的黑(0)背景网格。
- 4~6 个灰(5)占位符 4-连通对象，每个由 2~4 个像素构成，分为 2~3 种平移归一化形状。
- 网格中有 1~2 条全黑(0)空行（整行无任何前景像素），将对象在垂直方向分隔成若干组。
- 生成约束：每种归一化形状至少出现 2 次；空行不在首行或末行。

**规则**：
1. 对每个灰(5)占位符对象计算平移归一化掩码（将边界框左上角对齐到原点）。
2. 将相同归一化掩码的对象分配同一颜色：按该形状在输入中首次出现的位置排序（行优先、列次之），第一种形状分配蓝(1)，第二种分配红(2)，第三种分配绿(3)。
3. 将所有灰(5)像素替换为对应颜色，其余像素保持黑(0)不变，得到重涂色后的 H x W 网格。
4. 构建 2H x 2W 的黑(0)画布。
5. 将重涂色后的网格放入画布的左上 H x W 区域和右下 H x W 区域（对角排布）。
6. 原输入中的全黑空行，在两份对角副本中对应的行均改为全宽（2W）绿(3)分隔行。

**关键洞察**：空行在重涂色阶段看起来无关紧要（它只是没有对象的留白），但在对角平铺阶段它变成了结构性标记——需要对比示例才能发现空行与分隔色行的对应关系，以及分隔行在两份副本中都会出现。

## 新题 6：孔洞填充改变对称性后筛选

**组合逻辑**：[填充·调色板映射](已有) x [筛选·对称性](已有) — 填充操作创造对称性，筛选判据依赖填充结果（创新耦合）

**来源原语**：填充(fill) — dbff022c；筛选(filter) — 72ca375d；裁剪(crop) — 72ca375d；空心精灵体(hollow_sprite) — dbff022c；封闭区域(enclosed_region) — dbff022c；调色板图例(palette_legend) — dbff022c；对称性筛选目标(symmetry_filter) — 72ca375d；边框色映射填充色(border_to_fill_mapping) — dbff022c

**依赖链**：调色板图例 → 边框色到填充色映射 → 填充每个空心精灵体的孔洞 → 填充改变了精灵体的整体色彩分布 → 对称性检测现在考虑颜色 → 唯一变为颜色对称的精灵体被选出。不填充就无法判断对称性，不读调色板就无法填充，三步紧密耦合。

用调色板图例填充空心精灵体的孔洞，然后裁剪出填充后在颜色层面呈现对称性的唯一精灵体。

**输入结构**：
- 约 14x14 的黑(0)背景网格。
- 网格底部边缘有一个 2 x N 的调色板条（N = 边框色数量）：上行列出边框色，下行列出对应填充色（如蓝(1)→红(2)，绿(3)→黄(4)，橙(7)→品红(6)）。
- 3~4 个空心精灵体散布在网格上方，每个约 5x5 到 7x7 像素。每个精灵体有一种边框色（出现在调色板上行中），内部有一个或多个被边框完全包围的黑(0)孔洞区域。
- 精灵体的外轮廓形状各不相同，每个精灵体的边框形状本身都是关于某条轴对称的。
- 生成约束：恰好一个精灵体在其孔洞被调色板指定的颜色填充后，整体（边框色 + 填充色）呈现垂直或水平反射对称；其余精灵体填充后不对称（例如孔洞位置不对称，导致填充色分布不对称）。

**规则**：
1. 读取网格底部的调色板条，建立边框色 → 填充色的映射。
2. 对每个空心精灵体，识别其边框色，找到被边框完全包围的黑(0)孔洞区域（不接触网格边界的背景连通分量）。
3. 用映射得到的填充色填充孔洞。
4. 对每个填充后的精灵体做颜色对称性检测：裁剪为最小边界框，检测整个裁剪图案（含边框色和填充色）是否关于垂直中轴或水平中轴反射对称。
5. 输出唯一通过对称性检测的精灵体的最小边界框裁剪。

**关键洞察**：填充前所有精灵体的边框外形都是对称的（单色看起来都对称），但孔洞的不对称分布使得填充后只有一个精灵体保持整体对称——对称性是由填充操作与孔洞位置的交互"涌现"出来的，不是预设的。

1. 保留绿(3)分隔线不变。

## 新题 8：控制极值定框后端点锚定连线

**组合逻辑**：[描框·控制极值](已有) x [补全·端点锚定](已有) x [连线](已有) — 控制像素定义的矩形框同时约束端点连线的有效绘制空间（创新耦合）

**来源原语**：描框(draw_frame) — e4075551；补全(reconstruct) — 98c475bf；连线(draw_line) — e4075551, 3bd67248；控制像素(control_pixel) — e4075551；端点标记(endpoint_marker) — 98c475bf；极值行列(extreme_row_col) — e4075551；锚点定位(anchor_position) — 98c475bf；颜色对应形状(color_to_shape) — 98c475bf

**依赖链**：四个控制像素的极值行列 → 确定矩形框的边界 → 框内的端点标记对按同色配对 → 同色端点对之间画直线连接 → 连线被框边界裁剪。矩形框的几何定义和端点连线的空间约束是同一组控制像素决定的——去掉框就没有边界约束，去掉端点就没有连线内容。

用四个控制像素的极值位置画矩形框，再将框内成对的同色端点用直线连接。

**输入结构**：
- 约 14x14 的黑(0)背景网格。
- 四个单像素的控制点，颜色互不相同（如红(2)、蓝(1)、黄(4)、绿(3)），分别位于全局所有前景像素中最上、最下、最左、最右的位置（每个极值方向恰好由一个控制点独占）。
- 四个控制点围成的矩形内部，散布 2~3 对端点标记。每对端点标记同色且该色与所有控制点颜色均不同（如品红(6)两个、橙(7)两个、灰(5)两个）。每对端点标记要么在同一行，要么在同一列。
- 端点标记严格在四个控制点围成的矩形内部（不在边界行列上）。
- 生成约束：不同颜色的端点对的连线可能交叉。

**规则**：
1. 找到最上方控制像素的行号 r_top、最下方的 r_bot、最左方的列号 c_left、最右方的 c_right。
2. 用灰(5)画矩形框：顶边在 r_top 行（从 c_left 到 c_right），底边在 r_bot 行，左边在 c_left 列（从 r_top 到 r_bot），右边在 c_right 列。若灰(5)与某对端点标记颜色相同，则框色改为栗(9)。
3. 四个控制像素保留原色，绘制在框边上，不被框色覆盖。
4. 对框内每对同色端点标记，用该颜色画直线连接：若两端点在同一行则画水平线段（填充两端点之间所有像素），若在同一列则画垂直线段。
5. 绘制顺序：按端点标记颜色在输入中首次出现的位置排列（行号小的优先，行号相同则列号小的优先），先绘制的在下层，后绘制的在交叉点覆盖先绘制的。

**关键洞察**：矩形框不只是视觉装饰——它由控制像素的极值位置唯一确定，同时为端点连线划定有效空间。去掉控制像素的框构建步骤，连线的空间边界就无法确定；去掉端点连线，框内就是空的——两部分通过"框内空间"这一共享概念耦合。

## 新题 10：布尔交集的自决定放大

**组合逻辑**：[布尔运算](已有) → [像素放大](已有) — 布尔交集的结果同时充当被放大的图案内容和放大系数的来源（创新：输出自引用）

**来源原语**：布尔运算(boolean_op) — 6430c8c4；像素放大(pixel_scale) — ac0a08a4；掩码区域(mask_region) — 6430c8c4；分隔线(divider_line) — 6430c8c4；前景像素(foreground_pixel) — ac0a08a4；对齐(alignment) — 6430c8c4；双掩码交集输出(bg_intersection_out) — 6430c8c4；数量决定倍率(count_determines_scale) — ac0a08a4；前景数为放大系数(foreground_count_as_scale_factor) — ac0a08a4

**依赖链**：分隔线分割两掩码 → 逐像素对齐 → 计算前景交集（双方都有非背景色的位置）→ 交集像素数 N = 放大系数 → 用 N 倍像素放大交集图案。布尔运算的输出同时决定了"放大什么"（图案形状）和"放大多少"（像素数），是一个自引用结构。

两掩码做前景交集，交集图案的像素数恰好是放大系数，输出该交集图案的像素放大版。

**输入结构**：
- 约 11x5 的黑(0)背景网格。
- 一条全宽灰(5)分隔行将网格分为上下两个等高等宽的矩形掩码（如各 5x5）。
- 上掩码有若干红(2)前景像素，下掩码有若干蓝(1)前景像素，分别在各自的黑(0)背景上。
- 生成约束：两掩码尺寸相同；上下掩码中恰好有 2~4 个位置同时为非背景色（交集像素数在 2~4 之间，控制输出尺寸合理）。

**规则**：
1. 移除灰(5)分隔行。
2. 将上下掩码逐像素对齐。
3. 计算前景交集：对每个位置，若上掩码该位置为非背景色且下掩码该位置也为非背景色，则该位置为交集点。
4. 生成交集图案 P：与单个掩码同尺寸，交集位置填绿(3)，其余位置填黑(0)。
5. 计算交集像素数 N（P 中绿(3)像素的总数）。
6. 将图案 P 做 N 倍像素放大：每个像素替换为 N x N 的同色方块，输出尺寸为 (掩码高 x N) x (掩码宽 x N)。

**关键洞察**：布尔运算的结果同时扮演两个角色——它既是被放大的图案内容（决定形状），又通过其前景像素数决定放大倍率（决定大小）。增减任一掩码中的前景像素会同时改变交集的形状和放大系数，形成一个自引用的耦合结构。
