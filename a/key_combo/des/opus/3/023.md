## 新题 1：同心环的调色板周期涂色

**组合逻辑**：[切比雪夫距离→同心方环](已有) + [循环填充](已有，创新：作用目标从线性列改为同心环层) + [标记高度决定长度](已有，创新：运行长度控制连续环数而非连续行数) → [擦除](已有)

**来源原语**：切比雪夫距离/同心方环/中心对齐/距离映射(ac0c2ac3)，循环填充/调色板列/顺序排列(e7b06bea)，标记高度决定长度/长度标记段(e7b06bea)，擦除(e7b06bea)

**依赖链**：调色板列提供颜色序列，灰色标记段的高度提供运行长度 R，同心方环结构提供空间框架；三者缺一不可——环的距离决定"第几个色槽"，R 决定每个色槽跨越几层环，调色板决定每个色槽的颜色。运行长度不是简单地逐像素涂色，而是以整层环为单位批量着色，这是源题中不存在的结构关系。

将一个奇数方阵中的同心方环按调色板循环着色，每种调色板颜色连续覆盖 R 层环（R 由灰色标记段高度编码），用完调色板后回到第一种颜色继续循环，直到所有环层都被着色。

**输入结构**：一个奇数边长的方阵（约 13x13 至 17x17），以黑(0)为背景。网格中心像素用一种非背景色标记（如红(2)），表示同心环的中心。网格右侧边缘有一列垂直调色板条，由 2~4 种不同颜色的像素从上到下排列（每种颜色占 1 个像素，如蓝(1)、绿(3)、橙(7)），调色板条紧贴右边界且顶部对齐。网格左上角有一段灰(5)竖直线段（1~3 像素高），顶部对齐网格第一行。调色板条和灰色段之间、与中心标记之间无重叠，均在不同区域。生成约束：网格边长足够大以容纳至少 2 轮完整调色板循环。

**规则**：
1. 识别网格中心像素位置 (cr, cc)，即行列索引均为 (边长-1)/2 的位置。
2. 读取右侧边缘的调色板条，从上到下获得颜色序列 P = [P0, P1, ..., Pk-1]（k 为调色板颜色数）。
3. 读取左上角灰(5)段的像素数 R（运行长度）。
4. 对网格中每个像素 (r, c)，计算其到中心的切比雪夫距离 d = max(|r - cr|, |c - cc|)。
5. 计算该像素的调色板索引：color_index = floor(d / R) mod k。将该像素涂为 P[color_index]。
6. 擦除灰(5)段和调色板条（涂为背景黑(0)）。中心像素也涂为 P[0]。

**关键洞察**：灰色段的高度不是直接映射某一层环的颜色，而是作为"每种调色板颜色覆盖多少层环"的运行长度指令；需要对比多个示例才能区分运行长度 R=1（每层一种颜色）和 R>1（多层共享颜色）的情况。

## 新题 2：组件对接驱动的腔室多数决填充

**组合逻辑**：[射线方向推断→对接](已有) + [轨迹涂黑](已有) → [正交邻接→邻接多数决→填充](已有，创新：填充所依据的标记像素不是预设的，而是由对接步骤动态放置的)

**来源原语**：对接/射线方向推断/内部槽位/可移动组件/轨迹涂黑(8b9c3697)，填充/连通腔室/分隔墙/标记像素/正交邻接/邻接多数决(7c8af763)

**依赖链**：对接步骤将外部彩色组件滑入墙体结构的内部槽位，对接过程在轨迹上涂黑；对接完成后，组件像素成为嵌入墙体的标记像素，与相邻腔室产生正交邻接关系；腔室的填充颜色由邻接标记的多数决确定。关键耦合：标记像素的最终位置取决于对接方向和距离，而非初始位置——同一组件在不同示例中可能对接到不同槽位，导致不同腔室获得不同填充色。

将外部彩色组件沿射线方向对接进墙体结构的内部槽位，然后以对接后的组件为投票标记，对每个背景腔室进行多数决颜色填充。

**输入结构**：约 15x15 的网格，黑(0)背景。网格中央偏内有一个由灰(5)像素构成的墙体结构，墙体围出 3~5 个独立的 4-连通背景腔室（每个腔室 4~12 像素大小）。墙体结构的包围盒内部有 2~3 个 1 像素的背景槽位（槽位与墙体像素正交邻接且位于墙体包围盒内部）。网格外围（墙体包围盒之外）散布 2~3 个小型单色组件（每个 1~3 像素，4-连通，颜色各不相同，如红(2)、蓝(1)、绿(3)），每个组件与某个槽位沿一个正交方向对齐。生成约束：每个槽位恰好与一个外部组件在某个正交方向上对齐（射线从槽位出发沿该方向命中该组件），组件数量等于槽位数量；每个腔室至少与一个槽位正交邻接。

**规则**：
1. 识别墙体结构为灰(5)的最大连通区域。
2. 识别内部槽位：位于墙体包围盒内部、颜色为背景黑(0)、且至少一个正交邻居为灰(5)的像素。
3. 对每个槽位，沿四个正交方向发射射线，找到第一个命中的彩色组件（非黑、非灰）。该方向即为对接方向。
4. 将命中的组件沿该方向平移，使组件的前缘像素到达槽位位置。组件经过的所有原始位置涂为黑(0)。
5. 对接完成后，识别所有 4-连通的背景腔室（仅由黑(0)像素组成、被灰(5)和对接后的彩色像素围住的区域）。
6. 对每个腔室，收集所有与该腔室正交邻接的彩色（非黑、非灰）像素的颜色。将腔室内所有像素涂为出现次数最多的颜色。若出现次数并列，选择邻接像素中距腔室最上最左像素曼哈顿距离最短者的颜色。

**关键洞察**：腔室的最终颜色不由任何预设标记决定，而完全取决于对接步骤将哪些组件放到了哪些槽位——对接改变了标记的空间分布，进而改变了每个腔室的投票结果；仅看初始位置无法推断填充结果。

## 新题 3：旋转等价分组下的异常精灵体提取

**组合逻辑**：[旋转](已有，创新：不是作为变换操作，而是作为等价关系用于分组判定) + [去重筛选→异常值选择](已有，创新：去重时考虑旋转等价而非像素完全相同) + [裁剪](已有) → 输出

**来源原语**：旋转/整体旋转(ed36ccf7)，像素数编码旋转(6ffbe589)，提取/去重筛选/异常值选择/图案仅出现一次/带框精灵体/尺寸最大(aee291af)，裁剪/连通精灵/布局轴方向/按位置紧密排列(67636eac)

**依赖链**：首先需要裁剪出所有精灵体的包围盒；然后对每对精灵体检测是否为 0/90/180/270 度旋转关系，建立旋转等价类；最后选出仅有一个成员的等价类作为异常值。旋转不是施加给输出的变换，而是分组时的等价判据——这与源题中旋转作为独立操作的用法完全不同。不做旋转等价比较就无法发现异常值（因为所有精灵体视觉上都不相同），不做异常值选择就不知道输出什么。

从若干视觉上各不相同的同色精灵体中，找到在旋转等价意义下独一无二的那个，裁剪输出。

**输入结构**：约 18x18 的网格，黑(0)背景。网格中散布 5~7 个单色精灵体（均为同一种非背景色，如蓝(1)），彼此 8-连通互不接触。所有精灵体的包围盒尺寸相同（如 4x4 或 5x5）。其中大部分精灵体（4~6 个）是同一个基础图案的不同旋转版本（0/90/180/270 度），在视觉上看起来各不相同但旋转后可互相重合。恰好有 1 个精灵体的图案与基础图案在任何旋转下都不匹配。精灵体内部为不规则形状（非矩形、非对称，4~8 像素），确保旋转后产生视觉差异。生成约束：基础图案在 4 种旋转下产生至少 2 种不同的视觉外观（即基础图案不具有 90 度旋转对称性）。

**规则**：
1. 识别所有非背景的 8-连通精灵体，裁剪每个精灵体到其包围盒。
2. 对每对精灵体裁剪结果，检查是否存在一个旋转角度（0/90/180/270 度）使两者像素完全匹配。若存在，它们属于同一旋转等价类。
3. 构建所有旋转等价类。找到恰好只有 1 个成员的等价类，该成员即为异常精灵体。
4. 输出该异常精灵体的包围盒裁剪结果（保持其在裁剪中的原始朝向，不做额外旋转）。

**关键洞察**：表面上每个精灵体看起来都不一样，但大多数只是同一形状的旋转版本；需要系统性地测试旋转匹配才能发现哪个是真正的异类。仅凭一个示例无法确定"旋转等价"这一分组规则——必须对比多个示例观察到不同旋转关系才能归纳出该判据。

## 新题 4：下采样揭示邻接形状以编码重涂色

**组合逻辑**：[下采样 + 奇偶索引分离](已有) → [形状编码颜色→重涂色](已有，创新：形状不是预设的标记字形，而是由下采样后新产生的邻接关系动态涌现的)

**来源原语**：下采样/分隔行列/奇偶索引分离/保留偶索引交叉(68b67ca3)，重涂色/标记字形/形状编码颜色/按形状映射颜色(009d5c81)，擦除(009d5c81)

**依赖链**：下采样移除分隔行列后，原本被分隔的标记像素在压缩网格中变为正交邻接，组成可识别的连通形状；这些形状在原始网格中因分隔行列的存在而无法直接观察——它们是下采样的涌现产物。形状的几何类型（水平线段、竖直线段、L 形、单点）编码了该区域应涂的目标颜色。这是两个源题中都不存在的结构关系：68b67ca3 的下采样不涉及形状解读，009d5c81 的形状解读不涉及下采样。

在含有分隔行列的稀疏网格中，特殊标记色像素分散在格点上；移除分隔行列后，这些标记像素形成新的连通形状，根据形状类型将其所在区域重涂为对应颜色。

**输入结构**：偶数边长的方阵（约 12x12 至 16x16），黑(0)背景。所有奇数行和奇数列均为背景（分隔行列）。偶数行偶数列的格点位置包含两类像素：一类是普通前景色（如蓝(1)），另一类是品红(6)标记色。品红标记像素散布在格点上，每 2~4 个品红像素在下采样后会形成一个连通组（在原始网格中，相邻格点间隔为 2，被分隔行列隔开，因此品红像素在原始网格中不正交邻接）。生成约束：下采样后每个品红连通组的形状恰好属于以下四类之一——水平线段（2~3 像素宽、1 像素高）、竖直线段（1 像素宽、2~3 像素高）、L 形（3 像素）、或单个像素。每种形状至少出现一次。

**规则**：
1. 下采样：保留所有偶数行偶数列的格点像素，移除所有奇数行和奇数列，得到压缩网格（尺寸为原始的一半）。
2. 在压缩网格中，识别所有品红(6)像素的 4-连通分组。
3. 判定每组的形状类型并映射为目标颜色：水平线段 → 红(2)，竖直线段 → 绿(3)，L 形 → 橙(7)，单像素 → 黄(4)。
4. 将每组中的品红像素重涂为对应的目标颜色。其他像素保持不变。
5. 输出为压缩后的网格。

**关键洞察**：品红标记像素在原始网格中被分隔行列隔开，彼此不邻接，看不出形状；下采样消除分隔后它们才形成可识别的连通形状。形状到颜色的映射规则需要对比多个示例中不同形状对应的输出颜色才能归纳。

## 新题 5：计数器偏移十字以选区裁剪拼接

**组合逻辑**：[计数→平移](已有) + [计数器消失](已有) → [十字分区→裁剪→排序→拼接](创新：十字图案不是输出对象，而是作为空间分区工具选择要拼接的精灵体)

**来源原语**：计数/平移/十字图案/计数器像素/计数决定偏移/计数器消失(e48d4e1a)，裁剪/拼接/排序/连通精灵/布局轴方向/按位置紧密排列(67636eac)

**依赖链**：灰色计数器像素的数量决定十字图案的平移量（行下移、列左移），平移后的十字将网格分成四个象限。仅位于特定象限（右下象限）内的精灵体被选中，裁剪到包围盒后按左到右排序并水平拼接。核心耦合：计数器的值通过改变十字位置间接决定了哪些精灵体被选中——不同的计数值导致不同的选区、不同的精灵体子集、不同的拼接结果。十字不出现在输出中，它仅是选区的隐式边界。

根据灰色计数器偏移一个彩色十字以重新划分象限，然后裁剪并拼接落入右下象限的所有精灵体。

**输入结构**：12x12 的黑(0)网格。一条完整的水平行和一条完整的竖直列被涂为同一种非黑非灰颜色（如红(2)），形成十字图案。十字的交叉点不在边界上。网格最右列的顶部有 1~3 个灰(5)像素（计数器）。网格中另有 4~6 个小型单色精灵体（每个 2~5 像素，4-连通，颜色各不相同且非黑、非灰、非红），分散在网格各处，不与十字重叠。生成约束：十字平移后，右下象限内恰好包含 2~3 个精灵体（精灵体的所有像素都在象限内）；不同示例中计数器值不同，导致不同的精灵体被选中。

**规则**：
1. 计数最右列中灰(5)像素的个数 N。
2. 将灰(5)像素擦除为黑(0)。
3. 找到红(2)十字图案的行索引 R 和列索引 C。
4. 计算新位置：新行 R' = R + N，新列 C' = C - N。十字本身不绘制到输出中（十字仅作为空间参考）。
5. 将网格划分为四个象限，以 (R', C') 为分界：右下象限为所有 r > R' 且 c > C' 的区域。
6. 收集所有像素完全位于右下象限内的精灵体。
7. 将每个选中精灵体裁剪到其包围盒，按原始位置从左到右排序（列索引较小者在前），水平拼接。
8. 输出拼接后的结果（高度为所有裁剪中最高者，较矮的裁剪顶部对齐，空余位置为黑(0)）。

**关键洞察**：十字图案本身不出现在输出中，它的唯一作用是经过偏移后定义选区边界。计数器值改变了选区位置，因此改变了被选中的精灵体集合——需要对比多个示例才能发现"右下象限"这一选区规则，因为不同示例中十字位置和计数器值不同。

## 新题 6：嵌套展开后按提示精灵体旋转各层

**组合逻辑**：[展开嵌套 + 块序映射层序 + 逆序读取](已有) → [同色匹配→像素数编码旋转→旋转](已有，创新：旋转不是作用于整个色层，而是作用于嵌套展开后的每个同心层，且同一颜色可能出现在多层中，由层的主色决定匹配)

**来源原语**：展开嵌套/块单元/象限/嵌套层/块序映射层序/逆序读取(8fff9e47)，旋转/色层/提示精灵体/同色匹配/像素数编码旋转(6ffbe589)

**依赖链**：2x2 块条带经逆序读取展开为同心方环嵌套图案，每层环有 4 种颜色（分属四个象限）。每层存在一个"主色"（出现次数最多的颜色），主色用于在外部查找同色提示精灵体。提示精灵体的像素数 mod 4 决定该层旋转多少个 90 度。耦合：展开决定了每层的颜色分布（进而决定主色），主色决定了匹配哪个提示精灵体，提示精灵体决定了旋转量。三步形成不可跳过的推理链。

将 2x2 块条带展开为同心嵌套图案，然后根据外部提示精灵体的像素数旋转对应颜色的同心层。

**输入结构**：输入由两个区域组成。区域 A：一个 4 像素宽的矩形条带（高度为偶数，约 4~8 行），可被精确分割为若干 2x2 单色块，每块颜色来自 {蓝(1), 红(2), 绿(3), 黄(4), 橙(7)} 等。区域 B：条带外侧散布 1~3 个小型单色提示精灵体（每个 1~4 像素，4-连通），颜色各不相同，且每个提示精灵体的颜色与条带中至少一个块的颜色相同。背景为黑(0)。生成约束：条带展开后形成一个边长为 2*块数 的方阵，每层同心环由来自同一个 2x2 块的四个象限颜色构成；每层的四象限颜色中，恰好有一种出现 2 次或以上（即该层有明确的主色）。

**规则**：
1. 将条带中的 2x2 块按逆序行主序读取（从右下角的块开始，向左移动，然后向上移动到上一行的右端，继续向左），得到层序列 L0, L1, ..., Ln-1（L0 为最外层，Ln-1 为最内层）。
2. 每个块 Li 的 4 个像素分配给输出方阵的第 i 层同心环的四个象限：左上像素 → 上左象限，右上 → 上右象限，左下 → 下左象限，右下 → 下右象限。
3. 确定每层的主色：Li 的 4 个像素中出现次数最多的颜色（若并列，取左上像素的颜色）。
4. 在外部提示精灵体中查找与主色颜色相同的精灵体。若找到，计算该精灵体的像素数 S，将该层环绕中心顺时针旋转 (S mod 4) x 90 度。
5. 若某层主色无对应提示精灵体，该层不旋转。
6. 输出为旋转处理后的同心嵌套方阵（不含条带和提示精灵体）。

**关键洞察**：提示精灵体的像素数不直接对应任何可见的空间属性，必须通过计数并取 mod 4 才能得到旋转量。同时，"哪个提示精灵体控制哪层环"的匹配规则依赖于展开后每层的主色——这需要先完成展开才能确定。

## 新题 7：对角线阻挡点发射正交对角线并在交叉处画环

**组合逻辑**：[对角线对齐→连线](已有) + [对角线上阻挡→阻挡点发射正交线](已有) → [交叉点→交叉邻域环涂色](已有，创新：环涂色的触发条件从行列交叉改为对角线交叉，环的中心由几何推导而非直接给定)

**来源原语**：连线/对角线对齐/对角线上阻挡/阻挡点发射正交线(55783887)，射线延伸/描边(55783887, a3df8b1e)，描边/交叉点/交叉邻域环涂色/全行条/全列条(67a423a3)

**依赖链**：首先识别主对角线上的阻挡点，每个阻挡点发射穿越全网格的正交对角线（55783887 的机制）。当两个阻挡点发射的正交对角线相交时，在交叉点处画一个 3x3 的黄色环（67a423a3 的机制，但触发条件从正交线交叉变为对角线交叉）。关键耦合：阻挡点的位置决定了正交对角线的路径，路径的几何关系决定了交叉点的存在和位置，交叉点决定了环的位置。三步形成几何推理链，每步的输出是下步的空间输入。

在主对角线段上标记阻挡点，每个阻挡点发射全长正交对角线，在正交对角线的交叉处绘制黄色方环。

**输入结构**：约 15x15 的黑(0)网格。有两个蓝(1)像素位于同一条 45 度对角线上（从左上到右下或从左下到右上），它们是主对角线段的两个端点。在这两个端点之间的对角线路径上，有 2~3 个不同颜色的标记像素（如红(2)、绿(3)），这些是阻挡点。阻挡点的颜色各不相同且与端点颜色不同。生成约束：至少存在一对阻挡点，它们发射的正交对角线在网格内有交点；交叉点距网格边界至少 1 像素（确保 3x3 环完全在网格内）。

**规则**：
1. 找到两个蓝(1)端点，连接它们的对角线段，将段上所有像素涂为蓝(1)，但保留阻挡点像素的原始颜色。
2. 每个阻挡点发射一条正交对角线（与主对角线垂直的 45 度方向），从阻挡点出发向两个方向延伸到网格边界，涂为该阻挡点的颜色。已有非背景像素不被覆盖。
3. 检测所有正交对角线之间的交叉点：若两条不同阻挡点发射的正交对角线经过同一个像素，该像素为交叉点。
4. 在每个交叉点处，以该点为中心绘制 3x3 的黄(4)方环（8 个像素），保留中心像素原有颜色。若环的某个像素超出网格边界则跳过该像素。
5. 其他非背景的前景像素保持不变。

**关键洞察**：交叉点的位置无法直接从阻挡点位置"看出"——需要实际追踪两条正交对角线的完整路径才能确定它们是否相交以及在哪里相交。仅凭一个示例很难确定环的颜色是黄(4)（而非交叉线之一的颜色），需要对比多个示例。

## 新题 8：变换掩码匹配定位印章后按空间序循环调色

**组合逻辑**：[模式匹配→掩码变换匹配则补→填充](已有) + [循环填充 + 顺序排列](已有，创新：填充色不是统一的单色，而是按印章的空间顺序从调色板循环取色) + [擦除](已有)

**来源原语**：填充/矩形精灵体/标记像素/模式匹配/掩码变换匹配则补(7df24a62)，旋转/镜像(7df24a62)，循环填充/调色板列/顺序排列(e7b06bea)，长度标记段/标记高度决定长度(e7b06bea)，擦除(e7b06bea)

**依赖链**：源精灵体的标记掩码定义匹配模板；在网格中搜索该模板的所有旋转/镜像副本，每个命中位置是一个待填充的印章框。印章框按其左上角的行主序排列，然后从调色板循环取色：每 R 个连续印章（R 由灰色段高度编码）共享同一调色板颜色，用完调色板后循环回第一色。耦合：掩码匹配决定印章数量和位置，位置决定排列序，排列序决定每个印章分配到调色板的哪个颜色。单独的匹配或单独的循环填充都无法产生正确输出。

找到与源精灵体标记掩码匹配的所有变换副本，在每个位置填充矩形，填充颜色按空间顺序从调色板循环分配。

**输入结构**：约 20x20 的网格，黑(0)背景。网格中有一个矩形源精灵体（约 4x4 至 5x5），由橙(7)填充色和品红(6)标记色像素组成：包围盒内所有像素非黑，其中大部分为橙(7)，少数（2~4 个）为品红(6)，品红像素构成标记掩码。网格其他位置散布品红(6)像素组，这些组中的部分是源精灵体标记掩码的旋转或镜像副本（即将掩码经过某种 0/90/180/270 旋转或水平/垂直翻转后，恰好与该组品红像素重合，且对应矩形区域内其余像素均为背景）。网格一侧边缘有一条短竖直调色板条（2~3 种颜色，如红(2)、绿(3)、蓝(1)），另一角有灰(5)竖直段（1~2 像素高）。生成约束：匹配位置为 3~6 个，互不重叠；调色板条和灰色段不与任何匹配区域重叠。

**规则**：
1. 找到源精灵体：唯一的矩形区域，其包围盒内所有像素均为橙(7)或品红(6)，且包含至少一个橙(7)像素。提取其品红(6)像素的相对位置作为标记掩码 M。
2. 对 M 生成所有 8 种变换（4 种旋转 x 是否水平翻转）。
3. 在网格中搜索每种变换后的掩码：若变换后掩码的所有位置在网格中恰好为品红(6)，且掩码对应的矩形包围盒内其余位置均为背景黑(0)，则该位置为一个匹配。
4. 将所有匹配位置按其包围盒左上角坐标的行主序（先按行从小到大，行相同则按列从小到大）排列，编号为 0, 1, 2, ...。
5. 读取调色板条的颜色序列 P（从上到下），读取灰(5)段高度 R。
6. 对编号为 i 的匹配位置，计算 color_index = floor(i / R) mod len(P)。将该匹配位置的包围盒内所有背景像素填充为 P[color_index]（品红像素保留）。
7. 擦除源精灵体（涂为背景黑(0)）、调色板条和灰色段。

**关键洞察**：源题 7df24a62 中所有印章使用同一种填充色，而本题中每个印章的填充色取决于其在所有匹配中的空间排位和调色板循环规则——需要对比多个示例才能发现"按行主序分组循环取色"这一隐蔽规则（而非按匹配到的旋转类型或按距离源精灵体的远近取色）。
