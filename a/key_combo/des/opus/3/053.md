## 新题 1：精灵遮罩下的曼哈顿色环

**组合逻辑**：[距离映射 distance_mapping] + [周期平铺 periodic_tiling](创新：精灵从放大模板变为可见性遮罩) + [循环色板 cyclic_palette](创新：色板起点随标记色旋转)

**来源原语**：距离映射/曼哈顿距离/循环色板/同心环/标记像素 ← aaef0977；掩码映射/周期平铺/控制精灵 ← bf45cf4b, 53fb4810

**依赖链**：曼哈顿距离场为每个像素分配环色；控制精灵以标记像素为锚点进行周期平铺生成二值可见性遮罩；两者逐像素 AND 合成最终输出——遮罩决定"哪些像素可见"，距离场决定"可见像素显示什么颜色"，任一结构缺失则无法确定输出。

在标记像素周围生成曼哈顿距离循环色环，但仅落在以标记为锚点周期平铺的精灵遮罩填充区域内的像素才显色，其余保持背景色。

**输入结构**：
- 约 15x15 的橙(7)背景网格。
- 一个非橙标记像素（其颜色属于下述色板之一，如绿(3)或红(2)），位于网格内偏离中心的位置。
- 一个单色控制精灵，由灰(5)像素组成，位于网格某个角落区域，与标记像素不相邻。精灵为一个 4-连通区域，边界框约 3x4 或 4x3，边界框内含有若干橙(7)孔洞像素（即精灵不完全填满其边界框）。
- 生成约束：精灵的边界框尺寸使得从标记像素出发向四个方向平铺时能至少覆盖网格大部分区域。不同示例中精灵的形状和孔洞位置不同，标记像素的位置和颜色也不同。

**规则**：
1. 定义 9 色循环色板为有序序列：绿(3), 黄(4), 黑(0), 灰(5), 红(2), 青(8), 栗(9), 品红(6), 蓝(1)。
2. 找到标记像素的颜色在色板中的位置索引 s（例如绿(3) 对应 s=0，红(2) 对应 s=4）。
3. 以标记像素所在位置为中心，计算网格中每个像素 (r, c) 到标记的曼哈顿距离 d。对每个像素，其环色 = 色板[(s + d) mod 9]。
4. 以标记像素的位置为锚点，将控制精灵的边界框作为瓦片单元，向上下左右周期平铺直到覆盖整个网格。锚点定义：精灵边界框的左上角对齐到标记像素所在位置。平铺超出网格边界的部分裁剪。
5. 对每个网格像素 (r, c)：计算其在平铺中对应的精灵边界框内的局部坐标 (r', c')，其中 r' = ((r - marker_r) mod tile_H + tile_H) mod tile_H，c' = ((c - marker_c) mod tile_W + tile_W) mod tile_W（tile_H 和 tile_W 为精灵边界框的高和宽）。若精灵在 (r', c') 处为灰(5)（填充），则输出该像素的环色；若为橙(7)（孔洞），则输出橙(7)。
6. 精灵自身所在原始位置的灰(5)像素也被上述规则替换（不保留精灵原色）。

**关键洞察**：精灵平铺的锚点与标记像素位置绑定——不同示例中标记移动时遮罩图案同步平移，需要对比多个示例才能发现这一对齐规则，而非认为遮罩是固定位置的。此外，色板的起始偏移由标记颜色决定而非固定从绿(3)开始。

## 新题 2：滑动着陆后的条件描边

**组合逻辑**：[滑动 slide] + [描边 outline](创新：描边位置由滑动终点决定而非原始位置) + [重涂色 recolor](创新：最近者重涂矩形，其余者描边) + [标记色决定描边色 marker_color_determines_outline]

**来源原语**：滑动/最近距离/最近者进入内部/矩形/标记像素/行列对齐 ← d6e50e54；描边/中心扩展/标记色决定描边色/孤立像素/空心矩形 ← 913fb3ed；重涂色 ← c8f0f002

**依赖链**：滑动决定每个标记像素的着陆位置 → 距离比较决定哪个标记是"进入者"（分支点）→ 进入者重涂整个矩形 → 其余标记在各自着陆位置展开为描边框。描边颜色由标记原色经固定配对表映射得到。移除滑动则不知描边中心在哪；移除距离比较则不知谁进入谁描边。

每个孤立彩色像素沿行或列滑向中央矩形；全局最近的一个进入矩形并将矩形整体重涂为映射色；其余像素在着陆位置展开为以映射色绘制的 3x3 空心描边框。

**输入结构**：
- 约 13x13 的黑(0)背景网格。
- 一个实心黄(4)矩形，尺寸约 3x4 或 4x3，位于网格中部偏移位置。
- 3~5 个孤立彩色像素，颜色仅限绿(3)、青(8)、红(2)。每个像素与矩形严格行对齐或列对齐（即像素的行坐标落在矩形行范围内，或列坐标落在矩形列范围内），且位于矩形外部。
- 每个孤立像素周围至少有 1 格空白邻域（确保描边框不会紧贴另一个像素的着陆点）。
- 生成约束：恰好一个像素是全局距矩形边界曼哈顿距离最小的（无并列）。各像素滑动后着陆位置的 3x3 描边框不互相重叠，也不与矩形重叠（最近者除外）。

**规则**：
1. 固定颜色配对表：绿(3)→品红(6)，青(8)→黄(4)，红(2)→蓝(1)。
2. 每个孤立像素沿其与矩形对齐的行或列直线滑向矩形。计算每个像素到矩形边界的曼哈顿距离（沿滑动方向的格数）。
3. 距离最小的唯一像素为"进入者"：将其移到矩形边界上最近的格子处（进入矩形内部），并将整个矩形从黄(4)重涂为该进入者的配对色。进入者像素自身也变为该配对色（融入矩形）。
4. 其余每个像素滑动到矩形外侧相邻的第一个格子处停下（紧贴矩形外壁）。在该着陆位置为中心，绘制一个 3x3 空心描边框（仅 8 个边界格），颜色为该像素的配对色。着陆格本身保留该像素的原始颜色（不被描边覆盖）。
5. 描边框超出网格边界的部分裁剪（不绘制）。
6. 原始位置的像素被清除（变为黑(0)背景）。

**关键洞察**：颜色配对表（绿→品红、青→黄、红→蓝）无法从单个示例确定——必须对比多个不同标记色的示例才能归纳出完整映射。此外，进入者使矩形整体变色而非局部着色，这一行为与外部像素的描边行为形成条件分支。

## 新题 3：墙壁阻断的条件十字交叉

**组合逻辑**：[射线延伸 ray_extend](创新：射线被墙壁截断) + [交叉点重置背景 intersect_reset_bg](创新：仅双射线均到达时才重置) + [可达性 reachability]

**来源原语**：射线延伸/交叉点重置背景/实心方块/十字图案/行列对齐 ← e9bb6954；可达性/墙壁障碍 ← dd6b8c4b；擦除 ← 91714a58

**依赖链**：墙壁位置决定每条射线的有效延伸范围 → 射线范围决定哪些潜在交叉点实际被双方到达 → 到达状态决定交叉点是重置为背景还是保留单方射线色。三步之间信息逐级传递且不可跳过：不知墙壁就无法确定射线范围，不知射线范围就无法判断交叉行为。

多个实心方块各自沿中心行和中心列发射射线形成十字，射线遇墙壁则截止；两条不同方块射线的交叉点仅在双方均实际到达该点时才重置为背景，若一方被墙壁挡住则另一方正常填色。

**输入结构**：
- 约 15x15 的橙(7)背景网格。
- 2~3 个实心 3x3 单色方块，颜色各不相同（从蓝(1)、绿(3)、青(8)、栗(9)中选取）。各方块中心行互不相同，中心列互不相同。
- 若干品红(6)墙壁线段：每条墙壁为 1 像素宽的水平或垂直直线段，长度 3~7 像素，放置在方块之间的区域。墙壁不与任何方块的 3x3 区域重叠。
- 生成约束：至少一对方块之间存在墙壁，使得它们的潜在交叉点处恰好有一条射线被阻断；至少一对方块之间无墙壁阻断，其交叉点处双方射线均到达。不同示例中墙壁数量和位置不同。

**规则**：
1. 复制输入网格。
2. 对每个 3x3 方块，从其中心格向上、下、左、右四个方向延伸射线（颜色为该方块的颜色）。射线逐格推进，遇到以下情况停止：(a) 到达网格边界，(b) 到达品红(6)墙壁格。墙壁格本身不被射线覆盖。射线覆盖路径上所有橙(7)背景格。
3. 确定所有"潜在交叉点"：方块 A 的中心行与方块 B 的中心列的交点 (rA, cB)，以及方块 A 的中心列与方块 B 的中心行的交点 (rB, cA)。
4. 对每个潜在交叉点：检查方块 A 的射线是否实际延伸到了该点（未被墙壁在到达前截断），同时检查方块 B 的射线是否也实际延伸到了该点。若双方均到达，则将该交叉点重置为橙(7)背景色。若仅一方到达，则该点保留到达方的射线颜色。若双方均未到达，该点保持原状。
5. 所有 3x3 方块保持原色不变。品红(6)墙壁保持不变。
6. 射线可以覆盖原有的非背景散落像素（若有），但不覆盖其他方块的 3x3 本体和墙壁。

**关键洞察**：交叉点的重置是有条件的——仅当两条来自不同方块的射线均未被墙壁拦截而同时到达交叉点时才发生。单个示例中若所有交叉点都被双方到达，则看似"所有交叉点都重置"；需要另一个示例中墙壁挡住一方射线使交叉点变为单色填充，才能归纳出这一条件规则。

## 新题 4：面积选模板、距离排旋转

**组合逻辑**：[面积比较 area_comparison](创新：从多候选中选出唯一模板) + [旋转 rotate] + [距离映射 distance_mapping](创新：宏格曼哈顿距离决定旋转角度而非空间位置顺序) + [擦除 erase]

**来源原语**：旋转/逐槽位累计旋转/模板/分隔线/槽位/顺序排列 ← 8e5a5113；面积比较/仅保留最大矩形/擦除/噪声像素/实心矩形 ← 91714a58；距离映射 ← aaef0977

**依赖链**：面积比较在多个候选区域中选出唯一模板（选择阶段）→ 非模板区域的前景被擦除（清理阶段）→ 模板区域到每个空槽位的宏格距离确定旋转顺序（排序阶段）→ 按距离排名逐槽位累计旋转填充（执行阶段）。四阶段紧密串联：选错模板则后续全错，排序错误则旋转角度全错。

灰线分隔的网格中多个区域含前景图案，仅保留非背景像素面积最大的区域作为模板，按其与各空槽位的宏格曼哈顿距离排序，依次填入 90 度递增的旋转副本。

**输入结构**：
- 约 15x15 或 17x17 的网格，由灰(5)完整行和列分隔为 3x3 的宏格阵列（每个区域约 4x4 或 5x5 像素）。
- 3 个区域内含有非黑前景图案（各区域内图案颜色统一，可各不相同或相同），其中恰好一个区域的非背景像素数严格最大。
- 其余区域为纯黑(0)背景（空槽位）。
- 各前景图案为 4-连通的单色区域，像素数范围 3~10，形状各异（不限矩形）。
- 生成约束：面积最大的区域唯一（无并列）。空槽位数量为 5~6 个（总 9 区域减去 3 个有图案的）。

**规则**：
1. 统计每个含前景图案的区域中非背景(非黑(0)、非灰(5))像素的数量。选出像素数最多的区域作为模板区域。
2. 将其余含前景图案的区域内所有前景像素擦除为黑(0)（它们是干扰项）。
3. 在 3x3 宏格坐标系中，计算模板区域到每个空槽位的曼哈顿距离（|行差| + |列差|）。
4. 将所有空槽位按曼哈顿距离升序排列。距离相同时，按宏格阅读顺序（先上后下、同行先左后右）排列。
5. 排名第 1 的槽位填入模板旋转 90 度顺时针的副本；排名第 2 填入 180 度；排名第 3 填入 270 度；排名第 4 填入 0 度（原始方向）；排名第 5 填入 90 度——以此循环（旋转角度 = (排名 × 90) mod 360）。
6. 副本颜色与模板颜色相同。灰(5)分隔线保持不变。模板区域自身保持原样不动。被擦除的干扰区域在输出中为黑(0)。

**关键洞察**：旋转顺序由宏格距离排名决定，而非由区域在网格中的空间阅读顺序决定——距离更近的空槽位获得更小的旋转角度。需要对比不同示例（模板位于不同宏格位置）才能发现这一规则，因为某些情况下距离排名恰好与阅读顺序一致，造成假象。

## 新题 5：周期行补全后的精灵列遮罩

**组合逻辑**：[补全 completion] + [周期平移 periodic_translation](创新：生成的新行也包含待遮罩内容) + [掩码映射 mask_mapping](创新：精灵作为列可见性过滤器而非放大模板)

**来源原语**：补全/周期平移/周期偏移延续行/行图案/画布 ← 53b68214；掩码映射/控制精灵 ← bf45cf4b；同行对应 ← c9f8e694

**依赖链**：周期规律从已有行中推断 → 缺失行由周期平移补全 → 补全后的完整图案被精灵列遮罩过滤，未通过遮罩的列清零。补全阶段确定"每个格子的理论前景值"，遮罩阶段确定"哪些列的理论值实际保留"。若跳过补全则下半部无数据可遮罩；若跳过遮罩则输出比正确答案多出若干列的前景。

先将不完整的周期行图案向下补全至目标行数，再用控制精灵的列结构作为周期遮罩，仅保留对应"填充列"的前景、清除对应"孔洞列"的前景。

**输入结构**：
- 网格宽 12，高约 8~10（低于 12）。黑(0)背景。
- 网格分为两个水平区域（无显式分隔线）：
  - 上区（前 2~3 行）：一个灰(5)控制精灵，左对齐于第 0 列。精灵边界框约 3~5 列宽、2~3 行高，包含灰(5)填充像素和黑(0)孔洞。精灵至少有一列完全是孔洞（全黑列）且至少有一列完全是填充（全灰列）。
  - 下区（从精灵下方隔 1 行空行开始）：宽 12 的行图案区，包含 3~5 行前景行，使用一种非黑非灰颜色（如红(2)或蓝(1)）。行图案具有周期平移特征：存在一个最小垂直周期 P（2 或 3）和水平偏移 S（1 或 2），使得行 i+P 的前景位置是行 i 的前景位置整体右移 S 格（超出右边界的裁剪）。
- 生成约束：已有行数足以唯一确定 P 和 S。精灵边界框宽度 W 能整除 12（即 W 为 2, 3, 4, 6 之一），确保周期遮罩均匀覆盖。

**规则**：
1. 从下区已有行中推断最小垂直周期 P 和水平偏移 S。
2. 将下区行图案向下补全至总共 12 行（形成 12x12 的完整图案块）。每个缺失行的前景 = 其上方 P 行处的前景整体右移 S 格，超出右边界的像素丢弃。
3. 读取控制精灵边界框的列结构。对精灵边界框内的每一列 j（0 到 W-1）：若该列内至少有一个灰(5)像素，标记为"开放"；若该列内全部为黑(0)，标记为"封闭"。
4. 对完整 12x12 图案块中的每一列 c（0 到 11）：计算 c mod W 得到精灵列索引。若该精灵列为"封闭"，则将该列所有前景像素清除为黑(0)。若为"开放"，保持不变。
5. 输出为处理后的 12x12 图案块。上区精灵和分隔空行不出现在输出中。

**关键洞察**：精灵并非被放大或平铺为可见图案——它的列结构被抽象为一个周期为 W 的二值列遮罩，逐列过滤补全后的行图案。精灵的行数和具体形状无关紧要，只有逐列是否有填充像素这一属性被使用。需要对比不同精灵形状的示例才能归纳出"按列判断有无填充"这一规则。

## 新题 6：角标记定矩形、可达性选填色

**组合逻辑**：[填充 fill] + [四角标记围定内部 four_corners_define_interior](创新：矩形不再用固定色填充) + [可达性 reachability](创新：用于筛选哪个颜色源可以为矩形供色) + [距离排序填充 distance_ranked_fill](创新：最近可达源决定填色)

**来源原语**：填充/四角标记围定内部/角标记/矩形/行列对齐 ← af902bf9；可达性/墙壁障碍/距离排序填充/标记像素/目标块 ← dd6b8c4b；擦除 ← 91714a58

**依赖链**：角标记几何确定矩形位置和范围 → 墙壁拓扑确定每个颜色源的可达范围 → 可达性过滤 + 距离排序联合选出每个矩形的唯一供色源 → 供色源的颜色填入矩形内部。四步形成决策图而非线性流水线：矩形几何和墙壁拓扑同时需要被解析，然后在可达性和距离两个维度上联合约束才能确定填色。

黄色角标记定义隐形矩形的边界，散布的彩色源像素经墙壁可达性筛选和距离排序后，最近的可达源为矩形提供填充颜色。

**输入结构**：
- 约 15x15 的橙(7)背景网格。
- 2~3 组黄(4)角标记，每组恰好 4 个黄像素，共享两行两列，围定一个矩形区域。各矩形互不重叠，内部为橙(7)背景。
- 4~6 个彩色源像素，颜色从蓝(1)、绿(3)、红(2)、青(8)、栗(9)中选取（每个源颜色不同），散布在矩形外部的橙(7)地板上。
- 若干品红(6)墙壁线段（1 像素宽，长 3~6 像素），放置在源像素与矩形之间的路径上。
- 生成约束：每个矩形至少有一个可达的源像素（通过橙(7)地板的 4-连通洪水填充，不穿越品红(6)墙壁、黄(4)角标记或其他源像素）。至少一个矩形存在一个更近但不可达的源和一个更远但可达的源，以体现可达性筛选的必要性。

**规则**：
1. 识别所有由四个黄(4)像素围定的矩形：四个黄像素恰好共享两个行坐标和两个列坐标，形成矩形的四个角。矩形内部区域为这四角围成的开区域（不含角标记行列本身的边界格）。
2. 对每个矩形，以其几何中心（内部区域的中心坐标，取整数下取整）为目标点，计算每个彩色源像素到该中心的曼哈顿距离。
3. 对每个源像素，执行从该源出发的 4-连通洪水填充：可通行格为橙(7)背景格。检查洪水填充是否能到达目标矩形的任一内部格——若能，则该源为该矩形的"候选源"。
4. 在每个矩形的所有候选源中，选距离最小者。距离并列时选行坐标更小者；仍并列选列坐标更小者。
5. 将所选源像素的颜色填入该矩形的整个内部区域。被选中的源像素从网格中擦除（变为橙(7)）。每个源像素至多被一个矩形选中。若多个矩形竞争同一个源，距离更近的矩形优先获得该源；落选矩形取其下一个最近候选源。
6. 黄(4)角标记保留。品红(6)墙壁保留。未被选中的源像素保留。无候选源的矩形内部保持橙(7)。

**关键洞察**：填充颜色既不是固定色也不是由矩形自身属性决定的——它取决于哪个颜色源能通过墙壁迷宫到达该矩形且距离最近。在某些示例中，空间上最近的源被墙壁隔断，导致更远的源反而供色，这一反直觉现象只有对比有墙和无墙的示例才能归纳。

## 新题 7：十字图案驱动的瓦片放大

**组合逻辑**：[射线延伸 ray_extend] + [交叉点重置背景 intersect_reset_bg] → [像素放大 pixel_upscale](创新：十字图案的二值结果作为放大遮罩) + [像素展开为瓦片 filled_pixel_expands_to_tile]

**来源原语**：射线延伸/交叉点重置背景/实心方块/十字图案 ← e9bb6954；像素放大/像素展开为瓦片/掩码映射/多色瓦片/控制精灵 ← bf45cf4b

**依赖链**：方块射线延伸生成十字图案（含交叉点重置逻辑）→ 十字图案转化为二值遮罩 → 遮罩中每个前景像素展开为角落瓦片的副本，每个背景像素展开为等大的背景块。射线延伸的结果直接决定放大遮罩的内容——交叉点重置处在放大后变为瓦片大小的空洞，成为输出中最显著的结构特征。

实心方块发射十字射线（交叉处清空），再将整张结果图逐像素放大为角落多色瓦片的副本拼贴。

**输入结构**：
- 约 10x10 的黑(0)背景网格。
- 1~2 个实心 3x3 单色方块（颜色从蓝(1)、绿(3)、红(2)中选取），中心行和中心列互不相同。
- 一个 2x2 或 3x3 的多色正方形瓦片，位于网格的一个角落（如左上角或右下角），由 2~3 种非黑颜色组成（如黄(4)和青(8)的棋盘格，或红(2)、灰(5)、蓝(1)的条纹）。瓦片不与任何方块的射线路径在输入中重叠。
- 生成约束：若有 2 个方块，它们的十字射线有至少一个交叉点。瓦片所在角落与方块不相邻。

**规则**：
1. 对每个 3x3 方块，以其颜色填充其中心行的全部列和中心列的全部行（覆盖整行整列），方块自身 3x3 区域保持不变。
2. 若有两个方块，检查所有交叉点（方块 A 中心行与方块 B 中心列的交点，及方块 A 中心列与方块 B 中心行的交点）。所有交叉点重置为黑(0)背景。
3. 瓦片在步骤 1-2 中如果被射线经过，则被射线颜色覆盖（瓦片不具有保护性）。
4. 将步骤 1-3 后的整张网格视为二值遮罩：非黑(非 0)像素为"填充"，黑(0)像素为"空白"。
5. 读取原始输入中瓦片的内容（步骤 1-3 之前的原始颜色）。设瓦片尺寸为 TxT。
6. 构造输出网格，尺寸为 (输入高 x T) 行 x (输入宽 x T) 列。
7. 对输入网格每个像素 (r, c)：若遮罩中该像素为"填充"，则在输出的 (r*T, c*T) 到 (r*T+T-1, c*T+T-1) 区域粘贴瓦片副本；若为"空白"，则该区域全部填黑(0)。

**关键洞察**：十字射线的交叉重置点在放大后变为瓦片大小的黑色空洞——这是区分"只有一个方块"和"两个方块交叉"情况的关键视觉线索。需要对比有交叉和无交叉的示例才能发现放大前存在交叉重置步骤，而非简单地将所有非黑像素放大。

## 新题 8：生长收缩后中心行决定重涂色

**组合逻辑**：[生长 grow / 收缩 shrink] + [最大外扩余内缩 max_grow_rest_shrink](创新：几何变换改变对象中心位置) + [重涂色 recolor] + [行首色决定填色 row_key_color](创新：重涂色目标是变换后的对象而非占位像素，映射键是变换后的中心行)

**来源原语**：生长/收缩/最大外扩余内缩/前景对象/中心间隙/面积最大者 ← df978a02；重涂色/行首色决定填色/占位像素/控制像素/同行对应 ← c9f8e694

**依赖链**：面积比较确定哪个对象生长、哪些收缩 → 生长/收缩改变每个对象的几何形状和像素集合 → 变换后的像素集合决定新的中心行 → 新中心行与列 0 控制像素匹配确定重涂色 → 一对一分配保证每个控制像素仅供一个对象使用。生长/收缩不仅改变形状还通过中心行平移间接改变颜色分配结果——这是关键耦合点。

四个灰色对象围绕中心间隙，面积最大者外扩三像素帽、其余内缩一像素尖；变形后每个对象按其新中心行匹配列 0 处最近的控制像素颜色来重涂。

**输入结构**：
- 约 13x13 的黑(0)背景网格。
- 四个灰(5)前景对象，各为 4-连通单色区域，像素数 5~12，形状各异（非矩形的不规则图形）。四个对象分别从上、下、左、右指向网格中央的一个黑(0)背景间隙区域，每个对象有一个尖端像素最靠近中心间隙。
- 恰好一个对象的像素数严格最大（无并列）。
- 在列 0（最左列）中，有恰好四个非黑非灰的控制像素，颜色各不相同，从蓝(1)、红(2)、绿(3)、黄(4)、青(8)中选取。四个控制像素位于不同行，行坐标分散在网格的上中下区域。
- 生成约束：生长/收缩操作后，每个对象的中心行（所有像素行坐标的平均值，向下取整）各不相同。每个对象的新中心行最近的控制像素也各不相同（无两个对象抢同一控制像素的情况）。

**规则**：
1. 找到四个灰(5)对象中像素数最大的一个（"优胜者"）。
2. 找到中心间隙：四个对象围成的中央黑(0)连通区域。
3. 对三个非优胜者：找到其距中心间隙最近的那个像素（尖端），将该像素擦除为黑(0)背景（收缩）。
4. 对优胜者：确定其远离中心间隙的一侧方向（即从中心间隙看向优胜者的延伸方向——上、下、左或右）。在优胜者最外侧边缘的该方向上，沿与延伸方向垂直的轴居中添加 3 个灰(5)像素作为帽（若优胜者从左指向右，则帽加在最右列的右侧一列，垂直居中于优胜者在该列的像素范围）。帽像素超出网格边界则裁剪。
5. 计算每个对象变换后的中心行：对象所有像素（含新增帽像素或移除尖端后的集合）行坐标的算术平均值，向下取整。
6. 对每个对象，在列 0 的四个控制像素中，选行坐标与该对象中心行距离最小的控制像素。距离并列时选行坐标更小（更靠上）的控制像素。
7. 将每个对象的所有像素（含帽、不含已擦除尖端）从灰(5)重涂为所匹配的控制像素颜色。
8. 列 0 的控制像素在输出中擦除为黑(0)背景。中心间隙保持黑(0)。

**关键洞察**：重涂色不是用对象的原始中心行匹配控制像素，而是用变换后的中心行——优胜者因外扩帽而中心行可能偏移，收缩者因丢失尖端而中心行也可能偏移。需要对比变换前后中心行的变化及其对颜色分配的影响，才能归纳出"先变形再匹配"的执行顺序。
