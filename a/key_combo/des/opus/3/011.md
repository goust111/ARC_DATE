## 新题 1：对称补全划定洪泛区域

**组合逻辑**：[对称补全](已有) → 创建封闭边界(创新——补全结果充当洪泛屏障) → [洪泛填充](已有，种子选取由新形成的封闭域决定) → [重涂色](已有)

**来源原语**：对称补全/symmetry_complete (e40b9e2f), 洪泛填充/flood_fill (9edfc990, 753ea09b), 封闭背景区域/enclosed_bg_region (753ea09b), 种子像素/seed_pixel (9edfc990), 旋转对称/rotational_symmetry (e40b9e2f), 四邻连通/four_neighbor_connectivity (9edfc990), 四次旋转闭合/four_fold_closure (e40b9e2f), 小区域被填充/small_regions_filled (753ea09b), 重涂色/recolor (多源)

**依赖链**：对称补全在网格中创建新的前景像素，这些新像素与原有像素共同构成屏障，将背景划分为若干 4-连通区域；只有完成补全后才能判定哪些背景区域被完全包围；洪泛填充的颜色取决于被包围区域中包含的种子像素的颜色。删除对称补全步骤则封闭边界不完整，区域无法正确分类；删除洪泛填充则种子像素的意义丢失。

将部分前景图案旋转补全为四重对称图形，由此产生的新封闭背景区域按其内部种子像素的颜色进行洪泛填充。

**输入结构**：约 15x15 的网格，背景为黑(0)。网格中存在一组蓝(1)像素，构成某个四重旋转对称图形的一部分（约占完整图形的 1/4 到 1/2），这些像素位于一个隐含的正方形区域内。正方形区域的边长和中心位置需从蓝像素的分布推断。另外，网格背景上散布 2-4 个不同颜色的单像素种子点，颜色来自红(2)、绿(3)、黄(4)、品红(6)，每个种子颜色唯一。种子点的位置使得：补全后的蓝色图案与网格边缘共同形成若干封闭背景区域，每个封闭区域恰好包含一个种子点。生成约束：蓝像素的 90 度旋转闭合不产生颜色冲突；补全后每个封闭区域恰含一个种子；种子不位于蓝像素上。

**规则**：
1. 找到包含所有蓝(1)像素的最小正方形区域，使得将蓝像素绕正方形中心做 0/90/180/270 度旋转后无颜色冲突。
2. 在该正方形内，将蓝像素的所有旋转像（0/90/180/270 度）绘制为蓝(1)，完成四重旋转对称。
3. 将补全后的所有蓝像素视为屏障，连同网格边缘一起，找出所有 4-连通的背景区域。
4. 对每个不触及网格边缘的封闭背景区域：找到其中唯一的种子像素，将该封闭区域的所有背景像素（含种子像素本身）重涂为种子的颜色。
5. 触及网格边缘的背景区域中的种子像素擦除为黑(0)。
6. 蓝像素保持不变。

**关键洞察**：种子像素的填充颜色和填充范围都无法在对称补全完成之前确定——补全创建的新蓝像素改变了背景的连通结构，决定了哪些区域被封闭以及哪个种子属于哪个区域。

## 新题 2：令牌下落后经邻接获取墙壁标记色

**组合逻辑**：[重力下落](已有，作用对象改为中性令牌) → [邻接传色](已有，传色来源改为墙壁标记) → 冲突解决(创新——多色邻接时取较低墙壁位置的标记色)

**来源原语**：重力下落/gravity_drop (2b83f449), 邻接传色/adjacency_transfer (b7256dcd), 擦除/erase (b7256dcd), 令牌/token (2b83f449), 管道网络/pipe_network (2b83f449), 标记像素/marker_pixel (b7256dcd), 碰撞停止/collision_stop (2b83f449), 标记接触即赋色/marker_touch_color (b7256dcd)

**依赖链**：令牌的最终位置由重力下落和堆叠顺序决定；位置确定后才能判断每个令牌与哪些墙壁标记 4-相邻；标记颜色到令牌的传递依赖于邻接关系。删除重力使令牌停留在初始位置（不邻接任何标记），删除邻接传色则令牌无法获得颜色信息。

中性色令牌在管道网络中下落至静止，然后根据与之 4-相邻的墙壁内嵌标记像素获取最终颜色。

**输入结构**：约 15x15 的网格，背景为黑(0)。灰(5)像素构成管道壁，围出若干垂直和水平通道（每条通道宽度为 1-2 像素的黑色空间）。通道内壁的某些位置嵌有彩色标记像素（红(2)、蓝(1)、绿(3)），每个标记为壁上的一个单像素，替换原本应为灰(5)的位置，但仍作为壁的一部分阻挡通行。橙(7)中性令牌（每个为单像素）放置在管道入口处（通道顶部的黑色单元格中），各令牌之间不直接相邻。生成约束：每个令牌下落路径上不存在分叉（通道无交叉口在令牌经过的范围内）；每个令牌最终静止位置至少邻接一个标记。

**规则**：
1. 每个橙(7)令牌在其所在通道内向下移动，逐格穿过黑(0)单元格，遇到灰(5)壁、已静止的另一个令牌或网格底部时停止。同一通道内多个令牌按从下到上的顺序依次下落（最低的先落）。
2. 所有令牌静止后，检查每个令牌的 4-邻居。
3. 若令牌恰好邻接一种标记颜色（可能邻接该色的多个标记像素），将令牌重涂为该颜色。
4. 若令牌邻接两种或更多不同标记颜色，选择行号最大（离网格底部最近）的那个标记像素的颜色。若行号相同，选择列号最小（最靠左）的标记颜色。
5. 若令牌不邻接任何标记颜色（仅邻接灰壁或黑背景），令牌保持橙(7)。
6. 墙壁（灰像素和标记像素）均保持不变。

**关键洞察**：同一通道内的令牌因堆叠高度不同而邻接不同的墙壁标记，获得不同颜色。令牌的数量和初始位置间接决定了堆叠高度，从而决定了颜色分配——改变令牌数量会改变所有令牌的配色方案。

## 新题 3：射线分区后精确平铺筛选

**组合逻辑**：[射线延伸](已有，从标记像素发出而非从矩形边缘) → 空间分区(创新——射线交叉点切割背景为矩形区域) → [平铺](已有，条件改为精确覆盖可行性测试) → [重涂色](已有，颜色由区域所属标记决定)

**来源原语**：射线延伸/ray_extend (a2d730bd, 25d487eb), 平铺/tiling (626c0bcc), 重涂色/recolor (多源), 标记像素/marker_pixel (25d487eb), 小型瓦片/small_tile (626c0bcc), 轴线对齐/axis_aligned (a2d730bd), 碰撞停止/collision_stop (多源), 精确覆盖按形着色/exact_cover_by_shape (626c0bcc)

**依赖链**：射线从标记出发将网格切割为矩形区域；每个区域是否能被瓦片精确覆盖取决于区域的宽高（由射线位置决定）；覆盖成功的区域获得所属标记的颜色。删除射线步骤无法产生分区，删除平铺检测无法区分可填区域与不可填区域。

从标记像素向四方延伸射线将网格分区为矩形，仅对宽高均为偶数的区域填入 2x2 瓦片并涂上控制该区域的标记色。

**输入结构**：约 18x18 的网格，背景为黑(0)。网格中散布 3-5 个彩色标记像素（红(2)、蓝(1)、绿(3)、黄(4)），每个标记为单像素，任意两个标记不在同一行也不在同一列。网格左上角 2x2 的区域绘有一个全填充的灰(5) 2x2 方块，作为瓦片模板。生成约束：所有标记位于距网格边缘至少 2 像素以内；标记位置使得射线分区后至少存在一个宽高均为偶数的区域和一个宽高并非均为偶数的区域（以体现筛选逻辑）。

**规则**：
1. 从每个标记像素向上、下、左、右四个方向延伸射线，射线以该标记的颜色绘制。射线遇到另一条射线（任何颜色）、另一个标记像素或网格边缘时停止（不覆盖已有非背景像素）。
2. 射线和网格边缘共同将背景切割为若干矩形区域。确定每个矩形区域的宽度 W 和高度 H。
3. 对每个矩形区域：若 W 和 H 均为偶数，则用 2x2 方块精确平铺该区域（无旋转、无重叠、无间隙），将所有瓦片像素重涂为该区域的控制标记色。
4. 控制标记的确定规则：检查矩形区域四条边界分别由哪个标记的射线构成，选择贡献了最多边界边的标记作为控制者。若两个标记贡献边界边数相同，选择行号较小的标记。网格边缘不算任何标记的贡献。
5. 若 W 或 H 为奇数，该区域保持黑(0)背景不变。
6. 标记像素和射线像素保留在最终输出中。灰(5)瓦片模板保留。

**关键洞察**：标记的位置同时决定了两件事：区域的几何尺寸（能否精确平铺）和区域的颜色归属（哪个标记控制）。移动一个标记可能让原本可铺的区域变为不可铺，同时改变相邻区域的控制归属。

## 新题 4：重力落子后逐行扫描填色

**组合逻辑**：[重力下落](已有，作用对象改为散布的彩色像素) → 行内配对(创新——落定位置决定扫描线端点) → [填充/逐行扫描](已有，填充色由左端点颜色决定)

**来源原语**：重力下落/gravity_drop (36a08778, 2b83f449), 填充/fill (aa18de87), 轮廓像素/outline_pixel (aa18de87), 跨度/span (aa18de87), 逐行扫描/row_scan (aa18de87), 填充轮廓间区域/fill_between_outlines (aa18de87), 碰撞停止/collision_stop (36a08778), 架子/shelf (36a08778)

**依赖链**：重力使彩色像素重新排列到新的行位置；落定后同一行内的像素对构成扫描线端点；扫描填充颜色取决于端点颜色（由落定位置的具体像素决定）。删除重力则像素处于初始位置（不同行），无法形成同行端点对；删除扫描填充则落定像素无法产生连续区域。

散布的彩色像素经重力下落到架子或底部后，在每行内相邻像素之间执行扫描线填充，填充色取决于左端点的颜色。

**输入结构**：约 15x15 的网格，背景为黑(0)。灰(5)水平线段作为架子分布在若干行（每个架子为一段连续灰像素，宽度 3-8 像素），架子之间有纵向间距。彩色像素（红(2)、蓝(1)、绿(3)，每色 2-4 个，每个为单像素）散布在网格各处，部分悬浮于黑色背景上方（下方有黑色空位），部分已在架子上。生成约束：每个彩色像素下落后不会落在另一个彩色像素正上方（即每列中架子上或底部最多只有一个彩色像素最终着陆）；下落后每行至少有 0 个、至多有若干个彩色像素，保证至少有两行各含 2 个以上彩色像素。

**规则**：
1. 所有彩色像素（非灰、非黑）向下移动，逐格穿过黑(0)单元格，遇到灰(5)架子、网格底部时停止在该障碍上方一格。灰架子和已处于架子上的像素不移动。每列独立处理。
2. 所有像素落定后，逐行从左到右扫描。在每一行中，找出所有彩色像素（非灰、非黑）的位置。
3. 对每一行中相邻的两个彩色像素（中间无其他彩色像素），将它们之间所有黑(0)背景单元格重涂为左侧像素的颜色。
4. 若相邻两个彩色像素之间存在灰(5)架子像素，则不跨过架子填充——将该对视为被架子隔断，仅填充左像素到架子左端之间的背景、以及架子右端到右像素之间的背景（各自作为独立的半跨度，颜色仍取各半跨度的左端点颜色；若半跨度的左端点为架子像素则不填充）。
5. 灰架子像素保持不变。单独出现在行中（左侧或右侧无配对像素）的彩色像素不产生填充。

**关键洞察**：像素的初始纵向位置决定它落在哪个架子上（或底部），从而决定它与哪些其他像素成为同行邻居。调换两个像素的初始列可能改变整行的填充图案，因为左端点颜色决定填充色。

## 新题 5：按内部拓扑筛选边框后裁剪并按角标色重涂

**组合逻辑**：拓扑检测(创新——空洞检测应用于框内图案的筛选而非直接重涂) → [面积比较](已有，比较空洞面积) → [裁剪](已有) → [重涂色](已有，颜色来源为角标)

**来源原语**：裁剪/crop (3de23699, be94b721), 检测/detection (b2862040), 重涂色/recolor (3de23699), 边框/frame (3de23699), 角标记像素/corner_marker (3de23699), 封闭区域/enclosed_region (b2862040), 连通分量/connected_component (b2862040, be94b721), 中心图案/central_pattern (3de23699), 内部包含/interior_containment (b2862040, 3de23699), 面积比较/area_comparison (be94b721), 含空洞对象重涂/objects_with_holes_recolored (b2862040), 角标色决定重涂/corner_color_sets_recolor (3de23699)

**依赖链**：拓扑检测（有无空洞）决定哪个边框被选中；面积比较在多个含空洞框之间做仲裁；裁剪提取选中框的内部图案；角标色提供最终颜色。删除拓扑检测则无法确定选取哪个框；删除角标色则裁剪后不知该涂什么颜色。

在多个含角标的矩形边框中，选出内部图案含有最大封闭空洞的那个，裁剪其内容并以角标颜色重涂后输出。

**输入结构**：约 20x20 的网格，背景为黑(0)。网格中有 2-4 个互不重叠的矩形边框，每个边框为 1 像素厚的灰(5)矩形轮廓。每个边框的四个角像素被替换为一种独有的颜色（如红(2)、蓝(1)、绿(3)、黄(4)——同一框四角同色，不同框颜色不同）。每个框内包含一个由橙(7)像素绘成的中心图案——该图案为 4-连通的单色区域，形状各异（3-15 像素，可能有复杂轮廓）。部分框内的橙色图案包含封闭的黑(0)背景空洞（完全被橙色像素 4-连通包围的黑色区域），部分不含空洞。生成约束：至少一个框的图案有空洞，至少一个没有；若多个有空洞则空洞总面积互不相等。

**规则**：
1. 识别每个矩形边框（灰(5)轮廓 + 彩色角标）。
2. 对每个边框，提取其内部区域（去除 1 像素厚的边框本身）。
3. 检查每个框内的橙(7)图案是否包含封闭的背景空洞：在框内部范围内，找不触及框内边界的 4-连通黑(0)区域。
4. 在所有含封闭空洞的框中，选择总空洞面积（所有空洞像素数之和）最大的框。若仅一个框含空洞则直接选它。
5. 将选中框的内部图案裁剪到橙(7)像素的紧凑边界框（最小包围矩形）。
6. 将裁剪结果中所有橙(7)像素重涂为该框的角标颜色。黑(0)像素保持黑色。
7. 输出仅为裁剪后的重涂图案（不含边框）。

**关键洞察**：角标像素同时标识了边框边界和输出颜色，但选取哪个边框完全由拓扑属性（空洞面积）决定，与角标颜色、框的大小或位置均无关。求解者需要对比多个示例才能确定筛选条件是空洞面积而非其他属性。

## 新题 6：重力重排证据后推断周期瓦片

**组合逻辑**：[重力下落](已有，目的改为证据重排) → [周期推断](已有，但证据经重力打乱后重排才一致) → [补全](已有)

**依赖链**：输入中部分瓦片证据被位移到错误行（悬浮），直接做周期推断会得到矛盾的相位信息。重力下落将悬浮像素移回正确的列底部位置，使非黑像素在列内恢复正确的空间关系后，周期推断才能找到唯一的最小重复瓦片。删除重力步骤则证据不一致无法推断周期；删除周期推断则无法补全缺损位置。

**输入结构**：约 12x12 的网格。大部分单元格为黑(0)（缺损/空位）。其余单元格使用红(2)、蓝(1)、绿(3)三种颜色，呈现某个周期瓦片的部分证据。该瓦片的行周期 P_r 和列周期 P_c 均为 2-4 之间的小整数。证据像素分为两类：一类已处于正确位置（与隐含瓦片的相位一致），另一类被人为抬高——在同一列中上移了若干行，下方留出黑色空位。每列内的非黑像素之间没有黑色间隔（悬浮像素紧贴在正确位置像素上方或独立悬浮在列顶部附近）。生成约束：重力下落后（每列内非黑像素堆叠到列底部，保持列内相对顺序），所有非黑像素恰好满足唯一的最小周期瓦片相位一致性；下落前则不满足。每个瓦片相位至少在一个非黑像素中可见。

**规则**：
1. 对每列独立执行重力下落：将该列中所有非黑像素向下移动，堆叠到列的底部（或已有非黑像素之上），保持列内非黑像素的从上到下相对顺序不变。腾出的上方位置变为黑(0)。
2. 下落完成后，将所有黑(0)单元格视为缺损位置。
3. 找到最小的行周期 P_r 和列周期 P_c（P_r >= 1, P_c >= 1，P_r * P_c > 1），使得所有非黑像素按 (row mod P_r, col mod P_c) 相位分组时，同相位像素颜色一致。
4. 由推断出的瓦片相位，将每个缺损（黑色）单元格重涂为其相位对应的颜色。
5. 输出完整修复的周期壁纸网格。

**关键洞察**：悬浮的证据像素提供了某些列中缺失的瓦片相位信息，但只有在重力将它们移到正确的行位置后，这些信息才与整体瓦片周期一致。重力下落与周期推断之间的耦合不是简单的前后传递——重力改变了像素的行坐标，而行坐标直接决定相位计算。

**组合逻辑**：拓扑检测(创新——检测空洞并度量面积作为排序键) → [排序](已有，排序键改为空洞面积) → [计数](已有，计数对象改为空洞个数) → [压缩](已有，编码方式为柱高=空洞个数，列序=面积排序)

**依赖链**：必须先检测每个对象的空洞拓扑（有几个洞、总面积多大）才能确定排序键和柱高；排序决定输出列序；计数决定柱高。三者不可分离：没有拓扑检测则排序键和柱高均无从确定；没有排序则列序不定；没有计数则柱高不定。

**规则**：
1. 找出所有 4-连通的单色前景对象（排除灰(5)干扰像素）。
2. 对每个对象，找出其所有封闭背景空洞（不触及网格边缘且完全被该对象像素 4-连通包围的黑色区域）。计算：空洞个数 N 和空洞总面积 S（所有空洞的像素数之和）。
3. 将对象按空洞总面积 S 降序排列。S 相同时（生成保证不会出现）无需 tie-break。
4. 输出一个紧凑网格：宽度 = 对象数量，高度 = 所有对象中最大的空洞个数 N_max。

6. 空洞个数为 0 的对象对应的列全部为黑(0)（柱高为 0）。

**关键洞察**：输出编码了两个独立的拓扑度量——列序反映空洞总面积（排序键），柱高反映空洞个数（计数）。仅看单个示例无法区分排序键是面积还是个数，必须对比多个示例中两者不同排序时列序的变化才能归纳规则。

## 新题 8：轮廓围合域由内嵌角标着色

**组合逻辑**：[洪泛填充/轮廓围合](已有，屏障角色不变) → 边界邻接计数(创新——角标通过邻接像素数投票决定填充色) → [重涂色](已有，颜色来源改为角标投票)

**依赖链**：轮廓线划定封闭区域的边界；角标嵌在轮廓中，其与封闭区域的邻接关系决定填充颜色；同一角标可能影响多个区域，同一区域可能被多个角标争夺。删除轮廓则无封闭区域；删除角标则不知该填什么颜色。

**输入结构**：约 16x16 的网格，背景为黑(0)。灰(5)像素形成 8-连通的轮廓线，绘制出若干封闭或半封闭形状（线条宽度 1 像素）。在轮廓线的某些弯折处或交叉点处，单个像素被替换为彩色角标（红(2)、蓝(1)、绿(3)、黄(4)），每种颜色可出现 1-3 次。角标像素在空间上与相邻灰像素共同保持轮廓的 8-连通性（即用角标替换灰像素后轮廓仍然 8-连通）。轮廓和角标共同将背景划分为若干 4-连通区域。生成约束：至少 2 个封闭区域（不触及网格边缘的背景区域）；每个封闭区域至少与一个角标 4-相邻；存在至少一个封闭区域与两种不同颜色的角标均 4-相邻（以体现投票逻辑）。

**规则**：
1. 将所有非黑像素（灰轮廓 + 彩色角标）视为屏障。找出所有 4-连通的黑(0)背景区域。
2. 区分封闭区域（不触及网格任何边缘行/列的背景区域）和开放区域（触及网格边缘的背景区域）。
3. 对每个封闭区域，统计其边界上（4-邻居中属于该区域的像素数量）所有角标像素的颜色投票：对每种角标颜色，计算该颜色的角标与该封闭区域之间 4-相邻的像素对总数。
4. 将封闭区域填充为得票最高的角标颜色。若两种颜色得票相同，选择 ARC 颜色编号较小的颜色。
5. 无角标邻接的封闭区域（生成保证不出现此情况）保持黑色。
6. 开放区域保持黑(0)。所有轮廓像素和角标像素保持不变。

**关键洞察**：角标既是轮廓结构的一部分（维持连通性），又是颜色投票者。一个角标可能 4-邻接多个封闭区域从而同时影响它们的颜色，而一个封闭区域周围可能有多种颜色的角标在"争夺"其填充色——最终颜色由邻接像素对的数量决定，而非角标的数量或距离。

2. 对每个对象，计算与其 4-相邻的黄(4)标记像素数量 K。
3. 将该对象进行 K 倍像素放大：对象中每个像素替换为 K x K 的同色方块。
4. 将所有放大后的对象按原始对象中心点的位置排列：先按行从上到下，再按列从左到右排序。放大后的对象从左到右依序排列，相邻对象之间间隔 1 列黑(0)像素。
5. 输出网格的高度 = 所有放大后对象的最大高度；宽度 = 所有放大后对象宽度之和 + (对象数 - 1) 列间距。
6. 高度不足最大高度的对象在输出中垂直顶部对齐，底部补黑(0)。
7. 黄标记和灰干扰像素不出现在输出中。

**关键洞察**：标记像素的空间分布（与哪个对象相邻）决定了各对象的放大倍率，因此在参考题 c59eb873 中固定的全局 2x 倍率在此变为局部可变参数。移动一个标记像素从一个对象旁边到另一个对象旁边，会同时改变两个对象的放大尺寸，产生完全不同的输出布局。
