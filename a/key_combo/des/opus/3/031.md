## 新题 1：对角印章造墙与洪泛探洞

**组合逻辑**：[印章覆盖/stamp + 尺寸决定步幅](已有) → [洪泛填充/flood_fill + 内外分区](已有，但以印章输出作为墙壁——创新耦合) → [填充/fill 封闭区域](已有)

**来源原语**：印章覆盖/stamp、尺寸决定步幅/size_determines_stride、对角偏移重复/diag_offset_repeat（参考题 e619ca6e）；洪泛填充/flood_fill、内外分区/in_out_partition、边界连通分内外/border_in_out（参考题 7b6016b9）；实心矩形/solid_rect（参考题 e619ca6e）；封闭区域/enclosed_region（参考题 7b6016b9）

**依赖链**：矩形的尺寸决定印章步幅 → 印章轨迹在网格中形成非背景像素墙壁 → 洪泛填充以这些墙壁为边界分离内外 → 被墙壁围住的背景区域被着色。删除印章步骤则墙壁不存在；删除洪泛步骤则无法判断哪些区域被围住。

将实心矩形沿双对角方向印章复制后，用轨迹形成的非背景像素作为洪泛填充的墙壁，封闭的背景区域染红(2)。

**输入结构**：黑(0)背景，约 22x22 网格。网格中有 2~3 个不相邻的蓝(1)实心矩形块，每个矩形为 4-连通的轴对齐填充区域，高 h 宽 w 各不相同（h 和 w 在 2~4 像素范围内）。矩形的位置经过设计，使得沿两条对角方向印章复制后，不同矩形的轨迹会在网格内交叉或相邻，围出至少一个封闭的背景区域。矩形之间留有足够间距（至少 5 像素），保证各矩形可被独立识别。生成约束：至少存在一个被轨迹完全包围且不与网格边界 4-连通的黑色区域。

**规则**：
1. 保留所有原始蓝(1)矩形不变。
2. 对每个矩形（高 h、宽 w），以其左上角为起点，沿右下对角方向在偏移 (h, w)、(2h, 2w)、(3h, 3w)…处各印章一个相同的蓝(1)矩形副本；同时沿左下对角方向在偏移 (h, -w)、(2h, -2w)、(3h, -3w)…处各印章一个副本。超出网格边界的部分裁剪丢弃；某条轨迹的所有副本完全超出边界后停止该方向。后印章的像素覆盖先印章的像素（颜色相同所以视觉无区别）。
3. 印章完成后，将所有非黑像素视为墙壁。从网格四条边缘上所有黑(0)像素开始，进行 4-连通洪泛扩散，标记可达的背景像素为"外部"。
4. 未被洪泛标记的黑(0)像素即为被墙壁封闭的区域，将其全部填充为红(2)。
5. 外部背景和所有蓝(1)像素保持不变。

**关键洞察**：墙壁不是输入的一部分，而是由印章操作涌现出来的；矩形的尺寸和位置共同决定了轨迹的几何形态，从而决定了哪些背景区域会被围住。需要对比多个示例才能确认印章同时沿两条对角方向进行，以及步幅等于矩形自身的高和宽。

## 新题 2：对称性决定平铺翻转模式

**组合逻辑**：[对称检测/symmetry_detection](已有，但从布尔输出改为控制后续操作——创新) → [平铺/tiling + 条件性镜像/mirror](已有的平铺和镜像，但由对称检测结果分支决定——创新耦合)

**来源原语**：对称检测/symmetry_detection、镜像轴/mirror_axis（参考题 44f52bb0）；平铺/tiling、拼接/concatenation、奇偶位交替翻转/alternating_flip（参考题 bc4146bd）；镜像/mirror（参考题 846bdb03）

**依赖链**：检测每个精灵体是否具有左右镜像对称性 → 对称结果决定平铺时是否在偶数位置翻转 → 最终平铺结果取决于对称检测。删除对称检测则无法确定使用哪种平铺方式；删除平铺则对称检测结果无处应用。

检测每个小精灵体的左右对称性，对称者平铺为 5 份均一条带，不对称者平铺为 5 份交替翻转条带，再按颜色标记顺序纵向堆叠。

**输入结构**：黑(0)背景，约 20x25 网格，分为上下两区。上区包含 2~3 个互不相邻的小型单色精灵体，每个精灵体是一个 4-连通的单色区域（3~8 像素），使用不同的前景色（如蓝(1)、绿(3)、橙(7)），每个精灵体严格包含在一个 3x4 或 4x4 的边界框内。其中部分精灵体具有左右镜像对称性，部分不具有。下区是一行颜色标记像素，从左到右排列，每个标记像素的颜色对应上区某个精灵体的颜色，标记像素之间间隔 1 列，标记像素的颜色不重复，且与上区精灵体颜色一一对应。生成约束：至少一个精灵体对称、至少一个不对称。

**规则**：
1. 对每个精灵体，提取其边界框内容（包含精灵体像素和黑色背景像素）作为瓦片单元。
2. 检测瓦片单元是否具有左右镜像对称性（将瓦片水平翻转后，非背景像素的相对位置与原瓦片完全一致即为对称）。
3. 若对称：将瓦片水平拼接 5 份，全部使用原始朝向，构成一条水平条带。
4. 若不对称：将瓦片水平拼接 5 份，第 1、3、5 份使用原始朝向，第 2、4 份使用左右镜像，构成一条交替翻转的水平条带。
5. 按下区颜色标记像素的从左到右顺序，依次将对应精灵体的条带纵向堆叠（第一个标记对应的条带在最上方）。条带之间无间隔。
6. 输出仅包含堆叠后的条带区域，输出尺寸 = 条带高度之和 x 条带宽度。

**关键洞察**：对称检测的结果不再是一个颜色指示像素（如参考题 44f52bb0），而是一个控制后续平铺算法的分支条件。需要对比多个示例才能发现：对称精灵体使用均一平铺，不对称精灵体使用交替翻转平铺，且条带堆叠顺序由标记像素而非空间位置决定。

## 新题 3：方向耦合的反转印章与碰撞着色

**组合逻辑**：[颜色反转/color_invert](已有) → [印章覆盖/stamp + 对角偏移重复](已有，但原色与反色分别沿不同对角方向——创新耦合) → [碰撞检测着色](创新：两条轨迹重叠处产生第三种颜色)

**来源原语**：颜色反转/color_invert、二值图案/binary_pattern（参考题 48131b3c）；印章覆盖/stamp、对角偏移重复/diag_offset_repeat、尺寸决定步幅/size_determines_stride、实心矩形/solid_rect（参考题 e619ca6e）

**依赖链**：颜色反转产生反色副本 → 原色副本沿右下印章、反色副本沿左下印章 → 两条轨迹在交叉点产生碰撞 → 碰撞像素被赋予第三种颜色。删除反转则两条轨迹同色、无法区分方向；删除碰撞规则则交叉点处理不确定；删除对角印章则无交叉可碰撞。

将一个二值图案块沿右下对角印章原色副本、沿左下对角印章反色副本，在两条轨迹的交叉处将重叠像素标记为红(2)。

**输入结构**：黑(0)背景，约 25x25 网格。网格内有一个小型二值图案块：一个轴对齐的矩形区域（高 2~3、宽 3~4 像素），内含黑(0)和一种前景色（如蓝(1)）的混合图案。图案块位于网格中上部偏左位置，使得沿两条对角方向印章时，至少一对副本在网格内交叉。图案块不对称（左右翻转后图案不同），以确保原色轨迹与反色轨迹视觉可区分。生成约束：图案块位置保证两条对角轨迹在网格范围内至少有一个重叠区域。

**规则**：
1. 设图案块高 h、宽 w，前景色为 C。
2. 创建图案块的颜色反转副本：原图案中黑(0)像素变为 C，原 C 像素变为黑(0)。
3. 以图案块左上角为起点，沿右下对角方向在偏移 (h, w)、(2h, 2w)…处印章原色图案块（保持原始颜色），超出网格裁剪，完全超出后停止。
4. 以图案块左上角为起点，沿左下对角方向在偏移 (h, -w)、(2h, -2w)…处印章反色图案块，超出网格裁剪，完全超出后停止。
5. 原始图案块本身也保留在输出中（属于原色轨迹的第 0 个副本）。
6. 印章顺序：先绘制右下轨迹（从远到近），再绘制左下轨迹（从远到近），最后绘制原始图案块。
7. 碰撞规则：若某个像素同时被原色轨迹中的非黑像素和反色轨迹中的非黑像素覆盖（即两条轨迹都在该位置放置了前景色 C 的像素），则该像素最终变为红(2)。判定逻辑：对每个像素，记录它是否在原色轨迹中被赋予过 C，以及是否在反色轨迹中被赋予过 C；若两个记录都为真，最终颜色为红(2)，否则按最后一次印章的颜色绘制。

**关键洞察**：红(2)碰撞色不在输入中出现，是两条轨迹交叉的涌现结果。需对比多个示例确认三点：原色沿右下、反色沿左下；碰撞仅在双方都放置前景色时才发生（一方的黑色不算碰撞）；碰撞色固定为红(2)。

## 新题 4：洪泛分区后按面积排名交替着色

**组合逻辑**：[洪泛填充/flood_fill + 内外分区](已有) → [计数/counting 封闭区域面积](已有，但此处用于排名而非简单计数——创新) → [排序/sorting 面积](创新引入) → [交替填色/alternating_fill 按排名奇偶](已有的交替概念，但基于面积排名而非空间位置——创新耦合)

**来源原语**：洪泛填充/flood_fill、内外分区/in_out_partition、边界连通分内外/border_in_out、线条对象/line_object、封闭区域/enclosed_region（参考题 7b6016b9）；计数/counting（参考题 e3fe1151, d5c634a2）；排序/sorting（参考题 817e6c09）；交替填色/alternating_fill、奇偶决定颜色/parity_determines_color（参考题 db3e9e38）

**依赖链**：线条对象形成墙壁 → 洪泛填充分离外部与封闭区域 → 计算每个封闭区域的面积（像素数）→ 按面积从大到小排序 → 排名奇偶决定填充颜色。删除洪泛则无法识别封闭区域；删除面积排序则无法确定交替顺序；删除交替规则则所有区域同色。

线条对象将背景分为外部和若干封闭区域，外部染绿(3)，封闭区域按面积从大到小排名后交替染红(2)和黄(4)。

**输入结构**：黑(0)背景，约 18x18 网格。一种非背景色（如灰(5)）的像素形成一个 4-连通的正交线条对象（线条仅沿水平或垂直方向延伸，宽度为 1 像素）。线条对象将黑色背景分隔为若干不连通的区域：部分区域与网格边界 4-连通（外部），其余区域完全被线条包围（封闭区域）。封闭区域数量为 3~5 个，且面积（像素数）互不相同。生成约束：所有封闭区域的面积互不相同，以避免排名歧义。

**规则**：
1. 保留灰(5)线条对象不变。
2. 从网格边界上所有黑(0)像素出发，进行 4-连通洪泛扩散。所有可达的黑色像素标记为外部，填充为绿(3)。
3. 统计每个封闭区域的面积（该区域包含的黑色像素数）。
4. 将所有封闭区域按面积从大到小排序，排名从 0 开始。
5. 排名为偶数（0, 2, 4, ...）的封闭区域填充为红(2)。
6. 排名为奇数（1, 3, 5, ...）的封闭区域填充为黄(4)。

**关键洞察**：交替颜色不是基于封闭区域的空间位置（如从左到右或从上到下），而是基于面积排名。仅看单个示例可能误判排序依据为位置，需对比多个示例确认颜色交替依据面积大小。

## 新题 5：遮挡重建后按层深生长同心边框

**组合逻辑**：[补全/reconstruct + 遮挡层序/occlusion_order](已有) → [计数/counting 遮挡深度](创新：遮挡层序中的深度数值化) → [生长/grow 同心边框](已有，但层数由遮挡深度参数化——创新耦合)

**来源原语**：补全/reconstruct、遮挡层序/occlusion_order、可见像素定边框/visible_defines_bbox、空心矩形精灵/ring_sprite、遮挡碎片/occluded_fragment（参考题 652646ff）；生长/grow、同心正方形层/concentric_layer（参考题 3befdf3e）；计数/counting（参考题 d5c634a2）；堆叠/stacking（参考题 652646ff）

**依赖链**：可见碎片重建完整空心矩形 → 分析哪些颜色遮挡哪些颜色得到层序 → 层序中每个精灵的深度（它被多少层覆盖）决定生长层数 → 按层序渲染生长后的精灵。删除重建则无法得到完整形状；删除层序则无法确定深度和渲染顺序；删除参数化生长则输出尺寸不确定。

从部分重叠的空心矩形碎片重建完整轮廓，按遮挡深度为每个矩形添加相应数量的同心外边框，最后按层序从底到顶渲染。

**输入结构**：黑(0)背景，约 22x22 网格。3~4 个空心矩形轮廓（1 像素宽的矩形边框，内部和外部均为黑色背景），每个使用不同颜色（如蓝(1)、绿(3)、橙(7)、灰(5)）。矩形大小不同（边界框在 4x4 到 7x7 之间），且部分重叠——重叠处仅显示上层矩形的颜色，下层矩形的对应轮廓像素被遮挡。每个矩形至少有 60% 的轮廓像素可见（以确保可重建）。矩形周围留有至少 3 像素的空余空间（为生长预留）。生成约束：遮挡关系构成全序（任意两个有重叠的矩形都有明确的上下关系，不存在循环遮挡）。

**规则**：
1. 对每个颜色 C 的可见像素集合，推断其完整的空心矩形轮廓。方法：C 的可见像素确定矩形边界框的部分边缘；在 C 的预期轮廓位置上，若存在另一颜色 C' 的像素，则 C' 在 C 之上。
2. 由遮挡关系的传递闭包确定从顶到底的全序。设最顶层深度 D=0，次层 D=1，以此类推。
3. 对深度为 D 的矩形，在其完整轮廓外侧添加 D 层同心矩形边框（每层 1 像素宽），全部使用该矩形自身的颜色 C。D=0 的矩形不添加任何额外边框。
4. 在黑色画布上，按从底层到顶层的顺序依次渲染每个矩形及其生长边框。后渲染的覆盖先渲染的。
5. 输出网格尺寸与输入相同。生长超出网格边界的部分裁剪丢弃。

**关键洞察**：被遮挡得越深的矩形反而生长得越多——遮挡深度与生长量正相关。需对比多个示例确认生长层数等于遮挡深度值（而非常数或与面积相关），以及最顶层矩形不生长。

## 新题 6：框体尺寸定缩放、框色过滤模板

**组合逻辑**：[像素放大/pixel_scaling](已有，但缩放因子由框体尺寸而非标记方块边长决定——创新) × [颜色匹配/color_match 过滤模板像素](创新：框色作为掩码选择模板中的特定颜色) + [擦除/erase 干扰标记](已有)

**来源原语**：像素放大/pixel_scaling、模板/template、缩放对应/scale_correspond、边长定缩放因子/side_sets_scale（参考题 447fd412）；空心框架/hollow_frame、颜色匹配/color_match（参考题 8f215267）；擦除/erase、忽略干扰项/ignore_distractors（参考题 8f215267, 817e6c09）；标记像素/marker_pixel（参考题 846bdb03）

**依赖链**：框体几何尺寸 → 推导缩放因子 → 缩放模板；框体颜色 → 过滤模板中同色像素 → 仅保留匹配色的缩放像素。框体同时编码两个独立参数（尺寸→缩放、颜色→过滤），删除任一解码路径都使输出不确定。

一个多色模板根据每个空心框的内部短边长缩放后，仅保留与该框颜色匹配的模板像素，填入框内。

**输入结构**：黑(0)背景，约 20x20 网格。网格左上角有一个小型多色模板图案（3x3 像素），模板中包含 2~3 种不同的非背景色（如红(2)、绿(3)、蓝(1)），每种颜色至少占 2 个像素。网格其余区域分布有 2~3 个空心矩形框（1 像素宽边框），每个框使用模板中出现的某种颜色（如一个红(2)框、一个绿(3)框）。不同框的内部尺寸（内部空间的短边长度）互不相同且均为模板边长（3）的整数倍，如内部为 3x3、6x6、9x9（对应缩放因子 k=1, 2, 3）。框与框之间不重叠，框不与模板重叠。在一些框的外侧附近有 1~2 个灰(5)干扰标记像素。生成约束：每个框的内部短边长是模板边长的整数倍。

**规则**：
1. 擦除所有灰(5)干扰标记像素（替换为黑(0)）。
2. 识别左上角的 3x3 模板图案。
3. 对每个空心矩形框：测量其内部空间的短边长度 S；计算缩放因子 k = S / 3（模板边长）。
4. 将模板按因子 k 像素放大（每个模板像素变为 k x k 块）。
5. 颜色过滤：在缩放后的模板中，仅保留与该框边框颜色相同的像素，其余像素变为黑(0)。
6. 将过滤后的缩放模板放置于框的内部空间，左上角对齐框内部的左上角。若缩放模板尺寸与框内部不完全匹配（因框为非正方形），多出的部分裁剪。
7. 框边框本身保留不变。

**关键洞察**：单个框同时编码两个信息维度——几何尺寸编码缩放因子，颜色编码模板过滤掩码。需对比多个示例确认缩放因子来自框的内部尺寸而非外部尺寸或面积，并确认颜色过滤保留的是与框同色的模板像素而非其他。

## 新题 7：面板对称性决定叠加层序

**组合逻辑**：[透明叠加/transparent_overlay](已有，但叠加顺序不再由空间位置决定——创新) ← [对称检测/symmetry_detection](已有，从输出布尔值改为输出排序优先级——创新耦合) + [计数/counting 非背景像素](创新引入的排序辅助)

**来源原语**：透明叠加/transparent_overlay、分隔列/separator_column、色彩面板/color_panel、前后遮挡/front_back_occlusion、面板顺序即层序/panel_order_is_depth（参考题 cf98881b）；对称检测/symmetry_detection、镜像轴/mirror_axis、对称否决定输出色/symmetric_vs_asym_color（参考题 44f52bb0）

**依赖链**：分离面板 → 检测每个面板图案的对称性 → 对称性决定面板的前后优先级（对称面板在前/上层，不对称面板在后/下层）→ 同类内部按非背景像素数量排序（少的在前）→ 按此顺序叠加面板。删除对称检测则层序未知；删除像素计数则同类内部顺序不确定。

三个分隔面板按"对称优先、稀疏优先"的规则重排层序后透明叠加为一张图。

**输入结构**：黑(0)背景网格，由两条红(2)竖直分隔列将网格等分为三个相同尺寸的面板（每个面板约 8x8 到 10x10）。每个面板内有一个单色图案（面板间颜色互不相同，使用除黑(0)和红(2)以外的颜色，如蓝(1)、绿(3)、黄(4)），图案由该颜色的像素在黑色背景上构成。三个面板中，至少一个的图案具有左右镜像对称性，至少一个不具有。三个面板的非背景像素数量互不相同。生成约束：三个面板的对称/不对称分类和像素数量的组合保证叠加层序唯一确定。

**规则**：
1. 按红(2)分隔列将输入切分为三个面板（不含分隔列本身）。
2. 对每个面板，检测其图案（非背景像素集合）是否具有左右镜像对称性。
3. 排序规则：对称面板排在不对称面板之前（对称 = 更高优先级 = 上层/前景）。在同为对称或同为不对称的面板之间，非背景像素数量更少的排在前面（更少 = 更高优先级 = 上层/前景）。
4. 创建一个与单个面板同尺寸的黑色输出画布。
5. 按排序从最低优先级（最底层）到最高优先级（最顶层）依次叠加：将面板的非黑像素绘制到输出画布上，后绘制的覆盖先绘制的。
6. 输出仅包含叠加后的单面板尺寸网格。

**关键洞察**：面板的空间位置（左/中/右）是干扰项，真正决定层序的是几何属性（对称性）和统计属性（像素密度）。需对比多个示例排除"左面板在前"等位置假说，确认对称性为主排序键、像素数为副排序键。

## 新题 8：重力对齐后按原始高度排名交替着色

**组合逻辑**：[对齐/align 至基线](已有，但对齐擦除了原始位置信息——创新设置) → [排序/sorting 按原始高度](创新：排序依据是变换前的属性而非变换后的) → [重涂色/recolor + 奇偶交替选择/alternating_parity_selection](已有的交替选择，但基于原始高度排名——创新耦合)

**来源原语**：对齐/align、基线对齐/baseline_aligned、标记行/marker_row（参考题 41ace6b5）；排序/sorting、沿轴排列/axis_arrangement（参考题 817e6c09）；重涂色/recolor、奇偶交替选择/alternating_parity_selection（参考题 817e6c09）；小方块/small_square（参考题 817e6c09）；忽略干扰项/ignore_distractors（参考题 817e6c09）

**依赖链**：记录每个方块的原始行位置 → 将所有方块下落至基线行上方 → 按原始行位置（离基线越远排名越前）排序 → 排名奇偶决定着色。对齐操作抹去了空间信息，但颜色编码了被抹去的信息——删除对齐则无法产生正确的空间布局；删除基于原始高度的排序则无法确定着色。

散落在不同高度的同色方块下落至基线后，按其原始距离基线的远近排名，交替涂为两种颜色。

**输入结构**：黑(0)背景，约 15x20 网格。网格中有一条水平灰(5)标记行位于下方（约第 15 行），宽度占满整行。标记行上方散布着 4~6 个蓝(1)小方块（每个 2x2 像素），各方块占据不同的列（每列至多一个方块），且各方块的底边到标记行的距离互不相同。方块之间水平不相邻（列间距至少 1）。生成约束：所有方块的底边到标记行的垂直距离互不相同，以确保排名无歧义。

**规则**：
1. 保留灰(5)标记行不变。
2. 记录每个蓝(1)方块的底边行号，计算其到标记行的垂直距离 d（标记行行号减去方块底边行号）。
3. 将所有方块下移至标记行正上方：每个方块的底边行号变为标记行行号减 2（因方块高 2 像素，底边紧贴标记行上方一行），列位置保持不变。
4. 按原始垂直距离 d 从大到小排序所有方块，排名从 0 开始（原始位置离标记行最远的方块排名 0）。
5. 排名为偶数（0, 2, 4, ...）的方块重涂为青(8)。
6. 排名为奇数（1, 3, 5, ...）的方块重涂为红(2)。
7. 方块的原始位置上留下黑(0)背景（方块已移走）。

**关键洞察**：下落后所有方块对齐到同一行，空间上无法区分谁原来更高，但颜色编码了这一被抹去的信息。仅看输出无法判断着色依据（因为方块已在同一行），必须结合输入的原始高度才能理解交替规则。需对比多个示例确认排序依据是原始垂直距离而非列位置。
