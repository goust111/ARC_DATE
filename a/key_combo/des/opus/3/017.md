## 新题 1：缺口定引力，滑入残框

**组合逻辑**：[补全](创新：缺失侧编码引力方向，而非仅用于修复) + [滑动/碰撞停止](创新：引力方向由框架缺口决定，而非固定墙壁列) + [缺失像素补新色](已有原语)

**来源原语**：补全/边界框推断/缺失像素补新色(6d75e8bb)，滑动/碰撞停止/近者优先不重叠(f0100645)，不完整矩形(6d75e8bb)，最近邻选择(6df30ad6)

**依赖链**：框架缺口的位置决定了引力方向（缺口编码方向），引力方向决定了物体的滑动轨迹（方向驱动运动），物体滑入后框架才被补全（运动完成后才封口）。缺口同时承担"结构缺陷"和"方向参数"两个语义，三步之间无法跳过任何一步。

将散落在网格中的小物体按各自最近残框的缺口方向滑入框内，再用新颜色封闭缺口。

**输入结构**：约 18x18 的黑(0)背景网格。网格中有 2-3 个蓝(1)像素构成的不完整矩形框（每个约 5x5 至 7x7），每个框恰好缺少一条完整的边（上/下/左/右之一），其余三条边完整。框内部为黑(0)。网格中另有 3-5 个散落的小型 4-连通单色精灵体，每个精灵体由 2-4 个像素组成，颜色各不相同，从{红(2), 绿(3), 黄(4), 橙(7)}中取用。所有精灵体都位于所有框的外部。每个精灵体与所有框之间有明确的距离差（不存在到两个框等距的情况）。精灵体的滑动路径不穿越其他框。生成时保证每个框至少有一个精灵体被分配给它。

**规则**：
1. 对每个不完整矩形框，检测其缺失的边所在方向。缺失方向即为该框的"引力方向"（缺失顶边 → 引力向上；缺失底边 → 引力向下；缺失左边 → 引力向左；缺失右边 → 引力向右）。
2. 对每个散落精灵体，计算其边界框中心到每个矩形框边界框中心的欧氏距离，将该精灵体分配给最近的框。
3. 对每个框，按其被分配的精灵体到框缺口开口边的距离从近到远排序，依次处理。
4. 将每个精灵体沿该框的引力方向平移，保持精灵体形状不变，直到精灵体的任一像素紧邻框壁或已在框内安顿的另一个精灵体为止（碰撞停止）。精灵体最终必须完全位于框的边界框内部。
5. 所有精灵体安顿完毕后，用红(2)像素将每个框的缺失边补全，封闭框架。若红(2)已作为某精灵体颜色使用，则改用栗(9)补全。
6. 输出中擦除所有未被分配到任何框的残留像素（如果有的话）。

**关键洞察**：不完整矩形框的缺口同时承担两个角色——它既是需要补全的结构缺陷，也隐式编码了将外部物体拉入框内的引力方向；求解者必须先读取缺口位置、再执行滑动、最后才封口，三步顺序不可交换。

## 新题 2：模板旋转定射线方向，交叉点涌现新标记

**组合逻辑**：[模板提取/旋转反射等价](已有原语) + [射线延伸](创新：射线方向由模板旋转态隐式编码，而非由端口显式标注) + [补全](创新：补全与射线发射共享同一旋转参数)

**来源原语**：模板提取/旋转反射等价/对齐签名匹配(79369cc6)，射线延伸/端口编码射线(5961cc34)，补全(79369cc6)

**依赖链**：必须提取模板才能判断各副本的旋转态 → 旋转态同时决定补全内容和射线方向 → 射线交叉产生源题中不存在的涌现几何（交叉点标记）。旋转态是三个操作的共享参数，删除任一操作都使其余部分缺失关键信息。

识别散布的不完整模板副本的旋转态，补全缺失部分，并沿各副本的朝向发射射线，在射线交叉处标记新像素。

**输入结构**：约 20x20 的黑(0)背景网格。网格某处有一个完整的 3x3 模板区域，内含黄(4)和品红(6)像素，构成一个非对称图案（4 个旋转态互不相同）。模板中黄(4)像素分布不对称：恰好有一条边上的黄(4)像素最多（例如右边有 2 个黄像素，其余边各 0 或 1 个），该边为模板的"箭头方向"。网格其他位置有 3-5 个不完整副本，每个副本仅显示品红(6)像素（黄(4)像素被省略），且各副本可处于 0/90/180/270 度旋转状态之一。各副本及完整模板之间的间距至少 4 像素。生成时保证至少有一对副本的射线会相交。

**规则**：
1. 提取完整模板：以所有黄(4)像素的边界框为模板范围，裁剪得到 3x3 的二色（黄+品红）模板。
2. 对每个不完整副本（仅含品红像素的孤立簇），逐一尝试模板的 4 种旋转，找到唯一一种使得旋转后模板的品红位置与该副本的品红像素完全吻合的旋转态。
3. 补全副本：在确定的旋转态下，将模板中对应黄(4)的位置在网格上也涂为黄(4)。
4. 确定射线方向：原始模板中黄(4)像素最多的那条边为"箭头方向"（如原始模板箭头朝右）。对旋转了 θ 度的副本，箭头方向也旋转 θ 度（0°→右，90°→下，180°→左，270°→上）。
5. 从每个副本的 3x3 边界框中心像素出发，沿箭头方向发射 1 像素宽的射线，用绿(3)逐像素绘制，直到射线到达网格边界或进入另一个副本/模板的 3x3 边界框为止（不包含终点所在边界框内的像素）。
6. 若两条射线经过同一个像素，将该像素涂为红(2)而非绿(3)。
7. 完整模板本身不发射射线，也不被补全操作修改。

**关键洞察**：每个不完整副本的旋转态是一个共享参数，同时决定了两件事——补全时黄色像素的放置位置和射线的发射方向；求解者必须同时解决"这是哪个旋转"的问题才能执行后续两步操作。

## 新题 3：三点定框，最近标签定填色

**组合逻辑**：[三点定矩形框/补全](已有原语) + [最近邻选择/欧氏距离最小](创新：从选择已有对象的颜色变为选择散布标签的颜色来填充新构造的矩形内部) + [填充](创新：填充目标是由标记点构建的矩形，而非已存在的区域) + [擦除](已有原语)

**来源原语**：补全/三点定矩形框/包围盒/标记像素(e7639916)，最近邻选择/欧氏距离最小/擦除(6df30ad6)，填充(2a28add5)

**依赖链**：标记三点确定矩形几何（构建） → 矩形中心位置确定后才能计算到各标签的距离（度量） → 距离最近的标签颜色决定矩形内部填色（着色）。构建、度量、着色三步串联，且度量依赖于构建的结果（中心坐标），着色依赖于度量的结果（最近标签）。

从多组三点标记推断矩形边框，再由散布的颜色标签像素中距离最近者决定每个矩形的内部填充颜色。

**输入结构**：约 15x15 的黑(0)背景网格。包含 2-3 组标记三点，每组三点颜色相同（如第一组为绿(3)，第二组为黄(4)，第三组为橙(7)），每组恰好 3 个像素，位于各自边界框的边上但不共线。另有 3-4 个孤立单像素作为颜色标签，颜色从{蓝(1), 红(2), 品红(6), 栗(9)}中取用，每个标签颜色不同。标记组的颜色与标签颜色不重叠。各组三点的边界框可以部分重叠。每个矩形的中心到各标签的欧氏距离互不相等，且不同矩形的最近标签也互不相同。

**规则**：
1. 对每组同色标记三点，计算三点的边界框，确定一个矩形区域。
2. 用灰(5)像素绘制该矩形的四条边框（1 像素宽）。
3. 计算每个矩形的几何中心（边界框中心，取整数坐标时向下取整）。
4. 对每个矩形，计算其中心到每个颜色标签像素的欧氏距离。选择距离最小的标签像素，用该标签的颜色填充矩形内部（边框以内、不含边框本身的区域）。若距离相等（生成时已排除此情况），按标签像素从上到下、从左到右的扫描顺序选取第一个。
5. 擦除所有原始标记三点像素和所有标签像素（将它们所在位置设为黑(0)），但保留灰色边框和彩色填充。
6. 若两个矩形区域重叠：重叠部分的边框和填充由边界框面积较小的矩形覆盖（小矩形画在上层）。面积相等时，边界框左上角靠左靠上者优先。

**关键洞察**：矩形的几何形状和内部填色来自两个独立的信息源——三点标记确定形状，散布标签确定颜色——两者通过矩形中心的空间位置产生耦合；求解者必须先构建矩形才能知道中心在哪，才能判断哪个标签最近。

## 新题 4：精灵边缘编码迷宫，路径决定输出序列

**组合逻辑**：[编码映射](创新：精灵体的边缘像素分布隐式编码通道开闭，而非颜色数编码倍率) + [寻路/最短路径](已有原语) + [裁剪/紧凑排列](创新：路径序列决定裁剪对象和排列顺序)

**来源原语**：编码映射(b91ae062)，寻路/最短路径/走廊通道(3ad05f52)，裁剪/紧凑排列/空间位置排序(1990f7a8)，网格单元(38007db0)

**依赖链**：精灵体的内容编码了迷宫的通道开闭（内容即规则） → 迷宫通道结构决定了最短路径（结构决定路径） → 路径经过的单元格决定了哪些精灵体被提取及排列顺序（路径决定输出）。精灵体同时扮演"迷宫编码器"和"输出内容"两个角色，构成自指结构。

网格单元中的精灵体通过其边缘像素分布隐式定义了单元间的通行关系，求解者需读取精灵体来解迷宫，再沿最短路径提取精灵体作为输出。

**输入结构**：约 15x15 的网格，由栗(9)网格线（1 像素宽）分割为 3x3 的格子阵列（9 个单元格），每个单元格内部为 4x4 像素。每个单元格内部有一个绿(3)精灵体图案（2-6 个像素）位于黑(0)背景上。左上角单元格和右下角单元格的精灵体颜色替换为黄(4)，作为起点和终点标记。精灵体的像素位置决定通道开闭：若某单元格内部的精灵体在紧邻某条边的那一行/列上至少有 1 个像素，则该方向的通道开放。例如，精灵体在单元格内部最顶行有像素 → 向上通道开放；在最右列有像素 → 向右通道开放。两个相邻单元格之间的通道仅在双方都在共享边方向上开放时才可通行。

**规则**：
1. 对每个单元格，检查其精灵体（绿(3)或黄(4)像素）在 4x4 内部区域的四边分布：
   - 内部最顶行（第 0 行）有至少 1 个前景像素 → 上方通道开放
   - 内部最底行（第 3 行）有至少 1 个前景像素 → 下方通道开放
   - 内部最左列（第 0 列）有至少 1 个前景像素 → 左方通道开放
   - 内部最右列（第 3 列）有至少 1 个前景像素 → 右方通道开放
2. 构建 3x3 的单元格邻接图：两个水平/垂直相邻的单元格之间有通路，当且仅当左侧单元格右方通道开放且右侧单元格左方通道开放（上下方向类似）。
3. 从左上角单元格（起点，黄(4)）到右下角单元格（终点，黄(4)）执行 BFS 寻找最短路径。若存在多条等长路径，优先选择在分叉处按"右→下→左→上"方向顺序尝试的那条路径。
4. 沿最短路径依次提取每个经过的单元格内部的精灵体，裁剪为 4x4 区块。将黄(4)起点/终点单元格的精灵体颜色统一替换为绿(3)。
5. 将提取的 4x4 区块按路径顺序从左到右排成一行，相邻区块之间用 1 列栗(9)分隔。输出网格高度为 4，宽度为 (路径长度 x 4 + (路径长度 - 1) x 1)。

**关键洞察**：精灵体的几何形状同时承担两个语义——它既是迷宫通道的编码（边缘分布 → 通行规则），也是最终输出的内容；求解者必须"阅读"精灵体形状来解谜，然后"提取"同样这些形状作为答案。

## 新题 5：选择器匹配精灵，像素面积编码条形图

**组合逻辑**：[颜色索引匹配/选择器块](已有原语) + [计数](创新：从计数 2x2 方块变为计数任意精灵体的像素面积) + [条形图](创新：多柱条形图由选择器的空间布局决定柱序) + [忽略干扰项](已有原语)

**来源原语**：颜色索引匹配/选择器块/图例位置映射(7d18a6fb)，计数/条形图/计数编码为条长/忽略干扰项(1fad071e)，空间位置排序(1990f7a8)

**依赖链**：选择器中的标记颜色决定哪些精灵体被选中（颜色匹配选择） → 被选精灵体的像素面积决定对应条形高度（面积编码） → 标记在选择器中的空间位置决定条形排列顺序（位置定序）。删除选择器则不知选哪些精灵体；删除计数则不知条高；删除位置排序则条序不确定。

利用选择器块中的颜色标记匹配外部精灵体，统计每个被选精灵体的像素面积，按标记在选择器中的位置顺序输出为多柱条形图。

**输入结构**：约 15x15 的黑(0)背景网格。网格中有一个 5x5 的灰(5)选择器块（实心灰色方块），其内部有 3 个单像素标记，颜色各不相同，从{蓝(1), 红(2), 绿(3)}中取用，位于选择器块内不同行列。网格其他位置散布有若干前景元素：对每种标记颜色，恰好有一个由该颜色组成的 4-连通精灵体（3-7 个像素），以及 1-2 个同颜色的孤立单像素（干扰项）。不同颜色的精灵体像素数互不相同。精灵体和干扰项都不与选择器块相邻。

**规则**：
1. 识别选择器块：找到网格中唯一的 5x5 灰(5)实心区域（可含非灰标记像素）。
2. 在选择器块内定位所有非灰像素，记录每个标记的颜色和在块内的位置 (r, c)。
3. 对每种标记颜色，在选择器块外部寻找该颜色的所有像素。忽略孤立单像素（4-连通分量大小为 1 的像素即为干扰项）。剩余的 4-连通分量即为匹配的精灵体。
4. 统计每个匹配精灵体的像素数量 N。
5. 将标记按其在选择器块内的位置从上到下排序（同行则从左到右）。此排序决定条形图中各柱的从左到右顺序。
6. 输出条形图：宽度为标记数量（3），高度为所有 N 值中的最大值。每柱宽 1 像素，从底部向上填充 N 个像素，用对应精灵体的颜色。未填充部分为黑(0)。各柱紧邻排列无间隔。

**关键洞察**：选择器块扮演"目录"角色，其内部标记的颜色选出目标精灵体，标记的空间位置编码输出顺序——这两个信息编码在同一组标记像素中，求解者必须同时提取颜色和位置。

## 新题 6：转置压缩网格以解锁拉丁方补全

**组合逻辑**：[压缩/网格分区](已有原语) + [镜像/对角对称](创新：转置不是最终步骤而是中间步骤，目的是使约束可解) + [补全/拉丁方约束](创新：补全的前提条件是先完成一个空间变换)

**来源原语**：压缩/网格分区/分隔线/单色区域(9f236235)，镜像/对角对称/沿主对角线转置(9dfd6313)，补全/拉丁方约束/行列唯一约束/空白单元(4cd1b7b2)

**依赖链**：必须先压缩分区网格为小矩阵（降维） → 压缩后的矩阵直接补全有多个合法解（不可解） → 转置后恰好有唯一解（转置解锁唯一性） → 补全转置后的矩阵为拉丁方。转置不是最终输出变换，而是使约束满足问题可解的中间操作，这在源题中从未出现。

将分区网格压缩为小矩阵后沿主对角线转置，再利用拉丁方约束填补空白格。

**输入结构**：一个正方形网格（约 13x13），被橙(7)分隔线（1 像素宽，水平和垂直各 3 条）划分为 4x4 的等大正方形区域。每个区域内填充单一颜色，从{蓝(1), 红(2), 绿(3), 黄(4)}中取用，或为黑(0)表示空白。已填色的区域满足以下生成约束：**转置前**，同行或同列可能存在重复颜色（所以直接补全不具唯一解）；**转置后**，已填色的格子在每行每列中无重复，且恰好有唯一一种方式可将所有黑(0)格填为{1,2,3,4}使每行每列各色恰出现一次。4x4 矩阵中至少有 6 个非空格和至少 4 个空格。橙(7)分隔线连通且横贯整个网格。

**规则**：
1. 识别分隔线颜色：找到形成连通十字格栅且横贯网格的颜色（橙(7)）。
2. 压缩：将每个分隔线界定的矩形区域替换为一个像素，颜色为该区域的填充色，得到 4x4 的小矩阵。
3. 沿主对角线转置该 4x4 矩阵：将第 r 行第 c 列的像素与第 c 行第 r 列的像素交换。
4. 在转置后的矩阵中，将每个黑(0)格替换为{蓝(1), 红(2), 绿(3), 黄(4)}中唯一满足"该行该列尚未出现"的颜色。逐格求解时，若某格仅剩一种合法颜色则填入，反复迭代直到所有格填满。
5. 输出为完成后的 4x4 小矩阵（不再扩展回大网格）。

**关键洞察**：转置操作在此并非为了产生视觉对称效果，而是一个使拉丁方约束从"多解"变为"唯一解"的数学前提——求解者必须发现"先转置才能唯一补全"这一隐藏步骤，仅看单个示例可能误以为直接补全即可。

## 新题 7：计数门控级联激活

**组合逻辑**：[级联激活/链式反应传播](创新：激活不再无条件传播，而是受计数门控) + [计数/忽略干扰项](创新：计数结果用作激活阈值而非编码条形长度) + [重涂色](已有原语) + [擦除](已有原语)

**来源原语**：级联激活/链式反应传播/端口/连通分量/重涂色(5961cc34)，计数/忽略干扰项(1fad071e)，擦除/最近邻选择(6df30ad6)，走廊通道(3ad05f52)

**依赖链**：走廊的长度定义了激活阈值（走廊编码阈值） → 每个团块内有效标记的计数决定该团块是否满足阈值（计数 vs 阈值） → 满足阈值的团块被激活并参与下一轮级联（条件传播） → 级联顺序影响最终哪些团块被激活（顺序依赖）。计数和级联相互耦合：不计数则无法判断是否激活，不追踪级联顺序则无法确定下一步从哪个团块出发。

从起始团块出发沿走廊传播激活信号，但每个团块仅在其内部有效标记数达到连接走廊长度时才被激活，形成有条件的链式反应。

**输入结构**：约 20x20 的黑(0)背景网格。包含 4-6 个蓝(1)矩形团块（4-连通，每个约 3x3 至 5x5）。团块之间由灰(5)走廊连接（1 像素宽的水平或垂直通道，长度 1-5 像素不等）。每个团块内部散布有两种小点：绿(3)点为有效计数标记，黄(4)点为干扰项。一个团块的边界上有一个红(2)像素标识其为起始团块。每个非起始团块内有 1-4 个绿(3)点和 0-2 个黄(4)点。起始团块内可以没有绿/黄点。网络连通结构为树形（无环），使级联顺序唯一。生成时保证至少一个团块因计数不足而无法激活。

**规则**：
1. 激活起始团块（含红(2)标记的那个）。将其所有蓝(1)像素重涂为红(2)。同时将连接起始团块的走廊也涂为红(2)。
2. 从每个已激活团块出发，检查通过走廊相连的每个尚未激活的邻居团块：
   a. 统计该邻居团块内部绿(3)点的数量（忽略黄(4)干扰点）。
   b. 测量连接两团块的走廊长度（走廊像素数，不含团块本身的边界像素）。
   c. 若绿(3)点数量 >= 走廊长度，则该邻居团块被激活：将其蓝(1)像素和连接走廊涂为红(2)。
   d. 若绿(3)点数量 < 走廊长度，则该邻居团块不被激活。
3. 重复步骤 2，直到没有新团块被激活为止。
4. 若多个团块可同时激活，按团块左上角坐标从上到下、从左到右的顺序依次处理。
5. 擦除所有未被激活的团块及其连接走廊（设为黑(0)）。擦除所有绿(3)和黄(4)标记点。保留所有红(2)像素。

**关键洞察**：走廊不仅是物理连接通道，其长度还隐式编码了下游团块的激活阈值——这使得级联传播变成一个条件分支过程，求解者必须逐步计数并比较才能确定激活网络的最终形态。

## 新题 8：互补掩码排序打包

**组合逻辑**：[紧凑排列/空间位置排序](创新：排序依据从输入空间位置变为互补掩码的像素密度) + [互补掩码/自身互补](创新：互补掩码不再作为印章覆盖使用，而是作为排序键和输出内容) + [裁剪](已有原语)

**来源原语**：紧凑排列/空间位置排序/按输入位置排列(1990f7a8)，裁剪(1990f7a8)，互补掩码/自身互补/印章覆盖(0692e18c)，前景像素(0692e18c)

**依赖链**：必须裁剪精灵体才能计算互补掩码（裁剪 → 互补） → 互补掩码的前景像素数决定排列顺序（互补 → 排序） → 排列顺序决定输出布局中每个互补掩码的位置（排序 → 放置）。排序依据来自互补计算的结果，而非输入的原始属性，形成计算依赖。

裁剪散布的精灵体，计算每个精灵体的互补掩码，按互补掩码的像素密度排序后打包到紧凑画布中。

**输入结构**：约 15x15 的黑(0)背景网格。包含恰好 4 个散布的红(2) 4-连通精灵体，每个精灵体的边界框为 3x3，各精灵体形状互不相同，每个占据其 3x3 边界框中 3-6 个像素（确保互补掩码也有 3-6 个像素，即非平凡）。4 个精灵体的像素数互不相同（保证互补像素数也互不相同，排序无歧义）。精灵体之间互不相邻（边界框之间至少间隔 1 像素）。两个精灵体位于网格上半部分，两个位于下半部分。

**规则**：
1. 找到 4 个红(2)的 4-连通分量，将每个裁剪为其 3x3 边界框。
2. 对每个裁剪后的 3x3 图案，计算互补掩码：将红(2)像素变为黑(0)，将黑(0)像素变为蓝(1)。得到 4 个 3x3 的蓝(1)/黑(0)互补图案。
3. 统计每个互补图案中蓝(1)像素的数量（即 9 减去原精灵体像素数）。
4. 将 4 个互补图案按蓝(1)像素数从少到多排序。像素数相同时（生成时已排除），按原精灵体在输入中的位置从上到下、从左到右排序。
5. 构造 7x7 的黑(0)输出画布，分为 4 个 3x3 象限，由第 4 行（中间行）和第 4 列（中间列）的空白行/列隔开（行列编号从 1 开始）。
6. 将排序后的第 1 个互补图案放入左上象限（第 1-3 行、第 1-3 列），第 2 个放入右上象限（第 1-3 行、第 5-7 列），第 3 个放入左下象限（第 5-7 行、第 1-3 列），第 4 个放入右下象限（第 5-7 行、第 5-7 列）。

**关键洞察**：输出画布中的排列顺序并非来自精灵体的输入位置，而是来自它们互补掩码的像素密度——求解者必须先"反转"每个精灵体形状才能推断正确的放置顺序。

## 新题 9：选择器象限匹配精灵后按对角轴翻转输出

**组合逻辑**：[复制放置/颜色索引匹配/图例位置映射](已有原语) + [镜像/对角对称](创新：对角翻转作用于已组装的精灵画布而非原始输入) + [标记选精灵涂色](创新：选中的精灵在放置前先统一重涂为选择器块的主体色)

**来源原语**：复制放置/选择器块/颜色索引匹配/图例位置映射/象限(7d18a6fb)，镜像/对角对称/沿主对角线转置(9dfd6313)，标记选精灵涂色/重涂色(5117e062)

**依赖链**：选择器中的标记颜色确定外部精灵（颜色匹配） → 精灵放入对应象限后需先统一重涂色（涂色依赖于选择器主体色） → 组装后的画布整体沿主对角线转置（空间变换依赖于组装结果）。三步之间信息逐步变换：选择决定内容，重涂改变颜色，转置改变布局。

按选择器块的颜色标记匹配外部精灵并放入对应象限，将精灵重涂为选择器主体色，最后将整个组装画布沿主对角线转置。

**输入结构**：约 18x18 的黑(0)背景网格。包含一个 7x7 的选择器块，其主体色为灰(5)，内部在 4 个 3x3 象限的中心位置各有一个标记像素（颜色各不相同，从{蓝(1), 红(2), 绿(3), 黄(4)}中取用）。象限由选择器块的第 4 行和第 4 列（灰(5)）分隔。选择器块外部，对每种标记颜色恰好有一个同颜色的 8-连通精灵体，边界框为 3x3，精灵体由 3-7 个该颜色像素组成。精灵体之间和精灵体与选择器块之间互不相邻。

**规则**：
1. 识别选择器块（7x7 灰(5)区域）及其 4 个象限中心的标记颜色和位置。
2. 对每个标记颜色，在选择器块外部找到同颜色的 8-连通精灵体，裁剪为 3x3 边界框。
3. 将每个精灵体中的所有前景像素（原标记颜色）统一重涂为灰(5)（选择器块的主体色）。
4. 构造 7x7 的黑(0)画布，分为 4 个 3x3 象限，由空白的中间行和中间列分隔。将每个重涂后的精灵体放入其标记所在的对应象限（左上标记 → 左上象限，右上标记 → 右上象限，左下 → 左下，右下 → 右下）。
5. 将整个 7x7 画布沿主对角线转置：将第 r 行第 c 列的像素与第 c 行第 r 列的像素交换（r, c 从 0 开始计数）。
6. 输出转置后的 7x7 画布。

**关键洞察**：精灵体被统一重涂为灰色后失去了颜色区分，使得求解者无法通过最终输出的颜色反推匹配关系，必须理解选择器的象限映射机制和转置的组合效应——仅看单个示例时可能将转置误认为旋转或其他变换。
