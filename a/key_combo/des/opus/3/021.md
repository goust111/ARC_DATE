## 新题 1：色配反射印入框

**组合逻辑**：[镜像/mirror](反射轴由标记像素在框边的位置决定，而非固定轴) + [颜色匹配锚点/color_match_anchor](精灵体内的颜色与框上标记配对) + [印章覆盖/stamp](反射后的精灵体定位印入框内) + [重涂色/recolor](印入后颜色统一为框色，仅配对像素保留原色)

**来源原语**：镜像(6855a6e4)、颜色匹配锚点(581f7754)、印章覆盖(a9f96cdd)、重涂色(9aec4887)、空心矩形(9aec4887/6855a6e4)、标记像素(581f7754)

**依赖链**：颜色匹配将精灵体与特定框配对 → 标记像素在框边的位置决定反射轴朝向 → 镜像变换依赖该轴 → 印章定位依赖反射结果中配对像素落在标记邻位 → 重涂色依赖框的边框颜色。每一步的参数都由前一步或框结构决定，无法跳过。

将散落在框外的小精灵体通过颜色配对找到归属框，根据框边标记的位置确定反射轴，镜像后印入框内并统一为框色。

**输入结构**：黑(0)背景网格，约 18x18。网格中有 3 个不重叠的空心矩形框，每个框由不同颜色的单像素宽边框构成（如红(2)、蓝(1)、黄(4)），内部为黑(0)背景，框的内部尺寸约 4x4 至 6x6。每个框的某一条边（上/下/左/右之一）上恰好有一个标记像素，该标记像素颜色与框色不同且各框标记颜色互不相同（如绿(3)、橙(7)、灰(5)）。在框的外部区域散布 3 个小精灵体（4-连通、单色、3~6 像素的不规则形状），每个精灵体的颜色恰好与某个框上的标记像素颜色相同。不同示例中精灵体的具体形状不同。生成约束：精灵体与其配对框之间无其他框阻隔；精灵体反射后的形状完全落在框内部区域内；各框的标记像素分布在不同方位的边上。

**规则**：
1. 通过颜色匹配将每个精灵体与框上同色标记像素配对，确定其归属框。
2. 确定反射轴方向：标记像素位于框的上边或下边 → 反射轴为经过框中心的水平线；标记像素位于框的左边或右边 → 反射轴为经过框中心的垂直线。
3. 将精灵体相对于框中心进行镜像反射（沿步骤 2 确定的轴翻转精灵体的坐标）。
4. 平移反射后的精灵体，使其中与标记同色的像素（即精灵体本身的颜色像素之一，取距离标记最近的那个）落在标记像素沿框边法线方向的相邻内侧格子上。
5. 将印入框内的精灵体所有像素重涂为框的边框颜色，但精灵体中距标记最近的那个像素保留原色（即标记颜色）。
6. 框的边框像素、标记像素、以及未被印章覆盖的框内部背景像素均保持不变。框外区域的原精灵体被擦除（变为黑(0)）。

**关键洞察**：反射轴不是全局固定的，而是由每个框上标记像素所在边的方位局部决定的——求解者必须对比多个示例中标记出现在不同边时反射方向的变化，才能归纳出"标记在上下边→水平轴，标记在左右边→垂直轴"这条隐蔽规则。

## 新题 2：逻辑或非生成螺旋障碍

**组合逻辑**：[逻辑运算/logical_op · NOR](两半区掩模的逐像素或非) → [螺旋绘制/spiral_draw](NOR 结果作为障碍场) + [遇障碍停止/stop_at_blocker](螺旋遇 NOR 障碍终止)

**来源原语**：逻辑运算(1b2d62fb)、逐像素对应(1b2d62fb)、分隔条(1b2d62fb)、螺旋绘制(e5c44e8f)、种子像素(e5c44e8f)、障碍像素(e5c44e8f)、遇障碍停止(e5c44e8f)

**依赖链**：左半区掩模 + 右半区掩模 → NOR 运算生成障碍像素的空间布局 → 螺旋从种子出发，障碍布局决定螺旋能延伸多远、形成何种断裂形态。NOR 是障碍的唯一来源，删除则螺旋无阻碍地铺满；删除螺旋则 NOR 结果无用途。

两个掩模的逻辑或非运算生成障碍场，在右半区从种子像素绘制螺旋，遇障碍即停。

**输入结构**：黑(0)背景网格，约 11x23（高 11、宽 23）。一条竖直蓝(1)分隔条将网格分为等宽的左右两个 11x11 半区。左半区：若干红(2)像素散布在黑背景上，构成一个稀疏的不规则图案（约 8~15 个红像素）。右半区：若干红(2)像素散布在黑背景上（数量和位置与左半区不同），加上恰好一个绿(3)种子像素。左右半区的红像素位置独立，不对称。生成约束：NOR 运算后产生的障碍像素（橙(7)）不覆盖绿种子像素位置；NOR 障碍至少有 5 个，以保证螺旋被有效截断；螺旋至少能画出 2 条完整的边（步长 2 的前两条腿）再遇到障碍。

**规则**：
1. 以蓝(1)分隔条为界，将左右半区视为两个等大的二值掩模（红(2) = 活跃，黑(0) = 非活跃）。
2. 对左右掩模做逐像素 NOR 运算：仅当左右对应位置均为非活跃（均为黑(0)）时，该位置标记为橙(7)障碍像素；否则保持黑(0)。
3. 输出仅保留右半区（删除左半区和蓝分隔条），输出尺寸为 11x11。
4. 在右半区中，保留原有的红(2)像素和绿(3)种子像素，并放置步骤 2 生成的橙(7)障碍像素。
5. 从绿(3)种子像素出发，按方向序列"上→右→下→左"绘制螺旋，腿长依次为 2, 2, 4, 4, 6, 6, ...。逐格推进：若下一个格子在网格内且为黑(0)背景，则涂为绿(3)；若下一个格子是橙(7)障碍或红(2)像素，则停止绘制（不涂该格）；若下一个格子超出网格边界，则跳过该步但仍计入腿长计数。
6. 最终输出保留所有红(2)、橙(7)、绿(3)像素，其余为黑(0)。

**关键洞察**：障碍不是直接给出的，而是由两个掩模的 NOR 涌现而来——"两边都空"的位置反而成为阻碍。求解者需要先识别出 NOR 运算规则，再理解螺旋的遇障停止机制，两步推理缺一不可。

## 新题 3：虚线补全成墙后扫描线填充

**组合逻辑**：[填充/fill · 间隙补全](将虚线段的单像素间隙补全为连续墙壁) + [填充/fill · 扫描线](补全后的墙壁界定扫描线区间并填色) + [标记列为参考/marker_col_ref](标记像素的列坐标作为扫描线的参考轴)

**来源原语**：填充(a699fb00)、单像素间隙补填(a699fb00)、虚线段(a699fb00)、邻接(a699fb00)、填充(78e78cff)、墙壁像素(78e78cff)、扫描线区间(78e78cff)、墙壁界定范围(78e78cff)、单点标记(78e78cff)、标记列为参考(78e78cff)

**依赖链**：虚线段的间隙补全 → 连续墙壁形成 → 墙壁相对于标记列界定左右扫描线范围 → 范围内背景填色。若不补全间隙，虚线不构成有效墙壁，扫描线区间无法正确界定；若无扫描线填充，补全后的虚线只是变成了实线，无进一步变换。

将水平虚线段的单像素间隙补全为连续墙壁，然后以标记像素的列为参考轴，在每行墙壁之间的扫描线区间内填充标记色。

**输入结构**：黑(0)背景网格，约 13x13。网格中有若干行（3~5 行）水平虚线段，由蓝(1)像素构成，每段蓝像素之间间隔恰好 1 个黑像素（即蓝、黑交替排列），虚线段不一定占满整行，可能只覆盖行的一部分。不同行的虚线段起止列位置不同、长度不同。网格中恰好有一个红(2)标记像素，位于不含虚线段的行上。虚线段所在的行分布在标记像素行的上方和下方。生成约束：每行虚线段补全后至少有 2 个连续蓝像素块（即至少 1 个间隙会被补全）；标记像素的列坐标落在至少部分虚线段补全后的左右墙壁之间；虚线段不与标记像素同行。

**规则**：
1. 找到所有蓝(1)虚线段。对每个黑(0)像素，若其左邻和右邻均为蓝(1)，则将该黑像素涂为蓝(1)（间隙补全）。补全后，原虚线段变为连续的蓝墙壁段。
2. 找到红(2)标记像素，记其列坐标为 c。
3. 对每一行含有蓝墙壁的行：找到列 c 左侧最近的蓝墙壁像素（严格小于 c 的最大蓝像素列）和列 c 右侧最近的蓝墙壁像素（大于等于 c 的最小蓝像素列）。将这两个墙壁之间（不含墙壁本身）的所有黑(0)背景像素涂为红(2)。若该行在列 c 左侧无蓝墙壁，则从该行最左蓝墙壁的右侧一直涂到列 c 右侧最近蓝墙壁的左侧；若该行在列 c 右侧无蓝墙壁，则从列 c 左侧最近蓝墙壁的右侧涂到网格右边界。
4. 对不含蓝墙壁的行（含标记行和虚线段区间外的空行）：若该行在最上墙壁行和最下墙壁行之间，则整行涂为红(2)（不覆盖标记像素本身）。若在墙壁行范围之外，则复用最近端墙壁行的扫描线区间。
5. 保留所有蓝(1)墙壁像素（含补全的）和红(2)标记像素，不被覆盖。

**关键洞察**：虚线段本身不是最终的视觉元素，而是墙壁的"编码形式"——间隙补全是理解题目的前置步骤，补全后才能应用扫描线区间规则。求解者必须先发现间隙补全规则，再发现扫描线填充规则，两步之间有因果依赖。

## 新题 4：空白行列化身对角射线反射镜

**组合逻辑**：[重涂色/recolor · 空白行列检测](全空行列从输入图案中隐式浮现) + [射线延伸/ray_extend · 对角](从种子发出对角线射线) + [边界反射/boundary_reflection](射线遇空白行列反射) + [遇障碍停止/stop_at_blocker](射线遇前景像素停止)

**来源原语**：全空行列(c1d99e64)、空行列涂标记色(c1d99e64)、重涂色(c1d99e64)、对角射线种子(7e2bad24)、射线延伸(7e2bad24)、边界反射(7e2bad24)、特定色反射射线(7e2bad24)、前景像素(c92b942c)、遇障碍停止(e5c44e8f)

**依赖链**：前景图案的布局决定哪些行列完全空白 → 空白行列构成反射镜面 → 射线从种子出发沿对角线前进，遇空白行反射垂直分量、遇空白列反射水平分量 → 射线遇前景像素停止。反射镜不是显式标注的，而是从输入图案的"负空间"中涌现。

前景图案的完全空白行列隐式充当反射镜面，对角线射线在这些隐式镜面间反射前进，遇前景像素终止。

**输入结构**：黑(0)背景网格，约 12x12。网格中有一种前景颜色（如灰(5)）构成稀疏的像素图案（约 10~20 个像素），图案的分布使得恰好有 2~3 行和 2~3 列完全不含灰(5)像素（即全黑行/列）。网格中恰好有一个绿(3)种子像素，位于非空白行、非空白列上。种子像素与最近的前景像素之间至少间隔 2 个格子。生成约束：种子像素沿初始对角方向（右下）前进时，在遇到前景像素之前至少经历一次空白行或空白列的反射；射线路径最终会遇到一个前景像素或网格边界而停止。

**规则**：
1. 检测所有完全空白的行（该行所有像素均为黑(0)，不含灰(5)也不含绿(3)）和完全空白的列（同理）。
2. 将所有空白行和空白列上的像素涂为红(2)——这些成为可见的反射镜标记线。射线路径与红(2)线交叉处，红(2)保留（射线不覆盖镜面）。
3. 从绿(3)种子像素出发，初始方向为右下（行+1、列+1）。逐格推进：
   - 若下一格在网格内且为黑(0)背景：涂为绿(3)，继续。
   - 若下一格为红(2)（空白行/列标记线）：不涂该格，执行反射——若该格所在行是空白行，翻转行方向分量（如 +1 变 -1）；若所在列是空白列，翻转列方向分量。若该格同时是空白行和空白列的交叉点，则两个分量都翻转（等效于 180 度反弹）。反射后从当前位置（反射前的位置）沿新方向继续。
   - 若下一格为灰(5)前景像素：停止（不涂该格）。
   - 若下一格超出网格边界：停止。
4. 保留所有灰(5)前景像素、红(2)镜面标记线、绿(3)种子和射线路径。

**关键洞察**：反射镜面不是显式给出的特定颜色对象，而是前景图案"未覆盖"的行列——求解者必须先从前景像素的分布中推断哪些行列完全空白，再理解这些空白行列的反射功能。反射镜从负空间涌现，这是与参考题中显式红色镜面段的根本区别。

## 新题 5：行列乘积提取后镜像嵌入匹配框

**组合逻辑**：[提取/extract · 行列乘积](找到行列乘积完整的双色图像并裁出) + [镜像/mirror](将提取的图像水平镜像) + [尺寸匹配/size_matching](提取图像的尺寸与框内部尺寸配对) + [重涂色/recolor](嵌入时一种颜色映射为框色)

**来源原语**：提取(b71a7747)、行列乘积完整(b71a7747)、双色图像(b71a7747)、裁剪(b71a7747)、镜像(6855a6e4)、空心矩形(9aec4887/890034e9)、尺寸匹配(890034e9/f21745ec)、重涂色(9aec4887)

**依赖链**：行列乘积法则确定哪对颜色构成隐藏图像 → 提取图像确定其尺寸 → 尺寸匹配找到唯一对应的框 → 镜像方向由框的标记像素位置决定（左侧标记→水平镜像，上侧标记→垂直镜像） → 嵌入时重涂色将图像的其中一种颜色替换为框色。提取结果同时决定了"嵌入什么"和"嵌入哪里"。

从混杂网格中提取隐藏的双色图像，镜像后嵌入尺寸匹配的空心矩形框内，图像颜色部分映射为框色。

**输入结构**：黑(0)背景网格，约 18x18。网格中包含三类元素：(a) 两种颜色（如橙(7)和青(8)）的像素混合散布在网格各处，这两种颜色的像素恰好占据了某些行与某些列的完整笛卡尔积区域（即选出这些行和列后，每个交叉格子都是橙或青之一）；(b) 其他颜色的"干扰"像素（如灰(5)），分布在乘积区域之外；(c) 2~3 个不同颜色（如红(2)、蓝(1)、黄(4)）的空心矩形框，内部为黑(0)，框边宽 1 像素，它们的内部尺寸各不相同，其中恰好一个框的内部尺寸等于提取出的双色图像的尺寸。每个框的某一条边上有一个绿(3)标记像素。生成约束：只有一对颜色满足行列乘积完整条件；满足条件的框恰好一个；框之间互不重叠且不与乘积区域重叠。

**规则**：
1. 找到唯一的颜色对，使得这两种颜色的像素恰好覆盖了它们所在行与所在列的笛卡尔积中的每一个格子。提取出该子网格作为双色图像（仅保留这些行和列，按原相对顺序排列）。
2. 找到内部尺寸（宽和高）与提取图像完全相同的那个空心矩形框。
3. 检查该框上绿(3)标记像素的位置：若标记在框的左边或右边 → 将提取图像做水平镜像（左右翻转）；若标记在框的上边或下边 → 将提取图像做垂直镜像（上下翻转）。
4. 将镜像后的图像放入框的内部：图像中属于颜色对里出现像素数较多的那种颜色 → 替换为框的边框颜色；另一种颜色保持不变。
5. 输出中仅保留该目标框（含边框和填入的图像），其余所有内容（其他框、散布像素、干扰像素）均清除为黑(0)。输出网格尺寸与输入相同。

**关键洞察**：隐藏图像的识别标准不是颜色本身，而是行列乘积的完备性——这是唯一能从多种混杂颜色中锁定目标对的结构性判据。镜像方向由框上标记决定，需对比标记出现在不同边的示例才能归纳。

## 新题 6：多标记对划分网格并填充封闭区域

**组合逻辑**：[连线/draw_line](每对同色标记引出全幅行列分割线) + [擦除/erase](分割线画完后标记像素本身被擦除) + [填充/fill · 封闭区域](所有分割线共同围成的封闭矩形区域内填色) + [冲突优先级/conflict_priority](多对分割线交叉时，围成较小面积的那对颜色优先)

**来源原语**：连线(21f83797)、标记像素(21f83797)、行列分割线(21f83797)、对角标记定矩形(21f83797)、擦除(d5d6de2d)、填充(d5d6de2d)、封闭区域(d5d6de2d)、空心内部变色(d5d6de2d)、冲突优先级(c92b942c)

**依赖链**：多对标记 → 各对独立画出行列分割线 → 不同对的分割线在网格上交叉，涌现出被分割线完全围住的矩形子区域 → 对每个封闭区域判断应填何色（由围住它的分割线所属标记对决定）→ 当多个标记对都围住同一区域时，按标记对所界定的矩形面积大小选择优先色。单对标记的行为是参考题 21f83797 的规则，但多对标记的交叉产生了参考题中不存在的涌现结构。

多对同色标记分别引出全幅行列分割线，所有分割线共同切割网格，仅在被完全封闭的矩形区域内填色，颜色取围成面积最小的标记对的颜色。

**输入结构**：黑(0)背景网格，约 14x14。网格中有 2~3 对标记像素，每对由 2 个同色像素组成，不同对颜色不同（如红(2)对、蓝(1)对、黄(4)对）。每对中的两个标记像素位于不同行且不同列。不同对的标记行/列可能重合也可能不重合。生成约束：至少存在一个由多对分割线共同围成的封闭矩形区域（即该区域的四条边来自不同的标记对）；没有三个以上的标记共线。

**规则**：
1. 对每一对同色标记（颜色 C，标记坐标 (r1,c1) 和 (r2,c2)）：在行 r1、行 r2 上画全幅水平线（整行涂为 C），在列 c1、列 c2 上画全幅竖直线（整列涂为 C）。
2. 擦除所有标记像素本身（将标记原位恢复为黑(0)）——分割线在标记所在格仍保留颜色，但标记的"标识"功能已完成。注意：由于分割线经过标记位置，标记位置实际仍有颜色（来自分割线本身），此步仅概念性表示标记不再特殊。
3. 在网格中找出所有被分割线完全围住的矩形区域——即上、下、左、右四个方向的边界均恰好是某条分割线。仅考虑严格内部（不含边界线本身）面积大于 0 的区域。
4. 对每个封闭矩形区域：确定围住它的分割线分别属于哪些标记对。对于每个包含该区域的标记对（即该对的两行两列形成的矩形包含该区域），计算该标记对定义的矩形面积（|r2-r1-1| x |c2-c1-1|）。将该封闭区域内的黑(0)像素填为面积最小的那个标记对的颜色。
5. 分割线上的像素保留其颜色。当两条不同颜色的分割线交叉于同一像素时，面积较小的标记对的颜色优先显示。

**关键洞察**：单对标记的行为与参考题相同，但多对标记同时存在时，分割线的交叉涌现出新的封闭区域——这些区域不属于任何单一标记对，而是多对的"公共领地"。按面积优先级决定填色的规则需要对比不同示例中标记对配置不同时的输出才能归纳。

## 新题 7：位移向量驱动的平铺与花纹叠印

**组合逻辑**：[位移向量/displacement_vec](从中心精灵体到部分副本的位移同时编码平铺周期和方向) + [平铺/tiling · 非均匀](沿位移向量方向重复精灵体，而非整个网格的均匀平铺) + [印章叠加/stamp_overlay](平铺副本与空心矩形框重叠时，框的内部花纹叠印到副本上) + [重涂色/recolor](每个平铺副本继承其引导副本的颜色)

**来源原语**：中心精灵体(045e512c)、部分副本(045e512c)、位移向量(045e512c)、副本指示方向与色(045e512c)、平铺(c92b942c)、空心矩形(f21745ec)、内部花纹(f21745ec)、印章叠加(f21745ec)、有花纹框为模板(f21745ec)、重涂色(f21745ec)

**依赖链**：部分副本的位置和颜色 → 位移向量确定平铺方向和步长 → 中心精灵体沿该方向重复平铺 → 每个平铺副本涂为引导副本的颜色 → 若某平铺副本的边界框与框的边界框重叠，则框的内部花纹以该副本的颜色叠印到重叠区域。位移决定平铺，平铺位置决定是否触发叠印，叠印颜色取决于副本颜色。

中心精灵体沿部分副本指示的方向重复平铺，每当平铺副本覆盖到空心框的区域时，框的内部花纹以副本的颜色叠印上去。

**输入结构**：黑(0)背景网格，约 20x20。网格中有一个中心精灵体（灰(5)，4-连通，约 4~8 像素，不规则形状）。网格中有 1~2 个部分副本，每个是中心精灵体的一个子集（形状匹配，占中心精灵体像素的一部分），各自有不同颜色（如红(2)、蓝(1)），位于中心精灵体的不同方向。网格中另有一个空心矩形框（如黄(4)边框，单像素宽），框内有若干黄(4)像素构成的花纹图案（花纹不填满内部，仅占部分内部格子）。框的位置与中心精灵体不重叠，但与某些平铺副本的预期位置重叠。生成约束：中心精灵体对齐到部分副本的位移量是唯一的（即整数平移使中心精灵体的像素子集与部分副本完全重合的平移向量仅一个）；沿位移方向重复平铺时，至少一个副本的边界框与框的边界框有非空交集；平铺副本之间不重叠。

**规则**：
1. 找到中心精灵体（灰(5)中最大的 4-连通分量）。
2. 对每个部分副本（非灰(5)、非框色的彩色小图形），找到使中心精灵体平移后覆盖该副本所有像素的唯一位移向量 (dr, dc)。
3. 从中心精灵体的位置开始，沿 (dr, dc) 方向每隔一个位移量放置一份中心精灵体的副本（即在位移 1x(dr,dc)、2x(dr,dc)、3x(dr,dc)... 处），直到副本完全离开网格。每个副本涂为对应部分副本的颜色。位移 1x 处的副本覆盖并替换原来的部分副本。
4. 对每个平铺副本：计算其边界框与空心矩形框边界框的交集区域。若交集非空，则在交集区域内，将框的内部花纹像素以该平铺副本的颜色绘制（仅绘制花纹像素对应位置落在交集内的那些）。花纹覆盖副本像素。
5. 保留框的边框像素（黄(4)）和原中心精灵体像素（灰(5)）。

**关键洞察**：位移向量在参考题中只驱动颜色射线的方向，在本题中它同时编码了平铺的步长和方向——每一步平铺产生一个新对象，该对象的空间位置决定了是否触发与框的交互。平铺与花纹叠印之间的耦合不是预设的，而是由几何位置涌现的。

## 新题 8：循环位移后最近边重涂色

**组合逻辑**：[循环位移/cyclic_roll](控制列编码的偏移量驱动内容滚动) + [最近边归属/nearest_side_assignment](滚动后像素与边框四边的距离关系改变) + [重涂色/recolor](按新的最近边归属重涂前景像素) + [空心矩形/rectangular_frame](框的四边各有独立颜色)

**来源原语**：循环位移(6d1d5c90)、控制列(6d1d5c90)、标记像素(6d1d5c90)、标记位定位移量(6d1d5c90)、行偏移编码(6d1d5c90)、最近边归属(9aec4887)、最近边决定涂色(9aec4887)、重涂色(9aec4887)、空心矩形(9aec4887)、前景掩码(9aec4887)

**依赖链**：控制列中标记位置 → 确定循环位移量 → 框内前景图案按该量向下滚动（环绕） → 滚动后每个前景像素到四边的距离改变 → 按新的最近边归属重涂颜色。重涂色的结果完全取决于滚动后的布局，而滚动量来自外部控制列，求解者必须先破解位移编码、再破解最近边规则。

读取控制列中标记的行位置作为滚动偏移量，将框内前景图案循环下移后，按每个前景像素到框四边的最近距离重涂为该边颜色。

**输入结构**：黑(0)背景网格，约 10x12（高 10、宽 12）。最左一列为控制列，全部为品红(6)，其中恰好一个像素为红(2)标记，其余为品红(6)。控制列右侧为主区域（10x11），主区域中央有一个空心矩形框，框的四条边各用不同颜色：上边绿(3)、下边蓝(1)、左边黄(4)、右边橙(7)，四角留为黑(0)背景。框的内部尺寸为 n x n（约 5x5 至 7x7）。框内有若干灰(5)前景像素构成不规则图案（4-连通，约 6~12 像素），其余内部为黑(0)。生成约束：红(2)标记的行索引 r 满足 1 <= r <= n-1，保证滚动量有意义；灰(5)图案不对称，以使滚动后最近边归属发生可见变化；不同示例中灰(5)图案形状不同。

**规则**：
1. 读取控制列中红(2)标记像素的行索引 r（从 0 开始计数）。删除控制列，输出宽度减 1。
2. 将框内部的内容（灰(5)像素和黑(0)背景）作为一个 n x n 子网格，循环向下滚动 r 行（最底部的 r 行移到最顶部）。框边框不动。
3. 滚动完成后，对每个灰(5)前景像素，计算它到框内部区域四边的距离（到上边 = 像素行 - 内部顶行，到下边 = 内部底行 - 像素行，到左边 = 像素列 - 内部左列，到右边 = 内部右列 - 像素列）。
4. 若最近的边唯一（四个距离中最小值唯一出现），则将该像素重涂为对应边的颜色（上→绿(3)，下→蓝(1)，左→黄(4)，右→橙(7)）。若最近边不唯一（存在并列最小距离），则该像素保留灰(5)不变。
5. 输出保留框边框、重涂后的前景像素、以及框内的黑(0)背景。框外区域保持黑(0)。

**关键洞察**：循环位移改变了每个前景像素在框内的相对位置，从而改变其最近边归属和最终颜色——同一个灰像素在不同滚动量下会被涂成不同颜色。求解者必须先发现控制列编码了滚动量（对比不同示例中标记行与像素移动的关系），再理解最近边涂色规则，两条规则的推理相互独立但结果紧密耦合。

## 新题 9：间隙补全计数驱动行排列

**组合逻辑**：[填充/fill · 间隙补全](虚线段单像素间隙补红) + [排序/sorting · 行排列](按每行补全的红像素数量升序排列行) + [裁剪/crop](去除全黑行)

**来源原语**：填充(a699fb00)、单像素间隙补填(a699fb00)、虚线段(a699fb00)、邻接(a699fb00)、排序(85b81ff1)、按计数升序排列(85b81ff1)、列内计数(85b81ff1 → 行内计数，创新改造)、裁剪(b71a7747)

**依赖链**：间隙补全产生红(2)像素 → 红像素计数成为排序依据 → 行按红像素数量升序重排 → 裁剪去除空行。排序的依据不是输入中已有的属性，而是补全操作"创造"出来的属性——删除补全步骤则无红像素可计数，排序失去依据；删除排序则补全只是视觉变化，不改变行顺序。

将水平虚线段的单像素间隙补红后，按每行补出的红像素数量升序重新排列所有非空行。

**输入结构**：黑(0)背景网格，约 10x15（高 10、宽 15）。网格中有 4~6 行包含水平蓝(1)虚线段（蓝像素之间间隔恰好 1 个黑像素交替排列），每行的虚线段长度、起始列位置和间隙数量各不相同。其余行为全黑空行。不同行虚线段的间隙数量互不相同（以保证排序无歧义）。生成约束：每行虚线段至少有 1 个间隙（即至少 3 个蓝像素：蓝-黑-蓝）；不同行的间隙数量两两不同；虚线段不跨越多行（每行独立）。

**规则**：
1. 对每行中的每个黑(0)像素：若其左邻和右邻均为蓝(1)，则将该像素涂为红(2)（间隙补全）。
2. 统计每行被补全的红(2)像素数量（即该行的间隙数）。全黑行的计数为 0。
3. 将所有非全黑行（含至少一个蓝或红像素的行）按红像素计数升序排列。行内内容保持不变（蓝像素和红像素的位置关系不动），仅改变行之间的上下顺序。
4. 排列完成后，去除底部的全黑行（裁剪），输出高度等于非空行数，宽度不变。

**关键洞察**：排序的关键指标（红像素数）在输入中不可见——它是间隙补全操作的产物。求解者必须先观察到间隙补全规则（红色从何而来），然后从多个示例中发现行的排列与红色像素数量的关系，两步推理有严格的因果链。
