## 新题 1：障碍禁区重塑洪泛区域驱动面积分色

**组合逻辑**：[邻域禁区](创新：从寻路阻断扩展为洪泛拓扑重塑) + [洪泛填充](创新：用于划分封闭区域而非涂色通道) + [面积分类→重涂色](已有原语，但分类对象从连通分量变为洪泛区域)

**来源原语**：邻域禁区(cc9053aa) + 洪泛填充(a64e4611/7491f3cf) + 面积分类(d2abd087) + 重涂色(d2abd087)

**依赖链**：障碍物的 8-邻域禁区改变了墙壁之间的连通性，导致洪泛填充产生不同数量和面积的封闭区域；封闭区域的面积反过来决定了区域内精灵体的重涂色方案。去掉禁区扩展，区域拓扑不同，面积阈值判断结果改变；去掉洪泛填充，无法得到区域面积；去掉面积分类，无法确定颜色。

根据障碍物的禁区扩展重塑网格的连通区域，再按封闭区域面积对区域内的精灵体分色。

**输入结构**：约 15x15 的黑(0)背景网格。灰(5)像素构成不规则的墙壁线段（4-连通，总长 20~40 像素），将网格分割为若干不完全封闭的区域。橙(7)像素（2~4 个）散布在墙壁附近的空隙处。每个被墙壁大致围合的区域内部放置一个由青(8)像素构成的小型 4-连通图形（3~6 像素）。生成约束：去除橙像素后，所有区域都与网格边界连通（即无封闭区域）；加入橙像素的 8-邻域禁区后，恰好产生若干个与边界不连通的封闭区域，每个封闭区域恰好包含一个青色图形。

**规则**：
1. 将每个橙(7)像素及其 8-邻域内的所有非墙壁、非橙像素标记为禁区（不可通行）。
2. 从网格的四条边界出发，通过非墙壁、非禁区、非橙的黑色像素进行 4-连通洪泛填充，到达的区域标记为"外部"。
3. 未被标记为"外部"且不是墙壁/禁区/橙的黑色像素区域，构成若干"封闭区域"。统计每个封闭区域的黑色像素数（不含其中的青色图形像素）。
4. 封闭区域面积（黑色像素数）大于等于 10 的，将其中的青色图形重涂为红(2)；面积小于 10 的，将其中的青色图形重涂为蓝(1)。
5. 墙壁、橙像素、禁区内像素、外部区域的像素均保持不变。

**关键洞察**：橙色障碍物本身只占少数像素，但其 8-邻域禁区扩展会封堵墙壁间的空隙，从而将原本连通的空间切割成不同面积的封闭区域——必须先理解禁区如何改变拓扑，才能推断出正确的面积分色。

## 新题 2：压缩色带生成转向指令驱动射线路径

**组合逻辑**：[压缩](创新：输出不是视觉摘要而是控制指令序列) + [射线延伸+转向](创新：转向指令来自外部编码区域而非路径上的控制点)

**来源原语**：压缩(746b3537) + 条带方向(746b3537) + 射线延伸(e5790162) + 转向(e5790162) + 颜色决定转向(e5790162)

**依赖链**：色带压缩产生有序颜色序列，该序列作为射线在每次遇到障碍物时的转向指令表。若不压缩，指令序列未知，射线路径无法确定；若无射线追踪，颜色序列无处施加。两个操作通过"颜色序列即指令"这一桥梁紧耦合。

将一侧的色带压缩为颜色序列，作为另一侧射线遇阻时的转向指令，驱动射线绘制路径。

**输入结构**：约 14x14 的网格，由一条单像素宽的灰(5)竖线分为左右两个区域。左区域包含若干全高（贯穿左区域所有行）的彩色竖条纹，每条宽度 1~3 像素不等，颜色为红(2)、蓝(1)或黄(4)。右区域为黑(0)背景，包含一个绿(3)起点像素（位于右区域的某条边上）和若干栗(9)障碍像素（散布在右区域内部，互不相邻）。生成约束：左区域压缩后产生的颜色序列长度等于右区域中射线从起点出发按规则行进时遇到障碍物的次数；射线最终在序列耗尽后恰好从网格边界离开。

**规则**：
1. 对左区域的竖条纹按从左到右顺序进行压缩：将连续相同颜色的条纹折叠为一个条目，得到一个有序颜色列表 S。
2. 在右区域，从绿(3)起点像素出发，沿起点所在边的法线方向（朝向右区域内部）发射一条射线。沿途将黑色背景像素涂为绿(3)。
3. 当射线的下一步将进入栗(9)障碍像素时，消耗 S 中的下一个颜色：红(2)表示右转 90 度，蓝(1)表示左转 90 度，黄(4)表示掉头（转 180 度）。转向后继续前进，不覆盖障碍像素。
4. 当 S 耗尽后，射线继续沿当前方向直行，直到离开网格边界为止，沿途继续涂绿(3)。
5. 灰色分隔线、左区域条纹、栗色障碍像素均保持不变。

**关键洞察**：左区域的条纹看似只是颜色装饰，实则其压缩后的有序颜色序列编码了右区域射线的完整转向程序——必须正确压缩（消除宽度冗余）才能读出正确的指令序列。

## 新题 3：连通分量计数选定模板印章覆盖至标记位置

**组合逻辑**：[计数+完整方块过滤](创新：计数结果不编码在对角线上而是用作模板选择索引) + [查表映射](创新：映射目标从固定输出变为可参数化的印章形状) + [印章覆盖+标记锚定](已有原语，但印章内容由前序计数动态决定) + [透明叠加](创新：多印章重叠区域产生新颜色)

**来源原语**：计数(3b4c2228) + 完整方块过滤(3b4c2228) + 忽略干扰项(3b4c2228) + 查表映射(9110e3c5) + 印章覆盖(e6721834) + 标记锚定精灵(e6721834) + 透明叠加(d19f7514)

**依赖链**：完整方块过滤+计数→查表映射选定模板→模板在标记位置印章覆盖→重叠区域透明叠加产生新颜色。去掉计数，不知道选哪个模板；去掉查表，计数无法转化为形状；去掉印章覆盖，模板无法放置；去掉叠加规则，重叠区域颜色不确定。

统计合格方块数量选定模板形状，将该模板印在每个标记位置上，重叠处变色。

**输入结构**：约 18x18 的黑(0)背景网格，由一条单像素宽的灰(5)横线分为上下两个面板。上面板包含若干散布的前景对象：绿(3)像素构成的对象（有些是完整 2x2 实心方块，有些是单像素或不规则的 3~5 像素小图形）以及红(2)像素构成的干扰对象（形状不限）。下面板为黑(0)背景，散布着 2~4 个品红(6)标记像素，各标记之间的曼哈顿距离至少为 5。生成约束：上面板中完整的绿色 2x2 方块数量为 1、2 或 3；下面板中标记像素之间间距足够，使得放置 3x3 模板时至少有一对模板的覆盖范围存在重叠。

**规则**：
1. 在上面板中，找到所有绿(3)的 4-连通分量，保留边界框恰好 2x2 且面积恰好为 4 的完整方块，忽略所有红色对象和不完整的绿色对象。统计完整绿色方块数量 N。
2. 根据 N 查表选择模板（均为 3x3）：N=1 → "十"字形（中心行+中心列共 5 像素），N=2 → "X"对角线形（两条对角线共 5 像素），N=3 → 实心 3x3 方块（9 像素）。
3. 将选定的模板以青(8)色、以每个品红(6)标记像素为中心，印章覆盖到下面板上。模板不覆盖品红标记本身（标记保留品红色）。超出网格边界的部分舍弃。
4. 若两个印章的覆盖范围有重叠，重叠像素涂为黄(4)而非青(8)。三重及以上重叠同样涂黄(4)。
5. 上面板保持不变，灰色分隔线保持不变。

**关键洞察**：上面板中混杂的绿色和红色对象是计数与干扰分离的考验，而计数结果不直接显示为数字，而是决定了下面板中印章的几何形状——必须同时理解过滤计数和形状查表才能确定输出。

## 新题 4：跨面板连线依据所属面板决定重涂色

**组合逻辑**：[连线+两点直线路径](已有原语) + [所属面板](创新：从面板内属性判断扩展为线段穿越时的上下文切换) + [对侧面板色](创新：不作用于缺陷条而是作用于被线段穿过的对象) + [按原色区分涂色](创新：区分依据从蓝/黑变为面板归属)

**来源原语**：连线(bcb3040b) + 两点直线路径(bcb3040b) + 按原色区分涂色(bcb3040b) + 所属面板(9b5080bb) + 对侧面板色(9b5080bb)

**依赖链**：两个标记点确定一条直线段，线段穿越两个面板，面板归属决定了被穿过对象的重涂色方案（取对侧面板的底色）。去掉连线，不知道哪些像素受影响；去掉面板归属判断，不知道用哪种颜色重涂；去掉对侧面板色规则，颜色映射不确定。

在双面板之间画一条直线段，被线段穿过的灰色对象依据其所在面板被涂为对面面板的底色。

**输入结构**：约 15x11 的网格，由一列单像素宽的黑(0)竖线在水平中央将网格分为左右两个面板。左面板底色为蓝(1)，右面板底色为红(2)。每个面板内散布着 2~4 个灰(5)的小型 4-连通对象（3~7 像素），对象不触碰面板边界和分隔线。恰好有两个栗(9)标记像素，一个在左面板、一个在右面板，且两者处于同一水平行、同一垂直列、或同一 45 度对角线上。生成约束：两个标记之间的直线段至少穿过每个面板中的一个灰色对象；线段不经过任何对象的边界框之外的灰色像素。

**规则**：
1. 在两个栗(9)标记像素之间画一条包含端点的直线段（水平、垂直或 45 度对角线方向）。
2. 线段经过的每个像素：
   - 若该像素是灰(5)且位于左面板（蓝底），将其重涂为红(2)（对侧面板底色）。
   - 若该像素是灰(5)且位于右面板（红底），将其重涂为蓝(1)（对侧面板底色）。
   - 若该像素是面板底色（蓝或红）或黑色分隔线，涂为栗(9)形成可见路径。
   - 若该像素是栗(9)标记像素，保持栗(9)不变。
3. 线段未经过的灰色对象保持灰(5)不变。
4. 所有其他像素保持不变。

**关键洞察**：线段穿过的灰色像素并非统一重涂为同一颜色，而是根据该像素所处面板取对侧面板的底色——同一条线段在两个面板中产生不同的颜色效果，需要同时理解几何路径和面板上下文。

## 新题 5：去重还原隐藏对角几何后填充平行四边形区域

**组合逻辑**：[去重/压缩](创新：作为几何还原的预处理而非最终输出) + [填充+段间区域填充](已有原语，但作用于去重后才显现的对角结构) + [平行配对](已有原语，但配对对象需在去重后才可识别)

**来源原语**：去重(e1baa8a4) + 合并相同行列(e1baa8a4) + 填充(7666fa5d) + 对角线段(7666fa5d) + 平行配对(7666fa5d) + 段间区域填充(7666fa5d)

**依赖链**：输入网格经过行列重复拉伸，导致对角线段变形为阶梯状像素带，无法直接识别其平行关系。去重还原后对角线段恢复为规则的反对角线像素序列，才能正确识别平行对并填充其间的平行四边形区域。去掉去重，几何结构不可识别；去掉填充，去重无意义（只是缩小了图）。

先折叠重复行列还原隐藏的对角线几何，再在还原后的网格中填充平行对角线段之间的区域。

**输入结构**：约 18x18 的网格，无背景色区分——所有像素非黑即有色。网格由一个较小的（约 8x8）基础网格经行列重复拉伸而成：基础网格的每一行被复制 1~3 次，每一列被复制 1~3 次。基础网格的黑(0)背景上有若干绿(3)像素构成的短对角线段（每段 2~4 像素，位于反对角线 r+c=常数 上），且这些线段成对出现，每对位于平行的反对角线上。拉伸后，对角线段变为不规则的矩形像素块。生成约束：基础网格中每对平行反对角线段之间在某些主对角线轴上存在纯背景像素可供填充；拉伸倍数在不同行/列可以不同。

**规则**：
1. 检测连续相同的行组和列组，将每组保留第一行/列，折叠为基础网格（即去重）。
2. 在基础网格中，识别所有绿(3)像素构成的反对角线段（同一段中所有像素的 r+c 值相同）。
3. 按主对角线轴（r-c 值）将各段分组，在每组内按反对角线索引（r+c 值）排序，相邻段形成配对。
4. 沿每条主对角线轴，将严格位于配对段之间的所有黑(0)背景像素填充为红(2)。
5. 输出为去重并填充后的基础网格。

**关键洞察**：输入网格的行列重复拉伸把清晰的对角线段伪装成了不规则的块状像素群——必须先通过去重还原基础网格的真实几何，对角平行关系和填充区域才变得可辨认。

## 新题 6：射线轨迹划定内外分区选择源面板合成

**组合逻辑**：[射线延伸+转向](创新：射线路径不只是轨迹而是构成封闭边界) + [内外分区](创新：分区边界由射线动态生成而非预置墙壁) + [掩码选择源面板](创新：掩码来自射线划分而非洪泛填充) + [透明叠加](已有原语，选择性逐像素合成)

**来源原语**：射线延伸(e5790162) + 转向(e5790162) + 颜色决定转向(e5790162) + 内外分区(7491f3cf) + 掩码选择源面板(7491f3cf) + 透明叠加(d19f7514) + 逐像素对齐(d19f7514)

**依赖链**：射线追踪生成的路径构成封闭边界→洪泛填充从网格角出发确定内外→内外掩码逐像素选择两个源面板的内容。去掉射线追踪，无边界可分区；去掉内外分区，不知道用哪个面板；去掉面板合成，分区结果无用。

射线在控制面板中追踪出一条封闭路径，路径内外分别取自两个纹理面板的对应像素，合成输出。

**输入结构**：约 8x24 的网格（或 24x8），由两条单像素宽的灰(5)竖线分为三个等大的 8x8 面板（面板 0、面板 1、面板 2，从左到右）。面板 0（控制面板）：黑(0)背景上有一个绿(3)起点像素（位于面板边缘），若干品红(6)和青(8)转向控制像素散布在面板内部。面板 1（源面板 A）：由红(2)和黑(0)构成的任意纹理图案。面板 2（源面板 B）：由蓝(1)和黑(0)构成的任意纹理图案。生成约束：面板 0 中射线从绿色起点出发，按转向规则行进后最终回到起点所在行或列的相邻像素，形成一条简单封闭曲线（不自交）；面板 0 的尺寸足以让射线路径围出一个面积至少为 4 的内部区域。

**规则**：
1. 在面板 0 中，从绿(3)起点出发，沿起点所在边的法线方向射出一条射线，沿途将背景像素标记为路径。
2. 遇到品红(6)控制点时右转 90 度，遇到青(8)控制点时左转 90 度，不覆盖控制点本身。
3. 当射线回到起点的 4-邻居时停止，形成封闭路径。
4. 从面板 0 的四个角出发进行 4-连通洪泛填充（不穿越路径像素和控制点），到达的区域为"外部"，未到达的非路径非控制点区域为"内部"。
5. 输出一个 8x8 网格：对于内部区域的每个像素位置，取面板 1 对应位置的颜色；对于外部区域的每个像素位置，取面板 2 对应位置的颜色；路径位置输出绿(3)。

**关键洞察**：控制面板中的品红和青像素并非装饰，而是通过控制射线转向间接决定了封闭路径的形状——路径形状又决定了两个纹理面板的像素被如何选择和拼合，三个面板的信息交织在一起才能确定输出。

## 新题 7：隐藏通道检测配合图例位置匹配分色填充

**组合逻辑**：[洪泛填充+背景通道检测](创新：检测到的通道不统一涂色而是分别按位置匹配着色) + [相对位置对应+最小距离匹配](创新：匹配对象从占位块变为负空间通道) + [图例矩形](创新：图例不驱动前景对象重涂色而是驱动负空间通道填色)

**来源原语**：洪泛填充(a64e4611) + 背景通道(a64e4611) + 长矩形通道涂色(a64e4611) + 图例矩形(1da012fc) + 控制标记点(1da012fc) + 相对位置对应(1da012fc) + 最小距离匹配(1da012fc)

**依赖链**：通道检测确定哪些负空间是"真通道"→通道中心的相对位置与图例标记的相对位置建立对应→匹配结果确定每条通道的填充颜色。去掉通道检测，不知道负空间在哪；去掉位置匹配，不知道哪条通道用哪种颜色；去掉图例，无色可选。

识别被杂色掩盖的隐藏通道，再根据图例中标记点的位置对应关系为每条通道分配不同的填充颜色。

**输入结构**：约 16x16 的网格，主背景色为黑(0)。橙(7)像素作为杂色前景散布在网格中（密度约 10%~20%），其中隐藏着 2~4 条长矩形通道（全黑的长条形区域，长轴至少为网格边长的一半，方向为水平或垂直）。网格的右下角（或任一角落）放置一个灰(5)实心矩形（约 4x4），其内部嵌入与通道数量相同的彩色标记像素，颜色各不相同，从红(2)、蓝(1)、绿(3)、黄(4)中选取。生成约束：每条通道的中心相对于网格边界框的归一化位置与恰好一个图例标记相对于图例边界框的归一化位置最近，且该最近匹配是唯一的（无平局）。通道之间互不相交。

**规则**：
1. 保留 3x3 邻域全为黑色的背景像素（一像素间隙清除），在此清洁掩码上枚举极大矩形，按面积降序接受长轴至少为网格边长一半的矩形作为"真通道"。
2. 计算每条真通道的中心坐标 (r_c, c_c)，归一化到网格边界框 [0,1]x[0,1]。
3. 计算灰色图例矩形内每个彩色标记像素的位置，归一化到图例边界框 [0,1]x[0,1]。
4. 用最小欧氏距离将每条通道匹配到唯一的图例标记。
5. 将每条通道内的黑色像素填充为其匹配标记的颜色。橙色杂色、图例矩形和标记像素保持不变。

**关键洞察**：图例看似只是角落里的一个灰色方块，实则其内部标记点的空间布局编码了每条隐藏通道应该被涂什么颜色——通道和标记通过归一化位置相互对应，而非通过计数顺序或颜色名称。

## 新题 8：瓦片对称性过滤后堆叠合成并按面积排序

**组合逻辑**：[对称检测](创新：不是选出唯一异类瓦片而是过滤出一组对称瓦片参与后续操作) + [堆叠+角对齐](创新：堆叠对象来自对称过滤而非直接给定) + [排序+按面积降序](创新：排序依据是瓦片前景面积而非矩形总面积) + [透明叠加](已有原语，黑色背景透明)

**来源原语**：对称检测(662c240a) + 选无对角对称瓦片(662c240a) + 堆叠排列(662c240a) + 堆叠(20818e16) + 角对齐(20818e16) + 按面积降序(20818e16) + 透明叠加(d19f7514)

**依赖链**：对称检测筛选出参与堆叠的瓦片子集→按前景面积排序确定堆叠层序→角对齐堆叠时背景透明形成叠加合成。去掉对称检测，所有瓦片都参与（结果错误）；去掉排序，堆叠遮挡顺序不确定；去掉透明叠加，底层瓦片被完全遮挡。

从瓦片网格中筛选出具有转置对称性的瓦片，按前景像素面积从大到小透明堆叠合成。

**输入结构**：约 12x16 的网格，由灰(5)分割线将其划分为 3 行 4 列共 12 个等大的方形瓦片（每个瓦片约 3x3 或 4x4）。每个瓦片内部是黑(0)背景上的单色图案，不同瓦片可用不同前景色（从红(2)、蓝(1)、绿(3)、黄(4)、青(8)中选取）。约一半的瓦片具有主对角线转置对称性（即像素矩阵等于其转置），另一半不具有。生成约束：具有对称性的瓦片至少有 3 个；这些对称瓦片的前景像素面积互不相同（不存在面积平局）；各瓦片的前景色可相同也可不同。

**规则**：
1. 沿灰(5)分割线切割网格，得到所有方形瓦片。
2. 对每个瓦片检测主对角线对称性：若瓦片内容（含背景）等于其沿主对角线的转置，则标记为"对称"。
3. 丢弃所有非对称瓦片。
4. 对保留的对称瓦片，统计每个瓦片中非黑前景像素的数量（面积）。
5. 按前景面积从大到小排序。输出一个瓦片大小的黑色网格。
6. 按排序顺序（面积最大者最先），将每个瓦片左上角对齐到输出网格左上角，逐层绘制。黑(0)像素视为透明（不覆盖下层），非黑像素覆盖下层。

**关键洞察**：不对称的瓦片是干扰项，对称性检测是入门门槛；但通过门槛后，前景面积排序决定了堆叠层序，而堆叠中的透明度规则使得面积最小的瓦片反而决定了最终可见的颜色——面积排序和透明覆盖的交互产生了非直觉的视觉结果。

## 新题 9：对称补全生成缺失精灵后像素放大对齐放置

**组合逻辑**：[对称补全+三存一缺推断](创新：补全的精灵不留在原位而是提取用于后续放大对齐) + [像素放大+对齐放置](创新：放大对象是补全推断出的新内容而非输入中已有的图形) + [着色约束对齐缩放](创新：约束来自目标区域中的提示像素而非角标记)

**来源原语**：对称补全(2546ccf6) + 镜像(2546ccf6) + 三存一缺推断(2546ccf6) + 块内对称(2546ccf6) + 像素放大(8a004b2b) + 对齐放置(8a004b2b) + 着色约束对齐缩放(8a004b2b) + 角标记(8a004b2b)

**依赖链**：三存一缺推断生成缺失精灵的内容→缺失精灵被像素放大到目标区域尺寸→放大结果依据目标区域内的提示像素对齐放置。去掉对称补全，不知道要放大什么图案；去掉放大对齐，补全出的小精灵无法匹配目标区域的尺寸；去掉着色约束，放大后的放置位置不唯一。

从三个已知精灵推断出缺失的第四个，再将其放大并依据提示像素对齐填入目标框架。

**输入结构**：约 18x18 的网格。上半部分由灰(5)分割线划分为 2x2 共 4 个等大的小格子（每个约 4x4）。其中 3 个格子各包含一个由同一前景色（如蓝(1)）绘制的小图形（3~6 像素，4-连通），第 4 个格子为空（全黑(0)）。这 3 个图形是同一图案在 2x2 块中心的镜像变体。下半部分包含一个由四个黄(4)角标记像素标定的矩形目标区域（约 8x8 或 12x12），该区域内部大部分为黑色，但散布着 2~3 个蓝(1)提示像素。生成约束：缺失格子通过三存一缺镜像推断可唯一确定；缺失精灵经某个整数倍放大后，恰好存在唯一一个放置位置使得所有提示像素被放大图案覆盖且颜色一致；放大倍数由目标区域尺寸与精灵边界框尺寸的比值确定（取整数倍）。

**规则**：
1. 在上半部分的 2x2 格子中，找到空格子的位置。
2. 根据空格子与三个已填格子的相对位置关系，分别对三个已有图形做水平和/或垂直镜像翻转（使其映射到空格子位置的视角），三个翻转结果应一致。取该一致的图案作为缺失精灵。
3. 在下半部分，用四个黄(4)角标记裁出目标区域。
4. 计算放大倍数：目标区域宽度 / 缺失精灵边界框宽度（取整数）。
5. 将缺失精灵按该倍数像素放大。
6. 在目标区域内尝试所有合法放置位置，找到唯一的位置使得放大图案的有色像素覆盖目标区域内所有蓝(1)提示像素。
7. 将放大后的精灵绘制到该位置。黄色角标记保留。上半部分保持不变。

**关键洞察**：上半部分的 2x2 镜像结构不是用来直接修复画面的——它编码了一个"密码"图案，需要先通过对称推断解码，再通过放大和提示对齐才能在下方的大画框中正确放置。

## 新题 10：双面板并集掩码驱动对角线段间选择性填充

**组合逻辑**：[透明叠加+并集取前景](创新：并集掩码不直接涂色而是作为后续填充操作的空间约束) + [填充+段间区域填充](创新：只填充掩码覆盖的子区域而非所有段间区域) + [对角线段+平行配对](已有原语)

**来源原语**：透明叠加(d19f7514) + 并集取前景(d19f7514) + 逐像素对齐(d19f7514) + 填充(7666fa5d) + 对角线段(7666fa5d) + 平行配对(7666fa5d) + 段间区域填充(7666fa5d)

**依赖链**：两个面板的并集掩码确定了"活跃区域"→对角线段在活跃区域内识别平行对→仅填充活跃区域内的段间像素。去掉并集掩码，无法区分活跃/非活跃区域，所有段间区域都会被填充（产生过多填充）；去掉段间填充，掩码无意义。

叠合两个面板的前景得到活跃区域掩码，仅在掩码范围内填充平行对角线段之间的空隙。

**输入结构**：约 10x20 的网格（偶数高度），沿水平中线分为上下两个等大的 10x10 面板。上面板：黑(0)背景上有绿(3)前景像素构成的不规则掩码区域（4-连通，约占面板面积的 30%~50%）。下面板：黑(0)背景上有灰(5)前景像素构成的不规则掩码区域（4-连通，约占面板面积的 30%~50%），同时有若干橙(7)像素构成的短反对角线段（每段 2~4 像素，位于 r+c=常数 上），这些线段成对出现在平行的反对角线上。生成约束：上下面板的前景掩码并集（对齐后）覆盖了部分段间区域但不覆盖所有段间区域；至少有一个段对的段间区域被并集掩码部分覆盖、部分未覆盖。

**规则**：
1. 将上面板和下面板逐像素对齐。对于每个坐标位置，若上面板该位置是绿(3)或下面板该位置是灰(5)或橙(7)（即任一面板为非黑前景），则标记该位置为"活跃"。
2. 在下面板中，识别橙(7)像素构成的反对角线段，按主对角线轴（r-c 值）分组并按反对角线索引（r+c 值）排序，相邻段形成配对。
3. 对每个段对，沿主对角线轴扫描严格位于两段之间的像素：仅当该像素位置被标记为"活跃"且在下面板中为黑(0)时，将其填充为红(2)。
4. 输出为下面板大小的网格：橙(7)线段保留，红(2)填充出现在活跃的段间区域，其余保持下面板原样。

**关键洞察**：上面板的绿色区域看似与下面板的对角线结构无关，但它通过并集掩码间接控制了哪些段间空隙会被填充——两个面板的空间信息必须叠合后才能确定最终的填充范围。
