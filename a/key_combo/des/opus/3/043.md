## 新题 1：障碍中继变色射线

**组合逻辑**：[射线延伸](从边缘标记出发向上发射) → [障碍像素作为中继站](创新：障碍不终止射线而是转发) → [颜色查找键](中继时查表变色后继续发射)

**来源原语**：射线延伸(ray_extend)←891232d6/c87289bb, 重涂色(recolor)←891232d6/d35bdbdc, 障碍像素(obstacle_pixel)←891232d6, 边缘标记(edge_marker)←891232d6, 颜色查找键(color_lookup_key)←d35bdbdc, 路径连通(path_connectivity)←d35bdbdc

**依赖链**：射线方向由边缘标记决定 → 射线遇到障碍时触发颜色查表 → 查表结果决定下一段射线的颜色 → 多次中继后颜色可能循环回已出现的颜色（但查表是确定性的，不存在歧义）。移除射线机制则无法确定路径位置；移除查表则无法确定中继后的颜色。

从底部边缘标记发射射线向上穿越网格，每遇一个障碍像素即查表变色后继续上行，直至无表可查或到达顶部。

**输入结构**：约 15x15 网格，黑(0)背景。底部边缘（最后一行）有 2~3 个彩色标记像素，颜色各不相同（例如红(2)、蓝(1)）。网格内部散布若干绿(3)障碍像素，每列至多 2 个，互不相邻。左上角有一个灰(5)边框包围的 2 列 N 行颜色键面板：左列是输入色，右列是对应的输出色（例如红(2)→黄(4)、蓝(1)→橙(7)、黄(4)→品红(6)、橙(7)→红(2)）；键面板行数 = 映射条目数，每条占一行。生成约束：每个底部标记的颜色以及可能经中继产生的后续颜色，至少有一条存在于键面板的左列中，保证至少发生一次中继；键面板不含重复的左列条目。

**规则**：
1. 保留输入网格中的所有像素（障碍、键面板、标记均不变）。
2. 从每个底部标记像素向上发射射线，初始颜色为标记自身颜色。射线逐行上行，将经过的每个黑(0)背景格涂为当前射线颜色。
3. 当射线到达一个绿(3)障碍像素所在行的正下方一格时，该格是当前段最后一个涂色格；射线段在障碍正下方停止。
4. 查阅键面板：以当前射线颜色为键，在面板左列查找；若找到，取对应右列颜色作为新射线颜色。新射线从障碍正上方一格开始，继续向上发射。障碍像素本身保持绿(3)不变。
5. 若当前射线颜色在面板左列中无对应条目，射线在该障碍处终止，不再继续上行。
6. 若射线未遇到任何障碍即到达顶部边缘（第 0 行），则涂色直到并包含第 0 行的格子。
7. 多条射线的路径互不交叉（生成约束保证各标记所在列上的障碍布局使路径不共享列）。

**关键洞察**：障碍像素不是死胡同，而是颜色转换的中继站；同一条射线在穿越多个障碍后可能经历多次变色，形成分段多色的竖直路径。求解者必须同时发现射线机制和查表机制才能确定输出。

## 新题 2：奇偶定镜像的对角射线

**组合逻辑**：[排列顺序](按位置排序定等级) → [奇偶定方向](等级奇偶决定是否镜像) → [镜像](翻转对角标记位置) → [射线延伸](从最终对角标记位置发射射线至网格边缘)

**来源原语**：射线延伸(ray_extend)←7ddcd7ec, 镜像(mirror)←5b692c0f, 排列顺序(ordering)←4364c1c4, 实心正方形(solid_square)←7ddcd7ec, 对角标记(diag_marker)←7ddcd7ec, 对角邻接(diag_adjacency)←7ddcd7ec, 奇偶定方向(parity_determines_dir)←4364c1c4, 锚角对角射线至边(anchor_diag_to_edge)←7ddcd7ec

**依赖链**：位置排序赋予每个方块一个等级 → 等级奇偶决定是否对对角标记做水平镜像 → 镜像改变标记相对于方块的位置 → 射线从（可能已镜像的）标记位置沿对角线延伸至网格边缘。移除排序则无法确定奇偶；移除镜像则偶数方块的射线方向错误；移除射线则无输出。

根据 2x2 方块的垂直排序等级，奇数等级直接延伸对角射线，偶数等级先水平翻转对角标记再延伸。

**输入结构**：约 14x14 网格，黑(0)背景。3~5 个蓝(1)的 2x2 实心方块分散在网格中，每个方块恰有一个蓝(1)像素位于其四个对角邻位之一（即方块某角外扩一格的对角位置）。各方块的上边界行互不相同，保证垂直排序无歧义。方块之间至少间隔 3 格，保证射线初始段不与其他方块重叠。

**规则**：
1. 按每个方块的上边界行从小到大排序（顶部优先），等级从 1 开始。
2. 奇数等级方块（第 1、3、5 ...）：保持对角标记位置不变。
3. 偶数等级方块（第 2、4、6 ...）：将对角标记相对于方块中心做水平镜像。具体地：若标记在方块左侧的对角位（左上或左下对角），则将其移至右侧对应的对角位（右上或右下对角）；反之亦然。上下位置不变。移动后，原标记位置恢复为黑(0)背景，新位置涂蓝(1)。
4. 从每个方块的（可能已镜像的）对角标记位置出发，沿相同的对角方向（从方块中心穿过标记的方向继续延伸），逐格涂蓝(1)，直至离开网格边界。只涂背景格；若遇到已有前景色的格子（含其他方块或其他射线），射线在该格前一格停止。
5. 所有原始方块像素保留不变。

**关键洞察**：同一类对象（2x2 方块 + 对角标记）因垂直排名的奇偶而接受不同的预处理（是否镜像），导致射线方向发生系统性翻转。求解者需同时发现排序规则和奇偶镜像规则。

## 新题 3：精灵频率普查决定框内操作

**组合逻辑**：[计数](全局精灵频率普查) → [条件分支：频率最高→填充 / 频率最低→擦除 / 中间→保持] → [填充](框内填色) + [擦除](框内清除)

**来源原语**：计数(counting)←39a8645d, 填充(fill)←ef135b50/6cf79266, 擦除(erase)←d35bdbdc, 精灵体(sprite)←39a8645d/d35bdbdc, 前景矩形(foreground_rectangle)←ef135b50, 形状相同(shape_identity)←39a8645d, 最高频精灵输出(most_frequent_sprite_output)←39a8645d, 无遮挡才填充(fill_if_unobstructed)←ef135b50

**依赖链**：全局精灵频率普查得出每种精灵类型的频率排名 → 排名映射到三种不同操作（填充/擦除/保持） → 操作作用于包含该类型精灵的矩形框内部。移除普查则无法确定操作类型；移除框结构则无法确定操作范围；普查结果与框内操作通过精灵类型耦合。

统计网格中所有精灵的出现频率，对每个矩形框内的精灵执行频率排名决定的操作：最高频类型填充整个框内，最低频类型被擦除，中间频率类型不变。

**输入结构**：约 18x18 网格，黑(0)背景。3~4 个灰(5)空心矩形框（1 像素宽边框，内部为黑(0)），互不重叠，每个框的内部空间至少 4x4。每个框内恰有一个小型单色精灵（4 连通，3~6 像素，边界框 3x3），精灵颜色与灰(5)不同，各框内精灵颜色各异（如红(2)、蓝(1)、绿(3)、橙(7)）。框外散布若干同类型精灵的额外副本：全网格中所有精灵（框内 + 框外）共 3 种不同类型（按形状 + 颜色定义身份），各类型频率互不相同。生成约束：恰好 3 种类型的精灵，频率两两不同；每种类型至少出现 2 次；至少有一种类型同时出现在某个框内和框外。

**规则**：
1. 将每个精灵归一化为其 3x3 边界框内的掩码，以形状 + 颜色定义类型身份。
2. 统计全网格（框内 + 框外）中每种精灵类型的出现次数。
3. 对每个矩形框，检查其内部精灵所属的类型：
   - 若该类型是全局频率最高的：用该精灵的颜色填充整个框的内部区域（框边框以内、精灵自身像素以外的所有黑(0)格），精灵像素保持不变。
   - 若该类型是全局频率最低的：擦除该精灵（将框内精灵像素恢复为黑(0)），框变成空框。
   - 若该类型频率居中（既非最高也非最低）：框及其内部保持不变。
4. 所有框外的精灵一律擦除（恢复为黑(0)背景）。
5. 灰(5)框边框始终保留不变。

**关键洞察**：决定每个框内发生什么操作的不是框或精灵的任何局部属性，而是跨越整个网格的全局频率统计。求解者必须对比多个示例才能发现频率排名与操作类型的映射关系。

## 新题 4：路径钉住行列的选择性压缩

**组合逻辑**：[压缩](合并相邻重复行列) ⊗ [路径绘制](路径像素阻止其所在行列被合并) — 两个机制同时约束输出，非线性先后

**来源原语**：压缩(compression)←ce8d95cc, 路径绘制(path_drawing)←891232d6, 重复行(dup_row)←ce8d95cc, 重复列(dup_column)←ce8d95cc, 路径网络(path_network)←d35bdbdc, 相邻相同(adjacent_identical)←ce8d95cc, 相同行列合并(merge_identical)←ce8d95cc, 路径连通(path_connectivity)←d35bdbdc

**依赖链**：压缩规则要求合并相邻相同的行/列 → 但路径像素所在的行/列被豁免合并 → 路径的空间位置因此直接影响压缩结果的几何形状。移除压缩则输出等于输入（错误）；移除路径豁免则全压缩丢失路径结构（错误）。两者同时约束输出。

对一个行列拉伸过的网格做压缩，但包含灰色路径像素的行和列被路径"钉住"，不参与合并，从而产生局部压缩、局部保留的非对称输出。

**输入结构**：约 16x16 网格。网格是一个小图案（约 6x6）沿行和列做游程扩展后的结果：部分相邻行完全相同，部分相邻列完全相同。图案使用 2~3 种前景色（如红(2)、蓝(1)）在黑(0)背景上。灰(5)像素形成一条 4 连通路径，穿越网格中部分重复行和重复列区域。路径宽度为 1 像素。路径像素替换了图案中的对应位置像素（即路径像素所在格的原始图案色被灰(5)覆盖）。生成约束：路径至少经过 2 个不同的重复行带和 2 个不同的重复列带；路径不经过的某些重复带仍然存在（以便展示正常压缩效果的对比）。

**规则**：
1. 标记所有包含至少一个灰(5)路径像素的行为"钉住行"，所有包含至少一个灰(5)路径像素的列为"钉住列"。
2. 行压缩：从上到下扫描行。对于相邻的连续相同行组成的"行带"（忽略灰(5)像素后其余像素完全相同的行也算相同）：
   - 若行带内无任何钉住行：合并为一行，保留行带中的第一行。
   - 若行带内存在钉住行：该行带内每一行均单独保留，不合并。
3. 列压缩：对行压缩后的结果，从左到右扫描列，应用完全对称的规则：
   - 无钉住列的相邻相同列带合并为一列。
   - 有钉住列的列带内每列单独保留。
4. 输出为选择性压缩后的网格。灰(5)路径像素在输出中保持原位。

**关键洞察**：路径不只是视觉元素——它在结构上阻止了所经过区域的行列合并，使得同一个拉伸图案的不同区域以不同的比率被压缩。求解者必须发现路径对压缩的抑制作用。

## 新题 5：面积决定落距的障碍绕行重力

**组合逻辑**：[计数](对象面积) → [重力下落](面积 = 下落距离) → [绕行](遇障碍水平绕行后继续下落) → 先落对象成为后落对象的障碍（处理顺序反馈）

**来源原语**：重力下落(gravity_drop)←c87289bb, 绕行(detour)←c87289bb, 计数(counting)←b2bc3ffd, 前景对象(foreground_object)←b2bc3ffd, 障碍线段(obstacle_segment)←c87289bb, 全宽条纹(full_width_stripe)←b2bc3ffd, 位移等于面积(shift_equals_area)←b2bc3ffd, 遇障碍绕最近侧(detour_nearest_side)←c87289bb

**依赖链**：每个对象的面积决定其下落距离 → 下落路径上若有障碍线段则绕行 → 绕行改变对象的最终列位置 → 处理顺序（从上到下）使先安置的对象成为后续对象的新障碍。面积决定落距（来自 b2bc3ffd 但原题是向上平移）；绕行机制（来自 c87289bb 但原题是连续下落至底部）；两者在新题中交叉：面积限制了总位移量，而绕行消耗了部分位移预算。

小对象在网格中做有限距离的重力下落（距离等于自身面积），途中遇到障碍线段则水平绕行至最近侧继续下落，先安置的对象阻挡后续对象。

**输入结构**：约 15x18 网格，黑(0)背景。最后一行为全宽红(2)条纹（固定基线，不移动）。条纹上方散布 3~5 个小型单色蓝(1)4 连通对象，每个 2~6 像素，边界框不超过 3x3。对象之间水平和垂直间隔至少 2 格。条纹与对象之间有 1~2 条水平绿(3)障碍线段（1 像素高，3~6 像素宽）。生成约束：每个对象的面积（像素数）使其下落后的最低行不超出网格底部（含条纹行）；至少有一个对象的下落路径经过某条障碍线段。

**规则**：
1. 按每个对象的上边界行从小到大排序（顶部优先），确定处理顺序。
2. 依次处理每个对象：
   a. 计算该对象的面积 A（像素数）。
   b. 将对象从原始位置清除（恢复为黑(0)）。
   c. 将对象整体向下平移，目标为向下移动 A 行。逐行移动，每移动一行消耗 1 单位位移预算。
   d. 每移动一行后，检查对象的任何像素是否与绿(3)障碍线段或已安置的其他对象或红(2)条纹重叠：
      - 若重叠：回退到重叠前一行的位置。将对象整体水平平移至与该障碍/对象的最近空闲侧（比较对象中心列到障碍左端和右端的距离，选较近一端；等距时选右端）。水平平移不消耗位移预算。然后从新列位置继续向下消耗剩余位移预算。
      - 若到达红(2)条纹正上方一行或网格底部：停止，不论预算是否用完。
   e. 在最终位置放置对象（涂蓝(1)），此后该对象成为后续对象的障碍。
3. 障碍线段和红(2)条纹始终保留不变。
4. 若多个对象上边界行相同，按左边界列从小到大确定先后。

**关键洞察**：面积不是"落到底部"而是"落 A 行"，所以小面积对象可能悬停在半空中。绕行改变水平位置后继续消耗剩余下落预算，使路径呈折线而非直线。处理顺序创造了级联依赖：先安置的对象改变了后续对象的可行路径。

## 新题 6：对角线段计数编码平铺因子

**组合逻辑**：[计数](右区对角线段数量 → 平铺因子 N) + [最长线段选中](最长对角线段的方向 → 平铺轴) → [平铺](左区瓦片沿选定轴平铺 N 次)

**来源原语**：平铺(tiling)←a59b95c0, 计数(counting)←a59b95c0/aa300dc3, 对角线段(diagonal_segment)←aa300dc3, 最长线段选中(longest_selected)←aa300dc3, 瓦片(tile)←a59b95c0, 阵列排布(array_layout)←a59b95c0, 平行对角线带(parallel_diagonal_band)←aa300dc3, 色数决定重复次数(color_count_repetition, 创新为线段数决定重复次数)←a59b95c0

**依赖链**：右区的对角线段的几何结构编码了两个参数——数量（平铺因子）和最长线段的方向（平铺轴）。这两个参数共同决定左区瓦片如何被平铺。移除计数则不知道平铺几次；移除方向判断则不知道沿哪个轴平铺。

右侧面板中对角线段的总数决定平铺倍数，最长线段的走向决定平铺方向；左侧面板的小瓦片按此规则铺开后即为输出。

**输入结构**：约 8x18 网格（宽大于高）。一条灰(5)竖直分隔线将网格分为左右两区。左区约 8x6，包含一个小型彩色瓦片图案（使用 2~3 种前景色，如红(2)、蓝(1)、黄(4)，在黑(0)背景上），占满左区或居中放置。右区约 8x11，灰(5)背景，其中有若干黑(0)像素组成的最大连续对角线段（沿 ╲ 或 ╱ 方向），每段至少 2 像素长，各段之间互不相邻（8 连通意义下也不接触），共 2~5 段。生成约束：恰好一段最长且唯一最长；各段可以是 ╲ 方向也可以是 ╱ 方向。

**规则**：
1. 在右区中找出所有最大连续对角线段（沿 ╲ 方向或 ╱ 方向的连续黑(0)像素序列，每段在其方向上不可再延伸）。
2. 统计线段总数 N。
3. 找出最长的线段。若其方向为 ╲（左上→右下），则平铺轴为水平（左右铺开）；若为 ╱（左下→右上），则平铺轴为垂直（上下铺开）。若最长长度有多段并列，取上边界行最小（最靠近顶部）的那段的方向。
4. 输出仅包含平铺结果（不含右区和分隔线）：
   - 水平平铺：将左区瓦片沿水平方向重复 N 次（垂直方向 1 次），输出大小为 瓦片高 x (瓦片宽 x N)。
   - 垂直平铺：将左区瓦片沿垂直方向重复 N 次（水平方向 1 次），输出大小为 (瓦片高 x N) x 瓦片宽。

**关键洞察**：右区是一个"参数面板"——其中对角线段的几何特征（数量和方向）编码了两个独立参数，共同控制左区瓦片的平铺方式。求解者必须意识到线段被用作计数对象和方向指示器，而非图案本身的一部分。

## 新题 7：对称补全后奇面积封闭区域填色

**组合逻辑**：[对称补全](沿黄色轴镜像完成部分图案) → [填充](对补全后产生的封闭区域做面积奇偶判定后选择性填色)；补全结果创造了填充所需的封闭几何，且轴长度参与奇偶判定的空间逻辑

**来源原语**：对称补全(symmetric_completion)←5b692c0f, 填充(fill)←ef135b50/6cf79266, 计数(counting)←b2bc3ffd, 对称轴(symmetry_axis)←5b692c0f, 控制标记(control_marker)←5b692c0f, 控制标记指示源侧(control_marker_indicates_source)←5b692c0f, 轴对称反射(axial_mirror_reflection)←5b692c0f, 空白区域(blank_region)←6cf79266, 无遮挡才填充(fill_if_unobstructed)←ef135b50

**依赖链**：控制标记确定源侧 → 沿轴镜像补全 → 补全后的前景像素围成封闭区域（输入中不存在这些封闭区域） → 计数每个封闭区域的面积 → 面积为奇数时填色、偶数时不填。移除补全则封闭区域不存在；移除面积奇偶判定则无法确定哪些区域该填。

将带黄色轴的部分图案做镜像补全，补全后新出现的封闭背景区域按面积奇偶决定是否填色。

**输入结构**：约 16x16 网格，黑(0)背景。2~3 个非重叠的部分图案，每个使用不同的前景色（如红(2)、蓝(1)、绿(3)），彼此间距至少 3 格。每个图案含一条黄(4)的水平或竖直轴线（连续的一排或一列黄色像素，长度 3~6）和一个不在轴上的黄(4)控制像素（位于轴的某一侧，标识源侧）。源侧的图案像素形成一个开口朝向轴对面的弧形或钩形（4 连通，5~10 像素），其镜像补全后将在轴对面形成封闭区域。生成约束：每个图案补全后至少产生一个封闭背景区域；不同图案产生的封闭区域面积有奇有偶（至少各一个），以便求解者对比发现奇偶规则。

**规则**：
1. 对每个图案，确定源侧（包含离轴黄(4)控制像素的一侧）。
2. 将源侧的整个矩形半区（以轴为分界）沿轴镜像反射到对侧，逐像素复制。前景色和黑(0)背景均被复制。黄(4)轴线和控制像素保持不变。若目标侧已有像素与镜像像素冲突，镜像像素覆盖。
3. 补全所有图案后，找出所有封闭背景区域：4 连通的黑(0)连通分量，且该分量不与网格边缘相邻（不接触第 0 行、最后一行、第 0 列或最后一列）。
4. 对每个封闭背景区域，计算其面积（像素数）：
   - 面积为奇数：用包围该区域的前景色（即与该区域 4 邻接的非黑非黄前景色，保证唯一）填充整个区域。
   - 面积为偶数：保持黑(0)不变。
5. 所有前景像素、黄(4)轴和控制像素均保留不变。

**关键洞察**：镜像补全是填充的前提条件——输入中没有封闭区域，只有补全后才产生。面积奇偶是隐蔽规则，需要对比多个示例中填充 vs 不填充的封闭区域才能归纳出来。

## 新题 8：框缝射线长度编码拉伸系数

**组合逻辑**：[射线延伸](从带框块缝隙向外发射射线) → [计数](射线长度作为数值) → [拉伸](用射线长度作为参考面板的拉伸系数)；射线的空间测量结果跨区域地参数化了另一个操作

**来源原语**：射线延伸(ray_extend)←e12f9a14, 拉伸(stretch)←9841fdad, 带框块(framed_block)←e12f9a14, 框架缺口(frame_gap)←e12f9a14, 参考面板(reference_panel)←9841fdad, 压缩与展开(compress_expand)←9841fdad, 连接跨越(connection_span)←9841fdad, 碰撞停止(collision_stop)←e12f9a14

**依赖链**：框缝位置和方向决定射线路径 → 射线遇到障碍或边界时停止，长度被测量 → 水平射线长度成为水平拉伸系数，垂直射线长度成为垂直拉伸系数 → 参考面板按这两个系数被拉伸。移除射线则拉伸系数未知；移除拉伸则参考面板无法变换；两个射线分别贡献水平和垂直参数。

两个带框方块的缝隙分别朝水平和垂直方向发射射线，射线在碰到障碍或网格边缘时停止；两条射线的长度分别作为参考面板内容的水平和垂直拉伸系数。

**输入结构**：约 18x18 网格，黑(0)背景。左上角有一个灰(5)边框包围的参考面板，内部为一个小型彩色图案（2x3 或 3x2，使用红(2)、蓝(1)等前景色，黑(0)背景）。网格中另有 2 个带框块：每个是 4x4 的绿(3)方框包围 2x2 的单色内部（如黄(4)和橙(7)），方框上恰有 1 个缺口像素（绿(3)被黑(0)替换）。一个带框块的缺口朝水平方向（缺口在框的左侧或右侧中间），另一个缺口朝垂直方向（缺口在框的上侧或下侧中间）。两个带框块之间、以及带框块与参考面板之间有足够间距（至少 3 格黑(0)背景）。生成约束：每条射线到达障碍或边界前至少经过 2 格背景，保证拉伸系数 >= 2。

**规则**：
1. 保留输入网格中的所有像素。
2. 对每个带框块，从其缺口位置向外（远离框中心的方向）发射一条射线，颜色为该框内部 2x2 块的颜色。射线逐格延伸，涂过的每个黑(0)背景格变为该颜色。
3. 射线在遇到以下情况时停止（最后一个涂色格为停止前一格）：下一格为非黑(0)像素（任何前景色、框、面板边框等），或下一格超出网格边界。
4. 测量每条射线的长度 L（射线涂色的背景格数）。
5. 确定拉伸系数：
   - 缺口朝水平方向的框的射线长度 = 水平拉伸系数 H。
   - 缺口朝垂直方向的框的射线长度 = 垂直拉伸系数 V。
6. 将参考面板内部图案（不含灰(5)边框）做最近邻拉伸：每个像素在水平方向重复 H 次、在垂直方向重复 V 次。
7. 将拉伸后的图案放置在参考面板的原始位置，覆盖原参考面板及其灰(5)边框。若拉伸后图案超出原面板区域，向右和向下扩展，覆盖对应的背景格。若拉伸后图案与带框块或射线重叠，拉伸图案优先覆盖。
8. 带框块和射线保留在输出中（除非被拉伸图案覆盖）。

**关键洞察**：射线不是装饰性输出——它们的长度是对空间距离的测量，被用作另一个完全不同的操作（拉伸）的参数。求解者必须发现射线长度与拉伸系数之间的跨区域数值对应关系。
