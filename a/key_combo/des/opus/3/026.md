## 新题 1：交叉射线格与交汇混色

**组合逻辑**：[射线延伸](创新：从无条件全方向发射改为仅在存在异色共线种子时发射) + [重涂色](创新：交叉点混色而非简单覆盖) + [种子色决定延伸方向] + [双色交叉混合色]

**来源原语**：射线延伸/ray_extend(参考题 178fcbfb)，重涂色/recolor(参考题 a8610ef7)，种子像素/seed_pixel(参考题 178fcbfb)，共行或共列/shared_row_col(参考题 e760a62e)，种子色决定延伸/seed_color_determines_extend(参考题 178fcbfb)，双色交叉混合色/intersect_blend_color(参考题 e760a62e)

**依赖链**：种子颜色决定射线朝向（红(2)→纵向，蓝(1)→横向）；但射线是否真正发射取决于该种子所在行/列是否存在异色种子（共线异色检测）；两条异色射线在同一像素交汇时，该像素着绿(3)而非任何一条射线的原色；最终输出是一张非均匀间距的正交线网，交叉节点有独特颜色。三层逻辑（发射条件→射线延伸→交汇混色）逐层依赖，删去任一层结果都不同。

将散布的红(2)和蓝(1)种子像素按颜色决定的方向发射射线，仅当该种子与某个异色种子共享行或列时才发射，射线交叉点着绿(3)。

**输入结构**：约 15x15 的黑(0)背景网格。散布若干红(2)像素和蓝(1)像素，每个像素占一格，各像素互不同行同列（即任意两个种子不共享同一行且不共享同一列，但红种子可以与蓝种子共享行或列）。种子总数约 4~8 个。生成约束：至少存在一对红-蓝种子共享同一行，且至少存在一对红-蓝种子共享同一列，以保证至少出现一个交叉点。同色种子之间不共享行也不共享列。

**规则**：
1. 对每个红(2)种子像素，检查其所在列是否存在至少一个蓝(1)种子像素。若是，将该红种子沿整列扩展为红(2)竖线（从第 0 行到最后一行）。若否，该红种子保留为单个红像素不扩展。
2. 对每个蓝(1)种子像素，检查其所在行是否存在至少一个红(2)种子像素。若是，将该蓝种子沿整行扩展为蓝(1)横线（从第 0 列到最后一列）。若否，该蓝种子保留为单个蓝像素不扩展。
3. 当一条红竖线与一条蓝横线在同一像素交叉时，该像素着绿(3)，不保留红或蓝。
4. 未被射线覆盖的像素保持黑(0)。

**关键洞察**：并非所有种子都会发射射线——只有与异色种子共享行或列的种子才会激活，这需要对比多个示例才能发现（单个示例中可能所有种子恰好都满足条件，看不出这条过滤规则）。

## 新题 2：格子单元对称分级涂色

**组合逻辑**：[镜像/对称检测](创新：不是对整图做镜像变换，而是对每个格子单元独立做对称性测试作为分类依据) + [重涂色](创新：同一格子内部根据逐像素对称匹配结果做差异化涂色) + [格子单元分区] + [交集差集分别着色]

**来源原语**：镜像/mirror(参考题 a8610ef7)，重涂色/recolor(参考题 a8610ef7, 94f9d214)，填充/fill(参考题 e760a62e)，格子单元/lattice_cell(参考题 e760a62e)，网格线/lattice_line(参考题 e760a62e)，反射对称/reflection_symmetry(参考题 a8610ef7)，逐像素比较/per_pixel_comparison(参考题 94f9d214)，交集差集分别着色/intersection_diff_colored(参考题 a8610ef7)

**依赖链**：青(8)网格线将画布分割为格子单元→每个单元内的前景图案被独立提取→对每个图案做左右反射对称测试→测试结果决定涂色方案（完全对称→整体涂绿；不完全对称→对称匹配的像素涂蓝、不匹配的像素涂红）。网格分割定义了测试边界，对称测试定义了分类，分类决定了涂色方案——三者形成不可跳步的推理链。

在青(8)网格线划分的每个格子单元中，对前景图案做左右对称测试：完全对称的单元前景涂绿(3)，不对称的单元中对称匹配像素涂蓝(1)、不匹配像素涂红(2)。

**输入结构**：约 13x13 的黑(0)背景网格。青(8)的单像素宽网格线将画布分为 3x3 或 4x4 的等大矩形格子单元（每个单元内部约 3x3 像素）。每个格子单元内部有若干橙(7)前景像素组成的小图案（1~6 个像素的 4-连通或散布图案）。不同单元中的图案形状各异：部分具有左右反射对称性，部分不具有。至少有一个单元无前景像素（全黑）。生成约束：每个单元内部尺寸为奇数列宽（如 3 或 5），以保证左右对称轴为整数列。

**规则**：
1. 识别青(8)网格线，确定所有格子单元的边界。青(8)网格线在输出中保持不变。
2. 对每个格子单元，提取其内部的前景像素图案（忽略网格线像素）。
3. 若该单元内无前景像素，保持全黑(0)不变。
4. 对有前景像素的单元，以该单元内部的垂直中轴为对称轴，做左右反射对称测试：将每个前景像素 (r, c) 映射到 (r, c_mirror)，其中 c_mirror = 单元左边界 + 单元宽度 - 1 - (c - 单元左边界)。
5. 若单元内所有前景像素都有对应的反射像素（即图案完全左右对称），则将该单元内所有前景像素重涂为绿(3)。
6. 若图案不完全对称：对于每个前景像素，若其反射位置也是前景像素，则该像素重涂为蓝(1)；若其反射位置不是前景像素，则该像素重涂为红(2)。
7. 背景像素保持黑(0)。

**关键洞察**：完全对称与不完全对称采用不同的涂色方案（统一绿色 vs. 蓝红分离），这一分支规则需要在同一示例中同时看到两种情况、或对比多个示例才能归纳出来。

## 新题 3：配对框内周期修复

**组合逻辑**：[裁剪](创新：不是选最大框，而是按边框颜色配对后裁剪两个框的内容) + [补全](创新：周期信息不从自身推断，而是从配对框提供的完整瓦片获得) + [边框配对] + [完整边框检测]

**来源原语**：裁剪/crop(参考题 1a6449f1)，补全/complete(参考题 e95e3d8e)，周期瓦片/periodic_tile(参考题 e95e3d8e)，矩形框/rectangular_frame(参考题 1a6449f1)，内部区域/interior_region(参考题 1a6449f1)，边框包围内容/border_encloses_content(参考题 1a6449f1)，周期对齐/periodic_align(参考题 e95e3d8e)，调色板匹配配对/palette_match_pairing(参考题 4c7dc4dd)，完整边框检测/complete_border_check(参考题 1a6449f1)，最小周期修复缺口/min_period_repair_gap(参考题 e95e3d8e)

**依赖链**：在画布上检测所有完整矩形框→按边框颜色将框两两配对→每对中面积较小的框内部包含一个无缺损的小图案（即周期瓦片）→面积较大的框内部包含同色系的周期图案但有黑色缺损→以小框图案为瓦片，按行列取模对齐填补大框内的缺损→输出修复后的大框内部。框的配对提供了外部周期信息源，这与参考题 e95e3d8e 从自身内容推断周期完全不同。

按边框颜色配对矩形框，用小框内部的完整图案作为周期瓦片修复大框内部的缺损像素，输出修复后的大框内部区域。

**输入结构**：约 20x20 的黑(0)背景网格。画布上有两对矩形框（共 4 个框），每个框由单像素宽的同色边框围成。第一对框的边框颜色为红(2)，第二对为蓝(1)。每对中有一个大框（内部约 6x6 至 9x9）和一个小框（内部约 2x2 至 3x3）。大框内部包含由绿(3)和黄(4)像素组成的周期图案，但有若干像素被替换为黑(0)（缺损位置）。小框内部包含同一周期图案的一个完整瓦片（无缺损），用与大框相同的绿(3)和黄(4)颜色。不同对使用不同的周期图案。框之间不重叠、不接触。生成约束：大框内部尺寸是小框内部尺寸在行列方向上的整数倍，以保证瓦片能精确铺满；每对的两个框边框颜色完全相同且与另一对不同；画布上不存在不完整的边框（无干扰）。

**规则**：
1. 检测所有由单像素宽同色边框组成的完整矩形框。
2. 按边框颜色将框分组配对：边框颜色相同的两个框为一对。
3. 每对中，内部面积较小的框为"瓦片源"，较大的框为"修复目标"。
4. 提取瓦片源框的内部区域作为周期瓦片 T（高 th 行、宽 tw 列）。
5. 对修复目标框的内部区域，将每个黑(0)像素 (r, c)（相对于目标内部左上角）替换为 T[r mod th][c mod tw]。非黑像素保持不变。
6. 输出仅包含所有修复目标框的内部区域。若有多个目标框，按其在输入中左上角位置从左到右、从上到下的顺序，垂直拼接为一个输出网格（两个目标内部之间无间隔行）。

**关键洞察**：周期瓦片不是从损坏图案自身推断的（与参考题 e95e3d8e 不同），而是由配对的小框显式提供——配对依据是边框颜色匹配，这需要对比多个示例（有多对不同颜色的框）才能确认配对规则不是基于空间邻近度。

## 新题 4：多竖条梯度扩展与循环借色

**组合逻辑**：[延伸填充](创新：从单条扩展到多条，各自独立产生高度梯度) + [填充](创新：扩展区域的颜色不由扩展源决定，而是从循环相邻的下一条竖条借色) + [距离控制高度] + [循环相邻借色] + [不对称递变]

**来源原语**：延伸填充/extension_fill(参考题 5207a7b5)，填充/fill(参考题 c4d1a9ae)，竖条/vertical_bar(参考题 5207a7b5)，竖向色带/vertical_band(参考题 c4d1a9ae)，距离控制高度/distance_controls_height(参考题 5207a7b5)，循环相邻/cyclic_adjacent(参考题 c4d1a9ae)，空缺借邻色填充/gap_borrows_neighbor(参考题 c4d1a9ae)，不对称递变/asymmetric_gradient(参考题 5207a7b5)

**依赖链**：多条不同颜色的竖条从画布顶部边缘向下延伸→每条竖条向左右扩展填充，填充高度随距离递减（距离控制高度）→但扩展区域的颜色并非自身颜色，而是循环借取右邻竖条的颜色（循环借色）→当两条相邻竖条的扩展区域在某些列重叠时，高度更大的一方覆盖另一方。梯度高度决定覆盖范围，循环顺序决定覆盖颜色，两者共同决定最终外观。

多条顶部对齐的竖条各自向两侧扩展递减高度的填充区域，填充色取自右侧循环相邻竖条的颜色，重叠处由较高者覆盖。

**输入结构**：约 12x15 的黑(0)背景网格。3~4 条单像素宽的竖条从第 0 行向下延伸若干行（各条高度不同，范围 3~8 行），竖条颜色互不相同，使用红(2)、绿(3)、蓝(1)、黄(4)中的 3~4 种。竖条之间至少间隔 3 列以留出扩展空间。竖条按列位置从左到右自然排列。生成约束：相邻竖条之间的列间距大于各自高度的一半（以减少完全重叠的极端情况），但不完全避免重叠（部分列应当出现两条竖条的扩展范围交叉）。

**规则**：
1. 识别所有从第 0 行开始的非黑单像素宽竖条，记录每条竖条的列位置 col_i、高度 h_i（即连续非黑像素的行数）和颜色 color_i。
2. 将竖条按列位置从左到右排列，编号为 1, 2, ..., N。定义循环邻居：竖条 i 的右邻为竖条 (i mod N) + 1（即最右侧竖条的右邻是最左侧竖条）。
3. 对每条竖条 i，保留其原始像素不变（颜色 color_i）。
4. 对竖条 i 左侧距离为 d（d = 1, 2, ...）列的每一列：从第 0 行向下填充 h_i - d 个像素（若 h_i - d <= 0 则不填充）。填充颜色为竖条 i 的右邻竖条的颜色 color_{(i mod N)+1}。
5. 对竖条 i 右侧距离为 d（d = 1, 2, ...）列的每一列：从第 0 行向下填充 h_i - d 个像素（若 h_i - d <= 0 则不填充）。填充颜色同样为竖条 i 的右邻竖条的颜色。
6. 当某一列同时处于两条竖条的扩展范围内（即两条竖条对该列的填充高度均 > 0），在每一行取填充高度较大的那条竖条所对应的颜色。若两者高度相同，取列位置靠左的竖条的颜色。
7. 超出网格行范围的填充截断至网格底部。

**关键洞察**：扩展区域的颜色不是竖条自身的颜色，而是循环借自右邻竖条——这在单个示例中容易被误判为"每条竖条就是那个颜色"，必须对比多个示例中竖条颜色与扩展区域颜色的不匹配才能发现借色规则。

## 新题 5：精灵体对称分类与分区印章

**组合逻辑**：[缩放/归一化](创新：从固定来源归一化改为多个不同来源的精灵体统一归一化到同一尺寸) + [镜像/对称检测](作为分类器使用) + [印章覆盖](创新：印章位置不固定，由对称性分类结果决定放置在输出的哪个区域) + [归一化到固定尺寸] + [反射对称]

**来源原语**：缩放/resize(参考题 db118e2a)，印章覆盖/stamp_overlay(参考题 db118e2a)，镜像/mirror(参考题 a8610ef7)，精灵体/sprite(参考题 4c7dc4dd, 4df5b0ae)，圆角边框/rounded_frame(参考题 db118e2a)，归一化到固定尺寸/normalize_size(参考题 db118e2a)，反射对称/reflection_symmetry(参考题 a8610ef7)，中心对齐/center_alignment(参考题 c8cbb738)，对角放置/diagonal_placement(参考题 db118e2a)

**依赖链**：从画布中提取各个带框精灵体→裁剪出精灵体内部并归一化到 3x3→对归一化后的图案做 180 度旋转对称测试→对称的精灵体按从左到右的原始位置顺序放入输出上半区，不对称的放入下半区→输出尺寸由分类结果数量决定。归一化提供统一的测试基底，对称测试产生二元分类，分类决定空间分配——三步不可跳过。

从带框精灵体中提取图案，归一化到 3x3 后按 180 度旋转对称性分为两组，对称组横排在输出上半区，不对称组横排在下半区。

**输入结构**：约 18x18 的黑(0)背景网格。散布 4~6 个圆角矩形框（四角为黑(0)，其余边框像素为灰(5)），每个框内有一个由非黑非灰颜色组成的小图案（2~6 像素，颜色可包含红(2)、蓝(1)、绿(3)、黄(4)中的一种或多种）。不同框中的图案尺寸不同（边界框从 1x2 到 3x3 不等），且各图案的具体形状各异。部分图案具有 180 度旋转对称性（即旋转 180 度后与原图案重合），部分不具有。框之间互不重叠、互不相邻。生成约束：至少有 1 个对称图案和 1 个不对称图案。

**规则**：
1. 识别所有圆角矩形框（四角为黑(0)的灰(5)边框），提取每个框的内部区域。
2. 将每个内部图案裁剪到其前景像素的最小边界框。
3. 将裁剪后的图案居中放入 3x3 的黑(0)画布中（若图案宽或高小于 3，两侧均匀留黑；若某方向多出 1 像素的余量，偏左上）。得到归一化后的 3x3 图案。
4. 对每个 3x3 图案做 180 度旋转对称测试：将图案旋转 180 度，与原图案逐像素比较。若所有像素匹配（颜色相同），则归为"对称组"；否则归为"不对称组"。
5. 构建输出网格：宽度 = max(对称组数量, 不对称组数量) x 3 像素，高度 = 7 像素（上半区 3 行 + 1 行灰(5)分隔线 + 下半区 3 行）。背景为黑(0)。
6. 对称组的图案按其原始框在输入中的左上角列坐标从小到大排序，依次从左到右放入上半区（第 0~2 行），每个占 3 列，紧密排列无间隔。
7. 不对称组的图案按相同排序规则放入下半区（第 4~6 行）。
8. 若某组为空，则该区域保持全黑，但分隔线和总高度不变。

**关键洞察**：对称测试在归一化之后进行——不同尺寸的原始图案可能在归一化后获得或失去对称性（因为居中填充改变了像素布局），因此不能直接在原始图案上判断对称性。这一点需要对比多个示例才能确认。

## 新题 6：链式检测与孤立条支撑过滤的联合判定

**组合逻辑**：[旋转](创新：仅对满足链式条件的竖条执行旋转，其余竖条不动) + [擦除](创新：擦除条件不是简单的邻接计数，而是取决于竖条是否被链式系统"引用") + [链式连接] + [高度即宽度] + [邻接不足则删除]

**来源原语**：旋转/rotate(参考题 84551f4c)，擦除/erase(参考题 7f4411dc)，竖条/vertical_bar(参考题 84551f4c)，标记条/marker_bar(参考题 84551f4c)，链式序列/chained_sequence(参考题 84551f4c)，孤立像素/isolated_pixel(参考题 7f4411dc)，链式连接/chain_linkage(参考题 84551f4c)，高度即宽度/height_equals_width(参考题 84551f4c)，邻接不足则删除/delete_unsupported(参考题 7f4411dc)，邻接/adjacency(参考题 7f4411dc)

**依赖链**：底部对齐的竖条群中，绿(3)标记条启动链式检测→从标记条出发，按"下一条的列 = 当前列 + 当前高度"的规则寻找后续红(2)条→链内所有条旋转为水平（高度变宽度）→未被任何链覆盖的红(2)条成为"孤立条"→孤立条按邻接支撑规则过滤：若某孤立条的底部像素左右两侧均无其他非黑像素（即无邻接支撑），则擦除该条；有支撑的孤立条保留为竖直状态。链式归属决定是否旋转，邻接支撑决定孤立条是否存活——两套规则共同决定每条竖条的命运。

底部对齐的竖条群通过链式规则分为链内条和孤立条：链内条旋转为水平，有邻接支撑的孤立条保留竖直，无支撑的孤立条被擦除。

**输入结构**：约 10x20 的黑(0)背景网格。若干单像素宽的竖条从网格底部向上延伸（底部对齐于最后一行），高度各异（2~7 行）。其中 1~2 条为绿(3)色（标记条），其余为红(2)色。竖条之间的列间距不等。生成约束：每条绿色标记条能通过链式规则（下一条的列位置 = 当前条的列位置 + 当前条的高度）连接到至少 1 条红色条；存在至少 2 条红色条不被任何链覆盖（即孤立条）；孤立条中至少 1 条的底部像素左右相邻列有其他竖条的像素（有支撑），至少 1 条没有（无支撑）。

**规则**：
1. 识别所有底部对齐于最后一行的单像素宽竖条，记录每条的列位置 col、高度 h、颜色。
2. 对每个绿(3)标记条，启动链式检测：从该标记条出发，寻找列位置 = col + h 处是否存在一条红(2)竖条。若存在，将其纳入链中，然后以该红条为新的起点继续寻找（新的目标列 = 红条的列 + 红条的高度），直到找不到后续红条为止。
3. 对链中的每条竖条（包括绿色标记条本身）：清除其竖直像素，在其原始底部像素位置向右绘制水平条，长度等于其原始竖直高度，颜色保持不变。绘制方向固定向右。水平条超出网格右边界的部分截断。
4. 将所有未被任何链覆盖的红(2)竖条标记为"孤立条"。
5. 对每条孤立条，检查其底部像素（最后一行的像素）的左右两个 4-邻居列（col-1 和 col+1）在最后一行是否存在非黑像素。若至少一侧存在非黑像素，则该孤立条保留，维持竖直状态不变。若两侧均为黑(0)或超出边界，则擦除该孤立条（所有像素变为黑(0)）。
6. 被链式旋转为水平的条如果覆盖了某个孤立条的列，该孤立条的支撑检查在水平条绘制之后进行（即水平条的像素计入支撑判断）。

**关键洞察**：孤立条的存活不仅取决于自身的邻接状况，还取决于链式旋转的结果——链内条旋转为水平后可能为某个孤立条提供底部邻接支撑，使原本会被擦除的孤立条得以存活。这种跨规则的因果反馈需要对比多个示例才能理解。

## 新题 7：类比学习循环色移变换

**组合逻辑**：[类比推理](创新：学习的变换不是空间几何变换，而是色彩空间中的循环位移) + [重涂色](创新：涂色不是按固定映射，而是按从训练对中推断出的循环步长统一位移) + [训练对映射] + [调色板匹配配对] + [循环相邻]

**来源原语**：类比推理/analogy_inference(参考题 4c7dc4dd)，规则推断/rule_inference(参考题 4c7dc4dd)，重涂色/recolor(参考题 a8610ef7)，空心框/hollow_frame(参考题 4c7dc4dd)，精灵体/sprite(参考题 4c7dc4dd)，训练对映射/training_pair_mapping(参考题 4c7dc4dd)，调色板匹配配对/palette_match_pairing(参考题 4c7dc4dd)，循环相邻/cyclic_adjacent(参考题 c4d1a9ae)

**依赖链**：画布上的多个空心框中，两个框通过边框颜色相同配成训练对→比较训练对的两个内部图案，发现每个像素的颜色沿一条固定的颜色循环序列向前移动了 K 步→K 值仅能从训练对推断→将同样的 K 步循环位移应用到测试框的内部图案→输出变换后的图案。颜色循环序列本身也必须从训练对中归纳（不是预设的 0-9 顺序）。

从边框颜色相同的训练对中推断颜色循环位移步长 K 和循环序列，将相同变换应用于测试框内的精灵体图案并输出。

**输入结构**：约 15x15 的黑(0)背景网格。3 个空心正方形框（单像素宽边框，内部 3x3 至 4x4），互不重叠。其中两个框的边框颜色相同（如灰(5)），构成训练对；第三个框的边框颜色不同（如橙(7)），为测试框。训练对的第一个框（左上角位置更靠左上的那个）内部有一个由 2~3 种颜色组成的图案（如红(2)、蓝(1)、绿(3)的像素组合），第二个框内部有相同空间布局但每种颜色被替换为循环序列中后 K 个位置的颜色。测试框内部有另一个由部分相同颜色组成的图案。背景像素（框内外的黑(0)）在循环位移中保持不变。生成约束：训练对的两个内部图案像素位置完全对应（同一位置有像素或同一位置为黑），仅颜色不同；循环序列包含训练对和测试框中出现的所有非黑非边框颜色；K >= 1 且使得变换后的颜色在 0-9 范围内；循环序列长度 >= 3 以避免平凡的互换。

**规则**：
1. 识别所有空心正方形框（单像素宽的同色边框围成的正方形，四个角像素属于边框）。
2. 按边框颜色分组。边框颜色相同的两个框为训练对（若存在恰好两个同色框）。剩余的一个框为测试框。
3. 在训练对中，以左上角位置更靠左（若列相同则更靠上）的框为"训练输入"，另一个为"训练输出"。
4. 提取训练输入和训练输出的内部图案（不含边框）。逐像素比较两个图案中的非黑像素颜色，收集所有颜色映射关系 {color_A → color_B}。
5. 从映射关系中推断循环序列和步长 K：找到一条最短的颜色循环 (c1 → c2 → c3 → ... → c1)，使得训练对中每个颜色映射都可以解释为沿此循环前进 K 步。黑(0)不参与循环（黑像素始终保持黑色）。
6. 提取测试框的内部图案。对每个非黑像素，将其颜色沿同一循环前进 K 步，得到新颜色。黑像素保持不变。
7. 输出变换后的测试框内部图案（不含边框）。

**关键洞察**：变换发生在颜色空间而非几何空间——训练对的两个图案形状完全相同，只有颜色被循环移位了。循环序列和步长都不是预定义的，必须从训练对的颜色映射中推断。

## 新题 8：噪声过滤后的种子图案周期铺满

**组合逻辑**：[擦除](创新：不是对全局做邻接过滤，而是仅对种子图案区域做过滤以净化周期种子) + [平铺](创新：平铺的种子图案是过滤后的结果，而非直接使用输入底部图案) + [邻接不足则删除] + [周期重复] + [填满网格]

**来源原语**：擦除/erase(参考题 7f4411dc)，平铺/tile(参考题 9b30e358)，种子图案/seed_motif(参考题 9b30e358)，孤立像素/isolated_pixel(参考题 7f4411dc)，邻接/adjacency(参考题 7f4411dc)，周期重复/periodic_repeat(参考题 9b30e358)，填满网格/fill_grid(参考题 9b30e358)，邻接不足则删除/delete_unsupported(参考题 7f4411dc)

**依赖链**：底部若干行包含一个前景图案与散布的噪声像素混合→噪声像素的 4-邻居中同色像素少于 2 个，通过邻接支撑过滤去除→净化后的底部图案成为周期种子→将种子图案向上周期重复铺满整个网格。如果不先过滤噪声，直接铺满会将噪声像素也复制到每一个周期中，导致错误结果。过滤的判据（邻接支撑）依赖于图案本身的结构，而铺满的正确性依赖于过滤的准确性——两步形成真正的逻辑耦合。

底部图案混有噪声像素，按邻接支撑过滤噪声后，将净化的图案向上周期平铺以填满整个网格。

**输入结构**：约 12x10 的黑(0)背景网格。底部连续的 3~4 行包含一个由红(2)和蓝(1)像素组成的前景图案（有一定结构，如水平条纹或棋盘片段），同时在这些行中散布若干额外的黄(4)单像素噪声点。底部以上的所有行均为黑(0)。生成约束：前景图案中的红(2)和蓝(1)像素每个都至少有 2 个同色 4-邻居（保证过滤不会误删真实图案像素）；黄(4)噪声像素每个的 4-邻居中同色像素少于 2 个（保证能被正确识别为噪声）；底部图案行数能整除网格总行数（保证向上铺满时行数恰好对齐）。

**规则**：
1. 确定底部图案区域：从最后一行向上扫描，连续的包含非黑像素的行为图案区域（遇到全黑行即停止）。记录图案区域的行范围和高度 H。
2. 在图案区域内，对每个非黑像素检查其 4-邻居（上下左右）中与自身颜色相同的像素个数。若同色 4-邻居个数 < 2，将该像素视为噪声并擦除为黑(0)。
3. 擦除后的图案区域即为净化后的周期种子，高度仍为 H 行。
4. 将种子图案向上周期重复：对网格中第 r 行第 c 列的像素，其值等于种子图案中第 (r mod H) 行第 c 列的像素值。这里 r mod H 的计算使得底部原始种子区域的位置保持不变（即种子区域的第一行对应 r mod H = 种子区域起始行 mod H）。
5. 输出完整的铺满后网格，尺寸与输入相同。

**关键洞察**：噪声与真实图案使用不同颜色（噪声为黄(4)，图案为红(2)和蓝(1)），但这一颜色分离规律需要对比多个示例才能确认——单个示例中可能被误认为黄(4)是图案的一部分。邻接支撑过滤提供了颜色无关的结构判据，与颜色分离形成冗余线索，增加了推理的可靠性。
