## 新题 1：缺失交叉点定义镜像轴的格子重涂

**组合逻辑**：[缺失交叉点定位](已有，创新：从裁剪标记改为对称轴标记) + [镜像](已有，创新：作用于格子内容而非整体场景) + [计数比较](创新：判定稀疏侧方向) + [重涂色](已有)

**来源原语**：缺失交叉点/背景色空洞(a644e277), 网格线(a644e277), 镜像/镜像对称(dc0a314f), 重涂色/按控制色重涂(33b52de3), 行列位置对应(33b52de3), 计数(1190e5a7)

**依赖链**：缺失交叉点的位置决定镜像轴方向 → 镜像轴将格子划分为两组对称配对 → 对每组配对统计前景像素数确定哪侧为"稀疏侧" → 稀疏侧格子的内容被其镜像配对格子的内容覆盖重涂

用一行格子内容的镜像修复来填补另一行缺失的图案，修复方向由格线缺口位置和前景密度共同决定。

**输入结构**：约 15x15 的网格。灰(5)色单像素宽的横纵直线构成规则格子，将网格划分为若干等大矩形单元（每个单元约 3x3），背景为黑(0)。每个单元内含有一个由某种颜色（蓝(1)、红(2)、绿(3)、橙(7)中的一种或多种）绘制的小图案（2~4 像素的 4-连通图形，不同单元的图案形状不必相同）。恰好有 2 个格线交叉点被替换为黑(0)背景色（即"缺失交叉点"）。这 2 个缺失交叉点始终位于同一条格线上（同一行格线或同一列格线），使得它们的连线定义一条水平或垂直的对称轴。对称轴将所有单元分为两组，每组单元数量相等。生成约束：对称轴一侧的单元全部包含图案（"密侧"），另一侧至少有一个单元为空或图案像素明显更少（"疏侧"），以确保密度方向无歧义。

**规则**：
1. 识别灰(5)格线结构，找到 2 个缺失交叉点（格线上应为灰(5)却为黑(0)的位置）。
2. 两个缺失交叉点必然位于同一行格线或同一列格线上，将该格线作为镜像对称轴。
3. 对称轴将单元格划分为两组。对于轴两侧的每对镜像配对单元，统计各自的前景（非黑非灰）像素数。前景像素总数较少的一侧为"疏侧"。
4. 将疏侧每个单元的内容替换为其镜像配对单元内容的镜像翻转（沿对称轴方向翻转，即轴为水平线时上下翻转，轴为垂直线时左右翻转），颜色保持不变。
5. 密侧单元、格线（包括缺失交叉点位置，保持黑(0)）及背景均不变。

**关键洞察**：缺失交叉点在源题中标记裁剪角点，此处创新为标记对称轴；解题者必须先从缺口推断轴方向，再判断哪侧需要修复——单看一个示例可能猜错修复方向，需对比多个示例才能归纳出"疏侧被密侧覆盖"的规则。

## 新题 2：射线分割区域内的隐含十字检测与选择性保留

**组合逻辑**：[隐含十字检测/缺失中心标记](已有) → [射线延伸/射线分割](已有，创新：射线从边界控制像素发出，穿越含微型条的区域) → [切割/边界归属保留](已有，创新：保留判据结合了检测结果)

**来源原语**：射线延伸/行列对齐(99fa7670), 切割/射线分割区域/边界归属决定保留(4a21e3da), 重涂色/缺失中心(9f5f939b), 微型条/隐含十字/四向对齐(9f5f939b), 控制像素(4a21e3da)

**依赖链**：先在全局检测隐含十字并标记中心 → 控制像素发射射线将网格分割为区域 → 仅保留与控制像素同侧边界相邻的区域 → 保留区域中的十字中心标记和原始微型条一起留在输出中，其余区域清空

检测散布微型条构成的隐含十字中心，然后用边缘射线裁出包含这些中心的局部区域。

**输入结构**：约 14x14 的网格，黑(0)背景。蓝(1)的水平和垂直二像素条（微型条）散布在网格内部，总数约 15~25 个。其中部分微型条在四个基方向上围绕某个空白中心排列（中心与每根条之间隔 1 像素），形成 2~3 个隐含十字结构。另有若干微型条不属于任何十字结构（孤立条）。网格的一条边缘（上/下/左/右之一）上放置 1~2 个红(2)控制像素。生成约束：每个控制像素发射的射线（沿其所在行或列向网格内部延伸）将网格分为 2~3 个区域；至少一个包含隐含十字中心的区域与控制像素同侧边界相邻，至少一个不相邻。射线仅穿越黑(0)背景像素；遇到蓝(1)微型条像素时跳过（射线不覆盖该像素，继续向前）。

**规则**：
1. 检测所有隐含十字中心：对每个黑(0)背景像素，检查在上、下、左、右四个方向的偏移 2~3 格处是否各有一根方向匹配的蓝(1)二像素条。如果四个方向均满足，将该中心像素标记为黄(4)。
2. 从每个红(2)控制像素沿其所在行（若在上/下边缘）或列（若在左/右边缘）向网格内部发射射线。射线在黑(0)背景像素上涂红(2)，遇到蓝(1)像素时跳过该像素不涂色但继续前进，直至到达对面边界。
3. 射线将网格分割为若干区域。与控制像素所在边界直接相邻的区域为"保留区域"，其余区域为"清除区域"。
4. 输出中，保留区域内的所有像素（蓝(1)微型条、黄(4)十字中心、红(2)射线像素、黑(0)背景）原样保留。清除区域内的所有像素设为黑(0)背景。
5. 处理顺序：先标记十字中心（步骤 1），再绘制射线（步骤 2），最后执行区域裁切（步骤 3-4）。射线像素在保留区域中可见。

**关键洞察**：检测操作和分割操作作用于同一批微型条，但目的完全不同——检测将微型条视为十字信号的组成部分，分割将它们视为射线的障碍物。解题者须意识到同一元素在两条逻辑链中承担不同角色：构成十字 vs. 阻挡射线。射线跳过微型条的行为需要对比多个示例才能归纳（部分示例中射线路径上无微型条，无法单独发现此规则）。

## 新题 3：条纹类型选择双重涂色策略

**组合逻辑**：[条纹传播/颜色循环](已有) → [条纹类型→选择分支](创新：条纹颜色不只是涂色结果，而是选择后续操作的判据) → [索引映射/按控制色重涂](已有，仅在特定条纹类型下激活) / [统一重涂](已有，在另一条纹类型下激活)

**来源原语**：条纹传播/颜色循环/条纹范围差异(221dfab4), 边界线段(221dfab4), 索引映射/行列位置对应/按控制色重涂(33b52de3), 控制矩阵/模板格点/模板对象(33b52de3)

**依赖链**：边界线段发起条纹传播，产生交替的两类条纹 → 每类条纹激活不同的重涂策略 → 黄条纹行/列的模板对象按控制矩阵对应位置的颜色重涂 → 绿条纹行/列的模板对象统一涂绿，忽略控制矩阵

根据条纹传播产生的周期颜色，对模板阵列中的对象分别施以"查表涂色"或"一律涂绿"两种策略。

**输入结构**：约 17x17 的网格，黑(0)背景。网格中存在一个 4x4 的模板格点阵列：16 个相同的灰(5)模板对象（每个为 3x3 边界框内的 4-连通图形，3~6 个前景像素，可含孔洞），相邻模板之间隔 1 列/行背景。在网格上边缘有一段黄(4)水平线段（宽度 2~4 像素）。在网格左下角有一个 4x4 的控制矩阵，每个像素为蓝(1)、红(2)、橙(7)、栗(9)中的某种颜色，共 16 个像素，与 4x4 模板阵列一一对应（控制矩阵第 i 行第 j 列对应模板阵列第 i 行第 j 列）。生成约束：黄线段的水平位置覆盖模板阵列的某几列（不必全覆盖）；条纹传播方向为从上往下；模板阵列的行间距足够使得至少一行模板被黄条纹覆盖、至少一行被绿条纹覆盖、至少一行不被任何条纹覆盖。

**规则**：
1. 从上边缘的黄(4)线段向下传播条纹，步长为 2（每条条纹占 1 行，条纹间隔 1 行背景），颜色按周期循环：黄(4)、黄(4)、绿(3)、黄(4)、黄(4)、绿(3)...
2. 黄条纹仅在线段的水平跨度范围内绘制（不超出线段左右边界）。绿条纹则横跨整行。
3. 判定每个模板对象的"条纹状态"：如果模板对象的中心行（边界框垂直中间行）被某条条纹覆盖，则该模板处于该颜色条纹状态。否则为"无条纹"状态。
4. 黄条纹状态的模板对象：查找控制矩阵中对应位置的颜色，将该模板的所有灰(5)前景像素重涂为该颜色。
5. 绿条纹状态的模板对象：将所有灰(5)前景像素统一重涂为绿(3)，不查控制矩阵。
6. 无条纹状态的模板对象：保持灰(5)不变。
7. 控制矩阵本身、黄线段、条纹像素（落在非模板区域的条纹）保持不变。

**关键洞察**：条纹的颜色不只是视觉装饰，它充当了一个选择器，在两种完全不同的重涂逻辑之间做路由——黄条纹触发"个性化查表涂色"，绿条纹触发"无差别统一涂色"。解题者需要先发现条纹传播规则，再发现条纹颜色与涂色策略的对应关系，最后才能理解控制矩阵的作用范围。仅看单个示例无法区分"黄条纹也统一涂某色"还是"黄条纹查表涂色"，必须对比多个示例中黄条纹行的模板颜色差异。

## 新题 4：最近扩散色谱被镜像位置索引

**组合逻辑**：[最近扩散/种子分区](已有) + [镜像](已有，创新：镜像确定的位置作为色谱索引) + [分隔线两侧](已有，创新：分隔线两侧执行完全不同的操作类型)

**来源原语**：最近扩散/最近种子分区/等距异色为分隔(332202d5), 种子条/标记列(332202d5), 镜像/邻接/标记侧翻转且变色(2bcee788), 标记像素/前景对象(2bcee788), 分隔线/分隔线两侧(05a7bcf2)

**依赖链**：分隔线将网格分为上下两区 → 上区执行最近扩散，为每行生成一个颜色值 → 下区执行镜像翻转，确定镜像副本的位置 → 镜像副本的颜色不继承原对象颜色，而是取其中心行对应的上区扩散颜色

上半区的种子条扩散形成按行分布的色谱；下半区的小对象镜像产生副本，但副本颜色由其所在行在色谱中的查找结果决定。

**输入结构**：约 13x18 的网格（宽 13，高 18），黑(0)背景。一条灰(5)水平分隔线横贯全宽，将网格分为上区（约 8 行）和下区（约 9 行）。上区包含 2~3 条全宽水平种子条，每条种子条为单一颜色（从蓝(1)、红(2)、绿(3)、橙(7)中选取，各不相同），其余行为黑(0)背景。上区左侧第一列为标记列：种子条行的标记列像素为品红(6)，背景行的标记列像素为黄(4)。下区包含一个约 3x3~5x5 的 4-连通单色前景对象（颜色为灰(5)），以及一个与该对象某侧相邻的红(2)标记像素（1 个像素）。生成约束：下区对象的位置使得镜像后副本不超出网格边界；镜像副本中心行对应上区某个已确定颜色的行（非等距分隔行）。

**规则**：
1. 识别灰(5)水平分隔线，将网格分为上区和下区。
2. 上区最近扩散：每个非种子行取最近种子条的颜色，标记列像素规则与源题(332202d5)相同（详见下文）。若某行等距于两条不同颜色的种子条，该行整行设为品红(6)（分隔行）。种子条行自身保持种子颜色，但标记列像素改为黄(4)。
3. 下区镜像：找到红(2)标记像素相邻的前景对象侧面（上/下/左/右），沿该侧外缘设置镜像轴，将前景对象反射到轴另一侧生成副本。
4. 镜像副本的颜色确定：找到副本边界框的垂直中心行，将该行号映射到上区对应行号（下区第 k 行对应上区第 k 行，若上区行数不足则对应上区最后一行）。副本的所有前景像素涂为上区该行的扩散结果颜色。若对应行为品红(6)分隔行，则副本涂品红(6)。
5. 原前景对象保持灰(5)不变。红(2)标记像素被副本覆盖时，副本优先。
6. 下区的黑(0)背景保持不变（不涂绿）。

**关键洞察**：镜像操作的空间结果（副本的位置）并非只决定"在哪画"，它同时是一把钥匙，索引到另一个独立操作（最近扩散）的输出中去取颜色。两个操作在分隔线两侧各自独立运行，但通过行号映射形成跨区耦合。解题者需要发现颜色不来自原对象也不来自标记，而来自副本位置与上区色谱的对应关系——这需要在多个示例中对比副本颜色与上区行颜色后才能归纳。

## 新题 5：隐含十字中心驱动距离递变楔形生成与孤立条擦除

**组合逻辑**：[隐含十字检测/缺失中心](已有) → [距离递变/填充/三角楔形](已有，创新：锚点不是给定的线段而是检测出的隐含中心) → [擦除](已有，创新：擦除判据来自检测结果的反面——未构成十字的条) + [冲突解决](创新：楔形与原有微型条重叠时的优先级规则)

**来源原语**：重涂色/缺失中心(9f5f939b), 微型条/隐含十字/四向对齐(9f5f939b), 填充/距离递变/逐行宽度递变成楔(a65b410d), 三角楔形/线段(a65b410d), 擦除(47c1f68c/31aa019c)

**依赖链**：检测隐含十字 → 中心标记为黄(4)并成为楔形锚点 → 从每个锚点向上下扩展距离递变楔形 → 楔形基宽由该十字的水平臂跨度决定 → 未参与任何十字结构的孤立微型条被擦除 → 楔形像素与十字微型条像素重叠时，微型条优先保留

检测微型条构成的隐含十字，以中心为锚生长楔形区域，同时清除不属于任何十字的孤立条。

**输入结构**：约 15x15 的网格，黑(0)背景。蓝(1)的水平和垂直二像素微型条散布在网格中，总数约 18~30 个。其中若干条在四个基方向上围绕空白中心排列（中心与条之间隔 1 像素），形成 2~4 个隐含十字。剩余微型条不属于任何十字（孤立条）。生成约束：不同十字中心之间至少相隔 5 行，使各自的楔形区域不完全重叠；每个十字的水平臂（左右各一条水平微型条）总跨度为 6 像素（中心 1 + 间隔 1 + 条 2 + 间隔 1 + 条 2 - 1 = 6，含中心）。若两个十字的楔形确有部分重叠，按先上后下、先左后右的锚点处理顺序处理，后处理的楔形不覆盖已有非黑非蓝像素。

**规则**：
1. 检测所有隐含十字中心：对每个黑(0)像素，检查上、下、左、右偏移 2~3 格处是否各有一根方向匹配的蓝(1)二像素条（水平条在左右，垂直条在上下）。四个方向均满足则标记该中心为黄(4)。
2. 对每个检测到的黄(4)中心，计算其水平臂总跨度 W（左侧水平条最左像素到右侧水平条最右像素的距离 +1）。W 即为楔形基宽。
3. 从中心向上生长绿(3)楔形：中心行宽度为 W，向上每行宽度 +1（左右各扩 0.5 取整，交替扩左/扩右），直到宽度达到网格宽度或碰到网格上边界时停止。楔形水平居中于中心列。
4. 从中心向下生长栗(9)楔形：中心行宽度为 W，向下每行宽度 -1（左右各缩 0.5 取整，交替缩左/缩右），直到宽度缩为 0 时停止。楔形水平居中于中心列。
5. 识别所有未参与任何隐含十字结构的蓝(1)微型条（即既不是某十字的水平臂也不是某十字的垂直臂），将这些孤立条的像素设为黑(0)。
6. 冲突解决：参与十字的蓝(1)微型条像素优先于楔形像素（楔形不覆盖蓝(1)）。黄(4)中心像素优先于一切。多个楔形重叠时，锚点行号较小（靠上）的楔形优先；行号相同则列号较小（靠左）的优先。

**关键洞察**：同一批微型条在逻辑中承担双重身份——构成十字的条提供检测信号并决定楔形参数，不构成十字的条则被擦除。检测结果同时驱动"建造什么"（楔形）和"拆除什么"（孤立条），这种对称的生灭逻辑在源题中不存在。解题者必须先发现哪些条属于十字、哪些不属于，才能同时理解楔形的来源和条的消失规律。

## 新题 6：跨尺度异或合成与频率定位框选

**组合逻辑**：[形状匹配/跨尺度同形](已有，创新：匹配后不裁剪返回，而是用于生成对齐掩码) → [异或合成/恰一为前景](已有，创新：两个掩码不是空间对齐的半区，而是通过缩放对齐) → [频率唯一性/最低频色定位](已有，创新：频率分析作用于异或结果而非原始输入) → [描边/框](已有)

**来源原语**：形状匹配/跨尺度同形/返回较小者(ce602527), 缩放对象/干扰对象(ce602527), 异或合成/对齐/恰一为前景(31d5ba1a), 前景掩码/半区掩码(31d5ba1a), 计数/频率唯一性/最低频色定位目标(31aa019c), 描边/框(31aa019c)

**依赖链**：在三个对象中匹配跨尺度同形对 → 将较小对象放大至与较大对象同尺寸 → 两个同尺寸掩码执行异或合成 → 异或结果中存在多种颜色区域(来自两个对象的不同原色) → 统计异或结果中各颜色的像素数量 → 频率最低的颜色像素位置被框选输出

找到跨尺度匹配的形状对，将小形状放大后与大形状异或，在差异区域中定位出现频率最低的颜色并用框标记。

**输入结构**：约 16x16 的网格，黑(0)背景。包含三个不同颜色的 4-连通前景对象：对象 A 为蓝(1)，较大（约 6x6 边界框内的不规则图形）；对象 B 为绿(3)，较小（约 3x3 边界框），与对象 A 形状相同但缩小 2 倍；对象 C 为橙(7)，与 A、B 形状均不同（干扰对象）。三个对象互不相邻，各自独立。生成约束：对象 A 和 B 的形状在 2 倍缩放下完全匹配（B 放大 2 倍后与 A 的掩码逐像素一致，忽略颜色）；对象 A 允许部分超出画布边界（被裁剪），此时 B 放大后同样在对应位置裁剪；对象 A 和 B 的形状差异（若 A 被裁剪导致掩码不完全对称）使异或结果中至少有一个颜色的像素数明显少于另一个。

**规则**：
1. 将三个对象按颜色分离。尝试对每对对象进行缩放匹配（将较小者放大 2 倍），找到掩码完全匹配的一对（A 和 B）。
2. 将较小对象 B 放大 2 倍，对齐到对象 A 的边界框左上角。放大后的 B 掩码中前景像素保持绿(3)。
3. 在对象 A 的边界框范围内执行异或合成：仅 A 有前景的位置输出蓝(1)，仅放大 B 有前景的位置输出绿(3)，两者都有或都没有的位置输出黑(0)。
4. 统计异或结果中蓝(1)和绿(3)像素的数量。找到数量较少的那种颜色（频率最低色）。
5. 输出：在与输入同尺寸的黑(0)网格上，找到所有频率最低色像素的位置（这些位置在原始输入中属于对象 A 的边界框区域），对每个这样的像素用红(2)绘制 3x3 框（该像素为中心，周围 8 格涂红(2)，中心像素保持其异或结果颜色）。框超出网格边界的部分舍弃。多个框重叠时红(2)简单叠加（不影响，因为都是红(2)）。
6. 干扰对象 C 不出现在输出中。

**关键洞察**：跨尺度匹配在源题中用于选择并裁剪返回较小者，此处创新为用匹配生成对齐条件以进行异或合成——匹配不再是终点而是中间步骤。异或合成在源题中作用于空间对齐的两半，此处作用于通过缩放对齐的两个对象。频率分析在源题中作用于原始输入，此处作用于异或合成的计算结果。三个来自不同源题的原语形成了一条全新的信息传递链：匹配→缩放对齐→异或→频率分析→框选。
