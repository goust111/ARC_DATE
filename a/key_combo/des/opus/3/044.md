## 新题 1：蛇形路径的周期补全

**组合逻辑**：[展直(straighten)] + [补全(completion)](创新：从 2D 蛇形路径拉直为 1D 序列后在 1D 空间推断周期并回填) + [周期瓦片推断(periodic_tile inference)](创新：周期推断的对象不是 2D 网格平铺而是 1D 遍历序列)

**来源原语**：展直/蛇形路径/端点/遍历顺序(traversal_order) ← 7b5033c1；补全/标记为缺失值(markers_missing_val)/周期瓦片/行列周期(row_col_period) ← f823c43c；标记像素(marker_pixel) ← f823c43c

**依赖链**：必须先确定蛇形路径的遍历方向（从哪个端点出发），才能将 2D 像素拉直为 1D 序列；拉直后才能识别 1D 周期；推断出周期后才能填补缺失位置的颜色；填补后必须沿蛇形路径反向映射回 2D 坐标。四步之间任何一步被跳过都无法得到正确输出。

将蛇形路径拉直为一维序列，推断序列中的颜色周期，补全被标记遮蔽的位置，再将修正后的颜色写回二维蛇形位置。

**输入结构**：约 12x12 至 16x16 的网格，黑(0)背景。网格中有一条由非背景像素组成的 4-连通蛇形路径，路径无分叉，恰好有两个端点（仅一个路径邻居的像素）。路径像素使用 2-3 种非背景颜色（如蓝(1)、红(2)、绿(3)）形成周期性排列，同时部分路径位置被灰(5)像素替代作为缺失标记。蛇形路径在网格中弯曲折返，肉眼难以直接看出周期。不同示例中蛇形路径的弯折方式、长度和周期长度均不同。生成约束：灰(5)标记不会连续出现超过周期长度减一个位置，以保证周期可从非标记像素唯一推断。

**规则**：
1. 找到蛇形路径的两个端点（仅有一个 4-连通路径邻居的像素）
2. 从行号更小的端点开始遍历；若行号相同，从列号更小的端点开始（即"左上优先"）。沿路径逐像素遍历，生成一维颜色序列
3. 在一维序列中，将灰(5)视为未知值，从剩余已知颜色像素中推断最短重复周期 P：对于每个候选周期长度 P，检查所有非灰位置 i 是否满足 color[i] = color[i mod P]（仅在 color[i mod P] 位有已知值时比较）。取满足条件的最小 P
4. 用推断出的周期填补所有灰(5)位置：将位置 i 的颜色设为周期中第 (i mod P) 个位置的颜色
5. 将修正后的一维序列沿遍历路径依次写回对应的二维网格坐标，替换原有颜色（包括将灰标记替换为正确颜色）
6. 网格中蛇形路径以外的所有像素保持不变

**关键洞察**：蛇形路径的空间弯折与周期无关——只有沿路径遍历的一维顺序才决定周期相位。必须在心里"拉直"蛇形后才能发现颜色规律。

## 新题 2：尺寸分类门控的指示像素重涂

**组合逻辑**：[计数(counting)] + [尺寸分类(size_classification)](创新：分类结果不直接决定重涂色，而是建立"同类一致性"约束) → [重涂色(recolor) / 擦除(erase)](创新：重涂或擦除取决于全局一致性判定，而非局部属性)

**来源原语**：连通分量(connected_component)/尺寸分类(size_classification)/单像素分量重涂(single_pixel_component_recolored) ← aedd82e4；指示像素(indicator_pixel)/邻接(adjacency)/指示定镜像与色(indicator_sets_axis_color) ← b775ac94；计数(counting) ← 37ce87bb；擦除(erase) ← 782b5218

**依赖链**：需要先识别所有连通分量并按像素数分组（尺寸分类）；再为每个分量收集其相邻指示像素的颜色；然后在同一尺寸组内检查所有分量的指示颜色是否一致——这是一个全局判定，单个分量无法独立完成。一致则整组重涂，不一致则整组擦除。分类、指示收集、一致性判定三步紧密耦合。

根据连通分量的像素数将其分组，若同组内所有分量的指示像素颜色一致则整组重涂为该颜色，否则整组擦除。

**输入结构**：约 12x12 至 15x15 的网格，黑(0)背景。网格中有 4-8 个红(2)色的 4-连通分量，每个分量包含 2-8 个像素，形状各异（无固定形状名，可为任意不规则连通结构）。网格中还散布着单像素的指示点，颜色为蓝(1)、绿(3)、黄(4)等非红非黑颜色。每个指示像素恰好与一个红色分量 4-邻接（不会同时邻接两个分量）。每个红色分量至少有一个指示像素邻接。不同示例中分量数量、大小分布和指示颜色分配不同。生成约束：至少存在一个尺寸组包含两个以上分量，且至少一个组的指示颜色一致、至少一个组不一致，以展示两种结果。

**规则**：
1. 识别网格中所有 4-连通的红(2)色分量，记录每个分量的像素数
2. 按像素数分组：像素数相同的分量归为同一"尺寸组"
3. 对每个红色分量，收集所有 4-邻接的单像素指示点的颜色集合
4. 对每个尺寸组进行一致性检查：收集该组内所有分量的所有指示像素颜色，若全部为同一颜色 C，则该组"一致"
5. 一致的组：将组内所有红色分量的像素重涂为颜色 C
6. 不一致的组（组内存在不同颜色的指示像素）：将组内所有红色分量的像素擦除为黑(0)
7. 所有指示像素（单像素点）在输出中均擦除为黑(0)

**关键洞察**：决定一个分量是被重涂还是被擦除，不取决于它自身的指示颜色，而取决于与它同尺寸的所有分量的指示颜色是否一致。一个分量可能有完全明确的指示颜色，却因为同组另一个分量的指示颜色不同而被擦除。

## 新题 3：象限并集推断模板印章

**组合逻辑**：[透明叠加(transparent_overlay) / 像素并集(pixel_union)](创新：并集的目的不是产生最终输出，而是推断隐藏的完整形状) → [印章覆盖(stamp_overlay)] + [重涂色(recolor)](创新：推断出的形状反向广播回各象限，每个象限用自身颜色着色)

**来源原语**：分隔十字(separator_cross)/象限区(quadrant)/透明叠加(transparent_overlay)/非背景优先合并(nonbackground_priority_merge)/层级优先(layer_priority) ← a68b268e；印章覆盖(stamp_overlay)/精灵体(sprite)/重涂色(recolor) ← 94be5b80；像素并集(pixel_union) ← fea12743

**依赖链**：任何单个象限只包含目标形状的部分像素，无法独立得知完整形状；必须对四个象限做像素并集才能重建完整形状掩码；重建后必须将完整掩码印回每个象限并用该象限的专属颜色着色。推断（并集）和应用（印章+重涂）紧密耦合，且推断本身依赖所有象限的信息。

将四个象限中各自不完整的同形状碎片通过像素并集重建完整形状，再将完整形状以各象限自身的颜色印回每个象限。

**输入结构**：奇数边长的网格（如 9x9、11x11、13x13），由一行灰(5)像素和一列灰(5)像素构成十字分隔线，将网格分成四个等大的象限。每个象限包含若干前景像素，颜色各不相同：左上=蓝(1)，右上=红(2)，左下=绿(3)，右下=黄(4)。四个象限的前景像素是同一个底层形状掩码的不同子集——每个象限只显示该形状的一部分像素（2-5 个像素），没有任何单个象限包含完整形状。底层形状为一个 4-连通或 8-连通的小图形（总像素数约 4-8），在象限坐标系下占据相同位置范围。不同示例中底层形状和各象限的子集划分方式不同。生成约束：四个子集的并集恰好等于完整形状（无遗漏），且任意三个子集的并集严格小于完整形状（每个象限至少贡献一个独有像素）。

**规则**：
1. 裁剪出四个象限（不含灰色分隔线），得到四个等大的子网格
2. 对四个子网格逐像素计算并集掩码：若某位置在任何象限中有非背景像素，则该位置属于完整形状掩码
3. 对每个象限，将完整形状掩码印入该象限，所有掩码内的像素统一着色为该象限的原始前景色（蓝/红/绿/黄）；掩码外的像素保持黑(0)
4. 将四个完成后的象限与灰色分隔十字重新组装为输出网格
5. 分隔十字保持灰(5)不变

**关键洞察**：每个象限只是同一形状的"部分证据"，完整形状只能通过四象限并集推断。这不是简单的叠加输出——并集是中间推断步骤，最终每个象限要独立展示完整形状的单色版本。

## 新题 4：走廊路径的符号累积计数

**组合逻辑**：[路径追踪(path_trace)](创新：路径追踪不仅产生终点位置，还沿途累积符号化计数值) + [计数(counting) / 颜色编码正负(color_encodes_sign)](创新：走廊壁色在引导粒子运动的同时编码正负符号，双重功能) → [填充(fill)](创新：累积值决定输出条的高度和颜色)

**来源原语**：路径追踪(path_trace)/粒子(particle)/走廊(corridor)/平行色条(parallel_colored_bar)/同色夹道(same_color_flanking)/碰撞转向(collision_turn)/碰撞停止(collision_stop) ← 9bbf930d；计数(counting)/柱状条(vertical_bar)/结果槽(result_slot)/颜色编码正负(color_encodes_sign)/高度加减运算(height_arithmetic) ← 37ce87bb

**依赖链**：粒子在走廊中行进时，走廊壁色同时决定了运动方向（碰撞转向规则）和累积的正负值（青色+1/红色-1）。路径未完成前无法得知累积值，累积值又决定了输出柱状条的高度和颜色。走廊壁色的"运动引导"功能和"算术编码"功能是同一结构的两面，不可分割。

粒子沿走廊追踪路径，在经过青色走廊时累加、经过红色走廊时累减，最终累积值决定结果槽中柱状条的高度和颜色。

**输入结构**：约 15x20 的网格，橙(7)背景。品红(6)粒子像素位于第 0 列，每个奇数行至多一个粒子（共 2-4 个粒子）。偶数行上有水平色条（青(8)或红(2)），色条之间有间隙，使得相邻偶数行的同色色条在奇数行形成走廊（奇数行的某些列两侧被同色条夹住）。最右侧一列为空白（仅背景色），作为结果槽。粒子初始朝右移动。不同示例中色条的位置、颜色分配和粒子数量不同。生成约束：每个粒子的路径最终会因到达网格边界或完全被阻挡而停止；各粒子的路径互不交叉。

**规则**：
1. 每个品红(6)粒子从其在第 0 列的位置出发，朝右移动
2. 粒子在背景色(橙(7))格子中直行；当前方被色条像素阻挡时，粒子尝试 90 度转向——转入垂直方向上由同色色条夹住的走廊（即上下相邻偶数行有同色条的那个方向）
3. 粒子到达网格边缘或所有方向均被阻挡时停止
4. 在追踪过程中计数：粒子每经过一个被青(8)色条夹住的走廊格子，累积值 +1；每经过一个被红(2)色条夹住的走廊格子，累积值 -1；经过无色条夹住的背景格子不计数
5. 追踪结束后，在结果槽列（最右列）绘制柱状条：从粒子起始行向下填充 |累积值| 个格子。若累积值 > 0，填青(8)；若累积值 < 0，填红(2)；若累积值 = 0，不填
6. 擦除所有品红(6)粒子像素为背景色；其余所有像素（色条、背景）保持不变
7. 若两个粒子的柱状条在结果槽中有重叠格子，后处理的粒子（起始行号更大的）覆盖先处理的

**关键洞察**：走廊的壁色承担双重角色——它既是碰撞转向规则中引导粒子运动方向的物理墙壁，又是算术累积中编码正负符号的语义标签。这两个功能在同一结构上不可分离。

## 新题 5：最大矩形锚定对称轴与标记穿透填充

**组合逻辑**：[定位(locate) / 最大实心矩形(largest_solid_rect)](创新：矩形不是被填充的目标，而是为其他操作定义参考系) → [对称补全(symmetry_complete) / 双轴对称(biaxial_symmetry)](创新：对称轴由矩形中心决定，不由输入中的显式十字线定义) → [填充(fill) / 保留边框填内部(keep_border_fill_in)](创新：填充必须避开对称补全后的标记像素)

**来源原语**：最大实心矩形(largest_solid_rect)/边框(border)/保留边框填内部(keep_border_fill_in)/忽略干扰项(ignore_distractors) ← e88171ec；对称补全(symmetry_complete)/稀疏标记(sparse_marker)/双轴对称(biaxial_symmetry)/四象限镜像填充(quadrant_mirror) ← 60d73be6；填充(fill) ← 37ce87bb

**依赖链**：必须先找到最大矩形（定位）来确定对称轴中心；有了轴才能做标记的双轴对称补全；补全后的标记位置影响了填充的结果（标记处不填），三步形成不可跳过的链。矩形的角色从"被操作对象"变为"元信息提供者"，这是源题中不存在的结构关系。

找到最大灰色矩形以其中心为对称轴，将散布的彩色标记做双轴反射补全，最后用青色填充矩形内部但保留标记像素不被覆盖。

**输入结构**：约 15x15 的网格，黑(0)背景。网格中有一个较大的实心灰(5)矩形（至少 5x5，边长为奇数以保证中心点唯一），位置不固定。网格中散布着若干单像素的彩色标记点（红(2)、蓝(1)、绿(3)），有些在矩形内部，有些在矩形外部。标记点不位于矩形的边框像素上。标记点的分布不对称。不同示例中矩形的大小和位置不同，标记点的颜色、数量和位置也不同。生成约束：矩形是网格中唯一的最大实心同色矩形（无歧义）；矩形边长为奇数；标记点不位于矩形中心的水平和垂直轴线上（避免反射到自身）。

**规则**：
1. 找到网格中面积最大的实心灰(5)矩形
2. 计算该矩形的中心点坐标 (cr, cc)，以此定义水平对称轴（行=cr）和垂直对称轴（列=cc）
3. 对网格中每个彩色标记像素（非黑非灰），执行双轴反射：
   - 关于水平轴反射：(r, c) → (2*cr - r, c)
   - 关于垂直轴反射：(r, c) → (r, 2*cc - c)
   - 关于两轴同时反射：(r, c) → (2*cr - r, 2*cc - c)
   - 每个反射位置放置与原标记相同颜色的像素
   - 落在网格外的反射位置丢弃
4. 保留灰(5)矩形的 1 像素宽边框不变
5. 将矩形严格内部（不含边框）的所有非标记像素填充为青(8)
   - 已有的原始标记和反射生成的标记保留其颜色，不被青色覆盖
6. 矩形外部的标记和反射标记保持原色，矩形外部的黑色背景不变

**关键洞察**：最大矩形本身不是变换的对象——它提供对称轴的位置。对称轴不是输入中画出的显式线条，而是从矩形几何隐含推导的。这意味着在不同示例中矩形位置不同，对称轴也随之移动，必须对比多个示例才能发现"轴随矩形走"的规则。

## 新题 6：自模板放大中的分量角色分裂

**组合逻辑**：[尺寸分类(size_classification)](创新：分类结果不是决定重涂颜色，而是分配功能角色——"模板"与"种子") → [像素放大(pixel_upscale) / 自身为模板(self_as_stencil)](创新：只有多像素分量构成模板形状，单像素分量借用模板形状但施加自己的颜色) + [重涂色(recolor)]

**来源原语**：像素放大(pixel_upscale)/自身为模板(self_as_stencil)/非背景处印章(stamp_at_nonbg) ← 007bbfb7；孤立像素(isolated_pixel)/连通分量(connected_component)/尺寸分类(size_classification)/单像素分量重涂(single_pixel_component_recolored) ← aedd82e4；重涂色(recolor)/精灵体(sprite) ← b775ac94

**依赖链**：必须先通过尺寸分类将前景像素分为"模板"和"种子"两个角色；模板角色决定了放大后印章的形状；种子角色决定了对应印章块的颜色覆盖。角色分配、形状确定和颜色覆盖三步不可跳过，且任何一步的结果都影响后续步骤的输入。

将小网格中的多像素分量作为印章模板、单像素分量作为颜色种子，执行自模板放大——模板位置印原色模板，种子位置印种子色模板。

**输入结构**：小网格（3x3 至 5x5），黑(0)背景。网格中有一个或多个由蓝(1)像素组成的 4-连通多像素分量（每个分量 2-5 个像素），构成"模板图案"。网格中还有若干孤立的单像素点，颜色各不相同（如红(2)、绿(3)、黄(4)），与多像素分量不相邻。不同示例中模板图案的形状和单像素点的位置/颜色不同。生成约束：多像素分量的总像素集合就是"模板掩码"；输出尺寸为 (输入高度 x 输入高度) x (输入宽度 x 输入宽度)。

**规则**：
1. 识别所有 4-连通前景分量，按像素数分为两类：
   - 多像素分量（像素数 >= 2）→ 角色="模板"
   - 单像素分量（像素数 = 1）→ 角色="种子"
2. 提取模板掩码：所有多像素分量的像素位置集合，保留原色蓝(1)
3. 创建输出网格，尺寸为 (H*H) x (W*W)，其中 H、W 为输入的高和宽
4. 将输出划分为 H x W 个子块，每个子块大小为 H x W，对应输入的一个像素位置
5. 对于输入中属于模板（多像素分量）的像素位置 (r,c)：将模板掩码以蓝(1)色印入对应输出子块
6. 对于输入中属于种子（单像素分量）的像素位置 (r,c)：将模板掩码印入对应输出子块，但颜色替换为该种子像素的颜色
7. 对于输入中为背景的像素位置 (r,c)：对应输出子块保持全黑(0)

**关键洞察**：单像素种子不印自己（一个点没有有意义的形状），而是借用多像素分量的形状来印章，同时把自己的颜色施加给借来的形状。输入中的尺寸差异不是用于重涂/保留的二分判断，而是用于"形状提供者 vs 颜色提供者"的角色分配。

## 新题 7：分隔墙镜像与角落优先解冲突

**组合逻辑**：[镜像(mirror)](创新：镜像轴不是显式画出的线而是分隔墙本身) + [洪泛填充(flood_fill) / 四连通分区(four_connected_partition)](创新：墙的移除时机影响填充结果) + [角落锚定(corner_anchor)](创新：从"选择哪一侧"变为"多个镜像源争夺同一空区时的优先级判定") + [擦除(erase)]

**来源原语**：镜像(mirror)/指示定镜像与色(indicator_sets_axis_color) ← b775ac94；分隔墙(divider_wall)/四连通分区(four_connected_partition)/角落锚定(corner_anchor) ← 782b5218；擦除(erase) ← 782b5218；层级优先(layer_priority) ← a68b268e

**依赖链**：必须先识别分区和各区的内容（空/非空）；非空区的图案需要镜像到相邻空区——但镜像轴由墙的位置和方向决定；当多个非空区都相邻同一空区时，角落优先规则决定谁的镜像胜出；最终墙被擦除，暴露合并后的图案。分区识别→镜像方向确定→冲突仲裁→墙擦除四步紧密耦合。

红色分隔墙将网格分为多个区域，非空区域的图案镜像到相邻空区域，多个图案争夺同一空区时由距左上角最近的源区获胜，最后擦除所有墙。

**输入结构**：约 12x12 至 14x14 的网格，黑(0)背景。红(2)像素构成分隔墙（水平和/或垂直线段），将网格分成 3-5 个 4-连通区域。部分区域包含小型单色图案（蓝(1)、绿(3)或黄(4)的 3-6 像素 4-连通图形），其他区域全黑（空区域）。非空区域的图案与墙之间至少隔 1 个黑色像素。每个空区域至少与一个非空区域共享墙段。不同示例中墙的布局、区域数量和图案形状不同。生成约束：墙严格为水平或垂直的直线段；至少有一个空区域同时与两个非空区域相邻，以测试优先级规则。

**规则**：
1. 将红(2)像素视为不可通行的墙，识别所有 4-连通区域
2. 将区域分为"非空区"（包含非黑非红像素的区域）和"空区"（全黑的区域）
3. 对每个空区，找到所有与其共享墙段的非空区域。对每个这样的非空区域，将其图案关于共享墙段所在直线做镜像翻转，生成候选镜像图案
4. 若空区仅有一个非空邻居：直接将镜像图案放入空区（镜像像素超出空区范围的部分丢弃）
5. 若空区有多个非空邻居：比较各非空区域中距网格左上角 (0,0) 最近的像素（以行优先的欧氏最小行号、再最小列号为准），距左上角最近的非空区域胜出，仅放置该区域的镜像图案
6. 所有空区处理完毕后，将所有红(2)墙像素擦除为黑(0)
7. 原有非空区域的图案保持不变

**关键洞察**：分隔墙既是物理隔断（定义区域）又是镜像轴（定义翻转方向）。冲突解决不依赖图案本身的任何属性，而依赖源区域的空间位置——一个看似更"合适"的图案可能因为它的源区域远离左上角而被淘汰。

## 新题 8：方位编码旋转与目标区域平铺

**组合逻辑**：[定位(locate) / 相对方位(relative_position)](创新：方位信息不选择目标内的槽位，而是编码旋转角度) → [旋转(rotate)](创新：旋转角度由空间方位隐式编码，而非显式标注) → [平铺(tiling)](创新：平铺的单元不是原始输入，而是经旋转变换后的图形)

**来源原语**：控制像素(control_pixel)/相对方位(relative_position)/方位决定槽位(position_selects_slot) ← 18286ef8；旋转(rotate)/交替旋转换色(alt_rotate_recolor) ← fd4b2b02；平铺(tiling)/周期瓦片(periodic_tile) ← f823c43c；边框(border)/保留边框填内部(keep_border_fill_in) ← e88171ec

**依赖链**：必须先判定控制像素相对于精灵体的方位（上/右/下/左），由此确定旋转角度；旋转后的精灵体才是平铺的单元；平铺的目标区域（红色边框内部）是独立于精灵体和控制像素的第三个元素。三者缺一不可：没有方位无法确定角度，没有旋转无法确定瓦片，没有目标区域无法确定平铺范围。

由控制像素相对精灵体的方位决定旋转角度，将旋转后的精灵体作为瓦片周期性平铺到红色边框内部。

**输入结构**：约 15x15 的网格，黑(0)背景。网格中有三类元素：(a) 一个由蓝(1)像素组成的小型非正方形 4-连通精灵体（3-6 像素，宽高不等以使旋转可见），位于网格某处；(b) 一个灰(5)单像素控制点，位于精灵体附近（不与精灵体邻接，但在精灵体包围盒外 1-3 格范围内）；(c) 一个由红(2)像素构成的 1 像素宽空心矩形边框，位于网格另一处，内部尺寸至少 5x5。精灵体和控制点不与红色边框重叠。不同示例中精灵体形状、控制点方位和边框位置/大小均不同。生成约束：控制点相对精灵体包围盒中心的偏移在水平和垂直方向上不等大（有明确的主方向）。

**规则**：
1. 计算灰(5)控制像素相对于蓝(1)精灵体包围盒中心的方位：
   - 若控制点在中心正上方（或偏移量中垂直分量为负且绝对值大于水平分量）：旋转 0 度（不旋转）
   - 若控制点在中心正右方（或偏移量中水平分量为正且绝对值大于垂直分量）：顺时针旋转 90 度
   - 若控制点在中心正下方（或偏移量中垂直分量为正且绝对值大于水平分量）：顺时针旋转 180 度
   - 若控制点在中心正左方（或偏移量中水平分量为负且绝对值大于垂直分量）：顺时针旋转 270 度
2. 将精灵体绕其包围盒中心旋转上述角度，得到旋转后的瓦片图案（保持蓝(1)色）
3. 找到红(2)边框矩形，确定其严格内部区域
4. 从内部区域的左上角开始，将旋转后的瓦片按行优先周期性平铺填满内部区域：
   - 瓦片包围盒按网格排列，行间距 = 瓦片高度，列间距 = 瓦片宽度
   - 超出内部区域右边界或下边界的瓦片做裁剪（仅绘制落在内部的部分）
5. 擦除原始精灵体和控制像素为黑(0)
6. 红(2)边框保持不变

**关键洞察**：控制像素既不移动也不改变任何对象的颜色——它通过自身的空间方位隐式编码了一个旋转角度。这个角度应用于精灵体后产生的旋转版本才是平铺的基本单元，而平铺的目标区域又是一个完全独立的结构。网格中三个功能区域（源形状、控制信号、目标容器）的协同才能确定输出。
