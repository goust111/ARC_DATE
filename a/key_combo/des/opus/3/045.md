## 新题 1：面积仲裁的透明带叠合

**组合逻辑**：[连通检测](已有) + [面积比较](已有) → [透明叠加](创新：固定优先替换为面积动态优先) + [等高带](已有)

**来源原语**：连通检测(#6 3194b014), 面积比较(#6/#16 67385a82), 透明叠加(#17 3d31c5b3), 等高带(#17 3d31c5b3), 折叠(#17 3d31c5b3)

**依赖链**：等高带切分提供待叠合的层 → 每层内连通检测为每个前景像素赋予其所属分量的面积 → 叠合时同一坐标上出现多色时，面积最大者胜出 → 若面积相同则取最上层。删掉连通检测则无法判定面积优先级；删掉叠合则无输出。

将等宽等高的四条彩色带按坐标对齐折叠为一条，但冲突像素不由带的编号顺序决定，而由该像素在原带中所属 4-连通分量的面积决定。

**输入结构**：约 24x6（即 4 条 6x6 等高带纵向拼成 24x6）的网格，背景黑(0)。网格被均分为四条等高的水平带，每条高 6 行。每条带内包含 1~3 个由单色前景像素构成的 4-连通图形（3~8 像素，形状各异，可含孔洞），前景色在四条带之间各不相同（从红(2)、蓝(1)、绿(3)、黄(4) 中选取，每条带恰好一种前景色）。不同带内的图形在同一局部坐标系下可能存在重叠。生成约束：至少存在两处局部坐标上有来自不同带的前景像素重叠，且重叠双方在各自带内所属分量的面积不同。

**规则**：
1. 将四条带视为共享同一坐标系的透明层，输出网格大小等于单条带的大小（6x6）。
2. 对每条带中的每个前景像素，计算该像素所属的 4-连通同色分量的面积（像素数量）。
3. 在输出的每个坐标位置上：若仅一条带在该坐标有前景像素，直接取该色；若多条带在该坐标均有前景像素，取所属分量面积最大者的颜色；若面积相等，取带编号最小（最上方的带编号为 1）的颜色。
4. 若所有四条带在该位置均为黑(0)，输出黑(0)。

**关键洞察**：叠合优先级不是固定的带顺序，而是由每条带内的局部连通结构决定的——同一条带内不同分量的面积不同，因此同一条带上的像素在不同位置可能具有不同的优先级。

## 新题 2：唯一分量门控的对角射线

**组合逻辑**：[连通检测 + 唯一连通分量](已有) → [筛选](已有) → [射线延伸 + 角对角对齐](创新：射线触发条件由外部框角改为颜色分量唯一性)

**来源原语**：连通检测(#6 3194b014), 唯一连通分量(#6 3194b014), 筛选(#6 3194b014), 射线延伸(#7 ec883f72), 角对角对齐(#7 ec883f72), 经过框角才延伸(#7 ec883f72), 空心矩形(#7 ec883f72), 实心矩形(#7 ec883f72)

**依赖链**：连通检测判定每种颜色的分量数 → 分量唯一的颜色通过筛选 → 仅通过筛选的实心矩形才参与射线延伸 → 射线方向由空心框角位置决定。删掉连通检测则无法筛选；删掉射线延伸则通过筛选的矩形无后续操作。

在含有多个同色矩形和一个空心框的网格中，先按分量唯一性筛选出"完整颜色"，再从对应矩形的角沿对角线穿过框角延伸射线。

**输入结构**：约 15x15 的网格，背景黑(0)。网格包含若干实心矩形（2x2 至 4x4），颜色从红(2)、蓝(1)、绿(3)、橙(7) 中选取。某些颜色恰好出现一个 4-连通分量（即该颜色的所有像素构成一个连通体），其他颜色的像素被分成多个不相连的碎片。另有一个灰(5) 的一像素宽空心矩形框（5x5 至 8x8），其四个角各为一个灰像素。每个"唯一分量"矩形至少有一个外角在对角方向上与框的某个角对齐（即矩形角与框角在同一条 45 度线上，中间全为背景）。生成约束：不同矩形的射线路径互不冲突；至少有一种颜色是碎片化的（分量数 >=2），至少有两种颜色是唯一分量的。

**规则**：
1. 对每种非背景、非灰(5) 的颜色，计算其 4-连通分量数。
2. 分量数恰为 1 的颜色标记为"合格色"；分量数 > 1 的颜色标记为"碎片色"。
3. 碎片色的所有像素在输出中保持不变（不删除也不添加），灰框保持不变。
4. 对每个合格色的实心矩形，检查其四个外角：若某外角沿外扩 45 度方向的射线上，第一个遇到的非背景像素是灰框的某个角像素，则从该框角像素开始，继续沿同一 45 度方向向外绘制该合格色的像素，直到到达网格边界。射线经过的像素（从框角之后开始，不含框角本身）全部涂为该合格色。
5. 不满足对齐条件的矩形角不发射射线。

**关键洞察**：碎片化颜色虽然总像素数可能更多，但因分量不唯一而被排除在射线操作之外；射线是否发射取决于分量唯一性和几何对齐的双重条件。

## 新题 3：点阵标记色编码旋转后居中

**组合逻辑**：[标记色编码距离](创新：编码旋转角度而非距离) → [旋转](已有) → [平移对齐 + 格元内居中](创新：居中依赖旋转后的新边界框)

**来源原语**：标记点阵(#10 20981f0e), 格元内居中(#10 20981f0e), 平移对齐(#10 20981f0e), 旋转(#8 103eff5b), 标记色编码距离(#12 72a961c9), 精灵图(#10 20981f0e), 格元(#10 20981f0e)

**依赖链**：标记色解码为旋转角度 → 旋转改变精灵图的边界框形状 → 居中计算依赖旋转后的边界框尺寸。删掉旋转解码则不知道如何变换精灵图；删掉居中则旋转后的精灵图位置错误。旋转与居中之间存在形状依赖：旋转 90/270 度可能交换宽高，直接改变居中偏移量。

读取点阵标记的颜色确定旋转角，对格元内的精灵图旋转后重新居中放置。

**输入结构**：约 15x15 的网格，背景黑(0)。橙(7) 像素构成一个完整的规则笛卡尔点阵（行距和列距相同，均为 5 像素），将网格分成若干 5x5 的格元。每个格元的左上角有一个点阵标记像素，颜色为以下之一：红(2) 表示顺时针 90 度、绿(3) 表示 180 度、蓝(1) 表示顺时针 270 度、黄(4) 表示不旋转。每个被占用的格元内（标记像素之外）包含一个由灰(5) 像素构成的 4-连通小图形（2~4 像素，形状不对称，边界框不超过 3x3），位置偏离格元中心。至少有 3 个被占用的格元，其中至少出现三种不同的标记色。生成约束：每个精灵图旋转后的边界框仍能完全容纳在 5x5 格元内部（去掉标记像素所在行列后的 4x4 可用区域内）。

**规则**：
1. 识别橙(7) 点阵，确定格元划分（每个格元 5x5，标记在左上角）。
2. 读取每个被占用格元的左上角标记色，解码旋转角度：黄(4) = 0 度；红(2) = 顺时针 90 度；绿(3) = 180 度；蓝(1) = 顺时针 270 度。
3. 将格元内灰(5) 精灵图的像素集合以其边界框中心为旋转中心，按解码的角度旋转。旋转在连续坐标中进行，结果取最近整数坐标。
4. 计算旋转后精灵图的新边界框。将该边界框平移至格元内部可用区域（去掉左上角标记所在的第 0 行和第 0 列后的 4x4 区域）的中心，上下或左右剩余空间不等时向上、向左取整。
5. 清除格元内原始灰像素，在新位置绘制旋转后的精灵图。标记像素和点阵像素保持不变。

**关键洞察**：标记色与旋转角度的映射需对比多个示例才能确定；旋转可能交换精灵图的宽高，使得同一形状在不同格元中的居中偏移量不同——不能直接套用某个固定偏移。

## 新题 4：线路配对传输框心色并过滤干扰

**组合逻辑**：[提取 + 边框包围中心](已有) → [传输 + 端点配对](创新：传输的不是令牌形状而是提取出的颜色) + [忽略干扰项](已有) + [擦除](已有)

**来源原语**：提取(#13 d9fac9be), 边框包围中心(#13 d9fac9be), 忽略干扰项(#13 d9fac9be), 传输(#1 a47bf94d), 线路网络(#1 a47bf94d), 端点配对(#1 a47bf94d), 擦除(#9 f83cb3f6), 单色边框(#13 d9fac9be), 中心像素(#13 d9fac9be)

**依赖链**：边框检测定位各框心色 → 线路网络确定框间配对关系 → 配对双方互换框心色 → 干扰像素被擦除。删掉边框检测则不知道传输什么颜色；删掉线路则不知道传输给谁；删掉干扰过滤则输出含噪声。

在散布着干扰像素的网格中，找出由单色边框围住中心像素的多个 3x3 框，沿灰色线路配对连接，互换框心颜色，同时擦除所有干扰像素。

**输入结构**：约 18x18 的网格，背景黑(0)。网格中包含偶数个（2 或 4 个）3x3 的"信号框"：每个信号框的 8 个边界像素是同一种非背景色（框色，从蓝(1)、绿(3)、橙(7) 中选取，不同框的框色可以相同也可以不同），中心像素是另一种非背景、非框色的颜色（从红(2)、黄(4)、品红(6) 中选取）。信号框两两配对，每对之间用灰(5) 的一像素宽正交折线（水平段和垂直段的组合，无分叉）连接，折线的两个端点分别与一对信号框的外侧相邻（4-邻接框边界的某个像素）。网格中另有若干与框色或中心色相同颜色的孤立散布像素作为干扰项（每个干扰像素均不与任何信号框或灰线路 4-邻接）。生成约束：不同配对的灰线路互不相交；干扰像素不形成 3x3 框结构。

**规则**：
1. 识别所有 3x3 信号框（8 个边界像素同色、中心像素异色且非背景的 3x3 窗口）。
2. 沿灰(5) 线路追踪配对关系：从每个信号框外侧出发，沿 4-连通灰像素路径到达另一个信号框，确定配对。
3. 在输出中保留所有信号框的边界像素和灰线路不变。
4. 对每一对配对的信号框 A 和 B：将 A 的中心像素改为 B 的原始中心色，将 B 的中心像素改为 A 的原始中心色（互换）。
5. 将所有不属于信号框和灰线路的非背景像素（即干扰像素）设为黑(0)。

**关键洞察**：散布的同色像素是干扰项而非信号框的组成部分；只有完整 3x3 边框结构才是有效信号框。线路网络定义的是互换关系而非单向传输。

## 新题 5：边界标记划线分区后顺时针色轮换

**组合逻辑**：[连线 + 边界标记定贯穿线](已有) → [重涂色 + 顺时针轮换](创新：轮换作用于线划出的矩形分区而非预置框)

**来源原语**：连线(#3 6cdd2623), 边界标记定贯穿线(#3 6cdd2623), 边界定位(#3 6cdd2623), 画布边界(#3 6cdd2623), 重涂色(#4 ad173014), 顺时针轮换(#4 ad173014), 环形连接(#4 ad173014)

**依赖链**：边界标记生成贯穿线 → 贯穿线将画布分割为矩形分区 → 分区的填充色沿边界环顺时针轮换。删掉连线则无分区；删掉轮换则分区不改色。连线的输出同时定义了分区的几何结构和轮换顺序（沿边界的分区排列顺序），两者不可分离。

边界像素生成贯穿线将画布划分为矩形区域，然后沿画布边界顺时针方向将各区域的填充色向后轮换一步。

**输入结构**：约 12x12 的网格。网格的四条边界上分布着若干栗(9) 标记像素：上/下边界上的标记定义垂直贯穿列，左/右边界上的标记定义水平贯穿行。这些贯穿线将网格内部分割成若干矩形区域。每个矩形区域内部用某种非背景、非栗(9) 色纯色填充（从蓝(1)、红(2)、绿(3)、黄(4)、灰(5) 中选取），不同区域的颜色各不相同。贯穿线本身（即标记像素所在的完整行或列）用栗(9) 绘制。生成约束：恰好有 2 个垂直贯穿列和 2 个水平贯穿行，将内部分为 9 个矩形区域（3x3 排列）；中心区域不参与轮换；8 个周边区域颜色各不相同。

**规则**：
1. 找出边界上的栗(9) 标记像素。上/下边界的标记确定垂直贯穿列，左/右边界的标记确定水平贯穿行。
2. 在输出中将每条贯穿行/列的所有像素涂为栗(9)。
3. 贯穿线将画布内部分成 9 个矩形区域（3x3 排列）。中心区域的颜色保持不变。
4. 对其余 8 个周边区域，按从左上角开始顺时针方向编号为 1~8（左上→上中→右上→右中→右下→下中→左下→左中）。将编号为 k 的区域的颜色替换为原编号 k-1 的区域的颜色（编号 1 取原编号 8 的颜色），即所有周边区域的颜色顺时针移动一步。
5. 贯穿线的栗(9) 像素和边界标记保持不变。

**关键洞察**：分区的轮换顺序不是由显式连接线给出的，而是由分区在画布中的环形排列位置隐式决定的——必须从贯穿线划分出的几何结构推断出顺时针排列顺序。

## 新题 6：源像素计数定周期间隙再正交压缩

**组合逻辑**：[计数](创新：计数结果动态修改引导条结构) → [压缩 + 投射到引导条](已有) + [投射落间隙则擦](已有)

**来源原语**：计数(#20 6e02f1e3), 压缩(#9 f83cb3f6), 引导条(#9 f83cb3f6), 投射到引导条(#9 f83cb3f6), 投射落间隙则擦(#9 f83cb3f6), 散布像素(#9 f83cb3f6), 擦除(#9 f83cb3f6), 周期掩码(#15 6a980be1)

**依赖链**：计数引导条一侧的源像素数量 → 该计数值作为周期参数在引导条上打孔（每隔 count 个位置制造一个间隙） → 压缩时投射到间隙位置的源像素被擦除。删掉计数则不知道间隙周期；删掉压缩则计数无用。计数的对象（源像素）也是压缩的对象，形成自指耦合。

统计引导条一侧的散布像素数量，以此为周期在引导条上开间隙，然后将所有散布像素正交压缩到引导条旁——落在间隙上的被擦除。

**输入结构**：约 15x15 的网格，背景黑(0)。一条蓝(1) 的水平一像素宽引导条横贯网格中部（占据某一行的全部列），初始无间隙。引导条上方和下方各散布着若干红(2) 孤立像素（每个像素与其他红像素不 4-邻接），分布在不同的列上。生成约束：引导条上方的红像素数量 N_above 和下方的红像素数量 N_below 不相等，且 max(N_above, N_below) 不超过引导条长度的一半；两侧的红像素不会出现在同一列上。

**规则**：
1. 分别统计引导条上方的红(2) 像素数量 N_above 和下方的红(2) 像素数量 N_below。
2. 取较大值 N = max(N_above, N_below) 作为间隙周期。
3. 在引导条上从左起第 N 个位置开始，每隔 N 个位置放置一个间隙（将该位置的蓝像素改为黑(0)）。即引导条的第 N, 2N, 3N, ... 列位置变为间隙（列编号从 1 开始计数）。
4. 将引导条上方的每个红像素沿其所在列垂直向下移动到引导条正上方一格的位置（紧贴引导条）。将引导条下方的每个红像素沿其所在列垂直向上移动到引导条正下方一格的位置。
5. 若某个红像素所在列恰好是引导条的间隙位置，则该像素被擦除（不出现在输出中）。
6. 输出中除了修改后的引导条和存活的压缩后红像素外，其余位置为黑(0)。

**关键洞察**：散布像素既是被压缩的对象，也是决定间隙位置的参数来源——像素数量多的一侧反而可能导致更多同侧像素被间隙擦除，产生反直觉的自我削减效应。

## 新题 7：模板标记定位副本后从副本角发射方向性射线

**组合逻辑**：[模式匹配 + 标记模板](已有) → [射线延伸](创新：射线方向由标记模板的臂朝向决定，而非由外部框角触发)

**来源原语**：模式匹配(#5 e2092e0c), 标记模板(#5 e2092e0c), 形状相同(#5 e2092e0c), 样本区域(#5 e2092e0c), 射线延伸(#7 ec883f72), 角对角对齐(#7 ec883f72), 描框(#5 e2092e0c)

**依赖链**：L-模板标识样本区域 → 模式匹配在网格中找到副本 → L-模板的两臂朝向决定副本的哪些角发射对角射线。删掉模式匹配则无法定位副本；删掉射线延伸则找到副本也无操作；L-模板同时承担两个功能（标识样本 + 编码射线方向），不可分离。

灰色 L 形标记标识一个 3x3 样本，找到该样本在网格中的唯一副本，然后从副本的两个由 L 臂朝向指定的角沿对角线向外延伸灰色射线。

**输入结构**：约 14x14 的网格，背景黑(0)。一个 3x3 的彩色样本区域（内含 2~3 种非背景色的图案），其外侧紧邻一个灰(5) L 形标记：L 的两臂分别沿样本的某两条相邻边（共享一个角），每臂长 3 像素、宽 1 像素。该 3x3 图案在网格中恰好还出现一次（副本），副本周围一圈全为背景。网格中可能散布少量其他非背景色的噪声像素（不构成 3x3 图案）。生成约束：副本的两条射线路径上不存在非背景像素阻挡；射线不经过样本区域或 L 标记。

**规则**：
1. 找到灰(5) L 形标记，从 L 的内凹角确定 3x3 样本区域的位置（样本位于 L 内凹角方向的 3x3 区域）。
2. 在网格中搜索与该 3x3 样本完全相同的另一处出现（副本）。
3. 确定 L 标记的两臂朝向。L 的两臂从其内凹角出发分别向两个正交方向延伸。这两个方向对应样本的两条相邻边，共享样本的一个角——这个角称为"L 指示角"。
4. 在副本中找到与"L 指示角"相对位置相同的那个角。从该角沿远离副本中心的 45 度对角方向延伸灰(5) 射线，每步行列各加减 1，直到到达网格边界。
5. 对"L 指示角"相邻的两个副本角（即共享一条边的角），分别也从各自沿远离副本中心的对角方向延伸灰(5) 射线。
6. 与"L 指示角"对角的副本角不发射射线。
7. 样本区域、L 标记、副本内部像素均保持不变。噪声像素保持不变。

**关键洞察**：L 标记不仅标识样本，还通过其两臂的朝向编码了副本上哪三个角需要发射射线——必须从 L 的几何结构推断出角的选择规则，而非简单地框选副本。

## 新题 8：嵌套框限域行列标记扩展

**组合逻辑**：[提取 + 边框包围中心](创新：框不止包围中心，还定义行列扩展的作用域) + [连线 + 标记展为整行整列](创新：扩展范围被框界限截断) + [裁剪](已有)

**来源原语**：边框包围中心(#13 d9fac9be), 单色边框(#13 d9fac9be), 连线(#2 8731374e), 标记展为整行整列(#2 8731374e), 行列交叉(#2 8731374e), 裁剪(#2 8731374e), 矩形(#2 8731374e), 标记像素(#2 8731374e)

**依赖链**：框检测确定各层作用域边界 → 标记像素在各自所属框的作用域内扩展为行列 → 嵌套关系决定冲突解决（内框优先）。删掉框检测则标记扩展到全网格（错误）；删掉标记扩展则框无作用；嵌套优先级规则需对比有无嵌套的示例才能归纳。

多个嵌套的单色矩形框各自框定一个作用域，框内的标记像素仅在所属框的内部展开为整行整列，内层框的扩展覆盖外层。

**输入结构**：约 18x18 的网格，背景黑(0)。网格包含 2~3 个一像素宽的矩形框，框色各不相同（从蓝(1)、绿(3)、橙(7) 中选取）。框之间存在嵌套关系（一个框完全包含在另一个框内部，不相交不共边）。每个框的内部区域背景为黑(0)，并散布若干红(2) 标记像素（1~3 个，互不相邻）。标记像素仅出现在框的内部（不在框边界上），且每个标记像素属于"最内层包含它的框"。生成约束：不同框内的标记像素不在同一行或同一列上；最内层框内至少有 1 个标记像素。

**规则**：
1. 识别所有矩形框（一像素宽的闭合矩形，每个框有唯一的非背景色）。
2. 确定嵌套关系：若框 A 完全在框 B 内部，则 A 是 B 的子框。每个标记像素属于包含它的最内层框。
3. 对每个标记像素，在其所属框的内部区域（不含框边界本身）内，将该标记像素所在的整行和整列涂为该框的框色。涂色范围严格截止于框边界内侧，不超出框边界。
4. 若某个位置同时被外层框的标记扩展和内层框的标记扩展覆盖，以内层框的扩展结果为准（内层覆盖外层）。
5. 若某个位置被同一框内两个标记的行扩展和列扩展同时覆盖（行列交叉点），涂为该框的框色（即交叉点无特殊处理，仍为框色）。
6. 所有矩形框的边界像素保持不变。原始标记像素被框色覆盖（不保留红色）。
7. 输出网格大小与输入相同，不做裁剪。

**关键洞察**：同样的"标记展为整行整列"操作在不同框的作用域内独立执行，嵌套层次决定了冲突解决的优先级——从单个示例中可能无法分辨是"内层优先"还是"外层优先"，需要对比多个嵌套配置。

## 新题 9：镜像四联平铺后跨界分量重涂色

**组合逻辑**：[镜像 + 拼接](创新：从水平拼接扩展为 2x2 四变体平铺) → [连通检测](已有) → [重涂色](创新：重涂条件由分量是否跨越镜像边界决定)

**来源原语**：镜像(#14 6d0aefbc), 拼接(#14 6d0aefbc), 拼接镜像副本(#14 6d0aefbc), 连通检测(#6 3194b014), 重涂色(#16 67385a82), 多像素涂色留单(#16 67385a82), 连通分量(#16 67385a82)

**依赖链**：镜像平铺在四个象限创建对称副本 → 部分原本分离的图形在镜像接缝处连通 → 连通检测识别出跨象限分量 → 跨象限分量被重涂色。删掉平铺则无接缝概念；删掉连通检测则无法判断是否跨界；删掉重涂色则检测无用。跨界连通是镜像平铺的涌现属性，源题中不存在。

将输入网格做 2x2 镜像平铺（四个象限分别为原图、水平翻转、垂直翻转、180 度旋转），然后找出在拼合后跨越象限边界连通的分量，在输出（仍为原图大小）中将这些分量的原始像素重涂为灰(5)。

**输入结构**：约 8x8 的网格，背景黑(0)。网格中包含若干由非背景色构成的 4-连通图形（2~5 像素，颜色从红(2)、蓝(1)、绿(3)、黄(4) 中选取）。部分图形的像素触及网格边缘（即至少有一个像素在第 0 行、最后一行、第 0 列或最后一列上），部分图形完全在网格内部。生成约束：至少有一个触及边缘的图形在镜像平铺后会与其镜像副本 4-连通（接缝处连通），至少有一个触及边缘的图形在镜像平铺后不会与镜像副本连通（例如沿边缘延伸但不在角落或对称位置）。

**规则**：
1. 概念性地构造一个 2W x 2H 的平铺网格（W, H 为输入宽高）：左上象限 = 原输入；右上象限 = 原输入水平翻转（列倒序）；左下象限 = 原输入垂直翻转（行倒序）；右下象限 = 原输入 180 度旋转（行列均倒序）。
2. 在该 2W x 2H 网格上，对每种非背景色分别做 4-连通分量检测。
3. 对每个分量，判断它是否跨越象限边界（即分量的像素分布在两个或更多象限中）。
4. 输出网格大小与原输入相同。对原输入（左上象限）中的每个前景像素：若该像素所属的分量在平铺网格中跨越了象限边界，则在输出中将该像素涂为灰(5)；否则保持原色不变。
5. 背景像素保持黑(0)。

**关键洞察**：镜像平铺不用于生成输出的几何结构，而是作为一个隐式测试——测试哪些图形在对称复制后会与副本连通。触及边缘不等于跨界连通：只有在接缝处恰好对齐的像素才会连通，必须通过实际连通检测而非简单的"是否触边"来判断。

## 新题 10：形状循环压缩与引导条间隙过滤

**组合逻辑**：[形状变换 + 形状循环映射](创新：循环发生在压缩过程中而非线路传输中) + [压缩 + 投射到引导条](已有) + [投射落间隙则擦](已有)

**来源原语**：形状变换(#1 a47bf94d), 形状循环映射(#1 a47bf94d), 令牌(#1 a47bf94d), 压缩(#9 f83cb3f6), 引导条(#9 f83cb3f6), 投射到引导条(#9 f83cb3f6), 投射落间隙则擦(#9 f83cb3f6), 散布像素(#9 f83cb3f6), 擦除(#9 f83cb3f6)

**依赖链**：形状循环映射定义令牌的变换规则 → 压缩将令牌向引导条投射 → 间隙位置过滤掉部分令牌 → 存活的令牌在新位置以循环后的形状出现。删掉形状循环则令牌保持原形（错误）；删掉压缩则令牌不移动；删掉间隙过滤则所有令牌均存活。引导条的间隙同时选择了哪些令牌被保留和哪些发生形状变换。

散布在引导条两侧的 3x3 令牌沿正交方向压缩到引导条旁，同时形状按循环规则变换：实心方块变为菱形，菱形变为 X 形，X 形变为实心方块；投射到引导条间隙位置的令牌被擦除。

**输入结构**：约 17x17 的网格，背景黑(0)。网格中部有一条绿(3) 的垂直一像素宽引导条（占据某一列的全部行），引导条上可能有 1~2 个间隙（黑色像素中断）。引导条左右两侧散布着若干 3x3 的红(2) 令牌，每个令牌属于以下三种形状之一：实心方块（3x3 全填充）、菱形（中心 + 4 个正交邻居，共 5 像素）、X 形（中心 + 4 个对角邻居，共 5 像素）。每个令牌的 3x3 边界框中心行确定其投射目标（令牌沿水平方向向引导条压缩）。生成约束：不同令牌的中心行互不相同；至少包含两种不同的令牌形状；至少有一个令牌的中心行对应引导条的间隙位置，至少有一个对应引导条的实体位置。

**规则**：
1. 识别绿(3) 垂直引导条及其间隙位置（引导条所在列中为黑(0) 的行）。
2. 识别引导条左右两侧的所有 3x3 红(2) 令牌，确定每个令牌的形状类型（实心方块/菱形/X 形）和中心行。
3. 对每个令牌，将其中心行投射到引导条所在列：若该行在引导条上是绿(3)（实体位置），令牌存活；若该行在引导条上是黑(0)（间隙位置），令牌被擦除。
4. 对存活的令牌，执行形状循环变换：实心方块 → 菱形，菱形 → X 形，X 形 → 实心方块。
5. 将变换后的令牌放置在引导条相邻位置：令牌原在引导条左侧的，放在引导条左侧紧邻的列（中心列 = 引导条列 - 2）；原在右侧的，放在右侧紧邻的列（中心列 = 引导条列 + 2）。令牌中心行保持不变。
6. 清除原始令牌位置的所有红像素。引导条（含间隙）保持不变。输出中只有引导条和变换后的存活令牌。

**关键洞察**：形状循环规则（实心→菱形→X→实心）需对比多个示例中不同形状的输入/输出才能归纳——单个示例中可能只展现循环的一步。引导条间隙同时起到空间过滤和选择的双重作用。
