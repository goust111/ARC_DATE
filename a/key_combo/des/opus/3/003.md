## 新题 1：十字线围合洪填

**组合逻辑**：[射线延伸 ray_extend](已有) → [行列交叉 row_column_crossing + 异源交叉特殊着色](已有) → [泛洪填充 flood_fill](创新：将十字线作为围合墙壁而非终态) → [重涂色 recolor](创新：填充色由围合边界的标记源数量决定)

**来源原语**：射线延伸/行列交叉/异源交叉着色(45bbe264), 泛洪填充/可达性(8f3a5a89), 重涂色(多题)

**依赖链**：射线延伸生成十字线网格 → 交叉点变红形成额外墙壁节点 → 十字线+交叉点共同围合出封闭区域 → 泛洪填充识别封闭区域 → 每个封闭区域的填充色取决于其边界上有几个不同标记源的十字线，该计数信息只有在射线全部画完后才能确定

一句话总结：将孤立标记像素扩展为全行全列十字线，然后根据每个被围合区域边界上来自几个不同标记的十字线数量来决定该区域的填充色。

**输入结构**：黑(0)背景网格，约 15x15。网格上散布 3~5 个孤立的非背景、非红色标记像素，每个标记颜色互不相同（从蓝(1)、绿(3)、黄(4)、灰(5)、品红(6)、橙(7)、青(8)、栗(9)中选取），且任意两个标记不在同一行也不在同一列。生成约束：标记数量和位置确保至少产生一个仅由两个标记的十字线围合的区域，以及至少一个由三个或更多标记的十字线围合的区域。

**规则**：
1. 对每个标记像素，将其所在整行和整列的所有背景像素(0)涂为该标记的颜色。标记像素本身保持原色。
2. 当来自不同标记的十字线交叉于同一像素时（即某标记的行线穿过另一标记的列线所在位置），将该交叉像素涂为红(2)。若某像素同时被同一标记的行线和列线覆盖（即标记自身位置），保持标记原色。涂色冲突解决：先绘制所有行线（按标记从上到下的行顺序），再绘制所有列线（按标记从左到右的列顺序），后绘制的覆盖先绘制的；最后将所有异源交叉点统一涂红。
3. 十字线将网格划分为若干矩形区域。对每个区域执行泛洪填充检测：从区域内任一背景像素出发，沿四方向扩展，以非背景像素（十字线、红色交叉点、标记像素）和网格边界为阻挡。如果该区域的所有背景像素都无法到达网格的任何一条边（即该区域被十字线完全围合），则该区域为"封闭区域"。
4. 对每个封闭区域，统计其边界上涉及几个不同标记源的十字线（每条十字线的颜色可追溯其来源标记；红色交叉点同时属于两个标记源）。若恰好 2 个不同标记源的十字线参与围合，将该区域内所有背景像素填充为黄(4)。若 3 个或更多标记源参与围合，填充为橙(7)。
5. 接触网格边的非封闭区域不填充，保持黑(0)。

**关键洞察**：十字线不是最终输出的主体，而是中间构造物——它们充当泛洪填充的墙壁。每个封闭区域的填充色不取决于任何单个标记的属性，而取决于围合该区域的十字线来自几个不同的标记源，这一信息只有在所有十字线全部绘制完毕后才可计算。

## 新题 2：锚点定向复制与矩形容器过滤

**组合逻辑**：[包含于边界框 in_bounding_box](已有，创新用途：过滤锚点目标) + [锚点对齐 anchor_alignment](已有) + [方向指示 dir_indication](创新：矩形上的标记决定副本镜像方向) → [平移复制 translate_and_copy](已有) + [镜像 mirror](条件性触发)

**来源原语**：平移复制/锚点对齐/锚点偏移对应(2c737e39), 包含于边界框/仅处理区域内标记(a04b2602), 镜像/方向指示/标记指示放置侧(760b3cac)

**依赖链**：矩形的边界框决定哪些目标锚点有效（过滤） → 矩形上的方向标记决定复制品是否镜像（朝向） → 源精灵体的锚点与有效目标锚点的偏移决定复制品的放置位置（定位） → 矩形框线在冲突时遮挡复制品（遮挡优先级）

一句话总结：将源精灵体按锚点偏移复制到矩形框内的目标位置，矩形边缘的方向标记决定副本是否水平翻转，框外的锚点是干扰项。

**输入结构**：黑(0)背景网格，约 18x18。包含以下元素：
- 一个多色源精灵体（由 2~3 种非背景颜色组成的 4-连通小图形，约 8~15 像素），其中恰好包含一个灰(5)像素作为源锚点。源精灵体形状不对称（水平翻转后与原形不同）。
- 2~4 个绿(3)空心矩形框（仅边框一像素宽，内部为黑色背景，尺寸至少 5x5），彼此不重叠且不与源精灵体重叠。每个绿矩形的左边框或右边框上恰好有一个栗(9)方向标记像素（位于该边框的中点位置）。
- 3~6 个孤立的灰(5)目标锚点像素，散布于网格各处。其中部分位于某个绿矩形的边界框内部（不在框线上），其余位于所有绿矩形边界框之外。
- 生成约束：源精灵体的尺寸小于任何绿矩形的内部空间，确保副本可以完整放入；各绿矩形之间、矩形与源精灵体之间至少间隔 2 像素；至少有一个目标锚点在矩形内部，至少有一个在矩形外部。

**规则**：
1. 识别源精灵体及其灰(5)源锚点。识别所有孤立灰(5)目标锚点（不属于源精灵体的灰像素）。
2. 过滤目标锚点：仅保留落在某个绿矩形边界框内部（严格在矩形内，不在框线上）的目标锚点。框外的目标锚点为干扰项，忽略。
3. 对每个有效目标锚点，确定其所在的绿矩形。检查该矩形的栗(9)方向标记位于左边框还是右边框。
4. 计算偏移向量：从源锚点到该有效目标锚点的行列差。
5. 将源精灵体的所有非灰像素按该偏移向量平移复制到目标位置。若方向标记在左边框，则先将精灵体图案水平镜像后再平移复制；若方向标记在右边框，则保持原朝向直接复制。
6. 绘制顺序与冲突解决：先保留所有绿矩形框线和栗标记，再绘制复制品。复制品的像素不覆盖绿框线和栗标记（框线优先级更高）。有效目标锚点在绘制复制品前擦除为黑(0)。多个复制品像素冲突时，所属矩形边界框面积较小的复制品优先。

**关键洞察**：绿矩形同时承担三重角色——过滤哪些目标锚点有效（容器）、通过方向标记决定副本朝向（编码器）、以及框线遮挡副本边缘（遮罩）。仅看一个示例中只有右标记矩形的情况，无法推断出左标记矩形要求镜像的规则。

## 新题 3：走廊连通决定格子推断分组

**组合逻辑**：[对边连通 opposite_edge_connect](创新用途：走廊不再直接涂色，而是作为格子框架间的连通关系) + [跨框架对应 cross_frame_match](已有) + [推断 infer](已有) + [填充 fill](已有)

**来源原语**：对边连通/走廊/无阻挡跨行列涂色(2bee17df), 跨框架对应/槽位位置决定颜色/推断/填充(2e65ae53)

**依赖链**：边界标记像素定义走廊 → 走廊穿过哪些格子框架决定哪些框架属于同一推断组 → 同组框架的已有槽位填色互相补充信息 → 推断出每个槽位位置的唯一颜色 → 填充所有同组框架的空槽位

一句话总结：通过网格边缘标记确定行列走廊，走廊穿过的格子框架归为同一推断组，组内框架的部分槽位填色互为线索，推断并填满所有空槽位。

**输入结构**：黑(0)背景网格，约 20x20。包含以下元素：
- 3~5 个灰(5)一像素宽矩形格子框架，散布于网格中，彼此不重叠。每个格子框架内部被灰线分隔为相同的 R x C（如 2x3 或 3x2）个矩形槽位。所有格子框架的槽位行列数相同（同构）。部分槽位内填有单一非灰非背景颜色像素（该颜色均匀填充整个槽位内部），其余槽位为黑(0)空白。
- 网格的四条边上散布若干红(2)标记像素。部分红标记像素成对出现在同一行的左右两边（一个在最左列，一个在最右列），或同一列的上下两边（一个在最顶行，一个在最底行）。
- 生成约束：对于每对对边红标记，两者之间的整行或整列上除格子框架的灰线外只有黑(0)背景像素（即走廊畅通，不被其他前景对象阻挡）。每个格子框架至少被一条走廊穿过。同一推断组内所有框架的已有填色合并后，恰好能唯一确定每个槽位位置的颜色（不存在同一位置有两种矛盾颜色的情况，也不存在某位置在组内所有框架中都为空白的情况）。不同推断组的槽位颜色方案可以不同。

**规则**：
1. 识别所有走廊：对于网格中的每一行，如果最左列和最右列都有红(2)标记，且该行上除灰(5)格子框架线外所有像素均为黑(0)，则该行形成一条水平走廊。列方向同理。
2. 建立连通关系：若一条走廊穿过（即该行或列与格子框架的边界框有交集）两个或更多格子框架，则这些框架被该走廊"连通"。将所有被走廊直接或间接连通的框架归入同一推断组。
3. 对每个推断组，汇总组内所有框架中已填色的槽位。由于所有框架同构，使用槽位的行列位置（如第 r 行第 c 列）作为索引。每个槽位位置从组内各框架的对应槽位中提取已有颜色。
4. 将推断出的完整颜色方案填回组内每个框架的所有空白槽位：每个空白槽位的内部区域全部填充为对应位置的推断颜色。
5. 不属于任何走廊连通组的孤立框架（如果存在）保持不变。红标记像素保持不变。格子框线保持灰(5)不变。

**关键洞察**：走廊本身不产生任何着色效果——它的作用完全是结构性的：决定哪些格子框架共享同一套颜色方案。不同走廊构型产生不同的分组，进而产生不同的推断结果。仅凭一个示例无法区分"所有框架共享一套方案"和"走廊决定分组"这两种假设。

## 新题 4：可达性过滤轨道滑动

**组合逻辑**：[泛洪填充 flood_fill](已有) + [可达性 reachability](创新用途：不再画边界，而是筛选轨道的有效段) + [擦除 erase](已有，用于清除装饰墙) + [滑动 sliding](已有) + [沿轨道进一槽位 advance_one_slot](已有)

**来源原语**：泛洪填充/可达性/边界连通区分结构/擦除(8f3a5a89), 滑动/轨道点/等距排列/沿轨道进一槽位(5168d44c)

**依赖链**：角落标记启动泛洪填充 → 可达性判定区分结构墙与装饰墙 → 擦除装饰墙 → 可达性同时决定哪些轨道点属于"有效轨道" → 滑动对象仅沿有效轨道移动一个槽位

一句话总结：从角落标记泛洪填充确定可达区域，擦除装饰性墙壁碎片，然后将轨道上的对象沿仅由可达轨道点构成的有效段向前滑动一个槽位。

**输入结构**：黑(0)背景网格，约 15x15。包含以下元素：
- 蓝(1)墙壁像素形成若干线段和碎片，将网格分为不同区域。部分蓝墙连接到网格边界（结构性墙壁），部分蓝墙不连接到边界（装饰性碎片）。
- 一个品红(6)单像素角落标记，位于网格四角之一。
- 一条由绿(3)单像素轨道点组成的等距排列轨道。轨道点沿同一行或同一列排列，间距相等（例如每隔 2 格一个点）。轨道跨越蓝墙两侧——部分轨道点在角落标记可达的区域内，部分在不可达区域内。
- 一个红(2) 4-连通前景对象（3~6 像素的不规则小图形），当前覆盖在一个或多个绿轨道点上。该对象位于可达区域内。
- 生成约束：轨道上在可达区域内的绿点至少有 3 个（足够容纳对象及其移动）；红对象前进方向上的下一个可达轨道点处有空间放置对象（不被结构墙阻挡）；至少有一个装饰性蓝墙碎片存在。

**规则**：
1. 从品红(6)角落标记出发，对黑(0)背景像素执行四方向泛洪填充，以蓝(1)墙壁像素和网格边界为阻挡，标记所有可达的背景像素。
2. 识别装饰性蓝墙：一个蓝(1)像素的 4-连通分量如果没有任何像素位于网格边界行/列上，则为装饰性墙壁。将装饰性墙壁的所有像素擦除为黑(0)。
3. 筛选有效轨道点：仅保留位于可达区域内的绿(3)轨道点（即该轨道点的至少一个四方向邻居是可达的背景像素或角落标记像素）。不可达区域内的轨道点擦除为黑(0)。
4. 确定轨道方向和前进方向：有效轨道点排列在同一行或同一列上，前进方向为从红对象当前位置指向更多剩余有效轨道点的方向。若两侧有效轨道点数量相同，则向右（水平轨道）或向下（垂直轨道）前进。
5. 将红对象沿前进方向平移到下一个有效轨道点对齐的位置（使对象的首像素对齐到下一个有效轨道点）。擦除对象原位置为黑(0)，在新位置绘制对象。
6. 品红角落标记在完成可达性判定后擦除为黑(0)。

**关键洞察**：轨道在视觉上看似连续穿过整个网格，但被结构性墙壁隔断后，只有从角落标记可达一侧的轨道点才是有效的移动轨道。泛洪填充的结果不用于画边界或着色，而是作为一个布尔过滤器决定轨道的哪一段参与滑动计算。

## 新题 5：贪心正方形选择与邻接数标记

**组合逻辑**：[贪心选择 greedy_selection + 非重叠约束 + 从大到小优先](已有) → [计数 counting](创新用途：不再计数区域，而是计数选中方块之间的邻接关系) → [标记 marking + 角点邻接](创新：标记方式由邻接计数决定) + [重涂色 recolor](条件性触发)

**来源原语**：贪心选择/空白正方形区域/障碍像素/非重叠约束/从大到小优先/最小边长约束(31adaf00), 计数(89565ca0), 标记/角外像素/角点邻接/完整方块才标记(14b8e18c), 重涂色(多题)

**依赖链**：贪心选择确定哪些正方形区域被选中 → 选中方块构成一个邻接图 → 每个方块的邻接度数决定其标记方式 → 标记/重涂色的具体操作取决于邻接计数值

一句话总结：在障碍网格中贪心选取互不重叠的最大全黑正方形区域，然后根据每个选中方块与其他选中方块的邻接数量决定其着色和角标记方式。

**输入结构**：黑(0)背景网格，约 18x18。散布着灰(5)障碍像素，将空白区域分隔为各种不规则形状的黑色空间，其中部分区域可容纳边长 >= 2 的正方形。生成约束：确保经贪心选择后至少有 4 个不同的正方形被选中；选中方块中至少存在一个孤立方块（无邻接）、一个有恰好 1 个邻接的方块、和一个有 >= 2 个邻接的方块。

**规则**：
1. 搜索所有可能的全黑(0)正方形区域（边长 >= 2，区域内所有像素为黑色背景，不含灰障碍）。
2. 按边长从大到小排序。依次选择：若当前候选正方形与所有已选中方块无像素重叠，则选中；否则跳过。同一边长的候选按其左上角坐标从上到下、从左到右排序处理。
3. 将所有选中方块的内部像素涂为蓝(1)。
4. 计算每个选中方块的邻接度数：两个选中方块"邻接"当且仅当它们的边界像素之间存在至少一对 8-邻域相邻的像素（即两个蓝色方块之间的最小棋盘距离 <= 1）。
5. 根据邻接度数决定处理方式：
   - 度数 = 0（孤立）：保持蓝(1)，在该方块四个角的外侧各绘制 2 个红(2)标记像素（与角像素正交相邻的两个背景像素位置，如 14b8e18c 的角标记方式）。若标记位置不是黑(0)背景（如是灰障碍或其他方块），则该位置不绘制标记。
   - 度数 = 1（单邻接）：保持蓝(1)，仅在最靠近其唯一邻接方块的那两个角的外侧绘制红(2)标记（共 4 个标记像素）。"最靠近邻接方块的两个角"定义为：该方块四个角中，到邻接方块中心欧氏距离最小的两个角。
   - 度数 >= 2（多邻接）：将该方块从蓝(1)重涂为黄(4)，不绘制任何角标记。
6. 灰(5)障碍像素保持不变。

**关键洞察**：角标记的数量和位置不仅取决于方块自身的几何属性，更取决于贪心选择产生的全局邻接结构——改变一个障碍像素可能改变选择结果，进而级联改变多个方块的邻接度数和标记方式。单示例中如果所有选中方块恰好邻接度相同，则无法区分三种标记规则。

## 新题 6：完整方块的空心/实心分支处理

**组合逻辑**：[完整方块才标记 only_complete_marked](已有，作为第一级分支条件) + [包含关系/封闭孔洞 containment + enclosed_hole](创新用途：作为第二级分支条件) → [标记 marking + 角外像素](条件分支 A) / [填充 fill + 重涂色 recolor + 描边 draw_outline](条件分支 B) / [描边 draw_outline](默认分支)

**来源原语**：完整方块/角外像素/角点邻接/标记(14b8e18c), 封闭孔洞/包含关系/有孔触发重涂/描边/填充/重涂色(aa4ec2a5)

**依赖链**：完整方块检测（第一级分支）→ 空心/实心检测（第二级分支，仅对完整方块执行）→ 实心方块走角标记分支 / 空心方块走孔填充+重涂+描边分支 / 非方块走纯描边分支

一句话总结：检测前景对象是否为完整方块，再检测完整方块内部是否有孔洞——实心方块获得角标记，空心方块获得孔洞填充和边框重涂，非方块对象仅获得描边。

**输入结构**：黑(0)背景网格，约 16x16。包含 4~6 个 4-连通单色前景对象（每个对象由一种非背景颜色组成），颜色从蓝(1)、绿(3)、黄(4)、橙(7)、栗(9)中选取，不同对象颜色可相同也可不同。对象类型包括：
- 实心完整方块：边界框为正方形，且边界框边界上所有像素都填充为该对象颜色，内部也全部填充（无背景孔洞）。边长范围 3~6。
- 空心完整方块：边界框为正方形，边界框边界上所有像素都填充为该对象颜色，但内部包含一个或多个 4-连通的黑(0)背景孔洞。边长范围 4~6（至少 4 才能容纳内部孔洞）。
- 非方块不规则对象：4-连通的单色前景图形，边界框不是正方形，或边界框边界上存在缺失像素。大小 4~12 像素。
- 生成约束：至少包含一个实心完整方块、一个空心完整方块、和一个非方块对象。各对象彼此不相邻（8-邻域不接触），确保描边不会冲突。

**规则**：
1. 对每个 4-连通前景分量，检测是否为"完整方块"：其边界框必须为正方形（宽 = 高），且该边界框四条边上的所有像素都是该对象的颜色。
2. 对每个完整方块，检测是否"空心"：在边界框内部（不包括边界行列），是否存在至少一个 4-连通的黑(0)背景区域被该方块完全包围（该背景区域的泛洪填充无法到达网格边界）。
3. 分支处理：
   - **实心完整方块**：保持原色不变。在其四个角各自的外侧绘制 2 个红(2)标记像素——即与角像素正交相邻的两个外部位置（一个沿行方向，一个沿列方向）。若外部位置已被其他对象像素占据或超出网格边界，则不绘制该标记。共计最多 8 个红标记。
   - **空心完整方块**：将该方块的所有对象像素重涂为青(8)。将其内部所有封闭的黑(0)孔洞像素填充为品红(6)。然后绘制一圈红(2)描边：对该方块（含已填充孔洞区域）的每个像素，检查其 8-邻域中是否存在不属于该方块也不属于已填充孔洞的像素（即外部像素）；在所有这样的外部邻居位置绘制红(2)。若该外部位置已有其他对象像素，则不覆盖。
   - **非方块对象**：保持原色不变。仅绘制红(2)描边（规则同空心方块的描边步骤，但不做重涂和孔洞填充）。
4. 绘制顺序：先处理所有对象的内部变换（重涂、孔洞填充），再统一绘制所有描边和角标记。描边像素之间无冲突（因为对象彼此不相邻）。

**关键洞察**：同样是"完整方块"，空心和实心走向完全不同的处理路径——实心方块获得角标记（来自 14b8e18c 的逻辑），空心方块获得内部填充+重涂+描边（来自 aa4ec2a5 的逻辑）。仅看包含实心方块的示例无法推断空心方块的规则，反之亦然。两个来源题的规则在这里通过"空心/实心"判断交织成一个决策树。

## 新题 7：格子墙壁缺口竞争洪填

**组合逻辑**：[泛洪填充 flood_fill](创新：在格子间隙图上执行，而非连续背景上) + [格子框架/格子槽位](创新用途：不按位置推断颜色，而是作为泛洪节点) + [擦除 erase](已有，清除装饰碎片) + [可达性 reachability](创新用途：竞争性可达) + [重涂色 recolor](竞争冲突时触发)

**来源原语**：泛洪填充/可达性/墙壁障碍/装饰碎片/擦除/边界连通区分结构(8f3a5a89), 格子框架/格子槽位/填充(2e65ae53), 擦除(3bdb4ada)

**依赖链**：格子结构定义拓扑节点 → 墙壁缺口定义节点间连通边 → 装饰碎片识别与擦除保证连通性正确 → 种子像素从各自节点出发竞争洪填 → 冲突节点（两个不同种子同时到达）变为特殊颜色

一句话总结：在格子框架的墙壁缺口构成的隐式图上，多个种子像素竞争性地泛洪填充，每个种子染色其可达且未被其他种子先到达的槽位，两种子同时到达的槽位涂为冲突色。

**输入结构**：黑(0)背景网格，约 18x18。包含以下元素：
- 一个灰(5)一像素宽的格子框架，将网格内部划分为规则的 M x N 个矩形槽位（例如 4x4 或 5x4）。格子线延伸到网格边界。
- 格子的部分墙壁段存在单像素缺口（缺口处为黑(0)背景像素而非灰(5)），使相邻槽位通过缺口相连。每段墙壁（两个格子交叉点之间的线段）上最多有一个缺口。
- 2~4 个种子像素，分别位于不同的槽位中央，颜色各不相同（从蓝(1)、绿(3)、黄(4)、橙(7)、栗(9)中选取）。
- 部分槽位内部可能存在灰(5)装饰碎片（小的灰色像素块，不与格子框线 4-连通相连），这些碎片不属于格子结构。
- 生成约束：缺口连通图保证每个无种子槽位至少能从一个种子到达；至少存在一个槽位可以从两个不同种子通过不同路径到达（产生冲突）；至少存在一个装饰碎片。

**规则**：
1. 识别格子框架结构：灰(5)像素中与网格边界 4-连通相连的分量构成格子框架。
2. 擦除装饰碎片：灰(5)像素中不与格子框架 4-连通相连的分量为装饰碎片，擦除为黑(0)。
3. 构建槽位间隙图：每个槽位为一个节点。当两个相邻槽位之间的灰墙壁段存在缺口（至少一个黑像素中断了墙壁连续性）时，在这两个节点之间添加一条边。
4. 从每个种子像素出发，在间隙图上执行广度优先泛洪：从种子所在槽位开始，沿图的边扩展到邻接槽位，记录每个槽位被每个种子首次到达时的步数（图距离）。
5. 着色规则：
   - 若一个槽位仅能被一个种子到达（或被多个种子到达但其中一个步数严格最少），将该槽位内部所有黑(0)背景像素填充为该种子的颜色。种子像素本身保持原色。
   - 若一个槽位被两个或更多种子以相同最少步数到达（距离平局），将该槽位内部所有黑(0)背景像素填充为红(2)。
6. 格子框线保持灰(5)。缺口处保持黑(0)。

**关键洞察**：格子墙壁的缺口模式构成一个隐式图，种子在这个图上的最短路径竞争决定了每个槽位的颜色。缺口的位置直接控制可达性和距离——堵上一个缺口就可能改变大片区域的颜色归属。冲突色仅在两个种子势均力敌的边界处出现。

## 新题 8：分区条纹定向精灵体旋转与轨道滑动

**组合逻辑**：[旋转 rotate / 翻转 flip](已有) + [标记色定朝向 marker_color_sets_orientation](创新：不是标记像素的颜色，而是分区条纹的方位决定朝向) + [滑动 sliding + 沿轨道进一槽位](已有) + [擦除 erase](已有)

**来源原语**：旋转/翻转/分区条纹/标记色定朝向(6e4f6532), 滑动/轨道点/等距排列/沿轨道进一槽位(5168d44c), 擦除(多题)

**依赖链**：分区条纹将网格分为若干区域 → 每个精灵体包含一个与某条分区条纹同色的方向标记像素 → 标记颜色指示精灵体应朝向哪条同色条纹 → 旋转/翻转精灵体使标记像素面向该条纹 → 朝向确定后，精灵体沿轨道向标记指向的方向滑动一个槽位

一句话总结：每个精灵体根据其方向标记像素的颜色确定应朝向哪条同色分区条纹，旋转至正确朝向后沿轨道向该方向滑动一个槽位。

**输入结构**：黑(0)背景网格，约 15x18。包含以下元素：
- 2~3 条单像素宽的彩色分区条纹，沿网格边缘或横贯网格排列（例如一条蓝(1)横条纹在网格顶部，一条绿(3)竖条纹在网格右侧）。每条条纹颜色不同。条纹将网格分为若干矩形区域。
- 一条由栗(9)单像素轨道点构成的等距排列轨道（沿一行或一列，间距相等，如每隔 3 格一个点），穿过一个或多个区域。
- 2~3 个小型非对称精灵体（每个 4~7 像素，4-连通，主色互不相同且不与条纹或轨道颜色重复，从黄(4)、灰(5)、品红(6)、橙(7)中选取）。每个精灵体内部恰好包含一个与某条分区条纹颜色相同的像素（方向标记像素），该标记像素位于精灵体的边缘位置（不在精灵体的几何中心）。
- 每个精灵体当前覆盖在轨道的某个槽位上。
- 生成约束：每个精灵体的方向标记像素颜色对应一条唯一的分区条纹，且该条纹在精灵体的某个方向上（上/下/左/右之一）。精灵体的形状满足：经过最多一次 90 度旋转和/或一次翻转，可以使方向标记像素位于精灵体朝向该条纹的那一侧边缘。精灵体的旋转/翻转变换是唯一确定的（精灵体形状足够不对称）。轨道上在每个精灵体的移动方向有至少一个空闲槽位。

**规则**：
1. 识别所有分区条纹（横跨网格整行或整列的单色线段）及其颜色和方位（水平/垂直）。
2. 对每个精灵体，找到其内部的方向标记像素（与某条条纹同色的那个像素）。确定对应条纹相对于精灵体当前位置的方向（上/下/左/右）。
3. 旋转和/或翻转精灵体，使方向标记像素位于精灵体朝向该条纹的那一侧边缘。具体地：精灵体的边界框有四个边，方向标记像素应位于面向条纹那一边的像素行/列上。如果当前已满足此条件则不变换。变换选择规则：优先使用仅旋转（0/90/180/270 度）；如果纯旋转无法满足，则使用一次翻转（水平或垂直）后再旋转。每个精灵体的变换由形状唯一确定。
4. 确定滑动方向：精灵体沿轨道向方向标记像素指向的方向（即朝向对应条纹的方向）移动。
5. 将精灵体沿该方向平移到下一个轨道槽位对齐的位置（精灵体边界框的前缘对齐到下一个栗(9)轨道点）。擦除原位置为黑(0)，在新位置绘制变换后的精灵体。
6. 轨道点被精灵体覆盖时，精灵体像素优先显示。分区条纹保持不变。

**关键洞察**：分区条纹不仅是视觉分隔线，还隐式编码了每个精灵体的目标朝向——精灵体通过内部方向标记的颜色"读取"应该面向哪条条纹，然后旋转到位并朝那个方向移动。朝向和滑动方向由同一个标记决定，两者不可分离。
