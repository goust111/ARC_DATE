## 新题 1：载体方向射线划分区域交替填色

**组合逻辑**：[射线延伸](创新：方向由载体颜色决定而非朝固定锚点) + [洪泛填充](创新：填充对象是射线划分出的子区域而非绿色边界围成的封闭区) + [交替着色](已有原语) + [遇障碍截断](已有原语)

**来源原语**：射线延伸(ray_extend) ← d43fd935/212895b5；载体区域(carrier_region) + 颜色决定方向(color_determines_direction) ← 9b4c17c4；洪泛填充(flood_fill) + 交替着色(alternating_coloring) ← 3bd292e8；障碍像素(blocker_pixel) + 遇障碍截断(truncate_at_blocker) ← 212895b5

**依赖链**：载体颜色决定射线方向 → 射线在载体内部形成结构性隔断 → 隔断将载体区域分割成子区域 → 子区域之间交替填色。射线的几何形态直接决定子区域的形状和邻接关系，进而改变交替填色的图案。删除任一环节均无法独立求解。

用载体颜色编码的方向射线将载体区域切割成子区域，再对子区域进行交替填色。

**输入结构**：约 15x15 的黑(0)背景网格。网格中有 2-3 个互不重叠的矩形色块区域，每个区域为蓝(1)或青(8)单色填充，宽度 5-8 像素、高度 4-7 像素。每个色块区域内部分布有 1-3 个红(2)单像素标记和 0-2 个黄(4)单像素障碍。标记和障碍不与区域边界像素重合，各标记在区域内的行位置互不相同（即同一载体内没有两个标记在同一行）。生成约束：每个载体区域至少有一个标记；标记与同行障碍之间至少间隔 1 个空格。

**规则**：
1. 对每个红(2)标记像素，根据其所在载体区域的颜色决定射线方向：蓝(1)载体内的标记向右延伸，青(8)载体内的标记向左延伸。
2. 射线沿水平方向逐像素绘制红(2)，遇到以下任一条件停止（不包含停止点本身）：(a) 到达载体区域的边界像素所在列；(b) 遇到黄(4)障碍像素。
3. 红色射线连同载体区域的边界共同将每个载体的内部划分为若干 4-连通子区域。以每个载体左上角像素所在的子区域为起始区域，将其填充为灰(5)；与起始区域隔一条射线相邻的子区域填充为绿(3)；再隔一条射线的子区域回到灰(5)，如此交替。
4. 红色射线像素、黄色障碍像素、载体边界像素均保持不变。黑色背景区域不受影响。
5. 若载体内无射线（无标记的载体不存在，受生成约束保证），整个内部为灰(5)。

**关键洞察**：射线不是装饰性的线条——它们是结构性的内部隔墙，其方向由载体颜色隐式编码。求解者必须同时推断方向规则和交替填色规则，仅看单个载体无法区分"蓝→右"还是"蓝→左"。

## 新题 2：标记计数决定象限叠加顺序

**组合逻辑**：[计数](已有原语) + [排序](已有原语) + [透明叠加](创新：叠加顺序不再由象限位置固定，而由标记计数动态决定)

**来源原语**：计数(counting) + 排序(sorting) + 按计数升序排列(sorted_by_count) ← d4c90558；透明叠加(transparent_overlay) + 象限掩码(quadrant_mask) + 层叠顺序(layer_stack) ← 75b8110e；标记像素(marker_pixel) + 包含(containment) ← d4c90558

**依赖链**：计数各象限标记数 → 排序确定叠加顺序 → 叠加产生最终输出。计数结果直接决定哪个象限的掩码在最上层（可见优先），改变任何一个象限的标记数量都会改变叠加顺序从而改变重叠区域的颜色。三个操作环环相扣。

统计每个象限中灰色标记的数量，按数量从少到多依次叠加四个象限的掩码，最多标记的象限在最顶层。

**输入结构**：偶数尺寸方形网格（如 16x16 或 20x20），黑(0)背景。网格被等分为四个象限（左上、右上、左下、右下）。每个象限内包含：(a) 一个单色前景掩码图案，四个象限各用不同颜色——红(2)、绿(3)、黄(4)、蓝(1)，每个掩码由 8-20 个 4-连通前景像素组成，形状各异（不规则连通图形，无固定几何名称）；(b) 1-4 个灰(5)标记像素，放置在该象限的背景区域（不与掩码像素重合）。四个象限的灰标记数量互不相同。生成约束：四个掩码在折叠到同一画布后至少有两对存在像素级重叠。

**规则**：
1. 统计每个象限中灰(5)标记像素的数量。
2. 按标记数从小到大对四个象限排序，得到叠加顺序：标记最少的象限最先绘制（底层），标记最多的象限最后绘制（顶层）。
3. 创建一个象限尺寸大小的黑(0)输出画布。按排序后的顺序，依次将各象限的彩色掩码像素印到输出画布上，后绘制的覆盖先绘制的。
4. 灰色标记像素不出现在输出中——它们仅作为计数信号存在。

**关键洞察**：灰色标记像素在输出中完全消失，但它们的数量编码了叠加的 z-order。在参考题 75b8110e 中叠加顺序由象限位置固定，这里叠加顺序是动态的、由隐藏计数决定的。求解者必须在不同示例间对比标记数与重叠结果的对应关系才能归纳出规则。

## 新题 3：字形编码填充色的封闭区域洪泛

**组合逻辑**：[洪泛填充](创新：不再用单一全局颜色，每个区域的填充色由内嵌字形独立指定) + [重涂色](已有原语，通过字形解码获得目标色) + [字形映射颜色](创新：字形从"为邻居掩码选色"变为"为整个宿主封闭区域选色")

**来源原语**：洪泛填充(flood_fill) + 封闭区域(enclosed_region) + 拓扑内外(topological_in_out) + 仅填封闭内部(fill_enclosed_only) ← 00d62c1b；编码字形(code_glyph) + 字形映射颜色(glyph_maps_color) + 重涂色(recolor) ← ed74f2f2；边界(boundary) ← 00d62c1b

**依赖链**：拓扑检测确定封闭区域 → 在每个区域内定位并解码字形 → 解码结果决定该区域的填充颜色。字形与区域的包含关系将两个独立的逻辑（区域检测 + 颜色解码）绑定在一起——字形脱离区域无意义，区域缺少字形则颜色不确定。

检测绿色边界围成的封闭区域，解码每个区域内嵌的灰色字形以确定该区域的独立填充颜色。

**输入结构**：约 15x18 的黑(0)背景网格。绿(3)像素形成 2-4 个闭合形状（不规则多边形轮廓，每个由 12-30 个绿色边界像素构成，互不相交，内部面积各异），围成封闭的背景区域。每个封闭区域的内部某个角落处有一个 3x3 的灰(5)字形图案，字形图案有三种（每种由 4-5 个灰像素和 4-5 个黑像素在 3x3 格内排列而成）：(a) 中心像素加四个正交邻居（形成十字，5 个灰像素）→ 映射蓝(1)；(b) 中心像素加四个对角邻居（形成叉形，5 个灰像素）→ 映射红(2)；(c) 占据 3x3 区域某个角的 2x2 子块（4 个灰像素）→ 映射黄(4)。字形不接触绿色边界像素。绿色边界外部的黑色区域（与网格边缘连通的部分）不含任何前景像素。生成约束：每个封闭区域的面积至少为 16 个像素（包括字形占位），同一种字形可出现在不同区域中。

**规则**：
1. 用 4-连通洪泛从网格边角出发标记所有外部背景像素（与网格边缘连通的黑色区域）。
2. 识别所有未被标记的黑(0)像素区域——它们是被绿色边界封闭的内部区域。
3. 对每个封闭区域，定位其内部的 3x3 灰(5)字形并解码：十字形 → 蓝(1)；叉形 → 红(2)；角块形 → 黄(4)。
4. 将该封闭区域内所有非绿色像素（包括字形像素本身和黑色空白像素）全部涂为解码所得的颜色。
5. 绿色边界像素和外部背景区域保持不变。

**关键洞察**：每个封闭区域携带自己的颜色指令——字形是嵌入式元数据而非待变换的对象。求解者必须同时掌握拓扑封闭检测和字形解码两套规则，缺一不可。仅看单个区域可以猜到一种字形的映射，但需要多个区域和多个示例来确认完整的编码表。

## 新题 4：模板形状匹配筛选目标后逐列调色带重涂

**组合逻辑**：[归一化形状比对](已有原语，用于筛选目标) → [重涂色](创新：不再涂为单一颜色，而是按调色带逐列涂色) + [调色带指定列色](已有原语)

**来源原语**：模板对象(template_object) + 归一化形状比对(normalized_shape_matching) + 匹配模板则重涂(recolor_on_match) ← 4ff4c9da；调色带(palette_strip) + 逐列对应(column_correspondence) + 调色带指定列色(palette_assigns_color) ← 278e5215；连通分量(connected_component) ← 4ff4c9da；重涂色(recolor) ← 4ff4c9da/278e5215

**依赖链**：模板形状确定"重涂哪些对象"→ 调色带确定"重涂成什么颜色"→ 逐列对应决定每一列的具体颜色。形状匹配是筛选门，调色带是颜色源，两者缺一不可——没有匹配就不知道涂谁，没有调色带就不知道涂什么。

用青色模板的形状在网格中筛选出形状匹配的对象，然后按调色带逐列为这些对象重新上色。

**输入结构**：约 18x18 的黑(0)背景网格。网格中分布 5-8 个单色 4-连通对象，每个对象由 4-8 个像素组成，颜色为红(2)或蓝(1)，形状各异（不规则连通图形，边界框宽度 2-4 像素）。其中有一个青(8)对象作为模板，像素数 4-6 个。网格底部有一个 3 行的调色带矩形，宽度等于青色模板的边界框宽度：前两行是相同的逐列颜色序列（颜色取自 {绿(3)、黄(4)、橙(7)、品红(6)}），第三行为统一的灰(5)。生成约束：红色和蓝色对象中恰好有一种颜色的部分对象（不是全部）与青色模板形状匹配（平移归一化后像素集合相同），另一种颜色的所有对象均不匹配；至少有一个匹配对象和一个不匹配的同色对象。

**规则**：
1. 将青(8)模板对象的形状平移归一化（将边界框左上角对齐到原点）。
2. 对每个非黑、非青、非调色带的 4-连通对象，同样平移归一化后与模板形状比较。
3. 形状匹配的对象被选为重涂目标。对每个目标对象：以其边界框为参考，按列将对象中的像素重涂为调色带对应列的颜色（目标对象边界框的第 k 列对应调色带的第 k 列颜色）。边界框内的背景像素不变。
4. 不匹配的对象保持原色不变。
5. 输出中移除青色模板和调色带（设为黑色背景）。

**关键洞察**：形状匹配和调色带是两个独立的信息源，必须同时使用才能完成变换——匹配决定"谁被涂"，调色带决定"涂什么"。参考题 4ff4c9da 中匹配后涂为单一颜色，参考题 278e5215 中调色带作用于整个蒙版；此题将两个机制交织，形成"先筛后涂、涂法逐列"的新结构。

## 新题 5：封闭区域内精灵体按全局象限旋转后平铺

**组合逻辑**：[洪泛填充](已有原语，用于区域检测) + [平铺](创新：不再对整个输入平铺，而是在每个封闭区域内部独立平铺该区域自身的精灵体) + [旋转](创新：旋转角度由区域在全局网格中的象限位置决定)

**来源原语**：洪泛填充(flood_fill) + 封闭区域(enclosed_region) + 仅填封闭内部(fill_enclosed_only) + 拓扑内外(topological_in_out) ← 00d62c1b；平铺(tile) + 旋转(rotate) + 四象限各不同旋转(quadrant_rotation) ← cf5fd0ad；精灵体(sprite) ← f5c89df1

**依赖链**：封闭区域检测确定"在哪些区域内操作"→ 从每个区域中提取精灵体 → 区域中心在全局网格中的象限位置决定旋转角度 → 旋转后的精灵体在该区域内部平铺。四个环节串联且各自不可省略：无区域检测则不知边界，无精灵体提取则无平铺素材，无象限判定则不知旋转量，无平铺则输出不完整。

检测封闭区域并提取各区域内的小精灵体，根据区域在全局网格中的象限位置旋转精灵体后平铺填满区域内部。

**输入结构**：约 20x20 的黑(0)背景网格。红(2)边界像素形成 3-4 个互不相交的闭合轮廓（每个轮廓由 14-30 个红色像素组成，围成的内部区域为近似矩形但边缘可能不规则），分散在网格的不同象限中。每个封闭区域的内部左上角区域放置一个蓝(1)精灵体——一个 2x2 至 2x3 像素的小型 4-连通图形（各区域的精灵体形状可以不同）。区域内部除精灵体外全为黑色背景。生成约束：(a) 每个封闭区域的内部面积至少为精灵体面积的 4 倍；(b) 4 个象限中至少有 3 个各包含一个封闭区域的中心点（以确保旋转规则可从示例中归纳）；(c) 精灵体紧贴区域内部的左上角（精灵体边界框的左上角与区域内部的左上角像素对齐）。

**规则**：
1. 识别所有被红(2)边界完全封闭的 4-连通内部区域。
2. 在每个区域内部，提取蓝(1)像素集合作为该区域的精灵体模板。
3. 计算该封闭区域的几何中心（边界框中心），判断其落在全局网格的哪个象限：左上象限 → 旋转 180 度；右上象限 → 顺时针旋转 90 度；左下象限 → 逆时针旋转 90 度；右下象限 → 不旋转。
4. 将旋转后的精灵体从区域内部左上角开始、按行优先顺序平铺（精灵体的边界框按行列重复排列），覆盖整个内部区域。超出区域边界的精灵体副本被裁剪（只保留落在区域内部的像素）。
5. 红色边界像素和黑色外部区域保持不变。

**关键洞察**：每个区域看上去填充了不同的平铺图案，但旋转规则是全局性的——由区域中心在网格中的象限位置决定。求解者需要对比不同象限中的区域才能归纳出旋转映射关系，单看一个区域只能观察到一种平铺方向。

## 新题 6：边界标记同色配对触发整行填充，异色配对触发双向射线汇聚

**组合逻辑**：[填充](已有原语) + [射线延伸](已有原语) + [同色配对→分支](创新：配对结果不再只是"填/不填"的二值判断，而是分支到两种不同的几何操作)

**来源原语**：同色配对(same_color_pairing) + 画布边界(canvas_boundary) + 两端同色整行填充(full_row_fill_endpoints_match) + 填充(fill) ← 22eb0ac0；射线延伸(ray_extend) + 锚点方块(anchor_square) + 对齐标记连向锚点(marker_to_anchor) + 行列对齐(row_col_alignment) ← d43fd935

**依赖链**：颜色配对测试是分支节点——匹配与否决定对该行施加截然不同的操作。填充操作和射线操作共享同一个输入结构（边界标记 + 锚点），但各自只在自己的触发条件下执行。删除配对测试则无法决定该用哪种操作；删除任一操作则对应情况的输出缺失。

对比每行左右边界标记的颜色：同色则整行填充该色，异色则从两端分别向中央锚点方块发射射线。

**输入结构**：约 12x15 的黑(0)背景网格。网格中央偏右位置有一个青(8)的 2x2 锚点方块。在 3-5 个不同的行上（这些行与锚点方块所在的行无重叠），最左列（列 0）和最右列（末列）各有一个彩色像素，颜色取自 {红(2)、绿(3)、黄(4)}。未标记的行全为背景。生成约束：至少有 1 行的左右标记同色、至少有 1 行的左右标记异色，以确保两条分支规则都可被观察到。锚点方块的列范围不与列 0 或末列重叠。

**规则**：
1. 对每个有左右边界标记的行，比较两个标记的颜色。
2. 若颜色相同：将该行从列 0 到末列（含两端标记）全部填充为该颜色。
3. 若颜色不同：从左标记向右延伸射线（画该标记的颜色），从右标记向左延伸射线（画该标记的颜色），两条射线各自延伸到青色锚点方块边界框的相邻列为止（射线不覆盖锚点方块本身）。若该行不在锚点方块的行范围内，射线仍然延伸到与锚点方块左/右边界框列对齐的列。
4. 青色锚点方块始终保持不变。
5. 无标记的行保持为背景。

**关键洞察**：同色配对测试是一个逻辑分支节点，而非简单的过滤器——它将每一行路由到两种几何操作之一。参考题 22eb0ac0 中异色行被跳过；此题中异色行不是被跳过，而是触发另一种完全不同的空间操作（射线汇聚向锚点），使得每行都产生可见输出，增加了推理复杂度。

## 新题 7：二部图墙区域决定印章模板方向

**组合逻辑**：[印章覆盖](已有原语) + [镜像](创新：镜像不再作用于半侧轮廓，而是决定模板在某些区域内的印章方向) + [二部图结构](创新：二部图的两侧不再映射到两种颜色，而是映射到两种几何方向——原始与水平翻转)

**来源原语**：印章覆盖(stamp) + 模板面板(template_panel) + 分块对应(block_correspondence) ← b190f7f5；镜像(mirror) ← bf32578f；分隔墙线(separator_wall) + 背景区域(background_region) + 四邻接连通(four_neighbor_connect) + 二部图结构(bipartite_structure) + 交替着色(alternating_coloring) ← 3bd292e8

**依赖链**：墙线分割区域 → 构建二部图确定每个区域属于哪一侧 → 二部图侧别决定模板方向（原始 vs 镜像）→ 模板印章到各区域中心。墙线拓扑直接控制模板朝向——改变一条墙线的位置就可能改变某些区域的二部图归属，从而翻转其模板方向。

用墙线将网格分割成二部图区域，从独立面板提取模板，按二部图两侧分别以原始和水平镜像方向印章到各区域。

**输入结构**：约 16x16 的网格，由两个水平排列的子面板组成，中间以一列黑(0)像素分隔。左面板（约 16x11）：灰(5)背景，红(2)墙线像素（1 像素宽的 4-连通线段，2-4 条，将灰色背景分割成 3-6 个 4-连通区域）。右面板（约 16x4）：黑(0)背景上有一个蓝(1)模板图案（3-5 个 4-连通像素，边界框约 3x3，形状不对称——水平翻转后与原始不同）。生成约束：(a) 墙线结构保证区域邻接图为二部图（即无奇数长度环路）；(b) 每个区域的面积至少为模板边界框面积的 2 倍，以确保模板可以完整印章在区域内。

**规则**：
1. 识别左面板中被红(2)墙线分隔的 4-连通灰(5)背景区域。
2. 构建区域邻接图：两个区域若共享一段墙线（即它们在墙线两侧相邻），则在图中相连。
3. 对邻接图进行二部着色：包含左面板左上角像素的区域标记为"A 侧"，与 A 侧区域相邻的标记为"B 侧"，如此交替。
4. 从右面板提取蓝(1)模板图案。
5. 对 A 侧区域：以区域边界框的中心为印章锚点，将原始模板（蓝色）印章到该位置（模板边界框中心对齐区域边界框中心，像素坐标四舍五入取整）。
6. 对 B 侧区域：将模板水平镜像后，以绿(3)颜色印章到区域边界框中心。
7. 红色墙线、黑色分隔列和右面板保持不变。若模板印章后有像素落在区域外或落在墙线上，则裁剪掉这些像素。

**关键洞察**：二部图的两侧不再对应两种平涂颜色（如参考题 3bd292e8 的灰与绿），而是对应模板的两种几何朝向和两种印章颜色。求解者必须同时推断出墙线拓扑的二部性和"A 侧=原始+蓝、B 侧=镜像+绿"的映射关系。

## 新题 8：颜色编码列滑动受封闭区域拓扑过滤

**组合逻辑**：[滑动](已有原语) + [洪泛填充](创新：洪泛填充的结果不用于涂色，而是用作空间过滤器，决定滑动后的像素是否保留) + [擦除](已有原语)

**来源原语**：滑动(slide) + 颜色决定目标列(color_determines_col) + 边缘像素(edge_pixel) + 颜色编码列(color_coded_col) ← f45f5ca7；洪泛填充(flood_fill) + 封闭区域(enclosed_region) + 拓扑内外(topological_in_out) + 仅填封闭内部(fill_enclosed_only) ← 00d62c1b；擦除(erase) ← f45f5ca7

**依赖链**：颜色编码决定目标列（"去哪"）→ 拓扑检测确定封闭区域（"哪些位置合法"）→ 合法性过滤决定像素是否存活（"去了之后留不留"）。两个独立的信息源（颜色编码 + 区域拓扑）在目标位置处交汇：目标列由颜色决定，是否保留由拓扑决定，缺少任何一个信息源都无法得到正确输出。

左边缘彩色像素按颜色编码滑动到指定列，但只有目标位置落在封闭区域内部的像素才被保留，其余被丢弃。

**输入结构**：约 12x12 的黑(0)背景网格。绿(3)边界像素在网格内部形成 1-3 个闭合轮廓（互不相交，每个由 10-20 个绿像素组成），围成封闭区域。列 0（最左列）上分布有 4-8 个彩色像素，颜色取自 {青(8)、红(2)、黄(4)、蓝(1)}，分别位于不同行。列 0 上没有绿色边界像素。生成约束：(a) 至少有 2 个左边缘像素的目标位置落在某个封闭区域内部；(b) 至少有 1 个左边缘像素的目标位置落在所有封闭区域外部，以确保过滤规则可被观察到；(c) 封闭区域不接触列 0。

**规则**：
1. 识别所有被绿(3)边界完全封闭的 4-连通黑色区域（不含边界本身）。
2. 为每个列 0 的彩色像素确定目标列：青(8)→列 2，红(2)→列 3，黄(4)→列 4，蓝(1)→列 5。
3. 对每个彩色像素，检查目标单元格（同行、目标列）是否落在某个封闭区域的内部。
4. 若在内部：在目标单元格绘制该像素的颜色。
5. 若不在内部（在外部或在绿色边界上）：该像素被丢弃，不出现在输出中。
6. 擦除列 0 上所有原始彩色像素（设为黑色背景）。
7. 绿色边界像素保持不变。封闭区域内部原本为黑色的像素（除被步骤 4 绘制的之外）保持黑色。

**关键洞察**：颜色到列的映射和拓扑过滤是两套独立的规则，必须同时掌握。单独看滑动规则（参考题 f45f5ca7），所有像素都会到达目标列；单独看拓扑规则（参考题 00d62c1b），封闭区域会被均匀填充。此题中，拓扑检测不用于填色而用于选择性过滤，将两个原本无关的机制耦合为一个有信息交汇的判定节点。
