## 新题 1：重力沉降创建封闭区域后按面积奇偶填充

**组合逻辑**：[滑动/gravity_settle](已有) + [碰撞阻挡](已有) → 动态生成[封闭区域](创新：区域不存在于输入中，由沉降拓扑涌现) → [计数](已有) → [洪泛填充 + 面积奇偶定填充色](已有原语，但作用对象从预设矩形变为动态涌现区域)

**来源原语**：滑动/gravity_settle、碰撞阻挡（d282b262）；洪泛填充、封闭区域、面积奇偶定填充色（868de0fa）；计数（2753e76c）

**依赖链**：重力沉降改变所有对象的位置 → 沉降后的对象与地板/边界共同围合出若干封闭黑色区域（这些区域在输入中不存在）→ 计算每个封闭区域的面积 → 面积奇偶决定填充颜色。删除重力步骤则无封闭区域可填；删除奇偶判定则填充颜色不确定。

将散落的前景刚体在重力作用下沉降到地板上，由沉降后的堆叠拓扑涌现出封闭区域，再按区域面积的奇偶性分别填充不同颜色。

**输入结构**：约 12x15 的网格。黑(0)背景。一条横贯全宽的灰(5)水平条（厚度 1 像素）位于大约中间偏下的行。灰条上方散布 4-6 个小型刚性 4-连通前景对象（每个 2-4 像素，每个对象为单一非黑非灰颜色，不同对象颜色可相同也可不同），位于不同高度和列位置。生成约束：任意两个对象的边界框在水平方向无重叠（列范围不交）；灰条下方无前景对象；灰条上方的对象与灰条之间至少有 1 行空隙。

**规则**：
1. 所有前景对象（灰条除外）同时向下滑动。每个对象逐行下移，当其任何像素的下一行被灰条、网格底边或已沉降的对象像素占据时停止。沉降顺序：按对象最低像素行从大到小处理（最低的对象最先沉降）。每个对象保持形状和内部颜色不变。
2. 沉降完成后，检测所有极大 4-连通的黑(0)像素区域。若一个黑色区域的所有像素到网格边界的任何 4-连通路径都必须经过非黑像素（对象像素、灰条或网格边缘），则该区域为"封闭区域"。
3. 计算每个封闭区域的面积（像素数）。
4. 面积为偶数的封闭区域用红(2)洪泛填充；面积为奇数的封闭区域用橙(7)洪泛填充。
5. 灰条和所有沉降后的对象保持原色不变。未被封闭的黑色区域保持黑色。

**关键洞察**：封闭区域完全是沉降后的拓扑涌现产物——输入中这些区域不存在。将任何一个对象水平移动一列就可能改变哪些区域被围合以及它们的面积，导致填充颜色完全不同。必须先完整模拟重力沉降，才能检测区域并判定颜色。

## 新题 2：逐面板压缩揭示隐藏平移后外推下一帧

**组合逻辑**：[压缩/compress + 阵列排布](已有) → 逐面板独立应用(创新：压缩不再是终态，而是中间表示) → [帧序列检测 + 匀速运动延续](已有原语，但作用于压缩后的抽象 3x3 帧而非原始精灵) → [外推/extrapolate + 平移](已有)

**来源原语**：压缩、阵列排布、含标记涂标记色（e57337a4）；外推、平移、帧序列、匀速运动延续（ba1aa698）

**依赖链**：原始像素级别的标记位置在各面板间无一致运动模式（块内位置随机变化）→ 必须先将每个面板压缩到 3x3 才能揭示干净的平移模式 → 检测连续帧间的恒定偏移向量 → 将该向量再应用一次得到外推帧。删除压缩步骤则运动模式不可见；删除外推步骤则压缩结果不构成最终输出。

三个并排面板各自压缩为 3x3 粗粒度地图后，发现标记模式在帧间做恒定平移，输出第四帧的 3x3 外推结果。

**输入结构**：约 9 行 x 27 列的宽网格，由 3 个等宽面板（每个 9x9）左右并排组成。每个面板的高和宽均可被 3 整除。所有面板使用完全相同的两种颜色：一种占主导的填充色（如青(8)）和一种稀疏的标记色（如红(2)）。每个面板内的标记像素分布于不同的粗粒度块中，但当面板被压缩为 3x3 时（包含标记的块记为标记色，否则记为填充色），压缩后的标记模式在三帧之间做恒定的 (dr, dc) 平移。生成约束：三帧间的平移向量相同且模式不会环绕出界；不同面板中标记在块内的局部位置不同（刻意制造像素级噪声）；第三帧平移后的模式再平移一步仍在 3x3 范围内。

**规则**：
1. 将三个面板各自独立压缩为 3x3：将每个 9x9 面板分成 3x3 的等大矩形块，若块内含任意标记色像素则输出标记色，否则输出填充色。
2. 将三个 3x3 结果视为连续帧。检测帧 1→2 和帧 2→3 之间标记模式的恒定平移向量 (dr, dc)。（生成约束保证两次偏移相同。）
3. 输出一个单独的 3x3 网格：将第三帧的标记模式按 (dr, dc) 再平移一步。移出 3x3 范围的标记位置丢弃（变为填充色）；移入范围的新位置若无标记则为填充色。

**关键洞察**：原始像素级的标记位置在面板之间刻意不同（块内偏移随机），直接比较像素找不到任何一致运动。只有先压缩到粗粒度 3x3 表示，才能看到干净的线性平移。求解者必须同时发现压缩规则和运动外推规则。

## 新题 3：视线过滤后的连通体计数直方图

**组合逻辑**：[视线可见 + 视线遮挡判断](已有) → 空间过滤(创新：视线不再驱动路径行走，而是作为统计过滤器) → [连通检测 + 计数](已有) → [排序 + 柱状填充/histogram_fill](已有，但输入集被视线过滤改变)

**来源原语**：视线可见、视线遮挡判断、起始块（3490cc26）；连通检测、计数、排序、柱状填充、按数量降序、靠端对齐（2753e76c）

**依赖链**：观察者位置决定哪些对象可见（视线过滤）→ 仅对可见对象进行连通体计数 → 按颜色汇总计数 → 降序排列生成右对齐直方图。不可见颜色完全不出现在输出中。删除视线过滤则直方图包含所有颜色（与参考题 2 无异）；删除直方图则视线检测无输出目的。

从红色观察者出发，仅对视线可见的前景对象进行分色连通体计数，将可见颜色的计数按降序排列为右对齐直方图，不可见颜色被完全排除。

**输入结构**：约 14x14 的网格。黑(0)背景。一个红(2) 2x2 方块作为"观察者"，放置在非边界位置。多个小型 4-连通单色前景对象（每个 2-5 像素，每个对象为单一非黑非红颜色）散布在网格中。至少出现 3 种不同的非红前景色，每种颜色有 1-4 个独立的 4-连通对象。部分对象被放置在其他对象的视线遮挡位置（即从观察者到该对象的所有水平/垂直射线都被其他前景像素阻断）。生成约束：可见颜色的连通体计数互不相同；至少有一种颜色完全不可见（该颜色的所有对象均被遮挡）。

**规则**：
1. 对每个非红前景对象，判定可见性：若存在至少一条从红色方块的任意像素到该对象任意像素的水平或垂直射线，使得射线内部（严格介于两端点之间的单元格）全部为黑(0)，则该对象"可见"。
2. 仅对可见对象进行分色统计：对每种非红前景色，计算其可见的 4-连通对象数量。
3. 按可见连通体数量降序排列这些颜色。
4. 生成右对齐直方图：输出宽度 = 最大可见连通体数量；每行对应一种可见颜色，从上（最多）到下（最少）排列。每行左侧为黑(0)，右侧为该行颜色重复其计数次。
5. 完全不可见的颜色不出现在输出的任何行中。

**关键洞察**：直方图不是对全局对象的完整普查，而是一个"视角依赖"的摘要。重新摆放同一批对象会改变遮挡关系，从而改变可见集合、直方图行数和每行的值。求解者需要对比多个示例才能发现不可见颜色被排除的规则（而非仅仅计数为零）。

## 新题 4：角标记一致性驱动空心矩形的填充或擦除

**组合逻辑**：[角标记 + 对角邻接](已有) + [角标一致性/corners_set_region](创新改造：从"四角同色→该色填充"扩展为"四角同色→填充，四角不同色→擦除"的分支判定) → [洪泛填充](已有) 或 [擦除](已有)（条件分支）

**来源原语**：角标记、对角邻接、四角固定配色装饰（95990924）；角标一致性、四角同色定区域色（7837ac64）；洪泛填充、空心矩形（868de0fa）；擦除（bf89d739）；分类、内部判定类型（2ba387bc）

**依赖链**：检测每个空心矩形的四个外对角角标记 → 判断四角是否颜色一致 → 一致则以该颜色填充矩形内部（填充分支），不一致则擦除整个矩形含边框和角标记（擦除分支）。角标记同时充当"分类依据"和"填充颜色来源"两个角色，两个功能耦合在同一组像素上。

检查每个灰色空心矩形四角的彩色标记像素：四角同色则用该色填充内部，否则擦除整个矩形及其角标记。

**输入结构**：约 14x14 的网格。黑(0)背景。3-5 个一像素厚的灰(5)空心矩形，大小各异（外框 3x3 到 6x6），彼此不重叠，矩形内部为黑色。每个矩形的四个几何角向外对角方向各一格处（即外框左上角的左上方一格、外框右上角的右上方一格、外框左下角的左下方一格、外框右下角的右下方一格），各有一个彩色单像素标记（非黑非灰，如蓝(1)、红(2)、绿(3)、黄(4)等）。部分矩形的四个角标记颜色完全相同；其余矩形的角标记颜色至少有一个不同。生成约束：矩形间距足够大，任何一个矩形的角标记不会落在另一个矩形的边框或角标记位置上；至少有一个矩形四角一致，至少有一个不一致。

**规则**：
1. 对每个灰色空心矩形，检查其四个外对角位置的角标记像素颜色。
2. 若四个角标记颜色完全相同：用该共同颜色洪泛填充矩形的黑色内部区域。灰色边框和四个角标记保持不变。
3. 若四个角标记颜色不全相同：擦除整个矩形（灰色边框全部变为黑(0)）以及其四个角标记（也变为黑(0)）。矩形内部保持黑色。
4. 处理顺序不影响结果（矩形互不干涉）。

**关键洞察**：角标记的外观像是纯装饰（类似参考题 95990924 的固定配色装饰），但实际上它们是一致性投票——全票一致决定填充色，任何分歧导致整体擦除。仅看一个全部一致的示例会以为是简单的角色填充规则，必须对比有不一致角标记的示例才能发现擦除分支。

## 新题 5：远程连通体计数编码障碍排斥半径的路径规划

**组合逻辑**：[连通检测 + 计数](已有) → 计数结果作为参数注入(创新：计数不再生成直方图输出，而是编码为空间操作的参数) → [避障 + 禁区 + 像素计数编码半径](创新改造：半径不由障碍物自身的像素数决定，而由远程同色散点的数量决定) → [连线/draw_path + 路径起点](已有)

**来源原语**：连线、避障、禁区、路径起点、像素计数编码半径（cb2d8a2c）；连通检测、计数（2753e76c）；擦除（bf89d739）

**依赖链**：统计每种障碍颜色在网格中的孤立散点数量 → 该数量成为同色障碍条的排斥半径 → 路径从起点出发绕开各障碍条的排斥区域行进到对边 → 绘制路径后擦除所有孤立散点。散点与障碍条空间上分离，但通过颜色关联；删除散点计数步骤则排斥半径未知，删除路径绘制步骤则计数结果无用。

统计网格中每种障碍色的孤立同色散点数量，以此作为该色障碍条的排斥半径，从绿色起点绘制路径绕开所有排斥区域到达对边，最后擦除所有散点。

**输入结构**：约 14x16 的网格。青(8)背景。一个绿(3)单像素位于网格某一条边上（路径起点）。2-3 条水平或垂直的障碍线段，每条为一种非青非绿颜色（如红(2)、蓝(1)、黄(4)），长度 3-6 像素，宽度 1 像素。对于每种障碍颜色，网格中还散布着若干同色孤立单像素（不与该色的障碍线段 4-连通），每个孤立点自成一个 4-连通分量。生成约束：不同障碍色的孤立散点数量互不相同，范围为 1-3；在对应的排斥半径下，从绿色起点到对边存在合法路径；障碍线段之间不相邻。

**规则**：
1. 对每种障碍颜色 C，统计颜色 C 在网格中不与障碍线段 4-连通的孤立单像素数量 N(C)。N(C) 即为颜色 C 的障碍线段的排斥半径。
2. 从绿色起点向对边延伸路径。路径每步沿水平或垂直方向前进一格。路径必须与每种颜色 C 的障碍线段的每个像素保持切比雪夫距离严格大于 N(C)。
3. 路径尽可能直行，仅在直行会进入某条障碍的排斥区域时才做直角转弯。在有多条合法路径时，选择转弯次数最少的路径。若转弯次数仍相同，选择第一个转弯点离起点最远的路径。
4. 路径以绿(3)绘制。
5. 绘制完成后，所有孤立散点（用于编码半径的点）被擦除为青(8)背景。障碍线段本身保持不变。

**关键洞察**：障碍线段的危险程度不由线段自身的任何属性决定，而由远处同色散点的数量编码。散点看起来像噪声，但它们是障碍参数的密码本——数量越多，同色障碍越危险。求解者必须在空间上分离的元素之间建立颜色关联，才能推导出每条障碍的正确排斥半径。

## 新题 7：最密分区定义主干轴线后其余分区生成垂直连接线

**组合逻辑**：[计数 + 筛选 + 最密区域保留填充](已有) → 最密区域的空间位置涌现为主干轴线(创新：主干不由共行列像素定义，而由统计最大值的空间位置推导) → [连线 + 连接到主干](已有原语，但主干来源从坐标重复变为统计选举) → [擦除](已有)

**规则**：
1. 统计每个分区内的非黑非灰彩色像素数量。识别唯一的最密分区（像素数最多）。
2. 用该分区的颜色洪泛填充整个最密分区（覆盖其中的黑色间隙）。
3. 确定最密分区内部区域的中心行（内部行范围的中位行，若为偶数行则取靠上的）和中心列（内部列范围的中位列，若为偶数列则取靠左的）。以灰(5)沿该中心行画一条贯穿全网格的水平线，沿该中心列画一条贯穿全网格的垂直线。这两条线构成十字主干轴线（与已有分隔线视觉上相同但可能位于分区内部）。
4. 对每个非最密分区：计算该分区中心像素到水平主干轴线的行距和到垂直主干轴线的列距。选择距离更近的轴线（若相等则选水平轴线）。从该分区的中心像素出发，沿垂直方向（若连接水平轴线）或水平方向（若连接垂直轴线）画一条一像素宽的直线，颜色为该分区的原始颜色，直到到达对应的主干轴线（不包含轴线本身的那一格）。
5. 擦除所有非最密分区中的原始散点像素（变为黑色），仅保留步骤 4 中画出的连接线。
6. 原有的灰色分隔线保持不变。

**关键洞察**：主干轴线不是预设在输入中的——它由"哪个分区最密"这个全局统计量的空间位置推导出来。如果改变一个像素使另一个分区成为最密者，主干轴线就会移到完全不同的位置，所有连接线的方向和长度都会随之改变。统计选举与几何绘制之间的耦合是本题的核心。

## 新题 8：镜像色带后由标记总数编码镜像副本的腐蚀半径

**组合逻辑**：[镜像 + 色带翻转到对侧 + 对称](已有) → 镜像产生副本(创新：副本不是原样复制，而是受损的复制) → [计数](已有) → 计数结果编码为半径(创新：标记总数的全局属性编码每个标记的局部效果) → [擦除 + 禁区](已有原语，但作用于镜像副本中的特定区域)

**来源原语**：镜像、对称、色带翻转到对侧、色带行（496994bd）；计数、前景像素（794b24be）；擦除（bf89d739）；像素计数编码半径、禁区（cb2d8a2c）；标记像素（e57337a4）

**依赖链**：原始顶部色带（含嵌入标记）完整镜像到底部 → 统计色带中标记像素的总数 T → 每个标记在镜像副本中的对应位置生成切比雪夫半径为 (T-1) 的腐蚀区 → 腐蚀区内的镜像像素被擦除。标记数量越多，每个标记的破坏力越大（因为 T-1 更大），产生非线性的损伤放大效应。

将顶部色带镜像到底部，但色带中嵌入的标记像素在镜像副本中制造腐蚀孔洞——每个标记的腐蚀半径等于标记总数减一，标记越多，每个孔洞越大。

**输入结构**：约 12x12 的网格。黑(0)背景。顶部 2-3 行为贯穿全宽的彩色色带，色带主色为一种前景色（如蓝(1)）。色带内嵌入 1-3 个单像素的标记，颜色与色带主色不同（如红(2)）。色带下方所有行均为黑色。生成约束：标记像素不在色带最顶行；各标记之间的间距足够大，使得当标记数 = 2 时腐蚀半径为 1、标记数 = 3 时腐蚀半径为 2 时，腐蚀区在镜像副本中不互相覆盖完全重叠（允许部分重叠）；色带宽度足以让腐蚀后仍有可见残留。

**规则**：
1. 将顶部色带镜像到网格底部：色带的行序上下翻转后放置在网格最底部的对应行数内。原始顶部色带保持不变。中间的黑色间隔保持不变。
2. 统计原始色带中标记像素的总数 T。
3. 对原始色带中的每个标记像素，找到它在镜像副本中的对应位置（行翻转后的坐标）。
4. 在镜像副本中，以每个标记对应位置为中心，将切比雪夫距离 <= (T-1) 范围内的所有镜像副本像素擦除为黑(0)。此擦除仅影响镜像副本区域，不影响原始色带和中间间隔。
5. 原始色带（包括其中的标记像素）完全不变。

**关键洞察**：标记像素具有双重角色——它们是色带图案的一部分（被镜像复制），同时又是腐蚀炸弹（在镜像副本中制造空洞）。更微妙的是，每个标记的破坏力不是固定的，而是由标记总数全局决定的：1 个标记时半径为 0（无破坏），2 个标记时每个半径为 1（小孔），3 个标记时每个半径为 2（大洞）。这种"群体越大个体越强"的非线性规则需要对比不同标记数量的示例才能归纳。
