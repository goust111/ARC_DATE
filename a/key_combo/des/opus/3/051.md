## 新题 1：封闭区域内的对角周期修复

**组合逻辑**：[洪泛填充](判定区域封闭性) + [补全/对角周期](仅在封闭区域内独立推断并填充) + [描边/内外边界分色](区分已修复区域与未修复区域的边界)（洪泛填充为已有原语但作用从"直接涂色"变为"分类门控"；补全为已有原语但从全局模式变为逐区域独立推断；描边为已有原语但触发条件从"蓝色边缘"变为"已修复 vs 未修复"）

**来源原语**：洪泛填充/区域封闭/孤立背景区域填充(a5313dff), 补全/对角周期图案/对角线同余/对角周期补缺失(c3f564a4), 描边/内外边界/内外边界分色(d931c21c), 墙壁线段(a5313dff)

**依赖链**：洪泛填充将所有背景区域分为"封闭"与"开放"两类 → 分类结果决定哪些区域执行对角周期补全（仅封闭区域）→ 每个封闭区域的可见像素独立推断出各自的对角周期参数 → 补全结果改变了封闭区域的像素内容 → 描边操作对已修复的封闭区域画绿(3)内边界，未修复的开放区域画红(2)外边界，最终输出中边界颜色反映了区域是否被修复

对角周期补全在每个封闭区域内独立运行，将该区域中的黑(0)像素替换为由该区域可见非黑像素推断出的对角周期颜色；封闭区域边界像素着绿(3)标记已修复，开放区域的墙壁外侧像素着红(2)标记未修复。

**输入结构**：约 15x15 的网格，黑(0)背景。红(2)像素构成单像素宽的墙壁线段，形成若干不规则闭合轮廓和若干不闭合的开放轮廓（生成时保证至少 2 个封闭区域和至少 1 个与网格边界相通的开放区域）。每个封闭区域内部散布 3~5 个非黑前景像素（可使用蓝(1)、黄(4)、橙(7)等，每个封闭区域使用的颜色集合相同但对角周期参数——即周期长度和起始偏移——可以不同）。开放区域内部也散布少量相同颜色集合的像素作为干扰。生成约束：每个封闭区域内的可见前景像素足以唯一确定一个对角周期（即 (row+col) mod cycle_length 到颜色的映射），且不同封闭区域的周期参数至少有一项不同（周期长度或起始偏移不同）。

**规则**：
1. 以红(2)像素为墙壁，从网格四条边界出发做 4-邻域洪泛填充，标记所有可达的黑(0)像素为"外部"。未被标记的黑(0)像素为"内部"（属于某个封闭区域）。红(2)像素本身不变。
2. 对每个 4-连通的内部黑(0)像素团（即每个封闭区域的内部），收集该区域中所有已有的非黑前景像素，推断对角周期：计算 cycle_length = 该区域使用的非黑颜色种数，建立映射 (row + col) mod cycle_length → 颜色。
3. 将该封闭区域内所有黑(0)像素替换为映射给出的颜色。
4. 描边：对每个已修复的封闭区域，将其 8-邻域中属于红(2)墙壁的像素重涂为绿(3)。对每个未修复的开放区域，将其 8-邻域中属于红(2)墙壁的像素保持红(2)不变。若某段红(2)墙壁同时邻接封闭区域和开放区域，该墙壁像素涂绿(3)（封闭侧优先）。
5. 外部黑(0)像素和开放区域内的干扰前景像素均保持不变。

**关键洞察**：墙壁既是洪泛填充的障碍（决定哪些区域封闭），又是对角周期的边界（不同封闭区域独立推断各自的周期参数）；最终墙壁自身的颜色变化（绿或保持红）反过来编码了洪泛填充的分类结果，形成三层逻辑的循环依赖：墙壁→区域分类→补全→墙壁重涂色。

## 新题 2：边框色编码重力方向的分组排序堆叠

**组合逻辑**：[颜色匹配边](将线段按颜色分组到四个方向) → [滑动](每组线段朝匹配的边框边滑动) + [排序/按长度递增堆叠](同组内按长度排序后依次堆叠)（颜色匹配边为已有原语但从"单像素平移一格"变为"分组依据"；排序为已有原语但从单一方向变为四个独立方向）

**来源原语**：边框边/颜色匹配边/朝匹配边移动(5034a0b5), 排序/线段/对齐/按长度递增堆叠(beb8660c), 滑动(494ef9d7), 擦除(494ef9d7)

**依赖链**：边框四边颜色定义四个方向组 → 每条内部线段的颜色决定它属于哪个方向组 → 同组线段按长度排序 → 排序后的线段从匹配边框边开始向内依次堆叠 → 不同方向组的堆叠相互独立，但若堆叠区域在中心交汇重叠，长线段覆盖短线段

输入中散落的彩色水平/垂直线段各自"坠向"与其颜色相同的边框边，同方向的线段按长度从短到长依次堆叠在该边附近。

**输入结构**：约 13x13 的网格。最外一圈为单像素宽的矩形边框，四个角落像素为黑(0)。上边为蓝(1)，下边为红(2)，左边为黄(4)，右边为橙(7)（四种不同颜色，不同示例中具体颜色-边的对应关系可能不同，需从示例归纳）。内部（边框之内）为黑(0)背景，散布 6~10 条单像素宽的水平或垂直线段，每条线段长度 2~5 像素，颜色为上述四种边框色之一。生成约束：每种边框色至少对应 1 条内部线段；水平线段只能匹配上边或下边颜色，垂直线段只能匹配左边或右边颜色（线段方向与其匹配边框边的朝向一致）；线段初始位置互不重叠。

**规则**：
1. 识别边框四边各自的颜色（角落黑(0)像素不属于任何边）。
2. 对每条内部线段，根据其颜色找到匹配的边框边。该边框边所在的方向即为该线段的"重力方向"。
3. 将同一方向组的线段按长度升序排序（长度相同时，按距该边框边从近到远的初始位置排序，近者优先）。
4. 擦除所有线段的原始位置。
5. 从匹配的边框边紧邻的第一行/列开始，依次放置排序后的线段：最短的线段紧贴边框边，次短的在下一行/列，依此类推。每条线段在其堆叠行/列内居中对齐（若线段长度为偶数且堆叠空间为奇数宽度，则偏左/偏上）。
6. 若两个方向组的堆叠区域在网格中心附近重叠（水平线段与垂直线段交叉），交叉像素取后放置的线段颜色（按上、右、下、左的固定放置顺序，左组最后放置因此优先级最高）。

**关键洞察**：边框颜色不只是装饰——它同时编码了"哪些线段归这一组"和"这一组朝哪个方向堆叠"两层信息，而且颜色-方向的对应关系在不同示例中可能轮换，必须从每个示例的边框观察得出。

## 新题 3：图例重涂色后的象限叠加与孔洞穿透

**组合逻辑**：[重涂色/图例映射](按图例修改面板前景色) → [透明叠加/图层优先级](四象限叠加) + [孔洞保留不填](孔洞作为透明窗口穿透图层)（重涂色为已有原语但触发源从"左侧图例"变为"角落图例"；透明叠加为已有原语但叠加中孔洞的语义从"不填"变为"向下穿透"）

**来源原语**：重涂色/颜色图例/图例映射(5adee1b2), 透明叠加/图层优先级/象限位决定层序(e99362f0), 封闭孔洞/孔洞保留不填(5adee1b2), 十字分隔线/面板(e99362f0), 裁剪(337b420f)

**依赖链**：角落图例定义颜色映射 → 重涂色改变每个象限中前景对象的颜色 → 叠加时图层优先级决定冲突区域取哪个象限的颜色 → 但高优先级层中的孔洞不遮挡低优先级层，而是让低层内容透出 → 最终输出同时取决于图例映射结果和孔洞的空间位置

四象限各有带孔洞的前景图形，先按角落图例重涂颜色，再叠加为单一画布；高优先级象限的孔洞像玻璃窗一样露出下层内容。

**输入结构**：约 15x15 的网格（奇数行奇数列），灰(5)像素构成一条完整的十字分隔线（正中间行和正中间列），将网格分为四个大小相等的矩形象限。左上角的 2x2 区域为颜色图例：左列像素颜色为"源色"，右列像素颜色为"目标色"（共 2 行，映射 2 种颜色）。每个象限内有黑(0)背景和恰好一个 4-连通的单色前景对象（3~8 像素），其中至少 2 个象限的前景对象内部包含 1~2 个被前景像素完全包围的黑(0)孔洞（孔洞为不与象限边界 4-连通的黑(0)连通分量）。前景对象使用图例中的源色（如蓝(1)和红(2)），不同象限可以使用不同源色。生成约束：图例中的两种源色各至少在一个象限中出现；叠加后至少有一处因孔洞穿透产生与普通叠加不同的结果。

**规则**：
1. 读取左上角 2x2 图例，建立源色→目标色映射（如蓝(1)→绿(3)，红(2)→橙(7)）。
2. 擦除图例区域（置为黑(0)）和十字分隔线（置为黑(0)）。
3. 对每个象限，将其中所有源色前景像素替换为对应目标色。孔洞（黑(0)像素）保持黑(0)不变。
4. 将四个象限按局部坐标对齐，叠加到一个与象限同大的输出画布上。图层从底到顶的顺序固定为：左下 → 右上 → 左上 → 右下（右下最高优先级）。
5. 叠加规则：从底层到顶层依次绘制。当高优先级层的某像素为非黑前景时，覆盖下层。当高优先级层的某像素为黑(0)且该像素位于该层某前景对象的孔洞内时，不覆盖，保留下层已有内容（孔洞穿透）。当高优先级层的某像素为黑(0)且不在任何孔洞内（即普通背景）时，不覆盖，保留下层已有内容。
6. 若画布某位置所有四层均为黑(0)，输出黑(0)。

**关键洞察**：图例在叠加之前改变了颜色，因此叠加冲突发生在目标色之间而非源色之间；同时孔洞虽然视觉上是空的，但在高优先级层中它的语义是"此处该层不参与遮挡"——这使得某些被高优先级层覆盖的区域反而能显示低优先级层的内容，必须同时理解图例映射和孔洞穿透才能正确推断输出。

## 新题 4：空心矩形内面积决定印章填充模式

**组合逻辑**：[计数/面积比较](比较空心矩形内面积) → [印章覆盖](大内面积矩形接收模板铺贴) / [循环填充](小内面积矩形改为同心层涂色)（计数为已有原语但从"输出计数摘要"变为"决定后续操作分支"；印章覆盖为已有原语但目标从掩码标记变为空心矩形内部；循环填充为已有原语但触发条件从"始终执行"变为"面积不足时的替代方案"）

**来源原语**：计数/面积比较/最大内部面积胜出(445eab21), 印章覆盖/模板区/分隔行(b4a43f3b), 循环填充/同心层/边距深度/奇偶交替着色(516b51b7), 空心矩形/封闭区域(445eab21), 裁剪(337b420f)

**依赖链**：分隔行上方的模板确定印章内容 → 分隔行下方的空心矩形各自的内面积被计算 → 内面积 >= 模板面积的矩形内部铺贴模板 → 内面积 < 模板面积的矩形内部改为同心层交替涂色 → 两种填充模式的结果都保留空心矩形的边框不变

分隔行上方的小模板被铺贴进下方足够大的空心矩形内部；空间不足的矩形则改用同心层交替着色填充。

**输入结构**：约 18x12 的网格，黑(0)背景。顶部有一个由单色 2x2 块组成的模板区（约 4x4 像素，即 2x2 的粗粒度模板，使用蓝(1)和绿(3)两色），模板区下方紧接一行灰(5)分隔行横跨全宽。分隔行下方有 3~5 个互不重叠的空心矩形，每个矩形边框为单像素宽的品红(6)，内部为黑(0)。各矩形大小不同：有的内部区域（不含边框）面积 >= 4（即模板粗粒度面积 2x2=4），有的内部区域面积 < 4。生成约束：至少 1 个矩形内面积 >= 4，至少 1 个矩形内面积 < 4；矩形互不相邻（间距 >= 1 像素）。

**规则**：
1. 识别灰(5)分隔行，将其上方区域作为模板区。将模板区的每个 2x2 块压缩为一个像素颜色，得到一个 2x2 的粗粒度模板瓦片。
2. 识别分隔行下方所有品红(6)边框的空心矩形。对每个矩形，计算其严格内部区域的面积（行数 x 列数，不含边框像素）。
3. 对内面积 >= 粗粒度模板面积（2x2=4）的矩形：从内部左上角开始，以粗粒度模板为瓦片向右向下周期铺贴，每个瓦片像素扩展回 2x2 块绘制。超出内部边界的部分裁剪掉。
4. 对内面积 < 4 的矩形：对其内部像素按距矩形边框的切比雪夫距离分层（最外层距离 1，向内递增）。距离为奇数的像素涂红(2)，距离为偶数的像素涂黄(4)。若内部只有一层，涂红(2)。
5. 所有矩形的品红(6)边框、灰(5)分隔行、模板区原有像素均保持不变。

**关键洞察**：同一类对象（空心矩形）根据内面积大小走完全不同的变换路径——大矩形执行模板铺贴，小矩形执行同心层着色——面积阈值由模板自身的大小隐式决定，求解者必须先理解模板尺寸才能判断分支条件。

## 新题 5：异或掩码调制同心层着色反转

**组合逻辑**：[循环填充/同心层](为矩形生成分层底图) + [异或](掩码与底图逐像素比较) → [重涂色](异或为真的位置反转同心层颜色)（循环填充为已有原语但结果不是最终输出而是中间底图；异或为已有原语但操作对象从"两个等大掩码"变为"掩码 vs 几何生成的图案"）

**来源原语**：循环填充/同心层/边距深度/奇偶交替着色(516b51b7), 异或/分隔行/掩码/逐像素异或输出(3428a4f5), 重涂色(5adee1b2), 实心矩形(516b51b7)

**依赖链**：分隔行上方的二值掩码独立存在 → 分隔行下方的实心矩形先执行同心层着色生成底图 → 底图被二值化（非黑=1，黑=0）→ 与上方掩码逐像素异或 → 异或为 1 的位置，底图颜色在红(2)/绿(3)之间反转；异或为 0 的位置保持不变

实心矩形先着上同心层交替色，再由上方掩码通过异或选择性反转部分层的颜色。

**输入结构**：约 15x11 的网格。顶部为一个与下方区域等宽的二值掩码区（高度 h 行），使用黄(4)表示"活跃"、黑(0)表示"非活跃"。紧接一行灰(5)分隔行横跨全宽。分隔行下方为黑(0)背景区域（高度也恰好为 h 行，与掩码等高等宽），包含 1~3 个不重叠的实心矩形，颜色为蓝(1)。生成约束：每个矩形的最小边长 >= 3（保证至少 2 层同心层）；掩码中黄(4)像素的分布与矩形位置有部分重叠也有部分不重叠。

**规则**：
1. 识别灰(5)分隔行，分离上方掩码区和下方矩形区。二者行数和列数相同。
2. 对下方区域的每个蓝(1)实心矩形，计算每个蓝像素到该矩形边缘的切比雪夫距离 d（边缘像素 d=0）。d 为偶数的像素涂红(2)，d 为奇数的像素涂绿(3)。完成后下方区域成为"同心底图"。
3. 将同心底图二值化：非黑像素记为 1，黑(0)像素记为 0。将上方掩码二值化：黄(4)记为 1，黑(0)记为 0。
4. 逐像素计算二者的异或。对异或结果为 1 且底图该位置为非黑的像素：若底图为红(2)则改为绿(3)，若底图为绿(3)则改为红(2)。对异或结果为 1 且底图为黑(0)的像素（即掩码活跃但底图无矩形覆盖的位置）：不做任何改变（保持黑(0)）。异或结果为 0 的像素保持底图不变。
5. 输出为处理后的下方区域（不含掩码区和分隔行）。

**关键洞察**：掩码并不直接决定输出颜色——它只决定同心层的颜色是否被反转；最终每个像素的颜色同时取决于它在矩形中的几何深度（决定初始红/绿）和它在掩码中对应位置的活跃状态（决定是否翻转），两种信息缺一不可。

## 新题 6：面积竞选胜者按标记方向镜像扩展

**组合逻辑**：[比较/面积比较](选出最大内面积对象) + [擦除](移除落选者) + [镜像](按标记方向镜像胜出对象) + [相邻拼接](镜像体贴合放置)（比较为已有原语但选择结果不是输出颜色块而是决定哪个精灵体存活；镜像为已有原语但方向由独立的十字标记编码而非精灵体自身属性）

**来源原语**：比较/空心矩形/面积比较/最大内部面积胜出(445eab21), 镜像/精灵体/十字标记/相邻拼接/最长臂决定镜像侧(9bebae7a), 擦除(494ef9d7), 封闭区域(445eab21)

**依赖链**：识别所有空心矩形框并计算内面积 → 面积最大者胜出，其内部的精灵体被保留 → 十字标记的最长臂方向决定镜像轴 → 胜出精灵体沿该轴镜像并贴合放置在原精灵体的对应侧 → 落选矩形框及其内容全部擦除为背景

多个空心矩形框各自内嵌一个小精灵体，比较矩形框内面积选出胜者，然后按十字标记指示的方向镜像拼接胜出的精灵体。

**输入结构**：约 16x16 的网格，黑(0)背景。有 2~3 个互不重叠的空心矩形框，每个框为单像素宽的单色边框（不同框颜色不同，可使用蓝(1)、红(2)、黄(4)等），内部为黑(0)背景加一个 4-连通的绿(3)小精灵体（3~6 像素，形状不规则，各框内精灵体形状不同）。各框的内面积（边框内部行数x列数）互不相同。另有一个橙(7)十字标记（一个中心像素向四个正交方向各延伸若干像素形成十字，其中恰好一个臂比其余三个臂长至少 1 像素）。十字标记不与任何矩形框重叠。生成约束：胜出精灵体的边界框到网格边缘在镜像方向上有足够空间放置镜像副本。

**规则**：
1. 识别所有空心矩形框。对每个框，计算其严格内部面积（不含边框的行数 x 列数）。
2. 选出内面积最大的唯一矩形框，记为"胜出框"。提取其内部的绿(3)精灵体。
3. 识别橙(7)十字标记的中心像素和四个臂。找到唯一最长臂，将该臂方向顺时针旋转 90 度得到"镜像拼接侧"（如最长臂朝上 → 拼接侧为右；朝右 → 拼接侧为下；朝下 → 拼接侧为左；朝左 → 拼接侧为上）。
4. 擦除所有非胜出框的矩形框及其内容（置为黑(0)）。擦除十字标记（置为黑(0)）。擦除胜出框的边框像素（置为黑(0)），仅保留胜出精灵体。
5. 将胜出精灵体沿拼接侧对应的轴做镜像：拼接侧为左或右时水平翻转，拼接侧为上或下时垂直翻转。
6. 将镜像副本紧贴胜出精灵体的边界框在拼接侧方向放置，两者之间无间隙。镜像副本颜色保持绿(3)。

**关键洞察**：空心矩形框本身不出现在输出中——它们仅作为"竞选容器"提供面积比较的依据；十字标记独立于竞选过程，仅编码镜像方向。求解者必须分别理解"谁胜出"（面积比较）和"怎么镜像"（标记方向），两个判断来源完全不同。

## 新题 7：行列标签交叉掩码内的对角周期补全

**组合逻辑**：[行列交叉/标签同色时填充](行列标签颜色比较生成二值掩码) + [补全/对角周期](在掩码活跃区域内推断并补全对角周期图案)（行列交叉为已有原语但输出从"直接涂该标签色"变为"生成活跃掩码"；补全为已有原语但从"全局补全"变为"仅在掩码内补全"）

**来源原语**：行标签/列标签/行列交叉/标签同色时填充(a406ac07), 补全/对角周期图案/对角线同余/对角周期补缺失(c3f564a4), 内部单元格(a406ac07)

**依赖链**：右边和底边的标签颜色逐对比较 → 匹配的交叉单元格构成"活跃区域" → 活跃区域中已有的散布前景像素用于推断对角周期 → 推断出的对角周期仅填充活跃区域中的黑(0)像素 → 非活跃区域无论有无前景像素均保持黑(0)

右边和底边的颜色标签决定哪些内部单元格是"活跃"的，活跃区域内隐含的对角周期图案被补全，非活跃区域保持空白。

**输入结构**：约 10x10 的网格。最右列为行标签：每个像素为蓝(1)、红(2)或黄(4)之一。最底行为列标签：每个像素为蓝(1)、红(2)或黄(4)之一（右下角像素为黑(0)，不属于任何标签）。内部区域（不含最右列和最底行）为黑(0)背景，其中散布若干非黑前景像素（使用绿(3)、橙(7)、品红(6)中的 2~3 种颜色）。前景像素仅出现在"活跃位置"——即行标签色等于列标签色的交叉位置，但并非所有活跃位置都有前景像素（部分活跃位置为黑(0)待补全）。生成约束：活跃位置中的已有前景像素足以唯一确定一个全局对角周期（(row+col) mod cycle_length → 颜色映射），且 cycle_length 等于使用的前景颜色种数。

**规则**：
1. 读取最右列的行标签和最底行的列标签。对内部每个单元格 (r, c)，比较第 r 行的行标签颜色与第 c 列的列标签颜色。
2. 若二者相同，该单元格为"活跃"；否则为"非活跃"。
3. 收集所有活跃位置中已有的非黑前景像素，推断对角周期：cycle_length = 前景颜色种数，建立映射 (row + col) mod cycle_length → 颜色。
4. 对每个活跃且当前为黑(0)的单元格，填充为映射给出的颜色。
5. 非活跃单元格保持黑(0)，无论其当前是否有前景像素（若生成时保证非活跃位置无前景像素，则此条无实际效果，但规则上如此定义以排除歧义）。
6. 行标签列和列标签行保持不变。

**关键洞察**：标签的颜色比较仅生成一个空间掩码，不直接决定内部单元格的颜色——单元格颜色由独立的对角周期决定；但对角周期的推断只能使用活跃位置的线索像素，所以掩码间接约束了周期推断的信息来源，两层逻辑通过"哪些线索可用"这一隐式通道耦合。

## 新题 8：图例色膨胀后按面积排序堆叠

**组合逻辑**：[膨胀/图例映射](按图例为每个对象画色框) → [排序/按长度递增堆叠](按膨胀后的总面积排序并重新排列)（膨胀为已有原语但作用从"就地扩展"变为"计算排序键"；排序为已有原语但排序键从"线段长度"变为"膨胀后面积"）

**来源原语**：膨胀/颜色图例/图例映射/孔洞保留不填(5adee1b2), 排序/对齐/按长度递增堆叠(beb8660c), 连通分量(337b420f), 条带(beb8660c)

**依赖链**：左侧图例定义对象色→光晕色映射 → 每个对象就地膨胀一圈得到光晕 → 计算每个对象含光晕的总边界框面积 → 按此面积升序排序 → 将对象（含光晕）从网格底部的条带上方开始向上依次堆叠，每个对象水平居中 → 原始位置擦除

散落的彩色对象各自膨胀出图例指定颜色的光晕，然后按膨胀后面积从小到大堆叠在底部条带上方。

**输入结构**：约 18x14 的网格，黑(0)背景。左侧边缘有一个颜色图例区：2~3 对上下排列的 1x2 色块，每对中上方像素为对象色、下方像素为光晕色（如蓝(1)→黄(4)，红(2)→橙(7)）。网格最底行为一条灰(5)条带横跨全宽。主区域（图例右侧、条带上方）有 3~5 个互不重叠的 4-连通单色前景对象（形状不规则，3~8 像素，各对象颜色为图例中的某个对象色）。对象之间间距 >= 2 像素（保证膨胀后光晕不重叠）。生成约束：每种对象色至少出现一次；各对象膨胀后的边界框面积互不相同。

**规则**：
1. 读取左侧颜色图例，建立对象色→光晕色映射。
2. 对每个前景对象，计算其紧密边界框，向四周扩展 1 像素（裁剪到网格范围但不含图例列和条带行）。在扩展区域中，将所有黑(0)像素涂为该对象对应的光晕色。对象内部被对象像素完全包围的黑(0)孔洞不涂光晕色（保持黑(0)）。
3. 对每个"对象+光晕"组合体，计算其紧密边界框面积（行数 x 列数）。
4. 按边界框面积升序排序。面积相同时（生成约束排除此情况，但若发生），按对象在原网格中边界框左上角的行坐标升序排列。
5. 擦除所有对象和光晕的原始位置（置为黑(0)）。
6. 从灰(5)条带正上方开始，依次向上放置排序后的组合体：面积最小的紧贴条带，次小的在其上方（间隔 1 行黑(0)），依此类推。每个组合体在放置时水平居中于网格（若无法完美居中则偏左）。
7. 图例区和条带保持不变。

**关键洞察**：排序键不是对象本身的大小，而是膨胀后的总面积——形状狭长的对象膨胀后面积增长比例大于紧凑的对象，因此膨胀操作实质上改变了排序结果，求解者不能仅看对象像素数来排序。

## 新题 9：分面板局部洪泛后的不对称跨面板叠加

**组合逻辑**：[洪泛填充](每个面板内独立判定封闭区域) → [裁剪](去除分隔列) + [逻辑运算/逐格比较](两面板不对称叠加规则)（洪泛填充为已有原语但边界条件因分隔列而与全局不同；逻辑运算为已有原语但从"双空涂绿"变为"洪泛结果参与不对称优先级判定"）

**来源原语**：洪泛填充/墙壁线段/区域封闭/孤立背景区域填充(a5313dff), 裁剪/分隔列/等宽面板/逐格比较(f2829549), 逻辑运算/双空交集涂色(f2829549), 填充(d6ad076f)

**依赖链**：分隔列将网格分为左右两个等大面板 → 每个面板独立执行洪泛填充：以红(2)像素为墙壁，标记封闭区域并填充蓝(1) → 去除分隔列后逐格比较两个处理后的面板 → 叠加规则不对称：左面板的蓝(1)填充区优先级高于右面板的蓝(1)填充区，但右面板的红(2)墙壁优先级高于左面板的蓝(1)填充区 → 形成"红墙 > 左蓝 > 右蓝 > 背景"的四级优先级

左右面板各自用红墙围出封闭区域并填蓝，去除分隔列后按不对称优先级叠加：右侧红墙最强，左侧蓝填充次之。

**输入结构**：约 11x15 的网格（奇数列），黑(0)背景。正中间一列为灰(5)分隔列，将网格分为宽度相等的左右两个面板。每个面板内有若干红(2)单像素宽的墙壁线段，形成一些闭合轮廓和一些不闭合的开放轮廓。生成约束：每个面板各自至少有 1 个封闭区域（红墙围成的、不与该面板边界 4-连通的黑(0)区域）和 1 个开放区域；左右面板的封闭区域在对应坐标上有部分重叠也有部分不重叠（叠加后能体现优先级差异）。

**规则**：
1. 识别灰(5)分隔列，分离左面板和右面板。每个面板为独立的子网格。
2. 对每个面板独立执行：以红(2)像素为墙壁，以该面板的四条边界为起点做 4-邻域洪泛遍历，标记所有从边界可达的黑(0)像素为"外部"。将所有不可达的黑(0)像素（封闭区域）涂为蓝(1)。红(2)墙壁和外部黑(0)像素不变。
3. 去除分隔列，将两个面板按局部坐标对齐到同一输出画布（大小等于单个面板）。
4. 逐像素叠加，按以下优先级从高到低决定输出颜色：
   - 右面板红(2)墙壁 → 输出红(2)
   - 左面板蓝(1)填充 → 输出蓝(1)
   - 左面板红(2)墙壁 → 输出红(2)
   - 右面板蓝(1)填充 → 输出蓝(1)
   - 两面板均为黑(0) → 输出绿(3)
   - 其他情况（一面板黑(0)一面板蓝(1)或红(2)） → 取非黑(0)面板的颜色
5. 完整优先级可归纳为：右红(2) > 左蓝(1) > 左红(2) > 右蓝(1) > 绿(3)（双空）> 黑(0)（仅当某面板外部黑(0)与另一面板外部黑(0)重合但不满足双空条件时——实际上双空已覆盖此情况）。

**关键洞察**：洪泛填充必须在每个面板内独立执行——一个红墙构型在左面板中围成封闭区域，但如果去掉分隔列后与右面板合并，同一构型可能不再封闭。面板分离不仅是视觉分割，更是逻辑上的边界条件隔离。同时叠加优先级的不对称性（右红 > 左蓝 > 左红 > 右蓝）必须通过对比多个示例中不同重叠情况才能完整归纳。

## 新题 10：棋盘奇偶调制模板印章方向与配色

**组合逻辑**：[印章覆盖](将模板铺贴到标记位置) + [奇偶性选色](标记位置的行列奇偶决定印章变体) + [镜像](奇偶不同则镜像翻转印章)（印章覆盖为已有原语但每次印章的内容不固定；奇偶性选色为已有原语但从"选棋盘格颜色"变为"选印章几何变体"；镜像为已有原语但触发条件从十字标记变为位置奇偶）

**来源原语**：印章覆盖/模板区/掩码标记/标记位置接收模板(b4a43f3b), 棋盘格图案/奇偶性选色(5e6bbc0b), 镜像(9bebae7a), 分隔行(b4a43f3b), 重涂色(5adee1b2)

**依赖链**：分隔行上方的模板确定基础印章 → 分隔行下方的红(2)标记确定印章放置位置 → 每个标记位置的 (行+列) 奇偶性决定印章变体：偶数用原始模板，奇数用水平镜像 → 同时奇数位置的模板中蓝(1)→橙(7)色替换 → 最终形成方向和配色交替的编织图案

模板被印到下方标记位置，偶位置用原版，奇位置用水平镜像且换色，形成交织图案。

**输入结构**：约 14x14 的网格，黑(0)背景。顶部为模板区：一个由单色 2x2 块组成的矩形（约 6x6 像素，即 3x3 粗粒度模板），使用蓝(1)和绿(3)两色，模板图案左右不对称（保证镜像后与原版可区分）。模板区下方紧接一行灰(5)分隔行横跨全宽。分隔行下方为等宽等高的标记区，黑(0)背景上有若干红(2)标记像素。标记像素所在的位置可视为粗粒度网格的格点（每个格点对应一个 3x3 的输出块区域）。生成约束：标记像素间距足够，使得印章后的 3x3 块互不重叠；标记位置中既有 (row+col) 为偶数的也有奇数的（保证两种变体都出现）。

**规则**：
1. 识别灰(5)分隔行。将其上方的模板区每个 2x2 块压缩为一个颜色，得到 3x3 粗粒度模板瓦片 T。
2. 生成 T 的水平镜像变体 T'（沿垂直轴翻转）。对 T' 中所有蓝(1)像素替换为橙(7)，绿(3)像素保持不变，得到变体 T''。
3. 在分隔行下方的标记区中，定位所有红(2)标记像素。将每个标记像素的位置转换为粗粒度坐标 (R, C)：R = (标记行 - 分隔行行号 - 1) / 2（整数除法），C = 标记列 / 2（整数除法）。
4. 对每个标记位置的粗粒度坐标 (R, C)：
   - 若 (R + C) 为偶数，将原始模板 T 的每个像素扩展为 2x2 块，绘制在以该标记像素为左上角的 6x6 输出区域。
   - 若 (R + C) 为奇数，将变体 T'' 的每个像素扩展为 2x2 块，绘制在同样的 6x6 区域。
5. 红(2)标记像素被印章内容覆盖。模板区和分隔行保持不变。未被印章覆盖的标记区像素保持黑(0)。

**关键洞察**：标记位置的棋盘奇偶性同时控制两个独立维度——几何方向（原始 vs 镜像）和颜色方案（蓝/绿 vs 橙/绿），求解者仅看单个印章无法区分这两个效果，必须对比奇偶位置的多个印章才能分离出"镜像"和"换色"两条规则。
