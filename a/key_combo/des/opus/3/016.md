## 新题 1：对角射线分区下的重力着色

**组合逻辑**：[射线延伸](创新：交替方向发射形成编织分区) + [重力下落](创新：下落路径被斜射线偏转) + [重涂色](已有) — 射线分区决定着色归属，重力确定着陆位置，两者共同决定最终颜色

**来源原语**：射线延伸/ray_extend（参考 469497ad, 1190bc91）、重力下落/gravity_drop（参考 963c33f8, 3618c87e）、重涂色/recolor（参考 5b37cb25）、多色长线段/multicolor_run（参考 1190bc91）、射线遮挡分区/ray_partition（参考 1190bc91）、处理顺序决定遮挡/order_determines_block（参考 1190bc91）

**依赖链**：多色水平条的每个像素发射对角射线，射线之间的遮挡关系将条上方空间切分为若干楔形区域，每个区域归属于发射端的条像素颜色；灰色散落像素在重力作用下竖直下落，遇到斜射线时沿射线方向滑行直至到达条上方一格停止；最终每个灰色像素被重新涂为它着陆时所在区域归属的条像素颜色。移除射线分区则无法确定着色归属；移除重力则无法确定着陆位置；移除重涂色则输出无变化。

将散落灰色像素沿重力下落并沿交替方向对角射线滑行至多色条上方，依着陆区域的条像素颜色重涂。

**输入结构**：约 14x14 的黑(0)背景网格。底部偏上（约第 10 行）有一条水平多色线段，宽 4-5 像素，每像素颜色互不相同，使用蓝(1)、红(2)、绿(3)、黄(4)中的 4 种。线段上方散布 5-7 个灰(5)单像素，各自占据不同的列，分布在第 1-8 行之间。生成约束：每个灰像素的列都在多色线段的列范围之内；灰像素之间不同行不同列；多色线段各像素之间无间隔。

**规则**：
1. 从多色线段的每个像素向上方发射一条 45 度斜射线。处理顺序为从左到右。奇数位（第 1、3、...个，从 1 计数）的线段像素向左上方发射，偶数位（第 2、4、...个）向右上方发射。每条射线用其线段像素的颜色绘制，逐像素延伸直至碰到已有的非黑像素或网格边界（不覆盖碰到的像素）。
2. 射线将线段上方的空间划分为若干区域。每个区域归属于其右侧边界射线的发射源像素颜色；若某区域的右侧边界是网格右边缘而非射线，则归属于最右侧线段像素。最左侧区域（左边界为网格左边缘或射线）归属于其右侧边界射线的发射源。
3. 每个灰(5)像素竖直下落。若下落过程中遇到一条斜射线像素，该灰像素不停在射线上方，而是沿射线方向继续滑行（沿射线的延伸方向逐格移动），直到滑行到达线段正上方一行时停止。若竖直下落未遇到任何射线，则直接落到线段正上方一行停止。若着陆位置已被占据，则停在该已占据位置的正上方一格。
4. 每个着陆后的灰像素被重涂为其着陆位置所在区域的归属颜色。
5. 原始多色线段和射线像素保留不变。

**关键洞察**：奇偶交替的射线发射方向创造了编织状分区——仅从单个示例无法确定交替规则是"奇左偶右"还是"奇右偶左"，必须对比多个示例归纳。

## 新题 2：循环移位属性排序为同心方框

**组合逻辑**：[循环移位](已有) → [排序](已有) → [重绘](创新：将排序结果渲染为同心框而非条形图) — 循环移位改变颜色-高度配对，排序依赖移位后的高度，同心框顺序依赖排序结果

**来源原语**：循环移位/cyclic_shift（参考 2601afb7）、排序/sort（参考 c920a713）、重绘/redraw（参考 c920a713）、竖直条/vertical_bar（参考 2601afb7）、同心方框/concentric_frame（参考 c920a713）、有序槽位/ordered_slots（参考 2601afb7）、色与高反向轮转/color_height_rotate（参考 2601afb7）

**依赖链**：输入的竖直条有颜色和高度两个独立属性。循环移位将颜色右移一位、高度左移一位，产生全新的颜色-高度配对。按移位后的高度从大到小排序，得到颜色序列。该序列从外到内绘制为同心正方形框。三步环环相扣：移位改变配对关系，配对关系改变排序结果，排序结果改变框的嵌套顺序。

将底部对齐的彩色竖直条经颜色右移、高度左移后，按新高度降序排列，以排列顺序从外到内绘制为同心正方形框。

**输入结构**：约 12x16 的黑(0)背景网格。底部对齐的 4-6 根单色竖直条（每根宽 1 像素），分布在不同列，各条颜色互不相同，从蓝(1)、红(2)、绿(3)、黄(4)、灰(5)、品红(6)中选取。每根条的高度在 2-10 像素之间且互不相同。条从左到右排列形成有序槽位。生成约束：条的数量 N 满足 4 <= N <= 6；各条高度互不相同以保证排序唯一。

**规则**：
1. 读取从左到右的有序槽位，记录每个槽位的颜色和高度。
2. 将颜色序列循环右移一位（最右颜色移到最左）。
3. 将高度序列循环左移一位（最左高度移到最右）。
4. 得到每个槽位新的（颜色, 高度）配对。
5. 按移位后的高度从大到小排序。若有相同高度（生成约束保证不会），则按槽位原始位置从左到右排。
6. 输出为正方形网格，边长 = 2N - 1（N 为条的数量）。以排序后的颜色序列，从外到内绘制同心正方形框：第 1 个颜色为最外圈（边长 2N-1 的正方形框，宽 1 像素），第 2 个为次外圈（边长 2N-3），依此类推。最内层若为单个像素则填充最后一个颜色。

**关键洞察**：颜色和高度的移位方向相反（颜色右移、高度左移）——仅从一个示例无法区分"颜色右移+高度左移"和"颜色左移+高度右移"，必须通过多个示例确认方向。

## 新题 3：对角偏移复制后的涌现十字连接

**组合逻辑**：[拼接/对角偏移复制](已有) + [连线](创新：作用于复制涌现的新十字体而非原始输入) — 偏移复制创造出原始中不存在的空间关系，连线规则在涌现的新对齐上运行

**来源原语**：拼接/concatenate + 对角线偏移复制/diagonal_offset_copy（参考 d13f3404）、连线/connect（参考 55059096）、十字图案/plus_object（参考 55059096）、前景图案/foreground_motif（参考 d13f3404）、中心对角对齐/center_diagonal_alignment（参考 55059096）、画布加倍/canvas_doubling（参考 d13f3404）、无障碍通路/unobstructed_path（参考 55059096）

**依赖链**：输入含若干十字图案。对角偏移复制在加倍画布上为每个前景像素沿主对角线方向生成多个副本，部分副本恰好重新组合成新的完整十字图案。这些涌现的十字图案与原始十字图案之间可能形成新的对角对齐关系。连线规则检测所有有效十字体（恰好 5 像素的 4-连通十字）之间的对角对齐，并在无障碍路径上绘制连接线。没有偏移复制就没有涌现对齐；没有连线规则则复制无意义。

将绿色十字图案沿主对角线逐格偏移复制到加倍画布上，在涌现的新完整十字体之间沿无障碍对角路径绘制红色连接线。

**输入结构**：约 8x8 的黑(0)背景网格。2-3 个绿(3)十字图案（每个由中心像素及上下左右 4 个邻居共 5 像素组成，3x3 边界框）。十字图案之间互不相邻（边界框不重叠且间隔至少 1 像素）。生成约束：各十字图案的位置满足——在 16x16 的输出画布上，对角偏移产生的十字副本中至少存在 2 对有效十字体中心对角对齐且路径无障碍；同时存在至少 1 对中心对角对齐但路径被其他偏移痕迹阻挡的情况（用于区分"所有对齐都连"和"仅无障碍对齐连"）。

**规则**：
1. 创建 (2H)x(2W) 的黑(0)输出画布（H、W 为输入高度和宽度）。
2. 对输入中每个绿(3)像素位于 (r, c)，在输出画布的 (r+k, c+k) 处绘制绿(3)，k = 0, 1, 2, ...，直至超出画布边界。后绘制的像素覆盖先绘制的（实际颜色相同，无冲突）。
3. 在输出画布中识别所有有效十字体：恰好由 5 个绿(3)像素组成的 4-连通分量，且形态为中心像素加四个基本方向邻居。因偏移痕迹重叠而形成的像素数超过 5 或形态非十字的连通分量不算有效十字体。
4. 对每对有效十字体，检查两中心是否在同一条 45 度对角线上（行差绝对值 = 列差绝对值）。若是，检查两中心之间的严格内部对角像素是否全为黑(0)。若全为黑(0)，将这些内部像素涂为红(2)。
5. 处理顺序：按十字体中心的 (行, 列) 从小到大排列所有有效对，依次绘制。先绘制的红色像素不阻碍后续对的无障碍判定（判定时只看绿色和黑色）。

**关键洞察**：涌现的有效十字体必须恰好 5 像素且形态为标准十字——偏移痕迹合并产生的非标准连通体被排除。这一筛选条件仅凭单个示例难以确定，需要多个示例中出现"合并体不被连接"的反例才能归纳。

## 新题 4：瓦片周期驱动双重操作——修复与压缩

**组合逻辑**：[补全](已有) + [压缩](创新：压缩的分块尺寸由推断出的瓦片周期决定) — 补全操作推断的瓦片周期同时作为压缩的分块参数，两个操作共享同一个推断结果

**来源原语**：补全/completion（参考 ca8f78db）、压缩/compress（参考 5783df64）、重复瓦片/repeating_tile（参考 ca8f78db）、遮挡区域/occluded_region（参考 ca8f78db）、分区网格/partitioned_grid（参考 5783df64）、稀疏前景像素/sparse_foreground_pixel（参考 5783df64）、可见像素约束推断/infer_from_visible（参考 ca8f78db）、分区采样/block_sampling（参考 5783df64）

**依赖链**：输入网格包含一个周期性瓦片图案，部分区域被黑色遮挡。首先从可见像素推断出最小重复瓦片的行周期 Pr 和列周期 Pc。用推断出的瓦片修复所有被遮挡的像素。然后以 Pr x Pc 为分块尺寸对修复后的网格做压缩——每个分块取其中心像素的颜色作为输出像素。推断瓦片周期是两个操作的共享前提：没有推断就无法修复也无法确定分块尺寸；修复失败则压缩采样到错误颜色。

从部分遮挡的周期性网格中推断最小瓦片，修复遮挡区域，再按瓦片周期大小压缩为缩略图。

**输入结构**：约 12x12 至 18x18 的网格（行列数分别是瓦片行周期 Pr 和列周期 Pc 的整数倍）。网格由一个 Pr x Pc 的最小瓦片（3x3 或 4x4）周期平铺而成，瓦片使用 2-3 种非黑颜色（如红(2)、蓝(1)、黄(4)）。1-3 个互不重叠的矩形黑(0)区域覆盖了部分瓦片像素。生成约束：遮挡区域不超过总面积的 40%；每个瓦片周期的每一行中至少有一个像素在某处可见（即可见像素覆盖了瓦片的所有残差类）；各遮挡矩形的边界不与瓦片周期边界对齐（避免整行/整列瓦片信息完全丢失）。

**规则**：
1. 将黑(0)像素视为未知。从所有非黑像素推断最小矩形周期 (Pr, Pc)，使得任意非黑像素 (r, c) 的颜色等于 (r mod Pr, c mod Pc) 处瓦片原型的颜色。保证推断结果唯一。
2. 用推断出的瓦片原型填充所有黑像素：像素 (r, c) 的颜色 = 瓦片原型 (r mod Pr, c mod Pc) 的颜色。
3. 将修复后的网格按 Pr x Pc 的分块大小划分为矩形块（保证整除）。每个块取中心像素 (floor(Pr/2), floor(Pc/2)) 处的颜色作为输出对应位置的像素。
4. 输出网格尺寸 = (输入行数 / Pr) x (输入列数 / Pc)。

**关键洞察**：瓦片周期既是修复的依据又是压缩的参数——这个双重角色必须通过观察多个不同周期大小的示例（如一个示例周期 3x3，另一个 4x4）才能归纳出"压缩分块尺寸 = 瓦片周期"这一非显然关系。

## 新题 5：视线滑动标记触发分色桥接

**组合逻辑**：[滑动](已有) + [连线/draw_line](创新：桥接条件由滑动后的标记位置决定，桥接形态为分色空心矩形) — 滑动决定标记最终位置，位置决定哪些方块对构成桥接对，桥接颜色来自标记颜色

**来源原语**：滑动/slide（参考 e1d2900e）、连线/draw_line（参考 b7249182）、标记像素/marker_pixel（参考 e1d2900e）、实心方块/solid_block（参考 e1d2900e）、空心矩形/hollow_rectangle（参考 b7249182）、视线对齐/sightline_align（参考 e1d2900e）、最近邻/nearest_neighbor（参考 e1d2900e）、中点对称/midpoint_symmetry（参考 b7249182）、沿视线移至近块旁/slide_to_nearest_block（参考 e1d2900e）、分色矩形桥接/split_rect_bridges_pixels（参考 b7249182）

**依赖链**：多色标记像素沿视线滑动到最近方块旁。滑动后，检查每对方块：若两块在同一水平或竖直带上且面对面的两侧各有一个标记像素，则用这两个标记的颜色构建分色空心矩形桥接。桥的左半（或上半）用靠近该方块的标记颜色，右半（或下半）用靠近另一方块的标记颜色。滑动结果决定标记附着在哪个方块的哪一侧，从而决定桥接是否成立以及桥的分色方案。

将散落标记像素沿视线滑动到最近的实心方块旁，在面对面拥有标记的方块对之间绘制分色空心矩形桥。

**输入结构**：约 18x18 的黑(0)背景网格。3-4 个红(2)实心方块（每个 2x2 像素），位置分散。6-8 个单像素标记，颜色从蓝(1)、绿(3)、黄(4)、品红(6)中选取，每个标记与恰好一个方块有唯一的水平或竖直无障碍视线（中间全为黑(0)）。生成约束：每个方块至少被 1 个标记"看到"，至少 2 个方块各自在面对面的一侧有标记（滑动后形成桥接对）；至少存在一个方块对尽管各自有标记但不在面对面一侧（作为非桥接的反例）。

**规则**：
1. 对每个标记像素，找到其唯一的水平或竖直无障碍视线方向上最近的 2x2 红色方块。将标记移动到该方块外围一圈（8-邻域环）中与视线方向对应的那个格子。标记保留原色。若目标格已被占据，标记不移动（保持原位）。
2. 滑动完成后，检查所有方块对 (A, B)：
   - 若 A 和 B 的中心在同一行（行差 <= 1）且 A 在 B 左侧：检查 A 的右侧环格和 B 的左侧环格是否各有一个标记。
   - 若 A 和 B 的中心在同一列（列差 <= 1）且 A 在 B 上方：检查 A 的下侧环格和 B 的上侧环格是否各有一个标记。
   - 满足条件则该对为桥接对。
3. 对每个桥接对，在两方块之间的空间构建一个一像素厚的空心矩形。矩形的高度（水平桥接时）等于方块高度（2 像素），宽度 = 两方块外围之间的距离。矩形沿中线分为两半：靠近 A 的一半涂 A 侧标记的颜色，靠近 B 的一半涂 B 侧标记的颜色。若两侧标记颜色相同，则整个桥统一该色。若中线落在像素边界上，左半/上半多分一列/行。
4. 原始方块像素保留红(2)不变。未参与桥接的标记保留在滑动后的位置。

**关键洞察**：桥接的触发条件是"面对面的方块侧各有一个标记"——"面对面"由方块对的相对位置决定，而标记附着在哪一侧由滑动方向决定。这一多步条件需要对比多个示例（特别是有标记但不在面对面侧的反例）才能归纳。

## 新题 6：镜像形状中控制像素选择性填孔

**组合逻辑**：[镜像](已有) + [区域填充](创新：只对镜像半中由控制像素标记的孔执行填充) — 镜像创建反射结构和默认映射，控制像素选择性覆盖默认映射

**来源原语**：镜像/mirror（参考 6f473927）、区域填充/flood_fill（参考 1190bc91）、前景形状/foreground_shape（参考 6f473927）、控制像素/control_pixel（参考 963c33f8）、接触边界定轴/touching_border_determines_axis（参考 6f473927）、负片色映射/negative_color_remap（参考 6f473927）、控制色定行为/control_color_determines_behavior（参考 963c33f8）、穿透或停靠/pass_through_or_stop（参考 963c33f8）

**依赖链**：红色前景形状接触一侧竖直边界，确定镜像轴。镜像后对反射半施加负片映射（黑→青、红→黑）。前景形状中的封闭孔洞在负片映射后变为青色区域。每个孔洞边界上有一个控制像素（蓝或栗），蓝表示"将镜像孔洞改填橙色"，栗表示"保持青色默认"。三层操作交织：镜像创建孔洞副本，负片映射提供默认色，控制像素选择性覆盖。

将接触竖直边界的红色形状镜像翻转并施加负片色映射，再根据原始形状中每个孔洞的控制像素颜色选择性地将镜像孔洞填充为橙色或保留为青色。

**输入结构**：约 10x8 的黑(0)背景网格。红(2)像素构成一个 4-连通连接的前景形状，接触且仅接触一侧竖直边界（左边界或右边界）。形状内部有 2-3 个封闭孔洞（完全被红像素包围的黑色连通区域，每个孔洞 2-5 像素大小）。每个孔洞的边界红像素中恰好有一个被替换为控制像素：蓝(1)或栗(9)。控制像素视觉上是形状边界的一部分，不破坏孔洞的封闭性。生成约束：至少一个孔洞的控制像素为蓝(1)，至少一个为栗(9)（以便示例中两种行为都可见）；形状不接触上下边界；形状的水平跨度不超过网格宽度的一半（保证镜像后不溢出）。

**规则**：
1. 确定前景形状接触的竖直边界（左或右），该边界为镜像轴。
2. 输出宽度 = 输入宽度 x 2。若形状接触左边界，输出 = [镜像半 | 原始半]（镜像半在左）；若接触右边界，输出 = [原始半 | 镜像半]（镜像半在右）。高度不变。
3. 镜像半通过水平翻转原始半得到，然后施加负片色映射：黑(0) → 青(8)，红(2) → 黑(0)，蓝(1) → 黑(0)，栗(9) → 黑(0)。即所有非黑色前景像素在镜像半都变为黑(0)，所有黑色背景/孔洞在镜像半变为青(8)。
4. 对每个孔洞，找到其在原始半中的控制像素颜色：
   - 蓝(1)：将该孔洞在镜像半中对应的青(8)连通区域整体改为橙(7)。
   - 栗(9)：该孔洞在镜像半中保持青(8)不变。
5. 原始半的所有像素保持不变（包括控制像素）。

**关键洞察**：蓝(1)表示"覆盖填充"而栗(9)表示"保持默认"——这一编码对应关系不能从单个孔洞推断（因为可能两色都是填充只是颜色不同），必须在同一示例中看到两种控制像素导致不同行为，或在多个示例中对比确认。

## 新题 7：条纹填充与标记路径上的颜色互换

**组合逻辑**：[填充/像素数转条纹](已有) + [颜色互换](创新：互换只发生在条纹填充与标记路径的交叉处) — 两个独立操作的结果在空间交叉点产生交互，交叉处的颜色由两条规则共同决定

**来源原语**：填充/fill + 像素数转为条纹/pixels_to_stripes（参考 d93c6891）、颜色互换/color_swap + 配对间像素互换/toggle_between_pairs（参考 d2acf2cb）、条形段/bar_segment（参考 d93c6891）、矩形容器/rect_container（参考 d93c6891）、标记像素/marker_pixel（参考 d2acf2cb）、相邻接触/adjacent_touch（参考 d93c6891）、对边配对/opposite_edge_pair（参考 d2acf2cb）

**依赖链**：灰色条的像素数量被转移为橙色矩形内的条纹行/列（填充操作），同时黄色标记对选定的行/列上所有像素执行颜色互换。当条纹填充区域与标记路径交叉时，两条规则冲突：填充将空白变为橙色，互换又将橙色翻转为黑色。最终颜色取决于两个操作的叠加效果。移除填充则互换无内容可翻转；移除互换则无法解释交叉处的异常颜色。

将灰色条的像素数作为条纹填入相邻橙色矩形，然后沿黄色标记对选定的行列执行颜色互换，条纹与标记路径的交叉处呈现叠加后的翻转结果。

**输入结构**：约 16x16 的黑(0)背景网格。2-3 个橙(7)实心矩形（每个约 4x4 至 6x6），互不重叠，间隔至少 2 像素。每个矩形的一侧（上、下、左或右）4-连通接触一根灰(5)条（宽 1 像素、长 2-5 像素的直线段）。灰色条的方向与接触侧一致（水平条接触上/下侧，竖直条接触左/右侧）。网格的两对对边上各有 1-2 对黄(4)标记像素：左右边对上的标记选定行，上下边对上的标记选定列。生成约束：至少一条标记路径穿过至少一个橙色矩形的条纹填充区域（产生交叉）；至少一条标记路径不穿过任何矩形（作为无交叉对照）；至少一个矩形未被任何标记路径穿过（作为纯条纹对照）。

**规则**：
1. 将所有灰(5)像素重涂为黑(0)（擦除灰条）。
2. 对每个橙(7)矩形，统计其 4-连通邻接的原灰色像素数量 G。
   - 若灰条水平接触矩形的上侧：从矩形最上行开始向下，将 G 个完整行涂为橙(7)，其余行涂为黄(4)。
   - 若灰条水平接触矩形的下侧：从矩形最下行开始向上，将 G 个完整行涂为橙(7)，其余行涂为黄(4)。
   - 若灰条竖直接触矩形的左侧：从矩形最左列开始向右，将 G 个完整列涂为橙(7)，其余列涂为黄(4)。
   - 若灰条竖直接触矩形的右侧：从矩形最右列开始向左，将 G 个完整列涂为橙(7)，其余列涂为黄(4)。
   - 若 G 大于等于矩形在该维度的尺寸，则全部涂橙(7)。无邻接灰条的矩形保持全橙(7)不变。
3. 对每对黄(4)边缘标记确定的行或列路径，对路径上处于矩形内部的每个像素执行颜色互换：橙(7) ↔ 黑(0)，黄(4) ↔ 品红(6)。路径上不在任何矩形内部的像素不变。
4. 处理顺序：先完成所有条纹填充（步骤 2），再统一执行所有颜色互换（步骤 3）。边缘上的黄标记像素本身保持不变。

**关键洞察**：条纹区域中被标记路径穿过的行/列呈现的颜色既不是纯条纹结果也不是纯互换结果，而是两者的叠加——橙条纹被翻转为黑，黄条纹被翻转为品红。这一叠加效应必须通过对比"有交叉"和"无交叉"的示例才能推断互换规则。

## 新题 8：边界色数缩放后十字体对角连接

**组合逻辑**：[像素放大](已有) + [连线](创新：连线对象是缩放后涌现的对齐关系) — 缩放改变空间间距从而改变对角对齐关系，连线在缩放后的新空间中运行

**来源原语**：像素放大/pixel_scale + 色数决定缩放/color_count_sets_scale（参考 469497ad）、连线/connect + 中心对角对齐/center_diagonal_alignment + 无障碍通路/unobstructed_path（参考 55059096）、边界色带/border_color_strip（参考 469497ad）、十字图案/plus_object（参考 55059096）、角点射对角至挡/corner_diag_to_block（参考 469497ad）

**依赖链**：底行和右列的非黑颜色数决定缩放因子 S。全图按 S 倍像素放大后，原本不在同一 45 度对角线上的十字图案可能因缩放而形成新的对齐关系（原始间距 d 缩放为 Sd，改变了行差/列差的比值关系）。在缩放后的网格中，检测所有放大后的十字体之间的对角对齐并绘制红色连接线。缩放因子改变则对齐对改变；不缩放则无法产生特定对齐。

统计边界色带的颜色数量作为缩放因子，将含十字图案的网格像素放大，在放大后对角对齐的十字体之间绘制红色连接线。

**输入结构**：约 8x8 的网格。黑(0)背景。底行和最右列各有一段非黑色带（2-4 像素长），使用 2-3 种颜色（如蓝(1)、绿(3)、黄(4)），每种颜色至少出现一次。网格其余区域有 2-4 个绿(3)十字图案（5 像素，3x3 边界框）。十字图案之间、十字图案与边界色带之间不相邻。生成约束：设缩放因子 S = 底行和右列的非黑颜色种类数。缩放后的网格中，至少一对十字体中心的行差绝对值等于列差绝对值（对角对齐），且两者之间的路径无障碍；同时在未缩放的原始网格中，同一对十字体不满足对角对齐条件。

**规则**：
1. 统计底行和最右列中出现的所有不同非黑颜色的种类数，得到缩放因子 S。
2. 将输入网格的每个像素扩展为 S x S 的同色方块，输出网格尺寸 = (输入行数 x S) x (输入列数 x S)。
3. 在缩放后的网格中，识别所有放大后的十字体。每个原始 5 像素十字放大后变为一个由 5 个 S x S 方块组成的大十字形区域。取每个大十字的几何中心像素作为其中心坐标。
4. 对每对大十字体，检查两中心是否满足行差绝对值 = 列差绝对值（对角对齐）。若满足，检查两中心之间的 45 度对角线路径上所有严格内部像素是否全为黑(0)。若是，将这些内部像素涂为红(2)。
5. 若多对连接线共享像素，后绘制的覆盖先绘制的（但颜色相同均为红色，无实际冲突）。按中心对 (行较小者, 列较小者) 的字典序处理。
6. 缩放后的边界色带保留原样，不参与十字识别也不阻碍连接线（连接线路径如需穿过色带区域，色带像素视为障碍，该对不连接）。

**关键洞察**：缩放因子改变了十字体之间的绝对间距，使得原本不满足"行差=列差"的十字对在缩放后满足。需要对比不同缩放因子的示例才能确认"连接条件基于缩放后的坐标而非原始坐标"。

## 新题 9：遮挡顺序决定对角连接优先级

**组合逻辑**：[排序/遮挡顺序](创新：遮挡顺序不用于绘制同心框，而用于确定连接优先级) + [连线](创新：连线之间可能冲突，由优先级解决) — 框的交叉可见性提供优先级序，对角连线在冲突时依据该优先级裁决

**来源原语**：排序/sort + 遮挡顺序/occlusion_order + 交叉处可见性/crossing_visibility + 遍历所有颜色/traverse_all_colors（参考 c920a713）、连线/connect + 中心对角对齐/center_diagonal_alignment + 无障碍通路/unobstructed_path（参考 55059096）、矩形边框/rect_frame（参考 c920a713）、十字图案/plus_object（参考 55059096）

**依赖链**：多个矩形框重叠，交叉处的可见颜色建立了框之间的优先级有向图——可见色在上，被遮挡色在下。每个框的几何中心放置一个与框同色的十字图案。对角对齐的十字体之间绘制连接线，连接线颜色为两端十字中优先级较高者的颜色。当两条连接线在同一像素交叉时，优先级更高的连接线的颜色覆盖较低的。移除遮挡分析则无法确定冲突裁决；移除对角连接则遮挡分析无用武之地。

从重叠矩形框的交叉可见性推断优先级序，在各框中心的十字图案之间绘制对角连接线，交叉冲突由优先级裁决。

**输入结构**：约 20x20 的黑(0)背景网格。4-5 个一像素厚的矩形框，每个框一种独立颜色，从蓝(1)、红(2)、绿(3)、黄(4)、品红(6)中选取。框的尺寸各异（最小 5x5，最大 12x12），位置部分重叠——每对相邻优先级的框至少有一段边相交。在每个交叉点处，优先级高的框的颜色可见（覆盖低优先级的）。每个框的几何中心（边界框中心取整）放置一个该框颜色的 5 像素十字图案（若中心被另一框边覆盖，十字仍绘制在下层）。生成约束：至少 2 对十字图案的中心对角对齐（行差绝对值 = 列差绝对值）且路径无障碍（仅含黑色像素）；至少 1 对对角连接线与另一对在某像素处交叉（即两条线共享至少一个内部像素）。优先级形成全序（每对框都有直接或间接的优先级比较）。

**规则**：
1. 从框的交叉点推断优先级全序：在两框边界的交叉像素处，可见颜色属于优先级更高的框。构建有向图，找到唯一的拓扑排序（全序保证唯一）。记优先级从高到低为 P1 > P2 > P3 > ...
2. 对每对十字图案 (X, Y)，检查其中心是否对角对齐（行差绝对值 = 列差绝对值）。若对齐，检查中心之间 45 度对角线路径上所有严格内部像素是否全为黑(0)（框边界和十字像素都视为障碍）。若无障碍，标记为可连接对。
3. 对每个可连接对 (X, Y)，连接线颜色 = X 和 Y 中优先级较高者的颜色。在两中心之间的所有严格内部对角像素位置记录该颜色。
4. 若多条连接线覆盖同一像素，该像素最终颜色为所有覆盖该像素的连接线中优先级最高的那条的颜色。
5. 所有原始框像素和十字像素保持不变（连接线仅绘制在黑色背景像素上）。

**关键洞察**：连接线的颜色不是两端的混合或平均，而是取优先级较高者——这一规则从单条连接线无法判断（因为总是某种颜色），必须在多个示例中观察到"当低优先级十字与高优先级十字连接时，线色总是高优先级的颜色"才能归纳。交叉冲突的裁决进一步强化了优先级的作用。
