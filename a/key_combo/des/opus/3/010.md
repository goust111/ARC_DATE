## 新题 1：交叉层序决定空心矩形的填充色

**组合逻辑**：[层序推断/layer_infer](创新：从直线交叉改为矩形轮廓交叉) + [填充/fill](创新：填充颜色不固定，由层序关系动态决定) ← [遮挡层次/occlusion_order] 驱动 [仅填矩形内部/fill_interior_only] 的颜色选择

**来源原语**：层序推断(22425bda), 填充(e73095fd), 遮挡层次(22425bda), 交叉可见色为上层(1a2e2828), 空心矩形(e73095fd), 仅填矩形内部(e73095fd)

**依赖链**：矩形轮廓在交叉点的可见颜色 → 推断出所有矩形的从底到顶层序 → 每个矩形的内部用"它正下方一层的矩形颜色"来填充。层序推断和填充色选择互为条件：不知道层序则无法确定填色，而填色结果是整道题的输出目标。

从多个部分重叠的空心彩色矩形的轮廓交叉中推断层序，然后用每个矩形"下一层"矩形的轮廓色填充其内部。

**输入结构**：约 18x18 的黑(0)背景网格。其上有 4~5 个空心矩形，每个矩形的轮廓为 1 像素厚的单色线条，轮廓颜色互不相同（如蓝(1)、红(2)、绿(3)、黄(4)、灰(5)），矩形内部为黑(0)。各矩形大小不等（边界框约 5x5 至 9x9），位置使得部分矩形的轮廓线互相交叉——即一个矩形的边穿过另一个矩形的边，形成交叉点。在每个交叉点处，只有一种颜色可见，代表该位置"上层"矩形的颜色。所有矩形两两之间至少有一处轮廓交叉，以确保层序完全确定。生成约束：矩形的层序构成一条唯一的全序链，无歧义。

**规则**：
1. 识别每个空心矩形及其轮廓颜色。矩形定义为：一种非背景色形成的 4-连通闭合环，环内全为黑(0)。
2. 在轮廓交叉点（两个矩形的轮廓线在同一像素位置重叠之处），可见颜色属于层序更高的矩形。收集所有交叉约束，建立从底到顶的唯一全序。
3. 对于全序中第 k 层（k >= 2，从底数起）的矩形，将其黑(0)内部像素全部填充为第 k-1 层矩形的轮廓颜色。最底层（k=1）的矩形内部保持黑(0)。
4. 当两个矩形的内部区域在空间上重叠时（一个矩形的内部落在另一个矩形的内部范围内），该像素的填充色取层序更高的矩形所应填的颜色（即高层优先覆盖）。
5. 所有矩形轮廓像素保持原色不变。

**关键洞察**：每个矩形的内部填色不是它自身的颜色，而是层序中紧邻其下方的矩形的颜色——必须从轮廓交叉中完整推断出层序后才能确定各内部的颜色，且最底层矩形保持黑色这一规则需要对比多个示例才能归纳。

## 新题 2：噪点邻接雕塑精灵体以匹配孔洞

**组合逻辑**：[擦除/erase + 重涂色/recolor](创新：噪点合并/删除不是清理目的，而是改变精灵体形状) → [嵌入/embed](创新：嵌入目标不是原始精灵体，而是经噪点处理后的变形精灵体) ← [形状匹配/shape_matching] 仅在噪点处理后成立

**来源原语**：擦除(7e0986d6), 重涂色(7e0986d6), 嵌入(228f6490), 邻接(7e0986d6), 邻接够归并否则删(7e0986d6), 形状匹配(228f6490), 精灵体(228f6490), 孔洞(228f6490), 噪点(7e0986d6)

**依赖链**：噪点像素的邻接计数决定它们是合并入精灵体还是被删除 → 合并/删除改变了精灵体的实际形状 → 处理后的精灵体恰好与某个孔洞形状一致 → 嵌入。删除噪点处理步骤则精灵体形状不匹配任何孔洞；删除嵌入步骤则失去输出目标。

将散落的噪点像素按邻接规则合并或删除，使精灵体变形为恰好匹配灰色对象内孔洞的形状，然后将变形后的精灵体嵌入对应的孔洞。

**输入结构**：约 20x20 的黑(0)背景网格。其上有 3 个灰(5)矩形对象（约 6x6 至 8x8），每个内部有一个不规则的黑(0)孔洞（4-连通，3~7 像素，形状各异——非标准几何图形，由连通像素块构成）。网格其他区域分布着 3 个单色精灵体（颜色分别为蓝(1)、红(2)、绿(3)），每个精灵体是一个 4-连通的小图形（3~6 像素）。在精灵体附近（与精灵体相距 1~2 像素范围内）散布着橙(7)色噪点像素（每个精灵体附近有 2~4 个噪点）。生成约束：原始精灵体的形状不与任何孔洞匹配；经过噪点合并/删除处理后，每个精灵体恰好与一个孔洞形状匹配（一一对应）。

**规则**：
1. 识别灰(5)矩形对象及其内部黑(0)孔洞，提取每个孔洞的二值形状掩码（相对于孔洞边界框左上角的偏移）。
2. 识别所有橙(7)噪点像素。对每个噪点像素，统计其 4-邻域中属于任何精灵体（蓝(1)/红(2)/绿(3)）的邻居数量。
3. 若某噪点像素有 >= 2 个精灵体邻居，则将其合并入相邻精灵体（重涂为该精灵体的颜色）。若有来自不同精灵体的邻居，取邻居数最多的精灵体（生成约束保证无平局）。
4. 若某噪点像素的精灵体邻居 < 2 个，则删除该噪点（恢复为黑(0)）。
5. 处理完所有噪点后，每个修改后的精灵体的二值掩码与恰好一个孔洞的二值掩码相同（忽略平移）。将每个精灵体以其自身颜色粘贴到匹配的孔洞位置，替换孔洞中的黑(0)像素。
6. 原始精灵体位置上的像素恢复为黑(0)背景。灰(5)对象和未匹配部分保持不变。

**关键洞察**：原始精灵体"故意"不匹配任何孔洞——噪点像素不是需要清理的杂质，而是精确的补丁材料：它们的邻接模式决定了哪些像素被"焊接"到精灵体上，从而将精灵体雕塑成目标孔洞的精确形状。

## 新题 3：散布标记列位置编码面板叠加优先级

**组合逻辑**：[排序/sort](创新：排序对象从散布标记变为面板的外部代理) → [透明叠加/transparent_overlay](创新：叠加优先级不由面板位置固定决定，而由外部编码动态指定) ← [列序排列/column_order] 将标记序转化为 [图层优先级/layer_priority]

**来源原语**：排序(cdecee7f), 透明叠加(281123b4), 列序排列(cdecee7f), 图层优先级(281123b4), 面板(281123b4), 分隔列(281123b4), 散布标记(cdecee7f)

**依赖链**：散布标记的列坐标 → 排序得到颜色序列 → 该序列定义面板的前到后叠加优先级 → 叠加产出最终图像。删除排序步骤则不知道叠加顺序；删除叠加步骤则排序结果无处输出。

从独立区域中散布标记的列坐标排序来确定多个面板的叠加优先级，然后按此优先级将面板透明叠加为一个图像。

**输入结构**：约 7x25 的网格，分为两个区域。左区域：高度 5 像素，宽度 19 像素，由 3 列品红(6)分隔列将其分成 4 个 5x4 的面板。每个面板包含黑(0)背景和恰好一种前景色（4 个面板的前景色互不相同，取自蓝(1)、红(2)、绿(3)、黄(4)），前景色像素构成一个 4-连通的小图案（3~6 像素）。右区域：与左区域之间间隔 2 列黑(0)，高度相同，宽度约 5 像素。其中恰好有 4 个单像素标记，每个标记的颜色对应一个面板的前景色，4 个标记散布在不同的行和不同的列位置上。生成约束：4 个标记的列坐标互不相同。

**规则**：
1. 从左区域提取 4 个面板（每个 5x4），按左到右记为 P1、P2、P3、P4。
2. 从右区域提取 4 个单像素标记，记录每个标记的颜色和列坐标。
3. 将 4 个标记按列坐标从左到右排序，得到一个颜色序列 [C_left, ..., C_right]。
4. 叠加优先级：序列中最左的标记颜色对应的面板为最底层（最先绘制），最右的标记颜色对应的面板为最顶层（最后绘制）。
5. 创建一个 5x4 的黑(0)输出网格。按从底到顶的顺序依次叠加面板：对于当前面板中每个非黑(0)像素，覆盖输出网格对应位置的颜色；黑(0)像素视为透明，不覆盖。
6. 输出最终的 5x4 叠加结果。

**关键洞察**：面板的叠加顺序不由它们在输入中的物理位置决定（不是固定的循环序），而是由右侧区域中标记像素的水平位置编码。移动标记的列坐标会改变叠加顺序，从而产生不同的输出——这一编码机制需要对比多个示例才能发现。

## 新题 4：格子奇偶与边缘内部的双重分类决定四种单元格处理

**组合逻辑**：[印章覆盖/stamp_overlay](已有) + [重涂色/recolor](创新：重涂色规则不是单一分类，而是两个独立分类的笛卡尔积) ← [同奇偶格接收副本/same_parity_receive_copy] x [边缘与内部区分/perimeter_interior_distinction] 构成 2x2 决策矩阵

**来源原语**：印章覆盖(92e50de0), 重涂色(8a371977), 同奇偶格接收副本(92e50de0), 边缘与内部区分(8a371977), 格子结构(8a371977), 单元格阵列(92e50de0), 种子图案(92e50de0)

**依赖链**：格子将网格分成单元格阵列 → 种子图案的位置确定"同奇偶"类别 → 单元格的阵列行列坐标确定"边缘/内部"类别 → 两个类别的组合（2x2 矩阵）决定四种不同处理方式。删除任一分类维度，四种处理退化为两种，无法解释所有示例。

在格子单元格阵列中，用奇偶性和边缘/内部位置两个独立维度的交叉来决定每个单元格的处理方式：同奇偶内部格印章种子图案，异奇偶内部格填红色，同奇偶边缘格填绿色，异奇偶边缘格保持原色。

**输入结构**：约 23x23 的网格。橙(7)色格子线（1 像素宽）将网格分成至少 5 行 x 5 列的单元格阵列，每个单元格约 3x3 至 4x4 像素。所有单元格初始填充为灰(5)。其中一个非边缘单元格内包含一个多色种子图案（使用蓝(1)和黄(4)两种颜色，2~4 像素，4-连通，位于该单元格内部，其余像素为灰(5)），该单元格的阵列行索引和列索引的奇偶性确定"种子奇偶类"。生成约束：单元格阵列至少 5x5 以确保有足够的内部格和边缘格；种子图案足够小以完全容纳在最小单元格内。

**规则**：
1. 识别橙(7)格子线和它们围成的单元格阵列。按从上到下、从左到右对单元格编行列索引（从 0 开始）。
2. 定位包含种子图案的单元格，记录其阵列坐标 (r_s, c_s)。种子奇偶类定义为 (r_s mod 2, c_s mod 2)。
3. 对每个单元格，判断两个独立属性：
   - 奇偶匹配：该单元格的 (row mod 2, col mod 2) 是否等于种子奇偶类。
   - 位置类型：该单元格的行索引或列索引是否位于阵列边缘（第 0 行、最末行、第 0 列、最末列）——是则为"边缘格"，否则为"内部格"。
4. 四种处理：
   - 同奇偶 + 内部格：将种子图案的像素（相对于种子单元格左上角的偏移）印章到该单元格，其余像素保持灰(5)。
   - 异奇偶 + 内部格：整格填充为红(2)。
   - 同奇偶 + 边缘格：整格填充为绿(3)。
   - 异奇偶 + 边缘格：保持灰(5)不变。
5. 种子单元格自身保留其原始图案不变。橙(7)格子线保持不变。

**关键洞察**：仅观察边缘格会以为规则是"边缘绿色或灰色交替"；仅观察内部格会以为规则是"内部印章或红色交替"。只有同时考虑两个维度的交叉，才能解释所有单元格的处理方式——这一 2x2 决策矩阵需要对比多个示例中不同位置的种子格才能归纳。

## 新题 5：种子图案弹性拉伸后印章到不等尺寸格子单元格

**组合逻辑**：[印章覆盖/stamp_overlay](创新：目标单元格大小不一，印章不能是刚性复制) + [弹性拉伸/elastic_stretching](创新：拉伸对象从范例矩形变为种子图案，拉伸目标从固定矩形变为格子单元格) ← [同奇偶格接收副本/same_parity_receive_copy] 选择目标，[按目标尺寸调整/resize_to_target] 逐格适配

**来源原语**：印章覆盖(92e50de0), 弹性拉伸(40f6cd08), 同奇偶格接收副本(92e50de0), 按目标尺寸调整(40f6cd08), 内部行程(40f6cd08), 种子图案(92e50de0), 格子结构(8a371977), 单元格区域(8a371977)

**依赖链**：格子分隔出不等尺寸的单元格 → 种子图案的奇偶性选择目标单元格 → 每个目标单元格的尺寸与种子单元格不同 → 必须对种子图案做弹性拉伸（保持边界行程、拉伸内部行程）以适配目标尺寸 → 拉伸后的图案印章到目标。删除拉伸步骤则图案无法适配不同尺寸的单元格；删除印章步骤则拉伸无意义。

在分隔线不等间距的格子中，将种子图案按弹性拉伸规则适配到每个同奇偶目标单元格——边界图案带不变，内部图案带按目标尺寸拉伸或压缩。

**输入结构**：约 22x26 的网格。品红(6)色分隔线（1 像素宽）将网格分成单元格阵列（至少 4 行 x 4 列）。关键特征：分隔线间距不等——行方向和列方向上的间距各不相同（如单元格宽度可能为 3、5、4、6 像素，高度可能为 3、4、5 像素）。所有单元格初始填充为黑(0)背景。一个单元格包含多色种子图案：该图案至少 3 行 3 列，使用绿(3)作为外框色（最外一圈行/列全为绿(3)）、内部使用蓝(1)和红(2)构成一个非对称小图案。种子图案完全填满其所在单元格。生成约束：种子单元格的宽度和高度均 >= 3，以保证内部行程至少有 1 行/列；种子图案的行可分为外框行（顶行和底行）和内部行（中间行），列同理分为外框列和内部列。

**规则**：
1. 识别品红(6)分隔线和单元格阵列，记录每个单元格的宽度和高度。
2. 定位种子图案所在单元格，记录其阵列坐标和奇偶类。
3. 对种子图案做行程分析：
   - 行方向：将行分为上外框行（第 1 行）、内部行（中间若干行）、下外框行（最后 1 行）。
   - 列方向：将列分为左外框列（第 1 列）、内部列（中间若干列）、右外框列（最后 1 列）。
4. 对每个与种子同奇偶的目标单元格：
   - 计算目标单元格的宽度 W_t 和高度 H_t。
   - 保持上/下外框行各 1 行不变，将内部行的数量调整为 H_t - 2（复制或截取种子内部行的图案以填满）。若 H_t - 2 > 种子内部行数，则循环重复种子内部行；若 H_t - 2 < 种子内部行数，则从上往下截取。
   - 同理，保持左/右外框列各 1 列不变，将内部列数量调整为 W_t - 2。
   - 将生成的适配图案粘贴到目标单元格。
5. 异奇偶单元格和种子单元格保持原样。品红(6)分隔线保持不变。

**关键洞察**：同一个种子图案在不同大小的单元格中呈现不同的拉伸结果，但四角和边缘带始终保持一致——求解者必须同时发现"哪些单元格接收图案"（奇偶规则）和"图案如何适配不同尺寸"（弹性拉伸规则）这两个耦合条件。

**规则**：
1. 将网格水平等分为上半区和下半区（行数相等）。
2. 逐格比较上下两半对应位置的像素：
   - 若上半区该位置为遮挡物颜色（红(2)/绿(3)/灰(5)中的一种，且属于一个实心矩形连通块）且下半区对应位置也为遮挡物颜色 → 标记为"双重遮挡"。
   - 判断遮挡物的方法：找到每个半区中所有 4-连通的非周期色单色块，其边界框为实心填充矩形且两个维度均 > 1 的即为遮挡物。
3. 从两个半区中所有非遮挡位置的像素收集可见周期数据，推断最小重复瓦片（行周期和列周期最小的矩形，使得所有可见像素与瓦片一致）。
4. 输出一个与单个半区同尺寸的网格：
   - 双重遮挡位置：用周期瓦片恢复该位置应有的颜色。
   - 所有其他位置：复制上半区对应像素（无论是图案色还是遮挡物色）。

**关键洞察**：下半区不出现在输出中——它的唯一作用是与上半区交叉比较以标定"双重遮挡区"。只看上半区无法知道哪些遮挡区需要恢复；只看下半区无法知道输出内容。两半是对称的信息源但角色不同：一个提供输出框架，另一个提供选择掩码。

## 新题 7：稀疏精灵体稠密化改变面积排序后蛇形压缩

**组合逻辑**：[稠密化/densify](已有) → [排序/sort](创新：排序键是稠密化后的面积，而非原始像素数) → [压缩/compress + 蛇形填充/boustrophedon_fill](已有) ← 稠密化改变了排序键，使得排序结果与直觉不同

**来源原语**：稠密化(db615bd4), 排序(cdecee7f), 压缩(cdecee7f), 蛇形填充(cdecee7f), 稀疏精灵体(db615bd4), 散布标记(cdecee7f), 位置顺序(db615bd4), 奇行反序(cdecee7f)

**依赖链**：稀疏精灵体的可见像素数不等于稠密化后的实际面积 → 稠密化改变面积 → 面积排序得到的颜色顺序与按可见像素数排序的结果不同 → 该顺序决定蛇形填充的放置。删除稠密化步骤则排序键错误，输出颜色顺序改变。

将稀疏精灵体稠密化为实心形状后按面积排序，再将排序后的颜色按蛇形顺序压缩填入一个小网格。

**输入结构**：约 15x15 的黑(0)背景网格。散布着 9 个稀疏单色精灵体，每个精灵体使用不同颜色（蓝(1)、红(2)、绿(3)、黄(4)、灰(5)、品红(6)、橙(7)、青(8)、栗(9)各一个）。每个精灵体由 2~5 个同色像素组成，这些像素位于一个步长为 2 的格点上（即相邻像素之间水平/垂直间隔恰好为 2，中间隔一个黑(0)像素）。各精灵体互不相邻（边界框不重叠且间距 >= 1 像素）。关键特征：不同精灵体的可见像素数可能相同，但由于它们的稀疏布局不同（如 2x2 稀疏格点上 3 个像素 vs. 1x5 稀疏排列上 3 个像素），稠密化后的面积（边界框内所有格点位置填满后的像素数）不同。生成约束：稠密化后的 9 个面积值互不相同。

**规则**：
1. 识别 9 个稀疏精灵体（每种颜色恰好一个 4-连通块，步长-2 格点排列）。
2. 对每个精灵体进行稠密化：确定其像素所在的步长-2 格点的边界框，将该边界框内所有格点位置（每隔一个像素取一个）都填上该精灵体颜色。计算稠密化后的像素总数作为"实际面积"。
3. 按实际面积从小到大排序 9 个精灵体。
4. 将排序后的颜色序列填入一个 3x3 的黑(0)网格，采用蛇形顺序：第 0 行从左到右填前 3 个颜色，第 1 行从右到左填接下来 3 个颜色，第 2 行从左到右填最后 3 个颜色。
5. 输出该 3x3 网格。

**关键洞察**：排序键不是可见像素数（这对多个精灵体相同），而是稠密化后的面积——一个稀疏分布在 3x3 格点上的 3 像素精灵体稠密化后面积为 9，而一个稀疏排列在 1x5 格点上的 3 像素精灵体稠密化后面积为 5。求解者必须发现"先填满再计数"这一非显然的中间步骤。

## 新题 8：标记阵列的边缘内部分类决定印章副本的着色方式

**规则**：
1. 识别多色精灵体，提取其边界框内的完整图案（黑(0)像素视为透明）。
2. 识别所有灰(5)标记像素，根据它们的位置确定其构成的矩形阵列的行数 R 和列数 C（标记等间距排列）。
3. 对阵列中的每个标记，判断其是否位于阵列边缘（第 0 行、第 R-1 行、第 0 列、第 C-1 列中的任何一个 → 边缘标记）或内部（其余 → 内部标记）。

6. 删除原始精灵体（原位置恢复为黑(0)）。灰(5)标记像素被印章副本覆盖。

**关键洞察**：所有副本的形状完全相同（都是原始精灵体的拷贝），但颜色模式分为两类——内部副本保留多色细节，边缘副本退化为单色轮廓。求解者需要从副本阵列中发现"颜色保留 vs. 统一重涂"的分类规则取决于标记在矩形阵列中的位置，而非副本本身的空间属性。

## 新题 9：周期补全揭示隐藏的轴向重复后裁剪唯一瓦片

**组合逻辑**：[补全/completion](已有) → [裁剪/crop](创新：裁剪的前提是补全后涌现的结构——补全前看不到重复) ← [平移等价/translation_equivalence] 驱动补全，补全后 [轴向复制/axial_dup] 才成立，触发 [沿重复轴取首半/first_half_extract]

**来源原语**：补全(484b58aa), 裁剪(7b7f7511), 平移等价(484b58aa), 轴向复制(7b7f7511), 平移向量决定填充(484b58aa), 沿重复轴取首半(7b7f7511), 缺失像素(484b58aa), 重复瓦片(7b7f7511)

**依赖链**：网格有大量缺失像素（黑洞），破坏了视觉上的重复性 → 用周期平移向量填补所有黑洞 → 补全后的网格恰好是一个瓦片沿某一轴的两份完全拷贝 → 裁剪出其中一份。删除补全步骤则两半不同（缺失位置不同），无法识别重复轴；删除裁剪步骤则输出不确定。

先用周期平移向量填补网格中的缺失像素，然后发现补全后的网格恰好是一个瓦片的两份轴向复制，裁剪输出该唯一瓦片。

**输入结构**：约 8x16（或 16x8）的网格。包含一个由 3~4 种颜色（如蓝(1)、红(2)、绿(3)、黄(4)）构成的图案，但约 20%~30% 的像素被替换为黑(0)（缺失像素），散布在网格各处。未被替换的像素保留原色。关键特征：网格的长轴恰好是短轴的 2 倍（如 8x16），但由于缺失像素的干扰，从视觉上看不出长轴方向上两半是否相同。生成约束：底层的真实图案是一个 8x8（或等尺寸）瓦片沿长轴复制一次得到的 8x16 网格；缺失像素在两半中的位置不同，使得两半在补全前看起来不一样；存在唯一的非零平移向量使得所有可见像素一致。

**规则**：
1. 在所有非零平移向量中，找到使得重叠区域内可见像素对（两端都非黑(0)）全部颜色一致、且这样的一致对数量最多的向量。
2. 用该向量及其逆向量传播颜色：对每个黑(0)像素，若沿该向量（或逆向量）偏移后的位置有非黑颜色，则用该颜色填充当前黑(0)像素。重复传播直到所有可填充的黑(0)像素都被填满。
3. 补全后，检查网格是否沿某一轴可分为两个完全相同的半部（上下或左右）。找到唯一的这样的轴。
4. 输出该轴上的前半部（上半或左半）。

**关键洞察**：缺失像素的分布故意使得两半看起来不同——如果直接比较上下（或左右）半部会发现大量不匹配。周期补全是发现隐藏的轴向对称性的必要前提步骤。补全本身不是目的，而是揭示瓦片结构的工具。
