## 新题 1：对称残影构筑射线屏障

**组合逻辑**：[镜像](将原始图案水平翻转) → [逻辑交](原始与镜像的逐像素重叠提取对称残留点) → [射线延伸](从标记像素向四方发射，遇残留点或阻挡像素停止)

**来源原语**：镜像(mirror) ← f25ffba3；逻辑交(logical_AND) ← 0520fde7；射线延伸(ray_extend) ← 95755ff2；标记像素(marker_pixel) ← 40853293/ddf7fa4f；阻挡像素(blocker_pixel) ← ff72ca3e/95755ff2

**依赖链**：镜像的输出直接决定逻辑交能提取哪些像素作为绿(3)锚点；锚点的空间分布与灰(5)阻挡像素共同界定了每条射线的传播边界；因此蓝(1)图案的对称程度在数量上控制了锚点密度，进而在几何上控制了射线长度。

将一个非对称蓝色图案与其水平镜像做逻辑交，提取位于对称轴上的绿色锚点，再用这些锚点与灰色阻挡像素共同限制红色标记像素发出的四方射线的传播距离。

**输入结构**：
- 网格约 12x12，黑(0)背景。
- 蓝(1)像素组成一个 4-连通的不规则连通区域（约 15-25 像素），跨越网格中部，整体不具有水平对称性，但局部有若干像素恰好落在水平镜像后的对应位置上。
- 2-3 个红(2)标记像素散布在黑(0)背景区域（不与蓝像素重叠）。
- 2-4 个灰(5)阻挡像素散布在黑(0)背景区域（不与蓝、红像素重叠）。
- 生成约束：蓝(1)图案与其水平镜像的逻辑交至少产生 2 个绿(3)锚点，且不同示例中锚点数量不同；每个红(2)标记在至少一个方向上能被绿(3)锚点阻挡、在至少一个方向上能被灰(5)阻挡像素阻挡（使求解者必须区分两类阻挡源）。

**规则**：
1. 以网格的垂直中轴为翻转轴，将所有蓝(1)像素水平镜像，生成一份虚拟副本。
2. 对每个像素位置做逻辑交：若原始图案和镜像副本在同一位置都是蓝(1)，则该位置变为绿(3)锚点；所有不满足此条件的蓝(1)像素擦除为黑(0)背景。
3. 从每个红(2)标记像素分别向上、下、左、右发射射线。射线沿途将黑(0)背景像素涂为黄(4)，遇到以下任一情况时停止（不涂终止位置本身）：绿(3)锚点、灰(5)阻挡像素、网格边界。
4. 绿(3)锚点、红(2)标记、灰(5)阻挡像素在输出中保持不变。

**关键洞察**：蓝色图案的对称程度隐式编码了射线屏障的密度——高度对称的图案会产生大量绿色锚点使射线寸步难行，而几乎不对称的图案只留极少锚点让射线畅行无阻。求解者必须先发现"镜像再求交"这一隐藏步骤，才能理解绿色锚点的来源。

## 新题 2：连线分区内散点多数决填色

**组合逻辑**：[连线](同色成对标记连直线) → [洪泛填充](识别线段围成的封闭区域) → [多数决](封闭区域内散点的多数色) → [填充](按多数色填满封闭背景)

**来源原语**：连线(draw_line) ← 40853293；洪泛填充(flood_fill) ← 543a7ed5；多数决(majority_vote) ← af24b4cc；填充(fill) ← ff72ca3e/95755ff2；同色配对(same_color_pairing) ← 40853293；竖线交叉优先(vertical_priority_at_cross) ← 40853293

**依赖链**：连线的几何走向决定了洪泛填充能识别出哪些封闭区域；封闭区域的边界又决定了哪些散点被归入哪个区域；区域内散点的颜色分布决定了多数决的结果；最终填充色完全取决于散点的空间归属——而归属取决于连线的交叉方式。

将同色成对标记用直线连接以分隔网格，洪泛填充识别由线段围成的封闭区域，按区域内独立散点的多数色填充每个封闭区域的背景。

**输入结构**：
- 网格约 12x14，黑(0)背景。
- 3-4 对同色标记像素（每对颜色不同，可用蓝(1)、绿(3)、橙(7)、栗(9)等），每对中的两个像素共享同一行或同一列。线段颜色即为连线色。
- 另有 4-8 个独立散点（"独立"指其颜色在全图中仅出现一次，不构成配对），颜色取自红(2)、黄(4)、品红(6)，散布于网格中。
- 生成约束：连线后至少形成 2 个封闭区域（由线段与网格边界围成、洪泛填充从网格四角出发无法到达的区域）；每个封闭区域至少包含 1 个独立散点；至少一个封闭区域包含 2 个以上独立散点（使多数决有意义）；至少存在一处水平线段与竖直线段的交叉。

**规则**：
1. 对每对同色标记像素，用其颜色画出连接它们的水平或竖直一像素宽线段（含两端点）。若一条水平线段与一条竖直线段在同一像素交叉，该像素取竖直线段的颜色。
2. 将所有线段像素和独立散点视为"前景墙壁"。从网格四个角落出发，对黑(0)背景做 4-连通洪泛填充。无法被填充到达的黑(0)区域即为封闭区域；可到达的为开放区域。
3. 对每个封闭区域，收集其内部所有独立散点的颜色，取出现次数最多的颜色作为该区域的填充色。若出现平局，取在该区域中位置最靠上（行号最小）的散点颜色；若行号也相同，取列号最小者。
4. 将每个封闭区域内所有黑(0)背景像素涂为该区域的填充色。开放区域的背景保持黑(0)。所有线段像素和独立散点在输出中保持不变。

**关键洞察**：竖直线段在交叉点处覆盖水平线段的颜色，这可能导致一条水平线段在视觉上看起来被"切断"，但实际上该交叉点仍然是前景墙壁——封闭区域的判断基于前景/背景二值关系而非颜色连续性。求解者需要对比多个示例才能发现交叉优先规则以及"散点颜色多数决"而非"线段颜色决定填色"的机制。

## 新题 3：模板孔洞数匹配门控印章与擦除

**组合逻辑**：[洪泛填充](区分框架内外) → [计数](框架内标记数 & 模板孔洞数) → 比较判定 → [印章覆盖 | 擦除]（匹配则印章，不匹配则擦除框架）

**来源原语**：洪泛填充(flood_fill) ← 543a7ed5；计数(counting) ← 8698868d/902510d5；印章覆盖(stamp_overlay) ← e734a0e8/8719f442；擦除(erase) ← 902510d5；空心框架(hollow_frame) ← 8698868d；模板图块(template_tile) ← e734a0e8；标记像素(marker_pixel) ← e734a0e8/ddf7fa4f；孔洞(hole) ← 8698868d；区域可达性(region_reachability) ← 543a7ed5

**依赖链**：洪泛填充将空间分为框架内部和外部 → 计数在每个框架内部统计红色标记数 → 模板的孔洞数提供全局比较基准 → 标记数与孔洞数的相等性判定决定该框架被印章覆盖还是被完全擦除。模板同时承担"被印章的图案"和"提供选择阈值"两个角色。

统计模板图块中的孔洞数作为阈值，洪泛填充识别每个空心框架的内部，框架内红色标记数等于该阈值时印章模板，否则擦除框架。

**输入结构**：
- 网格约 15x15，黑(0)背景。
- 左上角放置一个绿(3)模板图块（4x4 或 3x3），由绿(3)前景像素和黑(0)孔洞像素组成，孔洞为模板内部被绿(3)像素 4-连通包围的黑(0)连通区域（1-3 个孔洞，每个孔洞 1-2 像素）。
- 3-5 个蓝(1)空心矩形框架分散在网格中（不与模板重叠，框架间互不重叠），每个框架边框一像素宽，内部尺寸至少能容纳模板。
- 框架内部散布若干红(2)标记像素（0-4 个不等），放置在黑(0)背景上，不与框架边框重叠。
- 生成约束：至少一个框架的内部红色标记数恰好等于模板孔洞数（将被印章），至少一个框架不等于（将被擦除）；不同示例中模板孔洞数不同（迫使求解者从模板中归纳阈值而非记忆固定数字）。

**规则**：
1. 从网格四角对黑(0)背景做 4-连通洪泛填充，标记所有外部可达的黑(0)像素。每个蓝(1)框架内部未被标记的黑(0)区域即为该框架的内部区域。
2. 统计模板图块中孔洞的数量：在模板的边界框内，找出所有被绿(3)像素 4-连通包围且无法从模板边界框外部到达的黑(0)连通区域，每个连通区域计为一个孔洞。记此数为 H。
3. 对每个框架，统计其内部区域中红(2)标记像素的数量，记为 M。
4. 若 M = H：将模板图块印章到该框架内部的左上角（模板左上角对齐框架内部区域的左上角），模板的绿(3)像素覆盖对应位置的黑(0)背景，模板孔洞位置保持黑(0)不变。红(2)标记像素保留在原位（即使被模板覆盖区域包含，标记像素仍显示为红(2)，优先级高于绿(3)）。
5. 若 M ≠ H：擦除该框架的全部蓝(1)边框像素（设为黑(0)），框架内部的红(2)标记像素保留为浮动散点。
6. 模板图块在原始位置保持不变。

**关键洞察**：模板既是被印章的图案，又是判定印章与否的选择标准来源——其拓扑属性（孔洞数）充当匹配阈值。求解者必须同时分析模板的几何结构和各框架内的标记数量，且需对比不同模板孔洞数的多个示例才能发现"孔洞数=标记数"这一匹配条件。

## 新题 4：桥接连通分量大小决定像素放大倍率

**组合逻辑**：[连通判定](经桥接路径将前景对象分组) → [计数](每组包含的对象数) → [像素放大](对象数即为该组每个对象的放大倍率) → [擦除](移除桥接路径)

**来源原语**：连通判定(connectivity_test) ← 239be575；计数(counting) ← 902510d5/8698868d；像素放大(pixel_scaling) ← 8719f442；擦除(erase) ← 902510d5；桥接路径(bridge_path) ← 239be575；前景对象(foreground_object) ← 239be575；计数决定尺寸(count_determines_size) ← 902510d5

**依赖链**：桥接像素的连通关系决定哪些对象属于同一组 → 组内对象数量成为所有组员共享的放大倍率 → 放大后的对象尺寸和位置取决于该数量 → 桥接像素在最终输出中被擦除，使得分组依据不再可见。

将散布的小型前景对象通过青色桥接路径分组，每组包含的对象数量即为该组所有对象的像素放大倍率；桥接路径最后被擦除。

**输入结构**：
- 网格约 12x12，黑(0)背景。
- 3-5 个小型单色前景对象，每个对象 2-4 像素，4-连通，颜色各异（可用红(2)、绿(3)、黄(4)、橙(7)、品红(6)）。对象间互不相邻。
- 青(8)桥接像素形成若干 4-连通路径，将部分对象连接起来（某个对象的某像素与青(8)路径的端点 4-相邻即视为连接）。某些对象不与任何桥接路径相连（孤立对象）。
- 生成约束：至少存在一个包含 2 个对象的连通组和一个包含 3 个对象的连通组（或一个孤立对象），以展现不同放大倍率；放大后的对象不超出网格边界（因此对象原始位置需靠近左上方且尺寸较小）；同一组内不同对象放大后不互相重叠。

**规则**：
1. 在所有非黑像素（前景对象 + 青(8)桥接像素）上做 4-连通分量分析，忽略颜色差异。每个连通分量构成一个"组"。
2. 统计每个组中包含的前景对象数量（一个对象 = 一个同色 4-连通区域，青色桥接不算对象），记为 S。孤立对象（无桥接连接）自成一组，S = 1。
3. 对每个组中的每个前景对象：以该对象边界框的左上角为锚点，将对象做 S 倍像素放大（每个原始像素变为 S x S 的同色方块）。放大后的像素仅覆盖黑(0)背景位置。
4. 若同组内两个放大后的对象发生重叠（生成约束应避免此情况，但作为兜底规则）：原始位置列号更大的对象绘制在上层。
5. 擦除所有青(8)桥接像素（设为黑(0)）。

**关键洞察**：桥接路径在输出中被擦除，但它决定了每个对象的放大倍率。求解者必须从放大倍率的差异反推出分组关系，进而理解输入中已不可见的桥接连接是分组依据。将更多对象桥接到同一组反而让每个对象变得更大——这种"连接越多越膨胀"的涌现效应是反直觉的。

## 新题 5：格子多数色连通性决定强化或清除

**组合逻辑**：[多数决](每个格子块提取多数色) → [连通判定](多数色相同的相邻块构成连通组) → [填充 | 擦除]（连通组大小 >= 2 则强化填实，孤立则清除）

**来源原语**：多数决(majority_vote) ← af24b4cc；压缩(compress) ← af24b4cc/7e4d4f7c；连通判定(connectivity_test) ← 239be575；填充(fill) ← ff72ca3e/95755ff2；擦除(erase) ← 902510d5；分隔行列(separator_row_col) ← af24b4cc；填色块(filled_block) ← af24b4cc；格子格局(lattice_layout) ← af24b4cc

**依赖链**：多数决将每个含噪声的混色格子块提炼为一个代表色 → 代表色在格子拓扑上的 4-连通性决定哪些块属于同一组 → 组大小决定每个块的命运（强化或清除）→ 强化操作回到原始分辨率修改像素，清除操作也在原始分辨率上执行。抽象层的连通分析驱动具体层的像素变换。

在分隔线划分的格子中，对每个混色块取多数色并在格子拓扑上做连通分析：多数色相邻形成连通组的块被强化为纯色，多数色在邻域中唯一的孤立块被清除为黑色。

**输入结构**：
- 网格约 15x17，灰(5)分隔行和分隔列（包括外边框，每条一像素宽）将网格内部划分为规则的格子阵列（如 4x4 排列的 3x3 大小格子块）。
- 每个格子块内填满 2-3 种颜色的像素（无黑色、无灰色），其中一种颜色像素数严格大于其他颜色（即存在唯一多数色）。可用颜色：蓝(1)、红(2)、绿(3)、黄(4)、品红(6)、橙(7)。
- 生成约束：在多数色组成的抽象格子图中，至少存在一个大小 >= 2 的 4-连通同色组和至少一个孤立块（多数色与所有 4-相邻块的多数色都不同）；不同示例中格子阵列尺寸或多数色分布不同（迫使求解者归纳一般规则而非记忆特定布局）。

**规则**：
1. 对每个格子块，统计块内各颜色的像素数量，取出现最多的颜色作为该块的"多数色"。若存在平局（生成约束保证不会出现），取块内左上角像素的颜色。
2. 构建格子拓扑的抽象图：每个格子块是一个节点，节点颜色为其多数色。两个节点之间有边当且仅当对应的格子块在格子阵列中 4-相邻（上下左右，不含对角）。
3. 在抽象图上找所有多数色相同的 4-连通分量。
4. 对于大小 >= 2 的连通分量中的每个格子块：将块内所有非多数色像素替换为多数色（整块变为纯色）。
5. 对于孤立块（连通分量大小 = 1）：将块内所有像素替换为黑(0)。
6. 灰(5)分隔线在输出中保持不变。

**关键洞察**：每个格子块的命运不仅取决于它自身的内容，还取决于邻居的多数色——这是一个"社会性"规则：多数色在邻域中被认同的块得到强化，而孤立的块被清除。求解者单看一个块无法判断其命运，必须在抽象的多数色拓扑上做全局连通分析。

## 新题 6：平铺揭示跨缝连通性驱动选择性装饰

**组合逻辑**：[平铺](2x2 复制产生拼接缝) → [连通判定](检测跨缝 8-邻接连通) → [标记邻居](仅对跨缝连通的种子做对角装饰，颜色取决于连通伙伴)

**来源原语**：平铺(tiling) ← 10fcaaa3；标记邻居(mark_neighbors) ← 10fcaaa3；连通判定(connectivity_test) ← 239be575；种子像素(seed_pixel) ← 10fcaaa3；对角邻接(diagonal_adjacency) ← 10fcaaa3；连通性(connectivity) ← 239be575

**依赖链**：平铺在象限接缝处产生新的 8-邻接关系，这些关系在原始单份中不存在 → 连通判定在平铺后的网格上发现哪些种子因接缝而连接到了其他种子 → 连通状态决定是否装饰以及装饰颜色（连通伙伴色 vs 灰色）。种子在原始网格中的位置隐式编码了平铺后是否会连通。

将小网格做 2x2 平铺后，检测哪些种子像素因象限接缝处的 8-邻接关系而与其他种子形成跨缝连通；跨缝连通的种子用伙伴色做对角装饰，孤立的种子用灰色做对角装饰。

**输入结构**：
- 网格约 5x6 或 6x5，黑(0)背景。
- 3-5 个单像素种子，每个种子颜色不同（可用蓝(1)、红(2)、绿(3)、黄(4)、橙(7)）。
- 种子散布在网格中的不同位置。无其他前景元素。
- 生成约束：平铺后至少一对种子（不同颜色）在象限接缝处 8-相邻（即一个种子位于原始网格的某边缘/角落附近，其平铺副本与另一个种子的副本在接缝处对角相邻），同时至少一个种子在平铺后不与任何其他种子 8-连通；不同示例中种子位置不同，导致跨缝连通关系不同。

**规则**：
1. 将输入网格做 2x2 平铺：输出网格尺寸 = 原始高度 x 2 行、原始宽度 x 2 列。四个象限各为原始网格的完整副本（左上 = 原始，右上 = 向右平移原始宽度，左下 = 向下平移原始高度，右下 = 同时平移）。
2. 在平铺后的网格上，对所有种子像素副本做 8-连通分量分析（忽略颜色差异，所有非黑像素视为前景）。
3. 分类每个种子（以原始网格中的身份标识）：
   - "跨缝连通"：该种子的某个副本与至少一个不同颜色种子的副本 8-相邻（处于不同象限的相邻副本之间）。
   - "孤立"：该种子的所有 4 个副本都不与任何其他种子的副本 8-相邻。
4. 对跨缝连通的种子：在平铺后的网格中，将其所有 4 个副本的 4 个对角邻位（左上、右上、左下、右下）涂为该种子的跨缝连通伙伴的颜色（若有多个伙伴，取在原始网格中行号最小、行号相同则列号最小的伙伴的颜色）。仅涂黑(0)背景位置。
5. 对孤立种子：在平铺后的网格中，将其所有 4 个副本的 4 个对角邻位涂为灰(5)。仅涂黑(0)背景位置。
6. 若两个种子的装饰区域在同一像素重叠，取行号更小的种子（在原始网格中）的装饰色。

**关键洞察**：种子在原始小网格中的位置隐式编码了平铺后的连通关系——靠近网格边缘（尤其是角落）的种子更可能在接缝处与位于对面边缘的种子产生 8-邻接。求解者必须在心中完成平铺，检查接缝处的空间关系，才能判断哪些种子会被装饰以及用什么颜色。单凭一个示例难以确定装饰规则，需要对比多个不同种子布局的示例才能归纳出"平铺后跨缝连通"这一判定标准。

## 新题 7：形状频次与切比雪夫距离双轴分类排列

**组合逻辑**：[排序](按形状频次分组 + 按切比雪夫距离排序) → [平移](频次组决定上下、距离决定左右) → [填充](距离值编码为正方形光晕) → [擦除](移除阻挡像素)

**来源原语**：排序(sorting) ← 62593bfd；平移(translate) ← 62593bfd；裁剪(crop) ← a61ba2ce；填充(fill) ← ff72ca3e；擦除(erase) ← 902510d5；精灵体(sprite) ← a61ba2ce/8698868d；阻挡像素(blocker_pixel) ← ff72ca3e/95755ff2；形状频次分组(shape_frequency_grouping) ← 62593bfd；切比雪夫距离(chebyshev_dist) ← ff72ca3e；旋转翻转不变(rotation_flip_invariant) ← 62593bfd；共享与唯一形状(shared_vs_unique_shape) ← 62593bfd

**依赖链**：形状的旋转/翻转不变规范形决定频次分组（共享 vs 唯一）→ 频次组决定垂直放置区域（顶部 vs 底部）以及组内水平排序方向 → 切比雪夫距离决定水平排序的具体位次以及光晕正方形的边长 → 填充操作使用距离值在目标位置绘制背景光晕 → 最后擦除灰色阻挡像素。两个独立的几何属性（形状拓扑 + 空间距离）交叉驱动两个独立的输出维度（垂直位置 + 光晕大小）。

按形状的旋转翻转不变规范形将精灵体分为"共享形状"和"唯一形状"两组，共享组平移到网格顶部、唯一组平移到底部；组内按到最近灰色阻挡像素的切比雪夫距离排序（共享组升序、唯一组降序），并在每个精灵体的目标位置绘制一个边长等于该距离的背景色光晕正方形。

**输入结构**：
- 网格约 16x16，黑(0)背景。
- 5-6 个小型单色 4-连通精灵体（每个 3-6 像素，边界框不超过 3x3），颜色各异（可用蓝(1)、红(2)、绿(3)、黄(4)、橙(7)、品红(6)），散布在网格中，互不相邻。精灵体的具体形状由连通结构和像素排列决定，不限于特定几何名称；同一形状（旋转/翻转后等价）的精灵体至少出现 2 次，至少一个精灵体的形状是唯一的。
- 3-5 个灰(5)阻挡像素散布在网格中，不与任何精灵体重叠或相邻。
- 生成约束：每个精灵体的边界框中心到最近灰(5)像素的切比雪夫距离 D 互不相同（保证排序无歧义）且 D >= 2；共享形状组至少 2 个精灵体，唯一形状至少 1 个精灵体；平移到目标位置后所有精灵体（含光晕）互不重叠。

**规则**：
1. 对每个精灵体，裁剪到其最小边界框，计算其二值掩码的旋转/翻转不变规范形（从 8 种变体中取字典序最小的二值矩阵）。
2. 按规范形分组：出现 2 次及以上的规范形对应"共享组"，仅出现 1 次的为"唯一组"。
3. 对每个精灵体，计算 D = 其边界框中心到最近灰(5)像素的切比雪夫距离。
4. 共享组精灵体：按 D 升序排列，依次平移到网格第 0 行，水平位置从左到右依次排列，相邻精灵体的边界框之间留 1 列黑色间隔。
5. 唯一组精灵体：按 D 降序排列，依次平移到网格最底行（边界框底边对齐网格底边），水平位置从左到右依次排列，相邻精灵体的边界框之间留 1 列黑色间隔。
6. 在每个精灵体的目标位置，先绘制一个以精灵体边界框中心为中心、边长为 D 的栗(9)色正方形光晕（仅覆盖黑(0)背景像素），再将精灵体本身叠加在光晕之上（精灵体像素覆盖光晕像素）。
7. 擦除所有灰(5)阻挡像素（设为黑(0)）。

**关键洞察**：共享组和唯一组的排序方向相反（共享组按距离升序、唯一组降序），且光晕大小直接编码了距离值。求解者必须同时发现两个独立的分类轴——形状频次（决定上/下和排序方向）与空间距离（决定左右位次和光晕大小）——并理解灰色阻挡像素在输出中被擦除但其位置是距离计算的关键参照物。
