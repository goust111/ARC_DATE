## 新题 1：对角带射线印章与层深取色

**组合逻辑**：[射线延伸](创新：射线目标从贯穿条改为对角带) + [印章覆盖](命中点放置标记) + [循环填充](创新：层深度不再用于重涂带本身，而是决定印章颜色)

**来源原语**：射线延伸·投射·命中处印标记 来自 ecdecbb3；循环填充·对角带·调色板行·层深度递增·层深模色板取色 来自 b457fec5；控制像素 来自 2f767503

**依赖链**：控制像素发射射线 → 射线命中对角带表面 → 命中点在带内的层深度决定印章颜色（经调色板循环取色） → 印章放置在命中点。射线目标、颜色来源、印章位置三者全部由对角带的几何结构统一决定，缺少任一环节均无法确定输出。

从控制像素发射射线命中对角带，在命中点放置印章，印章颜色由命中点在带内的层深度经调色板循环取色决定。

**输入结构**：
- 网格约 18x18，背景黑(0)。
- 2-4 条灰(5)对角带，每条是 45 度倾斜的带状区域（宽 3-5 像素、沿对角方向长 8-12 像素），方向为左上-右下或右上-左下。每条带在靠近网格某一边的端部有一个平坦的顶帽（与行或列对齐的平头端）。带之间不重叠。
- 一行水平排列的调色板，由 2-4 个不同颜色的像素组成（如红(2)、绿(3)、蓝(1)），放在网格顶部或底部边缘行，不与任何对角带重叠。
- 2-5 个孤立的橙(7)控制像素，各自位于某条对角带的行方向或列方向延长线上（即沿行或列可以"看到"一条带），与带保持至少 2 个像素的间隔。
- 生成约束：每个控制像素至少有一个基本方向的射线能命中一条对角带；不同控制像素可命中不同的带。

**规则**：
1. 保留调色板行和所有对角带像素不变。
2. 对每个橙(7)控制像素，分别向上、下、左、右四个基本方向发射射线。
3. 每条射线沿直线前进，在遇到第一个灰(5)对角带像素时停止。若在到达网格边缘前未遇到带像素，该方向不产生任何效果。
4. 在每个命中点，计算该像素在其所属对角带中的层深度：层 0 为带的最外层边界像素，层 1 为紧邻内侧的下一层，以此类推。层深度计算方式为该像素到带边缘沿垂直于带轴方向的最短距离。
5. 在命中点放置一个印章像素，颜色为 调色板[层深度 mod 调色板长度]，调色板从左到右依次索引为 0, 1, 2, ...。
6. 处理完所有射线后，移除所有橙(7)控制像素（设为背景色）。
7. 若两条不同射线命中同一个带像素，仅保留一个印章（按控制像素从上到下、从左到右的顺序，后处理的覆盖先处理的）。

**关键洞察**：印章颜色既不由控制像素决定，也不由射线方向决定，而由射线穿入对角带的深度位置决定；对角带的内部层结构本身编码了颜色映射表。

## 新题 2：空心十字连线驱动递减帽延伸

**组合逻辑**：[连线](已有：连接同行/列对齐的空心十字标记) + [递减填充](创新：起始长度不再由对象自身边缘行程决定，而等于连线段的像素长度；延伸方向从四方外扩改为垂直于连线方向)

**来源原语**：连线·空心十字标记·同行同列对齐·仅相邻锚点间连接 来自 60a26a3e；递减填充·边缘行程·逐步缩短行程·四方外扩 来自 9772c176

**依赖链**：识别空心十字标记并计算中心 → 连接同行/列相邻对的中心（产生蓝色连线段）→ 连线段长度 L 成为递减帽延伸的起始参数 → 从每条连线的两个端点（连线与标记臂的交点）向垂直于连线的方向向外延伸递减帽（L, L-2, L-4, ...）。删掉连线步骤则无法确定帽的起始长度；删掉递减帽则连线本身不足以解释输出中的黄色像素。

连接对齐的空心十字标记后，在每个连线端点向垂直方向延伸递减帽，帽的起始宽度等于连线的像素长度。

**输入结构**：
- 网格约 20x20，背景黑(0)。
- 4-8 个红(2)空心十字标记：每个是 3x3 图案，仅四个基本方向的臂像素存在（中心和四角为背景）。
- 部分标记的中心共享同一行或同一列，相邻标记臂之间有 3-10 个背景像素的间隔。
- 任意两个标记的边界框间距至少 3 个像素（不相邻）。
- 至少 3 对标记存在同行或同列对齐关系。
- 不同对齐对的连线长度各不相同（生成约束），以确保递减帽的高度可区分。

**规则**：
1. 计算每个空心十字标记的空缺中心位置。
2. 对每一行中包含多个中心的情况，按列从左到右排序；对每一列，按行从上到下排序。连接每对相邻中心：将它们对立臂之间的所有背景像素涂为蓝(1)。
3. 设某条连线段包含 L 个蓝色像素（不计两端的臂像素本身）。
4. 在该连线段的两个端点（连线与标记臂的交接处），向垂直于连线的方向向外延伸递减帽：
   - 若连线为水平方向，垂直方向为上和下。从臂像素所在行向外，逐行绘制黄(4)像素条。
   - 第 1 步（紧邻臂像素的下一行/列）绘制 L 个像素的条，以臂像素的列（水平连线时）或行（垂直连线时）为中心对称排列。
   - 第 2 步绘制 L-2 个像素的条，同样居中；第 3 步绘制 L-4 个像素；以此类推，直到剩余长度小于 1 时停止。
   - 每个端点向两个垂直方向（如上和下）各自独立延伸。
5. 超出网格边界的帽像素直接舍弃。
6. 若帽像素位置已有红(2)标记像素，红像素优先保留。
7. 若不同连线的帽延伸在同一像素重叠，后处理的连线（按行主序处理连线）的黄色覆盖先处理的。

**关键洞察**：递减帽的尺寸不是标记自身的固有属性，而由标记之间的连线距离传递而来；间距越大的标记对产生越高的递减金字塔，使视觉输出随标记间距系统性变化。

## 新题 3：框内精灵旋转角度排序堆叠

**组合逻辑**：[裁剪](已有：提取框内区域) + [旋转](已有：角标记定义旋转角度) + [排序](创新：排序键不再是颜色频率，而是旋转角度) + [堆叠](已有：按序堆叠)

**来源原语**：裁剪·空心矩形·包含·唯一完整边框 来自 c909285e；旋转·精灵体·单像素标记·缺角方形标记·角落对应·标记定旋转源目 来自 ecaa0ec1；排序·按计数升序 来自 81c0276b；堆叠 来自 505fff84

**依赖链**：识别灰色框并裁剪内部 → 在每个内部中根据角标记确定旋转角度 → 旋转精灵体 → 按旋转角度对裁剪结果排序 → 纵向堆叠输出。旋转角度同时是变换参数和排序键，两个用途缺一不可。

裁剪矩形框内的精灵体，依据角标记确定每个精灵需要的旋转角度，旋转后按角度升序堆叠输出。

**输入结构**：
- 网格约 20x25，背景黑(0)。
- 3-4 个不重叠的灰(5)空心矩形框，每个外部尺寸恰为 7x7（内部 5x5）。
- 每个框的四个角中，有一个角的像素为背景色而非灰色（即该角有 1 像素的缺口），其余三角完整。不同框的缺口角位置各不相同。
- 每个框内部包含：
  - 一个 3x3 双色精灵体（主体色各框不同：红(2)、蓝(1)、绿(3)、橙(7)等，主体占 6-8 像素，辅色占 1-3 像素），形状不规则但 4-连通。
  - 一个孤立的黄(4)单像素标记，位于精灵体某个角的对角线外侧 1 像素处（在框内部范围内）。
  - 三个黄(4)像素组成 L 形（缺角方形标记），接触精灵体的另一个角。
- 生成约束：4 个框的旋转角度（0, 90, 180, 270 度）各不相同。

**规则**：
1. 识别每个灰(5)矩形框，裁剪其 5x5 内部区域。
2. 在每个内部区域中，定位 3x3 精灵体、孤立黄色标记和 L 形黄色标记组。
3. 精灵体与孤立黄色标记对角相邻的那个角为"源角"。
4. 框的缺口角（灰色像素缺失的角）为该框的"目标角"。缺口角映射到内部区域的对应角。
5. 计算将源角映射到目标角所需的顺时针旋转角度（0, 90, 180, 或 270 度）。
6. 移除内部区域的所有黄(4)标记像素（设为背景），然后将整个 5x5 内部区域绕中心旋转该角度。
7. 将所有旋转后的 5x5 内部区域按旋转角度升序排列（0 < 90 < 180 < 270）。
8. 纵向堆叠（从上到下），无间隔行，输出网格宽度为 5，高度为 5 乘以框的数量。

**关键洞察**：旋转角度并非仅用于视觉变换，而是同时充当隐藏的排序键；要确定输出顺序，必须先独立求解每个框的角标记旋转问题，再将角度值用作排列依据。

## 新题 4：跨面板镜像与障碍绕行重涂色

**组合逻辑**：[镜像](已有：行序翻转) + [连线/绕行](创新：绕行目标不再是同色分量间的连接，而是镜像目标位置与实际放置位置之间的位移路径) + [重涂色](创新：重涂条件不再是形状匹配，而是是否发生了位移绕行)

**来源原语**：镜像·整幅画布·翻转行序 来自 68b16354；连线·障碍墙·同色连通分量·绕障碍最短路径 来自 f8f52ecc；分隔行·跨面板搬运 来自 dc46ea44；重涂色 来自 776ffc46

**依赖链**：上面板对象镜像到下面板计算目标位置 → 检测目标位置与障碍墙冲突 → 冲突对象通过 BFS 搜索最近无冲突放置位置 → 绘制位移连接路径 → 被位移的对象重涂为黄色以区分。镜像提供目标、障碍产生冲突、绕行解决冲突、重涂标记冲突——四步形成因果闭环。

将上面板的彩色对象镜像到下面板；与障碍墙冲突的对象被移至最近可用位置，绘制绿色连接路径，并重涂为黄色标记位移。

**输入结构**：
- 网格约 15x30（宽），背景黑(0)。
- 一条贯穿全宽的灰(5)水平分隔行将网格分为等高的上面板（行 0 至分隔行-1）和下面板（分隔行+1 至最后一行）。
- 上面板包含 3-5 个小型 4-连通单色对象（每个 3-6 像素），颜色各不相同且非灰非黄（如红(2)、蓝(1)、绿(3)、橙(7)、栗(9)）。对象间互不相邻。
- 下面板包含 2-4 段青(8)障碍墙：每段是短的水平或垂直条（3-5 像素长）。障碍的放置保证至少 2 个上面板对象的镜像目标位置与障碍重叠，且至少 1 个不重叠。
- 生成约束：对每个存在冲突的对象，下面板中存在通过背景像素可达的、能容纳该对象完整形状的无冲突区域，且该区域与镜像目标位置的曼哈顿距离不超过 5。

**规则**：
1. 保留分隔行不变。
2. 保留下面板所有青(8)障碍墙不变。
3. 对上面板中每个彩色对象，计算其镜像目标位置：每个像素的行 r 映射到 分隔行行号 + (分隔行行号 - r)，列不变。
4. 若镜像后的对象所有像素均不与任何障碍像素或已放置对象像素重叠，则将该对象以原色放置在镜像位置。
5. 若镜像后的对象有任何像素与障碍或已放置对象重叠：
   - 以镜像位置的质心为起点，对该对象执行 BFS 位移搜索：依次尝试将整个对象向上、右、下、左平移 1, 2, 3, ... 像素，找到第一个使所有对象像素均落在背景空位上（不与障碍、分隔行、已放置对象重叠）的位移方案。搜索按曼哈顿距离升序、同距离时按上-右-下-左优先。
   - 在镜像质心与实际放置质心之间绘制一条 1 像素宽的绿(3) L 形连接路径（先水平后垂直）。路径像素仅覆盖背景像素，遇到障碍或其他非背景像素则跳过该像素（路径不连续处断开）。
   - 将该对象重涂为黄(4)后放置在实际位置。
6. 按上面板对象的行主序（从上到下，同行从左到右）依次处理。先放置的对象成为后续对象的障碍。
7. 上面板的所有对象像素在输出中清除为背景。

**关键洞察**：镜像本身是平凡的，但障碍冲突将问题转化为带优先级的放置博弈：处理顺序决定了哪些对象能获得镜像位置、哪些被挤到次优位置并被标记为位移，使最终布局不可从单个对象独立推断。

## 新题 5：括号提取调色板驱动对角带层填充

**组合逻辑**：[裁剪/括号提取](已有：蓝·青标记对界定行段) + [循环填充](已有：层深度模调色板取色) — 创新在于调色板不再是输入中显式给出的一行像素，而是通过括号提取从网格的另一区域间接获得

**来源原语**：裁剪·控制像素对·行段·括号界定提取范围·按行序堆叠等宽段 来自 505fff84；循环填充·对角带·调色板行·层深度递增·层深模色板取色 来自 b457fec5

**依赖链**：识别蓝·青括号对标记行 → 提取每行括号间的像素段 → 每段的左起第一个非背景像素颜色成为调色板的一个条目 → 用此调色板按层深度循环填充对角带。提取步骤产出调色板，填充步骤消费调色板，两者缺一均无法确定输出。

- 网格约 20x20，背景黑(0)。

- 一条垂直灰(5)分隔线位于约第 10 列，贯穿全高。
- 右半区（约列 11-19）：2-3 条灰(5)对角带，每条宽 3-4 像素、沿对角方向长 6-10 像素，方向为 45 度。每条带在靠近网格顶部的一端有平坦的顶帽。
- 生成约束：提取出的调色板条目数大于等于所有对角带中最大层深度加 1。

**规则**：
1. 找到所有同时包含蓝(1)和青(8)像素的行，按行号升序排列。
2. 对每行，取蓝像素与青像素之间（不含端点）的像素段。段中左起第一个非背景像素的颜色记为调色板的一个条目。按行号升序，依次得到有序调色板 P[0], P[1], ..., P[k-1]。
3. 在输出中移除所有蓝(1)和青(8)标记像素（设为背景），移除垂直灰(5)分隔线（设为背景）。保留括号间提取出的彩色像素不变。
4. 对右半区的每条灰(5)对角带，计算每个像素的层深度：层 0 为带最外层边界像素，层 1 为下一内层，层深度等于该像素沿垂直于带轴方向到最近带边缘的距离。平坦顶帽的所有像素均属于层 0。
5. 将每个灰(5)带像素重涂为 P[层深度 mod k]。
6. 若带与分隔线的原位置重叠，带的重涂色优先。

**关键洞察**：调色板并非显式排列的一行颜色，而是隐藏在括号标记界定的提取结构中；求解者必须先识别提取模式、重建调色板序列，才能解读对角带的填充规则。

## 新题 6：标记扩展横带内的射线定向擦除

**组合逻辑**：[扩展 + 边框绘制](已有：单像素标记扩展为全宽横带框) + [射线延伸](已有：从标记发射射线) + [擦除](创新：擦除范围被横带边界限定——射线命中的目标对象仅在属于同一横带时才被擦除)

**来源原语**：扩展·边框绘制·单像素标记·横带·按行排序·中点划分归属 来自 0f63c0b9；射线延伸·标记条·控制像素·目标对象·射线命中·命中即整体擦除 来自 2f767503；擦除 来自 2f767503

将彩色标记扩展为全宽横带框，在每个横带内从标记发射射线，仅擦除同一横带内被射线命中的目标对象。

**输入结构**：
- 网格约 20x15，背景黑(0)。
- 3-4 个单像素彩色标记，颜色各不相同（红(2)、蓝(1)、绿(3)、橙(7)），每个位于不同行，列位置各异。
- 每个标记有一个相邻（上、下、左或右）的品红(6)控制像素，指示射线方向（从标记向远离品红像素的方向发射）。
- 6-10 个小型 4-连通灰(5)目标对象，每个 2-4 像素，分散在网格各处。
- 生成约束：计算横带后，每个横带内至少有 2 个目标对象；每个横带内至少有 1 个目标被其标记的射线命中，至少有 1 个目标不在射线路径上。存在至少一个目标对象被某标记的射线命中、但该目标的所有像素均位于另一个标记的横带内（用于测试跨带不擦除规则）。

**规则**：
1. 将所有彩色标记按行号升序排列。相邻标记之间的行号中点（向下取整）作为横带分界线。最上方横带从行 0 开始，最下方横带到最后一行结束。
2. 绘制横带边框：对每个横带，用该带标记的颜色绘制其上、下边界行（全宽），以及左边界列（列 0）和右边界列（最后一列）在横带范围内的部分。标记所在行整行涂为标记颜色。（与参考题 0f63c0b9 相同。）
3. 对每个标记，确定射线方向：从标记位置向远离其相邻品红(6)控制像素的方向。
4. 沿射线方向从标记出发延伸射线至网格边缘。
5. 找出所有满足以下两个条件的灰(5)目标对象：(a) 至少一个像素被射线穿过；(b) 该对象的所有像素（整个 4-连通分量）均位于发射该射线的标记所属横带的行范围内（含边界行）。
6. 对满足条件的目标对象执行整体擦除：将其所有像素设为背景色。
7. 被射线穿过但整体位于其他横带的目标对象不擦除。
8. 位于同一横带但未被射线穿过的目标对象不擦除。
9. 移除所有品红(6)控制像素（设为背景色）。

**关键洞察**：射线本身和横带本身都不能独立决定擦除范围——射线提供方向过滤，横带提供归属过滤，只有同时满足"被射线命中"且"属于射线源的横带"的目标才被擦除；这种双重作用域约束使得跨带穿行的射线成为"只对本带有效"的局部武器。

## 新题 7：滑动轨迹区内形状匹配重涂色

**组合逻辑**：[滑动](已有：边缘矩形滑至对侧) + [重涂色](创新：重涂条件不再是框内参考色匹配，而是双重条件——形状匹配且位于轨迹扫过区域内) + [形状匹配](创新：匹配对象从框内精灵体改为自由精灵体与边缘矩形之间的尺寸比对)

**来源原语**：滑动·边缘矩形·轨迹条纹·接触边缘·滑至对侧边缘 来自 b25e450b；重涂色·精灵体·形状匹配·框内参考色传同形 来自 776ffc46

**依赖链**：边缘矩形滑至对侧产生轨迹条纹 → 轨迹条纹定义"扫过区域" → 自由精灵体与矩形进行边界框尺寸匹配 → 仅当精灵体的边界框尺寸与某矩形相同且精灵体位于该矩形的扫过区域内时，才重涂为该矩形颜色。形状匹配确定颜色来源，空间包含确定是否生效，两个条件缺一不可。

边缘矩形滑至对侧留下轨迹；自由精灵体仅在与某矩形尺寸匹配且位于其轨迹区域内时，才被重涂为该矩形的颜色。

**输入结构**：
- 网格约 18x18，背景黑(0)。
- 2-3 个彩色实心矩形（颜色各不相同：红(2)、蓝(1)、绿(3)），每个触及恰好一条外边界（上、下、左或右），尺寸各不相同（如 2x4、3x2、1x5）。不触及角部。
- 4-6 个自由精灵体，均为灰(5)，每个是 4-连通的不规则小形状（4-8 像素）。部分精灵体的边界框尺寸（宽x高）与某个矩形的尺寸（宽x高）相同，部分不同。
- 部分尺寸匹配的精灵体位于对应矩形的滑动扫过列/行范围内，部分不在。
- 生成约束：至少存在 1 个精灵体同时满足两个条件（尺寸匹配且在扫过区域内），至少 1 个仅满足一个条件，至少 1 个两个条件都不满足。

**规则**：
1. 识别每个触及外边界的彩色矩形。
2. 确定每个矩形的滑动方向：垂直于其触及的边界，朝向对侧边界。
3. 定义矩形的"扫过区域"：矩形从原始位置滑到对侧边界过程中经过的所有列（垂直滑动时）或所有行（水平滑动时）的范围。
4. 将矩形滑至对侧边界，矩形自身以原色绘制在对侧。扫过区域中除矩形最终位置外的所有背景像素涂为橙(7)。
5. 对每个灰(5)精灵体，检查两个条件：
   - (a) 精灵体的边界框尺寸（宽, 高）与恰好一个矩形的尺寸（宽, 高）相同（允许宽高互换：即 2x4 匹配 4x2）。
   - (b) 精灵体的边界框完全包含在该匹配矩形的扫过区域（列范围或行范围）内。
6. 若两个条件均满足，将该精灵体从灰(5)重涂为匹配矩形的颜色。
7. 不满足任一条件的精灵体保持灰(5)不变。
8. 橙(7)轨迹像素与被重涂精灵体像素重叠时，精灵体颜色优先覆盖橙色。

**关键洞察**：形状匹配建立了精灵体与矩形之间的对应关系，但对应关系本身不足以触发重涂——精灵体还必须"站在"矩形滑过的路径上；这种几何相似性加空间包含的双重门槛防止了仅凭单一条件即可预测输出。

## 新题 8：标记频率决定平行四边形连接网络配色

**组合逻辑**：[线段绘制/平行四边形](已有：两标记间绘制平行四边形轮廓) + [计数](已有：统计同色标记频率) + [连线](创新：多于 2 个同色标记时按行主序形成链式连接，而非仅一对) — 标记频率同时决定连接拓扑（链的段数）和轮廓绘制颜色

**依赖链**：统计每种颜色的标记数量 → 数量决定平行四边形轮廓的绘制颜色（查图例） → 按行主序排列同色标记并两两成对 → 每对之间将偏移向量分解为 45 度对角分量和轴向分量，绘制平行四边形轮廓。标记数量既是颜色查表键又是拓扑生成参数，删除计数步骤则无法确定绘制颜色，也无法确定链的连接方式。

**输入结构**：
- 网格约 20x20，背景黑(0)。
- 8-12 个标记像素，分为 3-4 种颜色（红(2)、蓝(1)、橙(7)、栗(9)），每种颜色出现 2-4 次。
- 每对同色标记之间的偏移向量行分量和列分量不等（绝对值不同），保证平行四边形非退化。
- 网格最后一行为图例行：列 0 的像素颜色表示"该色标记出现 2 次时的轮廓绘制色"，列 1 表示 3 次，列 2 表示 4 次。图例使用非背景、非标记的颜色（如黄(4)、品红(6)、灰(5)）。
- 同色标记之间间距至少 4 像素，以减少轮廓重叠。

**规则**：
1. 统计每种标记颜色的出现次数 n。在图例行中查找列 n-2 的颜色作为该组标记的轮廓绘制色 C。
2. 对每种标记颜色，将其所有标记按行主序（行号升序，同行列号升序）排列。
3. 对排列中每对相邻标记（第 i 个与第 i+1 个），计算偏移向量 (dr, dc)。
4. 将偏移向量分解为 45 度对角分量和剩余轴向分量：对角分量大小为 min(|dr|, |dc|)，方向为 (sign(dr), sign(dc))；轴向分量为剩余的纯行或纯列偏移。
5. 以两个标记为对顶点，对角分量和轴向分量为相邻边，绘制平行四边形的四条边。四条边均使用颜色 C。边的绘制沿 Bresenham 离散线段。
6. 保留原始标记像素不变（不被轮廓颜色覆盖）。
7. 若两个不同颜色组的平行四边形轮廓在同一像素重叠，标记数量多的颜色组优先；若数量相同，图例行中列号更大的颜色组优先。
8. 移除图例行（输出网格行数减 1）。

**关键洞察**：标记数量并非仅是统计指标——它同时决定了绘制颜色（通过图例查表）和平行四边形链的段数（n 个标记产生 n-1 段平行四边形），使得同一个计数值在颜色空间和拓扑空间中各有一次使用，两次使用的结果在输出中同时可见。

## 新题 9：对称轨道与切比雪夫环联合筛选印章

- 每个种子像素的 D4 轨道（以网格中心为对称中心，包括关于两条轴和两条对角线的反射及 90/180/270 度旋转，去重后最多 8 个位置）中的所有位置均落在背景象限内（不在十字上）。
- 生成约束：不同种子不共享同一轨道。每个种子至少有一个轨道伙伴落在偶数切比雪夫距离处，且至少有一个落在奇数距离处。

**规则**：
1. 定位十字交叉点 C（网格中心）。
2. 对每个背景像素（不在十字上的像素），计算其到 C 的切比雪夫距离 d = max(|row - C_row|, |col - C_col|)。
3. 识别所有种子像素（非黑、非蓝、不在十字上的像素）。
4. 对每个种子像素，设其位置为 P、颜色为 c：
   - 计算 P 相对于网格中心的 D4 轨道伙伴集合（最多 8 个位置，含 P 自身，去重后可能少于 8 个）。
   - 对每个轨道伙伴位置 Q（Q 不等于 P，Q 在背景象限内，Q 当前为背景色）：
     - 若 Q 的切比雪夫距离为偶数，在 Q 放置颜色 c 的印章。
     - 若 Q 的切比雪夫距离为奇数，不放置印章（Q 保持背景色）。
5. 种子像素本身保持不变，无论其切比雪夫距离的奇偶性。
6. 十字像素永不修改。
7. 若两个不同种子的轨道在同一位置放置不同颜色的印章（生成约束保证不会发生此情况），取距网格中心更近的种子颜色。

**关键洞察**：单独的距离环结构会在每个象限产生均匀的棋盘格涂色，单独的对称轨道会在所有距离上复制种子——只有两者交叉才能解释为何某些轨道位置有印章而其对称伙伴没有：偶数环充当空间"通行证"，对称轨道充当颜色"发放者"。

**来源原语**：平移·多色精灵体·嵌入标记像素·孤立控制点·颜色配对·锚点对齐目标 来自 54dc2872；射线延伸·实心矩形·延伸条纹·控制像素·侧边带对齐·标记排除对应行列 来自 9def23fe

**依赖链**：识别多色精灵体和嵌入标记 → 颜色配对找到目标控制点 → 平移精灵体至控制点（L 形弯折点对齐控制点）→ 平移后精灵体占据的行/列成为矩形条纹扩展的排除位置 → 矩形仅向未被精灵体占据的行/列延伸条纹。平移结果直接改变了条纹扩展的可用空间，两步操作共享同一输出画布且相互制约。

将标记精灵体平移至颜色配对的控制点后，其落点行列阻止中央矩形向这些行列延伸条纹。

**输入结构**：
- 网格约 18x18，背景黑(0)。
- 一个中央蓝(1)实心矩形，约 4x4 至 5x5，位于网格中心附近。
- 2-4 个多色精灵体，每个是一个 L 形 4-连通体（3-5 像素），主体为同一颜色（如灰(5)或栗(9)），其中一个像素为不同的嵌入标记色（红(2)、绿(3)、橙(7)或黄(4)）。
- 对每个精灵体的嵌入标记颜色，在矩形的侧边带区域（矩形上方/下方/左方/右方，与矩形行或列对齐的区域）中存在恰好一个同色的孤立控制点像素。
- 精灵体初始位置在网格角落或边缘附近，远离矩形。
- 生成约束：平移后每个精灵体的边界框与矩形的某些行或列重合（即精灵体的某些像素与矩形行范围或列范围有交集），从而能产生排除效果。每个侧边带方向至少有 1 行/列不被排除（保证条纹扩展不完全为空）。

**规则**：
1. 识别中央蓝(1)实心矩形。
2. 识别多色精灵体：每个精灵体有一个连通的单色主体加一个不同色的嵌入标记像素。
3. 对每个精灵体，找到嵌入标记颜色对应的孤立控制点。将精灵体平移，使其 L 形弯折点（主体中拥有两个主体色邻居的像素）对齐到控制点位置。清除精灵体原始位置的像素和被消耗的控制点。
4. 没有匹配控制点的精灵体保持原位。
5. 完成所有平移后，确定矩形的四个侧边带区域：上方（矩形上方所有行、矩形列范围内）、下方、左方（矩形左方所有列、矩形行范围内）、右方。
6. 对每个侧边带区域，检查哪些矩形行（左/右侧边带）或矩形列（上/下侧边带）被"排除"：若平移后某个精灵体的任何像素占据了该行（对于左/右侧边带）或该列（对于上/下侧边带）在该侧边带区域范围内的位置，则该行/列被排除。
7. 对未被排除的行/列，从矩形边缘向网格边缘方向延伸蓝(1)条纹（填满该行/列在侧边带区域内的所有背景像素）。
8. 平移后的精灵体像素覆盖条纹像素（精灵体优先）。

**关键洞察**：精灵体的平移并非单纯的搬运操作——它将精灵体战略性地安置在影响矩形条纹扩展的位置上，使平移结果和条纹图案在逻辑上不可分离：不完成所有平移就无法确定最终的条纹布局。
