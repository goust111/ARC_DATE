## 新题 1：分散多米诺编码的链式重涂色

**组合逻辑**：[四邻接配对(已有)] → [双色多米诺→分布式图例(创新：多米诺不再仅触发擦除，而是充当空间分布的替换图例条目)] → [逐行顺序链式替换(已有，但图例来源从连续块变为空间散布的多米诺)] → [擦除(已有)]

**来源原语**：四邻接配对、双色多米诺、配对则变色擦除（参考题 d90796e8）；双列图例、图例行序决定替换、逐行顺序链式替换（参考题 e4888269）；擦除（参考题 d90796e8/12422b43）

**依赖链**：多米诺的四邻接配对识别出图例条目 → 每个多米诺的内部朝向（行主序先后）决定 from/to 方向 → 多米诺之间的纵向位置排序决定链式替换的执行次序 → 替换作用于大型前景对象的每个像素 → 多米诺本身被擦除。删除任何一环都无法求解：不识别多米诺则无图例；不确定朝向则不知哪个颜色映射到哪个；不排序则链式结果不确定（链式替换不满足交换律）；不擦除则输出包含多余图例碎片。

将散布在网格中的双色多米诺解读为替换图例条目，按纵向位置排列后对大型前景对象执行链式颜色替换，最后擦除所有多米诺。

**输入结构**：约 14x14 网格，黑(0)背景。网格中散布 3-5 个互不相邻的 4-连通双色多米诺（每个多米诺恰好 2 个像素、两种不同非黑颜色）。此外存在 1-2 个较大的（5 像素以上）4-连通单色或多色前景对象，颜色均取自多米诺中出现的颜色。不同多米诺的颜色对互不重复。可能存在少量与多米诺颜色无关的孤立前景像素（干扰项），这些像素不构成任何多米诺配对。生成约束：每个多米诺的两个像素在行主序（先比较行号、再比较列号）下有唯一先后关系；所有多米诺的最上方像素所在行互不相同。

**规则**：
1. 找出所有 4-连通的恰好两像素、双色的前景连通分量——这些是多米诺。其余前景像素（包括大型对象和孤立干扰项）不属于任何多米诺。
2. 对每个多米诺，按行主序（先行后列）确定两个像素的先后：先出现的像素颜色为"源色"，后出现的像素颜色为"目标色"，构成一条替换规则"源色→目标色"。
3. 将所有多米诺按其最上方像素所在行从上到下排序，得到替换规则的有序链 R1, R2, ..., Rk。
4. 对网格中每个非多米诺的前景像素，依次应用 R1 到 Rk：若当前像素颜色等于 Ri 的源色，则将其改为 Ri 的目标色，然后继续检查 Ri+1 到 Rk（即同一像素可被多次替换）。
5. 将所有多米诺像素设为黑(0)背景。
6. 干扰项像素（不属于任何多米诺的孤立前景像素）若其颜色在链式替换中被命中则同样被替换，否则保持不变。

**关键洞察**：多米诺不是要被合并或擦除的配对体，而是一种空间分布式的替换指令集；多米诺在网格中的上下位置编码了指令的执行顺序，而链式替换的非交换性使得这一顺序不可忽略。

## 新题 2：宽度门控的重力落种与容器填充

**组合逻辑**：[重力下落(已有)] + [宽度决定行为(创新：不再决定"穿透 vs 停靠于分隔行"，而是决定"能否通过杯口进入容器")] → [填充(已有，但填充颜色不再固定，而是由捕获的种子决定)] + [擦除(已有)]

**来源原语**：重力下落、精灵、分隔行、穿透与停靠、宽度决定行为（参考题 84ba50d3）；杯形容器、封闭区域、填充、内部包含、开口朝向（参考题 aba27056）；种子像素（参考题 8403a5d5）；擦除（参考题 d90796e8）

**依赖链**：杯口宽度筛选哪些种子能进入 → 重力确定种子的下落路径（列对齐） → 种子-容器匹配后种子颜色决定填充色 → 填充作用于杯形封闭区域。删除宽度门控：所有种子都能进入任何杯→错误匹配；删除重力：不知道种子到达哪个杯→无匹配；删除填充：知道匹配但无输出变换。

不同宽度的水平色条在重力下下落，只有宽度不超过杯口的色条能通过杯口进入杯内，捕获后以色条颜色填充杯的封闭区域。

**输入结构**：约 15x15 网格，黑(0)背景。底部区域有 2-3 个灰(5)色杯形容器，每个杯开口朝上、开口宽度各不相同（2-5 像素宽）。杯壁为灰(5)，杯内为黑(0)。顶部区域散布若干水平色条（每条由同色像素组成的 4-连通水平线段，宽度 1-4 像素），颜色各不相同且非灰非黑。每条色条占据一行中连续的若干列。色条之间不在同一行。生成约束：每个杯口正上方的列范围内最多只有一条能通过宽度门控的色条（避免歧义）；至少有一条色条因宽度超出所有杯口而无法进入任何杯。

**规则**：
1. 识别所有灰(5)杯形容器及其开口。开口定义为杯形包围框顶行中连续的非灰像素段，宽度为该段的像素数。
2. 识别顶部所有水平色条，记录每条色条的宽度和所占列范围。
3. 每条色条沿重力方向（向下）逐行移动。色条能通过一个杯的开口当且仅当：色条宽度 <= 杯口宽度，且色条的水平列范围完全包含在杯口的列范围内。
4. 色条在下落路径上遇到的第一个满足宽度门控条件的杯即为其目标杯。色条被该杯捕获。
5. 用捕获色条的颜色填充目标杯的全部封闭内部像素（原来的黑(0)像素改为色条颜色）。
6. 未被任何杯捕获的色条（宽度超出所有正下方杯口、或正下方无杯）从网格中擦除。
7. 杯壁（灰(5)）保持不变。未捕获任何色条的杯保持内部为黑(0)。
8. 被捕获的色条本身也从原位置擦除（不在原位保留）。

**关键洞察**：杯口宽度不仅是几何特征，更是一种物理筛选器——它将种子按尺寸分流到不同容器中，使得"什么颜色填什么杯"不由颜色匹配决定，而由几何兼容性决定。

## 新题 3：对称掩码提取为周期平铺模板

**组合逻辑**：[裁剪+镜像检测→对称图案选取(已有)] → [异常值选择(创新：非对称掩码不再被丢弃，其包围框成为待填充区域)] → [平铺(创新：对称裁剪体不再是最终输出，而是成为周期平铺的瓦片模板)]

**来源原语**：裁剪、镜像、对称、颜色掩码、包围框、对称图案选取、异常值选择（参考题 d56f2372）；平铺、周期间隔（参考题 8403a5d5）；循环重复（参考题 12422b43）

**依赖链**：对称检测选出唯一模板 → 非对称掩码的包围框定义填充区域 → 对称模板被周期平铺到这些区域中。删除对称检测：不知道哪个掩码是模板→无法确定瓦片内容；删除非对称掩码的包围框定位：有模板但不知道铺在哪里；删除平铺：知道模板和区域但无变换输出。

从多种颜色掩码中选出唯一具有左右对称性的掩码裁剪体作为瓦片，擦除其余非对称掩码并在其原包围框范围内周期铺设该瓦片。

**输入结构**：约 18x18 网格，黑(0)背景。3-4 种非黑颜色各自形成一组像素（颜色掩码），每组可能由多个 4-连通部分组成。各颜色掩码的包围框互不重叠。恰好有一种颜色的掩码裁剪到包围框后呈左右镜像对称，其余颜色的掩码裁剪后均不对称。对称掩码的裁剪体尺寸不超过 5x5。非对称掩码的包围框尺寸至少为对称裁剪体尺寸的 2 倍（在行方向和列方向上均如此），保证能容纳至少 2x2 个瓦片。生成约束：对称掩码中非背景像素构成一个视觉上明确的对称图案（不同示例的具体形状不同），各掩码颜色互不相同。

**规则**：
1. 对每种非黑颜色，将该颜色的全部像素裁剪到其最小包围框，得到候选裁剪体（框内其他颜色位置视为黑(0)）。
2. 选出唯一满足"裁剪体等于其左右翻转"的候选，该裁剪体即为瓦片模板 T（尺寸 h x w）。
3. 记录所有非对称掩码的包围框（每个框为一个矩形区域）。
4. 擦除所有非对称掩码的像素（设为黑(0)）。
5. 在每个记录的包围框内，从包围框左上角开始，以周期 (h, w) 在行方向和列方向重复铺设瓦片 T。超出包围框边界的部分裁去。瓦片中非黑像素保留瓦片原色（即对称掩码自身的颜色），黑(0)像素位置保持黑(0)。
6. 对称掩码本身保留在原位不变。

**关键洞察**：对称性不是用来选出"答案"（与参考题 d56f2372 不同），而是用来选出"工具"——对称掩码变成了一把模具，而被它淘汰的非对称掩码反而用自身的空间位置定义了模具的使用范围。

## 新题 4：连通分量面积仲裁的面板叠加

**组合逻辑**：[透明叠加(已有，但冲突解决机制从"非空即写"变为"面积权重仲裁")] + [计数+面积分级(创新：不再直接映射颜色，而是为叠加冲突提供优先级)]

**来源原语**：透明叠加、面板、分隔线、同尺寸面板、非空标记合并（参考题 7c9b52a0）；计数、连通分量、面积分级（参考题 08ed6ac7/e8593010）；面积决定颜色（参考题 e8593010，创新为"面积决定优先级"）

**依赖链**：面板解析提供待叠加的多层数据 → 同一位置存在多面板标记时触发冲突 → 各标记所属连通分量的面积计数决定仲裁结果。删除面板解析：无叠加对象；删除面积计数：冲突无法解决（不知道谁优先）；删除叠加：面积计数无用武之地。三者形成决策图而非流水线——面积计数只在冲突时才被触发，非冲突位置直接通过。

将多个同尺寸面板叠加为一个输出面板，在多面板标记冲突处以标记所属连通分量的面积为权重仲裁优先级。

**输入结构**：约 16x16 网格。一种唯一的分隔色（橙(7)）将网格分为 3 个同形状的矩形面板（水平或垂直排列，不同示例可不同）。每个面板内部以黑(0)为空白色，含若干彩色标记像素。标记像素在面板内形成若干 4-连通分量，各分量面积（像素数）各不相同。不同面板的标记颜色互不相同（如面板 1 用蓝(1)，面板 2 用红(2)，面板 3 用绿(3)）。生成约束：至少存在 2 个相对位置在多个面板中同时有非空白标记的冲突位置；在每个冲突位置上，竞争的各标记所属分量的面积互不相等（无需 tie-break）。

**规则**：
1. 识别橙(7)分隔色并将网格拆分为 3 个同形状面板，去除分隔色边框。
2. 创建一个与面板同形状的输出网格，初始全为黑(0)。
3. 对输出网格中的每个位置 (r, c)：
   - 收集所有面板在对应相对位置 (r, c) 处的标记像素。
   - 若恰好一个面板有非空白标记，输出该标记颜色。
   - 若无面板有非空白标记，输出黑(0)。
   - 若多个面板均有非空白标记（冲突），则对每个竞争标记找出它在其所属面板内的 4-连通分量，比较面积（像素总数）。面积最大的分量所对应的标记颜色胜出，写入输出。
4. 输出该合并后的单面板。

**关键洞察**：标准面板叠加中每个标记像素平权，而这里标记的"发言权"取决于它所属连通分量的规模——大分量的标记在冲突中压过小分量的标记，使得叠加结果依赖于面板内部的拓扑结构而非仅仅依赖位置。

## 新题 5：点对称复制与嵌套层色序反转

**组合逻辑**：[点对称补全(已有)] + [层序反转(创新：不在原对象上就地反转，而是在点对称复制品上反转，使复制品成为原件的"色彩倒影")]

**来源原语**：点对称补全、中心标记、分隔列、前景图案、绕中心点旋转对称（参考题 e729b7be）；层序反转、嵌套矩形层、实心矩形、嵌套层次、颜色序列逆转（参考题 8dae5dfc）；重涂色（参考题 8dae5dfc）

**依赖链**：点对称确定复制品的几何位置 → 嵌套层剥离确定原件的颜色深度序列 → 反转色序应用于复制品的对应层。删除点对称：不知道复制品位置→无几何输出；删除层剥离：不知道颜色序列→复制品颜色无法确定（简单克隆会得到与原件相同的颜色，但正确答案是反转的）；删除色序反转：复制品退化为普通点对称克隆（与参考题 e729b7be 重复）。三者的耦合在于：几何由点对称决定，颜色由层剥离+反转决定，二者同时作用于每个复制像素。

将分隔线一侧的嵌套矩形结构点对称复制到另一侧，但复制品的颜色层级从外到内反转——原件最外层的颜色变为复制品最内层的颜色，反之亦然。

**输入结构**：奇数尺寸网格（约 13x13），黑(0)背景。中心行的最左格、正中格、最右格为栗(9)色中心标记。黄(4)色填充中心列（除正中格外）构成分隔列。左半区有一个嵌套矩形结构，由 2-4 层不同颜色的矩形层构成（如最外层蓝(1)、中层红(2)、最内层绿(3)），每层通过逐步剥离当前均匀边界获得。右半区为空（全黑(0)背景）。生成约束：嵌套矩形不触及分隔列；层数至少 2 层；各层颜色互不相同且不含黑(0)、黄(4)、栗(9)。

**规则**：
1. 识别中心标记（栗(9)色，位于网格正中心）。
2. 识别左半区的嵌套矩形结构。从最外层开始逐步剥离当前均匀边界，记录颜色序列 C = [c1, c2, ..., cn]（c1 为最外层）。
3. 反转颜色序列得到 C' = [cn, ..., c2, c1]。
4. 对嵌套矩形的每个像素 (r, c)，计算其层深度 d（1 为最外层）。该像素的原色为 C[d]。
5. 将像素 (r, c) 绕中心标记旋转 180 度得到镜像位置 (r', c')。在 (r', c') 处绘制 C'[d] = C[n+1-d] 的颜色。
6. 保留原件、分隔列和中心标记不变。

**关键洞察**：复制品不是原件的简单几何克隆——它在形状上是点对称的，但在颜色上是"深度反转"的。求解者必须同时理解"去哪里"（点对称）和"涂什么色"（层序反转），这两个维度缺一不可。

## 新题 6：周期母题遇轴镜像并变色延续

**组合逻辑**：[平铺/周期填充(已有)] + [跨轴反射(创新：不作用于已有对象，而是作用于正在生成的周期序列，在轴处翻转生成方向)] + [标记色指定涂色(已有，但从"反射后读取标记"变为"轴另一侧的标记预先指定变色")]

**来源原语**：平铺、周期间隔、种子像素（参考题 8403a5d5）；跨轴反射、轴线段、标记色指定涂色（参考题 88207623）；周期步长（参考题 16de56c4）

**依赖链**：两个同色母题副本的间距确定周期 P → 轴线段的列位置确定镜像触发点 → 轴另一侧的标记像素指定变色 → 过轴后母题副本以周期 P 继续生成，但每个副本左右翻转且颜色替换为标记色。删除周期推断：不知道继续生成的间距；删除轴：不知道在哪里触发翻转和变色；删除标记色：翻转后颜色不确定。

在轴线段一侧，由两个同色母题副本定义的周期性图案延续到轴的另一侧，但过轴后每个副本被左右翻转并重涂为轴另一侧标记像素的颜色。

**输入结构**：约 15x20 网格（列数大于行数），黑(0)背景。左侧区域存在同一颜色（如蓝(1)）的两个完全相同的小型图案副本（3-5 像素的 4-连通图形），位于同一行范围内，水平间距为 P 列（P >= 3，以两副本左边缘的列差度量）。网格中部有一段红(2)色竖直线段（至少 3 像素高），作为轴线段。轴的右侧某处有一个独立的标记像素，颜色为非黑非红且与母题颜色不同（如绿(3)）。生成约束：两个母题副本的包围框不重叠且不触及轴线段；轴右侧有足够空间容纳至少 2 个周期的翻转副本；标记像素位于轴右侧且不在任何翻转副本的预期位置上。

**规则**：
1. 识别左侧的两个相同图案副本。将其裁剪到包围框得到母题模板 M（尺寸 h x w）。
2. 计算周期 P = 两个副本左边缘的列距离。
3. 识别红(2)轴线段所在的列 A。
4. 识别轴右侧的标记像素颜色 Cm。
5. 从轴线段右侧第一列起，以周期 P 放置母题副本。每个副本的行范围与原始副本相同。
6. 每个过轴副本执行左右翻转（列顺序反转）。
7. 每个过轴副本的颜色由原始母题颜色替换为 Cm。
8. 保留原始两个副本、轴线段和标记像素不变。过轴副本超出网格右边界的部分裁去。

**关键洞察**：轴线段身兼三职——它标记周期生成的起始边界、触发几何翻转、并分隔原色区与新色区。求解者需要从两个左侧副本推断出周期，再从轴和标记推断出翻转与变色规则，这三个信息源分布在网格的不同位置。

## 新题 7：包围框包含关系重定义循环重涂色

**组合逻辑**：[计数→连通分量排序(已有)] + [循环填充(创新：循环赋色不在空间区域上执行，而是在按序排列的连通分量上执行)] + [内部包含(创新：包围框包含关系打断循环计数，被包含分量继承包含者的颜色)]

**来源原语**：连通分量、计数、排序（参考题 08ed6ac7）；循环填充、循环重复、标记界定母题、母题行（参考题 12422b43）；包围框、内部包含（参考题 aba27056/d56f2372）；重涂色（参考题 e8593010）

**依赖链**：标记行定义循环色彩母题 → 连通分量识别并按行主序排序确定赋色顺序 → 包围框包含检测将某些分量标记为"被包含" → 被包含分量跳过循环计数器并继承包含者颜色。删除母题定义：不知道循环的颜色序列；删除分量排序：不知道赋色顺序；删除包含检测：所有分量平等参与循环→结果不同。三者形成条件分支结构：排序和循环是主路径，包含检测是分支条件。

灰色标记行定义循环颜色序列，连通分量按行主序排列后依次循环赋色，但被其他分量包围框完全包含的分量继承包含者的颜色而非推进循环计数器。

**输入结构**：约 14x14 网格，黑(0)背景。第 0 行（最顶行）为灰(5)背景，其中嵌入 2-4 个彩色像素（颜色互不相同，如红(2)、蓝(1)、绿(3)），按列从左到右排列，构成循环母题 M。第 1 行起的区域包含若干（5-8 个）橙(7)色 4-连通前景分量，形状各异（3-8 像素），互相之间 4-不连通。其中 1-2 个较小分量的包围框完全位于某个较大分量的包围框内部（但像素不重叠，因为所有分量 4-不连通）。生成约束：每个分量的行主序位置（最上方像素的行号，同行则取最左列号）唯一；包含关系无嵌套（不存在 A 包含 B、B 又包含 C 的情况）；被包含分量的包围框与包含者的包围框之间至少有 1 像素间隙。

**规则**：
1. 读取第 0 行中嵌入的彩色像素，按列从左到右排列得到循环母题 M = [m1, m2, ..., mk]。
2. 找出第 1 行及以下的全部橙(7) 4-连通前景分量。
3. 对每个分量计算包围框。检查包含关系：若分量 A 的包围框完全包含分量 B 的包围框，则 B 被标记为"被包含"，A 为 B 的包含者。
4. 将所有分量按行主序（最上方像素所在行，同行取最左列）排序。
5. 初始化循环计数器 i = 0。按排序顺序遍历每个分量：
   - 若该分量未被包含：将其所有像素重涂为 M[i mod k]，然后 i += 1。
   - 若该分量被包含：将其所有像素重涂为其包含者已被赋予的颜色（不推进 i）。
6. 第 0 行（含灰背景和母题像素）保持不变。

**关键洞察**：包围框包含关系创造了一种"继承"机制，打破了循环赋色的均匀推进——被包含分量像是包含者的"卫星"，从属于包含者的颜色身份而非独立参与循环。求解者必须先检测包含关系才能正确推进循环计数器。

## 新题 8：边界点射线分割与标记块壁纸铺色

**组合逻辑**：[射线延伸(已有)] + [标记块+对角映射(创新：2x2 标记块不再映射到固定的外围矩形，而是作为壁纸单元格通过模运算铺满射线分割出的网格)] + [填充(已有)]

**来源原语**：射线延伸/射线延伸(ray_cast)、边界点、周期步长（参考题 16de56c4）；标记块、象限区域、对角映射（参考题 93b581b8）；填充（参考题 93b581b8/aba27056）

**依赖链**：边界点发射垂直于所在边的射线 → 射线将网格内部分割为矩形区域 → 2x2 标记块定义 4 种颜色 → 每个矩形区域的颜色由其在分割网格中的（行序号 mod 2, 列序号 mod 2）映射到标记块对应位置的颜色决定。删除射线：无分割→无区域可填；删除标记块：有分割但颜色映射不确定；删除 mod 映射：有分割和颜色但不知道对应规则。射线提供拓扑结构，标记块提供颜色语义，模运算将二者粘合。

边界点向网格内部发射射线形成水平和竖直分割线，将网格划分为矩形区域；一个 2x2 标记块充当壁纸单元格，通过模 2 映射为每个区域着色。

**输入结构**：约 15x15 网格，黑(0)背景。网格的四条边上分布 3-5 个灰(5)色边界点，每条边 0-2 个，均位于非角落位置。网格内部偏中心处有一个 2x2 标记块，四格颜色各不相同（如左上蓝(1)、右上红(2)、左下绿(3)、右下黄(4)），且不含灰(5)和黑(0)。标记块不与任何射线路径重叠。生成约束：顶边或底边上的边界点发射竖直射线，左边或右边上的边界点发射水平射线；所有射线互相垂直交叉，将网格内部（排除边界行列本身）分割成至少 2x2 = 4 个矩形区域；标记块完全位于某个矩形区域内部且不跨区域边界。

**规则**：
1. 识别网格边上的所有灰(5)边界点。
2. 每个顶边或底边上的边界点沿其所在列发射一条竖直射线，穿过整个网格内部（从第 1 行到第 H-2 行，H 为网格高度）。每个左边或右边上的边界点沿其所在行发射一条水平射线，穿过整个网格内部（从第 1 列到第 W-2 列，W 为网格宽度）。射线像素着灰(5)色。
3. 射线与网格边界共同将网格内部分割为 R 行 x C 列的矩形区域网格。对区域按从上到下、从左到右编号为 (i, j)，其中 i 为区域行号（0 起），j 为区域列号（0 起）。
4. 识别 2x2 标记块，记录其四格颜色：TL（左上）、TR（右上）、BL（左下）、BR（右下）。
5. 对每个区域 (i, j)，计算 (i mod 2, j mod 2)，映射到标记块对应位置的颜色：(0,0)→TL，(0,1)→TR，(1,0)→BL，(1,1)→BR。
6. 用映射颜色填充该区域的所有黑(0)像素（射线像素和标记块像素保持不变）。
7. 边界点本身被擦除（设为黑(0)），但其射线保留。

**关键洞察**：边界点看似只是被动的标记，实际上它们的位置拓扑地决定了"房间"的划分；而 2x2 标记块看似只是局部装饰，实际上它是一个无限重复的壁纸单元格——网格中每个"房间"的颜色都是这个 2x2 图案在二维模运算下的投影。
