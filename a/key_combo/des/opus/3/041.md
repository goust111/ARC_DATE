## 新题 1：空洞数排名涂色

**组合逻辑**：[计数/counting](创新：统计每个分量的封闭空洞数，而非简单的有/无二值判断) + [排序/sorting](创新：排序依据从长度改为拓扑属性——空洞数) + [重涂色/recolor](已有) ← 条件门控：[有空洞则重涂/recolor_if_hole](创新：从二值门控扩展为多级排名门控)

**来源原语**：计数(a934301b, e872b94a), 排序(ea32f347), 重涂色(810b9b61, ea32f347), 连通分量(810b9b61), 封闭区域(810b9b61), 包含(810b9b61), 排名决定颜色(ea32f347)

**依赖链**：拓扑分析（识别封闭空洞）的结果喂入计数模块，计数结果喂入跨对象排名，排名结果决定涂色映射。零空洞分量被条件门控排除在排名之外。删除计数环节则排名无据；删除排名环节则颜色无法确定；删除门控则零空洞分量错误参与排名。

根据每个前景分量所包含的封闭空洞数量进行跨对象排名，按排名映射颜色，零空洞分量保持原色不参与排名。

**输入结构**：约 15x15 网格，黑(0)背景。网格上散布 4-6 个灰(5)前景 4-连通对象，对象之间互不相邻（任意两个对象的像素之间至少间隔 1 个黑像素）。每个对象是由灰像素组成的单连通区域，像素数在 8-25 之间，形状不规则（非矩形）。部分对象的灰像素围合形成封闭边界，内部包含 1 个或多个 4-连通的黑色封闭区域（空洞）；其余对象不构成封闭边界，没有空洞。不同对象的空洞数量互不相同（生成约束）。所有对象均使用灰(5)色。

**规则**：
1. 识别网格中所有 4-连通的灰(5)连通分量。
2. 对每个分量，计算其完全封闭的黑(0)区域数（空洞数）。封闭的定义：一个 4-连通的黑色区域，其所有像素均不与网格边界相邻，且该区域被该灰分量的像素完全包围（从该黑色区域出发沿 4-连通方向无法到达网格边界或其他分量）。
3. 空洞数为 0 的分量保持灰(5)不变，不参与后续排名。
4. 对空洞数 >= 1 的分量，按空洞数升序排名。若空洞数相同（生成约束保证不会出现），以包围盒左上角坐标为 tiebreak（行小者优先，行相同则列小者优先）。
5. 排名映射颜色：第 1 名 -> 红(2)，第 2 名 -> 蓝(1)，第 3 名 -> 绿(3)，第 4 名 -> 黄(4)。
6. 将对应分量的所有灰像素重涂为映射颜色。黑色背景和空洞内部保持黑(0)不变。

**关键洞察**：排名依据是拓扑属性（封闭空洞数），而非几何属性（面积、长度）；零空洞分量不参与排名的规则需要对比多个示例才能确认（单个示例中可能所有分量都有空洞）。

## 新题 2：标记阈值擦除与标记定轴对称补全

**组合逻辑**：[计数/counting] → 分支判断 →（分支A）[擦除/erase] |（分支B）[对称补全/symmetry_completion](创新：对称轴由存活的标记像素位置定义，而非从对称模式推断) ← [标记超阈值则擦除/erase_above_threshold] + [推断对称轴/infer_symmetry_axes](创新：轴不是推断而是标记直接指定)

**来源原语**：擦除(a934301b), 计数(a934301b), 标记像素(a934301b), 标记包含于对象(a934301b), 标记超阈值则擦除(a934301b), 对称补全(981571dc, af22c60d), 缺失像素(981571dc), 镜像对应(981571dc), 连通分量(810b9b61)

**依赖链**：标记像素同时承担两个角色——其数量决定对象的存亡（阈值门控），其位置决定存活对象的对称轴（几何指导）。擦除操作和对称补全操作通过同一标记信息耦合：如果不先做阈值判断就直接补全，多标记对象的轴会产生歧义；如果只做擦除不做补全，存活对象仍然是残缺的。两个操作共享输入信号但执行不同功能。

对每个前景对象计数其内部标记像素，超阈值者擦除，恰好一个标记者以标记位置为对称轴补全缺失像素，无标记者保持不变。

**输入结构**：约 14x14 网格，黑(0)背景。网格上有 4-5 个蓝(1) 4-连通对象，像素数在 6-20 之间，形状不规则。每个对象存在若干缺失像素（本应为蓝色但显示为黑色的位置，使对象看起来不完整/不对称）。部分对象内部嵌有红(2)标记像素（红像素位于对象包围盒内部，且与蓝像素 8-连通）。不同对象的红标记数量分别为 0、1 或 2 以上（至少各有一个代表）。含 1 个红标记的对象中，红标记像素恰好位于该对象潜在双侧对称轴上（水平轴或垂直轴）。各对象互不相邻。

**规则**：
1. 识别所有 4-连通的蓝(1)连通分量（连通性计算时，仅考虑蓝像素之间的 4-连通关系；红像素不参与连通性，但其位置在后续步骤中使用）。
2. 对每个蓝分量，统计其包围盒内的红(2)像素数量。
3. 红标记数 >= 2 的分量：将该分量所有蓝像素及其包围盒内所有红像素均设为黑(0)（擦除）。
4. 红标记数 = 1 的分量：该红像素标定对称轴的位置。若红像素所在列为 c，检查将蓝像素以列 c 为垂直轴做左右镜像后，是否与现有蓝像素无矛盾（已有蓝像素的镜像位置要么也是蓝像素，要么是黑像素）；若垂直轴一致，则按垂直轴镜像补全所有缺失蓝像素。若垂直轴不一致，则检查红像素所在行 r 作为水平轴是否一致，一致则按水平轴镜像补全。补全后将红像素设为黑(0)。
5. 红标记数 = 0 的分量：保持不变。
6. 黑色背景保持不变。

**关键洞察**：红标记像素具有双重语义——其数量是擦除判据，其位置是对称轴坐标；这两层含义需要对比含不同标记数量的示例才能分别识别出来。

## 新题 3：反射扩展后模板挖孔

**组合逻辑**：[镜像/mirror](已有) + [挖孔/punch_holes](创新：挖孔位置由镜像后的包围盒中心决定，而非原始位置) ← [标记几何定类型/marker_geometry_determines_type](已有) + [同色匹配/same_color_matching](已有)

**来源原语**：镜像(7ed72f31), 反射轴标记(7ed72f31), 标记几何定类型(7ed72f31), 透明叠加(7ed72f31), 精灵体(7ed72f31), 挖孔(58f5dbd5), 模板图案(58f5dbd5), 同色匹配(58f5dbd5)

**依赖链**：镜像操作改变精灵体的几何尺寸和包围盒，挖孔操作的模板定位依赖于镜像后的包围盒中心。若跳过镜像直接挖孔，模板中心对齐的目标形状是错误的（未扩展的原始精灵）；若跳过挖孔，最终形状缺少镂空特征。标记几何类型（线 vs 单点）决定镜像方式，进而决定扩展后的形状，进而影响模板对齐位置。

先根据红色标记的几何类型对每个精灵做镜像扩展，再将同色模板居中对齐到扩展后的精灵上挖孔。

**输入结构**：约 18x18 网格，黑(0)背景。网格上有 3 个彩色精灵体，每个使用不同的非黑非红颜色（如蓝(1)、绿(3)、黄(4)），每个精灵是 3-6 像素的 4-连通不规则小图形。每个精灵旁边紧邻一组红(2)标记像素：有的精灵旁边是单个红像素（与精灵 8-连通），有的旁边是 2-3 个红像素排成一条直线（水平或垂直，与精灵相邻）。另外，网格的远离精灵的区域有 3 个小模板图案，每个模板使用与某个精灵相同的颜色，模板为 2-4 像素的连通小图形。精灵和模板之间至少间隔 3 个黑像素。生成约束：每个精灵恰好对应一个同色模板；镜像扩展后的精灵包围盒足够大，使模板可以完全居中放置其中。

**规则**：
1. 识别每个精灵（非黑非红的 4-连通彩色分量）及其相邻的红(2)标记。
2. 判断红标记类型：若标记为单个红像素且与精灵 8-连通，则为点反射标记；若标记为 2 个以上红像素排成直线，则为轴反射标记（线的方向即反射轴方向）。
3. 点反射：以红像素为中心，将精灵的每个像素做 180 度点对称映射，映射位置绘制同色像素（原始像素保留，新像素叠加，即透明叠加）。轴反射：以红线为轴，将精灵的每个像素做镜像映射，映射位置绘制同色像素（透明叠加）。
4. 扩展完成后，计算每个精灵（含原始和新增像素）的包围盒中心 (cr, cc)（取包围盒行范围和列范围的中点，向下取整）。
5. 对每个精灵，找到同色模板。将模板的包围盒中心对齐到精灵的包围盒中心 (cr, cc)。
6. 模板覆盖的每个位置，若该位置是精灵的像素（含原始和镜像扩展的像素），则将该像素设为黑(0)（挖孔）。若模板位置不在精灵像素上，不做操作。
7. 移除所有红标记像素（设为黑(0)）。移除所有未被使用的独立模板像素（设为黑(0)）。

**关键洞察**：同一个模板因镜像方式不同（点反射 vs 轴反射）而对齐到不同的包围盒中心，导致挖孔位置完全不同；模板本身不变，但它的作用效果取决于镜像步骤的结果。

## 新题 4：滑向墙壁后按长度排名错切涂色

**组合逻辑**：[排序/sorting] → 并行输出 →（输出A）[错切/shear](创新：错切幅度由排名决定，而非固定每行+1) +（输出B）[重涂色/recolor] ← [滑动/slide](已有) + [长度排名/length_ranking](已有) + [贴墙移动/move_to_wall](已有) + [排名决定颜色/rank_determines_color](已有) + [逐行偏移/row_offset_incr](创新：偏移量不固定为 1 而是等于排名值)

**来源原语**：滑动(17829a00), 错切(9f41bd9c), 排序(ea32f347), 重涂色(ea32f347), 细条(ea32f347), 网格边缘(9f41bd9c), 边界色条(17829a00), 贴墙移动(9f41bd9c), 长度排名(ea32f347), 排名决定颜色(ea32f347), 逐行偏移(9f41bd9c)

**依赖链**：长度排名同时驱动两个下游操作——错切幅度和涂色映射。滑动操作确定垂直终点位置，错切操作以该终点为锚点施加对角偏移。删除排名则错切幅度和颜色均未定义；删除滑动则错切锚点不确定；删除错切则形状不变。三个操作通过排名这一中间结果交汇。

将不同长度的竖直细条滑向底部墙壁，按长度排名决定每根细条的对角错切幅度和重涂颜色。

**输入结构**：约 12x15 网格，黑(0)背景。顶行（第 0 行）为全宽蓝(1)色条，底行（最后一行）为全宽红(2)色条。网格中部区域有 3 根灰(5)竖直细条，每根宽 1 像素，长度（像素数）各不相同（如 3、5、7 像素），分布在不同列上。三根细条之间水平间距至少 4 列（为错切后的像素留出空间）。生成约束：三根细条的长度互不相同；各细条所在列距右边界至少有 max_rank * max_length 列的余量，确保错切后像素不会超出网格。

**规则**：
1. 识别 3 根灰(5)竖直细条，测量每根的像素长度。
2. 按长度升序排名：最短 = 排名 1，中间 = 排名 2，最长 = 排名 3。
3. 将每根细条向下滑动，使其最底部像素到达底部红色条上方一行（即倒数第 2 行）。滑动过程中保持列不变，清除原位置像素（设为黑(0)）。
4. 对每根滑动后的细条施加错切：以最底部像素为锚点（该像素列不变），从底部往上每一个像素向右偏移 rank 列。即，距锚点向上第 k 行的像素的列坐标 = 原列 + k * rank。若偏移后超出网格右边界，该像素丢弃。
5. 重涂色：排名 1 -> 绿(3)，排名 2 -> 黄(4)，排名 3 -> 橙(7)。
6. 顶行蓝色条和底行红色条保持不变。

**关键洞察**：错切的对角斜率不是固定常数，而是等于该细条在所有细条中的长度排名值；需要对比不同示例中不同长度配置的细条，才能归纳出"斜率 = 排名"这一隐蔽规则，而非"斜率 = 长度"或"斜率固定"。

## 新题 5：周期修复后连通性门控掩码涂色

**组合逻辑**：[补全/repair](已有) → [计数/counting](创新：统计修复后的连通分量面积) → [重涂色/recolor](创新：涂色依据是修复后的连通性，而非修复前的颜色) ← [最小周期推断填补/smallest_period_inferred_fill](已有) + [连通性/connectivity](已有) + [面积大于一则涂/recolor_if_area_gt_one](创新：反转——面积为 1 的孤立像素被涂色标记，而非面积大于 1 的)

**来源原语**：补全/repair(29ec7d0e), 平铺/tiling(29ec7d0e), 周期瓦片(29ec7d0e), 缺失单元(29ec7d0e), 最小周期推断填补(29ec7d0e), 重涂色(e0fb7511), 连通分量(e0fb7511), 孤立像素(e0fb7511), 连通性(e0fb7511), 面积大于一则涂(e0fb7511)

**依赖链**：周期修复决定了每个位置的颜色，颜色分布直接决定了 4-连通分量的结构。修复前某些位置是黑色空洞，修复后变为有色，可能将原本孤立的同色像素连接成大分量，也可能本身填入后仍为孤立像素。连通性分析只有在修复完成后才有意义。若跳过修复直接分析连通性，空洞位置会错误地切断分量；若跳过连通性分析直接涂色，无法区分孤立像素和连通像素。

先推断最小周期修复所有黑色缺失单元，再对修复后的网格做连通性分析，将每种颜色中的孤立单像素重涂为灰色。

**输入结构**：约 10x10 网格，显示一个被破坏的周期性彩色图案。图案使用 3 种非黑颜色（如蓝(1)、红(2)、绿(3)），最小重复周期为 p_r x p_c（约 3x3 或 4x4）。网格中散布若干黑(0)缺失单元（约占总格数的 15%-25%），缺失位置随机分布但保证每个周期瓦片位置至少在网格中出现一次非黑像素。生成约束：修复后的完整图案中，每种颜色既包含面积 > 1 的 4-连通分量，也包含面积 = 1 的孤立像素（这由周期图案的结构自然产生，如棋盘格的对角分布）。

**规则**：
1. 推断最小周期 (p_r, p_c)：找到最小的行周期 p_r 和列周期 p_c，使得所有非黑像素满足 grid[r][c] = tile[r mod p_r][c mod p_c]，其中 tile 是从现有非黑像素构建的周期瓦片。
2. 用周期瓦片填补所有黑(0)单元，得到完全修复的网格。
3. 在修复后的网格上，对每种非黑颜色分别计算其 4-连通分量。
4. 对每种颜色中面积 = 1 的孤立分量（该颜色的像素在 4-连通方向上没有同色邻居），将该像素重涂为灰(5)。
5. 面积 > 1 的分量保持修复后的颜色不变。

**关键洞察**：修复步骤本身创造了连通性分析的输入——同一个位置在修复前是空洞（不参与连通性），修复后可能成为连接两个同色区域的桥梁像素或仍为孤立像素；只有正确推断周期后，连通性判断才有效。

## 新题 6：方框尺寸填色与角落碎片四重对称挖孔

**组合逻辑**：[填充/fill](已有) + [对称补全/symmetry_completion](创新：补全对象嵌入在填充目标内部，补全后立即成为挖孔模板) + [挖孔/punch_holes](创新：挖孔模板由补全步骤生成，而非预先给定) ← [按边长映射颜色/size_to_color_mapping](已有) + [角落补全四重对称/corners_to_fourfold_symmetry](已有) + [中心对齐/center_alignment](已有)

**来源原语**：填充(00dbd492), 空心矩形(00dbd492), 中心标记(00dbd492), 按边长映射颜色(00dbd492), 对称补全(4290ef0e), 角落补全四重对称(4290ef0e), 中心对齐(4290ef0e), 挖孔(58f5dbd5), 模板图案(58f5dbd5)

**依赖链**：三个操作形成汇聚结构——框边长分析和角落碎片分析各自独立进行，但两者的结果在最终挖孔步骤中汇合：边长决定填充颜色（填充创造了"可挖孔的画布"），碎片补全决定挖孔图案。若跳过填充，内部是黑色，无画布可挖；若跳过碎片补全，挖孔图案不完整（只有四分之一）；若跳过挖孔，填充色会掩盖碎片信息。碎片嵌入在框内（非独立存在），使框同时承担"填充边界"和"碎片容器"双重角色。

对每个空心方框先按边长映射颜色填充内部，再将框内角落的彩色碎片做四重对称补全，最后将补全后的对称图案作为模板在填充色上挖孔。

**输入结构**：约 20x20 网格，黑(0)背景。有 2-3 个红(2)空心正方形框，边长分别为 7、9、11 像素（奇数，保证有唯一中心像素）。每个框由 1 像素宽的红边界围成，框的几何中心有一个红(2)标记像素。框之间互不重叠且间距至少 2 像素。每个框的内部（红边界以内、不含边界和中心标记的区域），在某一个角落象限中有一个小的彩色碎片图案，使用该框专属的非红非黑颜色（如框 A 用蓝(1)、框 B 用绿(3)、框 C 用黄(4)）。碎片为 2-4 像素的 4-连通小图形，位于该象限靠近角落的位置。不同框的碎片位于不同象限（如一个在左上、一个在右下）。生成约束：碎片做四重对称补全后，补全像素不会落在红边界或中心标记上。

**规则**：
1. 识别每个红(2)空心正方形框，测量其外边长 L。
2. 填充每个框的内部黑(0)像素（红边界以内且非中心标记的黑色区域）：L=7 -> 青(8)，L=9 -> 橙(7)，L=11 -> 品红(6)。红边界和红中心标记保持不变。
3. 识别每个框内部的彩色碎片（非红非黑非填充色的像素）。
4. 以框的中心标记像素为对称中心，将碎片做四重对称补全：对碎片中每个像素 (r, c)，计算其关于中心 (cr, cc) 的水平镜像 (r, 2*cc - c)、垂直镜像 (2*cr - r, c)、180 度旋转 (2*cr - r, 2*cc - c) 三个位置，在这些位置绘制同色像素。
5. 挖孔：四重补全后的完整对称图案覆盖的所有位置，若该位置当前为填充色（步骤 2 中填入的颜色），则将其设为黑(0)。彩色碎片像素本身保留不变（它们覆盖的位置显示碎片颜色，不是填充色）。
6. 红框边界、红中心标记、彩色碎片像素均保留原色。

**关键洞察**：角落碎片不是独立的装饰物，而是一个四分之一模板——只有将其做四重对称补全后，才能得到完整的挖孔图案；哪个角落放置碎片决定了补全的方向，但最终挖孔结果由对称性保证与角落位置无关（这个不变性需要对比多个示例才能确认）。

## 新题 7：隔板区域色彩轮换按内部隔室数排序

**组合逻辑**：[计数/counting](创新：统计每个区域内部被前景屏障分隔出的背景隔室数) → [排序/sorting](创新：排序依据从空间角度改为结构属性) → [循环轮换/cyclic_shift](创新：轮换顺序由隔室计数排名决定，而非空间角度顺序) ← [区域数编码/region_count_as_col](创新：计数结果不编码为输出像素列，而是用作排序键)

**来源原语**：循环轮换(880c1354), 分隔结构(880c1354), 分离区域(880c1354), 环绕角度排序(880c1354), 计数(e872b94a), 背景区域(e872b94a), 前景屏障(e872b94a), 区域数编码像素列(e872b94a), 排序(ea32f347)

**依赖链**：每个象限内的屏障拓扑分析（隔室计数）决定该象限在循环轮换中的位置。若跳过计数，轮换顺序不确定；若跳过轮换，颜色不变。计数结果不是最终输出（不同于 e872b94a 直接编码为像素列），而是中间排序键——这使得拓扑分析和颜色操作紧耦合。隔板结构既定义了空间区域（宏观分隔），又包含内部屏障（微观分隔），两层分隔服务于不同目的。

统计每个隔板分隔区域内部的背景隔室数，按隔室数升序排列各区域，沿该排列顺序循环轮换区域颜色。

**输入结构**：约 15x15 网格。一个黄(4)十字形隔板结构将网格分为 4 个象限（隔板为 1 像素宽的完整水平线和垂直线在网格中心交叉）。每个象限内有一个单色填充区域，四个象限使用四种不同的非黄非黑颜色（如蓝(1)、红(2)、绿(3)、橙(7)）。每个象限内，彩色区域之间还散布着若干灰(5)屏障像素，这些屏障将该象限的黑(0)背景分隔成不同数量的 4-连通隔室。四个象限的隔室数量互不相同（生成约束）。灰屏障像素数量在 3-8 之间，分布不规则。生成约束：黄隔板、灰屏障和象限边界共同围成的每个黑色隔室面积至少 2 像素（避免歧义）。

**规则**：
1. 保持黄(4)隔板像素和灰(5)屏障像素不变。
2. 对每个象限，以黄隔板和网格边界为该象限的边界，统计象限内 4-连通的黑(0)背景隔室数。统计时，彩色区域像素和灰屏障像素均视为非背景（墙壁），黄隔板和网格边界也视为墙壁。
3. 按隔室数升序对四个象限排序。隔室数相同时（生成约束保证不会），以象限位置为 tiebreak（左上 < 右上 < 左下 < 右下）。
4. 在排序后的序列中执行循环轮换：每个象限的彩色区域接收排序序列中前一个象限的颜色（第一个接收最后一个的颜色）。即，若排序后序列为 [Q_a, Q_b, Q_c, Q_d]，则 Q_a 获得 Q_d 的颜色，Q_b 获得 Q_a 的原色，Q_c 获得 Q_b 的原色，Q_d 获得 Q_c 的原色。
5. 每个象限中，所有原彩色像素被重涂为新颜色。黑色背景和灰屏障保持不变。

**关键洞察**：循环轮换的顺序不是象限的空间排列顺序（不同于 880c1354 的角度排序），而是由每个象限内部屏障创造的背景隔室数决定；需要对比多个示例才能排除"按空间位置轮换"的假设，确认排序键是隔室计数。
