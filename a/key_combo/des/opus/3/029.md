## 新题 1：对称修复揭示盆壁拓扑后的重力沉降

**组合逻辑**：[对称补全](创新：修复对象不是视觉图案而是物理容器壁) → [重力下落](已有原语) → [重涂色](创新：颜色由空间归属决定而非列序或频率)

**来源原语**：对称补全、对称轨道、反射旋转定颜色（f9d67f8b）；重力下落、碰撞停止、沿路径滑动、水像素、障碍物、盆地（28a6681f）；重涂色（58e15b12/575b1a71）

**依赖链**：对称补全修复缺损的盆壁像素 → 修复后的盆壁构成新的碰撞障碍物 → 重力模拟依赖修复后的障碍物布局决定水的最终位置 → 水的最终所在盆地的壁色决定水的重涂色颜色。删除对称补全则盆壁缺口导致水坠落到错误位置；删除重力则水不移动；删除重涂色则输出缺少颜色归属信息。

将部分对称的凹形盆地结构中的缺损壁通过对称修复补全，然后模拟水滴在完整盆地中的重力沉降，最终将定居水滴染为其所在盆地的壁色。

**输入结构**：约 15x18 的网格，黑(0)背景。网格中有 2-3 个凹形盆地结构（如 U 形或不对称漏斗形），每个盆地由不同颜色的像素构成壁体：一个用蓝(1)、一个用绿(3)、一个用橙(7)。每个盆地壁体具有关于某条垂直轴的镜像对称性，但壁体的一侧有若干像素被替换为栗(9)，破坏了对称性同时也在壁上打开了物理缺口。蓝(1)的水像素（每个 1-3 个独立像素）散布在盆地上方的空旷区域。生成约束：每个盆地的对称轴是垂直的；栗(9)像素仅出现在盆壁上；不同盆地的壁色互不相同且都不是栗(9)；修复对称后每个盆地是一个开口朝上的完整容器；水像素的位置保证修复后每滴水恰好落入一个盆地。

**规则**：
1. 识别栗(9)为遮挡色——它是唯一一种移除后使每个盆地结构具有无冲突垂直镜像对称性的颜色。
2. 将每个栗(9)像素替换为其在所属盆地垂直镜像轨道上的可见同伴颜色，完成盆壁修复。若遮挡像素的镜像同伴也被遮挡，则通过 180 度旋转对称确定颜色（与参考题 f9d67f8b 的多轨道解析逻辑一致）。
3. 模拟重力：每个蓝(1)水像素向下移动。遇到非背景像素阻挡时停止。若正下方被挡但左下或右下恰好有一个方向是空的，则沿该方向对角滑动一格后继续下落。若水平面上左右都被挡，则水停留在当前位置。重复直到所有水像素静止。水像素之间也互相碰撞。处理顺序：按行从下往上、同行从左到右。
4. 将每个已静止的水像素重涂色为它最终所在盆地的壁色（蓝(1)→盆地壁色）。判定归属方法：水像素所接触的（上下左右四邻域）非背景、非水像素中，颜色唯一确定其所在盆地。

**关键洞察**：栗(9)像素不是需要修复的表面瑕疵——它们是盆壁上的物理缺口。对称修复改变的是碰撞拓扑而非视觉外观：同样的水像素初始位置，在修复前和修复后会沉降到完全不同的终点。

## 新题 2：连接器对接合并空腔后的相位保持平铺

**组合逻辑**：[拼接/对接](已有原语) → [擦除](创新：擦除对象不是遮挡物而是结构连接件，擦除动作改变空腔拓扑) → [平铺](创新：平铺区域不是预存空腔而是由对接+擦除动态产生的合并空腔)

**来源原语**：拼接、连接标记、同色标记对齐对接、标记侧面决定方向（e9fc42f2）；擦除、填充矩形（3345333e）；平铺、种子图案、矩形空腔、保持种子相位、图案填满空腔（a57f2f04）

**依赖链**：同色连接器对接 → 确定对象的相对位置 → 擦除连接器像素 → 在对接边界打开通道 → 原本分离的空腔合并为一个连通区域 → 合并空腔的形状决定平铺区域 → 种子图案的绝对位置决定平铺相位。删除对接则对象位置未定；删除擦除则空腔不连通、平铺区域错误；删除平铺则合并空腔内容缺失。

将带有同色连接器的多个墙体对象对接组装，擦除连接器以合并内部空腔，然后用空腔内预置的种子图案以相位保持方式平铺填满整个合并空腔。

**输入结构**：约 18x20 的网格，灰(5)背景。网格中散布 3-4 个独立的墙体对象，每个由红(2)像素构成不规则但大致矩形的外壁（壁厚 1 像素），内部是一个矩形空腔（灰(5)背景色）。每个空腔内有几个蓝(1)像素，构成一个小的种子图案（约 2x2 或 2x3 的周期单元的一份拷贝）。每个墙体对象的外壁边界上嵌有 1-2 个连接器标记像素，颜色取自 {绿(3)、黄(4)、橙(7)}，每种连接器颜色在所有对象中恰好出现两次。连接器像素突出在壁体的外侧面，占据壁上一个像素位置。生成约束：每个连接器颜色的两个实例分别在不同对象上；对接后所有对象可以无重叠地组装；连接器所在壁段在擦除后恰好打通两个相邻空腔的边界；各空腔内种子图案的周期单元相同（颜色和形状一致），但种子在各空腔内的位置（相位）可能不同。

**规则**：
1. 按颜色匹配连接器对：每种连接器颜色的两个实例必须接触。确定连接器所在壁面的朝向（上/下/左/右），将对象平移使匹配连接器在其暴露面方向上相邻对齐。若有多对连接器，按连接器颜色在输入中从上到下、从左到右首次出现的顺序依次处理对接。
2. 对接完成后，将所有连接器像素（绿(3)、黄(4)、橙(7)）以及它们原本所在壁段的红(2)壁像素（连接器两侧各延伸 0 像素，即仅擦除连接器自身占据的那个壁位置）擦除为灰(5)背景色。这在相邻空腔之间打开 1 像素宽的通道。
3. 对合并后的每个连通空腔区域（由灰(5)背景色构成的四连通区域，被红(2)壁包围）：在其中找到蓝(1)种子像素，取种子像素的最小包围盒作为平铺单元。以种子像素的绝对网格坐标为相位基准，将平铺单元在整个合并空腔内周期性重复。仅填充灰(5)背景像素，不覆盖红(2)壁像素和已有的蓝(1)种子像素。
4. 最终输出的网格尺寸为组装后所有对象的紧凑包围盒，背景色为灰(5)。

**关键洞察**：连接器不仅决定对象的拼合位置，其擦除还改变了空腔的拓扑连通性。平铺填充的区域是对接+擦除后才存在的合并空腔，这个区域在任何单个源对象中都不存在。种子的绝对位置必须作为相位基准，因为合并后空腔边界已经改变，相对位置失去参照意义。

## 新题 3：频率门控的框内颜色互换与溢出射线

**组合逻辑**：[计数](已有原语) → 条件分支{[颜色互换](创新：互换由外部频率计数门控) | [射线延伸](创新：射线方向由框的缺口决定，颜色由框内幸存色决定)}

**来源原语**：颜色互换、矩形边框、框内区域、框内限定（7ee1c6ea）；计数、排序、单色矩形、颜色频率、频率排序、跳过最高频（f8b3ba0a）；射线延伸、边框缺口、缺口方向决定射线（551d5bf1/981add89）

**依赖链**：外部矩形的颜色频率计数 → 确定"最高频颜色" → 对每个框产生条件判断（框内是否含最高频色）→ 含最高频色的框：擦除最高频色 + 从缺口发射射线（射线颜色 = 幸存色）→ 不含最高频色的框：执行内部颜色互换 + 用壁色封闭缺口。这是一个条件分支结构，不是线性流水线——同一类输入对象（框）根据全局属性走不同的变换路径。

根据外部矩形的颜色频率决定每个框的行为：不含最高频色的框执行内部颜色互换并封口，含最高频色的框擦除该色并从缺口向外发射幸存色射线。

**输入结构**：约 20x20 的网格，黑(0)背景。网格中有 4-5 个单像素厚的矩形框，框壁为灰(5)。每个框的某一条边上恰好缺少一个非角落的灰(5)像素（即边框缺口），缺口位置各不相同。每个框内部包含恰好两种非黑、非灰颜色的像素（不一定填满框内所有位置，可以有黑(0)间隙）。在框外的空旷区域，散布着若干单色实心小矩形（约 2x2 至 3x4 大小），颜色取自 {蓝(1)、红(2)、绿(3)、黄(4)、橙(7)}。生成约束：框互不重叠且不接触；每个框的两种内部颜色互不相同；外部矩形中恰好有一种颜色的矩形数量严格多于其他所有颜色（即最高频色唯一）；至少有一个框的内部颜色包含最高频色，至少有一个框不包含；缺口方向上的射线路径不会穿过其他框。

**规则**：
1. 统计框外部各颜色的单色矩形数量（按对象数计数，非像素数），确定数量最多的颜色为"最高频色"。
2. 对每个框，检查其内部两种颜色是否包含最高频色：
   - **不包含最高频色**：在框内部交换两种非黑非灰颜色（颜色 A 的像素变为颜色 B，颜色 B 变为颜色 A）。黑(0)间隙像素和灰(5)框壁不变。然后将缺口位置填上灰(5)，封闭边框。
   - **包含最高频色**：将框内部所有最高频色像素擦除为黑(0)。框壁和另一种颜色的像素不变。缺口保持打开。从缺口位置向外（垂直于缺口所在边的方向）延伸射线，用框内幸存的那种非黑非灰颜色涂画路径上的所有黑(0)像素，直到触碰网格边缘。缺口本身也涂上该颜色。
3. 外部矩形和所有不相关的背景像素保持不变。

**关键洞察**：外部频率计数建立了一个全局条件，将框分成两类行为完全不同的对象。同一种框结构（含缺口的矩形框+两色内部）产生的输出形态截然不同——颜色互换是封闭性操作（框变完整），射线延伸是开放性操作（能量从框内泄漏到外部）。必须对比多个示例才能归纳出"最高频色决定分支"这一隐蔽规则。

## 新题 4：分槽阶梯扩展产生重叠计数驱动瓦片排序

**组合逻辑**：[阶梯扩展](创新：在受限的瓦片槽内对双色条对执行扩展) → [计数](创新：计数对象不是前景像素而是扩展产生的跨色重叠像素) → [排序+重排](已有原语)

**来源原语**：阶梯扩展、竖直条对、周期性步长、跨色重叠变色（58e15b12）；排序、计数、重排、瓦片、分隔线、阵列排布、前景数决定排序（dc2aa30b）

**依赖链**：每个瓦片内的双色条对执行阶梯扩展 → 不同颜色的扩展带在瓦片内相交产生品红(6)重叠像素 → 每个瓦片的品红像素数成为排序键 → 按品红数升序重排瓦片。删除扩展则无重叠像素、无排序键；删除计数则无法确定顺序；删除排序则瓦片位置不变。扩展步骤是"计算性"的——其目的不是生成最终视觉图案，而是产生驱动排序的度量值。

在分隔线划分的瓦片槽内对双色竖直条对执行阶梯扩展，统计每个瓦片内产生的跨色重叠（品红）像素数量，按该数量从少到多重排整个瓦片阵列。

**输入结构**：约 23x23 的网格。灰(5)分隔行和分隔列将网格切分为 3x3 共 9 个大小相等的瓦片槽（每个约 7x7）。每个瓦片槽内包含恰好两对同色竖直条：第一对颜色取自 {蓝(1)、红(2)、绿(3)} 中的一种，第二对颜色取自 {黄(4)、橙(7)、青(8)} 中的一种（每个瓦片的两对颜色不同）。每对竖直条由两根同色、同高度（2-4 像素高）的竖直线段组成，两根线段在同一行区间内、不同列上。同一瓦片内的两对条有不同的高度和不同的列位置，保证扩展后会产生不同程度的空间重叠。生成约束：每个瓦片的条对参数（高度、列间距、行位置）各不相同，使得 9 个瓦片产生的品红像素数量互不相同（无并列）。

**规则**：
1. 在每个瓦片槽内，分别对两对竖直条执行阶梯扩展：每根竖直条在其原始行区间内保持原列位置；超出原始行区间后，每经过一个完整的"条高度"行数，左侧条向左移一列，右侧条向右移一列。扩展在瓦片槽边界处截断（不跨越灰(5)分隔线）。
2. 在每个瓦片内，凡是被两种不同颜色的扩展带同时覆盖的像素，涂为品红(6)。仅被一种颜色覆盖的像素保留该颜色。
3. 统计每个瓦片内品红(6)像素的数量。
4. 按品红数量从小到大排列 9 个瓦片。将排序后的瓦片依次放入 3x3 阵列，从左上角开始，从左到右逐行填充，然后向下换行。每个瓦片保留其扩展和重叠后的完整视觉状态。灰(5)分隔线不变。

**关键洞察**：条对的高度和列间距共同决定阶梯扩展的展开速度和横向覆盖范围，而两对条的相对位置决定重叠面积。品红像素不是视觉装饰——它是一个由几何参数隐式编码的排序度量。需要对比多个示例才能发现"重叠面积 = 排序键"的隐蔽规则。

## 新题 5：标记选择晶格带后图例映射射线重涂色

**组合逻辑**：[标记行列选择](已有原语) + [射线延伸](创新：射线仅从标记选中的带与控制列的交点发射，而非从所有控制像素发射) + [图例配色映射](创新：射线颜色不等于控制像素自身颜色，而是通过图例间接映射) → 三个独立信息源（标记位置、控制像素列、图例映射）在交汇点产生涌现输出

**来源原语**：晶格网格、标记块、标记行列选择、行列带穿越标记（4f537728）；射线延伸、控制像素、同列对齐（981add89）；图例、图例配色、图例顺序决定层级、冲突优先级（305b1341）；重涂色（58e15b12）

**依赖链**：红(2)标记块选中晶格的两行两列 → 选中行列确定"活跃带" → 顶行控制像素中，仅列号落在活跃列上的控制像素触发射线 → 射线沿选中列向下延伸穿过整个网格 → 射线涂画颜色由图例映射决定（控制像素颜色 → 图例配对色）→ 射线与选中行的交点处，若多条射线重叠，按图例行序（上方优先）解决冲突。三个信息源缺一不可：标记决定"哪里"，控制像素决定"是否发射"，图例决定"什么颜色"。

红色标记块选中晶格中的行列带，仅与选中列对齐的顶行控制像素发射向下射线，射线颜色由角落图例间接映射，多射线重叠时图例行序决定优先级。

**输入结构**：约 16x16 的网格，黑(0)背景。蓝(1)像素构成一个规则晶格（等间距的水平线和垂直线，线宽 1 像素，间距约 3-4 像素，覆盖网格大部分区域）。在晶格的某个交叉点处，一个 2x2 的红(2)标记块替换了四个蓝(1)像素。网格左上角占据 2 行 x 2 列的区域作为图例：第 0 行第 0 列 = 绿(3)，第 0 行第 1 列 = 黄(4)；第 1 行第 0 列 = 橙(7)，第 1 行第 1 列 = 青(8)。图例区域不与晶格重叠。顶行（第 0 行）的若干非图例列上放置控制像素，颜色为绿(3)或橙(7)（与图例左列颜色对应）。生成约束：至少有一个控制像素的列恰好落在标记块选中的两个列之一上，至少有一个不落在选中列上；图例区域严格在网格左上 2x2 范围内，不与晶格线重合。

**规则**：
1. 找到红(2)标记块所占的两行（r1, r2）和两列（c1, c2）。
2. 将这两行和两列上所有蓝(1)晶格像素重涂为红(2)——标记出选中的行带和列带。
3. 扫描顶行（第 0 行）的所有控制像素。对于每个控制像素：若其列号等于 c1 或 c2（即落在选中列带上），则该控制像素"激活"，从该控制像素正下方开始，沿该列向下逐格延伸射线直到网格底部。若控制像素的列号不在选中列上，则不激活，不发射任何射线。
4. 射线经过的每个格子涂上图例映射后的颜色：绿(3)控制像素的射线涂黄(4)，橙(7)控制像素的射线涂青(8)（即图例同行右列的颜色）。射线覆盖该列上的所有像素（包括黑(0)背景和红(2)选中带像素），但不覆盖蓝(1)未选中的晶格像素。
5. 若同一个格子被多条射线覆盖（仅在 c1 = c2 时可能，但此题保证 c1 != c2，故无冲突；但若不同控制像素落在同一选中列上，则按图例行序解决：第 0 行图例对应的颜色优先于第 1 行）。
6. 清除图例区域（左上 2x2）为黑(0)背景。控制像素本身保持原色不变。

**关键洞察**：标记块不仅高亮晶格带，更充当射线的空间门控——只有列与标记对齐的控制像素才会"通电"。图例提供了一层间接映射，使射线的颜色与控制像素的颜色不同，必须对比示例才能发现颜色转换规则。三个独立编码的信息（标记位置、控制像素分布、图例映射）在输出中交汇。

## 新题 6：互补拼合嵌入框架后缺口溢出着色

**组合逻辑**：[裁剪+平移/互补拼合](创新：拼合目标不是最小框而是必须恰好匹配已知框架的内腔形状) → [洪泛填充](创新：填充方向和颜色由框架缺口与拼合结果的空间关系决定) → [擦除](已有原语)

**来源原语**：裁剪、平移、精灵体、无重叠拼合、互补拼合、最密堆叠最小框（681b3aeb）；洪泛填充、空心矩形、边框缺口、缺口方向决定射线（551d5bf1）；擦除（3345333e）

**依赖链**：两个精灵体互补拼合 → 拼合结果的形状必须匹配框架内腔 → 拼合方案确定了哪种颜色的精灵体占据缺口相邻的内壁位置 → 该颜色从缺口向外洪泛/射线延伸。删除拼合则不知道框内填什么；删除缺口判断则不知道溢出什么颜色；删除擦除则原始精灵体残留在框外。拼合的朝向（唯一解）隐式编码了溢出颜色。

将两个互补精灵体拼合后嵌入带缺口的矩形框架内，缺口相邻内壁位置的精灵体颜色沿缺口方向向外溢出为射线，最后擦除框外的原始精灵体。

**输入结构**：约 15x18 的网格，黑(0)背景。网格中有一个单像素厚的灰(5)矩形框，框的某一条边上恰好缺少一个非角落像素（边框缺口）。框的内腔为黑(0)。在框外的其他位置，有两个单色精灵体（4-连通的不规则形状，每个约 5-10 像素），一个为蓝(1)，一个为红(2)。两个精灵体的形状互补——存在唯一的平移方案使它们无重叠地拼合成一个实心矩形，且该矩形的尺寸恰好等于框的内腔尺寸。生成约束：互补拼合方案唯一；拼合后的矩形恰好填满框的内腔（无间隙、无溢出）；缺口位置的内壁相邻像素（从缺口向内看的第一个内腔像素）在拼合后被蓝(1)或红(2)之一确定性地占据；缺口方向上的外部射线路径上无其他非背景像素。

**规则**：
1. 裁剪两个精灵体至各自的最小包围盒。
2. 找到唯一的平移方案使两个精灵体无重叠拼合成一个矩形，该矩形尺寸等于框的内腔。
3. 将拼合结果放入框的内腔（对齐内腔左上角）。
4. 确定框的缺口位置。找到缺口内侧相邻的那个内腔像素（即从缺口向框内方向看的第一个像素），记录该像素的颜色（蓝(1)或红(2)）。
5. 从缺口位置向外（垂直于缺口所在边的方向），沿直线涂画所有黑(0)像素为步骤 4 确定的颜色，直到触碰网格边缘。缺口位置本身也涂上该颜色。
6. 将框外原始精灵体的位置擦除为黑(0)背景。

**关键洞察**：互补拼合的唯一解决定了内腔的颜色分布，但求解者只有在完成拼合后才能知道缺口旁边是哪种颜色——拼合结果隐式编码了溢出信息。不同示例中，即使两个精灵体颜色相同，不同的形状和框缺口位置会导致不同颜色的溢出，迫使求解者完整执行拼合推理而非猜测。

## 新题 7：对称与平铺双约束联合解遮挡

**组合逻辑**：[对称补全] + [平铺] 同时约束满足（非流水线：两个约束系统交织求解，任一约束单独不足以确定所有被遮挡像素）

**来源原语**：对称补全、对称轨道、遮挡像素、反射旋转定颜色（f9d67f8b）；平铺、瓦片、保持种子相位（c48954c1/a57f2f04）；擦除（3345333e）

**依赖链**：这不是线性依赖而是约束交织——被遮挡像素分三类：(A) 仅靠对称轨道可解（镜像同伴可见）；(B) 仅靠平铺周期可解（同位置的其他周期副本可见）；(C) 两者单独都不可解，但对称先解出 C 的某个平铺同伴，再由平铺传播到 C；或反过来。求解者必须迭代地交替应用两种约束直到所有遮挡像素被确定。删除任一约束系统都会留下无法确定的像素。

一个既有垂直镜像对称又有周期性平铺结构的彩色图案被栗色像素部分遮挡，求解者必须同时利用对称和平铺两种约束来唯一确定每个被遮挡像素的颜色。

**输入结构**：约 12x12 的网格，黑(0)背景。网格上铺设着一个周期性平铺图案，平铺单元约 3x4 或 4x3 像素，使用蓝(1)、红(2)、绿(3)三种颜色（部分位置为黑(0)背景）。该平铺图案同时具有关于网格某条垂直轴的镜像对称性（即整个平铺后的完整图案是左右对称的）。约 20-30% 的非背景像素被替换为栗(9)（遮挡色）。遮挡的分布经过精心设计，使得：
- 约 1/3 的栗(9)像素可以仅通过垂直镜像对称确定（其镜像位置的像素可见且非栗色）。
- 约 1/3 的栗(9)像素可以仅通过平铺周期确定（同一平铺单元内的同位置在其他周期副本中可见且非栗色）。
- 约 1/3 的栗(9)像素两种约束单独都无法直接解出——其镜像位置也是栗(9)，其平铺同位置也是栗(9)——但可以通过约束传播间接解出（例如：像素 P 的镜像同伴 Q 也是栗(9)，但 Q 的平铺同伴 R 可见，所以先由平铺解出 Q，再由对称解出 P）。

生成约束：遮挡分布保证最终解唯一；平铺周期可以从未被遮挡的区域中无歧义地推断（至少有一个完整的平铺单元完全可见）；对称轴可以从未被遮挡的像素中无歧义地推断；不存在仅靠约束传播仍无法确定的栗(9)像素。

**规则**：
1. 识别栗(9)为遮挡色。
2. 从非遮挡区域推断平铺周期：找到最小矩形单元 T，使得将 T 按行列周期性重复后，所有非栗(9)像素都与重复结果一致。
3. 从非遮挡区域推断垂直对称轴：找到列坐标 x_mirror，使得所有非栗(9)像素关于 x_mirror 的镜像位置要么颜色匹配、要么该位置是栗(9)。
4. 迭代解遮挡：
   a. 对每个栗(9)像素，检查其垂直镜像位置——若该位置已知（非栗色），则将当前像素设为镜像位置的颜色。
   b. 对每个仍为栗(9)的像素，检查其平铺周期的所有同位置副本——若至少有一个已知（非栗色），则将当前像素设为该已知颜色。
   c. 重复 a-b 直到没有新的栗(9)像素被解出。
5. 若网格边缘存在不完整的平铺单元区域（平铺周期在此处不完整复制），且其中的栗(9)像素在步骤 4 中已被解出，则保留解出的颜色；若未被解出（理论上不应发生，因为生成约束保证解唯一且完整），则擦除为黑(0)。

**关键洞察**：这道题的核心结构不是"先做 A 再做 B"，而是"A 和 B 互为前提的联立方程"。部分遮挡像素只有在另一种约束先解出其关联像素后才能被当前约束解出——这要求迭代的约束传播而非单次扫描。必须对比多个示例才能同时发现平铺周期和对称轴两套结构。
