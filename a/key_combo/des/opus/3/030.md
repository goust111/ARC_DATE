## 新题 1：异常块就地反转

**组合逻辑**：[计数/counting] + [异常值提取/outlier_extraction](创新：异常块不裁剪，而是就地变换) → [反转填充/occupancy_inversion](创新：仅对被选中的单个块执行，反转色用新颜色标记)

**来源原语**：计数、背景孔洞、异常值提取（358ba94e）；反转填充、重涂色、瓷砖（1c0d0a4b）

**依赖链**：孔洞计数产生每个块的特征值 → 异常值判断选出唯一目标块 → 反转填充仅作用于该目标块，其余块不变。计数结果决定了反转填充的作用域，而反转填充的输入图案正是计数时分析的孔洞分布。

将多个同色前景块中孔洞数量唯一的那一个就地执行占用反转，反转后的新前景用另一颜色标记，其余块保持原样。

**输入结构**：黑(0)背景，约 15x18 的网格。一种前景色（如蓝(1)）形成 4-6 个互不相连的同尺寸方块（每个约 5x5），各方块之间至少间隔 1 行/列背景。每个方块内部有若干黑(0)背景孔洞（1-4 个像素），形成不同的内部图案。大多数方块的孔洞数量相同（如都是 2 个），恰好一个方块的孔洞数量与其余不同（如 3 个）。生成约束：孔洞数量的众数恰好出现 N-1 次（N 为方块总数），剩余一个方块的孔洞数量唯一。

**规则**：
1. 对每个蓝(1)方块，计算其 5x5 包围盒内黑(0)背景像素的数量（即孔洞数）。
2. 找到孔洞数在所有方块中唯一出现的那一个方块（异常块）。
3. 对异常块执行占用反转：将其包围盒内原本为蓝(1)的像素改为黑(0)，原本为黑(0)的像素改为红(2)。
4. 所有其他方块保持不变，背景保持不变。
5. 输出完整网格。

**关键洞察**：异常块不是被裁剪提取出来，而是在原位被反转——用于识别异常的孔洞分布图案，恰好也是反转后新图案的"底片"，因此同一组孔洞同时承担了选择功能和变换定义。

## 新题 2：滑动标记生成行列交叉填充

**组合逻辑**：[滑动/sliding] + [碰撞停止/collision_stop](保留) → [行列交叉/row_col_intersection](创新：交叉坐标不由边缘标记直接给出，而由滑动落点隐式编码) → [填充/fill]

**来源原语**：滑动、碰撞停止、标记像素、射线对齐（a48eeaf7）；填充、行列交叉、边缘标记笛卡尔积（2281f1f4）

**依赖链**：标记像素沿射线滑向锚点块 → 落点位置隐式定义了"选中行"和"选中列" → 所有选中行与选中列的笛卡尔积交叉点被填充新色。滑动的终点是填充坐标的唯一来源；没有滑动，行列未知；没有交叉填充，滑动本身无法解释输出中远离锚点块的新像素。

将散布在网格边缘的标记像素沿射线滑至中心锚点块的邻环，然后用落点的行号和列号定义行列选择集，在所有行列交叉点填充新色。

**输入结构**：黑(0)背景，约 11x11 的网格。网格中部偏心位置有一个绿(3)的实心 2x2 方块作为锚点。4-6 个蓝(1)标记像素分布在网格边缘区域，每个标记像素与 2x2 方块在同一行、同一列或同一 45 度对角线上对齐。生成约束：每个标记与锚点块之间的射线路径上无其他非背景像素阻挡；不同标记的落点行号或列号不完全相同（至少产生 2 个不同的行和 2 个不同的列）。

**规则**：
1. 将每个蓝(1)标记像素沿其与 2x2 绿(3)锚点块对齐的射线方向（行/列/对角线）向锚点块滑动，在紧邻锚点块外侧一圈（4x4 环）的对应位置停下。
2. 从原位置擦除标记（恢复为黑(0)），在落点位置绘制蓝(1)。
3. 收集所有落点的行号集合 R 和列号集合 C。
4. 对 R x C 的所有交叉点 (r, c)，若该位置是黑(0)背景，则填充为红(2)。已有绿(3)或蓝(1)的位置不覆盖。
5. 输出完整网格。

**关键洞察**：标记像素滑动后的落点不只是装饰锚点块的邻环——它们的行列坐标被"提取"出来，作为隐式行列头驱动一个稀疏表格的填充，在远离锚点的区域产生规律排列的红色像素。

## 新题 3：嵌套矩形补全后方形孔洞条件填充

**组合逻辑**：[补全/complete] + [由外到内嵌套/outer_to_inner] + [大层先画小层覆盖/large_first_small_over] → [孔洞几何决定填充/hole_geometry_sets_fill](创新：孔洞不是原始输入中的，而是补全后嵌套结构涌现出的)

**来源原语**：补全、稀疏矩形层、嵌套矩形、大层先画小层覆盖（5751f35e）；填充、封闭区域、孔洞、仅正方形孔洞填充、孔洞几何决定填充（44d8ac46）

**依赖链**：稀疏像素补全为完整嵌套矩形 → 嵌套层叠后涌现出层间背景间隙（孔洞） → 仅几何形状为正方形的间隙被填充。补全决定了矩形边界，边界决定了间隙的形状，形状决定了是否填充。删除补全步骤则矩形边界不确定；删除几何判断则所有间隙都填充。

将稀疏散布的多色像素补全为嵌套的实心矩形，然后检查嵌套层之间涌现的背景间隙，仅将形状为正方形的间隙填充为新颜色。

**输入结构**：黑(0)背景，约 16x16 的网格。3-4 种前景色（如红(2)、绿(3)、黄(4)、蓝(1)），每种颜色有 4-8 个散布的像素，各色像素的包围盒面积互不相同且严格嵌套（外层包围盒严格包含内层）。生成约束：各色像素的包围盒不共享任何边界行/列；相邻层的包围盒之间至少在一个方向上间隔 2 行/列以产生可见的背景间隙；至少一个层间间隙区域（去掉被内层覆盖的部分后）的连通背景区域恰好是正方形，至少一个不是。

**规则**：
1. 对每种前景色，将其所有像素的包围盒填充为该颜色的实心矩形。按包围盒面积从大到小的顺序绘制，小矩形覆盖大矩形。
2. 补全后，在每对相邻嵌套层之间寻找 4-连通的黑(0)背景连通区域（间隙）。
3. 对每个间隙区域，计算其包围盒。若包围盒为正方形（宽 = 高）且包围盒内所有像素均为黑(0)，则将该间隙填充为灰(5)。
4. 非正方形或不完全填满包围盒的间隙保持黑(0)不变。
5. 输出完整网格。

**关键洞察**：需要填充的正方形间隙在原始输入中不可见——它们是补全嵌套矩形后才涌现的几何结构。间隙的形状取决于相邻两层矩形的相对尺寸和位置，而这些矩形本身在输入中只是散布的采样点。

## 新题 4：引导轴定心旋转补全与方向分色

**组合逻辑**：[引导条/guide_bar] + [引导条决定朝向/guide_determines_dir](创新：引导条不决定压缩方向，而是锚定对称中心) → [对称补全/symmetry_completion] + [旋转对称/rotational_symmetry] → [方向分色/direction_based_color_split](创新：不按水平/垂直分色，而按旋转角度分色)

**来源原语**：引导条、引导条决定朝向（c61be7dc）；对称补全、旋转、旋转对称、缺失部分标记新色（1b60fb0c）；方向分色（08573cc6）

**依赖链**：引导条的交叉点锚定对称中心 → 以该中心分析前景形状的 4 重旋转对称缺失像素 → 按将已有像素映射到缺失位置所需的旋转角度分配颜色。引导条提供中心（无引导条则对称中心歧义）；对称分析提供缺失像素（无分析则不知补什么）；旋转角度提供颜色选择（无角度区分则全部同色，与示例矛盾）。

在两条灰色引导条交叉点为圆心，将不完整的前景形状进行 4 重旋转对称补全，补全像素按所需旋转角度（90/180/270 度）分别着不同颜色。

**输入结构**：黑(0)背景，约 13x13 的网格。一条水平和一条垂直的灰(5)单像素宽线段穿过网格（不一定居中），交叉于一点。蓝(1)像素形成一个 4-连通的不规则前景形状（8-15 像素），位于交叉点附近但不与灰线重叠。该形状接近 4 重旋转对称但缺少约 1/4 的像素（某个象限的对应像素缺失）。生成约束：蓝像素不接触灰线；缺失的像素位置全部为黑(0)背景；以交叉点为中心旋转 90/180/270 度后，每个角度至少有 1 个缺失像素需要补全。

**规则**：
1. 取两条灰(5)线段的交叉点作为对称中心 O。
2. 对每个蓝(1)像素，计算其绕 O 旋转 90 度（顺时针）后的位置。若该位置为黑(0)，标记为红(2)。
3. 对每个蓝(1)像素，计算其绕 O 旋转 180 度后的位置。若该位置为黑(0)，标记为绿(3)。
4. 对每个蓝(1)像素，计算其绕 O 旋转 270 度（顺时针）后的位置。若该位置为黑(0)，标记为黄(4)。
5. 若某个位置同时被多个角度标记（旋转映射重叠），使用最小旋转角度对应的颜色（90 度 > 180 度 > 270 度，即红(2)优先）。
6. 灰线和原始蓝像素保持不变。输出完整网格。

**关键洞察**：引导条不是装饰性分隔线，而是对称中心的定位器；补全像素的颜色不是统一的，而是编码了"从哪个已有像素经过多少度旋转映射而来"，使得输出同时展示了形状的对称结构和旋转距离信息。

## 新题 5：面板内面积众数筛选后跨面板叠合

**组合逻辑**：[计数/counting](创新：计数目标从颜色频次改为对象面积) → [多数投票/majority_vote](创新：投票对象是面积值而非颜色) → [筛选/filtering] → [拼接/merge] + [位序选择/positional_selection](创新：不按面板序号选位序，而是保留所有通过筛选的对象)

**来源原语**：计数、多数投票、多数决（27a77e38）；拼接、位序选择、等分面板、分隔条（5ecac7f7）；筛选（23b5c85d）

**依赖链**：面板分割定义独立子问题 → 每个面板内对对象面积做众数投票 → 众数面积作为筛选阈值保留匹配对象 → 三个面板的存活对象叠合到统一画布。面板结构决定投票范围；投票结果决定筛选条件；筛选后对象集决定叠合内容。

在三个分隔面板中，分别对前景对象的像素面积做众数投票，仅保留面积等于众数的对象，然后将三个面板的保留对象叠合到一个画布上。

**输入结构**：约 10x32 的网格，由两条垂直灰(5)分隔条等分为三个 10x10 的面板（分隔条各 1 列宽）。每个面板的背景为黑(0)，包含 4-5 个单色 4-连通前景对象，每个对象使用面板内唯一的颜色（同一面板内不同对象颜色不同，但不同面板间颜色可重复）。各对象像素面积在 3-8 之间。生成约束：每个面板内恰好有一个面积值出现次数最多（严格众数），且不同面板的众数面积值可以不同；每个面板内至少有 2 个对象的面积等于众数，至少有 1 个对象面积不等于众数。

**规则**：
1. 按灰(5)分隔条将网格切分为三个 10x10 面板（左、中、右）。
2. 在每个面板内，计算每个 4-连通前景对象的像素面积。
3. 对每个面板，找到面积值的严格众数（出现次数最多的面积值）。
4. 仅保留面积等于该面板众数的对象，擦除其余对象（恢复为黑(0)）。
5. 创建一个 10x10 的黑(0)画布。将三个面板中保留的对象按原始面板内坐标叠合到该画布上。
6. 若不同面板的保留对象在同一位置重叠，右侧面板的对象覆盖左侧面板的对象。
7. 输出 10x10 画布（不含分隔条）。

**关键洞察**：众数投票在每个面板内独立进行且投票对象是面积而非颜色，因此不同面板可能保留不同大小的对象；最终叠合时，空间冲突由面板顺序（右优先）解决，这意味着即使知道了保留规则，仍需推断面板叠合的覆盖优先级。

## 新题 6：断线补全定义瓷砖边界后局部反转

**组合逻辑**：[补全/completion] + [相邻像素标有效线/adjacent_marks_line] + [缺口补另色/gaps_filled_other_color] → [瓷砖网格排列/tile_grid_layout](创新：瓷砖边界不是预设的分隔行列，而是由补全操作动态生成的) → [反转填充/occupancy_inversion](创新：反转仅作用于包含特定标记的瓷砖)

**来源原语**：补全、网格线、缺口、相邻像素标有效线、缺口补另色（4612dd53）；反转填充、重涂色、瓷砖、分隔行列（1c0d0a4b）

**依赖链**：断续的网格线被识别并补全 → 补全后的网格线划分出瓷砖区域 → 仅包含绿色标记像素的瓷砖执行占用反转。网格补全决定瓷砖边界（无补全则边界不完整、瓷砖区域不封闭）；标记像素决定哪些瓷砖被反转（无标记则不知反转哪些）。

先将断续的蓝色网格线补全（缺口填红色），补全后的线条划定瓷砖区域，然后仅对包含绿色标记的瓷砖执行前景/背景反转。

**输入结构**：黑(0)背景，约 15x15 的网格。蓝(1)像素形成一组断续的水平线和垂直线，构成不完整的矩形网格。有效线通过至少一对水平或垂直相邻的蓝(1)像素来标识。若干绿(3)单像素标记散布于网格区域内（不在蓝线上），每个标记落在某个由网格线围成的矩形区域内部。部分矩形区域内还有黄(4)前景像素形成小型 4-连通图案（3-5 像素）。生成约束：每条有效线至少有 1 个缺口（1-2 像素宽的中断）；补全后网格线能划分出至少 4 个完整封闭矩形区域；绿标记仅出现在部分区域内（至少 1 个区域无绿标记）；包含绿标记的区域中至少有 1 个同时包含黄色图案。

**规则**：
1. 识别有效的水平线（同行内至少存在一对水平相邻的蓝(1)像素）和有效的垂直线（同列内至少存在一对垂直相邻的蓝(1)像素）。
2. 在网格线整体包围盒范围内，将有效行和有效列上的所有黑(0)缺口像素填充为红(2)。保留原有的蓝(1)像素不变。
3. 补全后的蓝(1)+红(2)线条将网格划分为若干封闭矩形瓷砖区域。
4. 对于每个瓷砖区域：若其内部包含至少一个绿(3)标记像素，则对该区域执行占用反转——将区域内原本为黄(4)的像素改为黑(0)，原本为黑(0)的像素改为黄(4)。绿(3)标记像素本身被擦除（改为黑(0)）。
5. 不含绿标记的瓷砖区域保持不变。
6. 网格线（蓝(1)和红(2)）保持不变。输出完整网格。

**关键洞察**：补全断线同时完成两件事——修复视觉上的网格结构，以及划定反转操作的作用域边界。瓷砖的大小和形状完全由断线补全的结果决定，绿色标记是"反转开关"而非反转内容本身。

## 新题 7：朝向归一化后对角线循环铺满内部

**组合逻辑**：[归一化朝向/normalize_orient] + [角落边框/corner_frame] + [嵌套层/nested_layer](保留边框重绘) → [循环填充/cyclic_fill] + [对角线/diagonal] + [同余类交错铺满/congruence_interlaced](创新：铺满范围不是整个网格，而是归一化后的内部矩形)

**来源原语**：重涂色、角落边框、嵌套层、对角线轨迹、归一化朝向（bd5af378）；循环填充、对角线、等距偏移、同余类交错铺满（05269061）

**依赖链**：输入 L 形边框的朝向决定归一化变换 → 归一化后重绘嵌套 L 边框，确定内部矩形区域 → 种子像素在归一化坐标系中沿对角线循环铺满内部矩形 → 恢复原始朝向。归一化决定对角线方向（不同朝向下主对角线不同）；嵌套边框决定铺满边界；种子像素决定颜色分配。

将角落 L 形边框归一化到左上角并重绘嵌套层后，用内部的种子像素沿对角线方向循环铺满内部矩形区域，最后恢复原始朝向。

**输入结构**：约 8x10 的矩形网格，恰好两种颜色。一种颜色（如橙(7)）形成一个单像素宽的 L 形，紧贴网格的两条相邻外边（四个可能的角之一）。另一种颜色（如蓝(1)）填充其余区域。在蓝色填充区域内，有 2-3 个单独的像素使用其他颜色（如红(2)、绿(3)），作为对角线种子。生成约束：种子像素之间的行偏移量模 3 互不同余（即分别属于 mod 3 的 0、1、2 类）；种子像素不在 L 边框上；内部矩形至少 5x5 以容纳可见的对角线图案。

**规则**：
1. 检测 L 形边框的角落位置（左上/右上/左下/右下）。通过翻转/旋转将 L 归一化到左上角，同时对网格内所有像素（含种子）做相同变换。
2. 在归一化后的网格中，将最外层 L 涂为蓝(1)，次外层 L 涂为橙(7)，其余区域定义为内部矩形。
3. 对内部矩形中的每个种子像素，沿主对角线方向（左上→右下）画出完整的对角线（裁剪到内部矩形边界）。
4. 每条种子对角线以间隔 3 行重复铺满整个内部矩形（同余类扩展），颜色使用该种子的颜色。
5. 若不同种子的铺满对角线重叠，按种子在归一化后内部矩形中从上到下的行位置排序，行位置靠下的种子颜色覆盖靠上的。
6. 将整个网格恢复到原始朝向（执行步骤 1 的逆变换）。输出完整网格。

**关键洞察**：L 形角落的朝向不只是决定边框图案——它隐式地定义了"主对角线方向"，因为归一化变换同时旋转了对角线种子的位置。相同的种子分布在不同角落朝向下会产生不同方向的条纹图案。

## 新题 8：孔洞计数编程螺旋步长

**组合逻辑**：[计数/counting] + [背景孔洞/background_hole](创新：计数结果不用于选择对象，而是编程螺旋的步长序列) → [螺旋绘制/spiral_drawing] + [方向分色/direction_based_color_split] + [边界截断/boundary_truncation]

**来源原语**：计数、前景块、背景孔洞（358ba94e）；螺旋绘制、中心标记、递增步长、边界截断、方向分色（08573cc6）

**依赖链**：各前景块的孔洞数被计数 → 按块到中心标记的距离排序 → 排序后的孔洞数序列替代默认的递增步长 → 螺旋从中心标记出发按自定义步长绘制。计数结果编程了螺旋几何；块的空间分布决定了计数结果的使用顺序。

用网格中若干前景块的内部孔洞数量作为螺旋的步长序列，按块到中心标记的距离排序后依次驱动螺旋绘制。

**输入结构**：黑(0)背景，约 17x17 的网格。一个红(2)单像素中心标记位于网格中心附近。4 个蓝(1)的小方块（各约 4x4）分布在网格四角附近区域，每个方块内有不同数量的黑(0)孔洞（1-5 个）。网格左上角有 2 个相邻的调色板像素：左为橙(7)，右为绿(3)。生成约束：4 个方块到中心标记的欧氏距离互不相同；各方块孔洞数互不相同；中心标记周围至少有 8 格空间以容纳螺旋起始段；方块不与螺旋可能经过的中心区域重叠。

**规则**：
1. 计算每个蓝(1)方块包围盒内的黑(0)孔洞像素数量，得到 4 个计数值。
2. 按方块包围盒中心到红(2)中心标记的欧氏距离从近到远排序，得到步长序列 S = [s1, s2, s3, s4]。
3. 从中心标记出发绘制螺旋。行进方向依次为：左、下、右、上，循环重复。
4. 前 4 个线段的长度依次为 S 中的 s1, s2, s3, s4（单位：像素格数）。从第 5 个线段起，长度为 s4+1, s4+2, ... 依次递增。
5. 水平线段（左/右）使用橙(7)，垂直线段（下/上）使用绿(3)。
6. 若某线段在绘制过程中即将离开网格边界，则该线段画到边界处即停止，不绘制后续线段。
7. 中心标记红(2)保持不变。调色板像素保持不变。蓝方块保持不变。输出完整网格。

**关键洞察**：蓝色方块不是螺旋路径上的障碍物——它们的内部结构（孔洞数量）远程编程了螺旋的几何形态。方块与螺旋在空间上无直接交互，但通过"孔洞数→步长"的映射产生了跨区域的因果关系。

## 新题 9：十字模板匹配淘汰后裁剪最小幸存矩形

**组合逻辑**：[局部模板匹配/local_template_match] + [重涂色/recolor](创新：模板匹配的结果不是最终输出，而是中间淘汰标记) → [筛选/filtering] + [包含/containment](创新：筛选条件由模板匹配的涂色结果动态决定) → [裁剪/crop] + [最小面积矩形保留/smallest_rect_retained]

**来源原语**：重涂色、十字图案、正交邻接、局部模板匹配（7e02026e）；裁剪、筛选、实心矩形、最小面积矩形保留（23b5c85d）；包含（8efcae92）

**依赖链**：十字模板匹配将符合条件的像素重涂色 → 重涂色区域"污染"了部分矩形 → 被污染的矩形被淘汰 → 在未被污染的矩形中选取面积最小的裁剪输出。模板匹配决定了哪些区域变色；变色区域与矩形的空间包含关系决定了淘汰名单；淘汰后的存活集决定了最终裁剪目标。

在黑/青双色网格中找出所有青色十字图案并涂绿，然后在多个蓝色矩形中淘汰包围盒内含有绿色的矩形，裁剪输出面积最小的未被污染矩形。

**输入结构**：黑(0)背景，约 14x14 的网格。青(8)像素散布于网格中，部分形成十字图案（中心及上下左右 4 邻均为青(8)），部分为孤立点或非十字排列。3-5 个蓝(1)实心矩形（各 2x3 至 5x6 不等，面积互不相同）分布于网格中，矩形之间互不重叠，矩形像素不与青(8)像素重叠。生成约束：至少 1 个蓝矩形的包围盒范围内存在可被模板匹配涂绿的像素（即附近有完整青色十字），至少 2 个蓝矩形的包围盒内不含任何青色十字中心；未被污染的矩形中面积最小者唯一。

**规则**：
1. 扫描所有青(8)像素。若某青(8)像素的上、下、左、右四个邻居均为青(8)，则将该中心及其四个正交邻居全部重涂为绿(3)。重叠的十字区域合并涂绿。
2. 对每个蓝(1)实心矩形，检查其包围盒（含边界）范围内是否存在任何绿(3)像素。
3. 若包围盒内存在绿(3)像素，该矩形被淘汰。
4. 在所有未被淘汰的蓝(1)矩形中，选取像素面积最小的唯一矩形。
5. 将该矩形裁剪为其包围盒大小，输出裁剪后的纯蓝(1)网格。

**关键洞察**：十字模板匹配看似是一个独立的图案识别任务，但其真正作用是在空间上标记"危险区域"——任何包围盒与绿色区域重叠的矩形都被排除，最终输出取决于矩形与十字图案之间的空间远近关系，而非十字图案本身。

## 新题 10：遮挡补全恢复真实面积后压缩为引导条间柱状图

**组合逻辑**：[补全/complete] + [前景遮挡/foreground_occlusion] + [隐含区域重涂/implied_region_recolor](保留：恢复被遮挡像素) → [计数/counting] + [像素数决定长度/pixel_count_length](创新：计数对象从单个内部对象变为多个补全后形状) → [压缩/compress] + [引导条/guide_bar](创新：多条线段并排表示各形状的面积)

**来源原语**：补全、被遮挡形状、矩形足迹、前景遮挡、隐含区域重涂（52df9849）；压缩、重建、像素数决定长度、引导条、线段（c61be7dc）；计数（358ba94e/27a77e38）

**依赖链**：重叠形状的被遮挡部分被补全 → 补全后各形状的真实面积被计数 → 面积值转化为线段长度 → 线段在引导条之间排列成柱状图。遮挡补全决定了正确的面积（不补全则面积偏小）；面积决定线段长度；引导条决定排列方向。

将多个互相遮挡的前景形状补全为完整矩形后，统计各形状的真实像素面积，在两条平行引导条之间用与形状同色的线段表示各面积，形成柱状图。

**输入结构**：黑(0)背景，约 14x18 的网格。3-4 种前景色（如红(2)、绿(3)、黄(4)）各形成一个实心矩形形状，但矩形之间有部分重叠——后绘制的颜色覆盖了先绘制的颜色，导致被遮挡形状看起来不完整。两条灰(5)水平引导条分别位于网格的上部和下部（各占一整行）。生成约束：每个形状的完整矩形足迹内不含背景像素（即被遮挡的像素全被其他前景色占据而非背景）；引导条之间的垂直距离至少为最大形状面积+2；各形状面积互不相同。所有形状位于两条引导条之间。

**规则**：
1. 对每种前景色，确定其完整的矩形足迹：找到该颜色像素的包围盒，若包围盒内所有像素均为非背景色（可能是自身颜色或其他前景色），则该包围盒即为完整矩形足迹。
2. 将包围盒内所有非自身颜色的像素重涂为自身颜色，恢复完整矩形。
3. 计算每个补全后矩形的像素面积。
4. 清空两条灰(5)引导条之间的区域（填充为黑(0)），保留引导条本身。
5. 在两条引导条之间，紧贴上方引导条的下一行开始，为每种颜色画一条垂直线段，长度等于该颜色形状的面积（单位：像素）。
6. 线段从左到右的排列顺序按面积从小到大排列。各线段之间间隔 1 列背景。第一条线段从引导条间区域的第 2 列开始。
7. 每条线段使用对应形状的颜色。输出完整网格。

**关键洞察**：形状的可见面积因互相遮挡而失真，必须先通过包围盒内无背景像素的线索推断完整矩形、恢复被遮挡像素，才能获得正确的面积值。输出的柱状图是对"真实面积"而非"可见面积"的忠实压缩表示。
