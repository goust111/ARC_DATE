## 新题 1：最近标记定向擦除与外翻镜像

**组合逻辑**：[最近邻选择](创新：选择结果不决定颜色，而是决定擦除方位) → [擦除](创新：擦除边由外部标记方位决定，而非固定"最左两列") → [镜像](创新：擦除边即为镜像轴，向外翻转残余部分)

**来源原语**：擦除(erase) ← 52364a65；镜像(reflect) ← f8a8fe49；最近邻选择(nearest_neighbor_selection)、欧氏距离最小(minimum_euclidean_distance) ← 6df30ad6；相对自身定位(self_relative_pos) ← 52364a65

**依赖链**：最近标记的方位决定擦除哪条边 → 擦除后的缺失边成为镜像轴 → 残余像素沿该轴向外翻转并着标记色。三步之间的耦合点是"方位"：它既从最近邻关系中产生，又同时控制擦除的几何范围和镜像的对称轴。

根据每个灰(5)对象最近的彩色标记像素所在方位，擦除该对象朝向标记的那条边界行/列，再将剩余部分沿擦除边向外镜像，镜像副本着标记色。

**输入结构**：黑(0)背景，约 18x18 网格。散布 3~4 个灰(5)色 4-连通前景对象，每个对象为不规则形状（4~8 像素，边界框至少 3x3，无孔洞）。另有若干孤立的彩色标记像素（每种颜色恰好 1 个像素，颜色从蓝(1)、红(2)、绿(3)、黄(4)中选取，标记数量等于灰对象数量）。每个标记像素与恰好一个灰对象的欧氏距离最小（无平局），且标记不与任何灰对象同行同列（标记严格位于灰对象边界框的某一侧：上方、下方、左方或右方，不处于对角位置）。生成约束：各灰对象的边界框互不重叠且间距至少 3 像素；每个灰对象在擦除+镜像后的结果不超出网格边界。

**规则**：
1. 对每个灰(5)对象，计算所有标记像素到该对象任意像素的最小欧氏距离，选距离最小的标记作为该对象的配对标记。
2. 确定配对标记相对于灰对象边界框中心的主方位（上/下/左/右）：若标记行 < 边界框中心行则为"上"，标记行 > 则为"下"，标记列 < 则为"左"，标记列 > 则为"右"。
3. 擦除灰对象中朝向标记方位的边界行或列内的所有像素（设为黑(0)）。具体地："上"方位擦除对象边界框最上一行中属于该对象的像素；"下"擦除最下一行；"左"擦除最左一列；"右"擦除最右一列。
4. 将擦除后剩余的灰像素沿被擦除的那条边向外镜像：以被擦除的行/列所在位置为对称轴，将残余部分翻转到对象外侧。镜像副本的颜色为配对标记的颜色。
5. 保留原始残余灰像素不变。擦除配对标记像素（设为黑(0)）。镜像副本超出网格的部分裁剪丢弃。若多个对象的镜像副本重叠，按对象边界框左上角从左到右、从上到下的顺序绘制（后绘覆盖先绘）。

**关键洞察**：标记像素不提供颜色标签式的简单映射，而是通过其空间位置同时编码了"作用于哪个对象"（最近邻）、"作用于对象的哪条边"（方位）和"镜像副本的颜色"（标记色）三重信息。

## 新题 2：能量受限平移后的间隙桥接

**组合逻辑**：[平移 + 逐步充能](已有原语) → [行列跨度重叠检测](创新：检测对象是平移后的最终位置，而非原始位置) → [填充间隙](创新：填充条件依赖于平移是否因能量耗尽而提前停止)

**来源原语**：平移(translate)、逐步充能(incremental_charge)、能量上限步数(energy_caps_steps)、带边框容器(bordered_container)、目标标记(destination_marker)、颜色匹配配对(color_match_pairing) ← 271d71e2；填充(fill)、行列跨度重叠(row_span_overlap)、间隙区域(gap_region)、无遮挡才填充(fill_if_unobstructed) ← ef135b50

**依赖链**：灰单元格数上限容器的移动距离 → 移动后的最终位置决定哪些容器对有行列跨度重叠 → 只在重叠且无遮挡的容器对之间填充间隙。能量受限使得容器不一定到达目标，由此产生的非对称最终布局使间隙模式无法从初始布局直接推断。

带边框容器沿各自方向平移，灰(5)单元格逐步充能为橙(7)以驱动移动；平移结束后，在行跨度重叠且水平间隙无遮挡的容器对之间填充栗(9)色桥接。

**输入结构**：品红(6)背景，约 20x20 网格。3~4 个黑(0)边框矩形容器（每个约 3x5 ~ 4x6 大小），内部由灰(5)和橙(7)像素混合填充（灰像素数量 1~4 不等，其余为橙）。每个容器的一条短边外侧紧邻一个栗(9)色头部精灵（1 像素），在头部方向的远处沿同一行或列有一个同色栗(9)目标标记像素。头部到目标的方向为该容器的移动方向（仅水平或仅垂直）。生成约束：所有容器的移动方向均为水平（左或右）；容器在充分移动后不会相互碰撞；各目标标记不与任何容器重叠。

**规则**：
1. 对每个容器，确定其头部精灵和目标标记之间的曼哈顿距离 D，以及该容器内部灰(5)像素的数量 G。
2. 该容器沿头部→目标方向平移 min(D, G) 步（每步 1 像素）。每平移一步，将容器内部从头部朝向一侧起算的下一个灰(5)像素改为橙(7)（即从靠近头部的一侧向内依次充能）。
3. 所有容器完成平移后，检查每一对容器：若两个容器的边界框在行方向上有重叠跨度，且在列方向上有间隙（不相邻也不重叠），则该间隙为候选桥接区域。
4. 候选桥接区域定义为：行范围 = 两容器边界框行跨度的交集，列范围 = 两容器边界框之间的空列。
5. 若候选桥接区域内没有被第三个容器的边界框覆盖的行列交叉，则将该区域中所有背景像素涂为栗(9)。
6. 保留所有容器（含边框、充能后的内部）和剩余的头部/目标标记不变。

**关键洞察**：灰单元格数量不同导致容器停在不同位置，因此哪些容器对最终存在行跨度重叠、以及间隙宽度是否被第三方遮挡，都无法从初始布局直接判断——必须先完成能量受限平移才能确定桥接模式。

## 新题 3：十字分割降噪与噪声计数驱动的局部擦除

**组合逻辑**：[压缩 + 十字分隔线检测](已有原语) → [去噪取主色](创新：噪声不只被丢弃，其数量被记录) → [擦除](创新：擦除的列数不是固定值，而是由该象限的噪声像素数决定)

**来源原语**：压缩(compress)、十字分隔线(cross_separator)、四象限(quadrant)、去噪取主色(denoise_majority)、忽略干扰项(ignore_distractors) ← 996ec1f3；擦除(erase)、局部边界列(local_bounding_col)、按对象局部裁切(local_bbox_crop)、相对自身定位(self_relative_pos) ← 52364a65

**依赖链**：十字分隔线将网格分为四象限 → 每象限做降噪以识别主色对象 → 噪声像素计数成为擦除参数 → 对每象限的主色对象从左侧擦除相应列数的像素。降噪步骤的"副产物"（噪声计数）直接参数化了擦除操作的范围，形成信息流分叉——降噪同时产生"干净对象"和"擦除量"两路输出。

找到十字分隔线划分的四象限，在每象限中识别主色对象并计数噪声像素，然后从每个主色对象的局部左边界起擦除与该象限噪声数等量的列。

**输入结构**：黑(0)背景，约 15x15 网格。存在一条完整的灰(5)色横行和一条完整的灰(5)色纵列，交叉形成十字分隔线，将网格分为四个非空矩形象限。每个象限有一个主色 4-连通对象（各象限主色不同，从蓝(1)、红(2)、绿(3)、黄(4)中选取），占据象限面积的多数。每个象限还有 1~3 个噪声像素（颜色与主色不同，也不是黑(0)或灰(5)），散布在象限内。每个主色对象在其局部边界框中至少跨 4 列，以保证擦除后仍有残余。生成约束：每象限的噪声像素数严格小于主色对象的边界框列数。

**规则**：
1. 找到网格中颜色相同且占满整行的那一行和占满整列的那一列（均为灰(5)），确认它们形成十字分隔线。
2. 十字将网格分为四个矩形象限（左上、右上、左下、右下）。
3. 在每个象限中，统计各非背景(0)非分隔(5)颜色的像素数，像素数最多的颜色为该象限的主色，该颜色的所有像素构成主色对象。
4. 计算每象限中所有非背景(0)、非分隔(5)、非主色像素的数量，记为该象限的噪声计数 N。
5. 对每个象限的主色对象，计算其边界框。从该边界框的最左列起，将前 N 列中属于主色对象的像素设为黑(0)（即局部左侧擦除 N 列）。
6. 擦除所有噪声像素（设为黑(0)）。保留十字分隔线不变。

**关键洞察**：噪声不只是需要被过滤的干扰——它的数量直接控制了主色对象被擦除多少，噪声越多的象限其对象损失越大。求解者必须同时理解"降噪"和"噪声计数参数化擦除"这两个角色。

## 新题 4：缺角方位驱动对角平移后的列跨度重涂

**组合逻辑**：[平移](创新：平移方向由形状自身的缺角方位编码，而非外部标记) + [列范围包含](创新：包含关系基于平移后的位置而非原始位置) → [重涂色](创新：同一对象移动前后可能映射到不同控制像素)

**来源原语**：平移(translate)、对角偏移(diagonal_offset)、三连块(triomino)、缺角(missing_corner)、源色决定方向(source_color_decides) ← 1e5d6875；重涂色(recolor)、控制像素(control_pixel)、列范围包含(column_span_contains)、控制色决定填色(control_fill_color) ← ddf7fa4f

**依赖链**：三连块的缺角方位编码对角移动方向 → 移动改变对象的列跨度 → 新列跨度决定该对象落入哪个控制像素的管辖范围 → 控制像素的颜色成为重涂色。形状的几何属性（缺角）同时编码了空间变换和（间接地）颜色结果。

L 形三连块根据缺角方位对角平移一步，平移后根据所在列跨度内的顶行控制像素决定最终颜色。

**输入结构**：黑(0)背景，约 14x14 网格。顶行（第 0 行）有 3~5 个孤立的彩色控制像素（颜色从蓝(1)、红(2)、绿(3)、黄(4)、橙(7)中选取，各不相同），分布在不同列。网格其余区域散布 3~5 个灰(5)色 L 形三连块（每个占据 2x2 格中的 3 个像素，缺失一个角）。生成约束：每个三连块对角平移一步后，其边界框的列跨度恰好包含一个控制像素的列（不含平局）；平移后各三连块互不重叠且不与控制像素重叠；所有三连块平移后不超出网格边界。

**规则**：
1. 识别顶行（第 0 行）中所有非背景像素，记为控制像素及其颜色和列号。
2. 识别所有灰(5)色 4-连通三连块。每个三连块占据 2x2 边界框中的 3 像素，缺失的那个像素位置为缺角。
3. 每个三连块沿缺角方向对角平移 1 步。即：若缺角在三连块的右下角，则整个三连块向右下移动 1 像素（行+1，列+1）；缺角在左下角则向左下（行+1，列-1）；缺角在右上角则向右上（行-1，列+1）；缺角在左上角则向左上（行-1，列-1）。
4. 计算每个平移后三连块的边界框列范围 [c_min, c_max]。
5. 找到列号落在 [c_min, c_max] 内的唯一控制像素，将该三连块所有像素重涂为该控制像素的颜色。
6. 保留控制像素不变。原始位置的灰像素设为黑(0)（对象已移走）。

**关键洞察**：三连块的形状（缺角方位）不仅决定它往哪个方向移动，还间接决定它最终被涂成什么颜色——因为移动改变了列跨度，进而改变了与控制像素的对应关系。仅看原始位置会得到错误的颜色映射。

## 新题 5：长度排名重涂与排名相邻条件桥接

**组合逻辑**：[排序 + 长度排名](已有原语) → [重涂色](已有原语) + [排名相邻判断](创新：原语池中"排名决定颜色"被扩展为"排名关系决定是否桥接") → [填充间隙](创新：间隙填充的前提不再仅是空间无遮挡，还要求排名相邻)

**来源原语**：排序(sorting)、长度排名(length_ranking)、排名决定颜色(rank_determines_color)、细条(thin_bar) ← ea32f347；填充(fill)、行列跨度重叠(row_span_overlap)、间隙区域(gap_region)、无遮挡才填充(fill_if_unobstructed) ← ef135b50

**依赖链**：排序产生排名 → 排名决定颜色（视觉输出）→ 排名同时决定哪些条对是"排名相邻"→ 只在排名相邻且行跨度重叠且无遮挡的条对之间填充间隙。排名信息分叉为两路：一路决定颜色，另一路决定桥接资格。

按长度排名重涂细条颜色，然后仅在排名相邻（排名差恰好为 1）且行跨度重叠的条对之间填充无遮挡间隙。

**输入结构**：黑(0)背景，约 16x16 网格。5 根灰(5)色一像素宽直线条（细条），可为水平或垂直，长度各不相同（3~10 像素不等）。条之间互不接触，各自边界框间距至少 1 像素。至少有两对条在行跨度上有重叠（即边界框行范围有交集且列范围不接触）。生成约束：不存在三根条 A、B、C 使得 A 和 C 排名相邻、行跨度重叠、但 B 的边界框横跨 A-C 的水平间隙且 B 与 A 和 C 的行跨度也重叠（即不出现真正的遮挡歧义——遮挡只由非相邻排名的条造成）。

**规则**：
1. 找到所有灰(5)色 4-连通细条，计算每根条的像素数（即长度）。
2. 按长度从大到小排名：最长为排名 1，次长为排名 2，依此类推至排名 5。
3. 重涂色：排名 1 → 蓝(1)，排名 2 → 红(2)，排名 3 → 黄(4)，排名 4 → 绿(3)，排名 5 → 橙(7)。
4. 对每对排名差恰好为 1 的条（即排名相邻对），检查它们的边界框行跨度是否有交集。若有交集，计算它们之间的水平间隙区域（行范围 = 行跨度交集，列范围 = 两者边界框之间的空列）。
5. 对每个候选间隙区域，检查是否有第三根条的边界框在列方向上穿越该间隙且在行方向上与该间隙行范围有交叉。若无遮挡，将间隙区域涂为栗(9)。
6. 保留所有重涂后的条不变。

**关键洞察**：排名不仅是颜色标签——它定义了"邻接关系"，而这种邻接关系与空间上的行跨度重叠共同构成桥接的双重条件。仅靠空间关系或仅靠排名都无法确定哪些间隙被填充。

## 新题 10：行色段对齐与对齐后暴露的全空列涂色

6. 对每个红(2)列，向左逐列扩展：检查左侧相邻列是否全为蓝(1)（不含绿或黄），若是则也涂为红(2)，继续向左；遇到含绿(3)或黄(4)的列时停止。同理向右逐列扩展。
7. 保留所有绿(3)和黄(4)像素不变。

**关键洞察**：对齐操作压缩了绿色段的水平分布，在左侧制造了纯蓝(1)区域。这些区域中的全同色列成为红色扩展的种子，而扩展范围取决于绿/黄前景像素在对齐后的列分布——这是一个对齐前无法预测的结果，因为不同行的绿色段宽度相同但原始偏移不同。
