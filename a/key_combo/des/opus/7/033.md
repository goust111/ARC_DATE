## 新题 1：格子多数色构建孔洞形状的分区填色图

**组合逻辑**：[多数决/majority_vote] → [边界框推断/bbox_inference](创新：多数决结果作为分区填色映射) → [填充/fill](创新：孔洞模式匹配决定格子对位) → [补全/complete]

**来源原语**：多数决/majority_vote、格子格局/lattice_layout、每块取唯一多数色/majority_color_per_block（来自 af24b4cc）；边界框推断/bbox_inference、补全/complete、缺失像素补新色/missing_new_color（来自 6d75e8bb）；填充/fill、封闭孔洞/enclosed_hole（来自 aa4ec2a5）

**依赖链**：格子多数决压缩出一个 R x C 的颜色矩阵，同时压缩矩阵中的黑(0)单元标识了"空位"。独立的前景形状被等分为 R x C 个子区域，其中一些子区域已经是孔洞（背景色）。空位模式与已有孔洞模式的匹配确定了格子与形状的对齐方式，然后每个非空位子区域被重涂为对应格子单元的多数色，同时在空位处打出新孔洞。

将格子的多数色压缩结果作为另一个形状的分区填色指令，且利用孔洞模式匹配来建立两者的空间对应关系；格子中的空位同时承担"孔洞位置编码"和"对齐锚点"双重角色。

**输入结构**：黑(0)背景网格，约 25x25。网格分为两个区域：(1) 左半区有一个由灰(5)分隔行列划分的 R x C（约 3x4 至 4x5）格子，每个格子块约 3x3 至 5x5 像素，内部填有带噪声的多色像素（每块有一个明确的多数色，多数色从蓝(1)、红(2)、绿(3)、黄(4)、橙(7)中取），其中 2-3 个格子块的所有像素均为黑(0)（即"空块"）。(2) 右半区有一个 4-连通的单色（青(8)）前景形状，其边界框恰好可等分为与格子相同的 R x C 个子区域，其中一些子区域已经是完全的背景色孔洞。生成约束：格子中空块的位置模式在形状的所有可能对齐方式中是唯一的——即空块集合与形状已有孔洞集合存在唯一的行列偏移使空块位置是已有孔洞位置的超集。形状已有孔洞数量少于格子空块数量（至少有一个空块对应形状中尚未存在的孔洞）。

**规则**：
1. 在灰(5)分隔线划分的格子中，对每个非空块取其像素的唯一多数色，得到一个 R x C 的颜色矩阵，空块记为黑(0)。
2. 将右半区青(8)形状的边界框等分为 R x C 个子区域（从边界框左上角开始，每个子区域大小 = 边界框尺寸 / (R, C)，向下取整；余数像素归入最后一行/列的子区域）。
3. 找到颜色矩阵中黑(0)单元位置集合与形状中已有孔洞（全为背景色的子区域）位置集合之间的唯一行列偏移，使得所有已有孔洞位置加偏移后都落在黑(0)单元上。
4. 根据步骤 3 确定的对齐关系，对形状的每个非孔洞子区域：若对应颜色矩阵单元为非黑色，则将该子区域内所有青(8)像素重涂为该多数色；若对应颜色矩阵单元为黑(0)，则将该子区域内所有青(8)像素擦除为黑(0)（打出新孔洞）。
5. 已有孔洞保持不变。格子区域（包括分隔线）在输出中保持不变。

**关键洞察**：格子中的"空块"既是"此处无颜色信息"的标记，又是与形状孔洞进行模式匹配的锚点——求解者必须先完成多数决压缩才能识别空块位置，再利用空块与已有孔洞的对应关系才能确定格子与形状之间的行列映射。

## 新题 2：翻转方向决定填色的拼块嵌合

**组合逻辑**：[形状嵌合/shape_fitting] + [镜像/mirror](创新：嵌合所需的翻转类型编码为输出颜色) → [重涂色/recolor]

**来源原语**：形状嵌合/shape_fitting、互补拼合/complement_fit、拼块填孔洞后变色/pieces_fill_holes_recolor（来自 6a1e5592）；镜像/mirror、翻转对应/flip_correspond（来自 cfb2ce5a）；重涂色/recolor（来自多题）

**依赖链**：每个灰色拼块需要在四种朝向（原始、水平翻转、垂直翻转、双轴翻转）中尝试嵌入红色形状的孔洞。能够嵌合的唯一朝向决定了拼块放置后的涂色：翻转类型本身就是颜色编码。不做嵌合就无法确定翻转类型，不确定翻转类型就无法确定输出颜色。

尝试多种翻转朝向的嵌合搜索本身成为颜色编码的信息源，形状匹配过程与颜色输出融为不可分割的推理。

**输入结构**：黑(0)背景网格，约 20x20。网格中央有一个红(2)的 4-连通前景形状（约占网格面积的 30%-40%，非矩形，有复杂轮廓），其边界框内部有 3-4 个不重叠的矩形孔洞（全黑区域，每个孔洞 2x3 至 4x5 像素不等，形状各异）。网格边缘散布 3-4 个灰(5)的小型 4-连通拼块（每块 3-8 像素），每个拼块恰好在四种二面体变换（原始、水平翻转、垂直翻转、180 度旋转）中有且仅有一种能无碰撞地嵌入某个孔洞并完全覆盖该孔洞。生成约束：每个孔洞恰好被一个拼块匹配，每个拼块恰好匹配一个孔洞；不同拼块所需的翻转类型不全相同（至少覆盖两种不同的翻转类型）。拼块的原始朝向与目标孔洞的形状不同，必须经过特定翻转才能匹配。

**规则**：
1. 裁剪每个灰(5)拼块的最小边界框。
2. 对每个拼块，在四种朝向下尝试放入每个孔洞：将拼块对齐到孔洞左上角，检查拼块前景像素是否恰好覆盖孔洞的所有黑(0)像素且不与红(2)像素碰撞。找到唯一匹配的（拼块, 孔洞, 朝向）三元组。
3. 将拼块以匹配的朝向粘贴到对应孔洞位置，按以下规则涂色：
   - 无需翻转（原始朝向匹配）：涂蓝(1)
   - 需水平翻转（左右镜像）：涂绿(3)
   - 需垂直翻转（上下镜像）：涂黄(4)
   - 需双轴翻转（等价于 180 度旋转）：涂橙(7)
4. 红(2)形状保持不变。原始灰(5)拼块位置擦除为黑(0)。

**关键洞察**：颜色不是由拼块或孔洞的固有属性决定的，而是由"哪种翻转操作才能让拼块嵌入孔洞"这个搜索过程的结果决定的——求解者必须对比多个示例才能归纳出翻转类型与颜色的对应关系。

## 新题 3：对接拼装后的孔洞检测驱动描边与内填

**组合逻辑**：[拼接/stitch + 同色标记对齐对接/same_color_dock] → [封闭孔洞检测](创新：孔洞仅在对接后才涌现) → [有孔触发重涂/hole_presence_triggers_recolor + 描边/draw_outline + 填充/fill]

**来源原语**：拼接/stitch、同色标记对齐对接/same_color_dock、连接标记/connector_marker、标记侧面决定方向/marker_side_dir（来自 e9fc42f2）；描边/draw_outline、有孔触发重涂/hole_presence_triggers_recolor、封闭孔洞/enclosed_hole、包含关系/containment（来自 aa4ec2a5）；填充/fill（来自多题）

**依赖链**：多个分离的前景物体各自没有封闭孔洞，但通过连接标记对接拼装后，某些物体组合围出了封闭的背景孔洞。孔洞的存在触发了围合物体的重涂色和孔洞的填色，随后对整个拼装体描边。哪些物体参与围合、孔洞在哪里，都只有在完成对接后才能判断。

对接操作创造了单个物体中不存在的拓扑结构（封闭孔洞），该涌现结构反过来触发后续的颜色变换，形成"组装→拓扑涌现→条件触发"的推理链。

**输入结构**：黑(0)背景网格，约 22x22。网格中散布 4-6 个互不相邻的 4-连通多色前景物体，每个物体约 8-20 像素。所有物体共享同一种主体色（蓝(1)），但每个物体边界上有 1-2 个不同颜色的连接标记像素（从红(2)、绿(3)、黄(4)、橙(7)中取）。每种连接标记颜色恰好出现两次（分别在两个不同物体上），或出现一次（自由端，不参与对接）。标记像素位于物体的最外层像素（上/下/左/右边界），标记所在的边决定了对接方向。生成约束：每个物体单独看不含封闭的背景孔洞（即物体的 4-连通补集只有一个连通分量），但按连接标记对接拼装后，至少有一组物体（2-3 个）围出 1-2 个封闭的 4-连通背景孔洞。至少有一个物体对接后不参与围合任何孔洞。

**规则**：
1. 对每种出现两次的连接标记颜色，找到携带该标记的两个物体。确定每个标记像素在其物体中的边界方向（标记像素暴露的一侧：若标记在物体最上一行则方向为上，以此类推）。
2. 平移物体使两个同色标记像素在各自暴露方向上相邻（面对面接触）。对接后两个标记像素保留，物体其余部分保持原样。处理顺序：按标记颜色在调色板中的编号从小到大依次对接（先处理红(2)，再绿(3)，依此类推）。每次对接时固定已对接部分的位置，平移尚未连接的物体。
3. 拼装完成后，检测整个拼装体（所有已对接物体组成的 4-连通整体）内部的封闭 4-连通背景孔洞。
4. 对于包含封闭孔洞的拼装体：将所有参与围合该孔洞的物体像素（主体色蓝(1)和标记色）中的蓝(1)像素重涂为青(8)，标记像素颜色不变；将封闭孔洞填充为品红(6)。
5. 不参与围合任何孔洞的物体保持蓝(1)不变。
6. 最后，对整个拼装体（含重涂和填充后的所有像素）绘制一圈红(2)的 8-邻域描边（距拼装体像素 8-邻域距离为 1 的背景像素涂红(2)）。未参与对接的自由端物体也单独描边。

**关键洞察**：单个物体都不含孔洞——封闭孔洞是对接拼装后的涌现结构，因此重涂和填充的触发条件只有在完成空间组装后才能判定。

## 新题 4：对角线阻挡射线分区配合图例优先级填色

**组合逻辑**：[射线延伸/ray_extend + 对角线上阻挡/on_diagonal_blocking + 阻挡点发射正交线/blocker_emits_orthogonal_line] → [区域分割](创新：正交射线将网格分割为区域) → [图例配色/legend_color_pair + 图例顺序决定层级/legend_order_layer](创新：图例行序决定分区填色优先级) → [填充/fill]

**来源原语**：射线延伸/ray_extend、对角线对齐/diagonal_alignment、对角线上阻挡/on_diagonal_blocking、阻挡点发射正交线/blocker_emits_orthogonal_line（来自 55783887）；图例/legend、图例配色/legend_color_pair、图例顺序决定层级/legend_order_layer、冲突优先级/conflict_priority（来自 305b1341）；扩展/expand、填充/fill（来自 305b1341）

**依赖链**：主对角线上的阻挡像素发射正交对角线，这些正交线将网格切分成若干不规则区域。每个阻挡像素的颜色在图例中对应一种填充色，图例的行序决定了当多条正交线重叠划分出争议区域时哪种颜色优先。区域几何完全由射线决定，填色规则完全由图例决定，两者缺一不可。

射线发射创造了空间分区的几何结构，而图例提供了语义层级信息；几何与语义在"争议区域的颜色决定"这一节点上紧密耦合。

**输入结构**：黑(0)背景网格，约 20x20。(1) 网格左上角或右上角有一个由灰(5)背景围成的小矩形图例区域（约 2-4 行 x 2 列），每行左列为一种阻挡色（从红(2)、绿(3)、黄(4)、橙(7)中取），右列为对应的填充色（从蓝(1)、品红(6)、青(8)、栗(9)中取，不与阻挡色重复）。图例行数 = 阻挡像素数量，约 2-4 行。(2) 网格中有两个同色像素（灰(5)）定义一条主对角线段的两个端点，端点沿某条对角线方向排列（45 度或 135 度）。(3) 主对角线段上（两端点之间，不含端点）有 2-4 个不同颜色的阻挡像素，颜色恰好是图例左列的阻挡色。生成约束：阻挡像素的颜色互不相同；主对角线段足够长（端点间至少相隔 8 个对角步），使正交射线能将网格分割出明确的区域。

**规则**：
1. 在两个灰(5)端点之间绘制灰(5)主对角线段，保留段上已有的阻挡像素颜色不变。
2. 每个阻挡像素向其所在对角线的两个正交对角方向（即与主对角线垂直的两个 45 度方向）发射射线，射线以阻挡像素自身颜色绘制，延伸直到碰到网格边界为止。射线不覆盖已有的非背景像素。
3. 所有射线和主对角线将网格的背景区域分割成若干 4-连通区域。对于每个区域，确定"距该区域最近的阻挡像素"——即区域中任一背景像素到各阻挡射线的最小切比雪夫距离对应的阻挡像素。
4. 从图例中查找该阻挡像素颜色对应的填充色，将整个区域填充为该填充色。
5. 若一个区域与多条不同阻挡像素的正交射线等距（tie），则按图例行序决定优先级：图例中行号更小（更靠上）的阻挡色优先。
6. 图例区域本身在输出中保持不变。灰(5)主对角线和阻挡像素的射线保持不变。

**关键洞察**：正交射线的几何分区方式取决于阻挡像素在主对角线上的位置分布，而每个分区的填充颜色取决于图例中的配色与行序——求解者必须同时理解空间分割逻辑和图例优先级语义才能确定输出。

## 新题 5：不完整矩形补全后按标记计数决定棋盘相位

**组合逻辑**：[补全/complete + 边界框推断/bbox_inference] → [计数/counting](创新：标记像素数量编码棋盘相位) → [棋盘格填充/parity_fill + 边框与内部分离/border_interior_split] → [擦除/erase]

**来源原语**：补全/complete、边界框推断/bbox_inference、缺失像素补新色/missing_new_color（来自 6d75e8bb）；棋盘格图案/checkerboard、行列奇偶决定填充/parity_fill、边框与内部分离/border_interior_split、实心矩形/solid_rectangle（来自 ba9d41b8）；计数/counting（来自 f3cdc58f）；标记像素/marker_pixel（来自 36fdfd69）；擦除/erase（来自 952a094c）

**依赖链**：先推断边界框并补全矩形边框，确定哪些像素属于内部；然后计数内部的标记像素数量，该计数的奇偶性决定棋盘图案的相位；最后在内部应用对应相位的棋盘镂空并擦除标记。补全决定了内部范围，计数决定了棋盘朝向，两者缺一不可。

边界框推断→补全→内部确定→标记计数→棋盘相位，形成环环相扣的信息链，每一步的输出都是下一步的必要输入。

**输入结构**：黑(0)背景网格，约 18x18。网格中有 3-4 个不完整的单色矩形，每个矩形使用不同的非黑、非红颜色（从蓝(1)、绿(3)、黄(4)、青(8)中取）。"不完整"指矩形边框的 1-3 条边上有像素缺失（被黑(0)替代），但每条边至少保留一个像素使边界框可唯一推断。每个矩形至少 5x5（边框 1 像素宽，内部至少 3x3）。矩形互不重叠且边界框互不相交。每个矩形的边界框内部（不含边框像素）散布有 1-4 个红(2)标记像素，位于内部的不同位置。生成约束：同一个矩形内部的标记像素数量在不同示例中可能不同，但同一道题内不同矩形的标记数量至少有两个不同值（保证奇偶性不全相同）。

**规则**：
1. 对每种前景色，找到该颜色所有像素的最小边界框——这就是该矩形的完整边界。
2. 补全边框：将边界框四条边上所有缺失的像素（黑(0)）填充为该矩形的颜色。
3. 统计每个矩形边界框严格内部（不含边框）的红(2)标记像素数量 K。
4. 对每个矩形的严格内部，以内部左上角为原点，对每个内部像素计算 (local_row + local_col) 的值：
   - 若 K 为奇数：(local_row + local_col) 为偶数的内部像素设为黑(0)（背景色），其余保持矩形颜色
   - 若 K 为偶数：(local_row + local_col) 为奇数的内部像素设为黑(0)（背景色），其余保持矩形颜色
5. 所有红(2)标记像素在输出中擦除为黑(0)（无论其位置是否被棋盘规则保留）。
6. 矩形边框像素始终保留，不受棋盘规则影响。

**关键洞察**：红色标记的数量——而非位置——决定了棋盘镂空的相位；求解者必须从多个示例中归纳出"标记计数的奇偶性控制棋盘对齐方式"这条隐蔽规则。

## 新题 6：重复图案格点解码配合逐图案旋转重建

**组合逻辑**：[解码/decode + 槽位决定颜色/slot_determines_color](创新：槽位同时编码颜色和旋转角度) → [旋转/rotate](创新：每个格点独立旋转) → [重建格子/lattice_layout]

**来源原语**：解码/decode、重复图案/repeated_motif、色彩图例/color_legend、内部槽位/internal_slot、槽位决定颜色/slot_determines_color、图例映射/legend_mapping（来自 1be83260）；旋转/rotate（来自 103eff5b）；格子格局/lattice_layout（来自 af24b4cc）

**依赖链**：标记图案的内部槽位编码了两种信息：奇行奇列槽位的颜色决定对应格点图案的涂色（与源题相同），而每个图案四角之一的特殊标记像素决定该图案的旋转角度。解码颜色和解码旋转必须同时从同一个标记图案中提取，然后每个格点独立旋转后重建。颜色解码和旋转解码共享信息源但产生不同维度的控制指令。

同一个编码结构（标记图案的槽位）同时承载颜色维度和空间变换维度的信息，解码过程本身就是多逻辑交织的。

**输入结构**：黑(0)背景网格，约 20x25。网格中有一个紧凑的图案格点阵列，由 R x C（约 3x3 至 4x4）个相同的小图案（motif）组成，图案之间由一行/列背景色分隔。每个图案大小为 (2R'+1) x (2C'+1)，其中 R'=R, C'=C（即图案内部的奇行奇列槽位数等于格点阵列维度）。图案由单一的前景色（灰(5)）绘制在黑(0)背景上，是一个非对称的 4-连通小图形（约 5x5 至 9x9，非矩形，不具有 90 度旋转对称性，以便旋转后可区分方向）。其中恰好一个图案是"标记图案"，其内部的 R' x C' 个奇行奇列槽位中被填入了不同颜色的像素（从蓝(1)、红(2)、绿(3)、黄(4)、橙(7)、品红(6)、青(8)中取）；未被标记的槽位保持灰(5)（表示该格点保持原图案色）。此外，每个图案（包括标记图案）的四个角像素中恰好有一个角像素被涂为栗(9)——该角像素的位置编码旋转角度：左上角=0度，右上角=顺时针90度，右下角=180度，左下角=顺时针270度。生成约束：图案不具有 90 度旋转对称性；不同图案的栗(9)角标记可在不同角落（即不同图案可有不同旋转角度）。

**规则**：
1. 识别图案格点阵列的维度 R x C 和单个图案的尺寸。
2. 找到标记图案（内部槽位含有非灰(5)颜色的图案），读取其 R x C 个奇行奇列槽位的颜色，构建颜色矩阵 ColorMap[r][c]。灰(5)槽位在 ColorMap 中记为灰(5)。
3. 对于格点阵列中位置 (r, c) 的每个图案，读取其栗(9)角标记的位置，确定旋转角度 Angle[r][c]。
4. 重建输出：创建与输入同尺寸的网格，背景为黑(0)。对于每个格点位置 (r, c)：
   a. 取原始图案的灰(5)掩码（不含角标记的栗(9)像素）
   b. 将掩码以图案中心为原点旋转 Angle[r][c] 度
   c. 将旋转后的掩码像素涂为 ColorMap[r][c] 对应的颜色
   d. 放置到输出网格的对应格点位置
5. 栗(9)角标记在输出中不保留（被背景覆盖或被旋转后的图案覆盖）。格点间的分隔线保持为背景色。

**关键洞察**：标记图案的槽位提供颜色信息，而散布在每个图案角落的栗色标记提供旋转信息——两种编码嵌入在同一个格点结构中，必须同时提取才能正确重建输出。

## 新题 7：标记框选矩形重涂后沿分隔线方向射线延伸

**组合逻辑**：[标记围定区域重涂/marker_bounded_rect_recolor](创新：重涂色取决于矩形相对于分隔线的位置) → [射线延伸/ray_cast + 朝向与背离/toward_and_away](创新：射线方向由矩形与分隔线的相对位置决定，射线颜色为重涂前的原始色) → [擦除/erase]

**来源原语**：标记围定区域重涂/marker_bounded_rect_recolor、标记像素/marker_pixel、填充矩形/filled_rectangle、包围框内部/inside_bbox（来自 36fdfd69）；射线延伸/ray_cast、分隔线/divider_line、朝向与背离/toward_and_away、颜色决定射线方向/color_determines_ray_direction（来自 8d510a79）；擦除/erase（来自 952a094c）

**依赖链**：先通过红色标记识别"活跃矩形"并将其内部非红像素重涂为黄色，但重涂前必须记住每个矩形的原始体色——因为原始体色将成为从矩形中心发射的射线颜色。射线方向由矩形与灰色分隔线的相对位置决定：矩形朝向分隔线的一侧发射原始体色射线，背离分隔线的一侧发射黄色射线。重涂操作改变了矩形外观但其原始颜色信息通过射线保存下来。

标记检测→原始色记忆→重涂→射线方向判定→射线颜色分配，形成一条需要"回溯引用已擦除信息"的推理链。

**输入结构**：黑(0)背景网格，约 20x20。(1) 一条完整的灰(5)水平线或垂直线横贯网格（分隔线），将网格分为两半。(2) 两半各有 1-3 个实心填充矩形（至少 3x3），每个矩形由单一非黑非灰非红非黄颜色填充（从蓝(1)、绿(3)、橙(7)、青(8)中取，不同矩形可同色也可异色）。部分矩形（"活跃矩形"）的四条边上各至少有一个红(2)标记像素嵌在边框中（标记像素替换了该位置的矩形色像素）；其余矩形（"惰性矩形"）无红色标记。活跃矩形至少 2 个，惰性矩形至少 1 个。生成约束：矩形互不重叠，与灰(5)分隔线不重叠，矩形边框不紧贴网格边界（至少留 1 像素间距）。活跃矩形中至少有两个不同的原始体色。

**规则**：
1. 识别活跃矩形：一个矩形是"活跃"的当且仅当其上、下、左、右四条边各至少含一个红(2)像素。记录每个活跃矩形的原始体色（边框上非红像素的颜色）。
2. 将每个活跃矩形内部（含边框）的所有非红(2)像素重涂为黄(4)。红(2)标记像素保留。
3. 对每个活跃矩形，从其几何中心像素（行中位数、列中位数，向下取整）发射两条正交射线（沿分隔线的法线方向，即若分隔线水平则射线为上/下，若分隔线垂直则射线为左/右）：
   - 朝向分隔线的射线：使用该矩形的原始体色绘制
   - 背离分隔线的射线：使用黄(4)绘制
4. 射线从中心像素出发，逐像素延伸直至碰到以下任一条件时停止（不含终止像素）：网格边界、灰(5)分隔线、任何非背景非射线像素（其他矩形或其他射线的像素）。
5. 惰性矩形保持原样不变，但作为射线的障碍物阻挡射线。
6. 灰(5)分隔线保持不变。

**关键洞察**：活跃矩形的原始体色在重涂为黄色后"消失"了，但它通过朝向分隔线的射线被"记住"并重新显现——求解者必须推断出射线颜色来自重涂前的矩形原色，而非当前可见的黄色。

## 新题 8：四重旋转对称补全中标记像素阻断填充

**组合逻辑**：[补全/complete + 镜像/mirror](创新：四重旋转对称而非简单镜像) → [标记像素阻断](创新：标记位置阻止对称位的填充) → [擦除/erase] → [冲突解决]（同时约束满足结构，非线性流水线）

**来源原语**：补全/complete（来自 6d75e8bb）；镜像/mirror、翻转对应/flip_correspond（来自 cfb2ce5a）；标记像素/marker_pixel（来自 36fdfd69）；擦除/erase（来自 952a094c）；控制定颜色映射/ctrl_color_map（来自 cfb2ce5a）

**依赖链**：网格具有近似四重旋转对称性但有缺损和标记像素。补全对称性需要将已有像素旋转复制到缺损位置，但标记像素会阻止其旋转对称位的填充——标记位置本身也变为背景。这形成了一个同时约束满足问题：每个像素位置的最终状态取决于其四个旋转对称位中是否有已知颜色像素和是否有标记像素，两种信息相互制约。

对称性填充规则与标记阻断规则在同一像素位置上可能冲突，产生的"被阻断的空洞"是两条规则交互的涌现结果。

**输入结构**：黑(0)背景的正方形网格，边长为奇数（约 13x13 至 17x17），中心像素为网格中心。网格上有一个围绕中心的彩色图案，图案使用 2-3 种非黑非红颜色（从蓝(1)、绿(3)、黄(4)、青(8)、橙(7)中取）。该图案具有近似的 90 度旋转对称性（以网格中心为旋转中心），但有若干缺损：部分本应有像素的位置是黑(0)背景。此外，网格中有 2-4 个红(2)标记像素，位于图案的非缺损位置上（即标记像素替换了原本应有的彩色像素）。生成约束：对于每个旋转对称组（由同一位置旋转 0/90/180/270 度得到的四个格点），至少有一个格点包含非黑非红的彩色像素（保证对称性可推断）。标记像素的四个旋转对称位中，至少有一个位置是缺损（黑色），使标记阻断效果可观察。

**规则**：
1. 确定网格中心为旋转中心。对于网格中每个像素位置 P，其旋转对称组包含 P 本身及 P 绕中心旋转 90/180/270 度后的三个位置（共四个位置，若 P 在中心则组只有一个位置）。
2. 对每个旋转对称组，收集组内所有非黑(0)非红(2)的彩色像素。若组内有彩色像素，则该组的"目标色"为该彩色像素的颜色（生成约束保证同组内若有多个彩色像素则颜色相同）。
3. 对组内每个缺损位置（黑(0)），检查该组内是否有红(2)标记像素：
   - 若组内无红(2)标记：将所有缺损位置填充为目标色
   - 若组内有红(2)标记：所有缺损位置保持黑(0)不填充
4. 组内的红(2)标记像素在输出中擦除为黑(0)。
5. 组内原有的彩色像素保持不变。
6. 若旋转对称组内全为黑(0)和/或红(2)（无彩色像素），则该组所有位置在输出中均为黑(0)。

**关键洞察**：红色标记不仅自身消失，还会"传染性地"阻止同一旋转对称组中所有缺损位置的填充——求解者必须理解标记的阻断作用是按旋转对称组整体生效的，而非仅影响标记的直接对称位。
