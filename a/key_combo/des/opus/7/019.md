## 新题 1：墙壁双功能——分区定面积、阻挡定射程

**组合逻辑**：[墙分隔区域](已有) → [极值面积决定颜色](创新：从二值极值扩展为全序排名映射) → [射线延伸](创新：射线被分隔墙阻挡而非被分隔线阻挡，颜色由区域面积排名决定而非种子原色) ← [分隔墙](创新：同一结构同时承担区域划分和射线屏障双重功能)

**来源原语**：射线延伸 ← 05a7bcf2/53fb4810 | 重涂色 ← 62ab2642/d406998b | 连通区域 ← 62ab2642 | 分隔墙 ← 62ab2642 | 极值面积决定颜色 ← 62ab2642 | 标记像素 ← 3e980e27 等

**依赖链**：灰色墙壁定义 4-连通区域的边界 → 计算各区域面积并全序排名 → 排名决定每个区域内种子射线的发射颜色；同时，墙壁物理阻挡射线传播 → 射线只在自身区域内展开。墙壁的几何结构同时约束了"面积如何计算"和"射线能到达哪里"，删除任一环节都无法求解。

在由墙壁分隔的多个区域中，每个种子向四方发射射线（遇墙停止），射线颜色由该区域的面积排名决定而非种子原色。

**输入结构**：约 12x12 的网格，黑(0)背景。灰(5)像素形成一像素宽的连通墙壁网络，将黑色区域分割为 4~6 个不等大小的 4-连通区域。每个区域内恰好有一个彩色种子像素（颜色各不相同，可为蓝(1)、红(2)、绿(3)、黄(4)、橙(7)、品红(6)等）。生成约束：各区域面积互不相等；每个区域内恰好一个种子像素；种子像素不与灰色墙壁 4-连通相邻的行或列末端。

**规则**：
1. 找出灰(5)墙分隔的所有 4-连通黑(0)区域，计算每个区域的像素数（面积），不含种子像素本身。
2. 按面积从小到大排列区域，排名 1 为最小，排名 K 为最大（K 为区域总数）。
3. 每个种子像素向上、下、左、右四个方向逐格发射射线。射线遇到灰(5)墙像素或网格边界时停止，不包含终止位置的像素。
4. 射线颜色由区域面积排名决定，而非种子原色：排名 1 → 红(2)，排名 2 → 蓝(1)，排名 3 → 绿(3)，排名 4 → 黄(4)，排名 5 → 橙(7)，排名 6 → 品红(6)。
5. 种子像素本身也被重涂为其对应的排名颜色。
6. 灰(5)墙像素保持不变。未被射线覆盖的黑(0)像素保持黑色。

**关键洞察**：种子的原色是干扰项——真正决定输出颜色的是该种子所在区域的面积排名。墙壁承担双重功能：既是区域边界（用于面积计算），又是射线屏障（限制传播范围），同一几何结构同时约束两个独立的推理步骤。

## 新题 2：自计数缩放与异尺度中心叠加

**组合逻辑**：[计数](创新：每个对象独立计数作为自身专属的缩放因子，而非全局统一计数) → [像素放大](创新：缩放倍率因对象而异) → [透明叠加·中心对齐](创新：叠加的图案尺寸各不相同，绘制顺序由像素数决定)

**来源原语**：像素放大 ← ac0a08a4/bf45cf4b | 计数 ← ac0a08a4 | 透明叠加 ← c8cbb738 | 中心对齐 ← c8cbb738 | 前景掩码 ← c8cbb738 | 数量决定倍率 ← ac0a08a4 | 多色掩码合并 ← c8cbb738

**依赖链**：每个颜色簇独立计数像素数 N → N 作为该簇专属的像素放大系数（不同簇倍率不同）→ 缩放后各图案尺寸各异 → 按像素数从大到小依次中心对齐绘制，像素数最少的簇最后画（显示在最顶层）。计数同时决定了缩放倍率和叠加顺序，两者不可独立确定。

每个颜色簇按自身像素数进行像素放大，然后所有放大后的簇按像素数降序中心对齐叠加到同一画布上，像素最少的簇显示在顶层。

**输入结构**：约 15x15 的网格，黑(0)背景。网格中有 3 个空间上互不 4-连通相邻的单色簇，颜色分别为红(2)、蓝(1)、绿(3)。每个簇为一个 4-连通的小图形（2~4 个像素，非对称形状，如 2 个像素组成的水平/垂直对、3 个像素组成的折线形、4 个像素组成的不规则块等）。生成约束：三个簇的像素数互不相等（如分别为 2、3、4）；各簇在输入中的位置对输出无影响。

**规则**：
1. 对每种非背景颜色，找到其 4-连通簇，裁剪到边界框，并计数像素数 N。
2. 对每个裁剪后的图案进行 N 倍像素放大：图案中每个像素（无论有色还是黑色背景）都变为 N x N 的方块（有色像素变为同色方块，黑色像素变为黑色方块）。
3. 输出画布为正方形，边长等于所有放大结果中最大边长，填充黑(0)。
4. 按像素数从大到小的顺序依次将放大结果中心对齐绘制到画布上：像素数最多的簇先画（底层），像素数最少的簇最后画（顶层）。后画的非黑(0)像素覆盖先画的。
5. 若放大结果小于画布，四周用黑(0)填充使其居中（行列方向各取较小偏移量使位置偏左上）。

**关键洞察**：与参考题 ac0a08a4 不同（全局统一缩放因子），这里每个对象"自我决定"自己的缩放倍率。像素数少的对象放大倍率低、物理尺寸小，但却显示在最顶层——这种"小者居上"的反直觉规则，加上倍率因对象而异的非全局性，需要对比多个示例才能归纳出来。

## 新题 3：四角异构镜像——指示色编码变换表

**组合逻辑**：[印章覆盖](创新：每个角的副本施加不同变换) ← [镜像](创新：由颜色编码的四态变换表驱动，而非二态开关) + [四角布局·插入间隔](已有) + [颜色配对](创新：颜色映射到变换类型而非目标位置)

**来源原语**：印章覆盖 ← 3e980e27/b1fc8b8e | 镜像 ← 3e980e27 | 分离 ← b1fc8b8e | 精灵体 ← 3e980e27/b1fc8b8e | 标记像素 ← 3e980e27 | 四角布局 ← b1fc8b8e | 颜色配对 ← 3e980e27 | 插入空行列间隔 ← b1fc8b8e | 特定标记触发镜像 ← 3e980e27

**依赖链**：提取中央的非对称精灵体 → 识别四个角落的指示像素颜色 → 建立颜色到变换类型的映射表（需对比多个示例确认，因为单个示例无法区分"颜色驱动"还是"位置驱动"）→ 对精灵体施加各角对应的变换 → 将结果放入四角并插入间隔行列。

一个非对称精灵体被四种不同的几何变换分别处理后放入输出的四个角落，每个角落的变换类型由该角的指示像素颜色唯一决定。

**输入结构**：约 10x10 的网格，黑(0)背景。网格中央区域有一个灰(5)的非对称小精灵体（边界框 3x3，含 4~6 个灰色像素，在水平和垂直方向均不对称）。网格的四个角落区域各有一个孤立的彩色指示像素：左上角附近一个，右上角附近一个，左下角附近一个，右下角附近一个。四个指示像素的颜色分别为红(2)、蓝(1)、绿(3)、黄(4)的某个排列（各不相同，不同示例中排列可不同）。生成约束：精灵体在恒等变换、水平镜像、垂直镜像、180 度旋转下产生四种互不相同的结果（即精灵体无任何对称轴）。

**规则**：
1. 提取灰(5)精灵体（网格中央的 4-连通灰色图形）及其边界框（设为 H x W）。
2. 识别四个角落区域各自的孤立彩色指示像素及其颜色。
3. 颜色到变换的映射为固定规则：红(2) → 保持不变（恒等），蓝(1) → 左右镜像，绿(3) → 上下镜像，黄(4) → 旋转 180 度。
4. 输出网格尺寸为 (2H + 1) x (2W + 1)，全部初始化为黑(0)。中间行（第 H 行）和中间列（第 W 列）为黑(0)间隔。
5. 对输出的四个象限，分别使用对应角落指示像素颜色所指定的变换处理精灵体，然后将结果放入该象限：左上象限使用输入左上角指示色对应的变换，右上象限使用输入右上角指示色对应的变换，左下象限使用输入左下角指示色对应的变换，右下象限使用输入右下角指示色对应的变换。
6. 输入中的指示像素不出现在输出中。

**关键洞察**：参考题 3e980e27 中指示色仅区分"镜像/不镜像"二态，参考题 b1fc8b8e 中四个副本变换完全相同。本题将颜色信号扩展为四种变换的选择器，且每个角落独立选择。仅凭单个示例，无法区分"颜色决定变换"和"角落位置决定变换"这两种假说——必须对比多个示例（其中指示色排列不同）才能确认映射规则。

## 新题 4：重复色平移与周期背景修复的同源触发

**组合逻辑**：[重复色才移动](已有) + [平移](已有) → [擦除](创新：擦除后不留空白而是修复为周期背景) ← [补全·周期平铺图案](创新：需修复的区域由平移操作的源位置决定，修复内容由非遮挡区域推断) + [贴边定位](已有)

**来源原语**：平移 ← 22208ba4 | 擦除 ← 22208ba4/abbfd121 | 补全 ← abbfd121 | 周期平铺图案 ← abbfd121/f823c43c | 边界矩形 ← 22208ba4 | 贴边定位 ← 22208ba4 | 重复色才移动 ← 22208ba4 | 被遮挡 ← abbfd121

**依赖链**：识别哪种颜色出现多次（重复色条件）→ 该条件同时触发两个操作：(a) 确定哪些矩形需要平移，(b) 确定哪些位置需要周期背景修复 → 利用非矩形区域的可见像素推断最小周期瓦片 → 擦除重复色矩形并用周期图案填补原位 → 将矩形平移到新位置。周期推断必须在擦除前完成（擦除后可见信息减少），而擦除区域只有在确定重复色后才能知道——形成不可跳步的顺序约束。

重复出现颜色的边界矩形向内平移一个身位，原位置用推断出的周期背景图案填补；只出现一次的颜色矩形保持不动。

**输入结构**：约 13x13 的网格。背景不是纯色，而是一个 2x2 的周期瓦片图案（由蓝(1)和灰(5)构成，例如左上蓝-右上灰-左下灰-右下蓝的棋盘变体）。若干单色实心矩形（约 3x2 到 4x3 大小）贴在网格边缘（每个矩形至少有一条完整边与网格边界重合），遮盖了部分背景图案。矩形颜色为非背景、非图案色（如红(2)、绿(3)、黄(4)、橙(7)），其中恰好一种颜色出现两次（如两个红(2)矩形分别贴在不同边缘），其余颜色各出现一次。生成约束：周期图案在所有矩形之外完全可见，足以唯一确定最小重复瓦片；各矩形互不重叠；重复色矩形平移后不超出网格边界。

**规则**：
1. 找出所有贴边的单色实心矩形及其颜色。贴边指矩形至少有一条完整边与网格边界重合。
2. 确定哪种颜色出现多次（出现两个及以上独立矩形）——该颜色为"移动色"。
3. 利用所有矩形之外的可见像素推断最小周期瓦片（通过行周期和列周期确定 2x2 瓦片内容）。
4. 擦除所有移动色矩形，用周期瓦片图案恢复被擦除位置的背景（每个被擦除像素的颜色 = 该位置在全局周期瓦片中的对应值）。
5. 将每个移动色矩形从其所贴边缘向内平移：平移方向为垂直于其所贴边缘指向网格内部的方向，平移距离等于矩形在该方向上的尺寸（高或宽）。若矩形贴在左边缘则向右平移自身宽度，贴在右边缘则向左平移自身宽度，贴在上边缘则向下平移自身高度，贴在下边缘则向上平移自身高度。若矩形同时贴两条边缘（角落位置），则沿两个方向各平移对应尺寸。
6. 只出现一次的颜色矩形保持原位不动。
7. 若平移后的矩形与不动矩形位置重叠，移动色矩形覆盖在上层。

**关键洞察**："重复色"这一条件同时驱动了两个本质不同的操作——决定哪些对象平移（几何操作），以及决定哪些位置需要背景修复（图案推断操作）。周期背景推断必须利用移动前的全局可见信息完成，形成严格的顺序依赖：先推断周期、再擦除修复、最后平移覆盖。

## 新题 5：循环对角铺满与计数衍生的切比雪夫排斥区

**组合逻辑**：[循环填充·同余类交错铺满](已有) + [切比雪夫距离](创新：排斥区半径不由局部距离决定，而由全局对角线数量决定) ← [计数](创新：计数对象从前景像素变为输入中的对角线条数，计数结果跨操作传递)

**来源原语**：循环填充 ← 05269061 | 对角线 ← 05269061 | 同余类交错铺满 ← 05269061 | 等距偏移 ← 05269061 | 切比雪夫距离 ← ff72ca3e | 阻挡像素 ← ff72ca3e | 填充 ← ff72ca3e | 近阻挡距定尺寸 ← ff72ca3e | 计数 ← ac0a08a4

**依赖链**：统计输入中的彩色对角线条数 D → D 同时用于两处：(a) 作为循环填充的铺满周期，(b) 作为每个灰色阻挡像素的切比雪夫排斥区半径 → 循环填充产生全网格覆盖 → 排斥区擦除区域内的填充像素。增减一条输入对角线会同时改变铺满周期和所有排斥区半径，产生完全不同的输出。

彩色对角线以自身条数为周期循环铺满整个网格，但灰色阻挡点周围的切比雪夫排斥区（半径也等于对角线条数）内不允许填充。

**输入结构**：9x9 的网格，黑(0)背景。包含 2 或 3 条完整的同斜率对角线（均为主对角线方向，即从左上到右下），每条颜色不同（如红(2)、蓝(1)、绿(3)），且这些对角线在垂直于对角线方向上等距分布（相邻对角线的垂直偏移量相等）。另有 1~2 个灰(5)的孤立阻挡像素散布在网格中（不在任何彩色对角线上）。生成约束：对角线互不相交；阻挡像素不与任何原始对角线像素重合。

**规则**：
1. 统计输入中彩色对角线的条数 D（通过非背景、非灰色的颜色种类数确定）。
2. 对每条彩色对角线，沿垂直于对角线的方向每隔 D 个偏移量重复一条相同颜色的平行对角线，铺满整个 9x9 网格。即：若某色对角线经过坐标 (r, c) 且 r - c = k，则所有满足 (r - c - k) mod D = 0 的位置都填入该颜色。各颜色的同余类互不重叠。
3. 对每个灰(5)阻挡像素，计算以该像素为中心、半径为 D 的切比雪夫排斥区（即以该像素为中心的 (2D+1) x (2D+1) 正方形区域，裁剪到网格边界内）。
4. 排斥区内的所有循环填充像素被清除为黑(0)。阻挡像素本身保持灰(5)。
5. 排斥区之外的循环填充像素正常保留。
6. 原始输入中的对角线像素若不在任何排斥区内则保留原色；若在排斥区内也被清除为黑(0)。

**关键洞察**：排斥区的大小不是阻挡像素的局部属性，而是由全局的对角线数量 D 衍生的——D 同时控制铺满周期和排斥半径。增加一条对角线会让铺满更密但排斥区更大，两种效果相互拮抗，产生涌现的图案变化。这种全局计数同时参数化两个不同操作的结构在源题中不存在。

## 新题 6：压缩域连通性分析与极值区域重涂

**组合逻辑**：[下采样·奇偶索引分离](已有) → [连通区域](创新：连通性在压缩域而非原始域中计算，压缩改变了邻接关系) → [重涂色·极值面积决定颜色](创新：面积在压缩域中重新计算，原始域中不可见的连通结构驱动重涂)

**来源原语**：下采样 ← 68b67ca3 | 分隔行列 ← 68b67ca3 | 奇偶索引分离 ← 68b67ca3 | 保留偶索引交叉 ← 68b67ca3 | 重涂色 ← 62ab2642 | 连通区域 ← 62ab2642 | 极值面积决定颜色 ← 62ab2642

**依赖链**：识别奇数索引行列为分隔行列 → 压缩得到紧凑网格（仅保留偶数行偶数列交叉位置）→ 在紧凑网格中重新判定 4-连通区域（压缩前被分隔行列隔开的像素在压缩后可能成为邻居）→ 按压缩域中的区域面积排名 → 对极值面积区域重涂色。不理解压缩规则就无法发现真正的连通结构，不分析连通性就无法确定重涂目标。

将带有分隔行列的稀疏网格压缩后，在压缩域中分析连通区域，对面积最小和最大的区域分别重涂为指定颜色。

**输入结构**：偶数尺寸网格（如 10x10 或 12x12），黑(0)背景。所有奇数索引的行（第 1、3、5... 行，从 0 开始计数）和所有奇数索引的列均为纯黑(0)像素（分隔行列）。偶数行偶数列的交叉位置上有若干蓝(1)像素和黑(0)像素。所有非背景前景像素均为蓝(1)。在原始稀疏网格中，蓝色像素之间被分隔行列隔开，视觉上每个蓝色像素都显得孤立。但在压缩后的紧凑网格中（尺寸为原始的一半），某些蓝色像素在新的坐标系下成为 4-连通邻居，形成连通区域。生成约束：压缩后至少形成 3 个蓝(1)的 4-连通区域，且面积互不相等；最小和最大区域各唯一。

**规则**：
1. 删除所有奇数索引的行和列，得到尺寸为原始一半的紧凑网格。偶数行偶数列交叉位置 (2i, 2j) 映射到紧凑网格的 (i, j)。
2. 在紧凑网格中，找出所有 4-连通的蓝(1)区域，计算各区域面积（像素数）。
3. 面积最小的唯一区域重涂为橙(7)。
4. 面积最大的唯一区域重涂为青(8)。
5. 其余蓝(1)区域保持蓝色不变。
6. 黑(0)背景保持不变。
7. 输出为紧凑网格。

**关键洞察**：在原始稀疏网格中，由于分隔行列的存在，所有蓝色像素至少相隔一行一列，视觉上完全孤立。只有在理解压缩规则（删除奇数行列）后，才能在紧凑网格中发现哪些像素实际上是相邻的。压缩不仅改变了网格尺寸，更根本性地改变了像素间的拓扑关系——这是决定重涂目标的前提。

## 新题 7：奇偶分流压缩——枚举序位同时编码颜色与方向

**组合逻辑**：[交替选取·奇偶位决定涂色](创新：奇偶不仅决定颜色还决定压缩方向) + [压缩·压缩至远端边界](创新：同一列内的像素被拆分为两组，分别向相反方向压缩) + [重涂色](创新：颜色由枚举序位的奇偶性决定)

**来源原语**：交替选取 ← d406998b | 奇偶位决定涂色 ← d406998b | 压缩 ← 05a7bcf2 | 压缩至远端边界 ← 05a7bcf2 | 重涂色 ← d406998b/05a7bcf2 | 通道 ← 05a7bcf2 | 前景像素序列 ← d406998b

**依赖链**：在每个列（通道）中从上到下枚举前景像素并编号 → 编号的奇偶性同时决定两件事：(a) 重涂颜色（偶 → 绿、奇 → 红），(b) 压缩方向（偶 → 向底边压缩、奇 → 向顶边压缩）→ 同一列的像素被拆分为两组后分别向相反方向聚拢。颜色规则和方向规则共享同一个参数（枚举奇偶性），不可独立归纳。

每列中的前景像素按从上到下的枚举序位分为偶数组和奇数组，偶数组变绿并压向底边，奇数组变红并压向顶边。

**输入结构**：约 8x10 的网格（8 行 10 列），黑(0)背景。每列包含 2~4 个散布在不同行位置的灰(5)前景像素。不同列的灰色像素数量和行位置各不相同。网格中无其他颜色。生成约束：每列至少 2 个灰色像素；同一列中灰色像素不相邻（行间隔 >= 2）。

**规则**：
1. 独立处理每一列（通道）。
2. 在每列中，从上到下（行索引从小到大）枚举所有灰(5)像素，依次编号为 0、1、2、3...
3. 编号为偶数的像素（0、2、4...）重涂为绿(3)，并向该列的底边压缩：第一个偶数编号像素放在该列最底行，第二个放在倒数第二行，以此类推，保持原有的上下相对顺序（原序靠上的在压缩后仍靠上）。
4. 编号为奇数的像素（1、3、5...）重涂为红(2)，并向该列的顶边压缩：第一个奇数编号像素放在该列最顶行，第二个放在第二行，以此类推，保持原有的上下相对顺序。
5. 同一列中，压缩后的绿色像素和红色像素不会重叠（因为生成约束保证了像素数不超过行数的一半）。
6. 所有其他位置保持黑(0)。

**关键洞察**：枚举序位的奇偶性是一个"三合一"信号——它同时控制选择分组、输出颜色和压缩方向。观察单个列的单个示例时，"偶数→绿→向下"和"原位置靠上→绿→向下"等多种假说均可成立；必须对比多个列和多个示例（其中像素分布不同）才能确认驱动规则是枚举序位的奇偶性而非空间位置。
