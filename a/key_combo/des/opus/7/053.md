## 新题 1：重力堆叠序驱动同心层着色

**组合逻辑**：[gravity_drop](创新：关注落地时序而非终态位置) + [concentric_layer_filling](创新：层序由落地时序决定而非线段长度) + [adjacency_blocking](已有)

**来源原语**：gravity_drop / cushion_row_gap / adjacency_blocking (825aa9e9), concentric_layer_filling / outside_in_nesting / concentric_square_layer (3ee1011a)

**依赖链**：重力模拟产生落地时序（涌现属性）→ 时序决定同心层分配 → 层颜色来自对应色块。删除重力模拟则无法推断时序；删除同心填充则时序无用武之地。重力模拟中的堆叠交互（先落的色块成为后续色块的障碍）使时序非简单可读。

根据色块初始位置模拟重力下落，按落地先后顺序为同心方形的各层分配颜色。

**输入结构**：黑(0)背景，约 15x10 网格。底行为灰(5)水平地板条。地板上方散布 4~6 个单行水平色块（每个色块为单一非黑非灰颜色，宽 2~4 格，厚 1 格），各色块颜色互不相同，位于不同高度。部分色块的列范围存在重叠，使得下落时可以堆叠（先落地的色块成为后落色块的着陆平台）。生成约束：所有色块颜色互不相同；至少两对色块存在列范围重叠；不存在两个色块初始高度相同且列范围重叠的情况。

**规则**：
1. 模拟重力下落：按初始最底行位置从低到高逐个处理每个色块（同行则按最左列从左到右）。每个色块垂直下落，直到其底边紧贴地板顶部或已落地色块的顶部（无缓冲间距，直接相邻）。
2. 记录落地顺序：第一个处理并落地的色块为 rank 1，第二个为 rank 2，依此类推。共 N 个色块。
3. 构建 N x N 的输出网格，填充同心方形层：最外层（第 0 层，即边框）涂 rank 1 色块的颜色，第 1 层涂 rank 2 色块的颜色，依此类推，最内层涂最后落地色块的颜色。若 N 为偶数，最内层为 2x2 区域；若 N 为奇数，最内层为 1x1 中心格。

**关键洞察**：落地时序不等于初始高度排序——列范围重叠导致先落色块改变后续色块的着陆面高度，使时序偏离直觉预期。必须完整模拟堆叠过程才能确定同心层着色。

## 新题 2：互补形状匹配门控框内颜色互换

**组合逻辑**：[shape_match / complementary_shape](创新：匹配结果作为门控条件而非直接填充) + [color_swap / frame_interior_only](创新：仅对匹配成功的框执行互换)

**来源原语**：shape_match / complementary_shape / unique_complement / template_gap / source_shape (18447a8d), color_swap / rectangular_frame / interior_region / frame_interior_only (7ee1c6ea)

**依赖链**：几何互补匹配确定哪些框被"激活" → 仅在被激活框内执行颜色互换 → 未匹配框保持不变。删除匹配则无法区分激活与未激活框；删除互换则匹配结果无用途。匹配的输入（形状几何）与互换的作用域（框内区域）通过框结构紧密绑定。

将散落形状与框内空隙做互补匹配，仅在匹配成功的框内执行双色互换。

**输入结构**：黑(0)背景，约 16x16 网格。左半区有 3~5 个蓝(1)一格厚矩形框，互不重叠；每个框内含黑(0)像素和由红(2)与绿(3)两种颜色构成的前景图案（每框的图案不同，但都只用这两色）。右半区散布若干小型单色形状（每个形状为 4-连通，3~8 像素，使用非黑非蓝非红非绿的颜色，如黄(4)、灰(5)等，每个形状颜色互不相同）。右侧形状数量少于左侧框数量（即至少一个框没有匹配形状）。生成约束：每个右侧形状恰好与一个框的内部空隙（框内黑色区域的形状）几何全等（允许平移对齐但不允许旋转翻转），且匹配是一对一的；至少一个框无匹配形状。

**规则**：
1. 对每个右侧形状，将其归一化到原点坐标（以最小外接矩形左上角为原点），与每个左侧框的内部空隙（框内所有黑色格的集合，同样归一化）做精确匹配。
2. 匹配成功的框标记为"激活"。将激活框内的红(2)和绿(3)互换：所有红色格变绿，所有绿色格变红。
3. 未激活的框保持内部颜色不变。
4. 从输出中删除所有右侧形状（对应位置恢复为黑(0)）。框本身（蓝色边框）在输出中保留不变。

**关键洞察**：右侧形状不是直接填入空隙（参考题 18447a8d 的做法），而是充当"钥匙"——匹配成功仅触发框内的颜色互换操作。未被匹配的框是区分该规则与"全部互换"的关键线索，需要对比多个示例才能归纳。

## 新题 3：行均匀检测触发重涂后压缩相邻同行

**组合逻辑**：[detection / uniform_row_marked](创新：检测结果驱动重涂，重涂涌现新的相邻相同行) + [recolor](已有) + [compression / merge_identical](创新：压缩对象是重涂后的行而非原始行)

**来源原语**：detection / uniform_row_marked_else_black / row (25d8a9c8), recolor (22a4bbc2), compression / merge_identical / adjacent_identical / dup_row (ce8d95cc)

**依赖链**：行均匀检测 → 均匀行重涂为灰色 → 原本不同颜色的均匀行变为相同灰色 → 相邻灰色行成为可压缩的重复行 → 压缩合并。操作 A（重涂）的输出改变了操作 B（压缩）的触发条件：两行原本颜色不同（一行全红、一行全蓝）不会被压缩，但重涂后都变成灰色，成为相邻相同行而被合并。

检测均匀色行并统一涂灰，再将相邻相同行压缩为一行——重涂步骤涌现出原本不存在的可压缩行对。

**输入结构**：约 10x8 至 12x10 的彩色网格。行分两类：均匀行（整行同色，颜色各异，如全红、全蓝、全绿等）和混合行（含多种颜色）。网格中存在若干对相邻均匀行，它们原本颜色不同。也存在部分原本就相同的相邻混合行。生成约束：至少存在两对相邻的均匀行，其原始颜色不同（重涂后将变为相同灰色并可压缩）；至少存在一对原本就相同的相邻混合行（它们在压缩步骤中直接合并）。

**规则**：
1. 逐行检查：若该行所有格颜色相同，则将整行重涂为灰(5)。若该行包含多种颜色，保持不变。
2. 从上到下扫描重涂后的网格，将连续相邻的完全相同行合并为一行（保留每组连续相同行中的第一行）。
3. 输出为压缩后的网格，行数减少，列数不变。

**关键洞察**：压缩效果不能仅从原始网格预测——原本不同颜色的均匀行在重涂后变成相同的灰色行，产生了原始网格中不存在的相邻重复。必须先完成重涂再判断哪些行可压缩。

## 新题 4：叶标记定义镜像轴后双面板叠合

**组合逻辑**：[mirror](创新：镜像轴由叶标记动态指定而非全局翻转) + [leaf_selects_row_col](创新：叶标记选定行列后执行镜像而非射线延伸) + [transparent_overlay / separator_alignment](已有) + [erase](已有)

**来源原语**：mirror / column_reversal (67a3c6ac), leaf_protrusion / leaf_selects_row_col / swap_extend (f1cefba8), transparent_overlay / separator_row / equal_height_panel / separator_alignment / no_fg_collision (e98196ab), erase (e98196ab)

**依赖链**：叶标记的方向性确定镜像作用于行还是列 → 镜像改变面板内像素布局 → 叠合时两面板的前景区域因镜像而重新排列 → 最终输出依赖镜像后的像素位置。删除叶标记则无法确定镜像轴；删除镜像则叠合输入不正确；删除叠合则两面板结果独立无交互。

在两块面板内各自按叶标记指定的行/列做局部镜像，然后擦除分隔行并叠合两面板。

**输入结构**：黑(0)背景，约 13x17 网格（13列，17行）。中间有一整行红(2)水平分隔行将网格分为上下两个等高面板（各 8 行）。每个面板内有一个绿(3)实心矩形区域（约 4x6 至 6x8），矩形内部分格为橙(7)前景像素（形成不规则图案），其余格保持绿(3)。矩形外边缘伸出若干蓝(1)单格叶突起：位于矩形左边或右边的叶突起（其唯一绿色邻居在水平方向）标记所在行；位于矩形上边或下边的叶突起（其唯一绿色邻居在垂直方向）标记所在列。生成约束：每个面板 1~3 个叶突起；两个面板的前景像素在叠合时不发生冲突（不占据相同的局部坐标）；叶突起不会出现在矩形的角格位置。

**规则**：
1. 对每个面板独立处理：
   - 找到所有蓝(1)叶突起。判断每个叶的方向：若叶的唯一绿色 4-邻居在其左方或右方，则该叶标记其所在行；若在上方或下方，则标记其所在列。
   - 对被标记的每一行，将该行在绿色矩形范围内的像素序列左右翻转（水平镜像）。
   - 对被标记的每一列，将该列在绿色矩形范围内的像素序列上下翻转（垂直镜像）。
   - 若某格同时被行镜像和列镜像影响，两次镜像依次执行（先行后列）。
   - 处理完毕后移除蓝色叶突起（恢复为黑色）。
2. 删除红(2)分隔行。
3. 将下面板按局部坐标对齐叠合到上面板上：保留两个面板中所有非黑像素。两面板前景不冲突，因此叠合无歧义。

**关键洞察**：叶突起的朝向决定镜像维度（行或列），而非像参考题中决定射线方向。镜像改变了面板内的像素排列，因此叠合结果既取决于叶标记的位置和方向，也取决于两面板原始图案的互补关系。

## 新题 5：像素计数编码旋转量且旋转量决定叠合优先级

**组合逻辑**：[rotate / pixel_count_encodes_rotation](创新：旋转量同时编码叠合优先级) + [transparent_overlay](创新：层序由旋转量动态决定而非固定面板位置) + [same_color_matching](已有)

**来源原语**：rotate / color_layer / cue_sprite / same_color_matching / pixel_count_encodes_rotation (6ffbe589), transparent_overlay / panel / layer_priority / panel_layer_order (ea9794b1)

**依赖链**：角落提示体的像素数 mod 4 → 同时决定旋转角度和叠合层级 → 旋转改变前景分布 → 层级决定重叠区域的胜出颜色。提示体像素数承担双重角色（旋转量 + 优先级），使两个操作通过同一个参数耦合。修改一个提示体的像素数同时改变旋转和叠合结果。

用角落提示体的像素数同时控制各象限面板的旋转角度和叠合优先级，旋转越大的面板在叠合时位于越上层。

**输入结构**：黑(0)背景，约 14x14 网格。网格在概念上分为 2x2 共 4 个等大象限面板（每个约 5x5），面板之间有 2 列和 2 行的黑色间隔带。每个面板内有一个由单一非黑颜色构成的前景图案（4-连通，4~10 像素，形状不规则），四个面板颜色互不相同（如蓝(1)、红(2)、绿(3)、黄(4)）。在网格四角的间隔带区域内各有一个小型单色像素簇（提示精灵体），每个提示体的颜色与某一面板颜色相同，像素数为 1~4（4-连通）。生成约束：四个提示体颜色分别对应四个面板；四个提示体的像素数互不全同（至少两个不同，以展示不同旋转量）；旋转后至少两个面板存在前景重叠。

**规则**：
1. 将每个角落提示体按颜色匹配到对应面板。
2. 对每个面板的前景图案在面板局部坐标系内执行顺时针旋转：旋转角度 = (该面板对应提示体的像素数 mod 4) x 90 度。0 像素余数 = 不旋转，1 = 90度，2 = 180度，3 = 270度。
3. 将四个旋转后的面板叠合到一个面板大小的输出网格上。叠合层级由旋转量决定：旋转 0 度的面板最先绘制（最底层），90 度次之，180 度再次，270 度最后绘制（最顶层）。非黑像素覆盖先前层的像素。
4. 相同旋转量的面板之间按阅读序排列层级：左上 < 右上 < 左下 < 右下（先绘制的在下层）。
5. 提示精灵体不出现在输出中。

**关键洞察**：提示体像素数承担双重职责——既编码旋转角度，又隐式编码叠合优先级。增加一个提示体的像素不仅旋转该面板的图案（改变重叠位置），还提升其层级（改变重叠区域哪个面板胜出）。两个效应同时作用使单个像素的变化对输出产生非线性影响。

## 新题 6：包含树深度映射图例颜色并规范化嵌套框架

**组合逻辑**：[canonicalize / containment_tree / topology_determines_layout](创新：规范化几何的同时保留拓扑用于着色) + [fill / legend_maps_color](创新：图例按嵌套深度映射而非按对角配对) + [crop](已有)

**来源原语**：canonicalize / nested_frame / enclosed_region / containment_tree / topology_determines_layout (2d0172a1), fill / color_legend / legend_maps_color (9385bd28), crop (6ffbe589/2d0172a1)

**依赖链**：拓扑分析建立包含树 → 包含树决定每个对象的嵌套深度 → 深度作为图例的索引键查询填充颜色 → 同时规范化几何形状为矩形 → 输出是着色的规范嵌套结构。删除拓扑分析则无法确定深度；删除图例则颜色无来源；删除规范化则输出几何不确定。三个操作通过"深度"这一中间量交织。

分析不规则嵌套框架的拓扑包含关系，按嵌套深度查图例着色，同时规范化为整齐矩形嵌套。

**输入结构**：黑(0)背景，约 18x18 网格。网格主体由灰(5)前景像素构成若干粗糙的闭合框架和小型实心团块（4-连通）。框架嵌套深度最多 3~4 层。网格左下角有一竖列颜色图例：从上到下每行一个非黑非灰色格，依次对应深度 0、1、2、3 的填充颜色（如蓝(1)、红(2)、绿(3)、黄(4)）。图例与主体之间至少隔 2 格黑色间距。生成约束：最外层框架为深度 0；框架直接包含的子对象（框架或团块）深度为父+1；同深度对象颜色相同；图例行数等于实际出现的最大深度+1。

**规则**：
1. 检测主体中所有灰色 4-连通前景对象。区分框架（包含孔洞/内部黑色区域的对象）和团块（无孔洞的实心对象）。
2. 建立包含树：若对象 B 位于对象 A 的孔洞内部，则 B 是 A 的子节点。根节点（不被任何对象包含的对象）深度为 0。
3. 规范化几何：
   - 每个框架替换为一格厚的矩形边框，大小刚好在其所有直接子节点的规范化结果外围留出 2 格内边距。
   - 每个团块替换为单个像素。
   - 同层兄弟节点按原始重心的行优先列次序从左到右排列，相邻兄弟之间留 1 格空隙。
4. 读取图例：第 k 行（从上到下，k 从 0 开始）的颜色为深度 k 的填充色。
5. 将每个规范化对象（边框或单像素）涂上其深度对应的图例颜色。
6. 输出仅包含规范化嵌套结构，裁剪到最小外接矩形。图例不出现在输出中。

**关键洞察**：输入对象的不规则几何形状既不影响输出形状（被规范化）也不影响输出颜色（由嵌套深度通过图例决定）。两个外观完全不同但嵌套深度相同的框架在输出中获得相同颜色。拓扑关系是连接几何规范化和颜色分配的唯一桥梁。

## 新题 7：每隔 N 选取分流：选中者下落，未选中者镜像

**组合逻辑**：[sort / every_nth_selection](创新：选取结果分流到两种不同变换) + [gravity_drop](创新：仅作用于选中子集) + [mirror](创新：仅作用于未选中子集，按中心线水平镜像位置)

**来源原语**：sort / every_nth_selection / sort_by_position (22a4bbc2), gravity_drop / movable_object / adjacency_blocking / cushion_row_gap (825aa9e9), mirror / column_reversal (67a3c6ac)

**依赖链**：位置排序确定 rank → every-3rd 选取将对象分为两组 → 选中组执行重力下落 → 未选中组执行水平镜像 → 输出是两种变换结果的混合。选取规则是隐藏逻辑：单看输出只能观察到部分对象移到了底部而另一部分水平翻转了位置，必须推断出"每三个取一个"的选取模式才能完整解释。

按空间排序后每隔 3 个选取一个色块，选中色块做重力下落，未选中色块做水平镜像位移。

**输入结构**：黑(0)背景，约 12x12 网格。底行为灰(5)水平地板条。地板上方散布 6~9 个单行水平色块（每个为单一颜色，宽 2~4 格，厚 1 格），各色块颜色互不相同，位于不同高度。所有色块的列范围互不重叠（保证下落和镜像时不产生碰撞）。生成约束：色块数量至少 6 个以展示"每 3 个"的模式；镜像后色块不与其他色块或地板冲突。

**规则**：
1. 将所有色块按最顶行从上到下排序，同行则按最左列从左到右排序，得到 rank 1, 2, 3, ...。
2. 选取 rank 为 1, 4, 7, ... 的色块（即每 3 个取第 1 个）。
3. 选中色块：从原位置清除，在其原列范围内垂直下落到灰色地板正上方一行（1 格缓冲），保持水平位置和宽度不变。若多个选中色块列范围不重叠，它们各自独立下落。
4. 未选中色块：将每个色块的列位置关于网格垂直中心线做水平镜像（若网格宽 W，色块占列 c1..c2，则镜像后占列 (W-1-c2)..(W-1-c1)），行位置保持不变。从原位置清除后在镜像位置绘制。
5. 灰色地板保持不变。

**关键洞察**：输出中某些色块在底部（下落的），某些色块在原高度但水平翻转了位置（镜像的）。两类色块的区分不取决于颜色或大小，而取决于空间排序后的序号模式（每 3 个取 1 个），这个模式必须对比多个示例才能归纳。

## 新题 8：对齐框内像素奇偶门控颜色互换后绘制桥接线

**组合逻辑**：[color_swap](创新：由像素计数奇偶性门控而非固定执行) + [draw_line / row_column_alignment / midpoint_symmetry](创新：桥接线颜色取决于互换后的框内状态) + [detection](创新：检测像素奇偶性作为条件判断)

**来源原语**：color_swap / rectangular_frame / interior_region / frame_interior_only (7ee1c6ea), draw_line / row_column_alignment / midpoint_symmetry (b7249182), detection (25d8a9c8)

**依赖链**：框内非黑像素计数 → 奇偶性决定是否互换 → 互换改变框内颜色分布 → 框内互换后的多数色成为桥接线颜色 → 桥接连接行列对齐的框对。计数→互换→桥接色形成三步信息变换链，每步的输出实质性改变下一步输入。

检测各矩形框内前景像素总数的奇偶性决定是否互换双色，然后用互换后的多数色绘制对齐框对之间的桥接线。

**输入结构**：黑(0)背景，约 18x18 网格。散布 4~6 个一格厚矩形框，每个框用唯一颜色绘制（如蓝(1)、绿(3)、黄(4)、灰(5)等，各框颜色不同）。每个框的内部（严格在边框以内的区域）包含黑(0)像素和由红(2)与橙(7)两种颜色构成的前景图案（图案不规则，各框不同，但都只用红和橙两色）。部分框对在行方向或列方向上对齐（它们的中心行相同或中心列相同）。生成约束：至少一个框内前景像素总数为奇数，至少一个为偶数；至少两对框存在行对齐或列对齐关系；对齐的框对之间有足够空间绘制桥接线（至少 2 格间距）。

**规则**：
1. 对每个框，统计其内部所有非黑像素（红(2)和橙(7)）的总数。
2. 若总数为奇数，将该框内的红(2)和橙(7)互换（红变橙，橙变红）。若总数为偶数，保持不变。
3. 互换完成后，对每个框统计内部红(2)像素数和橙(7)像素数，确定多数色（若相等则取红(2)）。
4. 对每对行对齐或列对齐的框，绘制一条直线桥接连接它们最近边的中点：
   - 行对齐：水平直线连接两框最近竖边的中点。
   - 列对齐：垂直直线连接两框最近横边的中点。
   - 桥接线颜色 = 两个框中距网格左上角更近的那个框的多数色（互换后的）。距离按框中心到左上角的曼哈顿距离计算。
5. 桥接线绘制在黑色背景上，不覆盖任何框的边框或内部像素。

**关键洞察**：桥接线颜色无法从框的边框颜色推断——它取决于框内的互换后状态，而互换是否发生又取决于像素计数奇偶性。观察者必须先判断奇偶 → 确定是否互换 → 统计互换后多数色 → 才能预测桥接线颜色。这条推理链中任何一步的错误都会导致桥接线颜色错误。
