## 新题 1：光晕桥接决定精灵存亡

**组合逻辑**：[dilation](灰标记膨胀为蓝光晕) → [connectivity_test](光晕链是否桥接多个精灵) → [recolor](同连通分量内精灵统一涂色) + [erase](孤立精灵擦除)

**来源原语**：dilation/neighborhood_expand/marker_retains_color（4258a5f9）、connectivity_test/connectivity/bridge_path（239be575）、recolor（f560132c/de809cff）、erase（d90796e8）

**依赖链**：灰标记膨胀产生的蓝光晕覆盖范围决定了哪些精灵被桥接进同一连通分量；连通分量的成员关系决定了最大精灵的颜色向其余成员传播；未被任何光晕链触达的孤立精灵被完全擦除。删除膨胀步骤则连通关系无法建立；删除连通判定则无法确定重涂色范围；删除擦除规则则孤立精灵的处理方式不明。

一句话总结：灰色标记点膨胀出蓝色光晕，光晕重叠链将多个精灵桥接为一组，组内所有精灵被重涂为最大精灵的颜色，无法被任何光晕链触达的孤立精灵被擦除。

**输入结构**：
- 网格约 15x15，背景为黑(0)。
- 3~5 个单色精灵体散布在网格中，每个精灵由 3~7 个同色像素组成的 4-连通区域构成，各精灵颜色互不相同（使用红(2)、绿(3)、黄(4)、橙(7)、栗(9)等非黑非灰非蓝颜色）。
- 若干灰(5)单像素标记散布于精灵之间的空白区域，标记不与任何精灵 4-邻接。
- 任意两个精灵之间至少间隔 3 个像素（曼哈顿距离），保证精灵本身不直接接触。
- 生成约束：至少存在一组精灵能通过灰标记光晕链桥接（即存在一系列灰标记，使得相邻标记的 3x3 邻域有重叠，且链的两端各触及一个精灵的像素）；至少存在一个精灵无法被任何光晕链触达。

**规则**：
1. 对每个灰(5)标记像素，将其裁剪后的 3x3 邻域中的所有黑(0)像素涂为蓝(1)。然后恢复灰标记像素本身为灰(5)（标记保留原色）。若邻域中已有非黑像素（精灵像素或其他标记/光晕），该位置不涂蓝，保留原有颜色。
2. 在全部光晕绘制完成后，构建所有非黑像素（精灵像素 + 蓝光晕 + 灰标记）的 4-连通分量。忽略颜色差异，仅凭 4-邻接关系判断连通。
3. 对于包含 2 个或更多精灵的连通分量：找到该分量中像素数最多的精灵（若平局，选边界框左上角行号更小者；仍平局则选列号更小者）。将分量中所有其他精灵的每个像素重涂为该最大精灵的颜色。
4. 对于仅包含 1 个精灵的连通分量（孤立精灵）：将该精灵的所有像素设为黑(0)（擦除）。
5. 移除所有蓝(1)光晕像素和灰(5)标记像素（设为黑(0)）。输出仅保留存活的精灵像素（部分已被重涂色）。

**关键洞察**：灰标记的空间分布构成了一个隐式的连通图——只有通过观察多个示例中标记的不同布局与精灵存亡结果的对应关系，才能归纳出"光晕重叠桥接"这一中间机制。单看输入输出无法直接看到光晕，因为光晕在最终输出中被移除。

## 新题 2：滑动行程生长递减帽

**组合逻辑**：[slide/stop_at_barrier](行程左滑至障碍) → [shrinking_fill](从滑停位置向上下生长递减帽) ← [行程宽度决定帽初始宽度]（创新：滑动结果的几何属性参数化驱动递减填充的形状）

**来源原语**：slide/movable_run/fixed_barrier/same_row_blocking/stop_at_barrier（9c56f360）、shrinking_fill/side_run/progressively_shortened（9772c176）、ray_extend（9772c176）

**依赖链**：行程先滑动确定水平位置，滑停后的行程宽度直接成为递减帽的初始宽度参数，帽从行程上下边沿逐行向外递减。障碍既阻止行程滑动也阻止帽延伸。删除滑动步骤则帽的位置和宽度无法确定；删除递减帽步骤则滑动行程本身与原题无区别。

一句话总结：彩色行程沿行滑至障碍停下，然后从停下位置的上下两侧逐行生长递减宽度的黄色帽，帽宽从行程宽度开始每行缩减两像素直至消失。

**输入结构**：
- 网格约 15x20（15 行 20 列），背景为黑(0)。
- 橙(7)单像素形成固定障碍，散布于多行中，每行 0~2 个障碍像素。
- 蓝(1)像素形成 3~5 条水平行程，每条行程为同一行中连续的蓝(1)像素段，该段的最右像素紧贴网格右边缘（列索引 = 列数-1）。各行程宽度在 3~9 像素之间且互不相同。不同行程在不同行，且相邻行程之间至少间隔 3 行（为帽预留空间）。
- 生成约束：每条行程所在行至少有一个橙(7)障碍像素位于行程左侧（保证行程会被阻挡而不是滑到最左端）。各行程滑停后的帽延伸区域互不重叠。

**规则**：
1. 逐行处理每条蓝(1)行程（处理顺序不影响结果，因为行程在不同行且帽不重叠）。将该行程从右边缘清除，在同行中从该行最右侧橙(7)障碍像素的下一列开始，向右重绘同宽度的蓝(1)行程。若该行无障碍，则从列 0 开始重绘。
2. 对每条已滑停的蓝(1)行程，从其上边沿开始逐行向上生长帽：第一行帽的宽度等于行程宽度，水平居中于行程中心列；第二行帽宽度减 2（左右各缩 1 像素），同样居中；逐行递减直到宽度 ≤ 0 则停止。帽像素涂黄(4)。
3. 同样从行程下边沿逐行向下生长同样规则的黄(4)帽。
4. 帽生长过程中，若某帽像素位置已有橙(7)障碍像素或蓝(1)行程像素或超出网格边界，跳过该像素不涂色。仅覆盖黑(0)背景像素。
5. 橙(7)障碍像素和蓝(1)行程像素保持不变。

**关键洞察**：每条行程的宽度在输入中可直接读取，但滑停后的位置需要推理障碍关系；帽的几何形状同时取决于行程宽度（决定初始帽宽和总行数）和滑停位置（决定帽的水平坐标），二者缺一不可。不同宽度的行程产生不同高度的帽塔，形成参差结构。

## 新题 3：风车拼合触发跨象限多米诺

**组合逻辑**：[rotate + concatenate](精灵四旋转拼成风车) → [four_neighbor_pairing](跨象限边界的异色 4-邻接对形成多米诺) → [recolor + erase](多米诺规则：绿存为青、红消)（创新：旋转的几何结果隐式定义了哪些像素会形成跨边界配对）

**来源原语**：rotate/concatenate/array_layout/four_rot_pinwheel（ed98d772）、bicolor_domino/four_neighbor_pairing/pair_recolor_erase（d90796e8）、recolor（多源）、erase（d90796e8）

**依赖链**：旋转决定各象限中像素的位置，位置决定哪些像素跨象限边界 4-邻接，4-邻接关系中的红-绿配对触发多米诺变换。删除旋转拼合则无跨边界邻接可检测；删除多米诺规则则风车与原题无异。一个输入像素的颜色变化可通过四次旋转在四条象限边界上产生连锁反应。

一句话总结：将输入精灵拼成 2x2 风车后，跨越象限边界的红-绿相邻像素对按多米诺规则变换——绿侧变青、红侧消除。

**输入结构**：
- 网格为 N x N（N 为 3 或 4），背景为黑(0)。输出为 2N x 2N。
- 精灵仅使用红(2)和绿(3)两种前景色，像素数在 3~8 之间。精灵不必连通，但至少有一个红像素和一个绿像素。
- 生成约束：拼成风车后，至少存在 2 对跨象限边界的红-绿 4-邻接配对；至少存在 1 对跨边界的同色 4-邻接（用于验证同色对不被处理）。每个前景像素至多参与一个跨边界多米诺对（若同一像素与多个跨边界邻居均构成红-绿对，按上邻优先、左邻次之的顺序只取第一个配对，其余保留原色）。

**规则**：
1. 构建 2N x 2N 输出网格。将原始精灵放在左上象限（行 0..N-1，列 0..N-1）。
2. 将精灵逆时针旋转 90 度后放在右上象限（行 0..N-1，列 N..2N-1）。
3. 将精灵旋转 180 度后放在左下象限（行 N..2N-1，列 0..N-1）。
4. 将精灵顺时针旋转 90 度后放在右下象限（行 N..2N-1，列 N..2N-1）。
5. 扫描所有跨象限边界的 4-邻接像素对。象限边界指行索引 N-1 与 N 之间（水平边界）以及列索引 N-1 与 N 之间（垂直边界）。对于水平边界上的对，即 (N-1, c) 与 (N, c) 为一对；对于垂直边界上的对，即 (r, N-1) 与 (r, N) 为一对。
6. 按行优先、列次之的顺序逐对检查：若该对中一个为红(2)一个为绿(3)，且两个像素均未在本轮被先前的配对消耗，则标记为多米诺对。将绿(3)像素重涂为青(8)，将红(2)像素设为黑(0)。
7. 跨边界的同色对、非红绿组合的异色对、以及非跨边界的所有像素对不做任何处理。
8. 风车内部（非跨边界）的所有像素保持不变。

**关键洞察**：输入精灵的颜色布局通过旋转在四条象限边界上映射出不同的邻接模式。求解者需要先在脑中完成旋转拼合，才能判断哪些位置会产生红-绿跨界对——这种间接性使得仅看单个示例难以确认配对扫描的精确顺序规则（上优先还是左优先）。

## 新题 4：轮廓描边构筑重力地形

**组合逻辑**：[outline_tracing/polar_angle_ordering](顶点按极角连线成轮廓) → [轮廓边作为 fixed_barrier] → [slide/gravity](黄像素沿列下落直至碰轮廓或底边)（创新：描边产物同时充当后续重力操作的障碍物，双重身份）

**来源原语**：outline_tracing/outline_vertex/polar_angle_ordering/path_clearance（35ab12c3）、draw_line/endpoint_connection（3bd67248）、slide/fixed_barrier/stop_at_barrier（9c56f360）

**依赖链**：顶点位置决定描边路径，路径构成重力障碍，障碍位置决定黄像素的降落终点。删除描边步骤则无障碍、黄像素全落到底行；删除重力步骤则描边与原题无异。顶点的细微位移会重塑整条轮廓线从而大幅改变黄像素的落点分布。

一句话总结：多组彩色顶点连成多边形轮廓线，散布在上方的黄色像素沿列自由下落，落到轮廓线或网格底边时停住。

**输入结构**：
- 网格约 18x18，背景为黑(0)。
- 2~3 组顶点集合，每组使用一种颜色（如蓝(1)、红(2)、绿(3)）。每组包含 3~5 个单像素顶点，散布于网格中下部（行索引 ≥ 5）。
- 4~8 个黄(4)单像素散布于网格上部（行索引 ≤ 4），各黄像素所在列至少有一个顶点集合的轮廓边经过（保证不全都直接落到底边）。
- 生成约束：每组顶点按极角排序后相邻顶点之间的连线（水平、垂直或 45 度对角线段）的内部像素全为黑(0)（路径通畅）。不同组的轮廓线互不交叉。各黄像素所在列互不相同。

**规则**：
1. 对每组顶点，以该组所有顶点的质心为极点，按极角（从正上方顺时针）排序形成一个环路。
2. 按环路顺序依次连接相邻顶点（包括最后一个连回第一个）。仅绘制水平、垂直或 45 度方向的直线段，且线段内部（不含端点）的所有像素在绘制前必须为黑(0)。若某条边不满足方向约束或路径不通畅，则跳过该边不绘制。线段使用该组顶点的颜色。
3. 所有组的轮廓绘制完成后，逐个处理黄(4)像素（处理顺序不影响结果，因为各黄像素在不同列）。每个黄像素从其当前位置开始逐行向下移动（行索引递增），直到遇到以下之一时停止：
   - 下一行的同列位置是非黑像素（轮廓线、顶点或其他黄像素）：停在当前行。
   - 当前行已是网格最后一行：停在当前行。
4. 将黄像素的原位置设为黑(0)，在停止位置绘制黄(4)。
5. 所有顶点和轮廓线像素保持不变。

**关键洞察**：轮廓线承担双重角色——既是描边操作的输出（几何构造），又是重力操作的障碍（物理地形）。顶点的分布决定了"地形"的形状，而地形形状决定了黄像素的最终分布。不先完成描边就无法预测黄像素的落点。

## 新题 5：多米诺破壁开通新连线

**组合逻辑**：[four_neighbor_pairing → pair_recolor_erase](跨隔板的红-绿细胞配对触发多米诺擦除) → [擦除隔板段改变拓扑] → [connect/fill_gap_along_row_col](在新拓扑下同色像素沿行列连线)（创新：多米诺擦除不仅消灭像素，还移除隔板段，从而改变网格拓扑使原本不可达的同色像素变得可连接）

**来源原语**：bicolor_domino/four_neighbor_pairing/pair_recolor_erase（d90796e8）、divider_grid/fill_gap_along_row_col/same_color_pairing/axis_aligned（06df4c85）、connect（06df4c85）、erase（d90796e8）、recolor（多源）

**依赖链**：多米诺配对决定哪些隔板段被移除，隔板移除改变网格的连通拓扑，新拓扑决定哪些同色像素能够沿行列连通。三步之间存在结构性因果：隔板段的选择性移除是由多米诺的位置触发的，而连线路径是否通畅取决于移除后的隔板残余。删除多米诺步骤则隔板完整、某些连线无法穿越；删除连线步骤则隔板破壁无后续效果。

一句话总结：灰色隔板将网格分为单元格，跨隔板的红-绿相邻单元格配对后红格擦除、绿格变青并拆除中间隔板段，随后剩余同色像素沿行列方向穿越被拆除的隔板位置进行连线填充。

**输入结构**：
- 网格约 15x15，背景为黑(0)。
- 灰(5)像素形成完整的水平和垂直贯穿栏（每个栏占满整行或整列），将网格分割为矩形单元格，单元格大小约 3x3 至 5x5。
- 每个单元格内部（灰(5)栏围成的矩形区域）为黑(0)背景，其中部分单元格包含恰好一个彩色像素：红(2)、绿(3)或蓝(1)。其余单元格为空（全黑）。
- 生成约束：至少存在 2 对共享一段隔板的相邻单元格（水平相邻或垂直相邻），其中一个含红(2)像素、另一个含绿(3)像素（可形成跨隔板多米诺对）。至少存在 2 个蓝(1)像素，位于同一行或同一列，且它们之间的路径（沿该行或列）被至少一段隔板阻隔——该段隔板恰好是某对红-绿多米诺所共享的隔板段。红(2)和绿(3)像素在其单元格内的位置靠近共享隔板侧（保证"跨隔板邻接"可通过隔板两侧各一像素的概念成立）。

**规则**：
1. 识别隔板颜色：灰(5)。识别所有由灰(5)贯穿行/列划分的矩形单元格。
2. 定义"跨隔板邻接"：两个单元格共享一段灰(5)隔板段（水平方向：两个单元格上下相邻，之间隔着一行灰像素；垂直方向：左右相邻，之间隔着一列灰像素），且一个含红(2)像素、另一个含绿(3)像素。
3. 对每对跨隔板的红-绿对：将绿(3)像素重涂为青(8)，将红(2)像素设为黑(0)（擦除），并将它们之间共享的那段隔板上的所有灰(5)像素设为黑(0)（拆除隔板段）。拆除范围仅限于两个单元格之间的那段隔板（从两单元格重叠的行范围或列范围确定），不影响隔板的其他部分。
4. 所有多米诺处理完成后，对剩余的彩色像素（蓝(1)和青(8)分别处理）执行行列连线：对同色的每对像素，若它们在同一行或同一列上，沿该方向检查两者之间的所有像素——若路径上全为黑(0)像素（包括已被拆除的前隔板位置），则用该颜色填充路径上所有黑(0)像素。若路径上存在未拆除的灰(5)隔板像素或其他颜色像素，则不连线。
5. 同色像素的连线按对处理，顺序：先找同行对（行号从小到大，同行则列号从小到大），再找同列对（列号从小到大，同列则行号从小到大）。每对独立判断路径是否通畅。
6. 灰(5)隔板（未被拆除的部分）保持不变。

**关键洞察**：多米诺配对不仅消灭了红-绿像素本身，更关键的是拆除了它们之间的隔板段——这是一种拓扑修改操作。原本被隔板完全阻隔的两个蓝像素，在隔板被拆除后变得可沿行列连通。求解者必须先推理出哪些隔板会被拆除，才能判断哪些连线是可行的。

## 新题 6：标记计数定缩放因子、面积约束过滤印章

**组合逻辑**：[counting/marker_in_panel](计数矩形内标记数) → [pixel_scaling/side_sets_scale](计数结果作为缩放因子) → [stamp/same_size_replace](缩放模板印入矩形) ← [面积几何约束过滤]（创新：计数结果同时受到几何容纳性的约束——缩放后模板必须能装入目标矩形，否则该矩形不获得印章而是保留原样，成为干扰项）

**来源原语**：counting/marker_pixel/marker_in_panel/max_marker_panel（e50d258f）、pixel_scaling/scale_correspond/side_sets_scale（447fd412）、stamp/same_size_replace（e76a88a6）、solid_rectangle（e76a88a6）、ignore_distractors（35ab12c3/de809cff/d90796e8）

**依赖链**：标记计数决定缩放因子，缩放因子与矩形尺寸共同决定模板是否能装入（几何约束），能装入则印章、不能则保留原样。删除计数步骤则缩放因子未知；删除几何约束判断则所有矩形都被印章（部分会溢出出错）；删除印章步骤则计数无输出效果。

一句话总结：计数每个灰色矩形内的红色标记数作为缩放因子，将模板按该因子放大后印入矩形内部，若放大后模板超出矩形尺寸则该矩形保持灰色不变。

**输入结构**：
- 网格约 20x20，背景为黑(0)。
- 一个小型多色模板精灵位于网格左上区域，大小为 2x2 或 2x3，使用蓝(1)和黄(4)像素。模板为 4-连通。
- 4~6 个实心灰(5)矩形散布于网格中，尺寸各异（宽高在 3x3 到 10x10 之间），矩形之间互不重叠、不接触、不与模板重叠。
- 每个灰矩形内部包含 1~4 个红(2)单像素标记，标记位置不在矩形边缘行/列上（位于严格内部）。不同矩形的标记数量可能不同。
- 生成约束：至少一个矩形的标记数 k 满足"模板放大 k 倍后尺寸 ≤ 矩形内部尺寸"（能装入），至少一个矩形的标记数 k 满足"模板放大 k 倍后至少一个维度 > 矩形内部尺寸"（装不进，作为干扰项）。

**规则**：
1. 识别模板精灵：网格中唯一的由蓝(1)和黄(4)像素组成的 4-连通多色区域。记录其边界框及内部像素图案。
2. 识别所有灰(5)实心矩形。对每个矩形，计数其内部的红(2)标记像素数量，记为 k。
3. 将模板按因子 k 进行像素级放大（模板中每个像素变为 k x k 的同色方块）。计算放大后模板的尺寸（原宽 * k, 原高 * k）。
4. 判断放大后模板是否能装入该灰矩形的内部（灰矩形内部 = 去掉最外一圈灰像素后的区域，即宽-2 x 高-2）。若放大后模板的宽 ≤ 内部宽 且 高 ≤ 内部高，则能装入；否则不能。
5. 能装入的矩形：将放大后的模板印在矩形内部的左上角（内部区域的第 0 行第 0 列开始），模板像素覆盖灰(5)像素。内部中未被模板覆盖的区域保持灰(5)。矩形最外一圈灰(5)边框保持不变。
6. 不能装入的矩形：保持完全不变（包括红标记也保留在原位）。
7. 能装入的矩形中，红(2)标记像素被模板覆盖或被灰色保留区覆盖——标记在输出中不单独保留（被覆盖即消失）。
8. 模板精灵本身在输出中保持不变。

**关键洞察**：标记数量与矩形尺寸之间存在隐式的几何兼容性约束——不是所有矩形都会被印章，求解者必须同时考虑"数多少标记"和"矩形够不够大"两个条件。仅凭一个示例难以区分"标记数=3 但太小所以不印"和"标记数=3 且刚好装入"之间的差异。

## 新题 7：连接器拼合后内腔泛色并缩放印章

**组合逻辑**：[assemble/connector_pairing/incremental_assembly](连接器配对拼合精灵) → [flood_fill/enclosed_cavity](拼合体内腔泛色填充) + [counting → pixel_scaling → stamp](连接器对数决定缩放因子，模板印入锚点位置)（创新：拼合操作同时产生两个后果——内腔形状供填充、连接器对数供缩放，两条分支共享同一前驱且输出在空间上叠加）

**来源原语**：assemble/translate/connector_pixel/anchor_sprite/connector_pairing/incremental_assembly（cbebaa4b）、flood_fill/enclosed_cavity/connectivity_reachable（8b7bacbf）、counting（e50d258f）、pixel_scaling/scale_correspond（447fd412）、stamp（e76a88a6/447fd412）

**依赖链**：连接器拼合决定复合体形状 → 形状决定哪些区域是封闭内腔（泛色目标）；同时连接器对数决定模板缩放因子 → 缩放后模板印在锚点处。两条分支（泛色 vs 印章）在空间上可能重叠，需要优先级规则。删除拼合则无复合体、无内腔、无连接器计数；删除泛色则内腔留空；删除印章则对数信息无用。

一句话总结：散落的精灵通过红色连接器像素拼合成一体，拼合体内封闭的黑色腔体被蓝色泛色填充，同时连接器配对总数作为缩放因子将一个小模板放大后印在黄色锚点位置上，印章覆盖泛色但不覆盖精灵像素。

**输入结构**：
- 网格约 22x22，背景为黑(0)。
- 4~6 个小型精灵，每个由 4~10 个同色像素组成的 4-连通区域，使用绿(3)、橙(7)、灰(5)、栗(9)等颜色（每个精灵单色，不同精灵颜色可相同或不同）。
- 其中一个精灵包含一个 2x2 的黄(4)方块（锚点精灵），该方块是该精灵的一部分。
- 每个精灵边缘有 1~3 个红(2)单像素（连接器），连接器与精灵 4-邻接但不被精灵颜色包围（位于精灵轮廓的凸出位置）。
- 一个独立的 2x2 单色小模板（青(8)像素），位于网格角落，不与任何精灵接触。
- 生成约束：精灵散布位置保证存在唯一的拼合方案——每个非锚点精灵恰好可通过平移使其某个红像素与已有拼合体上的某个未配对红像素重合。拼合完成后所有红像素恰好全部配对。拼合后的复合体内部至少存在一个由黑(0)像素构成的封闭腔体（被精灵像素和红连接器完全包围的 4-连通黑色区域）。连接器配对总数 k 使得模板放大 k 倍后（2k x 2k）不超过复合体的边界框尺寸。

**规则**：
1. 锚点精灵（含黄(4) 2x2 方块的精灵）保持位置不变。
2. 按以下方式逐个拼合其余精灵：在当前拼合体（初始为锚点精灵）的未配对红(2)像素中，找到一个与某未拼合精灵的某个红(2)像素重合后能使该精灵的其他像素不与拼合体已有像素冲突（不重叠非红像素）的配对。将该精灵平移至配对位置，重叠的两个红像素视为已配对。重复直到所有精灵拼合完毕。
3. 拼合完成后，识别复合体内部的所有封闭黑(0)腔体：以复合体的所有非黑像素为边界，找到所有不与网格边缘黑像素 4-连通的黑(0)区域。
4. 将每个封闭腔体内的所有黑(0)像素泛色填充为蓝(1)。
5. 统计拼合过程中形成的红(2)连接器配对总数 k。将青(8)模板按因子 k 放大（每个像素变 k x k 方块），得到 2k x 2k 的放大模板。
6. 以锚点精灵中黄(4) 2x2 方块的左上角为基准点，将放大后的模板印在该位置（基准点 = 放大模板的左上角）。印章规则：青(8)模板像素可覆盖蓝(1)泛色像素和黑(0)背景像素；但不覆盖精灵原有颜色像素（绿/橙/灰/栗等）、红(2)连接器像素和黄(4)锚点像素。若放大模板某像素位置是精灵/连接器/锚点像素，跳过不印。
7. 裁剪输出为复合体边界框（包含所有非黑像素的最小矩形）。独立模板（原始青色 2x2）不出现在输出中。

**关键洞察**：拼合过程产生两个关键信息流——复合体的几何形状（决定内腔）和连接器配对数（决定缩放因子），二者在空间上汇聚于锚点处。印章与泛色的叠加顺序构成隐式的视觉冲突解决规则：青色印章覆盖蓝色泛色但不覆盖结构像素。求解者必须先完成拼合才能同时确定这两个后果。

## 新题 8：对角射线分割网格后计数选区

**组合逻辑**：[connect/draw_line/diagonal_alignment](对角像素对连线) → [ray_extend/trigger_splits_beam](触发点发射垂直射线分割网格) → [counting/marker_in_panel](分割区域内标记计数) → [crop/max_marker_panel](裁剪最多标记区域)（创新：对角连线和垂直射线共同构成非矩形分区，分区的形状由触发点位置隐式决定，计数在这些不规则分区中进行）

**来源原语**：connect/diagonal_pixel_pair/diagonal_alignment（db695cfb）、ray_extend/trigger_pixel/trigger_splits_beam（db695cfb）、counting/marker_pixel/marker_in_panel/max_marker_panel（e50d258f）、crop（e50d258f）

**依赖链**：对角像素对位置决定连线路径，路径上的触发点位置决定垂直射线方向，连线+射线共同分割网格为多个区域，标记在各区域中的分布决定输出哪个区域。删除连线步骤则触发点无所依附；删除射线步骤则网格无分区；删除计数步骤则无法选择输出区域。

一句话总结：蓝色对角像素对连成对角线，线上的品红触发点发射垂直对角射线将网格切分为多个区域，输出包含最多红色标记的区域。

**输入结构**：
- 网格约 15x15，背景为黑(0)。
- 2~3 对蓝(1)像素，每对中的两个像素位于同一条 45 度对角线上（同一条 / 或 \ 方向的对角线），相距 5~10 个像素。不同对位于不同的对角线上。
- 1~2 个品红(6)单像素，每个位于某对蓝像素所在对角线上、两个蓝像素之间的位置。
- 5~10 个红(2)单像素标记散布于网格各处，不在任何对角线上，也不在品红像素的位置。
- 生成约束：所有蓝(1)像素对之间的对角线段互不交叉。品红触发点发射的垂直射线（与所在对角线垂直的 45 度方向）在延伸到网格边界之前不会经过其他蓝(1)或品红(6)像素。对角线和射线将网格分为至少 3 个区域，且至少两个区域内有红标记。

**规则**：
1. 对每对蓝(1)像素（同一 45 度对角线上的两个蓝像素），用蓝(1)填充它们之间对角线上的所有像素（包括端点，端点本身已是蓝色）。对角线方向为 \ 或 /，由两端点的相对位置决定。
2. 对每个品红(6)像素，确定它所在的蓝色对角线的方向（\ 或 /）。从该品红像素出发，沿与该对角线垂直的 45 度方向（若对角线为 \，则垂直方向为 /；反之亦然）向两侧发射射线。射线逐像素延伸，用品红(6)涂色，直到到达网格边界为止。若射线路径上遇到已有的蓝(1)像素，射线在该蓝像素之前停止（不覆盖蓝像素）。品红像素本身保持品红色。
3. 所有对角线和射线绘制完成后，网格被蓝线和品红线分割为若干区域。定义区域为：由黑(0)和红(2)像素组成的 4-连通分量（蓝和品红像素作为边界，不属于任何区域）。
4. 统计每个区域中红(2)标记像素的数量。
5. 选择红标记数量最多的区域。若平局，选包含行索引最小的像素的区域；仍平局则选该行中列索引最小的像素所在区域。
6. 输出该区域的边界框裁剪：找到该区域所有像素（包括黑和红）的最小包围矩形，裁剪出该矩形。裁剪结果中，属于该区域的红(2)像素保留红色，属于该区域的黑(0)像素保留黑色，不属于该区域但在边界框内的像素（如其他区域的像素、蓝线、品红线）设为黑(0)。

**关键洞察**：对角线和垂直射线将网格分成非矩形的三角形或梯形区域——这种分区方式在标准 ARC 题中罕见。求解者必须先构建完整的线段网络，才能确定区域边界进而计数。触发点的位置沿对角线的哪个具体像素决定了射线的起点，从而大幅改变分区形状和各区域内的标记归属。

## 新题 9：空心框的边长映射填充色后光晕标记缺陷

**组合逻辑**：[fill/size_to_color_mapping](按边长给空心框填色) → [denoise/neighborhood_majority_color](识别填充后暴露的嵌入缺陷) → [dilation/defect_mark](缺陷位置膨胀生成反色光晕标记)（创新：第一步的填充操作使原本隐藏在黑色背景中的缺陷像素"暴露"出来——它们与填充色形成对比才被识别为缺陷，然后缺陷标记使用与填充色互补的另一种颜色）

**来源原语**：fill/hollow_rectangle/size_to_color_mapping/center_marker/marker_centered_inside_frame（00dbd492）、denoise/neighborhood_majority_color/dent/defect_mark/opposite_color_fill（de809cff）、dilation/neighborhood_expand/halo/marker_retains_color（4258a5f9）

**依赖链**：空心框边长决定填充色 → 填充后框内的异色像素成为可识别的缺陷 → 缺陷的邻域主色（即填充色）决定了用哪种对立色做光晕标记。删除填充步骤则缺陷不可识别（框内全是黑色背景，无法区分缺陷与背景）；删除缺陷识别则光晕无标记对象；删除光晕步骤则缺陷无可见标记。

一句话总结：红色空心框按边长被填入不同颜色，填色后框内残留的非填充色像素被识别为缺陷，每个缺陷位置膨胀出一圈使用对立颜色的 3x3 光晕并在中心标注青色。

**输入结构**：
- 网格约 18x18，背景为黑(0)。
- 3~5 个红(2)空心正方形框，边长分别为 5、7 或 9（不同框边长可相同或不同）。框与框互不重叠、互不接触，距网格边缘至少 1 像素。
- 每个框内部（被红框围成的黑色区域）有 0~2 个"缺陷像素"：它们是灰(5)单像素，在输入时与黑(0)背景混在一起，不与红(2)框像素邻接（至少距框边 1 像素）。
- 每个框的正中心位置（行列均为奇数索引差的中点）有一个红(2)标记像素（中心标记）。
- 生成约束：至少一个框包含缺陷像素，至少一个框无缺陷。缺陷像素的 3x3 邻域完全在框内部（不越过框边）。

**规则**：
1. 对每个红(2)空心框，根据其外边长映射填充色：边长 5 → 蓝(1)，边长 7 → 黄(4)，边长 9 → 绿(3)。将框内部所有黑(0)像素填充为对应颜色。红(2)框边和红(2)中心标记保持不变。
2. 填充完成后，检查每个框内部是否存在非填充色、非红(2)的像素。这些像素即为缺陷（灰(5)像素现在被填充色包围，成为明显异常点）。
3. 对每个缺陷像素，确定其所在框的填充色 C。查找对立色 C'：蓝(1) ↔ 绿(3)、黄(4) ↔ 橙(7)。（即蓝的对立色为绿，绿的对立色为蓝，黄的对立色为橙。）
4. 以缺陷像素为中心，将其裁剪后 3x3 邻域中的所有填充色 C 像素涂为对立色 C'。若邻域中有红(2)像素（框边或中心标记），保持红色不变。若邻域中有其他缺陷像素，该位置在处理到该缺陷时再独立处理。
5. 将缺陷像素本身（原灰(5)）重涂为青(8)，作为缺陷中心标记。
6. 所有缺陷处理顺序按行优先、列次之，不影响最终结果（因为不同缺陷的 3x3 邻域不重叠，由生成约束保证）。

**关键洞察**：缺陷在输入中是灰(5)像素嵌在黑(0)背景中，视觉上不显眼。只有在填充步骤将背景色替换后，灰像素才与填充色形成对比而被"暴露"。填充色本身又决定了光晕标记用哪种对立色——这意味着同一个灰缺陷在边长 5 的框中会产生绿色光晕，在边长 9 的框中则产生蓝色光晕。这种"填充暴露缺陷、填充色决定标记色"的双重依赖需要对比多个示例才能归纳。

## 新题 10：种子泛色沿线条画扩散后按封闭面积裁剪最大腔体

**组合逻辑**：[flood_fill/seed_pixel/connectivity_reachable](种子从边界沿线条画的连通关系泛色到封闭腔体) → [counting](计算每个腔体面积) → [crop/max_marker_panel](裁剪面积最大的腔体)（创新：泛色不仅标记腔体归属，其扩散范围取决于线条画的拓扑——同一条线条画可能围成多个腔体但只有与种子同侧连通的才被泛色，面积比较发生在泛色后的腔体之间而非所有腔体之间）

**来源原语**：flood_fill/seed_pixel/enclosed_cavity/line_drawing/connectivity_reachable（8b7bacbf）、counting/marker_in_panel/max_marker_panel（e50d258f）、crop（e50d258f）

**依赖链**：种子像素的位置与线条画的拓扑共同决定哪些腔体被泛色标记，泛色标记后的腔体面积决定裁剪目标。删除泛色步骤则无法确定腔体归属；删除面积比较则不知道裁剪哪个。

一句话总结：网格边界上的种子像素沿线条画的连通路径进入封闭腔体并泛色填充，计算每个被泛色的腔体面积，裁剪输出面积最大的腔体。

**输入结构**：
- 网格约 16x16，背景为黑(0)。
- 灰(5)像素形成线条画：多条连续的灰色线段（水平、垂直或 45 度对角线），交叉或相连构成一个网状结构，在网格内围出 3~6 个封闭腔体（被灰线完全包围的黑色 4-连通区域）。线条画整体 8-连通。
- 2~3 个种子像素位于网格边界（第 0 行、最后一行、第 0 列或最后一列），每个种子使用不同颜色（如蓝(1)、绿(3)、黄(4)）。每个种子像素与线条画的某部分 8-邻接。
- 生成约束：每个种子通过线条画的 8-连通路径可到达至少一个封闭腔体的边界。不同种子到达的腔体集合不完全相同（至少有一个腔体只能被一个种子的泛色到达）。所有封闭腔体的面积互不相同。至少一个封闭腔体不与任何种子连通（不被泛色，保持黑色）。

**规则**：
1. 识别线条画：所有灰(5)像素构成的结构。
2. 识别所有封闭腔体：网格中被灰(5)像素完全包围（4-连通意义下不与网格边界的黑(0)像素连通）的黑(0) 4-连通区域。
3. 对每个种子像素 S（颜色为 C_S），确定它能泛色哪些腔体：从 S 出发，沿灰(5)像素的 8-连通路径扩散。对于 S 能 8-连通到达的每一段灰线的每一侧，检查是否有封闭腔体与该段灰线 4-邻接。若有，则该腔体被种子 S "触达"。
4. 对每个被种子 S 触达的腔体，将腔体内所有黑(0)像素泛色填充为 C_S。若一个腔体被多个种子触达，使用沿灰线 8-连通路径距离该腔体边界最近的种子的颜色（最短路径，逐像素计算 8-连通步数）。若距离相等，使用行索引更小的种子；仍相等则列索引更小的种子。
5. 泛色完成后，计算每个已被泛色的腔体的面积（泛色像素数）。
6. 选择面积最大的腔体。输出该腔体的边界框裁剪：裁剪矩形包含该腔体的所有泛色像素及紧邻的灰(5)边界像素（即腔体边界框向外扩展 1 像素，但不超过网格边界）。裁剪结果中保留泛色像素和灰线像素的原色，其他位置设为黑(0)。

**关键洞察**：并非所有封闭腔体都会被泛色——只有通过线条画与种子连通的腔体才会被标记。这意味着线条画的拓扑结构（哪些线段连接哪些交叉点）隐式决定了种子的"可达范围"。面积最大的腔体未必是几何上最大的黑色区域，因为某些大腔体可能因与种子不连通而不被泛色，从而不参与比较。
