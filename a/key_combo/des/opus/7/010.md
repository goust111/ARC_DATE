## 新题 1：射线分隔腔室投票填充

**组合逻辑**：[射线延伸](原有) + [填充](原有) — 创新点：射线路径本身作为动态分隔墙创建腔室，腔室内标记像素的多数色决定填充色。源题中射线延伸和腔室填充是完全独立的两道题，此处射线路径"生成"了填充操作的作用对象。

**来源原语**：射线延伸、反射镜段、边界反射、特定色反射射线（来自 7e2bad24）；填充、连通腔室、正交邻接、邻接多数决（来自 7c8af763）；标记像素（多题共有）

**依赖链**：射线从种子端点出发沿对角方向延伸并在红色镜段上反射 → 射线路径与灰色墙段共同构成分隔结构 → 分隔结构将背景划分为若干 4-连通腔室 → 统计每个腔室内标记像素的颜色分布 → 以多数色填充整个腔室。删除射线步骤则腔室边界不完整无法确定区域；删除填充步骤则退化为单纯射线追踪。

从对角射线种子出发，沿对角线方向发射射线并在红色镜段上反射，射线路径与灰色墙段共同将网格分割为多个封闭腔室，每个腔室以其内部标记像素的多数色填充。

**输入结构**：黑(0)背景网格，约 13x13。包含：(1) 若干灰(5)直线段（水平或垂直，长 2-5 像素），作为固定墙段，分布于网格中但不自行围成封闭区域；(2) 一条 8-连通对角蓝(1)射线种子（2-3 像素长），其中一个端点的对角延伸方向指向网格内部；(3) 2-3 段红(2)短直线段（水平或垂直，长 2-3 像素），作为反射镜；(4) 散布的单像素标记，颜色为绿(3)、黄(4)、橙(7)中的若干种，分布在网格各区域。生成约束：射线完整追踪后，射线路径与灰色墙段共同将网格背景区域分隔为至少 3 个 4-连通腔室；每个含标记的腔室中有明确的多数色（不出现三色均等的情况）；至少两个腔室包含不同的多数色。

**规则**：
1. 从射线种子的可向网格内部对角延伸的端点出发，沿该对角方向逐步前进（8-连通方向）。
2. 若下一步到达的格子是红(2)镜段像素，不涂色该像素；水平镜段使行方向取反，垂直镜段使列方向取反。反射后继续沿新方向前进。
3. 若下一步到达的格子不是红(2)镜段像素，则将该格涂为蓝(1)，包括覆盖灰色以外的任何非红色前景像素。射线离开网格边界时停止。
4. 射线追踪完成后，将蓝(1)射线路径与灰(5)墙段像素共同视为墙。
5. 在剩余的黑(0)像素上做 4-连通区域标记，识别所有封闭腔室。
6. 对每个腔室，统计其内部标记像素（绿(3)、黄(4)、橙(7)）的颜色。将整个腔室填充为出现次数最多的标记色。
7. 若腔室不含任何标记像素，保持黑(0)。若多数色出现平局，选择腔室内该颜色标记像素中行索引最小（最靠上）的那个颜色；若行索引仍相同，选列索引最小（最靠左）的那个颜色。
8. 所有非背景像素（灰墙、红镜、蓝射线、标记像素本身）保持不变，不被填充覆盖。

**关键洞察**：射线的反射轨迹决定了网格如何被分割为腔室——不同的镜段排布会产生完全不同的区域划分，而区域划分直接决定了哪些标记像素"属于"哪个腔室，从而改变填充结果。必须先完整追踪射线才能确定腔室边界，这是一个动态生成结构再操作的过程。

## 新题 2：颜色位移蛇形压缩

**组合逻辑**：[平移](原有) + [排序+压缩](原有) — 创新点：颜色编码的位移改变了像素的列坐标，排序依据位移后的列位置而非原始位置。颜色同时充当运动指令和输出标识，"做双重用途"。

**来源原语**：平移、前景像素、颜色编码位移、颜色决定偏移（来自 342dd610）；排序、压缩、散布标记、列序排列、蛇形填充、奇行反序（来自 cdecee7f）

**依赖链**：按颜色编码偏移量平移每个像素 → 位移改变各像素的列坐标 → 以位移后列坐标排序 → 按蛇形顺序压缩到 3x3 输出。删除平移步骤则排序依据原始列位置，变成另一道题；删除排序/压缩步骤则退化为单纯平移。

将散布的彩色像素按颜色编码的偏移量平移后，以位移后列坐标为序蛇形压缩到 3x3 网格中。

**输入结构**：灰(5)背景网格，约 10x10。包含至多 9 个单像素前景标记，颜色为红(2)、蓝(1)、橙(7)、栗(9)中的若干种。所有前景像素占据互不相同的列。生成约束：每个像素按其颜色偏移量平移后仍在网格边界内；位移后所有像素的列坐标互不相同（无列冲突）。

**规则**：
1. 识别灰(5)背景和所有非灰前景单像素。
2. 对每个前景像素按颜色执行平移：红(2)向左移 2 格，蓝(1)向右移 1 格，橙(7)向上移 2 格，栗(9)向下移 2 格。保留原色。
3. 记录每个像素位移后的列坐标。
4. 按位移后列坐标从小到大排序全部前景像素。若位移后列坐标相同（生成时已排除此情况，但作为规则完备性说明），按位移后行坐标从小到大排序。
5. 将排好序的颜色序列写入一个 3x3 的灰(5)画布，蛇形填充：第 0 行从左到右，第 1 行从右到左，第 2 行从左到右。
6. 若前景像素不足 9 个，剩余格保持灰(5)。

**关键洞察**：排序的依据不是像素的原始位置，而是经颜色编码位移后的新位置。一个位于第 8 列的红(2)像素位移后到第 6 列，可能排在一个原本位于第 5 列但位移后到第 6 列右侧的蓝(1)像素之前。必须对比多个示例才能同时归纳出位移映射和蛇形填充方向。

## 新题 3：模板门控交替打孔

**组合逻辑**：[形状匹配](创新：匹配结果不用于重涂色，而用于选择性执行不同操作) + [擦除](原有) + [中线打孔](原有) — 创新点：形状匹配充当逻辑门，决定对每个目标对象施加"打孔"还是"擦除"两种完全不同的操作。源题中形状匹配仅用于重涂色，此处它控制操作分支。

**来源原语**：形状匹配、模板、框架、掩码相同、旋转反射等价（来自 845d6e51, 63613498）；擦除、矩形、中心线、交替、中线交替打孔（来自 3bdb4ada）

**依赖链**：从框架区提取模板形状 → 对每个矩形旁的关联精灵做旋转/反射归一化比较 → 匹配成功：擦除关联精灵后对矩形执行交替打孔 → 匹配失败：擦除整个矩形及其关联精灵。删除形状匹配则不知道哪些矩形该打孔哪些该擦除；删除打孔则退化为单纯形状筛选。

灰色 L 型框架内的模板形状决定了哪些矩形被交替打孔、哪些被整体擦除：矩形旁的关联精灵与模板形状匹配则打孔，不匹配则擦除。

**输入结构**：黑(0)背景网格，约 15x15。包含：(1) 一个灰(5) L 型框架（垂直臂在右、水平臂在底），其围合的左上区域内有一个单色模板精灵（4-连通，3-6 像素，颜色为青(8)），模板的归一化包围框不超过 3x3；(2) 框架区外，散布 3-5 个单色矩形（短边恒为 3，长边为 5 或 7，颜色各不相同，取自红(2)、蓝(1)、绿(3)、黄(4)、橙(7)），可水平或垂直放置；(3) 每个矩形的一条长边外侧紧邻（4-连通接触）一个小型单色精灵（4-连通，像素数与模板相同，颜色为品红(6)），其归一化包围框同样不超过 3x3。生成约束：至少一个关联精灵的归一化形状（在所有旋转和反射下）与模板相同，至少一个不同；所有矩形和精灵互不重叠、互不接触（同一矩形与其关联精灵的接触除外）。

**规则**：
1. 提取灰(5) L 型框架包围框内青(8)模板精灵的归一化形状掩码（最小包围框内的二值掩码）。
2. 对框架外的每个矩形，找到与之 4-连通接触的品红(6)关联精灵。
3. 将每个关联精灵的归一化形状掩码与模板在所有 8 种旋转/反射变换下比较。
4. 若匹配成功：先将该关联精灵擦除为黑(0)，然后对该矩形执行交替打孔——沿矩形长轴方向的中心线（短边方向的中间行/列），从距短边 1 像素处开始，每隔一个像素设为黑(0)。
5. 若匹配失败：将该矩形及其关联精灵全部擦除为黑(0)。
6. L 型框架和模板精灵保持不变。

**关键洞察**：形状匹配的结果不是决定"涂什么颜色"，而是决定"执行哪种操作"——这是一个条件分支结构。此外，匹配成功时必须先擦除关联精灵再打孔，因为关联精灵紧邻矩形长边，若不擦除会影响打孔结果的判读。需要对比多个示例才能归纳出"匹配→打孔，不匹配→擦除"的分支规则。

## 新题 4：色板交叉网格填充

**组合逻辑**：[生成网格](原有) + [填充](创新：填充规则由行/列色板的交叉匹配决定) — 创新点：网格生成与腔室填充共享同一空间结构，且填充逻辑是二维查表（行色板 x 列色板的交叉）而非单维映射。源题中网格生成只关注几何结构不涉及内容填充，此处几何参数和填充参数从输入的不同部分同时读取。

**来源原语**：生成网格、实心方块、网格线、边长决定间距、等距参数化（来自 695367ec）；填充、纯色色板、分栏面板、行列对应、色板决定填色（来自 15660dd6）

**依赖链**：读取角落实心方块的边长 S 和颜色 → 用 S 和颜色生成网格骨架 → 网格骨架将输出划分为格间腔室 → 读取顶行列色板和左列行色板 → 按行列色板交叉规则填充每个腔室。删除网格生成则无腔室可填；删除色板逻辑则只有空网格。

角落小方块的边长决定网格线间距，顶行和左列的色板行决定每个网格单元的填充色：行色板与列色板颜色相同时填充该色，不同时留空。

**输入结构**：黑(0)背景网格，约 8x8（仅作为信息编码区，输出尺寸由规则决定）。包含：(1) 左上角一个实心方块，边长 S（取 2 或 3），颜色为灰(5)；(2) 紧接方块右侧（从第 S 列开始），沿顶部第 0 行排列一行单像素列色板，共 K 个像素（K 在 3-4 之间），颜色取自红(2)、蓝(1)、绿(3)、黄(4)，允许重复；(3) 紧接方块下方（从第 S 行开始），沿最左列排列一列单像素行色板，共 K 个像素（与列色板数量相同），颜色取自同一集合，允许重复。生成约束：K*(S+1)+S 不超过 15（保证输出网格在 15x15 以内）。

**规则**：
1. 读取左上角方块的边长 S 和颜色 C（灰(5)）。
2. 读取顶行列色板序列 col_palette[0..K-1]（从左到右）。
3. 读取左列行色板序列 row_palette[0..K-1]（从上到下）。
4. 创建一个尺寸为 K*(S+1)+S 行 x K*(S+1)+S 列的黑(0)输出网格（但不超过 15x15）。
5. 绘制网格线：从第 S 行开始，每隔 S+1 行绘制一整行颜色 C 的水平线；从第 S 列开始，每隔 S+1 列绘制一整列颜色 C 的垂直线。共 K-1 条水平线和 K-1 条垂直线。
6. 对于第 i 行第 j 列的格间腔室（i, j 均从 0 起计）：若 row_palette[i] == col_palette[j]，则将该腔室内所有 SxS 个像素填充为该颜色；若不等，保持黑(0)。

**关键洞察**：填充结果既不能单看行色板、也不能单看列色板来预测——必须理解"交叉匹配"规则。只有行列色板颜色一致的格子才被填充，这形成类似真值表的二维逻辑。需要对比多个示例才能排除"按行填充""按列填充"等单维假设，归纳出交叉匹配规则。

## 新题 5：碰撞优先连线与聚合重涂色

**组合逻辑**：[连线](创新：多条线可能竞争同一格，需要距离优先解决冲突) + [重涂色](创新：重涂色目标由线段碰触投票决定) — 创新点：连线操作的冲突解决结果反馈决定了重涂色的输入，形成"多源汇聚→冲突裁决→聚合投票"的推理链。源题中连线和重涂色是独立逻辑。

**来源原语**：连线、孤立像素、矩形、行列对齐、对齐像素投射矩形、碰撞停止（来自 2c608aff）；重涂色（来自 963f59bc 等）；正交邻接（来自 7c8af763）

**依赖链**：每个对齐像素向矩形方向画线 → 多条线竞争同一格时按距离优先裁决 → 线段到达矩形边界处的颜色形成投票 → 矩形以边界处多数色重涂。删除连线则无颜色到达矩形；删除冲突裁决则线段颜色不确定；删除重涂色则只剩线段绘制。

将多个彩色像素沿行/列对齐方向向中央矩形画线，线段冲突时距目标更近的像素优先，矩形最终重涂为其边界上接触最多的线段颜色。

**输入结构**：灰(5)背景网格，约 12x12。包含：(1) 一个黑(0)单色矩形（宽 3-4、高 3-4），位于网格中部偏中央位置；(2) 5-8 个单像素前景标记，颜色取自红(2)、蓝(1)、绿(3)、黄(4)、橙(7)（允许不同像素同色）。每个像素与矩形共享至少一行或一列。生成约束：至少存在两个像素从同一方向（同行或同列的同一侧）朝矩形发射线段，使得线段在某些格上产生竞争冲突；每个像素与矩形之间的路径上无其他前景像素阻挡（路径仅经过灰(5)背景格）。

**规则**：
1. 识别灰(5)为背景，黑(0)矩形为目标，其余单像素为源像素。
2. 对每个源像素，确定它与矩形共享的行或列（若同时共享行和列，即像素在矩形的角延长线上，选择到矩形更近的方向；若距离相等，选行方向）。沿该共享行/列向矩形方向逐格延伸，直到下一格进入矩形区域时停止（不覆盖矩形像素），记录线段覆盖的所有格。
3. 若两条或多条线段覆盖同一格：该格取"到各自源像素曼哈顿距离最小"的那条线段的颜色。若距离相等，取源像素行索引较小的（更靠上优先）；行索引也相同则取列索引较小的（更靠左优先）。
4. 将所有线段（冲突解决后）绘制到输出上。
5. 收集矩形每条边界上、紧邻矩形外侧一格的所有线段颜色（即矩形四周正交相邻的非背景格的颜色）。
6. 将矩形整体重涂为这些边界相邻线段中出现频次最高的颜色。若频次并列，选其中行索引最小的相邻格对应的颜色；行索引也相同则选列索引最小的。
7. 背景、源像素、及无线段到达的格保持不变。

**关键洞察**：矩形的最终颜色不是由最多的源像素颜色决定，而是由"成功到达矩形边界"的线段颜色投票决定。一个颜色的像素数量多但距矩形远，其线段可能被更近的异色像素截断，导致边界投票中反而落败。空间距离通过碰撞裁决间接影响了重涂色的结果。

## 新题 6：标记三重功能的反射裁剪拼接

**组合逻辑**：[镜像](原有) + [裁剪](原有) + [拼接](原有) — 创新点：标记像素同时编码三种信息（反射轴、输出颜色、拼接顺序），三个操作通过标记的不同属性耦合在一起。源题中镜像由标记定轴但不涉及裁剪拼接，此处标记的空间位置额外决定了裁剪后的拼接顺序。

**来源原语**：镜像、单像素标记、共行列对齐、对齐决定镜像轴（来自 963f59bc）；裁剪（来自 7b7f7511, bc1d5164）；拼接/concatenate（来自 15660dd6）

**依赖链**：每个标记与源对象的对齐关系决定反射轴 → 整体反射源对象得到镜像副本 → 镜像副本涂为标记颜色 → 裁剪每个副本到最小包围框 → 按标记的列坐标排序 → 水平拼接为输出条带。删除镜像则无副本可裁剪；删除裁剪则无法拼接不同大小的副本；删除拼接则只是多个独立的反射。

源对象按每个标记像素的对齐关系分别镜像反射，反射副本涂为标记色后裁剪，再按标记列坐标左到右拼接成一条水平输出带。

**输入结构**：黑(0)背景网格，约 12x15。包含：(1) 一个多像素单色前景对象（4-连通，5-8 像素，颜色蓝(1)），位于网格左侧区域，形状为非对称的不规则连通体（非矩形、非线段，保证反射后形状与原件可区分）；(2) 2-3 个单像素标记，颜色各不相同（取自红(2)、绿(3)、黄(4)），每个标记恰好与源对象的某一个像素共享一行或一列（但不同时共享行和列），且每个标记仅与源对象的唯一一个像素有此共享关系。生成约束：各标记位置足够远离源对象和彼此，使得所有反射副本互不重叠、也不与源对象重叠；各标记的列坐标互不相同。

**规则**：
1. 保留源对象（蓝(1)）不动。
2. 对每个标记像素 M：
   a. 找到源对象中与 M 共享行（共行但不共列）或共享列（共列但不共行）的唯一像素 P。
   b. 若 M 与 P 共享行：以 P 和 M 之间的垂直中线为镜像轴，将整个源对象做水平反射（左右翻转）。
   c. 若 M 与 P 共享列：以 P 和 M 之间的水平中线为镜像轴，将整个源对象做垂直反射（上下翻转）。
   d. 将反射副本涂为 M 的颜色。
3. 对每个反射副本，裁剪到其最小包围框。
4. 按各标记的列坐标从小到大排列对应的裁剪副本。
5. 将排好序的裁剪副本水平拼接，副本之间间隔 1 列黑(0)，形成输出。输出中不包含源对象。

**关键洞察**：标记像素的"位置"决定反射轴（通过与源像素的行/列对齐关系），标记的"颜色"决定副本的涂色，标记的"列坐标"决定拼接顺序。三种属性来自同一个像素但驱动三个不同的操作步骤。改变标记位置不仅改变反射方向，还可能改变拼接顺序。

## 新题 7：楔形窗口下的瓦片渐显

**组合逻辑**：[平铺](原有) + [擦除](创新：擦除模式由楔形展开逻辑控制) — 创新点：瓦片提取提供"内容层"，楔形展开提供"可见性遮罩层"，两者叠加后输出仅显示三角窗口内的铺展内容。源题中瓦片提取和楔形展开完全独立，此处瓦片内容通过楔形遮罩被选择性展示。

**来源原语**：平铺、重复瓦片、轴向复制、沿重复轴取首半（来自 7b7f7511）；擦除、调色板行、标记竖条、以缺口为中心、逐行扩展楔形（来自 bae5c565）

**依赖链**：从输入下方区域提取重复瓦片 → 铺展瓦片覆盖目标画布 → 从调色板行读取缺口位置确定楔形中心列 → 从标记竖条读取楔形高度 → 用楔形遮罩擦除窗口外的铺展内容 → 在缺口列填入标记色。删除瓦片提取则无内容可显示；删除楔形遮罩则全部可见（退化为纯平铺）。

提取输入中的重复瓦片并铺满画布，再用以调色板行缺口为中心的三角楔形窗口遮罩它，仅保留楔形内的瓦片内容，缺口列填入标记竖条颜色。

**输入结构**：黑(0)背景网格，约 12x12。分为三个纵向区域：(1) 顶部第 0 行为调色板行，包含一行非黑前景像素（颜色各异，取自红(2)、蓝(1)、绿(3)、黄(4)等），其中恰有一个位置为黑(0)缺口；(2) 中部：一根垂直标记竖条，颜色为橙(7)，从第 1 行开始向下延伸 3-5 格，其列坐标位于缺口列或与缺口列正交相邻的列；(3) 底部：一个矩形色彩图案被完整复制了一次（水平并列或垂直并列），形成重复瓦片区域。瓦片尺寸约 3x3 至 4x4。生成约束：标记竖条的高度（行数 H）不超过调色板行宽度的一半，保证楔形不超出画布宽度。

**规则**：
1. 在底部区域找到重复轴，提取第一份瓦片（即两个相同半区中的第一个）。
2. 将提取的瓦片重复铺展，覆盖一个 H 行 x W 列的画布（H = 标记竖条高度，W = 调色板行宽度）。铺展时瓦片从画布左上角开始，按行优先、列循环地重复贴放。超出画布边界的部分裁掉。
3. 确定缺口列 G（调色板行中黑(0)像素的列坐标）。
4. 对铺展画布应用楔形遮罩：第 0 行（最顶行）仅保留第 G 列，其余设为黑(0)；第 k 行（k=0,1,...,H-1）保留第 G-k 列到第 G+k 列的范围（含两端），范围外设为黑(0)。若 G-k < 0 或 G+k >= W，则仅保留边界内的部分。
5. 在楔形内，将第 G 列的所有行强制设为橙(7)（标记竖条颜色），覆盖该列的瓦片内容。
6. 输出该遮罩后的画布。

**关键洞察**：同一瓦片在不同缺口位置下会呈现完全不同的三角切面——瓦片的周期性图案与楔形窗口的三角边界交互，产生的可见部分既非纯瓦片也非纯楔形。必须同时理解瓦片的重复规律和楔形的展开规律才能预测输出。

## 新题 8：形状图例索引的分块印章

**组合逻辑**：[形状匹配](创新：匹配结果用于索引印章内容而非重涂色) + [印章覆盖](创新：每个槽位印章的形状不同，由颜色间接索引) + [像素放大](原有) — 创新点：颜色→形状→位置的双重间接链。源题中印章覆盖在所有位置印相同图案，此处每个位置的印章内容由该位置的颜色经图例查表后决定，不同位置可能印不同形状。

**来源原语**：形状匹配、图例区域、分隔线、旋转反射等价（来自 845d6e51）；印章覆盖、输入图案、块槽位、高频色定印章位（来自 27f8ce4f）；像素放大（来自 27f8ce4f）；标记锚定精灵（来自 e6721834）

**依赖链**：读取图例区域的形状-颜色映射表 → 读取控制网格中每格的颜色 → 颜色查图例得到对应形状 → 将形状印入输出对应的块槽位。删除图例则颜色无法映射为形状；删除控制网格则不知印在哪；删除印章步骤则只有映射表无输出。

以颜色为索引在图例区查得对应的精灵形状，将每种形状印入控制网格中对应颜色所在位置的输出块槽位，实现"颜色→形状→位置"的双重间接印章。

**输入结构**：黑(0)背景网格，约 14x14。包含：(1) 左上区域由绿(3) L 型分隔线（从顶边到左边）围出一个图例区，图例区内包含 2-3 个单色模板精灵（4-连通，3-5 像素，每个精灵一种独特颜色，取自红(2)、蓝(1)、黄(4)），每个精灵的最小包围框不超过 3x3，精灵之间不相邻；(2) 右下区域有一个 3x3 的控制网格（9 个格，每格 1 像素），每格要么是黑(0)要么是图例中某模板精灵的颜色。生成约束：控制网格中每种非黑颜色恰好对应图例中的一个模板精灵（颜色一一对应）；至少使用 2 种不同的非黑颜色。

**规则**：
1. 读取图例：在绿(3) L 型分隔线围合的左上区域内，找出每个 4-连通单色精灵。每个精灵的颜色 c 映射到其最小包围框内的形状掩码 mask(c)（像素坐标相对于包围框左上角的二值矩阵）。
2. 读取 3x3 控制网格中每格的颜色。
3. 创建一个 9x9 黑(0)输出，逻辑上划分为 3x3 的块槽位（每个块槽位 3x3 像素）。
4. 对控制网格第 i 行第 j 列的格（i, j 从 0 起计）：
   a. 若该格为黑(0)，对应输出块槽位保持全黑。
   b. 若该格颜色为 c（非黑），查图例得 mask(c)。将 mask(c) 以颜色 c 绘制到输出第 i 行第 j 列的 3x3 块槽位中，掩码左上角对齐块槽位左上角。掩码中为 0 的位置保持黑(0)。
5. 绿(3)分隔线和图例精灵不出现在输出中。

**关键洞察**：与经典印章覆盖（所有位置印相同图案）不同，此处每个块槽位的印章形状取决于该位置在控制网格中的颜色。控制网格是"印什么、印哪里"的编码表，图例是"颜色→形状"的解码器。求解者必须先建立颜色到形状的映射关系，才能理解不同位置为何出现不同形状。
