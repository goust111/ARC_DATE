## 新题 1：重力沉降后的形状族重涂

**组合逻辑**：[滑动+重力沉降] → [形状相同+平移归一化](创新：在重力变形后的结果上做形状匹配) → [重涂色](创新：按形状族成员数量决定目标色) + [擦除](孤例形状被移除)

**来源原语**：滑动+重力沉降(3618c87e), 形状相同+平移归一化(ad38a9d0), 重涂色(ad38a9d0/e9b4f6fc), 擦除(009d5c81), 计数(794b24be)

**依赖链**：重力沉降改变像素的纵向位置 → 新位置决定沉降后形成的 4-连通分量形状 → 形状归一化后匹配出"形状族" → 族的成员数量驱动重涂色规则 → 成员数量为 1 的孤例族触发擦除。每一步的输出实质性改变下一步的输入：重力决定形状、形状决定分族、分族决定颜色或擦除。

将散布在网格上方的小型精灵体经重力沉降后按归一化形状分族，族大小决定统一重涂色或擦除。

**输入结构**：约 14x12 的网格，黑(0)为背景。底部一行为灰(5)基线行。网格上半部散布 6~8 个小型 4-连通单色前景精灵体（每个 3~6 像素），颜色取自蓝(1)、红(2)、绿(3)、橙(7)等，各精灵体颜色可能不同。关键生成约束：任意两个精灵体不共享任何列（各精灵体占据的列集合两两不相交），保证重力沉降后每个精灵体保持自身连通性不与其他精灵体合并。精灵体的具体形状不固定（不同示例中同一"族"的成员外形相同但颜色和位置不同），保证恰好存在 2~3 个形状族，每族 2~4 个成员，另有 0~1 个孤例。

**规则**：
1. **重力沉降**：每个非背景、非基线像素在其所在列内下落到最低可用单元格。基线行视为可穿透着陆面（像素可落在基线位置上替换灰色）。沉降后灰(5)基线中被像素占据的格子显示该像素颜色，未被占据的基线格子保持灰(5)。
2. **形状族识别**：对沉降后的全部非背景、非灰(5)像素做 4-连通分量分析。将每个分量的掩码平移归一化（边界框左上角对齐到原点）。掩码完全相同的分量归入同一形状族。
3. **重涂色**：对每个形状族，统计成员数 k。若 k=2，将该族所有成员像素重涂为红(2)；若 k=3，重涂为绿(3)；若 k>=4，重涂为蓝(1)。（k 与目标色的映射需对比多个示例才能归纳。）
4. **孤例擦除**：成员数 k=1 的形状族，其唯一分量的所有像素擦除为黑(0)背景。
5. 灰(5)基线中未被前景像素占据的格子保持不变。

**关键洞察**：重力沉降不改变各精灵体的归一化形状（因列不重叠），但改变了它们的纵向位置；形状族匹配发生在沉降后的结果上，而 k→颜色的映射关系是隐蔽规则，必须对比多个示例中不同 k 值的族与其输出色才能归纳。

## 新题 2：标记射线驱动的不对称纵向填充

**组合逻辑**：[射线延伸+行对齐](创新：射线从标记像素水平发射至网格边缘，射线终端成为纵向填充的起点) → [延伸填充+距离控制高度+不对称递变](创新：射线到达位置的水平距离决定纵向填充高度，且左右两侧的高度递变公式不同) + [重涂色](射线源标记的颜色决定填充色)

**来源原语**：射线延伸+行对齐(673ef223), 标记像素(673ef223), 延伸填充+距离控制高度+不对称递变(5207a7b5), 纵条(5207a7b5), 重涂色(673ef223)

**依赖链**：标记像素的行位置决定射线方向和到达列 → 射线到达列与源纵条的水平距离决定填充高度（通过不对称递变公式） → 标记像素在纵条内的相对偏移决定填充颜色。射线的空间信息同时编码了填充的位置、高度和颜色三个参数。

标记像素从中央纵条向两侧发射水平射线，射线在边缘产生纵向填充柱，填充高度随距离不对称递变，填充颜色由标记在纵条内的位置决定。

**输入结构**：约 15x15 的网格，黑(0)为背景。网格中间有一条灰(5)纵条（1 像素宽，从第 0 行延伸到第 H-1 行，H 为纵条高度，约 4~7）。纵条上有 2~4 个标记像素，分别着色为红(2)或蓝(1)，替换纵条对应行的灰色。纵条左右两侧各至少有 3 列空间。标记像素之间不相邻（至少间隔一行）。

**规则**：
1. **识别纵条和标记**：找到灰(5)纵条及其上的非灰标记像素。记录纵条高度 H 和纵条所在列 C。
2. **发射射线**：每个标记像素向左和向右各发射一条水平射线，射线颜色为该标记像素的颜色。射线在标记所在行上从纵条向外延伸，填充该行上纵条与网格边缘之间的所有背景格子（不覆盖纵条本身）。
3. **纵向填充**：对左侧每一列（距纵条水平距离为 d，d=1,2,3,...），从该列顶部向下填充 H + 2d 个格子，颜色为触发该列射线的标记像素颜色。若多条射线经过同一列，填充高度取各射线中 H+2d 的最大值，颜色取该列最上方射线的颜色。对右侧每一列（距离 d=1,2,3,...），从该列顶部向下填充 max(H - 2d, 0) 个格子，规则同上。填充高度超出网格时裁剪到网格边界。填充高度为 0 或负值时不填充。
4. **保留纵条**：灰(5)纵条像素始终保持不变，标记像素保持其原色。
5. **射线与填充柱重叠时**：射线行上的像素同时属于水平射线和纵向填充柱，保持该标记颜色不变（两者颜色一致）。

**关键洞察**：左侧填充柱随距离增高、右侧随距离缩短，这一不对称递变规则需通过对比多个示例中不同距离列的填充高度差异才能归纳。射线本身只是一维的水平线段，但它驱动了二维的不对称填充图案。

## 新题 3：完整方块计数决定图案缩放与反射方向

**组合逻辑**：[计数+完整方块过滤+忽略干扰项] → [缩放+尺寸比编码缩放](创新：计数结果作为缩放因子而非尺寸比) → [反射+奇偶性](创新：计数的奇偶性决定是否对缩放结果做水平反射)

**来源原语**：计数+完整方块过滤+忽略干扰项(3b4c2228), 缩放+尺寸比编码缩放(b10624e5), 图案母题(b10624e5), 反射(b10624e5), 奇偶性(22806e14)

**依赖链**：识别完整方块并过滤干扰项 → 完整方块计数 N 作为缩放因子 → N 的奇偶性决定反射轴的有无 → 缩放和反射共同作用于源图案生成输出。计数同时编码了两个参数（缩放幅度和反射与否），使三个操作不可分离。

统计网格中完整方块的数量 N，将源图案放大 N 倍；若 N 为奇数则对放大结果做水平翻转，偶数则不翻转。

**输入结构**：约 15x15 的网格，黑(0)为背景。左上角区域有一个 3x3 的彩色图案母题（使用 2~3 种非黑颜色，含内部黑(0)孔洞，具体像素排列因示例而异）。网格其余区域散布若干前景对象：部分为绿(3)的实心正方形（边长 2x2，4 个像素全为绿(3)），部分为红(2)的干扰项（单个像素、非方形的小连通体、或不完整的 2x2 区域）。绿(3)完整方块数量在 1~3 之间。图案母题与所有方块/干扰项之间至少间隔 2 行 2 列。

**规则**：
1. **完整方块计数**：在网格中找出所有绿(3) 4-连通对象。仅保留边界框恰为 2x2 且面积恰为 4 的对象，计其数量为 N。忽略所有红(2)对象和不满足 2x2 完整条件的绿(3)对象。
2. **提取图案母题**：裁剪左上角 3x3 图案母题的边界框内容（保留内部黑(0)孔洞）。
3. **缩放**：将母题放大 N 倍——母题中每个像素变为 NxN 的同色块。输出尺寸为 3N x 3N。
4. **奇偶反射**：若 N 为奇数，将整个缩放结果沿垂直中轴做水平翻转（左右镜像）；若 N 为偶数，不翻转。
5. **输出**：仅输出 3N x 3N 的缩放（并可能翻转后的）图案，不包含原始网格中的方块或干扰项。

**关键洞察**：干扰项的存在迫使求解者必须先正确过滤出完整方块；N 同时决定缩放倍率和翻转与否，两个决策无法独立做出——错误的 N 会同时导致尺寸和朝向都错。翻转规则（奇→翻，偶→不翻）是隐蔽规则，需对比不同 N 值的示例归纳。

## 新题 4：字形编码洪泛填充与最近传播

**组合逻辑**：[形状编码颜色+按形状映射颜色](创新：字形形状不再映射到全局统一色，而是映射到各自所在封闭区域的填充色) → [洪泛填充+封闭区域] → [最近扩散+最近种子分区+等距异色为分隔](创新：已填充区域作为种子向未填充区域扩散)  + [擦除]

**来源原语**：标记字形+形状编码颜色+按形状映射颜色(009d5c81), 洪泛填充+封闭区域+分隔线(941d9a10), 最近扩散+最近种子分区+等距异色为分隔(332202d5), 擦除(009d5c81)

**依赖链**：字形形状识别决定区域颜色 → 填充后的区域作为种子 → 无字形区域通过最近种子逻辑获得颜色 → 等距异色区域变为分隔色 → 字形本身被擦除。字形解码、区域填充、最近传播三步相互依赖：不识别字形就不知道种子色，不填充种子就无法传播，不传播就无法确定分隔行。

灰色分隔线将网格划分为多个封闭区域，部分区域包含小型标记字形；字形的形状编码该区域应填充的颜色，无字形区域通过最近已填充区域传播获得颜色。

**输入结构**：约 13x13 的网格，黑(0)为背景。灰(5)线条（单像素宽，水平或垂直贯穿整行或整列）将网格划分为 4~6 个封闭的矩形区域。其中 2~3 个区域内部各包含一个由品红(6)像素组成的 3x3 标记字形（字形位于区域中央，不接触灰线）。字形有三种可能形状：十字形（5 像素）、横杠形（3 像素，中间一行）、角形（3 像素，呈直角排列）。其余区域内部为纯黑背景，不含字形。生成约束：每种字形形状在一个输入中最多出现一次。

**规则**：
1. **识别区域与字形**：找到灰(5)分隔线划分出的所有封闭矩形区域。在每个区域内检测是否存在品红(6) 4-连通字形。
2. **字形解码**：将字形的归一化形状映射为颜色——十字形（中心加四邻）→ 红(2)；横杠形（水平三连）→ 蓝(1)；角形（直角三像素）→ 绿(3)。此映射需对比多个示例归纳。
3. **种子区域洪泛填充**：将含字形区域内所有黑(0)背景像素填充为字形解码出的颜色。字形本身的品红(6)像素擦除为该解码颜色（即字形融入填充区域）。
4. **最近传播**：对每个不含字形的空白区域，计算其中心点到每个已填充种子区域中心点的曼哈顿距离。将该空白区域填充为最近种子区域的颜色。
5. **等距分隔**：若某空白区域到最近的两个种子区域距离相等且这两个种子颜色不同，则将该区域填充为黄(4)作为分隔标记。若距离相等但颜色相同，则填充为该共同颜色。
6. **保留分隔线**：灰(5)分隔线始终不变。

**关键洞察**：字形形状与颜色的对应关系是隐蔽规则；更关键的是，空白区域的最终颜色取决于字形解码后的种子颜色分布，而非空白区域自身的任何属性——字形解码错误会导致传播结果完全不同。分隔标记（黄色）仅在异色等距时出现，这一条件判断也是隐蔽的。

## 新题 5：紧凑排列后的奇偶性角标

**组合逻辑**：[裁剪+紧凑排列+空间位置排序+按输入位置排列] → [标记+角点邻接+完整方块才标记](创新：标记不针对原始对象而针对排列后在图集中的对象) + [奇偶性+奇边长才标注](创新：奇偶性作为标记的过滤条件，仅对原始边界框短边为奇数的精灵体做角标)

**来源原语**：裁剪+紧凑排列+空间位置排序+按输入位置排列(1990f7a8), 精灵体+图集画布(1990f7a8), 标记+角点邻接+完整方块才标记(14b8e18c), 奇偶性+奇边长才标注(22806e14)

**依赖链**：裁剪和排列改变精灵体的相对位置 → 角标必须基于排列后的新位置计算 → 但角标是否生成取决于精灵体在原始输入中的边界框短边奇偶性（排列后无法获知这一信息，必须在裁剪前记录）。排列操作和标记操作通过"位置来自排列后、资格来自排列前"的双重依赖紧密耦合。

将散布的精灵体裁剪并紧凑排列为图集，然后仅对原始短边为奇数的精灵体在图集中的角落外侧标注红色标记。

**输入结构**：约 18x18 的网格，黑(0)为背景，使用一种前景色蓝(1)。恰好 4 个分离的 4-连通蓝(1)精灵体，每个包含在一个 3x3 或 3x4 或 4x3 或 4x4 的边界框内（即每个精灵体的边界框宽和高各为 3 或 4 像素）。精灵体内部可有黑(0)孔洞。4 个精灵体空间上分成上方两个、下方两个，左右各一，形成 2x2 的大致布局。精灵体之间间距较大（至少 4 行 4 列）。不同示例中精灵体的具体形状不同，但边界框尺寸的奇偶性组合因示例而异。

**规则**：
1. **裁剪**：提取每个精灵体的边界框内容（保留内部黑(0)孔洞）。记录每个精灵体边界框的宽 W 和高 H。
2. **排列**：按输入位置排序——上方两个（左先右后），然后下方两个（左先右后）。将 4 个裁剪结果排列到一个紧凑的图集画布上：2 行 2 列的块布局，每个块为 4x4（可容纳最大边界框），块之间水平间隔 1 列、垂直间隔 1 行，图集总尺寸为 9x9。若某精灵体边界框小于 4x4，其裁剪结果放置在块的左上角，剩余空间保持黑(0)。
3. **奇偶性过滤**：对每个精灵体，取其原始边界框短边 min(W, H)。若短边为奇数（即 3），该精灵体"有资格"获得角标；若短边为偶数（即 4），无资格。
4. **角标标记**：对每个有资格的精灵体，在图集中找到其裁剪内容的实际边界框（不是 4x4 块，而是其中非背景像素的最小包围矩形）的四个角点。在每个角点的两个正交外侧相邻背景格子上涂红(2)。若外侧格子超出图集边界或已被其他精灵体像素占据，则跳过该格子不涂。
5. **输出**：输出 9x9 图集画布。

**关键洞察**：角标的空间位置由排列后的图集决定，但角标的触发条件（奇偶性）由原始输入中的边界框决定——求解者必须同时追踪排列前后的信息才能正确标注。仅看图集输出无法推断奇偶条件，必须对比原始输入中各精灵体的边界框尺寸。

## 新题 6：对称补全后按补全轴分层排列

**组合逻辑**：[对称补全+轴对称反射+控制标记指示源侧](保留) → [裁剪+紧凑排列](创新：排列布局由补全轴方向决定而非仅由输入位置决定) + [排序+空间位置排序](创新：同一轴方向的精灵体内部按原始位置排序)

**来源原语**：对称补全+轴对称反射+控制标记指示源侧+对称轴+控制标记(5b692c0f), 裁剪+紧凑排列+空间位置排序(1990f7a8), 排序(941d9a10)

**依赖链**：控制标记和对称轴决定补全方向及结果形状 → 补全轴方向（水平/垂直）将精灵体分为两组 → 组别决定精灵体在输出图集中的行位置 → 组内按原始输入位置排序决定列位置。补全操作的副产品（轴方向）直接编码了排列结构，使补全和排列不可分离。

各精灵体经对称补全后裁剪，按其对称轴方向分为两组分层排列：水平轴补全的排上层，垂直轴补全的排下层。

**输入结构**：约 20x20 的网格，黑(0)为背景。散布 4~6 个不完整的前景对象，每个对象使用一种非黑、非黄的前景色（蓝(1)、红(2)、绿(3)、品红(6)、橙(7)中各取一种，各对象颜色互不相同）。每个对象内部包含黄(4)像素，由两部分组成：一条连续的黄(4)线段作为对称轴（水平或垂直，长度等于对象在该方向的跨度），以及至少一个偏离轴的黄(4)像素作为控制标记（位于轴的一侧）。对象的边界框约 4x4 至 6x6，各对象之间至少间隔 3 像素。生成约束：至少有一个水平轴对象和一个垂直轴对象。补全后每个对象的边界框不超过 6x6。

**规则**：
1. **对称补全**：对每个含黄(4)轴的对象，识别轴方向（水平或垂直）和控制标记所在侧。以控制标记所在侧为源侧，将源侧的全部像素（含前景色和黑(0)背景）沿轴镜像复制到对侧，覆盖对侧原有内容。轴本身保持黄(4)。
2. **记录轴方向**：标记每个对象的补全轴方向——"H"（水平轴，即上下对称）或"V"（垂直轴，即左右对称）。
3. **裁剪**：对每个补全后的对象裁剪其边界框内容。将裁剪结果中的黄(4)轴像素替换为该对象的前景色（轴融入对象）。
4. **分组排列**：将所有对象按轴方向分为两组：H 组和 V 组。H 组排列在输出图集的上层，V 组排列在下层。每组内部按原始输入中对象边界框左上角的位置排序（先比较行号，行号相同则比较列号，小的在左）。
5. **图集构建**：每个裁剪结果放入一个 6x6 的槽位（左上角对齐，不足部分保持黑(0)）。同一层的槽位水平排列，槽位间水平间隔 1 列。上下层之间垂直间隔 1 行。若某组为空（所有对象都是同一轴方向），则输出仅一层。图集画布大小恰好容纳所有槽位和间隔。

**关键洞察**：对称轴方向不仅决定补全操作的镜像方式，还同时决定了该精灵体在输出中的层级归属——这是原参考题中不存在的结构关系。求解者必须先正确判断每个对象的轴方向才能同时完成补全和分组两项任务。

## 新题 7：嵌套层展开与图例绑定重涂

**组合逻辑**：[展开嵌套+块序映射层序+逆序读取] → [重涂色+颜色替换映射+图例色替换](创新：图例不是全局替换，而是按层序号与图例行序号一一绑定) + [擦除](展开后擦除原嵌套图案)

**来源原语**：展开嵌套+块序映射层序+逆序读取+块单元+嵌套层(8fff9e47), 裁剪+重涂色+颜色替换映射+微型图例+图例色替换(e9b4f6fc), 擦除(009d5c81)

**依赖链**：展开操作确定每个 2x2 块对应哪一嵌套层（层序号） → 层序号与图例行序号绑定确定该块适用哪条替换规则 → 替换规则改变块中像素颜色。展开的逆序读取顺序直接决定了哪个图例作用于哪个块，使结构分解和颜色替换通过序号对齐紧密耦合。

将同心嵌套方阵展开为 2x2 块条带，然后按层序号与图例行号一一对应进行颜色替换。

**输入结构**：网格分为两个区域，以至少 2 列黑(0)间隔分隔。左侧区域包含一个同心嵌套正方形图案（边长为偶数，约 6x6 或 8x8），由 3~4 层同心"口"字形环构成，每层一种颜色（从外到内依次使用不同颜色，如蓝(1)、红(2)、绿(3)、橙(7)等）。右侧区域垂直排列 3~4 个水平 2 像素的微型图例色块（图例间垂直间隔 1 行），每个图例色块为左右两个像素 [新色, 旧色]，从上到下排列。图例数量等于嵌套层数。

**规则**：
1. **识别嵌套图案**：在左侧区域找到同心嵌套正方形图案。确定层数 L（最外层为第 1 层，最内层为第 L 层）。
2. **展开为块条带**：将嵌套图案转换为一条水平排列的 2x2 块序列。每一嵌套层贡献一个 2x2 块——该层环的四个角像素（左上、右上、左下、右下）分别成为块的对应位置像素。读取顺序为逆序：最内层的 2x2 块排在条带最左端，最外层排在最右端。
3. **图例绑定**：将右侧图例从上到下编号为 1, 2, ..., L。将条带中从左到右的 2x2 块编号为 1, 2, ..., L。序号相同的图例和块绑定。
4. **颜色替换**：对每个 2x2 块，应用其绑定图例的替换规则——将块中所有匹配"旧色"（图例右像素颜色）的像素替换为"新色"（图例左像素颜色）。块中不匹配旧色的像素保持原色。
5. **输出**：输出仅包含处理后的 2x2 块条带（水平排列，块间无间隔），尺寸为 2 x 2L。不包含原嵌套图案和图例。

**关键洞察**：展开的逆序读取将最内层与第一个图例绑定，而非直觉上的最外层与第一个图例绑定——这一顺序反转是核心隐蔽规则。若不仔细对比多个示例中各层颜色与图例的对应关系，很容易将绑定顺序搞反。

## 新题 8：多色像素分组计数与排序对角线编码

**组合逻辑**：[计数+像素数转计数图](创新：不是单色计数后转 tally，而是多色分别计数) → [排序+位置排序](创新：按计数值排序各颜色) → [对角线编码](创新：对角线上每个位置使用排序后对应颜色的实际色值填充，而非统一蓝色)

**来源原语**：计数+像素数转计数图(794b24be), 对角线编码+对角线单元(3b4c2228), 排序+位置排序(941d9a10), 前景像素(794b24be/3618c87e), 忽略干扰项(3b4c2228)

**依赖链**：分色计数得到每种颜色的像素总数 → 计数值排序决定各颜色在对角线上的位置（计数最少的在左上） → 对角线上的格子用对应颜色的实际色值填充。计数、排序、颜色编码三者环环相扣：计数决定排名，排名决定位置，颜色决定填充值。

统计网格中各前景色的像素数量，按数量从少到多排序，将排序后的颜色依次填入输出网格的主对角线格子。

**输入结构**：约 7x7 的网格，黑(0)为背景。前景像素散布在网格各处，使用 3~5 种不同的非黑前景色（如红(2)、绿(3)、蓝(1)、橙(7)、品红(6)等），每种颜色的像素数量互不相同，范围在 1~6 个之间。另外可能存在灰(5)的单像素干扰项（0~2 个），不参与计数。各颜色的像素空间分布随机，不构成规则形状。

**规则**：
1. **过滤干扰项**：忽略所有灰(5)像素，仅统计非黑(0)、非灰(5)的前景色。
2. **分色计数**：统计每种前景色的像素数量。设共有 K 种前景色。
3. **排序**：将 K 种颜色按像素数量从少到多排序。生成约束：各颜色像素数量互不相同，因此排序唯一确定，无需 tie-break。
4. **对角线编码**：创建一个 KxK 的黑(0)背景输出网格。将排序后的第 i 种颜色（i 从 0 开始）填入位置 (i, i)，即主对角线的第 i 个格子，填充值为该颜色的实际色值。
5. **输出**：仅输出 KxK 的对角线编码网格。

**关键洞察**：对角线上每个格子的颜色不同——它不是"计数多少填多少格"的 tally 图，而是"谁排第几就填在对角线第几位"的排名图。排序依据（像素数量从少到多还是从多到少）是隐蔽规则，需对比多个示例才能确定。同时，灰色干扰项的存在迫使求解者必须先正确过滤再计数。
