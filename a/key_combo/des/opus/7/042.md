## 新题 1：旋转族补全后的封闭区域条件填充

**组合逻辑**：[旋转/rotate + 补全/complete](已有) → [封闭区域检测/enclosure_detection](创新：在旋转补全结果上检测) → [填充/fill](创新：填充色由封闭面积阈值决定)

**来源原语**：旋转(rotate)·补全(complete)·缺失旋转变体(missing_rotation) ← be03b35f；填充(fill)·封闭区域(enclosed_region)·包围(enclosure)·含孔洞者选中(object_with_hole_selected) ← dbff022c / b9b7f026

**依赖链**：旋转补全恢复了第四象限的图案 → 恢复后才能判断各象限图案是否形成封闭区域 → 封闭区域面积决定填充颜色。缺失象限可能包含关键的封闭区域，因此补全是填充的前置条件而非独立步骤。

将被占位色遮蔽的旋转变体补全后，检测所有四个象限中图案围成的封闭区域，按面积分档填色。

**输入结构**：约 13x13 的网格。灰(5) 单像素宽的十字将网格分为四个等大的正方形象限（每个约 6x6）。三个象限内包含蓝(1) 像素在黑(0) 背景上构成的图案（4-连通、4~8 像素），三个图案互为 90° 旋转的连续变体。第四个象限被橙(7) 完全填充作为占位标记。图案的基础形态具有弯折结构，某些旋转方向下像素围成封闭回路，另一些则不围成。不同示例中基础形态的具体形状不同，但均保证在至少两个旋转方向上产生封闭区域，且不同旋转的封闭区域面积可能不同。

**规则**：
1. 识别三个可见图案的旋转关系，确定缺失的第四个 90° 旋转变体。将橙(7) 占位象限替换为该变体（蓝(1) 像素在黑(0) 背景上），旋转中心为象限中心。
2. 对全部四个象限分别执行封闭区域检测：在每个象限内部，找出被蓝(1) 像素完全包围的 4-连通黑(0) 区域，该区域的任何像素均不与象限边缘或灰(5) 十字相邻。
3. 对每个检测到的封闭区域计算面积（黑像素数量）。按面积分档填色：面积 1~2 → 填红(2)；面积 3~4 → 填绿(3)；面积 >= 5 → 填黄(4)。
4. 灰(5) 十字保持不变。非封闭的黑(0) 背景保持不变。蓝(1) 图案像素保持不变。

**关键洞察**：占位象限可能隐藏了面积最大的封闭区域，而面积阈值的分档只有在观察全部四个象限后才能验证——必须先补全再检测，无法跳过补全直接对三个可见象限做填充。

## 新题 2：周期瓦片恢复后的标记定向射线涂色

**组合逻辑**：[补全/complete](已有：周期推断) → [射线延伸/ray_cast](创新：射线方向由标记到最近边的方位决定) → [重涂色/recolor](创新：射线覆写恢复后的周期色)

**来源原语**：补全(complete)·周期瓦片(periodic_tile)·缺损像素(erased_pixel)·周期重复(periodic_repeat)·前景残留推断周期(residue_infers_period) ← ea959feb；射线延伸(ray_cast)·列遮挡(column_coverage)·遮挡列延伸至边(covered_col_to_edge) ← 6d58a25d；重涂色(recolor)·方位对应(direction_correspondence)·方位决定颜色(direction_color) ← d364b489

**依赖链**：周期推断恢复完整瓦片图案 → 标记像素位于原本属于图案的位置上（伪装成擦除） → 标记到最近网格边的方位决定射线方向 → 射线沿该方向覆写恢复后的图案像素为标记色。没有周期恢复就无法区分"真正的背景"和"被擦除的图案格"，也就无法定位标记的角色。

从部分擦除的周期壁纸中恢复完整图案，然后从伪装为擦除的标记像素出发，向最近网格边射出射线，沿途覆写为标记色。

**输入结构**：约 14x14 的网格。使用蓝(1)、红(2)、绿(3) 三种颜色构成的周期重复图案覆盖全网格，最小重复瓦片至少 3x3。部分图案像素被擦除为黑(0) 背景。另有 2~3 个橙(7) 单像素标记，放置在原本属于图案的位置上（替代了该位置的图案色）。标记不相邻，且各标记到最近网格边的射线路径互不重叠。黑(0) 既是背景色也是擦除色，但在恢复后的周期图案中不会出现歧义（每个残余类要么有前景证据，要么始终为背景）。

**规则**：
1. 忽略橙(7) 标记像素，从剩余的非黑、非橙前景像素中推断最小行/列周期。利用周期恢复全网格的完整图案（包括被擦除为黑(0) 的位置和被标记替代的位置）。
2. 对每个橙(7) 标记，计算其到四条网格边（上、右、下、左）的曼哈顿距离。选择距离最小的边作为射线方向。若距离相等，按顺时针优先序选择：上 > 右 > 下 > 左。
3. 从标记位置出发（含标记自身），沿选定方向逐格画射线直到到达网格边界（含边界格）。射线上所有格（无论恢复后是什么颜色）都被覆写为橙(7)。
4. 不在任何射线上的格保留恢复后的周期图案颜色。

**关键洞察**：橙标记伪装成擦除——它们占据了图案位置但颜色与图案色不同。只有在恢复周期后才能确认标记所在位置"本应"有什么颜色，从而理解标记是外来控制信号而非图案本身。射线方向完全由标记的绝对位置决定，与图案内容无关。

## 新题 3：空心形体的调色板填充与向下射线级联

**组合逻辑**：[封闭区域检测/enclosure_detection + 填充/fill](创新：填充色由边框色经调色板查表决定) → [射线延伸/ray_cast](创新：射线起点是填充后的新像素，射线被其他形体的边框阻断)

**来源原语**：填充(fill)·空心精灵体(hollow_sprite)·封闭区域(enclosed_region)·调色板图例(palette_legend)·编码映射(encoding_map)·边框色映射填充色(border_to_fill_mapping) ← dbff022c；射线延伸(ray_cast)·列遮挡(column_coverage)·遮挡列延伸至边(covered_col_to_edge) ← 6d58a25d；含孔洞者选中(object_with_hole_selected) ← b9b7f026；忽略干扰项(ignore_distractors) ← ce039d91

**依赖链**：调色板将边框色映射为填充色 → 填充操作在空心形体内部创造新的有色像素 → 这些新像素成为射线的起点 → 射线向下延伸直到被另一个形体的边框阻断或到达边界。实心形体不被填充（忽略），但它们的边框像素阻断射线。填充和射线共享同一网格空间，操作有严格时序依赖。

通过调色板将空心形体的边框色映射为填充色，填充其内部后，从每个填充像素向下投射射线，射线被其他形体边框阻断。

**输入结构**：约 15x18 的网格，黑(0) 背景。顶部两行为 2xN 调色板图例（N=3），第一行依次为蓝(1)、红(2)、绿(3)，第二行依次为对应的填充色黄(4)、灰(5)、橙(7)。调色板下方分布 4~5 个单色 4-连通形体（每个 5~10 像素），颜色从 {蓝(1), 红(2), 绿(3)} 中选取。其中 2~3 个形体是空心的（内部封闭 1~4 个黑(0) 背景像素，该背景区域不接触网格边界），其余为实心。形体间互不接触、互不重叠，也不与调色板接触。至少有一个空心形体正下方存在另一个形体（充当射线阻断器）。同一组列范围内不会有两个空心形体。

**规则**：
1. 识别空心形体：形体内部存在被其边框像素完全包围的 4-连通黑(0) 区域，该区域的任何像素不接触网格边界。实心形体无此性质，跳过。
2. 对每个空心形体，在调色板第一行中查找其边框颜色，读取第二行对应位置的填充色。
3. 将每个空心形体的所有封闭背景区域填充为对应的填充色。
4. 对每个新填充的像素，从该像素位置向下（行号递增方向）逐格画射线。射线在遇到以下情况时终止（不含终止位置）：碰到任何非背景像素（属于另一个形体的边框），或到达网格底边（含底边格）。射线格被涂为该填充色。
5. 若射线未遇到任何阻断物，则一直画到网格底部最后一行（含）。
6. 将调色板图例区域擦除为黑(0) 背景。
7. 实心形体保持原样。空心形体的边框像素保持原样。

**关键洞察**：实心形体在选择阶段被忽略（不填充），但在射线阶段作为阻断器发挥关键作用——同一个"无关"对象在两个逻辑阶段扮演不同角色。填充色由调色板间接决定，而非由边框色直接决定，因此无法跳过调色板查表。

## 新题 4：邻接标记选择对象 + 对角线偏移壁纸

**组合逻辑**：[标记选中邻接体/marker_selects_neighbor](已有) → [裁剪/crop](已有) → [对角线偏移复制/diagonal_offset_copy + 画布加倍/canvas_doubling](创新：被选中的对象成为对角线瓦片的内容)

**来源原语**：裁剪(crop)·前景对象(foreground_object)·标记像素(marker_pixel)·邻接接触(adjacency_contact)·标记选中邻接体(marker_selects_neighbor) ← 48d8fb45；拼接(concatenate)·前景图案(foreground_motif)·对角线偏移复制(diagonal_offset_copy)·画布加倍(canvas_doubling) ← d13f3404

**依赖链**：标记像素通过邻接选择唯一目标对象 → 裁剪该对象为瓦片 → 瓦片在加倍画布上沿对角线偏移复制。被选中的对象形状直接决定对角线干涉图案——不同形状产生截然不同的输出。选择错误的对象则对角线条纹完全不同。

灰标记选中与其邻接的对象，裁剪后在双倍画布上沿右下对角线偏移铺展。

**输入结构**：约 10x12 的网格，黑(0) 背景。3 个蓝(1) 小型对象（各 3~6 像素，4-连通，形状互不相同——不同示例中对象的具体形状也不同，但均为不规则的 4-连通单色小图形）。1 个灰(5) 单像素标记，与其中恰好一个蓝对象有且仅有 1 个 4-邻接接触。其余蓝对象与灰标记无 4-邻接。对象间互不接触。

**规则**：
1. 找到灰(5) 标记像素，检测与其 4-邻接的蓝(1) 对象，该对象即为选中对象。
2. 将选中对象裁剪至其最小外接矩形（边界框），框内非对象像素保留为黑(0)。此矩形即为"瓦片"，设其高 H、宽 W。
3. 创建输出画布，高 2H、宽 2W，全部初始化为黑(0)。
4. 对瓦片中每个蓝(1) 像素（设其在瓦片内局部坐标为 (r, c)），在输出画布的所有位置 (r+k, c+k)（k = 0, 1, 2, ...）处涂蓝(1)，当且仅当 r+k < 2H 且 c+k < 2W。
5. 灰标记和未被选中的蓝对象不出现在输出中。

**关键洞察**：三个形状不同的对象中只有一个被选中；对角线偏移是对瓦片中每个像素独立进行的，因此瓦片内部的像素相对位置决定了对角线条纹是否交汇——这是选择与几何变换的耦合，而非简单串联。

## 新题 5：十字定义对称轴 + 四象限镜像 + 边邻接多数决涂色

**组合逻辑**：[擦除/erase + 镜像/mirror](创新：十字删除后镜像扩展) ⇄ [重涂色/recolor + 邻接多数决/adjacency_majority_rule](创新：镜像接缝处多色相遇时按边邻接数决定颜色)

**来源原语**：镜像(mirror)·擦除(erase)·十字图案(cross_pattern)·前景遮罩(foreground_mask)·象限(quadrant)·对称轴定义(symmetry_axis_def)·十字色作涂色源(cross_as_palette) ← 47c1f68c；重涂色(recolor)·连通分量(connected_component)·边邻接计数(edge_adjacency_count)·邻接多数决(adjacency_majority_rule) ← 477d2879

**依赖链**：十字定义对称轴并被删除 → 上左象限的多色图案被镜像到四个象限 → 在原十字位置形成接缝带 → 接缝带上的每个格被四个象限的镜像副本包围 → 该格的颜色由其 4-邻居中各色的边邻接数多数决定。镜像产生的边界恰好是多数决的判定场所——两个操作在空间上嵌套。

删除十字后将左上象限图案四向镜像扩展；原十字所在的接缝行/列上每格的颜色由相邻镜像副本的边邻接多数投票决定。

**输入结构**：约 11x11 的奇数尺寸正方形网格，黑(0) 背景。一条绿(3) 像素构成的完整水平中线和完整垂直中线在网格中心交叉形成十字。左上象限（不含十字行列）内有由红(2) 和蓝(1) 两种颜色构成的图案（共 4~8 个前景像素），图案的 4-连通分量可以不止一个。其余三个象限（不含十字行列）均为黑(0) 背景。不同示例中左上象限图案的形状和颜色分布不同，但始终使用红(2) 和蓝(1) 两种颜色，且图案至少有一个像素与十字行或十字列 4-邻接。

**规则**：
1. 记录十字颜色绿(3)，然后删除十字（整条水平中线和垂直中线全部设为黑(0)）。网格缩小为去掉中线行和中线列后的偶数尺寸方阵（每象限尺寸不变，四象限紧贴拼合）。
2. 将左上象限的图案同时水平镜像和垂直镜像，放入其余三个象限的对应位置，保留各像素原色（红或蓝）。
3. 在缩小后的网格中，找到原十字行和原十字列被删除后形成的"接缝"——即四个象限两两相邻的边界。接缝不是独立的行/列，而是象限边缘像素之间的 4-邻接关系。
4. 对接缝处的每个像素（即紧邻另一象限边缘的像素），统计其所有 4-邻居的颜色（仅统计非黑色邻居）。若红(2) 邻居数 > 蓝(1) 邻居数，该像素涂为红(2)；若蓝 > 红，涂为蓝(1)；若相等，涂为绿(3)（十字的原色作为平局色）。此规则仅修改接缝处已有颜色的像素，不修改黑(0) 背景像素。
5. 非接缝位置的像素保持镜像后的颜色不变。

**关键洞察**：十字不仅是空间分隔器和颜色提供者，它的删除在接缝处制造了多色碰撞——而碰撞的解决必须用到镜像产生的对称结构和源自另一道参考题的邻接多数决规则。平局时十字色回归，使擦除的十字信息以另一种形式保留在输出中。

**规则**：
1. 找到两个红(2) 端点，计算通过黑(0) 格的 4-邻接最短路径（蓝(1) 格为不可通行障碍）。将路径上的黑(0) 格（不含端点本身）涂为黄(4)。
2. 对网格中每个仍为黑(0) 的背景格，计算它到最近的路径格或端点格的切比雪夫距离 D。
3. 若 D 为偶数且 D > 0，将该格涂为绿(3)；若 D 为奇数，保持黑(0) 不变。
4. 蓝(1) 墙壁像素不参与计算也不被修改。红(2) 端点保持原色。黄(4) 路径像素保持原色。

**关键洞察**：迷宫墙壁承担双重角色——既为寻路定义可通行空间，又为切比雪夫环填充定义扩展边界。路径的弯折处，来自不同路径段的环形填充会产生干涉图样，这是路径几何与环形填充的涌现效应。

## 新题 10：镜像对称对检测 + 周期推断验证 + 条件擦除

**组合逻辑**：[镜像对称检测/mirror_symmetry_detection + 镜像配对则涂色/recolor_if_mirror_pair](已有) ⇄ [周期重复推断/periodic_repeat_inference](创新：仅对称配对像素参与周期推断) → [擦除/erase](创新：不符合推断出的周期的配对像素被擦除)

**来源原语**：重涂色(recolor)·前景掩膜(fg_mask)·镜像对称(mirror_symmetry)·镜像配对则涂色(recolor_if_mirror_pair)·忽略干扰项(ignore_distractors) ← ce039d91；补全(complete)·周期瓦片(periodic_tile)·周期重复(periodic_repeat)·前景残留推断周期(residue_infers_period) ← ea959feb；擦除(erase) ← a416fc5b

**依赖链**：先检测水平镜像对称配对 → 配对像素构成"过滤后的前景集" → 从这个子集推断行方向的最小周期 → 凡是周期模型无法解释的配对像素（即存在同一残余类内颜色冲突的对）被视为噪声并擦除。对称过滤为周期推断提供干净的输入，周期推断反过来验证哪些对称对是"真正有规律的"，两步互相约束。

先筛出水平镜像对称配对的前景像素，从中推断行方向的最小重复周期，再擦除不符合该周期的"伪配对"像素。

**输入结构**：约 12x16 的网格（列数为偶数），黑(0) 背景。前景使用红(2) 单一颜色。前景像素分为三类（求解者需自行区分）：
- 真正对称且符合周期的像素：以网格垂直中线为轴左右对称出现，且在行方向上呈周期重复。
- 伪对称像素：同样以中线为轴左右对称出现，但不符合真正像素的行方向周期（在其残余类位置上，真正的模式本应为背景）。约 2~3 对。
- 噪声像素：不对称（在中线另一侧没有配对），约 2~4 个。

**规则**：
1. 对每个红(2) 像素，检查其关于垂直中线的镜像位置是否也是红(2)。保留所有有镜像配对的像素，记为"候选集"。无配对的像素直接擦除为黑(0)（即噪声像素被移除）。
2. 从候选集中（仅看网格左半部分的候选像素），推断列方向的最小重复周期 P：找到最小的 P 使得对候选集中每个左半部分像素 (r, c)，其所有同残余类位置 (r, c + kP)（在左半部分范围内）要么都在候选集中，要么存在唯一一致的"有/无"模式。
3. 利用推断出的周期 P，检查候选集中每个左半部分像素是否与其残余类内其他位置一致。若某像素的残余类中多数位置为背景（该残余类在周期模型中应为背景），则该像素及其镜像配对为"伪配对"，将两者都擦除为黑(0)。
4. 输出网格中只保留通过两层筛选（对称 + 周期一致）的红(2) 像素，其余为黑(0)。

**关键洞察**：单独的镜像对称检测会保留伪对称像素；单独的周期推断会被噪声像素干扰。两个逻辑必须协作：对称检测先过滤噪声使周期推断可靠，周期推断再回头清除通过了对称检测但不符合周期的伪对称像素——这是一个双向过滤的推理结构，而非线性流水线。
