## 新题 1：面板差异驱动沟槽分区着色

**组合逻辑**：[逐像素比较](已有) + [分区涂色](已有) + [边界框内外分色](创新：由比较结果动态决定边界框范围，而非由原始输入直接决定)

**来源原语**：逐像素比较/pixel_comparison、面板/panel、分隔列/separator_col、面板对齐/panel_align、差异分类着色/diff_class_color（来自 d47aa2ff）；分区涂色/zone_coloring、块阵列/block_array、网格沟槽/lattice_gutter、边界框/bounding_box、内部与外部沟槽/interior_vs_exterior_gutter、按边界框内外分色/color_by_bounding_box_membership（来自 137f0df0）

**依赖链**：逐像素比较决定哪些块存活及其颜色 → 存活块的集合重新定义边界框 → 边界框划分沟槽的内外归属 → 沟槽像素据此着色。删除比较步骤则边界框无法确定；删除沟槽着色则比较结果无后续用途。

将两块阵列面板逐块比较后重新着色，再根据存活块的边界框范围对沟槽间隙进行内外分区涂色。

**输入结构**：约 12x21 的网格。背景黑(0)。中央有一列宽度为 1 的绿(3)分隔列，将网格分为左右两个等宽面板（各约 12x10）。每个面板内有一个由灰(5) 2x2 方块组成的规则矩阵（例如 4 行 3 列方块），方块之间有 1 像素宽的沟槽间隙，沟槽为背景色。两个面板的方块矩阵行列结构完全一致，但部分位置的方块缺失（被背景色替代）——且两面板缺失位置不完全相同。生成约束：至少有 2 个方块位置仅在一个面板中出现，至少有 1 个方块在两个面板中都存在，且比较后存活块的边界框严格小于完整矩阵的边界框（即有些外围位置在比较后消失了）。

**规则**：
1. 移除绿(3)分隔列，将左右面板按位置对齐，逐 2x2 方块比较：
   - 该位置两面板都有方块 → 保留灰(5)。
   - 该位置仅左面板有方块 → 重涂为红(2)。
   - 该位置仅右面板有方块 → 重涂为蓝(1)。
   - 该位置两面板都无方块 → 保持黑(0)。
2. 输出为单个面板大小的网格，包含上述重涂后的方块。
3. 计算所有存活方块（灰、红、蓝）的最小外接矩形（边界框）。
4. 对沟槽像素（方块行带之间的水平空行、方块列带之间的垂直空列）着色：位于边界框内部的沟槽像素涂黄(4)；位于边界框外部、但与内部沟槽同行或同列延伸出去的沟槽像素涂橙(7)。
5. 不属于任何沟槽行带或列带的背景像素保持黑(0)。

**关键洞察**：面板比较不仅改变方块颜色，更通过消除某些外围方块收缩了边界框；沟槽的内外归属随比较结果动态变化，而非由原始矩阵几何静态决定。

## 新题 2：连接杆编码平铺参数与碰撞旋转

**组合逻辑**：[连接杆/connector_stem](创新：从滑动路径改为编码平铺方向和间距) + [平铺/tiling](已有) + [旋转/rotate](创新：由碰撞触发而非交替触发) + [擦除/erase](已有)

**来源原语**：连接杆/connector_stem、矩形体/rectangular_body、擦除/erase、碰撞阻挡/collision_blocking、沿杆滑至锚定物/slide_stem_to_anchor（来自 98cf29f8）；平铺/tiling、旋转/rotate、矩形条/rect_bar、交替旋转换色/alt_rotate_recolor（来自 fd4b2b02）

**依赖链**：连接杆方向 → 平铺方向；连接杆长度 → 平铺间距。多个矩形体各自沿编码方向平铺 → 平铺链在网格中相遇时产生碰撞 → 碰撞触发入侵方的旋转。删除连接杆则平铺参数不可知；删除碰撞旋转则重叠区域无法解决。

每个矩形体的连接杆编码了平铺方向和间距；沿各自方向平铺副本，当不同体的平铺链碰撞时将入侵副本旋转 90 度后放置。

**输入结构**：约 18x18 的网格，背景黑(0)。包含 2-3 个彼此不相邻的前景矩形体，每个矩形体为单色非正方形实心矩形（宽 2-3 像素、高 3-5 像素或反之），颜色各不相同（例如红(2)、蓝(1)、绿(3)）。每个矩形体的一条边中央伸出一根同色的一像素宽连接杆，沿某个基本方向（上/下/左/右）延伸 1-4 像素。不同矩形体的连接杆方向和长度可以不同。生成约束：沿各自编码方向平铺时，至少有一对矩形体的平铺链在网格中存在重叠区域。

**规则**：
1. 对每个矩形体，读取其连接杆：杆从矩形体伸出的方向即为该矩形体的平铺方向；杆的长度（像素数）即为相邻副本之间的间距（两副本最近边之间的空像素数）。
2. 擦除所有连接杆（仅保留矩形体本身）。
3. 从每个矩形体的位置出发，沿平铺方向以编码间距反复放置该矩形体的同色副本，直至网格边缘。超出边缘的副本裁剪到网格内。
4. 碰撞处理（按矩形体在输入中从上到下、从左到右的顺序依次放置各体的平铺链）：若放置某个副本时发现目标区域已被另一颜色的副本占据，则将当前副本顺时针旋转 90 度再尝试放置；旋转后仍完全被占据则跳过该副本。部分重叠时，当前副本覆盖已有像素（后来者覆盖先来者）。

**关键洞察**：连接杆在源题 98cf29f8 中是矩形体的滑动路径，但在此题中被重新诠释为平铺指令的压缩编码（方向+间距）；碰撞触发旋转是多体平铺交互的涌现规则，在任何单一源题中均不存在。

## 新题 3：重力沉降确定条纹种子

**组合逻辑**：[重力下落/gravity_drop](已有) + [平铺/tiling](已有) + [填充/fill](已有) → 创新关系：重力沉底的像素成为条纹种子，且仅底层像素有效（堆叠的上层像素是干扰项）

**来源原语**：重力下落/gravity_drop、可移动像素/movable_pixel、碰撞停止/collision_stop（来自 88e364bc）；平铺/tiling、填充/fill、种子像素/seed_pixel、条纹/stripe、阵列排布/array_layout、种子定条纹周期/seed_sets_stripe_period（来自 0a938d79）；贯穿条/full_span_bar（来自 ecdecbb3）

**依赖链**：散落像素经重力下落后堆叠在横杆上 → 仅与横杆直接接触的底层像素充当种子 → 种子的列位置和颜色定义条纹图案 → 种子间的最小列间距定义条纹周期 → 以该周期将条纹图案向横杆下方平铺。删除重力则种子不确定；删除平铺则种子无用途；忽略"仅底层"规则则输出错误。

散落在横杆上方的彩色像素经重力下落后堆叠于横杆表面；仅接触横杆的底层像素成为条纹种子，向下方平铺出周期性竖条纹。

**输入结构**：约 15x18 的网格，背景黑(0)。一根灰(5)水平贯穿条横跨整个网格宽度，位于约第 7 行。贯穿条上方散布若干彩色像素，颜色为红(2)或蓝(1)，每列最多 1-3 个像素，位置不规则。部分列可能没有像素。贯穿条下方全部为背景色。生成约束：至少 3 个列在重力下落后有像素落在横杆上；至少 1 个列有 2 个以上同列像素（下落后形成堆叠）；有种子的列的最小间距 P 能整除网格宽度或接近整除。

**规则**：
1. 重力下落：贯穿条上方所有彩色像素向下移动，遇到贯穿条表面或已堆叠的像素时停止。
2. 识别种子：对每个列，仅取紧贴贯穿条上表面的那个像素（堆叠底部）作为该列的种子。堆叠中位于种子上方的像素保留在原位但不参与后续逻辑。
3. 计算条纹周期 P：取所有种子列中相邻两列的最小列间距。
4. 在贯穿条下方填充竖条纹：对每个种子列，以种子颜色填充该列从贯穿条下方第一行到网格底部的所有像素。
5. 以周期 P 向左右平铺整个种子列颜色序列，填满贯穿条下方所有列。若平铺目标列无对应种子（种子序列比 P 短），该列保持黑(0)。

**关键洞察**：堆叠的上层像素是干扰项——看似与底层同等重要，但只有直接接触横杆的底层像素才是种子。求解者必须理解重力结果的分层语义，而非将所有落下的像素一视同仁。

## 新题 4：轮廓路径方向决定对称补全轴

**组合逻辑**：[滑动/slide + 轮廓邻接/contour_adjacency](已有) + [对称补全/symmetry_completion](已有) → 创新关系：轮廓路径的净方向不用于定位标记终点，而用于编码对称轴选择

**来源原语**：滑动/slide、标记像素/marker_pixel、障碍轮廓/obstacle_contour、轮廓邻接/contour_adjacency、最长贴边路径/longest_adjacent_path（来自 97c75046）；对称补全/symmetry_completion、对称图案/symmetric_pattern、标记矩形/marker_rectangle、双轴反射对称/biaxial_reflection_symmetry、标记遮挡区域/marker_occludes_region（来自 0934a4d8）

**依赖链**：标记像素沿视线滑向障碍物 → 沿轮廓选最长贴边路径 → 计算起点到终点的净位移向量 → 净位移主方向（水平/垂直）决定对称补全使用的反射轴 → 用该轴的反射对称恢复被遮挡的像素。删除轮廓滑动则对称轴未知；删除对称补全则滑动无目的。

一个标记像素沿障碍物轮廓滑行后的净位移方向，决定用哪条反射轴来补全被遮挡区域的图案。

**输入结构**：约 17x17 的网格，背景黑(0)。网格大部分区域被一个具有双轴反射对称性的彩色图案（使用红(2)、蓝(1)、绿(3)等颜色）覆盖，但图案的某个区域被橙(7)单色矩形块遮挡（遮挡区域位于图案的一侧，使得仅用一条对称轴即可恢复）。图案外侧（靠近网格边缘）有一个灰(5)连通障碍物区域（4-连通，约 8-15 像素，形状不规则）。距障碍物若干像素处有一个绿(3)标记像素，与障碍物恰好有一条水平或垂直的视线（视线上无其他非背景像素阻挡）。生成约束：轮廓路径的净位移在水平和垂直分量上不相等（不出现 45 度歧义）；遮挡区域恰好需要与净位移主方向对应的反射轴来恢复。

**规则**：
1. 从绿(3)标记像素出发，沿其唯一的水平或垂直视线滑向灰(5)障碍物，停在障碍物前最后一个背景像素。
2. 从该停留点出发，尝试两个与视线方向成 45 度的对角转向，选择能沿障碍物外轮廓保持 4-邻接的最长路径方向，沿该方向走到路径尽头。
3. 计算标记像素的起点到路径终点的净位移向量 (dr, dc)。取主方向：若 |dc| > |dr| 则主方向为水平；若 |dr| > |dc| 则主方向为垂直。
4. 主方向为水平 → 使用垂直反射轴补全图案（将可见侧左右翻转到橙(7)遮挡处）。主方向为垂直 → 使用水平反射轴补全图案（将可见侧上下翻转到遮挡处）。
5. 输出中橙(7)像素被替换为反射对应位置的颜色，其余部分不变。标记像素和障碍物保持原位不动（滑动仅用于计算，不改变网格内容）。

**关键洞察**：轮廓路径的几何形态不是用来放置标记的终点位置（不同于源题 97c75046），而是一个方向信号——其净位移的主分量编码了应当使用哪条对称轴来恢复被遮挡的图案。必须对比多个示例才能确定"水平净位移 → 垂直轴"还是反过来。

## 新题 5：指示像素双重编码的印章平铺

**组合逻辑**：[印章覆盖/stamp](已有) + [平铺/tiling](已有) + [重涂色/recolor](已有) → 创新关系：指示像素同时编码平铺方向（位置语义）和重涂色映射（颜色语义），一个像素承载两重信息

**来源原语**：印章覆盖/stamp、精灵体/sprite、占位对象/placeholder、掩码匹配/mask_matching、源色覆盖占位副本/source_colors_onto_placeholders、擦除/erase（来自 321b1fc6）；重涂色/recolor、平铺/tiling、指示像素/indicator_pixel、邻接触碰/adjacency_touch、指示决定方向色/indicator_dir_color（来自 e8dc4411）

**依赖链**：掩码匹配将占位对象与精灵体关联 → 印章将精灵体颜色覆盖到占位对象 → 每个占位对象旁的指示像素提供平铺方向（位置编码）和主色替换（颜色编码）→ 以指示方向平铺，以指示颜色替换精灵体主色。删除印章则无内容可平铺；删除指示像素则方向和颜色映射都缺失。

将精灵体颜色印入各占位对象后，依据每个占位对象旁指示像素的位置和颜色，分别确定平铺方向与主色替换，向外平铺变色副本。

**输入结构**：约 20x20 的网格，背景黑(0)。包含一个多色精灵体（4-连通，约 6-10 像素，由 2-3 种前景色组成，其中一种颜色像素最多，称为"主色"）。另有 2-3 个灰(5)单色占位对象，每个与精灵体形状（掩码）完全一致但位置不同。每个占位对象恰好有一个单像素的指示像素与其 4-邻接触碰——指示像素颜色各不相同（例如红(2)、蓝(1)、黄(4)），且均不同于精灵体使用的颜色和灰(5)。生成约束：指示像素分别从不同方向接触占位对象（例如一个从上方、一个从右方、一个从下方），使得各占位对象的平铺方向不同；平铺路径互不重叠。

**规则**：
1. 识别精灵体（唯一的多色连通前景对象）和占位对象（与精灵体掩码一致的灰(5)对象），通过掩码匹配建立对应。
2. 对每个占位对象，将精灵体的颜色图案原样覆盖到该占位对象的位置（印章操作）。
3. 对每个印章后的对象，读取其指示像素：
   - **方向编码**：指示像素相对于占位对象边界框中心的方向（上/下/左/右）即为该对象的平铺方向。
   - **颜色编码**：精灵体中的主色（出现次数最多的颜色）在平铺副本中被替换为该指示像素的颜色；精灵体中的其余颜色不变。
4. 从每个印章对象的位置出发，沿指示方向以对象自身高度（垂直平铺时）或宽度（水平平铺时）为步长，反复放置重涂色后的副本直至网格边缘。超出部分裁剪。
5. 擦除原始精灵体和所有指示像素。印章对象本身保留（不重涂色，保持原始精灵体配色）。

**关键洞察**：指示像素在源题 e8dc4411 中仅编码方向或仅编码颜色，但在此题中同一个像素同时承载两重语义——位置关系给出方向，颜色值给出重涂规则。求解者必须从多个示例中分别归纳出这两层编码。

## 新题 6：外部标记对定义区域内条纹障碍

**组合逻辑**：[填充/fill + 对角配对/diagonal_pairing](创新：标记对的间距不用于定义矩形而用于定义条纹周期) + [重力下落/gravity_drop](已有) + [颜色关联区域/color_links_to_region](已有)

**来源原语**：填充/fill、标记像素/marker_pixel、对角配对/diagonal_pairing、同色对定义矩形/pair_defines_rect（来自 56ff96f3）；重力下落/gravity_drop、封闭区域/enclosed_region、可移动像素/movable_pixel、碰撞停止/collision_stop（来自 88e364bc）；颜色关联区域/color_links_to_region（来自 88e364bc）；条纹/stripe、种子定条纹周期/seed_sets_stripe_period（来自 0a938d79）

**依赖链**：外部同色标记对的列间距 → 经颜色匹配链接到对应封闭区域 → 在区域内以该间距绘制竖条纹 → 条纹成为重力障碍 → 区域内可移动像素下落时被条纹阻挡。删除标记对则条纹周期未知；删除条纹则重力无内部障碍（结果不同）；删除颜色关联则标记对与区域无法配对。

网格边缘的同色像素对通过颜色匹配链接到封闭区域，其列间距定义区域内的竖条纹周期；条纹充当重力障碍，使区域内的可移动像素下落时被拦截。

**输入结构**：约 17x17 的网格，背景灰(5)。网格中有 2-3 个封闭矩形区域，各由不同颜色的单像素宽墙壁围成（例如红(2)墙、蓝(1)墙、绿(3)墙），区域内部为背景色，其中散布若干黄(4)像素（每个区域 2-5 个，位置不规则）。网格边缘（最外 1-2 行/列）放置成对的标记像素：每种区域墙壁颜色在边缘恰好出现两个同色标记像素（例如两个红(2)像素、两个蓝(1)像素），位于网格外围且不与区域墙壁相邻。生成约束：每对同色标记像素位于不同列（列间距 2-5），且该列间距能使条纹在对应区域内至少绘制 2 条竖线；黄(4)像素的初始位置不在条纹将要绘制的列上。

**规则**：
1. 对每种区域墙壁颜色 C，在网格边缘找到该颜色的两个标记像素，计算它们的列间距 P。
2. 在墙壁颜色为 C 的封闭区域内部，从区域左墙右侧第一列开始，以周期 P 在每个对应列上绘制整列高的竖条纹，颜色为 C。条纹仅绘制在区域内部的背景像素上，不覆盖已有的黄(4)像素。
3. 在所有区域内，对黄(4)像素施加向下的重力：每个黄像素向下移动，遇到区域底墙、另一个已停止的黄像素、或竖条纹列时停止。（条纹列是不可穿越的障碍；黄像素不能进入条纹占据的列，但可以贴着条纹侧面下落。）
4. 区域外部的标记像素在输出中保留。所有墙壁保持不变。

**关键洞察**：外部同色标记对在源题 56ff96f3 中定义矩形填充区域，但在此题中它们的空间间距被重新诠释为条纹周期参数；条纹在源题中不存在而是组合涌现的中间结构，其唯一目的是充当重力下落的障碍物。

## 新题 7：面板比较生成射线源

**组合逻辑**：[逐像素比较/pixel_comparison](已有) + [射线延伸/ray_extend](已有) + [印章覆盖/stamp_overlay](已有) → 创新关系：比较结果不仅分类像素颜色，更在功能上区分"活性射线源"与"惰性保留点"

**来源原语**：逐像素比较/pixel_comparison、面板/panel、分隔列/separator_col、面板对齐/panel_align、差异分类着色/diff_class_color（来自 d47aa2ff）；射线延伸/ray_extend、贯穿条/full_span_bar、控制像素/control_pixel、接触标记/contact_marker、投射/perpendicular_cast、命中处印标记/stamp_at_hit（来自 ecdecbb3）

**依赖链**：面板逐像素比较 → 差异像素（仅在一个面板中出现的）变为控制像素，共有像素变为惰性标记 → 控制像素向贯穿条投射射线 → 射线命中贯穿条处印章 3x3 标记。删除比较则无法区分控制像素和惰性像素；删除射线/印章则比较结果无后续变换。

两面板的前景像素经比较后，仅一方独有的像素变为射线源向贯穿条投射，命中处印章标记；双方共有的像素保持惰性不发射。

**输入结构**：约 12x23 的网格，背景黑(0)。一列宽为 1 的绿(3)分隔列居中，将网格分为左右两个等宽面板（各约 12x11）。每个面板内包含 1-2 根灰(5)水平贯穿条（横跨面板全宽），以及 3-6 个散布的孤立前景像素（颜色为橙(7)，不在贯穿条上）。两面板的贯穿条位置（行号）完全一致，但前景像素的分布不同：部分像素在两面板的同一位置都出现，部分仅在一个面板中出现。生成约束：至少 2 个像素为一方独有（产生射线源），至少 1 个像素为双方共有（保持惰性）；独有像素所在列上有贯穿条可供射线命中。

**规则**：
1. 移除绿(3)分隔列，将两面板按位置对齐，逐像素比较（仅比较非灰、非黑像素的位置）：
   - 该位置两面板都有橙(7)像素 → 在合并输出中标记为黄(4)（惰性：不发射射线）。
   - 该位置仅左面板有像素 → 标记为红(2)（活性控制像素）。
   - 该位置仅右面板有像素 → 标记为蓝(1)（活性控制像素）。
2. 合并为单面板输出。灰(5)贯穿条保留。
3. 对每个活性控制像素（红或蓝），沿垂直方向（贯穿条为水平时）向上下两侧投射射线，射线以该控制像素的颜色（红或蓝）绘制，遇到贯穿条时停止（射线终点为贯穿条前最后一个像素）。
4. 在每个射线-贯穿条命中点处，以灰(5)印章一个 3x3 方块（居中于命中点所在的贯穿条像素），然后将 3x3 方块的中心像素恢复为控制像素的颜色（红或蓝）。3x3 方块超出网格的部分裁剪。
5. 黄(4)惰性像素保持原位，不产生任何射线或印章。
6. 若两条射线在同一贯穿条像素处重合（来自不同控制像素），后处理的射线的 3x3 印章覆盖先处理的。处理顺序：按控制像素位置从上到下、从左到右。

**关键洞察**：面板比较在功能上不只是分类着色（源题 d47aa2ff 的终点），而是变成了射线延伸（源题 ecdecbb3）的前置筛选器——它将像素分为"活性"和"惰性"两个功能类别，只有差异像素才获得射线发射能力。

## 新题 8：L 标记扩展与对称补全分治遮挡孔洞

**组合逻辑**：[像素放大/pixel_scale → 扩展至外角/expand_to_corner](已有) + [对称补全/symmetry_completion](已有) → 创新关系：两种操作分治同一遮挡区域的像素，L 扩展填充角落部分，对称补全恢复剩余部分，两者的分工由 L 朝向决定

**来源原语**：像素放大/pixel_scale、角落标记/corner_marker、朝向对应角/facing_corner、扩展至外角/expand_to_corner（来自 b745798f）；对称补全/symmetry_completion、对称图案/symmetric_pattern、双轴反射对称/biaxial_reflection_symmetry、标记遮挡区域/marker_occludes_region、标记矩形/marker_rectangle（来自 0934a4d8）

**依赖链**：辨认 L 标记朝向 → 扩展 L 标记填充遮挡孔洞的对应角落像素 → 剩余遮挡像素由图案的反射对称补全。两种操作共同分治同一像素集合。删除 L 扩展则角落像素无法确定（对称补全在角落处可能有歧义）；删除对称补全则非角落区域仍被遮挡。

遮挡孔洞中的每个 L 标记扩展后填充对应角落；孔洞中未被 L 覆盖的像素由图案的双轴反射对称恢复。

**输入结构**：约 17x17 的正方形网格，背景黑(0)。网格被一个具有双轴反射对称性（水平轴+垂直轴）的彩色图案覆盖（使用红(2)、蓝(1)、绿(3)、灰(5)等颜色）。图案中央有一个矩形区域（约 6x6 至 8x8）被橙(7)像素完全遮挡。在遮挡矩形内部，存在 1-2 个小型 L 形标记（每个由 3 个像素组成，占据 2x2 方块中的一个角落），每个 L 标记颜色不同（例如黄(4)、栗(9)），且各自朝向不同的角（例如一个朝左上、一个朝右下）。生成约束：L 标记不位于遮挡矩形的最外围像素上（确保扩展有空间）；遮挡区域的非角落像素可通过双轴反射从可见区域恢复（不存在需要两次反射都无法确定的像素）。

**规则**：
1. 在遮挡矩形内部识别所有 L 形标记（3 像素 4-连通 L 形，颜色非橙(7)非黑(0)）。
2. 对每个 L 标记，根据其开口朝向确定对应的遮挡矩形角落（L 的凹面朝向即指向的角落）。将 L 标记扩展：沿两个臂方向延伸至遮挡矩形的边界，形成一个大型角 L（类似 b745798f，但扩展范围以遮挡矩形为边界而非整个网格），颜色与原 L 标记相同。
3. 遮挡矩形中已被扩展 L 覆盖的像素使用 L 的颜色。
4. 遮挡矩形中剩余的橙(7)像素（未被任何 L 覆盖的），通过图案的双轴反射对称恢复：优先使用同行水平反射位置的值，若该位置也被遮挡则使用同列垂直反射位置的值。
5. 输出整个网格：遮挡矩形区域现在由 L 扩展色和对称恢复色共同填充，其余区域不变。

**关键洞察**：遮挡孔洞不是由单一操作恢复的——L 扩展和对称补全各自负责一部分像素，而 L 的朝向决定了两种操作的管辖边界。这种"分治"关系在任何单一源题中都不存在。

## 新题 9：多象限轮廓滑行距离竞选裁剪目标

**组合逻辑**：[滑动/slide + 轮廓邻接/contour_adjacency](已有) + [裁剪/crop](已有) + [重涂色/recolor](已有) → 创新关系：轮廓滑行距离不用于确定终点位置，而用于四象限间的竞选比较——最长路径的象限被选为裁剪目标

四象限各含一个障碍物和一个标记像素；标记沿各自障碍物轮廓滑行后，路径最长的象限被选为裁剪输出目标。

**输入结构**：约 17x17 的网格，背景黑(0)。一行灰(5)水平分隔行和一列灰(5)垂直分隔列将网格分为四个象限。每个象限内包含：一个单色连通障碍物区域（约 5-10 像素，4-连通，形状不规则），颜色在四象限中各不相同（例如红(2)、蓝(1)、绿(3)、黄(4)）；一个品红(6)标记像素，不与障碍物相邻，但与障碍物有且仅有一条水平或垂直视线。生成约束：四个象限的轮廓路径长度互不相同（无平局）；障碍物形状各异以产生不同的轮廓长度。

**规则**：
1. 在每个象限中，从品红(6)标记像素出发，沿其与障碍物之间的唯一视线方向滑动至障碍物前最后一个背景像素。
2. 从停留点出发，尝试两个对角转向，选择沿障碍物外轮廓保持 4-邻接的最长路径，走到路径尽头。记录每个象限的路径总长度（从标记起点到路径终点的步数）。
3. 选择路径最长的象限作为输出目标。
4. 在选中象限中，将品红(6)标记像素从其原始位置移除（恢复为背景色），并在路径终点位置放置一个像素，颜色改为该象限障碍物的颜色（重涂色）。
5. 裁剪选中象限的内容（不含分隔行列）作为输出。

**关键洞察**：轮廓路径的长度在源题 97c75046 中仅决定标记终点，但在此题中它同时充当象限间的竞选得票——求解者必须在四个象限中各自执行完整的轮廓滑行，然后比较结果才能确定输出哪一个象限。

## 新题 10：锯齿平铺与封闭区域的干涉填充

**组合逻辑**：[平铺/tiling + 旋转/rotate + 对角锯齿排布/diag_zigzag](已有) + [间隙填充/gap_fill](已有) + [封闭区域/enclosed_region](已有) → 创新关系：锯齿平铺图案与封闭区域相互干涉——区域墙壁裁剪平铺链，而平铺链穿透区域内部后阻止间隙填充

**来源原语**：平铺/tiling、旋转/rotate、矩形条/rect_bar、对角锯齿排布/diag_zigzag、交替旋转换色/alt_rotate_recolor（来自 fd4b2b02）；间隙填充/gap_fill、网格沟槽/lattice_gutter、内部与外部沟槽/interior_vs_exterior_gutter（来自 137f0df0）；封闭区域/enclosed_region、碰撞停止/collision_stop（来自 88e364bc）

**依赖链**：矩形条经锯齿平铺产生覆盖全网格的图案 → 平铺遇封闭区域墙壁时被裁剪（不绘制在墙壁上）→ 但平铺穿透区域内部（在墙壁内的背景像素上正常绘制）→ 对区域内部执行间隙填充时，已被平铺占据的像素保留平铺色，仅未被平铺覆盖的背景像素被填充。删除平铺则区域内部全部被统一填充（无干涉图案）；删除间隙填充则区域内部有平铺和背景的混合（不完整）；删除封闭区域则无需填充。

一个矩形条的锯齿平铺图案覆盖全网格后穿入封闭区域内部；区域内未被平铺覆盖的空隙再以另一颜色填充，形成平铺与填充的干涉纹样。

**输入结构**：约 18x18 的网格，背景黑(0)。包含一个红(2)非正方形实心矩形条（例如 2x5 像素），位于网格某处。另有 2-3 个蓝(1)墙壁围成的封闭矩形区域（内部为黑(0)背景），分布在网格各处，大小约 6x6 至 8x8。矩形条不与任何区域墙壁接触。生成约束：矩形条的锯齿平铺在展开后至少穿过每个封闭区域的部分内部（平铺链的对角延伸范围覆盖到各区域）。

**规则**：
1. 以输入中的红(2)矩形条为种子，生成锯齿平铺图案：沿两条 45 度对角线方向放置矩形条的副本，副本间行列偏移量为矩形条的（高+宽）；相邻对角副本之间插入 90 度旋转后的矩形条副本，旋转副本颜色改为绿(3)。图案覆盖整个网格，超出边缘的副本裁剪。
2. 平铺遇到蓝(1)封闭区域墙壁像素时，不覆盖墙壁——墙壁像素始终保持蓝(1)。但平铺副本可以穿过墙壁进入区域内部（仅跳过墙壁上的像素，内部背景像素正常绘制平铺色）。
3. 对每个封闭区域的内部执行间隙填充：将内部仍为背景色黑(0)的像素填充为黄(4)。已被平铺覆盖的像素（红(2)或绿(3)）保持不变。
4. 封闭区域外部的背景像素不做间隙填充，保持黑(0)或平铺色。

**关键洞察**：锯齿平铺和封闭区域是两个独立的几何系统，但它们在网格上的叠加产生了干涉效应——区域内部的最终图案既不是纯平铺也不是纯填充，而是两者的交集/补集关系。这种干涉纹样无法仅凭其中一个系统推断。
