## 新题 1：连通分量计数驱动的周期印章阵列

**组合逻辑**：[连通检测](已有) + [计数](已有) → [周期掩码](创新：计数结果作为周期参数) → [印章覆盖](已有) + [分隔行](已有)

**来源原语**：连通检测(3194b014)、计数/计数决定尺寸(902510d5)、周期掩码(6a980be1)、印章覆盖/模板区(b4a43f3b)、分隔行(b4a43f3b/ce4f8723)

**依赖链**：分隔行将网格分为模板区和控制区。控制区中各颜色的连通分量数量被计数，计数值成为该颜色在输出中的水平重复周期。模板区提供印章内容，印章的放置位置由周期值和颜色的行分配共同决定。删除连通检测则无法得到周期；删除印章则无输出内容；删除分隔行则无法区分模板和控制区。

将模板图案按各颜色连通分量数量所确定的不同周期印入对应输出行。

**输入结构**：约 18x18 的网格，黑(0)为背景。一行完整的灰(5)分隔行将网格分为上下两区。上区为一个紧凑的模板图案（约 3x3 至 4x4 的多色小图形，颜色使用蓝(1)和红(2)构成，4-连通，无孔洞）。下区包含 2~4 种前景颜色（如绿(3)、黄(4)、橙(7)），每种颜色由若干分散的单色 4-连通小块组成（每块 1~4 像素），各颜色的连通分量数量互不相同（范围 2~5）。不同颜色的小块互不接触。生成约束：各颜色的分量数量互不相同，以保证周期唯一。

**规则**：
1. 识别灰(5)分隔行，提取上方模板区（紧裁剪为最小边界框）和下方控制区。
2. 对控制区中每种非背景颜色，计算其 4-连通单色连通分量的数量 K。
3. 构建输出网格：宽度 = 模板宽度 x 下区中分量数量最大值，高度 = 颜色种数 x 模板高度。按各颜色的分量数量从小到大排列行组（分量数最少的颜色占最上方行组）。
4. 对每种颜色，在其行组内每隔 K 个模板宽度的位置印入一份模板副本（从该行组的最左列开始，以模板宽度为步长，在第 0, K, 2K, ... 个位置处印章），印章中所有非背景像素重涂为该颜色。超出输出网格右边界的部分舍弃。
5. 行组之间不留间隔，未被印章覆盖的输出单元格为黑(0)背景。

**关键洞察**：每种控制颜色的碎片化程度（连通分量数量）不是干扰信息而是编码信号——它直接决定了该颜色在输出中的印章重复节奏，分量越少则印章越密集。

## 新题 2：连接点双重角色——对接方向即射线方向

**组合逻辑**：[对接拼合](已有) + [连接点颜色匹配](已有) → [射线延伸](创新：射线方向由对接轴的垂直方向决定) + [擦除](已有)

**来源原语**：对接拼合/连接点(20270e3b)、射线延伸(6a980be1)、擦除(6a980be1/fbf15a0b)、精灵体(c62e2108/20270e3b)

**依赖链**：连接点的颜色匹配确定精灵体配对关系；连接点在各自精灵体上的边缘位置确定对接方向；对接改变精灵体的空间位置；对接完成后，从每个原始连接点位置出发，沿对接轴的垂直方向向外发射射线。连接点同时承担三个结构角色（配对、定位对接面、确定射线方向），删除任一角色都无法完成变换。

将配对精灵体沿连接点对接后，从对接缝向两侧垂直发射彩色射线。

**输入结构**：约 20x20 的网格，黑(0)为背景。网格中有 2 对共 4 个精灵体，每个精灵体是一个 4-连通的单色小图形（3~8 像素），颜色为蓝(1)或绿(3)（同对精灵体同色）。每个精灵体的边缘恰有 1 个连接点像素（与精灵体颜色不同的单像素），连接点位于精灵体边界框的某条边的中点旁。同对精灵体的连接点颜色相同（如红(2)或黄(4)），不同对的连接点颜色不同。各精灵体之间互不相邻，保证足够间距（至少 3 格）供对接和射线使用。生成约束：同对精灵体的连接点分别位于相对的边（如一个在右边缘、另一个在左边缘），保证对接方向唯一。

**规则**：
1. 根据连接点颜色将精灵体配对（共享同色连接点的两个精灵体为一对）。
2. 对每对精灵体，确定对接方向：连接点在精灵体边界框上的位置指示该精灵体的对接面（如连接点在精灵体右边缘则该面朝右）。将两个精灵体平移，使两个连接点在对接方向上相邻（间距 1 像素）。
3. 对接完成后，从每个连接点的原始位置出发，沿与对接轴垂直的两个方向各发射一条射线，颜色为该连接点的颜色，直到到达网格边界。射线不覆盖已有非背景像素（遇到非背景像素时停止，不包含终点像素）。
4. 将对接后精灵体上的连接点像素重涂为其所属精灵体的颜色（擦除连接点标记）。
5. 两对精灵体独立处理。若两对的射线在同一像素交叉，后处理的对（连接点颜色编号较大的对后处理）覆盖先处理的对。

**关键洞察**：连接点不仅是对接的定位锚点，还隐式编码了射线发射方向——对接轴确定后，垂直方向就唯一确定，使得同一个像素同时约束了对接几何和射线几何。

## 新题 3：双面板框架联合与面积仲裁

**组合逻辑**：[透明叠加](已有) + [并集合并](已有) + [面积比较](创新：作为重叠区域的冲突仲裁规则) + [空心矩形/封闭区域](已有) + [分隔行](已有)

**来源原语**：透明叠加/并集合并/逐格对齐(ce4f8723)、面积比较/封闭区域/最大内部面积胜出(445eab21)、空心矩形(890034e9)、分隔行(b4a43f3b/ce4f8723)

**依赖链**：分隔行划分两个面板，每个面板包含空心矩形框架。逐格对齐使两面板的框架可以重叠。非重叠区域直接保留（并集合并），但重叠区域需通过比较各像素所属框架的封闭内部面积来仲裁归属（面积比较）。并集逻辑和面积仲裁逻辑同时作用于同一输出网格的不同区域，缺少任一条都无法确定完整输出。

将分隔行两侧的框架面板逐格叠合：无冲突处取并集，冲突处由框架的内部面积大小裁决。

**输入结构**：约 15x(2H+1) 的网格（H 约 7~9），黑(0)为背景。一行灰(5)横贯的分隔行将网格分为等高的上下面板（各 H 行、同宽）。上面板包含 2~3 个不重叠的单色空心矩形框架，均使用蓝(1)绘制，每个框架一像素粗，内部为黑(0)背景，尺寸各不相同（至少 3x3）。下面板同样包含 2~3 个不重叠的单色空心矩形框架，均使用红(2)绘制，格式与上面板相同。当上下面板逐格对齐后，部分框架像素重叠，部分不重叠。生成约束：每个框架的内部面积（边框内部的背景像素数）互不相同，保证仲裁无歧义。

**规则**：
1. 移除灰(5)分隔行，将上下面板按相同行列坐标逐格对齐。
2. 对每个输出单元格：
   - 若仅一个面板在该位置有框架像素（另一面板为背景），将该像素涂为绿(3)。
   - 若两个面板在该位置都有框架像素（重叠），确定上面板该像素属于哪个蓝(1)框架、下面板该像素属于哪个红(2)框架，比较两个框架各自的封闭内部面积（框架边界严格围住的背景像素数量）。保留内部面积较大的框架的像素，涂为绿(3)；较小的框架在该位置被丢弃。
   - 若两个面板在该位置都是背景，输出为黑(0)背景。
3. 输出网格大小等于单个面板大小（H 行 x 原宽）。

**关键洞察**：并集合并是默认逻辑，但在框架重叠像素处退化为面积竞争——解题者必须意识到同一张输出图上存在两套不同的归属判定规则，且分界线由重叠与否动态决定。

## 新题 4：轮廓围界内的精灵体周期平铺

**组合逻辑**：[轮廓描边/外侧相邻](创新：轮廓不用于描边而用于界定平铺区域) + [平铺](已有) + [精灵体](已有) + [擦除](已有) + [标记色/最小色为画笔](创新：标记色成为轮廓外环颜色)

**来源原语**：轮廓描边/轮廓线/外侧相邻(aa62e3f4)、平铺(c62e2108)、精灵体(c62e2108/20270e3b)、擦除(6a980be1)、标记色/最小色为画笔(aa62e3f4)

**依赖链**：轮廓线定义了一个封闭的平铺区域边界；精灵体提供平铺内容和周期；标记色为轮廓外环着色。轮廓线在源题中用于被描边的对象，这里变为划定平铺范围的容器。三个元素各自不可缺少：没有轮廓线就没有平铺边界，没有精灵体就没有平铺内容，没有标记色就没有外环颜色。

在闭合轮廓的内部周期平铺精灵体图案，并用标记色描绘轮廓的外侧相邻环。

**输入结构**：约 18x18 的网格，黑(0)为背景。网格中有一个由红(2)像素构成的闭合轮廓线（单像素粗的 8-连通封闭环，围住一个约 8x8~12x12 的不规则区域，内部为黑(0)背景）。轮廓内部某处有一个蓝(1)的小精灵体（4-连通，3~6 像素，非矩形，位于轮廓内部且不接触轮廓线）。轮廓外部有 1~2 个橙(7)的标记像素（单像素，不接触轮廓线）。网格中除上述元素外均为黑(0)背景。生成约束：轮廓线完全闭合（8-连通），内部区域为 4-连通的单一区域。

**规则**：
1. 提取蓝(1)精灵体的最小边界框作为平铺单元（边界框内背景像素保持为背景，视为透明）。
2. 确定轮廓线围住的内部区域（4-连通的黑(0)区域被红(2)轮廓线完全包围的部分）。
3. 以精灵体原始位置的左上角为起始锚点，将精灵体的边界框作为周期单元，沿水平和垂直方向在内部区域中周期平铺。仅绘制落在内部区域内的像素，超出内部区域或落在轮廓线上的像素不绘制。平铺使用蓝(1)颜色。
4. 计算轮廓线的外侧相邻环：所有 4-邻接于红(2)轮廓线像素、且不在轮廓内部区域中、且当前为背景的像素。将外侧相邻环涂为橙(7)。
5. 擦除原始轮廓线（红(2)像素全部变为黑(0)背景）。擦除轮廓外的橙(7)标记像素（变为黑(0)背景）。精灵体原始位置已被平铺覆盖，无需额外处理。

**关键洞察**：轮廓线在本题中不是被描边的对象而是平铺的围栏——它界定了精灵体可以铺满的区域形状，而自身在输出中消失，只留下外侧相邻环作为边界的痕迹。

## 新题 5：角落三角区的模板周期填充

**组合逻辑**：[计数/计数决定尺寸](已有) + [角落控制点/三角区域](已有) + [平铺](创新：平铺被三角区域的斜边裁剪) + [模板区](已有) + [擦除](已有)

**来源原语**：计数/计数决定尺寸(902510d5)、角落控制点/三角区域(902510d5)、平铺(c62e2108/6a980be1)、模板区(b4a43f3b)、擦除(6a980be1)

**依赖链**：角落控制点确定三角区域的位置和朝向；散点计数确定三角区域的边长；模板提供平铺内容；三角区域的斜边裁剪平铺范围。四个子系统（角落定位、计数定尺寸、模板内容、三角裁剪）共同决定输出，缺一不可。原题 902510d5 中三角区域是纯色填充，这里三角区域内的内容变为周期平铺的模板图案。

统计散点数量确定三角边长，在指定角落的三角区域内周期铺设模板图案。

**输入结构**：约 16x16 的网格，黑(0)为背景。网格的某一个角落（四角之一）有一个红(2)角标记像素（恰好在角落单元格）。网格中另有一个绿(3)的紧凑模板图案（4-连通，4~9 像素，约 2x2 至 3x3 边界框，可包含背景空隙，不接触网格边界）。网格中散布着若干黄(4)单像素控制点（3~6 个，各自独立、互不相邻、不接触模板和角标记）。生成约束：黄(4)控制点数量 N 满足 N x 模板边界框尺寸 <= 网格边长，保证三角区域不超出网格。

**规则**：
1. 识别红(2)角标记像素，确定三角区域所在的角落。
2. 统计黄(4)控制点的数量 N。
3. 以角标记所在角落为直角顶点，沿该角落的两条网格边各延伸 N x max(模板边界框高度, 模板边界框宽度) 个像素，定义一个等腰直角三角区域。三角区域包含所有满足"到两条边的像素距离之和 < N x max(模板高, 模板宽)"的单元格（即从角落向外的阶梯状三角区域）。
4. 在整个网格范围内，以模板的边界框为周期单元、以角标记位置为锚点进行周期平铺（模板边界框按行列无缝重复）。仅保留落在三角区域内的平铺像素，区域外的一律为黑(0)背景。平铺使用绿(3)颜色。
5. 擦除红(2)角标记和所有黄(4)控制点（变为黑(0)背景）。若原始模板位置在三角区域内则被平铺覆盖，若在区域外则被擦除。

**关键洞察**：控制点的计数不是直接给出三角边长的像素数，而是以模板尺寸为单位的倍数——这把计数、模板尺寸和三角几何三者耦合在一起，仅知其中两个不足以确定输出。

## 新题 6：切比雪夫路径被周期条纹分段变色

**组合逻辑**：[连线/切比雪夫最短路径](已有) + [周期条纹](已有) → [重涂色](创新：路径颜色按跨越条纹的次数交替) + [计数](已有) + [摘要生成](已有)

**来源原语**：连线/切比雪夫最短路径/起终点之间(992798f6)、周期条纹(6a980be1)、重涂色(50cb2852)、计数/分类计数(5289ad53)、摘要生成(5289ad53)

**依赖链**：路径的几何形状由起终点决定；条纹的位置独立于路径而存在；但路径穿越条纹的位置将路径分段，每段的颜色由其段序号的奇偶决定。穿越次数被计数后生成摘要。路径和条纹是两个独立结构，它们的交互关系（穿越事件）是涌现的——单独看路径或条纹都无法预测分段模式。

沿切比雪夫最短路径连线，每穿越一条周期条纹就交替路径颜色，并在角落生成穿越计数的摘要。

**输入结构**：约 15x15 的网格，黑(0)为背景。网格包含水平周期条纹：每隔固定间距（3~4 行间隔），有一整行灰(5)像素横贯网格。网格中有一个蓝(1)起点标记像素和一个红(2)终点标记像素，均不在灰(5)条纹行上，两者在行和列上都有距离。生成约束：蓝(1)和红(2)的位置保证切比雪夫路径至少穿越 2 条灰(5)条纹行；路径不经过网格边界外。

**规则**：
1. 计算从蓝(1)到红(2)的切比雪夫最短路径（国王走法：每步在 8 方向中选一，先走对角步消除行列差的较小值，再沿剩余轴走直线步）。路径包含起点和终点之间的所有中间像素，不包含起点和终点本身。
2. 沿路径从蓝(1)端到红(2)端逐步绘制。初始颜色为绿(3)。每当路径的下一步从非条纹行进入灰(5)条纹行，视为一次"穿越"：从该穿越点开始，路径颜色切换（绿(3)→橙(7)→绿(3)→...交替）。穿越点本身使用切换后的新颜色绘制。路径像素覆盖灰(5)条纹像素（即条纹行上的路径像素为路径颜色，非路径像素的条纹保持灰(5)不变）。
3. 统计路径的总穿越次数 C。
4. 在网格右下角，从角落像素开始，沿底边向左绘制一个 1xC 的黄(4)横条（C 个像素），作为穿越计数摘要。若 C=0 则不绘制。
5. 保留蓝(1)和红(2)标记像素不变。

**关键洞察**：路径本身不编码颜色信息，条纹本身也不编码颜色信息——路径的分段变色完全由两者的空间交叉决定，这是一个几何涌现效应。

## 新题 7：象限折叠由形状匹配确定层叠配对

**组合逻辑**：[形状匹配/旋转/翻转](已有) + [象限掩码/四象限折叠同画布](已有) → [透明叠加/层叠顺序](创新：层叠顺序由形状相似性分组决定) + [重涂色](创新：同组重叠区域执行混色规则)

**来源原语**：形状匹配/旋转/翻转/八方向匹配(898e7135)、象限掩码/四象限折叠同画布(75b8110e)、透明叠加/层叠顺序(75b8110e)、重涂色(890034e9/50cb2852)

**依赖链**：四个象限各含一个前景图形。形状匹配（含旋转/翻转）将四个图形分为两对。配对关系决定叠加时的冲突解决规则：同对图形重叠处重涂为第三色，异对图形重叠处保留后绘制者的颜色。此处形状匹配不是为了拼入框架（如源题 898e7135），而是建立分组关系来指导叠加行为——形状相似性被重新定义为一种"社会关系"而非几何填充。

折叠四象限到同画布，形状匹配确定配对，同对重叠区域特殊着色。

**输入结构**：约 (2W)x(2W) 的偶数尺寸网格（W 约 6~8），黑(0)为背景。网格被均分为四个 WxW 象限（左上、右上、左下、右下）。每个象限包含一个 4-连通单色前景图形（4~10 像素，不规则形状），四个象限的图形颜色互不相同，分别使用蓝(1)、红(2)、绿(3)、黄(4)。四个图形中恰好有两对在旋转/翻转下形状匹配（例如蓝(1)和绿(3)形状匹配，红(2)和黄(4)形状匹配）。生成约束：各图形不接触象限边界，以保证折叠后不会超出 WxW 输出画布；匹配判断在 8 种方向（4 旋转 x 2 翻转）下进行，恰好只有一种配对方案使两对都匹配。

**规则**：
1. 通过形状匹配（比较 8 种旋转/翻转下的形状）将四个象限图形分为两对。
2. 将四个象限掩码折叠到一个 WxW 输出画布上（各象限图形保持其在象限内的相对位置）。
3. 绘制顺序：左上 → 右下 → 左下 → 右上（与源题 75b8110e 相同的固定层序）。后绘制的覆盖先绘制的。
4. 冲突解决（覆盖时的颜色规则）：
   - 若后绘制的图形与先绘制的图形属于同一匹配对：重叠像素涂为灰(5)（标记同对交汇）。
   - 若后绘制的图形与先绘制的图形属于不同匹配对：重叠像素保留后绘制者的颜色（正常覆盖）。
5. 非重叠前景像素保留其原始颜色。背景保持黑(0)。

**关键洞察**：叠加的层序是固定的（与源题相同），但重叠处的颜色行为取决于形状匹配的分组——解题者必须先完成形状匹配来确定哪些是"同组"，然后才能正确解析每个重叠像素的颜色。

## 新题 8：标记选区裁剪后的最大框架内部重涂

**组合逻辑**：[标记对齐指定半区/保留标记半区](已有) + [连通检测/筛选](已有) + [空心矩形/封闭区域](已有) + [最大内部面积胜出](已有) + [重涂色/保留边框涂内部](创新：重涂色仅作用于仲裁胜出的框架)

**来源原语**：标记对齐指定半区/保留标记半区(fbf15a0b)、连通检测/筛选(3194b014)、空心矩形/封闭区域/最大内部面积胜出(445eab21)、重涂色/保留边框涂内部/内外分离(50cb2852)、裁剪(be94b721)

**依赖链**：标记像素选择保留哪一半网格（空间约简）；裁剪后的半区中包含多个空心矩形框架；框架的封闭内部面积被比较以选出最大者；仅最大框架的内部被重涂为特定颜色，其他框架保持原样。标记选区决定了哪些框架参与比较（不同半区可能有不同框架），面积比较在选定半区内进行，重涂仅影响比较的胜出者。三个阶段的逻辑依次缩小作用范围：全网格→半区→单个框架内部。

标记像素选出半区，半区中按封闭面积找到最大框架，仅将该框架内部重涂。

**输入结构**：约 12x20（宽大于高）的网格，黑(0)为背景。网格可被视为左右两半（各约 12x10）。其中一半包含 2 个橙(7)标记像素（同行或同列对齐，表示选择该半区）。两半各包含 2~3 个不同颜色的单色空心矩形框架（每个框架一像素粗，内部为黑(0)背景，颜色从蓝(1)、红(2)、绿(3)、黄(4)、品红(6)中选取，不同框架颜色不同）。框架之间互不重叠且不接触。生成约束：标记所在半区的各框架封闭内部面积互不相同，保证最大者唯一；两个标记像素不与任何框架接触。

**规则**：
1. 找到两个橙(7)标记像素，确定它们的对齐方向：
   - 若两标记同行，按它们所在的列位置判断属于左半还是右半（均在左半列范围内则选左半，均在右半列范围内则选右半）。保留该半区，裁剪掉另一半。
   - 若两标记同列，按它们所在的行位置判断属于上半还是下半。保留该半区，裁剪掉另一半。
2. 在保留的半区中，将橙(7)标记像素重涂为黑(0)背景（擦除标记）。
3. 识别半区中所有空心矩形框架（单像素粗、4-连通、单色的闭合矩形环）。
4. 对每个框架，计算其封闭内部面积（严格位于矩形环内部的背景像素数量）。
5. 选出封闭内部面积最大的框架。将该框架的内部像素（边框内缩一圈的矩形区域）全部涂为青(8)。该框架的边框像素保留原色不变。
6. 其他框架保持原样，不做任何修改。

**关键洞察**：变换的作用范围经过三级逐步聚焦——标记像素选半区（空间筛选）、面积比较选框架（属性筛选）、内外分离选像素（几何筛选）——每一级的输出都是下一级的输入域，而非独立的变换步骤。
