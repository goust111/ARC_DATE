## 新题 1：重力沉降后的走廊涌现

**组合逻辑**：[重力沉降/gravity_settling](已有) → [对边连通检测/opposite_edge_connect](已有) → [无阻挡跨行涂色/recolor](已有)（创新：走廊存在性由沉降结果动态决定，而非输入固有属性）

**来源原语**：滑动/sliding、列内独立/column_independent、重力沉降/gravity_settling（P2: 1e0a9b12）；射线延伸/ray_extend、对边连通/opposite_edge_connect、无阻挡跨行列涂色/unobstructed_span_recolored、走廊/corridor、边界像素/border_pixel（P13: 2bee17df）；重涂色/recolor（P13）

**依赖链**：重力沉降改变内部前景像素的垂直位置，使某些行从"有阻挡"变为"无阻挡"（像素下落腾出空间）或反之（像素堆积到该行）。走廊检测的结果完全取决于沉降后的布局——删除重力步骤后走廊判定将产生不同结果。

将内部前景像素按列内重力下沉后，检测并涂色所有沉降后无阻挡的水平走廊。

**输入结构**：约 12x12 的黑(0)背景网格。最左列（列 0）和最右列（列 W-1）的部分格为红(2)（边界标记），其余边界格为黑(0)；若干行的左右边界格同时为红(2)。网格内部（列 1 到列 W-2）散布约 5-8 个蓝(1)单像素前景点，分布在不同行列。生成约束：每列最多 2 个内部蓝像素；至少 2 行的左右边界同时为红(2)且在沉降前被蓝像素阻挡、沉降后变通透；至少 1 行在沉降后仍被蓝像素阻挡。

**规则**：
1. 对内部每一列（列 1 到列 W-2），读取该列中所有蓝(1)像素从上到下的顺序，将该列清空为黑(0)，再将这些蓝像素从该列最底行（行 H-1）开始向上依次放置，保持原始从上到下的相对顺序。
2. 沉降完成后，逐行检查（行 0 到行 H-1）：若该行第 0 列和第 W-1 列均为红(2)，且该行第 1 列到第 W-2 列的所有格均为黑(0)，则将该行第 1 到第 W-2 列的所有格涂为绿(3)。
3. 不满足条件的行保持不变。所有红(2)边界标记和蓝(1)沉降后的像素均保留原色。

**关键洞察**：必须对比多个示例才能发现走廊判定发生在重力沉降之后——单个示例中无法区分"先判定后沉降"与"先沉降后判定"两种假设，因为两者可能碰巧产生相同输出。

## 新题 2：拓扑分类决定展开几何

**组合逻辑**：[连通分量检测/connected_component_detection](已有) → [边界可达性分类/edge_reachability → 拓扑分类/topological_classification](已有) → {外部区域: [正交邻域展开](已有) | 内部区域: [对角邻域展开](已有)}（创新：拓扑属性而非标记颜色决定展开方向）

**来源原语**：连通分量检测/connected_component_detection、连通区域/connected_region、网格边界/grid_edge、边界可达性/edge_reachability、拓扑分类/topological_classification（P9: 84db8fc4）；印章覆盖/stamp_overlay、标记像素/marker_pixel、邻域扩展/neighborhood_expand、仅填背景格/only_fill_background（P1: dc1df850）；对角邻接/diagonal_adjacency、正交邻接/orthogonal_adjacency、标记色选邻域几何/marker_color_selects_neighborhood（P17: 0ca9ddb6）

**依赖链**：拓扑分类结果直接决定展开几何形状的选择分支——未完成分类时无法确定使用哪种展开模式。这不是线性流水线，而是分类后的条件分支结构。

根据红色标记像素所在黑色区域是否接触网格边缘，分别以正交或对角方式展开光环。

**输入结构**：约 15x15 的黑(0)背景网格。蓝(1)和绿(3)像素组成不规则屏障墙（4-连通的线状或块状结构），将黑色背景分割成多个 4-连通区域。部分黑色区域接触网格边缘（外部区域），部分被屏障完全包围（内部区域，至少 2 个）。在若干黑色区域内各有恰好一个红(2)标记像素（外部和内部区域各至少 1 个红标记）。生成约束：红标记与最近的屏障像素之间至少间隔 1 格黑色，使展开后的光环不触及屏障。

**规则**：
1. 将所有黑(0)像素按 4-连通性划分为若干独立区域。
2. 对每个区域分类：若其任意像素位于网格的第 0 行、最后一行、第 0 列或最后一列，则标记为"外部区域"；否则标记为"内部区域"。
3. 对每个红(2)标记像素：
   - 若该标记位于外部区域：将其上、下、左、右四个正交邻居中颜色为黑(0)的格涂为黄(4)。
   - 若该标记位于内部区域：将其左上、右上、左下、右下四个对角邻居中颜色为黑(0)的格涂为橙(7)。
4. 已有非黑色像素（屏障、红标记、已涂黄/橙的格）均不被覆盖。红标记像素本身保留。

**关键洞察**：所有标记像素颜色相同（均为红(2)），但展开方向完全不同——决定因素不是标记本身的任何属性，而是其所在背景区域的拓扑性质。需对比多个示例中外部和内部区域标记的展开结果来归纳此分支规则。

## 新题 3：轮廓填充涌现拓扑封闭

**组合逻辑**：[行跨度填充/row_span_fill](已有) → [连通分量检测/connected_component_detection](已有) → [拓扑分类 → 条件重涂色](已有)（创新：填充操作在空心轮廓处创建了输入中不存在的拓扑屏障，从而改变后续分类结果）

**来源原语**：填充/fill、轮廓线/outline、封闭区域/enclosed_region、行内边界配对/row_boundary_pairing、逐行跨度填充/row_span_fill（P5: 22168020）；连通分量检测/connected_component_detection、边界可达性/edge_reachability、拓扑分类/topological_classification、重涂色/recolor（P9: 84db8fc4）

**依赖链**：填充空心轮廓将其变为实心屏障 → 实心屏障重新划分黑色背景的连通性 → 部分原本连通至边缘的区域变为封闭区域 → 封闭区域内的标记被重涂色。三步之间每步的输出实质性改变下一步的输入空间结构。

先将空心轮廓按行跨度填实，再根据填充后的拓扑封闭性将被围标记涂灰。

**输入结构**：约 14x14 的黑(0)背景网格。2-3 条蓝(1)空心轮廓线：每条轮廓线覆盖若干连续行（4-8 行），在每一行恰好有两个蓝(1)像素（左右边界），形成空心的不规则封闭形状（如菱形、梯形、不对称多边形轮廓）。约 4-6 个红(2)单像素标记散布在轮廓线外部的黑色区域中。生成约束：填充前所有黑色区域通过轮廓线的行间空隙 4-连通至网格边缘；填充后至少 1 个红标记被蓝色填充体完全围住（不再 4-连通至边缘），且至少 1 个红标记仍可达边缘。

**规则**：
1. 对每条蓝(1)轮廓线，逐行处理：在该轮廓线覆盖的每一行上，将该行两个蓝(1)像素之间（含端点）的所有格涂为蓝(1)——即行跨度填充。
2. 填充完成后，将所有黑(0)像素按 4-连通性分组为独立区域。
3. 对每个黑色区域：
   - 若该区域的任意像素位于网格边缘行或列，则为"开放区域"——其中的红(2)标记保持红(2)不变。
   - 否则为"封闭区域"——其中的红(2)标记重涂为灰(5)。
4. 蓝(1)像素和无标记的黑(0)背景均不改变。

**关键洞察**：输入中的空心轮廓看似不影响背景连通性（行间有黑色空隙允许连通），但填充后变为实心屏障切断了连通路径。红标记的颜色变化不取决于它与轮廓的空间距离，而取决于填充后的全局拓扑封闭性——同一轮廓内外的标记结果不同。

## 新题 4：缺损比较驱动楔形传播

**组合逻辑**：[对齐比较/aligned_comparison → 差异提取/difference_extraction](已有) → [缺失格位置映射为传播种子](创新：从掩码裁剪改为几何参数传递) → [沿对角线扩展楔形传播/diagonal_propagate + 逐行交换双色/row_swap_bicolor](已有，从顶行色带改为离散种子点)

**来源原语**：差异提取/difference_extraction、对齐比较/aligned_comparison、前景图案/foreground_motif、缺损副本/damaged_copy、缺失掩码/missing_cell_mask（P4: 2037f2c7）；沿对角线传播/diagonal_propagate、收缩楔形/shrinking_wedge、逐行交换双色/row_swap_bicolor（P3: b5bb5719）

**依赖链**：差异提取产生缺失格的位置和颜色信息 → 缺失格的列位置决定楔形传播的起始列 → 缺失格在完整图案中的颜色决定楔形交替的初始相位。不进行比较就无法确定种子参数；参数不同则传播图案完全不同。

比较完整与缺损图案提取缺失格，以缺失格的列位置和颜色为种子，在下方区域生成逐行交替颜色的扩展楔形。

**输入结构**：约 15x20 的橙(7)背景网格。上半区（行 0 到行 5）包含两个相同大小（约 4x5，高x宽）的多色前景图案，水平排列，间隔 2 列橙色。左侧图案为完整副本，由红(2)和灰(5)像素组成。右侧图案为缺损副本，其中 1-3 个前景格被替换为橙(7)背景色。行 6 为橙(7)分隔行。下半区（行 7 到行 19）为纯橙(7)背景。生成约束：缺损格分布在不同列；每个缺损格在完整图案中的颜色为红(2)或灰(5)。

**规则**：
1. 将两个图案按边界框左上角对齐，逐格比较：记录所有"完整图案中为前景而缺损图案中为橙(7)"的格位置，及其在完整图案中的颜色（红(2)或灰(5)）。
2. 对每个缺失格，计算其在完整图案中的列偏移 c_offset。在行 7（分隔行下方第一行）的列位置 = 右侧图案的左边缘列 + c_offset 处放置一个种子。
3. 从每个种子位置向下传播扩展楔形：第 r 行（种子行为 r=0）填充从种子列 - r 到种子列 + r 的范围（宽度 2r+1），超出网格左右边界的部分截断。
4. 每行的填充颜色由该种子对应的缺失格原始颜色决定：若原始颜色为红(2)，则偶数行（r=0,2,4,...）填红(2)、奇数行填灰(5)；若原始颜色为灰(5)，则偶数行填灰(5)、奇数行填红(2)。
5. 若两个楔形区域在某格重叠，种子列位置靠左的楔形像素优先保留（先绘制靠右的楔形，再绘制靠左的楔形覆盖其上）。

**关键洞察**：楔形的起始位置和颜色交替的初始相位均由缺损比较的结果唯一确定——同一个图案的不同缺损方式会产生位置和相位都不同的传播图案。需对比多个示例确认种子的产生规则（来自差异提取而非固定位置）。

## 新题 5：重复图案解码印章模板

**组合逻辑**：[种子瓦片提取/crop + seed_tile](已有) → [标记色传递/marker_color_pass](已有，从角落标记改为散布标记) → [印章覆盖/stamp_overlay](已有，模板形状由提取结果动态决定而非固定)

**来源原语**：裁剪/crop、种子瓦片/seed_tile、重复图案/repeating_pattern、角落即种子/corner_is_seed、提取未偏移区域/extract_unshifted（P14: d10ecb37）；印章覆盖/stamp_overlay、标记像素/marker_pixel、邻域扩展/neighborhood_expand、仅填背景格/only_fill_background（P1: dc1df850）；标记色传递给模板/marker_color_pass（P11: fd02da9e）

**依赖链**：种子瓦片的形状从重复图案中解码 → 种子形状成为印章模板 → 标记像素的颜色替换模板中前景色后进行覆盖。删除种子提取步骤后印章形状无法确定；删除颜色传递后印章颜色无法确定。

从左区重复图案中提取种子瓦片作为印章模板，以右区每个标记像素为中心、用标记色印刷该模板。

**输入结构**：约 12x20 的黑(0)背景网格，由一列灰(5)竖直分隔线（列 9）分为左区和右区。左区（列 0-8，约 12x9）：由一个 NxM 的种子瓦片（N=2-3 行，M=2-3 列，包含蓝(1)前景像素和黑(0)背景像素，前景像素 2-4 个）平铺重复填满整个左区，种子瓦片的未偏移副本位于左区左上角。右区（列 10-19，约 12x10）：黑(0)背景上散布 2-4 个不同颜色的单像素标记（从红(2)、绿(3)、黄(4)中选取，每个标记颜色不同）。生成约束：标记之间的行列间距均不小于种子瓦片的对应维度，使印章不重叠；标记距右区边界不小于种子瓦片半径，使印章不截断。

**规则**：
1. 确定种子瓦片大小：找到使左区可被精确平铺的最小矩形单元——即最小的 NxM 使得左区每个像素 (r, c) 的颜色等于 (r mod N, c mod M) 处的颜色。
2. 提取左区左上角的 NxM 区域作为种子瓦片。
3. 对右区中的每个标记像素（位于行 r_m、列 c_m）：
   - 以 (floor(N/2), floor(M/2)) 为种子瓦片的中心锚点。
   - 将种子瓦片以锚点对齐到 (r_m, c_m) 后覆盖放置：种子中每个颜色为蓝(1)（前景）的格，将其在目标网格上对应位置涂为该标记像素的颜色。
   - 仅覆盖目标位置为黑(0)的格；已有非黑像素不被覆盖。
4. 左区、分隔线和标记像素本身均保持不变。

**关键洞察**：印章的形状不是预定义的简单几何图形（十字或方块），而是从左区的平铺周期中隐式编码——需对比多个示例中不同左区图案对应的不同印章形状，才能归纳出"种子即模板"的规则。

## 新题 6：频率排名门控选择性填充

**组合逻辑**：[频率排序/frequency_rank → 少数色判定](已有，从全局替换改为选择性门控) → [行跨度填充/row_span_fill](已有，仅对少数色轮廓执行)

**来源原语**：频率排序/frequency_rank、少数色替换/minority_replaced（P12: 9caf5b84）；填充/fill、轮廓线/outline、行内边界配对/row_boundary_pairing、逐行跨度填充/row_span_fill（P5: 22168020）；重涂色/recolor（P12）

**依赖链**：频率排序产生颜色优先级 → 优先级判定决定哪些轮廓属于"少数色" → 只有少数色轮廓被填充。频率计算必须先于填充决策；删除频率判断后无法确定填充目标。

统计所有轮廓线颜色的像素频率，仅将少数色轮廓线按行跨度填实，多数色轮廓保持空心。

**输入结构**：约 15x15 的黑(0)背景网格。4-5 条不同颜色的空心轮廓线（从蓝(1)、红(2)、绿(3)、黄(4)、品红(6)中选取，每条轮廓线一种颜色），每条轮廓线覆盖若干连续行，在每一行恰好有两个同色像素（左右边界），形成不同大小的空心形状。各轮廓线互不交叉、互不重叠。不同轮廓线包含的像素数不同（例如一条覆盖 8 行共 16 像素，另一条覆盖 3 行共 6 像素）。生成约束：恰好两种颜色的总像素数并列前两位（多数色），其余为少数色；各颜色像素数互不相等。

**规则**：
1. 统计输入中每种非背景颜色的总像素数，按像素数从高到低排序。
2. 将排名前两位的颜色标记为"多数色"，其余非背景颜色标记为"少数色"。
3. 对每条轮廓线：
   - 若其颜色为少数色：在该轮廓线覆盖的每一行上，将两个边界像素之间（含端点）的所有格涂为该轮廓线的颜色（行跨度填充）。
   - 若其颜色为多数色：保持原样（空心）。
4. 黑(0)背景和多数色轮廓线不改变。

**关键洞察**：填充与否不取决于轮廓线的几何属性（大小、位置、形状），而取决于颜色的全局频率排名——像素数多的颜色反而不被填充。需对比多个示例中不同频率分布下的填充结果才能排除"大轮廓被填充"或"特定颜色被填充"等错误假设。

## 新题 7：邻域展开阻塞走廊

**组合逻辑**：[描边/mark_neighbors + 标记色选邻域几何/marker_color_selects_neighborhood](已有) → [展开像素作为障碍物](创新：展开结果参与后续走廊判定) → [对边连通检测 + 无阻挡涂色/unobstructed_span_recolored](已有)

**来源原语**：描边/mark_neighbors、标记像素/marker_pixel、对角邻接/diagonal_adjacency、正交邻接/orthogonal_adjacency、标记色选邻域几何/marker_color_selects_neighborhood（P17: 0ca9ddb6）；射线延伸/ray_extend、边界像素/border_pixel、走廊/corridor、对边连通/opposite_edge_connect、无阻挡跨行列涂色/unobstructed_span_recolored（P13: 2bee17df）；重涂色/recolor（P13）

**依赖链**：标记展开在潜在走廊路径上产生新前景像素 → 这些像素将原本通透的走廊变为阻塞状态。走廊检测必须在展开之后进行——删除展开步骤会导致更多走廊被错误地判定为通透。

先对红/蓝标记分别执行对角/正交邻域展开，再检测展开后仍然通透的边界-到-边界走廊并涂色。

**输入结构**：约 12x12 的黑(0)背景网格。网格四条边缘上有若干青(8)像素作为走廊端点标记：某些行的第 0 列和第 W-1 列同时为青(8)，某些列的第 0 行和第 H-1 行同时为青(8)。网格内部有若干红(2)和蓝(1)的单像素标记（共 3-5 个），散布在不同位置。生成约束：展开前至少 3 条潜在走廊（行或列，两端均为青(8)且内部全为黑(0)）；展开后至少 1 条走廊被新产生的黄(4)或橙(7)像素阻挡而失效，至少 1 条走廊仍保持通透。

**规则**：
1. 对每个红(2)标记像素，将其四个对角邻居（左上、右上、左下、右下）中颜色为黑(0)的格涂为黄(4)。对每个蓝(1)标记像素，将其四个正交邻居（上、下、左、右）中颜色为黑(0)的格涂为橙(7)。红和蓝标记像素本身保留。
2. 展开完成后，逐行检查：若该行第 0 列和第 W-1 列均为青(8)，且该行第 1 列到第 W-2 列的所有格均为黑(0)（不含黄、橙、红、蓝等任何非背景色），则将该行内部（第 1 列到第 W-2 列）涂为绿(3)。
3. 逐列检查：若该列第 0 行和第 H-1 行均为青(8)，且该列第 1 行到第 H-2 行的所有格均为黑(0)，则将该列内部（第 1 行到第 H-2 行）涂为绿(3)。
4. 行走廊和列走廊交叉处的格涂为绿(3)（无冲突）。所有其他像素保持不变。

**关键洞察**：标记像素本身可能不在任何走廊路径上，但其展开辐射会"飞溅"到相邻的走廊行或列中造成阻塞——需理解展开的几何范围如何与走廊路径产生空间干涉。

## 新题 8：频率优先级决定重力碰撞顺序

**组合逻辑**：{[频率排序/frequency_rank](已有) → [冲突优先级/conflict_priority](已有，从空间位置改为频率决定)} + {[重力下落/gravity_drop + 碰撞阻挡/collision_blocking](已有)} → [条件重涂色](创新：触底与否决定最终颜色)

**来源原语**：滑动/slide、连通分量/connected_component、碰撞阻挡/collision_blocking、重力远近序处理/gravity_far_to_near、重力下落/gravity_drop（P18: 5ffb2104）；频率排序/frequency_rank（P12: 9caf5b84）；冲突优先级/conflict_priority（P7: 03560426）；重涂色/recolor（P9: 84db8fc4）

**依赖链**：频率排序决定碰撞时的处理优先级（谁先固定为障碍） → 碰撞结果决定每个对象的最终垂直位置 → 是否触底决定重涂色与否。三个机制同时约束最终布局——频率改变则碰撞顺序改变，碰撞顺序改变则触底判定改变，环环相扣。

所有对象同时下落，碰撞时颜色频率高的先固定为障碍，未触底的对象被涂为灰色。

**输入结构**：约 12x10 的黑(0)背景网格。4-6 个单色 4-连通对象（每个 2-5 像素，形状为不规则连通体），使用 3-4 种颜色（从蓝(1)、红(2)、绿(3)、黄(4)中选取）。部分颜色有多个对象（该颜色总像素数较高），部分颜色只有一个小对象（低频率）。对象分布在网格的中上部，底部留有下落空间。生成约束：各对象在水平方向上的列投影有部分重叠（至少两个不同颜色的对象在某些列有垂直遮挡关系——直接下落会碰撞）；各颜色的总像素数互不相等。

**规则**：
1. 统计输入中每种非背景颜色的总像素数，按像素数从高到低排序为优先级序列。
2. 按优先级从高到低依次处理每种颜色的所有对象：将该颜色的每个 4-连通对象在保持形状和列位置不变的前提下，向下滑动直到其最底行像素触及网格最后一行或碰到已固定的对象的像素的上一行而停止。同一颜色内若有多个对象，按原始最底行像素的行号从大到小（更靠下的先处理）依次固定。
3. 所有对象固定后，检查每个对象：若该对象的最底行像素位于网格最后一行（行 H-1），则保持原色；否则将该对象所有像素重涂为灰(5)。

**关键洞察**：碰撞优先级不由空间位置（谁更靠下或谁更靠右）决定，而由颜色的全局出现频率决定——高频色对象先行固定占位，可能在低频色对象的下落路径上形成障碍使其无法触底。需对比多个示例中不同频率分布下的碰撞结果来区分频率优先与空间优先。

## 新题 9：沉降障碍改变连线路径

**组合逻辑**：[列内重力沉降/gravity_settling](已有，仅作用于障碍物色) → [同色分量连线/connect + 绕障碍最短路径/shortest_detour](已有，路径依赖沉降后的障碍布局)

**来源原语**：滑动/sliding、列内独立/column_independent、重力沉降/gravity_settling（P2: 1e0a9b12）；连线/connect、同色连通分量/same_color_comp、障碍墙/obstacle_wall、同色分量依序连接/same_color_chain、绕障碍最短路径/shortest_detour（P6: f8f52ecc）

**依赖链**：障碍物沉降改变了连线需要绕行的几何布局——某条原本被障碍阻断的直线路径在沉降后可能变得畅通（障碍落到下方），反之亦然（障碍堆积到路径上）。连线结果完全依赖沉降后的空间约束。

将灰色障碍块按列内重力下沉后，用最短 L 形路径依序连接每种颜色的同色分量。

**输入结构**：约 14x14 的黑(0)背景网格。灰(5)像素组成若干小块障碍物（每块 1-3 像素，4-连通），悬浮在网格中部（不接触底行）。2-3 种非灰前景色（如蓝(1)、红(2)、绿(3)），每种颜色有 2-3 个 4-连通分量（每个 2-4 像素），分散在网格各处。生成约束：沉降后至少改变一对同色分量之间最短 L 形路径的走向——即沉降前路径需绕行灰块，沉降后灰块不在该路径上（或反之）；各待连接分量的形状不全相同。

**规则**：
1. 对每一列，将该列中所有灰(5)像素按列内重力下沉：读取该列中灰像素从上到下的顺序，清空这些位置为黑(0)，再从该列最底行开始向上依次放置灰像素，保持原始相对顺序。非灰像素不移动。
2. 沉降完成后，对每种非灰、非背景颜色，将其所有 4-连通分量按行主序排列（按分量中最小行号从小到大，行号相同时按最小列号从小到大）。
3. 依次连接每对相邻分量（第 1 与第 2、第 2 与第 3，依此类推）：从前一分量的某个边界像素到后一分量的某个边界像素，寻找经过格数最少的 L 形路径（至多一次 90 度转弯的正交路径）。路径只能经过黑(0)背景格或同色已有像素，不能经过灰(5)障碍或其他颜色像素。
4. 在所有等长最短 L 形路径中，选择先水平移动再垂直移动的路径（若先水平也有多条，选水平段行号较小的）。
5. 将选中路径上的黑(0)格涂为该颜色。各颜色的连线独立进行，按颜色在输入中首次出现的行主序依次处理（先完成一种颜色的所有连线，再处理下一种颜色；先连线的颜色占据的路径格成为后续颜色的障碍）。

**关键洞察**：连线路径的走向不取决于障碍物在输入中的空间位置，而取决于其沉降后的位置——同一组待连接分量在不同障碍沉降结果下会产生不同的绕行路径。需对比输入中障碍位置与输出中的路径走向来推断中间的沉降步骤。

**依赖链**：每个精灵体必须判断是否需要水平镜像才能与某个孔洞形状匹配 → 匹配结果决定使用原始还是镜像形态 → 所有（经可选镜像的）精灵体必须恰好拼合所有孔洞。这是约束满足结构而非线性流水线——镜像决策和分配决策相互制约。

将小精灵体（部分需水平翻转）平移拼入大对象的封闭孔洞中，精确覆盖所有孔洞格。

**输入结构**：约 16x16 的黑(0)背景网格。1-2 个大型蓝(1)单色对象（每个约 20-40 像素的 4-连通体），内部有封闭的黑(0)背景孔洞（被蓝(1)像素完全 4-连通包围的黑色区域），每个孔洞 3-8 像素，形状不规则且不左右对称。网格其他区域散布 2-4 个小型多色精灵体（每个 3-8 像素，4-连通，颜色从红(2)、绿(3)、黄(4)中选取，每个精灵体单色），位于大对象外部。生成约束：部分精灵体的原始形状与某个孔洞直接吻合，部分精灵体需要水平镜像后才与某个孔洞吻合（镜像轴为精灵体边界框的垂直中轴）；所有精灵体经可选镜像后恰好精确拼合所有孔洞（每个精灵体用恰好一次，每个孔洞格被恰好覆盖一次）；不存在第二种合法拼合方案（考虑镜像选择和分配两个维度的所有组合）。

**规则**：
1. 识别蓝(1)大对象内部的所有封闭黑(0)孔洞：被蓝(1)像素完全 4-连通包围、不与网格边缘连通的黑色区域。
2. 对每个外部精灵体，生成两种候选形态：原始形态和水平镜像形态（将精灵体的像素相对于其边界框的垂直中轴左右翻转）。
3. 找到精灵体到孔洞的唯一合法分配：每个精灵体以其两种候选形态之一平移后，其像素集合与某个孔洞的像素集合完全相同（形状和大小均匹配），且所有孔洞均被恰好一个精灵体覆盖。
4. 将每个精灵体以确定的形态（原始或镜像）平移到其匹配孔洞的位置，保持精灵体原有颜色。
5. 擦除每个精灵体在原始位置的所有像素（恢复为黑(0)）。蓝(1)大对象保持不变。

**关键洞察**：并非所有精灵体都需要镜像——只有原始形状与所有孔洞都不匹配的精灵体才需翻转。由于孔洞形状不对称，原始和镜像是两个不同的候选形态，求解者必须同时确定每个精灵体的形态和目标孔洞，形成组合约束满足问题。
