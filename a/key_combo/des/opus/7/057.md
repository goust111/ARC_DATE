## 新题 1：图元分解驱动方向滑移

**组合逻辑**：[分解/decompose] → [图元形状决定方向](创新：形状类型编码滑移方向而非仅编码颜色) → [滑动/slide] + [重涂色/recolor]

**来源原语**：分解/decompose、基本图元/primitive_shape、图元形状决定涂色/shape_determines_color（来自 150deff5）；滑动/slide、靠边对齐/edge_aligned、缺口决定方向/notch_determines_dir（来自 320afe60）；重涂色/recolor（来自 150deff5、320afe60）

**依赖链**：分解操作揭示每个碎片的几何身份（正方形 vs 长条）→ 几何身份决定滑移方向（左 vs 右）→ 方向决定目标边界 → 同侧碎片按原始距离堆叠 → 堆叠结果决定最终坐标。删去分解则方向未知；删去滑移则形状分类无意义；删去堆叠则输出有歧义。

将灰色复合块分解为正方形和长条形图元，正方形滑向左边界涂红，长条形滑向右边界涂蓝，同侧碎片按原始位置堆叠。

**输入结构**：约 12x14 网格，黑(0) 背景。3~5 个灰(5) 4-连通前景区域散布于网格中，每个区域由若干 2x2 正方形和 1x3 或 3x1 长条形无缝拼接而成（共享边界像素属于且仅属于一个图元，分解方式唯一）。每个灰色区域占 4~10 像素。各区域互不接触（至少间隔 1 个像素）。生成约束：每个灰色连通区域恰好存在唯一的非重叠分解方案（将其切分为 2x2 和 1x3/3x1 的拼接），且左半区和右半区各至少出现一个正方形和一个长条形。

**规则**：
1. 对每个灰(5) 4-连通区域，找到唯一的非重叠分解，将其切分为 2x2 正方形和 1x3（水平）或 3x1（竖直）长条形。
2. 清空画布为黑(0)。
3. 对每个 2x2 正方形碎片：保持其原始行跨度不变，将其水平滑移至网格最左侧边界对齐，重涂为红(2)。
4. 对每个 1x3 或 3x1 长条形碎片：保持其原始行跨度和朝向不变，将其水平滑移至网格最右侧边界对齐，重涂为蓝(1)。
5. 同一侧的碎片按堆叠规则排列：原始位置离目标边界更近的碎片紧贴边界放置，后续碎片依次紧邻前一个碎片。处理顺序：按碎片边界框左上角坐标先行后列排序（行号小优先，行号相同则列号小优先）。
6. 若两个碎片行跨度重叠且滑向同一边界，它们在各自的行上独立堆叠（每行独立计算已占用的列数）。

**关键洞察**：分解不仅是分类步骤，更是对每个碎片的运动指令解码——几何身份（正方形 vs 长条）编码了方向信息。必须先解决分解问题才能确定任何碎片的去向，且同侧碎片的堆叠顺序依赖于它们的原始空间位置，两层逻辑缺一不可。

## 新题 2：杯形开口路由的链式灌注

**组合逻辑**：[填充/fill] + [开口朝向/opening_direction](创新：开口作为定向出口和定向入口的双重角色) → [射线延伸/ray_extend] → [链式连接/chain_linkage](创新：链的连通性由杯体开口的空间对准关系决定)

**来源原语**：填充/fill、杯形轮廓/cup_outline、开口/opening、封闭区域/enclosed_region、开口决定延伸向/opening_extend_dir（来自 d4f3cd78）；射线延伸/ray_extend（来自 d4f3cd78、d07ae81c）；链式连接/chain_linkage、链式序列/chained_sequence（来自 84551f4c）

**依赖链**：识别源杯（标记像素定位）→ 填充源杯内部 → 从源杯开口射线延伸 → 射线命中另一杯的开口则进入并填充 → 递归传播直到无新杯可达。删去开口分析则传播方向未知；删去链式传播则只填充一个杯；删去射线则杯间连接断裂。

从标记杯出发，填充内部后通过开口方向发射射线，射线若正好进入另一杯的开口则链式填充该杯并继续传播，未被射线从开口方向击中的杯保持空白。

**输入结构**：约 18x18 网格，黑(0) 背景。4~6 个红(2) 杯形轮廓散布于网格中，每个杯由一个矩形（约 3x3 至 5x5）的三条边组成（一个像素厚的 U 形轮廓，开口朝上、下、左或右中的某个方向）。恰好一个杯的内部有一个黄(4) 标记像素（标识源杯）。杯体之间至少间隔 2 个像素。部分杯的开口方向正对另一杯的开口方向（即一杯的出射方向与另一杯的入射方向在同一行或列上对准），形成可达链路；部分杯的开口面向空旷区域或面壁，不与任何其他杯连通。生成约束：杯与杯之间的射线路径上不存在其他杯的壁体像素阻挡（即射线在到达目标杯开口之前不会被中间障碍截断），且从源杯出发至少可链式到达 2 个以上其他杯。

**规则**：
1. 找到含黄(4) 标记像素的杯（源杯）。
2. 将源杯的封闭内部（杯壁围成的区域中的黑(0) 像素以及黄(4) 标记像素）全部填充为青(8)。
3. 确定源杯的开口方向（杯壁缺失的那一边）。从开口处的每个内边缘像素向开口方向发射射线（青(8) 着色），射线沿该方向直线前进，直到碰到非黑(0) 像素或离开网格边界时停止（不覆盖碰到的非黑(0) 像素本身）。
4. 如果某条射线停止时碰到的非黑(0) 像素属于另一个杯的红(2) 壁体，检查：该壁体像素是否是目标杯开口边的邻接像素（即射线从开口方向进入了目标杯）。若是，则该杯被"链式激活"——对其执行步骤 2-3（填充内部为青(8)，从其自身开口射出新射线）。若射线碰到的是目标杯的封闭壁体（非开口边），则该杯不被激活，射线在此处终止。
5. 链式激活递归进行：每个新激活的杯都执行步骤 2-4，直到没有新杯被激活为止。每个杯最多被激活一次。
6. 所有红(2) 杯壁保持不变。未被激活的杯内部保持黑(0)。

**关键洞察**：杯体的开口方向构成一个有向连通图——填充信号只能沿开口的出射方向传播，且只有当目标杯的开口面向来射方向时才能接收信号。空间中杯的朝向编排决定了哪些杯可达、哪些不可达，这不是简单的距离关系而是方向对准关系。

## 新题 3：瓦片损伤计数驱动柱状填充

**组合逻辑**：[修复异常/repair] + [多数投票共识/majority_vote] → [计数/counting](创新：损伤单元格数量作为频率目标值) → [柱状填充/histogram_fill] + [频率匹配/frequency_matching]

**来源原语**：修复异常/repair、重复图块/repeated_tile、分隔网格/separator_grid、多数投票共识/majority_vote、受损副本被标记/damaged_marked（来自 e84fef15）；计数/counting、柱状填充/histogram_fill、频率匹配/frequency_matching、分隔行/separator_row、编码行/code_row、频率等于标记数/frequency_equals_marker_count（来自 2685904e）

**依赖链**：对瓦片格阵执行多数投票恢复共识图案 → 找到唯一的受损瓦片并计算损伤像素数 D → D 成为柱状填充的目标频率 → 在编码行中筛选出现次数恰好为 D 的颜色 → 按柱状规则绘制高度为 D 的竖条。删去修复则 D 未知；删去频率匹配则不知绘制哪些列；删去柱状填充则 D 无用武之地。

通过瓦片多数投票找到受损副本的损伤数量，以此数量为频率目标在编码行中筛选颜色并绘制对应高度的柱状条。

**输入结构**：约 15x20 网格，分为上下两区。上区：2 行 x 3 列共 6 个等大方块（每块约 4x4），由单像素宽的灰(5) 分隔行和分隔列隔开。每块内部使用红(2) 在黑(0) 背景上绘制同一图案，但恰好有一个块中部分红(2) 像素被替换为黑(0)（损伤）。下区：一条灰(5) 满行宽分隔行，其下方紧邻一行编码行，编码行中有若干不同颜色的像素（如蓝(1)、绿(3)、黄(4)、橙(7) 等），其余为黑(0)。编码行中每种颜色出现的次数各不相同。灰分隔行与编码行之间的区域为黑(0) 空白区，高度至少为 6 行（足以容纳柱状条）。生成约束：恰好存在一种编码行颜色的出现次数等于损伤像素数 D，且 D >= 2。

**规则**：
1. 在上区的 6 个方块中，对每个局部坐标取跨所有方块的多数颜色，恢复共识图案。
2. 找到唯一一个与共识图案不同的方块（受损方块），计算其中与共识不同的像素数量 D。
3. 在下区编码行中，统计每种非黑(0) 颜色的出现次数。
4. 找到出现次数恰好等于 D 的颜色（可能有多种）。
5. 对于编码行中这些匹配颜色的每次出现，在该列上方、灰(5) 分隔行下方的空白区内，从紧邻分隔行的行开始向下填充 D 个像素，使用该编码行颜色。
6. 上区瓦片、灰分隔行、分隔列、编码行本身均保持不变。

**关键洞察**：瓦片修复不是为了"修好"瓦片——它的真正目的是提取损伤计数 D。D 作为一条跨区域传递的"消息"，从瓦片分析域流入柱状填充域，参数化了一个完全不同的操作。单看上区或下区都无法独立求解。

## 新题 4：吸附定位后距离编码射线

**组合逻辑**：[吸附/snap] + [最近距离/nearest_distance] → [射线延伸/ray_extend](创新：射线长度由吸附前的原始距离编码) + [距离递变/distance_gradient](创新：距离信息在吸附中被擦除但以射线长度重新表达)

**来源原语**：吸附/snap、孤立像素/singleton_pixel、锚块/anchor_block、外框边缘/outer_frame、最近距离/nearest_distance、最短距离分配/nearest_frame_assign、擦除/erase（来自 1b8318e3）；射线延伸/ray_extend（来自 d4f3cd78、d07ae81c）；距离递变/distance_gradient（来自 a65b410d）

**依赖链**：计算每个孤立像素到最近锚块的距离 D → 将像素吸附到锚块外框上最近的帧格 → 从帧格位置判断外射方向 → 以 D 为长度绘制外射射线。删去吸附则射线起点未知；删去距离计算则射线长度未知；删去方向判断则射线朝向未知。三者缺一则输出不确定。

将每个孤立像素吸附到最近锚块的外框上，然后从吸附位置向外发射一条射线，射线长度等于吸附前像素到锚块的切比雪夫距离。

**输入结构**：约 15x15 网格，黑(0) 背景。2~3 个灰(5) 实心 2x2 锚块分布在网格中部区域，彼此间隔至少 5 个像素。4~6 个孤立像素散布在网格各处，每个像素颜色互不相同（从蓝(1)、红(2)、绿(3)、黄(4)、橙(7) 中选取），每个像素与其最近锚块的切比雪夫距离在 2~5 之间。生成约束：每个孤立像素有唯一最近锚块（无并列最近）；每个锚块的外框（锚块外围一圈共 12 个格子）有足够的空位接纳吸附到该锚块的所有像素；射线在网格内有足够空间延伸而不覆盖其他锚块。

**规则**：
1. 对每个孤立像素，计算它到每个灰(5) 2x2 锚块的切比雪夫距离（像素到锚块最近像素的切比雪夫距离），找到唯一最近的锚块。记录该距离为 D。
2. 在锚块的外框（围绕 2x2 锚块的 12 个相邻格子，含对角邻居）中，找到离该孤立像素原始位置最近的帧格（切比雪夫距离最短）。若有多个等距帧格，选择沿基数方向（上、右、下、左，按此优先顺序）的那个。
3. 清除孤立像素的原始位置（设为黑(0)）。在帧格处放置该像素的颜色。
4. 确定射线的外射方向：帧格相对于锚块中心（2x2 锚块四个像素的几何中心）的方向即为外射方向。若帧格在锚块正上方则方向为上，在右上方则方向为右上（对角），以此类推（共 8 个方向）。
5. 从帧格出发（包含帧格本身），沿外射方向绘制恰好 D 个像素的射线，使用该孤立像素的颜色。超出网格边界的部分截断。
6. 射线不覆盖灰(5) 锚块像素和已有的其他颜色像素。若射线路径上遇到非黑(0) 像素（已被先前射线占用），射线在该像素之前终止（不含该像素）。
7. 处理顺序：按孤立像素到其目标锚块的距离 D 从小到大处理；D 相同时按原始位置先行后列排序。

**关键洞察**：每个孤立像素携带两条信息到达目的地：颜色（画什么）和原始距离（画多远）。吸附操作抹除了像素的空间位置信息，但距离信息被"记忆"并重新编码为射线长度——这是一种跨操作的信息传递，在源题中不存在。

## 新题 5：边界框宽度自传播链式平移

**组合逻辑**：[平移/translate] + [边界框决定偏移/bounding_box_determines_offset] → [链式连接/chain_linkage](创新：链的连接条件是相邻对象边界框的水平邻接关系，平移距离由自身宽度决定) → [重涂色/recolor](创新：链内角色决定颜色)

**来源原语**：平移/translate、连通分量/connected_component、边界框决定偏移/bounding_box_determines_offset、按自身宽度平移/shift_by_own_width（来自 64a7c07e）；链式连接/chain_linkage、链式序列/chained_sequence、高度即宽度/height_equals_width（来自 84551f4c）；重涂色/recolor（来自 320afe60）

**依赖链**：计算每个对象的边界框宽度 W 和左边界列 L → 检测链式邻接（B.L = A.L + A.W 则 A→B 成链）→ 识别链首/链中/链尾/孤立四种角色 → 链内对象平移 W 列，孤立对象不动 → 按角色重涂色。删去宽度计算则链条件和平移距离都未知；删去链分析则不知哪些对象该动；删去角色涂色则输出丢失链结构信息。

在水平邻接的对象之间发现链式序列，链内每个对象向右平移自身边界框宽度的距离，并按链内角色（链首/链中/链尾）分别涂色。

**输入结构**：约 10x22（宽幅）网格，黑(0) 背景。5~7 个小型红(2) 8-连通前景对象，每个占 2~6 像素，分布在网格中。部分对象的边界框在水平方向恰好首尾相接（对象 A 的边界框右边界列 +1 等于对象 B 的边界框左边界列），形成 2~3 条链，每条链含 2~3 个对象。其余对象为孤立对象（不与任何链相邻）。各对象的行跨度可重叠，但像素不重叠。生成约束：链内对象平移后不会与其他对象（含其他链的平移结果）重叠；平移后不会超出网格右边界。

**规则**：
1. 识别所有红(2) 8-连通前景对象，计算每个对象的边界框宽度 W（列数）和左边界列 L。
2. 建立链式连接：若对象 B 的左边界列 L_B 恰好等于对象 A 的左边界列 L_A 加上对象 A 的宽度 W_A（即 B 紧邻 A 右侧），则 A→B 形成一条有向链接。
3. 沿链接方向拓展，找到所有最大链序列。链首 = 没有前驱的对象；链尾 = 没有后继的对象；链中 = 既有前驱又有后继的对象。不在任何链中的对象为孤立对象。
4. 清空画布为黑(0)。
5. 对每个链内对象（链首、链中、链尾），将其所有像素向右平移 W 列（W 为该对象自身的边界框宽度）。
6. 重涂色规则：链首涂蓝(1)，链中对象涂绿(3)，链尾涂黄(4)。若链仅含两个对象，第一个为链首（蓝(1)），第二个为链尾（黄(4)），无链中。
7. 孤立对象不移动，保持红(2)，在原位重新绘制。
8. 绘制顺序：先绘制孤立对象，再绘制链内对象（链内按链首→链中→链尾的顺序绘制；多条链之间按链首位置先行后列排序）。

**关键洞察**：链式关系隐藏在对象边界框的水平间距中——只有间距恰好为零（邻接）的对象才构成链。平移距离由每个对象自身的宽度决定（而非统一值），因此不同宽度的对象平移后展开的间距也不同。链的角色分析（首/中/尾）决定了颜色编码，三层逻辑紧密交织。

## 新题 6：标记像素计数排列面板选取规则

**组合逻辑**：[计数/counting] + [标记归属区域/marker_in_region] → [投票/vote](创新：标记计数在面板间产生排名，排名决定位序选择规则的分配) → [裁剪/crop] + [拼接/merge] + [位序选择/positional_selection]

**来源原语**：计数/counting、投票/vote、标记像素/marker_pixel、色块区域/color_region、标记归属区域/marker_in_region、最多标记区胜出/max_marker_wins（来自 de1cd16c）；裁剪/crop、拼接/merge、等分面板/equal_panel、分隔条/separator_bar、前景对象/foreground_object、位序选择/positional_selection、面板序号选对象/panel_selects_obj（来自 5ecac7f7）

**依赖链**：统计每个面板中黄色标记像素的数量 → 按数量排名（最多/中间/最少）→ 排名映射到位序选择规则（最多→选最左对象，中间→选中间对象，最少→选最右对象）→ 各面板按分配到的规则选取自己的对象 → 合成输出。删去标记计数则排名未知；删去排名-选取映射则选取规则未知；删去位序选取则无法确定输出对象。

三面板中每面板的黄色标记像素数量决定该面板的排名，排名最高的面板取最左对象、排名中间的取中间对象、排名最低的取最右对象，三者合成为输出。

**输入结构**：约 10x32（宽幅）网格。三个 HxH 等大面板（H 约 10）由单列灰(5) 分隔条隔开。每个面板黑(0) 背景上有恰好 3 个同色 4-连通前景对象（三个面板分别使用红(2)、蓝(1)、绿(3)），3 个对象在水平方向上分开排列（边界框互不重叠）。每个面板的背景区域还散布着若干黄(4) 标记像素（每面板 1~4 个，三个面板的黄色像素数量两两不同），黄色像素不与前景对象重叠。生成约束：三个面板中黄(4) 像素数量两两不同（无并列），三个面板内各自的 3 个前景对象在水平方向上排列顺序明确（边界框左边界列两两不同）。

**规则**：
1. 统计每个面板中黄(4) 标记像素的数量。
2. 按数量将三个面板排名：数量最多 → 排名 1，数量中间 → 排名 2，数量最少 → 排名 3。
3. 分配位序选择规则：排名 1 的面板 → 选取该面板中最左侧的前景对象（边界框左边界列最小者）；排名 2 的面板 → 选取该面板中水平位置居中的前景对象；排名 3 的面板 → 选取该面板中最右侧的前景对象（边界框左边界列最大者）。
4. 擦除所有黄(4) 标记像素。
5. 构建一个 HxH 的黑(0) 输出画布。将三个被选对象复制到输出画布上，保持各自在面板内的相对位置（行列偏移相对于其所在面板左上角的偏移量）。
6. 若被选对象在输出画布上重叠，后绘制的覆盖先绘制的。绘制顺序：排名 1 的面板对象先绘制，排名 2 次之，排名 3 最后。

**关键洞察**：标记像素看似噪声实则编码了一个排列组合——它们的数量决定面板排名，排名又决定位序选择规则如何分配到各面板。同一个面板在不同示例中可能因标记数量变化而分到不同的选取规则，因此必须对比多个示例才能归纳出"计数→排名→选取"的映射链。

## 新题 7：最大框架内隐式原型驱动形状匹配

**组合逻辑**：[裁剪/crop] + [面积最大选取/largest_area_select] + [最大框决定裁切/largest_frame_crops](创新：裁切结果不是最终输出而是中间原型) → [形状匹配/shape_match] + [压缩/compress] + [旋转反射等价/rotation_reflection_eq] → [重涂色/recolor] + [擦除/erase]

**来源原语**：裁剪/crop、矩形框架/rect_frame、面积最大选取/largest_area_select、最大框决定裁切/largest_frame_crops（来自 fcb5c309）；形状匹配/shape_match、压缩/compress、原型对象/prototype_object、候选对象/candidate_object、旋转反射等价/rotation_reflection_eq、游程压缩后比较/run_length_compare（来自 bd14c3bf）；重涂色/recolor、擦除/erase

**依赖链**：在多个矩形框中找到面积最大者 → 裁剪出最大框内部内容作为原型 → 对每个候选对象进行游程压缩 → 将压缩后的候选掩码与原型掩码在旋转/反射下比较 → 匹配者重涂色、不匹配者擦除。删去框架选择则原型未知；删去压缩则拉伸变体无法匹配；删去匹配则裁切无后续意义。

从多个矩形框中选出面积最大的一个，提取其内部图形作为匹配原型，然后在框外的候选对象中筛选出与原型拓扑等价（允许旋转、反射和游程拉伸）的对象并重涂色，淘汰不匹配者。

**输入结构**：约 20x20 网格，黑(0) 背景。2~3 个灰(5) 单像素厚矩形框架（完整封闭的矩形环），面积各不相同。面积最大的框架内部包含一个红(2) 小型图形（3~6 像素的 4-连通图案，如 L 形、T 形或不规则形状）和黑(0) 背景；其他较小框架内部为纯黑(0) 或包含无关噪声像素（品红(6)，1~2 个）。框架外的网格区域散布着 4~6 个蓝(1) 候选对象，每个占 3~8 像素，部分候选对象是原型的旋转/反射/游程拉伸变体，部分不是。生成约束：最大框架面积严格大于次大框架面积；至少有 2 个匹配候选对象和 1 个不匹配候选对象。

**规则**：
1. 识别所有灰(5) 单像素厚矩形框架，计算每个框架的边界框面积（宽 x 高）。
2. 选出面积最大的框架。裁剪其内部区域（不含框架边界本身），得到一个子网格。
3. 在子网格中提取红(2) 像素构成的图案作为原型。将原型裁剪至其最小边界框，然后对其进行游程压缩：沿行方向折叠相邻的相同列内容，沿列方向折叠相邻的相同行内容，得到压缩后的原型掩码 M。
4. 对每个蓝(1) 候选对象：裁剪至最小边界框，执行同样的游程压缩，得到压缩掩码 C。
5. 将 C 与 M 在全部 8 种旋转/反射变换下逐一比较（二值掩码逐像素匹配）。若任一变换下 C 与 M 完全一致，则该候选匹配。
6. 匹配的候选对象重涂为绿(3)。不匹配的候选对象擦除为黑(0)。
7. 所有灰(5) 框架、框架内部内容（含红(2) 原型和品红(6) 噪声）保持不变。

**关键洞察**：原型不是显式给出的——它被编码在最大框架的内部结构中。解题者必须先执行"找最大框→裁切→提取原型"的空间推理，才能进行后续的拓扑匹配。框架的选择机制（面积最大）和匹配的比较机制（压缩+旋转反射）是两个独立的推理维度，必须同时正确才能得出输出。

## 新题 8：对称轴定位噪声像素生成下行楔形

**组合逻辑**：[对称补全/symmetry_completion](创新：不是补全对称而是利用对称分析定位异常) → [擦除/erase] + [填充/fill] + [距离递变/distance_gradient](创新：异常位置成为楔形生长的种子点) + [逐行宽度递变成楔/row_width_increments_form_wedge]

**来源原语**：对称补全/symmetry_completion、色层/color_layer、对称轴/symmetry_axis、忽略干扰项/ignore_distractors（来自 8e5c0c38）；填充/fill、三角楔形/triangular_wedge、距离递变/distance_gradient、逐行宽度递变成楔/row_width_increments_form_wedge（来自 a65b410d）；擦除/erase

**依赖链**：对每个色层独立找到最佳垂直对称轴 → 识别破坏对称的噪声像素 → 擦除噪声像素 → 从每个噪声像素的原始位置向下生成三角楔形填充。删去对称分析则噪声位置未知；删去楔形填充则对称分析只产生清理效果（与源题无异）；两者组合产生了"异常检测→几何生成"的新逻辑链。

对每个颜色层找到垂直对称轴，定位并擦除破坏对称的噪声像素，再从噪声像素的原始位置向下生长三角楔形，楔形颜色为该像素原所属色层的颜色。

**输入结构**：约 16x16 网格，黑(0) 背景。2 种非背景色（如红(2) 和蓝(1)），每种颜色的像素构成一个近似关于某条垂直轴对称的图案（每种颜色有自己独立的对称轴，两条轴在不同列上）。每种颜色有 8~15 个像素，其中 1~2 个像素是"噪声"——它们在对称轴的另一侧没有同色镜像对应。噪声像素位于网格上半部分（行号 <= 网格高度/2），确保下方有足够空间生成楔形。两种颜色的像素互不重叠。生成约束：每种颜色的垂直对称轴唯一确定（使对称像素对数量最大化的轴只有一条）；噪声像素不位于对称轴上；噪声像素下方至少有 4 行空间。

**规则**：
1. 对每种非黑(0) 颜色，收集该颜色的所有像素坐标，逐列测试找到使同色镜像对数量最大化的垂直对称轴（轴可以在整数列上或两列之间的半整数位置上）。
2. 对每种颜色，找到没有同色镜像对应的像素——这些是噪声像素。记录每个噪声像素的位置 (r, c) 和颜色。
3. 将所有噪声像素从网格中擦除（设为黑(0)）。
4. 对每个被擦除的噪声像素位置 (r, c)，以该位置为顶点向下生成三角楔形，使用该噪声像素原来的颜色：
   - 第 0 行（行 r）：仅 (r, c) 一个像素，宽度 1。
   - 第 k 行（行 r+k，k >= 1）：以列 c 为中心，宽度为 2k+1，即填充列 c-k 到 c+k。
   - 持续向下直到楔形的任一侧触及网格列边界或到达网格底行。
5. 楔形填充不覆盖已有的非黑(0) 像素。当楔形某一行的某个像素位置已被非黑(0) 像素占据时，跳过该像素（该位置保留原有颜色），楔形的其他像素正常填充。
6. 保留对称部分的所有原始像素不变。

**关键洞察**：对称分析不是一个清理操作而是一个检测操作——它识别出"异常"位置。这些异常位置不被简单删除，而是转化为新几何结构（楔形）的种子点。输出同时包含"清理后的对称图案"和"从异常点生长的楔形"，两种视觉元素叠加在一起，理解题意需要同时掌握对称性分析和楔形生长两套规则。

## 新题 9：走廊路径区域投票着色

**组合逻辑**：[路径填充/path_fill] + [最短路径并集/monotone_shortest_path_union] → 空间筛选 → [计数/counting] + [投票/vote] + [标记归属区域/marker_in_region] + [最多标记区胜出/max_marker_wins](创新：只有路径邻域内的标记参与投票，投票结果决定路径颜色) → [重涂色/recolor]

**来源原语**：路径填充/path_fill、门框/doorway_frame、走廊路径/corridor_path、门洞朝向/doorway_orientation、最短路径并集/monotone_shortest_path_union（来自 692cd3b6）；计数/counting、投票/vote、标记像素/marker_pixel、色块区域/color_region、标记归属区域/marker_in_region、最多标记区胜出/max_marker_wins（来自 de1cd16c）；重涂色/recolor

**依赖链**：定位两个门框并计算走廊路径（单调最短路径并集）→ 识别路径邻域内的标记像素 → 按标记所在底色区域分组计数 → 票数最多的区域颜色成为路径填充色。删去路径计算则不知哪些标记参与投票；删去投票则路径颜色未知；删去区域归属则标记无法分组。路径几何筛选了投票者，投票者决定了路径属性——双向依赖。

计算两个门框之间的单调最短路径并集，然后统计路径上及其相邻区域内的标记像素对各底色区域的投票，票数最多的区域颜色作为路径填充色。

**输入结构**：约 18x18 网格。网格大部分区域被两种底色（红(2) 和蓝(1)）以大块矩形区域铺满（两色区域拼合覆盖整个网格，边界清晰）。两个灰(5) 小型矩形框（约 3x3，单像素厚）位于网格中不同位置，每个框中心有一个橙(7) 标记像素，每个橙(7) 标记像素恰有一个黑(0) 4-邻居（门洞间隙），门洞外侧下一个格子是外部门洞格。若干黄(4) 标记像素散布在底色区域中（不在灰框内），每个黄(4) 像素被其所在区域的底色（红(2) 或蓝(1)）包围。所有前景结构（灰框、橙中心）视为阻挡物。生成约束：两个门框之间存在至少一条不经过阻挡物的单调路径；黄(4) 标记像素在路径邻域（路径格及其 4-邻居中的非阻挡格）内至少有 3 个，且分属两种底色区域的数量不相等。

**规则**：
1. 找到两个灰(5) 矩形框，每框内部有一个橙(7) 中心像素。
2. 对每个框，找到门洞间隙：橙(7) 像素的唯一黑(0) 4-邻居。门洞间隙外侧的下一个格子（沿远离橙像素的方向）是外部门洞格。
3. 将所有非底色像素（灰(5) 框体、橙(7) 中心）视为阻挡物。计算两个外部门洞格之间的单调最短路径并集：仅允许行/列步进向目标靠近（每步要么减少行距要么减少列距），路径不经过阻挡物。将所有这样的路径经过的背景格（底色格）的并集记为走廊 C。
4. 定义路径邻域 N = 走廊 C 中所有格子及其 4-邻居中的非阻挡格的并集。
5. 在 N 中找到所有黄(4) 标记像素。对每个黄(4) 像素，确定它所在的底色区域：检查该像素的 4-邻居中占多数的底色（红(2) 或蓝(1)）。
6. 分别统计路径邻域内属于红(2) 区域的黄(4) 像素数量 n_R 和属于蓝(1) 区域的黄(4) 像素数量 n_B。
7. 若 n_R > n_B，将走廊 C 中所有格子及两个门洞间隙格涂为红(2)。若 n_B > n_R，涂为蓝(1)。若 n_R = n_B（生成约束下不会出现），涂为离左侧门框更近的外部门洞格所在底色区域的颜色。
8. 灰(5) 框体、橙(7) 中心像素、黄(4) 标记像素均保持不变。走廊外的底色区域保持不变。

**关键洞察**：路径几何和标记投票形成双向约束——路径形状决定了哪些标记有投票权（空间筛选），而标记的投票结果决定了路径用什么颜色填充。单看门框位置只能确定路径形状但不知颜色；单看标记分布只能确定颜色倾向但不知哪些标记相关。两个子问题必须交叉求解。
