## 新题 1：对称性分流的路径颜色接力

**组合逻辑**：[对称检测](创新：不做筛选/淘汰，而是分配"发射端/接收端"角色) → [路径连通](已有) → [重涂色](创新：按路径配对进行颜色传递) → [同心扩展](创新：用接收端原色而非统一色做扩展环)

**来源原语**：对称检测(44f52bb0), 路径连通(d35bdbdc), 重涂色(d35bdbdc/aedd82e4), 同心扩展(3a301edc), 颜色查找键(d35bdbdc)

**依赖链**：对称检测将每个图形分类为发射端或接收端 → 路径连通确定哪个发射端与哪个接收端配对 → 重涂色将接收端涂为配对发射端的颜色 → 同心扩展使用接收端的*原始*颜色在其外围添加一层环，使最终结果编码了"来自谁的颜色"和"自身原本是谁"两重信息。删除任一步骤，后续步骤缺少必要输入。

根据对称性分配发射/接收角色，沿灰色路径将发射端颜色传递给配对的接收端，并以接收端原色添加外围环标记来源身份。

**输入结构**：约 14x14 网格，黑(0)背景。网格中散布 4-6 个小型单色图形（4-连通，每个 3-6 像素，形态各异——不同示例中同类图形的具体外形不同），每个图形使用一种独特颜色，颜色取自 {蓝(1), 红(2), 绿(3), 黄(4), 品红(6), 橙(7)}。灰(5)像素构成单像素宽的 8-连通路径段，将图形两两连接（每个图形恰好连接一条路径，即图形成对出现）。生成约束：每对中恰好一个图形在其边界框内具有水平镜像对称性，另一个不具有；所有路径互不交叉。

**规则**：
1. 对每个图形，检测其在自身边界框内是否具有水平镜像对称性（即上半部分与下半部分关于中间行对称）。对称的图形标记为"发射端"，不对称的标记为"接收端"。
2. 对每个接收端，沿其连接的灰(5)路径追踪至另一端的发射端，建立配对关系。
3. 将每个接收端的所有像素重涂为其配对发射端的颜色。
4. 在每个已重涂的接收端周围，添加一层同心扩展像素（即在接收端边界框外围一圈，每个方向扩展 1 像素），扩展像素使用该接收端*重涂前*的原始颜色。扩展不超出网格边界。
5. 擦除所有灰(5)路径像素（变为黑(0)）。
6. 擦除所有发射端图形（变为黑(0)）。
7. 处理顺序不影响结果（各对互不干涉）。

**关键洞察**：对称检测不是过滤机制，而是角色分配机制——对称图形成为颜色源、不对称图形成为颜色目标，两者的身份由几何属性决定，再通过路径连通完成方向性颜色传递。外围环编码了接收端被覆盖前的原始身份。

## 新题 2：空腔形状匹配嵌套与阵列坐标奇偶换色

**组合逻辑**：[面积匹配 + 嵌套/dock](创新：匹配对象从边框框架改为瓦片阵列中的空腔) → [旋转/翻转](已有) → [阵列坐标编码](创新：坐标奇偶性决定是否触发颜色互换，而非原题中坐标决定孔洞位置) → [颜色互换](创新：由空间位置而非反射操作触发)

**来源原语**：嵌套/dock(a25697e4), 面积匹配(a25697e4), 旋转(a25697e4), 翻转(a25697e4), 颜色互换(a25697e4), 瓦片阵列(9ddd00f0), 阵列坐标编码(9ddd00f0), 擦除(d35bdbdc)

**依赖链**：空腔形状决定精灵体配对 → 嵌套需要旋转/翻转确定朝向 → 阵列坐标的行列之和的奇偶性决定是否在嵌套后交换精灵体的两种颜色 → 未匹配的精灵体被擦除。四个步骤形成"匹配→定向→条件变色→清理"的链条，每一步的输出改变下一步的行为。

将散落的双色精灵体嵌入瓦片阵列中形状匹配的空腔，阵列坐标奇偶性决定嵌入后是否交换精灵体的两种颜色。

**输入结构**：约 15x15 网格，黑(0)背景。网格上半区包含一个 3x3 瓦片阵列（每个瓦片约 3x3 像素，瓦片之间由单像素宽的黑(0)分隔行和分隔列隔开）。每个瓦片是一个单色边框（颜色为灰(5)），内部有一个由黑(0)像素构成的空腔（2-4 像素，形状各异——各瓦片的空腔形状互不相同，且不同示例中空腔的具体形态不同）。网格下半区散布若干小型双色精灵体（每个精灵体由两种颜色组成，4-连通，总像素数 3-6，每种颜色占据 2-4 像素），精灵体的颜色取自 {蓝(1), 红(2), 绿(3), 黄(4), 品红(6), 橙(7)}。生成约束：精灵体数量等于有空腔的瓦片数量；每个精灵体恰好有一种旋转/翻转方式使其一种颜色的像素区域形状与某个空腔完全匹配（像素数和形状均吻合），且该匹配是唯一的。瓦片阵列位置从左上角 (0,0) 开始编号。

**规则**：
1. 对每个精灵体，找到瓦片阵列中空腔形状与精灵体某一颜色区域的像素形状匹配的瓦片（允许 0/90/180/270 度旋转和水平翻转）。匹配条件：精灵体的该颜色区域经变换后与空腔形状逐像素一致。
2. 将精灵体以匹配所需的旋转/翻转方式嵌入对应瓦片的空腔中：匹配颜色填充空腔，另一种颜色的像素按同一变换覆盖空腔外的瓦片区域（若超出瓦片边界框则裁剪）。
3. 计算该瓦片在阵列中的位置 (row, col)。若 row + col 为奇数，则交换嵌入后精灵体的两种颜色。
4. 擦除下半区所有未嵌入的精灵体残余像素（变为黑(0)）。
5. 空腔未被任何精灵体匹配的瓦片保持原样（空腔仍为黑(0)）。
6. 精灵体按面积（总像素数）从大到小依次处理；面积相同时按精灵体边界框左上角坐标从左到右、从上到下处理。

**关键洞察**：瓦片阵列的坐标系隐含了一条棋盘格式的奇偶规则——奇数位置的精灵体颜色互换，偶数位置保持原色。这一规则仅通过对比不同阵列位置上同一类精灵体的颜色关系才能发现。

## 新题 3：同色射线交叉定靶与尺寸筛选印章

**组合逻辑**：[射线延伸](已有) → [行列交叉](创新：仅同色交叉产生靶点，跨色交叉忽略) → [按面积筛选](已有) → [印章覆盖](创新：印章目标由射线交叉而非预置标记决定) → [顺序对应](创新：绘制顺序由标记像素空间位置决定)

**来源原语**：射线延伸(45bbe264/fe9372f3), 行列交叉(45bbe264), 按面积筛选(337b420f), 印章覆盖(414297c0), 标记像素(45bbe264/414297c0), 标记色匹配精灵(414297c0), 颜色匹配配对(247ef758), 顺序对应(8e1813be)

**依赖链**：射线从标记像素发射 → 同色射线交叉产生靶点坐标 → 面积筛选为每种颜色选出正确的精灵体 → 精灵体按颜色匹配印章至靶点 → 绘制顺序由左侧标记像素的行位置决定（后处理的覆盖先处理的）。射线构造了靶点网格，筛选选择了印章模板，空间位置决定了叠放次序——三条线索在印章步骤汇合。

沿网格边缘的同色标记像素发射射线，仅同色射线的交叉点成为印章靶点；用面积筛选后的精灵体印章覆盖这些靶点。

**输入结构**：约 18x18 网格，黑(0)背景。沿顶部边缘，有 2-3 个不同颜色的标记像素（颜色取自 {蓝(1), 红(2), 绿(3)}），各自占据不同列。沿左侧边缘，有 2-3 个标记像素，使用与顶部标记相同的颜色集合（每种颜色在左侧恰出现一次），各自占据不同行。在网格右下区域，每种标记颜色对应两个同色精灵体（4-连通，单色）：一个较大（5-8 像素），一个较小（1-3 像素）。生成约束：同色的顶部标记和左侧标记各至少 1 个；各精灵体互不接触且不接触网格边缘；同色的两个精灵体大小严格不同。

**规则**：
1. 从每个顶部标记像素向下发射垂直射线（贯穿整列），从每个左侧标记像素向右发射水平射线（贯穿整行）。射线绘制为灰(5)。
2. 检查每个射线交叉点：仅当交叉的垂直射线和水平射线来自**同色**标记时，该交叉点成为该颜色的"靶点"。不同色射线的交叉点不产生靶点，保持灰(5)。
3. 对每种标记颜色，比较该颜色的两个精灵体的像素数，丢弃较小的（擦除为黑(0)），保留较大的作为该颜色的印章模板。
4. 对每种颜色，将其印章模板以模板的几何中心（边界框中心，向左上取整）对齐靶点中心，印章到所有该颜色的靶点上。印章像素覆盖该位置的已有像素（包括灰(5)射线）。
5. 绘制顺序：按左侧标记像素的行坐标从小到大（即从上到下）依次处理各颜色。后处理的颜色的印章覆盖先处理的。
6. 印章超出网格边界的部分裁剪（不绘制）。
7. 擦除所有原始精灵体位置的像素（包括被保留的大精灵体的原始位置）和所有标记像素（变为黑(0)），保留灰(5)射线和印章结果。

**关键洞察**：并非所有射线交叉都产生靶点——只有同色标记的交叉才有效。这意味着靶点网格是颜色选择性的，而非全局笛卡尔积，需要对比不同颜色的标记配置才能发现此规则。

## 新题 4：边界接触定轴的镜像探针选取条纹

**组合逻辑**：[接触边界定轴](已有) → [镜像](创新：镜像产物不是最终输出的一部分，而是作为空间探针使用) → [负片色映射](创新：映射后的颜色用于标记探针区域，使其与原始元素可区分) → [条纹决定填充轴 + 排序](创新：被探针覆盖的条纹被选中并按行序提取为输出)

**来源原语**：接触边界定轴(6f473927), 镜像(6f473927), 负片色映射(6f473927), 条纹(8e1813be), 排序(8e1813be), 填充(8e1813be), 裁剪(337b420f/414297c0)

**依赖链**：前景形状接触的边界决定镜像轴 → 镜像产生翻转副本 → 负片色映射将副本标记为探针（视觉上可区分）→ 探针的空间范围覆盖若干条纹 → 被覆盖的条纹被选中 → 选中条纹按原始行位置从上到下排列形成输出。形状几何决定了探针的空间范围，而这个范围恰好是条纹选择器。

将接触边界的红色形状镜像翻转形成空间探针，探针覆盖到的水平条纹被选中，按行序提取为单列输出。

**输入结构**：约 12x20 网格（宽大于高），黑(0)背景。一个由红(2)像素构成的前景形状（4-连通，6-12 像素，形态不规则——不同示例中具体外形不同）接触网格的恰好一条垂直边界（左边界或右边界），不接触水平边界。在网格远离该形状的一半区域，有 3-5 条水平条纹（每条 1 像素高，横跨部分网格宽度，颜色各不相同，取自 {蓝(1), 绿(3), 黄(4), 品红(6), 橙(7)}），分布在不同行。生成约束：形状镜像后的边界框在行方向上覆盖的范围至少包含 2 条条纹的行，且不覆盖所有条纹；条纹所在行互不相同。

**规则**：
1. 确定前景形状接触的垂直边界（左或右），该边界为镜像轴。
2. 将前景形状沿该镜像轴做水平翻转，在原轴的另一侧生成镜像副本。
3. 对镜像副本应用负片色映射：副本中红(2)像素变为青(8)，副本边界框内的黑(0)像素保持为黑(0)。（注意：映射仅作用于副本区域，不影响原始形状和条纹。）
4. 检查每条水平条纹：若该条纹的行坐标落在青(8)镜像副本的边界框行范围内，且该行中至少有一个青(8)像素存在，则该条纹被"选中"。
5. 输出为一个小网格：高度等于被选中的条纹数量，宽度为 1。按被选中条纹在原始网格中的行位置从上到下排列，每行填充对应条纹的颜色。
6. 原始形状、镜像副本、未选中条纹均不出现在输出中。

**关键洞察**：镜像翻转不是为了构造最终图案，而是作为"空间探针"——翻转后的形状决定了哪些行被激活，从而选中哪些条纹进入输出。改变前景形状的几何外形就改变了输出的颜色序列。

## 新题 5：干扰项过滤后的计数驱动同心嵌套

**组合逻辑**：[忽略干扰项 + 尺寸分类](创新：干扰项与主体同色，必须通过连通分量面积阈值过滤) → [计数](创新：计数的是过滤后主体的像素数，而非原题中的对象个数) → [排序 + 按数量排序](已有) → [同心扩展 + 嵌套遮罩](创新：嵌套层序由像素计数排序决定，而非原题中由边长分级决定)

**来源原语**：忽略干扰项(b1986d4b/337b420f), 尺寸分类(aedd82e4), 计数(b1986d4b), 排序(8e1813be), 按数量排序(b1986d4b), 同心扩展(3a301edc), 嵌套遮罩(b1986d4b), 连通分量(337b420f/aedd82e4)

**依赖链**：尺寸分类过滤每种颜色的干扰碎片 → 正确的像素计数仅在过滤后才可得 → 像素计数决定排序 → 排序决定同心嵌套中各颜色的层序（像素最多的颜色在最外层，最少的在最内层）。若不正确过滤干扰项，计数被污染，嵌套层序随之错乱。

**输入结构**：约 16x16 网格，黑(0)背景。3-5 个不同颜色的单色填充矩形（颜色取自 {蓝(1), 红(2), 绿(3), 黄(4), 橙(7)}，每个矩形 4-16 像素，宽高比各异），散布在网格中，互不接触。每种颜色除主矩形外，还有 1-2 个同色的小型"干扰碎片"（4-连通，每个 1-2 像素）散落在网格其他位置，与主矩形不相邻（8-连通下不相连）。生成约束：各色主矩形的像素数互不相同；干扰碎片的单个面积（像素数）始终不超过 3 像素；所有连通分量（主体和干扰项）互不接触。

**规则**：
1. 对每种出现的前景颜色，识别所有该颜色的 4-连通分量。
2. 丢弃像素数不超过 3 的分量（干扰碎片），保留像素数超过 3 的分量作为该颜色的"主体"。每种颜色恰好保留一个主体。
3. 记录每个主体的像素数。
4. 按像素数从大到小排列所有颜色。
5. 输出一个正方形网格，边长等于颜色数量乘以 2 再减 1（即 n 种颜色时为 2n-1）。从最外层开始，第一层（最外围）填充像素数最多的颜色；向内每层缩进 1 像素，依次填充下一个颜色；最内层为像素数最少的颜色的单像素中心。
6. 同心层的结构为以输出网格中心为对称中心的正方形环，最外层边长为 2n-1，向内依次为 2n-3、2n-5、...、1。

**关键洞察**：干扰碎片与主体共享颜色，如果不过滤就会错误地增大该颜色的像素计数，导致排序结果错误。过滤阈值本身也是一条隐蔽规则——需要对比多个示例确认"面积不超过 3"是干扰项的判别标准。

## 新题 6：路径到达位置决定印章行目标

**组合逻辑**：[路径连通](创新：路径不仅判断是否连通，其到达位置还编码印章的行目标) → [标记交叉定位](创新：列目标仍由框架标记决定，但行目标由路径终点而非精灵体颜色决定) → [复制放置](已有) → [擦除](已有)

**规则**：
1. 对每个精灵体，沿其灰(5)路径追踪至框架左边缘，记录到达行号 R。
2. 该精灵体的印章行目标为行 R（即路径到达的位置决定行目标，而非精灵体的原始行位置）。
3. 该精灵体的印章列目标为框架顶边上所有标记像素的列坐标集合（不区分颜色，所有顶边标记列都是目标列）。
4. 将精灵体（仅主体颜色部分，不含标记像素）以其标记像素为锚点，对齐到每个 (行目标, 列目标) 交叉点处进行印章。印章时标记像素位置保持为该交叉点坐标，主体像素按相对偏移放置。
5. 精灵体按路径到达行号从小到大（从上到下）依次印章。后印章的覆盖先印章的。
6. 印章完成后，擦除所有灰(5)路径像素、原始精灵体位置的像素、框架边缘标记像素（均变为黑(0)），保留框架本体和印章结果。

**关键洞察**：路径不只是连通性证明——路径*到达框架的具体行位置*编码了印章的行目标。精灵体可能位于网格的第 3 行，但其路径弯曲后到达框架的第 10 行，于是印章出现在第 10 行。需要对比多个示例才能发现"行目标由路径终点决定"这一隐蔽规则。

## 新题 7：障碍门计数驱动旋转量的走廊移动

**组合逻辑**：[移动 + 同轴对齐的矩形对](已有) → [障碍门处标记通道](已有) → [计数](创新：计数门的数量，而非原题中仅标记门) → [旋转](创新：旋转角度由门计数的模 4 值决定——每道门等于 90 度)

**规则**：
1. 确定移动方向：橙(7)图形向栗(9)目标沿共享轴方向直线移动。
2. 在移动路径（走廊）中，识别所有由黑(0)障碍段两侧夹持的开口区域。每个障碍段计为一道门。
3. 将每道门的开口单元格标记为红(2)。
4. 计算门的总数 G。
5. 将橙(7)图形顺时针旋转 (G mod 4) x 90 度。旋转中心为图形边界框的中心（向左上取整）。
6. 擦除原始橙(7)图形位置（变为灰(5)背景）。
7. 将旋转后的橙(7)图形放置在栗(9)目标的位置（以目标边界框中心对齐图形旋转后的边界框中心），替换掉栗(9)像素。
8. 红(2)门标记和黑(0)障碍段保留在输出中。

**关键洞察**：障碍门承担双重功能——既是走廊的视觉标记（红色），又是旋转变换的计数器（每门 90 度）。需要对比门数量不同的多个示例，才能归纳出"门数 mod 4 决定旋转角度"这一非显然规则。

## 新题 8：连通性分类的模板像素驱动平铺反转

1. 计算左上象限中非黑(0)像素的数量 H，右上象限中非黑(0)像素的数量 W。输出网格尺寸为 H 行 x W 列。

3. 将修改后的模板平铺覆盖整个 H x W 输出区域（周期性重复，对齐左上角）。

   - 若模板位置为品红(6)（原孤立像素）：从左下象限中对应粗坐标位置取颜色，然后填充左下象限中使用的**另一种颜色**（即该粗坐标位置若为绿(3)则填黄(4)，若为黄(4)则填绿(3)）。
5. 输出中不保留品红(6)或黑(0)——所有单元格要么是橙(7)，要么是左下象限的两种颜色之一。

**关键洞察**：孤立像素在模板中充当"反转标记"——它们不直接贡献颜色，而是翻转了该位置从色源获取颜色的逻辑。这一效果仅通过对比模板中孤立像素位置与集群位置在输出中的颜色差异才能发现。

## 新题 10：标记像素数控制区域重涂的扩散深度

**组合逻辑**：[标记形状决定操作 + 标记指向目标](已有) → [重涂色](已有) → [同心扩展](创新：扩展层数由标记的像素数决定，而非原题中由内部矩形尺寸决定) → [叠加冲突解决](创新：多个标记的扩散区域重叠时，像素数更多的标记优先)

**依赖链**：标记的方向性结构（一端突出的茎）指向目标区域 → 茎背后的区域确定源颜色 → 目标区域被重涂为源颜色 → 标记自身的像素总数决定重涂从目标区域边界向外扩散的层数 → 多个标记的扩散区域可能重叠，冲突解决规则为像素数多的标记优先。标记的几何属性同时编码了"指向哪里"和"影响多远"。

方向性标记指定目标区域及源颜色进行重涂，标记自身的像素数量控制重涂向外扩散的层数，重叠区域由更大的标记主导。

**输入结构**：约 16x16 网格。网格为多个相邻单色区域拼成的马赛克（4-连通区域，颜色取自 {蓝(1), 绿(3), 黄(4), 橙(7), 灰(5)}，每个区域 8-30 像素）。在若干区域交界处，有 2-3 个由红(2)像素构成的方向性标记。每个标记是一个 4-连通分量（3-5 像素），结构特征为：有一个像素沿唯一的基数方向突出（"茎"），其余像素构成垂直于茎的连续条（"横杆"）。不同标记的总像素数可能不同。生成约束：每个标记的茎指向一个单色区域（目标区域）；茎的反方向紧邻另一个单色区域（源区域）；各标记指向的目标区域互不相同；标记的像素数在 3-5 之间。

**规则**：
1. 对每个红(2)标记，确定其茎的方向（茎是从横杆的中心位置沿基数方向突出的唯一像素）。茎指向的一侧紧邻的单色区域为"目标区域"。
2. 茎的反方向紧邻的单色区域为"源区域"。记录源区域的颜色 C。
3. 将目标区域的所有像素重涂为颜色 C。
4. 记录该标记的像素总数 N。从目标区域的边界开始，向相邻的其他区域扩散重涂：扩散 N-2 层（即标记像素数减 2 层）。扩散的每一层将目标区域边界外 1 像素范围内的所有非红(2)像素涂为颜色 C。第 k 层扩散涂覆距离目标区域原始边界恰好 k 个曼哈顿步的像素。
5. 所有标记同时处理。若两个标记的扩散区域重叠（同一像素被两个标记的扩散覆盖），则该像素取像素数更大的标记的源颜色。若像素数相同，取在网格中位置更靠左上角（先比较行号再比较列号更小）的标记的源颜色。
6. 处理完成后，所有红(2)标记像素被填充为其所在源区域一侧的最终颜色（即标记被"吸收"进源区域）。

**关键洞察**：标记的像素数量承担双重角色——几何上定义了标记的形状（从而确定指向），数值上控制了重涂的扩散范围。像素更多的标记不仅影响更远，在冲突中也具有优先权。需要对比不同大小标记的示例才能归纳出"像素数=扩散层数+2"和"大标记优先"两条规则。
