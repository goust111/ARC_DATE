## 新题 1：射线划域反转

**组合逻辑**：[射线延伸](创新：射线不着色而是划定边界) + [控制像素](已有) + [反转填充](创新：按射线划分的区域局部反转) + [网格分区](创新：由射线动态生成而非预置分隔线)

**来源原语**：射线延伸/控制像素(981add89), 反转填充(1c0d0a4b), 网格分区(c444b776)

**依赖链**：控制像素的位置决定射线路径 → 射线在网格中划出不规则分区 → 每个分区按射线交叉奇偶性决定是否执行反转 → 反转操作的目标区域完全由射线几何决定，缺少射线信息无法确定哪些区域被反转

将控制像素发出的射线作为动态分区边界，根据射线交叉的奇偶性对各区域执行选择性占位反转。

**输入结构**：约 15x15 的网格，背景为黑(0)。网格左列和上行各散布若干灰(5)孤立控制像素（每列和每行最多各一个，共约 4~6 个）。网格内部散布若干蓝(1)前景像素块（每块为 4 连通的小连通分量，3~8 像素不等，共约 3~5 块，形状不规则、各不相同）。控制像素不与前景像素块相邻。左列的控制像素向右发出水平射线，上行的控制像素向下发出垂直射线，射线本身不着色、不改变任何像素，但在逻辑上将网格内部（去掉第 0 行和第 0 列后的区域）分割成若干矩形分区。生成时保证控制像素位置使得网格内部的每个分区面积至少为 3x3。

**规则**：
1. 左列（第 0 列）的每个灰(5)像素定义一条水平分割线，位于该像素所在行；上行（第 0 行）的每个灰(5)像素定义一条垂直分割线，位于该像素所在列。
2. 这些分割线将网格内部（行 1 至末行、列 1 至末列）分成若干矩形分区。
3. 对每个分区，计算它被几条分割线"围定"——具体地，计算从网格内部左上角 (1,1) 到该分区左上角所跨越的水平分割线数 H 和垂直分割线数 V，令 P = H + V。
4. 若 P 为奇数，对该分区执行占位反转：分区内所有蓝(1)像素变为黑(0)，所有黑(0)像素变为红(2)。
5. 若 P 为偶数，分区内所有像素保持不变。
6. 控制像素所在的第 0 行和第 0 列保持原样不变。

**关键洞察**：射线本身不留痕迹，但其逻辑位置创建了棋盘式奇偶分区；同一个蓝色前景块如果跨越分区边界，不同部分可能被不同地处理（一半反转一半保留），这要求求解者先推断出不可见的分区边界。

## 新题 2：孔洞计数排序压缩与调色板循环涂环

**组合逻辑**：[计数](创新：孔洞数同时决定排序键和涂色索引) + [排序](创新：按孔洞数而非面积排序) + [压缩](已有：压缩为嵌套方环) + [循环填充](创新：环色由孔洞数模调色板长度决定)

**来源原语**：计数/孔洞(8698868d), 排序/压缩/嵌套层次/方环(eb5a1d5d), 循环填充/调色板行(b457fec5)

**依赖链**：逐个形状计数孔洞 → 孔洞数既作为排序键确定嵌套顺序、又作为调色板索引确定环色 → 排序改变了嵌套层级但不改变孔洞数 → 同一孔洞数信息被两条不同路径使用，缺一不可

统计每个形状的内部孔洞数，按孔洞数从多到少排列为嵌套方环，每环颜色由该形状孔洞数对调色板取模决定。

**输入结构**：约 20x20 的网格，背景为黑(0)。网格中散布 4~6 个单色连通形状，每个形状使用不同颜色（从蓝(1)、红(2)、绿(3)、黄(4)、品红(6)中选取），形状为不规则的 4 连通区域（8~30 像素），各形状互不接触。每个形状内部包含 0~4 个孔洞（孔洞定义为被该形状像素完全包围的黑(0)连通区域，4 连通）。各形状的孔洞数互不相同。网格最底行是调色板行：从左到右依次放置 3 个连续像素，颜色分别为橙(7)、青(8)、灰(5)，其余位置为黑(0)。生成时保证各形状孔洞数两两不同。

**规则**：
1. 找到所有非黑、非调色板行的连通形状，统计每个形状内部的孔洞数（4 连通黑色封闭区域数）。
2. 按孔洞数从大到小排序。孔洞数最多的形状对应最外层方环，孔洞数最少的对应最内层。
3. 创建一个 (2K-1) x (2K-1) 的输出网格（K = 形状数量），由嵌套方环组成——最外环宽 1 像素，依次向内。
4. 每个方环的颜色不使用原形状颜色，而是取该形状的孔洞数 C，颜色 = 调色板行的第 (C mod 3) 个颜色（调色板从左到右索引为 0, 1, 2）。
5. 调色板行本身不出现在输出中。

**关键洞察**：孔洞计数承担双重角色——既是排序键也是调色板索引——两个用途产生不同的信息流（层级位置 vs. 颜色选择），仅看单个示例无法确定颜色映射规则来自调色板而非原色。

## 新题 3：双面板异或定向拉伸

**组合逻辑**：[逻辑运算](创新：XOR 而非 NOR) + [拉伸](创新：由面板归属决定拉伸方向) + [分隔列](已有) + [逐格比较](已有) + [碰撞停止](创新：拉伸线遇到已有前景时停止)

**来源原语**：逻辑运算/分隔列/逐格比较(f2829549, 1b2d62fb), 拉伸/控制像素(baf41dbf), 碰撞停止(6e453dd6)

**依赖链**：逐格比较两面板生成 XOR 掩模 → XOR 掩模中每个活跃像素根据其来源面板获得方向属性（左源→向右拉伸，右源→向左拉伸）→ 拉伸线在同行遇到另一个 XOR 像素时停止 → 逻辑运算的输出既是拉伸的起点集也是终止条件，形成内在约束

对两面板做逐格异或比较，差异像素依据来源面板向对侧水平拉伸，遇到同行其他差异像素时停止。

**输入结构**：约 11x25 的网格（11 行、25 列），背景为黑(0)。正中一列（第 12 列）为灰(5)分隔列，将网格分为左面板（列 0~11）和右面板（列 13~24），各 11x12。两面板各含若干蓝(1)前景像素（各约 8~15 像素），分布为若干小连通分量（2~5 像素），形状不规则。两面板存在部分重叠（在对应位置上约 30%~50% 的前景像素重合），使得 XOR 后仍有非平凡的差异集。生成时保证：每一行中 XOR 活跃像素不超过 3 个，且同行中来自左面板和来自右面板的活跃像素至少各有一个的行不少于 2 行（以确保拉伸有碰撞停止的情形）。

**规则**：
1. 去掉灰(5)分隔列，将左面板和右面板在对应位置逐格比较。
2. 输出网格尺寸与单面板相同（11x12）。
3. 对于两面板在对应位置都是前景或都是背景的单元格，输出为黑(0)。
4. 对于仅左面板为前景的位置（左源差异），标记为"向右拉伸源"。
5. 对于仅右面板为前景的位置（右源差异），标记为"向左拉伸源"。
6. 处理每一行：将所有差异源按列坐标从左到右排列。每个差异源从自身位置沿其方向（左源向右、右源向左）水平延伸，绘制红(2)像素，直到遇到同行中下一个差异源的位置（不含该位置）或到达行边界时停止。差异源自身的位置绘制绿(3)。
7. 若同一行中两个相邻差异源方向相对（一个向右一个向左），它们的拉伸线在中间相遇——填充它们之间的所有空格为红(2)，两个源位置自身为绿(3)。

**关键洞察**：逻辑比较的结果不是最终输出，而是携带方向信息的几何指令；拉伸的起点和终点都由同一个 XOR 运算的输出决定，形成自引用约束。

## 新题 4：格点缺位填充与镜像补全联合推断

**组合逻辑**：[对称补全](创新：补全后才能识别模板) + [笛卡尔积缺位填充](创新：模板来自补全结果而非直接输入) + [格点对齐](已有) + [最高频色为目标](创新：用于从多个补全结果中选出公共模板)

**来源原语**：对称补全/镜像/最高频色为目标(c35c1b4c), 笛卡尔积缺位填充/格点对齐/同形精灵体(5b526a93)

**依赖链**：输入的精灵体都是不完整的（只有对称形状的一半）→ 必须先镜像补全每个精灵体 → 补全后发现它们的完整形状相同 → 用完整模板填充格点缺位 → 如果不做补全就无法识别模板，无法填充；如果不做填充就不知道补全是否正确（因为需要多个示例对比确认镜像方向）

将格点上不完整的半对称精灵体逐个镜像补全，从补全结果中提取公共模板，用该模板填充格点的空缺位置。

**输入结构**：约 18x18 的网格，背景为黑(0)。存在一个 3x3 或 4x3 的行列格点（行间距和列间距相同，约 5~6 像素），格点上放置了若干蓝(1)精灵体，占据约 60%~75% 的格点位置，其余位置为空。每个精灵体是同一个左右对称图形的左半部分（含中轴）或右半部分（含中轴），具体是哪一半在不同格点位置可能不同。完整对称图形约 5x5 像素，4 连通，中轴上至少有 2 个像素。生成时保证：至少有 2 个精灵体是左半，至少有 2 个是右半，以便求解者通过对比推断镜像方向。格点中至少有 2 个空位需要填充。

**规则**：
1. 识别行列格点结构和每个已有精灵体的位置。
2. 对每个精灵体，判断它是左半还是右半（方法：检查精灵体像素相对于其边界框中轴的分布——若像素集中在左侧含中轴则为左半，反之为右半）。
3. 对左半精灵体，将其像素沿自身边界框的垂直中轴向右镜像补全；对右半精灵体，向左镜像补全。镜像时中轴像素不重复。
4. 补全后所有精灵体应呈现相同的对称模板。
5. 在每个空格点位置，放置该对称模板的完整副本，使用青(8)颜色（区别于原有的蓝(1)）。
6. 原有精灵体的补全像素也使用蓝(1)（与原像素同色），只有新填充的完整副本使用青(8)。

**关键洞察**：输入中没有任何一个完整的精灵体可供直接参考——必须先从多个半成品中推断镜像方向并补全，才能获得填充模板。左半和右半混合出现迫使求解者对比多个示例才能确定补全规则。

## 新题 5：分区内重力堆叠与同色碰撞融合变色

**组合逻辑**：[重力下落](已有) + [网格分区](创新：分区内独立施加重力) + [重涂色](创新：由碰撞条件触发) + [颜色匹配](创新：同色碰撞融合并变色，异色碰撞停止保留)

**来源原语**：重力下落/绕行(c87289bb), 网格分区/分隔线(c444b776), 重涂色/颜色匹配(981add89), 碰撞停止(6e453dd6)

**依赖链**：分隔线定义独立的列区 → 每个列区内连通分量独立下落 → 下落过程中同色分量碰撞则融合并变为指定新色 → 异色分量碰撞则停止不融合 → 最终的颜色布局取决于下落顺序和碰撞时的颜色判定，无法跳过任何一步

在由分隔线划分的各列区内独立施加重力下落，同色分量碰撞时融合为第三色，异色碰撞时停止保持不变。

**输入结构**：约 15x17 的网格，背景为黑(0)。有 2~3 条垂直灰(5)分隔列，将网格分为 3~4 个等宽列区（每区宽 4~5 列）。每个列区内有 2~4 个小连通分量（4 连通，3~6 像素，形状不规则），悬浮在列区的不同高度。连通分量的颜色从蓝(1)、红(2)、绿(3)中选取，同一列区内允许出现同色的不同分量。生成时保证：每个列区内，从上到下依次处理时至少出现一次同色碰撞和一次异色碰撞；各分量在水平方向上不超出所在列区的边界。

**规则**：
1. 识别灰(5)分隔列，将网格分为若干列区。分隔列本身在输出中保持不变。
2. 在每个列区内，找到所有非背景、非灰色的连通分量。
3. 按每个分量最低像素的行号从大到小排序（即最接近底部的先落地）。
4. 依次让每个分量向下平移，直到其最低像素触及列区底部边缘或触及已落地分量的最顶像素的上一行。
5. 碰撞判定（当分量停止时）：检查刚落地的分量是否与其正下方相邻的已落地分量颜色相同。
   - 同色碰撞：两个分量合并为一个连通分量，所有像素重涂为黄(4)。
   - 异色碰撞：两个分量保持各自颜色不变，仅物理上堆叠。
   - 落到列区底部（无下方分量）：保持自身颜色。
6. 后续分量继续下落时，已融合变黄的分量被视为颜色黄(4)的整体参与后续碰撞判定。

**关键洞察**：碰撞融合改变了颜色，而改变后的颜色又影响后续碰撞的判定结果——前一次碰撞的输出成为后一次碰撞的条件输入，形成链式因果。仅看一个示例难以区分"同色融合变黄"与"所有碰撞都变黄"这两种假设。

## 新题 6：嵌套深度决定对角周期填充的周期长度

**组合逻辑**：[嵌套层次](已有) + [循环填充](创新：周期长度由嵌套深度决定) + [对角线同余](创新：不同层使用不同周期的对角图案) + [调色板行](已有)

**来源原语**：嵌套层次/嵌套形状(eb5a1d5d), 循环填充/调色板行/层深度递增(b457fec5), 对角线同余/对角周期图案(c3f564a4)

**依赖链**：识别嵌套形状的层级 → 每层的深度值 D 决定该层间隙区域的对角周期长度 → 调色板行提供周期所需的颜色序列 → 深度为 1 的层使用周期 1（纯色填充），深度为 2 的使用周期 2（双色对角条纹），深度为 3 的使用周期 3（三色对角循环）→ 不知道嵌套深度就无法确定周期，不知道周期就无法正确填色

根据嵌套轮廓的层级深度，用相应周期长度的对角循环图案填充各层间的空隙区域。

**输入结构**：约 19x19 的网格，背景为黑(0)。网格中央有 3~4 层嵌套的单像素宽闭合轮廓线，从外到内颜色依次为红(2)、绿(3)、蓝(1)、品红(6)（按需选用前几个）。轮廓线形状为不规则但互不交叉的闭合环（各层之间间隔 2~4 像素），每层轮廓完全包含内层。轮廓线之间以及最内层内部为黑(0)背景。网格最底行为调色板行，从左到右依次放置 4 个连续像素：灰(5)、橙(7)、青(8)、黄(4)，其余为黑(0)。最外层轮廓与网格边缘之间的区域（深度 0）不做处理。

**规则**：
1. 识别所有闭合轮廓线（非黑非调色板的连通环），按包含关系确定嵌套层级。最外层轮廓深度 D=1，次外层 D=2，依此类推。
2. 对于深度为 D 的轮廓和深度为 D+1 的轮廓之间的间隙区域（或最内层轮廓内部，视为最大 D+1 层的间隙），用对角周期图案填充。
3. 该间隙区域的对角周期长度 = D（即外层轮廓的深度值）。
4. 对角周期规则：对于间隙区域中每个黑(0)像素，计算 (row + col) mod D，得到索引 I，用调色板行的第 I 个颜色替换该像素。
5. 轮廓线像素保持原色不变。调色板行在输出中保持不变。
6. 最外层轮廓外的区域（深度 0）保持黑(0)不变。

**关键洞察**：同一个调色板在不同嵌套层中被截取不同长度使用，导致相邻层产生视觉上截然不同的对角图案（内层图案更复杂），而这种差异完全由几何嵌套深度决定。

## 新题 7：控制像素定界拉伸后内部平铺种子图案

**组合逻辑**：[拉伸](已有：边界由控制像素确定) + [平铺](创新：拉伸后的内部区域用种子图案平铺) + [控制像素](已有) + [边缘对齐控制点](已有) + [瓦片图案](创新：种子图案从原始前景中提取)

**来源原语**：拉伸/控制像素/边缘对齐控制点(baf41dbf), 平铺/瓦片图案(c444b776)

**依赖链**：控制像素确定新边界 → 原始前景的外框拉伸到新边界 → 外框内部面积增大 → 从原始前景内部提取种子图案（左上角的最小重复单元）→ 用种子图案平铺填充拉伸后的内部 → 拉伸改变了容器大小，平铺填充了内容，种子提取连接了两步

将前景的外边框拉伸至控制像素指定的新边界，然后用从原图内部提取的种子图案平铺填充拉伸后的内部空间。

**输入结构**：约 16x16 的网格，背景为黑(0)。中央有一个蓝(1)的矩形边框（宽 1 像素，约 5x5 到 7x7），内部填有一个 2x2 或 2x3 的绿(3)周期图案（该图案在边框内部重复平铺，可能被边框裁断）。边框外部有 4 个红(2)控制像素，分别位于边框四条边的外侧延长线上（每条边外侧正好一个，距边框 2~5 像素），定义了新的更大边界矩形。控制像素到边框各边的距离不必相等。生成时保证控制像素定义的新矩形完全在网格内部，且新矩形面积至少是原矩形的 2 倍。

**规则**：
1. 识别蓝(1)矩形边框和其内部的绿(3)重复图案。
2. 从边框内部左上角提取最小重复单元（种子图案）：找到能完整平铺出内部现有图案的最小矩形块。
3. 找到 4 个红(2)控制像素。每个控制像素紧邻边框的一条边（上、下、左、右），控制像素所在行/列定义了新边框对应边的位置。
4. 将蓝(1)边框拉伸到新边界：上边移到上控制像素的下一行，下边移到下控制像素的上一行，左边移到左控制像素的右一列，右边移到右控制像素的左一列。
5. 在新边框内部，用种子图案从左上角开始重复平铺，超出边框内部的部分裁剪。
6. 控制像素在输出中保留为红(2)。

**关键洞察**：种子图案藏在原始边框内部的重复结构中，必须先从输入中识别出重复单元，才能在拉伸后的更大空间中正确平铺。拉伸改变了容器但不改变内容的周期，这个不变性是求解的关键。

## 新题 8：NOR 掩模作为射线源阵列与方向指示行

**组合逻辑**：[逻辑运算](已有：NOR) + [射线延伸](创新：NOR 结果像素成为射线发射点) + [调色板行](创新：充当方向指示，确定每列射线的发射方向) + [碰撞停止](创新：射线遇到其他 NOR 像素时停止)

**来源原语**：逻辑运算/逻辑或非合并/分隔条/二值掩模(1b2d62fb), 射线延伸/罗盘方向(1d398264), 碰撞停止(6e453dd6), 调色板行(b457fec5)

**依赖链**：NOR 运算确定哪些位置为活跃像素 → 方向指示行将每列映射到一个射线方向 → 每个活跃像素沿所在列指定的方向发出射线 → 射线遇到另一个活跃像素时停止 → 停止条件由 NOR 运算的其他输出决定，形成自引用结构

对双面板做逻辑 NOR 得到活跃像素集，每个活跃像素沿其列对应的方向发出射线，射线遇到另一个活跃像素时停止。

**输入结构**：约 15x23 的网格，背景为黑(0)。第 0 行是方向指示行，每个单元格为以下四色之一：红(2)=向下、绿(3)=向上、蓝(1)=向右、黄(4)=向左，分别指示该列的射线方向（方向指示行仅覆盖两面板区域对应的列范围，其余为黑(0)）。第 1 行至第 13 行为主区域：中间第 11 列为灰(5)分隔列，左面板占第 0~10 列（11 列宽），右面板占第 12~22 列（11 列宽）。两面板各含栗(9)前景像素（约 10~18 像素），形成若干小连通分量。第 14 行为黑(0)空行。方向指示行的列范围为 0~10（对应输出的 11 列）。生成时保证：NOR 运算后的活跃像素数约 8~15 个，分布不太密集（同行不超过 3 个），且至少 2 对活跃像素在同一行或同一列上形成碰撞停止的情形。

**规则**：
1. 去掉灰(5)分隔列，将左右面板逐格比较。
2. 计算逻辑 NOR：输出青(8)在两面板对应位置都为黑(0)的单元格，其余输出为黑(0)。输出网格尺寸为 13x11（行 1~13，列 0~10 对应的单面板大小）。
3. 读取方向指示行（第 0 行，列 0~10）：红(2)=下, 绿(3)=上, 蓝(1)=右, 黄(4)=左。
4. 对每个青(8)活跃像素，根据其所在列的方向指示，发出一条橙(7)射线。射线从活跃像素的相邻像素开始（不包含发射点自身），沿指定方向逐格绘制橙(7)，直到遇到以下任一情况停止：(a) 到达输出网格边界；(b) 遇到另一个青(8)活跃像素（不覆盖该像素，在其前一格停止）。
5. 若多条射线经过同一像素，后绘制的橙(7)覆盖先绘制的。射线的绘制顺序：按活跃像素位置从上到下、同行从左到右。
6. 活跃像素自身保持青(8)不变。方向指示行不出现在输出中。

**关键洞察**：NOR 运算的结果既是射线的发射源、又是射线的阻挡物——活跃像素集同时扮演"信号发生器"和"信号终止器"两个角色。方向指示行打破了射线方向的局部可推断性，必须从全局读取。

## 新题 9：缺口检测定网格线后沿网格线描边着色

**组合逻辑**：[相邻像素标有效线](创新：不仅检测有效线还输出缺口位置) + [描边](创新：沿检测到的网格线外侧描边而非围绕孤立像素) + [缺口补另色](已有) + [行列对齐](已有) + [标记色决定描边色](创新：缺口所在方向决定描边颜色)

**来源原语**：相邻像素标有效线/缺口/网格线/行列对齐/缺口补另色(4612dd53), 描边/标记色决定描边色(913fb3ed)

**依赖链**：检测相邻对识别有效网格线 → 定位网格线上的缺口 → 缺口位置确定补色 → 同时沿每条有效网格线的两侧各描一条 1 像素宽的边 → 描边颜色由该网格线上的缺口数量决定（缺口多→一种色，缺口少→另一种色）→ 检测、补缺、计数、描边四步紧耦合

先通过相邻对检测有效网格线并补全缺口，再根据每条网格线的缺口数选择颜色对其两侧描边。

**输入结构**：约 15x15 的网格，背景为黑(0)。蓝(1)像素构成一个不完整的正交网格——若干条水平线段和垂直线段，每条线段上有 1~3 个缺口（缺口处为黑(0)）。有效水平线通过至少一对同行水平相邻的蓝(1)像素识别，有效垂直线通过至少一对同列垂直相邻的蓝(1)像素识别。整个网格线系统的边界框约 11x11。线段之间的间距为 3~5 像素。生成时保证：至少 2 条有效线各有 1 个缺口，至少 2 条有效线各有 2 个或以上缺口。

**规则**：
1. 识别有效水平线和有效垂直线（方法：某行在前景边界框范围内存在至少一对水平相邻蓝(1)像素则该行为有效水平线；某列存在至少一对垂直相邻蓝(1)像素则该列为有效垂直线）。
2. 在前景边界框范围内，将每条有效线上的缺口（黑(0)像素）补为红(2)。保留所有原有蓝(1)像素不变。
3. 统计每条有效线上的缺口总数 G（补红之前的黑像素数）。
4. 沿每条有效水平线，在其上方一行和下方一行（在前景边界框范围内）绘制 1 像素宽的描边线，从边界框左边界到右边界。描边颜色：若 G = 1 则为绿(3)，若 G >= 2 则为黄(4)。描边线不覆盖已有蓝(1)或红(2)像素（如有冲突则跳过该位置）。
5. 沿每条有效垂直线，在其左方一列和右方一列绘制 1 像素宽的描边线，从边界框上边界到下边界，颜色规则同上。描边线不覆盖已有蓝(1)、红(2)或先前绘制的描边像素。
6. 绘制顺序：先处理水平线（从上到下），再处理垂直线（从左到右）。

**关键洞察**：缺口数量不仅驱动了补全操作，还被计数后用于选择描边颜色——同一信息（缺口）在两个不同操作中各承担一个角色。仅看一个示例可能将描边颜色误归因于线段的方向或位置。

## 新题 10：自相似块扩展后按连通分量数确定缩放因子

**组合逻辑**：[计数](创新：连通分量数决定扩展比例) + [印章覆盖](已有：自相似扩展) + [像素到块映射](已有) + [连通分量](创新：从分析对象变为缩放参数) + [重涂色](创新：每个副本继承源像素所属分量的颜色)

**来源原语**：计数/连通分量(8698868d, 6e453dd6), 印章覆盖/像素到块映射/前景位放自身副本(5b6cbef5), 重涂色(1c0d0a4b)

**依赖链**：统计输入网格中前景连通分量的数量 N → N 决定块扩展的缩放因子（每个像素映射到 NxN 块）→ 每个前景像素位置放置输入网格的完整副本 → 副本中的前景像素颜色被替换为源像素所属连通分量的颜色 → 分量计数同时决定几何尺寸和颜色分配规则

统计前景连通分量数作为自相似扩展的缩放因子，每个前景像素位置放置整幅输入的副本，副本颜色继承源像素所属分量的颜色。

**输入结构**：约 5x5 的网格，背景为黑(0)。前景由 2~4 个不同颜色的连通分量组成（4 连通，每个分量 2~5 像素），颜色从蓝(1)、红(2)、绿(3)中选取，每个分量使用不同颜色。各分量互不接触（无相邻像素属于不同分量）。前景像素总数约 6~12 个。生成时保证连通分量数 N 与网格边长的关系使得输出网格 (N*inputH) x (N*inputW) 不超过 20x20。

**规则**：
1. 识别所有前景（非黑）连通分量（4 连通），记数量为 N。
2. 创建输出网格，尺寸为 (N * 输入行数) x (N * 输入列数)。
3. 将输入网格的每个像素映射到输出网格中的一个 NxN 块。
4. 对于输入中的每个背景像素，对应的 NxN 块全部填黑(0)。
5. 对于输入中的每个前景像素 P（颜色为 C_P，属于分量 K），对应的 NxN 块中放置整幅输入网格的缩小副本——但副本中所有前景像素统一涂为 C_P（P 所属分量的颜色），副本中的背景像素保持黑(0)。
6. 各块之间无重叠，也无间隔。

**关键洞察**：连通分量计数决定了输出的几何尺寸（缩放因子），而每个分量的颜色决定了对应副本的着色——数量和身份是同一组分量的两个不同属性，但分别服务于几何和颜色两个独立维度。改变分量数会同时改变输出大小和每像素块的内容。
