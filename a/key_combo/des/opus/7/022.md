## 新题 1：封闭区域计数驱动瓦片自增殖

**组合逻辑**：[洪泛填充](用于拓扑检测而非着色) + [计数](区域数→平铺维度) + [裁剪](标记区域→瓦片源) + [平铺](由计数结果参数化)

**来源原语**：洪泛填充(#19 00d62c1b), 计数(#4 a59b95c0), 裁剪(#11 995c5fa3), 平铺(#4 a59b95c0), 封闭区域(#19), 边界(#19), 拓扑内外(#19), 种子像素(#6 8a6d367c)

**依赖链**：洪泛填充的拓扑分析同时产出两个信息——区域总数 N 和各区域的形状；种子像素标记哪个区域被裁剪为瓦片源；N 控制瓦片的行列重复次数。删掉洪泛填充则无法得到 N 和区域划分；删掉裁剪则无瓦片可铺；删掉计数则不知铺多少次。

输入中有多个封闭区域，其中一个被种子标记；将标记区域裁剪为瓦片，按区域总数 N 在两个方向各平铺 N 次。

**输入结构**：约 12x12 的黑(0)背景网格。绿(3)像素构成 3~5 条互不相交的闭合边界曲线（每条曲线为 4-连通的环形像素链，围成一个封闭区域；各封闭区域面积在 4~12 像素之间，形状各异——非全为矩形，可包含不规则轮廓）。恰好一个封闭区域的内部含有一个红(2)种子像素。其余封闭区域内部为纯黑(0)。绿边界之间互不相邻（最小间距 >= 2 像素），保证拓扑分区无歧义。

**规则**：
1. 对网格做拓扑分析（等价于从网格外部对黑像素做洪泛填充），识别所有被绿(3)边界完全封闭的内部区域，记区域总数为 N。
2. 找到包含红(2)种子像素的那个封闭区域，取其最小包围盒（含绿边界像素），裁剪为一个小矩形瓦片 T。裁剪时红(2)种子像素替换为黑(0)（种子不出现在输出中）。
3. 输出一个 (N * T_h) x (N * T_w) 的网格（T_h、T_w 为瓦片 T 的高和宽），将 T 在行方向重复 N 次、列方向重复 N 次，紧密排列。
4. 输出仅包含平铺后的内容，不保留原始网格中的其他区域或背景。

**关键洞察**：封闭区域的数量和形状分别承担不同角色——数量控制平铺规模，被标记区域的形状决定瓦片内容。两者都来自同一次拓扑分析，但用途完全不同；需要对比多个示例才能区分"哪个区域做瓦片"与"有多少区域"这两条规则。

## 新题 2：重力堆叠高度编码列式平铺

**组合逻辑**：[重力下落](散落令牌→有序堆叠) + [计数](堆叠高度→逐列平铺次数) + [平铺](以列为单位、由高度参数化) + [擦除](消耗令牌和分隔行)

**来源原语**：重力下落(#16 2b83f449), 计数(#4 a59b95c0), 平铺(#4), 擦除(#5 917bccba), 令牌(#16), 分隔行(#3 dc46ea44), 碰撞停止(#16), 高度编码数量(#10 a1aa0c1e)

**依赖链**：令牌在重力下必须堆叠后才能得到各列高度；高度是平铺次数的唯一来源；铺什么取决于分隔行下方的图元。三个环节缺一则输出不确定。

散落在上方的令牌经重力下落堆叠于分隔行之上，各列堆叠高度决定底部图元在该列方向上平铺几次。

**输入结构**：约 10x12 的黑(0)背景网格。一条完整的灰(5)水平分隔行将网格分为上下两个面板。上方面板中散布若干蓝(1)单像素令牌，分布在不同行和列（每列 0~4 个令牌，不同列令牌数量不同）。下方面板包含一个小型彩色图元（高 2~3 行，宽与网格等宽），由红(2)和黄(4)像素构成非全矩形的图案。生成时保证：上方面板的列数与下方图元的宽度一致；每列至少有一个令牌。

**规则**：
1. 上方面板中所有蓝(1)令牌向下做重力下落，堆叠在灰(5)分隔行的正上方（同列多个令牌依次堆叠，最低的先落）。
2. 统计分隔行正上方每列的令牌堆叠高度 H_c（c 为列索引）。
3. 取下方面板的图元（高度 h 行、宽度 w 列）作为母版。对于第 c 列，将母版第 c 列的像素条（高 h 像素）在垂直方向重复 H_c 次，得到该列的输出条。
4. 输出网格宽度 = w，高度 = h * max(H_c)。对于堆叠高度不足 max(H_c) 的列，底部多余空间填充黑(0)。各列按列索引从左到右排列。
5. 分隔行、原始令牌位置、上方面板均不出现在输出中。

**关键洞察**：令牌的空间分布经过重力收敛后变成可计数的列高度，这些高度不是输出的一部分，而是控制另一个对象（底部图元）逐列拉伸倍率的编码信号。需要多个示例才能确认"堆叠高度 = 该列平铺次数"这一非显然映射。

## 新题 3：对称恢复隐藏字形解码为区域填充色

**组合逻辑**：[镜像/对称补全](恢复遮挡区的隐藏像素) → [解码](恢复的像素模式→颜色值) → [洪泛填充](用解码得到的颜色填充对应封闭区域)

**来源原语**：对称补全(#1 67b4a34d), 镜像(#9 de493100), 解码(#11 995c5fa3), 洪泛填充(#19 00d62c1b), 遮挡矩形(#9), 对称图案(#9), 字形图案(#11), 封闭区域(#19), 边界(#19), 双轴对称(#9), 位置映射(#11), 镜像恢复遮挡区(#9), 字形映射颜色行(#11→改为字形映射填充色), 仅填封闭内部(#19)

**依赖链**：遮挡矩形盖住了字形，必须先做对称恢复才能看到字形内容；字形的含义（映射到哪种颜色）必须解码才能确定填充色；封闭区域必须由洪泛填充识别后才能着色。三步之间有实质信息变换——第一步输出像素模式，第二步将模式转为语义（颜色），第三步将语义施加到空间结构。

双轴对称图案中被遮挡的区域隐藏着字形编码；恢复字形并解码为颜色后，将颜色填入网格另一侧的对应封闭区域。

**输入结构**：约 16x16 的黑(0)背景网格，逻辑上分为左右两半（无显式分隔线）。左半部分：一个由多色像素构成的图案，具有关于其自身中心的双轴（水平 + 垂直）镜像对称性，但其中有一个品红(6)实心矩形（约 4x6）遮挡了部分像素。被遮挡区域实际包含 2~3 个并排的 2x3 字形块（每个字形块内部是灰(5)底色加黑(0)挖空像素构成的图案）。品红色仅出现在遮挡矩形中。右半部分：绿(3)像素构成 2~3 条闭合边界，形成等数量的封闭区域，各区域从上到下排列且面积各异。生成约束：左侧字形数量 = 右侧封闭区域数量；左侧对称图案的非遮挡部分足以通过双轴镜像唯一恢复所有遮挡像素。

**规则**：
1. 在左半部分的双轴对称图案中，定位品红(6)实心矩形。对矩形内每个像素，利用水平镜像、垂直镜像或 180 度旋转镜像位置的已知像素值进行恢复（优先使用可见的镜像位置；若多个镜像位置均可见，取任一即可——对称性保证它们一致）。
2. 恢复后的区域显现出 2~3 个 2x3 字形块，每个字形块是灰(5)底上黑(0)挖空的二值图案。按照固定的字形→颜色映射表解码每个字形（该映射表需对比多个训练示例才能归纳；例如：字形 A → 红(2)，字形 B → 蓝(1)，字形 C → 黄(4)，字形 D → 橙(7)，共 4 种字形对应 4 种颜色）。
3. 将解码得到的颜色按字形从上到下（或从左到右）的顺序与右半部分从上到下的封闭区域一一对应。
4. 对每个封闭区域，将其内部（不含绿边界本身）的所有黑(0)像素洪泛填充为对应的解码颜色。
5. 输出为完整的 16x16 网格：左半部分恢复为完整的对称图案（品红矩形被恢复像素替代）；右半部分的封闭区域被填充为解码颜色。

**关键洞察**：遮挡矩形隐藏的不只是普通像素值，而是承载语义信息的字形符号。对称恢复是获得语义的前提，而非最终目标——恢复操作本身只是信息提取的手段，真正的变换在于字形→颜色的符号解码驱动空间填充。仅凭单个示例无法确定字形映射表。

## 新题 4：十字重定位创建象限分区并着色

**组合逻辑**：[平移对齐](十字→框中心) + [洪泛填充/区域划分](十字将框内部切为四象限) + [重涂色](角落像素的颜色→对应象限的填充色) + [擦除](角落引导像素消失)

**来源原语**：平移对齐(#5 917bccba), 洪泛填充(#19 00d62c1b), 重涂色(#2 d89b689b / #7 aabf363d), 擦除(#5 / #7), 十字图案(#5), 空心矩形(#5), 散落单像素(#2→角落引导像素), 角落对齐(#5), 象限对应(#2), 拓扑内外(#19), 角落色转移后消(#7), 象限决定目标格(#2→象限决定填充区)

**依赖链**：十字必须先移到框中心才能形成四象限分区；分区之后才知道哪些像素属于哪个象限；角落像素的位置决定它与哪个象限对应，颜色决定该象限的填充色；角落像素在颜色传递后消失。任一步骤缺失都导致输出不确定。

将偏移的十字移至矩形框中心，将框内部切割为四象限，再用四角引导像素的颜色分别填充对应象限。

**输入结构**：约 13x13 的黑(0)背景网格。一个灰(5)空心矩形框（外边长约 9~11，线宽 1 像素）。框内部有一个蓝(1)十字图案（一整行 + 一整列的蓝像素，行列交叉于框内部某个非中心位置；十字仅在框内部可见，不超出框）。框的四个外角（紧邻框角的对角方向各一个像素）各有一个不同颜色的引导像素：左上角为红(2)，右上角为绿(3)，左下角为黄(4)，右下角为橙(7)。生成约束：框的高度和宽度均为奇数（确保有唯一中心行和中心列）；十字初始位置不在框中心。

**规则**：
1. 将蓝(1)十字图案平移，使其交叉点对齐到灰(5)矩形框内部的几何中心（中心行和中心列的交叉位置）。移动后十字仍仅在框内部可见。
2. 移动后的十字将框内部划分为四个矩形象限：左上、右上、左下、右下。
3. 读取四个角落引导像素的颜色，按其相对于框的象限位置与框内四个象限一一对应：左上引导像素的颜色填充左上象限，以此类推。
4. 将每个象限内的所有黑(0)像素重涂为对应的引导颜色。十字像素保持蓝(1)，框像素保持灰(5)。
5. 擦除四个角落引导像素（变为黑(0)）。

**关键洞察**：十字的作用不止是移动——它在新位置创造了拓扑分区结构，而这个结构是后续象限着色的前提。十字是"可移动的分割线"，角落像素是"可消耗的颜色指令"，两者协同才能确定输出。

## 新题 5：虚线补全后线段长度排序精灵体

**组合逻辑**：[填充/间隙补全](虚线→实线) → [计数](实线长度) → [排序](按长度重排精灵体) + [擦除](线段和间隙在输出中消失)

**来源原语**：填充(#12 a699fb00), 排序(#10 a1aa0c1e / #11 995c5fa3), 计数(#4 a59b95c0), 擦除(#5 917bccba), 虚线段(#12), 精灵体(#3 dc46ea44 / #20 36d67576), 邻接(#12), 单像素间隙补填(#12), 距离优先排序(#13 b5ca7ac4→改为长度排序), 行列对齐(#14 99fa7670)

**依赖链**：虚线必须先补全才能测量完整长度；长度是精灵体排序的唯一依据；精灵体与线段的空间关联（"哪个精灵体属于哪条线"）来自行列对齐。三层信息变换不可跳过。

水平虚线补全后各线段长度决定了其下方精灵体的排列顺序，精灵体按对应线段长度从短到长重排为一行。

**输入结构**：约 14x14 的黑(0)背景网格。上半区域（行 0~5）有 3~4 条水平蓝(1)虚线段，分布在不同行，每条虚线段由蓝(1)像素和单像素黑(0)间隙交替组成（间隙宽度恒为 1）。各虚线段长度不同（补全后总长在 4~12 像素之间）。下半区域（行 7~12）有等数量的小型单色精灵体（每个精灵体 3~6 像素，4-连通，颜色各不相同，分别为红(2)、绿(3)、黄(4)、橙(7)等），每个精灵体的水平中心与正上方某条虚线段的水平中心对齐（一一对应，无歧义）。各精灵体之间互不相邻。生成约束：各虚线段补全后长度互不相等；每个精灵体恰好对齐一条虚线段。

**规则**：
1. 对上半区域的每条蓝(1)虚线段，将所有满足"左右邻居均为蓝(1)"的黑(0)间隙像素填充为红(2)，完成虚线到实线的补全。
2. 测量每条补全后线段的总长度 L（蓝像素数 + 红像素数）。
3. 按水平中心对齐关系，将每个精灵体关联到其对应的线段，继承该线段的长度 L 作为排序键。
4. 将所有精灵体按 L 从小到大排序。
5. 输出一个单行（或最小高度容纳所有精灵体的）网格：排序后的精灵体从左到右依次放置，相邻精灵体之间间隔 1 列黑(0)像素。每个精灵体保持原始形状和颜色。
6. 虚线段、间隙填充、上半区域均不出现在输出中。

**关键洞察**：虚线间隙不是噪声——补全后的线段长度是隐含的排序键。精灵体本身不携带排序信息，它们的顺序完全由空间关联的线段长度决定。需要多个示例才能归纳出"长度排序"而非"位置排序"或"颜色排序"。

## 新题 6：边框颜色决定移动方向后对称轴类型决定内部恢复

**组合逻辑**：[平移](边框方块→网格边缘，颜色决定方向) + [对称补全](到达边缘后按方向关联的对称轴恢复内部遮挡) + [擦除](原位置清除)

**来源原语**：平移(#13 b5ca7ac4), 对称补全(#1 67b4a34d), 重涂色(#1), 边框方块(#13), 实心标记矩形(#1→缩小为标记像素), 颜色决定目标(#13), 双轴镜像对称(#1→退化为单轴), 行重叠内移(#13), 距离优先排序(#13), 遮挡由镜像恢复(#1), 镜像恢复遮挡区(#9 de493100)

**依赖链**：边框颜色决定移动方向（左/右）→ 移动方向决定采用哪种对称轴（垂直/水平）→ 对称轴决定如何恢复内部被遮挡的像素。三者形成不可跳步的因果链。

带颜色边框的方块移到对应边缘后，移动方向隐含地指定了内部图案的对称类型，据此恢复被标记像素遮挡的内容。

**输入结构**：约 18x18 的灰(5)背景网格。散布 3~5 个 5x5 方块，每个方块由 1 像素宽的边框和 3x3 内部区域组成。边框颜色为青(8)或红(2)。每个方块的 3x3 内部包含一个多色图案（使用蓝(1)、绿(3)、黄(4)、橙(7)中的 2~3 种颜色），该图案具有特定的镜像对称性，但其中恰好 1 个像素被品红(6)标记像素遮挡（品红仅出现在遮挡位置）。青(8)边框方块的内部图案关于垂直中轴具有镜像对称性；红(2)边框方块的内部图案关于水平中轴具有镜像对称性。各方块互不相邻（最小间距 >= 2 像素）。生成约束：行方向可能存在重叠的同色方块，处理顺序为离目标边缘近的先处理；行重叠时后到的方块向内偏移一个方块宽度（5 像素）。

**规则**：
1. 青(8)边框方块整体平移到网格左边缘（列 0 起），保持原始行位置。红(2)边框方块整体平移到网格右边缘（列 W-5 起），保持原始行位置。离目标边缘更近的方块优先放置；若同色方块的行范围重叠，后处理的方块向内偏移 5 列。
2. 清除所有方块的原始位置为背景灰(5)。
3. 对每个已移动到位的方块，检查其 3x3 内部中被品红(6)遮挡的像素：
   - 若该方块为青(8)边框（已移至左边缘）：利用内部图案的垂直镜像对称性，从品红像素关于垂直中轴的镜像位置复制颜色值，替换品红像素。
   - 若该方块为红(2)边框（已移至右边缘）：利用内部图案的水平镜像对称性，从品红像素关于水平中轴的镜像位置复制颜色值，替换品红像素。
4. 输出为完整的 18x18 网格：方块在新位置，内部图案已恢复完整，原位置为灰(5)背景。

**关键洞察**：移动目的地不仅是空间重排——它隐含编码了对称轴类型。同样的遮挡恢复操作因方块落在不同边缘而采用不同的镜像方向，这种"位置→对称类型"的映射是需要对比多个示例才能归纳的隐蔽规则。

## 新题 7：梳状结构高度参数化射线延伸距离

**组合逻辑**：[计数](梳状结构→射线长度参数) + [射线延伸](受限距离，非到边) + [连线](端点处转折) + [擦除](梳状结构消耗后消失)

**来源原语**：计数(#10 a1aa0c1e), 射线延伸(#14 99fa7670), 连线(#14→转折路径), 擦除(#5 917bccba), 梳状结构(#10), 色条(#10→退化为标记像素), 孤立像素(#14), 画布边界(#14 / #18 7ddcd7ec), 高度编码数量(#10), 行列对齐(#14), 转折至下一标记行(#14)

**依赖链**：梳状结构的固有高度必须先计数才能得到射线长度参数 N；射线从标记像素出发延伸 N 格后转折；梳状结构在输出中被擦除，因为它已完成编码任务。删除任一环节输出不确定。

每个标记像素有对应颜色的梳状结构，梳的实心行数 N 决定了该标记射线向右延伸 N 格后转折向下的距离。

**输入结构**：约 15x15 的黑(0)背景网格。左侧区域（列 0~2）有 3~4 个不同颜色的单像素标记，分布在不同行，颜色分别为红(2)、蓝(1)、绿(3)、黄(4)等。右侧区域（列 10~14）有与标记数量相等的三列宽梳状结构，每个梳状结构的颜色与一个标记像素匹配。梳状结构由交替的"三像素实心行"和"两侧像素行（中间空）"组成，实心行数量 N 在 1~5 之间变化（不同梳的 N 不同）。各梳状结构从不同行开始，互不重叠。生成约束：各标记像素的行位置互不相同；射线在延伸和转折过程中不会与其他射线或梳状结构冲突。

**规则**：
1. 对每个标记像素，找到颜色匹配的梳状结构，计数其实心行数量 N。
2. 从标记像素位置向右延伸 N 个像素的水平射线（含标记像素本身则总长 N+1；不含则为 N 格新像素），使用标记像素的颜色绘制。若射线在到达 N 格之前碰到网格右边界，则在边界处停止。
3. 在射线的右端点处转折向下，继续延伸 N 个像素的垂直射线（同色）。若垂直射线在到达 N 格之前碰到网格底边界，则在底边界处停止。
4. 擦除所有梳状结构（将其占据的像素恢复为黑(0)），标记像素保留（作为射线起点）。
5. 多条射线的绘制顺序为标记像素从上到下；若两条射线的路径存在像素重叠，后绘制的颜色覆盖先绘制的。

**关键洞察**：梳状结构不是输出的一部分，而是可读取的"参数存储器"——每个梳的垂直复杂度编码了一个数值，该数值限定了完全不同区域中射线的空间延伸范围。梳与射线通过颜色匹配关联，通过数值控制耦合。

## 新题 8：种子选模板后按封闭区域形状裁切平铺

**组合逻辑**：[洪泛填充](识别封闭区域) + [种子选择](种子颜色→模板匹配) + [平铺](模板在包围盒内重复) + [裁剪](按边界形状裁切多余平铺)

**来源原语**：洪泛填充(#19 00d62c1b), 平铺(#4 a59b95c0), 裁剪(#1 67b4a34d / #11 995c5fa3), 种子像素(#6 8a6d367c), 模板(#6), 封闭区域(#19), 边界(#19), 拓扑内外(#19), 框内匹配(#6→扩展为区域内匹配), 种子选择模板(#6), 仅填封闭内部(#19)

**依赖链**：洪泛填充识别出区域和边界→区域内的种子像素决定选用哪个模板→模板在区域包围盒内平铺→平铺结果被区域边界裁切。每个区域独立执行此流程，且不同区域可能选择不同模板。

多个封闭区域各含一个种子像素，种子颜色选定对应模板，模板被平铺填满区域，超出边界的部分被裁切。

**输入结构**：约 16x16 的黑(0)背景网格。顶部两行是"模板展示区"，包含 3 个并排的小模板（每个 2x2 或 2x3），以 2 列黑(0)间隔分开。每个模板使用一种底色（如红(2)、蓝(1)、橙(7)）加黑(0)组成二值图案。顶部模板区下方（行 3 起）是"区域区"：绿(3)像素构成 3 条互不相交的闭合边界曲线，形成 3 个封闭区域，面积各异（约 8~25 像素），形状不规则（非矩形）。每个封闭区域内部恰好有一个种子像素，其颜色与某个模板的底色相同。三个种子分别匹配三个不同的模板。生成约束：每个封闭区域的包围盒尺寸是其对应模板尺寸的整数倍（宽和高分别独立为整数倍）。

**规则**：
1. 识别绿(3)边界围成的所有封闭区域。
2. 对每个封闭区域，读取其内部种子像素的颜色 C。
3. 在顶部模板区中找到底色为 C 的模板 T。
4. 计算该封闭区域的最小包围盒，将模板 T 在包围盒内做行列方向的密铺（平铺直到完全覆盖包围盒）。
5. 对平铺结果进行裁切：仅保留位于封闭区域内部（被绿边界包围的黑像素位置）的平铺像素，封闭区域外部的平铺像素丢弃。种子像素位置也被平铺像素覆盖。
6. 输出为完整的 16x16 网格：顶部模板区保留不变，绿边界保留不变，每个封闭区域内部被裁切后的平铺图案填满。

**关键洞察**：每个封闭区域是独立的"画布"，其形状不规则，平铺必须适配不规则轮廓（而非填满矩形框）。种子像素是三路分发器——同一个网格中三个区域可能出现三种完全不同的平铺图案，而选择逻辑隐含在颜色匹配中。

## 新题 9：闸门旋转改变管道拓扑后洪泛填充新封闭区域

**组合逻辑**：[旋转](闸门 90 度旋转改变通路) + [洪泛填充](检测旋转后的新拓扑) + [重涂色](新封闭区域上色、旧封闭区域清色) — 三操作通过拓扑状态的前后对比耦合

**来源原语**：旋转(#16 2b83f449 / #20 36d67576), 洪泛填充(#19 00d62c1b), 重涂色(#2 d89b689b / #7 aabf363d), 闸门(#16), 管道网络(#16), 封闭区域(#19), 边界(#19), 拓扑内外(#19), 碰撞停止(#16→改为拓扑变化), 仅填封闭内部(#19)

**依赖链**：闸门旋转是拓扑操作——水平闸门变为垂直后，原本连通的通路可能被截断形成新封闭区域，原本封闭的区域可能被打开变为连通。填充操作必须在旋转后的拓扑上执行，且"新封闭 vs 旧封闭"的区分需要隐式的拓扑比较。

闸门从水平旋转为垂直后，管道网络的拓扑发生变化；仅对旋转后新形成的封闭区域进行填充。

**输入结构**：约 12x14 的网格。黑(0)像素构成管道壁（占据固定位置，形成迷宫状网络）。灰(5)像素为管道内部的通路空间。红(2)水平条（1x3 大小，1 行 3 列）为闸门，嵌在管道壁的间隙中（左右两端紧邻黑(0)壁，上下为灰(5)通路），共 2~4 个闸门。部分通路区域在当前（闸门未旋转）状态下已经形成了封闭区域（四周被壁包围），这些区域预填充了蓝(1)色。其余通路区域连通到网格边缘（非封闭），为灰(5)。生成约束：每个闸门的中心像素位置固定，旋转后变为 3x1（3 行 1 列）的垂直条，且旋转后的垂直条不与其他壁像素冲突；至少一个闸门旋转后会封闭新区域，至少一个闸门旋转后会打开已有封闭区域。

**规则**：
1. 将每个红(2) 1x3 水平闸门旋转 90 度为 3x1 垂直条：闸门中心像素位置不变，原水平闸门的三个像素位置变为灰(5)通路，新垂直闸门的三个像素位置（中心 + 上一行 + 下一行）变为红(2)壁。
2. 在旋转后的网格上做拓扑分析：从网格边缘对所有灰(5)像素做洪泛扩散，标记所有与边缘连通的灰色区域为"外部"。
3. 未被标记的灰(5)区域为旋转后的封闭区域。
4. 对比旋转前后的封闭状态：
   - 旋转前非封闭、旋转后封闭的区域（新封闭）→ 填充为黄(4)。
   - 旋转前封闭（已有蓝(1)填充）、旋转后仍封闭的区域 → 保持蓝(1)不变。
   - 旋转前封闭（蓝(1)）、旋转后非封闭的区域（被打开）→ 清除蓝(1)，恢复为灰(5)。
5. 管道壁黑(0)和旋转后的红(2)闸门保持不变。

**关键洞察**：闸门是拓扑开关而非障碍物——旋转操作同时创造和摧毁封闭区域，填充规则取决于旋转前后的拓扑差异而非绝对状态。"新封闭涂黄、旧封闭开放则清色"这一差分规则需要对比多个示例才能归纳。

## 新题 10：骨架对齐传递标注后标注像素发射对角射线

**组合逻辑**：[旋转/镜像 + 印章](骨架对齐→标注传递) → [射线延伸](传递后的标注像素→对角射线源) + [擦除](骨架和锚点消失，仅留射线)

**来源原语**：旋转(#20 36d67576), 镜像(#20), 印章覆盖(#20 / #15 d6542281), 射线延伸(#18 7ddcd7ec), 擦除(#5 917bccba), 精灵体(#20), 锚点像素(#20), 对角标记(#18), 实心正方形(#18→退化为锚点), 骨架对齐(#20), 对角邻接(#18), 完整标注传递副本(#20), 锚角对角射线至边(#18)

**依赖链**：骨架对齐确定每个副本的旋转/镜像变换→变换决定标注像素在副本上的具体位置→标注像素相对于锚点的对角方向决定射线方向→不同副本的旋转使同一标注产生不同方向的射线。删除骨架对齐则标注位置不确定；删除射线延伸则标注只是颜色标记无后续效果。

完整骨架的标注通过旋转/镜像传递到各副本后，每个标注像素从其位置向远离锚点的对角方向发射射线至网格边缘。

**输入结构**：约 16x16 的黑(0)背景网格。散布 4 个灰(5)骨架图形（每个骨架为 4~7 像素的 8-连通单色图形，形状相同但可能经过 0/90/180/270 度旋转或水平/垂直翻转），每个骨架含恰好一个蓝(1)锚点像素（位于骨架的某个端部或拐角处，是骨架的一部分）。其中恰好一个骨架额外包含 1~2 个标注像素（颜色为红(2)或绿(3)），每个标注像素位于锚点像素的某个对角方向的相邻位置（即标注像素与锚点在对角方向上 8-连通相邻）。标注像素不属于骨架（不是灰色），是额外附着的。其余 3 个骨架仅有灰(5)骨架 + 蓝(1)锚点，无标注。生成约束：各骨架互不重叠、互不相邻（间距 >= 3 像素）；各骨架可通过唯一的旋转/镜像变换相互映射。

**规则**：
1. 以含标注的骨架为源模板。对每个无标注的目标骨架，求出将源骨架的灰(5)像素集合和蓝(1)锚点映射到目标骨架的灰(5)像素集合和蓝(1)锚点的唯一二面体变换（旋转 + 可选镜像 + 平移）。
2. 将源模板上每个标注像素的相对位置（相对于锚点的行列偏移）通过该二面体变换映射到目标骨架的锚点，在目标位置绘制相同颜色的标注像素。
3. 现在每个骨架（含源模板）都有标注像素。对每个标注像素：确定它相对于其所属骨架锚点的对角方向（左上、右上、左下、右下之一）。从该标注像素出发，沿该对角方向持续延伸射线（每步行 +/-1、列 +/-1），绘制标注像素的颜色，直到射线离开网格边界。射线起始于标注像素的下一个对角位置（标注像素本身不重绘）。
4. 擦除所有灰(5)骨架像素和蓝(1)锚点像素（变为黑(0)）。标注像素本身也擦除。仅保留对角射线。
5. 若多条射线经过同一像素，后绘制的覆盖先绘制的（绘制顺序：骨架按锚点位置从左上到右下处理；同一骨架内多个标注按行优先序处理）。

**关键洞察**：骨架-标注传递系统不是为了视觉补全——传递后的标注像素是射线发射器的安装位置，而每个骨架的旋转状态决定了射线的发射方向。同一个标注模式在四个不同朝向的骨架上产生四组不同方向的对角射线，形成辐射状的几何图案。骨架是"方向编码载体"，用完即弃。
