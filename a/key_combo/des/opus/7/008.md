## 新题 1：对角连线阻断间隙对分填充

**组合逻辑**：[连线/connect + 对角偏移/diagonal_offset](已有) + [射线延伸式间隙对半分/gap_bisect](已有) + [射线遇障停止/ray_stops_at_block](创新：对角连线充当障碍阻断另一组对的间隙填充)

**来源原语**：连线(connect, 342ae2ed), 对角偏移(diagonal_offset, 342ae2ed), 同色矩形对(same_color_rect_pair, 342ae2ed), 对角线段(diagonal_segment, 342ae2ed), 间隙对半分(gap_bisect, d968ffd4), 射线延伸(ray_extend, d968ffd4), 奇数间隙留中线(odd_gap_midline, d968ffd4), 射线遇障停止(ray_stops_at_block, 6ffe8f07)

**依赖链**：首先根据每对同色矩形的空间关系将其分为"轴对齐对"与"对角偏移对"两类；对角偏移对执行对角连线绘制，轴对齐对执行间隙对半填充；但对角连线一旦绘制完成即充当墙壁，截断穿过它的间隙填充射线——连线结果决定了填充的边界，两类操作在空间上交叉耦合。

将同色矩形对按轴对齐/对角偏移分类后，对角对画对角连线，轴对齐对做间隙对分填充，但对角连线充当墙壁截断穿越它的间隙填充。

**输入结构**：约 15x15 的网格，黑(0)背景。包含 3-4 种前景色，每种颜色恰好出现两个分离的实心小矩形（宽、高各 2-3 像素）。部分同色矩形对共享相同的行跨度或列跨度（即轴对齐），其余同色矩形对的面对角位于一条 45 度对角线上（即对角偏移）。所有矩形互不接触、互不重叠。生成约束：对角连线路径互不交叉；至多一条对角连线穿过某个轴对齐对的间隙区域。

**规则**：
1. 对每种前景色，判断其两个矩形是"轴对齐"（共享行跨度或列跨度）还是"对角偏移"（面对角在 45 度线上）。
2. 对角偏移对：在两个矩形最近面对角之间绘制该色的一像素宽对角线段，排除已属于矩形的两个端点像素。
3. 轴对齐对：沿两个矩形之间的间隙，在整个垂直跨度上进行对分填充。间隙中每个像素取距其更近的那个矩形的颜色；若间隙长度为奇数，正中行/列保持背景色。
4. 间隙填充以逐像素射线方式从各自矩形向间隙中央推进。若射线遇到步骤 2 中已绘制的对角连线像素，则该射线立即停止（不覆盖对角连线像素，也不绘制其后方的像素）。
5. 处理顺序：先绘制所有对角连线，再执行所有间隙对分填充。
6. 对角连线始终保持可见，不被间隙填充覆盖。

**关键洞察**：求解者必须先将同色矩形对分为两类并分别执行不同操作，再处理两类操作结果在空间上的交互——某种颜色的对角连线可以截断另一种颜色的间隙填充，导致两半填充区域不等长。

## 新题 2：空心框内面积奇偶选择旋转印章

**组合逻辑**：[计数/counting](已有) + [面积奇偶定填充色/parity_sets_fill](创新：奇偶不决定填充色而决定模板选择和旋转) → [印章覆盖/stamp](已有) + [旋转/rotate](创新：旋转 90 度作为奇偶分支的变体操作) + [裁剪/crop](已有：精灵超出框时裁剪)

**来源原语**：印章覆盖(stamp, 363442ee), 精灵体(sprite, 363442ee), 分隔列(divider_column, 363442ee), 槽位(slot, 363442ee), 空心矩形(hollow_rect, 868de0fa), 面积奇偶定填充色(parity_sets_fill, 868de0fa), 计数(counting, 08ed6ac7/868de0fa), 旋转(rotate, 412b6263), 裁剪(crop, 963e52fc)

**依赖链**：空心矩形框的内部面积决定奇偶性；奇偶性选择使用哪个精灵模板以及是否旋转；选中的模板（或其旋转版本）被印章到框内部，若超出内部尺寸则裁剪。面积计算→奇偶判断→模板选择/旋转→印章/裁剪形成紧耦合链，每一步的输出改变下一步的行为。

对每个空心矩形框，根据其内部面积奇偶性选取不同精灵模板（偶取原版、奇取旋转版），印章到框内并按框尺寸裁剪。

**输入结构**：约 18x20 的网格，黑(0)背景。一条灰(5)竖直分隔列将网格分为左右两部分。左侧面板上下排列两个精灵模板：上方模板由红(2)像素构成，下方模板由绿(3)像素构成，两者均为 4-连通、4-8 像素的非矩形单色图形，且互不相同。右侧面板包含 4-5 个蓝(1)空心矩形框，框壁为一像素厚，内部为黑(0)，各框内部尺寸不同（宽、高各为 3-7 像素）。框之间互不接触、互不重叠。生成约束：至少一个框内部面积为偶数、至少一个为奇数；每个模板的旋转版本的边界框不超过 7x7。

**规则**：
1. 计算每个蓝(1)空心矩形框的内部面积（内部宽 x 内部高）。
2. 若内部面积为偶数：将上方红(2)精灵模板保持原始朝向，以左上角对齐印章到该框内部左上角。
3. 若内部面积为奇数：将下方绿(3)精灵模板顺时针旋转 90 度后，以左上角对齐印章到该框内部左上角。
4. 若印章后的精灵（含旋转版本）在水平或垂直方向超出框的内部边界，超出部分被裁剪不绘制，仅保留落在内部区域内的像素。
5. 蓝(1)框壁、灰(5)分隔列、左侧原始精灵模板以及所有背景像素保持不变。

**关键洞察**：内部面积奇偶不是直接决定填充颜色（如参考题 868de0fa），而是同时决定"使用哪个模板"和"是否旋转"两件事；旋转改变了模板的边界框比例，使得同一模板在不同尺寸框中的可见部分不同——裁剪结果与奇偶判断、模板形态、框尺寸三者紧密关联。

## 新题 3：周期性与轴对称联合约束恢复标记空洞

**组合逻辑**：[平铺/tile + 周期/period](已有) + [对称补全/symmetry_completion + 双轴镜像/biaxial_mirror](创新：对称仅用于补充周期性无法恢复的位置，两种约束同时作用于同一数据) + [标记色空洞/marker_color_hole](已有)

**来源原语**：平铺(tile, 963e52fc), 周期(period, 963e52fc), 对称补全(symmetry_completion, b8825c91), 双轴镜像(biaxial_mirror, b8825c91), 标记色空洞(marker_color_hole, b8825c91), 标记处填入轨道色(fill_marker_with_orbit_color, b8825c91)

**依赖链**：周期性约束从非标记像素推断水平重复单元，为大部分标记像素恢复颜色；但某些列位置的所有周期副本均被标记遮蔽，周期性无法单独确定——此时调用重复单元内的垂直镜像对称补全剩余位置。两种约束在数据层面互补而非流水线串联：周期性覆盖空间维度，对称性覆盖单元内结构维度，缺任何一种都无法完全恢复所有空洞。

通过水平周期性和周期单元内部的垂直镜像对称两种约束联合确定所有标记空洞的颜色，任一约束单独使用均不充分。

**输入结构**：约 10x18 的网格（高度 10 行，宽度 18 列），使用 3-4 种非背景色（从蓝(1)、红(2)、绿(3)、灰(5)中选取）在黑(0)背景上形成水平重复图案。水平周期 P 为 4-6 列。每个周期单元（P 列宽、10 行高的子网格）内的图案具有垂直镜像对称（第 1 列与第 P 列镜像、第 2 列与第 P-1 列镜像，依此类推）。部分像素被替换为黄(4)标记色。标记放置满足：至少一个周期单元内的列位置，其所有周期副本均为黄(4)标记——因此仅用周期性无法恢复该位置。但该位置在周期单元中的镜像伙伴位置至少有一个非标记副本可用。生成约束：非标记像素足以唯一确定完整周期单元。

**规则**：
1. 识别标记色：黄(4)是唯一的颜色，使得去除它后剩余像素与某个水平周期一致。
2. 从非标记像素推断最短水平周期 P。
3. 对于周期单元中的每个列位置 c（c = 1, 2, ..., P）：收集该列位置在所有周期副本中的非标记像素值。若至少有一个非标记值存在，则该值即为列位置 c 的真实颜色——用它替换该列位置所有周期副本中的标记像素。
4. 若某列位置 c 在所有周期副本中全部是标记：利用周期单元的垂直镜像对称，找到其镜像伙伴位置 c'（c' = P + 1 - c）。该伙伴位置必定在步骤 3 中已被确定颜色。用伙伴位置的颜色值逐行填入位置 c 的所有标记像素。
5. 输出中不保留任何黄(4)像素，所有标记均被替换为推断出的颜色。

**关键洞察**：周期性和对称性不是先后执行的两步操作，而是对同一组空洞的两种互补恢复手段。求解者必须意识到某些列"全被遮蔽"的异常情况，并从周期性切换到对称性来恢复——仅凭一个示例无法确定对称约束的存在，必须对比多个示例才能发现这一隐蔽规则。

## 新题 4：连通分量大小排名编码同心方环调色板

**组合逻辑**：[计数/counting + 排序/sorting](已有) + [同心方环/concentric_ring + 距离映射/distance_mapping + 切比雪夫距离/chebyshev_distance](已有) + [重涂色/recolor](创新：排名到颜色的映射不是预定义调色板，而是由散布在输入中的连通分量的颜色按大小排名提供)

**来源原语**：计数(counting, 08ed6ac7), 排序(sorting, 08ed6ac7), 连通分量(connected_component, 08ed6ac7), 重涂色(recolor, 08ed6ac7), 同心方环(concentric_ring, ac0c2ac3), 距离映射(distance_mapping, ac0c2ac3), 切比雪夫距离(chebyshev_distance, ac0c2ac3), 中心对齐(center_aligned, ac0c2ac3)

**依赖链**：散布的连通分量通过计数→排序建立一个颜色序列（大小排名→颜色）；网格中心标记定义同心方环的几何结构；方环 d 的颜色取自排名为 d 的连通分量。分量的大小提供抽象的"调色板索引"，方环的距离提供"调色板查询键"——两者通过排名值耦合，缺任一侧都无法确定最终颜色。

散布的连通分量按像素数排名生成颜色序列，该序列作为调色板，为以网格中心为圆心的同心方环着色。

**输入结构**：11x11 或 13x13 的奇数正方形网格，灰(5)背景。网格正中心一个像素为红(2)，标记方环圆心。网格中散布 K 个小型 4-连通单色连通分量（K = (网格边长 - 1) / 2，即 11x11 时 K=5），每个分量使用不同颜色（从蓝(1)、绿(3)、黄(4)、橙(7)、品红(6)中选取），且每个分量的像素数各不相同（例如分别为 1、2、3、4、5 个像素）。分量的位置随机散布，与中心标记不重叠。生成约束：K 种分量颜色互不相同且与红(2)、灰(5)不同。

**规则**：
1. 识别所有非红(2)、非灰(5)的 4-连通单色连通分量。
2. 计算每个分量的像素数。
3. 按像素数升序排列，得到排名序列：排名 1 = 最少像素的分量颜色, 排名 2 = 次少, ..., 排名 K = 最多。
4. 输出网格中，以中心像素为圆心绘制同心方环：切比雪夫距离为 d（d = 1, 2, ..., K）的所有像素取排名 d 对应的分量颜色。
5. 中心像素（d = 0）保持红(2)。
6. 输入中的所有原始连通分量及灰(5)背景均被方环覆盖，不保留。

**关键洞察**：连通分量的物理位置完全无关，仅其像素数（大小）参与排名；排名建立了颜色到环层的映射。求解者需要对比多个示例才能排除基于位置的映射假说，确认是大小排名。

## 新题 5：不规则分区上的拉丁方洪泛填充

**组合逻辑**：[洪泛填充/flood_fill + 封闭区域/enclosed_region](已有) + [补全/completion + 拉丁方约束/latin_square_constraint + 行列唯一约束/row_column_uniqueness_constraint](创新：拉丁方约束从像素级提升到不规则区域级，区域的行列归属需先解析空间分区)

**来源原语**：洪泛填充(flood_fill, 7447852a/868de0fa), 封闭区域(enclosed_region, 7447852a/868de0fa), 补全(completion, 4cd1b7b2), 拉丁方约束(latin_square_constraint, 4cd1b7b2), 行列唯一约束(row_column_uniqueness_constraint, 4cd1b7b2), 分隔线(divider_line, 7447852a), 空白单元(blank_cell, 4cd1b7b2)

**依赖链**：绿色分隔线将网格分割为 4x4 的不规则矩形区域——区域大小不一，求解者须先正确解析分区拓扑；已填色区域满足部分拉丁方约束，空白区域的颜色由行列唯一性唯一确定；确定颜色后对空白区域执行洪泛填充。空间解析→约束推理→填充三者紧耦合：错误的分区解析导致约束矛盾，缺少约束推理则无法确定颜色，缺少洪泛填充则无法将颜色应用到不规则形状的区域。

解析不规则矩形分区的拓扑，利用拉丁方行列唯一约束推断空白区域颜色，洪泛填充空白区域。

**输入结构**：约 13x13 的网格，黑(0)背景。绿(3)一像素粗线条构成水平和垂直的分隔线网络，将网格内部划分为 4x4 共 16 个矩形区域。分隔线不等距——区域宽度和高度各不相同（每个区域内部宽 2-4 像素、高 2-4 像素）。16 个区域中，8-10 个已被洪泛填充为某种颜色（从蓝(1)、红(2)、黄(4)、灰(5)中选取），其余区域内部为黑(0)（空白）。已填色区域满足拉丁方约束：在 4x4 区域网格中，每一区域行（4 个区域）和每一区域列（4 个区域）内，同一颜色至多出现一次。生成约束：已填色区域足以唯一确定所有空白区域的颜色。

**规则**：
1. 识别绿(3)分隔线网络，确定 4x4 区域网格的拓扑：哪些像素属于哪个区域，以及每个区域在 4x4 网格中的行号和列号。
2. 收集已填色区域的颜色及其在 4x4 网格中的位置。
3. 对每个黑(0)空白区域，利用拉丁方约束（该行和该列中已有颜色不可重复）确定其唯一颜色。若某个空白区域无法立即确定（多个颜色均可），则先确定可唯一确定的区域，再回来利用更新后的约束推断剩余区域，直到全部确定。
4. 将每个空白区域的所有内部像素洪泛填充为步骤 3 确定的颜色。
5. 绿(3)分隔线和已有填色区域保持不变。

**关键洞察**：与参考题 4cd1b7b2 中逐像素的拉丁方补全不同，这里拉丁方约束作用在不规则大小的空间区域上——求解者必须先正确解析分隔线结构以确定每个区域的行列归属，然后才能应用组合约束。分区解析本身就是推理的一部分，不是预处理。

## 新题 6：空心矩形框遮挡四向镜像补全

**组合逻辑**：[对称补全/symmetry_completion + 双轴镜像/biaxial_mirror + 标记方块/marker_square](已有) + [空心矩形/hollow_rect](创新：空心矩形框充当遮罩，阻止反射像素在框区域内生成) + [射线遇障停止/ray_stops_at_block](创新：障碍概念从射线推广到反射像素的放置判定)

## 新题 7：控制像素延伸种子激活分区洪泛填充

**组合逻辑**：[延伸/extend + 边缘条/edge_bar + 控制像素/control_pixel + 朝近端扩展/toward_nearer_expand](已有) → [洪泛填充/flood_fill + 封闭区域/enclosed_region + 分区/partition](创新：延伸像素不再是终态，而是作为种子决定其所在分区的洪泛填充颜色) + [冲突解决](创新：同一区域收到两种颜色种子时产生第三种颜色)

**来源原语**：延伸(extend, 642248e4), 边缘条(edge_bar, 642248e4), 控制像素(control_pixel, 642248e4), 朝近端扩展(toward_nearer_expand, 642248e4), 标记在两边之间(marker_between_edges, 642248e4), 洪泛填充(flood_fill, 7447852a), 封闭区域(enclosed_region, 7447852a/868de0fa), 分隔线(divider_line, 7447852a), 区域排列顺序(region_order, 7447852a)

**依赖链**：控制像素到边缘条的距离比较决定延伸方向和颜色（近蓝用蓝，近红用红）；绿色分隔线将两条边缘条之间的空间分割为若干封闭区域；延伸像素落入特定区域后，充当该区域的"激活种子"，决定洪泛填充色。若同一区域中既有朝蓝延伸的种子又有朝红延伸的种子，则冲突解决为第三种颜色。延伸方向→种子颜色→区域归属→填充色/冲突解决，每一步依赖前一步且无法跳过。

控制像素按距边缘条远近延伸一像素，延伸像素的颜色继承近端边缘条颜色，延伸像素作为种子激活其所在分区的洪泛填充，同区域双色冲突时变为第三色。

**输入结构**：约 14x14 的网格，黑(0)背景。顶行为蓝(1)满行（边缘条），底行为红(2)满行（边缘条）。两条边缘条之间散布 4-6 个灰(5)控制像素。一条绿(3)一像素粗折线（由水平和垂直线段组成，端点触及左右网格边缘或两条边缘条）将两条边缘条之间的黑(0)区域分割为 4-6 个封闭的矩形或近似矩形区域。控制像素位于这些区域的内部（不在绿线上）。生成约束：至少一个区域包含两个控制像素，且这两个控制像素到上下边缘条的距离使得一个向上延伸（取蓝色种子）、另一个向下延伸（取红色种子），从而在该区域产生双色冲突。至少一个区域不含任何控制像素。

**规则**：
1. 对每个灰(5)控制像素，比较其到蓝(1)顶行边缘条的行距与到红(2)底行边缘条的行距。
2. 在控制像素的正上方或正下方紧邻的一个像素位置（即沿垂直轴朝近端边缘条方向的相邻格），绘制近端边缘条的颜色：若近蓝则绘蓝(1)，若近红则绘红(2)。若两端等距，朝上延伸取蓝(1)。
3. 确定绿(3)分隔线将边缘条间空间分割成的各封闭区域。
4. 对每个封闭区域，收集其内部所有延伸像素（步骤 2 中绘制的像素）的颜色：
   - 若区域内仅有蓝(1)延伸像素：将该区域全部黑(0)像素洪泛填充为蓝(1)。
   - 若区域内仅有红(2)延伸像素：将该区域全部黑(0)像素洪泛填充为红(2)。
   - 若区域内同时有蓝(1)和红(2)延伸像素：将该区域全部黑(0)像素洪泛填充为黄(4)。
   - 若区域内无任何延伸像素：保持黑(0)不变。
5. 灰(5)控制像素本身保留不变。绿(3)分隔线、蓝(1)顶行边缘条、红(2)底行边缘条均保持不变。

**关键洞察**：控制像素的"近端方向"决定种子颜色，种子颜色决定区域填充色——但冲突区域（双色种子共存）产生了输入中完全不存在的黄(4)色。求解者必须对比多个示例才能发现黄色是冲突的产物而非独立规则。

## 新题 8：双中心同心方环叠加区域的间隙对分着色

**组合逻辑**：[同心方环/concentric_ring + 切比雪夫距离/chebyshev_distance + 距离映射/distance_mapping](已有) + [间隙对半分/gap_bisect](创新：间隙对分原理从一维矩形间隙推广到二维两组同心方环的重叠区域) + [填充/fill + 重涂色/recolor](创新：环层内交替着色由距离奇偶性驱动)

**来源原语**：同心方环(concentric_ring, ac0c2ac3), 切比雪夫距离(chebyshev_distance, ac0c2ac3), 距离映射(distance_mapping, ac0c2ac3), 中心对齐(center_aligned, ac0c2ac3), 间隙对半分(gap_bisect, d968ffd4), 填充(fill, ac0c2ac3/ce22a75a), 重涂色(recolor, 08ed6ac7/6ffe8f07), 矩形(rectangle, d968ffd4)

**依赖链**：两个中心点各自生成同心方环系统，每个系统内部使用距离奇偶交替着色；两个系统的覆盖范围在空间上重叠——重叠区域的每个像素需先通过间隙对分原则确定"归属于哪个中心"，再根据该中心的距离奇偶决定颜色。等距线上的像素保持背景色（奇数间隙中线规则的二维推广）。归属判定和颜色选择不可分离：一个像素的最终颜色同时取决于两个中心的距离关系和所归属中心的距离奇偶。

两个中心点各生成交替着色的同心方环，重叠区域按各像素到两个中心的切比雪夫距离差进行间隙对分归属，等距像素留为背景。

**输入结构**：15x15 的网格，黑(0)背景。网格中有两个标记像素：一个红(2)像素和一个蓝(1)像素，两者位于同一行或同一列上，间隔 4-8 个像素。两个标记像素即为两组同心方环的中心。除这两个像素外，输入中无其他前景内容。生成约束：两个中心的间距为偶数或奇数均可（奇数时产生等距中线效果）。

**规则**：
1. 以红(2)标记为中心定义红色方环系统：切比雪夫距离为奇数的像素着红(2)，偶数的着橙(7)。
2. 以蓝(1)标记为中心定义蓝色方环系统：切比雪夫距离为奇数的像素着蓝(1)，偶数的着绿(3)。
3. 对网格中每个非中心像素，计算其到红中心的切比雪夫距离 d_r 和到蓝中心的切比雪夫距离 d_b。
4. 若 d_r < d_b：该像素归属红色系统，按步骤 1 的奇偶规则着色。
5. 若 d_b < d_r：该像素归属蓝色系统，按步骤 2 的奇偶规则着色。
6. 若 d_r == d_b：该像素保持黑(0)背景（等距中线）。
7. 红(2)中心像素和蓝(1)中心像素保持原色不变（d=0 不属于任何环层）。

**关键洞察**：间隙对分的"等距留空"规则从参考题的一维线性间隙推广到了二维切比雪夫距离场的等值线上——两组方环的交界不是直线而是由切比雪夫距离差决定的折线区域。求解者需同时理解三层规则：距离奇偶交替着色、最近中心归属、等距留空。

## 新题 9：宏块级十字投影按长度排名重涂色

**组合逻辑**：[射线延伸/ray_extend + 十字投影/cross_projection](已有) + [排序/sorting + 计数/counting + 高度排名映射颜色/height_rank_to_color](创新：排名不是基于预先存在的对象高度，而是基于射线在宏块网格中传播后被障碍截断的长度) + [宏块格阵/macro_block_grid + 标记激活块/marker_activates_block](已有) + [射线遇障停止/ray_stops_at_block + 特定色为墙壁/specific_is_wall](已有)

**来源原语**：射线延伸(ray_extend, 6ffe8f07/d968ffd4), 十字投影(cross_projection, 6ffe8f07), 射线遇障停止(ray_stops_at_block, 6ffe8f07), 特定色为墙壁(specific_is_wall, 6ffe8f07), 排序(sorting, 08ed6ac7), 计数(counting, 08ed6ac7), 高度排名映射颜色(height_rank_to_color, 08ed6ac7), 重涂色(recolor, 08ed6ac7), 宏块格阵(macro_block_grid, ce22a75a), 标记激活块(marker_activates_block, ce22a75a)

**依赖链**：灰色宏块是障碍墙壁；从青色源宏块出发的四方向射线在宏块级别传播，遇灰色墙壁停止；四条射线各自的传播长度（经过的宏块数）被计数和排序；排名结果反过来决定每条射线所经宏块的重涂色方案。障碍分布→射线长度→长度排名→颜色分配，形成完整的因果链，且排名是全局比较——移动一个障碍可能改变所有四条射线的颜色。

从青色源宏块向四方向发射宏块级射线，遇灰色墙壁停止，按各射线覆盖的宏块数排名，根据排名为各射线着不同颜色。

**输入结构**：15x15 的网格（5x5 宏块网格，每个宏块 3x3 像素），黑(0)背景。部分宏块整体填充为灰(5)（障碍墙壁），一个宏块的中心像素为青(8)（射线源，该宏块其余像素为黑(0)）。灰(5)宏块在四个方向上不对称分布，使得四条射线长度各不相同。生成约束：青(8)源不在网格边缘的宏块行/列上（保证四个方向均可发射射线）；四条射线长度互不相同（保证排名无并列）。

**规则**：
1. 从包含青(8)源像素的宏块出发，向上、下、左、右四个方向发射射线。射线以宏块为单位逐块传播。
2. 射线进入一个宏块时：若该宏块为灰(5)（墙壁），射线停止，该灰色宏块不被涂色。若该宏块为黑(0)（空闲），射线继续传播，并将该宏块标记为"被该方向射线覆盖"。射线到达网格边界也停止。
3. 计算每条射线覆盖的宏块数（不含源宏块和墙壁宏块）。
4. 按覆盖宏块数降序排列四条射线，分配排名：排名 1（最长射线）、排名 2、排名 3、排名 4（最短射线）。
5. 将各射线覆盖的所有宏块整体填充为排名对应的颜色：
   - 排名 1（最长）：蓝(1)
   - 排名 2：红(2)
   - 排名 3：绿(3)
   - 排名 4（最短）：黄(4)
6. 青(8)源像素保留。灰(5)墙壁宏块保留。未被任何射线覆盖的黑(0)宏块保持不变。

**关键洞察**：每条射线的颜色不是由其方向预定义的，而是由它在四条射线中的相对长度排名决定——这是一个全局比较，求解者必须同时分析所有四条射线的长度后才能为任何一条着色。仅凭一个示例可能误以为颜色与方向绑定（如"向上永远是蓝色"），需要对比多个示例中方向与颜色对应关系的变化才能发现排名规则。
