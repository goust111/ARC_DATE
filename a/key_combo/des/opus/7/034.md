## 新题 1：框限距离环与重叠裁决

**组合逻辑**：[填充(fill) + 距离映射(distance_mapping)](创新：距离场被框边界截断) → [包含内部(containment)](创新：多框重叠区域按距离裁决归属) → [循环色板(cyclic_palette)](已有原语)

**来源原语**：填充、距离映射、曼哈顿距离、循环色板（参考题 aaef0977）；空心矩形、包含内部（参考题 c909285e）；忽略干扰项（参考题 c8b7cc0f）

**依赖链**：框边界截断距离场的范围 → 重叠区域的存在迫使引入距离比较裁决 → 裁决结果决定该像素使用哪个标记的距离值 → 距离值最终索引循环色板。删除框截断则距离场无界无法区分区域；删除裁决则重叠像素颜色不确定；删除距离映射则无法产生环状图案。

在参考题 aaef0977 中只有一个标记、距离场覆盖全网格。在参考题 c909285e 中框只用于裁剪、不做距离计算。此题中框既是距离场的空间约束，又在重叠区产生类 Voronoi 划分——这种"框作为距离场截断边界 + 多源距离竞争"的结构关系在任何参考题中都不存在。

**输入结构**：黑(0)背景，约 20x20 网格。网格中有 2~4 个一像素宽的空心矩形边框，每个边框颜色不同，使用蓝(1)、绿(3)、品红(6)等颜色。边框形状为矩形但尺寸各异（约 5x7 到 8x10 不等），允许部分边框在空间上重叠（重叠区域的边框像素可能交错）。每个边框严格内部（不含边框像素本身）恰有一个橙(7)标记像素，位置不固定。网格中还散布若干灰(5)孤立像素作为干扰项，不在任何边框内部。生成约束：每个边框的内部面积至少 3x3；标记像素不在边框像素上；至少有一对边框存在内部区域重叠。

**规则**：
1. 识别所有一像素宽的完整矩形边框，记录每个边框的颜色和内部区域（严格在边框像素围成的矩形内的所有像素）。
2. 忽略所有不在任何边框内部的非背景像素（灰色干扰项保持不变不参与计算，但输出中仍保留）。
3. 对每个边框，以其内部的橙(7)标记像素为中心，计算该边框内部每个像素到标记的曼哈顿距离。
4. 对于仅属于一个边框内部的像素：按该边框标记的距离值，用循环色板 红(2)、黄(4)、青(8)、栗(9) 依次赋色（距离 0 = 红(2)，距离 1 = 黄(4)，距离 2 = 青(8)，距离 3 = 栗(9)，距离 4 = 红(2)，以此类推）。
5. 对于同时属于多个边框内部的重叠像素：计算该像素到每个所属边框标记的曼哈顿距离，取距离最小的那个边框的距离值作为色板索引。若距离相等，取边框颜色在色板编号中较小的那个边框（如蓝(1)优先于绿(3)）。
6. 边框像素本身保持原色不变。橙(7)标记像素被赋色为距离 0 对应的红(2)。
7. 所有不在任何边框内部的背景像素和干扰像素保持不变。

**关键洞察**：每个边框不仅是空间边界，更是独立距离场的定义域；重叠区域产生的多源距离竞争创造了隐式的 Voronoi 划分——这一规则仅在出现重叠的示例中才可观察到，单个无重叠示例无法归纳。

## 新题 2：对角配对连线按长度排名重涂色

**组合逻辑**：[同色配对(same_color_pairing)](已有原语) → [对角线段连接(diagonal_segment_connect)](已有原语) → [计数(counting)](创新：测量线段长度而非计数对象) → [排序(sort)](创新：按长度排名) → [颜色循环分配(cyclic_color_assignment)](创新：按排名而非扫描位置分配)

**来源原语**：同色配对、对角线段连接（参考题 1f876c06）；排序、颜色循环分配、扫描序（参考题 9473c6fb）；计数、频率排序（参考题 f8b3ba0a）

**依赖链**：颜色配对确定哪些像素相连 → 连线产生几何线段 → 线段长度是新的可测量属性 → 长度排序决定重涂色顺序 → 循环色板按排名赋色。删除配对则不知道连谁；删除连线则无法测量长度；删除排序则无法确定色板索引。

在参考题 1f876c06 中，连线保持端点原色。在参考题 9473c6fb 中，重涂色按扫描位置索引。此题中，原色仅用于确定配对关系、在输出中完全被丢弃，输出色由线段长度的排名决定——"颜色仅作配对标签、几何属性决定输出"这种跨域依赖在参考题中不存在。

**输入结构**：黑(0)背景，约 15x15 网格。网格中有 3~5 种非黑前景色（如红(2)、蓝(1)、绿(3)、黄(4)、品红(6)），每种颜色恰好出现 2 个孤立像素。每对同色像素之间构成严格 45 度对角线（行差的绝对值等于列差的绝对值）。不同颜色的线段互不交叉。生成约束：所有对角线段长度互不相同（保证排名无平局）；任意两条线段不共享像素。

**规则**：
1. 识别每种非黑前景色的两个孤立像素，确认它们构成 45 度对角端点对。
2. 对每对端点，沿对角方向填充连线（包含两个端点和所有中间的对角像素），得到若干对角线段。
3. 计算每条线段的像素长度（端点间对角距离 + 1，即线段包含的像素总数）。
4. 按像素长度从短到长排序所有线段。
5. 按排序顺序，依次用循环色板 绿(3)、灰(5)、栗(9) 给整条线段（包括原端点）赋色：排名第 1（最短）的线段赋绿(3)，排名第 2 的赋灰(5)，排名第 3 的赋栗(9)，排名第 4 的赋绿(3)，以此类推。
6. 背景像素保持黑(0)不变。

**关键洞察**：端点的原始颜色在输出中完全消失——它们仅用于确定配对关系；输出颜色完全由线段长度的排名决定。需对比多个示例才能发现"长度排名决定颜色"这一规则，因为单个示例中颜色与长度的对应关系可能被误认为固定映射。

## 新题 3：框内象限编码印章旋转

**组合逻辑**：[包含内部(containment)](已有原语) → [坐标映射(coordinate_mapping)](创新：标记在框内的象限位置编码旋转角度) → [旋转(rotation)](创新：旋转角由空间位置决定，非固定) → [印章覆盖(stamp)](已有原语)

**来源原语**：印章覆盖、邻域模板、标记单元格（参考题 39e1d7f9）；旋转、逐象限旋转排布（参考题 7953d61e）；空心矩形、包含内部（参考题 c909285e）

**依赖链**：框识别确定标记的空间容器 → 标记在框内的象限位置决定旋转角 → 旋转角应用于模板 → 旋转后的模板印章到标记位置。删除框则无法确定象限（像素在全网格的象限没有意义，因为框位置不固定）；删除旋转则所有印章方向相同（与示例不符）；删除印章则无输出图案。

在参考题 39e1d7f9 中，印章不旋转直接复制。在参考题 7953d61e 中，旋转角是固定的象限分配。此题中，旋转角由标记在其所属框内的相对位置隐式编码——"空间容器的局部坐标编码变换参数"这种结构在参考题中不存在。

**输入结构**：黑(0)背景，约 18x18 网格。网格左上角有一个 3x3 的多色模板图案（由 2~3 种非黑色构成的非对称 4-连通小图形，约 5~7 像素，保证旋转后四个方向各不相同）。网格其余区域有 2~4 个一像素宽的灰(5)空心矩形边框，尺寸约 6x6 到 8x8，互不重叠。每个边框严格内部恰有一个红(2)标记像素。标记像素的位置落在边框内部的某个象限中（将边框内部区域按中心十字线分为四象限：左上、右上、左下、右下；若边框内部行数或列数为偶数，中心线取偏左上的整数分割点）。生成约束：模板 3x3 区域不与任何边框重叠；每个边框内部至少 4x4（保证四象限各有面积）；同一示例中不同边框内的标记位于不同象限。

**规则**：
1. 提取左上角 3x3 模板图案。
2. 识别所有灰(5)空心矩形边框及其内部区域。
3. 对每个边框，定位其内部的红(2)标记像素。将边框内部按行列中点划分为四个象限（行中点 = 内部起始行 + 内部行数 // 2，列中点 = 内部起始列 + 内部列数 // 2）。
4. 根据标记所在象限确定旋转角度：左上象限 = 不旋转（0 度）；右上象限 = 顺时针 90 度；右下象限 = 顺时针 180 度；左下象限 = 顺时针 270 度。
5. 将模板按确定的角度旋转后，以标记像素为中心进行印章覆盖（模板中心对齐标记位置）。印章仅覆盖边框内部区域，超出边框内部的部分裁掉。
6. 印章覆盖时，模板中的非黑像素覆盖目标位置的原有像素；模板中的黑(0)像素不覆盖（透明）。
7. 边框像素、模板原始位置、背景像素均保持不变。红(2)标记像素被模板中心像素覆盖。

**关键洞察**：边框不仅是空间边界，更是一个局部坐标系——标记在框内的象限位置隐式编码了模板的旋转角度。必须对比多个边框（或多个示例）中标记的不同象限位置与对应的模板朝向，才能归纳出象限-旋转映射规则。

## 新题 4：双层过滤计数填充图例

**组合逻辑**：[框内包含(inside_frame)](已有原语) → [特定色像素豁免(specific_color_pixel_exemption)](创新：豁免色不是固定的，而是由图例框中的特殊行指定) → [计数(counting)](已有原语) → [填充图例(populate_legend) + 计数映射点序列(count_to_dot_sequence)](已有原语)

**来源原语**：填充图例、图例框、颜色索引行、计数映射点序列（参考题 58490d8a）；矩形框、框内包含、标记数映射填充、忽略干扰项（参考题 c8b7cc0f）；特定色像素豁免（参考题 319f2597）

**依赖链**：图例框中的特殊标识行指定豁免色 → 豁免色决定哪些框内像素不参与计数 → 计数结果填入图例对应行。删除框包含则无法区分框内外（干扰项混入）；删除豁免色则计数结果错误；删除图例则无输出载体。

在参考题 58490d8a 中，计数不涉及框和豁免。在参考题 c8b7cc0f 中，计数在单个框内，无图例输出。在参考题 319f2597 中，豁免色是固定的红色。此题中，豁免色由图例框本身指定（图例框的底行颜色即豁免色），形成"图例既定义输出格式又定义过滤规则"的自指结构——这种结构在参考题中不存在。

**输入结构**：黑(0)背景，约 20x20 网格。右侧有一个一像素宽黄(4)边框的矩形图例框，内部约 5 行 8 列。图例框内部最左列有若干颜色键像素（如蓝(1)、绿(3)、品红(6)），每种颜色占一行，其余位置为黑(0)。图例框内部最底行有一个单独的栗(9)像素，标识豁免色。网格左侧和中部散布 2~4 个一像素宽的灰(5)空心矩形边框，尺寸约 4x4 到 7x7。每个边框内部有若干孤立前景像素，颜色包括图例键色和栗(9)色。边框外部也有零星前景像素作为干扰项。生成约束：每个边框内至少有 1 个图例键色像素和 0~2 个栗(9)像素；边框互不重叠且不与图例框重叠。

**规则**：
1. 识别黄(4)边框的图例框。图例框内部最左列的非黑像素为颜色键，每种颜色键对应图例中的一行。图例框内部最底行的独立像素颜色为本题的豁免色。
2. 识别所有灰(5)空心矩形边框。
3. 对每种颜色键色 C，计算所有灰框内部（严格在灰框像素围成区域内）颜色为 C 的像素总数。注意：边框外部的同色像素是干扰项，不计入。
4. 对每种颜色键色 C，从步骤 3 的计数中减去与豁免色像素"相邻"的 C 色像素数量（此处"相邻"指在同一灰框内部，与某个豁免色像素 4-连通相邻的 C 色像素；每个 C 色像素最多被减一次）。
5. 将最终计数结果填入图例：在图例框内，从颜色键像素的右侧第 2 格开始，每隔一格放置一个该颜色的点，共放置数量等于最终计数值个点。处理顺序为图例框中从上到下的行顺序。
6. 所有非图例框区域保持不变。

**关键洞察**：图例框的底行不是普通颜色键——它指定了全局豁免色，与豁免色相邻的目标像素被排除出计数。这一规则需对比有豁免色像素和无豁免色像素的示例才能发现：无豁免色像素时计数等于简单的框内同色像素数，有豁免色像素时计数偏少。

## 新题 5：点对称补全叠加距离渐变

**组合逻辑**：[点对称补全(point_symmetry) + 绕中心点旋转对称(center_rotational)](已有原语) ⊗ [距离映射(distance_mapping) + 曼哈顿距离(manhattan_distance)](创新：距离值作为色板偏移量修改反射副本的颜色) → 同时约束输出

**来源原语**：点对称补全、中心标记、绕中心点旋转对称、分隔列（参考题 e729b7be）；距离映射、曼哈顿距离、循环色板（参考题 aaef0977）

**依赖链**：中心标记确定反射中心 → 反射确定新像素的位置 → 同一中心标记作为距离场原点 → 反射像素到中心的距离决定色板偏移 → 原色 + 偏移 = 输出色。对称和距离共享同一中心点但产生不同效果（位置 vs 颜色），两者缺一不可。

在参考题 e729b7be 中反射副本保持原色。在参考题 aaef0977 中距离场赋色与对称无关。此题中对称决定"在哪里画"，距离决定"画什么色"，两个操作共享同一参数（中心点）但作用在不同维度——这种双操作共参数的同时约束结构在参考题中不存在。

**输入结构**：黑(0)背景，奇数行列的网格（约 15x15 或 17x17）。网格中心有一个黄(4)标记像素。一条灰(5)竖线贯穿中心列（除中心标记位置外全为灰色），将网格分为左右两半。左半部分有一个由 2~3 种颜色构成的 4-连通前景图案（约 6~12 像素，使用蓝(1)、红(2)、绿(3)等颜色），形状不规则且不关于中心对称。右半部分除灰分隔线外全为黑(0)。生成约束：前景图案完全在分隔线左侧；图案中不含黄(4)和灰(5)；图案像素到中心的最大曼哈顿距离不超过网格半宽。

**规则**：
1. 保持输入所有像素不变（包括左侧图案、灰分隔线、黄中心标记）。
2. 对左侧图案的每个前景像素 P（颜色为 C，位于坐标 (r, c)），计算其绕黄(4)中心标记 (cr, cc) 的 180 度旋转位置 (2*cr - r, 2*cc - c)。
3. 计算旋转后位置到中心标记的曼哈顿距离 D = |2*cr - r - cr| + |2*cc - c - cc| = |cr - r| + |cc - c|（注意：这等于原像素到中心的距离）。
4. 定义颜色偏移映射：固定一个颜色序列 蓝(1)、红(2)、绿(3)、品红(6)、橙(7)、青(8)。原色 C 在此序列中的位置为 idx(C)。反射像素的输出颜色 = 序列中位置 (idx(C) + D) mod 6 的颜色。
5. 在旋转后位置绘制计算出的输出颜色。若旋转后位置与灰分隔线或其他已有像素重合，不覆盖（保持原有像素）。

**关键洞察**：反射副本的颜色不是原色的简单复制，而是被原像素到中心的曼哈顿距离在颜色序列中做了偏移。距离近的像素颜色偏移小（接近原色），距离远的偏移大（可能变为完全不同的颜色）。需对比不同距离处的像素颜色才能归纳出偏移规则。

## 新题 6：十字擦除后同色配对射线恢复

**组合逻辑**：[十字擦除(cross_erasure)](已有原语) → [同色配对(same_color_pairing)](创新：配对中一方被擦除后触发恢复机制) → [射线延伸(ray_cast)](创新：射线方向由幸存像素指向被擦除像素的位置)

**来源原语**：十字擦除、标记块、十字区域（参考题 319f2597）；同色配对、端点对（参考题 1f876c06）；射线延伸、边界点（参考题 16de56c4 / 551d5bf1）

**依赖链**：十字擦除清空两行两列的非保护像素 → 清空后某些配对的一方消失 → 识别"半损配对"（一方幸存、一方被擦除）→ 从幸存方沿朝向被擦除方的正交方向发射射线到十字区域边界。删除擦除则无受损配对；删除配对识别则不知道哪些像素需要恢复；删除射线则恢复无法实现。

在参考题 319f2597 中擦除是终态，没有恢复机制。在参考题 1f876c06 中配对用于连线而非恢复。在参考题 16de56c4 中射线由边界点发射而非由配对关系触发。此题中"擦除创造损伤 → 配对关系检测损伤 → 射线部分修复损伤"形成破坏-检测-恢复链，这种对抗性结构在参考题中不存在。

**输入结构**：黑(0)背景上铺满多色像素的网格，约 12x12。网格中有一个 2x2 的黑(0)标记块。网格中有 3~5 种前景色（如蓝(1)、绿(3)、品红(6)、橙(7)、青(8)），每种颜色恰好出现 2 个像素（构成配对）。其余位置由黄(4)填充（黄是一般填充色，非配对色）。部分配对的两个像素中，恰好一个位于标记块所占的两行或两列上（即十字区域内），另一个不在十字区域内。也可能存在两个像素都不在十字区域内的配对（这些配对不受影响）。不存在两个像素都在十字区域内的配对。生成约束：标记块不在网格边缘行列；每种配对色至少有一个像素不在十字区域内。

**规则**：
1. 定位 2x2 黑(0)标记块，确定它占据的两行和两列（十字区域）。
2. 将十字区域内所有非黑像素改为黑(0)——但黄(4)像素受保护，保持不变。（即只擦除十字区域内的非黑、非黄像素。）
3. 擦除后，检查每种配对色：若该色的两个像素中恰有一个被擦除（位于十字区域内），则该配对为"半损配对"。
4. 对每个半损配对，从幸存像素出发，沿正交方向（行或列方向）朝被擦除像素所在行或列发射一条该配对色的射线。具体方向：若被擦除像素与幸存像素同行，射线沿行方向（水平）从幸存像素射向被擦除像素方向；若同列，射线沿列方向（垂直）。若既不同行也不同列，射线沿行方向水平射出（朝被擦除像素所在列的方向）。
5. 射线从幸存像素的下一个像素开始绘制，沿射出方向逐像素前进，遇到十字区域的近边界（即十字区域中距幸存像素较近的那条行或列）时停止（不包含十字区域内的像素）。射线覆盖路径上的黄(4)和黑(0)像素，但不覆盖其他配对色像素。
6. 两个像素都不在十字区域内的完整配对不做任何处理。
7. 标记块本身保持黑(0)。

**关键洞察**：十字擦除是破坏性操作，但被擦除的配对像素虽然消失了，其"曾经存在"的信息通过幸存的配对方推断出来，射线是从幸存方向十字区域边缘的部分恢复。需对比擦除前后（跨示例推断）才能理解"配对关系驱动恢复"的机制。

## 新题 7：缩略图与旋转对称双约束拼合

**组合逻辑**：[坐标映射(coordinate_mapping) + 缩略图(minimap)](已有原语) ⊗ [旋转(rotation) + 绕中心点旋转对称(center_rotational)](创新：全局 180 度旋转对称作为独立约束) → 冲突解决规则决定最终输出

**来源原语**：缩略图、坐标映射、缩放、已有块确认对齐（参考题 c4d067a0）；旋转、逐象限旋转排布（参考题 7953d61e）；点对称补全、绕中心点旋转对称（参考题 e729b7be）

**依赖链**：缩略图定义颜色布局约束 → 旋转对称定义另一组颜色约束 → 两组约束在部分位置一致（互相确认）、部分位置冲突 → 冲突解决规则产生最终输出。两个约束是并行的，不是串行的——无法先满足一个再满足另一个，必须同时考虑。

在参考题 c4d067a0 中只有缩略图一个约束。在参考题 7953d61e 中只有旋转一个约束。此题将两个独立的空间约束叠加，在冲突位置引入裁决规则——"双约束同时满足 + 冲突裁决"的结构在参考题中不存在。

**输入结构**：黑(0)背景，偶数行列的网格（约 16x16）。左上角有一个小型缩略图（约 4x4 像素），使用蓝(1)、红(2)、绿(3)、黄(4)等颜色，在黑背景上排列。主区域有若干已放置的 NxN（N=2 或 3）同色方块，颜色与缩略图中的像素对应，分布在网格的上半部分和左半部分。方块之间间距规律（可推断缩放因子和偏移量）。网格的下半部分和右半部分大部分为空（黑色），但有少量方块存在以确认对齐。生成约束：缩略图中的像素数至少为 8；已放置方块能唯一确定缩放因子和偏移；缩略图模式不具有 180 度旋转对称性（保证对称约束和缩略图约束会在某些位置冲突）。

**规则**：
1. 提取左上角缩略图，确定其尺寸和颜色模式。
2. 根据已有方块推断缩放因子 S 和偏移量 (dr, dc)：缩略图像素 (i, j) 对应主区域中左上角为 (dr + i*S*N + i*gap, dc + j*S*N + j*gap) 的 NxN 方块（gap 为方块间距，从已有方块推断）。简化：假设缩略图的每个像素对应主区域中一个方块位置，位置由线性映射确定，已有方块用于求解映射参数。
3. **缩略图约束**：对每个缩略图像素 (i, j) 颜色 C_map，其对应的主区域方块位置应填充颜色 C_map 的 NxN 方块。
4. **旋转对称约束**：整个主区域的方块布局应关于主区域中心具有 180 度旋转对称性——即位置 (i, j) 的方块颜色应等于位置 (H-1-i, W-1-j) 的方块颜色（H、W 为方块网格的行列数）。
5. **冲突解决**：当两个约束对同一位置给出不同颜色时：若该位置已有方块（输入中已存在），保持已有颜色；若该位置为空，采用缩略图约束的颜色。
6. 缩略图本身保持不变。背景保持黑(0)。

**关键洞察**：输出同时服从缩略图映射和 180 度旋转对称两个约束。大部分位置两个约束一致（用于确认规则），少部分位置冲突时已有方块作为裁判，无已有方块时缩略图优先。必须同时观察到两个约束才能正确预测所有位置，单独满足任一约束都会在某些位置出错。

## 新题 8：缺失掩码提取驱动递归展开铺底

**组合逻辑**：[模板与副本匹配(template_copy_match) + 缺失掩码(missing_mask)](已有原语) → [递归展开(recursive_expand) + 自相似替换(self_similar_sub)](创新：掩码形状作为递归种子而非原题中的预设种子) → [平铺(tile)](已有原语)

**来源原语**：模板精灵体、不完整副本、模板与副本匹配、缺失掩码、非标记精确匹配（参考题 bb52a14b）；递归展开、种子掩码、自相似替换、前景背景分别替换（参考题 58c02a16）

**依赖链**：模板与副本对比提取缺失掩码 → 掩码的二值形状成为递归展开的种子 → 种子经一级自相似展开产生更大图案 → 展开图案平铺覆盖所有副本的缺失区域。删除模板匹配则无法确定掩码形状；删除递归展开则掩码不会放大、无法铺满更大区域；删除平铺则展开结果无法应用到各副本位置。

在参考题 bb52a14b 中，缺失掩码直接用原色填充副本的缺失位置。在参考题 58c02a16 中，种子掩码是输入中预设的固定图案。此题中，掩码不是直接填充而是先提取出形状、再作为递归展开的种子——"模式识别的输出作为生成操作的输入"这种分析-合成跨域传递在参考题中不存在。

**输入结构**：黑(0)背景，约 18x18 网格。网格中有一个完整的 4x4 多色模板精灵体（使用红(2)和蓝(1)，其中蓝(1)像素标记"缺失位置"，红(2)像素是结构像素）。网格中还有 2~3 个模板的不完整副本：这些副本只保留了模板中红(2)像素的相对位置和颜色，蓝(1)标记位置为黑(0)（即缺失）。副本之间互不重叠，与完整模板也不重叠。网格右下角有一个 2x1 的小色条作为展开色指示：上格为绿(3)，下格为黄(4)。生成约束：模板中蓝(1)像素至少 4 个，构成一个 4-连通的子图案；模板中的红(2)像素在每个副本中位置精确匹配。

**规则**：
1. 识别完整的 4x4 模板，提取蓝(1)像素的位置集合作为缺失掩码 M（一个二值矩阵，蓝=前景，其余=背景）。
2. 读取右下角色条：上格颜色为前景展开色 C_fg = 绿(3)，下格颜色为背景展开色 C_bg = 黄(4)。
3. 对掩码 M 进行一级递归自相似展开：将 M 中每个前景像素替换为 M 本身的缩小副本（以 C_fg 绘制），将 M 中每个背景像素替换为 M 的缩小副本（以 C_bg 绘制）。得到一个 4x4 倍大小的展开图案 E（尺寸为原掩码的平方）。若掩码为 kxk，展开结果为 k^2 x k^2。
4. 对每个不完整副本，定位其缺失区域（与模板对比后为黑(0)的位置）。将展开图案 E 裁剪到缺失区域的尺寸（从 E 的左上角取对应大小的子区域），填入缺失区域。
5. 完整模板保持不变（蓝(1)像素不改动）。右下角色条保持不变。副本的红(2)结构像素保持不变。背景保持黑(0)。

**关键洞察**：蓝色像素在模板中标识缺失位置，但它们的空间排列本身成为递归展开的种子——缺失的"形状"决定了用什么图案来填补缺失。这种"缺什么就用什么形状来补"的自指逻辑是核心非显然规则，需对比模板中蓝色像素的排列与副本填充图案的细节才能发现。

## 新题 9：图结构度数着色与轨道周期填充

**组合逻辑**：[图结构(graph_structure)](已有原语) → [计数(counting)](创新：计数节点度数而非寻找路径) → [重涂色(recolor)](创新：按度数奇偶着色) + [周期填充(periodic_fill)](创新：轨道上的填充周期等于源节点度数)

**来源原语**：图结构、节点方块、轨道段（参考题 7b0280bc）；计数（参考题 f8b3ba0a / c8b7cc0f）；重涂色（参考题 9473c6fb）；周期填充、周期步长（参考题 16de56c4）

**依赖链**：图的连通结构决定每个节点的度数 → 度数的奇偶性决定节点颜色 → 度数的数值决定该节点发出的轨道段上的填充周期。节点着色和轨道填充共享同一个中间结果（度数），但从中提取不同维度的信息（奇偶 vs 数值）——这种"同源分叉"结构在参考题中不存在。

在参考题 7b0280bc 中，图结构用于最短路径搜索。在参考题 16de56c4 中，周期由两个标记点的间距决定。此题中，度数同时驱动着色和周期两个独立输出通道——这种一个属性分叉为两种不同变换的结构在参考题中不存在。

**输入结构**：黑(0)背景，约 20x20 网格。网格中有 4~6 个 2x2 的蓝(1)同色方块作为节点。节点之间由一像素宽的红(2)轨道段连接（轨道段沿正交方向——水平或垂直——从一个节点边缘延伸到另一个节点边缘，中间不拐弯）。整体构成一个无向图，可能有度数为 1 到 4 的节点。不存在节点与自身连接或两节点间多条轨道的情况。生成约束：图是连通的；至少有一个奇数度节点和一个偶数度节点；每条轨道段长度至少 4 像素（保证周期可见）。

**规则**：
1. 识别所有 2x2 蓝(1)方块作为图的节点，红(2)一像素宽线段作为边（轨道段）。
2. 计算每个节点的度数（与之相连的轨道段数量）。
3. **节点重涂色**：度数为奇数的节点重涂为绿(3)；度数为偶数的节点重涂为黄(4)。
4. **轨道周期填充**：对每条轨道段，确定其两个端点节点。取度数较大的端点作为"源节点"（若度数相同，取行号较小的节点；行号也相同则取列号较小的）。源节点的度数 D 即为该轨道的填充周期。
5. 从源节点侧的轨道起点开始，沿轨道方向每 D 个像素放置一个灰(5)标记像素，其余轨道像素保持红(2)。第 1 个轨道像素（紧邻源节点）为灰(5)，第 2 到第 D 个为红(2)，第 D+1 个为灰(5)，以此类推。超出轨道长度的部分忽略。
6. 背景保持黑(0)。

**关键洞察**：节点度数是一个隐式属性，同时控制两个不同的输出特征：节点颜色（通过奇偶性）和轨道标记间距（通过数值）。需要同时观察节点颜色变化规律和轨道标记间距规律，才能发现它们共享"度数"这一底层驱动因素。单独观察任一特征都可能误以为是独立规则。
