## 新题 1：弹射路径围合填色

**组合逻辑**：[射线延伸](创新：多起点同时弹射) + [反射弹回] + [洪泛填充] + [区域封闭](创新：由射线路径动态构成墙壁) + [计数](创新：统计边界归属以决定填色)

**来源原语**：射线延伸/反射弹回/描边(a3df8b1e), 洪泛填充/区域封闭(a5313dff), 标记像素(e7639916), 计数(d631b094)

**依赖链**：多条弹射路径相互独立地生长并形成墙壁网络 → 墙壁网络将画布分割为若干封闭区域和开放区域 → 封闭区域的填充颜色取决于其边界上哪条射线贡献的墙壁像素最多。三个阶段不可分离：无射线则无墙壁，无墙壁则无封闭区域，无边界归属统计则无法确定填色。

从边界上的彩色起点出发沿对角线弹射，多条路径交织形成墙壁，再用边界归属多数决填充围合区域。

**输入结构**：黑(0)背景的方形网格，约 15x15。网格的四条边界上各散布 2~4 个不同颜色的起点像素（使用红(2)、绿(3)、蓝(1)、黄(4)中的 2~3 种，每种颜色恰好出现 1~2 个起点）。起点像素严格位于边界像素上（即行=0 或行=H-1 或列=0 或列=W-1）。网格内部初始全为黑(0)。生成约束：各起点的弹射路径至少形成一个完全封闭的区域（即至少两条路径的轨迹相交或与边界围合出不可达区域）。

**规则**：
1. 从每个起点像素出发，沿 45 度对角线方向射出一条射线。初始方向由起点在边界上的位置决定：位于上边界的向右下出发，位于下边界的向右上出发，位于左边界的向右下出发，位于右边界的向左下出发。若起点在角落，则向网格内部的唯一对角方向出发。
2. 射线前进时，将经过的每个黑(0)像素涂为该起点的颜色。当射线到达网格左边界或右边界时，水平方向反转（行继续按原方向移动）；当到达上边界或下边界时，垂直方向反转（列继续按原方向移动）。射线在遇到以下任一情况时停止：(a) 射线回到起点像素；(b) 射线试图进入一个已被任意颜色（含自身颜色）占据的非背景像素。射线停止时不覆盖终点像素。
3. 所有射线按起点在边界上的位置顺序依次处理：从左上角沿顺时针方向扫描边界，先遇到的起点先发射射线。
4. 所有射线处理完毕后，将射线路径像素和边界像素都视为墙壁，用 4-邻域洪泛填充从网格四角的任一背景像素出发标记所有可达的外部区域。
5. 剩余的黑(0)背景像素构成封闭区域。对每个 4-连通的封闭区域，统计其边界上（与该区域的像素 4-邻接的非背景像素中）各颜色的像素数量，将该封闭区域填充为边界上出现次数最多的颜色。若存在平局，选择在顺时针边界扫描中起点更早出现的那个颜色。

**关键洞察**：弹射路径本身不是最终输出的主体——它们充当隐式墙壁，其交织方式决定了哪些区域被围合；而填色规则要求追溯每段墙壁的来源，因此射线的颜色身份在路径绘制和区域填充两个阶段都承载信息。

## 新题 2：旋转叠影连通筛选

**组合逻辑**：[旋转](创新：同一图案绕枢轴生成四份旋转副本) + [透明叠加](创新：按旋转角度顺序叠加) → [连通分量] + [重涂色](条件：面积大于一则涂)

**来源原语**：旋转/枢轴像素/距离保持不变(1a244afd), 透明叠加/前后遮挡(cf98881b), 连通分量/面积大于一则涂(e0fb7511), 重涂色(d511f180)

**依赖链**：旋转生成四份副本 → 叠加产生重叠区域 → 重叠区域的连通分量分析决定保留或移除 → 最终颜色由重叠次数决定。旋转角度决定叠加几何，叠加几何决定连通结构，连通结构决定涂色规则。

将单色图案绕枢轴旋转四次并叠加，根据重叠像素的连通性和重叠次数重新涂色。

**输入结构**：黑(0)背景的方形网格，约 13x13。网格中心附近有一个灰(5)枢轴像素。枢轴像素周围有一个由蓝(1)像素构成的不规则 4-连通小图形（3~8 像素），该图形不具备 90 度旋转对称性（保证旋转后四个副本不完全重合）。图形与枢轴不相邻也不重叠，但其所有像素到枢轴的曼哈顿距离不超过 5。网格中无其他非背景像素。生成约束：旋转后的四个副本全部落在网格范围内；至少存在一对副本在某些像素上重叠，且重叠像素中既有形成 4-连通多像素团的，也有孤立的单像素重叠点。

**规则**：
1. 以灰(5)枢轴像素为旋转中心，将蓝(1)图形分别旋转 0度、90度顺时针、180度、270度顺时针，生成四个副本。枢轴像素本身保持灰(5)不变。
2. 将四个副本叠加到同一网格上。对每个非背景位置，记录有多少个副本覆盖了该位置（重叠次数为 1~4）。
3. 对所有重叠次数 >= 2 的像素，检查它们的 4-连通性。形成面积 > 1 的连通分量的像素涂为红(2)；面积 = 1 的孤立重叠像素涂为黄(4)。
4. 重叠次数 = 1 的像素（仅被一个副本覆盖）保持蓝(1)不变。
5. 枢轴像素保持灰(5)。背景保持黑(0)。

**关键洞察**：单看旋转或叠加都无法预测最终颜色——颜色取决于重叠像素的连通结构，而连通结构由原始图案的几何形状和旋转角度共同决定；不对比多个示例无法确认"孤立重叠→黄"与"连通重叠→红"的分野。

## 新题 3：递归射线围合与标记奇偶填色

**组合逻辑**：[递归展开] + [正交转向] + [标记触发转向] → [洪泛填充] + [区域封闭] + [计数](创新：标记奇偶决定填色)

**来源原语**：递归展开/正交转向/标记触发转向/深度优先展开(b942fd60), 洪泛填充/区域封闭/孤立背景区域填充(a5313dff), 计数/数量决定输出宽(d631b094)

**依赖链**：标记像素控制射线网络的递归生长方向 → 射线网络将画布分割为区域 → 每个封闭区域内的标记数量的奇偶性决定填充颜色。标记同时承担两个不可分离的角色：作为射线转向的控制点塑造网络拓扑，作为区域内的计数对象决定填色规则。

从边缘起点递归发射正交射线，标记像素触发转向并塑造围合区域，再按区域内标记数的奇偶性选色填充。

**输入结构**：黑(0)背景的矩形网格，约 16x16。左边界中部有一个红(2)起点像素。网格内散布 5~8 个绿(3)标记像素，它们互不相邻且不在网格边界上。标记像素之间的行列间距至少为 2，保证射线在标记之间有足够的黑(0)空间行进。生成约束：按深度优先递归展开规则生成的射线网络至少围合出两个不与边界相通的封闭区域，且这些封闭区域中至少一个包含奇数个标记、至少一个包含偶数个标记（含零个）。

**规则**：
1. 从红(2)起点像素出发，向右发射一条水平红(2)射线，将沿途黑(0)像素涂红(2)。射线前进直到遇到第一个绿(3)标记像素或到达网格右边界。射线停止在标记前一格（不覆盖标记）或边界像素处。
2. 当射线因遇到某个绿(3)标记而停止时，如果该标记是第一次被射线触及，则从射线停止处（标记前一格的红像素）出发，分别向两个垂直于当前射线方向的方向发射新的红(2)射线。若当前射线水平，则新射线向上和向下；若当前射线垂直，则新射线向左和向右。新射线按同样规则前进和停止。如果标记已被先前的射线触及过，则当前射线仅停止，不再发射新射线。
3. 新射线的处理采用深度优先顺序：当一个标记同时触发两条新射线时，优先处理向右或向下的那条（右优先于下），处理完其所有递归后再处理另一条。
4. 所有射线处理完毕后，红(2)射线网络和绿(3)标记像素共同构成墙壁。用 4-邻域洪泛从网格四个角落的背景像素出发，标记所有可达的外部区域。
5. 每个未被标记到的 4-连通黑(0)背景区域为封闭区域。对每个封闭区域，统计其内部（严格在区域像素范围内，不含边界上的标记）及 4-邻接边界上的绿(3)标记像素总数。若标记数为奇数，将该区域填充为蓝(1)；若标记数为偶数（含零），将该区域填充为黄(4)。
6. 红(2)射线像素、绿(3)标记像素、外部黑(0)背景均保持不变。

**关键洞察**：绿色标记同时扮演两个角色——作为射线网络的转向控制点决定围合拓扑，又作为区域内的计数对象决定填色。移除任一角色（不转向或不计数）都会导致输出无法确定。需要对比多个示例才能归纳出奇偶填色规则。

## 新题 4：三点定框内对称修复

**组合逻辑**：[补全](创新：三点定框确定修复区域) + [对称补全](创新：框内点对称修复遮挡) + [绘制边框] + [标记色定边框色]

**来源原语**：补全/三点定矩形框/包围盒/标记像素(e7639916), 对称补全/遮挡像素/对称轨道/反射旋转定颜色(f9d67f8b), 绘制边框/标记色定边框色/擦除(fc754716)

**依赖链**：三点标记确定包围盒 → 包围盒界定对称修复的作用域 → 对称修复依赖框内非遮挡像素推断对称中心和颜色 → 修复完成后用标记颜色绘制边框。四步紧耦合：无标记则不知修复范围，无修复范围则无法定位对称中心，无对称中心则无法修复遮挡，边框颜色来源于标记。

用三个同色标记确定矩形范围，修复框内被遮挡破坏的点对称图案，最后用标记色绘制矩形边框。

**输入结构**：黑(0)背景的矩形网格，约 17x17。网格中有 2~3 组标记，每组由 3 个同色像素构成（不同组使用不同颜色，如蓝(1)、绿(3)、黄(4)）。每组的 3 个标记像素位于它们共同包围盒的边界上（至少一个在顶行或底行，至少一个在左列或右列）。每个包围盒内部（不含边界行列）有一个由多种颜色（红(2)、橙(7)、灰(5)等）构成的图案，该图案原本具有关于其中心的 180 度旋转对称性（点对称），但部分像素被品红(6)遮挡像素替换。每个包围盒内的遮挡像素数量为 1~4 个。不同组的包围盒互不重叠，且边界不相邻。生成约束：每个框内未被遮挡的像素足以唯一确定对称中心（框内区域的几何中心）和被遮挡位置的正确颜色。

**规则**：
1. 识别所有同色三像素组。每组三像素的颜色相同且不为黑(0)或品红(6)。
2. 对每组，计算三个标记像素的包围盒（最小行、最大行、最小列、最大列构成的矩形区域）。
3. 在每个包围盒的内部区域（不含包围盒边界行列本身），找到所有品红(6)像素。对称中心为包围盒内部区域的几何中心（内部区域行范围和列范围的中点，保证为整数坐标）。
4. 对每个品红(6)像素，计算其关于对称中心的 180 度旋转对应位置。将品红(6)像素替换为该对应位置上的颜色。若对应位置也是品红(6)，则查找该像素关于水平轴反射的对应位置的颜色；若仍为品红(6)，则查找关于垂直轴反射的对应位置的颜色。处理顺序：按从左到右、从上到下扫描品红像素。
5. 对称修复完成后，将每个包围盒的四条边界（顶行、底行、左列、右列的所有像素）涂为该组标记像素的颜色。标记像素本身已在边界上，自然被边框颜色覆盖。
6. 不同组按包围盒左上角位置从左到右、从上到下的顺序依次处理。组外的黑(0)背景保持不变。

**关键洞察**：标记像素同时编码了两个信息——它们的空间位置定义修复区域的边界，它们的颜色决定最终边框的涂色。对称修复必须在边框绘制之前完成，否则边框会覆盖用于推断对称的像素。需要对比多个示例才能确认对称类型是点对称而非轴对称。

## 新题 5：面板叠加后连通溯源

**组合逻辑**：[透明叠加] + [前后遮挡](面板顺序即层序) → [连通分量] + [重涂色](创新：连通分量颜色由贡献最多像素的源面板决定) + [擦除](面积等于一则擦)

**来源原语**：透明叠加/分隔列/色彩面板/面板顺序即层序/前后遮挡(cf98881b), 连通分量/连通性/面积大于一则涂(e0fb7511), 计数(d631b094), 擦除(fc754716)

**依赖链**：面板按层序叠加生成复合图 → 复合图中的 4-连通分量分析将像素分组 → 对每个分量追溯其像素在叠加前来自哪个面板 → 贡献像素最多的面板决定整个分量的最终颜色 → 面积为 1 的分量被擦除。叠加创造了新的连通结构（前层遮断后层可能分裂原有连通分量），溯源要求穿透遮挡关系回溯原始面板。

将三个面板透明叠加后，按连通分量的源面板归属重新统一涂色，并擦除孤立单像素分量。

**输入结构**：黑(0)背景的矩形网格，约 8x25（宽远大于高）。网格被两条红(2)竖直分隔列等分为三个 8x7 的面板（分隔列宽度为 1 像素）。左面板包含黄(4)像素构成的图案（黑(0)为透明），中面板包含橙(7)像素构成的图案，右面板包含蓝(1)像素构成的图案。每个面板的图案由 1~3 个不规则 4-连通区域组成，每个区域 3~10 像素。输出网格尺寸为 8x7（单个面板大小）。生成约束：叠加后至少存在一个连通分量由两个不同面板的像素共同构成；至少存在一个面积为 1 的连通分量；前层遮挡至少分裂了一个后层面板的连通区域。

**规则**：
1. 移除两条红(2)分隔列，提取三个面板。左面板为最后层（层 0），中面板为中间层（层 1），右面板为最前层（层 2）。
2. 在 8x7 的输出画布上，依次叠加：先放置层 0（左面板），再放置层 1（中面板的非黑像素覆盖层 0），再放置层 2（右面板的非黑像素覆盖层 1 和层 0）。记录每个最终非黑像素的来源层编号。
3. 在叠加结果中，对所有非黑像素做 4-连通分量分析。
4. 对每个连通分量，统计其像素来源：来自层 0 的像素数、来自层 1 的像素数、来自层 2 的像素数。将整个分量涂为贡献像素最多的那一层的面板颜色（层 0→黄(4)，层 1→橙(7)，层 2→蓝(1)）。若两层贡献像素数相同，选择层编号更大（更前层）的颜色。
5. 面积等于 1 的连通分量（孤立单像素）不涂色，直接擦除为黑(0)背景。
6. 输出 8x7 的处理后画布。

**关键洞察**：叠加不仅改变了颜色，还改变了连通结构——前层的遮挡可能将后层的一个连通区域分裂为多个分量。每个分量的最终颜色不由其表面可见颜色决定，而由追溯叠加前各层贡献的像素多数决定。不对比多个示例无法确认溯源规则和孤立像素擦除规则。

## 新题 6：朝向射线交叉连线涂色

**组合逻辑**：[射线延伸] + [朝向推断](缺角指示方向) → [连线](创新：由射线交叉点触发两箭头之间的连线) + [重涂色](按原色区分涂色)

**来源原语**：射线延伸/箭头精灵体/朝向推断/缺角指示方向(6e19193c), 连线/两点直线路径/按原色区分涂色(bcb3040b), 标记像素(e7639916)

**依赖链**：箭头精灵体的缺角确定射线方向 → 射线延伸到画布边界 → 两条不同箭头的射线相交时触发连线操作 → 连线路径上的像素根据其原始状态（背景 vs 射线）被涂为不同颜色。朝向推断决定射线方向，射线交叉决定哪些箭头之间需要连线，连线时的涂色规则区分原色。

从箭头精灵体沿其朝向发射射线，当两条射线交叉时，在交叉点与两个箭头之间画直线段，按经过像素的原色区分涂色。

**输入结构**：黑(0)背景的方形网格，约 15x15。网格中有 3~5 个箭头精灵体，每个由蓝(1)像素构成的 2x2 区域去掉一个角形成的 3 像素 L 形小图形。不同箭头的缺角位置不同，指示其朝向（缺右上角→向右上，缺左下角→向左下，等）。箭头之间互不相邻，最小间距 >= 3。网格中另有若干孤立的灰(5)噪声像素，散布在背景上。生成约束：至少有两对箭头的射线会相交（射线沿缺角所指的对角线 45 度方向延伸至边界）；至少有一条连线路径上会经过灰(5)噪声像素。

**规则**：
1. 对每个箭头精灵体（3 像素的 L 形蓝(1)图形），确定其缺角位置。缺角方向即为射线发射方向（例如缺右上角 → 射线向右上方 45 度延伸）。
2. 从箭头精灵体的包围盒中与缺角相邻的那个外角位置（缺角格的外侧对角位置），沿缺角方向以 45 度对角线发射绿(3)射线，将沿途的黑(0)像素涂为绿(3)。射线遇到网格边界或任何非黑非灰的像素时停止（灰(5)噪声像素被射线覆盖为绿(3)）。所有箭头的射线按箭头包围盒左上角位置从左到右、从上到下的顺序依次处理。
3. 所有射线处理完毕后，检查每一对箭头：如果箭头 A 的射线路径与箭头 B 的射线路径有至少一个公共像素（交叉点），则在箭头 A 的包围盒中心与箭头 B 的包围盒中心之间画一条直线段（沿水平、垂直或 45 度对角线之一——选择与两中心连线最接近的方向）。
4. 画连线时，逐像素处理从 A 中心到 B 中心的路径（含端点）：若该位置原本是黑(0)背景或灰(5)噪声，涂为红(2)；若该位置原本是绿(3)射线像素，涂为黄(4)；若该位置是蓝(1)箭头像素，保持蓝(1)不变。
5. 若多条连线经过同一像素，后画的连线覆盖先画的。连线按两个箭头中编号较小者（按步骤 2 的排序编号）优先、编号较大者次之的字典序排列，编号小的连线先画。
6. 没有参与任何交叉的箭头及其射线保持不变。灰(5)噪声像素若未被射线或连线覆盖则保持灰(5)。

**关键洞察**：射线交叉是一个隐式的空间匹配条件——只有射线相交的箭头对才触发连线。连线上的颜色编码了该位置的历史：曾被射线经过的位置（绿→黄）与纯背景位置（黑→红）被区分开来。需要对比多个示例才能归纳出交叉触发连线和按原色区分涂色的规则。

## 新题 7：滑动选择性射线发射

**组合逻辑**：[滑动](有后续像素则移) + [射线延伸] + [支撑](创新：支撑分析结果决定哪些对象发射射线) + [朝向推断](创新：滑动方向编码射线朝向)

**来源原语**：滑动/支撑/有后续像素则移/轮廓边界(025d127b), 射线延伸/箭头精灵体/朝向推断(6e19193c), 画布边界(a3df8b1e)

**依赖链**：支撑分析将每个对象的像素分为"可移动"和"边界固定"两类 → 滑动操作执行后改变对象形状 → 只有滑动后处于最右轮廓（未移动的原始边界像素）的像素向右发射水平射线 → 射线长度编码了该边界像素到网格右边界的距离。滑动改变了形状，形状决定了哪些像素在边界上，边界像素成为射线的发射源。

对象像素按支撑规则右移后，仅从未移动的右侧轮廓像素向右发射射线至画布边界。

**输入结构**：黑(0)背景的矩形网格，约 12x18（宽大于高）。网格左半区有 2~4 个由不同颜色（蓝(1)、红(2)、绿(3)、黄(4)）构成的单色 4-连通小图形，每个图形 4~8 像素，形状不规则（非矩形），有对角或倾斜边缘。各图形互不接触，且全部位于网格左半部分（列索引 < W/2）。网格右半区全为黑(0)背景。生成约束：每个图形至少有 1 个像素满足"其右下方存在同图形像素"的条件（即至少有 1 个像素会被右移），且至少有 1 个像素不满足该条件（留在原位）。

**规则**：
1. 对每个图形独立执行滑动操作：对图形中的每个像素 (r, c)，检查同一图形中是否存在行号 > r 且列号 > c 的像素。若存在，该像素右移一列至 (r, c+1)；若不存在，该像素留在原位。右移时若目标位置已被同图形的另一个像素占据，两个像素合并（颜色不变）。
2. 滑动完成后，对每个图形，识别其"右侧轮廓像素"——即图形中满足以下条件的像素：其右方（同行、列号更大的位置）不存在属于同一图形的像素。
3. 从每个右侧轮廓像素的位置出发，向右发射一条水平射线，将沿途的黑(0)像素涂为该图形的颜色。射线前进直到到达网格的右边界（最后一列），最后一列也被涂色。若射线遇到其他图形的射线像素（非黑非同色），射线在该像素前一格停止，不覆盖已有射线。
4. 射线的处理顺序：按图形的颜色编号从小到大（蓝(1)先于红(2)先于绿(3)先于黄(4)），同一图形内按射线起点的行号从上到下。
5. 滑动过程中像素右移后留下的原位置恢复为黑(0)背景。

**关键洞察**：滑动操作不仅改变了图形的形状，更关键的是重新定义了哪些像素处于右侧轮廓——只有滑动后仍在右侧边界的像素才发射射线。这意味着滑动是一个筛选机制而非单纯的位移：它通过改变图形几何来选择射线发射源。无法跳过滑动直接从原始图形推断射线，因为轮廓在滑动前后不同。

## 新题 8：双色互换揭示对称以修复遮挡

**组合逻辑**：[双色互换](创新：互换是揭示隐藏对称的前提条件) → [对称补全](创新：对称性只在互换后显现) + [重涂色](创新：修复完成后再逆向互换恢复原始色彩空间)

**来源原语**：双色互换/仅交换两色(d511f180), 对称补全/遮挡像素/对称轨道/反射旋转定颜色(f9d67f8b), 重涂色(e0fb7511)

**依赖链**：原始网格在视觉上无对称性 → 交换特定两种颜色后，非遮挡区域呈现轴对称 → 利用对称性修复遮挡像素 → 将修复后的网格逆向交换回原色。四步形成闭环：互换揭示对称 → 对称指导修复 → 修复后逆向互换。跳过互换则看不到对称，跳过逆向互换则输出色彩空间不对。

先交换两种颜色使隐藏的对称性显现，利用对称修复被遮挡的像素，最后逆向交换恢复原始配色。

**输入结构**：黑(0)背景的方形网格，约 11x11。网格中有一个大致居中的图案，由红(2)、蓝(1)、绿(3)三种颜色构成，占据约 7x7 的区域。图案中还有 2~5 个品红(6)遮挡像素分布在不同位置。图案在当前配色下不具备任何明显对称性。但如果将红(2)和蓝(1)互换（红→蓝，蓝→红），图案的非遮挡部分将呈现关于某一垂直轴或水平轴的严格反射对称。绿(3)像素不参与互换，在图案中起结构性作用（对称的一部分）。生成约束：互换前无轴对称性；互换后非遮挡像素关于唯一一条轴严格对称；对称轴通过图案区域的中央行或中央列；每个遮挡位置的对称对应位置均未被遮挡（保证可唯一修复）。

**规则**：
1. 在输入网格中，将所有红(2)像素改为蓝(1)，同时将所有蓝(1)像素改为红(2)。绿(3)、品红(6)、黑(0)保持不变。此为"正向互换"。
2. 在互换后的网格中，忽略品红(6)像素，检测非背景非遮挡像素的反射对称轴。对称轴为通过图案所有非遮挡像素的包围盒中心的一条垂直线或水平线（只有一条轴满足，通过对比多个示例确认是垂直还是水平——不同示例的轴方向可能不同，取决于图案结构）。
3. 对每个品红(6)遮挡像素，找到其关于检测到的对称轴的反射对应位置。将品红(6)像素替换为该对应位置的颜色（互换后的颜色）。若对应位置也是品红(6)（生成约束排除此情况，但作为安全措施），则保留品红(6)不变。
4. 对称修复完成后，执行"逆向互换"：将网格中所有红(2)像素改回蓝(1)，所有蓝(1)像素改回红(2)。绿(3)、黑(0)保持不变。此时不再有品红(6)像素。
5. 输出逆向互换后的最终网格。

**关键洞察**：原始配色故意隐藏了对称性——直接观察输入无法发现任何对称结构。求解者必须先发现红蓝互换能揭示对称，再利用对称修复遮挡，最后逆向互换恢复原始色系。三步形成不可分割的闭环推理：互换是修复的前提，修复是逆向互换的前提，逆向互换是正确输出的前提。

## 新题 9：周期瓦片补全后重力滑动

**组合逻辑**：[周期延拓](创新：仅水平方向周期补全) + [补全] + [滑动](创新：补全后的像素受重力下落) + [支撑] + [占位符区域]

**来源原语**：重复瓦片/周期延拓/占位符区域/补全后平移(50a16a69), 滑动/支撑/有后续像素则移(025d127b), 前景像素(d631b094)

**依赖链**：占位符区域隐藏了瓦片的延续 → 周期推断恢复完整图案 → 恢复出的像素不稳固，按重力规则下落 → 下落后的最终位置取决于下方是否有支撑（其他像素或底边界）。补全生成了新像素，但这些像素的最终位置由后续的重力滑动决定；而重力滑动的结果又取决于原始非占位区域的像素提供的支撑结构。

推断周期瓦片以填充占位符区域，然后让所有非背景像素在重力作用下逐列下落堆叠。

**输入结构**：黑(0)背景的矩形网格，约 10x14。网格左侧约 60% 的区域包含一个由 2~3 种颜色（蓝(1)、红(2)、绿(3)中选取）构成的周期性瓦片图案，瓦片尺寸约 3x3 到 4x4，水平和垂直重复。网格右侧约 40% 的区域全部填充为灰(5)占位符像素。瓦片图案不是全填充的——瓦片内部有黑(0)背景像素（即瓦片本身是稀疏的，每个瓦片约有 40%~60% 的像素为背景）。生成约束：灰(5)区域的左边界恰好落在瓦片周期的整数倍列上（保证可无歧义地延拓）；补全后至少有 3 列包含不与底边界相邻的"悬浮"像素（下方为背景）。

**规则**：
1. 从左侧非占位符区域推断最小水平重复周期 T（列数）。具体方法：找到最小的 T 使得非占位区域的所有列满足第 c 列与第 c+T 列（若存在）图案相同。
2. 用推断出的周期 T 水平延拓，将灰(5)占位符区域的每个像素替换为同行中列号 mod T 对应的非占位区域列的颜色。若对应颜色为黑(0)则替换为黑(0)。
3. 补全完成后，对整个网格执行重力下落：逐列处理（从左到右），在每一列中，将所有非背景像素向下滑动，直到碰到另一个非背景像素的顶部或到达网格底行。下落保持同列内非背景像素的相对上下顺序不变。
4. 像素下落后其原位置恢复为黑(0)。
5. 输出重力下落后的完整网格（尺寸不变）。

**关键洞察**：周期补全本身不是终态——它只是恢复了悬浮的瓦片图案。重力下落打破了瓦片的周期结构，产生了与输入截然不同的非周期输出。求解者需要先识别周期性并补全，才能获得重力下落的正确输入；但最终输出不再呈现任何周期性，使得逆向推理更具挑战。

## 新题 10：镜像拼接后射线网络着色

**组合逻辑**：[镜像] + [拼接](画布加倍) → [射线延伸](创新：在拼接后的扩展画布上发射) + [标记像素] + [重涂色](创新：射线颜色由该射线穿越对称轴的次数决定)

**来源原语**：镜像/拼接/画布加倍/轴对称(c9e6f938), 射线延伸/标记像素/起点像素(6e19193c, b942fd60), 重涂色/按原色区分涂色(bcb3040b)

**依赖链**：输入网格向右镜像拼接生成双倍宽画布 → 在拼接画布上从标记像素发射水平和垂直射线 → 射线穿越镜像对称轴（原始画布的右边界/拼接画布的中线）时改变颜色 → 颜色交替取决于穿越次数的奇偶。镜像拼接创造了对称轴，对称轴成为射线变色的触发线，这是源题中不存在的结构关系。

将输入水平镜像拼接后，从标记像素发射正交射线，射线每穿越一次对称轴就交替变色。

**输入结构**：黑(0)背景的矩形网格，约 7x10。网格中有 2~4 个红(2)标记像素，散布在不同行列。网格中还有若干蓝(1)像素构成的障碍物块（1~3 个 4-连通小区域，每个 2~5 像素）。标记像素与障碍物不相邻。生成约束：至少一个标记像素的行或列上，在镜像拼接后的画布中存在障碍物像素（保证射线不全穿越到边界）；至少一条射线会穿越对称轴。

**规则**：
1. 将输入网格水平镜像拼接：保留原始网格作为左半部分，将原始网格按列反转后拼接在右侧，生成宽度为原来两倍的画布。拼接后蓝(1)障碍物和红(2)标记也被镜像。
2. 记对称轴为拼接画布的垂直中线（列索引 = 原始宽度 - 0.5，即左半最后一列和右半第一列之间）。
3. 从拼接画布中每个红(2)标记像素的位置出发，向上、下、左、右四个方向各发射一条射线。只处理原始左半部分中的标记像素（镜像生成的右半标记忽略，视为普通红(2)像素）。
4. 每条射线从标记像素的邻格开始，逐像素前进。射线初始颜色为绿(3)。射线前进时，将黑(0)背景像素涂为当前射线颜色。射线每穿越一次对称轴（从左半进入右半或从右半进入左半），当前射线颜色在绿(3)和黄(4)之间切换（绿→黄→绿→...）。
5. 射线在以下情况停止：(a) 到达画布边界；(b) 遇到蓝(1)障碍物像素（不覆盖障碍物）；(c) 遇到另一条射线已涂色的像素（不覆盖，保留先画的颜色）。
6. 射线处理顺序：按标记像素的行号从上到下、同行则列号从左到右。同一标记的四条射线按上、右、下、左的顺序处理。
7. 红(2)标记像素（含镜像生成的）保持红(2)。蓝(1)障碍物（含镜像生成的）保持蓝(1)。输出为拼接后的完整双倍宽画布。

**关键洞察**：镜像拼接不仅扩展了画布，更创造了一条具有语义的对称轴——这条轴在源题中仅是几何边界，在此处成为射线变色的触发条件。射线的最终颜色模式同时编码了空间信息（穿越了几次轴）和拓扑信息（被障碍物阻断的位置），两者缺一不可。
