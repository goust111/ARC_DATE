## 新题 1：蛇径定序的框内重涂

**组合逻辑**：[遍历顺序](创新：遍历顺序不用于展直而用于定义优先级) + [矩形框/边框包围内容](已有) + [重涂色](创新：目标色由遍历到达时的蛇身颜色决定) + [计数/内部标记计数](创新：计数结果用于筛选而非擦除)

**来源原语**：遍历顺序/蛇形路径(7b5033c1)、矩形框/边框包围内容(1a6449f1)、重涂色(c3fa4749)、计数/内部标记计数(54db823b)

**依赖链**：蛇径的遍历顺序为每个被穿过的矩形框分配一个到达序号；框内灰(5)标记像素的计数筛选出需要重涂的框（仅保留标记数超过 1 的框）；被保留框的内部全部重涂为蛇身在该框处的像素颜色；未被蛇穿过或标记数不足的框连同边框一并擦为背景。遍历提供排序、计数提供筛选、重涂执行变换——三者缺一不可。

在一张网格上，一条多色蛇形路径穿过若干单色矩形框；蛇到达每个框时的身体颜色决定该框内部的输出颜色，但只有框内灰(5)标记像素数量大于 1 的框才被保留并重涂，其余框连同边框一并擦除。

**输入结构**：约 18x18 的网格，背景黑(0)。网格中散布 3~5 个完整单色矩形框（边框一像素厚，每个框的边框颜色互不相同，使用蓝(1)、绿(3)、黄(4)、品红(6)中的若干种），框内部分单元格为灰(5)标记像素（每框 0~3 个灰像素），其余内部为黑(0)背景。一条 4-连通蛇形路径从网格的一端延伸到另一端，蛇身每段由不同非黑非灰颜色组成（可使用红(2)、橙(7)、青(8)、栗(9)），蛇经过某些框时穿过框的边框进入内部再穿出。蛇恰好有两个端点（各只有一个路径邻居）。各矩形框互不重叠，蛇路径与框边框的交叉处恰好各一个入口像素和一个出口像素。生成约束：蛇穿过的框中至少有一个框的灰标记数 <= 1，保证筛选确实去除了某些框。

**规则**：
1. 找到蛇形路径的两个端点，以行号较小者为起点（行号相同则取列号较小者），沿 4-连通路径逐像素遍历。
2. 记录蛇进入每个矩形框时（即蛇身像素首次落入框边框所围区域的那一步），该蛇身像素自身的颜色，称为"到达色"。
3. 对每个矩形框，统计其严格内部（不含边框）的灰(5)像素数量。
4. 若某框的灰像素数量 > 1，则将该框的严格内部所有像素（含灰标记）统一重涂为该框的到达色，边框保留原色不变。
5. 若某框的灰像素数量 <= 1，或该框未被蛇穿过，则将该框的边框和内部全部擦为黑(0)背景。
6. 蛇形路径本身在输出中全部擦为黑(0)背景。

**关键洞察**：蛇路径本身不出现在输出中，它纯粹充当"调色探针"——只有同时满足"被蛇穿过"且"内部灰标记足够多"两个独立条件的框才存活，而存活框的内部颜色由蛇到达瞬间的颜色唯一确定。

## 新题 2：锚点距离定步长的周期阶梯碰撞

**组合逻辑**：[连线/阶梯图案](已有) + [周期延伸](创新：阶梯以周期方式重复生长而非单次绘制) + [碰撞阻挡/累积影响后续停靠](创新：多阶梯间的碰撞决定最终长度) + [最近角距离](创新：距离不用于填充而用于编码步长参数)

**来源原语**：连线/阶梯图案/锚点像素(d06dbe63)、周期延伸/长度即周期(1ae2feb7)、碰撞阻挡/累积影响后续停靠(4093f84a)、最近角距离(4a1cacc2)

**依赖链**：每个锚点到其最近网格角的曼哈顿距离决定该锚点阶梯的步长；阶梯以步长为周期沿两个对角方向重复延伸；多个锚点的阶梯可能碰撞，先绘制的阶梯像素阻挡后绘制的阶梯生长。距离→步长→周期→碰撞形成四层因果链。

多个彩色锚点各自生成灰(5)阶梯，每个阶梯的步长等于该锚点到最近网格角的曼哈顿距离；阶梯沿两个对角方向周期延伸直至撞上其他阶梯或网格边界，先到者阻挡后到者。

**输入结构**：约 20x20 的网格，背景黑(0)。网格中有 2~4 个单像素锚点，每个锚点颜色互不相同，使用蓝(1)、红(2)、绿(3)、黄(4)中的若干种。各锚点不在网格边界上，且任意两个锚点之间的曼哈顿距离 >= 6。生成约束：每个锚点到其最近角的曼哈顿距离在 2~5 之间（保证步长合理）；不同锚点的最近角不全相同（保证步长存在差异）。

**规则**：
1. 对每个锚点，计算其到四个网格角的曼哈顿距离，取最小值记为 S（步长）。
2. 从每个锚点出发，沿该锚点的两条对角方向（右上+左下为一组，左上+右下为一组；具体哪组由锚点所在象限决定：锚点离哪个角最近，就沿连接对角的方向画，即从锚点朝最近角方向和远离最近角方向各画一条臂）绘制阶梯。阶梯的绘制方式：每一步先画 S 个像素的水平段，再画 S 个像素的竖直段，交替进行，颜色为灰(5)。第一步的水平方向朝最近角的水平分量方向，竖直方向朝最近角的竖直分量方向；反向臂则两个方向均取反。
3. 阶梯周期延伸：上述水平段-竖直段交替是一个周期，持续重复直至下一段的像素超出网格边界或与已绘制的任何灰像素重叠。
4. 处理顺序：按锚点的步长 S 从小到大处理（S 相同时按锚点行号从小到大，再按列号从小到大）。先处理的锚点的阶梯像素已固定，后续阶梯遇到它们时立即截断。
5. 所有锚点像素在输出中保留原色不变。

**关键洞察**：步长不是预设常数而是由每个锚点的空间位置（到角距离）隐式编码的；必须对比多个示例才能确认"距离=步长"这一映射关系，而非直觉上的"每个阶梯步长相同"。

## 新题 3：图例驱动的分割滑移与对角拼合

**组合逻辑**：[颜色图例/图例映射](创新：图例不映射颜色而映射滑移方向) + [分割](已有) + [滑动](创新：方向由图例决定而非固定规则) + [对角邻接拼合](创新：不同对象的分割碎片跨对象对角拼合)

**来源原语**：颜色图例/图例映射(5adee1b2)、分割(fc4aaf52)、滑动(4093f84a)、对角邻接拼合(fc4aaf52)

**依赖链**：图例定义颜色→方向的映射；每个双色物体按水平中线分割成上下两半；每半的主色（像素数较多的颜色）查图例得到滑移方向；各半沿对应方向滑移直到与任意其他碎片形成对角邻接。图例→分割→方向查找→滑移→对角邻接判定构成不可跳步的推理链。

网格左边缘有方向图例（颜色-箭头对），网格中有若干双色物体；每个物体水平对半分割后，各半按其主色在图例中对应的方向滑移，直到与另一碎片对角相邻。

**输入结构**：约 16x20 的网格，背景黑(0)。左边缘有 2~3 个方向图例块，每块占 2 行 x 2 列：左列 2 像素为某前景色（如红(2)、蓝(1)、绿(3)），右列 2 像素为灰(5)箭头标记——上行灰像素在右列顶格表示"向上"，下行灰像素在右列底格表示"向下"，两行灰像素都在右列表示"不动"（生成时不使用"不动"，保证每个图例块指示上或下）。实际方向编码更精确：若右列上格为灰(5)、下格为黑(0)，则该颜色对应"向上滑移"；若右列上格为黑(0)、下格为灰(5)，则对应"向下滑移"。网格中央偏右区域有 2~3 个双色物体，每个物体是一个偶数高度的 4-连通区域（高 4~8 像素，宽 3~5 像素），由恰好两种非黑非灰颜色组成，且这两种颜色都出现在图例中。各物体之间水平间距 >= 4 列，竖直方向有足够空间供滑移（至少 3 行余量）。生成约束：同一物体的两种颜色在图例中对应的方向必须相反（一个向上一个向下），保证分割后两半朝相反方向运动。

**规则**：
1. 识别左边缘图例块：每个图例块占连续 2 行、最左 2 列，左列颜色为映射源色，右列的灰(5)像素位置编码方向（上格灰→向上，下格灰→向下）。
2. 对网格中每个双色物体，沿其边界框的水平中线（上半高度 = 下半高度）分割为上半和下半。
3. 每半统计两种颜色的像素数，像素数较多者为该半的"主色"。
4. 查图例得到主色对应的方向。上半和下半各自沿其方向逐行滑移（向上则整体上移一行，向下则整体下移一行），每步检查该半是否与任意其他碎片（来自同一物体或不同物体均可）形成对角邻接（即该半的某个像素与另一碎片的某个像素在对角方向相邻且不在水平/竖直方向相邻）。一旦形成对角邻接则停止。
5. 若某半滑移到网格边界仍未对角邻接，则停在边界处。
6. 处理顺序：所有碎片同时滑移，每步各移一行，同步检查对角邻接条件。当某碎片满足条件后固定，其余继续移动。
7. 图例块在输出中擦除为黑(0)背景。

**关键洞察**：图例在此题中不是颜色→颜色的映射（参考题中图例用于膨胀着色），而是颜色→运动方向的映射；且分割后两半的去向不由自身位置决定，而由各自主色在图例中的编码决定——单看一个示例无法区分"主色定方向"和"位置定方向"两种假说。

## 新题 4：分区压缩后的旋转对称补全

**组合逻辑**：[压缩/网格分区](已有) + [旋转/对称补全/四次旋转闭合](创新：对称补全作用于压缩后的抽象区域图而非原始像素) + [镜像](创新：当压缩图非正方形时先镜像拼接成正方形再做旋转补全)

**来源原语**：压缩/网格分区/分隔线/单色区域(9f236235)、旋转/对称补全/四次旋转闭合(e40b9e2f)、镜像/拼接(6d0aefbc)

**依赖链**：分隔线将网格分成均匀区域，压缩为每区域一像素的紧凑图；若紧凑图行数 != 列数，则沿短边方向镜像拼接使之成为正方形；最后对正方形紧凑图执行 90 度旋转对称补全，将部分前景图案扩展为四次旋转闭合。压缩改变了操作尺度，镜像修正了形状前提，对称补全完成最终变换——三步不可跳过。

用分隔线将大网格压缩为紧凑区域图，必要时镜像补成正方形，再对紧凑图执行四次旋转对称补全。

**输入结构**：约 15x21（或 21x15）的网格。橙(7)分隔线（水平和竖直各若干条，宽度 1 像素，贯穿整个网格）将网格划分为均匀大小的矩形区域（每区域约 3x3 或 4x4 像素）。分隔线之间的每个区域内所有像素同色，使用黑(0)作为背景色，蓝(1)、红(2)、绿(3)等作为前景色。压缩后的紧凑图为 N 行 x M 列（N != M），其中 N 和 M 之一是另一个的约数或者满足 2N=M 或 2M=N 的关系（保证镜像拼接后恰好成为正方形）。紧凑图中前景像素构成一个不完整的图案，该图案在被镜像补成正方形后，恰好可以通过四次旋转闭合补全（即补全后图案关于正方形中心具有 90 度旋转对称性）。生成约束：前景图案在补全前不具备旋转对称性（确保补全步骤非平凡）。

**规则**：
1. 识别分隔色：找到在某整行或整列上所有像素同色的颜色，即为分隔色（橙(7)）。
2. 将分隔线之间的每个矩形区域压缩为一个像素，颜色为该区域的统一色，得到 N x M 的紧凑图。
3. 若 N < M，则将紧凑图沿底边水平镜像拼接（即在下方追加紧凑图的上下翻转副本），使行数翻倍变为 2N = M，得到正方形。若 N > M，则沿右边竖直镜像拼接（在右方追加左右翻转副本），使列数翻倍变为 2M = N。若 N = M 则跳过此步。
4. 对正方形紧凑图执行四次旋转对称补全：对每个非背景像素 (r, c)，在 90 度、180 度、270 度旋转位置也涂上同色。旋转中心为正方形中心。若某旋转位置已有不同非背景色，保留行号较小的像素的颜色（行号相同则保留列号较小的）。
5. 输出即为补全后的正方形紧凑图（不展开回大网格）。

**关键洞察**：压缩和对称补全各自在参考题中独立存在，但此题中压缩改变了对称补全的操作尺度——求解者必须先发现"分隔线间区域即一个像素"的抽象映射，再发现紧凑图需要先补成正方形才能应用旋转闭合，两层抽象缺一不可。

## 新题 5：轨迹长度定印章朝向的覆盖与嵌入修补

**组合逻辑**：[印章覆盖](创新：印章朝向不由独立标记决定而由轨迹长度的奇偶性决定) + [沿路径移动/轨迹路径](创新：轨迹不用于移动源色而用于编码参数) + [修补/嵌入与孤立](创新：印章后嵌入标记需修补为印章色)

**来源原语**：印章覆盖/方向标记/朝向决定粘贴侧(4c177718)、沿路径移动/轨迹路径(c9680e90)、修补/嵌入与孤立(8886d717)

**依赖链**：每个模板对象连接着一条轨迹路径，路径末端有一个精灵体；轨迹长度的奇偶性决定精灵体应印章在模板的上方还是下方；印章完成后，若精灵体像素覆盖的区域内恰好有原本的标记像素被包围（嵌入），则修补为精灵体颜色；孤立的标记像素保留不变。轨迹→奇偶→朝向→印章→嵌入判定→修补，六步链。

模板与精灵体之间以彩色轨迹相连，轨迹的像素长度的奇偶性决定精灵体印章在模板上方还是下方；印章后被精灵体包围的标记像素修补为精灵体颜色。

**输入结构**：约 18x18 的网格，背景黑(0)。包含 2~3 组"模板-轨迹-精灵体"结构。每组中：模板对象为蓝(1)色的 4-连通单色区域（3~6 像素，形状不规则）；精灵体为红(2)或绿(3)色的 4-连通单色小图形（3~5 像素，形状不规则，与模板形状不同）；两者之间由一条黄(4)色 4-连通路径（轨迹）相连，路径宽度 1 像素，长度 3~8 像素不等。网格中另有若干灰(5)单像素标记散布在模板附近（模板上方或下方 1~3 行范围内），部分标记在印章后会被精灵体像素包围（嵌入），部分不会（孤立）。各组之间互不相邻（边界框间距 >= 2）。生成约束：每组的轨迹长度奇偶性不全相同（保证需要对比示例来确认奇偶规则）。

**规则**：
1. 识别每组结构：蓝(1)模板、与之通过黄(4)轨迹相连的彩色精灵体（非蓝非黄非黑非灰的 4-连通区域）。
2. 计算每条黄(4)轨迹的像素总数（不含模板和精灵体自身的像素）。
3. 裁剪精灵体的边界框，保持其内部形状和颜色不变。
4. 若轨迹长度为奇数，将精灵体印章到模板正下方（精灵体顶边紧贴模板边界框底边的下一行）；若为偶数，印章到模板正上方（精灵体底边紧贴模板边界框顶边的上一行）。精灵体左边缘与模板左边缘对齐。仅粘贴非背景像素。
5. 印章完成后，检查所有灰(5)标记像素：若某灰像素的 4-邻域中有 3 个或以上像素为同一精灵体颜色（即被精灵体"嵌入"），则将该灰像素修补为包围它的精灵体颜色。
6. 未被嵌入的灰(5)标记像素保留原色。
7. 黄(4)轨迹在输出中擦除为黑(0)背景。

**关键洞察**：轨迹在参考题中是运动路径，此题中轨迹不引发运动，而是作为"编码线"——其长度的奇偶性隐式编码了印章方向。单看一个示例无法区分"上印章"和"下印章"的规则来源，必须对比不同轨迹长度的组才能归纳奇偶规则。

## 新题 6：镜像周期延伸中的孔洞守恒

**组合逻辑**：[周期延伸/长度即周期](创新：每个周期内执行一次镜像翻转而非简单复制) + [镜像](创新：镜像交替应用于周期副本) + [膨胀](创新：延伸区域的外框膨胀一像素作为边界光晕) + [封闭孔洞/孔洞保留不填](创新：孔洞在镜像和膨胀中均必须保留)

**来源原语**：周期延伸/长度即周期/分隔列(1ae2feb7)、镜像(6d0aefbc)、膨胀/封闭孔洞/孔洞保留不填(5adee1b2)

**依赖链**：分隔列一侧有带孔洞的彩色对象，对象宽度为延伸周期；向另一侧延伸时，奇数周期副本做左右镜像、偶数周期副本保持原样；每个副本外框膨胀一像素画光晕色边框；孔洞在镜像和膨胀中均保留（光晕不填入孔洞内部）。周期→镜像交替→膨胀→孔洞保留四个约束同时作用。

带孔洞的对象以自身宽度为周期向分隔列对面延伸，奇数次副本镜像翻转，每个副本外扩一像素光晕，孔洞全程保留不填。

**输入结构**：约 12x22 的网格，背景黑(0)。一条竖直灰(5)分隔列（宽 1 像素）将网格分为左右两半。左半包含 1~2 个彩色 4-连通对象（使用红(2)或蓝(1)），每个对象宽 3~4 列、高 3~5 行，对象内部包含至少一个封闭孔洞（即被对象像素完全包围的黑(0)区域，大小 1~2 像素）。右半为空白目标区域。左半另有一个 2x2 图例块紧贴网格左边缘：左列为对象色，右列为对应光晕色（使用绿(3)、黄(4)等）。右半宽度足够容纳至少 3 个周期的延伸。生成约束：对象不触碰分隔列（至少间隔 1 列），对象的形状在左右镜像后不与自身完全相同（保证镜像步骤可观察）。

**规则**：
1. 识别灰(5)分隔列。识别左半的彩色对象及其封闭孔洞。识别左边缘图例块，建立对象色→光晕色映射。
2. 对每个对象，取其边界框宽度 W 作为延伸周期。
3. 从分隔列右侧第一列开始，逐周期向右绘制对象副本：
   - 第 1 个副本（奇数）：将对象左右镜像后绘制。
   - 第 2 个副本（偶数）：保持对象原样绘制。
   - 第 3 个副本（奇数）：再次镜像。依此交替。
   - 每个副本的垂直位置与原对象相同（顶边行号一致）。
   - 副本之间紧密排列，无间隔。
   - 延伸直到下一个副本的任何像素超出网格右边界时停止（不绘制不完整的副本）。
4. 对每个已绘制的副本（不含原始左半对象），将其边界框向四周各扩展 1 像素（裁剪到网格边界内），在扩展区域中仅将黑(0)背景像素涂为该对象的光晕色。但：若扩展区域中的某黑(0)像素位于该副本的封闭孔洞内部（即该黑像素被副本像素在 4-连通意义下完全包围），则不涂光晕色，保留黑(0)。
5. 不同副本的光晕若重叠，后绘制的（更右侧的）覆盖先绘制的。
6. 分隔列灰(5)像素保留不变。左半原始对象和图例块保留不变。

**关键洞察**：参考题中周期延伸是简单的同向复制，此题中每个周期交替镜像翻转——这意味着孔洞的位置在相邻副本中左右颠倒，而膨胀光晕必须识别每个副本各自的孔洞拓扑才能正确保留。单纯记住"孔洞不填"的规则不够，还必须在每个镜像副本中重新计算孔洞位置。

## 新题 7：行列乘积定位后的蛇径展直读出

**组合逻辑**：[提取/行列乘积完整](创新：乘积判据不直接输出子图而是定位蛇径的读取区域) + [展直/蛇形路径/遍历顺序](创新：展直不作用于整条蛇而仅作用于蛇在乘积区域内的子段) + [裁剪](创新：输出是蛇径子段展直后的单列而非矩形裁剪)

**来源原语**：提取/双色图像/行列乘积完整(b71a7747)、展直/蛇形路径/遍历顺序/端点/保留像素序(7b5033c1)、裁剪(a87f7484)

**依赖链**：网格中隐藏一个双色区域满足行列乘积完整条件——该区域覆盖的行列定义了一个"窗口"；一条多色蛇形路径穿过整个网格，蛇在窗口内的子段被截取；子段按遍历顺序展直为单列输出。乘积判据→窗口→蛇截取→展直，四步缺一不可。

网格中有一条贯穿的多色蛇形路径和一个隐藏的双色行列乘积区域；找到该区域覆盖的行列作为窗口，截取蛇在窗口内的子段，按遍历顺序展直为单列输出。

**输入结构**：约 15x15 的网格，背景黑(0)。网格中有两层结构叠加：(a) 一条 4-连通蛇形路径贯穿网格，蛇身每像素颜色不全相同，使用红(2)、绿(3)、蓝(1)中的若干种轮替，蛇恰好有两个端点；(b) 一组由黄(4)和橙(7)两种颜色构成的像素散布在网格中（不与蛇重叠），这两种颜色的像素恰好占据某些行和某些列的完整交叉（即它们的行集 R 和列集 C 的笛卡尔积 R x C 中每个位置都被黄或橙占据，且不被其他颜色占据）。其余非蛇非乘积区域为黑(0)背景。蛇路径穿过乘积区域所在的若干行列，在窗口内有连续的子段。生成约束：蛇在窗口（R x C 定义的矩形）内的子段是连续的（蛇进入窗口后不离开再重新进入）；蛇在窗口内的子段长度 >= 3。

**规则**：
1. 找到满足行列乘积完整条件的唯一颜色对：枚举所有非背景非蛇色的颜色对，找到一对颜色使得它们共同占据的像素恰好是某行集 R 和列集 C 的笛卡尔积。记录 R 和 C。
2. 定义窗口为行集 R 和列集 C 所界定的矩形区域（min(R) 到 max(R) 行，min(C) 到 max(C) 列）。
3. 找到蛇路径的两个端点，以行号较小者为起点（行号相同取列号较小者），沿 4-连通路径遍历整条蛇。
4. 在遍历过程中，记录蛇进入窗口后连续经过的所有蛇身像素（即位于窗口矩形内的连续子段），按遍历顺序排列。
5. 输出一个 K x 1 的单列网格（K 为子段像素数），每行一个像素，颜色为蛇身子段按遍历顺序的对应颜色。

**关键洞察**：行列乘积区域在参考题中是直接提取的输出目标，此题中它仅作为"定位器"——定义一个隐式窗口来截取蛇路径的某段。求解者必须先发现行列乘积结构来确定窗口，再用蛇的遍历逻辑来读取窗口内的内容，两种来自不同参考题的判据在此交汇于同一空间区域。

## 新题 8：缺陷修补与旋转补全的循环依赖

**组合逻辑**：[修补/嵌入与孤立](创新：嵌入判定需在旋转补全的假设下进行而非直接判定) + [旋转/对称补全](创新：补全的前提是先识别出缺陷并排除) + [射线延伸/边缘指示方向](创新：边缘线指示旋转中心而非射线方向)

**来源原语**：修补/嵌入与孤立/主体对象/标记像素(8886d717)、旋转/对称补全/四次旋转闭合/正方形区域(e40b9e2f)、射线延伸/边缘线/边缘指示方向(8886d717)

**依赖链**：主体对象接近四次旋转对称但含有标记色缺陷；边缘线的位置（行或列）指示旋转中心；求解者必须先假设旋转对称成立来判断哪些标记是"嵌入缺陷"（在旋转对应位置上应有主体色）、哪些是"真实特征"（所有旋转位置上一致存在）；修补嵌入缺陷后再执行旋转补全。修补和补全互为前提——不修补则无法识别对称轴，不知道对称轴则无法判断哪些是缺陷。

一个接近旋转对称的主体对象中混有标记色缺陷像素；边缘线指示旋转中心；只有在旋转对应位置缺少同色像素的标记才是缺陷（修补为主体色），其余标记是真实特征（保留并参与旋转补全）。

**输入结构**：约 15x15 的网格，背景黑(0)。网格的某一边（上边或左边）有一条贯穿的边缘线，颜色为灰(5)，宽 1 像素。网格中央有一个蓝(1)色的大型 4-连通主体对象（约 8x8 像素范围内，占据 15~25 个像素），对象整体接近四次旋转对称但不完全——部分位置缺少像素（需要补全），另有 2~4 个红(2)标记像素散布在对象内部或紧邻对象。标记像素分两类：(a) "缺陷标记"——该标记的旋转对应位置（0/90/180/270度）上其他三个位置要么是蓝(1)主体色要么为空，即该标记打断了旋转对称性；(b) "特征标记"——该标记的旋转对应位置上至少还有一个位置也是红(2)标记或将在补全后也成为标记。旋转中心由边缘线确定：若边缘线在上边（水平），则旋转中心的行坐标 = 边缘线行号，列坐标 = 主体对象边界框的水平中心（四舍五入）；若边缘线在左边（竖直），则旋转中心的列坐标 = 边缘线列号，行坐标 = 主体对象边界框的竖直中心。生成约束：至少有 1 个缺陷标记和 1 个特征标记；修补缺陷后主体对象恰好可以四次旋转闭合补全。

**规则**：
1. 识别边缘线（灰(5)，贯穿某一边）和主体对象（蓝(1)最大 4-连通分量）。
2. 确定旋转中心：若边缘线水平（在第 r 行），中心 = (r, 主体bbox水平中心列)；若边缘线竖直（在第 c 列），中心 = (主体bbox竖直中心行, c)。中心坐标取整数（边界框宽或高为偶数时取 floor((left+right)/2) 和 floor((top+bottom)/2)）。
3. 对每个红(2)标记像素 P，计算其在 90 度、180 度、270 度旋转下的三个对应位置。若这三个位置中没有任何一个也是红(2)标记，则 P 为缺陷标记，将其修补为蓝(1)主体色。否则 P 为特征标记，保留红(2)。
4. 修补完成后，对所有蓝(1)像素执行四次旋转对称补全：每个蓝(1)像素在 90/180/270 度旋转位置也涂为蓝(1)（若该位置在网格内且为黑(0)背景）。
5. 对所有红(2)特征标记也执行同样的旋转补全：每个红(2)像素在旋转位置也涂为红(2)。若旋转位置已有蓝(1)，红(2)覆盖蓝(1)。
6. 边缘线在输出中保留不变。

**关键洞察**：修补和旋转补全形成循环依赖：要判断标记是否为缺陷需要知道旋转中心和对称假设，而正确的对称只有在缺陷被修补后才成立。求解者必须同时推理"如果这是对称的，那么哪些标记破坏了对称"，这种"假设-验证"式推理在单纯的线性流水线中不会出现。

## 新题 9：累积吸附中的颜色互换分层

**组合逻辑**：[滑动/碰撞阻挡/累积影响后续停靠](已有) + [重涂色/颜色互换且偏移](创新：碰撞时不统一涂为吸附色而是与接触面颜色互换) + [分割](创新：互换后接触面分裂出新的颜色层)

**来源原语**：滑动/碰撞阻挡/最短基方向吸附/累积影响后续停靠/前景对象/吸附体(4093f84a)、重涂色/颜色互换且偏移(fc4aaf52)、分割(fc4aaf52)

**依赖链**：多个彩色对象向中央吸附体滑动；每个对象到达时，其面向吸附体的一排像素（接触层）与吸附体表面的一排像素互换颜色；互换后的像素成为新吸附体表面的一部分，影响下一个对象到达时的互换对象。累积→互换→新表面→下次互换形成迭代依赖。

多个彩色对象逐一向灰(5)吸附体滑动并贴合；每次贴合时，对象的接触层与吸附体的接触面互换颜色，换色后的新表面参与下一次互换。

**输入结构**：约 15x15 的网格，背景黑(0)。网格中央有一个灰(5)矩形吸附体（约 3x3 ~ 4x4）。吸附体上下左右分布 3~4 个单色矩形对象（每个 1~2 行/列厚，3~5 像素长），颜色分别使用红(2)、蓝(1)、绿(3)、黄(4)中的不同色。每个对象与吸附体在同一行或同一列上对齐，且到吸附体的基方向距离不全相同（保证存在明确的到达顺序）。生成约束：每个对象在其滑动方向上到吸附体之间无其他对象阻挡（初始时路径畅通）。

**规则**：
1. 识别灰(5)吸附体（最大的灰色 4-连通分量）和所有其他非黑非灰的前景对象。
2. 对每个前景对象，计算其沿最短基方向（上/下/左/右中使其最快接触吸附体的方向）到吸附体表面的距离。
3. 按距离从小到大排序处理对象（距离相同时，按对象边界框左上角的行号升序，再按列号升序）。
4. 处理每个对象时：
   a. 将对象沿最短基方向滑动，直到紧贴当前吸附体（含已累积部分）的表面。
   b. 定义"接触层"：对象面向吸附体的那一排像素（例如对象从右侧靠近，则接触层为对象最左列的像素）。定义"吸附面"：吸附体在同一方向上与接触层正对的那一排像素。
   c. 接触层中每个像素的颜色与吸附面中对应位置的像素的颜色互换。即：接触层像素变为原吸附面颜色，吸附面像素变为原接触层颜色。
   d. 互换后，整个对象（含已变色的接触层）合并为吸附体的一部分，参与后续对象的碰撞和互换计算。
5. 所有对象处理完毕后，输出最终网格。

**关键洞察**：参考题中滑动吸附后统一涂灰，此题中每次贴合执行颜色互换而非统一重涂——这意味着吸附体的表面颜色随着每次碰撞而变化，后到的对象看到的"表面色"取决于先前所有互换的历史。处理顺序（由距离决定）直接影响最终颜色分布，改变任一对象的到达顺序会导致完全不同的结果。

## 新题 10：侧边定色与面积排名的擦除竞争

**组合逻辑**：[接触侧定色](创新：侧边颜色不用于重涂而用于分组) + [面积排名](创新：排名在组内而非全局进行) + [擦除/最少标记者选中](创新：擦除对象不由标记数决定而由组内面积排名决定) + [填充](创新：擦除腾出的空间由同组存活者填充)

**来源原语**：接触侧定色/侧边标记/多色对象(c3fa4749)、面积排名(a87f7484)、擦除(54db823b)、填充/最近角距离(4a1cacc2)

**依赖链**：每个对象的侧边标记颜色将对象分入不同组；组内对象按面积排名，面积最小者被擦除；擦除后腾出的空间由同组中面积最大的对象向被擦除者方向填充矩形。分组→组内排名→擦除→定向填充四步耦合。

多个带侧边标记的对象按标记色分组，每组中面积最小的对象被擦除，腾出的空间由同组面积最大的对象朝被擦者方向填充矩形。

**输入结构**：约 18x18 的网格，背景黑(0)。包含 4~6 个蓝(1)色 4-连通单色对象（形状不规则，面积 4~12 像素不等），各对象互不相邻（边界框间距 >= 2）。每个对象的边界框恰好有一条边紧贴一个单像素宽的侧边标记条：该标记条由红(2)或绿(3)像素组成，长度等于对象在该边上的跨度。同色标记的对象属于同组。生成约束：红(2)标记组和绿(3)标记组各至少 2 个对象；每组内对象面积互不相同（保证面积排名唯一）。

**规则**：
1. 识别所有蓝(1)对象及其侧边标记。每个对象的侧边标记是紧贴其边界框某一边的非蓝非黑色条（红(2)或绿(3)），标记的颜色确定该对象所属的组。
2. 在每组内，按对象的前景像素面积从大到小排名。
3. 每组中面积最小的对象（排名末位）连同其侧边标记一起擦除为黑(0)背景。
4. 每组中面积最大的对象（排名首位）执行填充扩展：从该对象的边界框出发，向被擦除对象所在的方向（取两对象边界框中心的主基方向：上/下/左/右，取位移绝对值最大的轴方向）画一个矩形，矩形宽度等于该最大对象边界框在垂直于扩展方向上的跨度，矩形延伸到被擦除对象原边界框的近边位置（含），颜色为蓝(1)。填充不覆盖已有的非背景像素。
5. 组内排名居中的对象（既非最大也非最小）保留不变，其侧边标记也保留。
6. 最大对象的侧边标记保留不变。

**关键洞察**：侧边标记在参考题中用于决定重涂颜色，此题中标记颜色不影响任何像素的最终颜色——它纯粹是分组标签。面积排名在参考题中用于选出赢家，此题中排名同时决定"谁死"（最小者擦除）和"谁扩张"（最大者填充），而填充方向又依赖于被擦除者的空间位置。分组、排名、擦除、填充四个逻辑在空间和颜色两个维度上交织。
