## 新题 1：镜像异或差异显影

**组合逻辑**：[镜像/mirror] + [异或合成/xor_compositing]（创新：镜像不用于平铺而用于对齐，对齐后做异或提取差异点，两步不可分离）

**来源原语**：mirror 来自 67e8384a（原用于双轴反射平铺）；xor_compositing 来自 31d5ba1a（原用于上下半区比较）；alignment 来自 31d5ba1a

**依赖链**：镜像变换决定对齐方式 → 对齐方式决定异或比较的像素配对 → 配对结果决定输出。若不做镜像直接比较则配对错误，异或结果无意义；若不做异或则镜像结果无用途。

将输入网格的左右两半做镜像对齐后异或合成，输出仅保留两半在反射对称下不一致的像素位置。

**输入结构**：
- 一个偶数列数的矩形网格（约 10x12 至 14x16），背景为黑(0)。
- 单一前景色蓝(1)形成一个连通或非连通的图案，分布在网格的左半区和右半区。
- 左半区图案与右半区图案在左右镜像下**近似但不完全对称**：有 2 至 5 个像素位置存在差异（一侧为前景而镜像对应位置为背景，或反之）。
- 生成约束：差异像素不集中在同一行或同一列，至少分布在 2 行以上；前景像素总数占网格面积的 15%-40%。

**规则**：
1. 沿网格的垂直中线将输入分为左半区 L 和右半区 R，每半区宽度为总列数的一半。
2. 将右半区 R 做左右镜像翻转，得到 R'。
3. 逐像素比较 L 与 R'：
   - 若 L 的某位置为前景(1)且 R' 对应位置为背景(0)，或反之（恰好一个为前景），该位置输出红(2)。
   - 若 L 和 R' 对应位置同为前景或同为背景，该位置输出黑(0)。
4. 输出网格的尺寸为输入高度 x 半区宽度（即高度不变，宽度减半）。

**关键洞察**：输出不是简单的左右对比——右半区必须先做镜像翻转才能与左半区逐位对齐。红色像素精确标记了输入图案偏离完美左右对称的位置，相当于"对称性缺陷检测"。

## 新题 2：连通计数编码放大倍率

**组合逻辑**：[连通检测/connected_component_detection] + [计数/counting]（创新：计数结果不用于选择对象，而用于编码数值） → [像素放大/pixel_upscale]（创新：放大倍率由计数结果动态决定，非固定值）

**来源原语**：connected_component_detection 来自 2c0b0aff（原用于筛选特定面积的连通体数量）；counting 来自 2c0b0aff/dce56571；pixel_upscale 来自 e7a25a18/f25fbde4（原使用固定倍率 2）；specific_area_filter 来自 2c0b0aff；crop 来自 73ccf9c2

**依赖链**：面积筛选决定哪些连通体被计入 → 计数结果成为放大倍率 → 倍率决定输出尺寸和内容。删掉计数环节则倍率未知；删掉面积筛选则计数结果错误；删掉放大则计数无用途。

将输入中特定面积的标记色连通体数量作为放大倍率，对模板图案进行相应倍数的像素放大。

**输入结构**：
- 一个矩形网格（约 15x20），背景为黑(0)。
- 一条全宽的灰(5)水平分隔线将网格分为上下两个区域。
- 上方区域：一个红(2)前景形状，由 4-连通的红色像素构成，占 4 至 12 个像素，形态为非矩形的稀疏连通图形（包含背景间隙）。这是"模板"。
- 下方区域：若干蓝(1)标记像素散布在黑色背景上。这些蓝色像素形成多个 4-连通分量，各分量面积（像素数）从 1 到 4 不等。
- 生成约束：下方区域中面积恰好为 2 的蓝色 4-连通分量数量 N 为 2 或 3；模板的紧凑包围框在放大 N 倍后不超过 30x30 像素；不同蓝色分量之间 4-连通不相连。

**规则**：
1. 在下方区域中，识别所有蓝(1)像素的 4-连通分量。
2. 统计其中面积恰好为 2 个像素的分量数量，记为 N。
3. 将上方区域中红(2)模板裁剪到其紧凑包围框（包含包围框内的背景间隙）。
4. 将裁剪后的模板做 N 倍像素放大：每个像素替换为 NxN 的同色方块。
5. 输出：仅放大后的模板（不包含分隔线和下方区域）。

**关键洞察**：下方区域的蓝色像素不是装饰——面积为 2 的连通分量（"像素对"）的数量就是放大倍率。面积为 1（孤立点）和面积 >=3 的分量是干扰项，仅 2-像素对被计入。求解者需要同时发现面积筛选条件和计数-倍率映射关系。

## 新题 3：对称性决定射线纹样

**组合逻辑**：[对称检测/symmetry_detect]（创新：检测结果不用于选择/裁剪对象，而作为条件分支控制后续操作的形态） → [射线延伸/ray_extend] + [奇偶交替/parity_alternation]（创新：交替模式受对称检测结果控制，有条件启用）

**来源原语**：symmetry_detect 来自 73ccf9c2（原用于筛选唯一非对称对象进行裁剪）；ray_extend 来自 97999447（原用于从标记向边缘交替填充）；parity_alternation 来自 97999447

**依赖链**：对称检测决定每个对象的属性标签 → 标签决定对应射线的纹样模式（交替或实心） → 纹样模式决定输出中射线的视觉形态。若不做对称检测则无法区分两种射线模式；若不画射线则对称检测结果无法体现。

根据每个前景对象是否具有垂直镜像对称性，从其相邻标记像素发出不同纹样的水平射线——对称对象对应交替条纹射线，非对称对象对应实心射线。

**输入结构**：
- 一个矩形网格（约 15x20），背景为黑(0)。
- 3 至 5 个蓝(1)的小型 8-连通前景对象，每个占 3 至 6 个像素，形态各异（非固定形状，由结构属性——连通性、像素数、包围框尺寸——定义）。各对象在垂直方向上互不重叠（包围框的行范围不交），相邻对象间隔至少 3 行。
- 每个对象的紧凑包围框左侧一列处（同行范围内的最上行）放置一个红(2)标记像素。标记像素与对象之间无其他前景像素。
- 全部对象中，恰好有一个对象的前景掩码在其紧凑包围框内不是左右镜像对称的；其余对象均为左右镜像对称。
- 生成约束：射线向右延伸不会经过其他对象的像素位置（对象间列范围充分分离或行范围不重叠已保证此点）。

**规则**：
1. 对每个蓝(1)对象，计算其紧凑包围框，提取前景掩码，检测该掩码是否与其左右翻转完全相同（左右镜像对称测试）。
2. 从每个红(2)标记像素出发，向右（列递增方向）逐格填充直到网格右边界：
   - 若该标记对应的蓝色对象通过了对称测试（对称）：以奇偶交替方式填充——偏移量为偶数（0, 2, 4, ...）的格填红(2)，偏移量为奇数（1, 3, 5, ...）的格填灰(5)。标记像素本身为偏移 0（偶数），保持红色。
   - 若该标记对应的蓝色对象未通过对称测试（非对称）：全部填充为实心红(2)，不交替。
3. 射线仅覆盖背景(0)像素；若射线路径上遇到蓝(1)对象像素则跳过该像素（保留蓝色），继续在后续背景格上按同一偏移量序列填充。
4. 输出：在原网格上叠加所有射线后的结果。

**关键洞察**：射线的视觉模式（条纹 vs. 实心）编码了其相邻对象的几何属性。求解者必须注意到部分射线有灰色间隔而另一些没有，然后将这一差异与对象是否左右对称建立关联——交替条纹意味着对称对象，实心意味着非对称对象。

## 新题 4：十字交叉清除与粗粒度压缩

**组合逻辑**：[连线/draw_line] + [画布全长十字线/canvas_spanning_cross]（已有） → [交叉点重置背景/intersect_reset_bg]（创新：原用于实心方块的十字交叉，此处用于不同颜色标记像素的十字交叉） → [压缩/compress]（创新：压缩的输入不是原始标记而是经过交叉清除后的十字线残余）

**来源原语**：draw_line/canvas_spanning_cross 来自 41e4d17e（原用于空心矩形中心画十字）；intersect_reset_bg 来自 e9bb6954（原用于实心方块十字的交叉清除）；compress/coarse_block/array_layout 来自 e57337a4（原用于检测粗粒度块中标记像素的有无）

**依赖链**：标记像素位置决定十字线形态 → 不同颜色十字线的交叉位置被清除为背景 → 清除后的线段分布改变了各粗粒度块中的颜色分布 → 压缩结果取决于清除后的颜色分布而非原始标记位置。跳过交叉清除步骤会导致压缩结果错误。

从多个不同颜色的标记像素画出全长十字线，在不同颜色交叉点清除为背景后，将结果压缩为 3x3 的颜色编码图。

**输入结构**：
- 一个正方形网格，边长可被 3 整除（如 12x12 或 15x15），背景为黑(0)。
- 2 至 4 个孤立标记像素，每个颜色不同，从红(2)、绿(3)、黄(4)、橙(7)中选取。
- 任意两个标记像素不共享同一行或同一列。
- 生成约束：标记像素不在网格最外圈的边界行/列上；网格边长至少为 9。

**规则**：
1. 对每个标记像素，以该标记的颜色绘制一条全宽水平线（覆盖标记所在行的所有列）和一条全高垂直线（覆盖标记所在列的所有行）。标记像素本身是其十字线的交叉点。
2. 处理不同颜色十字线的交叉：若某格同时位于两个或更多不同颜色标记的水平线或垂直线上（即该格是多个十字线的重叠位置），则将该格重置为黑(0)背景。仅属于单一标记十字线的格保留该标记颜色。
3. 将清除后的网格划分为 3x3 的等大矩形粗粒度块。
4. 对每个粗粒度块：
   - 若块内全为背景(0)，输出黑(0)。
   - 若块内存在非背景像素，输出块内出现次数最多的非背景颜色。若出现次数相同，选择其标记像素距离网格中心（按曼哈顿距离）更近的那个颜色。
5. 输出：一个 3x3 的小网格。

**关键洞察**：十字线交叉处的清除在线段上制造了"断口"，这些断口改变了各粗粒度块中的颜色像素数量，从而影响压缩结果。仅靠标记像素的位置无法直接推算输出——必须先模拟十字线绘制和交叉清除，才能得到正确的压缩编码。

## 新题 5：反射平铺构建寻路迷宫

**组合逻辑**：[平铺/tiling] + [镜像/mirror] + [双轴反射/biaxial_reflection]（已有，用于生成对称迷宫结构） → [寻路/pathfinding] + [障碍触发转向/barrier_triggers_turn]（创新：寻路的迷宫不是直接给定的，而是由平铺操作动态生成的）

**来源原语**：tiling/mirror/biaxial_reflection 来自 67e8384a（原用于将整个输入做四象限镜像拼贴）；pathfinding/barrier_triggers_turn 来自 2dd70a9a（原用于在给定迷宫中按障碍转向规则寻路）

**依赖链**：小网格定义障碍布局 → 反射平铺将障碍布局扩展为四倍大的对称迷宫 → 寻路在平铺后的迷宫中执行。迷宫结构仅在平铺后才存在——原始小网格中起点到终点可能无有效路径，但平铺后路径可经由相邻象限的反射副本绕行。

将一个小网格做四象限镜像平铺以构建对称迷宫，然后在该迷宫中按障碍转向规则寻找路径。

**输入结构**：
- 一个小矩形网格（5x5 至 7x7），背景为黑(0)。
- 若干青(8)障碍像素分布在网格中。
- 一个绿(3)像素标记起点，一个红(2)像素标记终点。起点和终点不在网格最外圈边界上。
- 起点绿(3)像素恰好有一个相邻格（上下左右之一）为青(8)障碍，该障碍的反方向即为初始行进方向。
- 生成约束：经过 2x2 反射平铺后，从原始象限（左上）的绿色起点到原始象限的红色终点存在一条合法路径（遵循障碍转向规则）。

**规则**：
1. 将输入做 2x2 反射平铺，生成一个宽高各为原始两倍的网格：
   - 左上象限：原始输入。
   - 右上象限：原始输入做左右镜像。
   - 左下象限：原始输入做上下镜像。
   - 右下象限：原始输入做上下+左右镜像。
2. 在平铺后的网格中，将所有反射产生的绿(3)和红(2)副本像素重新标记为青(8)障碍。仅保留左上象限中的原始绿色像素作为起点、原始红色像素作为终点。
3. 从起点出发，初始方向为起点相邻障碍的反方向。路径沿当前方向直行，遇到以下情况时转向 90 度（优先尝试左转，左转不可行则右转；两者都不可行则路径终止）：
   - 当前方向的下一格为青(8)障碍。
   - 当前方向的下一格超出平铺网格边界。
4. 当路径的当前方向下一格为红(2)终点时，路径结束。
5. 将路径经过的所有格（不含起点和终点）涂为绿(3)。
6. 输出：平铺后的完整网格，叠加绿色路径。

**关键洞察**：小输入网格本身不是完整的迷宫——反射平铺将障碍布局扩展为一个四倍面积的对称迷宫，路径可以穿越象限边界利用反射副本中的通道。同时，反射产生的起点/终点副本被转化为额外障碍，进一步塑造迷宫结构。求解者必须先完成平铺，才能确定路径。

## 新题 6：笛卡尔积填充受矩形包含关系重涂色

**组合逻辑**：[填充/fill] + [边缘标记笛卡尔积/edge_marker_cartesian_product]（已有，用于生成交叉格点） + [重涂色/recolor]（创新：填充颜色不固定，由交叉格点是否位于空心矩形内部动态决定） + [原对象遮挡叠加/object_occludes_overlay]（创新：原用于矩形遮挡叠加层，此处用于矩形轮廓阻挡填充）

**来源原语**：fill/edge_marker_cartesian_product 来自 2281f1f4（原用于在行列交叉点统一填红色）；hollow_rectangle/object_occludes_overlay 来自 41e4d17e（原用于矩形遮挡十字线）；recolor 来自 1da012fc

**依赖链**：边缘标记决定笛卡尔积格点位置 → 空心矩形的空间位置决定每个格点的包含关系 → 包含关系决定填充颜色（矩形内用矩形颜色，矩形外用默认色）。删掉笛卡尔积则无格点可填；删掉包含判断则颜色全部相同，退化为原题。

计算边缘标记行列的笛卡尔积交叉点，根据每个交叉点是否落在某空心矩形内部来决定其填充颜色。

**输入结构**：
- 一个矩形网格（约 12x12 至 15x15），背景为黑(0)。
- 黄(4)标记像素：2 至 4 个位于顶行（标记列），2 至 4 个位于最右列（标记行）。
- 1 至 3 个空心矩形分布在网格内部（不触及网格边界行/列），每个矩形的轮廓用不同颜色绘制（从蓝(1)、绿(3)、橙(7)中选取），轮廓宽度为 1 像素，内部为黑(0)背景。矩形之间不重叠、不相邻。
- 生成约束：至少 2 个笛卡尔积交叉点落在某个矩形的严格内部（不在轮廓上），至少 2 个交叉点落在所有矩形外部；没有交叉点恰好落在矩形轮廓像素上。

**规则**：
1. 从顶行标记确定选中的列集合，从最右列标记确定选中的行集合。
2. 计算行集合与列集合的笛卡尔积，得到所有交叉点坐标。
3. 对每个交叉点：
   - 若该点严格位于某个空心矩形的内部（被轮廓完全包围，不在轮廓上），填充该矩形的轮廓颜色。
   - 若该点位于所有矩形外部，填充红(2)。
   - 若该点恰好位于矩形轮廓像素上（由生成约束保证不发生），轮廓保持不变。
4. 所有其他像素（背景、标记、矩形轮廓）保持不变。
5. 输出：叠加填充后的完整网格。

**关键洞察**：填充颜色不是统一的——交叉点落在不同矩形内部时会"继承"该矩形的颜色，落在外部则为默认红色。求解者必须同时发现笛卡尔积规则（确定哪些位置被填充）和包含关系规则（确定填充什么颜色），两者缺一不可。

## 新题 7：对称性决定滑动方向

**组合逻辑**：[对称检测/symmetry_detect]（创新：检测结果不用于选择/筛选，而作为条件分支决定运动方向） → [滑动/slide]（创新：滑动方向不固定为"向矩形靠近"，而由对称性动态决定为靠近或远离）

**来源原语**：symmetry_detect 来自 73ccf9c2（原用于筛选唯一非对称对象）；slide/nearest_distance 来自 d6e50e54（原用于标记像素向矩形滑动）；rectangle 来自 d6e50e54

**依赖链**：对称检测为每个对象赋予属性标签（对称/非对称） → 标签决定滑动方向（吸引/排斥） → 方向与距离共同决定最终位置。若不做对称检测则不知道方向；若不做滑动则对称检测无用途。

根据每个前景对象是否水平镜像对称来决定其滑动方向——对称对象向中央矩形靠拢，非对称对象向网格边缘远离。

**输入结构**：
- 一个矩形网格（约 15x15），背景为黑(0)。
- 网格中央偏中的位置有一个实心灰(5)矩形（约 3x4 至 5x6 像素）。
- 4 至 6 个小型 8-连通单色前景对象分布在矩形周围，每个对象 3 至 5 个像素，各自使用不同颜色（从红(2)、绿(3)、蓝(1)、黄(4)、橙(7)、青(8)中选取）。
- 每个对象与灰色矩形在水平方向或垂直方向上对齐（对象的包围框中心行与矩形的某行重叠，或中心列与矩形的某列重叠），且对齐轴明确唯一。
- 部分对象的前景掩码在其紧凑包围框内是水平镜像对称的，部分不是。
- 生成约束：各对象的滑动路径互不冲突（不经过其他对象或矩形）；非对称对象滑动到边缘后不超出网格。

**规则**：
1. 对每个前景对象，在其紧凑包围框内检测前景掩码是否水平镜像对称（左右翻转后完全重合）。
2. 对称对象：沿其与灰色矩形的对齐轴，向矩形方向滑动，直到对象的最近边缘与矩形边界相邻（间隔恰好 1 个背景像素）。
3. 非对称对象：沿其与灰色矩形的对齐轴，向远离矩形的方向滑动，直到对象的最远边缘与网格边界相邻（对象紧贴网格边缘，间隔 0 像素）。
4. 灰色矩形保持不变。各对象独立处理，原位置清除为背景。

**关键洞察**：对象的几何属性（对称 vs 非对称）决定了它的运动行为——对称者被吸引，非对称者被排斥。求解者需要从多个示例中发现这一关联：在不同示例中，同一位置的对象可能因形状不同而向相反方向移动。

## 新题 8：相邻簇面积编码射线长度

**组合逻辑**：[连通检测/connected_component_detection] + [计数/counting]（创新：不计连通体数量而计单个连通体的面积，面积值编码后续操作的参数） → [射线延伸/ray_extend] + [奇偶交替/parity_alternation]（创新：射线长度不是延伸到边界而是由面积值决定的有限长度）

**来源原语**：connected_component_detection 来自 2c0b0aff；counting 来自 2c0b0aff/dce56571（原用于计数或计面积）；ray_extend/parity_alternation 来自 97999447（原射线延伸到画布边缘）

**依赖链**：蓝色簇的面积决定射线长度参数 → 长度参数决定射线的终止位置 → 终止位置决定交替纹样的实际范围。若不计面积则不知射线在哪里停；若不画射线则面积值无用途。

每个标记像素旁的蓝色簇面积决定从该标记出发的交替射线长度。

**输入结构**：
- 一个矩形网格（约 12x18），背景为黑(0)。
- 3 至 5 个红(2)标记像素，各在不同行，全部位于同一列（如第 3 列）。
- 每个标记像素的左侧（第 0 列至标记列-1 列）有一个蓝(1)像素簇，构成一个 4-连通分量。各簇面积（像素数）互不相同，范围在 2 至 5 之间。
- 生成约束：每个标记右侧到网格右边界的距离不小于最大簇面积的 2 倍（保证射线不越界）；不同行的蓝色簇和射线互不干扰。

**规则**：
1. 对每个红(2)标记像素，识别其左侧的蓝(1) 4-连通分量，计算其面积 N（像素数）。
2. 从标记像素出发，向右绘制一条长度为 2N 格的射线（标记像素本身为偏移 0，射线覆盖偏移 0 至 2N-1 的格）。
3. 射线内部按奇偶交替填充：偏移为偶数（0, 2, 4, ...）的格填红(2)，偏移为奇数（1, 3, 5, ...）的格填灰(5)。
4. 偏移 2N 及之后的格保持黑(0)背景不变。
5. 蓝色簇在输出中保持不变。

**关键洞察**：蓝色簇不是装饰——每个簇的像素数直接控制对应射线的长度（每个蓝色像素贡献 2 格射线）。求解者需要从不同行射线长度的差异中发现面积-长度的 2 倍映射关系。

## 新题 9：标记计数编码粗粒度块旋转角度

**组合逻辑**：[计数/counting]（创新：计数结果不用于选择或编码存在性，而编码旋转角度） → [旋转/rotate]（创新：旋转角度不是固定值或累计值，而是由每个块内的局部计数独立决定） → [擦除/erase]（创新：旋转指令标记在执行后被擦除，输出中不留痕迹）

**来源原语**：counting 来自 2c0b0aff/dce56571；rotate/successive_rotation_per_slot 来自 8e5a5113（原使用按槽位累计的固定 90 度旋转）；erase 来自 98c475bf/e9bb6954；coarse_block/array_layout 来自 e57337a4

**依赖链**：橙色标记的数量编码旋转角度 → 旋转改变块内图案方向 → 标记在旋转后被擦除，消除了角度线索。求解者必须从多个示例中反推"标记计数 = 旋转90度的次数"这一隐藏编码。

输入网格的每个粗粒度块中，橙色标记像素的数量决定该块被旋转多少个 90 度；旋转后标记被擦除。

**输入结构**：
- 一个正方形网格，边长可被 3 整除（如 12x12 或 15x15），背景为黑(0)。
- 网格在概念上被等分为 3x3 共 9 个等大的正方形粗粒度块。
- 每个块内包含：
  - 一个蓝(1)前景小图案（3 至 6 像素，4-连通，形态各异且非轴对称——这保证旋转后的方向变化可被观察到）。
  - 0 至 3 个橙(7)标记像素，放置在块内的背景(0)位置上（不与蓝色图案重叠）。
- 生成约束：9 个块中的标记数量至少有两个不同的值（如某些块 0 个、某些 1 个、某些 2 个）；没有块超过 3 个标记。

**规则**：
1. 将网格等分为 3x3 共 9 个正方形块。
2. 对每个块，计数其中橙(7)像素的数量 K。
3. 将该块的全部内容（蓝色图案 + 背景 + 橙色标记）整体做 K x 90 度顺时针旋转。
4. 旋转完成后，将该块内所有橙(7)像素替换为黑(0)背景（擦除标记）。
5. 将 9 个处理后的块重新拼装为输出网格。

**关键洞察**：橙色标记是"旋转指令"——0 个标记表示不旋转，1 个表示转 90 度，2 个表示转 180 度，3 个表示转 270 度。指令在执行后被擦除，输出中看不到橙色像素。求解者必须对比输入输出中各块内蓝色图案的方向变化，才能反推出标记数量与旋转角度的编码关系。

## 新题 10：非对称选择裁剪与内部孔洞交替填充

**组合逻辑**：[对称检测/symmetry_detect] + [异常值选择/outlier_selection]（已有，用于选择唯一非对称对象） → [裁剪/crop]（已有） → [射线延伸/ray_extend] + [填充/fill]（创新：射线不向外延伸而向内填充封闭孔洞，填充使用交替颜色模式）

**来源原语**：symmetry_detect/unique_asymmetric/outlier_selection 来自 73ccf9c2（原用于裁剪唯一非对称对象）；crop 来自 73ccf9c2；ray_extend 来自 97999447（原用于水平向右延伸）；fill 来自 2281f1f4；parity_alternation 来自 97999447

**依赖链**：对称检测选出目标对象 → 裁剪提取目标 → 孔洞识别定位填充区域 → 交替填充生成最终输出。删掉对称检测则不知裁剪哪个对象；删掉孔洞填充则裁剪结果与参考题 73ccf9c2 无异；孔洞的形状和位置因对象的非对称性而每题不同，使得填充图案不可预测。

从多个前景对象中选出唯一非垂直对称者进行裁剪，并以交替颜色模式填充其内部封闭孔洞。

**输入结构**：
- 一个矩形网格（约 15x20），背景为黑(0)。
- 3 至 5 个蓝(1) 8-连通前景对象，每个占 8 至 15 个像素，在垂直方向上互不重叠（包围框行范围不交），相邻对象间隔至少 2 行。
- 每个对象内部恰好包含一个封闭孔洞：一个由黑(0)背景像素构成的 4-连通区域，被蓝色像素完全包围（从该区域内的任何像素出发，沿 4-连通路径无法到达网格边界而不穿过蓝色像素）。
- 全部对象中恰好一个的前景掩码在其紧凑包围框内不是左右镜像对称的（非对称对象）；其余均为左右镜像对称。
- 生成约束：非对称对象的孔洞至少跨 2 行（高度 >= 2）；所有对象的孔洞面积至少为 2 像素。

**规则**：
1. 对每个蓝(1)对象，计算其紧凑包围框，提取前景掩码，检测是否左右镜像对称。
2. 选出唯一非对称的对象。
3. 将该对象裁剪到其紧凑包围框。
4. 在裁剪结果中，识别内部封闭孔洞（不触及裁剪框边界的 4-连通黑色区域）。
5. 对孔洞逐列填充：对于孔洞覆盖的每一列，找到该列中孔洞的最顶行，从该行向下逐行填充——行偏移为偶数（0, 2, 4, ...相对于该列最顶孔洞行）的格填红(2)，行偏移为奇数（1, 3, 5, ...）的格填灰(5)。仅填充属于孔洞的格；非孔洞格不变。
6. 输出：裁剪后的对象，孔洞已被交替颜色填充。

**关键洞察**：对称检测选出目标（与参考题相同的机制），但后续操作完全不同——不是简单裁剪输出，而是对裁剪结果内部的封闭孔洞做交替填充。孔洞的形状和位置取决于非对称对象的具体几何结构，使得填充图案每题不同。求解者必须先发现对称性选择规则，再发现孔洞填充规则，缺一则无法求解。
