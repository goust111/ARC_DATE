## 新题 1：重力封口填色

**组合逻辑**：[重力下落](原有) + [面积区分角色](原有) + [洪泛填充](原有) + [标记色决定填充](原有) → 创新组合：重力改变轮廓几何使开口闭合，闭合后的区域按内部固定标记像素颜色填充

**来源原语**：重力下落、面积区分角色、大前景对象、小标记对象、触底停止（6ca952ad）；洪泛填充、封闭区域、标记在封闭区域内、标记像素（4b6b68e5）；标记色决定填充（444801d8）

**依赖链**：面积判断区分轮廓与标记 → 轮廓按重力下落 → 下落后轮廓与网格底部围成封闭区域 → 洪泛检测封闭性 → 标记像素恰在封闭区域内 → 标记颜色决定填充色。删除重力则无封闭区域，删除封闭性检测则不知填充范围，删除标记则不知填充颜色。

将大型开口轮廓按重力下落至底部，使其与网格底边围成封闭区域，然后用该区域内固定不动的标记像素颜色洪泛填充。

**输入结构**：
- 约 15x15 网格，背景黑(0)。
- 若干灰(5) 4-连通轮廓对象（每个面积 > 3 像素），形态为开口朝下的 U 形或 J 形（宽 3~6 像素，高 3~5 像素），悬浮在网格中上部（底边距网格底部至少 3 行）。不同示例中轮廓的具体形状应有变化（像素数和弯折方式不同），但都保持"底部开口"特征。
- 若干单像素标记点（面积 = 1），颜色各异（如红(2)、蓝(1)、绿(3)），分布在网格下半部，每个标记位于某个轮廓下落后将形成的封闭区域内。
- 生成约束：(a) 各轮廓下落后互不重叠且均触及网格底行或已落轮廓顶部；(b) 每个封闭区域内恰好一个标记像素；(c) 标记像素不落在任何轮廓的下落路径上。

**规则**：
1. 面积 > 3 的 4-连通单色对象为"轮廓对象"，面积 <= 3 的为"标记对象"。
2. 将所有轮廓对象按其边界框底行从大到小排序（底行行号最大的最先处理）。依次将每个轮廓整体向下平移，直到其边界框底行触及网格最后一行或已放置的轮廓/标记的最高占用行上方一行。
3. 标记对象保持原位置不动。
4. 下落完成后，从网格四条边界向内做 4-连通洪泛，标记所有可从边界到达且不穿越非黑像素的黑色像素为"外部"。
5. 剩余黑色像素为"封闭内部"。将每个 4-连通的封闭内部区域独立处理：找到其中唯一的标记像素，将该区域所有黑色像素重涂为该标记的颜色。
6. 标记像素本身被填充色覆盖。轮廓保持灰(5)。输出完整网格。

**关键洞察**：开口轮廓在空中不形成封闭区域，重力下落使其接触网格底边后才"封口"——封闭性是重力的结果而非输入的直接属性，填充依赖于这一涌现出的封闭性。

## 新题 2：对称轨道杯色传播

**组合逻辑**：[对称补全](创新：从恢复缺失像素改为推断缺失填充色) + [填充](原有) + [杯状轮廓](原有) + [追加封盖层](原有)

**来源原语**：对称补全、对称轨道、对称图案（e66aafb8）；杯状轮廓、填充、标记像素、标记色决定填充、追加封盖层（444801d8）

**依赖链**：杯的空间排布形成反射对称结构 → 部分杯有标记像素 → 对称轨道将有标记杯映射到无标记杯 → 无标记杯的填充色由对称伙伴的标记决定 → 填充所有杯内部 → 追加封盖层。删除对称分析则无法确定无标记杯的颜色，删除标记则无颜色来源。

对称排布的杯形轮廓中，部分杯有标记像素指示填充色，无标记杯的颜色通过全局反射对称从伙伴杯的标记推断，最后为所有杯填充并加盖。

**输入结构**：
- 约 14x14 网格，背景黑(0)。
- 4~8 个蓝(1)杯状轮廓，每个杯为朝上开口的 U 形（宽 3~5 像素，高 3~4 像素），由蓝(1)像素构成侧壁和底部。
- 杯的中心位置整体关于网格的垂直中轴呈左右反射对称排列（即左半区每个杯在右半区有一个镜像对应杯）。
- 部分杯的内部底行有一个非黑非蓝的标记像素（如红(2)、绿(3)、黄(4)、橙(7)等），指示该杯的填充色。
- 其余杯内部无标记像素，但其垂直中轴镜像对应的杯一定有标记。
- 生成约束：每对镜像杯中至少一个有标记；对称位置上标记颜色可以不同（即左右杯可独立着色）；如果两个杯都有标记，各自使用自己的标记色。

**规则**：
1. 识别所有蓝(1) 4-连通杯状轮廓对象（U 形，面积 >= 6 像素）。
2. 对每个杯，检查其内部（杯壁围成的黑色区域）是否有非黑非蓝标记像素。有则记录标记颜色。
3. 对无标记的杯，计算其关于网格垂直中轴（列坐标 = (网格宽度-1)/2）的镜像位置，找到该位置处的杯，取其标记颜色作为本杯的填充色。
4. 用确定的颜色填充每个杯的内部全部黑色像素（标记像素所在位置也被填充色覆盖）。
5. 在每个杯的开口正上方一行，绘制一段与杯内部宽度等长的水平色条（颜色与杯内填充色相同）作为"封盖"。
6. 输出完整网格。

**关键洞察**：单个无标记杯无法独立确定填充色——必须识别出杯群的全局反射对称结构，才能从镜像伙伴处"借"到颜色信息；对称性不是用于修复像素，而是用于传播语义属性（颜色）。

## 新题 3：调色带分形平铺

**组合逻辑**：[自相似/少数图案为蓝图](原有) + [缩放](原有) + [调色带指定列色](创新：从逐列涂蒙版改为逐单元格涂分形位置) + [分隔网格](原有) + [重涂色](原有)

**来源原语**：自相似、少数图案为蓝图、缩放、分隔网格、少数单元、多数单元（b99e7126）；调色带、调色带指定列色、逐列对应、重涂色、单色蒙版（278e5215）

**依赖链**：分隔线划分单元格 → 分类少数/多数 → 少数单元内部图案提供分形蓝图 → 蓝图决定哪些位置应为少数图案 → 调色带的行索引为每个少数位置指定独立颜色 → 重涂色。两套信息（蓝图定位置、调色带定颜色）缺一不可。

分隔网格的少数单元图案既是分形放置蓝图，又需根据独立调色带按行为每个新增少数位置指定不同颜色。

**输入结构**：
- 约 16x16 网格，由灰(5)分隔线（完整行和完整列各 N-1 条，宽 1 像素）划分为 NxN 等大单元格（N = 3 或 4），每个单元格内部为 MxM 像素（M = 3 或 4）。
- 大多数单元格内部图案相同（"多数图案"），由黑(0)背景和橙(7)前景构成。
- 少数单元格（输入中已有 2~3 个）内部图案不同（"少数图案"），由黑(0)和蓝(1)构成。
- 网格外侧右方有一条 Nx1 的调色带（N 行 1 列），每行一种颜色（如红(2)、绿(3)、黄(4)等，互不相同，不含黑(0)、灰(5)、蓝(1)、橙(7)）。
- 生成约束：少数图案的非黑像素排列在 MxM 中恰好形成一个二值图案，其中"活跃"像素的数量等于最终应出现的少数单元格总数；现有少数单元格的位置与蓝图中活跃像素的位置一一对应。

**规则**：
1. 识别灰(5)分隔线，确定 NxN 单元格边界。
2. 统计各单元格内部图案出现频次，出现次数最少的为"少数图案"，其余为"多数图案"。
3. 提取少数图案的 MxM 二值蓝图：非黑像素位置为"活跃"。
4. 将蓝图映射到 NxN 单元格网格：活跃位置 (r,c) 对应第 r 行第 c 列的单元格，该单元格应为少数图案。
5. 对每个应为少数图案的单元格位置 (r,c)：从调色带第 r 行（0-indexed）取颜色，将该单元格内所有蓝(1)像素重涂为该颜色，黑(0)像素保持黑(0)。
6. 非活跃位置的单元格保持多数图案不变。
7. 输出完整网格（含分隔线，不含调色带）。

**关键洞察**：蓝图仅决定"哪些单元格位置放少数图案"（分形自相似性），但每行的具体颜色由调色带的行索引独立指定——蓝图和调色带是两套正交的信息源，仅在输出处交汇。

## 新题 4：投影路径的滑动拼接

**组合逻辑**：[投影](原有：外部色迹投射入框) + [滑动/端点对齐](创新：从路径片段对齐改为框间对齐) + [裁剪](原有) + [拼接](原有)

**来源原语**：连线、投影、边框矩形、外部色迹、接触点映射（a6f40cea）；滑动、端点对齐、端点匹配拼接、路径片段、分隔列（d017b73f）；裁剪（28bf18c6）

**依赖链**：识别多个带边框矩形 → 每个框独立将外部色迹投影为内部曼哈顿路径 → 框间有分隔列 → 删除分隔列 → 按相邻框路径端点的行位置做垂直平移对齐 → 拼接内部区域为连续条带。投影结果决定端点位置，端点位置决定对齐偏移。

多个边框矩形各自将外部色迹投射为内部路径，然后删除框间空隙，按路径端点垂直对齐后水平拼接，输出连续的内部路径条带。

**输入结构**：
- 约 8x22 网格，背景黑(0)。
- 3~4 个等高的小矩形边框（边框色灰(5)，内部填充黑(0)，内部高 4 行、宽 4~5 列），水平排列，框间隔以 2~3 列纯黑背景列。
- 每个框的上边缘或下边缘外侧紧贴着 1~2 个彩色像素（如红(2)、蓝(1)、绿(3)等），每个框的左边缘和右边缘各有至多一个色迹像素紧贴框外。这些色迹均为单色（每个框的色迹颜色统一）。
- 不同示例中色迹的具体位置（贴在哪条边、在边上的具体行/列位置）应有变化。
- 生成约束：每个框至少在左/右各一边有色迹，保证内部路径有左右端点；框的排列从左到右，相邻框的右色迹与下一个框的左色迹可通过垂直平移对齐。

**规则**：
1. 识别所有灰(5)矩形边框，按其边界框左列坐标从左到右排序。
2. 对每个框，找到紧贴其外侧的彩色像素（与框边 4-相邻且不在框内）。将每个色迹像素在框边上的接触位置映射到框内部坐标（去掉边框后的局部坐标）。
3. 在每个框内部，用色迹颜色绘制从左端点到右端点的曼哈顿路径（先水平再垂直，或先垂直再水平——选择路径段数最少的方案；若相同则先垂直后水平）。若框还有上/下端点，从水平主路径分出垂直支线到达该端点。
4. 删除所有框间的纯黑分隔列。
5. 保持第一个框内部的垂直位置不变。对后续每个框的内部区域，整体垂直平移使其左端点行与前一个已放置框的右端点行相同。
6. 将所有框的内部区域（不含灰边框）从左到右水平拼接。
7. 输出拼接后的条带。

**关键洞察**：每个框的内部路径由其自己的外部色迹独立决定，但框与框之间的垂直偏移由路径端点的行坐标匹配决定——投影结果反过来约束了拼接的几何方式，两步不可分离执行。

## 新题 5：统计选色镜像涂绘

**组合逻辑**：[镜像](创新：不是补全空白半区，而是将上半区的掩码几何镜像到下半区) + [计数/选择/最大增长差](原有) + [掩码决定保留](创新：从全局掩码改为半区掩码) + [擦除](原有)

**来源原语**：镜像、翻转对称、半区、空白半区补全（f25ffba3）；计数、选择、两区域比较、最大增长差、标记掩码（8597cfd7）；掩码决定保留、掩码像素、重涂色、擦除（f76d97a5）

**依赖链**：水平分隔 → 上半区灰像素位置构成几何掩码 → 上下半区分别统计各色像素数 → 计算增长差选出获胜色 → 将上半区灰像素位置垂直镜像到下半区 → 在下半区镜像位置涂获胜色 → 擦除下半区原有颜色像素。"画在哪"和"画什么色"来自两条独立信息线，缺一不可。

上半区的灰像素位置镜像到下半区决定"在哪画"，上下半区的颜色计数差决定"画什么色"，两者在下半区输出中交汇。

**输入结构**：
- 约 12x10 网格。
- 一条完整的灰(5)水平线（占据某一行的全部列）将网格分为上半区（约 5 行）和下半区（约 5 行）。
- 上半区：黑(0)背景上有若干灰(5)像素构成一个不规则的 4-连通图案（5~10 像素），还有少量彩色像素散布（如红(2) 3 个、蓝(1) 2 个）。
- 下半区：黑(0)背景上有多种颜色像素散布（如红(2) 5 个、蓝(1) 8 个、绿(3) 4 个），无灰像素。
- 生成约束：恰好有一种颜色的"下半区数 - 上半区数"为正且唯一最大；上半区灰像素镜像到下半区后不超出网格边界。

**规则**：
1. 识别灰(5)水平分隔线（整行全为灰(5)的行），将网格分为上半区和下半区。
2. 对每种非黑(0)非灰(5)颜色 C，统计 C 在上半区的像素数 U_C 和在下半区的像素数 D_C。
3. 计算增长差 delta_C = D_C - U_C，选择 delta 最大的颜色为"获胜色" W。
4. 提取上半区所有灰(5)像素的坐标 (r, c)。设分隔线行号为 S，将每个坐标镜像为 (2S - r, c)，得到下半区的"掩码位置"集合。
5. 构建输出网格（与输入同尺寸）：全黑(0)背景，分隔线保留灰(5)，上半区保持输入原样不变，下半区仅在掩码位置涂获胜色 W，其余为黑(0)。
6. 输出完整网格。

**关键洞察**："画在哪里"完全由上半区灰像素的几何形状（垂直镜像后）决定，"画什么颜色"完全由上下半区的颜色人口统计差决定——两条独立的信息线在下半区的输出中交汇，单看任一条都无法确定输出。

## 新题 6：遮挡层序压缩为色序列

**组合逻辑**：[堆叠/遮挡层序](原有) + [压缩/每区域折叠单像素](创新：压缩轴从空间分区改为逻辑层级) + [排序](原有) + [忽略干扰项](原有)

**来源原语**：堆叠、遮挡层序、空心矩形精灵、遮挡碎片、可见像素定边框、补全、排序、忽略干扰项（652646ff）；压缩、每区域折叠单像素、分隔线、网格分区（780d0b14）

**依赖链**：识别重叠环形精灵碎片 → 忽略噪声像素 → 推断每个环的完整模板位置 → 从遮挡关系（A 的模板位置被 B 的颜色占据 → B 在 A 上方）构建偏序 → 拓扑排序为全序 → 将每层精灵压缩为一个像素 → 输出单行色序列。压缩不是按空间区域，而是按遮挡层级。

多个重叠的环形精灵通过可见碎片推断遮挡顺序，然后将每层的颜色按从顶到底顺序压缩为一行单像素序列。

**输入结构**：
- 约 14x14 网格，背景黑(0)。
- 3~5 个不同颜色（如红(2)、蓝(1)、绿(3)、黄(4)、品红(6)）的 6x6 环形精灵（矩形环轮廓：6x6 边界框中仅周边一圈 12 像素为前景，内部 4x4 全为黑(0)），各精灵为同一模板在不同位置的平移副本。
- 精灵之间有重叠区域：上层精灵的像素覆盖下层精灵在相同位置的像素。部分精灵可能被网格边界裁切（仅部分像素可见）。
- 少量孤立噪声像素（1~2 个，颜色可能与某精灵相同，但位置不在任何精灵模板上）散布于网格中。
- 生成约束：遮挡关系可形成全序（无循环遮挡）；每个精灵至少有 3 个像素可见。

**规则**：
1. 对每种非黑颜色，收集其所有像素坐标。尝试找到一个 6x6 环模板的平移使该颜色的像素全部落在模板上。若匹配失败（有像素不在任何单一模板平移上），则该颜色的不匹配像素为噪声，忽略之。
2. 对每个成功匹配的环精灵，检查其模板上的每个像素位置：若该位置实际显示的颜色不是本精灵颜色且不是黑(0)，则该位置被另一精灵遮挡，记录"该颜色的精灵在本精灵上方"。
3. 汇总所有遮挡关系，拓扑排序得到从顶层到底层的全序。
4. 输出 1 行 K 列的网格（K = 精灵数量），从左到右依次为顶层到底层精灵的颜色。

**关键洞察**：压缩轴不是物理空间的行列分区，而是逻辑层级——每个"区域"是一个遮挡层而非物理区域，必须从碎片的互相遮挡中反推层级关系，这一层级关系才是压缩的分组依据。

## 新题 7：角落图案旋转复制后扫描线填充

**组合逻辑**：[图案复制/旋转](原有：源角到目标角映射) + [填充轮廓间区域](创新：轮廓不是输入中的对角线条纹，而是旋转复制后的角落图案) + [逐行扫描](原有) + [各角独立着色](原有)

**来源原语**：图案复制、旋转、空心框、角落标记、源角到目标角映射、各角独立着色（4c416de3）；填充、填充轮廓间区域、轮廓像素、逐行扫描、跨度（aa18de87）

**依赖链**：识别源角图案 → 旋转到其他角（各角颜色由标记决定） → 角图案像素成为新的轮廓像素 → 逐行扫描矩形框内部行的所有非黑像素 → 相邻非黑像素间的跨度填充指定色。图案复制的结果改变了每行的扫描线端点位置，从而改变了填充的几何范围。

将一个角落的装饰图案旋转复制到矩形框的四个角，四角图案与框边共同构成轮廓后，在每行的相邻轮廓像素之间填充指定颜色。

**输入结构**：
- 约 14x14 网格，背景黑(0)。
- 一个灰(5)空心矩形框（宽高约 10x10，框线宽 1 像素）。
- 矩形框的一个角（如左上角）有一个已绘制的红(2)装饰图案：从角落沿内对角线方向延伸 2~3 像素，并在框边平行方向各延伸 1~2 像素，形成一个阶梯状图案（3~6 个像素），关于该角的内对角线轴对称。不同示例中图案的具体阶梯深度和宽度应不同。
- 其余三个角各有一个单像素标记：位于该角内对角线方向距角 k 格处（k = 源图案的对角线最深偏移），颜色各异（如蓝(1)、绿(3)、黄(4)）。
- 生成约束：源图案关于角的内对角线对称；旋转后的图案不与框边线重叠；框内部高度和宽度均 > 2k+2。

**规则**：
1. 在四个角中找到已有多像素图案的角为"源角"，提取图案相对于角顶点的偏移集合。
2. 对其他三个角，读取其标记像素颜色，将源图案的偏移集合旋转到该角的朝向（左上 → 右上旋转 90 度，左上 → 右下旋转 180 度，左上 → 左下旋转 270 度），用标记颜色绘制。标记像素自身被图案覆盖。
3. 四角图案绘制完成后，连同灰(5)框边，构成完整的边界轮廓集合。
4. 逐行扫描框的内部行（框顶行+1 到框底行-1）：在每行中从左到右收集所有非黑像素（含灰框边和彩色角图案像素），对每对相邻非黑像素之间的黑色间隙，将全部黑色像素填充为黄(4)。
5. 框外部区域、框边线本身、角图案像素均不改变。
6. 输出完整网格。

**关键洞察**：角落图案旋转复制后，其像素成为扫描线填充的边界锚点——图案越深，该行的填充宽度越窄；不同角的图案颜色不同，但它们共同决定每行有多少个分段和每段的起止位置。图案复制是填充几何形状的前提条件。

## 新题 8：精灵自计数的中点放置

**组合逻辑**：[放置/中点定位](原有) + [计数/像素数定尺寸数](创新：从定输出画布尺寸改为定放置次数) + [裁剪](原有) + [定位像素对](原有)

**来源原语**：放置、十字图案、定位像素对、中点定位、中点居中放置（e9614598）；平铺、计数、像素数定尺寸数、精灵体、阵列排布（91413438）；裁剪（28bf18c6）

**依赖链**：裁剪精灵 → 统计精灵前景像素数 K → 在网格中找到恰好 K 对蓝色定位像素 → 计算每对的中点 → 在每个中点居中放置精灵副本。精灵的像素数编码了全局约束（定位对的数量），改变精灵一个像素就改变需要寻找的蓝色对数。

精灵自身的前景像素数决定需要放置多少份副本，每份放置在一对蓝色定位像素的中点处。

**输入结构**：
- 约 16x16 网格，背景黑(0)。
- 网格一个明确隔离的区域（如左上角 4x4 范围）内有一个小型精灵（边界框 3x3），由黑(0)背景和一种前景色（如红(2)）构成，前景像素数为 K（K = 3~5）。精灵内部图案在不同示例中不同（不总是十字形），但边界框始终为 3x3。
- 网格其余区域散布着恰好 K 对蓝(1)像素。每对蓝像素在同一行或同一列上对齐，间距为偶数（保证中点为整数坐标），两像素间无其他蓝像素。
- 各对之间充分间隔，使得以每对中点为中心放置 3x3 精灵时不超出网格边界且不与其他放置区域重叠。
- 生成约束：精灵区域与蓝像素区域不重叠；K 对蓝像素可通过"同行或同列、间距为偶数、之间无其他蓝像素"唯一配对。

**规则**：
1. 识别精灵：找到网格中与蓝(1)像素不相邻的、唯一的非黑非蓝 4-连通前景对象，裁剪其 3x3 边界框。
2. 统计精灵中前景像素数量 K。
3. 找到所有蓝(1)像素。对蓝像素按空间关系配对：两个蓝像素构成一对当且仅当它们在同一行或同一列、间距为偶数、且之间无其他蓝像素。得到恰好 K 对。
4. 对每对蓝像素计算中点坐标 ((r1+r2)/2, (c1+c2)/2)。
5. 以每个中点为中心放置精灵的 3x3 副本（精灵中黑色像素保持黑色，前景像素保持原色）。
6. 保留所有蓝(1)像素不变。若精灵放置区域与蓝像素位置重叠，精灵像素覆盖蓝像素。
7. 输出完整网格。

**关键洞察**：精灵不仅是被复制的图案——它的前景像素数量编码了"需要多少对定位点"这一元信息，是像素级几何属性到全局计数约束的隐式映射。

## 新题 9：分区独立镜像（标记定轴）

**组合逻辑**：[分隔网格/网格分区](原有) + [镜像/对称补全](创新：从全局单一镜像改为每个分区独立判断镜像轴方向) + [标记像素](创新：标记的位置编码镜像方向而非颜色信息)

**来源原语**：分隔网格、网格分区、分隔线、色块区域（780d0b14）；镜像、翻转对称、半区、空白半区补全（f25ffba3）；标记像素、标记色决定填充（444801d8）；对称补全（e66aafb8）

**依赖链**：分隔线划分区域 → 每个区域内图案占据一半 → 另一半为空白 → 空白半区中有标记像素 → 标记在上/下/左/右半区指示镜像轴方向 → 沿该方向镜像补全。全局分区和局部标记位置共同决定每个区域的独立变换。

分隔网格的每个区域内有半区图案和一个标记像素，标记所在的空白半区指示该区域的镜像方向，各区域独立镜像补全。

**输入结构**：
- 约 15x15 网格。
- 红(2)分隔线（完整行和完整列，各 1~2 条，宽 1 像素）将网格分为 2x2 或 2x3 个矩形区域，每个区域内部约 5x5 到 6x6 像素。
- 每个区域中：一半（上半或下半或左半或右半）有一个由非背景色（可以是蓝(1)、绿(3)、橙(7)、品红(6)等，各区域颜色可不同）构成的小图案（4-连通，3~5 像素），另一半全为黑(0)背景。
- 空白半区中有一个单像素黄(4)标记，位于空白半区内任意位置。不同区域的镜像方向可以不同（例如第一个区域的图案在上半、标记在下半，第二个区域的图案在左半、标记在右半）。
- 生成约束：每个区域的图案严格在某一半区内；标记严格在对面半区内；图案不跨越区域中线。

**规则**：
1. 识别红(2)分隔线（跨越整行或整列的红色线），确定各矩形区域的边界。
2. 对每个区域独立处理：
   a. 找到黄(4)标记像素的位置，判断它位于区域的哪一半（将区域沿水平中线和垂直中线各分两半，标记落入哪一半则该半为"空白半区"）。
   b. 若标记在下半区，则图案在上半区，沿水平中线上下翻转到下半区。
   c. 若标记在上半区，则图案在下半区，沿水平中线上下翻转到上半区。
   d. 若标记在右半区，则图案在左半区，沿垂直中线左右翻转到右半区。
   e. 若标记在左半区，则图案在右半区，沿垂直中线左右翻转到左半区。
   f. 翻转后的像素覆盖空白半区的对应位置。黄(4)标记像素被翻转后的图案或背景覆盖（移除）。
3. 分隔线保留红(2)。
4. 输出完整网格。

**关键洞察**：镜像方向不是全局统一的，而是逐区域由黄色标记像素的位置隐式编码——必须先完成分区，再在每个区域内根据标记位置独立推断翻转轴。仅凭一个示例可能无法确定标记编码规则（需要看到至少两种不同方向的区域才能归纳）。

## 新题 10：调色带循环扫描线填充

**组合逻辑**：[填充轮廓间区域](原有) + [调色带](创新：从逐列着色改为按全局跨度序号循环取色) + [逐行扫描](原有) + [交替着色](创新：从两色交替改为多色循环)

**来源原语**：填充、填充轮廓间区域、轮廓像素、逐行扫描、跨度（aa18de87）；调色带、调色带指定列色、逐列对应（278e5215）；交替着色（a6f40cea）

**依赖链**：提取调色带颜色列表 → 逐行扫描轮廓像素 → 每对相邻轮廓像素间形成跨度 → 全局跨度按扫描顺序编号 → 按编号对调色带长度取模循环选色 → 填充该跨度。扫描线几何决定跨度数量和分布，调色带决定每个编号对应的颜色。

对角线轮廓的扫描线填充中，每个跨度的颜色按全局扫描顺序从调色带中循环取色。

**输入结构**：
- 约 12x12 网格，背景黑(0)。
- 一种轮廓色灰(5)构成若干对角线条纹（从左上到右下或从右上到左下倾斜），每行有 2~4 个灰(5)轮廓像素，连续轮廓像素之间有黑色间隙。不同示例中对角线条纹的方向和密度应不同。
- 网格最后一行为调色带：包含 P 种颜色（P = 2~4），从左到右排列（如红(2)、蓝(1)、绿(3)），每种颜色占一个像素，其余位置为黑(0)。调色带行不参与扫描线填充。
- 生成约束：扫描线产生的总跨度数 > P，保证调色带需要循环使用。

**规则**：
1. 识别调色带：最后一行中从左到右第一段连续非黑像素序列，提取颜色列表 [c_0, c_1, ..., c_{P-1}]。
2. 逐行从第 0 行到倒数第 2 行扫描（不含调色带行）。
3. 每行中从左到右找到所有灰(5)轮廓像素，取每对相邻灰像素之间的黑色间隙为一个"跨度"（两个灰像素之间必须有至少一个黑色像素才构成跨度）。
4. 全局跨度按扫描顺序编号：第 0 行第一个跨度编号 0，第 0 行第二个跨度编号 1，依此类推到最后一个有效行的最后一个跨度。
5. 编号为 i 的跨度用颜色 c_{i mod P} 填充其所有黑色像素。
6. 灰(5)轮廓像素保持原色。
7. 输出网格不含调色带行（输出行数 = 输入行数 - 1）。

**关键洞察**：填充色不是按行、按列或按区域统一指定，而是按全局跨度的扫描遍历序号循环分配——同一行中的两个跨度可能颜色不同，不同行的跨度可能颜色相同，具体取决于累积编号对调色带长度的取模结果。需要对比多个示例才能区分"按行着色"和"按全局序号着色"。
