## 新题 1：角位导向对角弹射与框架染色

**组合逻辑**：[角位控制射线](创新：从控制射线方向改为控制弹射方向) + [弹射](创新：从线性弹射改为对角弹射) + [重涂色](创新：框架吸收内容色) → 角位编码对角弹射方向，弹射清空内容后框架继承内容颜色

**来源原语**：角位控制射线/对角方向(1f0c79e5), 弹射/内容像素/像素数守恒(3dc255db), 重涂色(多源)

**依赖链**：角位标记决定弹射的几何方向 → 弹射操作清空内容并沿对角线放置等量像素 → 框架边框颜色由被弹射的内容颜色决定，三者缺一不可：无角位则方向不确定，无弹射则内容不移动，无框架染色则框架信息丢失

根据角位标记像素在框架角落的位置，将框架内的内容像素沿对应对角线弹射出去，并将空框架的边框重涂为内容颜色。

**输入结构**：约 15x15 的黑(0)背景网格。网格上有 2-3 个不相互接触的空心矩形框架，每个框架由 1 像素宽的单色边框围成（边框颜色各不相同，从蓝(1)、红(2)、绿(3)中选取），内部尺寸约 3x3 到 5x5。每个框架内部有一簇 4-连通的内容像素（3-5 个像素），内容颜色与该框架边框色不同且各框架的内容颜色互不相同（从橙(7)、青(8)、栗(9)中选取）。每个框架的边框上恰好有一个角落位置的像素被替换为黄(4)标记像素（即矩形边框四个角之一为黄色而非边框色）。框架之间以及框架与网格边缘之间留有足够空间（至少 4 个像素的间距），以容纳弹射轨迹。生成约束：每个框架的黄色角位选择使弹射方向指向远离网格中心的方向，保证轨迹不与其他框架重叠。

**规则**：
1. 对每个框架，定位其边框上唯一的黄(4)标记像素。该标记必定位于矩形边框的四个角之一。
2. 标记的角位决定弹射方向：左上角 → 向左上对角线（每步行-1、列-1）；右上角 → 向右上对角线（每步行-1、列+1）；左下角 → 向左下对角线（每步行+1、列-1）；右下角 → 向右下对角线（每步行+1、列+1）。
3. 统计框架内部内容像素的数量 N。
4. 擦除框架内部所有内容像素（替换为黑(0)）。
5. 从标记角位的坐标出发，沿弹射方向逐步放置内容色像素：第 1 个像素覆盖标记位置本身（黄色被内容色替代），后续每个像素沿对角方向偏移一步，共放置 N 个像素。超出网格边界的像素丢弃。
6. 将框架的全部边框像素（除已被步骤 5 覆盖的角位外）从原边框色重涂为该框架的内容色。
7. 多个框架按从左到右的顺序（以边框包围盒左上角列坐标排序，列相同则行坐标小的优先）依次处理。若两条弹射轨迹有交叉像素，后处理的框架的轨迹覆盖先处理的。

**关键洞察**：黄色标记像素身兼三职——它编码弹射方向（借用角位控制射线的位置语义）、充当弹射锚点（借用尾刺的起点功能）、同时自身被内容色覆盖成为轨迹的第一个像素。框架边框的重涂色使"曾经装过什么"的信息在弹射后仍然可读，形成弹射操作与颜色传递之间的双向耦合。

## 新题 2：对角扫掠遭障碍阻挡后按阻挡计数重涂障碍

**组合逻辑**：[滑动/对角轨迹](已有) + [计数](创新：统计被阻挡的扫掠像素数) + [重涂色](创新：阻挡数映射为障碍的新颜色) → 扫掠几何与障碍位置交互决定障碍最终颜色

**来源原语**：滑动/对角轨迹/逐步平移(feca6190), 障碍精灵体/绕障重绘(88bcf3b4), 计数(fcc82909/9565186b), 重涂色(多源)

**依赖链**：对角扫掠产生全局轨迹场 → 障碍的空间位置决定它拦截了哪些轨迹 → 拦截数量反过来决定障碍自身的颜色。三步形成闭环式依赖：扫掠几何→阻挡判定→颜色分配，且阻挡判定同时改变扫掠图案（被阻挡处不绘制）

在黑色网格底行放置一行彩色稀疏像素，对角扫掠填充网格；灰色障碍精灵体阻挡扫掠像素，每个障碍根据它阻挡的像素数量被重涂为对应颜色。

**输入结构**：约 12x12 的黑(0)背景网格。底行（最后一行）包含若干非黑像素（从蓝(1)、红(2)、绿(3)中选取），其余位置为黑(0)，形成一个稀疏的彩色横线。网格中部散布 2-4 个灰(5)障碍精灵体，每个精灵体是 4-连通的小图形（3-6 像素），形状各不相同（非特定几何名，仅保证 4-连通且紧凑）。生成约束：每个障碍至少被 1 条对角轨迹穿过（即障碍的某些像素恰好在某条底行非黑像素的对角扫掠路径上）；各障碍阻挡的扫掠像素数量互不相同，且最大阻挡数不超过 4；不同障碍不位于同一条对角轨迹上。

**规则**：
1. 从底行出发，将整行逐步向上平移并向右偏移（每步行-1、列+1），重复直到整行移出网格顶部。每步将底行中的每个非黑像素复制到新位置，保持其原色。超出网格左右或顶部边界的像素丢弃。
2. 在执行扫掠时，若某个即将放置的扫掠像素的目标位置被灰(5)障碍像素占据，则该扫掠像素被抑制（不绘制），障碍像素保持不变。
3. 扫掠完成后，对每个障碍精灵体统计其抑制的扫掠像素总数 B。
4. 根据 B 值重涂该障碍的所有像素：B=1 → 蓝(1)；B=2 → 红(2)；B=3 → 绿(3)；B=4 → 黄(4)。
5. 各对角轨迹从底行最左侧的非黑像素到最右侧依次独立处理；每个像素的抑制判定在其放置时即时评估。

**关键洞察**：扫掠几何和障碍位置双向交互——扫掠决定了每个障碍被穿过多少次（阻挡计数），而障碍的存在又在扫掠图案中制造了缺口。障碍的最终颜色编码了它与扫掠场的几何交互程度，这个信息无法脱离完整的扫掠模拟而直接推断。

## 新题 3：骨牌描边创建捕获域，域内色彩多样性驱动标记高度

**组合逻辑**：[描边](已有) + [尺寸分类](已有：区分骨牌与单像素) + [计数](创新：统计被描边框圈住的散点颜色种类数) + [绘制/标记矩形](创新：标记高度由捕获的颜色多样性决定) → 描边不仅是视觉装饰，更建立空间包含关系驱动后续计数

**来源原语**：描边/尺寸分类/微型对象描边(b27ca6d3), 计数/颜色数决定高度/标记矩形/绘制(fcc82909), 连通分量(多源), 擦除/单像素分量移除(42a50994)

**依赖链**：尺寸分类区分骨牌与单像素 → 描边仅作用于骨牌，创建空间区域 → 该区域的几何范围决定捕获了哪些散点 → 被捕获散点的颜色种类数决定标记高度。删除描边环节则无空间区域，无法计数；删除计数环节则标记高度无据可依

在红色骨牌周围绘制绿色描边框，统计框内被捕获的散点颜色种类数，在框下方绘制等高的黄色标记条。

**输入结构**：约 15x15 的黑(0)背景网格。红(2)前景像素分为两类：4-连通的骨牌（恰好 2 个红色像素，水平或垂直相邻）和孤立的单像素（8 邻域内无其他红色像素）。另外，网格上散布若干单独的彩色像素（每个像素与其他同色像素不相邻），颜色从蓝(1)、绿(3)、黄(4)、灰(5)、品红(6)中选取。生成约束：每个骨牌的扩展包围盒（原包围盒四个方向各外扩 1 格，裁剪到网格边界）内包含至少 1 个且至多 4 个散点像素；不同骨牌的扩展包围盒互不重叠；各骨牌捕获的散点颜色种类数互不相同；骨牌下方有足够空间（至少 4 行）容纳标记条；红色单像素不位于任何骨牌的扩展包围盒内。

**规则**：
1. 识别所有红(2)的 4-连通分量，按面积分为骨牌（面积=2）和单像素（面积=1）。
2. 对每个骨牌，计算其包围盒并四方向各外扩 1 格（裁剪到网格边界）。在扩展包围盒的周边绘制绿(3)描边：将周边上每个当前为黑(0)的格子涂为绿(3)。已有非黑像素的周边格保持不变。
3. 对每个已描边的骨牌，找出严格位于绿色描边框内部（不含描边周边本身）的所有非红、非黑、非绿像素。统计这些被捕获像素的不同颜色种类数 D。
4. 在每个描边框正下方（紧贴底边），绘制一个黄(4)填充矩形，宽度等于描边框宽度，高度等于 D。若标记矩形超出网格底部则裁剪。
5. 擦除所有红色单像素（替换为黑(0)）。红色骨牌像素保留。
6. 框内被捕获的散点像素保留原色不变。
7. 处理顺序：按骨牌包围盒左上角坐标从左上到右下（先按行从小到大，再按列从小到大）。

**关键洞察**：绿色描边不是装饰——它定义了一个空间捕获域。域内恰好包含哪些散点取决于骨牌的位置和描边的几何范围，而捕获的颜色多样性（非数量）又驱动标记的高度。这条链路中，描边的空间效应是连接对象分类和标记生成之间不可省略的中间推理层。

## 新题 4：标记排序后按位置奇偶执行差异化编码反转

**组合逻辑**：[排序](已有) + [反转编码](创新：反转行为由排序后的位置奇偶性决定，且奇偶位执行不同方向的反转) → 排序结果不仅改变排列，还决定每个块的变换类型

**来源原语**：排序/标记行指示顺序/整块移动保持内容/色块条带(f18ec8cc), 反转编码/块网格/重复精灵体/均匀空白块/精灵与空白互逆(6350f1f4)

**依赖链**：标记行指定排序目标顺序 → 排序将块移至新位置 → 新位置的奇偶性决定该块执行哪种反转操作。排序和反转不可分割：同一组块在不同排序结果下，奇偶位不同，反转结果完全不同

按标记指示的顺序重排垂直色块，然后对奇数位的块执行"精灵变实心"反转，对偶数位的块执行"颜色角色互换"反转。

**输入结构**：一个高 5、宽约 23 的网格（5 个宽度为 4 的块，被 4 列宽度为 1 的黑(0)分隔列隔开，总宽 5x4+4x1=24，但可微调）。每个块有唯一的主色（从蓝(1)、红(2)、绿(3)、黄(4)、灰(5)中选取）和一种副色（从品红(6)、橙(7)、青(8)、栗(9)中选取，各块副色互不相同）。每个块内部大部分像素为主色，副色像素形成一个小的 4-连通图形（2-4 个像素，形状不规则），嵌在主色区域内。最顶行（行 0）中，每个块恰好包含一个外来标记像素——其颜色为另一个块的主色，指示目标排序位置（即"此位置应放哪个块"）。标记像素的颜色在整行中互不重复，构成一个排列。生成约束：块的数量为奇数（5 个），以使奇偶位均有代表；标记指定的排序结果不等于当前顺序。

**规则**：
1. 读取标记行：每个块内标记像素的颜色指示应占据该位置的块的主色。将所有块按标记排列重新排序，使每个位置放置其标记颜色对应的块。
2. 排序完成后，从左到右将位置编号为 1, 2, 3, 4, 5。
3. 奇数位（1, 3, 5）的块执行"精灵消除"反转：将块内副色图形像素全部替换为主色，使整个块变为纯主色填充。
4. 偶数位（2, 4）的块执行"颜色互换"反转：将块内主色像素全部替换为副色，副色像素全部替换为主色。即原来的背景色变为图形色，图形色变为背景色。
5. 擦除标记行：所有块的行 0 中的标记像素替换为该块（排序后）的最终主色。
6. 分隔列保持黑(0)不变。

**关键洞察**：排序不仅是空间重排——它决定了每个块落入奇数位还是偶数位，从而选择完全不同的反转操作。同一个块在不同的排序结果中可能被简化（奇数位）或颜色翻转（偶数位），因此排序和反转之间存在因果耦合：不知道排序结果就无法确定每个块的变换类型。

## 新题 5：周期行补全后按区域包围盒做半区变色

**组合逻辑**：[补全/周期平移](已有) + [重涂色/半区变色](创新：对补全后形成的每个连通区域独立执行半区分割，而非对单一对象) → 补全决定区域几何形态，形态决定分割线位置

**来源原语**：补全/周期平移/周期偏移延续行/行图案(53b68214), 重涂色/半区变色/半区/包围盒(e7dd8335)

**依赖链**：从可见行推断周期和偏移 → 补全缺失行使图案延伸到完整画布 → 补全后的前景像素形成若干 4-连通区域 → 每个区域的包围盒决定其垂直中线 → 中线以下的像素被重涂。不执行补全则区域不完整，中线位置错误；不做半区分割则补全只是简单外推

将一个斜向周期行图案补全至完整画布后，对形成的每个前景连通区域按包围盒垂直中线进行上下分色。

**输入结构**：一个宽 10、高 4 到 6 的网格。背景为黑(0)，前景使用蓝(1)。前景像素排列为行间平移周期模式：第 k 行的前景掩码是第 k-p 行掩码向右平移 s 个像素的结果（超出右边界的像素丢弃，左边界不补入新像素）。周期 p 和偏移 s 从可见行中可推断。生成约束：补全至 10x10 后，前景的 4-连通区域至少有 2 个；每个区域的包围盒高度为偶数（以保证中线无歧义）；p 在 2-3 之间，s 在 1-2 之间。

**规则**：
1. 从可见行推断最小垂直周期 p 和水平偏移 s：存在唯一的 (p, s) 使所有可见行满足 row[k] = shift_right(row[k-p], s)。
2. 将网格扩展至 10 行 10 列：对每个缺失行 k（k >= 原始行数），取行 k-p 的前景掩码，向右平移 s 格（右边界裁剪），生成该行内容。
3. 在补全后的 10x10 网格中，识别所有蓝(1)的 4-连通区域。
4. 对每个区域计算其包围盒（最小行 r_min、最大行 r_max、最小列 c_min、最大列 c_max）。垂直中线位于行 r_mid = r_min + (r_max - r_min + 1) / 2（整除，下半从 r_mid 行开始）。
5. 将该区域中行号 >= r_mid 的所有前景像素从蓝(1)重涂为红(2)。行号 < r_mid 的像素保持蓝(1)。
6. 各区域独立处理，互不影响（因区域定义为 4-连通，不会共享像素）。

**关键洞察**：周期补全和半区变色的耦合点在于区域几何。补全的行数和偏移方式决定了斜向轨迹如何连接或分离为独立区域，而每个区域的包围盒形状决定了颜色分割线的具体位置。不同的 (p, s) 参数会产生完全不同的区域划分和分割结果——两个逻辑通过区域的涌现形态紧密关联。

## 新题 6：X 形折叠生成瓦片后按锚点约束旋转铺设

**组合逻辑**：[折叠/对角到边映射](已有) + [平铺](创新：铺设时每个位置的旋转角度由锚点约束决定) + [旋转](创新：旋转不是固定模式，而是逐块约束求解) → 折叠产生瓦片内容，锚点约束决定铺设方式，两者同时约束输出

**来源原语**：折叠/对角到边映射/对角线像素/正方形边框(ca8de6ea), 平铺/周期瓦片(29ec7d0e), 旋转(2697da3f)

**依赖链**：5x5 X 形图案通过对角-到-边折叠压缩为 3x3 瓦片 → 瓦片需要铺满目标区域，但每个位置的旋转角度未知 → 散布的锚点像素约束每个位置的旋转选择 → 求解唯一满足所有锚点的旋转组合。折叠和约束求解不是流水线关系——折叠决定"能放什么"，锚点决定"怎么放"，两者交织

将 5x5 的 X 形彩色图案折叠为 3x3 瓦片，然后在目标区域用该瓦片的旋转副本铺满，每个位置的旋转由预设的锚点像素唯一确定。

**输入结构**：一个 14x14 的黑(0)背景网格。左上角 5x5 区域包含一个 X 形图案：两条对角线上的 9 个像素各有不同颜色（从蓝(1)、红(2)、绿(3)、黄(4)、灰(5)、品红(6)、橙(7)、青(8)、栗(9)中选取），中心像素为两条对角线共享。其余 16 个位置为黑(0)。右下方有一个 9x9 的铺设区域（行 5-13、列 5-13），被概念性地划分为 3x3 的宏格网（每个宏格 3x3 像素），共 9 个宏格位置。铺设区域中散布 5-9 个"锚点"像素，每个为某种非黑颜色，位于某个宏格内部的某个位置。生成约束：锚点颜色与 X 形图案中使用的颜色相同；每个宏格至少有 1 个锚点；锚点的分布使得每个宏格的旋转角度（0°、90°顺时针、180°、270°顺时针）被唯一确定（即仅有一个旋转使得瓦片在该锚点位置的颜色与锚点颜色一致）。

**规则**：
1. 将 5x5 X 形图案折叠为 3x3 瓦片，映射规则如下（5x5 坐标 → 3x3 坐标）：
   - 中心 (2,2) → (1,1)
   - 左上臂 (0,0) → (0,0)，(1,1) 已归入中心
   - 左上臂 (1,1) 与中心共享，仅取 (0,0) 为独立臂端：(0,0) → (0,0)
   - 修正：按 ca8de6ea 的精确映射：西北臂 → 顶边从左到中，东北臂 → 右边从上到中，西南臂 → 左边从中到下，东南臂 → 底边从中到右：
     - (0,0) → (0,0)；(1,1) → (0,1)（西北臂）
     - (0,4) → (0,2)；(1,3) → (1,2)（东北臂）
     - (3,1) → (1,0)；(4,0) → (2,0)（西南臂）
     - (3,3) → (2,1)；(4,4) → (2,2)（东南臂）
     - (2,2) → (1,1)（中心）
2. 对铺设区域的每个宏格（3x3 块），确定瓦片旋转：尝试 4 种旋转（0°、90° CW、180°、270° CW），选取唯一一个使所有锚点位置的颜色匹配的旋转。
3. 将旋转后的瓦片粘贴到该宏格位置。
4. 擦除原始 5x5 X 形图案区域（全部填为黑(0)）。
5. 输出网格中，铺设区域之外的像素保持黑(0)。

**关键洞察**：这道题不是流水线——折叠和旋转约束形成同时约束。折叠规则决定瓦片的 9 个颜色值（"什么颜色可以出现在哪个相对位置"），而锚点约束决定每个宏格的旋转角度（"哪个旋转使锚点颜色成立"）。求解者必须同时理解几何折叠映射和旋转对称性，才能确定每个宏格的正确铺设方式。

## 新题 7：图例过滤擦除后残余像素重力下沉堆叠

**组合逻辑**：[擦除/图例作为过滤器](已有) + [堆叠/逐列填充](创新：从频率排序堆叠改为重力下沉，保持列内相对顺序) → 擦除改变空间格局，堆叠对擦除后的空间重新组织

**来源原语**：擦除/图例作为过滤器/包含全部目标色/图例区域(d59b0160), 排序/堆叠/逐列填充(bd283c4a), 连通分量(多源)

**依赖链**：图例定义目标色集合 → 目标色集合筛选出哪些连通分量被擦除 → 擦除在特定列制造空隙 → 重力堆叠利用空隙重排存活像素的垂直位置。擦除模式由图例和分量的颜色组成共同决定，堆叠结果由擦除后的列空隙分布决定——三者依次依赖

读取角落图例中的目标色集，擦除包含全部目标色的连通分量，然后让残余像素在各列中重力下沉到底部。

**输入结构**：约 12x12 的黑(0)背景网格。左上角有一个图例区域：灰(5)边框围成的 3x3 到 4x4 方形区域，右边和底边各一条灰(5)线作为边界标记，内部包含 2 个目标色像素（如蓝(1)和红(2)各一个，不相邻）。网格其余部分散布 5-7 个 4-连通多色连通分量（通过同一分量中不同像素的颜色定义——此处"连通分量"指 4-连通的非黑像素集合，一个分量可包含多种颜色）。每个分量由 2-3 种颜色组成，面积 4-8 像素。生成约束：至少 2 个分量包含全部目标色（蓝和红都有），至少 2 个分量不包含全部目标色（缺少至少一种）；分量之间互不接触；分量不与图例区域接触；擦除后至少有 2 个分量存活。

**规则**：
1. 读取图例：忽略灰(5)边框，提取边框内部的颜色集合作为目标色集（如 {蓝(1), 红(2)}）。
2. 识别网格中所有非图例的 4-连通非黑像素分量。对每个分量，检查其是否包含目标色集中的所有颜色。
3. 擦除所有包含全部目标色的分量（其所有像素替换为黑(0)）。不包含全部目标色的分量保留不变。
4. 擦除整个图例区域（边框和内部全部替换为黑(0)）。
5. 重力下沉：对每一列独立处理。将该列中所有非黑像素按从上到下的原始顺序收集，然后从底行向上紧密排列。即每个非黑像素下沉到该列最底部可用的黑色位置，同列内非黑像素的相对上下顺序保持不变。
6. 输出网格尺寸与输入相同。

**关键洞察**：图例决定了哪些分量被擦除，擦除在某些列上制造了空隙——正是这些空隙控制了重力下沉的效果。同一组分量搭配不同的图例（不同目标色集）会擦除不同的分量，产生不同的列空隙模式，从而导致完全不同的下沉后布局。过滤逻辑和空间重组通过"哪些列在哪些行出现了空位"这一中间结构紧密耦合。

## 新题 8：周期瓦片修复后输出损伤位置的负片

**组合逻辑**：[修复/最小周期推断填补](已有) + [反转编码](创新：从块级精灵/空白互逆改为像素级"缺失/存在"互逆) → 修复提供颜色信息，缺失掩码提供空间信息，两者同时约束输出

**来源原语**：修复/最小周期推断填补/周期瓦片/缺失单元(29ec7d0e), 反转编码/精灵与空白互逆(6350f1f4)

**依赖链**：从可见像素推断最小重复瓦片 → 瓦片确定每个位置应有的颜色（包括缺失位置） → 反转掩码：原来缺失的位置用修复后的颜色填入，原来完好的位置变为黑色。瓦片推断和掩码反转同时被需要：仅知瓦片无法确定输出哪些位置有色，仅知掩码无法确定输出什么颜色

修复一个有缺损的周期色彩网格，然后输出"负片"：仅显示原来缺损位置的修复颜色，原来完好的位置变为黑色。

**输入结构**：一个矩形网格（如 9x9 或 12x8），是一个 p x p 周期瓦片（p=3 或 4）的多次重复铺满。瓦片使用的颜色从蓝(1)、红(2)、绿(3)、黄(4)、品红(6)、橙(7)、青(8)、栗(9)中选取（不含灰(5)和黑(0)），瓦片自身不含黑色像素。网格中部分像素被替换为灰(5)，表示"缺损"。生成约束：p 整除网格的行数和列数；瓦片使用至少 3 种颜色；缺损比例在 20%-50% 之间；每个瓦片位置 (row mod p, col mod p) 在网格中至少有一个非灰(5)的可见样本，保证瓦片可唯一重建。

**规则**：
1. 推断最小周期瓦片：对每个瓦片位置 (r mod p, c mod p)，其颜色为该位置上所有非灰(5)像素的一致颜色值。遍历所有可能的 p 值（从小到大），选择使所有非灰像素在 (row mod p, col mod p) 分组内颜色一致的最小 p。
2. 构建输出网格（与输入同尺寸）：
   - 对于输入中为灰(5)的位置（缺损）：输出为该位置对应的瓦片颜色（即修复后应有的颜色）。
   - 对于输入中非灰(5)的位置（完好）：输出为黑(0)。
3. 输出网格中不存在灰(5)像素。

**关键洞察**：输出是输入缺损模式的"负片"，但着色来自推断出的周期瓦片。这形成同时约束：瓦片推断需要所有完好像素（它们在输出中消失），缺损掩码需要知道哪些位置原来是灰色（它们在输出中着色）。求解者必须先通过完好像素重建瓦片（这些像素随后被"销毁"），再用瓦片为缺损位置着色——修复与反转是一对互补操作，共享相同的周期结构但作用于互斥的像素集。
