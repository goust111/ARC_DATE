## 新题 1：标记选色与计数定周期的印章网格

**组合逻辑**：[按标记色选择同色](创新：选择印章模板而非擦除目标) + [连通检测 → 计数](创新：计数结果参数化印章周期而非柱状图条长) + [印章覆盖 + 周期内指定位变色](创新：变色周期由外部计数动态确定而非固定值)

**来源原语**：按标记色选择同色、角括号、标记像素（1e81d6f9）；连通检测、计数（2753e76c）；印章覆盖、周期排布、周期内指定位变色（d304284e）

**依赖链**：标记像素的颜色同时确定"哪个颜色的精灵体是模板"和"哪个颜色的精灵体是计数对象的补集"；计数的输出不是用来可视化，而是改变印章覆盖中变色节奏的周期参数；角括号的位置不仅用于颜色选择，还作为印章网格的空间锚点。

将标记色精灵体作为模板、对另一色精灵体计数以确定变色周期，然后从角括号位置出发进行印章覆盖，其中每隔 k 个印章变色并向下延伸。

**输入结构**：黑(0)背景，约 18x18 网格。包含以下元素：
- 一个灰(5)单色 4-连通角括号结构（3-5 像素的 L 形边界结构）。
- 角括号的边界框内部、非括号像素处有且仅有一个前景标记像素，颜色为 C（C 为蓝(1)或绿(3)之一）。
- 网格中散布若干颜色为 C 的 4-连通小精灵体（各 3-6 像素，互不相邻），共 1-3 个。
- 网格中另散布若干颜色为 D（D 为红(2)或黄(4)之一，D 不等于 C）的 4-连通小精灵体（各 2-4 像素，互不相邻），共 2-5 个。
- 所有精灵体均不接触角括号结构和标记像素。
- 生成约束：颜色 C 的精灵体中，恰有一个的边界框左上角的行号最小（若行号相同则列号最小），即存在唯一的"最靠左上"的颜色 C 精灵体。

**规则**：
1. 读取标记像素的颜色 C。颜色 C 的精灵体为模板来源，颜色 D（非 C、非灰、非黑的另一前景色）的精灵体为计数对象。
2. 对颜色 D 的精灵体进行 4-连通检测，计算其总数量 k。
3. 取颜色 C 的所有精灵体中，边界框左上角最靠左上的那个（按行优先、列次之）作为印章模板 T。记 T 的边界框宽度为 w、高度为 h。
4. 将全部原有颜色 C 和颜色 D 的精灵体从网格中擦除（设为黑(0)）。保留角括号和标记像素不变。
5. 以角括号边界框的左上角为起始位置，向右每隔 (w+1) 列放置一个 T 的副本（保持颜色 C），直到下一个副本完全超出网格右边界时停止。将这些副本从左到右编号为 1, 2, 3, ...
6. 编号为 k 的整数倍的副本（即第 k, 2k, 3k, ... 个）重涂为品红(6)。
7. 对每个品红副本，以该副本的位置为起点，向下每隔 (h+1) 行重复放置品红色的 T 副本，直到下一个副本完全超出网格下边界时停止。
8. 所有副本若部分超出网格边界，超出部分直接裁剪丢弃。

**关键洞察**：散布的颜色 D 精灵体不是视觉元素，而是一组一进制计数器；它们的数量编码了印章网格中品红列出现的节拍周期，改变 D 的数量会改变整个网格图案的结构。

## 新题 2：对角链拓扑编码镜像轴

**组合逻辑**：[连通检测 + 对角链式连接](创新：8-连通区域的内部拓扑不再用于决定变色，而是编码面板的几何变换类型) + [镜像](创新：镜像轴不由显式引导线给出，而由标记区域的连通拓扑隐式编码) + [重涂色](创新：消除编码标记，使变换指令在输出中不可见)

**来源原语**：八连通区域、对角链式连接、仅对角接触变色（ecb67b6d）；镜像、九宫面板、引导线、轴线决定变换（4e7e0eb9）；重涂色（880c1354）

**依赖链**：灰色标记区域的 4-连通分解决定了拓扑类型（对角链 vs 实心块），拓扑类型决定镜像轴方向，镜像改变面板内容的空间排列，最后标记被重涂消除——拓扑分析的结果被镜像操作消费，而重涂消除了推理线索。

分析每个面板内灰色标记区域的内部连通拓扑，以此决定镜像方向，然后将标记吸收进面板图案。

**输入结构**：约 19x19 网格，由灰(5)的单像素宽网格线分割为 3x3 共 9 个面板，每个面板内部为 5x5。每个面板包含：
- 黑(0)背景上的一组彩色像素图案（使用蓝(1)、红(2)、绿(3)中的一种，每面板一色）。图案为 3-8 个非对称分布的像素。
- 恰好一个灰(5)标记区域（3-5 像素），位于面板内不与彩色图案重叠的位置。标记区域是 8-连通的（作为整体连通），但其内部 4-连通结构分为两种情况之一：
  - **对角链型**：标记区域可分解为 2-3 个 4-连通团块，团块之间仅通过对角角点接触（形成阶梯状链），无 4-连通的直接相邻。
  - **实心型**：标记区域本身就是一个 4-连通区域（所有像素通过上下左右相邻彼此连通）。
- 生成约束：每个面板的彩色图案关于该面板的水平中轴或垂直中轴均不对称（确保镜像产生可观察的变化）。9 个面板中两种标记类型至少各出现 2 次。

**规则**：
1. 对每个面板，提取其灰(5)标记区域。
2. 将标记区域分解为 4-连通团块。检查团块间的连接方式：
   - 若所有团块仅通过对角角点相连（即任意两个不同团块之间无 4-连通相邻，但存在 8-连通相邻），则该面板为"对角链型"。
   - 若标记区域整体就是单个 4-连通区域，则该面板为"实心型"。
3. 对角链型面板：以面板的垂直中轴为轴，将面板内容（含彩色图案，不含标记）左右镜像。
4. 实心型面板：以面板的水平中轴为轴，将面板内容（含彩色图案，不含标记）上下镜像。
5. 镜像完成后，将每个面板中的灰(5)标记像素重涂为该面板中彩色图案的颜色（即标记像素变为与该面板的蓝/红/绿图案同色）。
6. 灰(5)网格线保持不变。

**关键洞察**：面板内没有显式的引导线——灰色标记区域的拓扑结构（对角阶梯 vs 实心块）本身就是镜像轴的编码；完成镜像后标记被吸收进图案，编码信息在输出中消失。

## 新题 3：推移方向统计为方位柱状图

**组合逻辑**：[推移 + 接触侧决定方向](保留) + [计数 → 排序 → 柱状填充](创新：不是计数对象数量，而是统计推移方向的频次；柱状图不是独立输出而是绘制在被清空的原位中心区域)

**来源原语**：推移、擦除、固定标记、接触侧决定方向、推至边界停止（5623160b）；计数、排序、柱状填充（2753e76c）

**依赖链**：接触侧分析产生推移方向（空间分析→运动），推移将对象移至边界并清空中心区域（运动→空间变化），清空区域成为柱状图画布（空间变化→可视化条件），方向频次统计产生柱状图数据（运动统计→数据），柱状图绘制方向与推移方向同构（数据→空间表达）。

将接触标记的对象各自推至网格边界，统计四个方向的推移次数，在中心被腾空的区域绘制方向对齐的柱状图。

**输入结构**：黑(0)背景，约 15x15 网格。包含：
- 栗(9)像素组成的固定标记，位于网格中心偏近的区域，形成一个 4-连通的十字形或 T 形结构（5-9 像素）。
- 4-8 个小型 4-连通单色对象，分布在标记四周，使用 2-4 种不同颜色（蓝(1)、红(2)、绿(3)、黄(4)），每个对象由 2-5 像素组成。
- 每个对象恰好有一条边（1 个或多个像素）与栗色标记 4-连通相邻，且该相邻仅发生在一个基本方向上（即对象完全位于标记的上方/下方/左方/右方之一，接触边位于对象朝向标记的那一侧）。
- 生成约束：四个基本方向（上/下/左/右）上各至少有 1 个对象；同方向的对象互不挡路（推移路径无冲突）。

**规则**：
1. 对每个非栗色前景对象，确定其与栗色标记接触的基本方向，推移方向为该方向的反向（远离标记）。例如对象在标记上方、接触标记的顶边 → 对象向上推移。
2. 将每个对象从原位擦除，然后沿推移方向平移，直到对象的边界像素触及网格边缘（对象紧贴边缘，不超出）。
3. 栗色标记保持不变。
4. 统计四个方向各有多少对象被推移：记 n_up, n_down, n_left, n_right。
5. 以栗色标记的质心像素（四舍五入取整）为中心点，向四个方向绘制灰(5)柱状条：
   - 向上：从中心点上方第 1 格开始，连续填充 n_up 个灰色像素。
   - 向下：从中心点下方第 1 格开始，连续填充 n_down 个灰色像素。
   - 向左：从中心点左方第 1 格开始，连续填充 n_left 个灰色像素。
   - 向右：从中心点右方第 1 格开始，连续填充 n_right 个灰色像素。
6. 若灰色柱状条与栗色标记像素重叠，栗色优先保留。

**关键洞察**：每个对象的接触侧既是推移指令（决定运动方向）又是方位投票（计入统计）；推移物理清空中心区域，为柱状图腾出画布，而柱状图的四条臂恰好指向对象离去的四个方向。

## 新题 4：标记邻域选色抑制像素放大掩码

**组合逻辑**：[标记像素](创新：标记不再位于角括号内，而是网格中的独立像素，其邻域信息编码操作参数) + [擦除](创新：不是从网格中擦除像素，而是从像素放大的掩码计算中排除一种颜色) + [像素放大 + 掩码映射 + 自身色选掩码](创新：掩码计算中增加了一个被抑制的颜色通道，且标记像素自身采用被抑制颜色的掩码)

**来源原语**：像素放大、掩码映射、自身色选掩码、全局掩码、块单元（973e499e）；擦除、标记像素、按标记色选择同色（1e81d6f9）

**依赖链**：标记像素的 4-邻域颜色分析确定"被抑制色"（局部空间分析→颜色选择）；被抑制色从所有块的掩码运算中被排除（颜色选择→全局掩码修改）；标记像素自身的块采用被抑制色的掩码图案（颜色选择→特殊块内容）——同一个选择结果同时改变了全局规则和局部规则。

读取标记像素邻域确定一种颜色，将该颜色从全局掩码映射中抑制，同时标记像素的块采用该被抑制颜色的掩码。

**输入结构**：约 4x4 的小网格（无黑色像素，全为前景色），使用 3 种非黑颜色，如蓝(1)、红(2)、绿(3)。其中：
- 恰好有一个像素为灰(5)，即标记像素。
- 灰(5)像素的 4-邻域中至少包含 2 种不同颜色。
- 生成约束：灰(5)像素的 4-邻域中，恰有一种颜色的出现次数严格最少（唯一最少），称为"被抑制色" S。每种非灰前景色在网格中至少出现 2 次。

**规则**：
1. 确定被抑制色 S：统计灰(5)像素的 4-连通邻居中各颜色的出现次数，出现次数最少的那个颜色为 S。（生成保证唯一最少。）
2. 对输入网格执行像素放大：输出是一个 (4*H) x (4*W) 的网格（H、W 为输入高宽），每个输入像素对应一个与输入同尺寸的块。
3. 对于颜色为 c（c 不等于灰(5)且 c 不等于 S）的输入像素，其对应块的规则为：在输入中颜色也是 c 的位置写 c，在输入中颜色是 S 的位置写黑(0)，在输入中颜色是灰(5)的位置写黑(0)，在输入中颜色是其他非 c 非 S 非灰色的位置也写黑(0)。即：只保留自身颜色的掩码，且被抑制色位置一律变黑。
4. 对于颜色为 S（被抑制色）的输入像素，其对应块为：在输入中颜色也是 S 的位置写 S，其他位置写黑(0)。即被抑制色的像素仍然正常执行自身色掩码映射（不受抑制）。
5. 对于灰(5)标记像素，其对应块采用被抑制色 S 的掩码图案：在输入中颜色是 S 的位置写灰(5)，其他位置写黑(0)。

**关键洞察**：灰色标记不仅标识位置，还通过邻域投票选出一种颜色来全局抑制；但被抑制色自身的块不受影响，而标记像素反而采用了被抑制色的掩码图案——标记"消灭"了一种颜色在其他块中的存在，却在自己的块中"继承"了该颜色的分布。

## 新题 5：拉伸精灵体入框后按最近边涂色

**组合逻辑**：[拉伸 + 包围盒映射 + 线段连接再填充](保留核心拉伸机制) + [重涂色 + 最近边归属 + 最近边决定涂色](创新：重涂色的对象不是预先存在的掩码，而是拉伸操作动态生成的填充区域；最近边的颜色来自框架四边而非独立的四根色条)

**来源原语**：拉伸、填充、精灵体、空心矩形、包围盒映射、线段连接再填充（465b7d93）；重涂色、裁剪、最近边归属、最近边决定涂色（9aec4887）

**依赖链**：拉伸操作将小精灵体映射到框架内部并填充，生成一个形状（几何生成→形状）；该形状中每个像素的位置相对于框架四边的距离决定其最终颜色（位置→颜色分配）。精灵体形状的不同导致拉伸后的填充区域不同，进而导致最近边分配完全不同——形状和颜色通过距离计算紧密耦合。

将外部小精灵体拉伸映射进彩色边框内部并填充封闭区域，然后根据每个填充像素到框架四边的最近距离将其涂为对应边的颜色。

**输入结构**：黑(0)背景，约 15x15 网格。包含：
- 一个空心矩形框架，由四段不同颜色的边组成（不含四个角像素，角像素为黑(0)）：上边红(2)、右边蓝(1)、下边绿(3)、左边黄(4)。框架的内部区域约 7x7 到 9x9，全为黑(0)。
- 框架外部有一个灰(5)的 4-连通小精灵体（3-6 像素），不接触框架。精灵体的像素构成一个可辨识的连通形状（非线性，至少有一个分叉或转角）。
- 生成约束：精灵体的像素数至少为 3，边界框至少 2x2。精灵体形状使拉伸后能产生可填充的封闭区域（至少 3 个精灵体像素不共线）。

**规则**：
1. 将精灵体裁剪为其边界框。
2. 将精灵体边界框的四个极点（最上、最右、最下、最左像素；若某方向有多个极点取质心）映射到框架内部区域的对应边的中点。将精灵体其他像素按在边界框内的相对位置等比映射到框架内部（取四舍五入的整数坐标）。
3. 在框架内部，对映射后相邻的精灵体像素对（在原精灵体中 4-连通相邻的），用灰(5)绘制连接它们映射位置的直线段（水平或垂直线段；若两个映射位置既不同行也不同列，先水平后垂直绘制 L 形折线）。
4. 在框架内部，将被灰色线段完全封闭的黑色区域（4-连通的黑色连通体，其所有边界邻居均为灰色线段或框架边）填充为灰(5)。
5. 对框架内部每个灰(5)像素，计算其到框架内部区域四条边的曼哈顿距离（到上边界 = 该像素行号 - 内部区域顶行行号，到下边界 = 内部区域底行行号 - 该像素行号，左右类似）。
6. 若最近边唯一（严格最小值唯一），将该像素重涂为对应边颜色：最近上边 → 红(2)，最近右边 → 蓝(1)，最近下边 → 绿(3)，最近左边 → 黄(4)。
7. 若最近边不唯一（有两个或更多边距离并列最近），该像素保持灰(5)。
8. 框架的四段边、角的黑像素、框架外部全部保持不变。精灵体从原位擦除。

**关键洞察**：精灵体的形状通过拉伸映射决定了框架内部的填充区域，而填充区域的几何形状又决定了每个像素被哪条边"认领"——同一个精灵体在不同比例的框架中会产生完全不同的颜色分区，形状与颜色通过空间距离深度耦合。

## 新题 6：凸起-缺口不对称编码错切参数

**组合逻辑**：[对称补全 + 凸起 + 缺口 + 对侧互补](保留补全机制) + [错切/剪切变换 + 偏移随行距增](创新：错切的方向和幅度不再固定，而由另一个对象的边界缺陷拓扑编码) + 两个对象的空间交互（创新：一个对象的结构信息控制另一个对象的几何变换，然后结构信息本身被修复消除）

**来源原语**：对称补全、凸起、缺口、边界、对侧互补、跨行列投射（8dab14c2）；剪切变换/错切、偏移随行距增、行偏移递变（423a55dc/3cd86f4f）

**依赖链**：蓝色形状的凸起所在的边决定红色矩形的错切方向（边界分析→变换参数选择）；凸起数量决定错切的每行偏移步长（计数→数值参数）；蓝色形状随后被对称补全，消除了方向不对称性（结构修复→信息湮灭）；两个对象最终共存于同一网格，重叠时补全后的蓝色形状覆盖红色（空间交互→冲突解决）。

一个形状的单侧凸起编码了另一个矩形的错切方向和步长；凸起被对称补全消除后，编码信息仅存留于红色矩形的变形中。

**输入结构**：黑(0)背景，约 13x16 网格。包含：
- 一个蓝(1)的厚实直角形状（宽度至少 3 像素的矩形或 L 形块），边界上有 1-3 个单像素凸起（tab），全部位于同一条边上（上/下/左/右之一）。对面那条边上有 0-2 个单像素缺口（notch），但缺口数量少于凸起数量。凸起和缺口不在同一行/列上（不成对）。
- 一个红(2)的实心矩形（3-5 行 x 2-4 列），与蓝色形状分离，位于蓝色形状凸起所在边的同侧外方（例如凸起在蓝色形状的右边，则红色矩形在蓝色形状右方更远处）。
- 生成约束：凸起数量 t 满足 1 <= t <= 3；红色矩形距蓝色形状至少 2 列/行；错切后红色矩形不超出网格边界。

**规则**：
1. 识别蓝色形状边界上的凸起（与形状本体仅有 1 个 4-连通前景邻居的蓝色像素）。记录凸起所在的边（上/下/左/右），设为方向 dir。凸起总数为 t。
2. 确定红色矩形的锚边：红色矩形最靠近蓝色形状的那条边为锚边（不动边）。
3. 对红色矩形施加错切变换：对于矩形中距锚边距离为 d 的每一行/列（d 从 0 开始），将该行/列沿 dir 方向平移 d * t 个像素。d=0 的行/列不动。
4. 对蓝色形状执行对称补全：每个凸起在形状的对侧投射一个缺口（移除对侧对应位置的蓝色像素）；每个原有缺口在形状的对侧投射一个凸起（添加蓝色像素）。
5. 若错切后的红色矩形与补全后的蓝色形状有重叠像素，蓝色优先显示。
6. 其余黑色背景不变。

**关键洞察**：蓝色形状的边界不对称（凸起集中在一侧）编码了红色矩形的变换指令——方向和步长；对称补全消除了这种不对称，但红色矩形的倾斜形态永久保留了已消失的编码信息。

## 新题 7：控制条序列换行后逐面板镜像

**组合逻辑**：[生成序列 + 换行平铺 + 控制条 + 条长决定序列](保留序列生成和换行机制) + [镜像 + 轴线决定变换](创新：镜像不作用于面板的原有内容，而作用于从外部换行铺入的序列片段；每个面板独立解码同一信号)

**来源原语**：生成序列、换行平铺、控制条、递增递减游程、长度递增后递减、条长决定序列（5d588b4d）；镜像、九宫面板、引导线、轴线决定变换（4e7e0eb9）

**依赖链**：控制条长度 n 决定 1D 序列的游程结构（长度→算术→几何）；序列被换行铺入面板化的网格，每个面板获得序列的不同片段（1D→2D 分配）；每个面板的引导线决定其片段的镜像方式（局部结构→局部变换）——同一源序列在不同面板中因独立镜像而呈现不同图案。

用控制条生成递增-递减序列并换行铺入面板网格，每个面板根据自身引导线独立镜像其内容。

**输入结构**：约 16x16 网格。包含：
- 第 0 行（最顶行）：从左边缘开始的一段蓝(1)水平条，长度为 n（2 <= n <= 5），其余为黑(0)。
- 第 1 行起至网格底部：由灰(5)单像素宽网格线分割为 2x2 或 2x3 的面板阵列，每个面板内部为 5x5 或 6x6。
- 每个面板内部初始全为黑(0)，但包含一条灰(5)的引导线——要么是完整的水平中心行（5 个灰像素），要么是完整的垂直中心列（5 个灰像素），但不会两者都有。
- 生成约束：至少有一个面板有水平引导线，至少有一个有垂直引导线。面板总数 >= 4。

**规则**：
1. 读取第 0 行蓝色条的长度 n。
2. 生成 1D 前景序列：蓝(1)游程长度依次为 1, 2, ..., n, n-1, ..., 2, 1，相邻游程之间插入 1 个黑(0)间隔像素。
3. 将该 1D 序列按行主序（从左到右、从上到下）填入面板区域。填充时跳过灰(5)网格线所在的行和列，仅写入面板内部像素。面板内部的引导线像素也被跳过（保持灰色）。序列不足以填满所有面板时，剩余位置保持黑(0)。
4. 填充完成后，对每个面板独立执行镜像：
   - 面板含垂直中心引导线 → 该面板左右镜像（引导线本身不动，左半内容与右半内容互换）。
   - 面板含水平中心引导线 → 该面板上下镜像（引导线本身不动，上半内容与下半内容互换）。
5. 第 0 行（控制条行）保持不变。灰(5)网格线保持不变。

**关键洞察**：1D 序列是全局共享信号，但换行将其分配到不同面板后，每个面板根据自己的引导线方向独立镜像——同一段序列片段在垂直引导线面板和水平引导线面板中呈现完全不同的空间图案。

## 新题 8：锚点叠合后按角度循环换色

**组合逻辑**：[透明叠加 + 锚点对齐 + 锚点重合叠加 + 裁剪](创新：叠加不是最终输出，而是产生一个复合结构供后续分析) + [循环轮换 + 环绕角度排序](创新：循环轮换的对象不是预设区域，而是叠合操作动态生成的色块；角度排序的中心不是固定分隔结构，而是锚点叠合位置)

**来源原语**：透明叠加、裁剪、精灵体、锚点像素、锚点对齐、锚点重合叠加（137eaa0f）；重涂色、循环轮换、环绕角度排序、分离区域（880c1354）

**依赖链**：锚点对齐决定精灵体的叠合方式（空间注册→复合形状）；复合形状中各色块的位置决定了角度排序（形状→排序依据）；角度排序决定循环换色的映射关系（排序→颜色重分配）——移动任一精灵体的锚点位置会改变复合形状，从而改变所有色块的角度关系和最终颜色。

将多个带锚点的精灵体叠合，然后对复合体中的各色块按角度循环换色。

**输入结构**：黑(0)背景，约 15x18 网格。包含 3-4 个互不接触的精灵体，每个精灵体由两种颜色组成：
- 恰好 1 个灰(5)像素作为锚点。
- 其余像素为同一种非灰、非黑颜色（各精灵体颜色互不相同，从蓝(1)、红(2)、绿(3)、黄(4)中选取）。
- 每个精灵体为 4-连通（含灰色锚点后整体连通），像素数 4-8。
- 精灵体彼此之间至少间隔 2 像素。
- 生成约束：叠合后各精灵体的非锚点像素不会完全重叠（至少每个颜色有 1 个像素不被其他精灵体覆盖）。叠合后至少存在 3 个不同颜色的 4-连通区域。

**规则**：
1. 将每个精灵体裁剪为其边界框。
2. 选择面积（非锚点像素数）最大的精灵体作为基底，其位置固定。（若面积并列，取边界框左上角行号最小者；仍并列取列号最小者。）
3. 将其余精灵体逐一叠加：移动每个精灵体使其灰(5)锚点与基底的灰(5)锚点对齐到同一坐标。叠加时，若非锚点像素发生重叠，面积较小的精灵体覆盖较大的（后叠加的小精灵体优先显示）。
4. 锚点位置在叠合完成后设为黑(0)（背景）。
5. 裁剪复合体为最小边界框（包含所有非黑像素的最小矩形）。
6. 在裁剪后的复合体中，识别所有 4-连通单色区域（不含黑色背景）。
7. 计算每个区域的质心坐标。以锚点原坐标（裁剪后坐标系中）为中心，计算每个区域质心相对于该中心的角度（以正上方为 0 度，顺时针递增至 360 度）。
8. 按角度从小到大排列区域。执行循环轮换：排序中第 1 个区域的所有像素涂为第 2 个区域原来的颜色，第 2 个涂为第 3 个的颜色，...，最后一个涂为第 1 个的颜色。

**关键洞察**：锚点注册将分散的精灵体融合为一个复合体，复合体内的色块分布是叠合的涌现结果；角度排序和循环换色在这个涌现结构上操作，使得任何一个精灵体的位移都会级联改变所有色块的最终颜色。

## 新题 9：推移至边界后同色配对绘制虚线连接

**组合逻辑**：[推移 + 接触侧决定方向 + 推至边界停止](保留推移机制) + [连线 + 奇偶决定虚线](创新：连线的端点不是预设的角标记，而是推移后的对象位置；虚线的疏密由推移距离这一涌现量决定) + [同色匹配 + 对角配对](创新：配对依据从空间对角位置改为颜色相同，配对对象从标记像素改为推移后的对象)

**来源原语**：推移、擦除、固定标记、接触侧决定方向、推至边界停止（5623160b）；连线、奇偶决定虚线（f35d900a）；同色匹配（8f215267）；对角配对（f35d900a）

**依赖链**：接触侧分析产生推移方向（边界分析→运动参数）；推移将对象送至网格边缘（运动→位置变化）；推移后的位置成为连线端点（位置→几何构造的输入）；同色对象配对确定哪些对象之间画线（颜色匹配→关系建立）；线长由推移后的距离决定，线长又决定虚线的具体图案（距离→视觉节奏）。

将接触标记的同色对象对推向网格边界，然后在每对同色对象之间绘制虚线连接。

**输入结构**：黑(0)背景，约 15x15 网格。包含：
- 栗(9)像素组成的固定标记结构，位于网格中心区域，形成一个 4-连通的紧凑形状（4-8 像素）。
- 恰好 6 个小型 4-连通单色对象（各 2-4 像素），分为 3 种颜色（蓝(1)、红(2)、绿(3)），每种颜色恰好 2 个对象。
- 每个对象恰好在一个基本方向上与栗色标记 4-连通相邻（对象完全在标记的上/下/左/右方，接触边朝向标记）。
- 同色的两个对象位于标记的不同方向（例如一个蓝色对象在标记上方，另一个在标记右方）。
- 生成约束：每个对象推移到边界后不与其他已推移对象重叠；6 个对象覆盖至少 3 个不同方向。

**规则**：
1. 对每个非栗色对象，确定其与栗色标记的接触方向，推移方向为远离标记的方向。
2. 将每个对象从原位擦除，沿推移方向平移至网格边缘（对象紧贴边缘）。
3. 栗色标记保持不变。
4. 对每对同色对象（已在网格边缘），计算两者的质心坐标。
5. 在两个质心之间绘制灰(5)虚线段：
   - 若两质心同行，绘制水平线段。若同列，绘制垂直线段。若既不同行也不同列，绘制 L 形折线（先水平到目标列，再垂直到目标行；水平段在靠近行号较小的质心那一行绘制）。
   - 虚线规则：沿线段路径，从第一个质心出发，依次编号 0, 1, 2, ...。编号为偶数的位置绘制灰(5)，编号为奇数的位置保持黑(0)（或保持原有颜色不覆盖）。
6. 虚线不覆盖已推移到边缘的对象像素和栗色标记像素（遇到这些像素保持原色跳过编号）。
7. 若两条不同颜色对的虚线路径相交，先绘制的线保留（绘制顺序：蓝(1)对先绘、红(2)对次之、绿(3)对最后）。

**关键洞察**：栗色标记是多功能枢纽——它的形状决定了对象的接触方向（发射方向），对象飞向边界后的落点距离决定了配对虚线的长度和节奏；推移既分离了同色对象（创造了需要连接的间距），又通过距离影响了虚线的视觉密度。
