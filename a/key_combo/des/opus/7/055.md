## 新题 1：环路弯折分类驱动选择性象限对称

**组合逻辑**：[环路追踪 trace_cycle](已有) → [分类涂色 classify_and_color](创新：分类结果不仅决定颜色，还决定是否参与对称复制) → [对称补全 symmetry_complete](创新：不同类别像素的反射行为不同，凹弯折不参与反射)

**来源原语**：环路追踪、弯折像素、直行像素、分类涂色（参考题 15663ba9）；对称补全、十字轴线、双轴对称（参考题 60d73be6）

**依赖链**：环路追踪的输出（弯折分类）决定对称补全的输入筛选——凸弯折像素参与全象限反射，凹弯折像素被标记但不反射，直行像素参与全象限反射。分类结果直接改变反射操作的作用范围。删除追踪则无法分类；删除分类则所有像素等同反射（输出错误）；删除反射则无象限扩展。

在一个被十字轴线划分为四象限的网格中，追踪单一象限内的闭合正交环路并分类其弯折像素，然后将凸弯折和直行像素反射到其余三个象限，而凹弯折像素仅保留在原始象限并变色。

**输入结构**：约 17x17 网格。背景为黑(0)。一条完整行和一条完整列由蓝(1)像素填满，形成十字轴线，将网格分为四个象限。恰好一个象限（例如左上）内存在一个由绿(3)像素构成的闭合正交环路：该环路是 4-连通的、一像素宽的闭合回路，每个前景像素恰好有 2 个 4-邻域前景邻居。环路包含至少 2 个凸弯折和至少 1 个凹弯折（即环路不是简单矩形）。其余三个象限为纯背景。生成约束：环路的边界框完全在该象限内，不与十字轴线相邻。

**规则**：
1. 追踪占据象限内的闭合正交环路。对每个像素判定类型：若像素的两个邻居在同一条直线上（水平或垂直），该像素为**直行像素**；否则为**弯折像素**。
2. 对环路中的弯折像素统计转向方向（从前一段到后一段的左转或右转）。出现次数较多的转向方向对应**凸弯折**，出现次数较少的方向对应**凹弯折**。
3. 将环路像素按类型分三组处理反射（反射轴为蓝(1)十字轴线的行和列）：
   - **凸弯折像素**：反射到其余三个象限（跨行轴、跨列轴、跨两轴各一份副本），副本颜色为黄(4)。原位保留绿(3)。
   - **直行像素**：反射到其余三个象限，副本颜色保持绿(3)。原位保留绿(3)。
   - **凹弯折像素**：**不反射**，仅将原位颜色从绿(3)改为红(2)。
4. 蓝(1)十字轴线保持不变。反射副本若落在十字轴线上则不绘制（轴线优先）。
5. 若任何反射副本超出网格边界，则裁剪丢弃。

**关键洞察**：对称补全并非全量复制——凹弯折作为结构缺陷被选择性抑制，导致输出在三个反射象限中出现与原始象限不同的"缺口"。求解者必须先理解环路追踪和弯折分类，才能预测哪些像素会出现在哪些象限。

## 新题 2：像素并集涌现形状匹配决定滑动方向

**组合逻辑**：[计数/分组](已有，按颜色分组) → [像素并集 pixel_union](创新：从关系判断变为主动构造操作，将两个精灵体合并为一个涌现形状) → [形状匹配 shape_match + 旋转翻转等价 dihedral_equiv](已有) → [滑动 slide + 碰撞停止 collision_stop](已有)

**来源原语**：像素并集、双掩码并集等三（参考题 fea12743）；形状匹配、归一化掩码、旋转翻转等价（参考题 6165ea8f）；滑动、墙壁列、同色物体朝同色墙、近者优先不重叠、碰撞停止（参考题 f0100645）

**依赖链**：颜色分组确定哪两个精灵体配对→配对后计算像素并集产生一个"涌现形状"→涌现形状与墙边参考形状做旋转翻转等价匹配→匹配结果决定该对精灵体向哪面墙滑动。不计算并集则无形状可匹配；不做等价匹配则不知滑动方向；不理解滑动规则则不知最终位置。涌现形状在输入中不以单一对象存在，这是组合产生的新逻辑。

在一个左右各有彩色墙壁的网格中，内部散布着成对的小精灵体；将每对精灵体的像素并集与墙边参考形状做旋转翻转等价匹配，匹配到哪面墙的参考形状就向哪面墙滑动。

**输入结构**：约 16x16 网格。背景为黑(0)。最左列全部为蓝(1)（左墙），最右列全部为红(2)（右墙）。紧邻左墙内侧（第 2 列起）有一个灰(5)参考形状，3~5 像素，4-连通；紧邻右墙内侧（倒数第 2 列起）有另一个灰(5)参考形状，3~5 像素，4-连通，与左侧参考形状在旋转翻转下不等价。网格内部散布若干小精灵体，每个精灵体 2~4 像素、4-连通。这些精灵体使用若干非墙非灰的颜色（如绿(3)、黄(4)、橙(7)等），每种颜色恰好出现两个精灵体，形成配对。同色的两个精灵体在空间上不相邻（边界框间距至少 2 像素），且两者的像素无重叠位置。生成约束：每对精灵体的像素并集（将两个精灵体平移到以其联合边界框左上角为原点后合并）在旋转翻转下恰好匹配左侧或右侧参考形状之一，不存在两者都匹配或都不匹配的情况。

**规则**：
1. 按颜色将内部精灵体分组——每种非墙非灰颜色恰好有 2 个精灵体组成一对。
2. 对每对精灵体，计算联合边界框（包含两者的最小矩形），将两个精灵体的像素坐标平移到以该联合边界框左上角为原点，取像素并集得到一个掩码。
3. 将该掩码与左侧灰(5)参考形状和右侧灰(5)参考形状分别做旋转翻转等价比较（8 种 dihedral 变换）。
4. 若并集掩码匹配左侧参考→该对的两个精灵体各自向左滑动（保持形状，水平平移），按照离左墙近的先处理的顺序，每个精灵体滑到碰触左墙或已定位的同方向精灵体时停止（精灵体边界框的最左像素抵达障碍右侧相邻列即停）。
5. 若匹配右侧参考→该对向右滑动，规则对称。
6. 两个灰(5)参考形状在输出中保持不变。左右墙保持不变。
7. 不同对之间的滑动互不干扰（不同颜色的精灵体可以在最终位置重叠，后处理的覆盖先处理的；处理顺序：按配对颜色在输入中首次出现的行优先、列优先的阅读序）。

**关键洞察**：没有任何单个精灵体能告诉你它的目的地——必须先将两个同色精灵体合成一个从未在输入中以单一对象出现的"涌现形状"，再通过旋转翻转等价识别该形状，才能确定滑动方向。

## 新题 3：背景区域计数编码条纹周期

**组合逻辑**：[计数 counting + 连通分量 connected_component](已有) → [条纹传播 stripe_propagation](创新：周期长度不再固定为 3，而由区域计数 N 动态决定) → [重涂色 recolor](创新：绿条纹的"泛洪"重涂作用于屏障像素本身，屏障同时是区域分隔者和重涂目标)

**来源原语**：计数、连通分量、背景区域、前景屏障、区域数编码像素列（参考题 e872b94a）；条纹传播、边界线段、颜色循环、条纹范围差异、重涂色（参考题 221dfab4）

**依赖链**：前景屏障将背景分为 N 个 4-连通区域→ N 作为条纹颜色循环的周期长度→条纹从边界线段向对边传播，每 N 条中最后一条为绿色"泛洪"条纹→绿条纹横穿整行并将该行上的屏障像素也涂绿。屏障承担双重角色：它既创造区域（影响 N 的值），又是绿条纹的涂色目标。删除计数则周期未知；删除传播则无输出变化；删除重涂则丢失绿条纹对屏障的改写效果。

在一个被屏障分割的网格中，统计屏障创造的背景区域数 N，然后从边界黄色线段向对边传播条纹，其中每 N 条一个循环、最后一条为绿色泛洪条纹，绿条纹会重涂整行包括屏障像素。

**输入结构**：约 14x20 网格。背景为青(8)。灰(5)像素构成路径状前景屏障，将背景分割为 N 个 4-连通区域（不同示例中 N 在 3~6 之间变化）。网格顶部边缘有一段由 2~3 个黄(4)像素组成的短线段。网格内部散布若干红(2)色小斑块（各 1~3 像素，不与屏障相邻）。生成约束：屏障不接触顶部边缘（条纹从顶部开始时不会立即碰到屏障），黄色线段不与屏障在同一列。

**规则**：
1. 识别背景色为青(8)，计算青色像素的 4-连通分量数量→ N。
2. 从黄(4)边界线段向下（朝对边）逐行传播条纹。条纹行与条纹行之间间隔 1 行背景（即每隔 2 行放置一条条纹）。
3. 条纹使用长度为 N 的颜色循环：前 N-1 条为黄(4)，第 N 条为绿(3)，然后重新开始循环。
4. 黄(4)条纹仅在黄色边界线段的水平跨度范围内绘制（与参考题 221dfab4 的黄条纹行为一致）。
5. 绿(3)条纹绘制时覆盖该行的**全部列**，并且将该行上所有非背景像素（包括灰(5)屏障像素和红(2)斑块像素）统一重涂为绿(3)。
6. 不在条纹行上的屏障像素和红色斑块保持原色不变。
7. 条纹传播到网格底部边缘时停止（不超出网格）。

**关键洞察**：屏障的空间复杂度（它分割出多少个背景区域）控制着条纹的时间频率——区域越多，绿色泛洪条纹出现得越稀疏。求解者必须对比多个示例中不同的 N 值与对应的条纹周期，才能发现这一编码关系。

## 新题 4：格栅纯色单元格引导精灵体滑动归位

**组合逻辑**：[提取 extract + 格内判定 cell_interior_test](已有，识别纯色单元格) → [擦除 erase](已有，清除噪声单元格) → [滑动 slide](创新：目标不再是固定墙壁而是格栅中特定颜色的单元格位置，运动路径受格栅几何约束) + [碰撞停止 collision_stop](已有)

**来源原语**：提取、分隔线网格、纯色单元格、格内判定、纯色即有效、忽略干扰项（参考题 458e3a53）；滑动、碰撞停止、近者优先不重叠（参考题 f0100645）；擦除（参考题 87ab05b8）

**依赖链**：格栅分析→识别纯色单元格及其颜色和格栅坐标→颜色匹配将外部精灵体配对到目标单元格→精灵体沿格栅通道滑向目标，以分隔线为路径边界→噪声单元格清除后为滑动腾出空间。格栅同时承担三重角色：分析单元（区分信号与噪声）、运动路径约束、停止线。删除格栅分析则无法区分信号与噪声；删除颜色匹配则不知目标；删除滑动则精灵体不移动。

在一个由分隔线网格划分的画布中，识别少数纯色单元格作为目标、清除噪声单元格，然后将外围同色精灵体沿格栅通道滑向匹配颜色的目标单元格。

**输入结构**：约 19x19 网格。背景为黑(0)。橙(7)像素构成完整的水平和垂直分隔线（每条分隔线贯穿整个网格宽度或高度，宽度 1 像素），将网格分为若干矩形单元格（例如 4x4 的格栅布局，每个单元格内部约 3x3~4x4 像素）。大多数单元格内部填有重复的多色噪声图案（使用黑(0)以外的至少 2 种颜色混合），但有一个由 2x2 或 2x3 个相邻单元格组成的连续矩形区域，其中每个单元格内部为纯粹的单一颜色。这些纯色单元格各不相同，使用蓝(1)、红(2)、绿(3)、黄(4)中的 2~4 种颜色（每种颜色最多出现一个纯色单元格）。在网格的最外圈分隔线之外的边缘区域（宽 1~2 像素），存在若干 4-连通小精灵体（各 2~4 像素），每个精灵体的颜色与某个纯色单元格颜色相同，且每种纯色单元格颜色在外围恰好有一个对应精灵体。生成约束：每个精灵体沿水平或垂直方向与其目标纯色单元格对齐（即精灵体的行范围或列范围与目标单元格的行范围或列范围有交集）。

**规则**：
1. 用橙(7)分隔行和分隔列将网格切分为矩形单元格。检查每个单元格内部：若内部所有像素为同一种颜色，标记为纯色单元格并记录其颜色和格栅坐标。
2. 将所有非纯色单元格的内部清除为背景黑(0)（保留分隔线）。
3. 对每个外围精灵体，找到与其颜色匹配的纯色单元格作为目标。
4. 将精灵体沿其对齐方向（水平或垂直）向目标单元格滑动，保持精灵体形状不变。精灵体穿过分隔线（分隔线像素被精灵体临时覆盖，精灵体通过后分隔线恢复）。精灵体停在目标单元格外侧紧邻的分隔线位置（精灵体的最近边缘像素落在目标单元格相邻的分隔线上）。
5. 若两个精灵体的滑动路径相交，像素数少的精灵体先停（停在冲突位置前一个像素），像素数多的继续滑动。像素数相同时，距离目标更远的先停。
6. 橙(7)分隔线网格、纯色单元格内容保持不变。

**关键洞察**：格栅不仅是分析工具（区分信号与噪声），更是运动的物理通道——精灵体沿格栅结构滑动、在分隔线上停靠。纯色单元格的空间位置隐式编码了每个精灵体的目的地。

## 新题 5：缺口列频率定义隐式镜像轴

**组合逻辑**：[计数 counting](创新：不是计数连通分量或像素频率，而是统计每列中条缺口的出现次数，将频率最高的列确定为隐式对称轴) → [镜像 mirror](已有) → [颜色互换 color_swap](已有) → [填充 fill](已有，填补缺口)

**来源原语**：条缺口、列对齐、按行序分段涂色（参考题 cf133acc）；镜像、分隔线为对称轴、颜色互换、原位颜色互换（参考题 2b01abd0）；计数（参考题 e872b94a / 5582e5ca）；填充（参考题 5582e5ca / 5ad8a7c0）

**依赖链**：条缺口的空间分布→统计每列的缺口频率→频率最高的列成为镜像轴→一侧的图案跨轴反射到另一侧→原位颜色互换→缺口被所在水平条的颜色填补。镜像轴不是显式的分隔线，而是从缺口分布中统计推断出来的——这是原语间全新的结构关系。删除缺口统计则轴位置未知；删除镜像则图案不复制；删除颜色互换则输出颜色错误。

在一个有多条水平色带（每条带有单像素缺口）的网格中，统计缺口在各列的出现频率，将缺口最密集的列作为隐式镜像轴，反射一侧的图案到另一侧并互换原位颜色，最后填补所有缺口。

**输入结构**：约 12x15 网格。背景为黑(0)。网格中有 5~8 条水平色带，每条带占 1 行、横跨网格全宽，使用蓝(1)和红(2)两种颜色交替（例如奇数行蓝、偶数行红，但不要求严格交替）。每条色带中恰好有 1 个单像素缺口（该像素为背景黑(0)）。缺口分布在不同列中，但其中一列的缺口数量严格多于其他任何列（生成约束：最高频列唯一）。在网格的一侧（镜像轴与网格边缘之间的区域），色带之间的背景行中存在一个由绿(3)和黄(4)两种颜色构成的小图案（4~8 像素，4-连通，位于单侧），另一侧对称位置为纯背景。生成约束：图案完全在轴的一侧，其镜像位置不与任何色带重叠。

**规则**：
1. 识别所有水平色带（整行为同一非背景色、仅含一个背景像素缺口的行）。
2. 统计每一列中包含的缺口数量。找到缺口数量最多的列→该列成为垂直镜像轴（若并列则取最左列）。
3. 找到色带之间背景区域中的双色图案（绿(3)和黄(4)构成的 4-连通对象），确定它在镜像轴的哪一侧。
4. 将该图案的每个像素反射到镜像轴的另一侧（列坐标关于轴列对称），反射副本保持原像素颜色。
5. 将原图案的每个像素**原位**颜色互换：绿(3)→黄(4)，黄(4)→绿(3)。
6. 将所有色带上的缺口像素填充为该色带的颜色（消除缺口）。
7. 镜像轴列本身不做任何标记（它是隐式的）。

**关键洞察**：镜像轴不是任何可见的线条或分隔符——它是从条缺口的统计分布中推断出来的隐式结构。求解者必须对比多个示例中缺口位置的变化，才能发现"缺口最密集的列=镜像轴"这一隐蔽规则。

## 新题 6：极值高度竖条定义框架，框内环路弯折分类涂色

**组合逻辑**：[排序 sorting + 高度排名 height_ranking](已有) → [描框 draw_frame](创新：框的几何参数不来自控制像素的极值行列，而来自竖条高度排名的结果) → [包含 containment](已有，判定环路是否在框内) → [环路追踪 trace_cycle + 分类涂色 classify_and_color](已有) + [擦除 erase](已有，清除框外环路)

**来源原语**：排序、竖直线段、高度排名、保留极值高度分色（参考题 a61f2674）；描框、矩形框、极值行列、包含（参考题 e4075551）；环路追踪、闭合正交环路、弯折像素、直行像素、分类涂色、多数转向为凸、少数转向为凹（参考题 15663ba9）；擦除（参考题 87ab05b8）

**依赖链**：竖条高度排名→最高和最短竖条的列位置与高度定义矩形框的四个边→绘制框→判定每个闭合环路是否完全包含在框内→框内环路进行弯折分类涂色，框外环路擦除。三种分析类型（排名、包含判定、环路追踪）形成门控链：排名决定框的几何→框的几何决定哪些环路被处理→被选中的环路才进行弯折分析。删除排名则框未知；删除包含判定则所有环路都被处理（输出错误）；删除环路追踪则框内环路无法分类。

在散布着灰色竖条和绿色闭合环路的网格中，根据竖条高度排名确定最高和最短两根，用它们的列位置和高度定义一个矩形框；框内的环路按弯折凸凹分类涂色，框外的环路擦除。

**输入结构**：约 18x18 网格。背景为黑(0)。5~7 根灰(5)竖直线段（各 1 像素宽），底端均对齐在网格最底行，高度各不相同（从 3 到 15 像素不等，保证最高和最短的高度唯一）。竖条之间间隔至少 2 列。网格中还散布着 2~4 个由绿(3)像素构成的闭合正交环路，每个环路是 4-连通、1 像素宽的闭合回路，每个像素恰好有 2 个前景邻居。每个环路至少有 8 个像素、包含凸凹两种弯折。环路不与任何竖条像素重叠。生成约束：至少一个环路完全在"由最高和最短竖条定义的框"内部，至少一个环路部分或全部在框外。

**规则**：
1. 测量每根灰(5)竖条的高度（像素数）。找到高度最大的竖条（记其列为 C_tall、高度为 H_tall）和高度最小的竖条（记其列为 C_short、高度为 H_short）。
2. 定义矩形框的四条边：左边 = min(C_tall, C_short)，右边 = max(C_tall, C_short)，顶边 = 网格最底行行号 - H_tall + 1（即最高竖条的顶端所在行），底边 = 网格最底行。
3. 将最高竖条的像素重涂为蓝(1)，最短竖条的像素重涂为红(2)。擦除所有其他灰(5)竖条（设为背景）。
4. 用蓝(1)绘制框的左右两条垂直边（从顶边到底边），用红(2)绘制框的上下两条水平边（从左边到右边）。四个角像素使用蓝(1)。若框边与已重涂的竖条重合则不重复绘制。
5. 对每个绿(3)闭合环路，判定其边界框是否完全在矩形框的内部（严格在四条边以内，不接触框边）：
   - **完全在框内**：追踪该环路，统计弯折转向方向。多数转向方向的弯折为凸弯折→重涂为黄(4)；少数转向方向的弯折为凹弯折→重涂为红(2)；直行像素保持绿(3)。
   - **不完全在框内**：擦除该环路所有像素（设为背景黑(0)）。
6. 框的边线覆盖任何与之重叠的像素（框优先级最高）。

**关键洞察**：竖条的高度差异隐式编码了一个矩形边界——不是显式画出的框，而是从"最高"和"最短"的比较关系中涌现的空间结构。这个涌现的边界又成为门控条件，决定哪些环路值得进一步分析。

## 新题 7：瓦片内嵌排除标记的自指编码平铺

**组合逻辑**：[计数 counting](创新：统计瓦片内特殊标记像素的数量，编码排除宽度) → [平铺 tiling + 引导行或列 guide_row_or_column](已有) → [擦除 erase](创新：根据标记像素的列位置和计数结果，选择性删除部分已平铺的副本，制造间断)

**来源原语**：平铺、画布扩展、输入瓦片、引导行或列、引导线选定填充带、引导线定填充带（参考题 15696249）；计数（参考题 e872b94a / 5582e5ca）；擦除（参考题 87ab05b8）；编码映射（参考题 cb2d8a2c）

**依赖链**：瓦片中的蓝(1)标记像素同时编码两种信息——其列位置指定要排除的块列地址，其总数决定每个排除位置的连续排除宽度。平铺操作先正常执行，然后排除逻辑擦掉特定块列处及其右侧相邻的若干块列中的瓦片副本。瓦片既是被复制的图案，又包含控制自身复制方式的元信息——这是自指编码，是源题中不存在的结构关系。删除计数则排除宽度未知；删除位置映射则不知擦哪些列；删除平铺则无基础图案。

一个小瓦片中嵌有蓝色标记像素，标记的列位置指定平铺输出中哪些块列不放置副本，标记的总数决定每个排除点的连续跳过宽度；先正常平铺再按编码擦除。

**输入结构**：一个 n x n 的小瓦片（n 在 4~6 之间）。背景为黑(0)。瓦片中恰好有一行完全由同一种非背景、非蓝颜色填满——这是引导行（例如全部为黄(4)），位于瓦片的第 r 行（0-indexed）。瓦片其余行包含由红(2)、绿(3)、灰(5)等颜色构成的装饰图案。此外，瓦片中有 1~2 个蓝(1)像素散布在非引导行上（蓝像素不出现在引导行中）。生成约束：蓝像素的列坐标互不相同；n >= 4 保证排除后仍有可见的瓦片副本。

**规则**：
1. 识别引导行（瓦片中完全由同一非背景颜色填满的行）及其行索引 r。
2. 记录瓦片中所有蓝(1)像素的列坐标集合 S，以及蓝像素总数 K。
3. 从瓦片中移除所有蓝(1)像素（替换为背景黑(0)），得到清洁瓦片。
4. 创建一个 n x n 块的输出画布，全部初始化为黑(0)。每个块的大小为 n x n 像素。
5. 将清洁瓦片复制到块行 r 的每一个块位置（即输出画布的第 r 个块行中，所有 n 个块位置都放上瓦片副本）。其余块行保持全黑。
6. 对于 S 中的每个列坐标 c：从块列 c 开始，连续 K 个块列（即块列 c, c+1, ..., c+K-1，超出画布右边界的部分忽略）中的瓦片副本被擦除（设为全黑）。
7. 若多个排除区间有重叠，重叠部分仍然为黑（擦除是幂等的）。

**关键洞察**：瓦片是自指的——它既是被复制的内容，又通过嵌入的蓝色标记编码了"哪些副本不应存在"以及"排除区间有多宽"。求解者必须识别出蓝像素不属于图案而是元信息，并分别解码其位置语义（列地址）和数量语义（排除宽度）。
