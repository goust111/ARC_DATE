## 新题 1：面积匹配选框 + 同心环填充

**组合逻辑**：[计数](counting) + [面积匹配](area_matching) → [同心层填充](concentric_fill, 创新：填充色来自源像素颜色而非固定色对) + [擦除](erase)

**来源原语**：计数·面积匹配·源像素集·擦除 ← 7acdf6d3；同心正方形层·控制像素·以控制点为中心·奇偶距离决定颜色 ← b7fb29bc；空心矩形·内部区域·包含 ← 1c786137

**依赖链**：源像素计数的结果决定哪个框被选中；被选中的框内部的控制像素位置决定同心环的中心；源像素的颜色决定环的填充色。三条信息分别来自不同的输入元素，汇聚到同一个填充操作中。

将散布的源像素数量与多个空心矩形框的内部面积匹配，选中匹配框后以其内部控制像素为中心绘制同心环，环色由源像素颜色和距离奇偶性共同决定。

**输入结构**：黑(0)背景上有 3~4 个灰(5)色一像素厚的空心矩形框，大小各异（内部面积分别约为 6、9、12、16 格），互不重叠且相距至少 2 格。每个框内部恰好有一个红(2)色控制像素，位置不在正中心（偏离至少 1 格，使环形图案不对称）。框外散布若干蓝(1)色源像素，源像素之间 4-连通不相连（每个是独立单像素），总数恰好等于某一个框的内部面积（不含控制像素所占格，即内部面积 = 内部背景格数 + 1 个控制像素格，源像素数等于该总面积）。网格大小约 18x18。生成约束：恰好一个框的内部面积等于源像素总数，其余框的面积与源像素数互不相等。

**规则**：
1. 计算所有蓝(1)源像素的总数 N。
2. 计算每个灰(5)空心矩形框的内部面积（边框内侧所围的全部格数，包括控制像素占据的格）。
3. 选中内部面积等于 N 的唯一框。
4. 在选中框的内部，以红(2)控制像素为中心，计算每个内部格到控制像素的切比雪夫距离 d。
5. d 为偶数的格涂蓝(1)（源像素颜色），d 为奇数的格涂黄(4)。控制像素本身 d=0（偶数），涂蓝(1)，即控制像素被覆盖。
6. 擦除框外的所有蓝(1)源像素（恢复为黑(0)背景）。
7. 未被选中的框及其内部保持不变。

**关键洞察**：填充的颜色并非固定配对——偶数环颜色来自源像素的颜色身份，而非颜色编号；需要同时完成"计数选框"和"识别源色"两个独立推理才能确定输出。

## 新题 2：调色板驱动的同心环周期着色

**组合逻辑**：[顺序一一对应](order_correspondence, 创新：对应对象从列段变为距离环) + [同心层填充](concentric_fill) + [裁剪](crop, 创新：裁掉调色板区域)

**来源原语**：调色板列·顺序一一对应·按列段分组匹配 ← 9b365c51；矩形边框·控制像素·同心正方形层·以控制点为中心 ← b7fb29bc；裁剪·内部区域 ← 1c786137

**依赖链**：调色板列的颜色数量决定同心环的周期长度；调色板的顺序决定每一层环的具体颜色；控制像素位置决定环的中心。三者缺一不可。

读取左侧调色板列的有序颜色序列，在右侧矩形框内以控制像素为中心绘制同心切比雪夫环，每层环的颜色按调色板顺序周期循环，输出时移除调色板区域。

**输入结构**：黑(0)背景，网格大小约 16x20（16 行 20 列）。左侧有 3~4 个全高单列调色板列（如第 1 列全为红(2)、第 3 列全为蓝(1)、第 5 列全为绿(3)），调色板列之间隔一列黑(0)背景。右侧（约从第 8 列起）有一个灰(5)色一像素厚的空心矩形框，内部面积约 8x10。框内恰好有一个橙(7)色控制像素。框内其余格为黑(0)背景。生成约束：调色板列数量在 3~5 之间；框的内部足够大以显示至少 2 个完整的颜色周期（内部短边 >= 调色板列数 x 2）。

**规则**：
1. 从左到右读取调色板列的颜色，得到有序列表 P（如 P = [红(2), 蓝(1), 绿(3)]）。
2. 在灰(5)框内部，以橙(7)控制像素为中心，计算每个内部格的切比雪夫距离 d。
3. 将距离 d 映射到调色板颜色：颜色 = P[d mod len(P)]。控制像素本身 d=0，涂 P[0]。
4. 从输出中移除调色板区域：将调色板列及其间隔列全部设为黑(0)背景。仅保留框及其内部填充结果。
5. 灰(5)框边框本身保持不变。

**关键洞察**：同心环的视觉周期模式直接编码了调色板的长度——看到 3 色循环就知道调色板有 3 列，但颜色的具体对应顺序需要对比调色板的从左到右排列才能确定。

## 新题 3：十字扩展遇障碍截停 + 触碰数决定中心重涂

**组合逻辑**：[扩展](expand) + [碰撞转向](collision_turn, 创新：碰撞不转向而是截停) → [计数](counting, 创新：计数对象是被截停的方向数) → [重涂色](recolor)

**来源原语**：十字图案·扩展·正交对角分工·臂色中心色分延 ← 0962bcdd；障碍像素·碰撞转向·遇障碍直角转 ← 6bcdb01e；计数 ← 多题；重涂色·面积决定颜色 ← e8593010

**依赖链**：十字扩展的形态被障碍像素截断，截断数量只有在扩展完成后才能统计，而截断数量反过来决定中心像素的最终颜色。障碍像素同时承担"塑造扩展形状"和"编码中心颜色"双重角色。

每个两色十字向外扩展臂和对角线，遇障碍像素则该方向截停；统计每个十字被截停的方向数，据此重涂中心像素颜色。

**输入结构**：黑(0)背景，网格大小约 20x20。网格上有 3~5 个独立的 3x3 两色十字图案：每个十字的四臂为蓝(1)，中心为红(2)。十字之间相距至少 5 格。网格上另有若干灰(5)障碍像素散布，每个障碍像素是独立单像素。障碍像素不与任何十字的 3x3 范围重叠，但可能出现在十字向外扩展 1~3 格的路径上。生成约束：每个十字的 8 个扩展方向（4 正交 + 4 对角）中，被障碍截停的方向数在 0~4 之间，且不同十字的截停数不全相同。

**规则**：
1. 对每个十字图案执行扩展：臂色蓝(1)沿 4 个正交方向（上、下、左、右）各延伸 1 格；中心色红(2)沿 4 个对角方向各延伸 1 格。扩展后十字占据 5x5 区域（中心 3x3 + 正交外延 + 对角外延）。
2. 截停规则：若某方向延伸的目标格已被灰(5)障碍像素占据，则该方向不延伸（不绘制该格）。障碍像素本身保持不变。
3. 扩展完成后，对每个十字统计被截停的方向总数 S（正交和对角方向合计，0 <= S <= 8）。
4. 根据 S 重涂该十字的中心像素（仅中心 1 格）：S = 0 保持红(2)不变；S = 1 或 2 涂绿(3)；S = 3 或 4 涂黄(4)；S >= 5 涂橙(7)。
5. 十字的臂和对角延伸部分颜色不变（蓝(1)和红(2)）。

**关键洞察**：障碍像素不只是视觉上切割了十字的轮廓——它们的数量隐式编码了中心颜色的变换规则，必须先完成扩展推演、再回头统计截止数，才能确定中心色。

## 新题 4：门位置定义对称轴 + 走廊内图案镜像补全

**组合逻辑**：[寻路](pathfinding, 创新：不画路径而是提取门中心坐标作为对称轴参数) + [对称补全](symmetry_completion) + [填充](fill, 创新：填充受墙壁边界约束)

**来源原语**：平行墙壁·门段·穿越门中心 ← 7e576d6e；对称补全·镜像·缺失区域·对称轴 ← 9ecd008a；墙壁像素·墙壁界定范围 ← 78e78cff

**依赖链**：门段的中心位置决定每条走廊的对称轴在哪一列（或哪一行）；对称补全需要知道轴才能执行镜像；而补全范围受走廊宽度（由平行墙壁界定）约束，超出走廊的部分不绘制。

平行墙壁之间的走廊各含一个半边图案，以该走廊上方墙壁的门段中心列为对称轴进行镜像补全。

**输入结构**：黑(0)背景，网格大小约 20x15。3~4 条水平灰(5)墙壁横贯整个网格宽度，将网格分成 2~3 条走廊（每条走廊高 3~5 行）。每条墙壁上有一个 3 像素宽的门段（门段处墙壁像素被替换为黑(0)背景，形成缺口）。每条走廊内，门段中心列的一侧（左侧或右侧）有一个由红(2)像素组成的小图案（2~5 像素的 4-连通图形），另一侧为空（黑(0)背景）。生成约束：每条走廊的门位置不同（门中心列各不相同）；每条走廊内的图案完全位于门中心列的某一侧，且镜像后不会超出网格边界；不同走廊中图案所在侧可以不同（有的在门左侧，有的在门右侧）。

**规则**：
1. 识别所有水平灰(5)墙壁及其上的门段（3 像素宽的黑(0)缺口）。
2. 对每条走廊（两条相邻墙壁之间的区域），取该走廊上方墙壁的门段中心列作为该走廊的对称轴。最上方走廊（网格顶边到第一条墙壁）使用第一条墙壁的门段中心列。
3. 在每条走廊内，将所有红(2)像素关于对称轴做左右镜像：对于位于列 c 的红(2)像素，在列 2*axis - c 处绘制红(2)像素（axis 为对称轴列号）。
4. 镜像目标格必须在该走廊范围内（不越过墙壁行）且在网格列范围内，否则不绘制。
5. 原有红(2)像素保留，墙壁和门段保持不变。

**关键洞察**：对称轴不是网格中心或固定位置——它由每条墙壁上门的位置隐式指定，不同走廊有不同的对称轴，必须逐一识别门段才能确定各走廊的镜像方向。

## 新题 5：异常精灵体频率决定放大倍率

**组合逻辑**：[图案匹配](pattern_match) + [异常值选择](outlier_selection) → [计数](counting, 创新：计数对象是多数组的出现次数) → [像素放大](pixel_upscale, 创新：倍率由频率而非色数决定) + [擦除](erase)

**来源原语**：精灵体·连通分量·图案匹配·唯一图案选取·异常值选择·忽略干扰项 ← cd3c21df；像素放大·整体缩放·色数决定倍率 ← d4b1c2b1；计数 ← 多题；擦除 ← 7acdf6d3

**依赖链**：必须先对比所有精灵体的裁剪图案才能找到异常值；多数组的重复次数只有在分组后才能得知；而该次数直接决定异常精灵体的放大倍率。删掉图案匹配或计数中的任何一步都无法得出正确输出。

找出唯一不重复的异常精灵体，将其按多数精灵体的出现次数进行像素放大，擦除所有其他精灵体。

**输入结构**：黑(0)背景，网格大小约 15x15。网格上有 5~7 个小型 4-连通前景精灵体（每个精灵体 3~6 像素），颜色可为蓝(1)、红(2)、绿(3)等非背景色，每个精灵体可包含多种颜色。精灵体之间 4-连通不相连，相距至少 2 格。其中一种图案（含颜色的边界框裁剪完全相同）恰好出现 K 次（K = 2 或 3），其余精灵体各自图案互不相同且每种只出现 1 次。生成约束：恰好有一组重复精灵体（出现 K 次，K >= 2），其余每种图案仅出现 1 次；在所有仅出现 1 次的精灵体中，恰好有一个被指定为"异常值"——它是唯一一个与重复组颜色集合完全不同的精灵体（其他单次精灵体至少与重复组共享一种颜色，异常值不共享任何颜色）。异常值精灵体的边界框尺寸乘以 K 后不超过网格大小。

**规则**：
1. 将每个精灵体裁剪为其边界框（含框内背景像素）。
2. 按裁剪图案分组，找到出现次数最多的组（重复组），记其出现次数为 K。
3. 在所有仅出现 1 次的精灵体中，找到与重复组不共享任何前景颜色的唯一精灵体，即异常值精灵体。
4. 对异常值精灵体执行像素放大：将其边界框裁剪中的每个像素替换为 K x K 的同色方块。
5. 将放大后的图案放置在异常值精灵体原始边界框左上角的位置。
6. 擦除所有其他精灵体（恢复为黑(0)背景）。

**关键洞察**：放大倍率不写在输入的任何显式数字中——它隐藏在重复精灵体的出现频率里，求解者必须先完成分组计数才能推断倍率，而异常值的选取需要颜色集合比对而非简单的频率排序。

## 新题 6：平行四边形边界框裁剪 + 宽高比决定镜像轴

**组合逻辑**：[对角分解](diag_decompose) + [标记为对顶点](markers_as_vertices) → [裁剪](crop, 创新：裁剪区域由平行四边形的边界框而非现有框架决定) → [镜像](mirror) + [宽高比决定镜像轴](aspect_ratio_determines_mirror_axis)

**来源原语**：平行四边形轮廓·对角分解·标记为对顶点·标记像素 ← cb227835；裁剪·包含 ← 1c786137；镜像·宽高比决定镜像轴·母题在框架内 ← 18419cfa

**依赖链**：标记像素的位置决定平行四边形的几何形状；平行四边形的边界框决定裁剪范围；裁剪范围的宽高比决定镜像轴向。三个环节串联且信息逐步变换（坐标→几何→比例→轴向）。

两个标记像素定义一个平行四边形，以其边界框裁剪网格内容，再根据边界框的宽高比选择镜像方向输出。

**输入结构**：黑(0)背景，网格大小约 20x20。网格上有两个橙(7)标记像素，它们之间的行偏移和列偏移均不为零且绝对值不相等（如行偏移 3、列偏移 5）。在两个标记像素的边界框范围内（以标记像素为对角的矩形区域），分布着一些蓝(1)和红(2)像素组成的不规则图案。该图案不具有任何对称性，且完全位于边界框内部。边界框外无前景像素（标记像素除外）。生成约束：两标记像素的行列偏移绝对值之差至少为 2（确保宽高比明显偏向一侧）；图案不接触边界框的边缘行或边缘列（留出至少 1 格空白边距）。

**规则**：
1. 将两个橙(7)标记像素之间的向量分解为一个 45 度对角向量和一个剩余的水平/垂直向量（分解方式与参考题 cb227835 相同）。
2. 以这两个向量为邻边、标记像素为对顶点，确定平行四边形的 4 个顶点。
3. 计算平行四边形的轴对齐边界框（包含所有 4 个顶点的最小矩形）。
4. 以该边界框裁剪输入网格（输出大小 = 边界框大小）。裁剪区域内保留所有像素（含标记像素和图案像素）。
5. 判断边界框的宽高比：若宽 > 高，对裁剪结果执行左右镜像（每行像素序列反转）；若高 > 宽，执行上下镜像（行序列反转）；若宽 = 高，执行左右镜像。
6. 输出镜像后的裁剪结果。

**关键洞察**：裁剪区域并非直接由标记像素的矩形框确定——中间经过了平行四边形的几何构造，平行四边形的形状可能使边界框比标记像素的直接矩形更大或方向不同，从而改变宽高比和最终的镜像轴向。

## 新题 7：色数决定印章尺寸 + 重叠区多数投票

**组合逻辑**：[计数](counting) + [色数决定倍率](color_count_scale, 创新：色数决定印章边长而非全局缩放) → [印章覆盖](stamp_overlay) + [仅填背景格](only_bg_filled, 创新：取消此约束，允许重叠) → [多数投票](majority_vote, 创新：投票发生在重叠区而非固定分区)

**来源原语**：色块·色数决定倍率·计数 ← d4b1c2b1；标记像素·印章覆盖·邻域块·中心邻域·仅填背景格 ← f0df5ff0；多数投票·多数决 ← 27a77e38

**依赖链**：输入的颜色多样性决定印章尺寸；印章尺寸决定哪些印章之间会产生重叠；重叠区域需要多数投票来解决冲突。增减一个标记像素可能改变总色数，从而改变所有印章的大小和全部重叠关系——这是一个全局耦合的涌现效应。

统计输入中的不同颜色数 K，将每个前景标记像素扩展为以其为中心的 K x K 同色方块，重叠处取周围印章的多数颜色。

**输入结构**：黑(0)背景，网格大小约 18x18。网格上散布 4~6 个不同颜色的单像素标记，颜色从蓝(1)、红(2)、绿(3)、黄(4)、灰(5)中选取（每个标记颜色不同）。标记像素之间相距 3~6 格，部分标记之间距离较近（扩展后会重叠），部分较远（不会重叠）。生成约束：输入中不同颜色总数（含黑(0)背景）K 在 4~6 之间；K 为奇数时，任意两个重叠印章在重叠区域内的像素数之差不超过 1（保证多数投票有唯一结果）；K 为偶数时，同一重叠区域最多只涉及 2 个印章（避免三方平局）；扩展后的印章不超出网格边界。

**规则**：
1. 统计输入网格中出现的不同颜色总数 K（包括黑(0)背景色）。
2. 对每个非背景标记像素，以其为中心生成一个 K x K 的同色方块（标记在方块正中心；K 为偶数时中心取左上偏移，即中心位于第 K/2 行第 K/2 列，0-indexed）。
3. 将所有方块绘制到网格上。对于无重叠的格子，直接绘制对应颜色。
4. 对于被多个方块覆盖的重叠格子，统计覆盖该格的各方块颜色，取出现次数最多的颜色（多数投票）。若两色票数相等，取行号较小的印章来源的颜色；若行号也相同，取列号较小的。
5. 不在任何方块范围内的格子保持黑(0)背景。

**关键洞察**：印章大小不是固定的——它由输入的颜色多样性隐式编码。增加一种新颜色的标记会同时增大所有印章（包括新标记自身的），导致重叠格局整体改变，这种全局耦合使得无法逐个标记独立求解。

## 新题 8：列段内嵌连通分量计数 → 列段重涂色

**组合逻辑**：[按列段分组匹配](column_run_group_match, 保留列段分割方式) + [连通分量](connected_component) + [计数](counting, 创新：计数对象是列段内的连通分量数) → [重涂色](recolor, 创新：重涂颜色由分量数决定而非外部调色板)

**来源原语**：目标列段·按列段分组匹配·顺序一一对应 ← 9b365c51；连通分量·面积分级 ← e8593010；计数 ← 多题；重涂色 ← e8593010 / 9b365c51

**依赖链**：必须先按列段规则将目标图形分割为若干块（空间分割），再在每块内部独立统计嵌入的连通分量数（局部计数），最后由该计数决定该列段的颜色（映射）。列段分割和分量计数相互依赖——错误的分割会导致错误的计数。

将单色目标图形的列段按内部嵌入的异色连通分量数量进行分类重涂。

**输入结构**：黑(0)背景，网格大小约 15x20。网格右半区有一个灰(5)色的目标图形，由若干列组成，每列有一段连续的垂直灰色区间（类似参考题 9b365c51 的目标图形）。相邻且垂直区间完全相同的列归为一个"列段"。在灰(5)目标图形的内部，嵌入了若干小型 4-连通红(2)连通分量（每个 1~3 像素），这些红(2)像素完全被灰(5)像素包围（位于目标图形内部）。不同列段内的红(2)分量数量不同（0、1、2 或 3 个）。网格左半区为空（无调色板列）。生成约束：每个列段内的红(2)分量数量在 0~3 之间；至少有两个列段的分量数不同。

**规则**：
1. 识别目标图形的列段：相邻列若灰(5)像素的垂直区间完全相同，则归为同一列段（从左到右贪心合并）。
2. 对每个列段，统计其灰(5)区域内部包含的红(2) 4-连通连通分量的数量 C。一个分量若跨越列段边界，归属于其最左列所在的列段。
3. 擦除所有红(2)像素（恢复为灰(5)），使目标图形恢复为纯灰色。
4. 按分量数 C 重涂每个列段的所有灰色像素：C=0 → 蓝(1)；C=1 → 绿(3)；C=2 → 黄(4)；C=3 → 橙(7)。
5. 背景保持黑(0)不变。

**关键洞察**：红色分量是"信使"而非"输出"——它们在输出中被完全擦除，但其在各列段中的分布数量编码了该列段的最终颜色。求解者必须先完成空间分割和局部计数，才能建立颜色映射。

## 新题 9：走廊路径按区段多数色着色

**组合逻辑**：[寻路](pathfinding) + [穿越门中心](through_door_center) → [多数投票](majority_vote, 创新：投票范围是路径经过的每段走廊) → [连线](draw_path, 创新：路径颜色逐段变化而非统一色)

**来源原语**：平行墙壁·门段·走廊路径·穿越门中心·走廊正交路径 ← 7e576d6e；多数投票·计数·最频色写入中心·多数决 ← 27a77e38；连线·标记像素 ← 7e576d6e / cb227835

**依赖链**：路径的几何形状由墙壁和门决定（空间约束）；每段路径的颜色由所经走廊内散布像素的多数色决定（局部统计）；两者必须同时完成——不知路径形状就无法确定路径经过哪些走廊，不知走廊内容就无法确定路径颜色。

在平行墙壁迷宫中画出穿越门中心的正交路径，路径在每段走廊内的颜色取该走廊中散布像素的多数色。

**输入结构**：黑(0)背景，网格大小约 20x18。3~4 条水平灰(5)墙壁横贯网格全宽，将网格分成 2~3 条走廊（每条走廊高 4~6 行）。每条墙壁上有一个 3 像素宽的门段（灰(5)被黑(0)替换的缺口）。两个橙(7)标记像素分别位于最上方走廊的顶边和最下方走廊的底边。每条走廊内散布若干有色像素（从蓝(1)、红(2)、绿(3)、黄(4)中选取），每条走廊内恰好有一种颜色的像素数量严格多于其他颜色（即多数色唯一）。散布像素不位于路径将经过的格子上（不阻挡路径）。生成约束：不同走廊的多数色互不相同（使路径颜色变化可见）；每条走廊内至少有 3 个散布像素。

**规则**：
1. 从上方橙(7)标记像素出发，向下进入第一条走廊，沿参考题 7e576d6e 的规则画正交路径穿越每条墙壁的门中心，最终到达下方橙(7)标记像素。路径规则：在走廊内沿垂直方向前进至墙壁前一行，然后沿水平方向移至门中心列，穿越门进入下一走廊，重复直至到达终点标记。
2. 对每条走廊，统计该走廊内（不含墙壁行、不含标记像素、不含路径格）散布像素的颜色，找到出现次数最多的颜色作为该走廊的多数色。
3. 将路径在每条走廊内的段落涂为该走廊的多数色。路径穿越门段时（在墙壁行上的那一格），涂为该门上方走廊的多数色。
4. 散布像素从输出中擦除（恢复为黑(0)背景）。
5. 墙壁、门段、标记像素保持不变。

**关键洞察**：路径本身是单一几何对象，但它的颜色是分段的——每一段的颜色由局部走廊环境决定，而非由标记像素或全局属性决定。求解者必须同时理解路径的空间结构和走廊的统计属性。

## 新题 10：框架宽高比定镜像轴 + 门缺口定源侧 → 双约束镜像补全

**组合逻辑**：[宽高比决定镜像轴](aspect_ratio_determines_mirror_axis) + [穿越门中心](through_door_center, 创新：门的位置不用于寻路而是标记"源侧") → [镜像](mirror) + [填充](fill, 创新：补全后封闭门缺口)

**来源原语**：矩形框架·母题在框架内·宽高比决定镜像轴·镜像 ← 18419cfa；门段·穿越门中心·平行墙壁 ← 7e576d6e；对称补全·缺失区域 ← 9ecd008a；填充 ← 78e78cff

**依赖链**：框架的宽高比决定镜像轴向（水平还是垂直），但仅凭轴向无法确定镜像方向（从左到右还是从右到左）。门缺口所在的半边指示"源侧"——图案从源侧镜像到对侧。两条约束同时作用于同一个操作，缺少任一条都有两种等概率的输出。

多个矩形框架各含半边图案和一个墙壁缺口；框架宽高比决定镜像轴向，缺口所在半边为源侧，将图案镜像补全到对侧后封闭缺口。

**输入结构**：黑(0)背景，网格大小约 22x22。网格上有 2~3 个互不重叠的灰(5)色一像素厚矩形框架，大小各异。每个框架的宽高比明显偏向一侧（宽框的宽 >= 高 x 1.5，或高框的高 >= 宽 x 1.5）。每个框架的一条边上有一个 1 像素的缺口（该边上一个灰(5)像素被替换为黑(0)背景，形成一个"门"）。缺口的位置将框架分为两半：对于宽框，缺口在左半边或右半边的水平边上；对于高框，缺口在上半边或下半边的垂直边上。在缺口所在的那一半框架内部，有一个由红(2)像素组成的小图案（3~6 像素的 4-连通图形）。另一半内部为空（黑(0)背景）。生成约束：不同框架中缺口所在侧不全相同（至少有一个框架的缺口在不同侧）；图案距离镜像轴至少 1 格（镜像后不与原图案重叠）。

**规则**：
1. 对每个灰(5)矩形框架，计算其内部区域的宽度 W 和高度 H。
2. 若 W > H，镜像轴为框架内部的垂直中线（列 = 框架内部左列 + W/2，取下整）。若 H > W，镜像轴为框架内部的水平中线（行 = 框架内部顶行 + H/2，取下整）。
3. 找到该框架边上的缺口位置，确定缺口在镜像轴的哪一侧——该侧为"源侧"。
4. 将源侧的所有红(2)像素关于镜像轴镜像到对侧：对于垂直轴，列坐标变为 2*axis - c；对于水平轴，行坐标变为 2*axis - r。镜像目标格必须在框架内部范围内。
5. 保留源侧的原始红(2)像素。
6. 封闭缺口：将缺口处的黑(0)像素恢复为灰(5)，使框架重新完整。
7. 所有框架独立处理，互不影响。

**关键洞察**：宽高比告诉你"沿哪个轴镜像"，但不告诉你"从哪边镜像到哪边"——这第二个自由度由门缺口的位置消除。两个几何线索协同解决同一个对称问题，缺少任何一个都会导致输出歧义。
