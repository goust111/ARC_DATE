## 新题 1：叠合涌现与重复图案提取

**组合逻辑**：[透明叠加](已有) → [涌现连通分量识别](创新——叠加后才出现的连通体) → [出现两次者选取](已有，但作用于涌现结果而非原始输入)

**来源原语**：透明叠加、面板、分隔线、同尺寸面板、非空标记合并（7c9b52a0）；裁剪、连通分量、图案匹配、出现两次者选取（f5aa3634）

**依赖链**：叠合操作将分散在多个面板中的碎片合成到同一画布上，产生任何单个面板中都不存在的连通分量；重复计数操作必须作用于叠合结果才能找到目标图案。去掉叠合，碎片无法拼成完整图形；去掉重复筛选，不知道该输出哪个连通分量。

将多个面板的稀疏标记透明叠加，提取叠合后恰好出现两次的涌现图案。

**输入结构**：约 15x20 网格，灰(5) 分隔线将网格分为 2x2 共 4 个等大矩形面板。每个面板以黑(0) 为背景，含 3-5 个稀疏前景像素，颜色取自红(2)、绿(3)、蓝(1)、黄(4)。单个面板内的前景像素互相不 4-连通，无法形成有意义的形状。生成约束：当四个面板的非黑标记叠加到同一画布时，至少形成 3 个不同的 4-连通前景分量，其中恰有一个分量的紧裁剪（包括其边界框内的黑(0) 像素）在叠加画布中出现恰好两次（即存在两个位置不同但裁剪完全相同的分量），其余分量各只出现一次。各面板对同一相对位置的贡献不会产生颜色冲突（即不同面板不会在同一相对位置放置不同的非黑颜色）。

**规则**：
1. 移除所有灰(5) 分隔像素，识别 4 个面板（由分隔线划分的非分隔区域），确认四个面板的边界框尺寸相同（H x W）。
2. 创建一个 H x W 的黑(0) 画布。
3. 按从左上到右下的阅读顺序遍历每个面板。将面板中每个非黑像素复制到画布的相同相对位置。（生成已保证无位置冲突。）
4. 在合成画布中，找到所有 4-连通前景分量。对每个分量做紧裁剪（最小边界框，保留框内的黑像素）。
5. 逐对比较所有紧裁剪（逐像素匹配，含内部黑像素）。返回恰好出现两次的那个裁剪。如果两个实例位于不同位置，输出其中行号较小者（行号相同则列号较小者）的裁剪。

**关键洞察**：单个面板中看不到任何完整图形；只有叠加后才涌现出连通分量，而"出现两次"的筛选条件必须在涌现层面执行——这使得叠加与筛选互为前提，不可分割。

## 新题 2：对角交替着色驱动四重对称补全

**组合逻辑**：[重涂色·奇偶交替](已有) → [对称补全·四重反射](已有，但作用对象从均匀色块变为交替色带，产生全新的视觉干涉)

**来源原语**：重涂色、对角线段、序列索引、奇偶交替涂色（a5f85a15）；对称补全、对称图案、中心对齐、角落补全四重对称（4290ef0e）

**依赖链**：交替着色在每条对角线段上制造蓝-黄节奏，该节奏成为对称补全的输入；对称反射后，交替节奏在四个象限产生相位偏移的干涉图案。若跳过着色，对称补全只是镜像均匀色带（平凡）；若跳过对称补全，只得到散落的交替线段。

将左上象限的对角线段做奇偶交替着色，然后四重反射补全为中心对称图案。

**输入结构**：约 11x11 网格（奇数边长），黑(0) 背景。蓝(1) 前景像素分布在左上象限（行 0..⌊H/2⌋，列 0..⌊W/2⌋），形成 2-4 条沿右下方向的最大对角线段（每条 3-6 像素，相邻像素坐标差为 (+1,+1)）。各线段互不 4-连通。线段集合构成一个"角形"轮廓——即所有前景像素关于中心行和中心列反射后能填满四个象限。生成约束：中心行和中心列上不放置前景像素（它们是对称轴，反射时共享）。

**规则**：
1. 在左上象限中，找到所有最大右下对角线段（沿 (+1,+1) 方向的极大连续像素序列）。
2. 对每条线段，从其左上端点开始沿右下方向编号（索引 0, 1, 2, ...）。保留偶数索引像素为蓝(1)，将奇数索引像素重涂为黄(4)。
3. 确定画布尺寸：设左上象限中前景像素的最大行号为 rMax、最大列号为 cMax，则画布为 (2*rMax+1) x (2*cMax+1)，中心点为 (rMax, cMax)。
4. 将着色后的左上象限图案视为角落基元。沿中心列做水平翻转，填入右上象限；沿中心行做垂直翻转，填入左下象限；同时沿两轴翻转，填入右下象限。中心行和中心列保持黑(0)。
5. 四个象限中的像素互不重叠（因为中心轴无前景），直接合并即可。

**关键洞察**：交替着色在每条对角臂上创建了有方向性的蓝-黄节律。四重反射不改变节律内容但翻转了方向，使得对称后四条同源臂上的蓝-黄位置形成"风车式"相位差——这种视觉复杂性完全来自交替着色与反射的交互，任一步骤单独都不产生此效果。

## 新题 3：异常值提取与稀疏查找表交叉定色

**组合逻辑**：[提取·逐行异常值](已有) + [重涂色·稀疏单元查找](已有) → [交叉引用](创新——两种独立识别机制的结果合并为一个输出)

**来源原语**：提取、网格单元、逐行比较、异常值选择（38007db0, c3202e5a）；重涂色、分隔栅格、位置索引、稀疏单元色查找表（09629e4f）

**依赖链**：非线性结构——两条独立的识别路径并行运行再汇合。路径 A：在每行单元中找异常值，获取输出形状。路径 B：在全局找稀疏单元，获取颜色映射表。两者缺一不可：无路径 A 不知道输出什么形状，无路径 B 不知道涂什么颜色。稀疏单元不是异常值（它可能在自己那行不是唯一的），异常值不是稀疏单元，两种身份完全独立。

在分隔栅格中，逐行提取异常值单元，用全局唯一稀疏单元的颜色映射对异常值重涂色后输出。

**输入结构**：约 17x17 网格。灰(5) 分隔线将网格划分为 3x3 共 9 个等大方形单元（每单元约 5x5）。每个单元以黑(0) 为背景，含若干非黑非灰的彩色像素构成小图案。每行 3 个单元中，有 2 个单元的紧裁剪完全相同（"多数"），另 1 个不同（"异常值"）。全局恰有 1 个单元只含 3 个非黑非灰像素（"稀疏单元"），其余 8 个单元各含 5-6 个。稀疏单元的 3 个彩色像素在单元内分别位于 3 个不同的行（相对于单元自身的行索引 0, 1, 2），每个像素颜色各不相同，取自红(2)、绿(3)、蓝(1)、黄(4)、橙(7)。生成约束：稀疏单元可以是也可以不是其所在行的异常值——两种身份独立。

**规则**：
1. 移除灰(5) 分隔线，将网格拆分为 3x3 的 9 个单元，记单元坐标为 (行号 R, 列号 C)，R, C 各取 0, 1, 2。
2. 对每一行 R 的 3 个单元，对比它们的非黑像素紧裁剪。找到裁剪不同于另外两个的那个单元，即该行的异常值单元。
3. 找到全局唯一的稀疏单元（非黑非灰像素数为 3 的单元）。在稀疏单元内，按该像素在单元内的相对行位置排序（相对行 0 = 顶部，行 1 = 中间，行 2 = 底部），得到 3 个颜色 [color_0, color_1, color_2]。这就是行-颜色查找表：行 R 的目标颜色为 color_R。
4. 对行 R 的异常值单元，将其所有非黑前景像素统一重涂为 color_R。保留黑(0) 背景像素不变。
5. 输出：将 3 个重涂色后的异常值单元自上而下垂直堆叠（行 0 在顶，行 2 在底），单元之间无分隔线，组成一个 (3*cellH) x cellW 的网格。

**关键洞察**：稀疏单元不是"异常值"的同义词——它按像素数量识别，异常值按图案唯一性识别，两种判据完全正交。求解者必须分别执行两种识别，再将结果交叉引用，才能同时确定输出的形状和颜色。

## 新题 4：网格线格纹与同心层着色的优先级干涉

**组合逻辑**：[网格线绘制](已有) + [同心层填充](已有) → [优先级仲裁](创新——两条着色规则同时作用于同一像素时的冲突解决)

**来源原语**：网格线绘制、方阵、网格线、行列索引奇偶性（332efdb3）；同心层填充、实心矩形、同心层、边距深度、奇偶交替着色（516b51b7）

**依赖链**：同时约束满足结构——两条规则并行定义每个像素的颜色，没有固定执行顺序。网格线规则覆盖全局，同心层规则只在矩形内生效。冲突发生在矩形内部的偶数行/列位置，需要优先级规则裁决。去掉网格线规则，矩形外全黑（丢失格纹背景）；去掉同心层规则，矩形只是格纹上的单色块（丢失层深信息）。

在奇数边长方阵上同时绘制周期格纹和矩形内同心层着色，矩形内同心层优先于格纹。

**输入结构**：约 13x13 的奇数边长方阵，全黑(0) 背景。内含 2 个互不接触的单色实心轴对齐矩形，颜色分别为红(2) 和绿(3)，每个矩形的两条边都 >= 3 像素。矩形不触及网格边界，彼此不相邻（最小间距 >= 2）。生成约束：两矩形的行范围和列范围均不重叠。

**规则**：
1. 对输出的每个像素 (r, c)（0-based 索引），首先检查它是否落在某个矩形的边界框内。
2. 若 (r, c) 不在任何矩形内：若 r 或 c 为偶数，涂蓝(1)（格纹线）；若 r 和 c 都为奇数，保持黑(0)。
3. 若 (r, c) 在某矩形内：计算该像素到该矩形最近边的切比雪夫距离 d（即 min(r-rTop, rBot-r, c-cLeft, cRight-c)）。d=0（矩形边框本身）保持该矩形的原始颜色。d 为奇数正整数涂橙(7)。d 为偶数正整数涂黄(4)。
4. 格纹线不穿透矩形——矩形内的像素一律由同心层规则决定颜色。

**关键洞察**：格纹规则和同心层规则各自都很简单，但求解者必须发现矩形边界是两套规则的分界线——矩形内外遵循完全不同的着色逻辑。仅看矩形外的像素会以为规则是"格纹覆盖全局"，但矩形内的像素完全不服从格纹规则。

## 新题 5：拓扑分类滑动后的间距编码射线

**组合逻辑**：[滑动·拓扑分类](已有) → [射线延伸·间距编码](已有，但射线参数由滑动后的中间状态决定，而非原始输入)

**来源原语**：滑动、堆叠、封闭对象、开放对象、封闭孔洞、分离、有孔者升无孔者降、碰撞停止（ac2e8ecf）；射线延伸、色条、距离、距离决定阶梯高度（b8cdaf2b）

**依赖链**：管线结构，但中间状态是全局的——滑动改变了所有对象的位置，射线的高度取决于滑动后的全局布局。封闭对象上移后在某些列留下空白，开放对象下移后在某些列制造拥挤；射线高度编码的正是这种拓扑驱动的空间重排效果。删除滑动步骤，射线高度只反映原始位置（无拓扑信息）；删除射线步骤，只看到对象搬移但无可读的编码输出。

先按拓扑将封闭对象推顶、开放对象沉底，再从底部色条向上发射高度等于间距的射线。

**输入结构**：约 15x12 网格，黑(0) 背景。3-5 个单色 4-连通前景对象，颜色取自红(2)、绿(3)、蓝(1)、品红(6)，每个对象 4-8 像素。其中 1-2 个对象是"封闭"的（其边界框内存在被该对象完全 4-包围的背景孔洞），其余为"开放"的（无包围孔洞的线状/条状精灵体）。最底行全部为橙(7)，作为色条。对象不接触底行色条，不接触网格顶行，各对象互相不 4-连通。生成约束：各对象的列范围可以重叠（但原始位置不碰撞），滑动后堆叠时不会超出网格。

**规则**：
1. 识别每个前景对象（非黑非橙的 4-连通分量）。判断封闭/开放：若对象的边界框内存在被该对象像素 4-围合的黑(0) 区域（flood-fill 从该黑像素出发不能到达边界框外），则该对象为封闭；否则为开放。
2. 创建同尺寸的空白画布，底行保留橙(7) 色条。
3. 封闭对象向上滑动：按原始位置从上到下的顺序依次处理。每个封闭对象保持列位置和形状不变，向上移动直到其最顶像素触及行 0 或触及已放置的其他封闭对象像素的下方一行（紧贴堆叠，不重叠）。
4. 开放对象向下滑动：按原始位置从下到上的顺序依次处理。每个开放对象保持列位置和形状不变，向下移动直到其最底像素触及橙(7) 色条上方一行或触及已放置的其他开放对象像素的上方一行。
5. 对每一列 c（0-based）：在滑动后的画布中，从色条所在行向上扫描，找到该列中第一个非黑非橙像素所在行 rObj。令间距 gap = (色条行 - 1) - rObj。若该列中色条上方无任何前景像素，则 gap = 0。
6. 从色条行 -1 开始，在列 c 向上填充 gap 个橙(7) 像素作为射线。射线不覆盖已有的前景对象像素（若射线路径上遇到前景像素则截断，不含该像素）。
7. 输出即为带有滑动后对象和射线的画布。

**关键洞察**：封闭对象因有孔洞而被推向顶部，其原先所在的列出现大段空白，产生高射线；开放对象沉向底部紧贴色条，其所在列几乎无间隙，射线极短甚至为零。射线的高低差直接可视化了对象的拓扑属性（有无孔洞），而这个信息在原始输入中需要仔细检查才能发现。

## 新题 6：噪声中寻矩形，矩形内含惊喜的周期平铺

**组合逻辑**：[擦除·最大矩形保留](已有) → [平铺·周期重复](已有，但种子并非纯色——矩形内嵌入的异色噪声像素被保留并随平铺扩散，成为周期图案的一部分)

**来源原语**：擦除、实心矩形、噪声像素、面积比较、仅保留最大矩形(91714a58)；平铺、种子图案、周期重复、填满网格(9b30e358)

**依赖链**：擦除步骤识别并隔离最大矩形，但不清除矩形内部碰巧落入的异色噪声——这些"内嵌杂质"成为种子的一部分。平铺步骤将含杂质的种子周期重复，使原本不起眼的 1-2 个噪声像素被放大为全局性的周期纹理。删除擦除步骤，无法在噪声中找到种子；删除平铺步骤，只得到一个带杂质的矩形而非完整图案。

在噪声中找到最大单色矩形，将其（含内部嵌入的异色像素）作为种子周期平铺满整个网格。

**输入结构**：约 12x16 网格，黑(0) 背景。散布 15-25 个单像素噪声，颜色随机取自红(2)、绿(3)、黄(4)、品红(6)。其中蓝(1) 像素由两部分组成：(a) 一个实心轴对齐矩形，尺寸 3x4 或 4x3，(b) 矩形外的 3-5 个散落噪声像素。矩形的边界框内恰好有 1-2 个非蓝非黑的噪声像素（来自其他颜色的噪声恰好落在矩形区域内）。没有其他颜色能形成边长都 >= 2 的实心矩形。生成约束：网格的行数和列数都是矩形对应维度的整数倍（例如矩形 3x4，网格 12x16），以保证平铺无残余。

**规则**：
1. 找到最大面积的单色实心矩形（所有像素颜色相同、两条边都 >= 2 的轴对齐矩形），记其颜色为 C、位置为 (rTop, cLeft)、尺寸为 H x W。
2. 从原始输入中裁剪该矩形的边界框区域，得到 H x W 的种子块。种子块中大部分像素为 C，但包含边界框内所有原始像素（包括嵌入其中的异色噪声像素），原样保留。
3. 创建与输入同尺寸的输出网格。从 (0, 0) 开始，以 H 为行周期、W 为列周期，将种子块重复铺满整个输出。输出像素 (r, c) 的颜色 = 种子块像素 (r mod H, c mod W) 的颜色。
4. 输出即为平铺结果，不保留原始矩形的绝对位置信息。

**关键洞察**：求解者通常会假设"矩形 = 纯色块"，但这道题中矩形内的 1-2 个异色像素不是缺陷而是信号——它们随平铺被复制到全网格，形成有规律的周期斑点。需要对比多个示例才能确认"内嵌噪声被保留"这一反直觉规则。

## 新题 7：缺角三角形构造后的桥接连线

**组合逻辑**：[画线·缺角推断三角形](已有) → [连线·控制序列桥接](已有，但桥接的对象不是预设的带框方块而是推断构造出的三角形，桥接端点由三角形几何决定)

**来源原语**：画线、标记像素、直角三角形、包围方块、缺角定位、缺角为直角顶点、忽略干扰项（1478ab18）；连线、控制序列、行列对齐、访问顺序编码、最近优先（3e6067c3）

**依赖链**：桥接操作的端点是三角形的边界，但三角形在输入中不存在——它们必须先通过缺角推断被构造出来。控制序列指定连接顺序，但连接对象的几何形状（三角形而非矩形）影响桥接的起止位置。删除三角形构造步骤，没有对象可供连接；删除桥接步骤，只有孤立的三角形。

从标记像素组推断缺角三角形，然后按控制序列将三角形用彩色桥接相连。

**输入结构**：约 20x20 网格，黑(0) 背景。3 组标记像素，每组 4 个同色像素：组 A 为红(2)，组 B 为绿(3)，组 C 为蓝(1)。每组的 4 个像素的边界框为正方形，其中 3 个像素恰好位于该正方形的 3 个角，第 4 个像素位于正方形内部（干扰项）。3 个组的边界框互不重叠，且至少有两组在行范围或列范围上有交叠（保证可对齐桥接）。最底行放置 2 个前景像素作为控制序列，从左到右读取为 [c0, c1]，颜色取自红(2)、绿(3)、蓝(1) 中的两个。生成约束：每对需要桥接的三角形在行带或列带上有对齐（边界框的行范围或列范围存在交集）。

**规则**：
1. 对每组标记像素，计算 4 个像素的最小边界正方形。检查正方形的 4 个角位置——恰有 3 个角有标记像素，1 个角为空。空角即为缺失角。
2. 以缺失角为直角顶点，以与缺失角相邻的两个有标记角为另外两个顶点，画直角等腰三角形的轮廓：两条轴对齐直角边 + 一条对角斜边。轮廓使用青(8) 绘制。已有的标记像素保留原色不被覆盖。
3. 读取控制序列 [c0, c1]。连接顺序为：先连 c0 色三角形到 c1 色三角形，再连 c1 色三角形到剩余第三个三角形。
4. 对每对待连接的三角形 (S, T)：找到两者边界框在行范围或列范围上的交集带。若同时存在行交集和列交集，选择使桥接更短的那个轴。沿该轴方向，在交集带的中间行（或中间列）上，从 S 边界框的近端画一条 1 像素宽的水平（或垂直）直线到 T 边界框的近端，颜色为源三角形 S 的标记色。桥接线不覆盖已有的三角形轮廓或标记像素——若路径上有已有像素，桥接线跳过该像素继续（仅填充空白像素）。
5. 输出包含原始标记像素、三角形轮廓和桥接线。

**关键洞察**：输入中没有三角形——只有散落的标记点和一个干扰项。求解者必须先通过"缺角"推断构造出三角形实体，这些实体才成为桥接的锚点。桥接的方向和长度取决于推断出的三角形位置，而非标记点本身的位置。

## 新题 8：频率排序驱动的角色级联印章

**组合逻辑**：[计数·频率排序](创新改造——不按边长而按出现次数排序) → [角色分配](已有) → [印章覆盖·角色级联](创新——印章内的颜色按角色顺位向下级联替换)

**来源原语**：排序、按边长降序排列（c658a4bd，改造为按频率排序）；角色分配、按频率分配（3979b1a8）；印章覆盖、精灵体、阵列排布、高频色位定印章（c3e719e8）

**依赖链**：频率统计决定角色分配（选择器/框架/填充），角色分配同时决定两件事：(a) 选择器颜色的位置确定印章放置位置，(b) 印章内部的颜色按角色顺位级联替换。改变任何一个像素的颜色都可能改变频率排名，从而重新分配角色、重排印章位置和颜色映射。三步环环相扣，不可拆分。

统计 3x3 输入中各色频率，按频率分配角色，在角色选择器位置印章输入图案并级联替换角色颜色。

**输入结构**：5x5 网格，黑(0) 背景上有一个 3x3 的彩色区域（位于中心，行 1-3 列 1-3），使用 3 种非黑颜色，取自红(2)、绿(3)、蓝(1)、黄(4)、橙(7)。3 种颜色在 3x3 区域内的出现次数互不相同（例如 2 次、3 次、4 次）。空间排布不限（不要求角-十字结构）。生成约束：3 种颜色的频率严格递增，无并列。

**规则**：
1. 统计 3x3 区域中每种非黑颜色的像素数，按频率从低到高排序。最少出现的颜色记为 S（选择器），中间频率的为 F（框架），最多出现的为 B（填充/背景角色）。
2. 创建 15x15 的黑(0) 输出网格，划分为 5x5 排列的 3x3 块槽（块槽坐标对应输入 5x5 网格的像素坐标）。
3. 在输入 5x5 网格中，找到所有颜色等于 S 的像素位置 (r, c)。对每个这样的位置，在输出的块槽 (r, c) 中放置一份印章。
4. 印章内容为输入 3x3 区域的副本，但做如下颜色级联替换：S 色替换为 F 色，F 色替换为 B 色，B 色保持不变。
5. 未被印章占据的块槽保持全黑(0)。

**关键洞察**：频率排名不仅决定"在哪里印章"（选择器位置），还决定"印章里的颜色怎么变"（角色级联）。这是一个自指结构：输入的统计属性改写了输入自身在输出中的表现形式。仅看一个示例很难区分"S 被替换为 F"还是"S 被替换为其他固定颜色"，需要对比多个示例（不同频率排名）才能归纳出级联规则。
