## 新题 1：互补掩码级联印章

**组合逻辑**：[印章覆盖 + 自身互补](创新：互补掩码不用于像素放大，而作为级联触发的印章形状) → [级联激活](创新：由印章的空间覆盖范围而非方向端口触发) → [重涂色](创新：依据激活/未激活状态着色)

**来源原语**：印章覆盖 + 自身互补(0692e18c)、级联激活 + 链式反应传播(5961cc34)、重涂色(多题共有)

**依赖链**：每个图形的互补掩码决定了印章的几何形状 → 印章的空间覆盖范围决定了哪些邻近图形被激活 → 激活状态级联传播直至无新图形可达 → 最终的激活/未激活分类决定重涂色结果。删除互补掩码计算则印章无形状；删除级联则只有种子被处理；删除重涂色则无法区分激活与未激活。

将散布的小图形通过互补掩码印章展开，印章的空间覆盖触发邻近图形级联激活，最终按激活状态重涂色。

**输入结构**：黑(0)背景网格，约 20x20。网格中散布 5~7 个小型单色 4-连通图形（每个图形 3~5 像素，占据一个 3x3 边界框内，各图形颜色互不相同，取自蓝(1)、红(2)、绿(3)、黄(4)、灰(5)、品红(6)）。各图形的 3x3 边界框互不重叠，但相邻图形的边界框间距不超过 6 个像素。其中恰好一个图形在其边界框中心像素位置有一个橙(7)像素作为种子标记（该橙像素叠加在图形的前景色之上）。生成约束：每个图形的 3x3 边界框内至少有 3 个黑(0)像素（确保互补掩码非空）且至少有 3 个前景像素（确保印章有足够覆盖）。

**规则**：
1. 对种子图形（含橙(7)标记的图形），将橙像素视为该图形前景色的一部分。提取该图形 3x3 边界框内的互补掩码：边界框内所有黑(0)像素位置构成掩码形状。
2. 以种子图形的边界框为中心，构建 9x9 展开区域（3x3 个 3x3 块）。对于种子图形 3x3 边界框中每个前景像素位置，将互补掩码以该图形的前景色印章到对应的 3x3 输出块中。边界框中黑(0)像素对应的输出块保持黑色。
3. 检查 9x9 展开区域中新出现的前景像素是否与任何尚未激活的图形的 3x3 边界框有重叠（至少 1 个像素位置重合且该位置被印章着色）。若有，该图形被标记为"已激活"。
4. 按扫描序（从左上到右下，以边界框左上角坐标排序）依次处理每个新激活的图形：计算其互补掩码，执行同样的 9x9 印章展开，检查是否触发新的未激活图形。
5. 重复步骤 4 直到一轮扫描中无新图形被激活。
6. 最终输出：所有已激活图形（含种子）的印章展开结果保留其原前景色。所有未激活图形整体重涂为栗(9)色。印章展开区域超出网格边界的部分舍弃。若多个印章展开区域在同一像素重叠，后处理的（扫描序靠后的）覆盖先处理的。

**关键洞察**：每个图形的内部几何形状（哪些像素是前景、哪些是背景）同时决定了两件事——印章的形状和印章的覆盖范围。一个"稀疏"的图形（前景少、背景多）产生大面积但稀疏的印章，可能跳过近邻而激活远处图形；一个"密实"的图形产生小面积但密集的印章，只能激活紧邻图形。级联的拓扑结构完全由各图形的几何形状涌现决定，无法从距离单独推断。

## 新题 2：字形门控弹射路径

**组合逻辑**：[射线延伸 + 边界反射](已有) → [解码指令](创新：字形不编码线段方向，而编码射线遇到字形时的转向指令) → [计数](创新：像素面积不决定颜色或线段参数，而决定射线物理行为) → [重涂色](创新：路径分割的区域面积决定涂色)

**来源原语**：射线延伸 + 边界反射(e179c5f4)、解码指令 + 字形指令(136b0064)、计数(e509e548)、重涂色(多题)

**依赖链**：射线从起点出发沿对角线弹射 → 遇到字形门时，字形的像素面积解码为转向指令，改变射线方向 → 射线继续弹射直到终止 → 路径将网格分为区域，较小区域被重涂色。删除弹射则路径无法延伸；删除字形解码则射线不受门控影响；删除面积计数则转向规则不确定；删除区域涂色则无最终输出变换。

对角弹射射线穿越网格，每经过一个字形门按其像素面积转向，最终路径封闭的较小区域被重涂色。

**输入结构**：黑(0)背景网格，约 15x15。网格底边有一个蓝(1)起点像素。网格内部散布 3~4 个灰(5)色的 3x3 字形门（每个字形是 3x3 边界框内的一个 4-连通灰色图形，像素面积分别为 3、4、5 中的某个值，各字形面积互不相同）。字形门之间不相邻，且不贴靠网格边缘。生成约束：射线从起点出发向右上方 45 度弹射时，其路径会依次穿过每个字形门的 3x3 边界框（即路径与每个字形的边界框至少有 1 个像素位置重合）；射线在经过所有字形门后最终从网格顶边射出。

**规则**：
1. 从蓝(1)起点像素出发，沿右上方 45 度对角线逐步延伸射线，每步行移 1 格、列移 1 格。遇到网格左右边界时水平方向反转（行方向不变），继续弹射。射线路径上的每个像素标记为蓝(1)。
2. 当射线的下一步将进入某个字形门的 3x3 边界框时，在进入点暂停，读取该字形的像素面积（3x3 框内灰色像素总数），按以下规则改变射线的行进方向：
   - 面积 3：射线穿过字形门不改变方向，继续原方向弹射。
   - 面积 4：射线方向顺时针旋转 90 度（例如原方向为右上变为右下）。
   - 面积 5：射线方向逆时针旋转 90 度（例如原方向为右上变为左上）。
3. 方向改变后，从字形门边界框的对侧边缘继续射线延伸。射线穿过字形门时，门内路径像素同样标记为蓝(1)，字形门的灰色像素保持不变。
4. 射线继续弹射（遇到网格边界仍反射），直到从网格的任意外边缘射出。
5. 射线路径将网格划分为若干连通区域（以路径像素和网格边缘为边界，4-连通判定）。计算每个区域的像素面积。将面积严格最小的那个区域中的所有黑(0)像素重涂为青(8)。若最小面积区域有多个且面积相同，全部涂为青(8)。

**关键洞察**：字形门的像素面积不是装饰属性而是物理指令——它直接改写射线的运动定律。求解者必须先识别出"面积→转向"的编码映射（需对比多个示例中不同面积字形对路径的影响），然后才能追踪完整路径并确定涂色区域。路径的最终形状是弹射物理与字形编码的涌现结果。

## 新题 3：四象限互补恢复

**组合逻辑**：[透明叠加](创新：不按固定层序叠加，而按互补恢复逻辑选取像素来源) × [镜像恢复遮挡](创新：不依赖镜像对称轴，而利用四个象限的互补关系恢复) × [排序](创新：前景密度排序决定冲突时的优先象限)

**来源原语**：透明叠加 + 图层优先级 + 象限位决定层序(e99362f0)、镜像 + 反射恢复遮挡 + 遮挡块(dc0a314f)、排序 + 按计数升序排列(85b81ff1)

**依赖链**：四个象限各含同一底图但各有不同遮挡区域 → 对每个被遮像素，需从未被遮挡的其他象限借用 → 当多个象限都可提供同一像素时，按象限前景像素密度排序选取最高密度象限的值 → 输出为完整恢复的单个象限尺寸图案。删除互补恢复则遮挡无法修复；删除密度排序则供体选择不确定。

从四个各自不同区域被遮挡的象限视图中，通过互补借用和密度优先规则恢复出完整底图。

**输入结构**：网格约 19x19（含十字分隔线）。一条水平和一条竖直的品红(6)分隔线将网格等分为四个 9x9 象限（分隔线宽 1 像素）。四个象限各包含同一个底图案（由若干颜色构成，背景为黑(0)），但每个象限内有一个不同位置的矩形遮挡块，遮挡块分别为红(2)、蓝(1)、绿(3)、黄(4)四色实心矩形（约 3x3 至 4x4 大小）。四个遮挡块在各象限的局部坐标中位置互不相同，且任意两个遮挡块的局部坐标范围不完全重叠（确保每个被遮像素至少有一个象限未遮挡）。生成约束：底图中不使用红(2)、蓝(1)、绿(3)、黄(4)这四种颜色（以免与遮挡块混淆）。

**规则**：
1. 移除品红(6)十字分隔线。将四个象限按局部坐标对齐（每个象限为 9x9）。
2. 识别每个象限中的遮挡块：象限内唯一出现的属于{红(2), 蓝(1), 绿(3), 黄(4)}的连通实心矩形即为该象限的遮挡块。记录遮挡块覆盖的局部坐标集合。
3. 计算每个象限的"前景密度"：该象限中非黑(0)且非遮挡块颜色的像素总数。按密度从高到低对四个象限排序。
4. 构建 9x9 输出网格。对于输出中的每个像素位置 (r,c)：
   - 收集所有在该位置未被遮挡的象限（即 (r,c) 不在该象限遮挡块范围内的象限）。
   - 若只有一个象限可用，取该象限在 (r,c) 的像素值。
   - 若多个象限可用，取其中前景密度排名最高（密度最大）的象限在 (r,c) 的像素值。
   - 若所有象限在该位置都被遮挡（设计时已排除此情况），输出黑(0)。
5. 输出完整恢复的 9x9 图案。

**关键洞察**：四个象限构成一组互补观测——每个象限遮挡了不同区域，但共同覆盖了全部底图。恢复过程不是简单的"哪个没被挡就用哪个"，因为当多个象限都未被遮挡时，前景密度排序决定了优先取哪个象限的值。这个优先规则需要对比多个示例才能归纳：为什么某些位置选了这个象限而非那个。

## 新题 4：弯折计数排序连线

**组合逻辑**：[计数](创新：弯折数不决定颜色，而决定对象在连线图中的排序位置) → [排序](创新：不是列的排列，而是对象的全序排列) → [连线](创新：连线拓扑由排序结果动态决定，非固定的行列对齐)

**来源原语**：计数 + 弯折数分类(e509e548)、排序 + 按计数升序排列(85b81ff1)、连线/描边(1bfc4729)

**依赖链**：检测每个图形的弯折数 → 按弯折数从少到多排序所有图形 → 按排序顺序将相邻排名的图形用直线段首尾相连，形成一条链 → 连线颜色由源端图形的弯折数决定。删除计数则无法排序；删除排序则连线无确定拓扑；删除连线则无输出变换。

统计散布图形的弯折数并按弯折数排序，然后按排序顺序用彩色线段依次连接，形成一条从弯折最少到最多的链。

**输入结构**：黑(0)背景网格，约 18x18。网格中有 5~7 个绿(3)色的 4-连通小图形（每个图形 4~8 像素，具有 1~4 个 L 形 2x2 弯折角）。各图形边界框互不重叠且间距至少 2 像素。每个图形的弯折数在输入图形集合中唯一（不存在两个图形弯折数相同的情况）。生成约束：图形在网格中的位置随机分布，不存在两个图形中心在同一行或同一列的情况（确保连线路径唯一）。

**规则**：
1. 检测所有绿(3)色 4-连通图形。对每个图形，扫描其像素掩码中所有 2x2 子块，统计恰好占据 L 形三像素的子块数量（即 2x2 子块中恰有 3 个前景像素的计数），此数为该图形的弯折数。
2. 按弯折数从小到大对所有图形排序。
3. 从排序后的第 1 个图形开始，依次连接到第 2 个、第 2 个到第 3 个，直到最后一个图形，形成一条链。每段连线的起点为源图形（弯折数较少者）边界框的中心像素（行列均取边界框中值，向下取整），终点为目标图形边界框的中心像素。
4. 每段连线绘制为两段直线段组成的直角折线：先从起点沿水平方向画到与终点同列的位置，再沿竖直方向画到终点。折线像素（含起点和终点）着色规则：弯折数 1→蓝(1)，弯折数 2→红(2)，弯折数 3→黄(4)，弯折数 4→灰(5)。每段折线使用源图形的弯折数对应颜色。
5. 原始绿(3)图形像素保持不变。若折线像素与绿(3)图形像素重合，绿(3)保留。若两段折线在同一像素重叠，弯折数较大的源图形对应的折线颜色优先。

**关键洞察**：图形的几何属性（弯折数）不是单纯的分类标签——它同时编码了连线的拓扑序和线段颜色。求解者必须发现弯折计数规则（需对比多个示例中不同弯折数图形被连接的顺序）、连线方向规则（先水平后竖直）和颜色映射规则，三者缺一不可。

## 新题 5：行反转揭示隐藏连通

**组合逻辑**：[反转](创新：反转不只是视觉翻转，而是揭示被背景色隐藏的信息) → [连线](创新：连线的端点不是预先可见的，而是通过反转才暴露) → [填充](创新：连线路径不是简单的行列对齐，而是在格子瓦片结构中沿子格位置传播)

**来源原语**：反转 + 主色与背景互换 + 逐行独立(2de01db2)、连线 + 同色同子格位置(a096bf4d)、填充(e9afcf9a)

**依赖链**：逐行识别主色并反转（主色→黑、黑→主色）→ 反转后原先不可见的像素（原为黑色背景）变为可见的端点标记 → 在底层格子瓦片结构中，将同色端点沿共享的瓦片行或瓦片列连接。删除反转则端点不可见；删除格子结构识别则连线无参考框架；删除连线则无输出变换。

逐行反转主色与背景色以揭示隐藏的端点标记，然后在底层格子瓦片结构中连接同色端点。

**输入结构**：网格约 16x16，由灰(5)色分隔行和分隔列划分为 4x4 的格子瓦片阵列（每个瓦片内部 3x3，分隔线宽 1 像素）。每个瓦片内部以黑(0)为底。部分瓦片的内部行含有一种主色前景色（蓝(1)或红(2)或绿(3)），该主色占据该行内大部分非灰非背景像素位置。少数行中还有 1~2 个"干扰色"像素（黄(4)或橙(7)），它们是隐藏端点的伪装：在反转前，这些干扰色像素看起来是噪声。关键：部分瓦片行中，某些黑(0)像素实际上是"隐藏端点"——它们的位置在反转后将变为主色，从而显现。生成约束：每种隐藏端点颜色（反转后显现的颜色）在瓦片阵列中恰好出现偶数次，且同色端点至少有一对共享瓦片行或瓦片列。灰(5)分隔线上无前景色像素。

**规则**：
1. 对网格中每一非分隔行（非灰(5)的行），识别该行的主色：该行中出现次数最多的非黑(0)非灰(5)颜色。若出现次数并列，取其连续像素段起始列最靠左的颜色。
2. 反转该行：该行中所有主色像素变为黑(0)，所有黑(0)像素变为主色。干扰色像素（非主色、非黑、非灰）保持不变。
3. 反转完成后，识别所有瓦片内部新出现的前景像素（即反转前为黑(0)、反转后变为某颜色的像素）。这些是"显现端点"。
4. 对每种显现端点颜色，按其在瓦片阵列中的瓦片坐标 (瓦片行, 瓦片列) 分组。找出共享同一瓦片行或同一瓦片列的端点对。
5. 对于共享瓦片行的同色端点对：在两个端点之间的每个中间瓦片中，在与端点相同的瓦片内部子格位置（端点在其 3x3 瓦片内的相对行列）填充该端点颜色。
6. 对于共享瓦片列的同色端点对：同理，在中间瓦片的相同子格位置填充该颜色。
7. 灰(5)分隔线和未被连线经过的瓦片内容保持反转后的状态。若连线填充与已有前景像素冲突，连线颜色覆盖。

**关键洞察**：端点在反转前以"缺失"的形式编码在背景中——它们是主色行中的黑色"空洞"。反转操作将正负空间互换，使空洞变为可见标记。连线规则作用在反转后的结果上，但连线的子格位置由端点在瓦片中的相对位置决定，这要求求解者同时理解反转机制和格子瓦片结构，二者缺一不可。

## 新题 6：图例查表缩放叠加

**组合逻辑**：[查表替换](创新：查表结果不直接输出，而作为缩放的输入) → [像素放大](创新：缩放倍率不固定，由编码块的某属性决定) → [透明叠加](创新：叠加层序不由象限位决定，而由各块到网格中心的距离决定)

**来源原语**：查表替换 + 颜色与形状对应(b20f7c8b)、像素放大(0692e18c)、透明叠加 + 图层优先级(e99362f0)

**依赖链**：根据图例面板将每个纯色编码块翻译为对应形状 → 每个形状按编码块的边界框尺寸决定的缩放倍率进行像素放大 → 缩放后的图案按距中心距离的远近确定图层优先级叠加输出。删除查表则无形状可缩放；删除缩放则形状尺寸不变、无重叠产生；删除叠加优先级则重叠区域输出不确定。

从图例面板查表获取颜色对应的形状，按编码块尺寸缩放后以距离优先规则叠加输出。

**输入结构**：网格约 20x20，黑(0)背景。左侧有一个青(8)色的竖直图例面板（约 3 列宽，全高），面板内以黑(0)分隔展示 3~4 个不同颜色的小形状（每个形状 3~5 像素，是 4-连通的单色图形，颜色取自蓝(1)、红(2)、绿(3)、黄(4)，每种颜色在图例中唯一对应一个形状）。面板右侧的画布区域有 3~4 个纯色实心方块（编码块），每个方块颜色对应图例中的某个颜色，尺寸分别为 2x2 或 3x3（尺寸即缩放倍率：2x2→2 倍，3x3→3 倍）。编码块在画布中的位置部分重叠（至少有一对编码块的缩放后范围重叠）。生成约束：缩放后的图案不超出画布边界。

**规则**：
1. 解析图例面板：提取每种颜色对应的形状掩码（在面板的 3x3 子区域内的非青(8)非黑(0)像素位置）。
2. 对画布中的每个编码块：根据其颜色在图例中查找对应形状。根据编码块的边长 s 确定缩放倍率（s=2→2 倍，s=3→3 倍）。将形状的每个像素放大为 s x s 的像素块，生成缩放后的图案。
3. 计算每个编码块中心到画布区域中心的欧氏距离。
4. 按距离从远到近的顺序逐个绘制缩放图案（远的先画，近的后画）。每个图案的放置位置以编码块的左上角像素为锚点。后绘制的覆盖先绘制的。
5. 移除图例面板和分隔，输出仅画布区域。原编码块的纯色像素被缩放图案替代。

**关键洞察**：编码块的尺寸承担双重角色——它既是"这里有一个需要替换的对象"的标记，又编码了缩放倍率。小编码块（2x2）产生较小的缩放图案，大编码块（3x3）产生较大的，而缩放倍率的差异直接影响哪些图案会重叠，进而需要距离优先规则来解决冲突。这种"标记属性即变换参数"的编码方式需要对比不同尺寸编码块的输出才能发现。

## 新题 7：印章围栏内棋盘填充

**组合逻辑**：[印章](创新：印章不是装饰，而是构建围栏边界) → [计数](创新：统计的不是弯折数，而是围栏边界上贡献的标记数) → [填充 + 棋盘格](创新：棋盘图案的两种颜色由围栏的标记计数奇偶性选择)

**来源原语**：印章 + 空心矩形(a04b2602)、计数 + 弯折数分类(e509e548)、填充 + 棋盘格图案 + 列奇偶交替(e9afcf9a)

**依赖链**：标记像素的 3x3 空心邻域印章构建围栏边界 → 围栏边界将画布分隔为若干封闭区域 → 统计每个封闭区域边界上有多少个原始标记像素 → 标记数的奇偶性决定该区域内棋盘填充的两种颜色选择。删除印章则无围栏边界；删除区域划分则无法确定填充范围；删除计数/奇偶判断则棋盘颜色不确定。

用标记像素的空心邻域印章构建围栏，然后在围栏围出的封闭区域内填充棋盘图案，棋盘颜色对由边界标记数奇偶性决定。

**输入结构**：黑(0)背景网格，约 15x15。网格中有 6~9 个红(2)色标记像素（孤立单像素），分布在网格中部区域。标记像素的位置经过设计：任意两个标记像素的曼哈顿距离至少为 2（不直接相邻），且部分标记像素的 3x3 邻域（8-邻域圆环）存在重叠。生成约束：所有标记像素的 3x3 空心邻域联合后形成的连通边界能将网格中部划分为至少 3 个互不连通的封闭区域（每个区域至少 2x2 像素大小），这些封闭区域中不包含任何标记像素。

**规则**：
1. 对每个红(2)标记像素，将其 8-邻域中所有在网格范围内的像素标记为蓝(1)（空心矩形印章）。若两个标记的印章在同一像素重叠，该像素仍为蓝(1)。红(2)标记像素本身保持红色。
2. 印章完成后，以蓝(1)像素和红(2)像素为边界，以网格边缘为边界，识别所有 4-连通的全黑(0)封闭区域。
3. 对每个封闭区域，统计其边界上（与该区域的像素 4-相邻的）红(2)标记像素的数量（不是蓝色印章像素数量，而是原始红色标记数量）。同一个红(2)标记若与多个区域相邻则分别计入。
4. 根据边界标记数的奇偶性决定棋盘填充颜色对：
   - 奇数个标记：使用绿(3)/黄(4)棋盘对。
   - 偶数个标记：使用灰(5)/橙(7)棋盘对。
5. 在每个封闭区域内填充棋盘图案：对于区域内像素 (r,c)，若 (r+c) 为偶数则填充颜色对中的第一色，若为奇数则填充第二色。
6. 与网格边缘连通的外围黑(0)区域不填充，保持黑色。蓝(1)围栏和红(2)标记保持不变。

**关键洞察**：红色标记像素在这道题中承担三重角色：(a) 作为印章中心生成蓝色围栏，(b) 围栏的重叠模式决定封闭区域的形状，(c) 标记自身的数量属性（奇偶性）决定区域的填充颜色方案。求解者容易发现印章和围栏，但"计数哪些像素"（是红色标记而非蓝色围栏像素）以及"奇偶性如何映射到颜色对"需要对比多个区域的填充结果才能归纳。

## 新题 8：镜像补全瓦片的通道连接

**组合逻辑**：[镜像补全](创新：不是全局场景镜像恢复，而是逐瓦片的局部对称补全) → [洪泛填充通道检测](创新：通道不是被填充的目标，而是连线的路径约束) → [连线](创新：连线不走直线，而必须沿瓦片间的通道蜿蜒)

**来源原语**：镜像 + 反射恢复遮挡 + 镜像对称(dc0a314f)、洪泛填充 + 背景通道(a64e4611)、连线 + 端点标记 + 同行列对齐(a096bf4d)

**依赖链**：逐个瓦片镜像补全被遮挡的半边 → 补全后的瓦片边缘可能出现彩色"端口"像素（原被遮挡而不可见）→ 检测瓦片之间的背景通道（分隔走廊）→ 沿通道连接同色端口。删除镜像补全则端口不可见；删除通道检测则连线无路径；删除连线则补全无意义。

镜像补全各瓦片的遮挡区域以暴露隐藏端口，然后沿瓦片间的背景通道连接同色端口。

**输入结构**：网格约 19x19，由黑(0)通道（宽 1 像素的行和列）划分为 3x3 的瓦片阵列（每个瓦片 5x5）。每个瓦片以橙(7)为底色，含有一个灰(5)色的多像素图案（3~6 像素，4-连通）。该灰色图案关于瓦片中心具有左右镜像对称性。部分瓦片（约 3~4 个）的左半或右半被一个青(8)色实心矩形遮挡（覆盖约 2~3 列），遮挡区域下的原始图案不可见。部分瓦片在靠近黑(0)通道的边缘行或列有 1~2 个彩色像素（红(2)、蓝(1)或绿(3)，称为"端口"），这些端口像素可能位于被遮挡区域内。生成约束：每种端口颜色在所有瓦片中恰好出现 2 次，且同色端口对要么共享瓦片行、要么共享瓦片列（瓦片阵列坐标），中间由连续的通道连通。

**规则**：
1. 对每个含有青(8)遮挡块的瓦片，利用灰(5)图案的左右镜像对称性恢复被遮区域：将未被遮挡的半边灰色图案沿瓦片竖直中轴线镜像翻转到被遮挡的半边，替换青(8)像素。翻转后若某像素位置在未遮挡侧为橙(7)底色，则遮挡侧对应位置也恢复为橙(7)。
2. 补全后，识别所有瓦片边缘的端口像素：位于瓦片最外圈行或列、颜色为红(2)/蓝(1)/绿(3)的像素。
3. 识别瓦片间的黑(0)通道：宽 1 像素的黑色行和列，构成连接瓦片的走廊网络。
4. 对每种端口颜色（红/蓝/绿），找到其两个端口像素所在的瓦片。沿黑(0)通道从一个端口向另一个端口绘制连线：连线沿通道的中心像素行进，先沿水平通道（若两端口在同一瓦片行）或先沿竖直通道（若在同一瓦片列），在通道交叉口按需转弯。连线颜色与端口颜色相同。
5. 连线像素覆盖黑(0)通道像素。若不同颜色的连线在同一通道像素交叉，按颜色编号升序优先（蓝(1) < 红(2) < 绿(3)，编号小的保留）。
6. 未被连线覆盖的通道像素和瓦片内部保持原状（补全后状态）。

**关键洞察**：部分端口在补全前被遮挡块隐藏——求解者看到瓦片只有一侧有端口像素，镜像补全后另一侧也出现了端口。这意味着连线的拓扑只有在补全之后才能确定。通道不是被填充的负空间，而是连线必须行经的路径——这颠倒了参考题 a64e4611 中通道的角色。

## 新题 9：弹射路径裁剪框

**组合逻辑**：[射线延伸 + 边界反射](创新：弹射路径不用于涂色背景，而用于确定裁剪的行范围) × [裁剪](创新：列范围由静态竖直线段确定，行范围由动态弹射路径确定) → [描边](创新：裁剪结果加边框，边框颜色由路径弹射次数决定)

**来源原语**：射线延伸 + 边界反射 + 反弹路径(e179c5f4)、裁剪 + 竖直线段 + 线段定裁剪列范围(3f7978a0)、描边 + 边框(1bfc4729)

**依赖链**：弹射路径确定行范围 → 竖直线段确定列范围 → 两者共同定义裁剪矩形 → 弹射次数决定边框颜色。删除弹射路径则行范围不确定；删除竖直线段则列范围不确定；删除描边则裁剪结果无边框。弹射次数同时用于边框颜色选择，使路径的物理属性影响最终装饰。

弹射射线的行程范围与竖直导轨的列位置共同框定裁剪区域，裁剪后添加由弹射次数决定颜色的边框。

**输入结构**：黑(0)背景网格，约 18x18。网格中有两条灰(5)色竖直线段（各约 8~12 像素长，宽 1 像素），分别位于网格左半和右半区域，二者列坐标不同、行范围部分重叠。线段之间的区域内有若干青(8)色散布像素（装饰内容，无规律）。网格左边缘某行有一个蓝(1)像素作为射线起点。起点所在行位于两条灰色线段的行范围之间。生成约束：射线从起点出发沿右上方 45 度弹射，其路径的最高点（最小行号）和最低点（最大行号）之间的行范围与两条灰色线段的行范围有交集；射线在弹射过程中至少反射 2 次后从网格顶边或底边射出。

**规则**：
1. 从蓝(1)起点像素出发，沿右上方 45 度方向（行减 1、列加 1）逐步延伸射线。遇到网格左右边界时列方向反转，继续弹射。遇到网格上下边界时终止。将路径像素标记为蓝(1)。
2. 记录射线路径中的最小行号 r_min 和最大行号 r_max。记录射线在左右边界反射的总次数 B。
3. 识别两条灰(5)竖直线段，按列坐标排序，记为左导轨（列 c_left）和右导轨（列 c_right）。
4. 定义裁剪区域：行范围为 [r_min, r_max]，列范围为 [c_left, c_right]（含端点列）。将此矩形区域从网格中裁剪出来。
5. 裁剪后的子网格四周添加 1 像素宽的边框。边框颜色由弹射次数 B 决定：
   - B = 2 → 红(2)
   - B = 3 → 绿(3)
   - B = 4 → 黄(4)
   - B >= 5 → 品红(6)
6. 输出带边框的裁剪子网格。裁剪区域内的蓝(1)路径像素、灰(5)导轨像素、青(8)装饰像素和黑(0)背景均保留。

**关键洞察**：裁剪框的两个维度由两种完全不同的机制确定——列范围来自静态的灰色导轨（几何特征检测），行范围来自动态的弹射路径（物理模拟）。这两个独立过程的交汇定义了裁剪区域，而路径的弹射次数（运动过程的统计量）又反馈为边框的装饰属性。求解者需要分别理解这两种机制并认识到它们的输出如何组合，仅看一个示例无法区分行范围是由导轨还是由路径决定的。

## 新题 10：对称补全碎片的密度排序拼装

**组合逻辑**：[对称补全](创新：补全不仅恢复碎片形状，还恢复碎片内的颜色编码) → [排序](创新：排序依据不是列内计数，而是补全后碎片的前景像素密度) → [平铺放置](创新：不是简单重复或质心定位，而是按排序结果重新排列到插槽阵列中)

**来源原语**：对称补全 + 质心偏移定位(4e45f183)、排序 + 按计数升序排列(85b81ff1)、平铺 + 放置(a32d8b75/a416b8f3)

**依赖链**：利用二面体对称性补全不完整的碎片 → 补全后统计每个碎片的前景像素数 → 按像素数排序决定碎片在输出阵列中的位置（左上角像素数最少，按行优先排列）。删除对称补全则碎片不完整、像素数不确定；删除计数排序则摆放位置不确定；删除拼装则无输出。

将不完整碎片对称补全后，按前景密度排序重新排列到输出插槽阵列中。

**输入结构**：网格约 17x17，由黑(0)色分隔行和分隔列划分为 3x3 的插槽阵列（每个插槽 5x5，分隔线宽 1 像素）。阵列中恰好有 6 个插槽被占用（含碎片），3 个插槽为空（全黑）。每个碎片是一个以栗(9)为底色的 5x5 瓦片，其中有若干红(2)色前景像素构成标记图案。碎片的标记图案原本关于瓦片中心具有某种二面体对称性（0度、90度、180度、270度旋转或水平/竖直/对角镜像之一），但部分碎片被截断——有 1~2 行或 1~2 列的标记像素被黑(0)替换，破坏了对称性。每个碎片的截断方式不同。生成约束：每个碎片至少保留了足够的标记像素，使得其二面体对称类可被唯一确定；补全后各碎片的前景像素数互不相同。

**规则**：
1. 识别 3x3 插槽阵列中所有非空插槽（含有栗(9)底色的 5x5 瓦片）。
2. 对每个碎片，检测其红(2)标记图案。枚举所有 8 种二面体变换（4 种旋转 x 是否镜像），找到使变换后图案包含当前可见标记且自身一致的对称类型。用该对称性补全被截断的标记像素：将可见标记通过对称变换映射到截断区域，恢复红(2)像素。截断区域的栗(9)底色不受影响。
3. 补全后，统计每个碎片中红(2)前景像素的总数。
4. 将 6 个碎片按前景像素数从少到多排序。
5. 将排序后的碎片按行优先顺序填入 3x3 输出阵列的前 6 个位置（位置 (0,0)、(0,1)、(0,2)、(1,0)、(1,1)、(1,2)），像素数最少的放 (0,0)。剩余 3 个位置（第 3 行）为空（全黑(0)）。
6. 输出带黑(0)分隔线的完整 3x3 阵列。

**关键洞察**：碎片在输入中的位置是随机的（不按密度排列），且碎片是不完整的——求解者无法直接数前景像素数来排序。必须先补全才能准确计数。补全依赖对称性识别，而不同碎片可能有不同的对称类型（有的是旋转对称、有的是镜像对称），需要分别判断。排序结果重新排列了碎片位置，产生与输入完全不同的布局。

## 新题 11：逐行反转与列奇偶棋盘的双重编码

**组合逻辑**：[反转](创新：反转操作不是整行执行，而是仅在特定列——由列奇偶性选择的列——上执行) × [棋盘格](创新：棋盘不是简单填充，而是对反转操作的空间选择器) × [连线](创新：反转后暴露的标记像素之间按行对齐连接)

**来源原语**：反转 + 逐行独立 + 主色与背景互换(2de01db2)、棋盘格图案 + 列奇偶交替 + 奇偶决定交换(e9afcf9a)、连线 + 行列对齐(50846271/a096bf4d)

**依赖链**：列奇偶性决定哪些列参与反转 → 仅在奇数列上执行逐行颜色反转 → 反转后的奇数列上出现隐藏标记 → 将同行同色标记水平连接。删除奇偶选择则反转范围不确定；删除反转则标记不可见；删除连线则无输出变换。

在奇数列上执行逐行颜色反转以暴露隐藏标记，然后水平连接同行同色标记。

**输入结构**：网格约 14x14，黑(0)背景。每行有一种主色前景色（蓝(1)、红(2)或绿(3)，每行可不同）。主色像素分布在该行的多个位置。关键设计：在偶数列（0-索引）上，主色像素正常显示；在奇数列上，部分"隐藏标记"被编码为黑(0)（看起来和背景一样），同时部分本应为黑(0)的位置被设为主色（作为掩护）。即奇数列的颜色是"反转"过的。每行在奇数列上隐藏了 1~2 个标记像素。生成约束：每行隐藏标记（反转后可见的非主色像素）数量为偶数，且同行隐藏标记颜色相同（即该行主色），在该行中成对出现以便连线。同行两个隐藏标记之间至少间隔 2 列。

**规则**：
1. 对每行，识别该行的主色：该行中所有偶数列上出现次数最多的非黑(0)颜色。
2. 对该行的所有奇数列执行反转：奇数列上的主色像素变为黑(0)，黑(0)像素变为主色。偶数列保持不变。
3. 反转完成后，识别每行中新出现的主色像素（仅出现在原先为黑(0)的奇数列位置）。这些是暴露的隐藏标记。
4. 对每行，将同色隐藏标记水平连接：在两个标记之间的所有像素位置（含两端标记）涂上黄(4)色连线。
5. 连线覆盖路径上的任何现有像素（无论是主色还是黑色）。原有的偶数列前景像素和反转后的奇数列前景像素保持不变（除非被连线覆盖）。

**关键洞察**：输入的奇数列是"颜色反转"的——求解者看到的像素颜色与真实值正好相反。列奇偶性充当了一个空间掩码，决定哪些列需要反转才能还原真相。这种"棋盘式选择性反转"既不是简单的全行反转（2de01db2），也不是简单的棋盘填充（e9afcf9a），而是两者的交叉组合。必须对比多个示例中奇偶列的颜色分布差异才能发现这个规则。
