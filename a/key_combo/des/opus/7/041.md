## 新题 1：反射重叠门控洪泛填充

**组合逻辑**：[镜像](创新：反射类型由标记几何决定) + [透明叠加](创新：用于检测自重叠像素) → [计数](创新：统计重叠像素而非散点) → [洪泛填充/擦除](创新：重叠存在性作为区域存亡的门控)

**来源原语**：镜像/mirror(7ed72f31), 标记几何定类型/marker_geometry_determines_type(7ed72f31), 透明叠加/transparent_overlay(7ed72f31), 洪泛填充/flood_fill(29623171), 分区区域/partitioned_region(29623171), 筛选/filtering(29623171)

**依赖链**：标记几何选择反射类型 → 反射产生镜像副本 → 叠加后检测原件与副本的空间重叠 → 重叠存在性决定该区域被洪泛填充还是被擦除。每步输出实质性改变下一步的输入：反射类型决定副本形状，副本形状决定重叠是否存在，重叠存在性决定区域命运。

将分区网格中的每个精灵体按其红色标记几何进行反射，反射后与原件产生空间重叠的区域被洪泛填充，无重叠的区域被擦除。

**输入结构**：约 16×16 网格。灰(5)色完整行和列将网格分割为若干矩形区域（约 4-6 个区域）。每个区域内的背景为黑(0)，包含一个不规则 8-连通精灵体（4-7 像素，单色，颜色从 {蓝(1), 绿(3), 黄(4), 品红(6)} 中取，各区域颜色不同）。每个精灵体内部或紧邻位置有一个红(2)标记：标记要么是一条 1 像素宽的线段（水平或垂直，长 2-3 像素，位于精灵体内部），要么是一个孤立红像素（位于精灵体的 8-连通邻域内但不与精灵体像素重合）。生成约束：每个区域的精灵体与标记的组合在反射后至少有一种确定的重叠/无重叠结果（不存在歧义情况）；至少一个区域产生重叠，至少一个区域不产生重叠。

**规则**：
1. 识别灰(5)分隔线，将网格划分为矩形区域。
2. 对每个区域，定位精灵体及其关联的红(2)标记。
3. 判断标记几何：若红标记是一条线段（2+ 像素的 4-连通水平或垂直直线），则沿该线段方向做轴对称镜像；若红标记是单个孤立像素，则以该像素为中心做 180° 点对称。
4. 将镜像副本透明叠加到原位置：仅非黑像素参与叠加。
5. 统计同时被原件和副本覆盖的像素数量（重叠计数）。红标记像素本身不参与此计数。
6. 若重叠计数 > 0：擦除红标记像素为黑(0)，然后用精灵体颜色洪泛填充该区域内所有黑(0)像素（灰分隔线不受影响）。
7. 若重叠计数 = 0：擦除该区域内所有非灰像素为黑(0)（包括精灵体和红标记）。
8. 灰(5)分隔线始终保持不变。

**关键洞察**：红标记的几何形态（线段 vs 孤立点）决定反射类型，而反射类型与精灵体自身形状的交互决定是否产生自重叠——这个"是否重叠"才是区域存亡的真正判据。求解者需要对每个区域模拟反射并检查重叠，而非简单计数散点。

## 新题 2：对角标记编码旋转角的栅格印章

**组合逻辑**：[对角标记像素](创新：编码旋转角度而非象限填充色) → [旋转](创新：角度由颜色查表确定) + [印章放置](创新：模板经旋转后放置) + [重叠区域重涂](已有)

**来源原语**：对角标记像素/diag_marker(e9ac8c9e), 角落对应/corner_correspond(e9ac8c9e), 印章放置/stamp(a395ee82), 旋转/rotate(2013d3e2), 栅格偏移/lattice_offset(a395ee82), 重叠区域重涂/overlap_recolor(a395ee82), 单像素布局/singleton_layout(a395ee82)

**依赖链**：对角标记的位置-颜色对应关系建立旋转查找表 → 各单像素的颜色通过查找表确定其对应的旋转角 → 模板在每个栅格位置被旋转后放置 → 重叠像素被重涂。查找表的编码方式必须从多示例中对比归纳，单示例无法确认四个角的旋转分配。

将对角标记像素作为旋转编码表，在栅格上放置经不同角度旋转的模板副本，重叠位置重涂为指定颜色。

**输入结构**：约 20×20 网格，背景黑(0)。网格中有一个不规则单色模板（蓝(1)，5-8 像素，4-连通，非矩形非对称）。模板边界框的四个对角位置（左上对角、右上对角、右下对角、左下对角各偏移 1 像素）各有一个单像素标记，颜色分别为四种不同颜色（从 {绿(3), 黄(4), 红(2), 橙(7)} 中取，每角一种，不重复）。网格其他位置散布若干单像素点（3-6 个），排列在均匀间距的栅格节点上，每个单像素的颜色是上述四种标记颜色之一。生成约束：栅格间距等于模板边界框的高和宽；各印章副本在旋转放置后至少有一对产生重叠，但不会有三个以上副本在同一像素重叠；模板形状在 0°/90°/180°/270° 旋转下互不相同（确保旋转角可被唯一识别）。

**规则**：
1. 识别模板（最大的蓝(1)连通分量）及其边界框。
2. 识别四个对角标记像素，按其相对于模板边界框角的位置建立旋转查找表：左上对角的颜色 → 0°，右上对角的颜色 → 90° 顺时针，右下对角的颜色 → 180°，左下对角的颜色 → 270° 顺时针。
3. 识别所有远离模板的单像素点。选取其中与模板同色（蓝(1)）的那个像素作为栅格原点。
4. 计算每个非蓝单像素相对于原点的偏移，以模板边界框尺寸为单位换算成栅格坐标。
5. 在每个栅格坐标处放置模板副本：先按该单像素颜色查旋转表得到角度，将模板旋转该角度后放置。原点位置放置一份 0° 副本，但将其颜色改为橙(7)（与模板色不同的指定颜色）。
6. 擦除原始模板区域、四个对角标记像素和所有单像素点为黑(0)。
7. 任何被两个或更多副本共同覆盖的像素重涂为灰(5)。

**关键洞察**：对角标记像素在参考题 e9ac8c9e 中编码象限填充颜色，此处被重新赋义为旋转角度编码表。求解者必须先破解"角位置→颜色→旋转角"的映射，再将其应用于每个栅格点。模板的不对称性是验证旋转角正确性的关键——对称模板会导致多种旋转角产生相同结果。

## 新题 3：降采样遮罩门控的射线投射

**组合逻辑**：[降采样](创新：生成列级门控掩码而非用于裁剪) × [射线延伸 + 遮挡覆盖](创新：投射仅在掩码开放列生效) — 两条独立输入在边缘条处交汇形成约束满足结构

**来源原语**：射线延伸/ray_extend(13713586), 遮挡覆盖/occlusion_overwrite(13713586), 边缘实心条/solid_edge_bar(13713586), 平行线段/parallel_segment(13713586), 降采样/downsample(6ecd11f4), 单色图案/mono_pattern(6ecd11f4), 整数缩放对应/int_scale_correspond(6ecd11f4), 按距离排序绘制/draw_ordered_by_distance(13713586)

**依赖链**：大型单色图案经降采样生成与边缘等长的二进制掩码 → 掩码决定哪些列位置允许投射通过 → 各线段的射线投射在允许列上按距离远近分层遮挡。降采样结果和距离排序同时约束每个输出像素的颜色，缺一不可。

将线段向边缘条投射彩色矩形，但投射受降采样后的单色图案作为列掩码的过滤——仅掩码"开"位置的列允许投射到达边缘，闭位置被截断。

**输入结构**：约 18×18 网格，背景黑(0)。底部一整行为实心红(2)边缘条。网格上半部分有 3-5 条一像素厚的水平线段，各线段颜色不同（从 {蓝(1), 绿(3), 黄(4), 品红(6), 橙(7)} 中选），长度 3-6 像素，位于不同行、不同列范围，彼此的列范围可以部分重叠。网格左上角或右上角有一个较大的单色灰(5)图案（4-连通，约 15-25 像素），该图案是一个二进制行向量的整数倍放大：行向量长度等于网格宽度，放大倍数为 2-3 倍。生成约束：掩码向量中"开"和"闭"位置均存在；至少有两条线段在某些"开"列上的列范围重叠（以检验遮挡规则）；各线段到底部边缘的距离互不相同。

**规则**：
1. 识别底部红(2)边缘条和所有水平彩色线段。
2. 识别灰(5)单色图案，将其裁剪到边界框后沿垂直方向降采样为 1×W 行向量（W = 网格宽度）。降采样方法：每列中若灰(5)像素数 > 0 则该位置为"开"（1），否则为"闭"（0）。
3. 每条线段向下投射一个同色填充矩形：矩形宽度等于线段宽度，高度从线段所在行的下一行延伸到红色边缘条的上一行。
4. 对每个投射矩形，逐列检查掩码：若该列在掩码中为"闭"，则擦除该列内该投射矩形的所有像素为黑(0)。
5. 在所有掩码过滤后的投射中，若多条投射在同一像素重叠，距离边缘条更近的线段的投射覆盖更远的（近者优先）。
6. 红(2)边缘条保持不变。灰(5)单色图案被擦除为黑(0)。原始线段像素保留。

**关键洞察**：灰色图案不是装饰——它降采样后成为逐列的通断门控，与距离排序的遮挡规则在每一列上同时生效。求解者需要先发现图案与网格宽度之间的整数缩放关系，再理解门控对投射的列级过滤作用。

## 新题 4：标记朝向编码嵌套轮廓的着色序列

**组合逻辑**：[重涂色](创新：不是映射到单一颜色，而是映射到一个颜色循环序列) ← [标记朝向编码](创新：编码的是颜色排列顺序而非单一颜色) + [邻域全包含](创新：迭代腐蚀生成多层轮廓而非仅二值分类)

**来源原语**：标记体/marker(604001fa), 标记朝向编码颜色/marker_orientation_encodes_color(604001fa), 重涂色/recolor(09c534e7), 连通分量/connected_component(09c534e7), 邻域全包含/full_neighborhood_inside_component(09c534e7), 嵌套层/nested_layer(bd5af378), 标记在对象上方/marker_above_object(604001fa)

**依赖链**：L 标记的缺角位置 → 选择一个三色循环序列 → 对每个连通分量做迭代 3×3 腐蚀产生逐层轮廓 → 按层深度依次使用序列中的颜色重涂。标记编码的是"排列"而非"值"，与腐蚀层数形成乘法式组合。

L 形标记的朝向为每个连通分量选择一个三色循环序列，该序列按迭代腐蚀得到的轮廓层深度逐层着色。

**输入结构**：约 18×18 网格，背景黑(0)。有 3-4 个蓝(1)的 4-连通前景分量，每个分量包含粗实心区域（至少有内部像素可形成 2-3 层嵌套轮廓）和单像素宽的走廊连接。每个分量的边界框正上方有一个橙(7)的 2×2 L 形三联标记（占据 2×2 方框中的 3 个像素，缺角位置因分量而异）。标记底行紧贴分量边界框顶行上方，且列范围与分量重叠。生成约束：每个分量的粗实心区域足够大以产生至少 2 层腐蚀层（即实心区域至少有 5×5 的核心）；各分量的 L 标记缺角位置至少有两种不同取值；走廊部分像素的 3×3 邻域不能完全落在分量内。

**规则**：
1. 移除所有橙(7)标记像素为黑(0)。
2. 对每个蓝(1)连通分量，确定其上方 L 标记的缺角位置，并选择对应的三色循环序列：
   - 缺角在左上 → 序列为 [绿(3), 黄(4), 红(2)]
   - 缺角在右上 → 序列为 [红(2), 绿(3), 黄(4)]
   - 缺角在左下 → 序列为 [黄(4), 红(2), 绿(3)]
   - 缺角在右下 → 序列为 [绿(3), 红(2), 黄(4)]
3. 对该分量做迭代腐蚀以生成嵌套轮廓层：
   - 第 0 层：分量内 3×3 邻域完全落在分量内的所有像素。
   - 从分量中移除第 0 层像素。在剩余分量像素中再次找 3×3 邻域完全落在剩余集合内的像素，标记为第 1 层。
   - 重复直到无新层产生。
4. 将第 k 层像素重涂为颜色序列中第 (k mod 3) 个颜色。
5. 未被任何层覆盖的分量像素（走廊和外边界像素）保持蓝(1)不变。

**关键洞察**：L 标记在参考题 604001fa 中编码单一颜色（一对一映射），此处被提升为编码一个颜色排列（一对多映射）。求解者需要发现：(a) 标记朝向与着色序列的对应关系，(b) 序列按腐蚀深度循环使用。仅看单个示例无法区分四种序列。

## 新题 5：配对色反转存活分区

**组合逻辑**：[计数 + 筛选](已有：最密区域保留) → [反转](创新：在空间区域级别而非 3×3 级别应用) + [配对色映射](创新：散点颜色身份既是计数目标又是映射键)

**来源原语**：计数/counting(29623171), 筛选/filtering(29623171), 分区区域/partitioned_region(29623171), 最密区域保留填充/densest_region_kept_filled(29623171), 反转/invert(6ea4a07e), 配对色映射/paired_color_mapping(6ea4a07e), 掩码/mask(6ea4a07e)

**依赖链**：散点颜色用于计数 → 计数结果决定区域存活 → 存活区域的散点空间分布被反转 → 反转后的填充色由散点颜色通过配对映射确定。散点颜色在整条链中承担三重角色（计数目标、反转遮罩来源、映射键），删除任一角色都导致规则不完整。

在分区网格中保留散点最多的区域，对其像素分布做正负反转，反转后的填充颜色由原散点颜色经固定配对映射决定。

**输入结构**：约 14×14 网格。橙(7)色完整行和列将网格分割为矩形区域（约 4-6 个区域，每个区域 4×4 到 6×6 不等）。每个区域内背景为黑(0)，散布若干同色像素（2-6 个），颜色从 {青(8), 绿(3), 灰(5)} 中取，每个区域仅用一种颜色。不同区域可使用相同或不同的颜色。各区域的散点数量互不相同（保证最大值唯一，无并列）。生成约束：至少两个区域使用不同的散点颜色；散点不紧贴区域边界的第一行/列（确保反转后边界仍然清晰可辨）。

**规则**：
1. 识别橙(7)分隔线，划分矩形区域。
2. 统计每个区域内非黑(0)、非橙(7)的散点数量。
3. 保留散点数量最多的唯一区域；擦除所有其他区域内的散点为黑(0)。
4. 对存活区域执行空间反转：原来为黑(0)的像素变为填充色，原来为散点色的像素变为黑(0)。
5. 填充色由该区域散点颜色的配对映射决定：青(8) → 红(2)，绿(3) → 蓝(1)，灰(5) → 黄(4)。
6. 橙(7)分隔线始终保持不变。

**关键洞察**：散点颜色同时充当三个角色——被计数以判定存活、作为空间遮罩以决定反转图案、作为配对映射的键以确定填充颜色。求解者需要从多个示例中归纳出颜色配对规则（青→红、绿→蓝、灰→黄），因为单个示例只展示一种配对。

## 新题 6：折叠涌现封闭区域的几何选择性填充

**组合逻辑**：[折叠](已有：铰接点折叠) → [封闭区域检测](创新：封闭区域由多根折叠杆的空间协作涌现) → [孔洞几何决定填充](创新：判断涌现封闭区域的几何形状)

**来源原语**：折叠/fold(230f2e48), 直线杆/straight_rod(230f2e48), 铰接标记/hinge_marker(230f2e48), 端点标记/endpoint_marker(230f2e48), 固定端与活动端/fixed_vs_free(230f2e48), 空间大侧折入/fold_toward_space(230f2e48), 封闭区域/enclosed_region(44d8ac46), 孔洞/hole(44d8ac46), 填充/fill(44d8ac46), 仅正方形孔洞填充/only_square_holes_filled(44d8ac46)

**依赖链**：每根杆独立折叠 → 折叠后的多根杆在空间上围合出封闭区域（单根杆无法围合，这是集体涌现属性） → 检测围合区域的几何形状 → 仅正方形区域被填充。折叠方向（取决于空间）决定最终几何形态，而几何形态决定是否填充，形成操作→涌现结构→条件判断的链条。

多根直线杆各自在铰接点折叠后，其折叠尾段与其他杆段及网格边缘共同围合出封闭区域；仅几何上为正方形的封闭区域被填充。

**输入结构**：约 16×16 网格，背景黑(0)。有 4-6 根直线杆，颜色为红(2)，每根杆长 7-11 像素，部分水平部分垂直。每根杆有一个灰(5)端点标记（位于一端）和一个蓝(1)铰接标记（位于杆的中间某处，不在端点）。杆的布局使得折叠后至少有一对杆的尾段与另一杆段或网格边缘形成封闭矩形区域。生成约束：折叠方向（向空间更大的一侧）对每根杆是唯一确定的；折叠后至少产生一个正方形封闭区域和一个非正方形封闭区域（以便求解者区分几何判据）；杆段之间不在折叠前交叉（折叠后可以端点相接但不重叠）。

**规则**：
1. 对每根杆，保持从灰(5)端点标记到蓝(1)铰接标记的部分不动（固定段）。
2. 将铰接标记另一侧的红(2)尾段旋转 90°，方向为铰接标记处垂直于杆方向的两个方向中空间更大的一侧（到网格边缘距离更远的方向）。旋转后的尾段从铰接标记旁的下一个像素开始绘制。
3. 折叠后，检测由红(2)杆段像素和网格边缘共同围成的封闭区域（内部全为黑(0)的 4-连通区域，其边界完全由杆段像素和/或网格边界构成）。
4. 对每个封闭区域：计算其边界框。若边界框为正方形且区域完全填满该正方形（即区域本身是正方形块），则将该区域填充为绿(3)。否则不填充。
5. 所有杆段像素（红(2)、灰(5)端点标记、蓝(1)铰接标记）保持原样。

**关键洞察**：单根杆折叠只产生一个 L 形——无法形成封闭区域。封闭区域是多根杆折叠结果的集体空间效应，是不可从单杆预测的涌现属性。求解者必须先完成所有折叠，然后在全局视角检测封闭区域并判定其几何形状。

## 新题 7：堆叠重排后涌现内部区域的标记着色

**组合逻辑**：[堆叠 + 位置排序](已有：按位置重排对象) → [邻域全包含](创新：作用于堆叠后的合并分量而非原始独立分量) → [重涂色](创新：颜色由堆叠中顶部对象的标记决定)

**来源原语**：堆叠/stacking(4acc7107), 位置排序/positional_ordering(4acc7107), 对齐紧凑排布/aligned_compact_layout(4acc7107), 按颜色分组/group_by_color(4acc7107), 单色前景对象/monochrome_foreground_object(4acc7107), 重涂色/recolor(09c534e7), 连通分量/connected_component(09c534e7), 单点标记/singleton_marker(09c534e7), 邻域全包含/full_neighborhood_inside_component(09c534e7), 标记在分量内/marker_inside_component(09c534e7)

**依赖链**：对象按位置排序确定堆叠顺序和布局 → 堆叠将原本分离的对象合并为紧邻列 → 合并后产生原始对象中不存在的新 3×3 内部像素（涌现属性） → 顶部对象的标记颜色决定这些涌现内部像素的着色。堆叠改变几何结构，几何结构决定内部像素的存在，标记身份决定颜色。

将分色对象按位置重排堆叠，堆叠后合并分量中新涌现的实心内部像素被重涂为该分量中堆叠位置最高的对象所携带的标记颜色。

**输入结构**：约 16×18 网格，背景黑(0)。有两个颜色组（如蓝(1)和红(2)），每组恰好两个 4-连通单色对象。每个对象为不规则形状（5-12 像素），具有至少一处 3 像素宽的粗壮部分但也有单像素宽的突起或走廊。每个对象内部有一个单点标记像素（蓝组用绿(3)标记，红组用黄(4)标记），标记位于对象的某个像素位置。生成约束：每个单独的对象裁剪后不存在 3×3 邻域完全落在对象内部的像素（即单独时没有"实心内部"）；但同色组的两个对象按规则堆叠后，连接处可以产生 3×3 内部像素（这要求对象在堆叠接合面有至少 3 像素宽的边缘对齐）。

**规则**：
1. 按颜色分组。每组内的两个对象按边界框左上角列坐标降序排列（列坐标大的排在前）。
2. 组间按最左占用列从左到右排列。
3. 对每个颜色组：裁剪两个对象到各自边界框，按组内顺序从上到下堆叠，对象之间间隔 1 行黑(0)，底部对齐到输出画布底端。组间间隔 1 列黑(0)。
4. 堆叠完成后，对每个颜色组的堆叠列视为一个整体连通分量。检测该分量中 3×3 邻域完全落在分量内的像素（实心内部像素）。
5. 确定该分量中堆叠位置最靠上的对象（即步骤 3 中排在上方的对象）。该对象携带的标记颜色即为该分量涌现内部像素的重涂色。
6. 将所有涌现内部像素重涂为该颜色。标记像素本身保留在其原有位置不变。

**关键洞察**：每个对象单独时因形状不够粗壮而没有实心内部像素。只有堆叠将两个对象紧密排列后，接合处的像素获得了完整的 3×3 邻域——这些内部像素是堆叠的涌现产物。求解者需要理解堆叠不只是重排，还创造了新的拓扑属性。

## 新题 8：对角标记二值门控与全局面积排名着色

**组合逻辑**：[分割](已有：四象限分割) + [对角标记像素](创新：编码二值开关而非颜色) → [计数 + 排序](创新：全局跨矩形排名而非局部) → [重涂色](创新：颜色由全局排名位次决定)

**来源原语**：分割/split(e9ac8c9e), 对角标记像素/diag_marker(e9ac8c9e), 象限/quadrant(e9ac8c9e), 实心矩形/solid_rect(e9ac8c9e), 角落对应/corner_correspond(e9ac8c9e), 排序/sorting(f8ff0b80), 像素数量/pixel_count(f8ff0b80), 面积排序/area_ordering(f8ff0b80), 按像素数降序/descending_pixel_count(f8ff0b80), 计数/counting(29623171)

**依赖链**：对角标记的有色/无色状态确定象限的活跃/非活跃 → 收集所有矩形的所有活跃象限 → 按像素面积全局排序 → 排名位次映射到固定调色板。增减任何一个标记的有色状态会改变全局排名，从而改变所有活跃象限的颜色——这是全局耦合而非局部规则。

将每个灰色矩形分割为四象限，对角标记的有色/无色状态决定象限是否活跃，所有活跃象限按面积全局排名并着色。

**输入结构**：约 16×16 网格，背景黑(0)。有 2-3 个灰(5)实心矩形（不一定是正方形，尺寸各异，如 4×6, 6×4, 4×4 等，彼此不重叠不相邻）。每个矩形的边界框四角对角线外侧各一个像素位置放置标记：标记要么是有色像素（颜色任意，非黑非灰，如红(2)、蓝(1)、绿(3)、黄(4)等），要么是黑(0)（即缺失/不可见）。生成约束：每个矩形至少有一个有色标记和一个黑色标记（即每个矩形至少有一个活跃象限和一个非活跃象限）；所有活跃象限的像素面积互不相同（无并列）；活跃象限总数不超过 8 个。

**规则**：
1. 对每个灰(5)矩形，定位其四个对角标记位置。
2. 将矩形水平和垂直各切一半，形成四个象限（若行数或列数为奇数，中间行/列归入左上象限和左下象限）。
3. 标记判定：对角标记为有色像素 → 对应象限为"活跃"；对角标记为黑(0) → 对应象限为"非活跃"。
4. 移除所有对角标记像素（置为黑(0)）。
5. 收集所有矩形的所有活跃象限，计算每个象限的像素面积（行数×列数）。
6. 按面积降序排列所有活跃象限。从固定调色板 [红(2), 蓝(1), 绿(3), 黄(4), 品红(6), 橙(7), 青(8), 栗(9)] 中依次取色：面积最大的活跃象限填充红(2)，第二大填充蓝(1)，第三大填充绿(3)，依此类推。
7. 非活跃象限保持灰(5)不变。

**关键洞察**：在参考题 e9ac8c9e 中，对角标记颜色直接成为象限的填充色（一对一局部映射）。此处标记颜色本身无意义——标记仅编码"有/无"二值信号。真正的颜色分配是全局的：取决于跨所有矩形的面积排名。这意味着增加一个新矩形或翻转一个标记的状态，会级联改变所有已有活跃象限的颜色。

## 新题 9：邻域上下文决定模板旋转的像素放大

**组合逻辑**：[像素放大 + 颜色到模板映射](已有：颜色查表选择模板) × [旋转](创新：旋转角由索引像素的局部邻域决定，而非全局属性) — 两条信息（颜色→模板身份、邻域→旋转角）在每个像素处交汇

**来源原语**：像素放大/pixel_expand(42f83767), 索引网格/index_grid(42f83767), 颜色到模板映射/color_stencil_map(42f83767), 色卡/color_swatch(42f83767), 模板遮罩/stencil_mask(42f83767), 顺序配对/ordered_pairing(42f83767), 旋转/rotate(2013d3e2), 旋转对称/rotational_symmetry(2013d3e2)

**依赖链**：色卡与模板遮罩的左右配对确定颜色→模板映射 → 索引网格每个像素的颜色选择对应模板 → 该像素 4-邻域中同色邻居的数量决定模板的旋转角 → 旋转后的模板被粘贴到输出位置。同一颜色的像素因邻域不同而产生不同旋转，这是单示例难以归纳的隐蔽规则。

**输入结构**：约 15×15 网格。上部为图例区：左侧是 2-3 个 2×2 单色色卡（颜色各不同，如蓝(1)、绿(3)、黄(4)），右侧是等数量的 3×3 灰(5)模板遮罩（每个遮罩内有不同的镂空图案，遮罩像素为灰(5)，镂空为黑(0)）。色卡与遮罩按从左到右的顺序一一配对。图例区与下方用 1-2 行黑(0)分隔。下部为 4×4 或 5×5 的密集索引网格，每个像素为色卡颜色之一。生成约束：每个模板遮罩在 0°/90°/180°/270° 旋转下至少有两种不同外观（即遮罩不具备 4 重旋转对称性）；索引网格中每种颜色至少出现 3 次且邻域上下文有差异（同色邻居数 0-4 至少覆盖两种不同值）。

**规则**：
1. 在图例区中识别色卡和模板遮罩，按从左到右的出现顺序一一配对。
2. 对索引网格中的每个像素 P：
   a. 通过 P 的颜色查找其配对的模板遮罩。
   b. 统计 P 的 4-邻域（上、下、左、右，不含对角；超出网格边界的方向不计）中与 P 同色的邻居数量 N（0 ≤ N ≤ 4）。
   c. 将模板遮罩顺时针旋转 90°×N。
3. 在输出中，每个索引像素被替换为一个 3×3 块：将旋转后的模板遮罩粘贴到该位置，其中遮罩的灰(5)像素替换为 P 的颜色，镂空位置保持黑(0)。
4. 图例区不出现在输出中。输出网格尺寸为索引网格的行列数各乘以 3。

**关键洞察**：两个相同颜色的索引像素会选择同一个模板遮罩，但若它们的同色邻居数不同，粘贴出的 3×3 块是遮罩的不同旋转版本。求解者必须发现旋转角与邻域上下文的关联——这只有在对比同色但不同邻域的像素输出后才能归纳出来。

## 新题 10：旋转拼图缺块推断与补全

**组合逻辑**：[裁剪](已有：提取象限) + [旋转对称](创新：不是提取已知位置的源瓦片，而是通过旋转测试推断哪个象限是源) → [旋转](创新：生成缺失旋转角度的副本) + [透明叠加](创新：将生成的瓦片填入空白象限)

**依赖链**：裁剪四个象限 → 旋转对称测试确定哪些象限之间存在旋转关系以及源瓦片是谁 → 推断空白象限对应的缺失旋转角 → 生成缺失瓦片并叠加到空白位置。与参考题 2013d3e2 的关键差异：源瓦片不固定在左上角，空白象限位置不固定，输出是补全后的完整拼图而非提取的源瓦片。

**输入结构**：约 14×14 网格（偶数行偶数列），背景黑(0)。网格中央有一个正方形区域（边长为偶数，如 8×8 或 10×10），被均分为四个等大正方形象限。其中三个象限各包含一个彩色精灵体（同色，如红(2)，不规则形状，4-8 像素，非对称），第四个象限为纯黑(0)背景（空白）。三个非空象限中的精灵体互为 90° 旋转关系（即存在一个源瓦片，其他两个分别是该源的 90° 顺时针和 180° 或 90° 逆时针旋转）。空白象限的位置不固定（可以是四个角中的任意一个）。正方形区域外的网格部分全为黑(0)。生成约束：精灵体在 0°/90°/180°/270° 旋转下形状互不相同；三个已知象限恰好对应四种旋转中的三种（由此可唯一推断缺失的第四种旋转角）。

**规则**：
1. 定位中央正方形区域并将其均分为四个象限（左上、右上、右下、左下）。
2. 裁剪每个象限。识别哪个象限是空白的（全黑）。
3. 对三个非空象限做两两旋转测试：对象限 A，检验将其旋转 90°/180°/270° 后是否与象限 B 或 C 匹配。确定源瓦片及其在拼图中的原始位置。
4. 确定旋转方案：左上 = 0°, 右上 = 90° 顺时针, 右下 = 180°, 左下 = 270° 顺时针（即 90° 逆时针）。三个已知象限验证此方案。
5. 空白象限对应的旋转角由其位置确定。将源瓦片旋转该角度，生成缺失瓦片。
6. 将缺失瓦片透明叠加到空白象限位置（仅非黑像素写入）。
7. 输出为补全后的完整中央正方形区域（裁剪掉外围黑边）。

**关键洞察**：参考题 2013d3e2 中源瓦片固定在左上角且输出是提取它。此处源瓦片可能在任何象限，空白也在任何象限，输出是补全而非提取。求解者必须通过旋转匹配测试反向推断源瓦片身份和空白象限应有的旋转角——这是一个逆向推理过程而非正向提取。
