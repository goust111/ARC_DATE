## 新题 1：视线距离控制对称修复深度

**组合逻辑**：[射线延伸 + 视线匹配](从参考题1) → [对称补全 + 推断对称轴](从参考题11) ← [间距编码尾长](从参考题1，创新：距离不再编码路径尾部重涂长度，而是编码对称修复的像素深度)

**来源原语**：射线延伸(696d4842)、视线匹配(696d4842)、间距编码尾长(696d4842)、对称补全(981571dc)、推断对称轴(981571dc)、缺失像素(981571dc)

**依赖链**：必须先从存活像素推断对称轴，才能确定哪些像素是"缺失"的；必须通过视线匹配将标记配对到图案边界，才能得到间距；间距决定修复深度，而非全量修复——三者缺一则输出不确定。

在一个接近双轴对称但局部被擦除的图案上，利用外围标记像素的视线间距逐区域控制对称修复的深度，而非一次性补全所有缺失。

**输入结构**：约 15x15 的网格，背景为黑(0)。网格中央有一个约 9x9 的多色图案（使用蓝(1)、红(2)、绿(3)三种颜色），该图案原本具有沿中心垂直轴的左右镜像对称性，但有若干连续片段被擦除为黑(0)，形成 2~4 个缺失区域，每个缺失区域包含 2~5 个连续像素。在图案外围（图案边界框与网格边缘之间的空白区域）散布 2~4 个橙(7)单像素标记。每个标记沿某个基本方向（上/下/左/右）与图案的某个边界像素之间有一条纯黑背景间隔（无其他非背景像素阻挡）。标记与图案边界像素之间的配对关系是唯一的一对一匹配。生成约束：每个缺失区域恰好对应一个标记的视线目标边界像素在对称轴同侧或跨轴可达的镜像区域；各标记的间距值互不相同。

**规则**：
1. 从所有非黑(0)、非橙(7)像素中推断图案的垂直对称轴位置——选择使现有非背景像素左右镜像匹配数最多的列作为对称轴。
2. 对每个橙(7)标记，沿四个基本方向找到它与图案边界框内最近非背景像素之间的纯背景间隔，取唯一可行方向建立视线匹配。若多个方向可行，取间距最短的那条。
3. 计算每条视线的间距 d（标记与图案边界像素之间的背景格子数，不含两端）。
4. 用标记的颜色橙(7)填充该视线间隔（标记像素本身保持不变，图案边界像素保持不变，仅中间背景格子变为橙(7)）。
5. 从视线命中的边界像素出发，找到该像素关于对称轴的镜像位置。从该镜像位置开始，沿远离对称轴的方向（即从轴向外），在图案内部恢复 d 个连续缺失像素——将它们的颜色设为其对称轴对侧对应像素的颜色。若可恢复的缺失像素不足 d 个（到达图案边界），则恢复到边界为止。
6. 未被任何标记覆盖的缺失区域保持黑(0)不变。

**关键洞察**：对称修复不是全量的——每个标记的视线间距恰好控制对称轴另一侧的修复深度，因此同一个图案上不同区域的修复程度不同，必须逐标记独立计算间距才能确定哪些像素被恢复。

## 新题 2：杯形开口方向引导基元图案的逐级缩放方向

**组合逻辑**：[开口朝向 + 开口决定延伸向](从参考题8，创新：开口方向不再决定填充射线方向，而是决定图案缩放的展开轴) → [像素放大 + 逐级展开 + 倍增缩放序列](从参考题2) → [填充 + 射线延伸](从参考题8，创新：射线长度等于放置的缩放副本数)

**来源原语**：开口朝向(d4f3cd78)、开口决定延伸向(d4f3cd78)、填充(d4f3cd78)、射线延伸(d4f3cd78)、像素放大(762cd429)、逐级展开(762cd429)、倍增缩放序列(762cd429)、基元图案(762cd429)、杯形轮廓(d4f3cd78)

**依赖链**：杯的开口方向同时决定两件事——图案向哪个方向做倍增缩放展开、以及杯内填充后射线的发射方向。缩放展开产生的副本数 k 又反过来限定射线的长度为 k 格。三个环节形成闭合约束：开口→缩放方向→副本数→射线长度，删去任一环节均无法确定输出。

根据杯形轮廓的开口方向，将相邻的基元图案沿该方向做倍增缩放展开，同时用填充色从杯的开口射出长度等于副本数的射线。

**输入结构**：约 18x18 的网格，背景为黑(0)。网格中有一个由蓝(1)像素构成的杯形轮廓（一个近似矩形的单像素宽边框，约 5x5 至 7x7，四条边中恰好有一条边缺少中间连续 2~3 个像素形成开口，其余三条边完整）。杯形轮廓内部为黑(0)。在距杯形轮廓 1~2 格处（沿开口方向的反方向），有一个 2x2 的基元图案，由红(2)和绿(3)两种颜色组成。图案与杯之间无接触。网格在开口方向上有足够空间（至少 10 格）放置若干倍增缩放副本。生成约束：开口方向在四个基本方向中随机选取；图案固定为 2x2；缩放副本不会超出网格边界。

**规则**：
1. 检测杯形轮廓的开口方向（上/下/左/右）——开口是轮廓边界框四条边中唯一有连续缺失像素的那条边所在的方向。
2. 用青(8)填充杯形轮廓内部所有黑(0)像素（内部定义为轮廓边界框内、不属于轮廓本身的像素）。
3. 以开口方向为展开轴，从基元图案的位置开始，依次放置缩放因子为 1、2、4、... 的副本。每个副本紧接前一个副本放置（沿展开轴方向，前一副本结束后下一像素列/行即为新副本起点）。持续放置直到下一个副本会超出网格边界为止。记放置的副本总数为 k。
4. 每个缩放副本中，原图案的每个像素被放大为 scale x scale 的同色方块。副本在垂直于展开轴的方向上以原图案中心行/列为基准居中对齐。
5. 从杯形轮廓开口处的每个缺失像素位置，沿开口方向向外绘制青(8)射线，射线长度恰好为 k 格（k 为步骤 3 中放置的副本数）。射线遇到非背景像素时停止（不覆盖该像素），但若在 k 格内未遇到阻挡则恰好画 k 格。
6. 杯形轮廓的蓝(1)像素保持不变。

**关键洞察**：杯的开口方向是一个隐式控制信号——它既决定基元图案的缩放展开方向，又决定射线的发射方向；而展开产生的副本数反馈回来限定了射线长度。必须对比多个示例（不同开口方向）才能归纳出开口方向与缩放轴的对应关系。

## 新题 3：对角链堆叠后开口存活性决定洪泛填充

**组合逻辑**：[堆叠 + 对角链排列 + 角点重叠 + 冲突优先级](从参考题10) ⊗ [洪泛填充 + 开口朝向 + 开口决定延伸向](从参考题8/9)（交织关系：堆叠后的遮挡决定哪些开口存活，存活的开口才触发填充和射线）

**来源原语**：堆叠(03560426)、对角链排列(03560426)、角点重叠(03560426)、冲突优先级(03560426)、按左边缘排序(03560426)、洪泛填充(551d5bf1)、杯形轮廓(d4f3cd78)、开口(d4f3cd78)、开口朝向(d4f3cd78)、射线延伸(551d5bf1)

**依赖链**：必须先对角链堆叠确定遮挡关系，才能判断哪些杯的开口被遮盖、哪些存活。只有存活开口的杯才被洪泛填充并射出射线。射线可能撞到链中相邻杯的外壁而被截断。堆叠顺序→开口存活性→填充资格→射线长度，形成四层因果链。

将散布的杯形轮廓按对角链方式堆叠，后放者遮挡先放者的边框；仅开口未被遮挡的杯才获得洪泛填充，并从存活开口发射射线直到撞上相邻杯壁。

**输入结构**：约 20x20 的网格，背景为黑(0)。网格中有 3~5 个不同颜色的杯形轮廓（每个杯由单一非背景色构成，如蓝(1)、红(2)、绿(3)、黄(4)等），每个杯为单像素宽的近矩形边框（约 4x4 至 6x6），恰有一条边的中间 1~2 个像素缺失形成开口。各杯在输入中互不重叠，水平散布在网格下半部分，底边齐平（均接触网格底部行或同一行）。每个杯的左边缘列坐标互不相同。杯的开口方向可以是上、左或右（不为下，因为底边接触边界）。生成约束：杯的数量和尺寸保证对角链堆叠后不超出网格边界；至少有一个杯的开口在堆叠后会被相邻杯的边框遮盖。

**规则**：
1. 按各杯左边缘列坐标从小到大排序。
2. 清空网格为黑(0)背景。将排序后的第一个杯放置在网格左上角（边界框左上角对齐网格 (0,0)）。
3. 对后续每个杯，放置时其边界框左上角位于前一个杯边界框右下角（即前杯高度 h-1 行下方、前杯宽度 w-1 列右方），使两杯恰好共享一个角点像素。后放的杯的像素覆盖先放的杯的像素（后者优先）。
4. 堆叠完成后，检查每个杯的开口状态：若开口处原本缺失的像素位置现在被其他杯的边框像素占据，则该开口被封堵（标记为"死"）；否则开口存活（标记为"活"）。
5. 对每个开口存活的杯，用青(8)洪泛填充其内部（边界框内部非边框非开口的所有黑(0)像素变为青(8)）。
6. 从每个存活开口的缺失像素位置，沿开口方向向外逐格绘制青(8)射线，直到碰到任何非黑(0)像素（任何杯的边框色）或到达网格边缘，不包含终点像素。
7. 开口被封堵的杯不做任何填充，内部保持黑(0)。

**关键洞察**：对角链的遮挡关系不是均匀的——它选择性地封堵某些杯的开口，使得"是否被填充"成为堆叠几何的涌现结果而非预设属性。仅看单个示例可能无法区分"天生无开口的封闭矩形"和"开口被遮挡的杯"，需对比多个示例才能归纳出开口存活机制。

## 新题 4：象限分隔叠加中异常值色标记重叠区

**组合逻辑**：[颜色异常值选择](从参考题19) → [透明叠加 + 锚点对齐 + 裁剪](从参考题17) ← [重涂色](从参考题15，创新：异常值的颜色不用于排除，而用于标记叠加后的重叠区域)

**来源原语**：颜色异常值选择(0b148d64)、象限(0b148d64)、分隔行列(0b148d64)、透明叠加(137eaa0f)、锚点对齐(137eaa0f)、锚点像素(137eaa0f)、精灵体(137eaa0f)、裁剪(137eaa0f)、重涂色(776ffc46)

**依赖链**：异常值检测决定哪些精灵体参与叠加（排除异常值精灵体），但异常值的前景色被保留用于标记叠加后多层重叠的像素。不做异常值检测则参与叠加的精灵体集合错误；不做叠加则无法产生重叠区域；不知道异常值颜色则重叠区域的标记色不确定。三个环节交织为非线性依赖。

在四象限中找出前景色独特的异常象限，将其余三个象限的精灵体按灰色锚点对齐叠加，叠加中多层重叠的像素用异常值的前景色标记。

**输入结构**：约 15x15 的网格，背景为黑(0)。网格被一条水平全黑分隔行和一条垂直全黑分隔列分为四个象限（分隔行列各 1 像素宽）。每个象限内有一个小精灵体（4-连通单色图形，3~7 个像素，形状不规则且各不相同），每个精灵体中恰有一个像素为灰(5)（锚点），其余像素为该象限的前景色。四个象限的前景色中，三个相同（如蓝(1)），一个不同（如红(2)）。精灵体在象限内的位置随机，不接触分隔行列。生成约束：三个同色精灵体按灰色锚点对齐叠加后，至少存在 1 个像素位置有两层或三层重叠；各精灵体的灰色锚点相对于各自象限中心的偏移量互不相同（保证叠加后不完全重合）。

**规则**：
1. 找到四个象限中前景色唯一的那个象限，记该象限为异常象限，其前景色为 C_out。
2. 将其余三个象限的精灵体分别裁剪为最小边界框。
3. 以灰(5)锚点像素为对齐基准，将三个精灵体叠加到同一坐标系：所有灰锚点对齐到同一位置。叠加时，非黑(0)像素覆盖黑(0)像素。
4. 在叠加结果中，统计每个像素位置被几个精灵体的非黑像素覆盖。覆盖层数 >= 2 的像素重涂为 C_out（异常值前景色）。覆盖层数 = 1 的像素保持原精灵体的前景色。灰(5)锚点位置：若三层都覆盖则涂为 C_out，否则保持灰(5)。
5. 将叠加结果裁剪为包含所有非黑像素的最小边界框，作为输出。

**关键洞察**：异常象限被排除出叠加，但它的颜色并未被丢弃——它成为叠加后重叠密度的视觉编码。求解者必须同时理解异常值排除机制和重叠标记机制才能还原输出。

## 新题 5：平行四边形对顶点射线与交叉着色

**组合逻辑**：[连线 + 对角分解 + 标记为对顶点](从参考题13) × 2（两组标记画两个平行四边形）→ [射线延伸](从参考题1/9，创新：射线方向由平行四边形边的法线决定) → [重涂色](从参考题1，创新：射线撞击另一个平行四边形边框时，将命中点重涂为射线颜色)

**来源原语**：连线(cb227835)、对角分解(cb227835)、标记为对顶点(cb227835)、标记像素(cb227835)、射线延伸(696d4842/551d5bf1)、重涂色(696d4842)、冲突优先级(03560426)

**依赖链**：必须先用对角分解画出两个平行四边形，才能确定各顶点处射线的发射方向（垂直于该顶点所在的较短边）。两个四边形的相对位置决定射线是否命中对方边框。命中时的重涂色创造了两个四边形之间的信息交换——单独看一个四边形无法确定其哪些边框像素会被改色。

用两对不同颜色的标记像素分别画出两个绿色平行四边形轮廓，从每个顶点沿所在边法线发射该顶点标记色的射线，射线撞到另一个四边形时将命中点染为射线颜色。

**输入结构**：约 18x18 的网格，背景为黑(0)。网格中有四个前景像素形成两对标记：一对为蓝(1)（2 个像素），一对为红(2)（2 个像素）。每对标记像素之间的行偏移和列偏移均非零且不相等（保证对角分解可行）。两对标记所构成的平行四边形不重叠但相距不远（边界框间距 2~5 格），使得至少一条射线能命中另一个四边形。生成约束：每对标记的对角分解方式唯一（取 45 度对角向量加剩余正交向量的分解）；两个平行四边形的边框互不相交；每个四边形至少有一个顶点的射线能到达另一个四边形。

**规则**：
1. 对每对同色标记（蓝(1)对和红(2)对），将两标记视为平行四边形的一对对角顶点。
2. 对每对标记，将标记间的位移向量分解为一个 45 度对角向量（行列分量绝对值相等，等于两个分量绝对值中的较小者）和一个剩余正交向量（纯水平或纯垂直）。这两个向量定义平行四边形的两条相邻边。
3. 计算四个顶点坐标，用绿(3)绘制四边形的四条边（含顶点）。四个标记像素保持原色（蓝(1)或红(2)），不被绿(3)覆盖。
4. 先绘制蓝(1)对的平行四边形，再绘制红(2)对的平行四边形。若两者有重叠像素，红(2)对的绿(3)覆盖蓝(1)对的绿(3)。
5. 从每个标记像素（四个标记各一条射线）出发，确定该标记所在的平行四边形中与该标记相连的较短边的外法线方向（指向四边形外部的那个正交方向）。沿该方向逐格发射射线，颜色为该标记的原色。
6. 射线在遇到第一个非黑(0)像素时停止。若该像素属于另一个平行四边形的绿(3)边框，则将该像素重涂为射线的颜色（蓝(1)或红(2)）。若该像素属于自身四边形边框或标记像素，射线不改变该像素。若射线到达网格边缘仍未命中，则射线止于边缘。
7. 射线本身（不含起点标记、不含终点命中像素）绘制为该标记的原色。

**关键洞察**：两个平行四边形通过射线产生单向信息传递——一个四边形的标记色可以"染"到另一个四边形的边框上，但这仅在几何关系允许射线到达时发生。哪些边框像素被改色完全取决于两个四边形的相对位置和朝向，无法从单个四边形独立推断。

## 新题 6：横带内模板翻转与标记距离控制重涂深度

**组合逻辑**：[扩展 + 边框绘制 + 中点划分归属 + 按行排序](从参考题4) → [镜像/翻转](从参考题16，创新：翻转方向由带的奇偶性决定而非象限位置) ← [间距编码尾长](从参考题1，创新：标记到带边缘的距离编码模板重涂色的列数)

**来源原语**：扩展(0f63c0b9)、边框绘制(0f63c0b9)、中点划分归属(0f63c0b9)、按行排序(0f63c0b9)、单像素标记(0f63c0b9)、横带(0f63c0b9)、镜像(cfb2ce5a)、模板块(cfb2ce5a)、间距编码尾长(696d4842)、重涂色(696d4842)

**依赖链**：标记的行坐标决定带的划分边界（中点归属），带的序号奇偶决定模板翻转方向，标记的列坐标到带左/右边缘的距离决定重涂色列数。标记同时承担三重角色（划分边界、翻转选择、重涂深度），三者不可分离：改变标记位置会同时改变带的宽度、翻转方向和重涂范围。

将标记按行排序划分横带，在每带中放置模板副本（奇数带原样、偶数带垂直翻转），并从标记所在列一侧起将模板的若干列重涂为标记色，列数等于标记到该侧带边缘的距离。

**输入结构**：约 16x12 的网格（16 行 12 列），背景为黑(0)。网格左上角 3x4 区域包含一个 3 行 4 列的模板图案，使用蓝(1)和绿(3)两种颜色（内部图案不对称，使翻转可辨别）。模板区域右侧和下方是空白区域。在空白区域中散布 3~4 个单像素标记，颜色各不相同（如红(2)、黄(4)、灰(5)、品红(6)），各标记的行坐标互不相同，列坐标也互不相同。标记的列坐标均在模板区域列范围之外（即列坐标 >= 4）。生成约束：相邻标记行坐标之差 >= 4（保证每个带至少能容纳模板的高度 3 行）；标记的列坐标与带的左右边缘（列 0 和列 11）的距离 <= 模板宽度 4。

**规则**：
1. 忽略模板区域（行 0~2，列 0~3）中的内容用于带划分。将所有标记按行坐标从小到大排序。
2. 在标记行之间的中点处划分网格为水平带（包含模板区域所在的行）。第一个带从行 0 开始到第一个中点，最后一个带从最后一个中点到网格底部。为每个带编号 1, 2, 3, ...（从上到下）。
3. 对每个带，在带的水平范围（列 0 至列 11）内、带的垂直范围内放置模板副本：奇数带放置原始模板（垂直方向不翻转），偶数带放置垂直翻转的模板（上下颠倒）。模板副本从列 0 开始，顶部对齐带的顶行（奇数带）或底部对齐带的底行（偶数带）。若带高度大于模板高度，模板仅占据对齐端的 3 行，带内剩余行保持黑(0)。
4. 确定每个标记到其所在带的左边缘（列 0）和右边缘（列 11）的列距离，取较小者记为 d，对应侧记为"近侧"。
5. 从近侧边缘开始，将该带中模板副本的前 d 列（从近侧数起）的所有非黑像素重涂为该标记的颜色。模板副本中原本为黑(0)的像素不变。
6. 模板区域（行 0~2，列 0~3）在输出中被清除为黑(0)——模板仅作为参考，不出现在输出中。标记像素本身在输出中保持其原色。

**关键洞察**：标记像素的行坐标决定带的分界（进而决定翻转方向），列坐标决定重涂深度——同一个标记同时参数化了两个独立维度的变换。仅看单个示例无法区分"翻转由带序号决定"还是"由标记颜色决定"，必须对比多个示例归纳奇偶规律。

## 新题 7：形状掩码裁剪翻转模板

**组合逻辑**：[镜像 + 翻转对应 + 象限 + 模板块](从参考题16) ⊗ [形状匹配 + 包含 + 空心矩形](从参考题15，创新：包含的精灵体不是用于颜色传递，而是作为空间掩码裁剪翻转后的模板)

**来源原语**：镜像(cfb2ce5a)、翻转对应(cfb2ce5a)、象限(cfb2ce5a)、模板块(cfb2ce5a)、空心矩形(776ffc46)、包含(776ffc46)、精灵体(776ffc46)、形状匹配(776ffc46)、重涂色(776ffc46)

**依赖链**：必须先翻转模板到各象限，才有"候选像素"；必须知道灰框内精灵体的形状，才能确定掩码；掩码决定哪些候选像素存活、哪些变为背景。精灵体的颜色还决定存活像素的重涂色。翻转、掩码、重涂三步必须在同一象限内协同完成，缺一不可。

在 2x2 象限布局中，上左象限为完整模板，其余三个象限各含一个灰色框包围的小精灵体。将模板翻转到各象限后，用框内精灵体的形状作为保留掩码——仅掩码覆盖位置的翻转模板像素被保留并重涂为精灵体颜色。

**输入结构**：约 15x15 的网格（奇数边长），背景为黑(0)。网格最外一圈为黑(0)边框。内部被均分为 2x2 的四个象限（各约 7x7，象限之间无分隔线）。左上象限：填满一个两色模板（使用蓝(1)和红(2)，非对称图案，使各方向翻转产生不同结果）。其余三个象限（右上、左下、右下）各包含：一个灰(5)单像素宽空心矩形框（约 4x4 至 5x5），框内包含一个小精灵体（3~5 个像素，4-连通，单色，颜色为绿(3)、黄(4)、品红(6)之一，三个象限颜色各不相同），框内其余位置为黑(0)。三个精灵体的形状各不相同。生成约束：灰框在象限内居中放置；精灵体的边界框不超过灰框内部；精灵体在框内的位置使得当映射到象限中心坐标系时，掩码至少覆盖翻转模板的 30% 像素。

**规则**：
1. 提取左上象限的模板内容。
2. 对右上象限：将模板水平翻转（左右镜像）。对左下象限：将模板垂直翻转（上下镜像）。对右下象限：将模板沿两轴翻转（等价旋转 180 度）。
3. 对每个非模板象限，提取灰(5)框内精灵体的形状掩码（精灵体像素为 1，其他为 0）和颜色。将掩码的中心（精灵体边界框中心）对齐到翻转模板的中心。
4. 在每个象限中，翻转模板的像素仅在掩码为 1 的位置被保留。保留的像素全部重涂为该象限精灵体的颜色。掩码为 0 的位置变为黑(0)。
5. 灰(5)框在输出中移除（变为黑(0)）。左上象限保持原始模板不变。
6. 输出网格与输入网格同尺寸。

**关键洞察**：精灵体在源题（776ffc46）中用于颜色传递给同形状的自由副本，但在此题中它的形状反而成为空间掩码，决定翻转模板的哪些区域被"雕刻"出来。同一个精灵体同时贡献形状（掩码）和颜色（重涂），双重角色无法分离。

## 新题 8：缺口射线生成内容参与行对齐提取堆叠

**组合逻辑**：[洪泛填充 + 边框缺口 + 缺口方向决定射线](从参考题9) → [堆叠 + 行对齐配对 + 按顺序堆叠](从参考题20)（交织：射线穿过提取区域时在其中留下痕迹，该痕迹被作为内容一并提取堆叠）

**来源原语**：洪泛填充(551d5bf1)、空心矩形(551d5bf1)、边框缺口(551d5bf1)、缺口方向决定射线(551d5bf1)、射线延伸(551d5bf1)、堆叠(aab50785)、标记块(aab50785)、行对齐配对(aab50785)、按顺序堆叠(aab50785)、提取区域(aab50785)、忽略干扰项(aab50785)

**依赖链**：洪泛填充和缺口射线在网格上绘制青色内容，其中射线可能穿越两个标记块之间的提取区域。提取步骤必须在填充/射线步骤之后进行，因为射线产生的像素是提取内容的一部分。若跳过填充步骤，提取区域中缺少射线痕迹，堆叠输出不同；若跳过提取步骤，则无法生成最终输出。射线的方向和长度由缺口位置决定，而提取的范围由标记块对决定——两者在空间上的交汇是偶然的，必须综合分析才能确定最终输出。

先对蓝色矩形框做洪泛填充和缺口射线，射线穿过的区域连同其他内容一起被行对齐的标记块对界定并提取，最后垂直堆叠。

**输入结构**：约 20x14 的网格（20 行 14 列），背景为黑(0)。网格中有 2~3 个蓝(1)空心矩形框（单像素宽，约 4x4 至 5x5），每个框的边框上有 0 或 1 个单像素缺口（非角点位置缺少一个蓝(1)像素）。框的内部为黑(0)。另有 4~6 个红(2) 2x2 实心方块作为标记块，成对出现在同一双行跨度上（每对中两个标记块分别在左侧和右侧，共享同两行），形成 2~3 对。每对标记块之间的矩形区域即为提取区域。蓝色矩形框的部分缺口射线方向恰好穿过某些提取区域。网格中可能有少量灰(5)散点作为干扰噪声。生成约束：至少有一个蓝色框的缺口射线穿过某个提取区域；标记块不与蓝色框重叠；各提取区域在射线绘制前可能包含黑(0)像素和/或灰(5)噪声像素。

**规则**：
1. 对每个蓝(1)空心矩形框：若边框完整（无缺口），仅将框内部的黑(0)像素洪泛填充为青(8)。若边框有一个单像素缺口，同样将框内部填充为青(8)，然后从缺口位置沿缺口所在边的外法线方向（垂直于该边、指向框外）逐格绘制青(8)射线，直到碰到非黑(0)、非灰(5)像素或到达网格边缘（灰(5)噪声不阻挡射线，射线覆盖灰(5)像素将其替换为青(8)）。
2. 识别所有红(2) 2x2 标记块。将共享同一双行跨度的标记块配对。
3. 对每对标记块，提取它们之间的矩形区域（不包含标记块本身）：行范围为标记块共享的两行，列范围为左标记块右边缘+1 到右标记块左边缘-1。
4. 将所有提取区域按其行跨度从上到下排序，垂直堆叠。堆叠时各区域之间无间隔。
5. 灰(5)噪声像素在提取区域中保持原样（除非已被步骤 1 的射线覆盖为青(8)）。
6. 输出为堆叠后的矩形（高度 = 所有提取区域行数之和，宽度 = 各提取区域中最大列宽，窄的区域左对齐，右侧补黑(0)）。

**关键洞察**：缺口射线不只是视觉装饰——它们在提取区域中留下青色痕迹，改变了被提取堆叠的实际内容。同一个提取区域在不同示例中可能包含也可能不包含射线痕迹，取决于附近蓝框的缺口方向。必须先完成所有填充和射线绘制，再进行提取，否则输出错误。

## 新题 9：标记间距隐式编码平铺缩放因子

**组合逻辑**：[扩展 + 中点划分归属 + 按行排序 + 边框绘制](从参考题4) ⊗ [平铺 + 像素放大 + 逐级展开](从参考题2，创新：缩放因子不再是固定的 2 的幂次，而是由带高度与图案高度之比决定)

**来源原语**：扩展(0f63c0b9)、中点划分归属(0f63c0b9)、按行排序(0f63c0b9)、边框绘制(0f63c0b9)、单像素标记(0f63c0b9)、横带(0f63c0b9)、平铺(762cd429)、像素放大(762cd429)、基元图案(762cd429)、逐级展开(762cd429)

**依赖链**：标记的行坐标决定带的划分（中点归属），带高度 = 带的行数。缩放因子 = floor(带高度 / 图案高度)。缩放因子 < 1 的带不放置图案。因此标记的不规则间距直接编码了图案在各带中的不同缩放大小——间距大的带产生大副本，间距小的带产生小副本或不产生副本。这种编码关系在源题中不存在。

标记点沿行方向不等距分布，将网格分为不等高的横带；在每带中以带高度与图案高度之比为缩放因子放置缩放后的图案，标记色作为边框色。

**输入结构**：约 20x10 的网格（20 行 10 列），背景为黑(0)。网格第 0 行、第 0~2 列有一个 3x3 的基元图案（仅占据行 0~2、列 0~2），使用蓝(1)和红(2)两色。在列 5 位置（或网格中部某固定列），有 3~4 个单像素标记，颜色各不相同（如绿(3)、黄(4)、灰(5)、品红(6)），行坐标互不相同且互不连续。生成约束：相邻标记之间的行间距不全相同（至少有两对间距不同）；最大间距不超过 9 行；最小间距 >= 3 行（即图案高度，保证至少缩放因子为 1）。

**规则**：
1. 将所有标记按行坐标从小到大排序。在相邻标记行坐标的中点（向下取整）处划分网格为水平带。第一个带从行 0 到第一个中点行（含），最后一个带从最后一个中点行+1 到网格底部行（含）。
2. 对每个带，计算带高度 H（带包含的行数）。计算缩放因子 s = floor(H / 3)，其中 3 为图案高度。
3. 若 s >= 1，将基元图案的每个像素放大为 s x s 的同色方块，得到 (3s) x (3s) 的缩放副本。将该副本放置在带内：水平居中于网格宽度，垂直方向顶端对齐带的顶行。若缩放副本超出带的底行则裁剪掉超出部分。若缩放副本超出网格右边缘则裁剪掉超出部分。
4. 若 s = 0（带高度 < 3），该带内不放置图案，保持黑(0)。
5. 对每个带，用该带对应标记的颜色绘制带的边框：带的顶行和底行全部填充为标记色，带的左列（列 0）和右列（最后一列）在带范围内填充为标记色。边框覆盖缩放副本的对应像素。
6. 基元图案原始位置（行 0~2、列 0~2）被纳入第一个带的正常处理流程中，不做特殊保留。标记像素保持其原色。

**关键洞察**：标记点的不等距分布看似只是划分边界，实则隐式编码了每个带内图案的缩放因子——相距远的标记产生大缩放，相距近的标记产生小缩放。求解者必须发现"带高度决定缩放因子"这一隐藏规则，仅看输出中图案大小的变化无法直接推断，需结合标记位置归纳。
