## 新题 1：邻接投票决定镜像分组

**组合逻辑**：[边邻接计数 + 邻接多数决](已有) → [重涂色](已有) → [逐色独立变换 + 包围盒内翻转](创新：镜像的分组不是由输入原色决定，而是由投票重涂后的颜色动态决定，使得两个远距区域可能被合并为同一镜像包围盒)

**来源原语**：重涂色/recolor、边邻接计数/edge_adjacency_count、邻接多数决/adjacency_majority_rule（477d2879）；镜像/mirror、逐色独立变换/per_color_transform、包围盒/bounding_box、包围盒内翻转/flip_within_bbox（e74e1818）

**依赖链**：投票结果决定每个灰区域的颜色 → 同色区域共享一个包围盒 → 在该包围盒内垂直镜像。投票改变了颜色分组，进而改变了哪些区域被合并、以多大的包围盒镜像。删除投票则镜像分组无定义；删除镜像则投票只是重涂色无几何效果。

以邻接标记投票为各灰色连通分量上色后，同色分量共享包围盒，在该包围盒内对该色所有像素执行垂直镜像翻转。

**输入结构**：约 15x15 网格，背景黑(0)。网格中分布 4-6 个灰(5) 4-连通不规则区域（各 4-8 像素，形状不固定，不同示例中形状各异，区域之间互不 4-邻接）。3 种标记颜色——红(2)、蓝(1)、绿(3)——各以若干孤立单像素散布在灰区域附近。每个标记像素与至少一个灰区域边邻接（两像素 4-相邻且共享一条边即为边邻接）。每个灰区域至少与两种标记颜色的像素边邻接，保证投票有意义。生成约束：任意两个灰区域不 4-邻接；标记像素之间不 4-邻接；至少有两个灰区域最终被投票到同一颜色（否则镜像效果平凡）。

**规则**：
1. 将所有灰(5)像素按 4-连通标记为独立连通分量。
2. 对每个灰分量，统计它与周围每种标记颜色像素的共享边数（灰像素与标记像素 4-相邻且共享一条边计 1；一个标记像素可与同一分量的多个灰像素相邻，每条边独立计数）。
3. 将该分量重涂为共享边数最多的标记颜色。若两种标记颜色共享边数相同，选在行优先扫描序（先比较行号从小到大，再比较列号从小到大）中最先出现的标记像素所属颜色。
4. 完成所有分量的重涂后，对每种出现在结果中的前景颜色，计算该颜色所有像素（仅限重涂后的灰区域像素，不含标记像素本身）的最小轴对齐包围盒。
5. 在每种颜色的包围盒内，对该颜色的所有像素执行垂直镜像：像素 (r, c) 移动至 (r0 + r1 - r, c)，其中 r0 和 r1 分别是该颜色包围盒的最小行和最大行。若目标位置已被另一种颜色的像素占据，则保持该目标位置不变（后来的颜色不覆盖先存在的颜色；处理顺序为行优先扫描序中最先出现的颜色先处理）。
6. 标记像素在输出中保持原位和原色不变。

**关键洞察**：两个空间上远离的灰区域若被投票到同一颜色，它们将共享一个跨越两者的大包围盒并在其中联合镜像，使像素飞跃到对方原来的位置区域附近——这一几何效果在单独的投票规则或单独的镜像规则中都不存在，只在组合时涌现。

## 新题 2：去噪改变形状等价关系

**组合逻辑**：[擦除 + 单像素分量移除 + 八连通判定](已有) → [形状匹配 + 旋转翻转等价](已有) → [绘制表格 + 等价涂指定色](创新：去噪改变了形状几何，使原本不等价的形状变为等价或反之，表格内容依赖于清洗后的几何而非原始几何)

**来源原语**：擦除/erase、孤立像素/isolated_pixel、单像素分量移除/single_pixel_removed、八连通判定/eight_connectivity（42a50994）；形状匹配/shape_match、旋转翻转等价/dihedral_equiv、绘制表格/draw_table、等价表格/equivalence_table、归一化掩码/normalized_mask、边缘图例/edge_legend、等价涂指定色/equiv_colored（6165ea8f）

**依赖链**：去噪改变对象形状 → 形状改变影响旋转翻转等价判断 → 等价判断决定表格中每个单元格的颜色。删除去噪环节则基于含噪形状比较，得到错误的等价关系；删除等价比较和表格绘制则去噪无用途。

对含噪彩色对象先做 8-连通单像素去噪，再将清洗后的形状按旋转/翻转等价关系生成颜色标注的等价矩阵表。

**输入结构**：约 18x18 网格，背景黑(0)。4-5 个不同前景色的 8-连通对象（如蓝(1)、红(2)、绿(3)、黄(4)、品红(6)），每个对象 6-12 像素，形状不固定但可置于一个紧凑包围盒内。每个对象周围散布 2-4 个同色孤立噪声像素（与主体不 8-连通的同色单像素）。网格最右列从上往下放置每种前景色各一个单像素（图例像素），图例像素与其主体不 8-连通，它们的纵向顺序定义表格行列的排列顺序。生成约束：不同颜色的对象互不 8-邻接；至少有一对对象在去噪后旋转/翻转等价但含噪时不等价（即噪声像素破坏了旋转对称性）；至少有一对对象在含噪和去噪后都不等价（用作对照）。

**规则**：
1. 对每种前景色，按 8-连通标记该色所有像素为连通分量。删除所有大小为 1 的分量（将该像素置为黑(0)）。保留所有大小 > 1 的分量。图例列中的单像素不做删除（它们作为元信息保留）。
2. 对每种颜色保留下来的主体对象，提取其紧凑包围盒中的二值掩码（前景=1，背景=0）。
3. 对每对颜色 (i, j)（i < j，按图例顺序编号），检查掩码 i 和掩码 j 是否在 8 种二面体变换（4 种旋转 x 是否翻转）下存在一种使两个掩码完全重合。
4. 绘制等价表格：图例中 N 种颜色产生 NxN 的表格。表格左侧和顶部各绘制 2x2 颜色标签块（按图例顺序），标签之间、标签与表格体之间各隔 1 列/行背景色。表格体中对角线单元格为 2x2 背景色块。非对角线单元格 (i, j)：若颜色 i 与颜色 j 的清洗后形状旋转/翻转等价，填 2x2 红(2)块；否则填 2x2 灰(5)块。表格关于对角线对称。
5. 输出仅包含该表格（原始网格内容不出现在输出中）。

**关键洞察**：噪声像素会在某些方向上打破对象的旋转对称性——去除噪声后，看似不同的形状可能因恢复了被噪声破坏的对称性而变为等价。表格的每个单元格都隐式依赖于去噪步骤的几何副作用。

## 新题 3：形状频次分类决定是否自相似展开

**组合逻辑**：[形状频次分组 + 旋转翻转不变](已有) → [掩码克罗内克自积](已有，创新应用：仅对共享形状执行，唯一形状被擦除；且用于展开的掩码与用于频次判定的掩码是同一个，使得几何内容同时充当分类依据和展开模板)

**来源原语**：排序/sorting、形状频次分组/shape_frequency_grouping、旋转翻转不变/rotation_flip_invariant、共享与唯一形状/shared_vs_unique_shape（62593bfd）；印章覆盖/stamp、自相似嵌套/self_similar_nest、掩码克罗内克自积/kronecker_self、二值掩码/binary_mask（80af3007）

**依赖链**：归一化掩码同时用于频次比较和克罗内克展开 → 频次判定结果（共享/唯一）决定是否执行展开 → 展开使用的正是判定时比较过的掩码。删除频次判定则不知道哪些对象该展开；删除展开则频次判定无可视效果。

将多个小对象按旋转/翻转等价分组；共享形状的对象各自在原位展开为 Kronecker 自积的 9x9 自相似图案，唯一形状的对象被擦除。

**输入结构**：约 18x18 网格，背景黑(0)。5-7 个单色小对象（不同颜色：蓝(1)、红(2)、绿(3)、黄(4)、品红(6)、橙(7)等），每个对象 4-连通、3-6 像素，可置于 3x3 包围盒内（包围盒不超过 3x3）。对象之间至少间隔 6 行 6 列（保证展开后的 9x9 不重叠）。生成约束：至少两个对象在旋转/翻转下形状相同（归一化到相同的 3x3 掩码）；至少一个对象的形状在旋转/翻转下唯一；包围盒严格 3x3（不足 3x3 的在相应方向补黑至 3x3，补黑方向为向右、向下扩展）。

**规则**：
1. 对每个对象，提取其 3x3 包围盒内的二值掩码（前景=1，背景=0）。若包围盒小于 3x3，向右和/或向下扩展到 3x3，扩展部分掩码值为 0。
2. 将每个掩码归一化为其 8 种二面体变换中字典序最小的形式（将 3x3 掩码展平为 9 位二进制串，选最小的那个变换结果）。
3. 按归一化掩码分组。出现 2 次及以上的掩码为"共享形状"，出现 1 次的为"唯一形状"。
4. 对每个共享形状的对象：以其原始 3x3 掩码（非归一化版本）执行 Kronecker 自积——构建 9x9 输出块，掩码中每个值为 1 的单元格替换为该 3x3 掩码本身的副本（前景色保持该对象的原色），值为 0 的替换为 3x3 全黑块。将该 9x9 块放置在以原对象包围盒左上角为左上角的位置。
5. 对每个唯一形状的对象：擦除（将其所有像素置为黑(0)）。
6. 输出网格大小与输入相同。共享形状对象被展开后可能部分超出网格边界，超出部分裁剪丢弃。

**关键洞察**：同一个 3x3 掩码既是形状比较的标准（决定该对象是否展开），又是 Kronecker 自积的模板（决定展开后的图案）。两个旋转等价但原始朝向不同的对象，虽然被归入同一频次组，但各自使用自己的原始掩码展开，产生不同朝向的自相似图案。

## 新题 4：方向标记指引滑动、高度排名决定顺序与着色

**组合逻辑**：[方向编码 + 色块决定输出位置](已有) + [高度排名 + 排序](已有) → (创新组合：高度排名不仅决定着色，还决定滑动处理的先后顺序，先处理的竖条占据目标位置后会阻挡后续竖条，使最终布局依赖于高度与方向的联合配置)

**来源原语**：滑动/sliding、方向编码/direction_encoding、色块决定输出位置/color_direction_determines_placement、精灵体/sprite、着色标记/colored_marker（a8c38be5）；排序/sorting、高度排名/height_ranking、竖直线段/vertical_bar、保留极值高度分色/keep_extremes_and_recolor（a61f2674）

**依赖链**：高度排名决定处理顺序 → 先滑动的竖条占位后阻挡后续竖条 → 最终位置由方向+顺序+阻挡三者共同决定 → 高度排名同时决定极值竖条的着色。删除排名则无处理顺序且无法决定着色；删除方向标记则不知道往哪滑。

将多根带方向标记的竖条按高度排名依次向指定方向滑动至边界或被阻挡的位置，最高和最矮竖条分别涂蓝和红。

**输入结构**：约 15x15 网格，背景黑(0)。4-6 根灰(5)竖直线段（1 像素宽、3-8 像素高），各自的底端对齐在网格底部（最后一行）。每根竖条的左侧或右侧紧邻放置一个非灰非黑的标记像素（标记颜色如橙(7)），标记像素在竖条的竖直范围中间行（即 floor((top_row + bottom_row) / 2) 行）。标记在左侧表示该竖条向左滑动，标记在右侧表示向右滑动。各竖条初始位置互不相邻（列间距至少 2）。各竖条高度互不相同。生成约束：至少有两根竖条朝同一方向滑动（使阻挡效果可被观察到）。

**规则**：
1. 按高度从高到矮对竖条排序。高度为竖条像素数。
2. 依排名顺序依次处理每根竖条：读取其标记像素的位置（左侧或右侧），确定滑动方向（左或右）。
3. 将竖条沿水平方向滑动：竖条保持原来的行范围不变，列号沿指定方向逐列移动，直到竖条的任何像素即将超出网格边界或即将与已放置的竖条像素（含先前处理的竖条）在同列重叠时停止。竖条停在最后一个合法列位置。
4. 滑动结束时删除所有标记像素。
5. 将最高的竖条重涂为蓝(1)，最矮的竖条重涂为红(2)。其余竖条保持灰(5)。
6. 若最高和最矮的竖条高度差为 0（不会发生，因生成约束保证互不相同），不做特殊处理。

**关键洞察**：最高的竖条先滑，总能到达边界；较矮的竖条后滑，可能被先到的高竖条阻挡而停在中途。改变任一竖条的高度会同时改变处理顺序、阻挡关系和极值着色，三者紧密耦合。仅凭一个示例无法区分"按高度排序处理"与其他可能的排序规则（如按初始列号）。

## 新题 5：标记围定矩形的缺色补全 + 补全色反涂边框

**组合逻辑**：[颜色多重集相同 + 各区域缺像素](已有，创新改造：操作对象从分隔线划分的区域改为标记围定的矩形) → [重涂色](创新：补全的颜色反过来成为该矩形红色边框标记的新颜色，使补全结果编码在边框上可见)

**来源原语**：填充/fill、计数/counting、颜色多重集相同/same_color_multiset、各区域缺像素/region_miss_pixel（e3fe1151）；重涂色/recolor、标记像素/marker_pixel、标记围定区域重涂/marker_bounded_rect_recolor、填充矩形/filled_rectangle、包围框内部/inside_bbox（36fdfd69）

**依赖链**：多重集比较确定每个矩形的缺失颜色 → 缺失颜色填入空位 → 同一颜色替换该矩形的所有红色边框标记。删除多重集比较则不知道缺什么颜色；删除边框重涂则补全结果只在内部可见，边框信息丢失。补全颜色同时充当"填充值"和"边框新色"——同一个值被两种不同操作消费，这在源题中不存在。

比较四个红色标记围定矩形的内部颜色多重集，找出各自缺失的颜色并填入空位，然后用该缺失颜色替换该矩形的所有红色边框标记。

**输入结构**：约 14x14 网格，背景黑(0)。网格中分布 4 个不重叠的矩形区域（各约 4x4 至 5x5），每个矩形的边缘由红(2)标记像素勾勒（红像素位于矩形的四条边上，不必铺满每个边缘位置，但四条边上各至少有 1 个红像素）。矩形内部（不含红边框）填有若干非黑非红前景像素（使用蓝(1)、绿(3)、黄(4)、品红(6)等），其中恰好一个位置是黑(0)空位。四个矩形的非黑非红内部像素构成的颜色多重集在补全后应完全相同（即它们拥有相同的完整多重集，但各缺少不同的一个颜色实例）。生成约束：四个矩形内部大小相同；每个矩形恰好缺少一个不同的颜色实例；补全后多重集完全一致。

**规则**：
1. 识别每个矩形：找到红(2)标记像素围定的最小轴对齐矩形，将其边框内部（不含红标记行列上的像素）视为该矩形的内容区域。
2. 对每个矩形的内容区域，收集所有非黑像素的颜色，构建该矩形的当前颜色多重集。
3. 取四个矩形中每种颜色的最大出现次数，构建完整多重集。
4. 对每个矩形，其缺失颜色 = 完整多重集减去当前多重集后剩余的唯一颜色。将该矩形内容区域中的黑(0)空位像素填为该缺失颜色。
5. 将该矩形边缘上所有红(2)标记像素替换为该矩形的缺失颜色。
6. 背景和其他非矩形区域的像素保持不变。

**关键洞察**：每个矩形的缺失颜色承担双重角色——它既是内容补全的填充值，又是边框标记的替换色。输出中边框颜色的差异直接暴露了各矩形原来缺失的是哪种颜色，使补全分析的结论编码在结构的外部可见属性上。

## 新题 6：隔间计数压缩为竖条高度再排极值着色

**组合逻辑**：[重建 + 封闭区域 + 计数 + 忽略干扰项](已有，创新改造：计数结果不映射为水平条长度而是生成竖直条高度) → [排序 + 高度排名 + 保留极值高度分色](已有，创新应用：排序对象是由计数生成的竖条而非输入中预存的竖条)

**来源原语**：计数/counting、重建/reconstruct、分隔框架/partitioned_frame、封闭区域/enclosed_region、区域数映射长度/region_count_to_length、忽略干扰项/ignore_distractors（89565ca0）；排序/sorting、高度排名/height_ranking、竖直线段/vertical_bar、保留极值高度分色/keep_extremes_and_recolor（a61f2674）

**依赖链**：框架内部墙壁结构 → 封闭房间计数 → 生成对应高度的竖条 → 竖条按高度排名 → 极值竖条着色。删除计数环节则无法生成竖条；删除排名着色则竖条仅是等价的灰条无区分。框架的 2D 空间结构被压缩为 1D 的高度属性，再被进一步压缩为 0D 的极值颜色属性。

将多个彩色分隔框架各自的封闭房间数转化为同色竖条高度，排列后对最高和最矮竖条分别着蓝和红。

**输入结构**：约 16x16 网格，背景黑(0)。3-5 个不同颜色的矩形分隔框架（蓝(1)、绿(3)、黄(4)、品红(6)等），每个框架由该颜色的水平和竖直线段构成外壁和内部隔墙，围出 1-5 个封闭的黑(0)背景房间。框架之间互不重叠。另有一种干扰颜色（如橙(7)）的散点像素随机分布在网格中，与任何框架的线段不对齐且不形成任何封闭区域。各框架的封闭房间数互不相同。生成约束：每种颜色的框架线段为严格的水平或竖直直线段（单像素宽），可能被干扰像素或其他框架的线段打断——需从致密的行列证据重建完整线段后再计数。

**规则**：
1. 识别干扰色：对每种非黑颜色，尝试重建其水平和竖直线段（在同一行或同一列中连续出现 3 个及以上像素即视为有效线段证据；不足 3 个的视为噪声），然后计数由重建后的线段完全围成的 4-连通黑色封闭区域数。封闭区域数为 0 的颜色即为干扰色，丢弃其所有像素。
2. 对每种剩余颜色 C，记其封闭房间数为 N_C。
3. 构建输出网格：高度 = max(N_C) + 1，宽度 = 剩余颜色数 x 2 - 1（竖条宽 1 像素，竖条间隔 1 列背景色）。输出背景黑(0)。
4. 按框架颜色在输入网格中出现的最小行号排序（出现最早的在最左列），依次在输出中放置竖条。每根竖条颜色为该框架颜色，高度 = N_C 像素，底端对齐输出底行。
5. 将最高的竖条重涂为蓝(1)，最矮的竖条重涂为红(2)。若该竖条原本就是蓝(1)或红(2)，仍然执行重涂（覆盖原色）。

**关键洞察**：输入中复杂的 2D 框架拓扑被压缩为一维高度值，而极值着色进一步将高度排名压缩为二元的颜色标签。求解者必须先理解框架的墙壁重建和房间计数规则，才能理解输出竖条的高度含义，再识别极值着色规则——三层信息压缩环环相扣。

## 新题 7：十字标记检测 + 重复臂色配对 + 包围盒填色

**组合逻辑**：[图案识别 + 中心与臂颜色 + 忽略干扰项](已有) → [计数 + 频率唯一性 + 重复色为答案](已有，创新改造：重复色不输出为 1x1 答案，而是驱动后续空间操作) → [包围盒 + 填充](创新：由重复臂色的两个十字标记的位置确定包围盒，再填充该包围盒内部)

**来源原语**：图案识别/pattern_recognition、十字标记/plus_marker、中心与臂颜色/center_and_arm_color、重复色为答案/repeated_color_answer、忽略干扰项/ignore_distractors（642d658d）；包围盒/bounding_box（e74e1818）；填充/fill（6cf79266）；擦除/erase（42a50994）

**依赖链**：十字标记检测过滤噪声 → 臂色频次分析找到重复色 → 重复色的两个标记空间位置确定包围盒 → 包围盒内填色。每步输出的信息类型发生变换：形状→颜色频次→空间坐标对→面积填充。删除任一步骤后续均无法执行。

在噪声网格中找出所有黄色中心的十字标记，统计臂色出现次数，将出现两次的臂色所对应的两个十字标记之间的包围盒用该臂色填满。

**输入结构**：约 15x15 网格，背景黑(0)。散布有各色噪声像素（非黄的随机前景色，单像素，不与任何十字标记的臂像素 4-邻接）。4-6 个十字标记：每个由一个黄(4)中心像素加上四个共色的正交臂像素组成（中心的上下左右各一个同色像素，臂色不为黑、不为黄）。不同十字标记的臂色各不相同，但恰好有一种臂色在两个十字标记上出现。生成约束：十字标记之间不重叠（中心间距至少 4）；噪声像素不与任何十字标记像素 4-邻接；重复臂色的两个十字标记之间的包围盒内不包含其他十字标记的中心。

**规则**：
1. 扫描网格，识别所有有效十字标记：黄(4)中心像素，其上下左右四个 4-邻居存在且为同一种非黑非黄颜色。若某黄像素的四邻居不满足此条件（缺少邻居、颜色不一致等），则该黄像素不是有效十字中心。
2. 记录每个有效十字标记的臂色。统计每种臂色出现在几个标记上。
3. 找到恰好出现 2 次的臂色（称为目标色）。生成约束保证恰好有一种这样的颜色。
4. 找到拥有该目标臂色的两个十字标记的中心坐标，计算以这两个中心为对角的最小轴对齐包围盒（含两个中心所在行列）。
5. 将该包围盒内的所有黑(0)背景像素填为目标色。包围盒内已有的非黑像素（十字标记像素、噪声像素）保持不变。
6. 擦除包围盒外部的所有非黑像素（十字标记和噪声均置为黑(0)），只保留包围盒内部的内容和包围盒外部的黑色背景。

**关键洞察**：十字标记检测将噪声网格简化为少数结构化锚点；臂色频次分析从锚点中筛选出唯一的一对；这对锚点的空间跨度定义了填充的几何范围。信息依次经历了形状过滤→统计筛选→空间配对→面积操作四种类型转换，每一步都在缩小目标范围。

## 新题 8：邻接投票着色 + 跨象限多重集补全

**组合逻辑**：[边邻接计数 + 邻接多数决 + 重涂色](已有) → [颜色多重集相同 + 各区域缺像素 + 填充](已有)（创新组合：投票着色的结果直接构成多重集比较的数据输入——投票改变哪个分量是什么颜色，进而改变各象限的多重集，最终改变补全填色。两套源题规则在颜色赋值层面深度耦合）

**来源原语**：重涂色/recolor、连通分量/connected_component、标记像素/marker_pixel、边邻接计数/edge_adjacency_count、邻接多数决/adjacency_majority_rule（477d2879）；填充/fill、分隔线/separator_line、矩形区域/rect_region、颜色多重集相同/same_color_multiset、各区域缺像素/region_miss_pixel（e3fe1151）

**依赖链**：邻接投票决定灰分量的颜色 → 各象限投票后的颜色分布构成该象限的多重集 → 跨象限比较得出完整多重集 → 每个象限的缺失颜色填入空位。投票结果直接影响多重集内容，进而影响补全结果。删除投票则分量全为灰色、多重集比较无信息；删除多重集补全则投票只是着色无后续逻辑。

灰色分量通过邻接标记投票获得颜色后，比较四个象限的颜色多重集，找出各象限的缺失颜色并填入空位。

**输入结构**：约 14x14 网格。一条完整的橙(7)横行和一条完整的橙(7)竖列交叉形成十字分隔线，将网格分为四个等大矩形象限。每个象限内有 2-3 个灰(5) 4-连通小区域（各 2-5 像素，形状不固定），以及若干孤立的标记像素（蓝(1)、红(2)、绿(3)、黄(4)中的若干种）。每个象限内还有恰好一个黑(0)空位像素（即该象限中应有前景色但为黑的一个位置）。标记像素散布在灰区域附近，与灰区域边邻接。生成约束：四个象限中灰区域总数相同；投票后四个象限应具有相同的完整颜色多重集（即投票后各象限的非黑非橙非灰前景色加上将来的补全色构成相同的多重集），但各自缺少不同的一个颜色实例；标记像素本身不参与多重集计算（它们是控制元素而非内容元素）。

**规则**：
1. 在每个象限内部独立处理：将该象限中所有灰(5)像素按 4-连通标记为连通分量。
2. 对每个灰分量，统计其与该象限内各标记颜色像素的共享边数。将该分量重涂为共享边数最多的标记颜色。若平局，选行优先扫描序中最先出现的标记像素的颜色。
3. 重涂完成后，对每个象限收集所有非黑(0)、非橙(7)像素的颜色（包含重涂后的分量颜色和标记像素颜色均不计入——仅计重涂后分量的颜色，不含标记像素）。构建该象限的当前颜色多重集。
4. 取四个象限中每种颜色的最大出现次数，构建完整多重集。
5. 对每个象限，计算完整多重集减去当前多重集的差，得到缺失的一个颜色实例。将该象限中的黑(0)空位像素填为该缺失颜色。
6. 标记像素和橙(7)分隔线保持不变。

**关键洞察**：标记像素的位置微小变化会翻转某个灰分量的投票结果（从颜色 A 变为颜色 B），这会改变该象限的多重集，进而可能改变四个象限中每一个的补全颜色。邻接投票和多重集补全通过颜色赋值层面形成紧密反馈：投票输出即补全输入，一处投票变化可波及所有象限的补全结果。
