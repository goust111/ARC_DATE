## 新题 1：遮挡层序决定角点邻域几何

**组合逻辑**：[遮挡层序/排序](已有) → [计数/奇偶分类](创新：层序rank的奇偶性作为分类依据) → [描边/mark_neighbors + 对角邻接/正交邻接](创新：rank奇偶替代颜色来选择邻域几何)

**来源原语**：遮挡层序/排序(68bc2e87) + 描边/mark_neighbors(0ca9ddb6) + 对角邻接/正交邻接(0ca9ddb6) + 计数(d5c634a2)

**依赖链**：遮挡分析产出各框架的层序rank → rank的奇偶性对框架进行二分类 → 分类结果决定在每个框架的四角施加对角扩展还是正交扩展。删除遮挡分析则无法确定rank，删除奇偶判断则无法选择几何类型，删除邻域扩展则输出无变化。

从重叠的空心矩形框中推断层叠顺序，再按层序rank的奇偶性为每个框架的四角选择对角或正交邻域扩展标记。

**输入结构**：黑(0)背景网格，约 15x15。网格中有 4~6 个单像素厚的空心矩形框，每个框使用不同的非黑非黄非橙颜色（如蓝(1)、红(2)、绿(3)、灰(5)、品红(6)等）。各框架的矩形区域部分重叠，重叠处仅显示最顶层框架的颜色。每个框架的可见像素至少足以确定其完整矩形边界框（即四个极值行列均有可见像素）。框架之间的重叠关系构成一个完整的线性顺序（不存在循环遮挡）。所有框架的四个角点的对角/正交邻居位置中至少有 2 个位于网格内且为黑(0)。

**规则**：
1. 对每种框架颜色，收集该颜色的所有可见像素，计算其行列极值，从而还原该框架的完整矩形边框（即极值行列围成的一像素厚矩形环）。
2. 在所有还原后的框架存在空间重叠的格子上，实际可见的颜色表示该位置的最上层框架。通过这些重叠证据推断所有框架的从底到顶的唯一线性堆叠顺序，记底层为 rank=1，依次递增。
3. 对每个框架，定位其矩形边框的四个角点像素（左上、右上、左下、右下）。
4. rank 为奇数的框架：对其每个角点，将该角点的四个对角邻居（左上、右上、左下、右下方向各偏移一格）中位于网格内且当前为黑(0)的格子涂为黄(4)。
5. rank 为偶数的框架：对其每个角点，将该角点的四个正交邻居（上、下、左、右方向各偏移一格）中位于网格内且当前为黑(0)的格子涂为橙(7)。
6. 扩展标记仅涂在当前为黑(0)的格子上；已有任何非黑颜色的格子不被覆盖。
7. 按 rank 从低到高的顺序依次处理各框架的角点标记（低层先画，高层后画），若多个框架的标记目标位置重叠，后处理的框架标记不覆盖先前已涂的标记像素（因为先涂的已非黑色）。
8. 所有原始框架像素和背景保持不变。

**关键洞察**：框架的深度rank奇偶性决定了邻域扩展的几何类型——这一决策必须通过遮挡分析获得，而非从任何可见颜色直接读取。源题 0ca9ddb6 中是标记颜色选择几何类型，这里替换为遮挡层序分析得出的rank属性。

## 新题 2：互补残片联合组装与遮挡排序的旋转象限铺设

**组合逻辑**：[对齐合并取并集/补全](已有) + [遮挡层序/排序](创新：同一组残片既提供形状信息又提供层序信息) → [旋转/拼接/逐象限旋转排布](创新：层序rank决定象限颜色分配)

**来源原语**：对齐合并取并集/各副本互补缺失(f8cc533f) + 遮挡层序/重叠定先后(68bc2e87) + 旋转/逐象限旋转排布(7953d61e) + 重涂色(2a5f8217)

**依赖链**：残片的像素并集还原完整模板形状 → 残片重叠处的可见颜色推断层叠顺序 → 层叠顺序rank与象限位置绑定，决定每个象限使用哪种颜色渲染完整模板 → 模板按象限位置做对应旋转后放置。删除并集合并则模板不完整，删除遮挡分析则颜色分配不确定，删除旋转则输出布局错误。

将多个互有缺失的同形残片合并为完整模板，同时从残片重叠处推断层叠顺序，然后按顺序rank将完整模板着色旋转放入四象限。

**输入结构**：黑(0)背景网格，约 14x14。网格中有恰好 4 个 4-连通的单色前景对象，分别使用 4 种不同颜色（从蓝(1)、红(2)、绿(3)、黄(4)、灰(5)、品红(6)中选取）。这 4 个对象是同一个图案模板的偏移副本——每个副本保留了模板的一部分像素，缺失了另一部分，但 4 个副本的像素掩码取并集恰好覆盖完整模板的所有像素位置。各副本在空间上有一定偏移，使得部分副本之间存在像素重叠（重叠处仅显示最上层的颜色）。完整模板可放入一个 NxN 的边界框中（N 约 3~5）。生成约束：4 个副本的重叠关系构成完整的线性层叠顺序（不存在循环遮挡），且至少有 3 对副本之间存在重叠证据。

**规则**：
1. 对每种颜色，将该颜色的所有可见像素裁剪到其边界框内，得到该颜色的部分掩码。
2. 将 4 个部分掩码对齐到左上角（每个掩码的边界框左上角对齐到原点），补零到最大观测高度和宽度，然后取 OR 并集，得到完整模板掩码。
3. 在输入网格中，找到多个还原后的副本掩码在空间上重叠的格子。在这些格子上，实际可见的颜色是最上层副本的颜色。通过所有重叠证据推断 4 种颜色的从底到顶的唯一线性层叠顺序，记底层为 rank=1，顶层为 rank=4。
4. 构造 2N x 2N 的输出网格（黑色背景），将完整模板放入四个象限：
   - 左上象限：使用 rank=1（底层）颜色，模板保持原始朝向。
   - 右上象限：使用 rank=2 颜色，模板逆时针旋转 90 度。
   - 左下象限：使用 rank=3 颜色，模板旋转 180 度。
   - 右下象限：使用 rank=4（顶层）颜色，模板逆时针旋转 270 度。
5. 每个象限内，模板的像素涂为对应颜色，非模板位置保持黑(0)。

**关键洞察**：同一组残片同时编码了两种信息——像素并集揭示完整形状，像素重叠揭示层叠顺序——两者缺一不可，且都不能从单独一个残片中获得。

## 新题 3：障碍分区洪填与面积阈值条件重涂

**组合逻辑**：[填充/洪水填充](创新：从种子点出发沿正交方向扩展) + [碰撞停止](已有，障碍边界拦截) + [计数/面积超阈值则变色](创新：填充面积而非连通体原始面积决定是否重涂) → [重涂色 + 编码映射](创新：图例映射在阈值通过后才生效)

**来源原语**：填充(94414823) + 障碍段/碰撞停止(fc10701f/a48eeaf7) + 计数/面积超阈值则变色(ae58858e) + 颜色图例/编码映射(edb79dae)

**依赖链**：障碍段将网格分割为若干封闭区域 → 种子像素在各自区域内洪水填充确定区域范围 → 填充面积计数判断是否超过阈值 → 超过阈值的区域按图例映射重涂，未超过的区域被擦除。删除障碍分析则不知区域边界，删除洪填则不知面积，删除阈值判断则不知哪些区域存活，删除图例则不知输出颜色。

障碍线将网格分成若干房间，种子像素洪水填充确定房间范围，面积达到阈值的房间按颜色图例重涂，面积不足的房间被清除。

**输入结构**：黑(0)背景网格，约 15x18。灰(5)单像素厚的障碍线段组成不规则的分隔结构，将网格分割为若干互不连通的封闭区域（每个区域内的黑色格子通过正交路径互相可达，但无法穿越灰色障碍或网格边界）。其中 3~5 个区域各包含恰好一个"种子像素"，种子像素的颜色各不相同（从红(2)、蓝(1)、绿(3)、品红(6)中选取）。网格右下角有一个 2~3 行的小色块阵列作为颜色图例：每行左侧一个种子颜色的像素，右侧一个对应输出颜色的像素（如红(2)→橙(7)，蓝(1)→黄(4)等）。图例区域被灰色障碍与主网格分隔。生成约束：每个含种子的区域面积（黑色格子数+种子格子本身=总面积）在 3~15 之间；不同区域的面积不全相同；面积阈值（在不同示例中可推断）为 6。

**规则**：
1. 从每个种子像素出发，沿正交方向（上下左右）对黑(0)格子进行洪水填充，遇到灰(5)障碍像素或网格边界时停止。每个种子声明其可达的所有黑色格子。
2. 计算每个种子区域的总面积（包含种子像素自身 + 所有被该种子填充的黑色格子数）。
3. 面积 >= 6 的区域：将该区域所有格子（种子 + 填充的黑色格子）涂为图例中该种子颜色对应的输出颜色。
4. 面积 < 6 的区域：将种子像素擦除为黑(0)，该区域所有格子保持黑色。
5. 所有灰(5)障碍像素保持不变。
6. 不含种子像素的封闭区域保持黑色不变。
7. 图例区域本身保持原样不被修改。

**关键洞察**：障碍线承担双重角色——既定义了洪水填充的空间边界，又隐式决定了每个房间的面积，而面积直接控制了该房间是否能按图例完成重涂。面积阈值不由输入显式给出，需要对比多个示例（有的区域被重涂、有的被擦除）才能推断出来。

## 新题 4：对称修复驱动的邻近矩形内部填色

**组合逻辑**：[对称补全/同轨道色填补损坏](已有) → [内部与边框/仅内部像素变色](创新：修复后的图案像素颜色作为填充指令) + [填充](创新：填充颜色由空间邻近的修复像素决定)

**来源原语**：对称补全/对称轨道/同轨道色填补损坏(3631a71a) + 内部与边框/仅内部像素变色(bb43febb) + 填充(94414823) + 标记像素(928ad970)

**依赖链**：中心对称图案中的损坏像素必须先通过对称轨道修复 → 修复后图案边缘上距离各矩形最近的像素颜色成为该矩形的填充指令 → 矩形的内部（边框以内的格子）被填充为该颜色。若跳过修复，朝向某些矩形的图案边缘可能正好是损坏像素，导致填色指令错误。

修复中心对称图案中的损坏像素，然后根据修复后图案边缘像素的颜色来决定周围各矩形的内部填充颜色。

**输入结构**：黑(0)背景网格，约 15x15。网格中心有一个正方形区域（约 5x5），内含由红(2)和蓝(1)像素组成的图案，该图案具有 180 度旋转对称性。其中若干像素被绿(3)替换（损坏标记），损坏后的图案在绿色位置失去对称性。绿色不出现在网格的其他任何位置。围绕中心图案的四个基本方向（正上方、正下方、正左方、正右方），各放置一个实心灰(5)矩形，每个矩形高宽均 >= 3。各矩形与中心图案之间至少间隔 1 列/行的黑色空隙。生成约束：每个矩形方向上的中心图案边缘（即图案边界框上靠近该矩形的那一侧边缘）上至少有一个非绿像素，以确保修复后的颜色可从对称轨道唯一确定。损坏位置的安排使得至少有一个矩形方向上，图案边缘最近像素恰好是被损坏的绿(3)像素，从而不修复就会产生错误结果。

**规则**：
1. 识别中心图案的旋转中心（图案边界框的几何中心）。图案具有 180 度旋转对称性。
2. 对中心图案中每个绿(3)像素，找到其关于旋转中心的 180 度旋转对称伙伴位置。如果伙伴位置是红(2)或蓝(1)，则将该绿色像素替换为伙伴的颜色。如果伙伴也是绿(3)，则在图案的完整对称群中寻找其他轨道成员（若图案同时具有水平和垂直镜像对称，则使用镜像伙伴；否则仅靠 180 度旋转足以修复所有损坏，因为生成约束保证同一轨道内至少一个成员未被损坏）。
3. 修复完成后，对四个矩形分别执行：找到中心图案边界框上距离该矩形最近的那一侧边缘（上方矩形对应图案的顶边，下方对应底边，左方对应左边，右方对应右边）。在该边缘上，取与矩形中心列（或中心行）最对齐的一个像素；若矩形中心恰好对齐两个像素之间，取更靠左上方的那个。该像素的颜色即为该矩形的填充色。
4. 对每个灰(5)矩形，将其一像素厚的灰色边框保留，将边框严格内部的所有灰色格子重涂为步骤 3 确定的颜色。
5. 中心图案（已修复）、灰色边框和黑色背景保持不变。

**关键洞察**：损坏像素可能恰好位于图案面向某个矩形的边缘，若不经对称修复直接读取，会将绿色（损坏标记）误认为填充指令。修复步骤不是独立的预处理，而是内部填色正确性的必要前提。

## 新题 5：长宽比分类驱动的双轨调色板内部填色

**组合逻辑**：[分类/朝向分组](创新：以长宽比替代图形朝向作为分类依据) → [计数/计数映射槽位](创新：类内排序索引替代全局计数) + [内部与边框/仅内部像素变色](已有) + [编码映射](创新：分类结果同时决定调色板和排序轴)

**来源原语**：分类/朝向分组(d5c634a2) + 计数/计数映射槽位(d5c634a2) + 内部与边框/仅内部像素变色(bb43febb) + 编码映射(edb79dae) + 面板(d5c634a2)

**依赖链**：矩形长宽比分类（"高"vs"宽"）→ 分类结果同时选择调色板（颜色序列）和类内排序轴（空间方向）→ 按排序轴对类内矩形排序获得索引 → 索引对应调色板中的颜色 → 该颜色填入矩形内部。删除分类则不知使用哪个调色板和哪个排序轴，删除排序则无法确定颜色索引，删除内部识别则不知修改哪些像素。

将矩形按长宽比分为"高型"和"宽型"两类，每类有专属调色板和排序方向，按类内位置顺序从调色板取色填充各矩形内部。

**输入结构**：黑(0)背景网格，约 16x20。网格中有 5~7 个实心灰(5)矩形，互不接触（任意两个矩形之间至少隔 1 格黑色）。每个矩形高宽均 >= 3，且高 != 宽（不存在正方形）。其中一部分矩形高 > 宽（"高型"），另一部分宽 > 高（"宽型"），每类至少 2 个。网格的最底行（或最右列）有两个小的调色板条：
- "高型调色板"：一行连续色块，从左到右排列，颜色各不相同（如红(2)、绿(3)、蓝(1)），色块数量恰等于高型矩形的数量。调色板条的左侧有一个纵向排列的双像素标记（两个上下相邻的品红(6)像素），表示"高型"。
- "宽型调色板"：一行连续色块，从左到右排列，颜色各不相同（如黄(4)、橙(7)、栗(9)），色块数量恰等于宽型矩形的数量。调色板条的左侧有一个横向排列的双像素标记（两个左右相邻的品红(6)像素），表示"宽型"。
两个调色板条之间用黑色分隔，且都位于网格底部，不与任何灰色矩形重叠。生成约束：高型矩形数量等于高型调色板长度，宽型矩形数量等于宽型调色板长度。

**规则**：
1. 对每个灰(5)矩形，计算其高（行数）和宽（列数）。高 > 宽者归为"高型"，宽 > 高者归为"宽型"。
2. 识别两个调色板：品红(6)标记为纵向双像素（上下相邻）的调色板是高型调色板，品红(6)标记为横向双像素（左右相邻）的调色板是宽型调色板。
3. 高型矩形按其边界框左上角的列坐标从小到大排序（列坐标相同时按行坐标从小到大），得到顺序索引 k=1,2,3,...。第 k 个高型矩形的填充色为高型调色板从左到右的第 k 个颜色。
4. 宽型矩形按其边界框左上角的行坐标从小到大排序（行坐标相同时按列坐标从小到大），得到顺序索引 k=1,2,3,...。第 k 个宽型矩形的填充色为宽型调色板从左到右的第 k 个颜色。
5. 对每个矩形，保留其一像素厚的灰(5)边框不变，将边框严格内部的所有灰色格子重涂为步骤 3 或步骤 4 确定的颜色。
6. 调色板区域、品红标记、黑色背景均保持不变。

**关键洞察**：矩形的长宽比属性同时编码了两个独立决策——选择哪个调色板（颜色来源），以及按哪个空间轴排序（列优先=高型 vs 行优先=宽型）。这一双重编码在任何单一源题中都不存在，需要对比多个示例中不同长宽比矩形的处理差异才能推断。

## 新题 6：网格线轨道上的间隙捕获滑行标记

**组合逻辑**：[补全/相邻像素标有效线](已有，识别有效网格线) → [滑动/碰撞停止](创新：沿网格线轨道而非射线滑行) + [间隙填充/缺口补另色](创新：间隙不是统一补色，而是被滑至此处的标记颜色所填充)

**来源原语**：网格线/缺口/相邻像素标有效线(4612dd53) + 滑动/碰撞停止(a48eeaf7) + 间隙填充/缺口补另色(4612dd53) + 标记像素(a48eeaf7/928ad970)

**依赖链**：识别有效网格线和线上间隙位置 → 网格线成为标记可滑行的轨道 → 标记沿轨道向网格中心方向滑行 → 标记在间隙位置停止 → 间隙被停止于此的标记颜色填充。删除网格线识别则无法确定轨道和间隙，删除滑行则标记无法移动，删除间隙捕获则无法确定输出颜色。

识别不完整网格线并将其作为滑行轨道，标记像素沿轨道向内滑行，在间隙处被捕获并以自身颜色填充该间隙。

**输入结构**：黑(0)背景网格，约 14x14。蓝(1)像素组成一个不完整的正交网格——若干水平线和若干垂直线，但部分线段有间隙（线上某些格子为黑色）。有效水平线的判断标准：该行内存在至少一对水平相邻的蓝色像素。有效垂直线类似：该列内存在至少一对垂直相邻的蓝色像素。前景边界框是所有蓝色像素的最小包围矩形。间隙定义为：在前景边界框内，位于有效网格线上但当前为黑(0)的格子。网格边缘（前景边界框的四条边附近）放置若干标记像素，每个标记使用不同于蓝的非黑颜色（红(2)、绿(3)、黄(4)、橙(7)等），每个标记恰好位于某条有效网格线上（即与某条有效行或有效列对齐）。生成约束：每条含间隙的有效网格线上恰好有一个标记像素位于该线的某一端（在前景边界框的边缘或外侧），且该标记与该线上最近的间隙之间的路径上无其他间隙（一个标记只捕获一个间隙）。标记数量等于间隙数量。

**规则**：
1. 识别所有有效水平线（行内含至少一对水平相邻蓝色像素的行）和所有有效垂直线（列内含至少一对垂直相邻蓝色像素的列）。
2. 在前景边界框范围内，标记所有间隙位置：有效线上当前为黑(0)的格子。
3. 对每个标记像素，确定其所在的有效网格线（行或列）。标记沿该线朝前景边界框中心方向逐格滑行。
4. 滑行过程中，标记跳过蓝(1)格子（蓝色格子是轨道的"铺好的路面"）。当标记到达一个间隙位置（有效线上的黑色格子）时，标记停止。
5. 将该间隙位置的颜色涂为停止于此的标记颜色，标记像素从其原始位置擦除（设为黑(0)）。
6. 所有原始蓝(1)像素保持不变。未被任何标记到达的间隙（若存在）保持黑色。

**关键洞察**：网格线结构同时充当两种角色——其完整的线段是标记滑行的轨道，其中的间隙是捕获标记的陷阱。这种"轨道即带缺口的容器"关系在两个源题中都不存在：源题 4612dd53 的间隙被统一颜色填充而非由移动体填充，源题 a48eeaf7 的滑行轨道是无障碍射线而非有间隙的离散网格线。

## 新题 7：平移产生新重叠与面积优先遮挡解析

**组合逻辑**：[平移/固定步长平移](创新：多个不同颜色对象各自平移而非全体同方向) + [遮挡层序](创新：遮挡优先级不来自输入中的堆叠，而来自对象面积比较) + [背景替换](已有) + [计数](创新：面积计数用于遮挡裁决而非阈值判断)

**来源原语**：平移/固定步长平移(32e9702f) + 遮挡层序/重叠定先后(68bc2e87) + 背景替换(32e9702f) + 计数(ae58858e/d5c634a2)

**依赖链**：所有前景对象按统一方向平移 → 平移后原本不重叠的对象可能产生新的空间冲突 → 面积计数确定每个对象的优先级 → 冲突格子上面积更大的对象可见。删除平移则无重叠产生，删除面积计数则冲突无法解决，删除背景替换则背景不正确。

将所有前景对象按统一方向平移，用灰色替换旧背景，对平移后产生的新重叠区域按对象面积从大到小决定可见颜色。

**输入结构**：黑(0)背景网格，约 14x16。网格中有 4~6 个 4-连通前景对象，每个对象使用不同的非黑颜色（从蓝(1)、红(2)、绿(3)、黄(4)、橙(7)、栗(9)中选取），每个对象包含 3~10 个像素，形状为不规则的 4-连通区域（非矩形）。在输入中，所有对象互不接触（任意两个对象之间至少间隔 1 格黑色），不存在任何重叠。网格左下角有一个方向指示符：一个品红(6)的 1x3 水平箭头形状（三个品红像素从左到右排列，最右侧像素的上方和下方各有一个品红像素构成箭头头部），表示平移方向为"向右 2 格"。生成约束：所有对象的面积（像素数）互不相同。平移 2 格后，至少有两对对象产生空间重叠，且无对象完全移出网格右边界。

**规则**：
1. 识别方向指示符：品红(6)箭头形状指示平移方向和步长。箭头朝右表示所有前景对象向右平移，步长为箭头主干长度（此处为 3 个像素对应 2 格位移，即主干像素数 - 1 = 步长）。
2. 创建与输入同尺寸的输出网格，全部填充灰(5)。
3. 计算每个前景对象的面积（像素数量）。
4. 将每个前景对象的所有像素坐标向右平移 2 列。超出网格右边界的像素被裁剪丢弃。
5. 在输出网格上绘制平移后的对象。按面积从小到大的顺序依次绘制（面积小的先画，面积大的后画覆盖），这样面积大的对象在冲突区域总是可见（后绘制覆盖先绘制）。
6. 方向指示符（品红箭头）不参与平移，在输出中被灰色背景覆盖（即不保留）。

**关键洞察**：输入中所有对象互不重叠，遮挡问题只在平移后才涌现——这意味着求解者无法从输入直接观察到遮挡关系，必须先执行平移再解决冲突。面积优先规则（非颜色编号、非位置）需要对比多个示例中不同面积对象在冲突区域的表现才能归纳。

## 新题 8：标记位置编码选择周期瓦片填充框架内部

**组合逻辑**：[极值内缩定边框/描边](已有，识别框架) + [标记像素/方位决定象限分配](创新：标记的粗略方位编码为候选瓦片的选择索引) → [平铺/周期重复](创新：所选瓦片周期性铺满框架内部) + [内部与边框](已有，仅填充内部)

**来源原语**：框架/内部与边框(bb43febb/edb79dae) + 标记像素/方位决定象限分配(94414823) + 平铺/周期重复(135a2760) + 编码映射(edb79dae)

**依赖链**：识别框架和框架内部区域 → 标记像素的粗略空间方位编码为二进制选择信号 → 选择信号索引到候选瓦片集合中的某一个 → 所选瓦片周期性铺满框架内部。删除框架识别则不知填充区域，删除标记方位解读则无法选择瓦片，删除周期铺设则内部为空。

框架外的标记像素通过其相对于框架中心的方位编码一个选择索引，从候选瓦片中选出一个，用于周期性铺满框架内部。

**输入结构**：黑(0)背景网格，约 18x18。一个灰(5)单像素厚的矩形框架，框架内部为黑色空区域（内部高宽均 >= 6）。框架外部散布着 3~4 个小瓦片图案，每个瓦片是一个 2x2 或 2x3 或 3x2 的紧凑色块区域，使用各自不同的颜色组合（如一个瓦片由红(2)和蓝(1)组成，另一个由绿(3)和黄(4)组成，等等）。瓦片图案互不接触，且不与框架接触。瓦片图案在框架外按特定空间布局排列：相对于框架中心，它们大致分布在不同的方位区域（左上区、右上区、左下区、右下区）。恰好两个栗(9)标记像素放置在框架外部（不在任何瓦片图案内），一个位于框架中心的左侧或右侧，另一个位于框架中心的上方或下方。生成约束：候选瓦片数量恰为 4，且能被框架内部的尺寸整除地铺满（或至少能周期重复覆盖内部，边缘处允许截断）。

**规则**：
1. 识别灰(5)矩形框架及其内部区域（框架边框内侧的所有黑色格子）。
2. 计算框架的几何中心（框架边界框的中心坐标，行和列取平均值）。
3. 识别两个栗(9)标记像素的位置。对每个标记，判断其相对于框架中心的粗略方位：
   - 标记 A：若其列坐标 < 框架中心列，则水平分量 = 0（左）；否则水平分量 = 1（右）。
   - 标记 B：若其行坐标 < 框架中心行，则垂直分量 = 0（上）；否则垂直分量 = 1（下）。
   - 两个标记合成一个二维索引 (垂直分量, 水平分量)，取值为 (0,0)、(0,1)、(1,0)、(1,1) 之一。
4. 识别框架外的 4 个候选瓦片图案，按其中心位置相对于框架中心的方位排列：左上方位=(0,0)，右上方位=(0,1)，左下方位=(1,0)，右下方位=(1,1)。
5. 选择方位索引与步骤 3 计算的 (垂直, 水平) 索引匹配的那个候选瓦片。
6. 将所选瓦片周期性地铺满框架内部：以框架内部区域的左上角为起始对齐点，将瓦片沿行和列方向重复平铺。若内部尺寸不是瓦片尺寸的整数倍，在右边缘和下边缘截断多余部分。
7. 灰色框架边框保持不变。框架外的所有内容（瓦片图案、标记像素、黑色背景）保持不变。

**关键洞察**：两个标记像素各自只编码一个比特的信息（左/右 或 上/下），联合起来才能编码一个 2-bit 索引来从四个候选瓦片中选择一个。标记的精确位置无关紧要，只有其相对于框架中心的粗略方位有意义——这一编码机制需要对比多个示例（不同标记方位选择不同瓦片）才能归纳。

## 新题 9：缩放锚点决定框架尺寸与遮挡序决定内部分区涂色

**组合逻辑**：[缩放/尺寸比编码缩放](创新：锚点尺寸比决定绘制框架的大小而非缩放已有图案) + [描边/draw_frame](已有) → [遮挡层序/重叠定先后](创新：绘制出的框架之间的重叠产生新的遮挡关系) + [分区涂色/按边界框内外分色](创新：遮挡序决定各框架内部的分区着色方案)

**来源原语**：缩放/尺寸比编码缩放(b10624e5) + 描边/draw_frame/极值内缩定边框(928ad970) + 遮挡层序(68bc2e87) + 分区涂色/按边界框内外分色(137f0df0) + 内部与边框(bb43febb)

**依赖链**：锚点方块的尺寸比 → 决定各框架的绘制大小 → 框架绘制后产生重叠 → 重叠处的可见规则产生遮挡序 → 遮挡序决定每个框架内部用什么颜色填充。删除缩放计算则框架大小不确定，删除框架绘制则无遮挡可分析，删除遮挡序则内部颜色不确定。

根据锚点方块的尺寸比绘制不同大小的同心空心矩形框，再由框架之间的重叠遮挡顺序决定各框架内部的填充颜色。

**输入结构**：黑(0)背景网格，约 18x18。网格中散布 3~4 个实心正方形锚点方块，每个方块使用不同颜色（如红(2)、蓝(1)、绿(3)、黄(4)），边长各不相同（如 1x1、2x2、3x3）。所有锚点方块的几何中心大致位于网格中心附近（距离网格中心不超过 3 格），但互不接触。网格边缘有一个参考方块：一个橙(7)的 1x1 像素，旁边一个灰(5)的空心矩形框（4x4，即外边长为 4 的一像素厚矩形环），表示"1x1 锚点对应 4x4 框架"。生成约束：按尺寸比计算出的各框架都能放入网格内（以各自锚点的中心为框架中心）。各框架至少两两之间存在空间重叠。

**规则**：
1. 识别参考方块（橙(7)）和参考框架（灰(5)空心矩形）。参考方块边长 = 1，参考框架外边长 = 4。基础缩放比 = 4/1 = 4。
2. 对每个彩色锚点方块，计算其框架的外边长 = 锚点边长 x 基础缩放比。以该锚点的几何中心为框架中心，绘制一个该边长的一像素厚空心矩形框，颜色与锚点相同。
3. 绘制顺序按锚点边长从大到小（边长大的先绘制，即框架大的先绘制，作为底层）。后绘制的框架线覆盖先绘制的。
4. 绘制完成后，从框架线的重叠处确认遮挡层序：边长小的锚点对应的框架在上层（后绘制的覆盖先绘制的），即锚点越小，框架层级越高。
5. 对每个框架的内部区域（框架线围成的空间，不含框架线本身）：
   - 如果该框架是最顶层（rank最高）：内部保持黑(0)不变。
   - 如果该框架不是最顶层：内部填充为紧邻其上一层框架的颜色。
6. 内部填充时，已有的框架线像素和锚点方块像素不被覆盖。填充仅涂在当前为黑(0)的内部格子上。
7. 参考方块和参考框架区域保持不变。

**关键洞察**：锚点尺寸比不仅决定了框架大小（大锚点=大框架=底层），还隐式决定了遮挡顺序（小框架覆盖大框架），而遮挡顺序又反向决定了每个框架内部的填充颜色（填充色来自其上层邻居）。尺寸、遮挡、着色三者构成链式因果，在任何单一源题中都不存在。

## 新题 10：形状匹配驱动的镜像方向与间隙填充色选择

**组合逻辑**：[形状匹配/归一化形状匹配](创新：匹配结果不是用于重涂，而是用于选择镜像轴) + [镜像/reflect](创新：镜像轴由匹配关系决定而非由象限位置决定) + [间隙填充/缺口补另色](创新：间隙填充色由镜像后的图案像素决定)

**来源原语**：形状匹配/归一化形状匹配(2a5f8217) + 镜像(b10624e5) + 间隙填充(4612dd53) + 网格线/缺口(4612dd53) + 模板对象/占位符对象(2a5f8217)

**依赖链**：占位符与模板的形状匹配 → 匹配到的模板的空间方位决定镜像轴 → 镜像变换应用于占位符所在区域的图案 → 镜像后图案中的缺口格子被填充为镜像源像素的颜色。删除形状匹配则不知哪个模板对应哪个占位符，删除镜像轴推断则无法执行正确的镜像，删除间隙填充则输出不完整。

通过形状匹配找到每个占位符的配对模板，模板相对于占位符的方位决定镜像轴，对占位符区域执行镜像后填补不完整的网格线缺口。

**输入结构**：黑(0)背景网格，约 16x16。网格被蓝(1)的不完整网格线分成若干矩形区域（如同 4612dd53 的网格结构，水平和垂直蓝色线段有部分间隙）。其中 2~3 个区域内包含一个小的单色 4-连通图案作为"占位符"（蓝色以外的颜色，如灰(5)），以及在网格外侧（超出蓝色网格线范围的区域）有对应数量的单色"模板"图案（使用与占位符不同的颜色，如红(2)、绿(3)等，每个模板颜色不同）。每个模板的归一化边界框掩码与某个占位符的归一化边界框掩码相同（形状匹配）。每个模板位于其匹配占位符的正左方、正右方、正上方或正下方（模板中心与占位符中心在同一行或同一列）。生成约束：每个占位符恰好匹配一个模板，匹配关系是一一对应。每个占位符所在区域的蓝色网格线边界上恰好有一处间隙。

**规则**：
1. 识别蓝(1)网格线及其间隙位置（有效水平线/垂直线上缺失的蓝色像素）。
2. 识别所有占位符图案（网格线围成的区域内的非蓝非黑 4-连通对象）和所有模板图案（网格外侧的非蓝非黑 4-连通对象）。
3. 通过归一化边界框掩码匹配，将每个占位符与唯一的模板配对。
4. 对每个配对，确定模板相对于占位符的方位：
   - 模板在占位符正左方或正右方 → 该占位符区域的镜像轴为垂直轴（左右镜像）。
   - 模板在占位符正上方或正下方 → 该占位符区域的镜像轴为水平轴（上下镜像）。
5. 以占位符所在矩形区域的中心线为镜像轴，对该区域内的所有非黑像素（包括占位符图案像素）执行镜像。镜像后的像素涂在区域内当前为黑(0)的格子上，不覆盖已有的非黑像素。
6. 镜像操作完成后，检查所有蓝色网格线的间隙位置。对每个间隙格子：如果该间隙格子所在的网格线行或列上，其左右（或上下）最近的两个蓝色像素之间恰好只有该一个间隙，则用模板的颜色（与该间隙相邻区域中占位符所匹配的模板颜色）填充该间隙。
7. 所有原始蓝色网格线像素保持不变。网格外侧的模板图案保持不变。

**关键洞察**：形状匹配的结果不直接用于重涂色（如源题 2a5f8217），而是其副产品——模板的空间方位——充当了镜像轴选择的编码信号。匹配"是什么形状"回答的不是"涂什么颜色"，而是"沿哪个方向镜像"。
