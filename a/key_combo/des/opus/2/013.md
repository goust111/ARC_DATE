## 新题 1：重叠空心矩形的深度扫描填充

**组合逻辑**：[逐行扫描/row_scan](创新：从单一对角线轮廓改为多重叠矩形轮廓) + [填充轮廓间区域/fill_between_outlines](创新：填充色由嵌套深度决定而非固定色) + [计数/counting](创新：计数的是重叠层数而非像素数) + [排序/sorting → 重涂色/recolor](创新：按面积排序确定遮挡优先级而非输出序列)

**来源原语**：逐行扫描(aa18de87)、填充轮廓间区域(aa18de87)、空心矩形(41e4d17e)、计数(f8ff0b80)、排序(f8ff0b80/eb5a1d5d)、面积排序(f8ff0b80)、重涂色(多源)

**依赖链**：逐行扫描识别出每行上的轮廓像素及其所属矩形；填充操作需要知道每个跨度位于几层矩形内部（计数）；计数结果决定填充使用哪个深度颜色；深度颜色的分配依赖于矩形面积排序（面积最小 = 最深层 = 最高优先级）。删除扫描则无法识别跨度边界，删除计数则无法区分深度，删除排序则无法分配深度颜色。

将多个部分重叠的彩色空心矩形，按重叠深度逐行扫描填充为深度热力图，面积最小的矩形层级最高。

**输入结构**：黑(0)背景上约 18x18 的网格。3~5 个不同颜色的空心矩形（每个由单色 4-连通像素围成，壁厚 1 像素，宽高各 4~10），颜色取自蓝(1)、红(2)、绿(3)、黄(4)、灰(5)。矩形之间有部分重叠（边界框交集非空），但没有完全包含关系（即没有一个矩形的边界框完全在另一个内部）。每个矩形的轮廓像素保持各自颜色不变。重叠处轮廓像素按面积小者优先显示。网格中还散布 2~3 个品红(6)像素作为干扰项，不参与任何规则。

**规则**：
1. 识别所有空心矩形对象，计算每个矩形的边界框面积（宽 x 高），按面积从大到小排序，赋予深度编号：面积最大的矩形深度为 1，次大为 2，依次递增。
2. 对输出网格的每一行，从左到右扫描。维护一个"当前所在矩形集合"：遇到某矩形的左侧边轮廓像素时将该矩形加入集合，遇到右侧边轮廓像素时将该矩形移出集合。
3. 对于扫描过程中集合非空的每个非轮廓背景像素，该像素的深度等于集合中所有矩形的最大深度编号。根据深度编号重涂色：深度 1 涂蓝(1)，深度 2 涂红(2)，深度 3 涂绿(3)，深度 4 涂黄(4)，深度 5 涂灰(5)。
4. 轮廓像素保持原色不变。重叠处两个矩形的轮廓像素在同一位置时，面积更小的矩形的颜色覆盖面积更大的。
5. 品红(6)干扰像素在输出中保持不变。
6. 不属于任何矩形内部且非轮廓、非干扰的像素保持黑(0)。

**关键洞察**：每个像素的填充色不是由它属于哪个矩形决定，而是由它同时被几个矩形覆盖决定——深度是重叠层数的函数，必须对比多个示例才能归纳出面积-深度映射规则和重叠计数逻辑。

## 新题 2：阶梯边界门控的列向射线填充

**组合逻辑**：[阶梯图案/staircase_pattern](创新：从装饰性输出变为功能性遮挡边界) + [列遮挡/column_coverage → 射线延伸/ray_cast](创新：射线的起点由阶梯下沿决定而非由固定对象下沿决定) + [计数/counting → 重涂色/recolor](创新：阶梯在该列的高度决定填充颜色)

**来源原语**：阶梯图案(d06dbe63)、步长固定(d06dbe63)、射线延伸/ray_cast(6d58a25d/aba27056)、列遮挡(6d58a25d)、遮挡列延伸至边(6d58a25d)、计数(f8ff0b80)、重涂色(多源)、标记像素(56ff96f3/6d58a25d)

**依赖链**：阶梯图案定义了每列的遮挡边界高度；标记像素的列位置决定哪些列被激活；只有阶梯覆盖的列才启动向下填充（列遮挡判断）；填充的起点是阶梯在该列的最低像素（射线起点依赖阶梯形状）；填充的颜色取决于阶梯在该列占据的行数（计数→颜色映射）。阶梯形状、列激活、填充起点、填充颜色四者互相耦合。

从阶梯图案的下沿向下发射填充射线，仅在有标记像素的列激活，射线颜色由阶梯在该列的高度决定。

**输入结构**：黑(0)背景上约 15x20 的网格。一个灰(5)阶梯图案从左上方向右下方延伸，步长为 2（每步水平 2 像素、垂直 2 像素），总共 4~6 级台阶，整体位于网格上半部。阶梯下方散布 3~5 个橙(7)标记像素，每个占 1 格，分布在不同列。部分标记像素的列被阶梯覆盖（该列存在灰像素），部分不被覆盖。生成时保证每个标记像素所在列至多有一个标记像素。

**规则**：
1. 识别灰(5)阶梯图案，对每一列计算该列中灰像素的数量（即阶梯在该列的"高度"h）。
2. 找到所有橙(7)标记像素。对每个标记像素，检查其所在列是否存在灰像素（列遮挡判断）。若不存在，该标记像素不触发任何操作。
3. 对于被阶梯覆盖的列中的每个标记像素：找到该列中灰像素的最大行号 r_bottom（阶梯最低点）。从 r_bottom + 1 开始向下填充直到网格底部（含底部行）。
4. 填充颜色由该列的阶梯高度 h 决定：h = 1 涂蓝(1)，h = 2 涂红(2)，h = 3 涂绿(3)，h = 4 涂黄(4)，h >= 5 涂品红(6)。
5. 填充过程中若遇到橙(7)标记像素，将其覆盖为填充色。
6. 阶梯本身和未被激活列中的标记像素保持原色。

**关键洞察**：阶梯不只是视觉形状，它同时编码了三重信息——哪些列可以填充（遮挡判断）、填充从哪里开始（最低行）、填充用什么颜色（列高度）。必须对比多个示例才能归纳出高度-颜色的映射表。

## 新题 3：碎片像素数配对与层叠矩形合成

**组合逻辑**：[计数/counting + 互补拼合/complement_fit](创新：配对标准从"同色"改为"像素数之和相等") + [移动/move + 擦除/erase](沿用但作用于多对碎片) + [面积排序/area_ordering → 原对象遮挡叠加/object_occludes_overlay](创新：合成矩形之间按面积排列遮挡层序)

**来源原语**：碎片(fe45cba4)、互补拼合(fe45cba4)、移动(fe45cba4)、擦除(fe45cba4)、计数(f8ff0b80)、面积排序(f8ff0b80)、原对象遮挡叠加(41e4d17e)、矩形(56ff96f3)

**依赖链**：首先计数每个碎片的像素数，找到像素数之和相等的碎片对（配对依赖计数）；然后对每对碎片，移动其中触边的一个到锚碎片旁拼合成矩形（移动依赖配对结果）；多个合成矩形可能在空间上重叠，此时按矩形面积从大到小绘制（面积小的后绘制，遮挡面积大的）。配对、移动、遮挡三步紧耦合。

多个不同颜色的碎片按像素数配对拼合成矩形，重叠处面积小的矩形覆盖面积大的。

**输入结构**：黑(0)背景上约 16x16 的网格。存在 3 种非黑前景色，每种颜色恰好有 2 个 4-连通碎片。同色的两个碎片可以平移拼合为一个实心矩形（它们互为矩形的互补区域）。每种颜色的两个碎片中，恰好一个触及网格上边缘，另一个不触及任何边缘（锚碎片）。每种颜色的两个碎片的像素数之和互不相同（如颜色 A 的总和为 12，颜色 B 的为 15，颜色 C 的为 20）。各锚碎片之间距离足够，但合成矩形的边界框可能部分重叠。颜色取自蓝(1)、红(2)、绿(3)。

**规则**：
1. 对每种前景色，找到其两个 4-连通碎片。将触及上边缘的碎片标记为"移动碎片"，不触边的标记为"锚碎片"。
2. 对每种颜色，计算移动碎片与锚碎片拼合后形成的矩形的唯一平移偏移量（使两碎片的并集恰好填满一个轴对齐实心矩形）。将移动碎片平移到该位置，擦除其原始位置的像素。
3. 计算每个合成矩形的面积（宽 x 高）。按面积从大到小的顺序依次绘制矩形：先绘制面积最大的，再绘制次大的，最后绘制最小的。后绘制的覆盖先绘制的。
4. 若两个矩形面积相同（生成时保证不会出现），按颜色编号小者先绘制。
5. 非前景色区域保持黑(0)。

**关键洞察**：配对标准不是颜色（颜色已经给定），而是几何互补性——同色两碎片必须恰好拼成矩形，需要推断唯一的平移向量。遮挡顺序必须对比多个示例中不同面积矩形的重叠结果才能归纳出面积优先规则。

## 新题 4：迷宫走廊的调色带周期填充

**组合逻辑**：[洪泛填充/flood_fill + 路径连通/path_connectivity](沿用走廊填充机制) + [调色带/palette_strip + 逐列对应/column_correspondence](创新：调色带不再逐列着色固定区域，而是定义填充的颜色循环序列) + [路径奇偶交替涂色/alternating_color_by_path_parity](创新：从二色交替扩展为多色周期循环，周期长度由调色带宽度决定)

**来源原语**：迷宫走廊(b782dc8a)、洪泛填充(b782dc8a)、路径连通(b782dc8a)、种子像素(b782dc8a)、路径奇偶交替涂色(b782dc8a)、调色带(278e5215)、逐列对应(278e5215)

**依赖链**：调色带的宽度定义颜色循环的周期长度，调色带中从左到右的颜色序列定义循环顺序（调色带→周期）；洪泛填充从种子像素出发沿走廊扩展，每个走廊像素的路径距离（BFS 层数）对周期取模后索引调色带颜色（填充→距离→调色带查询）。删除调色带则不知道用哪些颜色和周期，删除洪泛填充则没有距离信息。

从种子像素出发沿迷宫走廊洪泛填充，颜色按调色带定义的序列周期循环。

**输入结构**：黑(0)背景上约 15x15 的网格。青(8)像素构成迷宫墙壁（单像素宽，4-连通），围出若干黑(0)走廊通道。网格最底行是一个 1 行 N 列的调色带（N 为 3 或 4），由不同颜色的像素组成（如红(2)、绿(3)、黄(4)），调色带与迷宫之间有一行青(8)墙壁分隔。迷宫走廊中有 1 个栗(9)种子像素，位于某个走廊格中。生成时保证迷宫所有走廊从种子像素出发都是连通的（不存在孤立走廊段）。

**规则**：
1. 识别网格最底行的调色带，读取其从左到右的颜色序列 P = [c_0, c_1, ..., c_{k-1}]，其中 k 为调色带宽度。
2. 从栗(9)种子像素出发执行 BFS（广度优先搜索），沿 4-连通方向扩展到所有可达的黑(0)走廊像素。记录每个走廊像素到种子像素的最短路径距离 d（种子自身 d = 0）。
3. 将种子像素涂为 P[0 mod k] = P[0]（即调色带最左色）。对每个距离为 d 的走廊像素，涂为 P[d mod k]。
4. 青(8)迷宫墙壁保持不变。调色带行保持不变。
5. 若多条最短路径到达同一像素，距离 d 唯一确定，颜色无歧义。

**关键洞察**：调色带既编码了可用颜色又编码了循环周期——宽度为 3 的调色带产生三色循环，宽度为 4 的产生四色循环。仅看单个示例可能猜出颜色规律，但必须对比不同调色带宽度的示例才能确认"宽度即周期"。

## 新题 5：对角标记矩形内的精灵印章

**组合逻辑**：[对角配对/diagonal_pairing + 同色对定义矩形/pair_defines_rect](沿用矩形定义机制) + [印章覆盖/stamp_overlay + 自身为模板/self_as_stencil](创新：印章的放置区域被矩形区域裁切约束) + [像素放大/pixel_upscale](创新：放大比例由矩形尺寸与精灵尺寸的比值决定，非精灵自乘)

**来源原语**：对角配对(56ff96f3)、同色对定义矩形(56ff96f3)、矩形(56ff96f3)、精灵体(007bbfb7)、印章覆盖(007bbfb7)、自身为模板(007bbfb7)、像素放大(007bbfb7)、裁剪(278e5215)

**依赖链**：对角标记像素对定义矩形区域（配对→矩形）；精灵体被放大后印章到矩形区域内（矩形尺寸约束放大比例）；精灵以自身为模板——仅在非背景像素对应的块位置粘贴精灵副本（模板→印章位置）；矩形区域外的部分不绘制任何内容（裁切依赖矩形边界）。精灵的放大比例不是固定的，而是由匹配的矩形尺寸反推的。

用对角标记像素定义矩形区域，在每个矩形内按精灵自模板印章填充放大的精灵图案。

**输入结构**：黑(0)背景上约 20x20 的网格。左上角有一个小型精灵体（约 3x3 至 4x4，由灰(5)和黑(0)像素构成，灰像素为非背景，形状不规则但 4-连通）。网格其余区域散布 2~3 对标记像素，每对同色（颜色取自红(2)、绿(3)、蓝(1)），每种颜色恰好 2 个像素，分别标记一个轴对齐矩形的对角顶点。每对标记定义的矩形宽高均为精灵宽高的整数倍（如精灵 3x3，矩形 9x9 或 6x6）。不同颜色的矩形区域互不重叠。精灵体的边界框与所有标记矩形不重叠。

**规则**：
1. 识别左上角的精灵体：找到灰(5)像素的最小边界框，记精灵宽 sw、高 sh。
2. 对每种非灰、非黑的前景色，找到该色的 2 个标记像素，取其包围的轴对齐矩形区域（含边界），记矩形宽 rw、高 rh。计算放大倍数 mx = rw / sw, my = rh / sh（生成时保证为整数且 mx = my = m）。
3. 将精灵放大 m 倍：精灵中每个像素扩展为 m x m 的块。对放大后的精灵，以自身为模板执行印章覆盖——遍历放大后精灵的每个块：若对应原始精灵像素为灰(5)（非背景），则在该块位置粘贴一份原始精灵（未放大的 sw x sh 精灵）；若对应原始像素为黑(0)（背景），则该块保持黑(0)。
4. 将印章结果写入对应标记矩形区域，矩形区域内的标记像素被覆盖。矩形区域外不做任何改变。
5. 精灵本身在左上角区域保持原样。不同矩形的放大倍数可能不同。

**关键洞察**：精灵既是被放大的对象又是放大后的粘贴模板——放大产生块网格，模板决定哪些块粘贴原精灵。放大倍数不是固定参数，而是由标记矩形的尺寸隐式编码的，必须对比不同大小的矩形才能归纳。

## 新题 6：嵌套环内受限十字线与交叉点深度着色

**组合逻辑**：[连线/draw_line + 画布全长十字线/canvas_spanning_cross](创新：十字线不再画布全长，而是被嵌套环边界截断) + [嵌套层次/nesting_hierarchy + 内部包含/interior_containment](创新：嵌套层级不输出为压缩环，而是作为十字线的空间约束) + [行列交叉/row_col_intersection + 交叉点特殊着色/intersection_colored](创新：交叉点颜色由两条线所属的嵌套深度差决定)

**输入结构**：黑(0)背景上约 17x17 的网格。2~3 层灰(5)同心方环（最外层约 15x15，每层向内缩 2 像素，壁厚 1 像素），形成嵌套结构。每层环的内部区域（两层环之间或最内层内部）放置 1 个彩色种子像素（颜色互不相同，取自蓝(1)、红(2)、绿(3)、黄(4)）。种子像素不在环壁上。生成时保证不同层的种子像素不在同一行也不在同一列（但它们的十字线延伸后可能相遇）。

**规则**：
1. 识别灰(5)同心方环，按边界框面积从大到小排序，赋予深度：最外层深度 1，次外层深度 2，依此递增。最内层环内部的深度为最大深度 +1。
2. 每个种子像素的深度等于其所在区域的深度。
3. 从每个种子像素出发，沿上下左右四个方向画该种子颜色的直线。直线在遇到灰(5)环壁像素时停止（不包含环壁像素本身）。即十字线被种子所在的最内层包围环截断。
4. 若两条不同种子的十字线经过同一个像素（交叉点），则该像素涂为特殊颜色：设两种子的深度分别为 d1 和 d2，|d1 - d2| = 1 时涂橙(7)，|d1 - d2| = 2 时涂品红(6)，|d1 - d2| >= 3 时涂栗(9)。
5. 灰(5)环壁保持不变。种子像素保持原色。两条同深度种子的线不可能交叉（生成时保证同层至多一个种子）。

**关键洞察**：十字线的可见长度不是由画布边界决定，而是由嵌套层的几何墙壁决定——同一个种子在不同方向上的线长可以不同。交叉点颜色编码的是"深度距离"而非具体深度值，需对比多个交叉示例才能归纳映射。

## 新题 7：滑动接触后杯体方向感知填充

**组合逻辑**：[滑动/slide + 接触停止/contact_stop](沿用滑动接触机制) + [开口朝向/opening_direction + 填充/fill + 从开口发射/emit_from_opening](创新：杯的"活跃开口"不是几何固有属性，而是由滑动方向动态决定) + [重涂色/recolor](创新：填充色取决于滑动距离)

**来源原语**：滑动(56dc2b01)、接触停止(56dc2b01)、杯形容器(aba27056)、开口朝向(aba27056)、填充(aba27056)、从开口发射(aba27056)、封闭区域(aba27056)、重涂色(多源)

**依赖链**：滑动方向和停止位置决定物体从杯的哪一侧接触（滑动→接触侧）；接触侧的对面就是杯的"活跃开口"方向（接触侧→开口方向）；杯的内部填充色和射线方向都依赖活跃开口方向（开口→填充/射线）；填充颜色由滑动物体移动的曼哈顿距离决定（距离→颜色）。整条链从滑动到填充色完全耦合。

将小物体滑向杯形容器直到接触，接触方向决定杯的活跃开口，杯内填充并从开口射出颜色由滑动距离决定的射线。

**输入结构**：黑(0)背景上约 14x14 的网格。一个灰(5)杯形容器（由灰像素围成的三面封闭、一面开口的 U 形或 C 形结构，内部约 3x3 空腔，壁厚 1 像素），杯的几何开口可朝上、下、左或右。一个蓝(1)小物体（3~5 像素的 4-连通不规则图形）位于杯的开口方向或非开口方向的一侧，与杯不相邻。蓝物体与杯之间的路径上无障碍。杯的开口侧和蓝物体不在同一侧（即蓝物体需要朝杯的封闭壁滑动，而非滑入开口）。

**规则**：
1. 找到蓝(1)物体和灰(5)杯。确定蓝物体到杯的最短基数方向（上/下/左/右），即蓝物体沿该方向平移最短距离后，蓝物体的某像素与杯壁 4-邻接。
2. 将蓝物体沿该方向平移至接触位置。记录平移的曼哈顿格数 d（蓝物体移动的步数，不含初始位置）。擦除蓝物体的原始位置。
3. 确定杯的活跃开口方向：即蓝物体接触侧的正对面。例如蓝物体从左侧接触杯，活跃开口朝右。
4. 将杯内部空腔（灰壁围成的黑像素区域）填充为颜色 C，C 由 d 决定：d = 1 时 C = 红(2)，d = 2 时 C = 绿(3)，d = 3 时 C = 黄(4)，d >= 4 时 C = 橙(7)。
5. 从杯的活跃开口处，沿开口方向发射颜色 C 的射线，逐像素向外延伸直到网格边界。射线宽度等于开口宽度（开口处每一行/列的空腔像素各发射一条平行射线）。
6. 灰(5)杯壁和蓝(1)物体（在新位置）保持不变。

**关键洞察**：杯有几何上的唯一开口，但"活跃开口"完全由滑动接触方向决定——如果蓝物体从开口对面滑来，活跃开口就是几何开口；如果从侧面滑来，活跃开口则与几何开口不同（这要求杯有两个或以上的潜在开口面，但生成时杯只有一个几何开口且蓝物体总是从对面滑来，因此活跃开口总等于几何开口——真正的隐蔽规则是滑动距离到颜色的映射）。

## 新题 8：互补矩形填充与交叉图案冲突解决

**组合逻辑**：[互补拼合/complement_fit + 填充/fill](创新：两组碎片各自拼合的矩形存在空间重叠) + [行列交叉/row_col_intersection](创新：重叠区不做简单覆盖，而是画两矩形中心的交叉图案) + [计数/counting → 重涂色/recolor](创新：重叠区的图案颜色由两组碎片的像素数比较结果决定)

**来源原语**：互补拼合(fe45cba4)、碎片(fe45cba4)、填充(56ff96f3)、矩形(56ff96f3)、行列交叉(23581191)、交叉点特殊着色(23581191)、计数(f8ff0b80)、重涂色(多源)

**依赖链**：碎片拼合确定两个矩形的位置和尺寸（拼合→矩形）；两矩形的重叠区域触发冲突解决机制而非简单覆盖（重叠检测→冲突模式切换）；冲突区域绘制以两矩形中心为锚点的十字图案（矩形中心→十字位置）；十字的颜色由两组碎片的总像素数比较决定，像素多的颜色画十字（计数→颜色选择）。这是一个同时约束满足结构：填充和冲突解决必须同时考虑。

两对碎片各自拼成矩形并填充，重叠区绘制以矩形中心为锚的十字图案，十字颜色取像素数更多的碎片组。

**输入结构**：黑(0)背景上约 16x16 的网格。两种前景色（红(2)和绿(3)），每种颜色有 2 个 4-连通碎片。红色的两个碎片互补拼合为一个实心矩形 R_red；绿色的两个碎片互补拼合为一个实心矩形 R_green。每种颜色中，一个碎片触及左边缘，另一个不触边。R_red 和 R_green 的边界框有部分重叠（重叠区域面积 >= 4 个像素），但都不完全包含另一个。红色碎片的总像素数与绿色碎片的总像素数不相等。

**规则**：
1. 对每种颜色，找到触左边缘的碎片（移动件）和不触边的碎片（锚件），计算唯一平移使两者并集为实心矩形。擦除移动件原位，将其绘制到拼合位置。
2. 计算两个矩形的重叠区域 O = R_red 交 R_green。
3. 非重叠区域：R_red 独占区填充红(2)，R_green 独占区填充绿(3)。
4. 重叠区域 O 的处理：
   a. 计算 R_red 的中心坐标 (cr_r, cc_r) 和 R_green 的中心坐标 (cr_g, cc_g)（中心取边界框中心，向下取整）。
   b. 在 O 区域内，将位于 cr_r 行或 cc_r 列的像素，以及位于 cr_g 行或 cc_g 列的像素，涂为"胜出色"——胜出色为两组碎片中总像素数更多的那组的颜色。
   c. O 区域内不在上述行/列上的像素涂为另一组的颜色（"落败色"）。
5. 矩形区域之外保持黑(0)。

**关键洞察**：重叠区域不是简单的颜色覆盖，而是生成了一个新的几何图案（十字）——这个图案的位置由两个矩形各自的中心确定，其颜色由像素数量的全局比较确定。必须对比多个示例中不同的像素数大小关系才能归纳出"多者胜出"规则。

## 新题 9：双轴镜像平铺后的连通区域频率柱状图

**组合逻辑**：[镜像/mirror + 双轴反射/biaxial_reflection + 平铺/tiling](沿用四象限镜像) + [洪泛填充/flood_fill + 路径连通/path_connectivity](创新：对镜像后的图案做连通区域检测而非走廊填充) + [计数/counting + 频率匹配/frequency_matching + 柱状填充/histogram_fill](创新：直方图的计数目标是连通区域数量而非像素数)

**来源原语**：镜像(67e8384a)、双轴反射(67e8384a)、象限排布(67e8384a)、瓦片(67e8384a)、洪泛填充(b782dc8a)、路径连通(b782dc8a)、计数(f8ff0b80/2685904e)、频率匹配(2685904e)、柱状填充(2685904e)、分隔行(2685904e)、标记段(2685904e)

**依赖链**：输入的小图案经双轴反射生成 2x2 镜像平铺（镜像→平铺图案）；平铺图案中同色 4-连通区域的数量因反射对称而与原始图案不同（反射可能合并或分裂区域）；对每种前景色计数连通区域数 n（连通检测→计数）；在平铺图案下方，为区域数等于标记段长度的颜色绘制柱状图（频率匹配→柱状填充）。镜像直接影响连通区域拓扑，从而影响计数和柱状图输出。

将小图案双轴镜像平铺，统计平铺后每种颜色的连通区域数量，为匹配目标数量的颜色画柱状图。

**输入结构**：黑(0)背景上的网格分为两部分。上半部分是一个 5x5 至 7x7 的小图案，包含 2~3 种前景色（取自蓝(1)、红(2)、绿(3)、黄(4)），每种颜色有若干不规则的 4-连通区域。下半部分是一行灰(5)分隔行（与上半区域等宽）。分隔行下方有一段橙(7)标记段（连续的橙像素，长度 k 为 1~4），位于分隔行正下方的最左侧。分隔行下方其余为黑(0)。生成时保证：将上半图案做双轴镜像（左右翻转+上下翻转得 2x2 拼贴）后，至少一种前景色的 4-连通区域数恰好等于 k，且至少一种不等于 k。

**规则**：
1. 取分隔行上方的图案作为种子瓦片 T（高 h，宽 w）。
2. 生成 2x2 镜像平铺 M（高 2h，宽 2w）：左上 = T，右上 = T 左右翻转，左下 = T 上下翻转，右下 = T 旋转 180 度。
3. 在 M 中，对每种前景色，用 4-连通洪泛填充检测该色的连通区域数量 n_c。
4. 读取标记段长度 k（橙(7)像素的连续个数）。
5. 构建输出：将 M 绘制在输出网格上方。保留灰分隔行（宽度扩展至 2w）。在分隔行下方，对每种满足 n_c = k 的前景色 c，在该色在 M 最底行出现的每一列，从分隔行向下绘制高度为 k 的柱状条，颜色为 c。不满足条件的颜色不画柱。
6. 标记段在输出中保留（其位置不与柱状条冲突，因为标记段在分隔行正下方最左侧，而柱状条从分隔行下方第二行开始绘制）。

**关键洞察**：镜像平铺不只是视觉变换——它改变了连通区域的拓扑结构（原本分离的区域在对称轴处可能合并），这使得区域计数结果与原始图案不同且不直观。必须先正确完成镜像再计数，跳过任一步都会得到错误的柱状图。

## 新题 10：帧序列外推与嵌套环压缩摘要

**组合逻辑**：[外推/extrapolate + 匀速运动延续/constant_motion + 帧序列/frame_sequence](沿用帧外推机制) + [压缩/compress + 嵌套层次/nesting_hierarchy + 面积序映射环/area_order_to_ring](创新：压缩的对象不是单帧中的嵌套形状，而是多帧中精灵面积的时序变化) + [计数/counting](创新：计数每帧精灵的像素数作为面积)

**来源原语**：外推(ba1aa698)、匀速运动延续(ba1aa698)、帧序列(ba1aa698)、内部精灵(ba1aa698)、等间距排列(ba1aa698)、压缩(eb5a1d5d)、嵌套层次(eb5a1d5d)、面积序映射环(eb5a1d5d)、计数(f8ff0b80)

**依赖链**：帧序列外推产生新帧的精灵位置和形态（外推→新帧）；每帧精灵的像素数通过计数获得（计数→面积序列）；所有帧（含外推帧）的面积值按时序排列后映射为嵌套方环（面积→环层序）；输出不是外推后的帧网格，而是压缩后的嵌套环摘要（压缩依赖外推结果）。

外推帧序列中运动精灵的下一帧，然后将全部帧的精灵面积按时序压缩为嵌套方环摘要。

**输入结构**：黑(0)背景上约 5x20 的网格（宽大于高），由 3~4 个等宽面板水平排列组成，相邻面板共享一列灰(5)边框。每个面板内部填充黑(0)，包含一个由单色像素构成的小精灵（颜色为蓝(1)，形状在所有面板中相同）。精灵在每个面板中的水平列位置相同，但垂直行位置逐面板匀速变化（如每帧下移 1 行）。同时，每帧精灵的像素数也可能因为精灵部分超出面板底部而被裁切减少（靠近下边界的帧精灵像素数更少）。

**规则**：
1. 识别面板结构：找到灰(5)竖直边框列，将网格划分为 N 个面板。每个面板高 H、宽 W（不含边框）。
2. 检测每个面板内蓝(1)精灵的位置（左上角行号）和像素数 a_i（i = 1..N）。计算行位置的逐帧偏移量 dr（恒定）。
3. 外推第 N+1 帧：精灵行位置 = 第 N 帧行位置 + dr。绘制精灵时超出面板边界的部分裁切（不绘制）。计算外推帧精灵的像素数 a_{N+1}。
4. 构建面积序列 A = [a_1, a_2, ..., a_{N+1}]。
5. 输出为一个 (2*(N+1)-1) x (2*(N+1)-1) 的方形嵌套环图：最外层环（1 像素厚边框）颜色对应 a_1，次外层环对应 a_2，依此向内。颜色映射：面积值按从大到小排序后，最大面积涂红(2)，次大涂绿(3)，再次涂黄(4)，再次涂品红(6)，最小涂橙(7)。若两帧面积相同，按时间顺序先出现的排在外层。
6. 嵌套环的绘制顺序：第 1 帧（时间最早）对应最外层环，第 N+1 帧（外推帧）对应最内层。

**关键洞察**：外推不仅要延续位置，还要正确处理边界裁切对像素数的影响——这使得面积序列不是简单的等差数列。压缩摘要将时序信息编码为空间嵌套结构，外层=早期帧、内层=晚期帧，必须对比多个示例才能确认"时间→嵌套层"的映射方向。
