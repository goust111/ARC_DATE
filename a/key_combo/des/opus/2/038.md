## 新题 1：标记计数门控射线桥接

**组合逻辑**：[计数/counting] → 三路分支{[擦除/erase] | [射线延伸/ray_extend + 印章覆盖/stamp] | [重涂色/recolor]}（创新：计数结果同时门控三种互斥变换，而非源题中单一的阈值擦除或单一的射线投射）

**来源原语**：计数/counting（参考题 6e82a1ae, 6455b5f5, a934301b）、射线延伸/ray_extend（参考题 ecdecbb3）、擦除/erase（参考题 a934301b）、重涂色/recolor（参考题 6e82a1ae）、贯穿条/full_span_bar（参考题 ecdecbb3）、标记包含于对象/marker_in_object（参考题 a934301b）、投射/perpendicular_cast（参考题 ecdecbb3）、接触标记/contact_marker（参考题 ecdecbb3）

**依赖链**：标记计数 → 三路分支决策（0个: 擦除, 1个: 射线投射+接触印章, 2+个: 整体重涂色）→ 射线投射依赖贯穿条位置确定方向和终点 → 接触标记依赖射线命中位置。删除计数则无法区分三种命运；删除贯穿条则射线无目标；删除接触印章则命中点无标记。

将散布于网格中的前景对象按其内含标记像素的数量分为三种命运：无标记者消失，恰一个标记者向贯穿条投射射线并在命中处印下接触标记，多标记者被钝化为另一颜色。

**输入结构**：黑(0)背景，约 15x18 网格。一条完整的绿(3)水平贯穿条占据某一行（该行所有像素均为绿(3)）。若干蓝(1)的 4-连通前景对象散布在贯穿条上方和下方，每个对象为不规则形状（4~8 像素），对象之间互不相邻、不接触贯穿条。部分蓝(1)对象内部嵌有红(2)标记像素（0、1 或 2 个），标记像素四邻中至少 2 个为蓝(1)（即嵌入在对象内部而非边缘孤立点）。生成约束：每种标记数量（0 个、1 个、2+ 个）至少有一个对象属于该类，保证三种情况均可观察。

**规则**：
1. 对每个蓝(1) 4-连通对象，统计其内部红(2)标记像素的数量。
2. 标记数 = 0 的对象：将该对象所有像素设为黑(0)（擦除）。
3. 标记数 = 1 的对象：保留蓝(1)不变。从该唯一红(2)标记像素出发，沿垂直方向向绿(3)贯穿条投射射线（即若对象在贯穿条上方则向下投射，若在下方则向上投射）。射线沿途经过的背景像素涂为黄(4)，遇到贯穿条的第一个绿(3)像素即停止（不覆盖绿色）。在该命中点处，将命中点左右各 1 个像素（共 3 个像素的水平段，含命中点本身）涂为橙(7)，覆盖原有绿色。若命中点位于网格左/右边缘导致 3 像素段超出边界，则仅绘制边界内的部分。
4. 标记数 >= 2 的对象：将该对象所有像素（含红(2)标记）统一重涂为灰(5)。不投射射线。
5. 绿(3)贯穿条中未被橙(7)接触标记覆盖的像素保持绿(3)。红(2)标记像素若属于标记数 = 1 的对象则保留红(2)不变。

**关键洞察**：标记像素的数量在每个对象上产生三种互斥的变换命运——消失、投射、钝化——只有"恰好一个"这一中间分支会与贯穿条发生交互，使得求解者必须同时理解计数规则和投射规则才能推断输出。

## 新题 2：洪水分区驱动的同心层三路着色

**组合逻辑**：[填充/flood_fill] → [面积比较/area_comparison + 排序/sorting] → 三路分支{[同心层填充/concentric_layer_filling] | [重涂色/recolor（实心）] | [擦除/erase]}（创新：洪水填充的结果同时提供区域形状边界和面积排名，面积排名决定三种截然不同的区域内填充方式）

**来源原语**：填充/flood_fill（参考题 7491f3cf）、同心层填充/concentric_layer_filling（参考题 3ee1011a）、面积比较/area_comparison（参考题 6455b5f5）、墙壁边界/wall_boundary（参考题 7491f3cf）、指示像素/indicator_pixel（参考题 7491f3cf）、边距深度/edge_distance_depth（参考题 516b51b7）、极值区域分别涂色/extreme_regions_recolor（参考题 6455b5f5）、奇偶交替着色/odd_even_alternating_color（参考题 516b51b7）

**依赖链**：洪水填充从指示像素出发确定每个封闭区域的边界和像素集合 → 由边界和像素集合计算面积 → 面积排名决定每个区域接受三种处理中的哪一种 → 最大区域的同心层填充需要区域边界（来自洪水填充）来逐层向内剥离。

在墙壁分割的网格中，洪水填充确定各区域，面积最大者获得同心交替层填充，面积最小者实心着色，其余区域被清除。

**输入结构**：黑(0)背景，约 16x16 网格。灰(5)墙壁像素形成若干连通屏障（墙壁本身为 4-连通），将网格分隔为 4~5 个封闭区域，区域面积互不相同（差异足以肉眼区分大小）。每个区域内恰好有一个指示像素，各指示像素颜色互不相同，取自 {红(2), 蓝(1), 绿(3), 黄(4), 橙(7)}。指示像素不与墙壁 4-相邻。生成约束：至少 4 个区域，保证"最大""最小"和"中间"三类都存在。

**规则**：
1. 从每个指示像素出发，4-连通洪水填充，以灰(5)墙壁和网格边界为阻挡，标记该指示像素所属区域的所有像素。
2. 统计每个区域的像素数（含指示像素自身），按面积从大到小排序。
3. 面积最大的区域：从区域边界向内逐层计算 Chebyshev 距离。距离 0 层（与墙壁或网格边缘 4-相邻的区域像素）涂为该区域指示像素的颜色；距离 1 层涂为橙(7)；距离 2 层再次涂为指示像素颜色；以此类推，奇数层橙(7)、偶数层指示色交替。
4. 面积最小的区域：将区域内所有像素（含指示像素位置）实心涂为该区域指示像素的颜色。
5. 其余中间面积的区域：将区域内所有像素设为黑(0)（擦除），指示像素也被擦除。
6. 灰(5)墙壁像素保持不变。

**关键洞察**：洪水填充同时产出两个不可分离的结果——区域形状（决定同心层边界）和区域面积（决定处理类型）——求解者无法跳过填充直接判断某个区域应当接受哪种变换。

## 新题 3：直角连线分区驱动的对称生长与收缩

**组合逻辑**：[连线/draw_line]（创新：连线不仅是视觉连接，还隐式创建空间分区） → [内外分区/inside_outside_partition] → 分支{[生长/grow] | [收缩/shrink]}（创新：分区归属决定相反的形变方向，源题中生长/收缩由面积最大者决定）

**来源原语**：连线/draw_line（参考题 d4a91cb9）、直角路径/right_angle_path（参考题 d4a91cb9）、端点像素/endpoint_pixel（参考题 d4a91cb9）、生长/grow（参考题 df978a02）、收缩/shrink（参考题 df978a02）、前景对象/foreground_object（参考题 df978a02）、内外分区/inside_outside_partition（参考题 7491f3cf）、拐角由终点列定/corner_at_target_col（参考题 d4a91cb9）

**依赖链**：端点位置决定直角路径走向 → 路径与网格边界共同划分出两个区域 → 每个前景对象的位置决定其落在哪个区域 → 区域归属决定该对象执行生长还是收缩。删除连线则无分区依据；删除分区判定则无法分配生长/收缩；删除生长/收缩则对象无变换。

在黑色网格中连接两个端点像素形成 L 形路径，路径将网格分为两半，一侧的对象膨胀一圈，另一侧的对象腐蚀一圈。

**输入结构**：黑(0)背景，约 15x15 网格。恰好一个红(2)像素和一个青(8)像素，二者不在同一行也不在同一列。若干蓝(1)的 4-连通前景对象（每个 4~7 像素，不规则形状），散布在网格中。所有蓝(1)对象均不与红(2)、青(8)像素 4-相邻，且对象之间互不 4-相邻。生成约束：两个区域中各至少有 2 个蓝(1)对象；收缩侧的对象面积至少 3 像素（保证收缩后不会完全消失，以便观察效果）。

**规则**：
1. 从红(2)像素出发，沿水平方向画黄(4)像素到青(8)像素所在列，再沿该列垂直方向画黄(4)像素到青(8)像素所在行。拐角位于（红行, 青列）。红(2)和青(8)像素本身保留原色不被黄色覆盖。
2. 黄(4)路径将网格分为两个区域。判定方法：对每个蓝(1)对象，取其所有像素中行号最小、行号相同则列号最小的那个像素作为代表点。若代表点位于路径的"红侧"（即从代表点沿最短路径到达红像素时不穿越黄色路径），则该对象属于红侧；否则属于青侧。
3. 红侧的蓝(1)对象：生长——将该对象每个像素的 4 个基数方向邻居中为黑(0)的像素涂为蓝(1)。多个对象的生长互不干扰（同时执行，生长区域若重叠则合并为蓝(1)）。
4. 青侧的蓝(1)对象：收缩——移除该对象中所有在 4-邻域内存在非蓝(1)像素（黑(0)或黄(4)或网格边界）的蓝(1)像素（即腐蚀边界层），将被移除的像素设为黑(0)。
5. 红(2)、青(8)、黄(4)路径像素均保留不变。生长后的蓝(1)像素若与黄(4)路径相邻，不覆盖黄色。

**关键洞察**：L 形路径承担双重角色——既是两端点间的可见连线，又是隐式空间分界线；对象与路径的相对位置决定其接受膨胀还是腐蚀，使得路径的几何走向直接控制了变换的空间分布。

## 新题 4：扫描线区域与标记计数的联合门控擦除

**组合逻辑**：[填充/flood_fill（扫描线模式）] ∧ [计数/counting] → [擦除/erase]（创新：擦除触发条件是两个独立维度的"与"——空间包含性和标记数量——任一条件单独不足以决定擦除，源题中擦除仅由标记数量决定）

**来源原语**：填充/fill（参考题 78e78cff）、擦除/erase（参考题 a934301b）、计数/counting（参考题 a934301b）、墙壁像素/wall_pixel（参考题 78e78cff）、单点标记/singleton_marker（参考题 78e78cff）、扫描线区间/scanline_interval（参考题 78e78cff）、连通分量/connected_component（参考题 a934301b）、标记包含于对象/marker_in_object（参考题 a934301b）、墙壁界定范围/wall_bounds_span（参考题 78e78cff）、标记列为参考/marker_col_ref（参考题 78e78cff）、标记超阈值则擦除/erase_above_threshold（参考题 a934301b）

**依赖链**：墙壁像素 + 单点标记列 → 扫描线填充确定"活跃区域" → 对每个前景对象判定是否完全落入活跃区域（空间条件）并统计其内部标记数（数量条件） → 仅当两条件同时满足时擦除该对象。两个条件各自独立计算但必须联合判定。

墙壁像素与标记列定义的扫描线区域构成空间准入条件，标记计数构成数量准入条件，二者取交集才触发对象的擦除。

**输入结构**：黑(0)背景，约 16x16 网格。灰(5)墙壁像素分布在若干行上，每行有 1~3 个灰色像素，形成左右限位。一个红(2)单点标记像素位于网格中部。若干绿(3)的 4-连通前景对象（每个 5~10 像素，不规则形状）散布在网格中，部分对象内部嵌有黄(4)标记像素（0、1 或 2 个）。生成约束：至少有一个含 2+ 黄色标记的对象完全落在扫描线区域内（触发擦除），至少有一个含 2+ 黄色标记的对象不完全落在区域内（不擦除），至少有一个含 0~1 黄色标记的对象落在区域内（不擦除），以保证两个条件均可独立观察到"不满足"的情况。

**规则**：
1. 确定扫描线填充区域：在每个含有灰(5)墙壁像素的行上，找到红(2)标记列左侧最近的灰色像素和右侧最近的灰色像素（含与标记同列的），将二者之间（不含灰色像素本身）的黑(0)像素标记为"活跃"。若标记列某侧无灰色像素，则该侧延伸到网格边缘。在最上方墙壁行和最下方墙壁行之间的无墙壁空行上，整行标记为活跃。最上方墙壁行之上和最下方墙壁行之下的空行不标记。此步骤不改变任何像素颜色，仅在逻辑上标记活跃区域。
2. 对每个绿(3) 4-连通对象，判定两个条件：（a）该对象的所有像素是否全部位于活跃区域内；（b）该对象包含的黄(4)标记像素数量是否 >= 2。
3. 仅当条件(a)和(b)同时满足时，将该对象的所有像素（含其黄(4)标记）设为黑(0)（擦除）。
4. 其他所有对象保持原样（绿(3)像素和嵌入的黄(4)标记均不变）。
5. 灰(5)墙壁像素、红(2)单点标记像素均保持原位不变。活跃区域不着色——它仅作为逻辑判据。

**关键洞察**：擦除决策是空间条件（完全位于扫描线区域内）与数量条件（标记 >= 2）的逻辑合取——单看其中任何一个条件都不能正确预测哪些对象会被擦除，求解者必须对比不同示例才能推断出这一双重门控规则。

## 新题 5：线段长度排名决定同心环数的锚点印章

**组合逻辑**：[排序/sorting]（创新：排名值不决定顺序而决定同心环的数量参数） → [同心层填充/concentric_layer_filling + 印章覆盖/stamp]（创新：同心层数量由外部排名注入，且印章位置由锚点决定）

**来源原语**：排序/sorting（参考题 3ee1011a）、同心层填充/concentric_layer_filling（参考题 3ee1011a）、印章覆盖/stamp（参考题 a9f96cdd）、单色线段/mono_segment（参考题 3ee1011a）、锚点像素/anchor_pixel（参考题 a9f96cdd）、由外到内嵌套/outside_in_nesting（参考题 3ee1011a）、按长度降序/desc_segment_length（参考题 3ee1011a）、锚点粘贴固定图案/paste_fixed_pattern_at_anchor（参考题 a9f96cdd）、奇偶交替着色/odd_even_alternating_color（参考题 516b51b7）

**依赖链**：线段长度排序确定每条线段的排名 → 排名值作为参数注入同心层填充（排名 = 层数）→ 锚点位置确定印章放置中心 → 同心环的颜色由线段颜色和交替规则确定 → 重叠区域按层数多者优先。排名是相对值——增减一条线段会改变所有线段的排名和层数。

每条线段在其锚点位置生成一个同心环方阵，环的层数等于该线段在全局长度排名中的位次。

**输入结构**：黑(0)背景，约 20x20 网格。3~5 条水平或垂直的单色 4-连通直线段，每条线段颜色互不相同（取自 {红(2), 蓝(1), 绿(3), 黄(4), 橙(7)}），长度互不相同（范围 3~9 像素）。每条线段的中点像素（若长度为偶数则取靠左或靠上的中间像素）被替换为栗(9)色，作为锚点像素。生成约束：各锚点之间的 Chebyshev 距离足够大（至少 >= 最长线段的长度），保证同心环方阵不超出网格边界。

**规则**：
1. 识别每条线段（4-连通同色像素段 + 其栗(9)锚点）。线段长度 = 同色像素数 + 1（含锚点位置）。
2. 按长度降序排序。最长者排名 1，次长排名 2，以此类推。
3. 擦除所有原始线段像素（含锚点），将网格清为黑(0)。
4. 对每条线段，在其锚点位置为中心，生成一个边长为 (2R-1) 的正方形同心环图案，其中 R = 该线段的排名值。最外层（Chebyshev 距离 = R-1）涂为该线段的颜色。下一层（距离 = R-2）涂为黑(0)。再下一层涂为线段颜色。如此交替，直到中心像素。中心像素涂为栗(9)。
5. 按排名从大到小的顺序绘制（排名最大即最短线段先画，排名最小即最长线段后画）。后绘制的覆盖先绘制的像素。
6. 若同心环超出网格边界，仅绘制边界内的部分。

**关键洞察**：每条线段的同心环大小由其在全局的长度排名决定——这是一个相对属性而非绝对属性；增加或移除一条线段会改变所有其他线段的排名和输出尺寸，使得求解者必须进行全局比较而非逐对象独立求解。

## 新题 6：缺陷修复计数反馈驱动边缘线变色

**组合逻辑**：[修补/repair（嵌入式缺陷）] → [计数/counting（修补次数）] → [重涂色/recolor（边缘线）]（创新：修补操作的"副产品"——修补次数的奇偶性——反向修改了提供方向信息的边缘线本身的颜色；源题中修补与边缘线是并行独立的两个操作） ∧ [射线延伸/ray_extend（孤立标记）]（边缘线方向决定延伸方向，但边缘线颜色已被修补计数修改）

**来源原语**：修补/repair（参考题 8886d717）、射线延伸/ray_extend（参考题 ecdecbb3）、计数/counting（参考题 6e82a1ae）、主体对象/main_object（参考题 8886d717）、标记像素/marker_pixel（参考题 8886d717）、边缘线/edge_line（参考题 8886d717）、嵌入与孤立/embedded_vs_isolated（参考题 8886d717）、边缘指示方向/edge_indicates_direction（参考题 8886d717）、重涂色/recolor（参考题 6e82a1ae）

**依赖链**：嵌入/孤立分类 → 嵌入者修补（计入修补次数）→ 修补次数奇偶性 → 决定边缘线最终颜色 → 孤立者按边缘线方向延伸。修补和延伸依赖同一颜色分类但产出不同；修补的数量信息反向影响了指导延伸方向的边缘线外观。

标记像素按嵌入/孤立分流处理：嵌入者被修复为主体色，修复的总次数反过来决定边缘线是否变色；孤立者向边缘线方向延伸一格。

**输入结构**：黑(0)背景，约 13x16 网格。网格某一侧边缘（上/下/左/右之一）有一条完整的绿(3)实心边缘线（占据该边的整行或整列）。一个较大的蓝(1)主体对象（不规则形状，15~25 像素，4-连通）位于网格中部，不与边缘线相邻。红(2)标记像素若干（3~6 个）：部分嵌入在蓝(1)主体对象中（4-邻域中至少 3 个为蓝(1)），部分孤立在黑(0)背景上（4-邻域中无蓝(1)像素）。生成约束：嵌入的红色标记数在不同示例中有奇有偶，以便观察边缘线变色规则。孤立的红色标记至少 1 个。

**规则**：
1. 将红(2)标记像素分为两类：嵌入式（4-邻域中蓝(1)像素 >= 3）和孤立式（4-邻域中蓝(1)像素 = 0）。
2. 嵌入式修补：将每个嵌入式红(2)标记重涂为蓝(1)。统计修补次数 K。
3. 边缘线变色：若 K 为奇数，将绿(3)边缘线整体重涂为橙(7)；若 K 为偶数（含 0），边缘线保持绿(3)。
4. 孤立式延伸：每个孤立式红(2)标记保留原位，并将其朝边缘线方向的相邻像素涂为红(2)（即若边缘线在网格底部，则将该标记正下方的黑(0)像素涂为红(2)；若边缘线在右侧，则涂右方像素；以此类推）。若该相邻像素非黑(0)（例如属于蓝(1)主体或已有其他标记），则不覆盖。
5. 蓝(1)主体对象中未被修补的像素保持蓝(1)。

**关键洞察**：修补行为本身产生了一个计数副产品，该计数的奇偶性反过来改变了指导孤立标记延伸方向的边缘线的颜色——形成一个从"修补"到"方向线外观"的隐式信息反馈回路，求解者需要对比多个示例中修补次数的奇偶与边缘线颜色的对应关系才能归纳出规则。

## 新题 7：格点空洞裁剪与距离奇偶交替着色

**组合逻辑**：[裁剪/crop]（由缺失交叉点界定范围） → [同心层填充/concentric_fill + 交替填色/alternating_fill]（创新：裁剪边界不仅选择子网格，还作为距离计算的原点——同一组空洞既决定"裁什么"又决定"怎么涂"，源题中裁剪和着色是独立操作）

**来源原语**：裁剪/crop（参考题 a644e277）、同心层填充/concentric_fill（参考题 516b51b7）、交替填色/alternating_fill（参考题 db3e9e38）、网格线/lattice_line（参考题 a644e277）、缺失交叉点/missing_intersection（参考题 a644e277）、同心层/concentric_layer（参考题 516b51b7）、边距深度/edge_distance_depth（参考题 516b51b7）、四角围合/four_corner_bound（参考题 a644e277）、背景色空洞/background_hole（参考题 a644e277）、奇偶交替着色/odd_even_alternating_color（参考题 516b51b7）、奇偶决定颜色/parity_determines_color（参考题 db3e9e38）

**依赖链**：四个缺失交叉点确定裁剪矩形 → 裁剪矩形的边界同时作为 Chebyshev 距离的起始层 → 每个格子内的填色由其距裁剪边界的 Chebyshev 距离的奇偶性决定 → 格子内已有的标记像素覆盖距离规则。空洞同时扮演两个角色（选择 + 度量原点），删除任一则两个功能均失效。

格点网格中四个缺失交叉点定义裁剪范围，裁剪后的子网格内各格子按距裁剪边缘的深度奇偶交替涂色，已有标记像素不受影响。

**输入结构**：黑(0)背景，约 19x19 网格。蓝(1)网格线构成规则格点（水平线和垂直线各若干条，线宽 1 像素，间隔均匀，格子大小约 2x2 或 3x3）。恰好 4 个网格线交叉点被替换为黑(0)（缺失交叉点），这 4 个点形成一个轴对齐矩形的四个角。格子内部（非网格线位置）部分含有标记像素，颜色为红(2)或绿(3)，每个格子最多一个标记像素。生成约束：裁剪矩形内的格子数至少 3x3，保证可观察到多层距离变化。

**规则**：
1. 找到蓝(1)网格线上恰好为黑(0)的 4 个缺失交叉点。以这 4 个点的行列范围（含端点行列）确定裁剪矩形。
2. 输出仅包含裁剪矩形内的子网格（含边界上的网格线）。
3. 在裁剪后的子网格中，对每个格子（由蓝(1)网格线围合的矩形区域），计算该格子到裁剪边缘的 Chebyshev 距离 D。距离定义：格子的行索引与列索引（从裁剪矩形内 0 开始编号，以格子为单位）到最近边缘格子行/列的较小值。即 D = min(r, c, R-1-r, C-1-c)，其中 r,c 为格子的行列索引，R,C 为格子的总行列数。
4. D 为偶数（含 0）的格子：内部背景像素涂为黄(4)。D 为奇数的格子：内部背景像素涂为橙(7)。
5. 格子内已有的标记像素（红(2)或绿(3)）保留不变，不被黄/橙覆盖。
6. 蓝(1)网格线保持不变。裁剪边界上的 4 个缺失交叉点在输出中保持黑(0)。

**关键洞察**：四个缺失交叉点一举两得——既标定了裁剪区域的四角，又隐式地建立了一个环形距离坐标系；移动任何一个空洞不仅改变裁剪范围，还同时改变内部所有格子的着色方案，使得裁剪和着色不可分离地耦合在一起。

## 新题 8：标签对象双重编码驱动金字塔方向与配色

**组合逻辑**：[计数/counting（标签像素数）] → 决定 [展开/expand] 的方向（创新：计数结果不映射颜色而映射空间方向——正向或倒置金字塔） ∧ [交替填色/alternating_fill]（创新：交替的第二色由标签对象的颜色提供而非固定色，源题中金字塔只有单色和背景交替）

**来源原语**：展开/expand（参考题 db3e9e38）、交替填色/alternating_fill（参考题 db3e9e38）、计数/counting（参考题 6e82a1ae）、线段/line_segment（参考题 db3e9e38）、金字塔/pyramid（参考题 db3e9e38）、前景对象/foreground_object（参考题 df978a02）、中心对称展开/center_expand（参考题 db3e9e38）、奇偶决定颜色/parity_determines_color（参考题 db3e9e38）、像素数映射颜色/count_to_color（参考题 6e82a1ae，创新改造为像素数映射方向）

**依赖链**：标签对象的像素数奇偶性 → 决定金字塔展开方向（向上 vs 向下）→ 标签对象的颜色 → 决定交替填色的第二色 → 线段的颜色和长度 → 决定金字塔的第一色和高度。标签同时编码两维信息（方向 + 配色），缺少任一维度都无法确定输出。

每条垂直线段的相邻标签对象同时编码了两个参数：其像素数的奇偶性决定金字塔向上还是向下展开，其颜色决定交替填色的第二色调。

**输入结构**：黑(0)背景，约 15x20 网格。2~3 条垂直单色 4-连通直线段，每条颜色互不相同（取自 {红(2), 蓝(1), 绿(3)}），长度互不相同（范围 4~7 像素），彼此水平间距至少 6 列。每条线段的正右方（间隔 1 列）有一个小型标签对象：一个 4-连通单色小图形（2~4 像素），颜色取自 {黄(4), 橙(7), 灰(5)}且各标签颜色互不相同。标签对象的垂直位置与其线段的中部大致对齐。生成约束：不同示例中同一条线段的标签像素数奇偶性应在不同示例间有变化，保证求解者需要对比多组示例才能确定方向规则。

**规则**：
1. 识别每条垂直线段及其右侧相邻的标签对象（取线段最右列 + 2 列位置上的 4-连通同色区域）。
2. 统计每个标签对象的像素数 P。
3. 若 P 为偶数：该线段向上展开为金字塔——以线段最上端像素所在行为金字塔顶点行，逐行向下展开。每向下一行，水平宽度增加 2（左右各扩 1 列），以线段所在列为中心对称。最宽行的宽度 = 2 * 线段长度 - 1。
4. 若 P 为奇数：该线段向下展开为倒金字塔——以线段最下端像素所在行为倒金字塔底行（最窄行），逐行向上展开。每向上一行，水平宽度增加 2。最宽行在最上端，宽度 = 2 * 线段长度 - 1。
5. 金字塔/倒金字塔内每个像素的颜色由其到中心列的水平距离 d 决定：d 为偶数（含 0）时涂为线段颜色，d 为奇数时涂为该线段标签对象的颜色。
6. 原始线段像素被金字塔像素覆盖（它们位于中心列，d=0，涂线段颜色）。标签对象在输出中被擦除为黑(0)。
7. 若金字塔超出网格边界，超出部分不绘制。多个金字塔若有重叠，按线段从左到右的顺序绘制，后画的覆盖先画的。

**关键洞察**：标签对象是一个双重编码体——其像素数量的奇偶性编码金字塔的空间方向（上/下），其颜色编码交替填色的第二色调——求解者必须同时从标签中解读两个独立参数，且这两个参数分别作用于展开操作的不同维度（空间结构 vs 颜色方案）。
