## 新题 1：面板叠合揭示桥接对

**组合逻辑**：[透明叠加](已有) + [同色配对](已有，创新：配对对象来自不同面板的叠合结果而非同一画面) → [连线](已有，创新：桥接方向和间隙由叠合后的新空间关系决定) + [最短间隙优先连](已有)

**来源原语**：透明叠加(7c9b52a0), 同尺寸面板(7c9b52a0), 同色配对(f3b10344), 连线(f3b10344), 对向间隙(f3b10344), 最短间隙优先连(f3b10344), 非空标记合并(7c9b52a0)

**依赖链**：面板叠合产生新的空间布局 → 叠合后同色矩形之间出现了原始面板中不存在的对向关系 → 桥接连线依赖叠合后的几何位置和间隙长度 → 最短间隙优先选择保证输出唯一

将分散在多个面板中的小矩形叠合为一张复合图，再在复合图中桥接同色矩形对。

**输入结构**：黑(0)背景，约 15x21 的网格。灰(5)分隔线将网格分为 3 个大小相同的面板（约 15x7 每个，沿水平方向排列，面板之间有 1 列灰(5)分隔线）。每个面板以黑(0)为空白底色，其中分布 2~4 个单色实心矩形（2x2 至 3x4 像素），颜色取自红(2)、绿(3)、蓝(1)、橙(7)。每种颜色在所有面板中共出现恰好 2 个矩形，且这两个矩形分布在不同面板中。同一面板内不存在同色矩形。生成约束：叠合后同色矩形对在行跨度或列跨度上至少有 3 个单元格的重叠，且间隙区域全为黑(0)背景。

**规则**：
1. 移除灰(5)分隔线，将所有面板叠合到同一个 15x7 的画布上：以黑(0)为底，对每个面板中每个非黑像素，将其复制到画布的对应相对位置。若两个面板的非黑像素落在同一位置（题目生成时保证不会发生此冲突），则后面板覆盖前面板。
2. 在叠合结果中，找出所有同色矩形对。对每对同色矩形，检查它们是否沿水平或垂直方向对向（即一对矩形的行跨度或列跨度重叠至少 3 个单元格，且中间间隙区域全为黑(0)）。
3. 对每对满足条件的同色矩形，计算间隙长度（矩形边缘之间的空白单元格数）。在所有候选桥中，按间隙长度从短到长依次选取：若一座桥接只会连接尚未连通的同色矩形，则选中它。
4. 对选中的每座桥，在间隙区域内绘制青(8)色连接带。连接带的宽度等于两矩形在共享轴上的重叠跨度减去两端各 1 像素（即向内收缩 1 像素）。
5. 输出仅包含叠合后的复合画布（含桥接线），不包含分隔线。

**关键洞察**：单独查看任何一个面板都无法确定桥接对——同色矩形的配偶在另一个面板中；只有叠合后才能知道它们的相对位置和间隙距离。

## 新题 2：去噪种子的自相似膨胀

**组合逻辑**：[擦除](已有，创新：擦除结果同时改变印章内容和放置掩码) + [保留最大连通分量](已有) → [印章覆盖](已有，创新：印章即掩码，去噪同时改变两者)

**来源原语**：擦除(1f85a75f), 连通分量(1f85a75f), 噪声像素(1f85a75f), 面积比较(1f85a75f), 保留最大连通分量(1f85a75f), 印章覆盖(5b6cbef5), 像素到块映射(5b6cbef5), 前景位放自身副本(5b6cbef5)

**依赖链**：去噪改变了前景像素集合 → 前景像素集合既决定印章图案也决定哪些块位置放置副本 → 一个噪声像素的去留同时影响印章形状和膨胀拓扑

从带噪声的小网格中清理出最大连通体，再用清理后的结果做自相似分形膨胀。

**输入结构**：黑(0)背景，5x5 的小网格。网格中有一个由蓝(1)组成的 4-连通主体（8~14 像素），形状不规则（非矩形，具有连通性但无特定对称要求）。另有 2~4 个孤立的蓝(1)噪声像素，它们与主体不 4-连通。生成约束：主体的面积严格大于任何其他 4-连通分量的面积；噪声分量每个不超过 2 像素。

**规则**：
1. 找出网格中所有蓝(1)像素的 4-连通分量，保留面积最大的那个分量，将其余蓝(1)像素擦除为黑(0)。得到"清洁种子"。
2. 以清洁种子为基础进行自相似块膨胀：创建一个 25x25 的黑(0)输出网格，逻辑上划分为 5x5 个 5x5 的块。
3. 对清洁种子中每个像素位置 (r, c)：若该位置为蓝(1)（即属于保留的主体），则将整个清洁种子复制到输出网格中第 (r, c) 个块的对应位置；若该位置为黑(0)，则对应块保持全黑(0)。
4. 输出即为 25x25 的膨胀网格。

**关键洞察**：噪声像素的去留同时影响两件事——印章的形状和印章出现的位置。例如一个噪声像素如果不被移除，它既会在印章中多出一个像素，又会触发一个额外的块放置，产生双重错误。去噪和膨胀不可拆分为独立步骤。

## 新题 3：格栅压缩暴露线层叠序

**组合逻辑**：[下采样](已有，创新：压缩后才能识别线的交叉关系) + [层序推断](已有，创新：层次信息被格栅结构隐藏) → [压缩](已有，创新：最终输出为按层序排列的颜色序列)

**来源原语**：下采样(68b67ca3), 分隔行列(68b67ca3), 奇偶索引分离(68b67ca3), 保留偶索引交叉(68b67ca3), 层序推断(22425bda), 遮挡层次(22425bda), 直线(22425bda), 交叉点(22425bda), 唯一序链(22425bda), 压缩(4be741c5), 空间排列顺序(4be741c5)

**依赖链**：格栅分隔行列使线条的交叉点不可见 → 下采样移除分隔行列后交叉点暴露 → 交叉点处的可见颜色编码了遮挡层次 → 层序推断产生唯一的从底到顶排列 → 压缩为单列颜色向量

移除格栅分隔行列后，在压缩网格中推断叠压直线的遮挡层序，输出从底到顶的颜色列。

**输入结构**：黑(0)背景，偶数尺寸的网格（约 14x14）。所有奇数索引行和奇数索引列为纯黑(0)分隔行列。偶数行/偶数列的交叉位置构成一个 7x7 的逻辑网格。在逻辑网格中，有 3~5 条贯穿整行或整列的单像素宽直线（水平线或垂直线），颜色各不相同，取自红(2)、绿(3)、蓝(1)、黄(4)、橙(7)。两条线在同一逻辑单元格交叉时，仅有一种颜色可见（上层线遮挡下层线）。生成约束：所有线的遮挡关系形成唯一全序（即任意两条相交的线之间有确定的上下关系，且所有局部关系可传递地推出唯一全序）；每对相交线至少在一个交叉点处可观察到遮挡关系。

**规则**：
1. 识别黑(0)分隔行列（所有奇数索引行和列），移除它们，保留偶数行/偶数列交叉处的像素，得到压缩后的 7x7 逻辑网格。
2. 在逻辑网格中，恢复每条完整直线：每种非黑颜色的所有像素应共线（同行或同列）。将每条线延伸至贯穿整行或整列。
3. 在多条线交叉的逻辑单元格处，可见颜色是最上层的线。对每个交叉点，可见颜色遮挡了经过该点的所有其他线。收集所有这些"颜色 A 在颜色 B 之上"的局部约束。
4. 从所有局部约束中推出唯一的全序：从最底层到最顶层排列所有线的颜色。
5. 输出一个 Nx1 的列向量（N = 线的数量），从上到下为底层到顶层的颜色。

**关键洞察**：分隔行列在原始网格中隔开了线条，使交叉点无法直接观察；必须先压缩格栅才能发现哪些线真正交叉、谁遮挡谁。在压缩前尝试推断层序会因分隔行列的阻隔而失败。

## 新题 4：凹槽拟合筛选后的幸存者计数

**组合逻辑**：[形状匹配](已有) + [旋转平移嵌入](已有) → [擦除](已有，创新：擦除对象由几何拟合结果决定) → [计数](已有，创新：计数对象是拟合失败的幸存者) + [摘要生成](已有，创新：摘要内容编码拟合的几何筛选结果)

**来源原语**：形状匹配(1acc24af), 凹槽(1acc24af), 候选块(1acc24af), 结构体(1acc24af), 旋转平移嵌入(1acc24af), 完全覆盖(1acc24af), 无重叠(1acc24af), 重涂色(1acc24af), 计数(5289ad53), 摘要生成(5289ad53), 分类计数(bd283c4a), 行主序填充(5289ad53)

**依赖链**：几何拟合判定哪些候选块可嵌入凹槽 → 可嵌入者被擦除 → 幸存候选块按颜色分类计数 → 计数结果编码为固定格式的摘要网格

将能旋转嵌入蓝色结构凹槽的候选块擦除，按颜色清点剩余候选块并输出计数摘要。

**输入结构**：黑(0)背景，约 20x15 的网格。上半区（约前 7 行）有一个蓝(1)的 4-连通结构体，形成一个宽度为 1~2 像素的不规则框架。框架底边有 2~3 个向上凹陷的凹槽（黑(0)连通区域，与框架底边相邻，每个凹槽 3~6 像素）。下半区散布 4~6 个小型 4-连通前景对象（"候选块"），颜色为绿(3)或红(2)，每个候选块 3~6 像素，形状不规则。生成约束：恰好有 2~3 个候选块（可能需要旋转 0/90/180/270 度）能完全覆盖某个凹槽且不与蓝(1)像素重叠；其余候选块在任何旋转下都无法完全覆盖任何凹槽。每个凹槽至多被一个候选块匹配。

**规则**：
1. 在蓝(1)结构体的边界框内，找出所有与框架底边相邻的黑(0) 4-连通区域，这些是凹槽。
2. 对每个候选块（绿(3)或红(2)的 4-连通分量），尝试其 4 个旋转方向。对每个旋转，尝试所有平移位置，检查是否能完全覆盖某个凹槽的所有像素，且旋转后的候选块不与蓝(1)像素重叠，也不超出网格边界。
3. 能成功匹配任意凹槽的候选块标记为"已匹配"。将已匹配候选块的所有像素擦除为黑(0)。
4. 清点幸存（未被擦除）的候选块：分别统计绿(3)幸存者数量 G 和红(2)幸存者数量 R。
5. 生成一个 2x3 的黑(0)摘要网格，按行主序填入：先填 G 个绿(3)单元格，再填 R 个红(2)单元格，剩余位置保持黑(0)。
6. 输出仅为该 2x3 摘要网格。

**关键洞察**：计数的对象不是全部候选块，而是几何拟合的"落选者"——必须先完成旋转匹配才能知道谁幸存；摘要网格编码的是失败而非成功。

## 新题 5：行端匹配填色与射线交叉擦除的博弈

**组合逻辑**：[填充](已有，创新：填充结果成为擦除的筛选对象) + [两端同色整行填充](已有) ←对抗→ [射线延伸](已有，创新：射线仅擦除已填充的行，未填充行不受影响) + [命中即整体擦除](创新改造：命中目标从"连通分量"改为"已填充的整行")

**来源原语**：填充(22eb0ac0), 标记像素(22eb0ac0), 画布边界(22eb0ac0), 同色配对(22eb0ac0), 两端同色整行填充(22eb0ac0), 射线延伸(2f767503), 标记条(2f767503), 控制像素(2f767503), 射线命中(2f767503), 命中即整体擦除(2f767503), 擦除(2f767503)

**依赖链**：行边界标记的颜色匹配决定哪些行被填充 → 射线方向由标记条和控制像素决定 → 射线穿过的已填充行被擦除回背景 → 最终输出是未被射线穿越的已填充行

先按行端颜色匹配填充整行，再用射线擦除被射线穿越的已填充行，保留幸存的填充行。

**输入结构**：黑(0)背景，约 15x12 的网格。若干行（4~6 行）的最左列和最右列各有一个标记像素，颜色取自红(2)、绿(3)、蓝(1)、黄(4)。在这些被标记的行中，部分行的左右标记同色，部分行的左右标记异色。其余行没有标记像素。网格中另有一个标记条：3 个橙(7)像素组成的水平或垂直直线段，位于网格的某一边缘区域（但不在任何被标记行的最左或最右列上）。紧邻标记条中心像素的一侧有一个品红(6)控制像素。生成约束：标记条中心沿远离控制像素方向的射线至少穿过一行已填充行和一行未填充行；射线不会穿过任何行标记像素。

**规则**：
1. 复制输入网格。
2. 对每一行，检查其最左和最右像素是否都是非黑前景色。若两端都是非黑色且颜色相同，则将该行所有像素填充为该颜色（包括覆盖两端标记本身的位置）。若两端颜色不同或有任一端为黑(0)，则该行保持不变。
3. 找到由 3 个橙(7)像素组成的标记条及其相邻的品红(6)控制像素。确定射线方向：从标记条中心出发，沿远离控制像素的方向（上、下、左或右）。
4. 沿射线方向逐单元格延伸，直至网格边界。对射线经过的每一行（射线垂直时经过每一行，射线水平时仅经过标记条所在行）：若该行在步骤 2 中被填充过，则将整行擦除回黑(0)。
5. 标记条和控制像素在输出中保持不变。输出最终网格。

**关键洞察**：填充和擦除是对抗关系——填充由行端颜色决定，擦除由射线几何决定。求解者必须同时推断两个独立机制（颜色匹配规则和射线方向规则），然后计算它们的交互结果。单独理解任一机制都无法预测最终输出。

## 新题 6：碎片合并决定嵌套序，间隙宽度触发重涂色

**组合逻辑**：[补全](已有，创新：补全结果改变面积从而改变排序) + [合并对齐碎片](已有) → [排序+嵌套](已有，创新：嵌套后的间隙宽度成为重涂色的触发条件) → [重涂色](已有，创新：重涂色规则由嵌套后的空间关系决定)

**来源原语**：补全(8fbca751), 残缺矩形(8fbca751), 合并对齐碎片(8fbca751), 行列跨度重叠(8fbca751), 排序(6cbe9eb8), 嵌套(6cbe9eb8), 面积递减嵌套(6cbe9eb8), 角落对齐嵌套(6cbe9eb8), 重涂色(1acc24af), 对向间隙(f3b10344)

**依赖链**：碎片按行列跨度合并 → 合并改变矩形的实际尺寸和面积 → 面积排序决定嵌套的层次 → 嵌套后相邻层之间的间隙宽度决定是否重涂内层颜色 → 重涂色的源颜色来自外层矩形

合并散落碎片为完整矩形，按面积嵌套后，根据相邻层间隙宽度决定是否将内层重涂为外层颜色。

**输入结构**：黑(0)背景，约 20x20 的网格。有 4 个不同颜色的矩形结构，颜色分别取自红(2)、绿(3)、蓝(1)、黄(4)，每个矩形为 1 像素宽的空心框。部分矩形是完整的，部分被拆成 2~3 个不相连的碎片（碎片间不 4-连通，但它们的边界框在行跨度或列跨度上有重叠）。4 个矩形的完整边界框面积互不相同。生成约束：合并碎片后得到的 4 个完整矩形边界框面积严格递减排列时，相邻层之间的间隙（较大框内边到较小框外边的距离）要么恰好为 1 个像素，要么大于 2 个像素，不会出现恰好 2 个像素的情况。

**规则**：
1. 找出所有非黑前景像素的 4-连通分量。按颜色分组。
2. 对同色的分量，若它们的边界框在行跨度或列跨度上有重叠，则合并为一个矩形组。取合并组的最小外包边界框作为该颜色的完整矩形。
3. 按完整矩形的边界框面积从大到小排序。
4. 在一个新的黑(0)画布上嵌套放置：最大矩形放在画布左下角对齐，第二大矩形放在最大矩形内部的左下角对齐，依此类推，每个矩形放在上一个矩形内部的左下角。每个矩形绘制为 1 像素宽的空心框，使用其原始颜色。
5. 嵌套完成后，检查每对相邻层（第 k 大和第 k+1 大矩形）：计算外层框内边到内层框外边的最小正交距离。若该距离恰好为 1 像素，则将内层矩形的颜色重涂为外层矩形的颜色。若距离大于 2 像素，则保持内层原色不变。
6. 输出画布裁剪为最大矩形的边界框大小。

**关键洞察**：碎片合并改变了矩形的真实大小，从而改变排序和嵌套顺序；嵌套后的层间距离取决于排序结果，而重涂色又取决于距离。三个操作形成环形依赖——不先合并就不知道面积，不知道面积就不知道嵌套序，不嵌套就不知道间隙，不知道间隙就不知道重涂色结果。

## 新题 7：频率堆叠种子的旋转风车

**组合逻辑**：[计数+排序+堆叠](已有，创新：堆叠结果作为旋转的种子而非最终输出) → [旋转+拼接](已有，创新：旋转对象是频率编码的紧凑网格)

**来源原语**：计数(bd283c4a), 排序(bd283c4a), 堆叠(bd283c4a), 按频率降序(bd283c4a), 逐列填充(bd283c4a), 旋转(7fe24cdd), 拼接(7fe24cdd), 正方形画布(7fe24cdd), 阵列排布(7fe24cdd), 四旋转组成风车(7fe24cdd)

**依赖链**：逐色计数和频率排序决定堆叠网格的颜色分布 → 堆叠网格的空间布局决定旋转后四个象限的视觉效果 → 频率梯度与旋转对称性交互产生涌现的风车图案

统计各色像素频率并堆叠为紧凑方阵，再将方阵及其三个旋转拼成风车。

**输入结构**：黑(0)背景不参与计数。一个完全由前景色覆盖的矩形网格（无黑色像素），尺寸约 4x8 或 8x4（面积为 32 像素），使用 3~4 种颜色，取自红(2)、绿(3)、蓝(1)、黄(4)。每种颜色的像素数互不相同。生成约束：所有颜色的像素总数恰好为某个完全平方数的两倍对半（即可堆叠成一个 NxN 正方形，此处 N 取决于总像素数的平方根，如 32 像素无法成正方形——修正：总像素数等于 16，即 4x4 输入，可堆叠为 4x4）。修正：输入为一个 4x4 的网格，完全由前景色覆盖（16 像素），使用 3~4 种颜色，像素数互不相同（如 7、5、3、1）。

**规则**：
1. 统计输入中每种颜色的像素数量。
2. 按像素数量从多到少排序颜色。
3. 创建一个与输入同尺寸的 4x4 黑(0)网格。按排序后的颜色顺序，从左到右逐列、每列从下到上逐行填入像素：先将最多的颜色填满尽可能多的位置，然后下一种颜色接续填入，直到所有 16 个位置填满。
4. 将堆叠后的 4x4 网格作为种子，构建 8x8 的风车拼图：左上象限放原始种子，右上象限放顺时针 90 度旋转，左下象限放逆时针 90 度旋转，右下象限放 180 度旋转。
5. 输出 8x8 风车网格。

**关键洞察**：频率堆叠将无序的颜色分布转化为有梯度的空间排列；旋转拼接将这种梯度放大为四向对称的视觉模式。不同的频率分布会产生完全不同的风车图案——频率信息通过堆叠编码进空间，再通过旋转展开。

## 新题 8：面板叠合墙壁约束下的螺旋生长

**组合逻辑**：[透明叠加](已有，创新：叠加结果作为螺旋生长的障碍地图) + [非空标记合并](已有) → [螺旋生长](已有，创新：螺旋路径需同时满足转弯优先规则和叠合墙壁的回避约束) + [路径绘制](已有)

**来源原语**：透明叠加(7c9b52a0), 面板(7c9b52a0), 分隔线(7c9b52a0), 同尺寸面板(7c9b52a0), 非空标记合并(7c9b52a0), 螺旋生长(da515329), 路径绘制(da515329), 十字图案(da515329), 臂端(da515329), 优先转弯规则(da515329), 间距约束(da515329)

**依赖链**：多面板叠合产生复合墙壁地图 → 墙壁位置约束螺旋路径的可行方向 → 螺旋转弯优先规则与墙壁回避规则发生冲突时，墙壁回避优先 → 不同面板组合产生不同墙壁配置，导致完全不同的螺旋形态

叠合多个面板得到墙壁地图，从中心十字的臂端出发生长螺旋路径，路径必须回避所有叠合墙壁。

**输入结构**：黑(0)背景，约 21x15 的网格。灰(5)分隔线将网格分为 3 个同尺寸面板（每个约 7x15，沿水平排列，面板间 1 列灰(5)分隔线）。每个面板以黑(0)为底，其中有 3~6 个散布的红(2)像素作为"墙壁标记"。网格中央面板的正中心有一个青(8)十字图案（中心 1 像素加上下左右各延伸 1~2 像素，共 5~9 像素）。生成约束：叠合后的墙壁像素不与十字图案重叠；十字每个臂端沿其旋转后初始方向至少有 3 个连续空闲单元格。

**规则**：
1. 移除灰(5)分隔线，将 3 个面板叠合到同一个 7x15 的画布上：以黑(0)为底，保留青(8)十字图案，对每个面板中的红(2)墙壁标记像素，复制到画布对应位置。若多个面板在同一位置都有红(2)标记，结果仍为红(2)。
2. 从十字图案的 4 个臂端分别发射一个"画笔"。每个画笔的初始方向为其臂端朝外方向顺时针旋转 90 度。画笔绘制绿(3)像素。
3. 每个画笔按以下规则逐步移动：
   - 优先尝试右转（相对当前行进方向顺时针 90 度），若目标单元格合法则移动并转向。
   - 否则尝试直行，若目标合法则移动。
   - 否则尝试左转（逆时针 90 度），若目标合法且目标单元格不在网格边界上则移动并转向。
   - 若三个方向均不合法，画笔停止。
4. 合法性判定：目标单元格在网格边界内，为黑(0)背景，且与除画笔前一步位置之外的所有已有非黑像素（包括青(8)十字、红(2)墙壁、绿(3)已绘路径）保持至少 1 个单元格的正交间距。
5. 步长规则：刚完成转弯后的第一步步长为 1 个单元格；连续直行时步长为 2 个单元格（即跳过中间 1 格，中间格也绘制为绿(3)）。
6. 输出叠合后的画布（含十字、墙壁、螺旋路径），不含分隔线。

**关键洞察**：任何单个面板的墙壁都不足以显著约束螺旋；只有叠合所有面板后，墙壁密度才足以迫使螺旋改变路径。求解者必须先完成叠合才能判断螺旋的走向——叠合和螺旋生长是同时约束满足的关系，而非简单的顺序流水线。
