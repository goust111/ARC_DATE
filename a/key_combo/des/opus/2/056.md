## 新题 1：奇偶格栅门控的腔室洪泛填充

**组合逻辑**：[洪泛填充](作用范围从整个腔室缩减为奇偶格栅交集) + [坐标奇偶匹配](从全局背景过滤缩减为腔室内部过滤) → 双重空间约束同时生效

**来源原语**：洪泛填充/flood_fill(e69241bd)、墙壁/wall(e69241bd)、封闭区域/enclosed_region(e69241bd)、标记像素/marker_pixel(e69241bd, d492a647)、坐标奇偶匹配/coord_parity_match(d492a647)、奇偶格点/parity_lattice(d492a647)

**依赖链**：墙壁划分出腔室 → 标记像素的颜色决定填充色（与 e69241bd 相同）→ 但标记像素的行列坐标奇偶性同时决定了腔室内哪些像素被填充（与 d492a647 相同的奇偶筛选，但作用域从全局缩减到腔室内部）。腔室边界限制了奇偶格栅的作用范围，奇偶格栅限制了洪泛的覆盖面积——两个约束缺一不可。

用一句话概括：在墙壁分隔的腔室中，只将与标记像素行列奇偶性相同的背景像素涂为标记色，形成腔室内的棋盘格局部填充。

**输入结构**：约 15x15 的网格。黑(0)为背景色。灰(5)像素构成连通的墙壁线段（水平与垂直各若干段，厚度 1 像素），将网格分割为若干互不连通的矩形或近矩形腔室。部分腔室内部恰好有一个单像素标记，颜色为红(2)、蓝(1)、绿(3)等非黑非灰色；其余腔室无标记。不同腔室的标记颜色可以相同也可以不同。标记像素的位置在腔室内任意（不一定在中心）。生成约束：每个腔室至少 3x3 大小（不含墙壁），每个腔室至多一个标记。

**规则**：
1. 识别灰(5)为墙壁色——它是唯一一种出现次数远多于其他非背景色的前景色。
2. 以墙壁像素为障碍，找出所有 4-连通的非墙壁连通分量（即腔室）。
3. 对于无标记的腔室，保持不变。
4. 对于含有标记像素的腔室，设标记位于 (r_m, c_m)，颜色为 C：
   - 遍历该腔室中的每个背景像素 (r, c)。
   - 当且仅当 r % 2 == r_m % 2 **且** c % 2 == c_m % 2 时，将该像素涂为颜色 C。
   - 不满足奇偶条件的背景像素保持黑(0)不变。
5. 标记像素本身保留原色不变。墙壁像素保持灰(5)不变。

**关键洞察**：标记像素的网格坐标不仅标识了所属腔室（空间包含关系），还同时编码了一个奇偶格栅相位——同一腔室中标记若偏移一格，填充的棋盘相位就会反转。必须对比多个示例中标记在腔室内不同位置时的填充图案，才能归纳出奇偶规则而非简单的全填充。

## 新题 2：计数即层厚的同心框构建与图例重涂

**组合逻辑**：[计数](对象数量 → 几何参数) + [嵌套包裹](层厚由计数而非条纹高度决定) + [颜色替换映射](图例将输入色映射为输出色，独立于几何参数)

**来源原语**：计数/counting(ff28f65a)、数量映射/count_mapping(ff28f65a)、嵌套包裹/nested_wrapping(45a5af55)、逐层构建/layer_by_layer_build(45a5af55)、颜色替换映射/color_sub_map(e9b4f6fc)、微型图例/micro_legend(e9b4f6fc)、实心正方形/solid_square(22806e14)

**依赖链**：计数各色方块数量 → 数量决定同心框的层厚（不同于 45a5af55 中由条纹高度直接给出层厚）→ 数量大小排序决定从内到外的层序 → 图例将每种输入色映射为输出层色（不同于 e9b4f6fc 中对已有目标的局部替换，这里是对即将构建的结构指定颜色）。三条信息通路——计数→厚度、排序→层序、图例→颜色——分别来自不同的输入元素，缺任一通路都无法确定输出。

用一句话概括：数各色方块的个数作为层厚，按数量从少到多逐层包裹构建同心正方形框，每层颜色由微型图例指定。

**输入结构**：约 14x14 的网格。黑(0)为背景色。网格上散布着 3-4 种颜色的实心正方形（每个方块 2x2，同色方块互不相邻）。网格底部一行紧贴下边界放置一个 2xN 的微型图例条（N = 颜色种数），图例的上行像素为各方块颜色（如红(2)、蓝(1)、绿(3)），下行像素为对应的输出层颜色（如黄(4)、品红(6)、橙(7)）。图例上行的颜色集合与方块颜色集合完全一致。生成约束：不同颜色的方块数量互不相同（确保排序无歧义），每种颜色的方块数量在 1-4 之间。

**规则**：
1. 识别底部的 2xN 图例条：上行 → 输入色，下行 → 输出色，逐列对应。
2. 统计网格中（不含图例区域）每种颜色的 2x2 实心方块数量。记为 count(C) 对于每种颜色 C。
3. 将所有颜色按 count 值从小到大排列。若 count 相同（生成约束排除此情况，但作为保险），按颜色在图例中从左到右的出现顺序作为次序。
4. 构建同心正方形输出（黑(0)背景画布上）：
   - 取排序后第一种颜色（count 最小，设为 k_1），在画布中心放置一个 k_1 x k_1 的实心正方形，颜色为该色的图例映射输出色。
   - 取第二种颜色（count 为 k_2），在当前结构外围包裹一圈厚度为 k_2 像素的正方形框，颜色为该色的图例映射输出色。新结构边长 = 原边长 + 2 * k_2。
   - 依次对后续颜色重复包裹。
5. 输出仅包含该同心正方形结构，画布大小恰好包围最外层框。

**关键洞察**：方块的数量在源题(ff28f65a)中编码到固定位模式，在源题(45a5af55)中层厚由可视条纹高度直接给出；此题中数量从离散对象的计数中产生，再被用作几何参数，同时图例独立地决定了颜色——必须对比多个示例才能发现计数→厚度的映射规则（而非按颜色编号或其他属性）。

## 新题 3：容器开口定方向、像素数定深度的颜色匹配填充

**组合逻辑**：[颜色匹配](对象与容器配对) + [填充](方向与深度均由输入结构推断) + [计数](对象像素数 = 填充深度) + [擦除](原位对象消失)

**来源原语**：颜色匹配/color_matching(17829a00)、填充/fill(444801d8)、计数/counting(ff28f65a)、擦除/erase(6e4f6532)、杯状轮廓/cup_outline(444801d8)、单色对象/monochrome_object(17829a00)、标记色决定填充/marker_color_sets_fill(444801d8)、碰撞停止/collision_stop(17829a00)

**依赖链**：对象与容器通过颜色匹配配对（与 17829a00 的颜色匹配方向相似，但目标是容器而非边界条）→ 容器缺失的那一侧决定填充从哪个方向开始（不同于 444801d8 中杯子只开口朝上、不同于 17829a00 中方向由边界条位置决定）→ 对象的像素总数决定填充深度（不同于 444801d8 中完全填满、不同于 ff28f65a 中计数编码到固定图案）→ 原位对象被擦除。四个逻辑点互相依赖：颜色→配对，开口→方向，像素数→深度，擦除→清理。

用一句话概括：将每个小对象与同色容器配对，从容器开口对面的墙壁开始，填入与对象像素数等量的行或列，然后擦除原对象。

**输入结构**：约 14x16 的网格。黑(0)为背景色。3-4 个单色矩形轮廓（边框厚度 1 像素，内部 3-6 行 x 3-6 列的黑色空腔），每个轮廓颜色不同（如红(2)、蓝(1)、绿(3)、黄(4)），每个轮廓恰好缺少一条边（上、下、左或右），形成一个开口——不同容器的开口方向可以不同。3-4 个小型单色 4-连通对象（2-5 像素，形状各异——可以是直线段、L 形碎片、不规则小块等），每个对象的颜色恰好与一个容器颜色相同。小对象散布在容器外部，位置任意（不一定在开口方向上）。生成约束：每种颜色恰好一个容器和一个小对象；不同小对象的像素数互不相同且不超过容器沿填充方向的内部深度。

**规则**：
1. 按颜色将每个小对象与唯一的同色容器配对。
2. 确定每个容器的开口方向（缺失边的那一侧）。填充方向为开口的反方向：开口在上 → 从底壁向上填充；开口在下 → 从顶壁向下填充；开口在左 → 从右壁向左填充；开口在右 → 从左壁向右填充。
3. 计算配对小对象的像素总数 D。
4. 从容器内部紧贴开口对面的墙壁起，沿填充方向连续填充 D 行（若填充方向为上下）或 D 列（若填充方向为左右）的容器内部像素，颜色为该容器/对象的颜色。剩余未填充的内部像素保持黑(0)。
5. 擦除小对象在原位置的所有像素（置为黑(0)）。
6. 容器轮廓边框像素保持不变。

**关键洞察**：容器的几何缺口（开口方向）决定了填充方向，小对象的像素数决定了填充深度——两者分别编码在不同的输入元素中。必须对比多个示例（不同开口方向、不同像素数的对象）才能同时归纳出方向规则和深度规则；仅看单个示例可能误以为是完全填满。

## 新题 4：位序循环镜像印章

**组合逻辑**：[印章](精灵体复制到多个分区) + [镜像](变换类型由位置序号决定，而非全局统一) + [排序](分区的位置序号定义了变换的循环周期)

**来源原语**：印章/stamp(48f8583b, c3e719e8)、镜像/mirror(62c24649)、排序/sort(941d9a10)、位置排序/positional_ordering(941d9a10)、分隔线/divider_line(941d9a10)、掩码选位放置/mask_selects_placement(48f8583b)

**依赖链**：分隔线将画布划分为矩形分区 → 对分区按位置排序获得序号 → 序号的奇偶性决定印章时使用哪种镜像变换（不同于 48f8583b 中所有印章完全相同、不同于 62c24649 中全局统一镜像）。分区的位置信息（来自 941d9a10 的排序概念）直接控制了印章的几何变换（来自 62c24649 的镜像概念），产生了源题中不存在的"位置→变换映射"。

用一句话概括：将源精灵体印章到由分隔线划分的各个分区中，奇数序号分区使用左右镜像，偶数序号分区使用上下镜像。

**输入结构**：约 15x15 的网格。黑(0)为背景色。灰(5)直线（若干条完整横跨网格的水平线和/或垂直线，厚度 1 像素）将网格分割为若干矩形分区。左上角分区（即行列排序后序号为 0 的分区）包含一个多色精灵体图案（3-5 像素宽、3-5 像素高，使用 2-3 种非黑非灰颜色，形状不对称——即左右镜像和上下镜像均与原图案不同）。其余所有分区内部为黑(0)。生成约束：所有分区的内部尺寸相同（均能容纳精灵体），分区总数在 4-9 之间。精灵体在其分区内部居中放置。

**规则**：
1. 识别灰(5)分隔线，确定所有矩形分区。
2. 对分区按其内部区域左上角坐标排序：先按行（从上到下），行相同则按列（从左到右），得到序号 0, 1, 2, ...。
3. 序号 0 的分区包含源精灵体，保持不变。
4. 对于序号 k（k >= 1）的分区：
   - 若 k 为奇数：将源精灵体做左右镜像后，居中放置到该分区。
   - 若 k 为偶数：将源精灵体做上下镜像后，居中放置到该分区。
5. 灰(5)分隔线保持不变。

**关键洞察**：精灵体的不对称性使得左右镜像与上下镜像的结果互不相同，而哪种镜像被使用完全取决于分区的位置序号奇偶——这个规则不在输入中显式标注，必须对比多个分区的内容与其位置序号才能归纳。

## 新题 5：周期门控的对角交叉涂色

**组合逻辑**：[对角线激活](标记像素激活两条对角线) + [周期步长](边界点间距定义采样周期) + [重涂色](底色区域决定涂什么色) → 三重约束交织：对角线定路径、周期定采样、底色定颜色

**来源原语**：对角线激活/diagonal_activation(d07ae81c)、重涂色/recolor(d07ae81c)、基底色区域/base_color_region(d07ae81c)、底色决定涂色/base_color_fill(d07ae81c)、周期步长/periodic_step(16de56c4)、边界点/boundary_dot(16de56c4)、同余对齐/modular_alignment(16de56c4)、标记像素/marker_pixel(d07ae81c)

**依赖链**：边界点对的间距定义全局周期 P → 标记像素激活经过它的两条对角线（NW-SE 和 NE-SW）→ 但沿对角线只有与标记像素的对角距离为 P 的整数倍（含 0）的位置才被选中涂色 → 被选中位置的涂色由该位置原来的底色决定（每种底色有对应的标记色）。三条信息——路径（对角线）、采样（周期）、颜色（底色映射）——分别独立，但共同决定输出中每个像素的值。

用一句话概括：沿标记像素的两条对角线，仅在周期间隔处涂色，涂色颜色由该位置的原始底色决定。

**输入结构**：约 16x16 的网格。两种底色（如黄(4)和绿(3)）以宽度为 2 的水平条纹交替铺满整个网格（第 0-1 行为黄(4)，第 2-3 行为绿(3)，第 4-5 行为黄(4)，依此类推）。1-3 个标记像素散布在网格中，颜色为红(2)或蓝(1)等非底色、非黑色。网格底边（最后一行）上恰好有两个灰(5)像素，它们之间相隔若干列，间距定义周期 P（P = |col_2 - col_1|，2 <= P <= 5）。生成约束：标记像素不在底边行上；底边行除两个灰(5)像素外其余像素保持原底色。两种底色各自对应一个标记色：黄(4)区域涂红(2)，绿(3)区域涂蓝(1)（此映射通过标记像素所在位置的底色推断——标记像素位于哪种底色区域，就代表该底色的标记色）。

**规则**：
1. 识别底边行上的两个灰(5)像素，计算周期 P = |col_2 - col_1|。
2. 确定底色→标记色映射：对每个标记像素，它所在位置的原始底色（若该位置不是标记像素时应当是什么底色，根据条纹模式可以推算）记为 B，则 B → 该标记像素的颜色 C 就是一对映射。
3. 对每个标记像素（位于 (r_m, c_m)），激活经过它的 NW-SE 对角线和 NE-SW 对角线上的所有网格内位置。
4. 沿每条对角线，设某位置 (r, c) 与标记像素的切比雪夫距离（即 |r - r_m| = |c - c_m|）为 d。仅当 d % P == 0 时，该位置被标记为"激活"。
5. 对每个激活位置（不含标记像素本身）：
   - 根据该位置行号确定其原始底色 B'（由条纹模式决定）。
   - 将该位置涂为底色 B' 对应的标记色。
6. 标记像素本身保持原色不变。灰(5)边界点保持不变。未被激活的位置保持原底色。
7. 若两个标记像素的激活路径在同一位置重叠，行号较小的标记像素优先（行号相同则列号较小的优先）。

**关键洞察**：对角线路径上的涂色并非连续而是被周期 P 离散化为间隔点，形成虚线状图案；而每个间隔点的最终颜色不由标记像素直接给出，而由该点自身所处的底色条纹决定。必须对比不同 P 值的示例才能归纳出周期规则，对比不同底色条纹位置才能归纳出底色决定涂色的规则。

## 新题 6：边界框奇偶筛选存活与图例重涂裁排

**组合逻辑**：[裁剪](逐对象提取) + [重涂色](图例映射) + [擦除](奇偶性判定存废) + [排序](位置决定排列顺序) → 四步推理图：几何属性决定生死、图例决定颜色、位置决定排列

**来源原语**：裁剪/crop(e9b4f6fc)、重涂色/recolor(e9b4f6fc)、颜色替换映射/color_sub_map(e9b4f6fc)、微型图例/micro_legend(e9b4f6fc)、擦除/erase(22806e14)、奇偶性/parity(22806e14)、奇边长才标注/odd_side_marked(22806e14)、位置排序/positional_ordering(941d9a10)

**依赖链**：裁剪出每个对象的边界框 → 检测边界框宽度和高度是否均为奇数（源自 22806e14 的奇偶判断，但此处奇偶性决定的是对象存废而非中心标注）→ 仅存活对象参与图例重涂（源自 e9b4f6fc 的映射，但此处重涂的前提条件由奇偶过滤决定）→ 存活对象按原始位置排列在输出中（源自 941d9a10 的位置排序）。奇偶判定、图例映射、位置排序三者交织：删掉奇偶判定则不知道哪些对象存活；删掉图例则颜色错误；删掉排序则顺序不确定。

用一句话概括：只保留边界框宽高均为奇数的对象，对其强调色按图例重涂，然后按原始水平位置从左到右排列输出。

**输入结构**：约 18x18 的网格。黑(0)为背景色。散布着 4-6 个互不相邻的多色 4-连通对象（每个对象 4-12 像素，形状各异——有的紧凑如方块、有的狭长如条带、有的不规则如碎片）。每个对象恰好使用两种非黑颜色：一种是"主体色"（占多数像素），另一种是"强调色"（占少数像素，1-3 个像素）。不同对象的主体色互不相同，强调色也互不相同。网格右边界紧贴放置一个 Nx2 的微型图例条（N = 对象数量），图例左列为各对象的强调色，右列为对应的替换色。生成约束：有些对象的边界框宽高均为奇数，有些至少一个维度为偶数（确保存在筛选效果）；存活对象至少 2 个。

**规则**：
1. 读取右边界的 Nx2 图例条：左列为强调色，右列为替换色。
2. 对网格中（不含图例区域）的每个 4-连通多色对象，计算其边界框（最小包围矩形）的宽度 W 和高度 H。
3. 若 W 和 H 均为奇数，该对象"存活"；否则该对象被"淘汰"（不出现在输出中）。
4. 对每个存活对象：
   - 裁剪其边界框区域。
   - 将其强调色像素替换为图例映射的替换色。主体色不变，背景像素保持黑(0)。
5. 将所有存活对象的裁剪结果按原始边界框左上角的列坐标从小到大排列，横向拼接，相邻对象之间间隔 1 列黑(0)像素。若两个对象列坐标相同，行坐标较小的在前。
6. 输出为包含所有存活对象拼接后的最小矩形（高度为所有存活裁剪中最大的高度，较矮的裁剪底部对齐，上方空余填充黑(0)）。

**关键洞察**：边界框维度的奇偶性是一个隐藏的筛选条件——从单个示例看，被保留的对象可能恰好是最大的或某种颜色的，只有对比多个示例才能排除这些假设、锁定奇偶性规则。图例仅对存活对象生效，但图例本身包含了所有对象（含被淘汰的）的映射条目。

## 新题 7：伴随点截停与覆色的对角种子射线

**组合逻辑**：[射线延伸](种子沿对角线发射) + [角位控制射线](红色角像素编码方向) + [碰撞停止](伴随点截断射线) + [重涂色](伴随点颜色覆盖整条射线段) → 伴随点同时执行"停止"和"覆色"双重角色

**来源原语**：射线延伸/ray_extend(1f0c79e5)、种子块/seed_block(1f0c79e5)、对角方向/diagonal_dir(1f0c79e5)、角位控制射线/corner_controls_ray(1f0c79e5)、伴随点/companion_dot(16de56c4)、碰撞停止/collision_stop(17829a00)、重涂色/recolor(e9b4f6fc)

**依赖链**：种子块中红(2)角像素的位置编码对角射线方向（与 1f0c79e5 相同）→ 射线沿对角线延伸（与 1f0c79e5 相同）→ 但射线被沿途的伴随点截停（源自 16de56c4 的伴随概念 + 17829a00 的碰撞停止，但在原题中伴随点是周期射线的终止符或吸收壁，不改变射线颜色）→ 截停后整条射线段被重涂为伴随点的颜色（源自 e9b4f6fc 的重涂概念，但此处重涂的颜色来源是伴随点而非图例）。伴随点的新角色——同时截停和覆色——是源题中不存在的结构关系。

用一句话概括：从 2x2 种子的红色角位发射对角射线，射线被伴随点截停后整段重涂为伴随点的颜色；无伴随点的方向射线延伸至网格边缘并保持种子色。

**输入结构**：约 16x16 的网格。黑(0)为背景色。网格中央附近有一个 2x2 种子块，其中 1-3 个角像素为红(2)，其余角像素为另一种非红非黑颜色（"画笔色"，如橙(7)）。沿种子的各活跃对角方向（由红色角位决定），在对角线上可能存在一个单像素伴随点，颜色为非红非黑非画笔色的其他颜色（如蓝(1)、绿(3)、黄(4)等），不同方向的伴随点颜色可以不同。某些活跃方向上可能没有伴随点。生成约束：伴随点严格位于种子角像素的对角延长线上（行偏移量 = 列偏移量），与种子的对角距离至少为 2；同一方向至多一个伴随点。

**规则**：
1. 在种子块中，将所有红(2)像素替换为画笔色（输出中种子块为纯画笔色 2x2 方块）。
2. 红(2)角像素的位置编码对角方向：左上角 → NW（行减列减），右上角 → NE（行减列增），左下角 → SW（行增列减），右下角 → SE（行增列增）。
3. 对每个活跃方向，从种子块对应角像素出发，沿该对角方向逐步检查：
   a. 若遇到伴随点（非黑、非画笔色的像素），射线在该伴随点之前停止（伴随点本身不被覆盖）。从种子角像素（不含）到伴随点（不含）之间的所有对角线像素均涂为**伴随点的颜色**。
   b. 若该方向上无伴随点，射线延伸至网格边缘。从种子角像素（不含）到网格边界（含边界像素）的所有对角线像素均涂为**画笔色**。
4. 种子块本身为画笔色 2x2（步骤 1 已处理）。伴随点保持原色不变。
5. 若两条射线的路径在某像素重叠（例如两个不同方向的射线经过同一点），按方向优先级 NW > NE > SW > SE 选择该像素的颜色。

**关键洞察**：伴随点在此题中承担双重角色——它既是射线的物理终止符（碰撞停止），又是射线段的颜色来源（覆色）。无伴随点的方向与有伴随点的方向行为截然不同（一个保持画笔色延伸到边缘，一个被截停并变色），必须在同一示例中同时看到两种情况或对比多个示例才能归纳出完整规则。

## 新题 8：标记位编码四象限镜像粘贴

**组合逻辑**：[平移粘贴](标记偏移决定对齐位置) + [镜像](标记在窗口内的象限位置编码镜像变换类型) → 标记像素同时编码"对齐偏移量"和"变换类型"两种信息

**来源原语**：平移粘贴/translate_and_paste(2f0c5170)、标记点偏移对应/marker_offset_correspondence(2f0c5170)、精灵窗口/sprite_window(2f0c5170)、空白窗口/empty_window(2f0c5170)、共享标记点/shared_marker_pixel(2f0c5170)、镜像/mirror(62c24649)、四象限排布/four_quadrant_layout(62c24649)

**依赖链**：源窗口中标记像素的位置定义了精灵体的锚点 → 每个目标窗口中标记像素的位置定义了粘贴锚点（与 2f0c5170 相同的偏移对齐逻辑）→ 但标记像素在目标窗口内所处的象限同时编码了镜像变换类型（与 62c24649 的四象限概念结合，但在 62c24649 中镜像是全局统一的，而此处每个目标独立决定变换）。在源题 2f0c5170 中，标记只决定平移量；此题中标记的象限位置额外决定了几何变换，这是源题中不存在的结构关系。

用一句话概括：将精灵体分别粘贴到四个目标窗口中，每个目标窗口的标记像素所在象限决定了精灵体的镜像方式，标记像素的位置同时决定了对齐偏移。

**输入结构**：约 18x18 的网格。灰(5)为外部背景色。网格中包含五个大小相同的矩形窗口（填充色为黑(0)），互不重叠，被灰(5)背景隔开。其中一个窗口为"源窗口"，包含：(a) 一个多色精灵体图案（使用 2-3 种非黑非灰非栗色的颜色，3-6 像素宽、3-6 像素高，形状不对称），(b) 一个栗(9)色标记像素放置在精灵体内部或紧邻位置。其余四个为"目标窗口"，每个只包含一个栗(9)色标记像素，位于窗口内部的不同位置。生成约束：四个目标窗口的标记像素分别位于窗口内部的四个不同象限（左上、右上、左下、右下各一个）；窗口内部尺寸足以容纳精灵体在任意对齐下的粘贴结果；源窗口可通过"包含非标记非背景色像素"来唯一识别。

**规则**：
1. 识别源窗口（包含栗(9)标记和多色精灵体的窗口）和四个目标窗口（仅含栗(9)标记的窗口）。
2. 在源窗口中，提取精灵体图案（所有非黑非栗色像素），并记录标记像素相对于精灵体边界框左上角的偏移 (dr_s, dc_s)。
3. 对每个目标窗口：
   a. 确定标记像素在窗口内部的象限位置。将窗口内部（不含边框）在行方向二等分、列方向二等分：标记像素行 <= 中线行 且 列 <= 中线列 → 左上象限；行 <= 中线行 且 列 > 中线列 → 右上象限；行 > 中线行 且 列 <= 中线列 → 左下象限；行 > 中线行 且 列 > 中线列 → 右下象限。（中线行 = 窗口内部顶行 + floor(内部高度/2) - 1，中线列 = 窗口内部左列 + floor(内部宽度/2) - 1。）
   b. 根据象限选择镜像变换：
      - 左上象限：不做镜像（原样粘贴）。
      - 右上象限：左右镜像。
      - 左下象限：上下镜像。
      - 右下象限：左右镜像 + 上下镜像（等效于 180 度旋转）。
   c. 对精灵体应用所选镜像变换。同时对标记偏移 (dr_s, dc_s) 应用相同变换，得到变换后的偏移 (dr_t, dc_t)。
   d. 平移变换后的精灵体，使变换后的标记偏移位置与目标窗口中的标记像素坐标对齐。
   e. 将变换后的精灵体像素写入目标窗口。超出窗口内部范围的像素裁剪丢弃。栗(9)标记像素在输出中被精灵体覆盖（若有重叠）或保留（若无重叠）。
4. 源窗口在输出中保持不变（精灵体和标记均保留）。
5. 灰(5)背景保持不变。

**关键洞察**：标记像素的位置同时编码了两种信息——对齐锚点（决定精灵体平移量）和象限归属（决定镜像变换类型）。在源题 2f0c5170 中，标记仅用于对齐；此题中必须额外推断象限→变换的映射规则。对比四个目标窗口中精灵体的不同朝向与标记的不同象限位置，才能归纳出完整规则。
