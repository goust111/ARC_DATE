## 新题 1：门结构划界的分段周期修复

**组合逻辑**：[门结构 gate_motif](创新：从滑动终点改为周期域分界标记) + [四邻接连通 four_neighbor_connect] → [周期推断 periodic_inference](分段独立执行) → [间隙填充 gap_filling](在各段内修复)

**来源原语**：gate_motif / stop_at_gate / path / four_neighbor_connect 来自 182e5d0f；periodic_inference / gap_filling / ignore_missing_to_infer / repeating_tile 来自 1d0a4b61

**依赖链**：必须先识别门结构才能确定周期域的边界；必须划定域边界才能对每段独立推断周期；必须推断出周期才能修复缺损像素。删除门识别环节则所有段被混为一个域、周期冲突无法求解；删除周期推断环节则门结构失去意义。

在一条绿色通道上，门结构将通道切分为独立周期段，每段有自己的彩色周期图案和黑色缺损，需分段推断并修复。

**输入结构**：约 12x18 网格。背景黑(0)。绿(3)色像素构成一条 4-连通的水平或垂直通道（宽 1 像素，长度跨越网格大部分范围）。通道上嵌有 2-3 个门结构，每个门是与通道方向垂直的"栗(9)-绿(3)-栗(9)"三像素直线段（中心像素与通道重合，两端栗色像素在通道两侧各延伸 1 像素）。门结构将通道分为 3-4 段。每段内，部分绿色通道像素被替换为其他颜色（如红(2)、蓝(1)、黄(4)等），构成该段特有周期图案的可见样本；另有部分像素被替换为黑(0)表示缺损。不同段的周期长度和颜色组合互不相同。生成约束：每段内至少有一个完整周期的非黑像素可见，确保周期可唯一推断。

**规则**：
1. 识别通道中所有门结构：与通道垂直的栗(9)-绿(3)-栗(9)三像素直线段。门结构保持不变。
2. 门的绿色中心像素将通道分段。每段的范围是两个相邻门中心之间的通道像素（不含门中心本身），或从通道端点到最近门中心之间的通道像素。
3. 对每段独立执行：忽略黑(0)像素，从该段内可见的彩色像素（含绿色）推断沿通道方向的最小重复周期。
4. 用推断出的周期瓦片填充该段内所有黑(0)位置，保持与可见像素的相位一致。
5. 通道外的所有像素（包括背景和栗色门端）不变。

**关键洞察**：门结构不再是运动的终点，而是周期性的边界——同一条通道上不同段拥有完全不同的周期规律，必须先用门分段才能正确推断各段的独立周期。

## 新题 2：遮挡层级过滤镜像资格

**组合逻辑**：[遮挡顺序 occlusion_order] + [交叉处可见性 crossing_visibility] → 条件过滤(创新：遮挡层级决定是否激活镜像) → [镜像 mirror] + [接触边对齐 contact_edge_align]

**来源原语**：occlusion_order / crossing_visibility / rect_frame / traverse_all_colors 来自 c920a713；mirror / contact_edge_align / sprite / anchor_as_axis 来自 11dc524f

**依赖链**：必须先分析交叉处可见性才能确定遮挡全序；必须确定全序才能判断哪些精灵体获得镜像资格；必须知道资格才能执行或跳过镜像操作。遮挡分析和镜像操作缺一不可。

多个重叠矩形框各配一个同色精灵体，通过交叉遮挡关系推断层级全序；只有非最底层框对应的精灵体才被反射到框内侧。

**输入结构**：约 15x15 网格。背景黑(0)。3 个单像素厚的轴对齐矩形边框，颜色分别为红(2)、蓝(1)、绿(3)，彼此部分重叠（每对框至少有一处边缘交叉，交叉处可见的颜色记录遮挡关系）。每个框的外侧有一个同色的 4-连通小精灵体（3-6 像素，不规则形状，不同示例中形状不同），与框的某一条边平行且相隔 1-2 像素。每个精灵体仅与一个框关联（同色配对）。生成约束：三个框的遮挡关系构成唯一全序（无环），即存在唯一从底到顶的排列。

**规则**：
1. 对每对重叠框，检查它们边缘交叉处的可见颜色：若框 A 与框 B 交叉处显示 B 的颜色，则 B 遮挡 A（B 在 A 上方），记有向边 A->B。
2. 从遮挡图中确定唯一的全序（从最底层到最顶层）。
3. 全序中最底层的颜色对应的精灵体不执行任何操作，保持原位不变。
4. 对全序中非最底层的每个颜色 C 的精灵体：找到框 C 上离该精灵体最近的那条边，以该边为镜像轴，将精灵体反射到框内侧，反射副本用灰(5)绘制。
5. 所有矩形框和原始精灵体保持不变，仅在框内侧添加灰色反射副本。

**关键洞察**：遮挡层级不是渲染排列参数，而是条件过滤器——它决定哪些精灵体"有资格"被镜像。最底层的框被所有其他框遮盖，其精灵体失去镜像的机会。需要对比多个示例才能发现"最底层不镜像"这一隐蔽规则。

## 新题 3：L 标记朝向编码重力方向

**组合逻辑**：[标记朝向编码颜色 marker_orientation_encodes_color](创新：朝向编码改为方向编码) + [重力下落 gravity_drop](创新：方向由标记动态决定) + [容器 container] + [填充 fill] + [擦除 erase]

**来源原语**：marker / marker_orientation_encodes_color 来自 604001fa；gravity_drop / container / fill / column_fall_in / no_container_floor 来自 db7260a4；erase 来自 182e5d0f

**依赖链**：必须解读 L 标记的缺角方位才能确定坠落方向；必须确定方向才能判断彩色像素是否会进入某个容器；必须知道容器开口方向才能判断是否"接住"了坠落像素。三层判断环环相扣。

L 三联骨牌标记的缺角不编码颜色，而是编码重力方向；标记旁的彩色像素沿该方向坠落，落入开口方向匹配的 U 形容器。

**输入结构**：约 14x14 网格。背景黑(0)。网格中散布 3-4 个橙(7)色 L 三联骨牌标记（每个占据 2x2 区域中的 3 个像素，缺失一个角像素）。每个标记紧邻（共享一条边）1 个彩色单像素（颜色各异，从红(2)、蓝(1)、绿(3)、黄(4)中选取），该彩色像素位于标记 2x2 包围盒的某条边外侧的中间位置。网格中另有 3-4 个栗(9)色 U 形容器（两条平行边 + 一条底边，内部为空矩形区域，每个容器的开口朝某个基数方向——上/下/左/右），容器开口方向不全相同。生成约束：每个标记的坠落方向上恰好有一个开口方向与之相对的容器（向下坠落对应朝上开口、向左坠落对应朝右开口，以此类推），且不同标记指向不同容器，保证无冲突。

**规则**：
1. 擦除所有橙(7)标记像素（变为黑色）。
2. 对每个原标记，根据其 2x2 包围盒中缺失角的位置确定重力方向：缺左上角 → 向下，缺右上角 → 向右，缺右下角 → 向上，缺左下角 → 向左。
3. 将每个标记紧邻的彩色像素沿对应方向移动。像素沿该方向逐格移动直到遇到一个 U 形容器的开口。容器"接住"像素的条件：容器的开口方向与坠落方向相对（即容器朝上开口接住向下坠落、容器朝右开口接住向左坠落，以此类推），且像素的移动轨迹经过容器开口的行或列范围。
4. 当像素被容器接住时，用该彩色填满容器的整个内部空间。
5. 若像素到达网格边界仍未遇到匹配容器，则沿移动方向在边界行或列铺满该色（从像素起始位置到边界的整行或整列）。
6. 容器壁（栗色）保持不变。彩色像素的原始位置变为黑色。

**关键洞察**：L 标记的几何朝向编码的不是颜色而是物理方向，且容器的开口方向必须与坠落方向"相对"才能接住填充。需要同时解读标记的几何编码和容器的结构朝向。缺角位置到方向的映射是隐蔽规则，需对比多个示例才能归纳。

## 新题 4：差异掩码编码射线方向集

**组合逻辑**：[差异提取 difference_extraction] + [对齐比较 aligned_comparison] → 方向编码(创新：掩码几何形状编码射线方向) → [射线延伸 ray_extend] + [障碍块 blocker] + [碰撞停止 collision_stop]

**来源原语**：difference_extraction / aligned_comparison / foreground_motif / damaged_copy / missing_cell_mask 来自 2037f2c7；ray_extend / source_pixel / blocker / collision_stop 来自 69889d6e；erase 来自 182e5d0f

**依赖链**：必须比较两个图案才能提取差异掩码；必须分析掩码像素的空间分布才能确定射线方向集合；必须发射射线才能生成输出。差异提取的结果不是终态输出而是中间编码，射线延伸的方向参数不是固定的而是由差异动态决定。

上区两个对齐图案的缺失像素分布编码了射线方向，下区的源像素沿这些方向发射射线直到撞上障碍。

**输入结构**：约 15x15 网格。背景黑(0)。网格被一行灰(5)色水平分隔线分为上下两区。上区包含两个 4-连通多色前景图案（每个的包围盒约 4x4 到 5x5，互相水平间隔若干列），它们的包围盒大小相同。一个是完整图案，另一个是缺损副本（有 2-4 个像素被替换为黑色）。下区中央有一个红(2)色源像素，下区另有若干蓝(1)色障碍块（每个为 2x2 方块，共 2-4 个）。生成约束：缺损像素相对于掩码几何中心的方向集合中，每个归一化方向互不相同（不会有两个缺损像素映射到同一射线方向）。

**规则**：
1. 裁剪上区两个图案到各自包围盒，按左上角对齐逐像素比较。
2. 提取缺损副本中缺失的像素位置（完整中有前景色、缺损中为黑色的格子），得到差异掩码（一组相对于包围盒的坐标）。
3. 计算差异掩码的几何中心：所有缺失像素坐标的平均值（行和列分别平均，四舍五入取整）。
4. 每个缺失像素相对于几何中心的偏移 (dr, dc) 定义一个射线方向。方向归一化规则：若 |dr| > |dc| 则步长为 (sign(dr), 0)；若 |dc| > |dr| 则步长为 (0, sign(dc))；若 |dr| == |dc| 且均非零则步长为 (sign(dr), sign(dc))。偏移为 (0,0) 的像素不产生射线。
5. 从下区的红色源像素出发，沿每个归一化方向发射射线。射线逐格绘制红(2)色像素，遇到蓝色障碍块或网格边界时停止（不覆盖障碍块，不覆盖灰色分隔线）。
6. 擦除灰色分隔线和上区所有内容（变为黑色）。输出仅保留下区：红色射线、红色源像素、蓝色障碍块、黑色背景。

**关键洞察**：上区的"找不同"不是目的而是编码——缺失像素的空间分布决定了下区射线的发射方向集合。差异提取是中间推理步骤，其几何属性成为后续操作的参数。

## 新题 5：面积排名嵌套与位置排名着色的双轨同心框

**组合逻辑**：[面积排名 area_ranking] + [计数 counting] → 嵌套顺序 ‖ [空间位置排序 spatial_position_ordering] → 颜色赋值 → [重绘 redraw] + [同心方框 concentric_frame]（双轨并行汇合）

**来源原语**：area_ranking / max_foreground_count_selected / counting / sprite 来自 a87f7484；sort / concentric_frame / occlusion_order / traverse_all_colors 来自 c920a713；spatial_position_ordering 来自 1990f7a8；recolor 来自 575b1a71

**依赖链**：面积排名和位置排名是两条并行的推理链，各自独立计算，最终在同心框绘制时汇合——面积排名控制框的几何嵌套层次，位置排名控制框的颜色。两条链的结果通常不一致（面积最大的精灵体未必在最左边），迫使求解者发现并分离两条独立规则。

四个灰色精灵体的面积排名决定同心方框的嵌套顺序，而质心水平位置排名决定方框颜色，两种排名交叉赋值。

**输入结构**：约 18x18 网格。背景黑(0)。4 个互不相连的单色 4-连通精灵体，颜色均为灰(5)，形状各异（不规则，前景像素数分别约为 4、7、11、16，确保面积互不相同）。4 个精灵体的包围盒中心列坐标互不相同，包围盒中心行坐标也互不相同。生成约束：面积从大到小的排列与列坐标从左到右的排列不一致（至少有一对精灵体在两种排名中的相对位置不同）。

**规则**：
1. 计算每个精灵体的前景像素数（面积），按面积从大到小排列，得到嵌套序号（序号 1 = 面积最大 = 最外层框，序号 4 = 面积最小 = 最内层框）。
2. 计算每个精灵体包围盒中心的列坐标，按列坐标从左到右排列，映射到颜色序列：最左 → 蓝(1)，次左 → 红(2)，次右 → 绿(3)，最右 → 黄(4)。
3. 输出一个 9x9 的网格，背景黑(0)。绘制 4 个居中的同心单像素厚方框：最外层方框边长 9，次外层边长 7，次内层边长 5，最内层边长 3。
4. 嵌套序号为 k 的方框，颜色取面积排名第 k 的那个精灵体在位置排名中获得的颜色。即：面积最大的精灵体决定最外层框的颜色，该颜色由该精灵体的质心水平位置排名确定。

**关键洞察**：面积和水平位置通常给出不一致的排名，求解者必须发现"面积决定几何层次，水平位置决定颜色"这一双轨规则，而非单一排名同时决定两者。

## 新题 6：十字擦除划定独立周期修复域

**组合逻辑**：[十字擦除 cross_erasure] + [标记块 marker_block] + [特定色像素豁免 specific_color_pixel_exemption] → 域分割(创新：擦除后的十字线切割网格为四个独立域) → [周期推断 periodic_inference] + [间隙填充 gap_filling](各域独立执行)

1. 找到唯一的 2x2 黑色标记块，确定其占据的 2 行和 2 列。

3. 十字线（已变黑的行列，加上原本就是黑色的标记块）将网格分为 4 个矩形区域（左上、右上、左下、右下），区域不包含十字线本身。

5. 用推断出的瓦片填充该区域内所有黑(0)位置，保持与可见像素的相位一致。
6. 十字线上的黑色像素保持为黑色（不修复），十字线上的红色像素保持为红色。

**关键洞察**：十字擦除同时执行两个功能——划定周期域的边界，以及在域内制造额外缺损。红色像素承担双重角色：它们在十字擦除中作为保护像素幸存，同时在周期推断中作为不可或缺的锚点证据。

1. 识别蓝色对角线的方向（主对角方向）。
2. 对每个灰色引导体，找到其距离蓝色对角线最远的那个灰色像素（远端顶点）。
3. 通过每个远端顶点画一条与原对角线平行的蓝(1)色对角线，向两端延伸至网格边界。

5. 现在有 3 条平行蓝色对角线。相邻两条对角线之间形成一个对角带状区域。从网格顶边到第一条对角线（或从第一条到第二条等）之间围成的区域视为三角形容器。

7. 擦除原始顶行标记像素（变为黑色）。输出保留蓝色对角线、填充色和黑色背景。

**关键洞察**：引导体不是装饰而是建筑蓝图——它们的几何位置决定了对角容器壁的位置，进而决定了哪个标记落入哪个区域。容器是由引导体动态构建的，理解引导体的远端顶点语义是求解的前提。

## 新题 8：噪声中检测隐藏矩形作为射线偏转障碍

**组合逻辑**：[最大矩形检测 max_rect_detection] + [最小边长过滤 min_side_filter] + [噪声背景 noisy_background] → 障碍识别(创新：检测结果不重涂色而作为障碍) → [射线延伸 ray_extend] + [障碍偏转绕行 obstacle_deflection] + [对角方向 diagonal_direction] + [擦除 erase]

**来源原语**：max_rect_detection / min_side_filter / noisy_background / solid_mono_rect 来自 25094a63；ray_extend / source_pixel / obstacle_deflection / blocker / diagonal_direction 来自 69889d6e；erase 来自 182e5d0f

**依赖链**：必须先从噪声中检测出隐藏的大矩形才能确定障碍位置；必须知道障碍位置才能计算射线的偏转轨迹。检测和偏转构成不可分割的推理链——不先解决感知问题（哪些是真正的矩形）就无法执行物理模拟（射线怎么绕行）。

噪声网格中隐藏的大型同色矩形不被标记，而是作为射线偏转的障碍，射线的弯折轨迹间接揭示矩形的存在。

**输入结构**：约 16x16 网格。网格被随机多色噪声像素填满（颜色 0-9 随机分布，无大面积同色区域）。其中隐藏 2 个纯色实心矩形（如一个 4x5 的红(2)矩形和一个 5x4 的蓝(1)矩形），它们的颜色在噪声中也零散出现，但这两个矩形是唯一边长均 >= 4 的最大同色矩形区域。网格底行最左侧有一个黄(4)色源像素（该位置的噪声被显式替换为黄色）。网格中不存在其他黄(4)像素。生成约束：两个隐藏矩形不相邻也不重叠；源像素的对角射线路径上至少遇到一个矩形障碍。

**规则**：
1. 检测网格中所有边长均 >= 4 的最大同色实心矩形。"最大"指不存在一个更大的同色矩形严格包含它。忽略噪声中的小色块和短色条。
2. 将检测到的矩形标记为障碍块，保留其原色。
3. 从底行的黄色源像素出发，向右上方（对角方向，每步行-1 列+1）发射一个两像素宽的水平带。第一步在源像素上方一行放置两个黄色像素（源像素列和列+1）。
4. 每向上一行，带的两个像素都向右移一列（对角前进）。若带在新行的位置与障碍块碰撞（任一像素落在障碍块内），则将带继续向右平移直到两个像素都避开障碍块。
5. 若偏移导致当前行的带与上一行的带在列方向上产生间隙（当前行最左像素的列 > 上一行最右像素的列 + 1），则在上一行从其带的右端向右补充黄色像素直到列间隙消除（保持轨迹连通）。
6. 带移出网格右边界时停止。
7. 将所有非障碍块且非射线轨迹的像素替换为黑(0)。输出保留：检测到的矩形（原色不变）、黄色射线轨迹、黑色背景。

**关键洞察**：射线的弯折位置是矩形检测正确性的间接验证——不先从噪声中识别出真正的大矩形，就无法确定射线该在哪里偏转。感知和模拟必须同时正确才能得到正确输出。

**规则**：
1. 对 4 个精灵体按输入空间位置排序：先按包围盒中心行坐标分为上组（较小的 2 个）和下组（较大的 2 个），每组内按包围盒中心列坐标从左到右排序。排序后得到四个位置：左上、右上、左下、右下。
2. 图集位置到新颜色的固定映射：左上位 → 蓝(1)，右上位 → 红(2)，左下位 → 绿(3)，右下位 → 黄(4)。

4. 擦除上半区所有精灵体像素（变为黑色）。
5. 对下半区每个标记像素：根据标记的当前颜色找到同色的精灵体，将标记重涂为该精灵体的映射新颜色。

**关键洞察**：精灵体的空间排列不是为了展示紧凑图集，而是为了生成颜色转换映射表——原色 → 图集位置 → 新色。标记像素通过共享原色间接引用这张动态生成的映射表。排列顺序不同则映射不同，输出也不同。

## 新题 10：压缩颜色网格后中心分隔列翻转

**依赖链**：必须先筛选出大矩形并压缩成颜色网格才能确定每列有哪些颜色以及中心分隔像素是什么；必须识别中心分隔像素才能确定翻转的轴和范围；压缩结果的尺寸（行数）决定了翻转是否发生（行数为奇数时有唯一中心行，偶数时无中心行则不翻转该列）。两个操作通过网格尺寸和颜色内容紧耦合。

大网格中散布的填充矩形先压缩成紧凑颜色网格，再对网格每列以中心行像素为轴独立翻转上下两段颜色顺序。

**输入结构**：约 20x20 网格。背景黑(0)，散布少量干扰色单像素。包含 15 个单色填充矩形（5 行 x 3 列排列），每个矩形至少 3x3，颜色从 10 种 ARC 颜色中选取（可有重复）。同行矩形的垂直包围盒范围重叠，同列矩形的水平包围盒范围重叠，形成 5x3 的格点结构。干扰像素不构成边长 >= 3 的矩形。

**规则**：
1. 筛选出所有边长均 >= 3 的纯色 4-连通填充矩形（恰好填满其包围盒），忽略干扰像素。
2. 按矩形包围盒的行位置和列位置分组，压缩为 5x3 颜色网格（5 行 3 列，每格填入对应矩形的颜色）。
3. 对压缩后的 5x3 网格，将每一列（5 个像素的竖直序列）视为独立单元进行局部翻转：
   - 第 3 行（中间行，从 1 开始计数）的像素为中心分隔像素，保持不动。
   - 第 1-2 行的两个像素顺序翻转（第 1 行和第 2 行交换）。
   - 第 4-5 行的两个像素顺序翻转（第 4 行和第 5 行交换）。
4. 输出翻转后的 5x3 颜色网格。

**关键洞察**：压缩步骤决定了颜色网格的内容——哪些颜色在哪些位置——而翻转步骤重排了每列内的颜色布局。不先压缩就不知道颜色排列，不翻转就无法匹配输出。中心分隔行的颜色不变，但它隐式锚定了翻转的对称轴。
