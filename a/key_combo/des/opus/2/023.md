## 新题 1：剪切同心环

**组合逻辑**：[同心层填充](已有) + [剪切变换](创新——作用于环层而非单一对象) + [色板行](已有) → 环层几何与距离色板双重耦合

**来源原语**：同心层填充、色板行、切比雪夫距离索引（参考题 9356391f）；剪切变换、偏移随行距增、底行锚点（参考题 423a55dc）

**依赖链**：色板行为每层环指定颜色 → 种子像素按切比雪夫距离展开为同心方环 → 每一层环额外按其距离 d 向右偏移 d 列（剪切），底行不动 → 剪切量与色板索引共享同一个距离参数 d，删去任何一步均无法还原输出

根据种子像素和色板行生成同心方环，并将整个图案以底行为锚点向右剪切，形成斜塔式分层图案。

**输入结构**：约 15x15 网格，背景为黑(0)。第 0 行为色板行：从左端起连续排列 3~5 个非背景颜色像素（如红(2)、蓝(1)、绿(3)、黄(4)），其余为黑(0)。第 1 行为灰(5) 分隔行（整行灰色）。分隔行下方某位置有一个种子像素，其颜色等于色板行第一个颜色。网格中除上述元素外全为黑(0)。生成约束：种子像素距网格边缘至少 4 格（确保最外层环可展开），色板行长度不超过该最小边距。

**规则**：
1. 读取色板行：从第 0 行左端开始，收集连续的非背景像素颜色序列 palette[0..k-1]。若序列内部有黑(0)像素，则保留为"透明（不画）"。
2. 以种子像素为中心，对切比雪夫距离 d = 0, 1, ..., k-1 的每一圈，用 palette[d] 绘制方环。d=0 即种子本身。
3. 令 bottom 为最外层环的最底行。对整个已绘制的图案（含种子和所有环层）执行剪切：每个像素 (r, c) 移至 (r, c + (bottom - r))。即底行不动，越往上的行向右偏移越多。
4. 超出网格右边界的像素舍弃。
5. 色板行和分隔行在输出中保留原样。

**关键洞察**：切比雪夫距离 d 既索引色板颜色又决定剪切前的环层半径，而剪切偏移量由行到底行的距离（与 d 相关但不相同）决定——两个距离概念交织但不等价，需同时追踪才能还原正确的输出。

## 新题 2：走廊门控邻域印章

**组合逻辑**：[射线延伸](已有) + [印章覆盖](创新——门控条件来自走廊连通性) + [重涂色](创新——印章颜色由走廊方向决定)

**来源原语**：射线延伸、对边连通、走廊、无阻挡跨行列涂色（参考题 2bee17df）；印章覆盖、邻域块、中心邻域、仅填背景格（参考题 f0df5ff0）；标记像素、忽略干扰项（参考题 a04b2602）

**依赖链**：每个标记像素向四方射线检测是否存在无阻挡走廊 → 走廊方向决定该标记是否激活及印章颜色 → 激活标记按中心邻域规则印章 → 走廊检测结果既过滤标记又决定印章颜色，删去走廊检测则无法确定哪些标记被印章、印什么颜色

将标记像素按其所在行列的走廊连通性分类，仅对拥有贯穿走廊的标记执行方向感知的彩色邻域印章。

**输入结构**：约 15x20 网格，背景为黑(0)。灰(5) 像素作为障碍物散布于网格中，不构成完整分隔线。红(2) 标记像素散布于网格中（约 4~8 个），互不相邻（任意两个标记之间曼哈顿距离 >= 3）。生成约束：至少有一个标记拥有纯水平走廊（同行中该标记左侧到第 0 列与右侧到最后一列之间全为黑(0)），至少有一个拥有纯垂直走廊，至少有一个两者皆有，至少有一个两者皆无。

**规则**：
1. 对每个红(2)标记像素，检查其所在行是否形成水平走廊：从标记位置向左延伸到第 0 列、向右延伸到最后一列，路径上是否全为黑(0)（标记自身除外）。同理检查垂直走廊（从标记位置向上到第 0 行、向下到最后一行）。
2. 若标记仅有水平走廊，将其 3x3 邻域中的黑(0)像素涂为绿(3)，标记本身保持红(2)。
3. 若标记仅有垂直走廊，将其 3x3 邻域中的黑(0)像素涂为蓝(1)，标记本身保持红(2)。
4. 若标记同时拥有水平和垂直走廊，将其 3x3 邻域中的黑(0)像素涂为黄(4)，标记本身保持红(2)。
5. 若标记没有任何走廊，将该标记从网格中擦除（变为黑(0)）。
6. 邻域中的灰(5)障碍物像素不受影响，保留原位。
7. 所有灰(5)障碍物在输出中保留原位。

**关键洞察**：走廊检测是全局的跨网格边缘连通性测试，但其结果驱动的是局部 3x3 印章操作；单看印章无法知道颜色由何决定，必须将走廊方向与印章颜色对应起来才能归纳规则。

## 新题 3：遮挡层序驱动的循环补色

**组合逻辑**：[堆叠](已有) + [排序](创新——排序键为遮挡深度) + [填充](创新——填充色由循环邻居决定) → 深度排序决定循环填色

**来源原语**：堆叠、排序、补全、遮挡层序、遮挡碎片、可见像素定边框（参考题 652646ff）；填充、循环相邻、空缺借邻色填充（参考题 c4d1a9ae）

**依赖链**：识别重叠矩形帧的可见碎片 → 从遮挡关系推断层序（谁覆盖谁）→ 按层序排列后确定循环邻居 → 每个帧的被遮挡缺口用其循环后继帧的颜色填充 → 层序同时决定绘制顺序和填充配色，删去层序推断则循环填色无从着手

分析重叠矩形帧的遮挡关系，排出深度层序，然后用深度循环中下一层帧的颜色填补每帧的被遮挡缺口。

**输入结构**：约 20x20 网格，背景为黑(0)。3~5 个不同颜色的空心矩形帧（单像素宽边框，内部为黑(0)），每个帧为 5x5 到 8x8 大小不等。帧之间存在部分重叠：重叠区域中，位于上层的帧的边框像素覆盖下层帧的边框像素。每个帧至少有一段边框完全可见以确定其颜色和边界框。生成约束：遮挡关系可拓扑排序为唯一的从顶到底线性序列（无循环遮挡、无并列层）。

**规则**：
1. 识别每个颜色对应的矩形帧：该颜色所有可见像素的边界框即为帧的完整范围，帧形状为该边界框的单像素宽空心矩形。
2. 确定遮挡层序：若帧 A 的边界框内某些应为 A 色的位置实际显示了帧 B 的颜色，则 B 在 A 之上。据此拓扑排序得到从顶层到底层的完整序列。
3. 按层序建立循环后继关系：顶层的后继为第二层，第二层的后继为第三层，……底层的后继为顶层（循环）。
4. 在输出中，从底层到顶层依次绘制完整的空心矩形帧（后绘制的覆盖先绘制的）。
5. 对每个帧，其被遮挡的缺口像素（即在完整帧中应存在但被上层帧覆盖的位置）用该帧的循环后继帧的颜色绘制，而非该帧自身的颜色。
6. 上层帧的正常边框像素最终覆盖任何下层的缺口填色（即标准绘制顺序不变，缺口填色只影响最终未被上层覆盖的位置）。

**关键洞察**：缺口填充的颜色不是帧自身的颜色而是深度序列中的循环后继色——这个映射关系无法从单个示例中确定（因为可能误以为缺口色来自覆盖者的颜色），需要对比多个示例中不同层序排列来归纳。

## 新题 4：方块计数决定环层尺寸

**组合逻辑**：[计数](已有) + [同心层填充](创新——环层尺寸由计数结果决定而非预设) + [排序](创新——排序键为计数值) + [完整方块过滤](已有)

**来源原语**：计数、完整方块、完整方块过滤、忽略干扰项（参考题 3b4c2228）；同心层填充、同心正方形层、嵌套层次、按边长降序排列（参考题 c658a4bd）

**依赖链**：识别并过滤出完整 2x2 方块（忽略不完整碎片）→ 按颜色分组计数 → 计数值映射为同心环的边长 → 按边长降序排列绘制嵌套同心环 → 删去计数步骤则环层尺寸无从确定；删去过滤步骤则计数不正确

统计各颜色完整 2x2 方块的数量，将计数值转化为同心方环的边长，输出按计数排序的嵌套同心环图案。

**输入结构**：约 15x15 网格，背景为黑(0)。3~4 种非背景颜色（如红(2)、蓝(1)、绿(3)）的像素散布于网格中。每种颜色既包含若干完整的实心 2x2 方块，也包含不构成 2x2 方块的孤立像素或 L 形碎片（干扰项）。不同颜色的对象互不接触（任意两个不同颜色的非背景像素不 4 连通）。生成约束：每种颜色的完整 2x2 方块数量互不相同，且每种颜色至少有 1 个完整方块，数量范围 1~4。

**规则**：
1. 对每种非背景颜色，找出所有 4 连通的单色区域。保留边界框恰好为 2x2 且面积恰好为 4 的区域（完整方块），忽略其余区域。
2. 统计每种颜色的完整方块数量 n。
3. 每种颜色对应一个同心方环，环的边长 = 2n + 1。
4. 输出网格的边长等于最大环的边长。
5. 按边长从大到小排列：最大环绘制为输出网格最外层边框（单像素宽），次大环居中绘制为内层边框，依此类推。最小环位于中心。
6. 每个方环只画单像素宽边框，内部由更小的环或中心色块填充。若最内层边长为 1，则为单个像素。
7. 未被任何环覆盖的区域保持黑(0)。

**关键洞察**：输出的几何结构（环的大小和嵌套顺序）完全由输入中特定形状的统计量决定——求解者必须先识别哪些对象是"完整方块"（过滤），再计数（统计），最后映射到空间结构（构造），三步紧密耦合。

## 新题 5：投射筛选后的分支追踪

**组合逻辑**：[压缩](创新——投射结果作为后续追踪的起点) + [射线延伸](已有) + [分支](已有) + [擦除](已有)

**来源原语**：压缩、引导条、散布像素、投射到引导条、投射落间隙则擦（参考题 f83cb3f6）；射线延伸、分支、边缘标记、墙段、从边缘推进、墙段开口分支（参考题 f9a67cb5）

**依赖链**：散布像素投射到引导条 → 落在间隙上的被擦除 → 存活的投射点成为射线起点 → 射线沿垂直于引导条的方向延伸 → 遇墙段时在开口处分支继续 → 投射筛选决定哪些位置发射射线，删去引导条则无法确定起点

将散布像素投射到引导条上（落入间隙者淘汰），幸存的投射点作为起点向引导条的垂直方向发射射线，遇断裂墙段时在开口处分支延伸。

**输入结构**：约 20x15 网格，背景为黑(0)。一条水平的橙(7)引导条位于网格中部偏上（约第 3~5 行），引导条覆盖大部分列但有 1~3 个单像素间隙（间隙处为黑(0)）。引导条下方散布着 3~6 个红(2)源像素，位于不同列，部分列与引导条间隙对齐、部分与引导条实体对齐。引导条下方还有 2~3 条水平的灰(5)墙段（单像素高，跨 3~6 列），墙段之间有 1~2 像素的间隙。生成约束：至少 2 个源像素可成功投射，至少 1 个因间隙被淘汰；至少有一条射线能到达一个墙段并在开口处分支。

**规则**：
1. 保留引导条和所有墙段在输出中不变。
2. 对每个红(2)源像素，检查其所在列上引导条是否有橙(7)像素。若有，该源像素"投射成功"；若该列上引导条为间隙（黑(0)），该源像素被擦除（变为黑(0)）。
3. 每个投射成功的源像素从引导条正下方一格开始，沿向下方向发射红(2)射线。
4. 射线逐格向下绘制红(2)，直到：(a) 遇到灰(5)墙段像素——在该墙段像素正上方一格停止（不覆盖墙段）；(b) 到达网格底边。
5. 当射线因墙段停止时，找到该墙段连续灰(5)像素段的两端。检查每一端沿墙段方向的下一列：若该位置为黑(0)（即开口），则从该开口位置的正下方一格开始，发射新的向下红(2)射线（分支）。
6. 分支射线遵循同样的规则（遇墙段可继续分支）。
7. 所有射线仅在黑(0)背景像素上绘制，不覆盖任何已有的非背景像素。

**关键洞察**：引导条同时扮演两个角色——投射目标（决定哪些源像素存活）和射线的起跑面（决定射线从哪里开始）；间隙在投射阶段淘汰源像素，在墙段中作为分支点，两种"间隙"概念在不同阶段发挥不同作用。

## 新题 6：面板叠加中的冲突多重性分支

**组合逻辑**：[透明叠加](已有) + [反转](创新——仅作用于三层全冲突区域) + [重涂色](创新——由冲突层数决定涂色规则) + [配对色映射](已有)

**来源原语**：透明叠加、等高面板、图层优先级、底层最优先（参考题 6a11f6da）；反转、重涂色、配对色映射（参考题 6ea4a07e）

**依赖链**：三面板叠加 → 逐像素统计冲突层数 → 单层无冲突保留原色 → 双层冲突取优胜色后执行配对色映射 → 三层冲突反转为背景色 → 冲突层数决定执行哪种操作（保留/映射/反转），删去冲突计数则无法选择正确的操作分支

将三个等高面板叠加，对每个像素根据参与冲突的面板数量执行不同操作：无冲突保留，双冲突配对变色，三冲突擦为背景。

**输入结构**：约 18x6 网格（高 18、宽 6），由三个等高面板纵向堆叠而成，每个面板 6x6。背景为黑(0)。三个面板分别使用以下颜色之一作为前景色：青(8)、绿(3)、灰(5)（每个面板只用一种前景色）。每个面板内前景像素构成一个 4 连通图形（3~12 像素），其余为黑(0)。三个面板的前景图形存在部分空间重叠（即若将三个面板叠放到同一个 6x6 区域，某些位置有多个面板的前景像素重合）。生成约束：至少存在一个位置仅有一个面板有前景，至少一个位置恰好两个面板有前景，至少一个位置三个面板都有前景。

**规则**：
1. 输出为一个 6x6 网格。三个面板从上到下标记为面板 A（顶）、面板 B（中）、面板 C（底）。
2. 对输出中的每个位置 (r, c)，统计三个面板中在该位置有前景像素的面板数量 k。
3. k = 0：输出黑(0)。
4. k = 1：输出该位置唯一有前景的面板的颜色，不做任何变换。
5. k = 2：在两个有前景的面板中，取层级更低（更靠底部）的面板的颜色作为"胜出色"。然后对胜出色执行配对色映射：青(8) -> 红(2)，绿(3) -> 蓝(1)，灰(5) -> 黄(4)。输出映射后的颜色。
6. k = 3：输出黑(0)（三层全冲突区域被擦除）。

**关键洞察**：同一个叠加操作的结果因冲突多重性不同而走向三条完全不同的处理路径——这不是简单的"谁覆盖谁"，而是冲突的参与者数量本身成为一个决策变量，改变输出的性质（保留、变色、擦除）。需要对比包含不同冲突组合的多个示例才能归纳出三条分支规则。

## 新题 7：拉直归一后按长度排序堆叠

**组合逻辑**：[拉直](已有) + [计数](已有) + [排序](创新——排序键为归一化后的长度) + [堆叠](创新——堆叠顺序由排序决定)

**来源原语**：拉直、计数、居中放置、保留颜色与面积（参考题 dce56571）；排序、距离优先排序（参考题 b5ca7ac4）；堆叠（参考题 652646ff）

**依赖链**：识别各颜色前景区域 → 计数每个区域的像素数 → 将每个区域拉直为水平线段（长度 = 像素数，颜色不变）→ 按线段长度降序排列 → 逐行堆叠到输出网格（最长在顶行）→ 拉直步骤消除了原始形状差异，使排序只能依赖计数结果

将输入中多个不规则前景区域分别拉直为水平线段，按线段长度从长到短逐行堆叠并居中对齐。

**输入结构**：约 12x12 网格，背景为黑(0)。3~5 个不同颜色的前景区域（如红(2)、蓝(1)、绿(3)、黄(4)），每个区域是一个 4 连通的单色不规则图形（3~10 像素），区域之间互不接触（不同颜色的非背景像素不 4 连通）。不同区域的像素数互不相同。生成约束：所有区域的像素数之和不超过输出网格的宽度（确保最长的线段能放入输出网格）。

**规则**：
1. 识别每个 4 连通的非背景单色区域，记录其颜色和像素数。
2. 将每个区域"拉直"为一条水平线段：长度等于该区域的像素数，颜色保持不变。
3. 按线段长度从长到短排序。若长度相同（生成约束排除此情况），按该区域在输入中最上方像素的行号升序排列（更靠上的排在前）。
4. 输出网格的宽度等于最长线段的长度，高度等于区域数量。
5. 从输出网格的第 0 行开始，依次放置排序后的线段。每条线段在其所在行水平居中（左右黑(0)边距相等；若无法完全居中，左侧边距 = floor((宽度 - 长度) / 2)）。
6. 未被线段覆盖的位置为黑(0)。

**关键洞察**：原始区域的具体形状完全无关紧要——唯一重要的是像素计数，而计数结果同时决定了线段长度和排序位置。求解者必须意识到不同示例中形状各异但同色区域的输出始终一致，才能归纳出"拉直 + 计数"这一核心操作。

## 新题 8：包含门控下的射线分区填充

**组合逻辑**：[区域填充](已有) + [射线延伸](创新——射线用于空间分区而非绘制路径) + [印章覆盖](创新——仅在门控区域内生效)

**来源原语**：区域填充、射线遮挡分区、多色长线段、处理顺序决定遮挡（参考题 1190bc91）；印章覆盖、标记像素、包含于边界框、仅处理区域内标记、忽略干扰项（参考题 a04b2602）；空心矩形（参考题 a04b2602）

**依赖链**：识别空心矩形帧的边界框 → 仅矩形内部的标记为有效标记（外部为干扰）→ 矩形顶边的多色像素发射垂直射线分割矩形内部为若干竖向子区域 → 每个有效标记填充其所在子区域 → 包含性测试过滤标记，射线划分决定填充范围，两者缺一不可

在空心矩形帧内部，顶边色带发射的垂直射线将内部分割为子区域，仅位于帧内的标记像素将其所在子区域填充为该标记的颜色。

**输入结构**：约 20x20 网格，背景为黑(0)。一个灰(5)空心矩形帧（单像素宽边框，约 12x14 大小），帧的顶边上间隔嵌有 2~4 个不同颜色的像素（如红(2)、蓝(1)、绿(3)），替换该位置的灰(5)。帧内部散布着若干标记像素，颜色为矩形帧内未使用的非背景色（如黄(4)、橙(7)），每个标记为单独一个像素。帧外部也有少量同色标记像素作为干扰项。生成约束：帧顶边的彩色像素将帧内部分割为的子区域中，每个子区域最多含一个有效标记；至少有一个子区域不含标记（保持为黑(0)）。

**规则**：
1. 识别灰(5)空心矩形帧及其边界框 (r1, c1, r2, c2)。
2. 收集帧顶边（第 r1 行）上所有非灰(5)非黑(0)的彩色像素位置，这些是"分割点"。
3. 从每个分割点向下发射垂直射线（用该分割点的颜色绘制），从第 r1+1 行开始，直到第 r2 行（帧底边）结束（包含 r2 行，覆盖底边该列的灰(5)像素）。
4. 这些垂直射线将帧内部划分为若干竖向子区域。子区域的左右边界为相邻射线列（或帧左/右边界内侧）之间的列范围，上下边界为帧内部行范围（r1+1 到 r2-1 行）。
5. 仅保留位于帧内部（行在 r1+1 到 r2-1 之间，列在 c1+1 到 c2-1 之间）的标记像素为有效标记，帧外部的标记像素全部擦除（变为黑(0)）。
6. 对每个有效标记，确定其所在的子区域（通过列位置判断其位于哪两条相邻射线之间），将该子区域内所有黑(0)像素填充为该标记的颜色。标记自身保留。射线像素不被覆盖。
7. 没有有效标记的子区域保持黑(0)不变。
8. 帧边框保持灰(5)不变（除被射线覆盖的顶边和底边像素外）。

**关键洞察**：帧顶边的彩色像素扮演双重角色——它们的颜色本身不参与区域填充，但它们的位置决定了射线分割线从而间接控制了标记像素的填充范围。移除任何一条射线都会合并两个子区域，完全改变填充结果。

## 新题 9：边缘填充后的色控迁移

**组合逻辑**：[边缘填充](已有) + [平移](创新——目标边缘由颜色决定) + [像素放大](创新——填充等效于局部放大) + [排序](创新——碰撞处理引入距离排序)

**来源原语**：边缘填充、边缘行列、复制扩展、角像素双向扩展（参考题 e633a9e5）；平移、排序、边框方块、网格边缘、颜色决定目标、行重叠内移、距离优先排序（参考题 b5ca7ac4）；像素放大（参考题 0692e18c）

**依赖链**：识别各小精灵及其颜色 → 对每个精灵执行一层边缘填充扩展（3x3 变 5x5）→ 颜色决定目标边缘 → 按距目标边缘的距离排序处理迁移 → 行/列重叠时内移一个精灵宽度 → 边缘填充改变精灵尺寸从而改变碰撞检测范围，删去填充步骤则碰撞判断不同

将散布的小精灵先做一层边缘填充扩展，再按颜色将扩展后的精灵迁移到对应网格边缘，碰撞时近边者优先、远者内移。

**输入结构**：约 20x20 网格，背景为黑(0)。4~6 个单色小精灵散布于网格中，每个精灵为 3x3 区域内的非背景色图案（不全填满，至少有 1 个黑(0)内部像素使得精灵有"形状"），精灵之间互不相邻（任意两个精灵的 3x3 边界框不重叠且不相邻）。精灵颜色仅从以下四色中选取：蓝(1)、红(2)、绿(3)、黄(4)。同一颜色可出现在多个精灵上。生成约束：每种颜色至少出现一次。

**规则**：
1. 对每个 3x3 精灵执行一层边缘填充：将该精灵置于 5x5 区域的中心 3x3 位置，顶行复制精灵的第一行到第 0 行，底行复制精灵的最后一行到第 4 行，左列复制精灵的第一列到第 0 列，右列复制精灵的最后一列到第 4 列，四角像素由对应的精灵角像素填充（即精灵左上角像素同时填充到新区域的 (0,0)、(0,1)外侧、(1,0)外侧三处——实际为复制该行和该列时自然覆盖）。填充像素使用精灵自身的颜色（若原精灵该位置为黑(0)，则填充也为黑(0)）。精灵扩展后尺寸变为 5x5。
2. 按颜色确定每个扩展精灵的目标边缘：蓝(1) -> 左边缘（精灵左边对齐第 0 列），红(2) -> 右边缘（精灵右边对齐最后一列），绿(3) -> 上边缘（精灵上边对齐第 0 行），黄(4) -> 下边缘（精灵下边对齐最后一行）。
3. 迁移时保持精灵在非目标方向上的原始中心坐标不变（例如蓝色精灵水平平移到左边缘时，保持原始行位置不变）。
4. 对每种颜色的精灵，按原始位置到目标边缘的距离升序处理（离得近的先放置）。距离定义为精灵 3x3 边界框的对应边到目标边缘的像素距离。
5. 放置精灵时，若其 5x5 区域与已放置在同一边缘的精灵在平行于边缘方向上的行/列范围有重叠（任一行或列存在公共范围），则将该精灵沿垂直于边缘方向向内偏移 5 像素（一个精灵宽度）。
6. 不同边缘的精灵互不干扰（即使最终位置重叠，按左 -> 右 -> 上 -> 下的边缘顺序依次绘制，后绘制的覆盖先绘制的）。
7. 输出网格尺寸与输入相同。

**关键洞察**：边缘填充步骤将 3x3 精灵扩展为 5x5，这不仅改变了精灵的外观，还扩大了碰撞检测的范围——两个原本行距足够的精灵在扩展后可能产生行重叠，从而触发内移逻辑。扩展操作与碰撞规则之间的这种尺寸依赖是需要跨示例归纳的隐蔽规则。
