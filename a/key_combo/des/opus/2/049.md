## 新题 1：折叠制造邻接驱动重涂色

**组合逻辑**：[折叠/fold] → 产生新空间邻接 → [邻接传色/adjacency_transfer](创新：源题中邻接关系是输入中已存在的，此处邻接关系由折叠操作动态产生) → [重涂色/recolor](创新：涂色触发依赖折叠后几何位置，而非输入中的静态邻接)

**来源原语**：fold、端点标记/endpoint_marker、铰接标记/hinge_marker、固定端与活动端/fixed_vs_free、空间大侧折入/fold_toward_space（来自 230f2e48）；邻接传色/adjacency_transfer、标记接触即赋色/marker_touch_color、中性遮罩/neutral_mask、重涂色/recolor（来自 b7256dcd）

**依赖链**：折叠方向由铰接点到网格边界的空间决定 → 折叠改变自由段的空间位置 → 新位置产生源输入中不存在的邻接关系 → 该邻接关系驱动中性区域的重涂色 → 多折叠段冲突时由折叠段长度决定优先级。删除折叠环节则无法知道哪些邻接关系存在；删除重涂色规则则折叠操作无意义。

将带铰接点的彩色直线杆折叠后，利用折叠产生的新邻接关系对周围的中性区域进行涂色。

**输入结构**：黑(0)背景，约 12x14 网格。包含以下元素：
- 2~3 根直线杆，每根由 5~7 个像素组成，水平或垂直排列，主体为同一非黑色（各杆颜色互不相同，从红(2)、蓝(1)、绿(3)中选取）。每根杆的一端有一个灰(5)像素作为固定端标记，杆身内部（非端点）有一个黄(4)像素作为铰接标记，其余像素为杆的主体色。
- 3~4 个小型不规则橙(7) 4-连通区域（每个 3~5 像素），散布在网格中，与所有杆不相邻（间距至少 1 像素）。
- 生成约束：各杆互不相邻；每根杆折叠后，其自由段最多能 4-邻接到 2 个橙色区域；任意橙色区域最多被 2 根杆的折叠段同时邻接（且此时两段长度不同，保证无歧义）。

**规则**：
1. 对每根杆，识别固定段（从灰(5)端点标记到黄(4)铰接标记的所有像素，含两端）和自由段（铰接标记另一侧的所有主体色像素）。
2. 将自由段从原位置擦除（设为黑(0)）。
3. 以铰接标记为旋转中心，将自由段旋转 90 度重新绘制。旋转方向的选择：沿两个可能的垂直方向分别计算从铰接点到最近网格边界的距离，选距离更大（空间更多）的方向。若两方向距离相等，选顺时针方向。
4. 所有杆折叠完成后，检查每个橙(7)区域是否与某根杆的**自由段（折叠后的新位置）**存在 4-邻接。固定段不参与邻接判定。
5. 若某橙色区域仅与一根杆的折叠段 4-邻接，将该橙色区域整体重涂为该杆的主体色。
6. 若某橙色区域与零根杆的折叠段邻接，保持橙(7)不变。
7. 若某橙色区域同时与两根杆的折叠段邻接，重涂为折叠段像素数更多（更长）的那根杆的主体色。

**关键洞察**：折叠方向取决于空间上下文（铰接点周围哪侧更开阔），折叠后产生的邻接关系在输入中并不存在。不先计算折叠结果就无法判断哪些中性区域会被涂色。

## 新题 2：双面板交集定位对角射线源

**组合逻辑**：[透明叠加/transparent_overlay](保留) → 集合分类（创新：源题仅取并集，此处区分交集与对称差） → [射线延伸/ray_extend](创新：射线源不是输入中的孤立像素，而是叠加运算的交集结果) + [按原色区分涂色/recolor_by_origin](创新：源题中按路径上原色分涂，此处射线穿越不同类别区域时变色)

**来源原语**：透明叠加/transparent_overlay、分隔行/divider_row、二值掩码/binary_mask、双面板对齐/dual_panel_alignment、任一前景即输出/either_foreground_yields_output（来自 506d28a5）；射线延伸/ray_extend、对角放射/diagonal_radiation、延伸至边界/extend_to_edge（来自 ea786f4a）；按原色区分涂色/recolor_by_origin（来自 bcb3040b）

**依赖链**：双面板叠加产生两类像素（交集与对称差） → 交集像素成为射线源 → 对称差像素成为射线阻挡物 → 射线的长度和方向由阻挡物位置决定。叠加的分类结果同时决定了射线的起点和终点，两个逻辑无法独立求解。

将分隔线两侧的两个掩码叠加，交集像素发射对角射线，对称差像素阻挡射线。

**输入结构**：黑(0)背景，约 7x15（高瘦）网格。
- 一条贯穿全宽的灰(5)分隔行位于网格纵向中央，将网格分为形状相同的上下两个面板。
- 上面板：若干蓝(1)前景像素散布在黑(0)背景上，形成一个二值掩码。前景像素数量约 5~10 个，不构成简单几何形状。
- 下面板：若干红(2)前景像素散布在黑(0)背景上，形成另一个二值掩码。像素数量与上面板类似。
- 生成约束：两面板至少有 2 个位置同时为前景（交集非空），且至少有 3 个位置仅在一个面板中为前景（对称差非空）。交集像素互不 4-邻接（保证射线方向无歧义）。

**规则**：
1. 移除灰(5)分隔行。将上下面板按位置逐像素对齐比较。
2. 输出网格尺寸与单个面板相同。
3. 两面板对应位置均为前景的像素（交集）在输出中标记为绿(3)。
4. 仅在一个面板中为前景的像素（对称差）在输出中标记为黄(4)。
5. 两面板对应位置均为背景的像素保持黑(0)。
6. 从每个绿(3)像素出发，沿四个对角方向（左上、右上、左下、右下）延伸射线。
7. 射线像素着绿(3)色。射线在以下情况停止（不含停止点）：遇到黄(4)像素、遇到另一条射线已绘制的绿(3)像素、或到达网格边界。
8. 绘制顺序：按绿(3)源像素的行优先（从上到下）、列次优先（从左到右）顺序依次处理。

**关键洞察**：叠加操作不是简单取并集，而是将像素分为"交集"和"对称差"两类——前者成为射线发射源，后者成为射线阻挡壁。仅看单个示例可能无法确定射线遇到黄色像素时是停止还是穿越，必须对比多个示例验证阻挡规则。

## 新题 3：去重还原精灵体后计数驱动平铺

**组合逻辑**：[压缩/compress + 去重/deduplicate](保留) → 还原隐藏精灵体 → [计数/counting](创新：计数对象不是输入像素，而是压缩后才可见的精灵体像素) → [平铺/tile](创新：平铺内容和参数均由压缩结果决定，而非直接从输入读取)

**来源原语**：压缩/compress、去重/deduplicate、相邻重复/adjacent_repeat、合并相同行列/merge_identical_row_col（来自 e1baa8a4）；计数/counting、平铺/tile、精灵体/sprite、阵列排布/array_layout、像素数定尺寸数/pixel_count_sets_size_copies（来自 91413438）

**依赖链**：输入是拉伸膨胀的网格 → 去重还原真实精灵体 → 精灵体的前景/背景像素数分别控制平铺副本数和画布槽位数 → 不压缩就无法得知精灵体的真实形状和像素统计，三步逻辑环环相扣。

输入是一个被行列重复膨胀的网格；去重压缩还原出真实精灵体，再用精灵体自身的像素统计决定平铺布局。

**输入结构**：一个约 9x9 至 15x15 的全彩网格（无黑色背景可见），由 2~4 种颜色构成。
- 该网格是一个更小的隐藏精灵体（3x3 或 4x4）经行列不等量重复膨胀而成：隐藏精灵体的每一行被复制了 k_i 次（k_i 在 1~4 之间，不同行可以不同），每一列被复制了 l_j 次（l_j 在 1~4 之间，不同列可以不同）。
- 隐藏精灵体包含黑(0)背景像素和恰好一种非黑前景色像素。
- 生成约束：隐藏精灵体中前景像素数 F 和背景像素数 B 满足 F >= 2，B >= 4（保证画布足够大且至少放 2 份副本）。精灵体为正方形（行列数相同）。

**规则**：
1. 对输入网格执行行列去重：将所有最大相同相邻行段合并为单行，将所有最大相同相邻列段合并为单列。结果即为隐藏精灵体。
2. 统计精灵体中非黑前景像素数 F 和黑(0)像素数 B。
3. 构建一个黑(0)输出画布，大小为 (B x 精灵体行数) x (B x 精灵体列数) 像素。画布被逻辑划分为 B x B 个槽位，每个槽位大小等于精灵体尺寸。
4. 按行优先顺序（从左上到右下），将精灵体原样复制到前 F 个槽位中。剩余槽位保持全黑。

**关键洞察**：精灵体隐藏在膨胀网格中，不执行去重就无法获得精灵体的真实形状和像素计数。压缩结果同时提供了平铺的内容（精灵体本身）、画布尺寸（B）和副本数量（F），三者缺一不可。

## 新题 4：掏空实心矩形以揭示旋转指令

**组合逻辑**：[掏空/hollowing](创新：掏空不是终态变换，而是信息提取手段——暴露被实心填充遮蔽的标记像素) → 解码标记颜色 → [旋转/rotate](创新：旋转角度不是固定的，由掏空后暴露的标记颜色编码) + [擦除/erase](保留：标记作为控制信号被消耗后擦除)

**来源原语**：掏空/hollowing、实心矩形/solid_rectangle、边框/frame、保留边擦除内部/keep_border_erase_interior、内部包含/interior_containment（来自 4347f46a）；旋转/rotate、象限/quadrant、四象限各不同旋转/quadrant_rotation（来自 cf5fd0ad）；标记像素/marker_pixel、标记色定窗口填充/marker_sets_window_fill（来自 54d9e175，创新改造为"标记色定旋转角度"）；擦除/erase（来自 fd02da9e）

**依赖链**：实心矩形遮蔽了中心标记 → 掏空操作暴露标记 → 标记颜色编码旋转角度 → 各象限按各自标记指示独立旋转 → 标记被擦除，不留在输出中。掏空是不可跳过的信息提取步骤，不掏空就看不到旋转指令。

掏空四个实心矩形以暴露被遮蔽的中心标记像素，读取标记颜色确定各象限的旋转角度，旋转后擦除标记。

**输入结构**：黑(0)背景，网格大小为 (2H+1) x (2W+1)，其中 H 和 W 均至少为 3（典型值 5~7，总网格约 11x11 至 15x15）。
- 四个蓝(1)实心矩形，每个大小为 H x W，排成 2x2 阵列，矩形之间有一行和一列黑(0)间隔。具体位置：左上矩形占据行 [0, H-1] 列 [0, W-1]，右上矩形占据行 [0, H-1] 列 [W+1, 2W]，左下矩形占据行 [H+1, 2H] 列 [0, W-1]，右下矩形占据行 [H+1, 2H] 列 [W+1, 2W]。
- 每个矩形的几何中心位置有一个非蓝像素（中心标记），被蓝色填充完全包围因而不可见。四个标记分别使用红(2)、绿(3)、黄(4)、橙(7)中的四种颜色，各出现恰好一次（四个矩形分配四种不同颜色）。
- 颜色到旋转角度的映射：红(2) = 0 度（不旋转），绿(3) = 顺时针 90 度，黄(4) = 180 度，橙(7) = 逆时针 90 度。

**规则**：
1. 对每个蓝(1)实心矩形执行掏空：将其严格内部（不在矩形周长上）的蓝(1)像素全部设为黑(0)。内部的非蓝像素（即中心标记）保留不动。掏空后每个矩形变为蓝色空心框，中心标记在框内部的黑色背景上可见。
2. 读取每个矩形内暴露的标记颜色，按照映射表确定该象限的旋转角度。
3. 定义四个象限区域：左上象限 = 行 [0, H] 列 [0, W]（含间隔行列的一半），右上象限 = 行 [0, H] 列 [W+1, 2W+1-1]，左下象限 = 行 [H+1, 2H+1-1] 列 [0, W]，右下象限 = 行 [H+1, 2H+1-1] 列 [W+1, 2W+1-1]。间隔行/列各归入相邻的上方/左方象限。
4. 以每个象限的中心为旋转中心，将该象限内的所有像素（空心框 + 标记 + 黑色背景）按其标记指示的角度旋转。
5. 旋转完成后，将所有标记像素（红/绿/黄/橙）擦除为黑(0)。标记仅作为控制信号使用，不出现在最终输出中。

**关键洞察**：掏空不是终态变换而是信息提取——实心填充物理性地遮蔽了旋转指令，必须先掏空才能读取。标记颜色到旋转角度的映射需要对比多个示例才能归纳（单个示例无法确认四种映射关系）。

## 新题 5：路径编码位移与种子计数联合决定环-框交叉图案

**组合逻辑**：[端点编码位移/endpoints_encode_disp → 平移/translate](保留) + [计数/counting → 生长/grow](创新：生长环数由种子计数决定，而非种子间距) → 几何交叉分类涂色（创新：环与平移后框架的空间交叠产生第三种颜色，这种交叉涂色在源题中不存在）

**来源原语**：平移/translate、空心框/hollow_frame、路径端点/path_endpoint、端点编码位移/endpoints_encode_disp（来自 2b9ef948）；生长/grow、种子像素/seed_pixel、同心方框层/concentric_layer、等距对角排列/equi_diag_array（来自 5c2c9af4）；计数/counting（来自 b0c4d837/91413438）；按原色区分涂色/recolor_by_origin（来自 bcb3040b，创新改造为"按空间归属区分涂色"）

**依赖链**：灰色路径的两个彩色端点编码位移向量 → 框架按该向量平移到新位置 → 种子像素计数决定同心环层数 → 环在生长过程中与平移后框架产生空间交叠 → 交叠像素变为第三种颜色。位移决定框架落点，计数决定环的规模，两者共同决定交叠图案——是一个扇入结构而非线性流水线。

解码路径端点获得位移向量平移框架，同时从种子计数获得环层数生长同心环，环与框架交叠处变色。

**输入结构**：黑(0)背景，约 15x15 网格。
- 一个 3x3 黄(4)空心框（8 个黄色像素围成正方形边框），中心为红(2)像素。
- 在网格其他位置有第二个红(2)像素，通过一串灰(5)像素连接到一个孤立的黄(4)像素。灰色路径可以有转弯，但连通的两个彩色端点（红与黄）的相对位置编码了位移向量。
- 2~4 个蓝(1)种子像素散布在网格中，互不相邻，且不在灰色路径上，不与框架重叠。
- 生成约束：位移向量使框架平移后仍完全在网格内。种子像素的数量 S 满足 S >= 2。框架平移后的位置至少与一个种子的第 S 层同心环有重叠。

**规则**：
1. 找到第二个红(2)像素（不在 3x3 框架中心的那个）和孤立黄(4)像素（不属于 3x3 框架的那个）。计算位移向量 D =（孤立黄的行 - 第二红的行，孤立黄的列 - 第二红的列）。
2. 擦除灰(5)路径像素、第二个红(2)像素和孤立黄(4)像素（设为黑(0)）。
3. 将 3x3 黄(4)框架（含红色中心）整体平移向量 D。原位置擦除为黑(0)，新位置绘制。若新位置与种子像素重叠，框架像素覆盖种子像素。
4. 统计蓝(1)种子像素数量 S。
5. 从每个蓝(1)种子像素出发，绘制 S 层同心正方形环边框。第 k 层环（k = 1, 2, ..., S）是以该种子为中心、Chebyshev 距离恰好为 k 的所有像素构成的正方形边框，颜色为蓝(1)。
6. 若某个蓝色环像素与平移后的黄(4)框架边框像素位置重合，该像素涂为绿(3)。
7. 若不同种子的环相互重叠，重叠像素仍为蓝(1)（不变色）。仅环与框架的交叠产生绿色。
8. 框架的红(2)中心像素不参与交叠判定，保持红色。

**关键洞察**：位移向量和种子计数是两个独立信息源，分别控制框架落点和环的规模，但最终输出图案取决于两者的几何交叉——这是一个扇入汇合结构。仅看输出的绿色像素位置，需要同时逆推位移和环层数才能理解规则。

## 新题 6：角落模板印章构成反射屏障

**组合逻辑**：[印章覆盖/stamp_overlay + 角落位置选模板/corner_selects](保留) → 构建空间屏障 → [镜像/reflect](创新：反射不是无条件的全面板翻转，而是被印章模板部分遮挡/过滤的受限反射)

**来源原语**：印章覆盖/stamp_overlay、角落标记/corner_marker、固定模板/fixed_template、角落位置选模板/corner_selects、标记色传递给模板/marker_color_pass、擦除/erase（来自 fd02da9e）；镜像/reflect、画布/canvas、纵向拼接/vertical_stacking、对称翻转追加/symmetric_appending_reversed_rows（来自 8be77c9e）

**依赖链**：角落标记决定哪些角落有模板印章 → 印章绘制在网格中形成不透明区域 → 上半区图案向下反射时，与印章区域发生冲突 → 印章像素阻挡反射像素（印章不被覆盖） → 最终图案是反射图案与印章图案的空间博弈结果。删除印章逻辑则反射完整；删除反射逻辑则仅有印章。

在角落印章构建的不透明屏障之上，将上半区图案向下反射，被屏障遮挡的反射像素被抑制。

**输入结构**：黑(0)背景，8x8 网格。
- 2~3 个角落位置（四个角中选 2~3 个）各有一个彩色标记像素。标记颜色各不相同，从红(2)、蓝(1)、绿(3)、橙(7)中选取。
- 上半区（第 0~3 行）包含一个由品红(6)像素构成的小型不规则 4-连通图形（3~6 像素），不接触网格边缘，不与角落标记位置重叠。
- 下半区（第 4~7 行）初始为全黑（除可能存在的角落标记外）。
- 角落位置的固定模板定义（与 fd02da9e 一致但适配 8x8）：
  - 左上角 (0,0)：在 (1,1)、(1,2)、(2,1)、(2,2) 绘制 2x2 方块。
  - 右上角 (0,7)：在 (1,5)、(1,6)、(2,5)、(2,6) 绘制 2x2 方块。
  - 左下角 (7,0)：在 (6,1)、(5,1)、(6,2) 绘制 3 像素弯折。
  - 右下角 (7,7)：在 (6,6)、(5,6)、(6,5) 绘制 3 像素弯折。
- 生成约束：上半区图形的反射像素至少有 1 个会与某个印章模板位置重合（保证屏障效果可观察），且至少有 2 个反射像素不与印章重合（保证反射效果可观察）。

**规则**：
1. 对每个角落标记像素：擦除标记（设为黑(0)），按角落位置选取对应模板，用该标记的颜色绘制模板图案。
2. 生成上半区品红(6)图形的垂直镜像（行顺序翻转），映射到下半区对应位置。具体地：上半区第 r 行的图形像素映射到第 (7 - r) 行的同列位置。
3. 逐像素放置反射图形：若目标位置为黑(0)（空），则放置品红(6)像素；若目标位置已被印章模板像素占据，则反射像素被抑制（不放置），印章像素保留。
4. 上半区的原始品红图形保留不动。

**关键洞察**：角落印章不仅是装饰，它们构成了反射操作的空间屏障。不同角落标记的组合产生不同的屏障布局，从而选择性地阻挡反射图案的不同部分。需要对比多个示例才能确认屏障的阻挡规则（是反射被抑制还是反射覆盖印章）。

## 新题 7：色匹配对接后奇偶环扩展与互斥阻断

**组合逻辑**：[对接/dock + 色彩互换/color_swap](保留) → 确定环的起点和颜色 → [生长/grow + 奇偶距离决定填色/parity_distance_fill](创新：环的颜色不来自固定角落标记而来自对接后的色彩互换结果) → 环间互斥阻断（创新：不同源的环相遇时停止生长，产生类似最近归属的领地划分效果）

**来源原语**：对接/dock、色彩互换/color_swap、双色精灵体/two_tone_sprite、色条/color_bar、同色匹配/same_color_matching、颜色反转映射/inverted_color_mapping（来自 7c66cb00）；生长/grow、同心环/concentric_ring（来自 5c2c9af4）；奇偶距离决定填色/parity_distance_fill（来自 d22278a0）；最近归属/nearest_ownership（来自 d22278a0，创新改造为"环扩展时的领地互斥"）

**依赖链**：精灵体的外色匹配目标色条 → 对接确定环的空间起点 → 色彩互换确定环的绘制颜色 → 奇偶距离决定哪些环层实际绘制 → 不同精灵体的环相遇时停止，产生领地边界。对接结果同时决定环的位置、颜色和相互阻断格局。

双色精灵体对接到色匹配的色条中，对接点成为同心环的生长中心，环以奇偶距离交替绘制，不同来源的环互斥阻断形成领地。

**输入结构**：黑(0)背景，约 15x20（宽 15 高 20）网格。
- 上区（约前 5 行）：2~3 个双色小精灵体，每个为 3x3 大小，由外色（外圈 8 像素）和内色（中心 1 像素）构成。各精灵体的外色互不相同。精灵体之间水平间隔至少 2 列。
- 下区（约第 7 行起至底部）：2~3 条水平色条，每条横跨网格大部分宽度（至少 10 列），高 3 行。每条色条有一个填充色（中间行的颜色）和一个边界色（上下边缘行的颜色）。各色条之间垂直间隔 1~2 行黑色。各色条的填充色互不相同。
- 匹配关系：每个精灵体的外色恰好等于某条色条的填充色（一一对应，无重复匹配）。
- 生成约束：精灵体数量等于色条数量。精灵体在上区的列位置在对接后不会超出色条的列范围。

**规则**：
1. 将每个精灵体匹配到填充色等于该精灵体外色的色条。
2. 对接：将精灵体从上区移除（擦除为黑(0)），放置在对应色条的顶行位置，列坐标保持精灵体原来的列位置不变。对接后精灵体的底行与色条的顶行对齐。
3. 色彩互换：对接后的精灵体外色变为对应色条的边界色，精灵体内色变为色条的填充色。
4. 以每个对接后精灵体的中心像素为圆心，向外生长同心正方形环。环的颜色为该精灵体互换后的内色（即色条填充色）。
5. 仅绘制 Chebyshev 距离为偶数的环层（距离 2, 4, 6, ...）。奇数距离层跳过（保持黑色或已有颜色不变）。
6. 环的生长在以下情况停止：到达网格边界；或环层的某个像素会进入另一个精灵体的环已占据的区域（不同来源的环互斥，先绘制的占据优先）。绘制顺序：按精灵体对接后中心像素的列坐标从左到右处理。
7. 环像素不覆盖色条本身的像素（色条像素优先保留）。

**关键洞察**：对接操作决定了环的空间起点，色彩互换决定了环的颜色，而奇偶规则和互斥阻断共同塑造了最终的环状领地图案。需要多个示例才能归纳出偶数层绘制、奇数层跳过的隐蔽规则，以及不同环之间的互斥优先级机制。

## 新题 8：缩放后掏空再画线穿越分区涂色

**组合逻辑**：[计数/counting → 像素放大/pixel_scaling](保留) → [掏空/hollowing](创新：掏空对象是缩放后的放大矩形，而非输入中的原始矩形) → [连线/draw_line + 按原色区分涂色/recolor_by_origin](创新：线段穿越掏空后产生的不同区域时根据所在区域着色，三种操作的结果相互交织才确定最终颜色)

**来源原语**：像素放大/pixel_scaling、色数决定缩放/color_count_sets_scale、边界色带/border_color_strip（来自 469497ad）；掏空/hollowing、实心矩形/solid_rectangle、保留边擦除内部/keep_border_erase_interior（来自 4347f46a）；连线/draw_line、标记像素/marker_pixel、两点直线路径/straight_two_point、按原色区分涂色/recolor_by_origin（来自 bcb3040b）

**依赖链**：边界色带的颜色数决定缩放因子 → 缩放放大整个网格（含矩形和标记） → 放大后矩形被掏空产生"边框区"和"内部空腔" → 两标记之间画线 → 线段像素的颜色由其穿越的区域决定（内部空腔/边框/背景各对应一种颜色）。缩放改变矩形尺寸从而改变掏空后的空腔面积和边框宽度，间接改变线段的颜色分布。

缩放整个网格后掏空放大的矩形，再在两标记间画线，线段像素根据穿越的空间区域分别着色。

**输入结构**：黑(0)背景，约 6x6 至 8x8 小网格。
- 一个蓝(1)实心矩形，至少 2x2（缩放后至少 3x3 以保证有内部）。矩形不接触网格边缘。
- 两个红(2)标记像素，位于矩形外部，位于同一水平线、垂直线或 45 度对角线上（queen-move 路径），且该路径穿过蓝色矩形。
- 底行和/或右列有若干彩色像素（边界色带），使用区别于黑、蓝、红的颜色（如灰(5)、黄(4)、绿(3)等），每种颜色至少 1 个像素。
- 生成约束：两个红色标记的连线路径必须穿过蓝色矩形（经过矩形的边框和内部）。矩形在缩放后每个维度至少 3 像素（保证掏空后有内部空腔）。

**规则**：
1. 统计网格中所有不同的非黑颜色数量（包含蓝、红和边界色带中的颜色） → 缩放因子 S。
2. 将整个网格按因子 S 放大：每个像素变为 S x S 的同色方块。
3. 在放大后的网格中，对蓝(1)实心矩形执行掏空：保留矩形的 1 像素宽周长边框为蓝(1)，将严格内部的蓝色像素设为黑(0)。
4. 沿两个红(2)标记（缩放后每个标记变为 S x S 方块，取方块中心像素作为端点）之间的直线路径逐像素画线。路径方向与原始输入中两个标记的相对方位一致（水平/垂直/45度对角线）。
5. 路径上每个像素的颜色由该像素在画线前所处的区域决定：
   - 若该位置原为黑(0)背景 → 线段像素涂红(2)。
   - 若该位置原为蓝(1)边框像素 → 线段像素涂黄(4)。
   - 若该位置原为掏空后的内部空腔（黑(0)，但在矩形边框围成的内部区域内） → 线段像素涂绿(3)。
6. 路径上的红(2)标记像素本身保持红色。

**关键洞察**：线段穿越的三种空间区域（外部背景、矩形边框、矩形内腔）各自映射到不同颜色，但"内腔"区域只有在缩放+掏空之后才存在——未缩放时矩形可能无内部空间，未掏空时内部仍为蓝色。需要对比多个示例才能区分"外部黑色背景"和"内部空腔黑色"的不同涂色规则。
