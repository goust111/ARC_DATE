## 新题 1：障碍绕行的同心波纹

**组合逻辑**：[同心层填充](创新：距离度量从切比雪夫距离改为绕障碍的 BFS 最短路径距离) + [障碍块](从射线碰撞语境移植为距离传播的阻断体) + [按距离循环配色](已有) + [擦除](已有，清除障碍块的原始颜色)

**来源原语**：同心层填充、按距离循环配色(a3f84088)；障碍块、碰撞停止(e87109e9)；空心矩形(a3f84088)；擦除(93c31fbe)

**依赖链**：障碍块的位置改变了每个内部像素到边框的最短路径距离，使同心层不再是几何同心环而是沿障碍弯曲的 BFS 波前。距离场和颜色循环紧耦合——去掉障碍，距离场退化为标准切比雪夫距离，产生不同的着色结果；去掉距离循环，无法为波前上色。

将空心矩形框内部按绕开障碍的最短路径距离涂上循环色带，障碍块本身被擦除。

**输入结构**：约 15x15 的黑(0)背景网格。中央有一个单像素厚的灰(5)空心矩形框（边长约 11~13），内部除黑(0)背景外散布 2~4 个橙(7)障碍块（每个障碍块是 1x1 至 2x2 的实心小方块，4-连通，不紧贴框边）。框外全为黑(0)。不同示例中障碍块的数量、大小和位置不同，但均在框内部且不接触框边。

**规则**：
1. 保留灰(5)框边不变。
2. 对框内部每个像素，计算其到最近框边像素的 4-连通 BFS 最短路径距离，路径不能经过障碍块像素（障碍块视为不可通行）。
3. 按该 BFS 距离 d 循环配色：d mod 4 == 1 时涂灰(5)，d mod 4 == 2 时涂红(2)，d mod 4 == 3 时涂灰(5)，d mod 4 == 0 时涂黑(0)。
4. 障碍块像素本身被擦除为黑(0)。
5. 框外像素保持黑(0)不变。
6. 生成约束：障碍块不会完全封死任何内部像素到框边的通路（即所有内部非障碍像素均可达框边）。

**关键洞察**：同心环在没有障碍时是标准的几何嵌套正方形层；障碍的存在使"距离"变为路径距离，波纹绕障碍弯曲，需通过对比多个示例（不同障碍位置）才能确认距离度量是 BFS 而非切比雪夫。

## 新题 2：密铺拼合后的标签交叉掩码

**组合逻辑**：[平移/无重叠拼合](已有) + [行列交叉/标签同色时填充](创新：标签相等性不再决定是否填充某格，而是作为可见性掩码应用于已拼合的图形上) + [重涂色](已有)

**来源原语**：平移、无重叠拼合、互补拼合、最密堆叠最小框(681b3aeb)；行标签、列标签、行列交叉、标签同色时填充(a406ac07)；重涂色(a8610ef7)

**依赖链**：拼合步骤决定两块拼图在画布上的位置；位置决定每个拼图像素对应哪一行标签和哪一列标签；标签是否匹配决定该像素是否保留颜色。拼合改变了像素与标签的对齐关系，去掉拼合就无法确定哪些像素被掩码保留；去掉标签掩码则无法完成最终着色。

将两块互补拼图拼到最密排列，再用行列标签的相等性决定拼合体上哪些像素可见。

**输入结构**：约 12x12 的黑(0)背景网格。最右列为行标签列，每行一个着色像素（颜色取自红(2)、蓝(1)、绿(3)中的某个），最底行为列标签行，每列一个着色像素（同色域）。行标签列与列标签行的右下角交汇格为黑(0)。网格内部（排除标签行列后的区域约 11x11）包含两个不同单色的 4-连通拼图块：一个蓝(1)，一个绿(3)，各约 6~12 像素，形状不规则但互补（来自同一密铺分割）。两块在输入中分离放置，互不相邻。不同示例中拼图块形状不同，标签颜色序列不同。

**规则**：
1. 在排除标签行列后的内部区域中，找到两个拼图块的最密平移拼合：尝试所有非重叠平移组合，选使裁剪后边界框中黑(0)空格最少的排列。若有多个同密度方案，选边界框面积最小的；若仍平手，选边界框左上角坐标字典序最小的。
2. 将拼合结果放置在内部区域的左上角。
3. 对拼合结果中的每个非黑(0)像素，读取其所在行的行标签颜色和所在列的列标签颜色。若两者相同，该像素保留其原色（蓝(1)或绿(3)）；若两者不同，该像素涂为灰(5)。
4. 内部区域中拼合边界框之外的像素保持黑(0)。
5. 标签行列保持不变。

**关键洞察**：拼合操作本身不改变颜色，但它改变了每个像素与行列标签的对齐关系；同一块拼图放在不同列位置会遇到不同的标签匹配情况，因此最终可见图案是拼合几何与标签序列的交叉产物。

## 新题 3：字形编码比较器驱动分区填充

**组合逻辑**：[标记字形/形状编码颜色](创新：字形不再编码一种颜色，而是编码一种逻辑比较器——相等 vs 不等) + [网格分区/分隔线](已有) + [行列交叉/标签同色时填充](创新：填充条件由字形选择的比较器决定) + [擦除](已有)

**来源原语**：标记字形、形状编码颜色、按形状映射颜色(009d5c81)；网格分区、分隔线、分区区域(272f95fa)；行标签、列标签、行列交叉、标签同色时填充(a406ac07)；填充(272f95fa)；擦除(93c31fbe)

**依赖链**：字形的形状决定比较器类型（相等/不等），比较器决定行列标签匹配时的填充行为。去掉字形解码，无法确定用相等还是不等条件；去掉标签，无法评估比较结果；去掉分区结构，无法确定区域边界。三者互相依赖，缺一不可。

解码中央字形选择逻辑比较器，以此决定分区表格中哪些区域按行列标签关系填色。

**输入结构**：约 13x13 的黑(0)背景网格。灰(5)分隔线形成两条等间距的全宽水平线和两条等间距的全高竖直线，将网格切分为 3x3 共 9 个矩形区域。第一行的三个区域各包含一个单色像素作为列标签（颜色从红(2)、蓝(1)、黄(4)中取值），第一列的三个区域各包含一个单色像素作为行标签（同色域）。第一行第一列的区域（左上角）为空（黑(0)背景，无标签）。3x3 网格的中心区域包含一个 3x3 的单色小图形（标记字形），颜色为品红(6)，像素数在 4~6 之间，4-连通。其余四个"正文"区域（第 2~3 行 x 第 2~3 列，排除中心区域）为空（黑(0)背景）。不同示例中字形的形状不同，标签颜色序列不同。生成约束：标签颜色至少有两种不同值，以保证比较结果不全相同。

**规则**：
1. 解码中心区域的标记字形形状：若字形呈十字形（中心像素加四个正交邻居共 5 像素）则比较器为"相等"模式；若字形呈横条或竖条形（3 个像素排成一线）则比较器为"不等"模式。
2. 对四个正文区域中的每一个，确定其行标签颜色（该区域所在行的第一列标签）和列标签颜色（该区域所在列的第一行标签）。
3. 若比较器为"相等"模式：当行标签颜色 == 列标签颜色时，将该正文区域全部填充为该颜色；否则保持黑(0)。
4. 若比较器为"不等"模式：当行标签颜色 != 列标签颜色时，将该正文区域全部填充为行标签颜色；否则保持黑(0)。
5. 擦除中心区域的字形（替换为黑(0)）。
6. 分隔线和标签像素保持不变。

**关键洞察**：标记字形不编码一种颜色（如参考题 009d5c81），而是编码一种布尔运算（相等/不等）。同一组标签在不同字形下产生互补的填充图案；必须对比多个示例中字形形状与填充结果的对应关系才能确认这一编码。

## 新题 4：轨迹反向射线的级联障碍擦除

**组合逻辑**：[射线投射/轨迹/反向投射](已有) + [碰撞停止](已有) + [按距离循环配色](创新：射线沿途像素不再统一着色而是按离发射源的距离循环配色) + [擦除](创新：射线命中障碍后擦除障碍，可能为其他射线开路) + [首个障碍](已有)

**来源原语**：射线投射、轨迹、反向投射、首个障碍(9f8de559)；标记像素(9f8de559)；碰撞停止(e87109e9)；按距离循环配色(a3f84088)；擦除(93c31fbe)

**依赖链**：轨迹方向决定射线方向（反向投射），射线着色依赖射线长度（距离循环配色），射线终点的障碍被擦除后可能使另一个标记的射线路径延长并命中新目标。处理顺序制造了级联效应——先处理的标记擦除的障碍影响后处理标记的射线路径。去掉轨迹则无法确定射线方向，去掉距离配色则射线着色不确定，去掉障碍擦除则无级联效应。

每个带轨迹的标记向轨迹反方向发射距离着色射线，射线命中障碍后擦除该障碍，可能为后续射线开路。

**输入结构**：约 18x18 的黑(0)背景网格。网格中散布 2~4 个标记像素，每个标记为红(2)单像素。每个标记恰好有一条由 3 个灰(5)像素组成的直线轨迹，轨迹从标记的某个正交方向延伸（上/下/左/右）。网格中另有 2~5 个橙(7)障碍像素（均为单像素）。标记、轨迹和障碍互不重叠。不同示例中标记数量（2~4）、轨迹方向和障碍位置均不同。生成约束：每个标记的射线方向（轨迹反方向）上至少有一个障碍或网格边界；至少有一个障碍位于两个标记的射线路径上，使得先发射的标记擦除该障碍后能改变后发射标记的射程。

**规则**：
1. 按标记像素在网格中的位置从上到下、从左到右的顺序依次处理每个标记。
2. 对当前标记，确定其轨迹方向（灰(5)像素相对于标记的方向），射线方向为轨迹的反方向。
3. 从标记位置沿射线方向逐格前进。对经过的每个黑(0)像素，按其与标记的曼哈顿距离 d 循环配色：d mod 3 == 1 时涂蓝(1)，d mod 3 == 2 时涂绿(3)，d mod 3 == 0 时涂黄(4)。
4. 射线在遇到第一个非黑(0)像素或网格边界时停止。
5. 若射线命中一个橙(7)障碍像素，将该障碍擦除为黑(0)。射线本身不延伸到障碍位置（障碍被擦除但该格不着射线色）。
6. 若射线命中非障碍的非黑(0)像素（如另一个标记、轨迹或已有射线着色），射线在该像素前一格停止，不修改该像素。
7. 所有标记处理完毕后，标记像素保留红(2)，轨迹像素保留灰(5)。

**关键洞察**：处理顺序（从上到下、从左到右）产生级联效应：先处理的标记擦除的障碍可能恰好挡在后处理标记的射线路径上，使后者的射线延伸更远并可能命中另一个障碍。仅凭单个示例无法确定是否存在级联效应；需要对比多个示例中不同标记排列与射线长度的关系才能归纳出处理顺序规则。

## 新题 5：宽高比决定镜像轴的标记对齐印章

**组合逻辑**：[印章放置/标记对齐](已有) + [镜像/宽高比决定镜像轴](创新：宽高比不再应用于角标记框而是应用于源精灵本身，在印章前先做镜像变换) + [面积排序叠加](已有) + [裁剪](已有)

**来源原语**：印章放置、标记对齐、面积排序叠加(83eb0a57)；目标对象、源精灵、共享标记(83eb0a57)；镜像、宽高比决定镜像轴(93c31fbe)；裁剪(83eb0a57)

**依赖链**：每个源精灵的边界框宽高比决定其镜像轴（宽→左右翻转，高→上下翻转），镜像后的精灵再通过共享标记对齐到目标对象上。镜像改变了精灵的几何形状，进而改变对齐后精灵覆盖的区域。去掉镜像则对齐位置产生的叠加图案不同；去掉标记对齐则不知道放在哪里；去掉面积排序则重叠区域的颜色不确定。

根据每个源精灵的宽高比翻转后，按共享标记对齐印在目标对象上，面积大的先印。

**输入结构**：约 20x20 的黑(0)背景网格。包含一个最大的多色目标对象（约 8x8 边界框，包含红(2)和黄(4)像素，形状不规则但 4-连通）以及 2~3 个较小的单色源精灵（每个约 3x5 至 5x3 边界框，像素数 5~10，4-连通，形状不规则）。每个源精灵使用蓝(1)、绿(3)或品红(6)中的一种颜色。每个源精灵恰好包含一种与目标对象共享的标记颜色——即精灵中有若干像素颜色为红(2)或黄(4)，与目标对象中的某些同色连通分量在形状上完全一致（作为对齐锚点）。不同示例中精灵数量、形状、宽高比和标记颜色不同。生成约束：各精灵的共享标记连通分量与目标对象中的对应分量形状完全匹配；各精灵的边界框宽高比严格非正方形（宽 != 高）。

**规则**：
1. 裁剪目标对象的紧凑边界框作为输出画布。
2. 对每个源精灵，计算其裁剪后边界框的宽高比。宽 > 高（横向精灵）→ 对该精灵做左右镜像翻转；高 > 宽（纵向精灵）→ 对该精灵做上下镜像翻转。
3. 对翻转后的精灵，将其共享标记颜色的连通分量与目标对象中相同颜色的连通分量对齐（平移使标记完全重合）。
4. 按精灵面积从大到小的顺序依次将精灵印到输出画布上。后印的精灵中非黑(0)像素覆盖先印的内容。
5. 超出输出画布边界的精灵像素被裁剪丢弃。

**关键洞察**：源精灵在印章前需先翻转，翻转轴取决于精灵自身的宽高比而非目标对象的属性。翻转改变了精灵中非标记像素的相对位置，因此同一精灵在宽版和高版输入中会在目标对象上产生不同的覆盖图案。需对比多个示例才能确认翻转的触发条件是宽高比而非其他属性。

## 新题 6：控制像素排除条纹后跨分隔线反射填隙

**组合逻辑**：[射线延伸/延伸条纹/标记排除对应行列](已有) + [反射/跨轴对称/分隔线](已有) + [分隔色填充间隙](创新：间隙不再是源对象与反射之间的整个矩形带，而是仅限于有条纹延伸到的行或列对应的分隔线段) + [忽略干扰项](已有)

**来源原语**：射线延伸、控制像素、延伸条纹、标记排除对应行列(9def23fe)；实心矩形(9def23fe)；反射、分隔线、跨轴对称、分隔色填充间隙(538b439f)；忽略干扰项(538b439f)

**依赖链**：控制像素决定哪些列的条纹被排除（步骤一），条纹的有无决定反射时哪些列有镜像图案（步骤二），而间隙填充仅发生在有条纹的列上（步骤三）。去掉控制像素排除，所有列都有条纹，间隙填充覆盖整个分隔线；去掉反射则无镜像产生；去掉间隙填充则分隔线上留有断口。三步之间通过"哪些列活跃"这一信息紧密耦合。

将矩形向分隔线方向延伸条纹（排除被控制像素标记的列），再将条纹连同矩形反射到分隔线另一侧，在有条纹的列位置用分隔色填满间隙。

**输入结构**：约 16x20 的黑(0)背景网格。一条全宽的灰(5)水平分隔线位于网格中偏上位置（约第 5~7 行）。分隔线上方有一个蓝(1)实心矩形（约 3x6，距分隔线约 1~3 行）。矩形正下方（矩形与分隔线之间的侧边带）散布若干红(2)控制像素（单像素，各自位于不同列，标记这些列不生成条纹）。分隔线下方区域为空（黑(0)背景），但可能散布少量栗(9)干扰像素（单像素，散布在不影响规则的位置）。不同示例中矩形大小、与分隔线的距离、控制像素数量和位置、干扰像素位置不同。生成约束：控制像素只出现在矩形列范围内且在矩形与分隔线之间。

**规则**：
1. 对矩形列范围内的每一列：若该列在矩形正下方至分隔线之间没有红(2)控制像素，则将该列从矩形下边沿到分隔线上方一行的所有黑(0)像素涂为蓝(1)（延伸条纹）。有红(2)控制像素的列不生成条纹。
2. 将矩形和所有延伸条纹作为整体，以分隔线为轴做上下镜像反射，将反射结果绘制在分隔线下方对应位置。反射像素涂为蓝(1)。
3. 对于有延伸条纹的每一列，将分隔线所在行的该列像素涂为灰(5)（用分隔色填充间隙——连接上方条纹和下方反射条纹）。无延伸条纹的列的分隔线像素保持其原灰(5)不变（视觉上无差异，但逻辑上间隙填充仅发生在有条纹列）。
4. 红(2)控制像素保留在原位。栗(9)干扰像素：若被反射图案覆盖则被蓝(1)覆盖，否则保留。
5. 矩形原位保持蓝(1)不变。

**关键洞察**：控制像素通过排除特定列的条纹，间接控制了分隔线另一侧反射图案中哪些列有填充、哪些列是空缺。反射图案不是矩形本身的完整镜像，而是矩形加上经控制像素筛选后的条纹的镜像——呈现出带有缺口的梳齿状结构。

## 新题 7：对称恢复后透明层叠的象限合并

**组合逻辑**：[对称补全/对称轨道](创新：恢复出的像素在后续叠加中标记为透明，而非保留其推断颜色) + [透明叠加/层叠顺序/四象限折叠同画布](已有) + [重涂色](已有)

**来源原语**：对称补全、对称轨道、全对称恢复缺失、缺失矩形区域(e66aafb8)；透明叠加、象限掩码、层叠顺序、四象限折叠同画布(75b8110e)；重涂色(a8610ef7)

**依赖链**：对称补全确定哪些像素是"恢复的"（原本缺失），这些像素在叠加时被标记为透明——它们不遮挡下层。叠加顺序决定可见层，但被恢复的像素不参与遮挡。去掉对称补全则不知道哪些像素透明；去掉叠加则无合并结果。对称补全的输出不仅是颜色值，更是"原始/恢复"这一元信息，该元信息直接控制叠加的遮挡行为。

四个象限各自通过左右对称补全缺失像素，恢复出的像素在四象限折叠叠加时视为透明。

**输入结构**：约 14x14 的黑(0)背景网格（偶数尺寸，如 14x14 或 16x16），自然分为四个大小相等的象限（各 7x7 或 8x8）。每个象限包含一个单色前景图案（四个象限分别使用红(2)、蓝(1)、绿(3)、黄(4)），每个图案具有左右反射对称性但有若干像素缺失（被设为黑(0)）。缺失像素的位置使得利用左右对称性可唯一恢复它们的值。每个象限缺失 2~4 个像素。不同示例中图案形状和缺失位置不同。生成约束：每个象限的图案具有严格的左右对称性（在恢复后）；缺失像素仅出现在一侧（另一侧的对称位有值），保证恢复唯一。

**规则**：
1. 对每个象限，找出所有黑(0)像素位置，检查其关于象限垂直中轴的对称位。若对称位是非黑(0)前景像素，则该黑(0)像素为"缺失像素"，其恢复值为对称位的颜色。标记这些像素为"已恢复"。
2. 创建一个象限大小的输出画布，初始化为黑(0)。
3. 按以下顺序将四个象限（含恢复像素）叠加到输出画布上：左上(back) → 右下 → 左下 → 右上(front)。
4. 叠加时，每个象限的黑(0)像素（无论是原始背景还是恢复后仍为黑(0)）视为透明，不覆盖下层。每个象限的"已恢复"像素也视为透明，不覆盖下层，无论其恢复值是什么。
5. 仅"原始"（非缺失）前景像素在叠加时具有遮挡力，覆盖下层内容。

**关键洞察**：对称补全不仅推断出缺失值，还产生了"原始/恢复"这一分类；恢复的像素虽然有颜色值但在叠加中不生效（透明），使得最终合并图案取决于每个象限哪些位置的像素是原始存在的。必须对比多个示例才能确认"恢复像素透明"这一隐蔽规则，因为仅看单个示例可能误以为是其他叠加优先级。

## 新题 8：分区边界裁切的模板印章

**组合逻辑**：[印章放置/模板图案](创新：模板图案不再是逐像素复制而是在每个目标区域中被分区边界裁切) + [网格分区/分隔线](创新：分隔线不再仅作为视觉分区，还充当印章的物理裁切边界) + [颜色替换](已有) + [擦除](已有)

**来源原语**：印章放置、模板图案、颜色替换(abc82100)；网格分区、分隔线、分区区域(272f95fa)；填充(272f95fa)；擦除(93c31fbe)

**依赖链**：模板定义了印章的完整形状，分区边界决定每个区域中印章的可见部分（裁切），颜色替换决定印章的显示颜色。三者缺一不可：无模板则不知道印什么，无分区则不知道裁切边界在哪，无颜色替换则不知道印出的颜色。模板的大小可能超出单个分区区域，因此不同区域展示模板的不同局部——这是分区和印章的结构性交互。

将同一模板以目标像素为锚点印到各分区中，超出分区边界的部分被裁切，印章颜色替换为目标像素颜色。

**输入结构**：约 15x15 的黑(0)背景网格。灰(5)分隔线形成一条全宽水平线和一条全高竖直线，将网格切分为 2x2 共 4 个矩形区域（各区域大小不必相等）。其中一个区域（固定为左上角区域）包含一个青(8)模板图案：一个 4-连通的小图形，约 4~7 像素，紧凑分布在该区域内。其余三个区域各包含一个单独的着色像素（目标像素），颜色分别取自红(2)、蓝(1)、黄(4)（三个不同颜色各用一次）。不同示例中模板形状不同，目标像素在各自区域内的位置不同，分隔线位置（因而区域大小比例）不同。生成约束：模板图案完全位于左上角区域内部（不接触分隔线）。

**规则**：
1. 记录左上角区域中青(8)模板图案的形状——以模板的几何中心（边界框中心）为锚点，记录每个模板像素相对于锚点的偏移向量。
2. 对其余三个区域中的每个目标像素：以该目标像素的位置为锚点，按偏移向量放置模板的每个像素。放置的像素颜色替换为该目标像素的颜色。
3. 若放置的像素位置落在该目标像素所在分区区域之外（超出分隔线或网格边界），则该像素被裁切丢弃，不绘制。
4. 若放置的像素位置落在分隔线上，也被裁切丢弃。
5. 擦除左上角区域的青(8)模板（替换为黑(0)）。
6. 目标像素本身被模板覆盖（模板的锚点像素颜色与目标像素相同）。
7. 分隔线保持灰(5)不变。

**关键洞察**：同一模板在不同区域中因目标像素位置不同（靠近或远离分隔线边界）而被不同程度地裁切，产生不同的可见局部形状。求解者需要识别出各区域的局部图案是同一模板的不同裁切结果，然后在左上角找到完整模板以验证。分区边界不仅是视觉装饰，而是印章操作的物理限制。
