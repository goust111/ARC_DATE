## 新题 1：对角射线构建图结构后寻找最短路径

**组合逻辑**：[射线延伸(ray_cast)](创新：射线命中另一节点时建立图边，而非仅延伸到边界) + [最短路径(shortest_path)](已有) + [擦除(erase)](创新：未被选中的射线被清除)

**来源原语**：射线延伸/对角标记/实心正方形/锚角对角射线至边(来自 7ddcd7ec)；最短路径/节点方块/轨道段/终端节点/图结构/最短路径选择(来自 7b0280bc)；擦除(来自 1efba499)；碰撞停止(来自 f0100645)

**依赖链**：射线延伸的结果决定了图中哪些节点之间存在边——只有射线实际到达另一节点时才建边，未命中的射线不产生连接。图结构完全由射线构建后，最短路径算法才有可操作的拓扑。最终擦除步骤依赖最短路径的输出来决定保留哪些射线。三步互相依赖：没有射线就没有图，没有图就没有路径，没有路径就不知道擦除什么。

从散布在网格中的锚方块出发，通过对角标记射出射线来建立节点间的连接关系，然后在这张由射线构成的图上找出两个终端节点之间的最短路径，仅保留路径上的射线和节点。

**输入结构**：黑(0)背景，网格约 15x15。网格中散布 5-7 个实心 2x2 正方形：其中恰好 2 个为红(2)（终端节点），其余为蓝(1)（中继站）。每个正方形的 0-3 个对角邻接位置放有一个与该正方形同色的单像素（对角标记），表示该方向可以射出射线。各正方形之间保持至少 3 个像素的间距。生成时保证：(a) 两个红终端之间存在至少一条由射线边连通的路径；(b) 最短路径唯一（不存在相同边数的替代路径）。

**规则**：
1. 对每个对角标记像素，沿其相对于母方块的对角方向（即远离母方块的 45 度方向）逐格延伸射线，将经过的每个黑(0)格涂为灰(5)。射线在以下两种情况停止：(a) 射线的下一格属于某个 2x2 方块的边界框——此时该射线在这两个方块之间建立一条图边；(b) 射线离开网格边界——此时该射线不建立任何边。
2. 将所有方块视为图节点，所有成功连接两个方块的射线视为图边，找到两个红(2)终端节点之间边数最少的路径。
3. 将路径上的蓝(1)中继站方块重涂为绿(3)。将路径上的射线（灰(5)段）重涂为黄(4)。红(2)终端保持不变。
4. 将所有不在最短路径上的射线（包括成功连接但未被选中的射线和未命中任何方块的射线）擦除为黑(0)。非路径中继站保持蓝(1)不变。

**关键洞察**：两个方块之间是否存在边取决于是否有一条对角射线在空间上恰好能从一个方块到达另一个方块——视觉距离近的方块未必有边（若无对角标记指向对方），而距离远的方块可能通过一条长对角射线相连。图的拓扑由几何位置和标记方向共同决定，非直观。

## 新题 2：转置揭示隐藏周期性后修补缺失格

**组合逻辑**：[镜像/转置(transpose)](创新：转置不是最终输出变换，而是预处理步骤以揭示隐藏的周期结构) + [补全/平铺(repair/tiling)](已有：推断最小周期并填补黑洞) + [镜像/转置(transpose)](逆操作：修补完成后转置回原方向)

**来源原语**：镜像/转置/方阵/对角线/对角对称/沿主对角线转置(来自 9dfd6313)；补全/平铺/周期瓦片/缺失单元/最小周期推断填补(来自 29ec7d0e)

**依赖链**：原始网格直接观察不呈现任何空间周期性，因此补全操作无法直接应用。需要先沿主对角线转置，转置后的网格才显现出清晰的小周期瓦片结构（非黑格在模周期位置上一致），此时补全操作才可生效。修补后需再次转置回原方向才能得到输出。转置是补全的前提条件，补全是输出正确的前提条件。

网格表面看是无规律的彩色格阵加上若干黑洞，但沿灰色主对角线转置后会显现出周期性瓦片图案；利用该周期填补所有黑洞后再转置回来。

**输入结构**：正方形网格（如 12x12 或 15x15），黑(0)背景。从 (0,0) 到 (n-1, n-1) 的完整主对角线被灰(5)填充。对角线以外的格子使用 3-4 种非灰非黑前景色（例如红(2)、蓝(1)、绿(3)、黄(4)），其中约 15%-25% 的非对角线格为黑(0)（缺失格）。直接观察时，同色格没有明显的行列周期。但若将整个网格沿主对角线转置（即交换 (r,c) 与 (c,r) 处的值，对角线格不变），则所有非黑非灰格在 (row mod p, col mod p) 位置上完全一致，p 为一个小整数（2、3 或 4）。生成时保证每个周期瓦片位置至少在转置后的网格中出现一个非黑样本。

**规则**：
1. 识别灰(5)主对角线为转置轴。
2. 将网格沿主对角线转置：对每一对 (r,c) 和 (c,r)（r != c），交换它们的颜色值。对角线格保持不动。
3. 在转置后的网格中，找到最小正整数周期 p，使得所有非黑(0)非灰(5)格的颜色仅由 (row mod p, col mod p) 决定。
4. 构建 p x p 的周期瓦片，用每个 (row mod p, col mod p) 位置上可见的非黑非灰颜色填充。
5. 将转置后网格中所有黑(0)的非对角线格替换为其对应周期瓦片位置的颜色。对角线格保持灰(5)。
6. 将修补后的网格再次沿主对角线转置回原方向，得到最终输出。

**关键洞察**：原始网格看起来混乱无序，因为周期结构被转置"加密"了。灰色对角线既是一个视觉元素，也是解密钥匙——必须先沿它转置才能看到周期规律。仅凭单个示例很难确定需要转置（因为不知道周期应该是什么），必须对比多个示例发现"转置后才有周期"这一模式。

## 新题 3：对称补全创造碰撞障碍改变滑动终点

**组合逻辑**：[对称补全(symmetry_completion)](已有：从三个镜像变体推断第四个) + [擦除(erase)](已有：移除分割线) + [滑动(slide)](创新：滑动对象不是补全的对象本身，而是外部对象；补全产生的新形状改变了滑动的碰撞地图)

**来源原语**：对称补全/分割线/格元/块内对称/三存一缺推断(来自 2546ccf6)；滑动/碰撞阻挡/碰撞停止(来自 f0100645, 3906de3d)；擦除(来自 1efba499)；墙壁列(来自 f0100645)

**依赖链**：对称补全确定了第四个精灵体的具体形状和位置——不同的输入示例中三个可见精灵体不同，因此推断出的第四个形状也不同。这个新形状立即成为碰撞地图的一部分。随后蓝色对象向右滑动时，碰撞停止位置受到这个新形状的直接影响。如果跳过补全步骤，碰撞地图不完整，滑动终点就是错的。

在网格中央的分格区域中，三个红色精灵体暗示着第四个缺失的镜像变体；补全它之后，移除分割线，外部的蓝色对象向蓝色墙壁滑动时将被这些红色形状（包括新补全的那个）阻挡在不同的位置。

**输入结构**：黑(0)背景，网格约 17x15（17 列 15 行）。绿(3)分割线在网格中部形成一个十字，将中央区域分成 2x2 排列的四个等大矩形格元（每个约 5x5）。三个格元中各有一个红(2)精灵体（4-连通、不规则、4-8 像素），它们是同一形状在 2x2 块中心的水平和/或垂直镜像变体。第四个格元为空。网格最右列（第 16 列）整列填充蓝(1)，作为目标墙壁。在 2x2 格元区域的左侧（约第 0-3 列），有 3-5 个蓝(1)孤立像素，散布在不同的行上。生成约束：(a) 三个红色精灵体的镜像关系唯一确定第四个的形状；(b) 至少有一个蓝色像素所在行会穿过补全后的第四个红色精灵体占据的格子，使得补全与否会导致该蓝色像素的滑动终点不同。

**规则**：
1. 根据三个已有的红(2)精灵体在 2x2 格元块中的镜像对称关系，推断第四个精灵体的形状：取与空格元对角位置的精灵体，对其进行水平和垂直翻转，得到的掩码就是缺失精灵体。将其以红(2)绘入空格元。
2. 将所有绿(3)分割线像素擦除为黑(0)。
3. 将每个蓝(1)孤立像素沿其所在行向右滑动：逐列右移，直到下一列的该行位置是红(2)像素、蓝(1)墙壁列像素、或另一个已经停下的蓝(1)像素。处理顺序为从右到左（距离墙壁最近的蓝色像素最先处理）。
4. 输出最终网格。红色精灵体（含补全的）、蓝色墙壁和已滑动到位的蓝色像素均保留。

**关键洞察**：对称补全不仅是视觉上的"填空"——它创造了一个物理障碍物，直接改变了后续滑动操作的结果。不同示例中被补全的精灵体形状不同，因此它在哪些行上造成阻挡也不同，需要对每个示例分别推算。

## 新题 4：外推动画帧后统计频率绘制柱状图

**组合逻辑**：[序列外推(sequence_extrapolation)](已有：从多帧恒定偏移推断下一帧) + [计数(counting)](已有) + [排序(sort)](已有) → 柱状图输出格式(创新：跨越"空间预测"与"统计摘要"两种表征)

**来源原语**：序列外推/面板帧/分隔行/前景精灵/等距堆叠/恒定偏移平移(来自 351d6448)；计数/排序/前景像素/柱状图/频率排序/频率降序柱状图(来自 9af7a82c)

**依赖链**：计数和排序的输入数据不是直接可见的——它来自一个需要先外推出来的第四帧。而且外推过程中，部分像素可能因平移超出面板边界而丢失，这使得第四帧的颜色频率与前三帧不同（不能简单复制）。频率的正确值取决于空间外推中的边界裁切效应。若跳过外推，没有待统计的帧；若跳过统计，无法得到柱状图输出格式。

三帧动画条中，各色像素群按恒定向量逐帧平移；外推出不可见的第四帧后，统计该帧中各颜色的像素数量，按降序绘制为柱状图。

**输入结构**：网格约 8x26。三个等大面板（每个约 8x8）由灰(5)全宽分隔行上下堆叠。每个面板有黑(0)背景，其中散布 3-4 种颜色的像素群（例如红(2)、蓝(1)、绿(3)、黄(4)），每种颜色有 2-5 个像素构成一个 4-连通群组。从第一帧到第二帧、第二帧到第三帧，每种颜色群组均按相同的恒定向量 (dr, dc) 平移（不同颜色的平移向量可以不同）。生成约束：(a) 前三帧中所有像素均在面板边界内；(b) 第四帧外推时，至少有一种颜色的部分像素会超出面板边界（被丢弃），使得第四帧的频率与第三帧不同；(c) 第四帧中至少保留 2 种颜色。

**规则**：
1. 识别灰(5)分隔行，将输入分为三个 8x8 面板。
2. 对每种非黑非灰颜色，比较其在相邻帧中的像素位置，计算恒定平移向量 (dr, dc)。
3. 将第三帧中的每种颜色群组再平移一次 (dr, dc)，生成第四帧。超出 8x8 面板边界的像素丢弃。
4. 统计第四帧中每种颜色占据的像素数。
5. 将颜色按像素数降序排列。若两种颜色像素数相同，将它们的群组在第四帧中的最上最左像素按行优先序比较，靠前者排在左边。
6. 输出一个柱状图网格：宽度 = 存活颜色数，高度 = 最大像素数。黑(0)背景。第 k 列（从左起第 0 列开始）对应排名第 k 的颜色，从顶行起向下填充该颜色，填充行数 = 该颜色的像素数。

**关键洞察**：被统计的那一帧并不直接可见——它是空间外推的产物。关键的非显然之处在于边界裁切：某些颜色的像素在第四帧中被"推出"了面板，导致其频率下降甚至消失。仅观察前三帧的频率趋势（线性不变）无法预测第四帧频率，必须先做空间外推再做统计。

## 新题 5：多源角落填充矩形的重叠计数决定着色

**组合逻辑**：[填充(fill)](已有：从孤立像素到最近角填充矩形) + [计数(counting)](创新：不再统计颜色频率，而是统计每个格子被多少矩形覆盖的重叠层数) + [重涂色(recolor)](创新：重涂色依据不是颜色属性，而是空间重叠层数)

**来源原语**：填充/孤立前景像素/网格角/最近角距离/曼哈顿距离最小(来自 4a1cacc2)；计数/频率排序(来自 9af7a82c)；重涂色(来自 97d7923e, 9473c6fb)

**依赖链**：这不是一个线性流水线——所有矩形必须同时计算，因为重叠层数是全局属性。每个像素的填充方向由其到最近角的距离决定（来自 fill 原语），但最终颜色由所有矩形的集体重叠状况决定（来自 counting + recolor 的交互）。单独的 fill 操作只能给出单矩形的范围；单独的 counting 无矩形可数；必须两者协同作用才能确定每个格子的输出。

多个孤立前景像素各自向最近的网格角扩展为填充矩形，矩形之间可能重叠；每个格子的最终颜色由覆盖它的矩形数量决定——单层、双层和多层各有不同的颜色映射。

**输入结构**：黑(0)背景，网格约 12x12。网格上有 3-4 个孤立的单像素前景点，全部为橙(7)。这些像素分布在网格的不同区域，使得它们的最近角各不相同（没有两个像素共享同一个最近角）。像素的位置经过安排，使得至少两个填充矩形存在部分空间重叠，且至少有一个格子被 3 个或更多矩形覆盖。生成约束：每个橙色像素到其最近角的曼哈顿距离唯一确定（无平局），若存在距两角等距的情况，选择行号更小的角；行号也相同则选列号更小的角。

**规则**：
1. 对每个橙(7)前景像素，找到与其曼哈顿距离最小的网格角（四个角之一）。平局时取行号最小的角，仍平局取列号最小的角。
2. 计算该像素与其最近角所确定的轴对齐矩形（包含像素位置和角位置的最小矩形，两端包含）。
3. 同时处理所有像素：对网格中每个格子，计算有多少个矩形覆盖了它（重叠层数）。
4. 根据重叠层数进行重涂色：
   - 层数 = 0（未被任何矩形覆盖）：保持黑(0)。
   - 层数 = 1（仅被一个矩形覆盖）：涂为蓝(1)。
   - 层数 = 2（被恰好两个矩形覆盖）：涂为红(2)。
   - 层数 >= 3（被三个或更多矩形覆盖）：涂为黄(4)。
5. 原始的橙(7)像素位置保留为橙(7)不变（作为标记），无论该位置的重叠层数是多少。

**关键洞察**：这道题的逻辑结构不是流水线，而是同时约束满足——必须先构造所有矩形才能计算任何格子的重叠层数。层数到颜色的映射（1→蓝、2→红、>=3→黄）无法从单个示例中完全推断（单个示例可能不包含所有层数情况），需要对比多个示例才能归纳完整映射规则。

## 新题 6：全局布局决定扫描方向后射线按序循环着色

**组合逻辑**：[射线延伸(ray_extend)](已有：从锚方块对角标记向外射线) + [重涂色(recolor)](创新：着色单元是整条射线而非单个像素，颜色由射线的全局处理序号决定) + 全局扫描序判定(创新：扫描方向由所有锚方块的集体空间分布决定，而非单个方块的属性)

**来源原语**：射线延伸/实心正方形/对角标记/画布边界/对角邻接/锚角对角射线至边(来自 7ddcd7ec)；重涂色/孤立像素/位置排序/长轴决定扫描/颜色循环分配(来自 9473c6fb)

**依赖链**：射线延伸产生若干条射线，每条射线需要一个颜色。着色顺序由全局扫描序决定，而扫描方向（行优先或列优先）取决于所有锚方块中心构成的包围框的长宽比——这是一个全局几何属性，无法从单个方块推断。因此，改变任何一个方块的位置都可能改变包围框长宽比，从而翻转扫描方向，进而改变所有射线的颜色分配。射线的存在和扫描序的判定互相独立，但最终着色需要两者的结果共同作用。

多个绿色锚方块各自从对角标记发射射线到网格边界；所有方块的集体空间分布决定了行优先还是列优先的扫描顺序，射线按此顺序被循环着色为红、蓝、黄。

**输入结构**：黑(0)背景，网格约 15x15。网格中有 3-5 个绿(3)实心 2x2 方块，各方块间至少间隔 3 个像素。每个方块在其 1-2 个对角角位置有一个绿(3)单像素（对角标记），即方块某角的对角邻接位置。所有方块中心的包围框要么明显高于宽（行数 > 列数），要么明显宽于高（列数 > 行数），不出现正方形包围框。生成约束：(a) 不同方块的射线轨迹互不相交（射线路径上不经过其他方块或射线）；(b) 每个方块至少有一个对角标记。

**规则**：
1. 计算所有 2x2 方块中心坐标的最小包围框（行范围和列范围）。
2. 若包围框的行跨度 >= 列跨度，对方块按行优先序排列（按方块左上角的行号升序，行号相同则列号升序）；否则按列优先序排列（按方块左上角的列号升序，列号相同则行号升序）。
3. 按上述排列顺序依次处理每个方块。对每个方块，按其对角标记的顺时针方位顺序（从左上角开始：左上、右上、右下、左下）依次处理每个标记。
4. 对每个对角标记，沿远离母方块的对角方向逐格延伸射线，将黑(0)格涂色，直到射线离开网格边界。
5. 按射线的全局处理顺序（第 1 条、第 2 条、第 3 条...），循环分配颜色：第 1 条射线涂为红(2)，第 2 条涂为蓝(1)，第 3 条涂为黄(4)，第 4 条再涂为红(2)，以此类推。每条射线的所有像素涂同一颜色。
6. 锚方块及其对角标记保持绿(3)不变。

**关键洞察**：单看一个方块无法判断它的射线会被涂什么颜色——颜色取决于该射线在全局处理序列中的位置，而全局序列的方向（行优先 vs 列优先）由所有方块的集体空间分布决定。需要对比多个不同布局的示例才能归纳出"长轴决定扫描方向"这一隐蔽规则。

## 新题 7：方向标记控制印章反射模式的分块展开

**组合逻辑**：[印章覆盖(stamp)](已有：将源像素展开为模板副本) + [镜像(mirror)](创新：不再由外部标记指示固定方向，而是每个源像素自带方向标记，控制该位置的模板是否翻转及翻转方式) + [重涂色(recolor)](已有：模板颜色替换为源像素颜色)

**来源原语**：印章覆盖/模板面板/前景像素/分块对应/源色决定模板涂色(来自 b190f7f5)；镜像/精灵体/标记像素/方向指示/标记指示放置侧(来自 760b3cac)；重涂色(来自 97d7923e)；分隔列(来自 195ba7dc)

**依赖链**：印章操作需要知道模板形状（来自模板面板）和放置位置+颜色（来自源像素），但还需要知道每个印章的朝向（来自方向标记）。如果没有方向标记，所有印章朝向相同——对于非对称模板，输出将会错误。三种信息（模板形状、源颜色/位置、翻转方向）共同决定每个输出块的内容，缺一不可。每个源像素同时编码了三个通道的信息：位置决定哪个块、颜色决定涂色、邻接的灰标记决定翻转方式。

左右两面板以灰色列分隔：左面板是一个非对称模板，右面板的彩色像素各带一个灰色方向标记；将每个源像素展开为模板的着色副本时，方向标记决定该副本是否水平/垂直翻转。

**输入结构**：网格约 (2N+1) x N，被一条灰(5)分隔列分成左右两个 N x N 面板（N 在 4-7 之间）。左面板：黑(0)背景上有一个蓝(1)模板掩码，由 3-6 个 4-连通像素组成，形状不对称（水平翻转后与原始形状不同，垂直翻转后也不同）。右面板：黑(0)背景上有 2-4 个彩色前景像素（每个像素颜色互不相同，颜色从红(2)、绿(3)、黄(4)、橙(7)、品红(6)中选取，不使用蓝(1)和灰(5)以避免与模板色和标记色混淆）。每个彩色像素恰好有一个灰(5)像素与之 4-邻接（上、下、左、右之一），作为方向标记。生成约束：不同彩色像素的方向标记指向不同方位（保证示例中能观察到至少两种不同的翻转方式）。

**规则**：
1. 以灰(5)分隔列为界，分离出左面板（模板 T）和右面板（源区域 S），两者均为 N x N。
2. 创建 N^2 x N^2 的输出网格，初始化为黑(0)。
3. 对右面板中每个非黑非灰的源像素 P（位置 (r, c)，颜色 K）：
   a. 找到与 P 4-邻接的灰(5)方向标记的方位：
      - 标记在 P 的左边 → 使用模板 T 原样（不翻转）。
      - 标记在 P 的右边 → 将 T 水平翻转（左右镜像）。
      - 标记在 P 的上方 → 将 T 垂直翻转（上下镜像）。
      - 标记在 P 的下方 → 将 T 水平 + 垂直翻转（等价于 180 度旋转）。
   b. 将翻转后的模板中蓝(1)像素替换为颜色 K，得到着色后的模板 T'。
   c. 将 T' 印入输出网格中以 (r, c) 为索引的 N x N 子块：子块的行范围为 [r*N, (r+1)*N)，列范围为 [c*N, (c+1)*N)。T' 中的非黑像素覆盖子块对应位置，黑像素不覆盖（保持子块原有值）。
4. 若两个印章子块存在空间重叠（不同源像素映射到相邻的块且模板像素延伸到块边界外时不会发生——每个印章严格限制在自己的 N x N 子块内），则不存在冲突。未被任何印章覆盖的格子保持黑(0)。

**关键洞察**：每个源像素不仅编码了"在哪个块放置什么颜色的模板"，还通过相邻的灰色标记编码了"模板朝哪个方向"。模板是非对称的，因此四种翻转方式产生四种不同的输出图案。要发现方向标记与翻转方式的对应关系，必须对比多个示例中不同标记方位产生的不同印章形状。
