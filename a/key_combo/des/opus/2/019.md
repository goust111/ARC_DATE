## 新题 1：凸耳定向镜像后分解涂色

**组合逻辑**：[镜像/mirror](创新：镜像不改色，目的是凑成可分解形状) + [分解/decompose](已有) + [重涂色/recolor](已有)；[凸耳决定镜像轴/tab_determines_axis](已有) 决定镜像方向，[图元形状决定涂色/shape_determines_color](已有) 决定最终颜色

**来源原语**：镜像、凸耳、凸耳决定镜像轴、对侧放置（dc2e9a9d）；分解、基本图元、图元形状决定涂色（150deff5）；重涂色（dc2e9a9d / 150deff5）

**依赖链**：凸耳位置决定镜像轴方向 → 镜像产生的对称形状改变了可行的图元分解方案（单侧原始形状无法被无余分解） → 分解结果中图元的形状类别决定最终涂色。删除镜像步骤则分解不可行；删除分解步骤则无法区分涂色；删除凸耳识别则镜像方向未知。

将每个带凸耳的灰色不规则形状沿凸耳对侧镜像，使组合体恰好可被无余分解为方块和短条，再按图元类别涂色。

**输入结构**：黑(0)背景，约 14x14 网格。散布 2-4 个灰(5)色 4-连通不规则形状（每个 5-9 像素，边界框约 3x4 或 4x3，形状不对称且各不相同）。每个灰色形状的包围框恰好有一侧边界上存在一个单像素彩色凸耳——该凸耳颜色各不相同（如蓝(1)、红(2)、绿(3)），凸耳从包围框外缘向外延伸 1 像素，4-连通地与灰色形状相邻。各形状（含凸耳）互不接触，与网格边缘至少间隔 2 行/列。生成约束：每个灰色形状本身无法被 2x2 正方形与 1x3/3x1 矩形无余覆盖（总有剩余像素），但将其沿凸耳对侧镜像后，组合体恰好可以被这些图元无余铺满。

**规则**：
1. 对每个灰色形状，识别其凸耳像素及凸耳所在的包围框侧边（上/下/左/右）。
2. 在凸耳对侧放置该形状的镜像副本——若凸耳在左侧，则在原始包围框右侧紧邻（间距 0 像素）放置水平镜像；若凸耳在上侧，则在下侧紧邻放置垂直镜像；以此类推。镜像副本也为灰(5)色。
3. 擦除凸耳像素（变为黑(0)背景）。
4. 对组合体（原始 + 镜像，不含凸耳）执行无余分解：将其分割为不重叠的 2x2 正方形和 1x3 或 3x1 矩形，覆盖所有像素。
5. 将每个 2x2 正方形涂为青(8)；每个 1x3/3x1 矩形涂为红(2)。
6. 所有不属于任何形状的背景像素保持黑(0)。

**关键洞察**：单侧形状故意设计为无法被图元无余铺满，镜像翻倍后才恰好可分解——镜像不是装饰性复制，而是分解的前置必要条件。凸耳的方位同时编码了镜像轴信息和应丢弃的辅助标记，需对比多个示例才能确认"凸耳对侧镜像"而非"凸耳同侧镜像"的规则。

## 新题 2：遮罩恢复后对角折叠

**组合逻辑**：[对称补全/symmetry_completion](创新：作用于对角线 X 图案的遮罩恢复，利用八重轨道中旋转分量恢复同一对角线上被遮住的颜色) → [折叠/folding](已有：对角到边映射)

**来源原语**：对称补全、遮罩像素、正方形网格、八重对称轨道、轨道内唯一可见色（929ab4e9）；折叠、压缩、对角线像素、正方形边框、对角到边映射（ca8de6ea）

**依赖链**：遮罩隐藏了对角线上部分像素的真实颜色 → 八重对称恢复补全颜色（必须利用旋转分量，因为同一对角线上的反射伙伴也可能被遮罩） → 恢复后才能执行对角到边的折叠得到正确 3x3 输出。删除恢复步骤则折叠缺失颜色信息；删除折叠步骤则得到 5x5 而非所求的 3x3。

先用八重对称轨道恢复 5x5 X 形图案中被灰色遮罩覆盖的像素颜色，再将完整 X 折叠为 3x3 边框加中心。

**输入结构**：黑(0)背景上一个独立的 5x5 正方形区域。该区域内，两条对角线上的 9 个位置（含中心共享点）均有像素：其中 5-7 个为彩色前景像素（使用蓝(1)、红(2)、绿(3)、黄(4)等，每个位置颜色可不同），其余 2-4 个位置被灰(5)遮罩替换。遮罩分布约束：在每个八重对称轨道（4 个位置一组，中心单独一组）中，至少有一个位置未被遮罩，保证每个轨道有可见的参考颜色。同一轨道内所有未被遮罩的位置颜色相同。网格可以恰好 5x5，也可以更大（遮罩图案居于网格中央的 5x5 区域）。

**规则**：
1. 识别灰(5)为遮罩色。
2. 对 5x5 区域内每个灰(5)像素，计算其八重对称轨道——包括关于两条对角线、水平中线、垂直中线的反射以及 90°/180°/270° 旋转，共至多 8 个位置（在 5x5 中，非中心对角线位置的轨道大小为 4）。
3. 从该轨道中找到唯一的非灰色可见颜色，用此颜色替换遮罩。中心位置若被遮罩，其轨道仅含自身，此情况不会出现（生成约束保证中心不被遮罩）。
4. 恢复全部颜色后，执行对角到边折叠，将 5x5 X 折叠为 3x3：
   - 中心像素 (2,2) → 输出 (1,1)。
   - 西北臂：(1,1) → 输出 (0,0)，(0,0) → 输出 (0,1)。（从中心向外的像素依次映射到顶边从左到中）
   - 东北臂：(1,3) → 输出 (0,2)，(0,4) → 输出 (1,2)。（映射到右边从上到中）
   - 西南臂：(3,1) → 输出 (2,0)，(4,0) → 输出 (1,0)。（映射到左边从中到下）
   - 东南臂：(3,3) → 输出 (2,1)，(4,4) → 输出 (2,2)。（映射到底边从中到右）
5. 输出为 3x3 网格。

**关键洞察**：对角线上的像素被遮罩后，沿同一条对角线做反射得到的伙伴仍在该对角线上，也可能被遮罩。恢复必须依赖轨道中的旋转分量（90° 旋转将主对角线位置映射到副对角线位置），这是纯反射无法完成的。只有完成恢复后，折叠才能产出正确的 3x3 颜色布局。

## 新题 3：重复图案选取为模板印入分隔网格

**组合逻辑**：[裁剪/crop + 图案匹配/pattern_match](创新：在分隔网格的多个单元格间做裁剪比对) → [印章覆盖/stamp_overlay](已有) + [重涂色/recolor](已有)；[出现两次者选取/twice_pattern_selected](已有) 选定模板，[行调色板/row_palette](已有) 决定涂色

**来源原语**：裁剪、连通分量、精灵体、图案匹配、出现两次者选取（f5aa3634）；印章覆盖、分隔网格、模板掩码、行标记、行调色板、重涂色（5a5a2103）

**依赖链**：遍历所有单元格并裁剪 → 比对裁剪结果发现唯一重复图案 → 该图案成为模板 → 模板被印入每个单元格并按行标记涂色。删除比对步骤则模板未知；删除印章步骤则仅完成了选择未完成输出；删除行涂色则所有单元格颜色相同，与示例矛盾。

在分隔网格中找到唯一出现两次的精灵体图案作为印章模板，清空所有单元格后将该模板按行标记颜色印入每个单元格。

**输入结构**：约 15x15 网格。橙(7)色完整水平线和垂直线将网格分隔为规则的单元格阵列（如 4 行 4 列，每个单元格内部约 3x3）。最左列的每个单元格内各有一个单色标记像素（每行一种颜色，如第 0 行蓝(1)、第 1 行红(2)、第 2 行绿(3)、第 3 行黄(4)），该像素位于单元格内部任意位置。其余单元格（非最左列）内各含一个小型彩色精灵体（2-5 个前景像素，4-连通，单色或多色，包围框不超过单元格内部尺寸，可含背景孔洞）。绝大多数精灵体图案（裁剪到包围框后含内部背景孔洞的完整位图）互不相同，但恰好有一个图案在两个不同的非最左列单元格中完全相同（颜色和布局均一致）。生成约束：出现两次的图案唯一；最左列单元格中只有标记像素、无精灵体。

**规则**：
1. 对每个非最左列单元格，裁剪其内部到前景像素的紧致包围框（保留包围框内的背景孔洞），得到该单元格的精灵体位图。
2. 比对所有精灵体位图（逐像素比较，含背景孔洞），找到恰好出现两次的唯一图案。该图案即为模板掩码。
3. 清空所有非最左列单元格的内部为黑(0)背景。
4. 对每个非最左列单元格，将模板掩码居中印入（若模板小于单元格内部，水平和垂直方向各居中，余数向左上偏移）；模板中所有前景像素被重涂为该单元格所在行的行标记颜色，背景孔洞保持黑(0)。
5. 分隔线和最左列标记像素保持不变。

**关键洞察**：模板不是预先放置在特定位置的（与参考题 5a5a2103 的指定模板单元格不同），必须通过全局比对发现"恰好出现两次"的图案才能确定。需对比多个示例确认选取标准是"两次"而非"最多次"或"最少次"。

## 新题 4：轮廓提取后按周长下滑

**组合逻辑**：[轮廓提取（从 outline 对象派生的操作）](创新：提取操作同时改变形状和位移量的计算基数) + [滑动/shift](已有) + [计数/counting](已有)；[面积决定位移/area_determines_displacement](创新改造：由周长而非面积决定位移) + [超界裁剪/clip_beyond_edge](已有)

**来源原语**：轮廓、包围框（dc2e9a9d）；滑动、计数、连通分量、面积决定位移、超界裁剪（8e301a54）

**依赖链**：对每个填充连通分量提取 4-连通轮廓 → 轮廓像素数（周长）决定该轮廓的下滑行数 → 下滑后的重叠由周长大小决定覆盖优先级。提取步骤同时改变了"画什么"和"移多远"：一个大面积近似圆形的分量面积可能为 25 但周长仅为 18，轮廓提取使其比按原始面积滑动时移动距离更短。删除轮廓提取则位移基数和绘制内容均错误；删除滑动则形状原地不动。

将每个填充前景分量变为仅保留边界的轮廓，然后按各自轮廓周长值向下滑动，重叠时小周长者居上。

**输入结构**：黑(0)背景，约 15x15 网格。3-5 个单色填充 4-连通分量，颜色各不相同（如蓝(1)、红(2)、绿(3)、黄(4)），每个 6-20 像素，形状不规则（非简单矩形，含凹陷或突起，保证轮廓像素数与总面积差异显著）。各分量互不接触，且不接触网格边缘。各分量的周长（4-连通轮廓像素数）互不相同。生成约束：至少有一个分量在滑动后部分超出网格底边（需裁剪）；至少有两个分量在滑动后存在像素重叠区域。

**规则**：
1. 对每个填充分量，提取 4-连通轮廓：保留所有至少有一个 4-连通邻居为黑(0)背景的前景像素；将所有 4-连通邻居均为同色前景的内部像素变为黑(0)。
2. 计算每个轮廓的像素数 P（即周长）。
3. 将每个轮廓整体向下滑动 P 行：轮廓中每个像素 (r,c) 移动到 (r+P, c)。原位置变为黑(0)。
4. 滑动后行坐标 >= 网格高度的像素被丢弃（裁剪）。
5. 若两个轮廓滑动后存在像素位置重叠，周长较小的轮廓绘制在上层（其颜色覆盖较大周长轮廓的颜色）。
6. 背景保持黑(0)。

**关键洞察**：轮廓提取不仅改变了形状（从实心变空心），还同步改变了位移量的计算基数——位移由周长而非面积决定。一个紧凑的实心分量（面积大、周长相对小）比一个细长的分量（面积小、周长相对大）可能反而移动更少。需对比多个示例中不同面积/周长比的分量才能确认位移基数是周长而非面积。

## 新题 5：旋转补全扩展自相似印章

**组合逻辑**：[对称补全/symmetry_complete](创新：补全增加前景像素数，从而增加自相似展开的块数) → [像素放大/scale_up + 自相似嵌套/self_similar_nesting](已有)；[四次旋转闭合/four_fold_closure](已有) 决定补全方式，[前景位置决定印章/foreground_positions_determine_stamp](已有) 决定展开位置；补全像素与原始像素在展开后用不同颜色区分

**来源原语**：对称补全、前景图案、正方形区域、旋转对称、四次旋转闭合（e40b9e2f）；像素放大、精灵体、自相似嵌套、前景位置决定印章（8f2ea7aa）；重涂色（dc2e9a9d / 150deff5）

**依赖链**：提取不完整基元 → 四次旋转补全增加前景像素 → 补全后的基元既是放置掩码又是印章内容（自相似嵌套） → 原始像素位置对应的块用原色，补全像素位置对应的块用替代色。删除补全步骤则展开块数不足（且丢失对称性）；删除展开步骤则仅完成补全未完成放大；删除颜色区分则无法追溯哪些块来自补全。

将局部前景基元做四折旋转补全以获得更多前景像素，再将补全后基元作为自相似展开的掩码和印章，原始位置的块与补全位置的块以不同颜色区分。

**输入结构**：黑(0)背景，网格大小为 n^2 x n^2（典型 n=4，即 16x16）。网格左上角 n x n 区域内有一个部分前景基元：若干像素为绿(3)，其余为黑(0)。该基元不具备 90° 旋转对称性，但做四次旋转闭合后无颜色冲突（即基元中没有两个属于同一旋转轨道的位置分别为绿色和黑色以外的不同前景色——此处只有绿和黑，所以只需保证旋转不在已有绿色位置产生冲突）。基元外的网格区域全为黑(0)。生成约束：原始基元有 k 个前景像素（k < n^2 的一半），四次旋转补全后有 m 个前景像素（m > k），输出网格恰好能容纳 m 个印章块（每块 n x n）。

**规则**：
1. 提取左上角 n x n 区域作为基元。
2. 对基元做四折旋转补全：对每个绿(3)像素，将其在 90°、180°、270° 旋转下的映射位置（以 n x n 区域中心为旋转中心）也标记为前景。新增的前景像素标记为黄(4)（区别于原始绿(3)）。
3. 自相似展开：对补全后基元中每个前景像素（不论绿或黄）在局部坐标 (r,c) 处，将一份补全后基元的副本粘贴到输出网格的第 (r,c) 块（每块占 n x n 像素，块 (r,c) 在输出中的起始坐标为 (r*n, c*n)）。
4. 粘贴副本时的颜色规则：若该块对应的基元位置是原始绿(3)像素，则副本中所有前景像素用绿(3)绘制；若对应位置是补全新增的黄(4)像素，则副本中所有前景像素用黄(4)绘制。副本内的背景像素始终为黑(0)。
5. 基元中背景位置对应的块全为黑(0)。

**关键洞察**：旋转补全不仅改变了基元的视觉形态，还增加了自相似展开中"有内容"的块数量。绿/黄双色区分使得补全的"推断性"在宏观展开中可见——每个黄色块的存在本身就是旋转对称推理的结果。仅看一个示例可能无法确定黄色块是"补全位置"还是某种独立的颜色规则，需多个示例对比。

## 新题 6：循环换色后阻断射线传播

**组合逻辑**：[循环移位/cyclic_shift](已有) → [射线延伸/ray_extend](已有)；[有序槽位/ordered_slots](已有) 定义换色顺序，[阻挡点发射正交线/blocker_emits_orthogonal_line](创新改造：阻挡条件不是"有异色障碍"，而是"遇到与射线同色的竖条"——换色改变了哪些竖条成为阻挡者)

**来源原语**：循环移位、竖直条、条颜色、有序槽位、色与高反向轮转（2601afb7）；射线延伸、标记像素、对角线上阻挡（55783887）；连线（55783887）

**依赖链**：竖条按有序槽位排列 → 颜色循环右移一位 → 标记像素向两侧发射水平射线 → 射线遇到与自身同色的竖条时停止（不进入该竖条像素）。循环换色改变了哪些竖条与哪些标记同色，从而改变了射线的传播距离和覆盖范围。删除循环步骤则阻挡关系不同（射线长度改变）；删除射线步骤则仅有换色后的竖条、无水平射线。

先对一排竖直条循环换色，再让散布的标记像素发射水平射线，射线遇到换色后与自身同色的竖条即停，换色改变了射线的阻挡格局。

**输入结构**：黑(0)背景，约 12x12 网格。4-6 个单色竖直条（每条宽 1 像素，高度 3-8 像素不等，底部对齐网格底边），分布在不同列，颜色各不相同（如蓝(1)、红(2)、绿(3)、黄(4)、品红(6)）。竖条之间的间距至少 2 列。另有 2-3 个标记像素位于背景区域（不在任何竖条上），每个标记为某种颜色（与某些竖条颜色相同）。标记所在行在某些竖条的高度范围内（使射线有机会与竖条相交）。生成约束：换色前，没有竖条的颜色与任何标记颜色相同（因此换色前射线不会被任何竖条阻挡——可以自由穿越）；换色后，至少一个竖条获得了与某标记相同的颜色，形成新的阻挡。

**规则**：
1. 将竖条按列坐标从左到右排列为有序槽位 0, 1, 2, ...。
2. 循环换色：槽位 i 的竖条取槽位 i-1 的颜色（保持高度不变），槽位 0 取最后一个槽位的颜色。
3. 每个标记像素向左和向右各发射一条水平射线，射线颜色为标记的颜色。
4. 射线逐像素扩展：若下一像素为黑(0)背景，则染为射线颜色并继续；若下一像素属于换色后颜色与射线颜色不同的竖条，则该竖条像素被射线颜色覆盖（射线穿透异色竖条）并继续；若下一像素属于换色后颜色与射线颜色相同的竖条，则射线停止，该竖条像素保留竖条颜色不变（射线不进入同色竖条）；若到达网格边缘，射线停止。
5. 若两条射线到达同一背景像素，后处理的标记（按行坐标从上到下，同行按列坐标从左到右）的射线覆盖先处理的。
6. 标记像素本身保留不变。

**关键洞察**：循环换色在射线发射之前执行，改变了竖条的颜色身份。换色前没有竖条能阻挡任何标记的射线（生成约束保证），但换色后某些竖条获得了与标记匹配的颜色，形成了新的"同色墙"。射线的传播范围完全取决于换色结果，两个操作通过"同色阻挡"条件紧密耦合。

## 新题 7：锚定拼装后交替错移

**组合逻辑**：[拼接组装/assemble](已有) → [交替平移/alternating_shift](已有)；[锚定定位/anchor_positioning + 标记定输出朝向/marker_fixes_orientation](已有) 决定拼装方式，[排列顺序/ordering](创新：排列顺序由拼装结果的空间位置决定) + [奇偶定方向/parity_determines_dir](已有) 决定错移方向

**来源原语**：拼接组装、矩形精灵体、标记像素、锚定定位、标记定输出朝向（7b3084d4）；交替平移、单色前景体、排列顺序、奇偶定方向（4364c1c4）

**依赖链**：标记像素确定锚定精灵体及其输出朝向 → 所有精灵体拼装为无缝矩形 → 拼装后的空间位置（行主序）决定各精灵体的排名 → 奇数排名者左移 1 像素，偶数排名者右移 1 像素。删除拼装步骤则精灵体散布无序，排名未知；删除错移步骤则仅拼装无后续变换；删除锚定识别则拼装起点和朝向不确定。

将散布的矩形精灵体以标记像素为锚拼成紧密矩形，再按拼装后的空间排名交替左右错移。

**输入结构**：黑(0)背景，约 12x12 网格。3-5 个单色实心矩形精灵体（不同颜色，如蓝(1)、红(2)、绿(3)、黄(4)），大小各异（宽 2-4、高 2-5 像素）。其中一个精灵体的某个角像素被替换为品红(6)色（标记像素，与精灵体本色不同）。精灵体在网格中散布，互不接触。生成约束：所有精灵体（允许 90° 旋转）恰好能无缝拼成一个矩形；标记像素位于锚定精灵体的某个角上。

**规则**：
1. 识别含标记像素的精灵体为锚定精灵体。旋转锚定精灵体（0°/90°/180°/270°），使标记像素落在精灵体的左上角。
2. 将锚定精灵体放置在输出矩形的左上角（标记像素在 (0,0)）。
3. 将剩余精灵体（允许 90° 旋转）填入矩形的剩余空间，实现无缝铺满、无重叠。
4. 在拼装后的矩形中，按行主序（从上到下，同行从左到右）对每个精灵体的左上角坐标排序，得到排名 1, 2, 3, ...（锚定精灵体排名为 1）。
5. 奇数排名精灵体整体向左平移 1 像素；偶数排名精灵体整体向右平移 1 像素。
6. 平移后超出拼装矩形原始边界的像素被裁剪（丢弃）。平移后腾出的空位变为黑(0)背景。标记像素随其精灵体一起移动，保持品红(6)色。

**关键洞察**：交替错移的方向依赖于拼装后每个精灵体在矩形中的空间排名，而排名只有在正确拼装后才能确定。拼装方案可能不唯一（多种旋转组合），但标记像素锁定了锚定精灵体的朝向和位置，间接约束了其余精灵体的排列，使排名唯一确定。

## 新题 8：中位对齐线段界定编织区域

**组合逻辑**：[对齐/align](已有) → [编织填充/weave_fill](创新改造：编织区域的边界不由标记对决定，而由对齐后线段的共享跨度决定)；[中位线为参考/median_as_reference](已有) 决定对齐目标，[奇偶交替颜色/parity_alt_color](已有) 决定编织着色；交叉条提供编织的两种颜色

**来源原语**：对齐、线段、平行共向、中位线为参考（e376de54）；编织填充、交叉条、奇偶交替颜色（f3e14006）；裁剪/trim（e376de54）

**依赖链**：若干平行短线段按中位线对齐（改变各线段的起止列和长度） → 对齐后的线段共享一个列跨度 [c_left, c_right]，行跨度由最上和最下对齐线段的行坐标界定 → 该矩形区域内用两根交叉长条的颜色进行奇偶编织填充。删除对齐步骤则列跨度未统一，编织区域无法确定；删除编织步骤则仅完成对齐未产出网格纹。

将一组平行短线段按中位线的起止位置对齐，对齐后的公共跨度矩形区域用十字交叉条的两种颜色做奇偶编织填充。

**输入结构**：黑(0)背景，约 14x14 网格。一根蓝(1)色水平长条横贯网格某行（全宽或近全宽）。一根红(2)色垂直长条纵贯网格某列（全高或近全高）。二者交叉于一个像素。另有 3-5 根短水平线段（每段 3-6 像素长，颜色各异但不是蓝(1)或红(2)），位于不同行，起始列和长度各不相同，但方向一致（均水平）。短线段的行坐标各不相同，使中位线段唯一确定。生成约束：按行坐标取中位的那根短线段的列跨度与蓝/红交叉条均有重叠（即编织区域包含交叉条的部分区段）。

**规则**：
1. 在所有短水平线段中，按行坐标排序取中位线段（线段数为奇数时取正中，偶数时取靠上者）作为参考。
2. 对齐：将每根短线段水平平移使其左端与参考线段的左端对齐，然后截断或延伸使其长度与参考相同（延伸时新像素取该线段自身颜色；截断时丢弃超出部分）。
3. 对齐完成后，所有短线段共享列跨度 [c_left, c_right]（等于参考线段的列跨度）。行跨度为 [r_top, r_bottom]，其中 r_top 为最上方对齐线段的行坐标，r_bottom 为最下方对齐线段的行坐标。
4. 在矩形 [r_top..r_bottom] x [c_left..c_right] 内执行编织填充：位置 (r,c) 若 (r+c) 为偶数则涂蓝(1)，若为奇数则涂红(2)。此填充覆盖该矩形内的所有像素（包括背景、短线段、以及蓝/红长条落在此区域内的部分）。
5. 落在编织矩形内的对齐短线段保留原色绘制在编织之上（短线段像素覆盖编织像素）。
6. 编织矩形之外的蓝色水平长条和红色垂直长条保持不变。编织矩形之外的背景保持黑(0)。

**关键洞察**：编织区域的边界完全由中位对齐的结果决定——更换中位线段（因线段集合不同）会改变列跨度和行跨度，从而改变编织区域的大小和位置。对齐和编织通过共享边界紧密耦合。需要对比不同示例中线段数量和位置的变化来确认"中位线段"而非"最长线段"或"最短线段"是参考。

## 新题 9：全局计数定距离、颜色定方向的条件滑动

**组合逻辑**：[计数/counting](创新：计数对象为过滤干扰后的全局连通分量数，作为所有分量的共享位移量) + [滑动/shift](已有)；[忽略干扰项/ignore_distractors](已有) 过滤单像素噪声，[编码映射/encoding_map](创新改造：颜色不映射到模板而是映射到滑动方向) + [超界裁剪/clip_beyond_edge](已有)

**来源原语**：计数、连通分量、面积决定位移、超界裁剪（8e301a54）；查表映射、忽略干扰项、编码映射（9110e3c5）；滑动（8e301a54）

**依赖链**：过滤掉单像素干扰 → 统计剩余真实连通分量总数 N → N 成为所有分量的共同位移量 → 每个分量的颜色决定位移方向（蓝左/红下/绿右）。增减一个干扰像素不改变 N（因被过滤），但增减一个真实分量改变所有分量的位移量。删除过滤步骤则 N 计算错误；删除计数步骤则位移量未知；删除颜色→方向映射则方向未知。

过滤单像素干扰后统计连通分量总数 N，所有分量均按 N 行/列滑动，但各分量的颜色决定各自的滑动方向。

**输入结构**：黑(0)背景，约 12x12 网格。3-5 个单色 4-连通分量（每个 3-8 像素，尺寸 >= 2 像素，形状不规则且各不相同）。每个分量为蓝(1)、红(2)或绿(3)之一（可有同色分量，但颜色至少出现两种）。另有 3-6 个散布的单像素干扰点（颜色任意，1-连通大小为 1，与其他分量不相邻）。生成约束：过滤干扰后真实分量数 N 在 2-5 之间；至少一个分量在按 N 行/列滑动后部分超出网格边缘（需裁剪）；滑动后至少有两个分量存在像素位置重叠。

**规则**：
1. 识别所有 4-连通前景分量（任何非黑色像素为前景）。
2. 丢弃所有像素数为 1 的分量（干扰项），这些像素变为黑(0)背景。
3. 统计剩余分量总数 N。
4. 对每个剩余分量，根据颜色确定滑动方向：
   - 蓝(1)：向左滑动 N 列（每个像素列坐标减 N）。
   - 红(2)：向下滑动 N 行（每个像素行坐标加 N）。
   - 绿(3)：向右滑动 N 列（每个像素列坐标加 N）。
5. 原始位置变为黑(0)。滑动后超出网格边界的像素被丢弃。
6. 若两个分量滑动后存在像素重叠，像素数较少的分量绘制在上层（其颜色优先）。像素数相同时，原始位置更靠近网格左上角（行主序）的分量居上。

**关键洞察**：位移量是全局属性（过滤后的分量总数），而非每个分量自身的属性。增加或减少一个真实分量会改变所有分量的位移距离——这是一种"群体效应"，与参考题 8e301a54 中每个对象自决位移量的模式完全不同。颜色编码方向而非距离，也与参考题中"面积决定位移"的自身属性模式形成对比。需对比多个示例中分量数目变化与位移量变化的对应关系才能发现这一全局规则。
