## 新题 1：墙壁可达性决定精灵旋转角度

**组合逻辑**：[洪泛填充 + 可达性](创新：可达性结果不再用于聚集，而是转化为计数值) → [计数](已有) → [旋转](创新：旋转角度由可达标记数取模决定，而非由标记几何位置决定) → [擦除](已有)

**来源原语**：洪泛填充/可达性/墙壁障碍/标记像素(dd6b8c4b)、旋转/精灵体(ecaa0ec1)、计数(d0f5fe59)、擦除(dd6b8c4b)

**依赖链**：墙壁拓扑决定每个精灵可达哪些标记 → 可达标记数对 4 取模产生旋转参数 → 旋转改变精灵形态 → 已消耗的标记被擦除。删除可达性判断则旋转角度无从确定；删除旋转则精灵形态不变；删除擦除则标记残留导致输出错误。

根据墙壁拓扑判定每个精灵能到达多少标记像素，按可达数取模旋转精灵并擦除已用标记。

**输入结构**：约 15x15 的网格。背景为黑(0)。品红(6) 像素组成若干不相连的直线段或折线段充当墙壁障碍，将网格分割成若干连通的地面区域。网格中散布 3 个两色精灵体（每个精灵由蓝(1) 和绿(3) 像素组成的 3x3 非对称图案，各精灵形状相同但位置不同，像素数固定为 9）。另有若干红(2) 单像素标记散布在网格各处（总数约 8~12 个）。生成约束：每个精灵所在的地面连通区域至少包含 1 个标记像素；不同精灵的可达标记数对 4 取模的结果互不相同；精灵旋转后不会与墙壁或其他精灵重叠；精灵与标记之间的曼哈顿距离不能直接推断可达性（即存在近距但被墙壁阻隔而不可达的标记）。

**规则**：
1. 对每个精灵，从其占据的所有像素出发，通过 4-连通洪泛填充扩展到背景(0) 和红(2) 像素（品红(6) 墙壁不可通行，其他精灵像素不可通行），标记所有可达的红(2) 像素。
2. 统计该精灵的可达红色标记数量 K。
3. 计算旋转参数 R = K mod 4。R=0 不旋转，R=1 顺时针旋转 90 度，R=2 旋转 180 度，R=3 顺时针旋转 270 度。旋转以精灵 3x3 边界框的中心为旋转中心，原地旋转。
4. 将该精灵的可达红色标记像素全部替换为背景色(0)（擦除）。不可达的红色标记保持不变。
5. 所有精灵独立处理，处理顺序不影响结果（生成约束保证各精灵的可达区域互不重叠，各精灵旋转后互不冲突）。
6. 墙壁(6) 保持不变。

**关键洞察**：空间距离近的标记可能因墙壁阻隔而不可达，距离远的标记反而可能通过迂回通道可达——旋转角度取决于墙壁拓扑而非欧氏距离，必须对比多个示例才能发现 K mod 4 与旋转角度的对应关系。

## 新题 2：拓扑封闭性门控原型互换与边界吸色

**组合逻辑**：[包含/封闭区域检测](创新：封闭性不再用于判断重涂色，而是作为互换操作的门控条件) → [替换/互换原型](创新：仅被封闭的精灵执行互换，开放精灵不变) → [重涂色](创新：封闭边界吸收互换后新精灵的主色)

**来源原语**：包含/封闭区域/有空洞则重涂(810b9b61)、替换/互换原型/缩放/原型精灵/锚点区域(c7f57c3e)、重涂色(810b9b61)

**依赖链**：拓扑封闭检测将精灵分为"封闭"和"开放"两类 → 仅封闭类执行原型互换，产生新形态 → 互换后新精灵的主色回写到封闭边界。删除封闭检测则无法区分哪些精灵需要互换；删除互换则封闭精灵形态不变且边界无法确定吸收什么颜色；删除边界重涂色则输出与仅做互换无区别（无法验证封闭逻辑）。

检测哪些精灵被闭合边界完全包围，仅对被包围的精灵执行原型互换，再用新精灵的主色重涂其封闭边界。

**输入结构**：约 18x18 的网格。背景为青(8)。网格中存在两种原型图案 P1 和 P2（P1 为红(2) 像素组成的不对称 4-连通小图形，约 4~6 像素；P2 为橙(7) 像素组成的另一种不对称 4-连通小图形，像素数与 P1 相同）。P1 和 P2 各出现 2~3 个实例，均为 1 倍缩放（不做缩放变体）。其中部分精灵被灰(5) 像素组成的闭合边界完全包围——灰色边界是 8-连通闭合环，环内区域包含恰好一个精灵，环与精灵之间有至少 1 像素的背景间隔。其余精灵附近可能有灰(5) 像素片段，但不构成闭合环。生成约束：每种原型至少有 1 个被封闭实例和 1 个开放实例；闭合边界的形状不规则（非矩形），不同示例中边界形状不同；灰色片段（非闭合）的存在使得不能仅靠"附近有灰色"来判断封闭性。

**规则**：
1. 识别所有精灵实例，判定每个实例匹配原型 P1 还是 P2（通过像素颜色和相对形状匹配，颜色直接区分：红(2) 为 P1，橙(7) 为 P2）。
2. 对每个精灵，检测其是否被灰(5) 像素拓扑封闭——判据：从精灵外部紧邻的背景像素出发，4-连通洪泛填充仅通过背景(8) 像素扩展，如果填充无法到达网格边缘，则该精灵被封闭。
3. 被封闭的精灵执行原型互换：P1 实例替换为 P2 的形状（使用橙(7)），P2 实例替换为 P1 的形状（使用红(2)）。互换以精灵边界框左上角为对齐锚点，新形状放置于同一锚点位置。
4. 互换完成后，将该精灵封闭边界上所有灰(5) 像素重涂为互换后新精灵的颜色（原为 P1 红色的变为 P2 后涂橙(7)；原为 P2 橙色的变为 P1 后涂红(2)）。
5. 未被封闭的精灵及其附近的灰色片段均保持不变。
6. 背景(8) 不变。

**关键洞察**：判断封闭性是拓扑问题而非距离问题——一个精灵可能被灰色像素三面包围但仍然"开放"（因为有缺口连通到网格边缘），而另一个精灵的灰色边界看似稀疏但实际上通过 8-连通形成了闭合环。必须对比多个示例才能确认：只有拓扑封闭的精灵才会互换，且边界颜色随之改变。

## 新题 3：最密分区提供印章模板，稀疏像素引导旋转放置

**组合逻辑**：[筛选/最密区域保留](创新：最密区域不是最终输出，而是提供模板精灵) → [裁剪](已有) → [旋转 + 镜像 + 印章覆盖/颜色一致对齐](创新：模板来源于密度筛选而非预设，对齐目标是其他区域的稀疏像素) → [擦除](创新：模板源区域被清空)

**来源原语**：筛选/最密区域保留填充/分区区域/分隔线(29623171)、裁剪(7bb29440)、旋转/镜像/印章覆盖/颜色一致对齐/稀疏像素引导放置(0e206a2e)、擦除(dd6b8c4b)

**依赖链**：密度筛选确定哪个区域是模板源 → 裁剪提取模板精灵 → 稀疏像素引导对齐确定各目标区域的放置位置和朝向 → 模板源区域被清空。删除密度筛选则不知裁剪哪个区域；删除颜色一致对齐则不知如何放置模板；删除源区域清空则输出多出一份原始模板。

从被分隔线划分的多个区域中筛选最密区域作为精灵模板，裁剪后通过旋转/翻转对齐各稀疏区域的锚点像素进行印章放置，最后清空源区域。

**输入结构**：约 20x20 的网格。背景为黑(0)。黄(4) 像素组成 1~2 条贯穿整行的水平分隔线和 1~2 条贯穿整列的垂直分隔线，将网格分割为 4~6 个矩形区域。其中一个区域（"模板区"）包含较多非背景非分隔线颜色的像素（约 8~15 个像素），这些像素组成一个 4-连通的不对称多色小图形（使用蓝(1)、红(2)、绿(3) 中的 2~3 种颜色）。其余每个区域（"目标区"）各包含 2~3 个孤立的彩色像素，颜色取自模板图形中出现的颜色子集。生成约束：模板区的彩色像素数量严格多于任何目标区；模板图形不具有旋转对称性或镜像对称性（确保对齐方案唯一）；每个目标区的稀疏像素恰好对应模板图形在某个旋转/翻转变体下的部分像素位置（颜色一致），且该变体唯一；不同目标区对应不同的旋转/翻转变体。

**规则**：
1. 识别黄(4) 分隔线划分出的所有矩形区域。
2. 统计每个区域中非黑(0)、非黄(4) 像素的数量，选出像素最多的区域作为模板区。若存在并列，选边界框左上角更靠左上方的区域。
3. 以模板区的边界框为参考，裁剪出模板图形的相对坐标（每个像素相对于区域左上角的行列偏移及颜色）。
4. 生成模板图形的全部 8 个变体（0/90/180/270 度旋转 x 是否水平翻转）。
5. 对每个目标区，遍历 8 个变体，找到唯一一个变体使得：将该变体的左上角对齐到目标区内某个位置后，变体中与目标区已有稀疏像素重叠的位置全部颜色一致，且无颜色冲突。选择覆盖稀疏像素最多的对齐方案（生成约束保证唯一最优）。
6. 将选中的变体印章到目标区中：变体的像素覆盖到目标区对应位置，仅覆盖背景(0) 像素和已有稀疏像素位置，不覆盖分隔线。超出目标区边界的部分舍弃。
7. 将模板区中的所有非分隔线像素替换为背景色(0)（清空模板区）。
8. 分隔线(4) 保持不变。

**关键洞察**：最密区域不是答案本身而是模板来源——它的内容被"分发"到所有其他区域后自身被清空。稀疏像素是模板的"投影锚点"，必须同时匹配颜色和位置才能确定正确的旋转/翻转变体，单看一个示例可能无法区分模板区的角色（是保留还是清空）。

## 新题 4：障碍绕行式对角连接线

**组合逻辑**：[连线/对角补全连接](创新：对角连线不再沿直线绘制，而是在遇到障碍时发生路径偏折) + [绕行/遇障碍绕最近侧](创新：绕行逻辑从垂直射线场景迁移到对角线场景，绕行后以新列继续对角而非垂直) → [擦除](已有：清除孤立噪声)

**来源原语**：连线/对角补全连接/同色矩形对/对角偏移/对角线段(342ae2ed)、绕行/遇障碍绕最近侧/障碍线段(c87289bb)、擦除/噪声像素(91714a58)

**依赖链**：同色矩形对确定需要连接的端点 → 对角路径计算确定理想直线 → 障碍线段检测发现阻塞点 → 绕行逻辑确定偏折方向和新列 → 对角线在新列继续。删除对角连接则无连线可画；删除绕行逻辑则连线被阻塞无法完成；障碍位置影响绕行方向，绕行方向改变后续对角线的列位置。

在同色矩形对之间绘制对角连线，遇到水平障碍线段时绕行至最近空闲侧再继续沿对角方向前进。

**输入结构**：约 18x18 的网格。背景为黑(0)。网格中有 2~3 对同色实心矩形（每对颜色不同，使用蓝(1)、绿(3)、橙(7) 等；每个矩形约 2x2~3x3）。每对矩形沿 45 度对角偏移放置（一个在左上方，一个在右下方，两者最近的对角方向面对角之间有空隙）。网格中另有若干红(2) 水平障碍线段（每段为同一行上连续的 2~5 个红色像素），部分线段横跨某些矩形对的对角路径。可能有少量灰(5) 噪声像素散布在网格中。生成约束：每对矩形的理想对角路径（从上方矩形的右下角像素到下方矩形的左上角像素，沿 45 度逐行递增逐列递增）至多经过 1 条障碍线段；至少有 1 对矩形的对角路径被障碍阻挡，至少有 1 对不被阻挡；障碍线段不与任何矩形重叠；绕行后的新对角路径不会再遇到第二条障碍。

**规则**：
1. 移除所有灰(5) 噪声像素（替换为背景）。
2. 对每种前景颜色（非黑(0)、非红(2)、非灰(5)），找到该颜色的两个矩形。确定上方矩形（边界框中心行较小者）的右下角像素 S，和下方矩形（边界框中心行较大者）的左上角像素 T。
3. 从 S 向 T 方向沿 45 度对角线逐步绘制（每步行+1、列+1）。仅绘制在已有矩形像素之外的背景像素上，使用该对颜色。
4. 若对角线下一步将进入红(2) 障碍线段所在的行：在进入障碍的前一行停止对角绘制。从当前位置向左或向右水平搜索该障碍线段的两个端点，选择距当前列更近的一侧端点；在该行水平绘制从当前列到该端点外侧一列的连线（即绕过障碍端点再多走一列），使用该对颜色。若左右等距，选择右侧。
5. 绕行结束后，从绕行终点位置的下一行开始，继续以 45 度对角线向 T 方向绘制，直到到达 T 所在的行或列（以先到者为准）。若到达 T 的行时列位置与 T 不同，在 T 所在行从当前列水平绘制至 T 的列，作为最终水平修正段。
6. 红(2) 障碍线段保持不变。

**关键洞察**：绕行方向取决于障碍线段哪一端离当前对角线列更近，而非哪一端离目标矩形更近。这意味着相同的目标矩形对在不同示例中（障碍位置不同）可能产生不同方向的绕行，需要对比多个示例才能发现"就近绕行"规则。

## 新题 5：环形连接器决定传播色源，帧内底部标记引导纵向填充

**组合逻辑**：[环形连接/顺时针轮换](创新：轮换的不是遮罩颜色而是传播色源) + [传播/逐列填充/底行标记选定列](创新：传播发生在帧内部而非全局列中，传播的颜色来自环形邻居而非自身)

**来源原语**：环形连接/顺时针轮换/空心方框/连接线/内部遮罩/重涂色(ad173014)、传播/逐列填充/底行标记像素/纵向色带(17b80ad2)

**依赖链**：蓝色连接线确定帧的环形拓扑顺序 → 顺时针取下一帧的遮罩颜色作为传播色 → 帧内底行标记确定在哪一列执行传播 → 传播用环形邻居的颜色填充该列的背景间隙。删除环形顺序则不知传播什么颜色；删除传播机制则不知在哪里和如何绘制颜色；两者任一缺失都无法确定输出。

在由连接线串成环的空心帧中，每个帧内底行标记列使用来自环形下一帧的遮罩颜色执行向上传播填充。

**输入结构**：约 20x20 的网格。背景为黑(0)。网格中有 3~4 个红(2) 空心方框（每个约 6x6~8x8，框壁厚度 1 像素）。蓝(1) 像素组成线段将方框两两连接，形成唯一的环形通路（每个方框恰好与两个蓝色线段连通）。每个方框内部包含：(a) 一个由单一颜色组成的图案遮罩（使用绿(3)、黄(4)、橙(7)、品红(6) 等互不相同的颜色，占据框内部约 3~6 个像素，形状不规则且不同示例形状不同），其余内部像素为背景(0)；(b) 框内最底行（紧贴框下壁上方一行）恰好有 1 个灰(5) 标记像素，该标记所在列穿过框内部。生成约束：3~4 个帧的遮罩颜色两两不同；蓝色连接线不与帧内部重叠；各帧按中心坐标可以无歧义地确定顺时针顺序；灰(5) 标记所在列在框内至少有 2 个背景像素位于遮罩像素上方（确保传播可见）。

**规则**：
1. 从蓝(1) 连接线的拓扑中识别帧的环形连接关系。
2. 将所有帧按其中心坐标的极角排序（以所有帧中心的质心为原点，角度从正上方顺时针计量），确定顺时针顺序。
3. 对每个帧 F_i，确定顺时针方向的下一个帧 F_{i+1}（最后一个帧的下一个是第一个）。取 F_{i+1} 的内部遮罩颜色 C 作为 F_i 的"传播色"。
4. 在 F_i 内部，找到灰(5) 标记像素所在的列 col。
5. 在 F_i 内部沿 col 列从底部向顶部扫描（从标记像素位置向上）：将标记像素本身替换为传播色 C；继续向上，每遇到背景(0) 像素则替换为 C，遇到遮罩像素或帧壁则停止。
6. 帧内原有遮罩像素保持其原始颜色不变。
7. 红(2) 帧壁、蓝(1) 连接线、背景(0) 中不属于帧内部的像素均保持不变。

**关键洞察**：每个帧中出现的新颜色不是它自己的遮罩颜色，而是环形顺序中下一个帧的遮罩颜色——需要先从连接线拓扑重建环形顺序，才能确定每个帧应该传播哪种颜色。仅看单个帧无法推断传播色的来源，必须对比多个帧之间的颜色交换模式。

## 新题 6：可达性过滤标记数选择矩形，再按自身宽度平移

**组合逻辑**：[洪泛填充 + 可达性](创新：可达性不用于聚集而用于过滤标记计数) → [选择/最少标记数](创新：标记计数基于可达性过滤后的子集而非全部标记) → [平移/按自身宽度平移](已有) → [擦除](已有：清除未选中对象)

**来源原语**：洪泛填充/可达性/墙壁障碍(dd6b8c4b)、选择/最少标记数/前景矩形/标记像素(7bb29440)、平移/按自身宽度平移/边界框决定偏移(64a7c07e)、擦除(91714a58)

**依赖链**：墙壁拓扑过滤每个矩形的可达标记数 → 最少可达标记数确定被选中的矩形 → 被选中矩形按自身宽度右移 → 未选中矩形和所有标记被擦除。删除可达性过滤则标记计数错误导致选错矩形；删除选择则不知平移哪个矩形；删除平移则选中矩形位置不变。

通过墙壁限制的洪泛可达性过滤每个矩形能感知到的标记像素数量，选出可达标记最少的矩形并按自身宽度向右平移，擦除其余一切。

**输入结构**：约 16x16 的网格。背景为灰(5)。品红(6) 像素组成墙壁障碍（若干不相连的直线段或 L 形折线段，每段 3~8 像素）。网格中有 3~4 个单色实心矩形（每个矩形使用不同的颜色：蓝(1)、绿(3)、黄(4)、橙(7) 等；尺寸约 2x2~2x4 或 3x3，各矩形形状可以不同）。另有若干红(2) 单像素标记散布在网格中（总数约 6~10 个）。生成约束：每个矩形的可达标记数互不相同（确保无并列）；至少一个矩形有近距但不可达的标记（被墙壁阻隔），使得仅凭距离判断会得出错误选择；被选中矩形（可达标记最少者）向右平移自身宽度后不越出网格边界且不与墙壁或其他矩形的原始位置重叠；矩形之间互不相邻（至少间隔 1 像素）。

**规则**：
1. 对每个矩形，从其占据的所有像素出发，通过 4-连通洪泛填充扩展到背景(5) 和红(2) 像素（品红(6) 墙壁不可通行，其他矩形像素不可通行），标记所有可达的红(2) 标记像素。
2. 统计每个矩形的可达标记数量。
3. 选出可达标记数量最少的矩形作为目标矩形。若存在并列（生成约束排除此情况，但规则需完备），选边界框面积较小的矩形。
4. 将目标矩形向右平移其自身边界框的宽度（例如宽度为 3 则向右平移 3 列）。原位置替换为背景色(5)。
5. 擦除所有非目标矩形（替换为背景色）。
6. 擦除所有红(2) 标记像素（替换为背景色）。
7. 品红(6) 墙壁保持不变。

**关键洞察**：选择标准不是"最少标记"而是"最少可达标记"——墙壁障碍隐藏了部分标记的可达性。一个被标记包围但被墙壁封锁的矩形可能只有很少的可达标记。需要对比多个示例才能排除"最近标记"或"总标记数"等竞争假设，发现可达性过滤是关键。

## 新题 7：标记选定列的向上传播遇障碍绕行

**组合逻辑**：[传播/逐列填充/底行标记选定列](创新：传播方向上行时可被水平障碍打断) + [绕行/遇障碍绕最近侧](创新：绕行逻辑从垂直下落场景迁移到垂直上升传播场景，绕行后在新列继续上行传播) → [重涂色](已有：绕行段使用传播色)

**来源原语**：传播/逐列填充/底行标记像素/纵向色带(17b80ad2)、绕行/遇障碍绕最近侧/障碍线段/源列(c87289bb)、重涂色(810b9b61)

**依赖链**：底行标记选定需要传播的列 → 传播色沿列向上填充背景间隙 → 遇到障碍线段时绕行至最近侧 → 绕行后在新列继续传播，可能与原列产生分叉。删除列选择则不知处理哪些列；删除传播则无颜色填充；删除绕行则传播被障碍截断无法完成。

从底行标记像素开始向上传播颜色填充，遇水平障碍线段时绕行至最近空闲侧后继续在偏移列中向上传播。

**输入结构**：约 15x20 的网格（高度大于宽度）。背景为黑(0)。底行（第 19 行）有 2~3 个非背景单像素标记（使用蓝(1)、绿(3)、橙(7) 等不同颜色），每个标记标识一个需要处理的列。每个被标记的列中散布着若干与标记同色的彩色像素（约 2~4 个，位于不同行），像素之间有背景间隔。网格中另有若干红(2) 水平障碍线段（每段为同一行上连续的 3~6 个红色像素），部分线段横跨被标记列的传播路径。生成约束：每条障碍线段至多阻断 1 个被标记列的传播路径；至少有 1 个列的传播路径被障碍阻断，至少有 1 个不被阻断；绕行后的新列上不存在第二条障碍；绕行不会导致两个不同列的传播路径汇合到同一列。

**规则**：
1. 识别底行的标记像素，每个标记定义一个"传播列"及其"传播色"（即标记的颜色）。
2. 对每个传播列，从底行标记位置开始向上逐行扫描。维护"当前传播色" = 最近遇到的非背景像素颜色（初始为标记颜色）。
3. 向上扫描时，若当前像素为背景(0)，则替换为当前传播色。若当前像素为该列的同色彩色像素，更新当前传播色为该像素颜色（实际颜色不变，但确认色带延续）。保留原有同色像素不变。
4. 若向上扫描的下一行中，当前列位置为红(2) 障碍像素：停止向上扫描。在当前行（障碍的下方一行），从当前列向左和向右分别搜索该障碍线段的两个端点。选择距当前列更近的一侧；在当前行水平绘制从当前列到该端点对应列再外移一列的水平线段，使用当前传播色。若左右等距，选择右侧。
5. 绕行完成后，从绕行终点所在的列、障碍线段上方一行开始，继续向上逐行传播（规则同步骤 2-3）。传播色保持绕行前的值。
6. 传播在到达网格顶行（第 0 行）或遇到非背景、非同色像素时停止。
7. 未被标记选中的列不做任何处理。红(2) 障碍线段保持不变。

**关键洞察**：传播和绕行紧密耦合——绕行不仅改变了颜色填充的空间路径，还使得一条"纵向色带"在中途跳到了另一列继续延伸，最终产生 Z 字形或阶梯形的色带。需要对比多个示例才能发现绕行方向取决于障碍端点的相对距离而非目标列的原始位置。
