## 新题 1：拓扑封闭门控象限涂色

**组合逻辑**：[flood_fill](创新：用于拓扑封闭性检测而非直接涂色) + [split](象限划分) + [recolor](角标驱动涂色)

**来源原语**：flood_fill / enclosed_region / topological_in_out（来自 00d62c1b）；split / quadrant / diag_marker / corner_correspond（来自 e9ac8c9e）；recolor（来自 e9ac8c9e, 8dae5dfc）

**依赖链**：泛洪填充从网格边界向内标记所有可达的黑(0)像素，未被标记的黑像素即为被绿(3)边界拓扑封闭的区域——这一步决定了哪些区域参与后续处理。只有被封闭的矩形区域才被四等分并用对角标记像素指定的颜色涂色；未封闭的绿形状是干扰项，不处理。封闭检测的结果直接过滤了象限涂色的作用域。

将被绿色边界拓扑封闭的矩形黑区识别出来，四等分后用其外侧四角的标记像素颜色分别涂色。

**输入结构**：
- 背景为黑(0)，网格约 20x20
- 网格中有 2-4 个由绿(3)像素构成的闭合或非闭合形状。闭合形状为绿像素沿 4-连通路径围成的封闭环，内部围出一个矩形黑区域（宽、高均为偶数，至少 4x4）。非闭合形状为绿像素构成的开放曲线或断裂环（有至少一个缺口），不围出封闭区域
- 每个闭合绿边界的外接矩形（bounding box）的四个对角位置各有一个标记像素，位于对角外侧 1 格处（即 bounding box 左上角的左上方、右上角的右上方、左下角的左下方、右下角的右下方各 1 像素）。四个标记像素颜色互不相同，取自蓝(1)、红(2)、黄(4)、灰(5)、品红(6)、橙(7)、青(8)
- 非闭合形状没有标记像素
- 生成约束：各绿形状及其标记像素互不重叠；闭合区域的内部矩形宽高为偶数以确保四等分无余数；标记像素不与任何绿像素或其他标记像素相邻

**规则**：
1. 从网格四条边上所有黑(0)像素出发做泛洪填充（4-连通），标记所有可达的黑像素为"外部"
2. 未被标记的黑像素即为"封闭内部"像素。将每个 4-连通的封闭内部区域识别为一个封闭矩形区域
3. 对每个封闭区域，找到包围它的绿边界的 bounding box（绿边界像素的最小外接矩形），在该 bounding box 四对角外侧 1 格处读取标记像素颜色
4. 将封闭内部矩形沿水平和垂直中线四等分为左上、右上、左下、右下四个象限
5. 用左上对角标记色填充左上象限，右上标记色填充右上象限，左下标记色填充左下象限，右下标记色填充右下象限
6. 绿边界像素保持不变；标记像素设为黑(0)（移除）；非闭合绿形状及其周围区域不做任何修改
7. 多个封闭区域的处理顺序不影响结果（它们互不重叠）

**关键洞察**：绿色边界同时承担两个角色——判断封闭性（拓扑检测的材料）和定位标记像素（提供 bounding box 以定位对角标记）。非闭合绿形状是专门设计的干扰项：它们在视觉上与闭合形状相似，但因缺口的存在，其内部黑像素可从外部泛洪到达，因此不参与涂色。求解者必须先正确实现拓扑封闭检测，才能知道哪些区域该被处理。

## 新题 2：拼图组装涌现嵌套层并反转色序

**组合逻辑**：[assemble](连接器配对拼装) → [layer_order_reversal](对拼装后涌现的嵌套层反转颜色)

**来源原语**：assemble / connector_pixel / connector_pairing / anchor_sprite / incremental_assembly（来自 cbebaa4b）；layer_order_reversal / nested_rect_layer / nesting_hierarchy / color_sequence_reversed（来自 8dae5dfc）

**依赖链**：散落的精灵体各自不含完整的嵌套矩形层——只有通过连接器配对拼装成一个整体后，才涌现出同心矩形嵌套层结构。层序反转必须在拼装完成后才能执行，因为反转的对象（嵌套层颜色序列）在拼装前不存在。拼装决定了嵌套层的几何结构，嵌套层结构决定了反转的映射。

将散落精灵体通过红色连接器像素拼装成一体，拼装后的矩形结构呈同心嵌套层，将这些层的颜色由外到内反转。

**输入结构**：
- 背景为黑(0)，网格约 18x18
- 3-5 个单色矩形精灵体散落在网格上，颜色分别取自蓝(1)、绿(3)、黄(4)、灰(5)、橙(7)（每个精灵体整体为单一颜色，不同精灵体颜色不同）
- 其中一个精灵体在中心区域包含一个 2x2 的品红(6)锚块，该精灵体为锚点精灵
- 每个精灵体的边缘有 1-3 个红(2)像素作为连接器，红像素替换了该位置原本应有的精灵体颜色
- 正确拼装后，所有精灵体拼成一个大矩形（无间隙无重叠），且该大矩形从外到内呈同心矩形嵌套层——最外一圈是一种颜色，去掉最外圈后次外圈又是一种颜色，依此类推
- 拼装后红(2)连接器像素被其所属精灵体的颜色替代（即还原为该精灵体本色）
- 生成约束：每个红连接器恰好与另一个精灵体的一个红连接器在拼装后重合；拼装结果为合法的同心矩形嵌套层（每层均为均匀单色矩形环）；精灵体在散落状态下互不重叠

**规则**：
1. 锚点精灵（含品红(6) 2x2块的精灵体）保持原位不动
2. 逐步将其余精灵体平移（不旋转、不翻转）拼接到已有组装体上：每一步选择与当前组装体边界上未配对红连接器匹配数最多的精灵体；匹配数相同时，选择散落位置中左上角更靠左的精灵体（再按更靠上打破平局）
3. 平移精灵体使其红连接器与组装体上对应的红连接器重合。重合后，两个红像素都被替换为各自所属精灵体的本色
4. 全部拼装完成后，得到一个大矩形。从最外圈开始逐层剥离均匀的矩形边界，记录各层颜色序列 C1（最外）, C2, ..., Ck（最内）
5. 将每层的颜色反转：最外层涂 Ck 色，第二层涂 C(k-1) 色，...，最内层涂 C1 色
6. 品红(6)锚块保持品红不变（不参与反转）
7. 输出为反转后的大矩形裁剪到其 bounding box，背景为黑(0)

**关键洞察**：没有任何一个散落精灵体自身能展现出"嵌套层"结构——嵌套层是拼装的涌现结果。求解者不仅要正确拼装（连接器配对），还要理解拼装后的整体几何结构才能执行反转。品红锚块是反转的不动点，帮助求解者锚定层序。

## 新题 3：分形蓝图指定列延伸目标

**组合逻辑**：[scale / self_similarity](少数单元位置构成分形蓝图) → [ray_extend](蓝图激活的列向下延伸着色)

**来源原语**：scale / tile / self_similarity / separator_grid / minority_cell / majority_cell / minority_pattern_as_blueprint（来自 b99e7126）；ray_extend / same_column_propagation / fill_column_to_bottom / foreground_source（来自 d037b0a7）

**依赖链**：少数单元在 NxN 单元网格中的位置构成一个小型二值图案 P。将 P 按 N 倍放大覆盖整个单元网格，标记出"活跃单元"。只有活跃单元中的彩色像素才执行向下列延伸。分形蓝图决定了延伸的作用域，列延伸改变了大量单元的内容——两个操作在空间上深度交织。

利用少数单元在网格中的排布作为分形蓝图，放大后确定哪些单元列执行向下颜色延伸。

**输入结构**：
- 背景为黑(0)，网格约 15x15
- 灰(5)分隔线（1 像素宽）将网格划分为 NxN 排列的等大单元格（N = 3 或 4，每个单元格内部为 3x3 像素）
- 大部分单元格内部全黑（多数单元）
- 2-4 个单元格内部包含一个彩色像素（非黑、非灰），位于单元格内部的某个位置——这些是少数单元。不同少数单元的彩色像素可以是不同颜色（取自蓝(1)、红(2)、绿(3)、黄(4)、橙(7)），但在单元格内部的相对位置相同（例如都在内部的第 2 行第 1 列）
- 少数单元在 NxN 网格中的行列位置构成一个二值图案 P（少数=1，多数=0）
- 生成约束：P 中至少有 2 个"1"；P 放大 N 倍后叠回网格时，已有的少数单元位置与 P 中的"1"一致；各少数单元彩色像素的颜色互不相同

**规则**：
1. 识别 NxN 单元网格中所有少数单元的位置，构建二值图案 P（N 行 N 列，少数单元处为 1）
2. 将 P 放大到 NxN 单元网格尺度：P 的第 (i,j) 格对应单元网格中以 (i*N, j*N) 为左上角的 N x N 子块中的所有单元。若 P(i,j)=1，则该子块中的所有 N 个单元均为"活跃"单元
3. 已有的少数单元天然为活跃单元。新增的活跃单元（原为多数单元的空单元格）需填入一个彩色像素：颜色取自在单元网格中 Manhattan 距离最近的已有少数单元的颜色（距离相同时取最左的，再取最上的），位置为与已有少数单元相同的单元格内相对位置
4. 对每个活跃单元，将其彩色像素沿所在像素列（不是单元列）向下延伸：从该像素所在行开始，向下填充同色像素，直到遇到灰(5)分隔线时跳过该分隔线继续向下，直到到达网格底部边界
5. 延伸覆盖路径上的黑(0)像素和被跳过的分隔线下方的黑像素，但不覆盖其他彩色像素（遇到已有彩色像素时停止，不包含该像素）
6. 灰分隔线本身保持不变；非活跃单元保持全黑

**关键洞察**：分形蓝图不只是在复制图案（如源题 b99e7126），而是在指定一个完全不同的操作（列延伸）的作用范围。求解者需要先完成分形放大来确定哪些列被激活，然后才能执行延伸——而延伸的结果（垂直彩色条纹穿过多个单元）在视觉上与分形图案截然不同，增加了从输出反推规则的难度。

## 新题 4：反射生成互补拼图件并紧凑拼合

**组合逻辑**：[mirror](标记像素定轴反射) + [packing](原件与反射件互补拼合为矩形)

**来源原语**：mirror / singleton_marker / foreground_object / shared_row_col_align / alignment_mirror_axis（来自 963f59bc）；packing / polyomino_fragment / compact_rectangle / non_overlap_packing / descending_area_place（来自 b7cb93ac）

**依赖链**：每个多连块碎片旁的单像素标记同时编码了镜像轴方向和互补件的颜色。只有按该特定轴反射，碎片与其镜像才能无缝拼合为矩形——其他轴会留下空隙。反射创造了拼合所需的互补件，拼合验证了反射轴的正确性。

根据每个多连块碎片旁的单像素标记确定镜像轴，反射生成互补件，将每对原件-互补件拼合为紧凑矩形后排列输出。

**输入结构**：
- 背景为黑(0)，网格约 20x15
- 2-4 个单色 4-连通多连块碎片，像素数 3-7，颜色分别取自蓝(1)、绿(3)、黄(4)、青(8)（各碎片颜色不同）
- 每个碎片旁有恰好一个单像素标记，标记与碎片 4-相邻（共享一条边），标记颜色与碎片颜色不同且各标记颜色互不相同（取自红(2)、灰(5)、品红(6)、橙(7)）
- 每个标记恰好与碎片的一个像素共行或共列（不能同时共行又共列）
- 生成约束：以标记和共行/共列像素的中垂线为轴反射碎片后，原件与反射件恰好无缝拼合为一个实心矩形（无间隙、无重叠）；各碎片及其标记在输入中互不接触

**规则**：
1. 将每个单像素标记与其 4-相邻的碎片关联
2. 确定镜像轴：若标记与碎片某像素共行（同一行），则轴为过这两个像素中点的垂直线；若共列（同一列），则轴为过中点的水平线
3. 将整个碎片沿该轴反射，生成互补件。互补件颜色为标记的颜色
4. 将原件与互补件按反射位置关系拼合，得到一个实心矩形（原件保留原色，互补件为标记色）
5. 输出所有拼合后的矩形，按原碎片在输入中的 bounding box 左上角从左到右排列（左上角 x 坐标相同时按 y 坐标从上到下），矩形之间间隔 1 列黑像素，顶部对齐，背景为黑(0)
6. 标记像素不出现在输出中

**关键洞察**：标记像素不只是颜色图例——它的位置精确编码了唯一能使碎片与镜像互补拼合为矩形的那条轴。换一条轴反射，碎片就无法拼合。求解者必须发现标记同时承担"指定轴"和"命名互补件颜色"两个角色。

## 新题 5：对角平移改变行占用后跨面板压缩

**组合逻辑**：[translate](青角指示对角平移) → [compress](跨面板逆序扫描行压缩)

**来源原语**：translate / filled_rectangle / control_pixel / corner_indicates_dir / diagonal_fixed_step（来自 470c91de）；compress / concatenate / panel / divider_column / occupied_row / reverse_scan / empty_rows_discarded（来自 25c199f5）

**依赖链**：对角平移改变了每个面板中哪些行被占用（occupied_row）。行压缩只保留有内容的行，因此平移结果直接决定了压缩的输入。若不先平移就压缩，会保留不同的行集合，得到错误输出。两步操作通过"行占用状态"这一中间量紧密耦合。

在每个面板内将矩形按青色角指示的对角方向平移一格，然后从右到左扫描面板，仅保留有内容的行并压缩到单个面板底部。

**输入结构**：
- 背景为黑(0)，网格约 12x20（较高）
- 栗(9)分隔列（1 像素宽）将网格分为 2-3 个等宽面板，每个面板宽约 4-6 像素
- 每个面板内有 1-3 个小实心矩形（2x2 到 3x4 像素），颜色取自蓝(1)、绿(3)、黄(4)、灰(5)、橙(7)（同一面板内颜色不重复）
- 每个矩形有恰好一个角像素被替换为青(8)，表示对角平移方向（例如青在右上角 = 向右上平移 1 格）
- 面板内有足够空行，使平移后矩形不越出面板边界且不与其他矩形重叠
- 生成约束：平移后所有矩形保持在各自面板内；平移后无重叠；每个面板至少有 1 行在平移后变为全黑（保证压缩有效果）

**规则**：
1. 在每个面板内独立处理：对每个矩形，识别青(8)角像素在矩形四角中的位置，确定对角方向（左上→向左上 1 格、右上→向右上 1 格、左下→向左下 1 格、右下→向右下 1 格）
2. 擦除矩形原始位置（包括青像素），将完整矩形（青像素位置恢复为矩形本色）绘制在平移后的位置
3. 平移后：从右到左扫描面板（最右面板优先）
4. 在每个面板中从上到下逐行检查：若该行在面板范围内包含至少一个非黑像素，则保留该行；全黑行丢弃
5. 将所有保留的行按扫描顺序（右面板行在前，中面板行次之，左面板行在后；同一面板内保持上到下顺序）拼接
6. 在一个单面板宽度的输出网格中，将拼接后的行从底部向上排列，上方用黑行填满
7. 输出中不包含栗(9)分隔列和青(8)像素

**关键洞察**：青色角像素在两个操作中扮演不同的关键角色：在平移阶段，它是方向指令；在压缩阶段，它的消失（被本色替代）意味着平移已完成。平移使某些原本有内容的行变空、某些原本空的行变满，直接重塑了行压缩的结果。仅看平移前的布局无法推断最终压缩输出。

## 新题 6：槽位插入构建封闭体后径向泛洪填充

**组合逻辑**：[insert / rotate](尺寸匹配槽位插入) → [flood_fill + radiate](插入后形成的封闭体内泛洪填充并沿开口辐射)

**来源原语**：insert / rotate / rectangular_block / platform_slot / size_matches_slot / aligned_and_width_matched（来自 67c52801）；flood_fill / radiate / partial_enclosure / obstacle / fill_seed / opening_direction / obstacle_casts_shadow（来自 b9e38dc0）

**依赖链**：浮动矩形块插入平台槽位后，与已有的 U 形墙壁和平台共同围成半封闭区域。这些封闭区域在插入前不存在（墙壁+平台不够封闭）。泛洪填充从封闭区域内的种子像素出发，填满封闭区域并通过开口向外辐射。插入决定了封闭几何体的形状和开口方向，从而决定了填充的范围。

将浮动块按宽度匹配插入平台槽位，插入后与墙壁和平台围成半封闭区域，从种子像素出发泛洪填充并沿开口辐射，障碍物投射阴影阻断辐射。

**输入结构**：
- 背景为黑(0)，网格约 15x18
- 网格底行为灰(5)实心平台（贯穿整行）
- 平台上方一行由灰(5)段和黑(0)间隙交替组成，间隙即为槽位（宽 2-4 像素）；共 2-3 个槽位
- 每个槽位的上方或侧方有绿(3)像素构成的 U 形或 L 形部分墙壁，墙壁一端连接平台或槽位边缘的灰段，另一端悬空形成开口（开口方向为上、左或右之一，不向下因平台已封闭底部）
- 网格上部散布 2-3 个实心单色矩形块（颜色取自蓝(1)、黄(4)、青(8)），每块有一条边长度为 2，另一条边长度等于某个槽位宽度
- 每个槽位旁（在插入后会被封闭的区域内）有一个橙(7)种子像素
- 墙壁开口附近可能有 1-2 个栗(9)障碍像素
- 生成约束：每个块恰好匹配一个槽位（按较短边=2、较长边=槽位宽度匹配）；插入后每个墙壁+插入块+平台恰好形成一个有唯一开口的半封闭区域；种子像素位于封闭区域内部

**规则**：
1. 将每个浮动块与槽位匹配：块的较短边（若非 2 则旋转 90 度使之为 2）对应行数，较长边对应槽位宽度。每个块唯一匹配一个槽位
2. 从原位置擦除块，将旋转后的块（2 行高、槽位宽度宽）底部对齐放入槽位（底边紧贴平台）
3. 插入后：绿墙壁 + 插入的块 + 灰平台共同形成半封闭区域。确定每个封闭区域的开口方向（墙壁未封闭的那一侧）
4. 从每个橙(7)种子像素出发，在封闭区域内做 4-连通泛洪填充，将所有可达的黑像素涂为橙(7)。填充不穿越绿墙壁、灰平台、插入块或栗(9)障碍
5. 填充完封闭区域后，从开口处向外沿开口方向做直线辐射：以开口宽度为带宽，沿开口方向逐行/列扩展橙(7)像素，直到遇到网格边界
6. 栗(9)障碍像素在辐射路径上投射阴影：沿辐射方向，障碍像素正后方 1 像素宽的条带不被填充（阴影从障碍像素背面延伸到辐射终点）
7. 种子像素变为橙色；障碍、墙壁、平台、插入块保持原色不变

**关键洞察**：插入操作不是装饰性的空间移动——它直接创造了泛洪填充所需的拓扑封闭条件。若块插入了错误的槽位，形成的封闭体几何不同，填充范围和辐射方向都会改变。求解者必须理解"插入构建封闭体"这一因果关系，而非将插入和填充视为独立步骤。

## 新题 7：颜色编码位移的图案补全

**组合逻辑**：[pattern_union_completion](同色框共享图案取并集) + [translate / color_encoded_disp](并集图案中每个像素按其颜色编码的方向位移)

**来源原语**：pattern_union_completion / grouping / colored_frame / internal_motif / same_color_frames_share_motif / group_by_frame_color（来自 42918530）；translate / color_encoded_disp / foreground_pixel / color_determines_offset（来自 342dd610）

**依赖链**：同色边框组内取图案并集得到"完整图案"，但这不是最终答案——每个图案像素的颜色还编码了一个位移方向，必须施加位移后才得到最终输出。并集操作决定了"有哪些像素需要位移"，颜色编码决定了"每个像素移向哪里"。单独的并集或单独的位移都无法得出正确结果。

按边框颜色分组，取各组内部图案并集补全缺失像素，再将每个图案像素按其颜色编码的方向位移 1 格，得到最终帧内容。

**输入结构**：
- 背景为黑(0)，网格约 18x18
- 规则排列的 2x3 或 3x3 阵列的方框，框间隔 1 像素黑间隙
- 每个方框为 1 像素厚的实心边框，内部空间至少 3x3。边框颜色有 2-3 种（如蓝(1)、红(2)、绿(3)），每种颜色出现 2-4 次
- 每个框内部有 0-3 个彩色像素，取自黄(4)、橙(7)、灰(5)、青(8)四种颜色中的某些。不同的同色框可能包含不同子集的内部像素（有些框缺少某些位置的像素）
- 对于同一组（同色边框）内的所有框，其内部像素的并集为该组的"完整图案"
- 生成约束：每组完整图案中至少有 2 个像素；位移后所有像素仍在框内部范围内（不越出边框）；位移后同一框内不同像素不会落在同一位置；至少有一个框是不完整的（缺少图案中某些像素）

**规则**：
1. 按边框颜色将所有方框分组
2. 对每组，计算内部像素的并集：遍历该组所有框，收集出现过的（相对位置, 颜色）对。若同一相对位置在不同框中出现不同颜色，以出现次数最多的颜色为准（次数相同时取编号较小的颜色）
3. 将完整图案写入该组每一个框的内部（补全缺失像素）
4. 对每个框内的每个图案像素，按颜色执行位移：黄(4)向右移 1 格，橙(7)向上移 1 格，灰(5)向左移 1 格，青(8)向下移 1 格
5. 清除位移前的像素位置（设为黑），在位移后的位置绘制像素（保持原色）
6. 若像素位移后会超出框内部边界，则环绕到框内部对侧（水平方向：左出右进、右出左进；垂直方向：上出下进、下出上进）
7. 边框像素和框间背景保持不变

**关键洞察**：图案补全和颜色位移构成一个不可分割的流程——补全提供了需要位移的完整像素集合，而位移使最终输出与补全的并集截然不同。求解者若只做补全会发现输出不匹配，若只做位移则缺少被补全的像素。颜色在这里身兼二职：既是"属于什么图案"的标识，又是"往哪移"的指令。

## 新题 8：坐标轴距离排序驱动双朝向归一化排列

**组合逻辑**：[sort / distance_ordering](按到坐标轴距离排序) + [normalize_orient + arrange / each_rect_doubled](排序后每个矩形产生水平和垂直两份排列)

**来源原语**：sort / stack / coordinate_axis_line / distance_ordering / axis_color_determines_rotation（来自 291dc1e1）；normalize_orient / arrange / rectangle / width_height_swap / each_rect_doubled（来自 d749d46f）

**依赖链**：坐标轴线的距离度量决定了矩形的排列顺序，而轴线的朝向（蓝线水平还是垂直）决定了双份排列中水平版和垂直版哪个在上、哪个在下。排序和朝向判断都依赖同一对轴线，但提取的信息不同——一个是距离，一个是方向。归一化排列的结果完全取决于排序顺序和上下分配规则，三者不可跳步。

按矩形到两条坐标轴线的距离排序，排序后将每个矩形以水平和垂直两种朝向归一化排列，蓝轴朝向决定哪种朝向排在上半区。

**输入结构**：
- 背景为黑(0)，网格约 15x15
- 两条彩色边线在网格一角相交：一条沿某条边的完整水平线，一条沿垂直边的完整垂直线，相交角的像素为栗(9)。两条线分别为蓝(1)和红(2)，具体哪条是蓝、哪条是红在不同示例中可能不同
- 内部散布 3-5 个实心单色矩形（颜色取自绿(3)、黄(4)、灰(5)、橙(7)、青(8)），各矩形尺寸不同（没有两个矩形的 {宽, 高} 多重集相同）
- 矩形不接触边线，不互相重叠
- 生成约束：矩形到蓝线和红线的距离组合互不相同（不需要 tie-break）；矩形总数和尺寸保证输出不超过 20 列宽

**规则**：
1. 对每个矩形，计算其到蓝(1)线的最短 Manhattan 距离（矩形任意像素到蓝线任意像素的最小 Manhattan 距离）作为主排序键，到红(2)线的最短 Manhattan 距离作为次排序键
2. 按（主键升序，次键升序）排序所有矩形
3. 构建一个 10 行高的输出画布：
   - 若蓝(1)线为水平线：上半区排水平版，下半区排垂直版
   - 若蓝(1)线为垂直线：上半区排垂直版，下半区排水平版
4. 上半区排列：按排序顺序，对每个矩形取水平朝向（min(h,w) 行 x max(h,w) 列），顶部对齐排列，相邻矩形间隔 1 列黑像素
5. 下半区排列：按排序顺序，对每个矩形取垂直朝向（max(h,w) 行 x min(h,w) 列），底部对齐排列，相邻矩形间隔 1 列黑像素
6. 输出宽度为上半区总宽和下半区总宽中的较大值；较窄的半区左对齐
7. 边线、交点像素和原始矩形位置不出现在输出中；每个矩形保持其原色

**关键洞察**：同一对坐标轴线同时提供两种完全不同的信息——距离值（用于排序）和轴朝向（用于决定上下分区的内容）。蓝线从水平变为垂直时，排序键值可能不变（取决于矩形位置），但上下半区的朝向会交换，导致输出结构性地不同。求解者需要跨多个示例才能分离出"距离决定顺序"和"朝向决定分区"这两条独立规则。
