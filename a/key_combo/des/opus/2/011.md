## 新题 1：种子射线交叉环

**组合逻辑**：[射线延伸 + 种子色决定延伸](已有) + [遇障碍截断](已有) → 涌现交叉检测(创新) → [交叉邻域环涂色](创新改造：从固定单交叉变为多射线涌现交叉)

**来源原语**：射线延伸、种子色决定延伸 — 178fcbfb (#7)；遇障碍截断、障碍像素 — 212895b5 (#8)；交叉点、交叉邻域环涂色 — 67a423a3 (#13)

**依赖链**：种子颜色决定射线方向（红=纵向，绿=横向）。障碍像素截断射线。纵向射线和横向射线在同一个单元格相遇时产生涌现交叉点。每个交叉点触发 3x3 环涂色。环的位置无法不经射线计算而直接确定。

将彩色种子像素生长为方向性射线、用障碍截断射线、并在所有涌现的纵横交叉处标记彩色环。

**输入结构**：背景黑(0)，网格约 14x14。3-5 个红(2)种子像素散布在网格中，任意两个红种子不在同一列。3-5 个绿(3)种子像素散布在网格中，任意两个绿种子不在同一行。4-8 个灰(5)障碍像素散布在非种子位置。种子之间互不 4-邻接。生成约束：射线截断后至少存在 2 个纵横交叉点。

**规则**：
1. 从每个红(2)种子出发，向上和向下延伸纵向射线，沿该种子所在列逐格涂红(2)，直到遇到灰(5)障碍像素或网格边缘为止（不涂障碍本身，不涂网格外）。种子像素本身保持红(2)。
2. 从每个绿(3)种子出发，向左和向右延伸横向射线，沿该种子所在行逐格涂绿(3)，截断规则同上。
3. 若某个单元格同时被一条红纵向射线和一条绿横向射线涂色，则该单元格为交叉点，标记为黄(4)。
4. 对每个交叉点，将以该点为中心的 3x3 区域（共 9 格）全部涂黄(4)，覆盖该区域内任何已有的射线颜色。若 3x3 区域中的某格为灰(5)障碍，则该障碍不被覆盖（保持灰(5)）。若某格超出网格边界则跳过。
5. 若两个交叉点的 3x3 环重叠，重叠区域涂黄(4)（同色无冲突）。
6. 被环覆盖的种子像素变为黄(4)。
7. 未被射线或环覆盖的单元格保持原色（黑(0)背景或灰(5)障碍）。

**关键洞察**：环的位置不是输入中直接给出的，而是从射线的截断交汇中涌现。移动一个障碍像素可能同时消灭一个交叉并创造另一个——需要对比多个示例才能排除"环出现在固定位置"的假设。

## 新题 2：重力落位与象限色键重涂

**组合逻辑**：[重力下落 + 面积区分角色](已有) + [块内位置对应角落](创新改造：从空间展开变为查找表编码) → [重涂色](已有，但涂色规则由重力后的象限决定)

**来源原语**：重力下落、面积区分角色、大前景对象、小标记对象 — 6ca952ad (#3)；块内位置对应角落、前景块、网格角落 — 66e6c45b (#2)；重涂色 — b1948b0a (#15)

**依赖链**：一个 2x2 色键块将四种颜色映射到网格四个象限。大对象在重力作用下落到地面。落位后，每个对象的质心决定它所在的象限，象限通过色键决定该对象的新颜色。重力结果改变象限归属，象限归属改变涂色——三步紧密依赖。

识别 2x2 色键、让大对象下落、再根据落位象限经色键查表重涂每个对象。

**输入结构**：背景黑(0)，网格 13x13（奇数尺寸，中心行列明确）。最底行为灰(5)地面行，贯穿整行。网格左上角区域有一个 2x2 色键块，四个像素分别为蓝(1)（左上）、红(2)（右上）、绿(3)（左下）、黄(4)（右下），该块与其他对象不邻接。网格中散布 4-6 个单色 4-连通对象（每个面积 4-8 像素，形状不规则），颜色取自 {蓝(1), 红(2), 绿(3), 黄(4)}，可重复。它们悬浮在地面上方，互不接触，水平范围互不重叠。另有 2-3 个橙(7)小标记像素（面积=1）散布在地面行上或其附近。生成约束：每个大对象下落后，其质心所在象限对应的色键颜色与对象原色不同（确保涂色可见变化）。

**规则**：
1. 识别唯一的 2x2 块（四个像素颜色互不相同且均非黑(0)、非灰(5)、非橙(7)）。该块为色键：左上格颜色 → 左上象限，右上格颜色 → 右上象限，左下格颜色 → 左下象限，右下格颜色 → 右下象限。
2. 划分象限：以网格（不含地面行）的中心行和中心列为界。中心行和中心列本身归入左上象限。上半+左半 = 左上象限，上半+右半 = 右上象限，下半+左半 = 左下象限，下半+右半 = 右下象限。
3. 将色键块的 4 个像素擦除为黑(0)。
4. 所有大对象（面积 > 2，不含色键）执行重力下落：从最底部的对象开始，依次向下平移，直到其最低像素行抵达地面行上方一行或另一个已落定对象的最高像素行上方一行。水平位置不变。
5. 落定后，计算每个大对象的质心（所有像素行坐标的平均值向下取整，所有像素列坐标的平均值向下取整）。
6. 根据质心所在象限，查色键，将该对象所有像素重涂为色键中该象限对应的颜色。
7. 橙(7)小标记像素始终不移动、不重涂。

**关键洞察**：2x2 色键不是用于空间展开（不同于参考题 #2 的角落映射），而是一张颜色查找表。对象必须先物理下落才能确定其象限归属，同一个对象从不同列出发会落入不同象限、获得不同颜色——需要多个示例才能排除"颜色由原位置决定"的错误假设。

## 新题 3：载体滑动与锚定棋盘格填充

**组合逻辑**：[滑动 + 颜色决定方向 + 嵌入载体内](已有) → [填充 + 行列奇偶决定填充 + 边框与内部分离](已有，但奇偶锚点由滑动终点决定——创新耦合)

**来源原语**：滑动、擦除、可移动对象、载体区域、嵌入载体内、颜色决定方向 — 9b4c17c4 (#4)；填充、实心矩形、矩形内部、棋盘格图案、边框与内部分离、行列奇偶决定填充 — ba9d41b8 (#18)

**依赖链**：红色滑块在蓝/青载体中滑动（蓝向右、青向左）。滑动终点的包围盒左上角成为棋盘格的奇偶锚点。载体内部（除滑块占据的像素外）被棋盘格填充。棋盘格的相位由滑块终点决定，因此同一载体中不同形状的滑块会产生不同的棋盘格相位。

将红色滑块推到载体边墙，再以滑块终位为锚在载体内部铺棋盘格。

**输入结构**：背景黑(0)，网格约 16x14。2-4 个实心矩形载体区域，每个至少 6x5 像素，颜色为蓝(1)或青(8)，载体之间不接触（至少间隔 1 行/列黑(0)背景）。每个载体内部恰好有一个红(2)的 4-连通对象（面积 3-5 像素，形状不规则），完全位于载体边框内侧（不触碰载体的 1 像素宽边框）。生成约束：滑动后，滑块与载体对侧边框之间至少留 2 行 2 列的载体内部空间（以显示棋盘格效果）。

**规则**：
1. 对每个红(2)对象，检测其 4-邻接的非红像素颜色以确定载体（蓝(1)或青(8)）。
2. 滑动规则：
   - 蓝(1)载体：红对象整体右移，直到其最右像素列紧邻载体右边框内侧（即载体最右列 - 1）。
   - 青(8)载体：红对象整体左移，直到其最左像素列紧邻载体左边框内侧（即载体最左列 + 1）。
   - 红对象原位置的像素擦除为载体颜色，新位置涂红(2)。
3. 所有滑动完成后，对每个载体矩形执行棋盘格填充：
   - 载体内部 = 载体矩形中严格在 1 像素宽边框以内的所有单元格。
   - 锚点 (ar, ac) = 该载体内红(2)对象终位包围盒的左上角坐标。
   - 对每个内部单元格 (r, c)：若 (r - ar + c - ac) mod 2 = 0 且该格不被红(2)对象占据，则涂为黑(0)；否则保持载体颜色（或红(2)若被滑块占据）。
   - 载体边框像素不做任何修改。

**关键洞察**：棋盘格的奇偶相位锚定在红色滑块的终位而非固定网格原点。两个相同尺寸的载体，若滑块形状或初始位置不同，终位不同，棋盘格相位也不同。必须对比多个示例才能发现锚点来自滑块终位而非载体角落。

## 新题 4：按位置排序后逐级错切堆叠

**组合逻辑**：[排序 + 最高行决定序](已有) → 排名值参数化 [错切 + 逐行偏移](创新耦合：错切量由排名而非固定值决定) → [压缩/堆叠](已有)

**来源原语**：排序、最高行决定序、线段对象、压缩 — 668eec9a (#12)；错切、逐行偏移 — 9f41bd9c (#11)；堆叠 — e21a174a (#14)

**依赖链**：精灵体按最高行降序排列（最底部的排第一），排名决定错切量：排名 k 的精灵体在其内部第 j 行（从顶部起计，0 起）右移 k x j 个像素。错切后的精灵体按排名顺序纵向堆叠输出。排名既决定了堆叠位置又决定了错切强度——去掉排序则错切无参数，去掉错切则退化为简单堆叠。

将精灵体按纵向位置排序、用排名控制错切强度、再将变形后的精灵体堆叠输出。

**输入结构**：背景黑(0)，网格约 12x10。3-4 个单色 4-连通精灵体（每个面积 4-7 像素，形状不规则，非矩形），颜色各不相同，取自 {蓝(1), 红(2), 绿(3), 黄(4)}。每个精灵体的包围盒高度为 2-3 行，宽度为 2-4 列。各精灵体的最高行互不相同，水平范围可以重叠但精灵体像素不重叠。

**规则**：
1. 提取每个精灵体的包围盒，记录其最高行（精灵体占据的最小行号）。
2. 按最高行降序排列（最底部精灵体排第一）。分配排名：排名 0 给最底部精灵体，排名 1 给次底部，依此类推。
3. 对排名为 k 的精灵体执行错切：在其包围盒内，将第 j 行（从精灵体包围盒顶行起计，j=0 为顶行）的所有像素整体右移 k x j 个像素。右移后包围盒宽度相应扩展。空出的位置填黑(0)。
4. 输出网格：宽度 = 所有错切后包围盒宽度的最大值；高度 = 所有错切后包围盒高度之和。将错切后的精灵体按排名从 0 到最大依次从上到下堆叠，左对齐于第 0 列。不足宽度的行用黑(0)填充。

**关键洞察**：错切的方向和强度均由排序排名决定，而非固定常数。如果精灵体的纵向顺序改变（例如最底部的精灵体换了位置），所有精灵体的错切结果都会不同。必须对比多个示例才能发现错切量与排名的线性关系。

## 新题 5：镜像反射后标记定色再频率统计

**组合逻辑**：[镜像 + 跨轴反射](已有) → [标记色指定涂色](已有，但此处每个反射体的涂色由其着陆区的标记决定) → [计数 + 频率统计 + 按计数升序](已有，但统计对象是反射后的涌现色分布)

**来源原语**：镜像、跨轴反射、标记色指定涂色、轴线段、标记像素 — 88207623 (#5)；计数、频率统计、按计数升序 — 81c0276b (#1)

**依赖链**：黄色精灵体跨红色轴反射。反射着陆区中的标记像素决定反射副本的颜色。然后统计各颜色的反射副本数量，输出按升序排列的频率条。频率分布无法在执行反射之前确定，因为同一组标记配上不同的精灵体空间布局会产生不同的颜色分配。

将精灵体跨轴反射、用标记色给反射副本染色、统计结果色的频率并输出排序条。

**输入结构**：背景黑(0)，网格约 14x14。一列红(2)像素从第 0 行到最后一行贯穿网格某一列（靠近中央），形成垂直镜像轴。轴左侧有 4-6 个黄(4)的小型 8-连通精灵体（每个 2-4 像素），各精灵体至少有一个像素 8-邻接到红轴。轴右侧：对应每个精灵体的反射着陆区（将该精灵体各像素以轴列为对称轴水平翻转后的位置集合）内恰好有一个非黑、非红、非黄的标记像素。标记颜色取自 {蓝(1), 绿(3), 橙(7), 灰(5)}，不同精灵体的标记可同色。生成约束：不同精灵体的反射着陆区互不重叠；每个着陆区内恰好一个标记像素。

**规则**：
1. 识别红(2)垂直轴列 axis_col。
2. 对每个轴左侧的黄(4)精灵体，将其每个像素 (r, c) 反射到 (r, 2 x axis_col - c)，得到反射着陆区。
3. 在每个着陆区中找到唯一的标记像素，记录其颜色 paint_color。
4. 将反射着陆区的所有单元格涂为 paint_color，覆盖其中的标记像素。原始黄精灵体和红轴保持不变。
5. 统计所有反射副本的颜色频率：对每种 paint_color，计数有多少个反射副本使用了该色。
6. 输出频率条：每种颜色一行，按频率升序排列（频率相同时按颜色在网格中首次出现的列坐标升序）。每行为该颜色的左对齐水平条，长度等于该色的频率，其余填黑(0)。输出宽度 = 最大频率，高度 = 不同颜色数。

**关键洞察**：频率条的内容无法不经反射直接确定——同一套标记颜色配上不同空间布局的精灵体，会因为不同的精灵体"落"到不同的标记上而产生完全不同的频率分布。颜色分配是反射空间对应关系的涌现结果。

## 新题 6：克罗内克自积与块位奇偶条件填充

**组合逻辑**：[克罗内克积 + 二值掩码](已有) × [交替选取 + 奇偶位决定涂色](已有) → 双因子决策表(创新：每个块的填充内容由原掩码值和块坐标奇偶共同决定)

**来源原语**：克罗内克积、二值掩码、前景背景互换填充、块阵列 — 8e2edd66 (#16)；交替选取、奇偶位决定涂色 — d406998b (#10)

**依赖链**：输入二值掩码 M 被展开为 NxN 个块的大网格。每个块的内容由两个因子共同决定：(1) 该块对应的 M 值（0 或 1），(2) 该块行列坐标之和的奇偶性。四种情况分别产生不同的填充（正掩码、反掩码、全黑、全前景色）。去掉掩码值因子则退化为简单棋盘格，去掉奇偶因子则退化为原克罗内克题。

将二值掩码做克罗内克自积展开，但每个块的填充由掩码值和块坐标奇偶共同查表决定。

**输入结构**：背景黑(0)，网格为 NxN（N 取 3-5），恰好一种前景色蓝(1)。网格中黑(0)和蓝(1)各占至少 3 格，形成一个二值掩码。

**规则**：
1. 将输入视为二值掩码 M：黑(0) = 0，蓝(1) = 1。设输入尺寸为 N 行 x N 列。
2. 创建 (N x N) 行 x (N x N) 列的输出网格。输入中第 (r, c) 格对应输出中第 (r, c) 号块（块大小 NxN，块的左上角在输出的 (r x N, c x N)）。
3. 每个块的填充由下表决定：

   | M[r][c] | (r + c) 奇偶 | 块内容 |
   |---------|-------------|--------|
   | 0 | 偶 | M 的正副本（0→黑(0)，1→蓝(1)） |
   | 0 | 奇 | M 的反副本（0→蓝(1)，1→黑(0)） |
   | 1 | 偶 | 全黑(0) |
   | 1 | 奇 | 全蓝(1) |

4. 将所有块拼装为输出网格。

**关键洞察**：任何一个块的内容都无法仅凭掩码值或仅凭位置奇偶确定——必须同时考虑两个因子。M[r][c]=1 的块在偶位置为全黑、奇位置为全蓝，形成大尺度棋盘格；M[r][c]=0 的块在偶位置放正掩码、奇位置放反掩码，形成掩码级别的交替。两层结构叠加产生单层规则无法产生的复合图案。

## 新题 7：双面板叠加生成种子与前景阻断射线

**组合逻辑**：[透明叠加 + 位置对齐 + 分隔行 + 双面板背景交集](已有) → 交集产生种子位置、并集产生障碍(创新：同一叠加操作同时生成两种互补角色) → [射线延伸 + 遇障碍截断](已有)

**来源原语**：透明叠加、位置对齐、分隔行、面板、双面板背景交集 — 0c9aba6e (#9)；射线延伸 — 178fcbfb (#7)；遇障碍截断 — 212895b5 (#8)

**依赖链**：分隔行将网格分为上下两个面板。两面板对位后，背景交集（双黑位置）成为种子，前景并集（任一面板有色位置）成为障碍。种子向左右发射水平射线，障碍截断射线。种子与障碍的空间布局共同源于同一对面板的叠加，但扮演完全对立的角色。

叠加两个面板、以双背景位置为种子发射水平射线、以任一面板前景位置为障碍截断射线。

**输入结构**：背景黑(0)，网格约 11x23（宽窄高长，被分隔行一分为二）。一行灰(5)像素贯穿整行宽度，将网格分为上面板和下面板，两面板尺寸相同（各约 11x11）。上面板：黑(0)背景上有蓝(1)前景像素（一个不规则 4-连通形状，面积 10-20 像素）。下面板：黑(0)背景上有红(2)前景像素（另一个不规则 4-连通形状，面积 10-20 像素）。生成约束：背景交集（双面板对应位置均为黑(0)的单元格）至少 5 个且分散在至少 3 个不同行中；前景并集（任一面板为非黑的对应位置）在射线可达路径上提供有效截断。

**规则**：
1. 移除灰(5)分隔行。按位置对齐上下面板（它们的行列坐标一一对应）。
2. 创建与面板同尺寸的工作网格，初始全黑(0)。
3. 计算种子掩码：对应位置上面板和下面板均为黑(0)的单元格。
4. 计算障碍掩码：对应位置上面板为蓝(1)或下面板为红(2)（或两者皆有前景）的单元格。
5. 在工作网格中标记障碍：若对应位置仅上面板有蓝(1)，涂蓝(1)；仅下面板有红(2)，涂红(2)；若两面板在同一位置都有前景，涂黄(4)（重叠标记）。
6. 从每个种子位置出发，向左和向右发射水平射线，涂绿(3)，直到遇到障碍掩码中的单元格或网格边缘为止（不涂障碍本身）。种子位置本身涂绿(3)。
7. 输出工作网格。射线之间若重叠（两个种子在同一行），其重叠段仍为绿(3)。

**关键洞察**：种子和障碍共同源于同一对面板的互补方面——背景的交集是种子，前景的并集是障碍。改变任一面板的前景形状会同时改变种子位置和障碍位置，使射线图案发生非平凡变化。这不是两道参考题的顺序拼装，而是面板叠加操作同时生成了两种功能对立的空间角色。

## 新题 8：指示像素定向选择性擦除与排序裁剪

**组合逻辑**：[裁剪](已有) + [指示像素 + 邻接触碰](已有) → 指示色决定保留哪种颜色(创新：指示像素从方向信号变为选色信号) + [擦除](已有) + [排序 + 顺序排列](已有，但排序键由指示像素行位置决定)

**来源原语**：裁剪、双色互换 — b94a9452 (#20)；指示像素、邻接触碰、指示决定方向色 — e8dc4411 (#19)；排序、顺序排列 — 668eec9a (#12)；擦除 — 9b4c17c4 (#4)

**依赖链**：每个双色矩形旁有一个指示像素。指示色匹配矩形内的一种颜色→保留该色、擦除另一色。擦除后的剩余形状被裁剪。指示像素在网格中的行坐标决定裁剪结果的输出堆叠顺序。指示像素同时承担选色（决定保留什么）和排序（决定输出顺序）两个角色。

识别指示像素、保留其颜色而擦除矩形中的另一色、裁剪剩余形状、按指示像素的行位置堆叠输出。

**输入结构**：背景黑(0)，网格约 16x16。3-4 个实心矩形（无孔洞），每个至少 4x4。每个矩形内恰好使用两种非黑颜色，排列成水平条纹、竖直条纹或棋盘格等图案（每个矩形的图案可不同）。两种内部颜色取自 {蓝(1), 红(2), 绿(3), 黄(4), 橙(7)}，每个矩形的颜色对唯一（不与其他矩形完全相同）。每个矩形外恰好有一个单像素指示像素，4-邻接于矩形边框且不在矩形内，指示色等于该矩形两种内部颜色之一。各指示像素的行坐标互不相同。矩形之间互不接触，不触碰网格边界。

**规则**：
1. 对每个矩形，找到其唯一的指示像素（4-邻接于矩形边框、位于矩形外部、颜色匹配矩形内部两种颜色之一的单像素）。
2. 指示色 = 保留色。将矩形内所有非保留色的像素擦除为黑(0)。保留色像素不变。
3. 裁剪：取擦除后矩形原包围盒区域。输出的每个裁剪块包含保留色像素和黑(0)空隙（原来另一色的位置）。
4. 按各矩形指示像素的行坐标升序排列裁剪块（行坐标最小的排第一）。
5. 输出网格：宽度 = 所有裁剪块宽度的最大值，高度 = 所有裁剪块高度之和。裁剪块按排序结果从上到下纵向堆叠，左对齐于第 0 列。宽度不足的行用黑(0)填充。
6. 指示像素本身不出现在输出中。

**关键洞察**：指示像素是一个多功能信号——其颜色决定矩形内哪种颜色存活（改变指示色就改变了裁剪图案的正负形），其行位置决定输出排列顺序。两个矩形即使内部图案和颜色完全相同，若指示像素颜色不同，输出的裁剪图案就是互补的（一个保留条纹，另一个保留间隙）。

## 新题 9：类型分类驱动的频率直方图分区

**组合逻辑**：[分类 + 内部判定类型](已有) → 分类结果划分统计域(创新：分类不直接决定输出位置，而是决定频率统计的分组) → [计数 + 频率统计 + 按计数升序](已有) + [分隔行](已有，用于分区输出)

**来源原语**：分类、内部判定类型、空心矩形、实心方块、按类型分列 — 2ba387bc (#17)；计数、频率统计、按计数升序、表格单元 — 81c0276b (#1)；分隔行 — 0c9aba6e (#9)

**依赖链**：4x4 对象被分为空心框和实心块。在每个类别内部，按颜色统计对象数量。输出上半区是框类颜色频率条，下半区是块类颜色频率条，中间用灰行分隔。分类结果决定了哪些对象的颜色被归入哪个统计组——同色的框和同色的块贡献到不同的频率条中。

将对象按空心/实心分类，分别统计各类内颜色频率，输出两组分区频率条。

**输入结构**：背景黑(0)，网格约 18x18。6-8 个 4x4 非黑对象散布在背景上，互不接触。每个对象为以下两种之一：
- 空心框：1 像素宽的彩色边框，2x2 内部为黑(0)。
- 实心块：4x4 完全填充同一种非黑颜色。
每个对象使用一种颜色，取自 {蓝(1), 红(2), 绿(3), 黄(4), 橙(7)}。同色对象可以有多个，且可以跨类型（例如蓝色框和蓝色块同时存在）。生成约束：框和块各至少 2 个；框中至少 2 种不同颜色，块中至少 2 种不同颜色。

**规则**：
1. 对每个 4x4 对象分类：若其 2x2 内部（第 1-2 行、第 1-2 列，相对于对象左上角）全为黑(0)，则为空心框；否则为实心块。
2. 框类频率统计：在所有空心框中，统计每种颜色的框数量。按数量升序排列（数量相同时按颜色在网格中首次出现的行坐标升序）。
3. 块类频率统计：在所有实心块中，按同样方式统计和排序。
4. 输出网格：
   - 上半区：每种框类颜色一行，按升序排列。每行为该色的左对齐水平条，长度 = 该色框数量，其余填黑(0)。
   - 中间：一行灰(5)分隔行，宽度 = 输出宽度。
   - 下半区：每种块类颜色一行，规则同上。
   - 输出宽度 = max(最大框类频率, 最大块类频率)。输出高度 = 框类颜色种数 + 1 + 块类颜色种数。

**关键洞察**：颜色相同不意味着频率贡献相同。一个红色空心框和一个红色实心块虽然颜色都是红(2)，但分别贡献到不同的分区频率条中。必须先正确分类才能正确统计——分类错误会导致频率条的数值和颜色分布同时出错。

## 新题 10：模板平铺被重力落物截断

**组合逻辑**：[重力下落 + 面积区分角色](已有) → 落物产生障碍(创新：障碍不是输入中的静态像素，而是重力操作的动态产物) → [平铺 + 指示决定方向色 + 邻接触碰](已有) + [遇障碍截断](已有)

**来源原语**：重力下落、面积区分角色、大前景对象 — 6ca952ad (#3)；平铺、模板、指示像素、邻接触碰、指示决定方向色 — e8dc4411 (#19)；遇障碍截断 — 212895b5 (#8)

**依赖链**：大对象在重力作用下落到底部。落定后的大对象成为模板平铺的障碍。模板从指示像素处沿指示方向重复复制，直到副本与落定的大对象重叠为止。重力改变了障碍的位置分布，因此同样的模板和指示在不同的重力结果下产生不同长度的平铺链。

大对象下落形成障碍，模板从指示方向平铺直到碰撞落物为止。

**输入结构**：背景灰(5)，网格约 14x14。一个黑(0)模板对象（4-连通，面积 3-6 像素），位于网格中部偏上。2-3 个单像素指示像素，颜色各不相同，取自 {蓝(1), 红(2), 绿(3)}，每个 4-邻接于模板边界但不在模板内。2-3 个大单色 4-连通对象（面积 8-15 像素），颜色取自 {黄(4), 橙(7), 栗(9)}，位于模板上方或侧上方，悬浮未触底。生成约束：大对象水平范围各不重叠；下落后至少一个落物阻挡了至少一个平铺方向，且至少一个方向可平铺 2 次以上再被阻挡或到达边缘。

**规则**：
1. 面积 > 6 的对象为大对象。所有大对象执行重力下落：从最底部的开始，依次向下平移直到其最底像素行抵达网格最底行或另一已落定对象的最高行上方一行。原位置擦除为灰(5)背景。
2. 面积 <= 6 的对象（模板和指示像素）不移动。
3. 对每个指示像素，从模板质心（所有模板像素行坐标平均值和列坐标平均值，各向下取整）到该指示像素的方向向量确定平铺方向。方向向量归一化为四个基本方向之一：若 |delta_col| >= |delta_row| 且 delta_col > 0 则向右；delta_col < 0 则向左；若 |delta_row| > |delta_col| 且 delta_row > 0 则向下；delta_row < 0 则向上。
4. 沿该方向平铺模板：第 1 个副本的位置 = 模板各像素沿平铺方向平移 (模板包围盒在该方向的尺寸 + 1) 个像素。第 n 个副本 = 第 (n-1) 个副本再平移相同距离。每个副本涂为该指示像素的颜色。
5. 在放置每个副本前检查：若该副本的任何像素与非灰(5)单元格重叠（包括落定的大对象、其他已放置的副本、模板本身、或其他指示像素），则该副本不放置，该方向的平铺终止。若副本任何像素超出网格边界，同样不放置并终止。
6. 处理指示像素的顺序：按指示像素的行坐标升序依次处理（行坐标最小的先平铺）。先处理的指示像素的平铺副本可阻挡后处理的。
7. 输出最终网格。

**关键洞察**：平铺的截断障碍不是静态给定的——它们由重力操作动态生成。同一模板和指示配置下，移动大对象的初始位置改变落定位置，进而改变平铺长度。必须先计算重力再计算平铺，但重力的结果仅通过空间阻断间接影响平铺，形成非显然的因果链。
