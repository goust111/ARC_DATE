## 新题 1：对称重建障碍场后内滑

**组合逻辑**：[symmetry_completion](创新：从全局图案对称改为障碍子集对称推断) + [slide](已有) + [biaxial_reflection_symmetry](创新：用于推断隐藏障碍而非还原图案)

**来源原语**：symmetry_completion、biaxial_reflection_symmetry（0934a4d8）；slide、fixed_barrier、same_row_blocking、stop_at_barrier（9c56f360）；mirror（833dafe3）

**依赖链**：只有一个象限的障碍可见 → 必须通过双轴反射补全完整障碍场 → 补全后的障碍场才能确定每条可移动行程的阻停位置 → 阻停位置确定后执行滑动。删除对称补全步骤则障碍不完整、滑动结果错误；删除滑动步骤则补全后无输出变换。

将散布在网格边缘的彩色行程沿行/列向中心滑动，直到被通过双轴对称推断出的完整障碍场阻停。

**输入结构**：约 15x15 网格，黑(0)背景。灰(5)像素作为障碍，仅出现在左上象限（即行索引 < 行数/2 且列索引 < 列数/2 的区域），约 5-8 个分散的灰像素。红(2)和绿(3)各 1-3 条可移动行程，每条行程是 1-3 像素的水平或垂直连续段，紧贴网格边缘（红行程贴右边缘或下边缘，绿行程贴左边缘或上边缘）。保证每条行程所在行/列上的完整障碍场中至少有一个障碍像素。不同示例中障碍分布不同，行程数量和位置也不同。

**规则**：
1. 识别所有灰(5)像素，它们构成障碍子集，仅分布在左上象限。
2. 以网格中心为对称中心，将灰像素沿水平轴、垂直轴和两轴同时反射，补全四个象限的障碍场。补全后灰像素具有完美的双轴反射对称。
3. 对每条可移动行程，沿其所在行（水平行程）或列（垂直行程）向网格中心方向滑动，直到行程的前沿像素紧邻（4-相邻）一个灰障碍像素时停止。若路径上无障碍则滑动到网格中心行/列。
4. 处理顺序：按行程前沿像素到网格中心的曼哈顿距离从大到小处理。若已停止的行程阻挡了后续行程的路径，后续行程也会被该行程阻停（先停的行程等同于障碍）。
5. 输出网格与输入同尺寸；灰像素为补全后的完整障碍场，行程在新位置，背景不变。

**关键洞察**：障碍场的对称性在输入中被隐藏——只有左上象限的障碍可见，求解者必须推断出双轴对称关系才能获得完整障碍布局；这一推断与滑动规则紧耦合，因为错误的障碍补全会导致完全不同的滑动结果。

## 新题 2：封闭面积排名决定轮廓重涂色

**组合逻辑**：[counting](已有) + [outline_trace](创新：从单轮廓擦除改为多轮廓独立描边) + [recolor](创新：颜色不由标记色决定而由面积排名映射调色板)

**来源原语**：counting、enclosed_bg_region、ordered_arrangement（8ba14f53）；outline_trace、outer_adjacent、erase（aa62e3f4）；recolor（6ffe8f07）

**依赖链**：封闭面积计数 → 产生排名序 → 排名序映射调色板行颜色 → 外轮廓描边提供涂色几何位置 → 两者汇合才能确定最终输出。计数与描边分别提供"涂什么色"和"涂在哪"，缺一不可。

统计多个闭合轮廓各自围住的背景像素数量，按面积升序排名后，擦除原轮廓，用调色板行中对应位次的颜色描绘每个轮廓的外侧等距线。

**输入结构**：约 20x20 网格，黑(0)背景。第 0 行为调色板行，包含 N 个不同颜色的像素从左到右排列（如红(2)、绿(3)、黄(4)、橙(7)），中间用黑(0)分隔，N 等于网格中闭合轮廓的数量。第 1 行起为主区域，包含 N 个蓝(1)闭合轮廓，每个轮廓是一圈一像素宽的封闭环（4-连通闭合曲线），各轮廓互不接触且不接触调色板行，每个轮廓围住的黑色内部面积互不相同（如分别围住 2、5、9 个黑像素）。轮廓形状为不规则多边形（非全为矩形），不同示例中轮廓形状和位置不同。

**规则**：
1. 对每个蓝(1)闭合轮廓，计算其围住的黑(0)像素数量——即轮廓内部不经过轮廓像素就无法 4-连通到达网格边界的黑像素集合的大小。
2. 按围住面积从小到大排列轮廓，产生排名 1、2、...、N。
3. 擦除所有蓝(1)轮廓像素为黑(0)。
4. 对于排名为 k 的原轮廓位置，找到所有原来与该轮廓外侧 4-相邻的黑(0)像素（即轮廓外一圈的背景像素，不包含轮廓内部像素），将这些像素涂为调色板行第 k 个颜色（从左数第 k 个非黑像素）。
5. 调色板行保持不变。网格尺寸不变。

**关键洞察**：调色板颜色的分配不是按轮廓的空间位置（如从左到右）决定的，而是按各轮廓围住的内部面积升序排名决定的；求解者必须对比多个示例才能排除"按位置分配"的错误假设。

## 新题 3：旋转/翻转匹配下的异形腔体嵌入

**组合逻辑**：[inlay_fill](已有) + [rotation_matching](创新：从源-目标子精灵对齐改为精灵与异形腔体的旋转匹配) + [shape_identity](创新：从频次计数改为腔体-精灵的形状等价判定)

**来源原语**：inlay_fill、template_frame、rectangular_cavity、unique_slot_pairing（5dbc8537）；rotation_matching、source_target_alignment（3a25b0d8）；shape_identity（39a8645d）

**依赖链**：腔体形状与精灵形状不直接吻合 → 必须遍历 8 种旋转/翻转变体做形状等价匹配 → 匹配成功才能确定嵌入朝向 → 嵌入朝向确定后才能执行填充。若去掉旋转匹配则精灵无法对准腔体；若去掉填充则匹配结果无处施加。

在模板框架中找到异形（非矩形）腔体，将网格中散落的自由精灵旋转/翻转后嵌入各自唯一匹配的腔体。

**输入结构**：约 18x18 网格，黑(0)背景。一个大的灰(5) 4-连通区域构成模板框架，其内部包含 3-4 个异形腔体（腔体由灰框架围住的黑(0)连通区域构成，形状为非矩形的不规则多边形，每个腔体 4-8 像素）。模板框架的边界框约为 12x12。在模板边界框之外，有 3-4 个彩色精灵散布在黑背景上，每个精灵是一个 4-连通单色小图形（使用红(2)、绿(3)、黄(4)、蓝(1)等不同颜色，每个精灵 4-8 像素）。每个精灵的像素模式在某种旋转/翻转变换下与恰好一个腔体的像素模式完全重合（边界框尺寸和内部形状一致）。不同腔体尺寸或形状互不相同，保证配对唯一。不同示例中精灵与腔体的旋转关系不同（有的需 90 度旋转，有的需水平翻转，有的无需变换）。

**规则**：
1. 识别灰(5)模板框架的边界框作为输出区域。
2. 在模板内部找到所有黑(0)连通腔体区域。
3. 对每个外部彩色精灵，将其裁剪到边界框后，生成全部 8 种旋转/翻转变体（0/90/180/270 度旋转 x 是否水平翻转）。
4. 将每个精灵的 8 种变体逐一与每个腔体的形状（腔体的黑像素模式裁剪到边界框）进行逐像素比较，找到形状完全匹配的唯一（精灵变体, 腔体）配对。
5. 将精灵以匹配的变体朝向放入对应腔体的位置，精灵保持其原始颜色。
6. 输出为模板边界框区域——灰框架 + 填充后的腔体。

**关键洞察**：与矩形腔体仅需尺寸匹配不同，异形腔体的匹配要求逐像素的形状比对且必须考虑旋转/翻转；同一边界框尺寸的两个腔体可能具有不同的内部形状，仅靠尺寸无法区分。

## 新题 4：孔洞面积排名驱动的十字射线着色

**组合逻辑**：[ray_extend](已有) + [counting](创新：从压缩输出改为驱动射线颜色分配) + [role_assignment](创新：从频率角色改为面积排名角色)

**来源原语**：ray_extend、cross_projection、ray_stops_at_block、specific_is_wall（6ffe8f07）；counting、enclosed_bg_region、ordered_arrangement（8ba14f53）；role_assignment（3979b1a8）

**依赖链**：封闭面积计数 → 产生排名 → 排名映射调色板颜色 → 射线几何确定涂色区域 → 墙壁阻停确定射线终点 → 冲突规则解决重叠。面积计数与射线几何是两条独立计算分支，在输出层汇合。

从多个带孔洞的闭合形状向四方投射十字射线，射线颜色不是形状自身颜色而是由各形状的孔洞面积排名从调色板行中映射得到。

**输入结构**：约 18x18 网格，黑(0)背景。3-4 个小型闭合单色形状分散在网格中，每个形状使用不同的前景色（如蓝(1)、绿(3)、红(2)），每个形状为一像素宽的封闭环或实心小区域且内部围住不同数量的黑(0)像素（如 1、3、6 个）。一个栗(9)实心矩形（约 2x2 至 3x3）充当全局墙壁。网格最下一行为调色板行，包含 3-4 个不同颜色的像素从左到右排列（如黄(4)、橙(7)、品红(6)），颜色数等于形状数。各形状互不接触，与栗色矩形也不接触，各形状边界框互不重叠。

**规则**：
1. 对每个闭合形状，计算其围住的黑(0)像素数量（4-连通不可达边界框边缘的内部黑像素）。
2. 按围住面积从小到大排列形状，产生排名 1、2、...、N。
3. 从每个形状的边界框的每一行向左和向右投射水平射线，从边界框的每一列向上和向下投射垂直射线（形成十字投影）。
4. 每条射线向外延伸直到遇到栗(9)墙壁像素、另一个形状的像素或网格边缘（取最先遇到者），射线不包含终止位置本身。
5. 射线经过的所有黑(0)像素涂为调色板行第 k 个颜色，其中 k 为发射形状的排名。
6. 若两个形状的射线覆盖同一像素，排名数值较大者（围住面积更大）的颜色覆盖排名较小者的颜色。
7. 原形状像素、栗色墙壁和调色板行保持不变。

**关键洞察**：射线颜色并非形状的自身颜色，而是由孔洞面积排名从调色板中查询得到——求解者若直接用形状颜色涂射线将得到错误结果，必须先完成面积计数和排名才能确定射线颜色。

## 新题 5：对角传播交替反转与旋转

**组合逻辑**：[tiling + diagonal_propagate](已有) + [occupancy_inversion](创新：从瓷砖网格独立反转改为沿对角线位置决定是否反转) + [rotation](创新：从锯齿交替换色改为步长决定旋转角度)

**来源原语**：tiling、diag_zigzag、alt_rotate_recolor（fd4b2b02）；diagonal_propagate（b5bb5719）；occupancy_inversion（1c0d0a4b）；rotation（b20f7c8b）

**依赖链**：对角步长 k 同时决定旋转角度（k mod 4 x 90度）和是否反转（k 奇偶），两者耦合在同一位置参数上 → 旋转改变了哪些像素是前景/背景 → 反转在旋转后的布局上操作 → 旋转和反转的交互产生非线性的图案变化。

将种子瓷砖沿对角线传播，每步同时应用位置相关的旋转和奇偶相关的占位反转，产生非周期的对角图案带。

**输入结构**：约 18x18 网格，橙(7)背景。左上角 3x3 区域为种子瓷砖，包含红(2)和灰(5)前景像素以及至少一个橙(7)背景像素（例如：第 0 行为红-灰-橙，第 1 行为橙-红-灰，第 2 行为灰-橙-红）。种子瓷砖中红和灰像素合计 5-7 个，橙像素 2-4 个。种子瓷砖在不同示例中图案不同。网格其余部分全为橙(7)背景。

**规则**：
1. 将种子瓷砖沿主对角线传播，在位置 (3k, 3k) 放置第 k 步的瓷砖（k = 0, 1, 2, ...），直到 (3k, 3k) 处的 3x3 区域完全超出网格为止。
2. 第 k 步的瓷砖首先对种子进行顺时针旋转：旋转角度 = (k mod 4) x 90 度（k=0 不旋转，k=1 旋转 90 度，k=2 旋转 180 度，k=3 旋转 270 度，k=4 回到 0 度，以此循环）。
3. 旋转后，若 k 为奇数，对 3x3 区域执行占位反转：所有红(2)和灰(5)像素变为橙(7)，所有橙(7)像素变为红(2)。若 k 为偶数，不执行反转。
4. 若 3x3 区域部分超出网格边界，仅绘制在网格内的部分，超出部分丢弃。
5. 未被任何瓷砖覆盖的像素保持橙(7)背景。

**关键洞察**：旋转和反转通过同一个位置参数 k 耦合——旋转改变了 3x3 区域中前景/背景像素的空间分布，而反转基于旋转后的布局交换前景与背景。因此 k=1（旋转 90 度 + 反转）和 k=3（旋转 270 度 + 反转）产生的图案并非彼此的简单镜像，求解者必须追踪旋转-反转的组合效果。

## 新题 6：图例字典驱动的轮廓形状匹配与重涂

**组合逻辑**：[lookup_replace](创新：从编码块替换改为轮廓形状查表) + [outline_trace](创新：从单轮廓外描改为多轮廓按字典着色) + [rotation_reflection_match](已有)

**来源原语**：lookup_replace、legend_panel、color_shape_match、rotation_reflection_match（b20f7c8b）；outline_trace、outer_adjacent、erase（aa62e3f4）

**依赖链**：图例面板提供形状-颜色字典 → 主区域轮廓需归一化后与字典匹配（旋转/翻转等价）→ 匹配结果决定外轮廓涂色 → 轮廓描边提供涂色位置。字典查询和几何描边分别提供"颜色来源"和"涂色位置"，缺一不可。

将主区域中多个闭合轮廓的形状与图例字典中的形状进行旋转/翻转归一化匹配，然后擦除原轮廓并用匹配到的字典颜色描绘其外侧轮廓。

**输入结构**：约 20x20 网格，黑(0)背景。左上角有一个青(8)矩形面板（约 4-6 行 x 12-16 列），面板内部包含 3-4 个小型形状（每个 3-5 像素的 4-连通图形），每个形状使用不同的颜色（如红(2)、绿(3)、黄(4)），形状之间用青(8)隔开。面板以外的主区域（面板下方和右侧）包含 3-4 个蓝(1)闭合轮廓（一像素宽的封闭环），各轮廓互不接触且不接触面板。每个轮廓裁剪到边界框后的像素模式，在 8 种旋转/翻转变换中的某一种下与恰好一个面板形状的像素模式完全一致。不同轮廓对应不同的面板形状。不同示例中轮廓出现的朝向不同。

**规则**：
1. 从青(8)面板中提取每个彩色形状：裁剪到边界框，记录其颜色和像素模式。
2. 对主区域每个蓝(1)闭合轮廓，裁剪到边界框获取其像素模式。
3. 对轮廓模式生成全部 8 种旋转/翻转变体（0/90/180/270 度 x 是否水平翻转），与所有面板形状逐一比对，找到唯一匹配的面板形状及其颜色。
4. 擦除该蓝(1)轮廓的所有像素为黑(0)。
5. 找到所有原来与该轮廓外侧 4-相邻的黑(0)像素（轮廓外部一圈，不包含轮廓曾围住的内部像素），将这些像素涂为步骤 3 匹配到的面板颜色。
6. 对所有轮廓依次执行步骤 3-5（处理顺序不影响结果，因为轮廓互不接触）。青面板保持不变。

**关键洞察**：轮廓在主区域中以任意朝向出现，因此直接比较形状会失败——求解者必须对轮廓和面板形状都进行旋转/翻转归一化后才能正确匹配；而匹配到的颜色决定了外轮廓的涂色，两步推理不可跳过。

## 新题 7：中轴提取后按行程长度的对角射线

**组合逻辑**：[erase + center_axis_only](创新：从纯保留中轴改为中轴作为射线源) + [ray_extend](创新：从矩形十字投射改为单像素逐条对角投射) + [diagonal_propagate](创新：传播距离由局部行程长度决定而非全局递增)

**来源原语**：erase、center_axis_only、center_column、foreground_pixel（d23f8c26）；ray_extend（6ffe8f07）；diagonal_propagate（b5bb5719）

**依赖链**：中轴提取确定哪些像素成为射线源 → 中轴上连续同色行程的长度确定对角射线的延伸距离 → 非中轴像素提供射线颜色（与源像素同行的最近非中轴前景色）→ 三者汇合才能确定每条射线的起点、方向、长度和颜色。

提取网格中轴列的像素作为射线源，从每个源像素发射对角射线，射线长度由该像素所在连续行程的长度决定，射线颜色由同行最近的非中轴前景像素决定。

**输入结构**：约 15x15 网格（列数为奇数），黑(0)背景。前景像素使用红(2)、绿(3)、蓝(1)等颜色。中轴列（第 floor(列数/2) 列）包含若干前景像素，形成 1-3 段连续的垂直行程（每段 1-4 像素，段间有黑像素间隔，每段内所有像素同色）。在中轴列以外的位置，散布着少量前景像素（约 5-10 个），每个中轴前景像素所在行中至少有一个非中轴前景像素。不同示例中中轴行程的长度、颜色和非中轴像素的位置都不同。

**规则**：
1. 识别中轴列（列索引 = floor(列数/2)）中的所有前景像素。
2. 将中轴前景像素按垂直方向分组为连续行程：同色且行索引连续的像素组成一个行程。记录每个行程的长度 L。
3. 对每个中轴前景像素 P（位于行 r），找到第 r 行中距离 P 最近的非中轴前景像素 Q（若左右等距则取左侧），记录 Q 的颜色 C。
4. 从 P 向右上方（行减列增）和左下方（行增列减）各发射一条对角射线，每条射线延伸 L 个像素（L 为 P 所在行程的长度），射线像素涂为颜色 C。
5. 若射线像素超出网格边界则丢弃超出部分。若两条射线覆盖同一像素，行程长度更大的射线的颜色覆盖较小的；若行程长度相同则行索引更小（更高）的射线优先。
6. 擦除所有非中轴前景像素为黑(0)。中轴列前景像素保持不变。

**关键洞察**：中轴列不仅仅被"保留"——它被用作射线源阵列，而射线的两个关键参数分别来自不同的空间计算：长度来自中轴上的局部行程分析，颜色来自同行最近非中轴像素的查找。这三层信息（位置、行程长度、行内颜色）缺一不可。

## 新题 8：频率选种四向镜像后孔洞填充

**组合逻辑**：[counting + most_frequent_sprite_output](已有) + [mirror + four_way_symmetric_expansion](创新：从全网格镜像改为对选中精灵镜像) + [fill](创新：由第二频率精灵的颜色填充镜像产生的孔洞)

**来源原语**：counting、most_frequent_sprite_output、shape_identity、sprite（39a8645d）；mirror、four_way_symmetric_expansion、quadrant（833dafe3）；fill、hole（3a25b0d8）

**依赖链**：频率计数选出种子精灵 → 四向镜像扩展种子 → 镜像可能在中心产生封闭孔洞（原精灵没有的） → 孔洞用次频精灵颜色填充 → 次频颜色也依赖计数结果。计数结果同时决定"镜像什么"和"用什么颜色填"。

统计最高频精灵作为种子进行四向镜像扩展，然后用第二高频精灵的颜色填充扩展后产生的新封闭孔洞。

**输入结构**：约 14x14 网格，黑(0)背景。5-8 个小型单色精灵，每个精灵为 4-连通图形且边界框为 3x3。精灵使用两种前景色（如红(2)和绿(3)），每种颜色的精灵各有若干个。同色且同形状的精灵视为同一类型。恰好有一种类型出现次数最多（唯一众数），恰好有一种类型出现次数第二多（唯一次众数），两者颜色不同。最频精灵的 3x3 模式中至少有一个角像素为黑(0)（这保证四向镜像后中心会出现封闭孔洞）。不同示例中精灵的形状和频率分布不同。

**规则**：
1. 将每个精灵裁剪到 3x3 边界框，以（形状像素模式, 颜色）作为类型标识，统计各类型出现次数。
2. 出现次数唯一最多的类型为"种子"，记其 3x3 模式为 S，颜色为 C1。出现次数唯一第二多的类型的颜色为 C2。
3. 构建 6x6 输出网格：以 S 为右下象限（行 3-5，列 3-5），S 的水平翻转为左下象限（行 3-5，列 0-2），S 的垂直翻转为右上象限（行 0-2，列 3-5），S 的双轴翻转为左上象限（行 0-2，列 0-2）。
4. 在 6x6 输出中，找到所有被前景像素 4-连通完全包围的黑(0)连通区域（孔洞）——即无法通过黑像素 4-连通路径到达 6x6 边界的黑像素集合。
5. 将所有孔洞像素涂为 C2。
6. 输出为 6x6 的填充后镜像图案，背景为黑(0)。

**关键洞察**：四向镜像会将原精灵角落的缺失像素转变为中心的封闭孔洞——这是单精灵不具备的涌现特征；填充色来自第二高频精灵而非种子自身，使得频率计数不仅选择种子还决定填充色，形成三路耦合。

## 新题 9：障碍截断的轮廓跟随滑动

**组合逻辑**：[slide + contour_adjacency + longest_adjacent_path](创新：在轮廓路径上增加障碍截断条件) + [stop_at_barrier](创新：从行内阻停改为沿轮廓阻停)

**来源原语**：slide、contour_adjacency、longest_adjacent_path、marker_pixel、obstacle_contour（97c75046）；fixed_barrier、stop_at_barrier（9c56f360）

**依赖链**：标记像素沿视线滑向障碍物 → 在着陆点选择两个对角方向 → 沿轮廓行走但遇蓝色障碍像素则截断 → 障碍截断改变了哪个方向是"最长路径" → 标记移至截断后的最长路径终点。障碍像素引入了对基础轮廓跟随规则的修改，可能反转最优方向。

将标记像素沿视线滑向障碍物体后沿外轮廓行走，但轮廓路径上放置的截断障碍可能缩短某方向的有效路径，从而改变标记的最终落点。

**输入结构**：约 15x15 网格，黑(0)背景。一个绿(3) 4-连通障碍区域（约 15-25 像素的不规则形状，非凸）。一个红(2)单像素标记，不与障碍区域接触，但沿水平或垂直方向恰好有一条到障碍区域的直线视线（视线上全为黑(0)背景）。1-2 个蓝(1)单像素截断障碍，放置在绿色障碍区域外轮廓的 4-邻接位置上（即蓝像素与绿区域 4-相邻且蓝像素本身在黑背景上）。不同示例中障碍区域形状、标记位置、蓝色截断像素位置均不同。

**规则**：
1. 找到红(2)标记像素到绿(3)障碍区域的唯一水平或垂直视线方向。
2. 沿该视线方向将标记滑动到障碍区域前最后一个黑(0)像素位置（即视线方向上紧邻绿色区域的黑像素）。
3. 从着陆位置出发，考虑两个沿障碍外轮廓行走的对角方向（保持行走路径上每个像素都与绿色区域 4-相邻，且路径自身在黑背景上）。
4. 沿每个方向行走，逐像素前进。若下一个位置是蓝(1)截断像素或不再与绿色区域 4-相邻或到达网格边缘，则该方向的行走终止。蓝像素本身不算有效路径位置。
5. 比较两个方向的有效行走长度（经过的像素数），选择更长的方向。若等长，选择首步行方向为向上或向左的方向。
6. 将红(2)标记移至选定方向的行走终点。擦除原位置标记。蓝色截断像素保留在输出中。

**关键洞察**：没有蓝色截断障碍时，最长轮廓路径纯粹由障碍物几何决定；但截断障碍可能恰好阻断原本更长的方向，使原本较短的方向反而胜出——求解者必须同时考虑几何轮廓和截断约束。

## 新题 10：标记选中对象的旋转锯齿平铺

**组合逻辑**：[crop + marker_selects_neighbor](已有) + [tiling + diag_zigzag + alt_rotate_recolor](创新：种子从矩形条改为标记选中的不规则形状)

**来源原语**：crop、marker_selects_neighbor、adjacency_contact（48d8fb45）；tiling、rotation、alt_rotate_recolor、diag_zigzag（fd4b2b02）

**依赖链**：灰标记选中目标对象 → 裁剪得到种子 → 种子的边界框尺寸决定锯齿步长 → 锯齿平铺沿对角线放置种子副本 → 奇数步副本旋转 90 度并换色。选中步骤决定种子内容和步长参数，平铺步骤使用该参数生成输出。

用灰色标记选中多个对象中的一个，将其作为种子沿两条对角线进行锯齿平铺，交替放置原始副本与旋转 90 度并换色的副本。

**输入结构**：约 14x14 网格，黑(0)背景。2-3 个小型绿(3)4-连通对象（每个 3-6 像素，形状不规则，互不接触）。一个灰(5)单像素与其中恰好一个绿色对象 4-相邻。另有一个品红(6)单像素在网格中不与任何绿色对象接触（提供备用颜色）。不同示例中被选中的对象形状不同，灰标记接触不同的对象。

**规则**：
1. 识别与灰(5)标记 4-相邻的绿(3)对象，裁剪到边界框（H 行 x W 列）。该裁剪模式为种子。
2. 记录种子在原始网格中的边界框左上角位置为 (r0, c0)。
3. 沿两条对角线方向放置种子副本：位置为 (r0 + d*(H+W), c0 + d*(H+W)) 和 (r0 + d*(H+W), c0 - d*(H+W))，其中 d = ..., -2, -1, 0, 1, 2, ...
4. d = 0 的位置放置原始种子（绿(3)）。|d| 为偶数且 d != 0 的位置也放置原始种子（绿(3)）。
5. |d| 为奇数的位置放置种子的 90 度顺时针旋转副本，颜色改为品红(6)。
6. 若副本的任何部分超出网格边界，仅绘制在网格内的部分。
7. 擦除灰标记像素、品红指示像素和未被选中的绿色对象。

**关键洞察**：种子不是简单的矩形条（如参考题中），而是由标记从多个候选中选出的不规则形状——其不规则轮廓在 90 度旋转后产生与原始方向明显不同的视觉模式，使锯齿图案更具辨识度；同时种子的边界框尺寸决定了对角步长，形状与步长紧耦合。

## 新题 11：封闭面积奇偶驱动的路径色序反转

**组合逻辑**：[reverse_color_seq](创新：反转由外部条件触发而非无条件执行) + [counting + enclosed_bg_region](创新：计数结果不用于输出排列而用于生成二元触发信号) + [endpoint_traversal](已有)

**来源原语**：reverse_color_seq、endpoint_traversal、one_pixel_path、shape_fixed_reversed、endpoint_pixel（5792cb4d）；counting、enclosed_bg_region、ordered_arrangement（8ba14f53）

**依赖链**：闭合环面积计数 → 产生奇偶信号 → 信号决定配对路径是否反转 → 路径与环的配对依赖各自的排名（路径按长度排，环按面积排） → 配对本身也依赖计数。计数不仅决定"是否反转"还参与"配对谁"。

网格中的闭合环与多彩路径一一配对，环的封闭面积的奇偶性决定配对路径的色序是否反转。

**输入结构**：约 18x18 网格，黑(0)背景。2-3 条多彩单像素宽路径（每条由 4-连通链组成，恰好两个端点无分支，链上每个像素颜色各异，使用红(2)、绿(3)、黄(4)、蓝(1)、橙(7)等颜色），路径之间互不接触。另有 2-3 个灰(5)闭合环（一像素宽封闭曲线），环与路径互不接触，环之间也互不接触。每个环围住不同数量的黑像素（如 2、5、7）。路径数量等于环数量。各路径长度（像素数）互不相同，各环面积也互不相同。

**规则**：
1. 计算每个灰(5)闭合环围住的黑(0)像素数量（内部面积）。
2. 按内部面积从小到大给环排名：排名 1、2、...、N。
3. 按路径长度（像素数）从短到长给路径排名：排名 1、2、...、N。
4. 将排名相同的环与路径配对（排名 1 的环配排名 1 的路径，以此类推）。
5. 对每对配对：若环的内部面积为奇数，则将配对路径的色序反转——从距离路径边界框左上角更近的端点开始遍历到另一端点，收集颜色序列，将该序列反序后重新写回相同的路径像素位置。
6. 若环的内部面积为偶数，配对路径保持不变。
7. 擦除所有灰(5)闭合环为黑(0)。路径在原始几何位置上（可能色序已反转）。

**关键洞察**：环与路径是空间上完全独立的对象——求解者必须识别出环是路径的"控制信号"，配对规则基于各自类别内的排名（面积排名 vs 长度排名），而反转触发条件是面积的奇偶性而非面积的大小；仅看单个示例难以区分"总是反转"与"奇偶触发"。
