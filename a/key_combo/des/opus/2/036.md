## 新题 1：重力沉积后的奇偶洪泛

**组合逻辑**：[重力下落](已有) + [碰撞阻挡](已有) → 剩余面积计算 → [洪泛填充](创新：填充色由沉积后剩余面积的奇偶性决定，而非框架原始面积)

**来源原语**：重力下落(gravity_drop)、碰撞阻挡(collision_blocking)、重力远近序处理(gravity_far_to_near) 来自 5ffb2104；洪泛填充(flood_fill)、空心矩形(hollow_rect)、封闭区域(enclosed_region)、面积奇偶定填充色(parity_sets_fill) 来自 868de0fa

**依赖链**：重力下落改变哪些像素落入哪些框内 → 框内剩余空区面积因此改变 → 面积奇偶决定填充色。不执行重力就无法确定剩余面积，不计算面积就无法确定填充色。

小色块在重力作用下落入空心框架，框架内剩余空白按面积奇偶填充红色或橙色。

**输入结构**：
- 黑(0)背景网格，约 15x18。
- 下半区有 2~4 个一像素厚蓝(1)边框的空心矩形框架（内部为黑(0)），各框内部面积 4~12 像素，框架间水平排列互不重叠，底边贴近网格底部。
- 上半区有若干小型单色 4-连通前景对象（每个 2~4 像素，颜色为红(2)、绿(3)或黄(4)），每个对象正好位于某个框架的正上方（水平范围落在框架内部列范围内），与框架之间有若干行黑(0)间距。
- 生成约束：每个框架上方至少有一个色块；色块宽度不超过其对应框架的内部宽度；不同色块的水平范围互不重叠；色块落入后框架内部仍有剩余空区。

**规则**：
1. 所有小色块同时向下做重力下落。处理顺序：按初始位置从下往上（底部行号最大的色块先处理）。每个色块逐行下移，保持原形状和颜色不变，直到其任一像素的下一行位置超出网格边界、或与已固定的色块像素重叠、或与蓝(1)框架边框像素重叠。
2. 所有色块固定后，对每个蓝(1)框架，计算其内部（不含边框）仍为黑(0)的像素数 S。
3. 若 S 为偶数，将该框架内部所有黑(0)像素填充为红(2)；若 S 为奇数，填充为橙(7)。
4. 落入框架内部的色块像素保持不变（不被填充覆盖）；框架边框像素保持蓝(1)不变；框架外部一切保持不变。

**关键洞察**：填充颜色无法从框架的原始几何形状直接读取——必须先模拟重力沉积，才能知道框内剩余空区面积的奇偶性。不同示例中同一尺寸的框架可能因落入色块的大小不同而得到不同的填充色。

## 新题 2：角标记发射对角射线与障碍交汇染色

**组合逻辑**：[描边/角标记](创新：角标记不仅是装饰，还作为射线发射源) → [射线延伸](已有) → [碰撞阻挡](已有) → [重涂色](创新：障碍物按被命中射线数目决定最终颜色)

**来源原语**：描边(decorate)、前景方块(foreground_square)、角标记(corner_marker)、对角邻接(diagonal_adjacency)、四角固定配色装饰(fixed_color_diagonal_corner_decoration) 来自 95990924；射线延伸(ray_extend)、画布边界(canvas_boundary)、对角方向(diagonal_dir) 来自 5c0a986e、1d398264；缺陷像素(defect_pixel)、异常值选择(outlier_selection) 来自 71e489b6

**依赖链**：角标记的位置和颜色决定射线的起点、方向和颜色 → 射线在背景中传播直到碰到障碍像素或网格边界 → 每个障碍像素被命中的射线数目和颜色决定其最终颜色。三个环节环环相扣：不做装饰就没有射线源，不做射线延伸就不知道哪些障碍被命中，不统计命中数就无法确定障碍颜色。

灰色方块的四角装饰标记沿对角线发射彩色射线，射线被障碍像素阻挡，障碍像素按被命中的射线数量重新着色。

**输入结构**：
- 黑(0)背景网格，约 15x15。
- 2~3 个灰(5)实心 2x2 方块，彼此间距至少 4 格，不贴近网格边缘（各方向至少留 3 格距离边界）。
- 5~8 个孤立的栗(9)单像素散布在背景中，作为障碍物。每个障碍物与所有灰方块的曼哈顿距离 >= 3。
- 生成约束：任意两个灰方块的同方向对角射线不会命中同一障碍物（保证每条射线至多命中一个障碍）；至少有 2 个障碍物位于某条对角射线的路径上；至少有 1 个障碍物同时位于两条不同射线的路径上（即被 2 条射线命中）。

**规则**：
1. 对每个灰(5)方块，在其外侧四个对角位置放置角标记：左上角放蓝(1)，右上角放红(2)，左下角放绿(3)，右下角放黄(4)。
2. 每个角标记沿其相对于方块中心的对角方向发射一条射线（蓝→左上方向，红→右上方向，绿→左下方向，黄→右下方向）。射线颜色与角标记相同，逐像素向对角方向延伸。射线在以下情况停止（停在碰撞前的最后一个空位置）：(a) 下一步超出网格边界；(b) 下一步位置是栗(9)障碍像素；(c) 下一步位置是另一个灰(5)方块的像素或其角标记。
3. 对每个栗(9)障碍像素，统计有多少条射线在其相邻对角位置停止（即该障碍是多少条射线的终止原因）：
   - 被 0 条射线命中：保持栗(9)不变。
   - 被恰好 1 条射线命中：重涂为该射线的颜色。
   - 被 2 条或以上射线命中：重涂为灰(5)。
4. 角标记像素、射线像素、灰方块像素均保留在输出中。

**关键洞察**：角标记既是装饰又是射线源——它们的颜色编码了方向信息。障碍像素的最终颜色不由其自身属性决定，而由全局射线交汇模式决定——被单条射线命中则继承射线色，被多条射线命中则变灰。需要对比多个示例才能归纳出这条多射线汇合规则。

## 新题 3：去噪压缩驱动的滑动染色

**组合逻辑**：[压缩/去噪](已有) → 提取象限主色表 ← 并行 → [滑动](已有) → 两条路径在[重涂色](创新：标记像素的最终颜色由出发象限的主色决定)处汇合

**来源原语**：压缩(compress)、十字分隔线(cross_separator)、四象限(quadrant)、主色代表区域(dominant_per_region)、去噪取主色(denoise_majority)、忽略干扰项(ignore_distractors) 来自 996ec1f3；滑动(slide)、标记像素(marker_pixel)、行列对齐(row_col_aligned)、最近距离(nearest_distance) 来自 d6e50e54；重涂色(recolor) 来自 d6e50e54、d364b489

**依赖链**：去噪压缩确定四个象限的主色（颜色映射表）→ 标记像素沿行/列向中心矩形滑动（空间位移）→ 标记在目标位置停下后被重涂为其出发象限的主色。压缩结果提供颜色映射，滑动结果提供空间位置，两个独立推理在重涂步骤必须交叉引用。

十字分隔线将网格分为四个有噪声的象限，标记像素向中心矩形滑动后被重涂为其所在象限去噪后的主色。

**输入结构**：
- 网格约 13x13。一条完整行和一条完整列为同色灰(5)分隔线，将网格分为四个非空矩形象限。
- 每个象限有一种唯一的主色（从蓝(1)、红(2)、绿(3)、黄(4)中各取一种，四象限不重复），占该象限非分隔线像素的 70%~85%；其余像素为噪声色（从剩余颜色中随机选取，但不使用栗(9)和橙(7)）。
- 灰(5)分隔线交叉点附近（中心区域）有一个橙(7)实心小矩形（2x2 或 3x1 或 1x3），不与分隔线重叠。
- 每个象限恰好包含 1~2 个栗(9)标记像素，每个标记与橙(7)矩形在同一行或同一列上对齐。
- 生成约束：标记像素不在分隔线上；标记与橙矩形之间的行/列路径上没有其他标记或橙像素；从同一侧滑入的标记初始距离互不相同（保证近远顺序明确）。

**规则**：
1. 识别灰(5)分隔线，确定四个象限。对每个象限，忽略栗(9)标记像素和灰(5)分隔线像素后，统计剩余像素中出现次数最多的颜色作为该象限的主色。
2. 记录每个栗(9)标记像素所在的象限。
3. 每个栗(9)标记像素沿其与橙(7)矩形对齐的方向（同行则水平滑动，同列则垂直滑动）向橙矩形直线滑动。标记穿过噪声像素和分隔线像素（不被阻挡），但被橙(7)矩形边界和已停止的其他标记阻挡。标记停在橙矩形边界外侧或已停标记外侧紧邻的那一格。从同一侧滑入时，离橙矩形近的标记先处理、先停止，成为后续标记的阻挡物。
4. 每个标记像素停止后，将其颜色从栗(9)重涂为该标记出发时所在象限的主色。

**关键洞察**：标记像素的最终颜色不取决于它停留的位置，而取决于它出发的位置——必须追溯每个标记来自哪个象限，再查阅该象限的去噪主色。去噪和滑动是两个独立推理过程，但它们的结果必须在重涂步骤交叉引用，缺一不可。

## 新题 4：去遮挡补全与面积排名重涂

**组合逻辑**：[补全/隐含区域重涂](已有) → 面积计算 → [排序](创新：按补全后面积排名) → [重涂色](创新：排名决定最终颜色，而非原始颜色)

**来源原语**：补全(complete)、被遮挡形状(occluded_shape)、矩形足迹(rectangular_footprint)、前景遮挡(foreground_occlusion)、隐含区域重涂(implied_region_recolor) 来自 52df9849；排序(sorting)、质心偏移定位(centroid_offset_positioning) 来自 4e45f183；重涂色(recolor) 来自 d6e50e54

**依赖链**：补全操作恢复被遮挡的像素 → 补全改变每个形状的实际面积 → 面积排名决定每个形状的最终颜色。不做补全就不知道真实面积，不知道面积就无法排名，不排名就无法确定颜色。

多个部分重叠的前景矩形先被补全为完整形状，再按补全后的面积从大到小重涂为固定的颜色序列。

**输入结构**：
- 黑(0)背景网格，约 12x12。
- 3~4 个不同颜色的实心矩形前景形状（颜色从蓝(1)、红(2)、绿(3)、黄(4)、橙(7)中选取，各不相同），部分矩形彼此重叠。矩形尺寸在 2x3 到 5x6 范围内。
- 每个矩形的边界框（bbox）内所有像素均为前景色（无黑(0)背景），但可能包含其他矩形颜色的像素（即被其他矩形遮挡/覆盖的区域）。
- 每个矩形至少有 60% 的像素可见（为自身颜色），保证可识别。
- 生成约束：各矩形补全后的面积互不相同（无并列），以保证排名唯一。

**规则**：
1. 对每个前景颜色 C，找到颜色 C 所有像素的最小边界框。若该边界框内所有像素均为前景色（非黑(0)）且包含其他颜色的像素，则将边界框内所有非 C 像素重涂为 C，完成形状补全。
2. 计算每个补全后形状的面积（像素总数），按面积从大到小排序。
3. 面积最大的形状重涂为蓝(1)，第二大重涂为红(2)，第三大重涂为绿(3)，第四大（若有）重涂为黄(4)。
4. 重绘顺序：面积最大的最先绘制（最底层），面积最小的最后绘制（最顶层）。因此重叠区域显示面积较小形状的颜色。

**关键洞察**：形状的原始颜色与最终颜色无直接对应——最终颜色完全由补全后的面积排名决定。补全会恢复被遮挡部分使面积增大，可能颠覆仅凭可见像素数做出的排名判断。必须对比多个示例才能发现"面积→排名→固定颜色序列"的映射规则。

## 新题 5：中线打孔后的垂直射线发射

**组合逻辑**：[擦除/中线交替打孔](已有) → 孔洞成为发射点 → [射线延伸](创新：射线方向垂直于矩形长轴，从孔洞向两侧发射) + [碰撞阻挡](创新：射线被其他矩形阻挡，长度因矩形间距而异)

**来源原语**：擦除(erase)、中心线(center_line)、交替(alternating)、中线交替打孔(alternating_holes_on_center) 来自 3bdb4ada；射线延伸(ray_extend)、画布边界(canvas_boundary) 来自 5c0a986e、1d398264；矩形(rectangle)、碰撞阻挡(collision_blocking) 来自 d6e50e54、5ffb2104

**依赖链**：交替打孔在矩形中心线上创建特定位置的孔洞 → 孔洞位置成为射线起点 → 射线沿垂直于矩形长轴的方向向两侧延伸 → 射线被其他矩形阻挡决定长度。打孔模式决定射线的位置和疏密，矩形间空间关系决定射线长度。

对3像素宽矩形的中心线交替打孔，每个孔洞向矩形两侧发射垂直射线，射线被其他矩形阻挡。

**输入结构**：
- 黑(0)背景网格，约 15x15。
- 2~4 个非黑单色矩形（短边长度 3，长边为奇数且长度在 5~11 之间），可水平或垂直放置。各矩形颜色不同（从蓝(1)、红(2)、绿(3)、黄(4)中选取）。
- 矩形之间不接触、不重叠，间距至少 2 格。
- 生成约束：至少有一对矩形的长轴方向相互垂直（使射线阻挡现象出现）；至少有一条射线会被另一个矩形阻挡（不是所有射线都延伸到边界）。

**规则**：
1. 对每个矩形，确定其长轴方向。若垂直放置（高>宽），将其视为旋转为水平方向进行处理。沿长轴方向，中间行（短边方向的中心行）的像素从长轴第 2 个位置开始、每隔一个位置擦除为黑(0)（即沿长轴的位置 2, 4, 6, ... 被擦除，位置从 1 开始计数）。
2. 每个被擦除的像素（孔洞）成为射线发射点。从每个孔洞向垂直于矩形长轴的两个方向（即沿短轴方向的两侧，从矩形外部开始）各发射一条射线。射线颜色与矩形颜色相同。
3. 射线从矩形边界外的第一个像素开始，逐像素延伸，直到：(a) 下一步超出网格边界；或 (b) 下一步碰到任何非黑(0)像素（包括其他矩形的边框或已绘制的射线）。射线停在碰撞前的最后一个空位置。
4. 矩形本体（含孔洞）保持打孔后状态不变。射线绘制在黑(0)背景上。

**关键洞察**：射线的位置由打孔的交替模式严格决定——长轴奇数位保留实体、偶数位打孔发射射线。射线长度则由矩形之间的空间关系决定：平行矩形间的射线可以很长，而垂直放置的矩形会截断另一个矩形的射线，形成不对称的梳齿状图案。

## 新题 6：水平重力滑动合并后的图例计数

**组合逻辑**：[重力下落→水平变体/滑动](已有) + [碰撞阻挡](已有) → 同色合并判定（涌现行为）→ [计数](创新：计数的是合并后的对象数) → [填充图例](已有)

**来源原语**：滑动(slide)、连通分量(connected_component)、网格边界(grid_edge)、碰撞阻挡(collision_blocking)、重力远近序处理(gravity_far_to_near) 来自 5ffb2104；计数(counting)、填充图例(populate_legend)、图例框(legend_box)、前景对象(foreground_object)、颜色索引行(color_keyed_row)、计数映射点序列(count_to_dot_sequence) 来自 58490d8a

**依赖链**：水平重力使对象右滑 → 碰撞后同色对象若 4-连通则合并为一个 → 合并改变了每种颜色的对象数量 → 数量变化反映在图例中。不做滑动就不知道哪些对象碰撞，不判断合并就不知道最终数量。

彩色对象在水平重力作用下右滑碰撞，同色相邻对象合并为一个，最终各色对象数量记录在图例框中。

**输入结构**：
- 黑(0)背景网格，约 12x16（高 12，宽 16）。
- 左侧约 3/4 区域散布 6~10 个单色 4-连通前景对象（每个 2~5 像素），颜色为蓝(1)、红(2)、绿(3)中的 2~3 种，每种颜色有 2~4 个独立对象（当前各自不 4-连通）。
- 右侧有一个图例框：灰(5)一像素边框围成的矩形区域（约 5 列宽、覆盖网格全高或大部分高度）。图例框最左侧非边框列上，每种使用的前景颜色在不同行有一个该色关键像素，关键像素之间至少间隔一行。
- 生成约束：至少有一对同色对象在水平滑动后会变为 4-连通（可合并）；至少有一对同色对象滑动后不相邻（不合并），以使合并后的计数与原始计数不同；图例框关键像素右侧有至少 4 列空间容纳计数点。

**规则**：
1. 图例框固定不动。左侧所有前景对象向右做水平重力滑动：按原始边界框右边界列号从大到小的顺序处理（最右的对象先处理）。每个对象保持形状不变，逐列右移，直到其任一像素的右一列位置超出网格边界、或碰到已固定对象的像素、或碰到图例框边框像素。
2. 所有对象固定后，对每种前景颜色，重新计算该色所有像素的 4-连通分量数。若原本独立的两个同色对象滑动后变为 4-连通，则视为一个对象。
3. 统计每种颜色的最终连通分量数作为对象计数。
4. 在图例框中，从每个颜色关键像素出发，沿该行向右每隔一列放置一个该颜色的点，共放置该颜色最终对象计数个点（第 1 个点在关键像素右侧第 2 列，第 2 个点在第 4 列，以此类推）。

**关键洞察**：图例中的计数不是原始对象数量，而是碰撞合并后的数量。仅凭初始布局数对象会得到错误答案——必须先模拟滑动并判断同色合并，才能确定正确计数。需对比多个示例发现"同色相邻合并"规则，因为简单的"数量不变"假设在单个示例中也可能偶然吻合。

## 新题 7：空心框数量决定模板缩放倍率

**组合逻辑**：[计数](创新：对空心框计数，计数结果不写入图例而作为几何参数) → [像素放大](创新：缩放倍率由计数结果动态决定) + [标记位决定展开方向](已有)

**来源原语**：空心矩形(hollow_rect)、封闭区域(enclosed_region)、包含(containment) 来自 868de0fa；计数(counting) 来自 58490d8a；像素放大(pixel_scaling)、标记像素(marker_pixel)、填充色块(fill_block)、对角方向(diagonal_dir)、标记位决定展开(marker_pos_sets_expansion) 来自 4522001f

**依赖链**：空心框的数量 N 决定缩放倍率 → 3x3 模板中标记像素的对角方向决定展开方向 → 输出为 (3N)x(3N) 网格，模板中每个像素放大为 NxN 块，锚定在标记方向对应的角落。缩放倍率和展开方向分别由两个独立观察确定，两者共同决定输出。

数网格中空心框的数量作为缩放倍率，将带标记的 3x3 模板按此倍率像素放大，并按标记方向锚定到输出角落。

**输入结构**：
- 黑(0)背景网格，约 15x15。
- 网格中散布 2~4 个一像素厚蓝(1)边框的空心矩形框架（内部为黑(0)），框架大小各异（内部面积 2~8 像素不等），彼此不接触不重叠。
- 网格的某个角落区域有一个 3x3 的小模板，与所有框架不重叠不相邻。模板结构：一个 2x2 子区域包含一个栗(9)标记像素和三个橙(7)填充像素，标记占据 2x2 的一个角位置；模板剩余的第三行或第三列为黑(0)。
- 生成约束：空心框数量为 2、3 或 4（保证输出尺寸合理）；模板中标记的角位置在不同示例中可能不同。

**规则**：
1. 计数：统计网格中蓝(1)空心矩形框架的总数量 N。
2. 确定展开方向：在 3x3 模板中，找到栗(9)标记像素在 2x2 子区域中的角位置。该位置的对角方向即为展开方向（左上标记→展开向右下；右上标记→展开向左下；左下标记→展开向右上；右下标记→展开向左上）。
3. 创建 (3N)x(3N) 的黑(0)输出网格。
4. 将 3x3 模板进行像素放大：模板中每个非黑像素变为 NxN 的同色块，黑(0)像素仍为 NxN 的黑块。将放大后的 (3N)x(3N) 图案锚定在展开方向对应的输出角落：展开向右下时锚定在输出左上角，展开向左下时锚定在输出右上角，以此类推（标记像素的 NxN 块始终位于与展开方向相反的角落）。
5. 输出仅包含放大后的模板图案，不包含原始框架和输入的其他内容。

**关键洞察**：输出的尺寸和内容同时依赖两个独立信息源——框架数量控制缩放倍率和输出大小，标记位置控制锚定方向。仅看模板无法知道输出多大，仅数框架无法知道输出长什么样。两者必须同时推断。

## 新题 8：碎片质心排序与边框区域图例填充的交叉约束

**组合逻辑**：[排序/质心方向分类](已有) + [填充/固定图例补色](已有) → 交叉约束：排序结果改变填充目标集合，两者在共享插槽上互相影响

**来源原语**：排序(sorting)、瓦片碎片(tile_fragment)、分隔插槽阵列(separated_slot_array)、质心偏移定位(centroid_offset_positioning)、质心方向映射插槽(centroid_direction_maps_to_slot) 来自 4e45f183；填充(fill)、边框区域(bordered_region)、固定图例(fixed_legend)、位置对应颜色(position_to_color)、缺失位补色(fill_missing) 来自 a834deea

**依赖链**：瓦片碎片的质心方向决定目标插槽 → 部分插槽是边框区域（内部有缺失位）→ 碎片放入边框区域后占据了部分内部位置 → 剩余缺失位用固定图例补色。排序和填充互相影响：不知道碎片去哪就不知道哪些位置需要补色，碎片占据的位置不参与补色。

将标记碎片按质心方向分入 3x3 插槽阵列，然后对阵列中的边框区域用固定位置图例补全缺失像素，碎片占据的位置不再补色。

**输入结构**：
- 19x19 黑(0)网格，被黑(0)分隔行和分隔列分为 3x3 共 9 个 5x5 瓦片插槽（分隔线位于第 6、12 行和第 6、12 列，宽度 1 像素）。
- 9 个插槽中 4~6 个非空，其余全黑。非空插槽分两类：
  - 碎片插槽（3~4 个）：包含青(8)频繁填充色和红(2)少见标记色。标记色像素形成一个小碎片（2~4 个红(2)像素），碎片相对于 5x5 中心 (2,2) 的质心行偏移和列偏移的符号组合决定目标方向（如行负列负→左上插槽，行零列正→右中插槽）。
  - 边框插槽（1~2 个）：一像素厚黑(0)边框围成的 5x5 区域，3x3 内部中部分位置已填有青(8)像素，其余内部位置为黑(0)（缺失位）。
- 生成约束：碎片的目标插槽可以是当前为空的插槽或边框插槽，但不会是另一个碎片插槽；至少一个碎片的目标是边框插槽；碎片放入目标插槽后至少留有 1 个缺失位待补色。

**规则**：
1. 对每个碎片插槽，提取红(2)标记像素的坐标集合，计算集合质心相对于 5x5 中心 (2,2) 的行偏移 dr 和列偏移 dc。根据 (sign(dr), sign(dc)) 确定目标插槽在 3x3 阵列中的位置：(-1,-1)→左上, (-1,0)→上中, (-1,+1)→右上, (0,-1)→左中, (0,0)→中心, (0,+1)→右中, (+1,-1)→左下, (+1,0)→下中, (+1,+1)→右下。
2. 将碎片的红(2)标记像素移动到目标插槽的对应 5x5 内部坐标位置（保持相对于 5x5 中心的相同偏移）。原碎片插槽中的红(2)像素位置变为黑(0)，其余青(8)填充保留。
3. 对每个边框插槽的 3x3 内部（第 2~4 行、第 2~4 列），应用固定位置颜色图例：
   ```
   蓝(1)  橙(7)  品红(6)
   黄(4)  灰(5)  灰(5)
   红(2)  栗(9)  绿(3)
   ```
   内部 3x3 中已有青(8)像素的位置保持不变；已有红(2)碎片像素（由步骤 2 放入）的位置保持不变；剩余的黑(0)缺失位填充为图例中对应位置的颜色。
4. 目标为空插槽（非边框）的碎片直接放入，该插槽不做图例填充。

**关键洞察**：碎片和边框不是独立处理的两类对象——当碎片的目标恰好是边框插槽时，碎片像素"占位"使得该位置不被图例颜色覆盖，从而改变了边框区域最终呈现的颜色图案。必须先解决排序（碎片去哪），才能确定填充（补哪些色），形成不可跳步的交叉约束。

## 新题 9：对称补全后新增凸起发射外向射线

**组合逻辑**：[对称补全](已有) → 区分原始 vs 新增边界像素（元推理）→ [射线延伸](创新：仅新增凸起像素作为射线源，原始凸起不发射)

**来源原语**：对称补全(symmetric_complete)、凸起(tab)、缺口(notch)、边界(boundary)、对侧互补(opposite_side_complement)、跨行列投射(cross_span_projection) 来自 8dab14c2；射线延伸(ray_extend)、中心向外辐射(radiate_from_center)、罗盘方向(compass_direction) 来自 1d398264；画布边界(canvas_boundary) 来自 5c0a986e

**依赖链**：对称补全在形状对侧添加新凸起像素 → 这些新增像素（而非原始边界像素）成为射线发射源 → 每条射线从新增凸起出发沿远离形状的方向延伸至网格边界。不做补全就不知道哪些像素是"新增的"，也就无法确定射线的位置和数量。

对厚实前景形状做边界凸起/缺口的对侧补全，然后从每个新增的凸起像素向外发射射线至网格边缘。

**输入结构**：
- 黑(0)背景网格，约 13x13。
- 一个由蓝(1)构成的厚实直线形（rectilinear）4-连通形状，占据网格中心区域，行跨度和列跨度约 5~8 像素。
- 形状边界上有 2~4 个凸起（tab）：单像素向外突出，该蓝(1)像素在前景中只有 1 个 4-邻居。
- 形状边界上有 2~4 个缺口（notch）：单像素向内凹入的黑(0)像素，该像素有 3 个蓝(1) 4-邻居。
- 凸起和缺口可成对出现在形状的对侧（沿同行/列投射到另一边界），但输入中部分凸起缺少对侧缺口、部分缺口缺少对侧凸起（即补全尚未完成的状态）。
- 生成约束：形状厚度（各处的行/列跨度）>= 4 像素，使"对侧"可沿行/列明确投射；凸起旁紧邻的缺口不算独立缺口（属于凸起的局部形态）；至少有 2 个缺口需要补全（即至少会新增 2 个凸起像素）。

**规则**：
1. 对称补全：
   - 对每个缺口（有 3 个蓝(1) 4-邻居的黑(0)像素），沿其所在行或列（取与缺口开口方向一致的轴）投射到形状的对侧边界，在对侧边界外紧邻位置添加一个蓝(1)像素（新增凸起）。
   - 对每个凸起（只有 1 个蓝(1) 4-邻居的蓝(1)像素），沿其所在行或列投射到形状的对侧边界，将对侧边界像素擦除为黑(0)（新增缺口）。
   - 凸起旁紧邻的缺口不作为独立源处理。
2. 识别步骤 1 中**新增的凸起像素**——即由缺口的对侧补全规则在步骤 1 中新添加的蓝(1)像素。原始凸起（输入中已存在的单邻居突出像素）不算新增。
3. 从每个新增凸起像素出发，确定其外向方向（该像素相对于形状主体的突出方向：上/下/左/右），发射一条红(2)射线。射线从新增凸起的外侧下一个像素开始，沿外向方向逐像素延伸，直到离开网格边界。
4. 输出中：原始形状（含补全修改——新增凸起和新增缺口）保持蓝(1)；射线为红(2)；背景保持黑(0)。

**关键洞察**：射线不是从所有凸起发射——只有通过对称补全**新生成**的凸起才是射线源。原始凸起虽然形态完全相同（也是单邻居突出像素），但不发射射线。求解者必须理解对称补全规则、追踪哪些像素是新增的，才能判断射线的位置和数量。这是一个元推理任务：规则作用于规则自身的输出标记。
