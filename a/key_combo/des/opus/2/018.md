## 新题 1：射线可见度评分驱动精灵方块重排

**组合逻辑**：[射线投射](从源条逐行发射水平射线，统计每个精灵体被命中次数——创新：射线不再用于选择单一目标，而是为所有目标计分) → [计数](统计各精灵体的可见度得分) → [排序+压缩重排](按可见度得分升序，将精灵体转换为正方形并底部对齐排列)

**来源原语**：射线投射/视线可达/忽略干扰项(#1 3d588dc9), 计数(#10 e872b94a), 排序/压缩重排/像素数定边长/面积递增排列(#16 8abad3cf), 精灵体(#8/#13/#14)

**依赖链**：射线投射为每个精灵体生成可见度得分 → 得分决定排序顺序 → 排序后才能确定重排位置；同时精灵体的像素数决定其转换后的正方形边长。两条信息流（得分决定位置、像素数决定尺寸）在最终重排步骤汇合。

从源条水平发射射线，统计各精灵体被射线命中的次数作为可见度得分，按得分升序将精灵体压缩为正方形并底部对齐排列输出。

**输入结构**：约 18x18 网格，背景黑(0)。左边缘第 0 列为一条竖直的灰(5)源条（每行一个灰像素，覆盖全列高度）。网格中散布 4-5 个单色 4-连通精灵体，每个 3-8 像素不等，颜色互不相同，取自红(2)、蓝(1)、绿(3)、黄(4)、品红(6)。另有若干单像素橙(7)干扰点随机分布。生成约束：各精灵体互不相邻（边界框间距 >= 1），灰(5)源条仅出现在第 0 列，各精灵体的可见度得分互不相同。

**规则**：
1. 忽略所有橙(7)单像素干扰点（不遮挡射线、不参与后续操作）。
2. 从灰(5)源条的每个像素（每行一个）向右发射水平射线，射线沿该行逐列前进，遇到非背景、非橙(7)像素时命中该像素所属的精灵体后停止（射线不穿透精灵体）。若射线未命中任何精灵体就到达右边界，则该射线无效。
3. 对每个精灵体，统计被不同源行射线命中的总次数，记为该精灵体的"可见度得分"。
4. 将每个精灵体转换为一个实心正方形，边长 = 该精灵体像素数的整数平方根（生成约束：每个精灵体的像素数为完全平方数）。正方形颜色保持该精灵体的原色。
5. 按可见度得分升序（最低分在最左）将正方形从左到右排列，底部对齐（所有正方形的最底行相同），相邻正方形之间留 1 列黑(0)背景间隔。
6. 输出网格宽度 = 所有正方形宽度之和 + 间隔列数，高度 = 最大正方形边长。左上角开始放置。

**关键洞察**：精灵体的空间位置决定其被多少射线遮挡，但遮挡关系与精灵体本身的尺寸或颜色无关——只取决于它与源条的相对纵坐标重叠及前方是否有其他精灵体挡住射线。因此仅看输入中精灵体的位置无法直接推断排序，必须逐行模拟射线传播。

## 新题 2：环路弯折分类门控内部填充

**组合逻辑**：[环路追踪+分类涂色](追踪每条闭合环路，将弯折像素分为凸/凹) → [计数](统计各环路的凸弯折数，计算全局中位数阈值) → [填充](仅对凸弯折数达到中位数阈值且内部孔洞为正方形的环路进行填充，填充颜色由有无凹弯折决定)

**来源原语**：环路追踪/分类涂色/弯折像素/多数转向为凸/少数转向为凹(#7 15663ba9), 填充/封闭区域/孔洞/孔洞几何决定填充/仅正方形孔洞填充(#6 44d8ac46), 计数(#10 e872b94a), 内部包含(#6 44d8ac46)

**依赖链**：弯折分类（凸/凹）需要追踪完整环路 → 凸弯折计数需要在所有环路上完成后才能算出中位数 → 中位数门控 + 孔洞几何门控同时决定是否填充 → 填充颜色由该环路自身的凹弯折有无决定。全局阈值导致任何单个环路的结果都依赖于其余所有环路。

追踪所有闭合正交环路并分类弯折，以全局凸弯折中位数为门槛，对达标且内含正方形孔洞的环路按有无凹弯折分色填充。

**输入结构**：约 20x20 网格，背景黑(0)。3-4 条互不接触的蓝(1)闭合正交环路，每条环路为 1 像素宽的直角折线闭合曲线（每个前景像素恰好有 2 个 4-连通前景邻居）。每条环路围出一块黑(0)内部区域（孔洞）。部分孔洞的边界框为正方形且被黑像素完全填满（"正方形孔洞"），其余孔洞为长方形或 L 形等不规则形状。环路之间至少间隔 2 个像素，且不接触网格边界。生成约束：至少一个环路有凹弯折，至少一个环路仅有凸弯折；各环路的凸弯折数互不相同。

**规则**：
1. 追踪每条蓝(1)闭合环路。对每个环路像素，检查其两个 4-连通前景邻居的走向：若走向发生方向改变，该像素为弯折像素；否则为直行像素。
2. 对每个弯折像素，判断其转向方向。在该环路中统计两种转向方向的出现次数，出现次数更多的为凸弯折，更少的为凹弯折（依据：简单直角闭合曲线的凸弯折总比凹弯折多恰好 4 个）。
3. 统计每条环路的凸弯折总数。将所有环路的凸弯折数排序，取中位数（环路数为偶数时取较小的中间值）。
4. 一条环路被"激活"当且仅当其凸弯折数 >= 中位数。
5. 对每条激活的环路，计算其内部封闭区域（4-连通黑(0)像素且被该环路完全包围）。若该封闭区域的边界框是正方形且被黑像素完全填满，则执行填充：
   - 若该环路不含任何凹弯折 → 填充为黄(4)。
   - 若该环路含有至少一个凹弯折 → 填充为红(2)。
6. 未被激活的环路、以及激活但孔洞非正方形的环路保持原样不变。直行像素和弯折像素的颜色保持蓝(1)不变（不做源题 #7 中的弯折像素重涂色）。

**关键洞察**：某条环路的孔洞是否被填充不仅取决于自身的孔洞形状，还取决于所有环路的凸弯折数分布——全局中位数阈值使得增减任何一条环路都可能改变其他环路的激活状态。必须分析完所有环路后才能做出任何一条环路的填充判断。

## 新题 3：寻路方向决定模板印章朝向

**组合逻辑**：[寻路](BFS 搜索障碍触发转向路径) → [模板提取](从网格角落提取印章模板) → [旋转+印章覆盖](在路径上每个标记点处，按路径行进方向旋转模板后覆盖印章)

**来源原语**：寻路/障碍像素/起止标记/路径/障碍触发转向(#4 2dd70a9a), 印章覆盖/模板图块/标记像素/标记指定放置位置/仅标记格被覆盖(#5 e734a0e8), 旋转(#3 2b83f449/#13 2697da3f)

**依赖链**：障碍布局唯一确定路径走向 → 路径上每个标记点处的行进方向唯一确定模板旋转角度 → 旋转后的模板覆盖在标记点上。没有路径就不知道在哪里印章也不知道旋转多少度；没有模板就没有可印的内容；没有旋转则印章朝向错误。

沿障碍触发转向路径前进，在路径经过的每个标记点处，按当前行进方向旋转模板后印章覆盖。

**输入结构**：约 18x18 网格，背景黑(0)。青(8)障碍像素散布于网格中部区域。一段 2-3 像素长的绿(3)水平或竖直线段标记起点及初始行进方向；一段同长的红(2)线段标记终点。网格的一个角落（如左上角 4x4 区域）包含一个由黄(4)像素组成的小型非对称模板图块（约 3x3 边界框，4-6 个黄像素，非旋转对称），模板区域与路径区域不重叠。路径可达区域中放置有 2-4 个品红(6)标记像素，这些像素位于路径将经过的黑(0)格子上。生成约束：从起点到终点存在唯一的障碍触发转向路径；每个品红标记都恰好位于该路径上；路径上各标记点处的行进方向不全相同（至少出现 2 种方向）。

**规则**：
1. 从绿(3)起点出发，沿初始方向做 BFS：在黑(0)格子上直行，仅当前方下一格为青(8)障碍时触发转向（尝试左转或右转，选择可行方向继续；生成约束保证每个转向点只有一个可行方向）。到达红(2)终点前一格时停止。记录完整路径及路径上每个格子的行进方向。
2. 提取黄(4)模板图块：取所有黄(4)像素的边界框作为模板。
3. 路径上每个品红(6)标记点触发印章操作。按路径顺序（从起点到终点）依次处理各标记点：
   - 行进方向为右 → 模板保持原始朝向（0 度）
   - 行进方向为下 → 模板顺时针旋转 90 度
   - 行进方向为左 → 模板旋转 180 度
   - 行进方向为上 → 模板顺时针旋转 270 度
4. 印章以标记点为中心放置（模板边界框中心对齐到标记点坐标）。超出网格边界的部分裁掉。后处理的印章覆盖先处理的（沿路径方向越靠后的印章优先级越高）。
5. 输出保留绿(3)起点、红(2)终点、青(8)障碍、模板角落原样不变。路径本身不涂色（路径格子保持黑(0)，除非被印章覆盖）。品红(6)标记像素被印章覆盖。

**关键洞察**：模板在每个标记点的朝向不是固定的，而是由路径在该点的行进方向唯一决定；而行进方向又由障碍布局唯一决定。改变任意一个障碍像素的位置都可能改变路径走向，从而改变所有下游标记点的印章朝向。

## 新题 4：字形编码地板高度驱动令牌重力下落

**组合逻辑**：[解码指令](读取字形像素面积，编码为对应列的地板高度) → [重涂色](字形颜色匹配令牌颜色，建立字形-令牌对应关系——创新：颜色不再是置换映射，而是跨面板的配对信号) → [重力下落](令牌在各自列中下落直到碰撞地板或已沉降令牌)

**来源原语**：解码指令/字形指令/分隔列/顺序读取/编码映射(#17 136b0064), 重力下落/令牌/碰撞停止(#3 2b83f449), 重涂色(#1/#20), 入口侧决定列(#3 2b83f449)

**依赖链**：字形面积 → 地板高度（没有解码就不知道地板在哪）；字形颜色 → 令牌匹配（没有颜色对应就不知道哪个地板给哪个令牌）；地板高度 + 令牌位置 → 下落结果（没有重力模拟就不知道令牌最终位置）。三条信息缺一不可。

读取左面板字形的像素面积编码地板高度，通过颜色匹配确定各字形对应右面板的哪个令牌列，然后令牌在各自列中下落到地板上方停止。

**输入结构**：约 16x20 网格（宽 16，高 20）。一条全高灰(5)竖直分隔线将网格分为左右两个面板。左面板宽约 7 列，包含 3-4 个 3x3 彩色字形（glyph），字形之间以 1 列黑(0)背景分隔，字形排列在左面板顶部区域（约前 3-4 行）。每个字形由单色非背景像素构成，颜色互不相同，取自红(2)、蓝(1)、绿(3)、黄(4)；每个字形的像素面积（非背景像素数）在 3-6 之间且互不相同。右面板宽约 8 列，顶行（第 0 行）放置与字形同数量的彩色单像素令牌，每个令牌占一列，颜色分别与某个字形颜色相同（一一对应），令牌之间可能隔有空列。右面板其余区域为黑(0)背景。生成约束：每个字形颜色恰好匹配一个令牌颜色；字形的像素面积互不相同。

**规则**：
1. 读取左面板的每个字形，计算其像素面积 A（3x3 边界框内非背景像素数）。面积编码地板位置：地板行号 = 网格高度 H 减去 A（即 A=3 → 地板在第 H-3 行，A=4 → 第 H-4 行，以此类推，面积越大地板越高）。
2. 通过颜色匹配建立字形与令牌的对应关系：字形颜色 = 令牌颜色 → 该字形编码的地板高度应用于该令牌所在的列。
3. 在右面板中，对每个令牌列，在该列的地板行号位置放置一个与令牌同色的地板像素。
4. 每个令牌从第 0 行开始向下做重力下落，逐格下移直到：(a) 下一格是地板像素，则停在地板上方一格；(b) 下一格是另一个已沉降的令牌，则停在其上方一格。
5. 输出仅保留右面板内容（令牌沉降后的位置 + 地板像素），左面板和灰(5)分隔线擦除为背景。输出网格宽度 = 右面板宽度，高度不变。

**关键洞察**：字形同时编码两种信息——面积编码"地板有多高"，颜色编码"这个地板属于哪一列"。仅解码面积不够（不知道给谁），仅匹配颜色也不够（不知道高度多少）。两种信息在不同的视觉维度上（形状 vs 颜色），必须同时提取才能完成任务。

## 新题 5：象限定位决定模板旋转角度的补全

**组合逻辑**：[模板提取](从完整象限提取源模板) + [象限对应](锚定块中心定义象限轴，各象限位置编码旋转角度——创新：象限不再映射颜色到 2x2 格子，而是映射旋转角度到精灵体补全操作) → [旋转+补全](对每个不完整象限，按象限编码的旋转角度旋转模板，填补缺失像素)

**来源原语**：模板提取/补全/变换副本/对齐签名匹配/旋转反射等价(#12 79369cc6), 旋转(#3/#13), 象限对应/锚定方块/象限决定目标格(#11 d89b689b)

**依赖链**：需要先找到锚定块确定象限轴 → 再判断哪个象限有完整模板 → 源象限的位置决定其余三个象限各自的旋转角度 → 旋转后的模板与已有部分像素对比才能确定缺失位置。四步紧密串联，缺任何一步都无法正确补全。

以 2x2 锚定块为中心划分四象限，从唯一完整象限提取模板，按象限位置关系确定旋转角度，补全其余三个象限中的缺失像素。

**输入结构**：约 16x16 网格，背景黑(0)。网格中偏中心位置有一个 2x2 的灰(5)实心锚定方块。四个象限（以锚定块中心为原点划分的左上、右上、右下、左下区域）中，恰好一个象限包含一个完整的小型多色精灵体（边界框约 3x4 或 4x4，使用 2 种颜色如红(2)和蓝(1)，形状非旋转对称，边界框内无背景空洞——即所有格子都被红或蓝填满）。其余三个象限各包含该精灵体某个旋转版本的不完整副本（保留约 60%-80% 的像素，其余像素为黑(0)背景）。生成约束：完整象限随机选取（不固定在左上）；三个不完整副本中缺失的像素位置互不相同；每个副本保留的像素足以唯一确定其旋转角度。

**规则**：
1. 找到灰(5) 2x2 锚定方块，以其中心（四格交点）为原点，划分上/下、左/右四个象限。
2. 识别包含完整精灵体的象限（该象限中存在一个矩形区域，区域内无黑(0)背景像素）。提取该精灵体作为源模板。记录源象限的编号（左上=0，右上=1，右下=2，左下=3）。
3. 对其余三个象限，计算其旋转角度：旋转度数 = ((目标象限编号 - 源象限编号) mod 4) x 90 度（顺时针）。
4. 对每个目标象限，将源模板顺时针旋转相应角度得到期望图案。将该象限中缺失的像素（当前为黑(0)但期望图案中为非背景色的位置）填补为期望颜色。已有的非背景像素保持不变。
5. 输出：锚定块保持灰(5)不变，源象限保持不变，三个目标象限的精灵体被补全。

**关键洞察**：源象限不是固定的——必须通过完整性检测确定哪个象限是源，这一判断直接改变其余三个象限的旋转角度。如果误判源象限，所有旋转角度都会错误。此外，补全操作需要将旋转后的模板与已有像素精确对齐，已有像素既是对齐线索也是正确性校验。

## 新题 6：背景区域数编码同心扩展层数

**组合逻辑**：[计数](统计上半区被屏障分割的背景连通区域数 N) → [同心扩展](对下半区的嵌套矩形框结构，向外扩展 N 层，奇偶层交替用色——创新：扩展层数不再由内矩形尺寸固定确定，而是由另一区域的拓扑计数动态编码)

**来源原语**：计数/连通分量/背景区域/前景屏障/区域数编码像素列(#10 e872b94a), 同心扩展/填充/矩形边框/内部矩形/同心嵌套/严格内嵌/内尺寸定扩展量(#15 3a301edc)

**依赖链**：上半区的屏障拓扑 → 背景区域数 N → N 控制下半区的扩展层数 → 扩展的颜色交替规则依赖于下半区已有结构的颜色。上半区拓扑信息与下半区几何结构通过 N 这个数值桥梁耦合。

统计上半区被屏障分割出的背景区域数，以此数值作为下半区同心矩形框结构向外扩展的层数。

**输入结构**：约 20x20 网格，背景黑(0)。一条全宽水平灰(5)分隔线将网格分为上下两个区域。上半区：红(2)前景像素构成路径状屏障，将上半区的黑(0)背景分割为若干 4-连通区域（2-5 个）。下半区：一个两色同心矩形框结构——外层为蓝(1)的 1 像素宽矩形框，内层为绿(3)的实心矩形，绿矩形严格内嵌于蓝框之中，二者之间无间隙。该结构居中放置于下半区，四周留有足够背景空间用于扩展。生成约束：下半区结构四周的空间至少能容纳 5 层扩展（保证任何合法 N 值都不会超出边界）。

**规则**：
1. 统计上半区（灰分隔线以上）中黑(0)背景的 4-连通区域数量，记为 N。灰(5)分隔线本身不属于上半区。
2. 在下半区，找到已有的蓝(1)矩形框和绿(3)内部矩形。保持它们不变。
3. 以现有蓝(1)矩形框的外边界为基础，向外逐层扩展 N 层。每层为 1 像素宽的矩形框，四个方向（上、下、左、右）各扩展 1 像素：
   - 第 1 层（紧贴蓝框外侧）：绿(3)
   - 第 2 层：蓝(1)
   - 第 3 层：绿(3)
   - 以此类推，奇数层为绿(3)，偶数层为蓝(1)。
4. 若某层的某些像素会超出网格边界，则该像素不绘制（部分绘制该层的剩余部分）。
5. 输出：擦除上半区和灰(5)分隔线（全部变为黑(0)背景），仅保留下半区的扩展后同心结构。输出网格大小不变。

**关键洞察**：上半区的屏障形状看起来与下半区的矩形框毫无关联，但屏障创造的背景分区数是一个隐式编码的数值参数，直接控制了同心扩展的规模。必须对比多个示例才能归纳出"区域数 = 扩展层数"这一非显然映射。

## 新题 7：绕障重绘后按障碍周长排序拼接

**组合逻辑**：[绕障重绘](各线段绕各自障碍体重新路由，保持像素数) → [计数](计算每个障碍体的周长) → [排序+拼接](按障碍周长升序排列各线段-锚定条组装体，底部对齐拼接——创新：排序键不是线段自身属性，而是线段绕过的障碍体的几何属性)

**来源原语**：绕障重绘/线段/障碍精灵体/锚定条/边界贴合/像素数守恒(#9 88bcf3b4), 排序/拼接/面积排序/基线对齐排列(#14 4df5b0ae), 计数(#10 e872b94a)

**依赖链**：线段必须先绕障重绘才能确定最终形态 → 同时需要计算障碍体周长获取排序键 → 排序键和重绘后的形态共同决定最终输出布局。绕障和计数是对同一个障碍体的两种分析，在排序步骤汇合。

各线段绕各自灰色障碍精灵体重绘路线并保持像素数，然后按障碍周长升序将各组装体底部对齐拼接输出。

**输入结构**：约 22x20 网格，背景黑(0)。3-4 条彩色竖直锚定条，各从顶部边缘垂直向下延伸（1 像素宽，长度 4-7 像素不等），颜色互不相同，取自红(2)、蓝(1)、绿(3)、黄(4)。每条锚定条的底端连接一段同色的不规则 4-连通线段（4-8 像素，非直线形）。每条锚定条底端附近有一个灰(5)障碍精灵体（不规则 4-连通形状，5-12 像素，各障碍形状不同）。生成约束：各锚定条-线段-障碍三元组之间互不重叠且间距 >= 2；各障碍精灵体的周长（4-连通边界像素数，即至少有一个 4-邻居为非障碍的障碍像素数量）互不相同。

**规则**：
1. 对每条锚定条-线段对，执行绕障重绘：将线段从锚定条底端分离，从底端出发向最近的灰(5)障碍像素前进，沿障碍边界顺时针贴合行进，最后以 45 度对角线方向离开障碍。重绘后的线段像素总数与原线段相同（像素数守恒）。线段颜色保持不变。
2. 计算每个灰(5)障碍精灵体的周长：统计该障碍中至少有一个 4-邻居为非障碍像素（背景或其他颜色）的像素数量。
3. 按障碍周长升序排列各"组装体"（锚定条 + 重绘后线段 + 障碍精灵体的边界框整体）。周长相同时按原始锚定条列号升序排列（靠左的先）。
4. 将排序后的组装体从左到右拼接：每个组装体取其边界框，底部对齐（所有组装体的最底行对齐到输出网格的最后一行），相邻组装体间留 1 列黑(0)间隔。
5. 输出网格高度 = 最高组装体的边界框高度，宽度 = 所有组装体边界框宽度之和 + 间隔列数。

**关键洞察**：线段的最终形态和排序键都来源于同一个障碍精灵体，但提取的信息不同——形态来自障碍的边界轮廓（路径），排序键来自障碍的周长（标量）。仅看重绘后的线段形态无法推断排序顺序，必须回溯到障碍体本身的几何属性。

## 新题 8：格栅异常值提取后借轴对称修复

**组合逻辑**：[逐行比较+异常值选择](每行格栅单元中找出唯一不同的异常图案) → [提取](将异常单元组成单列格栅) → [对称轴借用+对称补全](从该行的多数图案中提取对称轴，将其应用于异常图案进行对称修复——创新：对称轴不来自异常图案自身，也不来自一个独立的对称标记物，而是从被丢弃的多数图案中"借"来)

**来源原语**：提取/裁剪/网格单元/逐行比较/异常值选择(#8 38007db0), 对称补全/对称体/非对称体/对称轴借用(#19 4c5c2cf0), 精灵体(#8/#13)

**依赖链**：逐行比较 → 找到异常单元 → 提取异常单元的同时必须记住多数单元的对称结构 → 用多数单元的对称轴修复异常单元。提取和修复不能分离执行——修复所需的信息（对称轴）存在于被丢弃的多数单元中，若先丢弃再修复就丢失了修复依据。

从格栅的每行中提取唯一异常图案，再借用同行多数图案的对称轴将异常图案修复为对称形式。

**输入结构**：约 23x17 网格。灰(5)全行/全列分隔线将网格划分为等大的矩形格栅单元（如 4 列 x 3 行，每个单元 5x5 像素）。每个单元内部有一个由蓝(1)像素构成的精灵图案（3-8 像素的 4-连通形状）。同一行中，除一个异常单元外的所有单元都包含完全相同的图案，且该图案具有水平或竖直双边镜像对称性（具体是哪种对称性可能每行不同）。异常单元的图案是多数图案的"破损版"——有 1-2 个像素偏移了位置，导致对称性被破坏。生成约束：每行至少 3 个单元（保证多数图案可以可靠识别）；每行的异常单元位于不同列；异常图案与多数图案的差异不超过 2 个像素位置。

**规则**：
1. 对每行格栅单元，逐对比较单元内部图案（忽略灰分隔线），找出唯一不同的异常单元（与其余所有单元的图案不一致的那个）。
2. 对每行的多数图案（非异常单元共享的图案），检测其对称轴：若图案关于竖直中轴对称，轴为竖直轴；若关于水平中轴对称，轴为水平轴。若两个轴都对称，优先使用竖直轴。记录轴类型和轴位置（相对于单元内部坐标）。
3. 提取各行的异常单元，按原行顺序排列成单列格栅（保留灰分隔线，单元尺寸不变）。
4. 对每个提取出的异常单元图案，将多数图案的对称轴应用于它：对异常图案中的每个蓝(1)像素，计算其关于该轴的镜像位置；若镜像位置当前为背景，则填充为蓝(1)。若异常图案中存在不在多数图案对应位置上的多余像素（即多数图案在该位置为背景），则擦除该像素为背景。
5. 输出为修复后的单列格栅。

**关键洞察**：异常图案自身没有可靠的对称性信息（它本身就是不对称的），修复它所需的对称轴隐藏在被丢弃的多数图案中。这意味着"丢弃"和"利用"是同一批数据的两种用途——提取操作必须同时保存被过滤掉的多数模式的结构信息供后续修复使用。

## 新题 9：环路内封闭区域数选择印章模板

**组合逻辑**：[环路追踪+计数](追踪每个目标格的闭合环路，统计环路内封闭的独立背景区域数 K) → [印章覆盖](从模板区选取像素数恰好为 K 的模板精灵体，印章到该目标格中心——创新：不是用标记像素选择印章位置，而是用拓扑计数选择印章内容)

**来源原语**：环路追踪/闭合正交环路(#7 15663ba9), 计数/连通分量(#10 e872b94a), 印章覆盖/分隔网格/模板图块/标记像素/标记指定放置位置/仅标记格被覆盖(#5 e734a0e8), 封闭区域/孔洞/内部包含(#6 44d8ac46)

**依赖链**：标记像素确定哪些格需要印章 → 环路追踪确定各目标格内的拓扑结构 → 封闭区域计数 K → K 选择对应的模板 → 模板被印章到目标格。计数结果作为模板选择的索引键，将拓扑分析与印章操作耦合。

**输入结构**：约 22x22 网格。灰(5)全行/全列分隔线将网格划分为 3x3 的等大正方形格栅单元（每个单元约 6x6）。左上角单元为"模板区"，内含 3 个小型单色精灵模板，颜色互不相同（红(2)、绿(3)、黄(4)），像素数分别为 1、2、3（或 2、3、4，具体值在生成时确定），模板之间用背景分隔。其余 8 个单元中，每个单元内部都有一条蓝(1)的 1 像素宽闭合正交环路。环路的形状各不相同：有的是简单矩形（围出 1 个封闭区域），有的是 U 形或 L 形折线闭合曲线（内部可能被环路自身分隔出 2-3 个独立的 4-连通背景区域）。部分单元（3-5 个）在环路外部但单元内部有一个品红(6)标记像素，标记该单元为"目标格"。生成约束：每个目标格中环路封闭的独立背景区域数恰好等于模板区中某个模板的像素数；非目标格的区域数可以是任意值。

**规则**：
1. 识别模板区（左上角单元），提取其中的 3 个模板精灵体及各自的像素数。
2. 对每个含品红(6)标记像素的目标格单元：
   a. 追踪该单元内的蓝(1)闭合环路。
   b. 统计环路所围出的独立 4-连通黑(0)背景封闭区域数量 K（被环路完全包围的背景连通分量数量）。
   c. 从模板区选取像素数 = K 的模板精灵体。
   d. 将选取的模板以该单元中心为基准印章覆盖（模板边界框中心对齐单元中心，模板像素覆盖背景但不覆盖蓝(1)环路和灰(5)分隔线）。
3. 无标记的单元保持原样不变。模板区保持不变。品红(6)标记像素在印章后被保留（不被覆盖——若印章像素与标记像素重叠，标记像素保留）。

**关键洞察**：标记像素只告诉你"这个格子需要印章"，但不告诉你印哪个模板；模板的选择完全由环路的拓扑复杂度（封闭区域数）决定。改变环路的形状会改变封闭区域数，从而改变选中的模板，即使标记像素位置不变。

## 新题 10：对称轴借用后叠加颜色置换与遮挡过滤

**组合逻辑**：[对称轴借用+对称补全](从对称物体借轴，将非对称物体做四象限镜像展开) → [遮挡过滤](镜像结果与散落单像素做位置比对，仅保留落在镜像图案上的单像素——创新：镜像补全的结果不是最终输出的主体，而是充当空间过滤器) → [颜色置换](对幸存的单像素应用固定颜色置换映射)

**来源原语**：对称补全/对称体/非对称体/对称轴借用/借轴复制非对称体(#19 4c5c2cf0), 重涂色/固定颜色置换映射/全局像素(#20 0d3d703e), 散落单像素/锚定方块/象限对应(#11 d89b689b), 频率比较(#18 a6953f00)

**依赖链**：对称体 → 提取对称轴 → 非对称体做镜像展开 → 镜像展开结果与单像素位置比对（空间过滤）→ 仅幸存单像素做颜色置换。没有镜像展开就无法确定过滤掩码；没有过滤就不知道哪些单像素需要置换；没有置换，幸存单像素的颜色就是错的。

借用对称物体的轴将非对称物体镜像展开为四象限图案，以此图案为掩码过滤散落单像素，仅对落在图案上的单像素执行颜色置换。

**输入结构**：约 15x15 网格，背景黑(0)。一个蓝(1)单色物体具有水平和竖直双镜像对称性（如十字形、菱形或 H 形，8-16 像素），位于网格中部。一个红(2)单色不规则 4-连通物体（3-6 像素）位于蓝物体对称轴所划分的某一个象限中（如左上象限），与蓝物体不接触。网格中散布 4-8 个单像素点，颜色取自绿(3)、黄(4)、橙(7)、栗(9)，位置随机但不与蓝物体或红物体重叠。生成约束：红物体镜像展开后的四象限图案恰好覆盖部分（但非全部）单像素的位置；至少 2 个单像素被覆盖，至少 2 个不被覆盖。

**规则**：
1. 识别蓝(1)物体，验证其具有水平和竖直双镜像对称性。提取其水平对称轴（行号）和竖直对称轴（列号）。
2. 识别红(2)物体。对红物体的每个像素，计算其关于两条对称轴的所有镜像位置（共产生最多 4 个位置：原始、水平镜像、竖直镜像、中心对称），将所有镜像位置标记为红(2)，形成完整的四象限镜像图案。
3. 检查每个散落单像素：若其坐标与镜像图案中某个红(2)像素重合，则该单像素"幸存"；否则该单像素被擦除为背景黑(0)。
4. 对所有幸存的单像素执行颜色置换：绿(3) <-> 黄(4)（绿变黄、黄变绿），橙(7) <-> 栗(9)（橙变栗、栗变橙）。其他颜色不变。
5. 输出保留：蓝(1)对称物体原样不变、红(2)四象限镜像图案、幸存并置换颜色后的单像素。其余格子为背景黑(0)。

**关键洞察**：镜像展开的红色图案在输出中确实可见，但它的核心作用是充当一个空间选择掩码——决定哪些单像素得以幸存。颜色置换映射（绿黄互换、橙栗互换）是固定的，但它作用于哪些像素完全取决于镜像展开的覆盖范围。改变红物体的形状或对称轴的位置都会改变幸存的单像素集合，从而改变颜色置换的结果。
