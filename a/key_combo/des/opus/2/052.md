## 新题 1：环缝洪泛门控色循环

**组合逻辑**：[flood_fill/洪泛填充](检测缝隙可达性，创新：穿透环缝而非填充封闭区域) → [counting/计数](统计被突破环数 N) → [recolor/重涂色 + colors_cycle_by_nesting/色循环](仅对被突破环执行，方向由 N 奇偶决定)

**来源原语**：flood_fill, enclosed_region, unreachable_background_filled ← a5313dff；recolor, concentric_ring, nesting_order, colors_cycle_by_nesting ← bda2d7a6；counting ← 1190e5a7

**依赖链**：洪泛可达性判定筛选出参与循环的环子集；被突破环的数量奇偶性反转循环方向；两层依赖缺一不可——删掉洪泛则无法确定哪些环参与，删掉奇偶判定则无法确定方向。

从网格边界洪泛，只有水流能穿透缝隙到达的同心环才参与颜色轮转，轮转方向由被突破环的数量奇偶性决定。

**输入结构**：
- 约 15x15 的网格，背景为黑(0)。
- 4~6 层单像素厚的同心矩形环，每层一种颜色（从外到内依次使用蓝(1)、红(2)、绿(3)、黄(4)、灰(5)等，各层颜色不重复）。
- 部分环上恰好有一个像素为黑(0)，形成 1 像素宽的缝隙，缝隙位置不规律。
- 最内层环内部区域为黑(0)背景。
- 生成约束：每条环最多一个缝隙；至少有一条环没有缝隙（确保不是所有环都被突破）；缝隙不出现在环的四个角上。

**规则**：
1. 从网格四周边界出发，对黑(0)像素执行 4-邻域洪泛填充，标记所有从边界可达的背景像素为"外部"。环的像素视为墙壁，环上的黑色缝隙视为通道。
2. 洪泛穿过一条环的缝隙后继续向内扩散。没有缝隙的环阻断洪泛，该环及其所有内侧环不会被到达。
3. 一条环被"突破"当且仅当洪泛标记到达了该环内侧紧邻的背景像素（即该环内侧第一个黑色像素被标记为"外部"）。
4. 收集所有被突破的环，按从外到内的嵌套顺序排列其颜色序列 [c_1, c_2, ..., c_N]。
5. 统计被突破环的数量 N。若 N 为奇数，颜色序列向外循环一位：c_1 -> c_N 的环涂 c_1 色，c_2 -> c_1 的环涂 c_2 色，...，c_N -> c_{N-1} 的环涂 c_N 色（即最外层颜色移到最内层被突破环，其余各向外移一位）。若 N 为偶数，颜色序列向内循环一位：c_1 的环涂 c_2 色，c_2 的环涂 c_3 色，...，c_N 的环涂 c_1 色（即最内层被突破环的颜色移到最外层，其余各向内移一位）。
6. 未被突破的环保持原色不变。
7. 缝隙位置保持黑(0)背景不变。洪泛标记仅用于判断，不改变输出中的背景颜色。

**关键洞察**：洪泛的可达性和环的完整性共同决定了哪些环进入颜色轮转池；被突破环的数量奇偶性是一个隐蔽规则，需要对比多个示例才能发现循环方向会反转——单个示例无法区分"总是向外"和"奇数时向外"。

## 新题 2：投射距离编码垂直递减填充

**组合逻辑**：[project/投射](确定碰撞点 + 量化投射距离 D) → [shrinking_fill/递减填充](碰撞点为起点，方向取投射的垂直方向，层数 = floor(D/2)，创新：距离参数化填充规模)

**来源原语**：project, marker_pixel, canvas_boundary, collision_blocking, border_projected_to_target ← 1f642eb9；shrinking_fill, rounded_object, side_run, four_way_expansion, progressively_shortened ← 9772c176

**依赖链**：投射方向决定碰撞点位置与递减填充的展开方向（互为垂直）；投射距离的量化值决定填充的层数上限；两个操作通过"方向正交"和"距离参数化"双重耦合——删掉投射则无起点无方向无层数，删掉递减填充则投射结果无用。

边界标记像素沿行或列投射到中心对象表面，碰撞点处沿垂直方向生长递减填充，填充层数等于投射距离的一半。

**输入结构**：
- 约 17x17 的网格，背景为黑(0)。
- 网格中央偏离中心的位置有一个青(8)色的 4-连通对象（约 10~20 像素，形状圆润，各边的水平和垂直行程连续且至少 3 像素长）。
- 网格的四条边界上分散着 3~5 个单像素标记，颜色各不相同（使用红(2)、绿(3)、黄(4)、灰(5)等），每个标记与中心对象在同一行或同一列上（保证投射能命中对象）。
- 生成约束：标记与对象之间的投射路径上无其他非背景像素；不同标记的投射方向可以相同或不同；标记到对象的距离（中间背景像素数）在 3~8 之间。

**规则**：
1. 对每个边界标记像素，沿其所在行（若标记在左边界或右边界）或列（若标记在上边界或下边界）向网格内部投射，直到遇到青(8)对象的第一个像素，记为碰撞点。
2. 记录投射距离 D = 标记与碰撞点之间的背景像素数（不含标记自身和碰撞点自身）。
3. 确定递减填充方向：水平投射的标记（在左/右边界）→ 填充沿垂直方向（碰撞点的上下两侧）；垂直投射的标记（在上/下边界）→ 填充沿水平方向（碰撞点的左右两侧）。
4. 从碰撞点出发，沿填充方向绘制递减行程。第一层行程长度 = 碰撞点所在行（或列）上，青(8)对象在该行（或列）的连续像素段长度。每向外一步，行程缩短 2 像素（两端各缩 1 像素），直到行程缩至 0 或已绘制 floor(D/2) 层为止（取较先满足的条件）。
5. 递减填充像素使用该标记的颜色，仅绘制在黑(0)背景上。不覆盖青(8)对象像素和其他标记像素。
6. 若两个标记的递减填充区域重叠，投射距离较大的标记覆盖投射距离较小的标记的填充（远处标记优先）。若距离相同，标记在网格边界上位置靠左上者（按从上到下、从左到右的扫描序）优先。
7. 青(8)对象和所有边界标记像素在输出中保持不变。

**关键洞察**：投射距离同时编码了"填充从哪里开始"和"填充延伸多远"——需要对比多个示例中不同距离标记产生的不同层数，才能归纳出 floor(D/2) 这个半数关系；仅看单个标记的填充无法确定层数公式。

## 新题 3：压缩归一化匹配分组与多数表决涂色

**组合逻辑**：[compress/压缩](消除行列拉伸) → [shape_match/形状匹配 + rotation_reflection_eq/旋转反射等价](分组) → [counting + majority_vote/计数与多数投票](组内定色) → [recolor/重涂色 + erase/擦除](统一涂色与孤立擦除)

**来源原语**：compress, adjacent_identical, merge_identical ← ce8d95cc；shape_match, candidate_object, prototype_object, rotation_reflection_eq, run_length_compare ← bd14c3bf；counting, majority_vote ← 27a77e38；recolor ← aabf363d；erase ← e4941b18

**依赖链**：压缩消除尺寸差异是匹配的前提→匹配建立分组是投票的前提→投票定色是重涂的前提→组大小 =1 触发擦除（匹配失败的后果）。四步链中每一步的输出都实质改变下一步的输入空间。

将拉伸变形的对象压缩后按旋转/反射等价分组，每组用多数表决色统一涂色，无法归组的孤立对象被擦除。

**输入结构**：
- 约 20x20 的网格，背景为黑(0)。
- 5~8 个互不相邻的 4-连通单色对象，每个对象 6~20 像素，对象之间至少间隔 2 个背景像素。
- 对象颜色使用 3~4 种（如蓝(1)、红(2)、绿(3)、黄(4)），同色对象可能形状不同，不同色对象可能形状相同。
- 部分对象是同一基础形状的拉伸版本：某些行或列被连续重复了 1~3 次（如一个 3x3 的基础形状可能被拉伸为 3x5 或 5x3）。部分对象在拉伸基础上还做了 90/180/270 度旋转或水平/垂直翻转。
- 恰好有 1~2 个对象的基础形状与所有其他对象都不匹配（孤立对象）。
- 生成约束：每个匹配组至少含 2 个对象；组内至少有一种颜色出现次数严格多于其他颜色（确保多数投票结果唯一）。

**规则**：
1. 裁剪每个对象到其边界框。
2. 对每个裁剪结果执行行列压缩：从上到下逐行扫描，若当前行的像素模式与前一行完全相同则删除当前行；再从左到右逐列扫描，若当前列的像素模式与前一列完全相同则删除当前列。得到每个对象的"压缩掩码"。
3. 对所有对象的压缩掩码进行两两形状匹配：两个掩码在 0/90/180/270 度旋转或水平/垂直翻转后若完全相同，则属于同一组。传递性生效（A 匹配 B、B 匹配 C 则 A、B、C 同组）。
4. 对每个包含 2 个及以上成员的组，统计组内各颜色拥有的对象数量，出现次数最多的颜色为该组的"统一色"。
5. 将组内所有对象的像素重涂为该组的统一色（保持每个对象的形状、位置和拉伸状态不变，仅改变颜色）。
6. 组大小为 1 的孤立对象的所有像素擦除为黑(0)背景。

**关键洞察**：行列压缩消除了拉伸造成的尺寸差异，使得外观完全不同的大小对象实际上是同一基础形状的变体；孤立对象的消失是匹配失败的结果，需要对比多个示例才能确定"不匹配就擦除"这一规则（而非"保持原样"）。

## 新题 4：象限格点补全与跨轴颜色继承镜像

**组合逻辑**：[completion/补全](左上象限内缺位填充) → [reflect/镜像](跨框架线对称到其余象限) + [recolor/重涂色](镜像体经另一条轴的对称关系间接继承颜色，创新：跨象限颜色传递链)

**来源原语**：completion, identical_sprite, row_column_lattice, lattice_alignment, cartesian_product_gap_fill ← 5b526a93；reflect, crop, frame_line, inner_pattern, symmetry_axis, frame_as_axis ← f8a8fe49；recolor ← bda2d7a6

**依赖链**：缺位补全确定完整格点布局→镜像将布局扩展到四个象限→镜像体的颜色取决于"另一条轴对称位"是否有原始精灵——补全与镜像的结果共同决定颜色。删掉补全则镜像不完整，删掉镜像则无需颜色继承，删掉颜色继承则镜像体全为单色。

先在一个象限内补全精灵格点阵列，再将完整阵列镜像到其余象限，镜像精灵的颜色通过另一条对称轴的间接映射继承自原始精灵。

**输入结构**：
- 约 19x19 的网格（奇数边长），背景为黑(0)。
- 正中央一行和正中央一列为红(2)框架线，将网格分为四个象限（左上、右上、左下、右下）。
- 左上象限内有一个不完整的精灵格点阵列：若干个形状相同的小精灵（4-连通，3~5 像素）排列在规则的行列格点上，但部分格点位置为空。精灵使用 2~3 种颜色（蓝(1)、绿(3)、黄(4)），不同位置的精灵颜色不同。
- 其余三个象限为空（仅黑色背景）。
- 生成约束：左上象限的格点阵列至少有一完整行和一完整列（可推断完整格点）；缺失格点不超过总格点数的一半；每种颜色的精灵至少出现 2 个；精灵不接触框架线（与框架线之间至少有 1 像素间距）。

**规则**：
1. 在左上象限中，识别精灵的通用掩码形状和格点间距（行间距和列间距）。
2. 根据已有精灵的行起始位置集合和列起始位置集合推断完整的格点阵列，在每个空缺格点处填入青(8)色的精灵副本（掩码相同、颜色为青(8)）。
3. 将补全后的左上象限沿垂直框架线水平镜像到右上象限，沿水平框架线垂直镜像到左下象限，同时沿两条框架线做中心镜像到右下象限。镜像时精灵的掩码形状也做对应翻转。
4. 镜像精灵的颜色确定规则：对于右上象限中的每个镜像精灵位置 P，找到 P 关于水平框架线的对称位置 P'（位于左下象限）。若左上象限中与 P' 水平对称的位置存在原始精灵（非青(8)补全），则 P 处的镜像精灵继承该原始精灵的颜色；否则使用青(8)。对左下象限和右下象限类似处理——左下精灵查找右上象限的对称位，右下精灵查找左上象限对角对称位。
5. 框架线像素在输出中保持红(2)不变。精灵若延伸到框架线位置则裁剪掉（不绘制在框架线上）。

**关键洞察**：补全必须在镜像之前完成（否则缺位会导致镜像结果不完整）；镜像精灵的颜色不是简单继承其在源象限的对称位颜色，而是通过另一条框架线的间接映射获取——这形成一条跨象限的颜色传递链，需要对比多个示例追踪不同位置精灵的颜色来源才能归纳此规则。

## 新题 5：逐色对称去噪揭示拓扑后差异化描边

**组合逻辑**：[symmetry_completion → erase/对称去噪](逐色层独立去噪，创新：去噪改变连通拓扑) → [outline/描边](对去噪后的形状做内外边界差异化标注，描边对象由去噪结果决定)

**来源原语**：symmetry_completion, color_layer, symmetry_axis, per_color_processing, ignore_distractors ← 8e5c0c38；outline, connected_component, hole, inner_outer_bound, boundary_diff_color ← d931c21c；erase ← aabf363d

**依赖链**：逐色对称去噪改变连通结构（噪声可能封堵孔洞或连接分量）→去噪后的拓扑决定哪些分量包含孔洞→仅含孔洞的分量被描边。直接对原图描边会得到错误结果——去噪是描边的必要前置步骤，且去噪的具体效果（打开孔洞或断裂分量）不可预知，必须实际执行。

先对每个颜色层独立执行垂直对称去噪，去噪改变对象的连通性和孔洞结构，再对去噪后的形状做内外边界差异化描边。

**输入结构**：
- 约 15x17 的网格，背景为黑(0)。
- 2~3 种非背景颜色（如蓝(1)、红(2)、绿(3)），每种颜色的像素形成一个近似垂直对称的图案（每种颜色有其独立的对称轴列位置）。
- 每个颜色层中有 2~4 个"噪声"像素破坏对称性。关键特征：某些噪声像素恰好填在了该颜色图案的孔洞边缘（去除后会打开一个新孔洞），或连接了本应分离的两个连通分量（去除后会断裂为两个分量）。
- 生成约束：每种颜色的对称轴位置互不相同；去噪后至少有一种颜色的拓扑结构发生变化（出现新孔洞或分量断裂）；去噪后至少有一个含孔洞的连通分量和一个不含孔洞的连通分量。

**规则**：
1. 对每种非背景颜色独立处理：找到使该颜色像素关于此轴的对称匹配数最多的垂直列位置作为该颜色的对称轴。
2. 删除每种颜色中没有同色镜像对应像素的"噪声"像素（将其设为黑(0)背景）。对称轴上的像素若在轴上无同色像素则也删除。
3. 在去噪后的网格上，识别所有非背景色的 4-连通分量。
4. 对每个包含孔洞的连通分量执行描边（孔洞定义：被该分量完全包围的、不接触网格边界的 4-连通黑(0)区域）：
   - 外侧边界描灰(5)：该分量像素的 8-邻域中属于外部背景（可达网格边界的黑(0)区域）的像素涂灰(5)。
   - 内侧边界描黄(4)：该分量像素的 8-邻域中属于孔洞的像素涂黄(4)。
5. 不包含孔洞的连通分量不描边，保持原色不变。
6. 灰(5)和黄(4)仅绘制在黑(0)背景像素上，不覆盖任何非背景色像素。若一个背景像素同时是某分量的外侧边界和另一分量的内侧边界，黄(4)优先。

**关键洞察**：去噪不仅是清洁步骤——它会打开原先被噪声封堵的孔洞或断裂连通分量，从根本上改变哪些区域需要描边以及描边的形状；仅看原始输入中的噪声位置无法预测去噪后的拓扑变化。

## 新题 6：最小间距连线与距离参数化径向涂色

**组合逻辑**：[connect/连线 + min_gap_triggered/最小间距触发](连接最近标记对) → [counting/计数](量化间距 G) → [recolor/重涂色](G 作为其余标记的涂色半径) + [erase/擦除](引导像素转色后消失)

**来源原语**：connect, mirrored_marker_pair, gap_segment, center_axis_symmetry, min_gap_triggered ← 5ad8a7c0；counting ← 27a77e38；recolor, erase ← aabf363d, e4941b18；guide_pixel, corner_positioning, corner_color_transfer_vanish ← aabf363d

**依赖链**：最小间距识别→连线填充 + 间距值 G 提取→G 作为其余标记对的涂色半径参数→角落引导像素决定涂色目标色并自身消失。间距值同时充当连线触发条件和径向涂色的范围参数——这是跨操作的数值传递。

连接间距最小的镜像标记对，然后用该间距值作为半径，将其余标记对周围的背景像素涂成角落引导像素指定的颜色。

**输入结构**：
- 约 13x13 的网格，背景为黑(0)，前景标记颜色为蓝(1)。
- 4~6 行各含两个蓝(1)像素，关于网格垂直中轴对称。各行的两个标记之间的水平间距（两标记之间的背景像素数）各不相同，且恰好有唯一一对间距最小。
- 网格左下角（最后一行第一列）有一个单独的引导像素，颜色为红(2)。
- 生成约束：最小间距 G 在 1~3 之间；各对间距互不相同；引导像素不在任何标记对所在行上；标记对所在行互不相邻（行间至少间隔一行）。

**规则**：
1. 在所有含对称标记对的行中，找到水平间距最小的那对。设其间距为 G（两标记之间有 G 个背景像素）。
2. 将该最小间距对之间的 G 个背景像素填充为蓝(1)，形成水平连线。
3. 读取左下角引导像素的颜色 C（本题为红(2)），然后将引导像素擦除为黑(0)。
4. 对其余每对未连线的对称标记：以每个标记像素为中心，将曼哈顿距离 <= G 范围内的所有黑(0)背景像素涂为颜色 C。
5. 涂色不覆盖蓝(1)前景像素和连线像素。不同标记的涂色范围若重叠，颜色相同，无冲突。
6. 被连线行的两个标记保持蓝(1)不变。其余行的标记像素也保持蓝(1)不变。

**关键洞察**：最小间距值 G 同时充当连线的触发条件和其余标记涂色范围的半径参数——这是一个跨操作的数值传递；需要对比多个示例中不同 G 值产生的不同涂色范围才能归纳出半径等于间距这一关系。

## 新题 7：射线分区内贪心选方着色

**组合逻辑**：[ray_extend/射线延伸](标记发射射线，创新：射线同时充当分区墙壁和颜色源) → [greedy_selection/贪心选择](每个分区内提取最大不重叠正方形) → [recolor/重涂色](正方形颜色由最近墙壁颜色决定)

**来源原语**：ray_extend ← c92b942c；greedy_selection, blank_square_region, obstacle_pixel, largest_first_priority, non_overlapping_constraint, minimum_side_length_constraint ← 31adaf00；recolor ← bda2d7a6；marker_pixel ← e4941b18

**依赖链**：射线延伸创建墙壁结构→墙壁定义分区边界→每个分区内独立执行贪心正方形提取→正方形颜色由最近墙壁颜色决定。射线同时提供空间结构和颜色信息——改变标记位置会同时改变分区形状和颜色分配。

标记像素向四方发射射线形成彩色墙壁，将网格分割成若干区域，在每个区域内贪心提取最大不重叠黑色正方形并涂上最近墙壁的颜色。

**输入结构**：
- 约 19x19 的网格，背景为黑(0)。
- 2~3 个单像素标记，颜色各不相同（如红(2)、绿(3)、蓝(1)），位于网格内部（不在边界行/列上），且互不在同行或同列。
- 生成约束：标记位置使得射线将网格分割成至少 4 个不同大小的矩形分区；每个分区面积至少 4（能容纳一个 2x2 正方形）；标记之间水平和垂直距离均 >= 4。

**规则**：
1. 按标记在网格中从左上到右下的扫描顺序（先按行从上到下，同行按列从左到右）依次处理每个标记。
2. 从每个标记出发，沿上、下、左、右四个方向延伸射线直到网格边界。射线像素（不含标记自身和边界像素）涂为该标记的颜色。若射线经过另一个标记的已有射线像素，当前标记颜色覆盖之前的颜色。
3. 射线和标记像素共同构成墙壁，将网格分割成若干矩形分区（每个分区是一个四面被墙壁或网格边界围合的矩形黑色区域）。
4. 在每个分区内，枚举所有边长 >= 2 的全黑正方形候选区域。
5. 按正方形边长从大到小排序。依次选取：若当前候选不与已选正方形重叠则选入，否则跳过。同一边长内按正方形左上角从左到右、从上到下的顺序处理。
6. 对每个选出的正方形，找到其边界框四边上距离最近的墙壁像素（若有多个等距的，选扫描序最先的那个），将该正方形所有像素涂为该墙壁像素的颜色。此处"距离"指正方形边界框边缘像素到最近墙壁像素的切比雪夫距离（棋盘距离）。
7. 射线和标记像素在输出中保持不变。未被选中的黑色区域保持黑(0)。

**关键洞察**：射线承担双重角色——作为空间分割的墙壁定义分区边界，同时作为颜色源为分区内的正方形提供涂色依据；改变任意一个标记的位置会同时改变所有分区的形状、大小和可用颜色。

## 新题 8：封闭区域总数编码区内螺旋臂数

**组合逻辑**：[flood_fill/洪泛填充](识别封闭区域集合) → [counting/计数](统计封闭区域总数 N，创新：全局计数参数化局部操作) → [spiral_drawing/螺旋绘制](每个封闭区域中心画螺旋，臂数 = 2N) + [boundary_clipping/边界裁剪](螺旋被裁剪在各自封闭区域内)

**来源原语**：flood_fill, enclosed_region, wall_segment, region_enclosure, unreachable_background_filled ← a5313dff；spiral_drawing, origin_positioning, boundary_clipping ← 8b28cd80；counting, partition_sets_size ← 1190e5a7

**依赖链**：洪泛填充确定封闭区域集合→区域数量 N 决定每个螺旋的臂数 2N（全局→局部参数传递）→每个区域中心起画螺旋→螺旋被裁剪在各自区域内。增减一个封闭区域会改变所有螺旋的长度——各区域通过全局计数隐式耦合。

识别被红色墙壁围成的封闭区域，在每个区域的质心处画正方形螺旋，螺旋的展开臂数由封闭区域的总数决定，超出区域边界的部分被裁剪。

**输入结构**：
- 约 21x21 的网格，背景为黑(0)。
- 红(2)色像素形成单像素厚的墙壁线段。墙壁之间或墙壁与网格边界围成若干封闭区域和非封闭区域。
- 封闭区域：4-连通的黑(0)背景像素集合，不能通过黑(0)像素路径到达网格边界。
- 封闭区域形状大致为矩形或不规则多边形，面积在 9~50 像素之间。
- 存在若干非封闭的背景区域（可达网格边界），不参与变换。
- 生成约束：封闭区域数量在 2~5 个之间；每个封闭区域的最短内径（内部最窄处的连续背景像素数）至少 3 像素；不同封闭区域之间至少隔 1 个墙壁像素。

**规则**：
1. 从网格四周边界出发，对黑(0)像素做 4-邻域洪泛填充，标记所有从边界可达的背景像素为"外部"。红(2)像素视为墙壁，不可通过。
2. 未被标记的黑(0)像素按 4-连通性分组，每组构成一个封闭区域。统计封闭区域总数 N。
3. 对每个封闭区域，计算其质心：所有区域内像素的行坐标平均值（四舍五入到最近整数）和列坐标平均值（四舍五入到最近整数）。若质心位置落在墙壁上或区域外部，将其调整为区域内曼哈顿距离最近的像素（若有多个等距的，取扫描序最先的）。
4. 从质心出发，按上→右→下→左的方向顺序绘制正方形螺旋。臂长序列为 1, 1, 2, 2, 3, 3, ...（第 k 条臂长度为 ceil(k/2)）。螺旋共绘制 2N 条臂。
5. 螺旋像素涂为蓝(1)色，但仅绘制落在该封闭区域内部的黑(0)像素上。落在墙壁上、其他区域内或外部背景中的螺旋像素不绘制（裁剪）。
6. 红(2)墙壁像素和外部背景在输出中保持不变。质心位置也涂为蓝(1)。

**关键洞察**：每个封闭区域的螺旋展开程度取决于所有封闭区域的总数 N——增加或减少一个封闭区域会改变全部螺旋的长度；这个全局参数到局部操作的隐式传递需要对比不同示例（封闭区域数量不同的情况）才能发现。
