## 新题 1：互补形状射线对接

**组合逻辑**：[形状匹配 shape_match](已有) + [对接/射线延伸 dock/ray_extend](已有) + [擦除 erase](已有) —— 创新点在于：形状互补逻辑决定"去哪"，射线对接机制决定"怎么去"，两个本属不同源题的操作在目标选择与路径规划两层紧耦合

**来源原语**：shape_match / complementary_shape / unique_complement（参考题 18447a8d）；dock / ray_extend / interior_socket / ray_inferred_direction / trail_painted_black（参考题 8b9c3697）；erase（多题共用）

**依赖链**：需先分析每个结构体内部槽位的形状轮廓 → 将每个可移动组件归一化后与所有槽位做互补匹配，找到唯一配对 → 从匹配到的槽位向外射线扫描确定对接方向 → 沿该方向滑入组件，路径涂黑 → 擦除原位置。删除形状匹配则不知道组件去哪个槽位；删除射线对接则不知道滑入方向；两者缺一不可。

将散布在结构体外部的小色块，按形状互补匹配到唯一对应的内部空腔，再沿射线方向滑入空腔并留下黑色轨迹。

**输入结构**：黑(0)背景，约 20x20。网格中有 2-4 个大型单色结构体（如蓝(1)），每个结构体为不规则的 4-连通多像素区域（15-30 像素），内部各有一个形状各异的空腔（空腔为结构体边界框内、被结构体像素 4-邻接包围的背景区域，3-6 像素）。结构体之间互不接触，边界框不重叠。网格中另有 2-4 个小型可移动组件（各为不同颜色的 4-连通单色区域，3-6 像素），散布在结构体外部。每个可移动组件的归一化形状恰好是某个空腔归一化缺口形状的精确互补（即组件形状 + 缺口形状 = 完整矩形），且配对唯一。生成约束：每个组件与其目标结构体之间有一条无障碍的水平或垂直通路（不穿过其他结构体或组件）。

**规则**：
1. 对每个结构体，提取其内部空腔：空腔 = 结构体边界框内、从边界框边缘出发不穿越结构体像素无法到达的背景像素集合。将空腔像素相对于空腔边界框左上角归一化得到缺口形状。
2. 对每个可移动组件，将其像素相对于自身边界框左上角归一化。在所有缺口形状中找到唯一的互补配对：组件形状与缺口形状叠加后恰好填满一个矩形，且配对唯一。
3. 确定对接方向：从匹配到的空腔中每个像素向上/下/左/右四个方向射线扫描，穿透结构体壁后继续延伸到网格边缘或遇到其他结构体停止。选择射线首先命中对应可移动组件的那个方向作为对接方向。
4. 将可移动组件沿对接方向的反方向平移，直到组件像素恰好填入空腔（组件的互补位置对齐空腔的缺口像素）。组件在滑动路径上经过的所有背景像素涂为黑(0)（轨迹标记；由于背景本身为黑(0)，轨迹实际表现为：若路径经过的像素原本是结构体壁的颜色，则该壁像素保持不变——轨迹只涂背景格）。
5. 擦除组件原始位置的所有像素（设为黑(0)）。组件在空腔内保留其原始颜色。结构体颜色不变。

**关键洞察**：形状互补匹配（来自参考题 18447a8d 的逻辑）决定每个组件的目标槽位，但对接的物理路径由射线扫描方向（来自参考题 8b9c3697 的逻辑）决定——两个操作分别负责"选目标"和"定路径"，在源题中各自独立，在此题中形成不可拆分的推理链。

## 新题 2：主干屏障下的面积重力

**组合逻辑**：[平移 translate](已有) + [画线 draw_line](已有) + [计数 count](创新：计数结果作为位移量但被屏障截断) —— 创新点在于：主干线段不再是"连接控制像素的装饰"而是"阻挡位移的物理屏障"，位移量与屏障位置共同决定落点

**来源原语**：translate / shift_equals_area / foreground_object（参考题 b2bc3ffd）；draw_line / spine_segment / connect_to_spine / shared_row_col_spine / control_pixel（参考题 bf89d739）；erase（多题共用）

**依赖链**：需先识别红(2)控制像素中的共行对 → 画出水平主干及垂直连接线（绿(3)屏障网络）→ 对每个非红色对象计数像素得到位移量 N → 对象向下平移 min(N, 到最近绿色屏障线的垂直距离 - 1) 格 → 擦除原位置。删除主干识别则无屏障，对象会穿过去；删除计数则不知位移量。

将散布的彩色对象按各自像素数向下坠落，但由红色控制像素构成的绿色主干网络充当物理屏障，截停过远的坠落。

**输入结构**：黑(0)背景，约 18x18。网格上半区有 3-5 个小型 4-连通单色对象（颜色各异，非红(2)非绿(3)，每个 2-6 像素）。网格中部偏下区域有若干红(2)像素（4-7 个）：其中恰好有一对红像素共享同一行（水平对齐），其余红像素的列坐标均落在该对所跨的列范围内。红像素之间不 4-邻接。生成约束：每个彩色对象的正下方最终会遇到主干网络或网格底边；不同对象的水平范围互不重叠，因此不会互相阻挡。

**规则**：
1. 识别主干：在所有红(2)像素中，找到共享同一行的唯一一对，该对之间（不含端点）的背景像素涂为绿(3)，形成水平主干线段。红端点保持红色。
2. 对每个不在主干行上的红像素，从该像素沿垂直方向画一条绿(3)线段连接到主干行（不含红端点本身和主干行交汇处已有的绿像素；若主干是水平的则垂直连接，反之亦然）。红端点保持红色。
3. 对每个非红、非绿的 4-连通单色对象，计算其像素数 N。
4. 将该对象整体向下平移。目标位移量为 N 格。但若对象在下移过程中其任一像素会到达或越过某条绿(3)屏障线段所在的行，则对象停在该屏障行的上方一格（对象底边的最低像素到达屏障行 - 1）。若对象下方无屏障，则位移量为 min(N, 对象底边到网格底边的距离)。
5. 擦除对象原始位置的像素（设为黑(0)）。对象在新位置保留原色。
6. 主干网络（绿线段 + 红端点）保持不变。

**关键洞察**：像素数决定了每个对象"想要"下落多远（来自参考题 b2bc3ffd 的面积=位移逻辑），但主干网络（来自参考题 bf89d739 的脊线构造逻辑）充当物理天花板——求解者必须先构造完整的屏障网络，才能判断每个对象的实际落点。两个来自不同源题的机制在"位移截断"处紧耦合。

## 新题 3：对称性决定洪泛填充色

**组合逻辑**：[镜像 mirror](创新：从操作降级为几何测试条件) + [洪泛填充 flood_fill](已有) + [擦除 erase](已有) —— 创新点在于：镜像不执行变换，而是作为条件判断节点，其结果分支到不同的填充色选择逻辑

**来源原语**：mirror / column_reversal（参考题 67a3c6ac，此处创新为对称性测试而非实际翻转操作）；flood_fill / outline_frame / enclosed_region / marker_in_enclosed_region / majority_color_fill（参考题 4b6b68e5）；erase（多题共用）

**依赖链**：对每个封闭轮廓 → 检测轮廓是否水平对称（镜像测试）→ 对称则取内部多数标记色填充，不对称则取少数标记色填充 → 擦除所有标记像素。删除对称性测试则无法区分两种填充策略；删除填充则无输出。

对灰色封闭轮廓内部进行洪泛填充，填充颜色取决于轮廓形状是否左右对称：对称用多数标记色，不对称用少数标记色。

**输入结构**：黑(0)背景，约 16x16。网格中有 3-5 个灰(5)的 4-连通封闭轮廓（每个轮廓为单像素宽的闭合边界，围成一个内部区域；轮廓形状各异，部分左右对称、部分不对称；每个轮廓 12-24 像素）。轮廓之间互不接触，边界框不重叠。每个轮廓内部有 2-3 个孤立标记像素，颜色取自红(2)、蓝(1)、绿(3)、黄(4)，且每个封闭区域内至少有两种不同颜色的标记，其中一种颜色的标记数量严格多于另一种（无平局）。轮廓外部不存在标记像素。生成约束：对称轮廓和不对称轮廓各至少有一个，以保证两种规则都可观察。

**规则**：
1. 保持所有灰(5)轮廓像素不变。
2. 对每个封闭轮廓，判断其形状是否具有水平对称性：将轮廓像素集合沿其边界框的垂直中轴做左右镜像，若镜像后的像素集合与原始集合完全重合，则判定为"对称"，否则为"不对称"。
3. 统计该封闭区域内部各颜色标记像素的数量。多数色 = 数量最多的标记颜色；少数色 = 数量最少的标记颜色。
4. 若轮廓对称：将封闭区域内所有非轮廓像素填充为多数色。若轮廓不对称：填充为少数色。
5. 擦除所有标记像素（它们被填充色覆盖或位于填充区域内，直接被新颜色替换）。

**关键洞察**：镜像操作在源题（67a3c6ac）中是对整幅画布执行的变换，但在此题中被创新为一个**几何测试条件**——它不改变任何像素，仅判断轮廓的对称性，然后将判断结果作为分支条件输入到填充色选择中。仅看单个示例可能以为所有轮廓都用同一种策略填充，需对比多个示例（含对称和不对称轮廓）才能归纳出分支规则。

## 新题 4：像素计数排序的印章叠放

**组合逻辑**：[印章覆盖 stamp](已有) + [计数 count](已有) + [排序 sort](已有) + [擦除 erase](已有) —— 创新点在于：精灵体的像素计数决定印章顺序，印章顺序决定重叠优先级，三层逻辑在"谁压在谁上面"这一视觉结果处耦合

**来源原语**：stamp / sprite / anchor_marker / same_color_match / anchor_positions_copy / ignore_distractors（参考题 1b59e163）；count / sort / connected_component / fixed_color_order（参考题 aaecdb9a，此处 fixed_color_order 被创新为由计数动态决定的排序）

**依赖链**：识别每个精灵体的锚色和体色 → 计数体像素 → 按像素数升序排列得到印章顺序 → 清空画布 → 按排序顺序依次将精灵体印到同锚色的单像素标记位置 → 后印的覆盖先印的。删除计数/排序则无法确定叠放顺序；删除印章则无输出；删除锚色匹配则不知印在哪里。

将多个精灵体按像素数从小到大排序，依次印章到同色锚点位置，后印的覆盖先印的，形成尺寸决定的叠放优先级。

**输入结构**：黑(0)背景，约 18x18。网格中有 3-4 个 8-连通精灵体，每个精灵体由单色体像素（3-8 个像素，颜色各异，互不相同）加上恰好 1 个不同颜色的锚点像素组成（锚点与体像素 8-邻接）。每个精灵体的锚色互不相同，且锚色不与任何精灵体的体色冲突。网格中还散布若干孤立单像素标记，颜色与某个锚色相同；每种锚色对应 1-3 个单像素标记。可能存在少量干扰标记（其颜色不匹配任何锚色），散布在网格中。生成约束：不同精灵体的像素数两两不同（保证排序无平局）；各单像素标记的位置保证以锚点为对齐点印章后，精灵体不越出网格边界；至少有一对标记位置使得两个不同精灵体的印章区域部分重叠。

**规则**：
1. 识别所有精灵体：每个 8-连通前景分量中恰好包含两种颜色，像素数较多的颜色为体色，像素数为 1 的另一颜色为锚色。记录体色、锚色、体像素数、以及精灵体中每个像素相对于锚点像素的偏移。
2. 按体像素数升序排列所有精灵体，得到印章顺序（像素最少的最先印）。
3. 清空整个网格为黑(0)背景。
4. 按印章顺序依次处理每个精灵体：在网格中找到所有与该精灵体锚色相同的孤立单像素标记位置。对每个标记位置，以该位置为锚点，按偏移量将精灵体的体色像素写入网格（锚点位置本身也写为体色）。若写入位置已有非背景像素（来自先前印章），直接覆盖。
5. 颜色不匹配任何锚色的孤立标记（干扰项）不参与任何印章，最终在输出中不出现。

**关键洞察**：精灵体的物理大小（像素数）不仅是几何属性，更是决定叠放层级的隐式编码——小精灵先印、大精灵后印，因此大精灵总是压在小精灵上面。求解者需从多个示例的重叠区域推断出"尺寸=优先级"这一非显然规则，而非依赖颜色编号或空间位置。

## 新题 5：嵌套深度柱状图

**组合逻辑**：[计数 count](创新：计数对象为嵌套层数而非连通分量个数) + [排序 sort](创新：排序依据为空间位置而非固定色序) + [画布生成 canvas_generation](已有) —— 创新点在于：被计数的"量"是结构嵌套深度（来自参考题 bd5af378 的嵌套层概念），但输出形式是柱状图（来自参考题 aaecdb9a），两者在源题中各有不同用途

**来源原语**：count / histogram / baseline_aligned（参考题 aaecdb9a）；nested_layer / corner_frame（参考题 bd5af378）；sort（参考题 aaecdb9a，此处排序键改为空间位置）；canvas_generation（参考题 c1990cce）

**依赖链**：识别各空间分离的嵌套组 → 对每组计数嵌套深度并记录最外层颜色 → 按组的水平中心位置从左到右排序得到柱序 → 生成柱状图画布，每列用对应组的最外层颜色从底部向上填充对应深度。删除嵌套分析则无法获得深度值；删除排序则柱序不确定；删除柱状图生成则无输出。

将多组嵌套矩形框的嵌套层数转化为柱状图，柱的颜色取最外层框色，柱的排列顺序由各组的水平位置决定。

**输入结构**：黑(0)背景，约 20x20。网格中有 3-5 个空间分离的"嵌套组"，每组由 1-4 层同心矩形边框嵌套而成（最外层为单像素宽矩形边框，内层逐层缩小，最内层为实心小矩形填充）。同一组内每层颜色不同，取自红(2)、蓝(1)、绿(3)、黄(4)、灰(5)、品红(6)、橙(7)等。不同组的最外层颜色互不相同。各组边界框互不重叠，水平中心位置两两不同。生成约束：至少有两组的嵌套深度不同，以便求解者区分"深度"和"固定常数"。

**规则**：
1. 识别每个嵌套组：找到所有 4-连通非背景区域的外轮廓，若一个轮廓完全在另一个轮廓内部，则它们属于同一嵌套组。每组的嵌套深度 = 该组包含的同心层数（包括最内层实心矩形，算作第 1 层；每增加一层外框加 1）。
2. 记录每组最外层边框的颜色作为该组的代表色。
3. 计算每组边界框的水平中心列坐标，按此从左到右排序，得到柱状图的列顺序。
4. 生成输出画布：宽度 = 嵌套组数量，高度 = 所有组中最大嵌套深度。背景为黑(0)。
5. 对第 k 列（对应排序后第 k 个组），从画布底行开始向上连续填充该组代表色，填充行数 = 该组的嵌套深度。其余格保持黑(0)。

**关键洞察**：在源题 aaecdb9a 中，柱状图的高度编码的是同色连通分量的**个数**；而此题中被计数的"量"是嵌套结构的**层数**——一个全新的几何属性。求解者可能最初误以为柱高编码的是像素数或颜色种类数，需对比多个嵌套深度不同的组才能发现"深度=柱高"的映射。列的排序依据（水平位置）也需要多示例对比才能确认，因为单个示例中可能恰好与颜色编号顺序重合。

## 新题 6：最小生成树遍历序驱动的对角格点相位

**组合逻辑**：[连接 connect](已有) + [循环填充 periodic_fill](创新：周期相位由遍历序而非固定参数决定) + [填充 fill](已有) —— 创新点在于：MST 的拓扑遍历顺序编码了每个房间内对角格点图案的相位偏移，使得物理连通性与视觉图案产生结构性关联

**来源原语**：connect / hollow_rectangle / corridor / shortest_gap / min_spanning_tree / overlap_corridor_width（参考题 b9630600）；periodic_fill / diagonal_lattice / periodic_phase_align（参考题 c1990cce）；fill / marker_pixel（参考题 4b6b68e5 / e9c9d9a1）

**依赖链**：识别所有空心矩形框 → 计算可见间距并构建 MST → 画走廊连接 → 从最大框 BFS 遍历 MST 确定每框的访问序号 → 每框内部绘制对角格点，相位 = 访问序号 mod 4 → 格点颜色取该框内部标记像素的颜色。删除 MST 构建则无法确定遍历序，进而无法确定相位；删除格点填充则无视觉输出；删除标记色则格点无颜色。

将通过走廊连接的空心矩形房间内部填充对角格点图案，格点的相位偏移由房间在最小生成树中的广度优先遍历顺序决定，格点颜色由房间内标记像素指定。

**输入结构**：黑(0)背景，约 22x22。网格中有 4-6 个绿(3)单像素宽空心矩形框，大小各异（内部面积从 3x3 到 7x7 不等），边界框互不重叠。每个矩形内部恰有 1 个孤立标记像素（颜色取自红(2)、蓝(1)、黄(4)、品红(6)、橙(7)，各框标记色互不相同）。矩形之间存在可见的水平或垂直间距（两框之间无障碍的背景通道，且两框的内部在垂直或水平方向有重叠范围）。生成约束：任意两个矩形之间至多有一条可见间距路径；所有矩形通过可见间距形成连通图；最大内部面积的矩形唯一。

**规则**：
1. 对所有绿(3)空心矩形框，计算每对之间的可见间距长度（两框面对的壁之间的背景像素列数或行数）。仅考虑水平或垂直方向、且两框内部在垂直或水平方向有重叠范围的框对。
2. 选择最小生成树（MST）：在所有可见间距中选择总长度最小的子集，使所有框连通。若总长度相同，选择包含最短单条间距的那棵。
3. 画走廊：对 MST 中每条选中的间距，在两框重叠的内部范围的边界两行（或两列）之间画绿(3)走廊壁，并擦除两框面对的壁上严格位于走廊壁之间的像素（设为黑(0)），形成通道。
4. 以内部面积最大的矩形为根节点，在 MST 上做广度优先遍历（BFS），相同层级内按间距长度升序访问（短间距优先）。根节点的访问序号 = 0，其第一个邻居 = 1，依次递增。
5. 对每个矩形框的内部区域（不含框壁），绘制 NW-SE 方向对角格点：将内部像素 (r, c)（r 为行号、c 为列号）中满足 (r + c) mod 4 == (该框访问序号 mod 4) 的像素涂为该框内部标记像素的颜色。
6. 擦除所有标记像素（被格点颜色覆盖或保持为背景）。走廊内部保持黑(0)。

**关键洞察**：走廊网络不仅是视觉连接——其最小生成树的 BFS 遍历序号直接编码了每个房间内对角格点的相位偏移（mod 4）。改变任何一条走廊的长度可能改变 MST 结构，进而改变所有下游房间的格点相位。这一"拓扑顺序→视觉图案"的映射在任何单一源题中都不存在。

## 新题 7：颜色编码射线与锚块吸收

**组合逻辑**：[射线延伸 ray_extend](已有) + [吸附 snap](创新：吸附目标由射线方向动态确定) + [擦除 erase](已有) —— 创新点在于：颜色编码的射线方向与锚块空间分布共同决定射线终点，且多射线竞争同一锚块表面时需全局冲突解决

**来源原语**：ray_extend / color_determines_motion / trail_segment（参考题 ac605cbb）；snap / anchor_block / outer_frame / nearest_frame_assign / conflict_priority（参考题 1b8318e3）；erase（多题共用）

**依赖链**：识别所有锚块和彩色单像素 → 由颜色确定每个单像素的射线方向 → 射线沿方向延伸直到遇到锚块外框或网格边缘 → 射线终点像素涂为射线源色标记吸收 → 若多条射线终点相同则距离近的胜出 → 擦除源像素。删除颜色→方向映射则射线无方向；删除锚块则射线无终止条件；删除冲突解决则有歧义。

彩色单像素沿颜色编码的方向发射灰色射线，射线被最近的灰色锚块外框捕获并标记；多条射线争夺同一锚块表面格时，距离近者胜。

**输入结构**：黑(0)背景，约 16x18。网格中有 3-5 个灰(5)实心 2x2 锚块，位于网格各处。另有 4-8 个彩色孤立单像素，颜色取自红(2)、蓝(1)、绿(3)三种，分散在锚块之间。生成约束：每个单像素沿其颜色指定的方向（见规则）射线路径上至少存在一个锚块；不同单像素的水平或垂直坐标可以相同（允许射线路径平行但不重合）。

**规则**：
1. 颜色→方向映射：红(2) → 向右，蓝(1) → 向下，绿(3) → 向左。此映射在所有示例中固定不变。
2. 从每个彩色单像素出发，沿其颜色指定的方向逐格延伸。将路径上的每个背景像素涂为灰(5)，形成射线轨迹。射线在遇到第一个灰(5)像素（属于某个锚块的 2x2 区域或该锚块的外框已被先前射线涂灰的格）时停止，停止位置为该灰像素的前一格（射线最后一个灰(5)格）。若射线方向上无锚块，射线延伸到网格边缘最后一格。
3. 射线终点标记：将射线的最末一格（紧邻锚块或网格边缘的那一格）重新涂为该射线源单像素的原始颜色，作为"吸收标记"。
4. 冲突解决：若两条或多条射线的终点恰好是同一格（紧邻同一个锚块的同一面），则只保留源单像素到该格曼哈顿距离最短的那条射线。距离更远的射线整体不画（该源单像素仅被擦除，不留射线和终点标记）。若距离相等，保留行号较小的源单像素的射线（行号也相同则保留列号较小的）。
5. 擦除所有彩色源单像素的原始位置（设为黑(0)）。锚块保持灰(5)不变。

**关键洞察**：射线方向由颜色固定编码（来自参考题 ac605cbb 的逻辑），但射线的终止和标记由锚块的空间位置决定（来自参考题 1b8318e3 的吸附逻辑）。在源题中，颜色编码射线和锚块吸附分属完全不同的场景——此处两者交织为"方向由自身颜色定、终点由外部锚块定"的双重约束。冲突解决规则（距离优先）需从多个示例中归纳。

## 新题 8：MST 遍历序驱动的循环母题填充

**组合逻辑**：[循环填充 cyclic_fill](已有) + [连接 connect](已有) + [擦除 erase](已有) —— 创新点在于：源题中循环填充的起始相位是固定的，此处相位由 MST 遍历顺序动态决定；源题中走廊连接是纯视觉操作，此处走廊的拓扑结构编码了填充参数

**来源原语**：cyclic_fill / marker_column / motif_rows / marker_delimits_motif / repeat_cyclically（参考题 12422b43）；connect / hollow_rectangle / corridor / min_spanning_tree / shortest_gap（参考题 b9630600）；erase（多题共用）

**依赖链**：在源框中通过标记列提取母题 → 构建所有框的 MST 并画走廊 → BFS 遍历 MST 确定每个非源框的访问序号 → 每个非源框内部用母题做循环填充，起始行偏移 = 访问序号 mod 母题高度 → 擦除源框中的母题区域。删除母题提取则无填充内容；删除 MST 遍历则相位不确定；删除走廊构建则视觉输出不完整。

从一个标记框中提取彩色母题，通过 MST 走廊网络将母题循环填入所有连接的房间，每个房间的母题起始行偏移由其在 MST 广度优先遍历中的序号决定。

**输入结构**：黑(0)背景，约 22x22。网格中有 4-6 个蓝(1)单像素宽空心矩形框，大小各异。其中恰好一个框（"源框"）的内部左侧一列有连续的灰(5)像素（从框内顶行到框内底行），灰(5)列右侧相邻列有 2-4 行彩色像素构成母题（每行可含多种非背景非蓝非灰颜色）。其余框（"目标框"）内部为空（全黑(0)）。矩形之间存在可见的水平或垂直间距。生成约束：所有框通过可见间距连通；源框唯一且其内部面积严格最大（保证 BFS 根节点唯一）；母题高度（灰标记覆盖的行数）严格小于所有目标框的内部高度（保证循环填充至少重复一轮）。

**规则**：
1. 识别源框：含有灰(5)标记列的唯一蓝(1)矩形框。提取母题：灰标记列标示的各行中，去掉灰像素后剩余的彩色像素图案。将灰像素设为黑(0)背景。母题为 H 行 x W 列的色块（H = 灰标记列覆盖行数，W = 源框内部宽度 - 1）。
2. 构建 MST：对所有蓝框计算可见间距（水平或垂直方向、内部有重叠范围的框对之间的背景像素距离），选最短总长度生成树使所有框连通。
3. 画走廊：对 MST 中每条边，在两框重叠内部范围的边界两行（或两列）画蓝(1)走廊壁，擦除两框面对壁上走廊壁之间的像素。
4. 以源框为根在 MST 上 BFS 遍历，同层邻居按间距长度升序访问。源框序号 = 0，其第一个邻居 = 1，依次递增。
5. 对每个目标框（序号 k >= 1），从其内部顶行开始，以相位偏移 (k mod H) 为起始行号循环填充母题：第 i 行填充母题的第 ((i + k) mod H) 行图案。填充宽度 = min(目标框内部宽度, W)；若目标框内部宽度 > W，则水平方向也循环。填充高度覆盖整个目标框内部。
6. 源框的母题区域在提取后清空为黑(0)背景（灰标记列已在步骤 1 清除，母题彩色像素也清除）。源框内部最终为全黑。

**关键洞察**：在源题 12422b43 中，循环填充的起始相位始终为 0（从母题第一行开始）。此处每个目标房间的起始相位由 MST 遍历序号动态决定——距离源框越远的房间，母题图案的垂直偏移越大，形成沿拓扑距离"滚动"的视觉效果。走廊网络不仅是几何连接，更是相位传播的拓扑通道。

## 新题 9：网格位置隐式编码平铺参数

**组合逻辑**：[平铺 tiling](已有) + [重涂色 recolor](已有) + [压缩 compress](创新：压缩方向反转——从"大格子压成小摘要"变为"小摘要的位置编码大格子的铺设方式") —— 创新点在于：分隔线网格的结构本身编码了变换参数（母题在网格中的行列位置 = 铺设的行列重复数），这是隐式编码结构，非线性流水线

**来源原语**：tiling / tile / side_len_determines_rep（参考题 ccd554ac，此处"边长"被创新为"网格坐标"）；recolor / marker_pixel / filled_gets_marker（参考题 5ad4f10b）；compress / grid_partitioning（参考题 5ad4f10b，此处方向反转）；separator_grid / grid_cell（参考题 e9c9d9a1）

**依赖链**：识别分隔线网格和各单元格内容 → 定位母题所在单元格的行列坐标 (i, j) → 母题铺设 (i+1) 行 x (j+1) 列 → 标记像素的网格坐标通过取模映射到特定铺设副本 → 对应副本重涂色。删除位置编码则不知铺设次数；删除铺设则无输出；删除标记映射则无法确定重涂色副本。

分隔线网格中某个单元格的彩色图案作为母题，其行列坐标编码平铺的重复次数；其他单元格中的标记像素通过坐标取模指定哪些副本被重涂色。

**输入结构**：黑(0)背景，约 15x15。网格被灰(5)单像素宽分隔线均匀分为 K x K 个等大单元格（K 为 3、4 或 5，各示例可能不同）。恰好一个单元格包含一个小型多像素 8-连通彩色图案（"母题"，3-6 像素，单色，非灰非背景色）。0-3 个其他单元格各包含恰好 1 个孤立彩色标记像素（颜色各异，非灰非背景色，与母题色不同）。其余单元格为空（全黑(0)）。生成约束：母题所在单元格的行列索引 (i, j) 均 >= 1（保证至少铺 2x2）；母题图案的边界框严格小于单元格尺寸（保证铺设时不溢出）。

**规则**：
1. 识别灰(5)分隔线，将网格分解为 K x K 单元格。单元格按 0-索引标记：左上角 = (0, 0)。
2. 找到包含多像素图案的单元格，记其行列索引为 (i, j)。提取母题图案（相对于单元格左上角的像素偏移和颜色）。
3. 生成输出画布（无分隔线）：将母题图案平铺 (i+1) 行 x (j+1) 列，各副本之间无间隔，输出画布大小 = (i+1) x 单元格高度 行, (j+1) x 单元格宽度 列。背景为黑(0)。每个副本在其对应的单元格大小区域内以相同偏移放置母题图案。
4. 对输入中每个含标记像素的单元格，记其行列索引为 (r, c) 和标记颜色。在输出中，将位于第 (r mod (i+1)) 行、第 (c mod (j+1)) 列的那个母题副本的所有前景像素重涂为该标记颜色。
5. 若多个标记映射到同一副本（取模后坐标相同），按标记像素在输入中从左到右、从上到下的扫描顺序，后扫描到的颜色覆盖先前的。
6. 未被任何标记映射到的副本保持母题原始颜色。

**关键洞察**：母题在分隔线网格中的位置不是随意放置——行索引编码垂直重复次数、列索引编码水平重复次数。这是一种**隐式编码**：网格结构本身就是变换指令。在源题 5ad4f10b 中，网格分块的作用是"从大到小压缩"；此处完全反转为"从小位置读取参数然后展开"。标记像素的位置通过取模映射到副本的机制也是非显然的——需要对比多个示例才能归纳。

## 新题 10：对角连线方向编码印章镜像

**组合逻辑**：[对角连线 line_drawing](已有) + [印章覆盖 stamp](已有) + [镜像 mirror](创新：镜像轴由对角线方向动态决定) + [擦除 erase](已有) —— 创新点在于：对角线连接不仅是视觉元素，其方向（NE-SW vs NW-SE）编码了印章操作的镜像参数——一个操作的几何属性成为另一个操作的变换指令

**来源原语**：line_drawing / endpoint_pair / same_color_pairing / diagonal_segment_connect（参考题 1f876c06）；stamp / sprite / anchor_marker / same_color_match / anchor_positions_copy（参考题 1b59e163）；mirror / column_reversal（参考题 67a3c6ac，此处创新为条件性单轴镜像）；erase（多题共用）

**依赖链**：识别精灵体及其锚色 → 找到同锚色的两个目标单像素 → 判断两目标像素之间的对角方向 → 画对角连线 → 在第一个目标位置正向印章 → 在第二个目标位置按对角方向决定的镜像轴印章 → 擦除原始精灵体。删除对角连线则无法确定镜像轴；删除镜像则第二份印章方向错误；删除印章则无输出。

将精灵体印到两个同色目标位置，其中一份正向放置，另一份根据两目标点之间的对角线方向做水平或垂直镜像。

**输入结构**：黑(0)背景，约 18x18。网格中有 2-3 个 8-连通精灵体（每个 4-7 像素，单色体 + 1 个不同色锚点像素；精灵体形状水平不对称，以保证镜像结果可区分）。对每个精灵体的锚色，网格中恰好有 2 个同色孤立单像素作为目标标记。每对目标标记呈严格 45 度对角位置关系（行差绝对值 = 列差绝对值）。生成约束：各精灵体的锚色互不相同；同一精灵体的两个目标标记之间的对角方向在不同示例中可能不同（保证镜像规则可通过多示例归纳）；精灵体印章后不越出网格边界；不同精灵体的印章区域互不重叠。

**规则**：
1. 识别每个精灵体的体色、锚色，以及体像素相对于锚点的偏移向量集合。
2. 对每种锚色，找到网格中 2 个同色孤立目标像素 P1 和 P2。约定 P1 为行号较小的那个（即更靠近顶部的目标点）。
3. 判断 P1 到 P2 的对角方向：若 P2 在 P1 的右下方（行增、列增），则方向为 NW-SE；若 P2 在 P1 的左下方（行增、列减），则方向为 NE-SW。
4. 用灰(5)画出 P1 到 P2 之间的对角线段（包含 P1 和 P2 所在格，但 P1 和 P2 本身保留锚色不被灰色覆盖）。
5. 在 P1 位置正向印章：以 P1 为锚点，按精灵体的原始偏移向量放置体色像素。P1 处像素涂为体色（覆盖锚色标记）。
6. 在 P2 位置镜像印章：
   - 若对角方向为 NW-SE：将精灵体偏移向量做**水平镜像**（列偏移取反，行偏移不变），然后以 P2 为锚点放置。
   - 若对角方向为 NE-SW：将精灵体偏移向量做**垂直镜像**（行偏移取反，列偏移不变），然后以 P2 为锚点放置。
   P2 处像素涂为体色。
7. 擦除所有原始精灵体（体色 + 锚点像素全部设为黑(0)）。灰色对角线段、P1 处正向印章、P2 处镜像印章保留在输出中。
8. 若印章像素与灰色对角线段重叠，印章像素（体色）覆盖灰色。

**关键洞察**：在源题 1f876c06 中，对角线连接同色端点纯粹是"连线"操作；在源题 1b59e163 中，印章在所有目标点处都是原样复制。此题中，对角线的方向成为一条**变换指令**：NW-SE 对角线命令目标端做水平镜像，NE-SW 对角线命令做垂直镜像。连线操作和印章操作通过"方向→镜像轴"这一新的结构关系紧耦合——这种跨操作的参数传递在任何单一源题中都不存在。
