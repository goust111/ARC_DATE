## 新题 1：拓扑分类驱动的区域差异化距离填充

**组合逻辑**：[连通分量检测](已有) + [拓扑分类](已有，创新：分类结果决定后续操作类型而非仅决定颜色) → [同心层填充](已有，创新：填充被区域边界裁剪而非正方形展开) / [重涂色](已有)

**来源原语**：连通分量检测、边界可达性、拓扑分类（参考题 84db8fc4）；同心层填充、以控制点为中心、奇偶距离决定颜色（参考题 b7fb29bc）；重涂色（参考题 84db8fc4）；标记像素（参考题 aaef0977）

**依赖链**：连通分量检测划分出各个黑色区域 → 拓扑分类判断每个区域是否触及网格边缘 → 对触边区域执行均匀重涂色，对封闭区域执行以内部标记为中心的奇偶距离填充。拓扑分类的结果不仅决定颜色，而是决定整个后续操作的种类——这在两道源题中都不存在。

将封闭区域视为距离场的容器，在其中生成以标记像素为中心的切比雪夫距离同心环，同心环被区域的不规则边界裁剪（而非源题中的正方形展开），使得距离环呈现非对称形状。

**输入结构**：约 15x15 的网格。背景为黑(0)。蓝(1)和绿(3)像素构成一像素宽的不规则障碍线网络，将黑色背景分割为多个 4-连通区域。部分区域触及网格边缘（开放区域），部分区域被障碍完全包围（封闭区域）。每个封闭区域内部恰好有一个红(2)标记像素；开放区域无标记。障碍线至少形成 2 个封闭区域和 2 个开放区域。封闭区域面积不小于 9 个像素，保证距离环可见。生成约束：不同封闭区域的标记像素相对于各自区域边界的位置不同（有的偏左，有的偏下），使得同心环形状各异。

**规则**：
1. 将所有黑(0)像素按 4-连通性划分为若干连通区域。
2. 若一个区域中存在至少一个像素位于网格最外一圈（第 0 行、最后一行、第 0 列或最后一列），则该区域为开放区域；否则为封闭区域。
3. 将所有开放区域的黑(0)像素重涂为灰(5)。
4. 对每个封闭区域：以该区域内唯一的红(2)标记像素为中心，计算区域内每个黑(0)像素到标记像素的切比雪夫距离（max(|dr|, |dc|)）。距离为偶数的像素涂为黄(4)，距离为奇数的像素涂为橙(7)。标记像素本身距离为 0（偶数），涂为黄(4)。
5. 所有蓝(1)和绿(3)障碍像素保持不变。

**关键洞察**：拓扑分类不只是选颜色，而是选操作——封闭区域获得以标记为中心的距离场填充，开放区域获得均匀涂色。同心环被封闭区域的不规则边界裁剪，因此每个区域中的环形状取决于该区域的几何形态和标记位置的共同作用。

## 新题 2：条纹空间序定义螺旋循环色板

**组合逻辑**：[排序](已有，创新：排序的输出不是填充轴而是调色板序列) + [螺旋绘制](已有，创新：螺旋的颜色不是单一种子色而是循环色板) + [遇障碍停止](已有)

**来源原语**：排序、顺序对应、条纹、条带方向（参考题 8e1813be, 746b3537）；螺旋绘制、递增步长、遇障碍停止、种子像素、障碍像素（参考题 e5c44e8f）；循环色板（参考题 aaef0977）

**依赖链**：先识别条纹的空间排列方向和顺序 → 提取条纹颜色构成有序色板 → 螺旋的每条边使用色板中的下一个颜色（循环使用）→ 螺旋遇到障碍或条纹像素时停止。条纹的空间顺序决定色板排列，色板排列决定螺旋的颜色模式——条纹不再是被填充的目标，而是元信息编码器。

将条纹从视觉装饰转变为螺旋的色彩指令源，螺旋的多色循环模式完全由输入中条纹的空间排列决定。

**输入结构**：约 15x15 的网格。背景为黑(0)。包含 3 或 4 条贯穿全高的垂直单色条纹（每条宽 1 像素，颜色各不相同，从蓝(1)、绿(3)、黄(4)、品红(6)中选取）。网格中某处有一个红(2)种子像素，不位于任何条纹所在列上。另有 0 到 2 个灰(5)障碍像素，同样不位于条纹列上。生成约束：种子像素周围至少有 5 像素的空间（到最近条纹或网格边缘），使螺旋有足够展开空间；条纹之间的间距不完全相等，以排除靠颜色编号排序的错误假设。

**规则**：
1. 识别所有贯穿全高的垂直条纹（每列像素颜色一致且非黑非红非灰）。
2. 按条纹所在列的列号从小到大排序，提取其颜色构成有序色板 P（如 P = [蓝(1), 黄(4), 绿(3)]）。
3. 从红(2)种子像素出发，按方向序列上、右、下、左绘制方形螺旋，边长依次为 2, 2, 4, 4, 6, 6, ...（每个长度重复两次后加 2）。
4. 螺旋的第 k 条边（从 k=0 开始）使用颜色 P[k mod |P|]。在该边上，将路径经过的网格内黑(0)背景像素涂为该颜色；超出网格的步数跳过但仍计入步长。
5. 若螺旋的下一个网格内目标像素是灰(5)障碍或条纹像素（非黑非红），则螺旋在该像素之前停止，不涂该像素。
6. 红(2)种子像素、灰(5)障碍像素和所有条纹像素在输出中保持不变。

**关键洞察**：条纹不是被操作的对象，而是色彩元数据——它们的空间排列顺序定义了螺旋的循环色板。改变条纹的左右排列会改变螺旋的颜色模式，但不改变螺旋的几何形状。需要对比多个示例（不同条纹排列）才能归纳出"条纹顺序=色板顺序"这一规则。

## 新题 3：锚点对齐方向同时控制射线与精灵体镜像方式

**组合逻辑**：[射线延伸](已有) + [镜像](已有，创新：镜像轴由射线的方向属性隐式决定，而非由独立标记编码) + [印章覆盖](已有，创新：印章位置由标记而非孤立像素决定)

**来源原语**：射线延伸、锚定方块、行列对齐、标记像素、对齐标记连向锚点（参考题 d43fd935）；镜像、相邻拼接（参考题 9bebae7a）；印章覆盖、中心展开（参考题 b60334d2）；精灵体（参考题 4290ef0e）

**依赖链**：每个标记像素与锚定方块的行列对齐关系同时决定两件事：(1) 射线从标记延伸到锚点的方向（行对齐→水平射线，列对齐→垂直射线）；(2) 在标记位置放置精灵体副本时的镜像方式（行对齐→水平翻转，列对齐→垂直翻转）。同一个几何属性驱动两个不同操作——这在源题中不存在。

利用"对齐方向"这一单一几何属性同时编码射线方向和镜像轴，在标记位置生成射线连接和方向感知的精灵体副本。

**输入结构**：约 16x16 的网格。背景为黑(0)。包含一个 2x2 蓝(1)锚定方块。一个不对称的小型 4-连通精灵体（3~6 个像素，绿(3)），位于远离锚定方块的位置（与锚定方块不行列对齐）。另有 3~4 个单像素标记，颜色各不相同（从红(2)、黄(4)、品红(6)、橙(7)中选取），每个标记恰好与锚定方块的某一行或某一列对齐（即标记的行号等于锚定方块占据的两行之一，或标记的列号等于锚定方块占据的两列之一）。生成约束：标记不紧贴锚定方块（至少间隔 4 个像素），使射线可见；标记中至少有一个行对齐和一个列对齐，使两种镜像方式都出现；各标记的精灵体副本的边界框互不重叠。

**规则**：
1. 对每个标记像素，判断它与锚定方块的对齐类型：
   - 行对齐：标记的行号等于锚定方块占据的两行之一。
   - 列对齐：标记的列号等于锚定方块占据的两列之一。
2. 对行对齐的标记：从标记位置向锚定方块方向水平绘制射线（涂为标记的颜色），直到锚定方块的边缘（不覆盖锚定方块像素），仅涂背景像素。
3. 对列对齐的标记：从标记位置向锚定方块方向垂直绘制射线（涂为标记的颜色），直到锚定方块的边缘，仅涂背景像素。
4. 在每个标记的位置，以标记为中心放置精灵体的一个副本：
   - 行对齐的标记：精灵体水平翻转（左右镜像）后放置。
   - 列对齐的标记：精灵体垂直翻转（上下镜像）后放置。
   - 副本颜色保持绿(3)不变，仅覆盖背景像素。
5. 锚定方块（蓝）、原始精灵体（绿）、所有标记像素和射线均保留。处理顺序：按标记在网格中的光栅顺序（从左上到右下）依次处理，先画射线再放精灵体副本。

**关键洞察**：标记与锚定方块的行列对齐类型是一个隐藏变量，同时编码射线方向和精灵体镜像轴。仅看单个示例可能以为镜像方向由标记相对于锚点的左右上下位置决定，需要对比多个示例（例如同在左侧但一个行对齐一个列对齐的标记产生不同镜像）才能归纳出真正的规则。

## 新题 4：最近种子条分组后组内孔洞异常值提取

**组合逻辑**：[最近扩散](创新：不是填充行颜色，而是将离散对象分配到组) + [计数](已有) + [异常值提取](创新：从全局唯一变为组内唯一) + [裁剪](已有) + [重涂色](已有，创新：涂色是分组可视化而非最终输出)

**来源原语**：最近扩散、最近种子分区、种子条（参考题 332202d5）；计数、异常值提取、孔洞数量唯一、前景块、背景孔洞、裁剪（参考题 358ba94e）；重涂色（参考题 84db8fc4）

**依赖链**：种子条的空间位置将前景块按最近距离分组 → 每个块被涂为其所属种子条的颜色（可视化分组）→ 在每组内部独立计算每个块的孔洞数量 → 在每组中找到孔洞数唯一的块（组内异常值）→ 裁剪所有组的异常值块并按种子条从上到下的顺序排列为输出。分组改变了异常值的判定范围——一个全局常见的孔洞数在某组内可能恰好是异常值。

通过空间邻近关系将对象分组，在每个组内独立执行异常值检测，使得异常值的判定依赖于分组结果，而分组结果依赖于种子条的空间布局。

**输入结构**：约 20x15 的网格。背景为黑(0)。包含 3 条贯穿全宽的水平种子条（每条厚 1 像素，颜色分别为蓝(1)、绿(3)、红(2)，从上到下排列，间距不等）。种子条之间和上下方散布着 6~9 个灰(5)前景块，每个块为实心矩形（4x4 到 6x6），内部包含若干黑(0)孔洞像素（0~4 个）。生成约束：每个种子条至少分配到 2 个块；每组内恰好有一个块的孔洞数与该组内其他块不同；不同组的异常值块的孔洞数可以相同（排除"全局唯一"的捷径）。各块互不接触，且不与种子条重叠。

**规则**：
1. 对每个灰(5)前景块，计算其中心行（边界框行范围的中间值，向下取整）到每条种子条所在行的绝对距离，将该块分配给距离最近的种子条。若距离相等，分配给行号较小（更靠上）的种子条。
2. 将每个块的灰(5)像素重涂为其所属种子条的颜色。
3. 在每个组内，统计每个块边界框内部的黑(0)孔洞像素数量。
4. 在每组中，找到孔洞数与该组其他块都不同的唯一一个块（组内异常值）。
5. 输出构造：将每个组的异常值块裁剪为其边界框大小（保留涂色后的颜色）。按该块所属种子条从上到下的顺序（行号从小到大），将裁剪后的块垂直堆叠，相邻块之间用 1 行黑(0)分隔。输出宽度为所有裁剪块中最宽者的宽度，较窄的块左对齐，右侧用黑(0)补齐。

**关键洞察**：异常值检测不是全局操作，而是在由空间邻近关系定义的分组内独立进行。一个孔洞数为 2 的块在全局可能很常见，但如果它所属的组中其他块都是 3 个孔洞，它就是异常值。改变种子条位置可能导致某个块从一组移到另一组，从而改变其异常值身份。

## 新题 5：周期修复重建完整对角线后奇偶交替涂色

**组合逻辑**：[补全/平铺](已有) + [奇偶交替涂色](已有，创新：交替作用于补全后的完整对角线而非输入中的片段，补全改变了对角线长度从而改变奇偶分配)

**来源原语**：补全、平铺、周期瓦片、最小周期修复缺口、周期对齐、缺失像素（参考题 e95e3d8e）；奇偶交替涂色、对角线段、序列索引（参考题 a5f85a15）

**依赖链**：先找到最小周期瓦片修复所有缺失像素 → 修复后的网格中出现完整的对角线运行段 → 对每段对角线执行奇偶交替涂色。关键耦合：输入中被黑色缺口打断的对角线看起来是独立的短片段，如果直接对片段交替涂色会得到错误结果；必须先修复缺口恢复完整对角线，才能正确确定每个像素在完整运行段中的序号和奇偶性。

周期修复不仅填补视觉缺口，还重建了对角线的真实长度信息——修复前和修复后对同一像素的奇偶判定可能不同。

**输入结构**：约 12x12 的网格。包含一个由 3~4 种颜色构成的二维周期模式（周期矩形约 3x3 或 4x3）。模式中，绿(3)像素恰好出现在周期瓦片的某些位置上，使得在完整网格中绿(3)像素形成若干条右下对角线运行段（每段长 3~6 像素）。输入中部分像素被替换为黑(0)（缺失像素），缺失位置经过精心选取：至少有一处缺失位于某条绿色对角线运行段的中间，将该段在视觉上断成两截。其他颜色的缺失像素也存在以保持周期修复的必要性。生成约束：非黑像素足以唯一确定最小周期瓦片；每种残差类（周期瓦片中的每个位置）至少被观测一次。

**规则**：
1. 找到能解释所有非黑(0)像素的最小面积周期矩形。每个非黑像素的颜色必须等于该像素位置在周期矩形中对应残差位置的颜色。
2. 用周期矩形的对应颜色替换每个黑(0)像素，完成修复。
3. 在修复后的完整网格中，识别所有由绿(3)像素构成的极大右下方向对角线运行段。一个运行段是沿 (行+1, 列+1) 方向连续的绿(3)像素序列，在两端被非绿像素或网格边界终止。
4. 对每个运行段，从其左上端点开始沿右下方向编号（从 0 开始）。将编号为奇数的像素从绿(3)重涂为黄(4)。编号为偶数的像素保持绿(3)。
5. 所有非绿像素（无论是原始的还是修复的）保持不变。

**关键洞察**：缺失像素打断了对角线运行段，使得片段内的序号偏移。例如，一条完整对角线长 5 被中间缺口断成长 2 和长 2 的片段——如果直接对片段交替涂色，两个片段各自从 0 开始，结果与对完整长 5 运行段交替涂色不同（后者的第二个片段从序号 3 开始）。必须先周期修复再交替涂色。

## 新题 6：障碍距离控制模板展开等级与重叠涌现

**组合逻辑**：[印章覆盖/像素替为固定模](创新：模板有多个展开等级，由距离选择) + [近阻挡距定尺寸](创新：距离不是定义正方形边长而是选择模板等级) → [连通分量检测](创新：不是检测输入区域而是检测展开后的重叠像素)

**来源原语**：印章覆盖、像素替为固定模、孤立像素、中心展开（参考题 b60334d2）；近阻挡距定尺寸、切比雪夫距离、障碍像素、标记像素（参考题 ff72ca3e）；连通分量检测（参考题 84db8fc4）

**依赖链**：每个标记的展开等级由其到最近障碍的切比雪夫距离决定 → 不同等级对应不同大小的模板 → 多个展开后的模板可能在空间上重叠 → 重叠区域（被两个或以上模板覆盖的像素）被检测并涂为特殊颜色。障碍的空间分布控制每个标记的展开幅度，展开幅度的差异则可能在标记之间制造重叠，而重叠的存在和位置是距离信息与空间布局共同作用的涌现结果。

障碍距离决定展开尺寸，展开尺寸决定是否产生重叠，重叠本身是一个需要检测的新结构——三者构成因果链，删除任一环节均无法得到最终输出。

**输入结构**：约 14x14 的网格。背景为黑(0)。包含 4~6 个黄(4)孤立标记像素和 3~5 个灰(5)障碍像素，均为单像素，互不相邻。生成约束：标记之间的间距在 3~6 像素之间，使得在不同展开等级下恰好存在部分标记的模板重叠；每个标记到最近障碍的切比雪夫距离在 1~4 之间，覆盖至少两个不同的展开等级。

**规则**：
1. 对每个黄(4)标记像素，计算它到所有灰(5)障碍像素的切比雪夫距离（max(|dr|, |dc|)），取最小值 D。
2. 根据 D 决定展开等级：
   - D = 1：不展开。标记保持黄(4)不变。
   - D = 2：小展开。将标记的 4 个正交邻居（上下左右）中的背景像素涂为蓝(1)。标记本身保持黄(4)。
   - D >= 3：大展开。将标记的 4 个正交邻居涂为蓝(1)，4 个对角邻居涂为红(2)。标记本身保持黄(4)。即完整的 3x3 模板：中心黄、正交蓝、对角红。
3. 按标记在网格中的光栅顺序（从左上到右下逐行扫描）依次处理每个标记的展开。后处理的展开可以覆盖先处理的展开所涂的像素。
4. 所有展开完成后，检测重叠：如果某个非标记、非障碍像素在展开过程中被两个或以上不同标记的模板覆盖过（即它出现在两个或以上标记的展开范围内，无论最终被哪个标记的颜色覆盖），则将该像素涂为绿(3)。
5. 灰(5)障碍像素始终保持不变。黄(4)标记像素始终保持不变。

**关键洞察**：最终输出中的绿(3)重叠标记不能通过单独分析每个标记得到——必须综合所有标记的展开范围。而每个标记的展开范围由它到最近障碍的距离决定，因此移动一个障碍可能同时改变多个标记的展开等级，连锁改变哪些区域产生重叠。需要对比多个示例才能发现重叠检测规则（因为单个示例中可能没有重叠，或者重叠位置可能被误认为固定模板的一部分）。

## 新题 7：四重对称补全构建容器后种子洪泛填充

**组合逻辑**：[对称补全](已有，创新：补全结果不是最终输出而是后续操作的空间约束) + [洪泛填充](已有，创新：填充边界由补全生成而非预先存在) + [种子沿连通域扩散](已有)

**来源原语**：对称补全、角落补全四重对称、对称图案、中心对齐（参考题 4290ef0e）；洪泛填充、种子像素、四邻连通、种子沿连通域扩散、障碍物（参考题 9edfc990）

**依赖链**：输入中的局部对称片段被补全为完整的四重对称障碍结构 → 补全后的障碍将空间划分为若干封闭区域和开放区域 → 种子像素通过 4-连通洪泛填充扩散到其所在封闭区域的所有背景像素。关键耦合：种子像素在输入中的位置看似可以自由扩散（因为障碍不完整），但补全后的障碍会限制其扩散范围。如果不先补全对称结构就执行洪泛填充，种子会泄漏到不应到达的区域。

对称补全不是视觉美化，而是为洪泛填充构建屏障——补全前后种子的可达域截然不同。

**输入结构**：约 13x13 的网格。背景为黑(0)。蓝(1)像素构成一个四重对称图案的局部片段——仅显示 1~2 个角落的 L 形片段（如只有左上角和右下角的 L 形），其余角落缺失。所有角落的 L 形片段如果存在，则相对于网格中心呈四重对称。完整对称图案的尺寸由已有片段的跨度和角落位置推断（最小奇数正方形）。网格中还散布着 2~3 个不同颜色的种子像素（从红(2)、绿(3)、黄(4)中选取），每个种子位于补全后的某个封闭区域内部（在输入中由于障碍不完整，种子看似未被包围）。生成约束：补全后的蓝色对称结构至少形成 2 个互不连通的封闭区域；每个封闭区域最多包含 1 个种子；至少有一个封闭区域不含种子（保持为黑）；所有种子都位于封闭区域内（不在开放区域）。

**规则**：
1. 识别蓝(1)像素构成的部分对称图案。根据已有的角落 L 形片段推断完整四重对称结构所需的最小奇数正方形尺寸和中心位置。
2. 将缺失角落的 L 形片段补全：对于已有的每个角落片段，将其关于中心进行 90 度、180 度、270 度旋转，在其余三个角落放置对应的蓝(1)像素（仅在目标位置为黑(0)背景时放置，不覆盖已有的非背景像素）。
3. 补全后，从每个种子像素出发，沿 4-连通方向遍历所有可达的黑(0)像素（不穿过蓝(1)障碍和其他种子像素），将到达的每个黑(0)像素涂为该种子的颜色。
4. 不同种子的填充互不干涉——由于生成约束保证每个封闭区域最多一个种子，不会出现两个种子填充同一区域的情况。
5. 未被任何种子填充到达的黑(0)像素保持黑(0)（包括开放区域和无种子的封闭区域）。
6. 所有蓝(1)像素（无论原始还是补全生成的）保持蓝(1)。所有种子像素保持其原始颜色。

**关键洞察**：在输入中，由于对称障碍不完整，种子像素看似可以自由扩散到大片区域。但正确的做法是先补全对称结构形成完整屏障，再执行洪泛填充。补全生成的蓝色像素是填充的关键边界——它们在输入中不存在，但在规则中起着阻断扩散的决定性作用。仅看单个示例可能无法确定对称补全的具体规则（四重对称还是二重对称），需要对比多个示例中不同的缺失模式来归纳。
