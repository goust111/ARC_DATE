## 新题 1：重力分层着陆后按面积排序水平重排

**组合逻辑**：[滑动/sliding](重力沉降至水平架层) → [计数/counting](统计各精灵体像素面积) → [排序/sorting](同层精灵体按面积排名) → [对齐/align](创新：按排名重排水平位置)

**来源原语**：滑动/sliding、重力沉降/gravity_settling（3618c87e）；计数/counting、面积分类/area_classification（d2abd087）；排序/sorting、长度排名/length_ranking（ea32f347）；对齐/align（1caeab9d）

**依赖链**：重力沉降决定每个精灵体落在哪一层架子上 → 着陆层决定哪些精灵体被分为一组进行比较 → 组内面积比较产生排名 → 排名决定最终水平排列位置。删除任何一环（重力/分组/排序/重排），都无法独立得到正确输出。

将散布在网格中的彩色小图形按重力下落到最近的灰色水平架子上，然后在每层架子上按图形面积从小到大重新排列水平位置。

**输入结构**：
- 网格约 15x15，黑(0)背景。
- 2-3 条灰(5)全宽水平条（各 1 像素厚），分布在不同高度，将网格分成 3-4 个纵向区域。
- 4-6 个小型单色 4-连通精灵体（每个 3-8 像素，形状各异——非固定几何形状），颜色各不相同，选自红(2)、蓝(1)、绿(3)、黄(4)、橙(7)、品红(6)。
- 每个精灵体完整地位于某个区域内（不跨越灰色条）。
- 同一区域内各精灵体的像素面积两两不同。
- 生成约束：精灵体足够小，使得落在同一架子上的所有精灵体按包围框宽度加 1 像素间隔排列后，总宽度不超过网格宽度。

**规则**：
1. 每个精灵体整体下落（保持内部形状不变），直到其最底行像素紧贴下方最近的灰(5)条的上一行为止；若下方无灰条，则落至网格底边上一行。下落过程中精灵体的水平位置不变。
2. 按着陆位置将精灵体分组：落在同一灰条（或底边）上的归为一组。
3. 组内按像素面积升序排列（面积最小者排第一）。
4. 按排序结果重排水平位置：第一个精灵体的包围框左边缘置于列 0；后续精灵体的包围框左边缘置于前一个包围框右边缘再右移 1 列处。每个精灵体相对于其着陆架子的垂直偏移保持不变。
5. 灰(5)条保持不变。

**关键洞察**：着陆架子对精灵体进行隐式分组——哪些精灵体需要互相比较面积，完全取决于它们各自落到了哪一层，而非它们的初始位置邻近关系。

## 新题 2：格子块多数色压缩后周期推断填补空白块

**组合逻辑**：[压缩/compress + 多数决/majority_vote](逐块提取信号色) → [周期推断/periodic_inference](从已知块推断周期和相位偏移) → [间隙填充/gap_filling](按周期填充空白块)

**来源原语**：压缩/compress、多数决/majority_vote、格子格局/lattice_layout、分隔行列/separator_row_col、每块取唯一多数色/majority_color_per_block（af24b4cc）；周期推断/periodic_inference、间隙填充/gap_filling、对角线相位偏移/diagonal_phase_shift、按列周期取色/column_modular_phase（1e97544e）

**依赖链**：多数决从每个噪声块中提取主色 → 提取后的主色序列暴露出全局周期模式 → 周期模式用于推断空白块应有的颜色。三步缺一不可：不做多数决则看不到周期；不做周期推断则无法填补空白；空白块只在块级别可识别，不在像素级别。

将背景分隔的格子中每个噪声块压缩为其多数色，发现压缩后颜色呈周期排列，据此填充空白块，输出完整的压缩色图。

**输入结构**：
- 网格约 20x20，灰(5)背景色构成完整的分隔行和分隔列（含外边框），将内部划分为 R 行 x C 列的格子（如 4x5），每个块大小相同（如 3x3）。
- 每个非空白块内填有 2-3 种颜色的像素，选自红(2)、蓝(1)、绿(3)、黄(4)、品红(6)，其中一种颜色占严格多数（超过该块像素总数的一半）。
- 2-4 个块完全填充为黑(0)，作为"空白"标志。
- 所有非空白块的多数色遵循一个周期为 L 的颜色循环（如 L=3: 红, 蓝, 绿, 红, 蓝, 绿, ...），按从左到右、从上到下的阅读顺序排列。每一行的起始相位相对于上一行偏移 1 位，即格子位置 (r, c) 的颜色为 cycle[(c + r) mod L]。
- 生成约束：非空白块数量足以唯一确定循环序列及其长度；空白块的分布不构成连续整行或整列（避免相位歧义）。

**规则**：
1. 识别分隔行和分隔列（全为灰(5)的行/列），提取内部的格子块阵列。
2. 对每个非空白块（非全黑(0)的块），计算其多数色（块内像素数最多的颜色）。
3. 从所有非空白块的多数色中推断周期循环：找到最短的颜色序列 cycle，使得对所有非空白位置 (r, c) 均满足 majority_color(r, c) = cycle[(c + r) mod L]。
4. 对每个空白块（全黑(0)），赋予颜色 cycle[(c + r) mod L]。
5. 输出一个 (R+2) x (C+2) 的紧凑网格：内部每个格 (r, c) 填入对应格子块的多数色或推断色，外围一圈灰(5)边框。

**关键洞察**：块内的颜色噪声是干扰项，真正的信号是多数决之后才浮现的周期性颜色循环；空白块是该循环中的刻意缺口，只有同时掌握压缩和周期两个步骤才能还原。

## 新题 3：形状配对与路径连通联合门控颜色互换

**组合逻辑**：[形状匹配/shape_match](按内部掩码配对精灵体) AND [路径连通/path_connectivity](检查灰色路径是否连通该对) → 条件分支（连通则互换内部色；不连通则擦除双方）

**来源原语**：形状匹配/shape_match、掩码相同/mask_equality（63613498）；路径连通/path_connectivity、颜色查找键/color_lookup_key（d35bdbdc）；擦除/erase（d35bdbdc、1a07d186）；重涂色/recolor（d35bdbdc）

**依赖链**：形状匹配识别哪些精灵体构成配对（独立于颜色和位置）。路径连通性判断配对双方之间是否存在灰色通道。两项分析相互独立但共同决定操作：连通配对执行颜色互换，断开配对执行双向擦除。仅知形状或仅知路径均无法确定输出。

按内部形状的归一化掩码将带边框的精灵体配对，若配对双方由灰色路径相连则互换内部颜色，否则擦除双方。

**输入结构**：
- 网格约 18x18，黑(0)背景。
- 6-8 个小型"带边框精灵体"，每个由 1 像素厚的矩形边框（包围框 3x3 至 5x5）和内部像素构成。边框为一种颜色，内部像素为另一种不同颜色，形成一个 4-连通的小形状（2-4 像素）。
- 边框颜色选自蓝(1)、绿(3)、黄(4)、品红(6)、橙(7)；内部颜色同样从不同颜色中选取。
- 灰(5)路径网络由 1 像素宽的 8-连通轨迹组成，连接部分精灵体（路径与精灵体的边框 8-邻接即视为连通）。
- 精灵体按内部形状严格配对：恰好两个精灵体共享相同的归一化内部掩码（平移至原点后一致）。无落单精灵体。
- 并非所有配对都由路径连通。至少一对连通，至少一对不连通。
- 生成约束：不同配对的内部掩码互不相同；灰色路径无歧义分支（每段路径恰好连接两个精灵体）；各精灵体互不接触。

**规则**：
1. 对每个精灵体，提取其内部像素（边框矩形内所有非边框、非背景像素）。将内部掩码平移至原点进行归一化。
2. 按归一化掩码相同将精灵体配对。
3. 对每对精灵体，判断是否存在灰(5) 8-连通路径从一方边框邻域通达另一方边框邻域。
4. 若连通：互换两个精灵体的内部颜色。内部形状不变，仅颜色值交换为对方原始内部颜色。边框颜色不变。
5. 若不连通：将两个精灵体完全擦除（边框和内部均替换为黑(0)背景）。同时擦除未连接到任何存活精灵体的孤立灰色路径段。
6. 连接存活（已互换）配对的灰色路径段保留不变。

**关键洞察**：形状匹配和路径连通是两个独立维度——单独知道形状配对或单独知道路径拓扑都不够，必须同时求解两者并交叉组合结果，才能确定每对精灵体的命运（互换还是消亡）。

## 新题 4：对角线段围合的平行四边形区域按内部散点多数色填充

**组合逻辑**：[填充/fill + 段间区域填充/fill_between_segments](几何定义平行四边形区域) + [多数决/majority_vote + 计数/counting](从区域内散点统计决定填充色) → 内容驱动的区域着色

**来源原语**：填充/fill、段间区域填充/fill_between_segments、对角线段/diagonal_segment、平行配对/parallel_pairing、平行四边形区域/parallelogram_region（7666fa5d）；多数决/majority_vote（af24b4cc）；计数/counting、面积分类/area_classification、连通分量/connected_component（d2abd087）

**依赖链**：对角线段的几何配对定义区域边界 → 区域内散布像素的颜色统计决定填充色 → 空区域与有内容区域的差异化处理。几何结构和统计内容各自独立，但必须联合才能确定输出。

识别由配对反对角线段围合的平行四边形区域，用区域内散布前景像素的多数色填充该区域；若区域内无前景像素则保持空白。

**输入结构**：
- 网格约 16x16，黑(0)背景。
- 若干灰(5)反对角线段（每段位于单条反对角线 r+c=常数 上，长 3-6 像素）。
- 线段形成 2-3 个平行对：同一对中的两段位于不同的反对角线上，但在主对角线方向（r-c）上的跨度有重叠，围合出一个平行四边形区域。
- 每个平行四边形内部散布着 4-8 个前景像素，颜色选自红(2)、蓝(1)、绿(3)、黄(4)中的 2-3 种，其中一种颜色占严格多数（超过半数）。
- 至多一个平行四边形内部无前景像素（完全空白）。
- 散布像素不与灰色线段相邻。
- 生成约束：各平行四边形区域互不重叠；每个有内容的区域内多数色明确无歧义。

**规则**：
1. 识别灰(5)反对角线段。按主对角线（r-c）方向的跨度重叠将线段配对。
2. 对每个配对，定义平行四边形区域为：沿每条主对角线轴，严格位于两条反对角线之间的所有格子。
3. 收集每个平行四边形内所有非背景、非灰色像素，计算多数色（出现次数最多的颜色）。
4. 将该平行四边形内所有背景格子填充为多数色。原有的散布像素融入填充（它们本身或与填充色一致、或被覆盖）。
5. 若平行四边形内无前景像素，保持背景不变（不做填充）。
6. 灰(5)线段保持不变。

**关键洞察**：填充色不是由线段的几何属性决定的，而是由区域内已有散点像素的统计投票涌现出来的——几何结构划定"在哪填"，内容统计决定"填什么色"。空区域的特殊处理需要对比多个示例才能归纳。

## 新题 5：标记色多重角色——选择、镜像触发、位置印章

**组合逻辑**：[裁剪/crop + 标记色最多者选中/max_marker_count_selected](按标记密度选取精灵体) → [镜像/mirror + 特定标记触发镜像/marker_triggers_mirror](创新：标记分布对称性决定是否镜像) → [印章覆盖/stamp + 标记色匹配目标位/marker_color_matches_dest](在孤立标记位置印章)

**来源原语**：裁剪/crop、标记色像素/marker_color_pixel、标记色最多者选中/max_marker_count_selected、形状内色频/color_frequency_within_shape（ae4f1146）；镜像/mirror、特定标记触发镜像/marker_triggers_mirror、标记色匹配目标位/marker_color_matches_dest（3e980e27）；印章覆盖/stamp（3e980e27）

**依赖链**：全局最稀有色被识别为标记色 → 标记色计数决定选中哪个精灵体 → 选中精灵体内标记像素的空间对称性决定是否水平镜像 → 网格中孤立标记像素的位置决定印章放置处。同一"标记"概念在四个不同的结构层次发挥作用，删除任一层次都会导致输出不确定。

选出标记色像素最多的精灵体，根据其标记像素的对称性决定是否镜像，然后将清理后的精灵体印章到所有孤立标记位置。

**输入结构**：
- 网格约 15x15，黑(0)背景。
- 3-4 个实心矩形精灵体（各 4x4 像素），各以一种非背景主色填充（如蓝(1)、绿(3)、黄(4)），不同精灵体主色不同。
- 在每个精灵体内部，部分像素被替换为全局最稀有的前景色——标记色（如红(2)）。不同精灵体含有不同数量的标记色像素（如分别含 1、2、3 个），恰好一个精灵体的标记色像素数量唯一最多。
- 网格其他位置散布 2-3 个孤立的标记色单像素，不与任何精灵体相邻。
- 生成约束：标记色在整个网格中的总像素数（含精灵体内和孤立的）明确少于任何其他非背景色；标记数最多的精灵体内的标记像素要么明确关于精灵体垂直中心轴对称，要么明确不对称。

**规则**：
1. 识别标记色：整个网格中像素总数最少的非背景色。
2. 识别每个精灵体（像素数 > 1 的非背景 4-连通区域，排除孤立单像素标记）。统计每个精灵体内标记色像素的数量。
3. 选中标记色像素数量最多的精灵体。
4. 生成"洁净版"：将选中精灵体内所有标记色像素替换为该精灵体的主色（精灵体内出现次数最多的非标记颜色）。
5. 检查选中精灵体内标记色像素在精灵体局部坐标系下的位置，判断是否关于精灵体垂直中心轴左右对称。若不对称，将洁净版精灵体水平镜像翻转；若对称，保持不变。
6. 将结果精灵体（洁净、可能已镜像）以每个孤立标记色像素为中心进行印章放置。超出网格边界的部分裁去。
7. 擦除所有未被选中的精灵体（替换为背景）。选中精灵体的原始位置也清除（仅保留印章副本）。

**关键洞察**：标记色同时承担四种结构角色——(a) 选择判据（精灵体内的标记计数）、(b) 变换触发器（标记的空间对称性）、(c) 清理对象（被主色替换）、(d) 位置指南（孤立标记决定印章坐标）。理解同一颜色的四重身份是解题的核心。

## 新题 6：滑向同色全幅条后按附着计数查调色板重涂

**组合逻辑**：[滑动/sliding + 同色配对/same_color_pairing](孤立像素滑至匹配条) + [擦除/erase + 无匹配色则删除/unmatched_deleted](清理不匹配像素) → [计数/counting](统计每条附着像素数) → [重涂色/recolor + 调色板行/palette_row](创新：用计数作为调色板索引来重涂)

**来源原语**：滑动/sliding、同色配对/same_color_pairing、碰撞阻挡/collision_blocking、孤立像素/isolated_pixel、满行列条/full_span_bar、无匹配色则删除/unmatched_deleted（1a07d186）；计数/counting（d2abd087、ff2825db）；调色板行/palette_row、矩形边框/rect_frame、众数颜色决定输出/majority_color_out（ff2825db）；重涂色/recolor（多个源题）

**依赖链**：同色配对决定哪些像素滑向哪条 → 滑动改变空间布局 → 附着计数量化每条的"吸引力" → 计数值作为调色板索引间接映射到目标颜色。调色板提供了从计数到颜色的非平凡映射，必须跨示例归纳。

将孤立像素滑到同色全幅条上，统计每条附着的像素数，以该计数为索引查顶部调色板行得到新颜色，重涂整条。

**输入结构**：
- 网格约 14x14，黑(0)背景。
- 第 0 行为调色板行：由若干相邻等色像素对组成（如 [绿(3)绿(3), 黄(4)黄(4), 品红(6)品红(6)]），从左到右定义 palette[1]、palette[2]、palette[3]...
- 调色板行下方：3 条全宽水平条，颜色各不相同，选自红(2)、蓝(1)、橙(7)，各 1 像素厚，分布在不同行。
- 网格中散布若干孤立单像素：部分颜色与某条相同（匹配像素），部分颜色不与任何条相同（干扰像素，如栗(9)）。
- 生成约束：滑动完成后，每条附着的匹配像素数量互不相同，且均在调色板索引范围内（1 到调色板长度）；每个匹配像素与其对应条之间的滑动路径上无其他条阻挡。

**规则**：
1. 读取调色板行（第 0 行）：从左到右每对相邻等色像素定义一个调色板条目，依次编号为 palette[1]、palette[2]、palette[3]...
2. 对每个孤立像素（单像素的非背景 4-连通分量，不在调色板行上），若其颜色与某条的颜色相同，将其沿垂直方向朝该条滑动，直到与该条相邻（紧贴其上一行或下一行）。若该像素处于两条同色条之间（本题不会出现此情况），取较近者。
3. 擦除所有颜色不匹配任何条的孤立像素（替换为背景）。
4. 统计每条附着的匹配像素数量 count_i（不含条自身）。
5. 将每条及其所有附着像素重涂为 palette[count_i] 对应的颜色。
6. 调色板行保持不变。

**关键洞察**：计数值不直接是颜色编号，而是调色板的间接索引——同样的数字在不同示例中可能映射到不同颜色（因为调色板不同），必须对比调色板行和计数结果才能归纳出索引映射规则。

## 新题 7：列状态模式外推后全体像素重力沉降

**组合逻辑**：[补全/complete + 外推/extrapolate + 前缀匹配/prefix_matching](推断列状态周期并续写) → [滑动/sliding + 重力沉降/gravity_settling](创新：对原始像素和新增像素统一执行重力) → 两步变换交互的复合结果

**来源原语**：补全/complete、外推/extrapolate、前缀匹配/prefix_matching、完整模式续写缺失/missing_suffix_continued_from_pattern、行组/row_group、列状态序列/column_state_sequence（90f3ed37）；滑动/sliding、重力沉降/gravity_settling、基线行/baseline_row、同列对齐/same_col_align、前景像素/foreground_pixel（3618c87e）

**依赖链**：模式推断决定在哪些列的哪些行创建蓝色新像素 → 重力沉降将所有像素（原色 + 蓝色新增）向下压缩堆叠 → 最终排列同时取决于外推产生的像素分布和逐列重力压缩。单独外推给出错误位置（未沉降），单独重力给出不完整内容（缺少外推像素）。

将部分列状态模式向右外推补全（新像素用蓝色），然后对所有前景像素（含原始和新增）执行重力沉降至基线上方。

**输入结构**：
- 网格约 12x15（12 行、15 列），黑(0)背景。
- 最底行为均匀灰(5)基线。
- 网格左侧部分（约列 0 至列 8）有一个使用 1-2 种颜色（如红(2)、黄(4)）的前景图案。该图案的列状态序列——每列中前景像素的垂直排列方式（如"第 3 行有 1 个像素""第 2-3 行有 2 个像素"等）——呈周期性重复，周期为 P 列。
- 网格右侧部分（约列 9 至列 14）全为背景（空白），代表待续写的缺失后缀。
- 生成约束：已有图案包含至少两个完整周期以确保周期可推断；每列前景像素至多 3 个，位于基线上方的不同行。

**规则**：
1. 识别基线色（底行的均匀颜色）和背景色（出现频次最高的颜色）。
2. 从左到右分析现有前景图案的列状态序列（每列中非背景、非基线像素的行位置集合），确定重复周期 P。
3. 外推：对每个空白列，按 column_index mod P 指定的列状态添加像素，所有新像素着蓝(1)色。
4. 重力沉降：对每一列，将所有非背景、非基线的前景像素（包括原始颜色像素和蓝(1)新增像素）向下移动，使其连续堆叠在基线行正上方。同一列内像素的上下相对顺序保持不变（原来在上面的仍在上面）。
5. 基线行保持不变。

**关键洞察**：外推和重力交互作用——模式决定蓝色像素在哪些行列被创建（保留了原始模式的空间高度），但重力随后将一切压平到底部，最终输出既非原始外推图案（位置被重力改变）也非简单的重力结果（缺少外推像素），而是两个变换耦合后的复合产物。
