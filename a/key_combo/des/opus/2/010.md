## 新题 1：裂缝分域的面积填色

**组合逻辑**：[分裂/fracture_line](创新：裂缝不再分离物体两半，而是在封闭轮廓内部划分子域) + [洪泛填充/flood_fill](已有) + [面积决定填充色/area_determines_fill_color](创新：面积的计算域由裂缝动态重定义)

**来源原语**：分裂/裂缝标记线(2faf500b)、洪泛填充/封闭区域(c0f76784)、面积决定填充色(c0f76784)、包围/enclosure(c0f76784)

**依赖链**：裂缝的存在与否决定了封闭域的分割方式 → 分割后的子域面积各自独立计算 → 面积值映射到不同的填充色。删除裂缝识别环节则无法知道子域边界；删除面积计算环节则无法确定填充色。

将灰色轮廓内部被红色裂缝线一分为二的封闭空间按各自子面积独立填色，无裂缝的轮廓按完整内部面积填色。

**输入结构**：
- 黑(0)背景，网格约 14x14。
- 3-5 个灰(5)像素构成的一像素宽封闭轮廓（4-连通闭合环），每个轮廓围出一块矩形或近矩形的内部背景区域（内部面积 2-12 像素不等）。轮廓之间互不相邻，各自独立。
- 其中 1-2 个轮廓内部有一条红(2)像素构成的一像素宽直线段，水平或垂直穿过内部区域，两端紧贴灰色轮廓壁（与轮廓 4-邻接但不重叠），将内部背景区域切分为两个互不连通的子域。
- 其余轮廓内部无裂缝线，内部是完整的单一背景区域。
- 生成约束：每个轮廓的内部面积至少为 2 像素；含裂缝的轮廓的两个子域面积均至少为 1 像素；不同轮廓（或同一轮廓的不同子域）允许面积相同。

**规则**：
1. 识别灰(5)轮廓围成的所有封闭背景区域（4-连通黑(0)分量，完全被灰像素包围，不与外部背景连通）。
2. 对含红(2)裂缝线的轮廓：裂缝线将内部分为两个 4-连通背景子域。擦除裂缝线（将红像素替换为黑(0)背景），然后对每个子域独立计算面积（像素数）。
3. 对不含裂缝线的轮廓：内部为单一域，直接计算面积。
4. 面积-颜色映射（对每个域独立应用）：
   - 面积 1-3 像素 → 蓝(1)
   - 面积 4-6 像素 → 黄(4)
   - 面积 7-9 像素 → 橙(7)
   - 面积 10+ 像素 → 品红(6)
5. 用映射所得颜色洪泛填充对应域的所有像素。
6. 灰(5)轮廓保持不变，外部黑(0)背景保持不变。

**关键洞察**：裂缝线并非装饰，而是将单一封闭域拆为两个独立域，使面积计算结果改变——同一个轮廓内部原本映射到一个颜色，被裂缝一分为二后可能映射到两个不同的颜色。需对比有裂缝与无裂缝的示例才能归纳出这一规则。

## 新题 2：射线封闭域的边界归属填色

**组合逻辑**：[射线延伸/ray_extend](创新：射线不再只是标记行列，而是与已有线段共同构成封闭边界) + [洪泛填充/flood_fill](创新：填充域由射线动态创建而非预设) + [异源交叉特殊着色/cross_source_special_color](已有：多色边界→冲突色)

**来源原语**：射线延伸/十字引导线(45bbe264)、洪泛填充/封闭区域(c0f76784)、异源交叉特殊着色(45bbe264)、包围/enclosure(c0f76784)、标记像素(e1d2900e)

**依赖链**：标记像素沿行列延伸射线 → 射线遇到灰线段停止，与灰线段共同构成新的闭合边界 → 新闭合域被填充，颜色取决于边界上射线的颜色构成。射线步骤和填充步骤同时约束：未画射线无法知道哪些域被封闭；不知封闭域就无法确定填色。

彩色标记像素向四方射出射线直至触及灰色线段或网格边缘，射线与灰线段围成的新封闭区域按边界射线颜色填色。

**输入结构**：
- 黑(0)背景，网格约 15x15。
- 若干灰(5)一像素宽直线段（水平或垂直），散布于网格中，线段之间不完全围合——即仅靠灰线段本身不构成任何封闭背景区域。
- 2-4 个单像素标记，颜色各不相同，选自蓝(1)、绿(3)、黄(4)、橙(7)中的不同颜色。标记不在灰线段上。
- 标记位置经选择，使得从标记射出的射线遇灰线段停止后，能与灰线段共同围合出至少一个封闭背景区域。
- 生成约束：任意两个标记不在同一行且不在同一列；射线延伸后，至少存在 2 个新围合的封闭区域；每个封闭区域的边界至少包含一段彩色射线。

**规则**：
1. 对每个标记像素，沿上、下、左、右四个方向各射出一条射线。射线逐像素推进，遇到灰(5)线段像素或网格边缘时停止（停止位置的灰像素不被着色；到达网格边缘时最后一个网格内像素被着色）。射线路径上的每个黑(0)像素被涂为该标记的颜色。
2. 标记像素本身保留原色。灰(5)线段像素保持不变。
3. 若某像素同时处于两条不同颜色标记的射线路径上（两条射线交叉），该像素涂为红(2)。
4. 射线绘制完成后，在由灰(5)线段 + 彩色射线 + 红(2)交叉点 + 网格边缘共同构成的边界中，识别所有完全封闭的 4-连通黑(0)背景区域（不与网格外连通、不含任何非黑像素的连通分量）。
5. 对每个封闭区域，检查其边界上的非灰像素：
   - 若边界射线全部来自同一标记颜色（可含灰段，但非灰射线仅一种颜色）→ 用该标记颜色填充该区域。
   - 若边界射线来自两个或以上不同标记颜色 → 用红(2)填充该区域。
6. 未被封闭的黑(0)背景区域保持不变。

**关键洞察**：射线不是终态装饰，而是结构建材——它们与灰线段共同围合出输入中原本不存在的封闭域。封闭域的填色取决于"哪些标记的射线参与了围合"，需同时理解射线扩展规则和封闭判定规则才能求解。

## 新题 3：吸附排序后的图例重涂色

**组合逻辑**：[滑动吸附/nearest_cardinal_attract](已有) + [累积影响后续停靠/mass_affects_stops](已有) + [排位对应/rank_correspond](创新：排位不再由布局预定义，而是由吸附模拟的最终位置动态产生) + [图例位映射色/legend_pos_color](创新：图例颜色映射到吸附排名而非空间坐标)

**来源原语**：滑动/吸附体(4093f84a)、累积影响后续停靠(4093f84a)、最短基方向吸附(4093f84a)、排位对应/颜色图例(fafd9572)、图例位映射色(fafd9572)、碰撞阻挡(4093f84a)

**依赖链**：吸附模拟决定每个像素的最终位置 → 最终位置沿吸附体排列产生排名 → 排名索引图例获取新颜色 → 新颜色覆盖原始颜色。删除吸附环节则无法确定排名；删除图例映射则无法确定目标颜色。

散落的彩色像素被灰色长条磁吸聚拢，沿长条停靠顺序对应图例颜色后被重涂。

**输入结构**：
- 黑(0)背景，网格约 13x13。
- 一条灰(5)实心长条（1 像素宽，长 4-7 像素，水平或垂直放置），位于网格中部偏左或偏上。
- 4-7 个单像素散落在长条周围（不与长条相邻），每个像素颜色各不相同，选自蓝(1)、红(2)、绿(3)、黄(4)、品红(6)、橙(7)。
- 一条颜色图例：由 4-7 个相邻像素组成的水平或垂直色带，位于网格边缘（如底行或右列），图例中的颜色与散落像素的颜色无关，图例颜色互不相同。图例像素数等于散落像素数。
- 生成约束：每个散落像素到灰色长条的最短基方向（水平或垂直）路径上无其他前景像素阻挡（初始状态下）；灰色长条足够长，使所有像素吸附后不会溢出。

**规则**：
1. 按每个散落像素到灰色长条最近表面像素的曼哈顿距离从小到大排序。距离相同时，行号较小者优先；行号也相同时，列号较小者优先。
2. 按此顺序依次处理每个像素：找到该像素到灰色长条（含已吸附像素构成的扩展体）的最短基方向路径（仅水平或仅垂直），将像素沿该方向滑动直至与长条或已吸附像素 4-邻接。将像素放置在该停靠位置，其原始位置变为黑(0)。已停靠的像素在后续步骤中视为长条的扩展，会阻挡后续像素。
3. 所有像素停靠完成后，沿灰色长条的延伸方向（水平长条则从左到右、垂直长条则从上到下）读取停靠像素的位置序列，得到排名：最左/最上位置为排名 1，依次递增。若有像素停靠在长条的垂直方向（水平长条的上方或下方），该像素的排名按其所对应的长条列位置确定；同列有多个像素时，靠近长条的排名在前。
4. 读取颜色图例：图例第 1 个像素的颜色对应排名 1，第 2 个对应排名 2，依此类推。
5. 将每个停靠像素重涂为其排名所对应的图例颜色。
6. 灰色长条保持灰(5)不变。颜色图例保持不变。

**关键洞察**：图例颜色并非按原始像素颜色或位置映射，而是按吸附后沿长条的空间排名映射。先到达的像素会改变后续像素的停靠位置，因此吸附顺序（由初始距离决定）间接影响排名分配——需模拟完整吸附过程才能确定最终颜色。

## 新题 4：同色计数驱动的同心生长与碰撞裁决

**组合逻辑**：[计数/counting](创新：计数结果不再用于排序输出，而是作为生长层数的参数) + [生长/grow](创新：生长层数由外部统计量决定而非固定) + [碰撞阻挡/collision_blocking](创新：碰撞裁决规则引入原始边长作为优先级)

**来源原语**：计数/按数量排序(b1986d4b)、忽略非正方形(b1986d4b)、生长/同心正方形层(3befdf3e)、碰撞阻挡(4093f84a)、忽略干扰项(b1986d4b)

**依赖链**：识别正方形并按颜色计数 → 计数值决定每个正方形的生长层数 → 生长过程中不同正方形的扩展区域可能冲突 → 碰撞裁决根据原始边长确定优先级。删除计数则无法确定生长量；删除碰撞裁决则重叠区域颜色不确定。

每个彩色实心正方形按同色兄弟数量向外生长同心边框层，扩展重叠时大正方形优先覆盖。

**输入结构**：
- 黑(0)背景，网格约 18x18。
- 4-8 个实心单色正方形，使用 3-4 种颜色，选自蓝(1)、红(2)、绿(3)、黄(4)、橙(7)。每种颜色出现 1-3 次。正方形边长 2-3 像素。正方形之间互不相邻（初始状态下最近正方形之间至少隔 3 像素）。
- 2-3 个非正方形干扰体：不规则 4-连通单色小图形（2-5 像素），颜色选自品红(6)或栗(9)，散布于网格中。
- 生成约束：每种正方形颜色至少出现 1 次；至少有一种颜色出现 2 次以上（确保存在生长行为）；正方形之间留足空间使生长层有可展开的余地，但至少有一对正方形的生长区域会发生重叠。

**规则**：
1. 擦除所有非正方形干扰体（品红(6)或栗(9)的不规则图形 → 替换为黑(0)）。判断标准：4-连通分量的边界框不是正方形，或边界框内有黑(0)空洞。
2. 对每种颜色 C，计算颜色为 C 的正方形个数，记为 N(C)。
3. 对每个颜色为 C 的正方形，向外生长 (N(C) - 1) 层同心一像素宽边框。边框颜色按层交替：第 1 层（紧贴原正方形）= 颜色 C，第 2 层 = 灰(5)，第 3 层 = 颜色 C，第 4 层 = 灰(5)，依此交替。若 N(C) = 1，则不生长（0 层边框）。
4. 碰撞裁决：若两个正方形的生长区域（含原始正方形本身）重叠于某像素，该像素归属原始边长较大的正方形。若原始边长相同，归属中心点距网格中心（行列各取中值）曼哈顿距离较小的正方形。
5. 生长层超出网格边缘的部分裁剪丢弃。
6. 黑(0)背景中未被生长覆盖的区域保持不变。

**关键洞察**：正方形的生长幅度取决于全局统计量（同色兄弟总数），而非自身属性——孤立颜色的正方形完全不生长，而同色兄弟多的正方形大幅扩展。碰撞区域的归属由原始尺寸决定，需同时掌握计数规则和碰撞规则才能确定每个像素的最终颜色。

## 新题 5：周期平铺的同源合流与异源冲突

**组合逻辑**：[周期平铺/periodic_tiling](已有) + [邻接侧决定方向/adjacency_side_determines_dir](已有) + [碰撞阻挡/collision_blocking](创新：十字体本身充当阻断墙) + [异源交叉特殊着色/cross_source_special_color](创新：同源重叠与异源重叠产生截然不同的颜色)

**来源原语**：周期平铺/十字图案/标记块(53fb4810)、邻接侧决定方向(53fb4810)、不覆盖源对象(53fb4810)、碰撞阻挡(4093f84a)、异源交叉特殊着色(45bbe264)、行列交叉(45bbe264)

**依赖链**：标记块邻接位置确定平铺方向 → 平铺向网格边缘或遇其他十字体时停止（碰撞阻挡） → 多条平铺带在远处交叉时根据是否同源产生不同颜色（同源合流 vs. 异源冲突）。所有平铺带必须同时计算才能判定交叉类型。

十字体臂端的彩色标记块沿臂方向周期平铺至边缘，同源重叠合为灰色、异源重叠变为红色。

**输入结构**：
- 黑(0)背景，网格约 20x20。
- 2-3 个灰(5)十字(+)形锚点，每个由 5 像素组成（中心 + 上下左右各 1 像素），十字体之间距离至少 6 像素。
- 每个十字体的 2-4 个臂端（非全部 4 个臂都必须有标记）各紧邻一个 1x1 单像素彩色标记块。标记块颜色选自蓝(1)、绿(3)、黄(4)、橙(7)，同一十字体的不同臂端标记颜色可相同或不同，不同十字体的标记颜色可相同或不同。标记块与臂端 4-邻接，且位于臂的延伸方向上（即标记在十字体外侧，而非内侧）。
- 生成约束：至少存在一对来自不同十字体的标记，其平铺方向互相垂直且路径会相交；至少存在一对来自同一十字体的标记，其平铺带会在远处某像素重叠。

**规则**：
1. 对每个标记块，确定其所属十字体及所邻接的臂（北/南/东/西臂）。标记的平铺方向 = 该臂从十字中心指向外侧的方向（即标记远离十字体的方向）。
2. 从标记块的位置开始，沿平铺方向逐像素推进，每隔 2 像素放置一个标记颜色像素（即标记本身为第 1 个，跳过 1 个像素后放置第 2 个，再跳过 1 个放第 3 个......周期为 2）。放置持续至以下任一条件终止：
   - 到达网格边缘（最后一个网格内像素仍可放置）。
   - 下一个放置位置落在某个十字体(灰(5))像素上：不放置，在该像素前一个周期位置停止。
3. 十字体像素永远不被覆盖。
4. 重叠裁决——若某像素被多条平铺带同时要求放置：
   - 所有相关标记块属于同一个十字体 → 该像素涂为灰(5)（同源合流）。
   - 相关标记块分属不同十字体 → 该像素涂为红(2)（异源冲突）。
   - 若同时存在同源和异源 → 红(2)优先（异源冲突覆盖同源合流）。
5. 标记块本身保留其原始颜色（即使处于"第 1 个放置位置"，也不被同源/异源规则覆盖）。

**关键洞察**：同一十字体两条臂的平铺带在远处交汇时融合为灰色（表示"同源汇合"），而不同十字体的平铺带交汇时变为红色（表示"冲突"）。求解者必须追踪每条平铺带的归属才能确定交叉点颜色，仅靠局部信息无法判定。

## 新题 6：裂缝诱导的分块反转

**组合逻辑**：[反转编码/invert_code](已有) + [分裂/split_along_short](创新：分裂不再作用于前景对象，而是对块网格中的单个块施加内部切割) + [精灵与空白互逆/sprite_blank_inv](创新：半块级别的反转，每半独立判定)

**来源原语**：反转编码/块网格/重复精灵体/均匀空白块(6350f1f4)、精灵与空白互逆(6350f1f4)、通配符视为空(6350f1f4)、分裂/裂缝标记线(2faf500b)、沿短轴分裂(2faf500b)、两侧等距分离(2faf500b)

**依赖链**：推断重复精灵体图案 → 判断每个块是精灵还是空白 → 对无裂缝块执行整块反转 → 对有裂缝块先沿裂缝切半再对每半独立反转并插入间隔行/列。裂缝改变了反转的粒度单位，精灵推断是一切反转的前提。

块网格中精灵块与空白块互换，但含红色裂缝线的块被一分为二后各半独立反转并隔开。

**输入结构**：
- 网格约 15x15，由黑(0)分隔行和分隔列将网格划分为 3x3 排列的等尺寸正方形块（每块约 4x4 像素，分隔条宽 1 像素）。
- 每个块要么是一个固定的双色精灵体的副本（精灵体使用蓝(1)作为主体色、黄(4)作为少数色），要么是黄(4)均匀填充的空白块。精灵体图案在所有精灵块中相同。
- 恰好 1-2 个块内部有一条红(2)一像素宽的裂缝线，水平或垂直穿过块的中间位置。裂缝线将该块分为上下两半或左右两半（沿块的较短维度方向切割；若块为正方形则水平切割）。
- 部分像素可能被灰(5)替代（作为擦除/通配符），出现在精灵块或分隔条上，数量 1-3 个。
- 生成约束：至少有 2 个完整可见的精灵块（无灰像素），用于推断精灵图案；裂缝块的裂缝位置恰在块的中间行或中间列。

**规则**：
1. 从完整可见的精灵块推断重复精灵体图案。灰(5)像素视为通配符，匹配精灵或空白块中的任何颜色。
2. 对不含裂缝的块执行标准反转：
   - 精灵块（匹配推断的精灵图案，忽略灰通配符）→ 输出为蓝(1)均匀填充的实心块。
   - 空白块（黄(4)均匀，忽略灰通配符）→ 输出为精灵图案的副本。
3. 对含裂缝的块：
   a. 移除裂缝线（红像素 → 黑(0)）。
   b. 将该块沿裂缝位置切分为两半。
   c. 对每半独立判断：该半块的像素模式与精灵图案对应半区匹配 → 该半输出为蓝(1)均匀填充的半块；该半块为黄(4)均匀 → 该半输出为精灵图案对应半区的副本。灰像素按通配符处理。
   d. 两半之间插入一行（水平裂缝）或一列（垂直裂缝）黑(0)间隔。
4. 所有分隔行/列（含其上的灰通配符）输出为黑(0)。
5. 裂缝引入的额外间隔行/列使含裂缝块所在的行组或列组比其他行组/列组多 1 像素宽。输出网格尺寸相应增大。

**关键洞察**：裂缝不仅在视觉上切开块，更将反转的操作粒度从"整块"细化为"半块"。一个精灵块被裂缝切分后，两半可能分别匹配精灵的不同半区，独立反转后产生出在完整反转中不可能出现的非对称输出。需先推断精灵才能判断每半的反转结果。

## 新题 7：轴邻计数门控的晶格带涂色

**组合逻辑**：[标记行列选择/marker_row_column_selection](创新：选择哪些带被涂色不再无条件，而由轴邻接关系的统计量门控) + [计数/counting](创新：计数对象不是独立物体的数量，而是标记之间的轴共享关系数) + [重涂色/recolor](创新：孤立标记被降级重涂而非简单保留)

**来源原语**：标记行列选择/晶格网格/标记块(4f537728)、行列带穿越标记(4f537728)、计数/按数量排序(b1986d4b)、重涂色(4f537728)、碰撞阻挡(4093f84a)

**依赖链**：识别所有标记块并计算每个标记的轴邻居数 → 轴邻居数决定该标记涂色的范围（全十字带/单带/降级为灰） → 多个标记的涂色范围可能重叠，重叠裁决需比较轴邻居数。整个推理需全局关系图才能完成。

晶格中嵌入的彩色标记块按其与其他标记共享行列带的数量决定涂色范围：连接多则全带投射、连接少则局部涂色、完全孤立则褪为灰色。

**输入结构**：
- 黑(0)背景，网格约 16x16。
- 蓝(1)晶格：一像素宽的规则网格线（水平线和垂直线），形成约 4x4 或 5x5 的矩形格子，每个格子内部约 3x3 像素。
- 3-5 个 2x2 彩色标记块嵌入在晶格的不同格子位置。标记颜色互不相同，选自红(2)、绿(3)、黄(4)、橙(7)、品红(6)。标记块占据格子内部的左上 2x2 区域。
- 生成约束：至少一个标记与 2 个以上其他标记共享行带或列带（高连接度）；至少一个标记不与任何其他标记共享行带或列带（完全孤立）；至少存在一处涂色带重叠。

**规则**：
1. 对每个标记块 M，计算其"轴邻居数" A(M)：在所有其他标记块中，与 M 共享至少一个行带（标记块所在的两行中有重叠）或至少一个列带（标记块所在的两列中有重叠）的标记数量。每个邻居只计一次，即使同时共享行带和列带。
2. 根据 A(M) 确定涂色行为：
   - A(M) >= 2（高连接度）：将 M 所在两行和两列中所有蓝(1)晶格像素涂为 M 的颜色（全十字带投射）。
   - A(M) = 1（低连接度）：仅涂 M 与其唯一轴邻居共享的那条带（若共享行带则涂 M 的两行中的蓝像素，若共享列带则涂 M 的两列中的蓝像素；若同时共享行带和列带，则涂行带）。
   - A(M) = 0（孤立）：将 M 自身的 2x2 标记块重涂为灰(5)，不涂任何晶格带。
3. 涂色重叠裁决：若某蓝(1)像素处于两个标记的涂色范围内，涂为 A 值较大的标记颜色。A 值相同时，涂为其 2x2 标记块中心点距网格中心曼哈顿距离较小的标记颜色。
4. 未被涂色的蓝(1)晶格像素保持蓝(1)。黑(0)背景保持不变。

**关键洞察**：每个标记的投射范围取决于它与其他标记的全局连接关系——这是一个图论问题（标记为节点，共享轴为边），无法通过逐个标记的局部分析求解。孤立标记不仅不投射，还被"降级"失去原色，需对比不同示例中孤立与非孤立标记的行为才能归纳出降级规则。

## 新题 8：形状匹配筛选后的精灵拼合与目标色继承

**组合逻辑**：[归一化形状比对/normalized_shape_matching](创新：匹配不再直接触发重涂，而是作为筛选门控决定哪些精灵参与拼合) + [精灵填入孔洞/sprites_fill_holes + 精灵精确拼合孔洞/sprites_exactly_tile_holes](创新：拼合对象不再是所有源精灵，而是经模板筛选后的子集) + [重涂色/recolor](创新：精灵拼入后继承目标大对象的颜色而非保留原色)

**来源原语**：归一化形状比对/模板对象(4ff4c9da)、匹配模板则重涂(4ff4c9da)、精灵填入孔洞/封闭孔洞/源精灵体(184a9768)、精灵精确拼合孔洞(184a9768)、擦除/标记噪声(184a9768)、重涂色(fafd9572)

**依赖链**：模板形状筛选出参与拼合的精灵子集 → 筛选后的精灵集必须恰好拼合所有孔洞 → 拼入后精灵颜色继承宿主大对象颜色。筛选步骤的正确性直接决定拼合是否可行：错选一个精灵则拼合无解。

用青色模板的形状从散布精灵中筛选出参与者，将它们平移拼入大型对象的孔洞中，拼入后重涂为宿主颜色。

**输入结构**：
- 黑(0)背景，网格约 18x18。
- 2-3 个大型单色对象（每个由单一颜色的 4-连通像素集构成，面积 20-40 像素），颜色分别为蓝(1)、红(2)、绿(3)中的不同颜色。每个大对象内部有 1-2 个封闭背景孔洞（被大对象像素完全包围的 4-连通黑(0)区域，面积 3-8 像素，形状不规则）。
- 6-10 个小型源精灵体散布在大对象外部，每个为 4-连通单色小图形（3-8 像素），颜色选自黄(4)、橙(7)、品红(6)。
- 1-2 个青(8)模板精灵体，也在大对象外部，每个为 4-连通图形（3-6 像素）。
- 2-4 个灰(5)孤立噪声像素散布于网格各处。
- 生成约束：在所有非青、非灰源精灵中，恰有一部分精灵的归一化形状（平移归一后的像素掩模，使用 4-连通）与某个青色模板匹配；这些匹配精灵的形状集恰好能唯一地精确拼合（partition）所有大对象孔洞的全部像素，每个精灵用恰好一次，不旋转；不匹配的精灵是多余的干扰项。

**规则**：
1. 识别青(8)模板精灵体，提取其归一化形状（平移至原点后的像素掩模集）。
2. 对每个非青(8)、非灰(5)的源精灵体，检查其归一化形状是否与任一青色模板匹配。匹配者标记为"参与者"，不匹配者标记为"干扰项"。
3. 识别所有大型对象内部的封闭背景孔洞。
4. 将所有"参与者"精灵（仅平移，不旋转不翻转）填入孔洞，使每个参与者恰好覆盖某个孔洞的一部分像素、所有参与者合起来恰好覆盖所有孔洞的全部像素（精确拼合）。
5. 拼入后，每个参与者的颜色被替换为其所填入的那个大对象的颜色。
6. 擦除所有"干扰项"精灵（替换为黑(0)）。擦除所有灰(5)噪声像素。擦除青(8)模板精灵体。
7. 大对象像素保持不变。未被覆盖的黑(0)背景保持不变。

**关键洞察**：模板匹配是拼合的前置过滤器——并非所有精灵都参与拼合，只有形状与模板一致的才有资格。如果不先做模板筛选就尝试拼合，多余的干扰精灵会导致拼合问题无解或多解。拼入后的颜色继承使输出中看不到精灵原色，需从多个示例推断"填入后变为宿主色"这一非显然规则。

## 新题 9：间隙修复顺序决定视线路径的滑动聚合

**组合逻辑**：[间隙填充/gap_fill](已有) + [端点朝向/endpoint_facing](已有) + [滑动/slide_to_nearest_block](创新：滑动路径受间隙填充结果影响——先修复的线段可能阻断后续视线) + [标记归属最近线/marker_assigned_to_nearest_line](创新：标记的最终颜色由滑动终点附近的线段颜色决定)

**来源原语**：间隙填充/端点朝向/线段网络(faa9f03d)、标记归属最近线(faa9f03d)、视线对齐/滑动(e1d2900e)、沿视线移至近块旁(e1d2900e)、最近邻(e1d2900e)、实心方块(e1d2900e)

**依赖链**：按稀有度排序修复线段间隙 → 修复后的线段改变网格中的障碍分布 → 标记像素的视线路径受新障碍影响 → 标记滑向最近灰色方块后，依据终点位置附近的线段颜色被重涂。间隙修复和标记滑动共享同一空间，修复顺序实质性改变标记的可达性。

先按线段稀有度修复断裂线段的间隙，再将红色标记沿视线滑向灰色方块，标记到达后按最近线段颜色重涂。

**输入结构**：
- 黑(0)背景，网格约 16x16。
- 3-4 种颜色的一像素宽水平或垂直线段（每段长 3-8 像素），每种颜色 2-4 段。线段颜色选自蓝(1)、绿(3)、黄(4)、橙(7)。同色线段之间可能存在间隙（同行或同列，端点相向，间隙 1-3 像素宽，间隙内仅有黑(0)背景）。不同色线段不在同一行或列上。
- 2-3 个灰(5)实心 2x2 方块散布在网格中。
- 3-5 个红(2)单像素标记散布在网格中，不在任何线段或方块上。
- 生成约束：至少有两种颜色的线段存在待修复间隙；至少一个红色标记的视线路径（到某个灰方块）会被某条间隙修复后的线段阻断（即修复前视线通畅，修复后视线被截断，标记必须改走其他方向）；每个红色标记至少有一条到某灰方块的视线在所有修复完成后仍然通畅。

**规则**：
1. 间隙修复阶段——按线段颜色的总像素数从少到多排序（最稀有颜色优先）。像素数相同时，颜色编号较小者优先。对每种颜色：找到同行或同列中两条该色线段端点相向且间隙内无非背景像素的配对，将间隙像素填为该色。每个间隙独立填充，填充后新增的像素在后续步骤中视为线段的一部分。
2. 标记滑动阶段——对每个红(2)标记像素，沿上下左右四个方向检查是否有到灰(5) 2x2 方块的无遮挡视线（路径上无非背景像素）。选择距离最近的方块（曼哈顿距离）。将标记沿该方向滑动至与目标方块 4-邻接的位置。原位置变为黑(0)。若某标记无任何无遮挡视线到任何方块，该标记保留在原位不动，保持红(2)。
3. 对每个成功滑动的标记：找到距其最终停靠位置曼哈顿距离最近的线段像素（任何颜色），将该标记重涂为该线段的颜色。距离相同时选择线段总像素数较少的颜色（稀有优先）。
4. 灰(5)方块保持不变。所有线段（含修复的间隙段）保持其颜色。

**关键洞察**：间隙修复的处理顺序决定了哪些空间被线段占据，进而改变红色标记能看到的视线路径。若修复顺序不同，某些标记可能滑向不同方向的方块，最终获得不同的颜色。需对比示例发现"稀有颜色优先修复"以及"修复阻断视线"两条隐蔽规则。

## 新题 10：控制像素递归印章内的封闭域面积填色

**组合逻辑**：[像素放大 + 递归印章/pixel_scaling + recursive_stamp](已有) + [洪泛填充/flood_fill + 面积决定填充色/area_determines_fill_color](创新：面积填色不作用于原始输入，而是作用于递归印章产生的内层图案中的孔洞) + [格位映射/cell_block_mapping](已有)

**来源原语**：像素放大/控制像素/输入图案(cce03e0d)、递归印章(cce03e0d)、格位映射(cce03e0d)、洪泛填充/封闭区域(c0f76784)、面积决定填充色(c0f76784)、包围(c0f76784)

**依赖链**：控制像素位置决定哪些块被印章 → 印章后的内层图案中出现封闭孔洞 → 孔洞面积决定填充颜色。未执行印章则无孔洞可填充；不知道控制像素位置就无法确定印章位置。

小图案中的红色控制像素在放大后的对应块位置递归印章完整图案，印章副本内部的封闭背景孔洞按面积填色。

**输入结构**：
- 一个小型输入网格（4x4 或 5x5），黑(0)背景。
- 图案使用 2-3 种非黑颜色。其中红(2)像素为控制像素（2-4 个），其余为蓝(1)、绿(3)等装饰像素。
- 图案的非黑像素构成一个或多个 4-连通结构，且结构内部存在 1-3 个封闭背景孔洞（完全被非黑像素包围的 4-连通黑(0)区域，面积 1-3 像素）。
- 生成约束：控制像素数量 >= 2；图案中至少有一个面积为 1 和一个面积 >= 2 的封闭孔洞（确保面积映射产生不同颜色）；控制像素本身不参与围合孔洞（移除控制像素不会破坏孔洞的封闭性）。

**规则**：
1. 像素放大：创建输出网格，尺寸 = 输入尺寸 x 输入尺寸（如输入 4x4 → 输出 16x16）。输入的每个像素对应输出中一个与输入同尺寸的块（如 4x4 块）。
2. 块填充规则：
   - 红(2)控制像素对应的块：用完整输入图案的副本填充（递归印章），副本中的红(2)像素保持红(2)不再递归（仅一层递归）。
   - 非红非黑前景像素对应的块：整块填充为该像素的颜色。
   - 黑(0)背景像素对应的块：整块填充为黑(0)。
3. 对输出网格中每个递归印章块内部：识别其中的封闭背景孔洞（完全被该块内非黑像素包围的 4-连通黑(0)区域）。按面积填色：
   - 面积 1 像素 → 黄(4)
   - 面积 2 像素 → 橙(7)
   - 面积 3 像素 → 品红(6)
4. 非印章块内部无孔洞（整块单色），不需要填充操作。
5. 红(2)控制像素在印章副本中保持红(2)（它们不变色，也不触发进一步递归）。

**关键洞察**：面积填色操作不作用于输入网格，而是作用于像素放大后由递归印章创造出的"内层世界"。同一个图案在输入中有孔洞但不填色，在输出的印章副本中同样的孔洞则被填色——两个尺度级别的同一结构有不同的处理方式。控制像素同时担任两个角色：在宏观层面决定哪些块被印章，在微观层面作为印章副本中的红色像素存在。
