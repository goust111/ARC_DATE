## 新题 1：镜像封腔洪泛填色

**组合逻辑**：[对称补全/symmetry_completion](创新：补全目的不是输出修复后的图案，而是封闭开放区域) → [洪泛填充/flood_fill](已有) + [种子像素/seed_pixel → 连通可达/connectivity_reachable](创新：种子通过墙壁外侧8-连通路径认领腔体)

**来源原语**：对称补全(9ecd008a), 洪泛填充(8b7bacbf), 种子像素(8b7bacbf), 封闭腔体(8b7bacbf), 连通可达(8b7bacbf), 镜像(9ecd008a)

**依赖链**：对称补全封闭墙壁缺口 → 产生原本不存在的封闭腔体 → 种子像素沿墙壁外侧连通路径认领腔体 → 洪泛填充腔体。删除对称补全则无封闭腔体；删除种子像素则无法确定腔体颜色；删除洪泛填充则无法着色。

将近似左右对称的墙壁图案补全以封闭开放区域，再由边界种子像素沿墙壁连通路径认领并填充各个新生腔体。

**输入结构**：约 15x15 网格，黑(0)背景。蓝(1)像素构成一组线段式墙壁，整体呈近似左右镜像对称的图案（对称轴为网格竖直中线）。对称性被故意破坏：右半区有 3~5 个墙壁像素被替换为黑(0)，形成缺口；这些缺口使得若干本应封闭的区域与外界连通。网格最上行或最下行的边界上放置 2~3 个互不同色的种子像素（从红(2)、绿(3)、黄(4)中选取），每个种子像素紧邻一段墙壁。生成约束：(a) 补全镜像后恰好封闭出与种子数量相同的腔体；(b) 每个种子沿墙壁外侧 8-连通路径恰好可达唯一一个腔体的边界；(c) 缺口仅出现在对称轴的一侧。

**规则**：
1. 找到蓝(1)墙壁图案的竖直镜像对称轴（网格水平中线列）。
2. 对于对称轴一侧每个黑(0)单元格，若其镜像位置为蓝(1)，则将该单元格也填为蓝(1)，完成镜像对称补全。此步骤封闭此前开放的区域，产生若干封闭腔体（4-连通的黑(0)区域，完全被蓝(1)墙壁包围，不触及网格边界）。
3. 对于每个种子像素 S，从 S 出发沿蓝(1)墙壁像素做 8-连通搜索（仅经过蓝(1)像素），找到所有与 S 的 8-连通墙壁路径相邻的封闭腔体——即腔体边界至少有一个蓝(1)像素属于从 S 可达的墙壁连通区域。每个腔体恰好被唯一一个种子认领。
4. 将每个被认领的腔体内所有黑(0)像素填为对应种子的颜色。
5. 移除所有种子像素（恢复为黑(0)）。输出完整网格。

**关键洞察**：墙壁缺口不是损坏——它们是故意设计的：只有完成镜像补全才能封闭腔体，而腔体的存在是洪泛填充的前提。求解者必须先识别近似对称性并补全，才能理解填充规则。

## 新题 2：连通分量计数编码为水平条长度

**组合逻辑**：[连通检测/connected_component_detection](已有) → [计数/counting](创新：统计的不是同行像素数，而是全局拓扑属性——同色连通分量个数) → [连线/draw_line](创新：条长度由分量计数决定而非两侧邻居计数)

**来源原语**：连通检测(3194b014), 计数(2a28add5/6e02f1e3), 连线/draw_line(6e02f1e3/3bd67248), 控制像素(2a28add5), 筛选/filtering(3194b014), 忽略干扰项(3194b014)

**依赖链**：对每种颜色做连通检测得到分量数 → 分量数编码为对应控制像素的水平条长度 → 绘制条。删除连通检测则条长度无法确定；删除控制像素则不知道哪种颜色对应哪根条；删除绘制则无输出。

统计上半区每种颜色的4-连通分量个数，以此长度从下半区对应色控制像素处向右绘制灰色水平条。

**输入结构**：约 18x12 网格，黑(0)背景。网格被一条灰(5)水平分隔线（占据某一完整行）分为上半区和下半区。上半区散布着若干小型单色对象（每个对象 3~6 像素，4-连通，形状不规则且各不相同），使用 2~3 种非黑非灰颜色（从红(2)、绿(3)、蓝(1)中选取）。同色对象可能有多个，分散在上半区不同位置，彼此不4-连通。下半区（分隔线之下 2~3 行）每种对应颜色恰好有一个控制像素，各控制像素位于不同行、不同列，互不相邻。生成约束：(a) 每种颜色在上半区至少有 1 个、至多 5 个 4-连通分量；(b) 不同颜色的分量数互不相同；(c) 下半区除控制像素外无其他非黑非灰像素。

**规则**：
1. 识别灰(5)分隔线，将网格分为上半区和下半区。
2. 对上半区每种非黑非灰颜色 C，计算其 4-连通单色分量的个数 → N_C。
3. 在输出中，擦除上半区所有像素（设为黑(0)）并擦除灰(5)分隔线。
4. 对下半区每个控制像素（位于第 r 行、第 c 列、颜色为 C），从 (r, c) 开始向右绘制一条灰(5)水平条，长度恰好为 N_C 个像素（即覆盖列 c 至 c + N_C - 1）。控制像素本身被灰(5)覆盖，成为条的起始端。
5. 若条超出网格右边界，截断至边界（不换行）。输出完整网格。

**关键洞察**：上半区的彩色对象本身不被保留——唯一被提取的信息是每种颜色的碎片化程度（分量个数），而非总像素数或面积。看上去面积很大的颜色，如果只形成一个分量，条长度仅为 1。

## 新题 3：角标裁剪区域内的同心距离色带

**组合逻辑**：[角标记像素/corner_marker + 裁剪/crop](已有) → [距离决定调色板/distance_determines_palette + 循环色带/cyclic_color_bands](创新：裁剪边界同时定义距离原点，标记像素深度编码调色板顺序，角标色本身成为调色板首色)

**来源原语**：角标记像素(3de23699), 裁剪/crop(3de23699), 内部包含/containment(3de23699), 同心正方形层(13e47133), 距离决定调色板(13e47133), 标记像素(13e47133), 循环色带(13e47133)

**依赖链**：角标记定义裁剪边界 → 裁剪边界即为同心距离的零号边界 → 角标色成为调色板首位 → 内部标记深度确定后续调色板位 → 循环色带向内辐射。删除角标则无法裁剪也无法确定首色；删除内部标记则调色板不完整；删除距离填充则无输出图案。

用角标记定义裁剪区域并提取内部图案，然后以裁剪边界为零距面、角标色为首色，结合内部标记像素的深度顺序构建循环调色板，向内辐射同心矩形色带。

**输入结构**：约 18x18 网格，黑(0)背景。一个灰(5)为主色的非黑像素簇占据网格中部。簇的四角各有一个红(2)像素作为角标记，它们恰好标出一个矩形边框（角标位于边框的四个角上）。边框内部（不含边框本身）是一块以灰(5)为底色的区域（约 8x10），其中散布 2~3 个孤立标记像素，颜色各不相同（从绿(3)、蓝(1)、黄(4)中选取），每个标记像素到裁剪边界的切比雪夫距离互不相同。簇外部可能有少量黑(0)背景上的干扰像素（随机颜色，不超过 3 个）。生成约束：(a) 角标恰好 4 个且同色；(b) 内部标记的切比雪夫距离两两不同且均 >= 1；(c) 内部无重复颜色的标记。

**规则**：
1. 定位四个红(2)角标记像素，确定它们围成的矩形区域。
2. 去除外层一圈边框（角标所在行列），提取内部矩形作为工作区（大小为原矩形减去上下左右各一行/列）。
3. 构建调色板：首位为角标色红(2)（切比雪夫距离 0，即紧贴裁剪边界的那一层）。然后按内部各标记像素到工作区边界的切比雪夫距离从小到大排序，依次将其颜色追加到调色板。
4. 对工作区内每个单元格，计算其到工作区边界的切比雪夫距离 d，将颜色设为 palette[d mod len(palette)]。
5. 忽略所有干扰像素。输出仅为重新着色后的工作区（裁剪后的矩形）。

**关键洞察**：角标记同时承担两个角色——标定裁剪范围和提供调色板首色。内部的孤立标记像素不是需要保留的对象，而是通过自身深度位置编码调色板顺序的指令。

## 新题 4：旋转绿色层后格子追踪与交叉混色

**组合逻辑**：[旋转/rotate](创新：仅对一种颜色的标记位置做格子坐标系内旋转，不旋转整个画布) + [连线/trace](已有) + [双色交叉混合色/intersect_blend_color](创新：交叉发生在原始红布局与旋转后绿布局之间)

**来源原语**：格子单元(e760a62e), 共行或共列(e760a62e), 连线/trace(e760a62e), 双色交叉混合色(e760a62e), 旋转/rotate(ed36ccf7), 标记像素(e760a62e), 网格线(e760a62e)

**依赖链**：绿色标记在格子坐标中旋转90度 → 旋转后的绿色位置参与追踪 → 红色原位追踪 → 两色追踪区域交叉处涂混合色。删除旋转则绿色追踪走向错误；删除追踪则无填充；删除混色规则则交叉区颜色不确定。

在格子坐标系中将绿色标记旋转90度后再做行列追踪，红色标记原位追踪，两色追踪区域交叉处涂黄色混合色。

**输入结构**：15x15 网格，黑(0)背景。青(8)线条将画布划分为 4x4 的正方形格子阵列（每个格子内部为 3x3 的黑(0)区域，格子间由 1 像素宽的青(8)网格线分隔；网格总尺寸 = 4*3 + 3*1 = 15）。若干格子内部中心放置红(2)标记像素（2~3 个），另有若干格子内部中心放置绿(3)标记像素（2~3 个）。无格子同时含两种标记。生成约束：(a) 格子阵列严格正方形（4x4）；(b) 红色标记至少有一对共享同一格子行或同一格子列；(c) 绿色标记在旋转后至少有一对共享同一格子行或同一格子列；(d) 旋转后的绿色标记不与红色标记占据相同格子。

**规则**：
1. 将格子阵列视为 4x4 的抽象坐标系，行列编号 0~3。
2. 红(2)标记保持原始格子坐标不变。对同一格子行中至少有两个红色标记的行，在该行最左和最右红色标记之间（含端点）的所有格子内部填充红(2)。对同一格子列中至少有两个红色标记的列，同理纵向填充。
3. 将每个绿(3)标记的格子坐标 (r, c) 变换为 (c, 3-r)（即在 4x4 坐标系中顺时针旋转 90 度）。以旋转后的坐标为准，按与红色相同的规则追踪并填充绿(3)。
4. 若某格子同时被红色追踪和绿色追踪覆盖，该格子内部改填黄(4)。
5. 所有填充仅作用于格子内部（3x3 区域），青(8)网格线始终保留不变。输出完整网格。

**关键洞察**：绿色标记的追踪路径不是从其输入位置出发，而是从旋转后的位置出发。求解者必须先在格子坐标系中完成旋转，才能正确预测绿色追踪走向和交叉位置。仅看单个示例可能误以为绿色也原位追踪。

## 新题 5：腔体计数决定模板平铺次数

**组合逻辑**：[洪泛填充/flood_fill → 封闭腔体/enclosed_cavity](创新：腔体不是被填充的目标，而是被计数的对象) + [计数/counting](创新：计数对象是拓扑结构而非像素) → [平铺/tiling](创新：平铺次数由拓扑计数决定而非固定)

**来源原语**：封闭腔体(8b7bacbf), 连通可达(8b7bacbf), 线条画(8b7bacbf), 计数(2a28add5/6e02f1e3), 模板精灵体(9b2a60aa), 平铺/tiling(9b2a60aa/eee78d87)

**依赖链**：识别线条画中的封闭腔体 → 计数腔体数量 N → 将模板精灵体水平平铺 N 次。删除腔体识别则 N 未知；删除模板则无可平铺对象；删除平铺则无输出。线条画和模板编码输出的不同维度（数量 vs. 形状）。

统计线条画围成的封闭腔体数量，以此数量将模板精灵体水平平铺。

**输入结构**：约 15x20 网格，黑(0)背景。网格由灰(5)水平分隔线分为上半区和下半区。上半区：红(2)像素构成一幅线条画（4-连通的线段网络，线宽 1 像素），围成若干封闭腔体（腔体内部为黑(0)，完全被红(2)线条和/或网格边界封闭的 4-连通黑色区域；与网格上/左/右边界相连的黑色区域不计为腔体）。下半区：一个绿(3)的小型模板精灵体（约 3x3~4x4 像素，4-连通，形状不规则，无孔洞），周围为黑(0)。生成约束：(a) 封闭腔体数量 N 在 2~5 之间；(b) 模板精灵体与线条画颜色不同；(c) 分隔线在垂直方向上将两个区域完全隔开。

**规则**：
1. 在上半区识别所有封闭腔体：4-连通的黑(0)区域，完全被红(2)像素包围且不触及上半区的上/左/右边界（但可以触及分隔线作为下边界）。统计腔体数量 → N。
2. 提取下半区的模板精灵体（其紧致边界框）。
3. 输出网格高度 = 模板高度，宽度 = N * 模板宽度 + (N-1) * 1（即 N 份模板水平排列，相邻模板间隔 1 列黑(0)）。
4. 将模板精灵体依次放置在输出网格中，从左到右，每份之间间隔 1 列。所有模板保持绿(3)原色。

**依赖链**：镜像补全填入缺失区域 → 新像素桥接原本分离的同色分量改变连通性 → 在补全后的网格上做连通检测 → 筛选恰好形成唯一分量的颜色 → 其中面积最大者决定输出色 → 输出 3x3 纯色块。删除补全则连通性不同导致错误筛选结果；删除连通检测则无法判断唯一性；删除面积选择则输出色不确定。

**输入结构**：约 11x11 网格，黑(0)背景。网格上有多种非黑颜色的前景像素（3~4 种颜色，从蓝(1)、红(2)、绿(3)、黄(4)、橙(7)中选取），构成一个整体近似左右对称的图案。图案中有一个 3x3 的矩形缺失区域（全为黑(0)），位于对称轴的一侧。在补全前，某种颜色（如绿(3)）恰好有 2 个 4-连通分量，但缺失区域的镜像对应位置包含该颜色的像素——补全后这 2 个分量将桥接为 1 个。其他颜色的分量数在补全前后不变。生成约束：(a) 补全前，没有任何颜色恰好有唯一分量且面积最大（即补全前的"正确答案"不存在或与补全后不同）；(b) 补全后，恰好有一种颜色从多分量变为唯一分量，且该颜色在"唯一分量颜色"中面积最大；(c) 缺失区域恰好 3x3。

**规则**：
1. 找到图案的竖直镜像对称轴。
2. 定位 3x3 的全黑缺失区域。对缺失区域内每个黑(0)单元格，将其替换为其关于对称轴的镜像位置的颜色（若镜像位置也是黑(0)则保持黑(0)）。
3. 在补全后的完整网格上，对每种非黑颜色统计其 4-连通分量数。
4. 筛选出分量数恰好为 1 的颜色集合 S。
5. 在 S 中选择总像素面积最大的颜色 C_out。
6. 输出一个 3x3 的纯色网格，全部填 C_out。

**关键洞察**：缺失区域的补全不仅修复了视觉对称性，更关键的是改变了某种颜色的拓扑连通性——将两个断开的分量桥接为一个。如果不补全就直接做连通检测，会选出错误的颜色。求解者必须理解"补全先于计数"这一隐含的执行顺序。
