## 新题 1：可达性门控的点对称补全

**组合逻辑**：[泛洪填充](已有) + [点对称补全](已有) + [擦除](已有) —— 泛洪填充的可达性结果决定哪些半成品图案接受对称补全、哪些被擦除（创新：可达性作为几何操作的分类门控，源题中可达性只用于描边，点对称只用于无条件补全）

**来源原语**：泛洪填充(flood_fill)、可达性(reachability)、墙壁障碍(wall_barrier)、角落标记(corner_marker) 来自 8f3a5a89；点对称补全(point_symmetry)、中心标记(center_marker)、前景图案(foreground_pattern) 来自 e729b7be；擦除(erase) 来自 8f3a5a89

**依赖链**：泛洪填充从角落标记出发确定可达区域 → 可达性将每个半成品图案分类为"保留"或"丢弃" → 点对称补全应用于保留的图案 → 擦除应用于丢弃的图案。删除泛洪填充则不知道哪些图案该补全；删除点对称则保留的图案无法复原；删除擦除则丢弃的图案残留在输出中。

从角落标记出发泛洪填充，仅对可达区域内的半成品图案做点对称补全，不可达区域的图案连同中心标记一起擦除。

**输入结构**：
- 网格约 17x17，背景黑(0)。
- 蓝(1) 像素构成 1 像素宽的墙壁线段，将网格分割为 3-5 个封闭区域。墙壁线段为 4-连通，每条线段至少有一端与网格边界相连或与另一条墙壁相连，形成密闭隔断。
- 一个品红(6) 单像素位于网格的某个角格——起始标记。
- 在 2-4 个区域内各有一个灰(5) 单像素（中心标记），以及一簇位于中心标记一侧的彩色像素（使用红(2)、绿(3) 或黄(4) 中的一种，每簇 3-8 个像素，4-连通）。每簇是一个点对称图形的"半边"——将它绕灰(5) 中心标记旋转 180 度可得完整图形的另一半。不同区域的簇使用不同颜色。
- 生成约束：每个半成品图案旋转 180 度后的目标位置全部落在同一区域内的背景格上（不与墙壁或其他图案重叠）。品红标记必须位于角格。至少一个含图案的区域从品红标记可达，至少一个不可达。

**规则**：
1. 从品红(6) 标记像素出发泛洪填充，以蓝(1) 墙壁为障碍，穿过黑(0) 背景格。记录所有可达的背景格。
2. 对每个灰(5) 中心标记：若该标记所在格可达（位于可达集合中或与可达背景格 4-连通），则对其关联的彩色半成品图案执行点对称补全——对图案中每个彩色像素，计算它绕灰(5) 中心标记旋转 180 度的位置，涂上相同颜色。
3. 对每个灰(5) 中心标记：若该标记所在格不可达，则将其关联的彩色图案像素和灰(5) 标记本身全部设为黑(0)。
4. 将品红(6) 标记像素设为黑(0)。
5. 蓝(1) 墙壁保持不变。

**关键洞察**：泛洪填充不只是装饰性操作——它的结果决定了对半成品图案施加哪种操作（补全还是擦除）。求解者必须先解决可达性问题，才能确定几何变换的方向。仅看单个示例无法确定"可达即补全、不可达即擦除"的规则方向，必须对比多个示例（交换可达/不可达区域的角色会得到不同输出）。

## 新题 2：压缩提取图案后以互补掩码印章扩展

**组合逻辑**：[压缩 + 降噪](已有) → [印章覆盖 + 自身互补](已有，重新定义作用对象) —— 压缩结果同时充当印章放置掩码和（取互补后的）印章模板（创新：一个派生图案自指地编码了下一步操作的两个独立参数——"在哪里印"和"印什么形状"，源题中压缩和印章分属不同谜题，从未交互）

**来源原语**：压缩(compress)、降噪(denoise)、网格分块(grid_partitioning)、噪声像素(noise_pixel)、忽略标记取主色(ignore_marker_dominant) 来自 5614dbcf；印章覆盖(stamp_overlay)、自身互补(self_complementary)、互补掩码(complement_mask)、前景像素(foreground_pixel)、前景位置放置瓦片(tile_at_foreground_positions) 来自 0692e18c

**依赖链**：网格分块 + 降噪将大网格压缩为小图案 → 小图案的前景位置决定哪些输出块接收印章 → 小图案的背景位置（即互补）决定印章的形状 → 印章覆盖生成输出。删除压缩则无图案可印；删除互补规则则印章形状不确定；修改压缩结果中任一块的分类同时改变印章的放置位置和形状。

将含噪声的大网格按块压缩为小图案，然后将该图案的互补形状印章到图案自身的前景位置上，生成新的扩展网格。

**输入结构**：
- 网格尺寸为 3 的倍数（如 9x9 或 12x12），可被均匀分为 3x3 的块格。
- 背景黑(0)。一种非背景、非灰的前景色（如红(2)）填满"前景块"中至少 8/9 个格。灰(5) 噪声像素零星分布，每块至多 1 个灰像素，可能出现在前景块或背景块中。
- 前景块与背景块的排列构成一个非平凡图案（非单行、单列或全填充），该图案至少有 3 个前景位置和 3 个背景位置。
- 生成约束：底层小图案既非全前景也非全背景，且不是简单的单行或单列条纹。

**规则**：
1. 将输入网格按 3x3 块分割。
2. 对每个块：若块内仅含黑(0) 和灰(5)，则该块为背景块（压缩为黑）；否则取块内唯一的非黑、非灰颜色作为该块的颜色 C。
3. 构造压缩小图案：每块映射为一个像素（前景色 C 或黑(0)）。
4. 构造输出网格，尺寸为压缩小图案的 3 倍。对小图案中的每个位置 (r, c)：
   - 若 (r, c) 为前景（非黑）：在输出中对应的 3x3 块内，用颜色 C 填充小图案中为黑的那些相对位置，其余位置保持黑(0)。即印章形状 = 小图案的互补（背景位置集合）。
   - 若 (r, c) 为背景（黑）：对应的 3x3 输出块全部为黑(0)。
5. 灰(5) 噪声不出现在输出中。

**关键洞察**：压缩后的小图案是自指的——它同时编码"在哪些块放置印章"（前景位置）和"印章长什么样"（背景位置的互补）。改变小图案中任一块的前景/背景分类，既改变了印章的放置位置集合，也改变了每个印章的形状——两者不可分离。

## 新题 3：十字射线被隐藏通道截断后通道显色

**组合逻辑**：[射线延伸 + 交叉点重置背景](已有) + [重涂色 + 背景通道检测](已有，从填充改为阻断) —— 隐藏在杂色前景中的负空间通道充当射线的物理屏障（创新：负空间检测的结果不再用于填充通道本身，而是约束了一个独立的几何扩展操作的范围，源题中通道检测和射线延伸从未交互）

**来源原语**：射线延伸(ray_extend)、实心方块(solid_block)、十字图案(cross_pattern)、行列对齐(row_col_align)、交叉点重置背景(intersect_reset_bg) 来自 e9bb6954；重涂色(recolor)、背景通道(background_corridor)、杂色前景(clutter_foreground)、区域包含(region_containment)、长矩形通道涂色(long_rectangular_corridors_filled) 来自 a64e4611

**依赖链**：通道检测识别隐藏的负空间屏障 → 射线从实心方块向外延伸但在通道边界停止 → 不同方块的十字交叉点重置为背景 → 通道被重涂为绿色。删除通道检测则射线贯穿全网格（错误输出）；删除交叉重置则重叠区域颜色错误；删除通道重涂则通道仍不可见。

实心彩色方块向外延伸十字射线，但射线在隐藏的背景通道边界处截断；不同方块的十字交叉处重置为背景；最后通道被涂成绿色。

**输入结构**：
- 网格约 20x20，背景黑(0)。
- 橙(7) 杂色像素散布全网格，构成嘈杂前景。在杂色中嵌有 1-3 条长矩形背景通道——全为黑(0) 的矩形条带，主轴至少跨越网格边长的一半，宽度至少 2 格。通道与背景同色，肉眼难以区分。
- 2-4 个实心 3x3 方块，颜色各不相同（使用红(2)、蓝(1)、黄(4) 中的 2-4 种）。方块的中心行和中心列互不重复。方块不与任何通道重叠。
- 生成约束：方块间距足够大，使得十字交叉点落在所有方块和通道之外。每个方块的中心行或中心列至少穿越一条通道（确保截断效果可观测）。

**规则**：
1. 检测隐藏通道：找出所有 3x3 邻域全为黑(0) 的背景格，在这些格中找出主轴至少跨越网格边长一半的极大矩形区域。这些区域即为通道。
2. 对每个实心 3x3 方块，从其中心行向左、向右延伸，从中心列向上、向下延伸，逐格涂上方块颜色。射线在遇到通道格时停止——不涂通道格本身，也不继续穿越通道。射线可覆盖橙(7) 杂色像素。
3. 若方块 A 的中心行与方块 B 的中心列相交于一格，且该格不在通道内，则将该格重置为黑(0)。
4. 将所有通道格重涂为绿(3)。

**关键洞察**：通道在输入中不可见（与背景同色的空隙藏在杂色中），但它们作为物理屏障决定了每条射线的终止位置。求解者必须先解决负空间检测问题，才能确定十字图案的几何形态——通道检测是几何变换的前提条件。

## 新题 4：嵌套框架深度编码周期填色相位

**组合逻辑**：[包含树 + 嵌套框架](已有) → [周期推断 + 间隙填充](已有，相位参数由深度决定) —— 框架的拓扑嵌套深度充当周期色环的相位索引（创新：拓扑深度作为数值参数驱动一个独立的周期着色系统，源题中包含树用于规范化布局而非编码数值，周期推断用于对角相位偏移而非深度索引）

**来源原语**：嵌套框架(nested_frame)、封闭区域(enclosed_region)、包含树(containment_tree)、拓扑决定布局(topology_determines_layout) 来自 2d0172a1；周期推断(periodic_inference)、间隙填充(gap_filling)、对角线相位偏移(diagonal_phase_shift)、按列周期取色(column_modular_phase) 来自 1e97544e

**依赖链**：包含树分析确定每个框架的嵌套深度 → 深度映射到色环相位 → 以对应相位的颜色填充该框架与下一层框架之间的带状区域。删除包含树分析则深度未知、相位无法确定；删除色环则填充颜色无依据。

分析嵌套矩形框架的包含树以获得每层深度，用深度作为相位偏移在色环中取色，填充每层框架之间的带状间隙。

**输入结构**：
- 网格约 15x15，背景黑(0)。
- 2-3 组相互独立的嵌套矩形框架结构，每组 2-4 层嵌套。所有框架用灰(5) 绘制，1 像素宽。框架严格嵌套（无部分重叠），相邻两层框架之间至少留 2 格间隙。
- 每组最内层区域包含 1 个单色像素（"种子"），颜色为红(2)、蓝(1)、绿(3) 或黄(4) 之一。不同组可共享种子颜色。
- 网格顶部或底部有一行位于所有框架之外的色环图例：3-4 个不同颜色的像素从左到右排列（如 红(2)、蓝(1)、绿(3)），定义颜色循环顺序。
- 生成约束：各组框架互不重叠。色环长度 n >= 3。同组内各层间隙宽度一致。

**规则**：
1. 识别所有灰(5) 矩形框架，构建包含树。为每个框架分配深度：每组最外层框架深度为 1，其内层框架深度为 2，依此递增。
2. 读取色环图例行（从左到右），记为颜色序列 cycle[0], cycle[1], ..., cycle[n-1]，长度为 n。
3. 对每个深度为 d 的框架，找出该框架内壁与下一层框架外壁之间的带状背景区域（若为最深层框架，则为框架内壁与种子像素之间的区域）。将该带状区域所有黑(0) 格涂上 cycle[(d - 1) mod n]。
4. 种子像素保持原色不变。色环图例行、灰(5) 框架保持不变。

**关键洞察**：嵌套深度不是简单的几何属性——外观上大小不同的框架可能有相同深度（属于不同组的最外层），而外观大小相近的框架可能有不同深度（一个是某组第 2 层，另一个是另一组第 1 层）。求解者必须追踪包含关系树才能确定深度，再将深度映射到在网格其他位置定义的色环——拓扑与着色之间的关联是非显然的。

## 新题 5：投票恢复精灵体后缩放填充空心框架

**组合逻辑**：[投票恢复 + 密集带检测](已有) → [缩放 + 对齐匹配](已有，模板来源改变) + [填充 + 内部区域](已有) —— 从噪声中恢复的精灵体成为缩放模板，用于填充空心矩形框架（创新：噪声复原操作的输出作为独立缩放操作的输入模板，源题中投票恢复用于清理阵列本身，缩放模板来自输入中最大对象，两者从未交互）

**来源原语**：投票恢复(majority_vote_recovery)、密集带检测(dense_band_detection)、精灵体(sprite)、插槽阵列(slot_array)、忽略干扰项(ignore_distractors) 来自 0607ce86；缩放(scaling)、对齐匹配(alignment_match)、模板(template)、指示区域(indicator_region) 来自 57aa92db；填充(fill)、空心矩形(hollow_rect)、内部区域(interior_region) 来自 d37a1ef5

**依赖链**：密集带检测定位精灵体网格 → 投票恢复从带噪副本中提取干净精灵体 → 精灵体作为模板按目标框架内部尺寸缩放 → 缩放后的精灵体填入框架内部。删除投票恢复则精灵体含噪（输出有瑕疵）；删除缩放则精灵体尺寸不匹配框架；删除框架则无目标可填。

从重复但含噪的精灵体副本中投票恢复干净精灵体，然后将其按最近邻缩放填入网格其他区域的空心矩形框架内部。

**输入结构**：
- 网格约 20x20，背景黑(0)。
- 网格上半区域：一个规则的 2x3 或 3x2 插槽阵列，每个插槽为 3x3 或 4x4 的矩形区域，包含同一精灵体的受损副本。精灵体使用红(2) 和蓝(1) 两种颜色绘制在黑(0) 背景上，每个副本有 1-2 个像素被随机替换为其他颜色或黑色。阵列外有少量散落的前景噪声像素。
- 网格下半区域：2-3 个黄(4) 绘制的空心矩形框架，1 像素厚。每个框架的内部尺寸不同，但内部宽度和高度分别是精灵体宽度和高度的正整数倍（如 2 倍、3 倍）。
- 生成约束：插槽阵列至少包含 4 个副本（保证投票可靠）。框架内部尺寸不小于精灵体。精灵体在所有副本中的结构一致（占据相同的像素位置子集），仅个别像素颜色被篡改。

**规则**：
1. 在插槽阵列区域，通过密集行带和密集列带检测定位插槽网格。每个插槽为一个精灵体大小的矩形。
2. 对精灵体矩形内的每个相对位置 (dr, dc)，取所有插槽中该位置出现最多的颜色（多数投票）。得到干净的恢复精灵体。
3. 对每个黄(4) 空心矩形框架，测量其内部尺寸 (W_i, H_i)。计算缩放因子：scale_x = W_i / 精灵体宽度，scale_y = H_i / 精灵体高度。
4. 对恢复精灵体执行最近邻缩放：精灵体中每个像素 (dr, dc) 扩展为 scale_x x scale_y 的同色块，放置在输出中对应的 (dr * scale_y, dc * scale_x) 区域。
5. 将缩放后的精灵体填入对应框架的内部区域。框架边框、框架外区域、以及上半区的插槽阵列均保持原样不变。

**关键洞察**：精灵体隐藏在噪声中——必须通过投票恢复才能获得干净模板。恢复后的精灵体承担了与其原始语境（清理阵列自身）完全不同的角色：作为缩放模板填充框架。谜题的两个空间区域（阵列区和框架区）通过恢复出的精灵体单向耦合。

## 新题 6：对侧像素相向留迹被结构墙阻断

**组合逻辑**：[滑动 + 对侧配对 + 相向移动留迹汇合](已有) + [泛洪填充 + 墙壁障碍 + 边界连通区分结构](已有，从描边改为阻断留迹) + [擦除](已有) —— 结构性墙壁截断相向移动的轨迹并偏移汇合点，装饰性墙壁被擦除（创新：墙壁分类的结果改变了一个独立运动系统的几何轨迹，源题中墙壁分类用于决定描边范围，与留迹运动从未交互）

**来源原语**：滑动(sliding)、连线(draw_line)、孤立像素(isolated_pixel)、汇合点(meeting_point)、对侧配对(opposite_pairing)、相向移动留迹汇合(inward_trails_meet_mark) 来自 29c11459；泛洪填充(flood_fill)、墙壁障碍(wall_barrier)、边界连通区分结构(border_connected_distinguishes_structural)、装饰碎片(decoration_fragment)、擦除(erase) 来自 8f3a5a89

**依赖链**：边界连通性测试将墙壁分为结构性和装饰性 → 装饰性墙壁被擦除（清理噪声） → 对侧像素对相向行进留迹，结构性墙壁阻断轨迹 → 汇合点位置因墙壁阻断而偏移。删除墙壁分类则无法区分障碍和噪声；删除擦除则装饰碎片干扰轨迹判断；删除滑动留迹则墙壁分类无用武之地。

对侧边缘的同色像素对相向行进并留下彩色轨迹，但结构性墙壁截断轨迹使汇合点偏移，装饰性墙壁碎片被擦除。

**输入结构**：
- 网格约 15x15，背景黑(0)。
- 蓝(1) 像素构成墙壁线段。部分线段的 4-连通分量触及网格边界（结构性墙壁）；其余分量完全悬浮在内部、不触及任何边界（装饰性碎片，通常 2-4 像素）。
- 2-4 对单色像素分布在网格对侧边缘（使用红(2)、绿(3)、黄(4)、橙(7)），每对共享同一行或同一列：一个像素位于左侧/顶部边缘行或列，其配对像素位于右侧/底部对应边缘行或列。
- 生成约束：每对像素的共享行或列最多穿越一段结构性墙壁。配对像素不在同侧。结构性墙壁沿轨迹方向至少 2 像素厚（阻断效果明确）。每对至少间隔 4 格以上（轨迹足够长以展示效果）。

**规则**：
1. 分类蓝(1) 墙壁像素：4-连通分量触及网格边界的为结构性墙壁，不触及的为装饰性碎片。
2. 擦除所有装饰性碎片（设为黑(0)）。
3. 对每对对侧像素（通过匹配同色、同行或同列、位于对侧边缘来识别）：
   a. 两个像素同时向对方方向逐格行进。每经过一格，将原位置涂上该像素的颜色（留下轨迹）。
   b. 若某像素的下一格是结构性墙壁格，该像素停止（轨迹终止于墙壁相邻格）。另一像素继续行进。
   c. 若两像素在无墙壁阻挡的情况下相遇，汇合格涂灰(5)。
   d. 若一个像素被墙壁阻断，另一个像素继续行进直到抵达墙壁的另一侧相邻格，该格涂灰(5) 作为偏移后的汇合标记。
4. 原始边缘像素被其轨迹覆盖（变为轨迹色）。结构性墙壁保持蓝(1)。

**关键洞察**：墙壁分类改变了轨迹的几何形态——结构性墙壁使灰色汇合标记从理论中点偏移到墙壁旁，而装饰性墙壁是必须清除的干扰项（若不清除，可能误判为障碍）。同一个连通性分析同时服务于两个目的：识别真正的障碍和识别需要擦除的噪声。

## 新题 7：边界像素编码决定空行列的填充颜色

**组合逻辑**：[重涂色 + 空行列涂标记色](已有，从固定色改为可变色) + [中心重建 + 边界像素编码](已有，从块边界改为行列边界) —— 每条空白行/列的填充颜色由其两侧的编码像素指定（创新：空行列重涂色的目标颜色不再固定，而是从网格自身的局部编码中读取，将块级别的边界编码机制迁移到行列级别，源题中空行列一律涂红，边界编码用于重建块中心，两者从未交互）

**来源原语**：重涂色(recolor)、全空行列(fully_blank_row_column)、空行列涂标记色(blank_lines_painted_marker) 来自 c1d99e64；中心重建(center_reconstruct)、边界像素编码(border_pixel_encoding) 来自 db0c5428

**依赖链**：空行列检测确定哪些行/列需要填充 → 边界像素读取为每条空行/列提取专属填充颜色 → 重涂色将每条空行/列涂上其专属颜色。删除空行列检测则不知道填充目标；删除边界编码读取则不知道涂什么颜色（颜色因行/列而异）；删除重涂色则无输出变化。

检测全空白行和列，读取每条空白行/列两侧最近的编码像素对以获取该行/列专属的填充颜色，用该颜色填充对应的空白行/列。

**输入结构**：
- 网格约 12x12，背景黑(0)。蓝(1) 前景像素构成一个不规则图案（4-连通，占据约 30-50% 的非空行列格）。
- 2-4 条全空白行（行内每格均为黑(0)）和/或 1-3 条全空白列（列内每格均为黑(0)）穿过图案。
- 对每条空白行：在该行正上方一格（row-1）和正下方一格（row+1）的某一列 c 上，各有一个非蓝、非黑的编码像素，两者颜色相同（使用红(2)、绿(3)、黄(4) 或橙(7) 之一）。列 c 是距网格水平中心最近的、在 row-1 和 row+1 上同时满足条件的列。
- 对每条空白列：在该列正左方一格（col-1）和正右方一格（col+1）的某一行 r 上，各有一个同色编码像素。行 r 是距网格垂直中心最近的满足条件的行。
- 不同空白行/列的编码颜色可以不同。
- 生成约束：编码像素不落在其他空白行/列上（避免歧义）。每条空白行/列恰好对应一对编码像素。编码像素的颜色与蓝(1) 和黑(0) 均不同。

**规则**：
1. 识别所有全空白行（每格均为黑(0)）和全空白列。
2. 对每条空白行 R：在 row = R-1 和 row = R+1 上，找距网格水平中心最近的列 c，使得 (R-1, c) 和 (R+1, c) 都是非黑、非蓝的同色像素。该颜色即为空白行 R 的填充色。
3. 对每条空白列 C：在 col = C-1 和 col = C+1 上，找距网格垂直中心最近的行 r，使得 (r, C-1) 和 (r, C+1) 都是非黑、非蓝的同色像素。该颜色即为空白列 C 的填充色。
4. 将每条空白行的所有格涂上其填充色。将每条空白列的所有格涂上其填充色。
5. 若重涂色后的空白行与空白列相交于一格，该格使用行的填充色（行优先）。
6. 编码像素本身保持不变。蓝(1) 前景图案保持不变。

**关键洞察**：与源题（所有空白行列统一涂红）不同，这里每条空白行/列携带自己的颜色指令，编码在相邻像素中。求解者不仅要检测空白行列，还要定位并解读编码像素——网格同时包含"哪里需要填"的信息和"填什么颜色"的信息，后者需要从局部几何结构中提取。仅看单个示例可能无法确定编码像素的定位规则（距中心最近），需要多个示例对比。

## 新题 8：完整方块检测生成角标记后角标记引发对角扫描轨迹

**组合逻辑**：[标记 + 完整方块才标记 + 角点邻接](已有，作为种子生成器) → [平铺/滑动 + 逐步平移 + 对角轨迹](已有，以种子点为起点) —— 完整方块检测产生的角标记成为对角扫描的起点（创新：结构完整性检测的输出不再是最终标注，而是驱动另一个几何扩展操作的种子集合，源题中角标记是终态输出，对角扫描从输入线段出发，两者从未交互）

**来源原语**：标记(marking)、完整方块(complete_square)、角外像素(corner_outside_pixel)、角点邻接(corner_adjacency)、完整方块才标记(only_complete_marked) 来自 14b8e18c；平铺(tiling)、滑动(slide)、逐步平移(stepwise_translation)、对角轨迹(diagonal_trace)、稀疏线段(sparse_line) 来自 feca6190

**依赖链**：完整方块检测筛选出合格对象 → 角标记在合格方块的四角外侧生成种子像素 → 种子像素沿各自的外向对角方向逐步平移直到网格边界，形成对角轨迹。删除完整方块检测则非方块对象也生成种子（错误位置和数量）；删除角标记则无种子可供扫描；删除对角扫描则标记只是静态点。

识别结构完整的方块对象，在其四角外侧放置种子标记，然后每个种子沿外向对角方向逐步平移至网格边界，留下对角轨迹。

**输入结构**：
- 网格约 16x16，背景黑(0)。
- 3-5 个单色 4-连通前景对象，颜色各不相同（使用蓝(1)、绿(3)、黄(4)、红(2) 中的 3-5 种）。对象的边界框大小从 2x2 到 4x4 不等。
- 部分对象是完整方块：边界框为正方形且边界框边线上每格都有该对象的颜色（填满或至少边框完整）。其余对象为不完整形状（缺角、矩形条、不规则轮廓等）。
- 生成约束：完整方块彼此之间、以及与网格边界之间至少间隔 3 格（保证对角轨迹不会立即碰到另一个对象）。至少 2 个对象是完整方块，至少 1 个不是。

**规则**：
1. 识别完整方块对象：边界框为正方形（宽 = 高）且边界框边线上每格都被该对象颜色填充的 4-连通单色对象。不完整对象和非方块对象忽略。
2. 对每个颜色为 C 的完整方块，定位其四个角格（左上、右上、左下、右下）。
3. 对每个角格确定外向对角方向：左上角 → 左上方 (-1, -1)；右上角 → 右上方 (-1, +1)；左下角 → 左下方 (+1, -1)；右下角 → 右下方 (+1, +1)。
4. 从每个角格沿外向对角方向偏移一步到达的格开始（种子格），沿同一对角方向逐步前进，每步涂上颜色 C，直到到达网格边界。种子格本身也涂色 C。
5. 若两条来自不同方块的对角轨迹交叉于同一格，该格涂灰(5)。
6. 不完整对象保持原样不变。完整方块本身保持原样不变。

**关键洞察**：只有结构上完整的方块（而非条状或缺角形状）才会发射对角轨迹——错误地将不完整对象识别为方块会在错误位置产生轨迹。分类步骤是几何扩展的必要前提。不同方块的轨迹交叉色（灰）需要追踪轨迹归属，这要求同时理解所有方块的轨迹几何。
