## 新题 1：裂缝分界多数投票重涂色

**组合逻辑**：[擦除+滑动](已有) + [多数投票+计数](已有，创新：投票范围由裂缝分界动态划定) + [重涂色](已有，创新：投票结果决定整半区颜色)

**来源原语**：擦除+滑动+裂缝标记线+沿短轴分裂+两侧等距分离（来自 2faf500b）；多数投票+计数+多数决（来自 27a77e38）；重涂色（来自 25d8a9c8/103eff5b）

**依赖链**：裂缝标记线划定了分割边界 -> 分割产生两个独立半区 -> 每个半区内部独立进行多数投票 -> 投票结果决定该半区的统一涂色 -> 涂色后两半区按裂缝方向等距分离

沿裂缝线将双色物体切开，每半区内多数色胜出并统一涂色，然后两半区分离。

**输入结构**：约 14x14 的黑(0)背景网格。包含 2~3 个互不相邻的 4-连通前景物体。每个物体由两种非黑前景色（例如蓝(1)和红(2)）混合构成，像素数约 12~30，两种颜色交错排布但数量不等。每个物体内部有一条完整的黄(4)裂缝标记线，宽度 1 像素，横穿物体 bbox 的较短轴（若 bbox 宽 > 高则裂缝为水平线，反之为垂直线）。裂缝线将物体精确分为上下（或左右）两半，每半至少 3 个非裂缝像素。生成约束：每个半区内两种前景色的数量不相等（保证多数投票有唯一结果）；不同物体的两种前景色可以相同也可以不同，但裂缝色固定为黄(4)。

**规则**：
1. 对每个物体，识别其黄(4)裂缝标记线，将裂缝像素设为黑(0)（擦除）。
2. 裂缝将物体分为两个 4-连通的半区。对每个半区，统计其中两种前景色各有多少像素。
3. 将每个半区的所有像素重涂为该半区内数量较多的那种前景色（多数色胜出，少数色被覆盖）。
4. 将两个半区沿垂直于裂缝的方向各向外平移 1 像素（即裂缝为水平线时，上半区上移 1、下半区下移 1；裂缝为垂直线时，左半区左移 1、右半区右移 1）。超出网格边界的像素舍弃。
5. 不属于任何物体的背景像素保持黑(0)。

**关键洞察**：裂缝线不只是物理切割线——它同时定义了多数投票的统计边界。同一个物体的两个半区可能投出不同的多数色，因此裂缝位置直接改变了最终的颜色分配。需要对比多个示例才能确认"多数色统一涂色"这一规则，因为仅看单个示例可能误以为是保留原色或交换色。

## 新题 2：路径可达性筛选锚点叠加

**组合逻辑**：[路径追踪](已有，创新：路径可达性作为筛选条件) + [透明叠加+锚点对齐](已有，创新：仅叠加被路径选中的精灵) + [裁剪](已有)

**来源原语**：路径追踪+引导像素+路径连接+终点相邻（来自 9ba4a9aa）；透明叠加+锚点像素+锚点对齐+锚点重合叠加（来自 137eaa0f）；裁剪（来自 67636eac/137eaa0f）

**依赖链**：引导像素路径从源点出发连接到部分精灵 -> 只有路径可达的精灵参与叠加 -> 可达精灵通过锚点像素对齐叠加 -> 裁剪叠加结果

追踪引导像素路径，筛选出路径可达的精灵体，将它们按灰色锚点对齐叠加后裁剪输出。

**输入结构**：约 20x20 的黑(0)背景网格。包含 4~6 个互不相邻的多色精灵体，每个精灵占约 3x3 到 5x5 区域，由一种独有前景色加恰好一个灰(5)锚点像素构成（如精灵 A 是蓝(1)+灰(5)，精灵 B 是红(2)+灰(5)等，每个精灵的主色互不相同）。网格的某一条边（如左边缘）上有一个橙(7)源像素。从源像素出发，有一条由橙(7)像素构成的路径，路径像素两两之间曼哈顿距离为 2（即每隔一个格子放一个橙像素，形成疏松的水平/垂直路径），路径分叉或转向后终止于某些精灵的邻近位置（路径末端像素与精灵 bbox 边缘 4-相邻）。路径仅连接到部分精灵（2~4 个），其余精灵无路径到达。生成约束：路径不穿越任何精灵的 bbox；路径的每一段沿水平或垂直方向延伸；被路径连接的精灵数量至少为 2。

**规则**：
1. 从橙(7)源像素出发，沿橙(7)引导像素追踪路径（每步在水平或垂直方向跳 2 格寻找下一个橙像素）。记录路径到达的所有精灵（路径末端像素与精灵 bbox 4-相邻）。
2. 忽略所有未被路径到达的精灵。
3. 将每个被选中的精灵裁剪为其 bbox 大小的小图。
4. 将所有被选中精灵的小图叠加：以每个精灵的灰(5)锚点像素为对齐点，将所有小图放置在同一坐标系中，使锚点重合。叠加时，非黑像素覆盖黑像素；若多个精灵在同一位置都有非黑像素，则按精灵被路径到达的先后顺序（路径追踪中先到达的精灵在下层，后到达的在上层），后层覆盖前层。
5. 裁剪叠加结果到包含所有非黑像素的最小 bbox，输出该裁剪图。丢弃所有路径像素和未选中精灵。

**关键洞察**：路径追踪不是为了找到一个目标对象，而是为了筛选哪些精灵参与后续的锚点叠加。路径的拓扑结构（连接了哪些精灵）直接决定了叠加的合成图案，改变路径连接就会改变输出。需要对比多个示例才能确认未连接的精灵被排除而非以某种默认方式参与。

## 新题 3：分区压缩列数编码对角周期长度

**组合逻辑**：[压缩+网格分区](已有，创新：压缩结果的几何属性编码另一操作的参数) + [补全+对角线同余](已有，创新：周期长度由压缩结果动态决定)

**来源原语**：压缩+分隔线+单色区域+网格分区（来自 9f236235）；补全+对角周期图案+对角线同余+对角周期补缺失（来自 c3f564a4）

**依赖链**：分隔线划定分区 -> 压缩得到紧凑区域色图 -> 紧凑图的列数 = 对角周期长度 -> 用该周期长度填补另一区域的对角图案空洞

将分隔线分区压缩为紧凑色图，其列数作为对角周期循环的长度，填补网格另一区域中的缺失像素。

**输入结构**：约 16x16 的黑(0)背景网格，从上到下分为两个水平区域，以一整行灰(5)分隔行隔开：
- 上区域（约占 5~7 行）：由灰(5)垂直和水平分隔条划分为矩形单色子区域。每个子区域填充一种非黑非灰颜色。分隔条将上区域分为 R 行 C 列的区域网格（C 在 2~4 之间变化）。
- 下区域（约占 8~10 行）：包含一个几乎覆盖整个下区域的对角周期彩色图案，使用 C 种非黑非灰颜色（C 与上区域压缩后的列数相同）。图案中有若干黑(0)像素作为缺失空洞。

生成约束：下区域使用的 C 种颜色可以与上区域的颜色不同；对角周期图案中每种颜色至少在某个对角线残差类上完整出现一次（保证可以从可见像素推断残差-颜色映射）；上区域的列数 C 恰好等于下区域的对角周期循环长度。

**规则**：
1. 识别上区域的灰(5)分隔条，将上区域压缩为紧凑的区域色图（每个分隔子区域变为一个像素，保持行列顺序）。
2. 读取压缩后色图的列数 C。
3. 在下区域中，对于每个非黑像素，根据其位置 (row, col) 计算对角线残差 (row + col) mod C，建立残差到颜色的映射。
4. 将下区域中每个黑(0)缺失像素替换为其对角线残差对应的颜色。
5. 保留上区域和分隔行不变，输出完整网格。

**关键洞察**：上区域的空间结构（分区数量）隐式编码了下区域对角图案的周期参数。求解者必须先完成压缩操作才能获得对角填充所需的周期长度，仅看下区域的局部图案无法确定循环是 2、3 还是 4。需要对比多个示例（上区域列数不同导致下区域周期不同）才能确认这一跨区域参数传递关系。

## 新题 4：线段排序确定模板旋转角度

**组合逻辑**：[排序+最高行决定序](已有，创新：排序位次编码旋转角度) + [旋转](已有，创新：旋转角度由外部排序结果参数化) + [像素放大+印章覆盖](已有，创新：放大后印章到排序对应位置)

**来源原语**：排序+线段对象+顺序排列+最高行决定序（来自 668eec9a）；旋转+像素放大+多色模板（来自 103eff5b）；印章覆盖+位置对应（来自 20fb2937）

**依赖链**：线段对象按最高行排序得到颜色序列 -> 序列中的位次决定旋转角度 -> 多色模板按该角度旋转 -> 旋转后的模板放大 2 倍印章到对应输出行

将线段对象按其最高行排序，排序位次决定小模板的旋转角度，将旋转并放大后的模板按序纵向排列输出。

**输入结构**：约 15x15 的黑(0)背景网格，包含两类元素：
- 线段对象：3~4 条不同颜色的 4-连通单色线段（每条 1 像素宽，长 2~5 像素，可为水平、垂直或对角方向），颜色互不相同（如蓝(1)、红(2)、绿(3)），分布在网格各处，彼此不接触。每条线段所占的最高行（行号最小的行）互不相同。
- 多色模板：一个位于网格角落的 2x2 小方块，四个像素各有不同颜色（如左上黄(4)、右上橙(7)、左下青(8)、右下栗(9)），与线段颜色均不同。

生成约束：线段数量 N 在 3~4 之间；模板固定为 2x2 且四色互不相同；线段的最高行互不相同以保证排序唯一。

**规则**：
1. 提取所有线段对象，记录每条线段的颜色和其占据的最高行（行号最小）。
2. 按最高行从小到大排序线段颜色，得到一个长度为 N 的有序颜色列表。列表中位次从 0 开始编号。
3. 提取 2x2 多色模板。
4. 对每个位次 k（0, 1, ..., N-1），将模板顺时针旋转 k x 90 度（位次 0 不旋转，位次 1 旋转 90 度，位次 2 旋转 180 度，位次 3 旋转 270 度）。
5. 将每个旋转后的 2x2 模板像素放大 2 倍（变为 4x4）。
6. 构建输出：宽 4 像素，高 4xN 像素。从上到下，按位次 0 到 N-1 依次纵向排列 N 个 4x4 放大模板。相邻模板之间无间隔。

**关键洞察**：线段本身的形状和长度无关紧要，只有它们的垂直位置顺序有意义——排序位次直接编码了旋转角度。需要对比多个示例（线段位置不同导致旋转顺序不同）才能区分"按位次旋转"与"按颜色编号旋转"或"固定旋转"等假设。

## 新题 5：双掩码交集定位周期性修复目标

**组合逻辑**：[透明叠加+逐像素比较](已有，创新：比较结果标记待修复位置而非直接输出) + [补全+平移等价](已有，创新：修复范围由叠加比较动态划定)

**来源原语**：透明叠加+掩码+逐像素比较+共同背景标前景（来自 94f9d214）；补全+周期性格+平移等价+平移向量决定填充（来自 484b58aa）

**依赖链**：两个掩码逐像素比较 -> 共同背景位置标记为"待修复" -> 待修复位置所在的周期性格中寻找最大支持平移向量 -> 用该向量从可见像素推断并填充待修复位置的颜色

将垂直堆叠的两个掩码逐像素比较，找到双方均为背景的位置，这些位置标记了底层周期图案的缺损处，再用周期平移恢复缺损像素。

**输入结构**：约 12x20 的黑(0)背景网格，上下等分为两半（各约 12x10），无显式分隔行：
- 上半区：一个周期性彩色图案（使用 3~4 种非黑颜色），其中某些位置被替换为蓝(1)前景像素（形成一个蓝色不规则形状），其余位置保留周期图案颜色或为黑(0)背景。
- 下半区：同样的周期性彩色图案（与上半区使用相同颜色和相同周期），其中某些位置被替换为红(2)前景像素（形成一个红色不规则形状），其余位置保留周期图案颜色或为黑(0)背景。
- 两半区的黑(0)背景像素分布不同。上半区的某些背景位置在下半区是可见周期图案像素，反之亦然。但有少量位置在两半区都是黑(0)背景——这些就是真正缺损的周期图案像素。

生成约束：两半区中周期图案相同（同一平移向量、同一颜色映射），但被遮挡的部分不同；双方均为黑(0)的位置数量少于总像素的 15%；从两半区合并可见周期像素后，每个平移等价类至少有一个可见像素，保证可唯一修复。

**规则**：
1. 将网格上下等分为两半区，每半区大小相同。
2. 逐像素比较两半区对应位置：若上半区像素为黑(0)且下半区对应位置也为黑(0)，则标记该位置为"双缺损"。
3. 忽略蓝(1)和红(2)前景像素（它们是遮挡物，不属于底层图案）。合并两半区中所有非黑非蓝非红的像素，作为底层周期图案的可见部分。
4. 从可见像素中找到支持数最大且无颜色冲突的非零平移向量。
5. 对每个"双缺损"位置，沿平移向量及其逆向量追溯到可见像素，确定该位置在周期图案中应有的颜色。
6. 输出一个与半区大小相同的网格：所有"双缺损"位置填入修复后的周期图案颜色，所有非双缺损位置填黑(0)。

**关键洞察**：两个掩码各自的黑色区域大多能被对方的可见像素补全，只有极少数位置在双方都缺失——这些才是需要通过周期平移恢复的真正空洞。掩码比较起到的是"筛选"作用而非"合成"作用，它将一个看似大量缺损的问题缩减为少量精确的修复目标。需要对比多个示例才能排除"输出所有非黑像素"或"输出红蓝并集"等错误假设。

## 新题 6：行均匀性检测驱动前缀序列外推

**组合逻辑**：[检测+单色行标记](已有，创新：检测结果作为序列信号而非直接输出) + [前缀匹配+外推](已有，创新：外推的对象是检测产生的二值序列) + [填充](已有，创新：外推的二值决定填充色)

**来源原语**：检测+行+单色行标记否则黑（来自 25d8a9c8）；前缀匹配+行组+列状态序列+完整模式续写缺失+外推（来自 90f3ed37）；填充（来自 f8c80d96/484b58aa）

**依赖链**：逐行检测均匀性 -> 产生每个行组的二值模式序列 -> 顶部行组的序列是完整参考 -> 下方行组的序列是参考的前缀 -> 外推缺失的后缀 -> 按外推结果添加填充行

- 每个行组由连续的非黑行构成，每行宽度等于网格宽度。每行要么是单色行（所有像素同色，使用某种非黑色），要么是混色行（包含 2~3 种非黑色的像素混合）。
- 最上方的行组包含最多的行（如 5~7 行），是完整的参考序列。
- 下方的行组包含更少的行（递减），每个下方行组的均匀性模式（从上到下，每行标记为 U（均匀）或 M（混色））是参考序列均匀性模式的一个从头开始的前缀。
- 各行组中使用的具体颜色可以不同，但均匀/混色的模式结构相同（如参考序列的前缀）。

生成约束：参考序列的均匀性模式中 U 和 M 至少各出现 2 次；不同行组中的具体颜色可以不同（保证求解者必须依赖均匀性判断而非颜色匹配）；每个下方行组至少包含参考序列前 2 行的模式。

**规则**：
1. 识别所有行组（连续非黑行的极大集合）。
2. 对每个行组中的每一行，检测该行是否均匀（所有像素同色）。产生一个由 U/M 组成的二值序列。
3. 取最上方行组的序列作为参考模式 P（长度为 L）。
4. 对每个下方行组，设其序列长度为 K（K < L），验证其序列是 P 的前 K 项。
5. 在每个下方行组下方追加 (L - K) 行来补全模式。追加行的规则：若 P 中第 i 项（i > K）为 U（均匀），则追加一行全绿(3)像素；若为 M（混色），则追加一行全蓝(1)像素。
6. 保持参考行组和所有原有行不变，仅追加新行。输出完整网格（网格高度因追加行而增大）。

**关键洞察**：行的实际颜色是干扰信息——真正的信号是每行"是否均匀"这个二值属性。检测步骤把视觉复杂的彩色行简化为一位信息，而前缀匹配和外推在这个抽象信号层面运作。需要对比多个示例（不同颜色方案但相同均匀性模式）才能确认规则不依赖具体颜色。

## 新题 7：阶梯射线与障碍偏转的交叉重涂

**组合逻辑**：[阶梯扩展+周期性步长](已有，创新：阶梯射线不是对称展开而是从源点单向发射) + [射线延伸+障碍偏转绕行](已有，创新：偏转方向由阶梯节奏决定) + [重涂色+跨色重叠变色](已有，创新：两种射线交叉区域变色)

**来源原语**：阶梯扩展+竖直条对+周期性步长+跨色重叠变色（来自 58e15b12）；射线延伸+源像素+障碍块+边缘起始+障碍偏转绕行（来自 69889d6e）

**依赖链**：竖直条的高度决定阶梯步长 -> 阶梯射线从条顶端向上发射 -> 对角射线从底边源像素向上发射并遇障碍偏转 -> 两类射线像素在同一格相遇时变为品红(6)

竖直条发射阶梯射线向上扩展，底边源像素发射偏转对角射线，两种射线交叉处重涂为品红色。

**输入结构**：约 18x18 的黑(0)背景网格，包含三类元素：
- 竖直条：2~3 根单色竖直条（各自颜色不同，如蓝(1)、绿(3)），每根宽 1 像素、高 2~4 像素，位于网格中部偏上的不同列。每根竖直条的高度 H 即为其阶梯步长。
- 源像素：1 个位于最底行的单独前景像素，颜色为红(2)，与竖直条不在同一列。
- 障碍块：2~4 个灰(5)单像素散布在网格中，作为对角射线的偏转障碍。障碍不与竖直条或源像素相邻。

生成约束：竖直条的阶梯射线在网格范围内至少各扩展 2 步；对角射线在到达网格上边缘前至少遇到 1 个障碍；两种射线至少有 1 个交叉像素。

**规则**：
1. 对每根竖直条：从其顶端像素开始，向上逐行发射该竖直条颜色的射线。每经过 H 行（H = 竖直条高度），射线水平位置向远离网格中心的方向偏移 1 列（若竖直条在网格左半侧则左移，右半侧则右移）。射线持续到超出网格边界为止。每步画 1 个像素。
2. 从底行红(2)源像素开始，向右上方逐行发射对角射线，每行右移 1 列、上移 1 行，画 1 个红(2)像素。若下一个目标位置有灰(5)障碍块，则该行跳过不画，射线在下一行继续（列位置再右移 1 列），相当于绕过障碍。射线到达网格顶行或右边缘后停止。
3. 若某个格子同时被阶梯射线和对角射线覆盖，将该格子重涂为品红(6)。
4. 保留所有原始竖直条像素和障碍块像素不变。源像素保留红(2)。

**关键洞察**：两种射线的扩展机制完全不同——阶梯射线的偏移节奏由竖直条高度决定（周期性步长），而对角射线的路径由障碍位置决定（偏转绕行）。它们的交叉点无法仅从任一射线独立推算，必须同时追踪两套路径规则。需要对比多个示例才能区分阶梯射线的偏移方向规则（"远离中心"而非"固定左移"）。

## 新题 8：象限投票驱动分类槽位填充

面板的"象限签名"定义：将面板 bbox 的行区间平分为上下两半、列区间平分为左右两半，得到四个象限 TL/TR/BL/BR。每个象限内统计各颜色像素数，数量最多的颜色为该象限的主色。四个主色按 TL-TR-BL-BR 顺序排列组成一个 4 元组，即为该面板的象限签名。

**规则**：
1. 识别所有矩形面板（非黑连通区域的最小 bbox，且 bbox 内所有像素均非黑）。
2. 对每个面板，将其 bbox 平分为 TL/TR/BL/BR 四象限。若行数或列数为奇数，上半/左半取较小的一半（如 5 行则上 2 行、下 3 行）。
3. 在每个象限内统计各颜色出现次数，取出现最多的颜色为该象限主色。
4. 四个主色按 TL-TR-BL-BR 排列为该面板的象限签名。
5. 将所有面板按象限签名分组。按每组中面板的最上最左面板的位置（先比较行再比较列）对组排序，得到有序的组列表 G1, G2, ...
6. 构建输出：一个 1 行 x N 列的网格（N = 组数），每个格子填入对应组的面板数量所映射的颜色：1 个面板 -> 蓝(1)，2 个 -> 红(2)，3 个 -> 绿(3)，4 个或更多 -> 黄(4)。

**关键洞察**：面板表面看上去只是彩色随机矩形，但每个面板内部隐含了象限级别的颜色统计结构。象限投票把视觉上混乱的颜色分布提炼为离散签名，签名又作为分类键决定了最终的计数。需要对比多个示例才能发现"按象限主色分类"而非"按面板整体主色分类"或"按面板位置分类"。

## 新题 9：裂缝分割后对角邻接重组与颜色互换

**组合逻辑**：[擦除+滑动+沿短轴分裂](已有，创新：分裂后不是平行分离而是对角重组) + [对角邻接拼合+颜色互换](已有，创新：颜色互换发生在分裂重组之后的特定半区) + [镜像](已有，创新：镜像轴由分裂方向决定)

**依赖链**：裂缝线擦除并分裂物体为两半 -> 其中一半左右镜像 -> 镜像后的半区与另一半对角邻接拼合 -> 拼合后对两半区的颜色执行互换

生成约束：裂缝将物体分为的两半在像素结构上不对称（镜像后形状会变化）；两半中蓝(1)和红(2)均存在；物体的 bbox 足够大，使得对角拼合后不会超出网格边界。

**规则**：
1. 对每个物体，擦除其橙(7)裂缝标记线（设为黑(0)），将物体分为两个 4-连通的半区 A 和 B。约定 A 为上半区（水平裂缝时）或左半区（垂直裂缝时），B 为另一半。
2. 将半区 B 沿裂缝方向做镜像翻转：若裂缝为水平线，则 B 做上下镜像；若裂缝为垂直线，则 B 做左右镜像。镜像以 B 自身的 bbox 中心为轴。
3. 保持 A 在原位不动。将镜像后的 B 平移，使 B 的 bbox 左上角位于 A 的 bbox 右下角的对角相邻位置（即 B 左上角 = A 右下角 + (1, 1)）。
4. 在 A 和 B 中执行颜色互换：A 中所有蓝(1)变红(2)、红(2)变蓝(1)；B 中同样互换。
5. 输出结果网格。未被物体覆盖的位置保持黑(0)。

**关键洞察**：裂缝不只是切割线——它同时决定了镜像的轴向（水平裂缝导致上下镜像，垂直裂缝导致左右镜像）。镜像改变了半区的形状，使得对角拼合产生新的整体轮廓，而颜色互换在拼合后进行，进一步掩盖了原始物体的外观。需要对比多个示例（水平裂缝 vs 垂直裂缝）才能确认镜像轴与裂缝方向的关系。

## 新题 10：等差矩形笔画内部的分区压缩

**组合逻辑**：[补全+等差序列+画布裁切](已有，创新：补全后的矩形笔画形成嵌套分区) + [压缩+网格分区](已有，创新：分区由嵌套矩形笔画的围合区域定义) + [重涂色](已有，创新：压缩后按面积排序重涂)

**来源原语**：补全+等差序列+矩形边框笔画+画布裁切可见（来自 f8c80d96）；压缩+分隔线+单色区域+网格分区+区域压缩后翻转（来自 9f236235）；重涂色+排序（来自 668eec9a/25d8a9c8）

**依赖链**：等差序列外推补全被裁切的矩形笔画 -> 补全后的嵌套笔画围合出同心环状区域 -> 将每个环状区域视为一个分区 -> 按区域面积从小到大排序 -> 从内到外依次涂色

补全等差递进的矩形笔画，由补全后的嵌套矩形围合出环状分区，按分区面积排序并依次涂上预定义颜色。

**输入结构**：约 18x18 的黑(0)背景网格。包含 2~3 个可见的同色矩形边框笔画（颜色为灰(5)，每个笔画是矩形边框的某几条边，如顶边+右边、或左边+底边+右边），每个笔画宽 1 像素。这些笔画的 bbox 按等差递增（相邻笔画的 bbox 宽度和高度各差一个固定常数 d，中心对齐）。最大的笔画部分被网格边界裁切（仅可见的像素存在）。另外，在最内层笔画围合的区域内有一个小的彩色标记像素（颜色非黑非灰，如红(2)），标记该区域。

生成约束：至少 2 个笔画完全可见（在网格内）；等差序列允许向外推 1~2 个笔画（但这些笔画因被画布裁切而部分可见或不可见）；所有笔画使用同一组边（如都是"顶边+右边"），保证形态一致。

**规则**：
1. 从可见笔画推断 bbox 的等差递增规则（中心坐标、宽高增量 d）。向两个方向（更大和更小）外推 bbox 序列，直到笔画完全超出网格边界。
2. 绘制所有推断出的笔画（包括原本因裁切而不完整的部分——只绘制在网格内的像素），颜色为灰(5)。
3. 补全后的嵌套矩形笔画将网格分为若干同心区域：最内层区域由最小笔画围合，每对相邻笔画之间围合一个环状区域，最外层笔画之外到网格边界是最外层区域。
4. 计算每个区域的像素面积（不含笔画像素本身），按面积从小到大排序。
5. 按排序顺序依次涂色：面积最小的区域涂蓝(1)，第二小涂红(2)，第三小涂绿(3)，第四小涂黄(4)，依此类推（最多用到第 7 个颜色橙(7)）。灰(5)笔画像素保持不变。
6. 输出完整网格。

**关键洞察**：可见笔画本身只是等差序列的中间几项——你必须先补全隐藏的项才能知道有多少个围合区域。补全改变了分区数量，从而改变了涂色方案。而且由于笔画是部分边框（不是完整矩形），围合区域的边界判定需要结合笔画形态和网格边界共同确定。需要对比多个示例来确认等差规则和涂色顺序。
