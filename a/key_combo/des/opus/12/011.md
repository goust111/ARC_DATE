## 新题 1：阴影桥接连通过滤

**组合逻辑**：[偏移阴影](创新：阴影不出现在输出中，仅作为连通判定的虚拟桥接层) + [八连通判定] + [擦除·单像素分量移除](创新：在阴影增强后的图上判定连通性，而非原图)

**来源原语**：偏移阴影·列环绕(310f3251)，擦除·八连通判定·单像素分量移除(42a50994)

**依赖链**：阴影偏移改变了像素间的八连通邻接关系 → 连通分量的大小因阴影桥接而改变 → 基于增强后分量大小的擦除判定不同于直接在原图上做的判定 → 移除所有阴影后的最终输出取决于阴影引起的连通性变化

散布在网格上的前景像素经阴影桥接后重新判定连通性，仅擦除在桥接图上仍然孤立的像素，阴影本身不留在输出中。

**输入结构**：约 10x10 网格，黑(0)背景。蓝(1)前景像素散布在网格中，数量约 8-15 个，部分互相 8-邻接形成小簇（2-4 像素），部分孤立。所有蓝像素不出现在第 0 行（最顶行）。生成约束：至少存在一个蓝像素在原图上是孤立的（无蓝邻居）但其阴影位置与另一个蓝像素或另一个阴影 8-邻接，保证阴影桥接确实改变了判定结果。

**规则**：
1. 对每个蓝(1)像素 (r, c)，计算其阴影位置为 (r-1, (c-1) mod W)，其中 W 是网格宽度。
2. 构建增强掩码：包含所有蓝像素位置以及所有落在黑(0)背景上的阴影位置（若阴影位置恰好已有蓝像素，则该位置仍计为蓝像素，不重复添加）。
3. 在增强掩码上计算 8-连通分量。对每个分量，统计其中蓝像素（非阴影）的数量。
4. 若某蓝像素所在分量的蓝像素计数为 1，则擦除该蓝像素（置为黑(0)）。
5. 移除所有阴影位置（它们不出现在输出中）。输出仅保留幸存的蓝像素。

**关键洞察**：阴影偏移在特定方向（左上，带列环绕）上创建虚拟邻接。一个在原图上完全孤立的蓝像素可能因为其阴影恰好落在另一个蓝像素的阴影旁边而被"桥接"进入一个多蓝像素分量，从而幸存。这种非对称的方向性桥接关系在任何一道参考题中都不存在。

## 新题 2：封闭面积参数化锯齿平铺

**组合逻辑**：[计数·封闭背景区域](已有) → [旋转·对角锯齿排布·交替旋转换色](创新：矩形条的宽高不是直接给出，而是由两个封闭形状的内部面积隐式编码)

**来源原语**：计数·封闭背景区域(8ba14f53)，平铺·旋转·对角锯齿排布·交替旋转换色(fd4b2b02)

**依赖链**：两个封闭形状各自包围的黑像素数 → 分别编码矩形条的宽度和高度 → 矩形条的几何参数决定了整个锯齿平铺的周期和形态 → 形状的空间位置同时决定锯齿种子的放置坐标

输入中两个封闭前景形状各自包围不同数量的黑像素，这两个面积值分别编码一个矩形条的宽和高，以该条为种子在全网格上生成交替旋转换色的对角锯齿平铺。

**输入结构**：约 20x20 网格，黑(0)背景。包含两个 4-连通单色前景对象：一个绿(3)，一个品红(6)。两个对象互不接触，分别位于网格左半区和右半区。每个对象是封闭形状（形成闭合边界，内部包围若干黑像素），像素数约 10-20，封闭的黑像素数在 2-5 之间。生成约束：两个对象的封闭面积不相等；封闭面积值使得生成的矩形条为非正方形。

**规则**：
1. 对每个前景对象，计算其边界框内、不与边界框边缘通过黑像素 4-连通的黑像素数量（封闭面积）。
2. 左侧对象（边界框左边缘 x 坐标较小者）的封闭面积为矩形条宽度 W，右侧对象的封闭面积为矩形条高度 H。
3. 擦除两个原始对象。以左侧对象边界框的左上角为种子位置，放置一个 H 行 x W 列的绿(3)矩形条。
4. 沿两条 45 度对角线方向，以行偏移 (H+W)、列偏移 (H+W) 为周期重复放置绿(3)条的拷贝。在同一对角线上相邻两个绿条之间，放置一个 90 度旋转后的 W 行 x H 列品红(6)矩形条。
5. 在另一条 45 度对角线方向上同样生成交替排列。超出网格边界的部分裁剪丢弃。

**关键洞察**：输入形状的拓扑属性（封闭面积）隐式编码了输出几何图案的参数。求解者无法从形状的外轮廓直接读出矩形条的尺寸，必须先计算孔洞面积，再用该值构造周期性平铺。

## 新题 3：模板筛选跨度连线

**组合逻辑**：[形状匹配·模板·框架](已有) → [连线·首尾跨度填充](创新：参与连线的标记不再是所有前景像素，而是经模板匹配筛选后的子集) + [擦除](创新：未匹配对象被移除)

**来源原语**：形状匹配·模板·框架·掩码相同(63613498)，连线·首尾跨度填充·同行列对齐(ded97339)，擦除(42a50994)

**依赖链**：模板掩码从 L-框架中提取 → 外部对象逐一与模板比对 → 匹配结果决定哪些对象作为连线标记保留、哪些被擦除 → 保留标记的行列对齐关系决定跨度连线的位置和长度

L-框架内的模板形状决定哪些外部对象被选中作为连线端点，仅在选中对象之间画行列跨度连线，未选中对象被擦除。

**输入结构**：约 15x15 网格，黑(0)背景。网格右下角有一个灰(5) L-框架（垂直腿在右，水平腿在底），其内部包含一个单色小图形（3-6 像素的 4-连通图形，颜色非灰非黑，如蓝(1)）。网格其余区域散布 5-8 个小型单色前景对象，每个 3-6 像素、4-连通，颜色各异（可包含多种非黑非灰颜色）。各外部对象互不接触且不与 L-框架接触。生成约束：至少 2 个外部对象的归一化掩码与模板相同（但颜色可不同），至少 2 个不同；匹配对象中至少有一对共享同一行或同一列。

**规则**：
1. 提取灰(5) L-框架边界框内部的有色图形（非灰非黑像素），计算其归一化掩码（平移至原点后的二值像素集）。
2. 对框架外部的每个 4-连通前景对象，计算其归一化掩码并与模板比对。
3. 掩码匹配的对象保留为"选中标记"，保持原色。掩码不匹配的对象整体擦除为黑(0)。
4. 对于包含至少两个选中标记像素的每一行，将该行上最左选中像素到最右选中像素之间的所有背景像素填充为灰(5)。
5. 对于包含至少两个选中标记像素的每一列，将该列上最上选中像素到最下选中像素之间的所有背景像素填充为灰(5)。
6. 选中标记像素保持原色不被灰色覆盖。灰(5) L-框架及其内部模板保持不变。

**关键洞察**：形状匹配充当了连线操作的准入过滤器——不同示例中模板形状不同，导致不同的对象被选中，从而产生完全不同的连线图案。求解者必须同时理解"什么形状算匹配"和"匹配后如何连线"两个逻辑层面。

## 新题 4：面积排序叠加与干扰去除

**组合逻辑**：[裁剪·保留最大分量·忽略干扰项](已有) + [计数·面积排序](已有) → [叠加](创新：叠加的图层顺序由像素面积而非空间位置决定)

**来源原语**：裁剪·保留最大分量·忽略干扰项·按面积筛选(337b420f)，计数·面积排序·按像素数降序(f8ff0b80)，叠加(337b420f)

**依赖链**：各面板中分量面积筛选 → 保留最大分量 → 跨面板比较像素面积以确定叠加顺序 → 叠加时遮挡关系由面积排序而非面板位置决定 → 遮挡区域的最终颜色取决于面积排名

三个面板各保留最大前景分量后，按像素面积从小到大依次叠加到单一画布上，面积最大的分量在最上层，遮挡重叠区域。

**输入结构**：5x17 网格，由三个 5x5 面板和两条一像素宽的黑(0)分隔列组成（与参考题 337b420f 结构相同）。每个面板有统一的非黑背景色（如灰(5)），以及恰好一种前景色的像素，分成 2-3 个 4-连通分量。三个面板的前景色互不相同（如蓝(1)、红(2)、绿(3)）。生成约束：每个面板内最大分量唯一（无并列）；三个面板的最大分量像素面积互不相等；至少有两个分量在叠加到 5x5 画布时的边界框存在重叠。

**规则**：
1. 在每个面板中，识别所有 4-连通前景分量，仅保留像素数最大的一个，丢弃其余分量。
2. 统计三个幸存分量各自的像素面积（像素数量）。
3. 按像素面积从小到大排序。将三个分量依次绘制到一个 5x5 的背景画布上（背景色与面板背景色相同），保持每个分量在其原面板中的局部坐标。
4. 面积最小的分量先绘制（底层），面积最大的后绘制（顶层）。后绘制的分量像素覆盖先绘制的。

**关键洞察**：叠加顺序不是面板的空间排列顺序（左中右），而是像素面积的数值顺序。在某些示例中，面积最大的分量来自中间面板或右侧面板，求解者必须通过对比多个示例、观察重叠区域的颜色来归纳出面积决定图层优先级的规则。

## 新题 5：拓扑过滤后的对角笔画选取

**组合逻辑**：[计数·封闭背景区域](创新：封闭性判定用作分量的过滤条件而非计数输出) + [重涂色·最长线段选中·对角线段](创新：候选对角线段仅来自拓扑上"开放"的分量)

**来源原语**：计数·封闭背景区域(8ba14f53)，重涂色·对角线段·最长线段选中·平行对角线带·奇数带选中间线(aa300dc3)，八连通判定(42a50994)

**依赖链**：八连通分量识别 → 逐分量封闭性判定（是否包围灰像素）→ 封闭分量被排除出对角笔画候选集 → 仅在开放分量中做对角线段搜索 → 选取最长段并重涂色

灰色场中的多个黑色八连通分量先按拓扑类型（开放/封闭）分类，仅在开放分量内搜索最长对角线段并涂为青色。

**输入结构**：10x10 网格，灰(5)为主色。黑(0)像素形成 3-5 个互不接触的八连通分量，每个分量 8-25 像素。部分分量形成封闭环路（环内有灰像素被完全包围），部分分量为开放链或分支结构（不包围任何灰像素）。生成约束：至少 1 个封闭分量和至少 2 个开放分量；某个封闭分量中存在比所有开放分量中最长对角段更长的对角段（若不做拓扑过滤，答案会不同）。

**规则**：
1. 识别所有黑(0)像素的八连通分量。
2. 对每个分量，检测其是否包围灰(5)像素：在该分量的边界框内，找到不与边界框边缘通过灰像素 4-连通的灰像素集合，若该集合非空则判定为封闭分量。
3. 排除所有封闭分量，仅保留开放分量作为候选。
4. 在所有候选分量中，沿 NE-SW 和 NW-SE 两个对角方向，找到所有极大连续黑像素段。
5. 选取最长的对角段。若最长候选构成相邻的平行对角线带，选取该带的中间一条。
6. 将选中段的像素重涂为青(8)，其余像素不变。

**关键洞察**：拓扑封闭性作为隐式过滤器决定了哪些分量参与对角笔画竞争。封闭分量中可能包含更长的对角段，但因拓扑类型不同而被排除——求解者必须先理解封闭/开放的区分标准，再在合格分量中做长度比较。

## 新题 6：阻挡抑制的边缘印章扩展

**组合逻辑**：[像素放大·格位映射·块格阵列](已有) + [切比雪夫距离·阻挡像素](创新：阻挡距离不再决定填充方块的尺寸，而是决定是否允许边缘印章扩展) + [印章覆盖·边缘像素复制](创新：印章仅在无阻挡的方向上生成)

**来源原语**：像素放大·格位映射·块格阵列·印章覆盖·边缘像素复制(8719f442)，切比雪夫距离·阻挡像素·近阻挡距定尺寸(ff72ca3e)

**依赖链**：5x5 输入映射到 15x15 块格阵列 → 前景和阻挡像素各自扩展为 3x3 块 → 边缘前景块的每个外侧方向检查是否有相邻阻挡块 → 有阻挡的方向禁止印章扩展 → 无阻挡方向正常印章 → 阻挡像素的空间布局决定了扩展的形状

5x5 前景掩码放大为块格阵列后，灰色阻挡像素选择性地抑制边缘块的外向印章，使最终扩展图案因阻挡位置不同而产生不对称形态。

**输入结构**：5x5 网格，黑(0)背景。蓝(1)前景像素 3-6 个，形成一个 8-连通图形。灰(5)阻挡像素 1-3 个，位于蓝前景的 4-邻域或对角邻域内（在 5x5 网格的格位坐标系中）。生成约束：至少一个蓝像素位于蓝前景掩码的边缘（上/下/左/右边界）且在至少一个外侧方向有相邻灰像素；至少一个边缘蓝像素的所有外侧方向均无灰像素。

**规则**：
1. 创建 15x15 黑(0)画布。将 5x5 输入的每个格位 (i,j) 映射到画布上以 (3i+3, 3j+3) 为左上角的 3x3 区块（中央 9x9 区域，行列索引 3-11）。
2. 每个蓝(1)输入像素 → 对应 3x3 区块填充为蓝(1)。每个灰(5)输入像素 → 对应 3x3 区块填充为灰(5)。
3. 对蓝前景掩码的每个边缘像素（即该蓝像素在上/下/左/右至少一个方向上没有蓝邻居的方向定义为"外侧方向"），检查每个外侧方向：
   - 若该外侧方向相邻的格位（5x5 坐标中）为灰(5)像素，则该方向被抑制，不放置印章。
   - 若该外侧方向相邻的格位为黑(0)背景或超出 5x5 边界，则在该方向上紧邻蓝块外侧放置原始 5x5 蓝前景掩码的 3x3 块格拷贝（仅蓝像素部分，不拷贝灰像素）。
4. 印章之间若有重叠，后绘制的覆盖先绘制的（处理顺序：按边缘像素在 5x5 中从左上到右下逐像素、每像素按上右下左顺序处理各外侧方向）。

**关键洞察**：灰阻挡像素的空间位置产生方向选择性——同一个边缘像素在不同方向上可能既被阻挡（不扩展）又未被阻挡（正常扩展），使得 15x15 输出图案呈现参考题中不可能出现的非对称扩展形态。

## 新题 7：自相似晶格补全与计数角三角叠加

**组合逻辑**：[补全·自相似晶格映射·掩码定插槽占位·擦除遮挡条](已有) + [计数·角落控制点·三角区域·填充](创新：计数的目标是晶格恢复前就存在的散点控制像素，必须在擦除遮挡条之前先完成计数) + [叠加](创新：三角区域覆盖在恢复后的晶格图案之上)

**来源原语**：补全·擦除·标记·自相似晶格映射·缩略图复原·掩码定插槽占位·局部对应晶格坐标(456873bc)，擦除·填充·计数·角落控制点·三角区域·计数决定尺寸·最大分量保留(902510d5)

**依赖链**：识别散点控制像素并计数（必须在恢复前完成，因为恢复会重绘某些区域）→ 角落控制像素指定三角方位 → 自相似恢复重建被遮挡的精灵体拷贝 → 三角区域以计数值为边长叠加在恢复后的网格上 → 三角覆盖可能遮挡部分精灵体像素，最终输出是两个操作的空间叠加结果

自相似晶格恢复被遮挡的精灵体拷贝，同时散点控制像素的数量决定了在指定角落绘制的实心三角形边长，三角形覆盖在恢复后的晶格之上。

**输入结构**：网格为正方形，边长约 (k*(k+1)-1)，其中 k 为 3 或 4（如 k=3 时边长 11，k=4 时边长 19）。网格被均匀分隔线（背景色，宽 1 像素）划分为 k x k 的插槽阵列，每个插槽 k x k。一种前景色（如红(2)）形成精灵体的重复拷贝，占据部分插槽。另一种前景色（如橙(7)）形成一个实心矩形遮挡条，恰好覆盖一整行或一整列插槽。此外，还有若干蓝(1)的孤立单像素散布在背景区域（不在精灵体或遮挡条上），其中恰好一个位于网格四角之一。生成约束：蓝像素数量（含角落像素）为 N，满足 2 <= N <= k；精灵体的前景掩码恰好编码了插槽占用模式（自相似性）。

**规则**：
1. 识别所有蓝(1)单像素。记录总数 N 和角落像素所在的角（左上/右上/左下/右下）。
2. 擦除遮挡条，利用精灵体自身的前景掩码作为粗粒度晶格掩码（精灵体的第 (i,j) 格被填充当且仅当第 (i,j) 个插槽应包含精灵体拷贝），恢复所有被遮挡的精灵体拷贝。使用红(2)绘制。
3. 擦除所有蓝(1)单像素（若位于恢复后精灵体覆盖区域内则被精灵体覆盖，若在背景区域则置为背景色）。
4. 在角落像素指定的角，绘制边长为 N 的实心直角三角形，颜色为蓝(1)。三角形定义：从该角顶点出发，满足到该角两条边的距离之和小于 N 的所有像素。
5. 三角形像素覆盖任何已有内容（包括精灵体像素和背景）。

**关键洞察**：散点控制像素承载两种信息——数量编码三角形尺寸，角落位置编码三角形方位——但这些像素在晶格恢复步骤中会被擦除或覆盖，因此求解者必须先提取计数信息，再执行晶格恢复，最后用提取的信息绘制三角形。信息提取和几何操作的时序依赖是本题的核心难点。

## 新题 8：框裁剪后的双角色传播填充

**组合逻辑**：[裁剪·最大框决定裁切·面积最大选取](已有) + [传播·逐列填充·底行标记选定列](创新：传播发生在裁剪后的子网格内，且矩形框的像素同时充当传播屏障) + [重涂色](创新：框像素在裁剪后从定界角色转换为屏障角色)

**来源原语**：裁剪·矩形框架·面积最大选取·最大框决定裁切(fcb5c309)，传播·逐列填充·底行标记选定列(17b80ad2)，重涂色(bda2d7a6)

**依赖链**：多个矩形框中选取最大框 → 裁剪到该框的边界框 → 裁剪决定了哪些散点颜色像素被保留 → 裁剪后底行的有色像素成为列标记 → 标记列内逐列向上传播颜色 → 框的红像素作为传播屏障阻止颜色穿越 → 最终输出取决于裁剪范围、标记位置和屏障布局的交互

选取最大矩形框并裁剪后，框内底行有色像素标记特定列，向上传播颜色，但框本身的像素阻止传播穿越，形成被框线分隔的色带。

**输入结构**：约 18x18 网格，黑(0)背景。包含 2-3 个红(2)矩形一像素厚框架，大小不同，互不重叠。最大框的边界框面积至少是次大框的 1.5 倍（确保唯一选取）。在最大框内部，散布若干彩色像素（非黑非红，使用蓝(1)、绿(3)、黄(4)等，每色 2-5 像素）。部分彩色像素位于最大框的底边内侧那一行（即框底边上方一行）。最大框外部也有一些彩色像素（裁剪后会被丢弃）。生成约束：最大框内至少有 2 列被底行彩色像素标记；至少一列中包含不同颜色的多个像素（使传播出现颜色切换）；框线与某些传播路径相交（框内可能有另一个较小的红框，其线条会阻挡传播）。

**规则**：
1. 识别所有红(2)矩形框架（一像素厚的完整矩形环）。选取边界框面积最大的一个。
2. 裁剪网格到该框的边界框范围（包含框像素本身）。
3. 在裁剪后的网格中，识别底行（最后一行，即框的底边）上方紧邻一行中的非黑非红像素，这些像素标记了需要传播的列。
4. 对每个被标记的列，从底部标记像素开始向上扫描：记住当前遇到的最新非黑非红颜色，将该列中每个黑(0)像素替换为记忆的颜色。
5. 红(2)框线像素是传播屏障：扫描遇到红像素时停止当前段的传播（红像素本身不变），红像素上方的黑像素需要由红像素上方的下一个彩色像素重新启动传播。若红像素上方到列顶端之间无彩色像素，则该段保持黑色。
6. 非标记列不做任何修改。

**关键洞察**：红色矩形框在本题中承担双重角色——首先作为空间选择器决定裁剪边界（哪些像素参与后续处理），随后其像素在裁剪后的网格中转变为传播屏障（阻断色带的延伸）。求解者必须理解同一结构在不同逻辑阶段的不同功能。
