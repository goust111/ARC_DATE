## 新题 1：频率定角色的滑动与重涂

**组合逻辑**：[频率排序](创新：频率决定像素角色而非筛选) + [滑动](已有) + [重涂色](创新：重涂色由滑动落点决定) + [同行阻挡](已有) + [靠近障碍停止](已有)

**来源原语**：频率排序(9caf5b84), 滑动(9c56f360), 重涂色(2204b7a8/9caf5b84), 同行阻挡(9c56f360), 靠近障碍停止(9c56f360), 可移动行程(9c56f360), 固定障碍(9c56f360), 标记像素(2204b7a8)

**依赖链**：全局频率统计为每种颜色分配角色（移动者/障碍/标记）→ 障碍位置约束移动者的滑动终点 → 滑动后移动者所在行决定同行标记的重涂色

输入中三种前景色扮演的角色由各自的全局像素数决定：最多的滑动、次多的阻挡、最少的被重涂——频率即指令。

**输入结构**：约 10x15 的网格，背景为黑(0)。恰好有三种前景色（如红(2)、蓝(1)、绿(3)），每种颜色的总像素数互不相同（生成约束）。其中一种颜色以连续水平行程（3~6 像素宽）出现在若干行的右边缘，另一种颜色以孤立单像素散布在网格各处，第三种颜色同样以孤立单像素出现但数量最少。同一行内最多有一个行程和若干孤立像素。哪种颜色承担哪种形态在不同示例中不固定——唯一确定角色的线索是全局像素总数。

**规则**：
1. 统计整个网格中每种前景色的总像素数。最多的色为"移动色"，次多的为"障碍色"，最少的为"标记色"。
2. 每一行中，移动色的连续行程向左滑动，遇到同行中最近的障碍色像素时停在其右侧相邻格；若同行无障碍色像素则滑到最左列。移动色行程保持其长度和颜色不变，原位置变为黑(0)。
3. 障碍色像素位置不变。
4. 滑动完成后，对于每个标记色像素：若该像素所在行存在移动色行程（已滑到新位置），则将标记色像素重涂为移动色；若该行无移动色行程，则将标记色像素变为黑(0)（擦除）。
5. 生成约束：三种前景色的总像素数两两不同且差距明显（至少相差 3），保证角色分配无歧义。

**关键洞察**：同一种形态（孤立像素）在不同示例中可能扮演障碍或标记的不同角色——角色不由形态决定，而由全局频率决定；必须对比多个示例才能排除"按颜色身份硬编码角色"的假说。

## 新题 2：步序染色的贪心走廊

**组合逻辑**：[贪心遍历](已有) + [连线](创新：走廊颜色由步序循环决定而非固定色) + [擦除](创新：未访问目标被擦除) + [视线遮挡判断](已有) + [循环色板](来自距离环题，用于步序)

**来源原语**：贪心遍历(3490cc26), 连线(3490cc26), 视线可见(3490cc26), 视线遮挡判断(3490cc26), 最近未访问优先(3490cc26), 擦除(3345333e), 循环色板(aaef0977)

**依赖链**：遍历顺序由视线+距离共同决定 → 步序号索引循环色板得走廊颜色 → 遍历完成后未被访问的目标块被擦除

走从起点出发的贪心最近可见路径，每一步的走廊颜色由步序在色板中循环确定，走不到的目标块消失。

**输入结构**：约 16x16 的黑(0)背景网格。包含一个红(2) 2x2 起始块和 6~8 个青(8) 2x2 目标块，各块之间有足够间距。另有若干灰(5)孤立像素散布在网格中作为视线阻挡物。块与块之间的可见性定义：两个块在同一个 2 行宽的水平带或 2 列宽的垂直带中对齐，且带内两块之间无任何非黑像素（含灰像素和其他块的像素）。生成约束：从起始块出发的贪心遍历序列唯一（每步只有唯一一个最近可见目标），且至少有一个目标块不可达。

**规则**：
1. 从红(2)起始块出发，在与当前块共享 2 行或 2 列带的未访问青(8)目标块中，选择曼哈顿距离最近的那个（距离量为两块外边界之间的背景格数）。
2. 将当前块与所选目标块之间的背景格涂上第 k 步对应的颜色，k 从 1 开始。色板为 [绿(3), 黄(4), 蓝(1), 橙(7)]，循环使用：第 1 步绿(3)，第 2 步黄(4)，第 3 步蓝(1)，第 4 步橙(7)，第 5 步回到绿(3)，依此类推。
3. 移动到所选目标块并继续，直到当前块没有可见的未访问目标块。
4. 遍历结束后，将所有未被访问的青(8)目标块擦除为黑(0)。灰(5)阻挡像素保留。红(2)起始块和已访问的青(8)目标块保留原色。
5. 生成约束：每一步最近可见目标唯一（无平局），至少存在 1 个不可达的目标块。

**关键洞察**：走廊颜色不反映端点身份而编码遍历步序——两段同色走廊仅说明其步序号模 4 相同；必须追踪完整路径才能确定每段走廊的颜色。

## 新题 3：揭露隐藏障碍的方向性滑动

**组合逻辑**：[擦除](创新：擦除对象不是前景主体而是障碍的遮罩) + [滑动](创新：滑动方向由行程颜色编码) + [遮挡](来自遮挡题，用于隐藏障碍) + [靠近障碍停止](已有)

**来源原语**：擦除(3345333e), 填充矩形(3345333e), 遮挡(3345333e), 滑动(9c56f360), 可移动行程(9c56f360), 固定障碍(9c56f360), 靠近障碍停止(9c56f360)

**依赖链**：擦除遮罩矩形暴露被隐藏的障碍 → 障碍的完整集合决定滑动终点 → 行程颜色决定滑动方向（非来自任一源题的结构关系）

先撕掉遮罩露出隐藏的障碍像素，再根据行程颜色决定滑动方向——向左还是向右取决于行程自身的颜色。

**输入结构**：约 12x15 的网格，背景为黑(0)。网格中有两种颜色的水平行程：红(2)行程和蓝(1)行程，每种各 2~4 个，分布在不同行中，每个行程宽 2~5 像素，紧贴网格的左边缘或右边缘。另有绿(3)孤立单像素散布在网格中作为障碍（每行 0~2 个）。此外，有 1~2 个黄(4)实心矩形（宽 2~4、高 2~4）覆盖了部分绿(3)障碍像素——这些障碍被遮挡而不可见。生成约束：每个行程所在行至少有一个障碍（可能被遮挡），且遮挡矩形下至少隐藏了一个障碍。

**规则**：
1. 识别所有黄(4)实心矩形（4-连通同色连通分量且为矩形形状）并擦除为黑(0)，暴露其下方被覆盖的绿(3)障碍像素。
2. 红(2)行程向左滑动：在其所在行内向左移动，遇到最近的绿(3)障碍像素时停在障碍右侧相邻格（行程左端紧贴障碍右侧）；若该行无障碍则滑到最左列。
3. 蓝(1)行程向右滑动：在其所在行内向右移动，遇到最近的绿(3)障碍像素时停在障碍左侧相邻格（行程右端紧贴障碍左侧）；若该行无障碍则滑到最右列。
4. 行程滑动后原位置变为黑(0)，行程保持其长度和颜色不变。绿(3)障碍像素（含被揭露的）保持原位。
5. 生成约束：黄(4)矩形不会覆盖任何行程像素，只覆盖障碍像素和背景像素。不同行程的滑动路径互不冲突（不同行）。

**关键洞察**：擦除遮罩前可见的障碍是不完整的——若仅按可见障碍计算滑动终点，部分行程会滑过头或滑到错误位置；真正的终点由遮罩下隐藏的障碍决定。

## 新题 4：框架形状决定距离环的对称补全方式

**组合逻辑**：[填充](创新：在框架内部生成距离环而非全网格) + [镜像](创新：镜像轴由框架宽高比决定，应用于距离环图案) + [矩形框架](已有) + [距离映射](已有) + [宽高比决定镜像轴](已有) + [曼哈顿距离](已有)

**来源原语**：填充(aaef0977), 镜像(18419cfa), 矩形框架(18419cfa), 内部母题(18419cfa), 母题在框架内(18419cfa), 距离映射(aaef0977), 宽高比决定镜像轴(18419cfa), 曼哈顿距离(aaef0977), 标记像素(aaef0977)

**依赖链**：标记像素位置 + 曼哈顿距离 → 生成距离环图案（填充操作的输出）→ 框架宽高比决定镜像轴 → 镜像操作改写距离环的对称性

在每个矩形框架内部从标记点生成曼哈顿距离环，然后根据框架的宽高比选择镜像轴对距离环图案做对称补全——容器的形状同时约束了内容的边界和对称方向。

**输入结构**：约 17x17 的网格，背景为黑(0)。网格中有 2~3 个不重叠的灰(5)矩形框架（仅由外边框像素构成，内部为黑(0)背景），每个框架内部尺寸至少 5x5。框架的宽高比各不相同：有的宽 > 高，有的高 > 宽（生成约束：宽高严格不等）。每个框架内部恰好有一个红(2)标记像素，位于框架内部区域的某个非中心位置。不同框架间至少间隔 1 格。

**规则**：
1. 对于每个灰(5)矩形框架，确定其内部区域（不含边框像素本身）。
2. 以框架内部的红(2)标记像素为中心，计算内部区域中每个格到标记的曼哈顿距离 d。
3. 按距离 d 对内部格赋色：d=0 保持红(2)，d=1 → 绿(3)，d=2 → 黄(4)，d=3 → 蓝(1)，d=4 → 橙(7)，d >= 5 时循环回 d=1 的配色继续（即 d mod 4 映射到 [绿(3), 黄(4), 蓝(1), 橙(7)]，d=0 特殊保持红(2)）。超出内部区域边界的距离环自然截断。
4. 确定框架的宽高比（内部区域的宽与高之比）：
   - 若宽 > 高，对内部区域中的距离环图案做左右镜像——以内部区域的垂直中轴为镜像轴，将左半部分反射到右半部分（覆盖右半部分原有内容）。
   - 若高 > 宽，对内部区域中的距离环图案做上下镜像——以内部区域的水平中轴为镜像轴，将上半部分反射到下半部分（覆盖下半部分原有内容）。
5. 灰(5)边框保持不变，框架外部保持黑(0)。
6. 若内部区域宽或高为偶数，镜像轴取靠左/靠上的中间列/行（即 floor(width/2) 或 floor(height/2) 处的列/行），被镜像轴穿过的列/行本身保留不变，将轴左/上侧的内容复制到轴右/下侧。

**关键洞察**：框架不只是容器——它的几何形状（宽高比）编码了对距离环图案施加何种对称操作；同一个标记点在宽框和窄框中产生完全不同的输出图案。

## 新题 5：邻近性增益的柱高算术

**组合逻辑**：[重涂色](创新：标记像素的重涂色由最近柱决定) + [计数](创新：重涂后标记纳入柱高统计) + [填充](已有) + [颜色编码正负](已有) + [高度加减运算](已有) + [最近距离](已有)

**来源原语**：重涂色(2204b7a8), 计数(37ce87bb), 填充(37ce87bb), 柱状条(37ce87bb), 结果槽(37ce87bb), 颜色编码正负(37ce87bb), 高度加减运算(37ce87bb), 标记像素(2204b7a8), 最近距离(2204b7a8), 标记继承最近源色(2204b7a8)

**依赖链**：标记像素按最近距离继承柱色（重涂色）→ 重涂后标记数计入对应柱的等效高度（计数）→ 增益后的加减运算决定结果柱高度（填充）

散布的绿色标记按距离最近的柱继承其颜色，然后每根柱的"等效高度"= 原始高度 + 该色标记数——标记的空间分布放大了它们临近的柱的权重，从而改变算术结果。

**输入结构**：约 10x14 的网格，背景为黑(0)。网格底部对齐有若干单像素宽的垂直柱：青(8)柱为正操作数，红(2)柱为负操作数，各柱高度 1~6 不等。柱之间以及柱的上方区域散布着若干绿(3)标记像素（每个标记为孤立单像素，不与任何柱相邻）。网格的倒数第二列为空的结果槽。生成约束：每个绿(3)标记到最近柱的曼哈顿距离唯一确定（无平局），且正运算总和大于负运算总和（保证结果为正）。柱之间至少间隔 1 列。

**规则**：
1. 对于每个绿(3)标记像素，计算它到每根柱（取柱中离标记最近的那个像素）的曼哈顿距离，找到距离最近的柱，将该标记重涂为那根柱的颜色（青(8)或红(2)）。
2. 计算增益后的总和：
   - 正总 = 所有青(8)柱的高度之和 + 被重涂为青(8)的标记数量
   - 负总 = 所有红(2)柱的高度之和 + 被重涂为红(2)的标记数量
3. 结果高度 = 正总 - 负总。
4. 在结果槽列中，从底部向上填充"结果高度"个格的灰(5)像素。
5. 所有原始柱保持不变。绿(3)标记被重涂后显示为对应的青(8)或红(2)。
6. 生成约束：结果高度至少为 1 且不超过网格高度。

**关键洞察**：绿色标记不是装饰噪声——它们的空间位置（靠近青柱还是红柱）直接影响算术结果；移动一个标记可能翻转它的阵营归属，从而改变最终柱高。

## 新题 6：对称补全决定查表编码

**组合逻辑**：[对称补全](已有) + [计数](创新：补全后统计像素以确定主色) + [查表替换](创新：查表的输入由补全后的统计结果决定而非原始颜色) + [八重对称轨道](已有) + [颜色映射符号](已有)

**来源原语**：对称补全(929ab4e9), 八重对称轨道(929ab4e9), 遮罩像素(929ab4e9), 轨道内唯一可见色(929ab4e9), 查表替换(d4469b4b), 颜色映射符号(d4469b4b), 固定符号(d4469b4b), 颜色决定输出(d4469b4b), 忽略干扰项(d4469b4b)

**依赖链**：遮罩像素被补全（对称补全）→ 补全后各前景色的像素数发生变化（计数）→ 像素数最多的前景色成为"编码色"→ 编码色查表得到输出符号（查表替换）

先用八重对称补全填回被遮罩的像素，补全改变了各色的像素计数，最终占优的颜色才是真正的查表键——遮罩隐藏了哪种颜色的真实规模。

**输入结构**：约 9x9 的正方形网格，背景为黑(0)。网格中有 2~3 种前景色（从红(2)、蓝(1)、绿(3)中取）的像素，整体图案在忽略遮罩色后具有正方形的八重对称性（关于水平轴、垂直轴、两条对角线均对称）。其中一种颜色充当遮罩（如灰(5)），遮罩像素覆盖了部分对称位置，使得在补全前各前景色的可见像素数排序可能与补全后不同。每个对称轨道中至少有一个非遮罩像素可见。生成约束：补全前后像素数最多的前景色发生变化（即遮罩不均匀地覆盖了不同前景色的像素，使补全前的"多数色"在补全后变成少数色或反之）。

**规则**：
1. 识别遮罩色：在八重对称下，遮罩色是使得剩余像素各轨道内颜色一致的那个颜色（与参考题 929ab4e9 相同的判定方式）。
2. 将每个遮罩像素替换为其八重对称轨道中唯一可见的非遮罩前景色。
3. 补全完成后，统计每种前景色（非黑、非原遮罩色）的总像素数。
4. 像素数最多的前景色为"编码色"。若为红(2)，输出 3x3 灰(5)顶部 T 形符号；若为蓝(1)，输出 3x3 灰(5)十字符号；若为绿(3)，输出 3x3 灰(5)右下 L 形符号。（符号定义同参考题 d4469b4b。）
5. 输出为 3x3 网格，背景黑(0)，符号像素灰(5)。
6. 生成约束：补全后恰好有一种前景色像素数严格最多（无平局）。

**关键洞察**：遮罩的分布是不均匀的——它选择性地隐藏了某种颜色的更多像素，使得补全前的"多数色"假象被推翻；只有先完成对称补全，才能得到真实的颜色人口，从而查到正确的输出符号。

## 新题 7：色带排序指定锚块命运

**组合逻辑**：[压缩](已有) + [滑动/紧缩](创新：压缩结果决定哪个锚块被紧缩、哪个被擦除) + [擦除](创新：擦除目标由色带排序的末位决定) + [空间排列顺序](已有) + [同色射线归属锚块](已有)

**来源原语**：压缩(4be741c5), 色带(4be741c5), 空间排列顺序(4be741c5), 行主色压缩单像素(4be741c5), 滑动(f28a3cbb), 锚块(f28a3cbb), 射线像素(f28a3cbb), 同色射线归属锚块(f28a3cbb), 射线像素紧缩至锚(f28a3cbb), 擦除(3345333e)

**依赖链**：色带按行主色压缩为颜色序列（压缩）→ 序列中的首色和末色映射到对应锚块（空间排列顺序）→ 首色锚块执行射线紧缩，末色锚块连同射线被整体擦除（差异化操作）

色带的空间顺序编码了一条隐式指令：排在最前的颜色"存活并收缩"，排在最后的颜色"连根拔除"——背景图案是前景对象的判决书。

**输入结构**：约 14x14 的网格，无黑色背景——整个网格被 3~5 种颜色的水平色带完全覆盖（每种颜色占据若干连续行，行内可能有边界锯齿但每行有明确的主色）。网格中叠放着恰好 2 个 3x3 实心锚块，颜色分别与色带序列的首色和末色相同。每个锚块有若干同色的射线像素沿行、列或 45 度对角线方向散布（与参考题 f28a3cbb 结构相同：每个前景色有一个 3x3 块和沿八邻射线的同色散点）。生成约束：色带序列中的首色和末色各恰好对应一个锚块；色带序列长度至少 3（确保首末不同）。

**规则**：
1. 对每一行确定主色（该行中像素数最多的颜色，忽略锚块和射线像素所占的格），得到从上到下的行主色序列。将连续相同主色合并为一个色带，得到色带颜色序列。
2. 取序列首色（最上方色带的颜色）对应的锚块为"存活锚"，取序列末色（最下方色带的颜色）对应的锚块为"淘汰锚"。
3. 对存活锚：保持 3x3 锚块不动，将该色所有散布的射线像素沿各自射线方向向锚块紧缩，使它们依次填入锚块周围的相邻格中（与参考题 f28a3cbb 规则相同）。
4. 对淘汰锚：将该色的 3x3 锚块及其所有射线像素全部擦除，替换为各位置所在行的色带主色。
5. 不属于首色或末色的其他锚块（若存在）及其射线像素保持原位不变。
6. 色带背景保持不变（除了淘汰锚擦除后露出的色带颜色）。

**关键洞察**：色带看似只是背景装饰，实则编码了一个排序——该排序决定了前景对象的生死；如果色带顺序翻转，存活和淘汰的锚块也会互换。

## 新题 8：标记密度编码放大倍率的模板复制

**组合逻辑**：[选择](创新：最少标记选出模板而非直接输出) + [计数](创新：标记数编码缩放因子) + [像素放大](创新：放大倍率因对象而异，由计数结果决定) + [重涂色](创新：放大时用目标矩形的填充色替换模板的填充色) + [最少标记数](已有)

**来源原语**：选择(7bb29440), 裁剪(7bb29440), 前景矩形(7bb29440), 标记像素(7bb29440), 最少标记数(7bb29440), 计数(37ce87bb), 像素放大(46f33fce), 缩放(46f33fce), 重涂色(9caf5b84)

**依赖链**：标记数最少的矩形被选为模板（选择）→ 其他矩形各自的标记数成为各自的缩放因子（计数→缩放因子）→ 模板按缩放因子放大并重涂为各目标矩形的填充色（像素放大+重涂色），替换各目标矩形

最稀疏的对象成为蓝图，其余对象的内部标记密度编码了蓝图应被放大到多大——密度即倍率指令。

**输入结构**：约 15x15 的黑(0)背景网格。网格中有 3~5 个互不相邻的实心前景矩形（每个矩形为一种颜色的实心区域，不同矩形颜色各不相同，如红(2)、蓝(1)、绿(3)、黄(4)），尺寸均为 3x2 或 2x3。每个矩形内部有 0~3 个灰(5)标记像素（标记覆盖了矩形填充色的对应格）。生成约束：恰好有一个矩形的标记数严格最少（无平局），且该矩形标记数为 0 或 1；其他矩形的标记数均 >= 2，互不相同且不超过 3。各矩形之间间距足够大，放大后的对象不会重叠或超出网格边界。

**规则**：
1. 统计每个前景矩形内部灰(5)标记像素的数量。
2. 标记数严格最少的矩形成为"模板"。裁剪该模板（保留其形状和内部标记的相对位置），记录其填充色为"模板色"。
3. 对于每个非模板矩形：
   a. 取其标记数 n 作为缩放因子。
   b. 将模板按 n 倍放大（每个像素变为 n x n 的块）。
   c. 将放大后图案中的"模板色"像素全部替换为该非模板矩形自身的填充色。灰(5)标记像素放大后仍为灰(5)。
   d. 将放大后的图案放置到以该非模板矩形原始边界框左上角为锚点的位置，覆盖原矩形及其周围的黑色区域。
4. 模板矩形本身保持原尺寸、原位置、原颜色不变。
5. 生成约束：所有放大后图案不会相互重叠，也不会超出网格边界，也不会覆盖模板矩形。

**关键洞察**：灰色标记在模板选择和放大倍率中起双重作用——数量最少使一个矩形成为蓝图，而其他矩形的标记数量则编码了该蓝图应被放大的倍率；标记不是噪声，而是元指令。
