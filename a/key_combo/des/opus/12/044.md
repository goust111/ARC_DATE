## 新题 1：滑轨穿越封域染色

**组合逻辑**：[滑动(slide)](创新：滑动轨迹作为空间查询路径) + [洪泛填充(flood_fill)](创新：填充色由穿越的滑块决定) + [重涂色(recolor)](已有原语)

**来源原语**：滑动/边缘矩形/轨迹条纹/接触边缘/滑至对侧边缘(b25e450b)、洪泛填充/封闭区域/墙壁线段/区域封闭/孤立背景区域填充(a5313dff)、重涂色(ea32f347)

**依赖链**：洪泛填充识别出哪些区域是封闭的（结构分析）；滑动产生跨越网格的轨迹路径；轨迹是否穿过某个封闭区域决定了该区域的填充色——三者缺一不可：无洪泛填充则不知哪些区域需要染色，无滑动则不知用什么颜色染，无两者交叉则输出未定义。

将边缘彩色矩形滑向对侧，其轨迹穿过的封闭区域被染上该矩形的颜色；矩形本身到达对侧后消失，未被穿越的封闭区域保持背景色。

**输入结构**：约 18x18 的黑(0)背景网格。红(2)像素构成若干一像素宽的墙壁线段（水平或垂直），这些墙壁与网格边界共同围成若干封闭区域和若干开放区域。另有 2~4 个单色小矩形（宽 1~2、高 1~3 的 4-连通块，每个颜色各异，可能为蓝(1)、绿(3)、黄(4)、橙(7)），每个矩形恰好有一条边贴合网格的某一外边缘（上/下/左/右）。生成约束：每个封闭区域至多被一个矩形的滑行轨迹穿过；不同矩形的滑行轨迹互不经过同一封闭区域；至少有一个封闭区域不被任何轨迹穿过。

**规则**：
1. 用洪泛填充从网格四周边界出发（4-邻接），标记所有能到达边界的背景像素为"外部"。不能到达边界的背景连通分量即为"封闭区域"。
2. 每个贴合外边缘的彩色矩形沿垂直于其贴边的方向滑向对侧边缘。贴上边缘的向下滑，贴下边缘的向上滑，贴左边缘的向右滑，贴右边缘的向左滑。矩形沿途扫过的所有列（或行）构成其"轨迹带"。
3. 对于每个封闭区域，检查是否有某个矩形的轨迹带穿过该区域（轨迹带中存在属于该封闭区域的背景像素）。若有，将该封闭区域的所有背景像素染为该矩形的颜色。
4. 矩形本身在输出中被擦除（不画在对侧边缘，也不保留原位）。轨迹带中不属于任何封闭区域的像素保持背景色。
5. 未被任何轨迹穿过的封闭区域保持黑(0)背景。
6. 所有红(2)墙壁像素保持不变。

**关键洞察**：滑块的轨迹不是视觉输出（不画条纹），而是一条空间查询路径——它"扫描"了哪些封闭区域，就把自身颜色赋予那些区域。必须对比多个示例才能发现轨迹不留痕而仅作为区域着色的媒介。

## 新题 2：类型约束下的连接件对接堆叠

**组合逻辑**：[分类(classify)](已有原语) + [拼接(stitch)](创新：拼接受分类结果约束，仅同类型内匹配) + [堆叠(stack)](已有原语)

**来源原语**：分类/排序/堆叠/空心矩形/实心方块/按类型分列/内部判定类型(2ba387bc)、拼接/裁剪/连接标记/前景物体/同色标记对齐对接/标记侧面决定方向(e9fc42f2)

**依赖链**：分类决定了哪些物体属于同一组，从而约束了连接件的配对范围（跨组同色连接件不对接）；拼接改变了物体的尺寸和形态，影响最终堆叠布局；堆叠需要知道分类结果来确定列位置。三步操作形成分叉-汇合结构：分类结果同时流入拼接（约束配对）和堆叠（决定列）。

将散落的方形物体按内部结构分为空心和实心两类，同类中连接标记颜色相同的一对物体沿标记侧面对接拼合，最终将所有拼合体和未配对单体按类型分列堆叠。

**输入结构**：约 20x20 的灰(5)背景网格。散布 4~6 个 4x4 的单色物体（颜色可为蓝(1)、红(2)、绿(3)、黄(4)、橙(7)），其中一部分是空心框（1 像素宽边框、内部 2x2 为灰(5)背景），另一部分是实心填充块（4x4 全为该颜色）。每个物体的边框上恰有一个像素被替换为品红(6)或栗(9)的连接标记。同一标记颜色在同一类型组（空心组或实心组）内恰好出现 0 次或 2 次（0 次表示该颜色未被使用）。生成约束：至少有一对同类型同色连接件；至少有一个物体无配对（该类型组内其标记颜色唯一）；物体之间在输入中互不相邻（间距至少 2 像素）。

**规则**：
1. 检查每个 4x4 物体的内部 2x2 区域：若全为灰(5)背景，分类为"空心"；否则分类为"实心"。
2. 在同一分类组内，找到连接标记颜色相同的两个物体组成配对。跨组的同色标记不配对。
3. 对每对配对物体，确定各自连接标记在物体边框上的方位（上/下/左/右边），将两个物体平移使连接标记相邻对接（标记像素在输出中保留）。对接时，标记在上边的物体放在上方、标记在左边的放在左方，以此类推。
4. 将所有拼合体和未配对单体按分类堆叠：空心类占输出左半（列 0 起），实心类占输出右半（紧邻左半右侧，间隔 0 列）。
5. 每列内，拼合体和单体按其在原输入中最上方像素的行坐标从小到大自上而下排列，相邻两个之间无间隔行。
6. 输出宽度 = 左列最大宽度 + 右列最大宽度；高度 = 两列中较高者。空余区域填充灰(5)背景。

**关键洞察**：连接标记的颜色匹配只在分类组内生效——必须对比含有跨组同色标记的示例才能归纳出这一约束，否则会错误地将不同类型的物体对接。

## 新题 3：字形解码驱动射线发射

**组合逻辑**：[解码(decode)](创新：字形编码方向而非颜色) + [射线延伸(ray_cast)](创新：方向由解码结果决定) + [擦除(erase)](已有原语)

**来源原语**：裁剪/解码/排序/字形图案/位置映射/字形映射颜色行(995c5fa3)、射线延伸/菱形轮廓/对角线段/端点发射/碰撞停止(80a900e0)、擦除(981add89)

**依赖链**：字形解码产出方向信息，而非颜色信息（创新改造）；种子像素通过颜色匹配绑定到特定字形，从而获得发射方向；射线碰撞停止规则使得多条射线的空间布局相互制约。无解码则方向不确定，无颜色匹配则种子与字形的绑定断开，无碰撞则射线输出无空间交互。

读取左区字形解码出四个基本方向，右区的种子像素按颜色绑定各自的字形后，沿解码方向发射射线直到碰撞或抵达边界；输出仅保留右区的种子和射线。

**输入结构**：约 15x20 的黑(0)背景网格，被一列灰(5)垂直分隔线分为左右两区。左区包含 2~4 个 3x3 的字形方块，每个字形的边框为某种非黑非灰颜色（如蓝(1)、红(2)、绿(3)、黄(4)），内部 1 个像素在九宫格的上/下/左/右四个非角位置之一为该边框色、其余为黑(0)。内部亮像素的位置编码方向：上→向上，下→向下，左→向左，右→向右。右区包含若干单像素种子，每个种子的颜色恰好匹配左区某个字形的边框色。同一颜色的种子可以有多个，对应同一方向。生成约束：左区字形颜色互不相同；右区每种颜色的种子至少 1 个、至多 3 个；射线在碰撞前的路径上不与分隔线或左区重叠。

**规则**：
1. 对左区每个 3x3 字形，识别内部亮像素的位置，解码为方向（中心偏上=向上，中心偏下=向下，中心偏左=向左，中心偏右=向右）。
2. 对右区每个种子像素，找到与之颜色相同的字形，获取该字形编码的方向。
3. 按照种子在网格中从上到下、同行从左到右的顺序，依次从每个种子出发沿其方向逐像素延伸射线，将路径上的背景像素涂为该种子的颜色。射线在遇到非背景像素（包括其他种子、其他射线、分隔线）或网格边界时停止，停止处的像素不涂色。
4. 输出时擦除左区和分隔线：输出仅包含右区（裁剪掉左区和分隔列），保留右区的种子像素和所有射线。

**关键洞察**：字形在源题中编码颜色，而此处编码方向——这一语义转换必须通过对比多个示例中种子射线方向与字形内部像素位置的对应关系才能归纳出。

## 新题 4：周期壁垒约束下的最短路径连接

**组合逻辑**：[补全(completion)](已有原语) + [连接(connect)](创新：将补全后的前景像素作为路径障碍) + [周期重复(periodic_repeat) x 起终点之间(between_endpoints)](创新交叉：周期结构定义障碍地图，路径在障碍间穿行)

**来源原语**：补全/平铺/周期瓦片/缺损像素/周期重复/前景残留推断周期(ea959feb)、连接/连线/起点标记/终点标记/路径/起终点之间/切比雪夫最短路径(992798f6)

**依赖链**：补全操作恢复周期壁纸图案，产出前景像素地图；连接操作将该地图作为障碍约束来规划路径——补全的输出直接决定了路径的可行走区域。单独做补全则忽略路径需求，单独做路径则不知哪些是障碍。两个操作同时约束同一网格，形成"结构解构+约束满足"的非线性骨架。

在一个被部分擦除的周期壁纸上恢复完整图案，然后在壁纸的背景空隙中寻找一条从蓝标记到红标记的最短 king-move 路径（仅走背景像素），用绿色绘制该路径。

**输入结构**：约 16x16 的网格，主体是一个多色周期壁纸图案（以黑(0)为背景，前景色可能包含黄(4)、橙(7)、品红(6)等），部分前景像素已被擦除为黑(0)。壁纸的最小重复瓦片约 3x3 至 5x5。网格中另有一个蓝(1)像素和一个红(2)像素，两者都位于壁纸的背景位置（即该位置在完整壁纸中本应为黑(0)）。蓝(1)和红(2)不属于壁纸图案。生成约束：蓝和红标记之间在完整壁纸的背景像素上存在至少一条 8-邻接连通路径；壁纸图案保证背景像素形成连通网络而非孤立点。

**规则**：
1. 忽略蓝(1)和红(2)像素，根据其余可见前景像素推断壁纸的最小行周期和列周期。
2. 用推断的周期将所有被擦除的前景像素恢复为其对应的壁纸颜色。
3. 在完整壁纸上，将所有非黑(0)像素视为不可通行的障碍（蓝和红标记位置视为可通行）。
4. 从蓝(1)像素出发，沿 8-邻接（king-move）寻找到红(2)像素的最短路径。路径仅经过黑(0)背景像素和两个标记像素本身。
5. 将路径上除蓝(1)和红(2)之外的所有像素涂为绿(3)。蓝和红标记保持原色。
6. 若存在多条等长最短路径，选择字典序最小的路径（将每步方向编码为 0~7，按上、右上、右、右下、下、左下、左、左上的顺序，选路径方向序列字典序最小者）。

**关键洞察**：被擦除的像素可能恰好位于两个标记之间的"捷径"上——只有先正确补全壁纸，才能知道这些位置是障碍还是通路，从而找到真正的最短路径。必须对比示例中路径绕行的方式才能发现补全后的像素是障碍。

## 新题 5：四面板叠合后的像素普查与压缩排序

**组合逻辑**：[透明叠加(transparent_overlay)](已有原语) + [计数(count)](已有原语) + [排序(sort) + 压缩(compress)](创新：将叠加后的可见像素统计压缩为单列排序输出)

**来源原语**：透明叠加/裁剪/面板/图层优先级/面板位决定层序(ea9794b1)、压缩/计数/排序/色条/高度编码数量(a1aa0c1e)

**依赖链**：叠加决定了哪些像素可见（被遮挡的不计数）；计数将空间信息转化为数值信息；排序将数值信息转化为顺序信息。三步中每一步都对信息做了不可逆变换——去掉叠加则计数对象错误，去掉计数则排序无依据，去掉排序则输出格式不确定。

将 2x2 排列的四个面板按位置层序叠合，统计叠合结果中每种前景色的可见像素数量，按数量从多到少输出一列色块。

**输入结构**：约 14x14 的灰(5)背景网格，均分为 2x2 的四个 7x7 面板（无间隔）。每个面板包含一种独有的非背景前景色（四个面板的前景色互不相同，可能为蓝(1)、红(2)、绿(3)、黄(4)、橙(7)等）。每个面板中前景色像素构成一个 4-连通的不规则图形（3~12 像素），其余为灰(5)背景。四个面板中的前景图形在对应位置可能存在重叠（即不同面板中前景像素映射到同一输出位置）。生成约束：至少有两对面板在某些位置存在重叠；四种前景色的最终可见像素数量互不相同。

**规则**：
1. 创建一个与单个面板同尺寸的输出画布，初始化为灰(5)。
2. 按固定层序依次将四个面板的非背景像素绘制到画布上：先画左上面板，再画右下面板，再画左下面板，最后画右上面板。后画的覆盖先画的。
3. 统计画布上每种前景色的可见像素数量。
4. 按像素数量从多到少排列所有前景色。
5. 输出一个 Nx1 的列（N = 前景色种数，通常为 4），从上到下依次填入排序后的颜色，每个颜色占一个像素。

**关键洞察**：层序（左上 < 右下 < 左下 < 右上，后者优先级高）不是直觉顺序，必须通过对比多个示例中哪些面板的像素被遮挡来归纳。遮挡改变了计数结果，进而改变排序输出。

## 新题 6：滑块遇控制点的切换偏折

**组合逻辑**：[滑动(slide)](创新：滑行可被中途偏折) + [切换重涂色(toggle_recolor)](创新：切换逻辑从垂直射线改为滑行途中的碰撞判定) + [射线延伸(ray_extend)](创新：偏折后以控制点为新起点发射垂直射线)

**来源原语**：滑动/边缘矩形/轨迹条纹/接触边缘/滑至对侧边缘(b25e450b)、射线延伸/切换重涂色/擦除/控制像素/网格边缘/同列对齐/颜色匹配(981add89)

**依赖链**：滑块颜色与控制像素颜色的匹配/不匹配决定了两种完全不同的行为分支（穿越 vs 偏折），形成条件分支结构。偏折后的射线方向取决于控制像素相对于网格中线的位置，引入空间判断。滑动、颜色匹配、射线延伸三者在每个碰撞事件中同时交互。

边缘彩色矩形沿垂直方向滑向对侧；途中若遇同色控制像素则穿越并擦除该像素，若遇异色控制像素则停止并从该控制像素出发沿水平方向发射一条该控制像素颜色的射线。

**输入结构**：约 15x15 的黑(0)背景网格。有 2~3 个单像素宽、1~2 像素高的彩色小矩形（颜色为蓝(1)、红(2)、绿(3)中的不同色），每个恰好贴合网格的上边缘或下边缘。网格内部散布 3~5 个孤立的控制像素，颜色也为蓝(1)、红(2)、绿(3)之一。每个控制像素恰好位于某个边缘矩形的滑行路径（同列）上。生成约束：每个边缘矩形的滑行路径上至少有一个控制像素；同一滑行路径上不会出现两个异色控制像素（即最多偏折一次）；偏折产生的水平射线不会经过其他控制像素。

**规则**：
1. 每个边缘矩形沿垂直于贴边的方向逐像素滑行（贴上边缘→向下，贴下边缘→向上）。
2. 滑行过程中，将经过的每个背景像素涂为该矩形的颜色（留下轨迹条纹）。
3. 若滑行遇到与自身同色的控制像素：擦除该控制像素为背景色，轨迹条纹继续涂色，滑行不中断地继续向前直到网格边缘。
4. 若滑行遇到与自身异色的控制像素：滑行立即停止（停止位置为控制像素前一格，控制像素保留不变），不再继续向前。然后从该控制像素的位置出发，沿水平方向发射一条该控制像素颜色的射线。射线方向为朝向更近的左/右网格边缘（若等距则朝左）。射线逐像素涂色直到网格边缘。
5. 所有滑块按从左到右的列顺序依次处理。后处理的滑块轨迹覆盖先处理的。
6. 边缘矩形在原始贴边位置保留其颜色。

**关键洞察**：同色控制像素被"吞噬"（穿越并擦除），异色控制像素引发"偏折"（停止并射线转向）——这一颜色匹配分支规则必须通过对比包含同色和异色碰撞的不同示例才能归纳。

## 新题 7：精灵体按尺寸匹配入框并染框

**组合逻辑**：[平移(translate) + 对齐(align)](创新：多对多匹配而非一对一) + [分类(classify)](创新：按尺寸兼容性分类配对) + [重涂色(recolor)](已有原语)

**来源原语**：平移/对齐/精灵体/引导标记/锚点对齐/跨面板搬运(dc46ea44)、重涂色/裁剪/空心矩形/模板/包含/尺寸匹配/框架色传递同形(890034e9)、重涂色/擦除/最近邻选择/欧氏距离最小(6df30ad6)

**依赖链**：尺寸匹配决定精灵体-框架配对（约束满足问题，非线性管道）；配对结果同时决定平移目标和框架染色——两个输出依赖同一个匹配决策。若匹配错误，平移位置和框架颜色都错。当存在尺寸歧义时，欧氏距离作为仲裁条件介入，使得空间位置信息也参与决策。

将多个彩色精灵体按尺寸匹配放入灰色空心框中（居中对齐），并将框边框染为对应精灵体的颜色；无匹配的框被擦除。

**输入结构**：约 20x20 的黑(0)背景网格。散布 2~4 个单色 4-连通精灵体（不规则形状，3~8 像素，每个颜色不同，可能为蓝(1)、红(2)、绿(3)、黄(4)），以及 3~5 个灰(5)空心矩形框（1 像素宽边框，内部为黑(0)背景）。框的内部尺寸各不相同（从 3x3 到 7x7 不等）。生成约束：每个精灵体的边界框尺寸恰好匹配某个框的内部尺寸（精灵体边界框 <= 框内部尺寸，且差值在行和列上均不超过 2）；不同精灵体匹配不同的框（一一对应）；至少有一个框无匹配（框数 > 精灵体数）；精灵体和框在输入中互不重叠。

**规则**：
1. 计算每个精灵体的边界框尺寸 (Ws, Hs) 和每个框的内部尺寸 (Wf, Hf)。
2. 精灵体 S 可匹配框 F 当且仅当 Ws <= Wf 且 Hs <= Hf 且 (Wf - Ws) + (Hf - Hs) 最小（总间隙最小）。
3. 若一个精灵体可匹配多个总间隙相同的框，选择精灵体中心到框中心欧氏距离最小的框。
4. 确定所有配对后，将每个精灵体平移到其匹配框的内部中心位置（精灵体边界框中心对齐框内部中心，若不能精确居中则偏左偏上）。
5. 将每个被匹配框的灰(5)边框重涂色为其对应精灵体的颜色。
6. 未被匹配的框（无精灵体配对）连同其边框一起擦除为黑(0)背景。
7. 精灵体原始位置擦除为黑(0)背景。

**关键洞察**：尺寸匹配的度量是"总间隙最小"而非"精确相等"——必须对比精灵体边界框与框内部尺寸不完全相等的示例才能归纳出这一弹性匹配规则。欧氏距离仅在尺寸歧义时介入，单个示例可能无歧义，因此需要多示例才能发现距离仲裁。

## 新题 8：封闭区域的标记投票染色

**组合逻辑**：[洪泛填充(flood_fill)](已有原语) + [计数(count)](创新：区域内标记计数决定填充色) + [重涂色(recolor)](已有原语) + [最近邻选择(nearest_neighbor_selection)](创新：作为计数为零时的后备规则)

**来源原语**：洪泛填充/封闭区域/墙壁线段/画布边界/区域封闭/孤立背景区域填充(a5313dff)、计数/填充/标记像素/计数映射尺寸(878187ab)、重涂色/擦除/前景对象/标记像素/最近邻选择/欧氏距离最小(6df30ad6)

**依赖链**：洪泛填充识别封闭区域（结构分析）；标记像素计数在每个区域内独立进行（空间包含判定）；计数结果的多数色决定填充色（投票机制）；无标记区域退化为最近邻规则（后备路径）。四种机制形成"多源汇聚"结构——区域边界、标记位置、标记颜色、空间距离四路信息同时汇入最终决策。

红色墙壁围出的每个封闭区域，由其内部散落的彩色标记像素"投票"决定填充颜色（多数色胜出）；无内部标记的区域取最近外部标记的颜色。

**输入结构**：约 16x16 的黑(0)背景网格。红(2)像素构成一像素宽的墙壁线段（水平和垂直），与网格边界共同围成 3~6 个封闭区域和若干开放背景。网格中另有若干孤立的彩色标记像素（颜色为蓝(1)、绿(3)、黄(4)），标记分布在封闭区域内部和外部（开放背景上）。生成约束：至少有两个封闭区域内部含有标记像素；至少有一个封闭区域内部无标记（需使用最近邻后备规则）；含标记的区域中，至少一个区域有两种颜色的标记且数量不等（存在投票竞争）；每个封闭区域面积至少 4 个像素。

**规则**：
1. 将红(2)像素视为墙壁，用 4-邻接洪泛填充从网格边界出发标记所有外部背景像素。不可达的背景像素连通分量为封闭区域。
2. 对每个封闭区域，统计其内部各颜色标记像素的数量。取数量最多的颜色作为该区域的填充色。
3. 若某个封闭区域内部无标记像素，则对该区域中每个背景像素计算到所有标记像素（包括区域外的标记）的欧氏距离，取距离最小的标记像素的颜色作为该区域的填充色。若多个标记等距，取行坐标最小者；仍相同则取列坐标最小者。
4. 若计数出现平局（两种颜色数量相同），采用与规则 3 相同的最近邻后备：从该区域的所有像素中找到距离最近的一个标记像素（无论区域内外），用该标记颜色填充。
5. 用确定的颜色填充每个封闭区域的所有背景像素。
6. 擦除所有标记像素（无论区域内外均置为黑(0)背景）。红(2)墙壁和外部背景保持不变。

**关键洞察**：区域内标记是"选票"，多数色胜出——但空区域和平局区域都退化为最近邻规则，这两条后备路径必须通过观察不同示例中"有标记区域"和"无标记区域"的不同行为才能归纳出完整规则。
