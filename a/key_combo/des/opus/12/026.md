## 新题 1：镜像缺陷定位与差异提取

**组合逻辑**：[镜像(mirror)](已有) + [提取(extract)](已有) + [擦除(erase)](已有) → 组合创新：镜像一致性验证作为缺陷检测条件，差异像素提取作为输出

**来源原语**：镜像(mirror)←0c786b71, 提取(extract)←d9fac9be, 四象限对称(four_quadrant_symmetry)←0c786b71, 颜色异常值选择(outlier_color_selection)←0b148d64, 裁剪(crop)←0b148d64

**依赖链**：必须先理解四象限镜像关系才能判断哪个象限不一致；必须通过对比重建"正确版本"才能定位差异像素；最终提取依赖于前两步的结果。三步缺一不可。

从一个被篡改的四象限镜像马赛克中找出破坏对称性的象限，提取其中与正确版本不同的像素。

**输入结构**：约 14×14 的网格，由一条水平和一条垂直的黑(0)分隔线将网格分为四个大小相同的象限（每个约 6×6）。四个象限中填有由蓝(1)和红(2)像素构成的图案（背景为黑(0)）。其中三个象限构成合法的镜像马赛克关系：右下象限为"原始"，左下为原始的左右镜像，右上为原始的上下镜像，左上为原始的180度旋转。第四个象限（被篡改的那个）总体形状与其应有的镜像版本一致，但其中恰好有 1~3 个像素的颜色被改动（从蓝(1)变为红(2)或反之，或从前景色变为黑(0)，或从黑(0)变为前景色）。生成约束：被篡改的象限在不同示例中位置不同（可能是任意一个象限）；篡改的像素数量和位置在不同示例中不同；三个未篡改象限严格满足镜像关系。

**规则**：
1. 识别四个象限及其分隔线位置。
2. 对每个象限，检验它与其他三个象限的镜像一致性：将其他三个象限按镜像关系映射到该象限的坐标系中，比较像素是否完全匹配。被篡改的象限与至少两个其他象限的映射不一致。
3. 利用三个一致象限中的任意一个，通过对应的镜像变换重建被篡改象限的"正确版本"。
4. 逐像素比较被篡改象限的实际内容与正确版本，找出所有不同的像素位置。
5. 输出一个与象限等大的网格（约 6×6），背景为黑(0)，仅在差异像素位置保留被篡改象限中的实际颜色。

**关键洞察**：异常象限的检测不是通过颜色频率（不同于 0b148d64 的颜色异常值），而是通过几何对称性验证——必须理解镜像变换才能判断哪个象限"不对"，这把镜像构造规则从生成工具变成了验证工具。

## 新题 2：多米诺定向射线与轮廓阻隔

**组合逻辑**：[描边(outline)](已有) + [射线延伸(ray_extend)](创新：射线方向由对象朝向决定而非开口方向) + [尺寸分类(size_classification)](已有) → 组合创新：描边产生的轮廓成为射线的阻隔壁

**来源原语**：描边(outline)←b27ca6d3, 射线延伸(ray_extend)←d4f3cd78, 尺寸分类(size_classification)←b27ca6d3, 碰撞阻挡(collision_blocking)←1f642eb9, 微型对象描边(micro_obj_outlined)←b27ca6d3

**依赖链**：尺寸分类决定哪些对象触发描边+射线（仅多米诺骨牌）；描边产生绿色轮廓框；射线从多米诺的每个像素出发沿垂直于多米诺轴的方向延伸；一个多米诺的绿色轮廓成为另一个多米诺射线的阻隔壁。描边与射线互为因果——没有描边就没有阻隔壁，没有射线就不需要阻隔。

识别红色多米诺骨牌，为其绘制绿色轮廓并沿垂直于多米诺方向发射青色射线，射线被其他多米诺的轮廓阻挡。

**输入结构**：约 15×15 的黑(0)背景网格。网格上散布若干红(2)前景像素，它们形成多个 4-连通对象。每个对象要么是孤立单像素（1 个像素），要么是两像素的多米诺骨牌（水平相邻的 1×2 或垂直相邻的 2×1）。不存在 3 像素及以上的红色对象。不同示例中多米诺和单像素的数量、位置、朝向各不相同。生成约束：任意两个多米诺的边界框（扩展 1 格后）互不重叠；至少存在一对多米诺使得其中一个的射线方向上存在另一个的轮廓。

**规则**：
1. 找出所有红(2)的 4-连通对象并按像素数分类。
2. 单像素对象：保持不变，不做任何处理。
3. 多米诺对象（恰好 2 像素）：
   a. 计算其边界框，将边界框向外扩展 1 格（裁剪到网格边界）。在扩展后边界框的周边位置，凡是当前为黑(0)的像素涂为绿(3)。
   b. 确定多米诺的朝向：水平（两像素在同一行）或垂直（两像素在同一列）。
   c. 从多米诺的每个像素出发，沿垂直于多米诺轴的两个方向各发射一条青(8)射线。水平多米诺→每个像素向上和向下各射一条线；垂直多米诺→每个像素向左和向右各射一条线。
   d. 射线逐像素延伸，遇到任何非黑(0)像素（包括绿色轮廓、红色像素、其他青色射线）立即停止，不覆盖终点像素。
4. 所有多米诺的描边（步骤 3a）在所有射线绘制（步骤 3c-d）之前完成。即先画完所有绿色轮廓，再画所有青色射线。

**关键洞察**：一个多米诺的绿色轮廓框是另一个多米诺射线的障碍物——描边操作的输出成为射线延伸操作的终止条件，这种跨对象的操作依赖在源题中不存在。

## 新题 3：内嵌标记排序的空心框打包

**组合逻辑**：[排序(sorting)](创新：排序键由框内部标记的空间位置决定，而非框自身位置) + [擦除(erase)](已有) + [拼接(concatenate)](已有) → 组合创新：内含物属性决定容器的排列顺序

**来源原语**：排序(sorting)←a680ac02, 擦除(erase)←a680ac02, 拼接(concatenate)←a680ac02, 空心矩形(hollow_rect)←868de0fa/a680ac02, 标记像素(marker_pixel)←db7260a4, 实心方块(solid_square)←a680ac02, 包含(containment)←868de0fa, 忽略干扰项(ignore_distractors)←a680ac02, 仅保留空心对象(hollow_only_retained)←a680ac02

**依赖链**：首先滤除干扰项（实心方块），仅保留空心框；然后读取每个空心框内部的标记像素颜色；标记颜色通过一个固定映射确定排序优先级；最后按此优先级将空心框（含标记）拼接成条带。排序键来自框内部而非外部，缺少包含关系分析就无法排序。

过滤掉实心干扰方块，按空心框内部标记像素的颜色优先级排序，打包成条带。

**输入结构**：约 20×20 的黑(0)背景网格。散布有若干蓝(1)的 4×4 单色对象。对象分两类：空心正方形框（边框为蓝(1)、内部 2×2 为黑(0)且框内恰好有 1 个非蓝非黑的标记像素）和实心正方形（4×4 全蓝）。空心框的内部 2×2 区域的 4 个像素中，恰好 1 个为标记像素（颜色从红(2)、绿(3)、黄(4)、灰(5)中选取），其余 3 个为黑(0)。标记像素在内部 2×2 中的位置在不同框中各不相同。不同示例中空心框和实心方块的数量（空心框至少 3 个，实心方块至少 1 个）、位置各不相同。每个空心框内部标记像素颜色互不相同。空心框的位置展开方向（沿行或沿列更分散）在不同示例中不同。

**规则**：
1. 识别所有蓝(1)的 4×4 对象。判定空心或实心：内部 2×2 区域全为蓝(1)则为实心，否则为空心。
2. 丢弃所有实心方块。
3. 对每个空心框，找到其内部 2×2 区域中唯一的非黑标记像素，记录其颜色。
4. 按标记颜色排序：红(2) < 绿(3) < 黄(4) < 灰(5)。此优先级的含义是红色排最前。
5. 判定打包方向：若空心框原始位置沿列方向的跨度大于沿行方向，则从左到右水平拼接；否则从上到下垂直拼接。
6. 将排序后的空心框（含其标记像素和蓝色边框）依次紧贴排列，框与框之间无间隙。输出网格大小恰好容纳所有框。

**关键洞察**：排序键不是框自身的空间位置（不同于 a680ac02 中按原始位置排），而是框内部所包含的标记像素的颜色——必须对比多个示例才能归纳出颜色到优先级的映射关系，仅看单个示例可能将排序键误判为框的位置或标记在框内的位置。

## 新题 4：面板对角选取与接缝对齐拼接

**组合逻辑**：[裁剪(crop)](已有) + [合并(merge)](创新：选取策略由面板序号确定纵向排名) + [重涂色(recolor)](已有) + [接缝对齐(seam_alignment)](已有) → 组合创新：面板索引与对象纵向排位形成对角选取矩阵

**来源原语**：裁剪(crop)←5ecac7f7, 合并(merge)←5ecac7f7, 重涂色(recolor)←234bbc79, 等分面板(equal_panel)←5ecac7f7, 分隔条(separator_bar)←5ecac7f7, 精灵体(sprite)←234bbc79, 标记像素(marker_pixel)←234bbc79, 位序选择(positional_selection)←5ecac7f7, 接缝对齐(seam_alignment)←234bbc79, 面板序号选对象(panel_selects_obj)←5ecac7f7, 控制像素对齐拼接(control_pixel_concat)←234bbc79

**依赖链**：面板索引决定从该面板中选取纵向第几个对象（对角选取）；选出的对象通过灰色接缝标记对齐垂直位置；接缝标记重涂为对象本色。面板索引→纵向排名→选取对象→接缝对齐→重涂色，每一步的输出都是下一步的必需输入。

从 N 个面板中按"面板序号=纵向排名"的对角规则选取对象，通过灰色接缝标记对齐拼接并重涂色。

**输入结构**：约 12×(8N+N-1) 的网格（N 为面板数，通常 3~4），由 N 个等宽的面板组成，面板之间以 1 列宽的灰(5)分隔条分隔。每个面板背景为黑(0)，内含 N 个 8-连通的单色前景对象（每个对象使用不同的非黑非灰颜色，像素数 3~8，形状为不规则连通图形）。同一面板内的 N 个对象在垂直方向上互不重叠（各自的边界框行范围不交叉），可按边界框顶行坐标从小到大排出第 1~第 N 名。每个对象在其边界框的最右列恰好有 1 个灰(5)像素（右接缝标记），在最左列恰好有 1 个灰(5)像素（左接缝标记）。生成约束：不同面板中同一纵向排名的对象的接缝标记行坐标不必相同（正是接缝对齐需要解决的偏移问题）。

**规则**：
1. 通过灰(5)分隔条识别面板边界，将面板从左到右编号为 1, 2, ..., N。
2. 在每个面板内，将所有前景对象按其边界框顶行坐标从小到大排序，排名为 1（最上）到 N（最下）。
3. 对角选取：从面板 k 中选取纵向排名为 k 的对象。即面板 1 取最上方对象，面板 2 取第二上方对象，面板 3 取第三上方对象，以此类推。
4. 将选出的 N 个对象裁剪到各自的边界框。
5. 从左到右拼接裁剪后的对象，紧贴排列无间隙。第一个对象保持其裁剪框内的相对位置；后续每个对象的垂直偏移量由接缝对齐决定：前一个对象右接缝标记的行坐标必须与当前对象左接缝标记的行坐标对齐到同一输出行。
6. 将所有灰(5)接缝标记像素重涂为该对象的主色（即该对象中唯一的非灰非黑颜色）。

**关键洞察**："面板序号=纵向排名"的对角选取规则是隐蔽的——仅看单个示例，可能误以为是"每面板选最大的""每面板选特定颜色的"；必须对比多个示例（面板数不同、对象排列不同）才能归纳出序号与排名的对应关系。

## 新题 5：四象限杯体填充与跨域射线交叉

**组合逻辑**：[镜像(mirror)](已有) + [填充(fill)](已有) + [射线延伸(ray_extend)](创新：射线方向由镜像变换决定的开口朝向而非原始开口) → 组合创新：镜像变换改变杯体开口方向，开口方向决定射线路径，不同象限的射线在共享空间中交叉

**来源原语**：镜像(mirror)←0c786b71, 填充(fill)←d4f3cd78, 射线延伸(ray_extend)←d4f3cd78, 象限(quadrant)←0c786b71, 杯形轮廓(cup_outline)←d4f3cd78, 开口(opening)←d4f3cd78, 封闭区域(enclosed_region)←d4f3cd78, 四象限对称(four_quadrant_symmetry)←0c786b71, 开口朝向(opening_direction)←d4f3cd78, 开口决定延伸向(opening_extend_dir)←d4f3cd78, 碰撞阻挡(collision_blocking)←1f642eb9

**依赖链**：镜像构造产生四个朝向不同的杯体→每个杯体的开口方向由其所在象限对应的镜像变换决定→根据开口方向填充杯体内部并发射射线→来自不同象限的射线在公共区域交叉时需解决冲突。镜像变换、方向检测、填充延伸三步紧耦合。

将含有一个杯形轮廓的网格镜像扩展为四象限马赛克，填充每个杯体并从各自开口发射射线，交叉处按绘制顺序覆盖。

**输入结构**：约 7×8 的矩形网格，黑(0)背景。网格中有一个由蓝(1)像素构成的杯形轮廓：一个近似矩形的边框（约 4×5），其中一条边有一段连续缺口（宽 1~2 像素），形成开口。开口可以在四边中的任意一边（上、下、左或右），但同一道题中只有一个朝向。杯形轮廓内部（被蓝色边框围合且通过开口与外部连通的区域）为黑(0)。杯形轮廓外部也为黑(0)。生成约束：杯形轮廓不紧贴网格边缘，至少距边缘 1 像素，以便镜像后各象限的杯体之间有空间。

**规则**：
1. 构造双倍尺寸（2H×2W）的输出网格，将输入网格放入右下象限。
