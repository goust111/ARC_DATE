## 新题 1：遮挡层序决定条纹填充顺序

**组合逻辑**：[层序推断/layer_infer](已有) + [遮挡层次/occlusion_order](已有) → [排序/sort](创新：排序键从空间位置改为遮挡深度) → [填充/fill](创新：条纹颜色序列由遮挡推断结果决定) + [条纹决定填充轴/stripe_determines_fill_axis](创新：轴的选择从条纹朝向改为直线类型的多数投票)

**来源原语**：层序推断、遮挡层次、直线、交叉点、唯一序链（来自 22425bda）；排序、条纹、正方形区域、填充、条纹决定填充轴（来自 8e1813be）

**依赖链**：交叉点处的可见颜色 → 推断出唯一的从底到顶遮挡序列 → 该序列成为条纹颜色的排列顺序；同时，各直线的朝向统计（水平多还是垂直多）决定条纹是按行填还是按列填。两条信息流汇合后才能生成正方形区域内的最终条纹图案。

将多条交叉直线的遮挡堆叠顺序推断出来，再按该顺序将各线颜色作为条纹依次填入灰色正方形区域，条纹方向由直线类型的多数投票决定。

**输入结构**：约 15x15 的黑(0)背景网格。网格中有 N 条（3~6 条）不同颜色的一像素宽直线，每条为全贯穿的水平线、垂直线或 45 度对角线之一。各线颜色互不相同，取自蓝(1)、红(2)、绿(3)、黄(4)、品红(6)、橙(7)。直线两两之间存在交叉点；在交叉点处仅一种颜色可见，其余被遮挡。此外网格中另有一个 NxN 的灰(5)实心正方形区域（N 等于直线数量），与所有直线不重叠。生成约束：直线的遮挡序从底到顶存在唯一 Hamiltonian 链（即相邻层的线必须几何上交叉）；正方形区域不被任何直线穿过。

**规则**：
1. 对每条直线，根据其可见的共线像素恢复完整直线轨迹（被遮挡的像素由共线推断补全）。
2. 在每个交叉单元格处，可见颜色的线位于不可见颜色的线之上。收集所有这些"上/下"约束对。
3. 从约束对中推断唯一的从最底层到最顶层的全排列（即唯一 Hamiltonian 链，相邻元素的线必须几何交叉）。
4. 统计所有直线中水平线与垂直线的数量（对角线不计入任何一方）。若水平线数量 >= 垂直线数量，填充轴为"行"（每行一色）；否则填充轴为"列"（每列一色）。
5. 将灰(5)正方形作为输出画布。按从底层到顶层的遮挡序列，依次用每条线的颜色填充正方形的第 1 行/列、第 2 行/列……（行模式：第 1 行 = 最底层颜色，逐行向下；列模式：第 1 列 = 最底层颜色，逐列向右）。
6. 输出仅为正方形区域的内容（裁剪输出）。

**关键洞察**：条纹的颜色排列不是由空间位置或颜色编号决定，而是由直线交叉处的视觉遮挡关系推断出的唯一层序决定；同时填充方向由直线类型的多数投票决定——两个独立推断汇合才能确定输出。

## 新题 2：方位编码射线的距离递变楔形填充

**组合逻辑**：[方位对应/direction_correspondence](创新：方位邻居从装饰角色变为射线方向编码器) → [射线延伸/ray_cast](创新：射线方向由邻居编码而非固定向下) → [距离递变/distance_gradient + 填充/fill](创新：沿射线方向产生逐行递变宽度的楔形，而非固定宽度填充)

**来源原语**：方位对应、十字图案、方位决定颜色（来自 d364b489）；射线延伸、列遮挡（来自 6d58a25d）；距离递变、三角楔形、填充、逐行宽度递变成楔（来自 a65b410d）

**依赖链**：每个标记像素的方位邻居确定射线方向 → 射线方向确定楔形的展开轴 → 沿射线每远离标记一格，楔形垂直于射线方向扩展一格 → 多个楔形可能重叠，需按标记到重叠格的距离解决冲突。方位编码、射线长度、楔形宽度三者逐级耦合。

从每个标记像素出发，根据其唯一方位邻居确定射线方向，沿该方向投射楔形：距离每增加一格，楔形垂直宽度扩展一格，形成三角扇面；多楔重叠处取距源标记更近者的颜色。

**输入结构**：约 18x18 的黑(0)背景网格。网格中有 2~4 个标记像素，颜色互不相同，取自蓝(1)、红(2)、绿(3)、黄(4)。每个标记像素恰好有一个 4-邻居位置放置了灰(5)像素，指示射线方向（灰在标记上方 → 向上射线，灰在下方 → 向下，灰在左 → 向左，灰在右 → 向右）。各标记之间距离足够大（边界框间距 >= 5），保证楔形在多数区域不重叠。生成约束：不同标记的方位邻居方向不全相同（至少两个方向不同）；标记不在网格边缘上（保证方位邻居有空间放置）。

**规则**：
1. 对每个标记像素，找到其唯一的灰(5) 4-邻居，确定射线方向：灰在标记的上方 → 射线向上，下方 → 向下，左方 → 向左，右方 → 向右。
2. 从标记位置出发沿射线方向逐格前进。设当前距离为 d（d=1, 2, 3, ...），在射线前进方向的第 d 格处，同时在垂直于射线方向的两侧各扩展 (d-1) 格，形成宽度为 (2d-1) 的一排填充。填充颜色为该标记的颜色。
3. 楔形填充在遇到网格边界时裁剪（超出部分丢弃），但不因此停止——继续沿射线方向前进直到射线本身到达网格边界。
4. 灰(5)方位指示像素在输出中擦除（恢复为黑(0)背景）。
5. 若两个楔形覆盖同一格，取该格到其源标记的切比雪夫距离（行差与列差的较大值）较小者的颜色。若距离相同，取行号较小的标记的颜色（行号相同则取列号较小者）。
6. 标记像素自身保留其原色。

**关键洞察**：方位邻居不是装饰性十字臂而是方向编码器，它决定了楔形展开的整个空间轴向；楔形的宽度又由射线距离逐级递增，使得方向选择的微小变化产生完全不同的空间覆盖模式。

## 新题 3：双面板逐格比较驱动的条件操作路由

**组合逻辑**：[逐格比较/cell_comparison](已有) → { 双前景 → [重涂色/recolor], 单前景 → [平移/shift](创新：移向分隔行), 双背景 → [背景替换/background_replace] }（分支结构，非线性流水线）

**来源原语**：逐格比较、双面板对齐、分隔行、二值掩码、任一前景即输出（来自 506d28a5）；压缩、堆叠掩码、双背景标记输出（来自 fafffa47）；平移、背景替换、固定步长平移（来自 32e9702f）；重涂色（来自多题）

**依赖链**：逐格比较是决策节点，其结果将每个像素位置路由到三条不同操作分支之一。三条分支的输出共同拼成最终结果——任何一条分支的规则缺失都会留下未确定的像素。比较结果本身依赖分隔行的位置（确定哪些行互相对齐），所以分隔行的识别是整个推理的前提。

用分隔行将网格分为上下两个等大掩码，逐格比较后按三种结果分别执行不同操作：双前景格涂红(2)，单前景格向分隔行方向平移一格，双背景格涂灰(5)，三条分支的结果合成为最终单面板输出。

**输入结构**：约 11x9（奇数行数）的网格，背景为黑(0)。正中间一行为品红(6)全宽分隔行。上半部分（分隔行之上）包含一个蓝(1)前景掩码（4-连通，约 8~15 像素的不规则形状）。下半部分（分隔行之下）包含一个绿(3)前景掩码（同样 4-连通，约 8~15 像素的不规则形状，与上半掩码部分重叠、部分不重叠）。上下两半尺寸相同。生成约束：两个掩码至少有 2 个位置双前景、至少有 2 个位置仅上半前景、至少有 2 个位置仅下半前景、至少有 2 个位置双背景，保证四种情况均出现。

**规则**：
1. 识别品红(6)全宽分隔行，将网格分为上半掩码和下半掩码（各含 (H-1)/2 行，H 为网格总行数）。
2. 将上半掩码与下半掩码按位置逐格比较（上半第 r 行第 c 列对应下半第 r 行第 c 列）。
3. 对每个位置 (r, c) 执行以下操作之一：
   - **双前景**（上半和下半该位置均为非背景色）：输出该位置为红(2)。
   - **仅上半前景**（上半非背景、下半为背景）：将上半该像素向下平移一格（即输出在 (r+1, c) 处为蓝(1)，原位 (r, c) 变为黑(0)背景）。若 r+1 超出输出网格范围则丢弃。
   - **仅下半前景**（下半非背景、上半为背景）：将下半该像素向上平移一格（即输出在 (r-1, c) 处为绿(3)，原位 (r, c) 变为黑(0)背景）。若 r-1 < 0 则丢弃。
   - **双背景**（上下均为背景色）：输出该位置为灰(5)。
4. 冲突解决：若一个平移操作的目标格恰好也是某个"双前景"格，则双前景的红(2)优先保留；若两个平移操作指向同一格（一个从上方下移、一个从下方上移），则输出黄(4)表示交汇。
5. 输出为单个面板（与半幅尺寸相同），不含分隔行。

**关键洞察**：比较结果不是简单的集合运算（并集/交集），而是路由到三条空间变换各异的操作分支；且平移操作可能产生新的冲突（目标格已被占用），需要二级冲突规则来裁决——这是比较结果与空间变换交互产生的涌现效应。

## 新题 4：条纹编码镜像瓦片阵列

**组合逻辑**：[条纹/stripe](创新：条纹从被填充对象变为二值编码信号) → [镜像/mirror](创新：镜像不是全局固定模式而是由条纹逐位控制) + [平铺/tiling](创新：阵列方向由条纹朝向决定) → [阵列排布/array_layout](已有)

**来源原语**：平铺、镜像、瓦片、阵列排布、中间行翻转（来自 00576224）；条纹、条纹决定填充轴、顺序对应（来自 8e1813be）；掩码映射（来自 bf45cf4b）

**依赖链**：条纹的颜色序列编码了一个二值模式（哪些瓦片需要镜像），条纹的空间朝向（水平/垂直）同时决定了瓦片阵列的排列方向和镜像轴。两条信息从同一个条纹对象中提取但作用不同，缺一不可。

将一个多色瓦片按条纹编码排列成一维阵列：条纹中颜色 A 对应原始瓦片、颜色 B 对应水平或垂直镜像瓦片，条纹朝向同时决定阵列排列方向和镜像翻转轴。

**输入结构**：约 12x12 的黑(0)背景网格。网格中包含两个互不接触的前景元素：(a) 一个 3x3 或 4x4 的多色瓦片（使用 2~4 种非背景色，内部图案非对称以使镜像效果可辨），位于网格一角附近；(b) 一条单像素宽的条纹，由两种交替出现的颜色组成（如红(2)和绿(3)），长度为 N（3~6 格），严格水平或严格垂直放置。条纹中的两种颜色在整条条纹中仅使用这两种，但排列不一定是严格交替的（如红-绿-红-红-绿）。生成约束：条纹的两种颜色与瓦片使用的颜色均不重叠（颜色互斥）；条纹长度 N 与瓦片尺寸 S 满足 N*S 不超过 25（保证输出网格合理）。

**规则**：
1. 识别瓦片：网格中包含多种非背景色的矩形连通区域即为瓦片。识别条纹：单像素宽、仅含两种颜色的水平或垂直线段即为条纹。
2. 设条纹中按出现顺序（水平条纹从左到右，垂直条纹从上到下）排列的像素颜色为 c_1, c_2, ..., c_N。将第一个出现的颜色定义为"原始色"A，另一种定义为"镜像色"B。
3. 确定阵列排列方向和镜像轴：若条纹为水平方向，则瓦片从左到右水平拼接，镜像操作为左右翻转；若条纹为垂直方向，则瓦片从上到下垂直堆叠，镜像操作为上下翻转。
4. 依次处理条纹中每个位置 i（i=1 到 N）：若 c_i = A，放置瓦片原样；若 c_i = B，放置瓦片的镜像版本。各瓦片紧邻拼接，无间隔。
5. 输出为拼接后的瓦片阵列（水平拼接时输出尺寸为 S x (N*S)，垂直堆叠时为 (N*S) x S）。

**关键洞察**：条纹既不是待填充的目标也不是视觉装饰，而是一个二值控制信号——它的颜色序列编码了镜像模式，它的空间朝向编码了排列轴和翻转轴。从同一个对象中同时提取两种不同性质的信息是非显然的。

## 新题 5：重力下落后十字印章级联阻挡

**组合逻辑**：[重力下落/gravity_drop](已有) → [印章覆盖/stamp_overlay + 方位决定颜色/direction_color](创新：十字印章不再是静态装饰而是动态障碍物生成器) → [触底停止/stop_at_bottom](创新：停止条件从网格底部扩展为"任何已有非背景像素") ← 循环依赖：先落地的标记的印章改变后落标记的停止位置

**来源原语**：重力下落、触底停止、面积区分角色（来自 6ca952ad）；印章覆盖、十字图案、方位决定颜色（来自 d364b489）；擦除（来自多题）

**依赖链**：标记按初始行号从低到高依次下落 → 每个标记触底（或碰到非背景像素上方一格）后停止 → 立即在停止位置盖上方位着色十字（上红(2)/下青(8)/左橙(7)/右品红(6)） → 该十字成为后续标记的新障碍。处理顺序、停止位置、印章范围三者形成级联耦合：改变任一标记的初始位置可能导致整个最终图案重构。

多个彩色标记像素按从低到高的顺序逐个下落，每个落地后立即印上方位着色十字，该十字作为障碍物阻挡后续下落的标记，形成级联堆叠结构。

**输入结构**：约 14x10 的黑(0)背景网格。网格中散布 3~5 个单像素标记，每个标记颜色互不相同，取自蓝(1)、绿(3)、黄(4)、灰(5)、栗(9)。标记分布在不同行和不同列（无两个标记同行或同列）。生成约束：任意两个标记的列距 >= 2（保证十字臂不会在初始时就重叠）；所有标记至少在第 2 行以上（非最底行），保证有下落空间。

**规则**：
1. 将所有标记按其初始行号从大到小排序（最接近底部的先处理）。行号相同时（本题约束下不会发生），列号小的先处理。
2. 对当前待处理的标记，将其从原始位置擦除（恢复为背景黑(0)），然后令其在同一列垂直向下移动，直到满足以下停止条件之一：
   - 到达网格最底行（行号 = H-1）；
   - 其正下方一格为非背景像素（已被先前的印章或标记占据），则停在该非背景像素的上方一格。
3. 在标记停止位置放置该标记的原始颜色。然后在其 4-邻居位置印上方位着色十字：
   - 上方一格 → 红(2)
   - 下方一格 → 青(8)
   - 左方一格 → 橙(7)
   - 右方一格 → 品红(6)
   - 如果邻居位置超出网格边界则跳过（裁剪）。
   - 如果邻居位置已被先前印章或标记占据（非背景色），则不覆盖（先到先得）。
4. 处理完所有标记后，输出最终网格。

**关键洞察**：十字印章不是终态装饰而是过程中的障碍物生成器——先落地标记的青(8)下臂会成为后续同列标记的停止面，使后者悬停在空中而非落到底部。处理顺序（由初始行号决定）从根本上改变最终图案，而这个顺序本身需要从输入推断。

## 新题 6：共线滑动中面积区分的阻挡与搭载

**组合逻辑**：[滑动/slide + 共线对齐/collinear_aligned](已有) + [面积区分角色/area_determines_role](创新：面积不再分"动/静"而是分"阻挡者/搭载者") → [擦除/erase](创新：搭载者被拾起后擦除原位) + [背景替换/background_replace](创新：滑过的路径替换为灰色轨迹)

**来源原语**：滑动、共线对齐、趋近目标、标记像素、目标像素（来自 dc433765）；面积区分角色、大前景对象、小标记对象（来自 6ca952ad）；擦除（来自多题）；背景替换（来自 32e9702f）

**依赖链**：绿标记沿共线方向向黄标记滑动 → 路径上遇到的前景对象按面积分类：大对象是阻挡者（标记停止），小对象是搭载者（被拾起随标记继续前进） → 搭载者的原位被擦除 → 标记停止后搭载者排列在标记身后 → 滑过的路径格替换为灰(5)。面积阈值判断、路径遇障、搭载排列三个环节交织——移除面积判断则无法区分障碍和搭载，移除路径逻辑则搭载顺序未定。

绿标记沿共线方向向黄标记滑动，路径上的小对象（面积 <= 3）被拾起搭载，大对象（面积 > 3）阻挡标记使其停止；搭载者按拾取顺序排列在标记身后，滑过路径变为灰色轨迹。

**输入结构**：约 16x16 的黑(0)背景网格。网格中恰有一个绿(3)标记像素和一个黄(4)标记像素，二者位于同一行、同一列或 45 度对角线上。沿二者连线方向的路径上分布有若干前景对象（4-连通），使用蓝(1)、红(2)、橙(7)等颜色：其中 1~2 个为"小对象"（面积 1~3 像素），0~1 个为"大对象"（面积 >= 4 像素，为填充矩形或不规则形状）。小对象的所有像素均位于连线路径上或路径相邻一格内。大对象至少有一个像素位于连线路径上。路径上不存在除上述对象和两个标记之外的其他前景像素。生成约束：若有大对象，它位于绿标记和黄标记之间，确保绿标记被阻挡而不能到达黄标记；若无大对象，绿标记最终停在黄标记相邻一格处。

**规则**：
1. 确定绿(3)标记和黄(4)标记的位置，计算归一化方向向量（行差和列差各自归一化为 -1/0/+1）。
2. 绿标记沿该方向逐格前进（每次移动一格）。对每个到达的格子：
   - 若该格为背景(0)：标记移入，原位变为灰(5)轨迹。
   - 若该格属于一个面积 <= 3 的前景对象：将该对象的所有像素擦除为黑(0)背景，该对象被"拾取"加入搭载队列（按拾取先后排序）。标记继续前进，当前格变为灰(5)轨迹。
   - 若该格属于一个面积 >= 4 的前景对象或为黄(4)标记：标记停止，停在该格的前一格（不进入阻挡物）。当前格不变。
   - 若该格超出网格边界：标记停在边界内最后一格。
3. 在标记停止位置放置绿(3)标记。然后沿标记来时方向的反方向，从标记位置向后依次排列搭载者：第一个拾取的对象放在标记后方第 1 格，第二个放在第 2 格……每个搭载者仅保留其原始颜色的一个像素（代表其被压缩为单点）。若后方空间不足（超出网格），多余搭载者丢弃。
4. 黄(4)标记始终保持不动。

**关键洞察**：面积阈值不是简单分类而是决定了两种截然不同的交互行为（阻挡 vs. 搭载），且搭载者的最终排列位置取决于绿标记在哪里被阻挡停下——阻挡者的位置间接决定了搭载者的输出位置，三种角色（滑动者、阻挡者、搭载者）形成不可分割的交互链。

## 新题 7：格子缺失交叉点裁剪后同心层色序反转

**组合逻辑**：[裁剪/crop](已有) + [四角围合/four_corner_bound + 缺失交叉点/missing_intersection](已有) → [同心方框层/concentric_layer](创新：层的深度基准从网格边缘改为裁剪边界) → [层色序内外翻转/reverse_layer_colors](创新：反转的对象从预设同心环改为由裁剪动态确定的深度层)

**来源原语**：裁剪、四角围合、缺失交叉点、背景色空洞、网格线（来自 a644e277）；同心方框层、深度排序、层色序内外翻转、重涂色（来自 85c4e7cd）

**依赖链**：缺失的格子交叉点确定裁剪矩形的四个角 → 裁剪后的子网格边界成为深度 0 → 每个像素的深度（到最近裁剪边界的切比雪夫距离）决定其所属的同心层 → 收集各深度层的颜色序列后反转重涂。裁剪边界直接改变深度分配——如果四个缺失交叉点位置不同，同一像素可能属于不同深度层，导致完全不同的颜色反转结果。

在格子结构中找到四个背景色缺失交叉点确定的矩形裁剪区域，将裁剪结果视为同心矩形环，按从外到内收集颜色序列后反转各层颜色。

**输入结构**：约 17x17 的网格。一种颜色（如橙(7)）形成规则的一像素宽水平线和垂直线，构成格子结构（行间距和列间距相等，约 3~4 格）。格子线的交叉点通常为橙(7)色，但恰好有 4 个交叉点为背景黑(0)色（缺失交叉点）。这 4 个缺失点恰好构成一个矩形的四角（不一定是最小矩形，但四点共构成一个轴对齐矩形）。格子单元格（格子线围成的矩形区域）内部填充有不同颜色，整体形成同心矩形色带模式——从裁剪区域的最外层到最内层，每层一种颜色，颜色序列无重复。使用的填充色取自蓝(1)、红(2)、绿(3)、黄(4)、灰(5)、品红(6)中的 3~5 种。生成约束：四个缺失交叉点定义的裁剪矩形内至少包含 3 层深度（保证反转效果可见）；格子线颜色不参与同心层颜色序列。

**规则**：
1. 识别格子线颜色（形成规则水平和垂直线的唯一非背景色，此处为橙(7)）。
2. 找到恰好 4 个格子交叉点位置为背景黑(0)色的缺失交叉点。
3. 取这 4 个点的最小行、最大行、最小列、最大列，定义裁剪矩形。进行包含边界的裁剪。
4. 在裁剪后的子网格中，计算每个非格子线像素的"深度"：该像素到裁剪矩形边界的切比雪夫距离（即 min(到上边距离, 到下边距离, 到左边距离, 到右边距离)）。格子线像素保持原色不变。
5. 收集深度序列：深度 0 的非格子线像素颜色为 color_0，深度 1 的为 color_1，……直到最大深度。（同一深度的所有非格子线像素颜色相同。）
6. 将颜色序列反转：深度 0 重涂为 color_max，深度 1 重涂为 color_(max-1)，……深度 max 重涂为 color_0。格子线像素和缺失交叉点像素保持不变。
7. 输出裁剪后的子网格（含反转后的颜色和保持不变的格子线）。

**关键洞察**：裁剪边界不是由内容决定而是由格子结构的缺陷（缺失交叉点）决定，而裁剪边界又定义了同心层的深度基准——移动缺失交叉点会改变裁剪范围，进而改变所有像素的深度分配，导致完全不同的颜色反转映射。裁剪与反转通过深度计算紧密耦合。
