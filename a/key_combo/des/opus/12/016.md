## 新题 1：可见性门控的对称补全

**组合逻辑**：[symmetry_completion](已有) + [path_trace](创新：从镜像中心向反射目标做视线检测) → [recolor](已有，受碰撞色条件控制)

**来源原语**：symmetry_completion / marker_biaxial_mirror（参考 4938f0c2），path_trace / collision_stop（参考 9bbf930d），recolor（参考 b74ca5d1）

**依赖链**：对称规则产生候选反射位置 → 路径追踪判定每个候选位置是否可达（不被障碍遮挡） → 可达的候选位置被填色，不可达的被丢弃。路径追踪结果反向决定对称补全的范围，两者互为约束而非顺序流水线。

从部分前景图形出发做四折镜像补全，但只有从镜像中心出发的直线视线未被障碍遮挡的反射位置才真正着色。

**输入结构**：约 15x15 的网格，背景为黑(0)。网格中心偏位处有一个 2x2 绿(3) 标记方块，作为镜像中心。红(2) 前景像素分布在标记方块的一个象限（如左上），构成一个 4-连通的不规则小图形（4~8 像素）。橙(7) 像素组成若干水平或垂直的单像素宽色条（长度 3~6），散布在其余三个象限中，充当视线障碍。生成约束：色条不接触标记方块，不进入红色图形所在象限；每个象限至少有一条通向标记方块的无障碍直线路径，但也至少有一条被色条阻断的路径。

**规则**：
1. 以 2x2 绿(3) 标记方块的几何中心为双轴镜像中心，计算每个红(2) 像素的三个镜像位置（水平镜像、垂直镜像、180 度镜像）。
2. 对每个候选镜像位置，从标记方块中心出发沿直线（水平、垂直或 45 度对角线中最接近的方向）向该候选位置做射线检测。若射线在到达目标前遇到橙(7) 像素，则该候选位置"不可达"，不放置任何像素。
3. 可达的候选位置填充红(2)。不可达的候选位置保持黑(0) 不变。
4. 原始红色图形和绿色标记方块保持不变。橙色障碍保持不变。
5. 当两条射线共享部分路径时，分别独立判定各自终点的可达性。

**关键洞察**：障碍色条不直接参与对称规则，而是通过阻断视线来"遮蔽"部分镜像位置——对称补全的结果不再是完整的四折对称图形，而是被环境几何过滤后的残缺对称。需要对比多个示例才能区分"规则本身只生成部分镜像"还是"障碍导致缺失"。

## 新题 2：稀疏边界补全引导的分层射线投影

**组合逻辑**：[complete](已有) → [ray_extend](已有) + [recolor](创新：投影穿越已补全的嵌套边界时动态变色)

**来源原语**：complete / sparse_rect_layer / outer_to_inner（参考 5751f35e），ray_extend / displacement_vec / copy_dir_and_color（参考 045e512c），recolor（参考 22a4bbc2）

**依赖链**：补全稀疏边界 → 确定嵌套层区域 → 射线投影穿越各层时根据所在层的边界颜色进行重涂色。补全结果决定色区边界，色区边界决定投影的颜色分段，形成信息变换链。

将中心精灵体沿位移向量反复投影，但投影副本在穿越已补全的嵌套矩形边界时变为该边界的颜色，产生分层着色的投影序列。

**输入结构**：约 20x20 的网格，背景为黑(0)。2~3 种颜色（如蓝(1)、灰(5)、栗(9)）的稀疏像素各自暗示一个轴对齐矩形边界，这些矩形严格嵌套（蓝最外、灰次之、栗最内），面积互不相同。最内层矩形中心有一个 3x3 的单色小精灵体（红(2)，不规则形状，4~6 像素）。最外层矩形之外有 1~3 个该精灵体的部分副本（与精灵体形状相同的子集，各 2~3 像素），每个副本颜色为绿(3)。生成约束：稀疏边界每条边至少有 2 个采样像素；各部分副本与中心精灵体的位移向量方向互不相同（如一个偏右上、一个偏左下）。

**规则**：
1. 将每种边界颜色的稀疏像素补全为完整的轴对齐矩形框（单像素宽边框），按子框与父框一像素内缩匹配至少三边时扩展至完整内缩的规则处理（同参考 5751f35e 的补全逻辑）。
2. 找到中心精灵体与每个部分副本之间的位移向量（使精灵体覆盖该副本的最大位移）。
3. 沿每个位移向量方向，从中心精灵体位置开始反复平移，每步平移量等于位移向量本身。对每个平移产生的副本：
   - 判断该副本的几何中心落在哪一层嵌套区域内（最内层、中间层、最外层、或已出界）。
   - 将副本的所有像素重涂为该层矩形边界的颜色。若中心落在最内层，重涂为栗(9)；中间层为灰(5)；最外层为蓝(1)。
   - 若副本的几何中心落在矩形边界之外（出界），则不绘制该副本，投影在此方向停止。
4. 原始精灵体保持红(2)。部分副本在输出中被擦除（涂为黑(0)）。已补全的矩形边界保持其颜色不变。
5. 多个投影方向的副本若占据同一像素，后绘制的（按位移向量的角度从 0 度顺时针排序）覆盖先绘制的。

**关键洞察**：稀疏边界的补全不仅用于"看到完整矩形"，更关键的是划定了颜色区域——同一投影序列中的相邻副本可能因跨越边界而颜色不同。需要对比多个示例才能归纳"副本颜色取决于所在层而非投影方向"这一隐蔽规则。

## 新题 3：邻接清洗后的面板叠加与间隔重涂

**组合逻辑**：[erase + recolor](创新：邻接判定同时执行清洗和归并) → [transparent_overlay](已有) → [sort + recolor](创新：叠加后的合并排序决定间隔重涂目标)

**来源原语**：erase / merge_or_delete / adjacency（参考 7e0986d6），transparent_overlay / union_foreground / separator_row / panel（参考 ce4f8723 + d19f7514），sort / every_nth_selection / sort_by_position / recolor（参考 22a4bbc2）

**依赖链**：邻接清洗改变每个面板中色条的形态 → 叠加时清洗后的形态决定并集的形状 → 合并后的色条按位置排序，间隔选取决定最终重涂目标。清洗结果实质性改变叠加输入，叠加结果实质性改变排序输入。

两个面板各自经过噪声清洗后对齐叠加为一个合并视图，合并后的色条按位置排序、每隔两个重涂为指定颜色。

**输入结构**：约 12x25 的网格，背景为黑(0)。一条品红(6) 全宽分隔行将网格分为等高的上下两个面板（各约 12x12）。每个面板包含 3~5 个水平色条（各为单色的轴对齐实心矩形，高 1~2 行、宽 4~8 列），颜色取自蓝(1)、灰(5)、橙(7)、青(8)（同一面板内颜色不重复）。每个面板还散布着黄(4) 噪声像素（每个噪声为 1~2 像素的小连通分量，共 4~8 个噪声分量）。生成约束：部分噪声像素与色条 4-邻接接触 >= 2 个色条像素，部分噪声与色条接触 < 2 个；两面板的色条在垂直对齐后存在部分重叠和部分互补区域。

**规则**：
1. 在每个面板中独立执行噪声清洗：找出所有 4-连通分量，面积 < 4 的为噪声分量，面积 >= 4 的为色条分量。对每个噪声分量，统计其像素与色条分量的 4-邻接接触数。接触数 >= 2 的，将噪声像素重涂为接触最多的那个色条的颜色（并入色条）；接触数 < 2 的，将噪声像素擦除为黑(0)。若与两个色条接触数相同，选上方（行号较小）的色条。
2. 移除分隔行，将清洗后的上下面板逐格对齐。在每个单元格：若两面板均为前景，保留上面板的颜色；若仅一个面板为前景，保留该颜色；若均为背景，保持黑(0)。
3. 在合并结果中识别所有 4-连通前景分量（即合并后的色条），按其边界框左上角的位置排序（先按行从上到下，行相同则按列从左到右）。
4. 排序后，将排名第 1、第 4、第 7、... 的色条（即每隔 3 个，从第 1 个开始）重涂为红(2)。其余色条保持合并叠加后的颜色不变。

**关键洞察**：噪声清洗的归并操作会扩大色条的边界，直接影响叠加后的前景并集形状；而叠加创造了一个新的色条集合（来自两个面板的色条可能合并为一个更大的连通分量），排序和间隔选取作用于这个新集合而非任何单一面板。需要对比多个示例才能发现"每隔 3 个重涂"的间隔规则。

## 新题 4：膨胀邻接图的度数编码

**组合逻辑**：[dilate_intersect](已有) → [counting](创新：计算每个分量的膨胀重叠邻居数) → [encoding + sort](创新：度数排序后编码为水平色条长度)

**来源原语**：dilate_intersect / path_gap_overlap（参考 f1bcbc2c），counting / count_mapping（参考 ff28f65a），encoding / count_sets_positions（参考 ff28f65a），sort / sort_by_position（参考 22a4bbc2）

**依赖链**：膨胀创造原本不存在的重叠区域 → 重叠定义了分量间的邻接关系图 → 度数统计压缩几何信息为标量 → 排序和编码将标量映射为输出图案。每一步的输出在本质上改变下一步的输入形态（从几何 → 拓扑图 → 数值 → 像素编码）。

多个孤立前景分量经膨胀后产生重叠关系，构成隐式邻接图；每个分量的邻接度数被编码为对应颜色的水平色条长度，按度数降序排列。

**输入结构**：约 15x15 的网格，背景为黑(0)。包含 4~6 个孤立的 4-连通单色前景分量，每个分量 3~8 像素，形状不规则，颜色各不相同（取自蓝(1)、红(2)、绿(3)、黄(4)、灰(5)、橙(7)）。任意两个分量之间的最近距离为 1~3 像素（即它们不接触但相距很近）。生成约束：至少有两对分量的间距恰为 1 像素（膨胀后必定重叠），至少有一对分量的间距 > 2 像素（膨胀后不重叠）；各分量的邻接度数不全相同。

**规则**：
1. 对每个前景分量做 1 像素的 8-邻域膨胀（将分量的每个像素的 8 个邻居标记为该分量的膨胀区域，不覆盖其他分量的原始像素）。
2. 检查每对分量的膨胀区域是否存在重叠像素（即两个分量的膨胀区各自标记了同一个空白像素）。若存在重叠，则这两个分量之间有一条"邻接边"。
3. 对每个分量，统计其邻接边的数量，即为该分量的"度数"。
4. 按度数降序排列所有分量；度数相同时，按分量边界框左上角的位置排序（先行后列，行号小的优先）。
5. 输出为一个 Nx(最大度数) 的网格（N 为分量数量），第 k 行对应排序后第 k 个分量：从左起填充该分量颜色，填充长度等于该分量的度数；若度数为 0，该行全部为黑(0)。

**关键洞察**：输入中分量之间并不直接接触，邻接关系完全由膨胀操作创造——间距恰为 1 的分量膨胀后重叠，间距 > 2 的则不重叠。输出完全丢弃了形状和位置信息，只保留了由空间距离编码的拓扑连接度。需要对比多个示例才能归纳膨胀半径恰为 1 以及度数 → 色条长度的映射规则。

## 新题 5：路径追踪定向的空区瓦片填充

**组合逻辑**：[search](已有) + [path_trace](已有) → [tiling + rotate](创新：粒子最终行进方向决定瓦片旋转角度，空区定位决定填充区域)

**来源原语**：search / empty_rect_region / largest_rect_filled / min_side_constraint（参考 3eda0437），path_trace / particle / corridor / collision_turn / collision_stop（参考 9bbf930d），tiling / tile / alternating_flip / concatenation（参考 bc4146bd），rotate / half_turn_rotation（参考 3c9b0459）

**依赖链**：路径追踪的终态方向 → 决定瓦片的基础旋转角。空区搜索 → 决定填充位置和尺寸。两条独立信息在瓦片填充步骤汇合：一条提供"怎么放"（方向），一条提供"放在哪"（区域）。路径还被着色，与填充结果共存于输出中。

一个粒子在色条走廊中追踪路径直到停止，其最终行进方向决定瓦片的旋转朝向；同时搜索网格中最大空矩形区域，将旋转后的瓦片平铺填入该区域。

**输入结构**：约 18x18 的网格，背景为黑(0)。橙(7) 色条以偶数行的水平段和偶数列的垂直段形式分布，形成走廊结构（走廊为色条之间的单像素宽通道）。一个品红(6) 粒子（单像素）位于网格左边缘的某个走廊入口。一个 3x3 的瓦片图案由绿(3) 像素构成（不规则、非对称形状，4~6 像素，其余为黑），位于网格右下角的 3x3 区域内。网格中存在若干全黑的矩形空区（由走廊结构围出），其中恰好一个空区的面积最大且两个维度均 >= 3。生成约束：粒子的路径追踪有且仅有一条确定性路线（每次碰撞只有一个合法转向方向）；最大空区的长宽均为 3 的倍数（确保瓦片能整除填充）。

**规则**：
1. 从品红(6) 粒子出发执行路径追踪：粒子沿当前方向直线前进，遇到橙(7) 色条时转向 90 度进入有黑(0) 空间的垂直走廊（若两侧都有走廊，选择两侧有同色色条夹道的那个方向）。粒子到达网格边缘或完全被堵时停止。记录粒子停止时的最终行进方向。
2. 将粒子经过的所有黑(0) 像素涂为品红(6)，形成路径轨迹。
3. 搜索网格中所有全黑矩形区域（宽高均 >= 3），选出面积最大的那个。
4. 根据粒子最终行进方向确定瓦片的基础旋转角度：向右 → 0 度；向下 → 顺时针 90 度；向左 → 180 度；向上 → 顺时针 270 度。
5. 将旋转后的瓦片平铺填入最大空区：从空区左上角开始，按行优先逐个放置瓦片。奇数位置（从 0 计数，位置 1、3、5...）的瓦片额外旋转 180 度（即与基础旋转叠加 180 度）。
6. 右下角原始瓦片位置的像素在输出中擦除为黑(0)。

**关键洞察**：粒子的路径追踪和空区搜索是两个独立的感知过程，但它们的结果在瓦片填充步骤交汇——追踪提供方向信息，搜索提供空间信息，缺少任何一个都无法确定最终输出。需要对比多个示例才能发现旋转角度与行进方向的映射关系（方向→角度的具体对应在单个示例中有多种可能解释）。

## 新题 6：放大使能的标记旋转对接

**组合逻辑**：[pixel_upscale](创新：放大不是目的而是为对接创造空间条件) → [ray_cast + dock](已有) + [rotate](创新：旋转角度由组件内部标记像素的局部位置编码)

**来源原语**：pixel_upscale / uniform_scale_factor（参考 c59eb873），dock / ray_cast / interior_socket / movable_component / structure / ray_inferred_direction / trail_painted_black（参考 8b9c3697），rotate / half_turn_rotation（参考 3c9b0459），marker_pixel（参考 7ec998c9）

**依赖链**：放大创造了容纳组件的物理空间（1x1 腔变为 2x2） → 射线投射在放大后的网格上找到组件 → 标记像素位置决定旋转 → 旋转后的组件对接入腔体。放大是后续所有操作的前提条件（非放大态下腔体装不下组件），不可跳过。

将整个网格 2 倍放大后，结构体的单像素腔体变为 2x2 空间，此时可移动组件通过射线定位并根据其内部标记像素的方位旋转后对接入腔体。

**输入结构**：约 9x9 的网格（输出为 18x18），背景为黑(0)。包含 2~3 个"结构体"，每个是一个由灰(5) 像素围成的 3x3 方框，中心为 1 个黑(0) 像素（即单像素腔体）。在结构体之外散布 2~3 个"可移动组件"，每个组件是一个 L 形或 T 形的 4-连通小图形（恰好 4 像素），由蓝(1) 像素构成，其中恰好 1 个像素为红(2)（标记像素）。组件数量 <= 结构体数量。生成约束：每个组件从其位置沿某个基本方向（上、下、左、右之一）做射线可以到达某个结构体的腔体（穿过的路径上只有黑(0) 像素）；不同组件指向不同的结构体。

**规则**：
1. 将整个输入网格做 2 倍像素放大：每个像素变为 2x2 同色块。此时每个结构体的中心腔体从 1x1 变为 2x2，组件从 4 像素变为 4 个 2x2 块（共 16 像素，占据一个 4x4 子区域的部分）。
2. 在放大后的网格上，从每个结构体的 2x2 腔体中心向四个基本方向（上、下、左、右）发射射线。首先命中的可移动组件（蓝(1)/红(2) 像素）为该结构体的配对组件，射线方向为对接方向。
3. 确定组件的旋转角度：在放大前的原始组件中，标记像素（红(2)）相对于组件边界框中心的方位决定旋转——标记在边界框上方 → 0 度；右方 → 顺时针 90 度；下方 → 180 度；左方 → 顺时针 270 度。（上方定义为行号较小的一侧；若标记恰在中心行或中心列，取其偏离的另一个轴的方位。）
4. 对放大后的组件施加该旋转（围绕组件边界框中心旋转），然后沿对接方向平移，直到组件的中心 2x2 块与腔体的 2x2 空间完全重合。将组件绘制到腔体位置。
5. 组件从原始位置移走后，将其原位置的所有像素涂为黑(0)。组件滑动经过的路径（从原位到对接位之间的像素）涂为栗(9)。
6. 未被任何射线命中的多余组件（如果有）保持不动。

**关键洞察**：放大操作看似只是视觉缩放，但实际上是对接操作的物理前提——原始网格中 1x1 的腔体无法容纳多像素组件，放大后 2x2 的腔体才能装入旋转后的组件。标记像素在组件中的位置同时编码了旋转信息，与射线方向无关（这是一个需要对比多个示例才能分离的隐蔽规则）。

## 新题 7：递增堆叠中的标记阻断与连通选择

**组合逻辑**：[stack](已有) + [counting](创新：标记位置在堆叠过程中造成断裂) → [erase + keep_largest_component](已有) → [draw_line](已有，连接最大连通分量的极端点)

**来源原语**：stack / color_run / row_by_row_increment / row_incremental_expand（参考 bbc9ae5d），counting（参考 ff28f65a），erase / connected_component / area_comparison / keep_largest_component（参考 1f85a75f），draw_line / marker_pixel（参考 7ec998c9）

**依赖链**：标记像素位置在堆叠的逐行扩展中制造空隙 → 空隙将前景分裂为多个连通分量 → 保留最大连通分量并擦除其余 → 在最大分量的极端点之间画线。标记位置决定了哪些行有缺口、缺口位置决定了连通性、连通性决定了保留哪些像素。

从单行色段逐行递增堆叠，但输入行中的标记像素位置在每行的对应列强制留空，造成前景断裂；保留面积最大的连通分量，在其最高和最低像素之间画一条垂直线。

**输入结构**：一行宽为 W（W 为偶数，10~16）的网格。前 L 个像素（L 在 3~6 之间）为蓝(1)（色段），其余为黑(0)。在该行的非色段区域中，有 2~3 个红(2) 标记像素散布在不同列位置。生成约束：至少一个标记像素的列号 < W/2（会在堆叠中期被色段扩展触及），至少一个标记像素的列号 >= W/2（色段扩展在到达该位置前已因行数限制停止，不受影响）；标记像素不相邻。

**规则**：
1. 以输入行为模板，生成 W/2 行的堆叠网格（行号从 0 开始）。第 k 行的蓝(1) 色段长度为 min(L + k, W)，从左端开始向右填充。
2. 在每一行中，如果某列的位置在输入行中是红(2) 标记像素，则该列在此行强制为黑(0)（即使色段扩展已覆盖到此列）。标记像素本身不出现在输出网格中。
3. 堆叠完成后，将整个前景（所有蓝(1) 像素）按 4-连通分量分组，找到面积最大的连通分量。若最大面积不唯一，选择边界框左上角行号最小的那个。
4. 将非最大连通分量的所有蓝(1) 像素擦除为黑(0)。
5. 在保留的最大连通分量中，找到最上方像素（行号最小；若有多个取列号最小者）和最下方像素（行号最大；若有多个取列号最大者）。从最上方像素到最下方像素画一条红(2) 垂直直线（若两者不在同一列，则画一条 Manhattan 折线：先垂直走到目标行，再水平走到目标列）。
6. 折线经过的蓝(1) 像素保持蓝(1)（线画在蓝色之上时保持蓝色不变），折线经过的黑(0) 像素变为红(2)。

**关键洞察**：标记像素表面上只是输入行中的静态点，但它们在堆叠过程中扮演"柱状屏障"角色——当色段扩展到标记列时，该列始终留空，像一根垂直的墙壁切断前景。这种切断效果是否发生取决于色段是否增长到了标记所在列，即取决于标记列号与色段初始长度及总行数的关系。需要多个示例才能归纳标记的阻断机制。

## 新题 8：折线路径的中轴提取与嵌套深度重涂

**组合逻辑**：[draw_line](已有) + [clip/center_axis_only](创新：从折线路径中提取通过中轴列的片段) + [complete + recolor](创新：中轴片段的颜色由其穿越的嵌套层深度决定)

**来源原语**：draw_line / folded_path / column_alignment / center_offset_selects_corner（参考 7ec998c9），clip / center_column / center_axis_only / foreground_pixel（参考 d23f8c26），complete / nested_rectangle / outer_to_inner（参考 5751f35e），recolor（参考 b74ca5d1）

**依赖链**：标记像素决定折线路径的走向 → 中轴列裁剪只保留路径与中轴的交集 → 嵌套矩形补全划定深度层 → 中轴上的每个像素根据其所在层深度重涂颜色。折线走向决定中轴上哪些像素被点亮，嵌套深度决定这些像素的颜色，两套结构在中轴列上交汇。

多条折线路径穿越网格，仅保留它们通过中轴列的部分；这些中轴像素再根据所在的嵌套矩形深度层重涂为对应层的颜色。

**输入结构**：约 15x15 的网格（列数为奇数），背景为黑(0)。2~3 种颜色（如灰(5)、橙(7)）的稀疏像素暗示 2~3 个轴对齐嵌套矩形边界（不经过中轴列）。在嵌套矩形之外或之间，有 2~4 个绿(3) 标记像素分布在不同行，且不在中轴列上。整个网格中不存在蓝(1) 像素（蓝将用于输出）。生成约束：各标记像素所在列与中轴列的左右关系不全相同（有的在左，有的在右）；稀疏矩形的每条边至少有 2 个采样像素；中轴列与每个嵌套矩形层在至少 3 行的区间重叠。

**规则**：
1. 补全稀疏像素为完整的嵌套矩形边框（同参考 5751f35e 的补全逻辑）。确定嵌套层级：最外层为深度 1，次层为深度 2，最内层为深度 3（以此类推）。
2. 为每个标记像素生成一条折线路径：从标记像素所在列出发，垂直涂满该列（从网格顶到底）；然后根据标记像素相对中轴列的位置连接角落——若标记在中轴列的左侧，从该列顶端水平连线到右上角、从底端连线到左下角；若在右侧则反之（顶端连左上角、底端连右下角）。路径颜色暂定为蓝(1)。
3. 在所有折线路径绘制完毕后，执行中轴裁剪：仅保留中轴列（第 (W-1)/2 列，W 为网格宽度）上的蓝(1) 像素。所有非中轴列的蓝(1) 像素擦除为黑(0)。
4. 对中轴列上保留的每个蓝(1) 像素，判断其所在的嵌套层深度：
   - 若该像素在所有矩形之外，深度为 0，颜色保持蓝(1)。
   - 若在深度 d 层内（d >= 1），将该像素重涂为该层矩形边框的颜色。
5. 标记像素保持绿(3) 不变。已补全的矩形边框保持其颜色不变。中轴列上未被任何折线路径覆盖的像素保持黑(0)。
6. 多条折线路径在中轴列同一像素重叠时，该像素仍为单个前景像素，按嵌套深度规则着色（颜色取决于位置而非路径来源）。

**关键洞察**：折线路径的走向由标记位置决定，但最终只有路径与中轴列的交集部分被保留——不同标记产生不同的交集段落。这些交集段落的颜色又由嵌套结构决定，而嵌套结构需要从稀疏像素补全后才能确定。两套独立的几何结构（折线路径和嵌套矩形）在中轴列这一"探针"上交汇产生最终输出。需要对比多个示例才能分离"路径决定位置"与"嵌套决定颜色"两条独立规则。
