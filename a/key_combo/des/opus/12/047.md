## 新题 1：旋转条生成禁区后寻找唯一安全路径

**组合逻辑**：[旋转](创新：旋转结果不直接输出，而是生成寻路禁区) + [寻路] + [重涂色]（旋转、寻路均为已有原语，"旋转输出定义禁区"是创新结构关系）

**来源原语**：旋转/中心点不变/朝向交换长度保持(f0f8a26d), 寻路/邻域禁区/唯一安全路径(cc9053aa), 重涂色(67385a82)

**依赖链**：旋转操作的输出改变了空间禁区分布 -> 禁区决定了哪些轨道像素可通行 -> 寻路在可通行子图上找唯一路径 -> 路径像素被重涂色。删除旋转步骤则禁区位置错误（用原始条位置会得到不同路径或无唯一路径）；删除寻路步骤则无法确定哪些像素需要重涂色。

根据输入中条的位置先做心算旋转确定真实障碍，再在轨道上寻找避开这些障碍的唯一路径，将路径涂为端点颜色。

**输入结构**：约 18x18 的黑(0)背景网格。青(8)像素构成一条 4-连通的弯曲轨道路径，轨道两端各有一个栗(9)端点像素。轨道上嵌有 2~3 个橙(7)障碍像素（与参考题 cc9053aa 类似）。此外，网格中散布 3~4 根灰(5)的单像素宽条（奇数长度，水平或竖直，长度 3~7 像素），它们不与轨道重叠，但位于轨道附近。生成约束：每根灰条旋转 90 度后，其旋转像素的 8-邻域至少覆盖到一段轨道像素；所有灰条旋转后产生的禁区加上橙障碍的禁区恰好使两端点之间仅存一条简单 4-连通路径。

**规则**：
1. 将每根灰(5)条绕其中心点旋转 90 度（水平变竖直、竖直变水平，长度和中心不变）。旋转后的灰像素覆盖到的位置成为新的障碍位置（原始灰条像素清除为背景）。
2. 将每个橙(7)障碍像素及其 8-邻域内的所有轨道像素标记为禁行（与参考题 cc9053aa 相同）。
3. 将每个旋转后灰障碍像素及其 8-邻域内的所有轨道像素也标记为禁行（规则与橙障碍相同）。
4. 在剩余可通行的青(8)/栗(9)像素构成的 4-连通子图中，找到两个栗(9)端点之间的唯一简单路径。
5. 将该路径上的所有青(8)像素重涂为栗(9)；端点、橙障碍及所有其他像素保持不变。灰条在输出中不出现（已被清除）。

**关键洞察**：灰条的当前朝向是误导——必须先心算旋转才能知道真正的禁区位置；原始位置的条可能完全不阻挡轨道，旋转后才产生关键阻断，使路径唯一。

## 新题 2：标记像素计数决定菱形轮廓收缩或膨胀

**组合逻辑**：[计数](创新：计数结果的奇偶性决定几何变换方向) + [收缩/膨胀] + [擦除]（计数、收缩/膨胀均为已有原语，"计数奇偶驱动收缩/膨胀选择"是创新结构关系）

**来源原语**：计数/按数量排序(b1986d4b), 收缩/膨胀/菱形轮廓/半径微调(d753a70b), 擦除(bae5c565), 标记像素(e760a62e)

**依赖链**：计数每个菱形内部的标记像素数 -> 奇偶性决定是收缩还是膨胀 -> 执行半径调整 -> 擦除标记像素。删除计数则不知道该收缩还是膨胀；删除收缩/膨胀则计数结果无用。

统计每个菱形轮廓内部的标记像素数量，奇数则收缩一层、偶数则膨胀一层，最后清除所有标记。

**输入结构**：16x16 的橙(7)背景网格。包含 3~4 个不同颜色的一像素厚曼哈顿菱形轮廓（颜色从红(2)、蓝(1)、绿(3)、灰(5)中选取，每个菱形一种颜色）。菱形半径为 2~5，中心距足够大使得膨胀一层后菱形之间不重叠。每个菱形的严格内部区域（不含轮廓本身）散布有 1~4 个黄(4)标记像素。生成约束：收缩后的菱形半径不小于 1；膨胀后不超出网格边界且不与其他菱形（含其变换后形态）重叠。

**规则**：
1. 对每个菱形轮廓，计算其严格内部（曼哈顿距离小于半径的像素集合中）黄(4)标记像素的数量 N。
2. 若 N 为奇数，将该菱形半径减 1（收缩一层）；若 N 为偶数（且 N > 0），将该菱形半径加 1（膨胀一层）。
3. 以原菱形中心为圆心、新半径重绘菱形轮廓，颜色保持不变。
4. 清除所有黄(4)标记像素为背景色橙(7)。
5. 背景和其他非菱形、非标记的像素保持不变。

**关键洞察**：标记像素不是简单装饰——它们的数量奇偶性隐式编码了几何变换方向；仅看单个示例可能恰好所有菱形都是奇数标记（全收缩），需要对比多个示例才能发现偶数情况下的膨胀规则。

## 新题 3：下采样揭示隐藏对称后补全缺失

**组合逻辑**：[下采样] + [对称补全]（均为已有原语，"下采样是对称补全的前置解码步骤"是创新结构关系）

**来源原语**：下采样/分隔行列/奇偶索引分离/保留偶索引交叉(68b67ca3), 对称补全/缺失像素/推断对称轴/镜像对应(981571dc)

**依赖链**：下采样移除分隔行列后才能看到真实的空间布局 -> 在压缩网格中推断对称轴 -> 利用对称性填补缺失像素。删除下采样则分隔行列破坏对称性（无法识别轴）；删除对称补全则下采样结果仍有空洞。

先压缩稀疏网格以去除分隔行列，在紧凑网格中发现双轴对称并修补被擦除的像素。

**输入结构**：偶数尺寸的网格（约 14x14 或 16x16），黑(0)为背景。所有奇数索引行和奇数索引列全为黑(0)（作为分隔行列）。偶数行偶数列交叉处的像素构成一个逻辑符号网格（约 7x7 或 8x8）。该逻辑网格的非零像素本应形成一个关于某条水平轴和某条竖直轴的双轴对称图案（使用 2~3 种非零颜色，如红(2)、蓝(1)、绿(3)）。但其中 3~5 个本应有色的逻辑位置被擦除为黑(0)。生成约束：擦除位置分布在不同象限，使得每个缺失位置至少有一个镜像位置保留着正确颜色；对称轴不在网格正中（需从现有非零像素推断）。

**规则**：
1. 提取所有偶数行偶数列交叉位置的像素，构成紧凑的逻辑网格（高度和宽度各为原输入的一半）。
2. 从逻辑网格的非零像素推断水平和竖直反射轴（选择最能保持现有非零像素对称性的轴位置）。
3. 对逻辑网格中每个黑(0)像素，检查其关于两条轴的镜像位置：若镜像位置有非零颜色，则填入该颜色；若两条轴的镜像给出不同颜色，取出现次数更多的颜色（即检查该像素的所有对称等价位置，取多数颜色）。
4. 输出为补全后的逻辑网格（不再包含分隔行列）。

**关键洞察**：原始网格中的分隔行列使相邻逻辑像素在视觉上相隔两行/两列，对称关系被物理间距掩盖；必须先下采样消除间距，才能在紧凑空间中识别对称轴并完成修复。

## 新题 4：全行/全列条交叉点处生成轮廓，轮廓色由条长度比较决定

**组合逻辑**：[描边](创新：描边色不由固定映射决定，而由动态比较决定) + [计数] + [重涂色]（描边、计数为已有原语，"长度比较→描边色"是创新结构关系）

**来源原语**：描边/空心矩形/交叉邻域环涂色(67a423a3), 计数/压缩/数量决定输出宽(d631b094), 重涂色(67385a82), 全行条/全列条/交叉点(67a423a3), 面积比较(67385a82)

**依赖链**：定位所有全行条和全列条的交叉点 -> 比较每对交叉条的像素长度 -> 比较结果决定该交叉点处空心方环的颜色 -> 交叉中心像素取较长条的颜色。删除描边则无输出形状；删除计数/比较则无法确定颜色。

在每对全行条与全列条的交叉处画一个 3x3 空心方环，方环颜色取两条中较短者的颜色，中心像素保留较长者的颜色。

**输入结构**：约 15x15 的黑(0)背景网格。包含 2~3 根全行条（各自用一种不同颜色，如红(2)、蓝(1)、绿(3)，一像素宽，横跨整行）和 2~3 根全列条（各自用一种不同颜色，如灰(5)、黄(4)，一像素宽，纵贯整列）。每根条的颜色独一无二。不同行条之间至少间隔 3 行，不同列条之间至少间隔 3 列，确保任意两个交叉点的 3x3 邻域不重叠。生成约束：同一种颜色只用于一根条；所有交叉点距网格边界至少 1 像素。

**规则**：
1. 识别所有全行条（完全覆盖某一行的非背景像素）和全列条（完全覆盖某一列的非背景像素）。
2. 对每个交叉点（行条所在行与列条所在列的交汇处），比较该行条的总像素数（即网格宽度）和该列条的总像素数（即网格高度）。
3. 以交叉点为中心的 3x3 区域中，将周围 8 个像素涂为较短条的颜色（若行条像素数 < 列条像素数则为行条颜色，反之为列条颜色）。
4. 交叉中心像素涂为较长条的颜色。
5. 若网格为正方形（行条与列条像素数相等），则 8 个周围像素涂黄(4)，中心保留行条颜色（行优先）。
6. 所有非交叉 3x3 区域内的行条和列条像素保持原色不变。

**关键洞察**：空心方环的颜色不是从固定的颜色映射表中查找的，而是取决于该交叉点处两根条的长度比较——这意味着同一根行条在不同交叉点处可能扮演"较短方"或"较长方"的角色（如果网格是非正方形的），由此产生不同的环色。但在正方形网格中所有交叉都平局，需要对比非正方形示例才能发现长度比较规则。

## 新题 5：射线延伸被旋转后的条截断

**组合逻辑**：[旋转](创新：旋转产物不输出，而是生成射线的终止屏障) + [射线延伸] + [擦除]（旋转、射线延伸、擦除均为已有原语，"旋转后条作为射线屏障"是创新结构关系）

**来源原语**：旋转/单像素宽条/中心点不变/朝向交换长度保持(f0f8a26d), 射线延伸/实心矩形/孤立标记/同色对应/轴线对齐/端帽(a2d730bd), 擦除(bae5c565)

**依赖链**：旋转条改变空间屏障布局 -> 射线从矩形向标记延伸时遇到旋转后的条则被截断 -> 被截断的射线不画端帽，到达标记的射线正常画端帽 -> 擦除标记像素。删除旋转则屏障位置错误（原始条可能不挡射线）；删除射线延伸则旋转结果无用。

实心矩形向同色标记发射带帽射线，但灰条旋转后形成屏障可截断部分射线。

**输入结构**：约 20x20 的黑(0)背景网格。包含 2 个不同颜色的实心矩形（如红(2) 3x2、蓝(1) 2x3），每个矩形有 2~3 个同色孤立标记像素分布在其水平或竖直轴线延伸方向上、矩形外侧。另有 2~3 根灰(5)的单像素宽条（奇数长度 3~7），水平或竖直放置，不与矩形或标记重叠。生成约束：每根灰条旋转 90 度后，至少有一根恰好横穿某条射线路径（处于矩形边缘与某个标记之间），但不是所有射线都被截断——至少每个矩形有一条射线能到达其标记。

**规则**：
1. 将每根灰(5)条绕其中心旋转 90 度（水平变竖直、竖直变水平，长度和中心不变）。旋转后的灰像素写入网格，原始灰条像素清除为背景。
2. 对每个实心矩形，找到所有与其同色的孤立标记像素（必须与矩形在同一行或同一列上对齐）。
3. 从矩形的相邻边缘向每个标记画一条一像素宽的直线射线。
4. 若射线路径中遇到旋转后的灰像素（或任何非背景、非标记的像素），射线在该障碍前一格停止，不画端帽，也不画矩形端的三像素横帽。
5. 若射线畅通到达标记：在标记一侧画三像素垂直帽（跨过标记并延伸一格），在矩形端画三像素垂直帽（与参考题 a2d730bd 相同），射线全程涂矩形颜色。
6. 将所有原始孤立标记像素清除为背景（无论射线是否到达）。
7. 灰条在输出中以旋转后的位置保留。

**关键洞察**：灰条的原始朝向可能与射线平行（不阻挡），但旋转后变为垂直于射线方向从而形成截断屏障；必须先心算旋转才能判断哪些射线会被阻断、哪些能到达标记并画帽。

## 新题 6：借用对称轴反射格子单元填充

**组合逻辑**：[填充/连线](创新：填充范围由格子内标记对决定) + [镜像](创新：反射轴不在格子中心而借自对称体) + [双色交叉混合]（填充、镜像为已有原语，"对称体位置偏移反射轴使格子填充产生非对称展开"是创新结构关系）

**来源原语**：填充/格子单元/网格线/共行或共列/双色交叉混合色(e760a62e), 镜像/对称体/对称轴借用/借轴复制非对称体(4c5c2cf0), 标记像素(e760a62e)

**依赖链**：识别格子中的标记并执行行列填充 -> 从对称体推断反射轴 -> 将已填充区域关于该轴做镜像填充 -> 原始填充与镜像填充重叠处涂混合色。删除格子填充则无待反射的内容；删除对称轴借用则不知道反射轴在哪里；删除混合色规则则重叠处理不确定。

在格子中沿标记对连线填充单元，然后借用格子内某个对称图形的对称轴将填充区域做镜像扩展，重叠处变为混合色。

**输入结构**：约 17x17 的黑(0)背景网格。青(8)像素构成一像素宽的正交网格线，将画布分为 4x4 或 5x5 的等大矩形格子单元（每个单元约 3x3）。其中一个格子单元内包含一个用灰(5)像素画的小图案，该图案同时具备水平和竖直镜像对称（例如一个 3x3 的十字或菱形），这是"对称体"。其余格子中，散布红(2)和绿(3)标记像素（每个标记占据一个格子单元的中心像素）。同色标记成对出现在同一格子行或同一格子列上。生成约束：对称体不在网格中心格子中（偏向某个角落），使得借用的对称轴不通过网格中心。红标记对和绿标记对各 2~3 对，不与对称体所在格子重叠。

**规则**：
1. 识别包含灰(5)对称图案的格子单元，提取该图案的水平和竖直对称轴（以该图案中心为原点，延伸到整个网格的格子坐标系中）。
2. 对红(2)标记：若同一格子行有两个及以上红标记，将该格子行中从最左红标记到最右红标记之间的所有格子单元填满红(2)（保留青(8)网格线不变）。同一格子列同理。
3. 对绿(3)标记同样执行。
4. 将所有已被红色填充的格子单元集合，关于步骤 1 中的两条对称轴做镜像，在镜像位置的格子单元也填充红色（若该单元为空）。绿色同理。
5. 若某个格子单元同时被红色填充和绿色填充（无论是原始填充还是镜像填充），该单元改为品红(6)。
6. 对称体所在格子保持灰(5)图案不变；青(8)网格线始终保留。

**关键洞察**：反射轴由对称体的位置决定，而对称体偏离网格中心，因此镜像后的填充区域不是简单的中心对称翻转——对称体越偏角落，镜像扩展越不对称，这要求求解者精确定位对称体才能确定轴。

## 新题 7：间隙填充色由跨区域多重集平衡决定

**组合逻辑**：[填充](创新：填充区域由矩形间隙决定，但填充颜色由全局约束决定) + [计数/多重集平衡]（填充、计数为已有原语，"间隙几何 x 多重集平衡"是创新的双约束结构）

**来源原语**：填充/前景矩形/行列跨度重叠/间隙区域/无遮挡才填充(ef135b50), 计数/分隔线/颜色多重集相同/各区域缺像素(e3fe1151), 矩形区域(e3fe1151)

**依赖链**：分隔线将网格分为区域 -> 每个区域内矩形间隙决定填充位置 -> 四个区域的间隙填充色不独立，而须满足全局多重集一致约束。删除间隙检测则不知道填哪里；删除多重集约束则不知道填什么色。两个约束同时作用，缺一不可。

网格被分隔为四个区域，每区域含矩形对之间的水平间隙需要填充，但填充色须使四区域的颜色多重集相同。

**输入结构**：约 15x15 的网格。灰(5)像素构成一条完整水平分隔行和一条完整竖直分隔列（各一像素宽），将网格分为四个大致等大的矩形区域。每个区域包含 2~3 个小实心前景矩形（用红(2)、蓝(1)、绿(3)、黄(4)中的颜色，每个矩形 2~4 像素宽、2~3 像素高）。某些矩形在水平方向上被间隔分开，且它们的行跨度重叠、间隙无第三个矩形遮挡（与参考题 ef135b50 的间隙条件相同）。每个区域恰有一个这样的可填充间隙（保证恰好一个）。背景色为黑(0)。生成约束：四个区域中已有矩形的颜色分布略有不同，但通过为每个区域的间隙选择合适的颜色，可以使四个区域的非背景、非分隔色像素的颜色多重集完全相同。

**规则**：
1. 识别灰(5)分隔行和分隔列，划分四个区域。
2. 在每个区域中，找到所有行跨度重叠且水平间隙无遮挡的前景矩形对（与参考题 ef135b50 判断逻辑相同）。
3. 对每个区域的（唯一一个）可填充间隙，确定间隙的几何范围（两个矩形边界框之间、共享行跨度内的矩形区域）。
4. 统计四个区域中每种非背景、非灰颜色的像素总数，取每种颜色在四个区域中的最大计数作为目标多重集（与参考题 e3fe1151 逻辑相同）。
5. 对每个区域，计算该区域当前颜色计数与目标多重集的差额——恰好缺一种颜色的若干像素数，且该缺额恰好等于间隙面积。用该缺额颜色填充间隙。
6. 分隔行列和原有矩形像素保持不变。

**关键洞察**：间隙的位置和面积由局部几何（矩形邻接和遮挡判断）决定，但间隙的颜色由全局约束（四区域多重集一致）决定——这两个独立的信息来源必须同时满足，求解者不能仅靠局部推断颜色，也不能仅靠全局推断位置。

## 新题 8：方向编码滑动后碰撞产生面积仲裁重涂色

**组合逻辑**：[滑动/方向编码] + [重涂色/面积比较]（均为已有原语，"滑动目的地碰撞触发面积仲裁"是创新结构关系——碰撞是滑动的涌现效应，面积比较是碰撞的解决机制）

**来源原语**：滑动/精灵体/着色标记/方向编码/色块决定输出位置(a8c38be5), 重涂色/连通分量/面积比较/多像素涂色留单(67385a82)

**依赖链**：方向编码决定每个精灵体的目标位置 -> 多个精灵体可能被编码到同一目标区域 -> 碰撞时面积更大的精灵体覆盖较小的 -> 被完全覆盖（不可见）的精灵体在输出中消失，部分被覆盖的保留可见部分并重涂为特定颜色。删除滑动则不知道目标位置；删除面积仲裁则碰撞无解。

多个精灵体按其内部方向编码滑向画布边缘，碰撞时大面积精灵体覆盖小面积精灵体，被部分遮挡的精灵体的可见像素重涂色。

**输入结构**：约 15x15 的黑(0)背景网格。包含 5~7 个灰(5)的 3x3 小方块（精灵体），彼此不相邻。每个方块内部有若干彩色像素（用红(2)、蓝(1)、绿(3)、黄(4)等颜色），彩色像素的位置编码方向（与参考题 a8c38be5 相同：颜色块偏向某侧表示该方块应滑向该方向）。其中一个方块全灰（无彩色像素），作为中心锚点不移动。部分精灵体的灰色像素数不同（有些精灵体内部彩色像素占 1 格，有些占 2 格，因此灰色面积从 8 到 7 不等，但这里的"面积"指 3x3=9 的完整方块面积），但为了面积仲裁的有意义性，设计中部分精灵体实际为非正方形的不规则4-连通灰色图形（面积 5~9 像素不等），内部同样有方向编码彩色像素。生成约束：恰好有 2 对精灵体的方向编码指向同一边缘区域（会发生碰撞），且每对中两个精灵体的灰色面积不同。

**规则**：
1. 识别所有精灵体（灰(5)为主色的 4-连通图形，内含彩色方向编码像素）。全灰的为中心锚点，不移动。
2. 对每个非锚点精灵体，根据其内部彩色像素相对于灰色主体的方向，确定滑动目标：上、下、左、右、或四个对角之一（与参考题 a8c38be5 类似）。
3. 将每个精灵体整体平移到画布对应边缘（精灵体边界框的对应边贴齐画布边缘）。
4. 若两个精灵体的目标区域重叠：灰色面积较大的精灵体的像素优先保留（覆盖较小者的重叠像素）。
5. 被部分遮挡的精灵体（仍有可见灰像素但少于原始灰面积）：其剩余可见灰像素全部重涂为栗(9)。
6. 被完全遮挡的精灵体（无可见灰像素）：从输出中移除。
7. 未发生碰撞的精灵体保持灰色不变。锚点方块保持在原位不变。

**关键洞察**：方向编码本身不含碰撞信息——碰撞是多个精灵体恰好被编码到同一边缘时的涌现效应；解决碰撞需要回头比较精灵体面积，而面积差异来自精灵体形状的不规则性（不全是标准 3x3），这是一个需要对比多示例才能发现的隐蔽规则。

## 新题 9：空心框角门控对称修复的射线扩展

**组合逻辑**：[对称补全] + [射线延伸](创新：射线延伸仅在修复像素恰好对齐框角对角线时触发) + [经过框角才延伸]（对称补全、射线延伸为已有原语，"修复过程中框角选择性激活射线"是创新结构关系——同时约束满足结构，非流水线）

**来源原语**：对称补全/缺失像素/推断对称轴/镜像对应(981571dc), 射线延伸/角对角对齐/经过框角才延伸(ec883f72), 空心矩形框(ec883f72)

**依赖链**：推断对称轴并确定每个缺失像素的修复颜色 -> 检查每个修复像素是否处于空心框某个角的对角线上 -> 若是，则不仅修复该像素，还沿该对角线向外延伸一条射线。删除对称补全则不知道修复什么颜色（射线也无颜色来源）；删除射线延伸则框角机制无意义；删除框角检查则不知道哪些修复点需要延伸。

修补双轴对称图案的缺失像素，若某个被修补的像素恰好落在空心框角的外延对角线上，则从该框角向外射出同色射线。

**输入结构**：约 15x15 的黑(0)背景网格。包含一个多色双轴对称图案（使用红(2)、蓝(1)、绿(3)等颜色，约占网格中心 9x9 区域），其中 3~5 个像素被擦除为黑(0)。另有一个黄(4)的一像素厚空心矩形框（约 7x7），其中心与对称图案的中心不重合（框整体偏移，使得框的某些角恰好落在某些被擦除像素的对角线方向上）。生成约束：恰好有 2~3 个被擦除像素落在框角的外延对角线上（从框角向外 45 度方向），其余被擦除像素不在任何框角对角线上。框不遮盖对称图案的非擦除像素（框的位置在图案边缘或外侧）。

**规则**：
1. 从对称图案的可见非零、非黄像素推断水平和竖直反射轴。
2. 对每个黑(0)缺失像素，通过镜像位置恢复其颜色（与参考题 981571dc 相同）。
3. 对每个刚被修复的像素，检查它是否位于空心框四个外角中某个角的精确外延对角线上（即从框角出发、沿远离框中心的 45 度方向的射线上）。
4. 若是：从该框角出发，沿向外的对角线方向，将该修复像素的颜色画到网格边缘的每个背景像素上（射线在遇到非背景像素时停止，不覆盖已有像素）。
5. 若不是：仅修复该像素，无额外操作。
6. 黄(4)空心框本身保持不变。

**关键洞察**：空心框的位置不仅是装饰——它的角选择性地将某些"被动修复"升级为"主动射线扩展"；必须先完成对称修复才知道修复像素的颜色，而框角几何同时约束了哪些修复会触发射线，两个逻辑不可分离地交织。

## 新题 10：排序拼接模板副本，位置奇偶决定旋转

**组合逻辑**：[排序拼接](已有原语) + [旋转](创新：旋转不是全局操作而是按排位奇偶选择性施加) + [裁剪/重涂色]（排序拼接、旋转、裁剪/重涂色均为已有原语，"排序位置的奇偶性触发旋转"是创新结构关系——隐式编码结构）

**来源原语**：排序拼接/多像素模板/单像素标记/标记共行或共列/按位置排序标记(12997ef3), 旋转/中心点不变/朝向交换长度保持(f0f8a26d), 裁剪/重涂色(50aad11f)

**依赖链**：识别模板和标记 -> 按标记位置排序 -> 排序后的序号奇偶决定该副本是否旋转 -> 裁剪模板并按对应标记色重涂 -> 拼接所有副本。删除排序则不知道奇偶分配；删除旋转则所有副本朝向一致（与仅看单个示例时的假设一致，但多示例会暴露交替旋转模式）。

将模板按标记排列顺序复制并重涂色，排位为偶数的副本额外旋转 90 度，最后按序拼接。

**输入结构**：约 12x15 的黑(0)背景网格。包含一个蓝(1)的多像素前景模板（4-连通，约 6~10 像素，非对称形状，边界框约 3x4 或 4x3）。另有 4~6 个不同颜色的单像素标记（如红(2)、绿(3)、黄(4)、灰(5)、品红(6)、橙(7)），全部位于同一行（或同一列）。生成约束：标记颜色两两不同；模板的边界框在旋转 90 度后尺寸为 4x3 或 3x4（宽高互换但仍可拼接）；标记数量为偶数，确保拼接结果有对称的旋转模式。

**规则**：
1. 裁剪蓝(1)模板到其最小边界框，得到模板掩膜 M。
2. 识别所有单像素标记（每种非背景、非蓝颜色恰好出现一次的孤立像素）。
3. 若标记共行，则按列坐标从左到右排序，编号 1, 2, 3, ...；若标记共列，则按行坐标从上到下排序。
4. 对编号为奇数的标记：复制 M 并将蓝色替换为该标记颜色，保持原始朝向。
5. 对编号为偶数的标记：复制 M 并将蓝色替换为该标记颜色，然后将该副本顺时针旋转 90 度。
6. 若标记共行：将所有副本按编号从左到右水平拼接（副本之间紧邻，无间隔）。若标记共列：按编号从上到下竖直拼接。
7. 输出为拼接后的矩形网格。

**关键洞察**：仅看单个示例可能恰好只有两个标记（一奇一偶），输出看似"第一个正常、第二个旋转"，可被误解为"交替翻转"或"第二个总旋转"；需要对比包含 4 个及以上标记的示例，才能确认规则是"偶数位旋转、奇数位不旋转"的位置奇偶规则。

## 新题 11：精灵体内标记色选择描边色，描边区域再做对称轴镜像

**组合逻辑**：[描边](创新：描边目标不是孤立点而是不规则精灵体) + [重涂色/标记色决定描边色] + [镜像/对称轴借用]（描边、重涂色、镜像均为已有原语，"精灵体描边+全局对称展开"是创新结构关系——非流水线，描边和镜像共同约束输出）

**来源原语**：描边/空心矩形/标记色决定描边色(913fb3ed), 重涂色(67385a82), 镜像/对称体/对称轴借用/借轴复制非对称体(4c5c2cf0), 精灵体(a8c38be5)

**依赖链**：识别精灵体及其内部标记颜色 -> 标记颜色通过映射表确定描边颜色 -> 在精灵体外围画描边轮廓 -> 识别对称体并提取其对称轴 -> 将描边后的精灵体（含轮廓）整体关于该轴做镜像。删除描边则无轮廓可镜像；删除镜像则描边不扩展；删除标记色映射则描边颜色不确定。

精灵体按内部标记色获得特定颜色的外围描边，然后整个描边结果关于场景中对称体的轴做镜像复制。

**输入结构**：约 16x16 的黑(0)背景网格。包含 1~2 个不规则的单色 4-连通精灵体（灰(5)，3~6 像素，非对称形状）。每个精灵体内部（或紧邻的唯一像素）有一个标记像素：绿(3)、红(2)或青(8)中的一种。另有一个蓝(1)的小图案（约 3x3 或 5x5，具备水平和竖直双轴对称，如十字或正方形），这是对称体。所有图形互不接触，精灵体的外围一圈（描边区域）也不与其他图形重叠。生成约束：对称体不在网格中心；精灵体位于对称体的对称轴一侧（使得镜像后的精灵体落在另一侧空白区域）。

**规则**：
1. 对每个灰(5)精灵体，找到其内部或 4-邻域中唯一的彩色标记像素，确定标记颜色。
2. 颜色映射（与参考题 913fb3ed 相同）：绿(3)标记 -> 描边色为品红(6)；红(2)标记 -> 描边色为蓝(1)；青(8)标记 -> 描边色为黄(4)。
3. 将精灵体的外轮廓（精灵体像素的 8-邻域中所有背景像素）涂为对应描边色。精灵体本身和标记像素保持不变。
4. 识别蓝(1)对称体，提取其水平和竖直对称轴（以对称体中心为交点）。
5. 对每个精灵体及其描边轮廓的所有像素，计算它们关于两条轴的全部镜像位置（水平镜像、竖直镜像、双轴镜像共 3 个副本），在镜像位置绘制相同颜色的像素。若镜像位置已有非背景像素，不覆盖。
6. 对称体本身保持不变。

**关键洞察**：描边色由标记映射决定（需要从多个示例归纳映射表），而镜像轴由对称体位置决定（需要识别对称体并定位其中心）——两个独立规则系统共同决定输出，且对称体的偏心位置使得镜像结果在视觉上不对称于网格中心，增加推理难度。
