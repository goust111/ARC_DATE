## 新题 1：错切掩盖下的对称修复

**组合逻辑**：[错切 shear](反向使用，需先逆向还原) → [对称检测 symmetry_detect](创新：检测目的不是选择对象而是确认对称轴存在) → [对称补全 symmetry_completion](已有) → [错切 shear](正向重新施加)

**来源原语**：错切 shear (3cd86f4f), 对称检测 symmetry_detect (73ccf9c2), 对称补全 symmetry_completion / 对称轨道 symmetry_orbit / 掩码像素 masked_pixel (3631a71a)

**依赖链**：必须先识别行偏移递变并逆向错切，才能暴露出左右对称结构；必须在对称空间中利用轨道配对修复灰色掩码像素；修复完成后必须重新施加原始错切，否则输出形状不对。删除逆向错切则对称轴不可见；删除对称补全则掩码无法恢复；删除正向错切则输出几何形状错误。

将一个被错切变形且部分像素被灰色掩码遮盖的平行四边形图案，还原其隐藏的对称结构以修复掩码，再变形回原始形状输出。

**输入结构**：约 12x18 的黑(0)背景网格。网格中有一个平行四边形区域，由多种前景色（蓝(1)、红(2)、绿(3)、黄(4)，不含灰(5)）构成的图案经过向左下方错切后形成。该区域的左边缘呈从左上到右下的阶梯状对角线，每行相对上一行左移一列（行偏移递变）。区域内有若干像素被替换为灰(5)，表示掩码损坏。平行四边形约 8 行高、原始矩形宽约 6 列。灰色掩码像素不超过总前景像素的 30%。生成约束：逆向错切后还原的矩形图案具有严格的左右镜像对称性；对于每个灰色掩码像素，其在对称轨道中至少有一个配对像素是未被遮盖的（保证可修复）。

**规则**：
1. 识别平行四边形区域的行偏移规律：找到每行非黑像素的起始列，计算相邻行的列偏移差 d（恒为 -1，即每行左移 1 列）。记录行数 H 和偏移方向。
2. 逆向错切：对于第 r 行（r = 0 为最顶行），将该行所有非黑像素右移 (H - 1 - r) 列，使平行四边形还原为矩形。矩形占据固定的列范围。
3. 裁剪出矩形区域（去除周围黑色），得到一个 H 行 W 列的子网格。
4. 在该子网格中，灰(5)像素为掩码。对于每个灰色像素 (r, c)，找到其左右镜像位置 (r, W - 1 - c)。若镜像位置非灰色，则将灰色像素替换为镜像位置的颜色。若镜像位置也是灰色，则这两个位置的修复颜色由它们各自的上下对称伙伴（若存在上下对称）或同一轨道中其他非灰成员决定——但生成时保证每个轨道中至少有一个非灰成员，因此简单的左右镜像即可修复所有掩码。
5. 正向错切：将修复后的矩形重新错切——对于第 r 行，左移 (H - 1 - r) 列，恢复原始平行四边形形状。
6. 输出与输入尺寸相同的网格，修复后的平行四边形放在对应位置，其余保持黑色。

**关键洞察**：平行四边形的外观让人误以为图案本身就是不规则的；只有逆向消除错切后，隐藏的对称轴才浮现，而这条对称轴正是修复掩码损坏的唯一线索。

## 新题 2：不对称度量排序与对象排列

**组合逻辑**：[对称检测 symmetry_detect](创新：从布尔判断改为计算量化得分) → [计数 counting](创新：统计不对称像素数而非填充数) → [排序 sorting](已有) → [裁剪 crop](已有，但作用于排列输出而非选择单个对象)

**来源原语**：对称检测 symmetry_detect / 唯一非轴对称 unique_asymmetric (73ccf9c2), 计数 counting (42a15761), 排序 sorting (7447852a), 裁剪 crop / 面积比较 area_comparison (be94b721), 连通分量 connected_component (ae58858e)

**依赖链**：对称检测为每个对象产出一个量化得分（不对称像素数），该得分作为排序的键值；排序结果决定裁剪后的对象在输出中的空间排列顺序。删除对称检测则无排序依据；删除排序则对象排列无序；删除裁剪则无法提取对象。

将散布在网格中的多个同色前景对象按其左右不对称程度从低到高排成一行输出。

**输入结构**：约 20x20 的黑(0)背景网格。网格中散布 4~6 个蓝(1)的 4-连通前景对象，彼此不相邻（任意两个对象的边界框不重叠且不相邻）。每个对象包含 4~10 个像素，形态各异——有的高度左右对称，有的明显不对称。不同对象的边界框尺寸可以不同。生成约束：所有对象的不对称得分（定义见规则）两两不同，保证排序唯一。

**规则**：
1. 找到所有 4-连通的蓝(1)前景对象。
2. 对每个对象，提取其紧边界框裁剪（边界框内非对象像素为黑(0)）。
3. 计算不对称得分：将裁剪图的前景掩码与其左右翻转版本逐像素比较，统计不一致的像素数。每个不一致位置计 1 分（即如果位置 (r,c) 在原图中是前景但翻转后不是，或反之，计 1 分）。
4. 按不对称得分升序排列所有对象（得分最小 = 最对称的在最左边）。
5. 构造输出：将排序后的裁剪图从左到右排列，相邻裁剪之间插入一列黑(0)分隔。输出高度等于所有裁剪高度的最大值；高度不足的裁剪顶部对齐，底部用黑(0)填充。

**关键洞察**：排列顺序既不由空间位置决定，也不由面积决定，而由一个需要计算的对称度量决定。求解者必须对每个对象执行"与自身镜像比较"这一非显然操作，并将结果转化为排序键。

## 新题 3：路径生长划分区域与标记像素定色填充

**组合逻辑**：[生长 grow / 寻路 pathfinding](已有) + [遇障碍则绕行 detour_on_obstacle](已有) → [洪泛填充 flood_fill](创新：填充对象不是预设区域而是路径动态生成的区域) → [重涂色 recolor](创新：填充颜色由区域内含的标记像素决定，而非行键或固定规则)

**来源原语**：生长 grow / 寻路 pathfinding / 起点像素 start_pixel / 障碍像素 blocker_pixel / 逐步推进 stepwise_advance / 遇障碍则绕行 detour_on_obstacle (d9f24cd1), 洪泛填充 flood_fill / 封闭区域 enclosed_region / 区域排列顺序 region_order (7447852a), 重涂色 recolor / 控制像素 control_pixel (c9f8e694), 标记像素 marker_pixel (97239e3d)

**依赖链**：路径生长输出的红色轨迹充当区域分隔线，定义了洪泛填充的封闭区域边界；每个区域内的标记像素颜色决定该区域的填充色。路径的具体走向（受障碍影响）直接改变区域形状，从而改变哪个标记落入哪个区域。三个环节环环相扣：删除路径则区域不存在；删除标记则填充色未定义；改变障碍布局则路径变化导致标记归属区域发生变化。

从底部起点向上生长路径（遇障碍右绕），路径将网格分割成若干封闭区域，每个区域用其内部标记像素的颜色填充。

**输入结构**：约 16x16 的黑(0)背景网格。底行有 2~3 个红(2)起点像素，位于不同列。灰(5)障碍像素散布在网格内部（不在最外一圈边界上）。另有若干单像素标记，颜色取自蓝(1)、绿(3)、黄(4)，放置在网格内部的空白区域（不与障碍相邻）。生成约束：红色路径生长完成后，路径轨迹加上网格边界将黑色区域分割成若干 4-连通分量；每个分量内恰好包含一个标记像素（保证填充色唯一确定）。标记像素本身不在任何路径上，也不与障碍相邻。

**规则**：
1. 对每个红(2)起点像素，从其位置开始逐步向上生长路径：每步尝试向上移动一格。若上方格为灰(5)障碍，则改为向右移动一格。若右方也不可行（障碍或超出网格），路径终止。路径持续生长直到到达顶行或终止。路径经过的每个格（含起点）涂为红(2)。
2. 所有路径生长完毕后，红(2)路径像素和灰(5)障碍像素视为边界。找到所有被边界和网格边缘围成的 4-连通黑(0)区域。
3. 对每个黑色区域，找到其中唯一的标记像素（蓝(1)、绿(3)或黄(4)）。将该区域内所有黑(0)像素洪泛填充为该标记的颜色。
4. 标记像素本身保留原色不变。红(2)路径和灰(5)障碍保留不变。

**关键洞察**：红色路径并非最终输出的主体——它们是"隐形的刀"，将网格切割成区域。求解者必须先完整模拟路径生长（包括所有绕行），才能确定区域边界，进而才能知道每个标记像素控制哪片区域的颜色。

## 新题 4：宏列排序触发位移条件色翻转

**组合逻辑**：[计数 counting](已有) → [列排序 column_sorting](已有) → [颜色互换 color_swap](创新：触发条件从对边标记对改为"排序后位置是否变化"，即位移检测)

**来源原语**：计数 counting / 列排序 column_sorting / 宏单元 macro_cell / 中心像素列 center_pixel_col / 间隔列 gutter_column / 按填充数降序 desc_filled_count (42a15761), 颜色互换 color_swap / 配对间像素互换 toggle_between_pairs (d2acf2cb)

**依赖链**：计数产出每个宏列的填充数，填充数驱动排序，排序产出位移信息（哪些宏列改变了位置），位移信息触发颜色翻转。翻转操作仅作用于"发生了移动"的宏列——这个触发条件在源题中不存在，是计数+排序的副产品。删除计数则排序无依据；删除排序则无位移信息；删除翻转则输出与纯排序无异（缺少第二层逻辑）。

在宏单元网格中按填充中心数降序重排宏列，并将所有发生了位置移动的宏列中的青/橙中心像素互换颜色。

**输入结构**：约 15x15 的网格，由红(2)色 3x3 宏单元排成方阵，宏单元之间有一列黑(0)间隔列和一行黑(0)间隔行分隔。宏阵列为 4 列 4 行（即 4x4 个宏单元）。每个宏单元的中心像素要么是黑(0)（空），要么是青(8)或橙(7)（填充）。宏单元的其余 8 个像素始终为红(2)。每个宏列的填充中心数（非黑中心像素数）两两不同（保证排序唯一且无平局）。每个宏列中青(8)和橙(7)都至少出现一次。

**规则**：
1. 对每个宏列（由同一组列索引上的 4 个宏单元组成），统计其中填充中心像素（青(8)或橙(7)）的个数。
2. 按填充数降序重排宏列：填充数最多的宏列移到最左边的宏列位置，次多的移到第二列位置，依此类推。重排时整个宏列（包含 4 个宏单元的完整 3 像素宽列带）一起移动，间隔列保持在原位置不动。
3. 确定哪些宏列在排序后的位置与排序前不同（即发生了位移）。
4. 对于每个发生位移的宏列，将其所有填充中心像素的颜色翻转：青(8) 变为 橙(7)，橙(7) 变为 青(8)。黑(0)中心保持不变。
5. 对于未发生位移的宏列（排序后位置与原位置相同），保持其所有中心像素颜色不变。
6. 红(2)框架和黑(0)间隔行列始终保持不变。

**关键洞察**：颜色翻转的触发条件不是位置标记或颜色本身，而是排序过程产生的"副作用"——位移。一个宏列即使包含可翻转的颜色对，只要排序后它恰好留在原位，就不会被翻转。求解者必须先完成排序才能知道哪些列触发翻转。

## 新题 5：骨架填充编码非均匀错切参数

**组合逻辑**：[计数 counting](创新：计数对象从宏列填充数改为骨架行的填充帧数，且计数结果不用于排序而用于编码变换参数) → [错切 shear](创新：从固定公式偏移改为由外部编码的逐行任意偏移)

**来源原语**：计数 counting / 宏单元 macro_cell / 中心像素列 center_pixel_col (42a15761), 骨架格子 scaffold_lattice / 空心小框 hollow_cell_frame / 标记像素 marker_pixel / 扩展填充 expand_fill (97239e3d), 错切 shear / 行偏移递变 row_offset_progress / 行内容保持 row_content_preserved (3cd86f4f)

**依赖链**：骨架区域的几何结构（哪些帧中心被填充）编码了一组数值序列；该序列定义了相邻图案区域的逐行偏移量；偏移量驱动非均匀错切变换。骨架不是被变换的对象，而是变换的"指令"。删除骨架则偏移量无法获取；删除错切则计数结果无用途；两者缺一则题目不可解。

读取骨架区域中每行的填充帧中心数作为偏移量，对相邻的彩色图案执行逐行非均匀右移。

**输入结构**：约 13x22 的黑(0)背景网格。左侧区域：H 行（如 H=5）绿(3)色空心 3x3 帧排成网格，每行排列 K 个帧（如 K=4），帧之间以一列黑(0)分隔，行之间以一行黑(0)分隔。部分帧的中心像素填充为黄(4)，其余中心为黑(0)。右侧区域：与左侧用 2 列黑(0)分隔，包含一个 H 行 W 列（如 W=5）的彩色矩形图案，使用蓝(1)、红(2)、品红(6)等颜色（不含绿(3)、黄(4)、黑(0)）。生成约束：每行帧中心的黄色填充数在 0~K 之间，不同行的填充数可以相同也可以不同。max(offset) + W 不超过输出画布宽度。

**规则**：
1. 识别左侧的骨架区域：定位绿(3)色空心 3x3 帧组成的网格结构。帧排列成 H 行 K 列。
2. 对每个帧行 r（r = 0 为最顶行，r = H-1 为最底行），统计该行中中心像素为黄(4)的帧的数量，记为 offset[r]。
3. 识别右侧的彩色矩形图案（H 行 W 列）。
4. 创建输出画布：H 行，宽度为 W + max(offset[0], ..., offset[H-1])，背景为黑(0)。
5. 对图案的每一行 r，将该行的 W 个像素复制到输出画布的第 r 行，起始列为 offset[r]。行内像素顺序和颜色保持不变。
6. 输出仅包含错切后的图案画布，不包含骨架区域。

**关键洞察**：骨架区域看似是一个独立的装饰结构，实际上它是一张"编码表"——每行填充帧的数量就是该行图案应当右移的距离。与固定公式的错切不同，这里的偏移序列完全由骨架内容决定，求解者必须先"解码"骨架才能执行变换。

## 新题 6：反射射线划分区域按面积排名填色

**组合逻辑**：[射线延伸 ray_extend](已有) + [边界反射 boundary_reflection](创新：反射产物不是最终输出而是中间结构——分隔线) → [洪泛填充 flood_fill](创新：填充区域由射线轨迹动态划分而非预设) → [排序 sorting](创新：排序键从空间位置改为区域面积) → [重涂色 recolor](创新：颜色由面积排名映射而非标记像素)

**来源原语**：射线延伸 ray_extend / 对角射线种子 diagonal_ray_seed / 反射镜段 mirror_segment / 边界反射 boundary_reflection / 特定色反射射线 specific_reflects (7e2bad24), 洪泛填充 flood_fill / 封闭区域 enclosed_region / 区域排列顺序 region_order / 等间隔采样填充 periodic_fill (7447852a), 排序 sorting (7447852a), 面积比较 area_comparison / 选取最大面积对象 largest_area_selected (be94b721), 重涂色 recolor (ae58858e)

**依赖链**：射线延伸（含反射）生成完整轨迹 → 轨迹充当分隔线将网格划分为区域 → 计算每个区域面积 → 按面积降序排序 → 排名决定填充颜色。射线轨迹的每一次反射都改变分隔线走向，直接影响区域形状和面积。删除射线追踪则区域不存在；删除面积排序则填充色未定义。

追踪一条在红色镜面上反射的对角蓝色射线，用其轨迹将网格分割为若干区域，按区域面积从大到小分配不同颜色。

**输入结构**：约 15x15 的黑(0)背景网格。一个由 2~3 个蓝(1)像素组成的对角线段（射线种子）位于网格的一个角落附近（如左上角），沿 45 度方向排列。网格内部放置 2~4 段红(2)水平或竖直线段作为反射镜（每段长 3~5 像素）。除射线种子和反射镜外，网格其余部分为黑(0)。生成约束：射线从种子端点出发沿对角方向延伸，遇红色镜面反射（水平镜翻转行方向，竖直镜翻转列方向），最终射出网格边界。射线轨迹加上网格边界将黑色区域分割成至少 3 个面积两两不同的 4-连通分量。射线不会穿过同一个格子两次（无自交）。

**规则**：
1. 找到蓝(1)对角射线种子。确定其向外延伸的端点和方向（远离网格角落的那一端继续延伸）。
2. 从该端点沿对角方向逐格前进。到达的每个黑(0)格涂为蓝(1)。
3. 若下一格为红(2)镜面：不涂色，执行反射——若镜面为水平线段则翻转行移动方向（上变下或下变上），若为竖直线段则翻转列移动方向（左变右或右变左）。从当前格沿新方向继续。
4. 若下一格超出网格边界，射线终止。
5. 射线追踪完成后，将蓝(1)射线轨迹和红(2)镜面视为边界。找到所有 4-连通的黑(0)区域。
6. 计算每个区域的面积（像素数），按面积降序排序。平局按该区域最上最左像素的位置排序（行号小的优先，行号相同则列号小的优先）。
7. 按排名分配颜色：第 1 名（最大）→ 绿(3)，第 2 名 → 黄(4)，第 3 名 → 灰(5)，第 4 名及以后 → 橙(7)。
8. 用分配的颜色洪泛填充对应区域。蓝(1)射线和红(2)镜面保持不变。

**关键洞察**：射线和镜面看似是题目的"主角"，实则只是生成分隔线的工具。真正的输出由射线轨迹对网格的切割方式决定——而这需要完整追踪所有反射才能确定。面积排名填色是一个全局操作，对每个区域的颜色依赖于所有区域的相对大小，不能逐区域独立求解。

## 新题 7：连通分量面积门控像素放大

**组合逻辑**：[计数 counting](创新：统计连通分量面积，用于门控而非排序/排列) + [面积超阈值则变色 recolor_above_threshold](创新：从变色改为"保留/清除"的二值门控) → [像素放大 pixel_scale + 掩码映射 mask_mapping](已有，但受门控选择性施加)

**来源原语**：像素放大 pixel_scale / 掩码映射 mask_mapping / 自身色选掩码 self_color_selects_mask / 全局掩码 global_mask / 块单元 block_cell (973e499e), 计数 counting / 面积超阈值则变色 recolor_above_threshold / 连通分量 connected_component (ae58858e)

**依赖链**：连通分量分析在原始小网格上执行，产出每个像素所属分量的面积；面积门控决定该像素在放大后是否保留其自色掩码块；像素放大为每个像素生成一个与输入同形的块。两个层级的分析（原始网格的连通性 vs. 放大后的块内容）交织：连通性在原始尺度计算，但结果在放大尺度体现。删除连通分量分析则所有块等价保留（退化为原题）；删除像素放大则门控结果无输出载体。

对小网格执行像素放大（每个像素展开为与输入同形的自色掩码块），但仅保留那些在原始网格中属于面积达到阈值的连通分量的像素对应的块，其余块清空为黑色。

**输入结构**：一个约 4x5 的小网格（无黑(0)背景列/行，整个网格都有内容）。使用 2~3 种前景色（如蓝(1)、红(2)、绿(3)），黑(0)不出现在输入中（黑仅在输出的清空块中出现）。每种前景色形成若干 4-连通分量，分量面积各异（有的面积 >= 3，有的面积 < 3）。同一种颜色可以有多个不相连的分量，且部分分量达标、部分不达标。网格中至少有一种颜色同时拥有达标和不达标的分量。

**规则**：
1. 在输入网格上，对每种颜色分别找到所有 4-连通分量，计算每个分量的面积（像素数）。
2. 面积阈值为 3。面积 >= 3 的分量中的像素标记为"大"，面积 < 3 的标记为"小"。
3. 执行像素放大：输出尺寸为 (H x H) 行 (W x W) 列（H 和 W 为输入的行数和列数）。输入的第 (r, c) 个像素对应输出中以 (r*H, c*W) 为左上角的 H x W 块。
4. 对于"大"像素 (r, c)，颜色为 color：在其对应的 H x W 块中，将输入网格中所有颜色也为 color 的位置写入 color，其余位置写入黑(0)。（这是标准的自色掩码规则。）
5. 对于"小"像素 (r, c)：其对应的 H x W 块全部填充为黑(0)。
6. 组装所有块得到最终输出。

**关键洞察**：两个相同颜色的像素会生成内容完全相同的自色掩码块，但如果一个属于大分量、另一个属于小分量，则前者的块完整保留而后者的块被清空。求解者必须在原始小网格上分析连通性——而不是在放大后的输出上——才能判断哪些块存在、哪些被清空。
