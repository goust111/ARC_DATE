## 新题 1：对角轨道滑动与镂空平行四边形填充

**组合逻辑**：[滑动对齐](创新：滑动方向由对角线段对决定，非由锚点边缘位置决定) + [填充](创新：填充区域由同一组对角线段定义，精灵体最终位置在填充区内形成镂空) ← [平行配对] + [颜色匹配锚点]

**来源原语**：滑动对齐、多色精灵体、边界锚点、颜色匹配锚点(581f7754)；对角线段、平行配对、段间区域填充、平行四边形区域(7666fa5d)

**依赖链**：对角线段对同时约束精灵体的可移动方向（沿主对角方向）和定义待填充的平行四边形区域；精灵体必须先完成滑动，填充才能在剩余背景像素上执行，因而精灵体的最终位置决定了平行四边形中镂空孔洞的形状与位置。

将多色精灵体沿对角线段对构成的轨道滑动至其标记像素与匹配的边界锚点对齐，然后用红色填充线段对之间的背景区域，精灵体所在像素保留为镂空。

**输入结构**：黑(0)背景，约 16x16。灰(5)短反对角线段（每段 3-5 像素，沿 r+c = 常数排列）成对出现，每对由两条平行的反对角线段组成（相同斜率，不同截距，间距 4-8 个像素）。每对线段之间有一个 4-连通的小型多色精灵体（3-6 像素，主色为一种非黑非灰颜色，其中恰好一个像素的颜色与主色不同，称为"标记像素"）。网格边界上散布若干孤立的锚点像素（4-邻域全为黑(0)的非黑非灰单像素），每个锚点的颜色恰好与一个精灵体的标记像素颜色相同。生成约束：每对线段之间至多一个精灵体；精灵体沿轨道滑动的全程不会与其他精灵体或线段碰撞；每个锚点恰好匹配一个精灵体。

**规则**：
1. 识别所有平行反对角线段对（同斜率、不同截距的两条灰(5)线段构成一对）。
2. 每对线段定义一条"轨道"，方向为主对角方向（垂直于反对角线段，即 (r-c) 增大或减小的方向）。轨道上的精灵体只能沿此方向整体平移。
3. 为每个精灵体找到颜色匹配的边界锚点（标记像素颜色 = 锚点颜色）。
4. 将精灵体沿轨道滑动，直至其标记像素与匹配锚点"对齐"：若锚点在网格的上边缘或下边缘（非角落），则对齐意味着标记像素所在列 = 锚点所在列；若锚点在左边缘或右边缘（含角落），则对齐意味着标记像素所在行 = 锚点所在行。
5. 滑动完毕后，对每对线段之间的平行四边形区域（严格位于两条线段之间的所有像素位置），将其中仍为黑(0)的像素填充为红(2)。精灵体像素和灰(5)线段像素不被覆盖。

**关键洞察**：对角线段对承担三重角色——约束滑动方向、定义填充区域、划定精灵体活动范围。填充必须在滑动之后执行，因此精灵体最终位置产生的镂空孔洞是输出中最显著的视觉特征，但要理解孔洞的位置就必须先理解滑动规则和锚点匹配。

## 新题 2：孔洞拓扑编码循环色移

**组合逻辑**：[计数](孔洞拓扑计数) → [循环移位](创新：移位量由拓扑特征——孔洞数——决定，而非由空间属性如高度决定) + [填充](创新：填充孔洞以销毁编码证据)

**来源原语**：循环移位、有序槽位、色与高反向轮转(2601afb7)；孔洞、封闭区域、内外边界(d931c21c)；计数(bd283c4a)；填充(d5d6de2d)

**依赖链**：孔洞计数是循环移位的参数来源；移位改变了每个框架的颜色；随后孔洞被填充为统一色，擦除了决定移位量的证据。求解者必须在证据被销毁前的输入中读取孔洞数量，再反推输出中的颜色排列。

统计每个空心矩形框内的孔洞数量，以此数量作为循环色移量重排各框架颜色，然后将所有孔洞填为绿色。

**输入结构**：黑(0)背景，约 16x18。N 个（3-5 个）空心矩形框沿水平方向从左到右排列，互不重叠，间距 2-3 列。每个框的边框为单像素厚的单色边框（每个框颜色不同，使用红(2)、蓝(1)、黄(4)、品红(6)、橙(7)等），框的内部为黑(0)。部分框的内部含有 0、1 或 2 个小型黑(0)孔洞——这些孔洞是框内部被额外的同色像素围成的封闭小区域（孔洞的 4-连通黑色分量不与框外部的黑色背景连通）。孔洞的形状为不规则的小型连通区域（2-4 像素），不同框内的孔洞形状可以不同。生成约束：所有框的孔洞数量不全相同（至少两个框的孔洞数不同）；循环移位后每个槽位的颜色与输入不完全相同（即变换可被观测到）。

**规则**：
1. 将 N 个空心矩形框按其边界框左上角的列坐标从小到大排序，依次编为槽位 0, 1, ..., N-1。
2. 记录每个槽位 i 的框边框颜色 C_i 和其内部孔洞数量 H_i。
3. 循环色移：槽位 i 的输出颜色 = 槽位 (i - H_i) mod N 的输入颜色 C_{(i - H_i) mod N}。即孔洞数 H_i 决定该框从左侧第 H_i 个位置借来颜色（循环取模）。
4. 用新颜色重涂每个框的所有边框像素。
5. 将所有框内部的孔洞像素（原本被同色边框围住的黑色封闭区域）填充为绿(3)。

**关键洞察**：孔洞的数量是拓扑属性，在空间上分散且形状不规则，不易直觉关联到颜色的代数运算。填充孔洞为绿色后，输出中已无法直接看到各框的孔洞数量，求解者必须从输入中提取拓扑信息、与输出的颜色排列对比，才能归纳出"孔洞数 = 移位量"这条隐蔽规则。

## 新题 3：连线交叉色优先决定封闭区域填色

**组合逻辑**：[连线](同色配对连线) → [填充](创新：填充目标是连线涌现出的封闭区域，填色由交叉点的优先色经邻接投票决定) ← [竖线交叉优先] + [邻接多数决]

**来源原语**：连线、同色配对、竖线交叉优先、标记像素、线段(40853293)；边邻接计数、邻接多数决、连通分量(477d2879)；封闭区域(d931c21c)

**依赖链**：连线操作在网格中创建几何结构，线段交叉产生封闭区域——这是涌现效应（单独的线段不产生封闭区域，组合后才出现）。交叉点处的竖线优先规则决定了交叉像素的颜色，而交叉像素恰好是封闭区域的边界像素之一，因此优先规则直接影响邻接投票的结果，从而改变封闭区域的填充色。

将同色标记像素对用直线连接，在交叉处保留竖线颜色，然后将连线围成的封闭区域填充为与其边界邻接最多的那条线段的颜色。

**输入结构**：黑(0)背景，约 14x14。若干对同色标记像素（每种非黑颜色恰好出现 2 次），共 3-5 对。每对的两个像素共享同一行或同一列。颜色使用红(2)、蓝(1)、绿(3)、黄(4)等。各对的连线会产生至少 2 个交叉点，且这些线段和网格边界共同围成至少 1 个不接触网格边界的封闭黑色区域。生成约束：保证至少一个封闭区域的邻接投票结果会因竖线优先规则而改变（即若取消优先规则改用水平优先，至少一个区域的填色会不同）；每个封闭区域的邻接投票结果唯一（无平票）。

**规则**：
1. 对每对同色标记像素，用该颜色绘制连接两者的水平或竖直线段（包含端点）。若两像素同行，绘制水平线段；若同列，绘制竖直线段。
2. 在线段交叉点（同一像素位置被两条不同颜色的线段经过），保留竖直线段的颜色。
3. 识别所有 4-连通的黑(0)封闭区域：那些不与网格任何边界像素连通的黑色连通分量。
4. 对每个封闭区域，统计其所有像素的 4-邻域中各线段颜色出现的次数（一个区域像素在某方向与某颜色的线段像素相邻，计 1 次）。将该区域填充为出现次数最多的颜色。
5. 接触网格边界的黑色区域保持黑(0)不变。

**关键洞察**：竖线交叉优先规则不只是解决视觉冲突——它改变了交叉像素的颜色，而交叉像素往往恰好位于封闭区域的边界上。因此优先规则间接决定了封闭区域的填色，形成了从交叉规则到填色结果的隐性传递链。求解者需要先理解交叉优先规则，再理解邻接投票，才能预测输出。

## 新题 4：形状匹配补孔后射线沿孔洞朝向延伸

**组合逻辑**：[填充](形状匹配 → 补孔着色) + [射线延伸](创新：射线方向由孔洞在对象内的相对位置决定，射线颜色由补孔颜色决定) → [裁剪]

**来源原语**：填充、带孔对象、标记形状、形状匹配、归一化形状对应、忽略干扰项(42f14c03)；射线延伸、方向指示、顶点反基底延伸(25d487eb)；裁剪(e66aafb8)

**依赖链**：形状匹配将标记对象的颜色传递给孔洞（填色），射线延伸使用该颜色绘制射线（颜色依赖）。同时，孔洞相对于宿主对象边界框的位置决定了射线方向（空间依赖）。两条信息流——颜色来自形状匹配、方向来自空间位置——在射线绘制环节汇合。裁剪操作截断射线长度。

找到含孔洞的前景对象，用颜色匹配的标记对象填充各孔洞，再从每个孔洞向其最近的边界框边射出同色射线，最后裁剪出对象的边界框。

**输入结构**：黑(0)背景，约 18x18。一个较大的蓝(1) 4-连通前景对象（约占 40-60 像素），其边界框内有 2-3 个黑(0)间隙区域（孔洞），每个孔洞为 3-6 像素的 4-连通区域，形状各异（由结构属性区分：像素数、连通方式、边界框宽高比）。在前景对象外部，散布 2-3 个小型单色标记对象（每个 3-6 像素，颜色各不相同，使用红(2)、绿(3)、黄(4)等），其中每个标记对象的归一化形状（平移至原点后的像素坐标集）与某个孔洞的归一化形状相同。可能存在 0-1 个"干扰"标记对象，其形状不匹配任何孔洞。生成约束：每个孔洞距离边界框的四条边中恰好有一条最近（无平局），且各孔洞最近的边互不相同；各孔洞的归一化形状互不相同。

**规则**：
1. 识别蓝(1)前景对象及其边界框内的所有黑(0)孔洞。
2. 对每个孔洞和每个外部标记对象，计算归一化形状（平移至左上角为 (0,0) 的像素坐标集合）。将形状相同的孔洞与标记配对。不匹配任何孔洞的标记为干扰项，忽略。
3. 用配对标记的颜色填充对应孔洞的所有像素。
4. 对每个已填充的孔洞，计算其边界框中心到宿主对象边界框四条边的距离，取最近的边确定射线方向（上/下/左/右）。
5. 从孔洞边界框中心出发，沿确定的方向绘制 1 像素宽的射线，颜色为该孔洞的填充色。射线穿过蓝(1)像素（将其覆盖为射线颜色）和黑(0)像素，直至到达宿主对象的边界框边（含该边上的像素）。
6. 输出为宿主对象边界框的裁剪结果。干扰标记和边界框外的所有内容被裁掉。

**关键洞察**：孔洞同时编码了两种信息——它的形状决定填充颜色（通过与外部标记的形状匹配），它在对象内的位置决定射线方向（通过与边界框边的距离比较）。这两种信息来自不同的推理路径，但在射线绘制时汇合：没有正确的颜色，射线颜色就错；没有正确的方向，射线位置就错。

## 新题 5：对称配对分类与条件性镜像重涂

**组合逻辑**：[对称补全](创新：对称性不用于填补缺失，而用于将连通分量分类为"已对称"与"非对称"两类) → [重涂色](条件分支：两类分量施加不同的重涂规则) + [对称镜像生成](非对称分量的镜像副本与已对称分量的像素优先级冲突)

**来源原语**：对称补全、对称轨道、对称图案(e66aafb8)；重涂色、连通分量(477d2879)；同色配对(40853293)

**依赖链**：对称性检测将分量分为两组，分组结果决定后续操作的分支走向。非对称分量的镜像生成可能与已对称分量的像素位置冲突，冲突解决规则（对称分量优先）使得输出不是完全对称的——这是一个反直觉的结果，需要理解全部三步才能预测。

检测具有水平对称配对的连通分量与没有配对的分量，前者统一重涂为一种颜色，后者重涂为另一种颜色并创建镜像副本，重叠时对称对优先。

**输入结构**：黑(0)背景，约 14x14。网格具有一条大致的水平反射对称轴（位于网格垂直方向的中间行或相邻两行之间）。网格中有 4-6 个 4-连通的单色前景分量，使用蓝(1)、橙(7)、品红(6)等颜色（每个分量单色，但不同分量可颜色不同）。每个分量为 4-10 像素的不规则形状。其中部分分量成对出现：两个分量形状相同且关于对称轴互为镜像（颜色也相同）。剩余分量没有镜像配对（它们只出现在轴的一侧，对侧没有对应物）。生成约束：至少有 1 对已配对分量和至少 1 个未配对分量；至少一个未配对分量的镜像位置与某个已配对分量的像素存在重叠。

**规则**：
1. 确定水平反射轴：取网格行数 R，若 R 为奇数，轴为第 R//2 行；若 R 为偶数，轴位于第 R/2-1 行与第 R/2 行之间。
2. 对每个 4-连通前景分量，计算其关于轴的镜像位置集合。若存在另一个相同颜色的分量恰好占据该镜像位置集合，则两者构成"对称对"。
3. 对称对中的所有分量：将其所有像素重涂为黄(4)。
4. 未配对分量：将其所有像素重涂为红(2)。然后在轴的另一侧生成其镜像副本，副本颜色也为红(2)。
5. 冲突解决：若红(2)镜像副本的某些像素位置已被黄(4)占据，则该位置保持黄(4)。即对称对像素的优先级高于镜像副本像素。
6. 背景保持黑(0)。

**关键洞察**：虽然操作试图让所有分量都获得对称性（配对的标黄保留，未配对的标红并补全），但由于黄色优先规则，未配对分量的镜像副本可能被部分遮挡，导致输出中出现"残缺的红色镜像"。这种不完美对称是对称检测与冲突解决规则交互的涌现结果，需要对比多个示例（有重叠和无重叠的情况）才能归纳出优先级规则。

## 新题 6：邻接投票驱动排序与竖条等分变色

**组合逻辑**：[重涂色](邻接多数决投票) → [排序](创新：排序键为投票后各颜色的总像素频率，非原始属性) → [等分变色](下半部变灰)

**来源原语**：边邻接计数、邻接多数决、标记像素(477d2879)；排序、按频率降序(bd283c4a)；等分、下半变色、竖直条(ce9e57f2)；有序槽位(2601afb7)

**依赖链**：邻接投票改变了每根竖条的颜色身份，颜色身份决定了频率分组与排序键，排序改变了竖条的空间位置，等分变色作用于最终位置上的竖条。删掉投票环节，排序无法执行（不知道按什么分组）；删掉排序环节，竖条位置不变，失去了"同色聚集"的输出特征。

统计每根蓝色竖条与周围标记像素的邻接关系，用最多邻接的标记色重涂竖条，然后按新颜色的总频率降序排列所有竖条，最后将每根竖条的下半部分变为灰色。

**输入结构**：黑(0)背景，约 12x16。底部对齐的 5-7 根蓝(1)竖条，各占一列，高度各异（3-10 像素），列与列之间间隔 1-2 列。在竖条之间的间隔列和竖条两侧的空白区域，散布若干孤立标记像素（4-邻域全为黑(0)或全为非标记色），颜色使用红(2)、绿(3)、黄(4)。每种标记颜色至少出现 2 次。生成约束：每根竖条至少与 1 个标记像素 4-相邻；每根竖条的邻接投票有唯一胜出颜色（无平票）；投票后各颜色对应的竖条总像素数互不相同（确保排序无平局）。

**规则**：
1. 对每根蓝(1)竖条，统计其所有像素的 4-邻域中每种标记颜色出现的总次数。将竖条重涂为出现次数最多的标记颜色。
2. 统计每种新颜色对应的所有竖条的总像素数（即该颜色所有竖条高度之和）。
3. 按总像素数从大到小排列颜色组。组内按竖条高度从高到低排列。
4. 将排列后的竖条依次放置在输出网格中（与输入同尺寸），从最左侧可用列开始，每根竖条占一列，相邻竖条之间间隔 1 列，底部对齐。
5. 对每根竖条，上半部分（上方 ceil(height/2) 个像素）保留投票所得颜色，下半部分（下方 floor(height/2) 个像素）重涂为灰(5)。
6. 标记像素在输出中不保留（全为黑(0)背景）。

**关键洞察**：标记像素不仅仅重涂竖条颜色，还隐式决定了竖条在输出中的空间排列——因为排列由重涂后的颜色频率驱动。相邻的标记像素使附近的竖条获得相同颜色，这些同色竖条在输出中会聚集在一起。等分变色是验证竖条身份的视觉指纹（高度在排序前后保持不变）。

## 新题 7：模板印章自由定位与坐标轴距离决定遮挡层序

**组合逻辑**：[印章覆盖](创新：印章位置由散布的控制像素决定，非由网格槽位决定) + [透明叠加](创新：遮挡层序由印章到坐标轴交点的距离排序决定，非由固定面板顺序决定) + [擦除](移除坐标轴线)

**来源原语**：印章覆盖、输入图案、控制像素对应副本(27f8ce4f)；排序、距离排序、坐标轴线(291dc1e1)；透明叠加、前后遮挡(cf98881b)；擦除(604001fa)

**依赖链**：坐标轴提供距离度量 → 距离决定遮挡深度 → 遮挡深度决定重叠区域的颜色 → 最后轴线被擦除。若不先识别轴线和计算距离，就无法确定哪个副本在重叠处"获胜"。轴线在输出中消失，求解者必须从输入中提取距离信息来解释输出中的遮挡模式。

将模板精灵体复制到每个控制像素位置并重涂为该控制色，按各副本到坐标轴交点的曼哈顿距离从远到近依次叠加（近者在上），最后擦除轴线。

**输入结构**：黑(0)背景，约 18x18。网格的某条水平边和某条垂直边各有一条单色线（共两种颜色，如红(2)水平线沿顶行、蓝(1)垂直线沿左列），两线在一个角落像素相交，交点像素为栗(9)。网格内部靠近交点处有一个小型模板精灵体（4-6 像素，颜色为栗(9)，与交点同色，形状不规则，4-连通）。内部另散布 3-5 个孤立控制像素，颜色各不相同（绿(3)、黄(4)、品红(6)、橙(7)等），彼此间距足够远使得以控制像素为左上角放置模板后，至少有部分副本之间存在像素重叠。生成约束：各控制像素到交点的曼哈顿距离互不相同；所有副本至少部分位于网格内（超出网格的部分裁掉）。

**规则**：
1. 识别坐标轴线（水平线 + 垂直线）及其交点（栗(9)像素）。
2. 识别模板精灵体：与交点同色(栗(9))且 4-连通、像素数 > 1 的对象。记录其形状（相对于其左上角的像素偏移集）。
3. 对每个控制像素，以该像素位置为模板的左上角，生成一个模板副本，颜色设为该控制像素的颜色。超出网格边界的像素舍弃。
4. 计算每个控制像素到交点的曼哈顿距离。
5. 按距离从大到小依次将副本绘制到输出网格上（距离最大的先画，最小的后画，后画的覆盖先画的）。即距离越近，遮挡优先级越高。
6. 擦除坐标轴线（将轴线所在的行与列上的轴线颜色像素恢复为黑(0)）、擦除原始模板精灵体、擦除交点像素。

**关键洞察**：坐标轴在输出中被完全擦除，但它是决定遮挡层序的唯一依据。求解者只能通过观察重叠区域的颜色推断"哪个副本在上"，再结合输入中控制像素与轴线交点的距离来归纳"距离近者在上"的规则。需要多个示例中不同的重叠配置才能排除其他可能的排序依据（如颜色编号、行列位置等）。

## 新题 8：竖条高度编码矩形个体旋转角后距离排序堆叠

**组合逻辑**：[排序](距离排序建立矩形-竖条对应关系) + [旋转](创新：每个矩形获得独立旋转角，由配对竖条的高度编码) + [堆叠](旋转后的矩形按排序顺序堆叠)

**来源原语**：排序、堆叠、旋转、矩形、坐标轴线、距离排序、轴色决定旋转(291dc1e1)；竖直条、条高度、有序槽位、色与高反向轮转(2601afb7)

**依赖链**：坐标轴距离排序同时确定堆叠顺序和矩形-竖条对应关系（排序后第 k 个矩形对应第 k 根竖条）。竖条高度编码旋转角，旋转改变矩形的宽高，宽高影响堆叠时的空间占位。三步紧耦合：距离排序 → 配对建立 → 读取竖条高度 → 旋转矩形 → 堆叠旋转后结果。

按矩形到坐标轴交点的距离排序，将排序后的矩形与竖条序列配对，用竖条高度决定各矩形的旋转角度，然后按排序顺序上下堆叠旋转后的矩形。

**输入结构**：黑(0)背景，约 18x20。网格由两个区域组成：上部区域（约占 2/3 高度）包含坐标轴和矩形；下部区域（约占 1/3 高度）包含竖条行。上部区域：网格某条水平边和某条垂直边各有一条灰(5)线，交点像素也为灰(5)。区域内散布 3-5 个单色实心矩形（颜色各异，使用红(2)、蓝(1)、绿(3)、黄(4)等；宽高各 2-5 像素），互不重叠，不与轴线重叠。下部区域：底部对齐的一行竖条，竖条数量与矩形数量相同，从左到右排列，间隔 1 列。每根竖条颜色为橙(7)，高度为 1-4 像素（分别编码 0、90、180、270 度逆时针旋转）。生成约束：各矩形到轴线交点的曼哈顿距离互不相同；竖条的颜色统一，仅通过高度传递信息。

**规则**：
1. 识别灰(5)坐标轴线及其交点。
2. 识别上部区域的所有单色实心矩形（非黑、非灰的连通矩形区域）。
3. 按每个矩形中心到轴线交点的曼哈顿距离从小到大排序，得到序列 R_0, R_1, ..., R_{N-1}。
4. 识别下部区域的橙(7)竖条，按列坐标从左到右排序，得到序列 B_0, B_1, ..., B_{N-1}。
5. 配对：R_k 与 B_k 配对。B_k 的高度 h 决定 R_k 的旋转角度：h=1 → 0 度（不旋转），h=2 → 90 度逆时针，h=3 → 180 度，h=4 → 270 度逆时针。
6. 对每个 R_k 应用其配对旋转。旋转以矩形中心为参考点，将矩形的像素图案旋转指定角度。
7. 构建输出网格：将旋转后的矩形按 R_0, R_1, ..., R_{N-1} 的顺序从上到下垂直堆叠，相邻矩形间隔 1 行。所有矩形水平居中对齐（取所有旋转后矩形的最大宽度，每个矩形在该宽度范围内居中）。输出网格的宽度 = 最大旋转后宽度，高度 = 所有旋转后高度之和 + (N-1) 行间距。背景为黑(0)。

**关键洞察**：坐标轴建立的距离排序不仅决定最终堆叠顺序，还建立了矩形与竖条的配对关系——这是一个隐性对应，输入中没有任何直接标记将特定矩形与特定竖条关联。求解者必须先发现距离排序，再发现左到右的竖条与排序后的矩形一一对应，最后发现高度编码旋转角。三层编码嵌套使得单个示例难以完全确定规则。
