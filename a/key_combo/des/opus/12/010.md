## 新题 1：对称恢复解锁模板涂色表

**组合逻辑**：[对称补全](从独立恢复变为恢复控制矩阵) + [重涂色](由恢复结果驱动) + [模板格点/行列位置对应](提供映射结构)

**来源原语**：对称补全、遮挡矩形、二面体对称、可见副本恢复遮挡 (f4081712)；重涂色、控制矩阵、模板格点、模板对象、行列位置对应、按控制色重涂 (33b52de3)

**依赖链**：对称恢复产出完整的颜色矩阵 -> 颜色矩阵作为控制信号驱动模板重涂色。遮挡区恰好覆盖了部分控制单元，若不恢复则无法确定对应模板的目标色。

从一个被部分遮挡的对称色阵中恢复隐藏颜色，用恢复后的色阵逐位置重涂一组模板对象。

**输入结构**：约 14x14 的网格，背景为黑(0)。左半区包含一个 3x3 的模板格点：9 个相同的灰(5) 小图形（4-连通、3~5 像素、带孔洞的不规则形状），按 3 行 3 列排列，相邻模板之间间隔 1 列/行的背景。右半区包含一个 7x7 的多色图案，该图案在旋转 90/180/270 度及水平/垂直/对角翻转下自映射（二面体对称群 D4）。图案中有一个 3x3 的绿(3) 实心矩形遮挡了部分像素。在图案中可选取一个 3x3 的子采样网格（每隔固定步长取一个像素），该子采样网格与模板格点一一对应。生成约束：被绿矩形遮挡的子采样位置至少有 2 个，且每个被遮挡位置在 D4 对称群下至少存在一个未被遮挡的等价位置，使恢复唯一。

**规则**：
1. 在右半区的 7x7 图案中，对每个被绿(3) 遮挡的像素，遍历 D4 对称群的所有旋转/翻转映射，找到未被遮挡的等价坐标，取其颜色作为该像素的恢复值（所有未遮挡等价坐标颜色一致）。
2. 恢复完成后，从图案中按固定步长（行步长和列步长均为 2）提取一个 3x3 的颜色子矩阵，起点为图案左上角 (0,0)。
3. 将子矩阵第 i 行第 j 列的颜色赋给模板格点中第 i 行第 j 列的模板对象：该模板的所有灰(5) 前景像素被重涂为对应颜色，模板内的背景孔洞保持黑(0)。
4. 绿遮挡矩形替换为恢复后的颜色。其余像素不变。

**关键洞察**：对称图案不是装饰，而是一张被损坏的查色表；恢复遮挡像素的目的不是修复图案本身，而是为了读取其中隐藏的控制颜色来驱动左侧模板的重涂色。

## 新题 2：穿墙路径的分段变色

**组合逻辑**：[连线/寻路](生成路径) + [计数](累计穿墙次数) + [循环填充](穿墙计数驱动颜色循环)

**来源原语**：连线、寻路、平行墙壁、门段、标记像素、穿越门中心、走廊正交路径 (7e576d6e)；计数 (6e82a1ae)；循环填充、色彩循环 (72207abc)

**依赖链**：寻路确定路线的几何形状 -> 穿墙次数递增产生分段索引 -> 索引查色循环确定每段颜色。路径不存在则无段可数；段数不确定则无法选色。

从起点到终点画穿过平行墙壁门洞的正交路径，路径每穿过一面墙即换一种颜色，颜色按给定循环轮转。

**输入结构**：约 20x12 的网格，背景为黑(0)。3~5 面平行水平墙壁横跨整个网格宽度，每面墙占 1 行，颜色为灰(5)。每面墙内有一个 3 像素宽的门段（该处墙壁像素被替换为背景色，形成通道）。各墙的门段列位置互不相同。网格顶行和底行各有一个红(2) 标记像素，分别为路径起点和终点。网格左上角有一条短色带（2~4 个连续像素，每像素颜色各异，如蓝(1)、绿(3)、黄(4)），定义颜色循环序列。生成约束：起点和终点不在同一列；门段互不重叠；色带像素与墙壁/标记不相邻。

**规则**：
1. 读取左上角色带中的颜色序列（从左到右）作为循环 C，长度为 L。
2. 从起点标记向下画正交路径（仅水平/垂直线段），依次穿过每面墙的门段中心像素，最终到达终点标记。路径规则：在每段走廊（两面相邻墙壁之间的空间）中，先水平移动到下一面墙门段中心的列位置，再垂直移动到门段所在行并穿过门洞中心。最后一段走廊连接到终点。
3. 将路径按穿墙事件分段：第 0 段为起点到第一面墙之前（含穿过门中心的像素），第 1 段为第一面墙之后到第二面墙之前，依此类推。
4. 第 k 段路径像素涂色为 C[k mod L]。门中心像素属于其所开启的下一段（即门中心像素的颜色 = 下一段的颜色）。
5. 起点和终点标记像素保持红(2) 不变。墙壁、色带和背景不变。

**关键洞察**：路径不是单色的——穿墙次数作为一个运行中的计数器，驱动颜色在循环中递进，使路径的色彩分段直接编码了迷宫的拓扑深度。

## 新题 3：面积奇偶决定棋盘格相位

**组合逻辑**：[填充](棋盘格方式) + [平铺](将两色行扩展为棋盘) + [计数](内部面积) —— 面积奇偶作为决策节点切换填充相位

**来源原语**：填充、矩形边框、封闭内部、内部面积、面积阈值决定颜色 (84f2aca1)；棋盘格图案、纯色行、列奇偶交替、奇偶决定交换 (e9afcf9a)；平铺 (caa06a1f)

**依赖链**：两色行提供棋盘调色板 -> 每个框的内部面积奇偶决定棋盘相位 -> 按相位铺设棋盘格。调色板、面积、框的几何形状三者共同约束输出，缺一不可。

读取两色行的颜色对，用棋盘格方式填充各矩形框的内部，但棋盘的起始相位由框内面积的奇偶性决定。

**输入结构**：约 14x14 的网格，背景为黑(0)。最顶部两行是两条纯色行：第 0 行全为蓝(1)，第 1 行全为橙(7)。下方散布 3~5 个灰(5) 的 1 像素厚矩形边框，大小各异（最小 3x3 外框即 1x1 内部，最大约 7x7 外框即 5x5 内部）。框之间互不重叠、互不相邻。每个框的内部全为背景色。生成约束：至少有一个框内部面积为奇数，至少有一个为偶数。

**规则**：
1. 从顶部两行读取棋盘颜色对：color_A = 第 0 行颜色（蓝(1)），color_B = 第 1 行颜色（橙(7)）。
2. 计算每个矩形框的内部面积（内部行数 x 内部列数）。
3. 对每个框的内部区域铺设棋盘格图案：
   - 若内部面积为偶数：内部左上角格填 color_A，相邻格交替（标准棋盘相位）。
   - 若内部面积为奇数：内部左上角格填 color_B，相邻格交替（反转棋盘相位）。
4. 框边框保持灰(5)。顶部两色行保持不变。背景不变。

**关键洞察**：棋盘格的两种相位不是随机分配的——框的内部面积奇偶性是一个隐蔽判据，需要对比多个示例中不同大小的框才能归纳出相位与面积奇偶的对应关系。

## 新题 4：邻接过滤后的十字扩展色由存活数全局控制

**组合逻辑**：[擦除](邻接过滤) -> [计数](存活十字数) -> [扩展](正交对角分工) —— 过滤改变存活集合，存活总数全局回馈到每个存活者的扩展配色

**来源原语**：擦除、孤立像素、邻接、邻接不足则删除 (7f4411dc)；扩展、十字图案、正交对角分工、臂色中心色分延 (0962bcdd)；计数、像素数映射颜色 (6e82a1ae)

**依赖链**：邻接过滤决定哪些十字存活 -> 存活数 N 作为全局信号 -> N 的奇偶决定所有存活十字的对角扩展颜色。单看一个十字无法确定其扩展色，必须知道全局存活数。

过滤掉孤立噪声像素后，统计存活十字数量，然后将每个存活十字扩展为 5x5 图案，其中对角扩展的颜色由存活总数的奇偶性全局决定。

**输入结构**：约 15x15 的黑(0) 网格。4~6 个两色 3x3 十字图案散布其中：每个十字的 4 个臂为橙(7)，中心为黄(4)。另有若干橙(7) 噪声像素随机散布在非十字位置。生成约束：噪声像素与十字的臂像素不直接 4-邻接（确保过滤不会误伤十字臂）；至少有一个十字的某个臂像素恰好只有 1 个橙色 4-邻居（即中心），该十字将因过滤被整体移除。不同示例中存活十字数量的奇偶性不同。

**规则**：
1. 对每个橙(7) 像素，统计其橙色 4-邻居数量。移除所有橙色 4-邻居数 < 2 的橙像素（变为黑(0)）。
2. 检查每个十字是否仍完整（中心 + 4 臂均保留）。不完整的十字整体移除（所有残余像素变黑）。
3. 统计存活的完整十字数量 N。
4. 对每个存活十字执行 5x5 扩展：
   - 正交方向（上下左右）：在原臂外侧延伸 1 像素，颜色为臂色橙(7)。
   - 对角方向（四角）：若 N 为奇数，对角像素涂黄(4)（中心色）；若 N 为偶数，对角像素涂绿(3)。
5. 中心像素保持黄(4) 不变。

**关键洞察**：每个十字的扩展配色不是由自身属性决定，而是由全局存活十字总数的奇偶性统一控制——噪声分布间接影响存活数，从而影响所有存活者的外观。需要对比多个示例中噪声不同、存活数奇偶不同的情况才能归纳出这条隐式全局规则。

## 新题 5：字形解码色 + 周期瓦片推断 = 双源汇合涂色

**组合逻辑**：[查表映射](字形解码颜色) + [平铺/补全](推断周期瓦片几何) + [重涂色](将瓦片中的占位色替换为解码色) —— 两个独立信息源分别提供"什么颜色"和"什么形状"，汇合后才能确定输出

**来源原语**：查表映射、编码字形、字形映射颜色、编码映射 (ed74f2f2, 9110e3c5)；平铺、补全、重复瓦片、遮挡区域、可见像素约束推断、最小周期推断填补 (ca8f78db, 29ec7d0e)；重涂色 (fafd9572)

**依赖链**：字形解码 -> 目标颜色 C；可见像素 -> 推断瓦片几何 T；用 C 替换 T 中的灰色 -> 输出。两路信息独立，但输出同时依赖两者。

从一个编码字形中解读目标颜色，从一个被遮挡的周期图案中推断重复瓦片的几何形状，然后用解读的颜色替换瓦片中的灰色像素并铺满整个图案区。

**输入结构**：约 12x12 的网格，背景为黑(0)。左上角 3x3 区域包含一个灰(5) 编码字形（5 个灰像素组成的特定形状，其余为黑）。该字形可以是以下三种之一：T 形（顶部三格 + 中下一格 + 底中一格）、右下折线（左上一格 + 中行中格 + 中行右格 + 下行右两格）、十字形（中心 + 上下左右各一格）。其余区域（从第 0 行第 4 列起至右下角）是一个周期色彩图案，使用灰(5) 和黑(0) 两色（灰为前景，黑为背景），但部分单元被栗(9) 矩形遮挡（栗色块覆盖了若干像素）。生成约束：遮挡区不覆盖字形区域；每个瓦片残基类的灰像素在未被遮挡处至少出现一次，使瓦片可唯一推断。

**规则**：
1. 解码字形：T 形 -> 蓝(1)，右下折线 -> 红(2)，十字形 -> 绿(3)。设解码颜色为 C。
2. 在图案区中，将栗(9) 像素视为未知，根据所有非栗像素推断最小矩形重复周期 (p_r, p_c)，使得每个非栗像素的颜色与 (row mod p_r, col mod p_c) 一致。构建 p_r x p_c 的瓦片 T。
3. 用瓦片 T 铺满整个图案区，替换所有像素（包括栗色遮挡区和原有像素）。
4. 在铺设结果中，将所有灰(5) 像素重涂为解码颜色 C。黑(0) 像素不变。
5. 字形区域保持原样（灰色字形不被重涂，因为它不在图案区内）。

**关键洞察**：字形和周期图案各自解决了一半问题——字形给出"涂什么颜色"，周期图案给出"涂在哪里"。两个信号源完全独立，只在最终输出阶段汇合。

## 新题 6：框面积阈值控制印章扩展半径

**组合逻辑**：[印章覆盖](标记像素扩展) + [填充](框内区域) + [计数](框内面积) —— 面积阈值作为决策节点改变印章的扩展半径，框的几何形状同时约束裁剪范围

**来源原语**：印章覆盖、标记像素、邻域块、中心邻域、仅填背景格 (f0df5ff0)；填充、矩形边框、封闭内部、内部面积、面积阈值决定颜色 (84f2aca1)

**依赖链**：框内面积 -> 阈值判断 -> 决定印章半径（3x3 或 5x5）-> 印章受框边界裁剪。面积决定半径，框边界决定裁剪，标记位置决定中心，三者缺一不可。

根据矩形框内部面积大小选择不同半径的蓝色印章，以框内标记像素为中心展开，印章受框边界裁剪且只覆盖背景格。

**输入结构**：约 16x16 的黑(0) 网格。散布 4~6 个灰(5) 的 1 像素厚矩形边框，大小各异（外框从 4x4 到 9x9 不等）。框之间互不重叠，间隔至少 1 像素。每个框的内部（边框围成的区域）全为背景色，其中恰好有一个蓝(1) 标记像素（位置不在内部正中心，各框的标记偏置不同）。生成约束：无框不含标记；标记与框边框不相邻（标记四周至少有 1 格背景间距）。

**规则**：
1. 对每个矩形框，计算其内部面积 S（内部行数 x 内部列数，不含边框像素）。
2. 以框内蓝(1) 标记像素为中心，选择印章半径：
   - 若 S <= 9，印章为 3x3（中心 +/- 1）。
   - 若 S > 9，印章为 5x5（中心 +/- 2）。
3. 在选定的印章范围内，将所有背景(0) 像素涂为蓝(1)。非背景像素（包括灰框边框）不被覆盖。
4. 印章范围超出框内部边界的部分被裁剪（不向框外延伸）。
5. 框边框保持灰(5)，标记像素保持蓝(1)。

**关键洞察**：印章不是固定大小的——其扩展半径由容器框的内部面积隐式控制。小框用小印章，大框用大印章，但印章始终被框边界裁剪，因此标记偏离中心时印章形状不对称。

## 新题 7：重叠框的遮挡顺序推断与分层填充

**组合逻辑**：[擦除](忽略干扰项) + [重涂色](按层级填充) + [图案识别](从重叠区推断层叠顺序) —— 结构解构型：先分离重叠框的层叠关系，再据此决定填充优先级

**来源原语**：擦除、干扰体、忽略干扰项 (7f4411dc, 9110e3c5)；重涂色 (fafd9572)；填充、矩形边框、封闭内部 (84f2aca1)；交叉 (ba97ae07)；图案识别、重复色为答案 (642d658d)

**依赖链**：干扰像素过滤 -> 识别出纯净的框边界 -> 重叠区颜色揭示层叠顺序 -> 层叠顺序决定填充优先级。这不是线性流水线——层叠顺序的推断需要同时分析所有重叠区的颜色，是一个约束满足问题。

过滤掉孤立干扰像素后，从多个重叠矩形框在交叉处显示的颜色推断出框的前后层叠顺序，再按从后到前的顺序填充每个框的内部（后层先填，前层覆盖）。

**输入结构**：约 14x14 的黑(0) 网格。3~4 个矩形边框（1 像素厚），每个框一种独特的前景色（如蓝(1)、红(2)、绿(3)、黄(4)），框的大小从 5x5 到 8x8 不等。框之间部分重叠：在两框边框交叉的像素位置，只有一种颜色可见（上层框的颜色覆盖了下层）。每个框的内部为背景色。另有若干孤立干扰像素（随机前景色，每个干扰像素的同色 4-邻居数 < 2）。生成约束：每对相邻框至少有一个边框交叉像素，使层叠顺序可唯一确定（即层叠关系构成全序，不出现循环）。框之间的重叠仅限于边框交叉，不存在一个框完全包含另一个框的情况。

**规则**：
1. 移除所有孤立干扰像素：前景像素若其同色 4-邻居数 < 2，则变为黑(0)。
2. 识别所有矩形框。对每对有交叉的框 A 和 B：交叉像素的颜色 = 上层框的颜色。由此建立成对层叠关系：显示 A 色的交叉意味着 A 在 B 之上。
3. 从所有成对关系推断全局层叠顺序（拓扑排序）：最底层到最顶层。
4. 按从底层到顶层的顺序依次填充：每个框的内部（边框围成的矩形区域）全部涂为该框的边框颜色。后填的覆盖先填的（即上层框的填充覆盖下层框的填充）。
5. 所有框的边框像素保持原色不变（始终可见）。

**关键洞察**：重叠处不是视觉干扰——每个交叉像素都是一条"谁在谁上面"的证据。求解者必须从所有交叉证据中重建全局层叠顺序，才能正确地按前后关系执行填充。

## 新题 8：三角数位置选择 + 图例循环涂色 + 噪声过滤

**组合逻辑**：[擦除](噪声过滤) -> [图案识别](三角数位置判定) -> [循环填充](图例排位驱动色循环) —— 三级递进筛选：物理过滤、数学过滤、序位着色

**来源原语**：擦除、孤立像素、邻接、邻接不足则删除 (7f4411dc)；图案识别、忽略干扰项 (642d658d, 9110e3c5)；循环填充、色彩循环、递增间距序列、三角数位置 (72207abc)；重涂色、颜色图例、排位对应、图例位映射色 (fafd9572)

**依赖链**：邻接过滤去噪 -> 存活对象中识别三角数列位置（数学过滤）去干扰 -> 对通过双重过滤的对象按位置排位 -> 排位索引驱动图例色循环。四个阶段逐级缩小目标集，每级的输出是下一级的输入。

先过滤噪声，再从存活的精灵体中筛选出位于三角数列位置的目标，最后按位置排位用图例中的颜色循环重涂。

**输入结构**：约 20x8 的网格，背景为黑(0)。中间行（第 3~4 行，高 2 行）散布若干相同形状的灰(5) 小精灵体（4-连通，3~5 像素的不规则形状），每个精灵体占据一个不同的列区间。精灵体出现在多个列位置，其中一部分位于三角数列位置（以精灵体边界框最左列计算：第 0, 1, 3, 6, 10, 15... 列），另一部分位于非三角数列位置（干扰体）。另有若干孤立灰(5) 噪声像素散布在非精灵体位置。顶行（第 0 行）左侧有一条紧凑色带：3~4 个相邻像素，每个一种不同颜色（如蓝(1)、红(2)、绿(3)），定义颜色循环图例。生成约束：噪声像素与精灵体不 4-邻接；色带与精灵体/噪声不相邻；三角数位置的精灵体数量 > 图例颜色数（确保循环生效）。

**规则**：
1. 移除噪声：灰(5) 像素若其灰色 4-邻居数 < 2，则变为黑(0)。（精灵体像素因内部连通性而保留。）
2. 识别所有存活的完整精灵体（4-连通分量）。
3. 对每个精灵体，取其边界框最左列的列号 c。检查 c 是否为三角数（即存在非负整数 n 使得 c = n(n+1)/2）。非三角数位置的精灵体整体移除（变为黑(0)）。
4. 对存活的三角数位置精灵体，按列号从小到大排位：rank = 0, 1, 2, ...
5. 读取顶行色带中的颜色序列（从左到右）作为循环 C，长度为 L。
6. 将 rank 为 k 的精灵体的所有灰(5) 像素重涂为 C[k mod L]。
7. 色带保持不变。背景不变。

**关键洞察**：精灵体经历了双重筛选——先是物理层面的邻接噪声过滤，再是数学层面的三角数列位置判定。两层筛选缺一不可：仅噪声过滤会保留干扰精灵体，仅位置判定会被噪声残留干扰形状识别。最终的颜色由通过双重筛选后的排位决定，而非由原始位置或像素数决定。
