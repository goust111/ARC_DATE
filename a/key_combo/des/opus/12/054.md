## 新题 1：自相似迷宫的奇偶洪泛

**组合逻辑**：[像素放大/编码映射](创新：块掩码解码) → [掩码克罗内克自积](创新：生成迷宫而非图案输出) → [洪泛填充 + 路径奇偶交替涂色](创新：BFS距离奇偶决定颜色)

**来源原语**：像素放大、编码映射、掩码克罗内克自积(80af3007)；洪泛填充、路径奇偶交替涂色、种子像素、路径连通(b782dc8a)

**依赖链**：块掩码解码产生 3x3 二值掩码 → 克罗内克自积将掩码变为 9x9 分形通道结构 → 种子在通道中 BFS 扩散，距离奇偶决定涂色。掩码的几何形状同时决定了粗尺度和细尺度的通道拓扑，任一步缺失都无法确定最终填充结果。

将块编码的二值图案转化为自相似分形迷宫，再从种子点按路径距离奇偶交替涂色填充迷宫通道。

**输入结构**：
- 网格约 12x12，黑(0)背景。
- 网格中央有一个 9x9 区域，由 9 个 3x3 的均匀块组成。每个块要么全部为灰(5)（表示"通"），要么全部为黑(0)（表示"阻"），构成一个块放大的 3x3 二值掩码。"通"块至少 5 个，保证克罗内克自积后存在连通通道。
- 两个不同颜色的种子像素（红(2)和绿(3)）各一个，分别放置在不同的灰(5)块的内部。两个种子在克罗内克自积后的通道中通过 4-连通路径可达彼此。
- 9x9 区域之外全部为黑(0)。

**规则**：
1. 将 9x9 区域压缩为 3x3 二值掩码 M：若第 (i,j) 个 3x3 块全为灰(5)则 M[i][j]=1，否则 M[i][j]=0。
2. 对 M 做克罗内克自积生成 9x9 通道图 K：K 中第 (3i+a, 3j+b) 格为通道（值 1）当且仅当 M[i][j]=1 且 M[a][b]=1。
3. 将两个种子像素的坐标从输入的 9x9 区域映射到 K 的对应位置（相对于 9x9 区域左上角的偏移量保持不变）。
4. 从两个种子同时开始 BFS（4-连通），只沿通道格（K 值为 1 的格）扩散。每个通道格被最先到达它的种子占有。BFS 距离为偶数的格涂该种子的颜色，距离为奇数的格涂另一个种子的颜色（即红种子的偶距格涂红(2)、奇距格涂绿(3)；绿种子的偶距格涂绿(3)、奇距格涂红(2)）。距离 0 即种子自身。若两个种子同时到达同一格（BFS 距离相等），由行索引较小者的种子占有；行索引也相同则由列索引较小者占有。
5. 输出为 9x9 网格：通道格按步骤 4 涂色，非通道格为黑(0)。

**关键洞察**：输入的粗粒度块掩码自我复制后产生分形迷宫拓扑，颜色不由空间区域决定而由通道中的 BFS 路径距离奇偶决定——同一种子的相邻通道格必然颜色不同，形成棋盘式交织。

## 新题 2：旋转对称模板识别与象限修复

**组合逻辑**：[旋转对称](条件：识别模板) → [模板与副本匹配](对比找出损坏象限) → [对称补全](旋转正确象限覆盖损坏象限)

**来源原语**：旋转对称、四次旋转闭合(e40b9e2f)；模板与副本匹配、非标记精确匹配(bb52a14b)；对称补全(b8825c91, 4290ef0e)；精灵体(4290ef0e, 38007db0)

**依赖链**：旋转对称性是模板识别的判据（不是显式标记） → 模板匹配发现各副本哪个象限被篡改 → 对称补全从模板的对应象限旋转得到正确内容并覆盖。三步缺一不可：没有对称检测无法识别模板，没有匹配无法定位损坏，没有旋转补全无法修复。

在散布的同构精灵体中找出唯一具有四重旋转对称的模板，将其余精灵体的损坏象限用模板对应象限旋转修复。

**输入结构**：
- 网格约 17x17，黑(0)背景。
- 散布 4~6 个互不重叠的精灵体，每个占据一个 5x5 的边界框。所有精灵体使用同一种前景色（蓝(1)）在黑(0)背景上绘制。
- 恰好一个精灵体具有完美的 90 度旋转对称性（绕其 5x5 边界框中心旋转 90/180/270 度后图案不变），此为模板。
- 其余精灵体与模板仅在一个象限（左上/右上/左下/右下，以中心行列划分，中心行列归属左上象限）不同：该象限中的蓝(1)像素被替换为红(2)像素，形状也被篡改为与模板不同的随机连通图案。其余三个象限与模板完全一致（蓝(1)像素位置相同）。
- 不同副本被篡改的象限位置各不相同。
- 生成约束：模板的四重旋转对称图案中每个象限至少有 2 个前景像素，确保篡改可被检测。

**规则**：
1. 扫描所有 5x5 精灵体，检测哪个具有 90 度旋转对称性——将其标记为模板 T。
2. 对每个非模板精灵体 S，逐象限与 T 对比：找到 S 中与 T 不一致的那个象限 Q（该象限包含红(2)像素）。
3. 从 T 中取出象限 Q 对应位置的蓝(1)图案，将其覆盖到 S 的象限 Q 位置，替换掉红(2)像素。
4. 输出整个网格，所有精灵体修复完毕（全部为蓝(1)），背景不变。

**关键洞察**：模板没有显式标记——必须通过检测旋转对称性来识别它；红色不是"需要填入的颜色"而是"标记损坏位置的信号"，修复后红色完全消失。

## 新题 3：射线交叉计数决定面板叠放顺序

**组合逻辑**：[射线延伸](创新：射线不画线而是用于探测) → [计数](射线与前景的交叉数) → [排序](按交叉数) → [透明叠加](排序后的面板合成)

**来源原语**：射线延伸(9344f635, 95755ff2)；计数、排序、按计数升序排列(d4c90558)；透明叠加、面板、分隔列、图层优先级(281123b4)

**依赖链**：射线从标记像素向下贯穿面板 → 统计每根射线穿过的前景像素数并按面板求和 → 和值升序决定面板从前到后的叠放顺序 → 透明叠加合成最终图像。射线不产生可见输出，只产生数值信号；数值信号控制叠放顺序；叠放顺序决定可见输出。任一步缺失链条断裂。

从面板顶部标记发射下行探测射线，统计各面板内射线与前景像素的交叉数，按交叉数升序确定面板叠放优先级，合成单幅透明叠加图像。

**输入结构**：
- 网格为 5x23，由 3 列灰(5)分隔列将网格分为 4 个 5x5 面板（从左到右编号 P0~P3）。
- 每个面板的背景为黑(0)，包含一个由单一前景色绘制的 4-连通精灵体（3~8 像素），四个面板的前景色互不相同，取自蓝(1)、红(2)、绿(3)、黄(4)。
- 每个面板的最顶行（第 0 行）放置 1~3 个橙(7)标记像素，位于该面板列范围内的不同列上。标记像素不与该面板的前景精灵体重叠。
- 生成约束：四个面板的交叉计数（见规则步骤 2）互不相等，保证排序结果唯一。

**规则**：
1. 对每个面板内的每个橙(7)标记像素，从该像素所在列的第 1 行（标记行下方）向下延伸一条垂直射线直到面板底部（第 4 行）。射线本身不绘制任何颜色。
2. 对每个面板，统计其所有射线经过的格中属于该面板前景色的像素总数。设面板 Pi 的交叉计数为 Ci。
3. 按 Ci 升序排列四个面板。Ci 最小的面板为最前层（前景），Ci 最大的面板为最后层（背景）。
4. 将四个面板在同一 5x5 画布上透明叠加：从最后层到最前层依次绘制，每个面板的黑(0)格视为透明（不覆盖已有内容），非黑格覆盖。最终输出 5x5 网格。

**关键洞察**：射线不画线——它们是隐形探针，其与前景的交叉频率编码了一个数值信号，该信号反向控制了图层深度：交叉越少的面板越靠前，因为遮挡少意味着"可见度高"。

## 新题 4：对角偏移平铺中的局部位置优先级冲突解决

**组合逻辑**：[对角线偏移复制](创新：多色图案的偏移平铺) → [局部位置分类](创新：分类应用于平铺副本而非独立矩形) → [重涂色 + 冲突优先级](创新：位置层级决定重叠胜者)

**来源原语**：对角线偏移复制、拼接(d13f3404)；局部位置分类、角边内部分别涂色(b6afb2da)；重涂色(d4c90558, 5ad4f10b)；冲突优先级(9344f635)

**依赖链**：对角偏移复制产生重叠区域 → 局部位置分类为每个副本中的每个前景像素赋予层级 → 重叠位置上层级高的副本胜出。如果不做平铺则无重叠，不做分类则无法解决重叠，不做冲突解决则输出不确定。

将多色图案沿右下对角线偏移平铺到加倍画布上，在重叠处按像素在其所属副本中的局部位置层级（内部 > 边缘 > 角）决定保留哪个副本的颜色。

**输入结构**：
- 网格约 5x5，黑(0)背景。
- 网格中有一个紧凑的多色前景图案，其边界框为 HxW（H、W 均为 3~5），使用 2~3 种前景色（取自蓝(1)、红(2)、绿(3)、黄(4)），前景像素 4-连通。
- 前景图案内部结构不对称，且至少包含角、边缘、内部三种局部位置类型的像素（即边界框 H>=3 且 W>=3）。

**规则**：
1. 确定前景图案的边界框（H 行 x W 列），创建一个 (H + H-1) x (W + W-1) 的输出画布，填充黑(0)。
2. 将前景图案作为"副本 0"放在输出画布的左上角（偏移 (0,0)）。然后依次放置副本 k（k=1, 2, ...），每个副本相对于前一个向右下偏移 1 行 1 列，直到副本的右下角触及画布边界。共产生 min(H, W) 个副本。
3. 对每个副本中的每个前景像素，按其在边界框内的位置分类：
   - **角**：位于边界框的四个角格（(0,0), (0,W-1), (H-1,0), (H-1,W-1)）。
   - **边缘**：位于边界框的边但不在角上（第 0 行、第 H-1 行、第 0 列、第 W-1 列的非角格）。
   - **内部**：不在边界框边上的格。
   层级：内部 > 边缘 > 角。
4. 按副本编号从小到大依次将前景像素绘制到画布上。每个像素绘制前检查该画布位置是否已被先前副本的前景像素占据：
   - 若未被占据，直接绘制该副本的原色。
   - 若已被占据，比较当前像素与已占据像素的层级：层级更高者保留其颜色。层级相同时，编号更大的副本（后绘制）覆盖先前的。
5. 输出画布为最终结果。背景像素（输入中黑(0)的位置）在所有副本中均视为透明，不参与绘制和冲突比较。

**关键洞察**：重叠不是简单的"后来居上"——一个副本的内部像素可以抵抗被后续副本的角像素覆盖，形成非均匀的层级遮挡效果，使得平铺输出中不同位置的"深度"取决于几何结构而非绘制顺序。

## 新题 5：周期性栅栏限界的指示像素镜像

**组合逻辑**：[邻接 + 指示像素](检测指示位置和颜色) → [镜像](创新：镜像范围不由画布决定) → [周期间隔 + 遇阻停止](创新：周期栅栏截断反射副本)

**来源原语**：镜像、指示像素、邻接、指示定镜像与色(b775ac94)；周期间隔(8403a5d5)；遇阻停止、阻挡像素(95755ff2)

**依赖链**：指示像素的位置决定镜像轴和反射色 → 镜像生成反射副本 → 周期栅栏截断反射副本超出栅栏区间的部分。如果不检测指示像素则不知道镜像方向；如果不做镜像则无反射内容；如果不施加栅栏约束则反射范围错误。

将精灵体按指示像素指定的轴和颜色做镜像反射，但反射副本被等间距的栅栏竖线截断——副本只在与原件同侧的栅栏区间内可见。

**输入结构**：
- 网格约 13x17，黑(0)背景。
- 灰(5)竖线以固定间距 d（d 为 4~6）等间隔地贯穿网格全高，形成若干宽度为 d-1 的纵向区间。灰(5)竖线为单像素宽、贯穿第 0 行至最后一行。
- 每个区间内至多包含一个 4-连通单色精灵体（3~7 像素），颜色取自蓝(1)、红(2)、绿(3)中的一种。不同区间的精灵体颜色可相同或不同。
- 部分精灵体的某一侧（上、下、左、右）紧邻一个单像素指示像素，颜色取自黄(4)、品红(6)、橙(7)中的一种。指示像素与精灵体 4-连通相邻，且指示像素位于精灵体所在区间内部（不在灰(5)栅栏上）。每个有指示像素的精灵体恰好有一个指示像素。
- 部分精灵体没有指示像素，这些精灵体保持不变。
- 生成约束：精灵体及其未来的反射副本不超出网格边界；同一区间内不会出现两个精灵体。

**规则**：
1. 对每个有指示像素的精灵体 S：
   a. 确定指示像素相对于 S 的方位（上/下/左/右）。该方位决定镜像轴：左或右 → 以指示像素所在列为轴做水平镜像；上或下 → 以指示像素所在行为轴做垂直镜像。
   b. 生成 S 的镜像副本 S'，所有像素涂为指示像素的颜色。
   c. 将 S' 放置到镜像位置。但 S' 中超出 S 所在栅栏区间（由两侧灰(5)竖线界定的纵向区间）列范围的像素全部丢弃。超出网格上下边界的像素也丢弃。
2. 绘制顺序：先保留所有原始精灵体和灰(5)栅栏，再绘制反射副本。反射副本不覆盖原始精灵体像素、指示像素和灰(5)栅栏像素。
3. 没有指示像素的精灵体保持不变。
4. 指示像素本身在输出中保留。

**关键洞察**：栅栏不只是装饰性分隔线——它们定义了每个精灵体的"活动范围"，镜像反射被硬性截断在同一栅栏区间内，使得不同区间的精灵体即使指示方向相同，反射结果也因区间宽度和精灵体位置而完全不同。

## 新题 6：奇数正方形尺寸循环后的通道洪泛填充

**组合逻辑**：[缩放 + 边长循环变换](创新：尺寸变化改变空间拓扑) → [洪泛填充 + 路径连通](创新：在动态产生的通道中扩散)

**来源原语**：缩放、奇数边正方形、中心点、同心定位、边长循环变换(522fdd07)；洪泛填充、种子像素、路径连通(b782dc8a)；迷宫走廊(b782dc8a)

**依赖链**：边长循环变换重新确定每个正方形的占据区域 → 收缩的正方形暴露出新的背景通道，膨胀的正方形封堵原有通道 → 种子像素从其位置出发通过 4-连通背景通道洪泛填充。尺寸循环规则决定了通道的拓扑形态，而通道拓扑决定了填充的可达范围和形状。

将若干奇数边正方形按 1->9->7->5->3->1 的循环规则变换边长后重新绘制，然后从种子像素出发对变换后产生的背景通道做洪泛填充。

**输入结构**：
- 网格约 17x17，黑(0)背景。
- 3~5 个单色实心正方形散布在网格中，互不重叠。每个正方形的边长为奇数（1、3、5、7 或 9），颜色互不相同，取自蓝(1)、红(2)、绿(3)、黄(4)、品红(6)。
- 1~2 个橙(7)种子像素放置在黑(0)背景格上（不在任何正方形内部）。
- 生成约束：边长循环变换后（1->9 的膨胀保持中心不变），所有正方形仍在网格内且互不重叠。种子像素在变换后仍位于背景格上。至少存在一条 4-连通背景通道连接种子像素与至少一个因收缩而新暴露的区域。

**规则**：
1. 清空画布为全黑(0)。
2. 对每个正方形，保持其中心和颜色不变，将边长 n 按循环规则变换：n>1 时变为 n-2；n=1 时变为 9。以新边长重新绘制该正方形（以原中心为中心的实心正方形）。
3. 按正方形面积从大到小的顺序绘制（面积相同则按中心行索引升序、再按中心列索引升序）。后绘制的不覆盖先绘制的。
4. 从每个橙(7)种子像素出发，通过 4-连通黑(0)背景格做洪泛填充，将可达的所有黑(0)格涂为橙(7)。种子自身也为橙(7)。填充不进入任何正方形的像素。
5. 输出为填充后的网格。

**关键洞察**：输入中正方形之间看似被隔开的区域，在尺寸循环后可能因收缩而贯通、或因膨胀而被封堵——求解者必须先完成尺寸变换才能判断洪泛填充的可达范围，而 1->9 的剧烈膨胀尤其容易改变拓扑连通性。

## 新题 7：菱形框内同心带填充被侧标记射线覆写

**组合逻辑**：[对角序映射色环 + 同心层填充](创新：同心带为菱形而非矩形) → [射线延伸 + 遇阻停止](创新：射线覆写同心带颜色而非填充空白) → [冲突优先级](射线层在同心层之上)

**来源原语**：同心层填充、空心矩形框(创新为菱形框)、对角线标记、嵌套层次、对角序映射色环(99306f82)；射线延伸、菱形框、侧标记、阻挡像素、框内填充、遇阻停止(95755ff2)；冲突优先级(9344f635)

**依赖链**：对角线标记提供色彩序列 → 同心带填充为菱形内部涂上分层底色 → 侧标记射线沿行或列覆写底色 → 阻挡像素截断射线。同心带提供"默认值"，射线提供"覆写值"，两者叠加才是最终输出。缺少同心带则射线未触及的格无颜色；缺少射线则侧标记信息丢失。

先用对角线标记序列从外到内为菱形框内部填充同心菱形色带，再用四边侧标记向内发射射线覆写沿途色带颜色，射线遇内部阻挡像素时停止。

**输入结构**：
- 网格约 15x15，黑(0)背景。
- 一个由灰(5)像素构成的一像素厚菱形框，其对角线长度为 9~13（奇数），位于网格中部偏右下。菱形框的四条边各为一段对角线段。
- 菱形框内部初始为黑(0)，但含有 1~3 个栗(9)阻挡像素，分布在不同行列上。
- 菱形框外部、框的边界框的上边/下边/左边/右边各有 0~2 个彩色侧标记像素。上侧标记位于菱形边界框顶行之上一行、对应列上；下侧标记位于底行之下一行；左侧标记位于左列之左一列；右侧标记位于右列之右一列。侧标记颜色取自蓝(1)、红(2)、绿(3)、黄(4)，每个标记颜色可不同。
- 从菱形框左上方出发，有一条由 2~4 个不同颜色的单像素组成的连续右下对角线，颜色取自蓝(1)、红(2)、绿(3)、黄(4)、品红(6)、橙(7)（与侧标记颜色可重叠）。对角线的最后一个像素（最右下的）距菱形框左上顶点恰好 1 格（即在顶点的左上方向紧邻）。
- 生成约束：对角线标记数量不超过菱形框从外到中心的同心带层数（即能填满所有层或填到中心）。

**规则**：
1. 读取对角线标记颜色序列，从左上到右下记为 C1, C2, ..., Ck。
2. 将菱形框内部（不含框线本身）按菱形同心带分层：最外层（紧邻框线的内部像素）为第 1 层，向内依次为第 2、3、... 层，直到中心。若层数 > k，则第 k+1 层及更内层全部使用 Ck 填充。
3. 用 Ci 填充第 i 层的所有黑(0)像素。阻挡像素（栗(9)）所在的格不被填充，保持栗(9)。
4. 对每个侧标记像素，向菱形内部发射一条垂直于所在侧的射线：上侧标记向下、下侧标记向上、左侧标记向右、右侧标记向左。射线沿该行或列前进，仅对严格位于菱形内部的格起作用。
5. 沿射线路径，将每个格的颜色覆写为该侧标记的颜色，直到遇到阻挡像素（栗(9)）或到达菱形内部的对侧边界为止。阻挡像素本身不被覆写。
6. 若多条射线经过同一格，后处理的射线覆写先处理的。处理顺序为：上侧标记从左到右、右侧标记从上到下、下侧标记从右到左、左侧标记从下到上（顺时针遍历）。
7. 菱形框、对角线标记、侧标记本身在输出中均保留不变。

**关键洞察**：菱形内部的最终颜色是两套独立逻辑的叠加结果——同心带提供空间分层底色，射线提供方向性覆写，阻挡像素同时限制两者（不被同心带覆盖，也截断射线），三重约束交织产生只靠单一规则无法解释的复杂图案。

## 新题 8：朝向标记控制图案迁移方向与边距映射

**组合逻辑**：[朝向决定方向](创新：朝向不决定射线方向而决定迁移维度) → [图案迁移 + 边距保持迁移](创新：迁移方向由外部朝向标记控制) → [行覆盖列/冲突优先级](创新：多方向迁移的叠加规则)

**来源原语**：朝向决定方向、微型标记(9344f635)；图案迁移、纯色矩形、带标记矩形、边距保持迁移、行范围重叠(57edb29d)；行覆盖列、冲突优先级(9344f635)；裁剪(57edb29d)

**依赖链**：朝向标记的水平/垂直决定迁移是沿行还是沿列进行 → 带标记矩形的标记图案按对应维度的边距保持规则迁移到目标矩形 → 当行迁移和列迁移在同一格冲突时，行迁移覆盖列迁移。朝向检测是迁移方向的唯一信息源；边距保持是迁移算法的核心；冲突规则使多源迁移的输出唯一确定。

检测每个带标记矩形旁的双像素朝向标记（水平或垂直），据此决定将该矩形的标记图案沿行方向还是列方向迁移到唯一的纯色目标矩形中，行迁移在冲突处覆盖列迁移。

**输入结构**：
- 网格约 12x18，黑(0)背景。
- 2~3 个彩色实心矩形（高、宽各 3~7），颜色互不相同，取自蓝(1)、红(2)、绿(3)。矩形内部包含若干灰(5)标记像素，形成边距相关的图案（如距顶边 1 格、距左边 2 格处有灰(5)像素）。这些为"带标记矩形"。
- 恰好 1 个纯色矩形（黄(4)），内部无灰(5)标记，高和宽均 >= 所有带标记矩形的对应维度。此为"目标矩形"。
- 每个带标记矩形的外侧紧邻一个同色双像素标记（domino），由 2 个同色像素组成。水平排列的 domino（两像素同行相邻列）表示"行迁移"；垂直排列的 domino（两像素同列相邻行）表示"列迁移"。domino 颜色与其所属带标记矩形颜色相同。domino 不与矩形重叠，位于矩形边界框外侧 4-连通相邻的位置。
- 每个带标记矩形与目标矩形在至少一个维度上有范围重叠：行迁移矩形与目标矩形的行范围重叠；列迁移矩形与目标矩形的列范围重叠。
- 生成约束：带标记矩形之间的标记图案经迁移后在目标矩形内不产生全面冲突（至少有部分格无冲突）。

**规则**：
1. 识别目标矩形 T（唯一不含灰(5)标记的矩形）。裁剪 T 作为输出画布，初始填充 T 的底色黄(4)。
2. 对每个带标记矩形 R，检测其旁边的 domino 朝向：
   - 水平 domino → R 的灰(5)标记图案沿**行方向**迁移到 T。迁移规则：对 R 中的每个灰(5)像素，保持其距 R 顶边和底边的距离不变，将其映射到 T 中行范围重叠部分的相同边距位置。灰(5)像素的列位置按距 R 左边的比例映射到 T 的列范围（取最近整数，从左边开始计）。
   - 垂直 domino → R 的灰(5)标记图案沿**列方向**迁移到 T。迁移规则：保持灰(5)像素距 R 左边和右边的距离不变，映射到 T 中列范围重叠部分的相同边距位置。行位置按距 R 顶边的比例映射到 T 的行范围。
3. 将所有迁移结果绘制到输出画布上：先绘制所有列迁移（垂直 domino）的灰(5)像素，再绘制所有行迁移（水平 domino）的灰(5)像素。行迁移的像素覆盖列迁移的像素。
4. 输出为填充后的目标矩形（黄(4)底色 + 灰(5)标记）。

**关键洞察**：同样的标记图案，因 domino 的水平或垂直朝向不同，被投射到目标矩形的不同维度上——朝向标记不控制"画一条线的方向"（源题用法），而是控制"在哪个维度上保持距离不变、在哪个维度上做比例映射"，从根本上改变了图案的空间展开方式。
