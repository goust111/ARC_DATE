## 新题 1：螺旋护盾与十字擦除

**组合逻辑**：[螺旋绘制](创新：螺旋路径充当保护掩码而非绘图结果) + [十字擦除](已有) + [遇障碍停止](已有)

**来源原语**：螺旋绘制、种子像素、障碍像素、遇障碍停止（e5c44e8f）；十字擦除、标记块、保护像素、十字区域、特定色像素豁免（319f2597）

**依赖链**：螺旋绘制在网格上产生红(2)路径 → 十字擦除清除标记块所定义的行列 → 但螺旋路径上的红(2)像素被豁免 → 螺旋的到达范围（受障碍限制）决定了十字区域中哪些像素幸存

一句话总结：从种子出发画一条被障碍截断的螺旋红线，然后以 2x2 标记块执行十字擦除，红色螺旋像素在擦除中幸存。

**输入结构**：约 15x15 的网格，背景由多种颜色随机填充（蓝(1)、绿(3)、黄(4)、橙(7)等混合），无大面积空白。网格中恰好有一个 2x2 的黑(0)标记块。另有一个红(2)种子像素，位于标记块的十字区域之外。网格上散布 3-5 个灰(5)单像素障碍。生成约束：种子像素不在标记块的两行或两列上；障碍像素不与标记块或种子重合；至少有一段螺旋路径穿越十字区域。

**规则**：
1. 从红(2)种子像素出发，按方向序列（上、右、下、左循环）、步长序列（2, 2, 4, 4, 6, 6, ...）追踪方形螺旋。将螺旋经过的网格内每个非灰(5)像素重涂为红(2)；越界步数照常计数但不绘制；若下一个网格内的螺旋单元是灰(5)障碍，则在绘制该单元之前停止螺旋。
2. 确定 2x2 黑(0)标记块占据的两行和两列，形成十字区域。
3. 将十字区域内每个非红(2)的像素重涂为黑(0)。红(2)像素（无论是原始的还是螺旋绘制的）保持不变。
4. 十字区域外的所有像素保持不变（包括灰(5)障碍和螺旋绘制的红(2)像素）。

**关键洞察**：螺旋不是装饰性绘图——它是十字擦除的防护机制。障碍截断螺旋的位置决定了十字区域中哪些像素被保护、哪些被擦除。移动一个障碍就会改变幸存像素的分布，这一因果关系需要对比多个示例才能归纳。

## 新题 2：面积计数决定周期延伸频率

**组合逻辑**：[计数](创新：像素面积转化为周期参数) + [拉直](创新：不规则形状归一化为色条) + [周期延伸](已有) + [近者优先](已有)

**来源原语**：计数、拉直、前景掩码、保留颜色与面积（dce56571）；周期延伸、分隔列、色条、长度即周期、近者优先（1ae2feb7）

**依赖链**：不规则前景区域的像素计数 → 决定拉直后色条的长度 → 色条长度成为周期延伸的周期 → 距分隔列的远近决定绘制优先级

一句话总结：将分隔列左侧的不规则色块按面积拉直为色条，然后以色条长度为周期向右侧延伸，近者优先绘制。

**输入结构**：约 12x22 的网格，黑(0)背景。一条纵贯全高的灰(5)单像素分隔列位于大约第 8 列。分隔列左侧有 3-4 个不规则单色前景区域（每个区域 3-7 个 4-连通像素，颜色各不相同，选自红(2)、绿(3)、蓝(1)、橙(7)）。每个区域的像素形态各异（含弯折、阶梯等非矩形形态），但每个区域完全位于某一行的范围内——即每个区域的包围框高度恰好为 1 行。分隔列右侧完全为黑(0)空白。不同区域占据不同的行，不在同一行重叠。生成约束：每个区域的像素数不超过分隔列右侧的列宽；各区域到分隔列的距离（包围框左边缘到分隔列的列差）互不相同。

**规则**：
1. 对分隔列左侧每个前景区域，计数其像素数 N，保留其颜色 C。
2. 将每个区域拉直为一个 1xN 的水平色条（颜色为 C），放置在该区域所在行、紧邻分隔列左侧（色条右端点在分隔列的左邻列）。原始不规则形态被擦除。
3. 以每个色条的长度 N 作为其周期，从分隔列右侧第一列开始，沿水平方向每隔 N 个像素绘制一个 1xN 色段（颜色为 C），直到超出网格右边界（末段可不完整，绘制到边界为止）。
4. 若多个色条的周期延伸在同一像素重叠，按色条到分隔列的距离排优先级：原始区域的包围框左边缘更靠近分隔列（列号差更小）的色条优先绘制，后到者不覆盖先到者。分隔列本身不变。

**关键洞察**：输入中不规则形状的具体形态无关紧要——仅其像素数量决定输出的周期频率。需要对比不同示例中像素数不同但形状类似的区域，才能归纳出"面积即周期"的规则。

## 新题 3：环路凸角计数通过图例编码填充色

**组合逻辑**：[环路追踪 + 分类涂色](已有) + [计数](创新：凸角数量作为排序键) + [填充](创新：填充色由图例按排名分配)

**来源原语**：环路追踪、分类涂色、闭合正交环路、弯折像素、多数转向为凸（15663ba9）；填充、封闭区域、调色板图例、边框色映射填充色（dbff022c）；计数（dce56571）

**依赖链**：追踪每个闭合环路并分类弯折像素 → 计数凸角数量 → 按凸角从少到多排序 → 从图例上到下逐个分配颜色 → 用分配的颜色填充对应环路内部

一句话总结：追踪并分类多个闭合环路的弯折像素，按凸角数量排序后，用网格边缘的竖向图例逐一分配颜色填充各环路的封闭内部。

**输入结构**：约 20x20 的黑(0)背景网格。3-4 个互不接触的绿(3)闭合正交环路（一像素宽，每个像素恰好有 2 个 4-连通前景邻居）。每个环路围成一块黑(0)封闭区域（不触及网格边界）。环路形状各异：有的是简单矩形轮廓（4 个凸角、0 个凹角），有的是 L 形或 U 形轮廓（凸角 5-8 个、凹角 1-4 个），有的有更复杂的凹陷。网格最右列有一个竖向单像素图例：K 个不同颜色的像素（选自红(2)、蓝(1)、黄(4)、橙(7)）从上到下排列，K 等于环路数量。生成约束：每个环路的凸角数量互不相同；图例像素之间无间隔，紧密排列。

**规则**：
1. 追踪每个绿(3)闭合环路。对每个弯折像素判定转向方向：该环路中出现次数较多的转向方向为凸角，出现次数较少的方向为凹角。将凸角重涂为黄(4)，凹角重涂为红(2)，直行像素保持绿(3)。
2. 计数每个环路中的凸角（黄(4)像素）数量。
3. 将所有环路按凸角数量从少到多排序。
4. 读取右侧竖向图例的颜色序列（从上到下）。将第 1 个图例颜色分配给凸角最少的环路，第 2 个图例颜色分配给凸角次少的环路，依此类推。
5. 用分配的颜色填充每个环路围成的封闭黑(0)区域（环路边框本身保留步骤 1 的分类涂色结果）。
6. 擦除右侧图例（重涂为黑(0)）。

**关键洞察**：图例颜色的上下顺序不对应环路的空间位置（如从上到下或从左到右），而对应凸角数量的排名。只有在多个示例中观察到同一空间位置的环路因凸角数量不同而获得不同填充色，才能归纳出这一映射规则。

## 新题 4：面板叠加碰撞点成为射线起点

**组合逻辑**：[透明叠加](创新：碰撞点不是错误而是功能元素) + [射线延伸](创新：射线从叠加产生的碰撞标记出发) + [重涂色](已有)

**来源原语**：透明叠加、分隔行、等高面板、前景不冲突（e98196ab）；射线延伸（cad67732）；重涂色（c8f0f002）

**依赖链**：两个面板透明叠加 → 前景碰撞点标记为栗(9) → 从碰撞点向四方向射线延伸 → 射线遇到非背景像素停止 → 射线路径重涂为栗(9)

一句话总结：删除分隔行并叠加两个面板，将前景碰撞点标记为栗色并向四方向射出射线直到遇障碍。

**输入结构**：约 11x15 的网格，黑(0)背景。一条蓝(1)水平分隔行横贯全宽，将网格分为上下两个等高面板（各约 5x15）。上面板：4-6 个单色前景像素，颜色选自红(2)、绿(3)、黄(4)，散布于不同位置。下面板：4-6 个单色前景像素，颜色同样选自红(2)、绿(3)、黄(4)，散布于不同位置。两面板中大部分前景像素在局部坐标上不重合，但恰好有 1-2 对像素在同一局部坐标上碰撞（即上面板的第 r 行第 c 列与下面板的第 r 行第 c 列都是前景像素）。生成约束：碰撞点的两个前景像素颜色不同；非碰撞前景像素在叠加后互不遮挡。

**规则**：
1. 删除蓝(1)分隔行。
2. 将下面板按局部行列对齐叠加到上面板上。对每个像素位置：
   - 若只有一个面板有前景像素，保留该前景像素及其颜色。
   - 若两个面板在同一局部坐标均有前景像素（碰撞），将该位置重涂为栗(9)。
   - 若两个面板均为背景，保持黑(0)。
3. 从每个栗(9)碰撞标记出发，沿上、下、左、右四个方向延伸射线。射线沿直线逐像素前进，将经过的黑(0)背景像素重涂为栗(9)。射线在遇到非背景像素（任何非黑(0)的像素，包括其他碰撞标记或保留的前景像素）或网格边界时停止，停止点像素不变。
4. 非碰撞的前景像素保持其原色不变。

**关键洞察**：叠加不是简单的合并——碰撞点被重新定义为射线发射源。碰撞的位置和数量由两个面板的前景布局共同决定，而射线的长度则取决于叠加后的全局前景分布。两步操作形成紧密耦合：叠加创造碰撞标记，射线利用叠加后的空间布局来确定传播范围。

## 新题 5：调色板双重编码——颜色映射与操作类型选择

**组合逻辑**：[填充](创新：由调色板条件性触发) + [标注中心](创新：由调色板条件性触发) + [解码](创新：从颜色一致性推断操作类型)

**来源原语**：填充、空心精灵体、封闭区域、调色板图例、边框色映射填充色（dbff022c）；标注中心、实心正方形、奇边长才标注（22806e14）；解码、编码映射（eee78d87）

**依赖链**：读取调色板图例获取边框色到结果色映射 → 判断结果色与边框色是否相同 → 相同：仅在精灵体中心标注一个结果色像素 → 不同：用结果色填充精灵体全部内部 → 擦除调色板

一句话总结：用调色板映射空心方形精灵体的边框色到结果色；若结果色与边框色不同则填满内部，若相同则仅标注中心像素。

**输入结构**：约 17x17 的黑(0)背景网格。4 个空心正方形精灵体（边长为奇数：5x5 或 7x7），每个的边框颜色不同，选自蓝(1)、绿(3)、橙(7)、黄(4)。每个精灵体内部完全为黑(0)。精灵体互不接触（包围框间至少间隔 1 像素）。网格顶部边缘有一个 2x4 调色板条（占据第 0-1 行、连续 4 列）：第一行为 4 个边框颜色（与 4 个精灵体的边框色一一对应，顺序可能与精灵体空间位置不同），第二行为 4 个对应的结果颜色。其中 2 个结果颜色与对应边框颜色相同，另 2 个不同（不同的结果颜色选自红(2)、灰(5)、品红(6)、青(8)等非边框色）。生成约束：精灵体边长均为奇数以保证中心像素唯一；调色板条不与任何精灵体重叠。

**规则**：
1. 读取调色板条第一行和第二行，建立边框色到结果色的映射。
2. 对每个空心精灵体，查找其边框颜色在映射中的结果颜色 R。
3. 若 R 与边框色不同：用 R 填充该精灵体的整个封闭内部（边框保持原色不变）。
4. 若 R 与边框色相同：仅将该精灵体中心像素（正方形几何中心的那一个黑(0)内部像素）涂为 R，其余内部保持黑(0)。
5. 擦除调色板条（全部重涂为黑(0)）。

**关键洞察**：调色板不只编码颜色映射——结果色与边框色的"一致/不一致"隐式编码了操作类型（全填充 vs 仅标注中心）。求解者必须对比多个示例中同一调色板下不同精灵体的处理差异，才能发现这条隐藏的条件分支规则。

## 新题 6：对称性筛选模板、像素计数配对目标

**组合逻辑**：[裁剪 + 镜像检测](创新：对称性作为角色分类器) + [计数](创新：像素数作为跨类配对键) + [印章覆盖](创新：形状来自模板、颜色和位置来自目标)

**来源原语**：镜像、对称、对称图案选取（d56f2372）；裁剪、包围框（d56f2372, bc1d5164）；印章覆盖、精灵体、颜色配对（3e980e27）；计数、保留颜色与面积（dce56571）

**依赖链**：裁剪所有精灵体并检测垂直镜像对称 → 对称精灵体为"模板"、非对称为"目标" → 按像素计数配对（相同像素数的模板与目标配对） → 将模板形状以目标颜色印章到目标包围框位置 → 擦除模板原位置

一句话总结：检测各精灵体的垂直对称性以分类模板和目标，按像素面积配对后，将模板形状以目标颜色印章到目标位置并擦除模板。

**输入结构**：约 20x20 的黑(0)背景网格。6 个小型单色精灵体（每个 4-连通、3-7 像素），颜色各不相同，选自蓝(1)、红(2)、绿(3)、黄(4)、橙(7)、品红(6)。其中 3 个精灵体的裁剪包围框具有垂直镜像对称性（掩码左右翻转后与原掩码完全相同），另 3 个不具有。像素计数配对：每个对称精灵体恰好有一个非对称精灵体与之像素数相同（如对称体 A 有 5 像素、非对称体 D 也有 5 像素），三对配对的像素数互不相同。精灵体互不相邻（包围框间至少间隔 2 像素）。生成约束：同一配对中的模板和目标包围框尺寸不必相同（像素数相同但形状不同）。

**规则**：
1. 裁剪每个精灵体到其最小包围框。
2. 检测每个裁剪结果是否满足垂直镜像对称（掩码左右翻转后与原掩码完全相同）。对称者标记为"模板"，非对称者标记为"目标"。
3. 计算每个精灵体的前景像素数。将像素数相同的一个模板与一个目标配对。
4. 对每一配对：在目标精灵体的包围框左上角位置，以目标精灵体的颜色印章模板的裁剪掩码（即用模板的形状、目标的颜色绘制）。若模板包围框大于目标包围框，超出部分正常绘制（不裁剪，仅在超出网格边界时丢弃）；若小于，未覆盖的原目标像素被擦除为黑(0)。
5. 擦除每个模板精灵体的原始位置（重涂为黑(0)）。
6. 未被配对的精灵体（如果存在）保持不变。

**关键洞察**：形状、颜色、位置三个属性分别来自不同来源——形状来自对称模板，颜色和位置来自非对称目标。配对键不是颜色也不是空间邻近，而是像素面积相等。求解者需要同时发现对称性分类规则和面积配对规则，两者缺一不可。

## 新题 7：像素面积奇偶决定裁剪后平铺的涂色方案

**组合逻辑**：[裁剪](已有) + [平铺](已有) + [重涂色](创新：由奇偶性决定涂色规则) + [奇偶性](创新：应用于面积而非边长)

**来源原语**：裁剪、角落图案、角落对应、最小包围框收缩（bc1d5164）；平铺、周期格点（eee78d87）；重涂色、逐像素替换（c8f0f002）；奇偶性（22806e14）

**依赖链**：裁剪四个角落图案 → 计算各图案前景像素面积 → 奇偶性判定 → 奇数面积涂为绿(3)、偶数面积涂为蓝(1) → 以裁剪包围框为单元平铺填满各象限 → 移除分隔十字

一句话总结：将四角的小图案按像素面积奇偶重涂为两种颜色之一，再以裁剪块为单元平铺各自的象限区域并移除中央分隔十字。

**输入结构**：约 13x13 的网格。一条 1 像素宽的灰(5)十字（一横行 + 一纵列交于网格中心）将网格分为四个 6x6 象限。每个象限中有一个小型红(2)前景图案（2-6 个 4-连通像素，形态各异——含弯折、阶梯等非矩形形态），背景为黑(0)。生成约束：每个图案的包围框不大于 3x3，以确保平铺时在 6x6 象限内至少重复 2 次；四个图案中至少一个像素数为奇数、至少一个为偶数。

**规则**：
1. 裁剪每个象限的红(2)前景图案到其最小包围框。
2. 计数每个裁剪图案中的前景像素数。
3. 若像素数为奇数，将该图案的红(2)前景重涂为绿(3)。若像素数为偶数，重涂为蓝(1)。
4. 以裁剪后的包围框为平铺单元，在对应的 6x6 象限内重复平铺该图案（从象限左上角开始，按行优先、列优先依次铺设；超出象限边界的部分裁切丢弃）。平铺时仅绘制前景像素，黑(0)背景像素不覆盖已有内容。
5. 删除灰(5)分隔十字，将四个 6x6 象限直接拼合生成 12x12 的输出网格。

**关键洞察**：所有输入图案均为红色，但输出中部分变绿、部分变蓝——颜色切换由像素面积的奇偶性决定而非图案形状或空间位置。不同示例中形状相似但像素数不同的图案会获得不同颜色，迫使求解者排除形状假设并归纳出面积奇偶规则。

## 新题 8：正交色条周期延伸在交叉点编织

**组合逻辑**：[周期延伸](创新：双方向同时延伸) + [编织填充](创新：仅在延伸交叉点生效而非预定义矩形区域) + [长度即周期](已有) + [奇偶交替颜色](创新：用行列坐标奇偶决定编织色)

**来源原语**：周期延伸、色条、长度即周期、近者优先（1ae2feb7）；编织填充、交叉条、奇偶交替颜色（f3e14006）

**依赖链**：水平色条向右周期延伸 + 垂直色条向下周期延伸 → 延伸产生的覆盖区域大部分不冲突 → 在水平与垂直延伸重叠的像素上按行列坐标奇偶做编织交替

一句话总结：将水平和垂直色条各自按自身长度为周期延伸至全网格，交叉点处以行列坐标奇偶交替选取水平或垂直色。

**输入结构**：约 16x16 的黑(0)背景网格。2-3 条水平色条位于网格左侧（每条占据一行的连续 2-4 个像素，颜色各不相同，选自红(2)、绿(3)、蓝(1)）。1-2 条垂直色条位于网格顶部（每条占据一列的连续 2-4 个像素，颜色各不相同，选自黄(4)、橙(7)、品红(6)）。水平色条和垂直色条的颜色互不重复。水平色条的最左像素紧贴网格左边缘（第 0 列）；垂直色条的最上像素紧贴网格上边缘（第 0 行）。水平色条与垂直色条不在同一像素上（即原始色条不重叠）。生成约束：至少有一条水平色条的行与一条垂直色条的列在延伸后产生交叉。

**规则**：
1. 对每条水平色条（颜色 C_h，长度 L_h，所在行 r_h），从色条右端下一像素起，沿水平方向以 L_h 为周期重复绘制：每隔 L_h 个黑(0)像素绘制一段长度 L_h 的 C_h 色段，直到超出网格右边界（末段可不完整）。原始色条像素保持不变。
2. 对每条垂直色条（颜色 C_v，长度 L_v，所在列 c_v），从色条下端下一像素起，沿垂直方向以 L_v 为周期重复绘制：每隔 L_v 个黑(0)像素绘制一段长度 L_v 的 C_v 色段，直到超出网格下边界（末段可不完整）。原始色条像素保持不变。
3. 若某像素仅被水平延伸覆盖（该像素位于某水平色条的周期延伸段上，且不在任何垂直延伸段上），涂为对应水平色 C_h。若仅被垂直延伸覆盖，涂为 C_v。
4. 若某像素同时被水平延伸（色 C_h）和垂直延伸（色 C_v）覆盖（交叉点），按该像素的行列坐标 (r, c) 判定：若 (r + c) 为偶数，涂为 C_h（水平色）；若 (r + c) 为奇数，涂为 C_v（垂直色）。行列坐标从 0 开始计数。
5. 原始色条像素（水平和垂直）始终保持原色不变，不被其他方向的延伸或编织规则覆盖。

**关键洞察**：交叉点的颜色不是简单的覆盖或混合——而是由行列坐标的奇偶性决定的棋盘式编织。只有观察到同一交叉区域内颜色交替排列且交替模式与空间坐标奇偶一致，才能归纳出编织规则。单独观察水平或垂直延伸无法预测交叉点行为。
