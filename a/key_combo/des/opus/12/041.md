## 新题 1：遮挡补全与嵌套层级填充

**组合逻辑**：[补全 complete](创新：从补全实心形状改为补全空心轮廓) + [洪泛填充 flood_fill](创新：填充色由嵌套深度决定，非由面积决定) + [计数 counting](创新：计数的是包围层数而非像素或分量数)

**来源原语**：补全 complete（参考题 52df9849），洪泛填充 flood_fill（参考题 c0f76784、782b5218），包围 enclosure（参考题 c0f76784），前景遮挡 foreground_occlusion（参考题 52df9849）

**依赖链**：补全空心矩形的被遮挡边段 → 完整轮廓划分出嵌套封闭区域 → 洪泛填充检测每个区域 → 对每个区域计算被多少层矩形包围 → 包围深度映射到填充颜色。删去补全步骤则无法确定轮廓边界；删去深度计数则无法选择颜色。

将重叠的空心彩色矩形轮廓补全后，按每个封闭区域被矩形包围的层数填入对应颜色。

**输入结构**：黑(0)背景网格，约 14x14。网格内有 3-4 个轴对齐的空心矩形轮廓（1 像素宽边框），每个矩形用不同颜色绘制，颜色取自 {蓝(1)、红(2)、绿(3)、黄(4)}。矩形之间存在部分重叠：在轮廓交叉处，一个矩形的颜色覆盖另一个的颜色（遮挡）。被遮挡的矩形有若干边段不可见（被前方矩形的轮廓像素覆盖），但每个矩形至少有两个可见角点或足够的可见边段来唯一确定其完整几何。生成约束：矩形可相互嵌套（一个完全在另一个内部），也可仅局部交叠；训练样例中嵌套深度 0、1、2 均需出现；至少一个矩形存在被遮挡的边段。

**规则**：
1. 对每个彩色矩形，根据其可见的角点和边段推断完整的轴对齐矩形轮廓，将被遮挡的边段像素恢复为该矩形自身的颜色（即补全操作覆盖遮挡色）。
2. 补全后，所有矩形轮廓完整可见。识别网格中每个最大 4-连通的黑(0)像素区域。
3. 对每个黑色区域，计算有多少个矩形完全包围它（即该区域完全位于该矩形的内部空间中）。此数值为该区域的「嵌套深度」。
4. 按嵌套深度填充颜色：深度 0（与网格边界相连，不被任何矩形包围）→ 保持黑(0)；深度 1 → 灰(5)；深度 2 → 橙(7)；深度 3 → 品红(6)；深度 4 → 青(8)。
5. 所有矩形轮廓像素（补全后的完整轮廓）保持原色不变。

**关键洞察**：遮挡顺序（哪个矩形的颜色画在前方）与嵌套顺序（哪个矩形在几何上位于另一个内部）是两个独立概念。一个矩形可以遮挡另一个但并不嵌套在其内部，反之亦然。必须先补全被遮挡段才能正确判定嵌套关系。需要对比多个示例才能区分「填充色取决于遮挡序」与「填充色取决于嵌套深度」这两个竞争假设。

## 新题 2：对称类型驱动射线发射方向

**组合逻辑**：[筛选 filter / 对称性检测](创新：对称类型不再作为二元筛选，而作为方向编码) + [射线延伸 ray_extension](创新：射线方向由精灵体的对称类型决定，而非从固定中心块向八方辐射)

**来源原语**：筛选 filter / 对称性筛选目标 symmetry_filter（参考题 72ca375d），射线延伸 ray_extension / 中心向外辐射 radiate_from_center（参考题 1d398264），精灵体 sprite（参考题 72ca375d），擦除 erase（参考题 782b5218）

**依赖链**：检测每个精灵体的对称类型 → 对称类型选择射线发射的方向轴 → 对称轴上的像素成为射线起点 → 沿选定方向延伸射线。删去对称检测则不知朝哪个方向发射；删去射线延伸则输出无变化。非对称精灵体被擦除，增加了「检测失败→擦除」的分支。

检测每个小精灵体的对称类型，以对称轴方向决定从该精灵体发射射线的方向，非对称精灵体被擦除。

**输入结构**：黑(0)背景网格，约 18x18。网格内有 3-5 个小型单色精灵体（各为不同颜色，4-连通，每个占 4-8 像素，形状不规则但可辨认对称性）。精灵体彼此充分分离（边界框不重叠，间距至少 2 像素）。每个精灵体恰好属于以下四类之一：仅有竖直轴对称、仅有水平轴对称、同时具有竖直和水平轴对称、无对称性。生成约束：训练样例中四类各至少出现一次。

**规则**：
1. 对每个精灵体，裁剪至其边界框并检测对称类型。
2. 仅有竖直轴对称的精灵体：从其竖直对称轴上的每个像素出发，向左和向右各发射一条水平射线，颜色为该精灵体的颜色。
3. 仅有水平轴对称的精灵体：从其水平对称轴上的每个像素出发，向上和向下各发射一条竖直射线，颜色为该精灵体的颜色。
4. 同时具有竖直和水平轴对称的精灵体：从其中心像素（两轴交点）出发，向四个基本方向（上、下、左、右）各发射一条射线。
5. 无对称性的精灵体：整体擦除为黑(0)，不发射任何射线。
6. 射线从起点沿指定方向逐像素延伸，直到遇到另一个精灵体的像素或到达网格边界时停止（不覆盖其他精灵体的像素，也不覆盖该精灵体自身的非轴像素）。
7. 若两条不同精灵体的射线交汇于同一像素，后处理的精灵体的射线覆盖先处理的。处理顺序：按精灵体边界框左上角坐标，从上到下、从左到右。
8. 所有未被擦除的精灵体自身的像素保持原色。

**关键洞察**：对称性不是一个「保留/丢弃」的二元筛选器（参考题 72ca375d 中的用法），而是一个方向编码器——对称轴本身成为射线的物理发射线。精灵体的几何结构同时编码了「是否发射」和「朝哪里发射」。需要多个示例才能区分「射线方向由精灵体颜色决定」与「射线方向由对称轴决定」。

## 新题 3：粗粒度压缩编码精灵镜像平铺指令

**组合逻辑**：[压缩 compress](创新：压缩结果从二元有/无扩展为三态——原样/镜像/空白) + [平铺 tiling](创新：非固定四象限铺展，由压缩模板控制) + [镜像 mirror](创新：是否镜像由压缩编码中的标记颜色决定)

**来源原语**：压缩 compress / 含标记涂标记色 marker_presence_color（参考题 e57337a4），平铺 tiling / 翻转形成对称铺展 mirror_symmetric_expand（参考题 62c24649），镜像 mirror（参考题 62c24649），标记像素 marker_pixel / 粗粒度块 coarse_block / 阵列排布 array_layout（参考题 e57337a4），精灵体 sprite（参考题 72ca375d）

**依赖链**：识别左半区精灵体并裁剪 → 压缩右半区为三态模板 → 模板每个单元决定放置原样精灵、镜像精灵还是空白 → 组装为平铺输出。删去压缩则不知道哪些位置放什么变体；删去镜像则无法生成正确的翻转版精灵体；删去裁剪则没有平铺内容。

将右半区的标记分布压缩为三态空间指令模板，根据模板用左半区的精灵体（原样或水平镜像）平铺生成输出。

**输入结构**：黑(0)背景网格，约 20x12。一条灰(5)竖直分隔线将网格分为左右两半。左半区包含一个小型单色精灵体（前景色如红(2)，3-5 像素宽、3-5 像素高，形状不对称以便区分原样与镜像）。右半区的尺寸在高和宽上均可被 3 整除，可视为 3x3 的等大矩形块阵列。每个块内部要么为空（全黑），要么散布有蓝(1)标记像素，要么散布有绿(3)标记像素。每个非空块内的标记只有一种颜色。生成约束：每个训练样例中至少有 2 个蓝标记块和 2 个绿标记块。

**规则**：
1. 从左半区裁剪精灵体至其边界框，得到高 h、宽 w 的精灵图案。
2. 对右半区进行 3x3 粗粒度压缩：对每个块，若块内含蓝(1)标记 → 编码为「原样」；含绿(3)标记 → 编码为「镜像」；无标记 → 编码为「空白」。
3. 构建 3x3 平铺输出网格（高 = 3h，宽 = 3w）：对 3x3 模板的每个单元 (i, j)：
   - 「原样」→ 在对应位置粘贴裁剪精灵体原样。
   - 「镜像」→ 在对应位置粘贴精灵体的水平镜像（左右翻转）。
   - 「空白」→ 在对应位置放置 h x w 的全黑矩形。
4. 输出即为组装完成的平铺网格。灰分隔线和右半区均不出现在输出中。

**关键洞察**：右半区不是一幅缩放后的图像（参考题 e57337a4 的压缩是「有/无」二元码），而是一套空间指令集——标记颜色编码变换类型（蓝=原样，绿=镜像），标记所在块的位置编码放置坐标。需要多个示例才能确认蓝→原样 vs. 绿→镜像的映射关系（单个示例中两个假设可能等价）。

## 新题 4：封闭区域面积奇偶决定描边邻域几何

**组合逻辑**：[描边 mark_neighbors](保留) + [洪泛填充 flood_fill](创新：从确定填充色改为确定邻域几何类型) + [计数 counting](创新：面积奇偶性作为几何选择器)

**来源原语**：描边 mark_neighbors / 对角邻接 diagonal_adjacency / 正交邻接 orthogonal_adjacency / 标记色选邻域几何 marker_color_selects_neighborhood（参考题 0ca9ddb6），洪泛填充 flood_fill / 封闭区域 enclosed_region / 包围 enclosure（参考题 c0f76784），计数 counting / 面积决定填充色 area_determines_fill_color（参考题 c0f76784）

**依赖链**：洪泛填充检测封闭区域 → 计算每个区域面积 → 面积奇偶性决定该区域内标记的描边几何（对角 vs. 正交） → 按选定几何执行描边。删去面积计算则不知道用哪种几何；删去描边则输出无变化；删去区域检测则无法量化面积。

在灰色轮廓划分的封闭区域内，根据区域面积的奇偶性选择标记像素的描边几何：奇数面积用对角，偶数面积用正交。

**输入结构**：黑(0)背景网格，约 15x15。网格内有若干灰(5)空心矩形轮廓（1 像素宽边框，互不重叠，互不嵌套）。每个矩形围出一个封闭内部区域。每个封闭区域内恰好有一个单像素彩色标记（颜色取自 {红(2)、蓝(1)、绿(3)}，不同区域的标记可以同色）。标记不紧邻灰轮廓（标记与最近的灰像素之间至少间隔 1 个黑像素）。生成约束：训练样例中奇面积和偶面积的区域各至少出现一个；至少一个训练样例中存在两个同色标记分别位于奇面积和偶面积的区域中（以排除「颜色决定几何」的假设）。

**规则**：
1. 识别每个最大 4-连通黑(0)像素区域。区分封闭区域（完全被灰轮廓包围，不与网格边界相连）和外部区域（与网格边界相连）。
2. 对每个封闭区域，计算其面积（不包含标记像素本身的黑像素数量）。
3. 对每个封闭区域内的标记像素：
   - 若所在区域面积为奇数：将标记的四个对角邻居标为黄(4)，前提是该邻居位于封闭区域内部（不在灰轮廓上，不在区域外）。
   - 若所在区域面积为偶数：将标记的四个正交（上下左右）邻居标为橙(7)，受同样的边界限制。
4. 灰轮廓像素、标记像素自身以及外部区域的黑像素均保持不变。

**关键洞察**：标记自身的颜色（红/蓝/绿）是干扰项——它对描边几何的选择毫无作用。真正的选择器是封闭区域的面积奇偶性，这是一个需要洪泛填充才能量化的全局属性。在参考题 0ca9ddb6 中，标记颜色直接选择几何（红→对角，蓝→正交）；此题将控制源从局部像素属性（颜色）反转为全局空间属性（面积），需要对比多个示例中同色标记在不同面积区域中的不同描边结果才能发现。

## 新题 5：连通分量面积排序生成柱状图后对称镜像

**组合逻辑**：[计数 counting](创新：计数对象从分量个数改为分量面积) + [排序 sorting](创新：排序依据从包围盒高度改为像素面积) + [镜像 mirror](创新：不再是整幅输入的四象限铺展，而是对排序后的柱状图做单次左右翻转拼接)

**来源原语**：计数 counting / 连通分量 connected_component（参考题 aaecdb9a），排序 sorting / 按高度排列 height_order（参考题 b7999b51），镜像 mirror / 翻转形成对称铺展 mirror_symmetric_expand（参考题 62c24649），柱状图 histogram_bar（参考题 b7999b51），基线对齐 baseline_aligned（参考题 aaecdb9a）

**依赖链**：识别每个单色连通分量 → 测量每个分量的像素面积 → 按面积降序排列 → 生成底部对齐的单列柱状图 → 将柱状图水平镜像拼接为对称山形。删去面积计数则不知柱高；删去排序则柱序错误；删去镜像则输出形状不对。

测量每个单色连通分量的面积，按面积从大到小排成柱状图，再将柱状图左右镜像拼接成对称的山形轮廓。

**输入结构**：黑(0)背景网格，约 12x15。网格内有若干单色 4-连通前景对象，每个对象为一种颜色（取自 {蓝(1)、红(2)、绿(3)、黄(4)、青(8)}），每种颜色仅出现一次（即一种颜色对应一个连通分量）。各对象形状不规则（非矩形，3-8 像素不等），面积互不相同。生成约束：至少 3 种颜色的对象；面积范围 2-8；至少一个训练样例中颜色编号顺序与面积排序不一致（以排除「按颜色编号排序」的假设）。

**规则**：
1. 对输入中每种前景颜色，识别其 4-连通分量并计算像素面积。
2. 按面积从大到小排序。面积相同时（生成约束保证不出现，但为完备性说明）：按颜色在输入中最上方像素的行号升序排列。
3. 构建柱状图：共 N 列（N 为颜色种数），每列 1 像素宽；柱高等于对应颜色的面积；以对应颜色着色；所有柱底部对齐于网格最底行。柱状图的网格高度等于最大面积值。
4. 将柱状图水平镜像（左右翻转），紧贴拼接到原柱状图的右侧。输出网格宽度 = 2N，高度 = 最大面积。
5. 输出中柱形区域以外的像素为黑(0)。

**关键洞察**：镜像拼接将单调递减的柱状图变成了一个竖直对称的「山形」轮廓。山峰（中央两列）始终是面积最大分量的颜色。这个对称性是排序+镜像的涌现结果——不是输入的固有属性。需要多个示例才能看出列顺序按面积排而非按颜色编号或空间位置排。

## 新题 6：方向标记滑动穿越房间网格重涂色

**组合逻辑**：[滑动 slide](创新：标记不是滑向固定目标物，而是沿指示方向穿越整个房间网格) + [洪泛填充 flood_fill](创新：从分区后选边填充改为标记轨迹选中房间填充) + [重涂色 recolor](创新：重涂色的范围由滑动轨迹与房间网格的交集决定)

**输入结构**：黑(0)背景网格，约 15x15。灰(5)水平线和竖直线将网格分隔为矩形房间阵列（3x3 或 3x4 等均可，灰线宽 1 像素）。每个房间是一个被灰线完全围合的黑色矩形区域。部分房间内包含一个由两个同色像素组成的 1x2 或 2x1 多米诺骨牌状标记（颜色取自 {红(2)、蓝(1)、绿(3)、黄(4)}，不同标记颜色不同）。多米诺骨牌的两个像素相邻：第一个像素（在该颜色中行号更小的，行号相同则列号更小的）为「锚点」，第二个像素的位置相对于锚点指示滑动方向（右方 → 向右滑动，下方 → 向下滑动，左方 → 向左滑动，上方 → 向上滑动）。生成约束：至少两个标记的滑动轨迹经过同一个房间（以展示冲突解决）；标记数量 2-4 个。

**规则**：
1. 对每个标记，确定其锚点和滑动方向。
2. 从标记所在房间开始，沿滑动方向逐个房间前进（穿越灰色分隔线），直到到达网格边界外侧的最后一个房间。标记经过的所有房间（包括起始房间）构成其「轨迹房间集合」。
3. 对轨迹房间集合中的每个房间，将其内部所有非灰像素（包括原有的标记像素）重涂为该标记的颜色。
4. 若两个标记的轨迹经过同一房间，该房间涂为锚点距该房间更近的标记的颜色（曼哈顿距离，以锚点像素到房间中心点计算）。若距离相等，涂为处理顺序靠后的标记的颜色。处理顺序：按标记锚点位置从上到下、从左到右。
5. 不在任何标记轨迹中的房间保持黑(0)。
6. 所有灰(5)分隔线像素保持不变。

**关键洞察**：多米诺方向不是指向某个目标对象（参考题 d6e50e54 中标记指向矩形），而是定义了一条扫描线穿越房间网格。标记轨迹与房间分区的交集决定了重涂范围——这是滑动操作与空间分区的结构性耦合，两者在源题中各自独立。

**规则**：
1. 将四个象限分别提取为数组，逐像素比较。找出恰好出现一次的象限图案（异常象限），裁剪它得到高 h、宽 w 的精灵图案。
2. 构建大小为 (h + 2w) x (h + 2w) 的全黑输出网格，进行四方环形拼接：

## 新题 8：最短路径长度阈值决定端点重涂色

**组合逻辑**：[寻路 pathfinding](创新：路径长度被量化并用于分类决策，而非仅确定路径像素) + [重涂色 recolor](创新：重涂色的目标颜色不由接触或固有属性决定，而由路径长度阈值决定) + [计数 counting](创新：计数路径步数作为中间判据)

**依赖链**：识别同色端点对 → 在迷宫中寻找最短路径 → 计算路径长度 → 长度与阈值比较 → 比较结果决定端点和路径的重涂颜色。删去寻路则无法确定长度；删去计数/比较则不知选哪种颜色；删去重涂则输出无变化。

在迷宫中找到同色端点对之间的最短路径，路径长度是否超过阈值决定了端点和路径被涂成哪种颜色。

**输入结构**：黑(0)背景网格，约 15x15。灰(5)像素构成迷宫墙壁（连通的灰色结构形成通道和死胡同）。迷宫中有 2-3 对同色端点：每对由两个相同颜色的单像素标记组成（如两个红(2)像素为一对、两个蓝(1)像素为一对、两个绿(3)像素为一对）。所有非墙壁、非端点像素为黑(0)（可通行）。生成约束：每对端点之间存在唯一最短 4-连通路径（无并列最短路径）；不同对的路径互不共享像素；训练样例中至少一对路径长度 <= 5 且至少一对 > 5。

**规则**：
1. 对每对同色端点，在可通行像素（黑色像素）中寻找 4-连通最短路径。
2. 计算路径长度（路径上的可通行像素数，不含两个端点本身）。
3. 若路径长度 <= 5：将两个端点和整条路径的所有像素涂为黄(4)。
4. 若路径长度 > 5：将两个端点和整条路径的所有像素涂为橙(7)。
5. 端点原有颜色被覆盖。灰色墙壁像素和不在任何路径上的黑色像素保持不变。

**关键洞察**：端点的原始颜色仅作为配对标识——在输出中完全被丢弃。输出颜色由路径长度这一全局迷宫属性决定。阈值 5 是一个隐含参数，必须通过比较多个示例中不同长度路径的输出颜色才能归纳得出（单个示例可能支持多种阈值假设）。

## 新题 9：曼哈顿连线构造封闭区域后按边界段数填充

**组合逻辑**：[连线 line_drawing](创新：连线不是最终视觉输出，而是中间构造步骤，用于创建空间分区) + [洪泛填充 flood_fill](创新：填充对象不是预先存在的封闭区域，而是由连线步骤动态创建的) + [计数 counting](创新：计数对象从面积/像素数改为边界线段条数)

**来源原语**：连线 line_drawing / 先横后纵路由 horizontal_then_vertical / 经由中间点路由 routed_via_waypoint（参考题 0e671a1a），洪泛填充 flood_fill / 封闭区域 enclosed_region / 标记在封闭区域内 marker_in_enclosed_region（参考题 4b6b68e5），计数 counting（参考题 aaecdb9a）

**依赖链**：同色边缘标记配对 → 曼哈顿路由连线 → 线网在网格中划分出封闭区域 → 对每个封闭区域计数其边界上有多少条独立线段 → 线段数映射到填充颜色。删去连线则无封闭区域产生；删去计数则不知填什么颜色；删去填充则输出只有线条。

在网格边缘放置同色标记对，用水平优先的曼哈顿路由连线，线网围合出的封闭区域按边界线段数量填色。

**输入结构**：黑(0)背景网格，约 14x14。网格的四条边界行/列上放置若干单像素彩色标记。标记成对出现：同色的两个标记位于不同的边界上（如一个在顶边一个在底边，或一个在左边一个在右边）。颜色取自 {红(2)、蓝(1)、绿(3)、黄(4)}，共 2-4 对。生成约束：标记位置经过选择，使得连线后至少产生 2 个不与网格边界相连的封闭区域；不同封闭区域的边界线段数互不全相同（至少两种不同的段数）。

**规则**：
1. 对每对同色标记，用灰(5)绘制曼哈顿路由连线：从「主标记」（行号较小者；行号相同则列号较小者）出发，先水平移动到目标标记所在列，再竖直移动到目标标记所在行。标记像素本身也变为灰(5)。
2. 若两条不同对的连线在某像素交叉，该像素仍为灰(5)（颜色不冲突）。
3. 连线完成后，识别每个最大 4-连通黑(0)像素区域。
4. 对每个不与网格边界相连的封闭黑色区域：沿其边界统计有多少条独立灰色线段接触它。一条「独立线段」定义为：沿封闭区域边界，一段连续的水平或竖直灰色像素序列（方向改变或被另一区域的边界打断则算新的一段）。
5. 按边界线段数填充颜色：恰好 2 段 → 红(2)；恰好 3 段 → 绿(3)；恰好 4 段 → 黄(4)；5 段及以上 → 蓝(1)。
6. 与网格边界相连的区域保持黑(0)。所有灰色线条像素保持灰(5)。

**关键洞察**：连线步骤不是最终装饰——它是空间拓扑的构造器。封闭区域在输入中并不存在，完全由连线创造。边界线段数量（而非面积或连通性）决定填充颜色，需要仔细区分「一条折线算几段」。需要多个示例才能确认计数规则（段数 vs. 总边界长度 vs. 面积）。

## 新题 10：邻域连通度决定像素放大图案

**组合逻辑**：[像素放大 pixel_upscaling](创新：放大后的 2x2 图案不再统一替换，而是因像素在原图中的局部连通度而异) + [图案替换 pattern_substitution](创新：替换模板从固定一种变为按连通度分档的多种) + [描边 mark_neighbors / 计数 counting](创新：邻域计数不用于描边输出，而用于选择放大图案)

**来源原语**：像素放大 pixel_upscaling / 图案替换 pattern_substitution / 按颜色条件分支 color_conditional_branch（参考题 2072aba6），描边 mark_neighbors / 标记色选邻域几何 marker_color_selects_neighborhood / 正交邻接 orthogonal_adjacency（参考题 0ca9ddb6），计数 counting（参考题 aaecdb9a）

**依赖链**：对每个前景像素统计其 4-连通前景邻居数 → 邻居数选择 2x2 替换图案 → 每个像素按选定图案放大为 2x2 块。删去邻域计数则不知道用哪种图案；删去像素放大则输出尺寸不对。两个操作通过邻域计数紧密耦合：同一颜色的像素在原图中位于不同位置时可能得到不同的 2x2 图案。

每个前景像素根据其在原图中的 4-连通前景邻居数量，被放大为不同的 2x2 图案——局部连通度编码为放大后的视觉纹理。

**输入结构**：黑(0)背景网格，约 8x8。网格内有由单一前景色（如青(8)）绘制的一个或多个 4-连通形状。形状结构丰富，包含端点（1 邻居）、走廊段（2 邻居）、T 形交叉（3 邻居）和内部填充像素（4 邻居）。生成约束：训练样例中 0-1、2、3、4 邻居的前景像素均至少出现一个。

**规则**：
1. 对输入中每个像素，统计其在原始网格中的 4-连通前景邻居数量（0 到 4）。
2. 将整幅输入放大为 2 倍（输出高 = 2 x 输入高，输出宽 = 2 x 输入宽）。每个输入像素对应输出中的一个 2x2 块：
   - 黑(0)像素：无论邻居数如何，2x2 块全为黑(0)。
   - 前景像素且邻居数为 0 或 1（孤立点或端点）：2x2 块全为前景色（纯色填充）。
   - 前景像素且邻居数恰好为 2（走廊段）：2x2 块为 [[前景色, 红(2)], [红(2), 前景色]]（棋盘格）。
   - 前景像素且邻居数恰好为 3（T 形交叉点）：2x2 块为 [[前景色, 黄(4)], [前景色, 前景色]]（右上角染黄）。
   - 前景像素且邻居数恰好为 4（内部像素）：2x2 块为 [[黄(4), 红(2)], [红(2), 黄(4)]]（双色棋盘格）。
3. 输出为组装完成的放大网格。

**关键洞察**：这不是参考题 2072aba6 的均匀像素放大（每个灰像素得到相同的棋盘格替换），而是上下文敏感的放大——同一颜色的像素因局部连通环境不同而获得不同的 2x2 图案。放大后的输出是原始形状的「连通度密度图」。需要对比多个示例中不同位置的前景像素及其 2x2 结果才能逆推出邻居数→图案的映射表。
