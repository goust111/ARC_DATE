## 新题 1：行列标签门控方向滑动

**组合逻辑**：[填充/行列交叉](创新：标签匹配不再填充单元格，而是充当精灵运动的条件门) + [滑动/颜色编码方向](已有) → 匹配色同时编码滑动方向（新结构关系）

**来源原语**：填充/fill、行标签/row_label、列标签/column_label、行列交叉/row_col_intersection、标签同色时填充/labels_match_fill（来自 a406ac07）；滑动/slide、空心矩形/hollow_rect、网格边界/grid_edge、颜色编码方向/color_coded_dir、颜色决定方向/color_determines_dir（来自 f3e62deb）

**依赖链**：行列标签的匹配结果决定哪些精灵被激活 → 匹配到的标签颜色同时编码了运动方向 → 精灵按该方向滑至内区边界。删去标签匹配则无法区分哪些精灵该动、哪些该留；删去颜色-方向映射则不知往哪滑。

在行列标签交叉处判断匹配，匹配色同时编码精灵的滑动方向，将精灵推至对应网格边界。

**输入结构**：约 12x12 的网格，背景黑(0)。最右列（列 W-1）为行标签列，每格为绿(3)、黄(4)、品红(6)、青(8) 之一或黑(0)（无标签）。最底行（行 H-1）为列标签行，规则相同。内区（行 0 至 H-2、列 0 至 W-2）散布 2-4 个 3x3 空心方框（8 像素环，中心无色），每个方框颜色各不相同，取自红(2)、蓝(1)、橙(7)、栗(9)。所有方框包围盒完全落在内区内，彼此不重叠。生成约束：每个方框中心 (r, c) 所在行和列的标签均非黑。

**规则**：
1. 对每个 3x3 空心方框，定位其中心格 (r, c)。
2. 读取行标签 L_r = grid[r][W-1] 和列标签 L_c = grid[H-1][c]。
3. 若 L_r == L_c 且该色属于 {绿(3), 黄(4), 品红(6), 青(8)}，则方框被"激活"，按该匹配色编码的方向滑动：绿(3) → 向左，黄(4) → 向下，品红(6) → 向上，青(8) → 向右。
4. 擦除被激活方框的原位置像素，将该方框沿指定方向平移，直到其包围盒与内区边界齐平（行 0、行 H-2、列 0 或列 W-2）。
5. 若两个方框向同一边界滑动导致重叠，则原本距目标边界更近的方框先到达边界，另一个停在其旁（包围盒相邻、间隔 0 像素但不重叠）。若原距相等，行索引更小（再列索引更小）的优先。
6. 若 L_r != L_c 或任一为黑(0)，方框保持原位不动。
7. 标签行和标签列保持不变。

**关键洞察**：行列标签交叉处的颜色匹配在源题 a406ac07 中用于填充单元格，在本题中被重新定义为精灵运动的条件开关，而匹配到的颜色本身又编码了运动方向——一次匹配同时回答"是否移动"和"往哪移动"两个问题，必须对比移动与未移动的精灵才能归纳出标签匹配这一隐蔽条件。

## 新题 2：对角连线划分投票腔室

**组合逻辑**：[计数/counting](创新：像素出现频次决定其语义角色) → [连线/draw_line + 同色配对/same_color_pairing](已有) → [填充/fill + 正交邻接/orthogonal_adjacency + 邻接多数决/adjacent_majority_vote](已有，但作用于由对角线动态生成的拓扑)

**来源原语**：计数/counting（来自 5582e5ca）；连线/draw_line、端点对/endpoint_pair、同色配对/same_color_pairing、对角线段连接/diagonal_segment_connect（来自 1f876c06）；填充/fill、连通腔室/connected_chamber、标记像素/marker_pixel、正交邻接/orthogonal_adjacency、邻接多数决/adjacent_majority_vote（来自 7c8af763）

**依赖链**：像素频次分类决定哪些像素是线端点、哪些是投票标记 → 对角连线生成新的空间分区 → 分区拓扑决定每个腔室的邻接标记集 → 多数决填充腔室。删去频次分类则无法区分端点与标记；删去连线则无腔室可填；删去投票则腔室无色。

统计每种颜色的像素数量以区分线端点与投票标记，连接端点对划分空间，再按多数决填充每个划分出的腔室。

**输入结构**：约 15x15 的网格，背景黑(0)。包含 3-4 种颜色各出现恰好两次的像素（端点对），每对的两个像素满足 |dr| == |dc|（在同一 45 度对角线上）。另有 3-5 种颜色各出现恰好一次的像素（投票标记），颜色均与端点对不同。所有有色像素彼此 4-不相邻（互相孤立）。生成约束：所有端点对连线后，连线与网格边界共同将背景划分为若干 4-连通腔室，每个腔室至少正交邻接一个投票标记。

**规则**：
1. **频次分类**：对每种非背景色统计像素个数。出现 2 次的为"线色"，出现 1 次的为"标记色"。
2. **画对角线**：对每种线色，在其两个像素之间画出 45 度对角线段，沿途所有格子（含端点）涂为该线色（同参考题 1f876c06）。
3. **画线顺序**：按各线色第一个像素的光栅序（先行后列，从小到大）依次绘制。若两条对角线在同一格交叉，后绘制的颜色覆盖先绘制的。
4. **识别腔室**：所有对角线绘制完成后，找出网格中所有极大的 4-连通黑(0) 背景区域，每个为一个"腔室"。
5. **投票填充**：对每个腔室，收集所有与该腔室的边界（包括对角线像素和网格边缘）正交邻接的标记像素。以出现最多的标记颜色填充整个腔室。若平票，取行索引最小（再列索引最小）的标记像素的颜色。
6. 标记像素和对角线像素保持不变（不被腔室填充覆盖）。无邻接标记的腔室保持黑(0)。

**关键洞察**：同一批初始像素既包含结构信息（线端点）又包含语义信息（投票标记），两者的区分标准——颜色的出现次数是 2 还是 1——从未被显式说明，必须通过对比多个示例才能发现这一隐蔽分类规则。

## 新题 3：障碍分区下的形状模板互换

**组合逻辑**：[交换/swap + 跨障碍配对/cross_barrier_pair](创新：配对从标记像素扩展到精灵，配对依据从同行列改为同行列 + 同包围盒尺寸) + [图案替换/pattern_swap](创新：不是全局两色互换模板，而是仅对配对精灵进行形状互换、颜色锚定)

**来源原语**：交换/swap、障碍段/barrier_segment、跨障碍配对/cross_barrier_pair、同行列两侧各一/one_each_side（来自 1efba499）；图案替换/pattern_swap、精灵模板/sprite_template、边界框/bounding_box、同尺寸边界框/same_size_bounding_box、同步替换/simultaneous_replacement（来自 3391f8c0）

**依赖链**：障碍将网格分为两区 → 同行/列且同包围盒尺寸的跨区精灵被配对 → 配对精灵的形状模板互换但颜色锚定于原位 → 未配对精灵被擦除。删去障碍则无法定义"跨区配对"；删去模板互换则不知如何变换已配对的精灵。

以障碍为界按行列对齐配对精灵，配对双方交换形状模板但保留原位颜色，未配对者消失。

**输入结构**：约 14x14 的网格，背景黑(0)。一条灰(5) 障碍横贯网格——水平全宽或垂直全高（1 像素厚），将网格分为两半。两半中各有若干小型 4-连通单色精灵。非背景、非灰色仅出现两种颜色（记为色 A 和色 B）。色 A 的所有实例共享同一模板形状（包围盒内相对像素图案一致），色 B 同理，两种模板形状不同但包围盒尺寸相同（如均为 3x3）。两种颜色在障碍两侧均有分布。生成约束：对任一侧的任一精灵，对面一侧在同行/列（以包围盒首行或首列为准）上至多有一个另一颜色的精灵可供配对。

**规则**：
1. **识别障碍**：找到灰(5) 的最大连通分量。若该分量跨越网格全宽 → 水平障碍；跨越全高 → 垂直障碍。
2. **配对**：
   - 垂直障碍：对左侧每个精灵，找右侧包围盒首行相同的另一颜色精灵；若存在且双方包围盒尺寸一致，两者配对。
   - 水平障碍：同理，按包围盒首列匹配。
   - 每个精灵至多参与一组配对。
3. **同步替换**：先擦除所有已配对精灵的像素（全部清为背景），再逐对重绘：
   - 在精灵 A 的原包围盒位置，绘制色 B 的模板形状，但使用色 A 的颜色。
   - 在精灵 B 的原包围盒位置，绘制色 A 的模板形状，但使用色 B 的颜色。
   - 即：形状互换，颜色留在原地。
4. **未配对精灵**：擦除后不重绘，消失为背景。
5. 障碍保持不变。

**关键洞察**：形状穿越障碍"传递"到对侧，但颜色锚定在原位——精灵的几何身份与色彩身份被拆开重组。求解者容易误以为是精灵整体交换位置；需要对比精灵形状在障碍两侧的变化才能发现"形状换位、颜色不动"的真正规则。

## 新题 4：四象限壁叠加涌现腔室填充

**组合逻辑**：[透明叠加/transparent_overlay](创新：不再是掩码层叠渲染，而是墙像素的布尔并集生成新拓扑) + [填充/fill + 邻接多数决/adjacent_majority_vote](已有，但作用于叠加后涌现的腔室)

**来源原语**：透明叠加/transparent_overlay、象限掩码/quadrant_mask、层叠顺序/layer_stack、四象限折叠同画布/quadrants_fold_one（来自 75b8110e）；填充/fill、连通腔室/connected_chamber、分隔墙/separator_wall、标记像素/marker_pixel、正交邻接/orthogonal_adjacency、邻接多数决/adjacent_majority_vote（来自 7c8af763）

**依赖链**：四象限叠合时墙像素取并集 → 涌现出单象限中不存在的完整腔室结构 → 标记像素叠合后通过优先级决议确定位置 → 腔室按邻接标记的多数决填色。删去叠合则无完整腔室；删去填充则腔室无色；删去优先级规则则标记冲突时输出不确定。

将四个象限的墙壁结构叠合生成完整腔室，同时叠合标记像素，再按邻接多数决填充每个涌现的腔室。

**输入结构**：偶数尺寸网格（如 16x16），背景黑(0)，概念上分为四个等大的 NxN 象限（左上 TL、右上 TR、左下 BL、右下 BR，各 8x8）。每个象限内有若干灰(5) 墙像素构成不完整的屏障片段（任何单象限内的墙均不足以围成封闭腔室），以及 1-3 个彩色标记像素（取自红(2)、蓝(1)、绿(3)、黄(4)、橙(7)，不含灰或背景色）。生成约束：四象限墙叠合后恰好围成若干封闭 4-连通腔室，且每个腔室至少正交邻接一个叠合后的标记像素。

**规则**：
1. **折叠坐标映射**：输出画布为 NxN。对输出中每个格 (r, c)，对应四个输入格：TL=(r, c)、TR=(r, c+N)、BL=(r+N, c)、BR=(r+N, c+N)。
2. **墙叠合**：若四个对应输入格中任一为灰(5)，输出格即为灰(5) 墙。
3. **标记叠合**：收集四个对应输入格中所有非背景、非灰色的颜色。
   - 若仅一种颜色，输出格为该标记色。
   - 若多种颜色，按象限优先级取最高者的颜色：TL > TR > BL > BR。
   - 若无标记，输出格暂为背景。
4. **识别腔室**：在叠合后的 NxN 画布上，找出所有极大 4-连通背景区域，每个为一个腔室。
5. **多数决填充**：对每个腔室，收集所有与该腔室正交邻接的标记像素颜色。以出现次数最多的颜色填充整个腔室。平票时取行索引最小（再列索引最小）的标记像素的颜色。
6. 墙像素和标记像素在输出中保持不变。

**关键洞察**：任何单个象限都既没有足够的墙来围成腔室，也没有足够的标记来投票——腔室的空间结构和投票群体都是四象限叠合后的涌现属性，两者必须同步建立才能求解。

## 新题 5：矩形层深编码外推周期

**组合逻辑**：[循环填充/concentric_fill 的层深概念](创新：层深不再用于着色，而是编码时间参数) + [外推/extrapolate + 周期调度/periodic_schedule](已有，但周期来源从固定时间表变为几何属性) → 几何属性成为时间行为的编码器（新结构关系）

**来源原语**：循环填充/concentric_fill、实心矩形/solid_rectangle、同心层/concentric_layer、边距深度/edge_distance_depth（来自 516b51b7）；外推/extrapolate、面板序列/panel_sequence、模板面板/template_panel、周期调度/periodic_schedule、预测下一帧/predict_next_frame（来自 2ccd9fef）

**依赖链**：每个矩形的 min(宽,高) 定义其层深 → 层深决定该矩形在面板序列中每隔几帧才移动一次 → 根据可见帧中的位移量和周期推断下一帧位置。删去层深计算则无法确定各矩形的运动频率；删去外推则无法预测下一帧。

矩形的几何层深（min(宽,高)）编码其在面板动画中的运动周期——体积越大惯性越大——据此预测下一帧。

**输入结构**：约 7 行 x 25 列的宽网格，灰(5) 垂直分隔线将其等分为 5 个面板（索引 0-4），每个面板约 7 行 x 4 列。面板 0-3 各含 2-3 个不同颜色的实心矩形（如红(2) 的 1x3、蓝(1) 的 2x4、绿(3) 的 3x3），同一颜色在各面板中标识同一矩形。面板 4 为空白模板面板（仅背景色）。各矩形在不同面板中可能处于不同位置（平移），也可能位置不变。各矩形的包围盒尺寸在所有面板中保持恒定。生成约束：不同矩形的 min(宽, 高) 值互不相同；每个矩形至少在两个可见面板中发生过位移。

**规则**：
1. **计算层深**：对每种颜色的矩形，取其包围盒 min(宽, 高) 为层深 d。
2. **确定运动周期**：层深 d 的矩形仅在面板索引为 d 的倍数时发生位移（即面板 0, d, 2d, 3d, ...）。非活跃面板中该矩形保持前一活跃面板的位置不变。
3. **测量位移量**：观察该矩形在两个相邻活跃面板之间的位置差 (dr, dc)，该位移量恒定。
4. **预测面板 4**：
   - 若 4 mod d == 0，该面板为活跃面板，矩形从面板 3 的位置平移 (dr, dc)。
   - 若 4 mod d != 0，矩形保持其在最近一个活跃面板中的位置不变（该位置与面板 3 中的位置相同，因为非活跃面板不改变位置）。
5. **输出**：在模板面板区域（面板 4 的位置）绘制所有矩形的预测位置。超出面板边界的部分裁剪。

**关键洞察**：矩形越大（层深越高）运动越迟缓——几何体积编码了动画惯性。求解者必须先注意到不同矩形的运动频率不同，再通过对比矩形尺寸发现 min(宽,高) 恰好等于运动周期，这一几何-时间映射在任何单个面板中不可见，只有纵观全序列才能归纳。

## 新题 6：对称轨道约束下的轮廓逐行填充

**组合逻辑**：[填充/fill + 行内边界配对/row_boundary_pairing + 逐行跨度填充/row_span_fill](已有) ⊕ [对称补全/symmetry_completion + 对称轨道映射/symmetry_orbit_mapping](创新：对称单位从单像素扩展到整个轮廓形状) → 两种约束同时作用（非流水线）

**来源原语**：填充/fill、轮廓线/outline、封闭区域/enclosed_region、行内边界配对/row_boundary_pairing、逐行跨度填充/row_span_fill（来自 22168020）；对称补全/symmetry_completion、对称图案/symmetric_pattern、掩码像素/masked_pixel、对称轨道映射/symmetry_orbit_mapping（来自 47996f11）

**依赖链**：非掩码轮廓可直接逐行填充确定其颜色与形状 → 网格整体的对称轴必须从所有轮廓（含掩码与非掩码）的位置布局中推断 → 掩码轮廓的完整边界由其对称伙伴的非掩码轮廓镜像得到 → 镜像后的边界再行逐行填充。删去填充则无法确定非掩码轮廓的视觉效果；删去对称映射则掩码轮廓无法恢复。

可见轮廓逐行填充后，通过整体对称轴将可见轮廓镜像到被掩码遮蔽的位置，恢复完整图案。

**输入结构**：约 13x13 的网格（宽度为奇数，使垂直中心轴明确位于列 (W-1)/2），背景黑(0)。包含 4-6 个由斜向边界像素构成的轮廓形状（同参考题 22168020：每行恰好两个同色像素标记左右边界）。这些轮廓形状关于网格垂直中心轴成对对称排列——左侧的每个形状在右侧有一个镜像对应物。部分轮廓的边界像素为正常颜色（如蓝(1)、红(2)、绿(3)），称为"可见轮廓"；其余轮廓的边界像素被替换为品红(6)，称为"掩码轮廓"。每个掩码轮廓的对称伙伴均为可见轮廓，反之亦然。生成约束：可见轮廓与掩码轮廓数量相等；可见轮廓的颜色互不相同。

**规则**：
1. **填充可见轮廓**：对每个非品红(6) 轮廓，逐行处理其占据的每一行。在每行上找到该轮廓的左右两个边界像素，将它们之间（含端点）的所有格子涂为该轮廓的颜色。
2. **确定对称轴**：取网格的垂直中心列 c_axis = (W-1)/2。
3. **重建掩码轮廓**：对每个品红(6) 轮廓形状，找到其对称伙伴——将该掩码轮廓每个品红像素 (r, c) 关于 c_axis 做水平镜像得到 (r, W-1-c)，该位置应属于某个可见轮廓。该可见轮廓即为对称伙伴。
4. **填充掩码轮廓**：将对称伙伴的边界像素逐行水平镜像，得到掩码轮廓的真实边界。用伙伴的颜色替换品红像素并逐行填充掩码轮廓的内部。
5. **冲突处理**：若可见轮廓的填充区域与重建后的掩码轮廓的填充区域重叠，可见轮廓的颜色优先。
6. 背景中不属于任何轮廓的像素保持黑(0)。

**关键洞察**：品红像素在源题 47996f11 中遮蔽的是全局对称图案中的单个格子，在本题中遮蔽的是整个轮廓形状的边界——对称操作的粒度从像素级跃升到对象级。求解者需要先识别出品红构成的是完整轮廓而非散布掩码，再从全局布局推断对称轴，最后通过镜像恢复轮廓并填充。

## 新题 7：形状频次决定叠加渲染模式

**组合逻辑**：[排序/sort + 形状频次分组/shape_frequency_grouping + 旋转翻转不变/rotation_flip_invariant](创新：频次不再决定空间位置，而是决定渲染透明度) + [透明叠加/transparent_overlay + 层叠顺序/layer_stack](已有) → 频次成为渲染属性的控制参数（新结构关系，同时约束结构）

**来源原语**：排序/sorting、多色连通分量/multicolor_component、形状频次分组/shape_frequency_grouping、旋转翻转不变/rotation_flip_invariant、共享与唯一形状/shared_vs_unique_shape（来自 62593bfd）；透明叠加/transparent_overlay、象限掩码/quadrant_mask、层叠顺序/layer_stack、四象限折叠同画布/quadrants_fold_one（来自 75b8110e）

**依赖链**：跨象限的形状标准化与频次统计决定每个对象是"共享"还是"唯一" → 共享形状以不透明模式叠加（覆盖一切），唯一形状以透明模式叠加（仅填空位） → 叠加结果取决于象限优先级顺序与渲染模式的交互。删去频次分析则不知各对象该用什么渲染模式；删去叠加规则则多象限对象无法合成。

统计各对象形状在四象限中的出现频次，出现多次的形状以不透明模式覆盖叠加，仅出现一次的形状以透明模式见缝插针，最终折叠为单象限画布。

**输入结构**：偶数尺寸网格（如 14x14），分为四个 NxN 象限（TL、TR、BL、BR，各 7x7），背景黑(0)。每个象限含 2-4 个小型单色 4-连通对象（3-8 像素），颜色各异。部分形状（在旋转/翻转等价意义下）在 2 个及以上象限中各出现至少一次（可能颜色不同），其余形状仅在 1 个象限中出现。生成约束：至少有一个共享形状和一个唯一形状；不同象限中的对象折叠后存在重叠区域。

**规则**：
1. **提取标准形状**：对每个对象，取其包围盒内的二值掩码，计算所有 8 种旋转/翻转变体，取字典序最小者为标准形状。
2. **统计象限频次**：对每个标准形状，统计它在多少个象限中至少出现一次。出现 >= 2 个象限 → "共享形状"；仅 1 个象限 → "唯一形状"。
3. **初始化输出**：NxN 画布，全黑(0)。
4. **按象限顺序叠加**：依次处理 TL、TR、BL、BR。对当前象限中的每个对象，将其像素映射到输出画布的对应坐标：
   - **共享形状**的对象：不透明绘制——每个像素直接覆盖输出格中的任何已有颜色。
   - **唯一形状**的对象：透明绘制——仅当输出格当前为背景黑(0) 时才写入，否则跳过该像素。
5. **同象限内冲突**：若同一象限内两个对象映射到输出的同一格，按包围盒左上角的光栅序（先行后列）决定覆盖顺序，后处理的覆盖先处理的（但透明对象仍仅填空位）。

**关键洞察**：在源题 62593bfd 中形状频次决定空间位置（上或下），在源题 75b8110e 中叠加顺序固定且全部不透明。本题将频次重新定义为渲染属性——共享形状"霸道"（不透明覆盖），唯一形状"谦逊"（透明填隙）。求解者必须同时进行跨象限的形状匹配（确定频次）和象限优先级推理（确定叠加顺序），两者交织决定最终每个像素的颜色。

## 新题 8：同心波前扩展与碰撞边界

**组合逻辑**：[射线延伸/ray_extend](创新：直线射线扩展为曼哈顿距离同心环) + [循环填充/concentric_fill + 奇偶交替着色/odd_even_alternating_color](已有，但从静态矩形层深变为动态扩展波前) + [碰撞停止/collision_stop](已有) → 同心扩展 + 多源碰撞涌现 Voronoi 状分区（新结构关系）

**来源原语**：射线延伸/ray_extend、带框块/framed_block、框架缺口/frame_gap、射线交汇/beam_intersection、碰撞停止/collision_stop（来自 e12f9a14）；循环填充/concentric_fill、同心层/concentric_layer、边距深度/edge_distance_depth、奇偶交替着色/odd_even_alternating_color（来自 516b51b7）

**依赖链**：每个框架缺口发射的不是射线而是同心波 → 波前逐层扩展时若与另一源的波前在同一格相遇则该格变为墙 → 墙阻止双方进一步扩展 → 最终每个源的势力范围由碰撞墙和网格边界共同界定，范围内呈同心环交替着色。删去同心扩展则回退为直线射线（不同题）；删去碰撞规则则波前无界。

从带框块的缺口发射同心曼哈顿距离波环，多源波前碰撞处凝固为灰墙，最终形成类 Voronoi 分区内嵌奇偶交替色环的图案。

**输入结构**：约 15x15 的网格，背景黑(0)。含 2-3 个"源结构"：每个由一个 2x2 单色块（波色，如红(2)、蓝(1)）外包一圈 4x4 绿(3) 框架组成，框架上恰有一个缺口（一个框架像素被替换为背景）。缺口位置相对于 2x2 块决定初始扩展种子：缺口正外方的背景格。各源结构间距足够远，波前在网格中部附近相遇。生成约束：不同源结构的波色互不相同；缺口方向使各源的波前必然在网格内相遇。

**规则**：
1. **识别源**：每个绿(3) 4x4 框架内的 2x2 块即为源。块的颜色为"波色"。缺口像素正外方的背景格为"种子格"。
2. **同心波扩展**：从每个种子格出发，按曼哈顿距离逐层向外画环，交替着色：
   - 距离 0（种子格本身）：波色。
   - 距离 1：交替色——若波色非红(2) 则为红(2)，否则为蓝(1)。
   - 距离 2：波色。
   - 距离 3：交替色。
   - 依此类推：偶数距离用波色，奇数距离用交替色。
3. **碰撞规则**：所有源的波同步扩展，每轮所有源同时尝试铺设下一环。若某格将被两个或更多不同源的波在同一轮或不同轮首次到达，该格变为灰(5) 墙。墙格不属于任何源的波，且阻止所有波从该格方向继续扩展。波也不穿越源结构本身（绿框和内部块）。
4. **终止**：当所有源的波前均被完全阻塞（网格边界、灰墙或源结构）时停止。
5. 未被任何波到达的格保持黑(0)。源结构（绿框和内部块）保持不变。

**关键洞察**：碰撞边界是涌现结构——其形态取决于所有源的相对位置和缺口方向，无法从单个源的局部规则预测。同心交替色环使每个源的"势力范围"在视觉上一目了然，而灰墙精确标记了两个势力范围的交锋线，类似加权 Voronoi 图但由离散碰撞逐格决定。
