## 新题 1：滑动终点配对生成填充矩形

**组合逻辑**：[滑动/sliding + 接触停止/contact_stop](已有) → [对角配对/diagonal_pairing](创新：作用于滑动后的终点位置而非静态标记) → [填充/fill + 同色对定义矩形/pair_defines_rect](已有操作，创新触发条件)

**来源原语**：滑动/sliding、接触停止/contact_stop（参考题 56dc2b01）；对角配对/diagonal_pairing、同色对定义矩形/pair_defines_rect、填充/fill（参考题 56ff96f3）

**依赖链**：滑动改变了同色对象的空间位置，使它们在终点处形成新的对角配对关系；只有知道每个对象的滑动终点，才能确定哪些对象构成对角对，进而确定填充矩形的范围。对角配对依赖滑动结果，填充依赖配对结果——三者不可跳步。

将同色小图形沿各自最近的基准方向滑至条形障碍接触面后停止，再将终点位置相同颜色的对象两两配对，以配对点为对角顶点填充矩形。

**输入结构**：约 18x18 的黑(0)背景网格。网格中央有一条完整的红(2)水平条形障碍（宽 1 像素，贯穿网格）。障碍上方和下方各散布若干单色小图形（4-连通，3~5 像素，形状各异），每种非黑非红颜色恰好出现两个图形，分布在障碍的同侧或两侧。使用的颜色包括蓝(1)、绿(3)、黄(4)、灰(5)，每色两个图形，共 8 个图形。生成约束：每个图形与障碍之间的路径上无其他图形阻挡；同色两个图形滑动后的终点不在同一行或同一列（确保对角配对有唯一矩形）。

**规则**：
1. 保留红(2)条形障碍不变。
2. 每个非红前景图形沿竖直方向（上方图形向下，下方图形向上）滑动，直到图形的边界像素与红色障碍的相邻行接触为止（即图形最近的一行紧贴障碍，图形不与障碍重叠）。
3. 滑动后，擦除图形在原位置的像素（设为黑(0)），在终点位置绘制图形。
4. 对于每种前景颜色，其两个图形的终点位置各取边界框中心像素，将这两个中心像素视为一对对角顶点。
5. 以该对角顶点确定的轴对齐矩形区域（含顶点行列），将矩形内所有黑(0)像素填充为该颜色。已有的红色障碍像素和其他颜色像素不被覆盖。
6. 不同颜色的矩形若有重叠区域，按图形终点距障碍更近的颜色优先（距离相同时按图形中心列从左到右优先）。

**关键洞察**：对角配对不是基于静态输入中的位置，而是基于滑动后的终点——必须先完成滑动才能知道矩形在哪里，这使得动态运动和几何构造紧密耦合。

## 新题 2：计数器控制射线长度，射线终点生成同心嵌套方框

**组合逻辑**：[计数/counting + 计数器消失](已有) → [射线延伸/ray_extend](创新：射线长度由计数器值而非障碍决定) → [嵌套包裹/nested_wrapping + 逐层构建](创新：包裹中心由射线终点确定，层色由色条提供)

**来源原语**：计数/counting、计数器消失/counter_disappears、计数决定偏移/count_determines_offset（参考题 e48d4e1a）；射线延伸/ray_extend（参考题 6bcdb01e）；嵌套包裹/nested_wrapping、逐层构建/layer_by_layer_build、条高决定框厚/stripe_height_as_thickness、色条/color_stripe（参考题 45a5af55）

**依赖链**：计数器值决定射线长度→射线终点坐标决定嵌套方框的中心位置→色条序列决定方框各层的颜色和厚度。去掉计数环节则射线长度未知；去掉射线则方框中心未知；去掉色条则各层颜色和厚度未知。

统计灰色计数器像素数量确定射线延伸步数，从起点条发射射线到指定距离停止，以射线终点为中心、按色条顺序和条高逐层向外包裹同心正方形框。

**输入结构**：约 25x25 的黑(0)背景网格。左边缘有一个绿(3)起点条（2 像素，竖直排列，上端像素紧贴网格左边界）。网格最右列自顶部起有若干灰(5)计数器像素（连续排列，数量 3~7 个）。网格底部有 2~4 条全宽水平色条，从下到上颜色依次为蓝(1)、红(2)、黄(4)等不同颜色，每条色条高度 1~2 行。生成约束：射线终点与色条之间留有足够空间，使得按色条条高从内到外逐层包裹后的最外层不超出网格边界，且不与色条重叠。

**规则**：
1. 统计网格最右列中灰(5)像素的数量，记为 K。然后将所有灰(5)像素擦除为黑(0)。
2. 从起点条的下方像素出发，沿水平向右方向延伸射线，步进 K 个像素后停止。射线路径上的所有像素（含起点像素）涂为绿(3)。射线终点坐标记为 (r, c)。
3. 读取底部色条：从最底行向上扫描，每段连续同色全宽行视为一条色条，记录其颜色和高度（行数）。按从底到顶的顺序编号为第 1、第 2、...、第 M 条。
4. 以射线终点 (r, c) 为中心，用第 1 条色条的颜色填充一个边长为 (2 * h1 - 1) 的实心正方形，其中 h1 是第 1 条色条的高度。
5. 对后续第 i 条色条（i = 2, 3, ...），在当前形状的外围包裹一层厚度为 hi 的正方形框，颜色为第 i 条色条的颜色。
6. 擦除底部原始色条区域（设为黑(0)）。保留绿色射线路径。

**关键洞察**：三个独立的输入元素（计数器、起点条、色条）通过射线操作串联——计数器编码距离，起点条编码方向，色条编码嵌套结构参数——缺少任何一个都无法确定输出。

## 新题 3：同色边框分组取并集生成瓦片，引导行选定铺设带

**组合逻辑**：[分组/grouping + 按边框颜色分组](已有) → [对称补全(pattern_union_completion)](创新：并集结果作为独立瓦片而非回填原框) → [平铺/tiling + 引导线选定填充带](创新：引导线颜色与框色匹配决定每条带铺哪个瓦片)

**来源原语**：分组/grouping、按边框颜色分组/group_by_frame_color、同色框共享图案/same_color_frames_share_motif、对称补全(pattern_union_completion)（参考题 42918530）；平铺/tiling、引导线选定填充带/guide_selects_fill_band、引导线定填充带/guide_determines_band（参考题 15696249）

**依赖链**：框色分组确定哪些框取并集→并集生成统一瓦片→引导行颜色与框色匹配决定该带使用哪个瓦片→瓦片平铺到对应带中。去掉分组则不知道怎样合并内部图案；去掉引导行则不知道瓦片铺到哪里。

将同色边框内部图案取并集合成完整瓦片，再根据引导行的颜色将对应瓦片铺满该行所在的水平带。

**输入结构**：约 20x20 的黑(0)背景网格，分为上下两个区域，中间隔一行黑(0)空行。上部区域包含 4~6 个大小相同的正方形边框（边框宽 1 像素，内部为 3x3 或 4x4 的空间），边框之间以至少 1 列黑(0)间隔。边框颜色从蓝(1)、红(2)、绿(3)中选取，每种颜色出现 2~3 个边框。每个边框内部有若干与边框同色的像素构成部分图案（不同同色边框的内部图案互不相同但可互补）。下部区域的最左列包含 2~3 个引导像素，颜色分别对应上部出现的边框颜色，每个引导像素所在行标记一个水平带（带的高度等于边框内部空间高度）。生成约束：同色边框的内部图案取并集后恰好填满内部空间（无遗漏像素）；各引导行之间的间距恰好等于带高度。

**规则**：
1. 识别上部区域所有正方形边框，按边框颜色分组。
2. 对每个颜色组，提取每个边框内部图案的相对坐标（以边框内部左上角为原点），将所有同色框的内部坐标取并集，生成该颜色的统一瓦片。瓦片大小等于边框内部空间大小。
3. 在下部区域，找到最左列中每个引导像素的行号和颜色。该行号起始、向下延伸一个瓦片高度的水平带为目标带。
4. 对每个引导像素，取其颜色对应的统一瓦片，沿水平方向反复平铺（从第 1 列开始），填满该水平带。瓦片中有色像素使用对应边框颜色，空白位置保持黑(0)。
5. 擦除上部区域（全部设为黑(0)），擦除引导像素本身。保留平铺结果。

**关键洞察**：边框分组产出的是"图案内容"，引导行产出的是"铺设位置"，两者通过颜色匹配建立映射——这是参考题 42918530（只回填原框）和 15696249（只铺单一瓦片）中都不存在的跨域耦合。

## 新题 4：腔室内标记位置编码旋转角度，精灵体旋转后嵌入腔室

**组合逻辑**：[格点骨架/lattice_frame + 封闭腔室/enclosed_cavity + 标记指定腔室](已有对象) → [标记位置编码旋转](创新：标记在腔室内的相对位置决定旋转角度，而非单纯指定目标) → [旋转/rotate + 对接拼合/docking](已有操作，创新触发条件)

**来源原语**：格点骨架/lattice_frame、封闭腔室/enclosed_cavity、标记像素/marker_pixel、标记指定腔室/marker_designates_cavity（参考题 17b866bd）；旋转/rotate、对接拼合/docking、颜色匹配配对/color_match_pairing、对称消歧旋转/symmetry_disambiguates_rotation（参考题 2c181942）

**依赖链**：标记像素的颜色与外部精灵体配对→标记在腔室内的角落位置编码旋转角度→精灵体按该角度旋转后嵌入腔室。去掉标记位置信息则旋转角度未知；去掉颜色匹配则不知道哪个精灵体进入哪个腔室。

读取格点骨架中每个腔室内标记像素的颜色和角落位置，将颜色匹配的外部精灵体旋转到标记指定的方向后嵌入对应腔室。

**输入结构**：约 20x20 的黑(0)背景网格。网格中有一个青(8)格点骨架，形成 2x2 或 2x3 的规则腔室阵列，每个腔室内部为 4x4 的黑(0)空间。若干腔室（2~4 个）的内部四角之一有一个单独的彩色标记像素（颜色各不同，从蓝(1)、红(2)、黄(4)、橙(7)中选取）。网格中骨架外围的空白区域散布着与标记像素同色的小精灵体（4-连通，4~8 像素，非对称形状，每色一个）。生成约束：每个精灵体的边界框不超过 4x4（恰好可放入腔室内部）；精灵体本身不具有四重旋转对称性（确保旋转有意义）；每个腔室最多一个标记。

**规则**：
1. 识别青(8)格点骨架及其所有封闭腔室（4x4 内部空间）。
2. 对每个含标记像素的腔室，记录标记的颜色 C 和它在 4x4 内部空间中的角落位置：左上角 → 0 度，右上角 → 90 度顺时针，右下角 → 180 度，左下角 → 270 度顺时针。
3. 在骨架外找到颜色为 C 的精灵体，将其裁剪为最小边界框。
4. 将该精灵体按步骤 2 确定的角度顺时针旋转。
5. 擦除腔室内的标记像素，将旋转后的精灵体放入该腔室的内部空间中，左上角对齐。精灵体的有色像素覆盖黑(0)背景，精灵体边界框中的黑(0)像素不覆盖腔室原有内容。
6. 无标记的腔室保持原样（内部全黑）。擦除骨架外原精灵体所在位置的像素（设为黑(0)）。

**关键洞察**：标记像素承担双重角色——颜色用于配对（哪个精灵体进入哪个腔室），位置用于编码旋转指令（角落位置 = 旋转角度）——这种"同一元素的不同属性驱动不同逻辑"在参考题中不存在。

## 新题 5：压缩后稀疏标记做四象限镜像，镜像结果按沙漏距离重涂色

**组合逻辑**：[坐标压缩/coordinate_compression](已有) → [对称补全/symmetry_complete + 四象限镜像填充](已有) → [沙漏距离谓词/hourglass_distance_predicate + 重涂色/recolor](创新：将沙漏距离判定应用于镜像产生的新像素而非原有像素)

**来源原语**：坐标压缩/coordinate_compression、分隔线/separator_line、块距离/block_distance、沙漏距离谓词/hourglass_distance_predicate（参考题 7d419a02）；对称补全/symmetry_complete、十字轴线/cross_axis、稀疏标记/sparse_marker、双轴对称/biaxial_symmetry、四象限镜像填充/quadrant_mirror（参考题 60d73be6）

**依赖链**：分隔线必须先压缩去除才能得到正确的像素距离→压缩坐标下做四象限镜像补全→镜像结果中每个像素按沙漏距离谓词决定是否重涂色。去掉压缩则距离计算错误；去掉镜像则待涂色的像素不完整；去掉沙漏判定则无颜色区分。

去除分隔线后在压缩坐标中对稀疏标记做十字轴四象限镜像补全，再按各像素到十字中心的沙漏距离关系将落入沙漏内的镜像像素重涂为第二色。

**输入结构**：约 15x15 的黑(0)背景网格。网格中有若干条完整的灰(5)分隔行和分隔列（仅沿一个轴方向，例如 2~3 条灰色完整行），将网格分成条带。有一条完整的品红(6)行和一条完整的品红(6)列形成十字轴线。在十字轴线的一个象限中散布 3~5 个蓝(1)稀疏标记像素（单像素点）。生成约束：分隔线均平行于同一轴（全是行或全是列）；稀疏标记仅出现在一个象限中；十字轴线不与分隔线重叠。

**规则**：
1. 删除所有灰(5)分隔行或分隔列，将其上下（或左右）的网格部分合拢，得到压缩后的网格。品红(6)十字轴线和蓝(1)标记的相对位置随之更新。
2. 对压缩网格中每个蓝(1)标记像素，计算其关于品红(6)十字行的镜像位置、关于品红(6)十字列的镜像位置、以及关于两者交叉点的中心对称位置。在这三个镜像位置放置蓝(1)像素（超出网格边界则忽略）。
3. 确定沙漏方向：分隔线所沿的原始轴为沙漏窄轴，垂直方向为沙漏开口轴。
4. 对压缩网格中所有蓝(1)像素（含原始标记和镜像生成的），计算其到十字交叉点的窄轴距离 dn 和开口轴距离 do（以像素为单位）。若 dn > 0 且 do > 0 且 dn <= do，则该像素落入沙漏内，将其重涂为黄(4)。
5. 十字交叉点上的像素保持品红(6)不变。十字轴线上（非交叉点）的像素保持品红(6)。dn = 0 或 do = 0 的蓝(1)像素保持蓝(1)。

**关键洞察**：镜像补全和沙漏重涂色的耦合在于——镜像产生的像素处于不同象限，其到十字中心的距离关系各不相同，因此同一个原始标记的四个副本可能有的被重涂、有的不被重涂，产生对称但不均匀的颜色分布。

**规则**：
1. 从起点条的边界像素出发，沿通过另一个起点像素的方向进入网格。将经过的黑(0)像素涂为绿(3)。
2. 当下一个像素是障碍像素时，记录当前直线段的长度 L（从上一个转弯点或起点到当前位置的绿色像素数），以及该障碍像素的颜色 C。然后转向唯一可行的 90 度方向继续行进。

4. 设共记录了 N 个障碍像素（产生 N 个颜色 C1...CN 和 N+1 段长度 L1...LN+1）。

6. 第 i 层（i = 1 到 N）：在当前形状外围包裹一层厚度为 L_{i+1} 的正方形框，颜色为 Ci。
7. 超出网格边界的部分裁剪掉。擦除走廊路径上的绿色像素和障碍像素（设为黑(0)），仅保留同心方框。

**关键洞察**：走廊路径的几何结构（段长和障碍颜色）同时编码了同心方框的两种参数（厚度和颜色），路径追踪是一次性的信息提取过程，提取完毕后路径本身被擦除——走廊是指令而非输出。

## 新题 9：十字图案计数偏移后，十字臂端点作为对角对生成填充矩形

**组合逻辑**：[计数/counting + 计数决定偏移](已有) → [平移/translate](已有) → [十字臂端点提取](创新：将十字图案的四个臂端视为两对对角标记) → [填充/fill + 同色对定义矩形](创新应用：端点对定义矩形而非独立标记)

统计灰色计数器数量决定十字图案的偏移步数，偏移后将十字的水平臂端配对为一组、垂直臂端配对为另一组，各自构成矩形的对角顶点并填充。

**输入结构**：约 15x15 的黑(0)背景网格。网格中有一个由蓝(1)构成的十字图案——一整行和一整列同为蓝(1)色，交叉形成十字。网格最右列自顶部起有 1~4 个灰(5)计数器像素。生成约束：十字偏移后的水平臂两端和垂直臂两端各形成一对点，这两对点分别构成的矩形不重叠且不超出网格边界；偏移量使十字不移出网格。

**规则**：
1. 统计最右列灰(5)像素数量 K，然后擦除所有灰(5)像素为黑(0)。
2. 找到蓝(1)十字的行号 R 和列号 C。
3. 将十字的行向下平移 K 行（新行号 R' = R + K），列向左平移 K 列（新列号 C' = C - K）。在新位置绘制蓝(1)十字，擦除旧位置（重叠部分保留蓝色）。
4. 取偏移后十字的水平臂两端点：(R', 0) 和 (R', W-1)，其中 W 是网格宽度。这两个点作为一对对角顶点，定义一个矩形区域。将该矩形内所有黑(0)像素填充为红(2)。
5. 取偏移后十字的垂直臂两端点：(0, C') 和 (H-1, C')，其中 H 是网格高度。这两个点作为一对对角顶点，定义一个矩形区域。但因两点在同一列，矩形退化为一条线——此时不做额外填充（垂直臂端点共线，不形成面积矩形）。

7. 两矩形重叠区域（若有）保持先绘制的红(2)。

**关键洞察**：十字图案在参考题中是整体平移的对象，但这里平移后十字的端点被重新解构为对角配对的标记——同一个几何元素在前半段是操作对象，在后半段是参数来源，这种角色转换是新的结构关系。

## 新题 10：碰触障碍后对侧生成阶梯轮廓，阶梯高度由滑动距离决定

**组合逻辑**：[滑动/sliding + 接触停止/contact_stop + 碰触后对侧放副本](创新改造：对侧放的不是副本而是阶梯轮廓) → [距离决定阶梯高度/distance_determines_step_height](创新：距离不来自底行标尺而来自滑动位移量) → [射线延伸/ray_extend](已有操作，生成阶梯的竖直线段)

**来源原语**：滑动/sliding、前景对象/foreground_object、条形障碍/bar_obstacle、接触停止/contact_stop、碰触后对侧放副本/touch_copy_opposite（参考题 56dc2b01）；距离/distance、距离决定阶梯高度/distance_determines_step_height、色条/color_bar、侧翼列/flanking_column（参考题 b8cdaf2b）；射线延伸/ray_extend（参考题 6bcdb01e）

**依赖链**：每个对象的滑动距离只有在滑动完成后才知道→滑动距离编码对侧阶梯高度→阶梯高度决定射线延伸长度。去掉滑动则距离未知；去掉阶梯映射则高度无法确定。

多个小对象从两侧向中央条形障碍滑动至接触，每个对象的滑动距离转化为障碍对侧对应位置的竖直阶梯高度。

**输入结构**：约 15x20 的黑(0)背景网格（宽大于高）。网格中央有一条完整的红(2)垂直条形障碍（宽 1 像素，贯穿网格上下）。障碍左侧散布 2~4 个蓝(1)小图形（4-连通，2~4 像素，形状各异），它们位于不同的行区间且互不重叠，与障碍的水平距离各不相同（2~6 像素）。障碍右侧散布同样数量的绿(3)小图形，布局类似。生成约束：每个图形与障碍之间无其他图形阻挡；同侧图形占据不同的行区间；左右两侧图形数量相同。

**规则**：
1. 保留红(2)条形障碍不变。
2. 对障碍左侧每个蓝(1)图形：计算其最右像素到障碍的水平距离 D（中间的空像素数）。将该图形向右水平滑动，直到其最右像素紧邻障碍左侧（与障碍相距 1 像素）。擦除原位置，在新位置绘制图形。
3. 对障碍右侧每个绿(3)图形：同理向左滑动至紧邻障碍右侧。记录每个图形的滑动距离 D。
4. 对每个已滑动的蓝(1)图形（原在左侧），在障碍右侧、与该图形相同行区间内，从障碍向右延伸该图形每个像素行上的一条水平射线，射线长度等于该图形的滑动距离 D，颜色为蓝(1)。
5. 对每个已滑动的绿(3)图形（原在右侧），在障碍左侧、与该图形相同行区间内，从障碍向左延伸对应射线，长度等于该图形的滑动距离 D，颜色为绿(3)。
6. 若对侧射线与已有的滑动后图形像素重叠，射线像素不覆盖图形像素。

**关键洞察**：每个对象的滑动距离是一个隐含的数值——它不在输入中直接给出，必须从对象位置和障碍位置推算，然后这个数值被"传送"到障碍对侧作为射线延伸长度，形成一种跨障碍的信息对称传递。
