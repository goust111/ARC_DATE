## 新题 1：墙壁分区链式重涂色

**组合逻辑**：[泛洪填充](从墙壁边界分区改为从网格边缘泛洪确定区域归属) + [链式连接](创新：按标记像素到墙壁的距离建立链序) + [重涂色](创新：链序位置决定目标颜色) → 三者交织：墙壁形状同时决定分区边界和链序参考点

**来源原语**：泛洪填充(flood_fill) + 墙壁边界(wall_boundary) 来自参考题 7491f3cf；链式连接(chain_linkage) 来自参考题 84551f4c；重涂色(recolor) + 单点标记(singleton_marker) + 连通分量(connected_component) 来自参考题 09c534e7

**依赖链**：墙壁将网格分成两个区域 → 区域归属决定哪些分量被分为一组 → 每个分量的标记像素到墙壁的曼哈顿距离决定组内链序 → 链序位置映射到固定颜色序列完成重涂色。墙壁既是分区工具又是排序参考点，双重角色产生源题中不存在的结构耦合。

将网格被墙壁划分成的两个区域中的各个标记分量，按其标记到墙壁的距离排成链，再按链序重涂色。

**输入结构**：约 15x15 的网格，黑(0)背景。灰(5)像素形成一条从网格顶部边缘到底部边缘的 4-连通连续路径（宽度为 1 像素），将网格分为左区域和右区域。每个区域中分布有 3~4 个互不相邻的蓝(1) 4-连通分量（每个分量 4~8 像素，形状不规则，非矩形），每个分量内部恰好包含一个颜色各异的单点标记像素（标记颜色取自 {红(2), 绿(3), 黄(4), 橙(7), 品红(6)}，全局无重复）。生成约束：同一区域内任意两个分量的标记像素到灰墙的最短曼哈顿距离互不相等；灰墙不接触网格左右边缘（确保左右区域各自连通到对应边缘）。

**规则**：
1. 从网格左边缘的所有黑(0)像素出发，做 4-连通泛洪填充（遇灰(5)墙壁像素阻断），所有被填充到的像素位置属于"左区域"；网格中既非灰墙、又不属于左区域的所有位置属于"右区域"。
2. 根据每个蓝(1)分量的质心（所有像素坐标的均值，四舍五入到最近整数格）所在区域，将分量归入左区域组或右区域组。
3. 在每个区域组内，计算每个分量的标记像素到灰墙的最短曼哈顿距离（即标记像素到最近灰(5)像素的曼哈顿距离）。按距离从小到大排序，形成该组的链。
4. 按链序对每个分量的非标记蓝(1)像素进行重涂色：链中第 1 个分量涂红(2)，第 2 个涂绿(3)，第 3 个涂黄(4)，第 4 个涂橙(7)。
5. 每个分量的标记像素保持其原色不变。灰(5)墙壁保持不变。黑(0)背景保持不变。

**关键洞察**：灰墙在本题中承担双重角色——它既是将分量划分为左右两组的空间分隔线，又是决定每组内部排序的距离参考点。删除任一角色（仅分区不排序、或仅排序不分区），题目都无法求解。

## 新题 2：框内对角连线的交叉色彩互换

**组合逻辑**：[框内限定](筛选有效矩形对) + [对角连线](画对角连接段) + [颜色互换](创新：连线交叉点触发两条连线的颜色互换，交换从交叉点向后传播) → 三者形成"空间筛选 → 路径构造 → 交叉涌现 → 颜色重路由"链

**来源原语**：矩形边框(rectangular_frame) + 框内限定(frame_interior_only) + 颜色互换(color_swap) 来自参考题 7ee1c6ea；连线(connect) + 同色矩形对(same_color_rect_pair) + 对角偏移(diagonal_offset) + 对角补全连接(diagonal_fill) 来自参考题 342ae2ed；忽略干扰项(ignore_distractors) 来自参考题 458e3a53/aab50785

**依赖链**：矩形框限定有效区域 → 仅框内的同色矩形对参与连线 → 对角连线的路径由矩形对位置决定 → 两条连线是否交叉取决于路径几何 → 交叉点触发两条线在交叉点之后互换颜色。框外干扰物不参与。

在矩形框内为同色矩形对画对角连线；当两条不同色的连线交叉时，在交叉点处互换颜色并向各自终点传播。

**输入结构**：约 14x14 的网格，黑(0)背景。一个灰(5)单像素厚的矩形边框（四角为黑(0)）。框内区域包含 3 对同色小矩形（每个矩形为 1x2 或 2x1 的实心块），每对使用不同颜色（取自 {红(2), 绿(3), 蓝(1)}）。每对的两个矩形沿 45 度对角线方向偏移，面对的角落在同一条对角线上。框外散布有与框内相同颜色的随机像素（干扰项）。生成约束：3 对连线中恰好有 1~2 对发生交叉；任意两条连线至多交叉一次；不存在三线共点。

**规则**：
1. 忽略框外所有像素（干扰项），仅处理严格位于框内部的矩形。
2. 对每对同色矩形，确定面对的角落（沿 45 度线最近的两个角），在两角之间的背景像素上画对角连线，颜色与该对矩形相同。连线不包含两个端点角落本身（端点已有矩形像素）。
3. 检查所有连线之间的交叉。若两条不同色的连线（设为色 A 和色 B）在某像素交叉：该交叉像素涂为橙(7)。沿每条连线的方向（以该连线所属矩形对中行号较小的矩形的面对角落为起点），交叉点之前的段保持原色，交叉点之后的段互换为对方颜色（原为 A 的变为 B，原为 B 的变为 A）。
4. 不与任何其他连线交叉的连线全程保持其原色。
5. 框、矩形本身、框外像素均保持不变。

**关键洞察**：交叉点是两条独立对角路径的涌现产物——只有同时追踪所有连线的几何路径，才能确定哪些像素发生颜色互换。连线方向的定义（行号较小的矩形角落为起点）决定了哪些段在交叉前、哪些在交叉后，这个方向选择需要对比多个示例才能归纳。

## 新题 3：四区域旋转互补复原

**组合逻辑**：[旋转](推断每个区域的旋转角度) + [补全](用跨区域信息填补缺失) + [缺失用分隔色填充](填补像素使用黄色而非原色) → 结构为同时约束满足：四个区域互相提供信息，无固定执行顺序

**来源原语**：旋转(rotate) 来自参考题 8e5a5113/84551f4c；补全(completion) + 分隔线(divider_line) + 阵列排布(array_layout) + 缺失用分隔色填充(missing_filled_with_divider_color) 来自参考题 1e32b0e9；模板(template) 来自参考题 8e5a5113/1e32b0e9

**依赖链**：每个区域是同一模板的不同旋转版本，但各自缺失不同部分 → 必须先从可见像素推断各区域对应哪个旋转角度 → 将所有区域的可见像素反旋转到 0 度坐标系下拼合出完整模板 → 再将完整模板正旋转回各区域、用黄(4)填补缺失。这是约束满足问题，非线性流水线。

四个区域各含同一图案的不同旋转版本且各有缺失；跨区域拼合所有可见信息重建完整图案，再填补各区域的缺失像素。

**输入结构**：约 11x11 的网格。灰(5)分隔线将网格分为 2x2 的四个等大正方形区域（每个约 5x5）。每个区域包含一个由红(2)和蓝(1)像素组成的不完整图案（缺失部分为黑(0)），位于黑(0)背景上。四个区域对应同一个底层模板分别旋转 0 度、90 度顺时针、180 度、270 度顺时针后的版本，但旋转角度与区域位置的对应关系不固定（不一定是左上=0 度、右上=90 度等），需从像素内容推断。每个区域缺失该旋转版本中至少 30% 的像素。生成约束：四个区域的可见像素在反旋转后的并集覆盖模板的所有像素（即信息总量足够重建）。底层模板不具有 90 度旋转对称性（确保四个旋转版本两两不同）。

**规则**：
1. 对四个区域的可见（非黑）像素，尝试所有旋转角度分配方案（共有 4!=24 种将 {0, 90, 180, 270} 度分配给四个区域的方式），找到唯一一致的方案：在该方案下，任意两个区域的可见像素反旋转到 0 度坐标后不产生颜色矛盾（同一模板位置若被多个区域覆盖，颜色必须一致）。
2. 在确定的方案下，将所有区域的可见像素反旋转到 0 度坐标系并合并，重建完整模板。
3. 将完整模板按每个区域对应的旋转角度正旋转，对比该区域的当前内容：凡是该区域中为黑(0)但模板旋转后对应位置非黑的像素，填充为黄(4)。
4. 已有的非黑像素保持不变。灰(5)分隔线保持不变。

**关键洞察**：没有任何一个区域能独立完成补全——每个区域的缺失恰好需要其他区域的可见像素（经旋转变换）来提供。同时，旋转角度分配本身就是一个推理步骤，需要对比区域间的像素一致性才能确定。

## 新题 4：内部密度分拣与互补拼合重涂色

**组合逻辑**：[邻域全包含测试](分类分量为"厚实"或"纤细") + [擦除](移除纤细分量) + [无重叠拼合](创新：将存活的厚实分量做最密平移拼合) + [重涂色](创新：拼合结果中每个分量涂其标记色)

**来源原语**：邻域全包含(full_neighborhood_inside_component) + 连通分量(connected_component) + 单点标记(singleton_marker) + 重涂色(recolor) 来自参考题 09c534e7；擦除(erase) 来自参考题 d59b0160；无重叠拼合(non_overlap_pack) + 互补拼合(complement_fit) + 最密堆叠最小框(densest_minimal_bbox) 来自参考题 681b3aeb

**依赖链**：3x3 邻域测试 → 分类厚实/纤细 → 纤细被擦除（过滤）→ 厚实分量裁剪后做最密拼合 → 标记色决定拼合后的着色。内部密度测试的结果决定了拼合问题的输入集，标记像素同时承担分类辅助和着色指令的双重角色。

用 3x3 邻域测试区分厚实与纤细分量，擦除纤细分量后将两个厚实分量做最密平移拼合，再按各自标记色重涂。

**输入结构**：约 15x10 的网格，黑(0)背景。包含恰好 4 个互不接触的蓝(1) 4-连通分量。每个分量内恰好有一个颜色各异的单点标记像素（标记色取自 {红(2), 绿(3), 黄(4), 橙(7)}，全局不重复）。其中 2 个分量是"厚实"的——至少有一个蓝(1)像素的 8 个邻居全部属于同一分量（即存在实心内部）；另外 2 个是"纤细"的——每个蓝(1)像素都至少有一个邻居不属于该分量（线状或窄条形态，宽度不超过 1 像素）。生成约束：两个厚实分量的形状互补——在最优平移拼合下，合并的边界框中空白像素不超过 2 个。每个分量的像素数在 5~12 之间。

**规则**：
1. 对每个蓝(1) 4-连通分量，检查是否存在至少一个非标记蓝像素，其 3x3 邻域（8 个邻居）全部属于该分量。有则分类为"厚实"，否则为"纤细"。
2. 将两个纤细分量的所有像素（含标记）擦除为黑(0)。
3. 分别裁剪两个厚实分量的最小边界框。
4. 枚举两个裁剪块的所有相对平移偏移量。对每个偏移量，将两块放在一张画布上（不允许任何非黑像素重叠）。在所有合法放置中，选择合并后最小外接边界框面积最小的方案。若有多个方案面积相同，选择第一个块（按其标记像素行号较小者）位于左上方的方案。
5. 在最终拼合的输出中，将每个厚实分量的所有蓝(1)像素重涂为该分量的标记色。标记像素本身也涂为该标记色。输出尺寸等于合并后的最小外接边界框。

**关键洞察**：3x3 邻域测试在本题中的作用与参考题 09c534e7 完全不同——参考题用它定位分量内部像素做局部重涂，本题用它做整体分量级别的二元分类（留/弃），分类结果决定哪些形状进入后续的空间拼合问题。

## 新题 5：孤立像素射线坐标定位印章

**组合逻辑**：[射线延伸](创新：孤立像素的射线不画在网格上，而是标记格子单元的行列为"活跃") + [行列交叉](活跃行与活跃列的交叉确定目标格元) + [印章覆盖](将模板精灵体复制到目标格元，且行方向和列方向的非交叉格元获得镜像副本)

**来源原语**：射线延伸(ray_extend) + 孤立像素(isolated_pixel) + 行列交叉(row_col_intersection) 来自参考题 23581191；印章覆盖(stamp_overlay) + 分隔线网格(separator_lattice) 来自参考题 e734a0e8/48f8583b；精灵体(sprite) 来自参考题 7d18a6fb/681b3aeb

**依赖链**：两个孤立像素的格元坐标 → 确定活跃格元行和格元列 → 行列交叉格元 = 主目标（放置原版精灵）→ 仅在活跃行的其他格元放水平翻转副本 → 仅在活跃列的其他格元放垂直翻转副本。翻转轴由格元属于活跃行还是活跃列决定，这一规则需对比多个示例归纳。

两个孤立像素在格子阵列中充当行列坐标选择器；行列交叉的格元获得原版精灵，同行或同列的其他格元获得对应方向的镜像副本。

**输入结构**：约 17x17 的网格。红(2)分隔线将网格分为 4x4 的等大方形格元阵列（每个格元约 3x3，格元之间由单像素宽红线分隔）。所有格元内部为黑(0)，除以下三种例外：(a) 一个格元包含一个绿(3)的小型不规则 4-连通精灵体（3~5 像素，不对称，无旋转对称性），即模板；(b) 另一个格元的中心有一个蓝(1)孤立像素；(c) 又一个格元的中心有一个黄(4)孤立像素。蓝像素和黄像素不在同一格元行，也不在同一格元列。生成约束：蓝像素、黄像素、模板精灵体分别在三个不同的格元中；活跃行与活跃列的交叉格元不是模板所在格元、蓝像素格元或黄像素格元；精灵体在任一方向镜像后仍能容纳在单个格元内。

**规则**：
1. 确定蓝(1)孤立像素所在的格元行号（称为活跃行 R），以及黄(4)孤立像素所在的格元列号（称为活跃列 C）。格元行列号从左上角 (0,0) 开始。
2. 在活跃行 R 与活跃列 C 交叉处的格元（即格元 (R, C)），以该格元左上角为锚点，放置模板精灵体的原版副本（保持精灵在模板格元中的相对位置不变）。
3. 活跃行 R 中的其他空白格元（不含蓝像素格元、不含模板格元、不含格元 (R,C)），各放一个精灵的水平翻转副本（沿格元垂直中轴左右镜像）。
4. 活跃列 C 中的其他空白格元（不含黄像素格元、不含模板格元、不含格元 (R,C)），各放一个精灵的垂直翻转副本（沿格元水平中轴上下镜像）。
5. 蓝像素格元和黄像素格元保持原样（仅含各自的孤立像素）。模板格元保持原样。所有非活跃行列的格元保持黑(0)。红(2)分隔线保持不变。

**关键洞察**：两个孤立像素建立了一个格元坐标系统（类似参考题 23581191 中十字射线的行列选择逻辑），但选中格元的内容不是着色而是印章放置。更隐蔽的规则是翻转方向的选择——活跃行格元做水平翻转、活跃列格元做垂直翻转——这一规则不能从单个示例中推断（需要至少两个示例验证翻转轴与行/列的对应关系）。

## 新题 6：边框方向平移与交替行波叠加

**组合逻辑**：[颜色匹配边 + 朝匹配边移动](像素按颜色朝对应边框边平移) + [逐行交替方向滑动](创新：平移后再施加交替行位移) → 两次空间变换复合，第二次的效果取决于第一次的结果位置，不可分解

**来源原语**：边框边(frame_side) + 颜色匹配边(color_match_side) + 朝匹配边移动(move_toward_match) + 内部像素(interior_pixel) 来自参考题 5034a0b5；矩形边框(rectangular_frame) 来自参考题 7ee1c6ea；滑动(shift) + 逐行交替方向(alternating_direction_per_row) + 底行锚定(bottom_row_anchored) 来自参考题 1c56ad9f

**依赖链**：像素颜色决定第一步平移方向（向匹配框边移动） → 平移改变像素所在行号 → 新行号决定第二步交替滑动是否生效及方向 → 最终位置是两步变换的复合。一个像素的最终位置同时取决于其颜色（决定步骤 1）和步骤 1 后所在行的奇偶性（决定步骤 2）。

框内像素先按颜色朝匹配的边框边移动一格，再施加从底行锚定的交替行位移；两步变换复合产生不可分解的最终位移。

**输入结构**：约 12x12 的网格。一个单像素厚的矩形边框，四边颜色各异：顶边=红(2)，底边=绿(3)，左边=蓝(1)，右边=黄(4)。四角为黑(0)。框内为黑(0)背景，散布有 8~12 个前景像素，每个像素颜色为红(2)、绿(3)、蓝(1)或黄(4)之一（即与某一边框边颜色匹配）。生成约束：没有像素在移动前已经紧邻其匹配的边框边（确保每个像素都会发生平移）；框内高度（上框边到下框边的内部行数）至少为 6，以产生足够的交替行效果；每种颜色的像素至少出现 1 个。

**规则**：
1. 对框内每个非黑前景像素，按其颜色匹配的边框边方向平移 1 格：红(2)像素上移 1 行，绿(3)像素下移 1 行，蓝(1)像素左移 1 列，黄(4)像素右移 1 列。若移动后像素会落在边框像素上，则该像素不移动（保持原位）。移动后原位置变为黑(0)。所有像素的移动基于移动前的快照同时计算（不存在先后顺序依赖）。
2. 在步骤 1 完成后的网格上，对框内区域施加交替行位移：以框内最底行为锚定行（不移动），从底行往上每隔一行右移 1 像素（即底行不动，倒数第 2 行右移 1，倒数第 3 行不动，倒数第 4 行右移 1 ...）。右移时若像素移出框的右边界内侧，则环绕到同一行的框左边界内侧。
3. 若步骤 1 中两个像素移动到同一格，保留颜色与顶边或左边颜色匹配的那个（优先级：蓝(1) > 红(2) > 黄(4) > 绿(3)），另一个被擦除。
4. 边框保持不变。

**关键洞察**：一个像素的最终位置是颜色决定的方向性平移与位置决定的行交替位移的复合——同一颜色的像素若初始位于不同行，步骤 1 后可能进入奇偶性不同的行，导致步骤 2 的滑动效果不同。两步变换的交互使得最终位移不可拆解为独立的行变换和列变换。

## 新题 7：图例过滤擦除与残余对角连线的障碍回避

**组合逻辑**：[图例作为过滤器](读取目标色集) + [擦除](删除包含所有目标色的多色分量) + [对角连线](为存活的同色矩形对画对角连接段) + 障碍回避（创新：被擦除分量的边界框成为连线的禁区，连线跳过禁区留下间隙）

**来源原语**：图例区域(legend_region) + 图例作为过滤器(legend_as_filter) + 包含全部目标色(contains_all_target_colors) + 擦除(erase) + 连通分量(connected_component) 来自参考题 d59b0160；连线(connect) + 同色矩形对(same_color_rect_pair) + 对角偏移(diagonal_offset) + 对角补全连接(diagonal_fill) 来自参考题 342ae2ed

**依赖链**：图例颜色集 → 决定哪些多色分量被擦除 → 被擦除分量的边界框变成空间障碍 → 同色矩形对的对角连线必须绕开障碍（留间隙）。同一擦除操作既清理了干扰又制造了路径障碍，对连线产生双重影响。

读取图例中的目标色集，擦除含全部目标色的多色分量；为剩余的同色矩形对画对角连线，但连线在被擦除分量的边界框范围内留下间隙。

**输入结构**：约 16x16 的网格，黑(0)背景。左上角有一个小型图例区域（约 3x3 内部），由灰(5)像素围成的框，框内含 1~2 个目标色像素（取自 {红(2), 蓝(1)}）。网格其余区域包含两类对象：(a) 3~4 个多色 4-连通分量（每个分量由 2~4 种颜色的像素组成，总像素 6~15 个，形状不规则），(b) 2~3 对同色实心小矩形（每个矩形 1x2 或 2x1，每对使用不同的单一颜色——取自 {绿(3), 黄(4), 橙(7)}，与图例目标色不同），每对的两个矩形沿 45 度线对角偏移。生成约束：多色分量中至少有 1 个包含图例中的所有目标色（将被擦除），至少有 1 个不包含所有目标色（保留）；至少有 1 对同色矩形对的对角连线路径经过某个被擦除分量的原始边界框。矩形对不与多色分量接触或重叠。

**规则**：
1. 读取图例框内部的目标色集合 T。
2. 对网格中每个 4-连通的多色分量（包含 2 种及以上颜色的分量），检查其是否包含 T 中的全部颜色。若是，将该分量的所有像素擦除为黑(0)，并记录其最小外接边界框作为"障碍区"。
3. 不包含全部目标色的多色分量保留不变。
4. 对每对同色矩形，确定面对的角落并画对角连线（仅在背景黑(0)像素上画）。连线颜色与矩形对相同。
5. 如果对角连线的路径上有像素位于任何障碍区内（被擦除分量的原始边界框范围），则跳过该像素（不画），在连线上留下间隙。连线路径上位于障碍区外的像素正常绘制。
6. 图例区域（含灰边框）保持不变。

**关键洞察**：被擦除的分量在物理上消失了，但它们的"幽灵"（边界框）作为空间障碍继续影响对角连线的形态。图例驱动的擦除同时产生了两个效果——清除视觉干扰和塑造连线几何——这种双重因果关系是源题中不存在的结构。

## 新题 8：瓦片提取与精灵编码旋转

**组合逻辑**：[提取](通过纯色判定从分隔线网格中提取有效瓦片) + [旋转](创新：旋转角度由一个特殊精灵瓦片的朝向编码) → 双通道读取：数据通道（哪些瓦片纯色、颜色是什么）和指令通道（精灵朝向编码旋转量），两者在最终旋转步汇合

**来源原语**：提取(extract) + 分隔线网格(separator_lattice) + 纯色单元格(solid_cell) + 纯色即有效(solid_is_valid) + 忽略干扰项(ignore_distractors) 来自参考题 458e3a53；旋转(rotate) + 逐槽位累计旋转(successive_rotation_per_slot) 来自参考题 8e5a5113；瓦片(tile) + 模板图块(template_tile) 来自参考题 e734a0e8；精灵体(sprite) 来自参考题 7d18a6fb/681b3aeb

**依赖链**：分隔线划分瓦片 → 纯色判定区分有效瓦片和噪声瓦片 → 有效瓦片的颜色组成缩小网格（数据通道）→ 同时，定位精灵瓦片并判断其朝向得到旋转角度（指令通道）→ 将缩小网格旋转指定角度输出。任一通道出错，输出都不正确。

从分隔线网格中提取纯色瓦片组成缩小网格，同时识别一个特殊精灵瓦片的旋转朝向，将缩小网格按该朝向旋转后输出。

**输入结构**：约 19x19 的网格。灰(5)分隔线（单像素宽的完整行和完整列）将网格分为 4x4 的等大矩形瓦片阵列（每个瓦片约 4x4）。瓦片分三类：(a) 噪声瓦片——内部包含 2 种以上颜色的重复图案（占多数），(b) 纯色瓦片——内部所有像素为同一种非黑非灰颜色（取自 {红(2), 蓝(1), 绿(3), 黄(4)}），形成一个连续的矩形子区域（如 2x3 或 3x2 的瓦片块），(c) 恰好 1 个精灵瓦片——内部在黑(0)背景上有一个橙(7)的小型不对称 4-连通精灵图（3~4 像素）。生成约束：精灵不具有任何旋转对称性（确保 0/90/180/270 度朝向两两可区分）。纯色瓦片子区域不对称（使旋转后的输出可区分）。精灵瓦片不在纯色瓦片的子区域中。

**规则**：
1. 用灰(5)完整行和完整列将网格划分为 4x4 的瓦片。
2. 对每个瓦片判定类型：若瓦片内所有像素为同一非黑非灰颜色，则为纯色瓦片；若瓦片内含橙(7)像素且非纯色，则为精灵瓦片；其余为噪声瓦片。
3. 提取所有纯色瓦片的颜色，保持其在 4x4 瓦片阵列中的相对位置，组成一个缩小的颜色网格（仅包含纯色瓦片占据的矩形区域，裁剪到最小边界框）。例如：若纯色瓦片位于瓦片阵列的第 1~2 行、第 0~2 列，则缩小网格为 2x3。
4. 确定精灵瓦片中橙(7)精灵的朝向：定义精灵的规范朝向为 0 度。将精灵分别与规范版的 0 度、90 度顺时针、180 度、270 度顺时针旋转版比较，找到匹配的旋转角度 theta。（规范朝向在不同示例对中保持一致，需要对比多个示例才能确定哪个朝向是 0 度。）
5. 将步骤 3 得到的缩小颜色网格顺时针旋转 theta 度。
6. 输出旋转后的缩小颜色网格。输出尺寸等于旋转后的网格尺寸。

**关键洞察**：输入编码了两条独立信息——纯色瓦片编码"数据"（缩小网格的内容），精灵瓦片编码"指令"（旋转多少度）。求解者必须同时正确解码两条信息并在最后一步合并。精灵的规范朝向是跨示例的隐蔽约定，仅从单个示例无法确定。
