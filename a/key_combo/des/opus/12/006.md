## 新题 1：拓扑定向位移与重涂色

**组合逻辑**：[滑动/slide](创新：方向由拓扑决定而非固定方向) + [计数/counting] + [重涂色/recolor](创新：拓扑属性同时决定方向和后处理颜色)

**来源原语**：滑动/slide、面积决定位移/area_determines_displacement、超界裁剪/clip_beyond_edge（来自 8e301a54）；重涂色/recolor、有空洞则重涂/recolor_if_hole（来自 810b9b61）；连通分量/connected_component、封闭区域/enclosed_region（来自 810b9b61）

**依赖链**：拓扑检测（是否有空洞）同时决定两个下游参数——滑动方向和后处理颜色。面积计数独立决定位移距离。三者在同一对象上读取，但控制输出的不同维度，缺一不可。

根据每个前景对象的拓扑结构（有无空洞）决定其滑动方向，根据像素面积决定位移距离，滑动完成后按拓扑属性重涂颜色。

**输入结构**：约 14x14 的黑(0)背景网格。散布 4-6 个单色 4-连通前景对象，每个对象 3-8 像素，颜色各异（可选蓝(1)、红(2)、黄(4)、橙(7)等），形态不固定（由连通性和像素数范围定义，非特定命名形状）。部分对象内部完全包围了至少一个黑(0)像素（即有封闭空洞），其余对象是实心的（无空洞）。生成约束：所有对象互不相邻（最近像素间距至少 2 格）；每个对象按规则滑动后不会与其他滑动后的对象重叠。

**规则**：
1. 识别每个 4-连通前景对象，判断其是否包围了至少一个黑(0)背景像素（即具有封闭空洞）。
2. 实心对象（无空洞）向下滑动 N 行，其中 N = 该对象的像素数。
3. 空洞对象（有封闭空洞）向上滑动 N 行，其中 N = 该对象的像素数。
4. 滑动过程中，超出网格上下边界的像素被裁剪丢弃。
5. 滑动完成后，将所有空洞对象重涂为绿(3)，实心对象保持原色不变。
6. 处理顺序不影响结果（生成约束保证滑动后的对象互不重叠）。

**关键洞察**：拓扑属性（有无空洞）同时编码了两个独立信息——运动方向和目标颜色。面积则编码了第三个信息——位移量。三者必须从同一对象上同步读取，仅凭单个示例若所有对象恰好同为实心或同有空洞，则无法区分方向规则。

## 新题 2：轮廓分区的种子生长与二部图着色

**组合逻辑**：[轮廓描边/outline_trace](用作区域边界定义) + [生长/grow](创新：生长受轮廓约束且颜色不由种子决定) + [填充/fill] + [交替着色/alternating_coloring](创新：着色由区域邻接图的二部性决定)

**来源原语**：轮廓描边/outline_trace、外侧相邻/outer_adjacent（来自 aa62e3f4）；生长/grow（来自 758abdf0, df978a02）；交替着色/alternating_coloring、二部图结构/bipartite_structure、四邻接连通/four_neighbor_connect（来自 3bd292e8）；标记像素/marker_pixel（来自 e50d258f）

**依赖链**：轮廓线划定区域边界 → 区域邻接构建二部图 → 二部图分组决定填充颜色（灰或绿）。种子像素仅决定哪些区域被激活（不决定颜色）。三个子系统（边界、激活、着色）交互耦合。

闭合轮廓线将网格分割为多个封闭区域，种子像素激活特定区域使其被填充，但填充颜色不取决于种子自身，而由区域邻接图的二部着色方案决定。

**输入结构**：约 14x14 的黑(0)背景网格。若干条青(8)色的闭合轮廓线（1 像素宽，4-连通闭合曲线），形成非重叠的封闭区域，区域可嵌套（一个区域完全包含另一个）或相邻（共享轮廓边）。部分（非全部）封闭区域内部包含恰好一个红(2)种子像素。每条轮廓线将其内侧区域与外侧区域分隔。生成约束：轮廓线不碰触网格边缘；至少有一对相邻区域分别有种子和无种子；区域邻接图是二部图（轮廓线不会形成奇环嵌套）。

**规则**：
1. 识别所有青(8)闭合轮廓线。轮廓线将网格划分为若干 4-连通的黑(0)区域（包括最外层的外部区域）。
2. 构建区域邻接图：两个区域若共享同一段轮廓线（即隔着一层青(8)像素相邻），则连一条边。外部区域也作为一个节点。
3. 对邻接图进行二部着色：外部区域固定为 A 组，然后沿邻接边交替分配 A/B 组。
4. 包含红(2)种子像素的区域被激活：A 组激活区域填充灰(5)，B 组激活区域填充绿(3)。填充覆盖区域内所有黑(0)像素（包括种子像素位置）。
5. 不含种子的区域保持黑(0)不变，无论其属于哪一组。
6. 青(8)轮廓线像素始终保持不变。

**关键洞察**：种子的红(2)色在输出中完全消失——它仅起激活开关作用，不携带任何颜色信息。实际填充颜色（灰/绿）由区域在邻接图中的拓扑位置（奇偶层）决定。这要求同时理解三套独立系统：轮廓分区、种子激活、二部图着色。

## 新题 3：像素对中点十字放置与循环色映射连线

**组合逻辑**：[连线/connect](创新：连线被十字覆盖切断) + [放置/place](创新：放置位置由像素对中点计算) + [重涂色/recolor](创新：颜色由循环映射决定而非直接指定)

**来源原语**：放置/place、十字图案/cross_pattern、中点定位/midpoint_location、中点居中放置/center_at_midpoint（来自 e9614598）；连线/connect、同行列对齐/row_col_aligned、相邻标记间填充/fill_between_markers（来自 dbc1a6ce）；循环迁移/cyclic_migration（来自 758abdf0）；定位像素对/locator_pixel_pair（来自 e9614598）

**依赖链**：像素对几何位置 → 计算中点 → 放置十字。像素对颜色 → 循环色映射 → 决定十字颜色。像素对位置 → 绘制连接线 → 连接线被十字物理覆盖。三条信息流在中点处汇聚。

同色像素对之间绘制连接线段，并在中点放置 3x3 十字图案，十字颜色由像素对颜色的循环后继决定。

**输入结构**：约 15x15 的黑(0)背景网格。2-4 对同色像素对，每对由两个相同颜色的单像素组成。每对内的两个像素共享同一行或同一列（水平或垂直对齐），且间距为偶数（保证中点落在整数坐标）。不同对使用不同颜色，颜色取自蓝(1)、红(2)、绿(3)、黄(4)。像素对之间互不干扰：不同对的像素不共享行或列，各对中点的 3x3 十字范围互不重叠。生成约束：每对间距至少 6 格（保证中点处十字不碰触端点像素）。

**规则**：
1. 识别每对共享同一行或同一列的同色像素对。
2. 在每对的两个像素之间，沿共享的行或列绘制连接线段，颜色为该对的颜色，填充两端像素之间（不含端点）的所有黑(0)像素。
3. 计算每对的中点坐标（两个像素行坐标的平均值, 列坐标的平均值）。
4. 在每个中点放置一个 3x3 十字（加号形：中心 + 上下左右各一格）。十字颜色按以下循环映射确定：蓝(1)→红(2)，红(2)→绿(3)，绿(3)→黄(4)，黄(4)→蓝(1)。即十字颜色是对应像素对颜色的循环后继色。
5. 十字像素覆盖该位置的一切已有内容（包括连接线段），但原始端点像素保持不变。

**关键洞察**：十字的颜色不等于连接线的颜色——它是循环映射的结果。连接线被十字从中间切断，形成两段同色线段夹着一个异色十字的视觉结构。循环映射必须从多个不同颜色的示例对比归纳。

## 新题 4：墙壁分区内去噪后的种子生长与多数色冲突裁决

**组合逻辑**：[去噪/denoise](创新：去噪验证种子合法性) → [生长/grow](创新：生长受墙壁边界约束) + [填充/fill] + [邻域多数色/neighborhood_majority_color](创新：用于解决同区域多种子冲突而非缺陷修复)

**来源原语**：去噪/denoise、邻域多数色/neighborhood_majority_color、忽略干扰项/ignore_distractors、凹痕/dent（来自 de809cff）；生长/grow（来自 758abdf0, df978a02）；分隔墙线/separator_wall、背景区域/background_region、四邻接连通/four_neighbor_connect（来自 3bd292e8）；填充/fill（来自 9841fdad）

**依赖链**：去噪改变哪些种子存活 → 存活种子在墙壁约束下生长填充区域 → 当同一区域内有多个异色种子时，邻域多数色裁决填充颜色。去噪结果直接影响冲突裁决的输入。

墙壁将网格分隔为多个区域，区域内的小色块作为种子向外生长填充整个区域，但必须先去除噪声像素以免错误激活；同一区域内多个异色种子由邻域多数色规则裁决最终填充颜色。

**输入结构**：约 15x15 的灰(5)背景网格。红(2)墙壁像素形成 1 像素宽的 4-连通线段网络，将网格分割为若干 4-连通灰(5)区域。部分区域内散布着 1-3 个小色块（种子），颜色可选蓝(1)、绿(3)、黄(4)，每个色块为 1-2 个 4-连通像素。同时，网格中散布着零星的孤立噪声像素（颜色同样为蓝(1)、绿(3)或黄(4)），这些噪声像素在 4-邻域内没有同色邻居且不与红(2)墙壁 4-相邻。生成约束：至少一个区域包含两种不同颜色的种子（去噪后）；至少一个区域无种子。

**规则**：
1. 去噪：移除所有孤立噪声像素——将每个非灰(5)、非红(2)的前景像素检查其 4-邻域，若 4-邻域中没有同色像素且不与红(2)墙壁 4-相邻，则将该像素恢复为灰(5)。
2. 去噪后的存活色块即为合法种子。每个种子在其所属区域内向外生长（4-连通洪泛填充），将区域内所有灰(5)像素重涂为种子颜色，直到碰到红(2)墙壁或网格边界停止。
3. 若同一区域内有多个同色种子，直接按该颜色填充（无冲突）。
4. 若同一区域内有不同颜色的种子，冲突裁决如下：对每个种子计算其 3x3 邻域（含自身）中同色像素的数量，同色像素最多的种子颜色胜出，用该颜色填充整个区域。若仍平局，选择行坐标更小（更靠上）的种子颜色；行坐标也相同时选列坐标更小（更靠左）的。
5. 无种子的区域保持灰(5)不变。
6. 红(2)墙壁像素始终保持不变。

**关键洞察**：去噪不是可选的预处理——它决定了哪些种子存活，直接改变冲突裁决的输入。一个被错误保留的噪声像素可能使本应无种子的区域被激活，或改变多种子区域的多数色结果。去噪、生长、裁决三步环环相扣。

## 新题 5：面积排名决定变换分支——轮廓化与配对色反转

**组合逻辑**：[排序/sort](创新：排名不用于选取目标，而用于选择施加哪种变换) + [轮廓描边/outline_trace](用于最大对象) + [反转/invert] + [擦除/erase] + [配对色映射/paired_color_mapping](用于非最大对象)

**来源原语**：排序/sort、长度排名/length_ranking（来自 97d7923e）；轮廓描边/outline_trace、外侧相邻/outer_adjacent、擦除/erase（来自 aa62e3f4）；反转/invert、配对色映射/paired_color_mapping（来自 6ea4a07e）；尺寸分类/size_classification（来自 aedd82e4）；连通分量/connected_component（来自 810b9b61, aedd82e4）

**依赖链**：面积排序 → 排名产生条件分支 → 最大者走轮廓描边路径，其余走配对色反转路径。两条路径是完全不同的操作，但共享同一排名判断节点。

按面积排名将前景对象分为"最大"和"其余"两组，最大对象被替换为其外轮廓线，其余对象在各自边界框内执行配对色反转。

**输入结构**：约 12x12 的黑(0)背景网格。包含 4-5 个单色 4-连通前景对象，颜色分别从青(8)、绿(3)、灰(5)中取值。对象面积各不相同（最大者约 8-12 像素，其余约 2-6 像素），不存在面积相同的两个对象。对象形态各异（由连通性和像素数描述，非特定命名形状），互不相邻（最近像素间距至少 2 格）。最大对象无空洞（实心）。生成约束：每个非最大对象的边界框互不重叠。

**规则**：
1. 检测所有 4-连通前景对象，按像素面积从大到小排序。面积各不相同，无需 tie-break。
2. 排名第 1（面积最大）的对象执行"轮廓化"：擦除该对象的所有像素（设为黑(0)），然后将该对象外轮廓（原本与该对象 4-相邻的黑(0)背景像素）涂为该对象的原色。
3. 排名第 2 及之后的所有对象执行"配对色反转"：在每个对象的最小边界框内，将该对象的所有前景像素设为黑(0)，将边界框内所有原本为黑(0)的像素涂为配对色。配对色映射为：青(8)→红(2)，绿(3)→蓝(1)，灰(5)→黄(4)。
4. 边界框外的像素不受非最大对象变换影响。
5. 各对象独立处理，处理顺序不影响结果（边界框不重叠）。

**关键洞察**：面积排名不是对同一操作选取不同目标（如选第 k 个），而是在两种完全不同的变换（轮廓化 vs. 配对色反转）之间切换。配对色映射必须从多个示例中归纳，因为单个示例只展示一种颜色的映射。

## 新题 6：标记像素双重编码——面板选取与逐行拉伸因子

**组合逻辑**：[计数/counting](创新：计数结果同时用于选取和参数化) + [拉伸/stretch](创新：拉伸因子逐行不同，由同一标记像素编码) + [裁剪/crop]

**来源原语**：计数/counting、标记归属面板/marker_in_panel、最多标记面板输出/max_marker_panel（来自 e50d258f）；拉伸/stretch、压缩与展开/compress_expand、端点标记/endpoint_marker（来自 9841fdad）；裁剪/crop（来自 e50d258f, 73182012）；矩形面板/rect_panel、标记像素/marker_pixel（来自 e50d258f）；边缘满条/full_edge_bar（来自 758abdf0）

**依赖链**：标记像素的全局计数 → 选取目标面板 → 标记像素的逐行分布 → 决定每行拉伸因子 → 拉伸后输出。同一组标记像素在两个层级（全局和局部）上编码了不同信息。

红色标记像素的总数决定选取哪个面板，而这些标记像素在选中面板内每行的分布数量则编码了该行的拉伸倍数。

**输入结构**：约 18x18 的灰(5)背景网格。3 个互不相邻的矩形面板，每个面板由青(8)像素组成紧凑矩形块（约 5-8 行、4-6 列），面板之间由灰(5)背景分隔。面板内部由青(8)底色和嵌入的红(2)标记像素混合构成。不同面板包含不同数量的红(2)标记像素。每个面板的左侧边缘有一列完整的单色竖条（颜色非青(8)、非红(2)，可选蓝(1)、绿(3)或黄(4)），作为该面板的边缘满条，指示拉伸方向为水平向右。生成约束：标记像素最多的面板唯一确定；该面板的每行至少有 1 个红(2)标记像素，每行标记数不超过 3。

**规则**：
1. 统计每个面板中红(2)标记像素的总数，选取总数最多的面板作为目标面板。
2. 目标面板的左侧边缘满条指示拉伸方向为水平（向右拉伸）。
3. 对目标面板逐行处理：统计该行中红(2)标记像素的数量 k，该行在输出中被水平重复 k 次（即输出宽度 = 原始面板宽度 x k）。不同行的 k 值可能不同，因此输出的每行宽度取所有行最大宽度，不足的行在右侧补灰(5)背景。
4. 在输出中，红(2)标记像素被替换为青(8)（标记完成使命后消失）。
5. 边缘满条在每个重复中保留（每行左侧第一列始终是边缘满条颜色）。
6. 仅输出拉伸后的目标面板，不输出其他面板和背景。

**关键洞察**：红(2)标记像素承担双重角色——在全局层面编码"选我"信号，在局部层面编码"拉伸几倍"参数。输出中标记消失，证明它们是纯粹的元数据而非内容。

## 新题 7：空洞拓扑选面板、对称修复缺失、空洞填色后象限提取

**组合逻辑**：[计数/counting](创新：空洞数量用于面板选取而非重涂判据) + [对称补全/symmetry_completion](创新：修复面板中的缺失像素) + [填充/fill](创新：修复后新封闭的空洞被填色) + [裁剪/crop](创新：提取象限而非整体)

**来源原语**：裁剪/crop、象限/quadrant、角落象限提取/corner_quadrant_extraction、四向反射对称/four_way_reflective_symmetry（来自 73182012）；对称补全/symmetry_completion、双轴镜像对称/bilateral_mirror_symmetry、遮挡由镜像恢复/occluded_recovered_by_mirror（来自 67b4a34d）；封闭区域/enclosed_region、有空洞则重涂/recolor_if_hole（来自 810b9b61）；前景面板/foreground_panel（来自 73182012）；缺失像素补新色/missing_new_color（来自 6d75e8bb）；计数/counting（来自 e50d258f）

**依赖链**：空洞拓扑检测 → 选取目标面板 → 对称修复缺失像素 → 修复可能封闭新空洞 → 所有空洞填新色 → 提取左上象限。对称修复改变了拓扑结构（封闭原本因缺失而开放的区域），使填色操作产生修复前不存在的效果。

在多个四向对称面板中，选取包含最多封闭空洞的面板，用对称性修复其缺失像素，将修复后的所有封闭空洞填充新颜色，最终输出左上象限。

**输入结构**：约 20x20 的黑(0)背景网格，包含 3 个互不相邻的前景矩形面板。每个面板具有偶数高度和偶数宽度（约 8x8 或 10x10），由非黑(0)的前景色像素构成图案。每个面板具有四向反射对称性（上下、左右镜像），但其中一个面板有 2-4 个像素被替换为黑(0)背景色（造成对称性局部破损）。面板内的图案包含形状各异的前景结构，部分结构包围了黑(0)空洞（4-连通的黑(0)区域被前景像素完全环绕）。不同面板的空洞数量不同。生成约束：空洞数最多的面板唯一确定，且该面板恰好是有缺失像素的面板；该面板的缺失像素中至少有一个位于某结构的边界上，使得修复前该结构旁的黑(0)区域与外部连通（非封闭），修复后变为完全封闭的空洞。

**规则**：
1. 对每个面板，统计其内部严格封闭的空洞数量（4-连通黑(0)区域，所有方向被前景像素完全包围、不与面板外部黑(0)连通）。
2. 选取空洞数最多的面板作为目标面板。
3. 目标面板具有四向反射对称性（左右 + 上下镜像），但有若干像素缺失（被替换为黑(0)）。对每个缺失位置，从其水平镜像、垂直镜像或 180 度旋转对应位置中找到非黑(0)值，用该值填补缺失像素。优先使用水平镜像位置的值；若该位置也缺失，使用垂直镜像；若仍缺失，使用 180 度对应位置。
4. 修复后重新检测面板内所有封闭空洞（修复可能封闭了新的区域）。将所有封闭空洞中的黑(0)像素填充为红(2)。
5. 输出目标面板左上象限（即面板高度/2 行、宽度/2 列的左上角区域）。

**关键洞察**：面板选取基于修复前的空洞计数，但修复操作本身会创造新的封闭空洞（因为缺失像素恢复后封闭了原本与外部连通的区域）。填色操作作用于修复后的拓扑，包括这些新产生的空洞。选取、修复、填色三步形成因果链，且修复步骤改变了拓扑状态。

## 新题 8：行共线计数编码旋转角的图案复制

**组合逻辑**：[图案复制/pattern_replication](创新：旋转角度由隐式空间编码决定) + [旋转/rotate](创新：角度非由方位直接给定，而由同行标记数量编码) + [计数/counting](创新：计数对象是同行标记而非像素面积) + [重涂色/recolor]

**来源原语**：图案复制/pattern_replication、旋转/rotation、各角独立着色/per_corner_coloring、源角到目标角映射/source_to_target_mapping（来自 4c416de3）；计数/counting、面积决定位移/area_determines_displacement（来自 8e301a54——此处面积概念被替换为行共线计数）；重涂色/recolor（来自 97d7923e）；标记像素/marker_pixel（来自 e50d258f, dbc1a6ce）；同行列对齐/row_col_aligned（来自 dbc1a6ce）

**依赖链**：行共线标记计数 → 编码旋转角度 → 旋转后的图案 + 标记颜色 → 放置在标记位置。旋转角度不可直接观察，必须从多个标记的行分布中统计推断。

将源图案复制到每个标记像素位置，复制件使用标记颜色并旋转特定角度，旋转角度由与该标记同处一行的其他标记数量隐式编码。

**输入结构**：约 14x14 的黑(0)背景网格。一个灰(5)色的不对称源图案（4-连通，4-6 像素，具有明显的方向性——旋转后视觉上可区分），位于网格某个角落区域。5-8 个单像素标记散布在网格其余位置，颜色可选蓝(1)、红(2)、绿(3)、黄(4)、橙(7)（每个标记颜色可相同或不同）。生成约束：标记不位于源图案的 3x3 邻域内；每个标记以其为中心放置旋转后源图案时不超出网格边界且不与源图案重叠；同一行的标记数量范围为 1-4（即某行有 1 个标记→0 个其他同行标记，某行有 2 个标记→各有 1 个同行伙伴，以此类推）；至少存在两种不同的同行标记计数值。

**规则**：
1. 识别灰(5)源图案（唯一的多像素灰(5)连通分量）。
2. 对每个标记像素，统计与它同处一行的其他标记像素数量 n（不含自身）。
3. 旋转角度 = n x 90 度（顺时针）。n=0 → 不旋转，n=1 → 90 度，n=2 → 180 度，n=3 → 270 度。
4. 将源图案按计算的旋转角度顺时针旋转后，以标记像素为中心放置。放置时使用标记像素的颜色替换灰(5)。
5. 标记像素自身被复制件的中心像素覆盖。源图案保持灰(5)不变。
6. 若多个复制件存在像素重叠，按标记像素从左到右、从上到下的顺序处理，后处理的覆盖先处理的。

**关键洞察**：旋转角度没有任何直接的视觉标记——它完全由同行标记的空间分布隐式编码。求解者必须注意到不同行的标记数量与图案旋转角度之间的对应关系，这需要对比多个示例才能归纳。同一行有多个标记时，它们互相影响彼此的旋转角度（因为彼此计为对方的同行伙伴）。
