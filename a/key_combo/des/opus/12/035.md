## 新题 1：方向截断包络

**组合逻辑**：[朝向推断(dir_inference)](创新：从缺角推断方向改为从不对称标记推断方向) + [包络生成(envelope_generation)](创新：全菱形截断为半菱形) → 耦合点：推断出的方向决定菱形包络的保留半侧

**来源原语**：朝向推断/缺角指示方向(6e19193c)、包络生成/逐步收缩/菱形轮廓(c97c0139)、实心条(c97c0139)

**依赖链**：方向推断的输出直接作为包络生成的几何裁剪参数——方向决定保留哪半侧菱形，删去方向推断则菱形全对称（错误），删去包络生成则方向推断无处施展（无输出）。

将每根条状前景对象的不对称端标记解读为方向指示，仅在该方向一侧绘制逐步收缩的半菱形包络。

**输入结构**：
- 黑(0)背景网格，约 15x15。
- 网格中散布 2~4 根一像素宽的实心条（水平或垂直），每根长度 5~9 像素，颜色为蓝(1)。
- 每根条的恰好一个端点处，有一个灰(5)像素位于该端点的垂直于条方向的 4-邻接位置（例如：水平条的左端点正上方一格有灰像素，则该条从左端向右方向指向）。灰像素始终只出现在条的一端，另一端无灰像素。
- 生成约束：各条的完整菱形包络（含半径 floor((L-1)/2)）互不重叠；灰标记像素不与其他条或标记相邻。

**规则**：
1. 对每根蓝(1)条，确定其方向：方向定义为**从灰标记所在端指向无标记端，并继续向前延伸**。即灰标记标注"尾部"，方向指向"头部"方向。
2. 以该条为中轴，按源题 c97c0139 的规则计算完整菱形包络——中轴两侧每远离一行/列则缩短一像素，总半径 R = floor((L-1)/2)。
3. 仅保留位于条的**头部一侧**（含中轴本身）的包络像素，头部一侧定义为：以条的几何中心为分界，沿方向矢量方向的那半平面内的所有包络像素。对于水平条向右指向的情况，保留中心列及其右侧的包络像素；对于垂直条向下指向的情况，保留中心行及其下方的包络像素。以此类推。
4. 保留的包络像素涂青(8)，仅涂在背景(0)像素上。
5. 原始蓝条像素和灰标记像素保持不变。
6. 各条独立处理，处理顺序不影响结果（生成约束保证包络互不重叠）。

**关键洞察**：灰像素不是缺陷也不是装饰——它打破了条的对称性，标识了"尾端"，从而将本应全对称的菱形包络截断为一侧的半菱形。需要对比多个示例（不同方向的条）才能归纳出灰像素与截断方向之间的反向关系。

## 新题 2：重力沉降入格栅分区变色

**组合逻辑**：[滑动/重力沉降(gravity_settling)] + [分区涂色(zone_coloring)/按边界框内外分色(color_by_bounding_box_membership)] → 耦合点：沉降的落点位置决定像素变色规则，落点依赖于格栅的几何布局

**来源原语**：滑动/重力沉降/前景像素/基线行(3618c87e)、间隙填充/分区涂色/块阵列/网格沟槽/边界框/内部与外部沟槽(137f0df0)

**依赖链**：重力沉降确定每个像素的终点坐标，分区涂色根据终点是否在块阵列边界框内部决定像素的输出颜色。二者通过"落点坐标"这一中间量紧耦合——不执行重力沉降则不知落点在哪个区、不知分区规则则沉降后颜色不确定。

将悬浮的彩色像素沿列下沉至格栅沟槽中，根据落点属于格栅内部沟槽还是外部延伸沟槽来决定像素的最终颜色。

**输入结构**：
- 黑(0)背景网格，约 15x20（15列20行）。
- 网格下半部分（约第 10~18 行）包含灰(5) 2x2 块组成的矩形格栅阵列，块间以 1 像素宽的黑色沟槽分隔。格栅的块阵列边界框不覆盖整个网格宽度——左右各留 2~3 列的外延沟槽区。
- 网格上半部分（第 0~8 行）散布 4~6 个橙(7)单像素，每个橙像素所在列恰好对应某条垂直沟槽的列坐标（即该列在格栅区域内是沟槽，不会被块占据）。不同像素位于不同列。
- 生成约束：每个橙像素的正下方列路径上无灰块阻挡（橙像素对齐沟槽列），保证每个像素都能沉降到格栅底部或网格底部。

**规则**：
1. 每个橙(7)像素沿其所在列向下移动，直到到达该列最低的空背景格（即该列中最靠底部的黑(0)格），遵循重力沉降规则。
2. 确定落点坐标后，判断该坐标是否在灰块阵列的边界框内部（边界框 = 所有灰块的最小外接矩形）：
   - 若落点在边界框**内部**的沟槽格：将该像素涂为红(2)。
   - 若落点在边界框**外部**的沟槽延伸格（与沟槽同行或同列，但列坐标超出边界框左右范围）：将该像素涂为蓝(1)。
   - 若落点在格栅区域的上方（即该列沟槽上方的空白区，像素因无更低空格而停留在格栅上方）：保持橙(7)不变。
3. 灰块保持不变，其余背景像素保持黑(0)。
4. 各像素独立沉降，互不干扰（生成约束保证不同像素在不同列）。

**关键洞察**：同为橙色的像素在沉降后变成不同颜色，其最终颜色完全取决于落点所在列是否在块阵列边界框内——这是一个仅通过多个示例对比（观察不同列的落点颜色差异）才能归纳出的隐蔽规则。

## 新题 3：压缩帧序列后外推运动

**组合逻辑**：[压缩/网格采样(downscale/grid_sampling)] → [外推/匀速运动延续(extrapolate/constant_motion)] → 耦合点：压缩揭示了在原始分辨率下被尺寸差异掩盖的运动模式，外推基于压缩后的模式进行，再反向放大为全尺寸输出

**来源原语**：压缩/矩形分区/网格采样/每分区缩为单像素(90c28cc7)、外推/帧序列/内部精灵/等间距排列/匀速运动延续(ba1aa698)、平移(ba1aa698)

**依赖链**：压缩是外推的前提——原始分辨率下分区尺寸不均，颜色变化规律被几何失真掩盖，只有先压缩到每分区一像素才能看到一个像素沿某方向匀速移动的简单模式；外推在压缩域执行后必须反向还原到原始分区尺寸。

在一组由不等尺寸分区构成的帧面板中，先将每帧压缩为每分区一像素的小网格，发现压缩域中某像素的匀速位移，外推一步后放大回原始分区几何。

**输入结构**：
- 黑(0)背景网格，总尺寸约 8x30（8行30列）。
- 网格被灰(5)竖线均匀分割为 3 个等宽帧面板（每帧约 8x9 的内容区，帧之间共享 1 列灰边框）。
- 每帧内部是一个 3x3 的分区网格（3 行 3 列的矩形子区域），分区之间无间隔但各分区的宽高不同（例如第一列分区宽 2 像素、第二列宽 4 像素、第三列宽 3 像素；行高类似不均匀）。每个分区内所有像素同色。
- 3 帧中的分区几何布局完全相同（同样的行高和列宽划分方式），分区颜色也大部分相同，但恰好有一个分区的颜色在 3 帧中沿某方向平移了一格（例如：第 1 帧中 (0,0) 分区为红(2)其余为黄(4)，第 2 帧中 (1,1) 分区为红(2)其余为黄(4)，第 3 帧中 (2,2) 分区为红(2)其余为黄(4)——红色沿对角线每帧移动 (+1,+1)）。
- 由于分区尺寸不等，在原始像素层面红色区域的面积和形状逐帧变化，不易直接看出匀速位移模式。

**规则**：
1. 识别每帧中的分区边界：找出所有分区（4-连通同色矩形区域），按其左上角的行列坐标排序，建立行号和列号映射。
2. 对每帧执行压缩：将每个分区缩为一个像素，得到一个 3x3 的小网格。
3. 在 3 个压缩后的 3x3 小网格序列中，找到颜色逐帧变化的像素及其位移向量 (dr, dc)。
4. 外推一步：在 3x3 压缩域中将变化像素按位移向量再移一步，得到第 4 帧的 3x3 压缩网格。若外推位置超出 3x3 边界，则该像素消失（变为其余分区的底色）。
5. 将第 4 帧的 3x3 压缩网格按照与输入帧相同的分区几何（相同的行高和列宽）放大回全尺寸，作为独立输出帧（无共享边框，仅输出内容区）。

**关键洞察**：分区尺寸不等是刻意的干扰——在像素级别看到的红色区域面积忽大忽小、形状各异，但压缩到分区级别后就是简单的单像素匀速直线运动。不先压缩就无法发现运动规律。

## 新题 4：线路锚定的对称补全

**组合逻辑**：[传输/端点配对(transmit/endpoint_pairing)] + [对称补全/对称轨道(symmetry_completion/symmetry_orbit)] → 耦合点：线路传输的颜色填充部分遮挡像素，填充后这些像素成为对称补全的可见锚点，使得原本因双侧遮挡而无法推断的像素变为可推断

**来源原语**：传输/线路网络/端点配对(a47bf94d)、对称补全/遮挡像素/对称图案/对称轨道/反射旋转定颜色(f9d67f8b)

**依赖链**：线路传输和对称补全互为前提的一部分——线路提供的颜色信息弥补了对称轨道中两个位置都被遮挡的"死锁"情况，而对称补全反过来验证了线路传输的颜色正确性。两步不能独立完成任务：仅靠对称有死锁像素无法求解，仅靠线路只能填一部分遮挡像素。

在一个被部分遮挡的对称图案中，通过灰色线路从远端彩色源像素传输颜色来修复"死锁"遮挡点，再用对称性补全剩余遮挡点。

**输入结构**：
- 黑(0)背景网格，约 17x17。
- 网格中心区域（约 9x9）包含一个具有水平和垂直反射对称性（反射轴可能偏移，即不一定过中心点）的多色图案，使用蓝(1)、红(2)、绿(3)、黄(4)。
- 图案中有 4~6 个像素被栗(9)色遮挡。其中大部分遮挡像素可通过水平或垂直反射从可见的对称伙伴推断颜色，但恰好 2 个遮挡像素的所有对称伙伴也被遮挡（"死锁对"）。
- 从每个死锁遮挡像素出发，有一条灰(5)单像素宽的直线（水平或垂直）延伸到图案外部，直线末端（网格边缘附近）有一个彩色源像素，其颜色就是该死锁像素应有的颜色。
- 非死锁遮挡像素没有线路连接。
- 生成约束：反射轴位置使得非死锁遮挡像素至少有一个可见的对称伙伴；灰线路不穿过图案中的其他非背景像素。

**规则**：
1. 识别栗(9)色遮挡像素。
2. 识别灰(5)线路：每条线路从某个遮挡像素出发，沿直线（上/下/左/右）到达一个非灰非黑的彩色源像素。
3. 对于有线路连接的遮挡像素（死锁像素）：将其颜色替换为线路末端源像素的颜色。移除灰线路像素（恢复为黑(0)背景）。移除源像素（恢复为黑(0)背景）。
4. 对于无线路连接的遮挡像素（非死锁像素）：通过水平反射或垂直反射找到其可见的对称伙伴，将遮挡像素替换为伙伴的颜色。若水平和垂直反射均有可见伙伴，两者颜色必然一致（由对称性保证）。
5. 步骤 3 必须在步骤 4 之前执行：因为步骤 4 中有些遮挡像素的对称伙伴恰好是步骤 3 中刚修复的死锁像素。即线路修复的结果成为后续对称推断的输入。

**关键洞察**：线路不是独立的传色机制——它精准修复了对称性推断的死锁。如果仅靠对称性，死锁对无法求解；如果仅靠线路，非死锁像素无法修复。两者严格互补，且有执行顺序依赖。

## 新题 5：柱高选行 + 柱色重涂种子

**组合逻辑**：[排序/高度排序(sort/height_ordering)] + [重涂色(recolor)] + [裁剪(crop)] → 耦合点：排序确定行的输出顺序，柱高值选择种子图案中的特定行，柱色决定被选行的重涂颜色

**来源原语**：排序/柱状条/基线/高度排序/槽位保持颜色(31f7f899)、重涂色(ba26e723/e048c9ed)、种子图案(9b30e358)、裁剪(2013d3e2)

**依赖链**：三重耦合——(1) 柱高度数值选择种子图案中哪一行被提取，(2) 柱的左右排序决定被选行在输出中的堆叠顺序，(3) 柱颜色覆盖被选行的前景色。三个信息通道（高度、位置、颜色）从同一组柱状条中提取，缺一不可。

从一组不同高度和颜色的柱状条中读取三重编码信息：高度 = 种子图案中的行索引，左右位置 = 输出行的堆叠顺序，颜色 = 该行前景像素的重涂色。

**输入结构**：
- 黑(0)背景网格，约 12x15。
- 网格分为左右两个区域，以一列灰(5)竖线分隔：
  - **左区（种子图案区）**：底部靠左排列一个由多色像素构成的矩形种子图案，高 H 行（H 约 5~7），宽 W 列（W 约 4~6）。种子图案中包含黑(0)背景像素和若干前景色像素（可能有多种颜色，但具体颜色不重要，因为会被重涂）。种子图案的底边与网格底边对齐。
  - **右区（柱状条区）**：底部有一行橙(7)基线横跨右区全宽。基线上方有 N 根柱状条（N = 3~4，N < H），每根柱状条宽 1 像素，颜色各不相同（从蓝(1)、红(2)、绿(3)、黄(4)中选），高度各不相同且都在 1~H 之间。柱间隔 1~2 列黑色。
- 生成约束：N 根柱的高度值互不相同，且每个高度值都在 [1, H] 范围内（合法行索引）。

**规则**：
1. 读取右区每根柱的三个属性：高度 h（像素数，不含基线）、列位置 x（在右区内从左到右排序）、颜色 c。
2. 按柱的列位置从左到右排序，确定输出的行堆叠顺序：最左柱对应的行放在输出最上方，最右柱对应的行放在输出最下方。
3. 对于排序后的第 i 根柱（高度 h_i，颜色 c_i）：从种子图案中提取第 h_i 行（从底部起计，1-索引：h_i=1 表示种子图案最底行，h_i=H 表示最顶行）。
4. 将提取出的行中所有非黑(0)前景像素的颜色替换为 c_i，黑色背景像素保持黑色。
5. 将 N 个经过重涂的行上下堆叠，形成一个 N 行 x W 列的输出网格。

**关键洞察**：柱状条是三通道信息的编码器——高度不是装饰而是行选择索引，颜色不是分类标签而是重涂指令，空间位置不是随机的而是堆叠顺序。必须同时解码三个通道才能正确求解。

## 新题 6：线段长度编码间隙填充色

**组合逻辑**：[间隙填充/补全(gap_fill/completion)] + [计数(counting)] + [重涂色(recolor)/固定编码表(fixed_encoding)] → 耦合点：填充颜色不是固定的，而是由缺口相邻完好线段的长度经编码表映射决定

**来源原语**：间隙填充/补全/网格线/缺口/行列对齐/相邻像素标有效线/缺口补另色(4612dd53)、计数/条形段/长度映射颜色/固定编码表(e048c9ed)、重涂色(ba26e723)

**依赖链**：间隙填充需要知道填什么颜色→颜色由计数决定→计数的对象是缺口两侧完好线段→线段的识别又依赖间隙填充中的网格线检测逻辑。三者形成闭合依赖环，必须在同一框架内求解。

在断裂的蓝色网格线中，每个缺口的填充颜色取决于其相邻完好线段的长度——通过固定编码表将长度映射为颜色。

**输入结构**：
- 黑(0)背景网格，约 15x15。
- 蓝(1)像素构成一个不完整的直线网格：若干水平线和若干垂直线，交叉处可能有共享蓝像素。
- 每条网格线由若干完好线段（连续蓝像素）和缺口（连续黑像素）交替组成。完好线段长度在 2~5 像素之间。缺口长度均为 1 像素。
- 有效网格线的判定标准与源题 4612dd53 一致：某行是有效水平线，当且仅当该行存在至少一对水平相邻的蓝像素；某列是有效垂直线，当且仅当该列存在至少一对垂直相邻的蓝像素。
- 缺口仅出现在有效线上，且每个缺口的两侧（沿线方向）都至少有一个完好线段。
- 生成约束：每个缺口仅位于一条有效线上（不位于两条有效线的交叉点）；每个缺口两侧的完好线段长度相同（无歧义——不需要"取较短"的仲裁规则）。

**规则**：
1. 识别有效水平线和有效垂直线（用相邻像素对检测法）。
2. 在每条有效线上，找到所有长度为 1 的缺口（缺口 = 该线上连续的黑像素，且两侧各有至少 1 个蓝像素）。
3. 对每个缺口，测量其任一侧紧邻的完好蓝线段长度 L（生成约束保证两侧相同）。
4. 按固定编码表将 L 映射为填充颜色：L=2 → 红(2)，L=3 → 绿(3)，L=4 → 黄(4)，L=5 → 灰(5)。
5. 将缺口像素涂为映射得到的颜色。
6. 所有蓝像素和非缺口黑像素保持不变。

**关键洞察**：缺口的填充色不是统一的——它是由相邻线段长度通过隐蔽的编码表决定的。需要对比多个示例中不同长度线段旁的缺口颜色，才能归纳出长度→颜色的映射关系。仅看一个示例，可能以为所有缺口填同一种颜色。

## 新题 7：叠加合并后密度触发洪泛

**组合逻辑**：[透明叠加/标记无冲突合并(overlay/markers_merge)] → [计数(counting)] → [洪泛填充(flood_fill)] → 耦合点：叠加合并改变了标记像素的空间分布，使得某些行的标记密度越过阈值，触发该行的洪泛填充；单个源矩形中没有任何行越过阈值

**来源原语**：透明叠加/填充矩形/标记像素/共享底色/同尺寸对齐/标记无冲突合并(25e02866)、计数/条形段(e048c9ed)、洪泛填充(551d5bf1)

**依赖链**：叠加合并是密度计数的前提（单个矩形中标记稀疏，不越阈值），密度计数是洪泛触发的前提（不计数则不知哪些行该填），洪泛填充是最终输出的产生者。三步中删任一步都无法得到正确输出。且该链条具有涌现性——单个源矩形中所有行的标记数都 <= 1，合并后某些行出现 >= 2 个标记才触发洪泛，这是单看任一源矩形都无法预见的效果。

将多个相同尺寸的矩形按局部坐标叠加合并标记像素，然后对合并结果中标记密度达到阈值的行执行洪泛填充。

**输入结构**：
- 黑(0)背景网格，约 12x18。
- 网格中散布 2~3 个相同尺寸的矩形（例如 5 行 x 6 列），各矩形互不重叠。每个矩形由黄(4)填充，边界也是黄色（实心矩形）。
- 每个矩形内部含有 1~3 个蓝(1)标记像素（单像素），位于矩形内的不同行列位置。
- 各矩形中的标记像素按局部坐标（相对于矩形左上角的行列偏移）不冲突——即合并后同一局部坐标最多有一个标记（或多个标记颜色相同）。
- 生成约束：每个单独矩形中，任意一行最多含 1 个标记像素；但合并后至少有一行包含 2 个或更多标记像素。

**规则**：
1. 识别所有矩形对象（同尺寸、同底色黄(4)的实心矩形）。
2. 将所有矩形的标记像素（蓝(1)）按局部坐标叠加到一个相同尺寸的合并矩形上，底色为黄(4)。
3. 在合并矩形中，逐行统计蓝标记像素数量。
4. 对于标记数 >= 2 的行：将该行内所有黄(4)像素替换为青(8)，蓝(1)标记保持不变。即对该行内的黄色区域执行洪泛填充。
5. 对于标记数 < 2 的行：保持原样（黄底 + 可能的零或一个蓝标记）。
6. 输出仅包含合并后的矩形（裁剪到矩形尺寸），不包含原始输入中的分散矩形。

**关键洞察**：洪泛填充的触发条件（某行标记数 >= 2）在任何单个源矩形中都不成立——只有合并后才会出现。这是一个"涌现"效应：叠加行为本身创造了触发洪泛的前提条件。需要对比多个示例才能确定阈值为 2。

## 新题 8：菱形包络约束下的帧内运动外推

**组合逻辑**：[包络生成/逐步收缩(envelope_generation/stepwise_shrink)] + [外推/匀速运动延续(extrapolate/constant_motion)] → 耦合点：菱形包络定义了精灵体的运动边界——精灵体在包络内做匀速直线运动，碰到包络边界时发生镜面反射；外推需要理解包络几何才能正确预测反射后的位置

**来源原语**：包络生成/实心条/菱形轮廓/中心对称/逐步收缩(c97c0139)、外推/帧序列/内部精灵/等间距排列/匀速运动延续(ba1aa698)、平移(ba1aa698)

**依赖链**：包络生成定义了运动的边界约束，外推定义了运动的趋势延续——在无碰撞帧中二者可独立工作（包络是装饰、运动是直线），但在碰撞帧中二者紧耦合：反射方向由包络边界的局部法线决定，外推位置由反射后的新速度向量决定。不理解包络就无法预测反射。

在帧序列中观察一个精灵体在菱形包络内做匀速运动，碰到菱形边界时镜面反射，外推下一帧的精灵体位置。

**输入结构**：
- 黑(0)背景网格，总尺寸约 9x28。
- 网格被灰(5)竖线均分为 4 个等宽帧面板（每帧约 9x6 的内容区，帧间共享 1 列灰边框）。
- 每帧中心包含一根水平蓝(1)条（长 5 像素，固定在每帧的正中间行），该条的菱形包络用青(8)绘制（半径 R=2，即中轴上下各延伸 2 行，每行比上一行短 1 像素）。蓝条和青包络在 4 帧中完全相同，是静态背景。
- 每帧中有一个红(2)单像素精灵体，位于菱形包络（含蓝条本身）围成的区域内部的某个背景(0)位置上。
- 精灵体在 4 帧中的位置表现为匀速直线运动（位移向量恒定，例如每帧 (+1, +1)），但在第 3 或第 4 帧中可能观察到一次方向改变——这是碰到菱形边界后发生了镜面反射。
- 生成约束：精灵体始终在菱形内部的背景格上（不与蓝条或青包络重叠）；4 帧中至多发生一次反射，保证规律可从 4 帧归纳。

**规则**：
1. 识别每帧中红(2)精灵体的位置（帧内局部坐标）。
2. 计算相邻帧间的位移向量：(dr, dc) = (r_{i+1} - r_i, c_{i+1} - c_i)。
3. 若所有位移向量相同，则精灵体尚未碰壁——直接用该向量外推第 5 帧位置。
4. 若观察到位移向量在某两帧间发生变化，识别为碰壁反射：
   - 碰到菱形的上斜边或下斜边（斜率为 +-1 的边）：行速度取反，列速度不变。
   - 碰到菱形的左端或右端（最尖角点）：列速度取反，行速度不变。
   - 反射后速度向量在剩余帧中保持恒定。
5. 用最近的稳定速度向量外推第 5 帧的精灵体位置。若外推位置恰好落在包络边界上，则再次执行反射并放置在反射后一步的位置。
6. 输出一个独立帧（与输入帧同尺寸，有灰边框），包含相同的蓝条、青包络和外推后的红精灵体。

**关键洞察**：菱形包络不是装饰——它是运动的"弹球台"边界。多数帧中精灵体做简单直线运动（看起来只需外推），但碰壁帧揭示了反射规则。需要至少一个包含反射的示例才能归纳出包络的约束作用。

## 新题 9：十字分隔去噪 + 象限旋转拼贴

**组合逻辑**：[压缩/去噪取主色(compress/denoise_majority)] + [旋转(rotate)/旋转对称(rotational_symmetry)] → 耦合点：去噪确定每个象限的纯净主色，但输出不是直接压缩为 3x3，而是将四个去噪后的象限按旋转对称规则重新排列——只有一个象限是"源瓦片"，其余三个必须是它的 90/180/270 度旋转

**来源原语**：压缩/十字分隔线/四象限/主色代表区域/去噪取主色/忽略干扰项(996ec1f3)、旋转/精灵体/象限/旋转对称/提取原始瓦片(2013d3e2)、裁剪(2013d3e2)

**依赖链**：去噪和旋转拼贴互相约束——去噪后四个象限应当满足旋转对称关系，但噪声干扰下可能有多个"候选主色"，此时旋转对称关系提供额外约束来消歧（选择使四象限构成旋转对称的那组主色分配）。

在一个被十字分隔的四象限网格中，去除噪声找到每个象限的主色图案，然后识别哪个象限是源瓦片并输出该源瓦片。

**输入结构**：
- 黑(0)背景网格，约 13x13（奇数边长以容纳十字中轴线）。
- 一条完整的水平行和一条完整的垂直列颜色为灰(5)，构成十字分隔线，将网格分为四个矩形象限（均为 6x6）。
- 每个象限内部包含一个小图案（约 3x3~4x4 的非黑像素区域），图案使用蓝(1)、红(2)、绿(3)等颜色。四个象限的图案之间具有旋转对称关系：左上象限的图案旋转 90 度顺时针 = 右上象限的图案，旋转 180 度 = 右下象限的图案，旋转 270 度顺时针（= 90 度逆时针）= 左下象限的图案。
- 每个象限中除了主图案外，还散布 2~4 个干扰噪声像素（颜色可能与图案色相同或不同），这些噪声像素不属于图案的旋转对称结构。
- 生成约束：噪声像素不落在图案像素的 4-邻接位置（与图案不直接相邻），使得图案可通过连通性与噪声区分；四个象限的图案旋转关系是精确的（无噪声像素落在图案的旋转映射位置上）。

**规则**：
1. 找到灰(5)十字分隔线，确定四个象限的边界。
2. 在每个象限内，将非黑非灰像素按 4-连通分组，最大的连通分量为图案，其余孤立或小连通分量为噪声。移除噪声像素（恢复为黑(0)）。
3. 验证旋转对称关系：将左上象限的去噪图案旋转 90/180/270 度，分别与右上/右下/左下象限的去噪图案比较。如果某个象限的图案与预期不一致（说明噪声移除不当），调整该象限的连通分量选择直至旋转对称成立。
4. 确认旋转关系后，输出左上象限的去噪图案（裁剪到图案的边界框），即源瓦片。

**关键洞察**：单独看一个象限时可能有多种方式区分"图案"与"噪声"（特别是当噪声连通分量与图案大小接近时），旋转对称约束提供了跨象限的全局一致性检验——正确的去噪方案是使四个象限构成精确旋转对称的那一种。

## 新题 10：头序列对角填充 + 周期列变色

**组合逻辑**：[缩放/循环头序列倍增(scaling/cyclic_header_doubled)/对角索引映射(diag_index_map)] + [重涂色/周期列触发变色(recolor/periodic_column_triggers_recolor)] → 耦合点：对角索引填充确定每个格子的基础颜色，周期列规则在此基础上对特定列的格子进行变色——变色的结果覆盖对角填充的结果，使得输出既不是纯对角填充也不是纯周期变色

**来源原语**：头序列/对角索引映射/循环头序列倍增(539a4f51)、重涂色/列周期/周期列触发变色(ba26e723)、缩放(539a4f51)

**依赖链**：对角索引填充生成底图，周期列变色在底图上叠加修改。但二者的耦合不是简单的"先做 A 再做 B"——周期变色的目标颜色不是固定的，而是由头序列中对应周期列位置的颜色经过一次固定颜色映射得到。即变色规则本身也来自头序列。

将一个方阵的头序列循环扩展并按对角索引规则填充更大方阵，然后将周期列位置上的所有格子颜色替换为该列头序列颜色的映射色。

**输入结构**：
- 输入为一个方阵，边长 N（N 约 4~6）。
- 顶行和左列是相同的头序列，包含 K 个非黑颜色后跟 (N-K) 个黑(0)尾缀（K 约 3~4）。
- 每个格子 (r, c) 的颜色 = 头序列在索引 max(r, c) 处的颜色（与源题 539a4f51 一致）。
- 输入中还包含一个额外信息：方阵右下角的 1x2 区域（最后一行最后两列）包含两个特殊颜色像素 A 和 B（不同于头序列中任何颜色，也不同于黑色），表示周期列映射规则：头序列颜色 → A 或 B（具体映射需从示例归纳）。

**规则**：
1. 从输入方阵中提取头序列（顶行前 K 个非黑颜色）。
2. 将头序列循环扩展至长度 2N：重复 K 个颜色直到达到 2N 长度。
3. 构造 2N x 2N 方阵：每个格子 (r, c) 的颜色 = 扩展后头序列在索引 max(r, c) 处的颜色。
4. 识别周期列：列号满足 col % 3 == 0 的所有列（列 0, 3, 6, ...）。
5. 对周期列上的每个非黑格子，将其颜色替换为品红(6)。
6. 输出 2N x 2N 方阵。

**关键洞察**：输出的"条纹感"来自两个独立规律的叠加——对角索引规则产生阶梯状色带，周期列变色产生竖直条纹。单看一个规律都无法解释完整输出。周期 3 的列变色规则需要对比多个示例（不同 N 值产生不同的周期列位置）才能确认。
