## 新题 1：多源并发生长与拓扑间隙分类

**组合逻辑**：[生长(grow)](创新：多源同步扩展，冲突像素生成新障碍) + [连通分量检测(connected_component_detection)] + [重涂色(recolor) + 拓扑分类(topological_classification)]（标注：生长为创新改造，冲突标记机制为新增；连通分量检测、拓扑分类为已有原语直接使用）

**来源原语**：生长/同心方框层/种子像素(5c2c9af4)、连通分量检测/边界可达性/拓扑分类(84db8fc4)、重涂色(多源)

**依赖链**：多源同步生长产生领地划分与冲突标记 → 冲突标记与原始障碍共同界定背景间隙的连通结构 → 对间隙进行拓扑分类（是否可达网格边缘）→ 分类结果决定间隙涂色。冲突标记是生长的涌现产物，它改变了拓扑结构：若无冲突标记，某些间隙可能与边界相通；有了冲突标记，这些间隙被封死变为内陷区域。

从多个种子同步向外逐层生长，生长冲突产生新的障碍像素，最终对残留的背景间隙按是否可达网格边界进行拓扑分类并涂色。

**输入结构**：约 15x15 的黑(0)背景网格。网格上散布 3~5 段灰(5)短线段（每段 2~4 像素，水平或垂直），作为初始障碍。另有 2~3 个种子像素，每个种子颜色不同（从红(2)、绿(3)、蓝(1)中选取），彼此不相邻，且不与灰障碍相邻。生成约束：种子位置和障碍布局保证生长过程中至少产生 2 个冲突像素，且最终残留的黑(0)间隙中至少有 1 个可达边界、至少有 1 个被完全封闭。

**规则**：
1. 所有种子同步向外生长。每一步中，每个种子的生长前沿向外扩展一层（曼哈顿距离加一），试图占据所有 4-邻接的黑(0)背景像素。已被占据的像素（障碍、其他种子领地、其他种子本身）不可被占据。
2. 若同一步中有两个或更多种子同时试图占据同一个黑(0)像素，该像素不归属任何种子，而被标记为灰(5)——与初始障碍同色，成为新的障碍像素。
3. 生长持续进行，直到所有种子都无法再扩展为止。
4. 生长完成后，识别网格中所有残留的黑(0)像素，将它们按 4-连通划分为若干连通区域。
5. 对每个黑(0)连通区域判断拓扑类别：若该区域中至少有一个像素位于网格最外圈（第 0 行、最后一行、第 0 列或最后一列），则该区域为"边缘可达区域"，将其所有像素重涂为橙(7)；否则该区域为"封闭区域"，将其所有像素重涂为黄(4)。
6. 所有灰(5)像素（原始障碍 + 冲突标记）、种子像素、生长占据的像素均保持不变。

**关键洞察**：冲突标记是多源生长的涌现产物而非输入的一部分——它们可以封堵原本通向网格边界的路径，从而将本应是边缘可达的间隙变为封闭区域。求解者必须先完成生长（含冲突解决），才能判断哪些间隙是封闭的。

## 新题 2：图元分解计数驱动的枢轴旋转与形状涂色

**组合逻辑**：[分解(decompose)] → [计数(counting)](创新：分解产物的数量编码旋转角度) → [旋转(rotate) + 绕点旋转(rotation_around_pivot)] → [重涂色(recolor) + 图元形状决定涂色(shape_determines_color)]（标注：分解、重涂色/图元涂色为已有原语；计数到旋转角的映射为创新；枢轴旋转为已有原语在新上下文中使用）

**来源原语**：分解/基本图元/图元形状决定涂色(150deff5)、旋转/枢轴标记/绕点旋转/顺时针四分之一圈(c074846d)、计数(445eab21)

**依赖链**：分解得到图元集合 → 每个复合体的图元计数 C 决定旋转角度 90°×C → 各图元绕其复合体的枢轴逐个旋转 → 旋转后的图元根据几何形状（方块或长条）获得最终颜色。删除分解则无法计数；删除计数则旋转角度未知；删除旋转则位置错误；删除形状涂色则输出无法区分方块与长条。

将灰色复合体分解为方块和长条图元，以每个复合体的图元数量决定旋转角度，各图元绕枢轴旋转后按形状涂色。

**输入结构**：约 14x14 的黑(0)背景网格。包含 2~3 个灰(5)复合体，每个复合体是若干 2x2 方块和 1x3（或 3x1）矩形通过边对边拼接而成的连通区域（4-连通，3~6 个基本图元组成，总像素数 9~20）。每个复合体恰好有一个红(2)枢轴标记像素与之 4-邻接（位于复合体外侧某边缘处）。各复合体（含其枢轴）的边界框互不重叠。生成约束：每个复合体的图元分解方式唯一；各图元旋转后不超出网格边界，且不同复合体旋转后的图元互不重叠。

**规则**：
1. 对每个灰(5)复合体，进行唯一的非重叠分解：将其拆分为若干 2x2 方块和 1x3/3x1 矩形。
2. 计算每个复合体分解得到的基本图元总数 C。
3. 将该复合体的每个图元绕其枢轴标记像素顺时针旋转 90°×C。若 C=1 则旋转 90°，C=2 则旋转 180°，C=3 则旋转 270°，C=4 则旋转 360°（回到原位）。旋转以枢轴像素为中心，图元的每个像素坐标相对于枢轴做标准二维旋转。
4. 清除原始灰(5)像素。在旋转后的位置绘制图元：每个 2x2 方块涂为青(8)，每个 1x3/3x1 矩形涂为绿(3)。
5. 枢轴标记像素保持红(2)不变。

**关键洞察**：同样由 3 个图元组成的两个复合体会旋转相同角度，但不同图元数量的复合体旋转角度不同——求解者必须先正确分解才能知道旋转角，而非直接观察复合体的整体外形。需要对比多个示例来确认"图元计数决定旋转角"这一隐蔽映射。

## 新题 3：旋转归一化下的瓦片多数投票修复

**组合逻辑**：[旋转(rotate) + 旋转对应(rotational_match)](创新：用于检测并归一化不同朝向的瓦片副本) + [修复异常(repair) + 多数投票共识(majority_vote)] + [重涂色(recolor) + 受损副本被标记(damaged_marked)]（标注：旋转对应从图案恢复场景改造为瓦片朝向检测；多数投票修复与受损标记为已有原语；两者的前后依赖关系为创新）

**来源原语**：旋转/旋转对应/半周旋转恢复(ff805c23)、修复异常/重复图块/分隔网格/多数投票共识/受损副本被标记(e84fef15)、重涂色(多源)

**依赖链**：旋转检测与归一化必须先于多数投票——未归一化的瓦片像素不对齐，直接投票会产生错误共识。归一化后投票得到正确图案 → 对比找出受损瓦片 → 标记受损像素。这是一个同时约束问题：旋转检测本身依赖瓦片间的相似性比对，而相似性比对的前提是知道哪些像素对应——两者需同步求解。

在包含旋转副本的瓦片格阵中，先检测并归一化各瓦片的旋转朝向，再通过多数投票修复唯一受损副本，输出共识图案并以蓝色标记受损位置。

**输入结构**：一个由品红(6)单像素宽分隔线划分的格阵，包含 6~9 个等大小方形区块（如每块 4x4 或 5x5），排列为 2x3 或 3x3 矩阵。每个区块是同一个基础图案的副本，但各副本可能被旋转了 0°、90°、180° 或 270°（不同副本旋转角度不同）。恰好有一个副本的若干前景像素被替换为黑(0)背景色（受损）。基础图案使用 2~3 种非黑非品红非蓝的前景色（如红(2)、绿(3)、黄(4)），且图案在四个旋转方向下产生四种不同的像素排列（无旋转对称性）。蓝(1)在输入中不出现，保留为输出标记色。生成约束：未受损副本中至少有 3 个共享同一旋转角度，保证归一化后多数投票有效；受损像素数不超过区块像素总数的三分之一。

**规则**：
1. 提取分隔线之间的所有方形区块。
2. 对每个区块尝试 4 种旋转（0°、90°、180°、270°），找到使最多区块互相一致的旋转组合。将所有区块旋转到该共识朝向（规范化朝向）。
3. 在规范化后的区块集合上，对每个局部坐标 (r, c) 取像素颜色的多数投票（出现次数最多的颜色），得到共识图案。
4. 找出唯一一个规范化后与共识图案不一致的区块——即受损区块。
5. 输出共识图案（尺寸等于单个区块），将受损区块与共识图案不一致的局部坐标涂为蓝(1)，其余坐标保持共识图案颜色。

**关键洞察**：如果直接对未归一化的区块进行多数投票，旋转导致的像素错位会产生错误结果——求解者必须先识别出瓦片存在旋转变体，归一化后才能正确投票。仅凭单个示例可能误以为所有瓦片朝向相同，需要对比多个示例（不同示例中旋转配置不同）才能归纳出旋转归一化这一前置步骤。

## 新题 4：分支射线的象限色图着色

**组合逻辑**：[射线延伸(ray_extend) + 分支(branch) + 墙段开口分支(branch_at_opening)] + [重涂色(recolor) + 象限归属(quadrant_member) + 角标色定象限涂色(corner_sets_quadrant)]（标注：射线延伸与分支为已有原语；角标/象限涂色为已有原语；两者的结合——动态分支过程受静态位置查表着色——为创新结构关系）

**来源原语**：射线延伸/分支/边缘标记/墙段/墙段开口分支(f9a67cb5)、重涂色/象限/角标像素/角标色定象限涂色/编码映射(77fdfe62)

**依赖链**：射线分支决定哪些像素被涂色 → 每个被涂像素的象限归属决定其颜色 → 颜色来自该象限对应的角标像素。分支是空间扩展过程，象限归属是位置判断，两者交织在每一个新涂像素上——同一条分支射线穿过象限边界时，前后涂色不同。

从边缘标记发出射线并在墙段开口处分支扩展，每个被射线经过的像素根据其所在象限获取对应角标像素的颜色。

**输入结构**：16x16 的黑(0)背景网格（偶数尺寸以保证四等分）。四个角落像素各有不同颜色：(0,0) 为红(2)，(0,15) 为蓝(1)，(15,0) 为绿(3)，(15,15) 为黄(4)。网格中散布 4~6 段灰(5)墙段，每段是 2~5 像素长的水平或垂直线段，各段互不接触。墙段之间和端点处有黑(0)间隙（开口）。一个品红(6)标记像素位于网格某条边的边缘（非角落位置），如第 0 行某列。生成约束：标记的射线方向（垂直于其所在边缘，朝网格内部）上至少能遇到 2 段墙，且分支后射线路径至少跨越 2 个象限。

**规则**：
1. 将网格按中心分为四个象限：行 0~7 且列 0~7 为左上象限（图例色 = 角(0,0)的红(2)），行 0~7 且列 8~15 为右上象限（图例色 = 角(0,15)的蓝(1)），行 8~15 且列 0~7 为左下象限（图例色 = 角(15,0)的绿(3)），行 8~15 且列 8~15 为右下象限（图例色 = 角(15,15)的黄(4)）。
2. 从品红标记像素出发，沿垂直于其所在边缘的方向发射一条射线（如标记在第 0 行，则射线向下）。射线逐格推进，每经过一个黑(0)背景像素，将其涂为该像素所在象限的图例色。
3. 当射线前方下一格为灰(5)墙段像素时，射线停止。确定该墙段：沿垂直于射线方向找出与此墙像素相连的整段连续灰(5)像素。检查墙段的两个端点：对于每个端点，若该端点沿射线行进方向的下一格在网格内且为黑(0)背景，则从该格开始新建一条同方向的分支射线。
4. 每条分支射线遵循相同规则：逐格推进并涂色（颜色由像素所在象限决定），遇墙则分支，直到射线到达网格边界或前方无黑(0)像素可涂。
5. 灰(5)墙段、品红(6)标记、四个角标像素均保持不变。射线只涂黑(0)背景像素，不覆盖任何已有非背景像素。

**关键洞察**：分支射线本身不携带固有颜色——它涂出的每个像素的颜色完全取决于该像素在网格中的象限位置。同一条连续射线穿越象限边界时会"变色"，这一规则需要对比多个示例（不同角标颜色配置）才能确认颜色来自象限角标而非射线来源。

## 新题 5：翻转调色板的克罗内克自指展开

**组合逻辑**：[翻转顺序(reverse_order)](创新：作用于调色板序列而非精灵体堆叠) + [克罗内克积(kronecker_product) + 二值掩码(binary_mask) + 前景背景互换填充(fg_bg_inverted_fill)](创新：前景块为纯色填充，背景块为掩码图案自指嵌入)（标注：翻转顺序从精灵体堆叠改为调色板索引；克罗内克积保留自积结构但引入行索引色映射与自指嵌入）

**来源原语**：翻转顺序/堆叠(e21a174a)、克罗内克积/二值掩码/前景背景互换填充(8e2edd66)、精灵体(e21a174a)

**依赖链**：调色板提取 → 翻转产生新的颜色-行索引映射 → 掩码的前景/背景像素分别执行不同的展开规则（纯色块 vs 自指图案块），两条路径均依赖翻转后的索引取色。翻转改变了颜色分配，掩码结构同时决定宏观布局和微观图案——形成一个自指循环：掩码解释自己。

将调色板颜色翻转后，以二值掩码进行克罗内克展开——前景位生成纯色块，背景位生成掩码图案的自指副本。

**输入结构**：约 12x6 的黑(0)背景网格，由一条竖直灰(5)分隔线（1 像素宽）分为左右两个区域。左区域上方到下方排列 N 条（N=3 或 4）单像素高的水平色条，每条色条颜色不同（从红(2)、蓝(1)、绿(3)、黄(4)中选取），宽度均为 W 像素（W=3 或 4），各色条之间无间隔、紧密堆叠。右区域包含一个 NxN 的二值图案：一种前景色（橙(7)）和黑(0)背景，前景像素数量在 N 到 N²-1 之间（不全为前景也不全为背景）。生成约束：NxN 图案在四个旋转方向下不对称（以便区分行索引）。

**规则**：
1. 从左区域提取 N 种颜色，按色条从上到下记录为调色板序列 P = [P₀, P₁, ..., P_{N-1}]。
2. 将调色板翻转为 P' = [P_{N-1}, P_{N-2}, ..., P₀]。
3. 从右区域提取 NxN 二值掩码 M。
4. 构建输出网格（大小 N·W 行 × N·W 列）：对掩码中每个位置 (i, j)：
   - 若 M(i,j) 为前景（橙(7)）：生成一个 W×W 的纯色块，颜色为翻转后调色板的第 i 个颜色 P'[i]。
   - 若 M(i,j) 为背景（黑(0)）：生成一个 W×W 的块，其中按掩码 M 的图案绘制——M 中前景位置的像素涂为 P'[i]，M 中背景位置的像素涂为黑(0)。即在该块内自指地嵌入掩码 M 自身的图案。
5. 仅输出展开后的网格，不包含分隔线和原始输入区域。

**关键洞察**：前景块是纯色的、背景块含有掩码自身图案——这一前景/背景互换的自指规则是克罗内克自积的变体，但视觉效果截然不同：纯色块和图案块形成的宏观图案恰好是掩码的"正片"，而每个图案块内部又是掩码的微缩"正片"。翻转改变了哪种颜色出现在哪一行，必须对比多个示例（不同调色板顺序）才能确认翻转规则。

## 新题 6：空心框内部面积编码的游程序列换行平铺

**组合逻辑**：[计数(counting) + 面积比较(area_comparison)] → [排序(sorting)] → [生成序列(generate_seq) + 长度递增后递减(length_rise_fall)](创新：游程长度不再由单一控制条决定，而由多个框的面积值组成序列) → [换行平铺(wrap_tile) + 重涂色(recolor)]（标注：面积计数与排序为已有原语；游程序列生成从单控制条改为多源面积驱动；换行平铺保留）

**来源原语**：计数/比较/面积比较/空心矩形/封闭区域/最大内部面积胜出(445eab21)、排序(e21a174a)、生成序列/换行平铺/控制条/条长决定序列(5d588b4d)、重涂色(多源)

**依赖链**：框检测 → 内部面积计算 → 面积排序 → 排序后的面积值序列成为游程长度序列 → 每段游程涂为对应框的颜色 → 一维序列按输入宽度换行。框的几何属性（面积）转化为序列的算术属性（游程长度），框的颜色属性传递为序列的涂色属性——两种不同维度的信息在同一输出中交汇。

测量多个空心矩形框的内部面积，按面积升序排列后生成一组同长游程，以各框颜色着色并换行平铺为输出。

**输入结构**：约 18x18 的黑(0)背景网格。包含 3~4 个空心矩形框，每个框由单一非黑颜色的一像素宽完整矩形边框组成（如红(2)、蓝(1)、绿(3)、黄(4)），框内部填充黑(0)。各框不重叠、不接触。各框大小不同（如 4x4、5x6、7x3），保证内部面积（(宽-2)x(高-2)）两两不等。生成约束：所有游程长度之和加上游程间隔（各间隔 1 像素）不超过输入宽度的 8 倍（即输出行数合理，不超过约 8 行）。

**规则**：
1. 检测所有完整的空心矩形框。每个框的内部面积 = (框宽 - 2) × (框高 - 2)。
2. 按内部面积从小到大排序。
3. 构建一维游程序列：对每个排好序的框，生成一段连续前景像素，长度等于其内部面积，颜色为该框的边框颜色。相邻两段游程之间插入 1 个黑(0)间隔像素。
4. 将该一维序列按行主序（row-major）换行到宽度等于输入宽度的输出网格中。末行不足的部分用黑(0)填充。
5. 仅输出换行后的游程网格。

**关键洞察**：输出中每段连续色带的长度并非任意值，而是恰好等于对应框的内部面积——一个不显眼的几何量。颜色出现的顺序由面积排序决定，而非框在输入中的空间位置。需要对比多个示例（框大小和位置不同）才能排除"按位置排序"等替代假说，确认面积驱动的排序规则。

## 新题 7：射线碰撞触发的同色模板印章与近距优先覆盖

**组合逻辑**：[射线延伸(ray_extend)] + [同色匹配(same_color_matching) + 模板图案(motif_stencil)] + [印章覆盖(stamp)](创新：印章位置由射线碰撞点决定，印章内容由碰撞墙色的同色模板决定) + 冲突解决：近距优先覆盖（标注：射线延伸、同色匹配、印章覆盖均为已有原语；三者的交汇关系——射线决定位置、颜色匹配决定内容、距离比较决定优先级——为创新组合）

**来源原语**：射线延伸(f9a67cb5, bdad9b1f)、同色匹配/模板图案/单色块(58f5dbd5)、印章覆盖/标记环/交叉点印章环形(ac3e2b04)、交叉/交叉点标记新色(bdad9b1f)

**依赖链**：射线碰撞点定位 → 碰撞墙颜色索引同色模板 → 在碰撞点印章模板 → 多个印章可能重叠 → 射线长度（碰撞距离）决定覆盖优先级（短射线的印章覆盖长射线的）。三种不同性质的信息（空间路径、颜色归属、距离度量）在每个印章事件上交汇，缺一不可。

从标记向四方发射射线，在每个碰撞墙段的位置印章该墙色对应的模板图案，重叠区域由射线长度较短者优先覆盖。

**输入结构**：约 17x17 的黑(0)背景网格。中心附近有一个品红(6)标记像素。网格上分布 3~4 段单像素宽的墙段，每段 2~4 像素长，水平或垂直排列，颜色各不相同（从红(2)、蓝(1)、绿(3)中选取）。对每种墙段颜色，网格角落附近有一个同色的小型模板图案（3x3 的不规则图形，4-连通，3~5 个前景像素组成，非对称形状），模板图案的其余位置为黑(0)。各墙段和模板不相邻。生成约束：品红标记向四个方向中至少 3 个方向上能碰到墙段；至少有 2 个碰撞点的印章会部分重叠。

**规则**：
1. 从品红(6)标记像素出发，向上、下、左、右四个方向各发射一条射线。每条射线沿该方向逐格推进，经过黑(0)背景像素。当下一格为非黑非品红像素（即碰到墙段或模板）或超出网格时，射线停止。记录射线停止前最后经过的那个黑(0)像素为碰撞点，射线长度为该射线经过的像素格数（不含起点标记）。若射线方向上标记的下一格就是非背景或越界，则该方向无碰撞点。
2. 对每个碰撞点，确定使射线停止的墙段颜色 C。找到网格中与 C 同色的模板图案。
3. 将该模板图案以碰撞点为中心进行印章：模板的中心像素（模板 3x3 边界框的中心格）对齐碰撞点。模板中每个前景像素映射到网格上对应位置，仅覆盖黑(0)背景像素（不覆盖墙段、标记或其他模板的原始像素）。
4. 若两个印章的覆盖范围有重叠（同一个黑(0)像素被两个印章都试图涂色），则射线长度较短（碰撞距离更近）的印章优先——该像素取近距印章的颜色。若射线长度相同，则水平射线的印章优先于垂直射线的印章。
5. 品红标记、所有墙段、所有原始模板图案保持不变。

**关键洞察**：印章的内容（哪个模板）由碰撞墙的颜色决定，印章的位置由射线路径决定，重叠冲突由射线长度决定——三条独立的信息链在每个碰撞事件上交汇。求解者必须同时追踪空间路径、颜色对应和距离度量，不能孤立地理解任何一条链。重叠优先规则（近距优先）需要对比多个示例才能从"看似随机的覆盖"中归纳出来。

## 新题 8：同心框界定的环形区域内螺旋填充

**组合逻辑**：[生长(grow) + 同心方框层(concentric_layer) + 等距对角排列(equi_diag_array) + 间距决定同心重复(spacing_concentric_repeat)] + [螺旋绘制(spiral_drawing) + 起点定位(origin_positioning) + 边界裁剪(boundary_clipping)](创新：螺旋不在自由网格上绘制，而被约束在同心框之间的环形区域内)（标注：同心方框生长为已有原语；螺旋绘制为已有原语；螺旋被环形区域约束为创新结构关系）

**来源原语**：生长/同心方框层/种子像素/等距对角排列/间距决定同心重复(5c2c9af4)、螺旋绘制/起点定位/边界裁剪/格点阵列(8b28cd80)

**依赖链**：对角种子 → 间距计算 → 同心方框绘制 → 方框界定若干同心环形区域 → 蓝色标记像素选定其中一个环 → 在选定环内绘制受环边界约束的螺旋。同心框的几何结构为螺旋提供了非矩形的绘制边界——螺旋的形状是框结构的函数，改变框间距就改变螺旋轨迹。

从三个对角种子构建同心方框，然后在蓝色标记所在的环形区域内绘制一条受框边界约束的方形螺旋。

**输入结构**：约 19x19 的黑(0)背景网格。三个红(2)像素位于一条 45 度对角线上，彼此等距（间距 d=3 或 4），中间像素大致位于网格中心。另有一个蓝(1)像素位于网格中某处，不在红像素所在的对角线上。生成约束：同心方框至少生成 2 层（即间距 d 足够使至少 2 个方框完整或部分落在网格内）；蓝像素严格位于两层相邻方框之间的环形区域内（不在方框线上、不在最内层区域内）。

**规则**：
1. 将三个红(2)像素按对角方向排序，取中间像素为中心 O，计算相邻种子到 O 的切比雪夫距离 d。
2. 以 O 为中心，在切比雪夫距离 d、2d、3d、... 处绘制红(2)方形边框（每个边框是一个正方形环，边长为 2kd+1，k=1,2,3,...），超出网格边界的部分裁剪掉。
3. 方框将网格划分为若干同心环形区域（相邻两层方框之间的黑(0)区域）和一个最内层区域（中心到第一层方框之间）。确定蓝(1)像素所在的环形区域 R。
4. 以蓝(1)像素为起点，在环形区域 R 内绘制蓝(1)方形螺旋。螺旋从起点开始，按上→右→下→左的方向循环行进，步长依次为 1, 1, 2, 2, 3, 3, ...（标准方形螺旋递增规则）。螺旋仅涂黑(0)背景像素；遇到红(2)方框边界、网格边界或已涂蓝(1)像素时，该方向的当前步立即截断，继续下一个方向的下一步。当螺旋在连续 4 个方向上均无法涂出新像素时，螺旋终止。
5. 红(2)方框和种子保持不变，蓝(1)像素（起点 + 螺旋轨迹）为最终蓝色图案。

**关键洞察**：螺旋的形状不是标准的无界方形螺旋——它被同心框夹成的环形通道所扭曲，只能在两层框之间蜿蜒展开。框的间距 d 直接控制环的宽度，从而控制螺旋的展开空间。求解者必须先构建框（确定环的边界），再理解螺旋如何在受约束的区域内行进——这两步缺一不可。需对比多个示例（不同 d 值和蓝像素位置）来确认螺旋的行进规则和约束方式。
