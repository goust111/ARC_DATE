## 新题 1：对角射线穿越计数决定连通分量涂色

**组合逻辑**：[射线延伸(ray_extend)](创新：射线不用于涂色而用于计数) + [重涂色(recolor)](创新：涂色条件由射线穿越计数的奇偶性决定) + [连通性(connectivity)](已有) + [对角线激活(diagonal_activation)](创新：激活结果不作用于射线路径上的像素，而作用于被射线穿越的连通分量)

**来源原语**：射线延伸、对角线激活(d07ae81c)；重涂色、连通分量、连通性(e0fb7511)

**依赖链**：标记像素的位置决定对角射线的几何路径 → 射线路径与连通分量的空间交集决定每个分量的穿越计数 → 穿越计数的奇偶性决定该分量的重涂色方案。删去射线则无法获得计数，删去连通分量则无涂色目标，删去奇偶判断则无法区分两种输出颜色。

从标记像素发出对角射线，统计穿越每个前景连通分量的射线条数，按奇偶性分别涂为两种不同颜色。

**输入结构**：
- 约 12x12 网格，背景为灰(5)。
- 2~4 个红(2)单像素散布在网格中，彼此不相邻，不与任何蓝(1)像素 4-连通相邻。这些是标记像素。
- 3~6 个蓝(1)的 4-连通前景连通分量，每个由 3~8 个像素组成，形状不规则（非矩形），各分量之间互不 4-连通相邻。
- 生成约束：每个蓝(1)分量至少被一条对角射线穿越（即没有任何分量的穿越计数为零）。

**规则**：
1. 从每个红(2)标记像素出发，沿 NW-SE 和 NE-SW 两条完整对角线延伸至网格边缘。这些对角线是逻辑射线，不在网格上绘制或改变任何像素。
2. 对每个蓝(1) 4-连通分量，统计有多少条不同的射线至少经过了该分量的一个像素。同一条射线即使穿越该分量的多个像素也只计一次。每个标记产生 2 条射线，k 个标记共产生 2k 条射线。
3. 若该分量的穿越计数为奇数，将其所有像素重涂为绿(3)。
4. 若该分量的穿越计数为偶数（且大于零），将其所有像素重涂为黄(4)。
5. 红(2)标记像素、灰(5)背景像素保持不变。

**关键洞察**：对角射线不是用来涂色的（与 d07ae81c 不同），而是用来"投票"——每条穿越分量的射线为该分量贡献一票，票数的奇偶性才是涂色判据。求解者必须同时追踪射线的几何轨迹和分量的空间范围，两者的交集关系无法分开推理。

## 新题 2：按前景面积排序面板后逐对叠加合并

**组合逻辑**：[排序(sorting)](创新：排序对象不是嵌入矩阵的列而是完整面板) + [透明叠加(transparent_overlay)](创新：叠加对象不是预设的左右面板而是排序后动态配对的面板) + [布尔并集合并(boolean_union)](已有)

**来源原语**：排序、按计数升序排列、列内计数(85b81ff1)；透明叠加、前景掩码、逐格对齐、布尔并集合并(dae9d2b5)；分隔面板(5a719d11)

**依赖链**：每个面板的前景像素计数决定排序位次 → 排序位次决定哪两个面板配对 → 配对关系决定叠加的掩码组合和最终输出图案。改变任何一个面板的前景数量都可能改变排序结果，从而改变所有配对和叠加结果。

统计每个面板的前景像素数并按升序重排面板，然后将相邻的面板两两叠加取并集，输出合并后的面板序列。

**输入结构**：
- 约 6x25 网格（宽大于高），背景为黑(0)。
- 4 个大小相同的矩形面板（约 6x5 每个）水平排列，相邻面板之间有一列宽的灰(5)分隔列。
- 每个面板有一个占主导的底色（从红(2)、蓝(1)、绿(3)、黄(4)中各取一种，四个面板底色互不相同），以及若干该面板专属的前景像素（颜色与底色不同，由面板的底色唯一确定，但前景颜色本身不影响输出）。
- 四个面板的前景像素数互不相同。
- 生成约束：每个面板至少有 2 个前景像素，至多占面板面积的一半。

**规则**：
1. 统计每个面板中前景像素的数量（非底色、非黑(0)背景的像素数）。
2. 按前景像素数从小到大对四个面板重新排列。若像素数相同（生成约束保证不会），以面板在输入中从左到右的原始位次为 tie-break（靠左的排前面）。
3. 将排序后的面板两两配对：第 1 和第 2 个面板为一对，第 3 和第 4 个面板为一对。
4. 对每一对，逐像素对齐两个面板。在对应位置上，若任一面板有前景像素，则输出橙(7)；若两个面板在该位置均为底色或背景，则输出黑(0)。
5. 输出由 2 个面板（与输入面板同尺寸）水平排列组成，中间以灰(5)分隔列分隔。

**关键洞察**：面板的前景颜色和底色都是干扰项——输出只取决于前景的位置掩码。排序改变了配对关系，使得最终叠加结果依赖于全局的面积排名，而非面板的空间邻接关系。仅看单个示例无法确定排序方向（升序还是降序），必须对比多个示例。

## 新题 3：角括号几何长度编码位移量，内嵌标记指定擦除色

**组合逻辑**：[循环位移(cyclic_roll)](创新：位移量不由控制列的标记位置编码，而由角括号的臂长编码) + [擦除(erase)](创新：擦除目标不由独立的选择器确定，而由同一角括号内的标记确定) + [角括号(corner_bracket)](创新：角括号承担双重功能——几何属性编码变换参数，同时内部标记指定擦除对象)

**来源原语**：循环位移、行偏移编码、标记位定位移量(6d1d5c90)；擦除、角括号、标记在括号内部、按标记色选择同色、保留标记本身(1e81d6f9)

**依赖链**：角括号的短臂像素数 → 整体网格的行循环下移量 → 位移后的网格布局 → 标记颜色指定的像素在位移后的位置被擦除。角括号同时为两个操作提供参数，两个操作共享同一结构但提取不同信息维度。

读取角括号的短臂长度作为循环下移量，对网格行施加循环位移，然后擦除与括号内标记同色的所有像素（保留标记本身），最后移除角括号。

**输入结构**：
- 约 10x10 网格，背景为黑(0)。
- 一个灰(5)角括号：由两条互相垂直的灰(5)像素臂在一个角点处相连，形成 L 形开口结构。两臂长度不同（短臂 2~4 像素，长臂 4~7 像素，均含角点像素）。角括号位于网格的某个角落区域，朝向网格内部开口。
- 角括号的开口区域内（在角括号边界框内、角括号像素之外）恰好有一个标记像素，颜色为红(2)、蓝(1)或绿(3)之一。
- 网格其余区域包含一个由多种颜色（含标记同色）构成的图案，至少使用 3 种非背景、非灰(5)颜色。
- 生成约束：短臂长度严格小于网格行数；标记颜色在图案中至少出现 2 次。

**规则**：
1. 识别灰(5)角括号，测量其两臂的像素长度（含共享角点），取较短臂的长度 L。
2. 将整个网格的所有行循环下移 L 行（第 i 行移到第 (i+L) mod H 行，H 为网格高度）。此步包括角括号和标记像素自身也参与位移。
3. 位移后，读取角括号内标记像素的颜色 C。将网格中所有颜色为 C 的像素改为黑(0)背景，但标记像素本身保持颜色 C 不变。
4. 将角括号的所有灰(5)像素改为黑(0)背景。
5. 输出处理后的网格，尺寸不变。

**关键洞察**：角括号在源题中仅作为颜色选择器（通过内部标记指定擦除目标），但在本题中它同时承担了变换参数编码的角色——其几何尺寸（短臂长度）编码了循环位移量。求解者必须从同一结构中读取两种不同性质的信息（几何度量和颜色编码），且位移先于擦除执行，使得擦除的空间效果依赖于位移结果。

## 新题 4：周期平铺后半周期偏移镜像追加

**组合逻辑**：[平铺(tile)](已有) + [镜像(reflect)](创新：镜像副本不是原样翻转，而是施加与列周期耦合的水平偏移) + [循环位移(cyclic_roll)](创新：位移量等于列周期的一半，由平铺步骤的结果隐式确定)

**来源原语**：平铺、最小周期单元、列周期重复、最小周期扩展(d8c310e9)；镜像、拼接、纵向拼接、对称翻转追加(8be77c9e)；循环位移(6d1d5c90)

**依赖链**：可见图案的列周期 P → 水平平铺完成完整上半部 → 上半部垂直镜像生成下半部 → 下半部每行右移 floor(P/2) 像素形成砖砌偏移。三个操作共享参数 P：P 决定平铺宽度、也决定镜像后的偏移量。不找到 P 就无法完成平铺，不完成平铺就不知道镜像什么，不知道 P 就无法确定偏移量。

找到部分可见图案的最小列周期并水平平铺，然后在下方追加垂直镜像副本，但镜像副本的每一行按半个周期宽度做循环右移。

**输入结构**：
- 约 6x14 网格（宽大于高），背景为黑(0)。
- 网格上半部分（所有行）的左侧区域包含一个由蓝(1)和红(2)像素构成的图案，占据约一半到三分之二的宽度，其余为黑(0)背景。
- 该图案具有水平方向上的最小列周期 P（P 为偶数，范围 4~8），即图案每 P 列重复一次。输入中至少显示 1.5 个完整周期，但未铺满整个宽度。
- 图案在每个周期内包含蓝(1)和红(2)两种颜色，构成非对称的纹样（上下不对称，确保镜像后视觉上可区分）。
- 生成约束：网格宽度是 P 的整数倍；图案非上下对称。

**规则**：
1. 分析可见图案，确定最小列周期 P（最小的正整数 P 使得对所有可见的非背景像素 (r,c)，若 (r, c+P) 仍在网格内且为非背景色，则 grid[r][c] == grid[r][c+P]）。
2. 以 P 为周期，将图案沿水平方向平铺至填满网格的整个宽度。此时网格上半部分完全被周期图案填充。
3. 将填充后的上半部分沿水平中轴做垂直镜像（上下翻转行序），生成下半部分。
4. 对下半部分的每一行，循环右移 floor(P/2) 个像素。
5. 输出为上下两部分拼接的网格，高度为输入高度的 2 倍，宽度不变。上半部是完整平铺的图案，下半部是偏移后的镜像。

**关键洞察**：输出不是简单的垂直镜像拼接（与 8be77c9e 不同），下半部的半周期偏移产生了砖砌效果。偏移量 floor(P/2) 由平铺步骤发现的周期 P 隐式决定——求解者必须先识别周期才能知道偏移多少。仅看单个示例时，偏移量可能被误解为固定常数；对比不同周期宽度的示例才能发现偏移量与周期的函数关系。

## 新题 5：平移后自交取交集揭示形状内核

**组合逻辑**：[平移(translate)](创新：平移不用于移动像素到新位置，而是生成形状的副本以进行集合运算) + [透明叠加(transparent_overlay)](创新：不取并集而取交集) + [重涂色(recolor)](已有) + [颜色编码位移(color_encoded_disp)](创新：位移方向由边界标记的位置编码而非前景像素颜色编码)

**来源原语**：平移、颜色编码位移、颜色决定偏移(342dd610)；透明叠加、逐格对齐(dae9d2b5)；双面板背景交集(0c9aba6e)；边界标记、标记指定观察方向(f341894c)；重涂色(e0fb7511)

**依赖链**：边界标记的边缘位置 → 位移方向和距离 → 原始形状与位移副本的空间对齐 → 两者的逐像素交集决定输出形状。标记位置决定位移向量，位移向量决定副本位置，副本位置决定交集区域——三者串联且每步的输出实质改变下一步的输入。

在边框上放置一个标记像素，其所在边缘编码平移方向。将前景形状沿该方向平移固定距离生成副本，输出原始形状与副本的位置交集，以新颜色绘制。

**输入结构**：
- 约 12x12 网格，背景为黑(0)。
- 一个绿(3)的 4-连通前景形状，由 6~15 个像素组成，形状不规则但连通，不触碰网格边缘（距边缘至少 3 个像素）。
- 网格最外圈（边框行/列）上恰好有一个红(2)单像素标记，位于四条边中的某一条上。该标记不与绿(3)形状相邻。
- 生成约束：绿(3)形状在标记所指方向上的"厚度"大于 2（即沿该方向平移 2 后，交集非空）。

**规则**：
1. 识别红(2)边界标记的位置。标记所在边缘决定平移方向：上边缘 → 向下平移，下边缘 → 向上平移，左边缘 → 向右平移，右边缘 → 向左平移（即标记指向网格内部的方向）。
2. 平移距离固定为 2 个像素。
3. 将绿(3)形状沿确定的方向平移 2 像素，得到一个虚拟副本（不实际绘制）。
4. 在一个干净的黑(0)网格上（与输入同尺寸，不含标记和原始形状），在原始形状与虚拟副本重叠的每个像素位置涂上蓝(1)。
5. 不重叠的位置保持黑(0)。红(2)标记不出现在输出中。

**关键洞察**：这不是两个独立形状的并集（与 dae9d2b5/195ba7dc 不同），而是同一形状与自身平移副本的交集。交集揭示了形状在指定方向上的"内核"——沿该方向足够厚的部分。红(2)标记的边缘位置编码的不是颜色信息（与 f341894c 不同），而是几何操作的方向参数。

## 新题 6：封闭区域拓扑计数编码自身旋转角度后加框堆叠

**组合逻辑**：[旋转(rotate)](创新：旋转角度不由外部标记指定，而由输入形状自身的拓扑属性——封闭区域数量——隐式编码) + [拼接/副本堆叠(concatenate/copy_stacking)](已有) + [边框(frame)](已有) + [封闭区域(enclosed_region)](创新：封闭区域不作为涂色目标，而作为变换参数的编码载体)

**来源原语**：旋转、拼接、副本堆叠、边框(412b6263)；封闭区域、连通分量、面积排名(a8d7556c)

**依赖链**：红色形状的拓扑结构（包含几个完全封闭的黑色区域）→ 封闭区域计数 N → 旋转角度 = N x 90 度顺时针 → 旋转后的网格被复制并垂直堆叠 → 加蓝色边框输出。形状的拓扑决定了自身如何被变换——这是一种自编码结构，删去拓扑分析则无法确定旋转角度，删去旋转则堆叠结果错误。

统计前景形状内部的封闭区域数量作为旋转次数，对整个网格施加相应角度的顺时针旋转，然后将旋转结果复制两份垂直堆叠并加蓝色边框。

**输入结构**：
- 约 7x7 正方形网格，背景为黑(0)。
- 一个红(2)像素构成的较大连通形状，占据网格中央区域（约 15~30 个像素），形状不规则。
- 该红色形状内部可能包含 0~3 个完全封闭的黑(0)区域（"洞"）：每个洞是一个由红(2)像素在 4-连通意义下完全包围的黑(0) 4-连通分量，且该黑色分量不与网格边缘的黑色背景 4-连通相连。
- 输入中不包含蓝(1)像素。
- 生成约束：不同示例的封闭区域数量不同，以便求解者归纳计数与旋转的映射关系。

**规则**：
1. 识别红(2)形状内部的封闭黑(0)区域：找出所有不与网格四边的黑(0)背景 4-连通相连的黑(0) 4-连通分量，即为封闭区域。记其数量为 N。
2. 将整个网格顺时针旋转 N x 90 度（N=0 不旋转，N=1 旋转 90 度，N=2 旋转 180 度，N=3 旋转 270 度）。
3. 将旋转后的网格复制两份，垂直拼接（上下排列）。
4. 在拼接结果的外围添加 1 像素宽的蓝(1)边框。在上下两个副本之间也插入 1 行蓝(1)分隔行。
5. 边框和分隔行的四个角像素（最左和最右两端）涂为黑(0)而非蓝(1)。
6. 输出尺寸：宽 = 输入宽 + 2，高 = 输入高 x 2 + 3（上边框 1 行 + 上副本 + 分隔行 1 行 + 下副本 + 下边框 1 行）。

**关键洞察**：旋转角度没有通过任何显式标记或控制条给出——它编码在形状自身的拓扑结构中（孔洞数量）。求解者必须从多个示例中推断"孔洞数 = 旋转次数"这一隐含映射。形状既是被变换的对象，又是编码变换参数的载体，构成自指结构。

## 新题 7：风车拼贴后跨边界连通分量变色

**组合逻辑**：[旋转(rotate)](已有) + [拼接/阵列排布(concatenate/array_layout)](已有) + [重涂色(recolor)](创新：涂色判据不基于原始图中的属性，而基于拼贴构造后涌现出的跨象限连通性) + [连通性(connectivity)](创新：连通性不在原始输入中评估，而在旋转拼贴构造出的新空间中评估)

**来源原语**：旋转、拼接、正方形画布、阵列排布、四旋转组成风车(7fe24cdd)；重涂色、连通分量、连通性、面积大于一则涂(e0fb7511)

**依赖链**：原始小网格 → 四个旋转副本拼成 2x2 风车 → 拼贴在象限边界处产生新的像素邻接关系 → 跨越象限边界的 4-连通分量被识别 → 跨边界分量重涂为新颜色，单象限分量保持原色。旋转拼贴创造了源题中不存在的空间关系（边界邻接），而连通性评估在这个涌现的新空间上进行——两者紧密耦合。

将正方形输入旋转四次拼成风车形拼贴，然后检测跨越象限边界的前景连通分量并将其重涂为新颜色。

**输入结构**：
- 一个正方形网格（5x5 或 6x6），背景为黑(0)。
- 若干蓝(1)前景像素构成一个或多个小型 4-连通图形（总计 4~10 个蓝色像素），形状不对称（不具有 90 度旋转对称性，以确保不同旋转副本的边界对齐情况因示例而异）。
- 生成约束：至少存在一个旋转拼贴后跨越象限边界的连通分量，且至少存在一个不跨越边界的分量（以提供对比）。

**规则**：
1. 设输入为 NxN 的网格 G。构造 2Nx2N 的风车拼贴：
   - 左上象限：G 的原始副本。
   - 右上象限：G 顺时针旋转 90 度。
   - 左下象限：G 逆时针旋转 90 度（即顺时针 270 度）。
   - 右下象限：G 旋转 180 度。
2. 在 2Nx2N 拼贴中，识别所有蓝(1)像素的 4-连通分量。
3. 对每个分量，检查它是否包含来自两个或更多不同象限的像素（即该分量跨越了象限边界）。
4. 跨越象限边界的分量：将其所有像素重涂为红(2)。
5. 完全位于单个象限内的分量：保持蓝(1)不变。
6. 黑(0)背景不变。输出为 2Nx2N 的拼贴网格。

**关键洞察**：风车拼贴本身是确定性的（与 7fe24cdd 规则相同），但拼贴后哪些分量跨越边界取决于输入形状在各旋转方向上的边缘像素分布——这是一种涌现属性，仅凭原始小网格难以直接预判，必须实际构造拼贴后才能评估连通性。求解者需要同时在脑中旋转形状并追踪边界处的像素对齐。
