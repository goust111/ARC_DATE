## 新题 1：遮挡层序决定生长厚度

**组合逻辑**：[排序(sorting)](已有) + [生长(grow)](已有) → [遮挡层序→生长量](创新：层序排名数值化为生长像素数)

**来源原语**：排序/遮挡层序/重叠层/空心矩形/重叠定先后 ← 68bc2e87；生长/同心正方形层 ← 3befdf3e

**依赖链**：遮挡分析得出层序 → 层序排名转化为各框的生长量 → 生长后产生新的重叠区域 → 使用同一层序解决新重叠的颜色冲突。排名同时控制生长幅度和重叠优先级，删除任一环节均无法确定输出。

从部分可见的重叠矩形框中推断层叠顺序，按排名向外生长不同厚度，高层框覆盖低层框的新重叠区域。

**输入结构**：约 18x18 网格，背景黑(0)。3~4 个不同颜色（如蓝(1)、红(2)、绿(3)、黄(4)）的 1 像素厚空心矩形边框，彼此部分重叠。重叠像素仅显示层叠顺序中较高框的颜色。每个框的边界框可从其可见像素推断（可见像素的最小外接矩形即为该框的完整形状）。各框尺寸不同（短边 4~8 像素），重叠区域至少涉及两对框，使得层序可从局部遮挡关系唯一推出。生成约束：任意两框之间至少有一段可见的重叠边，以保证层序唯一确定。

**规则**：
1. 重建每个框：将其可见像素的最小外接矩形视为该框的完整 1 像素厚边框。
2. 在每个被多个重建框覆盖的像素处，可见颜色属于层叠顺序中较高的框。由此推断从底到顶的完整层叠顺序，排名从 1（最底）到 N（最顶）。
3. 每个框向外四个方向各生长 R 个像素（R = 该框的层叠排名），形成 R 像素厚的同色实心边框带，围绕原始框外侧。框的内部区域保持为背景色不变。
4. 生长后若多个框的扩展区域重叠，排名高的框颜色覆盖排名低的。
5. 生长区域超出网格边界的部分直接丢弃。

**关键洞察**：层叠排名既决定了每个框的生长幅度，又决定了新重叠区域的颜色优先级——排名高的框生长得更多、覆盖得更广，形成"强者愈强"的涌现效果。这种"同一排序结果同时控制几何变换幅度和冲突解决优先级"的双重角色在源题中不存在。

## 新题 2：异常值选择分流不同操作

**组合逻辑**：[计数(counting)](已有) + [擦除(erase)](已有) + [补全/填充(fill)](已有) → [异常值→操作分流](创新：同一计数结果既选目标又决定操作类型)

**来源原语**：计数/前景块/背景孔洞/异常值提取/孔洞数量唯一 ← 358ba94e；擦除/连通分量 ← 52364a65；补全 ← 3aa6fb7a；标记像素 ← a04b2602

**依赖链**：统计每个块的孔洞数 → 识别异常值块 → 异常值块执行孔洞填充（填充色由内部标记像素颜色决定）→ 非异常值块整体擦除。计数结果同时驱动选择和操作分流，缺少任一环节输出不确定。

统计每个前景块的内部孔洞数量，孔洞数唯一的异常值块被填充完整并保留，其余块被擦除。

**输入结构**：约 20x20 网格，背景黑(0)。一种前景色（如灰(5)）形成 4~5 个分离的 4-连通块，每个块的外接矩形为 5x5 或 6x6，块形状不规则但均为单色连通区域。每个块的外接矩形内有若干背景色孔洞（0~4 个不等）。其中恰好一个块的孔洞数与其他所有块不同（其他块的孔洞数全部相同）。每个块的外接矩形内部还恰好有 1 个标记像素，颜色各不相同（取自蓝(1)、红(2)、绿(3)、黄(4)、橙(7)等），标记像素不与块的前景色相同。生成约束：非异常值块的孔洞数全部相等，异常值块的孔洞数严格唯一。

**规则**：
1. 识别所有前景色 4-连通块及其外接矩形。
2. 统计每个块外接矩形内的背景色像素数量（即孔洞数）。
3. 找到孔洞数唯一的那个块（异常值块）。
4. 对异常值块：将其外接矩形内所有背景色孔洞填充为该块内部标记像素的颜色。标记像素本身保留不变。
5. 对所有非异常值块：将其全部像素（包括前景色和标记像素）设为背景色（擦除）。
6. 输出完整网格（不裁剪），仅保留异常值块的填充结果，其余区域均为背景色。

**关键洞察**：同一个统计量（孔洞数）既用于识别目标（哪个块是异常值），又用于决定操作类型（异常值→填充，非异常值→擦除）。标记像素提供了填充颜色，但只有在块被选为异常值时才发挥作用——对于被擦除的块，标记像素随之消失，其颜色信息被浪费。

## 新题 3：箭头方向编码局部擦除方位

**组合逻辑**：[射线延伸/朝向解码](已有) + [擦除(erase)](已有) → [外部方向指令→参数化擦除方位](创新：箭头的朝向决定对每个对象执行擦除的方位，而非固定的"最左两列")

**来源原语**：射线延伸/箭头精灵/朝向对齐/横杆偏移定方向 ← 689c358e；擦除/连通分量/相对自身定位/按对象局部裁切 ← 52364a65

**依赖链**：解码箭头朝向 → 将箭头与最近的前景对象配对 → 箭头方向决定擦除方位（上/下/左/右）→ 在每个对象的局部边界框内执行方向性擦除。方向和擦除紧密耦合，删除方向解码则擦除方位不确定，删除擦除则方向信息无用。

根据每个前景对象旁边的箭头精灵的朝向，擦除该对象边界框中靠近箭头所指方向的两行或两列。

**输入结构**：约 18x18 网格，背景黑(0)。3~4 个绿(3)色 4-连通前景对象，每个对象包含 8~15 像素，形状不规则（非矩形），外接矩形至少 4x4。在每个绿色对象附近（与对象外接矩形间隔 1~2 像素），有一个红(2)色箭头精灵：箭头由一条长 4 像素的主杆和一条长 3 像素的横杆组成，横杆偏向主杆的一端，偏向的那端即为箭头指向。每个箭头精灵指向四个基本方向之一（上、下、左、右），且不同对象的箭头方向可以不同。生成约束：每个绿色对象恰好关联一个箭头精灵（以外接矩形最近距离配对），箭头精灵不与任何绿色对象像素重叠，每个对象在箭头所指方向的局部边界框内至少有 2 行（或 2 列）前景像素。

**规则**：
1. 识别所有绿(3)色 4-连通前景对象及其外接矩形。
2. 识别所有红(2)色箭头精灵，通过横杆偏移位置判断其指向方向。
3. 将每个箭头与外接矩形距离最近的绿色对象配对（距离相同时取行优先的对象）。
4. 对每个绿色对象，根据其配对箭头的指向方向，在该对象自身的外接矩形内擦除（设为背景色）前景像素：
   - 箭头指右：擦除外接矩形最右 2 列中的前景像素
   - 箭头指左：擦除外接矩形最左 2 列中的前景像素
   - 箭头指上：擦除外接矩形最上 2 行中的前景像素
   - 箭头指下：擦除外接矩形最下 2 行中的前景像素
5. 擦除所有箭头精灵（红色像素全部设为背景色）。
6. 其余像素不变。

**关键洞察**：擦除方位不是全局固定的，而是由每个对象的"配对指令物"（箭头精灵）逐一编码。箭头的横杆偏移结构解码出方向信息，这个方向信息驱动了完全不同于源题的操作——不是射线延伸，而是局部擦除。同一种方向编码机制在新语境中获得了全新的语义。

## 新题 4：拉伸后按面积选取并裁剪内部

**组合逻辑**：[拉伸(stretch)](已有) + [裁剪(crop)](已有) → [变换后选取](创新：选取条件基于变换后的属性而非变换前，使得变换和选取形成因果依赖)

**来源原语**：拉伸/空心矩形/标记像素/标记决定拉伸终点/行列对齐 ← b548a754；裁剪/矩形框/内部区域/边框包围内容/最大面积选取/完整边框检测 ← 1a6449f1

**依赖链**：配对框与标记 → 拉伸每个框至其标记位置 → 拉伸改变各框面积 → 按拉伸后面积选取最大框 → 裁剪该框的严格内部。不执行拉伸则无法知道哪个框最大；不做面积比较则不知道裁剪哪个框。

将多个空心矩形框各自拉伸到其配对标记像素的位置，然后裁剪输出拉伸后面积最大的那个框的内部区域。

**输入结构**：约 20x20 网格，背景黑(0)。3 个不同颜色的 1 像素厚空心矩形边框（如蓝(1)、绿(3)、橙(7)），初始尺寸各异（如 4x4、5x3、3x6）。每个框的内部包含若干灰(5)色内容像素，形成不规则图案。在每个框的某一侧外方，有一个与该框同色的标记像素，标记像素的行或列在该框的跨度范围内。不同框的标记像素位于不同方向（一个在右侧远处，一个在下方近处，一个在左侧中等距离）。生成约束：拉伸后面积最大的框在拉伸前不是面积最大的（即拉伸改变了大小排名），各框拉伸后不重叠，标记像素与框之间无其他框阻挡。

**规则**：
1. 将每个标记像素与同色的空心矩形框配对。
2. 对每个框执行拉伸：若标记像素在框的上方或下方且其列在框的列范围内，将框沿垂直方向拉伸到标记像素所在行；若在左方或右方且其行在框的行范围内，将框沿水平方向拉伸到标记像素所在列。标记像素被新边框覆盖。
3. 拉伸后，框的内部内容保持在原始位置不动（不随边框拉伸），新增的内部区域填充为背景色。
4. 计算每个拉伸后框的内部面积（不含边框本身）。
5. 裁剪面积最大的框的严格内部（去除边框），输出为结果网格。
6. 若拉伸后面积相同（生成时保证不会发生），取外接矩形左上角更靠近网格左上角的框。

**关键洞察**：面积最大的框是在拉伸之后才确定的——拉伸前最小的框可能因为标记像素距离远而变成拉伸后最大的。选取标准依赖于变换结果，而非输入的静态属性，这使得拉伸和选取形成不可分割的因果链。

## 新题 5：按帧尺寸缩放模板后印章覆盖

**组合逻辑**：[像素放大(pixel_upscale)](已有) + [印章覆盖(stamp)](已有) → [上下文感知缩放印章](创新：缩放因子由印章目标区域的尺寸与模板尺寸之比决定，同一模板在不同目标中产生不同大小的印章)

**来源原语**：像素放大/均匀整数倍缩放/缩放对应 ← 60c09cac, 898e7135；印章覆盖/十字模板/标记像素/内部包含/以标记为中心印章 ← 264363fd, a04b2602

**依赖链**：识别模板和各框 → 计算每个框与模板的尺寸比 → 按比例放大模板 → 将放大后的模板印章到框内标记位置。模板大小随目标变化，删除缩放计算则印章尺寸不确定。

一个小型模板图案在不同大小的矩形框内被按比例放大后印章到标记像素位置。

**输入结构**：约 22x22 网格，背景黑(0)。左上角区域有一个小型不对称模板图案（如 3x3 的十字形或 L 形变体），由红(2)色像素组成，模板的外接矩形为 KxK（K=2 或 3）。网格其余区域有 2~3 个灰(5)色 1 像素厚空心矩形框，内部宽度分别为 K 的整数倍（如内部宽度分别为 4、6、9，对应 K=3 时缩放因子约为 1.3, 2, 3——修正：内部宽高均为 K 的整数倍，如 6x6 和 9x9，缩放因子为 2 和 3）。每个框内部恰好有一个蓝(1)色标记像素。生成约束：框的内部宽度和高度均为模板外接矩形边长 K 的整数倍；标记像素位置保证放大后的模板以标记为中心放置时不超出框的内部区域。

**规则**：
1. 识别模板图案（非黑、非灰、非蓝的最小连通分量）并确定其外接矩形边长 K。
2. 识别所有灰(5)色空心矩形框及其内部尺寸（内部宽 W、内部高 H）。
3. 对每个框，计算缩放因子 S = W / K（W = H = S*K，因为生成约束保证内部为正方形且边长为 K 的整数倍）。
4. 将模板图案进行 S 倍像素放大：模板中每个像素替换为 SxS 的同色块。
5. 将放大后的模板以该框内的蓝(1)色标记像素为中心印章到框内部：模板的非背景像素覆盖框内部对应位置的像素（用模板像素的颜色），背景像素不覆盖。
6. 标记像素本身被模板覆盖（如果模板中心是非背景像素）或保留（如果模板中心是背景像素）。
7. 模板在网格中的原始位置保持不变。

**关键洞察**：模板不是固定尺寸的印章——每个框根据自身大小与模板大小的比值独立决定缩放因子。同一个 3x3 模板在一个 6x6 框内变成 6x6 图案，在 9x9 框内变成 9x9 图案。缩放和印章不再是两个独立操作，而是通过上下文（目标框尺寸）紧密耦合。

## 新题 6：边框色驱动的区域内扫描线填充

**组合逻辑**：[填充(fill)/逐行扫描(row_scan)](已有) + [裁剪(crop)/完整边框检测(complete_border_check)](已有) → [框定区域内局部扫描线填充，填充色由框色决定](创新：同一种轮廓图案在不同框内产生不同颜色的填充结果)

**来源原语**：填充/轮廓像素/跨度/逐行扫描/填充轮廓间区域 ← aa18de87；裁剪/矩形框/内部区域/边框包围内容/完整边框检测 ← 1a6449f1

**依赖链**：检测完整矩形边框 → 在每个框的严格内部独立执行扫描线填充 → 填充色取决于边框颜色 → 嵌套框需要从内向外处理。边框检测确定了填充区域的边界和颜色，填充操作依赖于边框属性，二者不可分离。

在不同颜色的矩形边框内部，对相同的对角线轮廓图案执行扫描线填充，填充颜色随边框颜色而异。

**输入结构**：约 20x20 网格，背景灰(5)。2~3 个完整的 1 像素厚矩形边框，颜色各不相同（如蓝(1)、红(2)、绿(3)）。每个框的严格内部以灰(5)色为底，包含若干黑(0)色像素形成对角线轮廓笔画（从左上到右下或从右上到左下的斜线段）。各框内的轮廓图案可以不同（不同的斜线组合）。框之间不重叠，不嵌套。生成约束：每个框内的每一行至少有 0 或 2 个以上的黑色轮廓像素（保证扫描线有成对的端点或该行不需要填充）。

**规则**：
1. 检测所有完整的同色矩形边框（边框的四条边完整无缺）。
2. 对每个边框，取其严格内部区域（去除边框本身的像素）。
3. 在该内部区域内逐行扫描：在每行中，从左到右找到所有黑(0)色轮廓像素。对每对相邻的轮廓像素（第 1 和第 2 个、第 3 和第 4 个……），将它们之间的所有灰(5)色像素重涂为该边框的颜色。
4. 轮廓像素本身保持黑(0)色不变。
5. 不在任何边框内部的灰(5)色像素和黑(0)色像素保持不变。
6. 边框像素保持不变。

**关键洞察**：完全相同的扫描线填充算法，在蓝色边框内产生蓝色填充、在红色边框内产生红色填充。边框不仅是空间定界器，还是颜色参数的来源。这种"容器决定内容颜色"的关系是扫描线填充和边框检测两个独立概念的交叉涌现。

## 新题 7：格子连线后的交替可见性

**组合逻辑**：[连线(connect)/填充(fill)](已有) + [擦除(erase)/交替(alternating)](已有) → [格子连线 + 基于瓦片奇偶性的交替擦除](创新：连线填充完成后，沿连线路径按瓦片位置的奇偶性交替擦除，产生间断条纹效果)

**来源原语**：连线/填充/格子瓦片/端点标记/同行列对齐/同色同子格位置 ← a096bf4d；擦除/交替/中线交替打孔 ← 3bdb4ada

**依赖链**：按子格位置分组端点 → 在共享瓦片行或列的端点之间填充连线 → 沿连线路径按瓦片索引奇偶性交替擦除填充 → 起始相位由端点瓦片位置决定。连线确定了路径，交替擦除依赖路径和起始相位，起始相位依赖端点位置——三者循环依赖。

在瓦片格子中连接同色端点后，沿连线按瓦片奇偶性交替保留和擦除填充色，形成间断虚线。

**输入结构**：约 19x19 网格，由灰(5)色分隔行和分隔列划分为 4x4 阵列的瓦片。每个瓦片内部为 3x3，背景黑(0)。部分瓦片的特定子格位置（2x2 内部的四个位置之一，但此处瓦片内部为 3x3，用左上/右上/左下/右下四个角像素位置代替）有彩色端点标记。端点标记有 2~3 种颜色（如蓝(1)、红(2)、绿(3)），每种颜色恰好出现 2 个端点标记。同色的两个端点标记占据相同的子格位置（如都在瓦片内部的左上角像素），且共享同一瓦片行或同一瓦片列。生成约束：同色端点之间的瓦片路径上无其他颜色端点标记占据相同子格位置。

**规则**：
1. 按颜色和子格位置分组端点标记（每组恰好 2 个端点）。
2. 对每组，确定两端点的瓦片坐标。若共享瓦片行，连线方向为水平；若共享瓦片列，连线方向为垂直。
3. 在两端点之间的每个中间瓦片中，将对应子格位置的像素填充为该端点颜色。
4. 对连线路径上的所有瓦片（含两端点瓦片），按瓦片行主序为每个瓦片编号（从 0 开始：行号 x 列数 + 列号）。
5. 取起始端点（编号较小的瓦片）的编号奇偶性作为相位基准：若编号为偶数，偶数编号瓦片保留填充、奇数编号瓦片擦除；若编号为奇数，奇数编号瓦片保留填充、偶数编号瓦片擦除。
6. "擦除"指将该瓦片中对应子格位置的像素恢复为黑(0)色。
7. 若两条不同颜色的连线在同一瓦片的同一子格位置交叉且都需保留，该像素显示在网格中端点标记总数更多的颜色（生成约束保证不会出现相同数量的情况）。
8. 分隔线和其他未涉及的像素保持不变。

**关键洞察**：交替的相位不取决于连线本身的方向或长度，而取决于端点所在瓦片在全局阵列中的位置奇偶性。两条平行的连线如果起始瓦片的奇偶性不同，其间断模式会错开，产生需要对比多个示例才能归纳出的隐蔽规则。

## 新题 8：双源约束的扫描线着色

**组合逻辑**：[填充(fill)/逐行扫描(row_scan)](已有) + [重涂色(recolor)](已有) → [填充区域由轮廓确定、填充颜色由标记距离确定](创新：填充区域和填充颜色来自两个独立信息源，在每个像素处交汇)

**来源原语**：填充/轮廓像素/跨度/逐行扫描/填充轮廓间区域 ← aa18de87；重涂色/标记像素/包含于边界框 ← a04b2602；印章覆盖 ← 264363fd

**依赖链**：轮廓像素确定每行的填充跨度（哪些像素需要填充）→ 标记像素的位置确定每个填充像素的颜色（最近标记色）→ 填充区域和颜色来自不同来源，必须同时满足两个约束才能确定每个像素的最终状态。这是同时约束满足结构，非线性流水线。

对角线轮廓围成的区域按扫描线法填充，但每个像素的颜色取决于距离最近的标记像素的颜色。

**输入结构**：约 15x15 网格，背景黑(0)。若干灰(5)色像素形成对角线轮廓笔画，跨越大部分网格区域，勾勒出一个或多个封闭的轮廓形状。在网格中散布 2~4 个标记像素，颜色各不相同（如蓝(1)、红(2)、绿(3)、黄(4)），标记像素可以在轮廓围成的区域内部或外部。生成约束：每行中灰色轮廓像素数量为偶数（保证扫描线端点配对），标记像素不在灰色轮廓像素的位置上，标记像素之间的间距足够大使得不同填充区域能展现多种颜色。

**规则**：
1. 保留所有灰(5)色轮廓像素不变。
2. 逐行扫描：在每行中从左到右找到所有灰色轮廓像素，按相邻对（第 1-2 个、第 3-4 个……）确定填充跨度。
3. 对每个需要填充的黑(0)色像素，计算它与每个标记像素的曼哈顿距离。
4. 将该像素重涂为距离最近的标记像素的颜色。若距离相等，取行号较小的标记像素的颜色；若行号也相等，取列号较小的。
5. 标记像素本身保持其原始颜色不变（即使它落在填充跨度内，也不重涂）。
6. 不在任何填充跨度内的黑色像素保持不变。

**关键洞察**：填充的"在哪里"由轮廓几何决定，填充的"用什么颜色"由标记像素距离决定——两个完全独立的信息源在每个像素处交汇。这不是先分析再填充的线性流水线，而是每个像素的输出同时依赖两种不同维度的判断。

## 新题 9：环形拓扑上的形状轮换与锚点重建

**组合逻辑**：[补全/重建(reconstruct)](已有) + [重涂色(recolor)](已有) + [旋转(rotate，拓扑旋转)](已有) → [环序决定形状来源、自身锚点决定绘制位置、自身标记决定绘制颜色](创新：形状、位置、颜色三者分别来自不同来源，通过环形拓扑耦合)

**来源原语**：补全/重建/擦除/字形模板/颜色对应形状/锚点定位/边框竖条/端点标记 ← 98c475bf；重涂色/环形连接/连接线/顺时针轮换/空心方框/内部遮罩 ← ad173014

**依赖链**：识别环形连接拓扑 → 确定顺时针顺序 → 每个区域从顺时针下一个区域获取形状模板 → 用自身的端点标记颜色绘制该形状 → 锚定在自身端点标记所在的行。形状来源、颜色来源、位置来源分属三个不同实体，通过环形拓扑和局部锚点联结。

多个框架区域在环形拓扑中相连，每个区域接收来自顺时针邻居的形状模板，但用自己的标记颜色和锚点位置绘制。

**输入结构**：约 25x25 网格，背景黑(0)。3~4 个红(2)色空心方框（5x5 至 7x7 不等），由蓝(1)色线段两两连接形成一个封闭环路。每个方框的内部包含一个由某种颜色（非红、非蓝、非黑，如绿(3)、黄(4)、橙(7)、品红(6)）绘制的小型字形图案（3~5 像素的 4-连通图形，形状各异——有的呈直线段，有的呈折线，有的呈小块状）。每个方框的内部还有一对端点标记像素：两个同色像素分别位于方框内部的最左列和最右列的同一行，颜色与该方框内字形颜色不同（端点标记颜色取自上述非红非蓝非黑的颜色集合，但与本框字形颜色不同）。生成约束：每个方框恰好触碰两条蓝色连接线，连接线形成唯一环路；各方框内的字形形状互不相同；各方框的端点标记颜色互不相同。

**规则**：
1. 识别所有红(2)色空心方框和蓝(1)色连接线，确定环路结构。
2. 以方框中心坐标为基准，按顺时针方向排列方框，确定环序：A → B → C → D → A。
3. 提取每个方框内部字形图案的形状（记录像素相对于字形外接矩形左上角的偏移集合，忽略颜色）。
4. 记录每个方框内部的端点标记对：标记颜色和标记所在行。
5. 擦除所有方框内部的字形图案和端点标记（设为黑(0)）。
6. 对每个方框 X，从环序中顺时针方向的下一个方框 Y 获取字形形状模板。
7. 在方框 X 的内部，用方框 X 自身的端点标记颜色绘制方框 Y 的字形形状，将字形的水平中心对齐到方框 X 内部的水平中心，将字形锚定在方框 X 的端点标记所在行（字形外接矩形的第一行对齐到端点标记行）。
8. 重新绘制方框 X 的端点标记对（保持原色和位置）。
9. 红色方框边框和蓝色连接线保持不变。

**关键洞察**：每个方框的最终内容由三个不同来源决定——形状来自环序中的下一个邻居，颜色来自自身的端点标记，垂直锚定位置也来自自身的端点标记行。这种"形状轮转但颜色和位置不轮转"的分离式变换，只有在理解环形拓扑和锚点机制的双重作用后才能归纳，仅看单个示例的前后对比无法区分形状是来自哪个邻居。
