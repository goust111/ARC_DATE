## 新题 1：遮挡深度决定同心层数

**组合逻辑**：[排序/sort](已有) + [遮挡顺序/occlusion_order](已有) → [计数/counting](创新：遮挡入度作为层数参数) → [同心层填充/concentric_fill](创新：层数由外部参数控制而非固定)

**来源原语**：排序(c920a713), 遮挡顺序(c920a713), 交叉处可见性(c920a713), 矩形边框(c920a713), 同心层填充(a3f84088), 按距离循环配色(a3f84088), 计数(89565ca0)

**依赖链**：交叉分析得到遮挡有向图 → 每个边框的入度（被多少个边框遮挡）成为该边框的同心层数参数 → 按遮挡顺序从底到顶逐层绘制同心方环 → 高层边框覆盖低层重叠区域

从重叠矩形边框的交叉可见性推断遮挡等级，每个边框的遮挡入度决定其内部绘制多少层同心方环，最终按从底到顶的顺序叠加输出。

**输入结构**：约 15x15 黑(0)背景网格。3~4 个一像素厚的轴对齐矩形边框，每个边框使用不同的非黑颜色（如红(2)、蓝(1)、绿(3)、黄(4)）。边框两两有部分重叠，在交叉点处只有一个颜色可见（记录遮挡关系）。每个边框的完整矩形至少 5x5，保证有足够空间绘制多层同心环。生成约束：遮挡关系构成全序（无环），即存在唯一的从底到顶排列；每个边框的可见像素足以确定其完整边界框。

**规则**：
1. 对每种颜色，取其所有可见像素的边界框作为该边框的完整矩形。
2. 在两个边框的周长交叉处，若颜色 B 覆盖了颜色 A，则添加有向边 A→B（A 被 B 遮挡）。
3. 对每个边框计算入度 d（被多少个其他边框遮挡）。令该边框的同心层数 = d + 1。
4. 在每个边框的边界框内部绘制同心方环：从最外层开始，颜色交替为"边框本色 → 黑(0) → 边框本色 → 黑(0) → ..."，共绘制 d+1 层。若空间不足以放下所有层，截断到能容纳的最大层数。
5. 按遮挡顺序从底（入度最大的）到顶（入度=0的）依次绘制。后绘制的覆盖先绘制的像素。

**关键洞察**：遮挡深度不仅决定绘制顺序，还编码了每个边框内部的同心层数——被压在最底下的边框反而拥有最多的同心环层（因为入度最高），形成"越被遮挡越复杂"的反直觉映射。需要对比多个示例才能发现入度与层数的对应关系。

## 新题 2：镜线路由射线填充封闭区域

**组合逻辑**：[射线延伸/ray_extension](已有) → [镜像/mirror](创新：镜面不反射形状而是改变射线方向) → [填充/flood_fill](创新：填充目标由射线到达位置决定)

**来源原语**：射线延伸(5961cc34/d037b0a7), 镜像(6855a6e4), 填充(753ea09b), 封闭背景区域(753ea09b), 最近邻归属(6855a6e4), 碰撞停止(2c608aff)

**依赖链**：源像素发射竖直射线 → 射线命中水平镜线后反射为水平方向（命中左半段转左、右半段转右） → 水平射线穿行至进入某封闭轮廓内部 → 该轮廓的封闭背景区域被填充为源像素的颜色

彩色源像素向下发射射线，碰到水平镜线后偏转为水平方向，偏转后的射线抵达哪个封闭轮廓就将其内部填充为源像素的颜色。

**输入结构**：约 18x18 黑(0)背景网格。上部区域：2~3 个彩色单像素（如红(2)、绿(3)、黄(4)），各自位于不同列。中部区域：2~3 条水平灰(5)线段（长度 5~7 像素），各线段不在同一行，互不相连，每条线段严格水平。下部区域：2~3 个由蓝(1)像素构成的封闭轮廓形状（4-连通闭合环，每个围住一块黑色背景区域，轮廓像素数 8~16，内部面积 2~6 像素）。生成约束：每个源像素的正下方恰好有一条灰(5)镜线段可被命中；每条镜线段最多被一个源像素命中；每条反射后的水平射线路径上恰好有一个蓝(1)轮廓的开口侧可以进入，不存在一条射线能到达两个轮廓的情况。

**规则**：
1. 每个彩色源像素向下发射一条竖直射线（逐行向下）。
2. 射线碰到灰(5)镜线段的某个像素后停止竖直运动，转为水平运动：若命中点位于该线段中点（含）左侧，射线转向左；若位于中点右侧，射线转向右。线段长度为偶数时，中点取左半最右像素。
3. 水平射线沿转向方向逐列前进，途中绘制源像素颜色。射线遇到蓝(1)轮廓像素时穿过该轮廓边界进入其内部。
4. 将该轮廓围住的全部黑(0)背景像素填充为源像素的颜色。
5. 源像素从原位置擦除。灰(5)镜线段和蓝(1)轮廓边界保持不变。水平射线经过的路径像素保留在输出中。
6. 若两条射线试图填充同一轮廓（生成时保证不会发生），则路径总长度较短的射线优先。

**关键洞察**：镜线不是在反射形状，而是在路由射线——源像素击中镜线的水平位置决定了偏转方向，进而决定哪个封闭区域被填充。同一个源像素若从不同列发射，会因命中镜线的不同位置而填充完全不同的目标区域。

## 新题 3：封闭区域奇偶性选择面板变换类型

**组合逻辑**：[计数/counting](已有) → 条件分支（创新：奇偶判定 × 引导线有无 = 四路决策表） → [镜像/mirror](已有) / [填充/flood_fill](已有) / 旋转(创新)

**来源原语**：计数(89565ca0), 镜像(4e7e0eb9), 重涂色(4e7e0eb9), 九宫面板(4e7e0eb9), 引导线(4e7e0eb9), 轴线决定变换(4e7e0eb9), 封闭区域(89565ca0), 区域数映射长度(89565ca0)

**依赖链**：面板内线条画分割出若干封闭背景区域 → 计数区域数得到 N → N 的奇偶性与引导线的有无组合成四种情况 → 每种情况对应不同的变换操作（镜像/填充反转/旋转/不变）

网格被分成若干面板，每个面板包含线条画和可能的引导线；面板内封闭区域的数量决定对该面板施加哪种几何变换。

**输入结构**：约 21x21 网格，由单像素宽灰(5)网格线分隔为 3x3 共 9 个面板，每个面板内部约 6x6。每个面板内部包含：(a) 一个由某种非黑非灰颜色构成的线条画（4-连通的单色像素集合，形成 1~3 个封闭的黑(0)背景区域，像素数 6~15），以及 (b) 可能存在的引导线——面板内部中间行或中间列被另一种非黑非灰颜色完全填满的单行/单列线段。不同面板的线条画颜色可以相同也可以不同。生成约束：9 个面板中至少出现全部四种组合情况（奇数+有引导线、偶数+有引导线、奇数+无引导线、偶数(>0)+无引导线）各至少一例；引导线颜色在整个网格中统一；每个面板的封闭区域数不超过 3。

**规则**：
1. 对每个面板，将其线条画像素作为障碍，计算面板内 4-连通的黑(0)背景区域中被线条画完全包围的数量 N（与面板边缘相连的背景区域不算封闭）。
2. 判断该面板是否包含引导线（中间行全填 = 水平引导线；中间列全填 = 竖直引导线）。
3. 按以下决策表变换面板内容（引导线和线条画一起变换，灰色网格线不变）：
   - N 为奇数且有水平引导线：沿引导线上下镜像翻转面板内容。
   - N 为奇数且有竖直引导线：沿引导线左右镜像翻转面板内容。
   - N 为偶数（N>0）且有引导线：将所有封闭背景区域填充为引导线的颜色，同时将原线条画像素改为黑(0)（图底反转）。
   - N 为奇数且无引导线：将面板内容旋转 180 度。
   - N 为偶数（N>0）且无引导线：将所有封闭背景区域填充为线条画的颜色（仅填充，不擦除线条画）。
   - N = 0（无封闭区域）：面板保持不变。
4. 变换后的面板放回原位，灰(5)网格线保持不变。

**关键洞察**：单独知道引导线类型不足以确定操作（与 4e7e0eb9 不同，那里引导线类型直接决定操作），单独知道区域数也不够——必须同时确定两者才能查表。需要对比包含不同组合情况的多个示例才能归纳出完整的决策表。

## 新题 4：连接杆编码旋转，面积匹配选定目标腔

**组合逻辑**：[擦除/erase](已有) + [计数/counting](创新：像素数用于面积匹配而非缩放) → [面积匹配/area_matching](已有) → [连接杆/connector_stem](创新：方向编码旋转角度而非滑动方向)

**来源原语**：擦除(98cf29f8), 计数(7acdf6d3), 连接杆(98cf29f8), 轮廓对象(7acdf6d3), 面积匹配(7acdf6d3), 像素数等于腔面积(7acdf6d3), 碰撞阻挡(98cf29f8)

**依赖链**：将精灵体与连接杆分离 → 计数精灵体像素数 → 在轮廓对象中找到内腔面积等于该像素数的唯一匹配 → 根据连接杆指向确定旋转角度 → 将旋转后的精灵体放入匹配的轮廓内腔

每个精灵体通过连接杆挂载，连接杆方向编码放置时的旋转角度，精灵体的像素数量决定它被放入哪个轮廓对象的内腔中。

**输入结构**：约 16x16 黑(0)背景网格。包含 2~3 个小型彩色精灵体（每个是 4-连通的单色不规则形状，像素数 3~6，颜色互不相同且非黑非绿），每个精灵体的边界框某一侧连接一条同色的直线段（宽 1 像素，长 2~4 像素），该直线段指向上/下/左/右四个基本方向之一。另外，网格中散布 2~3 个绿(3)像素构成的空心轮廓形状（每个轮廓是 8-连通的闭合环，内部是黑(0)背景区域，内腔面积各不相同且恰好与某个精灵体的像素数一一对应）。精灵体及其连接杆与所有绿(3)轮廓互不相邻。生成约束：精灵体的像素数两两不同；轮廓内腔面积集合与精灵体像素数集合完全相同（一一映射）；每个精灵体旋转后能完整嵌入其匹配轮廓的内腔（内腔形状容纳旋转后的精灵体，无需裁剪）。

**规则**：
1. 对每个精灵体，识别其连接杆：从精灵体边界框的某一侧延伸出的最长直线同色段即为连接杆。将精灵体像素集与连接杆像素集分离。
2. 计数精灵体像素数 P（不含连接杆）。
3. 在所有绿(3)轮廓对象中，找到内腔面积（轮廓内部 4-连通黑(0)区域的像素数）恰好等于 P 的唯一轮廓。
4. 根据连接杆指向确定旋转角度：杆指向右 → 0 度（不旋转）；杆指向下 → 顺时针 90 度；杆指向左 → 180 度；杆指向上 → 逆时针 90 度（即顺时针 270 度）。
5. 将精灵体按上述角度旋转后，放入匹配轮廓的内腔中，锚定于内腔边界框的左上角。精灵体使用其原始颜色绘制。
6. 从原始位置擦除精灵体及其连接杆。绿(3)轮廓边界保持不变。

**关键洞察**：连接杆同时承担两个独立功能——它是结构上分离精灵体本体的标记（确定哪些像素参与计数），也是旋转指令的编码器（方向决定角度）。若不识别连接杆，既无法正确计数也无法确定旋转，两条信息通道耦合在同一个结构元素上。

## 新题 5：异或差异像素播种对角线交错铺满

**组合逻辑**：[逐像素比较/cell_by_cell_comparison](已有) → [差异标记/mark_differences](创新：差异不直接输出，而是成为下一步的种子) → [循环填充/cyclic_fill](创新：沿对角线方向而非原始的等距偏移) + [同余类交错铺满/congruence_interlaced](已有)

**来源原语**：逐像素比较(34b99a2b), 异或差异判定(34b99a2b), 分隔列(34b99a2b), 循环填充(05269061), 对角线(05269061), 同余类交错铺满(05269061)

**依赖链**：移除分隔列并逐像素比较左右面板 → 将差异分为三类（仅左有/仅右有/两侧都有），分别着色 → 每类着色像素成为对角线种子，沿 ±1 斜率方向按模 3 同余类扩展 → 多色对角线交织形成最终图案

两个面板的像素差异被分类着色后，每种颜色的差异像素作为种子沿对角线方向周期性扩展，交织出密集的对角线图案。

**输入结构**：约 7x15 网格（高 7，宽 15）。正中央第 8 列（从 1 计）为灰(5)分隔列，将网格分为左右两个 7x7 面板。左面板：黑(0)背景上散布若干红(2)像素（4~8 个，不构成特定形状，分布较均匀）。右面板：黑(0)背景上散布若干蓝(1)像素（4~8 个），与左面板的红(2)像素部分重叠、部分不重叠（以面板内相对坐标衡量）。生成约束：三种差异类别（仅左有、仅右有、两侧都有）各至少出现 1 个像素；对角线扩展后不同颜色的冲突像素至少出现 2 处（以验证优先级规则）。

**规则**：
1. 移除灰(5)分隔列，将左右面板按行列对齐到同一个 7x7 坐标系。
2. 逐像素比较：
   - 仅左面板有前景像素（红(2)）的位置 → 在 7x7 输出中标记为红(2)。
   - 仅右面板有前景像素（蓝(1)）的位置 → 标记为蓝(1)。
   - 两侧都有前景像素的位置 → 标记为黄(4)。
   - 两侧都是背景的位置 → 暂时保持黑(0)。
3. 对输出中每个非黑像素 (r, c)，沿斜率 +1 方向（右下）以间隔 3 重复该颜色：将 (r+3k, c+3k) 和 (r-3k, c-3k)（k=1,2,...）中落在 7x7 网格内的像素涂为同一颜色。
4. 同时沿斜率 -1 方向（右上）以间隔 3 重复：将 (r-3k, c+3k) 和 (r+3k, c-3k)（k=1,2,...）中落在网格内的像素涂为同一颜色。
5. 当多种颜色的对角线扩展争夺同一像素时，优先级为：黄(4) > 蓝(1) > 红(2)。即黄色覆盖蓝色和红色，蓝色覆盖红色。
6. 输出为 7x7 网格。

**关键洞察**：逐像素比较不是终点而是起点——差异分类产生的三种颜色成为对角线扩展的种子，最终输出是这些种子经周期性对角线铺满后交织的结果。单看一个示例无法确定扩展间隔为 3 还是其他值，也无法确定颜色优先级，必须对比多组输入输出才能归纳。

## 新题 6：列填射线高度排序决定同心环配色

**组合逻辑**：[射线延伸/ray_extension](已有) → [排序/sort](创新：按射线长度排序而非遮挡关系) → [同心层填充/concentric_fill](创新：每层颜色由排序结果指定而非固定循环)

**来源原语**：射线延伸(d037b0a7), 前景源像素(d037b0a7), 同列传播(d037b0a7), 沿列填至底(d037b0a7), 同心层填充(a3f84088), 空心矩形(a3f84088), 按距离循环配色(a3f84088), 排序(c920a713), 嵌套层次(a3f84088)

**依赖链**：每个源像素向下延伸至网格底部形成彩色竖条 → 竖条高度 = 网格总行数 - 源像素所在行数 → 按高度从大到小排序得到颜色序列 → 该序列依次赋给空心矩形的同心方环（从外到内）

源像素向下延伸产生不同长度的彩色竖条，竖条长度的排序决定了空心矩形内部同心方环从外到内的配色顺序。

**输入结构**：约 15x15 黑(0)背景网格。上半部分：一个灰(5)空心正方形边框（边长 9~11 像素，边框厚 1 像素，内部为黑(0)）。下半部分（空心矩形下方）：3~4 个彩色单像素（颜色各不相同，如红(2)、蓝(1)、绿(3)、黄(4)），分布在不同列，各像素所在行不同（行号越小表示离网格顶部越近，竖条越长）。生成约束：所有源像素均在空心矩形的下方；每个源像素所在列不与空心矩形的左右边框同列（竖条不穿过边框）；源像素行号两两不同（保证高度排序无并列）；源像素数量不超过空心矩形可容纳的同心方环层数（例如边长 11 的边框最多容纳 5 层，要求源像素 <= 5 个）。

**规则**：
1. 复制输入网格。对每个非黑、非灰的源像素 (r, c)，将从第 r 行到网格最底行的整列 c 全部涂为该源像素的颜色（沿列向下填充）。
2. 计算每条竖条的高度 H = 网格总行数 - r（源像素行号从 0 计）。
3. 将所有源像素按竖条高度从大到小排序，得到颜色序列 [C1, C2, C3, ...]。
4. 在灰(5)空心矩形的边界框内绘制同心方环：最外层保持灰(5)。第一层内环涂 C1，第二层内环涂 C2，以此类推。若颜色序列用完而仍有更内层空间，则剩余内层保持黑(0)。
5. 竖条在输出中保留可见。空心矩形外部除竖条外保持黑(0)。

**关键洞察**：源像素的行位置表面上只是空间坐标，但通过向下延伸转化为可比较的长度量，这个长度量再映射为同心环的由外到内顺序。需要多个示例才能发现"高度排序→由外到内配色"的映射规则，以及灰色最外层始终保留的约定。

## 新题 7：双面板并集构造滑动目标形状

**组合逻辑**：[透明叠加/transparent_overlay](已有) + [并集合并/union_merge](已有) → [滑动/sliding](创新：滑动目标不是预存对象而是叠加后的涌现形状) + [碰撞阻挡/collision_blocking](已有)

**来源原语**：透明叠加(5d2a5c43), 并集合并(5d2a5c43), 分隔列(5d2a5c43), 双侧对齐(5d2a5c43), 滑动(3906de3d), 竖条(3906de3d), 碰撞阻挡(3906de3d), 同列对齐(3906de3d)

**依赖链**：移除分隔列并将左右面板的黄色像素取并集得到青色目标形状 → 底部的红色竖条在合并后的网格中沿列向上滑动 → 竖条碰到青色目标形状的底边时停止

两个面板的黄色像素分别是目标形状的左右两半碎片，叠加合并后才构成完整的阻挡物，底部红色竖条向上滑动至碰到该涌现形状为止。

**输入结构**：约 12x25 网格（高 12，宽 25）。第 13 列（从 1 计）为蓝(1)分隔列。左面板（12x12）：黑(0)背景上有若干黄(4)像素（5~10 个），组成目标形状的部分碎片（不连通也不构成可辨识形状）。右面板（12x12）：黑(0)背景上有若干黄(4)像素（5~10 个），组成目标形状的另一部分碎片，与左面板的碎片在行列坐标上部分互补。两面板最底部 2 行包含若干红(2)竖条段（每段高 1~2 像素），分布在不同列。生成约束：左右面板的黄(4)像素取并集后形成一个有意义的连通阻挡形状（例如跨越多列的横向不规则带），该形状位于面板上半部分；每条红(2)竖条所在列的正上方在合并后的目标形状中至少有一个黄→青像素（保证每条竖条都能碰到目标停下）；两面板各自的黄(4)像素单独不构成有效阻挡（即若只看一面板，某些竖条上方无黄色像素，会滑出网格顶部）。

**规则**：
1. 移除蓝(1)分隔列。将左右面板按行列对齐合并为一个 12x12 网格。
2. 合并规则：任一面板在 (r,c) 有黄(4)像素 → 合并网格中 (r,c) 涂为青(8)。两面板都是黑(0)的位置保持黑(0)。
3. 保留红(2)竖条段：对左面板中的红(2)像素，直接放入合并网格对应位置；对右面板中的红(2)像素，同样放入。若红色与青色冲突（同一位置），青色优先。
4. 每条红(2)竖条（同列的连续红色段）沿其所在列向上滑动，保持段长不变，直到段的最上方像素紧贴（正下方相邻）该列中最低的青(8)像素。
5. 红色竖条滑动后，原位置恢复为黑(0)。青(8)目标形状不变。
6. 输出为 12x12 网格。

**关键洞察**：目标形状在任何一个面板中都不完整——只有合并后才涌现出能阻挡所有竖条的连续结构。求解者必须先理解并集合并规则，才能预测每条竖条的停止位置。叠加步骤不是输出本身而是中间构造步骤。

## 新题 8：分隔框架房间数决定角落精灵体跳跃距离

**组合逻辑**：[计数/counting](已有) → [复制/copy](创新：复制距离由计数结果参数化而非固定一步) + [顺时针到下一角/clockwise_next](创新：泛化为顺时针跳 N 步)

**来源原语**：复制(bc93ec48), 计数(89565ca0), 重建(89565ca0), 角落对象(bc93ec48), 接触两边缘(bc93ec48), 分隔框架(89565ca0), 封闭区域(89565ca0), 顺时针到下一角(bc93ec48), 忽略干扰项(89565ca0/bc93ec48), 区域数映射长度(89565ca0)

**依赖链**：每个角落包含一个精灵体和一个分隔框架 → 重建框架墙壁、计数封闭背景区域数 N → 精灵体沿顺时针方向跳跃 N 个角落位置 → 将精灵体副本放置于目标角落

四个角落各有一个精灵体和一个分隔框架，框架内的房间数决定精灵体沿顺时针方向跳过几个角落再落下。

**输入结构**：约 17x17 黑(0)背景网格。四个角落区域（每个约占 4x4~5x5 范围）各包含：(a) 一个小型单色精灵体（4-连通，3~5 像素，形状不规则，颜色各不相同，如红(2)、蓝(1)、绿(3)、黄(4)），精灵体的边界框接触该角落的两条边缘（即贴在角落处）；(b) 紧邻精灵体但不与之相连的一个灰(5)小型分隔框架（由水平和竖直灰色线段构成的矩形框并带有内部分隔线，整体约 3x3~4x4，框架将其内部分割为 1~3 个黑(0)背景小房间）。网格中央区域可能存在若干品红(6)干扰像素（散布的单像素或小块），它们不参与任何规则。生成约束：四个角落的房间数取值为 {1, 2, 3} 中的不同组合（允许重复），使得至少有两个角落的跳跃距离不同；精灵体足够小，放置到任何目标角落时不会超出网格边界；每个分隔框架的墙壁线段清晰，不被干扰像素破坏。

**规则**：
1. 忽略所有品红(6)干扰像素。
2. 对每个角落的灰(5)分隔框架：识别其水平和竖直墙壁线段，计算框架内部被墙壁完全围合的 4-连通黑(0)背景区域数量 N（1 <= N <= 3）。
3. 将该角落的精灵体沿顺时针方向跳跃 N 个位置：角落编号为左上=0、右上=1、右下=2、左下=3。若精灵体在角落 k，则跳到角落 (k+N) mod 4。
4. 将精灵体的像素图案（保持原始朝向和形状）复制到目标角落，对齐方式为：精灵体边界框的角与目标角落的网格角重合。例如：跳到右上角时，精灵体边界框的右上角与网格的右上角重合。
5. 原始精灵体保留在原位不擦除（即原始位置和目标位置都有该精灵体的像素）。
6. 若两个精灵体的副本落在同一角落且像素重叠，按顺时针处理顺序（左上→右上→右下→左下），后处理的覆盖先处理的。
7. 灰(5)分隔框架和品红(6)干扰像素在输出中全部擦除。

**关键洞察**：分隔框架不是装饰——它们的房间数编码了一个位移指令。房间数为 2 的角落会把精灵体送到对角（跳两步），而非相邻角落，这产生了非直觉的交叉路由。擦除框架后，输出中只剩精灵体及其副本，框架的"信息"已被消耗为位移参数。
