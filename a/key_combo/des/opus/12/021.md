## 新题 1：对称门控洪泛填充

**组合逻辑**：[对称类型检测](创新：对称类型不再直接映射颜色，而是决定洪泛的通行方向) + [填充](创新：填充受门控墙壁约束，门的朝向与对称类型耦合) + [重涂色](已有：按可达区域涂色)

**来源原语**：对称类型决定颜色(symmetry_det_color) ← a09f6c25；填充(fill) ← aba27056/305b1341；墙壁障碍(wall_barrier) + 可达性(reachability) ← dd6b8c4b；障碍门处标记通道(barrier_gate_mark) ← fc10701f

**依赖链**：对称检测的结果不直接产出，而是筛选哪些墙壁缺口可通行，从而决定洪泛的可达范围；可达范围又决定最终的涂色区域。三者环环相扣：改变对称类型→改变可通行缺口→改变涂色区域。

在被墙壁分隔的多个房间中，每个种子形状的对称类型决定了它可以穿过哪个朝向的门洞进行洪泛填充，最终用种子颜色填满所有可达房间。

**输入结构**：约 18x18 的网格，背景为黑(0)。灰(5) 像素组成墙壁，将网格分隔为 4~6 个不规则房间。墙壁上有单像素宽的缺口作为门洞，每个门洞要么是水平朝向的（在竖直墙段上的缺口），要么是垂直朝向的（在水平墙段上的缺口）。每个房间中恰好有一个由蓝(1)、绿(3) 或红(2) 像素组成的 4-连通小图形（3~6 像素），这些图形各自恰好具有一种反射对称类型：水平对称、垂直对称、或无对称（仅旋转对称/不对称）。生成约束：每个房间恰好一个种子图形；同一房间的门洞不全同朝向；不同示例中同色种子的对称类型不同，迫使求解者从几何属性而非颜色归纳规则。

**规则**：
1. 检测每个种子图形的反射对称类型：水平对称、垂直对称、或无对称。
2. 水平对称的种子只能穿过水平朝向的门洞（竖直墙段上的缺口）进入相邻房间；垂直对称的种子只能穿过垂直朝向的门洞（水平墙段上的缺口）。无对称的种子可以穿过任意门洞。
3. 从每个种子出发，沿可通行门洞进行洪泛扩散，将所有可达的背景(0)像素涂为该种子的颜色。种子本身保持原色不变。
4. 若两个种子的填充区域在同一房间相遇（通过不同门洞到达同一房间），该房间的填充色取从各自种子出发到该房间经过的门洞数较少的种子颜色；若门洞数相同，取种子边界框左上角行号较小的种子颜色。
5. 墙壁像素灰(5)和种子图形像素保持不变，不被覆盖。

**关键洞察**：对称类型不是简单地映射到输出颜色，而是作为拓扑过滤器决定了洪泛的路径图——同一空间布局下，改变种子的对称性就会改变整个填充格局。

## 新题 2：图例驱动的缩放印章叠层

**组合逻辑**：[像素放大](创新：缩放因子不再由标记方块边长给出，而由图例行数编码) + [印章覆盖](已有：在目标位置放大绘制) + [重涂色](创新：图例提供颜色映射，放大后的精灵按图例转色) + [冲突优先级](创新：图例行序决定叠层优先级)

**来源原语**：像素放大(pixel_scaling) + 印章覆盖(stamp) + 边长定缩放因子(side_sets_scale) ← 447fd412；图例(legend) + 图例配色(legend_color_pair) + 图例顺序决定层级(legend_order_layer) + 冲突优先级(conflict_priority) ← 305b1341；重涂色(recolor) ← 9b5080bb

**依赖链**：图例同时编码两项信息——颜色映射和缩放因子（行数）；颜色映射决定精灵放大后的颜色，行序决定绘制叠层；缩放因子决定每个精灵放大多少倍。这三项信息全部从图例中解读，缺少任何一项都无法确定输出。

读取图例获取颜色映射和缩放因子，将每个精灵按因子放大并按图例转色后印章到目标位置，图例行序决定重叠时的优先级。

**输入结构**：约 20x20 的网格，背景为黑(0)。左侧两列（列 0 和列 1）为图例区，从第 0 行开始，每行左列为源色、右列为目标色，图例行数 k 即为缩放因子（如图例有 3 行则 k=3）。网格右侧散布 2~4 个小精灵体，每个精灵是一个由图例源色之一组成的 4-连通不规则小图形（2~4 像素），边界框不超过 3x3。每个精灵旁边（曼哈顿距离 1~2 像素处）有一个与该精灵同源色的单像素标记，标记的位置表示放大后精灵边界框左上角的目标位置。生成约束：放大后的精灵边界框互不重叠，或重叠区域由图例行序仲裁；所有精灵源色都出现在图例中。

**规则**：
1. 读取图例区（列 0-1），提取源色→目标色映射，并记录图例行数 k 作为全局缩放因子。
2. 对每个精灵，以其边界框内的图案为模板，将每个像素放大为 k x k 的色块，颜色从源色替换为图例中对应的目标色。
3. 将放大后的图案放置在该精灵的标记像素所指示的目标位置（标记像素即为放大后边界框的左上角），超出网格边界的部分裁剪。
4. 若多个放大精灵的区域重叠，图例中行号较小（靠前）的源色对应的精灵在上层（覆盖下层）。
5. 清除原始精灵和标记像素，清除图例区（全部置为黑(0)）。输出仅保留放大印章后的结果。

**关键洞察**：缩放因子没有单独编码，而是隐含在图例本身的行数中——图例同时承载颜色映射、缩放因子和优先级三重信息，需要对比多个示例（不同行数的图例）才能发现行数即倍率的规则。

## 新题 3：路径绘制中的对称绕行着色

**组合逻辑**：[路径绘制](已有：从边界标记出发向内直行) + [绕行](创新：绕行方向不再由障碍颜色决定，而由障碍的几何对称类型决定) + [重涂色](创新：绕行段的颜色由对称类型标记，区分于主路径)

**来源原语**：路径绘制(path_drawing) + 绕行(detour) + 障碍色决定绕行(obstacle_color_detour) + 阻挡(blocking) ← 96a8c0cd；对称类型决定颜色(symmetry_det_color) + 对称轴(symmetry_axis) ← a09f6c25；重涂色(recolor) ← 9b5080bb

**依赖链**：路径遇到障碍时需要绕行；绕行方向取决于障碍的对称类型（需先做几何分析）；绕行段颜色又由对称类型决定。对称分析同时驱动两个下游决策（方向和颜色），路径的最终形态是三者交织的结果。

从边界标记出发的红色路径遇到障碍时，根据障碍形状的对称类型决定绕行方向，并用对称类型对应的颜色绘制绕行段。

**输入结构**：约 15x15 的网格，背景为黑(0)。网格某条边上有一个红(2)标记像素作为路径起点。网格内部有 2~4 个障碍物，每个障碍物由橙(7)像素组成的 4-连通图形构成（3~5 像素），垂直或水平排列于路径前方。每个障碍物恰好具有一种反射对称类型——水平对称或垂直对称（不存在无对称的障碍物）。障碍物之间沿路径前进方向排列，互不接触。生成约束：路径从标记出发沿垂直于所在边的方向直行；每个障碍物至少有一个像素在路径的直行通道上；障碍物与网格边缘之间有足够空间完成绕行。

**规则**：
1. 红(2)标记从所在边界向网格内部沿垂直方向直行，沿途背景像素涂为红(2)。
2. 当路径前方遇到橙(7)障碍物时，检测该障碍物的反射对称类型。
3. 若障碍物为水平对称（有水平对称轴），路径从行进方向的左侧绕行；绕行段涂为蓝(1)。
4. 若障碍物为垂直对称（有垂直对称轴），路径从行进方向的右侧绕行；绕行段涂为绿(3)。
5. 绕行路线：路径在障碍物前一格横移一格到达绕行侧，沿障碍物边缘纵向通过，通过后横移一格回到原通道，继续以红(2)直行。绕行全程仅改变背景像素，不修改障碍物。
6. 路径到达对面边界时停止。所有障碍物橙(7)像素保持不变。

**关键洞察**：障碍物的颜色是统一的橙色，无法从颜色判断绕行方向——必须分析障碍物的几何对称性才能决定左绕还是右绕，这要求对比多个示例中不同对称形状的绕行行为才能归纳规则。

## 新题 4：杯口射线与虚线间隙的交叉着色

**组合逻辑**：[射线延伸](创新：射线不再填充到边界，而是与已有虚线结构交互) + [填充](创新：间隙填充色由射线来源决定而非固定色) + [开口朝向](已有：决定射线方向)

**来源原语**：射线延伸(ray_cast) + 从开口发射(emit_from_opening) + 开口朝向(opening_direction) ← aba27056；填充(fill) + 单像素间隙补填(single_gap_filled) + 邻接(adjacency) ← a699fb00；杯形容器(cup_shape) + 封闭区域(enclosed_region) + 内部包含(interior_containment) ← aba27056

**依赖链**：杯口方向决定射线发射方向；射线路径与虚线段的间隙产生交叉点；交叉点处间隙被填充为杯体颜色而非默认色。射线方向、虚线位置、杯体颜色三者共同决定最终哪些间隙被填成什么色。

杯形容器发射射线，射线穿过虚线段间隙时将间隙染为杯体颜色，未被射线触及的间隙保持默认填充色。

**输入结构**：约 16x16 的网格，背景为黑(0)。网格中有 2~3 条水平虚线段，每条由蓝(1)像素组成，蓝色像素之间间隔一个黑色像素（即模式为蓝-黑-蓝-黑-蓝...），每条虚线段至少长 7 像素。网格中另有 2~3 个杯形容器，每个杯的壁由一种非蓝非黑颜色（如红(2)、绿(3)、黄(4)中的一种）组成，杯壁为 4-连通的 U 形或旋转后的 U 形（5~8 像素），有一个方向的开口。每个杯的开口朝向不同。杯的内部为黑色。生成约束：每个杯的射线路径至少穿过一条虚线段；不同杯的射线不穿过同一个间隙；杯与虚线段互不接触。

**规则**：
1. 对每个杯形容器，确定其开口方向，从开口处沿开口朝向发射一条直线射线，射线宽度等于开口宽度。射线遇到非背景、非虚线像素时停止（虚线的蓝色像素不阻挡射线）。
2. 填充每个杯的内部黑色像素为黄(4)。
3. 对所有虚线段，检查每个单像素间隙（左右邻居均为蓝(1)的黑色像素）：若该间隙位于某个杯的射线路径上，将该间隙填充为该杯壁的颜色；若不在任何射线路径上，将该间隙填充为灰(5)。
4. 射线路径上的非间隙背景像素不着色（保持黑色）。
5. 所有杯壁像素和蓝色虚线像素保持不变。

**关键洞察**：间隙的填充色不是固定的，而是由"哪个杯的射线经过此处"动态决定——需要同时理解杯口方向决定射线路径、射线与虚线的空间交叉关系、以及杯壁颜色到间隙颜色的传递，三者缺一不可。

## 新题 5：控制像素计数驱动的矩形双向扩展与面板对色

**组合逻辑**：[计数](已有：统计控制像素) + [扩展](创新：扩展长度由计数决定，但扩展色由所属面板的对侧颜色决定) + [擦除](已有：移除原始控制像素)

**来源原语**：计数(counting) + 两侧计数决定长度(side_counts_length) + 控制像素(control_pixel) + 同行对齐(same_row_aligned) ← 2a28add5；扩展(expand) + 延伸条纹(extension_stripe) + 侧边带对齐(side_strip_align) ← 9def23fe；面板(panel) + 所属面板(panel_membership) + 对侧面板色(opposite_panel_color) ← 9b5080bb；擦除(erase) ← 9def23fe

**依赖链**：先识别面板归属→确定对侧面板色→统计控制像素数量→按计数扩展矩形→扩展部分涂对侧面板色。面板归属决定颜色，计数决定长度，两者对扩展结果的影响正交且不可分离。

两面板中的矩形根据四周控制像素数量向外扩展，扩展部分涂为对面面板的颜色。

**输入结构**：约 17x17 的网格。网格被一条贯穿全高的垂直灰(5)分隔线分为左右两个面板。左面板背景为蓝(1)，右面板背景为绿(3)。每个面板中有 1~2 个橙(7)实心矩形（3x3 至 4x4）。每个矩形的四条边外侧（紧邻矩形边缘、在同面板内的行或列上）散布红(2)控制像素，每侧 0~3 个。控制像素仅出现在矩形边缘的行列延长线上，不出现在对角方向。生成约束：矩形距面板边缘和分隔线至少 4 格，保证有扩展空间；同面板内两个矩形的扩展区域互不重叠。

**规则**：
1. 识别灰(5)分隔线，确定左面板（蓝(1)背景）和右面板（绿(3)背景）。
2. 对每个橙(7)矩形，确定其所属面板，并确定对侧面板的背景色（左面板矩形的对侧色为绿(3)，右面板矩形的对侧色为蓝(1)）。
3. 统计矩形每一侧（上、下、左、右）的红(2)控制像素数量 n_up, n_down, n_left, n_right。
4. 从矩形每条边向外扩展：向上扩展 n_up 行，向下扩展 n_down 行，向左扩展 n_left 列，向右扩展 n_right 列。扩展区域的宽度/高度与矩形对应边等长。扩展区域内的像素涂为该矩形的对侧面板色。
5. 擦除所有红(2)控制像素，替换为所在面板的背景色。
6. 原始橙(7)矩形、灰(5)分隔线保持不变。扩展不越过分隔线或网格边界。

## 新题 7：膨胀光晕中的距离排序聚集

**组合逻辑**：[膨胀/描边](已有：标记像素生成光晕) + [聚集](创新：聚集目标不再是固定目标块，而是动态生成的光晕中心) + [擦除](已有：被聚集的像素从原位消失) + [距离排序](创新：排序不再用于填充固定块，而是分配到多个光晕)

**依赖链**：先膨胀生成光晕（确定聚集目标区域）→计算栗色像素到各光晕中心的可达距离→按距离将栗色像素分配给最近的可达光晕→在光晕空位中按距离排序填入。光晕的几何形状决定了可容纳的像素数，可达性过滤掉被墙阻隔的候选者，距离排序决定填入顺序。

**输入结构**：约 16x16 的网格，背景为黑(0)。网格中有 2~3 个灰(5)标记像素和 6~12 个栗(9)散布像素。品红(6)像素组成若干墙壁段（每段 3~5 像素的直线），将网格空间部分阻隔。生成约束：每个灰色标记至少有 2 个栗色像素可通过非墙路径到达；标记之间距离足够远（曼哈顿距离 >= 6），使各光晕不重叠；栗色像素总数大于所有光晕空位之和，保证有剩余像素。

**规则**：
1. 对每个灰(5)标记像素，将其 3x3 邻域（裁剪到网格边界内）的背景(0)像素涂为蓝(1)，形成光晕。灰色标记本身保持灰(5)不变。光晕不覆盖墙壁(6)和栗色(9)像素。
2. 对每个栗(9)像素，通过仅经过背景(0)和栗(9)像素（不穿过墙壁(6)、蓝(1)光晕、灰(5)标记）的路径计算到每个灰色标记的最短曼哈顿路径长度。若某个栗色像素无法到达任何标记，则该像素保持不动。
3. 每个可达的栗色像素分配给其最近的可达灰色标记。若到两个标记等距，分配给行号较小的标记；若行号也相同，分配给列号较小的标记。
4. 对每个灰色标记，将分配给它的栗色像素按到该标记的距离从近到远排序。依次将这些栗色像素填入该标记光晕中的蓝(1)空位（按行优先从左上到右下遍历光晕空位）。多余的栗色像素（空位不够时）保留在原位不动。
5. 被成功聚集的栗色像素从原位置擦除，替换为背景(0)。

**关键洞察**：光晕不是预设的固定目标区域，而是由标记膨胀动态产生的——光晕的实际形状受墙壁和网格边界影响，因此不同标记的容量不同，这直接影响聚集的分配策略。

## 新题 8：分区网格中的条纹压缩与十字位涂色

**组合逻辑**：[压缩](创新：压缩不是全局操作，而是对每个分区独立执行) + [网格分区](已有：分隔线划分九宫格) + [填充](创新：压缩结果编码为十字位的颜色，而非固定颜色映射)

1. 识别灰(5)分隔线构成的 3x3 九宫格。

6. 所有角落分区保持原样不变。灰(5)分隔线保持不变。

**关键洞察**：角落分区的条纹结构不直接出现在输出的十字位中——条纹经过压缩后变成一个数字（序列长度），这个数字再映射为颜色，跨分区传递。需要对比多个示例才能发现"条纹数→颜色"的映射关系以及冲突时的绿色规则。

## 新题 10：移动标记的方向编码与矩形射线排除

**组合逻辑**：[移动](创新：标记的相对位置不再决定出口侧，而是编码射线延伸的排除方向) + [射线延伸](创新：排除方向由移动后的标记位置决定) + [擦除](已有：清除原始标记)

**来源原语**：移动(move) + 标记像素(marker_pixel) + 矩形(rectangle) + 标记在矩形外侧(marker_outside_rect) + 相对顺序决定出口(order_determines_exit) ← e4941b18；射线延伸(ray_extend) + 延伸条纹(extension_stripe) + 侧边带对齐(side_strip_align) + 标记排除对应行列(marker_excludes_row_col) ← 9def23fe；擦除(erase) ← 9def23fe

**依赖链**：两个标记的左右顺序编码一个方向→该方向成为矩形射线延伸的排除侧→排除侧不产生延伸条纹。移动规则和射线规则共享同一组标记像素，标记的位置信息同时服务于两个逻辑，形成信息复用。

矩形上方的两个标记通过相对位置编码排除方向，矩形仅向非排除方向延伸射线条纹。

**输入结构**：约 14x14 的网格，背景为黑(0)。网格中央有一个橙(7)实心矩形（3x4 至 5x5）。矩形正上方一行有两个标记像素：一个红(2)和一个青(8)，两者在矩形列范围内，不相邻。矩形的四个侧边带区域（矩形正上方、正下方、正左方、正右方的延长区域）中，可能散布 0~2 个绿(3)控制像素，每个控制像素位于矩形某行或某列的延长线上。生成约束：红和青标记在同一行；两标记之间至少间隔一列；控制像素不在矩形内部。

**规则**：
1. 确定红(2)到青(8)的水平方向：若红在青左边，排除方向为左；若红在青右边，排除方向为右。
2. 将红(2)标记移动到青(8)的位置（红覆盖青），原红(2)位置擦除为背景(0)。
3. 从矩形的四条边向外延伸条纹（与矩形同色橙(7)），但排除方向的一侧不产生任何延伸。具体为：若排除方向为左，则矩形左侧不延伸；若排除方向为右，则矩形右侧不延伸。上下两侧正常延伸。
4. 在非排除的三个方向上，每个方向的延伸规则为：将矩形的每一行（左右延伸时）或每一列（上下延伸时）向外延伸至网格边缘，但跳过包含绿(3)控制像素的行或列（该行/列在该侧不延伸）。
5. 绿(3)控制像素保持不变。矩形橙(7)像素保持不变。红(2)标记移动后留在新位置。

**关键洞察**：两个标记的相对位置既不是装饰也不仅仅触发移动——它们的左右顺序隐式编码了一个方向，该方向直接决定矩形哪一侧被完全排除在射线延伸之外。需要对比多个示例中标记顺序与排除侧的对应关系才能归纳此规则。
