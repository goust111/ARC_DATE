## 新题 1：奇偶格点定义重力地面

**组合逻辑**：[坐标奇偶匹配(coord_parity_match)](创新：奇偶格点从"涂色目标"变为"物理地面拓扑") + [重力下落(gravity_drop)](已有) + [墙分隔区域(wall_partitions_regions)](已有)

**来源原语**：坐标奇偶匹配、奇偶格点、标记像素、同奇偶背景涂色 ← d492a647；重力下落、碰撞停止、封闭区域、编码映射 ← 88e364bc；墙分隔区域、连通区域、分隔墙 ← 62ab2642

**依赖链**：灰墙划分出独立区域 → 每个区域中蓝标记的坐标定义该区域的奇偶格点 → 奇偶格点决定哪些背景格子是"实心地面" → 黄像素在重力作用下仅能停靠在实心格子上 → 不同区域因标记位置不同产生不同的地面拓扑 → 相同重力规则在不同区域产生截然不同的落点分布

在灰墙分隔的多个区域中，每个区域内的蓝标记像素以其坐标奇偶性定义一个隐形地面格点，黄色像素在重力作用下仅降落并停靠在该格点对应的格子上。

**输入结构**：
- 网格约 14x14，黑(0)背景
- 灰(5)单像素宽直线墙将网格分为 3~4 个矩形区域（墙沿整行或整列贯穿，区域面积各不相同）
- 每个区域内恰好一个蓝(1)标记像素，位于该区域内部（非墙上）；不同区域的蓝标记在区域内的相对位置不同（如一个在偶行偶列、另一个在奇行偶列），从而产生不同的奇偶格点
- 每个区域的上半部分散布 2~4 个黄(4)可移动像素，彼此不相邻，且不与蓝标记同行
- 生成约束：黄像素初始不在区域最底行；每个区域至少有 3 行高度供黄像素下落；各区域的蓝标记奇偶组合不全相同（至少两个区域的格点不同）

**规则**：
1. 对每个灰墙分隔的矩形区域独立处理。
2. 读取该区域中蓝(1)标记像素的绝对坐标 (r_m, c_m)，计算 p_r = r_m mod 2、p_c = c_m mod 2。
3. 该区域内，满足 r mod 2 = p_r 且 c mod 2 = p_c 的黑(0)格子为"实心格子"；其余黑(0)格子为"透明格子"。蓝标记本身所在的格子视为实心格子。
4. 每个黄(4)像素向下移动（行号增大方向）。它跳过所有透明格子，在以下情况停止：(a) 到达一个实心格子，且该实心格子的正下方是透明格子、灰墙或区域底边界——像素停在该实心格子上；(b) 到达一个实心格子，且该格子正下方的实心格子已被另一个黄像素占据——像素停在当前实心格子上。
5. 处理顺序：在每个区域内，从行号最大的黄像素开始逐个向上处理（先安置最底部的，再安置上方的）。
6. 蓝(1)标记像素和灰(5)墙在输出中保持不变。若黄像素下落路径经过蓝标记所在格子，蓝标记不受影响，黄像素继续向下穿过（蓝标记格子不阻挡黄像素）。

**关键洞察**：奇偶格点在源题 d492a647 中用于"填涂颜色"，此处被创新为定义"重力可停靠的地面拓扑"——同一个 parity 机制从视觉效果变为物理约束。不同区域的标记位置不同导致地面格点不同，必须逐区域独立推断标记位置才能预测落点。

## 新题 2：递减模板沿对角射线印章

**组合逻辑**：[颜色索引模板(color_indexes_template)](已有) + [对角方向(diagonal_dir) + 角位控制射线(corner_controls_ray)](创新：从 2x2 种子扩展改为任意模板沿对角递减印章) + [递减填充(shrinking_fill) + 逐步缩短行程(progressively_shortened)](创新：递减逻辑从边缘行程改为模板层级裁剪)

**来源原语**：颜色索引模板、模板掩码、调色板、解码 ← 65b59efc；对角方向、种子块、角位控制射线、射线延伸 ← 1f0c79e5；递减填充、逐步缩短行程、外推 ← 9772c176

**依赖链**：种子像素颜色 → 查找匹配的模板 → 种子旁红像素的相对位置 → 编码对角方向 → 沿该方向逐步印章模板 → 每步印章时模板从外圈向内逐层裁剪 → 印章序列形成锥形渐消轨迹

在网格上，每个彩色种子像素通过颜色选择模板、通过相邻红像素选择对角方向，沿该方向反复印章所选模板，且每一步模板从外圈剥离一层像素，形成递减消逝的斜向轨迹。

**输入结构**：
- 网格约 18x18，黑(0)背景
- 网格左上角有 2~3 个模板，每个为 5x5 的单色连通图案（颜色各不相同，如绿(3)、青(8)、品红(6)），模板之间间隔至少 1 列背景；模板形状各异（一个可能是十字形、一个是 L 形等，均为 4-连通，像素数 8~15）
- 网格下半区域散布 2~4 个种子像素，每个种子的颜色与某个模板颜色相同
- 每个种子像素恰好有一个红(2)像素与其 8-邻域相邻，位于种子的四个对角方向之一（左上/右上/左下/右下）
- 生成约束：不同种子的对角方向可以不同；各种子沿其对角方向有至少 10 格空间供印章展开；种子的颜色分配使得每个模板至少被一个种子引用

**规则**：
1. 识别左上角的模板区域：每个模板是一个连续的单色非黑非红连通块，记录其颜色 C 和相对形状（以模板包围盒左上角为原点的像素坐标集合 S_C）。
2. 对每个种子像素（颜色为 C_seed、位置 (r_s, c_s)），找到颜色 C_seed 对应的模板 S_{C_seed}。
3. 确定该种子旁红(2)像素相对于种子的位置，得到对角方向向量 (dr, dc)，其中 dr, dc 各为 +1 或 -1。
4. 第 k 步印章（k = 0, 1, 2, ...）：将模板 S_{C_seed} 的包围盒中心对齐到位置 (r_s + k*dr*W, c_s + k*dc*W)，其中 W 为模板包围盒宽度与高度的较大值。但在第 k 步，从模板中移除所有距包围盒边缘不超过 k 像素的像素（即剥离 k 层外壳）。将剩余像素绘制到对应网格位置，颜色为 C_seed。
5. 当第 k 步剥离后模板像素为空（k 足够大使整个模板被剥完），或者模板中心已超出网格边界时，停止。
6. 第 0 步在种子位置印章完整模板。印章从 k=0 开始按 k 递增顺序绘制。k=0 的种子位置印章覆盖原始种子像素。
7. 输出中移除所有红(2)控制像素（替换为黑(0)背景）。多个种子的印章轨迹若有重叠，后绘制的（k 值更大的步骤）覆盖先绘制的；若来自不同种子的同一 k 步重叠，按种子行号从小到大的顺序绘制（行号大的覆盖行号小的）。

**关键洞察**：源题 1f0c79e5 中沿对角线复制的是固定的 2x2 方块，源题 9772c176 中递减的是一维边缘行程。此处将两者耦合——沿对角射线行进的是从模板外圈逐层裁剪的二维图案，产生了"锥形衰减轨迹"这一源题中不存在的视觉结构。颜色编码选择模板内容，空间编码选择方向，递减规则控制轨迹形态，三者缺一则逻辑不完整。

## 新题 3：频率排名决定瓷砖的反转或保留

**组合逻辑**：[频率排序(frequency_ranking)](创新：从全局像素频率改为跨瓷砖的颜色使用频率) + [反转填充(occupancy_inversion)](已有) + [瓷砖网格排列(tile_grid_layout)](已有) + [重涂色(recolor)](已有)

**来源原语**：频率排序、最高频保留余替、前景像素 ← 9565186b；反转填充、重涂色、瓷砖、分隔行列 ← 1c0d0a4b；瓷砖网格排列 ← 1c0d0a4b

**依赖链**：统计每种前景颜色出现在多少个瓷砖中（跨瓷砖频率）→ 按频率分为三档（最高频 / 中间频 / 最低频）→ 最高频颜色的瓷砖执行反转填充并涂为红(2) → 最低频颜色的瓷砖原样保留 → 中间频颜色的瓷砖清空为纯背景

在分隔线划分的瓷砖网格中，统计每种前景颜色出现在几个瓷砖中，最常见颜色的瓷砖执行占位反转并涂红，最罕见颜色的瓷砖保留不变，其余瓷砖清空。

**输入结构**：
- 网格约 15x15，黑(0)背景
- 灰(5)整行/整列分隔线将网格等分为 3x3 共 9 个正方形瓷砖（每个瓷砖约 4x4）
- 每个瓷砖内有一种非黑非灰的前景颜色绘制的图案（3~8 个像素的 4-连通图形），瓷砖内的其余格子为黑(0)背景
- 共使用 3 种前景颜色（如蓝(1)、绿(3)、橙(7)），每种颜色出现在不同数量的瓷砖中，且三种颜色的瓷砖数量两两不同（如蓝出现在 4 个瓷砖、绿出现在 3 个、橙出现在 2 个）
- 同一颜色的不同瓷砖内图案形状互不相同
- 生成约束：三种颜色的瓷砖数量之和为 9；每种颜色至少出现在 1 个瓷砖中；三种颜色的瓷砖数量严格不同（无并列）

**规则**：
1. 识别分隔线和所有 9 个瓷砖的位置。
2. 对每种前景颜色 C，统计 C 出现在多少个不同的瓷砖中，得到频率 f(C)。
3. 找到频率最高的颜色 C_max、频率最低的颜色 C_min、以及中间频率的颜色 C_mid。
4. 对前景颜色为 C_max 的每个瓷砖：执行占位反转——将该瓷砖内原有的前景像素变为黑(0)背景，将原有的黑(0)背景像素变为红(2)前景。
5. 对前景颜色为 C_min 的每个瓷砖：保持原样不变。
6. 对前景颜色为 C_mid 的每个瓷砖：将瓷砖内所有前景像素清除为黑(0)背景（整个瓷砖变为纯黑）。
7. 分隔线灰(5)保持不变。

**关键洞察**：源题 9565186b 中的频率排序在全局像素级别决定保留/替换，源题 1c0d0a4b 中的反转填充对所有瓷砖统一执行。此处频率排序被提升到"跨瓷砖的颜色使用次数"层面，成为决定每个瓷砖命运的分流条件——最高频执行反转、最低频保留、中间频清空。必须对比多个示例才能确认频率排名决定哪种操作（而非颜色本身决定），因为不同示例中同一颜色可能因频率不同而获得不同命运。

## 新题 4：射线切割后按封闭孔洞数分拣碎片

**组合逻辑**：[切割(cutting) + 射线分割区域(ray_partition)](已有) + [计数(counting)](创新：计数对象从像素变为碎片内的封闭孔洞) + [极值面积决定颜色(extreme_area_determines_color)](创新：极值依据从面积改为孔洞数) + [滑动(sliding)](已有)

**来源原语**：切割、滑动、射线分割区域、控制像素、边界归属决定保留 ← 4a21e3da；计数、像素数决定尺寸 ← f931b4a8；极值面积决定颜色、连通区域 ← 62ab2642；封闭区域 ← 88e364bc

**依赖链**：边缘控制像素射线 → 将前景对象切割为碎片 → 统计每个碎片内部的封闭背景孔洞数量 → 孔洞最多的碎片滑动到控制像素所在角落 → 孔洞最少的碎片重涂为橙色 → 其余碎片消失

将一个带孔洞的前景对象沿边缘控制像素射入的切割线分成碎片，统计每个碎片包含的封闭孔洞数，孔洞最多者滑向角落保留，孔洞最少者涂橙原地保留，其余消失。

**输入结构**：
- 网格约 16x16，黑(0)背景
- 一个青(8)前景对象大致居中，占据约 8x8 到 10x10 的区域，形状不规则但 4-连通，内部有 3~5 个封闭的黑(0)背景孔洞（大小各异，1~4 像素）
- 网格边缘上恰好有 2 个红(2)控制像素，分别位于不同的边（如一个在顶边、一个在左边），且它们的行/列射线穿过前景对象时会将对象分为恰好 3 个碎片
- 生成约束：两条切割射线交叉于前景对象内部，将对象分成 3 个碎片（若两条射线不交叉则分成更多碎片——须保证恰好交叉一次）；3 个碎片各自包含的封闭孔洞数两两不同（如 0、1、2）；每个碎片至少包含 4 个青(8)像素

**规则**：
1. 从每个红(2)控制像素出发，沿其所在行（若在左/右边）或所在列（若在上/下边）向网格内部画射线。射线经过的每个格子：若为黑(0)背景则涂为红(2)；若为青(8)前景则跳过不涂（射线穿过前景像素但不破坏它）。射线到达对面边缘时停止。
2. 红(2)射线将前景对象切割为碎片：两个前景像素属于同一碎片当且仅当它们之间存在一条完全由青(8)像素组成的 4-连通路径且不跨越任何红(2)射线格子。注意：射线跳过了前景像素，因此切割发生在射线两侧的背景间隙处——实际上前景像素被射线的行/列位置逻辑分割：若一个前景像素在射线行/列的一侧、另一个在另一侧、且它们的连通路径必须穿越射线行/列中的背景段，则它们属于不同碎片。
3. 对每个碎片，统计其"封闭孔洞"数量：在该碎片的包围盒内，找到所有被该碎片的青(8)像素完全包围（4-连通不可达包围盒外部）的黑(0)背景连通区域，每个这样的连通区域算一个孔洞。
4. 孔洞数最多的碎片（唯一）：保持青(8)颜色，整体平移滑动到距其当前位置最近的网格角落（按碎片包围盒中心到四个角落中心的曼哈顿距离取最小；若并列则取行号更小的角落，再并列取列号更小的角落）。碎片紧贴角落放置（包围盒的角与网格角重合）。
5. 孔洞数最少的碎片（唯一）：原地保留，将所有青(8)像素重涂为橙(7)。
6. 其余碎片：从输出中移除（替换为黑(0)背景）。
7. 红(2)射线像素在输出中移除（替换为黑(0)背景）。

**关键洞察**：源题 4a21e3da 中切割后碎片的命运由"是否靠近控制边缘"决定，这里被替换为"碎片内部拓扑复杂度（孔洞数）"决定——切割改变了孔洞的归属分布，因此切割位置与孔洞计数紧密耦合：同一个孔洞在不同切割方案下可能归属不同碎片，改变各碎片的排名。

## 新题 5：边界图例编码逐色反射轴

**组合逻辑**：[逐色独立变换(per_color_transform) + 包围盒内翻转(flip_within_bbox)](已有) + [编码映射(encoding_map) + 边界图例(border_legend)](创新：图例从编码移动方向改为编码反射轴类型) + [标记颜色对应(marker_color_match)](已有)

**来源原语**：逐色独立变换、包围盒内翻转、单色掩码、包围盒、镜像 ← e74e1818；编码映射、边界图例、颜色关联区域 ← 88e364bc；标记颜色对应、外部标记决定朝向 ← 94133066

**依赖链**：每种前景颜色匹配一个同色边界图例 → 图例内两个点的排列编码反射轴（水平排列→左右镜像，垂直排列→上下镜像，对角排列→转置）→ 对该颜色的掩码在其包围盒内执行对应反射 → 不同颜色获得不同的反射变换

网格中多种颜色的掩码各自需要在包围盒内反射，但反射轴不固定——每种颜色通过匹配边缘上同色图例来解码该颜色专属的反射方式。

**输入结构**：
- 网格约 14x14，黑(0)背景
- 3 种非黑颜色（如蓝(1)、绿(3)、橙(7)）各形成一个 4-连通的不规则掩码（5~12 像素），掩码之间不相邻，包围盒不重叠
- 每个掩码形状刻意不对称——上下不对称、左右不对称、也非对角对称——使得不同反射方式产生不同结果
- 网格最外圈边缘（第 0 行、最后一行、第 0 列、最后一列）上有 3 个小图例矩形，每个为 3x3，填充色分别为蓝(1)、绿(3)、橙(7)中的一种，与三种掩码一一对应
- 每个 3x3 图例的中心格子为灰(5)（固定中心点），另有一个灰(5)指示点位于图例的边缘格子上（非中心），其余格子保持图例的填充色。中心点与指示点的相对位置编码反射方式：若指示点在中心的正左或正右 → 该颜色掩码执行左右镜像；若指示点在中心的正上或正下 → 执行上下镜像；若指示点在中心的对角位置 → 执行沿主对角线转置
- 生成约束：三个图例编码的反射方式两两不同（一个左右、一个上下、一个转置）；图例放置在边缘且不与掩码的包围盒重叠；若某掩码被指定为转置，其包围盒必须为正方形（行数=列数），以保证转置后包围盒不变

**规则**：
1. 识别网格边缘上的 3 个 3x3 图例。每个图例的填充色 C 是非灰的那种颜色。
2. 在每个图例中找到两个灰(5)像素：中心像素 (r_center, c_center) 和指示像素 (r_ind, c_ind)。计算偏移 (dr, dc) = (r_ind - r_center, c_ind - c_center)。
3. 解码反射轴：若 dr = 0 且 dc != 0 → 左右镜像（水平翻转）；若 dr != 0 且 dc = 0 → 上下镜像（垂直翻转）；若 dr != 0 且 dc != 0 → 沿主对角线转置。
4. 对每种颜色 C 的掩码，找到其包围盒 [r0, r1] x [c0, c1]。
5. 执行该颜色对应的反射变换：
   - 左右镜像：掩码中每个像素 (r, c) 移至 (r, c0 + c1 - c)。
   - 上下镜像：掩码中每个像素 (r, c) 移至 (r0 + r1 - r, c)。
   - 主对角线转置：掩码中每个像素 (r, c) 移至 (r0 + (c - c0), c0 + (r - r0))。
6. 所有颜色独立处理，互不影响。输出中清除原始掩码像素（替换为黑(0)），在新位置绘制变换后的掩码。图例在输出中移除（替换为黑(0)）。

**关键洞察**：源题 e74e1818 中所有颜色统一执行垂直翻转，此处反射轴变成由外部图例逐色编码的参数——必须先解码图例才能确定每个掩码的变换方式。源题 88e364bc 的图例编码的是移动方向，此处创新为编码几何变换类型，两种编码机制的作用域从"区域内像素移动"变为"掩码整体几何变换"。

## 新题 6：走廊阻断递减外推方向

**组合逻辑**：[递减填充(shrinking_fill) + 四方外扩(four_way_expansion)](已有) + [对边连通(opposite_edge_connect) + 无阻挡跨行列涂色(unobstructed_span_recolored)](创新：走廊从"涂色目标"变为"外推屏障") + [射线延伸(ray_extend)](已有)

**依赖链**：检测所有对象间的无阻挡行/列走廊 → 走廊涂绿(3)标记 → 对每个对象执行四方递减外推 → 但外推射线到达绿色走廊行/列时立即终止 → 走廊的存在选择性截断了某些方向的外推 → 最终图案取决于对象的几何形状与走廊网络的全局交互

网格中多个圆润对象各自向四方延伸递减行程，但先识别出所有对象间的无阻挡走廊并标绿，绿色走廊充当屏障截断其方向上的递减外推。

**输入结构**：
- 网格约 18x18，黑(0)背景
- 3~4 个青(8) 4-连通圆润对象（每个约 3x3 到 5x5，顶底左右边缘行程至少 3 像素长，形状大致凸形），分散于网格中，彼此不相邻
- 某些对象之间在水平或垂直方向上恰好存在无阻挡走廊：即某一行的两个对象边缘像素之间、或某一列的两个对象边缘像素之间，所有中间格子均为黑(0)背景
- 生成约束：至少存在 2 条走廊（可以是行走廊或列走廊的组合）；至少有一个对象的某个外推方向不被任何走廊阻挡（使该方向的递减外推完整展开直到长度归零）；至少有一个对象的某个外推方向被走廊截断

**规则**：
1. 走廊检测：对每一行 r，若存在两个不同对象在行 r 上各有至少一个青(8)像素，取这两个对象在行 r 上最靠近对方的像素列坐标 c1 和 c2（c1 < c2），若从 c1+1 到 c2-1 所有格子均为黑(0)背景，则行 r 的 [c1+1, c2-1] 段为一条行走廊。对每一列执行类似检测。
2. 将所有检测到的走廊格子涂为绿(3)。
3. 对每个青(8)对象独立执行四方递减外推：
   - 找到对象顶边、底边、左边、右边的各条边缘行程（顶边：对象最小行上的连续青像素段；底边类似；左边：对象最小列上的连续青像素段；右边类似）。
   - 向外扩展：以顶边为例，从顶边所在行向上逐行复制该行程，每步将行程长度缩短 2（两端各缩 1 像素），直到行程长度降至 0 或 1。底/左/右类似。
   - 外推像素的颜色为黄(4)。
   - 截断规则：在某个方向上逐步外推时，若下一步的行/列位置落在绿(3)走廊格子上或越过了绿(3)走廊格子所在的行/列，则该方向的外推在此终止，不绘制该步及后续步的外推像素。
4. 外推像素只绘制在黑(0)背景格子上；若某外推位置已被另一个对象的外推占据，后处理的覆盖先处理的。对象处理顺序：按对象包围盒中心的行号从小到大，行号相同则列号从小到大。
5. 青(8)对象像素和绿(3)走廊像素在输出中保持不变。

**关键洞察**：源题 9772c176 的递减外推在四方无差别展开，源题 2bee17df 的走廊检测结果是涂色本身。此处走廊从"输出效果"变为"另一个操作的约束条件"——走廊的全局网络决定了哪些对象的哪些方向被截断，而截断位置又取决于对象间的精确空间关系。两个操作通过走廊几何紧密耦合：改变任一对象位置会同时改变走廊检测结果和外推截断结果。

## 新题 7：转置后标记漂移驱动奇偶填充

**组合逻辑**：[沿主对角线转置(transpose_along_diagonal) + 对角对称(diagonal_symmetry)](已有) + [坐标奇偶匹配(coord_parity_match) + 填充(filling)](创新：转置改变标记坐标从而改变奇偶格点定义) + [碰撞停止(collision_stop)](创新：灰障碍阻断填充连通性)

**来源原语**：沿主对角线转置、对角对称、方阵、对角线、反射 ← 9dfd6313；坐标奇偶匹配、奇偶格点、标记像素、填充、同奇偶背景涂色 ← d492a647；碰撞停止 ← 88e364bc

**依赖链**：输入方阵含一条对角线和若干前景像素及一个特殊标记 → 转置方阵（对角线不动，前景像素行列互换）→ 标记像素的行列坐标在转置后改变 → 新坐标的奇偶性定义一个奇偶格点 → 从标记的新位置出发，沿该奇偶格点 4-连通扩散填充标记颜色 → 灰(5)障碍阻断填充连通性 → 最终图案由转置后的几何布局和奇偶格点共同决定

将一个含有对角线的方阵转置后，特殊标记像素的坐标发生变化，导致其奇偶格点定义改变；以新的奇偶格点为基础从标记位置出发扩散填充，灰障碍阻断连通。

**输入结构**：
- 网格为正方形，边长 11~15（奇数，保证对角线穿过中心），黑(0)背景
- 主对角线（从左上到右下）上所有格子为蓝(1)
- 灰(5)障碍像素散布在非对角线位置上，约 8~15 个，不形成大块连通区域，每个障碍为孤立单像素或 2 像素小块
- 恰好一个红(2)标记像素位于非对角线位置，且其行列坐标 (r_m, c_m) 满足 r_m != c_m（确保转置后位置改变）
- 可选：少量绿(3)前景像素散布于非对角线位置（作为装饰，转置后移动但不参与填充逻辑）
- 生成约束：红标记的转置前后奇偶组合不同——即 (r_m mod 2, c_m mod 2) != (c_m mod 2, r_m mod 2)，这等价于 r_m 和 c_m 的奇偶性不同（一奇一偶）；灰障碍不在对角线上

**规则**：
1. 对整个方阵执行主对角线转置：每个像素 (r, c) 的值移至位置 (c, r)。对角线上的像素（r = c）不动。转置后红标记从 (r_m, c_m) 移至 (c_m, r_m)。
2. 在转置后的网格上，读取红(2)标记的新坐标 (c_m, r_m)，计算奇偶格点：p_r = c_m mod 2, p_c = r_m mod 2。
3. 定义"格点格子"：转置后网格中所有满足 r mod 2 = p_r 且 c mod 2 = p_c 的格子。
4. 从红标记的新位置 (c_m, r_m) 出发，执行受限 4-连通扩散填充：填充扩展到所有通过格点格子 4-连通（仅沿上下左右方向，每步移动 2 格到达下一个格点格子）可达的格点格子上的黑(0)背景。扩散被以下条件阻断：(a) 目标格子不是格点格子；(b) 目标格子是灰(5)障碍；(c) 目标格子已有非黑颜色（蓝对角线、绿前景等）；(d) 从当前格点格子到目标格点格子的路径中间格子（非格点格子）包含灰(5)障碍——此条不适用，因为填充直接在格点格子间跳跃，不经过中间格子。
5. 所有被填充到达的格点背景格子涂为红(2)。红标记本身保持红(2)。
6. 未被填充的黑(0)格子、蓝(1)对角线、灰(5)障碍、绿(3)前景均保持转置后的状态。

**关键洞察**：转置看似只是几何变换，但它改变了红标记的坐标，从而改变了奇偶格点的定义——这是两个操作间的参数级耦合。求解者必须先执行转置才能知道该填充哪个奇偶格点，而奇偶格点反过来又在转置后的障碍布局中扩散，形成"几何变换改变参数、参数控制拓扑扩散"的推理链。灰障碍的位置在转置前后发生变化，进一步增加了预测难度。

## 新题 8：碎片主色查图例定方向，异常碎片原地固定

**组合逻辑**：[切割(cutting) + 射线分割区域(ray_partition)](已有) + [颜色关联区域(color_links_to_region) + 编码映射(encoding_map)](创新：颜色关联从"区域边界色"改为"碎片主色") + [异常值选择(outlier_selection)](创新：异常值从"单色单元"改为"无匹配图例的碎片") + [滑动(sliding)](已有)

**来源原语**：切割、滑动、控制像素、射线分割区域、边界归属决定保留 ← 4a21e3da；编码映射、边界图例、颜色关联区域 ← 88e364bc；异常值选择、忽略干扰项 ← c3202e5a；标记颜色对应 ← 94133066

**依赖链**：控制像素射线切割前景对象为碎片 → 统计每个碎片的主色（占多数的颜色）→ 主色在边界图例中查找匹配 → 图例编码该碎片的滑动方向 → 无匹配图例的碎片（异常值）原地保持 → 三级依赖：切割几何 × 碎片颜色构成 × 图例解码

将多色前景对象沿控制射线切割成碎片，每个碎片的主色在边界图例中查找对应的滑动方向并执行滑动，唯一没有匹配图例的碎片作为异常值固定不动。

**输入结构**：
- 网格约 16x16，黑(0)背景
- 一个多色前景对象居中偏左，约 8x10，由 3~4 种非黑颜色（如蓝(1)、绿(3)、橙(7)、品红(6)）的像素混合构成，4-连通，整体是一个连通块但内部颜色分布不均匀——不同区域以不同颜色为主
- 网格边缘有 2 个红(2)控制像素（分别在不同边上），它们的射线将前景对象切为 3 个碎片
- 网格边缘（非控制像素所在边）有 2 个 3x3 图例矩形。每个图例的填充色与某种前景颜色相同（如一个填蓝(1)、一个填橙(7)），图例中央为灰(5)圆心、另有一个灰(5)指示点，指示点相对圆心的位置编码滑动方向（上/下/左/右）
- 生成约束：3 个碎片的主色（该碎片中像素数最多的颜色）两两不同；恰好 2 个碎片的主色在图例中有匹配，1 个碎片的主色无匹配图例（此碎片为异常值）；图例中指示点只出现在中心的正上/正下/正左/正右四个位置之一（即 dr=0 或 dc=0）

**规则**：
1. 从每个红(2)控制像素出发沿行/列向网格内部画射线（规则同新题 4 的步骤 1），射线穿过前景像素时跳过，只涂黑(0)背景格子为红(2)。
2. 射线将前景对象分割为碎片（分割规则同新题 4 的步骤 2）。
3. 对每个碎片，统计各非黑颜色的像素数量，像素数最多的颜色为该碎片的"主色" D。若有并列，取在碎片包围盒中最先出现（按从上到下、从左到右扫描序）的颜色。
4. 对每个碎片的主色 D，在边界图例中查找填充色为 D 的图例。若找到：
   - 读取该图例的中心灰(5)点和指示灰(5)点，计算方向向量 (dr, dc)（指示点坐标 - 中心点坐标）。
   - 将整个碎片沿方向 (dr, dc) 平移，每步移动 1 格，直到碎片中任何像素的下一步位置超出网格边界或与另一个已固定碎片的像素重叠。碎片停在最后一个合法位置。
5. 无匹配图例的碎片（异常值）：原地保留，不移动，不变色。
6. 碎片处理顺序：先固定异常值碎片，然后按图例在网格边缘上的出现位置（从上到下、从左到右）顺序处理有匹配的碎片。
7. 红(2)射线像素和红(2)控制像素在输出中移除（替换为黑(0)）。图例在输出中移除。

**关键洞察**：切割、颜色统计、图例解码三个机制形成不可跳过的三级依赖——切割位置决定碎片边界，边界决定每个碎片内的颜色构成，颜色构成决定主色，主色决定查哪个图例，图例决定移动方向。异常值机制增加了一层筛选：求解者必须发现"没有图例对应的碎片不动"这条隐含规则，这需要对比多个示例中哪个碎片不动并追溯其主色在图例中缺席。
