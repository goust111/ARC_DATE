## 新题 1：障碍导向的重力合并与面积分色

**组合逻辑**：[gravity_drop] + [collision_stop](创新：蓝色物体作为固定障碍改变坠落路径) → [counting + area_classification](创新：对合并后的连通分量做面积判定) → [recolor](创新：面积阈值决定最终颜色)

**来源原语**：gravity_drop、collision_stop（参考题 2b83f449）；counting、area_classification、area_determines_color（参考题 d2abd087）；recolor（参考题 aabf363d）

**依赖链**：蓝色障碍物的位置改变绿色精灵体的坠落轨迹 → 坠落后相邻精灵体合并为新的连通分量 → 合并后的面积决定最终颜色。障碍物布局是输出颜色分布的隐性驱动因素。

绿色精灵体在蓝色障碍物的干扰下坠落、碰撞合并，合并后的连通分量按面积阈值重涂为两种颜色。

**输入结构**：约 15x15 的网格，背景为黑(0)。底行为灰(5)地面行。网格中散布 4-6 个绿(3)精灵体（4-连通单色小图形，每个 2-5 像素，形状各异——不规则连通块，非特定几何名称）和 2-3 个蓝(1)矩形障碍物（每个 1x2 或 2x1）。绿色精灵体悬浮在不同高度，部分精灵体在同一列或相邻列上下排列。蓝色障碍物固定在网格中部偏下，其位置使得某些绿色精灵体的坠落路径被阻断或偏移。生成约束：每个绿色精灵体正下方到地面行或蓝色障碍物之间至少有 1 行空隙；蓝色障碍物不与绿色精灵体在初始状态接触。

**规则**：
1. 蓝(1)障碍物固定不动，视为不可穿透的实体。
2. 所有绿(3)精灵体同时向下坠落。坠落按距地面行的距离从近到远依次处理（距地面近的先结算）。每个精灵体保持自身形状整体向下平移，直到其任一像素的正下方一格为地面行、蓝色障碍物或已结算的绿色像素时停止。
3. 坠落结算完毕后，计算所有绿(3)像素的 4-连通分量（原本分离的精灵体可能因坠落后相邻而合并为一个更大的连通分量）。
4. 对每个绿色连通分量计算面积：面积 >= 5 的分量重涂为红(2)；面积 < 5 的分量重涂为黄(4)。
5. 蓝色障碍物和灰色地面行保持不变。

**关键洞察**：精灵体的最终颜色不取决于它自身的初始面积，而取决于坠落后与哪些其他精灵体合并——蓝色障碍物通过阻断坠落路径间接控制合并结果，从而间接决定颜色。面积阈值（>= 5）需对比多个示例才能确定。

## 新题 2：嵌套矩形框的角落引导循环换色

**组合逻辑**：[draw_frame + bounding](已有：识别嵌套矩形框及深度) → [corner_positioning](创新：角落引导像素编码旋转偏移量) → [cyclic_shift](创新：按嵌套深度序列循环轮换颜色)

**来源原语**：draw_frame、bounding、frame_inset_from_extrema（参考题 928ad970）；corner_positioning、corner_color_transfer_vanish（参考题 aabf363d）；cyclic_shift、angular_order_around_center（参考题 880c1354）

**依赖链**：嵌套深度排序建立帧的有序序列 → 角落引导像素的颜色匹配某一帧，将帧深度转化为旋转偏移量 → 循环轮换以该偏移量移动所有帧的颜色。引导像素是解码旋转量的关键。

读取角落引导像素的颜色，找到对应深度的嵌套矩形框，以该深度为偏移量循环轮换所有框的颜色，然后擦除引导像素。

**输入结构**：约 15x15 的网格，背景为黑(0)。网格内有 3-4 个同心嵌套的单像素宽矩形框（相邻框之间间隔 1 像素），每个框使用不同的非黑颜色（如从外到内：红(2)、蓝(1)、绿(3)、黄(4)）。网格左上角 (0,0) 位置有一个引导像素，其颜色与某个框的颜色相同。生成约束：引导像素的颜色必须恰好匹配某一个框的颜色；框的嵌套关系明确（每个框严格包围下一个框）。

**规则**：
1. 识别所有矩形框，按嵌套深度排序：最外层深度为 0，向内依次递增。
2. 读取 (0,0) 处引导像素的颜色 C，找到颜色为 C 的框，记其深度为 D。
3. 将所有框的颜色向内循环轮换 D 个位置：深度 i 的框接收深度 (i - D) mod N 的框的原始颜色（N 为框的总数）。
4. 将 (0,0) 处的引导像素设为黑(0)（擦除）。

**关键洞察**：引导像素并非直接指定某个框的目标颜色，而是通过"匹配颜色 → 定位深度 → 转化为旋转偏移量"这一间接编码链来决定所有框的颜色变换。旋转方向（向内）需对比多个示例归纳。

## 新题 3：帧侧颜色编码的旋转印章

**组合逻辑**：[crop](创新：从参考框内提取模板图案) + [color_to_side](创新：框四边颜色建立颜色-旋转映射表) → [stamp_overlay + rotate](创新：按散落像素颜色查表旋转后印章) → [only_fill_background](已有：印章仅填充背景格)

**来源原语**：crop（参考题 5daaa586）；color_to_side（参考题 5daaa586）；stamp_overlay、only_fill_background（参考题 dc1df850）；rotate（参考题 2b83f449）；scattered_pixel（参考题 5daaa586）；erase（参考题 abc82100）

**依赖链**：矩形框的四边颜色隐式定义了一张颜色→旋转角度的映射表 → 提取框内灰色模板图案 → 每个散落像素的颜色在映射表中查找对应旋转角度 → 将模板按该角度旋转后印章到散落像素位置。映射表、模板、和散落像素三者缺一不可。

从四色矩形框中提取模板和旋转映射表，在每个散落像素处按其颜色对应的旋转角度印章模板。

**输入结构**：约 18x18 的网格，背景为黑(0)。左上角区域有一个 7x7 的矩形框，框的四边各为一种颜色：上边红(2)、右边绿(3)、下边蓝(1)、左边黄(4)（四角像素归属按顺时针优先：右上角归上边颜色，右下角归右边颜色，左下角归下边颜色，左上角归左边颜色）。框内部（5x5 区域）有一个灰(5)的不对称小图案（约 4-8 像素的 4-连通块，无旋转对称性）。网格其余区域散布 4-8 个孤立像素，颜色为红(2)、绿(3)、蓝(1)或黄(4)之一。生成约束：散落像素之间至少间隔 6 个像素（曼哈顿距离），以确保 5x5 印章不会超出网格边界且各印章之间有足够空间。

**规则**：
1. 提取矩形框内部的 5x5 灰色图案作为模板。
2. 建立颜色→旋转映射：框上边颜色→0度（不旋转）、框右边颜色→逆时针 90度、框下边颜色→180度、框左边颜色→顺时针 90度。即"该颜色对应的框边旋转到朝上位置"。
3. 对每个散落像素，读取其颜色，查映射表得到旋转角度，将模板旋转该角度后以散落像素为中心放置 5x5 印章。
4. 印章仅填充背景(0)格；若印章范围内已有非背景像素则保留原像素。印章颜色使用灰(5)。
5. 所有印章放置完毕后，将原矩形框区域（含框线和内部图案）擦除为黑(0)。

**关键洞察**：矩形框不只是容器——其四边颜色构成一张隐式旋转查找表，求解者必须发现"边颜色 = 旋转角度"这一编码关系。框的四角归属规则需对比多个示例确认。

## 新题 4：镜像扩展后的涌现封闭与泛洪填充

**组合逻辑**：[mirror + four_way_symmetric_expansion](已有：四向镜像扩展) → [flood_fill](创新：在镜像创造的新拓扑结构中填充) ← [partial_enclosure + opening_direction](创新：原始开口在镜像对称轴处可能闭合，产生涌现封闭区域)

**来源原语**：mirror、four_way_symmetric_expansion（参考题 833dafe3）；flood_fill、partial_enclosure、fill_seed、opening_direction（参考题 b9e38dc0）

**依赖链**：原始图案中的半封闭墙有开口 → 四向镜像后，对称轴处的镜像墙可能与原墙拼合形成完全封闭区域（涌现效应）→ 泛洪填充从种子像素出发，封闭区域被完全填充而开放区域填充受限。镜像操作改变了拓扑结构，拓扑结构决定填充范围。

将含有半封闭墙和填充种子的小图案四向镜像扩展，镜像在对称轴处创造新的封闭区域，泛洪填充揭示哪些区域因镜像而变得封闭。

**输入结构**：一个较小的矩形网格（约 6x6），背景为黑(0)。网格内有灰(5)像素构成的半封闭墙结构（一段连续的 L 形或 U 形墙线，由 3-6 个灰色像素组成，形成一个有明确开口方向的半包围区域）。半封闭区域内部有一个红(2)种子像素。墙的开口朝向网格的某一边缘（上、下、左或右）。生成约束：墙结构不触及网格边缘（至少距边缘 1 像素），使得镜像后墙段之间有空隙或接合的可能；种子像素被墙半包围但可通过开口连通到外部。

**规则**：
1. 将输入网格作为右下象限，执行四向镜像扩展（与参考题 833dafe3 相同）：左右镜像 → 左下象限，上下镜像 → 右上象限，双轴镜像 → 左上象限。输出网格尺寸为输入的 2 倍。
2. 镜像后，灰色墙段也被复制到四个象限。在对称轴处，来自相邻象限的墙段可能首尾相接，形成原本不存在的完全封闭区域。
3. 对输出网格中的每个红(2)种子像素（共 4 个，分布在四个象限），执行泛洪填充：从种子像素出发，向 4-邻域的黑(0)背景格扩散红(2)色，灰(5)墙像素阻止扩散。
4. 若种子像素位于完全封闭区域内（因镜像拼合而封闭），则该区域被完全填充。若种子像素位于仍有开口的区域内，填充扩散到整个连通的背景区域。
5. 灰色墙和红色种子/填充像素共存；墙不被覆盖。

**关键洞察**：原始图案中墙的开口方向决定了镜像后哪些对称轴处会发生墙段拼合——朝向网格内部的开口在镜像后闭合（形成涌现封闭），朝向网格边缘的开口则保持开放。这是一个纯粹的涌现效应：单独看原始图案和镜像操作都不会产生封闭区域，只有两者结合才会出现。

## 新题 5：对角错切射线与障碍阴影

**组合逻辑**：[ray_extend](创新：射线沿错切方向而非正交方向传播) + [shear + row_offset_incr](创新：错切规则应用于射线路径而非物体移动) → [obstacle_casts_shadow](创新：阴影沿错切方向投射)

**来源原语**：ray_extend、gap_bisect（参考题 d968ffd4）；shear、row_offset_incr（参考题 9f41bd9c）；obstacle_casts_shadow（参考题 b9e38dc0）；marker_pixel（参考题 dc1df850）

**依赖链**：标记像素的行位置决定射线起点 → 错切规则将射线路径从水平弯折为对角 → 障碍物沿错切方向投射阴影，阻断后续射线。射线路径的几何形状和阴影区域都由错切方向决定。

左侧标记像素沿对角错切路径向右发射彩色射线，灰色障碍物沿同一错切方向投射阴影阻挡射线。

**输入结构**：约 14x18 的网格（行数 14，列数 18），背景为黑(0)。左侧第 0 列有 3-5 个标记像素，分布在不同行，颜色各异（使用红(2)、蓝(1)、绿(3)、黄(4)等）。网格中散布 2-4 个灰(5)矩形障碍物（每个 1x2 或 2x1）。生成约束：标记像素之间至少间隔 2 行；障碍物不在第 0 列；不同标记像素的错切射线路径在未被阻挡时不会重叠（即在错切方向上各占不同的对角线带）。

**规则**：
1. 每个标记像素从其所在格 (r, 0) 向右发射射线。射线路径遵循错切规则：从起点出发，每向右移动一列，同时向下移动一行。即射线经过的格子序列为 (r, 0), (r+1, 1), (r+2, 2), ... , (r+c, c)。
2. 射线用标记像素的颜色逐格绘制，遇到以下情况停止：到达网格边界（底边或右边）；或遇到灰(5)障碍物像素。
3. 障碍物投射阴影：当射线被障碍物阻断时，从障碍物位置沿同一错切方向（继续每列下移一行）延伸一个阴影带直到网格边界。阴影带内的格子不绘制任何射线颜色（即使有其他射线路径经过该格）。
4. 射线的绘制按标记像素从上到下的顺序依次处理。先绘制的射线像素不会被后绘制的覆盖。阴影带内的格子对所有后续射线同样生效（不可绘制）。
5. 障碍物自身保持灰(5)不变。

**关键洞察**：射线不走水平直线而走对角错切路径，这意味着来自不同行的射线在空间上呈平行对角带分布。障碍物的阴影也沿对角方向投射，一个障碍物可能同时遮蔽多条潜在射线路径。错切方向（每列下移一行 vs 上移一行）需对比多个示例确认。

## 新题 6：分形蓝图定位后的同色连线

**组合逻辑**：[scale + self_similarity + minority_pattern_as_blueprint](已有：少数单元内部图案作为宏观放置蓝图) → [connect + same_color_chain](创新：蓝图确定的单元位置间进行同色最短路径连线) ← [shortest_detour](创新：连线路径需绕过分隔线和异色单元)

**来源原语**：scale、self_similarity、minority_pattern_as_blueprint、minority_cell、majority_cell、separator_grid（参考题 b99e7126）；connect、same_color_chain、shortest_detour（参考题 f8f52ecc）

**依赖链**：少数单元的内部图案编码了宏观放置蓝图 → 蓝图决定哪些单元格被填充为少数单元 → 填充后的少数单元按颜色分组 → 同色单元之间通过分隔通道以最短 L 形路径连线。蓝图放置决定了连线的拓扑结构。

用少数单元的自相似蓝图确定哪些单元格应被填充，然后在分隔线通道中连接所有同色的少数单元。

**输入结构**：约 19x19 的网格，由灰(5)分隔线划分为 4x4 的单元阵列（每个单元 4x4 像素，分隔线 1 像素宽）。大多数单元内部为全黑(0)（多数单元）。已有 2-3 个单元为少数单元，内部包含一个小彩色图案：每个少数单元内有一个 2-3 像素的彩色标记，使用红(2)或蓝(1)。少数单元内部的非标记像素中，有特定位置的像素为栗(9)（作为蓝图标记）。生成约束：所有少数单元的内部布局相同（含标记颜色和栗色蓝图标记的位置相同），仅标记颜色可能不同；少数单元在 4x4 阵列中的位置与其内部栗(9)像素在 4x4 内部空间中的位置自相似对应。

**规则**：
1. 识别少数单元（内部含有非黑像素的单元）。提取少数单元内部的栗(9)像素位置作为蓝图图案。
2. 将蓝图图案缩放到单元阵列层级：栗色像素在 4x4 内部空间中的位置对应 4x4 单元阵列中的单元坐标。在所有蓝图指示的位置放置少数单元的副本（已有的少数单元保持不变，新放置的少数单元复制已有少数单元的内部图案，标记颜色按行优先顺序交替使用红(2)和蓝(1)）。
3. 放置完毕后，将所有少数单元按其标记颜色分为两组（红组和蓝组）。
4. 在每组内，按单元位置的行优先顺序将相邻单元依次连线：在灰(5)分隔线的像素通道中，用该组颜色绘制最短 L 形路径连接每对相邻单元（路径仅经过分隔线像素，将分隔线像素重涂为连线颜色）。
5. 两种颜色的连线路径不可交叉。若存在冲突，红(2)路径优先占据该分隔线像素，蓝(1)路径绕行。

**关键洞察**：自相似蓝图决定了少数单元的空间分布，而空间分布直接决定了连线的拓扑复杂度——不同的蓝图产生截然不同的连线图案。蓝图的解码（栗色像素位置 → 单元阵列坐标的映射）需对比多个示例确认。

## 新题 7：周期裁剪后的端点配色行填充

**组合逻辑**：[crop + period + smallest_period_flipped](已有：找到含翻转的最小水平周期并裁剪) → [fill + same_color_pairing + full_row_fill_endpoints_match](创新：在裁剪后的周期块内，判断每行边界标记是否同色来决定是否填充)

**来源原语**：crop、period、smallest_period_flipped、sprite（参考题 2dee498d）；fill、same_color_pairing、full_row_fill_endpoints_match、marker_pixel、canvas_boundary（参考题 22eb0ac0）

**依赖链**：宽网格由含翻转的重复块构成 → 找到最小周期并裁剪出原始块 → 在该块中，左右边界标记像素的配对关系因翻转而被打乱（原始块的右边标记在翻转块中变成左边标记）→ 只有裁剪出正确的原始块后，边界标记的配对才正确 → 同色端点行填充。周期检测决定了哪些标记是真正的配对。

从含翻转重复的宽网格中裁剪出最小周期块，在该块中将左右边界同色标记行填满对应颜色。

**输入结构**：约 10x24 的宽网格（10 行，24 列），背景为黑(0)。网格由 4 个 10x6 的列块横向拼接而成。第 1 个块是原始图案，后续块是原始图案的左右镜像或原样重复（交替排列）。每个块内部：某些行的最左列和最右列各有一个彩色标记像素（使用红(2)、蓝(1)、绿(3)中的一种），其余像素为黑(0)背景。部分行的左右标记同色，部分行的左右标记异色。生成约束：至少有 2 行左右标记同色，至少有 1 行左右标记异色；块宽度（6）整除总宽度（24）；相邻块交替为原样和左右镜像。

**规则**：
1. 从最小候选宽度开始尝试，找到最小的列块宽度 W，使得每个宽度为 W 的列块要么与第一个块完全相同，要么与第一个块的左右镜像完全相同。裁剪出第一个块（最左侧的 10xW 子网格）。
2. 在裁剪出的块中，检查每一行的最左列（列 0）和最右列（列 W-1）像素。
3. 若某行两端像素颜色相同且非背景色，则将该行从列 0 到列 W-1 的所有像素填充为该颜色。
4. 若某行两端像素颜色不同或有一端为背景色，则该行保持不变。
5. 输出裁剪并填充后的 10xW 网格。

**关键洞察**：翻转重复使得在完整宽网格中直接观察边界标记会产生误导——镜像块的左右标记是原始块标记的镜像，配对关系被颠倒。只有先正确裁剪出最小周期块，才能得到真正的左右配对。最小周期的确定需对比多个示例。

## 新题 8：模板对齐后的光环干涉

**组合逻辑**：[align + shape_matching + coordinate_aligned_to_template](已有：以蓝色副本为模板对齐其他同形副本) → [stamp_overlay + neighborhood_expand + only_fill_background](创新：对齐改变了精灵体与标记像素的空间关系，影响光环扩展结果)

**来源原语**：align、shape_matching、coordinate_aligned_to_template、sprite、template（参考题 1caeab9d）；stamp_overlay、neighborhood_expand、only_fill_background、marker_pixel、halo_region（参考题 dc1df850）

**依赖链**：三个同形精灵体中，蓝色为模板，红色和绿色对齐到蓝色的行坐标 → 对齐后精灵体占据新位置 → 标记像素扩展 3x3 光环时，被精灵体占据的格子不可填充 → 对齐前后光环形状不同。对齐操作改变了空间遮挡关系，遮挡关系决定光环形状。

将红色和绿色精灵体垂直对齐到蓝色模板后，黄色标记像素扩展光环，但被精灵体占据的格子阻止光环填充。

**输入结构**：约 14x16 的网格，背景为黑(0)。网格中有三个形状完全相同的精灵体（4-连通单色块，5-8 像素，不规则形状），分别为蓝(1)、红(2)、绿(3)。三个精灵体在水平方向上分离（列跨度不重叠），但垂直方向上起始行不同（红色和绿色的行坐标偏离蓝色若干行）。另有 3-5 个黄(4)标记像素散布在网格中（不与任何精灵体重叠）。生成约束：三个精灵体的列跨度互不重叠且水平间距 >= 2 列；对齐后红色和绿色精灵体不会超出网格边界；黄色标记像素的 3x3 光环范围与至少一个精灵体（对齐后的位置）有重叠。

**规则**：
1. 识别蓝(1)、红(2)、绿(3)三组像素。验证它们的形状相同（存在平移使三者的像素掩码重合）。
2. 以蓝(1)精灵体为模板：保持蓝色精灵体不动。将红(2)精灵体的所有像素的行坐标替换为蓝色精灵体对应像素的行坐标，保持列坐标不变。绿(3)精灵体同理。（原位置清除为黑色。）
3. 对齐完成后，处理每个黄(4)标记像素：以该像素为中心，将 Chebyshev 距离 <= 1 的所有格子（3x3 邻域）中为黑(0)背景的格子填充为黄(4)。已有非黑像素的格子（包括精灵体像素和其他标记像素）不被覆盖。
4. 黄色标记像素本身保持黄(4)不变。
5. 处理顺序：多个标记像素的光环同时展开（不存在先后覆盖关系，因为它们都只填充背景格）。

**关键洞察**：光环的最终形状不仅取决于标记像素的位置，还取决于精灵体对齐后的位置——对齐使某些原本远离标记的精灵体像素移动到光环范围内，阻断了光环的部分填充。求解者必须先完成对齐推理，才能预测光环的遮挡缺口。哪个颜色是对齐模板（蓝色）需对比多个示例确认。
