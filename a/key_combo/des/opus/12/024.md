## 新题 1：对称侵蚀后的拓扑分类填充

**组合逻辑**：[镜像/反射对称](分析工具) + [重涂色/擦除](创新：擦除对象从"标记"变为"非对称像素") → [洪泛填充](创新：填充颜色由拓扑变化前后的对比决定)

**来源原语**：反射对称·交集差集分别着色(a8610ef7) + 重涂色(a8610ef7) + 洪泛填充·封闭腔体·区域可达性(8b7bacbf, 543a7ed5) + 连通可达(8b7bacbf)

**依赖链**：对称分析决定哪些像素被擦除 → 擦除改变前景形状的拓扑结构（可能打破封闭边界） → 比较擦除前后每个腔体的封闭性变化 → 变化类型决定填充颜色。三步之间存在信息变换：对称性→几何变化→拓扑变化→颜色编码。

输入中有一个复杂的连通前景形状，它将背景分隔出若干封闭腔体；对该形状做垂直镜像分析后擦除非对称像素，导致部分腔体的边界被破坏而与外部连通；最终根据每个腔体在擦除前后的封闭性变化分别着色。

**输入结构**：
- 约 15x15 网格，黑(0) 背景。
- 一种前景色（蓝(1)），形成单个 4-连通的复杂连通形状（约 40~60 像素），近似但不完全垂直对称。
- 该形状将背景划分为：外部区域（从网格边界可达）和 3~5 个封闭腔体（从网格边界不可达的背景连通分量）。
- 关键约束：部分非对称像素（仅存在于形状中、但其关于网格垂直中心线的镜像位置不是前景像素的那些像素）恰好位于某些腔体的边界上；擦除它们后会使部分腔体与外部连通。
- 生成约束：至少存在一个腔体在擦除后仍然封闭，至少存在一个腔体在擦除后变为开放。

**规则**：
1. 计算网格的垂直中心线（列索引 = (宽度-1)/2，若宽度为偶数则取左半列）。
2. 对每个蓝(1)前景像素，检查其关于垂直中心线的镜像位置：若镜像位置也是蓝(1)前景像素，则该像素属于"对称交集"；否则属于"非对称差集"。
3. 将所有"非对称差集"像素擦除为黑(0)，"对称交集"像素保持蓝(1)。
4. 在擦除后的网格上，从网格四条边界出发做 4-连通洪泛扩散，标记所有从边界可达的黑(0)像素为"外部"。
5. 对于原始网格中的每个封闭腔体（擦除前从边界不可达的背景连通分量）：
   - 若该腔体的所有像素在擦除后仍然从边界不可达（仍封闭）→ 填充黄(4)。
   - 若该腔体中至少有一个像素在擦除后变为从边界可达（封闭性被破坏）→ 填充绿(3)。
6. 外部背景区域保持黑(0)。

**关键洞察**：填充颜色不是由腔体自身属性决定，而是由对称侵蚀引发的拓扑变化决定——求解者需要同时推断对称轴、擦除规则和拓扑比较三层逻辑。

## 新题 2：印章生成端点后的同色轴对齐连线

**组合逻辑**：[印章覆盖](已有) → [连线·同色配对·轴对齐](创新：连线端点不是输入中预置的，而是由印章操作动态生成的)

**来源原语**：印章覆盖·锚点像素·固定图案(a9f96cdd) + 连线·同色配对·轴对齐(06df4c85) + 仅相邻锚点间连接(60a26a3e)

**依赖链**：锚点位置决定印章放置 → 印章的固定图案在不同位置生成不同颜色的端点像素 → 端点的空间分布决定哪些同色像素可以轴对齐连线 → 连线拓扑完全由锚点位置间接编码。删除印章步骤则无端点可连；删除连线步骤则印章图案没有后续交互意义。

在黑色网格上的若干锚点处粘贴固定的彩色角点图案，然后将不同印章中同色且共行/共列的角点像素用该色连线贯通。

**输入结构**：
- 约 13x13 网格，黑(0) 背景。
- 3~5 个红(2) 锚点像素，彼此间距至少 5 个单元格（确保印章不重叠）。
- 隐含的固定印章图案（不在输入中显示，需从示例归纳）：以锚点为中心的 3x3 区域，中心为红(2)，四角分别为：左上=蓝(1)、右上=绿(3)、右下=黄(4)、左下=橙(7)，四条边中点为黑(0)。
- 输入中只有锚点像素可见；印章图案需从输入输出对比中归纳。

**规则**：
1. 在每个红(2)锚点位置，放置 3x3 固定图案：中心=红(2)，左上=蓝(1)，右上=绿(3)，右下=黄(4)，左下=橙(7)，其余=黑(0)。若图案超出网格边界则裁剪。
2. 所有印章放置完毕后，对每种非黑非红颜色（蓝(1)、绿(3)、黄(4)、橙(7)），扫描所有该色像素。
3. 对于同色且共享同一行的像素对，按列坐标从左到右排序；对相邻对之间的所有黑(0)背景像素，填充为该颜色。
4. 对于同色且共享同一列的像素对，按行坐标从上到下排序；对相邻对之间的所有黑(0)背景像素，填充为该颜色。
5. "相邻对"指同色同行/同列像素序列中紧邻的两个，中间不能有第三个同色像素。
6. 连线只覆盖黑(0)像素；若路径上有非黑非同色像素则该连线不执行。

**关键洞察**：锚点位置看似只决定印章在哪里，实际上隐式编码了整个连线拓扑图——改变一个锚点的位置可能同时创建和破坏多条连线。

## 新题 3：孔洞匹配数驱动容器平移距离

**组合逻辑**：[嵌入填充·形状匹配孔洞·旋转翻转不变](已有，但匹配对象从模板框架变为容器) + [平移·逐步充能](创新：能量源从灰色单元格数变为成功匹配的孔洞数) + [颜色匹配配对](桥接两个操作的配对键)

**来源原语**：嵌入填充·形状匹配孔洞·旋转翻转不变(67e490f4) + 平移·逐步充能·能量上限步数(271d71e2) + 带边框容器·目标标记·颜色匹配配对(271d71e2) + 精灵体(67e490f4)

**依赖链**：精灵体与孔洞的形状匹配同时产生两个输出：(a) 孔洞的填充颜色，(b) 匹配成功计数。匹配计数作为移动能量传递给容器平移操作。移动距离 = min(匹配孔洞数, 到目标标记距离)。两个操作通过匹配计数紧耦合——一个未匹配的孔洞同时意味着一个未填充的洞和一格更少的移动距离。

将散落在外部的小精灵体按形状嵌入带边框容器的孔洞中，成功匹配的孔洞数决定容器能向目标标记平移多远，同时容器内部逐步充能。

**输入结构**：
- 约 18x18 网格，品红(6) 背景。
- 2~3 个带边框容器：黑(0) 一像素宽边框，内部为灰(5) 填充，每个容器在内部挖有 1~3 个不规则孔洞（孔洞为品红(6)色，即背景色透过来）。孔洞形状各异（3~6 像素的 4-连通区域），不同示例中同位置容器的孔洞具体形状不同。
- 每个容器的一条边外侧紧贴一个栗(9) 头部像素，标示移动方向起点。
- 沿头部像素所指方向（头部在容器左侧则向右移动，在上方则向下移动，以此类推），距容器若干格处有一个栗(9) 目标标记像素。
- 在网格的空白区域（不在任何容器内部），散布若干小单色精灵体（使用蓝(1)、绿(3)、黄(4)、橙(7) 等颜色，每个精灵体 3~6 像素，4-连通），每个精灵体的形状恰好匹配某一个孔洞（可能需要 90/180/270 度旋转或水平翻转）。
- 生成约束：每个精灵体最多匹配一个孔洞；至少一个容器有未匹配的孔洞（无对应精灵体）；至少一个容器的匹配数 < 到目标距离（会提前停下）。

**规则**：
1. 对每个容器的每个孔洞，在外部精灵体中搜索形状匹配（允许 0/90/180/270 度旋转和水平翻转），以精灵体的 4-连通形状与孔洞的 4-连通形状比较。
2. 若找到匹配，将该孔洞填充为匹配精灵体的颜色；未匹配的孔洞保持品红(6)。
3. 擦除所有外部精灵体（替换为品红(6)背景）。
4. 计算每个容器成功填充的孔洞数 → 此值为该容器的移动能量 E。
5. 计算每个容器的头部像素到目标标记的曼哈顿轴向距离 D（沿移动方向的直线距离）。
6. 容器整体（含边框和内部）沿移动方向平移 min(E, D) 格。
7. 平移过程中，容器内部灰(5)像素从移动方向的前端开始逐行/逐列转为橙(7)，每移动一步转换一行/列。

**关键洞察**：形状匹配是一个分叉节点——它同时输出视觉结果（孔洞填色）和数值结果（移动能量），两个下游效果缺一不可。

## 新题 4：控制条截断对角射线并隐身

**组合逻辑**：[顺时针轮换](已有) + [射线延伸](已有) + [擦除](创新：擦除的控制条在输出中不可见，但其位置决定了射线几何)

**来源原语**：顺时针轮换·对角角点·小方块·对角邻接(85fa5666) + 射线延伸(85fa5666, ac605cbb) + 擦除·控制条·跨度对齐(c62e2108)

**依赖链**：角点颜色经顺时针轮换后决定射线颜色 → 控制条的位置决定射线何处截断 → 控制条被擦除后在输出中不可见。求解者必须从射线的截断长度反推出不可见的控制条位置，才能理解规则。三者形成"生成—约束—隐藏"的推理三角。

2x2 方块的四个对角角点颜色顺时针旋转后向外发射对角射线，射线被网格上的控制条截断，最后控制条被擦除，仅留下射线痕迹。

**输入结构**：
- 约 16x16 网格，黑(0) 背景。
- 2~3 个实心 2x2 绿(3) 方块，彼此间距至少 6 格。
- 每个方块有 4 个对角邻接的单像素，颜色取自 {蓝(1), 红(2), 黄(4), 橙(7)}，四个角点颜色各不相同。
- 1~3 条灰(5) 控制条：每条是一像素宽的完整行或完整列（从网格一端到另一端），不穿过任何 2x2 方块。
- 生成约束：至少一条射线会被控制条截断（即控制条位于某个方块的某条对角射线路径上）。

**规则**：
1. 对每个 2x2 方块，将其四个对角角点颜色顺时针轮换一位：左上角→右上角，右上角→右下角，右下角→左下角，左下角→左上角。
2. 从每个轮换后的角点出发，沿其对应的外向对角方向（左上角向左上方，右上角向右上方，右下角向右下方，左下角向左下方）逐像素延伸射线，射线颜色为该角点轮换后的颜色。
3. 射线遇到以下任一情况时停止（不包含终止像素）：(a) 到达网格边界外一格（即最后一个射线像素在网格边缘）；(b) 到达灰(5)控制条像素；(c) 到达另一个 2x2 方块的像素或其角点像素。
4. 所有射线绘制完毕后，擦除全部灰(5)控制条像素（替换为黑(0)）。

**关键洞察**：控制条在输出中完全不可见，但它们的曾经存在塑造了射线的长度——求解者需从不同示例中射线的异常截断推断出"存在不可见障碍物"这一隐蔽机制。

## 新题 5：外部条形段像素数限定腔体洪泛填充容量

**组合逻辑**：[计数](创新：计数对象从方块变为条形段像素) + [洪泛填充](创新：填充被外部数值截断而非自然终止) + [擦除](条形段在输出中被擦除)

**来源原语**：计数·像素数转为条纹(d93c6891) + 洪泛填充·种子像素·封闭腔体·种子色标记填充(8b7bacbf) + 能量上限步数(271d71e2) + 相邻接触(d93c6891) + 擦除(d93c6891)

**依赖链**：外部条形段的像素数 → 同色种子的填充容量 → 容量与腔体大小的关系决定是完全填充还是部分填充 → 部分填充的边界形状由 BFS 扩散顺序决定。外部计数和内部几何两路信息在填充操作处汇合，缺任一路则无法确定输出。

线条画围出若干封闭腔体，每个腔体内有一个种子像素；线条画外部贴着同色条形段，条形段的像素数就是该种子的填充容量。填充从种子向外 BFS 扩散，容量耗尽即停。

**输入结构**：
- 约 14x14 网格，黑(0) 背景。
- 一个 4-连通的红(2)线条画（1 像素宽的连通线段网络），将网格内部分隔为 3~5 个大小不等的封闭腔体（腔体内部为黑(0)背景，从网格边界不可达）。
- 每个腔体内恰有一个种子像素，颜色各不相同，取自 {蓝(1), 绿(3), 黄(4), 橙(7), 灰(5)}。
- 在线条画的外部（从网格边界可达的区域），每种种子颜色对应一条同色条形段：1 像素宽的水平或垂直线段，4-连通接触红(2)线条画的外侧边界。条形段长度 2~8 像素不等。
- 生成约束：至少一个腔体的面积（黑色像素数）大于其对应条形段的像素数（会部分填充）；至少一个腔体面积小于等于对应条形段像素数（会完全填充）。

**规则**：
1. 对每条彩色条形段，计算其像素数 → 记为该颜色的填充容量 C。
2. 对每个封闭腔体，找到其内部的种子像素，确定种子颜色。
3. 从种子像素出发，做 4-连通 BFS 洪泛扩散（仅扩散到腔体内的黑(0)像素），将遍历到的像素重涂为种子颜色。
4. BFS 层序：按曼哈顿距离从小到大扩散；同一距离层内按行从上到下、同行按列从左到右的顺序处理。
5. 当已涂色的像素数（含种子自身）达到 C 时立即停止，即使腔体内还有未涂色的黑(0)像素。若腔体内黑(0)像素数+1（种子） <= C，则腔体被完全填充。
6. 填充完毕后，擦除所有外部条形段（替换为黑(0)），红(2)线条画保持不变。

**关键洞察**：同一个填充操作的输出形状由两个独立信息源共同决定——腔体几何（控制 BFS 路径）和外部条形段长度（控制何时截断）。求解者必须从部分填充的边界形状反推出容量限制机制。

## 新题 6：引导边定向旋转后沿控制条平铺

**组合逻辑**：[旋转/反射·引导边·颜色匹配朝向](已有) → [裁剪](已有) → [平铺·沿控制条重复](创新：平铺的方向和目标由引导边匹配的控制条决定，而非独立的跨度对齐)

**来源原语**：旋转·反射·裁剪·引导边·颜色匹配朝向(fc7cae8d) + 平铺·控制条·跨度对齐·沿控制条重复(c62e2108) + 擦除(c62e2108)

**依赖链**：引导边颜色确定目标控制条 → 目标控制条确定旋转方向 → 旋转改变精灵体形状 → 裁剪引导边后改变精灵体尺寸 → 新尺寸决定平铺的重复间距 → 控制条方向决定平铺轴向。每一步的输出是下一步的必要输入，形成六环依赖链。

带引导边的小精灵体根据引导边颜色找到网格边缘的匹配控制条，旋转至引导边朝向控制条方向，裁去引导边，然后从原位向控制条方向周期性平铺。

**输入结构**：
- 约 18x18 网格，黑(0) 背景。
- 2~3 个小矩形精灵体（内部为单一非黑颜色，如红(2)、绿(3)、黄(4)，大小约 3x4 至 5x6 像素）。
- 每个精灵体恰好两条相邻边（例如左边和上边）有 1 像素宽的引导边，引导边颜色各不相同，取自 {蓝(1), 橙(7), 灰(5), 品红(6)}。引导边与精灵体内部颜色不同。
- 网格的四条边（上下左右）各至多有一条控制条：1 像素宽、颜色与某个引导边匹配、覆盖该网格边的全部长度。
- 每个引导边颜色在控制条中恰好出现一次（一一对应）。
- 生成约束：精灵体之间间距足够大，平铺不会相互覆盖；每个精灵体到其匹配控制条之间有足够空间放置至少 2 个副本。

**规则**：
1. 对每个精灵体，识别其两条引导边的颜色，找到网格边缘上颜色匹配的两条控制条。
2. 确定精灵体需要的旋转/翻转变换：变换后，精灵体的两条引导边分别朝向其颜色对应的控制条所在的网格边方向。例如，若蓝(1)引导边应朝上（因为上边有蓝(1)控制条）、橙(7)引导边应朝左（因为左边有橙(7)控制条），则旋转精灵体使蓝边在上、橙边在左。
3. 裁去旋转后精灵体的两条引导边（删除 1 像素宽的引导行/列），得到纯内容精灵体。
4. 选择两条匹配控制条中较近的一条作为平铺方向（距离取精灵体边界到控制条的垂直距离）。
5. 从精灵体原始位置出发，向选定控制条方向周期性复制纯内容精灵体，每两个副本之间无间隙、首尾紧邻排列，直到副本触及控制条位置或网格边界。
6. 平铺副本不覆盖已有的非黑像素（若副本区域与其他精灵体或其他副本重叠，该副本中重叠的像素不绘制）。
7. 擦除所有控制条（替换为黑(0)）。

**关键洞察**：引导边颜色是信息枢纽——同一组颜色同时编码旋转朝向（引导边朝向控制条方向）和平铺终点（控制条位置），两个几何决策由同一颜色绑定。

## 新题 7：标记像素双参数编码矩形内部的周期格点

**组合逻辑**：[填充·保留边框填内部](已有，填充内容从实心色变为周期格点) + [循环填充·周期相位对齐](创新：相位由外部标记位置编码) + [擦除·标记色定边框色](创新：标记同时提供格点颜色和相位参数，然后被擦除)

**来源原语**：最大实心矩形·保留边框填内部·内部区域(e88171ec) + 循环填充·对角线格点·周期相位对齐(c1990cce) + 中心标记像素(c1990cce, fc754716) + 擦除·标记色定边框色(fc754716) + 忽略干扰项(e88171ec)

**依赖链**：最大矩形检测确定填充区域 → 标记像素颜色确定格点颜色 → 标记像素列坐标确定格点相位 → 三个参数（区域、颜色、相位）共同确定输出中的每一个像素。标记像素承担双重编码角色（颜色+位置），这种信息复用使得单一对象同时约束两个独立参数。

在含有多个黑色矩形的噪声网格中找出最大矩形，保留其边框，内部用标记像素编码的周期性对角格点图案填充。

**输入结构**：
- 约 16x16 网格，灰(5) 背景，其上散布少量随机噪声像素（颜色随机，约 5~10 个，充当干扰项）。
- 2~4 个不同大小的实心黑(0)矩形（每个矩形内部全部为黑(0)），最大矩形的尺寸至少 6x6，面积严格唯一最大。
- 网格上有一个标记像素（颜色取自 {蓝(1), 红(2), 绿(3), 黄(4), 橙(7)} 之一），位于所有黑色矩形之外。
- 生成约束：最大矩形内部至少 4x4（去掉边框后的区域足够展示格点图案）；标记像素不与任何矩形相邻。

**规则**：
1. 找到面积最大的实心黑(0)轴对齐矩形（在所有可能的轴对齐黑色矩形中面积最大的那个）。
2. 保留该矩形的 1 像素宽黑(0)边框不变。
3. 在矩形的严格内部区域（去掉四边各 1 像素后的区域），绘制 NW-SE 方向的对角格点：对每个内部像素 (r, c)，若 (r + c) mod 4 == (标记像素的列坐标) mod 4，则涂为标记像素的颜色；否则保持灰(5)背景色。
4. 将标记像素擦除（替换为灰(5)背景色）。
5. 所有其他矩形和噪声像素保持不变。

**关键洞察**：标记像素是一次性控制信号——它的颜色和位置各编码一个独立参数（格点颜色和相位偏移），用后即被擦除，求解者必须从格点图案的颜色和偏移同时反推标记的两个属性。

## 新题 8：分隔栅格中同色连线后的对称性分色

**组合逻辑**：[连线·同色配对·沿行列填充间隙](已有) → [重涂色·反射对称·交集差集分别着色](创新：对称分析的对象不是预设形状，而是连线操作动态生成的组合形状)

**来源原语**：连线·分隔栅格·标记像素·同色配对·轴对齐·沿行列填充间隙(06df4c85) + 重涂色·反射对称·交集差集分别着色(a8610ef7)

**依赖链**：同色配对连线改变每个颜色组的形状 → 新形状的反射对称性决定哪些像素被涂红、哪些涂灰。连线前各色块是分散的独立像素/小区块，无法独立判断对称性；连线后才形成可分析对称性的完整形状。对称结果反过来揭示了连线是否创造了对称结构——这是一种"操作创造分析对象"的耦合。

在分隔栅格中将同色单元格连线贯通，然后对每个连通色组检查水平反射对称性，将对称部分与非对称部分分别着不同颜色。

**输入结构**：
- 约 14x14 网格，黑(0) 背景。
- 灰(5) 分隔条：若干完整行和完整列的 1 像素宽灰(5)线，将网格分割为矩形单元格（每个单元格约 2x2 至 4x4 大小）。
- 部分单元格被填充为非黑非灰颜色，取自 {蓝(1), 绿(3), 黄(4), 橙(7)}，每种颜色出现 2~4 个单元格。
- 同色单元格在分隔栅格中位于同一行或同一列（单元格行列指栅格划分的逻辑行列，非像素行列），之间隔着若干黑(0)空单元格。
- 生成约束：至少一种颜色的连通组连线后在其边界框内具有水平反射对称性；至少一种颜色连线后不对称。不同颜色的单元格不共享同一栅格行或列（不会产生连线冲突）。

**规则**：
1. 识别灰(5)分隔条（完整行或完整列），确定栅格结构。
2. 对每种非黑非灰颜色，找到该色所有单元格的位置。
3. 对同色单元格按栅格行分组：同一栅格行内按列从左到右排序，相邻对之间的所有黑(0)单元格填充为该颜色。
4. 对同色单元格按栅格列分组：同一栅格列内按行从上到下排序，相邻对之间的所有黑(0)单元格填充为该颜色。
5. 连线完毕后，对每种颜色的所有像素（原始+连线填充的），计算它们在该色组边界框内的水平反射对称性：
   - 以边界框的水平中心线为轴（若高度为偶数则取上半边界），检查每个像素是否有关于此轴的镜像对应像素也属于同色组。
   - 若像素与其镜像位置都是同色 → 该像素重涂为红(2)。
   - 若像素属于同色组但其镜像位置不属于 → 该像素重涂为栗(9)。
6. 灰(5)分隔条保持不变。

**关键洞察**：连线操作动态创建了对称分析的目标形状——分散的色块本身无对称性可言，只有连线后的组合形状才能展现或打破对称，因此对称结果编码了连线拓扑的几何特征。
