## 新题 1：缺口射线遇障碍绕行

**组合逻辑**：[缺口定射线向](已有) + [射线延伸](已有) + [洪泛填充](已有) + [绕行/遇障碍绕最近侧](创新改造：原作用于顶部下落列遇水平障碍段，现改为从缺口射出的任意方向射线遇障碍段绕行) → 四个原语交织：缺口决定射线方向，射线遇障碍段时不终止而是绕行，绕行方向取决于障碍段最近的自由端

**来源原语**：
- 缺口定射线向(gap_determines_ray) ← 292dd178
- 射线延伸(ray_extend) ← 292dd178, 891232d6, c87289bb
- 洪泛填充(flood_fill) ← 292dd178
- 障碍线段(obstacle_segment) ← c87289bb
- 绕行/遇障碍绕最近侧(detour/detour_nearest_side) ← c87289bb
- 缺口矩形框(one_gap_rect_frame) ← 292dd178

**依赖链**：缺口检测产出射线方向 → 射线沿该方向延伸 → 遇障碍段时启用绕行逻辑（需知道射线当前方向和障碍段的空间范围来判定绕行侧）→ 绕行后射线继续沿原方向前进 → 洪泛填充框内部作为射线起点的语义标记。缺口方向、障碍段位置、障碍段长度三者共同决定射线的完整路径形态，删除任一环节路径不可确定。

从缺口矩形框射出的红色射线在遇到障碍段时绕行至最近自由端后继续前进，框内部被同色填充。

**输入结构**：
- 黑(0)背景，约 20x25 网格。
- 蓝(1)像素构成 2~3 个 4x4 矩形边框（4-连通），每个边框恰好缺少一个非角落边界像素（即缺口）。各边框互不接触，最近距离至少 3 个像素。
- 红(2)像素构成 2~4 条水平或垂直的线段（每条 3~6 像素长），散布在网格中，不与任何边框接触（最近距离至少 2 个像素）。线段之间互不接触。
- 生成约束：每个边框的缺口射线方向上至少存在一条障碍段挡住射线路径（射线所在行/列与障碍段有交集），且障碍段的至少一侧有足够空间供绕行（从障碍段端点到网格边界至少 1 个像素）。不同边框的射线路径（含绕行段）互不交叉。

**规则**：
1. 对每个蓝(1)边框，定位其缺口像素及缺口的外向方向（缺口像素邻接框外侧的方向：上/下/左/右）。
2. 将每个边框的 2x2 内部区域和缺口像素本身涂为绿(3)。
3. 从缺口像素的外向邻格开始，沿外向方向逐格绘制绿(3)像素，形成射线。
4. 如果射线的下一格是红(2)障碍段的一部分，执行绕行：沿障碍段所在行/列（与射线方向垂直的方向）在射线当前位置的前一格（紧贴障碍段之前的那一行/列）水平或垂直画绿(3)像素，朝向障碍段的最近自由端（即障碍段该方向端点之外的第一个非红像素所在侧；若两侧等距，选择行号/列号较小的一侧），画到障碍段端点的外侧列/行后，继续沿原射线方向（前进方向不变，但在新的行/列上）绘制绿(3)像素。
5. 若绕行后继续前进的射线再次遇到另一条障碍段，重复步骤 4 的绕行逻辑。
6. 射线到达网格边界时终止（最后一个绿像素画在边界行/列上）。
7. 各边框的射线独立处理。所有蓝(1)边框像素保留不变。所有红(2)障碍段保留不变。

**关键洞察**：源题 292dd178 的射线是无阻碍的直线，源题 c87289bb 的绕行作用于从顶部下落的列。本题的创新在于：缺口决定的任意方向射线与分布在网格中的障碍段产生交互，射线路径不再是直线而是折线，且折线形态由障碍段的长度和位置共同决定——这种"方向性射线 + 空间障碍绕行"的结构关系在任一源题中都不存在。

## 新题 2：模板匹配驱动的选择性重力下落

**组合逻辑**：[归一化形状比对](已有) + [重涂色/匹配模板则重涂](已有) + [重力下落](已有，创新改造：原作用于粗栅格中的所有非背景像素，现仅作用于通过形状匹配筛选出的对象) → 形状匹配将对象分为"可动"与"固定"两类，固定对象充当重力下的地形障碍

**来源原语**：
- 归一化形状比对(normalized_shape_matching) ← 4ff4c9da
- 匹配模板则重涂(recolor_on_match) ← 4ff4c9da
- 重力下落(gravity_drop) ← afe3afe9
- 模板对象(template_object) ← 4ff4c9da
- 连通分量(connected_component) ← 4ff4c9da

**依赖链**：模板形状 → 匹配判定（哪些对象可动） → 非匹配对象自动成为障碍 → 重力作用于匹配对象（下落距离取决于障碍位置） → 最终布局同时依赖形状分类结果和空间位置关系。形状匹配决定"谁动"，空间布局决定"动到哪"，两者缺一不可。

将与青色模板同形的对象重涂为青色并向下做重力下落，其余对象不动并充当地形。

**输入结构**：
- 黑(0)背景，约 15x15 网格。
- 一个青(8)小对象（3~6 像素，4-连通，形状不规则）作为模板，位于网格的某个角落区域。
- 5~8 个单色小对象（每个 3~6 像素，4-连通），颜色分别为蓝(1)、红(2)、绿(3)、黄(4)中的某一种。其中部分对象的归一化 4-连通掩码与青(8)模板相同（平移等价），其余对象掩码不同。
- 所有对象互不接触（任意两对象的像素之间至少间隔 1 个黑像素）。
- 生成约束：至少 2 个对象匹配模板，至少 2 个不匹配。每个匹配对象的正下方（沿其各像素列向下延伸到网格底部的路径上）至少存在一个不匹配对象或网格底部作为着陆面。匹配对象下落后不会相互重叠（各匹配对象下落路径在列维度无冲突，或冲突时按从下到上顺序处理即可避免）。

**规则**：
1. 提取青(8)模板对象的归一化 4-连通掩码（平移归一化：将边界框左上角对齐到原点）。
2. 对网格中所有非黑、非青的 4-连通对象，逐一计算其归一化掩码，与模板掩码比对。掩码相同者标记为"可动对象"。
3. 将所有可动对象重涂为青(8)。
4. 对可动对象施加向下重力：每个可动对象整体保持形状不变，逐行向下平移，直到其任何像素的正下方紧邻一个非黑像素（不匹配对象的像素或网格底部的虚拟边界）。处理顺序：按对象边界框底部行号从大到小（最靠底的先处理），若底部行号相同则按左上角列号从小到大。
5. 擦除青(8)模板对象本身（涂为黑(0)背景）。
6. 所有不匹配对象保持原位置和原颜色不变。

**关键洞察**：源题 4ff4c9da 的形状匹配仅决定重涂颜色，源题 afe3afe9 的重力作用于所有非背景像素。本题的创新在于：形状匹配不仅决定颜色变换，更决定了对象的物理角色（可动 vs 地形），而重力下落的结果依赖于不匹配对象的空间分布——同一套形状匹配结果在不同空间布局下产生完全不同的输出。这种"分类即赋予物理属性"的结构关系是两道源题都不具备的。

## 新题 3：分区内独立频率柱状图

**组合逻辑**：[网格分区](已有) + [计数](已有) + [频率排序/频率降序柱状图](已有，创新改造：原作用于整个网格生成单一柱状图，现在每个分区内独立生成局部柱状图) + [填充](已有) → 分区定义计数范围，计数结果在分区几何约束下生成柱状图

**来源原语**：
- 网格分区(grid_partition) + 分隔线(separator_line) ← 6773b310
- 计数(counting) ← 9af7a82c, 6773b310, fcc82909
- 频率排序(frequency_ranking) + 频率降序柱状图(descending_frequency_histogram) ← 9af7a82c
- 排序(sort) ← 9af7a82c
- 填充(fill) ← fb791726

**依赖链**：分隔线 → 确定分区边界 → 每个分区内独立统计各颜色像素数 → 按频率降序排列颜色 → 在该分区内原地生成顶对齐柱状图（柱高=频率，柱色=对应颜色） → 分区尺寸约束柱状图布局。分区边界同时定义统计范围和输出画布，计数结果决定柱高，三者紧耦合。

将分隔线划分的每个分区中的散布彩色像素统计频率，原地替换为顶对齐的频率降序柱状图。

**输入结构**：
- 黑(0)背景，约 17x17 网格。
- 灰(5)像素构成完整的水平分隔线和垂直分隔线（每条线贯穿整行或整列），将网格分为 2x2 或 2x3 个矩形分区。每个分区的内部尺寸至少为 4x4（不含分隔线）。
- 每个分区内散布 2~3 种非黑(0)非灰(5)颜色的像素（如蓝(1)、红(2)、绿(3)、黄(4)、橙(7)等），每种颜色 1~4 个像素，位置随机分布在分区内部。不同分区可包含不同的颜色组合。
- 生成约束：每个分区内不同颜色的像素数量互不相同（无频率平局）。每个分区的宽度（列数）不小于该分区内出现的颜色种类数（保证每种颜色至少有一列空间放置柱状图柱）。每个分区的高度（行数）不小于该分区内最高频率颜色的像素数（保证最高柱不超出分区）。

**规则**：
1. 识别所有灰(5)分隔线，确定各矩形分区的边界（分区内部不含分隔线像素）。
2. 对每个分区，统计其中各非黑非灰颜色的像素数量。
3. 将颜色按像素数降序排列。
4. 清空该分区内部为黑(0)。
5. 在该分区内部生成顶对齐柱状图：从分区内部的最左列开始，第一列对应频率最高的颜色，从该分区内部的第一行（最上方）向下填充该颜色，填充行数等于其像素计数；第二列对应次高频颜色，同样从顶部向下填充；以此类推。未使用的列保持黑(0)。
6. 所有灰(5)分隔线保持不变。

**关键洞察**：源题 9af7a82c 对整个网格做单一柱状图，源题 6773b310 在分区内做简单的标记计数（双标记→蓝）。本题的创新在于：分区结构同时定义了统计范围和输出画布的几何约束——柱状图必须在分区内部生成，分区尺寸隐式限制了可表达的频率范围。求解者必须同时理解分区语义（空间分割）和柱状图语义（频率编码），两者不可分离。需对比多个示例才能区分"分区内局部统计"与"全局统计后切割放回"这两种可能的规则。

## 新题 4：缺口射线测距与跨分区回响

**组合逻辑**：[缺口定射线向](已有) + [射线延伸](已有) + [洪泛填充](已有) + [网格分区](已有) → 创新结构关系：射线被分区边界截断，截断长度编码为信息，在相邻分区中生成等长的"回响"条纹

**来源原语**：
- 缺口定射线向(gap_determines_ray) + 洪泛填充(flood_fill) ← 292dd178
- 射线延伸(ray_extend) ← 292dd178, 891232d6
- 网格分区(grid_partition) + 分隔线(separator_line) ← 6773b310
- 缺口矩形框(one_gap_rect_frame) ← 292dd178
- 重涂色(recolor) ← 292dd178, c7d4e6ad

**依赖链**：缺口 → 射线方向 → 射线沿该方向延伸直到分区边界（分隔线） → 射线长度 L 作为测距信息 → 在分隔线另一侧的相邻分区中，沿同轴画 L 格的"回响"条纹（颜色=边框前景色） → 回响条纹的存在又可能影响其他边框的射线（如果回响进入了另一个边框的射线路径）。缺口方向决定通信通道，分区位置决定射线长度，射线长度决定回响尺寸——三重耦合。

缺口矩形框的射线被分区边界截断，截断长度作为"信号"在相邻分区中生成等长的彩色条纹。

**输入结构**：
- 黑(0)背景，约 20x20 网格。
- 灰(5)像素构成完整的水平和垂直分隔线，将网格分为 2x2（共 4 个）矩形分区。每个分区内部尺寸约 8x8。
- 其中 2~3 个分区各包含一个 4x4 缺口矩形边框（4-连通，一个非角落边界像素缺失），每个边框使用不同的前景色（从蓝(1)、绿(3)、黄(4)、橙(7)中选取）。
- 其余分区为空（仅含黑背景）。
- 生成约束：每个边框的缺口外向方向指向一条分隔线（即缺口射线会先碰到分隔线而非网格边界）。缺口射线指向的相邻分区不包含另一个边框（是空分区），以避免回响条纹与边框冲突。不同边框的回响条纹不会在同一分区中的同一行/列重叠。

**规则**：
1. 对每个缺口矩形边框，定位缺口及其外向方向。
2. 将边框的 2x2 内部和缺口像素涂为红(2)。
3. 从缺口外向邻格开始，沿外向方向逐格画红(2)射线，直到下一格是灰(5)分隔线或网格边界为止（不覆盖分隔线）。记录射线长度 L（新画的红像素数量，不含缺口像素自身）。
4. 确定射线指向的相邻分区：跨过分隔线，找到分隔线另一侧的分区。
5. 在该相邻分区中，从紧邻分隔线内侧的第一个像素开始，沿射线的同一方向，画 L 格的条纹，颜色为该边框的原始前景色（蓝/绿/黄/橙）。若条纹在画完 L 格之前遇到非黑像素或分区的另一侧分隔线，则提前终止。
6. 所有灰(5)分隔线保持不变。所有边框的原始前景像素保持不变。

**关键洞察**：源题 292dd178 的射线延伸到网格边界，不受任何中间结构约束。本题的创新在于：分区边界截断射线，而截断本身携带了几何信息（缺口到分区边界的距离），这个信息被"投射"到相邻分区中——射线不再是视觉效果，而是跨分区的信息传递通道。求解者必须理解"测距→编码→跨界再现"这个三步过程，而非简单的直线延伸。需对比多个示例（不同缺口位置、不同分区尺寸）才能归纳出"回响长度=截断射线长度"这一非显然规则。

## 新题 5：分区感知的条件性寻路

**组合逻辑**：[寻路/障碍触发转向](已有) + [网格分区](已有，创新改造：分区不再用于计数或信息传递，而是定义局部物理规则) + [每行独立取色→创新为每区独立定义障碍色](创新) → 同一颜色像素在不同分区中扮演不同角色（障碍 vs 惰性），路径形态由分区上下文决定

**来源原语**：
- 寻路(pathfinding) + 障碍触发转向(barrier_triggers_turn) + 起止标记(start_end_marker) ← 2dd70a9a
- 网格分区(grid_partition) + 分隔线(separator_line) ← 6773b310
- 每行独立取色(per_row_color) ← c7d4e6ad（创新：从"每行"推广到"每区"，从"取色"推广到"定义障碍类型"）
- 障碍像素(barrier_pixel) ← 2dd70a9a

**依赖链**：分区结构 → 每个分区的指示像素颜色 → 在该分区内哪种颜色像素是障碍 → 路径在该分区内的转向行为 → 路径跨越分区时障碍定义动态切换 → 最终路径形态。同一个蓝(1)像素在"指示色=蓝"的分区中是障碍，在"指示色=橙"的分区中是惰性背景。路径必须在全局上连通，但局部行为由分区上下文决定。

路径从起点到终点穿越多个分区，每个分区中只有与该区指示色相同的像素充当转向障碍，其余有色像素可自由穿过。

**输入结构**：
- 黑(0)背景，约 18x18 网格。
- 灰(5)完整水平线和垂直线将网格分为 2x3 或 3x2 个矩形分区（共 6 个分区），每个分区内部尺寸约 4x5 至 6x7。
- 每个分区内部的左上角格子包含一个"指示像素"，颜色为蓝(1)、橙(7)、黄(4)三种之一。
- 网格中散布蓝(1)、橙(7)、黄(4)的像素点（除指示像素外），位于各分区内部。这些像素在空间上不构成特定图案，随机分布。每个分区内三种颜色的像素都有若干个（各 2~5 个）。
- 绿(3)短线段（2~3 像素，水平或垂直）位于网格的某个边缘，作为起点和初始行进方向。
- 红(2)短线段（2~3 像素）位于网格的另一个边缘，作为终点。
- 分隔线不阻碍路径穿越（路径可自由通过灰(5)分隔线）。
- 生成约束：存在唯一一条从起点到终点的最短路径（在给定的分区障碍规则下），且该路径至少穿越 3 个不同的分区。

**规则**：
1. 读取每个分区左上角格子的指示像素颜色 C_zone。
2. 在该分区内部，颜色为 C_zone 的像素（不含指示像素本身）充当障碍：路径不能进入这些像素所在的格子，当路径沿当前方向的下一格是该分区的 C_zone 色障碍时，路径必须转向 90 度。
3. 在该分区内部，颜色不为 C_zone 的其他非黑非灰像素是惰性的：路径可以自由穿过它们所在的格子（视同黑色背景）。
4. 使用 BFS 搜索（状态=位置+方向），从绿(3)起点出发，沿初始方向前进，在障碍前转向（可左转或右转，BFS 搜索所有可能），找到到达红(2)终点的最短路径。
5. 路径跨越灰(5)分隔线进入新分区时，障碍颜色自动切换为新分区的指示色。灰(5)分隔线本身不是障碍。
6. 将找到的最短路径上的所有黑(0)格子涂为绿(3)。路径穿过的惰性有色像素保持原色不变。所有障碍像素、分隔线、指示像素、起止标记均保持原位置和原颜色。

**关键洞察**：源题 2dd70a9a 中障碍颜色全局统一（青色始终是障碍），路径规则不随位置变化。本题的创新在于：分区结构赋予同一颜色的像素在不同空间区域中截然不同的功能角色。一个蓝(1)像素在某个分区中是致命障碍，在相邻分区中却如同空气。路径的全局最优性必须综合考虑所有分区的局部规则——这不是"先分区再寻路"的线性流水线，而是"寻路过程中持续查询分区上下文"的同时约束满足问题。求解者需要多个示例才能发现"指示像素定义本区障碍色"这一隐蔽规则。

## 新题 6：行对齐涌现形状后的模板匹配

**组合逻辑**：[滑动/边界对齐](已有) + [归一化形状比对/匹配模板则重涂](已有) → 创新结构关系：对齐操作改变像素的空间邻接关系，使原本分散的像素合并为新的连通分量，这些涌现形状再被模板筛选

**来源原语**：
- 滑动(shift) + 边界对齐(edge_alignment) + 色段(color_run) + 同行排列(row_arrangement) ← 984d8a3e
- 归一化形状比对(normalized_shape_matching) + 匹配模板则重涂(recolor_on_match) ← 4ff4c9da
- 连通分量(connected_component) ← 4ff4c9da
- 重涂色(recolor) ← 4ff4c9da, c7d4e6ad

**依赖链**：每行的色段右边界不对齐 → 行滑动使右边界对齐 → 对齐后不同行的中间色像素在垂直方向上可能相邻 → 新的 4-连通分量涌现 → 与模板形状比对 → 匹配者重涂。对齐前的形状与对齐后完全不同，模板匹配只能在对齐后进行；而对齐规则本身需要从色段结构中推断。两步逻辑产生了涌现效应：单独的行滑动不会暗示形状匹配，单独的形状匹配不知道要先对齐。

将水平色段右边界对齐后，由中间色合并形成的新连通分量中与模板同形者重涂为青色。

**输入结构**：
- 黑(0)背景，约 12x15 网格（12 行 15 列）。
- 每行包含三段连续色段：左段为栗(9)像素（0~3 个），中段为蓝(1)像素（3~8 个），右段为红(2)像素（1~4 个）。每行的中段长度和左段长度不同，导致中段的右边界列号逐行变化。
- 网格右下角区域有一个青(8)小对象（3~5 像素，4-连通），作为形状模板。该对象不与任何色段行重叠（位于色段行的下方或右侧空白区域）。
- 生成约束：所有行的中段右边界列号中的最小值记为 C_min。对齐后（每行中段右边界移到 C_min），中段蓝(1)像素形成的 4-连通分量中，恰好有 2~3 个分量的归一化掩码与青(8)模板相同，其余分量的掩码不同。对齐前，这些匹配形状并不存在（对齐前的蓝色连通分量没有任何一个与模板匹配）。

**规则**：
1. 对每一行，识别三段色段及其边界：左段（栗(9)）、中段（蓝(1)）、右段（红(2)）。
2. 找到所有行中中段右边界列号的最小值 C_min。
3. 对每一行：保持中段宽度和右段像素数不变，将中段整体滑动使其右边界对齐到 C_min 列。中段左侧原本被栗(9)占据的空间变为栗(9)填充至中段新左边界。如果中段太宽无法在 C_min 处对齐（即中段宽度 > C_min + 1），则将中段左边界设为第 0 列。右段紧跟中段之后，右段之后的列为黑(0)。
4. 对齐完成后，提取所有蓝(1)像素形成的 4-连通分量。
5. 提取青(8)模板的归一化 4-连通掩码。
6. 将掩码与模板相同的蓝(1)分量全部重涂为青(8)。
7. 其余蓝(1)分量、栗(9)像素、红(2)像素均保持对齐后的位置和颜色不变。青(8)模板对象保持不变。

**关键洞察**：源题 984d8a3e 的行对齐是最终输出，源题 4ff4c9da 的形状匹配作用于静态输入。本题的核心涌现效应在于：对齐操作是隐式的"形状生成器"——它改变了哪些像素在垂直方向上相邻，从而创造出对齐前不存在的连通分量。求解者必须先推断对齐规则（需对比多个示例中的色段边界），再理解对齐后的形状匹配——两步推理中，第一步的输出构造了第二步的输入，而第一步本身没有暗示需要做形状匹配。

1. 识别所有多色精灵体及其签名像素颜色。识别方法：精灵体中恰好出现一次且不在其他精灵体中出现的颜色即为签名色。

6. 印章全部完成后，擦除所有原始精灵体（它们在上半区的原始位置全部涂为黑(0)）。
7. 目标标记被印章像素覆盖后不再单独可见。

## 新题 8：空心符号压缩后重力排列再模板展开

**组合逻辑**：[压缩](已有) + [重力下落/标记指示方向](已有) + [像素放大/颜色到模板映射](已有，创新改造：展开不是等比放大而是按色-模板映射替换) → 三级级联：压缩改变信息密度 → 重力改变空间排列 → 展开改变表征形式，且同一个边缘标记同时控制压缩目标粒度和重力方向

将空心符号压缩为像素后按边缘标记方向做重力堆积，再用色-模板映射将每个像素展开为对应的模板花纹。

- 黑(0)背景，网格整体约 20x22。

  - **图例区**（顶部 3~4 行）：左侧排列 2~3 个 2x2 纯色色卡（如蓝(1)、绿(3)、黄(4)），每个色卡之间间隔 1 列黑像素；右侧排列等数量的 2x2 灰(5)模板遮罩，每个遮罩的 4 个像素中 2~3 个为灰(5)、其余为黑(0)，形成不同花纹。色卡与模板遮罩按从左到右的顺序一一配对。
  - **空白分隔**（1~2 行全黑）。
  - **符号区**（底部区域，约 12x12）：在 3x3 的粗栅格上排列 3~6 个空心 3x3 符号。每个符号是一个 3x3 方格，其中 8 个边界像素为某种色卡颜色之一，中心 1 像素为黑(0)（即"空心"）。符号之间通过全黑的行/列分隔（空栅格位置不含符号）。符号的颜色不必都不同——同一颜色可出现在多个符号中。
- 网格的一条完整边缘（上/下/左/右之一）有一行/列红(2)标记像素，作为边缘标记线。该标记线不在图例区或符号区内部，而在网格的最外边缘。
- 生成约束：边缘标记线所在的边决定压缩方向和重力方向的映射关系（顺时针边界旅行：上→右, 右→下, 下→左, 左→上）。压缩/重力后的像素网格尺寸不超过 4x4。展开后的输出尺寸为压缩后网格尺寸乘以 2（因为模板是 2x2），即不超过 8x8。

**规则**：
1. 读取边缘标记线的位置，确定方向 D（上边→D=右，右边→D=下，下边→D=左，左边→D=上）。
2. 在符号区中，将每个空心 3x3 符号压缩为一个像素：该像素的颜色取符号的边界像素颜色，位置取该符号在粗栅格中的位置（行索引, 列索引）。完全空白的栅格位置不产生像素。结果是一个小的索引网格（2~4 行 x 2~4 列），包含有色像素和空位（黑色）。
3. 对索引网格施加方向 D 的重力：所有有色像素沿 D 方向滑动到尽头（碰到其他有色像素或网格边界停止），保持像素在垂直于 D 方向上的坐标不变。
4. 对重力后的索引网格做模板展开：每个有色像素根据图例中的色卡-模板配对，替换为对应的 2x2 模板遮罩。遮罩中灰(5)位置涂为该像素的颜色，遮罩中黑(0)位置保持黑(0)。空位像素展开为 2x2 全黑。
5. 输出仅为展开后的网格。图例区、分隔区、边缘标记线均不包含在输出中。

**关键洞察**：源题 afe3afe9 的压缩和重力是最终结果，源题 42f83767 的模板展开作用于静态索引网格。本题的创新在于三步操作的级联涌现：压缩将视觉丰富的空心符号降维为抽象索引，重力在索引空间中重新排列（一个在视觉空间中不可能的操作——你无法对 3x3 符号做精确重力堆积，但压缩后的像素可以），展开再将索引升维为新的视觉花纹。边缘标记的双重语义（同时控制压缩和重力）使得参数空间极小但效果空间极大。

## 新题 9：走廊连接后内部区域颜色多样性标记

**组合逻辑**：[连线/最小生成树连接](已有) + [擦除/重叠决定走廊宽度](已有) + [计数/颜色数决定高度](创新改造：原作用于独立方块，现作用于走廊连通后的合并内部区域) + [绘制](已有) → 走廊连接改变了区域的拓扑连通性，连通后的区域合并使颜色多样性统计结果与连接前不同

**来源原语**：
- 连线(connect) + 最小生成树连接(min_spanning_tree) + 最短可见间距(shortest_gap) ← b9630600
- 空心矩形(hollow_rectangle) + 走廊(corridor) + 重叠决定走廊宽度(overlap_corridor_width) ← b9630600
- 擦除(erase) ← b9630600
- 计数(counting) + 颜色数决定高度(color_count_height) ← fcc82909
- 绘制(drawing) + 标记矩形(marker_rect) + 邻接放置(adjacent_placement) ← fcc82909
- 内部区域(interior_region) ← 292dd178

**依赖链**：空心矩形各自内部有不同颜色的标记像素 → 走廊连接（改变拓扑：原本分离的内部区域通过走廊连通后合并为一个区域） → 统计合并后每个连通内部区域中不同颜色标记的种类数 → 在每个连通区域的最低矩形框下方绘制绿色标记矩形（高度=颜色种类数）。走廊决定了哪些内部区域合并，合并决定了颜色统计结果，统计决定了标记高度。

将空心矩形通过最短走廊连通后，统计每个合并内部区域的颜色多样性，并在下方绘制高度等于多样性的绿色标记。

**输入结构**：
- 黑(0)背景，约 20x20 网格。
- 蓝(1)像素构成 3~5 个空心矩形框（每个矩形的边框宽度为 1 像素，内部为空心区域，矩形尺寸各异，宽高在 4~7 之间）。矩形之间不接触，水平或垂直间距 2~5 像素。
- 每个矩形的内部区域包含 1~3 个不同颜色的标记像素（从红(2)、绿(3)、黄(4)、橙(7)、品红(6)中选取），分布在内部区域的任意位置。不同矩形的内部标记颜色组合不同。
- 生成约束：存在可见的水平/垂直间距连接候选（两个矩形在水平或垂直方向上有内部行/列的重叠，且它们之间全是黑背景）。用最短间距生成树可将所有矩形连通。走廊连接后，至少有两个矩形的内部区域通过走廊合并为一个连通区域。每个矩形下方有足够空间（至少 5 行）绘制标记矩形。

**规则**：
1. 检测所有蓝(1)空心矩形框。
2. 计算所有可见的水平和垂直间距候选（两矩形内部有行或列重叠，间距内全黑），记录间距长度。
3. 选取最短间距生成树连接所有矩形：对间距候选按长度升序排列，依次选取不产生环的间距，直到所有矩形连通。
4. 对选中的每个间距，构建走廊：
   - 水平间距：在两矩形内部重叠行范围的最上行和最下行之间（含），画两条蓝(1)水平线连接两矩形的面对的墙壁。擦除两矩形面对面的墙壁上、处于这两行之间（不含两行本身）的蓝(1)像素为黑(0)。
   - 垂直间距同理（转置操作）。
5. 走廊连接后，识别所有由黑(0)像素构成的、被蓝(1)像素完全包围的连通内部区域（4-连通）。走廊使原本分离的矩形内部可能合并为一个大的连通区域。
6. 对每个连通内部区域，统计其中包含的不同颜色标记像素的种类数 K（仅计颜色种类数，不计像素个数）。
7. 对每个连通内部区域，找到包含该区域的所有矩形中最低的那个矩形框（底边行号最大者）。在该矩形框底边的正下方一行开始，绘制一个绿(3)实心矩形，宽度等于该矩形框的宽度，高度等于 K。
8. 所有蓝(1)边框像素（含走廊新增的）和所有内部标记像素保持不变。

**关键洞察**：源题 b9630600 的走廊连接是最终结果（不涉及后续统计），源题 fcc82909 的颜色多样性统计作用于独立的 2x2 方块（内部不会合并）。本题的创新在于：走廊连接改变了拓扑——原本颜色多样性为 1 的矩形（内部只有一种标记色），通过走廊与另一个矩形合并后，多样性可能变为 2 或 3。走廊选择（最短生成树）决定了哪些矩形合并，合并决定了多样性统计，统计决定了标记高度。如果走廊选择不同（比如选了不同的间距），合并的矩形组合不同，颜色多样性不同，标记高度也不同。这种"连接决策→拓扑变化→统计结果变化→视觉输出变化"的因果链是两道源题各自不具备的。
