## 新题 1：面板差异生成墙壁与种子的洪泛填充

**组合逻辑**：[逐像素比较/pixel_comparison](创新：比较结果不作为最终输出，而是生成结构角色) → [洪泛填充/flood_fill](已有原语，作用于比较生成的结构)

**来源原语**：逐像素比较/pixel_comparison（d47aa2ff）、面板/panel（d47aa2ff）、分隔列/separator_col（d47aa2ff）、差异分类着色/diff_class_color（d47aa2ff）、洪泛填充/flood_fill（e69241bd）、墙壁/wall（e69241bd）、标记在区域内/marker_inside（e69241bd）、标记色填充区域/marker_color_fills（e69241bd）、封闭区域/enclosed_region（e69241bd）

**依赖链**：逐像素比较的输出不是最终答案，而是为洪泛填充生成输入结构——双面板的一致像素变为墙壁，差异像素变为种子标记。没有比较就没有墙壁/种子分布，没有洪泛填充比较结果就不是答案。两步逻辑不可分离。

将两块对齐面板逐像素比较，一致位置变墙壁、差异位置变种子标记，再以墙壁为屏障对每个封闭区域做种子色洪泛填充。

**输入结构**：约 11×23 的网格，黑(0)为背景。中央有一列品红(6)分隔列将网格均分为左右两块 11×11 面板。两块面板各含若干前景像素（颜色一致，均为黄(4)），分布大部分重合但有局部差异——某些位置仅左面板有前景，某些位置仅右面板有前景。生成约束：每个 4-连通非墙壁区域中，左独有像素和右独有像素不同时存在（即每个区域至多一种种子色），保证填充无歧义。

**规则**：
1. 移除品红(6)分隔列，将左右面板对齐为一个 11×11 网格。
2. 逐像素比较两面板：若两面板在该位置均为前景（黄(4)），该像素标记为灰(5)，作为墙壁；若两面板均为背景（黑(0)），保持黑(0)背景。
3. 若仅左面板有前景，该像素标记为红(2)；仅右面板有前景，标记为蓝(1)。这些像素是洪泛填充的种子。
4. 以灰(5)墙壁像素为不可穿透屏障，对每个 4-连通的非墙壁区域检查：若该区域内有种子像素，则将该区域内所有非墙壁像素（含背景）填充为种子颜色（红(2)或蓝(1)）。种子像素本身保持其颜色不变。
5. 无种子的区域保持黑(0)背景不变。墙壁像素保持灰(5)不变。
6. 处理顺序不影响结果（各区域独立），无冲突。

**关键洞察**：两面板的一致前景像素不是"共享内容"——它们变成了分隔空间的墙壁；差异像素不是"错误标记"——它们是决定各区域填充色的种子。比较结果的语义角色（墙壁 vs 种子）必须通过对比多个示例的输出才能归纳。

## 新题 2：墙壁腔室内从标记点出发的同心环循环着色

**组合逻辑**：[洪泛填充/flood_fill](创新：不是单色填充，而是确定像素归属腔室) + [循环填充/cyclic_filling](创新：循环基于曼哈顿距离而非对角层深) + [重涂色/recolor](已有，按距离+调色板决定色)

**来源原语**：洪泛填充/flood_fill（e69241bd）、墙壁/wall（e69241bd）、标记在区域内/marker_inside（e69241bd）、封闭区域/enclosed_region（e69241bd）、循环填充/cyclic_filling（b457fec5）、调色板行/palette_row（b457fec5）、层深度递增/layer_depth_increasing（b457fec5）、层深模色板取色/depth_mod_palette_color（b457fec5）、标记像素/marker_pixel（e69241bd, b457fec5）

**依赖链**：洪泛填充确定每个像素属于哪个腔室（从而知道距离计算的原点在哪），循环填充决定每个像素的具体颜色。标记像素既是洪泛填充的归属标识、又是距离计算的原点、还通过自身颜色编码调色板偏移量——三重角色不可拆分。

以墙壁为屏障确定像素所属腔室，从腔室内标记点出发计算曼哈顿距离，用共享调色板按距离循环着色，标记颜色决定调色板起始偏移。

**输入结构**：约 15×15 的网格，黑(0)为背景。灰(5)像素构成连通的墙壁网络，将网格分隔为 3~5 个不规则封闭腔室（每个腔室面积约 8~25 像素）。每个腔室内恰好有一个单像素标记，标记颜色各不相同且均非黑(0)、非灰(5)。网格最上方一行（不属于任何腔室）是一条水平调色板行，包含 2~4 个连续的彩色像素（颜色互不相同，均非黑(0)、非灰(5)），从左到右定义调色板序列 P[0], P[1], ...。生成约束：每个腔室恰好含一个标记；标记颜色的值在 0 到 len(P)-1 之间（可通过观察多个示例归纳映射规则，见关键洞察）。

**规则**：
1. 识别灰(5)墙壁和水平调色板行（最上方行中连续的非黑非灰像素序列），调色板长度记为 L。
2. 对每个 4-连通非墙壁腔室区域，找到其内部唯一的标记像素，记录标记位置 (mr, mc) 和标记颜色 C_m。
3. 确定该标记的调色板偏移量 offset：offset 等于标记颜色在调色板行中的位置索引（0-based）。若标记颜色不在调色板中出现，则 offset = 0。
4. 对该腔室内每个非标记像素 (r, c)，计算其到标记的曼哈顿距离 d = |r - mr| + |c - mc|，将其着色为 P[(d + offset) mod L]。
5. 标记像素本身保持原色不变。墙壁保持灰(5)。调色板行保持不变。背景（不属于任何腔室的黑色区域）保持黑(0)。
6. 各腔室独立处理，处理顺序不影响结果。

**关键洞察**：标记颜色不是填充色——它编码了调色板的起始偏移。同一个腔室形状，换一个标记颜色就会产生完全不同的同心环色彩图案。这一偏移规则必须对比多个腔室（或多个示例）才能归纳。

## 新题 3：视线匹配后沿轮廓行走并按间距重涂尾端

**组合逻辑**：[射线延伸/ray_extend](创新：用于视线匹配而非绘制) → [滑动/slide](创新：沿障碍轮廓行走而非移至端点) → [重涂色/recolor](创新：重涂长度由间距编码，起始于行走远端)

**来源原语**：滑动/slide（97c75046）、障碍轮廓/obstacle_contour（97c75046）、轮廓邻接/contour_adjacency（97c75046）、最长贴边路径/longest_adjacent_path（97c75046）、射线延伸/ray_extend（696d4842）、重涂色/recolor（696d4842）、路径对象/path_object（696d4842）、标记像素/marker_pixel（696d4842）、视线匹配/sightline_matching（696d4842）、间距编码尾长/gap_distance_encodes_tail_length（696d4842）

**依赖链**：视线匹配将每个标记关联到特定障碍（决定"走哪条轮廓"）。间距（标记到障碍的背景格数）编码重涂长度。轮廓行走确定路径形状和总长。重涂从行走远端回溯，长度取决于间距。四个变量（匹配目标、间距、行走路径、重涂范围）相互耦合，删除任一环节都无法求解。

标记像素通过视线匹配关联到障碍区域，沿障碍外轮廓行走最长贴边路径，然后从路径远端起回溯重涂，重涂长度等于标记到障碍的原始间距。

**输入结构**：约 15×18 的网格，黑(0)为背景。2~3 个由蓝(1)像素构成的不规则连通障碍区域（每个约 6~15 像素，4-连通，非矩形，有凹凸轮廓）分布在网格中。2~3 个单像素标记散布于障碍区域外侧，每个标记颜色各不相同（如红(2)、绿(3)、黄(4)），且每个标记恰好沿水平或垂直方向（唯一一条无阻挡的正交视线）正对某个障碍区域的边缘像素，中间全为背景像素（间距 >= 1）。标记到障碍之间不同标记有不同间距。生成约束：标记与障碍之间的匹配唯一（一对一），每个标记的视线方向到达障碍的触点有两个可选转向（沿轮廓顺时针或逆时针），其中一个方向能保持 4-邻接障碍的距离更长。

**规则**：
1. 对每个标记像素，沿其唯一的正交视线方向找到最近的障碍边缘像素（视线触点），记录间距 G = 标记与触点之间的背景格数（不含标记和触点本身）。
2. 从视线触点的前一个背景像素（即与触点相邻、在视线路径上的最后一个背景格）出发，选择沿障碍外轮廓行走的两个可选方向（左转/右转），选取能保持与障碍 4-邻接距离更长的方向。
3. 沿该方向行走，每步只走背景像素且必须保持与障碍区域 4-邻接，直到下一步无法同时满足这两个条件时停止。记录行走路径的总像素数为 W。
4. 将行走路径的最后 min(G, W) 个像素（从远端开始）重涂为该标记的颜色。
5. 标记像素原位保持不变。障碍区域保持蓝(1)不变。标记到触点之间的背景间距保持黑(0)不变（标记不"移动"到轮廓上）。
6. 多个标记的重涂区域不会重叠（由生成约束保证各标记匹配不同障碍的不同轮廓段）。

**关键洞察**：间距不仅是标记与障碍之间的空白——它精确编码了轮廓远端需要被重涂的长度。标记离障碍越远，远端被重涂的尾巴越长。这一"远端回溯"规则必须对比不同间距的示例才能发现。

## 新题 4：对角楔形区域内沿楔轴方向的定向沉降

**组合逻辑**：[填充/fill](创新：不是三角区域着色，而是确定像素所属楔形) + [滑动/sliding · 重力沉降/gravity_settling](创新：重力方向不固定向下，而是由楔形朝向决定)

**来源原语**：填充/fill（896d5239）、三角楔形区域/triangular_wedge（896d5239）、标记像素/marker_pixel（896d5239）、对角线边界/diagonal_boundary（896d5239）、标记定义楔形范围/marker_define_wedge（896d5239）、滑动/sliding（1e0a9b12）、前景像素/foreground_pixel（1e0a9b12）、重力沉降/gravity_settling（1e0a9b12）、列内独立/column_independent（1e0a9b12，创新为轴独立/axis_independent）

**依赖链**：对角边界定义楔形区域的形状和朝向。朝向同时决定了该区域内的重力方向（朝向开口面沉降）。前景像素的最终位置既取决于它属于哪个楔形（决定重力方向），又取决于楔形的几何边界（沉降时不能越过对角线边界）。楔形几何与重力方向是同一信息的两面，不可分离。

绿色标记定义 45 度三角楔形区域，散落在楔形内的彩色前景像素沿楔形朝向（开口方向）做重力沉降，在楔形边界内紧贴底边堆叠。

**输入结构**：约 13×13 的网格，黑(0)为背景。绿(3)像素稀疏分布，标记出 2~3 个不重叠的三角楔形区域的对角边界线（每个楔形由一个尖端像素和两条 45 度对角边界射线定义，开口方向为四个基本方向之一：上、下、左、右）。楔形高度约 3~5 像素。在每个楔形区域内部（对角边界围成的三角范围内），散落 2~5 个单像素前景色块，颜色各异（如红(2)、蓝(1)、黄(4)等），位置随机。不同楔形的前景色可以重复。生成约束：各楔形互不重叠；每个楔形的开口方向至少有两种不同方向出现在同一示例中（以便对比归纳方向规则）。

**规则**：
1. 识别每个楔形的尖端像素（绿(3)像素中度数为 2 的拐点，向两个 45 度对角方向延伸的绿色射线交汇处）和开口方向（尖端对面的方向即为开口方向）。
2. 确定每个楔形的沉降轴：开口方向即为重力方向。例如开口朝下的楔形，重力方向为向下；开口朝右的楔形，重力方向为向右。
3. 对每个楔形内的前景像素，沿重力方向平移，在垂直于重力方向的轴上保持坐标不变。像素移动到该轴坐标上、楔形边界内、重力方向最远端的可用位置（即紧贴楔形底边或已有像素堆叠）。
4. 同一轴坐标上多个前景像素按原始距离底边的远近排序（原本离底边近的先到达底边，后续像素依次堆叠在其上方）。实际操作等价于：读取该轴坐标上所有前景像素的颜色（按原始位置从远离底边到靠近底边的顺序），然后从底边起依次放回。
5. 绿(3)对角边界线保持不变。楔形外部的背景保持黑(0)。前景像素移动后原位清为黑(0)。
6. 各楔形独立处理，顺序不影响结果。

**关键洞察**：楔形的对角边界不只是装饰——它们的几何朝向隐式编码了内部像素的重力方向。同一个楔形换个朝向，内部像素会沉降到完全不同的位置。这一"朝向即重力"的隐式编码需要对比不同朝向楔形的示例才能发现。

## 新题 5：跨区段连通分量计数决定对角带循环调色板长度

**组合逻辑**：[计数/counting](已有) → [循环填充/cyclic_filling](创新：循环长度不固定，由另一区段的计数动态决定) + [重涂色/recolor](已有)

**来源原语**：计数/counting（b0039139）、分隔线/separator_line（b0039139）、连通分量计数/component_count（b0039139）、计数决定重复次数/count_determines_repetition（b0039139，创新为计数决定调色板长度）、循环填充/cyclic_filling（b457fec5）、对角带/diagonal_band（b457fec5）、调色板行/palette_row（b457fec5）、层深度递增/layer_depth_increasing（b457fec5）、层深模色板取色/depth_mod_palette_color（b457fec5）、重涂色/recolor（b457fec5）

**依赖链**：区段 A 的连通分量计数 N 决定从区段 B 的调色板行中截取前 N 种颜色作为有效调色板。区段 C 的对角带灰色像素用这个长度为 N 的调色板做循环着色。N 同时控制着色的周期和可用色彩范围——改变 N 会同时改变图案的颜色组成和重复频率。

统计一个区段中的连通分量数作为调色板截取长度，用截取后的调色板对另一区段的灰色对角带做层深循环着色。

**输入结构**：约 10×22 的网格，黑(0)为背景。蓝(1)实心分隔列（1 列宽）将网格竖向均分为三个区段，从左到右分别为区段 A、区段 B、区段 C，每个区段约 10×6。区段 A：包含 2~5 个由同一颜色（如红(2)）组成的 4-连通不规则小图形（每个 2~5 像素），彼此不相连，背景为黑(0)。区段 B：最上方一行为水平调色板行，包含 3~5 个连续的彩色像素（颜色互不相同，如绿(3)、黄(4)、品红(6)、橙(7)、青(8)），其余为黑(0)背景。区段 C：包含 1~2 条灰(5)对角带（斜向矩形条带，宽度 2~3 像素，长度跨越区段高度的大部分），带有一个靠近区段 B 一侧的平头端。生成约束：区段 A 中连通分量数 N 满足 2 <= N <= 调色板长度。

**规则**：
1. 识别蓝(1)分隔列，将网格分为区段 A、B、C。
2. 在区段 A 中，统计 4-连通非背景连通分量的数量，记为 N。
3. 从区段 B 的调色板行中取前 N 个颜色（从左到右），组成有效调色板 P[0..N-1]。
4. 对区段 C 中每条灰(5)对角带：找到其平头端（靠近区段 B 侧的端部），以平头端为起始层（layer 0），沿带的延伸方向逐层编号。每个灰色像素的层号 = min(该像素到带左边界的列偏移, 该像素到平头端的行偏移)，远端平头处层号被截断为最后层的值并延续。
5. 将每个灰色像素重涂为 P[layer mod N]。
6. 区段 A 和区段 B 保持不变。分隔列保持蓝(1)。对角带中原本非灰色的像素（若有）保持不变。

**关键洞察**：区段 A 的图形形状和颜色无关紧要——只有分量个数有意义，且这个计数不是决定"重复几次"，而是决定"调色板多长"，从而改变对角带每一层的颜色。对比不同 N 值的示例才能区分"计数决定重复"和"计数决定调色板长度"。

## 新题 6：视线连接路径后以标记为原点做距离循环着色

**组合逻辑**：[射线延伸/ray_extend](创新：用于连接标记与路径端点，而非独立射线) + [循环填充/cyclic_filling](创新：循环原点不在对角带边缘而在外部标记点) + [重涂色/recolor](已有)

**来源原语**：射线延伸/ray_extend（696d4842）、路径对象/path_object（696d4842）、标记像素/marker_pixel（696d4842）、视线匹配/sightline_matching（696d4842）、间距编码尾长/gap_distance_encodes_tail_length（696d4842，创新为间距作为距离偏移的一部分）、循环填充/cyclic_filling（b457fec5）、调色板行/palette_row（b457fec5）、层深度递增/layer_depth_increasing（b457fec5）、层深模色板取色/depth_mod_palette_color（b457fec5）

**依赖链**：视线匹配确定标记-路径配对关系。射线延伸连接标记与路径端点，间距成为距离计算的一部分。循环着色以标记为原点、覆盖整条扩展路径（间距段 + 原始路径），颜色由像素沿路径到标记的步行距离决定。标记位置既决定了匹配目标，又决定了着色原点——移动标记会同时改变匹配对象和所有像素的颜色。

标记与路径端点通过视线射线连接后，以标记为原点沿路径逐步行走，用共享调色板按步行距离循环着色。

**输入结构**：约 15×15 的网格，黑(0)为背景。最上方一行为水平调色板行，包含 2~3 个连续彩色像素（如红(2)、蓝(1)、绿(3)），从左到右定义调色板 P。网格中有 2~3 条单像素宽、无分支的正交折线路径（每条 5~12 像素，4-连通，同色，各路径颜色相同均为灰(5)），路径恰好有两个端点。同时有 2~3 个单像素标记（颜色各不相同，均非黑(0)、非灰(5)），每个标记沿水平或垂直方向与某条路径的一个端点有无阻挡的背景间距视线（间距 >= 1）。生成约束：标记与路径的视线匹配唯一（一对一）；不同标记到各自路径的间距不同。

**规则**：
1. 将每个标记像素与唯一视线可达的路径端点配对。记录标记位置 M、触达端点 E_near、间距 G（标记与端点之间的背景格数，不含两端）。
2. 用灰(5)填充标记与端点之间的 G 个背景像素，将间距段连入路径，形成一条从 M 的相邻格到路径另一端 E_far 的扩展路径。标记本身不属于路径。
3. 沿扩展路径从标记侧（E_near 侧）向 E_far 侧逐步行走，每步步行距离 d 从 1 开始递增（紧邻标记的第一个路径像素 d=1，接下来 d=2，依此类推）。
4. 将每个路径像素重涂为 P[(d - 1) mod L]，其中 L 为调色板长度。
5. 标记像素保持其原色不变。调色板行保持不变。非路径、非标记的背景保持黑(0)。
6. 多条路径独立处理，顺序不影响结果。

**关键洞察**：标记不只是匹配锚点——它是循环着色的距离原点。同一条路径被不同距离的标记匹配时，间距段会被纳入路径并改变后续所有像素的距离编号，从而产生完全不同的颜色图案。需要对比不同间距的示例才能发现距离从标记处起算。

## 新题 7：面积排序后按视线间距编码的间隔拼合碎片

**组合逻辑**：[排序/sort](已有) + [拼合填充/packing](创新：碎片间距不固定为 0 或 1，而是由视线间距编码) + [射线延伸/ray_extend](创新：用于测量间距而非绘制)

**来源原语**：排序/sort（4df5b0ae）、面积排序/area_ordering（4df5b0ae）、基线对齐排列/baseline_aligned_pack（4df5b0ae）、精灵体/sprite（4df5b0ae）、拼合填充/packing（b7cb93ac）、多连块碎片/polyomino_fragment（b7cb93ac）、无重叠拼合/non_overlap_packing（b7cb93ac）、射线延伸/ray_extend（696d4842）、标记像素/marker_pixel（696d4842）、视线匹配/sightline_matching（696d4842）、间距编码尾长/gap_distance_encodes_tail_length（696d4842，创新为间距编码排列间隔）

**依赖链**：面积排序决定碎片排列顺序。视线匹配将每个标记与碎片配对。标记到碎片的间距编码该碎片左侧的空白列数。三个信息（排列位置、碎片身份、间隔宽度）分别来自三个不同的原语，缺一不可。

**规则**：
1. 将每个灰(5)标记与其垂直向上视线可达的碎片配对，记录间距 S（标记与碎片最下方像素之间的背景行数，不含两端）。
2. 将所有碎片按像素面积从小到大排序。面积相同时按碎片包围盒左上角的列坐标从左到右排序。
3. 构建输出网格（高度 = 所有碎片包围盒的最大高度，宽度 = 所有碎片包围盒宽度之和 + 所有间距之和）：从左到右依次放置排好序的碎片，每个碎片底部对齐输出网格底部。碎片之间插入的空白列数 = 该碎片（非前一个碎片）对应的标记间距 S。第一个碎片（面积最小者）左侧也插入其对应标记的间距 S 列空白。
4. 每个碎片保持原色和形状（包围盒裁剪，内部背景保持黑(0)）。空白区域为黑(0)。
5. 标记像素不出现在输出中。

**关键洞察**：标记到碎片的垂直间距不是用于连线或着色——它编码了该碎片在最终排列中左侧的空白间隔。间距越大，碎片前面的留白越多。这一编码规则与面积排序规则交织：必须同时知道排列顺序和间隔宽度才能确定输出。

## 新题 8：重力沉降后在障碍场中绘制闪避螺旋

**组合逻辑**：[滑动/sliding · 重力沉降/gravity_settling](已有，作为预处理) → [螺旋绘制/spiral_draw](创新：螺旋不在空白画布上绘制，而是在有障碍的场景中闪避障碍)

**来源原语**：滑动/sliding（1e0a9b12）、前景像素/foreground_pixel（1e0a9b12）、列内独立/column_independent（1e0a9b12）、重力沉降/gravity_settling（1e0a9b12）、螺旋绘制/spiral_draw（28e73c20）、正方形画布/square_canvas（28e73c20）、路径/path（28e73c20）、碰撞转向/turn_on_collision（28e73c20）、画布边界/canvas_boundary（1e0a9b12, 28e73c20）

**依赖链**：重力沉降改变前景像素的分布，形成障碍场。螺旋绘制必须在沉降后的障碍场中进行，将已沉降的像素视为额外的碰撞边界。同样的初始像素分布，不做沉降就直接画螺旋会得到完全不同的路径。沉降后的障碍布局决定螺旋的每一次转向和终止点。

先将散落的彩色像素按列重力沉降到底部，然后在沉降后的布局上从左上角开始绘制顺时针螺旋，沉降后的像素作为障碍迫使螺旋提前转向或终止。

**输入结构**：约 9×9 的正方形网格，黑(0)为背景。网格中散布 5~12 个单像素前景色块，颜色可以相同或不同（如红(2)、蓝(1)、黄(4)等），位置随机分布在各处（不集中于底部）。网格左上角 (0,0) 位置保证为黑(0)背景。生成约束：沉降后左上角 (0,0) 仍然为黑(0)（即第 0 列的前景像素沉降后不会填到第 0 行）。

**规则**：
1. 对每一列独立地将该列中所有非黑(0)像素按从上到下的原始顺序紧凑到该列底部（标准重力沉降）。沉降后，各前景像素保持原色，腾空位置填黑(0)。
2. 在沉降后的网格上绘制顺时针螺旋：从左上角 (0,0) 开始，初始方向为向右。
3. 螺旋前进规则：每步检查沿当前方向的下一个像素。若下一个像素在网格内且为黑(0)背景，则将当前位置涂为绿(3)并前进。但若沿当前方向的前方第 2 步位置已经是绿(3)或前景色（非黑非绿也算障碍），则提前做顺时针转向。
4. 碰撞转向：当下一步位置出界、或下一步位置为非黑(0)像素（绿(3)螺旋轨迹或沉降后的彩色前景像素）时，顺时针旋转 90 度。若转向后下一步仍无法前进，再转 90 度，依此类推。若四个方向都无法前进，停止绘制。
5. 停止绘制后，输出网格同时包含沉降后的彩色前景像素（保持原色）和绿(3)螺旋路径。
6. 一步前瞻规则（与 28e73c20 一致）：若当前方向可以走一步但前方第 2 步是绿(3)，则也执行顺时针转向，以保持螺旋间隙。

**关键洞察**：散落的前景像素本身不是障碍——必须先沉降才形成实际障碍布局。同一组像素在不同列的分布经重力压缩后产生不同的底部障碍墙，螺旋在不同位置被迫偏转。需要对比输入的散布位置和输出的螺旋形状才能发现"先沉降再画"的两步逻辑。

## 新题 9：三连块对角复制后从副本角点发射对角射线

**组合逻辑**：[平移/translate · 重涂色/recolor](已有，用于生成对角副本) → [射线延伸/ray_extend](创新：不从路径端点发射，而是从副本的 L 形角点沿对角线发射)

**来源原语**：平移/translate（1e5d6875）、重涂色/recolor（1e5d6875）、三连块/triomino（1e5d6875）、缺角/missing_corner（1e5d6875）、对角偏移/diagonal_offset（1e5d6875）、源色决定方向/source_color_decides（1e5d6875）、射线延伸/ray_extend（2b9ef948）、对角射线/diagonal_ray（2b9ef948）、空心框/hollow_frame（2b9ef948，本题中无框，但射线延伸规则类比）

**依赖链**：缺角方向决定副本的对角偏移方向，源颜色决定偏移是朝向还是远离缺角。副本的 L 形几何形状（继承自原件的旋转）决定了角点位置和射线发射方向。射线在命中非背景像素或网格边界时停止。不同源色的副本产生不同颜色的射线，且黄(4)射线先绘制、绿(3)射线后绘制（后者覆盖前者）。副本位置、形状和射线方向是一条紧耦合链。

L 三连块产生变色对角副本，副本的两个端点像素各发射一条朝外的对角射线，射线颜色与副本同色，绘制优先级由副本颜色决定。

**输入结构**：约 15×15 的网格，黑(0)为背景。4~6 个 L 形三连块（每个占据 2×2 区域中的 3 个像素，缺一个角），颜色为红(2)或灰(5)，随机分布在网格中。不同三连块的 L 朝向（缺角在左上、右上、左下、右下）可以不同。生成约束：各三连块互不相邻（4-连通距离 >= 2）；副本位置和射线路径不会超出网格太多（至少部分可见）。

**规则**：
1. 对每个三连块，找到其 2×2 包围盒中缺失的角位置，确定缺角方向向量 V（从 2×2 中心指向缺角的对角向量，如缺角在右下则 V=(+1,+1)）。
2. 灰(5)三连块：沿 V 方向平移 1 步生成副本，副本颜色为黄(4)。红(2)三连块：沿 -V 方向（远离缺角）平移 1 步生成副本，副本颜色为绿(3)。
3. 原始三连块保持不变。若副本与已有非背景像素重叠，副本像素覆盖已有像素。
4. 对每个副本，识别其 3 个像素中的两个端点像素（端点 = 在副本的 3 像素中仅与 1 个其他副本像素 4-邻接的像素）和一个肘部像素（与 2 个其他副本像素 4-邻接）。
5. 从每个端点像素出发，沿远离肘部的对角方向发射射线（即从端点指向肘部的向量取反后旋转 45 度朝外侧的对角方向；具体地：端点到肘部的正交向量有两个分量，射线方向是两个分量各取反后组合成的对角向量）。射线颜色与副本颜色相同。
6. 射线逐像素延伸，遇到非背景像素或网格边界时停止（停止位置不绘制）。
7. 绘制顺序：先绘制所有黄(4)副本及其射线，再绘制所有绿(3)副本及其射线。后绘制的覆盖先绘制的。同色副本之间按包围盒左上角行优先、列次优先的顺序绘制。
8. 所有原始三连块像素保持原色不变（即使被副本或射线覆盖，原件优先级最高——实际操作中，先绘制所有副本和射线，最后重绘所有原件像素）。

**关键洞察**：副本的射线方向不是简单地"从角点向外"——它取决于副本的 L 形朝向，而副本的朝向继承自原件但因平移方向不同可能产生非直觉的对角射线角度。需要对比多个不同朝向的三连块才能归纳出射线方向的计算规则。
