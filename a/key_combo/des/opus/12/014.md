## 新题 1：多面板折叠深度图

**组合逻辑**：[折叠/fold](从两面板扩展到 N 面板) + [透明叠加/transparent_overlay](叠加计数化) + [计数/counting](创新：统计像素重叠层数而非连通体数) + [重涂色/recolor](创新：深度值映射到颜色)

**来源原语**：fold/transparent_overlay（e3497940），counting（2753e76c），recolor（bb43febb/639f5a19）

**依赖链**：分隔线划定面板边界 → 所有面板向首面板折叠叠加 → 每个像素位置统计有多少面板贡献了前景 → 重叠层数映射为输出颜色。删除折叠则无法对齐像素；删除计数则无法区分重叠深度；删除颜色映射则输出不确定。

将 N 个等宽面板沿分隔线逐一折叠叠加到首面板，按每个像素被前景覆盖的面板数量映射为不同颜色，生成重叠深度图。

**输入结构**：黑(0)背景网格，约 5 行 x (4K+K-1) 列（K 为面板数，3 或 4），由 K-1 条贯穿全高的灰(5)分隔列将网格分成 K 个等宽面板。每个面板宽约 4 列，高约 5 行。每个面板上有若干前景像素，颜色统一为红(2)。不同面板的前景图案不完全相同但有部分重叠（折叠对齐后，部分像素位置被 1 个面板覆盖、部分被 2 个覆盖、部分被 3 个覆盖，等等）。生成约束：每种重叠层数（1 到 K）在输出中至少出现一次，以确保所有映射规则均可观测。面板从左到右依次编号为 1, 2, ..., K，奇数编号面板直接叠加，偶数编号面板水平镜像后叠加（模拟交替折叠）。

**规则**：
1. 移除所有灰(5)分隔列。
2. 以最左面板（面板 1）的坐标系为基准。面板 1 保持原样。对于面板 i（i >= 2）：若 i 为奇数，将该面板原样对齐到面板 1 的坐标系；若 i 为偶数，将该面板水平镜像后对齐到面板 1 的坐标系。
3. 对基准坐标系中的每个像素位置 (r, c)，统计有多少个面板在该位置有前景像素（即重叠层数 D）。
4. 按重叠层数 D 映射输出颜色：D=0 保持黑(0)；D=1 → 蓝(1)；D=2 → 红(2)；D=3 → 绿(3)；D=4 → 黄(4)。
5. 输出网格尺寸等于单个面板的尺寸。

**关键洞察**：输出不是任何单次折叠的结果，而是所有面板叠加后的"深度图"——同一位置被越多面板覆盖，输出颜色编号越高。偶数面板的镜像折叠意味着求解者必须理解交替翻转规则，而非简单平移对齐。

## 新题 2：引导条间隙双重角色——投射筛选与分段着色

**组合逻辑**：[压缩/compress + 投射到引导条/project_to_guide](已有) → [擦除/erase + 投射落间隙则擦/erase_if_gap](已有) → [计数/counting + 排序/sort](创新：对投射存活像素按色计数并排序) → [重涂色/recolor](创新：排序结果反向映射到引导条分段，再驱动像素重涂色)

**来源原语**：compress/erase/project_to_guide/erase_if_gap（f83cb3f6），counting/sort/sort_by_count_desc（2753e76c），recolor（bb43febb）

**依赖链**：间隙擦除改变各色存活数量 → 存活数量决定排序 → 排序结果分配到引导条连续段 → 各段颜色反向重涂存活像素。间隙同时参与擦除筛选和分段定义，两个角色耦合不可拆分。

将散布像素沿正交方向投射到引导条旁，被间隙拦截的像素被擦除；按各色存活数排序后，将排序颜色依次分配给引导条的连续段，每个存活像素重涂为其所在段的分配色。

**输入结构**：黑(0)背景网格，约 12x12。一条水平引导条位于网格中部（约第 6 行），由橙(7)像素组成，跨越大部分列但有 1-2 个间隙（间隙处为黑(0)）。引导条将网格分为上下两个区域。上下区域中散布着 3 种不同颜色的孤立前景像素（如蓝(1)、红(2)、绿(3)），每种颜色 3-6 个像素，随机分布。每个散布像素与引导条不同行。生成约束：(a) 每种颜色至少有 1 个像素的投射列落在间隙上（会被擦除），至少有 1 个落在引导条实体上（会存活）；(b) 三种颜色的存活像素数互不相同，以保证排序无歧义；(c) 引导条的间隙将引导条分成的连续段数恰好等于散布颜色种类数（即 3 段）。

**规则**：
1. 对每个散布像素，沿垂直方向投射到引导条所在行的紧邻位置（上方像素投射到引导条正上方一格，下方像素投射到引导条正下方一格），保持其水平列坐标不变。
2. 若该像素的列坐标处引导条为间隙（黑(0)），则该像素被擦除（不出现在输出中）。
3. 统计每种颜色的存活像素数（未被擦除的），按存活数从大到小排列颜色。
4. 引导条的连续段（被间隙分隔的橙(7)像素连续区间）从左到右编号为第 1、2、3 段。将排序后的颜色依次分配：存活数最多的颜色分配给第 1 段，次多分配给第 2 段，最少分配给第 3 段。
5. 输出中：(a) 引导条每一段的橙(7)像素全部替换为该段分配的颜色；(b) 每个存活像素重涂为其投射落点所在引导条段的分配颜色（而非其原色）；(c) 间隙位置保持黑(0)；(d) 其余位置保持黑(0)。

**关键洞察**：引导条的间隙承担双重角色——既决定哪些像素被擦除（影响计数），又划定引导条的分段边界（决定颜色分配的空间单元）。移动一个间隙的位置会同时改变存活数排序和分段结构，使结果发生非线性变化。

## 新题 3：空心框内部分模板的联合重建

**组合逻辑**：[含孔洞者选中/object_with_hole_selected](已有，但从单一选择扩展为多目标筛选) + [对齐合并取并集/align_merge_union](创新：对齐基准从边界框左上角改为框内空间的左上角) + [补全/completion](已有) + [印章覆盖/stamp](创新：用各框自身颜色印章)

**来源原语**：hollow_rectangle/enclosed_region/enclosure/object_with_hole_selected（b9b7f026），partial_pattern/template_mask/align_merge_union/copies_complement（f8cc533f），stamp（ad7e01d0）

**依赖链**：孔洞检测筛选出参与重建的框 → 从各框内部提取部分图案 → 部分图案左上对齐取并集得到完整模板 → 完整模板以各框颜色印章回各框内部。孔洞检测决定哪些框参与重建；部分图案的互补性决定模板能否完整恢复；模板完整性决定印章是否正确。

识别所有含背景孔洞的彩色空心矩形框，从各框内部提取部分精灵图案，联合对齐取并集重建完整模板，再以各框自身颜色将完整模板印章回每个框的内部。

**输入结构**：黑(0)背景网格，约 15x15。网格中散布 3-5 个单色矩形框，每个框的颜色不同（可选蓝(1)、红(2)、绿(3)、黄(4)、品红(6)）。每个框是完整的单像素厚矩形边框，内部尺寸至少 3x3。其中 3 个框是空心的（内部含有背景孔洞），另外 0-2 个框是实心填充的（框内无背景像素，完全由框颜色填满）。在每个空心框的内部，有一个灰(5)的部分图案——这些部分图案是同一个完整模板的不同部分。各部分图案在框内部空间中左上角对齐放置，每个部分图案包含完整模板的一个子集像素，任意两个部分图案不重叠（即完整模板的每个像素恰好出现在某一个空心框中）。生成约束：(a) 所有部分图案的并集恰好覆盖完整模板的每个像素（互补无遗漏）；(b) 完整模板是一个 4-连通的灰(5)图形，约 5-10 个像素，不规则形状（非简单矩形）；(c) 实心框（若存在）的尺寸和位置与空心框无特殊关系，仅作为干扰项。

**规则**：
1. 识别所有矩形框（单像素厚、完整闭合的矩形边框）。
2. 对每个框，检查其内部是否存在 4-连通的背景(0)区域且该区域不接触框外部背景——即判断是否为空心框。选取所有空心框，忽略实心框。
3. 从每个空心框中提取其内部的灰(5)像素图案。将该图案裁剪到框内部空间的坐标系（内部空间的左上角为原点）。
4. 将所有提取的部分图案在左上角对齐，逐像素取并集（OR），恢复完整模板。
5. 对每个空心框：将完整模板以该框的边框颜色（而非灰(5)）印章到框的内部空间中（左上角对齐），同时保持框的边框不变。原来内部空间中模板未覆盖的位置保持黑(0)。
6. 实心框保持不变。背景保持黑(0)。

**关键洞察**：没有任何一个框的内部包含完整模板——求解者必须发现各空心框中的灰色碎片是互补的，合并后才能恢复完整形状。重建后的模板并非以灰色输出，而是以各框自身的边框色着色，因此每个框的输出颜色不同但形状相同。

## 新题 4：周期瓦片补全后按象限标记数定向循环平移

**组合逻辑**：[补全/completion + 周期延拓/periodic_extension](已有) + [计数/counting](创新：从输入的占位符区域统计标记数) + [平移/shift](创新：按象限独立平移，方向由象限位置决定，步数由标记数决定)

**来源原语**：completion/periodic_extension/repeating_tile/placeholder_region（50a16a69），counting/singleton_marker（4852f2fa），shift（50a16a69），relative_position_determines_color/quadrant_border_layer（639f5a19）

**依赖链**：标记像素嵌于占位符区域中，补全操作会覆盖标记 → 必须先从输入读取标记计数 → 补全后按象限划分 → 各象限按其位置确定平移方向、按该象限的标记数确定平移步数。信息提取（计数）与信息销毁（补全覆盖）形成时序依赖。

先从占位符区域读取各象限的标记数，再用周期瓦片补全整个网格，然后按象限位置确定平移方向、按标记数确定平移步数，对各象限内的图案独立循环平移。

**输入结构**：黑(0)背景网格，约 12x12。左上角区域（约 4x4）由一个彩色瓦片重复铺满（瓦片使用蓝(1)、红(2)、绿(3)中的 2-3 种颜色，最小瓦片为 2x2 或 3x2）。网格其余区域（右侧列和/或底部行）填充为灰(5)占位符色，表示瓦片的延续尚未可见。在灰(5)占位符区域中，散布着若干橙(7)单像素标记，每个标记独立不相邻。生成约束：(a) 网格的行数和列数均为偶数，确保可被精确四等分为象限；(b) 最小瓦片的宽度和高度均整除网格的半宽和半高，确保补全后各象限内图案完整周期；(c) 四个象限中至少两个象限含有标记（标记数 >= 1），至少一个象限标记数为 0（该象限不平移，作为参照对比）；(d) 各含标记象限的标记数互不相同且均不超过瓦片周期长度（确保平移后图案发生可辨识变化但不退化为完整周期回到原位）。

**规则**：
1. 读取输入，记录每个橙(7)标记像素的位置。将网格分为四个等面积象限（上左、上右、下左、下右），统计每个象限中的橙(7)标记数 N_UL, N_UR, N_LL, N_LR。
2. 从左上角的非占位符区域推断最小重复瓦片。将该瓦片周期延拓到整个网格尺寸，覆盖所有灰(5)占位符和橙(7)标记位置，得到完整的周期图案。
3. 对补全后的网格，按象限独立执行循环平移：
   - 上左象限：向右循环平移 N_UL 列（每行内像素右移 N_UL 格，溢出右边界的像素回绕到该象限左边界）。
   - 上右象限：向下循环平移 N_UR 行（每列内像素下移 N_UR 格，溢出下边界的像素回绕到该象限上边界）。
   - 下左象限：向上循环平移 N_LL 行（每列内像素上移 N_LL 格，溢出上边界的像素回绕到该象限下边界）。
   - 下右象限：向左循环平移 N_LR 列（每行内像素左移 N_LR 格，溢出左边界的像素回绕到该象限右边界）。
4. N=0 的象限保持补全后的图案不变。
5. 输出网格尺寸与输入相同。

**关键洞察**：橙色标记嵌入在灰色占位符区域中，补全操作会将它们全部覆盖——求解者必须在"补全前"提取标记信息。标记的数量编码了平移步数，而标记所在的象限决定了平移方向。同一个标记像素同时编码"在哪个象限"（方向信息）和"计入哪个计数"（步数信息）。

## 新题 5：镜像拼接后按内部与边框分层负片映射

**组合逻辑**：[镜像/mirror + 拼接/concatenate + 接触边界定轴/touching_border_determines_axis](已有) + [负片色映射/negative_color_remap](创新：不对全部像素做负片，仅对矩形内部做负片) + [内部与边框/interior_vs_border](创新：从单色重涂色改为控制负片映射的作用域)

**来源原语**：mirror/concatenate/touching_border_determines_axis/negative_color_remap（6f473927），interior_vs_border/only_interior_recolored（bb43febb），filled_rectangle（bb43febb）

**依赖链**：矩形接触的网格边界决定镜像轴和拼接方向 → 镜像生成反转副本 → 在反转副本中，矩形的"内部"执行负片映射而"边框"保持原色 → 内部与边框的划分取决于矩形的几何结构。镜像方向和负片作用域的耦合使得改变矩形位置会同时影响两个规则的结果。

将含有多个实心矩形的网格沿矩形所触的网格边界镜像拼接；在镜像侧，每个矩形的单像素边框保持原色，而内部像素执行前景/背景互换的负片映射。

**输入结构**：黑(0)背景网格，约 8x10。网格中有 2-3 个不同颜色的实心矩形（如蓝(1)、红(2)、绿(3)），每个矩形至少 3x3 像素。所有矩形均接触网格的同一条边界（如所有矩形的最左列均在网格第 0 列，即接触左边界），但矩形之间在垂直方向互不重叠、互不相邻（至少间隔 1 行黑色背景）。生成约束：(a) 所有矩形接触同一条垂直边界（左或右）；(b) 每个矩形的高和宽均 >= 3，保证存在非空内部区域；(c) 矩形之间不接触不重叠。

**规则**：
1. 确定所有矩形共同接触的网格边界（左边界或右边界）。
2. 将整个输入网格沿该边界做水平镜像，生成一个镜像副本。
3. 拼接方式：若接触左边界，镜像副本放在左侧、原始网格放在右侧；若接触右边界，原始网格放在左侧、镜像副本放在右侧。输出宽度为输入宽度的两倍，高度不变。
4. 在原始侧（非镜像侧），所有像素保持不变。
5. 在镜像侧，对每个矩形的像素进行分层处理：
   - 边框像素（矩形最外一圈像素）：保持该矩形的原始颜色不变。
   - 内部像素（矩形边框以内的所有像素）：执行负片映射——原来的矩形颜色变为黑(0)，原来的黑(0)背景变为青(8)。由于输入中矩形是实心的，其内部全为前景色，所以镜像侧的矩形内部全部变为黑(0)。
6. 镜像侧中不属于任何矩形的背景像素（原来为黑(0)）变为青(8)。

**关键洞察**：镜像侧并非简单的全局负片——每个矩形的边框在镜像侧保留原色（充当彩色画框），而框内执行负片后变为全黑，与周围的青色背景形成反差。求解者必须同时理解"哪些像素属于边框、哪些属于内部"和"负片映射仅作用于内部"两条交织的规则。

## 新题 6：重复出现精灵体的选取与缺角三角形定位印章

**组合逻辑**：[裁剪/crop + 出现两次者选取/twice_pattern_selected](已有) + [缺角定位/missing_corner_loc + 忽略干扰项/ignore_distractors](已有) + [像素放大/pixel_upscale](已有) + [连线/draw_line](创新：画线区域与放大印章共享空间，需要冲突解决)

**来源原语**：crop/twice_pattern_selected（f5aa3634），missing_corner_loc/ignore_distractors/right_triangle/bounding_square/marker_pixel（1478ab18），pixel_upscale/stamp（ad7e01d0），draw_line（1478ab18）

**依赖链**：精灵体比对选出唯一重复的模板 → 标记像素分析定位缺角 → 缺角位置决定放大印章的放置点和三角形连线方向 → 印章与连线在空间上重叠时，印章覆盖连线。四个环节环环相扣：选模板需要裁剪比较，定位置需要几何分析，放大需要知道模板，冲突解决需要知道两者的空间范围。

从多个精灵体中选取唯一出现两次的裁剪图案，在灰色标记方块的缺角位置放置 2 倍放大的印章，并画出缺角处的直角三角形两条轴对齐边。

**输入结构**：黑(0)背景网格，约 18x18。网格中有：(a) 5-7 个多色 4-连通精灵体，每个精灵体由 3-6 个非黑非灰像素组成（可使用蓝(1)、红(2)、绿(3)、黄(4)、品红(6)、橙(7)），精灵体之间互不相邻、互不接触。其中恰好有一个精灵体的裁剪图案（边界框裁剪，含内部背景像素）出现了两次（两个实例位置不同但裁剪后逐像素相同），其余精灵体的裁剪图案均唯一。(b) 4 个灰(5)单像素标记，其中 3 个位于一个轴对齐正方形的三个角上，第 4 个位于该正方形内部（干扰项）。该正方形的边长至少为 6（以容纳 2 倍放大的精灵体）。生成约束：(a) 两个重复精灵体实例的位置与灰色标记方块不重叠；(b) 灰色标记方块的缺角位置有足够空间放置 2 倍放大后的精灵体（放大后的边界框不超出网格范围）；(c) 正方形内部的干扰标记不在任何角的位置。

**规则**：
1. 将每个 4-连通前景精灵体（非灰(5)像素）裁剪到其最小边界框（保留边界框内的黑(0)背景像素作为图案的一部分）。
2. 比较所有裁剪图案，找出恰好出现两次的唯一图案。该图案即为选中模板。
3. 识别 4 个灰(5)标记像素。计算它们的最小边界正方形。找到该正方形四个角中唯一没有灰(5)标记的角——即缺角。正方形内部的灰(5)像素是干扰项，不参与角的判定。
4. 将选中模板进行 2 倍像素放大（每个像素变为 2x2 的同色块）。
5. 将放大后的模板印章到输出网格中，其左上角对齐到缺角位置。
6. 以青(8)画两条轴对齐的线段，分别从缺角沿水平方向和垂直方向延伸到与缺角相邻的两个灰(5)角标记位置（含端点处的标记位置）。这两条线段构成以缺角为直角顶点的直角三角形的两条直角边。
7. 冲突解决：放大印章的像素覆盖青(8)连线像素（印章优先）。
8. 所有灰(5)标记像素（包括干扰项）在输出中保持灰(5)不变。其余背景保持黑(0)。

**关键洞察**：三套独立的几何分析——精灵体裁剪比对（选什么）、标记方块缺角检测（放哪里）、轴对齐连线（画什么边界）——各自不可省略且共同决定最终输出。正方形内部的第四个灰色标记是干扰项，它既不是角也不影响缺角判定，但会干扰初步的几何分析。
