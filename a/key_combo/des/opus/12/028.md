## 新题 1：阶梯碰撞围合填色

**组合逻辑**：[连线/阶梯图案] → [碰撞终止（创新）] → [洪泛填充/封闭区域] → [边界归属决定填色（创新）]

**来源原语**：连线/阶梯图案/点对称/步长固定（d06dbe63），洪泛填充/封闭区域/拓扑内外/仅填封闭内部（00d62c1b）

**依赖链**：多锚点各自生成点对称阶梯臂，阶梯臂在网格中碰撞截断，碰撞后形成的闭合拓扑结构是洪泛填充的前提；每个封闭区域的填色取决于哪个锚点的阶梯构成了该区域的多数边界——这一归属条件是阶梯碰撞的涌现结果，不可独立于阶梯生成过程求解。

将多个锚点的阶梯臂延伸至碰撞截断，再按边界归属关系填充由碰撞产生的封闭区域。

**输入结构**：黑(0)背景，约 15x15 网格。网格内有 2~4 个锚点像素，每个锚点使用一种互不相同的非黑颜色（如青(8)、红(2)、蓝(1)等）。每个锚点距离网格边缘至少 3 格，任意两个锚点之间至少相隔 5 格。生成约束：锚点的放置保证不同锚点的阶梯臂会在网格内相交碰撞，从而形成至少 1 个被阶梯边界完全围合的黑(0)封闭区域。

**规则**：
1. 从每个锚点生成两条灰(5)阶梯臂，步长固定为 2：臂 A 先向上画 2 像素再向右画 2 像素，如此交替延伸；臂 B 先向下画 2 像素再向左画 2 像素，如此交替延伸。两条臂关于锚点构成点对称。
2. 每条阶梯臂逐像素延伸。当下一个待绘制像素的位置已被其他锚点的阶梯占据（灰(5)且不属于自身锚点），或超出网格边界时，该臂停止延伸，最后一个冲突像素不绘制。若待绘制位置被自身锚点的另一条臂占据，正常覆盖并继续延伸。
3. 所有锚点像素保留原色不变。
4. 识别封闭区域：阶梯绘制完成后，对所有黑(0)像素做 4-连通分析。与网格边界连通的黑(0)区域为外部，不做处理；不与网格边界连通的黑(0)连通分量为封闭区域。
5. 对每个封闭区域，统计其 4-邻接灰(5)边界像素中，属于各锚点阶梯的像素数量（每个灰(5)像素在绘制时归属于生成它的锚点）。将该封闭区域填充为贡献边界像素最多的那个锚点的颜色。若两个锚点贡献相同数量的边界像素，选择行坐标更小（更靠上）的锚点的颜色。

**关键洞察**：阶梯生成本身是确定性的几何扩展，但多阶梯碰撞截断后形成哪些封闭区域、每个区域的边界归属分布如何，都是碰撞的涌现结果——求解者必须先模拟碰撞过程才能确定填色。

## 新题 2：象限标记的方向条纹填充

**组合逻辑**：[对角映射/标记块→象限区域]（颜色选择） + [交替填色/条纹]（图案生成） + [象限几何→条纹方向（创新）]

**来源原语**：填充/标记块/象限区域/对角映射/标记色填对角区（93b581b8），交替填色/条纹/阵列排布/奇偶决定颜色（db3e9e38），平铺/种子像素/种子定条纹周期（0a938d79）

**依赖链**：2x2 标记块通过对角映射指定每个象限的颜色（源自 93b581b8），但填充方式不是实心色块，而是交替条纹（源自 db3e9e38/0a938d79）。条纹方向由象限区域自身的宽高比决定——这是一个在源题中不存在的新条件，将标记块的颜色指派与象限的几何属性交织在一起。

2x2 标记块通过对角映射指派各象限颜色，但每个象限以交替条纹方式填充，条纹方向由该象限自身的宽高比决定。

**输入结构**：黑(0)背景，网格尺寸至少 10x10（行数与列数不必相等）。网格内有且仅有一个 2x2 前景块，四个像素使用四种互不相同的非黑颜色（如左上红(2)、右上蓝(1)、左下黄(4)、右下绿(3)）。2x2 块不在网格的精确几何中心，其上下左右各至少有 3 行/列的空间。生成约束：网格的行数和列数不相等，且 2x2 块的位置使得四个象限区域中至少有一个宽>高、至少有一个高>宽。

**规则**：
1. 保留 2x2 标记块不变。
2. 标记块将网格分为四个象限区域（标记块本身不属于任何象限）。每个标记像素通过对角映射指定对面象限的填充颜色：左上像素→右下象限，右上像素→左下象限，左下像素→右上象限，右下像素→左上象限。
3. 对每个象限区域，计算其宽度（列数）和高度（行数）：
   - 若宽度 > 高度：绘制水平交替条纹。从该象限最靠近标记块的那一行开始，第一行填指定颜色，第二行填黑(0)，第三行填指定颜色，依此交替，直到象限边界（被网格边缘裁剪）。
   - 若高度 > 宽度：绘制垂直交替条纹。从该象限最靠近标记块的那一列开始，第一列填指定颜色，第二列填黑(0)，第三列填指定颜色，依此交替。
   - 若宽度 == 高度：整个象限实心填充指定颜色（不使用条纹）。
4. 条纹仅覆盖象限内的像素，不侵入标记块或其他象限。

**关键洞察**：同一个 2x2 标记块既编码颜色分配（对角映射），又间接决定各象限的几何形状（标记块的偏心位置造成各象限宽高比不同）。颜色规则和方向规则必须同时正确才能得到正确输出，而方向规则需要对比多个不同标记位置的示例才能归纳。

## 新题 3：遮挡碎片重建后按尺寸嵌套、按层序染色

**组合逻辑**：[补全/遮挡碎片→完整环形精灵] → [遮挡层序分析] + [面积递减嵌套]（双排序交叉赋色，创新）

**来源原语**：堆叠/补全/空心矩形精灵/遮挡碎片/遮挡层序/可见像素定边框/忽略干扰项（652646ff），排序/嵌套/前景矩形/面积递减嵌套/角落对齐嵌套（6cbe9eb8）

**依赖链**：首先从重叠碎片中重建每个完整的空心矩形精灵并推断遮挡层序（源自 652646ff）；然后按尺寸从大到小嵌套排列（源自 6cbe9eb8），但每个嵌套层位的颜色不由尺寸序决定，而由遮挡序决定——遮挡最顶层的颜色分配给最外层嵌套位、遮挡最底层的颜色分配给最内层嵌套位。尺寸序和遮挡序是两个独立排序，任意删去一个都无法确定输出。

从遮挡碎片重建多个不同尺寸的空心矩形精灵，按尺寸嵌套排列，但每层颜色按遮挡优先级重新分配。

**输入结构**：黑(0)背景，约 20x20 网格。3~4 个空心矩形精灵（矩形轮廓线，线宽 1 像素），尺寸各不相同（如 4x4、6x6、8x8 的外边界框），各使用一种互不相同的非黑颜色。精灵在网格中部分重叠放置，使得部分轮廓线像素被其他精灵的像素遮挡。某些精灵可能被网格边缘裁剪。可能存在 1~2 个小于 3 像素的孤立干扰像素，颜色不属于任何精灵。生成约束：尺寸从大到小的排列顺序与遮挡从顶到底的排列顺序不一致（即最大的精灵不一定是最顶层的）。

**规则**：
1. 忽略像素数少于 3 的孤立分量（干扰项）。
2. 对每种有效颜色，根据其可见像素的位置推断该空心矩形精灵的完整边界框尺寸和位置。若某个模板像素位置被其他颜色占据，说明该颜色的精灵在此处被遮挡，占据位置的颜色层级更高。
3. 根据遮挡关系进行拓扑排序，得到从顶层到底层的遮挡序列。
4. 根据完整边界框面积（宽x高）从大到小排序，得到尺寸序列。
5. 构建输出画布，尺寸等于最大精灵的边界框。按尺寸从大到小依次绘制空心矩形轮廓线，每个矩形的左下角与前一个矩形内部区域的左下角对齐（第一个即最大的矩形占据画布全部范围）。
6. 颜色分配：尺寸序列中第 k 大的嵌套位使用遮挡序列中第 k 层（从顶层计起）的颜色。即最外层嵌套位用遮挡最顶层精灵的颜色，最内层嵌套位用遮挡最底层精灵的颜色。
7. 最内层矩形的内部区域（矩形轮廓线围合的空间）保持黑(0)不填充。

**关键洞察**：输出的空间布局由尺寸序决定，输出的颜色布局由遮挡序决定——两者是独立维度。求解者必须同时正确推断这两个排序，才能得到正确的颜色-位置映射。

## 新题 4：连接色链驱动的归一化精灵对接

**组合逻辑**：[连接点颜色匹配→链式排序（创新）] → [归一化到固定尺寸] → [对接拼合/连接方向决定组装方向（创新）]

**来源原语**：缩放/圆角边框/内部图案/归一化到固定尺寸/对角放置（db118e2a），对接拼合/裁剪/精灵体/连接点/对接对齐/连接点颜色匹配（20270e3b）

**依赖链**：每个精灵的连接点颜色匹配另一个精灵的边框颜色，形成有向链（源自 20270e3b 的颜色匹配，但扩展为多节点链）。所有精灵先归一化到统一尺寸（源自 db118e2a），归一化后连接点的相对边缘位置保留，决定组装方向。链序和方向缺一不可——链序决定谁接谁，边缘方向决定往哪边接。

按连接色匹配形成精灵链，归一化所有精灵到固定尺寸后，沿链序依据连接点边缘方向逐个对接组装。

**输入结构**：黑(0)背景，约 20x20 网格。3~4 个精灵，每个被一个圆角矩形边框包围（四个角像素为背景色，其余外边框像素为边框色）。各精灵的边框颜色互不相同（如红(2)、蓝(1)、绿(3)等），内部图案由 1~3 种非背景非边框色像素组成，各精灵内部图案不同。边框尺寸各不相同（如 5x5、7x7、9x9）。每个精灵的边框上恰好有一个像素被替换为"连接色"，该连接色与该精灵自身的边框色不同，也与其内部图案颜色不同。连接色位于边框的上、下、左、右四条边之一的中间位置。生成约束：连接色形成单链——精灵 A 的连接色等于精灵 B 的边框色，精灵 B 的连接色等于精灵 C 的边框色，以此类推。恰好有一个精灵的边框色不被任何其他精灵的连接色引用（链头），恰好有一个精灵的连接色不匹配任何边框色（链尾，该连接色使用灰(5)作为终止标记）。

**规则**：
1. 通过颜色匹配确定链序：从链头（边框色不被任何连接色引用的精灵）开始，沿"当前精灵的连接色 = 下一个精灵的边框色"的关系依次排列。
2. 对每个精灵进行归一化：裁剪边框内部图案至其紧凑边界框，将其居中放入 3x3 区域（空余位置填黑(0)），外围绘制圆角 5x5 边框（保持原边框色，四角为黑(0)）。
3. 归一化后，连接点保留在 5x5 边框上：若原连接点在上边中间，则归一化后位于第 0 行第 2 列；若在右边中间，则第 2 行第 4 列；若在下边中间，则第 4 行第 2 列；若在左边中间，则第 2 行第 0 列。
4. 从链头开始组装：将链头精灵放置在画布上。对链中每个后续精灵，将其放置在前一个精灵的连接点所指方向的相邻位置（连接点在右边→后续精灵紧贴右侧，连接点在下边→后续精灵紧贴下方，以此类推）。两个相邻精灵的边框共享一行/列像素（重叠的边框像素使用后放置的精灵的边框色）。
5. 组装完成后，所有连接点像素被重涂为其所属精灵的边框色（连接点消失）。
6. 输出为组装结构的紧凑裁剪。

**关键洞察**：归一化将不同尺寸的精灵统一为 5x5，使得对接在视觉上呈规则网格状，但组装路径可以转弯（因为不同精灵的连接点可能在不同边）。求解者必须同时发现颜色链规则（决定顺序）和连接点边缘规则（决定方向），两者共同决定输出的空间布局。

## 新题 5：差异位移后的镜像配对筛选

**组合逻辑**：[平移/移动自身高度]（位置重排） → [镜像对称检测/镜像配对则涂色（创新：从像素级扩展到矩形级）] → [擦除未配对项]

**来源原语**：平移/实心矩形/无重叠间距/移动自身高度（5521c0d9），重涂色/前景掩膜/镜像对称/镜像配对则涂色（ce039d91），擦除（d35bdbdc）

**依赖链**：每个矩形按自身高度向上位移（源自 5521c0d9），不同矩形位移量不同，导致位移后的空间布局与输入完全不同。镜像配对检测在位移后的布局上进行（源自 ce039d91 的镜像对称概念，但从单像素扩展为整个矩形对象）。配对结果决定哪些保留哪些擦除——整条推理链中，位移改变了检测的几何前提，检测结果决定了擦除目标。

各矩形按自身高度上移后，检测关于网格竖直中线的矩形级镜像对称，保留配对矩形（涂蓝）并擦除未配对矩形。

**输入结构**：黑(0)背景，约 15x20 网格（高大于宽），列数为偶数。网格中有 4~6 个单色实心矩形，每个矩形使用一种互不相同的非黑颜色，高度和宽度各不相同（高度范围 1~4 像素，宽度范围 2~5 像素）。每个矩形的正上方恰好有等于其自身高度的空行（保证上移不会越界或碰撞）。生成约束：上移后至少有一对矩形关于网格竖直中线构成镜像对称（同高同宽，左右边界框关于中线对称），且至少有一个矩形上移后找不到镜像伙伴。

**规则**：
1. 将每个矩形从原位置向上平移，平移距离等于该矩形自身的高度（新的下边缘恰好在原上边缘所在的行）。清除原位置。
2. 平移完成后，以网格竖直中线（列 W/2 - 0.5，W 为网格列数）为对称轴，检测矩形级镜像对：两个矩形构成镜像对当且仅当——(a) 两者高度相同且宽度相同；(b) 一个矩形的边界框是另一个边界框关于竖直中线的水平镜像。
3. 属于镜像对的两个矩形均重涂为蓝(1)。
4. 不属于任何镜像对的矩形被擦除（设为黑(0)）。

**关键洞察**：每个矩形的上移量等于其自身高度，因此高度不同的矩形位移量不同。输入中看似对称的两个矩形，若高度不同则上移后错开对称位置；输入中不对称的两个矩形，若高度恰好使它们上移后对齐中线对称位置，则成为配对。求解者必须先模拟差异化位移，再在新布局上做对称分析。

## 新题 6：路径弯折数决定精灵旋转角度

**组合逻辑**：[路径连通/端点决定目标]（定位目标精灵） + [颜色查找键]（匹配源精灵） + [路径拓扑→旋转角度（创新）] → [重涂色/擦除]

**来源原语**：重涂色/擦除/精灵体/路径网络/路径连通/颜色查找键/端点决定目标（d35bdbdc），旋转/印章覆盖/颜色一致对齐/稀疏像素引导放置（0e206a2e）

**依赖链**：灰色路径的端点确定"目标精灵"（源自 d35bdbdc），目标精灵的中心色作为查找键匹配源精灵的边框色（源自 d35bdbdc）。但源精灵不是简单地传递颜色，而是整体旋转后覆盖目标精灵的位置——旋转角度由路径的弯折次数决定（创新条件），这将路径的几何拓扑与精灵变换紧密耦合。

灰色路径端点定位目标精灵，中心色匹配源精灵后，源精灵按路径弯折数旋转并替换目标精灵。

**输入结构**：黑(0)背景，约 15x15 网格。一条灰(5)路径网络：单像素宽的 4-连通路径（无分叉、无环路），连接两个不同的端点。4~6 个小精灵分布在网格各处，不与路径或彼此重叠。每个精灵为 3x3，边框 8 像素为同一颜色，中心 1 像素为另一种颜色（边框色和中心色在所有精灵间互不重复）。恰好有 2 个精灵是"目标精灵"：其边框像素的某个像素与灰色路径的某个端点 4-邻接。其余精灵为"源精灵"，不与路径邻接。生成约束：每个目标精灵的中心色恰好等于某个源精灵的边框色（颜色查找关系成立）。路径包含 0~3 个 90 度弯折。

**规则**：
1. 识别两个目标精灵：边框像素与灰色路径端点 4-邻接的精灵。
2. 对每个目标精灵，取其中心像素的颜色作为查找键，找到边框颜色等于该键值的源精灵。
3. 计算灰色路径从一个端点到另一个端点之间的 90 度方向变化次数（弯折数）。路径沿 4-连通逐像素行走，每次行进方向改变 90 度计为一次弯折（180 度掉头计为两次弯折）。
4. 将匹配到的源精灵顺时针旋转 (弯折数 x 90) 度（对 360 取模）。
5. 将旋转后的源精灵放置在对应目标精灵的位置，完全替换目标精灵的 3x3 区域。两个目标精灵使用同一个弯折数（因为路径只有一条）。
6. 擦除所有未被匹配使用的源精灵（设为黑(0)）。保留灰色路径和替换后的两个目标精灵。

**关键洞察**：路径具有双重功能——其端点定位目标精灵（连通条件），其弯折几何决定旋转变换量（拓扑条件）。颜色查找建立源-目标配对，但正确的旋转量只能从路径形状推断。求解者必须同时追踪路径拓扑和颜色映射。

## 新题 7：线条围墙分区与宽高比驱动的条纹填充

**组合逻辑**：[洪泛填充/边界连通分内外]（拓扑分区） + [封闭区域几何分析→条纹参数（创新）] + [交替填色/条纹]（条件化图案生成）

**来源原语**：洪泛填充/重涂色/线条对象/封闭区域/画布边界/内外分区/边界连通分内外（7b6016b9），交替填色/条纹/阵列排布/奇偶决定颜色（db3e9e38），展开/金字塔/中心对称展开（db3e9e38）

**依赖链**：线条对象将网格分为外部和多个封闭区域（源自 7b6016b9 的内外分区），外部统一涂绿(3)。但封闭区域不再简单涂红——每个封闭区域的填充方式由其自身边界框的宽高比决定（创新条件），不同形状的封闭区域获得不同方向的条纹。条纹生成（源自 db3e9e38）的参数直接来自分区的几何结果。

线条对象做围墙分区后，外部涂绿，每个封闭区域根据自身宽高比选择条纹方向进行交替填色。

**输入结构**：黑(0)背景，约 15x15 网格。一个由单色非黑像素（如橙(7)）组成的 4-连通线条对象，在网格中形成闭合或半闭合形状，将网格分隔为若干区域。线条对象至少围成 2 个形状各异的封闭区域（一个宽>高，一个高>宽）。线条像素不接触网格边缘的区域形成封闭内部，接触边缘的区域与外部连通。黑(0)像素出现在线条内外两侧。生成约束：各封闭区域的边界框宽高比互不完全相同，至少涵盖宽>高和高>宽两种情况。

**规则**：
1. 保留橙(7)线条对象所有像素不变。
2. 从网格四条边缘向内做 4-连通洪泛：与网格边界连通的所有黑(0)像素为外部区域，重涂为绿(3)。
3. 剩余黑(0)连通分量（4-连通，不与边界连通）为封闭区域。
4. 对每个封闭区域，计算其最小包围边界框的宽度 W 和高度 H：
   - W > H（横向区域）：绘制水平交替条纹。从该区域边界框的最上行开始，第一行填红(2)，第二行填黄(4)，第三行填红(2)，依此交替。仅区域内部的像素被填色（条纹在区域边界处裁剪），线条像素和区域外像素不受影响。
   - H > W（纵向区域）：绘制垂直交替条纹。从该区域边界框的最左列开始，第一列填红(2)，第二列填黄(4)，依此交替。同样仅填区域内像素。
   - W == H（正方形区域）：整个区域实心填充红(2)。
5. 条纹的行/列编号以该区域边界框左上角为基准，与全局坐标无关。

**关键洞察**：同一条线条结构可以围出形状迥异的多个封闭区域，每个区域的条纹方向取决于自身几何形状而非全局设定。求解者先靠拓扑分析找到封闭区域，再靠几何分析确定每个区域的填充方式——两步推理缺一不可，且第二步的参数是第一步结果的涌现属性。

## 新题 8：种子条纹的奇偶镜像拼接

**组合逻辑**：[平铺/种子像素→条纹生成]（半幅填充） + [镜像/拼接/画布加倍]（另半幅生成） + [种子间距奇偶→镜像是否反色（创新隐蔽规则）]

**来源原语**：平铺/种子像素/条纹/阵列排布/种子定条纹周期（0a938d79），镜像/拼接/整幅画布/轴对称/画布加倍（c9e6f938），奇偶决定颜色（db3e9e38）

**依赖链**：两个种子像素在网格左半区定义一个竖直条纹图案（源自 0a938d79），条纹仅填充左半区。右半区通过水平镜像生成（源自 c9e6f938 的画布加倍）。但镜像是否反转两种条纹颜色取决于种子间水平距离的奇偶性（创新：将 db3e9e38 的奇偶决定颜色概念应用于镜像行为）。这一隐蔽规则只有对比种子间距为偶数和奇数的多个示例才能发现。

左半区根据种子像素生成竖直条纹，右半区为左半区的水平镜像，但种子水平间距的奇偶性决定镜像时是否交换两种条纹颜色。

**输入结构**：黑(0)背景，网格行数约 10~14，列数为偶数（约 16~22）。网格中恰好有两个非黑像素（种子像素），颜色互不相同且互不为黑（如红(2)和蓝(1)）。两个种子均位于网格左半区（列索引 < W/2，W 为列数）。两个种子在不同行、不同列。两个种子均不位于网格的左右侧边缘（即列索引不为 0 也不为 W/2-1），因此按 0a938d79 的规则生成竖直全高条纹。生成约束：不同示例中种子的水平距离有时为偶数、有时为奇数，以便求解者归纳奇偶规则。

**规则**：
1. 计算两个种子的水平间距 d = |col_A - col_B|。
2. 在网格左半区（列 0 至 W/2-1）生成竖直条纹：分别在种子 A 和种子 B 所在列绘制全高的竖直色条（种子 A 的颜色填满 A 所在列，种子 B 的颜色填满 B 所在列）。以步幅 2d 沿水平方向重复这两列色条（即在 col_A + 2d, col_A + 4d... 和 col_B + 2d, col_B + 4d... 处复制），向左同理（col_A - 2d... 和 col_B - 2d...）。超出左半区范围（列 < 0 或列 >= W/2）的条不绘制。
3. 生成右半区：
   - 若 d 为偶数：右半区是左半区的简单水平镜像（每行的列 W/2 到 W-1 对应左半区列 W/2-1 到 0 的像素，颜色不变）。
   - 若 d 为奇数：右半区是左半区的水平镜像，但同时交换两种种子颜色（左半区中种子 A 颜色的像素在右半区变为种子 B 的颜色，反之亦然；黑(0)保持不变）。
4. 种子像素本身作为条纹的一部分被正常处理（不额外保留或标记）。

**关键洞察**：种子间距同时控制两个层面——条纹的空间周期（2d）和镜像的色彩行为（是否反色）。同一个几何参数的不同属性（数值大小 vs 奇偶性）分别影响不同的操作环节。这一耦合是隐蔽的：仅看一个示例无法区分"总是保色镜像"和"总是反色镜像"，必须对比奇偶不同的多个示例。
