## 新题 1：面积仲裁的光环扩展与核心标记

**组合逻辑**：[邻域扩展](已有) + [面积比较](创新：从筛选语境改为冲突仲裁语境) + [重涂色](创新：从象限着色改为核心/光环区分标记) + [冲突优先级](已有)

**来源原语**：邻域扩展、仅填背景格、光环区域(dc1df850)；连通分量、面积比较、保留最大连通分量(1f85a75f)；重涂色(77fdfe62)；冲突优先级(d6542281)

**依赖链**：连通分量分析确定每个对象的像素集合 → 邻域扩展产生光环区域 → 光环重叠处需要面积比较来仲裁归属 → 仲裁完成后才能确定哪些是原始核心像素、哪些是光环像素 → 核心像素重涂色为灰(5)。删除任一步骤都无法得到正确输出：无面积比较则重叠区域归属不确定；无重涂色则无法区分核心与光环；无邻域扩展则无光环可言。

在黑(0)背景上，多个不同颜色的小型前景对象各自向外扩展一圈光环；当光环交叠时，面积更大的对象赢得争议像素；扩展完成后，每个对象的原始像素被标记为灰色以区分核心与光环。

**输入结构**：黑(0)背景网格，约 14x14。网格上散布 3~5 个互不相邻的单色 4-连通前景对象，每个对象使用不同的颜色（从蓝(1)、红(2)、绿(3)、黄(4)、橙(7)中选取），每个对象由 3~8 个像素组成，形状为不规则的 4-连通单色图形（非矩形，各示例中同色对象的具体形状不同）。不同对象之间的最近距离在 2~4 个像素之间，保证部分光环会重叠但对象本身不相邻。生成约束：任意两个对象的像素面积互不相等，以确保面积仲裁无歧义。

**规则**：
1. 识别所有 4-连通单色前景对象，记录每个对象的像素集合与像素面积。
2. 对每个对象的每个像素，将其 Chebyshev 距离 1 邻域（3x3 区域）中的所有黑(0)背景格标记为该对象的候选光环格。
3. 若某背景格同时被两个或多个对象标记为候选光环格，则该格归属于像素面积最大的那个对象，涂上该对象的颜色。
4. 无争议的候选光环格直接涂上对应对象的颜色。
5. 所有光环确定后，将每个对象的原始核心像素（非光环像素）重涂为灰(5)。

**关键洞察**：面积比较在源题(1f85a75f)中用于筛选保留哪个分量，但在本题中转变为空间冲突的仲裁依据——面积不再决定"谁被保留"，而是决定"谁占领争议领土"。求解者必须同时追踪对象面积和光环几何才能确定每个重叠像素的归属。

## 新题 2：象限编码翻转方式的递归印章

**组合逻辑**：[递归印章 + 格位映射](已有) + [所属象限](创新：从区域填充选择器变为翻转类型编码器) + [镜像/翻转对应](创新：从固定模板翻转变为由控制像素位置动态选择的翻转)

**来源原语**：递归印章、控制像素、格位映射、输入图案(cce03e0d/ad7e01d0)；所属象限、控制像素(87ab05b8)；镜像、翻转对应(cfb2ce5a/00576224)

**依赖链**：控制像素的位置同时编码两个信息——它在哪个格位（决定输出中的哪个块）以及它在输入的哪个象限（决定该块内的图案如何翻转）。格位映射和象限归属是对同一个像素坐标的两种读取方式，二者缺一不可：缺格位映射则不知道印在哪里，缺象限归属则不知道印什么方向。

红(2)控制像素的位置同时决定在输出的哪个块印章、以及印章的翻转方式——落在输入左上象限则原样印，右上则水平翻转印，左下则垂直翻转印，右下则双轴翻转印。

**输入结构**：一个偶数边长的小网格（4x4 或 6x6），黑(0)背景上有一个由非红色前景像素（如蓝(1)、绿(3)等混合）构成的不对称图案，以及若干红(2)控制像素散布在图案内部或空白区域。红(2)像素不超过 4 个。网格行列数相等且为偶数，保证能均分为四个象限。生成约束：图案本身不具有水平或垂直对称性（否则翻转无法区分）；至少有两个红(2)像素落在不同象限中。

**规则**：
1. 将输入网格视为源图案（红(2)像素也是图案的一部分）。
2. 构造输出网格：每个输入像素对应输出中一个与输入同尺寸的块，输出总尺寸为（输入行数 x 输入行数）行 x（输入列数 x 输入列数）列。
3. 将输入均分为四个象限：左上（行 < H/2 且列 < W/2）、右上（行 < H/2 且列 >= W/2）、左下（行 >= H/2 且列 < W/2）、右下（行 >= H/2 且列 >= W/2）。
4. 对每个红(2)控制像素，根据其所属象限确定翻转方式：左上象限 → 不翻转；右上象限 → 水平翻转（左右镜像）；左下象限 → 垂直翻转（上下镜像）；右下象限 → 水平+垂直翻转（等价 180 度旋转）。
5. 将经过相应翻转的完整输入图案印入该控制像素对应的输出块中。
6. 非红(2)的输入像素对应的输出块全部填充黑(0)。

**关键洞察**：控制像素的坐标被同时用于两个独立用途——整数格位索引选定输出块位置，而同一坐标的象限归属选定翻转变换。求解者若只注意到递归印章的放置逻辑而忽略象限编码的翻转规则，将无法解释不同块中图案方向的差异。

## 新题 3：角点推断几何框架与外部计数参数化内部填充

**组合逻辑**：[角点定义正方形 + 已知角点推断中心](已有) + [计数 + 计数映射尺寸](创新：计数结果不再定义独立矩形尺寸，而是参数化另一几何结构的内部填充) + [区域填充](创新：填充区域由推断出的几何框架界定，填充尺寸由外部计数决定)

**来源原语**：角点标记、已知角点推断中心、对角线位置、缩小复制(11e1fe23)；计数、计数映射尺寸、标记像素(878187ab)；区域填充(87ab05b8)

**依赖链**：三个角点 → 推断第四角点和正方形边界（几何框架）；散布标记 → 分色计数（参数提取）；正方形边界 + 计数值 → 内部填充矩形的行列尺寸。几何推断和计数是两条独立推理线，但它们在"填充"步骤汇合——删除角点推断则无边界可填，删除计数则不知填多大。

三个角点像素定义一个正方形的几何边界，网格中另有两种颜色的散布标记像素；两种标记的各自数量决定正方形内部填充矩形的高和宽。

**输入结构**：黑(0)背景网格，约 18x18。三个不同颜色的单像素角点标记（从红(2)、绿(3)、蓝(1)中选取）分别位于某个轴对齐正方形的三个角上（第四角缺失），正方形边长在 8~12 之间。网格上另有两种颜色的散布标记像素：黄(4)和橙(7)，各自的像素数量在 2~6 之间且互不相等，这些标记像素不在正方形内部也不在正方形边上。生成约束：正方形足够大以容纳由两个计数值定义的填充矩形；三个角点不共线。

**规则**：
1. 从三个角点标记推断出缺失的第四个角点位置和正方形的完整边界。
2. 分别计数黄(4)标记像素和橙(7)标记像素的数量。
3. 在正方形内部（不含边界）填充一个灰(5)实心矩形：矩形高度 = 较小的计数值，矩形宽度 = 较大的计数值，矩形左下角对齐正方形内部的左下角。
4. 将缺失的第四角点位置涂上灰(5)。
5. 在正方形的几何中心（行列坐标均取两对角角点的中点）涂上品红(6)。
6. 保留原有的三个角点标记和所有散布标记像素不变。

**关键洞察**：输入中有两组完全独立的信息源——角点像素编码几何结构，散布标记编码数值参数——二者必须同时正确解读后在填充步骤合流。单看角点无法确定填充尺寸，单看计数无法确定填充位置。

## 新题 4：同心嵌套深度作为模板查表键

**组合逻辑**：[同心嵌套 + 严格内嵌](已有) + [计数](创新：计数对象从像素变为嵌套层数) + [查表映射 + 编码映射 + 固定模板](创新：查表键从主色身份变为几何深度值)

**来源原语**：同心嵌套、严格内嵌、矩形框、内部矩形、外围层(3a301edc)；计数(878187ab/8e301a54)；查表映射、固定模板、编码映射(9110e3c5)

**依赖链**：识别同心矩形框 → 计算嵌套层数 → 层数作为键查表 → 输出对应模板。如果不先正确识别同心结构就无法计数层数；如果不知道查表规则就无法从层数得到输出。此外最内层帧的偏心方向附加影响输出模板的朝向，使得嵌套几何分析和模板选择之间产生更深的耦合。

多层同心矩形框的嵌套深度编码一个离散类别，通过查表映射为一个固定 3x3 模板输出；最内层帧的偏心方向决定模板的朝向。

**输入结构**：黑(0)背景网格，约 15x15。网格中心区域有一组同心矩形框，每层框用不同颜色绘制（从蓝(1)、红(2)、绿(3)、黄(4)、橙(7)中按从外到内的顺序选取），每层框是宽度为 1 像素的矩形环。嵌套层数在 2~4 之间。最内层框的内部为黑(0)。最内层框不一定严格居中于次外层——它可能在水平或垂直方向上偏移 1 个像素（偏左、偏右、偏上或偏下）。生成约束：每层框严格内嵌于上一层框内部；相邻两层框之间至少间隔 1 行 1 列的黑(0)空间。

**规则**：
1. 识别所有同心矩形框层，计算嵌套层数 N。
2. 查表确定基础模板（3x3 黑(0)网格上的青(8)模板）：
   - N=2 → 青(8)填充左列（第 0 列三个格），即竖条模板；
   - N=3 → 青(8)填充中间行（第 1 行三个格），即横条模板；
   - N=4 → 青(8)填充主对角线（(0,0)、(1,1)、(2,2)三个格），即对角线模板。
3. 检测最内层框相对于次外层框的偏心方向：
   - 若最内层框水平居中且垂直居中 → 模板不旋转；
   - 若偏右 → 模板顺时针旋转 90 度；
   - 若偏下 → 模板旋转 180 度；
   - 若偏左 → 模板逆时针旋转 90 度（即顺时针 270 度）；
   - 若偏上 → 模板不旋转（与居中相同处理）。
4. 输出旋转后的 3x3 模板。

**关键洞察**：嵌套深度是一个从几何拓扑中抽取的离散量，功能等价于源题(9110e3c5)中的"主色类别"——都是从噪杂输入中提炼出的紧凑分类符号，但编码方式从颜色身份变为空间结构深度。偏心方向作为第二信号轴进一步约束输出，使得仅靠层数查表不够，还需分析空间对称性。

## 新题 5：噪声过滤提取印章模板并按锚点颜色匹配放置

**组合逻辑**：[保留最大连通分量 + 裁剪](创新：裁剪结果不是最终输出，而是后续印章操作的模板) + [印章放置 + 锚点标记 + 颜色匹配](创新：模板不预设于输入的独立区域，而是从过滤步骤动态提取) + [擦除 + 干扰项忽略](已有)

**来源原语**：连通分量、面积比较、保留最大连通分量、裁剪、噪声像素(1f85a75f)；印章放置、锚点标记、颜色匹配、最少色为锚点(a251c730)；擦除、干扰项忽略(87ab05b8)；仅填背景格(dc1df850)

**依赖链**：噪声过滤（识别并丢弃小分量）→ 提取最大分量作为模板（裁剪其边界框）→ 在锚点位置印章。过滤步骤的结果直接决定印章的内容——如果错误地保留了噪声或丢弃了信号，印章模板就会出错，所有后续印章位置的输出都会连锁出错。

从噪声前景中过滤出唯一的大型连通分量作为印章模板，然后在网格中散布的锚点标记位置印上该模板。

**输入结构**：黑(0)背景网格，约 18x18。网格上有一个较大的 4-连通单色前景对象（蓝(1)，8~15 像素，形状为不规则连通图形），以及若干噪声像素（红(2)或绿(3)，每个噪声分量仅 1~2 像素，总共 3~6 个噪声像素，随机散布）。另外有 1~3 个品红(6)单像素锚点标记，散布在网格的其他位置，与所有前景对象不相邻。锚点标记之间、以及锚点与大型对象之间的距离足够大，保证以锚点为中心放置模板后各副本之间不重叠。生成约束：蓝(1)对象是唯一面积 >= 3 的前景连通分量。

**规则**：
1. 识别所有 4-连通单色前景连通分量（忽略颜色差异，每个分量内部单色）。
2. 计算每个分量的面积。面积 <= 2 的分量视为噪声，擦除为黑(0)。
3. 面积最大的分量是信号对象。裁剪其紧凑边界框，得到一个小矩形模板（保留内部的黑(0)背景孔洞）。
4. 擦除信号对象在原始网格中的位置（涂为黑(0)）。
5. 对每个品红(6)锚点标记，将模板印章到网格上，使模板的几何中心（边界框中心，向下向右取整）与锚点位置对齐。印章时仅覆盖黑(0)背景格，不覆盖其他锚点标记。
6. 印章的颜色使用信号对象的原始颜色（蓝(1)）。品红(6)锚点标记在印章完成后保留不变。

**关键洞察**：源题(a251c730)的印章模板是输入中预设的独立区域，而本题中模板必须通过噪声过滤和裁剪从混杂的前景中"发现"——模板提取和印章放置形成紧密的上下游依赖，过滤阈值的判断直接影响印章内容。

## 新题 6：调色板行缺口定中心的瓦片阵列与逐列着色

**组合逻辑**：[平铺 + 阵列排布 + 瓦片](已有) + [以缺口为中心](创新：缺口从楔形展开的中心轴变为瓦片阵列的对齐锚点) + [重涂色](创新：调色板行既是颜色图例又是空间定位依据) + [调色板行](已有)

**来源原语**：平铺、阵列排布、瓦片(00576224)；调色板行、以缺口为中心、标记竖条(bae5c565)；重涂色(77fdfe62/cfb2ce5a)

**依赖链**：调色板行中的缺口位置 → 决定瓦片阵列的水平中心对齐列；调色板行中各格的颜色 → 决定该列所有瓦片的重涂色。缺口同时承载空间锚定和颜色例外（保持原色）两个语义。瓦片的几何排布和颜色分配被调色板行这一单一结构同时约束，二者无法独立求解。

**规则**：
1. 提取调色板行（第 0 行）和灰(5)瓦片图案（第 1 行以下的灰(5)连通块的紧凑边界框）。
2. 确定缺口列（调色板行中唯一的黑(0)格所在列）。
3. 在第 1 行以下的区域构建瓦片阵列：以缺口列为中心向两侧铺设瓦片列，每个瓦片列的宽度等于瓦片宽度，纵向从第 1 行开始向下重复铺设直到网格底部。
4. 若某瓦片列完全超出网格左右边界则不绘制。
5. 对每个瓦片列，取其中心列（若瓦片宽度为偶数则取左半的最右列）对应的调色板行颜色，将该瓦片列中所有灰(5)像素重涂为该颜色。
6. 中心列（缺口列）对应的瓦片列保持灰(5)不重涂。
7. 调色板行本身保持不变。

**关键洞察**：调色板行的缺口在源题(bae5c565)中是楔形展开的中心轴，在本题中变为瓦片阵列的对齐锚点——同一个"缺口"概念的空间角色完全改变。同时，调色板行中每个格的颜色不再是被逐行展开复制的对象，而是作为查表图例为对应列瓦片着色，使得一行信息同时编码位置和颜色两个维度。

## 新题 7：跨尺度形状匹配提取比例因子驱动第三对象的滑动

**组合逻辑**：[形状匹配 + 跨尺度同形](已有) + [滑动 + 超界裁剪](创新：位移量不再是对象自身面积，而是从另一对对象间提取的缩放比例) + [擦除 + 干扰项忽略](已有)

**来源原语**：形状匹配、跨尺度同形、缩放对象、干扰对象、返回较小者(ce602527)；滑动、面积决定位移、超界裁剪(8e301a54)；擦除(87ab05b8)

**依赖链**：跨尺度形状匹配 → 识别配对并提取缩放因子 K；配对中较小者的边界框高度 H → 位移量 = K x H；第三对象（干扰项）按此位移量向下滑动并裁剪超界部分。形状匹配的结果（K 值）直接参数化滑动操作，二者不可分离：不做匹配就不知道 K，不知道 K 就无法计算位移。

在三个前景对象中找到跨尺度同形的一对，提取其缩放因子；用该因子乘以较小匹配对象的高度作为第三个对象的下滑距离。

**输入结构**：黑(0)背景网格，约 16x16。网格上有三个不同颜色的 4-连通单色前景对象（从蓝(1)、红(2)、绿(3)、黄(4)、品红(6)中选取三种），每个对象占 4~20 像素，形状为不规则连通图形。其中恰好两个对象具有相同形状但不同尺寸（一个是另一个的 2 倍或 3 倍缩放），第三个对象形状独特不与任何其他对象匹配。三个对象互不相邻，间距至少 2 像素。缩放后的较大对象可能被网格边界裁剪（仅部分可见）。生成约束：两个匹配对象之间的缩放因子恰好为 2 或 3（整数倍）；第三个对象的形状不是前两个形状的任何整数缩放。

**规则**：
1. 对每对前景对象尝试缩放匹配：将较小者的掩码放大 2 倍和 3 倍，检查是否与较大者的掩码一致（允许较大者被网格边界裁剪，仅比较网格内部分）。
2. 找到匹配对后，记录缩放因子 K（2 或 3）和较小匹配对象的边界框高度 H。
3. 擦除两个匹配对象（涂为黑(0)），保留第三个对象（"干扰项"在此题中反转为操作目标）。
4. 将第三个对象整体向下滑动 K x H 行，保持列坐标不变。超出网格底部的像素裁剪丢弃。
5. 清除第三个对象的原始位置（涂为黑(0)）。

**关键洞察**：源题(ce602527)中"干扰项"被丢弃而匹配对的较小者被保留输出，本题反转了这一角色——匹配对被丢弃，"干扰项"反而成为唯一的操作对象。更关键的是，匹配对虽被擦除，但从它们中提取的缩放因子仍然影响干扰项的运动，形成"消失的信息源仍在驱动变换"的结构。

## 新题 8：帧内象限掩码密度驱动方向性同心扩展

**组合逻辑**：[裁剪 + 角标色定象限涂色](已有) + [计数](创新：计数对象从标记像素变为各象限中的掩码像素密度) + [同心扩展](创新：扩展不再由内矩形尺寸决定，而是由掩码密度最高象限的方向决定，且仅向该方向单侧扩展)

**来源原语**：裁剪、边框、象限、角标像素、角标色定象限涂色(77fdfe62)；计数(878187ab/8e301a54)；同心扩展、内尺寸定扩展量、外围层(3a301edc)

**依赖链**：帧裁剪 → 象限划分并按角标色重涂 → 计算每个象限的掩码像素数 → 密度最高的象限决定扩展方向 → 以帧为核心向该方向做单侧同心扩展。象限涂色的中间结果（各象限的颜色分布）是计数步骤的输入，计数的结果又驱动几何扩展——三步形成不可跳过的推理链。

一个带角标的矩形帧内部的掩码按象限重涂后，掩码像素最密集的象限决定帧向外扩展的唯一方向。

**输入结构**：黑(0)背景网格，约 18x18。网格中有一个灰(5)矩形帧（宽度 1 像素的矩形环，内外边长差 2），帧的四个对角方向外侧各有一个单像素角标（四个角标颜色各不相同，从蓝(1)、红(2)、绿(3)、黄(4)中选取）。帧内部在黑(0)背景上有若干橙(7)掩码像素，分布不均匀——某一个象限的掩码像素明显多于其他三个象限。帧足够大（内部至少 8x8）以使四个象限的掩码密度差异明确。生成约束：恰好有一个象限的掩码像素数严格最多（无并列）；帧与网格边界之间在扩展方向上至少有 3 行或 3 列的空间。

**规则**：
1. 识别灰(5)矩形帧，裁剪其内部矩形区域（不含帧本身）。
2. 将内部矩形均分为四个象限（左上、右上、左下、右下）。若行列数为奇数则中间行/列归属左上象限。
3. 将每个象限中的橙(7)掩码像素重涂为该象限对应角标的颜色（左上角标色、右上角标色、左下角标色、右下角标色）。
4. 计算四个象限各自的掩码像素数量，找到密度最高的象限（称为主象限）。
5. 确定主象限相对于帧中心的方向（例如主象限为右下 → 方向为向右且向下）。
6. 以帧的外边界为起点，仅在主象限方向上添加一层同心扩展：
   - 若主象限在右侧（右上或右下）：在帧右侧外部添加一列，高度等于帧外边界高度，颜色为主象限的角标色。
   - 若主象限在下方（左下或右下）：在帧下方外部添加一行，宽度等于帧外边界宽度，颜色为主象限的角标色。
   - 若主象限在角落（如右下），则同时向右添加一列和向下添加一行，交汇角格也填充该色。
   - 同理处理左上（向左+向上）、右上（向右+向上）、左下（向左+向下）方向。
7. 帧本身、角标像素和重涂后的内部掩码保持不变。

**关键洞察**：同心扩展在源题(3a301edc)中是对称的四方向均匀扩展，其尺寸由内矩形几何确定。在本题中扩展变为非对称的单方向扩展，且驱动方向不来自几何属性，而来自统计属性（象限掩码密度）。象限重涂步骤看似仅是着色，实则是为密度比较创建分组依据——不做重涂分组就无法正确计数各象限的像素。

## 新题 9：连通分量面积决定平移距离后按印章覆盖规则叠放

**组合逻辑**：[面积决定位移 + 滑动](已有) + [印章覆盖 + 冲突优先级](创新：优先级不由颜色重叠度决定，而由面积排名决定——面积小的对象后绘制并覆盖面积大的) + [仅填背景格](创新：从"仅填空白"反转为"面积小者可覆盖大者")

**来源原语**：连通分量、面积决定位移、超界裁剪(8e301a54)；滑动、平移(8e301a54/5521c0d9)；印章覆盖、冲突优先级(d6542281)；仅填背景格(dc1df850)

**依赖链**：面积计算 → 确定每个对象的位移距离 → 位移后多个对象可能重叠 → 面积排名决定绘制顺序（面积大的先绘制，面积小的后绘制并覆盖）。位移距离和冲突解决都依赖于同一个属性（面积），但用法不同：面积越大移动越远（容易离开画面），面积越小覆盖优先级越高（即使被大对象路径经过也不被遮挡）。

每个前景对象向右平移自身面积个像素，重叠时面积较小的对象绘制在最上层。

**输入结构**：黑(0)背景网格，约 16x20（宽大于高，为向右平移留出空间）。网格左半部分有 3~5 个互不相邻的单色 4-连通前景对象，颜色各不相同（从蓝(1)、红(2)、绿(3)、黄(4)、橙(7)中选取），每个对象 2~7 像素，形状为不规则连通图形。不同对象的面积互不相等。对象初始分布在网格左侧 1/3 区域内，保证平移后有足够空间。生成约束：至少有两个对象在平移后的纵向范围有重叠（即它们的行范围有交集），以确保产生覆盖冲突。

**规则**：
1. 识别所有 4-连通单色前景连通分量，记录每个分量的像素集合和面积 A。
2. 清空画布为黑(0)。
3. 对所有分量按面积从大到小排序。
4. 按排序顺序（面积最大的先绘制）依次将每个分量绘制到画布上：每个分量中的每个像素向右平移 A 列（A 为该分量自身的面积），保持行不变。超出网格右边界的像素裁剪丢弃。
5. 后绘制的分量（面积较小的）覆盖先绘制的分量（面积较大的）在同一格的像素。

**关键洞察**：面积在本题中承担双重角色——既是位移量又是优先级排序键，且两个角色产生对抗效应：面积大的对象移动得远（可能移出画面或让出中间空间），面积小的对象移动得近但绘制在最上层。求解者必须意识到面积的双重含义才能正确预测重叠区域的最终颜色。

## 新题 10：瓦片阵列中基于字形查表结果的选择性镜像

**组合逻辑**：[平铺 + 中间行翻转](创新：翻转行不固定为中间行，而是由查表匹配结果动态决定) + [查表匹配 + 对齐判定结果](创新：判定结果不再是底部色带的颜色，而是控制瓦片阵列中哪些行/列的瓦片被镜像) + [镜像](已有)

**来源原语**：平铺、瓦片、阵列排布、中间行翻转(00576224)；查表匹配、字形单元格、参考表、查询行、对齐判定结果、完整行列对齐(d8e07eb2)；镜像(cfb2ce5a/00576224)

**依赖链**：查表匹配确定哪些表格单元格被命中 → 命中的单元格所在行/列索引集合 → 在瓦片阵列中，这些索引对应的瓦片行/列使用镜像版本的瓦片，其余行/列使用原始瓦片。查表结果和平铺的耦合是通过索引映射实现的——改变查表结果直接改变瓦片阵列的对称结构。

一个小瓦片被铺成阵列，但哪些行的瓦片需要左右镜像取决于另一个查表匹配结构的命中行号。

**输入结构**：黑(0)背景网格，分为上下两个区域，由一条完整的品红(6)水平分隔行隔开。上方区域约 10 行高，包含一个参考查表结构：青(8)背景上有一行 3~4 个字形单元格（每个字形在 3x3 的单元格内用某种前景色绘制一个简单图案），下方紧跟一个 3~4 行 x 3~4 列的参考表，每格也是 3x3 字形单元格。上方区域的最上一行是查询行（含 3~4 个字形）。下方区域约 8~10 行高，左侧有一个 2x2 的小瓦片图案（由两种颜色如红(2)和绿(3)组成，不对称），右侧为空白。生成约束：瓦片不具有水平对称性；查询字形至少有一个能在参考表中匹配到。

**规则**：
1. 在上方区域执行查表匹配：将查询行中的每个字形与参考表中的所有字形比较（匹配条件：颜色和 3x3 形状完全一致）。
2. 记录所有命中的参考表单元格的行索引（参考表内部的行号，从 0 开始）。
3. 在下方区域，用 2x2 瓦片构建一个瓦片阵列，填满分隔行以下的整个区域（行列方向尽可能铺满，不足一个瓦片的边缘不铺）。
4. 对瓦片阵列中的每一瓦片行（从 0 开始编号）：若该行号出现在步骤 2 的命中行索引集合中，则该行的所有瓦片使用原始瓦片的水平镜像版本；否则使用原始瓦片。
5. 上方区域（含分隔行）保持不变。

**关键洞察**：源题(00576224)中镜像行固定为"中间行"，源题(d8e07eb2)中查表结果只控制底部色带颜色。本题中查表结果通过行索引映射动态选定了平铺阵列中哪些行发生镜像——两个原本毫无关联的操作（字形查表与瓦片翻转）通过"行索引"这个抽象接口耦合在一起，产生了源题中均不存在的结构关系。
