## 新题 1：去遮挡还原对称后洪泛填充涌现孔洞

**组合逻辑**：[擦除](去除遮挡矩形) → [对称补全](还原被遮挡的镜像对称形状) → [洪泛填充](创新：填充因补全而涌现的封闭孔洞，颜色由面积奇偶决定)

**来源原语**：擦除+遮挡+填充矩形+对称补全+去遮挡后镜像还原（3345333e）；洪泛填充+封闭区域+包含+面积奇偶定填充色（868de0fa）

**依赖链**：遮挡矩形被擦除后暴露出不完整的对称体 → 对称补全恢复缺失像素 → 补全后的完整形状才在内部围成封闭区域 → 封闭区域的面积奇偶决定填充颜色。孔洞在补全之前不存在，面积在补全完成前无法计算——三步环环相扣。

从含遮挡的不完整对称体中去除遮挡、补全对称、然后按面积奇偶填充因补全而涌现的内部孔洞。

**输入结构**：约 15x15 的黑(0)背景网格。包含一个蓝(1)单色 4-连通对象，该对象具有左右镜像对称性，在对称完整时其内部围成一个或多个黑(0)背景孔洞（4-连通封闭区域）。一个灰(5)填充矩形（实心连通分量，边界框为矩形且完全填满）与蓝(1)对象部分重叠，遮挡了对称体的若干像素（被遮挡的像素在输入中显示为灰(5)而非蓝(1)）。灰(5)矩形不完全覆盖对称体，至少一侧的对称信息完好。生成约束：对称体完整时至少围成 1 个孔洞；遮挡矩形必须遮盖与孔洞围合相关的像素，使得不补全对称就无法确认孔洞存在。

**规则**：
1. 检测灰(5)填充矩形分量（唯一的灰色实心矩形连通分量），将其所有像素擦除为黑(0)。
2. 以蓝(1)像素为对象，检测其左右镜像对称轴（竖直轴，x 坐标为蓝色像素水平范围的中点）。沿对称轴将所有现有蓝(1)像素镜像到对侧；若对侧为黑(0)则填蓝(1)，若已为蓝(1)则不变。
3. 补全完成后，检测所有 4-连通的黑(0)封闭区域——即完全被蓝(1)像素包围、不与网格边界相连的黑(0)连通分量。
4. 对每个封闭区域计算像素面积：面积为偶数则填充为红(2)，面积为奇数则填充为橙(7)。
5. 蓝(1)对象像素和外部黑(0)背景保持不变。

**关键洞察**：封闭孔洞是对称补全的涌现产物——输入中因遮挡而不存在完整围合，只有擦除遮挡并补全对称后孔洞才显现。面积奇偶规则需要对比多个示例（不同大小的孔洞）才能归纳。

## 新题 2：双面板背景交集生成种子，种子自相似印章扩展

**组合逻辑**：[透明叠加](双面板背景交集) → [印章覆盖](创新：交集结果既是印章内容又是放置掩码，实现自相似扩展)

**来源原语**：透明叠加+面板+分隔行+位置对齐+双面板背景交集（0c9aba6e）；印章覆盖+种子精灵+像素到块映射+前景位放自身副本（5b6cbef5）

**依赖链**：两面板的背景交集运算产生一个二值种子图案 → 该种子图案同时充当印章内容和放置掩码 → 前景位放置种子自身的完整副本，背景位留空。种子图案的每个像素都依赖于两个面板的对应位置，而种子的双重角色使得叠加结果在两个尺度上自相似地传播。

将两个面板的背景交集作为自相似种子，按前景位置印章扩展。

**输入结构**：约 (2N+1) 行 x M 列的黑(0)背景网格（N 在 3~5 之间，M 在 3~5 之间）。正中间有一行完整的品红(6)分隔行。分隔行上方为上面板（N 行），包含若干绿(3)前景像素散布于黑(0)背景上。分隔行下方为下面板（N 行），包含若干蓝(1)前景像素散布于黑(0)背景上。两面板尺寸相同（均为 N x M）。生成约束：两面板的背景交集（两面板对应位置均为黑(0)的集合）形成一个含 2~4 个前景像素的非空图案。

**规则**：
1. 移除品红(6)分隔行，将上面板和下面板按位置对齐。
2. 对每个位置 (r, c)：若上面板 (r, c) 为黑(0) 且下面板 (r, c) 也为黑(0)，则标记为青(8)前景；否则标记为黑(0)背景。得到一个 N x M 的二值"种子图案"。
3. 创建输出网格，尺寸为 (N*N) x (M*M)，划分为 N x M 个块，每块大小 N x M。
4. 对种子图案中的每个青(8)前景像素 (i, j)，将整个种子图案复制粘贴到输出的第 (i, j) 号块中（块内坐标与种子坐标一一对应）。
5. 对种子图案中的每个黑(0)背景像素 (i, j)，对应输出块保持全黑(0)。

**关键洞察**：种子并非直接给出，而是从两面板的背景交集中推导——这不是前景叠加而是"双空"判定。种子的双重角色（内容 = 掩码）使得仅从一个示例看到的输出难以反推是自相似扩展还是其他放大方式，需对比多组不同面板产生不同种子来确认。

## 新题 3：颜色编码位移后碰撞涌现交叉点，交叉点触发环形标记

**组合逻辑**：[平移](颜色决定偏移) → [交叉检测](创新：位移后碰撞涌现交叉点，源题中不存在碰撞概念) → [描边](交叉邻域环涂色)

**来源原语**：平移+前景像素+颜色编码位移+颜色决定偏移（342dd610）；描边+全行条+全列条+交叉点+交叉邻域环涂色（67a423a3）

**依赖链**：每个像素的颜色编码其位移方向 → 所有像素同时位移 → 位移后两个或更多像素落在同一格时涌现"交叉点" → 交叉点触发 3x3 黄色环标记。交叉点是位移的涌现结果，源题中完全不存在：342dd610 没有碰撞概念，67a423a3 的交叉来自整行整列而非像素碰撞。

按颜色编码的方向位移所有像素，在位移后发生碰撞的位置画黄色环形标记。

**输入结构**：约 12x12 的黑(0)背景网格。散布约 6~10 个前景像素，颜色为橙(7)、红(2)、栗(9)、蓝(1)中的若干种（不要求四种全出现）。没有两个像素占据同一格。网格足够大，使得所有位移后的像素在大多数情况下仍在网格内。生成约束：位移后至少存在 1 个碰撞（两个或更多像素落入同一格），且至少存在 1 个未碰撞的像素，以便求解者区分碰撞与非碰撞行为。

**规则**：
1. 清空网格为全黑(0)。
2. 对每个前景像素按颜色编码位移：橙(7)向上移 2 格，红(2)向左移 2 格，栗(9)向下移 2 格，蓝(1)向右移 1 格。
3. 位移后落在网格外的像素丢弃。
4. 若某格恰好有一个像素落入（无碰撞），将该格涂为该像素的原始颜色。
5. 若某格有两个或更多像素落入（碰撞），该格为"交叉点"，涂为绿(3)。
6. 对每个交叉点，将其 8-邻域的 8 个格涂为黄(4)。
7. 优先级（高到低）：绿(3)交叉点 > 非碰撞像素原色 > 黄(4)环 > 黑(0)背景。即：交叉点不被环覆盖；非碰撞像素不被邻近的黄色环覆盖；环像素之间不冲突（都是黄色）。

**关键洞察**：交叉点纯粹是位移后的涌现——无法直接从输入读出，必须模拟全部位移才能知道哪些格发生碰撞。环标记是碰撞的可见信号。位移规则需要对比多个示例中不同颜色像素的前后位置才能归纳。

## 新题 4：高度极值条保留并反相打孔

**组合逻辑**：[排序](高度排名) → [擦除+重涂色](创新：保留极值并分色) → [擦除](创新：交替打孔的起始相位由高度排名决定——最高从顶端开始，最矮从底端开始)

**来源原语**：排序+竖直线段+高度排名+保留极值高度分色（a61f2674）；擦除+矩形+中心线+交替+中线交替打孔（3bdb4ada）

**依赖链**：高度排名决定哪些条存活 → 存活条的排名（最高 vs 最矮）决定重涂色 → 排名同时决定打孔的起始相位（最高从顶、最矮从底）。排名不仅筛选对象，还控制操作参数——这种"排名→操作参数"的耦合在两道源题中均不存在。

按高度保留最高和最矮的竖条，分别蓝红重涂，并以相反的起始端交替打孔。

**输入结构**：约 15x20 的黑(0)背景网格。包含 5~7 根灰(5)竖条（每根宽 1 像素），各自位于不同列，高度互不相同且均为奇数（>= 5 像素）。竖条互不相邻（列间距 >= 2）。竖条顶端不一定齐平。生成约束：最高和最矮的竖条高度唯一（无并列）。

**规则**：
1. 将所有灰(5)竖条按高度排名，从最高到最矮。
2. 擦除所有非最高、非最矮的竖条为黑(0)。
3. 将最高的竖条重涂为蓝(1)，最矮的竖条重涂为红(2)。
4. 对蓝(1)竖条（最高）：从竖条最顶行开始，按"保留-擦除-保留-擦除-..."的节奏处理每个像素。即第 0 个像素（最顶）保留蓝(1)，第 1 个擦除为黑(0)，第 2 个保留，依此类推（0-索引自竖条顶端）。
5. 对红(2)竖条（最矮）：从竖条最底行开始，按"保留-擦除-保留-擦除-..."的节奏处理每个像素。即第 0 个像素（最底）保留红(2)，第 1 个（倒数第二）擦除为黑(0)，第 2 个保留，依此类推（0-索引自竖条底端）。
6. 所有其他像素保持黑(0)。

**关键洞察**：打孔的起始相位与高度排名绑定——最高条从顶端起保留，最矮条从底端起保留，形成视觉上的"一上一下"反相节奏。这一相位规则在任一源题中都不存在，需要对比多个示例（其中最高和最矮条在不同位置、不同高度）才能区分"从顶开始"与"从底开始"的映射规则。

## 新题 5：同色物体滑向匹配墙壁后紧凑排列涌现孔洞，孔洞触发重涂与描边

**组合逻辑**：[滑动](同色墙壁吸引，碰撞阻挡) → [洪泛填充](创新：孔洞不是预设的而是滑动紧凑排列后涌现的) → [重涂色](有孔触发重涂) → [描边](对最终构型绘制轮廓)

**来源原语**：滑动+墙壁列+前景物体+同色物体朝同色墙+近者优先不重叠+碰撞停止（f0100645）；洪泛填充+封闭区域+包含+面积奇偶定填充色（868de0fa）；重涂色+封闭孔洞+有孔触发重涂（aa4ec2a5）；描边+draw_outline（aa4ec2a5）

**依赖链**：物体按距离顺序滑向匹配墙壁并碰撞停止 → 紧凑排列后不规则形状之间涌现背景孔洞 → 孔洞存在性触发参与围合的物体重涂 → 孔洞被填充 → 最终构型被描边。孔洞在输入中不存在，是滑动紧凑排列的涌现效果。

将不规则物体滑向同色墙壁紧凑排列，检测排列涌现的封闭孔洞，重涂围合物体并描边。

**输入结构**：约 15x15 的灰(5)背景网格。最左列全部填蓝(1)为左墙壁，最右列全部填红(2)为右墙壁。内部散布若干蓝(1)的 8-连通小物体（每个 3~6 像素，非矩形不规则形状）和若干红(2)的 8-连通小物体（同规格）。物体互不相邻，与墙壁不相邻。生成约束：至少一侧墙壁的物体滑动紧凑排列后会形成至少 1 个 4-连通灰(5)封闭区域（被墙壁和/或物体完全围合的背景区域）。

**规则**：
1. 清除所有内部（非墙壁列的）非背景像素为灰(5)。
2. 对蓝(1)物体，按其 8-连通边界框中心到左墙壁的水平距离从近到远排序处理：将每个物体水平向左平移，直到物体任一像素的左邻为墙壁像素或已安置的同色物体像素，停止。保持物体形状不变。
3. 对红(2)物体，按其到右墙壁距离从近到远排序处理，类似向右平移直到碰墙壁或已安置同色物体。
4. 所有物体安置完毕后，检测内部所有 4-连通灰(5)背景区域。若某灰色区域不与网格边界（除墙壁列外的边界行/列）相连，则为"封闭孔洞"。
5. 将每个封闭孔洞填充为品红(6)。
6. 将所有 4-邻接于任何封闭孔洞的物体像素重涂为青(8)（不论原为蓝或红）。未邻接孔洞的物体像素保持原色。
7. 对每个最终的非背景连通簇（包括墙壁、物体、青色像素、品红孔洞），绘制 1 像素宽的黄(4)描边：将簇的 8-邻域中属于灰(5)背景的像素涂为黄(4)。若描边像素与另一簇的描边重叠，保持黄(4)。描边不覆盖非背景像素。

**关键洞察**：孔洞是滑动紧凑排列的涌现产物——同一组物体放在不同初始位置可能产生完全不同的孔洞（甚至没有孔洞）。必须先模拟完整的滑动过程才能判断哪些物体参与围合并被重涂。

## 新题 6：边缘条重叠区域过滤参与标记推进的竖条集合

**组合逻辑**：[填充](创新：列投影重叠区域定义空间过滤器) → [擦除](区域外竖条移除) → [重涂色](创新：标记仅在过滤后的竖条集合中按尺寸排序推进)

**来源原语**：填充+边缘线段+分隔行+列投影重叠+较长侧优先（770cc55f）；重涂色+竖条+标记段+尺寸排序+半段位置保持（48634b99）；擦除（3bdb4ada）

**依赖链**：顶底边缘条的列重叠确定活跃区域 → 较长侧填充黄色 → 重叠区域外的竖条被擦除 → 标记段仅在剩余竖条中按高度排序推进到下一根更高的竖条。空间约束（重叠区域）与排序逻辑（尺寸推进）交叉耦合——两者单独都无法确定输出。

根据顶底边缘条的列重叠区域过滤竖条，再在区域内竖条中按高度推进标记。

**输入结构**：约 12x20 的黑(0)背景网格。第 0 行（顶行）有一段连续绿(3)水平条。最后一行（底行）有一段连续绿(3)水平条。两段长度不同，位置有部分列重叠。网格中某个内部行是一整行红(2)分隔行（全宽）。分隔行与顶行之间分布若干蓝(1)竖条（宽 1 像素），高度互不相同且均为偶数（如 4, 6, 8, 10 像素），底端对齐在分隔行上方。其中一根竖条的上半段被涂为黄(4)——即该竖条从顶端到中点为黄(4)，从中点以下到底端为蓝(1)——这是标记段。生成约束：被标记的竖条和高度恰好比它大 2 的那根竖条都位于重叠列区域内；至少一根竖条位于重叠区域之外。

**规则**：
1. 计算顶行绿(3)条和底行绿(3)条各自占据的列集合，取交集得到"重叠列集合"。
2. 判断哪根边缘条更长。在重叠列集合中，在较长侧填充黄(4)：若顶行条更长，则对重叠列的每一列，从顶行下方第一行到分隔行上方第一行填黄(4)；若底行条更长，则从分隔行下方第一行到底行上方第一行填黄(4)。黄色填充不覆盖已有的蓝(1)竖条像素和标记像素。
3. 检查每根蓝(1)竖条（不含标记段的黄色部分）的列位置：若该列不在重叠列集合内，则擦除该竖条为黑(0)。
4. 在剩余的竖条中，找到当前被标记的竖条（含黄(4)上半段的那根）。记录其总高度 H 和标记位于上半段这一事实。
5. 将被标记竖条恢复为全蓝(1)（清除黄色标记）。
6. 在剩余竖条中找到总高度恰好为 H+2 的那根竖条。将该竖条的上半段重涂为黄(4)（保持半段位置一致）。
7. 顶底边缘条、分隔行保持不变。

**关键洞察**：边缘条重叠区域是一个空间过滤器，决定了标记推进链中哪些竖条有资格参与。若无此过滤，标记会推进到区域外的竖条上，产生不同结果。需要对比多组示例才能辨别"重叠过滤"与"所有竖条都参与"这两种可能假说。

## 新题 7：物体计数定种子尺寸，像素数定颜色，对角线种子自相似扩展

**组合逻辑**：[计数](物体数→种子边长) → [重涂色](像素数→颜色) → [印章覆盖](创新：对角线种子同时作为内容和放置掩码，双尺度编码物体数量信息)

**来源原语**：计数+连通分量+数量决定边长+对角线输出（d0f5fe59）；重涂色+前景对象+像素数映射颜色（6e82a1ae）；印章覆盖+种子精灵+像素到块映射+前景位放自身副本（5b6cbef5）

**依赖链**：物体计数 N 决定种子网格边长 → 每个物体的像素数决定其在种子对角线上的颜色 → 种子的前景像素位置决定哪些块被印章填充 → 印章内容就是种子自身。N 在两个尺度上编码：对角线长度（微观）和印章副本数量（宏观）。

统计前景物体数量确定种子尺寸，按像素数重涂颜色置于对角线，再将种子自相似印章扩展。

**输入结构**：约 15x15 的黑(0)背景网格。包含 N 个互相分离的 4-连通灰(5)物体（N 在 3~5 之间）。每个物体由 2、3 或 4 个灰色像素组成（形状不限，只要满足 4-连通）。各物体的边界框互不重叠。物体的边界框左上角可按行优先（先上后下、同行先左后右）无歧义排序。生成约束：N 个物体中至少出现两种不同的像素数（如有 2 像素和 3 像素的物体），以便颜色映射规则可被归纳。

**规则**：
1. 检测所有 4-连通灰(5)物体，计数为 N。
2. 对每个物体按像素数重涂颜色：2 像素 → 绿(3)，3 像素 → 红(2)，4 像素 → 蓝(1)。
3. 创建 N x N 的黑(0)种子网格。
4. 按边界框左上角的行优先顺序对物体排序，第 k 个物体（0-索引）的重涂颜色放置在种子的 (k, k) 位置（主对角线）。
5. 创建 (N*N) x (N*N) 的黑(0)输出网格，划分为 N x N 个块，每块 N x N。
6. 对种子中每个非黑前景像素 (i, j)，将整个种子网格复制到输出的第 (i, j) 号块中。
7. 对种子中每个黑(0)像素 (i, j)，对应输出块保持全黑。

**关键洞察**：物体数量 N 在输出中双重编码——对角线上恰好有 N 个彩色像素（微观），输出中恰好有 N 个非空块（宏观，因为种子有 N 个对角线前景像素）。像素数→颜色的映射规则必须对比包含不同像素数物体的多个示例才能归纳。

## 新题 8：镜像拼接补全残缺边框，裁剪后倍增内部图案

**组合逻辑**：[镜像+拼接](四象限对称补全残缺结构) → [裁剪](创新：裁剪目标是镜像后才完整的边框) → [像素放大](框内图案倍增填框)

**来源原语**：镜像+拼接+原始网格+象限+四象限对称（0c786b71）；裁剪+矩形边框+内部图案+图案在框内+图案倍增填框（e7a25a18）；像素放大（e7a25a18）

**依赖链**：输入仅显示框和图案的右下角片段 → 镜像拼接补全四个象限，使残缺边框成为完整封闭矩形，同时图案也被对称补全 → 裁剪到完整边框 → 提取框内完整图案并 2 倍放大填入。任何一步依赖前一步：不镜像则框不完整无法裁剪；不裁剪则无法确定图案边界；不放大则图案不填满框内空间。

将仅含边框和图案右下角片段的输入通过四象限镜像补全，裁剪到完整边框，再倍增内部图案。

**输入结构**：约 5x6 的小型网格。黑(0)背景上显示一个红(2)矩形边框的右下角部分——即边框的下边和右边可见，但上边和左边被截断于网格边界之外。边框内（右下角可见区域内）有一个小的彩色图案（使用一种非红非黑颜色如绿(3)），占据 1~3 个像素。边框厚度为 1 像素。生成约束：边框片段经四象限镜像后能形成封闭矩形（即边框的下边终止于网格右边界，右边终止于网格下边界，使得镜像后下边与上边对接、右边与左边对接）。图案在镜像后具有四重对称性（因为镜像本身产生四重对称）。

**规则**：
1. 以输入网格为右下象限，构造 2 倍尺寸的拼接网格：右下 = 原始输入；左下 = 输入的左右镜像；右上 = 输入的上下镜像；左上 = 输入的 180 度旋转。
2. 在拼接网格中，红(2)像素现在构成一个完整封闭的矩形边框。裁剪输出到该边框的边界框（含边框自身）。
3. 在裁剪后的区域内，提取所有非黑(0)、非红(2)像素的紧凑边界框作为"内部图案"。
4. 将内部图案按因子 2 放大（每个像素变为 2x2 块）。
5. 将放大后的图案写入框内区域的中心。框内其余空间填黑(0)。红(2)边框保持不变。

**关键洞察**：输入看起来只是角落里的几个像素碎片，毫无"框"的模样——只有在理解四象限镜像规则后，这些碎片才会拼成完整的框和图案。裁剪和放大都依赖于镜像产生的完整结构。需对比多个示例确认"输入放置在右下象限"这一规则。

## 新题 9：三角数位置循环填充生成模板，前缀行按模板解码补全

**组合逻辑**：[循环填充](创新：三角数列位置的循环色扩展生成一个非均匀模板行) → [补全](创新：用该模板行作为色彩映射的基准，各前缀行解码并补全)

**来源原语**：循环填充+色彩循环+递增间距序列+三角数位置（72207abc）；补全+模板行+前缀片段+列对齐+前缀色映射补全行+编码映射（82819916）

**依赖链**：三角数位置的色彩循环扩展 → 产生一个稀疏的非均匀"模板行"（仅三角数列有色，其余为背景） → 前缀行的左侧色段与模板行按列对齐 → 前缀的两色映射到模板的两色 → 用映射补全前缀行的所有三角数位置。模板不是直接给出的，而是从循环扩展中涌现——不扩展循环就无法得到完整模板，不得模板就无法解码前缀映射。

将三角数位置的循环色扩展为完整模板行，再用各前缀行的颜色映射解码并补全。

**输入结构**：约 5x20 的黑(0)背景网格。第 0 行在三角数列位置（列 0, 1, 3, 6, 10, ...）上有彩色像素，颜色在两种颜色间循环（如蓝(1)和红(2)交替：列 0 蓝、列 1 红、列 3 蓝、列 6 红、列 10 蓝...）。第 0 行仅显示前几个三角数位置的颜色（输入宽度内还有更多三角数位置未填色，显示为黑(0)）。第 1 行全黑(0)作为分隔。第 2~4 行各有一段从列 0 开始的连续非黑前缀（每行用两种与模板不同的颜色），前缀长度至少覆盖前两个三角数位置（列 0 和列 1）。前缀之后为黑(0)。生成约束：每行前缀在列 0 和列 1 处各有一个颜色，恰好对应模板的两色之一，使映射唯一确定。不同行的前缀使用不同的颜色对。

**规则**：
1. 从第 0 行已有的彩色像素中，按从左到右的顺序读取颜色，确定重复循环（始终为 2 色循环）。
2. 计算网格宽度内所有三角数列位置（0, 1, 3, 6, 10, 15, ...，即差值依次为 1, 2, 3, 4, 5, ...的累积序列）。
3. 将循环颜色扩展到第 0 行所有三角数列位置：按循环顺序依次为每个三角数位置赋色。已有颜色的位置保持不变，新位置按循环续接。非三角数列位置保持黑(0)。
4. 第 0 行扩展后即为"模板行"：三角数位置有色，非三角数位置为黑(0)。
5. 对第 2~4 行中每一行：将前缀像素与模板行相同列的颜色配对。前缀中出现的两种颜色分别对应模板的两种循环色，建立一对一映射。黑(0)（模板中非三角数位置）始终映射为黑(0)。
6. 用解码后的映射补全该行：对每一列，将模板行该列的颜色通过映射替换为该行的对应颜色，写入输出。
7. 输出中第 0 行为完整扩展后的模板行，第 1 行为黑(0)，第 2~4 行为补全后的完整行。

**关键洞察**：模板行并非显式给出，而是从三角数位置的稀疏循环中扩展而来。求解者必须先识别三角数间距规律（差值递增 1, 2, 3, 4, ...），扩展出完整模板，再理解前缀行的列对齐解码逻辑。两套规则（三角数位置规律 + 前缀映射规律）必须同时被归纳，仅看一个示例时三角数位置可能被误解为其他间距模式。
