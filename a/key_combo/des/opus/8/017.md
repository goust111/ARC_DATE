## 新题 1：异或差异揭示平铺种子

**组合逻辑**：[异或叠加](已有) + [平铺](已有)（创新：种子不直接给出，而是两掩码异或的涌现结果；空腔与掩码区域共存于同一网格中）

**来源原语**：异或叠加、前景掩码、分隔行、对齐、前景不一致处涂色(99b1bc43)；平铺、矩形空腔、墙壁、种子图案、图案填满空腔、保持种子相位(a57f2f04)

**依赖链**：分隔列将网格分为左右两个等宽掩码区域 → 逐单元格对齐取异或得到差异掩码 → 差异掩码的 bbox 即为种子图案 → 种子以保持相位的方式平铺填满底部空腔。异或结果为空则空腔保持全黑；异或的形状直接决定铺出的图案——删掉异或步骤则种子未知，删掉平铺步骤则空腔未填。

将分隔线两侧掩码的前景对称差异作为种子图案，平铺填充同一网格中由墙壁围出的矩形空腔。

**输入结构**：
- 约 18x12 的网格，背景色为黑(0)。
- 一条灰(5)垂直满列将网格上半部分左右分为两个等宽的掩码区域（各约 5 列宽、占网格上部约 8 行）。
- 左半区包含绿(3)前景像素在黑背景上构成一个 4-连通不规则形状（约 5-10 像素）。
- 右半区包含黄(4)前景像素在黑背景上构成另一个 4-连通不规则形状，与左半区部分位置重合、部分不同。
- 网格下部有一个由橙(7)像素围成的矩形空腔（单像素厚的封闭框），空腔内部全为黑(0)。空腔不与掩码区域重叠，不与分隔列重叠。
- 生成约束：左右半区行数列数相同，使得逐单元格对齐有意义。异或结果非空（两个掩码不完全相同）且非全覆盖。空腔内部宽高分别为异或结果 bbox 宽高的正整数倍。

**规则**：
1. 找到灰(5)垂直满列作为分隔线。将分隔线左侧的掩码区域和右侧的掩码区域逐行逐列对齐。
2. 对每对对齐的单元格，若恰好一侧为前景（绿(3)或黄(4)）而另一侧为黑(0)背景，则标记该位置为"差异位"；若双方都是前景或都是背景，则不标记。
3. 取所有差异位的 bbox 作为种子图案。在种子 bbox 内，差异位像素涂蓝(1)，非差异位像素保持黑(0)。
4. 找到橙(7)矩形框围成的空腔。以种子图案的左上角与空腔内部左上角对齐，沿行列方向重复平铺，直到填满空腔内部。平铺时保留种子内部黑(0)位为空腔背景色，蓝(1)位涂蓝(1)。
5. 分隔列、橙框、原始掩码区域均保持不变。

**关键洞察**：种子图案不在输入中直接出现，必须通过两侧掩码的异或运算才能推导出来；不同示例中两掩码的差异形状不同，导致平铺图案完全不同。

## 新题 2：连通唯一性筛选锚点，锚点行划分镜像带

**组合逻辑**：[连通检测 + 筛选](已有) → [中点划分归属](已有) → [镜像](创新：镜像轴由带的奇偶序号决定，而非固定为包围盒内翻转)

**来源原语**：连通检测、筛选、唯一连通分量、忽略干扰项(3194b014)；按行排序、中点划分归属、横带、单像素标记(0f63c0b9)；镜像、逐色独立变换、包围盒、包围盒内翻转(e74e1818)

**依赖链**：逐色检测 4-连通分量数量 → 仅保留恰好形成 1 个连通体的颜色（锚色），擦除多分量噪声色 → 各锚色质心行按行排序，相邻质心行的中点定义横带边界 → 每个横带内所有锚色对象按带的从上到下序号奇偶执行不同轴镜像。筛选结果改变带的数量与位置；带的奇偶性决定镜像方向——三步环环相扣。

根据连通分量唯一性筛选有效对象，以对象行位置划分横带，再按带序号奇偶执行水平或垂直镜像。

**输入结构**：
- 约 18x18 的网格，背景色为黑(0)。
- 网格上散布着 5-7 种非背景颜色的像素。
- 其中 3-4 种颜色各自的像素恰好形成**一个** 4-连通分量（锚色），每个锚色对象占约 4-8 像素，呈不规则非对称形状（具体形状因示例而异）。
- 其余 2-3 种颜色的像素被分裂为**多个**互不连通的 4-连通分量（噪声色），每个噪声分量不超过 3 像素，散布在网格各处。
- 锚色对象的质心行互不相同（质心行 = 该色所有像素行坐标的算术平均值，向下取整）。
- 生成约束：不同锚色对象的包围盒互不重叠。噪声色中至少有一种的某个分量位于极端行位置，若不筛除会改变带的划分结果。各锚色形状非水平对称也非垂直对称。

**规则**：
1. 对每种非背景色，计算其 4-连通分量数量。保留恰好 1 个分量的颜色（锚色），将所有多分量颜色（噪声色）的像素涂回黑(0)背景。
2. 计算每个锚色对象的质心行（所有该色像素行坐标的算术平均值，向下取整）。按质心行从小到大排序。
3. 相邻两个锚色质心行的中点（向下取整）划分出横带边界。最上横带从网格顶行（行 0）到第一个中点行（含），最下横带从最后一个中点行的下一行到网格底行。
4. 从上到下将横带编号为 1, 2, 3, ...。**奇数编号**横带内的所有锚色对象在其各自包围盒内做**水平镜像**（左右翻转：列坐标 c 映射为 c0 + c1 - c，c0 和 c1 为该色 bbox 的左右列）。**偶数编号**横带内的锚色对象在其各自包围盒内做**垂直镜像**（上下翻转：行坐标 r 映射为 r0 + r1 - r）。
5. 背景保持黑(0)。

**关键洞察**：镜像方向不是全局统一的，也不是由颜色决定的，而是由对象所在横带的奇偶序号决定——而横带边界本身又取决于哪些颜色通过了连通唯一性筛选，因此噪声色的存在间接影响了镜像行为。

## 新题 3：主干臂延伸遇走廊则变色贯穿

**组合逻辑**：[连线（主干+垂直臂）](已有) → [射线延伸 + 走廊检测](创新：走廊测试作用于臂的远端延伸方向，而非边界像素之间) → [重涂色](创新：涂色结果取决于走廊是否畅通)

**来源原语**：连线、控制像素、主干线段、连接到主干、共行列定义主干(bf89d739)；射线延伸、走廊、对边连通、无阻挡跨行列涂色(2bee17df)；重涂色(d931c21c)

**依赖链**：红像素中共行列的一对定义主干 → 其余红像素沿垂直方向连接到主干形成臂 → 每条臂从其红像素端点向远离主干的方向延伸射线至网格边缘 → 若射线路径上全为背景则该臂整体（含延伸段）涂绿(3)；若被其他前景像素阻挡则仅保留臂本身涂蓝(1)，阻挡像素不变。主干的检测决定臂的方向，臂的延伸检测决定臂的颜色——三步不可分割。

找到红色像素中共行或共列的一对构成主干，其余红像素垂直连接到主干形成臂，然后每条臂向远离主干方向做走廊测试：畅通则连同延伸段涂绿，受阻则仅臂涂蓝。

**输入结构**：
- 约 15x15 的网格，背景色为黑(0)。
- 网格中仅有红(2)和灰(5)两种前景色。
- 红(2)像素共 5-8 个，全为单像素点。其中恰好有一对红像素共享同一行或同一列，且该行/列不被其他红像素共享——该对定义主干。
- 其余红像素各自与主干方向垂直对齐（若主干水平，则各控制点与某主干像素在同一列上；若主干垂直，则在同一行上），且垂直坐标位于主干跨度范围内。
- 灰(5)像素为少量（2-4 个）分散的障碍物，位于部分红像素远离主干方向的延伸路径上。
- 生成约束：每个非主干红像素到主干之间全为背景（无障碍物）。部分红像素向远离主干方向到网格边缘之间有灰(5)阻挡，部分无阻挡。主干两端点之间也全为背景。

**规则**：
1. 在所有红(2)像素中找到恰好共享一行或一列的唯一一对——将它们之间的路径（含两端点）识别为主干。主干端点保持红(2)，端点之间的背景单元格涂橙(7)。
2. 对每个非主干红像素 P，画一条从 P 到主干的垂直连线（沿与主干方向垂直的方向），P 本身保持红(2)，P 与主干之间的背景像素涂橙(7)。
3. 对每个非主干红像素 P，从 P 沿远离主干的方向（即连线方向的反向）向网格边缘发射一条射线：
   - 若射线路径上直到网格边缘全为黑(0)背景（无灰(5)阻挡），则将该射线路径上的所有背景像素涂绿(3)，并将 P 与主干之间原本涂为橙(7)的连线像素也改涂为绿(3)，P 自身也涂为绿(3)。
   - 若射线路径在到达网格边缘前遇到灰(5)像素，则射线不绘制。P 与主干之间的连线像素保持橙(7)，P 自身保持红(2)。灰(5)阻挡像素保持不变。
4. 主干本身（两端红像素之间的橙色段及端点红像素）始终保持不变，不受臂测试影响。

**关键洞察**：同一结构（红色控制像素到主干的连接臂）会因远端走廊是否畅通而呈现完全不同的颜色——畅通臂变绿并贯穿至网格边缘，受阻臂保持橙色且不延伸；判断畅通与否需要考察每条臂各自方向上是否有灰色障碍。

## 新题 4：标记方块的边长定缩放、象限位置定旋转

**组合逻辑**：[像素放大 + 印章覆盖](已有) + [旋转](创新：旋转角度不由固定规则决定，而由标记方块相对于网格中心的象限位置决定——同一个标记方块同时编码了缩放因子与旋转角度)

**来源原语**：像素放大、印章覆盖、模板、标记方块、缩放对应、边长定缩放因子(447fd412)；旋转、阵列排布、四旋转组成风车(7fe24cdd)

**依赖链**：模板中的蓝色像素是源图案，红色像素是标记位 → 网格中分离的红色实心方块的边长 k 定义缩放因子 → 将每个方块的位置与模板标记位按缩放 k 对应 → 方块所在的网格象限决定源图案的旋转角度 → 在方块组对应的基准点处印上缩放 k 倍且按象限旋转后的蓝色图案。边长决定缩放，象限决定旋转，两者从同一个标记方块中提取却控制不同维度。

从标记方块的边长推断缩放因子，从其所在象限推断旋转角度，将模板中源色图案按此缩放与旋转后印章到对应位置。

**输入结构**：
- 约 25x25 的网格，背景色为黑(0)。
- 左上角附近有一个小型混色模板对象（bbox 约 3x3 至 4x4），由蓝(1)（源色）和红(2)（标记色）像素组成，4-连通。模板中蓝像素约 3-5 个，红像素约 2-3 个，排列成不规则但紧凑的非对称图案。
- 网格其余区域散布着若干独立的红(2)实心正方形（边长 k，k >= 2），每个方块的像素全为红(2)。所有方块边长相同。
- 方块分布在网格的不同象限（以网格中心行 R/2 和中心列 C/2 为分界）。
- 生成约束：所有方块的左上角坐标与模板中红色标记像素的坐标在缩放因子 k 下精确对应。每个象限至少有一个方块。将源图案按 k 倍缩放并按象限旋转后印章，各印章之间不重叠，不超出网格边界。模板图案非旋转对称（即 90 度旋转后与原图不同）。

**规则**：
1. 识别模板：找到同时包含蓝(1)和红(2)像素的 4-连通混色对象，取其 bbox 作为模板坐标系，记模板左上角为 (tr, tc)。
2. 计算缩放因子：找到模板外的独立红(2)实心正方形，其边长 k 即为缩放因子。
3. 确定旋转角度：以网格行数 R 和列数 C 的中点为分界，每个方块的左上角落入的象限决定旋转角：
   - 左上象限（行 < R/2 且列 < C/2）：0 度（不旋转）
   - 右上象限（行 < R/2 且列 >= C/2）：顺时针 90 度
   - 左下象限（行 >= R/2 且列 < C/2）：逆时针 90 度
   - 右下象限（行 >= R/2 且列 >= C/2）：180 度
4. 印章：对模板 bbox 中的蓝(1)像素图案，先应用该象限对应的旋转（绕模板 bbox 中心旋转），得到旋转后的图案。将旋转后图案的每个蓝像素扩展为 k x k 的蓝(1)色块。根据方块左上角相对于模板红标记位的缩放映射关系，确定印章的基准原点，将缩放色块绘制在对应位置。
5. 红色方块保持不变。模板保持不变。印章超出网格边界的部分裁剪丢弃。多个印章不会重叠（由生成约束保证）。

**关键洞察**：每个标记方块携带两重信息——边长编码缩放因子（全局一致），象限位置编码旋转角度（局部不同）；必须对比不同象限中的方块对应的输出图案才能发现旋转规则，仅看同一象限的方块会误以为所有印章方向一致。

## 新题 5：补填间隙改变面积排序，排序结果决定同心环嵌套

**组合逻辑**：[填充（间隙补填）](已有) → [排序](创新：排序依据不是原始像素数，而是补填后的总覆盖面积) → [同心环绘制](已有)

**来源原语**：填充、虚线段、邻接、单像素间隙补填(a699fb00)；排序、面积排序、面积决定嵌套序(5587a8d0)；同心环绘制、嵌套方环、连通分量(5587a8d0)

**依赖链**：每种颜色的虚线段含不同数量的单像素间隙 → 虚拟补填间隙后每种颜色的总覆盖面积（原始像素 + 间隙数）发生变化 → 补填后的面积排序决定同心环的嵌套次序。间隙数量直接影响覆盖面积，覆盖面积直接影响环的排列——不执行补填计算就无法得到正确排序。

将各色虚线段的单像素间隙虚拟补齐后计算覆盖面积，按面积降序绘制同心方环。

**输入结构**：
- 约 12x20 的网格，背景色为黑(0)。
- 网格中有 3-5 种不同颜色的水平虚线段（如红(2)、蓝(1)、绿(3)、黄(4)、品红(6)），每种颜色占据 1-2 行。
- 每种颜色在其行上呈"像素-间隙-像素-间隙-..."的虚线模式（每个间隙恰好 1 像素宽），但不同颜色的虚线起始列、跨度和间隙密度不同。
- 每种颜色的**原始着色像素数**（不含间隙）各不相同。
- 不同颜色的虚线段在行上互不重叠（各占独立的行）。
- 生成约束：各颜色补填后的总面积互不相等。至少有一对颜色在补填前后的面积大小关系发生反转（即颜色 A 原始像素数 > B，但 A 的"原始像素数 + 间隙数"< B 的"原始像素数 + 间隙数"）。

**规则**：
1. 对每种非背景颜色，扫描其所占行上的所有黑(0)像素：若某黑像素的左邻和右邻均为该色，则该像素是该色的一个"间隙位"。
2. 计算每种颜色的**补填后覆盖面积** = 该色原始像素数 + 该色间隙位数。
3. 按补填后覆盖面积从大到小对颜色排序。若面积相等（由生成约束保证不会），以颜色所在最上行的行号小者优先。
4. 设颜色数为 n。输出一个边长为 2n-1 的正方形网格，绘制同心方环：排序第 1 位的颜色填充最外圈环，第 2 位颜色填充次外圈环，依次向内，排序末位颜色填充中心像素。
5. 原始输入网格不保留在输出中，输出仅为同心方环。

**关键洞察**：排序依据是补填后的覆盖面积而非原始像素数；由于间隙密度因颜色而异，补填操作会改变颜色之间的面积相对大小，导致环的嵌套顺序与直觉的"谁原始像素多谁在外"不同。

## 新题 6：十字分隔去噪后按象限对角配对执行条件镜像

**组合逻辑**：[压缩/去噪](已有) + [镜像](创新：镜像轴不再是包围盒内固定方向，而是由象限的对角配对关系决定——对角象限做相同方向镜像，相邻象限做不同方向镜像)

**来源原语**：压缩、十字分隔线、四象限、主色代表区域、去噪取主色、忽略干扰项(996ec1f3)；镜像、单色掩码、逐色独立变换、包围盒内翻转(e74e1818)

**依赖链**：找到唯一的全行全列同色十字 → 十字将网格切为四象限 → 每个象限内去噪保留主色形状 → 对角象限（左上与右下、右上与左下）共享同一镜像轴方向。十字检测定义象限划分，去噪定义形状轮廓，象限位置决定镜像方向——三者不可分割。

在十字分隔线划分的四象限中去噪提取主色形状，然后对角象限做同方向镜像：左上/右下水平翻转，右上/左下垂直翻转。

**输入结构**：
- 约 15x15 的网格，背景色为黑(0)。
- 存在恰好一行和恰好一列的灰(5)像素，该行和该列全部为灰(5)，形成一个十字分隔线，将网格分为四个非空矩形象限。
- 每个象限内有一种主色（非黑(0)非灰(5)的前景色，四个象限的主色互不相同，从蓝(1)、红(2)、绿(3)、黄(4)中选取），以及少量噪声像素（1-3 个，颜色为品红(6)或橙(7)等非主色非背景非灰的颜色）。
- 每个象限的主色像素形成一个 4-连通的不规则形状（约 4-8 像素），非水平对称、非垂直对称。
- 噪声像素散布在象限内，不与主色像素 4-连通相邻。
- 生成约束：每个象限恰好只有一种出现次数最多的非背景非灰前景色（即主色明确）。各主色形状的包围盒不跨越十字分隔线。

**规则**：
1. 找到灰(5)的满行和满列，确定十字分隔线位置，将网格分为四个象限：左上(UL)、右上(UR)、左下(LL)、右下(LR)。
2. 在每个象限内，统计非背景(0)非灰(5)的各颜色像素数，出现次数最多的颜色即为该象限的主色。将该象限内非主色的前景像素（噪声）涂为黑(0)背景。
3. 对角配对镜像：
   - UL 和 LR 象限：各自象限内的主色形状在其**包围盒范围内做水平镜像**（列坐标翻转：c → c0 + c1 - c，c0、c1 为该色 bbox 在该象限内的左右列）。
   - UR 和 LL 象限：各自象限内的主色形状在其**包围盒范围内做垂直镜像**（行坐标翻转：r → r0 + r1 - r，r0、r1 为该色 bbox 的顶底行）。
4. 十字分隔线保持灰(5)不变。背景保持黑(0)。

**关键洞察**：镜像方向既非全局统一也非逐色独立决定，而是由象限的对角配对关系决定——必须对比至少两个示例中不同象限的形状变化方向，才能归纳出"对角象限同向镜像"的隐蔽规则。

## 新题 7：标记行扩展为带框后，框壁间的畅通列涂色

**组合逻辑**：[扩展 + 边框绘制](已有) → [走廊检测 + 重涂色](创新：走廊测试不作用于网格边界像素之间，而是作用于相邻带框的壁像素之间——框的存在是走廊涌现的前提)

**来源原语**：扩展、边框绘制、单像素标记、横带、按行排序、中点划分归属(0f63c0b9)；射线延伸、走廊、对边连通、无阻挡跨行列涂色、重涂色、边界像素(2bee17df)

**依赖链**：标记像素的行位置按中点划分归属定义横带 → 每个带绘制左右边界列和标记行形成框 → 相邻带的框壁在列方向上形成上下对峙的壁像素 → 若两壁之间该列全为背景则涂为走廊色。框的绘制创造了壁像素，壁像素的位置决定了走廊检测的起止——不画框就无壁，无壁就无走廊。

将标记行扩展为带框结构后，检测相邻带框壁之间的畅通列，将畅通列涂上走廊色。

**输入结构**：
- 约 20x14 的网格，背景色为黑(0)。
- 网格中有 3-4 个不同颜色的单像素标记（如蓝(1)、红(2)、绿(3)），分布在不同行上，列位置各异。
- 网格中还有若干品红(6)的单像素障碍物（3-5 个）散布在各处。
- 生成约束：标记像素所在的行各不相同。品红障碍物不在任何标记行上。相邻带的框壁之间（即上带底行与下带顶行之间的间隔行区域）至少有一列完全无障碍（保证至少存在一条走廊），且至少有一列被品红阻挡（保证非全通）。

**规则**：
1. 按标记像素的行坐标从上到下排序。相邻标记行的中点行（向下取整）作为带的分界。最上带从行 0 到第一个中点行（含），最下带从最后一个中点行的下一行到网格末行。
2. 对每个标记的带：将该带的标记行（从列 0 到网格末列）整行涂为标记颜色；将该带范围内的最左列（列 0）和最右列（网格末列）整列（在带的行范围内）涂为标记颜色。若带的行范围包含网格顶行（行 0）或底行，则也将该边界行整行涂为标记颜色。涂色时不覆盖品红(6)障碍物——品红像素保持不变。
3. 走廊检测：对每一对上下相邻的带，确定上带的底边行 r_bottom 和下带的顶边行 r_top（注意上带底边行和下带顶边行是各带通过规则 2 绘制的最下行和最上行）。检查每一列 c：若 r_bottom 和 r_top 之间（不含 r_bottom 和 r_top 本身）该列的所有像素均为黑(0)背景（无品红障碍物、无其他前景色），则将该列在 r_bottom+1 到 r_top-1 之间的所有像素涂黄(4)。
4. 品红(6)障碍物始终保持不变。已涂的框壁像素不被走廊涂色覆盖。

**关键洞察**：走廊不是输入中预设的结构，而是带框绘制后才涌现的——框壁充当走廊的两端，而框壁的位置又取决于标记行的中点划分；品红障碍物在框绘制阶段被保留但在走廊检测阶段充当阻断，一物两用。

## 新题 8：平铺填充空腔后，腔内颜色频率决定封闭环的描边配色

**组合逻辑**：[平铺](已有) → [描边](创新：描边颜色不固定，而是由平铺结果中的颜色统计量决定——平铺是描边的前置数据源) + [重涂色](已有)

**来源原语**：平铺、种子图案、矩形空腔、墙壁、图案填满空腔、保持种子相位(a57f2f04)；描边、封闭区域、连通分量、孔洞、内外边界、内外边界分色(d931c21c)；重涂色(2bee17df)

**依赖链**：蓝色环围出空腔，空腔内含种子 → 平铺种子填满空腔 → 统计空腔内平铺结果中各颜色的像素数 → 频率最高的颜色涂环的外边界，频率最低的颜色涂环的内边界（孔洞侧）。不同环的种子和空腔尺寸不同导致平铺后颜色频率不同，因此不同环的描边配色也不同——描边依赖于平铺的全局统计信息。

将种子图案平铺填满封闭环的空腔后，根据腔内平铺像素的颜色频率高低决定环的外描边色和内描边色。

**输入结构**：
- 约 22x22 的网格，背景色为黑(0)。
- 网格中有 2-3 个由蓝(1)像素组成的 4-连通封闭环形对象，每个环形成一圈连续的蓝色像素，环壁厚度为 1 像素，内部包围一个黑(0)孔洞区域。环的整体外形为不规则多边形（非矩形）。
- 每个环的孔洞内恰好有一小块种子图案，由两种非蓝(1)、非黑(0)颜色组成（例如红(2)和绿(3)、或黄(4)和品红(6)），每个种子的 bbox 为 2x2 至 3x3，位于孔洞内某处。
- 不同环内的种子图案可以使用不同的颜色对，但每个种子恰好使用两种颜色。
- 没有封闭孔洞的开放蓝色对象不参与规则，保持不变。
- 生成约束：每个孔洞区域的宽高分别为其种子 bbox 宽高的正整数倍。每个种子中两种颜色的像素数在种子 bbox 内不相等。平铺填满孔洞后两种颜色的总像素数也不相等。不同环内平铺后的最高频颜色可能不同（体现规则的数据依赖性而非固定映射）。

**规则**：
1. 识别每个有孔洞的蓝(1)封闭环对象：找到所有不接触网格边缘且不接触其他颜色对象的 4-连通黑(0)区域作为候选孔洞，确认其 4-邻域边界全部是同一个蓝(1)对象的像素。
2. 对每个孔洞，找到孔洞内非黑像素的 bbox 作为种子图案。将种子以其 bbox 左上角与孔洞 bbox 左上角对齐的方式沿行列方向平铺填满整个孔洞。种子 bbox 内的黑(0)位在平铺后保持黑(0)。
3. 统计每个孔洞中平铺完成后各非黑颜色的像素总数。记频率最高的颜色为 C_high，频率最低的颜色为 C_low。
4. 描边该环的外侧：在网格中找到与该蓝(1)环的像素 8-邻接且属于外部背景区域（接触网格边缘的黑色连通分量）的所有黑(0)像素，涂为 C_high。
5. 描边该环的内侧：在孔洞区域中找到与该蓝(1)环的像素 8-邻接的所有像素（这些像素现已被平铺填充为某种颜色），将它们的颜色替换为 C_low。
6. 蓝(1)环壁本身保持蓝(1)不变。无孔洞的蓝色开放对象不处理，保持不变。各环独立处理，互不影响。

**关键洞察**：描边的颜色不是预定义的固定色，而是由平铺结果中的颜色统计决定的——不同环因种子图案和孔洞形状不同，平铺后的频率排序也不同，因此同一网格中不同环可以有不同的描边配色方案；必须先完成平铺才能确定描边颜色。
