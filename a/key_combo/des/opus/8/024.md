## 新题 1：行填充桥接改变连通分量存活

**组合逻辑**：[填充(fill)](创新：行填充充当结构桥梁) + [同色配对(same_color_pairing) / 两端同色整行填充(full_row_fill_endpoints_match)](已有) → [连通分量检测(connected_component_detection)](已有) → [面积阈值筛选(area_threshold_filter) / 重涂色(recolor)](创新：筛选在填充后的拓扑上执行)

**来源原语**：填充 ← 22eb0ac0；同色配对/两端同色整行填充 ← 22eb0ac0；连通分量检测/面积阈值筛选/重涂色 ← 12eac192

**依赖链**：行填充改变了像素的前景/背景属性 → 这改变了连通分量的拓扑结构（原本分离的小物体可能被填充色桥接为一个大连通体） → 面积阈值筛选在新拓扑上执行，决定哪些物体被重涂为绿(3)。填充步骤不仅是视觉变化，更是决定后续哪些物体"存活"的结构性操作。

行填充在两端同色行上涂色，可能将两个原本分离的小前景物体桥接为一个大连通体，使其面积超过阈值而避免被重涂为绿(3)；未被桥接的小物体则被重涂。

**输入结构**：
- 约 12x15 的网格，背景为黑(0)。
- 若干行的左右边界各有一个前景色标记像素（成对出现在同一行的第 0 列和最后一列）。每行的两个标记使用相同或不同的颜色，颜色取自 {蓝(1), 红(2), 黄(4)}。
- 网格内部散布着若干小型单色 4-连通前景物体（每个物体 1~4 像素），颜色取自 {蓝(1), 红(2), 黄(4), 橙(7)}。这些物体的颜色可能与某些标记颜色相同。
- 生成约束：至少存在两个小物体（各 1~2 像素），它们位于同一行或相邻行，且该行的左右标记颜色匹配。至少存在一个小物体不在任何匹配行附近。不同示例中物体的具体形态不同。

**规则**：
1. 复制输入网格。
2. 对每一行检查左右边界标记：若两端标记颜色相同，则将该行中所有黑(0)背景像素涂为该标记颜色（已有的前景像素保持不变）。若两端不同色或该行无标记，不做处理。
3. 在填充后的网格上，检测所有非黑(0)的 4-连通同色连通分量（将所有非黑像素视为前景，按颜色分别检测连通性）。
4. 对每个连通分量，计算其像素面积。面积为 1 或 2 的连通分量，将其所有像素重涂为绿(3)。面积 >= 3 的连通分量保持不变。
5. 边界标记像素本身参与连通分量检测——如果标记像素与填充行或其他前景像素同色且 4-连通，则属于同一连通分量。

**关键洞察**：行填充不只是装饰——它是拓扑桥梁。同色填充行将行内或相邻行的小物体合并为更大的连通体，使它们逃过面积阈值筛选。判断哪些物体被重涂绿色，需要先确定哪些行会被填充、填充如何改变连通结构。

## 新题 2：对称恢复揭示隐藏射线种子

**组合逻辑**：[对称补全(symmetry_completion)](已有) → [种子像素(seed_pixel) 发现](创新：种子藏在遮挡区域下) → [射线延伸(ray_extend)](已有，但种子来源为恢复结果) + [种子色决定延伸(seed_color_determines_extend)](创新：恢复的种子色决定射线方向)

**来源原语**：对称补全/二面体对称/遮挡矩形/可见副本恢复遮挡 ← f4081712；射线延伸/种子像素/种子色决定延伸 ← 178fcbfb

**依赖链**：对称恢复从遮挡区域中还原出种子像素的颜色 → 种子颜色决定射线延伸方向（红=垂直，蓝=水平） → 射线在完整恢复图上绘制。不执行恢复则缺少部分种子，射线图案不完整；不知道种子色与方向的映射则无法确定射线走向。

**输入结构**：
- 约 13x13 的正方形网格。整个图案在非遮挡区域具有正方形的二面体对称性（4 次旋转 + 4 次反射，共 8 个等价位置）。
- 前景图案使用灰(5)像素构成几何结构（4-连通边框或线段），背景为黑(0)。
- 图案中散布着少量红(2)和蓝(1)单像素，它们是射线种子。
- 一个绿(3)实心矩形（约 3x4 或 4x5 像素）遮挡了部分图案。被遮挡的区域下隐藏着灰(5)结构像素以及 1~2 个种子像素（红或蓝）。
- 生成约束：每个被遮挡的种子像素，其至少一个对称等价位置是可见的（未被遮挡），以保证可恢复。不同示例中遮挡矩形的位置不同，导致被隐藏的种子不同。

**规则**：
1. 对每个绿(3)像素，检查其在二面体对称群下的所有等价坐标。忽略等价坐标中同样被遮挡（绿色）的位置。剩余可见位置的颜色应一致，取该颜色作为恢复值。
2. 用恢复值替换所有绿(3)像素，得到完整的对称图案。
3. 在完整图案上，识别所有红(2)和蓝(1)单像素作为射线种子。
4. 对每个红(2)种子，沿垂直方向（上下）延伸射线：将该列上所有黑(0)背景像素涂为红(2)，遇到非黑像素时停止（不覆盖已有前景）。
5. 对每个蓝(1)种子，沿水平方向（左右）延伸射线：将该行上所有黑(0)背景像素涂为蓝(1)，遇到非黑像素时停止。
6. 若一个红射线和一个蓝射线交汇于同一个黑(0)像素，该像素涂为黄(4)。
7. 灰(5)结构像素和种子像素本身保持不变。

**关键洞察**：绿色遮挡不仅隐藏了图案结构，更隐藏了射线种子的存在和颜色。必须先通过对称恢复找到所有种子，才能正确生成射线图案；射线的交汇色（黄）又需要同时处理两种方向的射线。

## 新题 3：格元内射线可见性决定精灵重涂色

**组合逻辑**：[标记点阵(marker_lattice) / 格元(lattice_cell)](已有) → [射线延伸(ray_cast)](创新：射线限制在格元内部) + [障碍像素(obstacle_pixel)](已有) → [计数(counting)](已有) → [重涂色(recolor)](创新：命中数决定颜色)

**来源原语**：标记点阵/格元/格元内居中 ← 20981f0e；射线延伸/障碍像素/碰撞产生侧翼 ← 79fb03f4；计数 ← 6455b5f5；重涂色 ← ddf7fa4f

**依赖链**：点阵定义格元边界 → 格元边界限定射线传播范围 → 射线从精灵出发检测障碍可见性 → 可见障碍计数决定精灵新颜色。格元边界、精灵形状、障碍位置三者共同决定最终结果。

**输入结构**：
- 约 19x19 的网格，背景为黑(0)。
- 黄(4)单像素形成规则笛卡尔点阵，点阵间距相等（如每隔 5 列 5 行一个黄点），将网格划分为等大的矩形格元（约 4x4 或 5x5 内部空间）。
- 每个格元内部包含一个灰(5) 4-连通小精灵（3~6 像素，不同格元中形状可不同但颜色均为灰）。
- 部分格元内部还有 0~3 个红(2)单像素障碍，散布在精灵周围。
- 生成约束：每个格元内，精灵与障碍互不 4-连通。不同格元的障碍数量不同（含 0 个的情况）。精灵和障碍均不接触黄点阵标记。

**规则**：
1. 识别黄(4)点阵标记，确定格元边界。每个格元的内部区域是两个相邻黄标记之间的矩形空间（不含黄标记本身）。
2. 对每个格元，从灰(5)精灵的每个像素向四个基本方向（上、下、左、右）发射射线。射线在格元内部传播，逐像素前进，遇到以下情况停止：(a) 碰到红(2)障碍像素（记录该障碍为"被命中"），(b) 碰到黄(4)标记或格元边界，(c) 碰到灰(5)精灵自身的另一像素。
3. 统计该格元内被至少一条射线命中的**不同**红(2)障碍像素数量（同一障碍被多条射线命中只计 1 次）。
4. 根据命中数重涂精灵颜色：0 个 → 蓝(1)，1 个 → 绿(3)，2 个 → 橙(7)，3 个及以上 → 品红(6)。
5. 黄标记和红障碍保持不变。

**关键洞察**：精灵的颜色不仅取决于格元内有多少障碍，还取决于从精灵的具体形状能"看见"多少个障碍——一个障碍若被另一个障碍遮挡（从精灵所有像素出发的射线都先碰到前方障碍），则不被计入。精灵的几何形状直接影响可见性判定。

## 新题 4：面板分层外推与重组

**组合逻辑**：[序列外推(sequence_extrapolation)](已有) + [透明叠加(transparent_overlay)](创新：每帧是两层叠加的合成结果) → [裁剪(crop)](已有) + [图层优先级(layer_priority)](创新：重叠色作为分层线索)

**来源原语**：序列外推/面板帧/分隔行/恒定偏移平移 ← 351d6448；透明叠加/图层优先级 ← 281123b4, e99362f0

**依赖链**：分帧 → 分层解码（黄色像素 = 两层重叠信号） → 每层独立追踪恒定平移 → 第 5 帧各层独立外推 → 按叠加规则重组合成帧。不分层则无法追踪各层独立运动；不外推则无法预测下一帧；不重组则输出不完整。

**输入结构**：
- 约 24x6 的网格。四个等大面板（每个约 5x6）纵向堆叠，相邻面板间由一整行灰(5)分隔行分开。
- 每个面板背景为黑(0)，包含蓝(1)和红(2)前景像素。部分像素为黄(4)。
- 蓝(1)像素构成一个 4-连通小图形（层 A），红(2)像素构成另一个 4-连通小图形（层 B）。黄(4)像素出现在层 A 和层 B 重叠的位置。
- 从第 1 帧到第 4 帧，层 A 以恒定偏移 (dr_A, dc_A) 平移，层 B 以恒定偏移 (dr_B, dc_B) 平移。两层的偏移通常不同。
- 生成约束：每帧中两层至少有 1 个像素重叠（产生黄色），以确保分层线索可见。每层的图形在所有 4 帧中均完整在面板内（不被截断）。第 5 帧外推后两层也完整在面板内。

**规则**：
1. 在灰(5)分隔行处将输入切分为 4 个面板。
2. 对每个面板进行分层解码：
   - 层 A 占据位置 = 蓝(1)像素位置 + 黄(4)像素位置（黄色表示两层重叠，层 A 在此存在）。
   - 层 B 占据位置 = 红(2)像素位置 + 黄(4)像素位置。
3. 对层 A，计算连续面板间的平移偏移 (dr_A, dc_A)。验证所有相邻帧间偏移一致。
4. 对层 B，同样计算恒定偏移 (dr_B, dc_B)。
5. 将层 A 和层 B 分别按各自偏移外推到第 5 帧位置。
6. 合成第 5 帧：仅层 A → 蓝(1)；仅层 B → 红(2)；两层均在 → 黄(4)；均不在 → 黑(0)。
7. 输出为单个面板大小的网格（不含分隔行）。

**关键洞察**：黄(4)不是独立物体，而是两层重叠的信号。必须将每帧分解为两层，才能独立追踪各层的运动规律并正确外推。直接对合成帧做整体外推会因重叠区的颜色变化而失败。

## 新题 5：十字扩展后按列控制重涂色

**组合逻辑**：[射线延伸(ray_extend) → 十字图案(cross_pattern)](已有) + [交叉点重置背景(intersect_reset_bg)](已有) → [列范围包含(column_span_contains)](创新：用于十字而非矩形) + [控制色决定填色(control_fill_color)](创新：控制色作用于生成的十字臂)

**来源原语**：射线延伸/实心方块/十字图案/行列对齐/交叉点重置背景 ← e9bb6954；控制像素/列范围包含/控制色决定填色 ← ddf7fa4f

**依赖链**：3x3 方块 → 十字扩展（确定十字形状） → 交叉点重置（确定十字间的间隙） → 列范围匹配控制像素（确定每个十字的颜色）。十字必须先生成再着色，因为着色依据是原始方块的列位置而非扩展后的十字列位置。

**输入结构**：
- 约 15x15 的网格，背景为黑(0)。
- 2~4 个灰(5)实心 3x3 方块，各中心行互不相同且各中心列互不相同。方块间距至少 4 像素，保证十字交叉点在所有方块外部。
- 顶行（第 0 行）有若干单像素控制标记，颜色取自 {蓝(1), 红(2), 绿(3), 黄(4)}，每个控制像素颜色互不相同。
- 生成约束：每个 3x3 方块的列范围（中心列 -1 到中心列 +1）恰好包含一个控制像素的列坐标。控制像素不与任何方块在同一行。

**规则**：
1. 复制输入网格。
2. 对每个灰(5) 3x3 方块，将其中心行的所有像素（从列 0 到最右列）涂为灰(5)，将其中心列的所有像素（从行 0 到最底行）涂为灰(5)。方块本身已为灰色，保持不变。此步骤生成灰色十字臂。
3. 检查所有十字交叉点：若某像素同时在方块 X 的中心行和方块 Y 的中心列上（X != Y），将该像素重置为黑(0)背景。
4. 对每个 3x3 方块，找到列坐标落在其列范围 [中心列-1, 中心列+1] 内的那个顶行控制像素，取其颜色。
5. 将该方块及其生成的所有十字臂像素（不含已重置为背景的交叉点）重涂为步骤 4 确定的控制颜色。
6. 顶行控制像素本身保持不变。

**关键洞察**：十字的颜色不由方块自身决定，而由顶行控制像素的列位置决定——判断依据是控制像素的列是否落在原始 3x3 方块的列范围内（宽度仅 3 列），而非扩展后的全宽十字。交叉点重置创造的间隙使不同颜色的十字臂在视觉上分离。

## 新题 6：端点位移定位种子并触发碰撞分叉射线

**组合逻辑**：[端点编码位移(endpoints_encode_disp)](已有) + [平移(translate)](创新：位移用于定位种子而非移动框) → [射线延伸(ray_extend) + 分叉(branching) + 碰撞产生侧翼(collision_generates_side_wakes)](已有) + [擦除(erase)](已有：清除路径结构)

**来源原语**：端点编码位移/路径端点/平移 ← 2b9ef948；射线延伸/分叉/种子像素/障碍像素/碰撞产生侧翼 ← 79fb03f4；擦除 ← 0607ce86

**依赖链**：路径端点解码出位移向量 → 位移确定种子像素的放置位置 → 种子在障碍场中发射分叉射线。路径的几何形状是噪声，仅端点携带信息；种子位置错则射线图案全错。

**输入结构**：
- 约 16x18 的网格，背景为黑(0)。
- 上半区（约前 7 行）包含 2~3 条灰(5)路径。每条路径是若干灰像素构成的 4-连通折线，两端各有一个非灰彩色端点：一端为蓝(1)，另一端为红(2)。路径可以有弯折，形状在不同示例中不同。
- 下半区（约后 11 行）包含：若干绿(3)单像素障碍散布其中；2~3 个橙(7)单像素标记（数量与路径数量相同）。
- 生成约束：每个橙标记与恰好一条路径配对（按从左到右的出现顺序一一配对：最左的橙标记配最左的路径，依次类推）。每条路径的位移向量（从蓝端到红端）应用于其配对橙标记后，目标位置在下半区内且为黑(0)背景。不同路径的位移向量互不相同。

**规则**：
1. 对每条灰(5)路径，计算其位移向量：从蓝(1)端点到红(2)端点的坐标差 (dr, dc) = (红行-蓝行, 红列-蓝列)。路径中间的弯折不影响位移。
2. 将路径按蓝端点列坐标从小到大排序，橙标记按列坐标从小到大排序，一一配对。
3. 对每个橙(7)标记，将其坐标加上配对路径的位移向量，得到目标位置。在目标位置放置一个橙(7)种子像素。
4. 擦除所有灰(5)路径像素、蓝(1)端点和红(2)端点（设为黑(0)）。原始橙标记也擦除。
5. 从每个新放置的橙(7)种子开始，向右发射水平射线，逐像素涂为橙(7)。
6. 射线碰到绿(3)障碍时：保持障碍不变；在障碍的上方和下方各绘制 3 像素侧翼尾迹（从障碍正上/正下开始，沿竖直方向各延伸 1 像素，再沿水平向右延伸 1 像素，共 3 像素呈 L 形），侧翼颜色为橙(7)。侧翼像素若遇到已有非黑像素则不绘制。
7. 若障碍的右上方和右下方（即 (障碍行-1, 障碍列+1) 和 (障碍行+1, 障碍列+1)）都是绿(3)障碍，则原始射线终止，在这两个相邻行上各启动新的水平射线继续向右传播（分叉规则与步骤 6 相同）。
8. 射线到达网格右边界时停止。

**关键洞察**：灰色路径是编码载体而非结构元素——其形状是噪声，仅两端彩色端点的坐标差编码了位移信息。该位移决定种子放置位置，进而决定整个射线分叉图案的起点。

## 新题 7：投票恢复精灵中的锚点驱动格内对角射线

**组合逻辑**：[投票恢复(majority_vote_recovery) + 密集带检测(dense_band_detection)](已有) → [实心正方形(solid_square) / 对角标记(diag_marker) 识别](创新：锚点从恢复结果中提取) → [射线延伸(ray_cast) + 对角邻接(diag_adjacency) + 锚角对角射线至边(anchor_diag_to_edge)](创新：射线限制在插槽内部) + [擦除(erase)](已有：清除槽外噪声)

**依赖链**：密集带检测定位插槽 → 多插槽投票恢复标准精灵（含被噪声破坏的锚点） → 恢复的精灵中找到 2x2 锚和对角种子 → 在每个插槽内从锚点对角种子发射对角射线，射线止于插槽边界。噪声破坏了个别插槽的锚点，只有投票恢复才能可靠确定锚点位置。

**输入结构**：
- 约 23x23 的网格，背景为黑(0)。
- 蓝(1)前景像素构成一个 4x4 规则插槽阵列（共 16 个插槽）。每个插槽是一个 5x5 的矩形区域，插槽间由 1 像素宽的黑间隙分隔。
- 每个插槽包含同一精灵图案的一个副本（精灵使用蓝(1)像素，约 8~12 像素）。精灵内部包含一个 2x2 的实心蓝方块作为锚点，锚点的 1~2 个角有对角邻接的蓝像素（对角种子）。
- 约 2~4 个插槽中，精灵的 1~2 个像素被破坏（颜色错误或缺失），可能波及锚点或对角种子。
- 插槽外部有少量零星蓝(1)噪声像素。
- 生成约束：每个精灵像素位置，16 个插槽中至少 12 个是正确的（保证多数投票可靠）。

**规则**：
1. 通过行密度和列密度检测找到密集行带和密集列带，确定 4x4 插槽阵列的位置（密集带间的交叉区域为插槽）。
2. 对精灵边界框内的每个相对位置 (r, c)，统计 16 个插槽在该位置的颜色，取多数颜色作为标准值。得到标准精灵。
3. 在标准精灵中识别唯一的 2x2 实心蓝方块（锚点）。检查锚点四角的对角邻接位置：若该位置为蓝(1)，则标记为对角射线种子，射线方向为从锚点中心指向该对角的方向（如左上角有种子则方向为左上）。
4. 用标准精灵替换每个插槽内的内容。
5. 在每个插槽内，从每个对角种子出发，沿其方向逐像素延伸对角射线，涂为蓝(1)。射线遇到插槽边界时停止（不越过插槽间的间隙）。
6. 将所有插槽外的像素设为黑(0)，清除噪声。

**关键洞察**：个别插槽的噪声可能恰好破坏了锚点或对角种子，若直接在各插槽中识别锚点会得到错误结果。只有通过 16 个副本的多数投票恢复标准精灵，才能可靠确定锚点位置和对角种子方向，进而正确生成每个插槽内的对角射线。

## 新题 8：对角连线构建围墙后按面积填充封闭区域

**组合逻辑**：[同色配对(same_color_pairing)](已有) → [连线(connect) / 对角线段(diagonal_segment)](已有) → [洪泛填充(flood_fill) + 封闭区域(enclosed_region)](已有) + [面积决定填充色(area_determines_fill_color)](创新：面积排名而非固定大小映射)

**来源原语**：同色配对/同色矩形对/对角偏移/对角补全连接/对角线段 ← 342ae2ed；洪泛填充/封闭区域/面积决定填充色 ← c0f76784；面积比较/极值区域分别涂色 ← 6455b5f5

**依赖链**：同色配对确定连线端点 → 对角连线创建新的围墙 → 围墙与已有灰墙一起构成封闭区域 → 封闭区域的面积排名决定填充颜色。对角连线改变了网格的拓扑：不画连线则封闭区域不存在或不同。

**输入结构**：
- 约 14x14 的网格，背景为黑(0)。
- 3~4 对同色单像素散布于网格中，每对使用一种唯一颜色（取自 {蓝(1), 红(2), 绿(3), 黄(4)}，每种颜色恰好出现 2 次）。每对中两个像素呈 45 度对角偏移（行差绝对值 = 列差绝对值）。
- 若干灰(5)像素构成直线墙段（水平或垂直），长度 3~8 像素。
- 生成约束：所有对角连线画完后，与灰墙共同形成至少 2 个不同面积的 4-连通黑(0)封闭区域（封闭 = 区域内无像素接触网格边界）。各对角连线互不交叉。封闭区域面积互不相同。

**规则**：
1. 对每对同色像素，画出连接它们的 45 度对角线段：从一端沿对角方向逐像素前进到另一端，将路径上的黑(0)背景像素涂为该对的颜色。两个端点像素已存在，保持不变。
2. 对角线段与灰(5)墙段共同构成围墙结构。找到所有 4-连通的黑(0)区域。
3. 将黑(0)区域分为"封闭"（区域内无像素位于网格的第 0 行、最末行、第 0 列或最末列）和"开放"（至少一个像素在边界上）。
4. 对所有封闭区域按面积（像素数）从小到大排序。
5. 最小封闭区域填充为品红(6)，最大封闭区域填充为青(8)，其余封闭区域填充为橙(7)。若仅有一个封闭区域则填品红(6)；若恰好两个则小的填品红(6)、大的填青(8)。
6. 开放区域保持黑(0)。所有彩色端点、对角线段、灰墙保持不变。

**关键洞察**：同色配对决定了画哪些对角线段，但这些线段的真正作用是拓扑性的——它们与灰墙配合创建封闭区域。对角线段的颜色是配对的视觉标记，而它们作为围墙的功能才是题目的核心。面积排名在连线完成后才能确定，因为连线改变了区域的划分方式。

**组合逻辑**：[排序(sorting) + 长度排名(length_ranking)](已有) → [重涂色(recolor) + 排名决定颜色(rank_determines_color)](已有) → [同色标记对齐对接(same_color_dock)](创新：对接目标的排列顺序独立于长度排名) + [裁剪(crop)](已有)

**输入结构**：
- 约 8x20 的网格，背景为黑(0)。
- 三条灰(5)水平细条（宽 1 像素），长度互不相同（如 3、5、7 像素），位于网格左半区的不同行。
- 每条细条的左端有一个彩色单像素连接标记，紧贴细条最左像素的左侧（即列坐标 = 细条最左列 - 1）。三个标记颜色互不相同，取自 {品红(6), 橙(7), 青(8)}。
- 网格最右列（最后一列）有三个彩色单像素，颜色与三个连接标记一一对应（同一组 {品红(6), 橙(7), 青(8)}），从上到下排列顺序任意（不同示例中排列不同）。
- 生成约束：三条细条的长度排名与连接标记颜色的排列无预设关系（最长条的标记不一定对应最上方的目标像素）。

**规则**：
1. 按长度排名重涂三条细条：最长 → 蓝(1)，中等 → 黄(4)，最短 → 红(2)。
2. 每条细条的连接标记颜色不变（品红/橙/青之一）。
3. 对每条细条，在最右列找到与其连接标记同色的目标像素。
4. 水平平移整条细条（含标记），使标记像素移到目标像素的左侧相邻位置（即标记列 = 目标列 - 1，标记行 = 目标行）。
5. 平移后，擦除最右列的目标像素和细条的连接标记像素（设为黑(0)）。
6. 输出为包含三条平移后细条的最小边界矩形，背景为黑(0)。

**关键洞察**：条的颜色由长度排名决定（最长=蓝，最短=红），但条的垂直位置由连接标记的对接决定——最右列目标像素的排列顺序独立于长度排名。因此颜色和位置由两套独立规则控制，输出中蓝/黄/红条的上下排列不可从长度排名直接推断，必须同时理解对接机制。

## 新题 10：嵌套空心框按深度选择控制色填充

**组合逻辑**：[洪泛填充(flood_fill) + 封闭区域(enclosed_region)](已有) + [包围(enclosure)](创新：嵌套深度作为新的空间关系) → [列范围包含(column_span_contains) + 控制色决定填色(control_fill_color)](已有) → [图层优先级(layer_priority)](创新：嵌套深度决定填充优先级)

**来源原语**：洪泛填充/封闭区域/空心矩形/包围 ← c0f76784；列范围包含/控制像素/控制色决定填色 ← ddf7fa4f；图层优先级 ← 281123b4, e99362f0

**依赖链**：空心框检测 → 嵌套关系判定（哪个框包含哪个框） → 每个框的列范围匹配控制像素确定候选填充色 → 嵌套深度决定填充优先级（内层覆盖外层）。框的列范围可能包含多个控制像素（外层框范围宽），此时取嵌套深度最深的匹配作为该框的填充色。

**输入结构**：
- 约 15x15 的网格，背景为黑(0)。
- 3~5 个灰(5)空心矩形框（仅边框为灰，内部为黑）。部分框嵌套在其他框内部（内层框完全在外层框的内部空间中），嵌套深度最多 3 层。框的边框像素互不重叠。
- 顶行（第 0 行，不与任何框的边框重叠）有若干单像素控制标记，颜色互不相同，取自 {蓝(1), 红(2), 绿(3), 黄(4), 品红(6)}。
- 生成约束：每个空心框的列范围（左边框列到右边框列）恰好包含至少一个控制像素的列。最内层框的列范围恰好包含一个控制像素。外层框的列范围可能包含多个控制像素（因为它跨度更大，可能覆盖内层框对应的控制像素的列以及其他控制像素的列）。

**规则**：
1. 识别所有灰(5)空心矩形框（边框为灰的 4-连通矩形环，内部为黑或包含更小的框）。
2. 判定嵌套关系：若框 A 的边框完全在框 B 的内部空间中，则 A 是 B 的子框。建立嵌套树。根节点是最外层框（不被任何框包含）。
3. 对每个框，找到其列范围 [左边框列, 右边框列] 内所有控制像素。
4. 在匹配到的多个控制像素中，选择列坐标距该框中心列最近的那个控制像素（若距离相同，取列坐标较小的），该控制像素的颜色即为该框的填充色。
5. 从最外层框开始，由外向内逐层填充：将每个框的内部黑(0)像素填为其填充色。内层框的填充覆盖外层框的填充（内层优先）。
6. 灰(5)边框保持不变。控制像素保持不变。框外部的黑(0)背景保持不变。

**关键洞察**：外层框的列范围通常包含多个控制像素的列（因为它也覆盖了内层框对应的控制像素），因此不能简单取"范围内的唯一控制像素"——必须用最近距离规则选取。嵌套深度决定填充覆盖优先级：内层框的颜色总是覆盖外层框的颜色，使最终输出呈现出同心矩形环状的多色分层效果。
