## 新题 1：环路凹弯数决定同心填充深度

**组合逻辑**：[环路追踪 + 分类涂色](弯折分类从着色用途变为计数用途) → [同心层填充](填充深度由外部计算值参数化，而非无限填满) + [奇偶距离决定颜色]

**来源原语**：环路追踪/分类涂色/闭合正交环路/弯折像素(15663ba9) + 同心层填充/奇偶距离决定颜色/控制像素/以控制点为中心(b7fb29bc) + 封闭区域(a8d7556c)

**依赖链**：环路追踪产出凹弯计数 K → K 成为同心填充的最大层深 → 填充范围由 K 和控制点位置共同决定。删除环路追踪则无法得到 K；删除同心填充则 K 无处使用；两者紧耦合。

对每条闭合环路，统计其凹弯数量，然后在环路围成的区域内以控制点为中心画同心方环，仅画到第 K 层（K = 凹弯数）。

**输入结构**：黑(0)背景网格，约 20x20。蓝(1)像素形成若干 4-连通单像素宽的闭合正交环路（每条环路的每个前景像素恰好度数为 2）。每条环路围成的内部区域中恰好有一个绿(3)控制像素。不同环路的复杂度不同：有的环路近似矩形（几乎无凹弯），有的环路有较多凹角（如 U 形、L 形拼合的不规则闭合轮廓，凹弯数在 1~6 之间）。各环路互不相交且互不嵌套。生成约束：每条环路内部区域的最小内切距离（从控制点到最近环路像素的 Chebyshev 距离）不小于该环路的凹弯数，以保证填充层不超出内部区域。

**规则**：
1. 对每条蓝(1)闭合环路，沿环路追踪像素序列，在每个像素处判断转向方向。多数转向方向为凸弯，少数转向方向为凹弯，直行像素既不是凸也不是凹。统计该环路的凹弯数量 K。
2. 蓝(1)环路像素本身保持不变，不做凸/凹着色。
3. 对环路内部的每个黑(0)背景像素，计算其到该环路内绿(3)控制像素的 Chebyshev 距离 D。
4. 若 D <= K：D 为奇数时涂黄(4)，D 为偶数（含 D=0，即控制点本身已为绿(3)不改）时涂红(2)。
5. 若 D > K：保持黑(0)不变。
6. 绿(3)控制像素保持不变。

**关键洞察**：环路的几何复杂度（凹弯数量）直接量化为同心环的层数上限。一个简单矩形环路（0 个凹弯）内部不会出现任何填充；而一个带 4 个凹弯的复杂环路内部会出现 4 层同心方环。必须对比多个示例中不同环路的凹弯数与填充层数的对应关系才能归纳出此规则。

## 新题 2：叠加涌现闭合环路后分类弯折

**组合逻辑**：[透明叠加](叠加不是终点，而是创造新几何结构的前置步骤) → [环路追踪 + 分类涂色](作用于叠加涌现出的环路，而非预先存在的环路)

**来源原语**：透明叠加/双面板对齐/分隔行/任一前景即输出(506d28a5) + 环路追踪/分类涂色/闭合正交环路/弯折像素/多数转向为凸/少数转向为凹(15663ba9)

**依赖链**：叠加产出新的几何形状 → 形状中涌现出闭合环路 → 环路追踪与弯折分类作用于涌现结构。单独任一面板不含闭合环路，故无法独立进行追踪；不做追踪则叠加结果缺少颜色分类。

将两个面板中各自不闭合的开放路径叠加合并，使之形成闭合环路，然后对涌现出的环路进行弯折分类着色。

**输入结构**：黑(0)背景网格，约 12x25（宽大于高）。中间有一整行灰(5)分隔行，将网格分为上下两个等大面板。上面板包含蓝(1)像素组成的若干不闭合的正交折线路径（4-连通，单像素宽，每条路径两个端点位于面板边缘或在面板内部自由终止）。下面板包含红(2)像素组成的若干不闭合的正交折线路径，结构类似。每条路径为 5~15 个像素的折线段。生成约束：上下面板的路径经叠加后，在对应位置恰好首尾相接形成若干闭合正交环路（每个前景像素度数恰好为 2），不会出现 T 形交叉或度数 >= 3 的节点。上面板路径端点的对应位置在下面板中恰好有路径端点与之衔接。

**规则**：
1. 移除灰(5)分隔行。将上面板与下面板逐像素对齐。
2. 任一面板中有前景像素的位置，在输出中变为绿(3)。
3. 合并后的绿(3)像素形成若干闭合正交环路。对每条环路进行追踪。
4. 在每个前景像素处判断转向：直行像素保持绿(3)；多数转向方向（凸弯）的像素涂黄(4)；少数转向方向（凹弯）的像素涂红(2)。
5. 输出网格的尺寸为单个面板的尺寸（即去掉分隔行后的半高宽度不变）。

**关键洞察**：闭合环路不存在于任何一个面板中，它们仅在叠加后涌现。求解者必须先识别叠加规则，再识别环路的形成，最后应用弯折分类。仅凭单个示例难以区分"叠加后直接涂绿"和"叠加后还要做弯折分类"，需要对比多个示例中不同弯折位置的颜色差异才能归纳完整规则。

## 新题 3：重力激活容器后容器发射水平射线

**组合逻辑**：[重力下落 + 填充](容器从填充终点变为射线发射源) → [射线延伸](射线源不再是十字图案的臂端，而是被激活容器的开口) + [面积排名](解决射线冲突的仲裁机制，而非直接用于重涂色)

**来源原语**：重力下落/填充/容器/列对齐落入/标记像素/无容器则铺满底行(db7260a4) + 射线延伸/遇前景终止(f8be4b64) + 面积排名(a8d7556c)

**依赖链**：重力下落判定哪些容器被激活 → 被激活容器的开口位置决定射线起点 → 射线碰撞时面积排名决定胜出色。三步缺一不可：不做重力则不知哪些容器激活；不发射线则激活无后果；不做面积仲裁则射线交叉无解。

从顶行标记像素向下做重力下落，落入容器则激活并填充；被激活的容器从开口向左右发射水平射线，射线交叉时小面积容器胜出。

**输入结构**：黑(0)背景网格，约 18x15。红(2)像素组成 2~4 个开口朝上的 U 形容器（两根竖直侧壁 + 一段水平底部，侧壁高 2~5 像素，底部宽 2~6 像素，内部全为黑(0)），分布在网格的中部和下部，互不相邻。灰(5)单像素标记点位于网格的第 0 行（最顶行），每个标记点的列坐标落在某个容器的水平脚印范围内（即该列位于容器左壁和右壁之间，含边界）。橙(7)水平条（1 像素高，2~4 像素宽）散布在容器之间的空白区域，作为射线障碍物。生成约束：每个标记点最多对应一个容器；至少有一个容器的水平脚印内无标记点（未激活容器）；标记点下落路径上无障碍物（即标记点所在列在标记点行与容器开口行之间无非背景像素）。

**规则**：
1. 对每个灰(5)标记像素，沿其所在列向下检查。若该列落入某个 U 形容器的水平脚印范围内，且容器开口（顶部）与标记像素之间无非背景像素阻挡，则激活该容器：将容器内部（侧壁与底部围成的矩形空间中的黑(0)像素）全部涂绿(3)。同时擦除该标记像素（变为黑(0)）。
2. 若标记像素所在列无容器承接，则将该列的最底行像素涂绿(3)，擦除标记像素。
3. 对每个被激活（内部已涂绿(3)）的容器，从其内部最顶行的最左像素向左发射一条绿(3)水平射线，从其内部最顶行的最右像素向右发射一条绿(3)水平射线。射线逐像素延伸，遇到任何非背景像素（红(2)容器壁、橙(7)障碍、或另一条绿(3)射线）时停止，不包含终点像素。
4. 若两条来自不同容器的射线到达同一像素（仅在两条射线同时从两侧逼近同一空像素时发生），则该像素取内部面积较小的容器的射线颜色——但由于两条射线颜色均为绿(3)，实际效果为像素涂绿(3)，但在该像素上方额外涂一个品红(6)标记点（用于标识冲突位置）。若两容器内部面积相同，冲突像素涂黄(4)。
5. 未激活的容器（内部未填充）、橙(7)障碍、红(2)容器壁均保持原色不变。

**关键洞察**：容器在源题中是被动接收容器，这里变成主动射线发射源。重力下落不只决定填充，还间接决定哪些射线会出现在网格中。射线冲突的仲裁依据是容器面积而非颜色或位置，需要对比多个示例中不同面积容器的冲突结果才能发现"小面积优先"规则。

## 新题 4：膨胀通道重新划定区域后按面积排名涂色

**组合逻辑**：[膨胀求交](通道从高亮目标变为拓扑边界) → [重涂色 + 面积排名](排名作用于通道重定义后的区域，而非预存的连通分量)

**来源原语**：膨胀求交/路径组件/两路径间隙重叠区/通道/连通至边缘的部分(f1bcbc2c) + 重涂色/封闭区域/连通分量/面积排名/分量最大矩形涂(a8d7556c)

**依赖链**：膨胀求交找到通道 → 通道像素作为新边界加入前景 → 新边界改变了背景区域的连通性和面积 → 面积排名对重新划定的区域涂色。不找通道则区域划分不对；不做面积排名则通道无后续影响。

识别两条平行路径之间的膨胀中线通道，将通道视为新增边界，然后对被路径和通道共同分割出的背景封闭区域按面积排名涂色。

**输入结构**：黑(0)背景网格，约 18x18。橙(7)像素形成恰好两条 4-连通单像素宽的路径组件，大致平行（间距 2~3 像素），从网格上部延伸到下部，路径有弯折但不闭合，两端可能到达网格边缘或在网格内终止。两条路径之间的间隙为 2~3 像素宽。路径和网格边缘共同围成若干黑(0)背景封闭区域。生成约束：两条路径的膨胀交集恰好形成一条连续的单像素宽通道；通道至少有一个连通分量与网格顶边相连；路径和通道将背景分割为至少 3 个不同面积的封闭区域（4-连通意义下的连通分量）。

**规则**：
1. 对两条橙(7)路径组件分别做 8-邻域膨胀一格，取两次膨胀的交集，得到中间通道像素集合。
2. 将通道中与网格顶边相连的那个连通分量涂青(8)。此连通分量的像素在后续步骤中视为前景（边界）。
3. 现在前景由橙(7)路径 + 青(8)通道组成。计算所有被前景和网格边缘共同围成的黑(0)背景区域（4-连通连通分量）。
4. 将这些背景区域按像素面积从大到小排名。面积最大的区域涂红(2)，面积第二大的涂蓝(1)，面积第三大的涂绿(3）。若有更多区域，第四大涂黄(4)，第五大涂灰(5)，依此类推。若两个区域面积相同，边界框左上角更靠左上（先比行号小、再比列号小）的区域排名靠前。
5. 橙(7)路径和青(8)通道像素保持不变。

**关键洞察**：通道在源题中是最终输出的高亮区域，这里却变成了重新划分背景区域的隐形边界。如果不先找到通道，两条路径之间的间隙是一个连续的背景区域；加入通道后，这个间隙被分割成多个更小的独立区域。面积排名操作的对象完全依赖于通道识别的结果。求解者需要对比多个示例才能发现通道的"边界"角色（而非简单的"高亮"角色）。

## 新题 5：复制旋转角落图案后以图案像素为锚计算距离场

**组合逻辑**：[图案复制 + 旋转](复制的图案不是装饰终点，而是后续距离计算的锚点集) → [同心层填充](距离目标从单一控制点变为一组分布式锚点的最近距离) + [奇偶距离决定颜色]

**来源原语**：图案复制/旋转/空心框/角落标记/源角到目标角映射/各角独立着色(4c416de3) + 同心层填充/以控制点为中心/奇偶距离决定颜色/矩形边框(b7fb29bc)

**依赖链**：角落图案复制+旋转确定了所有图案像素的位置 → 这些位置构成距离场的锚点集 → 每个内部像素到最近锚点的 Chebyshev 距离决定颜色。不做复制旋转则锚点缺失（只有源角有图案）；不做距离填充则复制无后续效应。

在空心矩形框的各角落复制旋转一个源图案，然后以所有图案像素为锚点集合，对框内部做基于最近锚点 Chebyshev 距离的奇偶着色。

**输入结构**：黑(0)背景网格，约 20x20。灰(5)像素构成一个空心矩形框（单像素宽边框，内部约 14x14 的黑(0)区域）。框的一个角落（如左上角）有一个由蓝(1)像素绘制的小图案（3~5 像素），图案沿该角落的内对角线方向分布（即从角落向内部延伸），图案关于该角落的内对角轴对称。其余 1~3 个角落的内对角线上各有一个不同颜色的单像素标记：如红(2)、绿(3)、黄(4)，标记位于图案最深偏移量 (k,k) 对应的位置。生成约束：图案的最大偏移量 k 不超过 4；各角落图案复制后互不重叠；框内部足够大使得距离场有意义（内部宽高均 >= 2k+4）。

**规则**：
1. 识别源角落（已有多像素图案的角落）及其图案。提取图案相对于角落的坐标偏移（规范化为左上角朝向）。
2. 对每个有单像素标记的非源角落，将规范化图案旋转到该角落的朝向（右上旋转 90 度、右下旋转 180 度、左下旋转 270 度），用该角落标记的颜色绘制图案。标记像素本身被图案覆盖。
3. 现在框的每个有标记的角落都有各自颜色的图案。收集所有图案像素（含源角落的蓝(1)像素和各目标角落的彩色像素）的坐标，形成锚点集合 A。
4. 对框内部每个黑(0)背景像素 p，计算 p 到锚点集合 A 中最近点的 Chebyshev 距离 D = min_{a in A} max(|p.row - a.row|, |p.col - a.col|)。
5. D 为奇数时涂品红(6)，D 为偶数（含 D=0，但 D=0 的位置已是图案像素不会再涂）时涂橙(7)。
6. 灰(5)框像素、所有图案像素保持各自颜色不变。

**关键洞察**：在源题中，角落图案复制是最终装饰；在源题中，同心填充以单个控制点为中心。这里，复制出的图案像素集合取代了单一控制点，成为分布式距离锚点。距离场的等值线不再是正方形环而是沿多个角落锚点形成的复杂沃罗诺伊样图案。必须先正确完成复制旋转，才能得到正确的距离场。

## 新题 6：位置排序选取精灵体后以侧带标记裁剪印章

**组合逻辑**：[排序 + 每隔N选取](选取机制从重涂色变为决定哪些精灵参与印章) → [印章覆盖 + 标记颜色配对](配对方式从颜色变为排序后的序号对应) → [标记排除对应行列](排除机制从射线变为印章裁剪)

**来源原语**：排序/每隔N选取/按位置排序(22a4bbc2) + 印章覆盖/标记像素/标记颜色配对/相对坐标复制(414297c0) + 射线延伸/标记排除对应行列/侧边带对齐(9def23fe) + 擦除(ae3edfdc)

**依赖链**：位置排序 → 每隔 N 选取确定活跃精灵 → 活跃精灵按序号与内部标记配对 → 印章复制到标记位置 → 侧带排除标记裁剪印章输出。选取决定哪些精灵参与；配对决定放在哪里；排除决定哪些像素被剪掉。三层缺一不可。

将外部精灵体按位置排序后每隔一个选取，按序号与矩形内标记配对，印章复制到对应位置，但被侧带标记标记的行和列处的印章像素被裁剪掉。

**输入结构**：黑(0)背景网格，约 18x18。一个蓝(1)填充矩形（约 10x10）位于网格中心偏右。矩形内部散布 2~4 个橙(7)单像素标记点。矩形外部散布 4~6 个小型精灵体（每个精灵由同一颜色的 3~6 个 4-连通像素组成，颜色各不相同，从红(2)、绿(3)、黄(4)、灰(5)、品红(6)中取），各精灵互不相邻。在矩形的四个侧带区域（矩形上方与矩形同列的区域、下方同列、左方同行、右方同行），散布若干栗(9)单像素标记点。生成约束：精灵数量 >= 内部橙(7)标记数量 x 2；侧带标记使得矩形的某些行和列被标记为排除（但不是全部行列都被排除）；印章相对偏移不超出矩形边界（裁剪后的印章至少保留 1 个像素）。

**规则**：
1. 识别所有矩形外部的精灵体。按每个精灵边界框的左上角位置排序（先按行号从小到大，行号相同则按列号从小到大）。
2. 从排序结果中选取排名为 1, 3, 5, ... 的精灵（即每隔一个选取，从第 1 个开始）。这些为"活跃精灵"。
3. 将活跃精灵按选取顺序与矩形内部的橙(7)标记点配对：第 1 个活跃精灵对应行号最小（行号相同则列号最小）的内部标记，第 2 个对应第 2 个标记，依此类推。若活跃精灵数量多于标记点数量，多余的精灵不参与。
4. 对每个配对，计算精灵中每个像素相对于精灵所含标记点（若精灵不含标记点，则以精灵边界框中心最近的像素为基准）的行列偏移，将这些偏移应用到对应的内部标记点位置，在蓝(1)矩形上用精灵的颜色绘制。
5. 检查栗(9)侧带标记：对矩形上方或下方的每个栗(9)标记，其所在列对应的矩形列为"排除列"；对矩形左方或右方的每个栗(9)标记，其所在行对应的矩形行为"排除行"。
6. 在排除行和排除列上的印章像素被擦除（恢复为蓝(1)矩形填充色）。内部橙(7)标记点保持不变。栗(9)侧带标记保持不变。
7. 未被选取的精灵从输出中擦除（变为黑(0)背景）。被选取的精灵也从原始位置擦除。

**关键洞察**：每隔 N 选取的 N 值（此处为 2）在源题中直接可见（每隔 3 个），但这里需要对比多个示例才能确定间隔值。同时，侧带排除机制在源题中用于射线，这里用于裁剪印章像素，作用方式完全不同。选取、配对、裁剪三层逻辑交织：改变任一层都会改变最终输出。

## 新题 7：滑动压缩区域后按原始围合面积解决重叠

**组合逻辑**：[滑动](从移动单像素变为移动整个连通区域) → [面积排名](排名依据不是当前面积，而是滑动前的围合背景面积) → [重涂色](按排名结果涂色)

**来源原语**：滑动/行列对齐/压缩到标记旁/擦除(ae3edfdc) + 重涂色/封闭区域/连通分量/面积排名(a8d7556c) + 标记像素(db7260a4)

**依赖链**：每个区域的围合背景面积在滑动前计算 → 滑动改变区域位置导致重叠 → 重叠像素归属由滑动前面积排名决定 → 最终按排名重涂色。面积必须在滑动前算（滑动后区域形状不变但围合关系变了），滑动后才出现重叠需仲裁。

将前景连通区域沿行或列滑动到对齐的标记点旁，重叠区域归属于滑动前围合背景面积更大的区域，最后按面积排名统一重涂色。

**输入结构**：黑(0)背景网格，约 16x16。蓝(1)像素形成 3~4 个互不相邻的 4-连通前景区域，每个区域为 5~10 像素的不规则形状（非矩形，有凹凸），部分区域围合了一小块黑(0)背景（即区域内部有孔洞或凹陷形成的封闭背景区域）。红(2)单像素标记点散布在网格中。每个前景区域与恰好一个标记点共享同一行或同一列（但不同时共享行和列）。生成约束：每个前景区域对应唯一一个标记点；滑动方向无歧义（每个区域与其标记在同行或同列中恰好只有一种选择）；滑动后至少有两个区域发生重叠；滑动距离为正数（区域与标记之间有间隔）。

**规则**：
1. 对每个蓝(1)前景区域，找到与该区域围合关系对应的封闭背景面积：将该区域视为边界，计算其内部（被该区域的像素在 4-连通意义下完全围合的）黑(0)背景像素数量。若区域不围合任何背景（无封闭内部），则围合面积为 0。记录每个区域的围合面积。
2. 对每个区域，找到与其共享行或列的唯一红(2)标记点。沿共享的行（若共享行）或列（若共享列），将整个区域平移（所有像素同步移动）直到区域的最近边界像素与标记点相邻（Chebyshev 距离 = 1）。擦除区域的原始位置像素。
3. 滑动后若两个或更多区域的像素重叠在同一格，该格归属围合面积最大的区域。若围合面积相同，则归属于滑动前边界框面积（高 x 宽）更大的区域。若仍相同，归属于滑动前边界框左上角行号更小的区域。
4. 对最终确定归属后的所有区域，按围合面积从大到小排名。排名第 1 的区域涂绿(3)，第 2 涂黄(4)，第 3 涂品红(6)，第 4 涂橙(7)。围合面积为 0 的区域保持蓝(1)不变。
5. 红(2)标记点保持不变。

**关键洞察**：重叠仲裁和最终着色都依赖于"围合背景面积"这个在滑动前才有意义的属性。滑动后，区域的邻接关系改变，围合关系也可能改变（原来围合的背景可能因移动而暴露）。求解者必须意识到面积是在滑动前计算的——这一点只有对比多个示例（不同围合面积的区域在不同重叠情境中的优先级）才能确认。

## 新题 8：共享侧带标记同时约束射线延伸与同心环填充

**组合逻辑**：[射线延伸 + 标记排除对应行列] ⊗ [同心层填充 + 奇偶距离决定颜色]（两个操作共享同一组约束标记，非流水线而是同时约束满足）

**来源原语**：射线延伸/实心矩形/标记排除对应行列/侧边带对齐/延伸条纹(9def23fe) + 同心层填充/矩形边框/控制像素/以控制点为中心/奇偶距离决定颜色(b7fb29bc) + 标记像素(多题共有)

**依赖链**：一组标记同时控制两种操作——标记排除射线延伸的行列，同时排除同心环填充的行列。不做任一操作都会导致另一操作的排除规则看起来毫无关联。两种操作通过共享约束耦合，而非通过数据流串联。

在矩形框内以控制点为中心画同心方环，同时从矩形向四周延伸射线条纹，但侧带标记同时禁止对应行列的环填充和射线延伸。

**输入结构**：黑(0)背景网格，约 18x18。蓝(1)像素组成一个实心矩形（约 8x8），位于网格中心。矩形内部有一个绿(3)控制像素。在矩形的四个侧带区域（矩形正上方与矩形同列的区域、正下方同列、正左方同行、正右方同行，不含对角区域），散布若干红(2)单像素标记。生成约束：控制像素不位于矩形的边界行/列上（至少离边界 2 格）；每个侧带标记恰好位于矩形对应边的外侧 1~3 格处；被标记排除的行/列不超过矩形行/列总数的一半。

**规则**：
1. 识别蓝(1)实心矩形、绿(3)控制像素、红(2)侧带标记。
2. **射线延伸**（矩形外部）：对矩形的上侧和下侧，沿每个矩形列向上/向下延伸蓝(1)射线至网格边缘——但若该列在对应侧（上方或下方）有红(2)标记，则该侧该列不延伸。对矩形的左侧和右侧，沿每个矩形行向左/向右延伸蓝(1)射线至网格边缘——但若该行在对应侧（左方或右方）有红(2)标记，则该侧该行不延伸。射线遇到红(2)标记像素时在标记前一格停止（标记保持红(2)不变）。
3. **同心环填充**（矩形内部）：对矩形内部的每个蓝(1)像素（非控制像素），计算其到绿(3)控制像素的 Chebyshev 距离 D。D 为奇数时涂黄(4)，D 为偶数时涂灰(5)。但若该像素所在的行或列被任一侧带标记排除（即该行在左方或右方有红(2)标记，或该列在上方或下方有红(2)标记），则该像素保持蓝(1)不变（即被排除的行列上不画同心环）。
4. 绿(3)控制像素保持不变。红(2)标记保持不变。

**关键洞察**：同一组红(2)标记同时控制了两种不同的空间操作——外部的射线延伸和内部的同心环填充。在源题中，侧带标记只影响射线；在源题中，同心填充无任何排除机制。这里两者共享约束源，形成同时约束满足结构而非流水线。求解者需要对比多个示例才能同时发现标记的双重作用：仅看射线部分会以为标记只影响外部，仅看内部会以为某些行列"恰好"未填充。

## 新题 9：块顺序排序由通道连通性决定

**组合逻辑**：[膨胀求交 + 连通至边缘的部分](通道连通分析从输出目标变为排序依据的编码) → [排序 + 整块移动保持内容](排序键不再是标记行顺序，而是通道连通结构编码的顺序)

**来源原语**：膨胀求交/路径组件/通道/连通至边缘的部分/两路径间隙重叠区(f1bcbc2c) + 排序/色块条带/整块移动保持内容/标记行指示顺序(f18ec8cc)

**依赖链**：每对相邻色块条带之间的边界可视为两条路径 → 膨胀求交找到它们的中线通道 → 通道是否连通到顶边决定该边界的"开放"状态 → 开放边界的数量和位置编码了排序规则。不做膨胀求交则排序依据不可知；不做排序则通道分析无后果。

分析相邻色块条带边界的膨胀通道连通性，据此决定条带的重排顺序。

**输入结构**：黑(0)背景网格，约 6x20（高较小、宽较大）。网格被分为 4~5 个等宽的垂直色块条带，每个条带有唯一的主色（从蓝(1)、红(2)、绿(3)、黄(4)、灰(5)中取），条带内部全为该主色像素。相邻条带之间有 2 像素宽的黑(0)间隙。在某些间隙中，间隙的顶部 1~2 行被橙(7)像素填充（形成部分阻塞）；其余间隙保持全黑(0)。生成约束：至少有一个间隙被部分阻塞（有橙(7)像素），至少有一个间隙完全畅通（全黑(0)）。

**规则**：
1. 将每个间隙的左右两个条带的边缘列各视为一条垂直路径组件（1 像素宽）。对这两条路径做 8-邻域膨胀一格后取交集，得到该间隙的中线通道（1 像素宽垂直线段）。
2. 检查中线通道是否有连通分量与网格顶边相连。若间隙中有橙(7)阻塞像素挡在顶部，则通道在阻塞处断开——顶部连通分量可能不存在或仅覆盖阻塞以上的部分。定义一个间隙为"开放"的当且仅当其中线通道存在从网格顶边到网格底边的完整连通路径（不被阻塞中断）。
3. 统计"开放"间隙的数量 M。
4. 若 M = 0（所有间隙都被阻塞）：保持条带顺序不变。
5. 若 M >= 1：将所有条带从左到右编号 1, 2, ..., N。将编号最小的 M 个条带（即最左边的 M 个条带）循环右移到最右边，其余条带保持相对顺序不变并左移填补。移动时每个条带的内容完整保留。
6. 橙(7)阻塞像素随间隙位置不变（它们不属于任何条带）。间隙在条带重排后重新分布（保持 2 像素宽度），阻塞像素不随条带移动。

**关键洞察**：在源题中，排序规则由标记行直接给出；在源题中，通道连通性是一个输出高亮目标。这里，通道连通性成为排序规则的**隐式编码**——求解者不会直接看到"移动 M 个条带"的指令，而是必须从间隙的物理特征中解码出 M 的值。需要对比多个示例中不同阻塞模式和不同排列结果才能归纳出完整规则。

## 新题 10：归一化朝向后按面板无冲突叠加

**组合逻辑**：[归一化朝向 + 宽高互换](归一化改变了矩形形状，从而改变空间占用和重叠判定) ⊗ [透明叠加 + 无重叠时叠加](叠加的冲突检测以归一化后的形状为准，而非原始形状)

**来源原语**：归一化朝向/矩形/宽高互换/每个矩形产生两份(d749d46f) + 透明叠加/面板/面板对应/分隔列/无重叠时叠加/前景掩码(bbb1b8b6)

**依赖链**：归一化改变矩形形状（宽高互换）→ 形状改变影响哪些位置有前景 → 叠加时的冲突检测以归一化后的位置为准。不做归一化则冲突判定基于原始形状（可能得出不同结果）；不做叠加则归一化无后续效果。

两个面板各含若干矩形，先将每个矩形归一化为横向（宽>=高），再检测逐矩形叠加冲突，仅将无冲突的右面板矩形叠加到左面板。

**输入结构**：黑(0)背景网格，约 12x25（宽大于高）。中间有一列灰(5)分隔列，将网格分为左右两个等大面板（约 12x12 each）。每个面板包含 2~4 个互不重叠的实心矩形（每个矩形为单色填充，颜色各不相同，从蓝(1)、红(2)、绿(3)、黄(4)、品红(6)中取）。矩形尺寸为 2x4 到 4x6 不等，有的是竖长型（高>宽），有的是横宽型（宽>=高）。左右面板中矩形的位置有部分对应关系但不完全对齐。生成约束：至少有一个右面板矩形在归一化后与左面板矩形冲突（重叠），至少有一个不冲突；归一化操作对至少一个矩形会改变其冲突状态（即原始形状不冲突但归一化后冲突，或反之）。

**规则**：
1. 移除灰(5)分隔列。
2. 对左面板和右面板中的每个矩形，将其归一化为横向朝向：若矩形的高 > 宽，则将其旋转 90 度（即宽高互换），旋转以矩形边界框的左上角为锚点（左上角位置不变，矩形向右下方展开）。若宽 >= 高，保持不变。
3. 以归一化后的左面板为画布。对右面板中的每个矩形（归一化后），检查其在左面板对应位置上是否与任何左面板归一化后的矩形前景像素重叠。
4. 若该右面板矩形与任一左面板矩形有像素级重叠，则忽略该右面板矩形（不叠加）。
5. 若该右面板矩形与所有左面板矩形均无重叠，则将其以自身颜色复制到左面板对应位置上。
6. 输出仅保留左面板大小的网格（去掉分隔列和右面板区域）。

**关键洞察**：归一化操作可能使一个原本不与左面板冲突的竖长矩形在横向展开后发生冲突（因为横向占用更多列），也可能使一个原本冲突的竖长矩形在归一化后恰好避开冲突。求解者必须先推断归一化规则（宽高互换），再判断冲突，顺序不能颠倒。需要对比多个示例中不同形状矩形的冲突结果才能区分"原始形状判冲突"和"归一化后判冲突"。
