## 新题 1：重力沉降后的模板形状涌现与重涂

**组合逻辑**：[滑动/重力沉降](原有) -> [连通分量重构](创新：重力改变连通关系，使原本分离的对象合并为新形状) -> [归一化形状比对 + 匹配模板则重涂](原有)

**来源原语**：滑动/重力沉降/列内独立（1e0a9b12）、归一化形状比对/匹配模板则重涂/连通分量/模板对象（4ff4c9da）、重涂色（4ff4c9da）

**依赖链**：重力改变像素的纵向位置 -> 列内像素堆叠导致原本分离的同色连通分量合并为新形状 -> 新形状与模板进行归一化比对 -> 匹配者被重涂为模板色。重力结果决定了哪些像素相邻进而决定了哪些形状存在，形状比对筛选出重涂目标。删除重力环节则连通分量不变、无法产生匹配形状；删除比对环节则无法确定重涂目标。

所有前景像素在列内下沉后，与模板形状匹配的新连通分量被重涂为模板色。

**输入结构**：
- 黑(0)背景，约 12x12 网格
- 网格中散布多个小型单色 4-连通对象（每个 2~5 像素），使用蓝(1)和红(2)两种颜色，分布在网格中上部区域
- 恰好一个青(8)对象作为模板（3~5 像素，4-连通），固定于网格底行且其下方无空位（重力不影响它）
- 各对象初始互不相邻（8-连通意义下不接触），但在同一列中某些不同高度的同色对象之间仅有空行间隔
- 网格宽度约 12 列，确保列内重力后不同对象能合并
- 生成约束：至少两个同色对象在重力沉降后因列内堆叠而合并为一个新 4-连通分量，该新分量的平移归一化掩码与青(8)模板完全一致；至少一个对象沉降后形状不变且不匹配模板；模板本身的像素所在列中没有其他同色像素

**规则**：
1. 对所有非背景、非青(8)像素执行列内独立重力：每列中的蓝(1)和红(2)像素保持自上而下的相对顺序向下沉降，直到触碰已有非背景像素的上方或网格底边。青(8)模板像素视为障碍，不参与沉降。
2. 沉降完成后，以 4-连通方式对每种颜色独立重新计算连通分量。
3. 将青(8)模板对象的形状掩码平移归一化（将边界框左上角对齐至原点）。
4. 对每个非青连通分量，平移归一化其形状掩码并与模板掩码逐像素比对。若完全一致，将该分量所有像素重涂为青(8)。
5. 不匹配的连通分量保留其原色。模板对象本身和背景像素不变。
6. 处理顺序不影响结果（各分量的重涂互相独立）。

**关键洞察**：重力可使原本不相邻的同色像素在同一列内堆叠而合并为新连通分量——匹配模板的形状并非输入中已存在的，而是重力操作涌现出的。求解者必须先模拟重力再检查匹配，而非在原始布局中寻找模板。

## 新题 2：图元分解后绕独立枢轴旋转

**组合逻辑**：[分解/基本图元](原有) -> [最近枢轴分配](创新：每个分解出的图元独立选择最近枢轴，而非所有图元共享一个旋转中心) -> [旋转/点对称](原有) + [图元形状决定涂色](原有)

**来源原语**：分解/基本图元/图元形状决定涂色（150deff5）、旋转/点对称/枢轴像素/绕枢轴半周旋转（90347967）

**依赖链**：分解确定旋转的作用单元和各单元形状 -> 各图元独立计算到枢轴的距离并分配最近枢轴 -> 围绕各自枢轴 180 度旋转 -> 图元形状类别决定最终颜色。分解方案影响图元中心位置，进而影响枢轴分配；不同分解可能导致同一枢轴被分配到不同数量的图元。

将灰色复合形状分解为基本图元，每个图元绕最近的枢轴像素旋转 180 度后按形状类别着色。

**输入结构**：
- 黑(0)背景，约 10x15 网格
- 1~2 个灰(5)复合形状，每个由若干 2x2 正方形和 1x3 或 3x1 矩形无重叠拼接而成（总计 3~5 个基本图元），图元之间共享边或角相邻
- 2~3 个绿(3)单像素枢轴，分散在网格空白区域，不与灰(5)形状重叠
- 生成约束：每个图元分解方案唯一（不存在两种不同的合法分解）；每个图元中心到最近枢轴的欧氏距离严格唯一（无平局）；至少存在两个图元被分配到不同枢轴的情况；所有图元旋转后的位置在网格内部且互不重叠，也不与枢轴像素重叠

**规则**：
1. 将每个灰(5)复合形状分解为不重叠的 2x2 正方形和 1x3/3x1 矩形。分解方案唯一。
2. 对每个图元，计算其所有像素坐标的算术平均值作为中心点 (cr, cc)。找到欧氏距离 sqrt((cr-pr)^2 + (cc-pc)^2) 最小的绿(3)枢轴像素 (pr, pc)。
3. 将图元的每个像素 (r, c) 映射到 (2*pr - r, 2*pc - c)，即绕该枢轴 180 度旋转。
4. 旋转后着色：2x2 正方形涂为青(8)，1x3/3x1 矩形涂为红(2)。
5. 原始灰(5)像素位置全部清除为背景(0)。
6. 绿(3)枢轴像素保留。若旋转后像素落在枢轴位置上，枢轴像素保持绿(3)不被覆盖。

**关键洞察**：同一复合形状的不同图元可能被分配到不同枢轴，导致它们旋转到完全不同的方向和位置；分解结果隐式决定了每个图元的中心，从而决定了枢轴分配。求解者需同时推断分解方案和枢轴分配规则。

## 新题 3：极角排序构建多边形轮廓后按内部标记填色

**组合逻辑**：[描边连线/极角排序](原有) + [路径需通畅/忽略干扰项](原有) -> [填充/封闭孔洞](创新：填充颜色不由轮廓色决定，而由封闭区域内部包含的标记像素颜色决定) + [内部包含](创新：标记-区域对应关系由空间包含而非行列对齐确定)

**来源原语**：描边连线/极角排序/轮廓顶点/忽略干扰项/路径需通畅（35ab12c3）、填充/封闭孔洞/仅填矩形内部（e73095fd）、单像素标记/对齐标记定颜色（ef26cbf6，但此处改为包含关系）、内部包含（3de23699）

**依赖链**：极角排序确定顶点连接顺序 -> 路径通畅检查筛选可绘制边 -> 可绘制边围成封闭区域 -> 区域内部的标记像素颜色决定填充色。轮廓定义了区域边界，标记决定了填充颜色，干扰像素同时影响哪些边可以绘制和哪些区域被封闭。

按极角排序连接顶点构建多边形轮廓，用封闭区域内标记像素的颜色填充该区域。

**输入结构**：
- 黑(0)背景，约 15x15 网格
- 6~10 个蓝(1)顶点像素，它们按极角排序后可构成一个封闭多边形（或两个不相交的封闭多边形，各自独立排序）
- 1~3 个橙(7)干扰像素，位于网格中，可能挡在某些顶点对之间的连线路径上
- 每个可封闭区域内部恰好有一个单像素标记，颜色各不相同（从红(2)、绿(3)、黄(4)中选取）
- 生成约束：相邻顶点的连线为水平、垂直或 45 度对角线方向之一；至少一条边的路径被橙(7)像素阻挡而无法绘制；被阻挡的边所对应的两个顶点之间无法通过该直线连接，但多边形的其余边仍能围成至少一个封闭区域；每个封闭区域面积至少 3 像素

**规则**：
1. 计算所有蓝(1)顶点像素的质心。以质心为原点、正右方为 0 度，计算每个顶点的极角，按极角从小到大排序形成循环序列。
2. 对循环序列中每对相邻顶点（包括末尾与首个之间），检查两者之间能否用一条 8 方向对齐的直线段连接（水平、垂直或 45 度对角线）。若两者不在同一行、同一列、也不在同一条 45 度对角线上，则该边不可绘制。
3. 对可绘制的边，检查连线路径上所有中间像素（不含两端顶点）：若全部为背景(0)或标记像素，则绘制该边（蓝(1)色）；若路径上存在橙(7)干扰像素，则该边不绘制。
4. 使用 flood fill 从网格四条边界的所有背景像素开始向内扩展（不穿越蓝(1)像素），标记所有可达的背景像素为"外部"。剩余未标记的背景连通区域（4-连通）即为封闭区域。
5. 对每个封闭区域：若其中包含恰好一个标记像素，则用该标记的颜色填充整个区域（包括标记像素自身的位置）。若区域内无标记像素则不填充。
6. 蓝(1)轮廓线保留。橙(7)干扰像素保留。

**关键洞察**：干扰像素同时扮演两个角色：阻断边的绘制使某些区域无法封闭，并且可能使看似会被同一轮廓包围的区域分裂为多个。填充颜色完全由区域内部的标记决定而非轮廓色，因此同一轮廓内不同区域可有不同颜色。

## 新题 4：象限编码旋转角的限数印章

**组合逻辑**：[印章覆盖/分隔网格/标记像素](原有) + [旋转](创新：旋转角度由标记像素在单元格内的象限位置隐式编码，而非显式标注) + [控制条/条长](创新：控制条长度不生成序列而是限制印章总数) + [标记相对方位/方位决定象限分配](原有，但此处"方位"指标记在格内的象限而非相对于外框)

**来源原语**：印章覆盖/模板图块/分隔网格/标记像素/仅标记格被覆盖（e734a0e8）、旋转（fd4b2b02/90347967）、控制条/条长决定序列（5d588b4d）、标记相对方位/方位决定象限分配（94414823）

**依赖链**：分隔网格定义单元格 -> 标记像素的格内象限位置编码旋转角 -> 模板按该旋转角印入标记格 -> 控制条长度限制实际执行的印章总数。三类独立信息（模板内容、旋转角、数量上限）分别由不同元素编码，求解者必须全部解码。

将模板图块按标记像素在单元格内的象限位置决定的旋转角印入标记单元格，总印章数受控制条长度限制。

**输入结构**：
- 黑(0)背景，约 15x15 网格
- 灰(5)完整分隔线（贯穿整行或整列的单像素线）将网格划分为 3x3 或 4x4 的等大矩形单元格，每个单元格内部为 3x3 或 4x4 像素
- 一个单元格内包含一个红(2)非对称精灵图（模板），占据单元格内部分像素（2~5 像素），形状非中心对称使得旋转后可区分方向
- 4~6 个其他单元格各包含一个绿(3)标记像素，分别位于单元格内部的不同象限位置
- 网格第 0 行（分隔线网格上方）有一条蓝(1)控制条，从第 0 列开始，长度为 n（2 <= n < 标记单元格总数）
- 剩余单元格为空

**规则**：
1. 识别包含红(2)精灵图的单元格为模板源，提取精灵图在单元格内的相对像素偏移。
2. 对每个含绿(3)标记的单元格，将单元格内部按行列中线等分为四个象限（若内部边长为奇数，中线像素归入左上象限）。确定标记像素所在象限：
   - 左上象限 -> 旋转 0 度
   - 右上象限 -> 顺时针旋转 90 度
   - 右下象限 -> 旋转 180 度
   - 左下象限 -> 顺时针旋转 270 度
3. 按阅读顺序（从左到右、从上到下扫描单元格）排列所有标记单元格，编号 1, 2, ..., k。
4. 仅对编号 1 到 n 的标记单元格执行印章：将模板按该格对应的旋转角度旋转后，以红(2)色印入该单元格（覆盖该格内的绿(3)标记像素，保持单元格内其余背景不变）。旋转以单元格中心为旋转锚点。
5. 编号 n+1 到 k 的标记单元格：清除其绿(3)标记像素为背景(0)。
6. 模板源单元格、灰(5)分隔线、蓝(1)控制条保持不变。

**关键洞察**：标记像素的颜色统一（全为绿色），不携带信息；真正的编码在其位于单元格内哪个象限——这决定了旋转角度。控制条长度是全局约束，限制了总印章数而非影响每个印章的内容。仅看一个示例可能无法分辨"是象限编码旋转还是某种固定旋转"。

## 新题 5：递增递减序列换行后遇障碍重力沉降

**组合逻辑**：[生成序列/换行平铺/条长决定序列](原有) -> [滑动/重力沉降/列内独立](原有) -> 创新交互：一维对称序列的二维换行图案被重力和障碍物重塑为非对称的堆积图案

**来源原语**：生成序列/换行平铺/控制条/递增递减游程/条长决定序列/长度递增后递减（5d588b4d）、滑动/重力沉降/列内独立/前景像素/画布边界（1e0a9b12）

**依赖链**：控制条长度决定序列内容 -> 序列换行为二维图案决定每列前景像素数量 -> 列内重力使前景像素下沉到障碍物上方或底边 -> 障碍物的逐列差异使得原本行内对称的序列变为参差不齐的堆积。序列结构决定"有多少像素要沉降"，障碍物位置决定"沉降到哪里停"，两者交互产生最终图案。

由控制条长度生成的递增递减游程序列换行平铺后，所有生成像素在各列内独立下沉，遇障碍物停止。

**输入结构**：
- 黑(0)背景，约 10x10 网格
- 第 0 行从第 0 列开始有一条红(2)控制条，长度 n（n 在 3~5 之间）
- 网格中散布 3~6 个灰(5)障碍像素，不在第 0 行，位置固定不动
- 除控制条和障碍物外，其余像素均为背景(0)
- 生成约束：网格高度足够容纳换行后的所有行加上重力沉降空间；至少两列的障碍物高度不同（含无障碍列），使得沉降后各列高度参差；障碍物不位于网格底行

**规则**：
1. 读取第 0 行红(2)控制条长度 n。
2. 生成一维前景游程序列：红(2)游程长度依次为 1, 2, ..., n, n-1, ..., 2, 1，相邻游程之间间隔恰好一个背景(0)像素。
3. 将第 0 行清除为全背景（控制条被消耗）。从第 1 行开始，将一维序列按网格宽度逐行填入（第一个元素放在第 1 行第 0 列，依次向右，满一行换到下一行第 0 列）。不足一整行的末尾以背景(0)补齐。
4. 对每一列独立执行重力沉降：该列中所有红(2)像素保持自上而下的相对顺序向下移动。每个红(2)像素下沉直到紧邻其正下方的灰(5)障碍物上方或网格底行，先到者为准。多个红(2)像素在同一列中依次堆叠（底部的先着陆，上方的堆叠在其上）。
5. 灰(5)障碍物不移动。若某列中障碍物上方空间不足以容纳该列所有下沉像素，多余像素依次堆叠在已着陆像素上方的连续单元格中。

**关键洞察**：换行平铺将一维对称序列映射为具有行内结构的二维图案，但重力消除了行结构，将像素重新按列堆积。最终图案既不保留序列的对称性，也不保留换行的行模式——它是序列生成规则与障碍物空间分布叠加的涌现结果。各列障碍物高度差异使沉降后的列高参差不齐。

## 新题 6：方位标记编码旋转的稠密化精灵体入框

**组合逻辑**：[稠密化/稀疏精灵体 + 加厚/稀疏边框](原有) + [旋转](创新：旋转角由精灵体旁标记像素的空间方位隐式编码) + [填入/等距排列入框/位置顺序](原有)

**来源原语**：稠密化/稀疏精灵体/稀疏边框/填入/等距排列入框/位置顺序/加厚（db615bd4）、旋转（fd4b2b02/90347967）、标记像素/标记相对方位（94414823）

**依赖链**：稠密化将稀疏表示转为实际形状 -> 标记像素方位编码旋转角 -> 位置顺序决定框内槽位 -> 旋转后的稠密精灵体插入对应槽位。稠密化改变精灵体尺寸和形状，旋转改变朝向，位置顺序决定排列，三者共同决定最终布局。

将外部稀疏精灵体稠密化后，按各自标记像素方位决定的旋转角旋转，再按位置顺序等距插入稠密化后的边框内。

**输入结构**：
- 黑(0)背景，约 15x20 网格
- 一个大型稀疏矩形边框：由灰(5)像素构成，像素位于二步点阵上（框的每条边上，每隔一个像素有一个灰(5)像素），描绘一个矩形周边
- 2~4 个外部稀疏精灵体，位于边框外部，每个由单一非背景非灰色颜色构成（例如红(2)、蓝(1)、绿(3)等不同颜色），像素同样位于二步点阵上（每个精灵体内部像素间隔一格）
- 每个精灵体的边界框外侧恰好有一个黄(4)标记像素，与该精灵体边界框的某一边相邻（在上方、右方、下方或左方的一格处）
- 精灵体形状非对称（不具备 90 度旋转对称性），使得旋转后朝向可区分
- 边框为宽型（宽度 > 高度）
- 生成约束：各精灵体稠密化后尺寸相同；框内空间足以等距容纳所有精灵体

**规则**：
1. 将稀疏边框加厚为实心单像素宽矩形边框（灰(5)色）：识别稀疏点阵描绘的矩形范围，在其四条边上绘制连续的灰(5)像素线。清除边框内部所有原始稀疏像素为背景。
2. 将每个稀疏精灵体稠密化：在其二步点阵上相邻像素之间的空格位置也填充为该精灵体的颜色，使精灵体成为连续掩码。
3. 确定每个精灵体的旋转角：检查黄(4)标记像素与精灵体边界框的相对位置：
   - 标记在上方（标记所在行 < 精灵体边界框最小行）-> 0 度（不旋转）
   - 标记在右方（标记所在列 > 精灵体边界框最大列）-> 顺时针 90 度
   - 标记在下方（标记所在行 > 精灵体边界框最大行）-> 180 度
   - 标记在左方（标记所在列 < 精灵体边界框最小列）-> 顺时针 270 度
4. 对稠密化后的精灵体应用对应旋转。
5. 按精灵体在输入中的从左到右位置顺序（以边界框最小列值为排序键，若相同则按最小行值排序）排列。
6. 将旋转后的精灵体等距放入框内部：水平间距 = (框内部宽度 - 所有旋转后精灵体总宽度) / (精灵体数 + 1)，向下取整。第 i 个精灵体的左边 x 坐标 = 框内左边界 + 间距 * i + 前 i-1 个精灵体的累计宽度。每个精灵体垂直居中于框内部（上下空余行数之差不超过 1，多余空行在下方）。
7. 清除所有黄(4)标记像素和原始位置的稀疏精灵体像素为背景(0)。

**关键洞察**：所有标记像素颜色统一为黄色，不编码任何信息——真正的编码在其相对于精灵体的空间方位（上/右/下/左），这隐式映射到旋转角度（0/90/180/270 度）。需对比多个示例才能发现"方位等于旋转角"的映射关系，因为仅看一个精灵体的标记位置无法排除其他可能的规则。

## 新题 7：双重筛选门控的射线发射

**组合逻辑**：[归一化形状比对/匹配模板则重涂](原有) + [射线延伸/像素为射线中心](创新：射线源不是所有前景像素，而是同时通过"形状匹配"和"附有控制标记"两道筛选的对象) + [控制像素](创新：控制标记的存在仅在匹配前提下才有效，不匹配的对象附近的标记成为干扰项)

**来源原语**：归一化形状比对/重涂色/匹配模板则重涂/模板对象/连通分量（4ff4c9da）、射线延伸/整行整列射线/像素为射线中心/控制像素/对角邻居（140c817e）

**依赖链**：模板形状比对筛选匹配对象（第一道门）-> 控制标记筛选有标记的匹配对象（第二道门）-> 双重通过者从质心发射全行全列射线。匹配是射线的必要条件，标记是附加要求。不匹配但有标记的对象是干扰项，匹配但无标记的对象只重涂不射线。

所有与模板形状匹配的对象被重涂，其中附有控制标记的匹配对象还从其质心发射全行全列射线。

**输入结构**：
- 黑(0)背景，约 15x15 网格
- 一个青(8)模板对象（3~5 像素，4-连通），位于网格某处
- 5~8 个蓝(1) 4-连通对象，散布在网格中，部分与模板归一化形状相同，部分不同
- 若干红(2)控制标记像素：每个紧邻某个蓝(1)对象的边界框外侧一格（与对象不重叠、不 4-连通，但 8-连通相邻）
- 生成约束：至少两个蓝(1)对象的归一化形状与模板匹配，其中至少一个旁边有红(2)标记、至少一个旁边没有；至少一个不匹配模板的蓝(1)对象旁边有红(2)标记（构成干扰项）；各对象互不重叠

**规则**：
1. 以青(8)对象为模板，平移归一化其 4-连通形状掩码。
2. 对每个蓝(1) 4-连通分量，平移归一化其掩码并与模板逐像素比对。匹配者全部像素重涂为青(8)。不匹配者保持蓝(1)。
3. 在步骤 2 的匹配对象中，检查该对象的边界框外侧一格范围内（8-连通邻域扩展一层）是否存在红(2)控制标记像素。若存在：
   a. 计算该对象所有像素坐标的算术平均值作为质心 (cr, cc)，四舍五入到最近整数。
   b. 从 (cr, cc) 向上、下、左、右四个方向延伸青(8)射线，直到网格边界。射线覆盖路径上的所有像素（无论原色为何）。
4. 不匹配模板的蓝(1)对象即使旁边有红(2)标记也不发射射线、不被重涂。
5. 所有红(2)控制标记像素在输出中清除为背景(0)。
6. 青(8)模板对象保持不变。若射线穿过模板对象，模板像素被射线覆盖为青(8)（颜色相同，视觉无变化）。
7. 多条射线交叉处取青(8)（颜色相同，无冲突）。

**关键洞察**：红(2)标记旁的不匹配对象是干扰项——标记本身不触发任何操作，只有"匹配 AND 有标记"的双重条件才产生射线。仅看一个示例可能误以为"有标记就射线"或"匹配就射线"，需对比多个示例区分这两个独立条件各自的作用。

## 新题 8：裁剪后四折对称补全涌现封闭孔洞并填色

**组合逻辑**：[裁剪/角标记像素/中心图案](原有) -> [镜像/轴对称](创新：不是全画布水平镜像，而是对裁剪出的部分图案做四折对称补全) -> [填充/封闭孔洞](创新：孔洞在单象限中是开放的，仅在对称补全后才涌现封闭) + [角标色决定重涂](创新：角标色同时编码裁剪边界和填充颜色，裁剪时角标被移除但其颜色需跨步骤记忆)

**来源原语**：裁剪/角标记像素/中心图案/内部包含/角标色决定重涂/边框（3de23699）、镜像/轴对称/画布加倍（c9e6f938）、填充/封闭孔洞/仅填矩形内部/孔洞在框内（e73095fd）

**依赖链**：角标像素定义裁剪区并编码填充色 -> 裁剪出中心图案的左上象限（角标被移除）-> 四折对称补全 -> 对称使开放区域封闭形成孔洞 -> 用记忆中的角标色填充孔洞。孔洞是对称操作的涌现产物；填充色在裁剪步骤中就被丢弃，需要跨步骤记忆。

裁剪出角标框内的部分图案，四折对称补全后，用角标颜色填充因对称而涌现的封闭孔洞。

**输入结构**：
- 黑(0)背景，约 14x14 网格
- 一簇非黑像素位于网格中央偏左上方向
- 该簇的四角有四个青(8)角标像素，描绘一个矩形框（角标在框的四个角上，框的四条边不绘制）
- 框内部尺寸为偶数行 x 偶数列（例如 6x6 或 8x8）
- 框内部仅左上象限（上半行、左半列）有蓝(1)前景像素构成的非对称图形（3~8 像素），右上、左下、右下象限全为黑(0)
- 左上象限图形设计为：其轮廓在象限的右边界和/或下边界处有开口（未封闭），但若将该象限分别水平翻转生成右上象限、垂直翻转生成左下象限、同时水平+垂直翻转生成右下象限，则四个镜像副本拼合后开口被彼此封闭，在中央区域形成封闭孔洞
- 生成约束：四折对称补全后至少产生一个面积 >= 2 像素的封闭孔洞（被蓝(1)像素完全包围的黑(0)连通区域）；左上象限图形本身无封闭孔洞（所有内部黑色区域均与象限边界连通）

**规则**：
1. 找到四个青(8)角标像素，确定其围成的矩形。记录角标颜色为青(8)。
2. 裁剪矩形内部区域：去掉角标所在的行和列，得到一个偶数行 x 偶数列的子网格。角标像素不包含在子网格中。
3. 将子网格的左上象限（前一半行、前一半列）作为源象限 S。
4. 四折对称补全：
   - 右上象限 = S 水平翻转（左右镜像）
   - 左下象限 = S 垂直翻转（上下镜像）
   - 右下象限 = S 旋转 180 度（同时水平+垂直翻转）
5. 在补全后的完整子网格中，使用 flood fill 从四条边界的所有黑(0)像素开始扩展（4-连通，不穿越蓝(1)像素），标记所有可达的黑(0)像素为"外部"。
6. 剩余未标记的黑(0)4-连通区域即为封闭孔洞。将所有封闭孔洞像素填充为青(8)（步骤 1 中记录的角标颜色）。
7. 输出为补全并填充后的子网格（尺寸为偶数行 x 偶数列，不含角标和外框）。

**关键洞察**：左上象限中的图形开口朝向象限边界，单独看不存在任何封闭区域。但四折对称补全使四个副本的开口互相对接——对称操作涌现出了原始图案中不存在的封闭孔洞。角标颜色在裁剪时已被物理移除，但它编码了最终的填充色，求解者需跨步骤记忆这一信息。
