## 新题 1：障碍绕行路径长度决定颜色排序

**组合逻辑**：[射线延伸 + 绕行](已有，从 c87289bb 提取) → [计数](创新：从计数对象频率改为计数路径单元格数) → [排序](已有，从 81c0276b 提取；创新：排序键从直接频率变为路径长度)

**来源原语**：射线延伸、绕行、障碍线段、源列、路径（c87289bb）；计数、排序、频率统计、按计数升序（81c0276b）

**依赖链**：障碍线段的空间布局决定了每条路径的绕行方式 → 绕行产生不同的路径形状 → 路径形状决定了各路径的单元格总数 → 总数之间的大小关系决定了最终颜色序列的排列顺序。删除障碍物则所有路径等长、排序退化；删除计数/排序则空间信息无法转化为序列输出。

从顶边彩色源像素向下绘制路径，遇障碍绕行后继续下行，统计每条路径的总长度，按长度升序输出颜色序列。

**输入结构**：约 15×12 的网格，黑(0)背景。第 0 行包含 3~5 个互不相邻的彩色像素（每个颜色不同，从蓝(1)、红(2)、绿(3)、黄(4)、橙(7)中选取），它们是路径源点。网格中间区域散布 2~4 条灰(5)水平障碍线段，每条线段长 2~5 像素，高 1 像素，互不重叠且不接触网格左右边界。障碍线段的行位置和列跨度各不相同。生成约束：每个源列至多与一条障碍线段的列范围重叠；不同源像素的路径绕行后不会交叉或重叠；所有路径最终到达底边。

**规则**：
1. 对每个源像素，从其所在列向下逐行绘制该颜色，直到遇到障碍线段或到达底边。
2. 若该列命中一条障碍线段，则在障碍上方一行沿水平方向绘制到该障碍段最近的外侧列（源列到障碍左端的距离与到障碍右端的距离比较，取较近侧；若距离相等则选右侧）。到达外侧列后，继续向下绘制至底边。
3. 统计每条路径覆盖的总像素数（包括水平段和竖直段的所有单元格）。
4. 输出为单行网格（1×源像素数），各颜色按路径长度从小到大从左到右排列。若两条路径长度相同，按源像素在第 0 行的列号从小到大排列。

**关键洞察**：障碍的空间位置并非只是视觉上的路径重定向——它们编码了一个隐藏的数值排序信息；路径越长的颜色排越右。等长时的列号 tie-break 规则需要对比多个示例才能归纳。

## 新题 2：点对称补全生成印章模板用于宏单元格替换

**组合逻辑**：[点对称补全](已有，从 e729b7be 提取；创新：补全结果不再是最终输出，而是中间产物) → [印章覆盖](已有，从 5833af48 提取；创新：印章模板不再直接给出，需通过对称推导)

**来源原语**：点对称补全、中心标记、分隔列、前景图案、绕中心点旋转对称（e729b7be）；印章覆盖、控制精灵体、宏单元格模式、粗模板精细替换（5833af48）

**依赖链**：半幅图案通过点对称补全获得完整模板 → 完整模板提取为印章掩码 → 掩码被印到宏单元格网格的激活位置。去掉对称补全则模板不完整、印章内容未知；去掉印章覆盖则对称补全结果无处施加。

将一个围绕中心标记的半幅彩色图案做 180 度旋转补全，生成完整印章模板，再将该模板印入右侧宏单元格网格中标记为激活的每个宏单元格。

**输入结构**：约 10×20 的网格，黑(0)背景。网格由一条宽 1 像素的灰(5)竖直分隔列（位于约第 9 列）分为左右两区。

- 左区（约 10×9）：中心行、中心列交汇处有一个品红(6)中心标记像素。分隔列左侧一列全为黄(4)（充当竖直分界条，高度等于左区行数，但不包含中心标记所在行的该列——该行仍为品红标记）。以中心标记为原点，左上象限存在一个由蓝(1)和红(2)像素构成的 4-连通前景图案（3~8 像素），右下象限为空（全黑）。左下和右上象限也为空。
- 右区（约 10×10）：一个由橙(7)和黑(0)构成的粗粒度宏单元格网格。宏单元格尺寸等于左区补全后前景图案的边界框大小（含补全部分）。橙(7)表示激活的宏单元格，黑(0)表示未激活。

生成约束：前景图案严格位于左上象限且不接触分隔列或中心行/列（中心标记本身除外）；右区的宏单元格数在 2×2 到 4×4 之间；至少一个宏单元格为激活状态。

**规则**：
1. 在左区，找到品红(6)中心标记和黄(4)分界条。以中心标记为旋转中心，将左上象限的前景图案做 180 度点对称旋转，将旋转后的像素绘制到右下象限对应位置（颜色不变）。
2. 提取补全后的完整前景图案的边界框（不包含黄分界条、灰分隔列和品红标记），获得印章掩码：掩码中非黑像素保留原色，黑像素视为透明。
3. 在右区，将宏单元格网格压缩为逻辑矩阵。对每个激活（橙色）的宏单元格，将印章掩码粘贴到对应位置：掩码的非透明像素覆盖目标区域，透明像素保留为黑(0)。
4. 输出仅包含右区（去除灰分隔列及左区），尺寸为右区的行数乘列数。

**关键洞察**：印章模板并未直接给出——它是通过对称补全"生成"的中间产物；分界条和分隔列虽然视觉突出，但不属于模板的一部分，这一排除规则需要对比多个示例确认。

## 新题 3：色带压缩计数决定瓦片平铺倍数

**组合逻辑**：[压缩](已有，从 4be741c5 提取；创新：压缩结果不再是最终输出，其长度成为数值参数) → [平铺](已有，从 ccd554ac 提取；创新：重复次数不再由输入边长决定，而由色带数决定)

**来源原语**：压缩、色带、空间排列顺序、行主色压缩单像素（4be741c5）；平铺、瓦片、阵列排布、边长决定重复数（ccd554ac）

**依赖链**：色带的数量需通过压缩操作才能确定 → 色带数 N 作为平铺倍数控制瓦片重复次数。去掉压缩则 N 未知、平铺无法执行；去掉平铺则压缩结果仅是一个无用的颜色列表。

将上方区域的多条交错色带压缩为一个颜色序列，序列长度 N 决定下方小瓦片被平铺为 N x N 大网格。

**输入结构**：约 15×10 的网格，分为上下两区，中间由一行全灰(5)像素分隔。

- 上区（约 8×10）：整个区域被 3~5 种颜色的水平色带完全填满（无黑背景），每条色带占若干行，色带边界呈锯齿状（同一行中少数像素可能属于相邻色带的颜色，但每行的行主色明确唯一）。色带从上到下的颜色各不相同，覆盖上区的每种颜色恰好出现一次。
- 下区（约 5×5 或更小）：一个正方形瓦片，边长 S 满足 2 <= S <= 4，由上区用到的颜色子集和黑(0)构成一个非对称的小图案。

生成约束：设上区色带数为 N，则 N*S 不超过 30（保证输出网格在合理尺寸内）。下区瓦片是非对称的（水平翻转或旋转后与自身不同），以便从示例中确认无旋转/翻转操作。

**规则**：
1. 对上区按行取行主色（每行中出现次数最多的颜色），得到一个长度等于上区行数的颜色序列。将连续相同颜色合并为一个色带，得到色带序列长度 N。
2. 取下区的 S x S 瓦片。
3. 将瓦片在水平方向重复 N 次、竖直方向重复 N 次，构成 (N*S) x (N*S) 的输出网格。每个副本保持与原始瓦片完全相同的像素（不旋转、不镜像）。
4. 输出仅为平铺后的大网格（不含上区和分隔行）。

**关键洞察**：上区杂乱的色带不是装饰——它们的数量（而非具体颜色）直接控制了下方瓦片的平铺倍数。瓦片在每个副本中不做旋转或镜像这一规则需对比含非对称瓦片的多个示例才能确认。

## 新题 4：模板形状匹配筛选可滑动对象进入括号通道

**组合逻辑**：[形状匹配](已有，从 63613498 提取) → { 匹配：[滑动](已有，从 98cf29f8 提取；创新：滑动目标从锚定物变为括号通道) + [重涂色](创新：匹配对象涂为框架色) | 不匹配：[擦除](已有，从 22806e14 提取) }

**来源原语**：形状匹配、模板、框架、掩码相同、模板选同形重涂（63613498）；滑动、连接杆、碰撞阻挡、沿杆滑至锚定物（98cf29f8）；括号框、通道对齐、目标底边对齐（df9fd884）；擦除（22806e14）

**依赖链**：L-框架内的模板形状决定匹配判定 → 匹配结果分流为两种操作（滑动入通道 / 擦除）→ 滑动时连接杆长度决定目标通道分配。去掉形状匹配则无法区分对象命运；去掉滑动则匹配对象无处可去；去掉擦除则非匹配对象残留。

从 L-框架中提取模板形状，检测散布对象中哪些与模板同形。匹配的对象沿其连接杆滑入右侧括号通道并变色；不匹配的对象被擦除。

**输入结构**：约 18×18 的网格，黑(0)背景。

- 左上角（约 7×7 区域）：一个灰(5) L 形框架，竖直腿在右侧、水平腿在底部，框架线宽 1 像素。框架围合的内部区域包含一个由红(2)像素构成的 4-连通小图形（3~6 像素），这是模板。
- 中部区域：3~5 个 4-连通小图形，每个由单一颜色构成（从蓝(1)、绿(3)、黄(4)、橙(7)中选取，颜色互不相同），像素数在 3~6 范围内。每个图形的右侧紧接一条宽 1 像素的同色水平连接杆，杆长 1~4 像素，杆末端不接触任何其他元素。图形之间互不相邻，且都位于括号通道的左侧。
- 右侧（约占最右 4 列）：2~3 个品红(6)括号框，每个括号框由 U 形结构构成（开口朝左），高度各不相同（3~6 像素），竖直方向互不重叠。括号框之间至少间隔 2 行。

生成约束：恰好有 1~2 个中部图形与模板形状匹配（旋转和翻转后也算匹配）；匹配图形的数量不超过括号通道数量；每个匹配图形的连接杆延长线（向右水平延伸）恰好指向某个括号框的内部行范围。

**规则**：
1. 提取 L-框架内红(2)模板的归一化掩码（平移到原点，不含框架像素）。
2. 对每个中部图形，提取其归一化掩码（忽略颜色和位置）。逐一与模板掩码比较——允许 0 度、90 度、180 度、270 度旋转和水平翻转后的 8 种变体中任意一种匹配。
3. 不匹配的图形：连同其连接杆一起擦除为黑(0)。
4. 匹配的图形：保持形状不变，沿连接杆方向（水平向右）平移，平移距离等于连接杆长度加 1（即跳过杆本身），使图形的边界框右边缘紧贴其连接杆延长线所指向的括号框的左边缘内侧。同时将该图形的颜色重涂为灰(5)。擦除原位置的图形和连接杆。
5. 若多个匹配图形指向同一个括号框（生成约束下不会发生），则按连接杆长度从短到长依次放置，短杆图形贴括号框顶部，长杆图形紧接其下。
6. 输出网格与输入同尺寸。L-框架和括号框保持不变。

**关键洞察**：L-框架不仅标识模板形状——它还隐含地定义了一个"存活测试"。连接杆不参与形状匹配，但它决定了匹配对象滑入哪个括号通道。匹配时允许旋转和翻转这一规则需要对比多个示例中不同朝向的匹配对象才能归纳。

## 新题 5：十字射线与标记矩形的优先级合成

**组合逻辑**：[连线/路径绘制](已有，从 29700607 提取) 并行 [填充 + 对角标记定矩形](已有，从 21f83797 提取) → [优先级合成](创新：两个独立构图共享画布，需要冲突解决)

**来源原语**：连线、路径绘制、边缘源像素、同色端点、同色配对、有端点则转弯、无端点则延伸（29700607）；填充、标记像素、矩形、行列分割线、对角标记定矩形（21f83797）

**依赖链**：路径绘制和矩形填充是两个独立的几何构图，但它们共享同一画布 → 重叠区域需要优先级规则来决定最终颜色。去掉路径绘制则画布只剩矩形填充；去掉矩形填充则只有路径；去掉优先级规则则重叠区域不确定。这不是流水线，而是两个并行构图的受约束合并。

顶边彩色像素向下绘制路径（有端点则转弯，否则直达底边），同时两个栗(9)标记像素定义一个矩形并将其内部填充蓝(1)。两个构图合成到同一画布上，按固定优先级处理重叠。

**输入结构**：约 15×15 的网格，黑(0)背景。

- 第 0 行：一段连续的 2~4 个不同颜色的像素（从绿(3)、黄(4)、橙(7)、品红(6)中选取），占据相邻的列，其余列为黑。这些是路径源像素。
- 网格内部：每个源像素颜色在网格中最多有一个同色的孤立端点像素（单个像素，不在第 0 行，不在源像素的同列）。有的源颜色有端点，有的没有。
- 网格中还有恰好 2 个栗(9)孤立像素，它们不在同一行也不在同一列，且不在第 0 行。它们是矩形标记。

生成约束：栗(9)标记不与任何端点像素重合；至少一条路径（有端点或无端点）的行/列范围与标记定义的矩形内部有交叉，以确保出现优先级冲突。

**规则**：
1. **路径绘制**：对第 0 行每个源像素，从其列向下绘制竖直段。若存在同色端点像素，竖直段画到端点所在行，然后画水平段从源列到端点列（含端点像素本身），路径颜色为源像素颜色。若不存在同色端点，竖直段一直画到底边（最后一行）。路径宽度为 1 像素。
2. **矩形构图**：两个栗(9)标记像素定义矩形的对角。画出经过两个标记行的完整水平线（跨网格全宽）和经过两个标记列的完整竖直线（跨网格全高），颜色为栗(9)。再将两个标记行之间、两个标记列之间的严格内部像素填充为蓝(1)。
3. **合成规则**（优先级从高到低）：栗(9)十字线 > 路径颜色 > 蓝(1)矩形填充 > 黑(0)背景。即：一个像素若同时被栗色十字线和路径覆盖，显示栗(9)；若同时被路径和蓝色填充覆盖，显示路径颜色；蓝色填充仅在无更高优先级元素时可见。
4. 输出网格与输入同尺寸。

**关键洞察**：路径和矩形填充是两个各自独立的几何操作，但它们的输出必须在同一画布上合成。三层优先级关系（栗色线 > 路径 > 蓝色填充）无法从单个示例可靠归纳——需要多个示例展示不同重叠配置来确认优先级顺序。

## 新题 6：周期修复还原着陆面后重力下落

**组合逻辑**：[补全/周期修复](已有，从 e95e3d8e 提取；创新：修复结果不是最终输出，而是后续物理模拟的边界条件) → [重力下落](已有，从 c87289bb / df9fd884 提取；创新：着陆面不是网格底边或固定结构，而是由修复操作动态生成的)

4. 擦除对象原位置（设为修复后该位置应有的周期背景色）。在新位置绘制对象。
5. 若多个对象需处理，按对象边界框顶行从高到低（行号从大到小，即靠近底部的先处理）依次执行，已落位的对象视为障碍。

**关键洞察**：缺失区域由两种不同的几何机制协同填补——旋转提供一部分（以绿色标记），对称提供其余部分（保持原图案颜色）。旋转线段的原始位置变为橙色而非消失，这个"留痕"规则需要多个示例才能确认。

1. 在左区，找到黑(0)缺失矩形的边界框 (r1, c1, r2, c2)。对缺失区域内的每个黑像素 (r, c)，遍历其 D4 对称轨道（以左区图案中心为对称中心），找到第一个非黑值，将 (r, c) 设为该值。
2. 裁剪出补全后的矩形 [r1..r2, c1..c2]，得到一个 H x W 的瓦片种子 T。
3. 在右区，将 T 作为周期单元：对右区每个黑(0)像素 (r', c')，计算其残余坐标 ((r' - r_offset) mod H, (c' - c_offset) mod W)，其中 r_offset 和 c_offset 是右区左上角的全局坐标。将该像素替换为 T 中对应残余位置的颜色。
4. 输出仅包含右区（不含灰分隔列和左区），尺寸为右区的行数乘列数。

**关键洞察**：两种不同的"补全"方法形成接力——对称补全的输出经裁剪后成为周期修复的输入种子。左区表面上是一个独立的对称拼图，实际上它隐藏了右区所需的周期单元。灰色分隔列不属于任何区域、不参与任何计算，这个排除规则需对比示例确认。
