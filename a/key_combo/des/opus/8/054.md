## 新题 1：连接点锚定的模板朝向推断与补全

**组合逻辑**：[模板提取](已有) → [连接点朝向推断](创新：连接点不再用于对接，而是作为旋转/反射的定位锚点) → [补全+重涂色](已有操作，但补全目标由连接点锚定的变换决定)

**来源原语**：模板提取(template_extraction, 79369cc6), 补全(completion, 79369cc6), 连接点(connector_pixel, 20270e3b), 旋转反射等价(rotation_reflection_equivalence, 79369cc6), 对齐签名匹配(alignment_signature_matching, 79369cc6), 重涂色(recolor, 多源)

**依赖链**：模板提取确定完整图案 → 连接点的相对位置在 8 种旋转/反射变换中匹配出唯一变换 → 该变换决定补全时每个缺失像素的位置 → 补全后重涂色为副本自身颜色。删除任一环节（无模板则无图案可补，无连接点则无法确定朝向，无补全则无输出变化），其余无法求解。

将散布在网格上的不完整副本通过连接点锚定朝向，用完整模板的对应变换补齐缺失像素并统一重涂色。

**输入结构**：黑(0)背景网格，约 18x18。网格一角（如左上角 5x4 区域）有一个完整的矩形模板，由蓝(1)和黄(4)两种颜色密铺，模板形状不对称（例如左上角和右下角的颜色分布不同，使得 8 种旋转/反射变换产生不同的图案）。模板边框上恰好有 2 个红(2)连接点像素，位置不对称（如一个在顶边偏左、另一个在右边偏下），使得连接点在 8 种变换下的相对位置各不相同。网格其余区域散布 3~5 个不完整副本，每个副本仅保留了原模板在某种旋转/反射变换下的部分像素（约 40%~70% 可见），但每个副本一定保留了两个红(2)连接点像素。每个副本使用与模板不同的单一前景色（如绿(3)、灰(5)、品红(6)等，各副本颜色互不相同），连接点始终为红(2)。不同副本对应的旋转/反射变换互不相同。生成约束：副本之间不重叠；每个副本的两个连接点在该副本的 8 种变换候选中能唯一匹配到一种；模板的连接点位置在 8 种变换下两两不同。

**规则**：
1. 提取模板：取蓝(1)/黄(4)像素的边界框为完整模板，记录两个红(2)连接点相对于模板左上角的坐标。
2. 对每个不完整副本，提取其两个红(2)连接点相对于该副本所有可见像素边界框左上角的坐标。
3. 遍历模板的 8 种旋转/反射变换（0/90/180/270 度旋转，各含或不含水平翻转），计算每种变换下连接点的相对坐标。找到与副本连接点坐标一致的唯一变换。
4. 将该变换应用于完整模板图案。对于变换后图案中每个非背景像素位置：若副本在该位置已有像素则保留；若该位置为空（黑(0)），则填入该副本的前景色。
5. 将所有连接点像素（红(2)）重涂为该副本的前景色。
6. 擦除原始模板区域（全部涂为黑(0)）。
7. 处理顺序：按副本边界框左上角的阅读序（从上到下、从左到右）依次处理。副本不重叠，故处理顺序不影响结果。

**关键洞察**：连接点在源题中是对接两个精灵体的匹配标记，这里被重新用作旋转/反射变换的定位锚——两个不对称放置的连接点在 8 种变换下产生 8 组不同的相对坐标，从而唯一确定每个副本的朝向。需要对比多个示例才能确认是连接点坐标（而非副本在网格中的位置或其他属性）决定了变换选择。

## 新题 2：地形表面射线的障碍偏转生长

**组合逻辑**：[地形轮廓分析](已有) → [射线延伸](已有操作，但起点由地形表面高度决定而非矩形边缘突起) → [障碍偏转生长](创新：射线在遇到障碍时横向偏移后继续，将路径生长的偏转逻辑嫁接到射线延伸上) → [极值列高亮](已有条件，但作用于射线颜色而非填充区域)

**来源原语**：射线延伸(ray_extend, f1cefba8), 地形轮廓(terrain_contour, e45ef808), 列高度极值(column_height_extreme, e45ef808), 生长(grow, d9f24cd1), 障碍像素(blocker_pixel, d9f24cd1), 遇障碍则绕行(detour_on_obstacle, d9f24cd1), 标记像素(marker_pixel, 40853293)

**依赖链**：地形轮廓确定每列的表面高度 → 标记像素在表面上的位置决定射线起点的行坐标（不同于源题中从固定边缘出发）→ 障碍像素迫使射线横向偏移（不同于源题中简单直线延伸）→ 极值列分析选出特殊列并改变其射线颜色（将地形分析的结果反馈到射线的视觉属性上）。删除地形则无法确定起点高度；删除偏转则射线被障碍截断失去意义；删除极值高亮则丢失地形深度与射线颜色的耦合。

从地形表面的标记点向上发射射线，射线遇到障碍横向偏转后继续上行，地形最深列的射线以特殊颜色标记。

**输入结构**：黑(0)背景网格，约 16x16。底部区域（约下方 5~8 行）为绿(3)地形轮廓：每列从底边向上有连续的绿(3)像素，不同列高度不同，形成参差的地形表面（最顶部的绿(3)像素即为该列的表面）。地形表面的若干列（3~5 列）上，表面正上方一格处有一个蓝(1)标记像素（即该列表面绿(3)像素上方紧邻的那个像素为蓝(1)）。地形上方的区域中散布若干灰(5)障碍像素（每个为单独的 1x1 像素，互不相邻，不在网格最顶行也不在最左/最右列），数量约 5~10 个。生成约束：每个蓝(1)标记像素所在列的地形表面高度互不相同（保证极值列唯一）；障碍像素不在任何标记像素正上方的同一列中连续出现两个（保证偏转后总能继续上行）；标记像素之间的列间距 >= 3（保证偏转不会导致射线合并）。

**规则**：
1. 识别地形表面：对每列，找到最高的（行号最小的）绿(3)像素，该行即为该列的表面行。
2. 识别标记像素：蓝(1)像素，每个位于某列地形表面正上方一格处。
3. 对每个标记像素发射射线：从标记像素所在位置开始，逐步向上生长（行号递减）。每步尝试向上移动一格：
   - 若上方一格为黑(0)背景或已有射线像素，则移动到该格并涂为蓝(1)。
   - 若上方一格为灰(5)障碍，则改为向右移动一格（列号加 1）并涂为蓝(1)，下一步继续尝试向上。
   - 若向右也超出网格边界，则射线停止。
   - 射线到达第 0 行时停止。
4. 确定极值列：在所有具有标记像素的列中，找到地形表面行号最大的列（地形最深处，即表面最低的列）。
5. 将该极值列的整条射线（包括标记像素和所有生长出的像素）重涂为黄(4)。
6. 处理顺序：按标记像素的列号从左到右依次生长射线。若一条射线偏转后进入了另一条射线将要经过的列，后处理的射线在该格遇到已有射线像素时视同障碍、继续向右偏转。

**关键洞察**：射线的起始高度不再是固定边缘，而是由地形轮廓的局部高度决定——同一组射线因地形参差而从不同行出发。障碍偏转使得射线路径不再是直线，而极值列的颜色替换将地形的全局统计属性注入到了射线的局部视觉表达中。需要对比多个示例才能发现射线处理顺序（左到右）对偏转冲突的影响。

## 新题 3：形状归一化分组与组内连线

**组合逻辑**：[平移归一化+形状分组](已有操作的创新应用：归一化后发现分组，而非已知分组后重涂色) → [重涂色](已有) → [连线](已有操作，但端点不再预设而是由分组结果动态确定) → [交叉优先级](创新：优先级不再由线段方向决定，而由分组成员数决定)

**来源原语**：形状相同(same_shape, ad38a9d0), 平移归一化(translate_normalize, ad38a9d0), 重涂色(recolor, ad38a9d0), 连线(draw_line, 40853293), 同色配对(same_color_pairing, 40853293), 行列对齐(row_col_align, 40853293), 竖线交叉优先(vertical_priority_at_cross, 40853293), 忽略干扰项(ignore_distractors, b1986d4b)

**依赖链**：平移归一化发现同形对象组 → 组的成员数决定涂色优先级和连线交叉优先级 → 连线端点由同组对象的位置决定（非预定义）→ 交叉点颜色由成员数多的组优先。删除归一化则无法分组；删除连线则只剩简单涂色（退化为源题 ad38a9d0）；删除交叉规则则多组连线的重叠无法解决。

将形状相同的占位符对象归为一组并涂色，组内对象两两连线，线段交叉处成员多的组颜色优先。

**输入结构**：黑(0)背景网格，约 17x17。网格中散布 8~12 个小型 4-连通单色对象，全部使用灰(5)作为占位符颜色，每个对象由 3~6 个像素组成，形状不规则（非简单矩形）。这些对象可分为 3~4 组，每组 2~4 个成员共享相同的平移归一化形状，各组形状互不相同。另有 1~2 个对象的归一化形状独一无二（不属于任何组），这些是干扰项。对象之间互不相邻（任意两个对象的边界框间至少隔 2 格）。同组内至少有一对对象的边界框中心共享行或列（保证存在非对角线连线）。生成约束：各组成员数互不相同（如分别为 2、3、4 个成员），保证成员数可作为唯一的优先级排序依据。

**规则**：
1. 裁剪每个灰(5)对象至其边界框，将边界框左上角平移至原点，得到归一化掩码。
2. 将归一化掩码相同的对象归为一组。仅含一个成员的"组"视为干扰项，保持灰(5)不变，不参与后续连线。
3. 为每个有效组分配颜色：按组成员数从大到小依次分配红(2)、蓝(1)、绿(3)、黄(4)。若成员数相同（生成约束排除此情况，但作为边界处理），以组内最靠左上的成员的边界框左上角阅读序在先者获得更早的颜色。
4. 将每组的所有成员对象重涂为该组的颜色。
5. 对每组内的所有成员，两两之间画连线：取两个对象各自边界框中心（行列坐标均取边界框行范围和列范围的算术平均值，向下取整），画一条从一个中心到另一个中心的折线——先水平段（从起点列到终点列，行不变），再垂直段（从起点行到终点行，列不变），使用该组颜色。若两中心同行则只画水平段，同列则只画垂直段。每对连线中，以边界框中心阅读序靠前的为起点。
6. 当不同组的连线经过同一像素时，成员数更多的组的颜色覆盖成员数少的组的颜色。
7. 连线覆盖背景像素和其他组的连线像素，但不覆盖任何对象本体像素（对象像素始终保留）。

**关键洞察**：在源题中，同色配对的端点由颜色直接给出；在本题中，"哪些对象是一对"必须通过形状归一化来发现，分组结果同时决定涂色方案和连线拓扑。交叉优先级由组的人口统计属性（成员数）决定，而非线段的几何方向——这是一种从源题不存在的"分组大小→绘图优先级"映射关系。需要对比多个示例确认干扰项的判定标准（唯一形状）以及交叉优先级的依据（成员数而非颜色编号）。

## 新题 4：降采样障碍图上的路径生长

**组合逻辑**：[降采样](已有操作，但产物不再是裁剪掩码而是可导航的障碍地图) → [寻路+生长](已有操作，但障碍不再是显式放置的像素而是通过尺度变换推导出的) → [擦除](已有，清除原始大图案)

**来源原语**：降采样(downsample, 6ecd11f4), 整数缩放对应(int_scale_correspond, 6ecd11f4), 单色图案(mono_pattern, 6ecd11f4), 寻路(pathfinding, d9f24cd1), 生长(grow, d9f24cd1), 起点像素(start_pixel, d9f24cd1), 遇障碍则绕行(detour_on_obstacle, d9f24cd1), 擦除(erase, 252143c9)

**依赖链**：大图案的降采样产生小障碍图 → 障碍图的空间结构决定路径可通行区域 → 起点像素在障碍图坐标下的位置决定路径起始 → 路径在障碍图上生长并偏转。删除降采样则不知道哪些格子是障碍；删除路径生长则降采样产物无用途；两者通过尺度变换紧密耦合。

将大尺度单色图案降采样为小障碍网格，从边缘起点出发在障碍网格上向右生长路径，遇障碍向下偏转。

**输入结构**：黑(0)背景网格，约 18x18。网格左上区域有一个大的蓝(1)单色图案，占据约 12x12 至 15x15 的范围，由蓝(1)和黑(0)组成，是一个小型二值网格（4x4 至 6x6）按整数倍（3 倍或 4 倍）放大得到的。即每个小格子对应大图案中一个 kxk 的块，全蓝块表示障碍，全黑块表示通行。网格右下角有一个小区域（与降采样后的障碍图同尺寸，如 5x5），其左边缘（第 0 列）上有 2~3 个起点像素，颜色各不相同（如红(2)、绿(3)、黄(4)），其余为黑(0)。生成约束：大图案的每个 kxk 块要么全蓝要么全黑（保证降采样无歧义）；降采样后的障碍图中，每行至少有一个通行格（保证路径不会完全被堵死）；起点像素所在行在障碍图中的对应格为通行格。

**规则**：
1. 分离大蓝(1)图案和小区域（小区域通过包含非蓝非黑像素来识别，或通过位置识别为右下角独立区域）。
2. 确定缩放因子 k：大图案边界框的宽度除以小区域的宽度（均为整数）。
3. 降采样：将大图案划分为 kxk 的块，每块若全部为蓝(1)则记为障碍(1)，否则记为通行(0)，得到与小区域同尺寸的障碍图。
4. 将小区域作为输出基底（初始为全黑(0)）。
5. 对每个起点像素（按其在小区域中的行号从上到下处理），从该像素位置开始向右生长路径：
   - 每步尝试向右移动一列（列号加 1）。
   - 若右方格在障碍图中为通行(0)且无已有路径像素，则移动并涂为该起点的颜色。
   - 若右方格为障碍(1)或已有其他路径像素，则改为向下移动一行（行号加 1）并涂色，下一步继续尝试向右。
   - 若向下也超出网格边界或为障碍，则路径停止。
   - 到达最右列时路径停止。
6. 擦除大蓝图案区域（全部涂黑(0)），输出仅包含小区域部分（即障碍图尺寸的网格，含路径）。

**关键洞察**：降采样在源题中生成裁剪用的二值掩码，本题中它生成路径导航用的障碍地图——同一个操作的产物在完全不同的下游逻辑中扮演关键角色。路径生长在源题中使用显式散布的障碍像素，本题中障碍结构是从大图案中通过尺度变换推导出的隐含信息。需要对比多个示例才能发现缩放因子的确定方法以及偏转方向（向下而非源题中的向右）。

## 新题 5：矩形遮挡层序推断与同层间隙填充

**组合逻辑**：[层序推断](已有操作，但作用对象从直线变为矩形，推断逻辑从共线像素变为面积覆盖) → [间隙检测+条件填充](已有操作，但填充颜色不再固定，而由层序推断的结果动态决定) → [计数](已有，统计各层矩形数作为验证约束)

**来源原语**：层序推断(layer_infer, 22425bda), 遮挡层次(occlusion_order, 22425bda), 排序(sort, 22425bda), 填充(fill, ef135b50), 间隙区域(gap_region, ef135b50), 行列跨度重叠(row_span_overlap, ef135b50), 无遮挡才填充(fill_if_unobstructed, ef135b50), 计数(counting, b1986d4b)

**依赖链**：矩形重叠区域的可见颜色 → 推断出全局自底向上的层叠顺序 → 层叠顺序确定"同层"矩形对 → 同层矩形对之间的间隙若无更高层矩形遮挡则填充 → 填充颜色来自紧邻上层的颜色（层序推断的结果直接决定填充参数）。删除层序推断则无法确定同层关系和填充颜色；删除间隙填充则层序推断无可视化表达；删除遮挡条件判断则可能错误填充被上层遮挡的间隙。

推断重叠矩形的层叠顺序，在同一层的水平相邻矩形之间用上层矩形的颜色填充未被遮挡的间隙。

**输入结构**：黑(0)背景网格，约 16x16。网格中有 4~6 个不同颜色的实心矩形（每个矩形使用一种唯一的非背景色，如红(2)、蓝(1)、绿(3)、黄(4)、品红(6)），矩形大小约 4x3 至 7x5 像素。部分矩形有重叠区域（至少有 3 对矩形重叠），重叠处只显示层叠顺序中较高那个矩形的颜色。至少有 2 对矩形在水平方向上不重叠（列范围不交），但行范围有重叠，且它们在层叠顺序中处于同一层深度。它们之间的水平间隙中没有更高层矩形穿过。另有至少 1 对矩形满足间隙条件但有更高层矩形的边界框穿越该间隙。生成约束：层叠顺序唯一（不存在两种合法排列都能解释所有重叠区域的可见颜色）；同层深度的矩形至少 2 个。

**规则**：
1. 恢复每个矩形的完整范围：通过可见边缘推断被遮挡部分。对每种颜色，找到其所有可见像素的行范围和列范围，取最小外接矩形作为该颜色矩形的完整范围（假设每个矩形都是完整的实心矩形，无孔洞）。
2. 推断层叠顺序：对每对重叠矩形，重叠区域中可见的颜色在上、被遮挡的颜色在下。收集所有这样的"上/下"约束，拓扑排序得到唯一的自底向上层叠序列。将层叠位置编号为 1（最底层）到 N（最顶层）。
3. 确定同层矩形对：同层的定义——两个矩形之间不存在直接或传递的上/下约束（即在偏序关系中不可比），且在拓扑排序中被分配到相同的层深度（层深度 = 该矩形在约束图中最长上行路径的长度 + 1）。
4. 对每对同层矩形，检查是否满足间隙填充条件：(a) 列范围不重叠；(b) 行范围有重叠；(c) 在行范围重叠的那些行中，两个矩形之间的列区间（间隙）内，没有任何层深度更大（更高层）的矩形的完整范围与该间隙在行列上均有交集。
5. 对满足条件的间隙：确定紧邻上层颜色——在层叠顺序中，找到层深度恰好为当前层深度 + 1 的矩形颜色。若有多个，选择其完整范围与间隙行列区间重叠面积最大的那个颜色。若层深度 + 1 不存在矩形（当前已是最顶层），则填充灰(5)。
6. 用上述颜色填充间隙中、行范围重叠区间内的所有黑(0)像素。不改变任何已有矩形像素。
7. 处理顺序：按间隙的左上角阅读序依次填充。

**关键洞察**：源题 22425bda 的遮挡推断作用于一维直线的交叉点，本题将其推广到二维矩形的面积重叠。源题 ef135b50 的间隙填充使用固定颜色（栗(9)），本题的填充颜色由层叠分析的结果——紧邻上层的颜色——动态决定，使得遮挡推断和间隙填充之间形成了源题中不存在的信息回路。需要对比多个示例才能发现"同层"概念以及填充颜色来自上层的规则。

## 新题 6：双轴反射地形的极值列射线

**组合逻辑**：[镜像+平铺](已有) → [地形极值分析](已有操作，但作用于反射拼合后的复合地形而非原始地形，极值位置因对称性可能发生迁移) → [射线延伸](已有操作，但起点由复合地形中的标记像素经镜像复制后的位置决定，射线方向由所在半平面决定)

**来源原语**：镜像(mirror, 67e8384a), 平铺(tiling, 67e8384a), 象限排布(quadrant_layout, 67e8384a), 双轴反射(biaxial_reflection, 67e8384a), 地形轮廓(terrain_contour, e45ef808), 列高度极值(column_height_extreme, e45ef808), 最深与最浅列唯一(unique_deep_shallow, e45ef808), 射线延伸(ray_extend, f1cefba8), 标记像素(marker_pixel, 40853293)

**依赖链**：输入瓦片镜像平铺 → 复合地形的列高度分布与原瓦片不同（对称创造了新的极值候选）→ 极值分析在复合地形上产生与原瓦片不同的结果 → 标记像素在四个象限中各有一份镜像副本，射线方向由所在象限决定。删除平铺则无复合地形，极值退化为原瓦片的极值；删除极值分析则标记像素的射线缺少颜色区分；删除射线则极值分析无可视化输出。

将小地形瓦片双轴反射拼成四象限复合地形，找到复合地形中地表最深与最浅的列并标注颜色，从标记像素处向最近的水平边缘发射射线。

**输入结构**：黑(0)背景网格，约 8x7（较小，用于拼合后不超过 16x14）。第 0 行为灰(5)分隔行。第 1 行到最后一行为地形区域：每列从底边向上有连续的绿(3)地形像素，不同列高度不同（高度范围 2~6），形成不规则的地形表面。地形表面具有不对称性（左半部分和右半部分的高度分布不同，保证拼合后极值位置可能变化）。地形表面上有 2 个红(2)标记像素，分别嵌入不同列的表面顶部（即该列最高的绿(3)像素被替换为红(2)）。生成约束：原瓦片中地形表面最深列和最浅列各唯一；双轴反射拼合后，由于反射对称，复合地形中可能出现多列并列最浅的情况——此时选最右列，但最深列在拼合后仍唯一（通过让原瓦片的最深列不在瓦片的对称轴上来保证）。

**规则**：
1. 以输入网格为瓦片，创建 2x2 双轴反射拼合：左上为原图，右上为左右镜像，下半部分为上半部分的上下镜像。输出网格尺寸为 2H x 2W。
2. 在复合网格中重新计算地形表面：对每列，找到最高的绿(3)或红(2)像素（红(2)标记像素也视为地形的一部分），该像素的行号即为该列的表面行。
3. 找到复合地形中表面行号最大的列（地形最深处，即表面最低）。若有多列并列，选最左列。将该列从灰(5)分隔行（第 0 行和通过镜像产生的中间分隔行）到表面之间的所有黑(0)像素涂为橙(7)。
4. 找到复合地形中表面行号最小的列（地形最浅处，即表面最高）。若有多列并列，选最右列。将该列从分隔行到表面之间的所有黑(0)像素涂为黄(4)。
5. 对复合网格中每个红(2)标记像素：判断它位于上半部分还是下半部分。若在上半部分（行号 < H），从该像素向上发射射线直到第 0 行（不含第 0 行），射线颜色为红(2)。若在下半部分（行号 >= H），从该像素向下发射射线直到最后一行（含最后一行），射线颜色为红(2)。射线覆盖路径上的黑(0)像素，不覆盖已有的绿(3)、灰(5)、橙(7)、黄(4)像素。
6. 保持所有原有的地形像素、分隔行像素和标记像素不变。

**关键洞察**：双轴反射在源题中是对任意图案的纯几何操作，这里应用于地形后产生了涌现效应——反射对称可能使原本不在极值位置的列成为新的极值列，因为拼合创造了新的列高度对比关系。这种"对称操作改变统计极值"的效应在任何源题中都不存在。需要对比多个示例才能确认极值分析是在拼合后的复合地形上进行、而非在原瓦片上进行后复制。

## 新题 7：叶状突起选定面板的内容互换

**组合逻辑**：[叶状突起识别+行列选定](已有操作，但选定目标从矩形内的行列变为面板网格中的面板行/面板列) → [面板交换+图案掩码重涂色](已有操作，但不再对所有面板统一交换，而由叶状标记选择性触发) → [顺序依赖](创新：先执行列选定的交换、再执行行选定的交换，导致某些面板被交换两次，最终内容取决于执行顺序)

**来源原语**：叶状突起(leaf_protrusion, f1cefba8), 突起定行列(leaf_selects_row_col, f1cefba8), 交换(swap, 5a719d11), 分隔面板(separated_panel, 5a719d11), 图案掩码(motif_mask, 5a719d11), 成对交换(pairwise_exchange, 5a719d11), 底色作为涂色源(base_color_source, 5a719d11), 重涂色(recolor, 多源)

**依赖链**：叶状突起的方向判定 → 选定面板行或面板列 → 选定列中上下面板交换内容 → 选定行中左右相邻面板交换内容 → 交换顺序（先列后行）影响被两次选中的面板的最终结果。删除叶状突起则无法确定哪些面板参与交换（退化为全部交换或不交换）；删除交换机制则叶状突起的选定结果无用途；删除顺序规则则双重选定的面板结果不确定。

叶状突起标记选定哪些面板行和面板列参与内容互换，先交换选定列中的上下面板、再交换选定行中的相邻面板，被两次选中的面板获得双重交换效果。

**输入结构**：黑(0)背景网格，约 15x17。灰(5)分隔行和分隔列将网格划分为 2 行 x 3 列共 6 个矩形面板（每个面板约 5x4 像素）。每个面板有一种底色（从蓝(1)、红(2)、绿(3)、黄(4)、品红(6)、橙(7)中各取一种，6 个面板底色互不相同）和一种少数色组成的图案掩码（图案由该面板底色之外的某种颜色构成，约占面板面积的 20%~35%，为不规则的 4-连通小图形，不同面板的图案形状不同）。在某些面板的外边框处（即面板与灰(5)分隔区域的交界），有叶状突起：面板图案掩码颜色的单个像素伸入灰(5)分隔区域中，该像素在分隔区域中的唯一同色邻居指回面板内部。约有 2~3 个叶状突起，分布在不同面板上。生成约束：叶状突起的行列选定不产生冲突（即不会有同一面板列被两个不同叶状突起同时选中）；至少一个面板同时位于某个被选定的面板行和某个被选定的面板列中（保证双重交换发生）。

**规则**：
1. 识别叶状突起：在灰(5)分隔区域中找到非灰非黑像素，其在分隔区域中仅有一个同色邻居且该邻居位于某面板内部。
2. 判断叶状突起选定行还是列：若该突起的唯一同色邻居在其上方或下方（即突起从面板的左边或右边伸出），则选定该面板所在的面板行。若邻居在其左方或右方（即突起从面板的上边或下边伸出），则选定该面板所在的面板列。
3. 第一轮交换（列交换）：对每个被选定的面板列，交换该列中上方面板和下方面板的图案掩码。交换方式：提取上方面板的图案掩码形状 M_top 和下方面板的图案掩码形状 M_bot。将 M_bot 粘贴到上方面板中，涂为上方面板的底色。将 M_top 粘贴到下方面板中，涂为下方面板的底色。先将两面板各自清除为纯底色，再粘贴对方的掩码形状。
4. 第二轮交换（行交换）：对每个被选定的面板行，将该行中的面板从左到右两两配对交换（第 1 和第 2 面板交换，若有第 3 面板则不交换、保持当前状态）。交换方式同上：提取当前状态下的图案掩码形状，清除为底色后粘贴对方掩码并涂为接收面板底色。
5. 未被任何叶状突起选中行或列的面板保持原始状态不变。
6. 叶状突起像素本身保留在输出中（不擦除）。

**关键洞察**：叶状突起在源题 f1cefba8 中选定行列用于对矩形内部进行直线切割和重涂，本题中它们选定面板级别的行列来触发面板间内容交换——选定机制和交换机制来自不同源题，在本题中形成了"选定→交换"的新结构关系。更关键的是先列后行的执行顺序使得处于交叉位置的面板经历两次交换，其最终内容不是简单的"交换后的结果"而是"交换的交换"——这需要对比含有交叉选定和不含交叉选定的示例才能归纳出来。

## 新题 8：地形谷地中的精灵体嵌入

**规则**：
1. 识别地形表面：对每列，最高的绿(3)像素的行号即为表面行号（行号越小，表面越高）。
2. 识别谷地：一个谷地是一段连续列范围 [c_left, c_right]，满足：(a) 范围内每列的表面行号都严格大于 c_left-1 列和 c_right+1 列的表面行号（即范围内地形比两端低）；(b) 范围是满足此条件的最大连续列段。谷地的宽度 = c_right - c_left + 1。谷地的谷底行 = 范围内表面行号的最大值（最低处）。谷地的深度 = 谷底行 - min(c_left-1 列表面行, c_right+1 列表面行)。
3. 裁剪每个精灵体至其边界框。
4. 匹配：对每个精灵体，找到边界框宽度等于该精灵体宽度的唯一谷地。
5. 放置：将精灵体放入匹配的谷地中——水平方向：精灵体边界框的最左列对齐谷地的 c_left 列。垂直方向：精灵体边界框的最底行对齐谷底行（使精灵体"坐"在谷底上）。若精灵体的某些像素与绿(3)地形像素重叠，精灵体像素覆盖地形像素。
6. 放置完成后，将所有已放置精灵体的像素统一重涂为品红(6)。
7. 擦除原始位置上的精灵体（涂为黑(0)）。
8. 无法匹配的精灵体（生成约束排除此情况）保持原位和原色。

**关键洞察**：源题 6a1e5592 的孔洞是 2D 对象中的平面缺口，精灵体以完整的 2D 形状嵌合。本题将"孔洞"概念转移到地形凹陷——一种 1.5D 的空间结构，匹配条件也从完整形状变为宽度优先（高度只需不超限即可）。放置位置由地形几何（谷底行号）而非孔洞坐标决定，使得嵌合逻辑与地形分析紧密耦合。需要对比多个示例确认匹配标准是宽度而非其他属性（如面积或高度）。

## 新题 9：象限导向对角射线的端点模板印章

**组合逻辑**：[象限方向推断](已有) → [射线延伸](已有操作，但射线不再是终态而是中间步骤，射线端点成为后续操作的定位参数) → [模板提取+印章覆盖](已有操作，但印章位置不再由框架尺寸匹配决定，而由射线端点的几何坐标决定) → [擦除](已有，清除方向指示像素和原始模板)

**来源原语**：象限指示方向(quadrant_indicates_dir, 252143c9), 同色像素定角(same_color_corner, 252143c9), 中心像素(center_pixel, 252143c9), 射线延伸(ray_extend, f1cefba8/252143c9), 模板提取(template_extraction, 79369cc6), 印章覆盖(stamp_overlay, f21745ec), 擦除(erase, f21745ec/252143c9), 尺寸匹配(size_match, f21745ec)

**依赖链**：散布的同色像素所在象限 → 确定对角射线方向 → 射线端点（网格边角处）坐标 → 模板印章以端点为锚点粘贴 → 印章重涂为射线颜色。删除象限推断则射线方向不确定；删除射线则印章位置不确定；删除模板提取则无印章内容；三者形成信息链。

从中心像素向同色散布像素所指象限发射对角射线，在射线到达网格边缘的端点处印上从网格角落提取的模板图案。

**输入结构**：黑(0)背景网格，奇数正方形，约 13x13 或 15x15。网格正中心有一个绿(3)像素。另有 3~5 个绿(3)像素散布在中心的同一个对角象限中（例如全部在中心的右下方，即行号 > 中心行且列号 > 中心列）。网格的某个角落（如左上角）有一个小矩形模板（约 3x3 至 4x4），由蓝(1)和红(2)两种颜色构成不对称图案（如蓝(1)为边框、红(2)为内部花纹，花纹不关于任何轴对称）。模板与中心像素和散布像素不重叠。生成约束：散布的绿(3)像素全部严格位于中心的同一个对角象限中（不在轴上）；模板所在角落与散布像素所在象限不同（即模板不在射线路径上）；模板边界框尺寸足够小，印章放置在边角附近时不会超出网格边界太多（允许少量裁剪）。

**规则**：
1. 找到网格中心像素（行列均为 (H-1)/2 的位置），确认为绿(3)。
2. 收集所有非中心的绿(3)像素，判断它们所在的对角象限：全部在中心的右下方则方向为 (+1,+1)，左下方为 (+1,-1)，右上方为 (-1,+1)，左上方为 (-1,-1)。
3. 从中心像素沿确定的对角方向逐步延伸（每步行号和列号各加方向增量），将路径上的每个像素涂为绿(3)，直到行或列到达网格边缘（行号为 0 或 H-1，列号为 0 或 W-1）。射线的最后一个像素为端点。
4. 提取模板：找到网格中由蓝(1)和红(2)组成的连通区域，裁剪为其边界框，得到模板图案。
5. 将模板图案以射线端点为锚点印章到网格上。锚点对齐方式：端点对齐模板的中心像素（模板边界框中心，向下取整）。若印章的某些像素超出网格边界，超出部分丢弃。
6. 印章中的蓝(1)像素重涂为绿(3)（与射线同色）；红(2)像素保持红(2)不变。
7. 擦除所有散布的绿(3)指示像素（即非中心、非射线路径上的原始绿(3)像素，涂为黑(0)）。实际操作中，由于射线路径覆盖了从中心到边缘的对角线，散布像素若恰好在射线路径上则已被射线覆盖，不在路径上的散布像素则被擦除。
8. 擦除原始模板区域（将模板原位置的蓝(1)和红(2)像素涂为黑(0)）。

**关键洞察**：源题 252143c9 中射线是最终输出——画完射线就结束了。本题中射线是中间产物，其端点坐标成为印章操作的定位输入，射线充当了"计算印章位置"的几何工具。源题 f21745ec 中印章位置由框架尺寸匹配决定（静态匹配），本题中印章位置由射线动态计算得到（运行时确定）。两种原本独立的定位机制（象限选方向、尺寸选位置）被替换为串联关系（象限选方向 → 方向定射线 → 射线定位置），构成了源题中不存在的"几何传递链"。需要对比多个示例才能确认印章的锚点对齐方式（模板中心对齐端点）以及颜色重涂规则（蓝变绿、红不变）。
