## 新题 1：墙壁可达性门控的路径局部反色

**组合逻辑**：[flood_fill + reachability](创新：可达性结果不再用于绘制边框，而是作为门控信号选择路径的哪些区段参与反转) → [reverse_color_seq](创新：不再反转整条路径，而是仅反转可达区段内的颜色子序列) + [erase](已有) + [border_connected_distinguishes_structural](已有)

**来源原语**：flood_fill / reachability / wall_barrier / erase / border_connected_distinguishes_structural（来自 8f3a5a89）；reverse_color_seq / one_pixel_path / endpoint_traversal（来自 5792cb4d）

**依赖链**：墙壁连通性分类区分出结构墙与装饰墙 → 结构墙阻断泛洪填充 → 泛洪填充的可达性结果标记出路径哪些像素属于可达区段 → 仅可达区段内的颜色子序列被原地反转。删除任一环节（墙壁分类、泛洪填充、选择性反转），其余部分均无法独立求解。

从角落标记出发进行泛洪填充，根据可达性将路径分为可达和不可达两段，仅在可达段内反转颜色序列，同时擦除装饰性墙壁碎片。

**输入结构**：约 15x15 网格，黑(0)背景。蓝(1)像素组成墙壁障碍，将网格空间分隔。一条多色 4-连通单像素宽路径（使用红(2)、绿(3)、黄(4)、橙(7)等颜色，每种颜色在路径上出现至少一次）蜿蜒穿过网格，恰好有两个端点（仅有一个路径邻居的像素）。路径不与蓝色墙壁相邻（路径和墙壁之间至少隔一个背景像素）。一个品红(6)单像素位于网格某个角落，作为泛洪填充的起始标记。部分蓝色墙壁组件与网格边界 4-连通（结构性墙壁），其余蓝色组件完全位于网格内部、不触及边界（装饰性碎片）。生成约束：路径必须同时穿过可达区域和不可达区域，即结构墙至少将路径切分为两段；每段至少包含 3 个路径像素。

**规则**：
1. 将蓝(1)墙壁按 4-连通分组，区分结构墙（组件中至少一个像素位于网格边缘行/列）与装饰墙（组件完全不触及网格边缘）。
2. 擦除所有装饰墙（替换为黑(0)背景）。
3. 从品红(6)角落标记出发，通过背景像素进行泛洪填充（被结构墙阻断），标记所有可达的背景像素。
4. 路径像素中，4-邻域内存在至少一个可达背景像素的，标记为"可达路径像素"；其余为"不可达路径像素"。
5. 沿路径从一端走到另一端（选择行号更小的端点为起点；行号相同则选列号更小的），收集所有可达路径像素的颜色子序列，将该子序列原地反转（第一个可达像素获得最后一个可达像素的原始颜色，依此类推）。
6. 不可达路径像素保持原色不变。品红标记保持不变。

**关键洞察**：墙壁的边界连通性决定了哪些是真正的空间屏障，从而决定了泛洪填充的可达范围；可达范围又精确划定了路径上哪些像素参与颜色反转——同一条路径上的像素可能因可达性不同而经历完全不同的变换。

## 新题 2：计数器定间距的空心矩形排序拼接

**组合逻辑**：[sorting + hollow_only_retained + ignore_distractors](已有) + [counting + counter_disappears](已有) → [concatenate](创新：不再紧贴拼接，而是由计数值决定间距) → [fill + gap_region_recolor](创新：不再桥接两个独立对象的间隙，而是填充排序拼接中由计数值产生的等距间隔)

**来源原语**：sorting / concatenate / hollow_rectangle / solid_square / hollow_only_retained / ignore_distractors / along_main_axis（来自 a680ac02）；counting / counter_pixel / counter_disappears / count_determines_offset（来自 e48d4e1a）；fill / gap_region / between_two_objects / gap_region_recolor（来自 d6ad076f）；enclosed_region / enclosure（来自 b9b7f026）

**依赖链**：空心/实心分类筛选出操作对象 → 计数器数值确定拼接间距 → 排序确定拼接顺序 → 间隔区域由计数值和排序结果共同确定 → 填充间隔。四条信息流（分类、计数、排序、填充）汇聚到最终拼接结果中，缺一不可。

筛选空心矩形并按位置排序，以计数器值为间距拼接成条带，间隔区域填充为青色桥梁。

**输入结构**：约 10x22 网格，黑(0)背景。散布着若干单色 4x4 矩形对象：部分为空心矩形框（外圈一层前景色像素、内部 2x2 为黑(0)背景），部分为 4x4 实心方块（全填充前景色），每个对象颜色各异（使用红(2)、绿(3)、蓝(1)、橙(7)等，不重复）。各对象之间不重叠、不相邻（最小间距 2 像素）。网格右下角有一簇灰(5)像素（1~4 个），排成一行或一列，作为计数器。生成约束：空心矩形至少 3 个、实心方块至少 1 个；空心矩形的列位置（左边界）互不相同。

**规则**：
1. 识别所有 4x4 矩形对象。将含有内部 2x2 黑色封闭区域的标记为空心矩形框，其余为实心方块（干扰项）。丢弃实心方块。
2. 计数灰(5)计数器像素的数量，记为 N。擦除计数器像素（替换为黑(0)）。
3. 按空心矩形的原始列位置（左边界列号）从小到大排序。
4. 将排序后的空心矩形拼接为一条水平条带：第一个矩形左边界对齐输出列 0；相邻矩形之间留 N 列宽的间隔。输出行数为 4，列数为（矩形数 x 4 + 间隔数 x N）。
5. 每段 N 列宽的间隔区域全部填充为青(8)。

**关键洞察**：计数器像素不是位移指令而是间距参数——它控制的不是单个对象的移动距离，而是排序拼接中所有相邻对象之间的统一间隔宽度。

## 新题 3：自相似嵌套扩展中的涌现封闭区域着色

**组合逻辑**：[stamp + scale_up + self_similar_nesting + foreground_positions_determine_stamp](已有) → [flood_fill](创新：不再从角落标记启动，而是检测扩展后涌现的封闭背景区域) → [recolor](创新：着色目标不是已有区域，而是扩展操作在宏观尺度涌现出的新拓扑结构)

**来源原语**：stamp / scale_up / sprite / self_similar_nesting / foreground_positions_determine_stamp（来自 8f2ea7aa）；flood_fill / reachability（来自 8f3a5a89）；recolor（来自 3bd292e8）；enclosed_region / enclosure / object_with_hole_selected（来自 b9b7f026）

**依赖链**：自相似扩展将图案的前景像素位置作为印章放置掩码 → 扩展后，多个印章副本的空间排列可能在宏观尺度上围合出原始图案中不存在的封闭背景区域 → 封闭区域检测识别这些涌现的孔洞 → 孔洞被重涂色。涌现封闭是扩展的几何必然结果，但仅从原始图案无法直接预测。

将紧凑图案的每个前景像素位置替换为图案自身的完整副本，然后在扩展结果中找到因副本排列而涌现的封闭背景区域并着色。

**输入结构**：网格尺寸为图案边界框边长的平方（例如图案为 4x4 边界框，则网格为 16x16）。网格包含一个单色（如蓝(1)）紧凑图案：一个 4-连通的前景像素集合，像素数在 6~12 之间，边界框为正方形（3x3 或 4x4 或 5x5）。图案占据网格的左上角区域，其余为黑(0)背景。生成约束：图案必须满足以下条件——经自相似扩展后，至少存在一个 4-连通的背景区域被前景像素完全包围（不与网格边界连通）。例如，一个"回"字形或近似环形的图案满足此条件，而一个凸形图案则不满足。图案本身在原始尺度下可以有孔也可以没孔。

**规则**：
1. 裁剪图案的边界框，得到一个 KxK 的小矩阵（K 为边界框边长）。
2. 构造 K^2 x K^2 的输出网格，初始化为黑(0)。
3. 对于小矩阵中每个前景像素位于局部坐标 (r, c) 的位置，将完整的 KxK 小矩阵粘贴到输出网格的第 (r*K) 行至第 (r*K+K-1) 行、第 (c*K) 列至第 (c*K+K-1) 列。背景像素位置对应的块保持全黑。
4. 在扩展后的输出网格中，用泛洪填充从网格四角同时出发，标记所有与网格边界 4-连通的背景像素为"外部背景"。
5. 未被标记的背景像素即为"涌现封闭区域"。将所有涌现封闭区域的像素重涂为橙(7)。

**关键洞察**：图案在原始尺度下的拓扑结构（是否有孔）和自相似扩展后的宏观拓扑结构是不同的——一个无孔的 C 形图案经扩展后可能围合出封闭区域。求解者必须在脑中完成扩展才能判断哪些区域被封闭。

## 新题 4：箭头方向编码的奇偶条纹射线

**组合逻辑**：[ray_extend + crossbar_determines](创新：箭头不再用于标记边框端点，而是为附近的标记像素指定射线发射方向) + [parity_alternation + alternating_fill_to_edge](创新：奇偶交替不再作用于单一标记的右向射线，而是作用于由箭头指定方向的多条射线) → [recolor at trail_intersection](创新：不同射线交叉处产生新颜色，而非固定的黄色对角线)

**来源原语**：ray_extend / arrow_sprite / crossbar_determines / orientation_aligned / frame_endpoint（来自 689c358e）；ray_extend / parity_alternation / alternating_fill_to_edge / isolated_pixel（来自 97999447）；trail_intersection / recolor（来自 ac605cbb）

**依赖链**：箭头横杆偏移编码方向 → 每个标记像素根据最近箭头获得射线方向 → 射线沿指定方向延伸并以奇偶交替着色 → 不同颜色射线在同一像素相交时产生混合色。方向编码、奇偶规则、交叉处理三层逻辑紧耦合。

根据箭头精灵编码的方向从各标记像素发射奇偶条纹射线，射线交叉处产生特定颜色。

**输入结构**：约 16x16 网格，黑(0)背景。包含 2~4 个单像素标记，颜色各异（如红(2)、绿(3)、蓝(1)）。另有 2~4 个灰(5)箭头精灵：每个箭头由 6 个灰色像素组成，沿主轴方向排列一条 4 像素长的杆，在杆的靠近尖端一侧排列一条 3 像素长的垂直横杆（横杆相对于杆中心的偏移方向指示箭头指向）。箭头的主轴为水平或垂直。标记像素与箭头精灵不重叠、不相邻。生成约束：每个标记像素的最近箭头（标记像素到箭头精灵任意像素的最小曼哈顿距离）是唯一的（无并列）；至少存在两条射线在网格内相交。

**规则**：
1. 对每个箭头精灵，根据横杆偏移方向确定其指向：横杆靠近杆的哪一端，箭头就指向那一端（例如水平杆上横杆偏左 → 箭头指向左；垂直杆上横杆偏上 → 箭头指向上）。
2. 对每个标记像素，找到与其曼哈顿距离最近的箭头精灵。该箭头的指向即为此标记像素的射线方向。
3. 从每个标记像素出发，沿其射线方向逐像素延伸至网格边界。沿射线方向，距标记偶数步（0, 2, 4, ...）的像素涂为标记的颜色，奇数步（1, 3, 5, ...）的像素涂为灰(5)。标记像素本身算第 0 步（保持自身颜色）。
4. 若两条不同颜色的射线占据同一像素，该像素涂为黄(4)，覆盖之前的颜色（无论是标记色还是灰色）。同色射线交叉处保持该颜色不变。
5. 箭头精灵本身保持灰(5)不变。射线经过箭头精灵像素时，不覆盖箭头像素（箭头像素优先保留）。

**关键洞察**：箭头的横杆位置是一个隐式的方向编码——必须对比多个示例才能确认横杆偏移与指向的对应关系，且这个方向决定了射线的几何走向，进而决定了哪些射线会相交。

## 新题 5：封闭孔洞计数驱动的空心对象选择性镜像与位移

**组合逻辑**：[enclosure + object_with_hole_selected](创新：封闭区域不仅用于筛选对象，其面积还作为后续位移的参数) → [mirror + separator_as_reflection_axis](创新：镜像操作仅作用于筛选出的空心对象，而非所有前景) → [slide via count_determines_offset](创新：位移量不来自独立的计数器像素，而来自对象自身的封闭区域面积) + [erase + ignore_distractors](已有)

**来源原语**：mirror / separator_line / separator_as_reflection_axis / in_place_color_swap（来自 2b01abd0）；hollow_rectangle / enclosed_region / enclosure / object_with_hole_selected（来自 b9b7f026）；counting / count_determines_offset（来自 e48d4e1a）；ignore_distractors / solid_square（来自 a680ac02）；slide（来自 025d127b）；erase（来自 8f3a5a89）

**依赖链**：封闭区域检测 → 同时产生两个信息：（1）筛选出空心对象（有孔的被保留），（2）孔洞面积值 K → K 作为位移距离 → 镜像产生对称副本 → 原件平移 K 格。分析步骤同时服务于筛选和参数化，形成扇出依赖。

识别含封闭孔洞的对象，将其跨分隔线镜像，并将原件沿水平方向位移孔洞面积对应的格数，丢弃无孔洞的干扰对象。

**输入结构**：约 12x18 网格，黑(0)背景。一条灰(5)全宽水平分隔线将网格分为上下两半。上半区包含 3~5 个单色矩形对象（每个颜色不同，使用红(2)、绿(3)、蓝(1)、橙(7)等）：部分为空心矩形框（边框一像素宽、内部为黑(0)封闭区域，整体尺寸 3x3 至 6x6 不等），部分为同尺寸范围的实心矩形块。下半区为纯黑(0)背景。各对象互不重叠、互不相邻（最小间距 1 像素），且距离分隔线至少 1 像素。生成约束：每个空心矩形的封闭面积（内部黑色像素数）各不相同；上半区有足够水平空间容纳位移后的对象不超出网格边界（若某对象位移后会超出右边界，则向左位移）。

**规则**：
1. 识别上半区所有矩形对象，按 4-连通性分组。对每个对象，检测其边界框内是否存在被该对象像素完全包围的 4-连通黑(0)区域（封闭孔洞）。

**关键洞察**：对象的内部拓扑结构（有无孔洞及孔洞面积）同时承担两个角色——筛选哪些对象参与变换和决定位移距离——这是一个分析步骤的扇出效应。

## 新题 9：缺陷标记改变前景拓扑后的支撑滑动

**组合逻辑**：[surround_marking + outlier_selection](创新：标记环绕不再是最终输出，而是中间步骤——橙色光晕改变了前景的像素分布) → [slide + shift_if_pixel_beyond + support](创新：滑动规则作用于经过缺陷标记后的修改前景，橙色光晕像素参与支撑判定，导致滑动结果与未标记时不同) + [erase 薄刺](已有)

**来源原语**：surround_marking / defect_pixel / foreground_region / neighborhood_surround / outlier_selection（来自 71e489b6）；slide / fg_object / contour_bound / support / shift_if_pixel_beyond（来自 025d127b）；erase（来自 71e489b6）

**依赖链**：缺陷检测识别异常像素 → 薄刺擦除改变前景形状 → 缺陷环绕标记添加橙色像素改变前景拓扑 → 修改后的前景拓扑决定每个像素的东南方是否有支撑 → 支撑判定决定滑动行为。前一步的几何修改直接改变后一步的判定条件。

检测蓝色前景中的黑色缺陷并用橙色环绕标记，擦除薄刺，然后在修改后的前景上执行支撑滑动。

**输入结构**：约 13x13 网格，黑(0)背景。蓝(1)前景像素构成 1~2 个较大的 4-连通区域（每个区域 15~40 像素）。每个区域内部含有 1~2 个小黑洞（1~2 个黑色像素被蓝色完全 8-邻域包围）。区域边缘可能有 1~2 个薄刺（蓝色像素的 4-邻域中有 3 个或更多黑色像素，即该蓝色像素仅有 0~1 个蓝色 4-邻居，且不属于主体区域的核心结构）。生成约束：缺陷（小黑洞）位于区域的非对称位置，使得橙色环绕标记对支撑判定产生实质影响（即标记前后至少有一个像素的滑动判定不同）。

**规则**：
1. 识别薄刺像素：蓝(1)像素若其 4-邻域中蓝色像素数量 <= 1 且其 8-邻域中黑色像素数量 >= 5，则为薄刺。擦除薄刺（替换为黑(0)）。
2. 识别缺陷黑洞：黑(0)像素若其 8-邻域全部为蓝(1)像素（或橙(7)、网格边界之外），则为缺陷像素。对每个缺陷像素，将其 8-邻域中所有蓝(1)像素重涂为橙(7)。缺陷像素本身保持黑(0)。
3. 将蓝(1)和橙(7)像素统一视为"前景"。对每个前景像素，检查其右下方（行号更大且列号更大的位置）是否存在另一个前景像素。若存在，将当前像素向右移动一列。若不存在（即当前像素是最右下方的前景像素之一），保持不动。
4. 移动按从右下到左上的顺序逐像素执行（行号从大到小，同行列号从大到小），每个像素基于当前网格状态判定是否移动。移动后原位置变为黑(0)。
5. 缺陷黑洞像素不参与移动，保持黑(0)。

**关键洞察**：橙色环绕标记看似只是视觉高亮，实则改变了前景的像素分布——新增的橙色像素可能为某些原本没有东南支撑的蓝色像素提供了支撑，使其发生滑动；反之，擦除的薄刺可能移除了某些像素的支撑。缺陷标记和薄刺擦除是滑动行为的隐式参数。

**依赖链**：双轴对称性检测 → 定位实心标记矩形（遮挡区域）→ 通过镜像对称恢复被遮挡的墙壁像素 → 恢复后的完整墙壁拓扑定义了正确的区域分割 → 基于完整拓扑进行二部图交替着色。对称补全是着色的前提条件——若不恢复被遮挡的墙壁，区域拓扑错误，着色结果完全不同。

**输入结构**：约 15x15 网格。网格整体具有水平和垂直镜像对称性（以网格中心为对称中心），除了一个实心品红(6)矩形（3x3 至 5x5）遮挡了部分区域，破坏了对称性。红(2)像素组成墙壁分隔线：一像素宽的线段将网格内部分割为若干 4-连通背景区域。墙壁图案本身也具有双轴对称性（被遮挡部分除外）。黑(0)为背景色。品红色仅出现在遮挡矩形中。生成约束：遮挡矩形覆盖了至少一段墙壁线，使得遮挡前后区域连通性发生变化（即某两个在遮挡下连通的背景区域在恢复墙壁后被分隔为独立区域）；恢复后的区域图构成二部图（无奇数环）。

**规则**：
1. 检测品红(6)实心矩形的位置和尺寸。
2. 对矩形内每个像素，通过水平镜像、垂直镜像或 180 度旋转找到其对称位置。从对称位置中读取非品红的值（若多个对称位置可用且一致，取任一；若仅一个可用，取该值）。用恢复的值替换品红像素。
3. 对恢复后的网格，保留所有红(2)墙壁像素不变。
4. 将所有黑(0)背景像素按 4-连通性分为若干区域。建立区域邻接图：若两个区域在某段墙壁的两侧直接相邻（隔一个红色像素），则在图中连边。
5. 对该二部图进行双色着色：包含网格左下角像素的区域涂为灰(5)，与之相邻的区域涂为绿(3)，再相邻的涂为灰(5)，如此交替。
6. 墙壁像素保持红(2)不变。

**关键洞察**：品红遮挡矩形下方隐藏的墙壁线段是区域拓扑的关键——恢复这些墙壁后，原本连通的大背景区域被切分为多个小区域，彻底改变了二部图结构和着色结果。对称补全不是终点而是中间步骤，其真正价值在于为后续着色提供正确的拓扑信息。
