## 新题 1：角标记矩形的面积排名同时决定填色与遮挡优先级

**组合逻辑**：[角标记推断矩形](已有，源自 af902bf9) + [面积排名映射填充色](已有，源自 694f12f3) + [面积反序遮挡](创新——将面积比较同时用于颜色分配和图层优先级，源题中两者分属不同机制)

**来源原语**：角标记(corner_marker, af902bf9), 行列对齐(row_column_alignment, af902bf9), 四角标记围定内部(four_corners_define_interior, af902bf9), 填充(fill, af902bf9/694f12f3), 面积比较(area_comparison, 694f12f3), 面积排名映射色(area_rank_maps_color, 694f12f3), 前后遮挡(front_back_occlusion, cf98881b)

**依赖链**：角标记定位 → 推断矩形边界 → 计算各矩形面积 → 面积排名同时确定两件事：(a) 填充颜色，(b) 遮挡层序。面积最小的矩形获得最高优先级（最后绘制，视觉上在最前）。没有面积排名就无法确定颜色，没有颜色也无法验证遮挡顺序，两者通过同一个排名绑定。

从黄色角标记推断出的重叠矩形，按面积排名分配颜色并按面积从大到小依次绘制（小的在最上层）。

**输入结构**：黑(0)背景的网格，约 15x15。网格中散布若干黄(4)像素，每 4 个黄像素构成一组角标记——它们恰好共享两个行坐标和两个列坐标，围定一个轴对齐矩形。共有 3 组角标记，定义 3 个矩形。这些矩形的内部在输入中为黑(0)。至少两个矩形的边界框存在空间重叠（即投影到行或列时有交集区域）。矩形面积（含边框的总像素数 = 宽 x 高）互不相同，最小不低于 3x3，最大不超过 8x8。除黄色角标记外无其他前景色。生成约束：每个黄色像素仅属于一组角标记，各组不共享角标记像素。

**规则**：
1. 识别每组 4 个黄(4)像素，它们共享恰好两个行值和两个列值，由此确定一个矩形的四个角。矩形区域为该四角围成的轴对齐矩形（含边框行列）。
2. 计算每个矩形的面积（宽 x 高，以像素计）。按面积升序排列，分配填充颜色：最小面积 → 蓝(1)，中等面积 → 红(2)，最大面积 → 绿(3)。
3. 按面积**降序**依次填充矩形（先填最大的，后填最小的）。每个矩形的所有像素（含原角标记位置）都涂为其对应颜色。后绘制的覆盖先绘制的，因此面积最小的矩形（蓝(1)）最后绘制，在重叠区域位于视觉最上层。
4. 移除所有未被矩形覆盖的黄(4)像素（理论上不会剩余，因为角标记属于矩形边界）。输出中不应出现黄(4)。

**关键洞察**：面积排名在此题中承担双重角色——既是颜色的分配依据，又是遮挡层序的决定因素。求解者必须同时从示例中归纳出"排名→颜色"映射和"小面积优先显示"的遮挡规则，二者由同一个面积排序驱动，删除任一侧都无法独立确定输出。

## 新题 2：螺旋路径作为周期瓦片的选择性揭示蒙版

**组合逻辑**：[周期瓦片推断](已有，源自 29ec7d0e) + [螺旋路径绘制](已有，源自 e5c44e8f) + [螺旋-瓦片交叉约束](创新——螺旋提供空间蒙版决定"哪些位置被揭示"，瓦片提供颜色决定"揭示成什么颜色"，二者在每个输出像素处交汇)

**来源原语**：周期瓦片(periodic_tile, 29ec7d0e), 最小周期推断填补(smallest_period_inferred_fill, 29ec7d0e), 缺失单元(missing_cell, 29ec7d0e), 种子像素(seed_pixel, e5c44e8f), 障碍像素(blocker_pixel, e5c44e8f), 螺旋绘制(spiral_draw, e5c44e8f), 遇障碍停止(stop_at_blocker, e5c44e8f), 递增步长(increasing_step, e5c44e8f)

**依赖链**：可见瓦片像素 → 推断最小周期 p → 构建 p x p 完整瓦片。同时：种子像素 → 按递增步长展开螺旋路径 → 遇红色障碍停止。两条信息流在每个螺旋路径单元格汇合：该单元格是否在螺旋路径上（由螺旋决定），应填什么颜色（由瓦片周期决定）。删除瓦片推断则颜色未知，删除螺旋路径则填充范围未知。

从种子像素出发沿螺旋路径逐格揭示隐藏的周期色彩瓦片，遇红色障碍停止，非螺旋路径上的缺失单元保持黑色。

**输入结构**：黑(0)背景的网格，约 12x12。网格中散布若干非黑、非灰(5)、非红(2)的彩色像素（可能包含蓝(1)、绿(3)、黄(4)等 2-3 种颜色），它们的位置与某个 p x p（p 为 2、3 或 4）周期瓦片一致——即每个可见像素的颜色等于瓦片在 (row mod p, col mod p) 处的颜色。部分应有颜色的位置为黑(0)（缺失）。可见像素至少覆盖瓦片的每个位置一次，使瓦片可被唯一推断。一个灰(5)像素为螺旋种子，位于某个黑色（缺失）单元格上。2-4 个红(2)像素为障碍，位于黑色单元格上且不与可见瓦片像素重合。生成约束：灰种子和红障碍均不占据可见瓦片像素的位置。

**规则**：
1. 从所有非黑(0)、非灰(5)、非红(2)的可见像素中，推断最小周期 p，使得所有可见像素按 (row mod p, col mod p) 归类后每组内颜色一致。构建 p x p 的完整瓦片 T。
2. 从灰(5)种子像素出发，按以下规则展开方形螺旋：方向依次为右、下、左、上循环；步长序列为 1, 1, 2, 2, 3, 3, 4, 4, ...（每个步长使用两次后递增）。螺旋在无限平面上追踪，超出网格边界的步数照常计数但不产生绘制。
3. 对螺旋路径上的每个网格内单元格：
   - 若该单元格当前为黑(0)，则将其涂为 T[row mod p][col mod p] 对应的瓦片颜色。
   - 若该单元格为已有的可见瓦片像素（非黑非灰非红），保持不变，螺旋继续通过。
   - 若该单元格为红(2)障碍像素，螺旋立即停止（不涂该格），该障碍像素保留为红(2)。
4. 灰(5)种子像素本身被替换为其瓦片颜色 T[seed_row mod p][seed_col mod p]。
5. 不在螺旋路径上的黑色缺失单元格保持黑(0)，即使瓦片为其分配了颜色。未被螺旋触及的红(2)障碍像素保持原位。

**关键洞察**：螺旋不是在涂单一颜色，而是充当选择性揭示蒙版——它决定哪些位置被"点亮"，而周期瓦片决定每个点亮位置的颜色。两个独立的数学结构（螺旋几何 + 周期代数）在每个输出像素处交叉约束，缺一不可。

## 新题 3：对称补全生成同色矩形副本后跨轴桥接

**组合逻辑**：[十字轴对称补全](已有，源自 60d73be6) + [同色矩形桥接](已有，源自 f3b10344) + [对称距离决定桥接拓扑](创新——矩形相对十字轴的距离决定反射副本之间的间隙大小，从而决定哪些副本对可以被桥接、桥接宽度多少)

**来源原语**：十字轴线(cross_axis, 60d73be6), 双轴对称(biaxial_symmetry, 60d73be6), 四象限镜像填充(quadrant_mirror, 60d73be6), 对称补全(symmetry_complete, 60d73be6), 实心矩形(solid_rect, f3b10344), 桥接条(bridge_bar, f3b10344), 同色配对(same_color_pair, f3b10344), 对向间隙(facing_gap, f3b10344), 最短间隙优先连(shortest_gap_first, f3b10344), 连线(draw_line, f3b10344)

**依赖链**：十字轴定位 → 各象限矩形按双轴反射 → 产生同色矩形副本对 → 副本对之间的间隙大小取决于原始矩形到轴的距离 → 仅在间隙行/列重叠达 3 格以上时绘制桥接。没有对称补全就没有同色配对可桥接；没有桥接规则就不知道反射后输出的完整形态。矩形离轴越近，反射副本间隙越小，越容易形成桥接——空间几何与连接判断紧密耦合。

将各象限中的单个矩形通过十字轴反射到四个象限，再在跨轴相邻的同色副本之间绘制桥接条。

**输入结构**：黑(0)背景的网格，约 15x15。一条绿(3)横行贯穿整个网格宽度，一条绿(3)纵列贯穿整个网格高度，交叉形成十字轴。十字将网格分为四个象限。在 2-3 个不同象限中各放置一个实心矩形（至少 2x3 像素），颜色各不相同（从蓝(1)、红(2)、黄(4)、灰(5)、品红(6)、橙(7)中选取），每种颜色仅出现一次。矩形完全位于其所在象限内，不与绿(3)十字轴重叠。无其他前景色。生成约束：每个矩形的行范围或列范围与十字轴的距离至少为 1 格；至少一个矩形在反射后，其副本对跨越十字轴时行或列重叠范围不少于 3 格。

**规则**：
1. 识别绿(3)十字轴：恰好一整行和一整列全为绿(3)。记录十字行号 R 和十字列号 C。
2. 对每个非黑(0)非绿(3)的实心矩形，将其反射到其他三个象限：关于十字行 R 做上下反射，关于十字列 C 做左右反射，关于两者同时反射。反射后的副本保持原矩形的颜色和尺寸。若反射目标象限已有另一颜色的矩形副本占据相同位置，后反射的覆盖先反射的（按颜色在输入中出现的从左到右、从上到下顺序决定反射先后，最后出现的最后反射因而覆盖）。
3. 反射完成后，在所有同色矩形副本对之间检查桥接条件：两个同色矩形必须在水平或垂直方向上隔着仅含绿(3)和黑(0)的间隙面对面，且它们在垂直（若水平面对）或水平（若垂直面对）方向上的重叠范围不少于 3 格。
4. 对每对满足条件的同色矩形，绘制青(8)桥接条：桥接条沿间隙方向从一个矩形的边缘延伸到另一个矩形的边缘（含起止列/行），宽度为重叠范围两端各缩进 1 格后的剩余范围。桥接条覆盖路径上的绿(3)像素。若同一颜色有多对候选桥接，仅绘制间隙最短的那对。
5. 未被桥接条覆盖的绿(3)十字像素保持绿(3)。

**关键洞察**：桥接是否发生不取决于输入中的矩形配对，而取决于对称反射后的副本几何——矩形离十字轴越近，反射副本间隙越小、重叠越大，越容易触发桥接。求解者必须理解对称操作如何改变空间邻接关系，才能预测桥接拓扑。

## 新题 4：对角线段填充掩码像素后经对称轨道传播解析剩余掩码

**组合逻辑**：[对角线连线](已有，源自 55783887) + [D4 对称轨道补全](已有，源自 47996f11) + [对角线提供对称锚点](创新——对角线段绘制产生的新可见像素成为对称轨道中缺失成员的参照源，两个信息系统通过轨道成员关系耦合)

**来源原语**：对角线对齐(diagonal_alignment, 55783887), 连线(draw_line/connect, 55783887), 对称轨道映射(symmetry_orbit_mapping, 47996f11), 掩码像素(masked_pixel, 47996f11), 全对称群轨道约束(full_symmetry_group_orbit_constraint, 47996f11), 对称图案(symmetric_pattern, 47996f11)

**依赖链**：橙色标记对 → 确定对角线段 → 绘制对角线，解析线段上的粉色掩码像素 → 被解析的像素加入"可见集" → D4 对称轨道遍历，每个粉色像素在轨道中查找可见成员 → 若某轨道的唯一可见成员是刚被对角线解析的像素，则该像素的颜色通过轨道传播到远端掩码像素。没有对角线就缺少部分轨道的可见锚点，没有对称轨道就无法解析非对角线上的掩码。

在方形对称色彩图案上，先画一条对角线段解析其上的掩码像素，再利用 D4 对称轨道将所有剩余掩码像素补全。

**输入结构**：正方形网格，边长约 9-11（奇数，使中心唯一）。网格中大部分像素构成一个 D4 对称（关于水平中轴、垂直中轴、主对角线、副对角线均对称）的多色图案，使用 2-3 种颜色（从蓝(1)、红(2)、绿(3)、黄(4)中选取）。部分像素为品红(6)掩码像素，表示缺失值。另有恰好 2 个橙(7)标记像素，位于同一条 45 度对角线上（主对角线或副对角线方向），二者之间间隔至少 2 格。对角线段（含两个端点之间的所有对角格）上可能包含品红(6)掩码像素和已有的非掩码像素。生成约束：(a) 所有非品红(6)、非橙(7)像素严格满足 D4 对称；(b) 每个品红像素的 D4 轨道中，在对角线段绘制后至少有一个可见（非品红）成员——即该成员要么本身就是非掩码像素，要么位于对角线段上因而在绘制后变为橙(7)。

**规则**：
1. 找到两个橙(7)标记像素。确定它们所在的 45 度对角线方向（行差与列差的绝对值相等）。
2. 在两个橙标记之间（含端点）沿对角线逐格绘制橙(7)。对角线段上：已有的非品红(6)非橙(7)像素保持原色不被覆盖（橙色线段在这些位置"跳过"，即这些像素保留原色）；品红(6)掩码像素被替换为橙(7)。
3. 将所有因步骤 2 而变为橙(7)的原品红像素标记为"已解析"。将它们加入可见像素集合。
4. 对每个剩余的品红(6)掩码像素，计算其 D4 对称轨道：以网格中心为对称中心，生成该像素经水平翻转、垂直翻转、主对角线翻转、副对角线翻转、90 度旋转、180 度旋转、270 度旋转后的 7 个像素位置（加上自身共最多 8 个位置，去重后可能少于 8 个）。
5. 在该轨道的所有位置中，找到非品红的可见像素。该可见像素的颜色即为此品红掩码像素的正确颜色，用该颜色替换品红。若可见成员为橙(7)（来自对角线段），则掩码像素也填为橙(7)。
6. 处理顺序不影响结果（因为生成约束保证每个掩码的轨道至少有一个非掩码可见成员）。

**关键洞察**：对角线段的绘制不仅是视觉装饰——它解析了一批掩码像素，使得那些原本轨道中全为掩码（无可见参照）的远端像素获得了参照源。对角线是对称补全得以运行的前提条件，而非独立的装饰操作。

## 新题 5：双面板占用补集构造射线障碍

**组合逻辑**：[双面板对齐取补集](已有，源自 66f2d22f) + [射线延伸遇障碍停止](已有，源自 e5c44e8f/6d58a25d) + [补集作为中间几何结构](创新——占用补集不是最终输出而是射线的阻挡层，两个操作通过中间空间结构耦合)

**来源原语**：双侧对齐(bilateral_alignment, 66f2d22f), 占用补集(occupancy_complement, 66f2d22f), 二值掩码(binary_mask, 66f2d22f), 射线延伸(ray_extend, 6d58a25d), 标记像素(marker_pixel, 6d58a25d), 遇障碍停止(stop_at_blocker, e5c44e8f), 障碍像素(blocker_pixel, e5c44e8f)

**依赖链**：左面板 + 右面板 → 对齐叠加 → 计算占用补集（两面板均为背景的位置） → 补集位置成为灰(5)障碍。同时：下方标记像素 → 向上发射射线 → 射线遇灰(5)障碍停止。补集计算决定障碍分布，障碍分布决定射线长度。不计算补集就不知道障碍在哪，不发射射线就无法确定最终输出。

将左右两面板叠加后的空位标记为障碍，从下方标记像素向上发射射线，遇空位障碍即停。

**输入结构**：网格约 8 列宽、12 行高，分为上下两个区域。上区域（行 0 至行 H-1，约 8 行高）从中间纵列一分为二，形成等宽的左面板和右面板，各约 4 列宽。左面板包含若干蓝(1)前景像素（1-3 个 4-连通单色区域，每个 2-5 像素），其余为黑(0)背景。右面板包含若干红(2)前景像素（1-3 个 4-连通单色区域，每个 2-5 像素），其余为黑(0)背景。下区域（行 H 至行 H+3，约 4 行高）：黑(0)背景中散布若干绿(3)标记像素，每个标记占 1 格，各标记位于不同的列。生成约束：上区域两面板的占用补集（两面板对齐后均为黑(0)的位置）至少有 2 个单元格，且至少一个绿标记像素的列上方存在至少一个补集单元格。

**规则**：
1. 将左面板和右面板按行列对齐（它们在上区域共享相同的行坐标，只是列偏移不同）。具体对齐方式：左面板的第 j 列对应右面板的第 j 列（j = 0, 1, ..., 面板宽度-1）。
2. 对对齐后的每个位置 (i, j)（i 为行号，j 为面板内列号），若左面板 (i, j) 为黑(0) **且** 右面板 (i, j) 也为黑(0)，则在输出的上区域中将该位置标记为灰(5)障碍。输出上区域使用面板的列范围（即输出宽度等于一个面板的宽度）。
3. 对齐后，若某位置在左面板或右面板中至少有一个是非黑前景色，则输出该位置为黑(0)背景（原面板前景色不保留到最终输出，它们的作用仅在于确定补集）。
4. 对下区域的每个绿(3)标记像素，从其正上方一格开始，沿所在列向上逐格发射射线。射线经过的每个上区域单元格：
   - 若为黑(0)（非障碍），涂为绿(3)。
   - 若为灰(5)（障碍），射线停止。该灰(5)像素保持灰色，不被涂为绿色。
5. 射线若到达上区域顶端（行 0）仍未遇到灰(5)障碍，则在行 0 处停止（涂为绿(3)）。
6. 下区域的绿(3)标记像素保留在输出中。下区域其余黑(0)像素保持黑色。

**关键洞察**：占用补集在源题 66f2d22f 中是最终输出，但在本题中仅是一个中间几何结构——它为射线延伸提供阻挡层。求解者必须识别出面板叠加 → 补集计算 → 障碍生成 → 射线阻断这条完整的信息链，而非将补集当作最终答案。

## 新题 6：面板叠加改变连通拓扑后按组件数直方图输出

**组合逻辑**：[透明叠加](已有，源自 cf98881b/6a11f6da) + [连通检测 + 计数](已有，源自 2753e76c) + [排序 + 柱状填充](已有，源自 2753e76c) + [叠加改变拓扑作为计数前提](创新——叠加时的遮挡切断或合并连通体，使得组件数量依赖于叠加顺序，这在源题中不存在)

**来源原语**：透明叠加(transparent_overlay, cf98881b/6a11f6da), 图层优先级(layer_priority, 6a11f6da), 等高面板(equal_height_panel, 6a11f6da), 连通检测(connected_component_detection, 2753e76c), 计数(counting, 2753e76c), 排序(sort, 2753e76c), 按数量降序(sort_by_count_desc, 2753e76c), 柱状填充(histogram_fill, 2753e76c), 靠端对齐(end_aligned_layout, 2753e76c), 擦除(erase, edcc2ff0)

**依赖链**：两面板叠加（底层覆盖顶层）→ 叠加改变 4-连通拓扑（一个大连通体可能被另一面板的像素切割成多个小连通体）→ 对叠加结果做 4-连通检测和分色计数 → 按组件数降序排列 → 输出为右对齐直方图。叠加顺序决定拓扑变化方向，拓扑变化决定计数，计数决定直方图行。整条链中任一环节删除都导致输出不可确定。

将两面板叠加后检测各色 4-连通组件数量，按组件数降序输出右对齐直方图。

**输入结构**：网格约 10 列宽、12 行高。上半区（行 0 至约行 5）为面板 A，下半区（行 6 至约行 11）为面板 B，两面板间无分隔行，高度相同。两面板具有相同的背景色黑(0)。面板 A 包含若干 4-连通单色前景对象，使用 2-3 种颜色（如蓝(1)、黄(4)、橙(7)），每种颜色的对象 1-3 个，每个对象 3-8 像素。面板 B 包含另一组 4-连通单色前景对象，颜色可能与面板 A 部分相同或不同（如红(2)、蓝(1)、绿(3)）。面板 B 中的某些对象在空间上与面板 A 中的对象投影重叠（即若将面板 B 的行坐标平移到与面板 A 对齐后，有像素位置重合）。生成约束：叠加后至少有一种颜色的连通体数量与叠加前（在其原始面板中的数量）不同（即叠加确实改变了拓扑）；叠加后各颜色的组件数量互不相同。

**规则**：
1. 将面板 B 的行坐标平移到与面板 A 对齐（面板 B 的第 0 行对应面板 A 的第 0 行，以此类推），产生一个与单面板等大的合成区域。
2. 叠加顺序：先放置面板 A 的所有像素，再放置面板 B 的非黑像素覆盖其上。即面板 B 的前景色覆盖面板 A 的同位置像素（无论面板 A 该位置是什么颜色）。
3. 在合成结果中，对每种非黑颜色做 4-连通组件检测，统计该颜色的独立连通体数量。
4. 按组件数量降序排列所有出现的颜色。组件数量相同的情况不会出现（生成约束保证）。
5. 输出为一个小网格（直方图）：行数等于参与排序的颜色数，列数等于最大组件数量。每行对应一种颜色（从上到下为组件数递减）。每行的内容为：左侧填充黑(0)背景，右侧填充该颜色，连续像素数等于该颜色的组件数量，右端对齐到网格右边界。

**关键洞察**：叠加不是简单的视觉合成——面板 B 的覆盖可能将面板 A 中的一个大连通体切割成多个碎片（当 B 的像素横贯 A 的对象中段时），也可能在 A 的两个分离对象之间搭桥（当 B 的同色像素恰好连接了 A 的两个同色岛屿时）。这种拓扑改变是组件计数偏离朴素预期的唯一原因。

## 新题 7：图例像素对的空间关系隐式编码精灵体变换类型

**组合逻辑**：[精灵体 + 镜像/旋转](已有，源自 68b16354/e41c6fd3) + [颜色配对驱动重涂色](已有，源自 54dc2872/e9ac8c9e) + [几何关系隐式编码操作类型](创新——图例像素对之间的空间位置不是数据而是指令，几何结构本身编码了变换规则，源题中无此结构)

**来源原语**：精灵体(sprite, e41c6fd3/b1fc8b8e), 镜像(mirror, 68b16354), 重涂色(recolor, e9ac8c9e/edcc2ff0), 颜色配对(color_pairing, 54dc2872), 象限(quadrant, e9ac8c9e), 角落对应(corner_correspond, e9ac8c9e), 印章覆盖(stamp, e41c6fd3)

**依赖链**：图例区的像素对 → 根据颜色匹配确定每对控制哪个精灵体 → 根据像素对的相对空间位置解码变换类型（水平/垂直/旋转） → 对目标精灵体施加该变换 → 同时将精灵体重涂为图例对中目标色。三层信息（控制目标、变换类型、目标颜色）全部编码在同一个两像素结构中，缺少任一层都无法还原输出。需要对比多个示例才能归纳出空间关系→变换类型的映射表。

根据图例区像素对的空间关系解码变换指令，对各象限中的精灵体执行对应的镜像/旋转操作并重新涂色。

**输入结构**：网格约 15x15，由灰(5)水平线和灰(5)垂直线将网格分为 4 个象限（各约 7x7）。三个象限（如左上、右上、左下）各包含一个小型 4-连通单色精灵体（3-6 像素，形状不对称——不关于任何轴对称，以使镜像/旋转产生可区分的结果）。三个精灵体颜色各不相同（如蓝(1)、红(2)、黄(4)）。第四个象限（右下）为**图例区**，包含 3 对像素。每对像素由 2 个 8-邻接（相距恰好 1 格）的单像素组成：其中一个像素的颜色匹配某个精灵体的颜色（称为"源色点"），另一个像素的颜色不匹配任何精灵体且三对的目标色各不相同（如绿(3)、橙(7)、品红(6)，称为"目标色点"）。每对内两个像素的相对位置编码变换类型。三对像素在图例区中互不相邻（相距至少 2 格），且三对的相对位置关系恰好覆盖以下三种之一且各不重复：(a) 同行相邻（目标色点在源色点的左方或右方）；(b) 同列相邻（目标色点在源色点的上方或下方）；(c) 对角相邻（目标色点在源色点的某个对角方向）。生成约束：每种相对位置关系在 3 对中恰好出现一次，且精灵体形状不对称以使变换结果可区分。

**规则**：
1. 识别灰(5)分隔线，将网格分为四个象限。找到不含精灵体的象限作为图例区。
2. 在图例区中找到 3 对 8-邻接像素对。对每一对，根据其中一个像素颜色匹配到目标精灵体。
3. 解码变换类型：根据目标色点相对源色点的方向：
   - **同行**（水平邻接）：对匹配的精灵体执行**水平镜像**（左右翻转）。精灵体在其所在象限内以其边界框中心为轴翻转。
   - **同列**（垂直邻接）：对匹配的精灵体执行**垂直镜像**（上下翻转）。精灵体在其所在象限内以其边界框中心为轴翻转。
   - **对角**（对角邻接）：对匹配的精灵体执行**180 度旋转**。精灵体在其所在象限内以其边界框中心为轴旋转。
4. 执行变换后，将精灵体的所有像素重涂为该图例对中目标色点的颜色。
5. 图例区在输出中清空为黑(0)。灰(5)分隔线保留。精灵体变换前的原始位置像素清空为黑(0)，变换后的新位置像素填充目标颜色。（若变换后精灵体仍在原边界框范围内——例如关于中心的 180 度旋转——则只在原位重绘。）

**关键洞察**：图例像素对的空间几何本身就是变换指令——水平排列意味着水平翻转，垂直排列意味着垂直翻转，对角排列意味着旋转 180 度。求解者必须通过对比多个示例中的图例配置与输出变换结果，归纳出这套"空间即指令"的编码规则，而非从单个示例中直接读出。
