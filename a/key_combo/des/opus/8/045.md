## 新题 1：分区计数驱动同心生长深度

**组合逻辑**：[计数/counting](创新：计数对象从分隔条变为墙围区域) + [同心层填充/concentric_fill](创新：层数由全局区域计数而非固定模式决定) + [分隔墙/partition_wall](双重角色：既定义区域又约束生长边界)

**来源原语**：计数(counting) ← 参考题 1190e5a7/27a28665；同心层填充(concentric_fill)/生长(grow) ← 参考题 a3f84088/5c2c9af4；分隔墙(partition_wall) ← 参考题 62ab2642；种子像素(seed_pixel) ← 参考题 5c2c9af4

**依赖链**：分隔墙定义区域 → 区域计数产生全局参数 N → N 决定每个种子的同心层数 → 分隔墙同时约束同心层的空间生长范围。分隔墙在"定义区域"和"约束生长"中承担双重角色，使得全局结构和局部操作不可分离。

给定分隔墙围出的若干区域，每个区域含一个种子像素；以全部区域数量作为同心壳层数，从每个种子向外生长同心方框，壳层遇墙或边界截断。

**输入结构**：约 13x13 的网格。黑(0)背景。灰(5)一像素宽墙将网格分割为 3~5 个不规则矩形区域（墙为完整的横贯行或纵贯列，或 T 形/十字形交叉）。每个区域内恰好有一个种子像素，种子颜色互不相同，从红(2)、蓝(1)、绿(3)、黄(4)、品红(6)中选取。种子不紧贴墙壁（与最近墙壁至少间隔 1 个像素）。生成约束：每个区域至少 4x4 大小以容纳多层同心壳。

**规则**：
1. 识别灰(5)墙并确定它们分割出的所有区域，计算区域总数 N。
2. 从每个种子像素出发，以种子为中心，向外依次绘制同心方框壳层。种子自身为第 0 层（保留种子颜色），第 1 层为 Chebyshev 距离 1 的 8 个位置，第 2 层为距离 2 的 16 个位置，以此类推。共绘制 N 层壳层（第 0 层到第 N-1 层）。
3. 壳层颜色交替：偶数层（0, 2, 4...）使用种子颜色，奇数层（1, 3, 5...）使用橙(7)。
4. 若壳层中某像素落在灰(5)墙上或网格外，则该像素不绘制（墙保持灰色，网格外丢弃）。若落在另一个种子已绘制的壳层上，同样不绘制（先绘制的保留；绘制顺序为种子按其所在区域面积从小到大，面积相同则按种子行号从上到下、列号从左到右）。
5. 所有灰墙保持不变。

**关键洞察**：壳层数量是一个全局属性（区域总数），而非由种子本身的颜色或位置决定。仅看单个区域无法确定应画多少层——必须知道整张网格被分成了几块。同时，墙既是"计数的依据"又是"生长的边界"，移除任何一个角色都会改变输出。

## 新题 2：重力沉降后反射对称分色

**组合逻辑**：[重力下落/gravity_drop](已有) + [反射对称/reflection_symmetry + 交集差集分别着色/intersection_diff_colored](创新：对称分析的对象从原始输入变为重力沉降后的构型)

**来源原语**：重力下落(gravity_drop)/碰撞停止(collision_stop)/近墙优先结算(nearest_first_settling) ← 参考题 6ad5bdfd；反射对称(reflection_symmetry)/交集差集分别着色(intersection_diff_colored)/重涂色(recolor) ← 参考题 a8610ef7；边墙(edge_wall) ← 参考题 6ad5bdfd

**依赖链**：边墙确定重力方向 → 重力沉降改变形状空间分布 → 沉降后构型决定反射对称分析结果 → 对称交集/差集分别着色。重力沉降是对称分析的前置条件，同一批形状在不同起始位置会产生不同的沉降构型，进而产生不同的对称着色结果。

将散落的小形状按重力堆积到边墙侧，然后对堆积后的形状掩码做左右镜像对称分析：对称交集像素涂一种颜色，差集像素涂另一种颜色。

**输入结构**：约 10x12 的网格。黑(0)背景。底部边缘为一整行红(2)边墙（固定不动）。红墙上方散布 3~5 个蓝(1)小形状，每个形状为 4-连通单色体，3~5 像素，形状各异（非全为矩形）。各形状互不接触，且不接触红墙。生成约束：所有形状的总宽度不超过网格宽度的 80%，保证沉降后不会溢出；网格宽度为偶数，以便定义明确的垂直中心线。

**规则**：
1. 红(2)底边墙固定不动。所有蓝(1)形状以刚体方式向下滑动（重力方向朝红墙）。
2. 沉降顺序：距红墙最近的形状先沉降。每个形状向下逐行移动，直到其任一像素的下一行位置会碰到红墙、网格底边或另一个已沉降的形状，则停止。
3. 沉降完成后，考察所有蓝像素的位置集合 S。定义垂直中心线为列索引 c = (网格宽度 - 1) / 2.0。对于 S 中的每个像素 (r, col)，计算其镜像位置 (r, 网格宽度 - 1 - col)。
4. 若像素 (r, col) 在 S 中，且其镜像 (r, 网格宽度 - 1 - col) 也在 S 中 → 将该像素重涂为绿(3)。
5. 若像素 (r, col) 在 S 中，但其镜像不在 S 中 → 将该像素重涂为橙(7)。
6. 红墙保持红(2)，背景保持黑(0)。

**关键洞察**：绿/橙着色取决于沉降后的构型而非原始位置。若跳过重力步骤直接对原始位置做对称分析，会得到完全不同的结果。需要对比多个示例才能确认"先沉降后分析"的顺序。

## 新题 3：对角链拓扑分类门控空心方框变换

**组合逻辑**：[连通检测/connected_component_detection + 对角链式连接/diagonal_chain](已有) + [方框换为十字掩模/square_to_cross_mask + 擦除/erase](创新：变换是否执行由外部拓扑分类决定，而非无条件应用)

**来源原语**：连通检测(connected_component_detection)/对角链式连接(diagonal_chain)/仅对角接触变色(diagonal_touch_recolor) ← 参考题 ecb67b6d；方框换为十字掩模(square_to_cross_mask)/擦除(erase)/空心矩形(hollow_rect) ← 参考题 6c434453；重涂色(recolor) ← 参考题 6c434453/ecb67b6d

**依赖链**：灰像素拓扑分类（对角链 vs 非对角链）→ 分类结果与蓝方框的空间邻接关系 → 决定每个方框是变换为十字还是被擦除。三个环节中删除任一个都无法确定方框的命运：无分类则不知哪些灰区域"有效"，无邻接检测则不知哪些方框受影响，无条件变换则不知做什么操作。

检测灰色 8-连通区域中哪些是对角链结构，然后对每个蓝色空心方框判定：若与对角链区域相邻则变换为红色十字，否则整体擦除。

**输入结构**：约 14x14 的网格。黑(0)背景。灰(5)像素形成 3~5 个互不相连的 8-连通区域（每个 4~8 像素），形态各异：其中一部分是"对角链"（其 4-连通分量之间仅通过对角角点连接，形成非分支的阶梯状链条或环），另一部分是普通连通块（含有同边接触的像素，即至少两个像素 4-连通）。蓝(1)像素形成 2~4 个 3x3 空心方框（每个方框的 8 个边界像素为蓝，中心像素为黑）。方框之间互不重叠，与灰区域也不重叠。部分方框与某个对角链灰区域有 4-邻接关系（即方框 3x3 范围的外侧紧邻灰像素），部分方框不与任何对角链灰区域相邻。生成约束：至少有一个方框与对角链相邻，至少有一个方框不与任何对角链相邻，以使两种输出都出现。

**规则**：
1. 找出所有灰(5) 8-连通区域。对每个区域进行拓扑分类：将其分解为 4-连通分量（"瓣"），若所有瓣之间仅通过对角角点相连（无任何两个像素共享行列方向的边），且连接模式为非分支链或简单环，则标记为"对角链"。
2. 对每个蓝(1) 3x3 空心方框，检查其 3x3 范围的 4-邻域扩展区（即方框外圈一像素宽的环带）中是否存在被标记为"对角链"的灰区域的像素。
3. 若存在（方框邻接对角链）：将方框变换为十字——擦除四个角像素为黑(0)，将四个边邻像素和中心像素重涂为红(2)。
4. 若不存在（方框不邻接任何对角链）：擦除方框全部 8 个边界像素为黑(0)，中心保持黑(0)。
5. 所有灰(5)区域无论分类结果如何，均保持灰色不变。

**关键洞察**：蓝方框本身没有任何属性差异（都是相同的 3x3 空心方框），其不同命运完全由附近灰区域的拓扑性质决定。求解者必须同时理解对角链的定义和邻接触发条件，缺一不可。

## 新题 4：对称补全重塑障碍景观影响射线路径

**组合逻辑**：[对称补全/symmetry_completion](创新：补全结果不是最终输出，而是改变后续操作的障碍环境) + [射线延伸/ray_extend](创新：射线的终点由补全后的障碍决定，而非原始输入) + [障碍像素/obstacle_pixel](双重角色：原始障碍 + 补全产生的新障碍)

**来源原语**：对称补全(symmetry_completion)/镜像(mirror)/缺失区域(missing_patch) ← 参考题 9ecd008a/4c5c2cf0；射线延伸(ray_extend)/障碍像素(obstacle_pixel) ← 参考题 891232d6/13713586；绘制(drawing) ← 参考题 13f06aa5

**依赖链**：蓝像素模式含缺口 → 对称补全填充缺口（产生新蓝像素）→ 新蓝像素成为射线障碍 → 射线终点由补全后的完整障碍集决定。删除对称补全步骤，射线会穿过缺口到达不同高度；删除射线步骤则无法产生黄色输出。

先将一个有缺口的蓝色图案做左右镜像补全，然后从底部种子向上投射射线，射线遇到补全后的障碍即停止。

**输入结构**：约 12x14 的网格，宽度为偶数。黑(0)背景。蓝(1)像素在网格上半部分形成一个大致关于垂直中心线左右对称的图案（如散布的水平短线段、小方块等），但有 2~3 处缺口：某些位置左侧有蓝像素而右侧对称位置为黑(0)，或反之。红(2)像素形成 1~2 个孤立的单像素障碍，位于网格中部。绿(3)种子像素沿底部边缘放置（2~3 个，不在最底行的墙上而在倒数第二行），每个种子占一个像素。生成约束：至少有一个绿种子的正上方路径上存在因对称补全而新增的蓝像素（即该路径上有一个缺口位置会被补全填充），使得补全步骤对射线结果产生实质影响。

**规则**：
1. 对蓝(1)像素图案做左右镜像补全：以网格垂直中心线为对称轴（中心列索引 = (宽度-1)/2.0），对于每对对称列 (c, 宽度-1-c) 的每一行，若一侧为蓝而另一侧为黑，则将黑侧填充为蓝(1)。若两侧都已为蓝或都为黑，则不改变。红(2)像素不参与对称补全（不会被覆盖，也不作为对称源）。
2. 补全完成后，从每个绿(3)种子出发向上投射射线（逐行上移，列不变）。射线经过的每个黑(0)像素涂为黄(4)。
3. 射线遇到第一个非黑像素（蓝(1)——包括补全新增的、红(2)或网格顶部边界）时停止。终止像素本身不涂黄。
4. 绿种子保持绿(3)。所有蓝像素（原始+补全）保持蓝(1)。红像素保持红(2)。

**关键洞察**：射线的高度取决于补全后的障碍布局，而非原始输入。在原始输入中看到缺口处射线本应穿过，但补全后该缺口被填充，射线提前终止。需要多个示例才能发现"先补全后投射"的两步关系，而非"射线对原始输入投射"。

## 新题 5：竞争性同心生长与领地决定方框命运

**组合逻辑**：[生长/grow + 同心正方形层/concentric_layer](已有) + [碰撞停止/collision_stop](创新：从重力碰撞改为同心生长碰撞) + [方框换为十字掩模/square_to_cross_mask + 擦除/erase](创新：变换条件从无条件改为由领地归属决定) — 形成循环依赖：黄方框阻挡生长 → 生长决定领地 → 领地决定方框变换

**来源原语**：生长(grow)/同心方框层(concentric_layer)/种子像素(seed_pixel) ← 参考题 5c2c9af4；碰撞停止(collision_stop) ← 参考题 6ad5bdfd；方框换为十字掩模(square_to_cross_mask)/擦除(erase)/空心矩形(hollow_rect) ← 参考题 6c434453；重涂色(recolor) ← 参考题 a8610ef7

**依赖链**：种子同心生长 → 黄方框作为不可穿越障碍分割生长空间 → 各种子的领地由生长结果确定 → 方框周围的领地归属决定其变换方式。这是一个循环约束：方框形状影响领地边界，领地边界又决定方框的命运。

多个种子同时向外做同心生长争夺领地，黄色空心方框作为障碍阻挡生长；生长结束后，每个方框根据其周围领地的归属情况决定变换为十字或被擦除。

**输入结构**：约 14x14 的网格。黑(0)背景。3 个种子像素，颜色分别为红(2)、蓝(1)、绿(3)，分散放置（彼此 Chebyshev 距离至少 5）。2~3 个 3x3 黄(4)空心方框（8 个边界像素为黄，中心为黑），放置在种子之间的区域。方框之间不重叠，不与种子重叠。生成约束：至少一个方框的 4-邻域扩展区在生长后仅被单一种子的领地包围，至少一个方框的邻域涉及两个或以上种子的领地。

**规则**：
1. 三个种子同时向外做同心方框生长。第 d 轮（d=1,2,3...），每个种子尝试占领其 Chebyshev 距离为 d 的所有像素。
2. 占领规则：一个像素只能被一个种子占领。黄(4)像素不可被占领（方框是永久障碍）。若某像素在第 d 轮被多个种子同时到达，则该像素归属于当前已占领像素最少的种子（已占领数相同则按种子在网格中的位置排序：行号小的优先，行号相同则列号小的优先）。
3. 生长持续进行，直到没有新像素可被任何种子占领（所有可达黑像素均已被占领或被方框阻隔）。
4. 生长结束后，检查每个黄(4) 3x3 空心方框：考察方框 3x3 区域的 4-邻域扩展带（方框外围一圈像素，不含方框自身像素和网格外像素）中被占领像素的种子归属。
5. 若扩展带中所有被占领像素均属于同一个种子 → 将方框变换为该种子颜色的十字：四个角像素擦除为黑(0)，四个边邻像素和中心像素涂为该种子颜色。
6. 若扩展带中存在属于两个或以上种子的像素 → 擦除整个方框：所有 8 个黄色边界像素和中心像素全部设为黑(0)。

**关键洞察**：黄色方框既是生长的障碍（影响领地边界的划分），又是被领地结果决定命运的对象。移动一个方框会改变领地的形状，进而可能改变其自身和其他方框的变换结果。这种双向依赖使得无法将"生长"和"方框变换"作为独立步骤理解。

## 新题 6：像素段翻转解码区域着色方案

**组合逻辑**：[局部翻转/local_reverse](创新：翻转不是最终输出，而是解码步骤，揭示隐含的颜色映射信息) + [计数/counting + 极值面积决定颜色/extreme_area_determines_color](创新：面积排序不直接映射到固定颜色，而是映射到翻转解码后的颜色序列) + [分隔墙/partition_wall + 墙分隔区域/wall_partitions_regions](已有)

**来源原语**：局部翻转(local_reverse)/中心分隔像素(center_separator)/像素段(pixel_segment)/各侧独立翻转(independent_side_reverse) ← 参考题 833966f4；计数(counting)/极值面积决定颜色(extreme_area_determines_color) ← 参考题 62ab2642；分隔墙(partition_wall)/墙分隔区域(wall_partitions_regions)/连通区域(connected_region) ← 参考题 62ab2642；重涂色(recolor) ← 参考题 62ab2642

**依赖链**：像素段需先翻转才能正确读取颜色序列 → 区域面积排序产生索引 → 颜色序列按索引分配到区域。翻转步骤和排序步骤缺一不可：跳过翻转会读到错误颜色，跳过排序会分配到错误区域。

网格顶部有编码柱（5x1 像素段），需做局部翻转后读取顶端像素颜色，形成颜色序列；下方区域按面积排序后，依序被涂上该颜色。

**输入结构**：约 12x16 的网格。黑(0)背景。网格分为上下两部分：

上部（前 5 行）：包含 K 个垂直的 5x1 像素柱（K = 3~4），柱间以黑像素分隔，柱与柱在不同列上。每个柱从上到下为 5 个像素：位置 0、1 为上段（两个不同颜色），位置 2 为灰(5)中心分隔符，位置 3、4 为下段（两个不同颜色）。每个柱的 5 种颜色从红(2)、蓝(1)、绿(3)、黄(4)、品红(6)、橙(7)、青(8)、栗(9)中选取，灰(5)仅用于中心分隔符。各柱按列位置从左到右排列。生成约束：每个柱的位置 0 和位置 1 颜色不同（翻转后读取结果才有意义），不同柱翻转后的顶端像素颜色互不相同。

下部（第 6 行起）：灰(5)一像素宽墙将剩余区域分割为恰好 K 个黑(0)矩形区域。各区域面积互不相同。

**规则**：
1. 找到上部的 K 个 5x1 像素柱，按列位置从左到右排序。
2. 对每个柱做局部翻转：保持位置 2 的灰(5)中心像素不动，交换位置 0 和位置 1（上段翻转），交换位置 3 和位置 4（下段翻转）。
3. 翻转后，读取每个柱的位置 0（最顶端）像素颜色 → 按柱的左右顺序形成颜色序列 C = [C1, C2, ..., CK]。
4. 在下部找到 K 个墙围区域，按面积从小到大排序。
5. 将颜色序列依次分配：面积最小的区域涂色 C1，次小的涂色 C2，...，面积最大的涂色 CK。
6. 灰(5)墙保持不变。上部像素柱在输出中保持翻转后的状态。

**关键洞察**：如果不做翻转而直接读取顶端像素，会得到错误的颜色序列（因为原始位置 0 的颜色不是目标颜色，翻转后位置 1 的颜色上移到位置 0 才是）。需要对比多个示例才能发现必须先翻转再读取。面积排序则增加了另一层间接性——颜色不是按区域位置而是按面积大小分配。

## 新题 7：精灵体方向编码加频率定长射线

**组合逻辑**：[质心偏移定向/centroid_bias_dir + 方向精灵体/directional_sprite](已有局部方向解码) + [频率匹配/frequency_matching + 计数/counting](创新：频率不用于筛选颜色，而用于决定射线长度) + [射线延伸/ray_extend](创新：射线长度不由边界或障碍决定，而由同色标记的全局出现频率决定) + [遮挡覆盖/occlusion_overwrite](新增冲突解决层)

**来源原语**：方向精灵体(directional_sprite)/质心偏移定向(centroid_bias_dir)/标记像素(marker_pixel) ← 参考题 13f06aa5；射线延伸(ray_extend)/绘制(drawing) ← 参考题 13f06aa5/13713586；频率匹配(frequency_matching)/计数(counting) ← 参考题 2685904e；遮挡覆盖(occlusion_overwrite)/按距离排序绘制(draw_ordered_by_distance) ← 参考题 13713586

**依赖链**：精灵体几何 → 解码射线方向（局部操作） → 统计各标记颜色的全局出现次数 → 出现次数决定射线长度（全局参数驱动局部操作） → 多条射线可能交叉 → 高频颜色的射线覆盖低频颜色的射线（全局频率同时决定长度和优先级）。方向和长度来自完全不同的信息源（局部几何 vs 全局统计），且冲突解决规则也耦合到频率上。

每个方向精灵体的几何形状编码了射线方向，而射线的长度由同色标记在全网格中的出现频率决定；射线交叉时，高频颜色覆盖低频颜色。

**输入结构**：约 15x15 的网格。黑(0)背景。灰(5)像素形成 4~6 个小型 8-连通方向精灵体（每个约 7 像素），散布在网格中。每个精灵体内嵌入一个单像素标记，标记颜色从红(2)、蓝(1)、绿(3)、黄(4)中选取。同一颜色的标记可以出现在多个精灵体中（例如 2 个精灵体含红标记、3 个含蓝标记等）。每个精灵体的灰像素相对于标记的分布不对称：灰像素的质心偏向标记的某一侧，该偏向方向的反方向即为射线的发射方向（上、下、左或右四个正方向之一）。生成约束：不同颜色的标记出现次数互不相同（例如红出现 2 次、蓝 3 次），且至少存在两条射线在延伸后路径有交叉。

**规则**：
1. 对每个精灵体，计算其灰(5)像素相对于标记像素的质心偏移方向。射线方向为质心偏移的反方向（即灰像素集中在标记的左侧 → 射线向右发射；集中在上方 → 射线向下发射；等等）。取四个正方向中与质心偏移反方向最接近的那个。
2. 统计每种标记颜色在所有精灵体中出现的总次数 → 频率 F(颜色)。
3. 从每个标记像素出发，沿其射线方向绘制一条射线。射线长度（不含标记本身）= F(该标记颜色) 个像素。射线使用标记的颜色绘制。若射线延伸过程中超出网格边界，则超出部分不绘制。
4. 若两条不同颜色的射线经过同一像素，则该像素颜色取频率更高的那个标记颜色（F 值大者覆盖 F 值小者）。若频率相同（生成约束已排除此情况），则取标记在网格中位置靠上（行号小）的那条。
5. 灰(5)精灵体本身保持不变。标记像素保持原色。射线不覆盖灰像素（射线像素若落在灰像素上则跳过该位置，继续向前计数直到画满 F 个非灰像素或超出边界）。

**关键洞察**：射线方向是每个精灵体的局部几何属性（质心偏移），而射线长度是一个全局统计属性（同色标记的总出现次数）。单看一个精灵体无法确定射线长度——必须扫描全网格统计同色标记的数量。同时，频率不仅决定长度还决定冲突优先级，使得出现次数多的颜色既画得更长又在交叉处胜出。
