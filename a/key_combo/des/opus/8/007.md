## 新题 1：闸门释放令牌沉降后按连通面积描边

**组合逻辑**：[旋转](已有，作用对象从管道闸门改为通道封锁条) → [重力下落](已有，去掉管道网络约束，改为自由下落) → [连通判定](创新，从二值输出改为全局分量构建，且忽略颜色差异) → [描边](创新，判据从"恰好面积2"改为"面积>=2"，描边对象从输入红色像素改为沉降后的动态连通分量)

**来源原语**：旋转/重力下落/闸门/碰撞停止(2b83f449)、连通判定/连通性/桥接路径(239be575)、描边/尺寸分类/连通分量/边框(b27ca6d3)

**依赖链**：闸门旋转打开通道 → 令牌沿通道自由下落并因碰撞停止 → 沉降位置决定哪些令牌与已有前景对象合并为同一连通分量 → 分量面积决定是否描边。四个环节串联：不旋转则令牌被阻无法下落；不下落则无法确定终点位置；不做连通分量合并则无法得到面积；不按面积判断则无法决定描边对象。

将闸门旋转释放的令牌沉降至已有前景对象之间，按沉降后的全局连通分量面积决定是否为其绘制外框。

**输入结构**：约 14x14 网格，黑(0)背景。网格上半区散布若干灰(5)水平封锁条，每条为 1x3 的水平连续灰像素段，横跨部分列，封锁条所在行的其余像素为黑(0)。封锁条上方散布若干单像素令牌，颜色为蓝(1)、红(2)或绿(3)，每个令牌正下方的路径被至少一根封锁条阻挡。网格下半区散布若干 4-连通单色前景小对象（每个 2~5 像素，颜色为蓝(1)、红(2)或绿(3)），这些对象相互不接触但部分对象之间仅隔 1~3 行/列。生成约束：每个令牌正下方的下落路径上恰好被一根封锁条阻挡；封锁条旋转后不会与任何前景对象重叠；每个令牌下落后恰好停在某个已有前景对象正上方一格或与其相邻，不会落到网格底部悬空处。

**规则**：
1. 将每根灰(5)封锁条原地旋转 90 度变为竖直方向（即 3x1），旋转中心为封锁条的中间像素；旋转后超出网格边界的像素丢弃。旋转后原封锁条占据的左右两端像素变为黑(0)背景，中间像素保持灰(5)竖直放置。
2. 所有令牌同时向下做重力下落，每步下移一行，遇到非黑(0)像素或网格底边时停止（碰撞停止）。令牌保持原色，停在碰撞位置的上一行。如果两个令牌落入同一列，上方令牌会停在下方令牌之上。
3. 忽略灰(5)竖直残留像素（将其视为背景），在所有非黑(0)、非灰(5)像素上构建 4-连通分量，**不区分颜色**——不同颜色的相邻像素属于同一分量。
4. 对每个面积 >= 2 的连通分量，将其边界框向四个方向各扩展 1 像素（裁剪到网格边界内），在扩展框的周边像素中，将所有当前为黑(0)的像素涂为黄(4)。面积为 1 的分量不做任何处理。
5. 若多个分量的扩展框周边有重叠像素，后处理的分量覆盖先处理的（按分量边界框左上角从左到右、从上到下的顺序处理）。

**关键洞察**：令牌的沉降位置取决于旋转后通道的开放情况，而沉降后令牌是否与已有对象合并为大分量取决于它们是否恰好 4-连通相邻——描边的对象并非输入中直接可见的，而是经过重力模拟后动态形成的。

## 新题 2：十字擦除改变迷宫拓扑后寻找最短路径

**组合逻辑**：[十字擦除](已有，作用对象从彩色填充网格改为迷宫墙壁) → [寻路](已有，输入迷宫从静态给定改为经擦除动态修改后的拓扑) + [特定色像素豁免](已有，保护色从红色改为端点色，保护范围从擦除豁免扩展到路径端点保留)

**来源原语**：十字擦除/标记块/保护像素/十字区域/特定色像素豁免(319f2597)、寻路/端点像素/障碍像素/最短路径/四邻接连通/最短路径唯一(b15fca0b)、重涂色(b15fca0b)

**依赖链**：十字擦除移除其行列上的蓝色墙壁像素（但保护红色端点），改变迷宫连通拓扑 → 在修改后的迷宫上寻找两个红色端点间的最短 4-邻接路径 → 将路径上的黑色内部像素涂为黄色。擦除步骤本质上是"开墙"——它打通了原本不连通的走廊，使得路径存在或变短。不执行擦除则最短路径不同甚至不存在；不寻路则擦除只是破坏画面无意义输出。

十字擦除清除迷宫墙壁的特定行列（保留红色端点），改变迷宫拓扑后在新迷宫中找出两端点间唯一最短路径并涂色。

**输入结构**：约 15x15 网格，黑(0)背景。蓝(1)像素构成迷宫墙壁，形成连通的走廊结构（黑色像素为可通行走廊）。恰好两个红(2)像素作为路径端点，分布在走廊中，两者之间在原始迷宫中不存在 4-邻接通路（或存在但较长）。恰好一个 2x2 的灰(5)标记块位于迷宫墙壁区域内（占据 4 个蓝色墙壁像素的位置）。生成约束：标记块的两行两列上存在若干蓝色墙壁像素，擦除这些墙壁后恰好打通一条新走廊，使得两个红色端点之间产生唯一最短 4-邻接路径；红色端点不在标记块的行或列上，或虽在其上但作为保护色被保留。

**规则**：
1. 找到 2x2 灰(5)标记块，选取其占据的两行和两列。
2. 将这些行列中所有蓝(1)像素改为黑(0)（墙壁被擦除，走廊打通），但保留这些行列中的红(2)像素不变。灰(5)标记块自身的 4 个像素也改为黑(0)。
3. 在修改后的网格上，以蓝(1)为障碍、黑(0)为可通行，寻找从一个红(2)端点到另一个红(2)端点的唯一最短 4-邻接路径。
4. 将该最短路径上所有黑(0)内部像素（不含两个红色端点本身）涂为黄(4)。
5. 输出修改后的完整网格（保留所有未被规则修改的像素）。

**关键洞察**：标记块不是单纯的视觉标注——它是迷宫拓扑的修改器，其位置决定了哪些墙壁被清除、走廊如何连通，从而间接控制了最短路径的走向。求解者必须先执行擦除再寻路，顺序不可逆转。

## 新题 3：箭头朝向决定逐对象滑动方向与碰撞堆叠

**组合逻辑**：[朝向推断](已有，从箭头精灵体缺角推断方向) → [滑动](创新，从全局统一方向改为每个对象独立方向，方向由对象自身几何特征决定) → [碰撞停止](已有，从管道边界碰撞改为对象间碰撞及网格边界碰撞) → [擦除](创新，滑动完成后移除方向指示部件)

**来源原语**：朝向推断/箭头精灵体/缺角指示方向(6e19193c)、滑动/标记指示方向/抵达边界(99caaf76)、碰撞停止(2b83f449)、擦除(6df30ad6)

**依赖链**：每个对象的箭头缺角方向 → 决定该对象的独立滑动方向 → 对象按距目标边界的距离排序依次滑动 → 先到位的对象成为后续对象的障碍 → 滑动完毕后擦除所有箭头部件。方向推断决定运动方向，碰撞机制决定终点位置，两者联合才能确定输出。

根据每个对象附带的箭头缺角推断其独立滑动方向，按距离排序逐个滑动至边界或碰撞停止，最后移除箭头部件。

**输入结构**：约 13x13 网格，黑(0)背景。散布 3~5 个互不接触的 8-连通单色对象，每个对象由"主体"和"箭头"两部分组成。主体是一个 4-连通的不规则小图形（3~6 像素，颜色各不相同，取自蓝(1)、红(2)、绿(3)、黄(4)、品红(6)）。箭头是紧贴主体某一侧（上/下/左/右）的 2 像素灰(5)突起，呈"L"形缺一角：箭头的 2x2 边界框中 3 个像素为灰(5)、1 个角为黑(0)背景，缺失的角指向箭头所指方向。每个对象的箭头朝向为上、下、左、右之一。生成约束：所有对象沿各自方向滑动时不会产生路径交叉冲突（即不同对象的滑动轨迹不共享同一行或同一列，或虽共享但滑动方向相同且距离排序不产生歧义）；每个对象滑动后至少移动 1 格。

**规则**：
1. 对每个对象，检查其灰(5)箭头部分的 2x2 边界框中缺失的角位于哪个方位（左上/右上/左下/右下）。缺角所指方向即为该对象的滑动方向：缺角在左上 → 朝左上方推断为朝左（水平分量）或朝上（垂直分量），具体取决于箭头相对于主体的附着侧。规则简化：箭头附着在主体的哪一侧，该对象就朝那个方向滑动（箭头在主体右侧 → 对象朝右滑动；箭头在主体上侧 → 对象朝上滑动，以此类推）。
2. 计算每个对象沿其滑动方向到网格边界的距离（从对象边界框的对应边到网格边缘的像素数）。按此距离从小到大排序处理各对象（距离最短的先滑动）。距离相同时，按对象主体边界框左上角行号从小到大、再按列号从小到大排序。
3. 逐个处理：将整个对象（主体 + 箭头）沿滑动方向逐步平移，每步 1 像素，直到对象边界框的前沿碰到网格边界或碰到已定位对象的非黑(0)像素（停在碰撞前一步的位置）。
4. 所有对象滑动完毕后，将所有灰(5)箭头像素设为黑(0)背景（擦除箭头），仅保留各对象的彩色主体。

**关键洞察**：每个对象的运动方向由自身几何特征（箭头附着侧）独立决定，而非全局统一；先到位的对象成为后续对象的碰撞障碍，因此处理顺序实质性地影响最终布局——这不是简单的"所有对象同时滑到边界"。

## 新题 4：异或合成提取隐藏周期图案并补全

**组合逻辑**：[异或合成](已有，从二值对称差改为多色场景的"恰一为前景"提取) → [补全](已有，从直接找周期改为在异或结果上找周期) + [列周期重复](已有)

**来源原语**：异或合成/半区掩码/前景掩码/对齐/恰一为前景(31d5ba1a)、补全/最小周期单元/局部图案/列周期重复/最小周期扩展(d8c310e9)

**依赖链**：上下两半区各自包含前景图案，单独观察任一半区都看不出周期性 → 异或合成提取两半区的对称差，消除共有的干扰图案 → 异或结果呈现出仅占据部分列的周期性图案 → 找到最小列周期并横向补全到输出全宽。如果跳过异或直接看任一半区，图案混有干扰无法确定周期；如果跳过补全，异或结果只是部分图案不是完整输出。

将上下两半区的前景掩码做对称差以过滤掉共有干扰，从差集中提取最小列周期并补全至全宽输出。

**输入结构**：偶数高度的网格（约 12 行 x 16 列），黑(0)背景。网格严格分为上半区和下半区（各占一半高度，无分隔线）。两个半区共享黑(0)背景。上半区包含蓝(1)前景像素构成的图案 A；下半区包含红(2)前景像素构成的图案 B。图案 A 和图案 B 在各自半区中的**位置**有部分重合（即同一列的对应行都有前景像素）和部分不同。不重合的部分（对称差）构成一个列周期图案，仅覆盖左侧若干列（不超过网格宽度的一半），其余列为纯背景。生成约束：上下两个半区高度相同；对称差图案存在唯一最小列周期 P（P >= 2），且图案至少显示一个完整周期加部分第二周期以使周期可辨认；对称差图案中所有前景像素统一使用品红(6)表示（输出时的颜色）。

**规则**：
1. 将网格按高度等分为上半区（前 H/2 行）和下半区（后 H/2 行），逐位置对齐。
2. 对每个位置 (r, c)（r 为半区内行号，c 为列号），比较上半区 (r, c) 和下半区 (r, c)：若恰好一个为前景（非黑）、另一个为背景（黑），则该位置输出品红(6)；若两者同为前景或同为背景，则输出黑(0)。
3. 得到一个 H/2 行 x W 列的中间网格（异或结果）。
4. 在中间网格中找最小列周期 P：即最小的正整数 P 使得所有已有品红像素满足 grid[r][c] == grid[r][c mod P]。
5. 以周期 P 将品红图案向右复制填满全部 W 列，输出 H/2 行 x W 列的最终网格。

**关键洞察**：两个半区的图案是"信号+噪声"的叠加，单独观察任一半区无法区分哪些是信号（周期图案）哪些是噪声（共有干扰）——只有通过异或合成消除共有部分，真正的周期结构才会浮现，这是一个先解构再重建的过程。

## 新题 5：垂直条延伸交叉点生成对角反弹射线

**组合逻辑**：[射线延伸](已有，从单条延伸改为水平/垂直双向延伸) + [交叉](已有) → [交叉点标记新色](创新，交叉点不仅标色还成为新操作的种子) → [对角射线](创新，从固定起点改为由交叉点动态生成) + [边界反射](已有) → [背景色替换](已有)

**来源原语**：射线延伸/横条段/竖条段/交叉/交叉点标记新色(bdad9b1f)、射线延伸/起点像素/反弹路径/边界反射/对角射线/背景色替换(e179c5f4)、重涂色(e179c5f4, bdad9b1f)

**依赖链**：水平/垂直条段各自延伸到网格全宽/全高 → 延伸后确定交叉点 → 交叉点成为对角反弹射线的发射源 → 射线沿四个对角方向弹射至离开网格 → 所有射线和条段绘制完成后，剩余黑色背景替换为新色。交叉点的位置由条段位置唯一决定，而射线的整个路径由交叉点位置和网格边界共同决定——这不是两道题的串联，而是一个操作（条段延伸）的几何产物（交叉点）成为另一个操作（反弹射线）的输入参数。

将水平和垂直两根短色条各自延伸满行/满列，在交叉点发射四条对角反弹射线直至离开网格，最后将剩余背景替换为新色。

**输入结构**：约 12x12 网格，黑(0)背景。恰好一段水平连续蓝(1)像素（长度 2~4，占据同一行的连续列）和一段垂直连续红(2)像素（长度 2~4，占据同一列的连续行）。两段不接触，且它们所在行与列的交叉像素为黑(0)背景。生成约束：蓝色段和红色段各只有一段；两段所在行列的交叉位置距离四条网格边界均至少 2 像素，确保对角射线能产生至少一次反弹。

**规则**：
1. 将蓝(1)水平段沿其所在行向左右延伸至网格边界，所有新增像素为蓝(1)。
2. 将红(2)垂直段沿其所在列向上下延伸至网格边界，所有新增像素为红(2)。
3. 蓝色行与红色列的交叉像素标记为黄(4)。
4. 从黄(4)交叉点出发，沿四个对角方向（右上、右下、左上、左下）各发射一条射线。每条射线逐步移动（每步行 +/-1、列 +/-1），遇到网格左右边界时水平分量反转（列方向取反），遇到网格上下边界时垂直分量反转（行方向取反）。射线经过的每个像素标记为黄(4)（覆盖该位置原有颜色）。每条射线持续行进直到回到黄(4)交叉点（形成闭合环路）或行进步数超过网格周长的 2 倍时停止。
5. 将网格中所有剩余黑(0)像素替换为青(8)。

**关键洞察**：交叉点不是预设的起点，而是由两根色条的空间位置唯一确定的几何产物——改变任一色条的位置都会改变交叉点，从而完全改变四条反弹射线的路径和最终的背景分割图案。

## 新题 6：缺角三角形轮廓成为十字擦除的保护屏障

**组合逻辑**：[缺角定位](已有) → [连线](已有，画三角形轮廓) → [十字擦除](已有，作用对象从全彩网格改为含三角形轮廓的网格) + [特定色像素豁免](创新，保护色不是输入预设的，而是由前一步几何构造动态生成的)

**来源原语**：连线/标记像素/直角三角形/包围方块/缺角定位/缺角为直角顶点/忽略干扰项(1478ab18)、十字擦除/标记块/保护像素/十字区域/特定色像素豁免(319f2597)

**依赖链**：标记像素定义包围方块 → 缺失角确定直角三角形顶点 → 画出三角形轮廓（青色像素） → 标记块执行十字擦除，但青色轮廓像素受保护不被擦除 → 最终输出中，三角形轮廓是唯一在擦除区域中幸存的结构。如果不画三角形，擦除区域全部清空，无法得到正确输出；如果不执行擦除，三角形轮廓只是叠加的装饰。两个操作通过"保护"机制深度耦合——几何构造的输出恰好是破坏操作的豁免条件。

在彩色填充网格中，先由标记像素的缺角定位画出直角三角形轮廓，再用标记块执行十字擦除，三角形轮廓像素作为保护色在擦除中幸存。

**输入结构**：约 13x13 网格，除黑(0)外的多种颜色填充大部分像素（类似 319f2597 的彩色网格，使用蓝(1)、红(2)、绿(3)、黄(4)、品红(6)等随机填充各位置，无大面积纯色区域）。恰好 4 个灰(5)像素构成标记组：它们的边界框为正方形（边长 3~5），其中 3 个灰像素位于边界框的 3 个角上，第 4 个灰像素位于边界框内部（非角位置，作为干扰项）。边界框第 4 个角无灰像素（缺角）。另有恰好一个 2x2 的橙(7)标记块位于网格中（占据 4 个像素位置）。生成约束：灰色标记组和橙色标记块不重叠；缺角位置不在橙色标记块的行或列上（确保三角形顶点不被擦除）；三角形轮廓至少有部分像素位于标记块的行或列上（确保保护机制有意义）。

**规则**：
1. 找到 4 个灰(5)像素，确定其边界框（正方形），识别哪个角没有灰色像素——该缺角即直角三角形的直角顶点。
2. 直角三角形的三个顶点为：缺角位置（直角顶点）和与其相邻的两个有灰色标记的角位置。用青(8)像素连线画出三角形的三条边（两条直角边沿行/列方向画直线，斜边用 Bresenham 直线算法连接两个非直角顶点）。青(8)像素覆盖这些位置上的原有颜色。灰(5)标记像素本身也改为青(8)（成为轮廓的一部分）。内部干扰灰像素同样改为青(8)。
3. 找到 2x2 橙(7)标记块，选取其占据的两行和两列。
4. 将这些行列上所有非青(8)像素改为黑(0)。橙(7)标记块自身的 4 个像素也改为黑(0)。
5. 青(8)像素无论是否在擦除行列上，均保持不变。
6. 不在擦除行列上的非青(8)像素也保持不变。

**关键洞察**：三角形轮廓不是装饰而是功能性的保护屏障——它的几何形状决定了擦除后哪些像素幸存。求解者必须先构建三角形才能理解擦除结果，反过来也必须理解擦除规则才能理解为什么要构建三角形。

## 新题 7：最近邻重涂色引发分量合并后按面积分级描边

**组合逻辑**：[最近邻选择](已有) → [重涂色](已有，从单对象改为多对象独立重涂) → [连通判定](创新，重涂色后同色相邻对象合并为新分量——合并行为是重涂色的涌现效应，原题中不存在) → [描边](创新，判据从固定面积阈值改为分级响应：不同面积范围触发不同描边颜色)

**来源原语**：重涂色/标记像素/前景对象/最近邻选择/欧氏距离最小(6df30ad6)、描边/连通分量/边框/尺寸分类/微型对象描边(b27ca6d3)、连通判定/四邻接连通/连通性(239be575)、擦除(6df30ad6)

**依赖链**：标记像素的空间分布 → 欧氏距离决定每个灰色对象获得什么颜色 → 重涂色后原本不同色的相邻对象可能变为同色 → 同色相邻对象合并为更大的 4-连通分量 → 合并后的分量面积决定描边颜色（面积 2~3 用绿描边，面积 >= 4 用黄描边）。如果跳过重涂色，对象都是灰色，无法产生选择性合并；如果跳过合并检测，无法得到正确的面积信息；如果跳过分级描边，无法区分不同大小的合并结果。

将多个灰色对象按最近邻标记色重涂，重涂后同色 4-连通相邻的对象合并为更大分量，按合并后面积分级绘制不同颜色的外框。

**输入结构**：约 14x14 网格，黑(0)背景。散布 5~8 个 4-连通的灰(5)小对象，每个 2~4 像素，形状各异（直线段、L形拐角、方块等均可能出现）。部分灰色对象彼此相邻（边界框间距 0~1 像素），部分彼此远离。另有若干孤立的单像素标记点，颜色为蓝(1)、红(2)、绿(3)中的某几种（每种颜色的标记点可能有 1~3 个，分散在网格各处）。生成约束：每个灰色对象到最近标记像素的最小平方欧氏距离唯一确定一种颜色（无平局）；重涂色后至少存在两个相邻的同色对象对（确保合并发生）；重涂色后存在至少一个面积 2~3 的合并分量和至少一个面积 >= 4 的合并分量（确保两种描边颜色都出现）。

**规则**：
1. 对每个灰(5)对象，计算该对象中每个像素到每个标记像素的平方欧氏距离（dx^2 + dy^2），取所有"对象像素-标记像素"对中距离最小值对应的标记颜色。将该灰色对象的所有像素重涂为该颜色。
2. 将所有标记像素设为黑(0)背景（擦除标记）。
3. 在重涂后的网格上，对所有非黑(0)像素构建 4-连通分量（同色相邻像素属于同一分量，不同色不合并）。
4. 对每个分量按面积分级描边：
   - 面积 1：不描边。
   - 面积 2~3：将该分量边界框向四方向各扩 1 像素（裁剪到网格边界内），在扩展框周边所有当前为黑(0)的像素涂为绿(3)。
   - 面积 >= 4：同样扩展边界框 1 像素，但周边黑(0)像素涂为黄(4)。
5. 多个分量的描边区域重叠时，面积更大的分量的描边颜色优先（覆盖面积更小的分量的描边）。面积相同时，按分量边界框左上角行号从小到大、再列号从小到大的顺序，后处理的覆盖先处理的。

**关键洞察**：描边颜色不由对象本身颜色决定，而由重涂色后的合并面积决定——而合并面积取决于哪些原本独立的对象碰巧被涂为相同颜色且恰好 4-连通相邻。标记像素的空间分布间接控制了最终的描边图案，这是一个跨越三步的因果链。
