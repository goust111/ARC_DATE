## 新题 1：散落连线生成滑动障碍

**组合逻辑**：[连线/scatter_connect_side](创新：连线结果不直接输出，而是作为滑动障碍) + [裁剪/crop] + [滑动/slide] + [颜色决定方向/color_determines_direction]

**来源原语**：连线+散落像素+颜色对应边+矩形框(5daaa586)、滑动+可移动对象+载体区域+颜色决定方向(9b4c17c4)、裁剪(6cbe9eb8)

**依赖链**：散落像素的颜色决定它连接到矩形框的哪条边 → 连线产生从框边向内延伸的障碍线段 → 障碍线段限制内部可移动对象的滑动终点 → 载体颜色决定滑动方向。连线步骤的输出是滑动步骤的空间约束；载体颜色是滑动方向的编码。缺少连线则滑动终点不确定，缺少载体颜色则方向不确定。

从矩形框外的散落像素引出障碍线段，框内可移动对象沿载体颜色指定的方向滑动至障碍或框边停止。

**输入结构**：约 15x15 的黑(0)背景网格。中央有一个约 9x9 的矩形框，四条边各由一种颜色构成：上边蓝(1)、下边绿(3)、左边红(2)、右边黄(4)，四角像素颜色归属于水平边（即左上角和右上角为蓝(1)，左下角和右下角为绿(3)）。框外散落着 2~4 个孤立像素，每个像素的颜色与某条框边颜色相同，分布在该边的延长线方向上（即与该边在同一行或同一列）。框内部背景分为若干水平条带，每条带为蓝(1)或青(8)单色填充，条带之间无间隙地铺满框内区域。每条条带内嵌入恰好一个橙(7)色的 4-连通小图形（3~5 像素），该图形完全位于条带内部且不接触框边。生成约束：不同散落像素引出的障碍线段互不交叉；每个橙色图形在其滑动方向上至少有一条障碍线段或框边可以阻挡。

**规则**：
1. 裁剪：以矩形框的外边界为裁剪范围，仅保留框及框内内容，丢弃框外区域（散落像素的信息已通过下一步提取）。
2. 连线生障碍：对每个散落像素，从该像素位置沿垂直于其所属框边的方向向框内画一条单像素宽的线段，颜色为灰(5)，线段从框边内侧第一个像素开始，一直延伸到碰到第一个非条带背景色像素（即碰到橙色图形或另一条灰色障碍）前一格停止。若路径上无障碍，则延伸到对面框边内侧为止。
3. 滑动：对每个橙(7)色图形，根据其所在条带的颜色确定滑动方向——蓝(1)条带内的图形向右滑动，青(8)条带内的图形向左滑动。图形保持形状和所在行不变，整体水平平移，直到图形的边界框在滑动方向上碰到灰(5)障碍线段或框边内侧为止。所有图形同时移动（移动计算基于初始位置，不考虑其他图形移动后的位置）。
4. 擦除原位：图形滑动离开的原位置恢复为该条带的背景色。

**关键洞察**：散落像素的连线方向由框边决定，但连线的长度由框内容决定；滑动方向由条带颜色决定，但滑动距离由连线障碍决定。两组规则通过共享的框内空间紧密耦合，单独理解任一组都无法确定最终输出。

## 新题 2：字形解码驱动循环位移后的嵌套重涂色

**组合逻辑**：[解码/decode](已有) → [循环位移/cyclic_roll](创新：位移量由解码结果决定) → [重涂色/recolor + 最外层颜色继承/outermost_color_inheritance](创新：位移改变了包含关系，从而改变了继承源)

**来源原语**：解码+字形图案+位置映射(995c5fa3)、循环位移+控制列+标记位定位移量(6d1d5c90)、重涂色+矩形边框+严格包含+最外层颜色继承(7d1f7ee8)

**依赖链**：字形图案解码为数值 → 数值作为循环位移的偏移量 → 位移重排了嵌套矩形的相对位置 → 包含关系改变 → 内层矩形按新的最外层矩形颜色重涂。解码结果决定位移量，位移改变几何关系，几何关系决定涂色。三步环环相扣。

解码字形获得位移量，对嵌套矩形区域做循环位移，然后按位移后的包含关系将内层矩形重涂为其最外层容器的颜色。

**输入结构**：约 14x10 的黑(0)背景网格，水平分为左右两区。左区宽 4 列，包含一个 4x4 的字形图案：灰(5)底色中嵌有若干黑(0)像素形成特定掩码图案，共有四种可能的图案，分别编码数值 1、2、3、4（各图案中黑色像素的数量分别为 1、2、3、4 个，且位置固定可区分）。右区宽 10 列，包含 3~4 个不同颜色的单色矩形边框（仅绘制边框一圈像素，宽度为 1 像素），颜色从蓝(1)、红(2)、绿(3)、黄(4)中选取且互不相同。这些矩形在垂直方向上形成嵌套关系：最大的矩形跨越右区大部分高度，较小的矩形严格位于较大矩形的内部。所有矩形的左右边界相同（均贴合右区左右边缘），仅在上下边界位置上不同，从而形成纯垂直方向的嵌套。生成约束：最大矩形的高度等于右区总高度，各矩形的上下边框行互不重合。

**规则**：
1. 解码：识别左区 4x4 字形图案中黑色像素的数量和位置，映射到对应数值 r（1~4）。
2. 删除左区：输出仅包含右区内容（宽度减少 4 列）。
3. 循环位移：将右区内容整体向下循环位移 r 行。即原来第 i 行的内容移到第 (i+r) mod H 行，H 为右区高度。
4. 重建包含关系：在位移后的网格中，重新判定矩形边框的嵌套包含关系——若矩形 A 的边框完全位于矩形 B 的边框严格内部（不含边框重合），则 A 被 B 包含。注意：循环位移可能导致某些矩形边框被截断后出现在网格顶部和底部，此时该矩形不再构成完整边框，视为不参与包含关系的碎片，保持原色不变。
5. 重涂色：对每个仍然完整的被包含矩形，将其边框颜色改为包含它的最外层完整矩形的颜色。最外层矩形自身和碎片矩形保持原色。

**关键洞察**：循环位移的量由字形编码决定，而位移直接改变哪些矩形保持完整、哪些被截断成碎片，进而改变包含关系图。同样的嵌套矩形在不同位移量下会产生完全不同的重涂结果。求解者必须从多个示例中同时归纳出解码映射和位移对包含关系的影响。

## 新题 3：噪声过滤后的双面板交集作为平铺种子

**组合逻辑**：[擦除/erase + 单像素分量移除 + 八连通判定](已有) → [布尔运算/boolean_op + 双掩码交集](创新：交集结果同时作为平铺内容和计数源) → [计数/counting + 平铺/tile](创新：交集像素数决定平铺份数)

**来源原语**：擦除+孤立像素+连通分量+单像素分量移除+八连通判定(42a50994)、布尔运算+掩码区域+分隔线+对齐+双掩码交集输出(6430c8c4)、计数(794b24be)、平铺+精灵体+阵列排布+像素数定尺寸数(91413438)

**依赖链**：去噪改变两面板的前景掩码 → 掩码交集改变可用像素集合 → 交集的像素数 N 同时决定平铺的份数和输出网格的列数 → 交集图案本身是被平铺的精灵体。去噪影响交集，交集同时影响内容和尺寸——一个噪声像素的有无可能改变 N 和精灵体形状，导致输出维度与内容同时变化。

去除两面板中的孤立噪声像素后求交集，交集图案作为精灵体平铺 N 次（N 为交集像素数）。

**输入结构**：约 7x15 的黑(0)背景网格，由一条水平灰(5)分隔线（占满整行宽度、高度 1 像素）分为上下两个等大的面板（各约 3x15）。上面板包含若干红(2)前景像素，下面板包含若干蓝(1)前景像素，两面板宽度相同。每个面板中，部分前景像素形成 8-连通簇（2~4 像素的小团），另有 1~3 个孤立的前景像素（与同色像素无 8-连通邻接）散布其中。两面板清理后的前景掩码存在 2~5 个位置重合的像素（交集非空）。生成约束：两面板的前景像素总数相同；去噪后的交集像素数 N 满足 2 <= N <= 5；交集区域的边界框不超过 3x3。

**规则**：
1. 去噪：在每个面板中，用 8-连通标记前景像素的连通分量。删除大小为 1 的分量（将其替换为黑(0)）。保留大小 >= 2 的分量。
2. 对齐求交：移除分隔线，将上下面板按像素位置逐格对齐。标记两个面板中同一位置均为前景（不论颜色）的像素集合 S。
3. 提取精灵体：以 S 的边界框裁剪出一个最小矩形，框内属于 S 的像素标记为绿(3)，不属于 S 的像素为黑(0)。该矩形即为精灵体 P。
4. 计数：令 N = |S|（交集像素总数）。
5. 平铺输出：创建一个高度等于 P 高度、宽度等于 P 宽度 x N 的黑(0)输出网格。将精灵体 P 沿水平方向紧密排列 N 份（第 k 份的左上角位于第 0 行、第 (k-1) x P宽度 列），无间距。

**关键洞察**：噪声像素的存在会同时误导两个下游结果——交集图案的形状和平铺的份数。求解者必须先意识到需要去噪（需对比多个示例中噪声位置不同但交集一致的情况），再理解交集的双重角色（内容和计数源），二者缺一不可。

## 新题 4：补全矩形的缺口由条纹颜色按轴向填充

**组合逻辑**：[补全/complete + 边界框推断 + 缺失像素补新色](创新：补全不是用固定新色，而是由条纹颜色决定) + [排序/sort + 条纹决定填充轴 + 顺序对应](创新：条纹颜色按位置顺序映射到补全区域的行或列)

**来源原语**：补全+不完整矩形+边界框推断+缺失像素补新色(6d75e8bb)、填充+排序+条纹+顺序对应+条纹决定填充轴(8e1813be)

**依赖链**：不完整矩形的边界框推断 → 确定需要补全的缺口区域 → 条纹方向决定缺口是按行填还是按列填 → 条纹按位置排序后的颜色序列决定每行/列的填充色。补全步骤定义了"哪些像素需要填"，条纹分析定义了"填什么颜色"和"按什么轴填"。二者共享同一区域，缺一不可。

检测不完整矩形的边界框，用条纹颜色按其方向和顺序填充缺口像素。

**输入结构**：约 12x12 的黑(0)背景网格。包含 1~2 个不完整的青(8)矩形轮廓（仅边框像素，边框宽度 1 像素），每个矩形的边框有若干像素缺失（被黑色替代），但剩余青色像素足以唯一确定该矩形的边界框。矩形之外的网格区域中存在 2~4 条完整的单色条纹——若为水平条纹则每条占满一整行，若为垂直条纹则占满一整列。同一网格中所有条纹方向一致（全水平或全垂直）。条纹颜色从红(2)、蓝(1)、绿(3)、黄(4)中选取，各条纹颜色不同。条纹不与矩形边框区域重叠。生成约束：每个矩形缺口区域的行数（水平条纹时）或列数（垂直条纹时）恰好等于条纹数量；多个矩形共享同一套条纹。

**规则**：
1. 边界框推断：对每个不完整矩形，找到所有青(8)像素的边界框，该框即为完整矩形的范围。
2. 识别缺口：在每个矩形的边界框范围内，边框位置上为黑(0)的像素即为缺口像素。
3. 条纹分析：找到所有条纹，判定方向（全为水平行或全为垂直列）。将条纹按位置排序——水平条纹按行号从小到大排，垂直条纹按列号从小到大排——得到有序颜色序列 C1, C2, ..., Ck。
4. 缺口填充：对每个矩形的缺口像素集合，按条纹方向分配颜色。若条纹为水平方向：将缺口像素按其所在行在矩形边界框中的相对行号（从上到下第 1、2、...行）分组，第 i 组中的所有缺口像素填充颜色 Ci。若条纹为垂直方向：将缺口像素按其所在列在矩形边界框中的相对列号（从左到右第 1、2、...列）分组，第 j 组填充颜色 Cj。此处相对行号/列号仅计算边框所在的行/列（即第 1 行 = 边框顶行，第 2 行 = 边框底行；对于高度 > 2 的矩形，左列和右列也计入，按从上到下/从左到右的顺序，仅统计边框像素所在的行或列）。
5. 保持原有青色像素和条纹不变，仅缺口像素被填充。

**关键洞察**：矩形的缺口位置分布在不同的行和列上，条纹的排列顺序决定了每个行/列的缺口获得什么颜色。求解者必须同时理解"边界框推断确定缺口在哪"和"条纹排序确定缺口填什么"，且条纹方向还隐式决定了分组维度（行 vs 列），需从不同方向的示例中归纳。

## 新题 5：控制列位移后按条纹方向修复十字遮罩

**组合逻辑**：[循环位移/cyclic_roll + 标记位定位移量](已有) → [擦除控制列](已有) → [填充修复/fill + 从平行行列推断](创新：修复依据是位移后的条纹位置，而非原始位置) + [条纹决定填充轴](创新：条纹方向决定修复时优先参考行还是列)

**来源原语**：循环位移+控制列+标记像素+行偏移编码+标记位定位移量(6d1d5c90)、十字遮罩+色块拼图+补全+从平行行列推断(b7955b3c)、条纹+顺序对应+条纹决定填充轴+排序(8e1813be)

**规则**：
1. 读取位移量：令 r = 控制列中红(2)像素的行号（0-indexed）。
2. 删除控制列：输出不含最左列，宽度减 1。
3. 循环位移：将主区域所有行整体向下循环位移 r 行（第 i 行内容移至第 (i+r) mod H 行）。
4. 判定条纹方向：在位移后的网格中，忽略灰(5)像素，检查非灰像素是否呈现水平条纹（同行非灰像素颜色相同）或垂直条纹（同列非灰像素颜色相同）。
5. 修复遮罩：将每个灰(5)像素替换为其应有的条纹颜色。若为水平条纹：每个灰像素取其同行中任一非灰像素的颜色。若为垂直条纹：每个灰像素取其同列中任一非灰像素的颜色。
6. 输出修复后的网格（不含控制列）。

**关键洞察**：同一个遮罩在位移前和位移后可能跨越不同的条纹，导致修复结果完全不同。求解者必须先理解位移机制（通过对比控制列标记位置与输出的条纹偏移），再理解条纹方向决定了修复策略，二者的顺序关系不可颠倒。

## 新题 6：接触侧与包含深度的双规则重涂

**组合逻辑**：[重涂色/recolor + 接触侧定色](创新：接触侧规则仅在接触条件满足时激活) ⊕ [重涂色/recolor + 最外层颜色继承](创新：继承规则仅在无接触时激活) + [填充/fill](创新：填充被重涂后矩形内的封闭空洞)

**依赖链**：检测矩形的包含层级 → 对每个内层矩形判断是否接触外层容器的某一边 → 若接触：取接触边上的标记色重涂 → 若不接触：取最外层容器色重涂 → 重涂后矩形内部若有黑色空洞则填充为该矩形的新颜色。两条重涂规则由同一个几何条件（是否接触容器边）互斥激活，填充步骤依赖重涂结果。

在嵌套矩形中，接触容器边的矩形按接触标记色重涂，不接触的按最外层容器色重涂，最后填充内部空洞。

**输入结构**：约 15x15 的黑(0)背景网格。包含 1~2 个最外层矩形边框，每个最外层矩形的边框为单一颜色（从蓝(1)、红(2)中选取），边框宽度 1 像素。每个最外层矩形内部嵌套 2~3 个较小的单色矩形边框，颜色从绿(3)、黄(4)、品红(6)、橙(7)中选取且互不相同。内层矩形分为两类：（a）"接触型"——该矩形的某一条边恰好与其直接容器的某一条边完全重合（共享同一行或列的像素），且在该重合边上，容器的边框像素被替换为一种标记色（青(8)或灰(5)），标记色仅出现在这些重合位置；（b）"浮空型"——该矩形的四条边均不与容器的任何边重合，完全悬浮在容器内部。部分内层矩形的内部有若干黑(0)像素空洞（矩形内部并非全黑，而是边框围起的空区域）。生成约束：每个最外层矩形内至少有一个接触型和一个浮空型内层矩形；标记色在整个网格中仅出现在接触重合边上。

**规则**：
1. 包含分析：识别所有矩形边框，建立严格包含关系层级。最外层矩形 = 不被任何其他矩形严格包含的矩形。
2. 接触检测：对每个非最外层矩形，检查其四条边是否有某条边与其直接容器（包含它的最小矩形）的某条边完全重合。若重合边上存在标记色像素（颜色不同于容器边框原色和内层矩形原色），则该矩形为"接触型"，标记色即为该标记色。
3. 接触型重涂：将接触型矩形的所有边框像素重涂为其标记色。同时将重合边上容器的标记色像素也保持为该标记色。
4. 浮空型重涂：将浮空型矩形的所有边框像素重涂为包含它的最外层矩形的边框颜色。
5. 空洞填充：对每个被重涂的矩形，若其边框围起的内部区域存在黑(0)像素，将这些黑像素填充为该矩形重涂后的颜色。
6. 最外层矩形自身的边框和所有不属于任何矩形边框的像素保持不变。

**关键洞察**：同一个包含层级中的两个矩形，可能因为一个接触容器边而另一个不接触，从而被完全不同的规则重涂为不同颜色。求解者必须同时发现"接触→取标记色"和"不接触→取最外层色"这两条互斥规则，仅凭单一示例无法区分二者（可能所有内层矩形恰好都是同一类型）。

## 新题 8：双面板布尔并集为螺旋路径设置障碍

**依赖链**：两面板前景掩码求布尔并集 → 并集像素标记为障碍。同时，一个面板中的不完整矩形被补全 → 补全后的矩形定义螺旋画布边界。螺旋在画布内绘制时，碰到障碍像素视同碰到边界，触发提前转向。三条逻辑通过共享的空间坐标交汇：并集决定哪些位置不可通行，补全决定画布大小，螺旋路径由两者共同约束。

**输入结构**：约 8x16 的黑(0)背景网格，由垂直中线分为左右两个等大的 8x8 面板。两面板中各有若干前景像素：左面板前景色为蓝(1)，右面板前景色为红(2)。左面板中额外有一个不完整的青(8)正方形轮廓（边框宽度 1 像素），正方形大小约 6x6，有 2~4 个边框像素缺失。右面板中无青色像素。两面板的蓝和红前景像素各有 3~6 个，散布在面板内部（可能在青色正方形内部也可能在外部）。生成约束：青色正方形的边界框内，布尔并集产生的障碍像素不超过正方形内部面积的 1/3；障碍像素不出现在正方形的第一行第一列（确保螺旋起点可用）。

**规则**：
1. 对齐求并集：将左右面板按像素位置逐格对齐。对每个位置，若左面板或右面板中该位置为前景（蓝或红），则该位置标记为障碍。输出一个 8x8 的障碍图，障碍像素暂标为灰(5)。
2. 补全矩形：在左面板中找到青(8)正方形轮廓的边界框，将缺失的边框像素补全为青(8)。
3. 确定螺旋画布：螺旋画布 = 青色正方形的内部区域（不含边框本身），大小约为 (边长-2)x(边长-2)。
4. 绘制螺旋：从画布左上角开始，向右移动，绘制绿(3)螺旋路径。碰撞规则：当下一步将离开画布、或下一步的像素已是绿(3)、或下一步的像素在障碍图中被标记为障碍时，顺时针转向。当前进方向上的下一步碰撞且顺时针转向后的下一步也碰撞时，螺旋停止。
5. 输出：8x8 网格，包含青(8)边框、绿(3)螺旋路径、灰(5)障碍像素，其余为黑(0)。不保留原始的蓝或红前景色。

**关键洞察**：螺旋路径不是在空白画布上绘制，而是在包含障碍的画布上绘制——障碍来自两个面板中任一面板都看不到的并集。求解者必须先发现布尔并集规则（需要同时看两个面板），再发现螺旋的碰撞行为受障碍影响（需要对比有障碍和无障碍的不同示例）。

## 新题 9：边缘标记去噪后的对侧线段颜色互换

**组合逻辑**：[擦除/erase + 单像素分量移除 + 八连通判定](创新：去噪规则应用于网格边缘的标记像素而非内部像素) + [颜色互换/color_swap + 配对间像素互换 + 对边配对](已有，但配对集合依赖去噪结果)

**来源原语**：擦除+孤立像素+连通分量+单像素分量移除+八连通判定(42a50994)、颜色互换+标记像素+线段+网格边缘+对边配对+配对间像素互换(d2acf2cb)

**依赖链**：边缘上存在真标记和噪声标记 → 八连通去噪区分二者（真标记与同边其他标记八连通相邻，噪声标记孤立）→ 去噪后的标记集合决定哪些行/列被选中 → 被选行/列的内部像素执行颜色互换。噪声标记不去除则会选中错误的行/列，导致互换区域错误。

清除边缘上的孤立噪声标记后，将对侧标记对之间的线段像素做颜色互换。

**输入结构**：约 10x10 的网格，内部填充由黑(0)、青(8)、品红(6)、橙(7) 四种颜色构成的图案。网格四条边缘上分布若干黄(4)标记像素。标记分为两类：（a）"真标记"——同一条边上有至少一个其他黄色像素与其 8-连通相邻（即在边缘上形成 2~3 像素的小簇），且在对面的边缘上有对应的黄色像素簇（在同一行或同一列上）；（b）"噪声标记"——孤立的黄色像素，在同一条边上没有任何黄色 8-连通邻居。左右边缘上的成对标记簇选中对应的整行，上下边缘上的成对标记簇选中对应的整列。每条边缘上有 1~2 个真标记簇和 0~2 个噪声标记。生成约束：噪声标记所在的行/列在对面边缘上没有标记，因此即使不去噪也不会误配对——但去噪仍是必要的，因为噪声标记的存在会干扰簇的 8-连通判定（一个噪声标记若恰好与真标记相邻会改变簇的范围，进而改变选中的行/列范围）。

**规则**：
1. 边缘标记识别：提取网格四条边缘上所有黄(4)像素。
2. 八连通去噪：在每条边缘上，对黄色像素做 8-连通分量标记。删除大小为 1 的分量（将其恢复为该边缘位置在内部图案中应有的颜色，即若边缘像素原本就是图案的一部分，恢复为图案色；若原本是黑色背景则恢复为黑(0)）。保留大小 >= 2 的分量。
3. 配对：将左边缘上幸存的每个标记簇与右边缘上同行范围内的标记簇配对（簇占据的行范围有交集即配对）。将上边缘的标记簇与下边缘同列范围内的标记簇配对。
4. 选中区域：对每个配对的标记簇对，选中对应的行段（左右配对）或列段（上下配对）。行段 = 两个黄色端点之间的所有严格内部像素（不含端点本身）；列段同理。
5. 颜色互换：对每个选中区域内的严格内部像素，执行颜色互换：黑(0) ↔ 青(8)，品红(6) ↔ 橙(7)。
6. 黄色标记像素（包括去噪后保留的）保持不变，其余未被选中的像素保持不变。

**关键洞察**：噪声标记可能与真标记簇 8-连通相邻，导致簇的范围扩大（多选一行/列）。求解者必须在多个示例中观察到噪声标记有时紧邻真标记、有时远离真标记，才能归纳出"先去噪再配对"的正确顺序——而非"先配对再过滤"。

**组合逻辑**：[计数/counting](创新：计数对象是矩形内部的前景像素而非矩形本身) + [排序/sort](创新：排序依据是内部像素数而非面积) + [嵌套/nest + 角落对齐嵌套](已有) + [裁剪/crop](已有) + [重涂色/recolor + 指定色统一替换](创新：嵌套后统一重涂)

**来源原语**：计数+像素数转计数图(794b24be)、排序+嵌套+前景矩形+面积递减嵌套+角落对齐嵌套+忽略干扰项+裁剪(6cbe9eb8)、重涂色+指定色统一替换(b1948b0a)

**依赖链**：统计每个矩形框内部的前景像素数 → 按此数值排序（而非按面积）→ 排序决定嵌套层级（数量最多的在最外层）→ 按角落对齐规则嵌套重组 → 嵌套完成后统一将所有矩形边框重涂为同一颜色。计数结果决定排序，排序决定空间结构，空间结构决定最终形态。

按矩形内部前景像素数从多到少排序，将矩形边框按该顺序左下角对齐嵌套，最后统一重涂边框色。

**输入结构**：约 14x14 的黑(0)背景网格。包含 3~4 个互不重叠的单色矩形边框（仅画边框、边框宽度 1 像素），颜色分别为蓝(1)、红(2)、绿(3)、黄(4)等互不相同的颜色。每个矩形的内部（边框围起的区域）散布若干灰(5)前景像素，形成不规则的小图形（4-连通，3~8 像素不等）。不同矩形内部的灰色像素数量互不相同。矩形在网格中随意放置，大小各异，但它们之间无嵌套关系（初始状态下互不包含）。网格中可能存在少量干扰像素（栗(9)色，散布在矩形外部），这些干扰像素不属于任何矩形且应被忽略。生成约束：各矩形的面积（边界框面积）按从大到小排序后的顺序，与按内部灰色像素数从多到少排序后的顺序至少有一处不同，确保面积排序和计数排序不等价。最小矩形可以被放入次小矩形内部，次小可以放入次次小内部，以此类推（尺寸上可嵌套）。

**规则**：
1. 忽略干扰：丢弃栗(9)色像素，不参与后续任何计算。
2. 识别矩形：找到所有非黑、非灰、非栗色像素构成的矩形边框，记录每个矩形的颜色和边界框。
3. 内部计数：对每个矩形，统计其边框严格内部的灰(5)像素数量，记为该矩形的"权重"。
4. 按权重排序：将矩形按权重从大到小排列。权重最大的矩形为最外层。
5. 裁剪：输出尺寸 = 权重最大矩形的边界框大小。
6. 嵌套重组：从最外层矩形开始，将其边框绘制在输出画布上（左上角对齐画布左上角）。然后依次将权重递减的矩形绘制在前一个矩形的内部，每个矩形的左下角与其容器内部区域的左下角对齐。矩形内部的灰色像素不保留——仅绘制边框。
7. 统一重涂：将所有矩形边框像素统一替换为品红(6)，抹去原来各矩形的不同颜色。输出中仅有品红(6)边框和黑(0)背景。

**关键洞察**：如果求解者按面积排序嵌套，在多数示例中会得到错误结果，因为面积排序与权重排序至少有一处不同。必须发现内部灰色像素的计数才是正确的排序依据，而灰色像素在最终输出中被丢弃——它们仅作为排序的隐式编码存在。这一规则只有通过对比面积排序与实际输出不一致的示例才能归纳。
