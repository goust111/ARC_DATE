## 新题 1：对称修复后按孔洞面积染色

**组合逻辑**：[对称补全](已有) → [封闭区域检测](已有，创新：作用于修复后的图案而非给定图案) → [按面积映射颜色](创新：将"按边长映射"泛化为"按面积映射"，且面积值依赖前序修复结果)

**来源原语**：对称补全/symmetry_completion(3631a71a)、封闭区域/enclosed_region(e3721c99, 810b9b61)、按边长映射颜色/size_to_color_mapping(00dbd492, 创新为按面积映射)、填充/fill(00dbd492)、掩码像素/masked_pixel(3631a71a)

**依赖链**：灰色掩码破坏了对称图案中封闭区域的边界 → 必须先通过对称轨道修复掩码才能得到正确的封闭区域拓扑 → 修复后封闭区域的面积决定填充颜色。删除对称修复则孔洞边界错误、面积错误、颜色错误；删除面积映射则无法确定填充色。

将对称图案中被掩码损坏的封闭区域修复完整，再根据每个封闭区域的像素面积选择填充颜色。

**输入结构**：约 13x13 的正方形网格。背景为黑(0)。红(2)像素构成一个具有左右镜像对称性的连通图案（图案关于网格垂直中轴对称）。图案中存在 3-4 个不同大小的封闭黑(0)区域（即被红(2)像素完全包围、不与网格边缘相连的黑色连通分量），面积分别在 1-3、4-6、7-10 像素范围内（不同示例中具体面积不同，但落入同一区间的封闭区域总得到同一填充色）。部分红(2)像素被替换为灰(5)，形成掩码损坏——灰像素可能出现在封闭区域边界上，使某些封闭区域在修复前看起来与外部黑色连通或面积被错误计算。生成约束：灰(5)掩码关于垂直中轴不对称（即对于每个灰像素，其镜像位置保留原色），保证修复方案唯一；每个封闭区域至少有一部分边界未被损坏。

**规则**：
1. 识别灰(5)为掩码色。对每个灰(5)像素，取其关于网格垂直中轴的镜像位置的颜色，替换该灰像素，恢复完整的对称图案。
2. 在修复后的网格中，找到所有被红(2)完全包围的黑(0)连通分量（4-连通），即不与网格边缘上的黑(0)像素连通的黑色区域。
3. 统计每个封闭区域的像素数（面积），按面积区间填充颜色：面积 1-3 → 蓝(1)；面积 4-6 → 黄(4)；面积 7-10 → 绿(3)。填充时将该封闭区域的所有黑(0)像素替换为对应颜色。
4. 红(2)边界像素保持不变。非封闭的黑(0)区域（与网格边缘连通的背景）保持黑(0)。

**关键洞察**：灰色掩码可能打破封闭区域的边界，使原本封闭的区域看似与外部连通（面积变为"无穷大"而不被检测为封闭区域），或使两个相邻封闭区域合并为一个更大的区域。必须先完成对称修复才能得到正确的拓扑结构和面积。面积-颜色映射的具体区间需对比多个示例才能归纳。

## 新题 2：标记朝向编码平移方向的碰撞式拼装

**组合逻辑**：[标记朝向编码](创新：从"编码颜色"改为"编码平移方向") → [平移拼接](已有) → [碰撞阻挡](已有，创新：处理顺序由线段长度决定而非位置)

**来源原语**：标记朝向编码颜色/marker_orientation_encodes_color(604001fa, 创新为编码方向)、标记体/marker(604001fa)、平移拼接/translate_assemble(83b6b474)、线段条/bar_sprite(83b6b474)、碰撞阻挡/collision_blocking(5ffb2104)、擦除/erase(多题)、高度排序/height_ordering(31f7f899, 创新为长度排序)

**依赖链**：L-标记的缺角方向决定每根线段的平移方向 → 线段按长度排序决定处理先后 → 先处理的线段成为后续线段的障碍物，改变后续停靠位置。三层逻辑环环相扣：方向解码、排序策略、碰撞物理缺一不可。

读取每根彩色线段旁的 L-标记缺角方向作为平移方向，按线段长度从短到长依次平移，碰到已放置线段或网格边缘时停止。

**输入结构**：约 18x18 的网格。背景为黑(0)。网格中散布 4-5 根直线段（每根宽 1 像素、长 3-7 像素，可以是水平或垂直方向），每根线段颜色各不相同，取自 {蓝(1), 红(2), 绿(3), 黄(4), 青(8)}。每根线段旁（曼哈顿距离 1-2 像素处）有一个橙(7)的 2x2 L-三连块标记（即 2x2 方格中缺少一个角的 3 像素图形）。不同线段的标记缺角方向可能不同。线段之间互不接触，标记之间互不接触，线段与非对应标记也不接触。生成约束：每根线段恰好对应一个最近的标记；不同线段的长度两两不同。

**规则**：
1. 对每根线段，找到与其最近的橙(7) L-标记。
2. 确定标记的缺角位置（2x2 方格中缺失像素的位置），映射为平移方向：缺左上角 → 向左平移；缺右上角 → 向上平移；缺右下角 → 向右平移；缺左下角 → 向下平移。
3. 擦除所有橙(7)标记像素（替换为黑(0)）。
4. 按线段长度从短到长排序（长度 = 像素数）。
5. 按排序顺序依次处理每根线段：将线段沿其指定方向逐格平移，直到下一步会使线段的任一像素超出网格边界或与已放置的线段像素重叠，此时停止。保持线段形状和颜色不变。
6. 已处理并停靠的线段立即成为后续线段的障碍物。

**关键洞察**：处理顺序至关重要——短线段先移动并停靠，成为长线段的障碍物，因此最终布局取决于长度排序。同一组线段若改变处理顺序会得到完全不同的结果。标记的缺角-方向映射需要对比多个示例才能确定（例如区分"缺角方向=平移方向"还是"缺角方向=平移反方向"）。

## 新题 3：散落空心框按面积嵌套并翻转层色序

**组合逻辑**：[排序](已有，按面积) → [同心嵌套](创新：将散落对象重组为同心结构) → [层色序翻转](已有，创新：翻转对象是动态构建的嵌套结构而非输入中已有的同心结构)

**来源原语**：空心矩形/hollow_rectangle(00dbd492)、排序/sort(31f7f899)、同心方框层/concentric_layer(85c4e7cd)、深度排序/depth_order(85c4e7cd)、层色序内外翻转/reverse_layer_colors(85c4e7cd)

**依赖链**：面积排序确定嵌套层次（最大框最外层、最小框最内层）→ 嵌套建立同心结构才能定义"深度"→ 深度排序后翻转颜色序列。排序决定几何布局，几何布局决定颜色分配，两者方向相反（位置按从大到小排列，但颜色按从小到大的原色赋予），构成紧耦合。

将散落在网格中的不同大小的空心矩形框按面积排序、嵌套对齐成同心结构，然后将各层颜色按深度反转。

**输入结构**：约 20x20 的网格。背景为黑(0)。网格中散布 3-4 个空心矩形框（每个框是一像素厚的矩形环），大小各不相同（例如外径分别为 5x5、9x9、13x13），每个框的边框颜色各不相同，取自 {蓝(1), 红(2), 绿(3), 黄(4)}。各框在输入中位置随意，互不重叠。每个框内部为黑(0)。生成约束：每个框都是正方形（宽=高）；框的边长两两不同且均为奇数（保证可以精确居中嵌套）。

**规则**：
1. 识别所有空心矩形框，计算每个框的边长（外径）。
2. 按边长从大到小排序。
3. 构建输出网格：尺寸等于最大框的外径。将所有框居中对齐嵌套——最大框在最外层，最小框在最内层，各框共享中心点。
4. 记录嵌套后从外到内的颜色序列，将其反转：最外层框取原来最内层框的颜色，最内层框取原来最外层框的颜色，中间层类推。
5. 各框之间和最内层框内部的区域保持黑(0)。

**关键洞察**：输入中各框分散放置，没有嵌套关系，也无法直接看出深度——必须先完成面积排序和居中对齐才能建立同心结构。颜色翻转的方向与嵌套方向相反，即空间上最外层的框在颜色上获得原来空间最内层的颜色，使得位置排序和颜色赋值形成交叉映射。

## 新题 4：射线穿透掩码的选择性染色

**组合逻辑**：[反向投射/射线延伸](已有) → [掩码决定保留](创新：掩码不再决定"保留哪些像素"，而是决定"射线能染色哪些像素") → [颜色替换](已有，创新：射线的轨迹色成为掩码像素的新颜色，多射线交叉时按处理顺序覆盖)

**来源原语**：射线延伸/ray_cast(9f8de559)、轨迹/trail(9f8de559)、反向投射/opposite_direction(9f8de559)、掩码决定保留/mask_determines_keep(f76d97a5, 创新为掩码决定可染色范围)、颜色替换/color_replacement(f76d97a5)、擦除/erase(多题)、标记像素/marker_pixel(9f8de559)

**依赖链**：轨迹方向决定射线方向（反向）→ 射线是否命中掩码像素决定该像素是否被染色 → 多条射线可交叉穿过掩码，交叉处颜色由处理顺序决定 → 未被任何射线命中的掩码像素保持灰色。掩码的形状、射线的方向、处理顺序三者共同决定最终图案。

从彩色标记像素沿其轨迹反方向发射射线，射线穿过灰色掩码区域时将路径上的灰色像素染为标记的颜色，最终擦除所有标记和轨迹。

**输入结构**：约 15x15 的网格。背景为黑(0)。网格中央偏某方向有一个灰(5)的不规则连通图形（4-连通，约 15-25 像素，形状不规则，可能有凹陷但无内部孔洞）作为掩码。掩码外围散布 3-4 个彩色标记像素，每个标记颜色各不相同，取自 {蓝(1), 红(2), 绿(3), 黄(4)}。每个标记像素旁有一条同色的直线轨迹（2-3 个像素，沿水平或垂直方向延伸，方向背离掩码）。标记和轨迹均在掩码外部，不与掩码相邻。生成约束：每条射线（从标记沿轨迹反方向延伸）都会穿过掩码的至少一部分；不同射线的路径可以交叉（在掩码区域内共享某些像素）。

**规则**：
1. 对每个彩色标记像素，确定其轨迹延伸方向（从标记朝向轨迹末端的方向）。
2. 从标记位置沿轨迹反方向（即从标记朝向掩码的方向）发射射线。
3. 射线逐格前进。对于射线路径上的每个位置：若该位置是灰(5)掩码像素，将其标记为待染色（染为该标记的颜色）；若该位置是黑(0)背景，跳过继续前进；若该位置是非背景非灰色像素或已超出网格边界，射线终止。
4. 按标记像素在网格中的阅读顺序（从上到下、从左到右）依次处理各条射线。后处理的射线覆盖先处理的射线在同一像素上的染色结果。
5. 所有射线处理完毕后，擦除所有标记像素和轨迹像素（替换为黑(0)）。
6. 未被任何射线命中的灰(5)掩码像素保持灰(5)不变。

**关键洞察**：射线不会在遇到掩码时停止——它穿透掩码，沿途染色所有灰像素，直到碰到其他障碍物或网格边缘。这意味着一条射线可以在掩码的凹陷处"跳过"黑色间隙，在掩码的另一段继续染色。当多条射线的路径在掩码内交叉时，交叉像素的最终颜色取决于处理顺序，而处理顺序由标记的空间位置（阅读顺序）决定——这是一个需要对比多个示例才能发现的隐蔽规则。

## 新题 5：框边长度排名为调色板索引，孔洞拓扑为查询键

**组合逻辑**：[矩形边框边长排名](创新：框的几何属性生成有序调色板) + [孔洞计数](已有) → [重涂色](已有，创新：颜色由几何排名和拓扑计数的交叉映射决定)

**来源原语**：矩形边框/rectangular_frame(9aec4887)、最近边归属/nearest_side_assignment(9aec4887, 此处不用于归属而用于排名)、封闭区域/enclosed_region(e3721c99, 810b9b61)、孔洞数映射颜色/hole_count_to_color_mapping(e3721c99, 创新：图例不由独立色块提供而由框边提供)、计数/counting(e3721c99)、重涂色/recolor(多题)

**依赖链**：框的四条边长度不等 → 按长度排名建立颜色优先序 → 内部精灵体的孔洞数作为索引查询该优先序 → 得到重涂颜色。框的几何属性（边长）和精灵体的拓扑属性（孔洞数）在两个独立维度上各自提供信息，在重涂色环节交叉耦合。

矩形框的四条不等长边按长度排名形成调色板，框内每个灰色精灵体按其内部孔洞数索引调色板完成重涂色。

**输入结构**：约 15x15 的网格。背景为黑(0)。一个一像素厚的矩形边框占据网格边缘附近，框的四条边颜色各不相同：顶边红(2)、右边蓝(1)、底边绿(3)、左边黄(4)。框的四个角为黑(0)（角像素不属于任何边）。框为长方形（宽 ≠ 高），因此四条边中两条较长、两条较短，且上下边同长、左右边同长，共两种长度。为使四条边产生四个不同排名，框的宽和高都不相同且不等于对方（即框不是正方形），同时上边和下边像素数相同、左边和右边像素数相同——因此实际只有两种长度。修正：为使排名有四档，改为框不是标准矩形而是每条边独立定义长度的"开口框"——顶边、底边、左边、右边各自为一条独立线段，端点不相连（角为黑色），且长度两两不同。生成约束：四条边长度两两不同，保证排名无歧义。框内部散布 3-4 个灰(5)的 4-连通小图形（每个 4-10 像素），它们的内部孔洞数（被图形像素完全包围的黑(0)连通分量数）分别为 0、1、2、3 中的不同值。各灰色图形互不接触，不与框边接触。

**规则**：
1. 识别四条框边（顶、右、底、左各一条水平或垂直线段），统计每条边的像素数（长度）。
2. 按长度从短到长排名：rank 1（最短边）、rank 2、rank 3、rank 4（最长边）。
3. 对每个灰(5)精灵体，统计其内部孔洞数：一个孔洞 = 一个被该精灵体的像素完全包围（4-连通意义下与精灵体外部黑色不连通）的黑(0)连通分量。
4. 将孔洞数加 1 作为排名索引：0 个孔洞 → rank 1 的颜色；1 个孔洞 → rank 2 的颜色；2 个孔洞 → rank 3 的颜色；3 个孔洞 → rank 4 的颜色。
5. 将该精灵体的所有灰(5)像素重涂为对应颜色。孔洞内部保持黑(0)不填充。
6. 框边和背景保持不变。

**关键洞察**：框不是普通的容器——它的四条边的长度差异编码了一个有序颜色映射表。精灵体的拓扑属性（孔洞数）不是直接映射到固定颜色，而是索引到这个由框几何属性动态生成的映射表。不同示例中框的边长比例不同，导致同一颜色在不同示例中可能对应不同的孔洞数。必须对比多个示例才能发现"排名"机制而非"固定颜色"映射。

## 新题 6：同心环逐层重力沉降后反转层色

**组合逻辑**：[同心方框层识别](已有) → [逐层重力下落](创新：重力作用范围被层边界约束，像素只在本层内下落) → [层色序翻转](已有，创新：翻转发生在重力改变像素位置之后，几何变换和颜色变换解耦执行但结果紧耦合)

**来源原语**：同心方框层/concentric_layer(85c4e7cd)、深度排序/depth_order(85c4e7cd)、层色序内外翻转/reverse_layer_colors(85c4e7cd)、重力下落/gravity_drop(5ffb2104)、碰撞阻挡/collision_blocking(5ffb2104)、擦除/erase(多题)

**依赖链**：层识别界定每个像素的归属层 → 逐层独立施加重力（像素仅在本层的合法位置内下落，不穿越层边界）→ 重力改变像素在层内的分布 → 最后按深度翻转各层颜色（最外层色↔最内层色）。单看一个示例可能误以为颜色直接移动了位置，必须对比多个示例才能分离出"重力"和"颜色翻转"是两个独立步骤。

同心矩形环中每层有部分像素被擦除形成缺口，先在每层内部施加向下重力使残余像素沉降，再将各层颜色按深度反转。

**输入结构**：约 13x13 的正方形网格。网格由 3-4 层同心矩形环组成，每层一像素厚，颜色各不相同，取自 {蓝(1), 红(2), 绿(3), 黄(4)}。层与层之间无间隙（相邻层紧密嵌套）。每层中有若干像素被擦除为黑(0)，形成不规则缺口（每层保留至少 60% 的像素，缺口不集中在一侧）。网格中心为最内层，可能是一个实心小方块或一个 1 像素厚的环。生成约束：每层的缺口位置在不同示例间变化；各层的原始颜色在不同示例间可能交换。

**规则**：
1. 按每个像素到网格最近边缘的切比雪夫距离（取行距边缘距离和列距边缘距离的较小值）确定其层归属：距离 0 = 最外层（depth 0），距离 1 = 次外层（depth 1），以此类推。
2. 对每一层独立施加向下重力：将该层中所有非黑像素在各自所在列内向下滑动，滑动范围仅限于该层的合法位置集合（即属于该层的所有格位）。像素在列内下落时，跳过不属于本层的格位，直到落在本层最底部的空位上或堆叠在本层内已有像素之上。处理顺序：同一层内从最底行的像素开始向上逐行处理。
3. 重力完成后，记录从 depth 0 到最大 depth 的颜色序列（每层的颜色 = 该层中当前存在的非黑像素颜色，每层只有一种颜色），将该序列反转。
4. 对每一层，将其所有非黑像素重涂为反转后对应深度的颜色。黑(0)缺口保持不变。

**关键洞察**：重力和颜色翻转是两个独立的变换，但在视觉上难以分离——像素既改变了位置（沉降）又改变了颜色（翻转）。层边界约束了重力作用范围，使得内层像素不会穿过外层，这与无约束的全局重力行为截然不同。观察者必须先理解层结构，才能正确解析重力行为和颜色翻转的独立作用。

## 新题 7：边界标记画线分区后按内容密度选模板补全

**组合逻辑**：[边界标记定贯穿线](已有) → [连线/分区](已有，创新：线不仅是视觉元素，还定义了区域边界) → [模板选择](创新：模板不固定在特定位置，而由区域内容密度决定) → [补全](已有，创新：缺失像素用分隔线颜色填充，分隔色同时承担分区和补全两种功能)

**规则**：
1. 找到仅出现在网格边界上的颜色（栗(9)）。
2. 对于在上边缘或下边缘的栗(9)标记，画一条该列的全高垂直线（颜色为栗(9)）。对于在左边缘或右边缘的栗(9)标记，画一条该行的全宽水平线（颜色为栗(9)）。画线时覆盖原有像素。
3. 分隔线将网格分为 4 个矩形区域（不含分隔线本身）。
4. 统计每个区域内非背景（非黑(0)、非栗(9)）像素的总数，选择像素数最多的区域作为模板。
5. 对其他三个区域，逐像素与模板对比（按区域内相对坐标对齐）：模板中有非背景像素而该区域对应位置为黑(0)的，将该位置填充为栗(9)。
6. 已有的非背景像素保持不变。分隔线保持不变。

**关键洞察**：栗色同时扮演两个角色——作为边界标记指示分隔线位置，以及作为补全填充色标记被模板覆盖但在当前区域中缺失的位置。模板不在固定位置（如左上角），而由内容密度决定，因此必须先完成分区和密度统计才能确定模板。仅看单个示例可能会把密度最高的区域误认为固定在某个象限。

## 新题 8：旋转拼合后跨象限孔洞分类填充

**组合逻辑**：[精灵裁剪](已有) → [旋转拼接](已有) → [封闭区域检测](已有，创新：检测对象是拼合后涌现的跨象限孔洞) → [按象限跨度分类填充](创新：填充颜色由孔洞横跨的象限数决定，这是拼合后才涌现的属性)

**来源原语**：精灵裁剪/sprite_crop(2697da3f)、旋转/rotate(2697da3f, 46442a0e)、拼接/concatenate(46442a0e)、四旋转变体组拼图/four_rotations_composite(46442a0e)、象限/quadrant(46442a0e)、封闭区域/enclosed_region(810b9b61, e3721c99)、有空洞则重涂/recolor_if_hole(810b9b61, 创新：不是重涂有洞对象而是填充洞本身)、填充/fill(00dbd492)

**依赖链**：裁剪+旋转+拼合生成 2x2 复合图案 → 复合图案中涌现出原始精灵中不存在的跨象限封闭区域 → 每个封闭区域跨越的象限数决定其填充颜色。涌现效应是核心：单个旋转变体中的孔洞在拼合后可能与邻接象限的孔洞合并，产生跨 2 或 3 个象限的大孔洞，这在任何单一象限中都无法预见。

**输入结构**：约 8x8 的网格。背景为黑(0)。网格中有一个蓝(1)的 4-连通不对称精灵体（无水平或垂直镜像对称性），约 8-15 像素，具有至少一个内部孔洞（被蓝像素完全包围的黑色区域）。精灵体不接触网格边界。生成约束：精灵体的边界框为 h x w；精灵体不具有 90° 旋转对称性（保证四个旋转变体互不相同）；精灵体的形状使得四变体拼合后在象限交界处会出现新的封闭区域（至少一个跨越 2 个象限的孔洞）。

**规则**：
1. 裁剪精灵体至其最小边界框（h x w）。
2. 生成四个变体：原始（0°）、顺时针 90°、180°、逆时针 90°。
3. 将四个变体排列为 2x2 网格：左上 = 原始，右上 = 顺时针 90°，左下 = 逆时针 90°，右下 = 180°。输出尺寸为 2h x 2w。
4. 在拼合后的 2h x 2w 网格中，找到所有被蓝(1)完全包围的黑(0)连通分量（4-连通），即不与网格边缘的黑色区域连通的封闭区域。
5. 对每个封闭区域，判断其像素跨越了哪些象限（左上、右上、左下、右下）：
   - 仅在 1 个象限内 → 填充为绿(3)。
   - 跨越恰好 2 个象限 → 填充为黄(4)。
   - 跨越 3 个或 4 个象限 → 填充为红(2)。
6. 蓝(1)像素保持不变。与网格边缘连通的黑(0)区域保持黑(0)。

**关键洞察**：原始精灵体中的孔洞在旋转拼合后可能与相邻象限的孔洞在边界处连通，形成跨象限的更大封闭区域——这是一种涌现效应，仅凭观察单个旋转变体无法预测。填充颜色取决于这种涌现后的拓扑属性（象限跨度），而非原始精灵体的任何属性。

**规则**：
1. 记录每根柱的原始颜色、高度和所在列位置（槽位）。
2. 按高度从矮到高排序所有柱。
3. 按列位置从左到右排序所有槽位。

7. 基线保持灰(5)。分隔线保持品红(6)。

**依赖链**：框界定了重力作用的封闭空间 → 精灵体在框内向下掉落并堆叠（碰撞阻挡）→ 掉落后每个像素的位置改变了它到四条框边的距离 → 距离最近的唯一框边决定该像素的颜色。重力是物理过程，最近边归属是几何计算，两者在时间上串联：同一个精灵体中不同像素可能因重力后的位置分布而被涂为不同颜色。

在四色矩形框内将灰色精灵体向下掉落堆叠，然后按每个像素到最近框边的距离将其涂为对应框边的颜色。

**输入结构**：约 15x15 的网格。背景为黑(0)。网格边缘附近有一个一像素厚的矩形边框，四条边颜色不同：顶边红(2)、右边蓝(1)、底边绿(3)、左边黄(4)。框的四个角为黑(0)。框内散布 3-5 个灰(5)的小精灵体（每个 4-连通，3-8 像素，形状不规则），悬浮在框内不同高度。精灵体之间互不接触，不与框边接触。生成约束：框为长方形（宽 ≠ 高），保证角落区域存在等距歧义像素；精灵体的初始位置使得至少有一个精灵体在重力前后改变了最近框边归属。

**规则**：
1. 对框内所有灰(5)精灵体施加向下重力。处理顺序：按精灵体边界框底边行号从大到小（最底部的精灵体先处理）。
2. 每个精灵体整体向下平移，保持形状不变，直到其任一像素的下一行位置被底部框边或已落定的其他精灵体像素占据。精灵体整体移动（不拆分）。
3. 所有精灵体落定后，对框内每个非黑非框边的像素（即原灰色精灵体像素），计算它到四条框边的最短曼哈顿距离：
   - 到顶边距离 = 该像素行号 - 顶边行号
   - 到底边距离 = 底边行号 - 该像素行号
   - 到左边距离 = 该像素列号 - 左边列号
   - 到右边距离 = 右边列号 - 该像素列号
4. 如果最近的框边唯一，将该像素涂为最近框边的颜色。如果存在两条或更多框边等距（平局），该像素保持灰(5)。
5. 框边本身保持原色不变。框内的黑(0)背景保持不变。

**关键洞察**：重力改变了精灵体的垂直位置，从而改变了每个像素到顶边和底边的距离——原本靠近顶边的像素在下落后可能变为靠近底边。同一个精灵体内部的不同像素可能因列位置不同而被涂为不同颜色（靠左的像素涂黄、靠右的涂蓝）。重力前后像素的最近边归属可能完全不同，必须基于落定后的最终位置计算颜色。
