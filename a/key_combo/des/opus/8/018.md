## 新题 1：角落指示镜像印章

**组合逻辑**：[mirror](创新：反射方式由帧内角落指示像素的空间位置动态编码，而非全局固定或由阵列坐标决定) x [stamp_overlay](已有：将变换后的精灵体印入空槽位) <-- [support_match](创新：支撑签名从"形状匹配"改为"角落位置编码反射类型")

**来源原语**：mirror/reflect(c48954c1, 8be77c9e, 9dfd6313)、stamp_overlay + shape_matching + support_match(e5062a87)

**依赖链**：每个空帧内部的角落指示像素位置决定了对精灵体施加哪种镜像反射 -> 反射结果决定了印入帧内的具体图案。去掉指示像素解读，反射类型不确定；去掉印章逻辑，反射结果无处放置。两者通过"角落位置 = 反射编码"这一结构关系紧密耦合。

从角落指示像素的位置推断反射类型，将精灵体的对应镜像印入每个空帧。

**输入结构**：
- 网格约 15x15，背景黑(0)。
- 左上角区域放置一个非对称精灵体（由红(2)像素组成的 4-连通单色图形，3~6 像素，关于水平轴和垂直轴均不对称，使四种反射产生四种不同图案）。精灵体的包围框为 RxC（R 行 C 列）。
- 网格其余位置散布 4~6 个矩形空帧，每个帧由灰(5)像素构成的 1 像素宽边框围成，内部大小恰好为 RxC（与精灵体包围框相同）。帧之间互不重叠，且不与精灵体重叠。
- 每个帧的内部恰好有一个蓝(1)像素，位于内部四角之一（左上、右上、左下、右下）。不同帧的蓝像素角落位置可能不同。
- 生成约束：精灵体在水平和垂直方向上都不对称（保证四种反射各不相同）。

**规则**：
1. 将精灵体包围框内的红(2)像素提取为印章掩码。
2. 对每个帧，识别其内部蓝(1)像素所在的角落位置：
   - 左上角 -> 对印章掩码不做变换（原始方向）。
   - 右上角 -> 水平翻转（左右列倒序）。
   - 左下角 -> 垂直翻转（上下行倒序）。
   - 右下角 -> 水平 + 垂直翻转（行列均倒序）。
3. 将变换后的印章掩码印入帧的内部区域，掩码的 (0,0) 对齐帧内部的左上角。掩码中红(2)位置覆盖帧内部对应单元（无论该单元原来是黑还是蓝）。掩码中非红位置不改变帧内部对应单元。
4. 各帧独立处理，处理顺序不影响结果。
5. 灰(5)帧边框和原始精灵体像素保持不变。

**关键洞察**：蓝色角落像素不是装饰——它编码了四种镜像中的哪一种应该填充该帧。精灵体的非对称性保证每种反射视觉上截然不同，需要对比多个示例中不同角落位置对应的不同印章方向才能归纳出编码规则。

## 新题 2：拓扑房间分类决定排序堆叠方向

**组合逻辑**：[connected_component_detection + edge_reachability -> topological_classification](已有) -> [sorting](创新：排序方向由拓扑分类动态决定，开放区域升序/封闭区域降序) -> [sliding -> 堆叠](创新：对齐锚点由拓扑分类决定，开放区域左对齐/封闭区域右对齐)

**来源原语**：connected_component_detection + edge_reachability + topological_classification(84db8fc4)、sorting + sliding + stacked_by_increasing_length(beb8660c)、alignment(beb8660c)

**依赖链**：泛洪填充将背景分为开放区域（触边）和封闭区域（不触边） -> 分类结果同时决定区域内线段的排序方向（升序/降序）和对齐锚点（左对齐/右对齐） -> 排序后的线段按决定的方向堆叠。去掉拓扑分类，排序方向和对齐方式不确定；去掉排序，堆叠顺序不确定。

根据房间是否触及网格边缘，以相反的排序方向和对齐方式堆叠其中的线段。

**输入结构**：
- 网格约 20x20，背景黑(0)。
- 灰(5)像素形成 1 像素宽的正交墙壁，将网格分成 4~8 个矩形房间。部分房间的一侧或多侧与网格外缘重合（开放房间），其余房间被墙壁完全包围（封闭房间）。
- 每个房间内有 2~4 条水平单色线段（每条线段为 1 像素高的水平条，颜色取自非黑非灰的颜色，各线段颜色可不同）。线段长度范围为 1 到 (房间宽度 - 2)，同一房间内各线段长度互不相同。线段放置在房间内的任意行位置，互不重叠。
- 每个房间中至少有一行不被线段占据的空行。
- 生成约束：每个房间至少包含 2 条线段；每个房间内各线段长度互不相同；至少有 2 个开放房间和 2 个封闭房间。

**规则**：
1. 识别所有 4-连通黑(0)区域（不含灰墙壁）。若区域中任一像素位于网格最外一圈（第 0 行、最后一行、第 0 列、最后一列），则分类为"开放"；否则分类为"封闭"。
2. 对每个开放房间：
   - 按长度升序排列该房间中的线段（最短在前）。
   - 清除所有线段的原始位置（设为黑(0)）。
   - 从房间内部最上一行开始，逐行向下放置排序后的线段，每条线段左对齐到房间内部最左一列。
3. 对每个封闭房间：
   - 按长度降序排列该房间中的线段（最长在前）。
   - 清除所有线段的原始位置（设为黑(0)）。
   - 从房间内部最下一行开始，逐行向上放置排序后的线段，每条线段右对齐到房间内部最右一列。
4. 所有灰(5)墙壁像素保持不变。
5. 房间中未被线段占据的行保持黑(0)。

**关键洞察**：外观相同的线段在开放房间和封闭房间中会被以完全相反的方式重新排列——这一差异仅取决于房间是否触及网格边缘，而房间的边缘可达性无法从线段本身看出。必须对比多个示例中不同位置房间的堆叠方向才能发现拓扑分类与排序方向的映射。

## 新题 3：近端边缘条着色的网格线与障碍遮断

**组合逻辑**：[grid_line_drawing](已有：绘制周期-2 网格线) + [toward_nearer_expand -> 颜色选择](创新：网格线的颜色不是固定的，而是由该位置到两条边缘条的距离动态决定) + [truncate_at_blocker](创新：障碍像素不是截断射线，而是在其所在列上定向遮断网格线)

**来源原语**：grid_line_drawing + row_column_index_parity(332efdb3)、edge_bar + toward_nearer_expand(642248e4)、blocker_pixel + truncate_at_blocker(212895b5)

**依赖链**：周期-2 奇偶规则确定哪些像素属于网格线 -> 每条网格线像素的颜色由其到两条边缘条的距离比较决定 -> 障碍像素在其所在列上阻断网格线（被遮断的像素保持背景色）。三者紧耦合：去掉网格线规则则没有需要着色的像素；去掉近端着色则颜色不确定；去掉障碍遮断则图案范围不正确。

在两条不同颜色的边缘条之间绘制周期-2 网格线，每条网格线像素取较近边缘条的颜色，但障碍像素在其列上定向遮断近端方向的网格线。

**输入结构**：
- 网格宽度为奇数（约 13~17），高度为奇数（约 13~17），背景黑(0)。
- 第 0 行为红(2)边缘条（整行红色）。最后一行为蓝(1)边缘条（整行蓝色）。
- 第 1 行到倒数第 2 行之间散布 3~6 个灰(5)单像素障碍，放置在黑(0)背景上。障碍不放在第 0 行或最后一行。
- 生成约束：障碍像素之间不相邻（4-连通意义下）；每列最多一个障碍。

**规则**：
1. 在第 1 行到倒数第 2 行的范围内（不含两条边缘条所在行），识别"网格线像素"：像素 (r, c) 为网格线像素当且仅当 r 为偶数或 c 为偶数（使用 0-基索引，即第 0 行为偶数行）。r 和 c 均为奇数的像素不是网格线像素，保持黑(0)。
2. 对每个网格线像素 (r, c)，计算到上边缘条的距离 d_top = r，到下边缘条的距离 d_bottom = (H-1) - r，其中 H 为网格总高度。若 d_top <= d_bottom，该像素颜色为红(2)；若 d_top > d_bottom，颜色为蓝(1)。
3. 障碍遮断：对每个灰(5)障碍像素 (r_b, c_b)，计算其较近的边缘条方向。若 r_b <= (H-1)/2（更靠近上边缘条），则列 c_b 上从第 1 行到第 r_b - 1 行的所有网格线像素被遮断（设回黑(0)，即不绘制）。若 r_b > (H-1)/2（更靠近下边缘条），则列 c_b 上从第 r_b + 1 行到第 H-2 行的所有网格线像素被遮断。
4. 障碍像素自身保持灰(5)不变。若障碍像素所在位置恰好也是网格线像素位置，该位置显示灰(5)（障碍优先）。
5. 两条边缘条保持不变。

**关键洞察**：障碍像素的遮断方向不是固定的——它遮断的是自己与较近边缘条之间的那段列，而非较远的那段。这意味着障碍在网格上半部会抹去其正上方的网格线，在下半部会抹去其正下方的网格线。此规则必须对比多个障碍在不同行位置的示例才能归纳。

## 新题 4：线段长度排序推断平铺周期修复遮挡

**组合逻辑**：[sorting](已有：按长度排序) -> [tiling](创新：排序结果不是用于堆叠，而是定义水平重复瓦片的颜色序列) -> [completion + infer_from_visible](创新：瓦片不是从可见像素推断，而是从独立的线段排序结果构建，用于修复遮挡区域)

**来源原语**：sorting + segment(beb8660c)、tiling + repeating_tile + completion + infer_from_visible(ca8f78db)、occluded_region(ca8f78db)

**依赖链**：线段按长度排序产生颜色序列 -> 该序列定义水平重复瓦片 -> 瓦片修复下方面板的遮挡区域。去掉排序，瓦片颜色顺序不确定；去掉瓦片构建，遮挡区域无法修复；单独看下方面板，因大面积连续遮挡无法从可见像素唯一推断瓦片。

将散布线段按长度排序得到颜色序列，以此为水平重复瓦片修复被黑色遮挡的周期图案。

**输入结构**：
- 网格约 12x18（12 行 18 列），背景黑(0)。
- 上半区（约前 5 行）：3~5 条水平单色线段散布在不同行。每条线段颜色互不相同（取自红(2)、绿(3)、黄(4)、橙(7)、品红(6)等非黑非灰颜色），长度互不相同（范围 1~5 像素）。线段的列位置任意，各线段之间不重叠。
- 一条灰(5)水平分隔行（1 像素高，跨越整个网格宽度），位于上下半区之间。
- 下半区（分隔行以下，约 6 行）：一个水平重复颜色图案，使用与上半区线段相同的颜色集合。该图案的水平周期 = 上半区线段数量。部分单元被替换为黑(0)（遮挡）。
- 生成约束：下半区中每行至少有一个完整周期长度的连续遮挡（确保无法仅从可见像素唯一推断颜色顺序）；下半区的重复图案颜色顺序恰好等于上半区线段按长度升序排列后的颜色顺序。

**规则**：
1. 提取上半区的所有水平线段，记录每条线段的颜色和长度（像素数）。
2. 按长度升序排列线段，得到颜色序列 [c1, c2, ..., cN]（c1 为最短线段的颜色，cN 为最长线段的颜色）。
3. 此颜色序列构成水平重复瓦片 T，周期为 N。
4. 在下半区中，对每个被遮挡的黑(0)单元 (r, c)，用 T[c mod N] 替换其颜色（c 为该单元在网格中的列索引，mod 运算使用 0-基索引）。
5. 下半区中原本可见的（非黑）单元保持不变。
6. 上半区和分隔行保持不变。
7. 输出为整个网格（包含上半区、分隔行和修复后的下半区）。

**关键洞察**：下半区的遮挡面积足够大，使得仅看可见像素无法唯一确定颜色排列顺序。必须利用上半区线段的长度排序来获取正确的颜色序列——线段的空间位置和颜色是干扰项，只有长度决定排列顺序。

## 新题 5：对角对称约束下的泛洪填色传播

**组合逻辑**：[flood_fill](已有：检测墙壁围成的房间) + [reflect/transpose -> diagonal_symmetry](创新：转置不是对整个网格操作，而是作为约束条件——每个无种子房间的颜色由其对角镜像房间的种子颜色决定)

**来源原语**：flood_fill + connected_region(84db8fc4, 7491f3cf)、reflect + diagonal_symmetry + transpose_along_diagonal(9dfd6313)

**依赖链**：泛洪填充定义房间边界 -> 有种子的房间直接获得颜色 -> 无种子房间需要找到其对角镜像位置的房间并复制该房间的颜色。去掉泛洪填充则房间不确定；去掉对角对称约束则无种子房间的颜色无从确定。这不是线性流水线，而是同时约束满足：填色结果必须使输出（不含墙壁）在主对角线上对称。

通过对角对称约束，从有种子的房间向其对角镜像位置的无种子房间传播颜色，使最终结果在主对角线上对称。

**输入结构**：
- 网格为正方形，约 11x11 或 13x13，背景黑(0)。
- 灰(5)像素形成 1 像素宽的正交墙壁，将网格分成多个矩形房间。墙壁图案关于主对角线对称（即将网格按主对角线转置后，墙壁图案不变）。
- 部分房间内包含一个单像素种子（颜色取自红(2)、蓝(1)、绿(3)、黄(4)等非黑非灰颜色）。
- 由于墙壁的对角对称性，房间成对出现：房间 R 的对角镜像房间 R' 的位置是将 R 中每个像素的 (row, col) 坐标互换后得到的区域。横跨主对角线的房间是自身的镜像。
- 生成约束：(a) 在每对对角镜像房间中，至少有一个包含种子；(b) 横跨对角线的房间必须包含种子；(c) 同一对镜像房间中不会出现两个不同颜色的种子（若两边都有种子则颜色必须相同）。

**规则**：
1. 用灰(5)墙壁作为障碍，对黑(0)背景进行 4-连通泛洪填充，识别所有房间。
2. 对每个包含种子像素的房间，将该房间中所有黑(0)像素填充为种子的颜色。种子像素本身保持不变。
3. 对每个不包含种子的房间，找到其对角镜像房间（将该房间任一像素的坐标 (r, c) 互换为 (c, r)，所在的房间即为镜像房间）。将该无种子房间的所有黑(0)像素填充为镜像房间的种子颜色。
4. 若镜像房间也无种子（生成约束下不会发生此情况），该房间保持黑(0)。
5. 所有灰(5)墙壁保持不变。所有种子像素保持原色。

**关键洞察**：没有种子的房间不是简单地保持空白——它的颜色由主对角线另一侧的镜像房间决定。从单个示例可能误认为"所有房间都被填充为相邻房间的颜色"，必须对比多个示例才能发现无种子房间的颜色总是等于其对角镜像房间的颜色，而非其他相邻房间的颜色。

## 新题 6：U 形框架液位排名决定重涂颜色

**组合逻辑**：[counting](已有：计数空行数/液位高度) -> [sorting](创新：排序不是为了堆叠线段，而是为了在多个框架之间确定相对排名) -> [recolor](创新：重涂颜色不由对象自身属性决定，而由全局排名映射表决定)

**来源原语**：counting + empty_rows_map_to_fill_amount + u_shaped_frame(b0c4d837)、sorting(beb8660c, 817e6c09)、recolor + alternating_parity_selection(817e6c09)

**依赖链**：计数每个框架的空行数（液面高度） -> 空行数在所有框架间排序产生全局排名 -> 排名映射到固定颜色表决定每个框架填充物的新颜色。去掉计数，排名无从建立；去掉排序，不知道哪个框架排名更高；去掉颜色映射，排名无法转化为输出。

比较多个 U 形框架的液位高低，按液位排名重新上色。

**输入结构**：
- 网格约 15x20（15 行 20 列），背景黑(0)。
- 3~5 个 U 形框架水平排列（框架之间至少隔 2 列黑色间距）。每个框架由橙(7)像素构成，形状为 U 形（底边 + 左右两侧壁，顶部开口）。框架外部尺寸相同（约 5 列宽、8~10 行高）。
- 每个框架内部底部有一段连续填充色（各框架填充色各不相同，取自红(2)、蓝(1)、绿(3)、黄(4)、品红(6)等），填充从框架内部最底行向上延伸若干行，形成底对齐的实心矩形。每个框架的填充高度不同。
- 填充色以上的内部空间为黑(0)（空行）。
- 生成约束：各框架的空行数（液面以上内部空行数）互不相同。

**规则**：
1. 对每个 U 形框架，计算其内部空行数 E（从框架内部最顶行到填充色最顶行之间的黑(0)行数）。E 越大表示液位越低。
2. 将所有框架按 E 升序排列（E 最小 = 液位最高 = 排名 0）。
3. 按排名重新上色每个框架内的填充像素：
   - 排名 0 -> 红(2)
   - 排名 1 -> 蓝(1)
   - 排名 2 -> 绿(3)
   - 排名 3 -> 黄(4)
   - 排名 4 -> 品红(6)
4. 填充的高度和位置不变，仅颜色改变。
5. 框架边框（橙(7)）和背景保持不变。

**关键洞察**：每个框架的新颜色不取决于它原来的颜色或自身的液位绝对高度，而取决于它在所有框架中的液位相对排名。单独看一个框架无法确定其输出颜色——必须对比所有框架的液位才能确定排名，而排名到颜色的固定映射表需要跨示例对比才能归纳。

## 新题 7：最短路径上的循环着色与路径外房间清除

**组合逻辑**：[pathfinding + shortest_path](已有) -> [cardinal_cyclic_fill](创新：循环颜色模式不是沿射线方向填充，而是沿路径行进方向逐单元填充) + [flood_fill -> 房间检测 -> 条件清除](创新：路径是否经过某房间决定该房间是保留还是清除)

**来源原语**：pathfinding + shortest_path + corridor + framed_room(3ad05f52)、cardinal_cyclic_fill(fe9372f3)、flood_fill + connected_region(84db8fc4)

**依赖链**：最短路径计算 -> 路径上的单元按行进顺序施加循环颜色 -> 路径同时判定每个房间是否被经过（路径至少穿过房间一个像素则"经过"） -> 未被经过的房间内容清除。路径决定了两件事（着色目标 + 房间保留判定），去掉路径则两者都无法执行；去掉循环着色则路径本身不可见；去掉房间清除则无法区分路径沿线与路径外。

沿最短路径施加循环颜色，同时清除路径未经过的房间。

**输入结构**：
- 网格约 15x15，背景黑(0)。
- 灰(5)像素形成 1 像素宽的正交墙壁，构成走廊和 4~6 个矩形房间（房间为墙壁围成的矩形内部空间，面积至少 3x3）。走廊为宽度 1 的通道连接房间。
- 两个单像素端点：红(2)和蓝(1)，分别位于不同的房间内。
- 部分房间内有黄(4)像素组成的小图形（1~4 像素的 4-连通图形），代表房间"内容"。不是每个房间都有内容。
- 网格右上角有一个 1x3 的颜色条：由三个相邻像素组成，颜色分别为绿(3)、品红(6)、橙(7)（不同示例中颜色条的颜色可能不同），定义循环颜色序列。
- 生成约束：红蓝端点之间存在至少一条通路；走廊不形成环路（保证最短路径唯一）。

**规则**：
1. 提取颜色条中的循环序列 [c0, c1, c2]（从左到右读取）。
2. 将灰(5)墙壁视为不可通过。在所有非墙壁像素中，找到从红(2)端点到蓝(1)端点的最短 4-连通路径（按经过的单元数计算长度）。由于无环路约束，最短路径唯一。
3. 沿路径从红端点出发向蓝端点行进，对路径上每个非端点单元依次赋予循环颜色：第 1 个单元 -> c0，第 2 个 -> c1，第 3 个 -> c2，第 4 个 -> c0，依此循环。端点像素保持原色。
4. 识别所有墙壁围成的矩形房间（4-连通非墙壁区域中，面积 >= 9 即至少 3x3 的区域为"房间"，其余为"走廊"）。
5. 若路径经过某房间（路径至少包含该房间的一个像素），则保留该房间中的所有黄(4)内容。
6. 若路径未经过某房间，则将该房间中的所有黄(4)内容清除为黑(0)。
7. 灰墙壁保持不变。颜色条保持不变。走廊中不在路径上的像素保持黑(0)。

**关键洞察**：路径同时承担两个角色——作为循环着色的载体，和作为房间保留/清除的判据。循环颜色序列必须从颜色条读取（不同示例的颜色条可能不同），而房间保留规则必须对比多个示例中路径与房间的空间关系才能归纳。

## 新题 8：双面板空域交集的连通分量按面积分级着色

**组合逻辑**：[logical_operation(intersection)](已有：双面板空域交集) -> [connected_component_detection](创新：不是对前景对象做连通分量检测，而是对交集产生的"双空"掩码做检测) -> [sorting + recolor](创新：连通分量的面积排名决定着色，而非所有交集像素统一着色)

**来源原语**：logical_operation + cell_comparison + separator_column + equal_width_panel + intersect_empty_fill(f2829549)、connected_component_detection + edge_reachability(84db8fc4)、sorting + recolor(817e6c09)

**依赖链**：双面板逐格比较产生"双空"掩码 -> 对掩码做 4-连通分量检测，分割为多个独立区域 -> 区域按面积排序得到排名 -> 排名映射到颜色表。去掉交集运算则没有掩码；去掉连通分量检测则无法区分不同区域；去掉面积排序则颜色分配无据。交集的形状由两侧面板共同决定，其内部结构（连通分量的数量和大小）是两侧形状的涌现结果。

两个面板的空白区域交集被分割为独立连通区域，按面积大小分级着色。

**输入结构**：
- 网格约 11x23（11 行 23 列），背景黑(0)。
- 第 11 列（正中列）为灰(5)分隔列（1 像素宽，跨整个网格高度）。
- 左面板（第 0~10 列）：黑(0)背景上有若干红(2)前景形状（4-连通，形态不规则，2~8 像素）。
- 右面板（第 12~22 列）：黑(0)背景上有若干蓝(1)前景形状（4-连通，形态不规则，2~8 像素）。
- 左右面板尺寸相同（均为 11 行 11 列）。
- 生成约束：两侧面板的前景形状布局使得"双空"交集掩码产生至少 3 个互不相连的 4-连通分量，且各分量面积互不相同。

**规则**：
1. 移除灰(5)分隔列。
2. 将左面板和右面板逐像素对齐比较（左面板的 (r, c) 对应右面板的 (r, c)，其中 c 为面板内局部列索引 0~10）。
3. 对每个位置 (r, c)：若左面板该位置为黑(0)且右面板该位置也为黑(0)，则该位置标记为"双空"；否则标记为"非双空"。
4. 对所有"双空"位置做 4-连通分量检测，识别各个独立的连通区域。
5. 按面积（像素数）降序排列所有连通分量。面积最大的排名 0，次大的排名 1，依此类推。
6. 着色映射：
   - 排名 0 -> 绿(3)
   - 排名 1 -> 黄(4)
   - 排名 2 -> 橙(7)
   - 排名 3 及以后 -> 栗(9)
7. "非双空"位置在输出中为黑(0)。
8. 输出为一个 11x11 的网格（分隔列已移除，左右面板合并后的结果）。

**关键洞察**：与参考题 f2829549 不同，交集区域不是统一着色——双空掩码的内部结构（由两侧面板形状共同涌现）被进一步分析为连通分量，面积排名决定了差异化着色。需要对比多个示例才能确认是面积排名（而非位置、形状等其他属性）决定颜色分配。

## 新题 9：缺角补全后的方块发射对角射线，射线被补全产物截断

**组合逻辑**：[completion](已有：缺角补全为 2x2 方块) -> [ray_extension + corner_diagonal_radiate](创新：射线起点不是预置方块的角，而是补全后才确定的方块角) + [truncate_at_blocker](创新：障碍集包含补全产生的新像素，而非仅原始输入中的像素)

**来源原语**：completion + missing_corner_completes_square + inside_bbox(3aa6fb7a)、ray_extension + corner_diagonal_radiate + truncate_at_blocker(212895b5)、solid_square + corner_ray + blocker_pixel(212895b5)

**依赖链**：先将所有不完整的 L 形小图形补全为 2x2 实心方块 -> 补全后的方块四角向外发射对角射线 -> 射线被其他方块（包括被补全后才形成的方块）截断。去掉补全则方块不完整无法确定角点位置和射线起点；去掉射线则补全结果只是简单填充。两步通过共享的空间状态紧密耦合。

先将散布的 L 形小图形补全为 2x2 实心方块，然后从每个方块的四角向外发射对角射线，射线遇到任何非背景像素（包括补全新增的像素）时截断。

**输入结构**：
- 约 14x14 的黑(0)背景网格。
- 散布 4~7 个由青(8)像素组成的 4-连通小图形，每个小图形恰好有 3 个像素且占据一个 2x2 包围框，形成 L 形（2x2 区域缺少一个角）。
- 另有若干（0~4 个）孤立的栗(9)像素作为额外障碍物散布在网格中。
- 生成约束：各 L 形图形的包围框互不重叠且不 4-连通相邻；栗(9)像素不与任何 L 形图形 4-连通相邻；至少有两个 L 形图形在补全为 2x2 方块后，一个的对角射线会被另一个的方块体截断（即补全产生了新的有效障碍）。

**规则**：
1. 对每个青(8)的 L 形图形，在其 2x2 包围框中找到唯一的黑(0)缺角位置，填充为绿(3)。所有 L 形图形同步补全。
2. 补全后，每个 2x2 方块有四个角像素。从每个角像素出发，沿该角对应的外向对角方向（左上角像素 -> 左上对角方向、右上角像素 -> 右上对角方向、左下角像素 -> 左下对角方向、右下角像素 -> 右下对角方向）逐格延伸，绘制红(2)射线。
3. 射线逐格前进，遇到以下情况停止（停止格不绘制）：超出网格边界；目标格为非黑(0)像素（包括青(8)、绿(3)补全像素、栗(9)障碍、其他方块像素）。
4. 所有射线基于补全后的完整网格状态同时计算路径，然后同时绘制。若两条射线覆盖同一格，均为红(2)，无颜色冲突。
5. 原有的青(8)像素、栗(9)障碍像素、绿(3)补全像素均保持不变。

**关键洞察**：补全不仅修复了图形的几何形状，还引入了新的障碍物——一个方块的补全像素可能截断另一个方块的射线。求解者必须先完成所有补全，才能正确计算射线路径，两步操作通过共享的空间状态紧密耦合。

## 新题 10：可见像素推断瓦片与内外分区选择性修复

**组合逻辑**：[tiling + infer_from_visible](已有：从可见像素推断最小重复瓦片) + [flood_fill + inside_outside_partition](创新：瓦片修复的范围不是全局的，而是由拓扑分区限定为封闭区域内部)

**来源原语**：tiling + repeating_tile + completion + infer_from_visible(ca8f78db)、occluded_region(ca8f78db)、flood_fill + inside_outside_partition(7491f3cf)、wall_boundary(7491f3cf)、mask_selects_source_panel(7491f3cf)

**依赖链**：可见像素推断出最小重复瓦片 -> flood_fill 区分封闭/开放区域 -> 仅封闭区域内的遮挡（黑色像素）被推断瓦片修复，开放区域的遮挡保持不变。去掉瓦片推断则无修复材料；去掉内外分区则无法确定修复范围。

从部分被黑色矩形遮挡的重复图案中推断最小瓦片，但只修复被灰色围栏封闭的区域内的遮挡，开放区域中的遮挡保持黑色。

**输入结构**：
- 约 12x12 的网格，本底为一个规则的二维重复色彩图案（周期约 3x3 或 4x4，使用红(2)、蓝(1)、黄(4)等 2~3 种颜色）。
- 若干矩形区域被黑(0)遮挡覆盖（原图案内容被替换为黑(0)）。
- 灰(5)像素构成一个或多个 4-连通闭合围栏，围栏穿越图案但不破坏图案的周期性（围栏位置不影响瓦片推断）。
- 部分遮挡矩形在围栏内部，部分在围栏外部。
- 生成约束：围栏外部的可见（非黑非灰）像素足以唯一确定最小重复瓦片；至少一个遮挡矩形完全位于围栏内部，至少一个完全位于围栏外部；灰(5)不出现在重复图案中。

**规则**：
1. 将灰(5)像素和黑(0)像素均视为"未知"，利用其余可见像素推断最小矩形重复瓦片 T（找到与所有可见像素一致的最小周期矩形）。
2. 从网格四条边缘向内 4-连通 flood fill（不穿越灰(5)像素），标记可达区域为"外部"，不可达区域为"内部"。
3. 对网格中每个黑(0)像素：
   - 若该像素位于"内部"区域：用推断瓦片 T 的对应位置颜色替换（即 T[r mod Tr][c mod Tc]，其中 Tr、Tc 为瓦片行列周期）。
   - 若该像素位于"外部"区域：保持黑(0)不变。
4. 灰(5)围栏像素保持不变。
5. 所有原本可见的非黑非灰像素保持不变。

**关键洞察**：同样的黑色遮挡在围栏内外有不同命运——围栏内部的遮挡被推断瓦片修复，外部的保持黑色。求解者必须同时理解瓦片推断规则和拓扑分区规则，两者交叉决定每个黑色像素的最终状态。单个示例可能让人误以为"所有遮挡都被修复"或"所有遮挡都保留"，需要对比不同拓扑位置的遮挡行为才能归纳出分区规则。
