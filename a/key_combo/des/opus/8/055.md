## 新题 1：对称门控重力与镜像着陆

**组合逻辑**：[镜像(mirror)](创新：从静态格元补全改为条件触发的动态反射) + [重力下落(gravity_drop)](已有) + [对称补全(symmetry_completion)](创新：从三存一缺补全改为对称性检测作为行为分支条件) — 条件分支结构，非线性流水线

**来源原语**：镜像/对称补全/块内对称 ← 2546ccf6；重力下落/穿透与停靠/宽度决定行为/分隔行 ← 84ba50d3

**依赖链**：对称性检测结果决定重力行为分支（穿透 vs. 停靠），停靠分支触发镜像操作生成下方反射体；三者中任一缺失都导致输出不同——无对称检测则所有精灵行为一致，无重力则无空间分离，无镜像则停靠精灵下方为空。

将分隔行上方的每个精灵按其对称性分流：对称精灵穿透分隔行降至底部，非对称精灵停靠在分隔行上方并在下方生成水平镜像。

**输入结构**：约 15x15 的黑(0)背景网格。一条红(2)水平分隔行横贯全宽，位于网格中部偏下（约第 10 行）。分隔行上方散布 3-5 个单色 4-连通精灵（每个精灵 3-8 像素，颜色各不相同，均非黑(0)、非红(2)），各精灵互不相邻且不接触分隔行。精灵形态多样——有的关于自身垂直中轴对称（如竖条、十字、菱形），有的不对称（如 L 形变体、不规则连通块）。分隔行下方全为黑(0)背景。生成约束：每个精灵的包围框宽度不超过 4 列；不同精灵的列范围互不重叠。

**规则**：
1. 对每个精灵，检测其是否关于自身包围框的垂直中轴线左右对称。
2. **对称精灵**：整体向下平移，穿过分隔行，直至其最底行到达网格最底行。精灵所经过的分隔行像素被删除（恢复为黑(0)）。精灵颜色不变。
3. **非对称精灵**：整体向下平移，直至其最底行紧贴分隔行上方（即最底行位于分隔行上一行）。随后，将该精灵在其包围框内水平翻转（左右镜像），将翻转后的图案绘制在分隔行正下方对应的列位置（镜像体最顶行紧贴分隔行下一行），颜色与原精灵相同。原精灵保留在分隔行上方。
4. 处理顺序：按精灵包围框左边缘列号从小到大依次处理。若某精灵的目标位置（下落终点或镜像位置）与已处理精灵的像素冲突，冲突像素保留先处理者的颜色，后处理者的冲突像素不绘制。
5. 未被穿透的分隔行像素保持红(2)不变。

**关键洞察**：分隔行充当"对称门"——几何对称的精灵如同获得通行证直接穿越，而非对称精灵被拦截并在门的另一侧产生其镜像副本。对称性不是用来补全缺失部分，而是决定物理行为的判据。需要对比多个示例才能确认"对称 vs. 非对称"是分流条件，而非精灵大小、颜色或位置。

## 新题 2：对角射线分区与图例解码填充

**组合逻辑**：[射线延伸(ray_extend)](创新：从视觉装饰改为空间分区工具) + [解码(decode)](创新：从图案内部槽位解码改为空间象限-图例位置的拓扑映射) + [区域填充(flood_fill)](已有)

**来源原语**：射线延伸/孤立像素/对角方向 ← 623ea044；解码/色彩图例/图例映射 ← 1be83260；区域填充/射线遮挡分区 ← 1190bc91

**依赖链**：射线从原点向四个对角方向延伸，将网格分为四个象限区域；图例的 2x2 布局与四象限形成拓扑映射；区域填充将映射后的颜色施加到每个象限。射线决定区域形状 → 图例决定区域颜色 → 填充产生输出。三者环环相扣。

以一个孤立像素为原点发射四条对角射线将网格分为四个象限，再用角落的 2x2 色彩图例为每个象限指定填充色。

**输入结构**：约 14x14 的黑(0)背景网格。左上角有一个 2x2 的色彩图例块，其四个像素颜色各不相同（从红(2)、绿(3)、蓝(1)、黄(4)中选取四种），图例块紧贴网格左上角（第 0-1 行、第 0-1 列）。网格中另有一个灰(5)孤立像素（单个像素，不与图例相邻），位于网格中部区域（距四边至少 3 格）。其余均为黑(0)。生成约束：灰(5)像素的行列位置使得四条对角射线均能延伸至少 3 格才到达网格边界。

**规则**：
1. 从灰(5)孤立像素出发，沿四个对角方向（左上、右上、左下、右下）各画一条射线直到网格边界。射线像素颜色为灰(5)。灰(5)原点像素保留。
2. 四条射线将网格划分为四个象限区域：上方象限（灰像素正上方、两条上行射线之间的区域）、右方象限（灰像素正右方、右上射线与右下射线之间）、下方象限（灰像素正下方、两条下行射线之间）、左方象限（灰像素正左方、左上射线与左下射线之间）。射线像素本身不属于任何象限。
3. 读取 2x2 图例块：左上格 → 上方象限的填充色，右上格 → 右方象限的填充色，左下格 → 左方象限的填充色，右下格 → 下方象限的填充色。
4. 将每个象限内的所有黑(0)像素填充为对应颜色。图例块所在位置的像素也被其所在象限的颜色覆盖（图例在输出中消失）。射线像素和灰(5)原点像素保持灰(5)不变。
5. 与灰(5)像素同行或同列但不在对角射线上的像素，归属到它们与射线围成的相邻象限中（即正上/正下/正左/正右的窄条分别归入上/下/左/右象限）。

**关键洞察**：图例的 2x2 空间布局与射线产生的四象限之间存在拓扑同构——图例的"左上/右上/左下/右下"对应射线交叉点划分的"上/右/左/下"。这一映射关系在单个示例中存在多种可能解读（如图例行优先 vs. 列优先），需对比多个示例（不同灰像素位置导致不同象限面积比）才能锁定正确映射。

## 新题 3：不规则分量面积驱动的同心框构建

**组合逻辑**：[计数(counting)](创新：从筛选依据改为构造参数编码) + [排序(sort)](创新：从水平顺序改为距中心距离排序) + [嵌套包裹(nested_wrapping)](创新：从色条高度驱动改为分量面积驱动) — 隐式编码结构

**来源原语**：计数/连通分量/面积筛选/忽略干扰项 ← a3325580；排序 ← a3325580；嵌套包裹/同心正方形层/逐层构建/条高决定框厚 ← 45a5af55

**依赖链**：连通分量面积计数提供框厚数值 → 分量到网格中心距离排序提供嵌套层序 → 逐层包裹生成同心结构。面积编码了几何参数（框厚），位置编码了嵌套序（近中心 → 内层），两个独立空间属性交织驱动同一构建过程。

将散布于网格的不规则单色连通分量转化为同心正方形框——每个分量的像素数决定对应框的厚度，分量到网格中心的距离决定框的嵌套层序。

**输入结构**：约 14x14 的黑(0)背景网格。散布 3-4 个单色 4-连通前景分量，每个分量颜色各不相同（从蓝(1)、红(2)、绿(3)、黄(4)、品红(6)、橙(7)中选取）。每个分量面积为 1-3 像素，形状不规则（不是矩形），各分量互不相邻。不同分量到网格中心（逐行逐列取整数中点）的曼哈顿距离（以分量质心计算，四舍五入到整数）各不相同。生成约束：所有分量面积互不相同。

**规则**：
1. 识别所有非黑(0)4-连通前景分量。
2. 计算每个分量的面积（像素数）和质心到网格中心的曼哈顿距离。
3. 按质心到网格中心的曼哈顿距离从小到大排序。最近的分量为最内层，最远的为最外层。
4. 最内层分量：以其颜色绘制一个边长等于其面积的实心正方形，作为同心结构的核心。
5. 每个后续分量：以其颜色绘制一圈正方形框包裹当前结构，框的厚度等于该分量的面积（像素数）。
6. 输出为最终同心结构，放置在恰好包含它的最小黑(0)画布上（无额外边距）。

**关键洞察**：输入分量的具体形状是干扰项——不规则的 L 形碎片、斜线段等都只是面积的载体。求解者必须忽略形态，提取面积作为框厚参数。同时，嵌套顺序并非由面积或颜色编号决定，而由分量在网格中的空间位置（到中心距离）编码——需对比多个示例中不同分量位置排列才能发现这一空间排序规则。

## 新题 4：十字线分割与标记选区填充

**组合逻辑**：[连线(draw_line)](创新：从画布全长装饰改为矩形内部分区工具) + [填充(fill)](创新：从完整内部填充改为子区域选择性填充) + [透明叠加(overlay)](创新：从同尺寸矩形合并改为十字线与填充的遮挡叠加) — 分解-选择结构

**来源原语**：连线/十字线/中心对齐/画布全长十字线/原对象遮挡叠加 ← 41e4d17e；填充/杯状轮廓/标记像素/内部包含/标记色决定填充 ← 444801d8；透明叠加/标记无冲突合并 ← 25e02866

**依赖链**：矩形中心决定十字线位置 → 十字线将矩形内部划分为四个子区域 → 标记像素位于哪个子区域决定哪个区域被填充 → 填充颜色由标记像素颜色决定。十字线的分区功能是填充选择的前提，标记位置是颜色和区域的双重选择器。

在每个空心矩形内部画十字线将其分为四个象限，仅填充包含标记像素的那个象限。

**输入结构**：约 16x16 的青(8)背景网格。散布 2-4 个蓝(1)空心矩形（仅轮廓，内部为青(8)背景），矩形互不重叠且不接触。每个矩形内部宽高均为奇数（保证中心恰好落在一个像素上），最小内部尺寸 5x5，最大 9x9。每个矩形内部恰好有一个标记像素，颜色为红(2)、绿(3)、黄(4)或橙(7)中的一种，各矩形的标记颜色可以相同也可以不同。标记像素不在矩形的中心行或中心列上（保证它明确属于某个象限）。生成约束：标记像素距矩形内部的中心行和中心列均至少 1 格。

**规则**：
1. 对每个蓝(1)空心矩形，计算其内部区域的中心行和中心列。
2. 在矩形内部（不含轮廓像素）画一条灰(5)水平线贯穿中心行、一条灰(5)垂直线贯穿中心列。两线交叉于内部中心点。灰(5)线将内部分为四个象限：左上、右上、左下、右下。
3. 确定标记像素位于哪个象限。
4. 将该象限内所有青(8)背景像素（不含灰(5)线像素）替换为标记像素的颜色。其余三个象限保持青(8)不变。
5. 蓝(1)轮廓像素、灰(5)十字线像素均保留在最终输出中。灰(5)线覆盖标记像素原位置（如标记恰在十字线上则不存在此情况，因生成约束已排除）。标记像素所在位置被填充色覆盖。
6. 矩形外部的青(8)背景不变。

**关键洞察**：十字线不是装饰性叠加，而是功能性分区器——它将每个矩形从"一个容器"变为"四个候选区域"。单看一个示例可能误以为"填充矩形内标记所在的半边"（上/下或左/右），需要对比多个示例中标记在不同象限的情况才能归纳出四象限选择规则。

## 新题 5：隐写标记驱动的瓦片移位

**组合逻辑**：[补全(completion)](已有) + [平移(shift)](创新：从固定一列左移改为由隐写标记编码的方向和幅度) + [解码(decode)](创新：从独立图例块解码改为从重复图案内嵌的异常像素解码) — 隐式编码结构

**来源原语**：补全/平移/重复瓦片/占位符区域/周期延拓/补全后平移 ← 50a16a69；解码/色彩图例/图例映射/槽位决定颜色 ← 1be83260；标记像素 ← 444801d8, 50aad11f

**依赖链**：补全依赖瓦片推断（必须忽略标记才能正确推断瓦片）→ 标记解码依赖瓦片结构（标记在瓦片内的相对位置编码移位幅度）→ 移位依赖解码结果。三步形成信息环路：补全需要知道哪个像素是标记（颜色异常），解码需要知道瓦片尺寸（来自补全），移位需要解码结果。

在带占位符的重复瓦片中找出隐藏的异色标记像素，其颜色编码移位方向，其在瓦片内的位置编码移位幅度，据此对补全后的完整图案执行循环移位。

**输入结构**：约 12x12 的网格。左上方块被一个矩形重复瓦片（约 3x3 或 4x4）铺满，其余区域填充灰(5)占位符色。瓦片使用 2-3 种非灰(5)、非黑(0)颜色构成图案。在可见瓦片区域中，恰好有一个像素的颜色与其在瓦片周期中应有的颜色不同——该像素是隐写标记。标记颜色为以下之一：红(2)表示向右移位，蓝(1)表示向下移位，绿(3)表示向左移位，黄(4)表示向上移位。生成约束：标记颜色不与瓦片图案中已使用的颜色重复；标记恰好出现一次。

**规则**：
1. 将标记像素视为噪声，用其在瓦片周期中应有的颜色替换它，从而正确推断最小重复瓦片。
2. 将推断得到的瓦片周期性延拓到整个网格（替换所有灰(5)占位符）。
3. 解码标记：标记的颜色决定移位方向（红(2)=右, 蓝(1)=下, 绿(3)=左, 黄(4)=上）。标记像素在其所在瓦片副本内的位置坐标决定移位幅度——若方向为左/右，幅度 = 标记在瓦片内的列偏移量（从 0 起计）；若方向为上/下，幅度 = 标记在瓦片内的行偏移量（从 0 起计）。若偏移量为 0，则幅度为瓦片在该轴的尺寸（即完整移位一个瓦片周期）。
4. 对补全后的整个网格执行循环移位：沿解码方向移动解码幅度的像素数，超出边界的像素从对侧循环回来。
5. 输出移位后的完整网格。

**关键洞察**：标记像素伪装为瓦片图案中的一个"错误"，求解者必须先识别出哪个像素不属于周期图案，再理解其颜色和位置分别编码了两个独立参数。颜色-方向映射需要对比多个示例才能归纳（单个示例中无法区分"红=右"还是"标记颜色=某种其他编码"）。

## 新题 6：射线生成障碍后的同色分量连接

**组合逻辑**：[射线延伸(ray_extend)](创新：从视觉输出改为动态障碍生成器) + [连线(connect)](已有) + [计数(counting)](创新：从面积筛选改为处理优先级排序依据) — 顺序约束生成结构

**来源原语**：射线延伸/孤立像素/对角方向 ← 623ea044；连线/同色连通分量/障碍墙/同色分量依序连接/绕障碍最短路径 ← f8f52ecc；计数/面积筛选 ← a3325580

**依赖链**：孤立像素发射对角射线 → 射线成为新增障碍 → 同色分量连接路径必须绕行射线障碍 → 分量面积决定连接处理顺序 → 先连接的路径成为后续连接的障碍。层层叠加的障碍使得处理顺序实质性影响路径形态。

先从孤立像素发射对角射线作为障碍墙，再将同色分量对用最短正交路径连接，路径须绕行所有射线和已有路径。

**输入结构**：约 16x16 的黑(0)背景网格。2-3 种非黑颜色各出现恰好两个 4-连通分量（每个分量 2-5 像素，形状不规则），共 4-6 个分量。若干青(8)障碍墙线段（水平或垂直，每段 2-5 像素长）。1-2 个黄(4)孤立像素（单像素），不与任何分量或墙相邻。生成约束：每种颜色的两个分量之间存在至少一条绕行所有障碍的正交路径；黄(4)不作为连接色使用。

**规则**：
1. 从每个黄(4)孤立像素出发，沿四个对角方向各画一条射线，直到遇到非黑(0)像素或网格边界为止（不包含终点的非黑像素）。射线颜色为黄(4)。
2. 将所有黄(4)射线像素和青(8)墙像素视为不可通行障碍。
3. 对每种非黑(0)、非青(8)、非黄(4)的颜色，计算其两个分量的总面积（两个分量像素数之和）。
4. 按总面积从小到大的顺序处理各颜色。对每种颜色，找到连接其两个分量的最短正交路径（仅沿水平或垂直方向移动，每步一格），路径只能经过黑(0)背景像素，不能经过障碍或其他颜色的分量/路径像素。路径颜色 = 该分量的颜色。若存在多条等长最短路径，选择先向水平方向移动再转向垂直方向的 L 形路径；若仍有歧义，选择先向左/上移动的路径。
5. 已绘制的路径像素成为后续颜色连接时的额外障碍。
6. 输出中保留所有原始分量、障碍墙、射线和连接路径。

**关键洞察**：黄色孤立像素看似无关紧要的单点，实际上通过对角射线生成了大面积隐形障碍网，从根本上改变了同色分量之间的最短路径。处理顺序（按面积升序）需要对比多个示例才能发现——单个示例中可能碰巧与按颜色编号排序或按位置排序的结果一致。

## 新题 7：对角折叠后邻接驱动的角色轮换

**组合逻辑**：[折叠(folding)](创新：从单个 X 到 3x3 改为批量处理并改变空间邻接关系) + [旋转(rotation)](创新：从固定一步顺时针改为邻接计数驱动的可变步数轮换) + [计数(counting)](创新：从面积计算改为邻接关系计数) — 空间反馈结构

**来源原语**：折叠/压缩/对角线像素/对角到边映射 ← ca8de6ea；旋转/顺时针轮换/对角角点/对角邻接 ← 85fa5666；计数 ← a3325580, 5289ad53

**依赖链**：折叠将 5x5 X 压缩为 3x3 块并改变块间距 → 块的新位置决定邻接关系 → 邻接计数决定旋转步数 → 旋转改变 3x3 块的角色像素颜色。关键反馈：折叠前相距甚远的 X 可能折叠后变为相邻（因 5x5 缩小为 3x3），这一空间变化是旋转步数的决定因素。

将多个 5x5 X 形图案分别折叠为 3x3 块，再根据折叠后各块之间的邻接数量，对每个块的四个角像素进行对应步数的顺时针轮换。

**输入结构**：约 15x15 的黑(0)背景网格。散布 2-4 个不重叠的 5x5 X 形图案——每个 X 占据一个 5x5 区域，其两条对角线上的 9 个像素被着色（各像素颜色可能不同，使用蓝(1)、红(2)、绿(3)、黄(4)、橙(7)等），其余 16 个像素为黑(0)。不同 X 的 5x5 包围框之间至少间隔 1 格。生成约束：折叠后的 3x3 块放置于各 X 中心位置时，至少有一对块正交相邻（共享一条边）。

**规则**：
1. 对每个 5x5 X，按以下映射折叠为 3x3 块（行列从 0 起计）：
   - (0,0) → (0,0)，(1,1) → (0,1)，(0,4) → (0,2)：西北臂 → 顶边
   - (2,2) → (1,1)：中心不变
   - (3,1) → (1,0)，(1,3) → (1,2)：西南臂首像素 → 左边中，东北臂首像素 → 右边中
   - (4,0) → (2,0)，(3,3) → (2,1)，(4,4) → (2,2)：西南角 → 左下，东南臂 → 底边中，东南角 → 右下
2. 在新画布上，将每个 3x3 块放置于其原始 5x5 X 中心像素所在的位置（3x3 块的中心对齐原中心）。画布尺寸与输入相同，背景为黑(0)。
3. 对每个 3x3 块，计算与之正交相邻（上下左右共享边）的其他 3x3 块的数量，记为 N。
4. 对该 3x3 块的四个角像素执行 N 步顺时针轮换：每一步将 (0,0)→(0,2)、(0,2)→(2,2)、(2,2)→(2,0)、(2,0)→(0,0) 的颜色顺移。N=0 则不动，N=1 轮换一次，N=2 轮换两次（等价于对角互换），以此类推。边中和中心像素不参与轮换。
5. 输出画布。

**关键洞察**：折叠不仅是形态压缩，更改变了对象间的拓扑关系——原本相距甚远的 X 折叠后可能变为紧邻块，从而获得更多邻接计数、更多轮换步数。求解者必须先完成折叠才能判断邻接关系，而邻接关系又决定了颜色变换的程度。单个示例中旋转步数可能碰巧为 1，需多个示例确认"步数=邻接数"。

## 新题 8：杯体标记高度驱动的互补填充与溢出射线

**组合逻辑**：[填充(fill)](创新：从完整填充改为标记高度控制的部分填充) + [射线延伸(ray_extend)](创新：从孤立像素出发改为从杯沿出发、长度由未填充高度决定) + [追加封盖层(cap_layer_added)](已有) — 守恒律耦合结构

**来源原语**：填充/杯状轮廓/标记像素/内部包含/标记色决定填充/追加封盖层 ← 444801d8；射线延伸/孤立像素/对角方向/画布边界 ← 623ea044；数量守恒 ← 9aaea919

**依赖链**：标记像素在杯内的垂直位置同时编码两个互补参数——填充高度和射线长度，二者之和恒等于杯内部高度（守恒律）。标记越深 → 填充越多、射线越短；标记越浅 → 填充越少、射线越长。填充和射线通过守恒约束形成此消彼长的紧耦合。

在每个杯状容器中，标记像素的高度位置决定从底部填充到该高度，未填充的剩余高度则转化为从杯沿向外发射的对角射线长度。

**输入结构**：约 16x16 的黑(0)背景网格。散布 2-3 个蓝(1)杯状轮廓——每个杯由蓝(1)像素组成 U 形（底边水平、两侧壁垂直、顶部开口），内部为黑(0)。每个杯的内部宽度为 3-5 列，内部高度为 4-7 行。每个杯内部恰好有一个标记像素，颜色各不相同（从红(2)、绿(3)、黄(4)、橙(7)中选取），标记像素位于杯内部的某一行（不在最底行也不在最顶行，保证填充和射线均非零）。各杯互不重叠，杯沿上方至少有 5 行空间供射线延伸。生成约束：不同杯的标记像素行位置不同（确保射线长度不同）。

**规则**：
1. 对每个蓝(1)杯，找到内部唯一的标记像素，记录其颜色 C 和其在杯内部的行位置（从杯底部内壁起计为第 0 行）。
2. 用颜色 C 填充杯内部从底部（第 0 行）到标记所在行（含标记行）的所有像素。标记像素本身被填充色覆盖。
3. 计算未填充高度 E = 杯内部总高度 - 已填充高度（即标记行上方的空行数）。
4. 从杯左侧壁顶端外侧一格的位置出发，沿左上方对角方向延伸 E 个像素，颜色为 C。从杯右侧壁顶端外侧一格的位置出发，沿右上方对角方向延伸 E 个像素，颜色为 C。射线若遇到非黑(0)像素或到达网格边界则提前停止。
5. 在杯顶部开口正上方一行、跨越杯的外部宽度（含两侧壁），绘制一条颜色为 C 的水平封盖层。
6. 蓝(1)杯轮廓保持不变。

**关键洞察**：每个杯内存在一个守恒量——填充高度 + 射线长度 = 杯内部高度。标记像素越靠近杯底，填充区域越大但溢出射线越长；越靠近杯顶则相反。求解者必须发现这一互补关系才能预测射线长度。单个示例中可能误以为射线长度是固定的或由杯宽度决定，需要对比多个杯（不同标记高度产生不同填充/射线比例但总和恒定）才能归纳守恒律。
