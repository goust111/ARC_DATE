## 新题 1：字形节拍控制的反弹射线

**组合逻辑**：[解码指令](创新：字形面积编码行进步数而非方向) + [射线延伸/反弹](已有) + [颜色继承](已有) —— 字形提供"走多远"，墙壁物理提供"往哪走"，两者交织控制完整路径

**来源原语**：解码指令/字形指令/编码映射/起始标记（#3 136b0064）、射线延伸/反弹/墙壁像素/碰撞停止/颜色继承（#10 142ca369）

**依赖链**：字形面积序列决定每个行进阶段的步数上限 → 步数上限与墙壁/边界的空间位置共同决定该阶段内发生几次反弹及反弹位置 → 反弹位置决定方向转折和颜色切换 → 方向与颜色决定下一阶段的起始状态 → 所有阶段串联形成完整路径

从起点发射对角射线，每个行进阶段的步数由字形面积编码，行进中碰到墙壁则反弹并继承墙壁颜色，所有阶段耗尽后射线停止。

**输入结构**：
- 约 15x15 黑(0)背景网格
- 一个灰(5)起始像素位于网格某个角落区域（距角落 1-2 格）
- 网格内部散布 3-5 个墙壁像素，颜色各不相同（使用蓝(1)、红(2)、绿(3)、黄(4)中的若干种），墙壁像素互不相邻
- 沿起始像素所在的网格边缘（边缘行或边缘列的外侧），排列 3-4 个 3x3 字形图案，字形之间以至少一列（或一行）黑(0)间隔分隔。每个字形由橙(7)像素构成，像素数（面积）在 3-7 范围内且各字形面积互不相同
- 生成约束：(a) 墙壁像素的位置保证射线在所有字形阶段耗尽前不会因退出网格而提前终止；(b) 字形排列不与网格内部的墙壁或起始像素重叠；(c) 射线路径不会经过字形所在的边缘区域

**规则**：
1. 沿起始像素所在边缘，按阅读顺序（若边缘为水平边则从左到右，若为垂直边则从上到下）读取所有 3x3 字形图案。每个字形的橙(7)像素总数即为该阶段的步数上限
2. 射线从灰(5)起始像素出发，初始方向为远离最近角落的 45 度对角方向（例如起始像素靠近左上角，则初始方向为右下）。射线初始颜色为灰(5)
3. 进入第一阶段（步数上限 = 第一个字形面积）。射线沿当前对角方向逐格行进，每移动一格执行以下判断：
   - 若目标格为墙壁像素：射线采纳该墙壁的颜色作为新颜色，将该墙壁格重涂为此颜色（保持可见），射线的行方向和列方向同时反转（等效于 180 度对角反射），然后从墙壁格沿新方向继续。此步计入步数
   - 若目标格超出网格边界：翻转垂直于该边界的轴分量（碰到左右边界则翻转列方向，碰到上下边界则翻转行方向），射线颜色不变，从边界内最后一格沿新方向继续。此步不计入步数（边界反弹为免费步）
   - 若目标格为背景(0)或已被射线涂色的格：将该格涂为射线当前颜色，计入步数
4. 当本阶段累计步数达到上限时，阶段结束。射线保持当前位置、方向和颜色，进入下一阶段（步数上限 = 下一个字形面积）
5. 重复步骤 3-4 直到所有字形阶段耗尽，射线停止
6. 输出为涂色后的完整网格（含起始像素、墙壁像素、射线轨迹，字形图案所在区域保持不变）

**关键洞察**：字形面积不编码方向（方向完全由墙壁和边界的反弹物理决定），只编码每个阶段的行进预算。因此同一组字形在不同墙壁布局下产生完全不同的路径——字形序列与空间几何构成不可分离的双重约束。

## 新题 2：稀疏度选形与对角残差填色

**组合逻辑**：[计数 + 选择/最少标记数](已有) + [填充/逐行跨度填充](已有) + [对角线同余](创新：轮廓总数决定对角周期长度，轮廓颜色序列决定残差-颜色映射)

**来源原语**：裁剪/选择/最少标记数（#2 7bb29440）、填充/轮廓线/封闭区域/行内边界配对/逐行跨度填充（#13 22168020）、对角线同余/对角周期补缺失（#4 c3f564a4）、计数（#5 b91ae062）

**依赖链**：统计每个轮廓内标记数 → 选择标记最少的轮廓 → 统计轮廓总数 K 得对角周期长度 → 按阅读顺序排列 K 个轮廓颜色得颜色序列 → 对选中轮廓的每个内部格按 (row+col) mod K 分配颜色 → 行跨度填充

统计各轮廓内标记像素数量，选择最稀疏的轮廓，用所有轮廓颜色按对角残差周期填充该轮廓。

**输入结构**：
- 约 15x15 黑(0)背景网格
- 3-4 个单色轮廓形状，每个轮廓使用不同的前景色（如蓝(1)、绿(3)、黄(4)、品红(6)中的若干种）。每个轮廓在其覆盖的每一行上恰好有两个同色像素，标记该行区间的左右边界（左右边界之间为轮廓内部）
- 轮廓形状互不重叠、互不相邻（边界框之间至少间隔 1 格）
- 每个轮廓的内部区域散布 0 个或多个灰(5)标记像素。不同轮廓内的标记数量互不相同（无并列），且至少有一个轮廓内标记数为 0
- 轮廓覆盖的行数在 4-8 之间，宽度（同一行左右边界距离）在 3-7 之间
- 生成约束：恰好一个轮廓的标记数严格最少；标记像素不在轮廓边界上（只在内部）

**规则**：
1. 对每个轮廓形状，逐行扫描其内部（左右边界之间），统计灰(5)标记像素的数量
2. 选择标记数最少的那个轮廓作为目标
3. 统计网格中轮廓的总数 K（即不同轮廓色的数量）
4. 按阅读顺序（比较每个轮廓最上方边界像素所在行，行相同时比较最左侧边界像素所在列；行小者优先，行同则列小者优先）排列所有轮廓，取其颜色组成长度为 K 的颜色序列 C = [C_0, C_1, ..., C_{K-1}]
5. 对目标轮廓的每个内部格 (r, c)（严格位于该行左右边界之间的格子），计算对角残差 d = (r + c) mod K，将该格涂为 C[d]
6. 目标轮廓的边界像素保持原色不变；目标轮廓内部原有的灰(5)标记像素被对角填充覆盖
7. 非目标轮廓及其内部所有内容（含标记像素）保持不变

**关键洞察**：轮廓总数 K 同时扮演两个角色——它是选择池的大小（决定"哪个最稀疏"），也是对角周期的长度（决定填充条纹的粗细和颜色循环）。增减一个轮廓会同时改变被选中的目标和目标内部的条纹图案。

## 新题 3：镜像噪声度编码滑动距离

**组合逻辑**：[镜像](已有) + [逐像素比较/异或差异判定](已有) + [计数](已有) + [滑动](创新：差异格数直接编码滑动步数) —— 非线性依赖：镜像产生参考基准，比较产生差异量，差异量反馈为几何操作参数

**来源原语**：镜像/跨轴反射（#6 88207623）、逐像素比较/差异标记/异或差异判定/分隔列/面板对齐（#19 34b99a2b）、计数（#5 b91ae062, #18 ff28f65a）、滑动/擦除（#12 d255d7a7, #20 7d7772cc）

**依赖链**：左面板镜像 → 与实际右面板逐像素比较 → 计数差异格数 D → D 作为左面板所有对象的水平滑动距离 → 输出仅含滑动后的左面板

将左面板水平镜像后与实际右面板比较，差异像素数即为左面板对象的整体滑动距离。

**输入结构**：
- 约 12x10 网格（偶数宽度，如 12 列），中央有一条全高灰(5)分隔列（第 6 列，0-indexed 第 5 列），将网格分为等宽的左面板（5 列）和右面板（5 列）
- 左面板：黑(0)背景上有 2-3 个小型单色前景对象（4-连通，3-6 像素），颜色各不相同（如蓝(1)、红(2)、绿(3)），对象互不相邻，且每个对象的所有像素距分隔列至少 3 格
- 右面板：黑(0)背景上有与左面板数量相同的前景对象，颜色与左面板一一对应。每个右面板对象近似为对应左面板对象的水平镜像（以分隔列为轴），但有 1-3 个像素位置存在偏差（某些像素缺失或多出）
- 生成约束：(a) 差异格数 D（镜像后的比较不一致格数）在 1-4 范围内；(b) 左面板对象距分隔列的最小距离 > D，保证滑动后不越过分隔列也不与分隔列重叠；(c) 滑动后各对象互不重叠

**规则**：
1. 将左面板以分隔列为轴做水平镜像，生成"理想右面板"（左面板第 i 列映射为右面板第 (面板宽度-1-i) 列）
2. 将理想右面板与实际右面板逐格比较：统计所有"至少一侧为非背景色且两侧颜色不同"的格子数量，记为 D
3. 在左面板中，将每个前景对象整体向右（朝分隔列方向）平移 D 格。对象原位置擦除为黑(0)背景
4. 输出：仅保留左面板（宽度 = 左面板宽度），移除分隔列和右面板。输出网格高度不变，宽度为原左面板宽度

**关键洞察**：右面板不是答案的组成部分，而是一个带有可控噪声的参考镜像。噪声的精确程度（差异格数 D）编码了左面板对象的滑动距离——求解者必须先做镜像比较才能知道该滑多远。

## 新题 4：引导线交叉定裁剪区，精灵色数定放大率

**组合逻辑**：[射线延伸 + 行列交叉 + 异源交叉特殊着色](已有) → [裁剪 + 选择](创新：交叉点定义裁剪矩形，精灵体数量最多的区域被选中) → [计数 + 像素放大/前景色数定倍率](创新：区域内精灵体的颜色多样性决定放大倍率)

**来源原语**：射线延伸/标记像素/十字引导线/行列交叉/异源交叉特殊着色（#1 45bbe264）、裁剪/选择/最少标记数（#2 7bb29440，此处反转为最多）、像素放大/计数/前景色数定倍率（#5 b91ae062）、精灵体/包含（#7 8a004b2b）

**依赖链**：标记像素行列延伸 → 不同标记交叉处标红 → 红色交叉点构成矩形角点 → 选择包含最多精灵体的矩形 → 统计区域内精灵体的不同前景色数量 → 以此为倍率放大区域内容

将标记像素的行列引导线交叉点作为矩形裁剪区的角点，选出精灵体最多的矩形，按区域内精灵体颜色多样性放大输出。

**输入结构**：
- 约 20x20 黑(0)背景网格
- 3 个标记像素，颜色各不相同且非黑非红（如蓝(1)、绿(3)、黄(4)），分别位于不同行不同列
- 网格内散布 4-6 个小型多色精灵体（4-连通，3-7 像素），每个精灵体使用一种非黑非红的前景色（精灵体之间可同色），精灵体互不相邻，且不与标记像素同行或同列
- 生成约束：(a) 3 个标记的行列延伸线产生恰好 3 个两两交叉点（C(3,2)=3），这 3 个交叉点不能构成矩形（3 个点最多 1 个矩形需要 4 个角点，所以至少一对标记共享行或列才能凑成矩形——实际上 3 个标记可在 3 行 3 列上产生的交叉点中选取 4 个点构成矩形仅当存在恰好 2 行 2 列被占用时成立）。修正：需要至少 4 个交叉点形成矩形，故要求标记行列延伸产生的交叉点中存在共享两行两列的 4 个点。实际上 3 个标记在 3 个不同行和 3 个不同列上，共产生 C(3,2)=3 个交叉点，位于 (r_A, c_B)、(r_A, c_C)、(r_B, c_C) 等位置——从中可找到若干矩形（4 个交叉点共享 2 行 2 列）。但 3 个标记只产生 3 个交叉行列对，交叉点为所有 (r_i, c_j) 其中 i!=j，共 3x3-3=6 个交叉点；(b) 至少两个由交叉点构成的矩形区域各含至少一个精灵体，且各矩形包含的精灵体数量互不相同（无并列）；(c) 精灵体不位于标记的行或列上

**规则**：
1. 对每个标记像素，将其所在整行和整列涂为该标记的颜色。不同标记的引导线重叠时后绘制的覆盖先绘制的（按标记的阅读顺序——行小优先，行同则列小优先）。标记像素本身保持原色
2. 不同标记的引导线相交的格子（即该格的行属于标记 A、列属于标记 B，且 A != B）涂为红(2)
3. 从所有红(2)交叉点中，找出所有可构成轴对齐矩形的四元组（即四个交叉点恰好共享两个行坐标和两个列坐标）
4. 对每个候选矩形，统计其内部（严格在四角之间，不含边界行列）在**步骤 1 之前**就已存在的精灵体的数量（精灵体的任何像素落入区域内部即计为包含该精灵体）
5. 选择包含精灵体数量最多的矩形。若并列则选面积最小的
6. 在选中矩形的内部，统计所包含精灵体使用的不同前景色数量 S（S >= 1）
7. 输出：将选中矩形内部区域（不含边界行列上的引导线）以 S 倍像素放大（每个格变为 SxS 块），仅保留原始精灵体像素和背景，引导线不出现在输出中

**关键洞察**：引导线交叉不是最终输出（与参考题 #1 不同），而是一种几何构造，用于划定候选裁剪区域。区域内精灵体的颜色多样性同时决定放大倍率——多色精灵体群产生高倍放大，单色群仅 1 倍（即原样输出）。标记位置、精灵体位置、精灵体颜色三者共同且不可分地决定最终输出。

## 新题 5：颜色匹配驱动滑动，滑动结果与墙壁围合封闭区域

**组合逻辑**：[逐像素比较/对齐比较 + 颜色匹配定去向](已有) + [滑动 + 擦除](已有) + [填充/封闭区域](创新：滑动后的像素位置与预设墙壁共同界定填充区域) —— 同时约束：匹配关系决定空间布局，空间布局与几何障碍共同决定填充结果

**来源原语**：滑动/擦除/分隔线/参考像素/源像素/对齐比较/颜色匹配定去向（#20 7d7772cc）、填充/封闭区域/轮廓线（#13 22168020）、墙壁像素（#10 142ca369）

**依赖链**：逐列比较源像素与参考像素颜色 → 匹配者向分隔行滑动、不匹配者向远端滑动 → 滑动后像素的新位置与墙壁像素共同判定是否围成封闭区域 → 封闭区域被填充

比较源像素与参考像素，匹配者滑向分隔行、不匹配者滑向远端，滑动结果与墙壁围合的封闭区域被填充。

**输入结构**：
- 约 12x15 网格，一条全宽橙(7)分隔行将网格分为上面板和下面板（分隔行位于约 1/3 高度处，上面板较窄）
- 上面板（参考侧）：黑(0)背景，紧邻分隔行上方的一行排列着 4-6 个参考像素，每个占一列，颜色使用蓝(1)、红(2)、绿(3)、黄(4)中的若干种（可重复），其余格为背景
- 下面板（源侧）：黑(0)背景。在远离分隔行的某一行（下面板倒数第 2-3 行）排列着与参考像素列对齐的源像素，每列最多一个，颜色同样使用蓝(1)、红(2)、绿(3)、黄(4)。下面板中还散布若干灰(5)墙壁像素，形成不完全的水平或垂直短线段（2-4 格长），线段有缺口
- 生成约束：(a) 每个源像素恰好有一个列对齐的参考像素；(b) 墙壁像素不与源像素或参考像素同列；(c) 至少有一个源像素与参考像素颜色匹配、至少有一个不匹配；(d) 匹配的源像素滑到分隔行下方后，其位置与墙壁像素共同围成至少一个 4-连通封闭背景区域（区域内所有格均为背景色，且被非背景格完全包围——包围者可以是墙壁像素、滑动后的源像素、或分隔行像素）

**规则**：
1. 逐列比较：对每个源像素，找到同列的参考像素，比较两者颜色
2. 若颜色相同（匹配）：将该源像素向上滑动到紧邻分隔行下方的第一个背景格（即分隔行正下方一行的对应列）
3. 若颜色不同（不匹配）：将该源像素向下滑动到下面板最底行的对应列
4. 擦除每个源像素的原始位置为黑(0)
5. 滑动完成后，在下面板中识别所有 4-连通封闭背景区域：一个区域是封闭的，当且仅当其所有 4-邻域边界格都是非背景色（灰(5)墙壁、源像素、或橙(7)分隔行）
6. 将每个封闭背景区域的所有格涂为红(2)
7. 保留分隔行、参考像素、墙壁像素、源像素（在新位置）和上面板的其他内容不变

**关键洞察**：颜色匹配规则决定了哪些源像素靠近分隔行、哪些远离，而这种空间分布与预设墙壁的几何关系决定了封闭区域的形成。单独看匹配规则或墙壁结构都无法预知最终的红色填充图案——两者必须联合求解。

## 新题 7：方向编码方块构建迷宫，单调路径填充

**组合逻辑**：[方向编码/色块决定输出位置 + 滑动](已有) → [路径填充/最短路径并集](创新：滑动后的方块布局构成路径搜索的障碍物，门洞方块提供起终点) —— 操作 A（滑动）的输出成为操作 B（路径搜索）的输入约束

**来源原语**：滑动/精灵体/着色标记/方向编码/色块决定输出位置（#8 a8c38be5）、路径填充/门框/走廊路径/门洞朝向/最短路径并集（#17 692cd3b6）

**依赖链**：每个方块内的彩色像素位置 → 解码为滑动方向 → 方块滑动到网格边缘 → 滑动后的方块布局形成迷宫墙壁 → 门洞方块的缺口位置确定路径端点 → 在墙壁布局中搜索所有单调最短路径的并集 → 并集涂色

将编码了方向的小方块滑动到网格边缘构建墙壁，然后在墙壁之间的空间中填充两个门洞之间所有单调最短路径的并集。

**输入结构**：
- 约 15x15 黑(0)背景网格
- 5-7 个灰(5)的 3x3 方块散布在网格中（方块间至少间隔 1 格），包括：
  - 1 个全灰方块（9 个像素全为灰(5)）——空白块，不参与后续操作
  - 2 个门洞方块：3x3 区域中恰好 1 个格为黑(0)背景（其余 8 个格为灰(5)），黑格位于方块的边缘位置（非角落），形成"门洞"。每个门洞方块内还有 1 个彩色像素（非灰非黑）位于方块边缘，指示滑动方向
  - 其余 2-4 个普通方块：3x3 全灰(5)区域内有 1-2 个彩色像素（非灰非黑）位于方块边缘，指示滑动方向
- 彩色方向像素的编码规则：像素位于方块上边缘（第 0 行中间列或相邻列）→ 向上；下边缘 → 向下；左边缘 → 向左；右边缘 → 向右。若有两个彩色像素，它们指示同一方向
- 生成约束：(a) 所有方块（含空白块）在网格中不重叠不相邻；(b) 滑动到边缘后方块不重叠（不同方块滑向不同边缘位置）；(c) 两个门洞方块滑动后门洞朝向网格内部（门洞缺口面向非边缘方向）；(d) 滑动后的布局中两个门洞的外侧格（门洞缺口相邻的网格内部背景格）之间存在至少一条可行的单调路径

**规则**：
1. 识别并忽略全灰空白块
2. 对每个其余方块（含门洞方块），根据其内部彩色像素的位置解码滑动方向
3. 将每个方块整体沿其编码方向滑动，直到方块的边缘接触网格边界。方块内部的彩色像素在滑动后保持相对位置不变
4. 滑动后，所有灰(5)像素构成墙壁（阻挡物）。定位两个门洞方块的门洞缺口（黑(0)格），以及每个缺口朝向网格内部一侧的相邻背景格（"外侧格"）
5. 在两个外侧格之间，计算所有单调最短路径的并集：每一步只允许向缩短两个外侧格之间曼哈顿距离的方向移动（即每步行或列坐标严格单调趋向目标），且不可穿越灰(5)墙壁像素
6. 将路径并集经过的所有背景格（含两个门洞缺口格本身）涂为黄(4)
7. 方块内的彩色方向像素、灰(5)墙壁像素均保持不变

**关键洞察**：方向编码决定了迷宫的空间布局（哪些位置有墙），空间布局决定了路径的可行性和形状。这两个独立的逻辑系统——方向解码与路径搜索——通过墙壁几何紧密耦合：改变任一方块的方向编码会改变墙壁位置，进而改变可行路径。

## 新题 8：双箭头射线互阻形成轮廓，逐行配对填充

**组合逻辑**：[射线延伸/反弹 + 碰撞停止](创新：两条射线以对方轨迹为终止条件，互相阻断) + [填充/行内边界配对/逐行跨度填充](创新：射线轨迹像素充当轮廓边界，行内恰好两个轨迹像素时触发填充) —— 互作用结构：A 的轨迹阻断 B，B 的轨迹阻断 A；两者的组合轨迹又构成第三种结构（轮廓）

**来源原语**：射线延伸/反弹/箭头精灵体/墙壁像素/碰撞停止/颜色继承（#10 142ca369）、填充/轮廓线/封闭区域/行内边界配对/逐行跨度填充（#13 22168020）

**依赖链**：两个箭头各自射出对角射线 → 射线碰墙壁反弹并继承颜色 → 射线碰到对方已涂色格时停止 → 两条射线的停止位置互相依赖（先到者决定后到者的边界） → 停止后逐行扫描：行内恰好两个射线涂色格构成边界对 → 边界对之间填充

两支箭头射出对角射线，射线碰到对方轨迹即停止；停止后逐行寻找恰好有两个射线涂色格的行，对其间区域做行跨度填充。

**输入结构**：
- 约 15x15 黑(0)背景网格
- 2 个 L 形箭头精灵体（每个为 2x2 包围盒中缺一角的 3 像素 L 形），颜色不同（如蓝(1)和绿(3)），位于网格的不同区域（距离至少 5 格），缺角方向指向网格内部
- 网格内散布 2-4 个墙壁像素，颜色各不相同（使用黄(4)、品红(6)、橙(7)等，不使用蓝(1)、绿(3)、红(2)），墙壁像素不与箭头相邻
- 生成约束：(a) 两支箭头射出的射线最终会相遇（一条射线会碰到另一条的已涂色轨迹）；(b) 射线停止后，存在若干连续行，每行恰好有两个射线涂色格（来自同一条或不同条射线均可）；(c) 两条射线不会同时到达同一格（存在先后顺序——按箭头的阅读顺序决定哪条射线先行进：行坐标小者优先，行同则列小者优先）

**规则**：
1. 确定两个箭头的行进顺序：比较两个箭头最上方最左侧像素的坐标，阅读顺序靠前的箭头为"先行者"
2. 先行者的箭头从其缺角方向射出对角射线，射线初始颜色为箭头颜色。逐格行进：
   - 目标格为墙壁像素：两轴方向同时反转，射线采纳墙壁颜色，墙壁格被重涂为射线新颜色。继续行进
   - 目标格超出网格边界：射线停止（边界即终点，不反弹）
   - 目标格为背景(0)：涂为射线当前颜色，继续行进
   - 目标格为另一条射线已涂色的格：射线停止（不重涂该格）
3. 后行者的箭头以相同规则射出射线。在后行者行进时，先行者的轨迹已存在于网格上，可能阻断后行者
4. 两条射线都停止后，逐行扫描整个网格（从第 0 行到最后一行）：
   - 若某行恰好有 2 个被射线涂色的格（颜色可以不同），将这两格之间（不含两端）的所有背景(0)格涂为红(2)
   - 若某行有 0 个、1 个、或 3 个及以上射线涂色格，该行不做填充
5. 保留箭头精灵体、射线轨迹（含被颜色继承改变的格）的颜色不变

**关键洞察**：两条射线的路径存在因果不对称——先行者不受后行者影响，但后行者可能被先行者轨迹阻断。这种不对称决定了射线的最终几何形状，进而决定哪些行满足"恰好两个涂色格"的填充条件。射线追踪与行跨度填充通过几何拓扑紧密耦合：修改任何一个墙壁的位置会连锁改变射线路径、阻断点、以及最终填充的行。

## 新题 9：对角周期补全揭示轨迹色，驱动条件性边缘迁移

**组合逻辑**：[补全/对角周期图案/对角线同余/对角周期补缺失](已有) + [平移/擦除/标记指示活跃边/含轨迹色行列移动](创新：补全操作的结果改变了哪些行含有轨迹色，从而改变迁移操作的目标行集合) —— 信息依赖：必须先补全才能知道哪些行参与迁移

**来源原语**：补全/对角周期图案/对角线同余/对角周期补缺失（#4 c3f564a4）、平移/擦除/边缘带/标记像素/标记指示活跃边/含轨迹色行列移动（#12 d255d7a7）

**依赖链**：边缘带中可见像素 → 推断对角周期（周期长度和残差-颜色映射） → 补全边缘带中的缺失格 → 补全后某些行的边缘带切片中出现了轨迹色（补全前这些行的轨迹色像素恰好在缺失格中） → 含轨迹色的行将其边缘带切片迁移到对边

补全边缘带中不完整的对角周期图案，补全后才能确定哪些行含有轨迹色，含轨迹色的行将边缘带切片迁移到对边。

**输入结构**：
- 约 12x12 黑(0)背景网格
- 沿网格左边缘有一条宽 2 列的边缘带（第 0-1 列），边缘带中包含若干非黑前景色像素，形成不完整的对角周期图案：可见像素遵循 (row + col) mod K 的颜色映射规则，但部分格为黑(0)（缺失）
- 对角周期使用 K 种颜色（K = 2 或 3），颜色从蓝(1)、绿(3)、黄(4)、品红(6)中选取。其中一种颜色被指定为"轨迹色"（如橙(7)）——轨迹色是周期中的一种颜色
- 在边缘带的第 0 列中，有 1-2 个栗(9)标记像素，标识左边缘为"活跃边"。标记像素不参与对角周期（其位置的对角残差由周期规则确定，但被标记像素覆盖）
- 边缘带之外（第 2-11 列）为纯黑背景，无其他元素
- 生成约束：(a) 边缘带中可见的非黑非栗像素足以唯一确定周期长度 K 和残差-颜色映射；(b) 至少有 2 个缺失格在补全后会被填入轨迹色（即这些格的对角残差对应轨迹色，但当前为黑(0)）；(c) 至少有 1 行的边缘带切片在补全前不含轨迹色、补全后才含有轨迹色（即该行的轨迹色像素全部位于缺失格中）

**规则**：
1. 识别活跃边：栗(9)标记像素所在的边缘即为活跃边（本题中为左边缘）
2. 分析边缘带中所有非黑(0)非栗(9)的可见像素，推断对角周期：确定周期长度 K，并为每个残差类 (row + col) mod K 确定对应颜色
3. 补全边缘带中所有黑(0)缺失格（不含栗(9)标记像素所在格）：将每个缺失格 (r, c) 涂为其残差类 (r + c) mod K 对应的颜色
4. 补全后，逐行检查每行的边缘带切片（第 0-1 列的两个格）：
   - 若该行的边缘带切片包含至少一个轨迹色像素（忽略栗(9)标记像素），则该行"活跃"
   - 若不含轨迹色像素，则该行"不活跃"
5. 对每个活跃行，将其边缘带切片（第 0-1 列）的内容复制到对边（右边缘，第 10-11 列），保持行坐标不变、列顺序不变（第 0 列内容到第 10 列，第 1 列内容到第 11 列）。然后将活跃行原边缘带切片中的非栗(9)格擦除为黑(0)
6. 不活跃行的边缘带切片保留在原位不变
7. 栗(9)标记像素始终保留在原位（即使其所在行为活跃行，标记像素也不擦除，但其内容会被复制到对边）

**关键洞察**：补全操作不仅修复了图案的视觉完整性，更揭示了隐藏的轨迹色信息——某些行的轨迹色像素恰好落在缺失格中，只有补全后才能判定这些行是否参与边缘迁移。补全与迁移之间存在信息依赖而非简单顺序：跳过补全直接迁移会遗漏应参与的行。
