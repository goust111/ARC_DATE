## 新题 1：标记投票决定镜像方向后填充封闭域

**组合逻辑**：[投票/counting](创新：由标记密度决定对称源侧，替代单一控制标记) + [对称补全/symmetric_completion] + [洪泛填充/flood_fill](创新：同一批标记复用为填充色源)

**来源原语**：投票/counting(de1cd16c), 对称补全/symmetric_completion(5b692c0f), 洪泛填充/flood_fill(4b6b68e5), 标记像素/marker_pixel(de1cd16c/4b6b68e5), 对称轴/symmetry_axis(5b692c0f), 轮廓框/outline_frame(4b6b68e5), 多数色决定填充/majority_color_fill(4b6b68e5)

**依赖链**：标记像素的空间分布决定镜像方向（投票 -> 对称补全），对称补全改变了轮廓框的拓扑结构（可能创建新的封闭区域），而填充色又来源于该区域内的标记像素密度（对称补全 -> 洪泛填充）。三步之间标记像素承担双重角色且互相不可跳过。

在黑(0)背景上，多个单色轮廓框各自被一条黄(4)轴线一分为二；投票决定哪侧可信并镜像补全，再用区域内多数标记色洪泛填充封闭域。

**输入结构**：约 18x18 的黑(0)背景网格。包含 2~3 个互不重叠的单色 4-连通轮廓框（每个轮廓框使用不同颜色，如蓝(1)、绿(3)、品红(6)；每个轮廓框由 8~15 个像素组成，形态为不规则的开环或半封闭形状）。每个轮廓框的边界框内有一条连续的黄(4)水平或竖直直线段将该框一分为二（轴线与轮廓框像素不重叠，长度等于框的边界框在该方向上的跨度）。轴线两侧各有 2~5 个散布的单像素标记点，标记颜色为红(2)或橙(7)（同一框内两种标记色都存在）。不同示例中，轴线方向可变（有的水平、有的竖直），每个框内两侧标记数不等。生成约束：每个框恰好有一侧标记数严格多于另一侧；镜像补全后至少产生一个封闭背景区域。

**规则**：
1. 对每个轮廓框，定位其内部的黄(4)轴线，将框的边界框区域沿轴线分为两半。
2. 统计轴线每一侧的标记像素（红(2)和橙(7)）总数。标记数较多的一侧为"可信源侧"。
3. 将源侧的全部内容（轮廓框像素、标记像素、背景像素）沿轴线做轴对称反射，覆盖到另一侧。轴线本身保留为黄(4)。源侧内容不变。
4. 镜像完成后，对每个轮廓框，寻找其边界框内部无法经由背景像素（不穿过轮廓框像素或轴线像素）到达边界框边缘的 4-连通背景区域——即封闭区域。
5. 对每个封闭区域，统计区域内红(2)和橙(7)标记像素的数量，取多数色（保证不平局）。用该多数色洪泛填充整个封闭区域（覆盖区域内原有的背景和标记像素）。
6. 封闭区域外的标记像素保留不变。

**关键洞察**：标记像素承担双重功能——先作为投票票据决定镜像方向，镜像完成后又作为颜色信号决定填充色。镜像操作会复制一部分标记到对侧，改变封闭区域内的标记分布，因此填充色无法在镜像之前确定。

## 新题 2：偏移弯折连线与碰撞过滤

**组合逻辑**：[连线/connect] + [逐步偏移/step_deflection](创新：偏移作用于锚点间连线路径而非边缘起点流) + [筛选/filtering](创新：偏移路径的合法性决定连线是否成立)

**来源原语**：连线/connect(60a26a3e), 逐步偏移/step_deflection(f15e1fac), 筛选/filtering(29623171), 空心十字标记/hollow_plus_marker(60a26a3e), 偏移控制像素/deflector_pixel(f15e1fac), 仅相邻锚点间连接/connect_only_between_adjacent_anchors(60a26a3e)

**依赖链**：偏移像素使连线路径弯折（偏移 -> 连线形态），弯折后的路径可能越界或撞到其他锚点/偏移像素（连线形态 -> 筛选条件），仅合法路径被绘制。偏移的空间布局同时决定路径形状和路径合法性，无法分离处理。

在黑(0)背景上，红(2)空心十字标记间需连线，但绿(3)偏移像素使连线路径逐步弯折；弯折后若路径越界或碰撞则该连线取消。

**输入结构**：约 15x20 的黑(0)背景网格。分布有 3~5 个红(2)空心十字标记（每个标记为 3x3 区域中仅保留上下左右四个臂像素，中心为背景色的 4 像素十字形）。网格左侧边缘上分布有 2~4 个绿(3)单像素（偏移控制像素），各占不同行。标记中心之间可能共享行或列。不同示例中标记数量和位置变化，绿像素的行位置也变化。生成约束：至少一对标记共享同一行且之间无其他标记遮挡（在无偏移条件下可直接连接）；至少一条连线在偏移后变得不合法（越出网格边界或撞上另一个标记）。

**规则**：
1. 计算每个红(2)空心十字标记的中心坐标（3x3 边界框中心的那个背景像素位置）。
2. 对共享同一行的标记中心，按列坐标从左到右排序，仅对相邻对尝试连线；对共享同一列的标记中心，按行坐标从上到下排序，仅对相邻对尝试连线。
3. 对每条候选连线，从一端锚点的外臂出发，沿行方向（水平连线）或列方向（竖直连线）逐像素绘制路径。每当路径推进到一个新行/新列时，检查该行/列是否有绿(3)偏移像素：若有，路径在该步额外平移一个像素（水平连线时向下偏移一行，竖直连线时向右偏移一列）。
4. 合法性检查：若偏移后路径上的任一像素落在网格外，或落在另一个红(2)标记像素上，或落在绿(3)偏移像素上，则该连线不合法，不绘制。
5. 对所有合法连线，将路径像素涂为蓝(1)。原有红(2)标记和绿(3)偏移像素保留不变。

**关键洞察**：偏移像素不仅弯折路径形状，还通过弯折的副作用决定哪些连线在几何上可行。必须逐步追踪每条路径才能判断其合法性——无法从锚点间的距离或偏移像素数量直接推断结果。

## 新题 3：重力堆叠后按内部重叠度选取并裁剪

**组合逻辑**：[堆叠/滑动/stack+slide](已有) + [裁剪/crop](创新：裁剪目标由堆叠后的空间关系决定) + [计数/比较/counting+compare](创新：比较堆叠后重叠像素数以选取裁剪目标)

**来源原语**：堆叠/stack(ac2e8ecf), 滑动/slide(ac2e8ecf), 裁剪/crop(1a6449f1), 比较/compare(445eab21), 封闭对象/closed_object(ac2e8ecf), 开放对象/open_object(ac2e8ecf), 封闭孔洞/enclosed_hole(ac2e8ecf), 内部区域/interior_region(1a6449f1), 面积比较/area_comparison(445eab21)

**依赖链**：重力堆叠改变了所有对象的纵向位置（堆叠 -> 新空间布局），新布局中封闭框内部可能叠入了开放精灵体（堆叠 -> 重叠关系出现），计数每个框内部重叠的精灵像素数以选出目标框（计数/比较 -> 裁剪目标确定），最后裁剪该框内部。三步的因果关系严格链式且不可跳步。

黑(0)背景上若干空心矩形框向上堆叠、开放精灵体向下堆叠；堆叠后统计每个框内部叠入了多少精灵像素，取最多者裁剪输出其内部。

**输入结构**：约 20x15 的黑(0)背景网格。包含 2~3 个不同颜色的单色空心矩形框（如蓝(1)、绿(3)、品红(6)；每个框一像素厚，宽 4~7 列、高 3~5 行，内部为背景色，构成封闭孔洞），以及 3~5 个不同颜色的小型开放精灵体（如红(2)、橙(7)、灰(5)；每个精灵体为 3~6 像素的 4-连通不规则形状，无封闭孔洞）。所有对象在输入中互不重叠，纵向分散。不同示例中对象的水平位置和形状变化，使得堆叠后哪个框内叠入最多精灵像素的结果不同。生成约束：堆叠后至少两个框的内部各有不同数量的精灵像素进入（保证不平局）；堆叠不产生跨对象碰撞冲突（列范围互不冲突的对象可独立堆叠）。

**规则**：
1. 分类所有前景对象：边界框内包含至少一个 4-连通封闭背景区域（孔洞）的对象为"封闭对象"，其余为"开放对象"。
2. 封闭对象保持水平位置不变，向上滑动直到碰到网格顶边或另一个已放置的封闭对象（按原始纵向位置从上到下依次处理，先处理更靠上的）。
3. 开放对象保持水平位置不变，向下滑动直到碰到网格底边或另一个已放置的开放对象（按原始纵向位置从下到上依次处理，先处理更靠下的）。
4. 在堆叠完成的网格上，对每个封闭对象，统计其边界框严格内部区域（去掉一像素厚边框后的矩形）中有多少像素属于某个开放对象。
5. 选择内部重叠精灵像素最多的那个封闭对象。输出该封闭对象边界框严格内部区域的内容（裁剪掉边框），保留其中所有颜色（含精灵体像素和背景像素）。

**关键洞察**：输入中框与精灵体互不重叠，必须先完成重力堆叠才会出现"精灵体落入框内"的空间关系。选择裁剪哪个框完全取决于堆叠后的几何重叠结果，无法从输入直接判断。

## 新题 4：对角扩散创建对接槽位

**组合逻辑**：[仅对角邻接重涂/diagonal_only_adj recolor](创新：扩散像素不只是装饰，而是构造对接几何) + [对接/dock](创新：对接目标由前一步动态生成) + [轨迹涂黑/trail_painted_black]

**来源原语**：仅对角邻接/diagonal_only_adj(396d80d7), 重涂色/recolor(396d80d7), 对接/dock(8b9c3697), 射线投射/ray_cast(8b9c3697), 封闭框/enclosing_frame(396d80d7), 内层前景/inner_foreground(396d80d7), 可移动组件/movable_component(8b9c3697), 轨迹涂黑/trail_painted_black(8b9c3697)

**依赖链**：对角扩散在框的角点位置生成新的内层前景像素（扩散 -> 新像素出现），这些新像素如果恰好位于框边界上的缺口旁则构成"槽位"入口（扩散结果 -> 对接几何），然后从槽位向外射线投射寻找可移动组件并滑入（对接 -> 最终输出）。若跳过扩散步，框上不存在槽位，对接无从进行。

黑(0)背景上若干彩色封闭框含内层前景图案；对角扩散后在框角点产生新像素，这些像素定义了对接槽位方向，红(2)组件沿射线滑入槽位。

**输入结构**：约 18x18 的黑(0)背景网格。包含 2~3 个彩色封闭框（如蓝(1)、绿(3)框；每个框为矩形环形结构，宽和高各 5~8 像素，一像素厚边框，框上有 1~2 个单像素缺口）。每个框内部包含少量内层前景像素（与框不同色，如框为蓝(1)则内层前景为黄(4)），内层前景像素数量 2~4 个。框外空间中分布有 2~3 个红(2)小型组件（每个组件为 2~3 像素的 4-连通形状）。不同示例中框的缺口位置和内层前景像素位置变化，导致对角扩散产生的槽位方向不同。生成约束：每个框恰好有一个缺口方向经对角扩散后与某个红组件在同一行或同一列上对齐（保证至少一个有效对接）；射线路径上不存在其他前景像素遮挡。

**规则**：
1. 对每个封闭框，找到所有与该框颜色仅有对角邻接（四个正交方向均无该框颜色邻居）的背景(0)像素。将这些像素涂为该框的内层前景色。
2. 新涂的像素如果正好位于框边界缺口的对角位置，则该缺口的外侧正交方向定义了一个"槽位入口方向"（即从缺口出发向框外延伸的方向）。
3. 对每个槽位入口，从缺口位置沿入口方向向外投射射线。如果射线在碰到网格边界前遇到一个红(2)组件，则将该组件沿射线反方向滑入，直到组件的最前端像素到达缺口位置。
4. 组件滑动过程中经过的所有格子涂为黑(0)（轨迹涂黑）。组件最终位置显示为红(2)。
5. 未被任何射线命中的红(2)组件从画布上擦除（涂为黑(0)）。

**关键洞察**：对角扩散不是视觉装饰——它在框的角点处创建了新的前景像素，这些像素与框缺口的位置关系才定义了对接的方向和可行性。没有扩散步骤就没有槽位几何，对接无法启动。

## 新题 5：视线计数竞争筛选分区

**组合逻辑**：[射线延伸/ray_extend](创新：射线从标记出发，计数命中而非移动) + [计数/counting] + [筛选/filtering+洪泛填充/flood_fill](创新：视线命中总数决定分区存亡)

**来源原语**：射线延伸/ray_extend(e1d2900e), 视线对齐/sightline_align(e1d2900e), 计数/counting(1fad071e), 洪泛填充/flood_fill(29623171), 筛选/filtering(29623171), 实心方块/solid_block(e1d2900e), 标记像素/marker_pixel(e1d2900e), 分区区域/partitioned_region(29623171), 分隔线/separator_line(29623171), 最密区域保留填充/densest_region_kept_filled(29623171)

**依赖链**：标记与方块的相对位置决定视线命中数（空间布局 -> 计数结果），各分区的命中总数竞争（计数 -> 筛选），胜出分区被洪泛填充（筛选 -> 填充）。方块同时是视线目标和分区内容的一部分，移除任何一步都无法确定输出。

**组合逻辑**：[流动绘制/flow_draw + 逐步偏移/step_deflection](已有) + [投票/vote](创新：投票票据为路径穿越次数而非标记数量) + [洪泛填充/flood_fill + 筛选/filtering](创新：胜出分区由路径密度而非标记密度决定)

**依赖链**：偏移像素的位置决定流动路径的弯折轨迹（偏移 -> 路径几何），路径穿过不同分区时对各分区投票（路径几何 -> 投票计数），票数最多的分区被填充保留（投票 -> 筛选/填充）。偏移像素同时影响路径形状和路径穿越了哪些分区，两层效应耦合。

黑(0)背景被灰(5)线分区；青(8)像素从顶部边缘向下流动，红(2)像素在左侧边缘偏移流路径；统计每个分区被流路径穿越的次数，穿越最多的分区用橙(7)洪泛填充，其余清空。

**输入结构**：约 16x16 的黑(0)背景网格。灰(5)完整行和完整列将内部分为 2x2 或 2x3 共 4~6 个矩形分区。顶部边缘（第 0 行）上有 3~5 个青(8)单像素作为流动起点，分布在不同列。左侧边缘（第 0 列）上有 2~4 个红(2)单像素作为偏移控制，分布在不同行。每个分区内有 1~2 个橙(7)单像素标记（仅提供颜色信息）。不同示例中青像素和红像素的位置变化，导致路径弯折形态和穿越分区集合不同。生成约束：恰好一个分区被穿越的路径数严格最多（不平局）；每条路径至少穿越一个分区。

**规则**：
1. 确定流动方向：青(8)像素位于顶部边缘，流动方向为从上到下。红(2)像素位于左侧边缘，偏移方向为向右。
2. 对每个青(8)起点像素，从其位置开始逐行向下推进。每推进一行时，检查该行是否有红(2)偏移控制像素（在左侧边缘）：若有，路径在该行额外向右偏移一列。路径在碰到网格底边时终止。
3. 路径经过灰(5)分隔线时直接穿越（分隔线不阻挡路径），但路径像素不绘制在灰线上。
4. 对每个分区，统计有多少条不同的路径穿过了它（路径的任意一个像素落在该分区内即算穿过）。
5. 穿越路径数最多的分区为胜出分区。将该分区内的所有非灰像素涂为橙(7)（洪泛填充）。
6. 所有非胜出分区的内部清为黑(0)。
7. 灰(5)分隔线保持不变。所有流动路径不在最终输出中显示（仅用于计数）。青(8)起点和红(2)偏移像素在最终输出中保留。

**关键洞察**：红色偏移像素通过弯折流动路径，间接决定了哪些分区获得更多穿越票数。同一个偏移像素可能同时使某条路径偏离一个分区、偏入另一个分区——因此偏移像素的效果是全局性的、无法局部判断。必须追踪所有路径的完整轨迹才能确定投票结果。
