## 新题 1：孔洞计数定长射线

**组合逻辑**：[计数/counting](创新：计数结果不压缩为摘要行，而是作为空间操作的长度参数) + [射线延伸/ray_extension](已有) + [重涂色/recolor](已有)

**来源原语**：计数·封闭背景区域·顺序排列（参考题 8ba14f53）、射线延伸·等距标记点·等距共线·边界内延续（参考题 0b17323b）、重涂色（参考题 1c0d0a4b / 50cb2852）

**依赖链**：封闭区域的面积计数决定射线延伸的步数；标记三元组的间距和方向决定射线方向；颜色匹配将两套独立结构关联起来。删掉计数则射线长度无法确定；删掉标记三元组则射线方向未知；删掉颜色匹配则计数结果与射线无法配对。

将封闭区域内的背景像素数量作为参数，控制等距标记点定义的射线向前延伸多少步——孔洞面积在空间上远离射线，但通过颜色匹配隐式关联。

**输入结构**：约 15x15 网格，黑(0)背景。网格中有 2-3 个单色 4-连通前景对象（每个对象颜色不同，例如蓝(1)、绿(3)、黄(4)），每个对象的形状各异（3-8 像素的不规则连通体，不要求是矩形），但每个对象在其边界框内封闭了若干黑(0)像素（即对象像素包围了一个或多个黑色孔洞，孔洞像素不与边界框外的黑色背景 4-连通）。此外，网格中有 2-3 组等距共线标记三元组，每组由三个同色像素组成（颜色分别与某个前景对象一致），三像素等间距排列在一条直线上（可以是水平、垂直或对角方向）。各对象与标记三元组在空间上不重叠、互不相邻。生成约束：每个前景对象的孔洞面积在 1-5 之间；标记三元组的步长在 1-3 之间；射线延伸不会与任何前景对象或其他射线交叉。

**规则**：
1. 对每个前景对象，计算其边界框内被该对象像素完全包围（不与边界框外黑色背景 4-连通）的黑(0)像素总数，记为 K。
2. 对每组标记三元组，按行优先序排列三个像素，计算相邻像素之间的行列步进向量 (dr, dc)。
3. 通过颜色匹配将每组标记三元组关联到同色的前景对象，获取该对象的 K 值。
4. 从每组标记三元组的最后一个像素（行优先序最末）出发，沿 (dr, dc) 方向逐步绘制红(2)像素，共绘制 K 步。若某步超出网格边界则跳过该步（但继续计数后续步；若后续步回到界内则继续绘制——但在直线延伸场景下不会发生，故等价于提前终止）。
5. 原有前景对象和标记三元组保持不变。

**关键洞察**：射线的长度信息不在射线附近——它被编码在空间上完全分离的前景对象的孔洞结构中，求解者需先独立完成计数任务，再将结果作为参数注入射线延伸任务。

## 新题 2：倍增画布上的周期色带与墙壁可见性裁切

**组合逻辑**：[射线延伸·周期重复/periodic_repeat](创新：周期延伸到倍增画布) + [镜像/mirror](创新：墙壁镜像到四象限) + [擦除/erase](创新：由可达性判定触发擦除)

**来源原语**：对角色带·周期重复·画布倍增（参考题 cad67732）、镜像（参考题 0e206a2e / 2dee498d）、擦除（参考题 1e81d6f9）、墙壁障碍·可达性（参考题 dd6b8c4b）

**依赖链**：周期延伸在倍增画布上生成完整色带模式→墙壁镜像在四象限形成屏障→从原点出发的泛洪填充确定可达背景区域→不与可达区域相邻的色带像素被擦除。三个过程的输出在"可见性"这一新概念上汇合。

将输入的对角色带周期性延伸到倍增画布上，同时将输入中的墙壁镜像到四个象限形成屏障，然后仅保留从原点可见的色带像素——墙壁背后被遮挡的色带段被擦除。

**输入结构**：约 8x8 网格，黑(0)背景。网格中有一条沿某个对角方向排列的窄色带（由 1-2 个对角偏移量上的像素组成），色带内像素的颜色沿行方向呈周期性变化（例如周期为 2，交替使用蓝(1)和绿(3)），色带内不在这些对角偏移上的位置保持为背景色。此外，网格中散布 3-6 个品红(6)墙壁像素，不在色带上。生成约束：色带的行周期为 2 或 3；色带使用恰好两种前景色；墙壁像素不在网格角落；倍增画布上至少有一段色带被墙壁完全遮挡。

**规则**：
1. 确定色带的对角方向、偏移量集合、行周期和颜色序列（含带内的背景间隙）。若色带斜向左上/右下，先水平翻转使其规范化为右下方向。
2. 创建一个 2H x 2W 的黑(0)画布（H、W 为输入网格高、宽）。将色带的偏移/周期规则延伸到整个画布上，填充所有符合规则的像素。若步骤 1 做了翻转，完成后撤销翻转。
3. 将输入中的品红(6)墙壁像素复制到画布的四个象限中对应的镜像位置（左上象限为原始位置，右上象限水平镜像，左下象限垂直镜像，右下象限中心镜像），共最多 4 份。
4. 从画布位置 (0, 0) 开始，对所有非墙壁、非色带的背景像素做 4-连通泛洪填充，标记为"可达"。
5. 检查每个色带像素：若其 4-连通邻居中至少有一个被标记为"可达"，则保留该色带像素；否则将其擦除为黑(0)背景。
6. 墙壁像素保持品红(6)不变。

**关键洞察**：墙壁不阻止色带被绘制——它们阻止色带被"看见"。色带先完整生成，再根据从原点出发的背景连通性决定哪些段落存活，这是一种空间可达性驱动的后过滤。

## 新题 3：括号选色触发重力级联

**组合逻辑**：[擦除/erase](创新：擦除不是最终目标而是级联触发器) + [重力下落/gravity_drop](已有) + [碰撞停止/collision_stop](已有)

**来源原语**：擦除·角括号·标记像素·按标记色选择同色·保留标记本身（参考题 1e81d6f9）、重力下落·障碍物·碰撞停止·沿路径滑动（参考题 28a6681f）

**依赖链**：角括号内的标记色决定擦除目标→擦除移除了支撑结构→失去支撑的其他颜色像素在重力下落→障碍物决定最终停靠位置。擦除的对象选择与物理级联紧密耦合：擦除不同的颜色会产生完全不同的下落结果。

角括号内的标记像素指定一种颜色，该颜色的所有非标记像素被擦除；擦除导致原先被该颜色支撑的其他颜色像素失去支撑并在重力作用下坠落，直到碰到障碍物或网格底部。

**输入结构**：约 12x12 网格，黑(0)背景。网格中有若干像素簇，每簇由 3-6 个同色 4-连通像素组成，使用 2-3 种不同颜色（例如蓝(1)、绿(3)、黄(4)）。部分像素簇在垂直方向上相互堆叠（一个簇的像素直接在另一个簇的像素上方，形成支撑关系）。网格中有 2-4 个灰(5)像素作为固定障碍物（不受重力影响），分布在不同高度。网格右下角区域有一个由红(2)像素组成的 4-连通角括号（开口朝左上的直角形，宽高各 3 像素），括号内部（括号边界框内、非括号像素的位置）恰好有一个标记像素，其颜色与网格中某种像素簇颜色相同。生成约束：标记颜色的像素簇至少支撑着一个其他颜色的像素簇（即标记色像素的正上方有非标记色像素）；不同示例中标记颜色不同；擦除后下落的像素不会与角括号或障碍物的水平位置冲突。

**规则**：
1. 识别角括号（红(2)像素组成的直角形连通体）并定位其边界框内唯一的非括号、非背景标记像素，读取标记颜色 C。
2. 将网格中所有颜色为 C 的像素（标记像素本身除外）替换为黑(0)背景。
3. 擦除后，检查每个非背景、非障碍、非括号像素：若其正下方为背景且自身不在网格最底行，则该像素"悬空"。
4. 所有悬空像素同时开始下落：每个像素沿垂直方向逐格下移，直到正下方遇到非背景像素（另一个已稳定的像素、障碍物、括号像素）或到达网格底行时停止。处理顺序为从最底行的悬空像素开始向上逐行处理，确保下方像素先稳定。
5. 角括号、标记像素和灰(5)障碍物始终保持原位不变。

**关键洞察**：角括号不是在做颜色清理——它在选择性拆除支撑结构。被擦除的颜色本身不重要，重要的是它的移除如何改变其他颜色的物理平衡，触发一场由选色决定结果的重力级联。

## 新题 4：矩形内部提取为印章模板，标记计数定调色

**组合逻辑**：[内外分离·保留边框涂内部/interior_exterior_sep](创新：内部不是涂色目标而是模板提取源) + [印章覆盖/stamp_overlay](已有) + [计数·标记最多者选取/counting + rectangle_with_most_markers_selected](创新：计数选模板而非选裁剪对象)

**来源原语**：重涂色·前景矩形·矩形内部·内外分离·保留边框涂内部（参考题 50cb2852）、印章覆盖·同形精灵体·格点对齐（参考题 5b526a93）、计数·实心矩形·标记像素·包含·标记最多者选取（参考题 8efcae92）

**依赖链**：标记计数在多个矩形之间选出"模板源"→内部提取从该矩形获得印章模板→印章覆盖将模板复制到格点位置。计数结果决定提取哪个矩形的内部；提取内容决定印章图案；三者缺一不可。

多个有边框的矩形中，标记像素最多的矩形被选为模板源——提取其一像素内缩的内部图案，将该图案印章覆盖到网格中散布的精灵体位置上，替换原有精灵体。

**输入结构**：约 15x15 网格，黑(0)背景。网格中有 3-4 个实心矩形（每个至少 5x5），每个矩形由单一颜色的像素填充（颜色各不相同，例如蓝(1)、绿(3)、黄(4)、橙(7)），矩形之间不相邻。部分矩形的内部（去掉一像素宽边框后的区域）有若干红(2)标记像素替换了原色像素，形成不同的内部图案。各矩形内的红(2)标记数量不同（例如 1 个、3 个、2 个），且恰好有一个矩形的标记最多（无并列）。此外，网格中散布 2-4 个相同的小型青(8)精灵体（3-5 像素的 4-连通小图形，每个形状相同），它们的边界框尺寸与最多标记矩形的内部尺寸一致（即矩形宽-2 x 矩形高-2）。精灵体之间和与矩形之间互不相邻。生成约束：最多标记的矩形是唯一的；精灵体边界框尺寸与该矩形内部尺寸完全匹配；精灵体放置位置保证印章不超出网格边界。

**规则**：
1. 对每个矩形，计算其内部（去掉一像素宽度边框后的区域）中红(2)标记像素的数量。
2. 选择标记数量最多的矩形作为模板源矩形。
3. 提取模板源矩形的内部图案：将内部区域中的原色像素记为前景(用栗(9)表示)、红(2)标记像素记为红(2)、背景(若有)保持黑(0)。该内部图案即为印章模板。
4. 对网格中每个青(8)精灵体，将其边界框区域替换为印章模板——模板左上角对齐精灵体边界框左上角，逐像素覆盖。
5. 非模板源的矩形保持不变；模板源矩形本身也保持不变（仅提取内部图案，不修改）。

**关键洞察**：矩形的边框不是装饰——它是将矩形标识为"容器"的结构信号。标记像素在源题中用于选裁剪对象，在此处它们选择"哪个容器的内容值得复制"，将计数竞争与模板提取耦合成一个选拔机制。

## 新题 5：收缩楔形穿越障碍间隙的分支传播

**组合逻辑**：[填充·沿对角线传播/diagonal_propagate](创新：传播遇障碍不终止而是从间隙穿越并分裂) + [碰撞停止/collision_stop](创新：从完全阻断变为间隙过滤) + [逐行交换双色/row_swap_bicolor](已有，色带交替在分支间延续)

**来源原语**：填充·顶行色带·收缩楔形·沿对角线传播·逐行交换双色（参考题 b5bb5719）、重力下落·障碍物·碰撞停止（参考题 28a6681f）

**依赖链**：顶行色带启动楔形传播→障碍行的间隙位置决定楔形分裂方式→每个子楔形的宽度由间隙宽度决定→子楔形继续独立收缩并可能遇到下一行障碍再次分裂。障碍不消灭传播，而是过滤和分叉传播——这是源题中不存在的结构关系。

顶行色带向下传播为收缩楔形，遇到水平障碍条时不终止而是从障碍中的间隙穿过，在间隙下方生成更窄的子楔形，每个子楔形独立继续收缩，色带的红灰交替计数跨分支连续。

**输入结构**：约 15x15 网格，橙(7)背景。第 0 行有一段连续的交替红(2)/灰(5)像素（长度为奇数，5-11 像素），左右两端对称地位于行中央。第 0 行其余位置为橙(7)背景。在网格下方有 1-2 条水平障碍条（品红(6)像素组成的完整行，但每条障碍行中有 1-2 个间隙——即该行中有 1-2 段连续的橙(7)背景像素）。障碍条之间以及障碍条与顶行之间至少间隔 3 行。生成约束：每个间隙宽度至少 3 像素且为奇数；间隙水平范围完全在楔形到达该行时的有效宽度范围内；每个子楔形在到达下一障碍或网格底部前至少能收缩 2 行。

**规则**：
1. 初始楔形从第 0 行的红(2)/灰(5)色带开始。定义楔形的有效列范围为 [L, R]（色带首尾列），初始行计数器 r=0。
2. 对下方每一行 r+1：楔形有效列范围收缩为 [L+1, R-1]。在有效列范围内，每个像素取第 0 行中沿对角线上溯 r+1 步对应的颜色（即列 c 的颜色取第 0 行列 c-(r+1) 的颜色），然后每增加一行翻转一次红(2)<->灰(5)。
3. 若行 r+1 是障碍行：不在该行填充楔形像素。取该障碍行中与当前有效列范围重叠的每个间隙段 [G_L, G_R]，在障碍行下方一行为每个间隙段启动一个独立子楔形，初始有效列范围为 [G_L, G_R]。子楔形继承父楔形的行计数器（用于颜色交替），从父楔形中断处继续计数。
4. 每个子楔形按步骤 2-3 独立向下传播，可能遇到更下方的障碍行再次分裂。
5. 楔形或子楔形在有效列范围收缩至宽度 < 1 时自然终止，或在到达网格最底行时终止。
6. 障碍行的品红(6)像素保持不变。

**关键洞察**：障碍条不是楔形的终点——它是分束器。一个收缩楔形穿过障碍后变成多个独立的窄楔形，如同光束被狭缝衍射。颜色交替的行计数器跨越分裂保持连续，所以分支的色相取决于分裂发生在第几行。

## 新题 7：占位反转的双重作用——既产生传播源又约束填充范围

**组合逻辑**：[反转填充/occupancy_inversion](创新：反转结果同时充当下游操作的源信号和约束边界) + [沿对角线传播/diagonal_propagate](创新：传播源从反转结果中读取，而非独立的顶行色带) + [重涂色/recolor](已有)

**来源原语**：反转填充·瓷砖·分隔行列·瓷砖网格排列（参考题 1c0d0a4b）、填充·沿对角线传播·逐行交换双色（参考题 b5bb5719）、重涂色（参考题 50cb2852）

**依赖链**：瓷砖内占位反转将前景变背景、背景变红——反转后的顶行瓷砖提供对角传播的源色带，同时反转后的红(2)像素成为传播的不可覆盖区域（传播只能填入黑(0)像素，而黑像素恰好是原来的前景位置）。反转同时产生了"要传播什么"和"能填到哪里"这两个信息。

在分隔瓷砖网格中执行占位反转后，最顶行瓷砖的反转图案作为色带源沿对角线向下传播，但传播只能填充反转后为黑(0)的位置——即原先前景占据的位置——形成一种原始图案的对角投影。

**输入结构**：约 13x13 网格，黑(0)背景。网格由灰(5)分隔行和分隔列划分为 3x3 的瓷砖区域（例如 3 行 3 列共 9 个瓷砖，每个瓷砖 3x3，分隔线各 1 像素宽）。每个瓷砖内有若干青(8)前景像素，其余为黑(0)背景像素。不同瓷砖的青(8)图案各不相同。生成约束：最顶行的每个瓷砖至少有 1 个青(8)像素和 1 个黑(0)像素（反转后顶行瓷砖既有红(2)像素也有黑(0)像素，确保色带非空且传播有可填空间）；整个网格中反转后黑(0)位置（即原青(8)位置）的分布不全在同一列（否则对角传播无意义）。

**规则**：
1. 对每个 3x3 瓷砖执行占位反转：将瓷砖内每个青(8)像素改为黑(0)，将每个黑(0)像素改为红(2)。灰(5)分隔行/列保持不变。
2. 读取反转后网格的第 0 行（最顶行瓷砖的顶行）作为色带源序列。色带中红(2)和黑(0)交替的模式定义了传播内容。
3. 从第 0 行开始沿对角线向下传播：对于第 r 行（r >= 1）非分隔行的每个列 c，其传播源颜色取第 0 行列 c-r 处的颜色（若 c-r 超出色带范围则跳过）。传播源颜色每经过一行翻转一次：红(2)变蓝(1)、黑(0)保持黑(0)，再下一行蓝(1)变回红(2)，依此循环。
4. 传播规则：仅当目标位置 (r, c) 当前为黑(0)时才填入传播源颜色；若目标位置已为红(2)（即该位置是反转后的像素）或灰(5)（分隔线），则不覆盖。
5. 最终输出中存在三种非背景像素：红(2)（反转生成的、未被传播覆盖的像素）、蓝(1)（传播填入的像素）、灰(5)（分隔线）。

**关键洞察**：占位反转做了双重工作——它既生成了对角传播的源图案（顶行的红/黑序列），又划定了传播的可填区域（仅黑(0)位置，即原前景位置可被填入）。同一次变换的两个产物彼此约束：源越密则可填区越稀疏，反之亦然。

**依赖链**：格点检测找到缺位→每个缺位所在列上方有一个彩色像素→彩色像素在重力作用下穿过格点区域下落→像素停在障碍平台上的列位置决定该列缺位精灵体的颜色。重力改变了颜色的空间分配，使补全颜色不可预测。

**规则**：
1. 识别格点上的精灵体形状和格点行列位置，确定所有缺位位置（笛卡尔积中缺失的槽位）。
2. 每个彩色像素从初始位置开始向下做重力下落：逐格下移，经过黑(0)背景像素。当正下方被灰(5)障碍或精灵体像素阻挡时，像素尝试向左或向右滑动一格再继续下落（若左右均被阻挡或均为空，优先向左）。像素最终停在格点区域上方的最后一个可用位置（即格点区域顶行的正上一行，或障碍上方如果无法继续下落）。
3. 每个彩色像素最终停留位置的列号关联到一个缺位列（最终列号与哪个缺位的列号相同，该像素的颜色就分配给该缺位）。
4. 在每个缺位格点位置放置精灵体的副本，颜色使用步骤 3 中分配的颜色（而非原始青(8)色）。
5. 下落后的彩色像素从画面中擦除（替换为黑(0)背景）。灰(5)障碍物保持不变。原有青(8)精灵体保持不变。

**关键洞察**：悬浮的彩色像素不是装饰——它们是"颜色炸弹"，通过物理下落过程被分配到格点缺位。障碍物重新路由了颜色的分配，使得空间布局决定了补全的调色方案。

**规则**：
1. 读取灰(5)标记三元组，按行优先序排列，计算步进向量 (dr, dc) 和步长 D（两相邻标记间的距离）。
2. 中心矩形（移动体）沿 (dr, dc) 方向移动，直到与网格边缘齐平。在目标矩形上开出与移动体等宽的通道，将目标矩形分为两个碎片，碎片各向垂直于轴线的方向平移 1 像素。清除移动体原位置和目标矩形通道位置的像素。推动器矩形保持不变。
3. 计算每个碎片中红(2)标记像素的数量，选择标记最多的碎片。
4. 裁剪出该碎片的边界框区域作为输出基底。
5. 在裁剪结果中，从每个红(2)标记像素出发，沿 (dr, dc) 方向向前绘制射线，每条射线长度为 D 步。射线像素颜色为栗(9)。射线仅在裁剪区域内绘制，超出裁剪边界的部分截断。射线覆盖碎片原色像素（蓝(1)被栗(9)覆盖），但不覆盖其他红(2)标记像素。
6. 输出即为裁剪并绘制射线后的区域。

**关键洞察**：灰色标记三元组是整道题的"参数种子"——它同时编码了分裂的方向、移动的距离和射线的方向及长度。分裂改变了标记在碎片间的分布，决定了裁剪哪一半；而裁剪后射线又复用同一组参数从标记出发延伸。同一信息源驱动了三个不同操作。
