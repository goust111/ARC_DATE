## 新题 1：射线计数驱动旋转叠色

**组合逻辑**：[射线延伸](已有) + [计数](已有) → [旋转](创新——旋转角度由全局计数动态决定) → [重涂色](创新——基于旋转后重叠位置触发)

**来源原语**：射线延伸(ray_extend, d43fd935), 行列对齐(row_col_alignment, d43fd935), 锚定方块(anchor_square, d43fd935), 标记像素(marker_pixel, d43fd935/88a10436), 旋转(rotate, 1a244afd), 计数(counting, a59b95c0), 重涂色(recolor, 多源), 距离保持不变(distance_preserved, 1a244afd)

**依赖链**：对齐检测确定哪些标记参与射线绘制 → 射线绘制产生线段 → 对齐标记的全局计数 K 决定所有射线的旋转角度(K*90 度) → 旋转后的射线像素若与非参与标记重合则触发重涂色。删除计数则旋转角度不确定；删除旋转则重叠永不发生；删除射线则无旋转对象。

从锚定方块出发，对齐标记发射射线，射线作为整体围绕锚心旋转（角度由对齐标记总数决定），旋转后与散落标记的重合位置被重涂为橙色。

**输入结构**：约 15x15 的黑(0)背景网格。网格中有一个红(2) 2x2 锚定方块，位于网格中部偏左。散布 4-6 个孤立单像素标记，每个标记颜色各不相同（使用蓝(1)、绿(3)、黄(4)、灰(5)、品红(6)中的若干种），标记之间不相邻。其中 2-4 个标记与锚定方块的某行或某列对齐（即标记的行坐标与方块占据的两行之一相同，或标记的列坐标与方块占据的两列之一相同），其余标记不与方块对齐。生成约束：所有标记与锚定方块之间至少间隔 2 个像素；旋转后的射线不超出网格边界（可通过调整标记距离保证）。

**规则**：
1. 识别红(2) 2x2 锚定方块，记录其中心点（2x2 方块的四格几何中心，坐标取四格中心的平均值，可能为半整数）。
2. 对于每个与方块行或列对齐的标记像素，从该标记向方块绘制一条水平或垂直线段，线段颜色为标记颜色，线段终点为距方块最近边缘相邻的那个像素（不覆盖方块本身）。标记本身保留。
3. 计算与方块对齐的标记总数 K。
4. 将所有绘制的线段像素（不含标记像素和方块像素）整体围绕锚定方块中心旋转 (K * 90) 度顺时针。旋转以最近整数坐标取整。旋转后超出网格边界的像素丢弃。
5. 在旋转后的线段位置绘制像素（保留旋转前的颜色）。原始线段位置不保留（只保留旋转后的位置）。
6. 旋转后的线段像素若与任何原始标记像素（无论是否对齐）占据同一位置，该位置变为橙(7)。
7. 锚定方块和所有原始标记像素保持不变（不被线段覆盖）。

**关键洞察**：对齐标记的全局总数决定了所有射线共同的旋转角度，因此增减一个对齐标记会同时改变旋转角和参与射线的集合。橙色重叠标记需要求解者同时追踪射线的旋转目的地和非对齐标记的固定位置。

## 新题 2：双框移位-互换交叉检测

**组合逻辑**：[滑动/波形移位](已有) ∥ [颜色互换](已有) → [逐位比较 + 重涂色](创新——两个独立变换的输出在像素级交叉产生新标记)

**来源原语**：滑动(shift, 1c56ad9f), 逐行交替方向(alternating_direction_per_row, 1c56ad9f), 底行锚定(bottom_row_anchored, 1c56ad9f), 颜色互换(color_swap, 7ee1c6ea), 矩形边框(rectangular_frame, 7ee1c6ea), 框内区域(interior_region, 7ee1c6ea), 框内限定(frame_interior_only, 7ee1c6ea), 重涂色(recolor, 多源)

**依赖链**：上框内容经波形移位变换 → 下框内容经颜色互换变换 → 逐像素比较两个变换后的内容 → 匹配位置在两框中均标橙色。移位改变上框像素位置从而改变哪些位置匹配；互换改变下框颜色从而改变匹配内容。两个变换并行但通过比较步骤耦合。

上下两个灰框各含相同双色图案；上框内容做波形行移位，下框内容做双色互换，然后逐位比较——两框在同一位置呈现相同非黑颜色的格子被标记为橙色。

**输入结构**：约 16x16 的黑(0)背景网格。上半部和下半部各有一个灰(5)单像素厚矩形边框，两框垂直排列，间隔至少 2 行黑像素。两框的内部区域大小相同（宽 W 高 H，W 和 H 均为 5-7）。每个框的内部包含由两种非黑非灰颜色构成的图案（例如蓝(1)和黄(4)），内部可含黑(0)空位。两框的初始内部图案不同但使用相同的两种颜色。生成约束：两框内部尺寸严格相等；使用的两种颜色在整个网格中仅出现在框内部。

**规则**：
1. 识别两个灰(5)矩形边框。按垂直位置区分：边框顶边行号较小的为上框，另一个为下框。
2. 对上框内部执行波形移位：以内部最底行为基准行（行索引 0），固定不动。从基准行向上逐行编号（1, 2, 3, ...）。奇数行向右平移 1 像素，偶数行固定不动。平移时，超出内部右边界的像素环绕到该行内部最左位置。
3. 对下框内部执行颜色互换：将内部的两种非黑非灰颜色彼此交换（例如蓝(1) 变黄(4)、黄(4) 变蓝(1)）。内部的黑(0)像素不变。
4. 逐像素比较上框和下框变换后的内部内容（两内部大小相同，按相对位置一一对应）。对于每个位置：若两框在该位置的颜色相同且不为黑(0)，则将两框中该位置的像素均涂为橙(7)。
5. 灰(5)边框像素、边框外部像素均保持不变。

**关键洞察**：波形移位和颜色互换分别独立地改变各自框的内容，但求解者必须同时在脑中完成两种变换才能判断哪些位置同色匹配。移位改变的是位置，互换改变的是颜色值，两者的交叉效应无法通过单独理解任一变换获得。

## 新题 3：等价形状对齐连线与分组重涂

**组合逻辑**：[形状匹配/旋转翻转等价](已有) → [连线](已有，创新——仅在对齐条件满足时连线) + [重涂色](创新——由分组大小决定是否重涂)

**来源原语**：形状匹配(shape_match, 6165ea8f/776ffc46), 旋转翻转等价(dihedral_equiv, 6165ea8f), 归一化掩码(normalized_mask, 6165ea8f), 连线(line_drawing, 1bfc4729), 行列对齐(row_col_align, d94c3b52/d43fd935), 重涂色(recolor, 多源), 精灵体(sprite, 多源), 排序(ordering, 1bfc4729), 忽略干扰项(ignore_distractors, 6165ea8f)

**依赖链**：形状等价判定建立分组 → 组内成对检查行列对齐 → 对齐的等价对之间绘制连线（颜色由方向决定）→ 分组大小决定精灵体是否被重涂。形状匹配是分组基础，对齐是连线条件，分组大小驱动重涂——三者缺一不可。

网格上散布多个小精灵体，按旋转翻转等价分组；组内两个精灵体若边界框中心共行或共列则连线；连线方向决定线色；包含两个以上成员的组将精灵体统一重涂。

**输入结构**：约 18x18 的黑(0)背景网格。散布 5-7 个小型 4-连通单色精灵体（每个 3-6 像素），每个精灵体使用不同颜色（从蓝(1)、红(2)、绿(3)、黄(4)、灰(5)、品红(6)、橙(7)中选取），精灵体之间不接触（边界框互不重叠且间隔至少 1 像素）。部分精灵体的紧边界框掩码在旋转/翻转下等价（同一形状的不同朝向），形成 2-3 个等价组，剩余为单元素组。生成约束：至少有一对等价精灵体的边界框中心共享同一行或同一列（行/列坐标相同）；至少有一对等价精灵体不共享行列。

**规则**：
1. 对每个精灵体提取紧边界框内的掩码（前景为 1、背景为 0 的二值矩阵）。
2. 两个精灵体属于同一等价组，当且仅当其掩码在 0/90/180/270 度旋转和水平/垂直翻转的 8 种变换中至少有一种使两掩码完全相同。
3. 对于同一等价组中的每对精灵体 (A, B)：计算 A 和 B 各自边界框的中心坐标（边界框行范围的中间值，列范围的中间值，取整数向下取整）。若两中心的行坐标相同，绘制一条水平线段连接两边界框最近的左右边缘（含边缘像素，不含边界框内部），线色为蓝(1)。若两中心的列坐标相同，绘制一条垂直线段连接两边界框最近的上下边缘，线色为红(2)。若行列均不相同则不连线。若行列均相同（极端情况），仅绘制水平线。
4. 连线若经过某个非本组精灵体的边界框区域，该线段整体改为黄(4)。
5. 将所有包含 2 个及以上成员的等价组中的精灵体统一重涂为绿(3)。单元素组的精灵体保持原色不变。
6. 连线不覆盖精灵体像素（精灵体优先）。

**关键洞察**：形状等价判定需要在旋转/翻转下比较掩码，视觉上不同朝向的精灵体可能等价。连线仅在等价且对齐时出现，因此求解者必须同时判断形状等价和空间对齐两个独立条件。穿过其他精灵体的连线变色增加了一层空间推理。

## 新题 4：棋盘反转旋转拼接加框

**组合逻辑**：[旋转+拼接](已有) × [颜色反转](创新——反转不均匀施加，棋盘式交替选择象限) + [外框绘制](已有)

**来源原语**：旋转(rotate, 7953d61e/ed98d772), 拼接(assembly, 7953d61e), 逐象限旋转排布(quadrant_rotation_layout, 7953d61e), 颜色反转(color_invert, 48131b3c), 二值图案(binary_pattern, 48131b3c), 外框绘制(frame_draw, db93a21d), 尺寸倍增嵌套(size_doubled_nesting, db93a21d), 阵列排布(array_layout, ed98d772/a59b95c0)

**依赖链**：旋转产生四个象限内容 → 棋盘式选择决定哪些象限做颜色反转 → 反转改变选中象限的像素值 → 拼接合并四象限 → 外框绘制包裹拼接结果。反转选择模式需对比多个示例才能归纳。

将 n x n 二值输入旋转为四象限拼成 2n x 2n；对角线位置的两个象限做颜色反转（黑与前景色互换），另两个不反转；最后加绿色外框。

**输入结构**：一个较小的 n x n 正方形网格（n 为 3-5），仅含黑(0)和一种前景色（如红(2)），形成一个非对称的二值图案（图案在 90 度旋转下不与自身重合，以便区分各象限的旋转状态）。无背景边框或标记。

**规则**：
1. 构造 2n x 2n 的输出核心区域，由四个 n x n 象限组成：
   - 左上象限：原始输入，不做颜色反转。
   - 右上象限：输入逆时针旋转 90 度，然后做颜色反转（黑(0)变为前景色，前景色变为黑(0)）。
   - 左下象限：输入旋转 180 度，然后做颜色反转。
   - 右下象限：输入逆时针旋转 270 度（即顺时针 90 度），不做颜色反转。
2. 反转模式为棋盘式：将四象限视为 2x2 网格，左上(0,0)和右下(1,1)不反转，右上(0,1)和左下(1,0)反转。
3. 在 2n x 2n 核心区域外围绘制一圈单像素厚的绿(3)边框。最终输出大小为 (2n+2) x (2n+2)。

**关键洞察**：旋转序列（0/90/180/270）和源题相同是诱导项；真正的隐蔽规则是颜色反转的棋盘式施加——仅对角位置的象限（右上和左下）做反转，而非全部或交替。求解者必须对比多个示例区分"哪些象限被反转了"和"哪些象限只是旋转了"。

## 新题 5：面板压缩行数驱动模板旋转印章

**组合逻辑**：[压缩](已有) → [计数](创新——压缩后的行数作为旋转参数) → [旋转](已有) + [印章放置](已有) + [擦除](已有)

**来源原语**：压缩(compress, 25c199f5), 分栏面板(panel, 25c199f5), 分隔列(divider_column, 25c199f5), 非空行(occupied_row, 25c199f5), 空行丢弃(empty_rows_discarded, 25c199f5), 印章放置(stamp, abc82100/88a10436), 模板图案(stencil_pattern, abc82100), 旋转(rotate, 1a244afd/7953d61e), 擦除(erase, abc82100), 重涂色(recolor, 多源), 计数(counting, a59b95c0)

**依赖链**：从模板面板提取模板 → 对内容面板执行压缩得到紧凑内容和空闲区域 → 计算压缩后占用行数 K → K 决定模板的旋转角度 → 旋转后的模板印章到空闲区域 → 擦除原始模板。压缩同时完成两件事：腾出印章空间和提供旋转参数，是双重用途的核心节点。

三栏面板中，左栏含青色模板，中右栏含散布图案；压缩中右栏（丢弃空行、下沉内容）后，各栏的占用行数决定模板旋转角度，旋转后的模板被印到各栏上方空闲区。

**输入结构**：约 12x18 的黑(0)背景网格，被 2 列灰(5)分隔列均分为 3 个等宽面板（每面板宽 W，约 4-5 像素）。左面板中包含一个青(8)模板图案（一个 4-连通小图形，3-5 像素，位于面板中部），其余为黑(0)。中面板和右面板各包含若干行非黑像素（使用蓝(1)、红(2)等颜色），行与行之间夹杂全黑空行，形成稀疏的行图案。生成约束：中面板和右面板的非空行数量不同（以产生不同旋转角度）；各面板高度 H 至少为 10 以保证压缩后有足够空闲空间容纳模板；模板边界框不超过 3x3。

**规则**：
1. 识别左面板中的青(8)模板，提取其紧边界框内的形状掩码。
2. 对中面板执行压缩：丢弃所有全黑行，将剩余非空行保持相对顺序下沉到面板底部，上方填充黑(0)。计算压缩后的非空行数 K_mid。
3. 对右面板执行相同压缩，计算非空行数 K_right。
4. 计算各面板的模板旋转角度：将模板旋转 (K * 90) 度顺时针，其中 K 为该面板的非空行数（对 4 取余以确定实际旋转：0 度、90 度、180 度或 270 度）。
5. 在中面板的空闲区域（压缩后上方的黑色区域）顶部放置旋转后的模板：模板左上角对齐面板空闲区域的左上角。模板颜色从青(8)重涂为该面板中出现最多的非黑颜色（按像素数计，若并列取在输入中行号最小的颜色）。
6. 对右面板执行相同操作（使用 K_right 决定旋转角度，重涂为右面板最频繁非黑色）。
7. 擦除左面板中的青(8)模板（替换为黑(0)）。分隔列保持灰(5)不变。

**关键洞察**：压缩承担双重角色——既为模板腾出放置空间，又通过压缩后的行数决定模板的旋转角度。内容越多的面板压缩后剩余空间越少，同时旋转角度也不同，形成一种"内容密度同时影响位置和形态"的耦合关系，这在任何源题中都不存在。

## 新题 6：枢轴旋转点的阶梯射线扩展与重叠标记

**组合逻辑**：[旋转/枢轴旋转](已有) → [阶梯扩展](创新——扩展步长由旋转距离参数化) → [重涂色/跨色重叠变色](已有)

**来源原语**：旋转(rotate, 1a244afd), 枢轴像素(pivot_pixel, 1a244afd), 源像素(source_pixel, 1a244afd), 同行或同列(same_row_or_col, 1a244afd), 距离保持不变(distance_preserved, 1a244afd), 阶梯扩展(stepped_expansion, 58e15b12), 周期性步长(periodic_step_length, 58e15b12), 跨色重叠变色(cross_color_overlap_recolor, 58e15b12), 射线延伸(ray_extend, d43fd935), 重涂色(recolor, 多源)

**依赖链**：枢轴旋转产生新像素点及其距离参数 → 距离参数决定阶梯射线的步长 → 阶梯射线从新像素向四方向扩展 → 不同新像素的射线重叠处变色。旋转的几何参数（距离）直接参数化了后续扩展操作的形态。

品红源像素绕蓝枢轴旋转 90 度产生橙色新点；每个新点向四方向发射阶梯射线，射线步长等于该新点到其枢轴的距离；不同新点的射线重叠处变红。

**输入结构**：约 15x15 的黑(0)背景网格。包含 2-3 个蓝(1)枢轴像素和 3-4 个品红(6)源像素。每个品红源与恰好一个蓝枢轴位于同一行或同一列（通过行列唯一对应配对）。各品红源到其配对枢轴的曼哈顿距离不全相同（至少两个不同距离，范围 2-4）。生成约束：旋转后的目标位置均在网格内；不同源像素配对到不同枢轴（一对一映射，若枢轴数少于源数则允许一个枢轴匹配多个源，但优先选择唯一行列对齐的配对）。

**规则**：
1. 对每个品红(6)源像素，找到与它同行或同列的蓝(1)枢轴像素作为配对（若同行同列各有一个枢轴，选同行的）。
2. 计算源到枢轴的偏移向量，将偏移向量逆时针旋转 90 度，得到目标位置。在目标位置放置一个橙(7)像素。移除原品红源像素。蓝枢轴保持不变。
3. 记录每个橙像素到其对应枢轴的曼哈顿距离 D。
4. 从每个橙像素出发，向上、下、左、右四个方向发射阶梯射线。射线规则：每前进 D 个像素为一步，每步结束后射线在该方向继续前进。射线像素绘制为绿(3)。射线到达网格边界时停止（不环绕）。
5. 橙像素本身不被绿射线覆盖（橙优先）。蓝枢轴像素也不被覆盖（蓝优先）。
6. 若两个不同橙像素发出的绿(3)射线在同一位置重叠，该位置变为红(2)。三个及以上重叠也为红(2)。

**关键洞察**：旋转操作不仅产生新像素的位置，还将旋转的距离参数"遗传"给阶梯扩展的步长。距离短的新点产生密集射线，距离长的产生稀疏射线，使得不同源像素的扩展模式截然不同。红色重叠标记是两套不同密度射线相交的几何痕迹，无法通过单一变换预测。

## 新题 7：行带平铺与标记计数驱动的印章优先级翻转

**组合逻辑**：[平铺](已有) ∥ [印章覆盖](已有) → [计数](创新——标记数量作为合成优先级的开关) → [重涂色](创新——优先级翻转改变最终可见层)

**来源原语**：平铺(tile, 8eb1be9a), 行带(row_band, 8eb1be9a), 纵向重复(vertical_repetition, 8eb1be9a), 前景行带铺满画布(foreground_band_tiles_to_fill_canvas, 8eb1be9a), 印章覆盖(stamp, 88a10436), 精灵体(sprite, 88a10436/776ffc46), 标记像素(marker_pixel, 88a10436/d43fd935), 中心对齐(center_align, 88a10436), 精灵对准标记复制(sprite_at_marker, 88a10436), 计数(counting, a59b95c0), 重涂色(recolor, 多源)

**依赖链**：行带纵向平铺产生全画布背景图案 → 精灵体印章到各标记位置产生前景副本 → 标记总数 K 决定合成规则（K <= 3 时印章优先覆盖平铺层；K > 3 时平铺层优先覆盖印章层）→ 最终可见像素取决于优先级。计数驱动合成规则翻转是核心创新。

网格含一条水平行带和一个小精灵体，行带纵向平铺铺满画布，精灵体印章到各灰色标记处；灰色标记总数决定平铺层与印章层的叠放优先级。

**输入结构**：约 15x15 的黑(0)背景网格。包含以下元素：(a) 一条水平行带——由 2-3 行连续的非黑像素组成（使用蓝(1)和黄(4)等颜色交替排列），横跨网格全宽，位于网格中部某处，行带上下方均有黑(0)行。(b) 一个小精灵体——一个 4-连通单色图形（3-5 像素，使用红(2)），位于行带上方或下方。(c) 2-6 个灰(5)标记像素，散布于网格各处（不在行带行内，不与精灵体重叠）。生成约束：精灵体的边界框不超过 3x3；标记位置保证印章后的精灵体副本不超出网格边界；行带至少包含两种颜色。

**规则**：
1. 识别水平行带（包含所有非黑像素的连续行范围，横跨全宽）。
2. 以行带为瓦片，纵向重复铺满整个画布：向上和向下复制行带，保持行带的原始行位置对齐（即从行带位置开始，向上每隔行带高度放一个副本，向下同理，直到超出网格边界）。超出部分裁剪。这产生"平铺层"。
3. 识别红(2)精灵体，提取其紧边界框掩码（边界框内黑(0)像素视为透明）。
4. 对每个灰(5)标记像素，以标记为中心对齐精灵体的边界框中心，放置一个精灵体副本（保持红(2)色）。移除灰标记像素（被精灵体覆盖或变为黑(0)）。这产生"印章层"。原始精灵体也保留在原位。
5. 计算灰标记的总数 K。
6. 合成两层：
   - 若 K <= 3：印章层优先——在平铺层之上绘制印章层，印章层的非透明像素覆盖平铺层。
   - 若 K > 3：平铺层优先——在印章层之上绘制平铺层，平铺层的非黑像素覆盖印章层。
7. 原始精灵体始终可见（不被任何层覆盖）。

**关键洞察**：标记数量本身不影响每个印章的位置或行带的铺排方式，但它翻转了两个图层的合成顺序。当标记少时，印章清晰可见于行带之上；当标记多时，行带遮盖了大部分印章，仅在行带的黑(0)间隙中露出印章痕迹。这个阈值规则必须通过对比不同标记数量的示例才能发现。
