## 新题 1：重力着陆后的邻接传色

**组合逻辑**：[重力下落](已有) → [面积区分角色](已有，创新：区分可移动中性色块与固定标记) → [邻接传色](已有，创新：传色关系由重力后新位置决定而非输入中已有)

**来源原语**：重力下落(gravity_drop)、面积区分角色(area_determines_role) ← 6ca952ad；邻接传色(adjacency_transfer)、中性遮罩(neutral_mask)、标记像素(marker_pixel)、擦除(erase) ← b7256dcd

**依赖链**：面积阈值将前景对象分为可移动的灰色中性色块（大）和固定彩色标记（小）。中性色块按重力下落至底部后产生新的4-连通邻接关系，此时标记像素的颜色通过新邻接传递给着陆的中性色块。传色规则以重力后的空间布局为依据，而非输入时的原始布局。

在输入中远离彩色标记的灰色块，经重力下落至底部后与标记相邻而获得标记颜色。

**输入结构**：约15x15网格，背景为黑(0)。灰(5)色的4-连通单色块（每块4~8像素，不规则形状，非矩形）分布在网格上半区，共3~5块，彼此水平范围互不重叠。底部2行内散布若干单像素彩色标记（红(2)、蓝(1)、绿(3)等颜色各异），每个标记面积为1。灰色块与标记像素在初始位置不4-连通相邻。生成约束：各灰色块的列跨度互不重叠，保证下落路径不冲突；每个灰色块下落后至少有一侧与某个标记像素4-连通相邻。

**规则**：
1. 将网格中所有4-连通非背景对象按面积分类：面积 > 2 的灰(5)色对象为可移动中性色块，面积 <= 2 的非灰色对象为固定标记。
2. 将每个中性色块从原始位置清除（设为背景色黑(0)）。
3. 对每个中性色块，整体垂直向下平移，直到其边界框底行接触网格底边（row = H-1）。若多个色块在同一列范围内（本题生成约束已排除此情况），则先处理边界框底行row值最大的色块，后续色块叠在其上方。
4. 对每个落定的中性色块，检查其所有像素的4-连通邻居中是否包含标记像素。若包含一种标记颜色，将整块中性色块重涂为该标记颜色。若邻接多种不同颜色的标记，取列号最小的标记像素的颜色。
5. 未邻接任何标记的中性色块保持灰(5)不变。标记像素本身在输出中保留原色和位置不变。

**关键洞察**：输入中灰色块与标记像素距离较远，无法直接推断传色关系；必须先模拟重力下落确定最终位置，才能知道哪个色块获得哪种颜色。重力改变了空间邻接图谱，这是传色的前提。

## 新题 2：蛇径遍历顺序编号的分区着色

**组合逻辑**：[网格分区](已有) → [展直/遍历](已有，创新：遍历不输出序列，而是给穿越的区域赋予编号) → [计数](已有，创新：对编号做奇偶分类) → [重涂色](已有)

**来源原语**：蛇形路径(snake_path)、端点(endpoint)、遍历顺序(traversal_order) ← 7b5033c1；分隔线(separator_line)、网格分区(grid_partition) ← 6773b310；重涂色(recolor) ← 多源

**依赖链**：分隔线将网格划分为若干矩形区域。一条蛇形路径穿越部分区域，路径的拓扑遍历顺序为每个被穿越的区域赋予唯一编号。编号的奇偶性决定该区域的填充色——奇数区域涂红，偶数区域涂绿。遍历顺序依赖路径的空间走向而非区域的网格坐标。

蛇形路径穿过分隔网格的各区域，路径遍历的先后顺序决定区域编号，编号奇偶决定区域填充颜色。

**输入结构**：约16x18网格，背景为黑(0)。灰(5)色的完整行和完整列作为分隔线，将网格划分为3x3或4x3共9~12个矩形区域。一条蓝(1)色的4-连通蛇形路径在区域内部和分隔线间隙中穿行（分隔线上留有1像素宽的间隙供路径通过），路径有且仅有两个端点（仅一个路径邻居的像素）。每个区域内最多经过一段连续路径。生成约束：蛇径至少穿过6个不同区域；路径不分叉（严格单链）；两个端点不在同一区域内。

**规则**：
1. 识别灰(5)色完整行和完整列作为分隔线，将网格划分为矩形区域。
2. 找到蛇径的两个端点（仅有一个4-连通路径邻居的蓝色像素）。选择行号更小的端点作为起点；若行号相同则取列号更小的。
3. 从起点沿路径逐像素遍历。按遍历顺序记录路径依次进入的区域序列（同一区域仅在首次进入时记录），得到区域的访问编号（从1开始递增）。
4. 访问编号为奇数的区域：将该区域内所有背景像素（黑(0)）涂为红(2)。访问编号为偶数的区域：涂为绿(3)。
5. 未被蛇径穿过的区域保持黑(0)背景不变。蛇径像素保持蓝(1)不变。分隔线保持灰(5)不变。

**关键洞察**：区域的填充颜色不由其在网格中的空间坐标决定，而由蛇径穿越的拓扑顺序决定——即使空间上相邻的两个区域，如果蛇径的走向使它们的访问编号奇偶不同，颜色也不同。必须完整追踪蛇径才能确定每个区域的编号。

## 新题 3：对角连线交叉形成的连通分量排序涂色

**组合逻辑**：[同色配对](已有) + [对角线段连接](已有) → [连通分量合并](创新：交叉点使不同颜色线段融合为同一8-连通分量) → [面积排序](已有) → [重涂色](已有)

**来源原语**：端点对(endpoint_pair)、同色配对(same_color_pairing)、对角线段连接(diagonal_segment_connect) ← 1f876c06；计数(counting)、面积排序(area_ordering)、按像素数降序(descending_pixel_count) ← f8ff0b80；重涂色(recolor) ← 多源

**依赖链**：每种前景色恰好有两个像素作为端点对，沿45度对角线画线连接。多条对角线段在网格上交叉，交叉点使原本分属不同颜色的线段在8-连通意义下合并为同一连通分量。合并后的连通分量按总像素面积降序排列，排名决定最终涂色。

同色端点对画对角线后，因线段交叉而合并形成的连通分量按面积排序决定最终涂色。

**输入结构**：约14x14网格，背景为黑(0)。有3~4种前景颜色（如红(2)、蓝(1)、绿(3)、黄(4)），每种颜色恰好出现2个单像素点，构成端点对。各端点对的两点位于同一条45度对角线上（行差绝对值=列差绝对值）。生成约束：至少有两对线段的对角路径共享某个格子（即交叉），使得画线后部分线段通过交叉点形成8-连通的合并分量；所有合并后分量的像素面积互不相等。

**规则**：
1. 对每种前景颜色，沿其两个端点之间的45度对角线段填充所有经过的背景像素为该颜色（包含两个端点本身）。
2. 按颜色在输入中首次出现的行号从小到大的顺序依次处理各颜色的连线。若两条线段经过同一像素（交叉），该像素涂为后处理颜色（后处理的覆盖先处理的）。
3. 连线全部完成后，在整个网格上计算所有8-连通前景分量（将所有非背景像素视为前景，不区分颜色，按8-连通划分分量）。
4. 按每个分量的总像素数从大到小排序。将面积最大的分量所有像素重涂为橙(7)，次大的重涂为青(8)，第三大的重涂为栗(9)。若存在第四个及更多分量，依次涂为红(2)、蓝(1)。面积相同时（生成约束已排除此情况），以分量最上方像素的行号更小者排前。

**关键洞察**：单独观察端点对的位置无法判断最终颜色——必须画出所有对角线段后才能发现哪些线段通过交叉点合并成了同一个8-连通分量。交叉合并是涌现效果：每条线段独立时互不相关，但画在同一网格上后因共享格子而产生了结构性连接，这改变了面积排名和最终涂色。

## 新题 4：面板镜像引发的边界邻接传色

**组合逻辑**：[轴线决定变换](已有) + [镜像](已有) → [邻接传色](已有，创新：传色关系由镜像后新的边界接触决定) → [重涂色](已有)

**来源原语**：九宫面板(panel)、引导线(guide_line)、轴线决定变换(axis_determines_op)、镜像(reflect) ← 4e7e0eb9；邻接传色(adjacency_transfer)、标记像素(marker_pixel)、标记接触即赋色(marker_touch_color) ← b7256dcd；重涂色(recolor) ← 多源

**依赖链**：每个面板根据引导线方向执行镜像变换，改变面板内前景图案的空间分布。镜像后，部分前景像素移动到面板边界位置，与面板外的标记像素产生新的4-连通邻接。邻接关系触发标记颜色向面板内前景分量的传色。未镜像则不会产生该邻接，因此镜像是传色的前提条件。

面板按引导线镜像后，新出现在边界上的前景像素与外部标记产生邻接，触发标记颜色向面板内传播。

**输入结构**：约17x17网格，由1像素宽的灰(5)色网格线分为2x2共4个面板，每个面板内部约7x7。每个面板内包含：一个由蓝(1)色像素组成的4-连通前景图案（4~8像素，不规则形状），以及一条贯穿面板的引导线——水平引导线用黄(4)色占满面板内某行全部像素，垂直引导线用黄(4)色占满面板内某列全部像素。面板外侧（紧贴灰色网格线的外边缘）散布若干单像素标记（红(2)、绿(3)、橙(7)等），每个面板外侧最多2个标记。生成约束：每个面板的前景图案在初始状态下不与面板边界的最外行/列接触（即图案不在面板边缘上），但镜像后至少一个面板的图案会移动到边界位置与外部标记4-连通相邻。

**规则**：
1. 对每个面板，识别引导线方向：水平引导线（黄(4)占满面板内某一完整行）→ 对该面板执行上下镜像（以引导线为轴）；垂直引导线（黄(4)占满面板内某一完整列）→ 执行左右镜像（以引导线为轴）。镜像时引导线本身保持不变，仅翻转引导线两侧的内容。
2. 镜像完成后，对每个面板，检查面板边界行/列上的蓝(1)前景像素是否与面板外（灰色网格线另一侧或网格边缘外侧）的彩色标记像素4-连通相邻。
3. 若面板边界上的某个蓝(1)前景像素与某个标记像素相邻，将该蓝色前景像素所属的整个4-连通蓝色分量重涂为该标记的颜色。若同一分量同时邻接不同颜色的标记，取行号更小的标记的颜色。
4. 边界上无前景像素、或前景像素不与标记相邻的面板，其前景图案保持蓝(1)不变。引导线保持黄(4)、网格线保持灰(5)、标记保持原色、背景保持黑(0)。

**关键洞察**：镜像变换不只是视觉上的对称操作——它改变了哪些前景像素出现在面板边界上。只有镜像后恰好落在边界位置的像素才能与外部标记产生邻接，触发传色。不执行镜像就无法判断传色目标，因为原始图案不在边界上。

## 新题 5：标记行分区后的像素计数蛇形压缩

**组合逻辑**：[稀疏标记线](已有，创新：用作分区边界而非镜像轴) → [计数](已有) → [排序](已有) → [蛇形填充](已有，创新：填充内容为区域主色而非单个标记色)

**来源原语**：稀疏标记线(sparse_marker_line) ← 66ac4c3b；计数(counting)、面积排序(area_ordering)、按像素数降序(descending_pixel_count) ← f8ff0b80；蛇形填充(boustrophedon_fill)、列序排列(column_order)、奇行反序(odd_row_reversed)、压缩(compress) ← cdecee7f

**依赖链**：含有灰色像素的稀疏行将网格分割为水平带状区域。计算每个区域内前景像素的总数并记录区域主色。按像素数降序排列各区域，将排序后的主色序列蛇形折叠填入紧凑矩阵。分区方式决定了区域划分，像素密度决定了排序，蛇形折叠决定了输出布局。

稀疏标记行将网格分为带状区域，按各区域前景像素数排序后蛇形折叠输出颜色序列。

**输入结构**：约16x14网格，背景为黑(0)。2~3条水平稀疏标记行（行内有若干灰(5)像素散布，其余为背景黑(0)，灰色像素数占该行宽度的30%~70%），将网格分为4~5个水平带状区域。每个带状区域包含一种主前景色（红(2)、蓝(1)、绿(3)、黄(4)、橙(7)中的一种）的若干散布像素，各区域主色互不相同。生成约束：各区域的前景像素总数互不相等；稀疏行的灰色像素位置随机分布，但同一行内至少有3个灰色像素以便识别为标记行。

**规则**：
1. 识别稀疏标记行：扫描所有行，若某行包含灰(5)像素且灰色像素数 >= 3，则该行为稀疏标记行。
2. 以标记行为边界，将网格划分为水平带状区域。标记行本身不属于任何区域。最顶部标记行之上为第一区域，相邻标记行之间为中间区域，最底部标记行之下为末尾区域。
3. 对每个区域，计算其中非背景(0)、非灰(5)的前景像素总数，并记录该区域中出现次数最多的前景色作为主色。
4. 按前景像素数从多到少排列各区域。
5. 将排序后的区域主色序列蛇形填充到一个 R x 3 矩阵中（R = ceil(区域数 / 3)）：第0行从左到右填入第1~3名的主色，第1行从右到左填入第4~6名的主色，依此交替。不足3个的行末尾填充黑(0)背景。输出该矩阵。

**关键洞察**：输出颜色的排列顺序既不反映区域在输入中的上下位置，也不对应颜色本身的任何固有属性——而是由各区域内像素的密度（前景像素总数）决定排名，再经蛇形折叠交替反转阅读方向。必须先正确识别稀疏标记行（它们不是完整分隔线，而是断续的灰色像素行）才能正确分区。

## 新题 6：形状匹配后按孔洞面积轮转涂色

**组合逻辑**：[形状匹配孔洞](已有) + [面积排序](已有) → [轮转涂色](创新：颜色不直接来自匹配精灵体，而是在面积排名中循环位移一位)

**来源原语**：模板框架(template_frame)、精灵体(sprite)、孔洞(hole)、形状匹配孔洞(shape_matches_hole)、旋转翻转不变(rotation_flip_invariant)、嵌入填充(inlay_fill) ← 67e490f4；面积排序(area_ordering)、按像素数降序(descending_pixel_count) ← f8ff0b80；重涂色(recolor) ← 多源

**依赖链**：外部精灵体按形状匹配到框架内的孔洞（旋转/翻转允许），建立精灵体-孔洞的一一对应。将孔洞按面积从大到小排列。每个孔洞的填充色不是其匹配精灵体的颜色，而是面积排名中下一位孔洞所匹配精灵体的颜色（最小孔洞循环取最大孔洞的精灵体颜色）。颜色在面积排名链上循环位移一位。

精灵体按形状匹配到框架孔洞后，填充颜色沿面积排名循环位移：每个孔洞获得面积紧邻下一级孔洞的匹配精灵体颜色。

**输入结构**：约16x16网格，背景为黑(0)。一个大型单色框架（绿(3)色，占据网格中央约12x12区域），框架内部有3~4个不同形状的孔洞（背景色(0)的连通区域，每个3~7像素，不规则形状，4-连通）。框架外部散布3~4个单色精灵体，每个精灵体由不同颜色绘制（红(2)、蓝(1)、黄(4)、橙(7)等），每个精灵体的形状与框架内恰好一个孔洞匹配（旋转和翻转允许，即8种朝向中至少有一种重合）。生成约束：各孔洞的像素面积互不相等；精灵体颜色互不相同；每个精灵体恰好匹配一个孔洞（一一对应）。

**规则**：
1. 裁剪到框架的边界框，将框架外的精灵体作为"颜色键"保留参考但不出现在输出中。
2. 对每个孔洞，在外部精灵体中找到形状匹配的精灵体（比较时允许旋转0/90/180/270度和水平翻转共8种朝向）。记录匹配关系：孔洞 Hi ↔ 精灵体 Si（颜色 Ci）。
3. 将所有孔洞按像素面积从大到小排列：H1（最大）、H2、H3、…、Hn（最小）。对应匹配精灵体颜色为 C1、C2、…、Cn。
4. 执行颜色轮转填充：用 C2 填充 H1，用 C3 填充 H2，……用 C1 填充 Hn。即每个孔洞填入面积排名紧邻下一位孔洞的匹配精灵体颜色，最小孔洞循环取最大孔洞的匹配精灵体颜色。
5. 输出为框架边界框区域，框架色保持绿(3)，孔洞已按上述规则填充，背景保持黑(0)。

**关键洞察**：每个孔洞的最终颜色既不来自其自身匹配的精灵体，也不来自固定的颜色映射——而是由面积排名体系中"下一级"孔洞的匹配精灵体决定。解题者必须同时完成形状匹配（确定谁配谁）和面积排序（确定排名），然后将颜色做一次循环位移。仅完成形状匹配而不做面积排序，或仅知道排序而不知匹配关系，都无法得出正确答案。

## 新题 7：标记像素的双重身份——分区激活与邻接传色

**组合逻辑**：[网格分区](已有) + [计数](已有，创新：标记数量决定区域激活状态) → [邻接传色](已有，创新：同一批标记像素既充当计数对象又充当传色源) + [擦除](已有)

**来源原语**：分隔线(separator_line)、网格分区(grid_partition)、标记像素(marker_pixel)、双标记区域出前景(dual_marker_foreground)、计数(counting) ← 6773b310；邻接传色(adjacency_transfer)、中性遮罩(neutral_mask)、标记接触即赋色(marker_touch_color)、擦除(erase) ← b7256dcd；重涂色(recolor) ← 多源

**依赖链**：分隔线将网格划分为区域，每个区域内有灰色中性色块和若干彩色标记。标记像素承担双重角色：其数量决定区域是否为"活跃区域"（恰好2个标记→活跃），其颜色决定活跃区域中中性色块的涂色。计数判别和传色操作共享同一组标记像素作为信息源，且计数结果门控传色是否发生。

分隔网格中的标记像素同时作为区域激活的计数依据和中性色块的传色来源，只有含恰好两个标记的区域才执行传色。

**输入结构**：约16x16网格，背景为黑(0)。黄(4)色的完整行和完整列作为分隔线，将网格划分为3x3共9个矩形区域（每个区域约4x4）。每个区域内包含：一个灰(5)色的4-连通中性色块（3~6像素，不规则形状，非矩形），以及1或2个单像素彩色标记（使用红(2)、蓝(1)、绿(3)三种颜色之一）。标记像素与同区域内的灰色中性色块4-连通相邻。当区域内恰好有2个标记时，两个标记颜色相同。生成约束：9个区域中至少4个含2个标记（活跃），至少3个仅含1个标记（非活跃）；不同活跃区域的标记颜色不全相同（至少用到2种颜色）。

**规则**：
1. 识别黄(4)色的完整分隔行和完整分隔列，将网格划分为矩形区域。
2. 对每个区域，计数其中非背景(0)、非黄(4)、非灰(5)的彩色标记像素数量。
3. 恰好含2个标记的区域为"活跃区域"：将该区域内所有灰(5)中性色块的像素重涂为标记的颜色（两个标记同色）。然后将该区域内的标记像素擦除（设为背景色黑(0)）。
4. 仅含1个标记的区域为"非活跃区域"：中性色块保持灰(5)不变。同样擦除标记像素。
5. 分隔线保持黄(4)，背景保持黑(0)。输出中不含任何彩色标记像素（全部被擦除）。

**关键洞察**：标记像素具有双重身份——同一个标记既是计数判别的统计对象（决定区域是否激活），又是传色操作的颜色来源（决定涂什么色）。这两个看似独立的规则（计数阈值判别 + 邻接传色）共享同一组标记像素，且计数结果严格门控传色是否执行。在参考题中，计数判别（6773b310）和邻接传色（b7256dcd）分别使用不同的标记体系；本题将两者合并到同一组标记上，产生了源题中不存在的"数据复用"结构关系。
