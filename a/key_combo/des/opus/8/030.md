## 新题 1：对称分类定色、阻挡距定半径的切比雪夫光晕

**组合逻辑**：[对称类型决定颜色](创新：从重涂对象本身 → 重涂围绕对象的同心环) + [同心层填充](创新：范围不由对象自身尺寸决定，而由外部阻挡像素的切比雪夫距离限定) + [擦除](已有：清除噪声单像素)

**来源原语**：重涂色 recolor、同心层填充 concentric_fill（参考题 a09f6c25, 516b51b7, 9356391f）；切比雪夫距离 chebyshev_dist、阻挡像素 blocker_pixel（参考题 ff72ca3e）；对称轴 symmetry_axis、对称类型决定颜色 symmetry_det_color（参考题 a09f6c25）；擦除 erase、单像素为噪声 singleton_noise（参考题 a09f6c25）

**依赖链**：对称分类产出颜色标签 → 该标签决定同心环的颜色方案；切比雪夫距离到阻挡像素产出半径上限 → 该上限决定同心环能画几层。两个独立分析在"绘制同心环"这一步汇聚，缺任何一路都无法确定输出。

根据每个前景物体的反射对称类型选择光晕颜色，根据到最近阻挡像素的切比雪夫距离限制光晕层数，在物体周围绘制交替双色的同心方环。

**输入结构**：约 15x15 的黑(0)背景网格。网格中散布 3-5 个红(2)的 4-连通单色前景物体，每个由 3-6 个像素构成，形状各异（保证每个物体恰好具备水平、垂直或对角线三种反射对称中的一种）。另有 2-4 个灰(5)阻挡像素散布于网格中，与所有前景物体不相邻。可能存在孤立的单个红(2)像素作为噪声。生成约束：任意两个前景物体之间的最短切比雪夫距离 >= 6，以保证光晕不交叉；每个物体到最近阻挡像素的切比雪夫距离在 2-5 之间。

**规则**：
1. 擦除所有孤立的单个红(2)像素（4-连通分量大小为 1 的红色像素），将其设为黑(0)背景。
2. 对每个剩余的红(2)前景物体，判断其唯一的反射对称类型：水平对称 → 分配颜色蓝(1)；垂直对称 → 分配颜色绿(3)；对角线对称 → 分配颜色橙(7)。
3. 对每个前景物体，计算该物体中任意像素到任意灰(5)阻挡像素的最小切比雪夫距离，记为 D。
4. 将物体本身的像素重涂为步骤 2 分配的颜色（替换红色）。
5. 对切比雪夫距离 d = 1, 2, ..., D-1（从物体像素集合算起），绘制同心环：奇数 d 使用步骤 2 分配的颜色，偶数 d 使用黄(4)。仅在当前为黑(0)背景的像素上着色。
6. 灰(5)阻挡像素保持不变。
7. 若两个物体的光晕理论上会重叠（因生成约束，正常情况不会发生），重叠像素取切比雪夫距离更小的那个物体的颜色。

**关键洞察**：物体的反射对称类型与物体到阻挡像素的空间距离是两个完全独立的几何属性，它们分别控制光晕的色彩方案和空间范围。仅看单个示例可能误将颜色归因于位置或大小，需要对比多个不同对称类型且不同阻挡距离的物体才能分离这两条规则。

## 新题 2：重复精灵体作为印章模板，在其余精灵体的镜像位置盖章

**组合逻辑**：[裁剪 + 图案匹配 + 出现两次者选取](已有：找出重复精灵体) → [镜像位置](创新：不是镜像重复精灵体自身，而是镜像其他精灵体的位置以确定盖章坐标) → [印章放置](创新：模板来自重复精灵体，而非输入中显式的模板区域) → [重叠区域重涂](已有：重叠处变色)

**来源原语**：裁剪 crop、图案匹配 pattern_match、出现两次者选取 twice_pattern_selected（参考题 f5aa3634）；镜像位置 mirrored_position、内部朝向不变 orientation_preserved（参考题 8ee62060）；印章放置 stamp、重叠区域重涂 overlap_recolor（参考题 a395ee82）

**依赖链**：图案匹配找出重复精灵体 → 该精灵体被提取为印章模板（同时从网格中移除两个副本）；剩余精灵体的位置经水平镜像计算 → 产出盖章坐标；模板在各坐标处盖章 → 多份印章若重叠则触发重涂色。

找出唯一出现两次的精灵体作为印章模板，在所有其他精灵体的水平镜像位置盖章，重叠处变为灰色。

**输入结构**：约 16x16 的黑(0)背景网格。包含 5-7 个 4-连通多色精灵体，每个精灵体由 2-4 种非背景色构成，边界框为 2x2 或 3x3。其中恰好有一个精灵体的完整彩色裁剪（含边界框内的背景像素）在网格中出现两次（位于不同位置），其余精灵体的裁剪各不相同且互不重复。生成约束：精灵体之间互不相邻（最小间隔 >= 2 像素）；非重复精灵体的水平镜像位置不与任何原始精灵体重叠。

**规则**：
1. 将每个前景精灵体裁剪到其紧致边界框（含框内背景像素），比较所有裁剪。找出恰好出现两次的那个裁剪——这就是印章模板 S。
2. 将两个 S 副本从网格中擦除（设为背景），记录模板 S 的像素图案和尺寸。
3. 对每个剩余的（非重复）精灵体，计算其边界框左上角 (r, c) 的水平镜像位置：new_c = grid_width - sprite_width - c，行 r 不变。sprite_width 为该精灵体自身边界框的宽度。
4. 在每个镜像位置，以该位置为左上角放置模板 S 的一份副本。仅在黑(0)背景像素上着色；若目标像素已被先前的盖章占据，该像素改为灰(5)。
5. 原始的非重复精灵体保留在原位不动。
6. 盖章处理顺序：按镜像位置的左上角坐标从上到下、从左到右依次盖章。

**关键洞察**：重复精灵体在源题中是输出本身，但在本题中它只是一把"钥匙"——被提取为模板后消失。盖章位置不由模板决定，而由完全不同的精灵体的镜像位置决定，形成了"选模板"和"定坐标"两个独立逻辑路径的汇合。

## 新题 3：柱状条高度算术决定菱形轮廓半径，算术正负决定轮廓颜色

**组合逻辑**：[计数 + 颜色编码正负 + 高度加减运算](已有：柱状条高度的加减) → [连线（菱形轮廓）](创新：算术结果不填入结果槽，而是转化为几何形状的半径参数) + [颜色决定操作](创新：正负号不再编码操作数符号，而是编码输出形状的颜色)

**来源原语**：计数 counting、柱状条 vertical_bar、颜色编码正负 color_encodes_sign、高度加减运算 height_arithmetic、结果槽 result_slot（参考题 37ce87bb）；菱形轮廓 diamond_outline（参考题 d753a70b）；分隔线 separator_line、矩形区域 rect_region（参考题 e3fe1151）

**依赖链**：分隔线将网格分为四个象限 → 每个象限内独立进行柱状条高度算术（青色正、红色负）→ 算术结果的绝对值成为菱形轮廓的 Manhattan 半径 → 结果的正负号决定菱形轮廓的颜色。算术、几何生成、颜色选择三步紧密串联。

在由分隔线分割的每个象限中，将青色柱状条高度之和减去红色柱状条高度之和，以绝对值为半径在象限中心画曼哈顿菱形轮廓，正值为蓝色、负值为绿色。

**输入结构**：约 21x21 的橙(7)背景网格。一条水平灰(5)分隔线和一条垂直灰(5)分隔线交叉形成十字，将网格分为四个大致相等的矩形象限（每个约 10x10）。每个象限内包含 2-3 根底部对齐的单列宽柱状条：青(8)柱状条代表正值，红(2)柱状条代表负值，高度在 1-3 之间。生成约束：每个象限内青色高度总和与红色高度总和不相等（保证结果非零）；结果绝对值不超过 4（保证菱形轮廓可在象限内完整显示）。

**规则**：
1. 识别灰(5)十字分隔线，将网格分为四个矩形象限。
2. 在每个象限内，计算 R = sum(所有青(8)柱状条的高度) - sum(所有红(2)柱状条的高度)。
3. 擦除该象限内的所有柱状条像素（设为橙(7)背景）。
4. 计算象限的中心像素：center_r = 象限顶行 + 象限高度 // 2，center_c = 象限左列 + 象限宽度 // 2。
5. 以 (center_r, center_c) 为中心，绘制 Manhattan 距离恰好等于 |R| 的菱形轮廓（即满足 |r - center_r| + |c - center_c| = |R| 的所有像素）。
6. 若 R > 0，轮廓颜色为蓝(1)；若 R < 0，轮廓颜色为绿(3)。
7. 菱形轮廓仅在当前为橙(7)背景的像素上绘制；若轮廓超出象限边界则裁切（不绘制越界部分）。
8. 灰(5)分隔线保持不变。

**关键洞察**：柱状条高度在源题中直接输出为一根结果柱，但本题将高度算术的结果转化为几何半径——数值信息从一维（高度）跨模态映射为二维（菱形轮廓面积）。正负号在源题中只区分操作数角色，在本题中它进一步编码了输出的颜色，使同一个算术结果同时携带"大小"和"类别"两层信息。

## 新题 4：瓦片阵列补全与列周期相位推断

**组合逻辑**：[补全](已有：补全缺失瓦片) + [周期推断 + 对角线相位偏移](创新：瓦片颜色不由坐标孔洞直接决定，而由跨行列的周期模式推断得出) + [孔洞位置等于坐标](已有：坐标编码)

**来源原语**：瓦片阵列 tile_array、补全 completion、分隔行列 separator_row_col、位置孔洞 position_hole、阵列坐标编码 array_coord_encoding、孔洞位置等于坐标 hole_equals_coordinate（参考题 9ddd00f0）；周期推断 periodic_inference、对角线相位偏移 diagonal_phase_shift、按列周期取色 column_modular_phase（参考题 1e97544e）

**依赖链**：已有瓦片的坐标孔洞提供其阵列位置 → 每个瓦片的填充颜色随阵列列号周期变化，行号产生相位偏移 → 该周期规则必须从多个已有瓦片跨行列对比才能推断 → 推断得出后才能确定缺失瓦片的颜色并补全。

从部分存在的彩色瓦片阵列中推断出行偏移的列周期着色规则，补全缺失的瓦片，每个瓦片在其阵列坐标处保留背景孔洞。

**输入结构**：13x13 的黑(0)背景网格。网格为 3x3 瓦片阵列，每个瓦片 3x3，瓦片之间由单像素宽的黑(0)分隔行和分隔列隔开（3*3 + 2 = 11，加上左右各 1 列边距共 13；行同理）。9 个瓦片位置中约 5-6 个已被填充——填充色为红(2)、绿(3)、蓝(1)三种之一，每个已填充瓦片内恰有一个黑(0)背景像素位于局部坐标 (tile_row, tile_col)（tile_row, tile_col 为该瓦片在阵列中的行列索引，0-indexed）。其余 3-4 个瓦片位置全为背景（缺失）。生成约束：已有瓦片的分布保证三行三列中每行至少有一个已有瓦片、每列至少有一个已有瓦片，以确保周期规则可被唯一推断。

**规则**：
1. 识别 3x3 瓦片阵列结构和分隔行列。
2. 对每个已有瓦片，通过其坐标孔洞确认其阵列位置 (r, c)，记录其填充颜色。
3. 推断着色规则：定义色板 palette = [红(2), 绿(3), 蓝(1)]，瓦片 (r, c) 的颜色 = palette[(c + r) mod 3]。该规则需通过对比不同行、不同列的已有瓦片才能归纳——单行内观察到的列周期无法区分相位偏移量。
4. 对每个缺失瓦片位置 (r, c)：用推断出的颜色 palette[(c + r) mod 3] 填充整个 3x3 区域，然后在局部坐标 (r, c) 处保留一个黑(0)背景孔洞。
5. 分隔行、分隔列和边距保持黑(0)背景。

**关键洞察**：单独看某一行的瓦片，颜色呈简单的三色循环，但行与行之间的循环起点不同——相位随行号递增。仅凭一行无法确定相位偏移方向（+1 还是 +2），必须跨行对比才能锁定规则。孔洞同时承担"坐标标签"和"视觉锚点"的双重角色。

## 新题 5：框架宽高比决定母题镜像方向，镜像后空隙以母题色循环周期填充

**组合逻辑**：[镜像 + 宽高比决定镜像轴](已有：按框架宽高比选择镜像方向) → [间隙填充 + 颜色循环](创新：间隙不由全局周期表推断，而由镜像后框架内剩余空白区域的对角位置索引 + 母题自身颜色循环共同决定)

**来源原语**：镜像 mirror、矩形框架 rectangular_frame、内部母题 interior_motif、母题在框架内 motif_inside_frame、宽高比决定镜像轴 aspect_ratio_determines_mirror_axis（参考题 18419cfa）；间隙填充 gap_filling、颜色循环 color_cycle、对角线相位偏移 diagonal_phase_shift（参考题 1e97544e）

**依赖链**：框架宽高比 → 决定镜像方向 → 镜像产生母题副本 → 母题原件 + 副本占据部分框架内部 → 剩余空白区域需要填充 → 填充颜色由母题的颜色种类按出现顺序排成循环，再由空白像素在框架内的对角位置 (local_row + local_col) 索引得到。

将框架内母题按宽高比规则镜像后，用母题自身颜色的对角周期循环填充框架内剩余空白。

**输入结构**：约 18x18 的黑(0)背景网格。包含 2-3 个蓝(1)矩形框架（单像素厚边框），宽高比各不相同（至少一个宽框、一个高框）。每个框架内部包含一个由 2-3 种非背景、非蓝色的颜色构成的小母题（3-6 个像素），母题位于框架内部的一侧（宽框中母题偏左半，高框中母题偏上半）。框架内部其余像素为黑(0)背景。框架之间互不重叠，间距 >= 2。生成约束：母题镜像后不会超出框架内部范围；每个母题至少包含 2 种不同颜色。

**规则**：
1. 识别蓝(1)框架色（非背景色中面积最大者）；其余非背景、非蓝色为母题色。
2. 对每个框架，计算其内部区域（不含边框）的宽 W 和高 H：
   - 若 W > H（宽框）：将框架内所有母题像素以内部区域垂直中轴左右镜像，镜像像素放置在对应的对称位置。
   - 若 H > W（高框）：将框架内所有母题像素以内部区域水平中轴上下镜像。
   - 若 W = H（正方框）：以垂直中轴左右镜像。
3. 镜像只添加新像素，不覆盖已有母题像素。若镜像位置已有母题像素则保持原色不变。
4. 对每个框架，按阅读序（从左到右、从上到下）扫描母题像素（原件 + 镜像件），提取各像素颜色中首次出现的不同色值，按首次出现顺序排成颜色循环列表 cycle（长度 = 母题颜色种数 K）。
5. 框架内部仍为黑(0)背景的每个像素 (r, c)（局部坐标，内部区域左上角为 (0,0)），填充为 cycle[(r + c) mod K]。
6. 框架边框保持蓝(1)，框架外部保持黑(0)。

**关键洞察**：母题承担双重功能——它既是需要镜像的视觉图案，又是间隙填充的颜色词汇表。填充规则中的对角相位 (r+c) 使得即使两个框架内的母题颜色集相同，因框架尺寸和母题位置不同，填充图案也不同。必须先完成镜像才能确定哪些位置是"间隙"，才能进行填充。

## 新题 6：重复色物体发射路径粒子，路径可达性决定单色物体的存亡与重涂

**组合逻辑**：[重复色才移动](创新：重复色物体不平移，而是发射粒子沿路径运动) + [路径模拟 + 交替转向 + 碰撞停止](已有：粒子碰壁交替转向) → [重涂色 / 擦除](创新：不按对称性分类，而按路径可达性决定——路径触及的单色物体重涂，未触及的擦除)

**来源原语**：重复色对象 repeated_color_obj、重复色才移动 repeated_color_moves（参考题 22208ba4）；路径模拟 path_simulation、交替转向 alternating_turn、碰撞停止 collision_stop、粒子 particle（参考题 195c6913）；重涂色 recolor、擦除 erase、单像素为噪声 singleton_noise（参考题 a09f6c25）

**依赖链**：颜色出现次数统计 → 识别重复色 R → 每个 R 色物体发射粒子 → 粒子按交替转向规则在网格中画出轨迹 → 轨迹的空间覆盖范围决定哪些非 R 色物体被"触及" → 被触及者重涂为 R 色，未被触及者擦除。

重复色前景物体各自发射一个沿边界反弹的粒子，粒子轨迹触及的其他颜色物体被重涂为重复色，未被触及的物体被擦除。

**输入结构**：约 16x16 的黑(0)背景网格。包含若干小型 4-连通单色前景物体（每个 3-5 像素）。其中一种颜色（如红(2)）出现为 2-3 个独立的 4-连通分量（即重复色），每个重复色物体恰好贴紧网格的一条边界（上/下/左/右，每个物体仅贴一条边）。另有 3-4 个其他颜色的物体（每种颜色仅出现一次）散布于网格内部，不贴边。生成约束：重复色物体的发射轨迹互不交叉（通过控制物体位置保证）；至少有一个非重复色物体不在任何轨迹的 4-邻接范围内（保证存在被擦除的物体）。

**规则**：
1. 统计每种非背景色的 4-连通分量数量。分量数 >= 2 的颜色为重复色 R；分量数 = 1 的颜色为单例色。
2. 对每个 R 色物体，确定其贴紧的那条网格边界。选取该物体中离网格中心最近的像素作为粒子起点（若有多个等距，选阅读序最靠前的）。粒子初始方向为垂直于所贴边界指向网格内部的方向。
3. 粒子前进时逐格绘制 R 色轨迹（覆盖背景像素）。粒子到达网格边界（下一步会越界）时进行碰壁处理：
   - 将当前像素涂为 R 色。
   - 第 1 次碰壁：逆时针转 90 度。
   - 第 2 次碰壁：顺时针转 90 度。
   - 以此交替。
   - 若转向后的方向同样会越界或撞上已有非背景像素，则粒子停止。
4. 所有粒子的轨迹全部绘制完毕后，检查每个单例色物体：若该物体的任意像素与某条 R 色轨迹像素 4-邻接，则将该物体所有像素重涂为 R 色；否则将该物体所有像素擦除为黑(0)背景。
5. 原始 R 色物体像素保持不变。

**关键洞察**：交替转向的路径几何形态决定了哪些区域被"覆盖"，而这个覆盖范围不可预测地取决于粒子起点和碰壁次数。物体的存亡不由自身属性（颜色、大小、对称性）决定，而由外部路径的空间可达性决定——这是一种几何命运。

1. 统计每种非背景色的 4-连通分量数量。分量数 >= 2 的颜色为重复色 R。
2. 将所有 R 色像素设为黑(0)背景。
3. 现在网格中只剩绿(3)笔画像素（含原本可见的 + 被遮挡后露出的碎片）和可能的单例色物体。

7. 绘制所有序列成员（包括已存在的和补全的）的绿(3)笔画。
8. 将网格中所有仍为黑(0)的像素（非绿(3)、非单例色物体）涂为灰(5)。
9. 单例色物体保持原色不变。

**关键洞察**：遮挡物不是装饰——它们系统性地隐藏了等差序列中的关键成员。擦除是推断的前提条件：不擦除就看不到完整的笔画集合，看不到就无法确定等差步长，无法确定步长就无法补全。这形成了一个严格的因果链，而非两个独立操作的串联。

## 新题 8：分隔线到种子距离偏移色板相位的曼哈顿同心菱形环

**组合逻辑**：[同心层填充（曼哈顿菱形）](创新：不用切比雪夫方环而用曼哈顿菱形环) + [色板按距离配色](创新：色板相位不由固定规则决定，而由种子到分隔线的距离动态偏移) + [分隔线](创新：不仅是空间分割器，还是相位参数的编码载体和扩展边界)

**依赖链**：色板行提供颜色词汇 → 分隔线将网格分为象限并充当扩展边界 → 每个种子到最近分隔线的 Manhattan 距离产出相位偏移量 → 同心菱形环从种子向外扩展，环色 = palette[(ring_distance + phase_offset) mod K]，碰到分隔线或网格边界即停。相位偏移使得相同环距的像素在不同种子周围呈现不同颜色。

**输入结构**：约 17x17 的黑(0)背景网格。最顶行为色板行，包含 3 个相邻的非背景像素（如红(2)、绿(3)、蓝(1)），其余位置为背景。第 2 行起为工作区域。工作区域内有一条水平灰(5)分隔线和一条垂直灰(5)分隔线交叉形成十字，将工作区域分为四个象限。每个象限中有 0 或 1 个黄(4)种子像素（总计 2-4 个种子）。生成约束：种子距离分隔线至少 2 个像素；不同种子的菱形环在各自象限内不会重叠（因分隔线截止）。

**规则**：
1. 读取色板行：从最顶行左起第一个非背景像素开始，连续读取直到遇到背景或行尾，得到 palette[0], palette[1], ..., palette[K-1]。
2. 识别灰(5)分隔十字，确定四个象限的边界。
3. 对每个黄(4)种子像素，计算其到最近灰(5)分隔线像素的 Manhattan 距离，记为 D。
4. 从种子位置向外绘制 Manhattan 同心菱形环：距离种子 Manhattan 距离为 r (r = 1, 2, 3, ...) 的像素集构成第 r 环。

   - 仅在黑(0)背景像素上着色。
   - 若环的某个像素位于分隔线上、色板行上或网格外，则跳过该像素（分隔线充当环的截止边界）。
5. 种子像素保持黄(4)不变。
6. 色板行、分隔线保持原色不变。

**关键洞察**：分隔线在本题中承担三重角色——空间分割（定义象限）、扩展边界（截止菱形环）、以及相位参数源（种子到分隔线的距离编码了色板循环的起始偏移）。两个距离分隔线不同的种子即使环半径相同，颜色也不同，这一非显然规则必须通过对比多个种子的输出才能归纳。

## 新题 10：阻挡像素间距编码尺寸阈值，联合对称分类对精灵体四分命运

**组合逻辑**：[切比雪夫距离](创新：不用于限定填充范围，而用于编码一个全局尺寸阈值参数) + [对称类型决定颜色](已有：按对称性分类) + [计数](已有：像素计数判断尺寸) → 多条件交叉判定（非流水线：对称性和尺寸是两个独立轴，它们在决策节点汇合产生四种输出类别）

**来源原语**：切比雪夫距离 chebyshev_dist、阻挡像素 blocker_pixel、近阻挡距定尺寸 blocker_dist_size（参考题 ff72ca3e）；对称轴 symmetry_axis、对称类型决定颜色 symmetry_det_color（参考题 a09f6c25）；重涂色 recolor、擦除 erase、单像素为噪声 singleton_noise、前景物体 foreground_object（参考题 a09f6c25）；计数 counting（参考题 37ce87bb）

**依赖链**：灰色阻挡像素的最近对间距 → 产出全局尺寸阈值 T；每个精灵体独立进行两项检测：(a) 是否具有反射对称性、(b) 像素数是否 <= T。两项检测结果在决策矩阵中交叉：
- 对称 + 小 → 按对称类型重涂（水平→蓝、垂直→绿）
- 对称 + 大 → 统一涂橙
- 不对称 + 小 → 统一涂黄
- 不对称 + 大 → 擦除

阻挡像素间距编码尺寸阈值，精灵体按对称性和尺寸的联合条件被分为四类，分别重涂不同颜色或擦除。

**输入结构**：约 16x16 的黑(0)背景网格。包含 5-7 个红(2)的 4-连通前景物体（精灵体），每个由 3-8 个像素构成，形状各异。部分精灵体具有水平或垂直反射对称，部分不具有任何反射对称。另有 2 个灰(5)阻挡像素散布于网格中（不与任何精灵体相邻）。可能存在 1-2 个孤立的单个红(2)像素（噪声）。生成约束：两个灰(5)像素之间的 Manhattan 距离在 4-6 之间（使阈值 T 落在精灵体像素数的分布范围内，确保两侧都有精灵体）；精灵体的像素数分布跨越阈值 T（即有些 <= T，有些 > T）。

**规则**：
1. 擦除所有孤立的单个红(2)像素（4-连通分量大小为 1），设为黑(0)。
2. 计算尺寸阈值 T：找出所有灰(5)像素，计算它们之间的最小成对 Manhattan 距离，T = 该最小距离。
3. 对每个剩余的红(2)精灵体，执行两项独立检测：
   - 对称性检测：该精灵体（在其紧致边界框内的像素图案）是否具有水平反射对称？垂直反射对称？（可能两者皆有）
   - 尺寸检测：该精灵体的像素数量是否 <= T？
4. 根据联合结果重涂：
   - 具有水平对称（无论是否也有垂直对称）且像素数 <= T → 重涂为蓝(1)
   - 仅具有垂直对称（无水平对称）且像素数 <= T → 重涂为绿(3)
   - 具有任何反射对称但像素数 > T → 重涂为橙(7)
   - 不具有任何反射对称且像素数 <= T → 重涂为黄(4)
   - 不具有任何反射对称且像素数 > T → 擦除（设为黑(0)背景）
5. 灰(5)阻挡像素保持不变。
6. 当一个精灵体同时具有水平和垂直对称时，水平对称优先（归入蓝(1)类）。

**关键洞察**：阻挡像素在源题中是填充的空间障碍，但本题中它们是一个全局参数的编码载体——其间距定义了一条"尺寸分界线"，将精灵体群体一分为二。这个分界线与对称性检测完全正交，二者在一个 2x2（加细分为 2x3）的决策矩阵中交叉。仅看单个示例可能猜测颜色取决于位置或大小，但对比多个示例会发现：相同大小的精灵体因对称性不同而颜色不同，相同对称性的精灵体因大小不同而颜色不同——两个维度必须同时锁定。
