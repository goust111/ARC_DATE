## 新题 1：射线命中计数驱动的区域循环重涂

**组合逻辑**：[射线延伸](创新：射线不再用于填充，而是作为"投票"信号命中目标区域) + [循环轮换](创新：轮换步数由射线命中次数决定，非固定角度排序) + [洪泛填充](已有：识别分离区域边界)

**来源原语**：射线延伸·缺口方向决定射线(551d5bf1), 循环轮换·环绕角度排序(880c1354), 空心矩形·边框缺口(551d5bf1), 分离区域(880c1354), 视线遮挡判断(3490cc26)

**依赖链**：缺口方向决定射线的发射路径 → 射线是否命中某个分离区域取决于路径上有无遮挡（视线遮挡判断）→ 每个区域被命中的总次数决定其颜色循环轮换的步数 → 颜色循环的基序列由区域的空间角度排序确定

将框体缺口发出的射线视为投票信号：每条射线穿越空旷背景直至命中某个色块区域或抵达网格边缘；每个区域累计被命中次数后，按该次数在角度排序的颜色环上前进相应步数，获得新颜色。

**输入结构**：约 18x18 网格，黑(0)背景。网格中散布 3~5 个蓝(1)单像素宽空心矩形框（边框 4~8 像素长，内部为黑(0)），每个框在某一侧边框上恰有一个缺口（缺失一个非角像素）。框之间互不接触、互不重叠。网格中另有 3~5 个单色 4-连通实心色块区域（每个 3~6 像素，颜色各不相同，取自红(2)、绿(3)、黄(4)、灰(5)、品红(6)），各区域互不相邻且不与任何框接触。生成约束：每个框的缺口朝外方向至少可到达一个色块区域或网格边缘；至少两个不同的框射线命中同一个区域。

**规则**：
1. 对每个蓝(1)空心矩形框，找到其唯一缺口所在的边（上/下/左/右）。从缺口位置向该边的法线外方向发射一条单像素宽射线（若缺口在左边框则向左，在右边框则向右，在上边框则向上，在下边框则向下）。射线沿途涂为橙(7)，遇到第一个非黑(0)非橙(7)像素时停止（不覆盖该像素），若先抵达网格边缘则止于边缘。
2. 识别所有非蓝(1)非橙(7)的 4-连通单色区域。对每个区域，统计被多少条射线"命中"——若某条射线的终点紧邻（4-连通）该区域的某个像素，则计为命中一次。记该区域的命中次数为 h。
3. 将所有被命中的区域按其质心到网格中心的角度排序（以网格中心为原点，正右方为 0 度，顺时针递增；角度相同时质心离中心近的排在前）。按此顺序排列它们的原始颜色，形成循环颜色序列 C。
4. 对序列 C 中的每个区域，将其颜色替换为序列 C 中向后第 h 步的颜色（h 为该区域自身的命中次数，按循环取模）。未被任何射线命中的区域颜色不变。
5. 蓝(1)框体像素和橙(7)射线像素均保留在输出中。

**关键洞察**：射线不是用来填充空间的，而是一种"投票"机制——每条射线为它命中的区域贡献一个计数，而这个计数决定了该区域在颜色环上前进多少步；必须同时理解射线路径（含遮挡）和循环轮换机制才能求解。

## 新题 2：边界标记点编码内部对象的滑动向量

**组合逻辑**：[周期填充·周期检测](创新：不用于填充，而是提取周期间距作为滑动步长) + [滑动](创新：方向和步长均由边界标记编码，而非固定一步) + [编码映射](创新：标记颜色映射为方向，标记间距映射为距离)

**来源原语**：周期步长·边界点(16de56c4), 滑动·固定步长平移(25ff71a9), 编码映射(7ed72f31), 同余对齐·周期(16de56c4), 方向(25ff71a9)

**依赖链**：边界点的颜色编码滑动方向 → 同色边界点的周期间距编码滑动步长 → 内部对象与边界点的行列对齐关系决定该对象受哪个标记控制 → 对象按解码后的向量滑动

网格四边散布彩色标记点，同色标记点在同一边上以固定间距重复出现；标记颜色编码滑动方向，同色标记间的间距编码滑动步长；内部小对象与某边标记对齐（共享行或列），按对齐标记解码出的方向和步长滑动。

**输入结构**：约 15x15 网格，黑(0)背景。网格的恰好一条边（上、下、左或右之一，需从示例中归纳）上分布若干彩色标记点（非黑单像素），其余三条边上无标记。标记点有 2~3 种颜色（取自红(2)、绿(3)、黄(4)），每种颜色在该边上恰好出现 2 个像素，两像素间距即为该颜色的步长 s。网格内部有 2~4 个单色 4-连通小图形（3~5 像素，颜色为灰(5)），每个图形的质心行或列（取决于标记所在边是水平边还是垂直边）与某个标记点对齐（差值不超过 1 像素）。生成约束：每个内部对象恰好与一个标记颜色对齐；滑动后对象不重叠、不出界。颜色到方向的映射在所有示例中一致，但需对比多个示例归纳（例如红(2)=向右、绿(3)=向下、黄(4)=向左，具体映射由示例决定）。

**规则**：
1. 确定标记所在的唯一网格边。若标记在上边或下边（水平边），则每个标记的"对齐坐标"为其列号；若在左边或右边（垂直边），则为其行号。
2. 对标记边上的每种颜色，找到该颜色的 2 个标记点，计算它们在沿边方向上的间距，记为该颜色的步长 s。
3. 对每个内部灰(5)对象，找到与其质心对齐坐标最近的标记点，确定该标记的颜色 c 和步长 s_c。
4. 根据颜色 c 查找方向映射（从示例中归纳），获得滑动方向 d。
5. 将该对象沿方向 d 整体平移 s_c 个像素。平移后原位置恢复为黑(0)。
6. 标记点本身在输出中保留不变。

**关键洞察**：边界标记点不是要被填充的种子（与参考题 16de56c4 不同），而是一套编码系统——颜色编码方向，间距编码步长；必须同时破解编码规则和对齐关系才能确定每个对象的运动。

## 新题 3：缺口朝向决定框内操作类型

**组合逻辑**：[平铺](已有：水平周期平铺) ⊕ [镜像](已有：垂直轴镜像) ← [缺口方向决定射线](创新：缺口方向不再决定射线，而是决定对框内图案执行平铺还是镜像) + [射线延伸](已有：缺口向外发射射线，颜色由变换结果决定)

**来源原语**：平铺·周期(963e52fc), 镜像·对称(c35c1b4c), 缺口方向决定射线(551d5bf1), 空心矩形·边框缺口(551d5bf1), 边界包围内部(62b74c02), 周期图案(963e52fc)

**依赖链**：缺口所在边的方向决定对框内图案执行哪种操作（条件分支）→ 操作结果填满框内部 → 填充后框内的主色决定从缺口外射的射线颜色 → 射线从缺口向外延伸直至遇障碍或边缘

在每个框体内放置一小块种子图案；框体的缺口位于水平边时，将种子沿垂直轴镜像后填入框内；缺口位于垂直边时，将种子沿水平方向周期平铺填入框内；然后从缺口向外发射一条射线，射线颜色为框内变换后出现次数最多的前景色。

**输入结构**：约 16x16 网格，黑(0)背景。网格中有 2~4 个蓝(1)单像素宽空心矩形框，每个框内部宽高均至少 3 像素。每个框恰好有一个缺口（一个非角的边框像素缺失）。框内左上角区域有一小块种子图案（2~3 像素宽，高度等于框内高度或宽度等于框内宽度，具体取决于缺口方向），种子颜色取自红(2)、绿(3)、黄(4)中的 1~2 种，剩余框内为黑(0)。框之间互不重叠，彼此间距至少 2 像素。生成约束：至少有一个框缺口在水平边、至少一个在垂直边，以确保两种操作都出现。

**规则**：
1. 对每个蓝(1)框，判断缺口所在边是水平边（上或下）还是垂直边（左或右）。
2. 若缺口在垂直边（左或右）：框内种子图案占据内部最左侧若干列，其宽度 w 为种子的列数。以 w 为水平周期，将种子向右重复平铺直至填满整个框内部（最后一个周期若超出则在框内右边界处裁剪）。
3. 若缺口在水平边（上或下）：框内种子图案占据内部最上方若干行，其高度 h 为种子的行数。将种子关于其底边做垂直镜像，得到种子+镜像拼合体（高度 2h-1，共享中间行），再以此拼合体为单元向下重复平铺填满框内部（最后一个周期若超出则在框内下边界处裁剪）。
4. 变换完成后，统计每个框内部非黑(0)像素中出现次数最多的颜色，记为该框的主色 mc（若出现次数相同，取在框内部从上到下从左到右扫描时最先出现的颜色）。
5. 从每个框的缺口位置，沿缺口朝外方向发射一条 1 像素宽射线，涂为 mc 色。射线遇到第一个非黑(0)像素时停止（不覆盖该像素），若先到网格边缘则止于边缘。
6. 蓝(1)框体像素保持不变。

**关键洞察**：缺口的朝向不仅决定射线的发射方向，更根本地决定了对框内种子执行哪种几何操作——仅看单个示例可能恰好只有一种缺口方向，必须对比包含两种方向的示例才能归纳出这一条件分支规则。

## 新题 4：走廊动态遮挡下的贪心路径着色

**组合逻辑**：[贪心遍历](创新：每一步绘制的走廊会遮挡后续步骤的视线，使路径依赖于执行顺序) + [连线·走廊路径](已有) + [洪泛填充](创新：框内填充色取决于通向该框的走廊方向)

**来源原语**：贪心遍历·最近未访问优先(3490cc26), 连线·走廊路径(3490cc26), 视线遮挡判断(3490cc26), 洪泛填充(551d5bf1), 空心矩形(551d5bf1), 同行同列对齐(3490cc26), 方向(25ff71a9)

**依赖链**：贪心选择最近可见框 → 绘制走廊 → 走廊像素成为后续步骤的遮挡物，改变哪些框可见 → 到达框的走廊方向（水平或垂直）决定框内填充颜色 → 不可达的框不填充

从红色起点出发，贪心遍历灰色空心矩形框；每步绘制的橙色走廊会遮挡后续的视线通道，因此路径是动态决定的；每个被到达的框根据走廊抵达方向（水平到达填绿，垂直到达填黄）填充内部。

**输入结构**：约 17x17 网格，黑(0)背景。一个红(2) 2x2 实心起始块。4~6 个灰(5)单像素宽空心矩形框（内部宽高均至少 2，内部为黑(0)）。框的外边界框中心在某些行或列上与起始块或其他框对齐（共享至少 2 行或 2 列的带状区域）。框之间互不接触。生成约束：在静态视线下（忽略走廊遮挡），从起始块可达至少 4 个框；但在动态遮挡下（走廊阻挡视线），至少有 1 个框因被中间走廊遮挡而无法到达。

**规则**：
1. 当前位置初始化为红(2)起始块。
2. 在当前位置的 2 行宽或 2 列宽带状视野中，寻找所有尚未访问的灰(5)框。"可见"定义：当前块与目标框在同一个 2 行或 2 列的带状区域内，且两者之间的所有像素均为黑(0)——任何非黑像素（包括之前步骤绘制的橙(7)走廊像素和其他灰(5)框的边框像素）都会遮挡视线。
3. 从可见的未访问框中选择距离最近的一个（距离为当前块边缘到目标框边缘沿对齐方向的像素数；距离相同时选同一行/列带中靠上或靠左的框）。
4. 将当前块与选中框之间的所有黑(0)像素涂为橙(7)，形成走廊。记录走廊方向：若走廊沿行方向绘制则为"水平"，沿列方向则为"垂直"。
5. 根据走廊方向填充目标框内部：水平到达的框内部填绿(3)，垂直到达的框内部填黄(4)。
6. 将当前位置更新为目标框，重复步骤 2-5，直到无可见未访问框为止。
7. 未被到达的框保持原样（内部为黑(0)）。红(2)起始块和灰(5)框体像素均保留。

**关键洞察**：与参考题 3490cc26 中在静态网格上规划路径不同，这里每一步走廊的绘制都动态改变了后续的可视图——同样的框布局，若第一步选择了不同的最近框，后续路径可能完全不同；必须逐步模拟走廊绘制才能确定最终结果。

## 新题 5：对称修复揭示隐藏引导色

**组合逻辑**：[对称补全](已有：修复被遮挡像素) → [重涂色](创新：修复后暴露出的特殊颜色像素充当引导色，决定其所在区域的重涂颜色) + [擦除](创新：引导像素在完成颜色转移后自身被擦除)

**来源原语**：对称补全·遮挡像素·对称轨道(f9d67f8b), 重涂色·引导像素(aabf363d), 擦除(aabf363d), 角落色转移后消(aabf363d), 反射旋转定颜色(f9d67f8b), 分离区域(880c1354)

**依赖链**：遮挡色隐藏了部分对称图案 → 对称修复还原真实图案 → 修复后某些位置出现了一种在修复前未见的新颜色（引导色）→ 引导色像素所在的连通区域被整体重涂为引导色 → 引导色像素本身被擦除为背景色，仅保留重涂效果

修复一个被损坏的对称图案后，某些修复位置会"显现"出一种原本被隐藏的引导颜色；该颜色指示其所在区域应重涂为何色，随后引导像素自身消失。

**输入结构**：约 12x12 方形网格。网格包含一个以网格中心为对称中心的图案，使用 2~3 种前景色（取自蓝(1)、绿(3)、黄(4)）绘制在黑(0)背景上。图案同时具有水平和垂直反射对称性（未被遮挡时）。若干像素被栗(9)色覆盖（遮挡色），遮挡了原始图案。在被遮挡的像素中，大部分的真实颜色可由对称轨道中的可见像素唯一确定。其中 1~2 个被遮挡位置的真实颜色为红(2)——这是"引导色"，仅在对称修复后才出现（输入中不存在任何红(2)像素）。前景图案自然地将网格分割为若干 4-连通黑(0)背景区域。每个引导色像素恰好 4-连通邻接一个这样的背景区域。生成约束：每个背景区域至多被一个引导像素邻接；引导色的对称轨道中至少有一个非遮挡像素可用于确定其颜色。

**规则**：
1. 识别栗(9)为遮挡色（它是唯一一种移除后能使剩余图案具有关于网格中心的水平和垂直反射对称性的颜色）。
2. 对每个栗(9)像素，在其水平反射、垂直反射和 180 度旋转的对称位置中寻找非栗(9)像素，用找到的颜色替换该栗(9)像素。若多个对称位置给出颜色，它们必须一致（由生成约束保证）。
3. 修复完成后，找到所有红(2)像素——这些是引导像素。对每个红(2)引导像素，找到其 4-连通邻域中唯一的黑(0)背景连通区域 R。
4. 将区域 R 中的所有像素重涂为红(2)。
5. 最后，将所有原本为引导像素的位置（步骤 3 中识别的红(2)像素）擦除为黑(0)。

**关键洞察**：对称修复不仅是目的本身，更是揭示隐藏信息的手段——引导色被刻意编码在遮挡像素之下，只有完成对称修复后才能知道哪些区域需要重涂；引导色的"出现后自毁"机制需要对比修复前后的状态才能理解。

## 新题 6：最大对象裁剪为原型按阶梯骨架拉伸

**组合逻辑**：[裁剪·选取最大面积对象](已有：按面积选取) → [延伸填充·距离控制高度](创新：最大对象的边界框宽度决定阶梯的步进量) → [拉伸·顶点坐标映射](创新：阶梯顶端作为骨架锚点，裁剪出的对象作为原型拉伸上去)

**来源原语**：裁剪·选取最大面积对象·面积比较(be94b721), 延伸填充·距离控制高度·不对称递变(5207a7b5), 拉伸·顶点坐标映射·行列独立拉伸(b0f4d537), 连通分量(be94b721), 纵条·侧翼列(b8cdaf2b), 稀疏骨架锚点(b0f4d537)

**依赖链**：面积比较选出最大对象 → 裁剪得到紧凑原型 → 原型的边界框宽度 w 决定纵条的阶梯步进量（每列高度差 = w）→ 阶梯顶端坐标构成骨架锚点行列 → 原型被拉伸映射到骨架锚点上

三角依赖：裁剪结果（原型）决定了拉伸的内容和阶梯的参数；阶梯的几何形状决定了拉伸的目标骨架；三者缺一不可。

**输入结构**：约 20x20 网格，黑(0)背景。网格分为左右两个区域，由一列灰(5)像素分隔。左侧区域包含 3~5 个不同颜色的 4-连通单色前景对象（每个 3~10 像素，颜色取自蓝(1)、红(2)、绿(3)、黄(4)、品红(6)），其中恰好一个对象面积最大（唯一最大）。右侧区域底行有一排橙(7)色条（连续的橙(7)像素，占据底行的若干连续列），色条上方每一列有一个青(8)像素点，各列青(8)点的行位置不同：距色条左端第 d 列（从 0 开始计）的青(8)点位于从底行向上第 (d * w + 1) 行的位置，其中 w 为左侧最大对象的边界框宽度。右侧区域除了底行橙(7)色条和各列青(8)点外均为黑(0)。生成约束：右侧色条的列数等于左侧最大对象边界框中有前景像素的行数（即原型的有效行数）；右侧各列青(8)点的行位置严格递增。

**规则**：
1. 在左侧区域找到面积最大的 4-连通单色前景对象，裁剪出其最小边界框作为紧凑原型 P（边界框内非该对象的像素视为透明/黑(0)）。记 P 的宽度为 w，高度为 h。
2. 在右侧区域，将各列青(8)点的位置作为骨架锚点。将 P 的各行（从上到下第 0 行到第 h-1 行）映射到右侧各列（从色条左端开始第 0 列到第 h-1 列）。
3. 对 P 的每一行 r（r = 0, 1, ..., h-1），将该行的前景像素水平拉伸后垂直放置：取右侧第 r 列，从该列的青(8)锚点位置向下到橙(7)色条顶部的区间，用 P 第 r 行的颜色序列（按列顺序）均匀映射填入。具体方法：将 P 第 r 行的 w 个像素均匀分配到该列的垂直区间中（区间长度 L_r = d_r * w，其中 d_r 为该列的阶梯索引），每个原型像素纵向重复 d_r 次；若原型像素为黑(0)/透明则对应位置保持黑(0)。
4. 左侧区域所有内容保持不变。灰(5)分隔列保持不变。橙(7)色条和青(8)锚点保持不变。

**关键洞察**：三个操作形成三角依赖而非线性流水线——裁剪结果同时决定了"拉伸什么"和"阶梯步进多大"，而阶梯的几何形状又决定了"拉伸到哪里"；单独理解任何两个步骤都无法推出第三个。

## 新题 7：环形区域交换内部图案并几何适配

**组合逻辑**：[循环轮换](创新：不再轮换纯色，而是轮换区域内部的图案) + [裁剪](已有：提取每个区域内部图案) + [拉伸](创新：将图案从一个区域形状适配到下一个区域形状)

**来源原语**：循环轮换·环绕角度排序(880c1354), 分隔结构·分离区域(880c1354), 裁剪(be94b721), 拉伸·行列独立拉伸(b0f4d537), 顶点坐标映射(b0f4d537)

**依赖链**：角度排序确定区域的循环顺序 → 每个区域的内部图案被裁剪提取 → 图案按循环顺序移交给下一个区域 → 接收的图案按目标区域的边界框做行列独立拉伸以适配新形状

分隔结构周围的区域各自包含小图案；按角度顺序，每个区域将自己的图案传递给下一个区域，接收到的图案需拉伸到新宿主区域的边界框尺寸。

**输入结构**：约 15x15 网格，黑(0)背景。网格中央有一个由黄(4)和橙(7)像素构成的十字形或 T 形分隔结构（总计 8~15 像素），将网格分割为 3~4 个独立的黑(0)背景区域。每个区域内有一个小型多色图案（2x2 到 3x3 的边界框，使用蓝(1)、红(2)、绿(3)、灰(5)、品红(6)中的 2~3 种颜色），图案不接触分隔结构也不接触网格边缘。各区域的边界框尺寸各不相同（例如一个较宽较矮，另一个较窄较高）。生成约束：分隔结构的质心近似位于网格中心；各区域面积至少为 4x4 以容纳拉伸后的图案。

**规则**：
1. 识别黄(4)和橙(7)构成的分隔结构，将其像素标记为不可修改。
2. 以分隔结构的质心为原点，计算每个背景区域的质心相对于原点的角度（正右方 0 度，顺时针递增）。按角度从小到大排列区域，得到循环序列 R_0, R_1, ..., R_{n-1}。
3. 对每个区域 R_i，提取其内部图案的最小边界框，记为 P_i（边界框宽 w_i，高 h_i）。
4. 按循环轮换：区域 R_i 接收图案 P_{(i-1) mod n}（即前一个区域的图案）。
5. 将接收到的图案 P_{(i-1) mod n} 拉伸适配到 R_i 的可用空间：确定 R_i 中原图案 P_i 所占的边界框位置和尺寸（宽 w_i，高 h_i），将来源图案 P_{(i-1) mod n}（原宽 w_{i-1}，原高 h_{i-1}）做行列独立拉伸——水平方向缩放比为 w_i / w_{i-1}，垂直方向缩放比为 h_i / h_{i-1}，使用最近邻插值（目标像素 (r, c) 对应源像素 (floor(r * h_{i-1} / h_i), floor(c * w_{i-1} / w_i))）。拉伸后的图案放置在 R_i 中原图案 P_i 的边界框位置。
6. 分隔结构像素和网格边缘外的像素不变。

**关键洞察**：与参考题 880c1354 中仅轮换纯色标签不同，这里轮换的是完整的二维图案，而各区域形状不同迫使图案必须做几何适配——循环轮换确定"谁的图案去哪"，拉伸解决"怎么放进去"，两者缺一不可。

## 新题 8：镜像与周期平铺的同时约束求解

**组合逻辑**：[镜像](创新：不是执行镜像操作，而是"输出必须满足镜像对称"作为约束) ⊗ [平铺](创新：不是执行平铺操作，而是"输出必须满足周期重复"作为约束) + [填充](已有：用满足双重约束的唯一颜色填入空白格)

**来源原语**：镜像·对称(c35c1b4c), 平铺·周期(963e52fc), 填充(e88171ec), 对称轨道(f9d67f8b), 周期图案(963e52fc), 宽度加倍延续周期(963e52fc)

**依赖链**：同时满足两个约束而非顺序执行两个操作 → 水平周期性决定了某些像素必须与周期偏移处同色 → 垂直对称性决定了某些像素必须与垂直镜像处同色 → 两个约束的传递闭包唯一确定每个空白格的颜色

输入网格局部给出了少量彩色像素和大量空白（黑色）格；输出中每个空白格必须同时满足水平周期约束和垂直对称约束，且所有约束的联合使得每个空白格的颜色唯一确定。

**输入结构**：约 12x10 网格（宽 > 高），黑(0)背景。网格中散布 8~15 个非黑前景像素（使用蓝(1)、红(2)、绿(3)、黄(4)中的 2~3 种颜色），其余为黑(0)。网格宽度 W 可被某个周期 p 整除（p 为 3 或 4），即 W = k * p（k >= 2）。网格具有一条垂直对称轴，位于网格水平中线（列索引 (W-1)/2 处，W 为奇数时恰好居中；W 为偶数时轴在两列之间）。前景像素的分布满足：对任意前景像素位于 (r, c)，位置 (r, c mod p) 定义了"周期等价类"，(r, W-1-c) 定义了"对称等价类"；在两种等价关系的传递闭包下，每个等价类内至少有一个前景像素提供颜色约束，且类内所有前景像素同色（无矛盾）。生成约束：前景像素的数量足以使每个空白格的颜色被唯一确定；前景像素之间无颜色矛盾。

**规则**：
1. 确定水平周期 p：p 是满足以下条件的最小正整数——对所有非黑像素 (r, c)，若 (r, c+p) 在网格内且非黑，则两者同色。
2. 确定垂直对称轴位于列 (W-1)/2 处（W 为网格宽度）。
3. 对每个黑(0)位置 (r, c)，沿周期方向寻找同周期等价类（列号 c, c+p, c-p, c+2p, ...，均取模后在 [0, W) 内的位置）和对称等价类（行相同、列为 W-1-c 的位置及其周期等价类）中已有颜色的前景像素。
4. 通过传递闭包（周期等价 + 对称等价的交替应用），确定 (r, c) 的唯一颜色，填入该颜色。
5. 所有原有前景像素保持不变。

**关键洞察**：这道题不是"先做镜像再做平铺"或反过来，而是两个约束同时生效的约束满足问题——求解者必须理解周期等价和对称等价如何通过传递闭包相互传播颜色信息，仅用其中一个约束会留下无法确定的空白格。
