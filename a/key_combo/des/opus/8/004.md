## 新题 1：十字源点周期射线

**组合逻辑**：[模式检测](已有，从检测十字改为以十字为射线发射源) → [射线延伸](已有，从间隙填充改为从检测到的十字中心发射) → [重涂色·周期](创新，射线像素按距离做周期性三色循环)

**来源原语**：模式检测·邻域全匹配(1818057f), 射线延伸(d968ffd4), 周期内指定位变色(d304284e), 碰撞停止(9bbf930d)

**依赖链**：十字检测的输出确定射线起点坐标和发射条件——只有被判定为十字中心的像素才发射射线；射线延伸的长度决定周期着色的像素总数；多条射线可能交叉，冲突解决规则依赖射线源的空间位置比较。三步缺一不可：无检测则无源点，无射线则无载体，无周期着色则无法区分不同射线。

从包含十字图案的前景中发射四向射线，射线像素按距离做三色周期循环，多射线交叉时按源点位置优先。

**输入结构**：约 15x15 网格，黑(0) 背景。黄(4) 前景像素构成若干 4-连通区域，形态各异（不规则斑块、折线、小团簇等，3~12 像素不等）。部分区域内部自然形成"+"十字结构：存在一个黄像素使其上下左右四个正交邻居均为黄像素。不同示例中十字数量不同（1~3 个），非十字区域的形态也不同。网格中无其他非背景色。生成约束：任意两个十字中心之间至少间隔 4 个像素；每个十字中心的四条射线方向上至少有 2 格背景空间。

**规则**：
1. 检测所有"+"十字中心：一个黄(4)像素，其上、下、左、右四个正交邻居均为黄(4)。
2. 从每个十字中心向上、下、左、右四个方向各发射一条射线。射线从十字臂端点的下一个像素开始（即跳过十字本身的 5 个像素），沿该方向逐像素延伸。射线遇到非背景像素或网格边界时停止，停止位置的像素不着色。
3. 对每条射线的像素按离十字中心的距离（从近到远）编号 1, 2, 3, ...。编号对 3 取余：余 1 涂绿(3)，余 2 涂蓝(1)，余 0 涂红(2)。
4. 若两条来自不同十字中心的射线在同一像素交叉，保留行索引更小的十字中心的射线颜色；行索引相同时保留列索引更小的。
5. 原始黄(4)前景像素保持不变。

**关键洞察**：十字检测不仅是标记，而是作为射线发射器的入场条件——非十字区域的黄像素不参与任何射线操作。周期着色的三色序列和周期长度（3）必须通过对比不同长度的射线才能归纳，单个短射线可能恰好只展示一两种颜色。

## 新题 2：色彩离群体嵌孔印章

**组合逻辑**：[筛选·异常值选择](已有，从裁剪输出改为确定印章源) → [形状匹配·旋转](已有，从标记重涂改为确定嵌入位置和姿态) → [印章覆盖](已有，从骨架传递改为将离群体嵌入孔洞)

**来源原语**：筛选·异常值选择·颜色多样性比较(9a4bb226), 形状匹配·旋转平移嵌入(1acc24af), 印章覆盖(36d67576), 擦除(fd02da9e), 孔洞(228f6490)

**依赖链**：异常值选择决定哪个对象成为印章源（而非输出本身）；形状匹配的旋转搜索依赖已确定的印章源形状；印章覆盖的目标位置由匹配结果决定。去掉异常值选择→不知道用哪个对象；去掉形状匹配→不知道嵌入哪个孔洞和用什么旋转；去掉印章操作→无输出变化。

在多个小对象中找出颜色最丰富的离群体，将其旋转嵌入上方结构体中形状匹配的孔洞。

**输入结构**：约 18x18 网格，黑(0) 背景。上半区：一个灰(5) 4-连通矩形结构体（约 10x6），内部有 2~3 个黑色孔洞，每个孔洞是 3~6 像素的 4-连通区域，形态各异（非矩形，如 L 形弯折、阶梯状等）。下半区：3~4 个互不相邻的小型 4-连通对象，每个 3~6 像素，由非灰非黑颜色构成。其中大多数对象使用 2 种颜色，恰好一个对象使用 3 种颜色（离群体）。不同示例中离群体的位置、颜色组合和形状均不同。生成约束：离群体的像素掩码恰好与某一个孔洞的掩码在某个旋转（0/90/180/270度）下全等；其余对象的掩码不与任何孔洞匹配。

**规则**：
1. 统计下半区每个小对象使用的不同颜色数量（仅计非背景色）。选出颜色数最多的唯一对象作为"离群体"（生成保证唯一）。
2. 将离群体的像素掩码依次尝试 0/90/180/270 度旋转，与上半区结构体内每个孔洞的掩码做全等比较。找到唯一匹配的孔洞和旋转角度。
3. 将离群体按匹配旋转角度变换后，平移至匹配孔洞的位置，用离群体的原始颜色填充孔洞对应像素（覆盖原来的黑色）。
4. 擦除离群体在下半区的原始位置（恢复为背景色）。
5. 其余非离群体的小对象和灰色结构体保持不变，未匹配的孔洞保持黑色。

**关键洞察**：选择标准（颜色多样性）和放置标准（形状匹配）是两个独立维度的判断——颜色多的不一定是最大的，形状匹配需要尝试旋转。求解者必须先从颜色维度筛选对象，再从几何维度确定位置，两步判断缺一不可且互不替代。

## 新题 3：线段排序生成递变楔形栈

**组合逻辑**：[排序·最高行定序](已有) → [计数·保留面积](已有，从拉直改为确定楔形底宽) → [填充·距离递变](已有，从双侧楔形改为单向递减楔形的堆叠)

**来源原语**：排序·最高行决定序(668eec9a), 计数·保留颜色与面积(dce56571), 填充·距离递变·逐行宽度递变成楔(a65b410d)

**依赖链**：排序输出的序列决定楔形的垂直堆叠顺序；计数结果决定每个楔形的底边宽度；递变填充将每个计数值展开为具体的三角形态。删除排序→楔形堆叠顺序不确定；删除计数→楔形宽度不确定；删除递变填充→无法从宽度值生成几何输出。

将不同颜色的线段按垂直位置排序，以各自长度为底宽生成递减三角楔形，自上而下堆叠输出。

**输入结构**：约 12x20 网格，黑(0) 背景。3~5 条单像素宽的彩色线段，每条线段是水平或竖直的连续像素段，颜色各不相同（从蓝(1)、红(2)、绿(3)、黄(4)、灰(5) 中选取）。每条线段占据不同的行范围（竖直线段）或位于不同行（水平线段），长度 3~8 像素不等。不同示例中线段数量、颜色、长度和朝向均可变化。生成约束：任意两条线段的最高行（线段占据的最小行号）互不相同。

**规则**：
1. 对每条线段，记录其颜色和像素总数（长度），以及其最高行号（占据的最小行索引）。
2. 按最高行号从小到大对线段排序。
3. 构造输出网格（宽度 = 输入网格宽度，高度按需确定）。从输出网格第 0 行开始，按排序顺序依次为每条线段生成一个左对齐的三角楔形：
   - 楔形第一行（顶行）宽度等于该线段的像素总数，全部填充该线段的颜色。
   - 每向下一行，宽度减少 1 像素，仍左对齐，仍用同一颜色填充。
   - 宽度减至 1 后该楔形结束。
4. 下一个楔形紧接上一个楔形的最后一行之下（无间隔行），继续向下生长。
5. 原始线段不出现在输出中——输出仅包含生成的楔形栈。

**关键洞察**：每条线段的空间位置（最高行）只决定输出中楔形的排列顺序，而线段的像素数量决定楔形的大小（底宽和高度均等于像素数）。两个独立属性——位置和面积——分别控制输出的不同方面，必须对比多个示例才能区分"位置决定顺序"和"面积决定形状"这两条规则。

## 新题 4：象限旋转补全后透明叠合

**组合逻辑**：[旋转·骨架对齐](已有，从全局motif改为在象限内做锚点对齐旋转) → [印章覆盖·完整标注传递](已有) → [透明叠加·层级优先](已有，从直接叠加改为叠加已补全的象限)

**来源原语**：旋转·骨架对齐(36d67576), 印章覆盖·完整标注传递副本(36d67576), 透明叠加·非背景优先合并(a68b268e), 象限区·分隔十字(a68b268e), 锚点像素(36d67576)

**依赖链**：旋转对齐必须先于印章传递（否则标注像素位置错误）；印章传递必须先于象限叠合（否则叠合时信息不完整，某些象限缺少标注，叠合结果会遗漏像素）。三步构成严格的时序依赖。

四个象限各含一个带锚点的骨架图案，其中一个象限有完整标注；先通过锚点对齐将标注旋转传递到其余三个象限，再将四个已补全象限叠合成单一输出。

**输入结构**：约 17x17 网格。一行灰(5)像素和一列灰(5)像素构成分隔十字，将网格分为四个 8x8 象限（分隔行列本身不属于任何象限）。每个象限包含：若干蓝(1)像素构成的 4-连通骨架图案（3~8 像素，形态不规则），以及恰好一个红(2)锚点像素。四个象限的骨架形态相同但可能经过 0/90/180/270 度旋转。恰好一个象限除了蓝骨架和红锚点外，还包含绿(3)和/或黄(4)的标注像素（此象限称为"完整象限"）。生成约束：四个象限的骨架+锚点之间存在唯一的旋转映射关系（即给定任意两个象限，恰好一个旋转角度使骨架和锚点同时对齐）。

**规则**：
1. 识别完整象限（包含绿(3)或黄(4)标注像素的象限）。
2. 对其余三个不完整象限，分别找到将完整象限的蓝骨架+红锚点映射到该象限骨架+锚点的唯一旋转角度（0/90/180/270 度，旋转中心为 8x8 象限的中心）。
3. 将完整象限中所有标注像素（绿和/或黄）施加相同旋转，平移到对应象限的局部坐标中，写入该象限。蓝骨架和红锚点不受影响。
4. 现在四个象限均已补全。将它们叠合成一个 8x8 输出网格：对每个像素位置，依次检查左上、右上、左下、右下象限对应位置的值，取第一个非背景(非0)的颜色作为输出；若四个象限该位置均为背景，则输出背景(0)。
5. 分隔十字不出现在输出中。

**关键洞察**：如果跳过标注传递直接叠合，不完整象限在叠合中会"留空"，导致输出缺少某些标注像素。旋转传递和叠合的优先级规则共同决定最终输出——某些标注像素可能在叠合中被更高优先级象限的骨架像素覆盖，这种遮挡效果是两步交互的涌现结果。

## 新题 5：贪心房间占领与走廊对半染色

**组合逻辑**：[区域提取·贪心选择](已有，从纯着色改为确定房间身份和颜色) → [射线延伸·间隙对半分](已有，从矩形间隙改为走廊连接段的对半染色)

**来源原语**：区域提取·贪心选择·从大到小优先(31adaf00), 最小边长约束·非重叠约束(31adaf00), 射线延伸·间隙对半分·奇数间隙留中线(d968ffd4)

**依赖链**：贪心选择决定哪些区域成为"房间"以及它们的颜色（按占领顺序分配）——这是走廊对半染色的前提条件，因为走廊两端的颜色取决于相邻房间的颜色。删除贪心选择→房间不确定，无法确定走廊端色；删除对半染色→房间着色完成但走廊空白，信息不完整。

在障碍像素构成的迷宫中，贪心占领最大的空白方形房间并按序着色，再将相邻房间之间的走廊对半染上两端房间的颜色。

**输入结构**：约 20x20 网格，黑(0) 背景，灰(5) 障碍像素。障碍像素构成不规则的墙壁和隔断，将黑色区域分割为若干不同大小的开阔空间和窄走廊。开阔空间中可以找到边长 >= 2 的全黑正方形区域；走廊是宽度为 1 的黑色通道。不同示例中障碍布局不同，房间数量 3~5 个，走廊连接方式各异。生成约束：每对相邻房间（各自最近边之间仅隔一条宽度为 1 的水平或竖直走廊连通）之间恰好有一条直线走廊段；走廊段与两端房间的连接点在同一行或同一列上。

**规则**：
1. 在网格中搜索所有完全由黑(0)像素组成的正方形区域（边长 >= 2）。
2. 按边长从大到小排序。依次尝试占领每个正方形：如果它与任何已占领的正方形有像素重叠，则跳过；否则占领它。
3. 按占领顺序为房间分配颜色：第一个占领的涂蓝(1)，第二个涂红(2)，第三个涂绿(3)，第四个涂黄(4)，第五个涂品红(6)。将占领区域内所有像素涂为对应颜色。
4. 对每对相邻房间（通过宽度为 1 的直线走廊段连通的两个已占领房间），找到连接它们的走廊段。走廊段是两个房间边界之间沿同一行或同一列的连续黑色像素序列。
5. 将走廊段对半染色：靠近一端房间的那一半像素涂为该房间的颜色，靠近另一端房间的那一半涂为另一端的颜色。若走廊段长度为奇数，中间那个像素保持黑(0)背景不变。
6. 未被任何房间占领且不属于连接走廊的黑色像素保持不变。灰色障碍保持不变。

**关键洞察**：房间的颜色由贪心占领的顺序决定（面积越大越先占领，颜色编号越小），而非由空间位置决定。因此走廊两端的颜色反映的是两端房间的相对大小排名，而非它们的物理方位。求解者需要先完成贪心排序才能确定走廊配色。

## 新题 6：粒子路径追踪与转角模板展开

**规则**：
1. 从品红(6)粒子出发，沿走廊追踪路径：粒子沿当前方向前进，遇到墙壁(灰(5))时转向 90 度（转向走廊开口方向——由背景(橙(7))像素被同色墙壁夹道的方向决定）。粒子到达蓝(1)目标像素或网格边缘时停止。
2. 将粒子经过的所有走廊像素（不含起点和终点）涂为品红(6)，形成可见路径。
3. 识别路径中的转角点：路径方向发生 90 度变化的像素。
4. 对每个转角点，擦除该像素的品红色（恢复为背景橙(7)），然后以该像素为中心放置 3x3 模板：4 个对角邻居涂品红(6)，4 个正交邻居涂灰(5)。
5. 如果模板的某个像素位置已有非背景内容（墙壁或路径），则保留原有内容不覆盖。
6. 起点品红像素和终点蓝像素保持不变。

**关键洞察**：模板展开将每个转角标记为视觉上突出的菱形节点，与直线段的品红走廊形成对比。模板中使用灰(5)（与墙壁同色）作为正交填充，使转角标记在视觉上融入墙壁结构，而品红对角线像素则标示了路径的方向转变——这种双色模板编码了路径与结构的交互关系。

## 新题 7：色彩多样性选源的骨架标注传递

**组合逻辑**：[筛选·颜色多样性比较](已有，从选出离群体裁剪输出改为在多个候选源中选定唯一传递源) → [擦除](已有) → [旋转·骨架对齐·印章覆盖](已有，从单一完整源改为经筛选确定的源)

**来源原语**：筛选·颜色多样性比较·颜色最多者入选(9a4bb226), 擦除(fd02da9e/8cb8642d), 旋转·骨架对齐·完整标注传递副本(36d67576), 锚点像素(36d67576)

**依赖链**：颜色多样性筛选从多个带标注的候选motif中选出唯一源——选错源则所有传递结果错误；擦除其余候选的标注防止干扰；骨架旋转对齐确定每个目标的变换参数。删除筛选→不知道用哪个候选的标注；删除擦除→多套标注并存造成歧义；删除对齐传递→目标motif不完整。

**规则**：
1. 对每个带标注的 motif，统计其标注色的种类数（不计蓝(1)骨架色和红(2)锚点色）。选出标注色种类数最多的唯一 motif 作为"传递源"。
2. 擦除所有其余带标注 motif 的标注像素（将这些像素恢复为背景黑(0)），仅保留它们的蓝骨架和红锚点。
3. 对每个非源 motif（包括刚被擦除标注的和原本就无标注的），找到将传递源的蓝骨架+红锚点映射到该 motif 骨架+锚点的唯一旋转角度。
4. 将传递源的所有标注像素施加该旋转，平移到目标 motif 的局部坐标系中，写入目标位置。
5. 传递源自身保持不变。骨架和锚点像素不受任何影响。

**关键洞察**：输入中有多个"看起来像是完整模板"的 motif（因为它们各自带有一些标注），但只有标注色种类最多的那个才是真正的传递源。求解者如果选错源（比如选了面积最大的或位置最靠前的），传递结果会全错。这个筛选条件必须通过对比多个示例中不同 motif 的标注丰富度才能归纳。

## 新题 8：质心定位决定嵌入体重涂色

**组合逻辑**：[形状匹配·旋转平移嵌入](已有，从候选块验证改为确定嵌入配对) → [质心偏移定位](已有，从瓦片分类改为对孔洞位置分类以决定颜色) → [重涂色](已有，从直接映射改为由位置分类结果驱动) → [嵌入](已有)

**来源原语**：形状匹配·旋转平移嵌入·完全覆盖(1acc24af), 质心偏移定位·质心方向映射插槽(4e45f183), 重涂色(d511f180), 嵌入·拼图块嵌入孔洞(228f6490)

**依赖链**：形状匹配确定每个精灵体对应哪个孔洞和所需旋转→质心定位对该孔洞在结构体内的位置做四象限分类→分类结果决定精灵体的重涂色颜色→最后将重涂色后的精灵体嵌入孔洞。精灵体原始颜色是干扰信息。删除形状匹配→不知道谁进哪个洞；删除质心分类→不知道涂什么色；删除重涂色→原始颜色不变（错误结果）；删除嵌入→精灵体留在原位。

将彩色精灵体旋转嵌入灰色结构体的孔洞中，嵌入前按孔洞在结构体内的象限位置重新指定颜色，精灵体原色无关。

**输入结构**：约 18x18 网格，黑(0) 背景。中央偏上有一个灰(5) 矩形结构体（约 12x8），内部有 4 个黑色孔洞，每个孔洞 3~5 像素，4-连通，形态互不相同（如 L 折、阶梯、斜钩等）。4 个孔洞分别位于结构体内部的四个象限（左上、右上、左下、右下），不靠近结构体中心线。结构体下方散布 4 个彩色精灵体，颜色各不相同（如红(2)、绿(3)、黄(4)、品红(6)），每个精灵体 3~5 像素，4-连通。生成约束：每个精灵体的像素掩码恰好与某一个孔洞的掩码在某个旋转（0/90/180/270度）下全等，且配对唯一（一一对应）。

**规则**：
1. 对每个精灵体，依次尝试 0/90/180/270 度旋转，与每个孔洞的像素掩码做全等比较，找到唯一匹配的（孔洞, 旋转角度）对。
2. 确定每个匹配孔洞在结构体内的象限位置：计算孔洞所有像素的质心相对于结构体中心的偏移方向。行偏移为负且列偏移为负→左上；行偏移为负且列偏移为正→右上；行偏移为正且列偏移为负→左下；行偏移为正且列偏移为正→右下。
3. 根据象限位置为精灵体重新指定颜色：左上→蓝(1)，右上→红(2)，左下→绿(3)，右下→黄(4)。精灵体的原始颜色被丢弃。
4. 将重涂色后的精灵体按匹配旋转角度变换，平移嵌入到对应孔洞的位置，覆盖原来的黑色像素。
5. 擦除精灵体在原始位置的像素（恢复为背景）。灰色结构体和其余背景不变。

**关键洞察**：精灵体的原始颜色是误导——它既不影响匹配（匹配只看形状掩码），也不影响输出颜色（输出颜色由孔洞位置决定）。求解者如果假设"原始颜色保留"或"颜色按某种映射表转换"，会在示例验证中失败。真正的颜色规则是空间位置编码：孔洞在结构体哪个象限，就用哪个固定颜色。

## 新题 9：标记端控制楔形方向的射线填充

**组合逻辑**：[射线延伸](已有，从间隙填充改为从线段端点向外延伸) → [填充·距离递变](已有，从固定方向改为由标记端决定递变方向) → [擦除](已有，消除标记像素的特殊色)

**来源原语**：射线延伸(d968ffd4), 填充·距离递变·逐行宽度递变成楔(a65b410d), 标记像素(253bf280/8cb8642d), 行列对齐(253bf280), 擦除(fd02da9e)

**依赖链**：标记像素的位置（线段的左端还是右端）决定射线从哪一端延伸以及楔形向哪个方向递变——这是一个条件分支，同一组操作在不同标记位置下产生镜像对称的结果。射线延伸为楔形提供水平跨度基准；楔形填充依赖射线+线段的总跨度。删除标记检测→不知道方向；删除射线延伸→楔形宽度不确定；删除递变填充→无几何输出。

水平线段的一端有标记像素，从无标记端向外延伸射线；线段+射线的整体跨度作为基准，在上下方向分别生成颜色不同、方向相反的三角楔形。

**输入结构**：约 15x12 网格，黑(0) 背景。2~3 条水平红(2)线段，每条长度 3~6 像素，位于不同行，互不相邻（行间距 >= 4）。每条线段的某一端（左端或右端）有一个青(8)标记像素紧邻线段端点（与线段同行，在线段外侧相邻的一格）。不同线段的标记端可以不同（有的在左端，有的在右端）。不同示例中线段数量、长度、行位置和标记端位置均可变化。生成约束：每条线段从无标记端向外延伸至网格边缘的距离至少为 2 像素；每条线段上下方至少有 3 行空间供楔形展开。

**规则**：
1. 对每条红(2)线段，识别青(8)标记像素的位置（在线段的左端外侧还是右端外侧）。
2. 从线段的无标记端向外（远离标记端的方向）沿同一行延伸射线至网格边缘。射线像素涂绿(3)。
3. 擦除青(8)标记像素（恢复为背景黑(0)），并将该位置涂为红(2)（使标记像素融入线段，线段向标记端延长 1 格）。
4. 现在线段+射线构成一个完整的水平跨度。以此跨度为底边，向上生成三角楔形：第一行（线段所在行的上一行）宽度 = 跨度宽度 - 1，第二行宽度 = 跨度宽度 - 2，以此类推，宽度减至 0 时停止。楔形对齐方式：与标记端对齐（即标记端那侧齐平，无标记端那侧逐行缩进）。上方楔形颜色为红(2)。
5. 向下生成另一个三角楔形，规则同上（每行宽度递减 1，与标记端对齐），颜色为绿(3)。
6. 多条线段独立处理。若两条线段的楔形区域重叠（不应在生成约束下发生），则行索引更小的线段优先。

**关键洞察**：标记像素不参与最终输出的可见形态（它被擦除并融入线段），但它编码了一个关键的方向信息：楔形的对齐边和射线的延伸方向都由标记位置决定。同一个示例中如果所有标记都在同一侧，无法确定方向规则——必须看到标记在不同侧的情况才能归纳出"标记端决定对齐方向"的规则。

## 新题 10：角落模板种子与连通体尺寸分级

**组合逻辑**：[印章覆盖·角落位置选模板](已有) → [计数](已有，从面积拉直改为对连通体像素计数) → [重涂色](已有，从双色互换改为基于尺寸阈值的条件重涂)

**来源原语**：印章覆盖·角落位置选模板·标记色传递给模板(fd02da9e), 计数(dce56571), 重涂色(d511f180/1818057f), 中心展开(b60334d2)

**依赖链**：角落模板展开在网格角落附近创建新的像素区域——这些区域可能与已有的前景像素连通，形成更大的连通体。连通体的最终尺寸取决于模板与前景的空间邻接关系（涌现效应）。尺寸计数的结果驱动条件重涂色。删除模板展开→连通体不变，尺寸分级结果不同；删除计数→无法分级；删除重涂色→无可见变化。

角落标记像素展开为固定模板后，与网格内已有前景像素可能连通形成更大的连通体；按连通体像素数量分级重涂颜色。

**输入结构**：8x8 网格，黑(0) 背景。1~3 个角落（四个角中的部分）各有一个彩色标记像素（颜色从红(2)、绿(3)、黄(4)、品红(6) 中选取，每个角落颜色可不同）。网格内部散布若干孤立的灰(5)像素（每个像素的 8 个邻居中无其他非背景像素），数量 3~6 个。不同示例中角落标记数量、颜色、内部灰像素位置均不同。生成约束：部分灰像素的位置使得角落模板展开后会与它们 8-连通相邻（形成连通体），部分灰像素距离所有角落模板足够远，展开后仍保持孤立。

**规则**：
1. 对每个角落标记像素，按其角落位置放置固定模板（使用标记像素的颜色），并擦除原始角落像素：
   - 左上角标记：在 (1,1) 处放置 2x2 同色方块（覆盖 (1,1)(1,2)(2,1)(2,2)）。
   - 右上角标记：在 (1,cols-3) 处放置 2x2 同色方块（覆盖 (1,cols-3)(1,cols-2)(2,cols-3)(2,cols-2)）。
   - 左下角标记：在 (rows-2, 0) 处放置 L 形（3 像素）：(rows-2,0)(rows-2,1)(rows-3,0)，同色。
   - 右下角标记：在 (rows-2, cols-1) 处放置 L 形（3 像素，镜像）：(rows-2,cols-1)(rows-2,cols-2)(rows-3,cols-1)，同色。
2. 将所有非背景像素（包括新放置的模板像素和原有的灰像素）按 8-连通性分组，得到若干连通体。
3. 对每个连通体，统计其总像素数。若像素数 > 4，将该连通体的所有像素重涂为青(8)；若像素数 <= 4，保留各像素的当前颜色不变。
4. 背景像素不受影响。

**关键洞察**：角落模板的固定形状和内部灰像素的位置共同决定哪些像素会连通——这是一个涌现效应。一个孤立的灰像素如果恰好在角落模板的 8-连通邻域内，就会被并入该模板的连通体，可能使连通体超过尺寸阈值而触发重涂。求解者无法仅看输入中角落标记和灰像素的颜色/数量来判断输出——必须在脑中"模拟"模板展开后再检查连通性。
