## 新题 1：对称补墙与腔室染色

**组合逻辑**：[对称补全](创新：作用对象从前景图案改为墙壁像素，补全改变分区拓扑) + [洪泛填充](创新：腔室由补全后的墙壁动态定义) + [邻接多数决](已有)

**来源原语**：对称补全/旋转对称/四次旋转闭合(e40b9e2f)、洪泛填充/四连通分区/连通腔室/标记像素/正交邻接/邻接多数决(7c8af763)、分隔墙(782b5218)

**依赖链**：对称补全改变墙壁拓扑 → 新墙壁重新划分四连通腔室 → 标记像素按邻接多数决为各腔室着色。跳过补全则腔室边界错误（被打通的分区导致错误的合并或分裂），跳过填充则无颜色输出。补全操作的结果实质性改变了填充操作的输入：缺失墙壁段会打通相邻腔室使其合并，补全后这些腔室被正确隔开，不同腔室邻接的标记集合也随之改变。

从不完整的墙壁像素出发，通过四次旋转对称补全墙壁，利用补全后的墙壁将网格划分为若干腔室，再由标记像素的邻接多数投票为每个腔室着色。

**输入结构**：约 15x15 的网格。背景为黑(0)。灰(5)像素组成分隔墙，但墙壁图案只在部分区域完整绘制，其余区域有缺失段（整体呈不完整的四次旋转对称，旋转中心为网格中心）。网格中散布若干单像素标记点，颜色来自红(2)、蓝(1)、绿(3)三种，每个标记点正交邻接至少一个属于某腔室的背景像素。标记点不位于墙壁上，也不处于补全后新增墙壁的位置。生成约束：(1) 补全后的墙壁将网格分成至少 4 个四连通背景腔室；(2) 每个腔室邻接的标记点存在唯一多数色（不出现平票）；(3) 不同示例中缺失的墙壁区域不同，以防求解者通过记忆特定缺失位置解题；(4) 至少存在两个腔室，在补全前本为同一连通区域、补全后被分隔为不同腔室，且各自的多数投票色不同。

**规则**：
1. 以网格中心为旋转中心，将所有灰(5)墙壁像素旋转 90 度、180 度、270 度后取并集，补全墙壁图案至四次旋转对称。新增的墙壁像素涂灰(5)。
2. 将补全后的全部灰(5)像素视为阻隔，找出所有四连通背景(0)像素的连通腔室。
3. 对每个腔室，收集所有正交邻接该腔室任意像素的标记像素颜色（一个标记可以邻接多个腔室，每个腔室独立统计），取出现次数最多的颜色作为该腔室的填充色。
4. 将该腔室的全部背景(0)像素重涂为其填充色。灰(5)墙壁像素和彩色标记像素保持不变。

**关键洞察**：墙壁补全不是装饰性的——缺失的墙壁段恰好打通了本应分隔的腔室，使得补全前后同一标记点邻接的腔室集合发生变化，必须先补全再分区才能正确着色。

## 新题 2：射线筑障与行内滑动

**组合逻辑**：[射线延伸/连线](已有) + [滑动](创新：障碍由射线动态生成而非预置，滑动方向与射线方向正交)

**来源原语**：射线延伸/连线/行列对齐/对齐像素投射矩形/碰撞停止(2c608aff)、矩形/孤立像素(2c608aff)、滑动/可移动行程/固定障碍/同行阻挡/靠近障碍停止(9c56f360)

**依赖链**：行列对齐判断哪些像素可以向矩形射出射线 → 射线延伸在特定行列创建新像素 → 这些像素成为滑动操作的障碍 → 可移动行程向左滑动直到碰触最近射线像素或左边缘。跳过射线绘制则无障碍、行程滑到左边缘（错误结果）；跳过滑动则无位移输出。

将对齐像素向中心矩形射出的射线转化为行内障碍，随后将各行右侧的可移动色段向左滑动至碰触最近射线像素或左边缘。

**输入结构**：约 12x16 的网格。背景为黑(0)。网格中部偏左有一个灰(5)实心矩形（约 3x4 像素）。若干单像素孤立点分布在矩形右侧区域，颜色各异（从蓝(1)、绿(3)、黄(4)中选），每个像素与矩形共享同一行（行对齐）或同一列（列对齐）。在部分行的最右侧，有橙(7)色的连续水平色段（2~4 像素长）紧贴右边缘。生成约束：(1) 至少 2 行同时存在行对齐的射线源像素和橙色段（确保水平射线与水平滑动在同一行交互）；(2) 至少 1 行有橙色段但无射线经过（色段将滑至矩形旁或左边缘）；(3) 每行最多一个射线源像素；(4) 射线源像素与矩形之间有足够间距容纳滑动后的色段。

**规则**：
1. 对每个孤立彩色像素，判断它与灰(5)矩形是否行对齐（共享同一行）或列对齐（共享同一列）。若行对齐，从该像素位置向矩形方向水平逐像素延伸，涂上该像素的颜色，直到下一步将进入矩形时停止（射线不覆盖矩形像素）。若列对齐，从该像素向矩形方向垂直逐像素延伸，规则相同。既非行对齐也非列对齐的像素不产生射线（保持为单像素）。
2. 射线全部绘制完成后，对每行中存在的橙(7)色段执行滑动：将色段作为整体从当前位置向左平移，遇到第一个非黑(0)非橙(7)像素时停止，色段最右像素紧邻该障碍像素的左侧一列放置。若该行无障碍像素，色段滑至第 0 列起始。
3. 色段原始位置清除为背景(0)。没有橙色段的行保持不变。

**关键洞察**：障碍不是预置的——只有先完成射线绘制，才知道各行的阻挡位置；而射线颜色与色段颜色不同，最终输出中两者并存，可验证射线确实被画出且充当了屏障。

## 新题 3：孔洞计数驱动滑移距离

**组合逻辑**：[计数](创新：计数结果不再用于筛选异常值，而是直接作为空间操作的距离参数) + [滑动](创新：滑动距离由计数动态决定而非"尽可能远") + [靠近障碍停止](已有，但与计数距离形成竞争约束)

**来源原语**：计数/前景块/背景孔洞(358ba94e)、滑动/固定障碍/同行阻挡/靠近障碍停止(9c56f360)

**依赖链**：计算每个前景块的内部孔洞数 → 孔洞数即为该块的右移步数 → 若途中碰触障碍则提前停止。孔洞计数和障碍碰撞共同约束最终位置——计数给出意图距离，障碍给出物理极限——两者中的较小值决定实际位移，删除任一条件都无法确定结果。

统计每个前景块内部的背景孔洞数，以此作为该块向右平移的步数，若移动途中遇到固定障碍则提前停止。

**输入结构**：约 11x14 的网格。背景为黑(0)。每个非空行恰好有一个红(2)色的四连通前景块（3~7 像素，不规则连通形状，不同行的块形状各异）和一个蓝(1)单像素固定障碍。红块位于该行中部偏左区域，蓝障碍位于该行红块右侧。每个红块的边界框内有 0~3 个背景孔洞（即块内被红像素四连通包围的黑(0)像素）。没有红块的行全为背景。生成约束：(1) 不同行中，孔洞数与块的其他可数属性（总像素数、边界框宽度、边界框高度）不成线性相关，确保只有孔洞数是正确的距离参数；(2) 至少一行存在碰撞情形（孔洞数的步数足以触碰或越过障碍，块被迫提前停止）；(3) 至少一行不发生碰撞（步数不足以到达障碍，块完整移动至目标位置）；(4) 至少一行孔洞数为 0（块不移动），以区分"无孔洞不动"和"所有块都动"的误解。

**规则**：
1. 对每行的红(2)前景块，统计其边界框内被红像素四连通完全包围的背景(0)像素数量，记为 H。
2. 将该红块整体向右平移 H 个像素。平移时保持块的形状和连通结构不变；原位置清除为背景(0)。
3. 若平移过程中块的任何像素将与蓝(1)障碍重叠或越过障碍所在列，则块停在障碍左侧紧邻位置（块最右像素在障碍所在列的左一列）。
4. H = 0 时块不移动。蓝(1)障碍像素保持不变。

**关键洞察**：滑动距离不是"尽可能远"也不是固定值，而是由块自身的几何属性（内部孔洞数）决定的——需要先进行计数推理得到每块的个体化移动距离，再检查障碍碰撞约束，两步不可分离。

## 新题 4：周期铺障与终端寻路

**组合逻辑**：[平铺](创新：生成障碍场而非补全装饰图案) + [寻路](创新：障碍由隐式周期编码推导而非显式放置) + [重涂色](已有)

**来源原语**：平铺/控制条/控制条周期延伸(34cfa167)、寻路/轨道路径/端点/障碍物/邻域禁区/唯一安全路径/重涂色(cc9053aa)

**依赖链**：控制条定义水平和垂直周期 → 小图案按周期铺满网格生成障碍场 → 障碍及其八邻域标记为禁区 → 在剩余可通行区域中寻找两端点间唯一的四连通安全路径 → 路径重涂色。障碍场是隐式编码的（一个小图案 + 两个周期参数），不完成铺设就无法确定禁区分布，也就无法寻路。

将一个小障碍图案按控制条指示的周期铺满网格，生成隐式障碍场，然后在排除障碍及其八邻域后的可通行区域中，找出两端点间唯一的四连通安全路径并重涂色。

**输入结构**：约 18x18 的网格。全部填充青(8)（代表可通行轨道），以下元素叠加其上。左上角有一个小矩形区域（2x2 或 2x3），内含 1~3 个橙(7)障碍像素，其余为青(8)。紧邻该矩形右侧有一根灰(5)水平控制条（高度 1 像素，长度等于水平铺设周期，4~6 像素）。紧邻该矩形下方有一根灰(5)垂直控制条（宽度 1 像素，高度等于垂直铺设周期，4~6 像素）。两个栗(9)色单像素端点分别位于网格两个不相邻的边缘附近（如左下角附近和右上角附近）。生成约束：(1) 按周期铺满后，橙像素及其八邻域不覆盖两个栗色端点；(2) 排除禁区后，两端点之间恰好存在一条四连通简单路径（通过调整周期和图案确保唯一性）；(3) 不同示例的图案形状和/或周期不同。

**规则**：
1. 以左上角小矩形为母版，水平周期为灰水平控制条的像素长度，垂直周期为灰垂直控制条的像素长度。从母版左上角位置开始，在整个网格上以该周期重复铺设母版中的橙(7)像素（非橙像素不铺设）。超出网格边界的部分舍弃。铺设的橙像素覆盖原有青(8)像素。
2. 对每个橙(7)像素（含母版原始像素和铺设副本），将其八邻域中的青(8)像素标记为禁区（禁区像素颜色不变，仅在寻路时视为不可通行）。
3. 在剩余可通行的青(8)像素（非橙、非禁区）上，以四连通方式寻找从一个栗(9)端点到另一个栗(9)端点的唯一简单路径。
4. 将路径上的青(8)像素重涂为栗(9)。栗色端点、橙障碍、灰控制条及所有其他像素保持不变。

**关键洞察**：障碍不是显式标注的，而是通过一个小图案和两个周期参数隐式编码——求解者必须先在脑中完成周期铺设并标记八邻域禁区，才能在可通行区域中规划路径；这是两层推理的紧耦合：先解码空间约束，再在约束下寻路。

## 新题 5：分区计数参数化金字塔展开

**组合逻辑**：[计数](创新：计数结果不直接构成输出内容，而是参数化另一操作的几何形态) + [生成网格](创新：尺寸由分区计数确定) + [展开/交替填色](已有，但高度和宽度由外部参数指定而非线段自身决定)

**来源原语**：计数/分隔线/分区数决定尺寸/生成网格(7039b2d7)、展开/交替填色/线段/金字塔/中心对称展开/奇偶决定颜色(db3e9e38)

**依赖链**：计数水平分区 → 决定金字塔高度 R；计数垂直分区 → 决定输出宽度 C；线段颜色 → 决定金字塔主色。三者缺一则输出不确定。在源题中分区计数仅产生空白网格，展开操作的高度由线段长度决定；这里两个原本独立的参数来源被重新连接——分区结构编码了展开操作的几何参数。

统计分隔线将网格划出的行分区数和列分区数，以此作为输出网格的高和宽，再将输入中的彩色线段在该输出尺寸内展开为居中的交替色金字塔。

**输入结构**：约 13x13 的网格。背景为黑(0)。灰(5)像素形成若干完整的水平线和垂直线（每条线贯穿整行或整列），将网格划分为若干矩形分区。其中一个分区内有一条竖直的红(2)线段（高度 2~5 像素，宽度 1 像素）。其余分区为纯背景。生成约束：(1) 水平分区数 R 在 3~6 之间，垂直分区数 C 在 5~9 之间，且 C >= 2R - 1（确保金字塔底宽 2R - 1 不超出输出宽度）；(2) 红线段的像素长度不等于 R（排除"线段长度即金字塔高度"的误解）；(3) 不同示例中分隔线数量和位置不同，以体现分区计数规则而非固定尺寸。

**规则**：
1. 统计被水平灰线分隔出的连续非灰行区段数，记为 R（行分区数）。
2. 统计被垂直灰线分隔出的连续非灰列区段数，记为 C（列分区数）。
3. 生成一个 R 行 x C 列的全黑(0)输出网格。
4. 以输出网格的最后一行为金字塔底、第 floor(C/2) 列为水平中心轴，向上构建高度为 R 的居中金字塔：第 i 行（i = 0 为顶行，i = R - 1 为底行）的着色范围为中心轴左右各 i 个像素（共 2i + 1 像素）。对每个着色像素，若其与中心轴的水平距离为偶数则涂红(2)，为奇数则涂黄(4)。
5. 金字塔范围外的像素保持黑(0)。

**关键洞察**：分隔线在源题中仅用于计数并生成空白网格，金字塔展开在源题中由线段长度决定高度；这里分隔线结构编码了展开操作的几何参数（高度和宽度），两个原本独立的规则通过参数传递紧密耦合——不计数分区就无法确定金字塔形状，不展开就无法利用计数结果。

## 新题 6：异常块定位目标腔室填充

**组合逻辑**：[计数](已有) + [异常值提取](创新：提取结果不用于裁剪输出，而是作为空间定位信号选择操作区域) + [洪泛填充](创新：填充区域由异常块的空间位置而非角落锚定决定) + [擦除](已有)

**来源原语**：计数/前景块/背景孔洞/孔洞数量唯一/异常值提取(358ba94e)、洪泛填充/分隔墙/四连通分区(782b5218)、擦除(456873bc)

**依赖链**：计数各块孔洞 → 找到唯一异常块 → 异常块所在腔室成为填充目标 → 填充目标腔室并擦除其余块。异常值检测不直接产出输出像素，而是通过空间定位将后续操作的作用域锁定到特定腔室——这是一种间接寻址，删除检测步骤则无法确定哪个腔室应被填充。

统计散布在各个墙壁腔室中的前景块的孔洞数，找出孔洞数唯一的异常块，将该块所在腔室整体填充为块色，同时擦除所有其他腔室中的块。

**输入结构**：约 15x15 的网格。背景为黑(0)。灰(5)墙壁像素将网格分成 4~6 个四连通背景腔室（墙壁为连通结构，确保分区无歧义）。每个腔室内有一个绿(3)色四连通前景块（4~8 像素，不规则连通形状，各腔室内的块形状各异），块的边界框内含 0~3 个背景孔洞。生成约束：(1) 恰好一个块的孔洞数在所有块中唯一（如 4 个块的孔洞数分别为 1, 2, 1, 3，则孔洞数 2 和 3 都是唯一的——应确保仅有一个值出现恰好一次）；(2) 每个腔室恰好包含一个前景块；(3) 块不紧邻墙壁（块的任何像素与灰像素之间至少隔一个背景像素），确保块的腔室归属无歧义；(4) 异常块所在腔室的面积（背景像素数）不是最大或最小的，排除"最大腔室"或"最小腔室"等替代解释。

**规则**：
1. 对每个绿(3)前景块，统计其边界框内被绿像素四连通完全包围的背景(0)像素数量（孔洞数）。
2. 在所有块的孔洞数中，找到出现次数恰好为 1 的那个值，其对应的块即为异常块。
3. 确定异常块所在的四连通背景腔室（以灰(5)墙壁为阻隔划分腔室，异常块位于哪个腔室中）。
4. 将该腔室的所有背景(0)像素重涂为绿(3)（异常块本身像素保持不变，效果是整个腔室变为实心绿色区域）。
5. 将所有其他腔室中的绿(3)前景块像素擦除为背景(0)。
6. 灰(5)墙壁像素全部保持不变。

**关键洞察**：异常值检测在源题中直接指向裁剪输出的目标对象，但这里异常值充当空间索引——它选择的不是"哪个对象输出"，而是"哪个区域被填充"，将一个属性判别操作转化为后续空间操作的寻址信号，两者形成检测-定位-执行的三步不可跳链。

## 新题 7：遮挡深度解码与图例排位着色

**组合逻辑**：[排序](创新：排序依据为从视觉遮挡证据推断的深度而非可直接度量的长度或面积) + [重涂色](创新：图例索引对应的是推断出的深度排位而非空间位置排位) + [提取](创新：从重叠结构中提取各帧的独立身份和范围)

**来源原语**：排序/长度排名(97d7923e)、颜色图例/高度即排名索引(97d7923e)、重涂色/排位对应/图例位映射色(fafd9572)、空心方框/内部遮罩(ad173014)、忽略干扰项(bc93ec48)

**依赖链**：从重叠方框中提取各帧的完整范围 → 分析边框交叉处可见颜色推断遮挡深度顺序（全局约束满足） → 遮挡顺序即深度排位 → 图例高度 k 对应深度排位 k → 按图例重涂各帧内部遮罩颜色。这不是线性流水线——推断遮挡顺序本身是一个约束传播问题（需综合所有交叉点的证据），排位结果再通过图例间接映射到颜色。

从相互重叠的空心彩色方框中推断绘制的先后层次（深度排位），用图例中高度编码的排位将各方框内部遮罩重涂为对应颜色。

**输入结构**：约 14x14 的网格。背景为黑(0)。3~4 个空心矩形方框相互部分重叠，每个方框的边框为 1 像素厚，各用不同颜色（从红(2)、蓝(1)、绿(3)、黄(4)中选取，与方框数量对应），方框大小各异（边长 4~7 像素）。在两个方框的边框交叉处，只有"上层"方框的边框颜色可见（下层该像素被遮盖）。每个方框内部（边框围成的空间）包含一个由灰(5)像素组成的小不规则图案（内部遮罩，3~5 像素，各帧的遮罩形状不同），遮罩不与任何边框相邻。网格右下角有一个颜色图例区：纵向从上到下排列若干小色块，每个色块宽度 1 像素、高度分别为 1、2、3...（与方框数量相同），颜色各异（从橙(7)、青(8)、栗(9)、品红(6)中选取），色块间以 1 像素黑(0)背景间隔。生成约束：(1) 每对方框的边框至少有一处交叉像素，确保遮挡关系可完全推断出全序；(2) 方框的遮挡关系构成严格全序（无环、无并列）；(3) 内部遮罩完全位于各自方框内部且不被其他方框的边框覆盖；(4) 图例中色块的纵向排列顺序与深度排位无直接对应关系，排位必须通过高度值索引。

**规则**：
1. 识别每个空心方框的边框颜色和完整矩形范围。被遮挡的边框段可通过同色可见段所在的行坐标和列坐标推断完整矩形（每个方框的可见段足以唯一确定其四条边的位置）。
2. 对每对方框，检查其边框交叉位置的像素：该像素可见的颜色属于哪个方框，则该方框在此处位于上层。汇总所有交叉处的上下层关系，排出从最浅（排位 1，遮挡所有与之交叉的帧）到最深（排位 N，被所有与之交叉的帧遮挡）的完整深度排序。
3. 在图例中，高度为 k 像素的色块提供排位 k 对应的目标颜色。
4. 将深度排位为 k 的方框的内部灰(5)遮罩像素重涂为图例中高度 k 色块的颜色。
5. 方框边框、图例像素、背景及无遮罩的空白区域全部保持不变。

**关键洞察**：深度排位不能从任何单一可度量的几何属性（面积、周长、颜色编号、空间位置）读出，而必须通过分析多处交叉像素的遮挡证据进行全局推断——这是一个约束传播问题而非简单排序；推断出的排位再经图例高度间接索引到重涂颜色，形成"全局推断 → 间接索引 → 着色"的三层不可跳步耦合。
