## 新题 1：缺口环射线

**组合逻辑**：[循环移色/color_cycle](已有) + [射线延伸/ray_extend](创新：射线颜色由循环结果决定，射线方向由缺口朝向决定) ← 由 [缺口像素/gap_pixel](创新：从矩形框语境移植到环形语境) 和 [反向循环/opposite_cycle](已有) 共同约束

**来源原语**：循环移色(#46c35fc7), 反向循环(#46c35fc7), 角位像素(#46c35fc7), 边中像素(#46c35fc7), 角与边中分组(#46c35fc7), 射线延伸(#b942fd60/#292dd178), 缺口像素(#292dd178), 缺口定射线向(#292dd178)

**依赖链**：缺口位置决定射线方向 → 循环移色后缺口位置的"虚拟颜色"决定射线颜色 → 射线遇到其他环时停止，形成环间空间交互

将带缺口的多色 3x3 环先做角/边中反向循环移色，再从缺口向外发射由循环结果着色的射线。

**输入结构**：约 15x15 网格，黑(0)背景。散布若干 3x3 环形前景对象，每个环由 8 个非黑像素环绕 1 个黑(0)中心构成。每个环恰好缺少一个边中位置的像素（即上、下、左、右四个边中位之一为黑(0)），形成缺口。环的 8 个位置（实际可见 7 个）使用 2~3 种不同非黑颜色。不同环之间在缺口朝向所在的行或列上互不重叠（即从任一环的缺口向外延伸的射线路径上不会经过另一个环的缺口行/列，但可能遇到另一个环的外侧像素）。每个环的缺口朝向与环中心的相对位置明确（缺口在中心正上/正下/正左/正右）。生成时保证各环之间至少间隔 2 个像素。

**规则**：
1. 对每个 3x3 环，将四个角位像素的颜色沿顺时针方向循环一步（左上→右上→右下→左下→左上），将四个边中位像素的颜色沿逆时针方向循环一步（上→左→下→右→上）。缺口位置虽然无像素，但在边中循环中仍占位——其"虚拟颜色"等于循环后该位置应得的颜色。
2. 循环完成后，将缺口位置填入其虚拟颜色，成为射线起点。
3. 从缺口位置向外（远离环中心的方向）逐格延伸射线，射线颜色为该虚拟颜色。射线在以下条件停止（不含终点）：遇到任何非黑像素，或到达网格边界。
4. 环本身的 7 个可见像素按循环后的新颜色重绘。环中心保持黑(0)。

**关键洞察**：缺口虽然在输入中是空的，但它在边中循环中占有位置——必须模拟完整的四元循环才能确定缺口应该是什么颜色，而这个颜色正是射线的唯一着色依据。

## 新题 2：碎片合并后角向平移

**组合逻辑**：[补全/complete](已有：碎片合并) → [平移/translate](创新：平移方向由合并后 bbox 角落的控制像素决定) + [擦除/erase](已有)，受 [行列跨度重叠/span_overlap](已有) 和 [角位指示方向/corner_indicates_dir](创新：从完整矩形移植到合并后的碎片组 bbox) 共同约束

**来源原语**：补全(#8fbca751), 残缺矩形(#8fbca751), 连通分量(#8fbca751), 行列跨度重叠(#8fbca751), 合并对齐碎片(#8fbca751), 平移(#470c91de), 控制像素(#470c91de), 角位指示方向(#470c91de), 对角固定步移(#470c91de), 擦除(#1b8318e3)

**依赖链**：碎片的 4-连通分量分析 → 按行列跨度重叠合并 → 合并后 bbox 确定 → bbox 四角中唯一的控制像素指示对角方向 → 补全 bbox 内空缺并整体平移

将分散的同色碎片按行列跨度合并为完整矩形，再根据每组 bbox 角落的控制像素方向做一步对角平移。

**输入结构**：约 18x18 网格，黑(0)背景。一种前景色（如蓝(1)）形成若干不规则的 4-连通碎片（每个碎片 3~8 像素，形状不规则——非固定几何形状）。碎片之间可能空间上远离，但属于同一矩形的碎片的边界框在行跨度或列跨度上有重叠。另有若干青(8)控制像素散布在网格中。每个合并后碎片组的紧凑 bbox 恰好有一个角格上放置着青(8)像素（该青像素不与任何蓝碎片 4-连通）。不同碎片组的 bbox 互不重叠，且平移一步后也互不重叠。生成时保证每个碎片组的 bbox 至少 3x3，且距网格边界至少留 1 格余量以容纳平移。

**规则**：
1. 找出所有蓝(1) 4-连通碎片。
2. 若两个碎片的边界框在行跨度或列跨度上有任意重叠，则归入同一组。此合并具有传递性。
3. 对每个合并后的组，计算其紧凑包围框（所有成员碎片的最小公共 bbox）。
4. 找到位于该 bbox 四角之一的青(8)像素。该角位决定对角移动方向：左上角 →(-1,-1)，右上角 →(-1,+1)，左下角 →(+1,-1)，右下角 →(+1,+1)（行,列）。
5. 将 bbox 内所有黑(0)背景格填充为蓝(1)，形成完整填充矩形（含青像素位置也替换为蓝(1)）。
6. 擦除原始占用区域（bbox 范围内全部置黑(0)）。
7. 在 bbox 整体偏移一步对角方向后的新位置重绘完整蓝(1)矩形。
8. 处理顺序：按各组 bbox 左上角坐标的阅读序（先上后下，同行先左后右）。

**关键洞察**：只有完成碎片的跨度合并后才能确定 bbox 边界，而控制像素的角位只有在 bbox 确定后才能判读——碎片合并和移动方向的解读不可分离。

## 新题 3：障碍编码交换变色

**组合逻辑**：[交换/swap](已有) + [重涂色/recolor](创新：重涂色规则由障碍段自身颜色编码，而非外部图例) ← 由 [跨障碍配对/cross_barrier_pair](已有) 和 [图例映射/legend_mapping](创新：图例嵌入障碍结构本身) 共同约束

**来源原语**：交换(#1efba499), 障碍段(#1efba499), 标记像素(#1efba499), 跨障碍配对(#1efba499), 同行列两侧各一(#1efba499), 擦除(#1efba499), 重涂色(#a79310a0), 图例映射(#5adee1b2)

**依赖链**：识别障碍段的分段颜色结构 → 确定每行穿越的是哪个颜色段 → 标记像素跨障碍交换位置 → 交换后标记像素的新颜色取决于它穿越的障碍段颜色

标记像素跨越分段着色的障碍交换位置，交换后每个标记变为它所穿越障碍段的颜色。

**输入结构**：约 14x14 网格，黑(0)背景。一条垂直障碍线位于网格中部附近（占据一列，从上到下贯穿），由多段不同颜色构成（例如从上到下依次为 3 格红(2)、4 格绿(3)、3 格蓝(1)，段间无间隔，颜色互不相同）。障碍两侧散布若干单像素标记，颜色各异（不与障碍段颜色相同）。每个标记所在行恰好穿越障碍的某一个连续颜色段。满足配对条件的行（障碍两侧各恰好一个标记）不超过 6 行。生成时保证：障碍至少包含 2 个不同颜色段；每个颜色段至少覆盖 2 行；配对行中两侧标记的颜色互不相同。

**规则**：
1. 识别垂直障碍线，将其按颜色连续性分段。
2. 逐行扫描穿越障碍的行。若某行障碍两侧各恰好有一个标记像素，则进行交换：擦除两个原始标记，将每个标记放置在障碍对侧紧邻障碍的第一个格子上。
3. 交换后，每个标记的颜色变为它所穿越的障碍段的颜色（即该行上障碍像素的颜色）。
4. 若某行仅一侧有标记或无标记，该行不变。
5. 障碍本身保持不变。

**关键洞察**：障碍不是均质墙壁而是分段色码——标记穿越哪个颜色段决定了它的新身份；仅看单个示例可能误以为所有标记都变成同一种颜色，需要对比多个示例（涉及不同段的标记）才能归纳出"取所穿越段颜色"的规则。

## 新题 4：区域边界调制的周期平铺

**组合逻辑**：[周期平铺/periodic_tiling](已有) + [压缩/compress](创新：不压缩输出，而是将区域颜色作为平铺的色彩调制源) ← 由 [邻接侧决定方向/adjacency_side_determines_dir](已有) 和 [网格分区/grid_partition](创新：分区边界同时充当平铺的颜色切换触发器) 共同约束

**来源原语**：周期平铺(#53fb4810), 十字图案(#53fb4810), 标记块(#53fb4810), 邻接侧决定方向(#53fb4810), 不覆盖源对象(#53fb4810), 压缩(#780d0b14), 分隔线(#780d0b14), 色块区域(#780d0b14), 网格分区(#780d0b14), 每区域折叠单像素(#780d0b14)

**依赖链**：识别分隔线形成的区域分区及每个区域的主色 → 识别十字图案及其邻接标记块 → 标记块按邻接侧向外周期平铺 → 平铺跨越分隔线进入新区域时，颜色切换为该区域的主色

从十字臂旁的标记块向外周期平铺，每当平铺穿过分隔线进入新区域时，颜色自动切换为该区域的主色。

**输入结构**：约 18x18 网格，黑(0)背景。灰(5)像素构成若干完整的水平线和垂直线（贯穿整行或整列），将网格分割为矩形区域。每个区域内散布若干同色非黑非灰像素（每区域仅一种颜色，像素数 2~5，不填满区域），代表该区域的"主色"。另有 1~2 个青(8)十字形对象（每个十字为一行一列交叉、总共 5 像素的 '+' 形），十字可跨越分隔线。在每个十字的某些臂端外侧（紧邻臂端、在十字的上/下/左/右方向），各有一个 1 像素的彩色标记块（颜色非黑非灰非青，与某个区域主色可能相同也可能不同）。生成时保证：每个十字至少有 2 个方向带标记块；标记块所在位置不是灰(5)分隔线。

**规则**：
1. 识别灰(5)分隔线（完整行和完整列），确定它们划分出的矩形区域。
2. 对每个区域，统计其内部非黑非灰非青像素的颜色，确定该区域的主色。
3. 对每个十字旁的标记块，确定它位于十字的哪一侧（上/下/左/右），该侧即为平铺延伸方向。
4. 从标记块位置起，沿延伸方向每隔 1 格（即标记块宽度 1 + 间隔 0 = 步长 1）重复放置一个像素，直至网格边界。
5. 每个重复像素的颜色取决于它落入哪个区域：使用该区域的主色。若重复像素恰好落在灰(5)分隔线上，则跳过该位置（不覆盖分隔线），继续向前。
6. 不覆盖十字像素、灰分隔线和已有的区域主色像素。

**关键洞察**：分隔线同时承担两个角色——它既是确定区域主色的空间边界，又是平铺过程中颜色切换的触发点。平铺在空间上是周期性的，但在颜色上是区域自适应的。

## 新题 5：切比雪夫环形辐射填充

**组合逻辑**：[泛洪填充/flood_fill](已有：内部填充) + [填充/fill](创新：外部填充使用切比雪夫距离环而非均匀色) + [射线延伸/radiate](已有：从开口辐射) ← 由 [开口方向/opening_direction](已有) 和 [偶数切比雪夫距离/even_chebyshev_distance](创新：距离原点从十字交叉移到半封闭墙开口中点) 和 [障碍投射阴影/obstacle_casts_shadow](已有) 共同约束

**来源原语**：泛洪填充(#b9e38dc0), 半封闭墙(#b9e38dc0), 障碍物(#b9e38dc0), 填充种子(#b9e38dc0), 开口方向(#b9e38dc0), 障碍投射阴影(#b9e38dc0), 填充(#759f3fd3), 偶数切比雪夫距离(#759f3fd3), 交叉点中心(#759f3fd3), 射线延伸(#292dd178)

**依赖链**：识别半封闭墙的开口方向 → 内部用种子色均匀填充 → 开口中点成为切比雪夫距离原点 → 外部沿开口方向辐射，按切比雪夫距离奇偶交替着色 → 障碍物沿辐射方向投射阴影，阻断阴影区的填充

半封闭墙的内部均匀填充种子色，外部通过开口辐射出切比雪夫距离交替环，障碍物在辐射路径上投射阴影。

**输入结构**：约 16x16 网格，黑(0)背景。2~3 个灰(5)半封闭墙（每个是 U 形或 C 形，由连续灰像素围成三面，一面开口；围墙厚度 1 像素，围合的内部空间为 3x3 或 4x3 等矩形）。每个围墙内部放置一个彩色种子像素（颜色各不相同，如红(2)、蓝(1)、绿(3)）。围墙外部、开口方向的辐射路径上可能存在 1~2 个小型障碍像素（橙(7)），与围墙不相连。不同围墙的开口方向及辐射扇区互不重叠。生成时保证：每个围墙的开口宽度至少 2 格；障碍物位于开口正前方的辐射路径上；辐射区域不与其他围墙重叠。

**规则**：
1. 对每个半封闭墙，确定其开口方向（上/下/左/右）和围合的内部区域。
2. 将内部区域所有黑(0)格填充为种子像素的颜色（均匀填充）。
3. 确定开口边的中点像素坐标（若开口宽度为偶数，取靠左/靠上的中点），作为切比雪夫距离原点 O。
4. 从开口向外辐射：对开口方向一侧的所有黑(0)背景格，计算其到 O 的切比雪夫距离 d。辐射范围限制在以开口宽度为底、向外扩展至网格边界的梯形区域内（从开口两端向外各扩展 45 度）。
5. 辐射区域内：d 为偶数的格填种子色，d 为奇数的格保持黑(0)。
6. 障碍物（橙(7)像素）保持不变。障碍物沿辐射方向（从 O 看过去）投射阴影：障碍物正后方（沿从 O 到障碍物方向继续延伸）的所有格不填充，无论其距离奇偶如何。阴影宽度与障碍物宽度相同（逐格投射）。
7. 灰(5)围墙像素保持不变。

**关键洞察**：同一种子色在围墙内部表现为实心填充，在外部则碎裂为切比雪夫距离环——相同的颜色规则因位置语境不同产生截然不同的视觉模式；需要对比多个示例才能确认外部是距离环而非某种固定条纹。

## 新题 6：吸附计数决定光环尺寸

**组合逻辑**：[吸附/snap](已有) + [膨胀/dilate](创新：膨胀厚度由吸附到该锚块的像素计数决定) + [计数/counting](创新：计数结果不渲染为柱状图而是转化为空间膨胀参数) ← 由 [最近距离/nearest_distance](已有) 和 [冲突优先级/conflict_priority](创新：光环重叠时计数多者优先) 共同约束

**来源原语**：吸附(#1b8318e3), 锚块(#1b8318e3), 孤立像素(#1b8318e3), 外框边缘(#1b8318e3), 最近距离(#1b8318e3), 最短距离分配(#1b8318e3), 冲突优先级(#1b8318e3), 膨胀(#5adee1b2), 孔洞保留不填(#5adee1b2), 计数(#8597cfd7/#f3cdc58f), 擦除(#1b8318e3)

**依赖链**：每个孤立像素按最近距离分配到锚块 → 统计每个锚块吸附了几个像素 → 吸附计数决定光环膨胀厚度 → 最近的被吸附像素的颜色决定光环颜色 → 不同锚块光环重叠时按吸附计数解决冲突

孤立像素被吸附到最近的锚块，每个锚块的光环向外膨胀的厚度等于它吸附到的像素数量。

**输入结构**：约 16x16 网格，黑(0)背景。3~5 个灰(5) 2x2 锚块，彼此间距至少 5 格。散布 4~10 个彩色孤立像素（每个像素为单个非黑非灰的彩色格，颜色从红(2)、蓝(1)、绿(3)、黄(4)中取），没有孤立像素与锚块相邻（至少隔 1 格）。生成时保证：每个锚块至少被 1 个像素分配到；不同锚块分配到的像素数量不全相同（以产生不同尺寸的光环）。

**规则**：
1. 对每个孤立彩色像素，计算它到每个锚块的切比雪夫距离（到锚块 2x2 中最近格的切比雪夫距离）。将像素分配给距离最小的锚块。距离相同时按曼哈顿距离取较小者；仍相同时按像素坐标阅读序（行优先，从上到下从左到右）取先出现者分配给行号较小的锚块。
2. 对每个锚块，令 N = 分配到它的像素数量。
3. 找出分配到该锚块的所有像素中，切比雪夫距离最小的那个像素（距离相同取阅读序靠前者），其颜色记为 C。
4. 以锚块 2x2 区域为核心，向外膨胀 N 层（即 bbox 从 2x2 扩展为 (2+2N)x(2+2N)，中心对齐，裁剪到网格边界内）。将膨胀区域中的黑(0)背景格填充为颜色 C。
5. 灰(5)锚块像素保持不变。
6. 若两个锚块的光环区域重叠，重叠格归属 N 值更大的锚块（使用其颜色 C）。N 值相同时，归属切比雪夫距离更近的那个像素所属的锚块；仍相同则归属锚块左上角坐标阅读序靠前的锚块。
7. 所有原始孤立像素被擦除（置为黑(0)），然后被光环覆盖（若光环范围涵盖该位置则显示光环色，否则为黑(0)）。

**关键洞察**：每个锚块的"引力"（吸附到多少像素）直接控制其势力范围——吸附更多像素的锚块光环更厚，可能吞噬邻近锚块的领地；吸附计数既是统计结果也是空间参数。

## 新题 7：提取层序索引的环形循环

**组合逻辑**：[裁剪/crop](已有) + [堆叠/stack](已有) + [循环移色/color_cycle](创新：循环步数由提取层序号决定而非固定为 1) ← 由 [行对齐配对/row_aligned_pair](已有) 和 [反向循环/opposite_cycle](已有) 和 [按顺序堆叠/stacked_in_order](创新：堆叠顺序编码为循环参数) 共同约束

**来源原语**：裁剪(#aab50785), 堆叠(#aab50785), 标记块(#aab50785), 行对齐配对(#aab50785), 按顺序堆叠(#aab50785), 忽略干扰项(#aab50785), 循环移色(#46c35fc7), 环形前景(#46c35fc7), 角位像素(#46c35fc7), 边中像素(#46c35fc7), 反向循环(#46c35fc7), 角与边中分组(#46c35fc7)

**依赖链**：识别行对齐标记块对 → 按从上到下顺序提取标记块间内容 → 垂直堆叠提取内容 → 堆叠结果中定位 3x3 环 → 每个环的循环步数 = 它所来自的提取层编号（1-based）→ 必须追踪堆叠来源才能正确循环

从标记块对之间裁剪内容并堆叠，对堆叠结果中的每个 3x3 环做循环移色，循环步数等于该环所在提取层的序号。

**输入结构**：约 20x14 网格，黑(0)背景。红(2) 2x2 标记块成对出现，每对共享相同的两行跨度，分别位于左右两侧（行对齐配对）。共 3~4 对标记块从上到下排列，对与对之间行跨度不重叠。每对标记块之间的矩形区域宽度相同（如 8 列），包含 1~2 个 3x3 彩色环（环由 8 个非黑像素环绕 1 个黑(0)中心构成，使用 2~4 种颜色）。标记块对之间区域外可能有零散噪声像素（非红色）。每个提取区域的高度均为 2 行（与标记块高度相同），3x3 环的中心行在提取区域中央行，因此实际上每个提取区域高度需足够容纳 3x3 环——修正：每对标记块共享的行跨度为 3 行（标记块为 2x2 但行跨度取 3 行以容纳 3x3 环）。生成时保证：所有提取区域宽度相同；每个环的 8 像素使用至少 2 种不同颜色。

**规则**：
1. 识别所有红(2) 2x2 标记块，按共享行跨度配对。
2. 按行跨度从上到下排序，编号为层 1、层 2、层 3 ...
3. 对每对标记块，裁剪严格位于两个标记块之间（不含标记块列）的矩形内容。
4. 将所有裁剪内容按层序从上到下垂直堆叠，丢弃标记块和标记块外的所有内容。
5. 在堆叠结果中定位所有 3x3 环（8 个非黑像素围绕 1 个黑中心）。
6. 对来自层 k 的每个环，执行 k 步循环移色：每步中，四个角位颜色顺时针轮转一步，四个边中位颜色逆时针轮转一步。k 步即重复此操作 k 次。
7. 输出为堆叠后的网格，环按循环后的颜色显示，非环像素保持原样。

**关键洞察**：堆叠将空间来源扁平化为统一的纵列排布，但层序号（在堆叠后视觉上已丢失）作为隐式参数存活于循环步数中——求解者必须回溯每个环的提取来源层才能确定正确的循环次数。

## 新题 8：重叠矩形层序推断

**组合逻辑**：[排序/sort](创新：排序依据不是计数而是空间遮挡关系推断出的层序) + [压缩/compress](创新：压缩的不是空间分区而是推断出的层序关系) ← 由 [两区域比较/region_comparison](创新：比较的不是计数增长而是遮挡优先级) 和 [网格分区/grid_partition](创新：分区由矩形重叠隐式定义) 共同约束

**来源原语**：排序(#f3cdc58f), 压缩(#780d0b14), 每区域折叠单像素(#780d0b14), 填充矩形(#470c91de), 两区域比较(#8597cfd7), 选择(#8597cfd7), 冲突优先级(#1b8318e3)

**依赖链**：识别各颜色可见区域 → 推断每个矩形的完整 bbox（从可见像素的 bbox 推断）→ 在重叠区域判断谁遮挡谁 → 从所有成对遮挡关系传递闭包出全序 → 输出为单行颜色序列

从多个重叠填充矩形的可见部分推断完整的前后层序，输出为从底到顶的单行颜色序列。

**输入结构**：约 12x12 网格，黑(0)背景。3~5 个不同颜色的填充矩形（每个矩形为纯色，每个矩形颜色不同，从蓝(1)、红(2)、绿(3)、黄(4)、品红(6)中取）彼此部分重叠。每个矩形大小为 3x3 到 6x6 不等。在重叠区域，只有最上层矩形的颜色可见（下层被遮挡）。没有矩形被完全遮挡——每个矩形至少有 1 个像素可见。生成时保证：任意两个有重叠的矩形，其重叠区域至少 1 个像素；所有成对遮挡关系能传递闭包出唯一全序（不存在环形遮挡）；矩形均为轴对齐。

**规则**：
1. 识别输入中每种非黑颜色对应的可见像素集合。
2. 对每种颜色，其完整矩形 = 其可见像素集合的紧凑包围框（bbox）。（因为每个矩形是实心的轴对齐矩形且无矩形被完全遮挡，可见像素的 bbox 即为完整矩形范围。）
3. 对每对矩形 A、B，若它们的 bbox 有重叠区域，检查重叠区域内的像素颜色：若全为 A 的颜色，则 A 在 B 之上；若全为 B 的颜色，则 B 在 A 之上。
4. 从所有成对遮挡关系构建偏序，取其传递闭包得到全序（由生成约束保证全序存在且唯一）。
5. 输出为 1xK 网格（K = 矩形数量），从左到右列出矩形颜色，最左为最底层，最右为最顶层。

**关键洞察**：没有任何单个重叠区域能揭示完整层序——求解者必须收集所有成对遮挡证据并传递推断出全序；这是一个约束推理问题而非顺序执行流水线。

## 新题 9：递归射线网络划分后压缩

**组合逻辑**：[射线延伸/ray_extend](已有) + [递归展开/recursive_expansion](已有) → [压缩/compress](创新：射线网络本身成为压缩的分区边界而非预设分隔线) ← 由 [正交转向/perpendicular_turn](已有) 和 [标记触发转向/marker_triggers_turn](已有) 和 [网格分区/grid_partition](创新：分区由射线动态生成而非预置) 和 [每区域折叠单像素/region_to_pixel](已有) 共同约束

**来源原语**：射线延伸(#b942fd60), 递归展开(#b942fd60), 起点像素(#b942fd60), 标记像素(#b942fd60), 射线网络(#b942fd60), 正交转向(#b942fd60), 标记触发转向(#b942fd60), 深度优先展开(#b942fd60), 压缩(#780d0b14), 网格分区(#780d0b14), 色块区域(#780d0b14), 每区域折叠单像素(#780d0b14)

**依赖链**：红起点像素发射水平射线 → 遇标记像素时正交转向递归展开 → 射线网络将网格分割为若干封闭区域 → 每个封闭区域内散布着同一颜色的非射线像素 → 按区域拓扑位置压缩为小网格

递归射线网络在网格上展开后形成分区边界，每个封闭区域压缩为一个像素输出。

**输入结构**：约 15x15 网格，黑(0)背景。一个红(2)起点像素位于左边缘某行。若干彩色标记像素（绿(3)或蓝(1)）散布在网格中，它们决定射线转向点。除起点和标记外，网格中还散布少量彩色像素（黄(4)、品红(6)、橙(7)等，每种颜色集中在某个空间区域内，每区域 2~4 个同色像素）。这些散布像素不在射线将要经过的行列上。生成时保证：射线网络展开后恰好将网格分割为若干个封闭矩形区域（射线 + 网格边界围成）；每个封闭区域内恰好包含一种非黑非红非标记色的散布像素（该颜色即为区域主色）；各区域主色互不相同；标记像素布局使得射线网络能完整分割网格（射线到达网格边界或与其他射线相交即封闭区域）。

**规则**：
1. 从红(2)起点像素向右发射水平射线，逐格绘红色直到遇到第一个标记像素或网格边界。
2. 首次遇到某个标记像素时，射线停在标记前一格。从该格发射正交方向（垂直）的射线，向两个方向延伸直到遇到标记或边界。同一标记再次被射线触及时仅阻停射线，不再触发新的正交展开。
3. 新射线按深度优先展开：对同一标记触发的两个方向，先处理右/下方向再处理左/上方向。
4. 重复直到无新标记可达。所有射线像素绘为红(2)。
5. 射线网络与网格边界共同将网格分割为若干封闭矩形区域。对每个区域，找到其中所有非黑非红非标记色的像素，取其颜色为该区域主色。
6. 构建输出网格：输出的行列数对应区域的拓扑行列布局（即被水平射线/边界分隔的行带数 x 被垂直射线/边界分隔的列带数）。每个输出格填入对应区域的主色。输出中区域的相对空间位置与输入一致（左上区域映射到输出左上格等）。

**关键洞察**：射线网络不是装饰图案而是结构性分区边界——改变一个标记像素的位置会完全改变射线走向、区域划分乃至输出网格的尺寸。射线展开与区域压缩是不可分离的同一推理过程的两个阶段。

## 新题 10：缩略图引导的滑动校正与补全

**组合逻辑**：[补全/complete](已有：按缩略图补全缺失块) + [滑动/sliding](创新：不是平移整个对象而是将错位的色块滑回正位) + [缩放/scale](已有：缩略图到色块网格的坐标映射) ← 由 [坐标映射/coordinate_mapping](已有) 和 [已有块确认对齐/existing_blocks_confirm_alignment](创新：正确放置的块用于推断比例尺，错位块用于纠正) 和 [移动并变色/shift_and_recolor](创新：不变色只移动，但需先判断"错位"vs"正确") 共同约束

**来源原语**：补全(#c4d067a0), 缩略图(#c4d067a0), 色块网格(#c4d067a0), 缩放(#c4d067a0), 坐标映射(#c4d067a0), 已有块确认对齐(#c4d067a0), 滑动(#a79310a0), 移动并变色(#a79310a0), 前景对象(#a79310a0)

**依赖链**：识别缩略图和色块 → 从正确放置的色块推断比例尺/偏移 → 比对每个缩略图像素的期望位置与实际色块位置 → 颜色匹配但偏移 1 格的色块判定为"错位"并滑回 → 无色块对应的位置补全新块

缩略图既是补全指南又是校错参照：先将错位的色块滑回正位，再补全缺失位置。

**输入结构**：约 18x18 网格，黑(0)背景。左上角有一个小型彩色精灵（如 4x4 像素），每个像素为不同非黑颜色，构成缩略图。网格主区域放置若干 NxN（如 3x3）同色填充块，排列在规则栅格上。部分块正确放置在缩略图映射的精确位置上；部分块从正确位置整体偏移了恰好 1 格（上/下/左/右之一）；部分位置完全空缺（纯背景）。每个块是单色填充的正方形。正确放置的块至少 2 个（用于确认比例尺和偏移量）。缩略图中不同像素颜色互不相同。生成时保证：错位块的偏移方向可以不同（有的向上偏 1 格，有的向右偏 1 格等）；错位块偏移后不与其他块重叠；每个缩略图像素对应的块要么正确放置、要么偏移 1 格、要么缺失，不存在颜色错误的块。

**规则**：
1. 识别左上角缩略图的边界（被背景包围的最小矩形彩色区域）。
2. 识别主区域中所有非黑的单色方形块及其颜色和位置。
3. 利用至少 2 个正确放置的块（其颜色与缩略图中某像素匹配，且位置恰好在整数比例尺 + 偏移量映射的栅格点上），推断比例因子 S 和偏移量 (dr, dc)。缩略图像素 (i, j) 对应块的左上角位置为 (dr + i*S, dc + j*S)。
4. 逐一检查缩略图中每个像素 (i, j) 的期望块位置：
   - 若该位置已有颜色正确的块：保持不变（正确放置）。
   - 若该位置为空，但在上/下/左/右 1 格处存在颜色正确的块：将该块滑回期望位置（擦除原位置，在期望位置绘制）。块颜色不变。
   - 若该位置为空且周围无可匹配的错位块：在期望位置新绘制一个颜色匹配的 NxN 块。
5. 处理顺序：先纠正所有错位块（按期望位置阅读序），再补全所有缺失块（按期望位置阅读序）。
6. 缩略图本身保持不变。

**关键洞察**：缩略图不仅是补全的模板——它还是错误检测的参照标准。"几乎在正确位置"的块需要被识别和校正而非忽略或覆盖，求解者必须区分"错位"与"缺失"两种不同状态并分别处理。
