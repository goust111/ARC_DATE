## 新题 1：双掩码逻辑交构墙 + 洪泛填充内外分类

**组合逻辑**：[逻辑交](从产出最终输出改为产出中间墙结构) → [洪泛填充 + 内外分区](作用于动态计算出的墙而非给定线条) → [重涂色](按内外分类赋色)

**来源原语**：逻辑交、位掩码、分隔列（0520fde7）；洪泛填充、内外分区、边界连通分内外（7b6016b9）；重涂色（b2862040）

**依赖链**：逻辑交的结果决定了墙的拓扑形状，墙的拓扑决定了哪些区域被封闭、哪些与边界连通，最终内外分类决定了每个背景像素的颜色。删掉逻辑交则墙不存在；删掉洪泛填充则无法区分内外；删掉重涂色则无可见输出差异。

将两个二值掩码的逐像素交集作为墙，然后按该墙的拓扑封闭性对背景做内外着色。

**输入结构**：黑(0)背景网格，约 11x25。一条全高灰(5)竖线将网格分为左右两个等大面板（各约 11x12）。左面板中有若干蓝(1)像素构成一个二值掩码图案，右面板中有若干红(2)像素构成另一个等尺寸二值掩码图案。两个掩码的前景像素各自形成不同的 4-连通图形（3-15 像素），图形形状在不同示例中不同。生成约束：两个掩码的逻辑交（同时为前景的位置）形成至少一个封闭环路，使得存在被该环路完全围住的背景区域。

**规则**：
1. 定位灰(5)分隔列，将左右面板对齐到同一坐标系（去掉分隔列后，左右面板逐像素对应）。
2. 逐像素计算逻辑交：左面板为蓝(1)且右面板为红(2)的位置标记为绿(3)；其余位置为黑(0)。得到一个与单面板等大的网格。
3. 以绿(3)像素为墙，从网格四条边界出发做 4-连通洪泛填充：所有从边界可达的黑(0)像素涂为黄(4)（外部）。
4. 剩余黑(0)像素（被绿墙完全封闭、无法连通到边界）涂为橙(7)（内部）。
5. 输出为该单面板尺寸的网格，包含绿(3)墙、黄(4)外部、橙(7)内部。

**关键洞察**：逻辑交不是最终答案，而是构造了一张拓扑墙。求解者必须先完成位运算推断墙的形状，再进行空间连通性推理判断封闭性——两步推理缺一不可，且仅凭单个示例难以确定内外颜色的分配规则。

## 新题 2：杯形内部面积排序驱动调色 + 开口方向射线

**组合逻辑**：[洪泛填充](识别杯形内部区域) → [计数 + 排序](按内部面积排序) → [重涂色](排序结果映射色板) → [射线延伸](从开口方向向外发射已分配颜色的射线)

**来源原语**：杯形轮廓、开口、开口决定延伸向（d4f3cd78）；洪泛填充、封闭区域（7b6016b9）；计数、排序、按计数升序排列（d4c90558）；重涂色（b2862040）；射线延伸（981add89）

**依赖链**：洪泛填充产出各杯的内部面积 → 面积排序决定颜色分配 → 颜色分配决定射线颜色 → 开口方向决定射线走向。删掉计数/排序则无法确定颜色映射；删掉开口检测则射线无方向；删掉洪泛填充则无法获得面积。

按杯形内部面积从小到大排序后依次赋予色板颜色，并从各杯开口方向发射该颜色的射线。

**输入结构**：黑(0)背景网格，约 16x16。网格中有 3-4 个灰(5)杯形轮廓对象，每个由灰像素构成近封闭矩形框，框的某一侧有一个 1-2 像素宽的缺口（开口），不同杯的开口朝向不同（上、下、左、右均可能）。各杯的内部面积（被框围住的背景像素数）互不相同，范围约 4-20 像素。各杯互不相邻，距网格边缘至少 2 像素。网格最下方一行放置一排色板像素，从左到右依次为蓝(1)、红(2)、绿(3)、黄(4)（色板数量等于杯的数量），每个色板占 1 像素，彼此间隔 1 个黑像素。

**规则**：
1. 对每个灰(5)杯形轮廓，找到其边界框，将边界框内部通过杯壁封闭的黑(0)像素识别为该杯的内部区域（开口侧与外部连通的像素不算内部——如果开口被堵住则整个内部都算封闭，否则只有无法从开口逃逸的部分算封闭）。具体方法：将杯壁像素视为障碍，从开口向外做 4-连通洪泛，边界框内未被洪泛到达的黑像素即为内部。
2. 计算每个杯的内部像素数。
3. 按内部像素数从小到大排列所有杯。
4. 将排序后第 k 个杯（k 从 1 开始）的杯壁和内部像素全部重涂为最下方色板行的第 k 个颜色。
5. 对每个杯，检测其开口方向（上/下/左/右），从开口处沿该方向向网格边缘发射一条 1 像素宽的射线，颜色为该杯被分配的颜色。射线遇到其他杯的杯壁像素时停止（不覆盖该杯壁像素）。
6. 移除最下方色板行（输出中不包含色板）。

**关键洞察**：杯的颜色不由其空间位置或原始属性决定，而由所有杯的内部面积排名决定。求解者需同时推断面积→颜色映射规则和开口→射线方向规则，两者耦合在同一输出中——射线的颜色验证了面积排序，射线的方向验证了开口检测。

## 新题 3：分区降采样生成着色图谱 + 瓦片图案铺排

**组合逻辑**：[降采样](矩形分区网格压缩为颜色矩阵) + [裁剪](提取瓦片图案) → [平铺 + 重涂色](瓦片按颜色矩阵逐格变色铺排)——同时约束结构，降采样结果同时决定输出尺寸和每格颜色

**来源原语**：降采样、矩形分区、网格采样、每分区缩为单像素（90c28cc7）；平铺、瓦片图案（9c1e755f）；裁剪（57edb29d）；重涂色（b2862040）

**依赖链**：降采样产出 NxM 颜色矩阵 → 矩阵维度决定瓦片铺排的行列数 → 矩阵每格颜色决定对应位置瓦片的前景色。瓦片形状来自裁剪。三者同时约束输出，缺一不可。

将一个大分区网格降采样为颜色矩阵，再用该矩阵逐格指定颜色铺排一个小瓦片图案。

**输入结构**：黑(0)背景网格，约 20x20。一条全宽灰(5)水平线将网格分为上下两个区域。
- 上方区域：一个多色矩形分区网格，由若干大小不等的单色矩形紧密拼合而成（无间隙无重叠），使用蓝(1)、红(2)、绿(3)、黄(4)等颜色，每个矩形为纯色填充。分区网格的行数 N 和列数 M 在 2-5 之间。
- 下方区域：一个小的单色前景图案（3-5 像素，4-连通，单一颜色如橙(7)）置于黑背景上，图案的边界框为 PxQ（P、Q 均为 2-4）。
- 生成约束：上方分区网格中同一行的所有矩形高度相同，同一列的所有矩形宽度相同（保证合法的矩形分区）。

**规则**：
1. 对上方分区网格做降采样：收集所有分区矩形左上角的行坐标和列坐标，排序去重，得到 N 个行位置和 M 个列位置。在每个 (行位置i, 列位置j) 处采样颜色，得到一个 NxM 的颜色矩阵。
2. 裁剪下方区域的前景图案到其边界框，得到一个 PxQ 的瓦片（前景为橙(7)，背景为黑(0)）。
3. 构建输出网格，尺寸为 (N*P) x (M*Q)。
4. 对颜色矩阵中第 i 行第 j 列的颜色 C，将瓦片的一个副本放置在输出网格的 (i*P, j*Q) 位置。瓦片中橙(7)前景像素重涂为颜色 C，黑(0)背景像素保持黑(0)。
5. 输出不包含灰分隔线。

**关键洞察**：分区网格并非被直接压缩输出（如参考题 90c28cc7），而是作为颜色图谱驱动瓦片铺排。输出尺寸同时取决于分区数和瓦片尺寸，颜色分布取决于分区采样——求解者需发现降采样和铺排的双重角色。

## 新题 4：空洞拓扑筛选目标 + 朝向映射定位印章

**组合逻辑**：[内部包含检测](含空洞→有效目标，无空洞→干扰项) → [朝向映射](精灵体缺角方向决定印章放置象限) → [印章覆盖](将精灵体印入目标矩形的指定象限)

**来源原语**：内部包含、含空洞对象重涂（b2862040）；印章覆盖、仅处理区域内标记、忽略干扰项（a04b2602）；朝向映射、缺角决定目标象限、精灵体、象限区（a61ba2ce）

**依赖链**：空洞拓扑检测筛选出有效目标矩形（无空洞的被忽略）→ 精灵体的缺角方向决定它被印入目标矩形的哪个象限 → 印章操作将精灵体写入该象限。删掉拓扑检测则无法区分有效目标和干扰项；删掉朝向映射则不知道印在哪里。

根据矩形框是否含空洞筛选有效目标，再按 L 形精灵体的缺角朝向将其印入目标框的对应象限。

**输入结构**：黑(0)背景网格，约 16x18。网格中有：
- 3-5 个红(2)矩形轮廓框（仅边框像素为红，内部为黑背景），边界框尺寸在 5x5 到 8x8 之间。其中部分框的内部存在被框完全围住的 4-连通黑(0)背景空洞（即框内有完整封闭区域），另一些框的内部无空洞（框的边框在某处有间断，使得内部与外部连通）。
- 若干绿(3) L 形精灵体，每个为 3 像素组成的 L 形，占据一个 2x2 边界框中的三个角（缺少一个角）。精灵体数量等于含空洞的矩形框数量。
- 生成约束：所有对象互不重叠且互不相邻（间距至少 1 像素）。每个精灵体的缺角方向（左上、右上、左下、右下）互不相同。

**规则**：
1. 对每个红(2)矩形框，检测其内部是否存在完全封闭的背景空洞：将框像素视为墙，检查框边界框内部的黑像素是否全部能通过 4-连通路径到达框外部。若存在无法到达外部的黑像素连通区域，则该框"含空洞"，标记为有效目标。
2. 不含空洞的矩形框为干扰项，在输出中保持不变。
3. 对每个绿(3) L 形精灵体，确定其缺角方向（2x2 边界框中缺少像素的那个角的位置）。
4. 将精灵体按照距离最近的有效目标矩形框配对（以精灵体中心到矩形框中心的曼哈顿距离为准，生成时保证配对无歧义）。
5. 对每个配对：将精灵体印入目标矩形框内部，放置在与缺角方向相反的象限。具体地，将矩形框内部划分为四个象限（以框中心为界），缺角在左上→印在右下象限的角落，缺角在右上→印在左下角落，以此类推。印章颜色使用蓝(1)。
6. 原始绿(3)精灵体从原位置移除（原位置变回黑(0)）。

**关键洞察**：红框中哪些是有效目标取决于拓扑属性（是否含封闭空洞），而非几何大小或位置。精灵体印入哪个象限取决于其自身朝向而非目标框的属性——拓扑筛选和朝向映射是两条独立的推理线索，必须同时正确才能得到正确输出。

## 新题 5：对称补全推导种子 + 递归自相似展开

**组合逻辑**：[对称补全](从角落碎片重建完整对称图案作为种子) → [递归展开](用重建的种子做前景/背景分别替换的自相似铺排)

**来源原语**：对称补全、角落补全四重对称、对称图案、精灵体（4290ef0e）；递归展开、自相似替换、前景背景分别替换、种子掩码、边界图例（58c02a16）

**依赖链**：输入中不存在完整种子——必须先从角落碎片做四重对称补全才能得到种子掩码。种子掩码的形状直接决定递归展开的结果。对称补全的错误会导致种子错误，进而导致展开完全不同。两步之间有强信息依赖。

从分散的角落碎片重建四重对称种子，然后用该种子做递归自相似展开铺满网格。

**输入结构**：黑(0)背景网格，约 15x15。网格左上角区域（约 5x5）内包含：
- 蓝(1)像素组成的 1-2 个角落 L 形碎片，每个碎片是一个更大对称图案的某个角落部分（占据该图案 3x3 边界框中的一个角落 2x2 区域的 L 形，即 3 像素）。碎片分布在该 5x5 区域的不同角落位置。
- 一条橙(7)实心线沿该区域的最右列和最下行形成 L 形边界（即右列全为橙、下行全为橙，右下角交汇）。
- 生成约束：蓝像素碎片足以唯一确定一个 3x3 的四重对称图案（至少展示了一个完整角落）。

**规则**：
1. 识别橙(7) L 形边界，将其围住的区域（去掉橙边界行和列后）作为种子区域（例如 3x3）。
2. 在种子区域内，蓝(1)碎片只展示了部分角落。对这些碎片做四重对称补全：将碎片翻转/旋转到四个角落，生成完整的 3x3 对称种子掩码（蓝像素为前景，黑像素为背景）。
3. 以该种子掩码做递归展开：种子中每个蓝(1)前景像素替换为一份完整种子的蓝(1)副本；种子中每个黑(0)背景像素替换为一份完整种子的橙(7)副本。得到一个 9x9 的展开图案。
4. 将展开图案从网格左上角开始铺排，裁剪到原网格尺寸。
5. 橙(7) L 形边界在输出中不保留（被展开图案覆盖）。

**关键洞察**：递归展开的种子在输入中并不完整——它以碎片形式存在，必须通过对称性推理重建。错误的对称补全会生成完全不同的递归图案。求解者需要先识别对称类型和碎片来源角，才能获得正确种子。

## 新题 6：双向控制像素射线交叉构墙 + 周期选区填充

**组合逻辑**：[射线延伸](从两条边的控制像素发射交叉射线) → [洪泛填充](射线交叉点形成墙，划分区域) → [排序 + 等间隔采样填充](区域排序后周期性选择着色)——动态分区结构

**来源原语**：射线延伸、控制像素、网格边缘（981add89）；洪泛填充、内外分区（7b6016b9）；排序、区域排列顺序、等间隔采样填充（7447852a）

**依赖链**：控制像素的位置决定射线走向 → 射线交叉形成网格状墙 → 墙的拓扑划分出若干背景区域 → 区域按位置排序后周期性选择填充。删掉射线则无墙、无分区；删掉周期选择则不知道填哪些区域。

从顶边和左边的控制像素发射交叉射线形成网格墙，然后对被墙划分出的区域做周期性着色。

**输入结构**：黑(0)背景网格，约 12x12。
- 顶边（第 0 行）有 2-4 个蓝(1)控制像素，分布在不同列。
- 左边（第 0 列）有 2-4 个红(2)控制像素，分布在不同行。
- 左上角 (0,0) 位置为黑(0)背景（不同时属于两组控制像素）。
- 网格其余位置为黑(0)背景。
- 生成约束：控制像素的行列不完全重叠，确保射线交叉产生至少 4 个封闭区域。

**规则**：
1. 每个顶边蓝(1)控制像素向下发射一条垂直射线，将该列从第 1 行到最后一行全部涂为蓝(1)。
2. 每个左边红(2)控制像素向右发射一条水平射线，将该行从第 1 列到最后一列全部涂为红(2)。
3. 蓝射线和红射线交叉的位置涂为绿(3)。
4. 射线像素（蓝、红、绿）视为墙。识别所有被墙和网格边界围住的 4-连通黑(0)背景区域。
5. 将这些区域按其边界框左上角坐标排序：先按行从上到下，行相同则按列从左到右。
6. 对排序后的区域列表，将索引为 0、2、4、6... 的区域（从 0 开始的偶数索引）洪泛填充为黄(4)，其余区域保持黑(0)。
7. 顶边和左边的控制像素自身保留原色。

**关键洞察**：射线不是输出的主角——它们动态构建了一张分区网格。增减一个控制像素会改变区域数量和排列，导致周期填充的结果发生非局部变化。求解者必须理解射线→分区→排序→周期选择的完整因果链。

## 新题 7：标记像素计数驱动同心正方形多步循环

**组合逻辑**：[计数](统计每个正方形内的标记像素数) → [缩放/边长循环变换](按标记数多次应用尺寸循环)——计数结果控制变换迭代次数

**来源原语**：缩放、边长循环变换、奇数边正方形、中心点、同心定位（522fdd07）；计数、标记像素、包含（d4c90558）

**依赖链**：标记像素数决定循环步数 → 循环步数决定最终边长 → 最终边长决定输出中正方形的大小。删掉计数则不知道循环几次；删掉循环规则则不知道如何变换尺寸。不同正方形的标记数不同，导致非均匀变换。

每个正方形内的灰色标记数决定其边长在奇数循环 (1-3-5-7-9) 中前进几步。

**输入结构**：黑(0)背景网格，约 21x21。网格中有 3-5 个互不重叠的单色实心正方形，每个边长为奇数（属于 {1, 3, 5, 7, 9}），颜色各不相同（使用蓝(1)、红(2)、绿(3)、黄(4)、品红(6)中的若干种）。部分正方形（边长 >= 3）的内部放置了若干灰(5)标记像素（占据正方形内部的背景色位置——即正方形本身为实心填充，灰标记像素覆盖在正方形像素之上）。标记像素数量为 1-4 个，不同正方形的标记数不同。边长为 1 的正方形不含标记（无空间放置），其标记数视为 0。
- 生成约束：每个正方形循环变换后不与其他正方形重叠（以各自中心和最终边长计算）。

**规则**：
1. 对每个彩色正方形，计算其内部（边界框范围内）的灰(5)标记像素数量 K。
2. 对该正方形的边长 S，应用 K 次缩小循环：每次将 S 替换为 S-2；若 S=1，则替换为 9（循环回卷）。即循环链为 9→7→5→3→1→9→7→...
3. 保持每个正方形的中心位置和颜色不变，仅将边长替换为循环后的新值。
4. 移除所有灰(5)标记像素（输出中不包含灰色）。

**关键洞察**：变换不是对所有正方形统一应用一次循环——每个正方形根据自身标记数循环不同步数。例如，一个 7x7 红正方形含 1 个标记 → 7→5（变为 5x5），而含 3 个标记 → 7→5→3→1（变为 1x1）。求解者需要同时发现循环规则和"标记数=步数"的隐蔽映射。

## 新题 8：面板位序选择对象 + 标尺长度决定平铺次数

**组合逻辑**：[位序选择](面板序号决定选取该面板中的第几个对象) → [裁剪](提取选中对象) → [平铺](标尺长度决定重复铺排次数)——选择机制和铺排参数分别来自不同空间线索

**来源原语**：位序选择、面板序号选对象、等分面板、分隔条、前景对象（5ecac7f7）；平铺、标尺条、标尺长度决定重复（9c1e755f）；裁剪（57edb29d）

**依赖链**：面板位置决定选哪个对象 → 标尺长度决定该对象平铺几次。面板和标尺共同约束输出：面板选内容，标尺选数量。删掉位序选择则不知道选哪个对象；删掉标尺则不知道重复几次。

从三个面板中按位序选出对象，再按各面板下方标尺的长度分别平铺。

**输入结构**：黑(0)背景网格，约 12x30（宽大于高）。三个 HxH 正方形面板（H 约 8-10）由 1 像素宽的灰(5)竖直分隔条隔开。每个面板内包含恰好 3 个同色 4-连通前景对象（颜色在蓝(1)、红(2)、绿(3)之间，三个面板颜色各不相同），各对象为 3-8 像素的不规则形状，水平位置互不重叠。每个面板正下方（紧贴面板底边）有一条水平灰(5)标尺条，长度为 2-5 个像素，标尺条左端与面板左端对齐。
- 生成约束：每个面板内 3 个对象的边界框水平方向不重叠（可明确区分最左、中间、最右）。

**规则**：
1. 从左面板（第 1 个）中选取水平位置最靠左的对象（按边界框左边缘最小值）。
2. 从中间面板（第 2 个）中选取水平位置居中的对象（按边界框左边缘排序取第 2 个）。
3. 从右面板（第 3 个）中选取水平位置最靠右的对象（按边界框左边缘最大值）。
4. 将每个选中对象裁剪到其边界框。
5. 读取每个面板下方标尺条的长度（灰像素个数），记为 R1、R2、R3。
6. 构建输出：三行堆叠。第 1 行将左面板选中对象水平重复 R1 次，副本之间插入 1 列黑(0)间隔。第 2 行将中间面板选中对象水平重复 R2 次，同样间隔。第 3 行同理。各行之间插入 1 行黑(0)间隔。输出宽度取三行中最宽者，较短行右侧用黑(0)填充。

**关键洞察**：面板的位序（左/中/右）同时决定两件事：从该面板中选第几个对象（左面板选最左、中面板选中间、右面板选最右），以及使用哪条标尺的长度。仅凭单个示例很难同时确定选择规则和重复规则——需要对比多个示例中不同面板内对象排列顺序的变化。

## 新题 9：对称补全扩展画布 + 边距保持的标记图案镜像迁移

**组合逻辑**：[对称补全](将部分对称结构扩展为完整四重对称画布) → [图案迁移](将已有象限中的标记按边距保持规则镜像迁移到新象限)——同时约束结构，补全决定画布形态，画布形态决定迁移的边界参照

**来源原语**：对称补全、角落补全四重对称、对称图案（4290ef0e）；图案迁移、边距保持迁移（57edb29d）；裁剪（57edb29d）；标记像素（d4c90558/a04b2602）

**依赖链**：对称补全生成了新的象限区域（此前为空）→ 图案迁移需要知道新象限的边界才能计算边距 → 标记的镜像方式取决于对称轴方向。补全和迁移共享同一空间框架，互为前提。

将半成品对称图案补全为四重对称，并将已有象限中的标记像素按边距保持规则镜像复制到新象限。

**输入结构**：黑(0)背景网格，约 13x13（奇数边长正方形）。网格中有蓝(1)像素构成的结构图案，仅占据左半部分（左上和左下两个象限，以网格中心列为对称轴）。该图案关于水平中心行具有上下对称性（即左上象限和左下象限关于水平轴对称），但右半部分（右上和右下象限）为空（黑背景）。在左半部分的蓝图案像素之间散布有若干红(2)标记像素（2-5 个），每个标记位于蓝图案的边界框范围内。
- 生成约束：蓝图案补全右半部分后形成左右+上下均对称的四重对称图案。红标记不位于对称轴上。

**规则**：
1. 将蓝(1)图案沿垂直中心列做左右镜像，补全右半部分。此时蓝图案在四个象限均存在，形成四重对称。
2. 对左半部分的每个红(2)标记像素，计算它到其所在象限（左上或左下）四条边界（象限的上、下、左、右边缘）的距离：d_top、d_bottom、d_left、d_right。
3. 将该标记镜像迁移到水平对称的对应象限（左上的标记→右上，左下的标记→右下）：在目标象限中，保持 d_top 和 d_bottom 不变，将 d_left 和 d_right 互换（即左右镜像边距）。
4. 新标记像素同为红(2)。原始标记保留不变。
5. 输出为完整的四重对称蓝图案加上左右对称分布的红标记。

**关键洞察**：标记的迁移不是简单的坐标镜像——它是"边距保持"镜像：每个标记到象限边缘的距离在目标象限中水平翻转但垂直保持。如果求解者错误地将标记到网格边缘的距离（而非到象限边缘的距离）做镜像，会得到错误位置。必须先正确完成对称补全以确定象限边界，才能正确计算边距。

## 新题 10：引导条压缩内部对象为线段 + 标记块对角映射填充侧翼区域

**组合逻辑**：[压缩](引导条朝向决定压缩方向，内部对象像素数决定线段长度) → [重建](引导条贴靠线段两侧) → [对角映射](线段端点处的标记块按对角规则填充引导条与线段围成的矩形区域)

**来源原语**：压缩、重建、引导条、内部对象、线段、像素数决定长度、引导条决定朝向（c61be7dc）；对角映射、标记块、标记色填对角区、象限区域（93b581b8）

**依赖链**：引导条方向决定压缩轴向 → 内部对象像素数决定线段长度 → 线段位置决定引导条重建位置 → 引导条和线段围成的矩形为对角映射提供区域边界 → 标记块颜色填充这些区域。压缩步骤改变了空间布局，对角映射必须在新布局上执行。

将内部对象压成居中线段、引导条重建贴靠线段后，用端点标记块的对角映射规则填充线段两侧区域。

**输入结构**：黑(0)背景网格，约 15x15。
- 灰(5)引导结构：两条平行的灰竖条（全高，各 1 像素宽，间距约 7-9 列），加一条垂直于它们的灰水平中心条（全宽，1 像素高，穿过两竖条之间的中点行）。
- 两竖条之间有一个橙(7)的 8-连通内部对象（不规则形状，4-10 像素），不接触引导条。
- 在灰水平中心条的左端和右端各有一个 2x2 的彩色标记块（每块包含 4 个像素，颜色来自蓝(1)、红(2)、绿(3)、黄(4)，每个标记块的 4 个像素颜色各不相同）。
- 生成约束：内部对象完全在两竖条和水平中心条围成的某个半区内，不跨越中心条。

**规则**：
1. 计算橙(7)内部对象的像素数 L。
2. 将内部对象移除，在灰水平中心条上以其中点为中心，绘制一条垂直方向的橙(7)线段，长度为 L 像素（向上下各延伸 floor(L/2) 像素，若 L 为偶数则向下多延伸 1 像素）。
3. 移除原有两条灰竖条。在橙线段紧邻的左右各 1 列位置重建两条新的灰竖条（全高）。
4. 此时橙线段与两侧灰竖条之间无间隙（灰竖条紧贴橙线段）。线段上方和下方各形成一个矩形空白区域（由灰竖条左右夹持、橙线段端点和网格边缘上下界定）。将每个端点侧的矩形区域视为一个 2x2 的象限布局。
5. 读取水平中心条左端的 2x2 标记块：其 4 个像素按位置分为左上、右上、左下、右下。对橙线段上端形成的矩形区域，将其划分为 4 个象限（以矩形中心为界）。左上像素的颜色填充矩形的右下象限，右上填左下，左下填右上，右下填左上（对角映射）。
6. 同理，用水平中心条右端的 2x2 标记块对橙线段下端形成的矩形区域做对角映射填充。
7. 灰引导结构、橙线段和标记块本身保留在输出中。

**关键洞察**：对角映射的填充区域不是预先存在的——它们由压缩步骤重建引导条后才产生的空间间隙决定。标记块的空间意义（哪个像素对应哪个象限）取决于压缩后的布局而非原始布局。求解者必须先完成压缩和重建，才能正确定义对角映射的目标区域。
