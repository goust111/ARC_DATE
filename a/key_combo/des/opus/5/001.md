## 新题 1：对称清洗决定叠加优先级

**组合逻辑**：[对称补全](逐色去噪) → [计数](统计存活像素) → [透明叠加](按存活数排优先级) — 三者均为已有原语，创新在于：去噪输出改变计数结果，计数结果决定叠加顺序，形成信息逐步变换的链条，源题中不存在此结构关系。

**来源原语**：对称补全、色层、对称轴、逐色处理（源自 8e5c0c38）；透明叠加、同尺寸对齐、标记无冲突合并（源自 25e02866）；计数（源自 902510d5）

**依赖链**：每种颜色独立检测对称轴 → 对称轴决定哪些像素是噪声 → 去噪改变各颜色的像素总数 → 像素总数决定叠加优先级 → 优先级决定重叠位置的最终可见颜色。

以黑色画布为基底，逐色执行垂直对称清洗以去除噪声像素，再按清洗后像素数从多到少依次绘制各色层，最后绘制的（最少像素的）层覆盖在最上方。

**输入结构**：
- 网格约 14x14，黑(0)为背景。
- 3 种非背景颜色（如蓝(1)、红(2)、绿(3)），每种颜色的像素各自形成一个大致关于某条垂直轴对称的图案。三种颜色的图案在空间上部分重叠（占据同一片矩形区域的不同位置，但至少有若干像素位置是两种或三种颜色共享的候选位置）。
- 每种颜色各有其独立的垂直对称轴（轴位置可以不同）。
- 每种颜色各有 2-4 个"噪声"像素——缺少镜像对应像素的单点，打破该颜色的对称性。
- 生成约束：三种颜色清洗后的像素总数必须互不相同；清洗后至少有一对颜色在某些像素位置上重叠。

**规则**：
1. 对每种非背景颜色独立处理：找到使该颜色拥有最多镜像配对像素的垂直轴（半整数列坐标）。
2. 移除该颜色中所有缺少同色镜像对应像素的点（即噪声）。
3. 统计每种颜色清洗后的剩余像素数。
4. 在输出网格上按清洗后像素数从多到少的顺序依次绘制各色层：先绘制像素最多的颜色，再绘制次多的，最后绘制最少的。后绘制的像素覆盖先绘制的。
5. 未被任何清洗后色层覆盖的单元格保持黑(0)。

**关键洞察**：去噪不是终态装饰——它改变各颜色的像素数排名，从而翻转叠加顺序。一种原始像素极多但对称性差的颜色可能因清洗损失大量像素而排名下降，反而被更稀疏但高度对称的颜色压在下方。求解者必须先确定每种颜色的对称轴，才能判断哪些像素存活、谁在上层。

## 新题 2：沿引导路径弹射

**组合逻辑**：[弹射](创新：轨迹由路径而非直线决定) → [路径追踪](创新：路径作为弹射轨道而非通向目标物体) → [像素数守恒](创新：决定路径着色长度而非射线长度) — 弹射与路径追踪均为已有原语，创新在于路径充当弹射轨道，源题中弹射走直线、路径通向终点物体，二者从未组合为"沿任意路径弹射"的结构。

**来源原语**：弹射、杯形框架、内容像素、尾刺、尾部朝向决定射出、像素数守恒（源自 3dc255db）；路径追踪、引导像素、路径连接（源自 9ba4a9aa）

**依赖链**：尾刺尖端的位置选择相邻的引导路径入口 → 引导路径提供弯折的弹射轨道 → 杯内内容像素数决定沿路径着色的长度 → 内容被擦除，路径前 N 格被重涂为内容色。

将杯形框架内的内容像素擦除，沿从尾刺出发的灰色引导路径重新着色，着色长度等于原内容像素数。

**输入结构**：
- 网格约 18x18，黑(0)为背景。
- 2-3 个杯形框架，各自使用一种独特的边框颜色（如蓝(1)、绿(3)）。每个杯形为一个 4-连通的开口容器：三面封闭、一面开口（"杯口"），杯口对面有一个汇聚的尾刺（1-2 个像素构成的尖端，指向杯外）。杯形框架约 5-8 像素高、4-6 像素宽。
- 每个杯的杯口内部包含 2-5 个内容像素，各杯的内容颜色互不相同且与边框色、背景色不同（如红(2)、黄(4)）。
- 引导路径：从每个尾刺尖端的 4-邻接位置出发，由灰(5)像素组成的 4-连通链条，蜿蜒穿过网格。每条路径不进入任何杯的内部，不与其他路径交叉，不经过其他杯的边框。每条路径的灰(5)像素数至少等于其对应杯的内容像素数。
- 生成约束：每个尾刺尖端恰好有一条灰(5)路径与之 4-邻接。路径链条无分叉（每个路径像素至多有两个同色 4-邻居）。

**规则**：
1. 对每个杯，统计其杯口内的内容像素数 N，记录内容颜色 C，定位尾刺尖端。
2. 擦除杯口内所有内容像素（置为黑(0)）。
3. 找到与尾刺尖端 4-邻接的灰(5)像素作为引导路径的起点。沿路径追踪：从起点出发，每一步移动到当前像素的唯一未访问灰(5) 4-邻居。
4. 将路径的前 N 个像素从灰(5)重涂为内容颜色 C。
5. 将路径中第 N+1 个及之后的所有灰(5)像素擦除（置为黑(0)）。
6. 杯形框架的边框像素保持不变。

**关键洞察**：弹射轨迹不是直线（区别于源题 3dc255db 的直线射出），而是沿着任意弯折的引导路径行进。尾刺的作用从"方向指示器"变为"路径选择器"——它指向一条特定引导路径的入口，而非指示罗盘方向。求解者需同时理解杯的结构（找尾刺和内容数量）和路径追踪（找轨迹），二者缺一不可。

## 新题 3：图例调色板同心光晕

**组合逻辑**：[膨胀](创新：多层而非单层光晕) + [填充](同心距离环) + [图例映射](创新：一对多循环调色板而非一对一映射) — 膨胀和图例映射为已有原语，创新在于图例提供多色循环调色板驱动距离环着色，源题中图例仅映射到单一光晕色、同心环仅使用固定调色板。

**来源原语**：膨胀、颜色图例、图例映射、孔洞保留不填（源自 5adee1b2）；填充、同心环、距离映射、曼哈顿距离、循环色板（源自 aaef0977）

**依赖链**：图例条目提供每种源色的有序调色板 → 曼哈顿距离决定使用调色板中的哪个位置 → 调色板长度不同导致不同颜色的物体产生不同周期的环纹 → 多物体光晕重叠时取距源物体更近者 → 封闭孔洞免于填充。

读取左侧图例获得每种物体颜色的多色调色板，以物体边界为原点按曼哈顿距离循环着色同心光晕，重叠处取近者优先，封闭孔洞保留。

**输入结构**：
- 网格约 18x18，黑(0)为背景。
- 左侧边缘（第 0 列）：2-3 个图例条目，各条目之间至少隔 2 行背景。每个条目是一列纵向排列的 3-4 个彩色像素。每条目最上方的像素为"源色"（标识它对应的物体颜色），其下方的像素（从上到下）构成该源色的光晕调色板循环序列。
- 主区域（第 2 列起）：2-4 个单色 4-连通物体，每个物体使用图例中某个源色，像素数约 5-15，形状不规则（非矩形）。部分物体可能包含封闭孔洞（被物体像素完全 4-包围的背景连通分量，面积 >= 3 个像素）。
- 生成约束：不同源色的物体之间至少间隔 3 格背景。每个图例源色至少对应一个物体。无两个图例条目共享源色。各图例条目的调色板长度可以不同（如一个 3 色、一个 4 色）。

**规则**：
1. 读取图例：对每个条目，最上方像素为源色 S，其下方像素按从上到下顺序构成调色板 P = [P1, P2, ..., Pk]（k 为下方像素数）。
2. 对每个源色 S 的物体，计算网格中每个背景像素到该物体最近像素的曼哈顿距离 D（距离以物体边界为基准，非中心）。
3. 距离为 D 的背景像素涂为 P[((D-1) mod k) + 1]，即 D=1 涂 P1，D=2 涂 P2，...，D=k 涂 Pk，D=k+1 涂 P1，以此循环。
4. 若某像素同时处于两个同源色物体的光晕范围内（距离相同且调色板相同），颜色一致，直接涂色。
5. 若某像素接收来自不同源色物体的光晕，取距其最近物体的光晕颜色。若距两个不同源色物体的距离相同，取图例中行号更小（更靠上）的源色的调色板颜色。
6. 物体内部的封闭孔洞（面积 >= 3 的背景连通分量被物体像素完全包围）不填充，保持黑(0)。面积 < 3 的内部背景像素视为普通背景，正常接受距离 1 的光晕着色。
7. 图例区域（第 0 列和第 1 列）在输出中清除为黑(0)。

**关键洞察**：图例不再是简单的"源色→单一光晕色"映射（区别于源题 5adee1b2），而是"源色→多色循环调色板"。调色板长度不同导致不同物体的光晕呈现不同周期的色环——长调色板的物体产生缓变色带，短调色板的物体产生快速重复条纹。求解者必须从图例条目的长度推断循环周期。

## 新题 4：嵌套深度偏移的同心填充

**组合逻辑**：[包含树](树分析得深度) → [填充](创新：以深度为参数偏移循环色板) + [循环色板](创新：起始位置由外部参数控制) — 包含树和循环色板为已有原语，创新在于嵌套深度成为色板偏移量驱动填充着色，源题中包含树用于布局规范化、色板使用固定起始。

**来源原语**：规范化、嵌套框架、封闭区域、包含树、拓扑决定布局（源自 2d0172a1）；填充、同心环、距离映射、曼哈顿距离、循环色板（源自 aaef0977）

**依赖链**：检测框架嵌套结构 → 构建包含树 → 树中各区域的深度值确定 → 深度值偏移循环色板的起始颜色 → 曼哈顿距离选择色板中的具体条目 → 叶区域用同心环、非叶区域用深度对应的单色。

在嵌套矩形框架结构中，对叶区域按中心曼哈顿距离绘制同心色环，色板起始色由该区域的嵌套深度偏移；非叶区域涂其深度对应的单色。

**输入结构**：
- 网格约 20x20，黑(0)为背景。
- 灰(5)像素构成矩形框架边界（1 像素厚）。框架为轴对齐矩形，嵌套深度最多 3 层。一个框架的内部可能包含 0 个或多个子框架。
- 存在至少 2 棵独立的框架树（互不嵌套的最外层框架）。
- 叶区域：框架内部不含任何子框架的空间。非叶区域：框架内部包含至少一个子框架的空间（子框架周围的区域）。
- 生成约束：至少存在两个叶区域处于不同的嵌套深度。所有框架至少 5x5（内部至少 3x3）。同一深度若有多个叶区域，其内部尺寸应不同（使环纹看起来不同），以引导求解者注意深度而非尺寸。

**规则**：
1. 构建包含树：框架 A 是框架 B 的父级，当且仅当 B 的内部完全在 A 的内部之内，且不存在另一框架 C 满足 A 包含 C 包含 B。
2. 赋深度：最外层框架（无父级）深度为 1。子框架深度 = 父框架深度 + 1。
3. 定义循环色板：[蓝(1), 红(2), 绿(3), 黄(4), 橙(7), 品红(6), 青(8), 栗(9)]，长度 L=8。
4. 对每个叶区域：取其内部矩形的中心像素坐标（宽和高均取 floor(center_row), floor(center_col)）。对内部每个非边框像素，计算到中心的曼哈顿距离 D。涂色为色板位置 ((D + depth - 1) mod L)，其中 depth 是该区域的嵌套深度。中心像素 D=0，涂色板位置 ((depth - 1) mod L)。
5. 对每个非叶区域：其内部中不属于任何子框架或子框架内部的像素，统一涂色板位置 ((depth - 1) mod L) 对应的单色。
6. 灰(5)框架边界保持不变。
7. 所有框架外部的像素保持黑(0)。

**关键洞察**：同样距中心为 D 的像素，在不同嵌套深度的叶区域中会呈现不同颜色——深度偏移了色板起始位置。求解者无法仅看单个区域推断色板规则，必须比较不同深度的区域才能发现偏移关系。这种"参数化填充"结构源题中不存在。

## 新题 5：面积排序的滑轨对接

**组合逻辑**：[排序](面积决定处理顺序) → [平移](滑动对接) → [轨迹涂黑](创新：轨迹成为后续对接的物理障碍) — 排序和平移为已有原语，创新在于滑动轨迹不只是视觉标记，还作为障碍影响后续方块的对接位置，形成处理顺序→轨迹→位置冲突的涌现效应。

**来源原语**：排序、边框方块、距离优先排序（源自 b5ca7ac4）；平移、括号框、通道对齐、目标底边对齐（源自 df9fd884）；对接、内部槽位、轨迹涂黑（源自 8b9c3697）

**依赖链**：边框颜色匹配方块与括号框 → 面积排序确定处理顺序 → 处理顺序决定谁先占位 → 先到者的轨迹和占位阻挡后到者 → 被阻挡者被迫向右偏移 → 偏移量取决于先到者的尺寸。

按面积从大到小依次将各边框方块向左滑入同色括号框，滑动留下灰色轨迹，后处理的方块若目标位置被先到者的轨迹或占位阻挡则右移一个方块宽度。

**输入结构**：
- 网格约 22x18，黑(0)为背景。
- 左侧边缘：3-4 个括号框（C 形，开口朝右），各自使用一种独特颜色（如蓝(1)、红(2)、绿(3)、黄(4)）。括号框沿左侧垂直排列，各框之间至少隔 2 行背景。每个括号框的开口高度与其对应方块的边长匹配。
- 右半区域：3-4 个边框方块，尺寸分别不同（如 3x3、5x5、7x7），每个方块有 1 像素厚的边框（颜色与某个括号框相同）和独特的内部填充色。方块散布在网格右半部分。
- 生成约束：每个括号框颜色恰好对应一个方块。至少两个括号框的行范围重叠（它们的开口在垂直方向有交叉）。所有方块面积互不相同。

**规则**：
1. 按边框颜色将每个方块与同色括号框配对。
2. 按方块面积从大到小排序（面积不同，无需 tie-break）。
3. 按此顺序依次处理每个方块：
   a. 目标位置：方块保持原始行不变，左移使其左边缘对齐括号框开口右侧的第一列（即紧贴括号框内侧）。
   b. 检查目标位置的所有像素是否均为黑(0)（未被先前放置的方块或轨迹占据）。
   c. 若目标位置有任何非黑像素，将目标列右移该方块的宽度，重复检查，直到找到完全空闲的位置。
4. 将方块放置在最终确定的目标位置（保留原始边框和填充颜色）。
5. 方块从原始位置到最终位置之间经过的所有像素列（不含最终位置本身，含原始位置），在方块的行范围内涂为灰(5)——这是滑动轨迹。若轨迹像素覆盖了更早的轨迹，后来的轨迹覆盖先前的。
6. 括号框保持不变。

**关键洞察**：大方块先到先得，它不仅占据括号框附近的空间，其宽大的滑动轨迹还横跨大片区域。后处理的小方块即使目标括号框在不同行，也可能因大方块的轨迹经过其目标位置而被迫右移。这种"轨迹即障碍"的涌现效应在任何源题中都不存在——处理顺序不仅决定谁先到，还通过物理痕迹改变后续者的约束空间。

## 新题 6：对称清洗重塑射线障碍

**组合逻辑**：[对称补全](创新：清洗结果作为下游约束输入而非最终输出) → [射线延伸](创新：障碍集由上游清洗动态决定而非预设) — 两者均为已有原语，创新在于对称清洗的输出成为射线的障碍配置，清洗移除的像素改变射线可达长度，形成"约束变换→受约束生成"的结构。

**来源原语**：对称补全、色层、对称轴、逐色处理、忽略干扰项（源自 8e5c0c38）；射线延伸、侧标记、阻挡像素、遇阻停止（源自 95755ff2）

**依赖链**：蓝色图案的对称轴检测 → 识别噪声像素 → 移除噪声改变蓝色像素分布 → 分布变化导致某些列的最高蓝色像素行号改变 → 行号改变决定从顶部标记射出的射线长度。

将蓝色前景图案按垂直对称清洗去噪，清洗后的蓝色像素作为阻挡物，从顶部边缘标记向下射出彩色射线直至遇阻或触底。

**输入结构**：
- 网格约 15x15，黑(0)为背景。
- 蓝(1)像素在网格下半部（约第 7-14 行）形成一个大致关于某条垂直轴对称的图案（约 20-35 个蓝色像素）。图案中有 3-5 个噪声像素——缺少关于最佳对称轴的镜像对应点。
- 顶部边缘（第 0 行）：3-5 个单像素标记，各自使用不同的非蓝、非黑颜色（如红(2)、绿(3)、黄(4)、橙(7)），分布在不同列。
- 生成约束：至少一个标记所在列中存在噪声像素（即移除该噪声后，该列最高蓝色像素的行号发生变化，从而改变射线长度）。至少一个标记所在列不受噪声影响（清洗前后射线长度相同）。蓝色图案有唯一最佳垂直对称轴。

**规则**：
1. 找到蓝(1)图案的最佳垂直对称轴（使镜像配对像素数最多的半整数列坐标），移除所有缺少同色镜像对应点的蓝色像素。
2. 对每个顶部标记像素，从其正下方（第 1 行）开始，沿该列向下射出一条射线，使用标记的颜色。
3. 射线逐行涂色，仅涂黑(0)像素。遇到清洗后存活的蓝(1)像素时停止（该蓝色像素本身不被涂色）。若整列无蓝色像素则涂至网格底部。
4. 标记像素本身保留在输出中。清洗后的蓝(1)图案保留。被清洗移除的蓝色像素位置变为黑(0)。

**关键洞察**：噪声像素若保留则会阻挡射线，但清洗将其移除后射线得以延伸更远。反过来，噪声像素的镜像对应位置（原本就存在的蓝色像素）继续作为阻挡物。求解者必须正确判定对称轴以确定哪些蓝色像素是噪声，才能预测每条射线的终止位置。这种"清洗重塑约束景观"的结构在源题中不存在。

## 新题 7：最短路径筛选字形印章

**组合逻辑**：[寻路](创新：最短路径作为空间筛选器而非填充目标) → [图案印章](创新：仅对筛选通过的控制像素执行而非全部) + [裁剪](清除图例区) — 寻路和图案印章为已有原语，创新在于最短路径决定哪些控制像素"激活"，同色像素因位置不同而命运迥异，源题中寻路用于路径填充、印章无条件展开所有控制像素。

**来源原语**：寻路、端点分量、走廊通道、最短路径、路径及相交房间（源自 3ad05f52）；图案印章、控制像素、字形字典、编码映射、裁剪（源自 dfadab01）

**依赖链**：迷宫最短路径求解 → 路径经过的格子集合确定 → 集合充当空间滤波器筛选控制像素 → 通过筛选的控制像素查表展开为字形 → 未通过的同色控制像素被擦除 → 图例区被裁剪清除。

在迷宫中找到两端点间的最短路径，仅将路径上的彩色控制像素展开为图例对应的字形，路径外的同色像素和图例区均被擦除。

**输入结构**：
- 网格约 20x20。灰(5)像素构成迷宫墙壁（1 像素厚），黑(0)为可通行走廊。
- 两个红(2)单像素端点分别位于走廊中，一个靠近左上、一个靠近右下。
- 4-6 个彩色单像素（从蓝(1)、绿(3)、黄(4)、橙(7)中选取）散布在走廊中。其中至少 2 个位于两端点间的最短路径上，至少 2 个不在任何最短路径上。
- 右下角：一块由灰(5)墙壁隔出的 4x8 图例区域，内含 2 个字形定义。每个字形是一个 4x4 图案（使用栗(9)色绘制），其右侧紧邻一个单像素颜色标签。标签颜色标识该字形对应哪种控制像素颜色。
- 生成约束：两端点间的最短路径唯一（仅一条路径具有最小长度）。图例中的标签颜色恰好对应路径上出现的控制像素颜色。路径上每种颜色的控制像素至少 1 个。

**规则**：
1. 在迷宫中求从一个红(2)端点到另一个红(2)端点的唯一最短 4-连通路径（灰(5)为墙壁不可通行，黑(0)为走廊可通行，控制像素和端点所在格也可通行）。
2. 识别位于最短路径上的控制像素（非黑、非灰、非红的彩色像素且其坐标在最短路径的格子集合中）——这些为"激活"像素。
3. 对每个激活控制像素，在图例中查找与其颜色匹配的标签对应的 4x4 字形。
4. 以该控制像素的坐标为字形左上角，用栗(9)色绘制字形。字形像素若落在灰(5)墙壁上或网格外则不绘制（裁剪）。字形像素可覆盖黑(0)走廊像素和其他控制像素。
5. 擦除所有未激活的控制像素（置为黑(0)）。
6. 擦除整个图例区域（图例区内所有像素置为黑(0)，包括其灰色围墙）。
7. 红(2)端点、迷宫主体墙壁（图例围墙除外）、最短路径上的走廊像素（未被字形覆盖的部分）保留。

**关键洞察**：最短路径是一个空间筛选器——同色的控制像素仅因位于不同走廊而命运不同：路径上的展开为字形，路径外的消失。求解者必须先解迷宫确定最短路径，才能判断哪些像素应展开、哪些应擦除。

## 新题 8：标记定旋转的递减嵌套

**组合逻辑**：[旋转](创新：旋转角度由标记像素的角位决定而非固定) → [排序](面积递减) → [嵌套](创新：旋转改变宽高从而改变嵌套几何) — 旋转和嵌套为已有原语，创新在于标记位置驱动旋转、旋转改变矩形的宽高比、宽高比改变嵌套排布，形成"局部标记→全局几何"的信息放大链。

**来源原语**：旋转、拼接、矩形精灵体、标记像素、锚定定位、标记定输出朝向（源自 7b3084d4）；排序、嵌套、前景矩形、面积递减嵌套、角落对齐嵌套（源自 6cbe9eb8）

**依赖链**：每个精灵体的标记像素角位决定旋转角度 → 旋转后非正方形精灵体的宽高互换或保持 → 宽高改变影响嵌套时的空间排布 → 面积排序决定嵌套顺序 → 角落对齐使用旋转后的尺寸。

将每个矩形精灵体旋转至其标记像素位于左上角，按面积从大到小逐层嵌套在左上角对齐位置，标记像素在输出中消除。

**输入结构**：
- 网格约 18x18，黑(0)为背景。
- 4-5 个实心矩形精灵体，各自使用一种独特的非黑颜色（如蓝(1)、红(2)、绿(3)、黄(4)、橙(7)），散布在网格中互不重叠。精灵体尺寸各不相同且均为非正方形（如 3x7、4x6、5x8、2x9、6x3），使得 90 度旋转必然改变宽高。
- 每个精灵体恰有一个像素使用灰(5)色（"标记像素"），位于该精灵体边界框的四个角之一。其余像素均为精灵体的主色。
- 生成约束：所有精灵体面积（宽x高）互不相同。旋转后（标记到左上角），每个较小精灵体的旋转后宽度 < 上一级精灵体的旋转后宽度 - 2，且旋转后高度 < 上一级精灵体的旋转后高度 - 2（确保可嵌套且有间隙）。

**规则**：
1. 对每个精灵体，确定其标记像素（灰(5)）位于边界框的哪个角（左上、右上、左下、右下）。
2. 按最小旋转角度（0/90/180/270 度顺时针）旋转精灵体，使标记像素落在旋转后边界框的左上角。具体地：标记在左上角→旋转 0 度；标记在右上角→旋转 270 度（逆时针 90 度）；标记在右下角→旋转 180 度；标记在左下角→旋转 90 度。
3. 将标记像素替换为该精灵体的主色（灰(5)消失）。
4. 按旋转后的面积（=原面积，不变）从大到小排序。面积相同时不会出现（生成约束保证面积互不相同）。
5. 将最大精灵体放在输出的 (0, 0) 位置（左上角对齐）。
6. 将每个后续精灵体放在前一个精灵体的左上角偏移 (1, 1) 的位置——即向下 1 行、向右 1 列。后放置的精灵体像素覆盖先放置的。
7. 输出裁剪为最大精灵体旋转后的边界框尺寸。

**关键洞察**：旋转由标记位置决定，而旋转改变非正方形精灵体的宽高比。一个 3x7 的精灵体旋转 90 度后变成 7x3，嵌套时的可用空间完全不同。求解者必须正确识别每个标记的角位才能推导旋转角度，继而确定旋转后的尺寸和最终嵌套布局。标记像素是一个微小的局部线索，却决定了全局几何结构。
