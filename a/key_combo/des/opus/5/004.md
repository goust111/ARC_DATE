## 新题 1：缺口瞄准射线围合填充

**组合逻辑**：[notch_determines_dir](创新：缺口不决定滑动方向，而决定射线发射方向) → [ray_extend](已有) → [contour_enclosure](创新：围合边界部分由射线动态生成) → [flood_fill](已有)

**来源原语**：notch_determines_dir / border_notch / foreground_object（320afe60）；ray_extend（981add89）；contour_enclosure / enclosed_bg_region / flood_fill（753ea09b）

**依赖链**：缺口几何形状 → 决定射线方向 → 射线修改网格拓扑 → 射线与已有障碍联合形成封闭边界 → 封闭区域被识别并填充。删除缺口分析则射线方向不确定；删除射线则无封闭区域产生；删除填充则输出不完整。

从每个带缺口的小对象发射一条射线，射线与固定障碍共同围合出背景区域，再对封闭区域洪水填充。

**输入结构**：约 12x15 网格，背景黑(0)。散布 3-5 个蓝(1) 小型 4-连通单色对象，每个 3-6 像素，紧凑形状。部分对象的边界框边缘存在一个凹缺口（边界框某侧有一个被背景像素打断的间隙，间隙两侧均为对象像素）。其余对象无缺口（边界框各侧连续）。另有若干灰(5) 单像素宽直线段（水平或垂直，长度 3-8 像素），充当固定障碍。生成约束：各对象互不相邻（最小间距 2 像素）；每个有缺口对象的射线路径上不会与另一条射线交叉；至少存在一个背景区域仅在正确射线到位后才被完全围合。

**规则**：
1. 对每个边界框某侧有凹缺口的蓝(1)对象，确定缺口朝向的基方向（缺口开口朝向的那个正方向：上/下/左/右）。
2. 从缺口开口处紧邻的背景像素出发，沿缺口方向逐像素延伸一条红(2)射线，直到碰到任意非背景像素或网格边缘为止（终点像素不被覆盖）。
3. 无缺口的蓝(1)对象不发射射线，原地保留。
4. 所有射线绘制完成后，找出所有 4-连通背景(0)区域，其中每一个像素都无法通过背景路径到达网格任意一条边界的，视为"封闭区域"。（围合边界包括：蓝对象、灰障碍、红射线、网格边缘。）
5. 将每个封闭背景区域洪水填充为绿(3)。
6. 蓝对象、灰障碍、红射线均保持不变。

**关键洞察**：缺口不是装饰缺陷——它物理上瞄准一条射线，补全了障碍之间的断裂。求解者必须先从对象形状中识别缺口朝向、再追踪射线轨迹、最后才能判断哪些背景区域被围合。

## 新题 2：逐侧少数对角方向镜像

**组合逻辑**：[classify + diagonal_orientation](已有) → [counting 按侧统计](创新：不是全局计数，而是在对称轴两侧分别计数) → [outlier_selection 逐侧](创新：少数群由每侧独立决定) → [mirror + reflect_along_axis](已有) → [recolor 按朝向着色](创新：镜像副本的颜色由其源朝向决定，而非由多数/少数关系决定)

**来源原语**：classify / diagonal_bar / diagonal_orientation / majority_orient_color（1d61978c）；mirror / symmetry_axis / outlier_selection / min_pixel_color / reflect_along_axis（ad3b40cf）

**依赖链**：朝向分类 → 逐侧像素统计 → 每侧独立选出少数朝向 → 对少数朝向执行跨轴镜像 → 镜像副本按源朝向着色。两侧少数朝向可能不同，因此同一朝向类型可能在一侧被镜像、另一侧不被镜像——这种不对称性需要对比多个示例才能归纳。

在对称轴两侧分别找出像素更少的对角朝向组，将其跨轴镜像并按源朝向重涂色。

**输入结构**：约 15x15 网格，背景黑(0)。一条完整行或完整列的灰(5)像素构成对称轴（横轴或纵轴）。轴两侧散布若干橙(7)对角线段（单像素宽，8-连通，每段纯粹沿 NW-SE 或 NE-SW 方向延伸，长度 2-5 像素）。生成约束：每侧均有两种朝向的线段；两侧的少数朝向不同（例如左侧 NW-SE 是少数，右侧 NE-SW 是少数）；无线段横跨或接触对称轴；镜像后的副本不会与已有非背景像素重叠。

**规则**：
1. 将每个橙(7)对角线段分类为 NW-SE 朝向或 NE-SW 朝向（依据其像素的 8-邻域连通方向判定）。
2. 以对称轴为界，分别在轴两侧统计每种朝向的总像素数。
3. 在每一侧，选出像素总数较少的朝向组（即该侧的少数朝向）。若两朝向像素数相等，选择线段数较少的朝向组；仍相等则选 NE-SW 朝向。
4. 将每侧少数朝向组的所有像素逐像素反射到对称轴的另一侧（坐标关于轴镜像）。
5. 镜像副本的颜色取决于其源线段的朝向：NW-SE 朝向的镜像副本涂红(2)，NE-SW 朝向的镜像副本涂青(8)。
6. 若镜像目标位置已有非背景像素，跳过该像素（原始像素优先）。
7. 原始橙(7)线段与灰(5)对称轴保持不变。

**关键洞察**：少数朝向的判定是逐侧独立的，并非全局统计。这意味着同一朝向在轴的一侧被选为少数（被镜像），在另一侧却是多数（保持不动）。求解者必须对比多个示例才能发现此不对称选择规则。

## 新题 3：柱高算术决定升降周期铺设

**组合逻辑**：[counting + height_arithmetic + color_encodes_sign](已有) → [generate_seq + rise_fall_run](创新：算术结果不再生成单条结果柱，而是作为控制值生成升降高度序列) → [periodic_extension + length_as_period](创新：升降序列本身周期性重复，周期即序列长度)

**来源原语**：counting / height_arithmetic / color_encodes_sign / vertical_bar / result_slot（37ce87bb）；generate_seq / rise_fall_run / length_rise_fall（5d588b4d）；periodic_extension / length_as_period / separator_column（1ae2feb7）

**依赖链**：正负柱高度差 → 产生单一数值 P → P 参数化生成长度为 P 的升降高度序列 → 升降序列以自身长度为周期在输出区域重复铺设。算术结果既是序列的形状参数也是周期参数——删除算术则 P 未知，删除升降生成则输出形态错误，删除周期铺设则仅出现一份副本。

将正色柱高之和减去负色柱高之和，所得值作为升降序列长度，在分隔列右侧以该长度为周期重复铺设底对齐的绿色柱列。

**输入结构**：约 10x20 网格，背景黑(0)。左半部分自左向右排列若干底对齐、单列宽的垂直柱，柱间隔一列背景。柱有两种颜色：青(8)为正操作数，红(2)为负操作数。中央有一列灰(5)像素构成分隔列（全列高）。右半部分为纯背景。生成约束：正柱高度总和严格大于负柱高度总和，且差值 P >= 3 且 P 为奇数；左侧至少有 2 根青柱和 1 根红柱。

**规则**：
1. 计算 P = (所有青(8)柱高度之和) − (所有红(2)柱高度之和)。
2. 生成升降高度序列 H = [1, 2, ..., (P+1)/2, ..., 2, 1]，序列长度恰为 P。
3. 从分隔列右侧第一列开始，连续绘制 P 列底对齐的绿(3)柱，第 i 列柱高为 H[i]（i 从 1 开始）。
4. 紧接 P 列柱之后空一列背景（分隔间隙）。
5. 重复步骤 3-4 向右铺设，直到剩余列数不足 P 时停止（不绘制不完整的升降序列）。
6. 左半部分（含所有青、红柱）与灰(5)分隔列保持不变。

**关键洞察**：柱高编码的是算术操作数，但输出不是一根结果柱——算术差值变成了一个空间序列的形状参数和重复周期。求解者需先完成减法运算，再识别升降高度模式，最后发现周期性铺设规律。三步推理缺一不可。

## 新题 4：框内折杆分区与环形换色填充

**组合逻辑**：[fold + hinge_marker + fold_toward_space](创新：折叠发生在框架内部，折后杆将内部空间一分为二) → [contour_enclosure](创新：围合边界由框壁+折后杆组成) → [ring_connection + clockwise_rotation](创新：填充色来源不是本框，而是环上下一个框的标记色)

**来源原语**：fold / straight_rod / hinge_marker / endpoint_marker / fixed_vs_free / fold_toward_space（230f2e48）；hollow_square / connector_line / ring_connection / clockwise_rotation / interior_mask / recolor（ad173014）；contour_enclosure / flood_fill（753ea09b）

**依赖链**：折杆 → 产生框内分区 → 标记像素选定目标分区 → 环形连接决定填充色来源（取顺时针下一框的标记色） → 对选定分区执行填充。折叠决定分区形状，环形顺序决定颜色分配，标记像素消歧哪个子区域被填充——三者紧耦合。

在环形连接的空心框内折叠直杆将内部分为两区，用环上顺时针下一框的标记色填充标记像素所在的子区域。

**输入结构**：约 18x18 网格，背景黑(0)。3-4 个红(2)空心正方形框（边长 5-7，壁厚 1 像素），框与框之间通过蓝(1)单像素宽直线段两两连接构成恰好一个环（每个框恰好与两段蓝线相邻）。每个框内部包含：(a) 一根绿(3)直杆（水平或垂直），一端紧贴框壁内侧（该端有一个灰(5)端点标记像素），杆沿框内部延伸到对面框壁内侧（即杆跨满框内部宽度或高度）；杆上某处有一个橙(7)铰接标记像素。(b) 恰好一个单独的前景色像素（从黄(4)、青(8)、品红(6)、栗(9)中取，每框不同），位于框内部的背景区域中。生成约束：折叠后杆不会与框内的单色标记像素重叠；每框内折叠后恰好产生两个 4-连通背景子区域；环上至少有 3 个框。

**规则**：
1. 在每个框内，以铰接标记(橙(7))为铰链折叠绿杆：保留从端点标记(灰(5))到铰接标记的一段不变；将铰接标记另一侧的杆尾以铰接点为原点旋转 90°，方向选择框内可用空间较大的一侧（即折入后离对面框壁更远的方向）。折叠后的杆呈 L 形，仍为绿(3)。
2. 折后杆（L 形）加上框壁将框内部分割为两个 4-连通背景区域（"子区域"）。
3. 确定每框内单色标记像素所在的子区域——称为"选中子区域"。
4. 以所有框中心的质心为原点，按各框中心的极角将框排成顺时针序列。
5. 每个框的选中子区域被填充为**顺时针下一个框**内单色标记像素的颜色。（环的最后一个框取环第一个框的标记色。）
6. 未选中的子区域保持背景色。红框壁、蓝连接线、绿杆（含灰端点与橙铰接标记）、各框内的单色标记像素均保持不变。

**关键洞察**：折叠方向取决于框内空间几何，它决定了 L 形杆的具体形态从而决定分区拓扑。但填充色不来自本框——它由环上顺时针邻居的标记色决定。求解者需同时理解折叠力学和环形旋转赋色，二者独立但共同决定输出。

## 新题 5：方块计数参数化升降序列行绕排

**组合逻辑**：[counting + ignore_non_square](已有) → [count_ordering 排序](已有) → [generate_seq + rise_fall_run](创新：每个颜色的计数值独立生成一条升降游程) → [wrap_tile](已有，但输入是多色拼接序列)

**来源原语**：counting / solid_square / ignore_non_square / count_ordering（b1986d4b）；generate_seq / wrap_tile / rise_fall_run / bar_length_seq（5d588b4d）

**依赖链**：识别方块并过滤噪声 → 按颜色计数 → 计数排序决定拼接顺序 → 每个计数值生成一条该色升降游程 → 多色游程拼接 → 按输入宽度绕排成二维输出。计数结果既决定游程长度也决定拼接顺序——删除计数则序列形状未知，删除排序则输出顺序不确定，删除绕排则无法得到二维输出。

统计各色实心正方形的数量（忽略非方块），以计数为控制值为每色生成升降像素游程，按计数降序拼接后行绕排到与输入等宽的网格中。

**输入结构**：约 15x15 网格，背景黑(0)。散布若干实心单色正方形（边长 2-4，颜色从红(2)、蓝(1)、绿(3)、黄(4)中取，同色方块可有多个但大小可不同）。另有若干非方形噪声分量（单像素、L 形、线段等，颜色可与方块重叠）。生成约束：至少 3 种颜色各有至少 1 个方块；每种颜色的方块计数在 1-4 之间；无两种颜色的方块计数相同（保证排序无歧义）。

**规则**：
1. 识别所有 4-连通单色分量。仅保留外形为实心正方形的分量（即边界框为 k×k 且所有 k² 像素均为同色），丢弃所有非方形分量。
2. 统计每种颜色的方块个数，记为 n_c。
3. 将颜色按 n_c 从大到小排序。
4. 对排序后的每种颜色 c（计数为 n_c），生成一条升降像素游程：依次生成长度 1, 2, ..., n_c, ..., 2, 1 的连续 c 色像素段，相邻段之间插入 1 个背景像素。
5. 将所有颜色的游程首尾拼接，颜色之间插入 2 个背景像素。
6. 将拼接后的一维序列按输入网格宽度行绕排（每行宽度 = 输入列数）。最后一行不足部分以背景像素填充。
7. 输出网格宽度等于输入宽度，行数为容纳完整序列所需的最小行数。

**关键洞察**：输入中的方块大小不影响输出——只有每色方块的**数量**才是有效信息。非方形分量是干扰项，必须被过滤。输出的二维图案看似复杂，实际上是由计数值参数化的一维升降序列行绕排的结果。

## 新题 6：安全路径镜像重叠检测

**组合逻辑**：[pathfinding + neighbor_exclusion + unique_safe_path](已有) → [mirror + reflect_along_axis](创新：镜像对象不是已有前景集合，而是动态求出的路径) → [recolor 按重叠分类](创新：原始路径与镜像副本的重叠位置涂第三色，揭示路径的轴对称子集)

**来源原语**：pathfinding / track_path / endpoint / obstacle / neighbor_exclusion / unique_safe_path / recolor（cc9053aa）；mirror / symmetry_axis / reflect_along_axis（ad3b40cf）

**依赖链**：障碍排除 → 寻路确定唯一安全路径 → 路径像素跨轴镜像 → 镜像位置与原路径比较 → 重叠处涂黄、非重叠镜像处涂蓝。寻路结果决定镜像输入，镜像输出与原路径的比较产生新的分类。删除寻路则镜像对象不确定，删除镜像则无法发现对称结构。

找到避开障碍的唯一安全路径，将路径跨对称轴镜像，重叠处涂黄揭示路径的轴对称部分，非重叠镜像处涂蓝。

**输入结构**：约 15x15 网格，背景黑(0)。青(8)像素构成一个 4-连通轨道网络（含分支和死胡同）。恰好两个栗(9)端点像素嵌在轨道上。1-3 个橙(7)障碍像素嵌在轨道附近。一条完整行或完整列的灰(5)像素构成对称轴，不与轨道相交。生成约束：排除障碍及其 8-邻域后，两端点之间恰好存在一条 4-连通简单路径；对称轴将网格分为两半，两个端点在同一半；路径镜像后至少有一个位置落在原路径上（存在重叠），至少有一个位置落在背景上（存在非重叠）。

**规则**：
1. 将每个橙(7)障碍像素及其 8-邻域内的所有像素标记为禁区。
2. 在剩余的青(8)与栗(9)像素构成的 4-连通图中，找到两个栗(9)端点之间的唯一简单路径。
3. 将路径上的青(8)像素（不含端点）重涂为栗(9)。
4. 将整条路径（含端点）的每个像素坐标关于灰(5)对称轴做镜像反射，得到镜像坐标集。
5. 对每个镜像坐标：
   - 若该位置已有栗(9)像素（即属于原路径或端点）：将该位置重涂为黄(4)——标记为"对称重叠"。
   - 若该位置为背景(0)：涂蓝(1)——标记为"镜像延伸"。
   - 若该位置为青(8)（非路径的轨道部分）或橙(7)障碍或灰(5)轴：不改变。
6. 其余所有像素（未用到的轨道、障碍、轴、背景）保持不变。

**关键洞察**：输出中的黄(4)像素标出了安全路径上关于对称轴自映射的部分——即路径的"对称骨架"。这一结构性质仅在同时完成寻路和镜像后才可见。求解者需先排除障碍找到路径，再将路径投射到轴的另一侧，最后通过颜色分类理解重叠的含义。

## 新题 7：门结构定向标记投影

**组合逻辑**：[slide + path + stop_at_gate + erase](已有) → [gate_motif 几何解读](创新：门不仅是停止信号，其三像素排列方向还编码投影轴) → [project + contact_det_project](创新：投影方向由门朝向而非接触边决定)

**来源原语**：slide / marker_pixel / path / gate_motif / stop_at_gate / erase（182e5d0f）；project / small_square / contact_det_project / color_det_depth（e39e9282）

**依赖链**：标记沿路径滑动 → 到达门前停止 → 门的三像素几何方向决定投影轴 → 标记色沿投影轴投射到邻接方块内部。门结构同时充当"何处停"和"往哪投"的双重信号——这种双重角色在两道源题中均不存在。

标记像素沿路径滑到门前停止，门的排列方向决定向邻接方块的投影方向，在方块中心线上印下标记色。

**输入结构**：约 15x18 网格，背景黑(0)。3-4 条独立的绿(3) 4-连通路径，每条一端连着一个灰(5)标记像素，另一端连着一个门结构。门结构由三个像素组成：中心像素为绿(3)（属于路径末端），两侧各一个栗(9)像素，三者共线且垂直于路径的末段方向。每个门的中心像素紧邻一个 3x3 实心品红(6)方块（方块位于门的背面——即路径来向的反侧）。生成约束：每条路径无分支、不与其他路径相连；门的两个栗(9)像素不与方块接触；方块不紧贴网格边缘。

**规则**：
1. 对每条路径上的灰(5)标记像素，沿路径向门方向逐步滑动。滑过的路径像素（含标记原始位置）全部擦除为背景(0)。
2. 标记停在门中心像素的路径侧邻居位置（即紧挨门中心、处于路径一侧的那个像素），涂为灰(5)。
3. 确定门的朝向：门的两个栗(9)像素的排列方向即为门轴方向。投影方向为垂直于门轴、从门中心指向品红(6)方块的那个正方向。
4. 沿投影方向，在品红方块内部找到中心线（与投影方向垂直的中间一行或一列），在中心线上距门最近的那个像素位置印下灰(5)色（覆盖原品红色）。
5. 品红方块除被印记的像素外保持品红。门的栗(9)像素和绿(3)中心像素保持不变。

**关键洞察**：三像素门结构（栗-绿-栗）编码了两重信息：它是标记的终点也是投影的方向指示器。栗色像素的排列揭示门轴方向，其垂直方向就是投影轴。仅识别"停在门前"的规则不够，还需推断门的几何含义才能完成投影。

## 新题 8：旋转条交叉计数重涂色

**组合逻辑**：[rotate + center_fixed + orient_swap_keep](已有) → [counting](创新：不是统计已有对象数量，而是统计旋转后新产生的交叉重叠数) → [recolor + classify](创新：按交叉层数分类重涂色，交叉点涂不同于非交叉段的颜色)

**来源原语**：rotate / thin_bar / center_fixed / orient_swap_keep（f0f8a26d）；counting（37ce87bb）；recolor / classify（1d61978c）

**依赖链**：所有条同时旋转 90° → 旋转后的空间占位与其他旋转后条产生交叉 → 统计每个像素上重叠的条数 → 按重叠数分类重涂色。关键在于交叉点仅存在于旋转后的布局中（原始条互不接触），因此重涂色完全依赖旋转结果。

将每条前景条绕中心旋转 90°，在新位置按重叠条数重涂色：单条段涂绿、双条交叉处涂红。

**输入结构**：约 12x12 网格，背景黑(0)，所有前景像素为青(8)。前景由若干单像素宽直条组成（水平或垂直，长度为奇数，范围 3-7），每条沿水平或垂直方向延伸。生成约束：原始条互不接触且不共享像素（任意两条之间最短距离 >= 1）；将所有条绕各自中心旋转 90° 后，至少存在两个像素位置恰好被两条旋转后条共同覆盖（交叉点），且无位置被三条或更多条覆盖；输入至少包含 2 条水平条和 2 条垂直条。

**规则**：
1. 清空画布为背景(0)。
2. 将每条前景条绕其中心像素旋转 90°：水平变垂直、垂直变水平，保持中心位置和长度不变。单像素条（1x1）视为无方向，旋转后保持不变。
3. 将所有旋转后条的像素绘制到画布上，统计每个像素被多少条旋转后条覆盖。
4. 重涂色：被恰好 1 条覆盖的像素涂绿(3)；被恰好 2 条覆盖的像素涂红(2)。
5. 未被任何旋转后条覆盖的位置保持背景(0)。

**关键洞察**：红(2)像素标记的交叉点在输入中不存在——它们是旋转这一全局操作的涌现结果。求解者必须在脑中同时旋转所有条，找出新位置的重叠，才能确定哪些像素应涂红。仅对单条旋转无法发现交叉规律。
