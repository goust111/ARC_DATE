## 新题 1：遮挡序反转同心环

**组合逻辑**：[补全/reconstruct](已有) → [遮挡层序/occlusion_order](已有，作用从"输出排列"变为"驱动嵌套序") → [同心环绘制/concentric_draw](已有，排序依据从面积改为遮挡深度的逆序)

**来源原语**：补全/reconstruct, 空心矩形/hollow_rectangle, 遮挡层序/occlusion_order, 重叠定先后/overlap_determines — 来自参考题 68bc2e87；排序/sort, 同心环绘制/concentric_draw, 嵌套方环/nested_square_ring — 来自参考题 5587a8d0

**依赖链**：补全每个矩形框的完整边界框 → 在重叠像素处判定遮挡先后 → 将遮挡顺序反转后驱动同心环绘制（最被遮挡的颜色画为最外环）

将多个互相遮挡的矩形框按遮挡深度的逆序重绘为同心方环。

**输入结构**：黑(0)背景，约 15×20 的网格。4~6 个不同颜色的一像素宽空心矩形框（颜色取自蓝(1)、红(2)、绿(3)、黄(4)、橙(7)、栗(9)等，边界框尺寸各不相同，约 4×4 到 8×8），部分框之间存在空间重叠。重叠处仅显示最上层框的颜色，被遮挡框的像素不可见。每个框的可见像素至少暴露完整的两条边（相邻两边），使其完整边界框可被唯一重建。生成时保证：任意两个框至少与一个其他框存在重叠像素；所有框的遮挡关系可推出唯一的从底到顶的全序（不存在循环遮挡，即不会出现 A 遮 B、B 遮 C、C 遮 A 的情况）。

**规则**：
1. 对每个前景颜色，收集其所有可见像素，将这些像素的外接矩形扩展为完整的一像素宽空心矩形（即补全被遮挡而不可见的部分）。
2. 对每个被两个或以上重建矩形覆盖的像素位置：该位置显示的颜色为上层框，不显示的颜色为下层框。汇总所有这类约束，推导出唯一的从底（被遮挡最多）到顶（遮挡所有其他框）的全序。
3. 创建边长为 2N-1 的正方形输出网格（N 为矩形框数量）。按遮挡顺序的逆序绘制同心方环：全序中最底层（被遮挡最多）的框的颜色画在最外环（输出边界），依次向内；全序中最顶层（遮挡一切）的框的颜色画在中心像素。

**关键洞察**：遮挡顺序与环的嵌套顺序是反转的——最"不可见"的底层框反而占据输出中面积最大的外环，需要先从部分可见像素重建完整边界框，再从重叠位置推断全局遮挡全序，最后将该全序反转用于同心环绘制。

## 新题 2：枢轴牵引滑动

**组合逻辑**：[同行或同列/same_row_or_col](已有) → [滑动/slide](创新：滑向配对枢轴而非边界色条) + [冲突优先级/conflict_priority](创新：距离近者先到位并阻挡远者) → [重涂色/recolor](已有)

**来源原语**：枢轴像素/pivot_pixel, 源像素/source_pixel, 同行或同列/same_row_or_col, 距离保持不变/distance_preserved — 来自参考题 1a244afd；滑动/slide, 碰撞停止/collision_stop — 来自参考题 17829a00；冲突优先级/conflict_priority — 来自参考题 9344f635

**依赖链**：通过行列对齐将每个精灵体与唯一蓝(1)枢轴配对 → 配对关系确定滑动方向（朝枢轴）→ 配对距离从小到大排序确定滑动执行顺序 → 先到位的精灵体成为障碍物阻挡后续滑动 → 所有滑动完成后枢轴重涂为配对精灵体颜色

将同行或同列配对的精灵体沿轴向滑向其枢轴，距离近者优先到位成为障碍，远者被阻挡，到达后枢轴变色。

**输入结构**：黑(0)背景，约 14×14 的网格。3~5 个蓝(1)枢轴像素（单像素，各自独立不相邻）。同等数量的单色 4-连通小精灵体（每个 3~6 像素，颜色各不相同且均非蓝(1)和黑(0)，可使用红(2)、绿(3)、黄(4)、品红(6)、橙(7)等）。每个精灵体恰好与一个蓝(1)枢轴位于同一行或同一列（不会同时在同行又同列），且每个枢轴恰好配对一个精灵体，配对关系无歧义。生成时保证：所有精灵体的初始位置互不接触；至少存在一对精灵体，其滑动路径经过另一个精灵体的最终停靠位置或路径上的区域，从而产生碰撞阻挡效果。

**规则**：
1. 对每个精灵体，找到与其同行或同列的唯一蓝(1)枢轴像素，建立配对。
2. 计算每个精灵体中心到其配对枢轴的曼哈顿距离。按此距离从小到大排序所有精灵体。距离相同时，行号小的优先；行号也相同时，列号小的优先。
3. 按排序顺序依次执行滑动：每个精灵体沿行或列方向整体平移，目标是精灵体的边界框最近边紧邻枢轴像素（与枢轴相距恰好 1 像素）。若平移路径上遇到已到位的精灵体（路径上有非背景像素），则在接触前一像素处停止。
4. 所有滑动完成后，每个蓝(1)枢轴像素重涂为与其配对的精灵体的颜色。

**关键洞察**：滑动执行顺序由初始配对距离隐式决定——距枢轴近的精灵体先到位并成为不可穿越的障碍，可能阻挡距枢轴远的精灵体到达其目标位置；必须先算出所有距离确定全局执行顺序，才能正确模拟碰撞链。

## 新题 3：形状配对驱动的母题缩放填充

**组合逻辑**：[形状匹配孔洞/shape_matches_hole](已有) → [尺寸比编码缩放/size_ratio_encodes_scale](创新：配对双方的边界框边长比产生缩放因子) → [缩放/scale + 印章放置/stamp](已有，但缩放对象从锚点方块改为共享母题)

**来源原语**：模板框架/template_frame, 精灵体/sprite, 孔洞/hole, 形状匹配孔洞/shape_matches_hole, 旋转翻转不变/rotation_flip_invariant, 嵌入填充/inlay_fill — 来自参考题 67e490f4；缩放/scale, 尺寸比编码缩放/size_ratio_encodes_scale, 印章放置/stamp, 图案母题/motif — 来自参考题 b10624e5

**依赖链**：精灵体与孔洞按形状配对（旋转/翻转不变）→ 配对中孔洞边界框边长与精灵体边界框边长的比值给出缩放因子 → 共享红(2)母题按该因子做最近邻缩放 → 缩放后的母题印入对应孔洞并着色为配对精灵体的颜色

将形状配对产生的尺寸比作为缩放因子，把一个共享母题按不同倍率填入模板框架的各个孔洞，颜色由配对精灵体决定。

**输入结构**：黑(0)背景，约 22×22 的网格。一个灰(5)大型单色模板框架（约 16×16，由一像素宽边界加内部横竖灰(5)隔断组成），框架内部被隔断分割形成 3~4 个孔洞（孔洞为黑(0)区域，形状各异但每个孔洞的边界框均为正方形，边长分别为 2、4、6 等不同偶数）。框架外部散布 3~4 个小型单色精灵体（颜色各不相同，如蓝(1)、绿(3)、橙(7)，均非灰(5)、红(2)和黑(0)），每个精灵体的边界框统一为 2×2（占 2~4 像素，形状为非对称 4-连通图形）。每个精灵体的形状经旋转或翻转后与恰好一个孔洞的形状匹配（匹配指像素的连通结构一致，仅尺寸不同）。框架外还有一个红(2)小型非对称图案母题（占据 2×2 区域内的 3 个像素，形成明显不对称的图案）。生成时保证：精灵体与孔洞一一配对无歧义；各孔洞边界框边长均为精灵体边界框边长（2）的整数倍。

**规则**：
1. 对每个孔洞，在框架外的精灵体中寻找形状匹配者（允许 0°/90°/180°/270° 旋转和水平/垂直翻转后比较形状的连通结构）。
2. 计算该孔洞的边界框边长 L 与其匹配精灵体边界框边长 2 的比值 k = L / 2（例如孔洞 6×6 → k=3）。
3. 将红(2)母题进行 k 倍最近邻缩放（母题中每个像素扩展为 k×k 的方块）。
4. 将缩放后的母题左上角对齐孔洞区域的左上角进行印章放置：母题中红(2)像素位置替换为配对精灵体的颜色，母题中黑(0)像素位置保持黑(0)。若缩放后的母题大于孔洞区域，超出部分裁剪不绘制。
5. 灰(5)框架本身及框架外所有元素（精灵体和母题）保持不变。

**关键洞察**：精灵体的形状和颜色承担完全不同的角色——形状用于与孔洞配对以确定"谁填谁"，配对产生的尺寸比决定共享母题的缩放倍率；同一个红(2)母题在不同孔洞中以不同大小出现，但着色各异，三者（形状配对、尺寸比、母题）缺一不可。

## 新题 4：标记筛选后的周期遮罩射线

**组合逻辑**：[标记色筛选物体/marker_filters + 擦除/erase](已有) → [朝向编码方向/orientation_encodes_direction](创新：物体边界框长宽比编码射线方向而非 domino 朝向) → [射线延伸/ray_extend](已有) + [周期掩码/periodic_mask](创新：射线仅在周期激活的行/列上可见)

**来源原语**：指示条/indicator_bar, 标记像素/marker_pixel, 标记色筛选物体/marker_filters, 计数/counting, 擦除/erase — 来自参考题 edcc2ff0；矩形边框/rectangular_frame, 周期条纹/periodic_stripe, 周期掩码/periodic_mask, 射线延伸/ray_extend — 来自参考题 6a980be1；朝向决定方向/orientation_determines_direction, 微型标记/micro_marker — 来自参考题 9344f635

**依赖链**：顶行标记像素定义合法颜色集合 → 擦除不合法颜色的前景物体 → 幸存物体的边界框长宽比决定射线方向（宽>高→水平，高>宽→垂直）→ 从灰(5)边框内的橙(7)条纹推断周期掩码 → 射线仅在掩码激活的行或列上可见，形成间断虚线

标记筛选确定哪些物体可发射射线，物体朝向确定射线方向，边框内周期条纹定义射线的可见行列。

**输入结构**：黑(0)背景，约 18×18 的网格。第 0 行为黑(0)指示条，其中从第 0 列起有 2~3 个不同颜色的单像素标记（如红(2)、绿(3)），相邻标记之间间隔至少 1 个黑(0)像素。网格中央偏下有一个灰(5)一像素宽矩形边框（约 8×8 外尺寸），边框内部在等间距的行上有橙(7)水平条纹（如每隔 2 行一条，宽度 1 像素），形成周期行掩码。边框外散布 4~6 个单色 4-连通小物体（每个 3~8 像素），颜色包含标记中出现的颜色和未出现的颜色（如蓝(1)、黄(4)为非标记色）。每个物体的边界框为非正方形矩形（宽严格大于高或高严格大于宽）。生成时保证：至少有一个标记颜色对应 2 个以上物体；至少有一个非标记颜色的物体存在用于被擦除；各物体之间不接触。

**规则**：
1. 读取第 0 行指示条中所有非黑(0)像素的颜色，构成合法颜色集合 S。
2. 将网格中颜色不属于 S 的所有前景物体的像素重涂为黑(0)（擦除）。灰(5)边框和橙(7)条纹不受影响。
3. 对每个幸存物体，计算其边界框的宽 W 和高 H：W > H → 水平朝向，发射水平射线；H > W → 垂直朝向，发射垂直射线。
4. 射线从物体边界框的中心行（水平射线时取中心行，若像素数为偶则取偏上的行）或中心列（垂直射线时取中心列，若像素数为偶则取偏左的列）出发，向两端延伸至网格边界。
5. 从灰(5)边框内的橙(7)条纹推断周期行掩码：记录所有含橙(7)条纹的行号，计算行间距 p，将该周期延伸至整个网格高度，得到激活行集合。射线像素仅在激活行（对于水平射线）或激活列（对于垂直射线，需从边框内垂直条纹推断列周期；若边框内无垂直条纹则垂直射线全部可见）上绘制；非激活位置的射线像素不显示。
6. 射线颜色与发射物体颜色相同。射线不覆盖已有的非背景像素（包括幸存物体、灰(5)边框、橙(7)条纹）。

**关键洞察**：周期掩码像栅栏一样过滤射线——同一条连续射线在空间上变成间断的虚线段，虚线的间距由边框内条纹的周期决定，而非射线本身的任何属性；三个独立机制（标记筛选、朝向编码、周期掩码）会聚在最终输出上，缺少任何一个都无法正确绘制。

## 新题 5：锚点方块参数化的母题缩放镜像

**组合逻辑**：[相对方位/relative_position](创新：方位同时编码反射轴类型) + [尺寸比编码缩放/size_ratio_encodes_scale](创新：锚点方块边长直接作为缩放因子) → [缩放/scale + 镜像/mirror + 印章放置/stamp](已有) + [重涂色/recolor](已有)

**来源原语**：控制像素/control_pixel → 创新为锚点方块, 相对方位/relative_position, 方位决定槽位/position_selects_slot — 来自参考题 18286ef8；缩放/scale, 锚点方块/anchor_block, 尺寸比编码缩放/size_ratio_encodes_scale, 镜像/mirror, 印章放置/stamp, 图案母题/motif — 来自参考题 b10624e5；重涂色/recolor — 来自参考题 1a244afd

**依赖链**：锚点方块相对于母题中心的方位（上/下/左/右）→ 决定变换后母题的反射轴 → 锚点方块的边长 k → 决定母题的缩放因子 → 缩放并反射后的母题印在锚点方块的外侧 → 印章颜色取自锚点方块颜色

每个锚点方块的方位编码反射类型、边长编码缩放倍率，在方块外侧生成母题的变换副本。

**输入结构**：黑(0)背景，约 25×25 的网格。网格中央区域有一个蓝(1)非对称小母题，占据约 3×3 区域内的 5~6 个像素（形状非对称，确保水平翻转和垂直翻转后的图案与原始图案均可区分）。网格中另有 3~4 个不同颜色的正方形实心方块（锚点方块），颜色各不相同（如红(2)、绿(3)、黄(4)、橙(7)），边长分别为 1、2 或 3 像素。每个锚点方块位于母题的严格正上方、正下方、正左方或正右方（即方块中心与母题中心共享同一行或同一列），四个方向最多各有一个方块。锚点方块与母题之间保持足够间距（至少 3×方块边长 个像素），确保缩放后的副本不与母题、方块或其他副本重叠。

**规则**：
1. 识别蓝(1)母题及其边界框中心位置 C。
2. 对每个锚点方块，执行以下步骤：
   a. 确定方块中心相对于 C 的方向 D（正上/正下/正左/正右）。
   b. 读取方块边长 k（1、2 或 3）。
   c. 将母题进行 k 倍最近邻缩放（每个像素变为 k×k 的方块）。
   d. 根据方向 D 确定反射：D 为左或右 → 对缩放后的母题做水平翻转（左右镜像）；D 为上或下 → 对缩放后的母题做垂直翻转（上下镜像）。
   e. 确定副本放置位置：副本印在方块的外侧，紧邻方块（D 为右 → 副本左边缘紧贴方块右边缘的右侧一列；D 为左 → 副本右边缘紧贴方块左边缘的左侧一列；D 为下 → 副本上边缘紧贴方块下边缘的下侧一行；D 为上 → 副本下边缘紧贴方块上边缘的上侧一行）。
   f. 副本中蓝(1)像素全部替换为该锚点方块的颜色，黑(0)像素保持黑(0)。
3. 原始蓝(1)母题和所有锚点方块保持不变。副本超出网格边界的部分不绘制。

**关键洞察**：锚点方块同时携带两个独立参数——边长编码缩放因子、方位编码反射轴——必须对两者同时正确解码才能生成正确的副本形态和位置；仅靠观察一个示例中某一个方块可以猜到缩放或反射，但需要对比多个不同方块的输出才能归纳出方位-反射的完整映射规则。

**依赖链**：识别红(2)标记的几何形态（水平线段/垂直线段/单像素）→ 形态决定反射类型 → 多条对角射线各自沿 45° 传播并在遇到红标记时按类型反射 → 所有射线路径叠加 → 交叉像素变蓝(1)，独占像素保持射线色

红标记的形状决定射线如何反弹，多条射线的路径交汇点变为蓝色。

**输入结构**：黑(0)背景，约 18×18 的网格。2~3 个对角射线种子，每个由 2~3 个同色 8-连通像素组成的 45° 对角短线段（颜色各不相同，如绿(3)、黄(4)、橙(7)）。网格中散布 3~5 个红(2)标记，形态分三种：水平线段（3~4 像素宽、1 像素高）、垂直线段（1 像素宽、3~4 像素高）、单像素（1×1）。网格中不存在其他前景元素。生成时保证：每条射线在传播过程中至少遇到一个红(2)标记并发生反射；至少存在两条射线的反射后路径在某些像素上重合；所有射线种子的颜色互不相同且不为红(2)或蓝(1)。

**规则**：
1. 对每个射线种子，确定其两个端点。选择使射线沿 45° 对角延伸后仍留在网格内（至少可前进 1 步）的那个端点作为发射起点，延伸方向为从另一端点指向该端点的对角方向。
2. 射线逐像素沿对角方向传播（每步行号 ±1、列号 ±1）。记录射线经过的所有像素位置及其颜色。
3. 当射线的下一个目标像素为红(2)标记时，射线不进入该像素。根据该红(2)标记的几何形态执行反射：
   - 水平线段（宽 > 高）：翻转射线的行移动方向（上变下或下变上），列移动方向不变。
   - 垂直线段（高 > 宽）：翻转射线的列移动方向（左变右或右变左），行移动方向不变。
   - 单像素（1×1）：同时翻转行和列移动方向（等效 180° 掉头）。
4. 反射后射线从当前位置继续沿新方向传播，直到下一步将离开网格边界时停止。射线途中可遇到多个红标记并多次反射。
5. 所有射线独立传播完毕后，检查每个被射线覆盖的非种子、非红标记像素：若仅一条射线经过，涂为该射线种子的颜色；若两条或以上射线经过，涂为蓝(1)。
6. 红(2)标记像素和射线种子像素保持原状不变。

**关键洞察**：红标记的几何形状（线段朝向 vs 单点）不是装饰差异而是功能差异——它决定了射线反射时翻转哪个运动分量，从而产生截然不同的反射路径；多条射线的路径交叉模式是反射规则的涌现效果，无法通过分析单条射线预测。

**依赖链**：计算每个空心框架内部连通黑(0)孔洞区域的数量 h → h 同时决定两件事：(1) 该框架的最大滑动距离，(2) 滑动执行优先级（h 小的先动）→ 颜色匹配确定滑动方向（朝同色边界条）→ 先动的框架到位后成为障碍阻挡后动者

**输入结构**：黑(0)背景，约 16×16 的网格。第 0 行（顶行）为红(2)全宽色条（整行全部为红(2)），最后一行（底行）为绿(3)全宽色条（整行全部为绿(3)）。网格内部（第 1 行到倒数第 2 行）散布 4~5 个空心框架，每个框架为一像素宽的矩形边框（外尺寸约 3×3 到 5×5），颜色为红(2)或绿(3)。每个框架内部有 0~3 个灰(5)单像素或双像素障碍物，将框架内部的黑(0)空间分割为若干连通区域（即孔洞）。无内部障碍物的框架孔洞数 h=1（整个内部为一个连通黑(0)区域）；有 1 个障碍物可能 h=1 或 h=2，取决于障碍物是否接触框架边界等。各框架的 h 值互不相同。生成时保证：所有框架初始位置互不接触且不与边界色条接触；各框架与其同色边界条之间的距离均大于等于该框架的 h 值（确保有足够空间滑动）；至少有两个同色框架的滑动路径在同一列上存在交叉可能。

**规则**：
1. 对每个空心框架，计算其内部连通黑(0)区域的数量 h（灰(5)障碍物不计为孔洞的一部分；若框架内部完全为黑(0)则 h=1）。
2. 确定滑动方向：红(2)框架向上滑动（朝顶行红(2)色条），绿(3)框架向下滑动（朝底行绿(3)色条）。
3. 按 h 值从小到大排序所有框架。h 值相同时，距离目标边界色条更近的框架优先。仍然相同时，列号小的优先。
4. 按排序顺序依次执行每个框架的滑动：框架整体（含其内部灰(5)障碍物）沿上或下方向移动，最多移动 h 格。移动过程中，若框架的前进方向边界的下一行（或上一行）存在非黑(0)像素（包括已到位的其他框架、边界色条），则框架在该位置前一格停止（框架边界与障碍物相距 0 格，即紧贴但不重叠）。
5. 所有滑动完成后，框架及其内部在新位置绘制，原位置恢复为黑(0)。

**关键洞察**：框架的内部结构（孔洞数）同时控制两个关键参数——最大移动距离和移动优先级；孔洞少的框架"能力弱"（走得少）但"行动快"（先滑动），可能堵住孔洞多的框架的去路，产生"早到者设障"的涌现效应；必须先正确计算所有框架的孔洞数才能确定全局执行顺序和最终布局。

分隔线网格把补线操作限制在纯色格内，花纹格内的线段被擦除，补全后的线段还会被所在纯色格的颜色染色。

**输入结构**：黑(0)背景，约 17×17 的网格。灰(5)分隔线（完整横跨或纵跨网格的整行/整列，1 像素宽）将网格分为 3×3 共 9 个矩形格子（每格内部空间约 4×4 到 5×5）。其中 4~6 个格子是纯色格（格内所有非分隔线像素完全填充一种颜色，如红(2)、绿(3)、蓝(1)等，不同纯色格颜色可相同或不同，但均非黑(0)、灰(5)、黄(4)、橙(7)）。其余格子是花纹格（格内包含两种以上颜色的非规则图案）。网格中有 2~3 条贯穿多个格子的水平或垂直黄(4)直线段（1 像素宽），线段穿越分隔线时在分隔线上也有黄(4)像素。在某些纯色格内部，黄(4)线段被打断形成间隙，断口旁有橙(7) 45° 对角阶梯噪声（2~4 个 8-连通对角链像素）标记断口的位置和跨度。对角噪声的像素跨度（沿行或列方向的投影长度）等于间隙长度。生成时保证：每条线段至少经过一个纯色格和一个花纹格；所有间隙和对角噪声仅出现在纯色格内部；黄(4)和橙(7)不被用作任何纯色格或花纹格的组成颜色。

**规则**：
1. 用灰(5)整行和整列将网格分为矩形格子。
2. 对每个格子进行分类：格内所有非灰(5)像素（排除黄(4)线段像素和橙(7)噪声像素后）为同一颜色 → 纯色格；否则 → 花纹格。
3. 擦除所有橙(7)对角噪声像素，恢复为所在纯色格的底色。
4. 在纯色格内，补全黄(4)直线段的间隙：对于同一条直线上位于该纯色格内的两个断头（同行或同列的最近两个黄(4)像素），若它们之间的距离不超过已擦除的对角噪声在该方向上的跨度，则在两个断头之间填充黄(4)像素使线段连续。
5. 在花纹格内，擦除该格中所有黄(4)像素，恢复为该位置在花纹格原有图案中的颜色（即花纹格的图案在黄(4)线段位置下方有被遮盖的原始像素，还原该像素颜色；若无法确定原始颜色则恢复为黑(0)）。
6. 在纯色格内，将补全后的所有黄(4)线段像素重涂为该纯色格的颜色。
7. 分隔线上的黄(4)像素保持黄(4)不变。

**关键洞察**：分隔线网格不仅是视觉分区，更是逻辑门控——同一条直线的不同段在纯色格内被修复并染上该格颜色，在花纹格内被彻底擦除，使一条原本贯穿的直线变成仅存在于纯色格内的断续彩色片段，仅由分隔线上残留的黄(4)像素暗示原始的连通性。
