## 新题 1：交叉遮挡链驱动柱高循环置换

**组合逻辑**：[层序推断](创新：遮挡链不作为最终输出，而是用作置换密钥) + [循环移位](创新：移位量和移位映射由遮挡链拓扑决定，而非固定的 +1/-1) + [重分配](提供置换后的重新安放)

**来源原语**：层序推断/遮挡层次/唯一序链/直线/交叉点(22425bda)，循环移位/有序槽位/条高度/条颜色/柱状条(2601afb7)，重分配/高度排序(31f7f899)

**依赖链**：线交叉的可见颜色 → 推断唯一遮挡深度链 → 深度链定义颜色的循环置换 → 置换决定每个柱槽获得哪个柱的高度 → 输出柱高重新分配后的柱状图。删除遮挡推断则无法确定置换；删除循环移位则遮挡链无作用目标。两者在"置换密钥"这一结构关系上紧耦合——源题中遮挡链是终态输出，源题中循环移位是固定规则，此处遮挡链成为循环移位的参数化输入。

从交叉线的遮挡深度链中读出颜色循环置换，将对应柱状条的高度按此置换在槽位间重新分配。

**输入结构**：

- 约 18x20 网格，背景黑(0)。
- 上半区：4 条 1 像素宽的直线（水平线、垂直线或 45 度对角线均可），每条颜色不同（例如红(2)、蓝(1)、绿(3)、黄(4)），彼此交叉。高层线在交叉处遮挡低层线。每条线跨越上半区的完整宽度或高度。
- 一行黑(0)分隔行将上半区与下半区隔开。
- 下半区：4 根单色柱状条，颜色分别与 4 条线一一对应，各占一列，底端对齐网格底边，高度各不相同（2~5 像素不等）。柱列等间距排列。
- 生成约束：交叉遮挡关系恰好产生唯一的一条哈密顿链（底→顶），链中相邻颜色对应的线必须在几何上有交叉点；不存在两条线完全不交叉的情况。

**规则**：

1. 从可见的共线像素恢复每条线的完整走向（被遮挡的像素不可见但可从共线性推断）。
2. 在每个交叉点处，可见颜色在被遮挡颜色之上。收集所有两两"在上/在下"约束。
3. 找到唯一的哈密顿链 c0（最底层）→ c1 → c2 → c3（最顶层），使得链中相邻颜色对应的线在几何上交叉。
4. 将深度链读为颜色的循环置换：c0→c1→c2→c3→c0。
5. 对每根柱状条：将其高度替换为"深度链中下一个颜色"对应柱的高度。形式化：颜色为 ci 的柱获得颜色为 c((i+1) mod 4) 的柱的原始高度。
6. 柱的 x 坐标和颜色保持不变。分隔行和上半区线条不变。

**关键洞察**：交叉遮挡模式编码了一个特定的颜色循环置换。相同四根柱在不同遮挡排列下会产生完全不同的高度重分配。必须推断完整深度链（非仅两两比较）才能得到正确的循环映射。仅凭一个示例无法区分"循环置换"与"反序排列""两两互换"等其他可能映射。

## 新题 2：像素编码禁区中的印章跳步重复

**组合逻辑**：[印章重复](保留核心的 3 格步进周期复制) + [避障](创新：不是路由路径的转向，而是在周期复制序列中跳过被禁止的落点位置) + [像素计数编码半径](从障碍条上的蓝色像素数读取禁区半径)

**来源原语**：印章重复/精灵体/实心矩形/中心像素/颜色匹配/重叠停止(985ae207)，避障/障碍条/禁区/像素计数编码半径/编码映射(cb2d8a2c)，重涂色(cb2d8a2c - 蓝变红)

**依赖链**：蓝色像素计数 → 编码每个障碍的禁区半径 → 禁区空间范围过滤印章落点 → 被禁止的落点产生跳空 → 最终重复图案出现不规则间隔。删除印章重复则禁区无过滤对象；删除避障则所有落点都放置、无跳空效果。源题中避障是路径转向机制，源题中印章重复是无阻碍的周期复制——此处避障成为周期复制的空间过滤器，产生"跳步印章"这一源题不存在的效果。

将 3x3 精灵体沿目标方向周期复制，但落点在障碍禁区内的副本被跳过，产生不规则重复图案。

**输入结构**：

- 约 20x25 网格，背景黑(0)。
- 2~3 个精灵体，每个为 3x3 前景对象：8 个边框像素为同一颜色（"体色"，如绿(3)），中心 1 像素为另一颜色（"目标色"，如红(2)）。
- 对每个目标色，网格上存在恰好一个该颜色的实心矩形（宽/高各 2~4 像素）。
- 2~4 根障碍条散布于精灵体和目标矩形之间的路径上：每根障碍条由橙(7)像素和蓝(1)像素组成（混合排列），整体为 1 像素宽、3~6 像素长的竖直或水平条。每根障碍条内蓝(1)像素的数量等于该障碍的禁区半径 r（曼哈顿距离）。
- 每个精灵体与其目标矩形在同一行或同一列上对齐（纯基数方向分离）。
- 生成约束：每个精灵体的复制路径上至少有一个落点被禁区覆盖（产生至少一处跳空）；不同精灵体的路径互不重叠。

**规则**：

1. 将每个精灵体与中心像素颜色相同的实心矩形配对。
2. 从精灵体位置出发，沿与目标矩形对齐的基数方向，以 3 格为步长生成候选落点序列（第 k 个候选落点的中心 = 精灵体中心 + k*3 个像素偏移，k=1,2,3...）。
3. 对每个候选落点，检查 3x3 印章区域内是否有任何像素落在某个障碍条的禁区内。禁区定义：从该障碍条的任意像素出发，曼哈顿距离 <= r 的所有网格位置，其中 r = 该障碍条内蓝(1)像素的数量。
4. 若候选落点安全（3x3 区域完全在所有禁区之外），在该处印上 3x3 精灵体副本。
5. 若候选落点违反任何禁区，跳过该位置（保留背景），继续下一个候选落点。
6. 当某个印章副本的 3x3 区域与目标矩形重叠时，停止该精灵体的复制；重叠处印章像素覆盖矩形像素。
7. 所有印章完成后，将所有障碍条上的蓝(1)像素重涂为橙(7)（禁区编码在输出中消失）。
8. 原始精灵体、障碍条（已重涂）、未被覆盖的目标矩形区域保留不变。

**关键洞察**：障碍条上的蓝色像素编码了危险半径——蓝色越多，禁区越宽。印章重复路径不是均匀的周期图案，禁区造成的跳空产生了不规则间隔。相同精灵体-目标对齐方式下，不同障碍布局会产生不同的跳空模式。必须对比多个示例才能发现曼哈顿距离禁区规则和蓝色像素编码。

## 新题 3：块网格反转后的图例链式重涂

**组合逻辑**：[反转编码](保留精灵/空白互换的核心) + [逐行顺序链式替换](创新：替换目标不是预先存在的像素，而是反转操作产出的像素——反转改变了"哪些空间位置包含精灵颜色"，从而改变了链式替换的作用对象)

**来源原语**：反转编码/块网格/重复精灵体/均匀空白块/精灵与空白互逆/通配符视为空/修复(6350f1f4)，重涂色/双列图例/图例行序决定替换/逐行顺序链式替换/前景像素(e4888269)

**依赖链**：反转编码 → 精灵图案出现在原本为空白的块中 → 这些新位置上的精灵颜色成为图例链式替换的目标 → 替换按行序逐行扫描，同一像素可被连续替换多次 → 输出颜色同时取决于"哪些块被反转"和"图例替换链的顺序"。反转和重涂不可交换执行顺序：先重涂再反转与先反转再重涂产生不同结果，因为反转改变了重涂的空间目标，而重涂改变了反转后的颜色值。

反转块网格的精灵/空白编码，然后用双列图例对反转结果进行逐行链式颜色替换。

**输入结构**：

- 约 18x18 网格，由黑(0)分隔行和分隔列划分为 4x4 阵列共 16 个等大 3x3 块。
- 每个块为下列两种状态之一：(a) 某个固定两色精灵图案的副本（例如红(2)和黄(4)像素以固定 3x3 排列），或 (b) 精灵少数色（例如全黄(4)）填充的均匀空白块。部分块上有灰(5)像素作为擦除/通配符。
- 块网格右侧（不与块重叠）有一个双列竖直图例，包含 2~3 行，每行左列为被替换色、右列为替换色（例如：红(2)→绿(3)，黄(4)→蓝(1)）。
- 生成约束：至少一个块完全无灰(5)擦除，可从中推断完整精灵图案；图例中存在至少一组传递替换（即某行右列颜色等于后续行左列颜色，使得链式替换实际发生多次传递）。

**规则**：

1. 从完全可见的混色块推断出重复精灵图案（忽略灰色擦除像素）。
2. 反转块网格：将匹配精灵的块（灰色像素视为匹配通配符）替换为精灵多数色的均匀填充块；将均匀空白块替换为完整精灵图案。
3. 清理灰色擦除：分隔行/列上的灰(5)恢复为黑(0)；块内的灰色已被反转步骤解决。
4. 对反转后网格中所有非背景(0)、非分隔符(0)的像素，按图例行从上到下逐行扫描执行链式替换：若当前像素颜色等于该行左列颜色，则替换为右列颜色，然后继续扫描后续行（同一像素可在一次扫描中被多次改写）。
5. 图例本身、分隔符和背景不变。

**关键洞察**：反转和重涂不是独立的两步流水线——反转重新分配了精灵颜色的空间位置，图例链式替换再改写这些颜色。不做反转则图例会重涂错误的块（原始精灵位置而非反转后位置）。图例的行序也很关键：链式替换的先后顺序决定了中间颜色是否被二次传递改写，仅看单个示例无法区分"并行替换"与"链式替换"。

## 新题 4：控制像素分支——周期平铺与重力下落的二元分流

**组合逻辑**：[周期平铺](保留基于十字锚点的方向判定和周期重复) + [重力下落](创新：不再以整个标记为下落体，而是作为周期平铺的替代分支——同一结构中不同标记走不同操作路径) + [控制色定行为](从源题的"穿透或停靠"提升为"选择不同空间操作类型"的决策节点)

**来源原语**：周期平铺/十字图案/标记块/邻接侧决定方向/不覆盖源对象(53fb4810)，重力下落/控制像素/障碍物/控制色定行为/穿透或停靠(963c33f8)，射线延伸(53fb4810)

**依赖链**：标记块内的控制像素颜色 → 决策节点：蓝(1)则走周期平铺分支，栗(9)则走重力下落分支 → 平铺分支在延伸方向上按标记尺寸周期重复直至网格边界 → 重力分支沿延伸方向仅下落一个副本至首个障碍或网格边缘 → 同一十字锚点的不同臂可产生截然不同的输出形态。这是一个条件分支结构而非线性流水线：控制像素是决策节点，两个操作是互斥分支。

标记块内的隐藏控制像素决定该标记沿十字臂向外延伸时采用周期平铺还是重力下落。

**输入结构**：

- 约 20x20 网格，背景黑(0)。
- 2~3 个十字(+)形锚点，由灰(5)像素构成，每条臂长 2~3 像素（不含中心）。
- 每个十字的每条臂外侧紧邻一个标记块（2~4 像素的小色块），标记块内恰好有一个像素为蓝(1)或栗(9)——控制像素，其余像素为标记体色（如红(2)、绿(3)、黄(4)等各不相同）。
- 若干橙(7)障碍像素散布于网格上，不与任何十字或标记相邻。
- 生成约束：每个十字至少有一个蓝控制标记和一个栗控制标记；在栗控制标记的延伸方向上至少存在一个障碍像素；在蓝控制标记的延伸方向上可能有也可能没有障碍（不影响平铺行为）。

**规则**：

1. 对每个标记块，判断它紧邻十字的哪条臂 → 确定延伸方向（从十字中心向外，即远离十字的方向）。
2. 若标记的控制像素为蓝(1)：沿延伸方向周期平铺——以标记在延伸方向上的尺寸为步长，重复标记图案直至网格边界。十字像素和其他标记不被覆盖；若平铺副本与障碍像素重叠，障碍被覆盖（平铺忽略障碍）。
3. 若标记的控制像素为栗(9)：沿延伸方向重力下落——将标记整体作为下落物，在延伸方向上滑动，遇到第一个橙(7)障碍像素或网格边缘时停止（标记的前缘紧贴障碍前一格或网格最后一格）。仅放置一个副本，不做周期重复。
4. 所有标记处理完毕后，将输出中所有控制像素（蓝(1)和栗(9)）重涂为其所在标记的体色（控制标志在输出中消失）。
5. 两个标记的输出区域重叠时，距其所属十字中心更近的标记优先（该标记的像素后绘制、覆盖在上）。

**关键洞察**：控制像素在输出中被重涂为体色从而不可见，但它完全决定了该标记是周期平铺还是单次下落——外观相同的标记（体色相同、相对十字位置相同）可能因隐藏的控制像素不同而产生截然不同的输出。必须对比多个示例才能发现：(a) 哪种控制色对应哪种操作；(b) 重力下落在障碍处停止而周期平铺忽略障碍。

## 新题 5：重力投递种子像素决定腔体填充归属

**组合逻辑**：[重力下落](创新：下落物不是待排列的标记而是待分配的种子——重力路径决定种子与腔体的配对关系) + [填充](保留封闭腔体的泛洪填充核心，但种子不是固定在边界的静态点，而是经重力路径到达的动态着陆点) + [障碍拦截](从"穿透或停靠"简化为"障碍阻断种子到达腔体"的过滤机制)

**来源原语**：重力下落/边缘标记/障碍物/控制色定行为(963c33f8)，填充/种子像素/封闭腔体/线条画/连通可达/种子色标记填充(8b7bacbf)

**依赖链**：种子像素从顶边下落 → 障碍物拦截部分种子（搁浅） → 未被拦截的种子落在线条画边界上 → 着陆点决定种子与哪个封闭腔体相邻 → 相邻腔体被该种子颜色泛洪填充。删除重力下落则种子停在顶边无法到达任何腔体；删除泛洪填充则种子着陆但腔体不变。种子-腔体配对完全由重力路径和障碍布局决定——移动一个障碍可能让种子滑过原本的目标到达另一个腔体，彻底改变输出。这是"路由决定赋值"的结构，非线性流水线。

种子像素从顶边下落，着陆位置决定它填充哪个封闭腔体；被障碍拦截的种子搁浅，不填充任何腔体。

**输入结构**：

- 约 20x20 网格，背景黑(0)。
- 下方约三分之二区域：灰(5)像素绘制的线条画，形成 3~5 个互不嵌套的封闭环路，每个环路围成一个大小不同的背景色腔体（腔体面积 4~20 像素）。环路之间互不接触，由背景隔开。
- 上方约三分之一区域：若干灰(5)障碍像素散布其中，不属于任何线条画环路（4-连通不与任何环路相连）。
- 顶边（第 0 行）上放置 3~5 个不同颜色的种子像素（如红(2)、蓝(1)、绿(3)、黄(4)、橙(7)），各占不同列。
- 生成约束：每个种子的正下方列最终经过恰好一个环路的边界（确保着陆唯一性）；不同种子着陆后相邻的腔体各不相同（一对一映射）；至少一个种子的正下方有障碍像素阻挡，使其搁浅于障碍上方而非到达任何环路。

**规则**：

1. 每个种子像素从顶边向下做重力下落（每次移动 1 格）。
2. 种子在遇到正下方第一个非背景像素时停止——停在该像素正上方一格。该非背景像素可能是灰(5)障碍像素或灰(5)线条画像素。
3. 判断种子着陆处下方的灰(5)像素是否属于某个封闭环路的边界：
   - 若该灰(5)像素属于某个封闭环路（4-连通追踪可达一个完整闭合结构）：种子"到达"该环路。对该环路围成的背景腔体执行 4-连通泛洪填充，填充色为种子颜色。填充完成后种子本身被消耗（从输出中移除，仅保留填充后的腔体）。
   - 若该灰(5)像素不属于任何封闭环路（孤立障碍像素或开放线段）：种子"搁浅"。种子保留在着陆位置，不对任何腔体执行填充。
4. 线条画（所有灰(5)环路和障碍像素）在输出中保留不变。
5. 未被任何种子到达的封闭腔体保持背景色不变。

**关键洞察**：障碍像素是拦截器——它们在种子到达腔体前将其捕获，阻止特定填充的发生。障碍的空间布局决定了哪些种子到达哪些腔体，构成一个重力路由谜题。移动一个障碍可能让种子落到不同的腔体上，完全改变输出。必须对比多个示例才能发现：(a)"搁浅"与"到达"的区别取决于着陆点下方像素是否属于闭合环路；(b) 成功填充的种子被消耗而搁浅的种子保留。

## 新题 6：镜像对接构造封闭腔体再泛洪填充

**组合逻辑**：[滑动+镜像](保留精灵体沿基数方向滑向锚点并反射的核心机制) + [填充](创新：填充对象不是输入中预存的腔体，而是镜像操作动态构造出来的新封闭区域——精灵体的凹形轮廓与其镜像拼合后包围出原本不存在的背景空腔) + [颜色匹配配对](种子像素与腔体的配对基于空间邻近度，而邻近度取决于锚点位置和镜像几何)

**来源原语**：滑动/镜像/精灵体/方块锚点/接触边对齐/锚点边为镜像轴/碰撞停止(11dc524f)，填充/封闭腔体/种子像素/连通可达/种子色标记填充(8b7bacbf)，颜色匹配配对(2c181942)

**依赖链**：精灵体滑向锚点 → 接触边成为镜像轴 → 精灵 + 镜像形成可能的封闭边界 → 仅当精灵轮廓有凹面时，拼合后的边界才围成腔体 → 腔体的空间位置取决于锚点位置 → 最近种子像素（按曼哈顿距离）填充该腔体。删除镜像则无腔体产生；删除填充则腔体存在但不着色。精灵形状、锚点位置和种子位置三者共同决定输出——改变精灵凹凸性可能导致腔体出现或消失，改变锚点位置可能改变种子归属。这是"几何构造 → 拓扑检测 → 空间赋值"的三级耦合结构。

将精灵体滑向锚点并镜像反射；凹形精灵的原件与镜像拼合后围成新腔体，用最近种子像素的颜色泛洪填充。

**输入结构**：

- 约 20x20 网格，背景黑(0)。
- 3~4 组精灵-锚点对：
  - 每个精灵为一个小型 8-连通单色非背景图形（3~6 像素，形状不规则），颜色各不相同（如红(2)、绿(3)、蓝(1)）。至少 2 个精灵的轮廓有凹面（如 L 形、U 形、阶梯形），至少 1 个精灵的轮廓是凸的（如直线段、实心块）。
  - 每个锚点为一个 2x2 实心方块，颜色为另一种非背景色（如黄(4)、橙(7)、灰(5)），与配对精灵不同色。
  - 每对精灵-锚点沿恰好一个基数方向分离（精灵与锚点在同一行带或列带上）。
- 2~3 个不同颜色的种子像素（如栗(9)、青(8)）放置于锚点附近（距最近锚点 2 格以内，但不在任何精灵滑动路径上）。
- 生成约束：凹形精灵镜像后能围成至少一个背景像素的封闭腔体；凸形精灵镜像后不产生封闭腔体（原件 + 镜像的外边界无包围）；每个种子最近的锚点各不相同（一对一）。

**规则**：

1. 对每组精灵-锚点对：沿分离方向将精灵直线滑向锚点，直到精灵触碰锚点的近边（精灵前缘与锚点面紧贴）。
2. 以接触边为镜像轴，将接触后的精灵做反射，镜像副本用锚点颜色绘制。清除精灵和锚点的原始位置（若精灵已滑动，原位已空；锚点位置被镜像副本占据或成为背景）。输出中保留滑动后的精灵（原色）和镜像副本（锚点色）。
3. 所有对处理完毕后，检测新产生的封闭腔体：寻找完全被非背景像素包围的 4-连通背景区域。这些腔体仅因镜像拼合而存在（凸形精灵不产生腔体）。
4. 对每个新腔体，计算腔体边界框到每个种子像素的曼哈顿距离（种子到边界框最近边格的距离），选择最近的种子。
5. 用最近种子的颜色对该腔体执行 4-连通泛洪填充。
6. 不产生封闭腔体的精灵-镜像对保持原样（原件 + 镜像，无填充）。
7. 种子像素在输出中保留不变。
8. 若两个腔体的最近种子相同，两个腔体都用该种子颜色填充（种子不被消耗）。

**关键洞察**：只有凹形精灵镜像后才会产生封闭腔体——精灵的形状决定了腔体是否出现。种子-腔体的配对取决于腔体的空间位置，而腔体位置由锚点位置和精灵几何共同决定。必须先预测镜像几何才能知道哪些腔体存在，然后才能做种子赋值。必须对比多个示例才能发现：(a) 凹形产生腔体而凸形不产生；(b) 最近种子选择规则。
