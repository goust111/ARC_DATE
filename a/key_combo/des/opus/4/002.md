## 新题 1：缺口定向漂移与边界内轮廓描边

**组合逻辑**：[缺口方向决定射线](创新：缺口方向不再驱动射线延伸，而是驱动精灵体的平移方向) → [重力下落](创新：下落方向由缺口而非重力常数决定) → [描边/轮廓](已有：在最终位置绘制空心轮廓) + [框内裁剪](创新：轮廓被框边界截断)

**来源原语**：缺口方向决定射线(gap_direction_determines_ray, 551d5bf1)、边框缺口(border_gap, 551d5bf1)、重力下落(gravity_drop, 6ca952ad)、面积区分角色(area_determines_role, 6ca952ad)、描边/轮廓(outline, 913fb3ed)、空心矩形(hollow_square, 913fb3ed)

**依赖链**：缺口的朝向决定精灵体的滑动方向 → 滑动距离由框内部空间决定 → 精灵体到达新位置后才能确定轮廓绘制坐标 → 轮廓与框边界的空间交叉决定最终裁剪形态

根据每个空心矩形框的缺口方向将框内精灵体向缺口侧滑动至框壁，然后在精灵体的最终位置绘制被框边界裁剪的空心轮廓。

**输入结构**：约 20x20 的网格，黑(0)背景。包含 2~4 个蓝(1)色一像素厚的空心矩形框（边长约 5~8），彼此不相邻且不重叠。每个框的四条边中恰好有一条边缺失一个非角落像素（缺口）。每个框内部有一个单色的 4-连通小图形（3~5 像素，颜色在红(2)、绿(3)、黄(4)中各不相同），该图形与框壁之间至少有 1 像素间距。生成约束：每个精灵体沿缺口方向滑动后，其包围盒不会与缺口重合（即精灵体不会从缺口逃逸）；不同框之间距离至少 2 像素。

**规则**：
1. 对每个蓝(1)空心矩形框，识别其缺口所在的边（上、下、左、右）。
2. 将框内部的彩色精灵体沿缺口方向平移，直到精灵体的包围盒在该方向上触及框的内壁（不包含框壁像素本身）。若缺口在右边，精灵体向右滑动；若在上边，向上滑动；以此类推。
3. 在精灵体的最终位置，以每个精灵体像素为中心绘制 3x3 空心方环，颜色为灰(5)。多个方环重叠时后绘制的灰(5)覆盖先绘制的（实际效果相同，因为颜色一致）。
4. 空心方环中超出框内部区域（即落在框壁上或框外）的像素不绘制。
5. 蓝(1)框壁（包括缺口位置）保持不变；精灵体原位置的像素清除为黑(0)，精灵体在新位置保留其原色；灰(5)轮廓不覆盖精灵体本身的像素。

**关键洞察**：缺口在源题中是射线的出口，但在本题中缺口仅编码方向信息而不允许任何像素通过——精灵体被挡在框壁内侧。轮廓在源题中无边界约束，但在本题中框壁构成硬裁剪边界，不同缺口位置导致精灵体停靠在不同边，从而使同形轮廓被不同方向的框壁裁剪出不同外观。

## 新题 2：周期补全后的分区众数重涂色

**组合逻辑**：[补全](已有：推断周期瓦片并恢复缺失值) → [计数](创新：不对全局计数，而是在分区内分别计数) → [重涂色](创新：不按颜色映射重涂，而是按分区众数重涂整个分区)

**来源原语**：补全(completion, f823c43c)、周期瓦片(periodic_tile, f823c43c)、标记为缺失值(markers_missing_val, f823c43c)、行列周期(row_col_period, f823c43c)、计数(counting, ff2825db)、众数颜色决定输出(majority_color_out, ff2825db)、重涂色(recolor, ff2825db)

**依赖链**：粉(6)标记像素使颜色分布不完整 → 必须先推断周期瓦片恢复真实颜色 → 恢复后才能在每个分区内正确计数两种图案色的数量 → 众数颜色决定该分区的输出颜色 → 周期与分区边界的对齐偏移导致相邻分区众数不同

根据恢复后的周期图案在每个灰线分区内的颜色多寡，将整个分区统一涂为该区域的众数颜色。

**输入结构**：约 15x15 的网格。底色为由两种颜色（蓝(1)和黄(4)）构成的行列周期图案（周期约 2~4），其中若干像素被粉(6)替换（占总像素的 15%~30%）。网格被灰(5)的单像素宽水平线和/或垂直线分割为 2x2 或 2x3 个矩形分区（灰线贯穿整行或整列）。生成约束：粉(6)像素的分布保证去掉粉(6)后，剩余可见像素足以唯一确定最小周期瓦片；每个分区面积至少 9 像素（不含灰线）；至少存在两个分区的众数颜色不同（通过控制灰线位置相对于周期的偏移实现）。

**规则**：
1. 将所有粉(6)像素视为缺失值。从非粉、非灰的可见像素中推断蓝(1)与黄(4)构成的最小行列周期矩形瓦片。
2. 用推断出的瓦片恢复每个粉(6)像素的真实颜色（蓝(1)或黄(4)）。
3. 对灰(5)线分割出的每个矩形分区，分别统计恢复后该分区内蓝(1)与黄(4)的像素数量。
4. 将该分区内所有非灰像素统一重涂为该分区的众数颜色（数量较多的那种）。若两色数量相等，保留蓝(1)（即蓝优先）。
5. 灰(5)分隔线保持不变。

**关键洞察**：同一个周期图案在不同分区内可能产生不同的众数颜色——这取决于分区边界相对于瓦片周期的偏移量。粉(6)标记的存在使得不先完成补全就无法正确判断众数，因为被粉覆盖的像素可能改变多数关系。

## 新题 3：面积决定角色的镜像-射线分叉

**组合逻辑**：[面积区分角色](创新：面积不再区分"动/静"，而是区分"镜像目标"与"射线源") → [镜像](已有：围绕红标记点反射) ∥ [射线延伸](创新：射线方向由标记点→小分量的矢量决定，且使用交替色) → [遮挡判定](创新：镜像产物可阻断射线)

**来源原语**：面积区分角色(area_determines_role, 6ca952ad)、镜像(mirror, 7ed72f31)、反射轴标记(reflection_axis_marker, 7ed72f31)、透明叠加(transparent_overlay, 7ed72f31)、射线延伸(ray_extend, 97999447)、奇偶交替(parity_alternation, 97999447)、精灵体(sprite, 7ed72f31)

**依赖链**：每个红标记点的邻域内有多个不同大小的分量 → 面积最大者被选为镜像载荷，其余为射线源 → 镜像操作先执行，产物叠加到网格上 → 射线从小分量出发沿径向延伸，但镜像产物占据的像素会阻断射线 → 因此镜像的几何形状直接影响射线的长度

将每个红标记点附近面积最大的分量点反射到对侧，同时从较小分量沿离开标记点的方向发射交替色射线，射线被镜像产物阻断。

**输入结构**：约 18x18 的网格，黑(0)背景。包含 2~3 个红(2)单像素标记，彼此间距至少 8 像素。每个红标记的 8-连通邻域（半径约 3~4 像素内）有 2~3 个不同颜色的 4-连通单色分量（每个分量 2~7 像素，颜色从绿(3)、蓝(1)、橙(7)、栗(9)中选取，每个标记邻域内各分量颜色不同）。每个标记邻域内恰好有一个分量面积严格最大。生成约束：面积最大分量关于红标记点反射后落在网格内，且不与其他标记的邻域重叠；各标记邻域的分量不互相接触。

**规则**：
1. 对每个红(2)标记像素，找出与其 8-连通距离不超过 4 的所有非红、非黑 4-连通分量。
2. 在这些分量中，面积（像素数）最大的标记为"载荷"，其余标记为"射线源"。
3. 将载荷关于红标记做 180 度点反射（每个载荷像素 (r,c) 映射到 (2*mr-r, 2*mc-c)，其中 (mr,mc) 为红标记坐标），反射像素以载荷的原色绘制在网格上，仅覆盖黑(0)像素（非黑像素不被覆盖）。
4. 对每个射线源分量，计算从红标记指向该分量质心的方向矢量，取最近的正交方向（上/下/左/右）作为射线方向。若与两个正交方向等距，取行方向（水平）优先。
5. 从该射线源分量在射线方向上最远的像素开始，沿射线方向逐像素延伸：偏移量为偶数的像素涂该分量的颜色，偏移量为奇数的像素涂灰(5)。射线遇到非黑像素（包括步骤 3 的镜像产物、其他分量、其他射线已绘制的像素）时停止，不包含终止像素。射线超出网格边界时也停止。
6. 红(2)标记像素保持不变。各射线源和载荷的原始像素保持不变。

**关键洞察**：面积在源题中区分"动态精灵"与"静态标记"，但在本题中区分"被镜像的对象"与"发射射线的对象"——两种完全不同的变换操作由同一属性分配。镜像产物不是装饰性叠加，而是在空间中构筑了阻断射线的实体屏障。需要先完成镜像才能确定射线长度，射线长度对于不同标记点因其载荷形状不同而各异。

## 新题 4：端点对齐拼接涌现封闭轮廓与洪泛填充

**组合逻辑**：[滑动拼接](已有：去除分隔列并按端点垂直对齐) → [轮廓围合](创新：拼接后的链条形成了单个片段中不存在的封闭区域) → [洪泛填充](已有：对封闭背景区域填色)

**来源原语**：滑动(sliding, d017b73f)、拼接(concatenation, d017b73f)、端点对齐(endpoint_align, d017b73f)、端点匹配拼接(endpoint_match_concat, d017b73f)、路径片段(path_segment, d017b73f)、洪泛填充(flood_fill, 753ea09b)、封闭背景区域(enclosed_bg_region, 753ea09b)、轮廓围合(contour_enclosure, 753ea09b)、小区域被填充(small_regions_filled, 753ea09b)

**依赖链**：各路径片段单独都是开放曲线，无法围合任何区域 → 端点对齐拼接将片段首尾相连 → 正确拼接后链条恰好闭合形成封闭轮廓 → 封闭轮廓界定了需要填充的背景区域 → 填充颜色为轮廓自身的前景色

将分隔开的路径片段按端点对齐拼合为闭合轮廓，再将轮廓围合的内部背景区域洪泛填充。

**输入结构**：约 7x20 的窄长网格（高度小、宽度大），黑(0)背景。包含 3~5 个单色（绿(3)）路径片段组，每组占据连续的若干非背景列，组与组之间以全黑列分隔。每个片段组是由绿(3)像素构成的 4-连通弯折线段（3~8 像素），每组恰好在其最左列和最右列各有一个度为 1 的端点像素（仅有一个 4-连通前景邻居）。生成约束：按端点匹配规则拼接后，最左片段的左端点与最右片段的右端点恰好位于同一行，且拼合后的路径形成恰好一个简单闭合回路，围合至少一个内部背景区域（面积 >= 2 像素）；片段总数为奇数或偶数均可，但闭合是必要约束。

**规则**：
1. 识别所有由全黑列分隔的路径片段组，按从左到右的顺序编号。
2. 保持第一组的垂直位置不变。从第二组起，依次将每组垂直平移，使其左端点与前一组的右端点位于同一行，然后水平紧贴（去除分隔列后左端点列紧邻前一组右端点列的下一列）。
3. 拼接完成后，若最后一组的右端点与第一组的左端点位于同一行且水平相邻（或可通过网格的环绕/直接相邻连接），则整条路径闭合。（生成时保证闭合条件成立。）
4. 识别被闭合绿(3)轮廓 4-连通围合的背景区域（不触及网格边界的黑(0)连通分量）。
5. 将这些封闭背景区域的所有像素涂为绿(3)。
6. 所有绿(3)轮廓像素保持不变。触及网格边界的背景区域保持黑(0)。

**关键洞察**：每个路径片段都是开放线段，任何单一片段都不围合任何区域——封闭区域是拼接的涌现结果。求解者必须先正确执行端点匹配（需要对比多个示例推断匹配规则），才能获得闭合轮廓，进而判断哪些区域被围合。拼接规则和填充规则缺一不可。

## 新题 5：平铺后重力打破对称性与对角标记不对称显现

**组合逻辑**：[平铺](已有：2x2 复制) → [重力下落](创新：不按全局面积区分角色，而是按颜色区分——一种颜色下落，另一种静止) → [对角标记](已有：在种子像素的对角邻居涂色) → [对称性破缺](涌现效应：四个象限中重力使同一组对角位置的可用性不同)

**来源原语**：平铺(tiling, 10fcaaa3)、对角邻接(diagonal_adjacency, 10fcaaa3)、描边/标记邻居(mark_neighbors, 10fcaaa3)、平铺后对角涂色(diagonal_marked_after_tiling, 10fcaaa3)、重力下落(gravity_drop, 6ca952ad)、触底停止(stop_at_bottom, 6ca952ad)、种子像素(seed_pixel, 10fcaaa3)

**依赖链**：平铺创建四份完全对称的副本 → 重力使特定颜色的对象在各象限中向下移动，由于初始行位置不同，移动距离不同 → 移动后原位置变为黑色，新位置被占据 → 对角标记在种子像素周围寻找黑色对角邻居 → 重力清出或占据的像素改变了可用的对角位置 → 四个象限中对角标记图案因此各不相同

将小网格平铺 2x2 后，让一种颜色的对象下落至底部，然后在不动的种子像素的黑色对角邻居处涂青色——重力导致四个象限产生不同的标记图案。

**输入结构**：5x5 的小网格，黑(0)背景。包含一个橙(7)色的 4-连通小图形（3~5 像素，不触及网格底边）和 1~2 个蓝(1)色单像素种子。橙(7)图形与蓝(1)种子不相邻（4-连通距离 >= 2）。生成约束：平铺为 10x10 后，橙(7)副本下落后不会与蓝(1)种子在任何象限重叠；至少有一个蓝(1)种子在平铺后的某个象限中，其某个对角邻居在重力前被橙(7)占据、重力后被清空（从而该象限多出一个青(8)标记），同时在另一个象限中该对角邻居在重力后仍被橙(7)占据（从而该象限少一个青(8)标记）。

**规则**：
1. 将输入网格平铺为 2x2 的 10x10 网格（四个象限各一份完整副本）。
2. 在平铺后的网格中，将所有橙(7) 4-连通分量独立地垂直向下平移，直到每个分量的包围盒底边到达网格底边（第 9 行，0-indexed）。上方同列若有多个橙(7)分量，先落最下方的，再落上方的，后者停在前者之上（堆叠）。橙(7)分量的原位置清为黑(0)。
3. 蓝(1)种子像素保持原位不动。
4. 对平铺后网格中每个蓝(1)像素，检查其四个对角邻居。若对角邻居为黑(0)，将其涂为青(8)。若对角邻居为非黑色（橙(7)、蓝(1)或已有青(8)），不涂色。
5. 不同蓝(1)种子的对角标记范围可能重叠，重叠处颜色相同（均为青(8)），无冲突。

**关键洞察**：平铺本身产生完美的四重对称，但重力沿单一方向（向下）作用，打破了上下对称性。位于网格上半部的橙(7)副本下落距离远，清空了大片区域；位于下半部的副本下落距离短，仍占据原位附近空间。因此上半部象限的种子获得更多空闲对角位置用于标记，而下半部象限的种子对角位置更多被橙(7)堵塞。这种"平铺生成对称 → 重力打破对称 → 标记显现不对称"的三步涌现是任何单一源题中都不存在的。

## 新题 6：最小间距对触发交替色填充并向两侧射线延伸

**组合逻辑**：[最小间距对触发](已有：找到最近的镜像标记对) → [填充](创新：不做实心填充，改为交替色填充) → [射线延伸](创新：从标记对两端向外延伸，且延续填充的奇偶相位) → [相位耦合](涌现效应：间距的奇偶性决定外侧射线的起始颜色)

**来源原语**：连线/填充(connect/fill, 5ad8a7c0)、对称标记对(mirrored_marker_pair, 5ad8a7c0)、中轴对称(center_axis_symmetry, 5ad8a7c0)、最小间距对触发(min_gap_triggered, 5ad8a7c0)、射线延伸(ray_extend, 97999447)、奇偶交替(parity_alternation, 97999447)、交替填充至边界(alternating_fill_to_edge, 97999447)、画布边界(canvas_boundary, 97999447)

**依赖链**：识别所有镜像标记对并计算各自间距 → 最小间距决定哪些行被选中 → 选中行的两标记之间用交替色填充（前景/灰交替） → 填充的奇偶相位从左标记开始确定 → 左标记向左、右标记向右发射射线，射线的起始相位由填充在该标记处的相位连续推导 → 间距的奇偶性改变了右标记处的填充相位，进而改变右侧射线的起始颜色

在对称标记对中找到间距最小的行，用交替色横穿填充标记间的空隙，再从两端向网格边界延伸同相位的交替射线。

**输入结构**：约 12x16 的网格，黑(0)背景。网格有一条垂直中轴。每行至多一对前景像素（红(2)），且该对关于中轴对称。共有 4~6 行包含标记对，各行间距（两标记间黑像素数）各不相同，其中恰好有一行的间距严格最小（唯一最小）。不包含标记对的行全为黑色。生成约束：间距最小行的间距 >= 2（至少两个黑像素间隔）；不同示例中最小间距行位于不同行号，且间距的奇偶性在不同示例间有变化。

**规则**：
1. 对每行中的红(2)标记对，计算两标记之间的黑像素数量（即间距 = 右标记列 - 左标记列 - 1）。
2. 选择间距严格最小的行（唯一）。
3. 在该行中，从左标记位置开始，向右逐像素填充至右标记位置（含两端标记）：偏移量 0（左标记自身）涂红(2)，偏移量 1 涂灰(5)，偏移量 2 涂红(2)，以此类推交替。
4. 从左标记向左延伸射线至网格左边界：偏移量 -1 涂灰(5)，偏移量 -2 涂红(2)，交替进行直到列 0。
5. 从右标记向右延伸射线至网格右边界：右标记在步骤 3 中获得的颜色决定其相位；从右标记的下一像素起，相位翻转继续交替，直到最右列。
6. 其余所有行保持不变。

**关键洞察**：当间距为偶数时，右标记的填充相位与左标记相同（红），因此右侧射线从灰开始；当间距为奇数时，右标记的填充相位为灰，右侧射线从红开始。这意味着仅看单个示例，无法确定右侧射线的起始颜色规则——必须对比不同间距（奇/偶）的示例才能归纳出相位连续性规律。

## 新题 7：障碍绕行连线的弯折计数渲染

**组合逻辑**：[连线](已有：同色分量最短 L 形路径连接) → [计数](创新：不计标记像素数，而是计连接路径的弯折次数) → [计数渲染](已有：将计数结果渲染为 3x3 格式) + [颜色映射](创新：每种颜色的弯折数渲染到输出区的对应行)

**来源原语**：连线(connect, f8f52ecc)、同色连通分量(same_color_comp, f8f52ecc)、障碍墙(obstacle_wall, f8f52ecc)、绕障碍最短路径(shortest_detour, f8f52ecc)、同色分量依序连接(same_color_chain, f8f52ecc)、计数(counting, c8b7cc0f)、计数渲染(tally_render, c8b7cc0f)、忽略干扰项(ignore_distractors, c8b7cc0f)

**依赖链**：障碍布局决定了每种颜色的最短连接路径形态 → 路径形态中弯折次数是路径复杂度的量化 → 弯折次数作为计数值输入渲染步骤 → 每种颜色的渲染行需要知道该颜色的弯折数 → 障碍位置的微小变化会改变弯折数从而改变输出

统计每种颜色的同色分量连接路径绕过障碍时的弯折次数，将各颜色的弯折计数以色块行形式渲染到输出区。

**输入结构**：网格分为左右两部分。左侧为约 12x12 的工作区：黑(0)背景，包含青(8)色障碍墙段（若干 4-连通直线段或拐角段），以及 3 种非黑、非青颜色（从红(2)、绿(3)、黄(4)、橙(7)中选三种），每种颜色恰好有两个分离的 4-连通分量（每个分量 2~4 像素）。右侧为一个 3 列宽的输出区，由灰(5)竖线与工作区分隔，内部初始全黑，高度 >= 3 行（每种颜色预留一行）。生成约束：每种颜色的两个分量之间存在唯一最短 L 形路径（不经过障碍和其他颜色），弯折次数在 0~3 之间（0 表示直线连接，1 表示一个 90 度转弯，以此类推）；三种颜色的弯折数不全相同；在工作区中，按最上方像素的行主序确定三种颜色的从上到下排列顺序。

**规则**：
1. 在工作区中，对每种非黑、非青颜色，识别其两个 4-连通分量。
2. 计算连接两分量的最短路径（仅可通过黑(0)或同色像素，不可经过青(8)或其他颜色）。路径为正交逐步移动。在两分量间寻找弯折次数最少的 L 形路径：先沿一个轴走到对齐位置，再沿另一个轴走到目标。若路径被障碍阻挡需绕行，取弯折最少的绕行路径。
3. 统计该路径的弯折次数 B（方向改变的次数：直线连接为 0，单次转弯为 1，以此类推）。
4. 确定三种颜色的渲染顺序：按每种颜色在工作区中最上方、最左方像素的行主序（先比较行号，行号相同比较列号），从上到下排列。
5. 在输出区中，从上到下依次为每种颜色渲染一行（行高 1 像素，宽 3 像素）：该行的前 B 个像素（从左到右）涂为该颜色，其余保持黑(0)。若 B=0，该行全黑。
6. 工作区的所有像素保持输入状态不变（不绘制连接路径）。灰(5)分隔线保持不变。

**关键洞察**：连接路径本身不在输出中可见——障碍迫使路径绕行产生弯折，弯折次数被抽象为一个数值，最终以完全不同的几何形式（色块行）呈现在输出区。求解者需要"在脑中"完成路由、计数、再渲染三步变换。障碍的空间布局是一种隐式编码装置，将空间复杂度转化为数值信息。

## 新题 8：弹性拉伸模板填充与缺口位置决定射线颜色

**组合逻辑**：[弹性拉伸/模板填充](已有：将多色范例拉伸填入目标矩形) → [缺口位置采样](创新：在拉伸后的图案中，缺口位置处的颜色决定射线颜色) → [射线延伸](创新：射线不从孤立像素出发，而是从矩形边框缺口出发，颜色由拉伸结果决定)

**来源原语**：弹性拉伸(elastic_stretching, 40f6cd08)、模板填充(template_filling, 40f6cd08)、多色范例矩形(multicolor_exemplar_rect, 40f6cd08)、纯色目标矩形(solid_target_rect, 40f6cd08)、内部行程(interior_run, 40f6cd08)、按目标尺寸调整(resize_to_target, 40f6cd08)、射线延伸(ray_extend, 551d5bf1)、边框缺口(border_gap, 551d5bf1)、缺口方向决定射线(gap_direction_determines_ray, 551d5bf1)

**依赖链**：范例矩形的内部结构通过弹性拉伸适配到不同尺寸的目标矩形 → 不同目标尺寸导致内部行程拉伸程度不同 → 每个目标的缺口在拉伸后图案中对应不同的内部位置 → 该位置的颜色成为从缺口射出的射线的颜色 → 因此不同尺寸的目标矩形即使缺口在同侧，也可能产生不同颜色的射线

将多色范例弹性拉伸填入各目标矩形，再从每个目标的边框缺口处读取拉伸后的颜色，以该颜色向外发射射线。

**输入结构**：约 20x20 的网格，黑(0)背景。左上角有一个约 5x5 的多色范例矩形，其四角和外框为栗(9)色，内部包含由蓝(1)、黄(4)、绿(3)构成的条纹图案（行程式编码结构：外框行固定，内部有一个行方向和一个列方向的可拉伸行程）。网格其余位置有 2~3 个栗(9)色实心矩形（不同尺寸，宽度和高度在 4~8 之间），每个实心矩形恰好有一个非角落边框像素被移除（变为黑(0)），形成缺口。生成约束：各目标矩形互不重叠、互不相邻；缺口的垂直方向射线和水平方向射线不穿过其他目标矩形（即射线路径上全为黑(0)直到网格边界）；范例矩形的内部行程结构保证在弹性拉伸到任何目标尺寸后，缺口位置处的颜色可唯一确定。

**规则**：
1. 识别多色范例矩形（四角颜色相同、内部多色的矩形）和所有纯色目标矩形（单色且有一个缺口的矩形）。
2. 对范例矩形进行行程编码：将相同的行合并为行行程，相同的列合并为列行程。在每个轴上，识别边界行程（固定不变）和内部行程（可拉伸）。内部行程的判定方法：选择其代表行/列中包含最多不同颜色的那个行程，若颜色数相同则选宽度/高度唯一的那个。
3. 对每个目标矩形，计算其内部尺寸（减去边框），将范例的内部行程在行方向和列方向分别拉伸或收缩以适配该尺寸，边界行程保持不变。用拉伸后的图案替换目标矩形的内容。
4. 在每个目标矩形的缺口位置（被移除的边框像素），读取该位置在拉伸后图案中对应的颜色 C。（缺口位于边框上，对应图案的边界行程中的某个像素。）
5. 从缺口位置向外（垂直于缺口所在边，朝网格外侧方向）逐像素延伸射线，颜色为 C，直到网格边界。射线上的每个像素都涂为 C（不交替）。
6. 缺口位置本身也涂为 C（即缺口被修复为图案颜色，同时射线从此处延伸出去）。

**关键洞察**：射线颜色不由目标矩形的固有属性决定，而是由范例图案在弹性拉伸到特定尺寸后、恰好在缺口位置处呈现的颜色决定。因此同一范例在不同尺寸目标上可能在对应位置产生不同颜色，导致不同目标的射线颜色不同。求解者必须先理解弹性拉伸规则，才能推断射线颜色——两步逻辑紧密耦合且无法跳步。
