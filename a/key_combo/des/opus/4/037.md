## 新题 1：格栅单元循环重排

**组合逻辑**：[分隔线网格](已有) + [纯色即有效→标记单元定位](创新：原语从判断"哪些格子有效"改为"哪个格子是控制信号") + [循环位移](已有，但作用对象从像素行列提升到格栅单元) + [裁剪](已有)

**来源原语**：separator_lattice / solid_cell / solid_is_valid（458e3a53）、cyclic_roll / marker_is_shift（79cce52d）、crop（458e3a53 / 79cce52d）

**依赖链**：格栅解析产出单元阵列 → 纯色单元检测定位唯一的标记单元 → 标记单元的格栅行列坐标转化为双轴循环位移量 → 位移后裁剪去除分隔线输出重排阵列

将格栅中唯一纯色标记单元的位置解码为双轴偏移量，对整个格栅单元阵列做循环重排后输出。

**输入结构**：约 15x15 的网格，灰(5) 分隔线（完整行和完整列）将网格切分为 4x4 的方形单元阵列。每个单元约 3x3 像素。其中恰好一个单元的内部全部为红(2)（纯色标记单元），其余 15 个单元内部由黑(0) 背景上的彩色像素构成不规则小图案（使用蓝(1)、绿(3)、黄(4) 等，各单元图案互不相同，每个图案为 2~5 个像素的 4-连通图形）。生成约束：标记单元不在阵列角落位置，以保证两个偏移量均非零。

**规则**：
1. 识别所有完整灰(5) 行和完整灰(5) 列，将网格切分为 4x4 的单元阵列。
2. 找到内部全部为红(2) 的唯一单元，记其在阵列中的位置为 (R, C)（行列均从 0 开始计）。
3. 将该标记单元视为空白（内部全部替换为黑(0)）。
4. 对整个 4x4 单元阵列做循环位移：所有单元向下平移 R 行、向右平移 C 列（超出边界的回绕到对侧）。
5. 输出重排后的阵列内容，去除所有灰(5) 分隔线，单元之间直接拼接。

**关键洞察**：纯色检测在源题中用于判别有效/无效单元，这里被重新用作"哪个单元是控制信号"的定位手段；该控制信号的坐标同时编码两个位移量，而位移对象从像素级提升到了格栅单元级——必须先完成格栅解析才能正确定位标记，也必须正确读出位置才能执行位移。

## 新题 2：裂缝分离后的重力堆叠与重合判定

**组合逻辑**：[裂缝标记线 + 沿短轴分裂](已有) → [擦除](已有) → [重力下落 + 碰撞阻挡 + 重力远近序处理](已有，但作用对象变为裂缝产生的碎片) → [重涂色](已有，触发条件为碎片重合判定——创新)

**来源原语**：fracture_line / split_along_short / halves_separate / erase（2faf500b）、gravity_drop / collision_blocking / gravity_far_to_near（5ffb2104）、recolor（dc2e9a9d）

**依赖链**：裂缝分裂产出碎片集 → 碎片加入全局重力场 → 碰撞阻挡决定最终位置 → 同色碎片是否垂直相邻决定是否重涂色

将每个含裂缝的对象沿裂缝分离为两半，所有碎片与未裂对象一起向下做重力堆叠，堆叠后同源两半若垂直相邻则合并并变色。

**输入结构**：约 18x12 的黑(0) 背景网格。含 3~4 个 8-连通前景对象，每个对象使用一种独有的体色（从蓝(1)、绿(3)、黄(4)、橙(7) 中选取，各对象颜色互不相同）。对象为 4~8 像素的不规则连通图形（非矩形、非对称均可），bbox 为非正方形。其中 2~3 个对象内部有一条由栗(9) 像素组成的裂缝线，沿 bbox 较短轴完整贯穿（宽对象为竖线，高对象为横线）。其余对象无裂缝线。各对象在网格中垂直位置不同、互不接触，底部留有足够下落空间。生成约束：裂缝分离后产生的碎片形状保证在重力下落后，恰好有一对同源碎片能够垂直相邻（相邻指两碎片的 bbox 在垂直方向仅隔 0 行），而至少一对同源碎片因为中间夹有其他对象而无法相邻。

**规则**：
1. 对每个含栗(9) 裂缝线的对象：擦除裂缝线像素，将对象沿裂缝方向分离——裂缝左侧的体色像素向左移 1 格，右侧向右移 1 格（若裂缝为竖线）；上半向上移 1 格，下半向下移 1 格（若裂缝为横线）。无裂缝对象保持不变。
2. 对所有碎片和完整对象施加向下重力：按原始位置从下到上的顺序依次处理，每个碎片/对象保持形状和颜色向下滑动，直到触及网格底边或已就位的其他碎片/对象。
3. 重力就位后，检查每对同源碎片（同体色、来自同一原始对象的两半）：若它们的像素在垂直方向直接相邻（上半最低行紧邻下半最高行，且水平投影有重叠），则将这两个碎片的所有像素重涂为青(8)。
4. 不满足相邻条件的碎片保留原体色。

**关键洞察**：裂缝分离产出的碎片数量直接改变了重力场中的参与者集合，而重力堆叠的碰撞结果又反过来决定了哪些同源碎片能够重合——中间插入的无关对象充当阻隔，使得重合判定不可预知，必须模拟完整重力过程才能确定最终颜色。

## 新题 3：对角射线的方位涂色与障碍截断

**组合逻辑**：[标记像素](已有) → [射线延伸](已有，从正交方向扩展为四对角方向——创新) + [方位决定颜色](已有，从四邻域扩展为四对角方位) + [障碍像素 + 碰撞阻挡](已有，从正方形选择场景迁移到射线截断) + [非重叠约束→距离优先](创新：重叠时按距离源标记的步数裁决)

**来源原语**：marker_pixel / stamp_overlay / direction_color（d364b489）、ray_extend（99fa7670）、obstacle_pixel / collision_blocking / non_overlapping_constraint（31adaf00）

**依赖链**：标记位置确定射线起点 → 四对角射线向外延伸直到遇障碍或边界 → 方位决定每条射线的颜色 → 射线交叉处按距离优先裁决颜色

从每个标记像素向四个对角方向发射颜色射线，射线遇障碍或边界截断，交叉处由距源标记更近的射线胜出。

**输入结构**：约 15x15 的黑(0) 背景网格。含 2~3 个蓝(1) 标记像素，分布在网格不同区域。含 5~10 个灰(5) 障碍像素，散布在网格中（不与标记像素在同一对角线上紧邻）。标记像素之间的间距 >= 4，保证部分对角射线会相交但不会在源点处重叠。生成约束：至少存在两条来自不同标记的对角射线在某个空白格子相交，以确保距离优先规则被触发。

**规则**：
1. 保留所有蓝(1) 标记像素和灰(5) 障碍像素不变。
2. 从每个蓝(1) 标记出发，沿四个对角方向（右上、左上、右下、左下）逐步延伸射线（每步行列各变化 1）。射线在遇到障碍像素、标记像素或网格边界时停止（不包含终点）。
3. 每条射线的颜色由方位决定：右上方向涂红(2)，左上方向涂黄(4)，右下方向涂绿(3)，左下方向涂橙(7)。
4. 若两条来自不同标记的射线覆盖同一格子，保留距其源标记曼哈顿步数更小的那条射线的颜色。步数相同时，保留行号更小的源标记发出的射线颜色。
5. 同一标记的不同方向射线不会重叠（对角方向互不交叉）。

**关键洞察**：方位涂色在源题中仅作用于标记的四邻域（固定 1 步），这里扩展为不定长对角射线，使得障碍的位置决定了射线长度，而射线交叉处的颜色归属需要回溯计算每条射线到源标记的距离——几何延伸和距离优先两个逻辑缺一不可。

## 新题 4：标签条件驱动的模板差异化修复

**组合逻辑**：[分隔线 + 阵列排布 + 模板](已有) + [行标签 + 列标签 + 标签同色时填充](已有，从等式表场景迁移到模板修复的条件判断) → [补全](已有，但修复方式由标签匹配结果分支决定——创新) + [重涂色](已有)

**来源原语**：divider_line / array_layout / template / completion / missing_filled_with_divider_color（1e32b0e9）、row_label / column_label / labels_match_fill（a406ac07）、recolor（多题共有）

**依赖链**：格栅解析 + 标签读取同步进行 → 标签配对判断每个单元的修复模式 → 匹配时用模板图案修复并重涂为标签色，不匹配时填充分隔色

将被局部擦除的模板阵列按行列标签是否同色分两种方式修复：同色时恢复模板图案并染为标签色，异色时以分隔色填平。

**输入结构**：约 17x17 的网格，灰(5) 分隔线（完整行和完整列）将其切分为 3x3 的方形单元阵列，每个单元约 5x5。网格右侧紧邻一列标签列（3 个像素，每个对应一个单元行，颜色从红(2)、蓝(1)、绿(3) 中选取），网格底部紧邻一行标签行（3 个像素，每个对应一个单元列，颜色同样从上述三色中选取）。左上角单元包含完整的模板图案（由黑(0) 背景和一种前景色黄(4) 构成的 3~5 像素 4-连通图形）。其余 8 个单元中，部分像素被替换为黑(0)（模拟缺失），但至少保留 1 个黄(4) 像素以暗示原始图案存在。生成约束：标签行和标签列中至少有一对同色匹配和一对异色匹配，以确保两种修复模式都出现。

**规则**：
1. 识别灰(5) 分隔线，切分出 3x3 单元阵列和边缘标签。
2. 以左上角单元为模板。对于阵列中 (r, c) 位置的每个非模板单元：
   a. 读取行标签（右侧列第 r 个像素的颜色）和列标签（底部行第 c 个像素的颜色）。
   b. 若行标签与列标签颜色相同：将该单元中所有缺失位置（当前为黑(0) 但模板对应位置为黄(4) 的格子）恢复为前景，但颜色不用黄(4)，而用该匹配的标签颜色重涂。已有的黄(4) 像素也重涂为标签色。
   c. 若行标签与列标签颜色不同：将该单元中所有缺失位置填充为灰(5)（分隔色），已有的黄(4) 像素保持不变。
3. 模板单元本身不做任何改动。标签行列不做改动。

**关键洞察**：模板补全在源题中是无条件的（所有单元统一用分隔色填充缺失），这里引入行列标签匹配作为分支条件——同一个模板在不同单元中以不同颜色或不同方式修复。仅看单个示例无法确定标签匹配规则，必须对比多个示例中同位置单元在不同标签配色下的表现才能归纳出分支逻辑。

## 新题 5：嵌入/孤立分类控制镜像轴与修复

**组合逻辑**：[嵌入与孤立分类](已有) → [修补](已有，嵌入标记→修复) + [计数→奇偶判定](创新：孤立标记的数量编码镜像方向) → [镜像 + 对侧放置 + 颜色按方位定](已有，但轴选择由计数决定而非凸耳位置)

**来源原语**：embedded_vs_isolated / repair / edge_line / edge_indicates_direction（8886d717）、mirror / opposite_place / tab_determines_axis / color_by_orient（dc2e9a9d）、outline（dc2e9a9d）

**依赖链**：分类嵌入/孤立标记 → 嵌入标记修复为轮廓色 → 孤立标记计数 → 奇偶性决定镜像轴 → 按轴镜像并按方位涂色

修复轮廓中的嵌入缺陷，然后统计内部孤立标记数量，奇数时水平镜像（涂蓝），偶数时垂直镜像（涂青），在对侧生成副本。

**输入结构**：约 16x16 的黑(0) 背景网格。含 2~3 个绿(3) 轮廓对象（每个为 4-连通的单像素厚空心环形，围成的内部区域约 3x3~5x5，形状各异——可以是矩形环、不规则多边形环等）。每个轮廓内部和轮廓像素上散布若干红(2) 标记像素：嵌入标记位于轮廓像素位置（该位置本应为绿(3)，被替换为红(2)，其 4-邻域中有 >= 2 个绿(3) 像素），孤立标记位于轮廓内部的黑(0) 区域中（4-邻域中绿(3) 像素 <= 1 个）。每个轮廓内部的孤立标记数量为 1~4 个。生成约束：不同轮廓的孤立标记数量奇偶性不全相同（至少一个奇数、一个偶数），以确保两种镜像方向都出现。各轮廓之间间距 >= 3，镜像副本不会与任何原有对象重叠。

**规则**：
1. 对每个绿(3) 轮廓对象，识别其中所有红(2) 标记像素，分类为嵌入或孤立：
   - 嵌入：该红(2) 像素的 4-邻域中绿(3) 像素 >= 2 个。
   - 孤立：该红(2) 像素的 4-邻域中绿(3) 像素 <= 1 个。
2. 将所有嵌入标记重涂为绿(3)（修复轮廓缺陷）。孤立标记保留红(2) 不变。
3. 统计每个轮廓内部的孤立标记数量 N。
4. 若 N 为奇数：将修复后的轮廓（含内部孤立标记）水平镜像，副本放置在原轮廓 bbox 左侧（若原轮廓偏右）或右侧（若原轮廓偏左），间隔 1 列，副本涂蓝(1)（副本中孤立标记也变蓝）。
5. 若 N 为偶数：将修复后的轮廓垂直镜像，副本放置在原轮廓 bbox 上方（若原轮廓偏下）或下方（若原轮廓偏上），间隔 1 行，副本涂青(8)（副本中孤立标记也变青）。
6. "偏左/偏右/偏上/偏下"以轮廓 bbox 中心与网格中心的相对位置判定。
7. 镜像副本超出网格边界的部分裁剪丢弃。

**关键洞察**：嵌入/孤立分类在源题中只决定"修复还是延伸"，这里孤立标记的数量进一步编码了镜像方向——必须先完成分类和修复，才能正确计数，计数结果又决定了完全不同的空间变换。仅看单个示例可能无法区分奇偶规则，需要对比多个轮廓的不同行为才能归纳。

**依赖链**：连接杆长度和方向决定矩形体滑移量 → 矩形体就位后成为对角填充的边界约束 → 平行对角线段配对后在段间填充 → 填充区域被矩形体遮挡截断

**规则**：
1. 识别每个蓝(1) 连通对象，将其分解为最大矩形体和连接杆（杆为单像素宽的直线段）。
2. 擦除整个蓝(1) 对象（矩形体 + 连接杆）。
3. 将矩形体沿连接杆方向平移，距离等于连接杆长度（像素数），使矩形体的一侧紧邻最近的绿(3) 对角线段。
4. 将滑移后的矩形体以蓝(1) 重新绘制在新位置。
5. 对绿(3) 对角线段做平行配对：反对角线方向相同（斜率相同）且在主对角线轴（r-c）上相邻的两段为一对。

7. 填充时，已被蓝(1) 矩形体占据的格子不被覆盖（矩形体充当遮挡）。

**关键洞察**：连接杆滑移在源题中将矩形体送到锚定物旁，但这里"锚定物"不再是另一个矩形，而是对角线段——滑移的终点位置决定了矩形体作为遮挡物时截断多少填充区域。如果不先执行滑移就无法知道填充的实际形状，两步操作通过空间位置紧密耦合。

## 新题 7：贪心正方形选择与控制行颜色分配

**组合逻辑**：[控制行 + 标记像素](已有) + [贪心选择 + 空白正方形区域 + 最小边长约束 + 非重叠约束 + 从大到小优先](已有) → [填充](已有) + [颜色数决定尺寸→选择数反向驱动颜色循环](创新：选出的正方形数量决定如何使用控制行的颜色序列)

**来源原语**：control_row / marker_pixel / marker_is_shift（79cce52d）、greedy_selection / blank_square_region / obstacle_pixel / minimum_side_length_constraint / non_overlapping_constraint / largest_first_priority（31adaf00）、fill / color_count_size（feca6190）

**依赖链**：控制行提供颜色序列 → 主区域贪心选择正方形 → 选择数量 K 决定从颜色序列取前 K 色 → 按边长排序分配颜色（最大方块取第一色，依次类推） → K 超过序列长度时循环复用

在障碍网格中贪心选取最大非重叠黑色正方形，用顶部控制行的颜色序列按面积从大到小逐个上色。

**输入结构**：约 14x14 的网格。顶部第 0 行为控制行：黑(0) 背景上有 2~4 个彩色标记像素（颜色从红(2)、蓝(1)、绿(3)、黄(4) 中选取，互不相同），按列从左到右排列。第 1 行起为主区域：黑(0) 背景上散布灰(5) 障碍像素。主区域中存在若干全黑正方形口袋（边长 >= 2），部分口袋相互重叠。生成约束：贪心选择后得到的非重叠正方形数量 K >= 3，且 K 大于控制行的标记数量 M，使得颜色循环至少发生一次。

**规则**：
1. 读取控制行（第 0 行）中所有非黑(0) 像素，按列坐标从左到右排列，得到颜色序列 S = [s_0, s_1, ..., s_{M-1}]。
2. 在主区域（第 1 行及以下）中，搜索所有内部全为黑(0) 的正方形候选区域（边长 >= 2）。
3. 按边长从大到小排序。依次选择：若该候选区域不与已选中的任何正方形重叠，则选中。边长相同的候选区域按左上角行优先、列次优先的顺序处理。
4. 设最终选中 K 个正方形。将它们按边长从大到小排列（边长相同时保持选中顺序），第 i 个正方形（i 从 0 开始）填充颜色为 S[i mod M]。
5. 控制行在输出中移除（输出仅含主区域）。

**关键洞察**：控制行在源题中编码位移量（一个标量），这里编码的是颜色序列（一个向量），而贪心选择在源题中只做蓝色填充（固定颜色），这里由选择结果的数量驱动颜色循环——两个独立逻辑通过"数量"这个中间量耦合。需要多个示例才能归纳出循环复用规则。

## 新题 9：障碍截断的转折路径与行列扩展交叉

**组合逻辑**：[射线延伸 + 转折至下一标记行](已有) + [障碍像素 + 碰撞阻挡](已有，从正方形选择迁移到路径截断——创新) + [标记展为整行整列 + 行列交叉](已有，但只在路径终点处触发——创新)

**来源原语**：ray_extend / turning_path_to_next_marker_row / isolated_pixel / canvas_boundary（99fa7670）、obstacle_pixel / collision_blocking（31adaf00）、marker_to_row_col / row_col_cross / draw_line（8731374e）

**依赖链**：标记像素发射转折路径 → 障碍截断路径使其提前终止 → 终止点触发行列扩展（整行整列涂色） → 扩展线在交叉处产生新颜色

标记像素向右延伸并转折向下的路径被障碍截断后，在截断点处触发整行整列的扩展线，扩展线的交叉点涂以特殊颜色。

**输入结构**：约 15x15 的黑(0) 背景网格。含 2~3 个彩色标记像素（颜色互不相同，从红(2)、绿(3)、橙(7) 中选取），每个位于不同行，每行至多一个标记。含 6~10 个灰(5) 障碍像素，散布在网格中。生成约束：每个标记的右延路径上至少有一个障碍或者下延路径上至少有一个障碍，使得至少有一条路径被截断而非到达网格边界。至少两个标记的截断点所在行或列有重合，以产生扩展线交叉。

**规则**：
1. 按行从上到下排列标记像素。
2. 对每个标记，从其位置向右画水平线（标记颜色），逐格延伸直到遇到灰(5) 障碍像素或网格右边界（不含障碍格本身），记录水平线终点 H。
3. 从 H 向下画垂直线（同色），逐格延伸直到遇到灰(5) 障碍像素、到达下一个标记所在行的前一行、或到达网格底边（不含障碍格本身），记录垂直线终点 V。
4. 若水平线被障碍截断（H 不在网格右边界），则在 H 所在位置触发列扩展：将 H 所在列的所有黑(0) 格子涂为该标记颜色（已有颜色的格子不覆盖）。
5. 若垂直线被障碍截断（V 不在网格底边且不在下一标记行的前一行），则在 V 所在位置触发行扩展：将 V 所在行的所有黑(0) 格子涂为该标记颜色（已有颜色的格子不覆盖）。
6. 两条不同颜色的扩展线交叉的格子，涂为黄(4)（无论原来两条线是什么颜色）。
7. 障碍像素保持灰(5) 不变。标记像素保持原色不变。

**关键洞察**：转折路径在源题中总是到达网格边界，这里障碍的存在使路径可能在任意位置截断，而截断本身是一个信号——只有被截断的路径才触发行列扩展。扩展线的交叉产生第三种颜色，这一涌现效果在任何单一源题中都不存在。需要多个示例才能归纳出"截断触发扩展"和"交叉变色"两条隐蔽规则。

## 新题 10：裂缝方向引导的稀疏标记线反射

**组合逻辑**：[裂缝标记线 + 沿短轴分裂](已有，但分裂后不分离，而是确定反射轴——创新) → [稀疏标记线 + 平行对称轴 + 跨标记线反射](已有，但反射轴由裂缝方向决定而非预置) → [重涂色 + 擦除](已有)

**来源原语**：fracture_line / split_along_short（2faf500b）、sparse_marker_line / parallel_axes / reflect_across_markers / foreground_motif（66ac4c3b）、recolor / erase（多题共有）

**依赖链**：裂缝线的方向（水平/垂直）确定反射轴取向 → 裂缝线本身充当稀疏标记线的一条 → 前景图案跨裂缝线反射 → 反射副本重涂色 → 裂缝线擦除

每个对象的裂缝线既标示分裂方向又充当反射轴，对象的前景图案跨裂缝反射并重涂色后，裂缝线被擦除。

**输入结构**：约 16x16 的黑(0) 背景网格。含 2~3 个互不相邻的前景对象，每个对象由体色像素（从蓝(1)、绿(3)、橙(7) 中选取，各对象颜色不同）构成一个不对称的 4-连通图形（5~10 像素，bbox 为非正方形矩形）。每个对象中有一条栗(9) 裂缝线沿 bbox 较短轴完整贯穿。体色像素全部位于裂缝线的一侧（另一侧为空）。另外，网格中有一条与裂缝线平行的稀疏标记行或列（同样为栗(9) 像素，但非连续，仅在与裂缝线对应的位置有像素），位于对象 bbox 外部、与裂缝线平行且间距 1~3 行/列。生成约束：反射后的副本不超出网格边界，不与其他对象重叠。不同对象的裂缝方向可以不同（有的水平、有的垂直）。

**规则**：
1. 对每个前景对象：
   a. 识别其中的栗(9) 裂缝线，判断方向（水平/垂直）。
   b. 找到与该裂缝线平行的、位于对象 bbox 外部的栗(9) 稀疏标记行或列。
   c. 裂缝线和稀疏标记线构成一对平行轴。将裂缝线一侧的体色像素跨这对平行轴反射到另一侧。
   d. 反射的具体计算：对于体色像素 P，计算 P 到裂缝线的距离 d，反射位置在稀疏标记线的另一侧、距稀疏标记线 d 的位置。
   e. 反射副本重涂为该对象体色对应的变换色：蓝(1)→红(2)，绿(3)→黄(4)，橙(7)→品红(6)。
2. 擦除所有栗(9) 像素（裂缝线和稀疏标记线均移除）。
3. 原始体色像素保持不变。

**关键洞察**：裂缝线在源题中仅用于分裂对象，这里它同时充当反射轴的一条——裂缝方向决定了反射是水平还是垂直，而裂缝与外部稀疏标记线的配对决定了反射的锚点。必须同时理解裂缝的双重角色（方向编码 + 反射轴）和颜色映射规则才能求解。
