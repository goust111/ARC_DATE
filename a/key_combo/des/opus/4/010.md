## 新题 1：对称遮挡层序推断

**组合逻辑**：[对称补全](创新：从形状对称性推断层序，而非从标记矩形恢复) + [透明叠加](创新：反向运用——从叠加结果拆解出被遮挡层) + [擦除](已有) → [裁剪](已有)

**来源原语**：对称补全(67b4a34d)、透明叠加(281123b4)、图层优先级(281123b4)、遮挡由镜像恢复(67b4a34d)、裁剪(67b4a34d/f2829549)、擦除(d5d6de2d)

**依赖链**：需先通过对称性检测判断哪个形状是前层（可见像素已对称 → 无遮挡 → 在前），才能确定后层形状的缺失像素位置；缺失像素位置确定后才能用对称反射恢复；恢复后才能擦除前层并裁剪输出。层序推断、对称恢复、擦除裁剪三步环环相扣。

将两个部分重叠的左右对称形状拆解，输出被遮挡的后层形状的完整重建（裁剪至边界框）。

**输入结构**：约 14x14 的黑(0)背景网格。两个不同颜色的前景形状（如红(2)和蓝(1)），每个形状为 4-连通区域，像素数各约 8-15。两形状部分重叠，重叠区域仅显示前层颜色。每个形状若单独存在则关于其边界框的垂直中轴具有左右镜像对称性。前层形状的可见像素恰好完整且左右对称；后层形状的可见像素因被前层遮挡而呈现不对称（缺失若干像素）。两形状的颜色均不为黑(0)且互不相同。生成约束：两形状的对称轴互不重合；重叠区域连通且至少包含 2 个像素；后层形状被遮挡的像素全部可通过其自身的左右对称反射从可见像素恢复。

**规则**：
1. 识别网格中两种非背景颜色，分别收集各自的可见像素集合。
2. 对每种颜色，计算其可见像素集合的边界框，取边界框水平中线作为候选垂直对称轴。检验该颜色的可见像素是否关于此轴严格左右对称。
3. 可见像素已左右对称的颜色为前层形状（未被遮挡）；可见像素不对称的颜色为后层形状（部分被遮挡）。
4. 对后层形状，逐一检查其对称轴另一侧对应位置：若对应位置被前层颜色占据（即该处显示前层颜色），则该位置实际属于后层形状的被遮挡像素。将这些位置标记为后层颜色。
5. 输出：在与输入同尺寸的黑色画布上，绘制后层形状的所有像素（可见 + 恢复），然后裁剪到该形状的边界框。

**关键洞察**：前层形状的"完整对称性"本身就是判断层序的证据——对称性完好说明无遮挡、因此在前。这一推断方式与参考题中使用标记矩形或循环序来确定层序完全不同。求解者必须先做对称性检测才能知道哪些像素属于后层，形成推断-恢复的紧耦合。

## 新题 2：周期墙壁修复与腔室填充

**组合逻辑**：[周期推断](创新：从推断壁纸图案改为推断墙壁拓扑) + [间隙填充](创新：填充对象从颜色像素变为结构性墙壁) → [洪泛填充](已有)

**来源原语**：周期推断(1d0a4b61)、间隙填充(1d0a4b61)、忽略缺失值推断(1d0a4b61)、洪泛填充(e69241bd)、墙壁(e69241bd)、标记像素(e69241bd)、封闭区域(e69241bd)、标记色填充区域(e69241bd)

**依赖链**：周期推断确定完整墙壁结构 → 墙壁修复改变网格拓扑（分离原本相连的区域）→ 新的封闭腔室决定洪泛填充的范围和标记归属。若跳过周期推断，腔室通过缺口相连，标记与腔室的对应关系错乱，填充结果完全不同。

根据可见墙壁像素推断周期性墙壁图案、修复缺失墙段，然后用每个封闭腔室内唯一标记的颜色洪泛填充该腔室。

**输入结构**：约 20x20 的黑(0)背景网格。灰(5)像素构成墙壁，墙壁整体具有周期性平铺结构（最小重复瓦片约 4x4 至 6x6），但其中若干墙壁像素被替换为黑(0)（缺失）。缺失导致部分本应隔开的腔室通过缺口相连。在若干腔室内各有一个非黑(0)非灰(5)的彩色标记像素（如红(2)、蓝(1)、绿(3)等），颜色各不相同。生成约束：最小重复瓦片唯一；每个缺失的墙壁像素均可通过周期推断唯一恢复；墙壁完整修复后，每个包含标记的腔室恰好含一个标记；至少有两个腔室因墙壁缺失而在修复前错误地相连。

**规则**：
1. 将黑(0)视为缺失数据，灰(5)视为已知墙壁。在忽略黑(0)像素的前提下，推断使所有灰(5)像素位置一致的最小面积周期瓦片。
2. 用推断出的瓦片填补所有缺失位置：若瓦片在该位置指示墙壁，则将黑(0)替换为灰(5)。
3. 以灰(5)像素为障碍，识别所有 4-连通的非墙壁区域（腔室）。
4. 对每个腔室：若其中包含恰好一个标记像素，将该腔室内所有非标记的黑(0)像素重涂为该标记的颜色。若腔室无标记，保持黑(0)不变。
5. 输出包含灰(5)墙壁、已填充腔室和未填充腔室的完整网格。

**关键洞察**：墙壁的周期性是隐藏信息——输入中看不到完整图案，求解者必须从残缺的灰色像素中推断出瓦片。修复墙壁不是装饰性的，而是拓扑性的：它改变了哪些区域相连，从而决定标记归属于哪个腔室。

## 新题 3：面积排序决定镜像配对

**组合逻辑**：[面积分类](创新：从决定颜色改为决定空间配对) + [排序](已有) → [镜像](创新：反射目标由最近邻改为面积排名配对) + [擦除](已有)

**来源原语**：面积分类(d2abd087)、排序(1bfc4729)、面积决定颜色(d2abd087→创新为面积决定配对)、镜像(6855a6e4)、空心矩形(6855a6e4/d5d6de2d)、精灵体(6855a6e4)、最近邻归属(6855a6e4→创新为面积归属)、跨框中线反射入内(6855a6e4)、擦除(d5d6de2d)

**依赖链**：面积计算 → 排序产生配对关系 → 配对决定每个精灵体反射进哪个框架 → 框架的中线决定反射轴。若跳过面积排序，精灵体与框架的配对关系未知；若跳过镜像，无法确定精灵体在框架内的位置。

按面积从大到小将精灵体与空心框架配对，然后将每个精灵体反射进其配对框架的内部。

**输入结构**：约 20x20 的黑(0)背景网格。左半区域纵向排列 3-4 个灰(5)的 4-连通精灵体（不规则形状，像素数各不相同，范围 3-10 像素），精灵体之间至少间隔 2 行。右半区域纵向排列相同数量的红(2)空心矩形框架（1 像素宽边框），各框架的内部面积互不相同。精灵体数等于框架数。每个精灵体的像素数严格小于其将配对的框架内部面积（宽-2）x（高-2）。生成约束：各精灵体像素数互不相同；各框架内部面积互不相同；精灵体按像素数排序后与框架按内部面积排序后的配对是唯一的；每个精灵体的像素分布可以完整放入其配对框架的内部区域。

**规则**：
1. 计算每个灰色精灵体的像素数（面积）和每个红色框架的内部面积（(宽-2)x(高-2)）。
2. 将精灵体按像素数从大到小排列，框架按内部面积从大到小排列。第 k 大的精灵体配对第 k 大的框架。
3. 对每个配对，将精灵体水平反射（沿其配对框架的垂直中线翻转）到框架内部。具体地：精灵体的每个像素 (r, c) 映射到 (r', c')，其中 r' = r（行不变），c' = 框架垂直中线 x 2 - c（水平镜像）。反射后的像素绘制在框架内部，颜色为蓝(1)。
4. 擦除所有原始灰色精灵体（替换为黑(0)）。保留红色框架边框。
5. 输出完整网格。

**关键洞察**：配对规则不是空间邻近（最近的精灵体配最近的框架），而是面积排名匹配。一个紧挨小框架的大精灵体实际上要反射进远处的大框架里。求解者必须对比多个示例才能排除邻近假设、发现面积排名规则。

## 新题 4：折叠封闭再填充

**组合逻辑**：[折叠](创新：折叠目的从改变形状变为创造拓扑封闭) + [填充](创新：填充区域由折叠操作涌现) + [描边](已有，部分边框预置)

**来源原语**：折叠(230f2e48)、直线杆(230f2e48)、铰接标记(230f2e48)、端点标记(230f2e48)、固定端与活动端(230f2e48)、空间大侧折入(230f2e48)、填充(d5d6de2d/4a1cacc2)、封闭区域(d5d6de2d/e69241bd)、边框(1bfc4729)、边框包围内部(d5d6de2d)

**依赖链**：端点标记确定固定端 → 铰接标记确定折叠位置 → 折叠方向由空间判断 → 折叠后杆段与预置边框共同围成封闭区域 → 封闭区域被填充。折叠不发生则无封闭区域，填充无从谈起；去掉预置边框则折叠后仍无封闭，三者缺一不可。

将带铰链的彩色直线杆折叠后与灰色预置边框段合围成封闭矩形区域，再用杆的颜色填充该区域内部。

**输入结构**：约 16x16 的黑(0)背景网格。2-3 组独立结构，每组包含：(a) 灰(5)像素构成的三面矩形边框（U 形，缺少一条完整边，宽度 1 像素）；(b) 一条与 U 形缺口相邻的直线杆（水平或垂直的单色前景线段，颜色各组不同，从{蓝(1)、红(2)、绿(3)、黄(4)}中选取），长度等于 U 形缺口的长度加上一段延伸；杆内有一个黑(0)铰接标记像素和一个品红(6)端点标记像素。端点标记位于杆的一端，铰接标记位于杆的中间某处。各组结构间互不相邻（间隔至少 2 像素）。生成约束：每条杆的自由尾段（铰接标记到非端点标记那端的线段，不含铰接标记）的长度恰好等于 U 形缺口的长度；折叠方向（朝向网格边缘更远的一侧）使自由尾段恰好落在缺口位置。

**规则**：
1. 对每条杆，识别品红(6)端点标记和黑(0)铰接标记。从端点标记到铰接标记的线段为固定段，保持不动。
2. 从铰接标记到杆另一端的线段为自由尾段（不含铰接标记本身的杆色像素）。
3. 将自由尾段绕铰接标记旋转 90 度。旋转方向：选择铰接标记到网格边缘距离更大的那一侧（即朝向空间更大的方向）。
4. 旋转后的尾段像素用杆的颜色绘制在新位置。原始尾段位置清除为黑(0)。
5. 折叠后，检查每组中灰色边框段与杆色像素（固定段 + 旋转后尾段）是否共同围成一个封闭矩形区域。若是，将该矩形内部的所有黑(0)像素填充为杆的颜色。
6. 铰接标记位置保持黑(0)。灰色边框保持灰(5)。品红端点标记保持品红(6)。

**关键洞察**：折叠操作的目的不是改变杆的外观，而是创造一个之前不存在的封闭边界。填充操作依赖折叠的几何结果——这是一种涌现效应：折叠和边框单独都不构成封闭区域，组合后才产生可填充的空间。

## 新题 5：跨面板颜色频率分类重涂

**组合逻辑**：[计数](创新：从单区域频率改为跨面板出现次数统计) + [频率匹配](创新：匹配目标从标记数改为面板总数) + [重涂色](已有) + [擦除](已有)

**来源原语**：计数(2685904e/d2abd087)、频率匹配(2685904e)、重涂色(d2abd087/aabf363d)、擦除(d5d6de2d/aabf363d)、面板(281123b4)、分隔列(281123b4/f2829549)、连通分量(d2abd087)、面积决定颜色(d2abd087→创新为频率决定颜色)

**依赖链**：跨面板频率统计 → 频率值分类 → 分类结果决定重涂色/擦除操作。若跳过跨面板统计，无法确定哪些颜色应被保留、哪些应被擦除。

统计每种前景色在三个面板中出现的面板数，按出现面板数将对象重涂为红或蓝，或擦除。

**输入结构**：约 12x30 的黑(0)背景网格，被两条灰(5)全高分隔列分成三个等宽面板（每个约 12x9）。每个面板包含 3-5 个 4-连通前景对象，使用的前景色从{绿(3)、黄(4)、橙(7)、青(8)、栗(9)}中选取。同一面板内不同对象可以同色或异色。同一颜色可能出现在 1 个、2 个或全部 3 个面板中。生成约束：至少一种颜色仅出现在 1 个面板中（面板频率=1），至少一种颜色出现在全部 3 个面板中（面板频率=3），至少一种颜色出现在恰好 2 个面板中（面板频率=2）。面板中的对象大小为 3-8 像素，形状不规则，互不相邻。

**规则**：
1. 对每种非背景、非灰色的前景色 c，统计它在几个面板中出现（面板频率）。一种颜色在某面板中"出现"意味着该面板中至少有一个像素为 c。
2. 面板频率 = 1 的颜色（仅在一个面板出现）：将该颜色的所有对象重涂为红(2)。
3. 面板频率 = 3 的颜色（在全部三个面板出现）：将该颜色的所有对象重涂为蓝(1)。
4. 面板频率 = 2 的颜色（在恰好两个面板出现）：将该颜色的所有对象擦除为黑(0)。
5. 灰色分隔列保持不变。输出与输入同尺寸。

**关键洞察**：重涂色规则取决于全局属性（一种颜色在多少个面板中出现），而非局部属性（对象的面积、形状或位置）。单看一个面板无法确定任何对象的命运——必须横向比较所有三个面板才能归纳出频率分类规则。面板频率=2时的"擦除"尤其反直觉（出现两次反而被删除），需要多个示例才能发现。

## 新题 6：对称补全驱动的图例分层扩展

**组合逻辑**：[对称补全](创新：补全对象从被遮挡区域变为散布点集) + [扩展](已有) → [填充](已有) + [图层优先级](创新：优先级来源从面板位置改为图例行序)

**来源原语**：对称补全(67b4a34d)、双轴镜像对称(67b4a34d)、扩展(305b1341)、散布点(305b1341)、图例(305b1341)、图例配色(305b1341)、图例顺序决定层级(305b1341)、冲突优先级(305b1341)、填充(305b1341/4a1cacc2)

**依赖链**：对称补全改变点集 → 点集改变边界框 → 边界框改变扩展区域 → 扩展区域间的重叠需要图例层序来解决。若跳过对称补全，边界框错误，扩展范围偏小；若忽略图例层序，重叠区域颜色不确定。

先对每组散布点做垂直对称补全恢复缺失点，再按图例将每组点的扩展边界框填充为配对颜色，重叠处以图例行序决定前后。

**输入结构**：约 18x18 的黑(0)背景网格。列 0-1 从第 0 行开始为两列图例：每行左格为源色、右格为填充色（图例行数 2-4 行，图例以下行的列 0-1 为黑色）。图例使用的颜色从{蓝(1)、红(2)、绿(3)、黄(4)、橙(7)、青(8)、栗(9)}中选取，源色与填充色互不相同，各源色互不相同。在图例区域之外（列 2 及以后），每种源色有 4-7 个散布像素点。每种源色的完整点集本应关于其边界框的垂直中轴左右对称，但有 1-2 个点被移除（缺失）。生成约束：每种源色至少保留 3 个可见点，足以确定对称轴；补全后至少两种源色的扩展边界框（向四周各扩 1 像素）互相重叠；图例中每个源色的填充色互不相同。

**规则**：
1. 读取图例：从第 0 行开始，每行 (列0, 列1) 构成一对（源色, 填充色），直到遇到列 0 为黑(0)的行为止。
2. 对每种源色，收集图例区域外的所有该色像素。计算这些像素的边界框，取边界框水平中线作为垂直对称轴。
3. 对每个可见像素，检查其关于对称轴的镜像位置：若镜像位置为黑(0)且在网格范围内，则在该位置补画一个同色像素（恢复缺失点）。
4. 重新计算每种源色的边界框（含补全后的所有点），向四个方向各扩展 1 像素（不超出网格边界）。
5. 按图例行序从最后一行到第一行依次处理：对当前源色，将其扩展边界框内所有黑(0)像素填充为对应的填充色。保留所有已存在的源色像素和更高优先级的填充色像素不被覆盖。
6. 图例区域（列 0-1 的图例行）在输出中清除为黑(0)。

**关键洞察**：缺失点的补全不是装饰性的——它可能在对称轴远端增加新点，从而扩大边界框，改变扩展填充区域的范围。图例的行序是层叠优先级（第一行最高），但此规则在无重叠时无法观察到，只有当扩展区域交叉时才显现，需要对比含重叠和不含重叠的示例才能归纳。

## 新题 7：双面板对称恢复后求交集

**组合逻辑**：[对称补全](已有) × 2（并行在两个面板上执行） → [逻辑运算](创新：从双空交集改为双实交集) + [裁剪](已有)

**来源原语**：对称补全(67b4a34d)、遮挡由镜像恢复(67b4a34d)、实心标记矩形(67b4a34d)、逻辑运算(f2829549)、逐格比较(f2829549)、双空交集涂色(f2829549→创新为双实交集涂色)、裁剪(67b4a34d/f2829549)、分隔列(f2829549/281123b4)、等宽面板(f2829549)

**依赖链**：每个面板的对称恢复独立进行，但两者的恢复结果共同决定交集输出。面板 A 中被标记遮挡的前景像素可能恰好在面板 B 的对应位置也是前景——若不恢复，交集结果在该位置为"非前景"，输出错误。两个恢复操作和交集运算三者缺一不可。

两个面板各有被标记矩形遮挡的对称图案，分别恢复后求逐格前景交集，输出交集区域。

**输入结构**：约 12x25 的黑(0)背景网格。一条灰(5)全高分隔列将网格分为两个等宽面板（每个约 12x12）。每个面板内有一种前景色的图案（面板 A 用蓝(1)，面板 B 用红(2)），图案关于面板自身的垂直中轴左右对称。每个面板内另有一个实心标记矩形（面板 A 用黄(4)，面板 B 用橙(7)），该矩形覆盖了部分前景图案像素。标记颜色仅出现为该实心矩形，不出现在图案中。生成约束：每个面板的标记矩形不跨越面板的对称轴；标记矩形至少覆盖 2 个前景像素；两个面板恢复后的前景图案有非空交集（至少 4 个位置在两个面板中同时为前景）；交集区域不占满任一面板的全部前景。

**规则**：
1. 识别灰色分隔列，确定左面板和右面板的边界。
2. 对每个面板，识别其标记矩形（颜色唯一出现为实心矩形的区域）。
3. 对每个面板，确定其前景图案的垂直对称轴（面板宽度的水平中线）。
4. 对每个面板标记矩形覆盖的每个位置：在对称轴另一侧找到其镜像位置。若镜像位置为前景色，则该被覆盖位置也应为前景色（恢复）。若镜像位置也被标记覆盖，则检查两者的 180 度旋转对称位置。
5. 移除标记矩形（替换为恢复的前景色或黑(0)背景）。
6. 将两个面板按位置对齐（去除分隔列后），逐格比较：
   - 两个面板在该位置均为前景（各自恢复后的非背景像素）→ 输出绿(3)。
   - 其他情况 → 输出黑(0)。
7. 输出为单个面板尺寸的网格，仅包含绿(3)和黑(0)。

**关键洞察**：交集的正确性完全取决于两个面板各自的对称恢复是否完整。标记矩形下方的像素在一个面板中可能是前景，在另一个面板中可能是背景——如果不恢复就直接求交集，会遗漏真正的交集点或误判非交集点。两次恢复和交集运算形成"并行处理后汇合"的非线性结构。

## 新题 8：角落矩形围墙与标记洪泛

**组合逻辑**：[填充](创新：多个最近角矩形填充的叠加构成围墙) + [洪泛填充](创新：填充区域由前一步操作涌现而非预设) + [排序](创新：填充顺序影响围墙形状)

**来源原语**：填充(4a1cacc2)、孤立前景像素(4a1cacc2)、网格角(4a1cacc2)、最近角距离(4a1cacc2)、曼哈顿距离最小(4a1cacc2)、洪泛填充(e69241bd)、标记像素(e69241bd)、封闭区域(e69241bd)、标记色填充区域(e69241bd)、排序(1bfc4729)

**依赖链**：每个前景像素向最近角填充矩形 → 填充顺序决定重叠覆盖关系 → 覆盖关系决定围墙的最终形状 → 围墙形状决定标记像素所在腔室的边界 → 边界决定洪泛填充范围。五个环节链式耦合。

多个前景像素各自向最近网格角填充矩形作为围墙，然后洪泛填充围墙围出的包含标记像素的封闭区域。

**输入结构**：约 15x15 的黑(0)背景网格。3-4 个前景像素分布在网格不同位置，颜色从{蓝(1)、红(2)、绿(3)}中选取（可重复）。另有 1 个品红(6)标记像素，位于网格中央附近。生成约束：每个非标记前景像素的最近网格角是唯一的（无平局）；各像素向最近角的填充矩形按指定顺序绘制后，品红标记像素所在的黑(0)区域被这些填充矩形和网格边缘完全包围成一个封闭腔室；该腔室面积至少为 4 像素；至少两个填充矩形存在重叠。

**规则**：
1. 对每个非品红前景像素，找到曼哈顿距离最小的网格角（四角之一）。
2. 按照每个像素到其最近角的曼哈顿距离从小到大排序（距离最小的先处理）。距离相同则按行号从小到大、再按列号从小到大排序。
3. 按排序顺序依次处理：将该像素与其最近角之间的整个轴对齐矩形区域（含两端点）填充为该像素的颜色。后处理的矩形覆盖先处理的重叠区域。
4. 品红(6)标记像素在步骤 3 中不参与填充，且不会被其他矩形覆盖（生成约束保证）。
5. 将所有非黑(0)、非品红(6)的像素视为墙壁。找到品红像素所在的 4-连通黑(0)区域。
6. 将该区域内所有黑(0)像素（不含品红像素本身）重涂为品红(6)。品红标记像素保持不变。

**关键洞察**：前景像素的角落填充矩形不是目的而是手段——它们构成了围墙。标记像素被困在围墙中的哪个腔室、腔室有多大，完全取决于矩形的绘制顺序和覆盖关系。改变绘制顺序可能改变围墙形状，进而改变腔室拓扑。

## 新题 9：边界率分类重涂

**组合逻辑**：[计数](创新：计数对象从色频变为像素的拓扑属性——边界与内部) + [面积分类](创新：分类标准从绝对面积变为边界率比较) → [重涂色](已有)

**来源原语**：计数(d2abd087/2685904e)、面积分类(d2abd087)、面积决定颜色(d2abd087→创新为边界率决定颜色)、重涂色(d2abd087/aabf363d)、连通分量(d2abd087)

**依赖链**：边界像素计数 + 面积计数 → 比率比较 → 分类决定重涂色。若跳过边界计数，无法区分形状紧凑度；若跳过比率比较，无分类依据。计数和分类紧密耦合于重涂色操作。

按每个灰色对象的边界像素占比分类：边界率高（细长形）涂红，边界率低（紧凑形）涂蓝。

**输入结构**：约 14x14 的黑(0)背景网格。4-6 个灰(5)的 4-连通前景对象，分布在网格中互不相邻（任意两个对象的像素间至少间隔 1 个黑色像素）。对象形状各异：部分为紧凑形状（如 2x3 块、2x2 块加 1 像素凸出等，像素数 4-8），部分为细长形状（如 1xN 线段、L 形单像素宽折线等，像素数 4-8）。生成约束：每个对象的像素数在 4 到 12 之间；紧凑对象和细长对象各至少 2 个；不存在边界像素数恰好等于面积一半的对象（即 P = A/2 不出现）。

**规则**：
1. 识别所有灰色 4-连通分量。
2. 对每个分量，计算：
   - A = 该分量的像素总数（面积）。
   - P = 该分量中与至少一个黑(0)背景像素 4-邻接的像素数（边界像素数）。
3. 若 P > A/2（边界像素超过面积的一半，即形状细长、周长相对面积大），将该分量重涂为红(2)。
4. 若 P < A/2（边界像素不超过面积的一半，即形状紧凑），将该分量重涂为蓝(1)。
5. 输出重涂后的完整网格，背景保持黑(0)。

**关键洞察**：重涂色规则不基于形状名称或视觉直觉，而基于精确的几何量比较。一个 1x5 的线段（P=5, A=5, P>A/2）和一个 3x3 去角的块（P=4, A=8, P<A/2）看起来面积相近，但边界率截然不同。求解者必须发现边界率这个隐含量并计算其阈值。

## 新题 10：三面板投票合并与冲突消除

**组合逻辑**：[多数投票](创新：从全区域多数色改为逐格三面板投票) + [拼接](创新：从位序选择改为投票合并) + [擦除](创新：平票时消除而非选择)

**来源原语**：多数投票(27a77e38)、最频色写入中心(27a77e38→创新为逐格多数色)、拼接(5ecac7f7)、等分面板(5ecac7f7)、分隔条(5ecac7f7)、位序选择(5ecac7f7→创新为投票选择)、擦除(d5d6de2d)、逐格比较(f2829549)

**依赖链**：三面板对齐 → 逐格收集三个值 → 多数投票或平票消除 → 输出。投票规则和消除规则相互制约：需要对比含平票和不含平票的示例才能同时归纳出两条规则。若只看有多数的示例，会误以为永远选多数；看到平票消除的示例后才发现完整规则。

将三个面板逐格投票合并：有多数色时取多数，三色各异时消除为背景。

**输入结构**：约 10x32 的黑(0)背景网格，被两条灰(5)全高分隔列分成三个等大面板（每个约 10x10）。三个面板具有相同的前景区域轮廓（同一位置要么三个面板都是前景、要么都是背景），但各前景像素的颜色在三个面板间可能不同。使用的前景色从{蓝(1)、红(2)、绿(3)、黄(4)、橙(7)}中选取。生成约束：大多数前景位置至少有两个面板颜色相同（有明确多数）；至少 2 个前景位置的三个面板颜色全不相同（三方平票）；不存在"两个面板为背景、一个面板为前景"的位置（三面板轮廓一致）。

**规则**：
1. 移除灰色分隔列，将三个面板按位置对齐。
2. 对每个像素位置：
   - 若三个面板均为黑(0)，输出黑(0)。
   - 若三个面板的颜色中有一种出现至少 2 次（严格多数或全体一致），输出该多数颜色。
   - 若三个面板的颜色全不相同（三方平票），输出黑(0)（冲突消除）。
3. 输出为单个面板尺寸（10x10）的网格。

**关键洞察**：三方平票时的"消除为背景"规则极其反直觉——按常理应当保留某个面板的颜色（如中间面板或第一面板），但实际规则是全部抹去。这条规则只有在包含三方平票的示例中才可见。若训练示例中恰好没有平票出现，求解者无法确认此规则，必须从多个示例的对比中发现它。
