## 新题 1：磁吸滑动后的同色布线

**组合逻辑**：[滑动/slide](已有，作用对象从单色标记改为多色标记) → [同色配对/same_color_pairing](已有) → [连线/line_drawing](已有，端点由滑动后的位置决定，而非原始位置) + [纵线覆盖横线/vertical_over_horizontal_priority](已有)

**来源原语**：滑动、标记像素、实心方块、视线对齐、最近邻(来自 e1d2900e)；连线、同色配对、共行或共列、纵线覆盖横线(来自 070dd51e)

**依赖链**：视线检测确定每个标记的滑动方向 → 最近邻选择确定滑动终点 → 滑动改变标记位置 → 新位置决定同色对之间的连线路径 → 连线交叉时按方向优先级叠层。若不先滑动，连线路径完全不同；若不连线，滑动后的标记只是散点。

将散布的彩色标记像素沿视线磁吸到最近的 2x2 方块旁，再在落点之间按同色配对画直线段，交叉处纵线覆盖横线。

**输入结构**：
- 黑(0)背景，约 15x15 网格。
- 散布 4~6 个红(2) 2x2 实心方块，彼此不相邻（任意两块的曼哈顿距离至少 4）。
- 散布 6 个单像素彩色标记，使用 3 种颜色各 2 个：蓝(1)、绿(3)、黄(4)。每个标记恰好有一条无遮挡的水平或垂直视线通向某个 2x2 方块（即该标记所在行或列上，在它与某个方块之间没有其他前景像素）。不同标记可以指向同一个方块。
- 生成约束：每个标记滑动后落在方块外侧相邻一格处；滑动完成后，每对同色标记恰好共享一行或一列（保证可画一条轴对齐直线段连接它们）。

**规则**：
1. 对每个标记像素，沿其唯一无遮挡的水平或垂直视线方向，向最近的 2x2 方块滑动，在方块外侧相邻一格处停下。原位置清除为背景。
2. 所有标记滑动完毕后，对每对同色标记画一条直线段（含端点）：若两者同行则水平段，若同列则垂直段。线段颜色为该对标记的颜色。
3. 先画所有水平段，再画所有垂直段。因此交叉单元格保留垂直段的颜色。
4. 2x2 方块保持红(2)不变；线段不覆盖方块像素。

**关键洞察**：2x2 方块并非静态障碍，而是"磁铁"，将标记拉到自己身边后改变了同色对的几何关系，从而改变了整个布线拓扑。求解者必须先推断每个标记的落点，才能确定连线路径。

## 新题 2：括号选色擦除与幸存矩形掏空

**组合逻辑**：[角括号选色/select_same_color_by_marker](已有) → [擦除/erase](已有，作用对象从"所有同色像素"缩窄为"同色实心矩形") → [掏空/hollowing](已有，仅作用于未被擦除的矩形)

**来源原语**：擦除、角括号、标记像素、标记在括号内部、按标记色选择同色(来自 1e81d6f9)；掏空、实心矩形、边框、保留边擦除内部(来自 4347f46a)

**依赖链**：括号内标记色决定"目标色" → 目标色的矩形被整体擦除 → 非目标色的矩形被掏空（保留一像素宽边框，内部清为背景）。删掉括号选色步骤则无法区分擦除与掏空对象；删掉掏空步骤则幸存矩形无变化。

读取角括号内标记的颜色，擦除所有该色实心矩形，再将剩余矩形掏空为边框。

**输入结构**：
- 黑(0)背景，约 13x14 网格。
- 一个灰(5)单色 4-连通角括号（占 5~7 像素，形如直角弯折），其包围框内部、括号像素之外恰有一个单像素标记，颜色为蓝(1)、绿(3)或红(2)之一。
- 散布 5~7 个单色实心轴对齐矩形（每个至少 3x3），使用 3 种颜色：蓝(1)、绿(3)、红(2)。每种颜色至少出现一个矩形。矩形之间互不重叠、互不相邻。
- 角括号不与任何矩形重叠。

**规则**：
1. 读取角括号包围框内、括号像素之外的那个标记像素的颜色，记为"目标色"。
2. 将所有目标色的实心矩形整体擦除（所有像素设为黑(0)背景）。
3. 对每个非目标色的实心矩形执行掏空：保留其一像素宽的外周边框，将严格内部的所有像素设为黑(0)背景。
4. 角括号及其内部标记保持原样不变。

**关键洞察**：角括号是一个颜色分拣器——它将矩形分为两组，一组被整体消灭，另一组被掏空为空心框架。求解者必须先识别括号的选色功能，才能理解两种不同的命运。

## 新题 3：最大框架裁切与角标记编码旋转

**组合逻辑**：[面积最大选取/largest_area_select](已有) → [裁剪/crop](已有) → [角标记位置解码](创新：角标记不再框定目标区域，而是编码旋转角度) → [旋转/rotate](已有，角度由角标记位置决定而非固定)

**来源原语**：裁剪、矩形框架、标记像素、面积最大选取、最大框决定裁切(来自 fcb5c309)；旋转、整体旋转(来自 ed36ccf7)；角标记、包围框对齐(来自 a1570a43)

**依赖链**：面积比较确定最大框架 → 裁切提取内容 → 角标记的位置相对于该框架编码旋转角度 → 旋转裁切内容。删去面积选取则不知裁切哪个框架；删去角标记解码则不知旋转多少度；删去旋转则输出方向错误。

在多个矩形框架中选出面积最大者，裁切其内部内容，再根据黄色角标记相对于框架的角落位置旋转裁切结果。

**输入结构**：
- 黑(0)背景，约 18x18 网格。
- 3~4 个蓝(1)单像素厚的矩形框架（边框闭合），尺寸各不相同（最小的约 4x4，最大的约 8x8），互不重叠、互不相邻。
- 每个框架内部包含由红(2)和绿(3)像素构成的小图案（4-连通，3~8 像素），图案不触碰框架边框。非最大框架的内部图案仅作为干扰。
- 在最大框架的某一个角的外侧对角位置（与该角共对角线的相邻单元格），有一个黄(4)标记像素。其他框架没有这种角标记。
- 生成约束：最大框架的内部图案在四个旋转下互不相同（即旋转后可区分），以确保旋转结果唯一可辨。

**规则**：
1. 找到包围框面积最大的蓝(1)矩形框架（面积 = 包围框宽 x 高）。
2. 裁切该框架的内部区域（不含框架像素本身）。
3. 找到黄(4)角标记像素，确定它位于最大框架的哪个角的对角外侧：
   - 左上角外侧 → 旋转 0 度（不旋转）
   - 右上角外侧 → 逆时针旋转 90 度
   - 右下角外侧 → 旋转 180 度
   - 左下角外侧 → 逆时针旋转 270 度
4. 对裁切内容执行相应旋转。
5. 输出为旋转后的裁切区域（不含框架，不含角标记）。

**关键洞察**：黄色角标记身兼双职——它标识了哪个框架是目标（唯一拥有角标记的框架），同时它在哪个角落编码了旋转指令。求解者必须对比多个示例才能归纳出角落位置与旋转角度的映射关系。

## 新题 4：矩形掏空生墙与封闭区域按最近标记填色

**组合逻辑**：[掏空/hollowing](已有，作用对象不变但输出意义改变——边框成为洪泛填充的墙壁) → [洪泛填充/flood_fill](已有，但填色不再统一，而是由最近标记决定) + [最近邻/nearest_neighbor](已有，从标记-方块关系改为标记-区域关系)

**来源原语**：掏空、实心矩形、边框、保留边擦除内部(来自 4347f46a)；洪泛填充、封闭区域、画布边界、区域封闭、孤立背景区域填充(来自 a5313dff)；标记像素、最近邻(来自 e1d2900e)

**依赖链**：掏空将实心矩形变为边框 → 相邻或共壁的边框形成连通墙结构 → 墙结构划分出内外区域 → 从网格边界洪泛标记外部 → 无法到达边界的区域为封闭区域 → 每个封闭区域按质心到标记的曼哈顿距离分配最近标记的颜色。掏空是拓扑前提，洪泛是分区手段，标记是配色来源，三者缺一不可。

将多个相邻的实心矩形掏空为边框后，框壁围出若干封闭背景区域，每个封闭区域被染上离它质心最近的标记像素的颜色。

**输入结构**：
- 黑(0)背景，约 14x14 网格。
- 4~6 个灰(5)实心轴对齐矩形（每个至少 3x3，最大约 6x5），它们之间有些共享边缘（一个矩形的某条边与另一个矩形的某条边在同一行或同一列上相邻或重叠一段），共享的边使得掏空后的框壁形成连通的墙网络。
- 3 个单像素标记，颜色分别为红(2)、蓝(1)、绿(3)，放置在所有矩形外部的黑色背景区域中，彼此不相邻。
- 生成约束：矩形的共壁布局保证掏空后至少形成 2 个不同的封闭背景区域（即有些内部空腔被多个框的墙壁完全围住，无法通过 4-邻接背景路径到达网格边界）。不同封闭区域到 3 个标记的最近邻各不相同（保证配色无歧义）。

**规则**：
1. 对每个灰(5)实心矩形执行掏空：保留一像素宽的外边框，将严格内部像素设为黑(0)。若两个矩形共享边缘像素，该边缘保留为灰(5)。
2. 以灰(5)边框像素为墙壁，从网格四条边出发做 4-邻接洪泛标记所有可达的黑(0)像素为"外部"。
3. 剩余未标记的黑(0)像素形成若干 4-连通封闭区域。
4. 对每个封闭区域，计算该区域质心坐标（所有像素行坐标的算术平均、列坐标的算术平均，向下取整），然后求质心到三个标记像素的曼哈顿距离，选距离最小的标记。
5. 将该封闭区域的所有像素填充为最近标记的颜色。
6. 灰(5)边框像素和标记像素保持不变；外部背景保持黑(0)。

**关键洞察**：实心矩形不只是被掏空——当多个矩形共壁时，它们的边框共同构成迷宫般的墙壁网络。被围困的空腔根据自己的位置向最近的外部标记"求助"获取颜色，求解者必须先推断墙壁拓扑再判断空间归属。

## 新题 5：颜色反转瓷砖填充掏空容器

**组合逻辑**：[掏空/hollowing](已有，作用对象不变) + [颜色反转/color_invert](已有，作用对象从整个网格缩窄为小图案) → [平铺/tiling](已有，但平铺区域由掏空后的内部决定，而非固定的 2x2 复制)

**来源原语**：颜色反转、平铺、二值图案、反转后再平铺、阵列排布(来自 48131b3c)；掏空、实心矩形、边框、保留边擦除内部、内部包含(来自 4347f46a)

**依赖链**：掏空定义了需要填充的容器形状和尺寸 → 颜色反转变换了瓷砖内容 → 反转后的瓷砖按容器内部尺寸铺设并裁剪。容器形状决定铺设范围和裁剪边界，反转决定瓷砖色彩，二者在填充步骤交汇。删去掏空则无容器可填；删去反转则瓷砖颜色错误；删去平铺则容器内部空白。

将一个实心矩形掏空为边框，同时将网格上另处的小二值图案颜色反转，再用反转后的图案平铺填满边框内部。

**输入结构**：
- 黑(0)背景，约 15x15 网格。
- 一个红(2)实心轴对齐矩形，至少 6x6（保证内部空间足够铺多块瓷砖）。
- 在矩形外部（与矩形不相邻），有一个小的二值图案，由蓝(1)和黑(0)像素构成，整体大小为 2x3 或 3x2（恰好 6 个像素，其中 2~4 个为蓝(1)，其余为黑(0)）。该图案的包围框即为瓷砖模板。
- 生成约束：矩形内部的宽和高均至少为瓷砖模板宽和高的 2 倍（保证至少铺 2x2 块完整瓷砖）。

**规则**：
1. 掏空红(2)实心矩形：保留一像素宽的红(2)外边框，将严格内部所有像素设为黑(0)。
2. 对小二值图案执行颜色反转：蓝(1) → 黑(0)，黑(0) → 蓝(1)。反转后的图案即为瓷砖模板。
3. 从掏空后的内部区域左上角开始，将瓷砖模板按行优先顺序重复平铺：先向右铺满一行，再换到下一行从最左列继续。
4. 超出内部边界的部分直接截断（不绘制超出边界的像素）。
5. 红(2)边框保持不变。原始小图案的位置保持原样（即原图案不被擦除也不被改变，它既是输入的一部分也保留在输出中）。

**关键洞察**：矩形和小图案扮演完全不同的角色——一个提供容器，一个提供内容——但二者都要经过各自的变换（掏空/反转）才能组合。求解者需要对比示例才能发现小图案经历了颜色反转，因为反转后的结果在视觉上不显然。

## 新题 6：对角射线延伸与端点桥接连线

**组合逻辑**：[射线延伸/ray_cast](已有，方向和种子不变) → [连线/line_drawing](创新：端点不再是预置的标记对，而是射线到达网格边界前的最后一个像素) + [纵线覆盖横线/vertical_over_horizontal_priority](已有，应用于射线与连线的交叉)

**来源原语**：射线延伸、实心正方形、对角标记、画布边界、对角邻接、锚角对角射线至边(来自 7ddcd7ec)；连线、轴对齐线段、共行或共列(来自 070dd51e)

**规则**：
1. 保留输入中的所有红(2) 2x2 正方形及黄(4)对角标记。
2. 对每个对角标记，沿其远离正方形的对角方向，逐格绘制黄(4)像素，直到下一个像素超出网格边界为止。记录每条射线的最后一个像素位置（"终点"）。

5. 红(2)正方形像素不被任何射线或线段覆盖。

**关键洞察**：对角标记不仅发射射线——射线的落点（打在网格边界上的位置）成为一条桥接线的锚点。求解者必须先追踪两条发散的对角射线到达边界的位置，才能知道桥接线画在哪里。

**输入结构**：
- 约 24x8 的网格，由 3 个等宽面板（每个约 8 列宽、8 行高）通过共享纵边框排列组成。
- 面板边框颜色为灰(5)（一像素宽），面板内部填充色为黑(0)。
- 每个面板内部有一个相同形状的 2x2 小精灵，精灵在同一列位置（各面板中列偏移一致），但行位置逐面板匀速变化（例如第 1 面板的精灵顶行在第 2 行，第 2 面板在第 4 行，第 3 面板在第 6 行，行增量为 2）。
- 精灵颜色在 3 个面板中各不相同，且遵循一个可辨别的循环序列（例如红(2) → 绿(3) → 蓝(1)）。该序列需要对比 3 个面板才能归纳。

**规则**：
1. 识别面板分割：等宽面板由共享的灰(5)纵边框分隔。
2. 在各面板中定位精灵，提取其局部位置（相对于面板内部左上角的行、列偏移）。
3. 计算精灵行偏移的逐面板增量 dR 和列偏移的逐面板增量 dC（恒定）。
4. 提取精灵颜色序列，推导下一个颜色（序列的第 4 个值，按周期循环确定）。
5. 输出一个独立面板（同样的高度和宽度，含灰(5)边框和黑(0)填充），精灵位于外推位置（上一帧位置 + (dR, dC)），颜色为推导出的下一色。

**关键洞察**：面板同时编码两路独立信号——空间运动和色彩轮换。求解者若只关注运动会得到位置正确但颜色错误的答案，反之亦然。必须对比全部三个面板同时提取两种模式。

## 新题 8：模板匹配与角点朝向编码旋转印章

**组合逻辑**：[模板匹配/template_matching](已有，匹配规则不变) → [旋转角度解码](创新：模板上的角点标记与工作区副本上的角点标记位置差异编码旋转量) → [旋转/rotate](已有) → [印章覆盖/stamp_overlay](已有，但印章内容经过旋转)

**依赖链**：工作区碎片与目录模板匹配 → 确定对应模板 → 比较模板角点标记位置与碎片角点标记位置的旋转差异 → 确定旋转角度 → 旋转完整模板 → 印章到碎片位置。匹配决定"是哪个模板"，角点比较决定"转几度"，旋转决定"印什么内容"。

将工作区中的部分精灵碎片匹配到目录中的完整模板，通过角点标记的位移确定旋转角度，用旋转后的完整模板覆盖碎片以补全。

- 黑(0)背景，约 20x20 网格。

- 在黑色工作区中，有 2~3 个精灵碎片。每个碎片是某个模板的局部（至少包含模板 50% 的像素），且碎片中也保留了黄(4)朝向标记——但标记可能在不同的角（表示碎片相对于模板旋转了 0/90/180/270 度）。
- 可能有 1~2 个工作区对象无法匹配任何模板（干扰项）。
- 生成约束：每个碎片唯一匹配一个模板（通过颜色和形状局部匹配）。

**规则**：
1. 对每个工作区碎片，与目录中的模板逐一尝试四个旋转方向的匹配：将模板旋转 0/90/180/270 度，检查碎片的非背景像素是否与旋转后模板的对应子区域完全一致。找到匹配的模板和旋转角度。

4. 无法匹配任何模板的工作区对象保持原样。
5. 目录区域保持不变。

**关键洞察**：黄色角点不仅帮助匹配，还编码了朝向信息——目录中的模板黄点始终在左上角，碎片中黄点的漂移直接给出了旋转量。求解者必须发现"黄点在哪个角 = 旋转了多少度"这一隐蔽规则。

## 新题 9：残缺网格线修补与空白线着色分类

**组合逻辑**：[相邻像素标有效线/adjacent_marks_line](已有) → [补全/completion + 缺口补另色/gaps_filled_other_color](已有) + [空行列涂标记色/blank_lines_painted_marker](已有，但两类线用不同颜色区分) → [交叉高亮](创新：两类不同处理的线在交叉点产生第三种颜色)

**来源原语**：补全、填充、网格线、缺口、行列对齐、相邻像素标有效线、缺口补另色(来自 4612dd53)；重涂色、全空行列、空行列涂标记色(来自 c1d99e64)

**依赖链**：逐行逐列扫描分类——有相邻对的为"残缺线"、全空的为"缺失线" → 残缺线的缺口补红色 → 缺失线整行/列涂绿色 → 两类线交叉的单元格涂黄色作为交叉高亮。分类是双向处理的前提，两种处理结果在交叉点汇合产生第三种颜色，三步缺一不可。

识别残缺的网格线（有部分蓝色像素但有缺口）和完全缺失的网格线（整行/列无蓝色），分别用红色修补和绿色显现，两类线交叉处标为黄色。

**输入结构**：
- 黑(0)背景，约 14x14 网格。
- 一组蓝(1)像素构成一个不完整的正交网格：在网格的包围框内，部分行和部分列有蓝(1)像素——这些行/列中至少存在一对水平相邻（同行相邻两列）或垂直相邻（同列相邻两行）的蓝(1)像素，但也有一些位置的蓝像素缺失（黑色缺口）。
- 在同一包围框内，另有一些行和列完全没有蓝(1)像素——它们在包围框范围内的所有像素都是黑(0)。
- 蓝色网格之外（包围框之外）全为黑(0)。
- 生成约束：至少有 2 条残缺线（有蓝像素也有缺口）和 2 条缺失线（全空）。至少有一个残缺线和缺失线的交叉点。

**规则**：
1. 计算蓝(1)像素的包围框（最小行、最大行、最小列、最大列）。
2. 在包围框范围内，对每一行检查：若该行存在至少一对水平相邻的蓝(1)像素，则标记为"残缺行线"。
3. 在包围框范围内，对每一列检查：若该列存在至少一对垂直相邻的蓝(1)像素，则标记为"残缺列线"。
4. 在包围框范围内，对每一行检查：若该行在包围框列范围内不含任何蓝(1)像素，则标记为"缺失行线"。对每一列同理。
5. 对每条残缺行线，将该行在包围框列范围内的所有黑(0)像素填充为红(2)。对每条残缺列线，将该列在包围框行范围内的所有黑(0)像素填充为红(2)。
6. 对每条缺失行线，将该行在包围框列范围内的所有像素涂为绿(3)。对每条缺失列线同理。
7. 在同时属于一条残缺线和一条缺失线的交叉单元格处，颜色设为黄(4)（黄色覆盖红色和绿色）。
8. 所有原始蓝(1)像素保持不变（不被红、绿、黄覆盖）。
9. 包围框外的区域不做任何改变。

**关键洞察**：同样是"空白"位置，"残缺线上的缺口"与"完全缺失的线"在视觉上几乎相同（都是黑像素），但它们的判定标准不同（看同行/列是否有相邻蓝对），处理方式也不同（红色修补 vs 绿色显现）。二者交叉还产生第三种颜色，求解者必须理解这种分类才能正确着色。

## 新题 10：精灵对接拼合与封闭空腔洪泛填色

**组合逻辑**：[对接拼合/docking](已有) → [裁剪/crop](已有) → [洪泛填充/flood_fill](已有，但作用于对接后才出现的封闭区域) + [连接点颜色匹配/connector_color_match](已有，连接点颜色额外用作填充色)

**来源原语**：对接拼合、精灵体、连接点、对接对齐、连接点颜色匹配(来自 20270e3b)；裁剪(来自 fcb5c309)；洪泛填充、封闭区域、区域封闭、孤立背景区域填充(来自 a5313dff)

**依赖链**：连接点颜色匹配确定对接对 → 平移对接改变空间布局 → 拼合后的形状可能围出封闭空腔 → 洪泛填充检测这些空腔 → 空腔用连接点的颜色填充 → 紧凑裁剪。对接决定最终形状（拓扑），拓扑决定是否有封闭区域，封闭区域的颜色来自对接时用过的连接点。

将两个带有同色连接点的精灵对接拼合，拼合后形状围出的封闭背景空腔用连接点颜色填充，最后紧凑裁剪。

**输入结构**：
- 黑(0)背景，约 16x16 网格。
- 两个独立的灰(5)精灵体（各 8~15 像素，4-连通，不规则形状），放置在网格不同区域，互不接触。
- 每个精灵各有恰好一个红(2)像素作为连接点，该连接点位于精灵的边界（与至少一个背景像素 4-邻接）。
- 生成约束：基座精灵（包围框左上角在阅读顺序中更靠前的那个）的连接点位于其下边界；插入精灵的连接点位于其上边界。对接后（插入精灵的连接点移至基座连接点正上方一格），两个精灵合并后的 4-连通灰色+红色像素集合围出至少一个封闭的黑(0)背景区域（该区域无法通过 4-邻接背景路径到达合并体外部）。

**规则**：
1. 确定基座精灵：两个精灵中，包围框左上角按阅读顺序（先比行、行同比列）更靠前的为基座。另一个为插入体。
2. 平移插入体，使其红(2)连接点恰好位于基座红(2)连接点正上方一格。
3. 将两个连接点的红(2)像素重涂为灰(5)，使其融入精灵体。
4. 对合并后的形体执行紧凑裁剪：取所有非黑像素的最小包围框。
5. 在裁剪区域内，以灰(5)像素为墙壁，从裁剪区域的四条边出发做 4-邻接洪泛标记所有可达的黑(0)像素为"外部"。
6. 裁剪区域内剩余的未标记黑(0)像素为封闭空腔，将其全部填充为红(2)（连接点的原始颜色）。
7. 输出裁剪后的结果。

**关键洞察**：两个精灵单独存在时没有任何封闭区域，对接拼合后其几何形状产生了输入中不存在的空腔——这是典型的涌现效应。连接点的颜色从"匹配标识"变为"空腔填充色"，一色三用（匹配、定位、填色）。
