## 新题 1：同心环迷宫寻路

**组合逻辑**：[同心层填充](已有，从b7fb29bc) + [奇偶距离决定颜色→迷宫墙壁](创新：奇偶分色从装饰变为通行性判据) + [寻路](已有，从b15fca0b) + [重涂色](已有)

**来源原语**：同心层填充、控制像素、同心正方形层、奇偶距离决定颜色 → b7fb29bc；寻路、端点像素、障碍像素、最短路径、四邻接连通 → b15fca0b；重涂色 → b15fca0b

**依赖链**：控制像素的偏心位置决定同心环布局 → 奇偶距离规则将环分为通行层与阻挡层 → 路径搜索受限于通行层拓扑 → 路径像素重涂色。删除同心填充则无迷宫；删除寻路则无路径输出；删除奇偶规则则无墙壁约束。

在矩形边框内部，以偏心控制像素为中心生成同心方环，奇距离层为通道、偶距离层为墙壁，然后在通道层中找出两端点之间的最短路径并标记。

**输入结构**：约15x15黑(0)背景网格。一个灰(5)像素构成的矩形单像素边框。边框内部有一个绿(3)控制像素，位置偏离中心（不在边框内部的几何中心上）。边框内部另有两个红(2)端点像素，分布在控制像素的不同方位、位于不同切比雪夫距离层上。所有其他内部像素为黑(0)背景。生成约束：两个红(2)端点之间存在至少一条仅经过奇切比雪夫距离层的4-连通路径，且该路径唯一最短。

**规则**：
1. 保持灰(5)边框、绿(3)控制像素和红(2)端点像素不变。
2. 对边框内部每个黑(0)背景像素，计算其到绿(3)控制像素的切比雪夫距离 d。
3. d 为偶数的像素涂为红(2)（墙壁层）；d 为奇数的像素涂为黄(4)（通道层）。
4. 以黄(4)像素和红(2)端点像素为可通行区域，红(2)墙壁层像素为不可通行区域，找到两个红(2)端点之间的唯一最短4-连通路径。
5. 将路径上的黄(4)内部像素（不含两个端点本身）重涂为蓝(1)。

**关键洞察**：同心环的奇偶分色不是视觉装饰，而是迷宫墙壁的生成机制——控制像素的偏心位置导致各方向的通道层宽度不均匀，某些方向的通道仅一像素宽而另一些方向的通道宽达数像素，间接约束了路径走向。必须对比多个示例才能归纳出"偶距离=墙壁、奇距离=通道"的规则。

## 新题 2：形状频次筛选与自编码放大

**组合逻辑**：[形状频次分组](已有，从62593bfd) + [旋转翻转不变](已有) + [擦除](已有) + [计数→缩放因子](创新：存活对象数编码倍率，替代原d4b1c2b1中的色数编码) + [像素放大](已有，从d4b1c2b1) + [排序+拼接](已有，从6cbe9eb8/bc1d5164)

**来源原语**：形状频次分组、旋转翻转不变、共享与唯一形状 → 62593bfd；像素放大、计数 → d4b1c2b1；擦除 → bae5c565/252143c9；排序 → 62593bfd；拼接 → bc1d5164

**依赖链**：形状频次分组决定哪些精灵存活（唯一形状留、共享形状删） → 存活精灵数量 N 成为缩放倍率 → 每个存活精灵做 N 倍像素放大 → 放大后按原始位置排列拼接。N 既取决于删除结果，又反作用于输出尺寸，形成自平衡。

根据形状的旋转/翻转等价类对精灵分组，擦除形状重复的精灵，用存活数量作为缩放因子放大剩余精灵，然后水平排列输出。

**输入结构**：约20x20黑(0)背景网格。散布5~7个单色4-连通精灵体，每个精灵3~6像素，颜色各不相同（从蓝(1)、红(2)、绿(3)、黄(4)、灰(5)、品红(6)、橙(7)中取），精灵之间互不相邻。部分精灵的二值形状在旋转和翻转变换下等价（形状共享），其余精灵的形状唯一。生成约束：唯一形状的精灵数量 >= 2 且 <= 4，确保放大后输出尺寸合理。

**规则**：
1. 对每个精灵提取其二值形状掩码，计算旋转/翻转不变的标准化形状（8种变换取字典序最小）。
2. 统计每种标准化形状出现的次数。出现次数 >= 2 的精灵（形状被共享）全部擦除。
3. 形状唯一（出现次数 = 1）的精灵存活。
4. 计算存活精灵数量 N。
5. 对每个存活精灵做 N 倍像素放大：精灵掩码中的每个前景像素变为 NxN 的同色方块，背景像素变为 NxN 的黑(0)方块。
6. 按存活精灵在原始网格中的位置（先按行从上到下、同行按列从左到右排序），将放大后的精灵从左到右水平排列，相邻精灵之间间隔1列黑(0)背景。输出裁剪到最小包围框。

**关键洞察**：存活精灵的数量同时决定了"谁被放大"和"放大多少倍"——精灵越少，每个放大倍率越低，输出越紧凑；精灵越多，放大倍率越高，输出越大。这种自编码效应使得输出尺寸无法从输入尺寸直接推断，必须先完成频次筛选才知道缩放因子。

## 新题 3：图例定向对角射线与交叉优先级

**组合逻辑**：[射线延伸](已有，从252143c9) + [象限指示方向](已有) + [颜色图例](已有，从9385bd28) + [图例映射颜色](已有) + [处理顺序保护](已有，从9385bd28) + [擦除](已有) — 创新：多个射线源并行发射，图例同时编码颜色映射和优先级排序，交叉点颜色由隐式优先级决定

**来源原语**：射线延伸、擦除、中心像素、对角象限、象限指示方向、同色像素定角 → 252143c9；颜色图例、图例映射颜色、处理顺序保护 → 9385bd28

**依赖链**：卫星像素的象限位置 → 确定各射线方向 → 图例将源色映射为射线色 → 图例的排列顺序决定绘制先后（即交叉优先级） → 交叉点颜色由后绘制者覆盖。方向、颜色、优先级三重信息分别编码在不同结构中，缺一不可。

多个射线源各有卫星像素指示对角方向，射线颜色由图例映射，射线交叉时图例顺序决定哪条射线的颜色覆盖另一条。

**输入结构**：约15x15黑(0)背景奇数边长正方形网格。左侧两列为颜色图例区：每行一对相邻像素，左列为标记色、右列为射线色，共3~4条图例条目，各条目之间间隔至少1行黑(0)。图例右侧（第3列起）的主区域中散布3~4个前景像素作为射线源，颜色各不相同，与图例左列标记色一一对应。每个射线源附近（切比雪夫距离2~3内）有1~2个同色卫星像素，全部位于该射线源的同一个对角象限（左上/右上/左下/右下）。生成约束：至少存在一对射线的对角路径在主区域内有交叉点。

**规则**：
1. 读取左侧图例区所有条目，建立标记色→射线色的映射表，并记录每条图例的行位置。
2. 对主区域中的每个射线源，找到其全部同色卫星像素，确定卫星所在的对角象限，即为该射线的发射方向。
3. 擦除主区域中的所有前景像素（射线源和卫星），主区域变为全黑(0)。图例区保持不变。
4. 按图例条目从下到上的顺序（行号最大的先处理）依次绘制射线：从射线源的原始位置出发，沿确定的对角方向逐像素延伸直到触及网格边缘（含边缘像素），颜色为图例映射的射线色。
5. 后绘制的射线覆盖先绘制的射线——若两条射线交叉，交叉点保留图例位置更靠上（行号更小）的射线颜色。

**关键洞察**：图例的垂直排列顺序不仅映射颜色，还隐式编码了射线的绘制优先级——图例越靠上，绘制越晚，优先级越高，交叉时覆盖其他射线。这条优先级规则在单个示例中可能不可见（若无交叉），必须对比多个示例中交叉点的颜色归属才能归纳。

## 新题 4：计数器驱动十字对移与涌现对角连线

**组合逻辑**：[计数](已有，从e48d4e1a) + [平移](已有) + [计数器消失](已有) + [连线](已有，从55059096) + [中心对角对齐](已有) + [无障碍通路](已有) — 创新：平移不是单个十字的移动，而是一对十字的对向移动；对角对齐关系是平移后的涌现属性而非输入固有属性

**来源原语**：计数、平移、十字图案、计数器像素、计数决定偏移、计数器消失 → e48d4e1a；连线、十字图案、中心对角对齐、无障碍通路 → 55059096

**依赖链**：计数器像素数 N → 两个十字分别做方向相反的平移各 N 步 → 平移后检查两中心是否对角对齐 → 若对齐且路径无障碍则画连线。对角对齐是 N 值的涌现结果，换一个 N 可能就不对齐。

两个十字各自反向平移计数器指定的距离后，若中心恰好落在同一条45度对角线上且中间无阻挡，则在中心之间画对角连线。

**输入结构**：12x12黑(0)背景网格。两个不同颜色的小十字图案：一个蓝(1)、一个绿(3)，每个十字为标准5像素加号形（中心+上下左右各1像素），分别位于网格的不同位置。最右列从顶部起有若干连续灰(5)像素（1~3个），编码平移量。两个十字初始位置不在同一对角线上。生成约束：设灰(5)像素数为 N，蓝十字中心向下 N 行、向左 N 列移动后，绿十字中心向上 N 行、向右 N 列移动后，两个新中心的行差绝对值等于列差绝对值（对角对齐），且两新中心之间的对角线段上所有内部像素在移动后均为黑(0)背景。移动后的十字不超出网格边界。

**规则**：
1. 计数最右列连续灰(5)像素的数量 N。
2. 将蓝(1)十字整体向下平移 N 行、向左平移 N 列。将绿(3)十字整体向上平移 N 行、向右平移 N 列。
3. 灰(5)计数器像素全部擦除（变为黑(0)）。
4. 计算平移后两个十字中心之间的行差 dr 和列差 dc。若 |dr| = |dc|（对角对齐），扫描两中心之间的45度对角线段。
5. 若该对角线段上所有内部像素（不含两个中心本身）均为黑(0)背景，则将这些内部像素涂为红(2)。

**关键洞察**：计数器像素不仅控制平移距离，更间接决定了两个十字是否会产生对角对齐——这种对齐是平移的涌现结果而非输入的固有属性。求解者必须先执行平移，才能判断是否需要画连线。单看初始位置无法预测输出中是否存在红色对角线。

## 新题 5：嵌套框架与边界同色行填充

**组合逻辑**：[排序+嵌套](已有，从6cbe9eb8) + [面积递减嵌套](已有) + [角落对齐嵌套→左下对齐](已有) + [填充](已有，从22eb0ac0) + [同色配对](已有) + [两端同色整行填充](已有) — 创新：嵌套操作重组了矩形框的空间关系，产生了新的行端点颜色配置，由此触发的行填充规则依赖于嵌套结果

**来源原语**：排序、嵌套、前景矩形、面积递减嵌套、角落对齐嵌套 → 6cbe9eb8；填充、画布边界、同色配对、两端同色整行填充 → 22eb0ac0

**依赖链**：矩形按面积排序 → 嵌套到左下角产生多层嵌套框架 → 每行的最左和最右非背景像素由嵌套后的框边决定 → 同色端点行触发填充。改变嵌套对齐方式或排序顺序会改变哪些行被填充。

将散落的矩形框按面积排序后逐层嵌套至左下角，然后对嵌套结果中左右端恰为同色的行执行整行填充。

**输入结构**：约15x15黑(0)背景网格。散布3~4个不同颜色的矩形单像素空心边框（仅边框线，内部为黑(0)背景），颜色分别为蓝(1)、红(2)、绿(3)、黄(4)等，大小各不相同（最大约10x8，最小约4x3），位置任意且互不重叠。生成约束：按面积从大到小嵌套至左下角后，至少存在2行其最左与最右非背景像素来自同一矩形框（颜色相同），且至少存在1行其最左与最右非背景像素来自不同矩形框（颜色不同）。

**规则**：
1. 计算每个矩形边框的面积（宽 x 高），按面积从大到小排序。
2. 创建与输入同尺寸的黑(0)背景输出网格。将最大矩形框保持原样绘制。
3. 对第二大、第三大...的矩形框依次处理：将其放入前一个矩形框的内部左下角（小框的外边框左边紧贴大框内壁左侧，小框的外边框底边紧贴大框内壁底部）。逐层嵌套。
4. 嵌套完成后，逐行扫描输出网格。对每一行，找到该行最左的非黑(0)像素和最右的非黑(0)像素。
5. 若该行最左和最右像素颜色相同，则将这两个像素之间（含端点）的所有像素填充为该颜色（覆盖中间可能存在的其他颜色或背景）。
6. 若该行最左和最右像素颜色不同，或该行无非背景像素，则保持该行不变。

**关键洞察**：嵌套的左下角对齐使得各矩形框的上边和右边在不同行形成不同的端点配置——只有当某一行的左右边界恰好都属于同一个矩形框时（该框的左边和右边在该行都是最外层可见边），才会触发填充。这种条件完全取决于嵌套几何关系，无法从原始散落位置直接预判。

## 新题 6：叠加合成模板与补全

**组合逻辑**：[透明叠加](已有，从d19f7514) + [并集取前景](已有) + [逐像素对齐](已有) + [补全](已有，从bb52a14b) + [印章覆盖](已有) + [模板与副本匹配](已有) + [非标记精确匹配](已有) — 创新：完整模板不直接给出，而是分散编码在两个互补面板中，必须先叠加合成模板，再用它补全不完整副本

**来源原语**：透明叠加、面板、逐像素对齐、并集取前景 → d19f7514；补全、印章覆盖、模板精灵体、不完整副本、缺失掩码、模板与副本匹配、非标记精确匹配 → bb52a14b

**依赖链**：面板A和面板B叠加 → 并集生成完整模板 → 模板用于在下区匹配不完整副本 → 缺失位置被补全。单看任一面板都不知道完整形状，无法跳过叠加步骤。

两个互补面板分别持有模板的一部分前景，叠加后得到完整模板，然后用该模板在下方区域找到并补全所有不完整副本。

**输入结构**：约18x12黑(0)背景网格，由两条灰(5)水平分隔线分为三个区域（上区、中区、下区）。上区包含一个4x4大小的蓝(1)前景图案（面板A），部分位置为前景、其余为黑(0)背景，前景像素4-连通构成一个不规则形状（3~8个前景像素）。中区包含一个同样4x4大小的红(2)前景图案（面板B），与面板A形状互补——A为前景的位置B为背景，B为前景的位置A为背景（两个面板的前景并集恰好覆盖4x4窗口中的全部需要标记的位置，前景像素总数6~12个）。下区在黑(0)背景上散布2~3个4x4的不完整副本，每个副本的已有像素为绿(3)，像素位置是完整模板前景位置的真子集（缺失1~3个像素）。各副本之间不重叠、不相邻。生成约束：每个不完整副本的已有像素位置是模板前景位置的子集，且各副本缺失的位置可以不同。

**规则**：
1. 将上区面板A（蓝(1)前景）和中区面板B（红(2)前景）按像素对齐叠加：任一面板有前景的位置标记为模板前景，得到完整的4x4二值模板。
2. 在下区以4x4滑动窗口扫描。对每个窗口，检查窗口中所有绿(3)像素是否与模板前景位置的子集精确对应（绿像素出现的位置在模板中必须是前景，且模板的非前景位置在窗口中必须是黑(0)背景）。
3. 若匹配成功，该窗口为不完整副本。将窗口中模板前景位置上缺失的像素（黑(0)背景但模板中为前景）填充为绿(3)。
4. 上区和中区保持不变。

**关键洞察**：完整模板被拆分成两个颜色不同的互补面板——单独观察面板A或面板B都只能看到模板的一半，必须先执行叠加合成才能获得用于匹配的完整模板。这种"模板隐藏在叠加中"的编码方式是d19f7514（简单叠加）和bb52a14b（模板补全）都不具备的结构关系。
