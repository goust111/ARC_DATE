## 新题 1：腔室投票决定平铺方向与颜色

**组合逻辑**：[填充/邻接多数决](创新：投票结果不用于填充腔室本身，而是决定相邻模板的平铺颜色) + [平铺/邻接触碰](创新：平铺方向由模板与腔室的空间关系决定，而非独立的指示像素) + [分隔墙](已有) + [连通腔室](已有) + [模板](已有)

**来源原语**：填充/邻接多数决(7c8af763)、平铺/邻接触碰(e8dc4411)、连通腔室/分隔墙(7c8af763)、模板(e8dc4411)、标记像素(7c8af763/b457fec5)

**依赖链**：墙体结构同时划分投票区域和限定平铺范围 → 每个腔室的多数标记色决定了该腔室方向上平铺副本的颜色 → 平铺从模板出发朝腔室方向延伸，遇墙或网格边界停止 → 因此移动任一标记像素可能改变投票结果，进而改变整条平铺带的颜色

从中心模板出发，根据相邻腔室的标记投票结果，向各腔室方向平铺模板副本并着上对应投票颜色。

**输入结构**：黑(0)背景，约 17x17。灰(5)单像素宽直线组成的墙体将网格分为 4 个腔室（不要求均等），墙体交叉处附近有一个黑(0)色的 4-连通小型模板对象（3~5 像素，非矩形，各示例形状不同）。模板对象至少有一条边 4-邻接灰(5)墙体。每个腔室内散布 2~4 个单色标记像素，颜色取自蓝(1)、红(2)、绿(3)、黄(4)，同一腔室内可有多种颜色但保证存在唯一多数色。不同腔室的多数色互不相同。生成约束：模板对象紧邻墙体交叉区域，使其与所有 4 个腔室都至少有一个可推断的方向关系（上、下、左、右各对应一个腔室）。

**规则**：
1. 识别灰(5)墙体、黑(0)模板对象和各色标记像素。背景为黑(0)，但模板对象也是黑(0)——通过与灰墙 4-邻接的连通区域来区分模板（模板是唯一与墙 4-邻接的非墙非标记连通区域）。
2. 对每个由墙围成的 4-连通腔室，统计其中标记像素的颜色，取出现次数最多的颜色作为该腔室的投票色。
3. 确定模板对象中心到每个腔室质心的主方向（上/下/左/右），将四个腔室分别映射到四个主方向。
4. 对每个方向：以投票色重涂模板的形状，沿该方向以模板边界框高度（上下方向）或宽度（左右方向）为步长，逐步平铺副本，直到副本的任一像素将落在灰(5)墙体上或超出网格边界时停止（不绘制该最后一个越界副本）。
5. 保留原始模板为黑(0)不变，保留所有墙体和标记像素不变。

**关键洞察**：灰墙既是投票区域的边界也是平铺的物理障碍——改变墙的位置会同时改变哪些标记属于哪个腔室（从而改变投票结果）和平铺能延伸多远。

## 新题 2：骨架对齐传递保护标记 + 十字擦除豁免

**组合逻辑**：[印章覆盖/骨架对齐](已有) + [十字擦除/特定色像素豁免](已有，但豁免像素由前一步动态生成) + [旋转/镜像](已有)

**来源原语**：印章覆盖/骨架对齐(36d67576)、十字擦除(319f2597)、特定色像素豁免(319f2597)、旋转/镜像(36d67576)、锚点像素(36d67576)、标记块(319f2597)

**依赖链**：骨架对齐传递红色标注到各副本的精确位置 → 红色像素的分布图案决定了十字擦除中哪些位置被豁免 → 最终输出同时编码了骨架的二面体对称性和十字的几何结构 → 删除任一步骤（传递或擦除）都无法得到正确输出

将完整标注骨架的红色标记传递到所有旋转/反射副本后，用 2x2 黑色块定义十字擦除区域，红色像素在擦除中受保护。

**输入结构**：非黑背景色（如橙(7)），约 15x15，整个网格被橙(7)像素填满，上面有前景对象。3~4 个灰(5)色的 8-连通骨架图形散布其中，每个骨架 6~10 像素，形状各示例不同但所有骨架共享相同的结构骨架（可能经旋转/反射）。每个骨架包含恰好一个栗(9)色锚点像素。其中恰好一个骨架额外包含 2~3 个红(2)色标注像素（位于骨架相邻位置但不在骨架像素上），其余骨架只有灰(5)骨架和栗(9)锚点。此外，网格中存在恰好一个 2x2 的黑(0)标记块。生成约束：骨架间互不重叠；黑(0)标记块不与任何骨架像素重叠；各骨架通过旋转/反射可与完整标注骨架的灰(5)+栗(9)部分完全对齐。

**规则**：
1. 识别完整标注骨架（含红(2)标注的那个）和不完整骨架。
2. 对每个不完整骨架，找到唯一的旋转/反射变换，使完整骨架的灰(5)像素和栗(9)锚点像素与目标骨架的灰(5)和栗(9)像素完全重合。
3. 将该变换应用于完整骨架的红(2)标注像素，在目标骨架对应位置绘制红(2)像素。骨架像素和锚点不变。
4. 标注传递完成后，定位 2x2 黑(0)标记块，选取该标记块占据的 2 行和 2 列。
5. 将这 4 条线（2 行 + 2 列）上所有非红(2)的像素重涂为黑(0)。红(2)像素保持不变。
6. 不在这 4 条线上的像素保持不变。

**关键洞察**：骨架对齐步骤在看似无关的位置"种下"红色保护像素；这些保护位置只有在十字擦除发生后才显现其意义——它们恰好是擦除区中存活的信息点，编码了骨架的旋转状态。

## 新题 3：按轴距排序精灵体 + 轴反射 + 排名重涂色

**组合逻辑**：[镜像/沿轴反射](创新：反射所有精灵体而非仅最少像素色) + [排序](创新：排序键是精灵体到轴的距离而非行顺序或类型) + [重涂色/列序映射颜色](创新：颜色由距离排名决定而非列索引)

**来源原语**：镜像/沿轴反射(ad3b40cf)、对称轴(ad3b40cf)、排序(e21a174a)、重涂色(575b1a71)、列序映射颜色(575b1a71)、精灵体(e21a174a)

**依赖链**：对称轴位置同时决定反射几何和距离度量 → 精灵体到轴的距离决定排序名次 → 排序名次决定重涂颜色 → 反射副本继承源精灵体的名次颜色 → 轴位置的改变会同时改变反射位置和颜色分配

将轴一侧的精灵体按到轴距离排序并据名次重涂色，同时将每个精灵体反射到轴另一侧，反射副本与源同色。

**输入结构**：黑(0)背景，约 15x11（宽大于高）。一条红(2)色完整竖直线（占满整列，从第 0 行到最后一行）作为对称轴，位于网格中偏左或偏右的某列（非正中央，各示例位置不同）。轴的一侧（如右侧）散布 4 个灰(5)色 4-连通小精灵体，每个 3~6 像素，形状各不相同且各示例间同一序位的精灵体形状也不同。轴的另一侧（左侧）为空（仅背景）。生成约束：4 个精灵体的边界框互不重叠；每个精灵体的边界框中心到轴列的水平距离互不相同；反射后任何精灵体不会超出网格边界或与轴重叠。

**规则**：
1. 识别红(2)竖直轴线和所有灰(5)精灵体。
2. 计算每个精灵体的边界框中心列到轴列的水平距离（取绝对值）。
3. 按距离从小到大排序，名次 1 到 4 分别对应蓝(1)、绿(3)、黄(4)、品红(6)。
4. 将每个精灵体的所有灰(5)像素重涂为其名次对应的颜色。
5. 将每个重涂后的精灵体以轴列为镜像线反射到另一侧，反射副本的颜色与源精灵体相同。
6. 保留红(2)轴线不变。背景保持黑(0)。

**关键洞察**：对称轴不仅是几何镜像线，还隐含地充当了距离参考——精灵体的颜色不取决于它在网格中的绝对列位置，而是取决于它离轴有多远。仅看单个示例时，颜色可能被误解为与行位置或精灵体面积相关，必须对比多个示例（轴位置不同、精灵体分布不同）才能归纳出距离-排名规则。

## 新题 4：象限单像素组建循环调色板 + 对角带层深填充

**组合逻辑**：[重涂色/象限对应](创新：象限映射结果构成调色板而非最终输出) + [循环填充/层深模色板取色](创新：调色板来自象限映射而非输入中预设的调色板行) + [对角带](已有) + [散落单像素](已有)

**来源原语**：象限对应(d89b689b)、锚定方块(d89b689b)、散落单像素(d89b689b)、循环填充(b457fec5)、对角带(b457fec5)、层深度递增(b457fec5)、层深模色板取色(b457fec5)

**依赖链**：四个散落单像素的象限位置决定它们在 2x2 锚定方块中的排列 → 该排列构成一个有序调色板（按顺时针从左上读取） → 四条对角带各从锚定方块的一个角出发 → 每条带的起始色由其出发角在调色板中对应的颜色决定 → 带内各层按顺时针循环使用调色板中从起始色开始的后续颜色

四个单像素按象限映射到中心方块形成调色板，四条对角带从方块四角出发，每条带用该角的调色板色为起始进行层深循环填充。

**输入结构**：黑(0)背景，约 13x13。网格中央有一个 2x2 的灰(5)锚定方块。四个单像素分别位于锚定方块的四个对角方向外侧：一个在左上方、一个在右上方、一个在左下方、一个在右下方（即每个单像素的行在方块上方或下方、列在方块左方或右方）。四个单像素颜色各不相同，取自蓝(1)、红(2)、绿(3)、黄(4)（各示例中分配不同）。从锚定方块的四个角像素位置出发，各有一条灰(5)对角带（宽 2 像素的斜向带状区域），朝四个角方向延伸至网格边界。对角带与锚定方块在角像素处相连。生成约束：四个单像素不在任何对角带上，也不在锚定方块上。

**规则**：
1. 识别 2x2 灰(5)锚定方块、四个彩色单像素和四条灰(5)对角带。
2. 按象限映射将单像素颜色填入锚定方块：左上方的单像素颜色 → 方块左上格，右上方 → 右上格，左下方 → 左下格，右下方 → 右下格。将方块对应格的灰(5)替换为映射颜色。
3. 构建顺时针调色板序列：从方块左上格开始，按左上→右上→右下→左下读取四种颜色，形成长度为 4 的循环调色板 P。
4. 对每条对角带：确定其从方块哪个角出发（左上角、右上角、左下角、右下角），取该角在调色板 P 中的索引 s 作为起始偏移。
5. 对角带内的每个像素，计算其层深 d = 该像素到出发角的切比雪夫距离（即 max(|行差|, |列差|)）。将该像素重涂为 P[(s + d) mod 4]。
6. 删除四个原始单像素（涂为黑(0)背景）。保留方块（已被步骤 2 重涂）。

**关键洞察**：散落单像素的空间位置同时编码了两件事：它在调色板中的色值（由像素本身的颜色决定）和它在调色板中的位置索引（由它相对于锚定方块的象限决定）。仅看一个示例可能误认为对角带的颜色模式是固定的，需要对比多个示例（单像素颜色和象限分配不同）才能发现调色板是动态组建的。

## 新题 5：分类空心/实心 + 按类型向对应满行条滑动 + 碰撞堆叠

**组合逻辑**：[分类/内部判定类型](已有) + [滑动/同色配对](创新：配对依据是类型而非颜色，目标是类型对应的行条而非同色行条) + [碰撞阻挡](已有) + [重涂色](创新：最终颜色由类型决定)

**来源原语**：分类/内部判定类型(2ba387bc)、空心矩形/实心方块(2ba387bc)、滑动(1a07d186)、满行列条(1a07d186)、碰撞阻挡(1a07d186)、同色配对(1a07d186)、重涂色(575b1a71)

**依赖链**：每个对象的 2x2 内部决定其类型（空心/实心） → 类型决定其滑动目标行条（蓝条或红条） → 滑动顺序由到目标行条的距离决定（近者先着陆） → 先着陆的对象成为后续对象的物理障碍 → 着陆后所有对象按类型统一重涂色

将散布的 4x4 对象按空心/实心分类后，空心的向蓝色行条滑动、实心的向红色行条滑动，滑动过程中先到者阻挡后到者，最后按类型统一重涂。

**输入结构**：黑(0)背景，约 19x9（高大于宽）。网格顶部有一条蓝(1)满行条（占满整行的蓝色像素），底部有一条红(2)满行条。两条行条之间散布 4~6 个 4x4 对象，每个对象为单色（颜色取自绿(3)、黄(4)、灰(5)、品红(6)、橙(7)，各对象颜色可相同可不同）。部分对象是空心框（1 像素宽边框，内部 2x2 为黑(0)），其余为实心块（4x4 完全填充）。生成约束：所有对象边界框互不重叠且不与行条重叠；每列至少能容纳所有需要经过该列的对象在垂直方向上无冲突地堆叠。

**规则**：
1. 识别蓝(1)满行条、红(2)满行条和所有 4x4 前景对象。
2. 对每个 4x4 对象检查其内部 2x2 区域：若内部为黑(0)则分类为"空心"，否则为"实心"。
3. 空心对象向蓝(1)行条方向垂直滑动（即向上），实心对象向红(2)行条方向垂直滑动（即向下）。
4. 滑动优先级：按对象边界框到其目标行条的垂直距离从小到大排序，距离相同时按边界框左上角列号从小到大处理。每个对象沿垂直方向逐行移动，直到其边界框的前进边将要接触目标行条或已着陆的另一个对象时停止（停在接触前一行，不重叠）。
5. 所有对象滑动完成后，将所有空心对象重涂为蓝(1)（边框像素变蓝，内部仍为黑(0)），所有实心对象重涂为红(2)。
6. 两条行条保持原色不变。

**关键洞察**：对象的原始颜色是干扰项——决定行为的是内部结构（空心/实心），而非表面颜色。必须对比多个示例才能排除"按颜色配对"的假设，发现真正的分类依据是 2x2 内部区域。

## 新题 6：缺口列垂直填充 + 边距模式迁移 + 交叉覆盖冲突

**组合逻辑**：[填充/按行序分段涂色](已有) + [图案迁移/边距保持迁移](已有) + 冲突解决规则（创新：两种操作结果在空间上交叉，需要冲突优先级）

**来源原语**：填充/条缺口/按行序分段涂色(cf133acc)、列对齐(cf133acc)、图案迁移/边距保持迁移(57edb29d)、纯色矩形/带标记矩形(57edb29d)、行范围重叠(57edb29d)

**依赖链**：水平条的缺口列定义垂直填充区域 → 矩形的标记图案通过边距迁移到纯色矩形 → 垂直填充条和迁移图案在空间上交叉 → 交叉区域的最终颜色取决于冲突规则（垂直填充覆盖迁移图案） → 矩形位置的变化同时影响迁移范围和哪些列发生交叉

缺口列垂直填充产生彩色竖条，标记矩形的边距图案迁移到纯色矩形，二者交叉处竖条填充覆盖迁移图案。

**输入结构**：黑(0)背景，约 15x15。网格上半区有 2~3 条不同颜色的满行水平条（占满整行，颜色取自蓝(1)、红(2)、绿(3)），每条中有恰好一个单像素缺口（缺口为黑(0)）。多条缺口可能在同一列也可能在不同列。网格下半区有两个矩形区域（约 4x6 至 5x8，各示例尺寸不同）：一个为纯色矩形（如全黄(4)），另一个为带标记矩形（同色基底如黄(4)加上若干橙(7)标记像素形成边距相关的图案——标记像素到矩形边缘的距离构成规律性图案）。两个矩形的行范围（上下界）有重叠。缺口列中至少有一列穿过矩形区域。生成约束：水平条都在矩形上方；纯色矩形宽度 >= 带标记矩形宽度。

**规则**：
1. 识别满行水平条及其缺口位置、纯色矩形和带标记矩形。
2. 缺口列垂直填充：对每个缺口列，将该列从缺口行起向下逐行涂色，颜色为该缺口所在水平条的颜色，直到遇到另一条水平条或到达网格底部。如果同一列有多个缺口，从最上方的缺口开始处理，每段使用各自水平条的颜色。
3. 边距图案迁移：从带标记矩形中提取标记像素的边距图案——每个标记像素记录其到矩形四条边的距离。将这些标记像素按相同的边距关系映射到纯色矩形中对应位置，涂上橙(7)。对于带标记矩形的标记像素映射后超出纯色矩形边界的部分，直接丢弃。
4. 冲突解决：若缺口列垂直填充和边距图案迁移在纯色矩形内同一像素位置产生冲突，缺口列填充颜色优先（覆盖迁移图案）。
5. 输出为纯色矩形的裁剪区域（仅输出纯色矩形的边界框范围），包含基底色、迁移的标记图案和垂直填充条。

**关键洞察**：缺口列填充在逻辑上"穿透"了矩形区域，形成垂直彩色条纹；这些条纹破坏了迁移图案的完整性，意味着最终输出中的图案缺失并非错误而是冲突规则的结果。必须对比多个示例（缺口列与矩形重叠程度不同）才能确认覆盖优先级。

## 新题 7：提示精灵体像素数编码旋转 + 四象限独立旋转重组

**组合逻辑**：[裁剪/角落象限提取](创新：不是提取单个象限还原源，而是将源象限按不同角度旋转后放入各象限位置) + [旋转/像素数编码旋转](创新：旋转应用于裁剪出的象限而非色层) + [提示精灵体/同色匹配](已有)

**来源原语**：裁剪/角落象限提取(73182012)、四向反射对称(73182012)、旋转(6ffbe589)、像素数编码旋转(6ffbe589)、提示精灵体/同色匹配(6ffbe589)、象限(cfb2ce5a)

**依赖链**：前景面板被裁剪并分为四象限 → 左上象限被识别为源图案 → 每个象限位置有一个边框颜色标记 → 同色提示精灵体的像素数 mod 4 编码该象限的旋转量 → 源图案按编码角度旋转后放入对应象限 → 无提示精灵体的象限保持源图案不旋转

裁剪前景面板后提取左上象限为源图案，根据面板外各色提示精灵体的像素数确定每个象限的旋转角度，将旋转后的源图案填入各象限。

**输入结构**：黑(0)背景，约 15x15。中央有一个偶数行偶数列的前景面板（如 8x8 或 10x10），面板内有彩色图案。面板被一条单像素宽的灰(5)十字线分为四个等大象限。每个象限的十字线端点处（即面板边缘与十字线交汇的那个像素）为特定颜色的标记像素：左上象限对应的边缘标记为蓝(1)，右上为红(2)，左下为绿(3)，右下为黄(4)（标记位置：十字线在面板上边缘的左半处标蓝(1)、右半处标红(2)，在面板左边缘的上半处标蓝(1)、下半处标绿(3)，以此类推——每个象限由其相邻的两个边缘标记唯一确定）。面板外的黑色背景区域中，有 1~3 个小型单色提示精灵体（4-连通，2~7 像素，形状各示例不同），颜色为蓝(1)、红(2)、绿(3)、黄(4)中的某几种（不一定四种都有）。面板左上象限包含非对称的彩色图案（使用橙(7)和栗(9)等颜色），其余象限在输入中可能包含不同图案或为背景色。生成约束：左上象限图案在 0/90/180/270 度旋转下互不相同（即图案不具备 90 度旋转对称性）。

**规则**：
1. 裁剪到前景面板的边界框。识别灰(5)十字分隔线，将面板分为四个等大象限。
2. 提取左上象限（不含十字线像素）作为源图案 S。
3. 对每个象限位置（左上、右上、左下、右下），确定其边缘标记颜色 C。
4. 在面板外寻找颜色为 C 的提示精灵体。若找到，计算该精灵体的像素数 n，旋转量 = (n mod 4) x 90 度顺时针。若未找到同色提示精灵体，旋转量 = 0 度。
5. 将源图案 S 顺时针旋转对应角度后，填入该象限位置（替换该象限原有内容）。
6. 保留灰(5)十字线和边缘标记不变。输出为面板边界框范围。

**关键洞察**：输入面板的四个象限内容是干扰项——不论输入中各象限原有什么图案，输出完全由左上象限源图案加上外部提示精灵体的像素数决定。必须对比多个示例才能发现：(a) 只有左上象限是源，(b) 旋转量的编码方式是像素数 mod 4 而非其他属性。
