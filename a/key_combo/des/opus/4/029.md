## 新题 1：跨半区精灵移植

**组合逻辑**：[裁剪 crop](已有) + [擦除 erase](已有) + [拉伸 stretch](创新：拉伸的源对象来自被丢弃的半区而非同一画布) + [填充 fill](已有，线段连接后洪泛)

**来源原语**：裁剪/擦除/标记对齐指定半区/保留标记半区(fbf15a0b)；拉伸/填充/精灵体/空心矩形/包围盒映射/线段连接再填充(465b7d93)

**依赖链**：标记像素选定保留半区 → 裁剪丢弃另一半 → 被丢弃半区中的精灵体提供拉伸内容 → 保留半区中的空心矩形框提供拉伸目标 → 精灵体的包围盒映射到矩形框内部 → 线段连接并填充。裁剪决定了目标画布和框，但拉伸的内容来源恰好在被裁掉的半区，形成跨边界信息流。

从被丢弃的半区取出精灵体的形状，拉伸填入保留半区的空心矩形框中，标记像素在裁剪后擦除。

**输入结构**：约 14x14 的网格，背景为黑(0)。两个红(2)标记像素位于同一行（或同一列），且都处于网格的同一半区。该半区内有一个蓝(1)的一像素宽空心矩形框（内部约 4x4 至 6x6），框内为黑(0)背景。另一半区（不含标记的那一半）有一个绿(3)的 4-连通小图形（3~6 像素，形状不固定——不同示例中可以是直线段、弯折形、分叉形等）。两个半区之间无前景像素跨越。生成约束：精灵体的包围盒的行数和列数均不超过矩形框内部的行数和列数。

**规则**：
1. 找到两个红(2)标记像素。若它们共享同一行，则沿列方向将网格分为左右两半（以网格列数的中点为界），保留标记所在的半区；若共享同一列，则沿行方向分为上下两半，保留标记所在的半区。
2. 在裁剪前，记录另一半区中绿(3)精灵体的形状掩码及其包围盒。
3. 裁剪到保留半区，将两个红(2)标记像素擦除为黑(0)背景。
4. 将精灵体包围盒的四个角映射到蓝(1)矩形框内部区域的四个角（左上→左上、右下→右下）。对精灵体中每对 4-相邻像素，在映射后的位置之间画水平或垂直的直线段，颜色为绿(3)。
5. 对框内被绿(3)线段完全封闭的黑(0)背景区域，洪泛填充为绿(3)。
6. 蓝(1)矩形框本身不变。

**关键洞察**：精灵体总是位于被丢弃的半区——求解者必须意识到裁剪丢弃的部分恰恰提供了拉伸的来源，信息流跨越了裁剪边界。需对比多个示例才能确认这一跨半区方向关系。

## 新题 2：模板匹配门控洪泛分类

**组合逻辑**：[形状匹配 shape_match](创新：匹配结果不用于重涂色，而用于分类对象角色) → [洪泛填充 flood_fill](创新：种子与障碍物由匹配结果动态决定) + [重涂色 recolor](创新：匹配对象统一重涂为模板色后作为种子) + [擦除 erase](已有)

**来源原语**：形状匹配/模板/框架/掩码相同/模板选同形重涂(63613498)；洪泛填充/种子像素/障碍物/四邻连通/种子沿连通域扩散(9edfc990)；重涂色(09c534e7)

**依赖链**：模板形状定义匹配标准 → 各散布对象与模板做掩码比对 → 匹配者重涂为模板色成为洪泛种子 → 不匹配者重涂为灰色成为障碍物 → 洪泛填充从种子扩散受障碍物阻挡 → 框架区域最后擦除。匹配结果同时决定了洪泛的源点和拓扑障碍，两步不可分离。

模板形状决定哪些散布对象变为洪泛种子、哪些变为障碍物，从而控制洪泛填充的最终覆盖范围。

**输入结构**：约 18x18 的网格，背景为黑(0)。一个灰(5)L-框位于网格的某个角落（竖边在右、横边在下），框包围的矩形区域内有一个绿(3)的 4-连通小图形（3~5 像素）作为模板。框外散布着 3~5 个不同颜色（蓝(1)、红(2)、黄(4)、橙(7)中的若干种）的 4-连通小图形，每个 3~5 像素，形状各异——其中部分与模板的归一化掩码（平移对齐后的二值形状）完全相同，部分不同。图形之间有足够的黑(0)间距（至少 2 像素），无相互接触。灰(5)墙段（1 像素宽短线段，2~4 像素长）散布在网格中，将黑色背景分隔为若干 4-连通区域。生成约束：至少有一个匹配对象和一个不匹配对象；所有匹配对象通过黑色背景 4-连通相连（移除障碍物前）。

**规则**：
1. 提取灰(5)L-框包围盒内绿(3)图形的归一化掩码（只看形状，忽略平移和颜色）。
2. 对框外每个非背景、非灰色的 4-连通图形，计算其归一化掩码并与模板比较。
3. 掩码匹配的图形：将其所有像素重涂为绿(3)，该图形成为洪泛填充的种子。
4. 掩码不匹配的图形：将其所有像素重涂为灰(5)，该图形成为障碍物。
5. 从所有绿(3)种子像素出发，沿 4-连通黑(0)路径扩散，将到达的黑(0)像素涂为绿(3)。灰(5)像素（含原有墙段、L-框、和新障碍物）阻挡扩散。
6. 将 L-框及其内部区域（含原始模板）全部擦除为黑(0)背景。

**关键洞察**：模板在此处不是选择器（不像 63613498 那样只选中一个匹配对象来重涂），而是分类器——它同时定义了洪泛的种子集合和障碍集合，二者共同决定洪泛的拓扑连通结构。需对比多个示例中不同的匹配/不匹配组合才能归纳出这一分类机制。

## 新题 3：孔洞计数参数化平铺周期

**组合逻辑**：[计数 counting](创新：计数对象是封闭背景孔洞，计数结果用作空间周期参数) + [平铺 tile](创新：周期由外部计数动态决定，而非固定可观测)

**来源原语**：计数/前景对象/封闭背景区域/顺序排列/孔洞面积决定输出(8ba14f53)；平铺/种子图案/矩形空腔/图案填满空腔/保持种子相位(a57f2f04)

**依赖链**：每个前景对象内的封闭孔洞被计数 → 计数结果成为配对空腔中种子图案的水平平铺周期 → 以种子的当前位置为相位锚点进行平铺。计数提供周期参数，平铺消费周期参数；二者缺一不可。

统计每个前景对象内封闭的黑色孔洞数量，将该数量作为其配对矩形空腔中种子图案平铺的列周期。

**输入结构**：约 16x20 的网格，背景为黑(0)。左侧区域有 2~3 个单色 4-连通前景对象（颜色互不相同，取自蓝(1)、红(2)、绿(3)），每个对象由不规则的连通像素构成（像素数约 15~30），内部有 1~3 个封闭的黑(0)孔洞（孔洞 = 被该对象像素完全包围的黑色 4-连通区域，不与包围盒边界上的黑色像素 4-连通）。右侧区域有与之一一对应的矩形空腔：每个空腔由与对应对象同色的 1 像素宽边框围成（内部约 6 列 x 4 行），空腔内部填充黄(4)，并在某处有一个由该对象颜色构成的种子图案（2~3 像素的小连通块）。左侧对象与右侧空腔的配对关系通过颜色相同来确定，且按从上到下的顺序对齐。生成约束：各对象的孔洞数互不相同，以便不同示例能区分；空腔宽度足以容纳至少两个周期。

**规则**：
1. 对左侧每个前景对象，计算其封闭黑(0)孔洞的数量 N（孔洞定义：该对象包围盒内、被对象像素 4-邻域完全封闭的黑色 4-连通区域的个数）。
2. 在右侧找到与该对象同色边框的矩形空腔。
3. 取空腔内种子图案的包围盒作为瓦片，以水平周期 = N 列、垂直周期 = 种子包围盒行数进行周期平铺。平铺相位由种子当前位置锚定（种子不移动，向两侧和上下按周期扩展）。
4. 平铺仅覆盖空腔内黄(4)像素位置；边框像素和种子图案本身不变。若瓦片某位置落在种子颜色像素上则不覆盖。
5. 各对象独立处理，处理顺序不影响结果（空腔互不重叠）。

**关键洞察**：封闭孔洞不被显示或复制——它们的数量被提取为一个数值参数，传递给一个空间上完全不相邻的平铺操作。需对比多个示例中不同孔洞数对应不同平铺疏密程度，才能归纳出"孔洞数 = 列周期"的映射关系。

## 新题 4：路径消耗轨迹经门镜像

**组合逻辑**：[滑动 slide](已有) + [擦除 erase](已有) + [镜像 mirror](创新：镜像对象不是整幅画布而是滑动消耗的路径轨迹，镜像轴由门结构的朝向决定)

**来源原语**：滑动/擦除/标记像素/路径/门结构/四邻接连通/门前停止(182e5d0f)；镜像/拼接(6d0aefbc)

**依赖链**：标记像素沿路径滑动至门前 → 消耗的路径段形成一个多段折线轨迹 → 门结构同时作为滑动终止条件和镜像轴 → 门另一侧的路径被擦除后，由轨迹的镜像副本替换。滑动产出轨迹形状，镜像消费轨迹形状；门结构双重功能不可拆分。

标记沿路径滑动至门前停止，消耗的路径轨迹被镜像到门的另一侧替换原路径。

**输入结构**：约 12x15 的网格，背景为黑(0)。网格中有 1~2 个独立的 4-连通前景组件，每个组件由以下元素构成：(a) 绿(3)路径像素，形成一条单像素宽的连通折线（可含直角转弯，总长 6~12 像素）；(b) 一个灰(5)标记像素位于路径的一个端点；(c) 一个门结构位于路径中间某处——门由三个像素组成：中心像素为绿(3)（属于路径），两端像素为红(2)，三者共线（水平或垂直排列）。路径在门的两侧各延伸若干像素。生成约束：门将路径分为"接近侧"（含标记的一侧）和"远离侧"两段；接近侧路径长度不超过远离侧路径长度（保证镜像后不越界）；路径不与网格边界相邻。

**规则**：
1. 在每个前景组件中，灰(5)标记从其起始位置沿 4-连通绿(3)路径逐步滑向门结构中心旁的绿(3)像素（即与门中心 4-相邻但不在两个红(2)端点之间的那个路径像素）。
2. 标记经过的每个绿(3)路径像素被擦除为黑(0)。标记最终停在门旁像素上（该像素变为灰(5)）。
3. 记录被消耗的路径段的折线形状（从标记起始位置到门旁停止位置的像素序列）。
4. 门另一侧（远离侧）的所有绿(3)路径像素被擦除为黑(0)。
5. 确定镜像轴：若门的三像素水平排列，轴为经过门中心的垂直线；若垂直排列，轴为经过门中心的水平线。
6. 将步骤 3 记录的折线形状关于该轴做镜像，从门中心远离侧的邻接像素开始绘制，颜色为绿(3)。若镜像像素超出网格边界则丢弃。
7. 红(2)门端像素保持不变。门中心绿(3)像素保持不变。

**关键洞察**：门结构在此具有双重功能——既是滑动的终止条件（来自 182e5d0f），又定义了镜像轴的方向（新创结构关系）。消耗路径的具体折线形状（而非仅仅长度）决定了镜像输出的几何细节。需对比多个示例中不同门朝向来归纳镜像轴与门排列方向的垂直关系。

## 新题 5：遮挡排序与中位线对齐融合

**组合逻辑**：[排序 sorting](创新：排序依据不是颜色或大小，而是从重叠遮挡关系中推断的层序) + [对齐 align](创新：对齐参考不来自段自身的属性，而来自中位空间位置) + [重建 reconstruct](已有：从可见碎片恢复完整段)

**来源原语**：堆叠/排序/重建/遮挡碎片/遮挡层序/可见像素定边框(652646ff)；对齐/修剪/线段/平行共向/中位线为参考(e376de54)

**依赖链**：可见碎片 → 推断每段的完整范围和遮挡关系 → 遮挡关系确定输出行顺序 → 中位段（按原始行位置排）提供水平对齐参考 → 所有段截取/延伸至中位段长度 → 按遮挡深度从上到下输出。遮挡推断和中位线选择从同一重叠场景中独立提取，然后在输出阶段汇合。

从重叠的彩色线段场景中同时推断遮挡层序和空间中位线，按遮挡深度排列、对齐到中位线长度后输出。

**输入结构**：约 14x14 的网格，背景为黑(0)。4~5 条水平线段（每条一个像素高），颜色各不相同（取自蓝(1)、红(2)、绿(3)、黄(4)、橙(7)），分布在不同行上。各段的起始列和长度不同（长度 4~10 像素）。关键特征：部分线段在列范围上重叠——即同一像素位置(行, 列)有两条线段经过，此时仅显示顶层线段的颜色（遮挡）。每条线段至少有 2 个像素可见（未被遮挡）。生成约束：线段总数为奇数（保证中位线唯一）；遮挡关系构成全序（任意两条有重叠的段都有确定的上下关系）；段数足够多以确保至少两对有遮挡。

**规则**：
1. 识别每条线段的颜色：可见像素直接给出颜色，被遮挡的像素需从遮挡者确认（若位置 (r,c) 显示颜色 A 但颜色 B 的线段应在行 r' 经过列 c 且该位置显示 A 而非 B，则 A 遮挡 B 在该位置）。实际判断方法：对于在行 r_B 的颜色 B 线段，若其列范围内某列 c 处显示了颜色 A（A 在行 r_A），则 A 遮挡 B。
2. 对所有遮挡关系做拓扑排序，得到从最顶层到最底层的颜色顺序。
3. 按各线段在输入中的行号排序，取中位行的线段作为参考段。记录参考段的起始列 c_start 和长度 L。
4. 输出网格宽 = L，高 = 线段数量。
5. 从输出第一行开始，按遮挡拓扑序（最顶层在第一行、最底层在最后一行）依次绘制每条线段：每段在其输出行中，从第 0 列画到第 L-1 列，颜色为该段的原始颜色。（即所有段都被对齐为相同的起始和长度。）

**关键洞察**：输出的行顺序由遮挡层序决定（非空间位置），但对齐的参考长度由原始空间位置的中位线决定——两种信息从同一重叠场景中独立推断后在输出中融合。需对比多个示例中不同遮挡关系和不同中位行来分别归纳这两条规则。

## 新题 6：缩略图时间序列全尺度外推

**组合逻辑**：[缩放 scale](创新：缩略图不是静态布局图而是多帧时间序列) + [外推 extrapolate](创新：外推的时间信息来自缩略图而非主网格中的面板序列) + [叠加 overlay](已有)

**来源原语**：补全/缩放/缩略图/色块网格/坐标映射/已有块确认对齐(c4d067a0)；外推/叠加/面板序列/模板面板/周期调度/预测下一帧(2ccd9fef)

**依赖链**：缩略图中的多帧序列 → 区分静态像素和动态像素 → 动态像素在帧间的位移模式 → 外推到下一帧 → 缩放到大尺度网格 → 叠加到已有的模板色块上。缩略图提供时间维度，主网格提供空间尺度，外推生成新内容——三个来源缺一不可。

从角落缩略图的多帧序列中推断动态元素的运动规律，在大尺度色块网格上绘制外推的下一帧。

**输入结构**：约 20x20 的网格，背景为黑(0)。左上角有一个小区域（约 4 行 x 12 列），内含 3 个等宽的缩略面板（每个约 4x3 像素），面板之间由灰(5)的 1 像素宽竖线分隔。每个面板内有若干彩色像素（蓝(1)、红(2)、绿(3)等），大部分像素在三帧中位置和颜色不变（静态），少数像素在帧间沿某一方向移动（动态，每帧沿行或列偏移固定步长）。主区域（右下方大部分网格）由均匀的正方形色块（每块 3x3 像素）组成的网格，部分位置有色块（颜色与缩略图中的静态像素对应），部分位置为空（黑(0)）。已有色块与缩略图第三帧中的静态像素的位置存在固定的尺度和偏移映射关系。生成约束：动态像素在缩略图中至少出现 2 帧（可以只在第 2、3 帧出现）以确定位移方向和步长；外推后的动态像素位置仍在主网格范围内。

**规则**：
1. 识别左上角的三个缩略面板（由灰(5)竖线分隔），视为时间帧 1、2、3（从左到右）。
2. 将三帧逐像素比较：每个面板内位置 (r,c) 处的颜色在三帧中一致的为静态像素，颜色出现/消失或位置变化的为动态像素。
3. 利用已有的大尺度色块与帧 3 中静态像素的对应关系，推断坐标映射的缩放因子 S 和偏移 (dr, dc)：缩略图位置 (r,c) 映射到主网格的色块左上角 (dr + r*S, dc + c*S)。
4. 对每个动态颜色，从其在帧 2 和帧 3 中的位置计算逐帧位移向量 (delta_r, delta_c)。若仅在帧 2、3 出现，用两帧差值；若三帧都出现，用帧 2→3 的差值（与帧 1→2 一致时确认线性）。
5. 将动态像素的帧 3 位置加上位移向量，得到帧 4 的缩略图位置。
6. 将帧 4 的每个动态像素位置通过步骤 3 的映射转换为主网格色块位置，在该位置绘制 S x S 的纯色色块。

**关键洞察**：缩略图在此不是空间布局的小地图（如 c4d067a0），而是编码了时间演化的帧序列；主网格也不是包含多帧的面板（如 2ccd9fef），而是只提供空间尺度的静态快照。时间信息和空间尺度信息分别来自不同区域，必须跨区域整合才能生成输出。

2. 对每个嵌套矩形，检查其最外层的任意像素是否与某个蓝(1)像素（含临时标记的）4-相邻。
3. 若 4-相邻（被洪泛"触及"）：对该矩形执行层序反转——按从最外层到最内层的顺序读取各层颜色，然后将层颜色以相反顺序重新赋回各层（最外层获得原最内层颜色，反之亦然，中间层若有则也对称交换）。
4. 若不 4-相邻（未被触及）：该矩形保持原样。
5. 将所有蓝(1)像素（含种子和洪泛标记的）全部擦除为黑(0)背景。

**关键洞察**：洪泛填充在输出中完全不可见——它是一个纯粹的中间计算步骤。求解者必须从输入中矩形的颜色层序与输出中的差异，反推出存在一个不可见的洪泛分类过程。需对比多个示例中不同墙壁配置导致不同矩形被反转/保留，才能归纳出洪泛可达性这一隐藏机制。

7. 对框内被蓝(1)线段完全封闭的黑(0)区域，洪泛填充为蓝(1)。
8. 擦除原始蓝(1)精灵体为黑(0)。橙(7)框不变。

**关键洞察**：标记的左右顺序（一个二元判断）通过两步空间中介传递到拉伸操作的几何参数：顺序 → 出口侧 → 青标记位置 → 与框的距离 → 锚角选择。这条判断链跨越了灰矩形和橙框两个独立结构体，形成远程信息传递。需对比多个示例中红-青顺序翻转导致拉伸结果镜像翻转，才能归纳出完整的传递链。
