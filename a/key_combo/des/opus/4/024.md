## 新题 1：反弹路径分区决定镜像方向

**组合逻辑**：[射线延伸/ray_extend](创新：反弹路径作为分隔墙而非绘制目标) + [洪泛填充/flood_fill](创新：用于确定区域归属而非填色) + [镜像/mirror](创新：镜像方向由所在分区决定而非全局统一)

**来源原语**：射线延伸·边界反射·反弹路径·起点像素（e179c5f4）；洪泛填充·四连通分区·分隔墙·角落锚定（782b5218）；镜像·逐色独立变换·包围盒内翻转·单色掩码（e74e1818）

**依赖链**：反弹路径的几何轨迹决定分区边界 → 分区归属决定每个对象适用哪种镜像 → 镜像方向是路径与对象位置共同推断的结果，三步缺一不可

从蓝(1)起点像素出发沿对角线反弹，用路径把网格切成两个区域；左上角所在区域的对象做垂直翻转，右下角所在区域的对象做水平翻转，最后擦除路径。

**输入结构**：约 13x13 的黑(0)背景网格。恰好有一个蓝(1)像素作为起点，位于网格中部偏下。网格中散布 3~5 个单色前景掩码（每个掩码用一种非蓝、非黑的颜色，如红(2)、绿(3)、黄(4)、品红(6)等），每个掩码是一个 4-连通的不规则小图形（3~7 像素），具有单方向对称性——要么仅有左右对称、要么仅有上下对称、要么完全不对称。各掩码的包围盒互不重叠且不触碰网格边界。生成约束：蓝像素的反弹路径不经过任何掩码像素；路径将网格恰好分为两个 4-连通区域（以路径像素为墙），且每个区域至少包含一个掩码。

**规则**：
1. 从蓝(1)像素出发，每步向上移动一行、水平移动一列（初始方向为右上）。当下一步的列号超出网格左右边界时，水平方向反转（垂直方向不变）。持续移动直到行号超出网格上边界或下边界，路径结束。将路径经过的所有像素标记为蓝(1)。
2. 以蓝路径像素为墙（阻断 4-连通），将所有非蓝像素划分为 4-连通区域。确定包含网格左上角 (0,0) 的区域记为 A 区，包含网格右下角 (H-1,W-1) 的区域记为 B 区。
3. 对每个前景掩码，根据其所有像素所在区域（生成约束保证同一掩码不会横跨两个区域）：
   - 若在 A 区：在该掩码自身的包围盒内做垂直翻转（保持列不变，行 r 映射到 r0 + r1 - r，其中 r0、r1 为包围盒的上下边界行）。
   - 若在 B 区：在该掩码自身的包围盒内做水平翻转（保持行不变，列 c 映射到 c0 + c1 - c，其中 c0、c1 为包围盒的左右边界列）。
4. 擦除所有蓝路径像素，恢复为黑(0)背景。原始蓝起点像素也被擦除。

**关键洞察**：反弹路径不是最终输出的一部分，而是一个中间计算结构——它的几何形状决定了空间分区，分区决定了每个对象的镜像方向。仅看单个示例，无法确定分区规则（可能误以为是按颜色或按位置固定分类）。

## 新题 2：标记朝向解码修复对角序列后外推

**组合逻辑**：[擦除/erase + 重涂色/recolor](创新：标记朝向解码的目标不是下方对象的颜色，而是一维序列中的缺失值) → [外推/extrapolate](创新：外推的前提是序列已被正确修复，修复依赖于标记解码)

**来源原语**：标记朝向编码颜色·重涂色·擦除·标记体（604001fa）；头序列·对角索引映射·循环头序列倍增·平铺·缩放（539a4f51）；补全·外推·前缀匹配（90f3ed37）

**依赖链**：L 标记的朝向编码了被损坏的序列颜色 → 解码后才能修复头序列 → 修复后的序列循环倍增填充加倍网格。删除解码步则序列不完整无法外推；删除外推步则解码无处输出

用 L 形标记的缺角方向解码出对角颜色表中被损坏的颜色，修复头序列后循环倍增，按对角索引规则填充加倍的方阵。

**输入结构**：一个 NxN（N 约 6~8）的方阵，黑(0)背景。方阵遵循对角索引规则填充：位置 (r,c) 的颜色 = 头序列[max(r,c)]。头序列由 2~4 种非黑颜色组成（如红(2)、绿(3)、黄(4)），尾部可能有黑(0)作为空白后缀。其中 1~2 个头序列位置被"损坏"——对应的整条对角带（所有满足 max(r,c)=k 的像素）被替换为黑(0)。每条损坏对角带的外侧相邻位置（不在对角带上、不与其他标记重叠的空白区域）放置一个灰(5)的 2x2 L-三连块标记（即 2x2 方块缺一个角的三像素图形）。每个标记恰好与一条损坏带相邻，且不覆盖任何未损坏的前景像素。生成约束：不同标记之间不重叠；标记仅出现在黑(0)空白区域。

**规则**：
1. 识别所有灰(5)的 2x2 L-三连块标记。每个标记占据一个 2x2 方块中的恰好 3 个像素，缺少的那个角位置编码一种颜色：
   - 缺左上角 → 绿(3)
   - 缺右上角 → 蓝(1)
   - 缺左下角 → 黄(4)
   - 缺右下角 → 红(2)
2. 确定每个标记对应的损坏对角带索引 k（标记所在 2x2 方块中 max(r,c) 最近的那条全黑对角带）。将该对角带的颜色设为标记解码出的颜色。
3. 擦除所有灰(5)标记像素，恢复为黑(0)。
4. 此时头序列已完整（所有黑色后缀之前的位置都有非黑颜色）。去掉尾部黑色后缀，得到有效头序列长度 L。
5. 将有效头序列循环重复，直到长度达到 2L。用这个长度为 2L 的循环序列，按对角索引规则 cell(r,c) = 循环序列[max(r,c)] 填充一个 2L x 2L 的输出方阵。

**关键洞察**：L 标记不是装饰物，它们是修复被破坏的一维序列的密码本；解码错误会导致整个外推结果错误。需要对比多个示例才能确认缺角方位与颜色的映射关系。

## 新题 3：印章扩展构建围墙后洪泛填充封闭区

**组合逻辑**：[像素放大/pixel_scaling + 印章覆盖/stamp_overlay](创新：印章不再是视觉装饰，而是构建拓扑围墙的手段) → [洪泛填充/flood_fill](创新：填充的区域由印章图案的叠加几何涌现而来，非预设分隔线)

**来源原语**：像素放大·印章覆盖·前景掩码·块格阵列·格位映射·边缘像素复制（8719f442）；洪泛填充·四连通分区·分隔墙·角落锚定（782b5218）

**依赖链**：3x3 掩码决定块格阵列和印章位置 → 印章叠加后的前景像素拓扑决定哪些黑色区域被完全包围 → 只有被围住的区域才被填充。掩码形状同时控制"墙建在哪"和"围住什么"，是自指结构

将 3x3 前景掩码扩展为块格阵列并在边缘块外侧印章原始掩码，然后将由印章拓扑围出的封闭黑色区域填充为蓝(1)。

**输入结构**：一个 3x3 网格，黑(0)背景，恰好一种前景颜色（如红(2)），前景像素数为 3~6 个（即 3x3 中 3~6 个位置为红(2)，其余为黑(0)）。生成约束：前景像素的布局需保证在 15x15 画布上经过块格扩展和边缘印章后，至少存在一个被前景像素完全 4-连通包围的黑色区域（即该区域的 4-连通扩展不能到达 15x15 画布的边缘）。

**规则**：
1. 创建一个 15x15 的黑(0)画布。中央 9x9 区域为块格阵列：将 3x3 输入中每个前景像素映射为一个 3x3 的纯色实心块（输入位置 (r,c) → 画布位置 (3+3r, 3+3c) 起始的 3x3 块），颜色与输入像素相同。
2. 对每个输入前景像素，检查它是否位于输入 3x3 网格的边缘（第 0 行、第 2 行、第 0 列或第 2 列）。对于位于边缘的前景像素，在其对应 3x3 实心块的外侧方向上（上边缘→正上方、下边缘→正下方、左边缘→正左方、右边缘→正右方），以该实心块的边缘为基准，将原始 3x3 输入的前景掩码印章一次——印章的中心对齐到实心块在该方向上的邻接位置。印章只绘制前景像素（黑色位置透明不绘制）。若像素同时在两条边缘上（如角落位置），对每个边缘方向各印章一次。
3. 印章和实心块像素颜色相同，重叠处不变。
4. 在完成所有绘制后，将所有前景像素视为墙壁。找出所有黑(0)像素的 4-连通区域。将其中不触碰画布边缘（即 4-连通区域中没有任何像素位于第 0 行、第 14 行、第 0 列或第 14 列）的区域填充为蓝(1)。
5. 保留所有红(2)像素不变。

**关键洞察**：同一个 3x3 掩码既决定了墙的主体骨架（通过块格放大），又决定了墙的延伸细节（通过边缘印章），封闭区域是两者叠加后的拓扑涌现结果——微调掩码中的一个像素可能打破或新增封闭区域。

## 新题 4：角标记外移后生成受框约束的螺旋

**组合逻辑**：[平移/translate](创新：标记外移不再是最终输出，而是为螺旋定位起点) + [螺旋绘制/spiral_drawing](创新：螺旋不从独立中心标记出发，而是从外移后的标记出发；螺旋扩展受矩形框约束而非仅受网格边界约束) + [擦除/erase]

**来源原语**：平移·擦除·空心矩形·角标记·内外对角·标记内角移外角（952a094c）；螺旋绘制·中心标记·调色板·递增步长·边界截断·方向分色（08573cc6）

**依赖链**：框的几何形状决定标记外移的目标位置 → 外移位置决定螺旋起点 → 框的像素又作为螺旋扩展的障碍墙，框同时扮演"定位锚"和"约束壁"两个角色，删任一则输出不确定

将矩形框内角的四个标记移到框外对角位置，从每个外移位置出发画方形螺旋，螺旋遇到框像素或网格边界时截断停止。

**输入结构**：约 15x15 的黑(0)背景网格。包含一个一像素宽的单色空心矩形框（如蓝(1)），框的位置大致居中但不完全对称（上下左右到网格边缘的距离不等，以确保四个螺旋的展开空间各不相同）。框内部的四个角各有一个标记像素，颜色为红(2)。网格左上角位置 (0,0) 和 (0,1) 各有一个调色板像素：(0,0) 为绿(3)（水平螺旋段颜色），(0,1) 为黄(4)（垂直螺旋段颜色）。生成约束：框的每条边至少长 5 像素；框距网格每条边缘至少 3 像素；调色板像素不在框上也不在框内部。

**规则**：
1. 找到蓝(1)矩形框及其内角四像素位置。将四个红(2)角标记从内角移到外角——即框的包围盒向外扩展一格后的四个角位置。清除原始内角的红(2)像素为黑(0)。
2. 读取调色板：(0,0) 的颜色为水平段颜色 C_h = 绿(3)，(0,1) 的颜色为垂直段颜色 C_v = 黄(4)。清除调色板像素为黑(0)。
3. 从每个外移后的红(2)标记位置出发，绘制方形螺旋。螺旋方向序列为：左、下、右、上，循环重复。段长度依次为 2, 3, 4, 5, ...。
4. 绘制每一步时：
   - 水平移动的步用 C_h 着色，垂直移动的步用 C_v 着色。
   - 若下一个像素的位置超出网格边界、或该位置已有蓝(1)框像素、或该位置已有另一条螺旋的像素，则该步截断（不绘制该像素），整条螺旋在此停止（不继续后续段）。
5. 红(2)标记起点像素保留在输出中。蓝(1)框保留不变。
6. 四条螺旋按左上、右上、右下、左下的外角顺序依次绘制（先绘制的螺旋像素会阻挡后绘制的螺旋）。

**关键洞察**：矩形框承担双重角色——既是标记外移的参照系（决定螺旋起点在哪），又是螺旋扩展的物理障碍（阻止螺旋穿越框线）。框的偏心位置使得四条螺旋展开程度各异，需要多个示例才能确认螺旋的方向序列和段长递增规则。

## 新题 5：双色图案对角平铺的重叠冲突染色

**组合逻辑**：[平铺/tile · 对角线偏移复制/diagonal_offset_copy](创新：原始平铺仅含单色前景所以重叠必然一致，此处引入双色前景使重叠可能冲突) + [重涂色/recolor](创新：重涂色由重叠冲突触发，而非由周期列位置触发)

**来源原语**：平铺·对角线偏移复制·前景图案·画布加倍（d13f3404）；重涂色·交替格栅·周期列触发变色（ba26e723）；重涂色·标记朝向编码颜色（604001fa）

**依赖链**：双色图案的空间分布决定了哪些位置在对角平铺时会产生颜色冲突 → 冲突位置被染成第三种颜色。平铺和冲突检测不可分割——不平铺就无冲突，不检测冲突则双色重叠规则不明

将含两种前景色的稀疏图案沿右下对角线反复偏移铺展到加倍画布上，两个副本中不同颜色的前景像素落在同一位置时，该像素变为冲突标记色。

**输入结构**：一个约 5x5 到 7x7 的黑(0)背景网格。前景包含恰好两种非黑颜色（如红(2)和绿(3)），总前景像素数约 4~8 个，稀疏分布。生成约束：两种前景色各至少有 2 个像素；在对角偏移平铺过程中，至少存在一对来自不同副本的像素落在同一位置且颜色不同（即会产生至少一个冲突点）。

**规则**：
1. 设输入尺寸为 HxW。创建一个 2H x 2W 的黑(0)画布。
2. 对 k = 0, 1, 2, ..., 直到 (k < 2H 且 k < 2W)：将输入的前景像素以偏移 (k, k) 印到画布上。即对输入中每个前景像素 (r, c, color)，在画布位置 (r+k, c+k)（若在画布范围内）执行印章。印章规则：
   - 若画布该位置为黑(0)：直接设为该前景颜色。
   - 若画布该位置已有颜色且与当前前景颜色**相同**：保持不变。
   - 若画布该位置已有颜色且与当前前景颜色**不同**：将该位置设为黄(4)（冲突标记色）。
   - 若画布该位置已经是黄(4)（之前已标记为冲突）：保持黄(4)不变。
3. 输入的黑(0)背景像素在印章时透明，不覆盖任何已有内容。

**关键洞察**：冲突点不是图案中任何一种颜色的简单重叠——它们是两种不同颜色的对角相位差的几何干涉图样。仅看单个示例可能以为黄(4)是输入的第三种颜色，需要对比多个示例才能发现黄(4)仅出现在双色重叠位置。

## 新题 6：逐色对称类型检测决定补全方向

**组合逻辑**：[镜像/mirror](创新：镜像不作为变换操作，而是作为对称性检测工具——判断掩码已有的对称类型) → [对称补全/symmetry_completion](创新：补全的方向由检测结果决定，而非由外部标记指定) → [裁剪/crop]

**来源原语**：镜像·逐色独立变换·包围盒内翻转·单色掩码（e74e1818）；对称补全·缺失区域·对称轴·镜像（9ecd008a）；裁剪·前景掩模·边界框包围·裁剪区背景替换（a740d043）

**依赖链**：每个单色掩码已有的对称类型（水平或垂直）决定了它需要沿哪个方向补全（补全另一方向的对称） → 补全改变了掩码几何 → 裁剪依赖补全后的整体前景范围。对称检测是推理链的决策节点，不可跳过

检测每个单色掩码在其包围盒内已具备的对称性类型，然后沿垂直于该对称轴的方向补全缺失像素使其获得双轴对称，最后裁剪并替换背景。

**输入结构**：约 12x14 的灰(5)背景网格（注意背景不是黑(0)）。包含 3~4 个不同颜色的单色前景掩码（如红(2)、蓝(1)、绿(3)、黄(4)），每个掩码是一个 4-连通的小图形（4~8 像素）。各掩码的包围盒互不重叠且互不相邻（包围盒之间至少间隔 1 像素）。生成约束：每个掩码在其自身包围盒内恰好具备一种对称性——要么仅有左右对称（关于包围盒垂直中轴），要么仅有上下对称（关于包围盒水平中轴），绝不同时具有两种或都不具有。不同掩码的对称类型不必相同（鼓励混合）。

**规则**：
1. 对每个非背景颜色的单色掩码独立处理：
   a. 计算该掩码的紧包围盒（最小包含矩形），记上下边界行为 r0, r1，左右边界列为 c0, c1。
   b. 检测对称类型：
      - 左右对称检测：对包围盒内每个掩码像素 (r, c)，检查 (r, c0 + c1 - c) 是否也是掩码像素。全部满足则为左右对称。
      - 上下对称检测：对包围盒内每个掩码像素 (r, c)，检查 (r0 + r1 - r, c) 是否也是掩码像素。全部满足则为上下对称。
   c. 补全另一方向：
      - 若已有左右对称：沿水平中轴补全——对包围盒内每个掩码像素 (r, c)，将 (r0 + r1 - r, c) 也设为该颜色（若原来不是）。
      - 若已有上下对称：沿垂直中轴补全——对包围盒内每个掩码像素 (r, c)，将 (r, c0 + c1 - c) 也设为该颜色（若原来不是）。
2. 所有掩码补全完毕后，找到所有非背景像素的紧包围盒，裁剪网格到该范围。
3. 在裁剪区域内，将所有灰(5)背景像素替换为黑(0)。

**关键洞察**：对称性本身不是变换目标，而是一个分类信号——它告诉你"这个图形缺什么"。仅看单个示例中的一个掩码，无法确定"已有左右对称→补上下"还是"已有左右对称→保持不变"，必须对比多个掩码和多个示例才能归纳出"已有A轴对称则补B轴"的规则。

## 新题 7：前缀补全后按行组计数确定周期高亮

**组合逻辑**：[补全/complete · 外推/extrapolate](创新：补全产生的新像素是后续重涂色的作用对象) + [重涂色/recolor](创新：重涂色的周期不是固定常数，而是由输入的结构属性——行组数量——动态决定)

**来源原语**：补全·外推·行组·列状态序列·前缀匹配·完整模式续写缺失（90f3ed37）；重涂色·交替格栅·列周期·周期列触发变色（ba26e723）

**依赖链**：行组的数量 N 决定重涂色周期 → 但 N 需要先正确识别行组边界 → 补全规则又依赖于顶部参考行组 → 重涂色作用于补全后的像素。数量信息驱动操作参数，计数与补全两步交织

按顶部参考行组的列状态模式补全各下方行组的缺失后缀，然后以下方行组的总数 N 为周期，每隔 N 列将所有前景像素（含新补全的）重涂为品红(6)。

**输入结构**：约 12x16 的黑(0)背景网格。一种前景颜色（如红(2)）构成多个水平行组，行组之间以至少一行全黑分隔。最顶部的行组横跨网格全宽（所有列都有前景像素的某种排列），作为完整参考模式。下方有 N 个行组（N = 2~4），每个从左边缘开始，是参考模式的列状态序列的前缀——即前若干列的上下偏移状态与参考一致，剩余列为空。不同下方行组的前缀长度不同。生成约束：每个下方行组的前缀长度严格短于参考模式的总列数；各行组的行高相同（1~3 行）；N 至少为 2。

**规则**：
1. 识别顶部参考行组：找到最上方的、横跨所有列的行组，提取其每列的行偏移状态序列（从左到右）。
2. 识别下方各行组，按从上到下排列。计数下方行组数量 N。
3. 对每个下方行组，找到其已有前缀覆盖到的最后一列。将参考模式中对应后续列的状态依次填入，使用蓝(1)着色（与原始红(2)区分）。若下方行组的前缀已包含参考模式最终状态，则将该最终状态持续重复至右边缘。
4. 补全完成后，对整个网格执行周期高亮：对每个列索引 c，若 c mod (N+1) == 0，则将该列上所有非黑像素（无论是原始红(2)还是补全蓝(1)）重涂为品红(6)。
5. 不在高亮列上的像素保持原色不变。

**关键洞察**：重涂色的列周期 N+1 不是视觉上可直接读取的常数，而是通过计数输入中的行组数量间接推导的——行组越多，高亮列越密。仅看单个示例可能把周期当作固定值，必须对比不同 N 的示例才能发现周期随行组数量变化。

## 新题 8：角落对象顺时针复制后构建最近种子填充

**组合逻辑**：[复制/copy](创新：复制的目的不是产出最终图案，而是重新定位种子区域) + [最近扩散/nearest_fill](创新：种子不是预设的水平条，而是由复制操作动态生成的前景对象) + [擦除/erase](创新：干扰项标记被移除以避免污染种子集)

**来源原语**：复制·角落对象·顺时针到下一角·接触两边缘·忽略干扰项（bc93ec48）；最近扩散·填充·种子条·最近种子分区·等距异色为分隔（332202d5）；擦除（952a094c）

**依赖链**：识别哪些是角落对象、哪些是干扰项 → 角落对象顺时针复制改变种子空间布局 → 种子布局决定最近扩散的 Voronoi 分区图样 → 干扰项必须先移除否则污染种子集。分类、复制、扩散三步共同决定输出

识别角落对象并顺时针复制到下一角，移除非角落的干扰项像素，然后以所有保留的前景对象为种子进行最近扩散填充，等距异色处设为分隔色。

**输入结构**：约 13x13 的黑(0)背景网格。包含 2~4 个单色 4-连通前景对象，每个对象 4~10 像素，颜色各不相同（如红(2)、绿(3)、蓝(1)、黄(4)）。其中恰好有 2~3 个对象是"角落对象"——其包围盒同时触碰两条相邻的网格边缘（如左边缘和上边缘，即锚定在左上角）。剩余 1~2 个对象不触碰任何网格边缘或仅触碰一条边缘，为干扰项。每个角落最多有一个角落对象。生成约束：至少有一个角落是空的（即没有角落对象），以便接收顺时针复制；各对象的包围盒互不重叠。

**规则**：
1. 识别角落对象：包围盒同时触碰两条相邻网格边缘的 4-连通对象。其余前景对象为干扰项。
2. 将所有干扰项像素擦除为黑(0)背景。
3. 对每个角落对象，将其像素掩码和颜色复制到顺时针方向的下一个角落（左上→右上、右上→右下、右下→左下、左下→左上）。复制时将包围盒对齐到目标角落。若目标角落已有对象（原始角落对象），复制像素覆盖已有像素。原始角落对象保留不清除。
4. 所有复制完成后，将网格中所有前景像素（原始角落对象 + 复制体）视为种子区域。
5. 对每个黑(0)背景像素，计算其到每个种子区域的曼哈顿距离（到该区域中最近像素的曼哈顿距离）。将该背景像素填充为最近种子区域的颜色。
6. 若某背景像素到两个不同颜色的种子区域距离相等且都是最近的，则将该像素设为灰(5)作为分隔线。
7. 若距离相等的最近种子颜色相同（同一颜色出现在原始和复制体中），则正常填充该颜色，不设为分隔线。

**关键洞察**：顺时针复制改变了种子的空间分布，使得最近填充的 Voronoi 分区与仅看原始对象位置时截然不同。干扰项的存在迫使求解者先正确分类对象再执行后续操作——如果误将干扰项当作种子，整个填充图案都会出错。
