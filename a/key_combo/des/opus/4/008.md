## 新题 1：簇大小射线

**组合逻辑**：[计数](创新：计数对象从完整方块改为同色簇像素数) + [射线延伸](创新：射线长度由簇大小决定而非无限延伸) + [碰撞停止](已有) ← 条件：[种子色决定延伸](创新：从二元方向扩展为四元基数方向)

**来源原语**：计数(3b4c2228), 射线延伸(178fcbfb), 种子色决定延伸(178fcbfb), 碰撞停止(88e364bc)

**依赖链**：簇的像素数量决定射线长度 → 簇的颜色决定射线方向 → 多条射线在网格中可能碰撞截断 → 三层信息交织使得缺少任何一层都无法确定输出

每个同色像素簇沿其颜色指定的基数方向发射一条长度等于簇像素数的射线，射线遇到其他射线或非背景像素时提前截断。

**输入结构**：黑(0)背景，约 15x15 网格。散布 3~6 个 4-连通同色小簇（每簇 2~5 个像素，形状不规则），颜色限于红(2)、蓝(1)、绿(3)、黄(4)四种。同一颜色可出现多个簇。各簇之间至少间隔 2 个背景像素。生成约束：每个簇沿其对应方向延伸后，射线路径上至少有一段不被其他簇遮挡的空间，以确保输出可见。

**规则**：
1. 识别网格中所有 4-连通同色前景簇，统计每个簇的像素数 N。
2. 颜色→方向映射：红(2)→上，蓝(1)→右，绿(3)→下，黄(4)→左。
3. 对每个簇，找到其边界框的"发射端"像素：上方向取簇最上行所有像素，右方向取簇最右列所有像素，下方向取簇最下行所有像素，左方向取簇最左列所有像素。
4. 从每个发射端像素出发，沿对应方向逐格绘制该簇的颜色，共绘制 N 格（不含发射端像素本身）。若某格已被非背景像素占据（包括其他射线先前绘制的像素或其他簇的像素），该射线在该格前停止，不绘制该格。若某格超出网格边界，该格跳过但仍计入 N 格计数。
5. 处理顺序：按簇的边界框左上角坐标行优先排序（行相同则列小的先处理）。
6. 原始簇像素保持不变。

**关键洞察**：射线的长度不是固定的或无限的——它等于发射簇的像素数目。必须对比多个示例中不同大小的簇才能归纳出"簇大小 = 射线长度"这一隐藏规则。

## 新题 2：形状匹配决定重力缓冲

**组合逻辑**：[形状匹配 + 压缩 + 旋转反射等价](已有) → 决策分支 → [重力下落](已有，创新：缓冲行为由匹配结果决定) + [缓冲行间距](创新：从全局统一行为改为条件性行为)

**来源原语**：形状匹配 + 压缩 + 旋转反射等价(bd14c3bf), 重力下落 + 缓冲行间距(825aa9e9), 障碍物(825aa9e9)

**依赖链**：形状匹配的布尔结果控制重力下落的终止条件——匹配者获得缓冲悬停，不匹配者直接着陆——形成"分类→差异化物理行为"的决策结构

将所有非原型对象向下做重力下落；压缩后形状与原型匹配（允许旋转和镜像）的对象悬停在障碍物上方一行，不匹配的对象直接贴靠障碍物。

**输入结构**：黑(0)背景，约 18x14 网格。底部有一条灰(5)水平障碍行（占据最底 1~2 行，宽度等于网格宽度）。网格左上角有一个橙(7)原型对象（4-连通单色小图形，3~6 像素，可能含有行列方向的拉伸冗余）。网格上半区散布 4~6 个蓝(1)候选对象（4-连通单色小图形，3~8 像素，形状各异，部分含行列拉伸冗余）。各候选对象之间水平间隔至少 2 列，不重叠。生成约束：至少有一个候选对象的游程压缩掩码与原型的游程压缩掩码在旋转/镜像下相同，至少有一个不同。

**规则**：
1. 裁剪原型对象到其边界框，折叠相邻相同行和相邻相同列，得到原型压缩掩码。
2. 对每个蓝(1)候选对象执行相同的裁剪-折叠操作，得到候选压缩掩码。
3. 判断每个候选压缩掩码是否为原型压缩掩码的某个旋转（0/90/180/270度）或镜像的结果。
4. 所有候选对象在各自所在列范围内向下做重力下落（逐行下移直到不能继续）：
   - **匹配对象**：其最底行像素停在距灰(5)障碍物顶面 2 行的位置（即对象底部与障碍物之间留 1 行空背景作为缓冲）。
   - **不匹配对象**：其最底行像素停在紧贴灰(5)障碍物顶面的位置（无缓冲，直接相邻）。
5. 若两个对象下落后会在垂直方向重叠（列范围有交集），上方对象视下方对象为障碍物，遵守相同的缓冲/无缓冲规则。处理顺序：按对象原始位置从低到高（行号大的先处理）。
6. 原型对象保持在原始位置不动。匹配的候选对象在着陆后重涂为绿(3)，不匹配的保持蓝(1)。

**关键洞察**：悬停与否不取决于对象颜色或大小，而取决于其压缩后的拓扑形状是否与原型匹配。必须对比多个示例中不同形状对象的着陆位置差异，才能发现形状匹配是区分行为的判据。着陆后的重涂色进一步确认了分类结果。

## 新题 3：图例打破间隙对称

**组合逻辑**：[编码映射 + 边界图例](创新：图例编码的方向不再控制像素滑动，而是决定间隙中哪一侧矩形获得延伸权) → [射线延伸 + 间隙对半分](创新：从对称双向填充改为图例指定的单向填充)

**来源原语**：编码映射 + 边界图例(88e364bc), 射线延伸 + 间隙对半分 + 矩形(d968ffd4), 奇数间隙留中线(d968ffd4)

**依赖链**：图例中的方向编码确定哪个矩形拥有延伸权 → 被指定的矩形向对侧延伸填满间隙 → 未被指定的矩形保持不动 → 图例信息与间隙几何结构深度耦合

每对同色矩形之间的间隙不再对称填充，而是由对应颜色的边界图例指定哪一侧矩形独占整个间隙的填充权。

**输入结构**：黑(0)背景，约 16x16 网格。网格内部有 2~3 对同色实心矩形（每对矩形颜色相同但不同对颜色不同，使用蓝(1)、绿(3)、红(2)等）。每对矩形共享相同的行跨度或列跨度，面向边之间有背景间隙（间隙宽度 3~7 格）。网格最外圈边缘（上边或左边）放置 2~3 个小矩形图例，每个图例是一个 3x3 的填色方块，填色与某对矩形的颜色匹配。每个图例内部有一个中心像素为栗(9)、一个相邻像素为橙(7)作为方向指示（橙(7)在栗(9)的上/下/左/右之一）。生成约束：每对矩形恰好对应一个图例；图例方向仅为面向矩形间隙的两个方向之一（如矩形左右排列，图例方向只可能是左或右）。

**规则**：
1. 识别网格内部所有同色矩形对。对每对，确定它们的排列方向（水平并列或垂直并列）和间隙区域。
2. 对每对矩形的颜色 C，在边缘找到填色为 C 的图例。读取图例内栗(9)中心到橙(7)指示点的偏移向量（上/下/左/右之一）。
3. 将该偏移向量解释为"延伸权归属方向"——向量指向哪一侧，哪一侧的矩形获得延伸权：
   - 水平排列的矩形对：图例方向为"右"→ 右侧矩形获得延伸权；图例方向为"左"→ 左侧矩形获得延伸权。
   - 垂直排列的矩形对：图例方向为"下"→ 下方矩形获得延伸权；图例方向为"上"→ 上方矩形获得延伸权。
4. 获得延伸权的矩形将自身颜色填充整个间隙区域（间隙的行/列跨度与矩形对的共享跨度一致）。未获得延伸权的矩形保持不变。
5. 当间隙像素数为奇数时，间隙的正中行或正中列保持为背景色，延伸只填充从获权矩形面向边到中线之前的部分。
6. 图例本身在输出中保持不变。各对矩形独立处理，不同对之间无交互。

**关键洞察**：间隙不再平分给两侧——图例的方向编码打破了对称性，将整个间隙（或奇数间隙的大半部分）判给一侧。必须对比多个示例中图例方向与实际填充侧的对应关系，才能归纳出图例方向 = 获权矩形所在侧这一规则。

## 新题 4：缺角方向重力

**组合逻辑**：[重力下落](创新：下落方向从垂直向下改为对角方向) ← [对角偏移 + 缺角](创新：缺角不再产生静态副本，而是决定重力方向) + [源色决定方向](创新：颜色决定沿缺角方向还是反缺角方向下落) + [碰撞停止](已有)

**来源原语**：重力下落(825aa9e9), 对角偏移 + 缺角 + 源色决定方向(1e5d6875), 碰撞停止(88e364bc/36a08778), 重涂色(1e5d6875)

**依赖链**：三连块的几何属性（缺角位置）确定对角方向 → 三连块的颜色决定沿该方向还是反方向移动 → 移动持续到碰撞停止 → 几何属性、颜色属性和物理模拟三重耦合

每个 L 形三连块沿其缺角对角线方向做重力滑动，灰色沿缺角方向滑，红色沿反缺角方向滑，碰撞后停止并重涂色。

**输入结构**：黑(0)背景，约 14x14 网格。散布 4~7 个 L 形三连块（每个占据 2x2 方格中的 3 个像素，缺少一个角），颜色为灰(5)或红(2)。网格中另有若干青(8)固定障碍像素（单独像素或小块，不超过 3 个像素的簇），分布在网格中下部区域。各三连块之间至少间隔 3 个背景像素。生成约束：每个三连块沿其对应对角方向移动时，路径上最终有障碍物或网格边界可以阻挡，保证所有三连块最终停下。

**规则**：
1. 对每个三连块，确定其 2x2 边界框中缺失像素的位置，该位置相对于边界框中心的方向即为"缺角对角方向"（右下、左下、右上、左上之一）。
2. 灰(5)三连块的移动方向 = 缺角对角方向（例如缺角在右下角，则向右下滑动）。红(2)三连块的移动方向 = 缺角对角方向的反方向（例如缺角在右下角，则向左上滑动）。
3. 每个三连块沿其移动方向逐步对角平移（每步行+1或-1，列+1或-1）。当三连块的任何像素在下一步将到达网格外、覆盖青(8)障碍像素、或覆盖另一个已停止的三连块像素时，该三连块在当前位置停止。
4. 处理顺序：沿各自移动方向的前方距离最近的障碍物或边界的三连块先处理（即最先会停下的先处理）。若距离相同，按原始位置行优先排序。
5. 三连块停止后，清除其原始位置像素（设为背景），在新位置绘制。灰(5)三连块停止后重涂为黄(4)，红(2)三连块停止后重涂为绿(3)。
6. 青(8)障碍像素始终不变。

**关键洞察**：三连块不是垂直下落，而是沿对角线方向滑动，方向由自身几何结构（缺角位置）决定。红色和灰色虽然缺角位置相同也会走相反方向——必须对比多个示例中不同颜色、不同缺角方位的三连块的实际移动轨迹，才能同时归纳出缺角→方向和颜色→正/反两条耦合规则。

## 新题 5：格内重力压缩平铺

**组合逻辑**：[重力下落](创新：重力范围从全局改为格子槽位内部) → [压缩](创新：压缩对象从全局色带改为槽位内部沉积层) → [填充](创新：填充模式由压缩后的序列循环平铺而非单色填充)

**来源原语**：格子框架 + 格子槽位(2e65ae53), 重力下落(825aa9e9), 压缩 + 连续重复折叠(746b3537), 填充 + 槽位位置决定颜色(2e65ae53)

**依赖链**：局部重力确定颜色分层顺序 → 压缩提取去重色序 → 色序作为平铺模板填充整个槽位 → 三步变换中每一步的输出是下一步不可省略的输入

格子框架内每个槽位中的散落像素先局部下沉，沉积层压缩为去重色序后，该色序自底向上循环平铺填满整个槽位。

**输入结构**：黑(0)背景，约 16x16 网格。一个红(2)单像素线条构成的矩形格子框架，将网格分为 2x2 或 2x3 的槽位阵列。每个槽位内部面积约 4x4 到 6x6（不含框架线）。每个槽位内散布 3~8 个前景像素，颜色为蓝(1)、绿(3)、黄(4)、橙(7)中的 2~3 种，分布在槽位内的不同行列位置。同一槽位内同一行不会出现两个不同颜色的像素。生成约束：每个槽位内至少有 2 种颜色；各槽位的散落像素颜色组合可以不同。

**规则**：
1. 对每个槽位独立操作。将槽位内所有前景像素在槽位范围内做重力下落：每个像素沿列向下移动，直到碰到槽位底边框或另一个已沉底的像素为止。
2. 下落完成后，槽位底部形成若干水平色层。从底向上读取每一行的颜色（每行只有一种前景色或为空），跳过空行，得到一个有序颜色序列。
3. 对该序列做连续去重：相邻相同颜色合并为一个，得到压缩色序 S（例如 [蓝,蓝,绿,绿,蓝] → [蓝,绿,蓝]）。
4. 用 S 自底向上循环填充槽位全部行：槽位最底行填 S[0] 的颜色，次底行填 S[1]，依此类推；当 S 用完后循环回 S[0] 继续。每一行中，该行所有属于槽位内部的像素都涂为对应颜色。
5. 红(2)格子框架线条保持不变。框架外的背景保持不变。
6. 各槽位之间完全独立，互不影响。

**关键洞察**：散落像素的空间分布本身不携带层序信息——只有先做局部重力下沉才能确定颜色的上下叠放顺序。去重步骤进一步剥离了厚度信息，只保留颜色交替模式。这个交替模式反过来成为整个槽位的平铺花纹，从而将几个散落像素放大为一整块周期性色带。

## 新题 6：滤后计数参数化螺旋

**组合逻辑**：[计数](已有) ← [完整方块过滤 + 忽略干扰项](已有) → 参数化 → [螺旋绘制](创新：螺旋基准步长由计数结果决定而非固定为 2) + [遇障碍停止](已有)

**来源原语**：计数 + 完整方块过滤 + 忽略干扰项(3b4c2228), 螺旋绘制 + 遇障碍停止(e5c44e8f), 种子像素(e5c44e8f/178fcbfb)

**依赖链**：过滤区分有效方块与干扰项 → 有效方块计数 N 决定螺旋的基准步长 → 螺旋从种子出发按该步长绘制 → 过滤/计数的准确性直接决定螺旋的几何形态，任一环节出错则输出完全不同

统计有效绿色 2x2 方块的数目 N，以 N 为基准步长从种子像素出发绘制螺旋，螺旋遇到障碍像素时截断。

**输入结构**：黑(0)背景，约 18x18 网格。网格中散布若干绿(3)对象和若干红(2)对象：绿(3)对象有两类——完整 2x2 方块和不完整的孤立像素或非方形簇（1~3 像素）；红(2)对象均为单像素或小簇（1~2 像素），作为干扰项。另有一个黄(4)单像素作为螺旋种子，和若干品红(6)单像素作为障碍。绿(3)完整方块数量为 1~4 个。种子与各方块/障碍之间至少间隔 2 个背景像素。生成约束：螺旋在碰到障碍物之前至少能绘制出 2 条完整的边，以便输出有足够的螺旋结构可观察。

**规则**：
1. 识别所有绿(3) 4-连通对象。对每个对象检测其边界框是否恰好为 2x2 且面积恰好为 4（即完整 2x2 方块）。不满足条件的绿(3)对象和所有红(2)对象均为干扰项，不参与计数。
2. 统计完整绿(3) 2x2 方块的数目 N。
3. 从黄(4)种子像素出发，按方向序列"上→右→下→左"循环绘制螺旋。步长序列为：N, N, 2N, 2N, 3N, 3N, 4N, 4N, ...（即第 k 对边的步长为 kN，每个步长使用两次）。
4. 沿当前方向逐格移动。对每一格：若超出网格边界，跳过该格但计入步长消耗；若格内为背景(0)，涂为黄(4)；若格内为品红(6)障碍像素，停止整个螺旋绘制（不涂该格）；若格内为其他非背景像素，跳过该格但计入步长消耗。
5. 原始的绿(3)方块、绿(3)干扰项、红(2)干扰项、品红(6)障碍像素均保持不变。黄(4)种子像素保持不变。

**关键洞察**：螺旋的松紧程度（基准步长）不是固定的——它等于有效绿色方块的数量。只观察螺旋形状无法确定步长规律，必须同时注意到背景中散落的绿色方块并正确地过滤和计数，才能将计数结果与螺旋几何联系起来。

## 新题 7：形状分类边缘归位

**组合逻辑**：[形状匹配 + 旋转反射等价 + 游程压缩后比较](已有) → 分类决策 → [平移 + 排序](创新：排序依据从边框颜色改为形状匹配结果) + [距离优先排序 + 行重叠内移](已有)

**来源原语**：形状匹配 + 旋转反射等价 + 游程压缩后比较(bd14c3bf), 平移 + 排序 + 距离优先排序 + 行重叠内移(b5ca7ac4), 边框方块(b5ca7ac4), 原型对象(bd14c3bf)

**依赖链**：内部图案的压缩匹配结果取代颜色作为分类依据 → 分类决定目标边缘（左/右）→ 排序与碰撞避让使用已有的距离优先和行重叠规则 → 分类环节与排位环节缺一不可

边框方块根据其内部图案是否与原型匹配来决定移向左边缘还是右边缘，同侧方块按距边缘远近依次排列，行重叠时向内偏移。

**输入结构**：黑(0)背景，约 20x20 网格。散布 4~6 个灰(5)边框的 5x5 方块（边框为灰(5)外圈，内部 3x3 区域填有蓝(1)像素构成的图案，图案各不相同，占据 3x3 中的 3~7 个像素）。另有一个橙(7)边框的 5x5 方块作为原型，其内部 3x3 区域也有蓝(1)图案。各方块之间不重叠，至少间隔 1 列。生成约束：至少 2 个灰(5)方块的内部图案在游程压缩后与原型匹配（允许旋转/镜像），至少 1 个不匹配。网格宽度足够容纳同侧最多 3 个方块并列。

**规则**：
1. 裁剪每个方块的内部 3x3 蓝(1)图案。对每个图案和原型图案分别做游程压缩（折叠相邻相同行和列）。
2. 判断每个灰(5)方块的压缩图案是否为原型压缩图案在 0/90/180/270 度旋转或水平/垂直镜像下的某个变体。
3. 匹配的灰(5)方块 → 移向左边缘（方块左列对齐到列 0），保持原始行位置。不匹配的灰(5)方块 → 移向右边缘（方块右列对齐到最右列），保持原始行位置。
4. 同侧方块的处理顺序：左侧组按原始列从小到大（离左边近的先处理），右侧组按原始列从大到小（离右边近的先处理）。
5. 若一个方块在放置时其行跨度与同侧已放置方块的行跨度有重叠（任何一行同时被两个方块占据），则该方块向内偏移一个方块宽度（5 列）。若偏移后仍有重叠，继续偏移。
6. 原型方块（橙(7)边框）保持在原始位置不动，不参与移动。清除所有灰(5)方块的原始位置（设为背景），在新位置绘制。

**关键洞察**：方块的归属边缘不由其自身的边框颜色决定（所有候选方块的边框颜色都相同），而由其内部 3x3 图案与原型的拓扑匹配结果决定。必须同时理解形状匹配规则和边缘排位规则，二者缺一不可。

## 新题 8：压缩序位决定延伸长度

**组合逻辑**：[压缩 + 条带方向 + 连续重复折叠](已有) → 序位提取 → [射线延伸](创新：射线长度由种子在压缩色序中的位置决定) + [边界内延续](已有)

**来源原语**：压缩 + 条带方向 + 连续重复折叠(746b3537), 射线延伸 + 种子像素(178fcbfb), 边界内延续(0b17323b)

**依赖链**：色带压缩提取颜色序列 → 种子颜色在压缩序列中的位序决定射线长度 → 射线方向由色带方向的垂直轴确定 → 压缩分析和射线生成深度耦合，跳过压缩则无法确定长度

将色带压缩为去重色序后，每个种子像素沿垂直于色带方向发射射线，射线长度等于该种子颜色在压缩色序中的位序（1-索引）。

**输入结构**：黑(0)背景，约 12x16 或 16x12 网格。网格的主体区域由全宽水平色带或全高垂直色带填充（色带颜色使用蓝(1)、绿(3)、黄(4)、橙(7)中的 3~5 种，每条色带厚度 1~3 行/列，部分颜色可能连续出现多条形成重复段）。色带中嵌入 3~5 个品红(6)种子像素，每个种子位于某一色带内部，替换该色带的一个像素。被替换的色带像素的原色即为种子的"归属颜色"——通过种子所在行/列的色带颜色确定。生成约束：压缩色序长度不超过 6；每种出现在色序中的颜色至少有一个对应的种子像素。

**规则**：
1. 判断色带方向：若所有行内像素颜色一致（忽略种子像素）则为水平色带，否则为垂直色带。
2. 用种子所在行/列中非种子像素的颜色还原每个种子的归属色带颜色。
3. 将色带序列按行从上到下（水平色带）或列从左到右（垂直色带）读取颜色，做连续去重，得到压缩色序 S（例如 [蓝,蓝,绿,黄,黄,绿] → [蓝,绿,黄,绿]）。
4. 对每个种子像素，查找其归属颜色在 S 中首次出现的位序 P（1-索引）。
5. 每个种子沿垂直于色带方向的正方向发射射线：水平色带时向右发射，垂直色带时向下发射。射线长度为 P 格（从种子位置的下一格开始计数，共 P 格）。
6. 射线绘制为品红(6)。若射线某格超出网格边界则停止（不绘制超出部分）。射线不会被色带像素阻挡——直接覆盖色带颜色绘制为品红(6)。
7. 种子像素本身保持为品红(6)。色带中未被射线覆盖的像素保持原色。

**关键洞察**：色带的厚度是冗余信息，对射线长度没有贡献——只有压缩后颜色序列中的位序才决定长度。不同色带厚度组合的示例会产生不同的压缩序列和不同的位序映射，必须先正确完成压缩才能确定射线参数。
