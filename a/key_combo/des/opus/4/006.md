## 新题 1：可达性门控的空腔拼图

**组合逻辑**：[泛洪填充](已有) + [嵌入填充](已有) → 可达性作为空腔过滤器（创新：泛洪结果重新定义匹配池）

**来源原语**：泛洪填充/flood_fill（8f3a5a89）、嵌入填充/inlay_fill（5dbc8537）、墙壁障碍/wall_barrier（8f3a5a89）、矩形空腔/rectangular_cavity（5dbc8537）、精灵体/sprite（5dbc8537）、角落标记/corner_marker（8f3a5a89）、可达性/reachability（8f3a5a89）、唯一槽位配对/unique_slot_pairing（5dbc8537）、边界连通区分结构/border_connected_distinguishes_structural（8f3a5a89）

**依赖链**：泛洪填充确定哪些空腔可达 → 可达性过滤改变空腔集合 → 过滤后的空腔集合改变精灵体匹配关系 → 匹配关系决定每个精灵体的放置位置。删除泛洪填充则所有空腔都参与匹配，导致错误配对；删除尺寸匹配则无法确定放置。

从墙壁围成的模板中筛选出可达空腔，仅将外部精灵体嵌入这些可达空腔中，不可达空腔被封死。

**输入结构**：约 18x18 的网格，背景黑(0)。蓝(1) 像素构成一个大型模板框架，框架内部挖有 3-5 个矩形空腔（各空腔尺寸互不相同，范围约 2x3 到 4x5）。蓝(1) 墙壁同时在框架内部形成额外的封闭隔墙，使得部分空腔被完全包围在隔墙内部（从框架外部无法通过背景像素到达）。网格某一角落放置一个品红(6) 单像素标记。框架外部散布着若干小型彩色精灵体（使用红(2)、绿(3)、黄(4) 等颜色，每个精灵体为 3-8 像素的 4-连通单色图形，各精灵体形状各异），精灵体数量等于空腔总数。生成约束：每个精灵体的边界框尺寸恰好与某一个空腔的尺寸匹配（宽高完全相等），且匹配关系在所有空腔参与时为一对一；但当不可达空腔被封死后，剩余的可达空腔仍然与某些精灵体构成一对一匹配，多余的精灵体（其唯一匹配空腔被封死）无处安放。

**规则**：
1. 从品红(6) 标记像素出发，对背景色黑(0) 像素做泛洪填充（4-连通），蓝(1) 墙壁阻挡扩散。
2. 一个空腔是"活跃的"当且仅当其内部至少有一个背景像素被泛洪填充到达。完全被墙壁封死的空腔为"不可达"——将其所有内部像素填充为蓝(1)，使其融入墙壁。
3. 对每个活跃空腔，找到边界框尺寸（宽x高）与之完全相等的外部精灵体（匹配唯一）。
4. 将匹配的精灵体放置到对应空腔中，精灵体左上角对齐空腔左上角。
5. 没有匹配到活跃空腔的多余精灵体从网格中擦除（还原为背景色）。
6. 擦除品红标记像素。输出为模板框架的边界框区域。

**关键洞察**：墙壁同时扮演两个角色——定义空腔的边界和控制泛洪填充的可达性。一个几何上完好的空腔可能因为被隔墙包围而不可达，从而被移出匹配池。精灵体的最终归宿取决于拓扑可达性，而非几何距离或颜色。

## 新题 2：周长排序驱动的跨对象借色

**组合逻辑**：[计数](已有，创新为周长计数) + [重涂色](已有) → 全局排名建立非局部借色关系（创新：排名奇偶性决定自色/借色）

**来源原语**：计数/counting（fcc82909）、重涂色/recolor（67385a82）、连通分量/connected_component（67385a82）、标记像素/marker_pixel（多题）、面积比较/area_comparison（67385a82）、轮廓邻接/contour_adjacency（97c75046）

**依赖链**：计算每个对象的周长 → 周长排序建立全局序 → 排名奇偶性决定涂色策略（自色 vs 借色）→ 借色需要查找排名邻居的标记颜色。删除周长计算则无法排序；删除排序则无法确定奇偶；删除借色规则则退化为单逻辑直接涂色。

根据前景对象周长的全局排名，奇数名次对象涂自身标记色，偶数名次对象借用排名上方邻居的标记色。

**输入结构**：约 14x14 的网格，背景黑(0)。网格中散布 4-6 个灰(5) 的 4-连通前景对象，每个对象由 3-12 个像素组成，形状各异（无两个对象形状相同），对象之间互不相邻（任意两个对象之间至少隔一个背景像素）。每个对象内部恰好包含一个非灰非黑的"标记像素"——标记颜色取自 {红(2), 绿(3), 蓝(1), 黄(4)}，每种颜色在所有对象中至多使用一次。生成约束：所有对象的周长互不相等（无平局）。

**规则**：
1. 对每个灰(5) 对象，计算其周长：该对象中与背景像素或网格边界 4-相邻的边的总数（即对象像素的外露边计数）。
2. 将所有对象按周长升序排列，得到排名 1, 2, 3, ...（周长最小者排名第 1）。
3. 奇数排名的对象（第 1、3、5 ...名）：将该对象中所有灰(5) 像素重涂为其自身标记像素的颜色。
4. 偶数排名的对象（第 2、4、6 ...名）：将该对象中所有灰(5) 像素重涂为排名比自己小 1 的那个对象（即排名上方邻居）的标记像素颜色。
5. 所有标记像素本身保持不变（不被重涂）。

**关键洞察**：每个对象的最终颜色取决于一个全局几何排名，而非空间邻近性或颜色本身。偶数排名的对象必须"跨空间"去查找另一个对象的标记色，而这个借色关系由所有对象的周长共同决定——改变任何一个对象的形状都可能重排名次，从而改变多个对象的输出颜色。

## 新题 3：对角噪声修复揭示渗透性分区填充

**组合逻辑**：[擦除](已有) + [补线](已有) + [填充](已有) → 修复痕迹决定分区边界渗透性（创新：被修复的分隔段成为填充的可渗透边界）

**来源原语**：擦除/erase（7b80bb43）、补线/line_completion（7b80bb43）、填充/fill（272f95fa）、直线段/straight_line_segment（7b80bb43）、对角噪声/diagonal_noise（7b80bb43）、分隔线/divider_bar（272f95fa）、分区区域/partitioned_region（272f95fa）、网格分区/grid_partition（272f95fa）、忽略干扰项/ignore_distractors（7b80bb43）、间隙长度限制/gap_length_constraint（7b80bb43）

**依赖链**：识别并擦除对角噪声 → 噪声的空间跨度决定修复间隙长度 → 修复后的线段形成完整分区 → 被修复过的分隔段标记为"可渗透" → 种子色从种子区域出发，只能穿过可渗透边界扩散到相邻区域。删除噪声擦除则无法定位间隙；删除补线则分区不完整；删除渗透性规则则退化为简单全局填充。

擦除对角噪声并修复断裂的分隔线，修复痕迹使该段边界变为可渗透，种子颜色沿可渗透边界传播填充相邻区域。

**输入结构**：约 13x13 的网格，背景黑(0)。灰(5) 像素构成两条水平线和两条垂直线，这四条线本应各自横跨网格的整个宽度或高度，将网格分割为 3x3 共 9 个矩形区域。但每条线上恰好有一个间隙（连续缺失 1-3 个灰像素）。每个间隙旁边紧邻一簇红(2) 像素，这些红像素排列成 45 度对角链，链的像素数等于对应间隙的长度。9 个区域中恰好有一个区域包含一个种子像素（单像素，颜色为绿(3)、蓝(1) 或黄(4) 之一）。生成约束：不同间隙的对角链互不重叠；种子像素不在灰线上。

**规则**：
1. 删除所有红(2) 对角噪声像素（还原为背景色）。
2. 对每条灰线上的间隙，用灰(5) 填充修复，使线段完整横跨网格。间隙长度由该间隙旁已删除的对角链像素数确定。记录哪些分隔段是被修复过的（"可渗透段"）。
3. 修复后的四条线将网格分割为 9 个矩形区域。
4. 找到包含种子像素的区域，将该区域内所有背景像素填充为种子颜色。
5. 填充传播：对每个已填充区域，检查其与相邻区域之间的共享分隔段。如果该共享段包含至少一个被修复过的像素（可渗透段），则将相邻区域也填充为种子颜色。重复此传播直到没有新区域可被填充。
6. 分隔线本身（灰像素）保持不变。

**关键洞察**：对角噪声承担三重职能——标记断裂位置（用于擦除）、编码间隙长度（用于修复）、以及决定分区边界的渗透性（用于填充传播）。最终的填充图案不是由种子的空间位置决定的，而是由原始断裂的拓扑分布决定的：种子只能"穿过"曾经断裂过的边界。

## 新题 4：面积过滤后的缺角定向印章

**组合逻辑**：[擦除](已有) + [印章覆盖](已有) + [镜像](已有) → 面积过滤清除干扰项后，缺角位置与精灵体重心共同决定翻转方向（创新：双因素定向）

**来源原语**：印章覆盖/stamp（ac0c5833）、镜像/mirror（ac0c5833）、擦除/erase（多题）、三角标记框/three_corner_frame（ac0c5833）、精灵体/sprite（ac0c5833）、孤立像素/isolated_pixel（67385a82）、缺角定位/missing_corner_pos（ac0c5833）、面积比较/area_comparison（67385a82）、缺角决定翻转/flip_by_missing_corner（ac0c5833）、多像素涂色留单/multi_recolor_single（67385a82，反用）、唯一槽位配对/unique_slot_pairing（5dbc8537）

**依赖链**：面积过滤分离真精灵体与干扰单像素 → 过滤后的精灵体通过边界框尺寸匹配三角标记框 → 缺角位置确定翻转象限 → 精灵体内部像素分布（重心象限）与缺角象限的关系决定具体翻转方式 → 翻转后的精灵体印章到缺角位置。删除面积过滤则干扰像素污染匹配池；删除缺角检测则无法确定方向；删除重心判断则翻转不唯一。

过滤掉孤立单像素干扰后，将每个精灵体按尺寸匹配到三角标记框，根据缺角方位和精灵体重心共同决定翻转方向后印章放置。

**输入结构**：约 16x16 的网格，背景黑(0)。黄(4) 单像素构成若干组三角标记框：每组三个黄像素位于一个轴对齐正方形的三个角上（第四个角缺失），共 2-4 组，各组边长互不相同（边长范围 3-6）。网格中散布若干红(2) 像素：部分红像素构成多像素的 4-连通精灵体（3-10 像素，形状不规则），部分红像素是孤立的单像素（与其他红像素不 4-连通）。多像素精灵体的数量等于三角标记框的数量，且每个精灵体的边界框边长恰好等于某一个框的边长（匹配唯一）。生成约束：每个精灵体的像素分布不关于水平轴或垂直轴对称（确保翻转后形状可区分）；孤立红像素不位于任何三角标记框的缺角位置。

**规则**：
1. 识别所有红(2) 的 4-连通分量。将面积为 1 的分量（孤立单像素）擦除为背景色。
2. 对每个剩余的红精灵体，计算其边界框的边长（取宽和高中的较大值）。将该边长与各三角标记框的边长匹配（一对一）。
3. 对每个匹配的三角标记框，确定缺角位于正方形的哪个象限（左上、右上、左下、右下）。
4. 对匹配的精灵体，计算其"重心象限"：以精灵体边界框中心为原点，统计四个象限中哪个象限包含最多的精灵体像素，该象限即为重心象限。
5. 翻转规则：若重心象限与缺角象限在水平方向相反，则水平翻转精灵体；若在垂直方向相反，则垂直翻转。两个方向独立判断，可同时翻转、单向翻转或不翻转。
6. 将翻转后的精灵体印章放置到缺角位置，使精灵体边界框的与缺角同侧的角与缺角点重合。
7. 输出保留黄标记像素和所有印章后的红精灵体，其余为背景色。

**关键洞察**：孤立红单像素是干扰项——它们的边界框边长为 1，可能与某些小框匹配，必须先用面积测试排除。翻转方向由两个独立因素共同决定（框的缺角位置 + 精灵体的内部像素分布），仅看一个示例无法分辨是哪个因素在起作用，必须对比多个示例中不同缺角方位与不同精灵体形状的组合。

## 新题 5：前缀映射在路径网络分支上的色彩补全

**组合逻辑**：[补全/前缀映射](已有，创新为作用于网络分支而非行) + [重涂色](已有) → 分支补全结果影响枢纽涂色（创新：枢纽颜色由补全后的分支邻接统计决定）

**来源原语**：补全/complete（82819916）、重涂色/recolor（800d221b）、路径网络/path_network（800d221b）、中心枢纽/hub_square（800d221b）、种子区域/seed_region（800d221b）、模板行/template_row（82819916）、前缀片段/prefix_segment（82819916）、邻接传色/adjacency_color_transfer（800d221b）、列对齐/col_alignment（82819916）、前缀色映射补全行/prefix_map_complete（82819916）、邻接计数决定色/adjacency_count_determines_color（800d221b）

**依赖链**：识别模板分支的双色模式 → 每个非模板分支的前缀与模板对齐提取色彩映射 → 用映射补全整条分支 → 补全后统计各分支颜色对枢纽的邻接量 → 枢纽中心像素涂为邻接最多的分支颜色。删除模板识别则无映射来源；删除前缀映射则分支无法补全；删除枢纽涂色则缺少全局汇聚步骤。

一条完整着色的模板分支提供双色模式，其余分支用各自的前缀推导色彩映射后补全，枢纽中心色由补全后邻接统计决定。

**输入结构**：约 16x16 的网格，背景黑(0)。灰(5) 像素构成一个薄型正交路径网络（线宽 1 像素），网络中心有一个 3x3 的实心灰(5) 枢纽方块。从枢纽向外延伸 3-5 条分支，每条分支为水平或垂直的直线段（长度 4-8 像素，不含枢纽部分）。其中恰好一条分支（"模板分支"）全段使用两种颜色的交替图案着色（例如红(2) 和蓝(1) 交替），替换了该分支上的灰像素。其余每条分支在靠近枢纽的一端有 2 个像素被着色为该分支自己的颜色对（"前缀"，例如绿(3) 和黄(4)），其余部分仍为灰(5)。生成约束：每条分支的前缀恰好覆盖模板分支的两种颜色各至少一次（即前缀长度 >= 2 且包含两种不同颜色）；各分支的颜色对互不相同。

**规则**：
1. 识别模板分支：网络中唯一一条完全不含灰(5) 的分支。提取其双色交替模式（记两种颜色为 A 和 B，按从枢纽端向外的顺序排列）。
2. 对每条非模板分支，将其前缀像素与模板分支的对应位置（从枢纽端起第 1、第 2 个像素）逐位对齐：模板位置的颜色 A 对应前缀的颜色 X，模板位置的颜色 B 对应前缀的颜色 Y。这定义了该分支的色彩映射 {A→X, B→Y}。
3. 将模板模式按该映射转换，铺满整条分支（从枢纽端向外，若分支比模板长则循环平铺模板模式后再映射）。
4. 补全所有分支后，对枢纽的中心像素（3x3 枢纽正中的那个像素）进行涂色：统计所有分支中与枢纽 4-相邻的像素（即每条分支最靠近枢纽的那个像素）的颜色，取出现次数最多的颜色涂到枢纽中心。若平局，取在所有分支上出现总像素数更多的颜色。
5. 枢纽的其余 8 个像素保持灰(5) 不变。

**关键洞察**：行补全技术被重新部署到空间路径网络上——每条分支是一个方向各异的"行"，前缀映射必须沿分支方向对齐而非沿网格列对齐。枢纽颜色不是预设的，而是由补全结果的统计涌现出来的，形成"分支补全→枢纽涂色"的信息流：不完成所有分支的补全，就无法确定枢纽颜色。

## 新题 6：嵌套层展开与选择性镜像重组

**组合逻辑**：[展开嵌套](已有) + [镜像](已有) → 方向指示器的位置和内容分别编码镜像轴与层选择（创新：双通道编码的控制信号）

**来源原语**：展开嵌套/unfold_nest（8fff9e47）、镜像/mirror（ac0c5833）、嵌套层/nested_layer（8fff9e47）、象限/quadrant（8fff9e47）、块序映射层序/block_order_maps_layer（8fff9e47）、逆序读取/reverse_order_read（8fff9e47）、缺角定位/missing_corner_pos（ac0c5833，概念借用）

**依赖链**：提取嵌套层序列 → 方向指示器的角落位置确定镜像轴 → 方向指示器的颜色与最外层颜色的匹配关系确定哪些层被镜像 → 选择性镜像各层 → 将处理后的层重新组装为嵌套结构。删除展开则无法逐层处理；删除指示器解码则不知道镜像哪些层以及沿哪个轴；删除重组则无输出。

将同心嵌套方环逐层展开，根据角落方向指示器的位置决定镜像轴、根据指示器颜色与最外层的匹配关系决定哪些层参与镜像，最后将选择性镜像后的层重组为嵌套结构。

**输入结构**：约 9x9 或 11x11 的网格（奇数边长，确保有唯一中心像素），背景黑(0)。网格中心区域有一个同心嵌套的方环图案，共 3-4 层（从外到内），每层为 1 像素厚的正方形环，各层颜色互不相同，取自 {红(2), 绿(3), 蓝(1), 黄(4), 灰(5)}。最内层可以是一个单像素的实心中心。在网格的某一个角落（远离嵌套图案的位置），放置一个 1x2（水平）或 2x1（垂直）的"方向指示器"小条，由两个不同颜色的像素组成。生成约束：指示器的两个颜色中恰好有一个与嵌套最外层的颜色相同；指示器与嵌套图案之间有至少 1 像素的背景间隔。

**规则**：
1. 识别同心嵌套图案，按从外到内的顺序提取各层（层 1 = 最外环，层 N = 最内层或中心像素）。
2. 找到方向指示器（角落中的 1x2 或 2x1 双色小条）。根据指示器所在的角落确定镜像轴：
   - 左上角或右下角 → 沿垂直轴镜像（左右翻转）每个被选中的层。
   - 右上角或左下角 → 沿水平轴镜像（上下翻转）每个被选中的层。
3. 确定哪些层被选中镜像：指示器中两个颜色像素，其中一个与最外层颜色相同（"匹配色"），另一个不同（"指令色"）。若匹配色在指示器中更靠近网格中心（即更靠近嵌套图案的方向），则选中奇数层（1, 3, 5 ...）进行镜像；若指令色更靠近网格中心，则选中偶数层（2, 4, 6 ...）进行镜像。
4. 对选中的层施加步骤 2 确定的镜像变换。未选中的层保持不变。
5. 将所有层（含已镜像和未镜像的）重新组装回同心嵌套结构，输出到与输入相同大小的网格中（去掉方向指示器）。

**关键洞察**：方向指示器通过两个独立的信息通道编码两个独立参数——空间位置编码镜像轴，颜色排列编码层选择。对于正方形环来说，单独的水平或垂直镜像仅在环上的像素颜色不对称时可见（例如环的某一边有缺口或异色标记），因此层内部需要有不对称细节才能使镜像效果可观察。必须对比多个示例中不同指示器位置和颜色排列的组合才能分离两个编码通道。

## 新题 7：轮廓滑动的语义停止条件

**组合逻辑**：[滑动](已有) + [符号解码](已有) + [擦除](已有) → 符号解码结果作为滑动的停止条件（创新：几何运动的终止由嵌入式语义信号控制）

**来源原语**：滑动/slide（97c75046）、符号解码/symbol_decoding（17cae0c1）、擦除/erase（多题）、标记像素/marker_pixel（97c75046）、障碍轮廓/obstacle_contour（97c75046）、符号掩码/symbol_mask（17cae0c1）、轮廓邻接/contour_adjacency（97c75046）、符号映射颜色/symbol_to_color_mapping（17cae0c1）、最长贴边路径/longest_adjacent_path（97c75046）

**依赖链**：标记像素沿视线到达障碍 → 沿障碍轮廓滑动 → 滑动过程中遇到嵌入在障碍表面的符号掩码 → 解码每个经过的符号 → 当解码颜色与标记像素颜色匹配时停止滑动。删除滑动则标记不移动；删除符号解码则无停止条件（退化为走到尽头）；删除颜色匹配则不知在哪个符号停止。

标记像素沿障碍轮廓滑动，逐一解码嵌入在轮廓上的符号掩码，在解码颜色与标记色匹配时停止。

**输入结构**：约 14x14 的网格，背景黑(0)。一个连通的灰(5) 障碍区域占据网格中部（面积约 30-50 像素，形状不规则但无孔洞）。障碍的外轮廓上，在若干等距位置嵌入了 2x2 的符号掩码：每个掩码占据轮廓上的 2x2 区域，由黑(0) 和黄(4) 像素构成二值图案（4 种可能的图案，分别解码为红(2)、绿(3)、蓝(1)、橙(7)）。符号掩码嵌入在障碍表面——即掩码中黄(4)像素替换了原本的灰(5)像素，掩码中黑(0)像素也替换了灰(5)像素（形成凹陷）。一个单像素标记位于障碍外部的背景区域中，颜色为红(2)、绿(3)、蓝(1) 或橙(7) 之一，与其中某个符号的解码色相同。标记像素与障碍之间存在唯一的水平或垂直无阻挡视线。生成约束：沿轮廓顺时针方向，解码色匹配标记色的符号不是第一个遇到的符号（至少经过一个不匹配的符号后才遇到匹配符号）；符号掩码的 4 种图案到 4 种颜色的映射在所有示例中一致（作为需要归纳的隐蔽规则）。

**规则**：
1. 将标记像素沿其唯一视线方向移动，直到到达障碍轮廓旁的最后一个背景像素（即与障碍 4-相邻的背景像素）。
2. 从该位置开始，标记沿障碍外轮廓顺时针滑动（保持与障碍的 4-邻接）。
3. 每当标记到达一个与符号掩码 4-相邻的位置时，解码该 2x2 掩码：将黄(4)/黑(0) 的二值图案查表得到一个颜色。
4. 若解码颜色等于标记像素的颜色，标记停止滑动，固定在当前位置。
5. 擦除标记的原始位置（还原为背景色）。将标记绘制在停止位置。
6. 擦除所有符号掩码——将掩码中的黄(4) 像素还原为灰(5)，掩码中的黑(0) 像素也还原为灰(5)，恢复障碍为完整的灰色区域。

**关键洞察**：轮廓滑动的停止条件不是几何性的（不是走最长路径或走到端点），而是语义性的——标记必须"阅读"沿途的符号，找到与自身颜色匹配的那一个才停下。符号到颜色的映射是一条隐蔽规则，必须通过多个示例（不同标记颜色、不同符号排列）才能归纳出编码表。

## 新题 8：完整方块检测门控的边缘带选择性转移

**组合逻辑**：[标记](已有) + [平移/边缘带转移](已有) + [擦除](已有) → 方块完整性检测同时门控两个不同操作（创新：一个条件判断分叉驱动标记和转移两个输出）

**依赖链**：检测所有前景对象的方块完整性 → 完整方块触发角外标记 → 同时，完整方块的列/行范围决定边缘带的哪些段被激活转移 → 转移的段移动到对边 → 非完整对象不触发任何操作。删除完整性检测则不知道哪些对象是方块；删除标记则输出缺少角外指示；删除带转移则输出缺少边缘信息。

检测前景中的完整方块对象，为它们添加角外标记并将与它们对齐的边缘带段转移到对边，非方块对象不触发任何操作。

**输入结构**：约 15x15 的网格，背景黑(0)。网格的上边缘有一条 2 像素厚的灰(5) 水平边缘带（占据第 0-1 行，横跨整个网格宽度）。网格内部（第 2 行以下）散布 3-5 个蓝(1) 单色前景对象，对象之间互不接触。其中部分对象是完整方块（边界框为正方形且边界框边框上所有像素均为蓝色，包含实心方块和空心方框），其余为非方块形状（如 L 形、T 形、不规则连通体等）。边缘带中嵌有若干红(2) 标记像素，每个红像素的列坐标与某个前景对象的边界框列范围重叠。生成约束：每个完整方块的边界框列范围内恰好有 1-2 个红标记像素；非方块对象的列范围内也可能有红标记像素（干扰）。

**规则**：
1. 识别所有蓝(1) 的 4-连通前景对象。对每个对象判断是否为完整方块：边界框是正方形，且边界框的四条边上所有像素位置均被蓝像素占据。
2. 对每个完整方块，在其四个角的外侧各绘制两个绿(3) 像素：每个角的正上方和正下方各一个（若角在网格边缘导致某个位置越界则跳过该位置）；每个角的正左方和正右方各一个（同样跳过越界位置）。即每个角最多贡献 2 个绿像素（一个沿该角所在行的水平外侧，一个沿该角所在列的垂直外侧），总计每个方块最多 8 个绿像素。
3. 确定需要转移的边缘带列：一列边缘带被"激活"当且仅当该列处于某个完整方块的边界框列范围内。
4. 将所有被激活的边缘带列（包括其中的灰(5) 和红(2) 像素）从上边缘（第 0-1 行）复制到下边缘（最后两行），保持列位置不变。
5. 擦除上边缘中被激活列的所有像素（还原为背景色）。未被激活的边缘带列保留在上边缘不动。
6. 擦除所有红(2) 标记像素（无论是否被转移，最终输出中不含红像素）。

**关键洞察**：方块完整性检测是一个共享的门控条件，它同时控制两个独立的输出效果——角外绿标记（局部几何操作）和边缘带转移（全局空间操作）。非方块对象列范围内的红标记像素是干扰信号：它们存在于边缘带中，但由于对应对象不是完整方块，其列不会被激活转移。只有理解了方块检测才能正确区分哪些边缘段移动、哪些保留。

## 新题 9：互补拼合排序由符号解码控制

**组合逻辑**：[平移/裁剪/互补拼合](已有) + [符号解码](已有) → 几何拼合与符号编码独立求解后在组装阶段汇合（创新：并行子问题的结果合并）

**依赖链**：两对互补精灵体各自独立拼合为矩形（几何子问题）→ 符号掩码解码为颜色序列（编码子问题）→ 解码颜色与精灵体颜色的匹配决定两个矩形的上下排列顺序。删除拼合则无矩形可排列；删除符号解码则排列顺序不确定；两者缺一不可。

**输入结构**：约 12x16 的网格，背景黑(0)。网格分为左、中、右三个区域。左区和右区各有一对同色精灵体（左区一对为红(2)，右区一对为蓝(1)）。每对精灵体由两个互补形状组成——二者可以通过平移（不旋转）无重叠地拼合为一个实心矩形（矩形尺寸约 3x4 到 5x6），每个精灵体为 4-12 像素的 4-连通不规则图形。中间区域纵向排列两个 3x3 的符号掩码（上下排列，间距 1-2 行），每个掩码由黑(0) 和灰(5) 像素构成二值图案。每个符号解码为一种颜色（解码表在示例间一致）。生成约束：两个符号解码出的颜色恰好分别为红(2) 和蓝(1)（对应左区和右区的精灵体颜色），但上下顺序不固定。

**规则**：
1. 在左区中，找到两个红(2) 精灵体。尝试所有平移组合，找到使二者无重叠拼合后边界框内黑像素最少的放置方式（最密堆叠），得到红色拼合矩形。
2. 在右区中，对两个蓝(1) 精灵体执行同样的最密拼合操作，得到蓝色拼合矩形。
3. 解码中间区域的两个 3x3 符号掩码，将灰(5)/黑(0) 二值图案查表转换为颜色。上方符号解码得到颜色 C_top，下方符号解码得到颜色 C_bottom。
4. 按照符号顺序垂直堆叠两个拼合矩形：颜色匹配 C_top 的矩形放在上方，颜色匹配 C_bottom 的矩形放在下方。两个矩形左对齐，上下紧邻（无间隔行）。
5. 输出仅包含堆叠后的区域（裁剪到最小边界框）。

**关键洞察**：这道题包含两个独立的子问题——几何拼合（找最密堆叠）和符号解码（查表），二者在求解过程中互不依赖，但最终答案需要两者的结果汇合。拼合决定了矩形的内容和尺寸，符号决定了谁在上谁在下。任何一个子问题解错都会导致最终输出错误。

## 新题 10：滑动桥接改变墙壁拓扑后的泛洪分区

**组合逻辑**：[滑动](已有，创新为"桥接滑动") + [泛洪填充](已有) + [擦除](已有) → 滑动改变墙壁连通性 → 连通性决定墙壁存亡 → 存活墙壁决定泛洪结果（创新：三步级联拓扑变换）

**来源原语**：滑动/slide（97c75046）、泛洪填充/flood_fill（8f3a5a89）、擦除/erase（8f3a5a89）、标记像素/marker_pixel（97c75046）、墙壁障碍/wall_barrier（8f3a5a89）、角落标记/corner_marker（8f3a5a89）、障碍轮廓/obstacle_contour（97c75046）、可达性/reachability（8f3a5a89）、边界连通区分结构/border_connected_distinguishes_structural（8f3a5a89）、轮廓邻接/contour_adjacency（97c75046）

**依赖链**：红标记像素沿视线滑动到最近墙壁旁 → 滑动后的红像素成为墙壁延伸段，可能将孤立墙壁碎片桥接到边界连通墙壁上 → 判断每段墙壁是否边界连通（直接或通过桥接间接连通到网格边缘）→ 擦除所有非边界连通的墙壁碎片 → 从角落标记泛洪填充 → 不可达区域填充为橙色。删除滑动则桥接不发生，墙壁拓扑不变；删除边界连通判断则不知擦除哪些墙壁；删除泛洪填充则无法确定不可达区域。

红标记像素滑向最近墙壁形成桥接，桥接改变墙壁碎片的边界连通性，非边界连通碎片被擦除，最终从角落泛洪填充标记不可达区域。

**输入结构**：约 14x14 的网格，背景黑(0)。蓝(1) 像素构成墙壁：部分墙壁段连接到网格边缘（"结构性墙壁"），部分墙壁是游离在网格内部的短碎片（"装饰性碎片"，不与任何边缘连通的 4-连通蓝像素团，每个碎片 2-5 像素）。若干红(2) 单像素散布在网格中，每个红像素与最近的蓝墙壁之间存在一条无阻挡的水平或垂直视线（视线上无其他非背景像素）。一个品红(6) 单像素位于网格的某个角落。生成约束：至少有一个红像素的滑动会将某个装饰性碎片桥接到结构性墙壁上（即红像素滑动后落在某个碎片与某段结构墙壁之间的间隙中，使二者通过红像素 4-连通）；至少有一个装饰性碎片无论如何都不会被桥接（最终会被擦除）；红像素的数量为 2-4 个。

**规则**：
1. 对每个红(2) 像素，确定其到最近蓝(1) 墙壁像素的最短正交视线方向（水平或垂直，选距离最短的方向；若水平和垂直距离相等，选水平方向）。
2. 将每个红像素沿该方向滑动，直到它与蓝墙壁 4-相邻为止（停在墙壁旁的最后一个背景像素位置）。红像素留在停止位置，原始位置还原为背景色。
3. 每个滑动后的红像素视为墙壁的延伸——将其颜色改为蓝(1)，使其成为墙壁的一部分。
4. 重新计算所有蓝像素的 4-连通分量。一个分量是"边界连通的"当且仅当它包含至少一个位于网格边缘（第 0 行、最后一行、第 0 列或最后一列）的像素。
5. 擦除所有非边界连通的蓝像素分量（还原为背景色）。
6. 从品红(6) 角落标记出发，对背景色黑(0) 像素做 4-连通泛洪填充，蓝墙壁阻挡扩散。
7. 将所有未被泛洪到达的背景像素填充为橙(7)。擦除品红标记像素（还原为背景色）。

**关键洞察**：红标记像素是"桥梁建造者"——它们通过滑动到墙壁旁边，可能将原本孤立的装饰性碎片连接到边界连通的结构性墙壁上，从而"拯救"碎片免于被擦除。被拯救的碎片作为新的墙壁参与后续的泛洪阻挡，改变了不可达区域的形状。一个距离碎片很远的红像素不产生桥接效应；一个恰好落在碎片与结构墙壁之间间隙中的红像素则彻底改变输出的拓扑结构。三步操作（滑动→连通判断→泛洪）形成严格的级联依赖：每一步的输出都实质性地改变下一步的输入。
