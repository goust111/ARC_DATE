## 新题 1：对角阴影射线交汇着色

**组合逻辑**：[偏移阴影](创新：从单步偏移扩展为沿对角线的连续射线) + [计数](创新：统计同一像素被多少条射线覆盖) → [重涂色](创新：覆盖次数决定输出颜色)

**来源原语**：偏移阴影/offset_shadow (310f3251)、计数/counting (6455b5f5, e8593010)、重涂色/recolor (6455b5f5, e8593010)、面积决定颜色/area_determines_color (e8593010, 创新改造为"交汇数决定颜色")

**依赖链**：射线路径由前景像素的位置唯一确定 → 多条射线在空间上交汇产生不同的覆盖深度 → 覆盖深度值决定该像素的最终颜色。三步之间信息逐层聚合：位置→几何路径→数值计数→颜色映射。

每个前景像素沿左上对角线射出阴影射线，射线交汇点根据交汇条数着不同颜色。

**输入结构**：约 12x12 的黑(0)背景网格。散布 3~5 个孤立的蓝(1)前景像素，位于网格内部（不在第一行或第一列）。任意两个蓝像素不在同一条左上-右下对角线上（即对于任意两个蓝像素 (r1,c1) 和 (r2,c2)，r1-c1 != r2-c2），以保证每条射线来自唯一像素。不同示例中蓝像素的数量和位置不同。

**规则**：
1. 对每个蓝(1)像素 (r, c)，沿左上对角线方向逐格延伸射线：依次经过 (r-1,c-1), (r-2,c-2), ...，直到行或列到达网格边界（行<0 或列<0）。在射线路径上的每个像素处累加一次"被覆盖"计数。
2. 所有射线标记完毕后，对每个被射线覆盖的像素检查累计覆盖次数。
3. 覆盖次数恰好为 1 的像素涂红(2)。覆盖次数为 2 及以上的像素涂绿(3)。
4. 原始蓝(1)像素保持不变，不被射线颜色覆盖。
5. 未被任何射线覆盖的背景像素保持黑(0)。

**关键洞察**：绿(3)像素只出现在多条射线的汇聚处——当两个蓝像素位于同一条右上-左下对角线上（即 r1+c1 = r2+c2）时，它们的左上射线会在某段共享同一条左上-右下对角线路径。求解者必须先识别射线方向，再理解颜色区分的是覆盖深度而非距离或来源。

## 新题 2：十字线分区面积着色

**组合逻辑**：[射线延伸] + [异源交叉特殊着色](保留交叉标红) → [面积比较](创新：比较的不是预设分区，而是射线自身生成的分区) → [极值区域分别涂色](保留极值着色逻辑)

**来源原语**：射线延伸/ray_extend + 标记像素/marker_pixel + 行列交叉/row_column_crossing + 异源交叉特殊着色/cross_source_special_color (45bbe264)；面积比较/area_comparison + 极值区域分别涂色/extreme_regions_recolor + 封闭区域/enclosed_region + 分隔线/divider_line (6455b5f5)

**依赖链**：标记像素的位置决定十字线的行列坐标 → 十字线的坐标决定网格分区的几何形状 → 分区面积的极值排名决定填充颜色。标记位置同时编码了两类信息（视觉线条 + 分区结构），后者不可直接观察。

标记像素生成十字线并在交叉处着红，十字线将网格分为矩形区域，最小区域填绿、最大区域填蓝。

**输入结构**：约 15x15 的灰(5)背景网格。2~3 个孤立的非红、非灰标记像素，颜色各不相同（如蓝(1)、黄(4)、橙(7)），各自位于不同行不同列。标记像素不紧贴网格边缘（至少距边界 2 格），以保证所有分区面积非零。不同示例中标记数量、颜色和位置不同。

**规则**：
1. 对每个标记像素，将其所在整行和整列的所有像素涂为该标记的颜色（标记像素自身保持原色）。
2. 当来自不同标记的行线或列线交叉于同一像素时，该交叉像素涂红(2)。同一标记的行线与列线交叉处保持该标记颜色。
3. 将十字线视为分隔线，统计每个被分隔线围合的矩形区域内的灰(5)像素数作为该区域的面积。网格边界也算围合边。
4. 面积最小的区域（可能并列）内部全部灰(5)像素填绿(3)。面积最大的区域（可能并列）内部全部灰(5)像素填蓝(1)。面积既非最小也非最大的区域保持灰(5)。
5. 若所有区域面积相同，则全部保持灰(5)不变。
6. 分隔线像素（含交叉红像素和标记原色像素）不参与面积计算，也不被填充覆盖。

**关键洞察**：标记像素偏离网格中心越远，其生成的分区面积差异越悬殊。分区面积并非在输入中可直接看到，而是标记位置的隐式几何结果。求解者必须先归纳十字线规则，再发现分区着色取决于面积极值。

## 新题 3：嵌套层次展开为切比雪夫同心环

**组合逻辑**：[嵌套层次] + [排序](保留面积排序) → [交叉点中心](创新：中心不来自十字交点，而来自最内层形状的边界框中心) → [填充](创新：以切比雪夫距离环方式铺满全网格) + [颜色循环](创新：循环周期由嵌套颜色序决定)

**来源原语**：压缩/compress + 排序/sorting + 嵌套层次/nesting_hierarchy + 嵌套形状/nested_shape + 面积序映射环/area_order_to_ring (eb5a1d5d)；填充/fill + 偶数切比雪夫距离/even_chebyshev_distance + 交叉点中心/intersection_center (759f3fd3)；颜色循环/color_cycle (221dfab4)

**依赖链**：嵌套结构的几何检测确定颜色序列和内层中心 → 中心位置决定距离场的原点 → 颜色序列的长度决定距离环的周期 → 三者联合确定每个像素的输出颜色。改变任何一个嵌套层都会同时改变颜色序列和周期。

检测输入中嵌套形状的层次顺序和最内层中心，以该中心为原点用嵌套颜色的循环填充全网格切比雪夫距离环。

**输入结构**：约 15x15 的黑(0)背景网格。3~4 个不同颜色的单色形状（如红(2)、蓝(1)、绿(3)），每个形状是一个 4-连通区域，形状轮廓不规则（非标准矩形），像素数 5~30 不等。这些形状严格嵌套：每个形状的边界框完全包含在更大形状的边界框内部，且任意两个形状的像素不重叠。最内层形状的边界框中心不与网格中心重合。不同示例中嵌套层数、颜色和形状不同。

**规则**：
1. 检测所有非黑(0)的 4-连通区域，按边界框面积（宽x高）从大到小排序，确定嵌套顺序。记颜色序列为 C1（最外层）、C2、...、Cn（最内层），共 n 层。
2. 取最内层形状边界框的中心像素作为环心。若边界框宽度为偶数，中心列取左侧中间列；若高度为偶数，中心行取上侧中间行。
3. 对网格中每个像素 (r, c)，计算其到环心 (cr, cc) 的切比雪夫距离 d = max(|r-cr|, |c-cc|)。
4. 距离 d 对应的颜色为：先建立从内到外的颜色序列 [Cn, Cn-1, ..., C1]，然后 d 对应颜色 = 序列[d mod n]。即 d=0 着 Cn，d=1 着 Cn-1，...，d=n-1 着 C1，d=n 着 Cn（循环）。
5. 输出网格完全由距离环覆盖，原始嵌套形状全部擦除。

**关键洞察**：输入中的嵌套层次和颜色被"解码"为一个从中心向外展开的周期性同心方环。嵌套形状的具体轮廓完全无关——只有嵌套序（决定颜色周期）和最内层位置（决定环心）影响输出。需要对比不同嵌套层数的示例才能归纳出循环规则。

## 新题 4：角控制像素平移后重叠深度着色

**组合逻辑**：[角位指示方向] + [平移](保留对角平移) → [计数](创新：统计平移后像素重叠深度) → [重涂色](创新：重叠深度分级着色)

**来源原语**：平移/translate + 填充矩形/filled_rectangle + 控制像素/control_pixel + 角位指示方向/corner_indicates_dir + 对角固定步移/diagonal_fixed_step (470c91de)；计数/counting + 面积决定颜色/area_determines_color (e8593010，创新改造为重叠深度决定颜色)；重涂色/recolor (6455b5f5)

**依赖链**：控制像素的角位决定每个矩形的平移向量 → 平移结果决定矩形的新位置 → 新位置的重叠关系决定每个像素的覆盖深度 → 深度值映射为输出颜色。控制像素同时编码了方向信息和缺失角的修复信息。

每个矩形按其青色角控制像素所指方向对角平移一格，平移后重叠区域按覆盖层数涂不同颜色。

**输入结构**：约 14x14 的黑(0)背景网格。3~5 个不同颜色的填充矩形（如红(2)、蓝(1)、黄(4)、橙(7)），每个矩形至少 3x3。每个矩形恰好有一个角像素被替换为青(8)控制像素。平移前矩形互不重叠且不相邻。生成约束：平移后至少有两个矩形发生部分重叠。不同示例中矩形数量、大小、颜色和控制像素位置不同。

**规则**：
1. 对每个矩形，将青(8)像素视为其缺失角——先将青像素恢复为矩形的主色以补全矩形，然后按青像素所在角的方向对角平移 1 格（青在左上角则向左上平移 1 格，青在右下角则向右下平移 1 格，以此类推）。
2. 擦除所有原始矩形位置（含青像素）为黑(0)。
3. 在每个矩形的新位置绘制补全后的矩形。超出网格边界的部分裁掉。
4. 统计每个像素被多少个平移后矩形覆盖（重叠深度）。
5. 深度 = 1 的像素保持覆盖它的矩形的原始颜色。深度 = 2 的像素涂灰(5)。深度 >= 3 的像素涂品红(6)。
6. 未被任何矩形覆盖的像素保持黑(0)。

**关键洞察**：控制像素不仅编码平移方向，还间接决定了哪些矩形会在何处重叠。灰(5)和品红(6)像素的出现位置无法仅凭输入中矩形的位置预测——必须先完成平移才能确定。需要对比有重叠和无重叠的示例才能归纳深度着色规则。

## 新题 5：遮挡物宽高比编码对称补全轴

**组合逻辑**：[面积比较](创新：不比较面积，而比较遮挡矩形的宽与高) → [擦除](保留) + [对称补全](保留补全逻辑，但轴方向由上一步决定)

**来源原语**：擦除/erase + 对称补全/symmetry_completion + 去遮挡后镜像还原/mirror_after_occluder_removal + 填充矩形/filled_rectangle + 前景对象/foreground_object + 遮挡/occlusion (3345333e)；面积比较/area_comparison (6455b5f5，创新改造为宽高比比较)；内外分离/interior_exterior_sep (50cb2852，创新改造为遮挡物的几何属性编码规则参数)

**依赖链**：遮挡物的宽高比决定对称轴方向 → 擦除遮挡物后暴露缺失区域 → 沿选定方向寻找对称轴位置 → 按该轴镜像补全缺失像素。遮挡物同时是"需要移除的障碍"和"编码修复策略的信号"。

擦除遮挡矩形后，根据遮挡物的宽高比选择镜像轴方向来补全被遮挡的图案。

**输入结构**：约 13x13 的黑(0)背景网格。一个多色前景图案，由 2~3 种颜色（如蓝(1)、绿(3)、黄(4)）构成的 4-连通区域，占据网格中央约 7x7~9x9 的范围。该图案本身具备左右镜像对称或上下镜像对称（至少一种），但被遮挡物部分遮挡后对称性被破坏。一个灰(5)填充矩形覆盖在前景图案上方，宽度和高度不相等（非正方形），遮挡了部分前景像素。不同示例中遮挡物的位置和宽高比不同，前景图案的形状和颜色组合也不同。生成约束：被遮挡的区域恰好可通过宽高比所指示的那个方向的镜像补全完整恢复。

**规则**：
1. 检测灰(5)填充矩形（唯一的灰色 4-连通组件），测量其宽度 W（列数）和高度 H（行数）。
2. 若 W > H（遮挡物横宽），对称轴方向为垂直（即需进行左右镜像补全）。若 H > W（遮挡物纵高），对称轴方向为水平（即需进行上下镜像补全）。
3. 将灰(5)矩形的所有像素擦除为黑(0)。
4. 在选定方向上，检测使剩余前景像素对称性最大化的轴线位置。具体方法：遍历所有候选轴线（垂直方向遍历每一列及列间隙，水平方向遍历每一行及行间隙），对每条候选轴线统计前景像素关于该轴的对称匹配数，选择匹配数最多的轴线。
5. 对每个前景像素，计算其关于选定轴的镜像位置。若镜像位置为黑(0)，则将该位置填入与源像素相同的颜色。若镜像位置已有前景色，则保持不变。

**关键洞察**：遮挡物本身不包含任何前景信息，但它的形状（横扁 vs 纵长）隐式编码了应使用哪个方向进行对称修复。需要对比至少两个示例（一个横宽遮挡物对应左右补全，一个纵高遮挡物对应上下补全）才能归纳此规则。

## 新题 6：旋转对齐后平铺加阴影

**组合逻辑**：[旋转] + [颜色一致对齐](保留匹配逻辑) + [印章覆盖](保留) → [偏移阴影](创新：阴影不是加在原始输入上，而是加在旋转对齐结果上) → [平铺](创新：带阴影的合成瓦片进行 2x2 平铺)

**来源原语**：旋转/rotate + 印章覆盖/stamp_overlay + 颜色一致对齐/color_consistent_align + 稀疏像素引导放置/sparse_pixels_guide_placement + 精灵体/sprite + 锚点像素/anchor_pixel (0e206a2e)；平铺/tiling + 偏移阴影/offset_shadow + 列环绕/column_wrapping + 瓦片/tile (310f3251)

**依赖链**：锚点像素的颜色和位置约束旋转角度与放置位置 → 对齐后的合成图确定瓦片内容 → 瓦片内容决定阴影位置（阴影取决于非黑像素的坐标） → 带阴影的瓦片作为单元进行平铺。旋转角度的选择影响瓦片中像素的空间布局，进而影响阴影图案和最终的平铺结果。

**输入结构**：约 10x10 的黑(0)背景网格，由一行灰(5)像素（位于网格中部某行，横跨全宽）分隔为上半区和下半区。上半区包含一个多色精灵体（使用 2 种前景色如蓝(1)和黄(4)，3~7 个像素组成的 4-连通图形）。下半区包含一个与上半区等大的区域，其中散布 2~3 个锚点像素（颜色与精灵体中对应像素的颜色相同）。精灵体经过 0/90/180/270 度中恰好一种旋转后，其有色像素能与下半区锚点像素的颜色和相对位置完全吻合。红(2)在输入中不出现。不同示例中精灵体形状、旋转角度和锚点位置不同。

**规则**：
1. 分离上半区精灵体和下半区锚点像素。将下半区（不含灰分隔行）作为瓦片画布（大小记为 Rxt x Cxt）。
2. 对精灵体尝试 4 种旋转（0/90/180/270 度），对每种旋转在瓦片画布上尝试所有合法平移位置，寻找使旋转后精灵体的有色像素完全覆盖所有锚点像素且颜色逐像素一致的唯一组合（旋转角度 + 平移偏移）。
3. 在瓦片画布上放置旋转后的精灵体（覆盖锚点像素位置，其余位置保持黑(0)），得到合成瓦片。
4. 在合成瓦片中，对每个非黑像素 (r, c)，在位置 (r-1, (c-1+Cxt) mod Cxt) 处添加红(2)阴影像素。列索引到达左边界时环绕到右侧。若该位置已有非黑像素则不覆盖（原始前景像素优先）。
5. 以带阴影的合成瓦片为单元，进行 2x2 平铺（水平复制 2 份，垂直复制 2 份），生成大小为 (2xRxt) x (2xCxt) 的输出网格。灰分隔行不出现在输出中。

**关键洞察**：锚点像素同时充当两个角色——确定旋转角度的约束条件，以及合成瓦片中的组成像素。阴影位置取决于旋转对齐后的像素布局，因此不同的旋转角度会产生不同的阴影图案。求解者必须先完成旋转匹配，才能得到正确的瓦片内容用于后续的阴影计算和平铺。

## 新题 8：射线穿框后分割区域按面积极值着色

**组合逻辑**：[射线延伸] + [经过框角才延伸](保留选择性激活条件) + [角对角对齐](保留) → [封闭区域](创新：射线与框边联合分割出新区域) → [面积比较] + [极值区域分别涂色](创新：着色对象是射线与框联合围合的区域)

**来源原语**：射线延伸/ray_extend + 实心矩形/solid_rectangle + 空心矩形/hollow_frame + 角对角对齐/corner_diagonal_align + 经过框角才延伸/extend_past_corner (ec883f72)；面积比较/area_comparison + 极值区域分别涂色/extreme_regions_recolor + 封闭区域/enclosed_region (6455b5f5)；内外分离/interior_exterior_sep + 保留边框涂内部/keep_border_fill_inside (50cb2852)

**依赖链**：实心矩形角与空心框角的对角对齐关系决定哪些射线被激活 → 激活的射线改变框外空间的拓扑分割 → 分割后各区域的面积排名决定填充颜色。矩形的偏心位置同时决定了哪些射线存在和射线如何切分空间。

从实心矩形角沿对角线穿过空心框角后延伸射线，射线和框边围合出多个区域，按面积着不同填充色。

**输入结构**：约 15x15 的黑(0)背景网格。一个蓝(1)实心矩形（3x3 至 4x4），位于网格偏某个方向的位置（非正中央）。一个红(2)空心矩形框（1 像素厚，约 9x9 至 11x11），中心大致在网格中央。实心矩形完全位于空心框的内部。生成约束：实心矩形至少有 2 个角的外延对角线恰好穿过空心框的某个角（即实心矩形角的对角延伸方向上遇到的第一个非黑像素是框的角像素），但不一定所有 4 个角都满足此条件。不同示例中实心矩形的位置不同，导致不同的角被激活。

**规则**：
1. 从实心矩形的每个角出发，沿该角的外延对角线方向（左上角向左上、右下角向右下、左下角向左下、右上角向右上）逐像素检查。
2. 若该对角线上遇到的第一个非黑(0)像素恰好是空心框的一个角像素，则该射线被"激活"：从框角像素的下一个位置起，继续沿同方向逐像素延伸到网格边界，将路径上所有黑(0)像素涂蓝(1)。若遇到的第一个非黑像素不是框角（例如是框边），则该射线不激活。
3. 激活射线的像素、空心框的像素和实心矩形的像素共同将网格空间分割为若干封闭区域。仅考虑空心框外部的区域（框内部不参与面积比较）。
4. 计算每个框外封闭区域的面积（黑(0)像素数）。面积最小的区域（可能并列）填绿(3)。面积最大的区域（可能并列）填黄(4)。其余区域保持黑(0)。
5. 空心框、实心矩形和射线像素保持各自颜色不变。

**关键洞察**：射线能否激活取决于实心矩形与空心框之间精确的对角对齐关系，而激活的射线数量和方向直接决定框外空间被切分为几个区域以及各区域的面积比例。实心矩形的位置是唯一的自变量，同时控制射线的存在性和分区的几何形状。

## 新题 10：标记稀疏度排序决定镜像拼接方向

**组合逻辑**：[选择](创新：不选一个，而是对所有矩形排序) + [最少标记数](创新：标记数用于排序而非二元筛选) → [排序](保留) → [裁剪](保留) → [镜像] + [拼接](创新：排名奇偶性决定镜像轴方向) + [相邻拼接](保留)

**来源原语**：选择/selection + 最少标记数/minimum_marker_count + 前景矩形/foreground_rectangle + 标记像素/marker_pixel (7bb29440)；排序/sorting (eb5a1d5d)；裁剪/crop (73ccf9c2)；镜像/mirror + 拼接/concatenate + 相邻拼接/adjacent_placement (9bebae7a, c9e6f938)

**依赖链**：标记像素计数产生每个矩形的排序键 → 排序确定全局排名 → 排名的奇偶性决定该矩形的镜像方向（水平或垂直） → 镜像方向决定拼接后的形状 → 所有拼接结果按排名顺序排列为最终输出。标记数→排名→奇偶→变换方式，链中任何一步不可跳过。

裁剪所有前景矩形并按标记像素数排序，排名为奇数的矩形水平镜像拼接，偶数的垂直镜像拼接，最终按排名从左到右排列输出。

**输入结构**：约 18x18 的黑(0)背景网格。4~5 个互不重叠的单色填充矩形（每个矩形的主色各不相同，如红(2)、蓝(1)、绿(3)、橙(7)、黄(4)），每个矩形至少 3x3。每个矩形内部散布若干灰(5)标记像素，数量从 0 到 4 不等，且各矩形的灰色标记像素数互不相同（保证排序无歧义）。不同示例中矩形数量、大小、颜色、标记数和位置不同。

**规则**：
1. 检测所有非黑(0)非灰(5)的 4-连通填充矩形（每个矩形内部可能包含灰(5)标记像素）。
2. 裁剪每个矩形的最小包围盒（包含矩形边框和内部的标记像素）。
3. 统计每个矩形内灰(5)标记像素的数量，按数量从少到多排序。排名从 1 开始。
4. 排名为奇数（1, 3, 5, ...）的矩形：生成其左右镜像副本，拼接在其右侧（原始在左，镜像在右），得到宽度翻倍的结果。
5. 排名为偶数（2, 4, ...）的矩形：生成其上下镜像副本，拼接在其下方（原始在上，镜像在下），得到高度翻倍的结果。
6. 将所有拼接后的结果按排名从左到右水平排列，相邻结果之间间隔 1 列黑(0)像素。若某个结果高度不足所有结果中的最大高度，从底部补黑(0)像素使其等高。

**关键洞察**：标记像素的计数不仅决定了排列顺序，还通过排名的奇偶性决定了每个矩形的变换方式（水平 vs 垂直镜像拼接）。单看一个矩形无法判断它应该如何变换——必须知道其在全局排序中的位置。需要对比多个矩形的标记数与其变换方式的对应关系才能归纳出奇偶规则。
