## 新题 1：障碍偏转路径充当扫描线填充边界

**组合逻辑**：[路径生长 + 障碍偏转](来自 #20 712bf12e，创新：路径不再是最终输出，而是中间边界结构) → [逐行扫描 + 填充轮廓间区域](来自 #5 aa18de87，创新：轮廓不是预置的对角线笔画，而是由路径生长动态生成)

**来源原语**：路径生长(path_grow)、障碍偏转(obstacle_deflection)、控制像素(control_pixel)、障碍块(blocker)、底行起始(bottom_row_origin) ← #20 712bf12e；填充(fill)、轮廓像素(outline_pixel)、跨度(span)、逐行扫描(row_scan)、填充轮廓间区域(fill_between_outlines) ← #5 aa18de87

**依赖链**：路径生长的输出（红色像素的空间分布）直接成为扫描线填充的边界输入。灰色障碍物改变路径的列坐标，从而改变填充区域的几何形状。移除路径生长则无边界可扫描；移除扫描线填充则路径仅为一组无意义的红线。

从底行控制像素向上生长偏转路径，然后以这些路径为边界逐行填充它们之间的背景区域。

**输入结构**：
- 黑(0)背景网格，约 15 行 x 20 列。
- 4~6 个灰(5)障碍像素散布于网格上半部，每个障碍为单独的 1 像素，互不相邻（4-连通距离 >= 2）。
- 3~4 个红(2)控制像素位于最底行，相互间距至少 3 列。
- 生成约束：每个红控制像素至少能向上生长 5 行；障碍不得将所有路径全部截断。

**规则**：
1. 从每个红(2)控制像素开始，逐步向上生长路径：
   - 若正上方一格为背景(0)，将其涂红(2)，从该格继续向上。
   - 若正上方一格为灰(5)障碍，则改为将当前行右侧一格涂红(2)（前提是该格为背景(0)），然后从新位置继续向上。
   - 若右侧一格不可用（非背景或越界），该路径停止。
   - 路径到达第 0 行或无法继续时停止。
2. 所有路径完成后执行扫描线填充：从第 0 行到最底行，逐行从左到右找出该行所有红(2)像素。对每一对相邻红像素，将它们之间（不含端点）的所有背景(0)像素涂为蓝(1)。
3. 保留所有灰(5)障碍像素和红(2)路径像素不变。仅背景像素可能变为蓝(1)。

**关键洞察**：红色路径既是路径生长的产物，又是扫描线填充的结构性边界。一个灰色障碍使路径偏移一列，该偏移会沿路径向上传播，导致上方多行的填充区域宽度同时发生变化——障碍的局部效应通过路径产生全局几何后果。

## 新题 2：对角连线划分空间后裁剪最大空隙

**组合逻辑**：[连线 + 对角线段连接](来自 #10 1f876c06，创新：对角连线不是输出装饰，而是空间划分边界) → [连通分量分析 + 面积比较 + 裁剪](来自 #6 be94b721，创新：被选中的不是前景对象，而是对角线之间的背景空隙)

**来源原语**：连线(line_drawing)、对角线段连接(diagonal_segment_connect)、同色配对(same_color_pairing)、端点对(endpoint_pair) ← #10 1f876c06；裁剪(crop)、连通分量(connected_component)、面积比较(area_comparison)、选取最大面积对象(largest_area_selected) ← #6 be94b721

**依赖链**：对角连线的空间布局决定了背景被切割成哪些连通区域；面积比较和裁剪依赖于这些区域的几何形状。不画对角线则无划分；不做连通分量分析则不知道裁剪什么。

将同色像素对用对角线段连接，对角线把网格背景切割成若干区域，裁剪输出面积最大的背景区域。

**输入结构**：
- 黑(0)背景网格，约 12 行 x 12 列。
- 4~5 对同色前景像素，每对使用不同颜色（取自蓝(1)、红(2)、绿(3)、黄(4)、灰(5)），每种颜色恰好 2 个像素。
- 每对像素位于严格 45 度对角线上（行距等于列距）。
- 生成约束：连接后的对角线段不能全部平行；至少两条线段必须在不同方向上交叉或接近，以产生有意义的空间分割；所有端点不重合。

**规则**：
1. 对每种前景颜色，沿 45 度对角线连接该颜色的两个像素，将路径上每个格子涂为该颜色（保留已有像素不覆盖）。
2. 在连线完成后的网格中，找出所有 4-连通的背景(0)区域（被对角线段和网格边界包围的背景连通分量）。
3. 选出像素数最多的唯一背景区域。平局规则：若两区域面积相同，选边界框左上角更靠近网格左上角的那个（先比行号小者优先，再比列号小者优先）。
4. 输出：该区域的紧凑裁剪——在其边界框内，区域像素涂为灰(5)，其余格子为黑(0)。

**关键洞察**：彩色对角线是空间划分的基础设施，它们本身不出现在输出中。答案是对角线之间最大空隙的形状，而该形状只有在所有对角线全部画完后才能确定。

## 新题 3：路径连通性决定区域共享周期瓦片

**组合逻辑**：[路径生长 + 障碍偏转](来自 #20 712bf12e，创新：路径用于穿越障碍建立区域间连通关系，而非作为可见输出) + [平铺 + 最小周期修复缺口](来自 #9 e95e3d8e，创新：周期推断的像素池范围不再是整个网格，而由路径连通性动态决定) → [擦除](来自 #1/#7，擦除路径)

**来源原语**：路径生长(path_grow)、控制像素(control_pixel)、障碍偏转(obstacle_deflection)、底行起始(bottom_row_origin)、障碍块(blocker) ← #20 712bf12e；平铺(tiling)、周期瓦片(periodic_tile)、缺失像素(missing_pixel)、周期对齐(periodic_align)、最小周期修复缺口(min_period_repair_gap) ← #9 e95e3d8e；擦除(erase) ← #1 247ef758 / #7 456873bc

**依赖链**：路径的连通性将分离的区域归为同组；同组区域共享一个周期瓦片，跨区域汇聚像素信息以推断最小周期。路径不改变颜色数据，只改变"哪些像素参与同一次周期推断"。移除路径则每个区域独立推断（可能信息不足导致歧义）；移除周期填充则路径毫无用途。

用底行控制像素生长路径穿过障碍间隙连接不同区域，被连通的区域共享同一最小周期瓦片来填补各自的缺失像素。

**输入结构**：
- 黑(0)背景网格，约 12 行 x 25 列（窄长）。
- 3~4 条垂直灰(5)障碍列贯穿网格大部分高度，每条障碍列恰有一个单像素缺口（该列中有一格为黑(0)）。
- 相邻障碍列之间的矩形区域包含由 2~3 种非背景、非灰颜色（如蓝(1)、红(2)、绿(3)）构成的周期性图案，但其中部分像素为黑(0)缺失像素（即周期图案的采样缺损）。
- 2~3 个红(2)控制像素位于最底行，分布在不同区域内。
- 生成约束：至少两个区域通过红色路径可达（路径能穿过障碍缺口）；至少一个区域不被任何路径到达（保持独立）；被连通的区域使用相同的底层周期瓦片（但各自缺失不同位置的像素）；独立区域有自己独立的周期瓦片；单个区域内保留的像素不足以唯一确定周期，但连通组的像素汇总后可以。

**规则**：
1. 从每个红(2)控制像素向上生长路径（规则同新题 1 的路径生长）。路径可穿过灰(5)障碍列的单像素缺口进入相邻区域。
2. 判定连通性：若某条红色路径经过了两个不同区域（穿越了至少一条障碍列的缺口），则这些区域属于同一连通组。传递闭包：若区域 A 与 B 连通、B 与 C 连通，则 A、B、C 同组。
3. 对每个连通组：汇集该组所有区域中的非黑、非灰、非红像素，推断唯一的最小矩形周期瓦片（使得所有已观测像素与其所在行列的模余类一致）。
4. 用推断出的周期瓦片填补每个区域中的黑(0)缺失像素：将缺失像素替换为其 (行 mod 周期高度, 列 mod 周期宽度) 对应的瓦片颜色。
5. 擦除所有红(2)路径像素（用该位置的周期瓦片颜色替换）。保留灰(5)障碍列不变。

**关键洞察**：被障碍分隔的区域看似拥有各自独立的图案，但被红色路径连通的区域共享同一个周期瓦片。路径本身在输出中不可见——它只负责传递"哪些区域应汇聚信息"这一隐含关系。单个区域的缺损太多无法独立推断周期，但连通组的互补信息使推断成为可能。

## 新题 4：同色标记对编码色层对称轴以执行逐色去噪

**组合逻辑**：[同色配对](来自 #10 1f876c06，创新：配对不用于画连线，而是计算中点列作为对称轴) → [逐色处理 + 对称补全/去噪](来自 #16 8e5c0c38，创新：对称轴不再通过最佳拟合推断，而由标记对的几何位置显式编码) → [擦除](来自 #1/#7)

**来源原语**：同色配对(same_color_pairing)、端点对(endpoint_pair) ← #10 1f876c06；对称补全(symmetry_completion)、色层(color_layer)、对称轴(symmetry_axis)、逐色处理(per_color_processing)、忽略干扰项(ignore_distractors) ← #16 8e5c0c38；擦除(erase) ← #1/#7

**依赖链**：标记像素对的中点列确定对称轴；对称轴决定每个色层的去噪结果。误判标记对为噪声则得到错误对称轴，输出完全错误。三个环节（标记识别 → 轴计算 → 镜像去噪）缺一不可。

每种颜色有一对孤立标记像素，其中点列即该颜色聚类的垂直对称轴；以此轴为基准移除每个色层中无镜像对应的噪声像素。

**输入结构**：
- 黑(0)背景网格，约 16 行 x 16 列。
- 3~4 种非背景颜色（如蓝(1)、红(2)、绿(3)、黄(4)），每种颜色形成一个空间上分离的像素聚类，每个聚类包含 8~15 个同色像素、呈 4-连通结构。
- 每个聚类近似关于某一垂直列对称，但有 1~3 个"噪声"像素打破对称（噪声像素只出现在对称轴的一侧，且该行对称位置为背景(0)）。
- 对每种颜色 C，另有恰好 2 个孤立的 C 色像素远离聚类（与聚类中任何像素的切比雪夫距离 >= 3），这两个孤立像素的列坐标中点 M = (col1 + col2) / 2 即为 C 色聚类的垂直对称轴。
- 生成约束：不同颜色的标记对中点必须互不相同；中点必须为整数或半整数（若为半整数则对称轴在两列之间）；聚类之间不重叠、不相邻。

**规则**：
1. 对每种非背景颜色 C，识别该颜色的所有像素，将它们分为"聚类像素"（属于 5 个及以上同色像素的 4-连通分量）和"标记像素"（属于 1~2 个像素的孤立组）。
2. 每种颜色恰有 2 个标记像素。计算它们的中点列 M = (col1 + col2) / 2，此即颜色 C 的垂直对称轴。
3. 对颜色 C 的每个聚类像素 (r, c)：计算镜像位置 (r, 2M - c)。若镜像位置在网格内且包含颜色 C 的像素，保留该像素。否则该像素为噪声，替换为黑(0)。
4. 擦除每种颜色的两个标记像素（替换为黑(0)）。
5. 输出去噪后的网格。

**关键洞察**：每种颜色的两个孤立像素看起来像噪声，实际上它们编码了该颜色聚类的对称轴。将它们误判为噪声（而非轴标记）会导致对称轴无法确定或被错误推断。标记对的空间位置——而非颜色本身——承载了关键信息。

## 新题 5：方块边长循环变换重塑射线碰撞边界

**组合逻辑**：[缩放 + 边长循环变换](来自 #17 522fdd07，创新：尺寸变化不是最终输出，而是改变后续射线的碰撞几何) ↔ [射线发射 + 碰撞停止](来自 #19 80a900e0，创新：射线终止位置由变换后的方块尺寸决定，而非输入时的原始尺寸)——两个操作通过共享的空间几何相互约束

**来源原语**：缩放(resize)、奇数边正方形(odd_side_square)、中心点(center_point)、同心定位(concentric_position)、边长循环变换(side_length_cycle) ← #17 522fdd07；射线发射(ray_cast)、对角线段(diagonal_segment)、棋盘格图案(checkerboard_pattern)、端点发射(emit_from_endpoints)、碰撞停止(collision_stop) ← #19 80a900e0

**依赖链**：边长循环改变方块占据的空间范围 → 射线的碰撞边界随之改变 → 射线长度和最终图案因此不同于直接在原始网格上发射射线的结果。两个操作通过同一空间共享产生双向耦合：方块尺寸决定射线碰撞点，射线本身不影响方块，但求解者必须先完成尺寸变换才能正确计算射线。

先将所有奇数边正方形的边长循环变换，再从每个方块旁的对角线段端点发射射线，射线在碰到变换后的方块或网格边缘时停止。

**输入结构**：
- 棋盘格背景：黑(0)与灰(5)交替，(0,0) 为黑(0)。网格约 20 行 x 20 列。
- 3~4 个实心单色奇数边正方形（边长取自 {1, 3, 5, 7}），颜色各不同（取自蓝(1)、红(2)、绿(3)、黄(4)），中心间距至少 10。
- 每个方块有一个橙(7)对角线段（恰好 2 像素），紧邻方块的某个角，方向为 45 度指向远离方块中心的方向。
- 生成约束：方块之间不重叠；边长循环变换后方块之间仍不重叠；对角线段不与任何方块（含变换后）相接触。

**规则**：
1. 对每个方块执行边长循环变换：1 → 9, 3 → 1, 5 → 3, 7 → 5, 9 → 7。保持中心位置和颜色不变。新方块以原中心为中心，占据对应边长的正方形区域。
2. 从每个橙(7)对角线段的两个端点各发射一条对角射线，方向为从方块中心穿过该线段向外延伸的方向：每条射线沿 45 度方向逐步前进，将棋盘格像素（黑(0)或灰(5)）涂为橙(7)。射线在下一格为非棋盘格像素（方块像素或已有橙色射线像素）或越出网格时停止，停止格不涂色。
3. 输出最终网格：包含变换后的方块、原始对角线段以及射线延伸线，背景保持棋盘格。

**关键洞察**：射线的终止位置由变换后的方块尺寸决定，而非输入中的原始尺寸。一个 7x7 方块缩小为 5x5 后释放了对角空间使附近射线走得更远；一个 1 像素方块膨胀为 9x9 后可能截断原本畅通的射线。必须先完成全部尺寸变换，才能正确计算任何一条射线的长度。

## 新题 6：双面板异或差异揭示隐藏周期结构

**组合逻辑**：[逐像素比较 + 异或差异判定](来自 #18 34b99a2b，创新：XOR 结果不是最终输出的红色标记，而是周期推断的输入数据) → [平铺 + 最小周期修复缺口](来自 #9 e95e3d8e，创新：周期结构不存在于输入网格中，而是两面板差异的涌现属性)

**来源原语**：逐像素比较(cell_by_cell_comparison)、差异标记(mark_differences)、二值掩码(binary_mask)、分隔列(separator_column)、面板对齐(panel_alignment)、异或差异判定(xor_difference) ← #18 34b99a2b；平铺(tiling)、周期瓦片(periodic_tile)、周期对齐(periodic_align)、最小周期修复缺口(min_period_repair_gap) ← #9 e95e3d8e

**依赖链**：XOR 比较产生一个不完整的二值掩码 → 该掩码隐含周期结构 → 最小周期推断填补缺失位置。单个面板无周期性；XOR 产生的掩码中也有蓄意隐藏的位置（两面板在此一致导致该位置不出现在 XOR 中）。三步链路中每步都对下一步执行了不可逆的信息变换。

对齐左右面板并计算逐像素异或差异，差异位置构成一个有缺失的周期图案，推断最小周期并填补缺失位置后输出。

**输入结构**：
- 网格约 11 行 x 23 列，正中央一列为黑(0)分隔列（列索引 11）。
- 左面板（列 0~10）和右面板（列 12~22），均为 11 行 x 11 列。
- 两面板背景为灰(5)，前景像素使用蓝(1)和红(2)散布其中。
- 每个面板的前景图案看起来无规律、不具周期性。
- 生成约束：两面板的 XOR（恰好一个面板该位置有前景、另一个为背景的格子集合）必须构成一个矩形周期图案（周期尺寸在 2x2 到 4x4 之间），但该周期图案有 10%~30% 的位置被蓄意隐藏（这些位置两面板一致，不出现在 XOR 中）。

**规则**：
1. 将左右面板按行列对齐（忽略分隔列），得到 11x11 对齐网格。
2. 计算 XOR 掩码：某位置 (r, c) 为"激活"当且仅当对齐的两个格子中恰有一个为非背景色（蓝或红），另一个为背景(5)。
3. 激活位置构成一个有缺失的周期图案。推断最小矩形周期（最小的周期高度 pH 和宽度 pW，使所有激活位置与其 (r mod pH, c mod pW) 余类一致，且每个余类至少有一个激活位置作为证据）。
4. 填补缺失：对每个非激活位置，若其 (r mod pH, c mod pW) 对应的余类中存在激活位置，则将该位置也标记为激活。
5. 输出 11x11 网格：激活位置为红(2)，其余为黑(0)。

**关键洞察**：任一面板单独观察都不具有周期性——周期结构是两面板差异的涌现属性，只在 XOR 之后才可见。部分周期位置被蓄意隐藏（两面板在此一致），因此 XOR 掩码本身也不完整，必须通过最小周期推断来恢复完整图案。

## 新题 7：镜像精灵的占用补集中裁剪最大空隙分量

**组合逻辑**：[平移/镜像位置 + 内部朝向不变](来自 #11 8ee62060，创新：镜像位置不是最终输出，而是用于构造占用掩码) → [透明叠加 + 占用补集](来自 #14 66f2d22f，创新：叠加的不是两个面板，而是原始精灵集与其镜像副本的投影) → [连通分量 + 面积比较 + 裁剪](来自 #6 be94b721，创新：被选中的是补集中的最大连通区域，而非前景对象)

**来源原语**：平移(translate)、镜像位置(mirrored_position)、精灵体(sprite)、内部朝向不变(orientation_preserved) ← #11 8ee62060；透明叠加(transparent_overlay)、二值掩码(binary_mask)、双侧对齐(bilateral_alignment)、占用补集(occupancy_complement) ← #14 66f2d22f；裁剪(crop)、连通分量(connected_component)、面积比较(area_comparison)、选取最大面积对象(largest_area_selected) ← #6 be94b721

**依赖链**：精灵镜像产生新位置 → 原始+镜像的合并占用掩码 → 补集产生空隙区域 → 连通分量分析选出最大空隙 → 裁剪。每步执行不可逆的信息变换：镜像产生位置、叠加产生掩码、补集反转前景/背景、分量分析产生面积排序、裁剪产生几何剪切。移除任意环节均无法从其余步骤推出输出。

将精灵水平镜像（保留内部朝向），合并原始与镜像的占用区域，取补集后选出最大的 4-连通背景空隙并裁剪输出。

**输入结构**：
- 黑(0)背景网格，约 20 列 x 10 行（宽而矮）。
- 4~6 个小型多色精灵体，每个精灵的边界框为 2x2，包含 2~3 个非背景像素（使用蓝(1)、红(2)、绿(3)、黄(4)中的颜色）。
- 精灵分布在网格的左三分之二区域，互不重叠、互不相邻（4-连通距离 >= 2）。
- 生成约束：镜像后没有精灵与原始精灵重叠；补集区域必须产生至少 2 个大小不同的 4-连通分量。

**规则**：
1. 对每个精灵，计算其水平镜像位置：保持行不变，每个像素的新列 = 网格宽度 - 1 - 原列。内部像素布局和颜色不变（精灵被平移而非翻转）。
2. 构造占用掩码：所有原始精灵像素和所有镜像精灵像素的并集。
3. 计算补集：占用掩码之外的每个格子标记为灰(5)；占用掩码内的格子标记为黑(0)。
4. 找出所有灰(5)的 4-连通分量。
5. 选出像素数最多的唯一分量。平局规则：若两分量面积相同，选边界框上边缘行号更小的（更靠近网格顶部的）。
6. 输出：该分量的紧凑裁剪——在边界框内，分量像素为灰(5)，其余为黑(0)。

**关键洞察**：输出既不是精灵也不是其镜像——而是它们合并投影中最大的空隙。移动任何一个精灵同时改变其原始位置和镜像位置，可能合并或分裂空隙分量，导致输出形状和裁剪区域完全不同。

## 新题 8：帧边标记兼任射线转向触发器与印章坐标

**组合逻辑**：[射线延伸 + 转向](来自 #3 e5790162，创新：转向不由独立的粉/青控制点触发，而由帧边标记的行列对齐触发——标记同时扮演两个角色) ↔ [复制放置 + 标记交叉定位](来自 #1 247ef758，创新：不是在所有交叉点放置精灵，而是仅在射线经过的交叉点放置)——标记的双重角色使两个操作通过同一结构紧密耦合

**来源原语**：射线延伸(ray_extend)、转向(turn)、起点像素(start_pixel)、路径(path)、视线方向(line_of_sight) ← #3 e5790162；复制放置(replicate_stamp)、精灵体(sprite)、框架标记(frame_marker)、标记交叉定位(marker_intersection_positioning)、颜色匹配配对(color_match_pairing) ← #1 247ef758；擦除(erase) ← #1/#7

**依赖链**：帧边标记的位置同时定义了(a)射线的转向行/列和(b)候选印章坐标的行列网格。射线轨迹由标记的转向效应决定；印章仅放置在射线经过的交叉点。改变一个标记的位置同时改变射线路径和候选位置集合——这种双重角色使"路径选择"与"位置定义"不可分割。

一条射线在矩形帧内部行进，帧边标记既作为转向触发器控制射线方向，又作为坐标标记定义候选印章位置；仅在射线经过的标记交叉点处放置精灵。

**输入结构**：
- 黑(0)背景网格，约 16 行 x 16 列。
- 一个灰(5)空心矩形帧（1 像素宽边框），占据网格右侧约 12 列 x 10 行区域。
- 帧的上下边缘上有 2~3 个彩色标记像素（替换灰像素），标记颜色从蓝(1)、红(2)、绿(3)中选取；帧的左右边缘上也有 2~3 个彩色标记像素。
- 一个小精灵（3x3 区域，含 3~5 个非背景像素，背景为黑(0)）显示在网格左上角的 3x3 调色板区域内，与帧不重叠。
- 一个绿(3)起点像素位于帧内部，紧贴帧左内边缘（帧左边框右侧一格）。
- 生成约束：标记位置必须使绿色射线至少转向 2 次且经过至少 2 个标记交叉点；射线路径不能在第一次转向前就撞墙。

**规则**：
1. 从绿(3)起点像素开始，初始方向为向右。射线逐格移动，将每个背景(0)格涂为绿(3)：
   - 当射线进入某一行 r，且该行在帧的左边缘或右边缘上有一个彩色标记时，射线在当前格顺时针转 90 度（右转）。
   - 当射线进入某一列 c，且该列在帧的上边缘或下边缘上有一个彩色标记时，射线在当前格逆时针转 90 度（左转）。
   - 若同一格同时满足两个条件（既在标记行又在标记列），右转优先。
   - 当射线下一格为帧壁（灰色像素）、已有颜色的像素或越出帧时，停止。
2. 确定标记交叉点：帧内部位置 (r, c)，其中行 r 在帧的左/右边缘有标记，且列 c 在帧的上/下边缘有标记。
3. 在所有标记交叉点中，仅在绿色射线经过的格子及其曼哈顿距离 <= 1 的格子所涵盖的交叉点处放置精灵（精灵以该交叉点为中心放置，超出帧的部分裁去）。
4. 擦除绿色路径（涂回黑(0)）、擦除调色板精灵区域（涂回黑(0)）、擦除起点像素。输出帧及其标记、放置的精灵和黑色背景。

**关键洞察**：帧边标记扮演双重角色——它们既是定义候选放置位置的坐标网格节点，又是操纵选择射线的转向指令。移动一个标记同时改变了"哪些位置可以放精灵"和"射线会经过哪些位置"。这种结构性纠缠使路径规划和位置定义不可分离。
