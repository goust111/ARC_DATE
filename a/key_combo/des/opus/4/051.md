## 新题 1：对称轴垂直射线与交叉标记

**组合逻辑**：[对称类型判断](创新：对称轴类型决定射线发射方向，而非决定重涂色) → [射线延伸](从对象每个像素沿对称轴的垂直方向全长发射) → [重涂色](交叉点标记为黄色)

**来源原语**：对称类型决定颜色(a09f6c25)→创新为对称类型决定方向、射线延伸 ray_cast(9f8de559/bdad9b1f/673ef223)、交叉点标记新色(bdad9b1f)、前景物体(a09f6c25)、对称轴(a09f6c25)

**依赖链**：对称分类的结果决定射线方向（水平对称→垂直射线，垂直对称→水平射线）→ 多个对象的射线在网格中产生空间交叉 → 交叉点被标记为黄色。对称分类是方向选择的前提，射线方向组合决定了交叉位置——三步环环相扣，删任一步剩余无法独立求解。

每个前景对象根据其反射对称轴的垂直方向发射全长射线，不同对象射线的交叉点标记为黄色。

**输入结构**：约 15x15 网格，黑(0)背景。3-4 个小型 4-连通单色对象，每个对象使用不同的非黑色颜色（如蓝(1)、红(2)、绿(3)、橙(7)），像素数 3-6。每个对象恰好具有一种反射对称性：水平对称（沿水平轴翻转后不变）或垂直对称（沿垂直轴翻转后不变）。各对象的边界框在行范围和列范围上互不重叠，确保对称类型和射线归属无歧义。生成约束：至少包含一个水平对称对象和一个垂直对称对象，且它们的射线在空间上至少产生一处交叉。

**规则**：
1. 对每个前景对象，判断其反射对称类型（水平或垂直）。
2. 水平对称的对象：从该对象的每个像素向上和向下延伸垂直射线至网格边界，射线颜色为该对象的颜色。
3. 垂直对称的对象：从该对象的每个像素向左和向右延伸水平射线至网格边界，射线颜色为该对象的颜色。
4. 射线不被任何像素阻挡，始终延伸到网格边界。
5. 绘制顺序：先绘制所有射线（若同一单元格被多条同色射线覆盖则仅保留该色；若被不同色射线覆盖则后绘制的覆盖先绘制的——按对象在网格中边界框左上角的行优先、列次优先排序，排序靠后的后绘制）。
6. 然后标记所有交叉点：若某单元格被来自两个或更多不同对象的射线经过（无论最终显示哪个颜色），将该单元格涂为黄(4)。
7. 最后绘制原始对象像素（原色覆盖射线和交叉标记）。

**关键洞察**：对称轴方向与射线发射方向是垂直关系——水平对称的对象发射垂直射线，垂直对称的对象发射水平射线。这一反直觉映射必须通过对比多个示例（观察不同对称类型对象产生的射线方向）才能归纳出来。

## 新题 2：矩形筛选滑动与轨迹交叉标红

**组合逻辑**：[筛选](实心矩形判定作为入口过滤) → [滑动](边缘接触决定方向，滑至对侧) + [轨迹条纹](滑动留下橙色轨迹) → [重涂色](轨迹交叉点标记为红色) + [擦除](非矩形对象消除)

**来源原语**：筛选 filtering + 实心矩形 solid_rectangle(23b5c85d)、滑动 slide + 接触边缘 touching_edge + 滑至对侧边缘 slide_to_opposite + 轨迹条纹 trail_stripe(b25e450b)、擦除 erase(87ab05b8/9f8de559)、交叉点标记新色 crossing_cell_marked_new_color(bdad9b1f)

**依赖链**：形状分类（矩形判定）过滤哪些对象参与滑动 → 边缘接触位置决定滑动方向 → 滑动产生轨迹条纹 → 轨迹在空间中交叉产生红色标记。非矩形对象被擦除不参与后续逻辑。形状分类是入口过滤器，轨迹交叉是滑动几何的涌现结果。

只有实心矩形的边缘对象滑动到对侧并留下橙色轨迹，非矩形边缘对象被擦除，轨迹交叉处标红。

**输入结构**：约 15x15 网格，灰(5)背景。5-6 个单色前景对象，每个对象接触恰好一条外边界（上、下、左或右）。其中部分对象是实心矩形（像素恰好填满其边界框，宽或高 >= 2），部分是不规则的 4-连通形状（不填满边界框，如 L 形缺角、带孔洞等）。每个对象颜色不同（可用蓝(1)、红(2)、绿(3)、橙(7)、品红(6)等非灰非黑色）。生成约束：至少两个实心矩形分别接触不同朝向的边界（一个水平边界、一个垂直边界），使得它们的滑动轨迹在空间中产生交叉；至少一个非矩形对象作为干扰项。

**规则**：
1. 对每个接触边界的前景对象，判断其像素是否恰好填满其边界框（实心矩形测试）。
2. 未通过测试的对象（非矩形）被擦除为灰(5)背景色。
3. 通过测试的实心矩形同时滑向对侧边界：触顶边的向下滑至底边、触底边的向上滑至顶边、触左边的向右滑至右边、触右边的向左滑至左边。
4. 每个矩形滑过的完整条纹区域（矩形扫过的所有行或列）涂为橙(7)。
5. 矩形在目的地边缘以原色绘制。
6. 两条或更多橙色轨迹条纹重叠的单元格涂为红(2)。
7. 绘制顺序：先绘制所有轨迹为橙(7)，再将所有重叠位置涂为红(2)，最后绘制目的地矩形（原色覆盖轨迹和重叠标记）。

**关键洞察**：非矩形边缘对象是干扰项——它们看起来也接触边界，但不参与滑动，必须先判定形状才能确定哪些对象移动。轨迹交叉是水平滑动和垂直滑动在空间中的涌现效应，需要理解两种滑动方向如何产生重叠区域。

## 新题 3：控制像素选象限、矩形筛选后旋转镜像

**组合逻辑**：[控制像素/象限选择](红色像素定位源象限) → [筛选](仅保留实心矩形) → [镜像](创新：180度旋转至对角象限) + [擦除](清除所有非目标内容)

**来源原语**：控制像素 control_pixel + 所属象限 containing_quadrant(87ab05b8)、筛选 filtering + 实心矩形 solid_rectangle(23b5c85d)、镜像 mirror + 对称 symmetry(496994bd)→创新为绕中心点旋转180度、擦除 erase(87ab05b8)

**依赖链**：控制像素选定源象限（空间定位）→ 在源象限中筛选实心矩形（形状判断）→ 将筛选出的矩形绕网格中心旋转180度放置到对角象限（几何变换）→ 擦除所有其他前景。三者各自缩小输出的可能空间：象限确定区域，筛选确定对象，旋转确定目的地。

红色控制像素选定一个象限，该象限中仅实心矩形通过筛选，被绕网格中心旋转180度放置到对角象限，其余全部擦除。

**输入结构**：16x16 网格（偶数尺寸），黑(0)背景。以网格中心点（第8行第8列的交界处）将网格划分为四个 8x8 象限。四个象限中分布着多个小型 4-连通单色前景对象（3-8 像素），颜色各异（蓝(1)、绿(3)、橙(7)、品红(6)等非红非黑色）。部分对象是实心矩形（填满边界框），部分是不规则形状。恰好一个红(2)单像素位于某个象限内（控制像素），不与任何其他对象相邻。生成约束：红色控制像素所在象限至少包含一个实心矩形和一个非矩形对象；其他象限也各包含至少一个对象（作为应被擦除的干扰）。

**规则**：
1. 确定红(2)控制像素所在象限为源象限（上半区/下半区 x 左半区/右半区）。
2. 在源象限中，对每个非红色前景对象做实心矩形测试（像素是否恰好填满边界框）。
3. 未通过测试的对象被擦除为黑(0)背景。
4. 通过测试的矩形绕网格中心做180度点旋转：每个像素 (r, c) 映射到 (15-r, 15-c)，颜色保持不变。
5. 擦除源象限中的原始矩形和红色控制像素。
6. 擦除所有其他象限中的原有前景对象。
7. 输出网格仅在对角象限中包含旋转后的矩形，其余全为黑(0)背景。

**关键洞察**：不知道控制像素在哪个象限就无法确定从哪里取对象；不做矩形筛选就会将不规则形状也旋转过去；不做180度旋转就无法得到正确的目标位置——三个判断缺一不可。必须对比多个示例（控制像素在不同象限）才能确认是对角象限而非相邻象限。

## 新题 4：间隔生长树与障碍剪枝标记

**组合逻辑**：[生长](间隔行生成 + 交替变色) + [首个障碍](创新：障碍不在射线路径上而在生长路径上) → [重涂色](被命中的障碍变色标记) + [擦除](被命中位置的生长子像素不生成)

**来源原语**：生长 grow + 种子行 seed_row + 相邻间隔 adjacent_gap + 交替变色 alternating_color + 间隔行生成 gap_row_generate(af726779)、首个障碍 first_obstacle(9f8de559)→创新为生长碰撞检测、擦除 erase(9f8de559)、重涂色 recolor(multiple)

**依赖链**：种子行的间隔模式决定第一代子像素位置 → 每代子像素位置可能与预置障碍重合 → 重合时该分支被剪枝（子像素不生成）且障碍被标记为黄色 → 未被命中的障碍保持蓝色。生长规则和障碍分布共同决定最终图案——生长产生树形扩展，障碍选择性截断分支。

从种子行向下按间隔生长规则产生交替色像素树，遇到蓝色障碍的分支停止生长且障碍标黄，未碰到的障碍保持蓝色。

**输入结构**：约 15x18 网格，绿(3)背景。网格上部（约第3行）有一行水平分布的橙(7)像素作为种子行，像素之间有不等的间隔（非连续排列，相邻橙色像素之间隔1-3个背景像素）。网格下方区域（第6行至第15行之间）散布着若干蓝(1)单像素障碍。生成约束：种子行中至少有三组"活跃-背景-活跃"三元组（即间隔恰好1个背景像素的相邻对），确保生长至少能产生两代子像素；至少一个蓝色障碍位于某个生长子像素的预期位置上，至少一个蓝色障碍不在任何生长路径上。

**规则**：
1. 种子行中的橙(7)像素为第0代活跃像素。
2. 从当前代活跃像素向下生成下一代：对当前代中每个"活跃像素(列a)-背景像素(列a+1)-活跃像素(列a+2)"三元组，在下方第2行、列 a+1 的位置生成一个子像素。连续相邻的活跃像素（中间无背景间隔）不产生子代。
3. 生成行的颜色交替：第1代为品红(6)，第2代为橙(7)，第3代为品红(6)，依此类推。
4. 若某个子像素应生成的位置已被蓝(1)障碍占据：该子像素不生成（该分支被剪枝），且该蓝(1)像素被重涂为黄(4)。
5. 被剪枝的分支不再产生任何后续子代。
6. 未被任何生长路径命中的蓝(1)障碍保持蓝(1)不变。
7. 生长在当代无法产生任何新子像素（所有三元组都不满足条件或全被剪枝）或下一代行超出网格边界时终止。
8. 种子行本身保留在输出中不变。

**关键洞察**：生长模式完全由种子行的间隔结构决定（这是确定性的几何规则），但障碍像素的位置选择性地剪枝某些分支——最终图案是生长树与障碍分布的交互结果。蓝色障碍变黄是"被激活"的标记，未被激活的保持蓝色，这一区别需要对比包含不同障碍位置的多个示例才能归纳。

## 新题 5：对称计数决定平铺维度与棋盘格色彩互换

**组合逻辑**：[对称类型判断 → 计数](创新：对称类型的数量而非颜色映射) → [平铺](计数值决定水平和垂直重复次数) + [双色互换](创新：棋盘格位置决定是否互换)

**来源原语**：对称类型决定颜色 symmetry_det_color(a09f6c25)→创新为对称类型计数、计数 counting + 平铺 tiling + 色数决定重复次数 color_count_repetition(a59b95c0)→创新为对称数决定重复次数、双色互换 two_color_swap(b94a9452)→创新为条件性互换

**依赖链**：对称分类将对象分为水平对称和垂直对称两组 → 每组的数量分别决定水平和垂直平铺次数 → 平铺矩阵中棋盘格奇数位置的瓦片做前景色互换。对称分类同时控制了输出尺寸（计数→维度）和暗示了颜色变换规则的存在——两个看似独立的输出特征（尺寸和颜色模式）都源于同一个分类步骤。

统计水平对称和垂直对称对象的数量分别作为平铺的列数和行数，将输入网格按此维度平铺，并在棋盘格奇数位置的瓦片中互换两种前景色。

**输入结构**：约 8x8 网格，黑(0)背景。恰好两种非背景前景色（如蓝(1)和红(2)）。4-6 个 4-连通前景对象（每个 3-6 像素），每个对象仅使用一种前景色。每个对象恰好属于水平对称或垂直对称中的一种（不存在同时具有两种对称性的对象，也不存在无对称性的对象）。生成约束：水平对称对象数 H >= 2，垂直对称对象数 V >= 2，且 H != V（使得输出明显不是正方形平铺，便于区分哪个维度对应哪种对称类型）。

**规则**：
1. 对每个前景对象判断其反射对称类型（水平或垂直）。
2. 统计水平对称对象的数量 = H，垂直对称对象的数量 = V。
3. 将整个输入网格平铺为 H 列 x V 行的矩阵（水平方向并排 H 个副本，垂直方向堆叠 V 个副本）。
4. 在平铺矩阵中，将每个瓦片位置编号为 (行索引 i, 列索引 j)，从 (0,0) 开始。
5. 若 i + j 为奇数（棋盘格"奇"位），则该瓦片中的两种前景色互换（蓝(1)变红(2)、红(2)变蓝(1)），背景色不变。
6. 若 i + j 为偶数（棋盘格"偶"位），该瓦片保持原色不变。

**关键洞察**：对称分类不是给对象重涂色（如参考题 a09f6c25 那样），而是用来计数以决定平铺尺寸——这个从"分类→标签"到"分类→计数→几何参数"的映射转换必须通过对比不同示例中对象数量与输出网格尺寸的变化关系才能发现。棋盘格色彩互换则是第二层需要独立归纳的规则。

## 新题 6：格子压缩后同色对连线与交叉标黄

**组合逻辑**：[下采样](删除分隔行列改变空间关系) → [连线](同色像素对直线连接) → [重涂色](交叉点标记为黄色)

**来源原语**：下采样 downsample + 分隔行列 separator_rows_and_columns + 奇偶索引分离 even_odd_index_separation + 保留偶索引交叉 keep_even_crossings(68b67ca3)、连线 draw_line(41e4d17e/55783887)、交叉 crossing + 交叉点标记新色 crossing_cell_marked_new_color(bdad9b1f)

**依赖链**：下采样改变像素间的空间距离和对齐关系 → 压缩后某些同色对变为行对齐或列对齐（在原始网格中因分隔行列的存在而看起来未对齐） → 对齐的同色对可用直线连接 → 不同颜色的连线在空间中交叉产生黄色标记。压缩不只是视觉清理——它重构了决定连线可行性的几何关系。

删除格子状分隔行列压缩网格后，用直线连接每对同色像素，交叉处标黄。

**输入结构**：约 16x16 网格（偶数尺寸），灰(5)背景。所有奇数索引行（第1、3、5...行）和所有奇数索引列（第1、3、5...列）均为灰(5)背景色，构成格子状分隔网络。偶数行 x 偶数列的格点位置上分布着彩色像素。每种非背景非灰颜色恰好出现 2 个像素（同色成对），共 3-4 对不同颜色（如蓝(1)对、红(2)对、绿(3)对、橙(7)对）。生成约束：压缩后每对同色像素共享同一行或同一列（即可用水平或垂直直线连接）；至少两对像素的连线在压缩后的网格中产生空间交叉。

**规则**：
1. 删除所有奇数索引行和奇数索引列，仅保留偶数行 x 偶数列格点上的像素，形成尺寸为原来一半的紧凑网格。
2. 在紧凑网格中，找到每对同色像素。
3. 用该颜色的直线段连接每对同色像素（水平连接填充同行两点之间的所有单元格，垂直连接填充同列两点之间的所有单元格），连线包含两个端点。
4. 若某个单元格被两条或更多不同颜色的连线经过，将该单元格涂为黄(4)。
5. 绘制顺序：先绘制所有连线（后绘制的覆盖先绘制的，按颜色编号从小到大的顺序绘制），再将所有交叉位置涂为黄(4)。

**关键洞察**：在原始网格中，分隔行列使像素对在视觉上距离较远且行列编号的奇偶性掩盖了对齐关系；必须先完成压缩（删除分隔行列）才能发现哪些对是行/列对齐的。压缩改变了空间拓扑，是连线步骤的必要前置条件。

## 新题 7：边缘矩形深度与滑动距离编码同心框架参数

**组合逻辑**：[接触边缘 → 深度测量 + 距离计算](创新：不实际滑动，仅从空间位置提取两个独立参数) → [排序](按滑动距离排序确定层序) → [嵌套包裹](深度值作为每层框架厚度)

**来源原语**：接触边缘 touching_edge + 边缘矩形 edge_rectangle + 滑动 slide + 滑至对侧边缘 slide_to_opposite(b25e450b)→创新为仅测量距离不实际滑动、嵌套包裹 nested_wrapping + 同心正方形层 concentric_square_frame + 逐层构建 layer_by_layer_build + 条高决定框厚 stripe_height_as_thickness(45a5af55)→创新为深度决定框厚、排序拼接 sort_and_concatenate(12997ef3)→创新为按距离排序、距离 distance(b8cdaf2b)

**依赖链**：边缘接触方向确定每个矩形的"深度"维度（垂直于接触边方向的尺寸） → 矩形内侧边缘到对侧边界的距离决定嵌套层序（距离小的在内层） → 深度值作为对应层的框架厚度。同一空间配置同时编码了层序（距离）和层厚（深度），两种信息从同一输入结构中读取但用途完全不同。

每个边缘矩形的深度决定同心框的层厚，到对侧边界的距离决定从内到外的嵌套层序，据此构建同心正方形框架。

**输入结构**：约 15x15 网格，黑(0)背景。3-5 个不同颜色的实心矩形（如蓝(1)、红(2)、绿(3)、橙(7)、品红(6)），每个矩形恰好接触一条外边界（上/下/左/右）。"深度"定义为矩形沿垂直于其接触边方向的像素行数或列数（例如：触顶边的矩形深度 = 它占据的行数；触左边的矩形深度 = 它占据的列数）。各矩形深度在 1-3 的范围内。生成约束：每个矩形内侧边缘到对侧边界的距离互不相同（确保排序无歧义）；矩形之间不重叠。

**规则**：
1. 对每个边缘矩形，确定其接触的边界方向，据此计算"深度"（垂直于接触边方向的像素尺寸）和"滑动距离"（矩形内侧边缘到对侧网格边界的像素距离）。
2. 按滑动距离从小到大排序所有矩形。
3. 距离最小的矩形：其颜色成为最内层中心实心正方形，正方形边长 = 该矩形的深度。
4. 按排序顺序，后续每个矩形依次向外包裹一层正方形框架：框架厚度 = 该矩形的深度，框架颜色 = 该矩形的颜色。
5. 输出为独立的同心正方形结构，裁剪至刚好包含完整图案的最小正方形网格，与原始网格中矩形的位置无关。

**关键洞察**：同一个矩形同时贡献了两个用途不同的参数——滑动距离决定它在同心框中从内到外的层级，深度决定它对应框架的厚度。两个量都从矩形在网格中的空间位置提取，但一个控制排序、一个控制几何，必须通过对比多个示例（不同距离和深度的组合产生不同的同心框结构）才能分离出这两条独立规则。

## 新题 8：镜像色带产生涌现障碍用于轨迹射线擦除

**组合逻辑**：[镜像](色带翻转到对侧，创造输入中不存在的新像素) → [反向投射](轨迹指示来源方向，射线沿反方向发射) → [首个障碍](射线命中目标包括镜像产生的像素) → [擦除](被命中像素消失)

**来源原语**：镜像 mirror + 色带行 colored_row_band + 色带翻转到对侧 band_flip_opposite(496994bd)、反向投射 opposite_direction + 轨迹 trail + 标记像素 marker_pixel(9f8de559)、射线延伸 ray_cast + 首个障碍 first_obstacle(9f8de559)、擦除 erase(9f8de559)

**依赖链**：镜像操作在网格下方生成原本不存在的新像素 → 这些新像素成为射线的潜在障碍 → 射线方向由标记的品红轨迹反向决定 → 射线命中的第一个非背景像素被擦除（该像素可能是原始色带像素或镜像新生成的像素）。关键耦合在于：被擦除的目标的存在依赖于镜像步骤——不完成镜像就无法正确推断射线目标。

将顶部色带镜像到底部后，从红色标记沿轨迹反方向发射射线，擦除射线命中的第一个非背景像素（可能是镜像产生的新像素）。

**输入结构**：约 15x15 网格，黑(0)背景。顶部 2-3 行为色带，包含非背景色像素和背景色像素的混合图案（如蓝(1)、绿(3)像素散布于黑色背景中，形成不规则的点阵图案）。底部对应行数为全黑(0)背景（用于接收镜像内容）。网格中部区域有 2-3 个红(2)标记像素。每个红色标记旁有 2-3 个相邻的品红(6)像素组成直线轨迹（沿一个基本方向排列：上、下、左、右之一）。生成约束：至少一个红色标记的射线方向（轨迹反方向）指向底部区域（会命中镜像生成的像素），至少一个指向顶部区域（命中原始色带像素）。各红色标记的射线路径互不重叠。

**规则**：
1. 将顶部色带逐行垂直翻转后放置到底部对应位置：顶部第0行的图案映射到底部最后一行，第1行映射到倒数第2行，依此类推。原始顶部色带保留不变。
2. 对每个红(2)标记像素，根据其相邻的品红(6)轨迹确定射线方向：轨迹从标记延伸出的方向为"来源方向"，射线沿相反方向发射。
3. 射线从红色标记位置出发（不含标记自身位置），沿确定方向逐像素前进。
4. 射线遇到的第一个非背景(非黑(0))像素即为命中目标——将该像素擦除为黑(0)背景色。
5. 若射线到达网格边界仍未命中任何非背景像素，则不做任何擦除。
6. 擦除所有品红(6)轨迹像素（全部设为黑(0)背景色）。
7. 红(2)标记像素保留在输出中不变。

**关键洞察**：镜像操作创造了输入中不存在的障碍像素——向底部发射的射线会命中由镜像新生成的色带像素，而非原始输入中的任何内容。求解者必须在心理上先完成色带镜像操作，再推算每条射线的命中目标，这两步不可颠倒且相互纠缠。需要对比向上射线（命中原始色带）和向下射线（命中镜像色带）的示例才能发现镜像是先决步骤。
