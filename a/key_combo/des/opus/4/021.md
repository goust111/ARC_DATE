## 新题 1：走廊重力竞标染框

**组合逻辑**：[重力下落](创新：令牌沿墙壁走廊下落至空心框) + [重涂色](创新：涂色目标从列段改为空心框边框) + [计数 + 频率唯一性](创新：颜色全局频率用于冲突仲裁而非目标定位)

**来源原语**：重力下落/gravity_drop (2b83f449), 令牌/token (2b83f449), 碰撞停止/collision_stop (2b83f449), 墙壁障碍/wall_barrier (dd6b8c4b), 可达性/reachability (dd6b8c4b), 空心矩形/hollow_rectangle (a04b2602), 重涂色/recolor (9b365c51), 计数/counting (31aa019c), 频率唯一性/frequency_uniqueness (31aa019c), 忽略干扰项/ignore_distractors (a04b2602)

**依赖链**：墙壁走廊拓扑限定令牌可达范围 → 重力决定落点 → 落点是否在空心框内决定框是否被激活 → 多令牌竞争同一框时，颜色全局稀有度仲裁胜者 → 胜者颜色重涂框边界

从墙壁走廊中下落彩色令牌至底部空心框，以到达者的颜色重涂框边界，死路令牌被擦除，多令牌争夺同一框时全局最稀有颜色胜出。

**输入结构**：
- 网格约 15x15，黑(0)背景。
- 品红(6)墙壁像素（每段宽 1 像素、长度不等）构成若干竖直走廊，宽 1-3 格。部分走廊向下延伸至底部区域，部分被墙壁封死或在网格底边终止而不通往任何框（死路）。个别走廊在中段合并为一条。
- 网格顶部或近顶部位置放置 3-6 个单像素彩色令牌，颜色取自红(2)、绿(3)、蓝(1)、黄(4)，各自位于某条走廊入口处。令牌颜色可重复（如两个红令牌、一个绿令牌）。
- 网格底部区域放置 2-4 个灰(5)空心矩形框（外尺寸 3x3 至 5x5，边框厚 1 像素，内部为黑(0)）。每个框的顶侧开口与恰好一条走廊出口对齐。并非所有走廊都通往框，也并非所有框都有令牌可达。
- 生成约束：每个框最多被 2 条走廊通达；每条走廊最多通往 1 个框。

**规则**：
1. 每个令牌沿其走廊逐格下落，遇到墙壁像素、网格边界则停止；若走廊通往某空心框，令牌进入框内部（停在框内第一行可用位置）。
2. 处于死路走廊的令牌（下方无框可达或走廊中途被封堵）擦除为黑(0)。
3. 令牌成功进入某框时，该框所有灰(5)边框像素重涂为该令牌的颜色。令牌本身保留在落点位置，保持原色。
4. 若两个令牌经由合并走廊到达同一框：统计整个输入网格中每种令牌颜色的总出现次数。全局出现次数更少（更稀有）的颜色胜出并重涂该框；落败令牌擦除为黑(0)。
5. 若稀有度计数平局，则原始位置列编号更小（更靠左）的令牌胜出。

**关键洞察**：死路走廊产生干扰令牌，被直接丢弃；竞争同一框的令牌之间的仲裁不是空间性的（不是谁先到达），而是统计性的（哪种颜色在全局更稀有）——这条规则只有对比不同令牌分布的多个示例才能归纳。

## 新题 2：块网格解码后流线穿行

**组合逻辑**：[反转编码 + 修复](精灵与空白互换，清理灰色通配符) → [流动绘制](创新：流线在解码后的结构中穿行，可通行性由反转结果决定而非原始网格)

**来源原语**：反转编码/invert_code (6350f1f4), 修复/repair (6350f1f4), 块网格/block_grid (6350f1f4), 重复精灵体/repeated_sprite (6350f1f4), 均匀空白块/uniform_blank (6350f1f4), 精灵与空白互逆/sprite_blank_inv (6350f1f4), 通配符视为空/wildcard_as_blank (6350f1f4), 流动绘制/flow_draw (f15e1fac), 边缘起点像素/edge_source_pixel (f15e1fac)

**依赖链**：块网格结构识别 → 精灵推断（多数表决跳过灰色损坏） → 精灵↔空白反转确定哪些宏块变为实心墙、哪些变为通道 → 边缘起点像素决定流线起点和方向 → 流线沿通道块内背景像素水平推进，遇实心墙块停止

将块网格中精灵编码块与均匀空白块互换解码，然后从左侧边缘起点像素发射水平流线，流线仅能穿过解码后变为通道的块内背景像素，遇到解码后变为实心墙的块立即停止。

**输入结构**：
- 网格约 16x16，由黑(0)分隔行和分隔列（各宽 1 像素）划分为规则排列的等大方形块（例如 4x4 块，构成 3x3 的宏网格，或 3x3 块构成 4x4 宏网格）。
- 每个块为以下两种之一：(a) 一个双色精灵的副本（例如蓝(1)前景像素绘制在红(2)背景上）——"编码块"；(b) 由精灵少数色均匀填充的实心块——"空白块"。
- 部分块内像素可能为灰(5)，表示损坏/通配符。
- 网格左侧边缘（分隔列或最左块列）出现若干绿(3)单像素，每个宏行最多一个，位置对齐到块内部行。这些是边缘起点像素。
- 生成约束：精灵内部的背景色像素（红(2)）构成连通可穿行路径；解码后至少存在一条从左边缘到右边缘的水平贯通路径。

**规则**：
1. 通过对所有无灰色损坏的混色块做多数表决，推断出重复精灵。
2. 解码：匹配精灵的块（灰色通配符视为匹配）替换为精灵多数色的实心块（墙）；均匀空白块替换为精灵副本（通道）。分隔行列上的灰色像素恢复为黑(0)。
3. 解码后，实心块为不可通行墙壁。精灵通道块内，背景色像素（红(2)）可穿行，前景色像素（蓝(1)）不可穿行。黑(0)分隔行列像素可穿行。
4. 从每个绿(3)边缘起点像素出发，向右发射水平流线。流线逐像素推进，仅通过可穿行像素。遇到不可穿行像素（精灵前景色、实心墙块像素）或网格右边界时停止。
5. 流线经过的像素涂为绿(3)，覆盖原有颜色。边缘起点像素保持绿(3)。

**关键洞察**：块级反转从根本上翻转了可穿行区域——原来"空"的均匀块变成了精灵填充的通道，而原来包含精灵的块变成了实心墙。不先完成反转就无法预判流线路径。

## 新题 3：平行四边形构造与包含触发的洪水填充

**组合逻辑**：[连线 + 对角分解](对角+轴向分解绘制平行四边形轮廓) + [填充](创新：洪水填充构造出的平行四边形内部，非预存区域) + 内部包含判定(创新：包含关系作用于计算生成的几何体，非原有边界框)

**来源原语**：连线/line_drawing (cb227835, bcb3040b), 对角分解/diag_decompose (cb227835), 标记像素/marker_pixel (cb227835, bcb3040b), 平行四边形轮廓/parallelogram (cb227835), 标记为对顶点/markers_as_vertices (cb227835), 填充/fill (a699fb00, 3ad05f52), 内部包含/containment (3de23699), 包含于边界框/in_bounding_box (a04b2602), 忽略干扰项/ignore_distractors (a04b2602)

**依赖链**：同色标记对识别 → 偏移向量对角分解 → 平行四边形轮廓绘制 → 黄色涂源像素的包含性判定（涂源在哪个平行四边形内？） → 包含涂源的平行四边形内部洪水填充为黄色 → 无涂源的平行四边形保持空心 → 落在所有平行四边形外部的涂源作为干扰项擦除

通过对角分解从标记对构造平行四边形轮廓，仅对包含黄色涂源像素的平行四边形执行内部洪水填充，外部涂源视为干扰项擦除。

**输入结构**：
- 网格约 15x18，黑(0)背景。
- 2-3 对同色标记像素，每对使用独特颜色（例如一对红(2)、一对蓝(1)、一对绿(3)）。每对标记之间既有行偏移又有列偏移，且两个分量的绝对值不等（既非纯轴向对齐也非纯 45 度对角线）。
- 3-5 个黄(4)单像素散布于网格各处（"涂源像素"），部分位于最终将被构造出的平行四边形内部，部分位于所有平行四边形外部。
- 生成约束：任意两个平行四边形的轮廓像素互不重合；涂源像素不落在任何平行四边形的轮廓上。

**规则**：
1. 对每对同色标记，将标记间偏移向量分解为一个 45 度对角分量（行列位移绝对值相等，方向与原始偏移的行列符号一致）和一个剩余纯轴向分量（纯水平或纯竖直）。对角分量取行列位移绝对值中较小者为步长。
2. 以两个标记为对顶点、上述两个分量向量为邻边，绘制平行四边形轮廓。轮廓颜色为灰(5)，原始标记像素保持原色不被覆盖。
3. 所有平行四边形绘制完毕后，检测每个黄(4)涂源像素：若它严格位于某个平行四边形内部（被轮廓完全包围），则对该平行四边形执行内部洪水填充为黄(4)。轮廓像素保持灰(5)，标记像素保持原色。
4. 不包含涂源的平行四边形内部保持黑(0)。
5. 位于所有平行四边形外部的黄色涂源像素擦除为黑(0)。
6. 若两个平行四边形的内部区域存在重叠（在生成约束的边界案例中可能出现）：重叠区域中的涂源仅触发面积更小的平行四边形填充。面积更大的那个不会被该涂源触发，除非它拥有自己的独立涂源（位于非重叠区域）。

**关键洞察**：平行四边形在构造完成前不存在——看似随机散布的涂源像素实际上是相对于尚未生成的几何体定位的。包含关系是在计算生成的形状与输入像素之间建立的，而非基于预存区域。

## 新题 4：自相似印章展开与锚点编码变色

**组合逻辑**：[像素放大/印章覆盖 + 自相似嵌套](图案自扩展为块网格) + [重涂色](创新：涂色由图案内锚点像素的角色决定，非外部调色板或角标)

**来源原语**：像素放大/scale_up (8f2ea7aa), 印章覆盖/stamp (8f2ea7aa, a04b2602), 自相似嵌套/self_similar_nesting (8f2ea7aa), 前景位置决定印章/foreground_positions_determine_stamp (8f2ea7aa), 重涂色/recolor (3de23699, 9b365c51), 内部包含/containment (3de23699), 角标色决定重涂/corner_color_sets_recolor (3de23699), 标记像素/marker_pixel (a04b2602)

**依赖链**：图案裁剪与边界框识别 → 前景像素分为基色与锚色两类 → 自相似扩展（每个前景位置粘贴完整图案） → 锚色位置对应的宏块整体变色 → 变色块内部锚点像素保持锚色，形成嵌套色彩层级

将含有双色前景的小图案自相似展开，锚色像素位置对应的宏块内所有基色像素变为第三色，而锚色像素自身保持不变，形成层级分明的双色分形。

**输入结构**：
- 网格尺寸为 NxN 的平方（例如 3x3 图案对应 9x9 网格，4x4 图案对应 16x16 网格），黑(0)背景。
- 一个紧凑图案占据网格中某个 NxN 区域。图案中大部分前景像素为蓝(1)（基色），另有 1-3 个前景像素为红(2)（锚色）。图案总前景像素数 3-7 个。
- 网格其余部分为黑(0)。
- 生成约束：图案至少包含一个蓝(1)前景像素和一个红(2)前景像素；图案的边界框恰好为 NxN，无空白边行或边列。

**规则**：
1. 裁剪图案的 NxN 边界框。
2. 对图案中每个前景像素（蓝或红）在局部位置 (r, c)，将完整图案粘贴到输出的第 (r, c) 个 NxN 宏块中。背景位置对应的宏块保持全黑。
3. 若宏块位置 (r, c) 在原始图案中是蓝(1)基色像素：粘贴的图案保持原色（蓝不变、红不变、黑不变）。
4. 若宏块位置 (r, c) 在原始图案中是红(2)锚色像素：粘贴的图案中所有蓝(1)像素重涂为绿(3)；红(2)像素保持红(2)；黑(0)保持黑(0)。
5. 未被任何前景像素激活的宏块保持全黑。

**关键洞察**：锚色像素承担双重角色——它既是图案形状的一部分（决定宏块放置位置），又是该宏块颜色变换的控制信号。识别这种双重身份需要观察到锚色位置的宏块总是产生绿色副本、而基色位置总是产生蓝色副本，这一规律需对比不同图案形状的多个示例方可确认。

## 新题 5：调色板列段重涂后镜像拼装

**组合逻辑**：[重涂色 + 顺序一一对应](调色板按序映射至列段) → [裁剪 + 擦除](移除调色板列) → [镜像 + 拼接](创新：对涂色后结果构建四象限镜像拼图，非原始网格)

**来源原语**：重涂色/recolor (9b365c51), 顺序一一对应/order_correspondence (9b365c51), 调色板列/palette_column (9b365c51), 目标列段/target_column_run (9b365c51), 按列段分组匹配/column_run_group_match (9b365c51), 擦除/erase (9b365c51), 裁剪/crop (3de23699), 镜像/mirror (0c786b71), 拼接/concatenation (0c786b71), 四象限对称/four_quadrant_symmetry (0c786b71)

**依赖链**：目标图形列段分割 → 调色板从左到右顺序对应列段 → 列段内灰色像素按对应调色板颜色重涂 → 调色板列擦除 → 涂色后的图形裁剪至边界框 → 裁剪结果作为右下象限构建四象限镜像拼图

将单色绘图的各列段按调色板顺序着色，裁去调色板，再以着色结果为右下象限构建四象限对称镜像拼图。

**输入结构**：
- 网格约 8x16，黑(0)背景。
- 左侧部分：2-4 列全高单像素宽调色板列，各使用不同颜色（如红(2)、绿(3)、蓝(1)、黄(4)），相邻调色板列之间以及调色板与目标图形之间各隔 1 列黑色间距。调色板从左到右的颜色顺序有意义。
- 右侧部分：一个由单一目标色灰(5)绘制的连通图形，由若干列段组成。每个列段是一组相邻且竖直跨度（前景像素的最上行与最下行）完全相同的列的极大分组。列段数量等于调色板列数量。
- 生成约束：各列段的竖直跨度互不相同（可通过不同的起始行或结束行区分）；调色板列数量恰好等于目标图形的列段数量。

**规则**：
1. 从左到右扫描目标图形，将相邻且竖直跨度完全一致的列归为同一列段，得到极大列段序列。
2. 按从左到右的顺序将调色板列与列段一一对应：第 1（最左）调色板色对应第 1（最左）列段，依此类推。
3. 将每个列段中的灰(5)前景像素重涂为对应调色板颜色。
4. 擦除所有调色板列（替换为黑(0)）。
5. 将涂色后的目标图形裁剪至其紧凑边界框（包含所有非黑像素的最小矩形）。
6. 以裁剪结果为右下象限构建四象限镜像拼图：右下为原图，左下为左右镜像，右上为上下镜像，左上为 180 度旋转。

**关键洞察**：镜像拼图会放大任何涂色错误——四个象限使错误配色一目了然。调色板排列顺序是隐含的映射纽带：不是空间邻近度、而是严格的从左到右序列将颜色配对到列段。需要对比不同调色板排列的多个示例才能确认这一规则。

## 新题 6：重力着陆后虚线间隙染色

**组合逻辑**：[滑动/重力下落](创新：前景对象下落至虚线段而非网格底部，接触即停) + [填充 + 单像素间隙补填](创新：间隙填充颜色来自着陆对象而非固定颜色) + 邻接关系(着陆判定)

**来源原语**：滑动/sliding (a79310a0), 移动并变色/shift_and_recolor (a79310a0, 部分使用移动组件), 填充/fill (a699fb00), 虚线段/dashed_segment (a699fb00), 邻接/adjacency (a699fb00), 单像素间隙补填/single_gap_filled (a699fb00), 前景对象/foreground_object (a79310a0)

**依赖链**：前景对象位置与虚线位置共同决定着陆目标 → 重力决定每个对象停在哪条虚线上方 → 着陆对象的颜色成为该虚线的间隙填充色 → 多对象共享一条虚线时，按着陆列位从左到右循环分配颜色

彩色小对象受重力下落至水平虚线段上方，以着陆对象的颜色填充该虚线的单像素间隙；多对象共线时按水平位序循环着色。

**输入结构**：
- 网格约 14x14，黑(0)背景。
- 3-5 条水平蓝(1)虚线段：每条由蓝色像素和单像素黑色间隙交替组成（蓝、黑、蓝、黑……），横跨网格大部分宽度，位于不同行高度，相邻虚线之间至少间隔 3 行空行。
- 2-4 个小型彩色前景对象（每个 3-6 像素，4-连通，单色，颜色取自红(2)、绿(3)、黄(4)、橙(7)中的不同色），悬浮在虚线上方。每个对象的列范围与至少一条下方虚线重叠。
- 生成约束：初始状态下无对象直接接触虚线；每条虚线上方至少有一个对象；同列范围内的多个对象位于不同高度（无竖直重叠）。

**规则**：
1. 每个前景对象整体向下平移（逐行移动，保持形状），直到其最下方像素恰好位于某蓝色虚线像素正上方一行（与虚线相邻）。若对象下方有多条虚线，停在遇到的第一条（最上方的一条）。
2. 在输出中绘制对象的新位置（保持原色），擦除原始位置为黑(0)。
3. 对每条虚线，收集所有着陆在其上方的对象。按对象最左像素的列编号从小到大排序。
4. 从左到右填充该虚线的各单像素黑色间隙：第 1 个间隙用第 1 个着陆对象的颜色，第 2 个间隙用第 2 个对象的颜色……当间隙数多于对象数时，循环回到第 1 个对象的颜色继续。
5. 若某条虚线无对象着陆（所有上方对象都先被更高的虚线截停），其间隙保持黑(0)。
6. 蓝色虚线像素本身保持蓝(1)不变。

**关键洞察**：间隙填充颜色不是静态的——它取决于哪些对象在重力作用下物理到达了该虚线。多对象共线时的循环着色分配是一条隐蔽规则，需要观察对象数量与间隙数量比例不同的多个示例才能归纳。

## 新题 7：角框模板提取后的标记点印章铺设

**组合逻辑**：[裁剪 + 角标色决定重涂](提取角标框内图案并重涂) → [印章覆盖/平铺](创新：提取的图案作为印章在外部标记点位置铺设，非自相似展开)

**来源原语**：裁剪/crop (3de23699), 重涂色/recolor (3de23699), 角标记像素/corner_marker (3de23699), 中心图案/central_pattern (3de23699), 边框/frame (3de23699), 内部包含/containment (3de23699), 角标色决定重涂/corner_color_sets_recolor (3de23699), 平铺/tiling (3979b1a8), 印章覆盖/stamp (a04b2602, 8f2ea7aa), 标记像素/marker_pixel (a04b2602)

**依赖链**：角标像素识别 → 边界框裁剪 → 角标颜色统一涂色 → 移除外框得到内部图案 → 图案作为印章模板 → 红色标记点确定各印章放置位置 → 重叠区域按标记点空间优先级解决冲突

从角标框中提取内部图案并以角标色重涂，然后以该图案为印章在各红色标记点位置逐一铺设，重叠时上方靠左的标记优先。

**输入结构**：
- 网格约 14x14，黑(0)背景。
- 网格中央偏某方向有一个非黑色集群：一个蓝(1)中心图案（3-6 像素，任意 4-连通形状）被 1 像素厚的边框包围。边框的四个角为黄(4)角标像素，边框的非角像素为灰(5)。
- 集群外部散布 2-5 个红(2)单像素（"放置标记"）。标记之间的间距大多不小于图案边界框尺寸，但至少有一对标记距离较近，可能导致印章重叠。
- 生成约束：集群足够小，使得所有标记点处的印章不会超出网格边界。

**规则**：
1. 识别四个黄(4)角标像素，裁剪集群至其边界框。
2. 将裁剪区内所有非黑像素（边框和内部图案）统一重涂为黄(4)。
3. 移除外层 1 像素边框，得到纯黄(4)的内部图案。
4. 生成一个与输入同尺寸的全黑(0)输出网格。
5. 在每个红(2)标记点位置放置印章：印章的左上角对齐到标记位置，用黄(4)绘制图案前景像素，图案边界框内的黑色像素保持黑(0)。
6. 若两个印章的像素范围重叠，行编号更小的标记点优先（其印章像素覆盖后者）。行编号相同时，列编号更小的标记点优先。
7. 红色标记像素本身被印章覆盖（不保留）。

**关键洞察**：角标框中的集群不是最终输出——它是一个"模板工厂"。真正的变换是将该模板的空间分布由外部标记点决定。重叠优先级规则（上方、靠左的标记胜出）必须通过包含重叠情况的多个示例才能推断。

## 新题 8：迷宫多源寻路与距离渐变涂色加交叉印章

**组合逻辑**：[寻路 + 最短路径](多对端点间寻路) + [重涂色 + 按原色区分涂色](创新：路径像素按距离最近端点着色而非按穿过的原始颜色着色) + [印章覆盖](创新：印章在路径交叉点动态触发，非在预设标记位置)

**来源原语**：寻路/pathfinding (3ad05f52), 最短路径/shortest_path (3ad05f52), 端点分量/endpoint_component (3ad05f52), 走廊通道/corridor (3ad05f52), 墙壁障碍/wall_barrier (dd6b8c4b), 重涂色/recolor (bcb3040b), 按原色区分涂色/recolor_by_origin (bcb3040b), 印章覆盖/stamp (a04b2602), 碰撞停止/collision_stop (2b83f449)

**依赖链**：迷宫墙壁定义可通行图 → 三对端点间分别求最短路径 → 路径像素按沿路距离归属最近端点 → 端点颜色决定路径像素重涂色 → 同时属于两条路径的交叉像素触发十字印章 → 印章覆盖路径涂色

在三个彩色端点之间穿过迷宫求最短路径，每个路径像素涂为距其最近的端点颜色，两条路径相交处盖上黄色十字印章。

**输入结构**：
- 网格约 16x16，橙(7)背景（地板）。
- 品红(6)墙壁像素构成迷宫，走廊宽 1-2 格，4-连通拓扑。
- 恰好三个端点分量，各为一个 2x2 实心方块，颜色分别为红(2)、蓝(1)、绿(3)。三个端点位于迷宫不同区域，彼此通过走廊连通。
- 生成约束：每对端点之间存在最短路径；至少一个像素格同时被两条不同对的最短路径经过（交叉存在）；没有任何像素格同时被全部三条对路径经过。

**规则**：
1. 对三对端点（红-蓝、红-绿、蓝-绿）分别计算穿过地板像素的最短 4-连通路径。若某对存在多条等长最短路径，选取路径上所有像素的 (行, 列) 坐标字典序总和最小的那条（偏好靠上靠左的路线）。
2. 对每个仅属于一条对路径的路径像素：计算它沿路径到该对两个端点的步数距离，涂为距离更近的端点的颜色。若到两端点等距，涂为行坐标更小的端点颜色；行坐标也相同则涂为列坐标更小的端点颜色。
3. 对两条不同对路径交汇的像素（该像素同时出现在两条对路径上）：以该像素为中心，绘制一个 3x3 十字形印章（中心 + 上下左右 4 个正交邻居），颜色为黄(4)。印章仅绘制在地板像素上（不覆盖墙壁或端点分量）。印章覆盖下方已有的路径涂色。
4. 端点分量像素保持原色不变。
5. 非路径、非端点、非印章的地板像素保持橙(7)。墙壁保持品红(6)。

**关键洞察**：交叉印章只有在计算完全部三对路径后才能确定——单独一对路径不产生交叉。距离渐变涂色在每条路径上创造了从一端颜色过渡到另一端颜色的视觉效果，而黄色十字标记出迷宫中的关键汇合节点。涂色规则和交叉检测都需要对比不同迷宫布局的多个示例才能归纳。
