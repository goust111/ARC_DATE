## 新题 1：嵌套深度决定射线长度

**组合逻辑**：[包含树检测](已有) → [计数·嵌套深度](创新：计数对象从弯折数改为嵌套层数) → [射线延伸·深度参数化](创新：射线长度不再由墙段决定，而由拓扑深度量化) + [重涂色](已有)

**来源原语**：包含树/嵌套框架(2d0172a1), 射线延伸(f9a67cb5/140c817e), 计数(e509e548), 重涂色(e509e548/140c817e)

**依赖链**：必须先检测嵌套框架的包含树才能确定每个控制像素的深度；深度同时决定射线长度，而控制像素相对于最内层框架的位置决定射线方向——两者缺一则射线无法确定。

从嵌套框架内的控制像素出发，沿朝向最近框边的方向发射射线，射线长度等于该像素的嵌套深度，同时将控制像素本身重涂为红色。

**输入结构**：
- 黑(0)背景，约 15x15。
- 灰(5)像素组成若干严格嵌套的矩形空心框（即每个框完全包含在另一个框内部，或完全在所有框外部；不存在部分重叠）。框的数量为 2~3 层。
- 在不同嵌套深度的空间内，散布着若干孤立的彩色控制像素（颜色取自 {蓝(1), 绿(3), 黄(4), 橙(7)}，每个像素颜色可不同）。每个控制像素严格位于某一层框的内部（不在框线上）。
- 生成约束：每个控制像素到其最内层包围框的四条边的距离各不相等（确保最近边唯一）；每个控制像素的嵌套深度（包围它的框的数量）至少为 1、至多为 3；射线路径在网格范围内且不会有两条射线交叉在同一个像素上。

**规则**：
1. 检测所有灰(5)框对象，构建包含树（框 A 包含框 B 当且仅当 B 的所有像素都在 A 围成的封闭区域内部）。
2. 对每个控制像素，计算其嵌套深度 D = 包围它的灰色框的数量。（最外层框内部、第二层框外部的像素 D=1；两层框之间 D=1；最内层框内部 D 等于总框数。）
3. 对每个控制像素，确定其最内层包围框（即直接包含它的那个框），找到该框四条边中距离该像素最近的那条边，射线方向为从像素指向该边（上/下/左/右）。
4. 从控制像素出发沿射线方向，依次将接下来的 D 个格子涂为该控制像素的原始颜色（若射线到达网格边界则在边界处截断）。射线经过灰色框线时直接覆盖。
5. 将每个控制像素本身重涂为红(2)。

**关键洞察**：嵌套框架的包含层级不仅是需要检测的拓扑结构（如参考题 2d0172a1 中用于规范化布局），更是一个量化参数，直接控制另一个空间操作（射线延伸）的幅度。拓扑深度与几何距离的这种跨域耦合在所有参考题中均不存在。

## 新题 2：弯折拓扑优先的贪心走步与双重编码走廊

**组合逻辑**：[计数·弯折数](已有) → [贪心遍历·弯折优先](创新：遍历优先级从距离改为拓扑属性) + [连线·弯折编码色](创新：走廊颜色不再是固定的橙色，而由目的地的几何拓扑决定) → [重涂色](已有)

**来源原语**：弯折数分类/弯折数决定颜色(e509e548), 贪心遍历/最近未访问优先/视线可见/视线遮挡判断(3490cc26), 连线/走廊路径(3490cc26), 重涂色(e509e548)

**依赖链**：弯折数同时决定两件事——走步优先级和走廊颜色。不计算弯折数则既无法确定访问顺序，也无法确定涂色。而走步顺序又影响哪些形状"可见"（已访问形状遮挡视线），因此弯折数通过优先级间接改变后续的可见集。

从起点出发，在可见的未访问形状中优先走向弯折数最少的目标；走廊颜色由目的地形状的弯折数编码；到达后将形状重涂为走廊颜色。

**输入结构**：
- 黑(0)背景，约 18x18。
- 若干绿(3)的小型 4-连通单色形状（每个 3~8 像素），每个形状包含 1、2 或 3 个拐弯（L 形 2x2 弯折模式，可出现在任意旋转方向）。不同示例中同类弯折数的形状具体外形不同。至少每种弯折数各出现一个形状。
- 一个红(2)的单像素标记起点。
- 形状排布使得从起点和每个形状出发，至少有一个其他形状与之共享两行或两列的视线带（即存在公共的两行或两列区间，且带内无非背景像素遮挡）。
- 生成约束：在每一步贪心选择中，当弯折数相同时，曼哈顿距离最近者唯一（不存在平局）。

**规则**：
1. 对每个绿色形状，裁剪其边界框，统计其中所有旋转方向的 L 形 2x2 弯折模式数量，得到弯折数 B（1、2 或 3）。
2. 从红色起点开始贪心遍历：
   a. 在当前位置的视线范围内（与当前位置共享两行带或两列带、且带内无非背景像素遮挡的形状）找出所有未访问的绿色形状。
   b. 在这些形状中选择弯折数 B 最小的；若 B 相同，选曼哈顿距离最近的。
   c. 将当前位置与目标形状之间的背景间隙涂上走廊颜色：B=1 → 蓝(1)，B=2 → 品红(6)，B=3 → 橙(7)。走廊沿两行带或两列带的中线绘制（与参考题 3490cc26 的走廊绘制方式相同）。
   d. 将目标形状的所有像素从绿(3)重涂为其走廊颜色。
   e. 从该形状继续下一步遍历。已访问的形状视为非背景障碍物，会遮挡后续视线。
3. 当从当前形状出发无可见未访问形状时停止。

**关键洞察**：弯折数在参考题中只决定静态重涂色（属性→颜色映射），在本题中它还兼任贪心遍历的优先级指标，使同一个几何属性同时控制走步顺序和视觉输出。由于已访问形状会遮挡视线，弯折优先级还间接改变了后续步骤的可达集合——一个早期看似远但弯折少的形状被优先访问后，可能遮挡住原本可见的其他形状。

## 新题 3：标记门控的四重对称补全

**组合逻辑**：[对称补全·四重旋转](已有) × [标记激活块](已有) → [填充·交叉判定着色](创新：填充颜色不再由标记颜色决定，而由两个独立激活机制的交集/差集决定)

**来源原语**：对称补全/角落补全四重对称(4290ef0e), 标记激活块/中心标记触发/宏块格阵(ce22a75a), 填充(ce22a75a/af902bf9)

**依赖链**：对称补全给出"理想位置集"，标记给出"允许位置集"，两者的交集决定蓝色填充，标记独有的位置变为红色。删除对称补全则无法区分蓝与红；删除标记检测则无法判断哪些对称位置被实际激活。两个机制作用于同一个宏块坐标系，输出颜色编码了它们的集合关系。

在宏块格阵上，将局部角落色块扩展为四重旋转对称的完整图案，但只有同时拥有灰色中心标记的宏块才真正被填充为蓝色；有标记但不在对称位置的宏块被填充为红色。

**输入结构**：
- 网格尺寸为 3 的倍数（如 15x15），概念上构成 5x5 宏块格阵，每个宏块 3x3。背景黑(0)。
- 在宏块格阵的一或两个角落区域，若干宏块被整体填充为蓝(1)——这些是四重旋转对称图案的局部可见角。
- 独立地，一些宏块的中心位置（即宏块内第 2 行第 2 列）有一个灰(5)像素——这些是"启用标记"。启用标记可以出现在蓝色块内、也可以出现在空白块内。
- 生成约束：蓝色角落块的完整四重旋转对称补全是良定义的（即对称中心为宏块格阵的中心）；对称推断出的非原始蓝色位置中，至少有一个拥有启用标记、至少有一个缺少启用标记；至少有一个启用标记不在任何对称推断位置上。

**规则**：
1. 识别所有原始蓝(1)宏块的位置（在 5x5 宏块坐标系下）。
2. 计算这些位置关于宏块格阵中心的四重旋转对称闭包（0/90/180/270 度旋转），得到"理想对称位置集" S。
3. 识别所有拥有灰(5)中心标记的宏块位置，得到"启用位置集" E。
4. 对于 S 中的每个位置：
   - 如果该位置是原始蓝色块 → 保持蓝(1)整块填充，不论是否有启用标记。
   - 如果该位置不是原始蓝色块但属于 E（有启用标记）→ 整块填充为蓝(1)。
   - 如果该位置不是原始蓝色块且不属于 E → 保持黑色（对称补全被门控阻断）。
5. 对于 E 中但不在 S 中的位置 → 整块填充为红(2)。
6. 所有灰色中心标记在输出中被消除（被蓝色或红色覆盖，或被黑色背景覆盖）。

**关键洞察**：对称补全和标记激活是两个独立的空间模式，它们各自无法决定输出——输出颜色编码的是两者的集合关系（交集=蓝，标记独有=红，对称独有=不填充）。求解者必须同时重建完整对称图案和识别标记分布，再交叉判定每个宏块的命运。

## 新题 4：框边色编码的精灵体旋转印章与距离分层

**组合逻辑**：[颜色对应边](已有) → [旋转·边色决定角度](创新：旋转角度不再是固定交替，而由颜色-方向映射确定) + [印章覆盖·锚点定位](创新：印章位置由锚点对齐决定，而非自身模板对应) → [冲突解决·距离排序](创新：重叠时的绘制优先级由标记到框边的距离决定)

**来源原语**：颜色对应边/散落像素/矩形框(5daaa586), 旋转(fd4b2b02), 印章覆盖(007bbfb7), 锚点对齐/源锚点/目标锚点(2c737e39), 散落连接同色框边(5daaa586)

**依赖链**：标记颜色决定附着边（方位）→ 方位决定旋转角度 → 旋转后的精灵体在附着点处印章 → 多个印章重叠时，标记到其对应框边的垂直距离决定绘制先后。四个环节顺序耦合，且距离排序依赖于第一步的边选择结果。

将矩形框外的散落标记按颜色匹配到对应框边，在框内的附着点处印章旋转后的精灵体模板；重叠区域由标记离框边的距离决定前后层次。

**输入结构**：
- 黑(0)背景，约 15x15。
- 一个轴对齐的单像素宽矩形框，四条边各一种颜色：顶边蓝(1)、右边红(2)、底边绿(3)、左边黄(4)。四个角像素归属于与其同行的水平边。
- 框内左上角区域放置一个 3x3 的多色精灵体模板，其中恰好一个像素为灰(5)（锚点），位于 3x3 边界框的某一边缘行或列上。其余像素使用橙(7)和品红(6)。
- 框外散布若干单像素标记，每个标记的颜色与四条框边颜色之一相同。无两个标记在同一条框边上的投影位置重合。每个标记到其匹配框边的垂直距离各不相等。
- 生成约束：每个标记的印章区域完全位于框内；标记数量 3~6 个。

**规则**：
1. 识别精灵体模板（框内左上角的 3x3 区域）及其灰色锚点位置（锚点在 3x3 内的相对坐标）。
2. 对每个框外标记像素：
   a. 确定其颜色匹配的框边（蓝→顶边，红→右边，绿→底边，黄→左边）。
   b. 找到附着点：对于顶/底边标记，附着点为该框边上与标记同列的像素；对于左/右边标记，附着点为该框边上与标记同行的像素。
   c. 旋转精灵体模板使锚点朝向框外（即朝向标记方向）：顶边附着 → 锚点在上方（0 度），右边 → 锚点在右方（顺时针 90 度），底边 → 锚点在下方（180 度），左边 → 锚点在左方（270 度）。
   d. 将旋转后的精灵体放置于框内，锚点对齐到附着点位置。精灵体其余像素向框内方向延伸。
   e. 锚点位置不绘制精灵体颜色（保留框边原色）。
3. 当多个印章的非锚点像素重叠时：标记到其匹配框边的垂直距离较短者最后绘制（在最上层）。即离框近的标记产生的印章覆盖离框远的。
4. 原始精灵体模板（左上角）被擦除为黑色。

**关键洞察**：矩形框的四条边同时编码三重信息——颜色选择附着位置、附着位置隐含旋转角度、标记到边的距离产生绘制优先级。框不只是一个边界容器（如参考题 5daaa586 中用于裁剪和连线），而是一个复合编码器，一个几何结构承载了位置、朝向和深度三个独立信道。

## 新题 5：镜像修复遮挡后的分区压缩

**组合逻辑**：[镜像·双轴对称恢复](已有) → [网格分区·分隔线检测](已有) → [压缩·每区域折叠单像素](已有)（三步紧耦合：前一步的输出是后一步的必要前提）

**来源原语**：镜像/双轴对称/遮挡矩形/镜像恢复遮挡区(de493100), 网格分区/分隔线/每区域折叠单像素(780d0b14)

**依赖链**：灰色遮挡矩形破坏了若干分区的颜色信息，直接压缩会得到错误结果。必须先用双轴镜像对称恢复被遮挡的像素，才能正确识别每个分区的主色。三步形成严格的先决条件链：镜像恢复 → 分区识别 → 区域压缩。

将被灰色矩形遮挡的双轴对称色彩图案恢复原貌，然后沿橙色分隔线将网格划分为矩形区域，最终将每个区域压缩为一个代表色像素。

**输入结构**：
- 黑(0)背景，约 15x15（奇数行奇数列，使中心点唯一）。
- 一个使用蓝(1)、红(2)、绿(3)、黄(4)四种颜色绘制的稀疏图案，关于网格中心具有双轴（上下、左右）镜像对称性。图案像素散布在网格各处。
- 一个实心灰(5)矩形覆盖了图案的一部分。灰色矩形内的原始图案像素被遮挡不可见。
- 若干完整的橙(7)行（整行全为橙色）和橙(7)列（整列全为橙色）贯穿网格，包括穿过灰色矩形区域。这些橙色线在灰色矩形内也可见（灰色不覆盖橙色线，或橙色线在灰色之上）。
- 生成约束：对于每个被灰色遮挡的非橙色像素位置，其水平镜像(r, W-1-c)、垂直镜像(H-1-r, c)、180度旋转(H-1-r, W-1-c)三个伙伴中至少有一个未被遮挡且不在橙色线上，从而可以恢复原色。橙色分隔线将网格划分为至少 2x2 的区域阵列。恢复后每个矩形区域内恰好有一种主色（出现次数最多的非黑非橙颜色唯一）。

**规则**：
1. 识别灰(5)矩形区域内的所有像素位置。
2. 对每个灰色像素位置 (r, c)（排除位于橙色行/列上的位置）：
   - 计算三个镜像伙伴：水平镜像 (r, W-1-c)，垂直镜像 (H-1-r, c)，180度 (H-1-r, W-1-c)。
   - 取第一个未被灰色遮挡且非橙色的伙伴的颜色，填入 (r, c)。
3. 识别所有橙色完整行和完整列，它们将网格切割成矩形区域。区域由相邻橙色线（或网格边缘）围成的矩形内部定义（不含橙色线本身）。
4. 对每个矩形区域，统计其中所有非黑(0)非橙(7)像素的颜色，取出现次数最多的颜色作为该区域的代表色。
5. 输出一个小网格，行数等于水平区域数，列数等于垂直区域数，每个单元格填入对应区域的代表色。

**关键洞察**：分区压缩（参考题 780d0b14）本身是一个简单操作，但在本题中它无法直接应用——灰色遮挡矩形使部分区域的颜色信息缺失或失真。镜像恢复（参考题 de493100）不是一个独立的装饰步骤，而是压缩操作的严格前提。两个源题中各自独立的操作在此形成了不可省略的因果链。

## 新题 6：重力下落后的面积竞争性形变

**组合逻辑**：[重力下落·通道对齐](已有) → [面积最大者·排名](已有) → [生长](已有) + [收缩](已有)（创新：生长/收缩不再围绕中心间隙进行方向性编辑，而是全方向形态学操作；触发条件从最大/非最大二分变为最大/最小/其余三分）

**来源原语**：重力下落/括号框/通道对齐(df9fd884), 生长/收缩/面积最大者/最大外扩余内缩(df978a02), 前景对象(df978a02)

**依赖链**：重力下落确定对象的最终空间位置（影响生长时是否碰到其他对象或边界）→ 落位后比较面积 → 面积排名决定差异化形态操作。不执行重力则对象位置错误，生长方向和碰撞检测全部失效；不比较面积则无法知道谁该生长、谁该收缩。

将悬浮的多个彩色对象沿各自的括号通道下落至底边，然后面积最大者向外生长一圈、面积最小者收缩去掉最外环、其余对象不变。

**输入结构**：
- 黑(0)背景，约 20x15。
- 网格底边上方排列着若干灰(5)的上开口括号形通道（每个通道由两条短竖线和底部横线构成，开口朝上），通道宽度各不相同（至少 3 像素宽），通道之间有间隔。
- 在每个通道的正上方（列范围与通道内部列范围一致），悬浮着一个彩色 4-连通对象（每个对象一种颜色，颜色各不相同，选自 {蓝(1), 红(2), 绿(3), 黄(4), 橙(7)}），对象形状不规则（3~10 像素），水平跨度不超过通道内部宽度。
- 生成约束：所有对象的像素数两两不同。对象数量 3~5 个。每个对象的水平跨度严格小于其通道内部宽度（保证下落后两侧有空间）。最小面积的对象至少有 3 像素（收缩后可能剩余像素也可能完全消失）。各通道之间的间距大于 2（最大对象生长后不会与相邻通道内的对象接触）。

**规则**：
1. 将每个彩色对象沿垂直方向下落（保持形状和水平位置不变），直到对象最底部像素紧贴网格底边（行索引 H-1）。括号通道的灰色像素保持不动，对象不会落在灰色像素上——对象的列范围位于通道内部列范围内，通道底部横线不阻挡（对象落至网格底边）。
2. 所有对象落位后，比较它们的面积（像素总数）：
   a. 面积最大的对象执行生长：对该对象的每个像素，检查其四个基邻居（上下左右），若邻居为黑(0)且在网格范围内，则标记为待生长。所有待生长位置同时涂为该对象的颜色。（生长不覆盖灰色通道像素和其他彩色对象。）
   b. 面积最小的对象执行收缩：移除该对象中所有至少有一个基邻居为黑(0)或在网格边界上的像素（即移除最外层轮廓）。若所有像素均被移除，该对象消失。
   c. 其余对象不变。
3. 灰色括号通道在输出中保持不变。

**关键洞察**：重力下落（参考题 df9fd884 的核心操作）不只是移动对象到目标位置——它决定了对象的最终邻域关系，这直接影响生长操作的像素生成方向和收缩操作的轮廓判定。如果对象没有正确落位，形态学操作的结果会完全不同。此外，面积排名的三分法（最大/最小/其余）比参考题 df978a02 的二分法更细，需要对比所有对象才能确定行为。

## 新题 7：锚点平移作为选择性图案补全

**组合逻辑**：[平移复制·锚点对齐](已有) × [补全·完整图案推断缺失](已有) → [选择性绘制](创新：平移不再是盲目复制整个精灵体，而是仅填充目标位置的缺失像素，使每次"复制"都是不同的补全操作)

**来源原语**：平移复制/锚点对齐/锚点偏移对应/源锚点/目标锚点(2c737e39), 补全/形状匹配/完整图案推断缺失/模板精灵体(72322fa7)

**依赖链**：源精灵体提供完整模板（什么该存在），目标位置的现有像素提供局部约束（什么已存在），两者的差集决定实际绘制内容。没有源模板则不知道完整图案；没有目标现状则无法判断缺失部分。平移对齐将源的坐标系映射到目标的坐标系，使补全成为可能。

将完整精灵体的形状通过锚点对齐平移到每个目标标记处，但只绘制目标位置上缺失的像素，保留已有像素不变。

**输入结构**：
- 黑(0)背景，约 14x14。
- 一个源精灵体区域：包含一个小型 4-连通多色图案（4~8 像素，使用 1~2 种非黑非灰颜色，如蓝(1)和红(2)），加上一个紧邻该图案的灰(5)像素作为源锚点。
- 2~4 个目标区域，每个包含：
  - 一个灰(5)目标标记像素。
  - 源精灵体图案的一个局部副本：精灵体中的部分像素已按正确的相对位置（以目标标记为锚点）出现，其余缺失（为黑色）。不同目标可能缺失不同的像素子集。
- 生成约束：所有目标区域（含完整补全后的范围）互不重叠，也不与源区域重叠。每个目标至少有一个像素已存在、至少有一个像素缺失。已存在的像素颜色与源模板对应位置一致。

**规则**：
1. 识别源精灵体：以灰色源锚点为参照，记录所有相邻的非黑非灰像素及其相对于锚点的偏移 (dr, dc) 和颜色。
2. 对每个灰色目标标记位置 (r_t, c_t)：
   a. 对源精灵体的每个像素偏移 (dr, dc) 及颜色 C：
      - 检查目标位置 (r_t + dr, c_t + dc)。
      - 若该位置为黑(0)（缺失）→ 涂为颜色 C。
      - 若该位置已有非黑像素 → 不改动（该像素应已与 C 一致）。
   b. 将目标标记灰色像素擦除为黑(0)。
3. 将源锚点灰色像素擦除为黑(0)。源精灵体的其余非灰像素保持不变。

**关键洞察**：参考题 2c737e39 中的平移复制是无条件的——整个精灵体被复制到目标位置。本题将平移复制重新解释为条件补全：每个目标位置已有部分信息，平移只填补空缺。这使得同一个精灵体在不同目标处产生不同的绘制结果，求解者必须识别出部分副本是同一完整模板的不同子集，而非不同的图案。

## 新题 8：墙段分支射线穿越后的通道计数条纹填充

**组合逻辑**：[射线延伸·墙段分支](已有) → [计数·穿墙数](创新：计数对象从弯折形状改为射线路径穿越的障碍数) → [填充·条纹化](已有，但条纹颜色由穿墙计数编码) + [排序·入口位置序](已有)

**来源原语**：射线延伸/分支/墙段开口分支/边缘标记/墙段(f9a67cb5), 计数(e509e548/b7999b51), 填充/条纹/条纹决定填充轴/顺序对应(8e1813be), 排序(8e1813be/b7999b51)

**依赖链**：射线在墙段间分支传播，每条分支路径穿越的墙段数不同 → 穿越数同时决定到达矩形的入口位置（哪些分支到达）和条纹颜色 → 入口列位置决定条纹排列顺序。射线分支结构是一切的上游：不追踪分支就不知道哪些通道到达目标、各通道穿了几面墙。

从边缘标记射入的光线穿过多层有缺口的墙段发生分支，到达底部矩形的各个入口；在矩形内按入口列序绘制垂直条纹，条纹颜色由对应分支穿越的墙段数编码。

**输入结构**：
- 黑(0)背景，约 18x18。
- 网格顶边上有一个红(2)单像素边缘标记。
- 标记下方排列着 2~3 道水平灰(5)墙段。每道墙段跨越网格大部分宽度，但各有 1~3 个单列宽缺口（开口）。墙段之间有若干行间距。各墙段的缺口位置互不对齐（不同墙段的缺口在不同列上）。
- 最下方墙段的下方，有一个黄(4)轮廓矩形框（空心，1 像素宽边框）。矩形框的顶边有若干缺口（位置与射线分支能到达的列对齐）。
- 生成约束：从红色标记出发沿向下方向追踪射线、在墙段缺口处分支后，恰好有 2~4 条分支到达黄色矩形顶边的缺口。不同分支穿越的墙段数可能相同也可能不同。黄色矩形的内部宽度能被到达的分支数整除。

**规则**：
1. 从红(2)标记出发向下发射射线。射线沿列向下移动，将经过的黑色格子涂为红(2)。
2. 当射线遇到灰色墙段时：
   a. 射线在该墙段的命中点停止。
   b. 找到该墙段（同一水平连续灰色段）上的所有缺口（黑色列位置）。
   c. 从每个缺口位置，向下发射新的分支射线（涂为红色），继续下行。
   d. 记录每条分支已穿越的墙段总数（包括刚触发分支的这道墙）。
3. 当一条分支射线到达黄色矩形顶边的缺口时，该分支穿过缺口进入矩形内部。记录该分支穿越的墙段总数 N 和进入的列位置。射线在进入矩形后停止（不继续在矩形内画红线）。
4. 在黄色矩形内部绘制垂直条纹：
   a. 将到达的各分支按进入列位置从左到右排序。
   b. 矩形内部宽度等分为与分支数相同的条纹数。
   c. 从左到右第 k 条条纹涂为第 k 个分支对应的颜色：穿越 1 道墙 → 蓝(1)，穿越 2 道墙 → 绿(3)，穿越 3 道墙 → 橙(7)。
   d. 条纹高度等于矩形内部高度，宽度等于内部宽度除以分支数。
5. 黄色矩形边框保持不变。射线路径（红色）保持在矩形外部。

**关键洞察**：射线分支过程（来自参考题 f9a67cb5）不仅产生路径本身，还隐含地生成了一个统计量——每条分支的穿墙次数。这个统计量被转化为条纹填充（来自参考题 8e1813be）的颜色编码。射线的空间分支结构同时决定了条纹的数量（多少分支到达）、位置（按入口列排序）和颜色（穿墙计数），三个维度的信息全部来自同一个上游过程。
