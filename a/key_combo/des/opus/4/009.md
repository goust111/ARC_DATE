## 新题 1：角标共识门控平铺

**组合逻辑**：[角标一致性检测](已有，改为门控条件) + [裁剪+平铺](创新：将角标共识用作区域筛选门而非直接着色) + [重涂色](已有，但着色来源从区域像素改为角标色)

**来源原语**：角标一致性/corner_consistency（7837ac64）、裁剪/crop + 平铺/tile（a416b8f3）、重涂色/recolor（50aad11f）、分隔网格/divider_grid（7837ac64）、包围关系/enclosure（da6e95e5）

**依赖链**：角标共识检测充当门控节点——只有通过检测的区域才接收平铺内容；模板裁剪提供平铺原型；共识色提供重涂目标色。三者缺一则输出不确定。

将模板裁剪后平铺到通过四角共识检测的区域中，并以共识色重涂。

**输入结构**：约 15×15 的网格。灰(5)色单像素宽的水平和垂直分隔线构成矩形网格，将画布划分为若干矩形区域（约 3×3 到 5×5 大小）。其中恰好一个区域内部包含一个由非黑(0)、非灰(5)颜色组成的 4-连通小图形（3~8 像素），该区域不含任何单像素角标——此为模板区域。所有其他区域的四个内角位置（即紧邻分隔线交叉点的对角线方向一格处）各有一个单像素标记，颜色为非黑、非灰的某种颜色。某些区域四个角标全同色，其余区域至少有一个角标颜色不同。背景为黑(0)。生成约束：模板区域是所有区域中唯一包含多像素非背景图形的区域；每个非模板区域恰好有四个角标像素且无其他前景像素。

**规则**：
1. 找到模板区域：唯一一个内部含多像素非黑非灰图形的区域。将该图形裁剪到其最小边界框，得到模板。
2. 对每个非模板区域，检查其四个角标像素的颜色。若四色完全相同，记该颜色为 C；否则跳过该区域。
3. 对通过检测的区域，以区域内部左上角为起点，将模板按原比例水平和垂直重复平铺，超出区域边界的部分裁剪丢弃。平铺后的所有非黑像素重涂为颜色 C。
4. 未通过检测的区域保持原样（仅保留角标像素，内部仍为黑色）。
5. 分隔线和模板区域原样保留。

**关键洞察**：角标共识并非直接为区域着色（与 7837ac64 不同），而是充当二元门控——决定该区域是否接收平铺内容。模板提供几何形状，共识色提供颜色，门控提供空间选择，三重信息缺一不可。需对比多个示例才能确认门控条件是"四角全同"而非"多数一致"。

## 新题 2：像素密度决定叠加优先级

**组合逻辑**：[计数](已有) → [排序](创新：排序结果不用于空间重排而是确定叠加优先级) → [透明叠加](已有，但优先级从固定位序改为由密度决定)

**来源原语**：计数/counting（794b24be）、排序/sort（bd283c4a）、透明叠加/transparent_overlay + 折叠/collapse（3d31c5b3）、等高带/equal_height_band（3d31c5b3）、同坐标叠加/same_position_overlay（3d31c5b3）

**依赖链**：计数为排序提供依据；排序结果直接改变叠加冲突解决规则；无计数→优先级不确定→叠加结果错误。

按各层前景像素数量排序确定叠加优先级，将等高色带合并为单层输出。

**输入结构**：约 20×5 的网格（高为宽的约 4 倍）。网格被均匀等分为 4 个等高水平带（每带高度相同），彼此间无分隔线、直接相邻。每个带恰好使用一种非黑(0)前景色（四带颜色互不相同，例如蓝(1)、红(2)、绿(3)、黄(4)），在黑色背景上形成各自的图案。各带内前景像素数量互不相同。生成约束：四带的前景像素总数互不相等，以确保排序无歧义。

**规则**：
1. 将网格等分为 4 个等高水平带，每带高 H/4 行（H 为总高度）。
2. 统计每个带内非黑前景像素的总数。
3. 前景像素最多的带获得最高叠加优先级，最少的获得最低优先级。
4. 输出网格尺寸为单带尺寸（宽度不变，高度为 H/4）。对输出中的每个位置 (r, c)，从最高优先级带开始检查该位置：若该带在局部坐标 (r, c) 处有前景像素，输出该颜色；否则检查次高优先级带，依此类推。若所有带在该位置均为黑色，输出黑(0)。

**关键洞察**：参考题 3d31c5b3 的叠加优先级是固定的带位序（第1>第2>第4>第3），此题中优先级由带内像素密度动态决定。单个示例中密度排序可能恰好与位置顺序吻合，必须对比多个示例（其中密度最高的带出现在不同位置）才能排除位置假设、确认密度规则。

## 新题 3：控制像素约束反射距离

**组合逻辑**：[反射](已有) + [填充间隙](已有) + [控制像素边界约束](创新：控制像素原用于拉伸线条图的边界，现改为限制反射的远端距离)

**来源原语**：反射/reflect + 填充/fill + 分隔色填充间隙/sep_color_fills_gap（538b439f）、控制像素/control_pixel + 边缘对齐控制点/edges_align_control + 控制点定拉伸界/control_stretch_bound（baf41dbf）、实心矩形/solid_rectangle（538b439f）、分隔线/separator_line（538b439f）

**依赖链**：分隔线定义反射轴；控制像素修改反射的远端位置（非标准对称距离）；间隙带的长度取决于修改后的反射位置。三者共同决定输出几何形状。

将实心矩形沿分隔线反射，但反射副本的远端被控制像素截断，原件与截断副本之间的间隙用分隔色填充。

**输入结构**：约 15×15 的网格，黑(0)背景。一条全宽水平蓝(1)分隔线将网格分为上下两半。上半区有 2~3 个单色实心矩形（每个约 2×3 到 3×4 像素，颜色各不相同，如红(2)、绿(3)、黄(4)），均位于分隔线上方。下半区在对应每个矩形的正下方区域中，各有一个孤立的橙(7)控制像素。每个控制像素的行坐标不同，但均比标准对称反射位置更靠近分隔线（即控制像素在分隔线和完整镜像位置之间）。上半区还散落少量灰(5)干扰像素。生成约束：每个控制像素的列坐标位于其对应矩形的列范围内；各控制像素到分隔线的距离互不相同且均小于对应矩形到分隔线的距离。

**规则**：
1. 识别蓝(1)全宽水平分隔线。忽略灰(5)干扰像素。
2. 识别分隔线上方的实心矩形（每个是同色 4-连通区域，形成完整矩形）。
3. 对每个矩形，找到其正下方列范围内的橙(7)控制像素。
4. 标准反射会将矩形关于分隔线完全对称；此题中，反射副本的远端（离分隔线最远的边）截断到控制像素所在行。即副本的顶边贴着分隔线下方一格，底边在控制像素所在行（含该行）。若截断后副本的高度小于原件，副本只保留从贴近分隔线一侧开始的相应行数。
5. 在原件底边与分隔线之间填充蓝(1)分隔色；在分隔线与副本顶边之间（已紧邻，无间隙）不额外填充；在副本底边以下不填充。
6. 控制像素在输出中保留。分隔线保留。干扰像素被覆盖时丢弃，否则保留。

**关键洞察**：控制像素在参考题 baf41dbf 中用于拉伸线条图的边界，在此题中被重新用作反射距离的截断点——它不改变反射轴，而是改变反射副本的尺寸。不同矩形的控制像素距离不同，因此各副本被截断的程度不同。需对比多个示例确认控制像素决定的是副本远端（而非近端）以及截断方式。

## 新题 4：图例定序同心环与最近种子分区

**组合逻辑**：[查表替换](创新：图例面板不再做颜色-形状翻译，而是提供有序调色板) + [同心层填充](已有，但调色板来源从色板行改为图例面板) + [最近邻分区](创新：多种子的切比雪夫最近分配，源题中不存在)

**来源原语**：查表替换/lookup_replace + 图例面板/legend_panel（b20f7c8b）、同心层填充/concentric_fill + 切比雪夫距离索引/chebyshev_index + 种子像素/seed_pixel（9356391f）、色板按距离配色/palette_color_by_distance（9356391f）、最近邻匹配/nearest_neighbor_matching（50aad11f）

**依赖链**：图例面板的垂直排列顺序决定调色板；种子像素提供扩展中心；切比雪夫距离索引将调色板映射到空间；当多种子环形重叠时最近邻规则解决冲突——四个逻辑交织成空间分区着色。

从图例面板中自上而下读取调色板，以多个种子像素为中心画同心方环，重叠区域归属切比雪夫距离最近的种子。

**输入结构**：约 20×20 的网格。左侧 5 列为青(8)边框的图例面板，面板内从上到下排列 3~5 个小图形（每个为不同颜色的 4-连通形状，约 2~4 像素），图形之间用青(8)行分隔。面板右侧为黑(0)背景画布，画布上散布 2~3 个孤立的白色单像素种子（因白色不在 0-9 标准色中——修正：使用栗(9)色单像素作为种子标记）。生成约束：种子之间的切比雪夫距离至少为 6，以确保最近环之间有足够空间区分；调色板长度（图例中图形数量）不超过种子间最小半距离。

**规则**：
1. 读取图例面板：从上到下依次记录每个图形的颜色，形成有序调色板 P[0], P[1], ..., P[N-1]。图形的具体形状不影响规则，仅颜色和垂直位序有意义。
2. 画布上每个非种子单元格 (r, c)，计算其到所有种子像素的切比雪夫距离（max(|r-sr|, |c-sc|)），取最小值及对应种子。若到两个种子的最小切比雪夫距离相同，归属行坐标更小的种子；若行坐标也相同，归属列坐标更小的种子。
3. 设该单元格到其归属种子的切比雪夫距离为 d。若 d ≤ N-1，将该单元格着色为 P[d]；若 d > N-1，保持黑(0)。
4. 种子像素本身着色为 P[0]（调色板第一色取代种子标记色）。
5. 图例面板原样保留在输出中。

**关键洞察**：图例面板在参考题 b20f7c8b 中是颜色-形状双向字典，此题中仅用其垂直排列顺序编码距离调色板——形状本身无意义，这一点只有对比不同示例（相同颜色出现在形状不同的图例中但输出不变）才能确认。多种子的切比雪夫最近分区产生类似 Voronoi 的方形边界，是源题中不存在的涌现结构。

## 新题 5：方向标记定向 + 连通分量定次数的印章重复

**组合逻辑**：[印章覆盖](已有) + [连通分量计数](已有，改为同时提供重复次数和各副本颜色) + [方向标记](已有，但从示范面板的朝向指令改为直接控制堆叠方向)

**来源原语**：印章覆盖/stamp_overlay + 方向标记/direction_marker + 朝向决定粘贴侧/orientation_determines_side（4c177718）、计数/counting + 连通分量计数/component_count + 计数决定重复次数/count_determines_repetition（b0039139）、裁剪/crop + 重涂色/recolor（50aad11f）、精灵体/sprite（4c177718）

**依赖链**：方向标记决定堆叠方向（垂直/水平）；连通分量数目决定堆叠副本数；各分量的颜色按空间位序映射到各副本的重涂色——三个独立信息源交汇决定最终输出。

读取 T 形方向标记确定堆叠方向，数模板区连通分量确定副本数，按分量位序对各副本分别重涂色后堆叠粘贴。

**输入结构**：约 18×18 的网格，黑(0)背景。一条全宽灰(5)水平分隔行将网格分为上下两区。上区包含三类元素：(a) 一个红(2)的 T 形方向标记（3×3 区域中占 5 像素，水平臂在顶行或底行，竖臂在中列），(b) 一个非红、非灰的单色 4-连通精灵体（约 4~8 像素），(c) 一个模板区，包含 2~4 个互不相邻的单色 4-连通小图形（每个 2~4 像素），各图形颜色互不相同且非红、非灰、非黑。下区包含一个灰(5)色的 4-连通模板对象。生成约束：T 形标记、精灵体和模板区互不重叠；模板区中各图形之间 4-不连通（保证分量可数）。

**规则**：
1. 识别上区的 T 形红(2)标记。若水平臂在顶行，堆叠方向为"向下"；若水平臂在底行，堆叠方向为"向上"。
2. 识别上区的模板区：所有非红、非灰、非黑像素中排除精灵体后剩余的像素。统计其中 4-连通分量的数目 N，并按各分量边界框左上角的位置从左到右排序（若列相同则从上到下），记录每个分量的颜色得到颜色序列 C[0], C[1], ..., C[N-1]。
3. 裁剪精灵体到其最小边界框。
4. 输出以下区为基础（保持下区尺寸和模板对象位置不变）。将精灵体副本印章到模板对象旁：
   - 若方向为"向下"：第 1 个副本紧贴模板对象底边下方、左边缘与模板对象左边缘对齐；第 2 个副本紧贴第 1 个副本下方，依此类推。
   - 若方向为"向上"：第 1 个副本紧贴模板对象顶边上方、左对齐；第 2 个副本紧贴第 1 个副本上方，依此类推。
5. 共印章 N 个副本。第 i 个副本（i 从 0 开始）的非黑像素重涂为 C[i]。
6. 超出网格边界的副本像素丢弃。非黑像素覆盖背景；若副本与模板对象重叠，副本像素覆盖模板像素。
7. 输出只包含下区（上区和分隔行被裁去）。

**关键洞察**：T 标记不是示范面板的一部分（与 4c177718 不同），而是独立的方向编码器。连通分量不仅决定重复次数（与 b0039139 相同），还按空间位序提供各副本的重涂色——这是源题中不存在的双重编码。需对比多个示例确认颜色分配是按分量位序而非按颜色编号或分量面积排序。

## 新题 6：射线交叉点生成涌现网格并铺设模板

**组合逻辑**：[射线延伸](已有) → [行列交叉检测](创新：交叉点不是来自边缘标记的笛卡尔积，而是由射线几何涌现) → [平铺/印章](创新：模板不铺满区域而是仅放置在涌现的交叉点上)

**来源原语**：射线延伸/ray_extend + 投射到最近边界/projection_to_nearest_edge + 最近边界方向/nearest_boundary_direction（705a3229）、行列交叉/row_col_intersection（2281f1f4）、平铺/tile + 印章覆盖/stamp_overlay（4c177718、a416b8f3）、标记像素/marker_pixel（705a3229）、模板/template（b0039139）

**依赖链**：标记像素的位置决定射线路径；射线的水平/垂直段产生涌现的行列集合；不同标记射线的交叉点构成非均匀网格；模板仅印章在这些交叉点上。移除射线→无交叉点→无处放模板；移除模板→交叉点无内容可放。

各标记向最近的两个边界射出 L 形射线，不同标记射线段的交叉点构成涌现网格节点，在每个节点处印章一个小模板。

**输入结构**：约 18×18 的网格，黑(0)背景。画布内散布 3~4 个不同颜色的孤立单像素标记（颜色从蓝(1)、红(2)、绿(3)、黄(4)中选取）。画布左下角 4×4 区域内有一个由品红(6)像素组成的小 4-连通图形（约 3~5 像素），作为模板。各标记到任一边缘无中点平局（即到最近水平边的距离和到最近垂直边的距离均无歧义）。生成约束：标记之间距离足够大（切比雪夫距离 ≥ 5），使得射线有充足的交叉机会；模板区域不与任何射线路径相交。

**规则**：
1. 对每个标记像素 (r, c)，向最近的水平边界（上或下）画一条垂直射线（沿列 c），向最近的垂直边界（左或右）画一条水平射线（沿行 r）。射线包含标记像素本身和从标记到边缘的所有像素。射线颜色为该标记的颜色。
2. 收集所有水平射线段所在的行集合 R，和所有垂直射线段所在的列集合 C。
3. 对 R 与 C 的笛卡尔积中的每个坐标 (ri, cj)：若 ri 行的水平射线来自标记 A、cj 列的垂直射线来自标记 B、且 A ≠ B，则 (ri, cj) 为一个有效交叉点。
4. 裁剪模板到其最小边界框。对每个有效交叉点，以交叉点为中心（模板边界框中心对齐到交叉点）印章模板副本。模板像素保持品红(6)色不变。
5. 若模板超出网格边界，超出部分裁剪丢弃。
6. 绘制顺序：先画所有射线，再画所有模板副本（模板覆盖射线像素）。若多个模板副本重叠，后绘制的覆盖先绘制的（按交叉点从上到下、从左到右的顺序绘制）。
7. 原始标记像素保留其颜色（不被射线或模板覆盖）。

**关键洞察**：交叉点不是预先标记的（与 2281f1f4 不同），而是由射线几何涌现——标记的位置隐式决定了一个不规则网格。这是射线延伸与行列交叉两个原语组合后的涌现效应：单独的射线只画 L 形，单独的交叉规则需要显式标记，组合后产生了隐式网格生成。需对比多个示例确认只有不同标记的射线交叉才产生节点（同一标记的 L 形拐角处不放模板）。

## 新题 7：时钟指针编码旋转角度修复周期图案

**组合逻辑**：[旋转](已有，但旋转的目标不是精灵放置而是修复瓦片的朝向) + [修复噪声](已有，但修复瓦片不直接可用，需先旋转) + [裁剪](已有)

**来源原语**：旋转/rotation + 时钟指针编码角度/clock_hand_encodes_rotation（a32d8b75）、修复噪声/repair_noise + 周期瓦片/periodic_tile + 周期重复/periodic_repetition（135a2760）、裁剪/crop（da6e95e5）、分隔线/separator_line（b0039139）、忽略干扰项/ignore_distractors（135a2760）

**依赖链**：参考瓦片提供修复的素材但朝向不对；时钟指针提供旋转角度；旋转后的瓦片才能正确修复周期图案。跳过旋转→瓦片方向错→修复结果错。

读取时钟指针确定旋转角度，将参考瓦片旋转后用于修复损坏的周期图案。

**输入结构**：约 20×15 的网格。蓝(1)色全宽分隔行将网格分为三个区段（从上到下）。区段 1（约 10 行高）：黑(0)背景上有一个周期性图案，该图案由某个小瓦片（约 3×3 到 4×4）水平和垂直重复平铺而成，但其中 3~6 个像素被随机替换为错误颜色（损坏）。区段 2（约 3~4 行高）：包含一个完好的参考瓦片，但该瓦片的朝向与区段 1 中实际使用的瓦片存在旋转偏差（即参考瓦片是区段 1 中瓦片经过某个 90 度倍数旋转后的版本）。区段 3（恰好 3 行高）：包含一个 3×3 的时钟指针图案——中心像素为一种颜色，加上一个相邻像素（上/右/下/左方向）构成指针，其余位置为黑色。生成约束：区段 1 的宽度和高度均为瓦片边长的整数倍（保证完美平铺）；损坏像素不超过总图案像素的 15%；参考瓦片裁剪到其最小边界框后与实际瓦片恰好差一个 90 度倍数旋转。

**规则**：
1. 从区段 3 读取 3×3 时钟指针：指针方向为上→旋转 0 度，右→顺时针旋转 90 度，下→旋转 180 度，左→顺时针旋转 270 度。
2. 从区段 2 裁剪参考瓦片到其最小边界框。
3. 将参考瓦片按步骤 1 确定的角度顺时针旋转，得到修正瓦片。
4. 在区段 1 中，以修正瓦片从左上角开始水平和垂直无间隙重复平铺，生成理想周期图案。
5. 将区段 1 中与理想图案不同的像素替换为理想图案中的对应颜色（即修复损坏像素）。
6. 输出仅包含修复后的区段 1（裁去分隔行和区段 2、3）。

**关键洞察**：参考瓦片不能直接用于修复——它的朝向与实际图案不同。旋转角度编码在时钟指针中，这是区段 3 的唯一功能。需对比多个示例确认指针方向到旋转角度的映射关系（例如"右"对应 90 度而非 270 度）。三个区段分别提供不同维度的信息（损坏图案、参考形状、旋转角度），缺任一则修复不可能。

## 新题 8：频率排序驱动的模板重复与重涂色

**组合逻辑**：[计数+排序](已有) → [重复/平铺](创新：重复次数由颜色种类数决定，排列顺序由频率决定) → [重涂色](已有，但每个副本的颜色来自排序后的不同颜色)

2. 按像素数量从多到少排序这 N 种颜色，得到有序颜色列表 C[0]（最多）, C[1], ..., C[N-1]（最少）。

4. 输出网格宽度为 N*w + (N-1)（N 个副本之间各有 1 列黑色间隔），高度为 h。
5. 从左到右放置 N 个模板副本。第 i 个副本（i 从 0 开始）的所有非黑像素重涂为 C[i]。副本之间插入 1 列黑(0)。

**关键洞察**：左区不是装饰——它的像素分布编码了两个信息：颜色种类数（决定副本数量）和频率排名（决定副本颜色的左右顺序）。模板的原色（灰(5)）在输出中完全消失，被频率排序后的颜色替代。需对比多个示例确认排列方向是从多到少（而非从少到多），以及确认是按频率而非按首次出现的空间位置排序。

## 新题 9：连通分量数量选择对称补全轴

**组合逻辑**：[连通分量计数](已有) → [对称补全](已有，但补全所用的轴从固定改为由分量数量动态选择) → [镜像](已有，但镜像轴的选择逻辑是创新的)

**来源原语**：对称补全/symmetry_completion + 对称轴借用/axis_borrowed + 借轴复制非对称体/axis_replicates_asym（4c5c2cf0）、计数/counting + 连通分量计数/component_count（b0039139）、镜像/mirror（963f59bc）、对称体/symmetric_object + 非对称体/asymmetric_object（4c5c2cf0）

**依赖链**：对称体提供 H 轴和 V 轴两条候选；每个非对称体的连通分量数量决定选用哪条（些）轴——这是一个分类决策节点，使得对同一张图中不同对象应用不同的反射操作。删去分量计数→不知选哪条轴→补全结果不确定。

统计每个非对称体的连通分量数量，以此选择从对称体借用的反射轴（水平、垂直或双轴），然后对该非对称体执行对应的对称补全。

**输入结构**：约 17×17 的网格，黑(0)背景。网格中央有一个灰(5)色的 4-连通对称体（约 5×5 像素），同时具有水平和垂直镜像对称性。对称体的水平对称轴和垂直对称轴将网格隐式分为四个象限。在不同的象限中分布着 2~3 个非对称体，每个非对称体为不同颜色的 4-连通像素集合（如蓝(1)、红(2)、绿(3)）。每个非对称体可能由 1 个、2 个或 3 个 4-连通分量组成（各分量间 4-不连通，但颜色相同）。各非对称体完全位于某一个象限内。生成约束：对称体的 H 轴和 V 轴分别为某一行和某一列；各非对称体的反射像（无论选哪条轴）均不与其他非对称体或对称体重叠。

**规则**：
1. 识别灰(5)对称体，确定其水平对称轴所在行 rH 和垂直对称轴所在列 cV。
2. 对每个非对称体，统计其 4-连通分量数量 K。
   - K = 1：仅沿水平轴（行 rH）做镜像反射。即对该体的每个像素 (r, c)，在 (2*rH - r, c) 处画同色像素。
   - K = 2：仅沿垂直轴（列 cV）做镜像反射。即对该体的每个像素 (r, c)，在 (r, 2*cV - c) 处画同色像素。
   - K ≥ 3：同时沿两轴做反射（生成水平镜像、垂直镜像和中心对称三组像素）。
3. 原始非对称体像素保留。反射生成的像素画在对应的象限中。
4. 对称体原样保留。
5. 若反射像素超出网格边界，丢弃超出部分。

**关键洞察**：对称体提供反射轴（与 4c5c2cf0 相同），但使用哪条轴不再是固定的——由非对称体自身的连通结构决定。这是分量计数（来自 b0039139 的计数概念）与对称补全（来自 4c5c2cf0）之间的创新结构关系：计数结果不是驱动重复次数，而是驱动轴选择的分类开关。需对比多个示例才能归纳出 K 值与轴选择的映射关系（因为单个示例可能只展示一种情况）。

## 新题 10：图例形状分类决定射线方向与笛卡尔积填充

**组合逻辑**：[查表替换](创新：图例不做颜色-形状翻译，而是将形状的几何属性用作分类依据) → [射线延伸](创新：射线方向不由最近边界决定，而由图例分类决定) → [填充](已有，笛卡尔积)

**来源原语**：查表替换/lookup_replace + 图例面板/legend_panel + 颜色与形状对应/color_shape_match（b20f7c8b）、射线延伸/ray_extend（705a3229）、填充/fill + 行列交叉/row_col_intersection + 边缘标记笛卡尔积/edge_marker_cartesian_product（2281f1f4）、标记像素/marker_pixel（705a3229）

**依赖链**：图例的形状宽高比将每个标记分类为"水平发射器"或"垂直发射器"→ 发射器类型决定射线方向 → 水平射线与垂直射线的交叉点被填充。图例→分类→射线→交叉→填充，每一步依赖前一步的输出且不可跳过。

通过图例面板中形状的宽高比将画布上的标记分为水平型和垂直型，水平型发射全宽水平射线，垂直型发射全高垂直射线，两类射线的交叉点填充为指定颜色。

**输入结构**：约 18×18 的网格。左侧 5 列被青(8)边框围成图例面板，内含 4~5 个图例条目，每个条目为一种颜色的 4-连通小图形（3~6 像素），条目之间用青(8)行分隔。图形中有些宽大于高（如横排 3 像素），有些高大于宽（如竖排 3 像素）。面板右侧为黑(0)背景的画布。画布上散布若干单像素彩色标记，每个标记的颜色恰好对应图例中某一条目。生成约束：同色标记最多 2 个；图例中每种形状的最小边界框宽高比明确大于或小于 1（不存在宽=高的情况），以确保分类无歧义。

**规则**：
1. 读取图例面板，对每个条目记录其颜色和形状的最小边界框。
2. 若边界框宽度 > 高度，该颜色被分类为"水平型"。若高度 > 宽度，分类为"垂直型"。
3. 对画布上的每个标记像素，根据其颜色查找分类：
   - 水平型标记：沿该标记所在行画一条从画布左边缘到右边缘的全宽水平线，颜色为该标记色。
   - 垂直型标记：沿该标记所在列画一条从画布上边缘到下边缘的全高垂直线，颜色为该标记色。
4. 每个水平线与垂直线的交叉点（来自不同标记）的颜色覆盖为橙(7)。若两条同方向的线重叠在同一行或同一列，保持各自标记色不变（同方向不产生交叉点）。
5. 标记像素本身保留其原色（不被射线覆盖）。
6. 图例面板原样保留。

**关键洞察**：图例面板在参考题 b20f7c8b 中是颜色-形状的翻译字典，此题中形状仅作为分类信号——宽扁形状意味着水平射线，窄高形状意味着垂直射线。标记的颜色查找图例后获得"行为模式"而非外观翻译，这是图例用途的根本改变。需对比多个示例确认分类依据是边界框宽高比（而非颜色编号、像素数量或形状的绝对位置）。交叉点的橙(7)着色需通过示例确认，因为仅看射线部分无法推断交叉点的特殊处理。
