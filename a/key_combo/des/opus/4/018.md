## 新题 1：种子射线分区与近边着色

**组合逻辑**：[射线延伸/ray_extend](创新：从框内种子向四个正方向射出，碰壁停止，在框内部形成十字分区) → [洪泛填充/flood_fill](创新：对十字分出的四个区域分别填色) + [最近边归属/nearest_side_assignment](创新：以区域质心到四条框边的距离决定该区域颜色，而非原题中逐像素判断掩码到边的距离)

**来源原语**：射线延伸(3ac3eb23, 4e469f39)、洪泛填充(4e469f39)、空心矩形/rectangular_frame(9aec4887)、最近边归属/nearest_side_assignment(9aec4887)、孤立像素/isolated_pixel(3ac3eb23)

**依赖链**：种子位置决定十字射线的分区形状 → 分区形状决定每个区域的质心坐标 → 质心到四条框边的距离决定该区域使用哪条边的标记颜色。删除射线则无分区可填；删除最近边规则则无法确定颜色；删除框边标记则无颜色来源。

将框内种子射出的十字射线划分出的四个区域，按各区域质心最近的框边标记颜色进行洪泛填充。

**输入结构**：约 14x14 的网格，黑(0)背景。网格中有 2~3 个灰(5)空心矩形框（壁厚 1 像素，外尺寸约 6x6 至 8x8，框之间不重叠不接触）。每个框的四条边（顶、底、左、右）各有一个单像素颜色标记嵌在该边的中点位置（标记颜色从红(2)、蓝(1)、绿(3)、黄(4)中选取，同一框内四边标记颜色互不相同，不同框可复用颜色）。标记像素替换该位置的灰(5)像素。每个框的内部（被灰壁围住的矩形区域）放置一个孤立的彩色种子像素（颜色为橙(7)或品红(6)），种子不在内部正中心。生成约束：种子与任何框壁不同行且不同列（保证射线在四个方向均能延伸至少 1 格），且种子位置使四个分区的面积互不相等。

**规则**：
1. 对每个框，从其内部种子像素出发，分别向上、下、左、右各延伸一条射线。射线在碰到灰(5)框壁时停止（不包含框壁像素本身）。射线像素涂为种子的颜色。
2. 十字射线将框内部划分为四个矩形区域（左上、右上、左下、右下），射线像素不属于任何区域。
3. 计算每个区域的质心（区域内所有像素坐标的算术平均）。
4. 对每个区域，计算其质心到框顶边、底边、左边、右边的垂直距离，取距离最小的那条边，该区域洪泛填充为那条边的标记颜色。若存在最小距离平局（质心到两条边等距），该区域填充种子自身的颜色。
5. 种子像素和射线像素保持种子颜色不变。灰(5)框壁（含被标记像素替换的位置除外）保持灰(5)。框外背景保持黑(0)。
6. 多个框独立处理，互不影响。

**关键洞察**：同一个框在不同示例中种子位置不同，导致四个区域质心的偏移方向不同，从而同一个区域可能在不同示例中被分配到不同的框边颜色。求解者必须对比多个示例才能排除"固定象限对应固定方向"的假设，归纳出"质心到最近边"的真正规则。

## 新题 2：重力沉降计程与同心层构建

**组合逻辑**：[滑动/slide + 重力沉降/gravity_settle + 碰撞阻挡/collision_block](创新：下落距离作为信息载体，不仅是物理结果) → [计数/count](创新：计量每个对象的行位移量) → [同心层填充/concentric_layer_filling + 由外到内嵌套/outside_in_nesting](创新：层序由下落距离而非线段长度决定)

**来源原语**：滑动/slide(d282b262, 17829a00)、碰撞阻挡/collision_block(d282b262)、重力沉降/gravity_settle(d282b262)、计数/count(8e301a54)、同心层填充/concentric_layer_filling(3ee1011a)、由外到内嵌套/outside_in_nesting(3ee1011a)、连通分量/connected_component(8e301a54, cd3c21df)

**依赖链**：重力模拟决定每个对象的最终位置和行位移量 → 碰撞阻挡使低层对象改变高层对象的位移量 → 位移量排序决定同心层的由外到内着色顺序。删除重力模拟则无位移量；删除碰撞则位移量独立于其他对象，丢失关键交互；删除同心层则无输出形式。

将多个小对象做下落重力模拟，以各对象的下落行数为排序键，构建颜色同心方阵。

**输入结构**：约 12x12 的网格，黑(0)背景。网格中散布 4~5 个互不相连的小型单色 4-连通对象（每个 2~5 像素，形状各异：可为线段、拐角、不规则团等），每个对象颜色互不相同，颜色从红(2)、蓝(1)、绿(3)、黄(4)、橙(7)中选取。对象之间水平列范围可能重叠（即存在相同列号的像素属于不同对象）。生成约束：不存在两个对象下落后位移量相同的情况（保证排序无平局）。

**规则**：
1. 对所有对象同时施加向下重力：每个对象作为刚体整体下移，每一步所有可移动的对象同时下移一行，直到某对象的任一像素紧贴网格底边或紧贴另一个已无法移动的对象的顶部。重复此同步移动直到所有对象静止。
2. 记录每个对象从初始位置到最终位置的行位移量（对象边界框顶边的行号差）。
3. 按行位移量从大到小排序所有对象的颜色。位移最大的颜色排在最前（最外层），位移最小的排在最后（最内层）。
4. 创建一个 N x N 的输出网格（N = 对象数量），按上述排序，从外到内逐层填充同心方形层：最外圈一层像素用排序第一的颜色，次外圈用第二，依此类推，直到中心。
5. 若 N 为偶数，最内"层"是一个 2x2 区域而非单像素。

**关键洞察**：下方存在阻挡物的对象下落距离较短，会被分配到内层。求解者必须完整模拟重力沉降过程（包括碰撞阻挡的级联效应）才能确定层序，无法通过对象的初始位置或高度直接推断。需要对比多个示例来确认排序依据是"位移量"而非"最终行号"或"初始行号"。

## 新题 3：调色板循环镜像补全

**组合逻辑**：[对称补全/symmetric_completion + 镜像/mirror](创新：镜像仅决定哪些像素需要生成，不决定颜色) + [循环填充/cyclic_fill](创新：对镜像生成的像素按扫描序循环赋色) + [标记高度决定长度/marker_height_run_len](保留：灰段高度控制每种调色板颜色的连续重复次数)

**来源原语**：对称补全/symmetric_completion(5b692c0f)、镜像/mirror(5b692c0f)、控制标记/control_marker(5b692c0f)、控制标记指示源侧/control_marker_indicates_source(5b692c0f)、循环填充/cyclic_fill(e7b06bea)、调色板列/palette_col(e7b06bea)、长度标记段/length_marker(e7b06bea)、标记高度决定长度/marker_height_run_len(e7b06bea)

**依赖链**：控制标记确定源侧 → 镜像反射确定哪些像素位置需要生成 → 调色板列提供颜色序列 → 灰段高度提供每色的连续重复次数 → 对生成像素按行优先扫描序循环赋色。删除镜像则不知道哪些位置要填色；删除调色板则不知道填什么色；删除灰段则不知道循环节奏。

将半缺的精灵体经镜像确定待填位置后，用调色板颜色按灰段高度为游程的循环方式逐像素着色。

**输入结构**：约 11x15 的网格，黑(0)背景。左侧区域有一个多色精灵体，占据约 7x5 的范围。精灵体具有一条垂直的黄(4)像素线作为对称轴（1 列宽，贯穿精灵体边界框的全部行）。精灵体的一侧（源侧）像素完整，另一侧（目标侧）大部分像素为黑(0)背景（缺失）。对称轴的上方或下方有一个偏离轴的黄(4)像素作为控制标记，标记位于源侧表示源侧为完整侧。右边缘有一列紧贴网格右侧的调色板列（1 列宽，从上到下排列 3~4 种不同颜色，每种颜色仅 1 像素高）。调色板列正上方有一段灰(5)垂直线段（高度 2~4 像素，顶端对齐网格顶边），灰段的高度即游程长度 R。生成约束：源侧的非背景像素数量至少为 R 乘以调色板颜色数的 2 倍，保证循环至少完整走过调色板两遍。

**规则**：
1. 根据控制标记判断源侧（控制标记所在的那一侧）。
2. 将源侧的所有非背景像素相对于黄(4)对称轴做镜像反射，得到目标侧需要填色的像素位置集合 P。
3. 读取调色板列的颜色序列（从上到下）：c1, c2, ..., ck。读取灰段高度 R。
4. 将 P 中的像素按行优先顺序排列（行号小的在前；同行内列号小的在前），编号为 0, 1, 2, ...。
5. 编号为 i 的像素被赋予颜色 c_{(floor(i/R) mod k) + 1}。即每 R 个连续像素使用同一种调色板颜色，然后切换到下一种，调色板用完后从头循环。
6. 源侧像素、黄(4)对称轴和控制标记保持不变。调色板列和灰段保持不变。其余背景保持黑(0)。

**关键洞察**：镜像反射提供的是几何模板（哪些位置需要着色），而非颜色模板——目标侧的颜色完全由调色板循环决定，与源侧像素颜色无关。求解者若套用"镜像复制颜色"的直觉会得到错误答案，必须对比多个示例中目标侧的颜色模式才能发现循环规律和游程参数。

## 新题 4：异常图案定位偏移印章

**组合逻辑**：[裁剪/crop + 图案匹配/pattern_match + 异常值选择/outlier_selection](创新：异常槽位不是输出对象，而是编码一个位置偏移的信号) → [计数/count + 面积决定位移/area_determines_displacement](创新：异常图案的像素面积转化为槽位偏移量) → [印章覆盖/stamp](创新：覆盖目标由异常位置+面积偏移计算得出)

**来源原语**：裁剪/crop(9aec4887, 1990f7a8)、图案匹配/pattern_match(cd3c21df)、异常值选择/outlier_selection(cd3c21df)、计数/count(8e301a54)、面积决定位移/area_determines_displacement(8e301a54)、印章覆盖/stamp(363442ee)、分隔列/divider_column(363442ee)、槽位/slot(363442ee)、分区/partition(363442ee)

**依赖链**：图案匹配发现异常槽位 → 异常图案的面积计算出偏移量 → 从异常位置按偏移量定位目标槽位 → 将源精灵体印章覆盖到目标槽位。删除异常检测则不知偏移起点；删除面积计数则不知偏移多远；删除印章则无输出变换。

识别右侧槽位中唯一不同的图案，以其像素面积为偏移量定位目标槽位，将左侧源精灵体印入该目标。

**输入结构**：约 12x18 的网格，黑(0)背景。一列灰(5)垂直分隔线将网格分为左右两区。左区有一个多色小精灵体（约 3x3，含至少两种非背景颜色，是一个 4-连通区域）。右区从上到下均匀分为 6 个等高槽位（每个槽位高度约 2 行，宽度与右区相同），槽位之间无间隔。每个槽位内部中央有一个红(2)小图形（4-连通，2~5 像素），其中 5 个槽位的小图形形状完全相同（裁剪后的像素图案一致），1 个槽位的小图形与其余不同（异常值）。生成约束：异常图形的像素面积 A 满足 1 <= A <= 5，且异常槽位编号加 A 不超过 6（即目标槽位不越界；槽位从上到下编号 1~6）。

**规则**：
1. 裁剪每个槽位中红(2)图形的最小边界框，比较所有 6 个裁剪结果的像素图案（包含边界框内的背景像素）。
2. 找到唯一图案出现恰好一次的槽位，即异常槽位。记其编号为 S（从上到下编号 1~6）。
3. 计算异常图形的像素面积 A（红(2)像素的个数）。
4. 目标槽位编号 T = S + A。
5. 将左区源精灵体（保持其多色像素图案）印章覆盖到目标槽位 T 的中央位置，精灵体居中放置。覆盖时精灵体像素替换目标区域原有内容（包括原有红色图形）。
6. 异常槽位内的异常图形被擦除（替换为黑(0)背景）。其余 4 个正常槽位保持不变。分隔列和左区保持不变。

**关键洞察**：异常图案是信号而非答案——它标记的不是"哪里有问题"而是"从哪里开始数"。异常图案的面积不是偶然属性而是有意编码的偏移量。求解者需要对比多个示例才能发现面积与偏移量的对应关系，因为单个示例中面积和偏移量的数值巧合无法排除其他假设。

## 新题 5：缺口方向洪泛与走廊连通着色

**组合逻辑**：[洪泛填充/flood_fill](创新：填充有缺口的矩形框内部) + [射线延伸/ray_extend + 帽向决定射线/cap_determines_ray + 缺口不对称/gap_asymmetry](创新：射线从缺口射出，方向由缺口旁的方向帽决定) → [路径填充/path_fill + 最短路径并集/monotone_shortest_path_union](创新：当两条射线相遇或射线触及另一框的缺口时，将连接段重涂为走廊色)

**来源原语**：洪泛填充/flood_fill(4e469f39)、射线延伸/ray_extend(4e469f39, 3ac3eb23)、缺口不对称/gap_asymmetry(4e469f39)、帽向决定射线/cap_determines_ray(4e469f39)、开顶矩形框/open_top_rect_frame(4e469f39)、路径填充/path_fill(692cd3b6)、走廊路径/corridor_path(692cd3b6)、门洞朝向/doorway_orientation(692cd3b6)、最短路径并集/monotone_shortest_path_union(692cd3b6)

**依赖链**：缺口方向帽确定射线方向（局部） → 射线延伸后判断是否触及另一框（全局连通关系） → 已连通的框之间射线重涂为走廊色，未连通的框射线保持填充色。删除方向帽则射线无方向；删除射线则无法发现连通关系；删除走廊重涂则无法区分孤立框和联通框。

每个缺口框内部洪泛填充并从缺口沿帽向射出射线；两框的射线若相遇或一条射线触及另一框的缺口，则将连接射线段改涂为走廊色。

**输入结构**：约 15x15 的网格，黑(0)背景。网格中有 3 个灰(5)矩形框（壁厚 1 像素，外尺寸约 4x4 至 6x6）。每个框的顶边有一个 1 像素宽的缺口（该位置为黑(0)背景而非灰(5)），缺口左侧或右侧有连续 2 个灰(5)像素紧贴缺口（方向帽），方向帽在缺口的哪一侧因框而异。三个框分布在网格不同位置，不重叠不接触。生成约束：至少有两个框的射线能够相遇（即一个框缺口射出的向左或向右射线经过另一个框缺口的正上方行或同一行，且路径上无第三个框的壁阻挡）。至少一个框的射线不与任何其他框连通（射线延伸到网格边界也未遇到其他框的缺口或射线）。

**规则**：
1. 对每个框，将框内部（除缺口外被灰壁围住的区域）的所有黑(0)像素和缺口上方紧邻的那个像素洪泛填充为红(2)。灰(5)框壁保持不变。
2. 确定缺口方向：方向帽（缺口旁的 2 像素灰段）所在的方向即为射线方向。若方向帽在缺口右侧，射线向右延伸；若在左侧，射线向左延伸。
3. 从缺口正上方一行（即框顶边的上一行）的缺口对应列出发，沿方向帽指示的水平方向延伸射线，逐像素涂为红(2)，直到碰到网格边界或碰到非黑(0)像素时停止（不包含终点）。
4. 连通检测：若框 X 的射线经过某列时该列恰好是框 Y 的缺口列且行号在框 Y 缺口上方同一行，则 X 和 Y 形成走廊连通。同样，若两个框的射线在同一像素位置相遇（都经过该点），也形成走廊连通。
5. 走廊着色：对每一对连通的框，将连接它们的射线段（从一个缺口上方到另一个缺口上方之间的所有射线像素，包括连接点）重涂为黄(4)。两个缺口上方的连接起点也涂为黄(4)。
6. 未与任何其他框连通的框，其射线保持红(2)不变。
7. 框壁灰(5)保持不变，框外其余背景保持黑(0)。

**关键洞察**：每个框的缺口方向帽决定射线方向，但射线是否形成走廊取决于另一个框的位置和缺口方向——这是一个全局的连通性判断，不是逐框独立可解的。求解者需要对比有走廊和无走廊的示例才能发现"相遇则重涂"的规则，而非"所有射线都变黄"。

## 新题 6：种子周期生长碰撞计程与存活稀疏化

**组合逻辑**：[射线延伸/ray_extend + 种子周期生长/seed_periodic_growth + 对角偏移/diagonal_offset](保留：多种子对角周期生长) → [碰撞阻挡/collision_block](创新：不同种子的轨迹碰撞产生灰像素) → [计数/count](创新：计量每个种子的碰撞像素总数) → [重涂色/recolor + 交替选取/alternating_selection](创新：碰撞计数决定存活轨迹的稀疏化间隔)

**来源原语**：射线延伸/ray_extend(3ac3eb23)、种子周期生长/seed_periodic_growth(3ac3eb23)、对角偏移/diagonal_offset(3ac3eb23)、孤立像素/isolated_pixel(3ac3eb23)、轨迹/trail(3ac3eb23)、碰撞阻挡/collision_block(d282b262)、计数/count(8e301a54)、重涂色/recolor(817e6c09, d406998b)、交替选取/alternating_selection(d406998b)

**依赖链**：种子周期生长产生轨迹 → 轨迹间碰撞产生灰像素 → 碰撞计数为每个种子生成稀疏化参数 → 按该参数对存活轨迹做交替擦除。删除生长则无轨迹；删除碰撞检测则无稀疏化参数；删除交替擦除则输出无差异化。

多个种子各自做周期对角生长，轨迹碰撞处变灰，每个种子的碰撞总数 C 决定其存活轨迹每隔 C+1 个像素保留一个、其余擦除。

**输入结构**：约 15x15 的网格，黑(0)背景。网格上方散布 3~4 个孤立的彩色种子像素（每个 1 像素，颜色互不相同，从红(2)、蓝(1)、绿(3)、橙(7)中选取）。种子位于网格的上半部分（行号在 0~4 范围内），水平间距至少 3 列。生成约束：按照周期-2 对角生长规则，至少有两个种子的轨迹存在碰撞（占据同一格），且至少有一个种子的轨迹不与任何其他种子碰撞。

**规则**：
1. 对每个种子执行周期-2 对角生长：以种子位置 (r,c) 为中心，在 (r,c)、(r-1,c-1)、(r-1,c+1)、(r+1,c-1)、(r+1,c+1) 五个起点各开始一条向下的轨迹，每条轨迹每隔 2 行生成一个该种子颜色的像素（即第 0、2、4、6... 步各生成一个像素，步进方向为正下方），直到超出网格底边为止。
2. 碰撞处理：若两个或多个种子的轨迹在同一像素位置重合，该位置涂为灰(5)，不属于任何种子。
3. 对每个种子，统计其碰撞像素总数 C（即因与其他种子冲突而被涂灰的像素数）。
4. 存活轨迹稀疏化：对每个种子的存活（非碰撞）轨迹像素，按距种子的曼哈顿距离从小到大排序，编号 0, 1, 2, ...。保留编号为 (C+1) 的整数倍的像素（即编号 0, C+1, 2(C+1), ...），其余存活像素擦除为黑(0)背景。若 C=0（无碰撞），则所有存活像素全部保留（间隔为 1，即保留所有）。
5. 种子像素本身始终保留。灰(5)碰撞像素保留。

**关键洞察**：碰撞不仅直接消灭像素，还通过计数间接稀疏化该种子的整条存活轨迹——碰撞越多的种子损失越大，形成正反馈惩罚。求解者需对比碰撞数不同的种子在存活轨迹上的密度差异，才能归纳出"C 决定保留间隔"的规则。

## 新题 7：瓦片缺陷定位与循环填色起点

**组合逻辑**：[裁剪/crop + 轴向复制/axial_dup + 沿重复轴取首半/first_half_extract](创新：从近重复的 2x2 瓦片阵中提取基准瓦片并定位唯一缺陷) → [图案匹配/pattern_match](创新：多数表决确定正确瓦片，少数偏差定位缺陷像素) → [循环填充/cyclic_fill + 标记高度决定长度/marker_height_run_len](创新：缺陷位置作为循环填色的起始偏移)

**来源原语**：裁剪/crop(7b7f7511, 1990f7a8)、轴向复制/axial_dup(7b7f7511)、沿重复轴取首半/first_half_extract(7b7f7511)、图案匹配/pattern_match(cd3c21df)、循环填充/cyclic_fill(e7b06bea)、调色板列/palette_col(e7b06bea)、标记高度决定长度/marker_height_run_len(e7b06bea)、长度标记段/length_marker(e7b06bea)

**依赖链**：瓦片检测 → 多数表决得到正确瓦片 + 定位缺陷副本及缺陷像素位置 → 缺陷位置转化为循环填色的起始偏移 → 用调色板和游程对基准瓦片循环着色。删除瓦片检测则不知道基准图案；删除缺陷定位则不知道起始偏移；删除循环填色则无输出变换。

在 2x2 瓦片阵列中找到唯一缺陷像素，以其在瓦片内的行优先编号作为循环填色的起始偏移，对基准瓦片做调色板循环着色后输出。

**输入结构**：约 12x12 的网格（行列数均为偶数），网格为一个基准瓦片的 2x2 平铺（上下各两份、左右各两份，共 4 份），每份约 6x6。基准瓦片是一个含有多种颜色的图案（至少 3 种非背景色，4-连通前景像素形成 1~2 个区域）。4 个副本中恰好有 1 个副本的某个像素颜色被改为栗(9)（其余像素与基准瓦片完全一致）。此外，网格右边缘外侧追加 1 列宽的调色板列（使网格总宽度为偶数+1），调色板列自上而下排列 2~3 种颜色（每种 1 像素高），调色板列正上方有一段灰(5)垂直线段（高度 1~3，指示游程长度 R）。生成约束：缺陷像素在瓦片内的行优先编号（从 0 开始）不超过瓦片总像素数减去调色板颜色数乘以 R（保证循环在偏移后仍能覆盖至少一轮完整调色板）。

**规则**：
1. 将网格（不含调色板列）分为 2x2 的四个等大区块，每块即为瓦片的一个副本。
2. 比较四个副本的像素图案。通过多数表决（至少 3 个副本一致的像素取多数颜色）确定基准瓦片。
3. 找到唯一含有栗(9)像素的副本，记录栗(9)像素在瓦片内的位置 (row_local, col_local)。计算行优先编号 D = row_local * tile_width + col_local。
4. 读取调色板列的颜色序列 c1, c2, ..., ck（从上到下）。读取灰段高度 R（游程长度）。
5. 对基准瓦片的所有像素按行优先顺序编号 0, 1, 2, ...。
6. 对编号 i 的像素，计算偏移后的循环索引 j = (i + D) mod (k * R)，该像素被重涂为 c_{floor(j / R) + 1}。即从编号 0 的像素开始，颜色按照偏移 D 后的调色板循环赋值，每种颜色连续重复 R 个像素。
7. 输出为重涂后的单个瓦片（尺寸与基准瓦片相同）。

**关键洞察**：栗(9)缺陷像素不是需要修复的错误，而是故意编码的信号——它在瓦片内的位置决定了循环填色的相位偏移。求解者需要对比多个示例（缺陷在不同位置）才能发现"缺陷编号=循环偏移"的关系，而非假设缺陷只是需要恢复的损坏。

## 新题 8：双向滑动配对与条件变换

**组合逻辑**：[滑动/slide + 颜色匹配/color_matching](创新：不是滑向同色边界条，而是左右两侧对象同时向中央分隔线滑动) + [碰撞停止/collision_stop](保留：碰撞决定最终位置) → [图案匹配/pattern_match](创新：跨分隔线配对相邻对象) → [对称补全/symmetric_completion | 重涂色/recolor](创新：配对双方的标记状态决定执行哪种变换——三种条件分支)

**来源原语**：滑动/slide(17829a00, d282b262)、颜色匹配/color_matching(17829a00)、碰撞停止/collision_stop(17829a00)、碰撞阻挡/collision_block(d282b262)、对称补全/symmetric_completion(5b692c0f)、控制标记/control_marker(5b692c0f)、重涂色/recolor(817e6c09, d406998b)、分隔列/divider_column(363442ee)

**依赖链**：双向滑动 + 碰撞决定最终位置 → 位置决定哪些对象形成跨线配对 → 配对双方的标记状态决定变换类型（三分支条件判断）。删除滑动则无法确定配对关系；删除标记检测则无法区分三种变换；删除变换则无输出变化。这是一个非流水线结构：配对是双向对称的涌现结果，变换类型取决于配对双方的联合属性。

左右对象同时向中央分隔线滑动并碰撞停止后，跨线相邻的对象形成配对；双方均有标记则各自向外镜像补全，仅一方有标记则未标记方被重涂为标记方的颜色，双方均无标记则互换颜色。

**输入结构**：约 11x15 的网格，黑(0)背景。一条灰(5)垂直分隔列居中（1 列宽，贯穿全部行）。分隔列左侧有 2~3 个小型单色 4-连通精灵体（每个 3~6 像素，形状各异），右侧同样有 2~3 个。每侧的精灵体颜色互不相同，颜色从红(2)、蓝(1)、绿(3)、橙(7)、品红(6)中选取。部分精灵体紧邻（4-邻接）一个黄(4)单像素标记（标记不与精灵体同色，仅用于标识该精灵体"有标记"）。左侧和右侧精灵体的颜色组合不要求相同。生成约束：滑动后至少存在一对跨线配对（双方边界框的行范围有重叠），且至少存在一个无配对的精灵体。三种条件分支（双标记、单标记、无标记）至少各出现一次跨所有训练示例的总和中（单个示例不必三种齐全）。

**规则**：
1. 所有左侧精灵体（含其标记）作为刚体同时向右滑动；所有右侧精灵体（含其标记）同时向左滑动。每步所有可移动对象同步平移 1 列，某对象的任一像素碰到分隔列或碰到另一个已停止的对象时该对象停止。重复直到所有对象静止。优先停止距分隔列更近的对象。
2. 配对检测：对于每个左侧精灵体 L 和每个右侧精灵体 R，若 L 停止后的最右列 = 分隔列 - 1，且 R 停止后的最左列 = 分隔列 + 1，且 L 和 R 的边界框行范围有至少 1 行重叠，则 L 和 R 形成一对。每个精灵体最多属于一对；若一个精灵体可与多个对面精灵体配对，选行范围重叠最多的那个。
3. 对每对配对 (L, R) 检查标记状态，执行对应变换：
   - **双标记**（L 和 R 均有黄(4)标记）：以分隔列为对称轴，将 L 向左镜像补全（在 L 的左侧生成 L 的水平镜像副本），将 R 向右镜像补全（在 R 的右侧生成 R 的水平镜像副本）。镜像像素使用各自精灵体的颜色。
   - **单标记**（仅一方有标记）：将无标记方的所有像素重涂为有标记方的颜色。
   - **无标记**（双方均无标记）：互换两个精灵体的颜色——L 的所有像素涂为 R 原来的颜色，R 的所有像素涂为 L 原来的颜色。
4. 未形成配对的精灵体保持滑动后的位置和颜色不变。
5. 所有黄(4)标记在变换完成后擦除（替换为黑(0)背景）。
6. 分隔列灰(5)保持不变。其余背景保持黑(0)。镜像补全产生的像素若超出网格边界则裁剪舍弃。

**关键洞察**：配对关系不是输入中显式给出的，而是滑动模拟后涌现的——改变任何一个精灵体的初始位置或形状都可能改变最终的配对结果和变换类型。三种条件分支需要对比多个示例才能完整归纳，单个示例最多展示其中一两种。
