## 新题 1：标记定向印章

**组合逻辑**：[标记坐标编码槽位](创新：从离散槽位改为连续方向向量编码) + [尺寸决定步幅] + [印章覆盖] + [擦除]（标记坐标编码槽位、尺寸决定步幅为已有原语；方向向量编码为创新用法）

**来源原语**：标记坐标编码槽位(marker_encodes_slot) ← 6d0160f0；尺寸决定步幅(size_determines_stride) ← e619ca6e；印章覆盖(stamp) ← e619ca6e；擦除(erase) ← e39e9282

**依赖链**：标记像素在矩形内的局部位置编码出方向向量（不再是离散的格子槽位，而是连续的八方向之一），矩形的宽高同时决定水平/垂直步幅。方向与步幅共同决定印章轨迹，两者缺一不可——改变标记位置则整条轨迹方向改变，改变矩形尺寸则步幅改变。

将每个彩色矩形沿其内部黄(4)标记像素所编码的方向反复印章，步幅由矩形自身尺寸决定，印章副本中的标记被擦除。

**输入结构**：约 20×20 的黑(0)背景网格。散布 3-5 个互不相邻的实心矩形（每个宽 3-6 像素、高 3-6 像素），各为不同颜色（从蓝(1)、红(2)、绿(3)、灰(5)、品红(6)、橙(7)、青(8)中选取）。每个矩形内部恰好有一个黄(4)像素（标记像素），占据矩形的某个位置区域。生成约束：各矩形间距足够大，使得沿任意方向印章时各矩形的轨迹互不重叠；每个矩形的宽和高均为 3 的倍数（便于三等分）。

**规则**：
1. 对每个矩形，将其边界框沿宽度和高度各三等分，形成 3×3 的九宫格区域。黄(4)标记像素落入的区域决定方向向量：左上→(-1,-1)、上中→(-1,0)、右上→(-1,+1)、左中→(0,-1)、正中→无印章、右中→(0,+1)、左下→(+1,-1)、下中→(+1,0)、右下→(+1,+1)。
2. 以矩形高度为垂直步幅 sv、宽度为水平步幅 sh。从矩形当前位置出发，沿方向向量每步偏移 (sv × 方向行分量, sh × 方向列分量)，在新位置放置矩形的完整副本。
3. 副本中的黄(4)标记像素替换为该矩形的主体颜色。
4. 超出网格边界的部分裁剪丢弃；当某次印章完全超出网格时停止该矩形的轨迹。
5. 保留原始矩形，但将其中的黄(4)标记像素也替换为矩形主体颜色。
6. 处理顺序：按矩形边界框左上角从上到下、从左到右依次处理。后处理的印章覆盖先处理的。

**关键洞察**：黄色标记像素不是装饰——它在矩形内的九宫格位置编码了八个可能的印章方向之一，而矩形的宽和高则各自独立地控制水平和垂直步幅，因此同一个对象同时提供了精灵图、方向和步幅三个参数。

## 新题 2：对角链拓扑门控递减射线

**组合逻辑**：[对角链式连接 + 仅对角接触变色](拓扑分类) → 门控 → [射线延伸 + 递减填充](从边界框四侧发射递减宽度射线)（对角链式连接、射线延伸、递减填充均为已有原语；拓扑分类结果门控射线发射为创新结构关系）

**来源原语**：对角链式连接(diagonal_chain) ← ecb67b6d；仅对角接触变色(diagonal_touch_recolor) ← ecb67b6d；射线延伸(ray_extend) ← 9772c176；递减填充(shrinking_fill) ← 9772c176；四方外扩(four_way_expansion) ← 9772c176

**依赖链**：首先对每个 8-连通灰色区域做拓扑分类（是否为对角链），分类结果同时决定两件事：(1) 区域自身的颜色变换（活跃→青色，惰性→保持灰色），(2) 是否从该区域发射递减射线。射线的几何参数（起始宽度）取决于边界框尺寸，而边界框尺寸又取决于哪些区域被选中——这在多区域场景中形成拓扑→几何的间接耦合。惰性灰色区域还充当射线的阻挡物，进一步将分类结果反馈到射线路径中。

对灰色 8-连通区域做对角链拓扑测试：通过测试的区域变色为青(8)并向四方发射逐步收窄的黄(4)射线扇；未通过的区域保持灰色并阻挡射线。

**输入结构**：约 18×18 的黑(0)背景网格。散布 4-7 个由灰(5)像素构成的 8-连通区域（每个 4-12 像素）。部分区域是"对角链"——将其按 4-连通分解为若干小瓣（lobe），各瓣之间仅通过对角角点接触、形成不分叉的链或环。其余区域是"非链"——包含 4-连通面积 ≥ 3 的大瓣、分叉连接、或矩形块。生成约束：至少 2 个对角链区域和 2 个非链区域；各区域的边界框互不重叠且间距 ≥ 3 像素。

**规则**：
1. 对每个灰(5)的 8-连通区域，按 4-连通分解为小瓣。若所有瓣之间仅以对角角点接触且连接拓扑为不分叉的链或简单环（每个瓣最多与另外 2 个瓣对角接触），则该区域标记为"活跃"，重涂色为青(8)；否则标记为"惰性"，保持灰(5)。
2. 对每个活跃区域，取其轴对齐边界框。从边界框的四条边分别向外发射"递减扇"：
   - 上侧扇：第一步在边界框上方紧邻的一行，宽度 = 边界框宽度，居中对齐；每再往上一行，宽度减少 2（左右各缩 1 像素），直到宽度 < 1 为止。
   - 下侧扇：对称地向下发射，宽度从边界框宽度开始递减。
   - 左侧扇：第一步在边界框左侧紧邻的一列，高度 = 边界框高度；每再往左一列，高度减少 2，直到高度 < 1。
   - 右侧扇：对称地向右发射。
3. 扇中每个像素涂为黄(4)，但遇到以下情况时该像素不涂色且该方向的扇在此行/列终止：(a) 该像素位置已是惰性灰(5)区域的像素；(b) 该像素位置超出网格边界。
4. 若多个活跃区域的扇在同一像素重叠，该像素涂为品红(6)。
5. 处理顺序：所有活跃区域的扇同时计算，重叠检测在所有扇完成后统一执行。

**关键洞察**：同一个拓扑测试（对角链分类）同时控制了三个后果——区域自身的颜色、是否发射射线、以及是否作为射线阻挡物。惰性区域的双重角色（保持灰色 + 阻挡射线）使得拓扑分类的结果从两个方向影响最终输出。

## 新题 3：嵌套深度决定投影距离

**组合逻辑**：[包含](计算嵌套层数) → [计数](深度数值化) → [投影](距离 = 深度) + [重涂色](颜色 = 最内层框架色) + [擦除]（包含、投影、计数均为已有原语；嵌套深度作为投影距离的数值参数为创新结构关系）

**来源原语**：包含(containment) ← 8efcae92；投影(project) ← e39e9282；计数(counting) ← 642d658d；重涂色(recolor) ← 多源；擦除(erase) ← e39e9282

**依赖链**：嵌套矩形框架构成包含层级，标记像素的嵌套深度（被几层框架包围）直接成为投影的位移量——深度不再只是分类标签而是连续的几何参数。同时，最内层框架的颜色决定投影像素的颜色。移动任何一层框架会同时改变多个标记的深度和颜色归属，形成结构→数值→空间的三层耦合。

在嵌套矩形框架中，将栗(9)标记像素沿其所在侧向内投影，投影距离等于该标记被框架包围的层数，投影颜色取自最内层框架。

**输入结构**：约 17×17 的黑(0)背景网格。3-4 层嵌套的空心矩形框架（仅边框像素着色，内部为黑色），每层框架颜色不同（从蓝(1)、红(2)、绿(3)、橙(7)、青(8)中选取）。框架之间留有 2-3 像素的黑色间隙。在间隙中散布 4-6 个栗(9)标记像素，分布在不同嵌套深度的位置。生成约束：每个标记像素严格靠近其最内层框架的某一侧（与该侧边框的距离严格小于与其他三侧的距离）；不同标记的嵌套深度不全相同（至少出现 2 种不同深度）；投影后的目标位置不会落在框架像素上也不会超出最内层框架的内部区域。

**规则**：
1. 对每个栗(9)标记像素，计算其嵌套深度 D = 完全包围该像素的矩形框架数（一个框架"完全包围"某像素，当且仅当该像素在框架矩形的内部区域内，不在框架边框上）。
2. 确定该标记像素相对于其最内层包围框架的方位：计算标记到最内层框架内部区域四条边的距离，取距离最小的边作为"所在侧"。左侧→向右投影，右侧→向左投影，上侧→向下投影，下侧→向上投影。
3. 沿确定的方向移动 D 个像素，在目标位置放置一个新像素，颜色 = 最内层包围框架的颜色。
4. 擦除原始栗(9)标记像素（设为黑(0)）。
5. 框架本身不变。
6. 处理顺序：按标记像素位置从上到下、从左到右依次处理；若多个投影落在同一位置，后处理的覆盖先处理的。

**关键洞察**：嵌套深度在这里不是离散类别而是一个数值参数——它直接等于投影位移的像素数。求解者必须同时推断"投影方向由方位决定"和"投影距离由嵌套深度决定"两条规则，且两条规则必须配合才能确定输出。

## 新题 4：间隙桥色由朝向标记多数决

**组合逻辑**：[填充 + 间隙区域涂色](桥接间隙) ← 桥色由 → [计数 + 邻接多数决](朝向边上的标记投票) + [擦除]（填充、邻接多数决、计数均为已有原语；标记投票决定桥色为创新结构关系——源题中多数决用于区域重涂色，这里用于间隙填充的颜色选择）

**来源原语**：填充(fill) ← d6ad076f；间隙区域涂色(gap_region_recolor) ← d6ad076f；邻接多数决(adjacency_majority_rule) ← 477d2879；边邻接计数(edge_adjacency_count) ← 477d2879；计数(counting) ← 642d658d；擦除(erase) ← e39e9282；两体之间(between_two_objects) ← d6ad076f

**依赖链**：间隙的几何形状由两个同色矩形的相对位置决定，但间隙的填充颜色不是固定的——它由两个矩形朝向间隙一侧的边缘上的标记像素投票产生。标记的空间分布（在哪条边上、有多少个）直接决定投票结果，改变任何一个标记的位置或颜色都可能翻转投票结果并改变桥色。

找到同色矩形对之间的间隙，用两个矩形面向间隙的边缘上标记像素的多数颜色填充该间隙，然后擦除所有标记。

**输入结构**：约 18×18 的黑(0)背景网格。2-3 对同色矩形（每对的两个矩形颜色相同，不同对颜色不同；选自蓝(1)、绿(3)、灰(5)），每对中两个矩形在同一行或同一列上对齐，中间隔着 2-4 像素的黑色间隙。每个矩形的边缘（仅面向间隙的那条边）上嵌有若干标记像素（从红(2)、黄(4)、橙(7)中选取），标记像素替换了矩形该边上的部分像素。生成约束：每对矩形的朝向边上合计至少 3 个标记像素，且存在一个严格多数颜色（不出现平票）；不同对矩形之间不共享间隙区域。

**规则**：
1. 识别同色矩形对：颜色相同且在水平或垂直方向上边界框对齐的两个矩形构成一对。
2. 对每对矩形，确定间隙区域：两矩形朝向边之间的轴对齐矩形区域（宽度 = 两矩形重叠的行/列范围，深度 = 间隙的像素数）。
3. 统计两个矩形各自朝向间隙那条边上的标记像素颜色。将两个矩形的标记合并计数。出现次数最多的标记颜色即为该对的"桥色"。
4. 用桥色填充间隙区域中的所有黑(0)像素。
5. 擦除所有矩形上的标记像素：将标记像素恢复为其所在矩形的主体颜色。
6. 处理顺序：按矩形对的间隙中心从上到下、从左到右依次处理。

**关键洞察**：间隙的颜色既不是背景色也不是矩形本身的颜色，而是由面向间隙的边缘上的标记像素"投票"产生的。求解者需要对比多个示例才能发现投票规则——单个示例中可能看起来像是随机指定颜色。

## 新题 5：十字臂重复色决定缺陷光晕色

**组合逻辑**：[图案识别 + 中心与臂颜色](识别十字标记并提取重复臂色) → 参数传递 → [标记环绕](用提取的颜色绘制缺陷光晕) + [擦除]（图案识别、标记环绕均为已有原语；重复臂色跨域传递为光晕颜色参数是创新结构关系——源题中十字臂色输出为 1×1 答案，这里它变成另一个操作的颜色参数）

**来源原语**：图案识别(pattern_recognition) ← 642d658d；中心与臂颜色(center_and_arm_color) ← 642d658d；重复色为答案(repeated_color_answer) ← 642d658d；标记环绕(surround_marking) ← 71e489b6；缺陷像素(defect_pixel) ← 71e489b6；邻域包围(neighborhood_surround) ← 71e489b6；擦除(erase) ← e39e9282；忽略干扰项(ignore_distractors) ← 642d658d

**依赖链**：十字标记的图案识别提取出一个颜色值（重复出现的臂色），该颜色值不直接输出为答案，而是作为参数传递给缺陷光晕绘制操作。两个操作作用于同一网格的不同特征（十字标记 vs. 缺陷孔洞），但通过颜色参数紧密耦合。删除十字标记→不知道光晕该用什么颜色；删除缺陷检测→不知道光晕该画在哪里。

在蓝(1)前景中找到所有黄(4)中心十字标记，提取重复出现的臂色，用该颜色为前景中的小黑洞缺陷绘制 8-邻域光晕，然后擦除所有十字标记。

**输入结构**：约 15×15 的网格，大部分为蓝(1)前景，边缘和角落有黑(0)背景区域。蓝色前景中嵌有 3-5 个十字标记：每个十字标记由 1 个黄(4)中心像素和 4 个正交相邻的同色臂像素构成。各十字的臂色各不相同（从红(2)、绿(3)、橙(7)、青(8)、栗(9)中选取），但恰好有一种臂色出现在 2 个或以上十字标记上。蓝色前景中还散布 2-4 个小黑(0)缺陷孔洞（每个为 1-2 像素的 4-连通黑色区域，完全被蓝色像素包围）。生成约束：十字标记之间互不相邻（间距 ≥ 2 像素）；缺陷孔洞不与十字标记相邻；除重复臂色外，其余臂色各出现恰好一次；前景中的大块黑色背景区域不算缺陷（缺陷仅限面积 ≤ 2 的完全被蓝色包围的黑色 4-连通分量）。

**规则**：
1. 识别所有十字标记：在蓝(1)前景中找到所有黄(4)像素，检查其上下左右 4 个邻居是否为同一种非蓝、非黄、非黑颜色。满足条件的为十字标记，该非蓝色为其臂色。
2. 统计各臂色出现次数。出现次数 > 1 的唯一臂色记为"光晕色" H。
3. 识别缺陷孔洞：在蓝(1)前景内部找到所有面积 ≤ 2 的 4-连通黑(0)分量（其每个像素的 4 个正交邻居全部为蓝(1)或同一分量的黑(0)像素，即该分量完全被蓝色包围）。
4. 对每个缺陷孔洞的每个像素，将其 8-邻域中当前为蓝(1)的像素重涂为光晕色 H。缺陷像素本身保持黑(0)不变。
5. 擦除所有十字标记：将黄(4)中心和臂像素全部重涂为蓝(1)，恢复前景。
6. 其余像素不变。

**关键洞察**：十字标记不是装饰物——它们是一个隐藏的投票系统，其中重复出现的臂色是一条需要对比多个十字才能归纳出的规则。这个被提取的颜色不直接出现在输出中，而是通过光晕操作间接体现在缺陷周围。

## 新题 6：障碍重置循环填充相位

**组合逻辑**：[标记界定母题](提取母题行) + [循环填充](向下循环铺设) ← 相位被 → [障碍物](重置循环计数器) + [擦除]（循环填充、标记界定母题、障碍物均为已有原语；障碍物触发循环计数器重置是创新结构关系——源题中障碍物阻挡路径，这里它重置周期相位）

**来源原语**：循环填充(cyclic_fill) ← 12422b43；标记界定母题(marker_delimits_motif) ← 12422b43；循环重复(repeat_cyclically) ← 12422b43；障碍物(obstacle) ← cc9053aa；邻域禁区(neighbor_exclusion) ← cc9053aa；母题行(motif_rows) ← 12422b43；空白后缀区(empty_suffix_region) ← 12422b43；擦除(erase) ← e39e9282

**依赖链**：灰色标记界定母题行并提取循环内容，循环填充按母题周期向下铺设。橙色障碍物不只是遮挡单个像素——它使循环计数器重置为第 1 行，从而改变障碍物下方所有行的相位对齐。因此一个障碍物的位置影响的不是局部像素而是整个下游的周期排列。障碍物越多，相位断裂越频繁，输出图案越碎片化。

从灰(5)标记行提取母题，向下循环填充空白区域；遇到橙(7)障碍像素时跳过该像素并重置循环计数器，使下一行从母题第 1 行重新开始。

**输入结构**：约 20×25 的网格（较高）。黑(0)背景。最左列的前 M 行（M = 3-5）为灰(5)标记像素，标记出母题区域。这些行的其余列包含由 1-3 种前景色（从蓝(1)、红(2)、绿(3)、青(8)中选取）绘制的图案（母题）。标记行下方可能有少量非空前景行（延续已有图案）。再往下是大片空白的黑色后缀区域（约 12-18 行）。后缀区域中散布 2-4 个橙(7)像素作为障碍物。生成约束：障碍物之间在垂直方向上间距 ≥ 3 行（确保相位重置效果可见）；母题行数 M ≥ 3（使循环周期明显）；后缀区域高度 ≥ 3M（至少能完整循环一轮）。

**规则**：
1. 提取母题：找到最左列中从第 1 行开始的连续灰(5)像素段，这些行即为母题行。将母题行中的灰(5)标记像素替换为黑(0)后，剩余内容即为母题（保留各行的全部列），记母题行数为 M，行编号为 1 到 M。
2. 确定填充起始行：找到网格中最后一个包含非黑前景像素的行（不含橙(7)障碍），其下一行为填充起始行。
3. 初始化循环计数器 c = 1。从填充起始行开始，逐行向下处理直到网格底部：
   - 若当前行包含橙(7)障碍像素：保留障碍像素不变，该行其余黑色像素按母题第 c 行对应列的内容填充（障碍像素所在位置跳过不填），然后将 c 重置为 1。
   - 若当前行不含障碍像素：按母题第 c 行对应列的内容填充所有黑色像素，然后 c = (c mod M) + 1。
4. 填充起始行以上的内容保持不变（原有前景行不被覆盖）。

**关键洞察**：橙色障碍物的作用不是简单的遮挡——它触发循环计数器的相位重置。这意味着一个位于第 k 行的障碍会影响从第 k+1 行到下一个障碍（或网格底部）之间所有行的母题对齐方式。求解者需要对比有障碍和无障碍的示例才能发现这一非显然的"重置"语义。

## 新题 7：高度排名决定印章复制数

**组合逻辑**：[排序 + 高度排名](对竖直条按高度排序) → 排名值参数化 → [印章覆盖](复制数 = 排名值) + [重涂色](副本颜色 = 标记颜色) + [擦除]（排序、印章覆盖、重涂色均为已有原语；排名数值直接作为印章重复次数是创新结构关系——源题中排名用于选择极值，这里用于量化操作参数）

**来源原语**：排序(sorting) ← a61f2674；保留极值高度分色(keep_extremes_and_recolor) ← a61f2674（创新：不限于极值，排名值全部使用）；印章覆盖(stamp) ← e619ca6e；重涂色(recolor) ← 多源；标记像素(marker_pixel) ← 多源；擦除(erase) ← e39e9282；竖直线段(vertical_bar) ← a61f2674

**依赖链**：高度排名将竖直条的物理属性（高度）转化为一个序数值，该值直接控制印章覆盖的重复次数。同时标记像素的颜色独立地决定印章副本的颜色。排名、形状、颜色三个参数分别来自同一竖直条的不同属性——高度、轮廓和标记——形成"一体三参"的紧耦合结构。

将灰(5)竖直条按高度排名后，每个竖直条向右印章复制"排名值"次，副本涂为该条顶端标记像素的颜色，原始条和标记均被擦除。

**输入结构**：约 15×20 的黑(0)背景网格。沿底边排列 4-6 个灰(5)一像素宽竖直条（每个竖直条底部与网格底边对齐，高度各不相同，范围 3-10 像素）。每个竖直条最顶端的像素被替换为一个彩色标记像素（从蓝(1)、红(2)、绿(3)、黄(4)、橙(7)、青(8)中选取，各条标记色不同）。竖直条之间水平间距 ≥ 3 列。生成约束：所有竖直条高度互不相同（保证排名无歧义）；竖直条数量 N 满足：最矮条（排名 = N）向右印章 N 次后不超出网格右边界（即每条右侧有足够空间放置其排名值个副本，每副本间距 2 列）。

**规则**：
1. 识别所有竖直条：底边对齐的、宽度为 1 列的灰(5)连续像素段（顶端标记像素视为该条的一部分，高度包含标记像素）。
2. 按高度从高到低排序，赋予排名：最高 = 1，次高 = 2，...，最矮 = N。
3. 对每个竖直条（高度 h，排名 r，标记色 C，所在列 col）：
   - 在 col + 2, col + 4, ..., col + 2r 列上各放置一个高度为 h 的竖直条副本（底部对齐），颜色为 C（非灰色，也不含标记像素）。
   - 超出网格右边界的副本部分裁剪丢弃。
4. 擦除所有原始灰(5)竖直条和标记像素（设为黑(0)）。
5. 处理顺序：从左到右依次处理各竖直条。后生成的副本若与先生成的副本重叠，后者覆盖前者。

**关键洞察**：排名和复制数之间的反直觉关系——最高的竖直条排名 1，只生成 1 个副本；最矮的竖直条排名最大，反而生成最多副本。求解者需要对比多个示例中不同高度条的副本数量才能推断出"复制数 = 高度排名"这一规则，而非更直觉的"复制数 = 高度值"。

## 新题 8：连通性筛选后极值重涂色加描边

**组合逻辑**：[连通性 + 面积大于一则涂](筛选掉单像素噪声) → 改变排名池 → [排序 + 保留极值高度分色](对存活分量按面积极值分色) + [描边 + 微型对象描边](为所有存活分量绘制轮廓)（连通性判断、排序、描边均为已有原语；噪声筛选改变极值排名池是创新结构关系——源题中噪声筛选与排名、描边分属不同题目且各自独立运行）

**来源原语**：连通性(connectivity) ← e0fb7511；面积大于一则涂(recolor_if_area_gt_one) ← e0fb7511（创新：面积 = 1 则擦除，而非保留）；排序(sorting) ← a61f2674；保留极值高度分色(keep_extremes_and_recolor) ← a61f2674（创新：按面积而非高度排极值）；描边(outline) ← b27ca6d3；尺寸分类(size_classification) ← b27ca6d3；擦除(erase) ← e39e9282

**依赖链**：第一步的连通性筛选（擦除单像素分量）直接改变了第二步排名的候选池——原本面积最小的可能是单像素噪声，被擦除后"最小"这一角色由另一个多像素分量接替。因此，添加或删除单像素噪声会改变最终哪个分量被涂红。描边操作应用于所有存活分量，为极值分量的颜色区分提供视觉参照。

擦除单像素灰(5)噪声后，对剩余 4-连通分量按面积排名：最大分量内部涂蓝(1)、最小分量内部涂红(2)，并为所有存活分量绘制绿(3)轮廓。

**输入结构**：约 16×16 的黑(0)背景网格。散布 6-10 个由灰(5)像素构成的 4-连通分量，面积从 1 到 15 像素不等：其中 2-4 个是单像素分量（噪声），其余是多像素分量（面积 ≥ 2）。多像素分量形态多样——有的是不规则斑块（4-8 像素）、有的是短线段（2-3 像素）、有的是较大团块（10-15 像素）。生成约束：擦除单像素分量后，剩余分量中面积最大和面积最小的各只有一个（无并列）；至少存在一个单像素分量的面积（= 1）小于所有多像素分量的面积（此条件恒成立）；各分量边界框之间间距 ≥ 2 像素（确保描边不重叠）；存在至少一个单像素分量位于两个多像素分量之间的区域（使其擦除对空间布局产生可见变化）。

**规则**：
1. 识别所有灰(5)的 4-连通分量，计算每个分量的面积（像素数）。
2. 擦除所有面积 = 1 的分量（将其像素设为黑(0)）。
3. 对剩余分量按面积排序。将面积最大的分量内部像素重涂为蓝(1)；将面积最小的分量内部像素重涂为红(2)。其余分量保持灰(5)。
4. 对每个存活分量（不论颜色），计算其轴对齐边界框，将边界框向外扩展 1 像素（上下左右各 1 像素），裁剪到网格范围内。在扩展后边界框的外圈像素位置中，凡当前为黑(0)的像素涂为绿(3)。
5. 处理顺序：先执行步骤 2（擦除），再执行步骤 3（重涂色），最后执行步骤 4（描边）。描边按分量边界框左上角从上到下、从左到右依次处理。

**关键洞察**：单像素噪声的存在不只是视觉干扰——它们的擦除直接改变了哪个分量成为"面积最小"从而被涂红。求解者如果忽略筛选步骤直接排名，会得到错误的极值分量。需要对比有/无特定单像素噪声的示例才能发现"先筛后排"的规则。

## 新题 9：旋转镜像匹配查表决定重涂色

**组合逻辑**：[图案识别 + 旋转 + 镜像](几何形状匹配，允许旋转和镜像变换) → 查表 → [重涂色](匹配结果决定颜色) + [擦除]（图案识别、旋转、镜像、重涂色均为已有原语；以形状为键的几何查表为创新结构关系——源题中旋转/镜像用于拼图组装，这里用于形状→颜色的查表映射）

**来源原语**：图案识别(pattern_recognition) ← 642d658d（创新：从十字图案改为任意精灵体形状匹配）；旋转(rotate) ← f560132c（创新：从拼装辅助改为匹配辅助）；镜像(reflect) ← f560132c；重涂色(recolor) ← 多源；擦除(erase) ← e39e9282；包含(containment) ← 8efcae92；精灵体(sprite) ← 5117e062；边框(border_frame) ← b27ca6d3

**依赖链**：框内参考精灵体构成一个"形状→颜色"查找表。框外查询精灵体通过几何匹配（含旋转和镜像）在表中找到对应条目，获取目标颜色。两类精灵体的角色完全不同（参考 vs. 查询），但它们之间的结构关系（形状匹配）是唯一决定输出颜色的机制。删除参考精灵体→无查找表；删除旋转/镜像→匹配失败；删除查询精灵体→无对象需要重涂。

框内彩色参考精灵体定义了"形状→颜色"映射表，框外灰(5)查询精灵体通过旋转/镜像匹配查表后被重涂为对应颜色，框架和参考精灵体随后被擦除。

**输入结构**：约 18×18 的黑(0)背景网格。网格一侧（如左侧或上方）有 3-4 个灰(5)空心矩形框架（边框宽度 1 像素），每个框架内部包含一个小型彩色精灵体（3-6 像素的 4-连通图形，各用不同颜色：蓝(1)、红(2)、绿(3)、橙(7)等）。框外区域散布着与框内精灵体形状相同但可能经过 90°/180°/270° 旋转和/或水平/垂直镜像变换的灰(5)精灵体，数量 = 框架数量。生成约束：每个框内精灵体的形状在所有 8 种旋转/镜像变换下互不相同（即不同框内精灵体不会通过变换得到相同形状，保证匹配唯一）；每个框外精灵体恰好匹配一个框内精灵体（一一对应）；框外精灵体之间互不相邻，与框架之间也不相邻。

**规则**：
1. 识别框架：灰(5)空心矩形（边框为灰(5)、内部为非灰色内容或黑色背景）。提取每个框架内部的精灵体及其颜色，记为参考列表 {形状_i → 颜色_i}。
2. 识别框外精灵体：不被任何框架包围的灰(5)的 4-连通分量。
3. 对每个框外精灵体，生成其所有旋转（0°, 90°, 180°, 270°）和镜像（水平翻转、垂直翻转及其旋转组合，共最多 8 种变换）下的形状。在参考列表中找到形状匹配的条目（像素模式逐格比对，忽略平移），获取对应颜色 C_i。
4. 将该框外精灵体的所有灰(5)像素重涂为 C_i。
5. 擦除所有框架（灰(5)边框设为黑(0)）和框内参考精灵体（设为黑(0)）。
6. 处理顺序：框外精灵体按边界框左上角从上到下、从左到右依次处理。

**关键洞察**：框内精灵体不是普通的图例——它们构成了一个以"几何形状（含旋转/镜像等价类）"为键、以"颜色"为值的查找表。求解者需要发现框外灰色精灵体是框内彩色精灵体的变换副本，并推断出允许旋转和镜像的匹配规则——这需要对比多个示例中不同变换类型的出现来确认。
