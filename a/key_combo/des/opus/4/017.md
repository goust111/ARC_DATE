## 新题 1：射线分割区域的邻近归属与排名填色

**组合逻辑**：[射线延伸](从对角线改为正交十字射线，射线源是散布的标记像素而非基底色区域中的标记) → [射线分割区域](射线不再是从边缘控制像素向内，而是从内部标记向边缘，分割整个网格) → [面积排名](创新：不再是分量内最大矩形，而是分割出的区域按面积排名) → [重涂色](排名决定颜色，而非模板传递)

**来源原语**：射线延伸(d07ae81c), 射线分割区域(4a21e3da), 面积排名(a8d7556c), 重涂色(recolor, 多题), 标记像素(d07ae81c/dc433765/928ad970), 连通分量(d0f5fe59)

**依赖链**：标记像素的位置决定射线路径 → 射线将网格分割为若干矩形区域 → 每个区域的面积由分割拓扑唯一确定 → 面积排名驱动填色映射。标记数量和位置同时影响分割数量和每个区域的大小，无法跳过任一步骤。

从散布的标记像素出发发射正交射线分割网格，按分割区域面积排名为各区域填入不同颜色。

**输入结构**：约 14x14 的黑(0)背景网格。网格内部（非边缘行列）散布 2-3 个红(2)标记像素，各标记之间不共享行或列（即任意两个标记不在同一行也不在同一列）。无其他前景元素。生成约束：标记像素数量为 2 或 3；标记不在网格最外一圈；任意两标记不共行不共列。

**规则**：
1. 从每个红(2)标记像素出发，沿上、下、左、右四个方向延伸射线直至网格边缘。射线涂为灰(5)。标记像素本身也涂为灰(5)。
2. 灰色射线将网格分割为若干互不相连的矩形区域（由于标记不共行不共列，每条水平射线和垂直射线不会在标记之外交叉于同一点，分割结果均为矩形）。
3. 统计每个矩形区域中黑(0)像素的数量作为该区域的面积。
4. 将所有区域按面积从大到小排名。面积最大的区域填充为蓝(1)，第二大填充为绿(3)，第三大填充为黄(4)，其余区域保持黑(0)。若两个区域面积相同，按其左上角位置从左到右、从上到下排先后（靠左上的排名更前）。
5. 灰(5)射线像素保持不变。

**关键洞察**：标记像素的数量和位置共同决定分割拓扑——仅改变一个标记的行或列就会彻底改变所有区域的面积和排名结果。求解者必须先完成分割，才能确定哪些区域获得颜色，无法从局部推断全局。

## 新题 2：散布令牌计数决定枢轴旋转角度

**组合逻辑**：[计数](计数对象从连通分量变为散布的孤立令牌像素) → [绕点旋转](旋转角度不再固定为 90°，而由全局计数值动态决定) → [重涂色](旋转前旧位置涂新色作为痕迹，已有原语)

**来源原语**：计数(ff28f65a/d0f5fe59), 绕点旋转(c074846d), 重涂色(c074846d), 枢轴标记(c074846d), 线段(c074846d), 连通分量(d0f5fe59)

**依赖链**：令牌计数 → 确定旋转倍数 → 旋转角度作用于每个枢轴-线段对 → 旧位置涂痕迹色。计数结果是全局的，但旋转是局部的（每个枢轴独立），二者通过角度参数耦合。

统计散布的孤立蓝色令牌数量 N，将每个灰色枢轴上的红色线段绕枢轴顺时针旋转 N x 90 度，原位留绿色痕迹。

**输入结构**：约 12x12 的黑(0)背景网格。包含以下元素：
- 2-3 个灰(5)枢轴标记像素，各自恰有一条红(2)直线段从枢轴出发沿水平或垂直方向延伸（线段长度 2-4 像素，不含枢轴本身）。每条红线段仅与一个枢轴相邻，且线段仅从枢轴的一侧延伸。不同枢轴的线段互不接触。
- 若干孤立蓝(1)单像素散布于网格中，不与任何枢轴或线段的 4-邻域相邻。蓝色像素数量为 1、2 或 3。
- 生成约束：旋转后的线段不超出网格边界；不同枢轴旋转后的线段互不重叠。

**规则**：
1. 统计蓝(1)孤立像素的数量，记为 N（N 取值 1、2 或 3）。
2. 对每个灰(5)枢轴及其红(2)线段：将红色线段绕枢轴顺时针旋转 N x 90 度。
3. 将旋转前红色线段所在位置重涂为绿(3)（痕迹）。
4. 在旋转后的新位置绘制红(2)线段。
5. 灰(5)枢轴像素和蓝(1)令牌像素保持不变。
6. 冲突处理：若痕迹位置与旋转后新位置重叠（例如 N=2 即 180 度旋转，起点终点对称时不会重叠；N=0 无旋转时不存在痕迹），重叠像素保持红(2)（新位置优先）。

**关键洞察**：蓝色令牌像素与枢轴-线段在空间上毫无关联——它们的唯一作用是编码旋转角度的倍数。必须对比不同数量蓝色令牌的示例，才能发现计数与旋转角度的乘法关系。

## 新题 3：半轮廓镜像重建后按调色带逐列着色

**组合逻辑**：[镜像](从单一半轮廓推广为横向对称重建，保留) → [擦除+填充](擦除轮廓线并填充内部行段，已有原语组合) → [逐列对应+调色带指定列色](创新：填充后的形状不再是单色，而是每列独立从调色带取色)

**来源原语**：镜像(bf32578f), 擦除(bf32578f), 填充(bf32578f), 内部行段填充(bf32578f), 半侧轮廓(bf32578f), 对称轴(bf32578f), 调色带(278e5215), 逐列对应(278e5215), 调色带指定列色(278e5215), 裁剪(crop, 278e5215/890034e9)

**依赖链**：半轮廓 → 镜像重建完整形状 → 确定内部区域（行段填充）→ 内部区域的列范围与调色带宽度匹配 → 逐列着色。调色带的宽度恰等于重建后形状边界框的宽度，但这只有完成镜像和内部填充后才能验证。

将左半轮廓镜像重建为完整对称形状并填充内部，再用下方调色带为每列独立指定颜色。

**输入结构**：约 15x18 的黑(0)背景网格，分为上下两个区域：
- 上方区域（约占 12-14 行）：包含一个红(2)的左半轮廓，即一个水平对称闭合形状的左半部分。轮廓由 4-连通的红色像素构成，高度 6-10 像素，最右列紧靠上方区域水平中轴（即对称轴恰在轮廓最右列的右侧）。轮廓内部为黑(0)。
- 下方区域（最底部 1 行）：一条调色带，宽度恰好等于上方形状镜像重建后边界框的宽度 W。调色带中每个像素是 ARC 0-9 中的某种颜色（不含黑(0)和红(2)），相邻列颜色可以不同。
- 上方区域和下方调色带之间有至少 1 行黑色间隔。
- 生成约束：调色带宽度 W 与重建后形状的边界框宽度严格相等；半轮廓的每一行至少有 1 个红色像素（保证镜像后每行都有内部区域）。

**规则**：
1. 找到红(2)半轮廓的边界框，令其最右列为 C_right。对称轴位于 C_right 与 C_right+1 之间（半列位置）。
2. 将半轮廓水平镜像到右侧，重建完整的对称闭合轮廓。
3. 擦除所有红色轮廓像素（置为黑(0)）。
4. 对重建后形状覆盖的每一行：找到该行最左和最右的原轮廓像素位置（即对称后的边界），填充两者之间严格内部的像素（不含边界本身）。
5. 确定填充区域的边界框宽度 W 和左起列 C_left。对于填充区域中位于列 c 的每个像素，从调色带的第 (c - C_left) 个位置取颜色进行涂色。
6. 输出：裁剪到填充区域的边界框。

**关键洞察**：调色带的宽度只有在完成镜像重建和内部填充之后才能与形状宽度对齐——如果跳过镜像直接读调色带，宽度不匹配无法正确映射。调色带实质上是对最终形状每列颜色的预编码。

## 新题 4：双掩码逻辑交的连通分量计数编码为对角线矩阵

**组合逻辑**：[逻辑交](保留核心的双掩码 AND 操作) → [连通分量识别](创新：AND 结果不再直接输出，而是作为连通分量分析的输入) → [计数+对角线输出](分量数量编码为正方形对角线矩阵)

**来源原语**：逻辑交(0520fde7), 位掩码(0520fde7), 分隔列(0520fde7), 逐像素对齐(0520fde7), 双掩码重叠标记(0520fde7), 连通分量(d0f5fe59/a8d7556c), 计数(d0f5fe59/ff28f65a), 对角线输出(d0f5fe59), 数量决定边长(d0f5fe59)

**依赖链**：灰色分隔列定位 → 拆分左右掩码 → 逐像素 AND → AND 结果的连通分量识别 → 分量计数 → 计数值决定输出矩阵边长 → 对角线填色。AND 结果的几何形状决定分量数量，分量数量决定输出尺寸。

将灰色竖线分隔的左右掩码做逻辑交，统计交集中的连通分量数量 M，输出 MxM 的对角线矩阵。

**输入结构**：约 7x(2W+1) 的网格（高度 5-9 行，宽度由两个 W 列宽的掩码加 1 列分隔组成，W 约 4-7）。
- 正中一列为灰(5)，从第一行贯穿到最后一行，将网格分为左右两个等宽面板。
- 左面板：黑(0)背景上分布若干蓝(1)像素，构成一个或多个 4-连通的前景区域。
- 右面板：黑(0)背景上分布若干蓝(1)像素，构成一个或多个 4-连通的前景区域。
- 左右面板形状不同但尺寸相同。
- 生成约束：左右掩码的 AND 结果至少有 1 个蓝色像素；AND 结果的 4-连通分量数在 2-5 之间。

**规则**：
1. 找到灰(5)分隔列，将其左侧和右侧分别作为左掩码和右掩码。
2. 逐像素比较：若左掩码和右掩码在对应位置都是蓝(1)，则该位置标记为活跃；否则标记为非活跃。
3. 对所有活跃像素进行 4-连通分量分析，统计连通分量数量 M。
4. 在所有活跃连通分量中，找到像素数最多的那个分量，记录其颜色为蓝(1)（输出颜色固定为红(2)——见下）。
5. 输出一个 MxM 的黑(0)网格，主对角线（左上到右下）像素涂为红(2)。

**关键洞察**：两个看似独立的蓝色图案的交集，其几何碎片化程度（连通分量数）才是真正的输出信息。交集可能是一个连通区域也可能碎成多个孤立块——这取决于两个掩码前景的精确对齐方式，而非任一掩码单独的形态。

## 新题 5：面板引导线决定镜像轴向后叠加检测封闭区域

**组合逻辑**：[轴线决定变换](保留引导线编码镜像轴的机制) → [镜像](创新：不再是面板内自镜像，而是两个面板各自镜像后做叠加) → [透明叠加+逐像素比较](创新：叠加不再是寻找共同背景，而是按三种逻辑分类着色) → [填充](创新：叠加结果中被非背景像素完全包围的黑色区域填充新色)

**来源原语**：轴线决定变换(4e7e0eb9), 镜像(4e7e0eb9/bf32578f), 引导线(4e7e0eb9), 九宫面板(4e7e0eb9), 透明叠加(94f9d214), 逐像素比较(94f9d214), 共同背景标前景(94f9d214), 填充(bf32578f), 封闭区域(a8d7556c)

**依赖链**：引导线朝向 → 决定各面板的镜像轴 → 镜像完成各面板 → 叠加比较产生三色分类 → 分类结果中封闭的黑色区域被填充。两面板的引导线方向可能不同（一个水平一个垂直），导致叠加后的几何形态无法从单个面板预测。

两个面板各自根据引导线方向镜像补全，叠加后按像素重叠情况分三色标记，并填充叠加结果中的封闭黑色区域。

**输入结构**：约 9x19 的网格（高 9 列宽 19），由一列灰(5)分隔列分为左右两个 9x9 面板。
- 每个面板内部有一条引导线：要么是完整的水平灰(5)中心行（第 5 行），要么是完整的垂直灰(5)中心列（第 5 列）。引导线将面板分为两半。
- 面板的一半包含若干蓝(1)像素构成的图案（4-连通，约 6-12 像素），另一半为黑(0)。
- 左面板和右面板的引导线方向可以相同也可以不同。
- 生成约束：两面板各自镜像补全后尺寸相同（都是 9x9 去掉引导线后的 8x9 或 9x8，统一裁剪到不含引导线的区域后尺寸匹配）；叠加后至少存在一个被非黑像素完全 4-邻域包围的黑色连通区域。

**规则**：
1. 对每个面板，根据引导线方向确定镜像轴：水平引导线 → 上下镜像（将有图案的一半镜像到另一半）；垂直引导线 → 左右镜像。
2. 移除引导线像素（置为黑(0)），得到两个补全后的面板 P_left 和 P_right。
3. 将 P_left 和 P_right 裁剪为相同尺寸后逐像素叠加：
   - 两面板对应位置都是黑(0)→ 保持黑(0)。
   - 仅一个面板有蓝(1)→ 该位置涂为蓝(1)。
   - 两个面板都有蓝(1)→ 该位置涂为黄(4)。
4. 在叠加结果中，找到所有被非黑像素（蓝(1)或黄(4)）在 4-邻域方向上完全包围的黑(0)连通区域（即该区域的任何像素走 4-邻域路径都无法到达网格边缘而不经过非黑像素），将这些区域填充为红(2)。
5. 输出叠加并填充后的网格。

**关键洞察**：两个面板的引导线方向组合（水平+水平、垂直+垂直、水平+垂直）产生完全不同的叠加几何——特别是当方向不同时，一个面板的对称图案与另一个面板的对称图案以正交方式叠加，可能在交叉处围出仅靠单面板无法预见的封闭区域。

## 新题 6：轮廓像素计数驱动环形边框间隔平铺与内向射线

**组合逻辑**：[计数](创新：计数对象从连通分量变为单个轮廓形状的像素数，且计数结果不再映射到固定图案位置，而是映射到环形周期间距) → [环形周期+间隔等长重复](创新：间隔长度不再由边框段自身长度决定，而由外部计数值决定) → [射线延伸](创新：射线源不再是内部标记像素，而是边框上被激活的像素，方向为向网格中心的正交方向)

**来源原语**：计数(ff28f65a/d0f5fe59), 环形周期(30f42897), 间隔等长重复(30f42897), 边框段(30f42897), 矩形边界(30f42897), 射线延伸(d07ae81c), 轮廓字形(eee78d87), 标记像素(marker_pixel)

**依赖链**：轮廓像素计数 N → 决定边框激活间距 → 间距决定哪些边框像素被激活 → 激活位置成为射线源 → 射线向内延伸直到碰到轮廓本身或其他射线。轮廓同时提供计数信息和射线终止边界。

**输入结构**：约 13x13 的黑(0)背景网格。
- 网格中心附近（距边缘至少 3 行/列）有一个橙(7)单色 4-连通轮廓形状，像素数 3-6 个，边界框不超过 3x3。形状不限（可以是直线、L 形、T 形等各种小结构）。
- 网格最外圈（边框）的一个位置有一个蓝(1)单像素作为起始标记，位于四条边之一上。
- 网格其余位置（边框和内部）均为黑(0)。
- 生成约束：轮廓形状像素数 N 满足 3 <= N <= 6；网格边框周长能容纳至少 2 个激活位置（即 2N <= 边框周长）。

**规则**：
1. 统计橙(7)轮廓形状的像素数量 N。
2. 从蓝(1)起始标记出发，沿网格边框顺时针展开为环形序列。将起始标记位置重涂为橙(7)。
3. 从起始位置开始，沿环形序列每隔 N 个位置（即跳过 N-1 个黑色位置）放置一个橙(7)像素。若最后一段剩余位置不足 N 个则不放置。
4. 对每个被激活的边框像素（包括起始位置），向网格内部发射一条橙(7)射线：方向为该边框像素所在边的法线内向方向（上边框 → 向下，下边框 → 向上，左边框 → 向右，右边框 → 向左）。四角像素按顺时针展开顺序归属：属于其在环形序列中前一条边。
5. 射线逐像素延伸，遇到以下情况停止（不包含停止位置的像素）：碰到橙(7)轮廓形状的像素、碰到另一条已绘制的橙(7)射线像素、到达对面边框（不涂对面边框像素）。
6. 轮廓形状像素保持橙(7)不变。

**关键洞察**：中心轮廓形状既是被"保护"的内容，又是控制信号的来源——它的像素数编码了边框激活间距，同时它的物理位置阻挡了射线延伸。不同形状即使像素数相同，由于占据不同空间位置，会产生不同的射线终止图案。

## 新题 7：孤立令牌计数决定平铺密度与位置相关旋转

**组合逻辑**：[计数](保留) → [平铺](创新：平铺密度不再由输入边长决定，而由外部令牌计数决定) → [旋转](创新：旋转角度不再固定或由枢轴决定，而由瓦片在网格中的坐标位置编码) + [逐象限旋转排布](将象限级旋转推广为逐瓦片级旋转)

**依赖链**：令牌计数 N → 确定 NxN 平铺网格 → 每个瓦片位置 (i,j) 的旋转角度由 (i+j) mod 4 确定 → 相邻瓦片具有不同旋转。平铺密度和旋转规则两个维度同时由全局信息和局部位置决定。

**输入结构**：约 10x10 的黑(0)背景网格。
- 左上角区域包含一个正方形图案瓦片（3x3 或 4x4），至少使用 2 种非黑颜色，非旋转对称（即旋转 90 度后与原图不同，以便区分旋转状态）。瓦片的边界框左上角与网格左上角对齐或偏移 1 像素。
- 网格其余区域散布若干绿(3)孤立单像素（4-邻域内无其他非黑像素），数量 N 取值 2、3 或 4。
- 生成约束：瓦片为正方形且非旋转对称；绿色像素不与瓦片的 4-邻域接触。

**规则**：
1. 识别瓦片为最大的多像素 4-连通分量，裁剪到其边界框（边长 S）。
2. 统计绿(3)孤立单像素数量 N。
3. 生成 (S x N) 行 x (S x N) 列的输出网格。
4. 输出网格分为 NxN 个 SxS 的瓦片槽，行索引 i 从 0 到 N-1（从上到下），列索引 j 从 0 到 N-1（从左到右）。
5. 瓦片槽 (i, j) 中放置原始瓦片顺时针旋转 ((i + j) mod 4) x 90 度后的副本。即：(i+j) mod 4 = 0 → 不旋转，= 1 → 顺时针 90 度，= 2 → 180 度，= 3 → 顺时针 270 度。

**关键洞察**：(i+j) mod 4 旋转规则在输出中形成对角条纹状的旋转图案——同一条对角线上的瓦片旋转角度相同。求解者需要从多个示例中发现：(1) 绿色令牌数量决定平铺密度，(2) 瓦片位置的对角线坐标和决定旋转倍数，二者缺一不可。

## 新题 8：半轮廓重建后由标记框架选择排名填色区域

**输入结构**：约 16x16 的黑(0)背景网格。

- 生成约束：至少 2 个重建后的形状与蓝色标记定义的窗口区域有交集；各半轮廓重建后的填充形状互不重叠。

**规则**：
1. 对每个红(2)半轮廓：找到其最右列 C_r，以 C_r 右侧为对称轴水平镜像，重建完整对称形状。
2. 擦除所有红色轮廓像素。对每个重建形状，填充其内部行段为绿(3)（对每行，取该行重建轮廓的最内侧左右边界之间的像素）。

4. 检查每个绿色填充形状是否与选择窗口有交集（至少 1 个绿色像素落在窗口内）。
5. 对有交集的形状按面积（绿色像素数）从大到小排名。排名第 1 → 重涂为橙(7)，排名第 2 → 重涂为品红(6)，排名第 3 → 重涂为黄(4)。面积相同时，边界框左上角更靠左上的排名更前。
6. 无交集的形状保持绿(3)不变。蓝(1)标记像素保持不变。

**关键洞察**：蓝色标记像素定义的不是要绘制的框架，而是一个"视野窗口"——只有落入窗口的重建形状才参与排名竞争。移动标记像素可能改变哪些形状被选中，从而完全改变颜色分配。

## 新题 10：模板框架色传递后射线切割保留匹配区域

**组合逻辑**：[尺寸匹配+框架色传递](保留模板匹配和色传递的核心逻辑) → [切割+射线分割](创新：射线不再切割精灵体，而是切割整个网格，包括已完成色传递的框架) → [边界归属决定保留](保留：仅保留控制像素所在边界分区的内容)

**来源原语**：尺寸匹配(890034e9), 框架色传递同形(890034e9), 空心矩形(890034e9/928ad970), 模板(890034e9), 包含(890034e9), 切割(4a21e3da), 射线分割区域(4a21e3da), 控制像素(4a21e3da), 边界归属决定保留(4a21e3da), 裁剪(crop)

**依赖链**：源框架识别 → 尺寸匹配找到隐藏框架 → 色传递完成所有框架涂色 → 控制像素射线分割网格 → 边界归属筛选 → 仅保留归属区域中的框架（包括新涂色的）。色传递和射线切割是两个独立过程，但它们的结果在最终筛选步骤中交汇。

先按模板框架的尺寸和颜色补全网格中隐藏的同形框架，再从边缘控制像素发射射线切割网格，仅保留控制像素所在分区的内容。

**输入结构**：约 16x16 的黑(0)背景网格。
- 一个完整的单色空心矩形框架（绿(3)，外边长约 4x4 至 6x6，内部为黑(0)）作为源模板。
- 1-2 个与源模板外边长相同的"隐藏"矩形区域：内部同样为黑(0)，但边框颜色与背景相同（黑(0)），因此在输入中不可见。这些隐藏框架的位置与源框架不重叠。
- 1-2 个红(2)控制像素位于网格最外圈边缘（四条边之一上），不在角落。
- 生成约束：源框架和隐藏框架互不重叠、不接触；控制像素的射线至少切割一个隐藏框架区域的所在分区；至少一个已补色的框架落在控制像素的归属分区内。

**规则**：
1. 识别源框架：找到唯一完整的单色非黑空心矩形（绿(3)），记录其颜色 C_src、外边长 (H, W)、内部空色（黑(0)）。
2. 扫描网格中所有与源框架外边长相同的矩形区域，检查其内部是否全为黑(0)。对这些"隐藏"区域的边框涂上 C_src（绿(3)），完成色传递。
3. 对每个红(2)控制像素，从其位置沿所在边的法线方向（向网格内部）发射一条灰(5)射线，穿过黑色像素直至到达对面边缘。射线遇到非黑非控制色像素时不停止，直接覆盖涂灰。
4. 灰色射线将网格分为若干分区。确定每个控制像素所在的边缘侧（上/下/左/右），该控制像素"归属"射线同侧的分区。
5. 保留归属分区内的所有像素（包括源框架和新涂色的框架）。非归属分区的所有像素清为黑(0)。灰色射线像素保持灰(5)。红色控制像素保持红(2)。
6. 输出完整网格（不裁剪）。

**关键洞察**：隐藏框架在色传递前不可见——求解者必须先通过源框架推断模板尺寸，再扫描全图找到匹配区域。但色传递后，射线切割可能将某些新涂色的框架划入"丢弃"分区。因此最终保留哪些框架取决于色传递和射线切割的联合结果。
