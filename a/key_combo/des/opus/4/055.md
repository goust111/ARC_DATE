## 新题 1：凹弯数筛选与排序重排

**组合逻辑**：[环路追踪](已有) → [分类涂色 → 计数](创新：从"上色"改为"计数凹弯数") → [条件筛选](创新：凹弯数 > 0 作为选择门控) → [排序](已有) → [裁剪 + 压缩重排](已有)

**来源原语**：环路追踪、分类涂色、弯折像素(15663ba9)；排序、压缩重排、面积递增排列(8abad3cf)；裁剪(358ba94e)；少数转向为凹(15663ba9)

**依赖链**：环路追踪产出每个环的弯折分类 → 凹弯计数将拓扑属性转化为标量 → 该标量同时充当筛选门控（是否保留）和排序键（在输出中的位置） → 被选中的环路内部精灵体按此标量排列重排。删除任何一步均无法确定输出。

将多条闭合正交环路中内含的精灵体，依据环路凹弯数量进行筛选和排序后，裁剪重排到输出画布上。

**输入结构**：约 20x20 网格，黑(0)背景。网格上有 4-6 条灰(5)闭合正交环路，每条环路由 1 像素宽的 4-连通前景像素构成，所有前景像素度数为 2。每条环路内部恰好包含一个小型单色精灵体（3-7 像素，4-连通，颜色各不相同，均非黑(0)非灰(5)，如蓝(1)、红(2)、绿(3)、黄(4)、橙(7)等）。环路之间互不接触、互不嵌套。生成约束：至少 2 条环路为简单凸正交多边形（0 个凹弯），至少 2 条环路具有 1 个以上凹弯，且各有凹弯的环路凹弯数互不相同。

**规则**：
1. 对每条灰(5)闭合环路执行环路追踪，在每个前景像素处判断转向方向，将其分类为凸弯（多数转向方向）或凹弯（少数转向方向）。直行像素不计入弯折。
2. 统计每条环路的凹弯数量。
3. 筛选：仅保留凹弯数 > 0 的环路（即具有凹面的环路）。凹弯数为 0 的简单凸环路及其内部精灵体从输出中排除。
4. 对保留的环路，按凹弯数升序排列。
5. 裁剪每个被保留环路内部精灵体到其最小边界框（不含灰色环路像素）。
6. 在一个新的最小尺寸输出画布上，将裁剪后的精灵体从左到右依排序顺序放置，底部对齐，相邻精灵体之间间隔 1 列黑(0)背景。
7. 输出画布的高度等于所有被选精灵体中最大边界框高度，宽度等于所有精灵体宽度之和加间隔列数。

**关键洞察**：环路的拓扑凹凸性同时担任两个角色——门控（是否入选）和排序键（输出位置），二者来自同一次环路追踪但在不同逻辑层面起作用；仅看单个示例无法区分"按凹弯数排序"与"按环路面积排序"等替代假设。

## 新题 2：枢轴旋转产生锚点对齐射线

**组合逻辑**：[旋转(围绕枢轴)](已有) → [行列对齐检测](创新：对旋转后的新位置执行对齐检测) → [射线延伸](已有，但作用对象从原始标记变为旋转产物)

**来源原语**：旋转、枢轴像素、源像素、距离保持不变、同行或同列(1a244afd)；射线延伸、锚定方块、行列对齐、对齐标记连向锚点(d43fd935)；擦除(184a9768)

**依赖链**：枢轴旋转改变源像素的空间坐标 → 旋转后的坐标是否与锚点行列对齐是不确定的（取决于旋转前的具体位置） → 仅对齐的旋转产物触发射线延伸 → 射线方向和长度由旋转后位置与锚点的相对关系决定。旋转既是变换又是对齐条件的制造者。

将品红源像素围绕蓝色枢轴旋转 90 度，旋转后与锚定方块行列对齐的新像素向锚点延伸橙色射线。

**输入结构**：约 15x15 网格，黑(0)背景。包含一个 2x2 绿(3)锚定方块，位于网格中部偏某方向。散布若干蓝(1)枢轴像素和品红(6)源像素，每个品红像素与恰好一个蓝像素共享同一行或同一列（不与其他蓝像素共行共列），形成唯一配对。品红像素与其配对蓝像素之间无其他前景像素遮挡。生成约束：旋转后至少 1 个新位置与锚定方块行列对齐，至少 1 个不对齐；所有旋转后的目标位置均在网格内；旋转后位置与锚点之间的路径上无其他前景像素阻挡。

**规则**：
1. 配对：每个品红(6)像素与其同行或同列的唯一蓝(1)像素配对。
2. 旋转：以蓝像素为圆心，将品红像素逆时针旋转 90 度。保持曼哈顿距离不变。在旋转目标位置绘制橙(7)像素。擦除原品红像素。
3. 对齐检测：对每个新生成的橙(7)像素，检查它是否与绿(3)锚定方块的边界框共享至少一行或一列。
4. 射线延伸：对每个与锚点对齐的橙像素，沿其对齐方向（所在行或列）绘制橙(7)射线，从该像素向锚点方向逐像素延伸，直到碰到锚定方块边界外侧的相邻格子为止（不覆盖锚点本身）。
5. 不对齐的橙像素保留为单个像素，不延伸。
6. 蓝(1)枢轴和绿(3)锚定方块保持不变。

**关键洞察**：旋转并非最终变换，而是制造射线延伸的前提条件——只有旋转恰好将源像素送入锚点的行或列时，射线才会出现；需要对比多个示例才能发现"逆时针 90 度"而非其他旋转角度。

## 新题 3：空洞拓扑决定差异化平移规则

**组合逻辑**：[拓扑检测(有无空洞)](已有) → [条件分支：空洞 → 重涂色 + 按自身宽度平移 / 无空洞 → 保持颜色 + 固定平移](创新：拓扑属性同时决定颜色变换和位移量两个独立参数)

**来源原语**：重涂色、连通分量、封闭区域、有空洞则重涂(810b9b61)；平移、边界框决定偏移、按自身宽度平移(64a7c07e)

**依赖链**：拓扑检测（空洞与否）在决策图中分出两条路径，每条路径同时确定颜色和位移两个参数 → 空洞对象的位移依赖其自身边界框宽度（局部属性），非空洞对象的位移固定为 1 → 这使得不同对象的输出位置无法用统一公式计算，必须逐对象先判断拓扑再选规则。

根据每个蓝色对象是否包含内部空洞，选择不同的颜色和平移距离：空洞对象变绿并右移自身宽度，实心对象保持蓝色并右移 1 格。

**输入结构**：约 18x18 网格，黑(0)背景。包含 4-6 个蓝(1)单色 4-连通前景对象，形状各异（有的是封闭环形结构围住背景像素，有的是实心不规则块状，像素数约 5-15）。对象之间互不接触。每个对象右侧有足够空间容纳其最大可能平移（边界框宽度）。生成约束：至少 2 个对象有内部空洞（4-连通背景区域被该对象完全包围），至少 2 个对象无空洞；不同空洞对象的边界框宽度互不相同；平移后对象之间不重叠。

**规则**：
1. 找到所有蓝(1) 4-连通前景对象。
2. 对每个对象，检测它是否包含封闭的背景空洞：即是否存在黑(0)的 4-连通区域被该对象的像素完全包围（不与网格边界的背景连通）。
3. 空洞对象：将其所有像素重涂为绿(3)，然后整体向右平移其边界框宽度（列数）个格子。
4. 无空洞对象：保持蓝(1)不变，整体向右平移 1 格。
5. 清除所有对象的原始位置像素（先擦后画，避免自覆盖）。
6. 超出网格右边界的像素直接丢弃（裁剪到网格内）。

**关键洞察**：拓扑属性（有无空洞）不仅决定颜色变化，还决定了位移规则的类别（按宽度平移 vs 固定平移 1），两个效果从同一个判断节点分叉；仅看单个示例可能误以为所有对象统一右移某固定量。

## 新题 4：异常象限接受模板定位重涂

**组合逻辑**：[相等比较 → 异常值选择](已有) → [模板匹配(二面体搜索)](已有，但作用目标从全图变为异常象限) → [重涂色](已有) → [裁剪](已有)

**来源原语**：象限、分隔十字、相等比较、异常值选择、输出唯一象限(88a62173)；模板匹配、二值图案、二面体变换、唯一匹配(269e22fb)；重涂色(810b9b61)；裁剪(358ba94e)

**依赖链**：四象限比较确定异常值 → 异常象限成为模板匹配的搜索空间（搜索范围被前一步缩小） → 模板匹配在 8 种二面体变换中找到唯一对齐位置 → 对齐位置确定重涂区域 → 裁剪输出修改后的象限。每一步的输出都缩小了下一步的可能性空间。

在四象限分割的网格中找到异常象限，用分隔十字上的模板在异常象限内定位匹配区域并重涂该区域，输出修改后的异常象限。

**输入结构**：约 13x13（奇数行列）网格。中间行和中间列为灰(5)分隔十字，将网格分成四个大小相同的矩形象限（如每个 6x6）。四个象限中三个包含完全相同的红(2)前景图案（在黑(0)背景上），第四个象限包含不同的红(2)前景图案（异常值）。在灰(5)分隔十字的交叉区域附近（如十字的某段上），嵌入一个 2x2 或 2x3 的黄(4)二值模板图案。生成约束：模板图案在异常象限中经某种二面体变换后存在且仅存在一个匹配位置（模板的前景像素恰好覆盖异常象限中一组红色像素的子集）；三个相同象限中不存在该模板的任何二面体变换匹配。

**规则**：
1. 提取四个象限区域（不含分隔十字）。逐对比较四个象限的完整像素矩阵。三个相同的为多数派，一个不同的为异常象限。
2. 从分隔十字上提取黄(4)模板图案，裁剪到其最小边界框。
3. 在异常象限内搜索模板匹配：尝试模板的全部 8 种二面体变换（4 次旋转 x 2 次镜像），在象限内逐像素滑动窗口，找到模板前景像素与象限中红(2)像素完全重合的唯一位置和变换。
4. 将匹配位置处对应的红(2)像素重涂为黄(4)。象限内其余像素不变。
5. 输出仅包含修改后的异常象限（裁剪为象限大小）。

**关键洞察**：模板仅在异常象限内有匹配（在多数象限中无匹配），这意味着异常象限的"异常"之处恰恰包含了模板能对齐的局部结构；需要对比多个示例才能确定重涂目标色为黄(4)而非其他颜色。

## 新题 5：像素计数配对与边框完整性决定填充模式

**组合逻辑**：[计数(框内面积) + 计数(标记数量)](已有) → [相等比较 → 配对](创新：将两种不同计数结果做匹配) → [边框完整性检测](创新：框的拓扑属性决定操作的具体形式) → [条件填充(实心 / 棋盘格)](创新：同一操作的两种模式由拓扑条件切换)

**来源原语**：计数、空心矩形、棋盘格图案、像素数匹配格数(df8cc377)；填充(00dbd492)；有空洞则重涂(810b9b61) → 创新为边框完整性检测；擦除(184a9768)

**依赖链**：框内面积计数与标记计数的相等关系建立颜色配对 → 框的边框是否完整决定填充模式（实心或棋盘格） → 配对和模式共同确定每个框的最终外观。计数提供"哪个颜色填哪个框"，拓扑提供"用什么方式填"。

统计散布标记数量与框内面积做匹配，按匹配颜色填充对应框，边框完整的框做实心填充，有缺口的框做棋盘格填充。

**输入结构**：约 15x15 网格，黑(0)背景。包含 2-4 个灰(5)空心矩形框，一像素宽边框，框的大小不同（内部面积互不相同）。部分框的边框是完整的（四条边无缺失像素），部分框的边框有 1-3 个缺口（边上缺失像素，但缺口不影响内部面积的定义——内部面积仍按边界框内部计算）。框之间互不接触、互不嵌套。网格上另散布有单独的标记像素，每种标记颜色（非黑(0)非灰(5)，如蓝(1)、红(2)、绿(3)、黄(4)等）的总数各不相同，且每种颜色的标记总数恰好等于某一个框的内部面积（内部行数 x 内部列数）。标记像素不在任何框的内部或边框上。生成约束：每个框恰好匹配一种标记颜色（一一对应）；至少 1 个框边框完整，至少 1 个框有缺口。

**规则**：
1. 对每个灰(5)框，计算其内部面积：边界框内部的行数乘以列数（不含边框像素本身）。
2. 对每种标记颜色，统计该颜色在网格上的标记像素总数。
3. 将每种标记颜色与内部面积等于该颜色标记数量的框配对。
4. 对每个配对的框，检查其灰(5)边框是否完整（边界框的四条边上是否全部为灰色像素，无缺失）。
5. 边框完整的框：将其全部内部像素用配对颜色实心填充。
6. 边框有缺口的框：将其内部像素用配对颜色做棋盘格填充——从内部左上角格子开始上色，按行列奇偶性交替填色与留黑（内部坐标 (r, c) 满足 (r+c) 为偶数的格子填色，奇数的留黑(0)）。
7. 擦除所有标记像素。框的灰(5)边框保持不变（含缺口的仍有缺口）。

**关键洞察**：同一种填充操作在不同条件下表现为两种模式（实心与棋盘格），而模式的切换由框本身的拓扑属性（边框是否完整）决定，而非由所配对的颜色或其他外部标记决定；需对比多个示例才能排除"按框大小决定模式"等替代假设。

## 新题 6：稠密化揭示空洞拓扑以筛选并排入框架

**组合逻辑**：[稠密化/加厚](已有) → [拓扑检测(空洞)](创新：稠密化后才显现的拓扑属性用于筛选) → [计数(空洞面积)](已有) → [排序](已有) → [填入框架(等距排列)](已有)

**来源原语**：稠密化、加厚、稀疏边框、稀疏精灵体、等距排列入框、位置顺序(db615bd4)；封闭区域、有空洞则重涂、含孔洞者选中(810b9b61/b9b7f026)；计数(df8cc377)；排序、面积递增排列(8abad3cf)

**依赖链**：稠密化改变精灵体的几何形态（填充稀疏间隙） → 稠密化后某些精灵体形成了闭合边界、包围住背景像素（原本稀疏状态下无法判断闭合性） → 空洞检测筛选出拓扑上有空洞的精灵体 → 空洞面积提供排序键 → 排序结果决定框内放置顺序。稠密化是后续所有逻辑的前提：不稠密化，就无法判断闭合性。

将稀疏精灵体稠密化后，筛选出形成封闭空洞的精灵体，按空洞面积排序后等距放入稠密化的框架中。

**输入结构**：约 20x20 网格，黑(0)背景。网格上有灰(5)的规则二步点阵（偶数行偶数列的位置有灰点，纯装饰性）。一个大型稀疏矩形边框由红(2)像素构成，像素位于二步点阵位置上（即每隔一格出现一个红像素），形成矩形轮廓。边框外部散布 3-5 个稀疏单色精灵体，每个精灵体的颜色互不相同（如蓝(1)、绿(3)、黄(4)、橙(7)等），其像素也均位于二步点阵位置上，每个精灵体 4-8 个稀疏像素。生成约束：稠密化后（见下规则），至少 2 个精灵体形成封闭边界（包围住 1 个以上的背景像素），至少 1 个不形成封闭边界；形成封闭边界的精灵体各自空洞面积（封闭的背景像素数）互不相同；稠密化后的精灵体均能容纳在稠密化后的框架内部。

**规则**：
1. 稠密化红(2)框架：每对在同一行或同一列上相邻的红色点阵像素（水平或垂直距离为 2），填充它们之间的中间格子为红(2)。结果为一个实心一像素宽红色矩形边框。
2. 稠密化每个精灵体：同样地，每对在同一行或同一列上相邻的同色点阵像素（距离为 2），填充中间格子为该精灵体的颜色。
3. 对每个稠密化后的精灵体，检测其是否包含封闭背景空洞：是否存在黑(0)的 4-连通区域被该精灵体像素完全包围（不与外部背景连通）。
4. 筛选：仅保留具有封闭背景空洞的精灵体。丢弃无空洞的精灵体。
5. 对保留的精灵体，计算其封闭空洞的总面积（被包围的背景像素总数）。
6. 按空洞面积升序排列精灵体。
7. 清除框架内部和所有精灵体原始位置的像素（含点阵灰点）。绘制稠密化后的红色边框。
8. 将排序后的稠密化精灵体按顺序放入框架内部。判断框架的长轴方向：若框架宽度 > 高度，沿水平方向从左到右放置；若高度 >= 宽度，沿垂直方向从上到下放置。精灵体之间等距分布（首尾精灵体与边框内壁之间以及相邻精灵体之间的间距相等，按长轴方向计算间距）。
9. 精灵体在框内沿短轴方向居中放置。

**关键洞察**：稀疏状态下所有精灵体看起来都只是散落的点，无法判断闭合性；稠密化是一个拓扑属性的"显影剂"——它将隐藏在点阵间距中的封闭结构实体化，之后才能进行空洞检测和面积比较。

## 新题 7：宽度自适应平移产生涌现性封闭区域

**组合逻辑**：[按自身宽度平移](已有) → [涌现性封闭检测](创新：平移后多个独立对象的相对位置可能围成封闭区域——这在平移前不存在) → [填充](已有，但目标区域由涌现产生)

**来源原语**：平移、连通分量、边界框决定偏移、按自身宽度平移(64a7c07e)；封闭区域、有空洞则重涂(810b9b61)；填充(00dbd492)

**依赖链**：每个对象按自身宽度右移 → 不同宽度的对象移动距离不同 → 平移后对象之间的相对位置发生非均匀变化 → 某些对象恰好首尾相接形成封闭边界 → 封闭区域在平移前不存在，是组合的涌现结果 → 涌现区域触发填充。单独的平移操作和单独的封闭检测各自没有意义；它们必须组合才产生非平凡结果。

将每个前景对象右移自身边界框宽度后，检测平移后新形成的封闭区域并用灰色填充。

**输入结构**：约 16x16 网格，黑(0)背景。包含 3-5 个不同颜色的 8-连通前景对象（如蓝(1)、红(2)、绿(3)、黄(4)等），每个对象 4-12 像素，形状各异（有 L 形、长条形、块状等结构特征，但用像素连通性和边界框尺寸描述而非固定名称）。对象之间互不接触。每个对象右侧有足够空间容纳其按宽度平移。生成约束：平移后恰好有一组对象（2 个或更多）的像素在 8-连通意义下共同形成一个或多个封闭边界（围住至少 1 个背景像素），而其余对象不参与任何封闭；平移前没有任何封闭区域存在。

**规则**：
1. 找到所有 8-连通前景对象，计算每个的边界框宽度。
2. 将每个对象整体向右平移其边界框宽度个列。擦除原位置像素，在新位置绘制。
3. 平移后，将所有前景像素（所有颜色）视为一个整体，检测它们是否共同围成了封闭的背景区域：即是否存在黑(0)的 4-连通区域，该区域被前景像素（8-连通边界）完全包围，不与网格边缘的背景连通。
4. 将所有此类被封闭的背景像素填充为灰(5)。
5. 所有前景对象保持其平移后的颜色和位置不变。未被封闭的背景区域保持黑(0)。

**关键洞察**：封闭区域在输入中并不存在——它是不同对象以各自不同的距离平移后，在新位置上碰巧拼合产生的涌现结构；求解者必须先完成全部平移，才能判断哪些区域被封闭。

## 新题 8：嵌套深度决定重涂色，外层面积决定重排序

**组合逻辑**：[包含关系分析 → 计数(嵌套深度)](创新：包含关系的传递闭包产生深度标量) → [按深度映射颜色](已有原语的创新用法：边长映射颜色变为深度映射颜色) → [裁剪](已有) → [按外层面积排序 → 压缩重排](已有)

**来源原语**：包含、封闭区域(810b9b61/b9b7f026)；按边长映射颜色(00dbd492) → 创新为按嵌套深度映射颜色；裁剪(b9b7f026)；排序、压缩重排、面积递增排列(8abad3cf)；计数(df8cc377)

**依赖链**：包含关系的传递分析产出每组的嵌套深度 → 深度决定最内层精灵体的重涂颜色 → 重涂颜色是输出的一部分 → 同时，最外层框的面积（与深度无关的另一属性）决定排列顺序 → 两条信息从同一嵌套结构的不同层面提取，汇合到输出中。

分析嵌套矩形框组的深度决定内部精灵体的颜色，按最外层框的面积排序后重排输出。

**输入结构**：约 20x20 网格，黑(0)背景。包含 3-4 组嵌套结构，每组由 1-3 个同色灰(5)空心矩形框构成（一像素宽边框），从外到内严格嵌套（内框完全在外框内部，框之间不共享像素）。每组最内层框的内部包含一个小型白(0以外颜色)精灵体（3-6 像素，4-连通），各组精灵体的原始颜色相同（均为栗(9)）。不同组的嵌套深度（框的层数）可以不同（1 层、2 层或 3 层）。各组之间互不接触。生成约束：各组的嵌套深度互不全相同（至少两种不同深度）；各组最外层框的边界框面积（宽 x 高）互不相同。

**规则**：
1. 识别所有灰(5)空心矩形框，根据包含关系将它们分组（被同一个最外层框包含的框归为一组）。
2. 对每组，计算嵌套深度 = 该组中框的数量（即最内层精灵体被多少层框包围）。
3. 按嵌套深度将最内层精灵体重涂色：深度 1（仅一层框包围）→ 青(8)；深度 2 → 黄(4)；深度 3 → 绿(3)。
4. 裁剪每个重涂后的精灵体到其最小边界框（不包含任何灰色框像素）。
5. 计算每组最外层框的边界框面积（像素宽度 x 像素高度，含边框）。
6. 按最外层框面积升序排列裁剪后的精灵体。
7. 在最小尺寸输出画布上，将精灵体从左到右按排序顺序放置，底部对齐，相邻精灵体间隔 1 列黑(0)背景。

**关键洞察**：嵌套深度和最外层面积是从同一个嵌套结构中提取的两种不同度量——深度决定颜色（语义属性），面积决定位置（空间属性），二者互相独立但都依赖于对嵌套包含关系的正确解析；仅看一个示例无法区分"按深度排序"与"按面积排序"。

## 新题 9：射线分割产生区域，精灵体形状匹配精确拼合

**组合逻辑**：[射线延伸](已有) → [区域分割(涌现)](创新：射线与锚点共同划分出输入中不存在的矩形区域) → [精灵体形状匹配 → 拼合填充](已有原语的创新组合：精灵体不是填入预有孔洞，而是填入射线产生的新区域)

**来源原语**：射线延伸、锚定方块、标记像素、行列对齐、对齐标记连向锚点(d43fd935)；拼合填充、源精灵体、精灵填入孔洞、精灵精确拼合孔洞(184a9768)；计数(df8cc377)；擦除(184a9768)

**依赖链**：标记到锚点的射线延伸在空间中画出分割线 → 分割线与锚点和网格边界共同围成矩形区域（这些区域在输入中不存在） → 每个区域的形状和面积成为精灵体匹配的目标 → 精灵体必须恰好无旋转无翻转地平铺满区域 → 匹配结果决定哪个精灵体放入哪个区域。射线创造了容器，精灵体选择容器。

用锚点对齐的标记像素延伸射线分割画布，然后将散布的精灵体按形状精确拼合到射线围成的各个区域中。

**输入结构**：约 18x18 网格，黑(0)背景。网格中部偏位置有一个 3x3 灰(5)锚定方块。散布若干灰(5)标记像素，部分与锚定方块共享行或列（行列对齐），部分不对齐。另有 2-3 个小型单色精灵体（各 3-8 像素，4-连通，颜色各不相同，如蓝(1)、红(2)、绿(3)等），位于远离锚点的区域。生成约束：对齐的标记像素分布在锚点的不同方向（至少有来自两个方向的射线）；射线延伸后与锚点和网格边界共同围出的矩形区域数量等于精灵体数量；每个精灵体恰好可以通过纯平移（不旋转不翻转）重复铺满恰好一个区域（精灵体面积整除区域面积，且形状可无间隙无重叠地铺满该矩形）；每个精灵体与区域的配对是唯一的。

**规则**：
1. 识别所有与锚定方块行列对齐的灰(5)标记像素（与锚定方块的边界框共享至少一行或一列）。
2. 从每个对齐标记沿其对齐方向（同行则水平、同列则垂直）向锚定方块延伸灰(5)射线，直到碰到锚定方块边界外侧相邻格子。射线像素绘制为灰(5)。
3. 不对齐的标记像素直接擦除。
4. 射线、锚定方块、网格边界共同将背景划分为若干矩形区域。识别所有完全由灰(5)像素和/或网格边界围成的矩形背景区域（不含灰色像素本身，仅统计区域内的黑色背景格子）。
5. 对每个精灵体，检查它能否通过纯平移重复铺满某个矩形区域（精灵体的边界框尺寸必须整除区域尺寸，且铺满后无间隙无重叠）。将每个精灵体与它能唯一铺满的区域配对。
6. 将每个精灵体按平铺方式填入其配对区域：从区域左上角开始，逐行逐列重复精灵体图案。
7. 擦除精灵体原始位置的像素和所有原始标记像素。灰(5)射线和锚定方块保留。

**关键洞察**：待填充的区域在输入中并不存在——它们是射线延伸这一几何操作的副产物；精灵体与区域的配对不靠颜色或位置，而靠几何形状的铺满兼容性，这需要同时理解区域形状和精灵体形状。

## 新题 10：行列标记交叉约束同时决定格内颜色

**组合逻辑**：[行列对齐(双向)](创新：行标记和列标记同时对同一格子施加约束) → [相等比较(颜色一致性)](已有) → [计数(全局颜色频率)](创新：频率统计作为冲突解决依据) → [填充](已有)

**来源原语**：行列对齐(d43fd935)；标记像素(d43fd935/df8cc377)；相等比较(88a62173)；计数(df8cc377)；填充(00dbd492)；空心矩形(00dbd492)

**依赖链**：这不是线性流水线，而是约束满足结构——每个输出格子同时受到行标记和列标记两个约束的约束 → 当两个约束一致时直接确定颜色 → 不一致时需要全局频率统计作为仲裁依据 → 频率统计依赖于所有标记的整体分布。每个格子的最终值取决于局部（该行和该列的标记）和全局（所有标记的频率排名）两个层面的信息。

在空心矩形框内，每个内部格子的颜色由其所在行的行标记和所在列的列标记共同决定：一致则直接填色，不一致则填全局更高频的颜色。

**输入结构**：约 12x12 网格，黑(0)背景。包含一个灰(5)空心矩形框（一像素宽边框），内部为 NxM 的黑色区域（如 4x5）。沿网格顶部边缘（框的上方），在与框内部每一列对齐的位置各有一个彩色标记像素（列标记），共 M 个。沿网格左侧边缘（框的左方），在与框内部每一行对齐的位置各有一个彩色标记像素（行标记），共 N 个。标记颜色取自蓝(1)、红(2)、绿(3)、黄(4)中的 2-3 种。生成约束：至少有 2 个格子的行标记与列标记颜色相同，至少有 2 个格子颜色不同；所有标记中各颜色的出现次数（行标记 + 列标记合计）互不相同（无并列）。

**规则**：
1. 识别灰(5)框的内部区域。将内部区域划分为 NxM 个格子（每个格子一个像素）。
2. 对每个内部格子 (r, c)，找到其所在行的行标记颜色 R 和所在列的列标记颜色 C。
3. 如果 R = C，将该格子填充为颜色 R。
4. 如果 R =/= C，统计所有标记像素（行标记 + 列标记合计，共 N+M 个）中颜色 R 和颜色 C 各出现多少次。选择出现次数更多的颜色填充该格子。
5. 灰(5)边框保持不变。所有标记像素保持不变。

**关键洞察**：每个格子是两个一维约束的交汇点，不存在固定的执行顺序——不能先处理所有行再处理所有列，也不能逐行逐列独立填充；冲突解决规则依赖于标记的全局频率分布，而非局部优先级，需对比多个示例才能排除"行标记优先"或"列标记优先"等替代假设。
