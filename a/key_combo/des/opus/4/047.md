## 新题 1：轮廓填充驱动克罗内克自扩展

**组合逻辑**：[填充/逐行跨度填充](已有) + [克罗内克积/前景背景互换填充](已有，作用对象从显式二值图改为填充结果) → 填充结果即扩展掩码（创新耦合）

**来源原语**：填充/逐行跨度填充/行内边界配对（22168020），克罗内克积/二值掩码/前景背景互换填充（8e2edd66）

**依赖链**：稀疏轮廓本身不是合法的二值掩码——只有经过逐行跨度填充后才形成完整的实心形状，这个实心形状才定义了克罗内克积的掩码矩阵。反过来，克罗内克积的输出尺寸和图案完全由填充后的形状决定，跳过任一步都无法得到正确输出。

将稀疏轮廓填实后，用所得实心形状作为二值掩码进行克罗内克自积扩展，生成自相似分形图案。

**输入结构**：
- 网格约 5x5，背景为黑(0)。
- 网格中有一个单色前景轮廓（颜色为绿(3)），由稀疏像素构成。
- 该轮廓在其覆盖的每一行上恰好有两个前景像素，分别标记该行的左、右边界。
- 轮廓所围面积在 4~8 像素之间，不同示例中轮廓的具体形状不同（有的偏宽矮、有的偏窄高），但都满足每行两像素的配对条件。
- 生成约束：轮廓像素的行跨度至少为 2 行，列跨度至少为 2 列。

**规则**：
1. 对轮廓执行逐行跨度填充：在轮廓覆盖的每一行中，将左右边界像素之间（含边界）的所有像素涂为绿(3)，其余保持黑(0)。得到一个 5x5 的二值图（绿=前景，黑=背景）。
2. 以该二值图作为掩码，进行克罗内克自积扩展——输出尺寸为 (5x5) x (5x5) = 25x25：
   - 原二值图中的每个黑(0)像素替换为一个 5x5 子块，子块内容为二值图的前景/背景互换版（即黑→绿、绿→黑）。
   - 原二值图中的每个绿(3)像素替换为一个全黑(0) 5x5 子块。
3. 输出即为 25x25 的扩展结果。

**关键洞察**：轮廓的稀疏像素自身不是有效掩码——必须先通过行配对填充将其"实心化"，而填充结果的几何形状直接编码了分形扩展的结构；两步共享同一中间表示，无法独立求解。

## 新题 2：边缘匹配链序决定重力压缩顺序

**组合逻辑**：[排序/链式连接排序](已有，从平面排列改为决定处理优先级) + [滑动/碰撞停止](已有，从同色匹配墙改为按链序逐一压缩) → 链序即压缩序（创新耦合）

**来源原语**：排序/边缘像素匹配/链式连接排序/精灵体（78332cb0），滑动/碰撞停止/墙壁列（f0100645）

**依赖链**：精灵体的边缘像素决定链接顺序，链接顺序决定哪个精灵体先滑向墙壁占据靠墙位置，先到者成为后到者的障碍物。不同的链序产生不同的堆叠结果，因此排序和滑动不可分离。

根据精灵体边缘像素的链式匹配确定处理顺序，再按此顺序逐一将精灵体水平滑向墙壁，先到者成为后续障碍。

**输入结构**：
- 网格约 15x20，背景为黑(0)。
- 网格最左列整列填充为灰(5)，充当墙壁。
- 网格中散布 4~6 个大小相近的单色前景精灵体（均为蓝(1)），每个精灵体是一个 4-连通的不规则小图形（3~6 像素），彼此不相邻、不接触墙壁。
- 每个精灵体有一个明确的左边缘像素列和右边缘像素列。
- 生成约束：存在唯一的链式连接序列——从某个起始精灵体出发，每次恰好有唯一的下一个精灵体，其左边缘的前景像素行坐标集合与当前精灵体右边缘的前景像素行坐标集合有非空交集。所有精灵体恰好形成一条完整链（无分叉、无孤立）。

**规则**：
1. 对每个精灵体，提取其最左列和最右列中前景像素所在的行坐标集合，分别作为"左边缘"和"右边缘"。
2. 构建链式连接：找到链头（其左边缘不与任何其他精灵体的右边缘匹配的精灵体），然后反复将当前精灵体的右边缘与所有未链接精灵体的左边缘匹配（行坐标集合有交集），形成完整链序。
3. 按链序从先到后处理每个精灵体：将该精灵体整体水平向左滑动，直到其最左像素紧邻墙壁(灰(5)列)或紧邻已定位精灵体的最右像素列的下一列。精灵体保持原始形状和行位置不变，仅列坐标平移。
4. 清除每个精灵体的原始位置像素（置为黑(0)），在新位置绘制。

**关键洞察**：边缘匹配的链序不只是排列关系——它直接决定了墙边的堆叠层次；链头精灵体紧贴墙壁，后续精灵体依次紧贴前者，不同链序产生不同的水平压缩结果。

## 新题 3：镜像重塑负空间后按区域序周期填色

**组合逻辑**：[镜像/标记侧翻转](已有，从单纯复制改为拓扑重构手段) + [洪泛填充/等间隔采样填充](已有，从固定分隔改为依赖镜像后产生的新分区) → 镜像创造新区域 + 区域总数编码填充周期（创新耦合）

**来源原语**：镜像/标记像素/邻接（2bcee788），洪泛填充/区域排列顺序/等间隔采样填充（7447852a）

**依赖链**：原始输入中前景物体只有一侧，背景是一整块连通区域。镜像后，物体及其镜像共同将背景切分为多个不连通的区域。这些区域的数量和位置完全由镜像结果决定，而填充规则又依赖区域数量来确定周期。三者形成环形依赖：镜像→区域拓扑→填充周期→最终输出。

将前景物体沿标记像素指示的方向镜像，镜像后物体与原件共同将背景切分为若干封闭区域，按从左到右、从上到下的顺序对区域编号，每隔固定间距对区域填色。

**输入结构**：
- 网格约 15x15，背景为黑(0)。
- 一个 4-连通的单色前景物体（橙(7)，约 8~15 像素），形状不规则但保证从一侧到对侧的行或列跨度与网格尺寸接近（即物体较大，能有效分割空间）。
- 若干红(2)标记像素紧邻该物体的某一侧边缘（上/下/左/右之一），标记像素自身也构成一个 4-连通区域。
- 物体不接触网格边界。
- 生成约束：镜像后，原物体 + 镜像副本 + 网格边界共同将黑(0)背景分割为至少 3 个 4-连通区域。不同示例中标记方向不同，产生的区域数量也不同。

**规则**：
1. 识别红(2)标记像素所邻接的物体侧（上/下/左/右）。
2. 在物体边界框的该侧外一像素处设置镜像轴，将整个物体沿该轴反射。在反射位置绘制橙(7)镜像副本，同时清除红(2)标记像素（置为黑(0)）。
3. 将镜像后的网格中所有黑(0)区域进行 4-连通洪泛标记，识别出 N 个不连通的背景区域。
4. 按各区域边界框左上角坐标排序（先按行升序、同行按列升序），对区域编号 0, 1, 2, ...
5. 编号满足 i mod 3 == 0 的区域整体填充为黄(4)。其余区域保持黑(0)。
6. 橙(7)像素（原物体 + 镜像）保持不变。

**关键洞察**：红标记不只指示镜像方向——镜像改变了背景的连通拓扑，而填充目标是这些新产生的封闭区域；不执行镜像就无法确定区域划分，不划分区域就无法确定填色位置。

## 新题 4：空心矩形面积对决分配迷宫填充角色

**组合逻辑**：[计数/比较/最大内部面积胜出](已有，从直接输出颜色改为角色分配) + [洪泛填充/路径奇偶交替涂色](已有，从固定种子颜色改为由比较结果动态分配) → 几何比较决定填充语义（创新耦合）

**来源原语**：计数/比较/空心矩形/最大内部面积胜出（445eab21），洪泛填充/迷宫走廊/种子像素/路径奇偶交替涂色（b782dc8a）

**依赖链**：迷宫中有两个种子像素，各自被一个空心矩形包围。哪个种子的颜色在交替填充中"先手"，取决于包围它的矩形的内部面积大小。面积比较的结果不是直接输出，而是作为决策节点改变后续洪泛填充的颜色分配方案。

在青色迷宫中，两个种子各被一个空心矩形框住；框内面积较大者的颜色成为交替填充的起始色，从两个种子同时向走廊扩散。

**输入结构**：
- 网格约 15x15。
- 青(8)像素构成迷宫墙壁，形成若干黑(0)走廊。
- 迷宫中有两个非青、非黑的种子像素，颜色分别为蓝(1)和绿(3)，各占一个像素。
- 每个种子像素被一个同色的空心矩形框完全包围（框线一像素厚，框本身嵌在迷宫走廊中，框线颜色与种子相同）。两个空心矩形的内部面积（框内黑色像素数）不相等。
- 两个矩形框不重叠、不嵌套。
- 走廊将两个矩形框区域连通。
- 生成约束：两个种子各自可达的走廊区域有交叉——即存在走廊像素同时可被两个种子的扩散到达。不同示例中面积较大者的颜色不同。

**规则**：
1. 识别两个空心矩形框，计算各自内部面积（框线内部的黑(0)像素数量，不含框线本身）。
2. 面积较大的矩形框所对应的种子颜色记为 C_primary，面积较小的记为 C_secondary。
3. 从两个种子同时开始 BFS 洪泛扩散，扩散目标为黑(0)走廊像素（青(8)为墙壁不可通过，矩形框线不可通过）：
   - 每一步扩散中，距离为偶数步（含 0 步，即种子自身）的像素涂为 C_primary。
   - 距离为奇数步的像素涂为 C_secondary。
   - 当两个种子的扩散在同一像素相遇时，先到者占据该像素；同时到达时 C_primary 优先。
4. 空心矩形框线、青(8)迷宫墙壁保持不变。

**关键洞察**：空心矩形不参与走廊填充，但它们的内部面积差异决定了两种颜色在交替扩散中的主次角色——面积比较的结果不是最终答案，而是下游填充规则的参数。

## 新题 5：对角线计数同时参数化循环填充与错切变换

**组合逻辑**：[循环填充/同余类交错铺满](已有) + [错切/行偏移递变](已有) ← 共享参数 K（创新：两个独立操作由同一隐式参数耦合）

**来源原语**：循环填充/对角线/等距偏移/同余类交错铺满（05269061），错切/前景网格/行偏移递变/行内容保持（3cd86f4f）

**依赖链**：输入中不同颜色对角线的数量 K 同时是两个变换的参数：循环填充的重复周期为 K，错切的行偏移步长也为 K。K 不是显式给出的——必须从输入中计数得到。两个操作通过共享隐式参数 K 耦合，缺少任何一个操作都无法验证 K 的正确值。

数清输入中不同颜色对角线的条数 K，以 K 为周期循环填充网格，再以 K 为步长对填充结果进行错切。

**输入结构**：
- 网格为 N x N（N 在 6~9 之间），背景为黑(0)。
- 网格中有 K 条完整对角线（K 在 2~4 之间），每条对角线颜色不同，均为非黑色（从蓝(1)、红(2)、绿(3)、黄(4)中选取 K 种）。
- 所有对角线斜率方向相同（均为左上→右下或均为右上→左下）。
- 对角线之间的列偏移不一定等距，但每条对角线可明确归入 mod K 的一个同余类。
- 生成约束：K 条对角线恰好覆盖 K 个不同的 mod K 同余类，使得循环填充后每个同余类恰好对应一种颜色。

**规则**：
1. 统计输入中不同的非黑前景颜色数量，得到 K。
2. 循环填充：对于每条颜色为 c 的输入对角线，计算其所在的同余类 j（即该对角线上任一像素 (r, col) 满足 (col - r) mod K == j，对于左上→右下对角线；右上→左下类似）。然后，对所有满足 (col - r) mod K == j 的网格位置，绘制颜色 c 的像素。填充完成后得到 N x N 的交错彩色图案。
3. 错切变换：创建一个 N x (N + K - 1) 的黑(0)画布。将填充结果的第 r 行（r 从 0 开始）整行复制到画布的第 r 行、起始列为 (K - 1 - (r mod K)) 的位置。即每 K 行为一组，组内行偏移从 K-1 递减到 0。
4. 输出该错切后的画布。

**关键洞察**：对角线的数量 K 是一个隐式编码的参数，同时控制着填充的模周期和错切的偏移步长——两个看似独立的几何变换被同一个计数结果耦合在一起。

## 新题 6：黑洞检测重塑碎片补全路径

**组合逻辑**：[填充/全黑窗口换前景色](已有，从最终着色改为地形修改) + [移动/补全/互补拼合](已有，从自由平移改为受新地形约束的路径规划) → 填充改变可用空间，空间改变补全策略（创新耦合）

**来源原语**：填充/空白区域/全黑窗口换前景色（6cf79266），移动/补全/擦除/碎片/锚定物体/矩形/同色碎片拼成矩形/互补拼合/碎片触边锚不触边（fe45cba4）

**依赖链**：网格中的全黑 3x3 窗口一旦被填充为蓝(1)，就成为不可穿越的障碍物。碎片的补全目标位置可能恰好与某个黑洞填充位置重叠——此时碎片必须寻找另一个合法的互补拼合方位。填充结果实质性地改变了补全的搜索空间。

先将网格中的全黑 3x3 空洞填蓝，再将触边碎片平移到同色锚定物旁补全为矩形——但蓝色填充可能封堵补全路径，迫使碎片选择不同的拼合方位。

**输入结构**：
- 网格约 15x18，背景为黑(0)。
- 网格中散布多个非蓝的彩色噪声像素（品红(6)、橙(7)等各色杂点），覆盖约 15~25% 的网格面积。
- 嵌有 2~3 个完全由黑(0)组成的 3x3 正方形窗口（与周围噪声像素之间有明确边界）。
- 有一种特定前景色（红(2)）被分成恰好两个 4-连通物体：一个触及网格左边缘（碎片），一个不触及任何边缘（锚定物体）。两者的形状互补——存在唯一的平移方向（上/下/左/右之一），使碎片平移后与锚定物体的并集恰好构成一个实心的轴对齐矩形。
- 生成约束：至少一个 3x3 黑洞的位置与碎片的某个潜在补全位置（四个方向之一）重叠，使得该方向的补全在填充后不再合法。但始终存在至少一个方向的补全在填充后仍然合法（碎片目标区域不与任何蓝色填充位置冲突且全为黑(0)或红(2)像素）。

**规则**：
1. 扫描网格中所有 3x3 窗口，找到内容完全为黑(0)的窗口，将其填充为蓝(1)。如果多个 3x3 黑窗口有重叠，按从左到右、从上到下的顺序逐个填充。
2. 识别红(2)色的两个 4-连通物体：触及左边缘的为碎片，不触及任何边缘的为锚定物体。
3. 尝试四个基本平移方向（碎片向上/下/左/右平移），对每个方向计算碎片平移后的目标像素集合：
   - 目标位置的每个像素必须在网格内。
   - 目标位置的每个像素当前必须为黑(0)或已属于锚定物体（红(2)）——不能与蓝(1)填充区域、噪声像素或网格边界冲突。
   - 碎片平移后与锚定物体的并集必须恰好构成一个实心的轴对齐矩形。
4. 选择满足以上条件的唯一合法方向，将碎片从原位清除（置为黑(0)），在目标位置绘制红(2)。
5. 所有其他像素（蓝(1)填充、噪声、锚定物体）保持不变。

**关键洞察**：全黑窗口的填充不只是视觉标记——它创造了新的空间障碍，直接排除了碎片的某些补全方向，使得最终合法的拼合方位取决于黑洞的分布。

## 新题 7：包含层级重涂改变异常值身份

**组合逻辑**：[重涂色/最外层颜色继承](已有) + [提取/异常值选择](已有) ← 重涂改变模式等价性，等价性决定异常值身份（创新耦合：不是流水线，而是同时约束）

**来源原语**：重涂色/矩形边框/严格包含/最外层颜色继承（7d1f7ee8），提取/裁剪/网格单元/逐行比较/异常值选择（38007db0）

**依赖链**：网格中每个单元格包含嵌套矩形框。在重涂之前，两个单元格可能因为内层矩形颜色不同而看似不同；重涂后内层矩形继承了最外层颜色，反而可能变得相同。异常值的判定必须基于重涂后的模式，而非原始模式。这意味着：不做重涂就不知道哪些单元格"真正相同"，不做异常值判定就不知道提取哪个单元格。

在网格阵列的每个单元格内，先让内层矩形继承最外层矩形的颜色，再按行比较单元格的重涂后模式，提取每行中模式唯一的异常单元格。

**输入结构**：
- 网格约 20x20，由灰(5)网格线分割成 3 行 x 4 列的矩形单元格阵列，每个单元格约 5x4 像素（不含网格线）。
- 每个单元格内部背景为黑(0)，包含 1~2 层嵌套矩形边框（一像素厚）。最外层矩形框紧贴单元格边界内侧或略小，内层矩形框严格嵌套在外层内部。
- 矩形框的颜色各不相同，从蓝(1)、红(2)、绿(3)、黄(4)、品红(6)、橙(7)中选取。
- 同一行的 4 个单元格中：重涂前，各单元格外层矩形颜色相同但内层矩形颜色不全相同；重涂后，恰好有 3 个单元格的模式完全一致，1 个不同。
- 生成约束：每行中的异常单元格位于不同列。不同示例中异常单元格的分布模式不同。重涂前的异常值与重涂后的异常值不同——即存在至少一行，重涂前看起来独特的单元格在重涂后变得与多数一致，而另一个在重涂前与多数一致的单元格在重涂后反而变得独特。

**规则**：
1. 对每个单元格执行包含层级重涂：找到不被任何其他前景矩形严格包含的最外层矩形框，将其边界框内所有非黑像素重涂为该最外层矩形的颜色。保持黑(0)背景像素和最外层矩形框像素不变。
2. 重涂后，逐行比较同一行中 4 个单元格的像素模式（逐像素对比）。每行中恰好有一个模式独特的单元格（异常值）。
3. 提取每行的异常单元格，组成一列——输出为一个 3 行 x 1 列的单元格阵列（用灰(5)网格线分隔），每个单元格保持重涂后的模式。

**关键洞察**：包含层级重涂不是无关的预处理——它改变了单元格之间的等价关系。重涂前的"不同"可能在继承规则下变为"相同"，真正的异常值只有在重涂之后才能确定。

## 新题 8：瓦片色彩映射决定间隙填充资格

**组合逻辑**：[颜色映射/匹配对推导映射](已有) + [填充/无遮挡才填充](已有，选择条件从原始颜色改为映射后颜色) → 映射结果改变对象等价性，等价性决定哪些间隙被填充（创新耦合）

**来源原语**：颜色映射/瓦片/分隔行/带内三瓦片对齐/匹配对推导映射/应用于剩余瓦片（b0722778），填充/前景矩形/行列跨度重叠/间隙区域/无遮挡才填充（ef135b50）

**依赖链**：间隙填充的条件是"两个矩形颜色一致"，但此处"一致"是指经过色彩映射后的颜色相同，而非原始颜色相同。色彩映射从瓦片区学习得到。两个原始颜色不同的矩形可能在映射后变为同色，从而触发间隙填充；反之，原始同色的矩形可能映射为不同颜色而不触发填充。

从瓦片示例对中学习颜色替换映射，将映射应用于矩形区的前景色；映射后颜色一致且水平间无遮挡的矩形对之间填充栗色桥梁。

**输入结构**：
- 网格约 20x15，背景为黑(0)。
- 网格上部（约前 5 行）为瓦片区：一行灰(5)分隔行将瓦片区与下方矩形区隔开。瓦片区包含恰好三个等大的小瓦片（约 3x3），水平排列，瓦片间由黑(0)间隔。三个瓦片中恰好有两个具有相同的像素模式（颜色可不同但模式同构），第三个模式不同。
- 网格下部（灰(5)分隔行以下）为矩形区：包含 3~5 个 4-连通单色实心矩形，颜色各异，从蓝(1)、红(2)、绿(3)、黄(4)、品红(6)、橙(7)中选取。矩形之间水平分离但行跨度可能重叠。
- 生成约束：色彩映射是一个颜色到颜色的双射（在涉及的颜色子集内）。映射后至少有一对原始不同色的矩形变为同色，且该对满足无遮挡条件。同时至少有一对原始同色或映射后同色的矩形之间存在第三个矩形的遮挡，不应被填充。

**规则**：
1. 在瓦片区中找到模式同构的两个瓦片（排除背景色后，像素模式在颜色重命名下一致）。确定从源瓦片到目标瓦片的有序颜色映射 M（如红→蓝、绿→黄等）。
2. 将映射 M 应用于矩形区每个矩形的颜色，得到每个矩形的"映射后颜色"。矩形区的实际像素暂不修改。
3. 对于矩形区中每一对矩形 (A, B)，如果满足以下所有条件则在它们之间填充栗(9)：
   - A 和 B 的映射后颜色相同。
   - A 和 B 的列跨度不重叠（水平分离）。
   - A 和 B 的行跨度有重叠。
   - 在 A 与 B 的水平间隙中，没有第三个矩形的边界框同时横跨该水平间隙且与 A、B 的共享行跨度重叠。
4. 对于满足条件的矩形对，将它们共享行跨度内、两者列跨度之间的所有黑(0)像素填充为栗(9)。
5. 瓦片区、灰(5)分隔行、矩形本身的像素均保持不变（矩形不被重涂为映射后颜色——映射仅用于判断填充资格）。

**关键洞察**：颜色映射不改变矩形的可见颜色——它只改变矩形之间的"等价关系"，从而改变哪些间隙应被桥接；不学习映射就无法确定正确的填充目标。

## 新题 9：重力压缩封闭区域后洪泛着色

**组合逻辑**：[滑动/碰撞停止/同色物体朝同色墙](已有，从视觉整理改为拓扑构建手段) + [洪泛填充/路径连通](已有，从现有区域改为压缩后涌现的区域) → 滑动改变拓扑 + 新拓扑定义填充目标（创新耦合）

**来源原语**：滑动/墙壁列/前景物体/同色物体朝同色墙/近者优先不重叠/碰撞停止（f0100645），洪泛填充/封闭区域/路径连通（7447852a, b782dc8a）

**依赖链**：散布的前景物体在滑动前不形成任何封闭区域；滑动压缩后，物体紧密排列在墙边，与墙壁和网格边界共同围出若干封闭的背景区域。这些区域是滑动的涌现产物——不存在于原始输入中。洪泛填充只作用于这些涌现区域。

将两组彩色物体分别滑向各自的同色墙壁，压缩后物体与墙壁围成的封闭背景区域用黄色洪泛填充。

**输入结构**：
- 网格约 12x18，背景为黑(0)。
- 最左列整列填充为蓝(1)（左墙），最右列整列填充为红(2)（右墙）。
- 网格内部散布若干蓝(1)物体和若干红(2)物体，每个物体是一个 4-连通的不规则小图形（3~7 像素），远离各自的同色墙壁。
- 物体之间互不接触、不接触任何墙壁。
- 生成约束：每种颜色至少有 2 个物体。滑动完成后，蓝(1)物体紧靠左墙排列、红(2)物体紧靠右墙排列，且压缩后的物体群+墙壁+网格上下边界共同围成至少 1 个完全封闭的黑(0)背景区域（即该区域的 4-连通黑色像素不与网格边界的黑色通道相连）。

**规则**：
1. 对蓝(1)物体执行左滑：按物体边界框最左列从小到大的顺序（近者优先），逐个将物体水平向左平移，直到其最左像素紧邻左墙（蓝(1)列）或紧邻已定位蓝(1)物体的最右像素列右侧一列。物体保持原始形状和行位置。
2. 对红(2)物体执行右滑：按物体边界框最右列从大到小的顺序（近者优先），逐个将物体水平向右平移，直到其最右像素紧邻右墙（红(2)列）或紧邻已定位红(2)物体的最左像素列左侧一列。物体保持原始形状和行位置。
3. 清除所有物体原始位置（置为黑(0)），在新位置绘制。
4. 在滑动后的网格中，对所有黑(0)像素进行 4-连通洪泛标记，识别各连通区域。
5. 对于每个黑(0)连通区域，检查其是否与网格的上、下边界的黑(0)像素相连（左右边界被墙壁占据，不算）。如果某区域不与上边界或下边界的任何黑(0)像素 4-连通相连，则该区域为"封闭区域"，将其所有像素填充为黄(4)。
6. 墙壁列和压缩后的物体像素保持不变。

**关键洞察**：原始输入中不存在任何封闭区域——封闭性是物体压缩后涌现的拓扑属性；不执行滑动就无法知道哪些区域会被包围，不执行洪泛检测就无法区分封闭与开放区域。

## 新题 10：网格异常值源列编码错切偏移

**组合逻辑**：[提取/异常值选择/逐行比较](已有) + [错切/行偏移递变](已有，偏移量从公式计算改为由提取元数据编码) → 提取动作附带位置信息，位置信息驱动几何变换（创新耦合：结构解构型）

**来源原语**：提取/裁剪/网格单元/精灵体/逐行比较/异常值选择（38007db0），错切/行偏移递变/行内容保持（3cd86f4f）

**依赖链**：每行的异常值单元格提供两种信息——内容（精灵图案）和来源列索引。内容决定输出中画什么，来源列索引决定输出中画在哪（水平偏移量）。两者不可分离：如果只提取内容而忽略位置，输出布局无法确定；如果只用位置而忽略异常值检测，不知道提取哪个单元格。

从网格阵列的每行中找出模式独特的异常单元格并提取，然后按各异常值在原始行中的列索引作为水平偏移量，将提取结果错切排列为倾斜的单列输出。

**输入结构**：
- 网格约 20x25，由品红(6)网格线分割成 4 行 x 5 列的矩形单元格阵列。每个单元格约 4x4 像素（不含网格线）。
- 每个单元格内部背景为黑(0)，包含一个小精灵图案（2~5 像素的 4-连通前景图形，颜色从蓝(1)、红(2)、绿(3)、黄(4)中选取）。
- 每行 5 个单元格中，4 个单元格的精灵图案完全相同（颜色和形状都一致），1 个不同（异常值）。
- 不同行的异常值位于不同的列（列索引各不相同，从 0~4 中取 4 个不同值）。
- 生成约束：异常值的列索引序列不单调递增也不单调递减（非平凡排列）。

**规则**：
1. 对每一行，逐像素比较该行 5 个单元格的内容。找出恰好出现一次的模式，记录其单元格内容和所在列索引 c_r（列从 0 开始编号）。
2. 构造输出画布：高度 = 4 个单元格的总高度 + 3 条网格线，宽度 = 1 个单元格宽度 + max(c_0, c_1, c_2, c_3)（额外宽度用于偏移），背景为黑(0)。用品红(6)网格线分隔 4 个单元格行。
3. 将第 r 行（r 从 0 开始）提取的异常单元格内容放置在输出的第 r 个单元格位置，但水平偏移 c_r 个像素（即单元格内容整体右移 c_r 像素，超出单元格右边界的部分裁剪掉，左侧空出的位置保持黑(0)）。
4. 品红(6)网格线在输出中保持完整水平线形式。

**关键洞察**：异常值的列索引不只是查找过程中的副产品——它编码了输出布局的水平偏移，使得提取和错切操作共享同一个信息源，无法独立执行。
