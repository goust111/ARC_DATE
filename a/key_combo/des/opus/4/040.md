## 新题 1：弹射线选择嵌套层并按命中序着色

**组合逻辑**：[射线延伸 + 边界反射](创新：反射面不再是独立线段镜，而是嵌套矩形边框本身) → [洪泛填充](创新：仅对被射线命中的边框的内部区域填充) → [由外到内嵌套](提供填充覆盖顺序) + [命中序编码填充色](创新：射线依次命中边框的先后顺序决定该区域的填充颜色)

**来源原语**：射线延伸、边界反射(7e2bad24)；洪泛填充(83302e8f)；嵌套矩形、由外到内嵌套(5751f35e)；特定色反射射线(7e2bad24，改造为"所有边框都反射")

**依赖链**：射线物理轨迹决定哪些嵌套边框被命中 → 被命中边框被标记为"活跃" → 命中顺序(第 1 个、第 2 个...)为活跃边框分配填充颜色 → 填充从最外层活跃边框向内进行，内层覆盖外层 → 最终只有活跃层可见填充色，非活跃层内部保持背景色

对角射线从种子出发在嵌套矩形边框间反射前进；射线依次命中的边框获得序号编码的填充色，未命中边框不填充。

**输入结构**：约 20x20 的黑(0)背景网格。3~4 个严格嵌套的单像素厚轴对齐矩形边框，每个边框使用不同颜色，从外到内依次取自 {蓝(1), 红(2), 绿(3), 黄(4)}。边框之间间距至少 2 像素，保证射线在两次反射之间至少行进 2 步。网格某个角落附近（距最外层边框外侧 1~2 像素处）有一段 2~3 像素的 8-连通对角线种子，颜色为橙(7)。种子的朝向使其向网格内部延伸时必然穿过至少两个边框。生成约束：射线路径上不存在两个边框角点重合的退化情况；每次反射点落在边框的水平段或垂直段上（不在角像素上），保证反射方向唯一。

**规则**：
1. 从种子的两个端点中，选择向内延伸（沿对角方向）仍在网格内的那个端点作为起点，沿该对角方向逐像素推进。
2. 推进时，若下一个像素是黑(0)背景，则将该像素涂为橙(7)并继续。
3. 若下一个像素是某个矩形边框的像素，则不涂该像素，执行反射：碰到水平边框段则翻转行方向分量，碰到垂直边框段则翻转列方向分量。记录该边框为"被命中"，并记录命中序号（从 1 开始递增）。然后从反射后的方向继续推进。
4. 若下一个像素超出网格边界，射线终止。
5. 射线终止后，对所有被命中的边框，按命中序号分配填充颜色：序号 1 → 灰(5)，序号 2 → 品红(6)，序号 3 → 青(8)，序号 4 → 栗(9)。
6. 从命中序号最小（最先命中）的边框开始，依次用分配的颜色洪泛填充该边框严格内部的所有黑(0)像素（不改变边框像素和已有射线像素）。后填充的内层覆盖先填充的外层重叠区域。
7. 未被射线命中的边框，其内部保持黑(0)不变。

**关键洞察**：矩形边框同时扮演"容器"和"反射镜"双重角色——同一组对象既定义了嵌套包含关系，又决定了射线物理行为。填充颜色不由边框自身属性决定，而由射线命中该边框的先后顺序决定，因此必须先完整模拟射线轨迹才能确定任何区域的填充色。

## 新题 2：格子完整性决定填充操作分支

**组合逻辑**：[洪泛填充 + 连通分量检测](检测格子框架内的封闭背景区域) → [完整与缺损区异色](创新：不再仅用颜色区分，而是用分类结果决定完全不同的操作) → [填充](对完整格子区域执行纯色填充) / [周期平铺](对缺损格子区域执行图案平铺)；[顶行色序](编码纯色填充的颜色循环)

**来源原语**：洪泛填充、格子框架、封闭背景区域、完整与缺损区异色(83302e8f)；周期平铺(53fb4810)；填充、顶行色序、分隔下循环填色(bd4472b8)；连通分量检测(12eac192)

**依赖链**：洪泛填充识别格子内所有背景连通区域 → 面积与边界框面积比较分类为完整/缺损 → 完整区域从顶行色序中按阅读序循环取色做纯色填充 → 缺损区域从缺口形态中提取最小包围图案，将该图案周期平铺到整个缺损区域 → 分类结果决定哪条规则生效，两条规则不可互换

每个格子区域按其完整性接受不同变换：完整格子被纯色填充（颜色由顶行序列循环指定），缺损格子被其缺口图案周期平铺。

**输入结构**：约 15x15 的黑(0)背景网格。灰(5)像素构成一个不完美的矩形格子框架，将网格划分为约 3x3 或 4x3 个大致等大的矩形单元格。格子的大部分边完整，但有 2~3 处边段缺失（缺口宽度 1~2 像素），使得某些相邻单元格的背景区域通过缺口连通成一个更大的连通分量。网格最顶行（行 0）不属于格子，而是一行颜色序列，包含 3~4 种不同颜色的像素，如 [红(2), 蓝(1), 绿(3), 黄(4)]，按列排布且刚好覆盖整行宽度（循环重复直到填满）。生成约束：每个完整单元格（4-连通背景区域恰好等于其边界框面积）至少有 1 个；每个缺损区域（跨越多个单元格的连通分量）至少有 1 个；缺口位置使得缺损区域的缺口图案（缺失的灰色像素的局部排列）在不同缺损区域之间不完全相同。

**规则**：
1. 识别灰(5)格子框架，对网格中所有黑(0)像素执行 4-连通分量检测。
2. 对每个黑色连通分量，计算其面积 A 和其轴对齐边界框面积 B。若 A = B，该区域为"完整"；若 A > B 或 A < B（即区域形状非矩形），该区域为"缺损"。实际上，对于格子结构，缺损区域的 A 严格大于其中任一子单元格的边界框面积。
3. 对所有完整区域，按其边界框左上角坐标的阅读序（先行后列）排列。从顶行色序中依次取色（循环使用），将每个完整区域的所有像素填充为对应颜色。
4. 对每个缺损区域，找到该区域边界上所有与灰(5)格子相邻但格子缺失的位置（即缺口），提取缺口处一个 1x2 或 2x1 的局部模式作为图案种子（取缺口方向上包含背景像素和相邻最近非背景像素的最小矩形窗口）。将该 2 像素图案以缺口位置为起点，沿缺口方向在整个缺损区域内周期重复，使用橙(7)着色。若缺损区域有多个缺口，每个缺口独立平铺，后平铺覆盖先平铺。
5. 灰(5)格子像素和顶行色序像素保持不变。

**关键洞察**：格子的结构完整性不仅是一个分类标签，而是一个操作分支开关——完整和缺损区域接受完全不同的变换算法。必须对比多个示例才能归纳出"完整→纯色循环、缺损→缺口图案平铺"这一分支规则，因为单个示例可能只展示一种情况。

## 新题 3：矩形堆叠揭示隐藏标记驱动水平重复

**组合逻辑**：[排序 + 堆叠](按面积从大到小堆叠矩形) → [前景遮挡](堆叠产生遮挡关系，决定哪些标记可见) → [计数](统计可见标记数) → [重复](按标记数水平重复堆叠结果)

**来源原语**：排序、堆叠、填充矩形、角对齐、按面积降序(20818e16)；前景遮挡(52df9849)；计数、重复、单像素标记、标记数等于副本数(4852f2fa)；标记计数驱动重复(4852f2fa)

**依赖链**：各矩形按面积降序堆叠于左上角 → 堆叠顺序决定遮挡关系：小矩形在上层可见，大矩形被部分遮挡 → 某些矩形内部嵌有栗(9)标记像素，被更大矩形遮挡的标记不可见，只有最终可见的标记参与计数 → 可见标记总数 N 决定输出宽度：将堆叠结果水平拼接 N 份

矩形按面积堆叠后，仅未被遮挡的标记像素可见；可见标记数决定堆叠图像的水平重复次数。

**输入结构**：约 18x18 的黑(0)背景网格。散布 4~5 个不同颜色的实心矩形（颜色取自 {蓝(1), 红(2), 绿(3), 黄(4), 灰(5)}），每个矩形的宽和高在 3~8 像素之间，面积互不相同。矩形在输入中的位置互相分离（不重叠），每个矩形的完整尺寸可由其可见像素的边界框恢复。其中 2~3 个矩形内部各含有 1~2 个栗(9)标记像素（替换了该矩形颜色的像素）。标记像素的位置经过设计：当矩形按面积降序堆叠于左上角后，部分标记被更上层的小矩形完全覆盖而不可见，剩余标记仍然可见。生成约束：最终可见标记数 N 在 2~4 之间；堆叠结果的宽度乘以 N 不超过 30 像素；至少有 1 个标记在堆叠后被遮挡（否则遮挡逻辑无法验证）。

**规则**：
1. 对每种非背景、非栗(9)的前景颜色，用该颜色所有像素（包括被栗(9)标记替换的原始位置）的边界框宽高恢复其完整矩形。标记像素视为其所在矩形颜色的一部分来确定边界框，但标记像素本身保持栗(9)。
2. 按矩形面积从大到小排序。以输出画布左上角 (0,0) 为所有矩形的左上角对齐点，依次绘制矩形（大的先画，小的后画覆盖大的）。每个矩形内部的栗(9)标记像素在对应相对位置保持为栗(9)。
3. 堆叠完成后，统计画布上所有可见的栗(9)像素数量，记为 N。（被后绘制的矩形覆盖的标记不计入。）
4. 输出为堆叠图像在水平方向拼接 N 份。输出高度等于最大矩形的高度，输出宽度等于最大矩形的宽度乘以 N。各份之间无间隔，直接相邻。

**关键洞察**：堆叠顺序（由面积决定）不仅决定视觉结果，还过滤了哪些标记像素可见——这是一个信息揭露步骤而非简单的渲染步骤。求解者必须先正确堆叠才能正确计数，而计数结果又驱动输出的整体结构。单个示例中可能无法区分"统计所有标记"和"统计可见标记"，必须对比多个示例（不同遮挡情况）才能发现遮挡过滤规则。

## 新题 4：十字扩展生成引导臂并按臂类型决定接触重涂

**组合逻辑**：[扩展](十字图案的臂色和中心色分别沿正交和对角方向无限延伸至网格边界) + [正交对角分工](创新：扩展后的正交臂和对角臂承担不同的"引导线"角色) → [接触判定](检测延伸线与散布的精灵体是否接触) → [重涂色](创新：被正交臂接触的精灵体涂为一种颜色，被对角臂接触的涂为另一种颜色；同时被两种臂接触的涂为第三种颜色)

**来源原语**：扩展、十字图案、正交对角分工、臂色中心色分延(0962bcdd)；连线/引导线(0d87d2a6)；接触判定、接触则重涂、前景对象(0d87d2a6)；重涂色(12eac192)

**依赖链**：十字的两种颜色分别沿正交和对角方向延伸至边界，形成两类引导线 → 每个散布的精灵体被检测是否与引导线 4-邻接接触 → 接触类型（仅正交 / 仅对角 / 两者都有）决定重涂目标色 → 精灵体的最终颜色编码了它与十字之间的空间角度关系

十字的正交臂和对角臂延伸为两类引导线；散布的小图形按接触的引导线类型被重涂为不同颜色。

**输入结构**：约 20x20 的黑(0)背景网格。网格中央偏左上方有一个 3x3 的十字图案：四个正交臂像素为蓝(1)，中心像素为红(2)。网格中散布 5~7 个小型 4-连通单色图形（精灵体），每个由 3~6 个灰(5)像素组成，形状各异（不规则，非矩形），互不相邻且不与十字相邻。精灵体的位置经过设计：一部分仅在十字的正交方向延长线附近（上下左右），一部分仅在对角方向延长线附近（四个 45 度方向），一部分同时靠近正交和对角延长线的交叉区域。生成约束：每种接触类型（仅正交、仅对角、两者兼有）至少各有 1 个精灵体；精灵体不位于十字的正交或对角延长线正上方（不被延伸线穿过），只在旁边与延伸线 4-邻接接触。

**规则**：
1. 从十字中心出发，沿上、下、左、右四个正交方向，逐像素延伸蓝(1)线直到网格边界（覆盖路径上的黑色像素，但不覆盖已有的非背景像素——若遇到非背景像素则跳过该像素继续延伸）。
2. 从十字中心出发，沿左上、右上、左下、右下四个对角方向，逐像素延伸红(2)线直到网格边界（同样跳过非背景像素继续延伸）。
3. 对每个灰(5)精灵体，检查其所有像素的 4-邻域中是否存在蓝(1)延伸线像素和/或红(2)延伸线像素。
4. 若精灵体仅与蓝(1)正交臂接触（4-邻域中有蓝(1)延伸像素但无红(2)延伸像素），将整个精灵体重涂为绿(3)。
5. 若精灵体仅与红(2)对角臂接触（4-邻域中有红(2)延伸像素但无蓝(1)延伸像素），将整个精灵体重涂为黄(4)。
6. 若精灵体同时与蓝(1)和红(2)延伸线接触，将整个精灵体重涂为橙(7)。
7. 若精灵体与两类延伸线均不接触，保持灰(5)不变。
8. 十字本身（3x3 区域）保持原样不变。

**关键洞察**：十字扩展中的"臂色/中心色角色分工"不再仅仅决定生长方向，而是直接编码了两个语义不同的"引导线系统"——正交系统和对角系统。精灵体的重涂颜色由它处于哪个系统的辐射范围内决定，相当于十字将空间划分为正交区、对角区和交叉区三个语义区域。需要对比多个示例才能区分"接触任一类型即涂同色"和"按接触类型分色"。

## 新题 5：连通分量面积筛选出候选体与凹槽并按旋转匹配执行颜色互换

**组合逻辑**：[连通分量检测 + 面积阈值筛选](创新：同一次检测中按面积阈值将分量分为"候选体"和"凹槽主体") → [洪泛填充](识别凹槽主体内部的凹槽区域) → [旋转平移嵌入 + 形状匹配](候选体旋转后尝试嵌入凹槽) → [颜色角色互换](创新：成功匹配后，候选体和凹槽的颜色互换而非简单填充)

**来源原语**：连通分量检测、面积阈值筛选、单色连通体(12eac192)；洪泛填充、封闭背景区域(83302e8f)；形状匹配、凹槽、候选块、旋转平移嵌入、完全覆盖、无重叠(1acc24af)；颜色角色互换(c6141b15)；重涂色(1acc24af/12eac192)

**依赖链**：连通分量检测将所有前景分量按面积分为两组 → 大分量（面积 >= 阈值）是"凹槽主体"，其内部的背景连通区域即凹槽 → 小分量（面积 < 阈值）是"候选体" → 每个候选体尝试四种旋转与每个凹槽做形状匹配 → 匹配成功时执行颜色互换：候选体像素变为凹槽主体颜色，凹槽像素变为候选体原色 → 面积阈值决定了角色分配，而不是位置

连通分量的面积决定其角色（候选体 vs. 凹槽主体）；候选体旋转匹配凹槽后，双方颜色互换。

**输入结构**：约 18x18 的黑(0)背景网格。网格中有 2 个较大的单色 4-连通前景对象（"凹槽主体"），颜色分别为蓝(1)和绿(3)，每个面积在 15~25 像素之间，形状不规则但内部各含有 1 个由黑(0)背景构成的封闭凹槽（凹槽面积 3~5 像素，形状不规则）。网格中另有 3~4 个较小的单色 4-连通前景对象（"候选体"），颜色各异取自 {红(2), 黄(4), 灰(5), 品红(6)}，每个面积在 3~5 像素之间。候选体散布在凹槽主体周围，与凹槽主体不相邻。生成约束：恰好有 2 个候选体能在某个旋转（0/90/180/270 度）下与某个凹槽完全形状匹配（面积相等且形状吻合），其余候选体与所有凹槽均不匹配；每个凹槽最多被一个候选体匹配；所有前景分量的面积要么 >= 12（大），要么 <= 6（小），中间无歧义。

**规则**：
1. 检测网格中所有非背景的 4-连通单色分量，计算每个分量的面积。
2. 面积 >= 12 的分量为"凹槽主体"；面积 <= 6 的分量为"候选体"。
3. 对每个凹槽主体，找到其边界框内被该主体颜色完全包围的黑(0) 4-连通区域，即"凹槽"。凹槽不触及网格边界且不触及主体边界框外部。
4. 对每个候选体，尝试 0/90/180/270 四种旋转。对每种旋转后的形状，检查是否与某个凹槽面积相同且形状完全一致（像素逐一对应）。
5. 若候选体在某个旋转下与某个凹槽匹配，执行颜色互换：(a) 将该候选体在输入中的所有像素（原始位置、原始未旋转形态）重涂为其匹配的凹槽主体的颜色；(b) 将该凹槽的所有像素重涂为该候选体的原始颜色。
6. 不匹配的候选体保持原色不变。凹槽主体的非凹槽像素保持原色不变。
7. 若一个候选体的旋转能匹配多个凹槽（生成约束保证不会发生），优先匹配按凹槽主体边界框左上角阅读序靠前的。

**关键洞察**：面积阈值同时完成了"角色分配"和"干扰排除"——求解者无法通过位置或颜色判断谁是候选体谁是凹槽主体，只能通过面积。而匹配成功后不是简单地把候选体塞入凹槽，而是执行颜色互换，使得输入中的候选体和凹槽都发生颜色变化。需要对比多个示例才能归纳出"互换"而非"单向填充"的规则。

## 新题 6：标记对定义裁剪跨度后按面积分配平铺角色

**组合逻辑**：[标记对定义跨度](每个矩形框上的标记对定义裁剪窗口) → [裁剪](从每个框中裁出标记跨度内的子区域) → [尺寸排序](按裁剪结果面积排序) → [周期平铺](创新：面积最小的裁剪结果作为图案模板，周期平铺到所有较大裁剪结果的区域内)

**来源原语**：标记对定义跨度、标记像素(f3e14006)；裁剪、矩形框、内部区域(1c786137/1a6449f1)；尺寸排序(48634b99)；周期平铺(53fb4810)；边框包围内容(1a6449f1)；包含(1c786137)

**依赖链**：每个矩形框的边框上有两个同色标记像素，它们定义了一个行跨度或列跨度 → 该跨度限定了从框内部裁出的子区域范围 → 所有裁出的子区域按面积排序 → 面积最小的子区域成为"图案模板" → 其余子区域在输出中被该模板周期平铺填充 → 标记位置决定裁剪范围，裁剪范围的相对大小决定谁是模板谁是画布

矩形框上的标记对定义裁剪跨度；裁剪出的最小子区域成为模板，周期平铺到其余裁剪区域中。

**输入结构**：约 22x22 的黑(0)背景网格。网格中有 3 个互不重叠的单像素厚单色矩形框（空心矩形），颜色分别为蓝(1)、红(2)、绿(3)，大小不同（内部区域约 4x4 到 8x8）。每个矩形框的边框上恰好有 2 个黄(4)标记像素，替换了边框原色。这两个标记像素位于同一条边框边上（同在顶边、底边、左边或右边），定义了一个跨度：若在水平边上则定义列跨度（两标记之间的列范围），若在垂直边上则定义行跨度（两标记之间的行范围）。每个矩形框的内部包含一些由灰(5)像素组成的小图案（1~6 个灰像素，位置各异）。生成约束：三个框的标记跨度裁剪出的子区域面积互不相同；最小裁剪区域的宽和高都能整除其余每个裁剪区域的对应维度（保证周期平铺无余数）；框内灰(5)图案不触及边框。

**规则**：
1. 找到每个矩形框边框上的两个黄(4)标记像素。确定它们所在的边（上/下/左/右）。
2. 若标记在水平边上，裁剪窗口的列范围为两标记像素之间（不含标记所在列），行范围为框内部的全部行。若标记在垂直边上，裁剪窗口的行范围为两标记像素之间（不含标记所在行），列范围为框内部的全部列。
3. 从每个框内部裁出对应窗口内的子网格（包含其中的灰(5)图案像素和黑(0)背景像素）。
4. 按裁剪子网格的面积（行数 x 列数）从小到大排序。面积最小的子网格记为 T（模板）。
5. 对其余每个裁剪子网格 C，将 T 从 C 的左上角开始周期平铺（水平和垂直方向均重复），直到完全覆盖 C 的范围。平铺时 T 中的灰(5)像素覆盖 C 中对应位置的像素，T 中的黑(0)像素不覆盖（保持 C 原有内容）。
6. 将平铺结果写回每个非模板框的对应内部区域。模板所在框的内部保持不变。矩形框边框保持不变（黄(4)标记也保留）。框外区域保持黑(0)。

**关键洞察**：标记像素的位置在每个框上独立定义了不同的裁剪窗口，导致同样大的框可能裁出不同大小的子区域。谁是"模板"谁是"画布"不由框的大小决定，而由标记位置决定的裁剪结果的相对面积决定——这个角色分配是间接的，必须先完成裁剪才能确定。

## 新题 7：边界标记引导线同时选择目标框和编码框内填充方向

**组合逻辑**：[连线/引导线](从边界标记对生成贯穿全网格的引导线) → [接触判定](创新：引导线与矩形框边框接触时选中该框) + [邻接侧决定方向](创新：引导线从框的哪一侧接触，决定框内部的填充扫描方向) → [填充](创新：将被选中框的内部按指定方向逐行或逐列用颜色序列循环填充)

**来源原语**：连线、边界标记对、引导线、接触判定、接触则重涂(0d87d2a6)；邻接侧决定方向(53fb4810)；矩形框、内部区域、边框包围内容(1a6449f1)；填充、顶行色序、分隔下循环填色(bd4472b8)；标记色编码距离(72a961c9，改造为"标记色编码填充颜色序列")

**依赖链**：边界标记对生成水平或垂直引导线 → 引导线穿过网格时接触某些矩形框的边框 → 接触事实选中这些框为"活跃框" → 引导线接触框的边（上/下 → 垂直方向扫描，左/右 → 水平方向扫描）决定了该框内部的填充扫描方向 → 引导线的颜色决定填充使用的颜色序列 → 未被引导线接触的框保持不变

边界标记对产生的引导线选中它接触的矩形框，并以接触侧编码框内的填充方向和颜色。

**输入结构**：约 22x22 的黑(0)背景网格。网格中散布 4~5 个单像素厚矩形框（空心矩形），颜色均为灰(5)，大小各异（内部区域约 3x3 到 6x6），互不重叠且互不相邻，框内部为黑(0)背景。网格的四条边界上有若干标记像素：左右两条边界上各有 0~2 个标记像素（颜色为红(2)或蓝(1)），分别位于同一行，形成水平标记对；上下两条边界上各有 0~2 个标记像素（颜色为红(2)或蓝(1)），分别位于同一列，形成垂直标记对。总共有 2~3 个标记对。生成约束：每条引导线至少接触 1 个矩形框的边框；至少有 1 个框被水平引导线接触，至少有 1 个框被垂直引导线接触；若某个框被多条引导线接触，取从框左上角出发最先遇到的引导线（按阅读序最靠前的接触点）。

**规则**：
1. 对每个标记对（同行的左右边界标记或同列的上下边界标记），沿该行或该列画一条贯穿全网格宽/高的引导线，颜色为标记像素的颜色（红(2)或蓝(1)）。引导线覆盖黑(0)像素但不覆盖灰(5)框边框像素。
2. 对每个灰(5)矩形框，检查其四条边框边是否有像素与引导线像素 4-邻接。若有，该框被"选中"。
3. 确定选中框的填充方向：若引导线接触框的上边或下边（水平边框段），则填充方向为"逐列从左到右"。若引导线接触框的左边或右边（垂直边框段），则填充方向为"逐行从上到下"。若框被多条引导线接触在不同侧，取按接触点坐标阅读序最靠前的那条引导线决定方向。
4. 确定选中框的填充颜色序列：若决定方向的引导线颜色为红(2)，则颜色序列为 [红(2), 黄(4)]交替。若引导线颜色为蓝(1)，则颜色序列为 [蓝(1), 绿(3)]交替。
5. 按填充方向，将框内部的每一行（若逐行）或每一列（若逐列）整体填充为颜色序列中的下一个颜色（第 1 行/列用序列第 1 色，第 2 行/列用第 2 色，如此循环）。
6. 未被任何引导线接触的框，其内部保持黑(0)不变。引导线像素本身保留在输出中。

**关键洞察**：引导线对矩形框执行三重编码：(1) 是否接触→选择/不选择，(2) 接触框的哪一侧→填充的扫描方向，(3) 引导线自身颜色→填充的颜色序列。单条引导线同时携带"选择信号"、"方向参数"和"颜色参数"三种信息，而不仅仅是一个选择器。需要多个示例对比才能分离出方向编码规则（接触上下→逐列 vs. 接触左右→逐行）。

## 新题 8：竖条高度排序确定连线端点并由标记段半侧决定连线色

**组合逻辑**：[尺寸排序](竖条按高度排序形成逻辑序列) → [连线/连接](创新：相邻排序位的竖条之间画水平连线) + [半段位置保持](创新：标记段在竖条上半/下半的位置编码连线的颜色) → [平移](创新：标记段从当前竖条平移到下一个排序位的竖条的同侧)

**来源原语**：尺寸排序、竖条、标记段、半段位置保持(48634b99)；连线/连接(c6141b15/0d87d2a6)；平移(48634b99)；重涂色(48634b99)；端点对应(c6141b15)

**依赖链**：各竖条按高度排序得到逻辑顺序 → 逻辑上相邻的竖条之间在标记段所在行高度画水平连线 → 标记段在当前竖条的上半还是下半决定连线颜色（上半 → 一种色，下半 → 另一种色）→ 标记段从当前竖条移除并出现在排序序列中下一根竖条的同侧（上半或下半）→ 连线的行高度由源竖条标记段的实际行位置决定

按高度排序竖条后，在相邻排序位之间画水平连线，连线颜色和行位置均由标记段编码。

**输入结构**：约 18x22 的黑(0)背景网格（宽 > 高）。网格中有 5~7 根垂直的单像素宽竖条，颜色均为蓝(1)，高度互不相同（范围 4~14 像素），底部对齐于网格底边（所有竖条的最低像素在同一行），水平方向均匀分布（相邻竖条间距 2~3 列）。其中恰好一根竖条上有一段连续的红(2)标记段（2~3 像素高），替换了该竖条对应位置的蓝(1)像素。标记段完全位于竖条的上半部分或下半部分（以竖条中点行为界）。生成约束：标记段所在竖条不是高度排序中的最后一根（最高的一根）；所有竖条高度差至少为 2，保证排序无歧义；排序序列中当前竖条的"下一根"（高度次大的）足够高，使得标记段的目标位置（同侧）不超出该竖条范围。

**规则**：
1. 测量每根蓝(1)竖条的高度（含被红(2)标记段替换的像素，将标记段计入竖条高度）。
2. 按高度从矮到高排序，形成排序序列 S[0], S[1], ..., S[n-1]。
3. 找到包含红(2)标记段的竖条 S[k]。确定标记段位于 S[k] 的上半部分（标记段中点行 < 竖条中点行）还是下半部分（标记段中点行 >= 竖条中点行）。
4. 将 S[k] 上的标记段重涂回蓝(1)（恢复竖条原色）。
5. 在排序序列中找到 S[k] 的下一根竖条 S[k+1]（高度次大的）。在 S[k+1] 的同侧（上半或下半）的对应相对位置（相对于竖条顶部或底部的偏移量相同）涂上红(2)标记段。
6. 从 S[k] 的标记段原始中点行出发，画一条水平连线连接 S[k] 和 S[k+1] 的列位置（含两端点列，覆盖之间所有像素）。连线颜色：若标记段在上半部分则为黄(4)，若在下半部分则为绿(3)。连线不覆盖两根竖条本身的像素（仅画在竖条之间的空白区域和两根竖条的边缘列上）。
7. 若连线路径上有其他竖条被穿过，连线跳过这些竖条的像素（不覆盖蓝(1)像素），在竖条另一侧继续。

**关键洞察**：竖条的空间位置（从左到右的物理顺序）与逻辑顺序（按高度排序）不同，连线连接的是逻辑上相邻的竖条而非物理上相邻的。标记段的半侧位置承担双重角色：既编码连线颜色（隐蔽规则，需对比多个示例发现），又指定标记段在目标竖条上的放置位置。物理顺序和逻辑顺序的差异是核心推理难点。
