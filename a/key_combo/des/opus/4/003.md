## 新题 1：孔洞计数驱动射线选择性填充

**组合逻辑**：[计数counting](创新：孔洞数决定对象自身颜色) → [重涂色recolor](已有) → [射线延伸ray_extend](创新：射线颜色与目标颜色匹配时填充目标孔洞) + [填充fill](创新：由颜色匹配条件触发)

**来源原语**：计数/封闭背景区域/孔洞数映射颜色(37d3e8b2)、射线延伸/侧标记/遇阻停止(95755ff2)、填充/框内填充(e88171ec)、重涂色(多题共有)

**依赖链**：计数孔洞→确定对象颜色→射线到达对象时，颜色匹配决定是否填充孔洞。若跳过计数，无法确定对象颜色；若跳过射线，无法确定哪些对象的孔洞被填充。

孔洞数决定对象颜色，边缘射线到达对象时若颜色匹配则额外填充该对象的孔洞，否则仅停止。

**输入结构**：黑(0)背景，约15x15。网格中散布3-4个灰(5)单色实心矩形对象（4-连通，宽高各3-6像素），每个对象内部有1-3个封闭的背景孔洞（4-连通背景区域，被灰像素完全包围）。不同对象的孔洞数互不相同。网格的四条边缘（顶行、底行、左列、右列）各有1-2个单像素彩色标记，颜色为蓝(1)、红(2)或绿(3)中的一种。对象之间互不相邻，且不接触网格边缘。生成约束：每个边缘标记至少与一个对象共享行或列；标记总数不超过6个。

**规则**：
1. 对每个灰(5)对象，在其边界框内计数4-连通封闭背景区域（孔洞）数量。
2. 按孔洞数重涂对象的灰像素：1个孔洞→蓝(1)，2个孔洞→红(2)，3个孔洞→绿(3)。孔洞本身保持背景色不变。
3. 从每个边缘标记出发，沿其所在行（左/右边缘标记）或所在列（顶/底边缘标记）向网格内部发射射线，将路径上的背景像素涂为标记颜色。射线遇到第一个非背景像素时停止，不涂终点像素。
4. 若射线停在某个已重涂对象的外壁上，且射线颜色与该对象的重涂颜色相同，则额外将该对象内部的所有孔洞像素填充为该颜色。若颜色不匹配，孔洞保持背景色。
5. 多条射线可能到达同一对象：只要任一条射线颜色匹配，孔洞即被填充（填充动作幂等）。射线仅在背景像素上绘制，先后顺序不影响最终结果。

**关键洞察**：孔洞是否被填充取决于射线颜色与对象颜色的匹配，而对象颜色由孔洞数量决定——形成"数量→颜色→匹配→填充"的间接依赖链。仅看最终输出，被匹配填充的对象呈纯色块，但其颜色编码了它曾经拥有的孔洞数。

## 新题 2：旋转补全后按奇偶印章铺展

**组合逻辑**：[对称补全symmetry_completion](已有) + [印章覆盖stamp_overlay](创新：印章内容来自补全结果而非输入中的现有图案) ← [同奇偶格接收副本same_parity_receive_copy](创新：奇偶性由独立标记指定而非由种子图案位置隐式确定)

**来源原语**：对称补全/旋转对称/旋转恢复缺失像素(11852cab)、印章覆盖/种子图案/开放单元格/同奇偶格接收副本(92e50de0)、分隔线/单元格阵列(92e50de0)

**依赖链**：补全构造出待印章的完整图案→奇偶标记选择目标单元格→将补全图案印入目标格。若跳过补全，无完整图案可印；若跳过奇偶选择，不知印在哪些格中。两条信息路径独立计算后汇合。

在分隔线网格中，先将某单元格内的残缺图案做90度旋转对称补全，再按独立标记指定的奇偶性将补全后的图案印入所有同奇偶单元格。

**输入结构**：黑(0)背景，约17x17。绿(3)全宽/全高分隔线将网格划分为规整的4x4开放单元格阵列（每个单元格约3x3像素，分隔线宽1像素）。恰好一个单元格内包含一个红(2)的残缺小图案（2-4像素，具有90度旋转对称性——即补全缺失位置后形成90度旋转对称的完整图案，完整图案约4-6像素）。另一个不同的单元格内包含一个黄(4)单像素标记。其余所有单元格为空（纯背景）。生成约束：残缺图案的旋转对称中心为其所在单元格的中心像素；补全后的完整图案不超出单元格边界；黄色标记所在单元格与红色图案所在单元格不同。

**规则**：
1. 在包含红(2)残缺图案的单元格中，以单元格中心为旋转对称中心，将每个红像素旋转90度、180度、270度到其他三个位置。若这些位置为背景，则填充红(2)，得到完整的90度旋转对称图案。
2. 记录黄(4)标记所在单元格的行索引和列索引（从0开始，仅计数开放单元格，分隔线不计入索引）的奇偶性，记为(p_r, p_c)。
3. 将补全后的完整红色图案（以单元格内相对偏移表示）印入所有满足以下条件的单元格：该单元格的(行索引 mod 2, 列索引 mod 2) = (p_r, p_c)。
4. 移除黄(4)标记（恢复为背景）。红色图案的源单元格保留补全后的图案，无论其是否满足奇偶条件。
5. 若目标单元格为边缘截断的不完整单元格，仅绘制落在网格内的像素，超出部分丢弃。

**关键洞察**：待印章的图案在输入中并不完整——必须先通过旋转对称推断缺失部分。同时，哪些单元格接收印章由一个独立的黄色标记控制，而非由图案位置隐式决定。两个独立推理（补全形状 + 确定奇偶类别）必须同时完成才能生成正确输出。

## 新题 3：面积排名驱动旋转角度与对角链堆叠

**组合逻辑**：[排序sorting](创新：按面积而非长度排名) → [旋转rotate](创新：旋转角度由排名决定) → [堆叠stacking/对角链排列diagonal_chain_layout](创新：旋转后的尺寸决定链的几何形状) + [重涂色recolor](已有：排名决定颜色) + [冲突优先级conflict_priority](已有)

**来源原语**：排序/长度排名/排名决定颜色(ea32f347)、旋转/旋转关系(a416fc5b, 412b6263)、堆叠/对角链排列/角点重叠/按左边缘排序/冲突优先级(03560426)、实心矩形(03560426)

**依赖链**：面积排名→同时决定三个属性：颜色、旋转角度、放置顺序。旋转改变矩形的宽高比→直接影响对角链中每步的偏移量。删除排名则无法确定旋转角度；删除旋转则链的几何形状错误。

对底部排列的灰色矩形按面积排名，排名同时决定颜色、旋转角度和对角链放置顺序，旋转后的尺寸改变链的几何轨迹。

**输入结构**：黑(0)背景，约15x15。底行上贴合3个灰(5)实心矩形，彼此不重叠且不相邻，左边缘位置各不相同，面积（像素数）各不相同。每个矩形宽高不等（非正方形），宽高各在2-5像素范围内。矩形底边贴合网格底行。生成约束：三个矩形面积严格不同；旋转并对角链堆叠后的总覆盖区域不超出网格边界。

**规则**：
1. 按像素面积从小到大排名：最小=排名1，中间=排名2，最大=排名3。
2. 重涂色：排名1→蓝(1)，排名2→红(2)，排名3→绿(3)。
3. 旋转：排名1不旋转（0度），排名2顺时针旋转90度（宽高互换），排名3顺时针旋转180度（像素行列均反转，形状的上下左右镜像翻转）。
4. 清空画布为背景。按排名顺序（1→2→3）将旋转后的矩形放置为对角链：第一个矩形左上角置于网格(0,0)。设刚放置的矩形旋转后高度为h、宽度为w，则下一个矩形左上角置于当前矩形左上角偏移(h-1, w-1)处。
5. 后放置的矩形在角点重叠处覆盖先放置的像素。

**关键洞察**：排名是唯一的决策变量，但它扇出为三个不同效果：颜色、旋转角度、放置顺序。由于排名2的矩形发生90度旋转导致宽高互换，对角链的第二段偏移与原始矩形尺寸不同——仅凭原始尺寸无法推算链的轨迹。必须先确定排名，再旋转，最后才能计算正确的链布局。

## 新题 4：互补填充改变孔洞拓扑后重涂

**组合逻辑**：[形状匹配shape_match/互补形状complementary_shape](已有) → [填充fill](创新：填充改变封闭区域拓扑) → [计数counting](创新：计数对象是填充后才出现的封闭区域) → [重涂色recolor](创新：由拓扑变化后的孔洞数决定)

**来源原语**：形状匹配/互补形状/缺口形状唯一配对(18447a8d)、填充(18447a8d, e88171ec)、计数/封闭背景区域(e872b94a, 37d3e8b2)、重涂色/孔洞数映射颜色(37d3e8b2)、归一化形状比对(4ff4c9da)

**依赖链**：互补匹配决定哪块形状填入哪个模板→填充封闭缺口→缺口变为有色区域改变模板内4-连通背景区域拓扑→新的孔洞数决定模板框体颜色。每一步的输出实质性改变下一步的输入拓扑。

将右侧彩色形状匹配填入左侧模板的互补缺口，填充后重新计算模板内封闭背景孔洞数，按孔洞数重涂模板框体。

**输入结构**：黑(0)背景，约18x14。一列灰(5)单像素宽的竖直分隔线将网格分为左右两半。左半区：3个水平条带（由至少2行背景分隔），每个条带包含一个青(8)单色连通模板形状（8-15像素，4-连通，边界框约5x5至7x7）。每个模板有一个缺口——一块与模板边界框边缘相邻的背景连通区域（3-5像素，4-连通），缺口形状各不相同。在缺口被填充前，每个模板内部另有0-2个完全封闭的背景孔洞（被青色像素四面包围的4-连通背景区域）。右半区：3个小型彩色形状，分别为红(2)、绿(3)、蓝(1)，各3-5像素。每个右侧形状经平移归一化后恰好与某一个左侧缺口的形状完全相同（唯一配对）。生成约束：三个缺口形状互不相同；填充缺口后，三个模板的封闭孔洞数互不相同且在0-2范围内。

**规则**：
1. 将每个右侧形状和每个左侧缺口分别归一化到各自边界框左上角的相对偏移集合。
2. 将每个右侧形状匹配到归一化偏移集合相同的唯一左侧缺口。
3. 将匹配的右侧形状像素绘入左侧缺口对应位置，使用右侧形状的颜色。移除右半区的原始形状像素（置为背景）。
4. 填充后，在每个模板的边界框内计数4-连通的完全封闭背景区域（四周全部被非背景像素包围的背景连通分量）。
5. 按封闭孔洞数重涂模板的青(8)像素：0个孔洞→橙(7)，1个孔洞→黄(4)，2个孔洞→栗(9)。填入缺口的彩色像素保持其原色不变。
6. 移除灰(5)分隔线（置为背景）。

**关键洞察**：填充缺口前后，模板内部的封闭孔洞数量会发生变化——缺口是与外部连通的开放区域，填充后可能将原本与外部连通的背景区域封闭成新的孔洞，也可能不改变已有孔洞拓扑。因此必须先正确匹配和填充，才能得到正确的孔洞计数，进而确定模板框体的重涂颜色。

## 新题 5：字形解码作为隐式控制矩阵驱动模板重涂

**组合逻辑**：[图案印章stamp_glyph/编码映射encoding_map](创新：字形不是被展开绘制，而是被解码为颜色信息) → [索引映射index_mapping/行列位置对应row_column_correspondence](已有) → [重涂色recolor/按控制色重涂recolor_by_control](已有)

**来源原语**：图案印章/字形字典/编码映射(dfadab01)、标记字形/形状编码颜色/按形状映射颜色(009d5c81)、索引映射/控制矩阵/模板格点/行列位置对应/按控制色重涂(33b52de3)、模板对象(4ff4c9da, 33b52de3)

**依赖链**：字形形状→解码为颜色→字形的空间位置→映射到模板格点位置→重涂对应模板。若跳过字形解码，无法得到控制颜色；若跳过空间映射，无法确定哪个模板被重涂为什么颜色。两步间接寻址缺一不可。

散布的小字形经形状解码得到颜色，再按字形的空间位置映射到模板格点，重涂对应位置的模板对象。

**输入结构**：黑(0)背景，约18x18。灰(5)模板对象排列为3x3格点（每个模板为3x3边界框内的固定非对称掩码，如缺角矩形或不规则连通形状，所有9个模板形状完全相同；模板间以1列/行背景间隔）。格点占据网格左上方约11x11的区域。在格点右侧和/或下方的空白区域中，散布9个品红(6)小字形，每个为2x2边界框内的2像素图案。字形有三种形状：对角两像素（左上+右下）、竖直两像素（上+下）、水平两像素（左+右）。9个字形在空白区域内按大致的3x3空间布局排列（行间和列间有不等的背景间距）。生成约束：9个字形与9个模板一一对应。

**规则**：
1. 解码每个品红字形的形状为颜色：对角两像素→红(2)，竖直两像素→绿(3)，水平两像素→蓝(1)。此映射需从训练示例中归纳。
2. 按字形的空间布局确定其对应的格点位置：将9个字形的边界框中心按行优先排序（先按中心y坐标从小到大均分为3组，每组内按中心x坐标从小到大排列），得到的序列依次对应格点位置(0,0), (0,1), (0,2), (1,0), ..., (2,2)。
3. 将每个格点位置的模板对象的灰(5)前景像素重涂为该位置字形解码出的颜色。
4. 移除所有品红(6)字形像素（置为背景）。模板内的背景孔洞保持不变。

**关键洞察**：控制矩阵在输入中不以颜色方阵的形式显式存在，而是以一组需要形状解码的品红字形隐式编码。求解者必须先识别字形的形状含义（间接层1：形状→颜色），再将字形的空间排布映射到模板格点（间接层2：位置→索引），才能完成重涂。任一层间接寻址被跳过，输出都将错误。

## 新题 6：长度排名决定描边层数与颜色

**组合逻辑**：[排序sorting/长度排名length_ranking](已有) → [描边outline/拉伸extrude](创新：描边层数由排名决定而非固定为1) + [重涂色recolor/排名决定颜色rank_determines_color](已有) + [冲突优先级conflict_priority](创新：描边重叠区域由排名高者覆盖)

**来源原语**：排序/细条/长度排名/排名决定颜色(ea32f347)、描边/拉伸/画布边界/边缘行列/边缘延伸角落留黑(49d1d64f)、冲突优先级(03560426)

**依赖链**：长度排名→同时决定颜色和描边层数。描边层数改变每个条的视觉占地面积→条间描边可能重叠→由排名高者覆盖。删除排名则无法确定层数和颜色；删除描边则无法产生重叠冲突。

将三条不同长度的灰色细条按长度排名，排名同时决定条的颜色和围绕它的描边层数，描边重叠区域由排名更高的条覆盖。

**输入结构**：黑(0)背景，约14x14。三条灰(5)直线细条（1像素宽，可为水平或竖直），长度各不相同（例如3、5、7像素）。条之间间距为3-5像素（足以容纳部分描边但可能产生重叠）。所有条不接触网格边缘且彼此不接触。生成约束：三条的长度严格不同；排名最高的条的最外层描边不超出网格边界。

**规则**：
1. 按像素长度从短到长排名：最短=排名1，中间=排名2，最长=排名3。
2. 重涂条本身的颜色：排名1→蓝(1)，排名2→红(2)，排名3→绿(3)。
3. 围绕每条画同心矩形描边环，环的层数等于该条的排名值。描边颜色为黄(4)。第1层描边紧贴条外壁（条的每个像素向8个方向扩展1格中的背景像素），第2层紧贴第1层外壁，以此类推。描边包含角落像素。
4. 描边仅在背景像素或已有低优先级描边像素上绘制。若两条的描边区域重叠，排名较高（更长）的条的描边覆盖排名较低者的描边。条本身的彩色像素不被任何描边覆盖。
5. 超出网格边界的描边像素丢弃。

**关键洞察**：排名不仅决定颜色（视觉标签），还决定描边厚度（空间占用），而厚度差异导致不同的重叠模式。最长的条拥有最厚的描边和最高的覆盖优先级，使其描边在视觉上"压制"较短条的描边——但这一压制关系只有在确定排名后才能推断。

## 新题 7：频率过滤后射线穿透变化

**组合逻辑**：[计数counting/频率排序frequency_ranking](已有) → [擦除erase](创新：擦除对象是框内的少数色像素而非独立前景对象) → [射线延伸ray_extend](创新：射线行为因擦除导致的阻挡布局变化而改变) + [遇阻停止stop_at_blocker](已有)

**来源原语**：计数/频率排序/最高频保留余替(9565186b)、擦除(a416fc5b)、射线延伸/菱形框/侧标记/阻挡像素/遇阻停止/框内填充(95755ff2)

**依赖链**：框内像素频率统计→保留最高频色、擦除其余→阻挡像素减少→射线穿透距离变化→最终填充图案不同。若跳过频率过滤，射线在已擦除位置仍被阻挡导致输出错误；若跳过射线，频率过滤的效果不可见。

菱形框内的少数色像素被擦除后，边缘射线因阻挡物减少而穿透更远，产生与擦除前完全不同的填充图案。

**输入结构**：黑(0)背景，约15x15。一个青(8)一像素厚的菱形框（四个顶点分别在边界框的上中、下中、左中、右中位置，边界框约11x11至13x13）。菱形框外侧，紧贴其边界框四条边中点的位置各有1个彩色标记像素（颜色为红(2)或绿(3)，每个标记颜色独立选取）。菱形框内部散布若干单像素前景点，使用2-3种不同颜色（从蓝(1)、黄(4)、橙(7)中选取），总计6-10个内部像素。生成约束：内部像素中恰有一种颜色的数量严格最多（唯一最高频）；其余颜色的像素至少各有1个；至少有一个被擦除像素位于某条射线路径上（即擦除确实改变了射线行为）。

**规则**：
1. 统计菱形框内部所有非背景(0)、非框体(8)像素的颜色频率，找出唯一最高频颜色。
2. 将框内所有非最高频颜色的像素擦除为背景(0)。最高频颜色的像素保留原位。
3. 从每个框外标记像素出发，沿其所在行（左/右标记）或所在列（上/下标记）向菱形内部发射射线。射线仅绘制严格在菱形框内部的背景像素，使用标记颜色。
4. 射线遇到第一个非背景像素（保留的最高频内部像素或菱形框体像素）时停止，不覆盖终点像素。
5. 菱形框体、保留的内部像素和框外标记像素均保持不变。

**关键洞察**：擦除少数色像素后，原本会阻挡射线的位置变成了背景，使射线穿透更远。最终射线图案取决于哪些阻挡物存活——而这由频率比较决定。不对比多个示例，无法确定"保留最高频"这一规则（可能误以为是保留特定颜色或保留特定位置的像素）。

## 新题 8：旋转-平移双参数序列外推

**组合逻辑**：[序列外推sequence_extrapolation](创新：外推对象同时包含平移和旋转两个独立参数) + [旋转rotate](创新：旋转作为序列的隐藏维度而非显式操作) + [裁剪crop](已有：输出为单面板)

**来源原语**：序列外推/面板帧/分隔行/前景精灵/等距堆叠/恒定偏移平移(351d6448)、旋转/旋转关系(a416fc5b, 412b6263)、裁剪(351d6448)

**依赖链**：面板序列中精灵同时发生平移和旋转→必须分离两个变换参数→分别外推→组合得到下一帧。若只外推平移忽略旋转，精灵朝向错误；若只外推旋转忽略平移，精灵位置错误。两个参数必须同时被识别和外推。

四帧面板动画中非对称精灵每帧同时发生恒定平移和90度顺时针旋转，输出为外推的第五帧。

**输入结构**：黑(0)背景，约20x6（高约20，宽约6）。四个等宽面板（每个约4x6像素）由橙(7)全宽分隔行（1像素高）纵向堆叠（从上到下：面板1、分隔行、面板2、分隔行、面板3、分隔行、面板4）。每个面板内有一个红(2)小精灵（3-5像素的4-连通非对称形状，如L形或闪电形——90度旋转后形状可区分地不同）。从面板1到面板4，精灵的边界框左上角位移呈恒定等差：每帧相对前帧平移相同的(dr, dc)向量。同时精灵的形状每帧顺时针旋转90度（以精灵边界框中心为旋转中心）。生成约束：精灵非旋转对称（4个90度旋转朝向各不相同）；四帧中精灵均完全在面板内部；(dr, dc)中至少有一个分量非零；外推的第五帧精灵也完全落在同尺寸面板内。

**规则**：
1. 识别橙(7)全宽分隔行，将输入分割为4个等尺寸面板。
2. 提取每帧中红色精灵的边界框左上角坐标(r_k, c_k)和形状掩码（相对于边界框的像素偏移集合）。
3. 验证帧间平移恒定：(r_{k+1}-r_k, c_{k+1}-c_k)对k=1,2,3均相同，记为(dr, dc)。
4. 验证帧间旋转恒定：将第k帧精灵掩码顺时针旋转90度后，与第k+1帧精灵掩码一致。
5. 输出一个与单面板同尺寸的网格，内容为第五帧：精灵位置为(r_4+dr, c_4+dc)，形状为第四帧精灵掩码再顺时针旋转90度。背景为黑(0)。

**关键洞察**：若精灵具有任何旋转对称性，旋转变换将不可见，因此精灵必须是非对称的。求解者容易只注意到位移的等差规律而忽略每帧的形状旋转——但精灵在四帧中的朝向各不相同，仅靠平移外推无法复现正确的第五帧形状。平移和旋转是序列的两个独立隐含参数，必须同时被识别。
