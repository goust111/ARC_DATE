## 新题 1：交叉遮挡序驱动的环形颜色轮换

**组合逻辑**：[层序推断](已有) + [顺时针轮换](创新：轮换顺序由交叉层序决定而非空间位置) + [重涂色](已有)

**来源原语**：层序推断/直线/交叉点/遮挡层次/唯一序链 ← 22425bda；重涂色/空心方框/内部遮罩/环形连接/顺时针轮换 ← ad173014

**依赖链**：交叉线的可见色 → 推断层序 → 层序定义轮换顺序 → 按此顺序在框间轮换内部遮罩颜色。无法跳过层序推断直接确定轮换方向。

在环形排列的方框之间，根据连接线的交叉遮挡顺序确定颜色轮换方向，将每个方框内部图案的颜色替换为轮换序列中下一个方框的内部颜色。

**输入结构**：约 18x18 网格，背景为黑(0)。4 个灰(5)空心方框（边长 3~5 像素，单像素边框）大致分布在四个象限，各框内部有一个由不同前景色（红(2)、蓝(1)、绿(3)、黄(4)之一）构成的小连通图案（2~4 像素，4-连通，形状各异）。相邻方框之间各有一条单像素宽的彩色直线段（橙(7)、品红(6)、青(8)、栗(9)四种颜色各用一次）作为连接线，连接线两两交叉于网格中部，交叉处可见色由层序决定。四条连接线恰好形成一个环路连接所有方框。生成约束：每条连接线仅在一个点与另一条线交叉，且四条线的层序构成唯一全序。

**规则**：
1. 从连接线的交叉处推断层序：若两条线交叉，交叉点处可见色为上层线的颜色，被遮挡的为下层。
2. 由所有交叉点的上下关系推断唯一的从底到顶全序链（如 橙(7) < 品红(6) < 青(8) < 栗(9)）。
3. 沿全序链从底到顶依次读取每条连接线所连接的两个方框，确定方框的遍历序列——起点为最底层线连接的、在该线两端中行坐标更小的方框，沿环路按层序上升方向遍历。
4. 按遍历序列，将每个方框的内部图案颜色替换为序列中下一个方框的原始内部颜色（末尾方框的颜色替换为首个方框的原始颜色，形成循环）。
5. 仅替换图案颜色，图案形状、位置、方框边框、连接线、背景均不变。

**关键洞察**：轮换方向不由方框的空间位置（如顺时针/逆时针）决定，而由连接线在交叉点的遮挡层序编码——必须先从视觉交叉推断出唯一全序链，才能确定颜色轮换的方向和起点。

## 新题 2：宽高比条件镜像引发跨色包含擦除

**组合逻辑**：[镜像](已有) + [宽高比决定镜像轴](已有) → [包围框包含检测 + 擦除](创新：镜像生成的新对象改变了包含关系)

**来源原语**：镜像/矩形框/角标记/宽高比决定镜像轴 ← 93c31fbe；擦除/连通分量/包围框包含/异色包含则删 ← 9720b24f

**依赖链**：各对象宽高比 → 确定镜像轴 → 执行镜像 → 镜像后对象的包围框扩大 → 新包围框可能包含其他对象 → 包含的异色对象被擦除。跳过镜像则包含关系不成立；跳过擦除则镜像后的重叠区域不清理。

对每个前景对象按其宽高比选择镜像轴进行翻倍镜像，然后擦除镜像后被其他异色对象的包围框完全包含的对象。

**输入结构**：约 20x20 网格，背景为黑(0)。包含 4~6 个互不重叠的单色 8-连通前景对象，每个对象使用不同颜色（从红(2)、蓝(1)、绿(3)、黄(4)、灰(5)、品红(6)中选取）。每个对象由 4~8 个像素构成，形状不规则（非矩形），包围框宽高比各异（有的宽>高，有的高>宽，有的正方形）。各对象之间间距至少 2 像素。生成约束：镜像后至少有一对对象形成严格的单向包围框包含关系，但原始输入中不存在任何包含关系。

**规则**：
1. 对每个前景对象，计算其包围框的宽高比：
   - 宽 > 高：以该对象包围框的底边为轴，将对象向下镜像翻倍（原对象保留，镜像副本紧接下方）。
   - 高 > 宽：以该对象包围框的右边为轴，将对象向右镜像翻倍（原对象保留，镜像副本紧接右方）。
   - 宽 = 高：不镜像，保持原样。
2. 镜像副本使用与原对象相同的颜色。超出网格边界的镜像部分裁剪丢弃。
3. 所有对象完成镜像后，重新计算每个对象的包围框。若对象 A 的包围框完全包含在另一异色对象 B 的包围框内（A 的四边均不超出 B），则将 A 的所有像素擦除为背景色。
4. 包含检测仅考虑严格单向包含（A 在 B 内但 B 不在 A 内）。若两对象包围框恰好相等，则两者均不擦除。
5. 被包含对象按面积从小到大依次擦除。

**关键洞察**：原始输入中没有任何对象被另一对象的包围框包含——包含关系完全由镜像操作创造。必须先完成所有对象的镜像，才能判断哪些对象应被擦除。

## 新题 3：列区带编码光环颜色与绘制优先级

**组合逻辑**：[列位置映射](创新：映射目标从行色变为光环色) + [印章覆盖](已有) + [仅填背景格](创新：绘制顺序由列区带优先级决定)

**来源原语**：重涂色/标记像素/列位置映射/标记列决定整行色 ← a85d4709；印章覆盖/标记像素/光环区域/邻域扩展/仅填背景格 ← dc1df850

**依赖链**：标记像素列位置 → 所在列区带 → 决定光环颜色 + 绘制优先级 → 按优先级顺序展开光环 → 先绘制的光环占据背景格，阻挡后绘制的光环扩展。去掉列位置映射则光环颜色无法确定；去掉优先级顺序则重叠区域结果不确定。

根据灰色标记像素所在的列区带确定其光环颜色和绘制优先级，然后按优先级顺序将每个标记扩展为 3x3 彩色光环。

**输入结构**：约 12x12 网格，背景为黑(0)。网格列被均分为 3 个等宽列区带（左区列 0~3、中区列 4~7、右区列 8~11）。第一行的每个区带首列有一个颜色指示像素：左区首列 = 红(2)，中区首列 = 蓝(1)，右区首列 = 绿(3)。网格中（不在第一行）散布 4~6 个灰(5)标记像素。生成约束：至少有一对标记像素分属不同列区带且切比雪夫距离 = 2，确保存在跨颜色的光环重叠。

**规则**：
1. 每个灰(5)标记像素根据其所在列确定列区带（列 0~3 为左区，列 4~7 为中区，列 8~11 为右区）。
2. 该标记像素的光环颜色为其所在区带的指示色（左区 → 红(2)，中区 → 蓝(1)，右区 → 绿(3)）。
3. 绘制优先级：左区标记先绘制，中区次之，右区最后。同一区带内，按从上到下、从左到右的顺序绘制。
4. 按优先级顺序，将每个标记像素扩展为以该像素为中心的 3x3 光环（切比雪夫距离 <= 1 的所有格子），填充光环颜色。
5. 光环仅填充背景色(0)的格子——已有前景像素（包括指示像素、其他灰标记、先绘制的光环）不被覆盖。
6. 标记像素自身也被重涂为其光环颜色。
7. 第一行的颜色指示像素保留不变。

**关键洞察**：标记像素的列位置同时编码了两个信息——光环颜色和绘制优先级。重叠区域的最终颜色由绘制优先级决定（优先级高的区带先绘制并占据共享的背景格），单看一个示例可能无法区分这种优先级机制与其他冲突解决方式。

## 新题 4：过滤空心框后逐个按宽高比镜像再排序拼接

**组合逻辑**：[忽略干扰项 + 仅保留空心对象](已有) → [宽高比决定镜像轴](创新：逐对象独立决定镜像方向) → [排序 + 拼接](创新：排序依据为镜像后面积)

**来源原语**：排序/拼接/空心矩形/实心方块/仅保留空心对象/忽略干扰项/沿主轴排列 ← a680ac02；镜像/宽高比决定镜像轴 ← 93c31fbe；裁剪 ← 28bf18c6

**依赖链**：过滤 → 确定存活对象 → 每个对象独立判断宽高比 → 独立镜像 → 镜像改变尺寸 → 新尺寸决定排序 → 排序决定拼接顺序。移除过滤则干扰项混入；移除镜像则排序基于原始面积；移除排序则拼接顺序无定义。

丢弃所有实心方块干扰项，对每个留存的空心矩形框按其宽高比独立选择镜像轴翻倍，再按镜像后的像素面积从小到大排列并水平拼接。

**输入结构**：约 25x25 网格，背景为黑(0)。包含 5~7 个互不相邻的单色对象，每个对象使用不同颜色（红(2)、蓝(1)、绿(3)、黄(4)、灰(5)、橙(7)中选取）。其中 3~4 个是空心矩形框（单像素边框，内部为背景色，尺寸各异如 4x6、6x3、5x5 等），其余是实心方块（包围框内无背景像素）。生成约束：空心框的宽高比不全相同，且至少一个宽>高、一个高>宽。

**规则**：
1. 识别所有 8-连通单色对象。丢弃实心对象（包围框内无背景像素的对象），仅保留空心矩形框（包围框内含有背景像素的对象）。
2. 裁剪每个空心框至其包围框。
3. 对每个裁剪后的空心框判断宽高比：
   - 宽 > 高：将裁剪结果水平翻转并拼接在右侧（结果宽度翻倍）。
   - 高 > 宽：将裁剪结果垂直翻转并拼接在下方（结果高度翻倍）。
   - 宽 = 高：保持原样，不镜像。
4. 计算每个镜像后对象的非背景像素总数（面积）。
5. 按面积从小到大排序。面积相同时，按原始包围框左上角的列坐标从小到大排序。
6. 将排序后的对象从左到右水平边对边拼接，顶部对齐。对象之间无间隔。输出高度等于最高对象的高度，较矮对象下方填充背景色。

**关键洞察**：每个空心框的镜像方向不同（由各自宽高比独立决定），导致不同对象经历异质变换，最终面积和形状各异。排序依据是镜像后而非镜像前的面积，必须先完成异质镜像才能确定正确顺序。

## 新题 5：双面板叠加联合驱动列涂色并平铺

**组合逻辑**：[透明叠加](已有) → [含前景列整列涂色](创新：涂色依据来自叠加联合而非原始前景) → [平铺](已有)

**来源原语**：透明叠加/面板/分隔列/前景掩码/对齐/双面背景交集标记 ← e133d23d；重涂色/平铺/前景列/列选择/含前景列整列涂色 ← f5b8619d

**依赖链**：左右面板叠加 → 联合掩码 → 联合掩码决定哪些列为前景列 → 前景列整列涂色 → 涂色结果平铺为 2x2。去掉叠加则前景列集合不同；去掉涂色则无法生成连续列条纹；去掉平铺则输出尺寸错误。

将分隔列两侧的面板前景掩码叠加取联合，在联合结果中对含前景像素的列整列涂青色，然后将结果平铺为 2x2。

**输入结构**：约 7x13 网格（宽度为奇数），背景为黑(0)。中间列为灰(5)垂直分隔列，将剩余列均分为宽度各 6 列的左右两个面板。左面板含红(2)前景像素构成的小连通图案（3~6 像素，4-连通），右面板含蓝(1)前景像素构成的小连通图案（3~6 像素，4-连通，形状与左面板不同）。两面板的前景图案在部分列上重叠、部分列上不重叠（即左面板某些列有前景但对应右面板列无前景，反之亦然）。生成约束：联合后的前景列数严格多于单侧面板的前景列数。

**规则**：
1. 去掉灰(5)分隔列，将左右面板按对应位置对齐（左面板第 k 列对应右面板第 k 列）。
2. 对齐后，逐格取联合：若对应的左面板格或右面板格中任一为前景（非背景），则该位置为前景。前景色统一重涂为红(2)，背景保持黑(0)。
3. 在联合结果中，识别所有包含至少一个红(2)前景像素的列。
4. 对这些列中的所有黑(0)背景格涂为青(8)。已有的红(2)前景像素保持不变。
5. 不含前景像素的列保持全黑(0)不变。
6. 将上述处理后的面板（6 列 x 7 行）平铺为 2x2：水平复制两份、垂直复制两份，输出为 12 列 x 14 行的网格。

**关键洞察**：联合操作合并了两侧的前景分布，使得某些原本在单侧为纯背景的列在联合后变为前景列，进而被整列涂色。涂色结果中的列条纹图案无法从单侧面板独立推断——必须理解双面板叠加联合的机制。

## 新题 6：内层尺寸同时驱动外扩与内部图案放大

**组合逻辑**：[同心扩展](已有) + [像素放大](创新：放大倍率由内层矩形短边长度决定，且放大后需适配扩展后的框内空间)

**来源原语**：同心扩展/填充/矩形框/内部矩形/外围层/严格内嵌/同心嵌套/内尺寸定扩展量 ← 3a301edc；裁剪/像素放大/矩形边框/内部图案/图案在框内/图案倍增填框 ← e7a25a18

**依赖链**：内部矩形尺寸 → 决定外扩厚度（同心扩展）+ 决定内部图案放大倍率（像素放大） → 外扩改变框内可用空间 → 放大后的图案必须适配新空间。两个操作共享同一个参数来源（内部矩形尺寸），彼此约束。

在同心双色矩形结构中，以内部矩形的短边长度作为倍率放大框内的种子图案，同时以内部矩形的尺寸向外扩展一层同色边框。

**输入结构**：约 20x20 网格，背景为黑(0)。网格中央有一个同心双色矩形结构：外层为蓝(1)单像素边框矩形（约 8x10），内部为绿(3)实心矩形（约 3x4，严格位于蓝色边框内部且不接触边框）。绿色矩形内部有一个由红(2)像素构成的种子图案（紧凑包围框为 2x2 区域内的 2~3 个像素，形状各示例不同）。蓝色边框与绿色矩形之间的间隙为背景色。生成约束：内部绿色矩形的短边长度为 2 或 3（作为放大倍率）；外扩后的结构不超出网格边界。

**规则**：
1. 识别同心结构：蓝(1)外框、绿(3)内部矩形、红(2)种子图案。
2. 读取绿色内部矩形的短边长度 k（如 3x4 矩形的短边为 3）。
3. 将红(2)种子图案像素放大 k 倍（每个红色像素变为 k x k 的红色方块），写入绿色矩形内部，从绿色矩形内部左上角开始放置。放大后超出绿色矩形范围的部分裁剪丢弃。绿色矩形内未被放大图案覆盖的区域保持绿(3)。
4. 以绿色矩形的尺寸向外扩展蓝色边框：在当前蓝色边框外围，上下各增加绿色矩形高度行数的像素行，左右各增加绿色矩形宽度列数的像素列。新增区域填充绿(3)。
5. 若外扩超出网格边界，则裁剪到网格边界内。
6. 原有蓝色边框保留、绿色矩形（未被放大图案覆盖的部分）保留、背景区域不变。

**关键洞察**：绿色内部矩形的尺寸是一个双重参数——它的短边决定了种子图案的放大倍率，它的宽高决定了外层边框向外扩展的厚度。必须同时理解这两个作用才能正确重建输出。

## 新题 7：面积阈值重涂色改变包含擦除的颜色条件

**组合逻辑**：[计数 + 面积超阈值则变色](已有) → [包围框包含 + 异色包含则删](创新：重涂色改变了"异色"判定，使原本安全的对象变得可被擦除)

**来源原语**：重涂色/计数/前景对象/连通分量/面积超阈值则变色 ← ae58858e；擦除/连通分量/包围框/包围框包含/异色包含则删 ← 9720b24f

**依赖链**：统计连通分量面积 → 面积超阈值的对象重涂色 → 重涂色改变对象颜色 → 包含关系中"异色"条件因颜色变化而改变 → 原本同色（安全）的包含对变为异色（触发擦除）。跳过重涂色则包含关系不触发擦除；跳过擦除则重涂色后不做清理。

先将面积达到阈值的前景对象重涂为新颜色，再擦除被异色对象的包围框完全包含的对象——重涂色改变了哪些对象对构成"异色"。

**输入结构**：约 15x15 网格，背景为黑(0)。包含 5~7 个红(2)色的 4-连通前景对象，面积从 1 到 6 像素不等，形状各异（非固定形状，由像素数范围和连通性定义）。部分对象之间存在包围框包含关系（小对象的包围框完全在大对象的包围框内部）。关键特征：所有对象初始均为红色（同色），因此初始状态下"异色包含"条件对任何一对对象都不触发。生成约束：至少有一对包含关系中，外层对象面积 >= 4 而内层对象面积 < 4（确保重涂色后出现异色包含）。

**规则**：
1. 找出所有 4-连通的红(2)前景对象，计算每个对象的面积（像素数）。
2. 将面积 >= 4 的红(2)对象重涂为品红(6)。面积 < 4 的对象保持红(2)不变。
3. 重涂色后，重新检查所有前景对象的包围框包含关系：若对象 A 的包围框完全包含在对象 B 的包围框内，且 A 与 B 颜色不同，则将 A 擦除（像素设为背景色黑(0)）。
4. 若某对象被多个不同对象的包围框同时包含，只要与任一包含者异色即触发擦除。
5. 擦除按被包含对象的面积从小到大依次执行，不进行二次迭代检查。

**关键洞察**：在原始输入中所有对象同色（红），包围框包含不会触发擦除。面积阈值重涂色将部分对象变为品红后，原本"同色安全"的包含关系变为"异色危险"——被包含的小对象或大对象因与包含者颜色不同而被擦除。必须先理解重涂色规则，才能预测哪些对象最终被擦除。

## 新题 8：边界图例的双重编码——颜色替换与镜像轴选择

**组合逻辑**：[图例色替换](已有) + [镜像](已有) + [边缘位置决定轴](创新：图例的边界位置同时编码镜像轴方向)

**来源原语**：裁剪/重涂色/多色目标对象/微型图例/颜色替换映射/图例色替换 ← e9b4f6fc；镜像/擦除/矩形框/宽高比决定镜像轴 ← 93c31fbe；滑动对齐/边界锚点/边缘位置决定轴 ← 581f7754

**依赖链**：图例位于网格哪条边 → 决定对应精灵体的镜像轴；图例的左右颜色 → 决定精灵体的颜色替换映射。两条信息从同一个图例元素中同时提取，缺一不可。去掉图例位置则镜像轴不确定；去掉颜色映射则替换不正确。

每个边界图例同时编码两条信息：其颜色对表示精灵体的颜色替换映射，其所在边的方向表示精灵体的镜像轴。

**输入结构**：约 16x16 网格，背景为黑(0)。网格内部有 2~3 个多色精灵体（每个由 2 种前景色构成，4-连通，5~10 像素总计），各精灵体互不相邻。网格边界（第一行、最后一行、第一列、最后一列）上有 2~3 个二像素图例色块（domino）——位于上边界或下边界的图例为水平排列（左右两像素），位于左边界或右边界的图例为垂直排列（上下两像素）。每个图例的一种颜色（源色）在恰好一个精灵体中出现（作为该精灵体的次要色），以此匹配图例与精灵体。生成约束：每个精灵体恰好匹配一个图例；至少一个图例在水平边界（上/下），至少一个在垂直边界（左/右）。

**规则**：
1. 识别所有边界图例（位于网格边缘的二像素色块）和内部精灵体。
2. 每个图例按阅读顺序读取为 [替换色, 源色]：水平图例从左到右，垂直图例从上到下。
3. 通过源色匹配图例与精灵体：精灵体中包含源色像素的那个精灵体是目标。
4. 颜色替换：将目标精灵体中所有源色像素替换为替换色。精灵体的另一种颜色（主色）保持不变。
5. 镜像轴由图例所在边决定：
   - 图例在上边界或下边界（水平边） → 将精灵体以其包围框底边为轴向下镜像翻倍（原图保留在上方，镜像副本紧接下方）。
   - 图例在左边界或右边界（垂直边） → 将精灵体以其包围框右边为轴向右镜像翻倍（原图保留在左方，镜像副本紧接右方）。
6. 先执行颜色替换，再执行镜像。精灵体的原始位置被替换+镜像后的结果覆盖。
7. 图例像素在输出中擦除为背景色。
8. 镜像后超出网格边界的部分裁剪丢弃。

**关键洞察**：每个图例是一个双重编码元素——它的颜色对编码替换映射（参照微型图例机制），它在网格边界上的位置编码镜像轴方向（参照边缘位置决定轴机制）。求解者必须同时解码这两条独立信息并将它们施加于匹配的精灵体。

## 新题 9：行内连通分量数选择该行的颜色置换映射

**组合逻辑**：[计数](创新：逐行计数连通分量作为决策节点) → [固定颜色置换映射](创新：不同计数值对应不同置换)

**来源原语**：计数/连通分量/前景对象/面积超阈值则变色 ← ae58858e；重涂色/全局像素/固定颜色置换映射 ← 0d3d703e

**依赖链**：逐行统计连通分量数 → 分量数决定该行适用哪种颜色置换 → 对该行所有前景像素执行对应置换。跳过计数则置换无法确定（单一全局置换不正确）；跳过置换则计数无用途。两个操作耦合在条件层面：分量数是操作选择的决策节点。

统计每行中独立前景段的数量，根据数量从预设的多套颜色置换映射中选择一套应用于该行。

**输入结构**：约 10x10 网格，背景为黑(0)。前景使用三种颜色：红(2)、蓝(1)、绿(3)。每行包含 1~3 个前景像素段（同一行内的一段连续非背景像素算一个段；被背景像素隔开的两段算两个段；相邻但颜色不同的像素属于同一段而非分开计算）。不同行的段数不全相同，且三种段数（1、2、3）在不同行中均有出现。生成约束：每种段数至少出现两行，以便从多个示例对比归纳每种段数对应的置换映射。

**规则**：
1. 逐行扫描，统计该行中的前景段数（一段定义为同一行内连续的非背景像素序列，被至少一个背景像素隔开则算两段）。
2. 根据段数选择颜色置换映射，对该行所有前景像素执行置换：
   - 段数 = 1：红(2) → 蓝(1)，蓝(1) → 绿(3)，绿(3) → 红(2)（三色循环右移）。
   - 段数 = 2：红(2) → 绿(3)，蓝(1) → 红(2)，绿(3) → 蓝(1)（三色循环左移）。
   - 段数 = 3：红(2) ↔ 蓝(1) 互换，绿(3) 保持不变。
3. 背景像素(0)不受置换影响，始终保持为黑(0)。
4. 空行（无前景像素，段数 = 0）保持不变。

**关键洞察**：每行适用的颜色置换映射不同，且由该行的几何结构（段数）隐式决定，而非由行的位置或颜色本身决定。仅看单行无法确定使用了哪种置换——必须对比多行的输入输出来归纳出"段数 → 置换映射"的对应关系。

## 新题 10：滑动对齐至锚点后沿控制条方向平铺

**组合逻辑**：[滑动对齐](已有) → [平铺](创新：平铺起点为滑动终点，平铺方向与滑动方向正交)

**来源原语**：滑动对齐/多色精灵体/边界锚点/标记像素/颜色匹配锚点/边缘位置决定轴 ← 581f7754；平铺/擦除/精灵体/控制条/跨度对齐/沿控制条重复 ← c62e2108

**依赖链**：匹配精灵体标记色与边界锚点 → 锚点边缘位置决定滑动轴 → 滑动至对齐 → 滑动终点成为平铺起点 → 控制条跨度决定平铺方向和范围 → 沿控制条方向周期重复。去掉滑动则精灵体不在正确起始位置上；去掉平铺则仅有单个精灵体而非周期图案。

将每个多色精灵体滑动对齐至匹配的边界锚点，然后从新位置出发沿垂直于滑动方向的控制条方向周期平铺。

**输入结构**：约 18x18 网格，背景为黑(0)。内部有 2 个多色精灵体（每个由一种主色和一个单像素标记色构成，4-连通，总计 4~6 像素），精灵体互不相邻。网格边界上有 2 个孤立锚点像素（非背景色，4-邻域全为背景色或网格外），颜色分别与两个精灵体的标记色匹配。网格边界上还有 2 条单像素宽的灰(5)控制条，每条控制条位于与对应锚点不同的边上。生成约束：一个锚点在上边界（对应水平滑动），其匹配控制条在左或右边界（垂直方向，跨度与该精灵体滑动后的行跨度一致）；另一个锚点在左边界（对应垂直滑动），其匹配控制条在上或下边界（水平方向，跨度与该精灵体滑动后的列跨度一致）。

**规则**：
1. 每个精灵体通过标记像素颜色匹配到一个边界锚点。
2. 锚点的边缘位置决定滑动轴：上/下边界锚点 → 精灵体水平滑动，使标记像素列对齐锚点列；左/右边界锚点 → 精灵体垂直滑动，使标记像素行对齐锚点行。
3. 精灵体整体平移至对齐位置，原始位置填充为背景色。
4. 找到与滑动后精灵体跨度对齐的控制条：精灵体的行跨度与某条控制条的行跨度一致，或精灵体的列跨度与某条控制条的列跨度一致。
5. 从精灵体的新位置出发，沿控制条的延伸方向周期重复精灵体：控制条在左/右边界 → 沿竖直方向（向控制条所在边方向）重复；控制条在上/下边界 → 沿水平方向（向控制条所在边方向）重复。重复直至到达控制条所在边界或网格边界。
6. 平铺时仅填充背景格，不覆盖已有前景像素。精灵体图案中的背景像素在平铺时保持为背景。
7. 控制条在输出中被擦除（设为背景色），锚点像素保留。

**关键洞察**：滑动方向与平铺方向正交——锚点决定了"去哪"（滑动终点），控制条决定了"沿哪个方向重复"（平铺方向）。两者协同作用于同一个精灵体，缺一不可，且这种正交耦合在任一源题中都不存在。
