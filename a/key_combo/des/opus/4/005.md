## 新题 1：标记排列同时编码膨胀距离与膨胀轴

**组合逻辑**：[counting + embedded_marker_count](已有) → [orientation_determines_direction](创新：原用于判断 domino 延伸方向，此处改为判断标记像素排列方向以选择膨胀轴) → [expansion_fill](创新：原为四面均匀膨胀，此处改为仅沿选定轴的两侧膨胀)

**来源原语**：counting, embedded_marker_count, control_pixel, rectangular_block, count_determines_expansion（来自 52fd389e）；orientation_determines_direction（来自 9344f635）

**依赖链**：标记像素的数量决定膨胀距离 d，标记像素在块内的空间排列（同行 vs 同列）决定膨胀轴（水平 vs 垂直）。两个参数从同一组标记中同时提取，缺少任一参数均无法确定输出。

一句话总结：每个黄色矩形块内的异色标记像素同时编码膨胀距离（数量）和膨胀方向（排列轴向），按此对块做单轴扩展并涂上标记颜色。

**输入结构**：
- 黑(0)背景，约 15x15 网格。
- 散布 2-4 个互不相邻的实心黄(4)矩形块（每个块 4-8 像素，至少 2 行 2 列）。
- 每个块内恰好包含 1-3 个同色非黄控制像素，且这些控制像素严格排成一条直线——要么全在同一行（水平排列），要么全在同一列（垂直排列）。不同块的控制颜色互不相同，可选蓝(1)、红(2)、绿(3)、灰(5)等。
- 生成约束：每个块的膨胀范围不超出网格边界，不同块的膨胀结果互不重叠。

**规则**：
1. 对每个黄色矩形块，找到其内部所有非黄控制像素，记其颜色为 C、数量为 d。
2. 判断控制像素的排列方向：若全在同一行，则膨胀轴为水平方向；若全在同一列，则膨胀轴为垂直方向。
3. 沿膨胀轴的两侧各扩展 d 个像素：若膨胀轴为水平，则将块的包围盒向左和向右各扩展 d 列；若膨胀轴为垂直，则向上和向下各扩展 d 行。非膨胀轴方向不扩展。
4. 将扩展区域（不含原块区域）涂为颜色 C。
5. 恢复原始黄色像素和控制像素，使之覆盖在扩展区域之上。
6. 处理顺序不影响结果（生成约束保证无重叠）。

**关键洞察**：同一组标记像素同时承载两个独立参数——数量编码距离、空间排列编码方向——必须同时解码才能确定唯一输出。仅看一个示例时，水平排列+2个标记的块与垂直排列+2个标记的块产生完全不同的膨胀形态，需对比多个示例才能归纳出排列方向与膨胀轴的对应关系。

## 新题 2：拓扑嵌套深度决定配对色映射的启用与否

**组合逻辑**：[flood_fill + topological_in_out](已有) → [counting](创新：计算嵌套深度而非像素数) → [invert + paired_color_mapping](创新：原为全局无条件应用，此处由嵌套深度奇偶性条件触发)

**来源原语**：flood_fill, topological_in_out, enclosed_region, boundary, fill_enclosed_only（来自 00d62c1b）；invert, paired_color_mapping, mask（来自 6ea4a07e）；counting（来自 52fd389e / 37ce87bb）

**依赖链**：绿色边界构成多层嵌套的封闭区域 → 计算每个区域的嵌套深度 → 深度的奇偶性决定该区域使用配对色映射还是保留原色 → 最终填充颜色同时依赖拓扑分析和颜色映射规则。

一句话总结：嵌套绿色边界划分出不同深度的封闭区域，奇数深度区域按配对色映射填充其内部标记颜色，偶数深度区域直接填充标记颜色本身。

**输入结构**：
- 黑(0)背景，约 12x12 网格。
- 绿(3)像素构成若干不相交的闭合边界环，部分边界完全嵌套在另一个边界的内部，形成 1-3 层嵌套（最外层深度=1，内一层深度=2，以此类推）。
- 每个最内层封闭区域（即不再包含更小封闭区域的区域）的内部恰好有一个孤立标记像素，颜色为青(8)、绿(3)或灰(5)之一。注意：当标记颜色为绿(3)时，该像素不与任何绿色边界 4-连通相邻，以此区分标记和边界。
- 非最内层的区域（即包含子区域的区域）不含标记像素。
- 生成约束：嵌套结构清晰，每个绿色边界构成严格闭合的环（4-连通），边界之间不共享像素。

**规则**：
1. 识别所有绿色闭合边界及其围成的封闭区域。计算每个区域的嵌套深度：不被任何其他封闭区域包含的区域深度为 1，被恰好 k 个区域包含的区域深度为 k+1。
2. 对每个包含标记像素的最内层区域，读取标记像素颜色 M。
3. 若该区域的嵌套深度为奇数：使用配对色映射——青(8)→红(2)，绿(3)→蓝(1)，灰(5)→黄(4)——将映射后的颜色填充到该区域所有黑色内部像素。
4. 若该区域的嵌套深度为偶数：直接将颜色 M 填充到该区域所有黑色内部像素。
5. 标记像素本身被填充色覆盖（即融入填充区域）。
6. 非最内层区域中不属于任何子区域的黑色像素保持黑色不变。
7. 所有绿色边界像素保持不变。

**关键洞察**：标记颜色相同的两个区域可能因嵌套深度不同而产生不同的输出颜色。仅凭一个示例中一个区域的 输入标记→输出颜色 映射，无法判断是固定映射还是条件映射，必须对比不同深度的同色标记才能归纳出奇偶分支规则。

## 新题 3：脊柱射线被骨架格子边界截断

**组合逻辑**：[draw_line + connect_to_spine + shared_row_col_spine](已有) → [scaffold_lattice](创新：原用于标记对齐，此处作为射线传播的物理障碍) → 射线截断规则（创新：源题中射线无阻挡地到达脊柱，此处骨架边界线截断射线）

**来源原语**：draw_line, connect_to_spine, shared_row_col_spine, spine_segment, control_pixel（来自 bf89d739）；scaffold_lattice, hollow_cell_frame（来自 97239e3d）；ray_cast, canvas_boundary（来自 8d510a79）

**依赖链**：红色控制像素中的共行/共列对定义脊柱方向 → 其余红色像素需向脊柱发射垂直射线 → 骨架的灰色边界线阻挡射线传播 → 射线在碰到骨架边界时截断而非到达脊柱。脊柱结构决定射线方向，骨架结构决定射线长度，两者缺一不可。

一句话总结：在灰色骨架格子中，红色控制像素组成的脊柱结构发射垂直连接线，但连接线遇到骨架边界行/列时被截断。

**输入结构**：
- 黑(0)背景，约 18x18 网格。
- 灰(5)像素构成规则的骨架格子：由等间距的完整行和完整列组成（例如每隔 4 行/列有一条灰色线），将网格分割成若干矩形单元格。
- 红(2)控制像素分布在骨架单元格的内部（不在灰色线上）。其中恰好有两个红色像素共享同一行或同一列（且该行/列上无其他红色像素），这对像素定义脊柱段。
- 其余红色像素分布在脊柱的垂直方向上、位于脊柱跨度范围之内。
- 生成约束：脊柱方向上的两个端点位于不同的骨架单元格中。其余红色像素与脊柱之间至少间隔一条骨架边界线（保证截断效果可见）。

**规则**：
1. 找到共享同一行或同一列的红色像素对，确定脊柱方向（水平或垂直）。将这对像素之间的黑色像素涂为绿(3)，但遇到灰色骨架边界线时跳过该灰色像素继续画线（脊柱线穿越骨架边界）。
2. 对每个非脊柱的红色像素，沿垂直于脊柱的方向向脊柱发射射线。
3. 射线逐像素前进：若下一个像素是黑(0)，将其涂为绿(3)并继续；若下一个像素是灰(5)骨架边界线，射线停止，该灰色像素保持不变。
4. 若射线在到达脊柱之前未遇到骨架边界，则射线一直画到脊柱为止（脊柱上的绿色像素已存在则不变）。
5. 所有红色像素保持红色，所有灰色骨架像素保持灰色。

**关键洞察**：与源题（bf89d739）中射线无阻碍到达脊柱不同，骨架格子将网格分隔成隔间，射线只能在本隔间内传播。求解者必须同时识别脊柱结构（确定射线方向）和骨架结构（确定射线终止条件），两者共同决定每条射线的长度。

## 新题 4：周期平铺后由定向标记引发局部相移

**组合逻辑**：[tile + periodic_repeat + seed_motif](已有) → [orientation_determines_direction + micro_marker](创新：原用于决定 bar 延伸的行/列，此处 domino 朝向编码平铺图案的相移方向——水平 domino 触发其所在行的水平相移，垂直 domino 触发其所在列的垂直相移)

**来源原语**：tile, periodic_repeat, seed_motif, fill_grid（来自 9b30e358）；orientation_determines_direction, micro_marker, row_column_bar（来自 9344f635）

**依赖链**：底部种子图案确定平铺周期 → 先用种子图案填满整个网格 → domino 标记的朝向决定相移方向（行移 vs 列移） → 相移改变局部平铺相位。若不先识别平铺周期，相移量无法定义；若不解读 domino 朝向，不知道对哪些行/列执行何种移位。

一句话总结：底部种子图案向上周期平铺填满网格，然后品红色 domino 标记在其所在行或列触发 1 像素的循环相移，朝向决定移位方向。

**输入结构**：
- 黑(0)背景，约 15x15 网格。
- 网格底部若干连续行（例如 3-5 行）包含非黑前景色像素，构成种子图案（motif）。种子图案的行高度为 H。
- 种子图案上方是空白的黑色区域（网格总高度是 H 的整数倍，保证平铺无余）。
- 空白区域中散布 1-3 个品红(6) domino 标记（每个 domino 是 2 个 4-连通的品红像素）。domino 要么水平（同一行相邻两列），要么垂直（同一列相邻两行）。
- 生成约束：不同 domino 不在同一行或同一列上（保证相移不冲突）。domino 所在位置不在种子图案所在的行内。

**规则**：
1. 识别底部种子图案块（最下方连续的非空行组成的矩形区域，高度 H，宽度=网格宽度），包含其中的黑色像素。
2. 将种子图案以周期 H 向上重复平铺，填满整个网格。此时得到基础平铺结果。
3. 对每个品红 domino：
   - 若 domino 为水平方向：将其所在行的所有像素向右循环移动 1 格（最右侧像素回到最左侧）。
   - 若 domino 为垂直方向：将其所在列的所有像素向下循环移动 1 格（最底部像素回到最顶部）。
4. 移位操作按 domino 从左上到右下的阅读顺序依次执行。
5. 最终将所有品红 domino 像素替换为该位置在移位后的平铺颜色值（即 domino 标记不出现在输出中）。

**关键洞察**：平铺图案本身是全局规律性的，domino 引入的局部相移打破了周期性。仅看一个示例可能将相移行/列误解为平铺错误或特殊边界处理，必须对比多个示例中 domino 位置、朝向与相移方向的对应关系才能归纳规则。

## 新题 5：定向 domino 在骨架格子中选择行/列填充，交叉处行优先

**组合逻辑**：[scaffold_lattice + hollow_cell_frame + marker_lattice_align](已有) → [orientation_determines_direction](创新：原选择网格行/列绘制 bar，此处选择骨架格子的单元格行/列) → [fill](已有) → [row_overrides_column + conflict_priority](已有，但作用于骨架单元格而非裸像素)

**来源原语**：scaffold_lattice, hollow_cell_frame, marker_lattice_align, marker_span_extent（来自 97239e3d）；orientation_determines_direction, micro_marker, row_overrides_column, conflict_priority（来自 9344f635）；fill（来自 37ce87bb）

**依赖链**：骨架格子定义单元格坐标系 → domino 位于骨架边界线上，其朝向决定选择单元格行还是单元格列 → 选中的单元格中心像素填充 domino 颜色 → 行选择和列选择可能在同一单元格交叉，行颜色覆盖列颜色。

一句话总结：骨架格子的边界线上放置彩色 domino 标记，水平 domino 选中该边界行的所有单元格，垂直 domino 选中该边界列的所有单元格，填充单元格中心，交叉处行颜色优先。

**输入结构**：
- 黑(0)背景，约 19x19 网格。
- 蓝(1)像素构成规则骨架格子：等间距的完整行和完整列（例如每 4 像素一条蓝线），将网格分割成若干 3x3 的空心单元格（蓝色线是单元格之间的边界）。每个单元格中心是一个黑色像素。
- 2-4 个彩色 domino（每个 2 像素，4-连通，颜色为红(2)、绿(3)、黄(4)、橙(7)等，各不相同）放置在蓝色边界线上（即 domino 的两个像素都在蓝色线位置，覆盖了原本的蓝色）。
- 水平 domino（同行相邻两列）位于水平边界线上；垂直 domino（同列相邻两行）位于垂直边界线上。
- 生成约束：每条骨架边界行/列上最多一个 domino。

**规则**：
1. 识别骨架格子结构，确定单元格的行列坐标。
2. 对每个 domino，确定其位于哪条骨架边界线上：
   - 水平 domino 位于某水平边界线 → 选中该边界线相邻的上方一整行单元格和下方一整行单元格中，domino 实际所在的那一侧行（domino 在两条相邻单元格行之间的边界上，选中该边界两侧的全部单元格）。简化处理：选中该水平边界线上方紧邻的那一整行单元格。
   - 垂直 domino 位于某垂直边界线 → 选中该垂直边界线左侧紧邻的那一整列单元格。
3. 将选中的每个单元格的中心像素涂为该 domino 的颜色。
4. 先处理所有垂直 domino（填充列），再处理所有水平 domino（填充行）。因此在行列交叉的单元格处，水平 domino 的颜色覆盖垂直 domino 的颜色。
5. 所有蓝色骨架像素保持不变（被 domino 覆盖的位置保留 domino 颜色）。未被选中的单元格中心保持黑色。

**关键洞察**：domino 的作用不是直接画一条像素线，而是通过骨架格子的坐标映射，选中一整行/列的离散单元格进行填充。交叉单元格的行优先规则必须通过对比含交叉与不含交叉的示例才能归纳出。

## 新题 6：标记数量奇偶性分支决定同心方块的变换类型

**组合逻辑**：[counting + embedded_marker_count](已有) → 奇偶分支判断（创新：源题中 swap 和 grow 总是同时执行，此处由标记计数的奇偶性决定执行哪一个） → [inner_outer_swap](条件触发) / [grow](条件触发)

**来源原语**：inner_outer_swap, concentric_layer, outward_rect, grow, border_core_swap_extend（来自 3befdf3e）；counting, embedded_marker_count, control_pixel, count_determines_expansion（来自 52fd389e）

**依赖链**：灰色标记数量 → 奇数触发颜色互换（不生长）；偶数（且>0）触发向外生长（不互换），生长距离=数量/2 → 变换类型和变换参数都由同一组标记编码，缺少计数则无法选择分支。

一句话总结：每个同心方块图案内的灰色标记数量决定对该图案执行颜色互换还是向外生长，且生长距离也由数量编码。

**输入结构**：
- 黑(0)背景，约 18x18 网格。
- 2-4 个互相分离的方块图案。每个图案由一个 3x3 的实心内核（颜色 A）和一圈 1 像素宽的外框（颜色 B）组成，整体为 5x5。A 和 B 都不是黑(0)或灰(5)，且不同图案的 (A, B) 颜色对互不相同。
- 每个图案的内核（3x3 区域）中有 0-4 个像素被替换为灰(5)标记像素（其余内核像素保持颜色 A）。
- 生成约束：图案之间留有足够间距（至少 4 像素），确保生长后不重叠、不超出网格边界。标记数量在不同图案之间不全相同，且至少包含一个奇数和一个偶数（>0）。

**规则**：
1. 对每个方块图案，计算其内核中灰(5)标记像素的数量 n。
2. 若 n = 0：图案保持不变。
3. 若 n 为奇数：执行颜色互换——将内核颜色 A 改为 B，外框颜色 B 改为 A。不向外生长。灰色标记像素被替换为互换后的内核颜色（即颜色 B）。
4. 若 n 为偶数且 n > 0：不执行颜色互换——保持原色。从外框的四条边各向外延伸 n/2 个像素的矩形条，延伸区域涂为外框颜色 B。灰色标记像素被替换为内核颜色 A。
5. 处理顺序不影响结果（生成约束保证无重叠）。

**关键洞察**：源题（3befdf3e）中颜色互换和向外生长始终绑定执行。本题将二者拆解为互斥分支，由标记计数的奇偶性决定走哪条分支。仅凭一个示例看到的某个图案变换无法判断分支规则，必须同时观察奇数和偶数标记的图案才能归纳出奇偶判据。

## 新题 7：拓扑位置决定像素放大时的图案替换规则

**组合逻辑**：[flood_fill + topological_in_out + enclosed_region](已有) → [pixel_upscale + pattern_substitution](创新：原由颜色决定替换图案，此处由拓扑位置决定——封闭内部的黑色像素放大为棋盘格，外部的黑色像素放大为纯黑块)

**来源原语**：pixel_upscale, pattern_substitution, checkerboard_pattern, color_conditional_branch（来自 2072aba6）；flood_fill, topological_in_out, enclosed_region, boundary, fill_enclosed_only（来自 00d62c1b）

**依赖链**：先在原始网格上执行拓扑分析，识别绿色边界内外的黑色像素 → 再将整个网格 2x 放大 → 放大时，拓扑内部的黑色像素用棋盘格图案替换，外部的黑色像素保持纯黑。拓扑判定必须在放大前完成（放大后边界形态改变，直接分析会出错）。

一句话总结：绿色闭合边界将黑色像素分为内外两组，2 倍放大时仅内部黑色像素被替换为蓝红棋盘格块，外部黑色像素和绿色边界像素各自放大为同色纯块。

**输入结构**：
- 黑(0)背景，约 8x8 网格（放大后为 16x16）。
- 绿(3)像素构成一个或多个 4-连通的闭合边界环。边界环围成的内部区域包含若干黑(0)像素。
- 边界环外部也是黑(0)像素。
- 网格中不含其他颜色。
- 生成约束：每个绿色边界严格闭合（4-连通环），边界环之间不嵌套（均为深度 1），内部区域至少包含 2 个黑色像素。

**规则**：
1. 在原始 8x8 网格上，对每个黑(0)像素判定其拓扑位置：若该像素从四面被绿(3)边界包围（即无法沿 4-连通路径不经过绿色像素到达网格边缘），则标记为"内部"；否则标记为"外部"。
2. 将网格放大 2 倍：每个像素对应输出中的一个 2x2 块。
3. 绿(3)像素 → 2x2 纯绿块。
4. "外部"黑(0)像素 → 2x2 纯黑块。
5. "内部"黑(0)像素 → 2x2 棋盘格块：左上=蓝(1)，右上=红(2)，左下=红(2)，右下=蓝(1)。
6. 输出网格尺寸为原始的 2 倍。

**关键洞察**：源题（2072aba6）中用颜色（灰 vs 黑）决定是否替换为棋盘格。本题改为用拓扑位置（边界内 vs 边界外）作为判据，且输入中两组像素颜色完全相同（都是黑色），只有空间位置不同。求解者必须先做拓扑分析才能知道哪些像素需要棋盘格替换。

## 新题 8：障碍物过滤射线，成功射线数汇总为计数条

**组合逻辑**：[ray_cast + toward_and_away + color_determines_ray_direction + divider_line](已有) → 障碍物截断判定（创新：源题中射线无障碍传播，此处引入橙色障碍物阻断射线） → [counting + summary_generation + categorical_count + row_major_fill](创新：源题中直接计数条/横条数量，此处计数的是成功穿越的射线数量)

**来源原语**：ray_cast, toward_and_away, color_determines_ray_direction, divider_line, isolated_pixel, canvas_boundary（来自 8d510a79）；counting, summary_generation, categorical_count, row_major_fill, horizontal_bar（来自 5289ad53）；boundary 作为障碍（来自 00d62c1b）

**依赖链**：红/蓝像素各自射出朝向/背离分隔线的射线 → 橙色障碍物可能截断射线 → 仅未被截断的射线计为"成功" → 成功射线按颜色分类计数 → 计数结果编码到输出区域的摘要条中。射线方向规则、障碍物判定、计数汇总三步环环相扣。

一句话总结：红蓝像素各自向/背离灰色分隔线射出射线，橙色障碍物可阻断射线，统计未被阻断的红蓝射线各有多少条，将计数写入角落的摘要格。

**输入结构**：
- 黑(0)背景，约 13x15 网格。
- 一条完整的水平灰(5)分隔线将网格分为上下两区。
- 上下两区各散布若干红(2)和蓝(1)孤立像素（每区 2-4 个，总共 5-8 个）。红蓝像素不在分隔线上，不在同一行或同一列上（保证射线不互相干扰）。
- 若干橙(7)孤立像素散布在网格中（不在分隔线上），位于某些红/蓝像素与其射线目标之间的路径上。
- 网格右下角预留一个 2x3 的黑色区域作为输出摘要槽（该区域内无其他像素）。
- 生成约束：至少一条红射线和一条蓝射线被橙色障碍物阻断，至少一条红射线和一条蓝射线未被阻断（保证摘要非空且体现过滤效果）。

**规则**：
1. 分隔线为水平方向。红(2)像素向分隔线方向射出垂直射线（若在上方则向下，若在下方则向上）。蓝(1)像素向远离分隔线的方向射出垂直射线（若在上方则向上朝网格顶部，若在下方则向下朝网格底部）。
2. 射线逐像素前进。若下一个像素是黑(0)，继续前进。若下一个像素是橙(7)障碍物，射线被阻断——停止前进，该射线标记为"失败"。若射线到达分隔线（红射线的目标）或网格边缘（蓝射线的目标），该射线标记为"成功"。
3. 在网格上绘制所有成功的射线路径：红色成功射线路径涂红(2)，蓝色成功射线路径涂蓝(1)。失败射线不绘制任何内容。射线路径不包含起始像素本身（起始像素已有颜色）也不包含终点（分隔线保持灰色，边缘像素保持黑色）。
4. 统计成功的红射线数量 R 和成功的蓝射线数量 B。
5. 在右下角 2x3 摘要槽中，按行主序（从左到右、从上到下）依次填入 R 个红(2)像素，然后填入 B 个蓝(1)像素。剩余格子保持黑(0)。若 R + B > 6，仅填前 6 格。
6. 所有灰色分隔线像素、橙色障碍物像素、红/蓝起始像素保持原色不变。

**关键洞察**：射线不是最终输出的全部——它们同时是中间计算步骤（决定摘要内容）和可视化输出。求解者必须理解三层逻辑：方向规则（颜色→朝向/背离）、障碍物过滤（橙色像素阻断射线）、摘要编码（成功数量→紧凑条带），且三层之间存在信息流动。
