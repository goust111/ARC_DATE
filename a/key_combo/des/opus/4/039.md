## 新题 1：对称补全揭示隐藏分区

**组合逻辑**：[对称补全](创新：补全目标不是输出本身，而是作为中间步骤恢复屏障结构) → [洪泛填充](已有) → [重涂色/拓扑分类](已有原语，但分类对象是补全后才涌现的区域)

**来源原语**：对称补全/symmetry_completion（b8825c91）、洪泛填充/flood_fill（7b6016b9）、重涂色/recolor + 拓扑分类/topological_classification（84db8fc4）、内外分区/in_out_partition（7b6016b9）、双轴镜像/biaxial_mirror（b8825c91）

**依赖链**：对称补全恢复了不完整的屏障像素 → 补全后的屏障改变了画布的拓扑结构，产生了原本不存在的完全封闭区域 → 从网格边界洪泛填充识别可达/不可达背景 → 据此分类涂色。删除补全步骤，屏障残缺，封闭区域无法正确识别；删除分类涂色步骤，补全就没有用途。

将含有标记色缺口的屏障图案通过双轴对称补全修复完整，再依据修复后的拓扑结构将背景区域分类涂色。

**输入结构**：约 15x15 的网格，背景为黑(0)。蓝(1) 像素构成一个近似双轴对称（水平轴 + 垂直轴）的屏障图案，屏障为 4-连通的线段或折线组合（总像素约 20~40），在画布内部形成若干隔断。屏障图案中有若干像素被替换为黄(4)（标记色），每个反射轨道中恰好有一个像素是黄色，其余为蓝色或黑色。黄色像素的位置使得屏障存在缺口：若将黄色当作背景，原本应被屏障封闭的区域会与网格边界连通。生成约束：(a) 屏障图案完成对称补全后，至少产生 2 个彼此独立的完全封闭背景区域，同时至少 1 个背景区域仍与网格边界连通；(b) 每个反射轨道（原位、水平镜像、垂直镜像、180度镜像，共最多 4 个位置）中恰有一个非黑非黄的颜色（即蓝），黄色位置的轨道伙伴均为蓝色。

**规则**：
1. 识别标记色：找到那种颜色，使得将其视为缺失后，剩余非背景像素在每个四元反射轨道中恰有一种一致的颜色。该颜色即为黄(4)。
2. 对称补全：对于每个含有黄(4) 像素的反射轨道，用该轨道中已知的蓝(1) 替换黄色像素，使图案恢复完整的双轴镜像对称。
3. 拓扑分类：在补全后的网格中，将蓝色像素视为不可穿越的墙壁。对黑(0) 背景做 4-连通区域分割。从网格四条边上的黑色像素出发洪泛填充，标记所有可达的背景像素为"外部"。
4. 涂色：将"外部"背景像素涂为绿(3)，将未被洪泛到达的背景像素（即被屏障完全封闭的区域）涂为红(2)。蓝色屏障像素保持不变。
5. 边界处理：网格边缘的黑色像素一定属于"外部"。

**关键洞察**：黄色标记不是要移动或保留的对象，而是屏障上的缺口——只有先通过对称性推断并修补这些缺口，才能正确判断哪些背景区域是真正被封闭的。对称补全是手段而非目的。

## 新题 2：重力下落穿越几何筛孔

**组合逻辑**：[重力下落](已有) → [孔洞几何决定填充](创新：几何判断不再决定是否填充孔洞本身，而是决定下落物体能否被拦截) → [连通分量检测](已有) → [填充](已有，但填充目标由下落路径动态决定)

**来源原语**：重力下落/gravity_drop（db7260a4）、孔洞几何决定填充/hole_geometry_sets_fill + 仅正方形孔洞填充/only_square_holes_filled（44d8ac46）、连通分量检测/connected_component_detection（84db8fc4）、容器/container（db7260a4）、内部包含/containment（44d8ac46）

**依赖链**：标记像素沿列向下"下落" → 途中依次遇到灰色矩形物体 → 检测每个物体内部孔洞的几何形状 → 正方形孔洞"实心"拦截标记（填充孔洞为标记色并停止下落）→ 非正方形孔洞"有缝隙"放行标记继续下落 → 若一路无拦截则标记落到底行。删除几何判断，所有物体都拦截或都放行，失去选择性；删除重力机制，几何判断无用武之地。

彩色标记从顶行下落，途经多个灰色矩形障碍物；只有内部孔洞为正方形的障碍物能拦截标记并被填充，非正方形孔洞的障碍物被穿透。

**输入结构**：约 20x10 的网格，背景为黑(0)。顶行（第 0 行）有 2~3 个彼此不同列的单像素标记，颜色各不相同，从红(2)、蓝(1)、绿(3) 中选取。顶行其余位置为黑色。网格中部和下部散布 4~6 个灰(5) 矩形物体（每个物体为实心灰色矩形，宽 3~6、高 3~6 像素，内部挖去一个连续黑色孔洞）。部分物体的孔洞是正方形（如 2x2 或 3x3），其余物体的孔洞是非正方形矩形（如 2x3 或 1x4）。物体之间不重叠、不相邻（间距至少 1 像素）。每个标记的正下方列至少穿过 1 个物体。生成约束：(a) 每列最多有 2 个物体与标记列重叠；(b) 至少有一个标记能在途中被正方形孔洞物体拦截，至少有一个标记一路穿透到底行。

**规则**：
1. 对每个顶行标记像素，从其所在列向下逐行扫描。
2. 当标记列进入某个灰色矩形物体的列范围时，检测该物体内部的黑色孔洞：提取物体边界框内的黑色连通区域，计算其边界框。
3. 判断：若孔洞的边界框是正方形且该边界框被黑色完全填满（即孔洞本身是实心正方形），则该物体"拦截"标记——将孔洞的所有像素涂为标记的颜色，标记停止下落。擦除标记在顶行的原始像素。
4. 若孔洞不是正方形（边界框非正方形，或边界框虽正方形但未被完全填满），标记"穿透"该物体，继续向下寻找下一个物体。
5. 若标记列上所有物体都被穿透（或该列无物体），标记落到最底行：将最底行该列的像素涂为标记颜色。擦除标记在顶行的原始像素。
6. 处理顺序：各标记独立处理，互不影响（生成时保证不同标记不会竞争同一个物体）。

**关键洞察**：灰色物体不是简单的容器——其内部孔洞的几何形状决定了它是"实心网"（正方形孔洞，能拦截）还是"破网"（非正方形孔洞，被穿透）。求解者必须对每个障碍物独立做几何判断才能追踪标记的最终落点。

## 新题 3：边界标记划线分区后选择性反转瓷砖

**组合逻辑**：[连线/边界标记定贯穿线](已有) → [瓷砖网格排列](已有，作为操作对象的结构背景) → [反转填充](创新：不再对所有瓷砖统一反转，而是仅对被划线完全围合的瓷砖子集执行反转)

**来源原语**：连线/draw_line + 边界标记定贯穿线/boundary_marker_span（6cdd2623）、反转填充/occupancy_inversion（1c0d0a4b）、瓷砖/tile + 瓷砖网格排列/tile_grid_layout + 分隔行列/separator_rows_and_columns（1c0d0a4b）、画布边界/canvas_boundary（6cdd2623）

**依赖链**：边界标记确定贯穿线位置 → 贯穿线恰好落在瓷砖之间的分隔行/列上，将瓷砖网格划分为若干分区 → 判断哪些瓷砖被贯穿线和网格边界共同围成封闭分区 → 仅对封闭分区内的瓷砖做占位反转。删除连线步骤则无分区，所有瓷砖处理方式相同；删除反转步骤则连线无意义。

在瓷砖网格的边界上识别标记像素，画出贯穿分隔行/列的线条，将瓷砖网格切割为分区，只有被线条和网格边界完全围合的分区内的瓷砖做占位反转。

**输入结构**：约 15x15 的网格，背景为黑(0)。青(8) 像素组成若干 3x3 瓷砖，瓷砖之间由宽度为 1 像素的全黑分隔行和分隔列隔开（形成规则的瓷砖网格，如 3 行 3 列共 9 个瓷砖）。每个瓷砖内部由青色和黑色像素组成不同的图案（各瓷砖图案不同，每瓷砖至少有 2 个青色像素和 2 个黑色像素）。在网格的四条边上（第 0 行、最后一行、第 0 列、最后一列）有 2~4 个橙(7) 单像素标记，每个标记的行号或列号恰好对应某条分隔行或分隔列的位置。生成约束：(a) 标记画出的贯穿线与网格边界共同围成至少 1 个封闭矩形分区和至少 1 个非封闭分区（一侧无线条也无边界）；(b) 每条分隔行/列上最多有一条贯穿线。

**规则**：
1. 找到网格边界上所有橙(7) 标记像素。
2. 对于位于顶行或底行的标记，在该标记所在列画一条从顶到底的垂直贯穿线（将该列所有像素覆盖为橙色）。对于位于左列或右列的标记，在该标记所在行画一条从左到右的水平贯穿线（将该行所有像素覆盖为橙色）。
3. 贯穿线将瓷砖网格划分为若干矩形分区。判断每个分区是否"封闭"：分区的四条边均由贯穿线或网格边界构成（即该分区不与任何未被线条覆盖的分隔行/列的外侧连通）。
4. 对于封闭分区内的每个 3x3 瓷砖：将瓷砖内所有青(8) 像素改为黑(0)，将所有黑(0) 像素改为红(2)。即占位反转，用红色标记原来的空位。
5. 非封闭分区内的瓷砖保持不变。
6. 分隔行/列上的像素：若被贯穿线覆盖则显示为橙(7)，否则保持黑(0)。

**关键洞察**：边界标记画出的线并非装饰——它们恰好落在分隔行列上，将瓷砖网格切割成分区。只有完全围合的分区才触发反转操作。求解者需要同时理解线条的分区作用和反转的局部性。

## 新题 4：拓扑孔洞数编码旋转角度

**组合逻辑**：[洪泛填充/内外分区](已有) → [计数](已有) → [旋转](创新：旋转角度不是固定的，而是由每个对象自身的拓扑属性——孔洞数——动态决定)

**来源原语**：洪泛填充/flood_fill + 内外分区/in_out_partition（7b6016b9）、计数/counting（edcc2ff0）、旋转/rotate（ed98d772）、连通分量检测/connected_component_detection（84db8fc4）、封闭区域/enclosed_region（44d8ac46）、内部包含/containment（44d8ac46）

**依赖链**：对每个精灵体做洪泛填充识别其完全封闭的内部孔洞 → 计数孔洞数 → 孔洞数映射为旋转角度 → 在原位旋转精灵体。删除孔洞检测则不知道旋转多少度；删除旋转则孔洞计数毫无用途。精灵体的结构既是分析对象又是变换对象——它用自身拓扑编码自身的变换指令。

每个精灵体内部封闭的孔洞数量决定其就地旋转的角度。

**输入结构**：约 18x18 的网格，背景为黑(0)。网格中有 3~4 个互不接触（8-连通距离至少 2 像素）的单色精灵体，每个精灵体使用不同的前景色（从蓝(1)、红(2)、绿(3)、黄(4) 中选取）。每个精灵体是一个 4-连通的单色像素集合，占据一个正方形边界框（边长 5~7 像素），且边界框内精灵体像素和黑色像素共同构成图案。精灵体的结构保证其 4-连通外部与网格边界连通后，内部可能剩余 0、1、2 或 3 个独立的 4-连通黑色封闭区域（孔洞）。不同精灵体的孔洞数各不相同。生成约束：(a) 每个精灵体的边界框是正方形（保证旋转后尺寸不变）；(b) 0~3 每种孔洞数至多出现一次；(c) 旋转后精灵体不会与其他精灵体重叠或超出网格边界。

**规则**：
1. 识别所有前景精灵体（非黑色的 4-连通区域）。
2. 对每个精灵体，将其像素视为"墙壁"，在其边界框内对黑(0) 像素做 4-连通区域分割。排除与边界框外部连通的黑色区域（这些是外部背景），剩余的 4-连通黑色区域即为该精灵体的"孔洞"。
3. 设孔洞数为 h。按以下映射旋转精灵体（以其边界框中心为旋转中心）：h=0 不旋转，h=1 顺时针旋转 90 度，h=2 旋转 180 度，h=3 顺时针旋转 270 度。
4. 旋转操作：将精灵体边界框内的所有像素（含该精灵体的前景像素和属于该精灵体内部的黑色像素）作为一个方阵整体旋转，然后写回原边界框位置。
5. 不属于任何精灵体边界框的黑色背景保持不变。

**关键洞察**：精灵体的拓扑复杂度（孔洞数）不是视觉特征——它是隐式编码的旋转指令。求解者必须先完成拓扑分析（数孔洞），再据此执行几何变换（旋转），二者缺一不可。

## 新题 5：边框边长编码目标面积匹配填充

**组合逻辑**：[计数](创新：计数对象从"4-连通物体个数"变为"矩形边框每条边的像素数") → [面积匹配/像素数等于腔面积](创新：匹配的不再是源像素集与腔面积，而是边框边长与轮廓内腔面积) → [填充](已有) + [朝向对应边色](创新：边色不再填入缺口，而是填入面积匹配的轮廓内腔)

**来源原语**：计数/counting（edcc2ff0/7acdf6d3）、面积匹配/area_matching + 像素数等于腔面积/count_equals_cavity（7acdf6d3）、填充/fill（7acdf6d3）、矩形边框/rectangular_frame + 朝向对应边色/facing_side_color（5b37cb25）、轮廓对象/outline_object + 行内腔/row_interior（7acdf6d3）、连通分量检测/connected_component_detection（84db8fc4）

**依赖链**：测量矩形边框四条边各自的像素长度 → 在边框内部找到多个灰色轮廓对象并计算每个轮廓的内腔面积 → 将每条边的长度与某个轮廓内腔面积做匹配（长度 = 面积） → 用匹配到的边的颜色填充对应轮廓的内腔。删除边长测量，不知道目标面积；删除面积匹配，不知道哪个轮廓对应哪个颜色。

测量矩形边框每条边的像素数，找到边框内部与该数值面积相同的轮廓内腔，用该边的颜色填充。

**输入结构**：约 16x16 的网格，背景为黑(0)。网格最外圈为一像素宽的矩形边框，四条边各自为不同的纯色：上边为蓝(1)、右边为红(2)、下边为绿(3)、左边为黄(4)（四个角像素为黑色，不属于任何边）。边框内部为黑色背景，其中有 4 个灰(5) 轮廓对象，每个轮廓对象是一个封闭的单像素宽灰色环（8-连通闭合曲线），内部为黑色空腔。四个轮廓的内腔面积（内腔中黑色像素总数）互不相同，且分别等于矩形边框四条边中某一条的像素长度（不含角，即纯色段的像素数）。轮廓对象之间不重叠、不相邻。生成约束：(a) 网格为矩形但不一定是正方形，使得四条边像素数可以不同（如 16x14 时上下边各 14 像素，左右边各 14 像素——需要非正方形才有不同长度的边）；(b) 实际使用非正方形网格如 14x18 使上边/下边为 12 像素（去掉两角），左边/右边为 16 像素（去掉两角），从而产生两种不同长度；为获得四种不同长度，将上边和下边各减去若干角落相邻像素或使用不对称设计——简化方案：允许上边和下边长度不同、左边和右边长度不同，通过在某些边上留出额外黑色间断来实现不同有效长度。(c) 每个轮廓内腔面积恰好匹配一条边，一一对应，无歧义。

**规则**：
1. 识别矩形边框的四条边。边框占据网格第 0 行、最后一行、第 0 列、最后一列。四个角(0,0)、(0,W-1)、(H-1,0)、(H-1,W-1)为黑色。上边 = 第 0 行中连续的非黑像素段，记录其颜色和像素数 L_top；同理得到 L_right、L_bottom、L_left 及各自颜色。
2. 在边框内部（去掉最外圈一行一列后的矩形区域），找到所有灰(5) 的 8-连通区域，每个即为一个轮廓对象。
3. 对每个轮廓对象，计算其内腔面积：轮廓边界框内、被灰色像素完全包围的黑色 4-连通区域的像素总数。
4. 对四条边中的每条，找到内腔面积等于该边像素数的唯一轮廓对象。用该边的颜色填充该轮廓的内腔。
5. 灰色轮廓本身保持不变。边框保持不变。其余黑色背景保持不变。

**关键洞察**：边框不是纯粹的装饰边界——每条边的像素长度是一条隐式编码的数值指令，它指定了哪个轮廓内腔是该颜色的目标。求解者需要同时"测量"边框和轮廓，然后通过数值等式建立对应关系。

## 新题 6：唯一精灵体经波浪弯折后保留

**组合逻辑**：[去重筛选/异常值选择](已有) → [移位/逐行交替方向](创新：波浪弯折不再应用于整个前景格子体，而是仅应用于通过唯一性筛选后的单个精灵体) → [擦除](已有，擦除重复精灵体)

**来源原语**：去重筛选/uniqueness_filter + 异常值选择/outlier_selection + 图案仅出现一次/pattern_once（aee291af）、移位/shift + 逐行交替方向/alternating_direction_per_row + 底行锚定/bottom_row_anchored（1c56ad9f）、擦除/erase（ae3edfdc）、连通分量检测/connected_component_detection（84db8fc4）

**依赖链**：在多个前景精灵体中识别哪个是唯一的（形状不重复） → 仅对该精灵体执行波浪弯折 → 擦除所有重复的精灵体。删除唯一性检测，不知道哪个精灵体做弯折；删除弯折，输出退化为简单的异常值提取。

在多个精灵体中找出形状唯一的那个，对其做逐行交替偏移的波浪弯折，擦除其余所有重复精灵体。

**输入结构**：约 15x20 的网格，背景为黑(0)。网格中有 5~7 个灰(5) 的 4-连通精灵体，彼此不相邻（8-连通距离至少 2）。精灵体均为小型图案（占据 3x3 到 5x5 的边界框，像素数 4~12）。其中存在若干组"重复"精灵体：同组内各精灵体归一化后形状完全相同（将精灵体平移到边界框左上角后像素图案一致），每组至少 2 个。恰好有一个精灵体的归一化形状在所有精灵体中仅出现一次（唯一精灵体）。该唯一精灵体的边界框每行都有至少一个灰色像素（保证波浪弯折有意义）。生成约束：(a) 重复组至少 2 组，每组 2~3 个；(b) 唯一精灵体的边界框高度至少 4 行，使弯折效果可见。

**规则**：
1. 找出所有灰(5) 的 4-连通精灵体。对每个精灵体提取其归一化形状（平移到左上角为原点后的像素坐标集合）。
2. 比较所有精灵体的归一化形状，找到仅出现一次的形状对应的精灵体（唯一精灵体）。
3. 对唯一精灵体执行波浪弯折：以其边界框最底行为锚定行（不偏移），从底行向上每隔一行交替偏移——第一个偏移行向右移 1 像素，第二个偏移行向左移 1 像素，依此交替。偏移在网格坐标系中执行，超出网格边界的像素舍弃。
4. 擦除所有非唯一精灵体（将其像素改为黑(0)）。
5. 输出中仅保留弯折后的唯一精灵体和黑色背景。

**关键洞察**：这不是简单的"找不同后提取"——唯一精灵体被找到后还要经历波浪变形，而变形参数（锚定行、偏移方向）隐含在弯折规则中，需要对比多个示例才能确定偏移模式（先右后左还是先左后右、锚定在底行而非顶行）。

## 新题 7：孔洞方位编码对角印章方向

**组合逻辑**：[洪泛填充/内外分区](已有) → [印章覆盖](已有) → [对角互补](创新：对角方向不再由已填充的两个对角块决定，而是由精灵体内部孔洞相对于边界框中心的象限位置决定)

**来源原语**：洪泛填充/flood_fill + 内外分区/in_out_partition（7b6016b9）、印章覆盖/stamp + 对角空位补块/complement_at_diagonal_vacancies（22233c11）、对角互补/diagonal_complement（22233c11）、连通分量检测/connected_component_detection（84db8fc4）、封闭区域/enclosed_region + 内部包含/containment（44d8ac46）

**依赖链**：检测每个精灵体的封闭孔洞 → 判断孔洞中心落在精灵体边界框的哪个象限 → 象限位置映射为对角方向（NW-SE 或 NE-SW）→ 在互补对角位置印章红色方块。删除孔洞检测，无法确定对角方向；删除印章步骤，孔洞信息无处输出。无孔洞的精灵体不产生印章，孔洞的位置信息是纯空间编码。

精灵体内部孔洞的位置决定在其边界框外哪两个对角方向印上红色方块。

**输入结构**：约 20x20 的网格，背景为黑(0)。网格中有 3~4 个互不接触（8-连通距离至少 3 像素）的单色精灵体，颜色各不相同（从蓝(1)、绿(3)、黄(4)、灰(5) 中选取）。每个精灵体占据一个偶数边长的正方形边界框（如 6x6 或 8x8），以便将边界框清晰地分为四个等大象限（NW、NE、SW、SE）。部分精灵体（至少 2 个）内部恰好有 1 个 4-连通黑色封闭孔洞（面积 1~4 像素），孔洞完全落在边界框四个象限中的某一个（孔洞所有像素的行列坐标均在该象限范围内）。其余精灵体没有封闭孔洞。生成约束：(a) 有孔洞的精灵体中，孔洞所在象限不全相同（至少出现 NW/SE 和 NE/SW 两种对角模式中的各一种）；(b) 印章位置不超出网格边界且不与其他精灵体重叠。

**规则**：
1. 找到所有非黑色的 4-连通精灵体。对每个精灵体计算其正方形边界框。
2. 在每个精灵体内部检测封闭孔洞：将精灵体像素视为墙壁，在边界框内对黑色像素做 4-连通分割，排除与边界框外部连通的区域，剩余即为孔洞。
3. 对无孔洞的精灵体：不做任何操作，保留原样。
4. 对有恰好 1 个孔洞的精灵体：计算孔洞的质心（所有孔洞像素行坐标的平均值和列坐标的平均值）。判断质心落在边界框的哪个象限：
   - 质心在 NW 或 SE 象限 → 该精灵体的对角方向为 NW-SE → 在边界框的 NE 和 SW 外侧紧邻位置各印一个与边界框同尺寸的红(2) 实心方块。
   - 质心在 NE 或 SW 象限 → 该精灵体的对角方向为 NE-SW → 在边界框的 NW 和 SE 外侧紧邻位置各印一个与边界框同尺寸的红(2) 实心方块。
5. "紧邻"定义：NE 外侧方块的左下角 = 精灵体边界框的右上角向右上偏移一格；NW 外侧方块的右下角 = 边界框左上角向左上偏移一格；同理 SW、SE。即印章方块与原边界框对角相接，中间无间隙。
6. 超出网格边界的印章像素舍弃（裁剪）。原精灵体像素保持不变。

**关键洞察**：孔洞的功能不是缺陷或待填充的区域——它是一种空间编码，用其在边界框内的方位来指示互补对角的印章方向。无孔洞的精灵体完全不参与印章逻辑，形成了"有孔→有动作、无孔→无动作"的条件分支。

## 新题 8：压缩射线计数后匹配容器宽度下落填充

**组合逻辑**：[滑动/压缩到标记旁](已有) → [计数](已有) → [重力下落](创新：不再由标记位置的列决定下落目标，而是由上一步的计数结果选择匹配的容器) → [填充](已有)

散布像素压缩到标记旁后，按聚集数量匹配下方容器宽度，将匹配容器的内腔填充为标记色。

**输入结构**：约 20x15 的网格，背景为黑(0)。网格分为上半区和下半区。上半区（约前 10 行）：有 2 个固定的单像素标记，颜色为栗(9)，分别位于不同列。上半区还散布着若干蓝(1) 和红(2) 像素（每种颜色各 3~6 个像素），每个散布像素与恰好一个标记处于同一行或同一列（即每个像素到某个标记有唯一的行对齐或列对齐关系），且散布像素与标记之间的路径上无其他非背景像素。每个散布像素有其自身颜色（蓝或红），同一标记吸引的像素可以有不同颜色。下半区（约后 10 行）：有 3~4 个栗(9) 色 U 形容器（由栗色像素构成），每个 U 形容器由两条垂直栗色边和一条水平栗色底边组成，内腔为矩形黑色空间，内腔宽度（水平方向黑色像素列数）互不相同。容器之间不重叠。生成约束：(a) 每个标记吸引的蓝色像素数恰好等于某个容器的内腔宽度，红色像素数也恰好等于另一个容器的内腔宽度；(b) 所有匹配为一一对应，无歧义。

**规则**：
1. 识别栗(9) 的单像素标记（上半区中不与其他栗色像素 4-连通相邻的栗色像素）。
2. 对每个非标记的前景像素（蓝或红），找到与其共享行或列的唯一标记，将该像素沿共享的行或列方向滑动到标记旁的紧邻空格（即标记与该像素之间直线上最靠近标记的一格）。清除原位置。
3. 滑动完成后，对每个标记统计其周围（上下左右四个紧邻格）聚集的蓝(1) 像素数 N_blue 和红(2) 像素数 N_red。
4. 在下半区找到所有栗(9) 色 U 形容器，计算每个容器的内腔宽度 W。
5. 对每个标记：找到内腔宽度 W = N_blue 的容器，用蓝(1) 填充该容器的整个内腔。找到内腔宽度 W = N_red 的容器，用红(2) 填充该容器的整个内腔。
6. 标记本身保留在原位。容器的栗色边壁保持不变。已压缩到标记旁的像素在输出中保留在其滑动后的位置。未被填充的容器保持空腔（黑色）。

**关键洞察**：散布像素不是要到达容器的——它们压缩到标记旁后只起计数作用。真正的信息流是：空间分布 → 压缩 → 计数 → 数值匹配 → 填充。容器的物理位置与标记不需要对齐，匹配完全基于数值等式（聚集数 = 腔宽）。

## 新题 9：按精灵体像素数排序后分区涂色

**组合逻辑**：[洪泛填充](已有) → [计数](已有) → [排序/位置排序](创新：排序依据不再是区域自身的位置，而是区域内精灵体的像素数量) → [重涂色](创新：涂色对象从精灵体变为包含它的区域背景)

**来源原语**：洪泛填充/flood_fill + 位置排序/positional_ordering + 位置决定填充色/position_determines_fill_color（941d9a10）、计数/counting（edcc2ff0）、排序/sort（941d9a10）、重涂色/recolor（84db8fc4）、分隔线/divider_line + 封闭区域/bounded_region（941d9a10）、连通分量检测/connected_component_detection（84db8fc4）

**依赖链**：灰色分隔线将画布分为若干区域 → 每个区域内有一个精灵体 → 计算每个精灵体的像素数 → 按像素数升序排列区域 → 按排名给区域背景涂色。删除计数步骤，无排序依据；删除排序步骤，退化为 941d9a10 的位置直接决定颜色。

灰色分隔线划分出多个区域，每个区域内含一个大小不同的精灵体；按精灵体像素数量从小到大排列区域，依排名为区域背景涂上对应颜色。

**输入结构**：约 15x15 的网格，背景为黑(0)。灰(5) 色直线（水平和/或垂直的完整贯穿线）将网格分割为 4~5 个矩形区域。每个区域内有一个 4-连通的单色精灵体（颜色为橙(7)），各精灵体形状不同、像素数互不相同（范围 3~10 像素）。精灵体不接触灰色分隔线。生成约束：(a) 所有精灵体像素数严格互不相等，无需 tie-break；(b) 区域数量与涂色色板大小匹配（4~5 个区域对应 4~5 种颜色）。

**规则**：
1. 识别灰(5) 分隔线，找到所有被分隔线和网格边界围成的矩形区域。
2. 在每个区域内找到橙(7) 的 4-连通精灵体，计算其像素数。
3. 将所有区域按其精灵体像素数从小到大排列。若像素数相同（生成时保证不会发生），按区域左上角从左到右、从上到下排列作为 tie-break。
4. 按排名涂色区域背景（区域内非灰色、非橙色的黑色像素）：排名第 1（最少像素）→ 蓝(1)，排名第 2 → 红(2)，排名第 3 → 绿(3)，排名第 4 → 黄(4)，排名第 5（若有）→ 品红(6)。
5. 精灵体自身像素保持橙(7) 不变。灰色分隔线保持不变。

**关键洞察**：区域的涂色不取决于其自身的空间位置（不同于 941d9a10），而取决于其内含精灵体的大小排名。求解者必须对比多个示例才能排除"位置决定颜色"的错误假设，发现真正的排序键是像素计数。

## 新题 10：风车拼接中按旋转后顶行奇偶性条件反转

**组合逻辑**：[旋转 + 拼接/阵列排布](已有) → [计数](已有) → [反转填充](创新：反转不再由空间分区决定，而是由每个旋转变体自身的局部属性——顶行前景像素奇偶性——独立决定)

**来源原语**：旋转/rotate + 拼接/concatenate + 阵列排布/array_layout + 四旋转变体组拼图/four_rotations_composite（46442a0e/ed98d772）、计数/counting（edcc2ff0）、反转填充/occupancy_inversion（1c0d0a4b）

**依赖链**：对输入精灵体生成四个旋转变体（0/90/180/270度）→ 计算每个变体顶行的前景像素数 → 奇数则对该变体做占位反转，偶数则保留原样 → 将四个变体（可能部分已反转）拼成 2x2 风车。删除旋转/拼接，没有四个变体可比较；删除奇偶判断，所有象限处理方式相同，退化为纯旋转拼接。同一个精灵体的四个旋转变体产生不同的顶行像素数，因此每个象限的命运不同——这种差异完全由旋转引发。

将输入方阵的四个旋转变体拼成 2x2 风车，但顶行前景像素数为奇数的变体需做占位反转后再放入。

**输入结构**：一个 5x5 的正方形网格，背景为黑(0)，前景为蓝(1)（像素数约 8~15）。前景图案不具备 90 度旋转对称性（保证四个旋转变体不全相同），且四个旋转变体的顶行前景像素数不全为同一奇偶性（即至少一个为奇数、至少一个为偶数）。生成约束：(a) 四个旋转变体中至少 1 个顶行前景像素数为奇数、至少 1 个为偶数，保证反转和不反转都出现；(b) 精灵体不具备 180 度旋转对称性（保证四个变体至少有两种不同形态）。

**规则**：
1. 生成输入精灵体的四个旋转变体：R0 = 原图，R1 = 顺时针 90 度，R2 = 180 度，R3 = 顺时针 270 度。
2. 对每个变体 Ri，计算其顶行（第 0 行）中蓝(1) 像素的数量 n_i。
3. 若 n_i 为奇数：对 Ri 做占位反转——将 Ri 中所有蓝(1) 像素改为黑(0)，所有黑(0) 像素改为红(2)。
4. 若 n_i 为偶数：Ri 保持不变。
5. 将处理后的四个变体按 2x2 排列拼接成输出：左上 = R0，右上 = R1，左下 = R3，右下 = R2。输出尺寸为 10x10。

**关键洞察**：旋转不仅产生四个视觉变体，还改变了每个变体的"顶行"内容。同一批像素在不同旋转下成为不同行，导致顶行像素计数的奇偶性在象限间不同。求解者需要意识到反转条件是与旋转后的局部属性绑定的，而非全局属性。
