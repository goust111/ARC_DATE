## 新题 1：偏转射线印章链

**组合逻辑**：[射线延伸 + 障碍偏转绕行](创新：射线不画线而是在路径上逐格印章) → [印章覆盖 + 仅填背景格](创新：印章沿动态路径展开而非固定标记位置) → 路径长度决定覆盖优先级(创新)

**来源原语**：射线延伸/ray_extension + 障碍偏转绕行/obstacle_deflection（来自 69889d6e）；印章覆盖/stamp_overlay + 仅填背景格/only_bg_filled + 中心邻域/center_neighborhood（来自 f0df5ff0）

**依赖链**：障碍物的位置决定射线路径的形状 → 路径形状决定印章落点的空间分布 → 多条路径的交叉区域中，路径长度决定最终颜色归属。三者缺一则输出不确定。

将底部边缘的源像素沿对角线向上发射，遇障碍右移绕行，在射线经过的每个格子盖一个 3x3 色块，重叠处由后处理的源覆盖。

**输入结构**：
- 约 15x15 的网格，背景为黑(0)。
- 底部边缘（最后一行）有 2~3 个不同颜色的源像素（如蓝(1)、红(2)、绿(3)），彼此间隔至少 3 列。
- 网格内部散布 4~7 个灰(5) 单像素障碍物。障碍物不在底部边缘行，不在最左列或最右列，彼此不 4-相邻。
- 生成约束：每个源像素的射线路径（含偏转）至少经过 4 个格子后才离开网格顶部或右侧边缘；至少有一对源像素的射线路径产生印章重叠区域。

**规则**：
1. 对每个源像素，从其正上方一格开始，逐步沿"上一行、右一列"的对角方向前进。
2. 若下一步目标格被灰(5) 障碍物占据，则在当前行向右平移一列（不上移），再继续对角前进。若平移后的格仍被障碍物占据，继续右移直到找到空格或超出右边界。
3. 射线在超出网格顶部边缘或右侧边缘时终止。记录射线经过的所有格子坐标序列，即为该源的"路径"。
4. 计算每个源的路径长度（格子数）。按路径长度从短到长排列源像素的处理顺序；长度相同则按源像素在底部边缘从左到右的顺序。
5. 按此顺序依次处理每个源：对其路径上的每个格子，以该格为中心画 3x3 正方形区域。区域内每个格子若当前为黑(0) 背景或为先前源印章所涂的颜色，则涂为当前源的颜色。灰(5) 障碍物格子永不被覆盖。超出网格边界的部分忽略。
6. 输出即为处理完所有源后的网格。底部边缘的源像素保留原色，障碍物保留灰(5)。

**关键洞察**：障碍物不仅阻挡射线使路径弯折，还保护自身周围的像素不被印章覆盖，在印章密集区域形成"阴影孔洞"。路径较长的源后处理，其颜色在重叠区占优——但路径长恰恰说明它被障碍物偏转得更多，因此"被干扰最多的源反而在视觉上最显著"。这条优先级规则需对比多个示例才能归纳。

## 新题 2：对称破缺定位条件互换与围合填充

**组合逻辑**：[对称轨道](分析用，非重建) → [重涂色 + 双色互换](创新：仅在轨道不一致的位置执行互换) → [填充 + 内部包含](创新：互换改变了拓扑连通性，产生新围合区域)

**来源原语**：对称补全/symmetry_completion + 对称轨道/symmetry_orbit（来自 e66aafb8）；重涂色/recolor + 双色互换/two_color_swap + 仅交换两色/swap_two_colors_only（来自 d511f180）；填充/fill + 内部包含/interior_containment（来自 b0c4d837）

**依赖链**：D4 对称轨道分析识别出不一致位置 → 不一致位置的双色互换改变了像素分布 → 改变后的分布影响背景区域的围合拓扑 → 围合区域的填充颜色取决于互换后的边界。四步环环相扣，任一步缺失则输出无法确定。

在近似 D4 对称的方阵中，仅在对称被破坏的位置执行青灰互换，互换后新出现的封闭背景区域用边界多数色填充。

**输入结构**：
- 一个 11x11 或 13x13 的正方形网格。
- 网格包含一个几乎具有 D4 对称性（水平、垂直、两条对角线共 4 面反射）的多色图案，使用黑(0) 作为背景，以及蓝(1)、红(2)、绿(3)、灰(5)、青(8) 等前景色。
- 图案中有 3~6 个像素"出错"：它们本应是青(8) 却被标记为灰(5)，或本应是灰(5) 却被标记为青(8)。这些出错像素打破了 D4 对称。
- 图案中存在若干由非背景像素围成的封闭黑(0) 区域（4-连通意义上完全被前景包围）。
- 生成约束：出错像素的互换操作至少会导致一个原本未封闭的背景区域变为封闭，或一个原本封闭的区域打开（拓扑改变）。每个封闭区域的 4-相邻边界像素中，某一颜色严格占多数（超过一半）。

**规则**：
1. 对网格中每个像素位置 (r, c)，计算其 D4 对称轨道（在正方形网格的 8 个对称操作下映射到的所有位置集合）。
2. 检查轨道中所有位置的颜色是否相同。若相同，称该位置"一致"；若不同，称其"不一致"。
3. 对每个不一致位置：若该像素当前为青(8)，改为灰(5)；若为灰(5)，改为青(8)。其他颜色不变。
4. 互换完成后（此时图案恢复完全 D4 对称），识别所有 4-连通的黑(0) 背景区域。
5. 对每个完全被非背景像素包围的封闭背景区域（即不与网格边缘 4-连通），统计其 4-相邻边界上各颜色的出现次数，取出现最多的颜色（生成约束保证有唯一多数色），将该封闭区域内所有黑(0) 像素填充为该颜色。
6. 与网格边缘连通的背景区域保持黑(0) 不变。输出最终网格。

**关键洞察**：互换操作并非全局生效——它只修改对称不一致的位置，因此解题者必须先做对称分析才能确定修改目标。互换后拓扑的改变（新的封闭区域出现或旧的消失）是涌现效应——单独看互换或填充都不会产生这种结果。需要多个示例才能确认：(a) 只有青-灰两色参与互换、(b) 填充色由边界多数色决定而非固定颜色。

## 新题 3：十字射线选区循环换色

**组合逻辑**：[射线延伸 + 八方向发射](创新：射线不绘制视觉输出，而是作为空间查询检测哪些区域被命中) → [环绕角度排序](创新：角度由命中射线的方向给出，非质心角) → [循环轮换](创新：仅对被射线命中的区域执行轮换，未命中区域保持不变)

**来源原语**：射线延伸/ray_extend + 八方向发射/eight_dir_emit + 十字图案/plus_pattern（来自 fe9372f3）；循环轮换/cyclic_shift + 环绕角度排序/angular_order_around_center + 分离区域/separated_region（来自 880c1354）

**依赖链**：十字图案的中心确定射线发射原点 → 八方向射线扫描确定哪些区域被"激活" → 每个被激活区域的角度由命中它的射线方向决定 → 角度序给出循环轮换的颜色传递顺序。未被任何射线命中的区域不参与轮换，这一选择性由射线路径决定。

从中心十字向八个方向发射隐式射线，命中的有色区域按射线角度排序后执行颜色循环轮换，未命中的区域颜色不变。

**输入结构**：
- 约 17x17 的网格，背景为黑(0)。
- 网格中心附近有一个红(2) 五像素十字图案（中心 1 格 + 上下左右各 1 格）。
- 网格中分布 5~8 个单色 4-连通前景区域（每个区域 3~10 像素，颜色各不相同，可选蓝(1)、绿(3)、黄(4)、灰(5)、品红(6)、橙(7)、青(8)、栗(9)）。
- 这些区域不与十字图案相邻。部分区域位于十字八个方向射线的路径上（即从十字中心沿上、下、左、右、左上、右上、左下、右下方向延伸的直线经过该区域的至少一个像素），部分区域不在任何射线路径上。
- 生成约束：至少 3 个区域被射线命中；至少 1 个区域不被任何射线命中；被命中的区域各自仅被一条射线命中（不位于两条射线的交叉处）；射线从十字中心出发，遇到第一个非背景像素时记录命中，然后继续前进（不停止），但同一区域只记录一次命中。

**规则**：
1. 以十字图案的中心像素为原点，向 8 个方向（上、右上、右、右下、下、左下、左、左上）各发射一条射线，射线沿该方向逐像素前进直至离开网格。
2. 射线前进过程中，若经过某个非背景、非十字颜色的像素，则该像素所属的 4-连通前景区域被标记为"激活"。同一区域被多次经过只算一次激活。
3. 对每个激活区域，记录命中它的射线方向角度（上=0°、右上=45°、右=90°、右下=135°、下=180°、左下=225°、左=270°、左上=315°）。若一个区域被多条射线命中，取角度最小的那条。
4. 将所有激活区域按其射线角度从小到大排序。
5. 对排序后的激活区域序列执行颜色循环轮换：序列中每个区域获得前一个区域的颜色，第一个区域获得最后一个区域的颜色。
6. 未激活的区域保持原色不变。十字图案保持红(2) 不变。输出最终网格。

**关键洞察**：十字图案不只是视觉元素——它是八向空间选择器。射线方向同时编码了"选哪些区域"和"以什么顺序轮换"。需要多个示例才能归纳出：(a) 未被射线命中的区域不参与轮换；(b) 轮换方向是角度升序的循环移位而非降序或其他映射。

## 新题 4：标记生长门控跨分隔线传色压缩

**组合逻辑**：[生长 + 逐步推进](创新：生长方向朝向分隔线而非远离边缘) → [擦除 + 循环迁移](创新：成熟标记擦除后颜色跨分隔线传递) → [压缩至远端边界](创新：压缩对象包含原有像素与跨线传入像素的混合体)

**来源原语**：生长/grow + 逐步推进/stepwise_advance + 擦除/erase + 标记条/marker_bar + 循环迁移/cyclic_migration（来自 758abdf0）；射线延伸/ray_extension + 压缩/compress + 分隔线/divider_line + 通道/lane + 分隔线两侧/opposite_sides_of_divider + 压缩至远端边界/pack_to_far_edge（来自 05a7bcf2）

**依赖链**：标记高度（1 格 vs 2 格）决定该标记执行生长还是擦除传色 → 传色操作在分隔线下方的对应通道中注入新颜色像素 → 注入后通道内既有原始像素也有传入像素，压缩时需将所有像素一起推向底部。标记高度是整个变换的门控信号：单格标记只改变自身，双格标记触发跨区域的颜色转移。

将分隔线上方单格标记向下生长一格，双格标记则擦除并将颜色传至分隔线下方同一通道，最后将下方所有有色像素压缩至底部。

**输入结构**：
- 约 13x10 的网格，背景为黑(0)。
- 网格中部有一条完整的水平灰(5) 分隔线（占据一整行）。
- 分隔线上方：若干列（通道）中有蓝(1) 或红(2) 的标记像素。每个标记是竖直的 1 格或 2 格色块（即同色像素在同一列中连续占据 1 行或 2 行）。标记的最下方像素紧邻分隔线上方（中间无空行）或距分隔线 1~2 行。不同通道的标记颜色独立。
- 分隔线下方：部分通道中有绿(3) 像素，每个通道 0~3 个绿像素，散布在该通道的分隔线下方区域。
- 生成约束：至少有 2 个单格标记和 2 个双格标记。含有双格标记的通道在分隔线下方至少有 1 个绿(3) 像素。不同标记在不同列，互不相邻。

**规则**：
1. 扫描分隔线上方每一列，识别每个标记（同色竖直连续段）及其高度。
2. **单格标记**：在该标记正下方一格添加同色像素（向分隔线方向生长一格）。若该位置已经是分隔线，则不添加（生长被分隔线阻止）。
3. **双格标记**：将该标记的两个像素全部擦除为黑(0)。在该列的分隔线正下方第一个黑(0) 背景格中放置一个该标记颜色的像素（"传色"）。若该位置已被绿(3) 占据，则传色像素放在该列分隔线下方从上往下第一个黑(0) 格。
4. 分隔线下方，对每一列独立执行压缩：将该列中所有非背景像素（绿(3) 和可能的传入蓝(1)/红(2)）向底部边缘推移，保持它们的上下相对顺序不变，空出的格子变为黑(0)。
5. 分隔线本身保持灰(5) 不变。输出最终网格。

**关键洞察**：标记的高度是一个隐式状态变量——它决定该标记执行"原地生长"还是"擦除并远程传色"。传色操作向分隔线下方注入了新颜色，改变了压缩后通道底部的颜色排列。需要对比多个示例才能归纳出高度阈值（1 格 vs 2 格）以及传色的目标位置规则。

## 新题 5：参照条对齐后围合填充

**组合逻辑**：[对齐 + 同色对齐 + 首行为参照](来自参考题但作用对象改变) → [填充 + 内部包含](创新：对齐操作改变拓扑连通性，产生新围合区域，填充色由预置标记决定)

**来源原语**：滑动/shift + 对齐/align + 同色对齐/same_color_align + 双色条/two_color_bar + 参考条/reference_bar + 首行为参照/top_row_reference（来自 9968a131）；填充/fill + 内部包含/interior_containment（来自 b0c4d837）；标记像素/marker_pixel（来自 f0df5ff0/e3fe1151）

**依赖链**：参考条定义了每种颜色的目标列 → 反转条的平移改变了条的水平位置 → 位置改变后，条与条、条与标记、条与网格边缘共同围成新的封闭背景区域 → 封闭区域用标记颜色填充。对齐步骤本身不知道会产生什么封闭区域，封闭区域的出现是对齐的涌现效应。

将散布的双色条按顶行参考条对齐，对齐后新出现的被围合背景区域用预置标记的颜色填充。

**输入结构**：
- 约 12x10 的网格，背景为黑(0)。
- 最顶行是参考条：蓝(1) 和红(2) 各占一半列，呈固定的左右分布（如偶数列蓝、奇数列红，或左半蓝右半红）。参考条覆盖整行。
- 参考条下方有 4~7 行各包含一个水平双色条（2 像素宽：一格蓝(1)、一格红(2)，相邻），其余格为黑(0) 背景。部分条的蓝-红顺序与参考条一致（正向），部分反转（红在左、蓝在右）。
- 网格中还散布 1~3 个绿(3) 单像素标记，位于双色条之间的背景区域中。标记不与任何条 4-相邻。
- 生成约束：反转条的对齐移动后，至少有一个由参考条、若干对齐后的条、绿标记和/或网格左右边缘共同围成的 4-连通封闭黑(0) 背景区域。对齐前该区域不封闭。

**规则**：
1. 对每个双色条检查其蓝(1) 像素是否在参考条中蓝(1) 所在的列上。若是，该条已对齐，不移动。
2. 若该条反转（蓝像素不在参考条蓝列上），将整个双色条水平平移，使蓝(1) 像素落在参考条中距其当前位置最近的蓝(1) 列上，红(2) 像素落在相邻的红(2) 列上。条移动后原位置变为黑(0)。
3. 对齐完成后，识别所有 4-连通的黑(0) 背景区域。
4. 对每个不与网格边缘 4-连通的封闭背景区域，将区域内所有黑(0) 像素填充为绿(3)（与预置标记同色）。
5. 绿(3) 标记像素本身保留。输出最终网格。

**关键洞察**：对齐操作是纯水平移动，看似只改变条的 x 坐标，但条的新位置可能恰好封堵了原本通向网格边缘的背景通道，使一片背景变为封闭区域。填充色固定为绿(3)（与已有标记同色），但这一映射关系必须通过对比多个示例确认，因为标记的作用不是"指向"而是"定义颜色"。

## 新题 6：擦除内部描外轮廓按围合面积排列

**组合逻辑**：[擦除 + 轮廓描边 + 最小色为画笔](创新：对多个独立物体分别执行轮廓描边，每个物体的画笔色由其内部标记决定) → [裁剪 + 排序 + 拼接 + 基线对齐排列](创新：排序键为轮廓围合面积而非像素面积或边界框面积)

**来源原语**：擦除/erase + 轮廓描边/outline_trace + 外侧相邻/outer_adjacent + 标记色/marker_color + 最小色为画笔/smallest_as_paint（来自 aa62e3f4）；排序/sort + 裁剪/crop + 拼接/concatenate + 面积排序/area_ordering + 基线对齐排列/baseline_aligned_pack（来自 4df5b0ae）

**依赖链**：物体内部标记色决定轮廓的绘制颜色 → 擦除+描边改变了每个物体的几何形态（实心变空心） → 轮廓围合的内部面积（非像素数）成为排序键 → 排序后按基线对齐拼接。形态变换、颜色来源、排序键三者各自依赖前一步的结果。

将每个填充物体替换为用其内部标记颜色绘制的外轮廓，裁剪后按轮廓围合的内部面积从小到大底部对齐排列。

**输入结构**：
- 约 20x20 的网格，背景为黑(0)。
- 网格中有 3~5 个互不相邻的单色 4-连通填充前景物体（每个物体 6~20 像素，形状不规则但无孔洞，颜色各不相同，可选蓝(1)、红(2)、绿(3)、灰(5)、品红(6)、橙(7)）。
- 每个物体内部恰好包含 1 个不同颜色的标记像素（如物体为蓝(1) 而标记为黄(4)）。标记像素被物体像素 4-邻域包围（不在物体边缘）。
- 生成约束：各物体的轮廓围合内部面积（轮廓内部黑像素数 = 物体像素数 - 轮廓像素数）互不相同。各物体的总像素面积排序与围合内部面积排序不同（至少有一对物体的两种排序逆序），以确保排序键的选择是非显然的。

**规则**：
1. 对每个前景物体，记录其填充颜色和内部标记像素的颜色。
2. 擦除物体的所有原色像素为黑(0)。
3. 在原物体占据的每个像素位置，检查其 4-邻域中是否有至少一个黑(0) 背景格（即该像素是否在物体的外边界上）。若是，该位置为轮廓像素；若否（即被物体完全包围），则不是轮廓像素。
4. 将所有轮廓像素涂为该物体的标记颜色。非轮廓位置保持黑(0)。标记像素本身若在轮廓上则涂标记色，否则保持黑(0)。
5. 裁剪每个轮廓图形到其最小边界框。
6. 计算每个轮廓的围合内部面积：边界框内被轮廓完全 4-连通包围的黑(0) 像素数（即无法从该黑像素通过 4-连通路径到达边界框外部的黑像素的数量）。
7. 按围合内部面积从小到大排序。
8. 将排序后的轮廓图形从左到右排列在一个新网格中：每个图形的边界框底边对齐于输出网格的最底行，相邻图形的边界框之间间隔 1 列黑(0)。输出网格的高度为最高边界框的高度，宽度为所有边界框宽度之和加间隔。

**关键洞察**：排序键是轮廓围合的空心面积，而非物体的像素总数或边界框面积。一个像素多但形状细长的物体可能围合面积很小，而一个像素少但形状紧凑的物体围合面积反而大。需要对比多个示例中不同物体的排列位置，才能区分出排序键是围合面积而非其他度量。

## 新题 7：跨象限局部遮挡序融合全局层序

**组合逻辑**：[补全/reconstruct + 遮挡层序](创新：每个象限只能恢复部分层序) → [颜色多重集相同 + 各区域缺像素](创新：多重集比较识别每个象限缺失的那一色) → 约束融合推断全局排序(创新)

**来源原语**：补全/reconstruct + 遮挡层序/occlusion_order + 空心矩形/hollow_rectangle + 重叠层/overlap_layer + 重叠定先后/overlap_determines（来自 68bc2e87）；颜色多重集相同/same_color_multiset + 各区域缺像素/region_miss_pixel + 分隔线/divider_line + 矩形区域/rect_region（来自 e3fe1151）

**依赖链**：每个象限的可见像素重建出部分矩形框 → 重叠处揭示该象限内可见色的局部遮挡顺序 → 四个象限各缺一色，多重集比较确定每个象限缺哪个 → 四份局部遮挡序合并为唯一的全局从底到顶层序。任何单一象限都无法给出完整答案。

四个象限各含三种重叠空心矩形框（共四种色各缺一种），比较象限以识别各自缺失色，融合四份局部遮挡序得到全局底到顶层序并输出为单列。

**输入结构**：
- 约 15x15 的网格，背景为黑(0)。
- 一条完整的灰(5) 水平分隔线和一条完整的灰(5) 垂直分隔线将网格分为四个等大的矩形象限。
- 全局使用 4 种前景色（如蓝(1)、红(2)、绿(3)、黄(4)），代表 4 层空心矩形框。每个框为 1 像素厚的矩形边框。
- 在每个象限内，有 3 个不同颜色的空心矩形框部分重叠。重叠处只显示较高层的颜色。每个象限恰好缺少 4 种颜色中的 1 种（该色的矩形框在该象限完全不可见——被其上方的框完全遮挡，或干脆不存在于该象限）。
- 四个象限各缺不同的 1 种颜色，即四种色在四个象限中各缺一次。
- 生成约束：四个象限的局部遮挡顺序与全局层序一致（在每个象限中可见的 3 色子序列是全局 4 色序列的子序列）。全局层序唯一。每个象限中至少有一个像素位置有两个框重叠，以便推断局部遮挡关系。

**规则**：
1. 在每个象限中，对每种可见前景色，将该色所有可见像素的最小外接矩形作为该色矩形框的重建结果。
2. 在每个象限中，找出两个重建矩形框重叠的像素位置。该位置显示的颜色在遮挡层序中高于被遮挡的颜色。由此推断该象限中 3 种可见色的相对遮挡顺序（局部偏序）。
3. 比较四个象限的可见颜色集合：全部 4 种前景色的并集为 {蓝(1), 红(2), 绿(3), 黄(4)}，每个象限只有 3 种。缺失的那种颜色即为该象限被完全遮挡或不存在的颜色。
4. 将四个象限的局部偏序合并：全局层序必须与每个局部偏序一致。由于每个象限提供了 4 色中 3 色的完整顺序信息，四份合并后唯一确定 4 色的全局从底到顶顺序。
5. 输出为一个 4 行 1 列的网格，从第 1 行到第 4 行依次填入全局层序的从底（最先绘制、最易被遮挡）到顶（最后绘制、最不易被遮挡）的颜色。

**关键洞察**：任何单个象限只能确定 3 色的相对顺序——缺失色在全局序列中的位置只能通过其他象限的证据推断。多重集比较告诉你"缺了谁"，而遮挡关系告诉你"谁在谁上面"，两者必须结合才能求解。

## 新题 8：连线计数驱动错切方向

**组合逻辑**：[连线 + 行列对齐 + 碰撞停止](创新：连线不只是视觉效果，其方向分布编码了几何变换参数) → [平移 + 贴墙移动](创新：移动方向由连线已确定) → [错切 + 逐行偏移](创新：错切方向和幅度由连线的方向统计决定)

**来源原语**：连线/draw_line + 行列对齐/row_col_align + 碰撞停止/collision_stop + 矩形/rectangle + 孤立像素/isolated_pixel + 对齐像素投射矩形/aligned_pixel_to_rect（来自 2c608aff）；错切/shear + 平移/translate + 贴墙移动/move_to_wall + 逐行偏移/row_offset_incr + 网格边缘/grid_edge + 前景物体/foreground_object（来自 9f41bd9c）

**依赖链**：行列对齐的孤立像素向矩形投射连线 → 连线从上方和下方到达矩形的数量对比确定错切方向 → 矩形移到对面墙后，按该方向逐行偏移。连线数统计是一个中间信息变换步骤——它将空间分布转换为单一方向信号。

将与矩形行列对齐的孤立像素连线至矩形，统计从上方和下方到达的线数之差确定错切方向，然后将矩形移到对面墙并按此方向错切。

**输入结构**：
- 约 15x12 的网格，背景为橙(7)（非黑色背景）。
- 一个蓝(1) 填充矩形（约 3x4~4x5 像素）紧贴网格的左侧或右侧边缘。矩形不跨越网格半高。
- 4~6 个不同颜色的单像素（可选红(2)、绿(3)、黄(4)、品红(6)、青(8)），散布在网格中远离矩形的位置。其中部分像素与矩形共享同一行或同一列（行列对齐），部分不对齐。
- 生成约束：至少 1 个像素从上方对齐（与矩形共享某列，且行号小于矩形顶部行）、至少 1 个从下方对齐（行号大于矩形底部行）、至少 1 个从侧方对齐（与矩形共享某行）。从上方到达的对齐像素数与从下方到达的不相等。

**规则**：
1. 识别背景色（像素数最多的颜色，即橙(7)）、最大前景矩形（蓝(1)）、以及所有其他单像素。
2. 对每个单像素，检查它是否与蓝矩形共享某一行或某一列。若是，沿该行或列方向朝矩形画一条同色直线，直到线的下一个像素将进入矩形区域时停止（线不覆盖矩形）。不对齐的像素不画线。
3. 统计到达矩形各侧的线数：上方线数 U（线从矩形上方向下到达）、下方线数 D（线从矩形下方向上到达）。侧方线不参与此统计。
4. 将蓝矩形从当前贴靠的墙移到对面墙（若原在左墙则移到右墙，反之亦然），保持行位置不变。原位置变为背景色。
5. 对移动后的矩形施加错切：
   - 若 U > D：矩形的每一行相对于最顶行向右偏移，偏移量 = (该行在矩形内的行索引) x 1 像素。即最顶行不动，第二行右移 1，第三行右移 2，以此类推。
   - 若 D > U：矩形的每一行相对于最顶行向左偏移，偏移量同上。
   - 偏移后超出网格边界的像素被裁剪（不显示）。
6. 连线保留在输出中。输出最终网格。

**关键洞察**：连线步骤有双重用途——它既在网格上画出可见的线条，又隐含地对矩形的后续变换投票。上方线和下方线的数量对比决定错切方向，但解题者在第一个示例中可能误以为错切方向由矩形所贴的墙决定。需要对比线数分布不同的多个示例，才能发现真正的驱动因素是线的方向统计。

## 新题 9：面板重叠统计螺旋仪表阵列

**组合逻辑**：[透明叠加 + 位置对齐](创新：叠加不生成交集掩码，而是计算每种颜色的逐色重叠统计量) → [计数 + 面积排序](创新：计数对象是逐色重叠像素数) → [螺旋填充](创新：填充量编码重叠统计而非液位高度)

**来源原语**：透明叠加/transparent_overlay + 面板/panel + 分隔行/separator_row + 位置对齐/positional_alignment + 双面板背景交集/both_panels_background_intersection（来自 0c9aba6e）；计数/counting + 螺旋填充/spiral_fill + U形框架/u_shaped_frame + 仪表盘/gauge_output + 空行数映射填充量/empty_rows_map_to_fill_amount（来自 b0c4d837）；排序/sort + 面积排序/area_ordering（来自 4df5b0ae）

**依赖链**：分隔行将网格分为两个面板 → 面板对齐后逐色计算重叠像素数 → 重叠数决定螺旋仪表的填充量 → 各色区域的总面积决定仪表的排列顺序。叠加提供统计输入，计数转化为编码量，排序决定空间布局。

将两个面板位置对齐，统计上面板每种颜色区域与下面板前景区域的重叠像素数，按上面板各色总面积从小到大排列 3x3 螺旋仪表。

**输入结构**：
- 约 7x13（宽大于高）的网格，背景为黑(0)。
- 正中间一行为品红(6) 分隔行，将网格分为上下两个等大的面板（如各 3x13）。
- 上面板包含 2~4 个单色 4-连通前景区域，颜色各不相同（可选蓝(1)、红(2)、绿(3)、黄(4)），每个区域 3~8 像素，不触碰分隔行。
- 下面板包含 2~3 个单色 4-连通前景区域，颜色为灰(5) 或青(8)（不与上面板颜色重复），每个区域 4~10 像素。
- 上下面板的前景区域在位置上有部分重叠（若去掉分隔行将两面板叠合，某些上面板前景像素的位置对应下面板的前景像素位置）。
- 生成约束：上面板至少有 2 种颜色的区域与下面板前景有重叠。每种颜色的重叠像素数在 1~7 之间（适合 3x3 仪表显示）。不同颜色的总像素面积互不相同。

**规则**：
1. 移除品红(6) 分隔行，将上下面板按位置对齐（上面板第 i 行第 j 列 对应 下面板第 i 行第 j 列）。
2. 对上面板中的每种前景色 C，计算重叠数 O(C)：在对齐后的位置中，上面板像素为 C 且下面板像素为任意非黑(0) 前景色的位置数量。
3. 对上面板中的每种前景色 C，计算总面积 A(C)：上面板中颜色为 C 的像素总数。
4. 将上面板的所有前景色按 A(C) 从小到大排序。A(C) 相同则按颜色编号从小到大排序。
5. 输出一个 3 行宽的网格，包含排序后的 3x3 仪表方块从左到右排列，相邻仪表间隔 1 列黑(0)：
   - 每个仪表为 3x3 网格，背景为黑(0)。
   - 从左上角开始，沿顺时针螺旋方向（右→下→左→上→...）依次填充 O(C) 个像素为颜色 C。螺旋顺序为：(0,0), (0,1), (0,2), (1,2), (2,2), (2,1), (2,0), (1,0)，最多 8 格。中心 (1,1) 不在螺旋路径上。
   - 若 O(C)=0，仪表为全黑 3x3。
6. 输出网格高度为 3，宽度为 (仪表数 x 3) + (仪表数 - 1)。

**关键洞察**：面板叠加在参考题 0c9aba6e 中产生交集掩码（布尔结果），而这里叠加产生逐色计数（数值结果），编码到螺旋仪表中。仪表的排列顺序由总面积决定而非重叠量——面积最小的色排最左但其仪表填充量未必最少。需要多个示例才能区分排列键（总面积）和填充量（重叠数）是两个独立的度量。
