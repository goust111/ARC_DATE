## 新题 1：重力沉降决定同心色带调色板

**组合逻辑**：[重力下落](创新：作用于标记像素而非水像素，沉降结果编码为调色板序列) → [填充/同心矩形带](已有原语：循环色带填充) + [碰撞停止](已有) + [距离决定调色板](创新：距离读数不变，但调色板来源从静态标记位置变为动态沉降后的排列)

**来源原语**：重力下落、碰撞停止、沿路径滑动（参考题 28a6681f）；填充、同心正方形层、距离决定调色板、循环色带（参考题 13e47133）；分区区域（参考题 13e47133）

**依赖链**：重力改变标记像素的空间排列 → 沉降后的水平读序构成调色板 → 调色板驱动 Chebyshev 距离的循环色带填充。删去重力则调色板顺序由原始散布位置决定（不同结果）；删去色带填充则重力只是把点往下移（无有意义输出）。

将散布在分区房间内的标记像素做重力沉降，沉降堆叠后的排列顺序定义该房间的循环同心色带调色板，再按 Chebyshev 距离逐层涂色。

**输入结构**：约 16x16 的网格，灰(5) 单像素宽直线将网格分成 2-3 个矩形房间。每个房间内部背景为黑(0)，含 2-4 个孤立标记像素，颜色互不相同且不为黑(0)或灰(5)（例如红(2)、蓝(1)、绿(3)等），散布在房间内任意位置。不同房间的标记颜色集合可以相同也可以不同。生成约束：同一房间内不存在两个标记像素位于同一列（保证沉降后每列至多一个标记，消除堆叠歧义）。

**规则**：
1. 识别每个由灰(5)墙围成的矩形房间。
2. 在每个房间内，对所有标记像素执行向下重力模拟：每个标记从当前位置向下移动，直到碰到房间底部墙壁或已沉降的另一个标记（即紧邻其上方一格停住）。处理顺序：起始行号最大（最靠近底部）的标记先沉降，依次向上。由于同列至多一个标记，此顺序保证无冲突。
3. 沉降完毕后，在每个房间内，将所有已沉降标记按列号从小到大排序（即从左到右读取），形成该房间的颜色调色板 palette。
4. 对房间内每个非墙单元格，计算其到该房间最近墙壁像素的 Chebyshev 距离 d（即 max(|dr|, |dc|) 的最小值，遍历房间四面墙壁上所有像素取最小）。
5. 将该单元格涂为 palette[d mod len(palette)]。
6. 灰(5)墙壁保持不变。标记像素原位置被色带覆盖（标记自身不保留）。

**关键洞察**：两个房间可以有完全相同的标记颜色集合，但标记散布的列位置不同导致重力沉降后左右排列不同，从而产生不同的同心色带图案。求解者必须先推断重力沉降规则，再发现沉降后的水平排列决定调色板，最后识别 Chebyshev 距离驱动的循环填充——三步中任一步的遗漏都无法还原输出。

## 新题 2：对称补全后的逐列异或合成

**组合逻辑**：[对称补全](创新：不是将碎片归位到插槽，而是在原地补全碎片的旋转对称形态) → [异或合成](创新：不是比较上下两个给定掩码，而是比较同列上下两个由补全产生的掩码) + [重涂色](已有：XOR 结果用新颜色标记)

**来源原语**：对称补全、瓦片碎片（参考题 4e45f183）；异或合成、半区掩码、恰一为前景（参考题 31d5ba1a）；重涂色（参考题 08ed6ac7）

**依赖链**：对称补全改变每个瓦片的前景掩码 → 改变后的掩码作为 XOR 的输入 → XOR 结果取决于补全后的形态而非原始碎片形态。如果跳过补全直接 XOR 原始碎片，结果完全不同；如果跳过 XOR，补全本身不产生最终输出的缩减形式。

将上下两行瓦片中的前景碎片各自按 180 度旋转对称补全，然后对每列的上下瓦片做异或合成，输出差异掩码。

**输入结构**：约 13x19 的网格，黑(0)背景上用灰(5)单像素线分隔成 2 行 3 列共 6 个 5x5 的正方形瓦片。上行 3 个瓦片各含一个红(2)前景碎片（3-8 个像素的 4-连通区域），下行 3 个瓦片各含一个蓝(1)前景碎片。每个碎片是某个具有 180 度旋转对称性的完整图案的一部分（即碎片加上其 180 度旋转后的像素集合构成一个 180 度对称图形）。碎片至少包含完整图案 40% 的像素，使得补全后的图案可由碎片唯一确定。生成约束：同列的上下两个碎片补全后的掩码不完全相同（否则 XOR 为空，无意义）。

**规则**：
1. 对每个 5x5 瓦片，将其中的前景碎片绕瓦片中心(第 3 行第 3 列)做 180 度旋转，将旋转后新增的像素并入原碎片，得到补全后的完整掩码。
2. 对每一列（共 3 列），取上方瓦片的补全掩码和下方瓦片的补全掩码，逐像素比较。
3. 输出为 1 行 3 列的 5x5 瓦片阵列（共约 5x17，含分隔线）。每个输出瓦片中：恰好一个输入掩码为前景的位置涂绿(3)；两个掩码一致（同为前景或同为背景）的位置涂黑(0)。
4. 灰(5)分隔线在输出中保留。

**关键洞察**：碎片的缺失部分在补全后才显现，而这些"新增像素"往往是 XOR 差异的主要来源。一个看似与下方碎片几乎相同的上方碎片，补全后可能变得截然不同——因为它们各自缺失的部分恰好在不同位置。求解者需要先发现 180 度对称补全规则（对比多个示例中碎片与完整图案的关系），再发现逐列 XOR 合成规则。

## 新题 3：边界标记定向的分区重力场

**组合逻辑**：[填充/区域识别](创新：flood_fill 不用于涂色，而是用于确定各封闭区域的边界，从而为每个区域建立独立的物理场) + [重力下落](创新：重力方向不固定为向下，而是由区域边界上的标记像素颜色编码) + [碰撞停止](已有)

**来源原语**：填充(flood_fill)、分区区域(partitioned_region)（参考题 13e47133）；重力下落(gravity_drop)、水像素(water_pixel)、障碍物(obstacle)、沿路径滑动(slide_along_path)、碰撞停止(collision_stop)（参考题 28a6681f）；颜色索引匹配(color_index_matching)（参考题 7d18a6fb）

**依赖链**：区域识别确定哪些水像素属于哪个区域 → 区域边界标记的颜色决定该区域重力方向 → 重力在各区域内独立模拟。删去区域识别则无法确定每个水像素适用哪个方向；删去重力则标记颜色无用。结构为分支型：一个区域识别步骤产生多个独立的带方向重力模拟。

识别由墙壁围成的封闭区域，读取每个区域边界上的标记像素颜色来确定该区域的重力方向，然后在各区域内独立模拟水像素沿指定方向的沉降。

**输入结构**：约 18x18 的网格，灰(5)墙壁将网格划分为 3-4 个不规则（但均为正交多边形，即只有水平和垂直边）的封闭区域。每个区域内部背景为黑(0)，散布有 3-6 个蓝(1)水像素。每个区域的边界墙壁上恰好有 1 个标记像素，颜色为以下四种之一：红(2)表示重力向下，绿(3)表示重力向上，黄(4)表示重力向左，橙(7)表示重力向右。标记像素位于墙壁像素的位置（替换该处的灰(5)），与区域内部相邻。生成约束：同一区域内不存在两个水像素在重力方向的投影线上重叠（即沿重力方向看过去，每条投影线上至多一个水像素），消除沉降堆叠顺序的歧义。

**规则**：
1. 通过连通性分析，识别被灰(5)墙壁围成的每个封闭区域（黑(0)像素的 4-连通分量）。
2. 对每个区域，找到其边界墙壁上的唯一非灰(5)标记像素，读取颜色：红(2)→重力方向为(+1,0)即向下，绿(3)→(-1,0)向上，黄(4)→(0,-1)向左，橙(7)→(0,+1)向右。
3. 在每个区域内，对该区域所有蓝(1)水像素执行重力模拟：每个水像素沿该区域的重力方向直线滑动，穿过黑(0)背景像素，直到下一个位置是墙壁或已沉降的水像素时停止（碰撞停止）。
4. 处理顺序：在重力方向上距目标墙壁最近的水像素先沉降（例如重力向下时，行号最大的先处理）。
5. 水像素沉降后保持蓝(1)色，原位置恢复为黑(0)。
6. 灰(5)墙壁和边界标记像素在输出中保持不变。

**关键洞察**：相邻区域的重力方向可以完全相反。一个位于两区域边界附近的水像素，其最终位置完全取决于它属于哪个区域——即使在空间上它离另一个区域的"重力目标墙"更近。求解者必须先发现区域边界上的标记颜色与重力方向的对应关系（需要对比至少两个重力方向不同的区域），再理解区域归属决定适用规则这一分支结构。

## 新题 4：指示序列驱动的选择性面板叠合

**组合逻辑**：[颜色索引匹配](创新：不是用颜色选取精灵体并放入固定象限，而是用颜色选取面板并决定其图层优先级) + [透明叠加](创新：不是所有面板都参与且顺序固定，而是仅被选中的面板参与，且叠加顺序由外部序列编码) + [排序](隐含：指示序列的空间位置编码了排序信息)

**来源原语**：颜色索引匹配(color_index_matching)、选择器块(selector_block)、图例位置映射(legend_position_mapping)（参考题 7d18a6fb）；透明叠加(transparent_overlay)、面板(panel)、图层优先级(layer_priority)、面板位决定层序(panel_layer_order)（参考题 ea9794b1）；排序(sorting)（参考题 08ed6ac7）

**依赖链**：指示像素的颜色决定哪些面板被选中（筛选） → 指示像素的左右顺序决定选中面板的图层优先级（排序） → 按此优先级执行透明叠加得到输出（合成）。三步中任一步缺失都改变结果：缺筛选则所有面板参与（冗余面板干扰）；缺排序则叠加顺序不确定；缺叠加则筛选和排序无用。结构为隐式编码型：指示序列同时编码了选择集合和优先级两种信息。

读取网格底部的指示像素序列，用颜色匹配筛选出参与叠合的面板子集，用序列的空间位置定义图层优先级，按此优先级对选中面板做透明叠加。

**输入结构**：约 15x15 的网格。上半部分被均分为 2x2 共 4 个大小相等的面板（每个约 6x6），面板之间无分隔线，直接相邻。每个面板有唯一的前景颜色（红(2)、蓝(1)、绿(3)、黄(4)四选一，不重复）在黑(0)背景上绘制一个 4-连通的单色图形（4-10 像素）。网格最底行（与面板之间空一行黑(0)间隔）放置 2-3 个指示像素，每个占据 1 格，颜色各不相同，每个颜色恰好匹配某个面板的前景色。指示像素之间至少隔 1 列黑(0)。生成约束：被选中的面板前景图形在叠合区域至少有一处重叠（否则叠加顺序无法被观测，题目无法求解）。

**规则**：
1. 从网格最底行提取所有非黑(0)指示像素，按列号从左到右排列，形成指示序列。
2. 指示序列中的每个颜色唯一匹配一个面板（颜色相同）。仅这些面板参与后续叠合，其余面板被忽略。
3. 指示序列定义图层优先级：序列中越靠左的颜色对应的面板图层越低（先绘制，可被覆盖），越靠右的图层越高（后绘制，覆盖在先前图层之上）。
4. 创建一个与单个面板等大的黑(0)输出画布。按从左到右的指示顺序依次将对应面板的前景像素绘制到输出画布上。每个面板只绘制其前景像素（非黑(0)的像素），保留该面板自身的颜色。后绘制的面板前景像素覆盖先绘制的。
5. 输出仅为此单面板大小的画布（不包含原始的 2x2 面板区域和指示行）。

**关键洞察**：与参考题 ea9794b1 中四面板固定位置层序不同，本题的指示序列可以选择任意 2-3 个面板并以任意顺序叠合。同一组四面板在不同指示序列下产生不同输出——例如指示序列 [蓝, 红] 与 [红, 蓝] 会在重叠区域产生不同的颜色（前者蓝在下红在上，后者相反）。求解者必须先发现颜色匹配选择面板的规则，再发现空间位置编码优先级的规则。

## 新题 5：锚点连线上的循环双色距离条纹

**组合逻辑**：[连线](已有：相邻同行同列锚点间画线) + [重涂色/循环色带](创新：线段不是统一颜色，而是根据到两端锚点的距离做循环双色条纹) + [遇前景终止](已有：仅相邻锚点连接) + [距离决定调色板](创新：调色板不来自标记深度，而来自线段两端锚点的颜色)

**来源原语**：连线(connect)、空心十字标记(hollow_plus_marker)、线段(line_segment)、同行同列对齐(same_row_column_alignment)、仅相邻锚点间连接(connect_only_between_adjacent_anchors)（参考题 60a26a3e）；循环色带(cyclic_color_bands)、距离决定调色板(distance_determines_palette)（参考题 13e47133）；重涂色(recolor)（参考题 08ed6ac7）

**依赖链**：锚点连接拓扑决定哪些线段存在 → 线段的两端锚点颜色决定该线段的双色调色板 → 每个线段像素的距离决定取调色板中的哪个颜色。删去连线则无线段可涂色；删去距离条纹则连线为单一颜色（丢失端点颜色信息）。两个操作通过线段这一共享几何体紧密耦合。

在同行或同列的相邻锚点之间画连线，线段上每个像素的颜色由它到两端锚点的距离决定——距离为偶数取近端颜色，奇数取远端颜色，形成交替条纹。

**输入结构**：约 17x17 的黑(0)背景网格，放置 5-7 个空心十字标记（即 3x3 区域中仅上下左右四个臂像素存在、中心为空的十字形），十字臂像素统一为灰(5)。每个十字的中心空格填有一个独特的颜色像素（颜色从红(2)、蓝(1)、绿(3)、黄(4)、橙(7)、品红(6)中选取，不重复）。部分十字的中心在同一行或同一列，它们之间的间距不等（至少 4 格间隔，保证线段长度足够显示条纹）。生成约束：任意两个十字中心之间的直线路径上不经过第三个十字（保证"相邻"关系无歧义——两个同行/同列的锚点之间无其他锚点阻挡即为相邻）。

**规则**：
1. 计算每个十字标记的中心位置（3x3 区域的正中格）。
2. 对所有中心做行分组和列分组。在每个分组内按位置排序（行内按列号升序，列内按行号升序）。
3. 对每组中的每对相邻中心（排序后紧邻的两个），在它们之间的背景像素上画连线：起点为靠近第一个中心的灰(5)臂外侧一格，终点为靠近第二个中心的灰(5)臂外侧一格（即连线不覆盖十字本身的臂像素）。
4. 对连线上的每个像素，计算它到两端中心的曼哈顿距离 d1 和 d2（因为线段为水平或垂直，曼哈顿距离等于直线距离）。令 d = min(d1, d2)（到较近端的距离）。若 d 为偶数（含 0），涂较近端中心的颜色；若 d 为奇数，涂较远端中心的颜色。若 d1 == d2（线段正中央），涂两个中心中行号较小者（若行号相同则列号较小者）的颜色。
5. 十字标记的灰(5)臂像素和彩色中心像素保持不变。

**关键洞察**：连线的条纹图案同时编码了两个信息：(a) 条纹的两种颜色揭示了线段两端是哪两个锚点，(b) 条纹的周期/相位揭示了线段的长度奇偶性。短线段可能只展示 1-2 个颜色交替，长线段则展示完整的周期条纹。求解者需先发现"仅相邻锚点连线"的拓扑规则，再发现距离奇偶决定颜色的编码规则——两者对比多个不同长度的线段才能确认。

## 新题 6：障碍物裁剪格点补全与存活率着色

**组合逻辑**：[补全/印章覆盖](已有：笛卡尔积缺位填充) + [裁剪](创新：不是对面板做空间裁剪，而是障碍物像素阻挡印章的部分像素，产生残缺副本) + [计数](已有) → [重涂色](创新：不是按高度排名着色，而是按存活像素比例二分类着色)

**来源原语**：补全(completion)、印章覆盖(stamp_overlay)、同形精灵体(identical_sprite)、行列格点(row_column_lattice)、格点对齐(lattice_alignment)、笛卡尔积缺位填充(cartesian_product_gap_fill)（参考题 5b526a93）；障碍物(obstacle)、碰撞停止(collision_stop)（参考题 28a6681f）；计数(counting)、重涂色(recolor)、高度排名映射颜色(height_rank_to_color)（参考题 08ed6ac7）；裁剪(crop)（参考题 ea9794b1）

**依赖链**：格点补全确定在哪些位置印章 → 障碍物裁剪印章产生残缺副本 → 计数存活像素 → 存活率决定颜色。信息类型链式变换：空间拓扑→几何裁剪→数量统计→颜色分类。删去格点补全则无新精灵体可裁剪；删去障碍物则所有新精灵体完整无差异；删去计数/着色则裁剪效果不可见。

在部分被占用的矩形格点的空缺位置印章同形精灵体，但障碍物像素会遮挡印章的部分像素，然后按存活像素比例对每个新精灵体着不同色。

**输入结构**：约 19x19 的黑(0)背景网格。黄(4)像素构成若干（3-5 个）完全相同的 4-连通精灵体（每个 4-8 像素，边界框不超过 4x4），放置在一个矩形行/列格点上（即存在一组行起点和一组列起点，已有精灵体的左上角恰好在某些 (行起点, 列起点) 交叉处）。已有精灵体至少覆盖一整行和一整列的格点位。网格上另有若干橙(7)障碍物像素（10-20 个），散布在空缺格点位附近及其内部，但不与已有黄(4)精灵体重叠。生成约束：每个空缺格点位内至少有 1 个橙(7)像素但不全被覆盖（保证每个新精灵体都被部分裁剪且至少存活 1 个像素），使得不同空缺位有不同的存活像素数。

**规则**：
1. 从已有黄(4)精灵体中提取公共精灵体掩码（相对于精灵体左上角的像素偏移集合）和格点的行起点集合、列起点集合。
2. 对行起点集合与列起点集合的笛卡尔积中的每个位置，若该位置为空缺（无已有黄(4)精灵体），则尝试在该位置印章精灵体。
3. 印章时，精灵体掩码中与橙(7)障碍物像素重叠的位置不绘制（即该像素被裁剪，障碍物保留）。其余位置正常绘制。
4. 印章完毕后，对每个新印章的精灵体，计算其存活像素数 s（实际被绘制的像素数）。令 S 为精灵体掩码的总像素数。
5. 若 s > S/2（严格过半存活），该精灵体涂为绿(3)。
6. 若 s <= S/2（半数或更少存活），该精灵体涂为红(2)。
7. 原有黄(4)精灵体保持黄(4)不变。橙(7)障碍物像素保持不变。

**关键洞察**：同一个精灵体掩码在不同空缺位因为障碍物分布不同而产生不同程度的裁剪，裁剪程度又被量化为二分类颜色。求解者不能仅靠"格点补全"得到答案（颜色不对），也不能仅靠"数障碍物"得到答案（不知道在哪里数）。必须先推断出格点补全规则和精灵体掩码，再发现障碍物裁剪机制，最后发现存活率的二分类阈值——需要对比多个空缺位的不同裁剪结果与输出颜色来归纳阈值规则。
