## 新题 1：字形像素计数驱动的对角弹射轨迹

**组合逻辑**：[解码/decode](创新：字形前景像素数编码线段长度而非方向) → [射线延伸/ray_cast](创新：分段弹射，每段长度由字形像素数决定) + [反射弹回/reflection_bounce](已有) + [顺序排列/sequential_order](已有)

**来源原语**：
- 解码/decode, 字形/glyph, 弯头决定偏移/elbow_determines_offset, 顺序排列/sequential_order ← e6de6e8f
- 射线延伸/ray_cast, 反射弹回/reflection_bounce, 画布边界/canvas_boundary, 对角遇边反射/diagonal_with_wall_reflection ← a3df8b1e
- 起点标记/start_marker ← e6de6e8f

**依赖链**：字形解码产出有序的（段长, 颜色）序列 → 射线弹射过程逐段消费该序列，每段按对应长度前进并涂对应颜色 → 触壁反弹改变水平方向后切换到下一段。解码结果直接参数化弹射过程：删除解码则段长未知无法正确绘制，删除弹射则无路径可画。

将底部字形条带中每个字形的像素数和颜色依次解码为线段指令，从起点标记出发沿对角线逐段弹射绘制彩色路径。

**输入结构**：
- 黑(0)背景网格，约 15x20。
- 底部两行是一条字形条带：包含 3~5 个紧邻排列的单色 4-连通字形，每个字形跨两行、宽 2~4 列，颜色互不相同，从蓝(1)、红(2)、黄(4)、灰(5)、品红(6)中取。字形从左到右排列，之间无间隔。
- 网格中非底部两行的某个位置有一个绿(3)起点标记像素。
- 生成约束：所有字形的前景像素数之和不超过网格高度减 3（保证路径不会在中途因网格顶部耗尽而截断前消耗完所有指令）；起点标记不在最左列或最右列（保证首段有空间进行弹射而非立刻触壁）。

**规则**：
1. 从左到右读取字形条带中的每个字形，计算其前景像素数 P_i，记录其颜色 C_i，得到有序指令序列 [(P_1, C_1), (P_2, C_2), ...]。
2. 从起点标记出发，初始方向为右上对角（行减 1、列加 1）。起点标记保留绿(3)不被覆盖。
3. 从起点标记的下一格开始，沿当前方向逐格前进，将经过的每格涂为当前指令的颜色 C_i，每涂一格计数加 1。
4. 当计数达到 P_i 时，切换到下一条指令 (P_{i+1}, C_{i+1})，计数归零，继续沿当前方向前进。
5. 当路径下一步将越过左边界或右边界时，水平方向取反（左变右、右变左），垂直方向不变（始终向上）。若方向反转与指令切换发生在同一步，先执行方向反转再继续涂色。
6. 所有指令消耗完毕后停止绘制。
7. 输出网格尺寸与输入相同，底部字形条带保留不变。

**关键洞察**：字形的前景像素数量（而非字形的宽度、高度或几何外形）编码了线段长度——不同形状的字形可拥有相同的像素数，求解者必须对比多个示例才能确认"像素计数"是正确的编码维度。

## 新题 2：碎片合并后按对称性分支填充

**组合逻辑**：[补全/complete](已有：合并行列跨度重叠的碎片) → [对称检测/symmetry_detection](创新：检测碎片分布的水平镜像对称性) →⟨分支⟩ 对称：[填充/fill](实心填红) | 不对称：[填充/fill + 行列奇偶决定填充/parity_fill](棋盘格填充)

**来源原语**：
- 补全/complete, 残缺矩形/fragmented_rectangle, 行列跨度重叠/span_overlap, 合并对齐碎片/merge_aligned_fragments ← 8fbca751
- 对称检测/symmetry_detection, 镜像轴/mirror_axis, 对称否决定输出色/symmetric_vs_asym_color ← 44f52bb0
- 填充/fill, 棋盘格图案/checkerboard, 矩形内部/rectangle_interior, 行列奇偶决定填充/parity_fill, 边框与内部分离/border_interior_split ← ba9d41b8

**依赖链**：碎片合并确定每个矩形的完整边界框 → 在每个边界框内检测原始碎片像素分布的水平对称性 → 对称性结果决定两种不同的填充策略。删除合并则边界框未知；删除对称检测则不知选哪种填充模式；两种填充模式缺一则输出不完整。

合并同属一个残缺矩形的碎片，然后根据碎片分布的水平对称性选择实心或棋盘格方式填补缺失区域。

**输入结构**：
- 黑(0)背景网格，约 12x12。
- 前景色为青(8)，形成若干互不相邻的残缺矩形碎片。每个目标矩形由 2~4 个 4-连通碎片组成，碎片之间不直接 4-连通但其边界框在行跨度或列跨度上有重叠。
- 不同目标矩形的碎片组之间，边界框既不共享行跨度也不共享列跨度（保证合并分组无歧义）。
- 每个目标矩形的完整尺寸至少 4x4（保证内部有足够空间展示填充模式差异）。
- 生成约束：至少一个矩形的碎片分布关于其边界框水平中轴线镜像对称，至少一个不对称（保证两种分支都被示例覆盖）。

**规则**：
1. 找出所有青(8)前景像素的 4-连通碎片。
2. 若两个碎片的边界框在行跨度上有交集或在列跨度上有交集，则传递合并为同一组。
3. 对每个合并组，计算其所有像素的总边界框（最小行 R_min、最大行 R_max、最小列 C_min、最大列 C_max）。
4. 在该边界框内，检查原始青(8)像素的分布是否关于水平中轴线镜像对称：对每个青(8)像素 (r, c)，验证 (R_min + R_max - r, c) 也是青(8)像素。全部满足则判定为对称。
5. 若对称：将边界框内所有黑(0)背景格填为红(2)。
6. 若不对称：将边界框内的黑(0)背景格按棋盘格模式填充——以边界框左上角 (R_min, C_min) 为锚点，(r - R_min + c - C_min) 为偶数的背景格填红(2)，奇数的保持黑(0)。
7. 所有原始青(8)像素保持不变。输出网格尺寸与输入相同。

**关键洞察**：对称性检测的对象不是矩形轮廓本身（矩形轮廓天然对称），而是矩形边界框内碎片像素的空间分布——这一非显然的检测目标需要对比至少两个示例（一个对称矩形、一个不对称矩形）才能归纳出分支规则。

## 新题 3：按连通分量数量编码的同心方块图

**组合逻辑**：[计数/count](已有：统计8-连通分量数) → [排序/sorting](创新：按分量数而非边长降序) → [同心层填充/concentric_fill](创新：分量数决定方块边长)

**来源原语**：
- 计数/count, 连通分量/connected_component, 固定色序/fixed_color_order ← aaecdb9a
- 排序/sorting, 按边长降序排列/descending_side_order ← c658a4bd（创新为按分量数降序）
- 同心层填充/concentric_fill, 同心正方形层/concentric_layer, 嵌套层次/nesting_hierarchy ← c658a4bd

**依赖链**：分量计数将散布对象的空间信息压缩为每种颜色的单一数值 → 数值排序决定同心嵌套顺序 → 同心构建将排序后的数值重新空间化为正方形层。数值既编码方块边长又隐含嵌套层级：删除计数则边长和排序依据皆无，删除排序则嵌套顺序未定，删除同心构建则无空间输出。

统计每种前景色的 8-连通分量数量，按数量从多到少构建同心方块，数量最多的颜色作最外层。

**输入结构**：
- 黑(0)背景网格，约 15x15。
- 前景包含 3~5 种颜色的单色 8-连通对象，随机散布于网格各处。每种颜色有 1~5 个独立的 8-连通分量，每个分量为 2~8 像素的不规则连通形状（非矩形）。
- 不同颜色的分量数互不相同（保证排序无歧义）。
- 生成约束：颜色数 K >= 3；最大分量数 N_max 满足 2 * N_max - 1 <= 15（保证输出方块边长在合理范围内）。

**规则**：
1. 对每种非背景色，统计其 8-连通分量的数量 N_i。
2. 按 N_i 从大到小排序，得到颜色序列 [C_1, C_2, ..., C_K]，其中 N_1 > N_2 > ... > N_K。
3. 输出为正方形网格，边长 S = 2 * N_1 - 1。初始全部填充黑(0)背景。
4. 从外到内逐层绘制：对第 j 种颜色 C_j（j 从 1 到 K），用 C_j 填充一个边长为 2 * N_j - 1 的正方形，居中放置于输出网格。
5. 后绘制的小方块覆盖先绘制的大方块在重叠区域的像素。
6. 若 N_K = 1，则最内层仅绘制中心一个像素。

**关键洞察**：输入中对象的形状、位置和大小对输出完全无影响——输出仅编码"每种颜色有多少个独立分量"这一纯数量信息，以同心方块的几何嵌套重新表达。求解者需要从多个示例中发现"分量数量"而非"面积""像素总数"或"边界框大小"才是正确的编码维度，以及边长公式 2N-1 的具体映射关系。

## 新题 4：棋盘格内填与边缘投影的叠加冲突

**组合逻辑**：[填充/fill + 行列奇偶决定填充/parity_fill](已有：矩形内部棋盘格) ⊕ [填充/fill + 列投影重叠/column_projection_overlap + 较长侧优先/longer_side_priority](已有：边缘条带投影) → 冲突解决规则（创新：投影区域无条件覆盖棋盘格）

**来源原语**：
- 填充/fill, 棋盘格图案/checkerboard, 实心矩形/solid_rectangle, 矩形内部/rectangle_interior, 行列奇偶决定填充/parity_fill, 边框与内部分离/border_interior_split ← ba9d41b8
- 填充/fill, 边缘线段/edge_bar, 分隔行/separator_row, 列投影重叠/column_projection_overlap, 较长侧优先/longer_side_priority ← 770cc55f

**依赖链**：棋盘格填充独立作用于每个实心矩形的内部 → 边缘条带投影独立计算列重叠范围并在较长侧填充黄色 → 两条规则在矩形内部的列重叠区域产生冲突 → 冲突解决规则（投影优先覆盖棋盘格）是将两个独立变换统一为一致输出的关键。任一规则缺失则输出截然不同；冲突解决规则从任一源规则都无法推导，必须观察重叠区域才能归纳。

在实心矩形内部刻出棋盘格空洞，同时从较长边缘条带一侧向分隔行投影填充黄色，投影区域覆盖棋盘格。

**输入结构**：
- 黑(0)背景网格，约 14x14。
- 一条红(2)全宽水平分隔行将网格分为上下两个区域（分隔行不在首行或末行）。
- 首行有一段连续的蓝(1)水平条带（边缘线段），末行有另一段连续的蓝(1)水平条带，两段宽度不同（一长一短），且列范围有部分重叠。
- 上下区域中各有 1~2 个单色实心矩形（颜色为绿(3)或灰(5)），尺寸至少 4x4，矩形之间互不接触，不与分隔行或边缘条带所在行重叠。
- 生成约束：至少一个实心矩形的列范围与两段边缘条带的列重叠区域有交集（保证棋盘格与投影的冲突确实发生）。

**规则**：
1. 对每个实心矩形，保留其单像素宽的边框（最外圈像素）不变。将内部按棋盘格模式处理：以矩形内部左上角（边框内侧第一格）为锚点 (r_0, c_0)，(r - r_0 + c - c_0) 为偶数的内部格替换为黑(0)，奇数的保持矩形原色。
2. 计算首行蓝(1)条带和末行蓝(1)条带的列范围交集（重叠列集合）。
3. 比较两段条带的像素数。若首行条带更长，则在重叠列范围内，从首行下方第一行到分隔行上方第一行，逐格填黄(4)。若末行条带更长，则在重叠列范围内，从分隔行下方第一行到末行上方第一行，逐格填黄(4)。
4. 冲突解决：黄(4)投影填充优先级高于所有其他操作——若某格在步骤 1 中被设为黑(0)（棋盘格空洞）或保持了矩形原色，但在步骤 3 中落入投影区域，则最终颜色为黄(4)。
5. 下列像素不被投影覆盖：分隔行的红(2)、边缘条带的蓝(1)、矩形的边框像素（边框仍保持原色）。
6. 输出网格尺寸与输入相同。

**关键洞察**：棋盘格填充和边缘投影是两条各自合理的独立规则，但它们在空间上可以重叠——冲突解决规则（投影无条件覆盖棋盘格）不是任何一条源规则的自然推论，求解者需要观察重叠区域的实际输出并对比非重叠区域才能归纳出优先级关系。

## 新题 5：双掩码差异区按连通尺寸分类重涂

**组合逻辑**：[压缩/compress + 逐格比较/cell_comparison](已有：双掩码比较) → [重涂色/recolor + 尺寸分类/size_classification](创新：差异像素合并后按连通分量尺寸分类重涂不同颜色)

**来源原语**：
- 压缩/compress, 堆叠掩码/stacked_mask, 逐格比较/cell_comparison, 背景交集/bg_intersection, 双背景标记输出/both_bg_marks ← fafffa47
- 重涂色/recolor, 连通分量/connected_component, 尺寸分类/size_classification, 单像素分量重涂/single_pixel_component_recolored ← aedd82e4

**依赖链**：逐格比较两个堆叠掩码产出三类区域（仅上层前景、仅下层前景、双背景）→ 将仅上和仅下区域合并为"差异区"→ 差异区像素按 4-连通性分割为连通分量 → 单像素分量和多像素分量分别涂为不同颜色。比较结果定义了差异区的形态，差异区的拓扑结构（连通性）决定了重涂颜色。删除比较则无差异区；删除连通分类则差异区着色未定。

比较上下两个堆叠掩码，将差异区域按 4-连通分量大小分类重涂为不同颜色，双背景区域另色标注。

**输入结构**：
- 黑(0)背景网格，高度为偶数（如 12 行），宽度约 8~10。
- 上半区（前 H/2 行）和下半区（后 H/2 行）各为一个同尺寸的二值掩码。背景色相同为黑(0)；上半区前景色为绿(3)，下半区前景色为橙(7)。
- 每个掩码中前景像素形成若干 4-连通分量，每个分量大小从 1 像素到 5 像素不等。
- 两个掩码的前景区域有部分位置重叠（对应位置都有前景）、部分仅上有、部分仅下有。
- 生成约束：合并后的差异区中，至少包含一个 4-连通大小为 1 的分量和一个大小 >= 2 的分量。

**规则**：
1. 将网格沿行等分为上下两半，各 H/2 行。
2. 逐格比较上下半对应位置 (r, c) 和 (r + H/2, c) 的像素，生成一个 H/2 行 x W 列的输出网格：
   - 若上格为黑(0)且下格为黑(0)（双背景）：输出灰(5)。
   - 若上格为绿(3)且下格为橙(7)（双前景）：输出黑(0)。
   - 若仅上格为绿(3)、下格为黑(0)：标记该格为"差异格"。
   - 若仅下格为橙(7)、上格为黑(0)：标记该格为"差异格"。
3. 将所有差异格按 4-连通性划分连通分量。
4. 大小为 1 的连通分量（边界框 1x1）涂蓝(1)。
5. 大小 >= 2 的连通分量涂红(2)。
6. 输出网格尺寸为 H/2 行 x W 列。

**关键洞察**：前景重叠区域在输出中消失（变为背景黑(0)），而差异区域的着色不取决于差异来自上层还是下层，而取决于差异像素合并后形成的 4-连通分量大小——这种"先做集合差运算、再按拓扑属性分类"的两步逻辑需要对比多个示例才能区分于简单的"上层→一种色、下层→另一种色"的朴素映射。

## 新题 6：孤立像素配对编码全局颜色互换映射

**组合逻辑**：[重涂色/recolor + 孤立像素/isolated_pixel + 尺寸分类/size_classification](创新：孤立像素不被重涂而是作为编码载体) → [颜色互换/color_swap + 对象内双色配对/bicolor_pairing_within_object](创新：互换映射由外部编码而非对象自身决定)

**来源原语**：
- 颜色互换/color_swap, 前景对象/foreground_object, 对象内双色配对/bicolor_pairing_within_object, 同对象内互换/swap_within_same_object ← 45737921
- 重涂色/recolor, 孤立像素/isolated_pixel, 尺寸分类/size_classification, 单像素分量重涂/single_pixel_component_recolored ← aedd82e4
- 颜色配对/color_pairing ← 3e980e27

**依赖链**：识别孤立单像素并按空间距离配对 → 每对的两种颜色定义一条全局 A↔B 交换规则 → 在每个多像素双色对象内部按匹配的规则执行互换 → 孤立像素自身从输出中移除。孤立像素编码交换映射，多像素对象是映射的作用目标。删除孤立像素识别则映射来源未知；删除对象内互换则映射无处应用。

孤立单像素按距离配对，每对的两种颜色定义一条交换规则，然后在所有多像素双色前景对象内部执行该颜色互换，最后移除孤立像素。

**输入结构**：
- 黑(0)背景网格，约 12x15。
- 若干多像素前景对象：每个为 4-连通、5~12 像素的不规则连通形状，每个对象恰好使用两种非背景色。不同对象可使用相同的颜色对。对象之间互不 4-连通。
- 若干孤立单像素（4-连通分量大小为 1）散布在网格中远离多像素对象的位置。孤立像素总数为偶数（2 或 4 个），颜色各不相同。
- 孤立像素的颜色集合恰好覆盖所有多像素对象中使用的全部颜色。例如若对象用了蓝(1)和红(2)、绿(3)和黄(4)，则孤立像素恰好有蓝(1)、红(2)、绿(3)、黄(4)各一个。
- 生成约束：每个孤立像素到其最近孤立像素的曼哈顿距离唯一（保证贪心配对无歧义）。

**规则**：
1. 找出所有 4-连通分量大小为 1 的前景像素，标记为孤立像素。
2. 对孤立像素按曼哈顿距离贪心配对：反复取当前未配对像素中曼哈顿距离最小的一对进行配对（若距离相等则取行坐标之和更小的那对；仍相等则取列坐标之和更小的那对）。
3. 每对孤立像素的两种颜色 (A, B) 定义一条全局交换规则：所有 A 像素换为 B，所有 B 像素换为 A。
4. 对每个多像素前景对象，检查其包含的两种颜色是否匹配某条交换规则。若匹配 A↔B，则将对象内所有 A 像素换为 B、所有 B 像素换为 A。
5. 所有孤立像素从输出中移除，替换为黑(0)背景。
6. 输出网格尺寸与输入相同。

**关键洞察**：颜色互换的映射关系不是由对象自身的内部结构决定的（与参考题 45737921 中"每个对象自主互换"不同），而是由远处孤立像素对间接编码——求解者需要发现孤立像素的"配对 → 定义映射"这一间接编码机制，并从多个示例中确认配对规则是基于曼哈顿距离贪心而非其他准则。

## 新题 7：多对端点直角连线交叉后按拐角距离重涂

**组合逻辑**：[连线/draw_line + 拐角由终点列定/corner_at_target_col](已有：直角路径) → [重涂色/recolor](创新：交叉格按到各路径拐角点的距离竞争着色) + [行列交汇/row_col_intersection](创新：从单路径拐角扩展到多路径交叉网络)

**来源原语**：
- 连线/draw_line, 端点像素/endpoint_pixel, 直角路径/right_angle_path, 行列交汇/row_col_intersection, 拐角由终点列定/corner_at_target_col ← d4a91cb9
- 重涂色/recolor, 尺寸分类/size_classification ← aedd82e4
- 颜色配对/color_pairing ← 3e980e27

**依赖链**：为每对同色端点画直角路径 → 多条路径在网格上交叉产生重叠格 → 交叉格的最终颜色由该格到各贡献路径拐角点的曼哈顿距离决定。路径绘制产生涌现的交叉结构，交叉结构的着色需要距离比较规则。删除路径绘制则无交叉；删除距离规则则交叉格颜色不确定。

用直角路径连接每对同色端点，交叉格涂为拐角点离它最近的那条路径的颜色。

**输入结构**：
- 黑(0)背景网格，约 12x12。
- 2~4 种非背景色，每种恰好有两个像素（形成端点对），共 4~8 个前景像素。可用颜色如蓝(1)、红(2)、绿(3)、黄(4)等。
- 每对端点的两个像素既不在同行也不在同列。不同对的端点之间也不在同行或同列。
- 生成约束：至少有两条不同颜色的路径在某格交叉（即路径的行范围和列范围有重叠）。

**规则**：
1. 对每种颜色的两个端点像素 (r1, c1) 和 (r2, c2)，取 r1 < r2 者为起点（行更小）。画该颜色的直角路径：先水平——沿行 r1 从列 c1 画到列 c2（含两端），再垂直——沿列 c2 从行 r1 画到行 r2（含两端）。路径像素涂为该对端点的颜色。拐角点定义为 (r1, c2)。
2. 所有路径按颜色编号从小到大的顺序依次绘制。
3. 绘制完成后，检查每个非背景格是否被多条路径覆盖。
4. 仅被一条路径覆盖的格：保持该路径颜色。
5. 被两条及以上路径覆盖的交叉格：计算该格到每条贡献路径的拐角点的曼哈顿距离 d = |r - r_corner| + |c - c_corner|。取距离最小的路径的颜色涂该格。若距离相等，取颜色编号更小的路径。
6. 端点像素保持原色不变。
7. 输出网格尺寸与输入相同。

**关键洞察**：直角路径的走法（水平优先、行更小者为起点）和交叉格的归属规则（拐角距离最近者获胜）都是隐含规则——前者需要从多个示例中路径的实际走向来确认方向约定，后者需要观察交叉格的颜色归属来推断距离判据（而非简单的"后画覆盖先画"或"颜色编号优先"）。

## 新题 8：行翻转对比量化不对称度后裁剪异常者

**组合逻辑**：[镜像/mirror](已有：翻转行序) → [逐格比较/cell_comparison](创新：原图与翻转图逐格比较) → [筛选/filter + 异常值选择/outlier_selection](创新：以差异格数量为选择标准) → [裁剪/crop](已有)

**来源原语**：
- 镜像/mirror, 整幅画布/full_canvas ← 68b16354
- 逐格比较/cell_comparison ← fafffa47
- 筛选/filter, 颜色多样性比较/color_diversity_compare, 异常值选择/outlier_selection, 颜色最多者入选/most_colors_selected ← 9a4bb226（创新：选择标准从"颜色最多"变为"差异格最多"）
- 裁剪/crop ← 9a4bb226

**依赖链**：行翻转生成对比副本 → 逐格比较原图与副本，按每个前景对象所占区域统计差异格数量 → 差异格最多的对象（垂直方向最不对称者）被选为异常值 → 裁剪输出该对象。翻转产生对比基准，对比量化不对称度，不对称度决定选择目标，裁剪提取结果。删除翻转则无对比基准；删除比较则无法量化；删除选择则目标未定。

将网格上下翻转后与原图逐格比较，裁剪输出差异格最多（最不关于水平中轴对称）的前景对象。

**输入结构**：
- 黑(0)背景网格，约 10x10 到 14x14，高度为偶数。
- 3~5 个互不接触的单色前景对象，每个对象为 4-连通的不规则连通形状（4~10 像素），颜色各不相同，从蓝(1)、红(2)、绿(3)、黄(4)、灰(5)中取。
- 对象分布在网格的不同区域，有的位置接近水平中轴线（翻转后自身大致重叠，差异小），有的远离中轴线或形状不对称（翻转后差异大）。
- 生成约束：恰好一个对象的差异格数量严格最多（无并列），保证选择唯一。各对象的边界框互不重叠。

**规则**：
1. 生成行翻转副本：将原图的行 r 映射到行 H - 1 - r（H 为网格高度），逐行翻转。
2. 逐格比较原图与翻转副本：若 original[r][c] != flipped[r][c]，标记 (r, c) 为差异格。
3. 对原图中每个 4-连通前景对象 O_i，统计 O_i 所占据的像素位置中有多少是差异格，记为 D_i。
4. 选取 D_i 最大的对象 O_max 为目标。
5. 裁剪 O_max 的最小外接矩形（边界框），输出该子网格。裁剪区域内的背景格保持黑(0)。
6. 输出尺寸为 O_max 边界框的高 x 宽。

**关键洞察**：选择目标对象的标准不是颜色、面积、位置或形状复杂度，而是该对象相对于网格水平中轴的"不对称程度"——这个属性无法从对象本身直接观察到，必须通过"翻转→比较→计数"三步推理才能量化。求解者需要对比多个示例才能排除"面积最大""颜色最稀有"等更直觉的假设，发现"差异格最多"才是正确的选择准则。
