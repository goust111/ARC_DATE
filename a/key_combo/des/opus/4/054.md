## 新题 1：标记块定向周期射线

**组合逻辑**：[对角映射](创新：从区域填充改为射线方向分配) + [射线延伸] + [周期延伸](创新：周期由空间距离编码) → 三者通过标记块同时编码方向和周期参数实现紧耦合

**来源原语**：对角映射(93b581b8)、射线延伸(5c0a986e/79fb03f4)、周期延伸/长度即周期(1ae2feb7)、标记块(93b581b8)、种子像素(79fb03f4)

**依赖链**：标记块的 2x2 颜色排列决定四个方向各分配哪个颜色的射线；每个种子像素到标记块的曼哈顿距离决定该射线的闪烁周期；必须先从标记块读取方向-颜色映射，再从空间距离读取周期，最后才能绘制射线——三步缺一不可。

从一个 2x2 标记块出发，向四个对角方向发射周期闪烁的彩色射线，射线颜色由标记块的对角映射决定，闪烁周期由种子像素到标记块的距离决定。

**输入结构**：约 15x15 的黑(0)背景网格。网格中央偏左有一个 2x2 的标记块，四个像素颜色互不相同，均为非黑非灰颜色（如红(2)、蓝(1)、绿(3)、黄(4)）。在标记块的四个对角方向上（左上、右上、左下、右下），各有一个灰(5)种子像素，每个种子像素到标记块最近角的曼哈顿距离在 2~5 之间且互不相同。除标记块和种子像素外无其他前景像素。生成约束：每个种子像素到标记块最近角的对角延长线不出网格至少还有 6 格空间；四个种子像素分别严格位于标记块的四个对角象限内。

**规则**：
1. 标记块保持不变。
2. 对于标记块的每个像素，找到与该像素对角相对的象限中的那个灰(5)种子像素。该种子像素将发射一条射线，颜色为该标记块像素的颜色（即：左上标记色 → 分配给右下象限的种子，右上标记色 → 分配给左下象限的种子，以此类推，遵循对角映射关系）。
3. 每条射线从种子像素出发，沿远离标记块的对角方向逐像素延伸，直至离开网格。
4. 射线为周期闪烁模式：该种子像素到标记块最近角的曼哈顿距离为 d，则射线每连续 d 个像素着色、接下来 d 个像素保持背景色，如此交替，从种子像素自身开始计为着色段的第 1 个像素。
5. 种子像素本身被射线颜色覆盖（即种子像素位置显示射线颜色而非灰色）。

**关键洞察**：标记块是一个同时编码两种信息的紧凑结构——其颜色排列通过对角映射决定"谁发射什么颜色"，而种子像素相对于它的空间距离决定"以什么频率闪烁"；必须同时解码这两层信息才能确定输出。

## 新题 2：蛇形路径局部方向决定邻接物变换类型

**组合逻辑**：[展直/遍历顺序](创新：遍历不输出直列，而是用局部方向作为条件分支) + [重涂色/方框换为十字掩模](创新：变换类型由外部条件选择) + [擦除] → 蛇形路径的局部几何同时编码处理顺序和变换类型

**来源原语**：蛇形路径/端点/遍历顺序(7b5033c1)、重涂色/方框换为十字掩模(6c434453)、擦除(e9bb6954/6c434453)、空心矩形(6c434453)

**依赖链**：蛇形路径的遍历顺序决定对象的处理先后（影响重叠时谁覆盖谁）；蛇形路径在每个邻接点的局部行进方向（水平/垂直）决定对该邻接对象执行哪种变换（十字还是菱形）；两层信息都必须从同一条蛇形路径中提取，缺少任何一层都无法确定输出。

沿蛇形路径遍历，将路径旁的空心方框替换为十字或菱形——具体形态取决于蛇在该接触点的行进方向。

**输入结构**：约 14x14 的黑(0)背景网格。一条灰(5)像素构成的蛇形路径在网格中蜿蜒，路径宽度为 1 像素，4-连通，恰好有两个端点（仅一个路径邻居的像素）。路径总长约 20~30 像素，包含多个水平段和垂直段的转弯。沿路径散布 3~5 个 3x3 空心方框（八个边缘像素为同一非黑非灰颜色，中心为黑(0)），每个方框颜色可不同（如红(2)、蓝(1)、绿(3)等）。每个空心方框恰好有一个边缘像素与蛇形路径的某个像素 4-邻接。不同方框互不接触，也不与蛇形路径有多于一个接触点。生成约束：每个方框的接触点要么在蛇的水平段上，要么在垂直段上（不在拐角像素上）。

**规则**：
1. 从蛇形路径的两个端点中选择行索引更小的（若行索引相同则选列索引更小的）作为起点，沿路径逐像素遍历。
2. 当遍历到一个与某空心方框 4-邻接的路径像素时，检查蛇在该像素处的局部行进方向：
   - 若该像素的前驱和后继在同一行（水平段）：将该 3x3 空心方框替换为同色的十字（即擦除四个角像素为背景色，填充中心像素为该方框颜色，保留上下左右四个像素）。
   - 若该像素的前驱和后继在同一列（垂直段）：将该 3x3 空心方框替换为同色的菱形（即擦除上下左右四个像素为背景色，填充中心像素为该方框颜色，保留四个角像素）。
3. 若两个方框的变换结果有像素重叠，遍历中后处理的方框覆盖先处理的。
4. 蛇形路径自身在输出中被擦除（所有灰(5)路径像素变为黑(0)背景）。
5. 不与任何方框邻接的路径像素和不被方框变换影响的背景像素保持不变。

**关键洞察**：蛇形路径不产生直接输出，而是一个双重编码器——其拓扑连接决定处理顺序（影响重叠冲突），其局部几何（水平/垂直）决定对邻接对象施加哪种变换；路径本身随后被擦除，仅留下它所"指挥"的变换结果。

## 新题 3：碰撞距离编码平铺周期

**组合逻辑**：[射线延伸/碰撞产生侧翼](创新：碰撞不产生侧翼，而是记录碰撞距离) + [平铺/模板瓦片](创新：平铺周期由碰撞距离参数化) + [计数](创新：碰撞次数决定平铺层数) → 射线物理模拟的输出参数化了平铺操作

**来源原语**：射线延伸/行传播(79fb03f4)、碰撞产生侧翼(79fb03f4)、种子像素/障碍像素(79fb03f4)、平铺/模板瓦片(f931b4a8)、计数(d5c634a2/1fad071e)、像素数决定尺寸(f931b4a8)

**依赖链**：种子像素发射射线并撞击障碍像素 → 第一次碰撞的距离决定模板瓦片的水平重复周期 → 总碰撞次数决定模板瓦片的垂直重复层数 → 三个数值（射线颜色、碰撞距离、碰撞次数）分别控制平铺的颜色、宽度、高度，缺少任一都无法确定输出尺寸。

种子像素向右发射射线，第一次碰撞障碍的距离决定输出瓦片的宽度周期，总碰撞次数决定输出的行数。

**输入结构**：约 5x20 的黑(0)背景网格，分为上下两个区域。上方区域（前 2~3 行）：最左列有一个彩色种子像素（如蓝(1)），同一行中散布 2~4 个橙(7)障碍像素，每两个障碍像素之间至少间隔 2 格。下方区域（底部 2~3 行）：一个小型矩形模板瓦片（如 2x3 或 3x2），由 2~3 种非黑非橙颜色构成，左上角与网格左下区域对齐。两个区域之间有至少 1 行全黑分隔。生成约束：种子像素与第一个障碍像素的距离在 2~5 之间；障碍像素均在种子像素同一行；模板瓦片的宽度不超过种子到第一个障碍的距离。

**规则**：
1. 从种子像素向右发射射线（沿同一行），射线遇到障碍像素时停止该段，跳过障碍像素后继续向右发射，直到射线离开网格右边界或没有更多路径。记录：(a) 种子像素到第一个障碍像素的距离 d（不含种子和障碍本身，即中间的空格数）；(b) 射线撞击障碍像素的总次数 n。
2. 输出为一个新网格，尺寸为 n 行 x d 列。
3. 将下方区域的模板瓦片在这个 n x d 网格中进行平铺：模板从左上角开始，水平方向每隔模板宽度重复一次直到填满 d 列（右侧多余部分裁剪），垂直方向每隔模板高度重复一次直到填满 n 行（底部多余部分裁剪）。
4. 上方区域的射线、障碍、种子均不出现在输出中——输出仅为平铺后的新网格。

**关键洞察**：射线碰撞模拟是一个"参数提取器"而非视觉操作——它不改变画面，而是从空间布局中提取两个数值（首次碰撞距离和碰撞总数），这两个数值随后控制一个完全不同的几何操作（瓦片平铺）的尺寸参数。

## 新题 4：频率排序驱动的层叠掩码合并

**组合逻辑**：[计数/频率排序](创新：频率不输出列表，而是决定叠加的 z-顺序) + [透明叠加/多色掩码合并] + [裁剪/中心对齐] → 频率分析的输出成为叠加操作的优先级参数

**来源原语**：计数/频率排序/跳过最高频(f8b3ba0a)、透明叠加/中心对齐/多色掩码合并(c8cbb738)、前景掩码/边界框(c8cbb738)、单色矩形/颜色频率(f8b3ba0a)、裁剪(c8cbb738)

**依赖链**：先统计每种颜色的对象个数得到频率排序 → 频率最高的颜色被跳过不参与叠加 → 剩余颜色的掩码按频率从低到高依次叠加（频率低的先画、频率高的后画覆盖在上层）→ 频率排序同时决定"谁被排除"和"谁覆盖谁"，两个决策不可分离。

统计散布对象的颜色频率，跳过最高频颜色，将剩余颜色的掩码按频率从低到高叠加到一个紧凑画布上。

**输入结构**：约 18x18 的黑(0)背景网格。散布着 3~4 种非黑颜色的小型单色连通体（每个连通体 3~6 像素，4-连通，形状不规则），每种颜色有 2~6 个连通体。同一颜色的所有连通体形状不要求相同，但所有连通体的边界框不超过 4x4。各连通体之间互不接触（4-邻接意义下），各对象间至少有 1 像素间隔。不同颜色的对象数量互不相同。生成约束：每种颜色的所有对象的像素并集的边界框尺寸（取该颜色全部像素的最小外接矩形）互不相同，但最大不超过 10x10。

**规则**：
1. 对每种非黑颜色，统计其连通体数量（即对象个数，非像素数）。
2. 跳过对象个数最多的那种颜色（该颜色的所有对象在输出中不体现）。
3. 对剩余每种颜色，提取其所有像素相对于该颜色全部像素最小外接矩形左上角的相对坐标，形成该颜色的掩码。
4. 确定输出画布大小：取所有参与颜色的掩码边界框的最大高度和最大宽度，输出为该尺寸的黑(0)背景网格。
5. 按颜色频率从低到高（对象数少的先画），将每种颜色的掩码居中放置到输出画布上。居中规则：掩码边界框在画布中上下和左右各留相等余量（若余量为奇数，多余的 1 像素放在下方或右方）。
6. 后画的颜色覆盖先画的颜色（即频率较高的颜色在重叠处可见）。

**关键洞察**：颜色频率分析执行三重角色——决定哪种颜色被排除、决定剩余颜色的叠加顺序（z-order）、间接决定哪些颜色在重叠区域可见；这三个决策耦合在同一个频率排序中，不能独立求解。

## 新题 5：十字生成器交叉点的图例填充

**组合逻辑**：[射线延伸/十字图案](创新：十字交叉清空点不再保持空白，而是成为待填充槽位) + [交叉点重置背景] + [展开/图例锚定对齐](创新：图例不对孤立标记展开，而是对交叉点坐标进行编码查找) → 十字操作的"副产物"（交叉空洞）成为图例查找的输入

**来源原语**：射线延伸/十字图案/交叉点重置背景(e9bb6954)、实心方块(e9bb6954)、边缘图例串/颜色位置匹配/图例锚定对齐(5af49b42)、行列对齐(e9bb6954)、填充(93b581b8)

**依赖链**：实心方块生成十字 → 不同方块的十字在交叉点处清空为背景 → 交叉点的行坐标在边缘图例串中查找匹配颜色 → 该颜色填入交叉点。十字生成产生交叉位置，图例串解码交叉位置为颜色——两个操作的因果关系不可逆转。

实心方块各自生成全幅十字线，十字交叉处清空后由边缘图例串的对应位置颜色填入。

**输入结构**：约 13x13 的黑(0)背景网格。网格左侧第 0 列是一条竖直的边缘图例串：该列从上到下每个像素都有颜色（可重复），颜色取自非黑的 2~4 种颜色（如红(2)、绿(3)、蓝(1)）；图例串长度等于网格高度。网格内部（第 2 列到最右列的区域）散布 2~4 个 3x3 实心方块，每个方块为单一非黑颜色，各方块颜色可相同也可不同。各方块的中心行互不相同，中心列也互不相同。方块之间不相邻，到网格边缘（不含第 0 列）至少有 1 像素间距。第 1 列全为黑(0)，作为图例串与主区域的分隔。生成约束：每个方块的中心行 r 处，第 0 列的图例颜色与该方块自身颜色不同。

**规则**：
1. 保留输入中所有像素的初始状态（包括第 0 列图例串和第 1 列分隔）。
2. 对每个 3x3 实心方块，沿其中心行（在第 2 列至最右列的范围内）和中心列（在第 0 行至最底行的范围内）绘制该方块颜色的十字线，覆盖该行和该列上所有背景像素。方块自身的 9 个像素保持不变。十字线不覆盖第 0 列和第 1 列。
3. 当两个不同方块的十字线在某像素重叠时（即一个方块的中心行 = 另一方块的中心列所在行，且一个方块的中心列 = 另一方块的中心行所在列的交叉点），将该像素重置为黑(0)背景。
4. 对每个被重置为背景的交叉像素，读取该像素所在行 r 在第 0 列图例串中的颜色 C，将该交叉像素填充为颜色 C。
5. 第 0 列的图例串和第 1 列的分隔在输出中保持不变。

**关键洞察**：十字生成的交叉冲突不是需要回避的问题，而是设计的核心——交叉点被"挖空"后恰好成为需要填充的槽位，而填充颜色由一个完全独立的结构（边缘图例串）通过行坐标索引提供；求解者必须先完成十字模拟找到交叉位置，再用图例串查表才能确定最终颜色。

## 新题 6：镜像铺展后的多数决压缩

**组合逻辑**：[镜像/四象限排布](创新：镜像不是最终输出，而是中间步骤) + [压缩/多数决/格子格局] + [分隔行列](创新：分隔线由镜像对称轴自然产生) → 镜像操作制造对称冗余，压缩操作检测并消除冗余

**来源原语**：镜像/四象限排布/翻转形成对称铺展(62c24649)、压缩/多数决/每块取唯一多数色(af24b4cc)、分隔行列/格子格局/填色块(af24b4cc)

**依赖链**：先对输入做四象限镜像铺展 → 在镜像结果的对称轴上插入分隔线形成格子 → 对每个格子单元做多数决压缩得到最终输出。镜像产生的四倍冗余信息并非完全一致（因为输入含不对称噪声），多数决在四个镜像副本间"投票"消除噪声——跳过镜像步骤则无法做多数决，跳过多数决则输出尺寸不对。

将含噪声的小网格做四象限镜像后，利用分隔线划分格子并对每格做多数决，压缩回原始尺寸同时消除噪声。

**输入结构**：约 7x7 的网格，由灰(5)分隔线分成 3x3 的格子布局（2 行分隔线 + 3 行格子带，2 列分隔线 + 3 列格子带），每个格子单元为 2x2 像素。每个 2x2 格子单元主要由一种非黑非灰颜色填充，但其中恰好有 0~1 个像素是"噪声"——被替换为另一种非黑非灰颜色（不同格子的噪声颜色可不同）。整个网格共使用 3~4 种非黑非灰填充颜色。生成约束：每个 2x2 格子单元中，主色至少占 3 个像素（即噪声最多 1 个像素），保证多数决结果唯一；噪声像素的分布不具有镜像对称性（即至少有一个格子单元的噪声位置在镜像后不与另一象限对应位置的噪声重合）。

**规则**：
1. 将输入网格做四象限镜像铺展：先将输入水平拼接其左右镜像得到宽度翻倍的中间结果，再将该中间结果垂直拼接其上下镜像得到高度翻倍的结果。铺展后网格为 14x14。
2. 在铺展后的网格中，原始分隔线及其镜像副本仍然可见。以这些灰(5)分隔线为界，将铺展网格划分为格子单元。铺展后每个原始 2x2 格子单元在四个象限各有一个镜像副本，共形成 4 个 2x2 块。
3. 对于原始网格中的每个格子位置 (i, j)，收集其四个镜像副本在相同格子内位置上的 4 个像素颜色，对每个像素位置取多数决（4 个颜色中出现次数最多的颜色胜出；由于噪声不对称且最多 1 个噪声像素，多数决结果唯一）。
4. 输出一个与原始输入相同尺寸（约 7x7）的网格，保留灰(5)分隔线，每个格子单元填充多数决后的颜色。

**关键洞察**：镜像铺展看似增加了冗余，但正是这种冗余使得多数决有足够的"选票"来纠正噪声——每个像素位置有四个副本投票，至多一个被噪声污染，因此多数决总能恢复正确颜色；求解者必须理解镜像不是目的而是纠错手段。

## 新题 7：方向标记控制旋转后的距离排序堆叠

**组合逻辑**：[方向编码/着色标记](创新：方向标记不决定滑动目标，而是编码旋转角度) + [旋转] + [距离排序] + [堆叠] → 方向标记同时编码旋转参数和排序键

**来源原语**：方向编码/着色标记/色块决定输出位置(a8c38be5)、旋转/排序/堆叠/距离排序(291dc1e1)、精灵体(a8c38be5)、矩形(291dc1e1)

**依赖链**：每个精灵体内部的着色标记方向编码该精灵体需要旋转的角度（上=0度、右=90度、下=180度、左=270度）→ 旋转后的精灵体按其原始位置到网格左上角的曼哈顿距离排序 → 排序后从上到下堆叠。方向标记决定旋转，旋转改变精灵体外形，外形改变堆叠后的视觉结果——三步环环相扣。

读取每个小图案内部标记的方向以决定旋转角度，旋转后按到左上角的距离排序并竖直堆叠。

**输入结构**：约 16x16 的黑(0)背景网格。散布 3~5 个互不接触的小型精灵体，每个精灵体是一个 3x3 的灰(5)方块，其中一个边缘中点像素（上、下、左或右中点之一）被替换为一种非黑非灰颜色（如红(2)、蓝(1)、绿(3)等），作为方向标记。不同精灵体的方向标记颜色互不相同，方向标记的朝向也尽量不完全相同。每个精灵体除方向标记像素外的内部结构存在可区分的不对称特征：其 3x3 区域中有 1~2 个额外像素被替换为另一种非黑非灰颜色（与方向标记颜色不同），使得旋转后外观发生可辨别的变化。各精灵体到网格左上角 (0,0) 的曼哈顿距离（以精灵体 3x3 边界框左上角计算）互不相同。生成约束：精灵体之间至少间隔 2 像素。

**规则**：
1. 对每个精灵体，读取其方向标记像素相对于 3x3 中心的方位：
   - 标记在上方中点（第 0 行第 1 列相对位置）：不旋转（0 度）。
   - 标记在右方中点（第 1 行第 2 列相对位置）：顺时针旋转 90 度。
   - 标记在下方中点（第 2 行第 1 列相对位置）：旋转 180 度。
   - 标记在左方中点（第 1 行第 0 列相对位置）：顺时针旋转 270 度。
2. 对精灵体的完整 3x3 区域（含方向标记和额外特征像素）执行对应角度的顺时针旋转。
3. 计算每个精灵体的原始位置到网格左上角 (0,0) 的曼哈顿距离（精灵体 3x3 边界框左上角的行+列）。
4. 按曼哈顿距离从小到大排列旋转后的精灵体。
5. 输出网格宽度为 3，高度为 3 x 精灵体数量。将排序后的精灵体从上到下紧密堆叠（第一个占第 0~2 行，第二个占第 3~5 行，依此类推），无间隔。

**关键洞察**：方向标记在源题（a8c38be5）中编码滑动目标位置，在本题中被创新为编码旋转角度——同一种"方向读取"机制驱动了完全不同的几何变换；且旋转后精灵体的外观变化使得求解者必须同时追踪旋转和排序两步才能验证规则。

## 新题 8：触发条邻接溅射计数填充面板槽位

**组合逻辑**：[平移/邻接触发对角溅射](保留触发机制) + [计数/分类/朝向分组](创新：分类维度从朝向改为溅射方向) + [填充/面板/槽位/计数映射槽位] → 物理模拟的输出事件被分类计数后编码到面板中

**来源原语**：平移/邻接触发对角溅射/固定步长移动/触发条/移动像素(73c3b0d8)、计数/分类/朝向分组/朝向决定面板/计数映射槽位(d5c634a2)、填充/面板/槽位(d5c634a2)

**依赖链**：移动像素向下平移一步 → 判断是否落到触发条正上方产生溅射 → 将溅射事件按像素在触发条上的水平位置分为左半区和右半区 → 左半区溅射计数填入左面板、右半区溅射计数填入右面板。平移决定了谁触发溅射、触发位置决定了属于哪个面板、溅射数量决定了面板填多少格——三层逻辑依次嵌套。

将像素下移一步，触发条上方的溅射事件按左右半区分别计数，结果编码到双面板的槽位中。

**输入结构**：约 12x12 的黑(0)背景网格。底部某行（如第 9 行）有一条横贯全宽的灰(5)水平触发条。触发条上方 2~6 行处散布 4~8 个彩色移动像素，所有移动像素颜色相同（如红(2)）。移动像素分布在不同列，部分像素正好在触发条上方 1 行处（下移一步即触发），部分在更高位置（下移一步后不相邻，不触发）。网格右下角（触发条下方）留有一个 3x6 的黑(0)空白区域，将用作输出面板。生成约束：最终触发溅射的像素数量在 1~4 之间；触发条的列宽为偶数（可被平分为左右两半）；每个移动像素所在列互不相同。

**规则**：
1. 将所有红(2)移动像素从原位置擦除，并在原位置下方一行、同一列处绘制红(2)像素（即每个像素下移一步）。
2. 检查每个下移后的像素：若该像素紧邻触发条上方（即其行号 = 触发条行号 - 1），则该像素触发对角溅射——从该像素向左上和右上两个对角方向画射线，每条射线延伸直到离开网格，颜色为红(2)。未紧邻触发条的像素不产生溅射。
3. 将触发条按列平分为左半区和右半区（若触发条占第 0~11 列，则第 0~5 列为左半区，第 6~11 列为右半区）。
4. 统计左半区产生溅射的像素数量 L，统计右半区产生溅射的像素数量 R。
5. 在网格右下角的 3x6 空白区域中构造双面板：左侧 3x3 面板和右侧 3x3 面板。
   - 左面板：按左上、右上、左下、右下的顺序，将前 L 个角落槽位填充为绿(3)，其余保持黑(0)，中心像素始终为黑(0)。
   - 右面板：按左上、右上、左下、右下的顺序，将前 R 个角落槽位填充为蓝(1)，其余保持黑(0)，中心像素始终为黑(0)。
6. 对角溅射射线、下移后的像素、触发条本身在输出中保持可见。

**关键洞察**：对角溅射在源题中是纯视觉效果，在本题中溅射事件被重新解读为"可计数的离散事件"，再按空间位置分类——物理模拟的结果不仅改变画面，还经过空间分区和计数后驱动一个完全不同的编码系统（面板槽位填充）。

## 新题 9：分隔格子中蛇形遍历的周期着色

**组合逻辑**：[格子格局/分隔行列] + [展直/蛇形路径/遍历顺序](创新：蛇形路径不是输入对象，而是格子单元的遍历策略) + [周期延伸/长度即周期](创新：周期着色应用于格子遍历序列而非空间射线) → 格子提供空间结构，蛇形遍历提供序列化方案，周期提供着色规则

**来源原语**：格子格局/分隔行列/填色块(af24b4cc)、蛇形路径/遍历顺序/保留像素序(7b5033c1)、周期延伸/长度即周期(1ae2feb7)、色条(1ae2feb7)、填充(93b581b8)

**依赖链**：分隔线将网格分成格子 → 第一行的色条长度 k 定义着色周期 → 按蛇形顺序遍历格子单元并用色条颜色以周期 k 循环着色每个单元 → 格子结构决定单元总数和空间布局、色条决定颜色循环内容、蛇形遍历决定哪个单元分到哪个颜色——三者缺一不可。

按蛇形顺序遍历格子中的单元，用顶部色条的颜色序列周期性地为每个单元着色。

**输入结构**：约 13x13 的网格。最顶行（第 0 行）是一条水平色条，包含 2~4 种不同非黑非灰颜色的连续像素（如红(2)红(2)蓝(1)绿(3)，长度为 k=4），色条从第 0 列开始，后方为黑(0)。第 1 行全为黑(0)作为分隔。第 2 行起，灰(5)分隔线将剩余区域分成 m 行 x n 列的均匀格子（如 3x4 的格子布局），每个格子单元为 2x2 或 3x3 大小。所有格子单元初始为黑(0)背景。生成约束：格子总单元数 m*n 大于色条长度 k，保证至少完成一个完整周期；m >= 2, n >= 2。

**规则**：
1. 读取第 0 行的色条，记录其颜色序列为 C[0], C[1], ..., C[k-1]，长度为 k。
2. 按蛇形顺序遍历格子单元：第一行格子从左到右，第二行格子从右到左，第三行从左到右，依此交替（行指格子行，非像素行）。遍历产生单元序列 S[0], S[1], S[2], ...
3. 对第 i 个被遍历的格子单元 S[i]，将其所有像素填充为颜色 C[i mod k]（即色条颜色按周期 k 循环）。
4. 灰(5)分隔线和第 0 行色条在输出中保持不变。第 1 行分隔保持黑(0)。

**关键洞察**：蛇形遍历将二维格子线性化为一维序列，使得周期着色能按空间上非直觉的顺序分配颜色——同一行相邻的两个格子可能收到相距很远的周期位置颜色（尤其在蛇形折返处），求解者必须同时理解蛇形遍历规则和周期循环才能正确预测每个单元的颜色。

## 新题 10：像素放大倍率由对象面积决定的分区缩放

**组合逻辑**：[像素放大/均匀倍率缩放](创新：倍率不是全局统一的，而是逐区域由面积计数决定) + [计数/像素数决定尺寸] + [分类](创新：分类依据是面积而非朝向) + [拼接] → 计数结果参数化了缩放操作

**来源原语**：像素放大/均匀倍率缩放(c59eb873)、计数/像素数决定尺寸(f931b4a8)、分类(d5c634a2)、拼接(a8c38be5)、精灵体(a8c38be5)、边界框(c8cbb738)

**依赖链**：统计每个连通对象的像素面积 → 面积值即为该对象的放大倍率 → 对每个对象的最小外接矩形区域执行对应倍率的像素放大 → 将放大后的各对象按原始位置关系（左到右排序）水平拼接，间隔 1 列黑背景。面积计数直接转化为缩放参数——少一个像素意味着完全不同的输出尺寸。

统计每个前景连通体的像素面积，面积值即为其像素放大倍率，放大后按水平位置拼接。

**输入结构**：约 5x15 的黑(0)背景网格。水平排列 2~4 个互不接触的小型单色连通体（4-连通），每个连通体颜色互不相同（如红(2)、蓝(1)、绿(3)），像素面积在 2~4 之间。各连通体的最小外接矩形不超过 3x3。连通体之间至少间隔 2 列。每个连通体形状不对称（不是简单的矩形或正方形），使得放大后的外观变化清晰可辨。生成约束：各连通体面积互不相同；放大后所有对象水平拼接（含间隔）的总宽度不超过 30。

**规则**：
1. 检测所有非黑的 4-连通连通体，记录每个连通体的颜色、像素面积 a、最小外接矩形内容。
2. 对每个连通体，以其像素面积 a 为倍率，对其最小外接矩形区域执行像素放大：矩形中每个像素（含黑色背景像素）替换为 a x a 的同色块。放大后该对象区域尺寸为 (原高 x a) x (原宽 x a)。
3. 按各连通体在输入中的水平位置从左到右排序（以最小外接矩形左列坐标为键）。
4. 输出网格高度 = 所有放大后区域中的最大高度。宽度 = 所有放大后区域宽度之和 + (连通体数量 - 1) 作为间隔列数。
5. 从左到右将放大后的各对象区域放置到输出中，相邻对象间间隔 1 列黑(0)背景。每个对象顶部与输出顶部对齐，下方不足部分填黑(0)。

**关键洞察**：对象的面积既是被测量的属性又是控制后续操作的参数——面积为 2 的对象放大 2 倍而面积为 4 的放大 4 倍，这种"自引用"关系（对象自身的几何属性决定对自身施加的变换强度）需要求解者跨过"属性→参数"的概念桥梁。
