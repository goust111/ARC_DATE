## 新题 1：路径几何编码镜像轴

**组合逻辑**：[路径连通/path_connectivity](已有) → [路径几何→镜像轴类型](创新：路径的物理走向编码反射类型) → [镜像/reflect](已有，但轴由路径决定) + [颜色查找键/color_lookup_key](已有，但改为配对端颜色互换) → [擦除/erase](已有)

**来源原语**：路径网络/path_network、路径连通/path_connectivity、端点决定目标/endpoint_determines_destination（d35bdbdc）；镜像/reflect、精灵体/sprite、邻接/adjacency、指示定镜像与色/indicator_sets_axis_color（b775ac94）；擦除/erase（3bdb4ada/d35bdbdc）

**依赖链**：路径的物理走向（水平/垂直/L形）编码了反射轴类型，路径的两端点确定了配对的精灵体，反射副本的颜色取自配对方的颜色。没有路径就无法确定配对关系和反射轴；没有精灵体就无反射对象；没有颜色互换规则就无法确定副本颜色。路径在完成使命后被擦除。

在黑色背景上，灰色路径连接精灵体对，路径的走向决定如何镜像每个精灵体，副本取配对方的颜色，最后路径被擦除。

**输入结构**：黑(0)背景，约 18x18。若干小型单色 4-连通精灵体（每个 3~6 像素，形状各异——不规则但紧凑，无孔洞），颜色各不相同，从蓝(1)、红(2)、绿(3)、黄(4)、橙(7)中取。灰(5)路径段将精灵体两两连接——路径宽度 1 像素，仅沿基数方向（上下左右）延伸，每条路径的端像素与对应精灵体的某个像素 4-邻接。每个精灵体恰好连接一条路径。路径之间互不交叉。路径分三种几何形态：(a) 所有路径像素同行——水平直线；(b) 所有路径像素同列——垂直直线；(c) 有且仅有一个 90 度弯折——L 形。生成约束：精灵体和路径互不重叠；每种几何形态至少出现一次；反射后的副本不会超出网格边界。

**规则**：
1. 识别所有灰(5)路径段及其两端 4-邻接的精灵体，建立配对关系 (A, B)。
2. 判定每条路径的几何类型：所有路径像素行坐标相同→水平型；列坐标相同→垂直型；其余→L 型（恰好有一个拐点）。
3. 对每对 (A, B)：
   - **水平型路径**：以路径所在行为水平轴，将 A 上下翻转得到 A'，将 B 上下翻转得到 B'。A' 着 B 的颜色，B' 着 A 的颜色。翻转时每个像素的列坐标不变，行坐标关于路径行做镜像：new_row = 2 * path_row - old_row。
   - **垂直型路径**：以路径所在列为垂直轴，将 A 左右翻转得到 A'，将 B 左右翻转得到 B'。A' 着 B 的颜色，B' 着 A 的颜色。翻转时每个像素的行坐标不变，列坐标关于路径列做镜像：new_col = 2 * path_col - old_col。
   - **L 型路径**：以拐点为中心做点对称（180 度旋转），将 A 旋转得到 A'，将 B 旋转得到 B'。A' 着 B 的颜色，B' 着 A 的颜色。旋转公式：new_row = 2 * elbow_row - old_row, new_col = 2 * elbow_col - old_col。
4. 将所有副本绘制到网格上。若副本像素落在已有非背景像素位置，副本覆盖原像素。处理顺序：按路径的拐点（直线型取路径中点）行优先、列次优先从左上到右下。
5. 将所有灰(5)路径像素擦除为黑(0)。原始精灵体保留不变。

**关键洞察**：路径不只是连接指示器——其物理走向本身编码了几何变换类型（水平翻转/垂直翻转/点对称），必须同时读取路径形状和端点身份才能确定完整变换。

## 新题 2：瓦片内部投票决定分隔线染色

**组合逻辑**：[格子瓦片/lattice_tile + 分隔线/separator_line](已有结构) → [邻域多数色/neighborhood_majority_color](创新：从像素 3x3 邻域扩展到瓦片对的内部像素集) → [重涂色/recolor](已有) + [频率排序/frequency_rank](已有，用于平局裁决)

**来源原语**：格子瓦片/lattice_tile、分隔线/separator_line、同行列对齐/same_row_col_align（a096bf4d）；邻域多数色/neighborhood_majority_color（de809cff）；重涂色/recolor（多源）；频率排序/frequency_rank（9caf5b84）

**依赖链**：瓦片结构定义了哪些内部像素属于哪个分隔段的"邻居"；多数色投票机制将分隔段视为需要被邻居决定颜色的输出目标；当两色平票时，全局频率排序作为仲裁。没有瓦片结构无法定义"邻居"范围；没有投票机制无法确定分隔段颜色；没有全局频率仲裁，平票情况下输出不唯一。

在格子瓦片网格中，每段分隔线的颜色由相邻两个瓦片内部像素的多数色投票决定，平票时以全局出现频率较高的颜色胜出。

**输入结构**：黑(0)背景，约 15x15。灰(5)分隔线将网格划分为 3x3 或 4x4 的规则瓦片阵列（如 3 行 4 列共 12 个瓦片）。每条分隔线宽度 1 像素。每个瓦片的内部为 3x3 区域（不含分隔线），内部像素由 2~3 种颜色填充，颜色从蓝(1)、红(2)、绿(3)、黄(4)、橙(7)中取。不同瓦片可使用不同颜色组合。生成约束：至少存在一段分隔线其相邻两瓦片的合并像素有两色平票；全局频率排序中不存在三色并列第一的情况。

**规则**：
1. 识别灰(5)分隔线和所有瓦片。对每段分隔线，确定其相邻的两个瓦片（分隔线段定义为：两个瓦片之间共享边界上的连续灰色像素序列）。
2. 对每段分隔线段：收集相邻两个瓦片的全部内部像素颜色（对于内部瓦片之间的段为 2 x 9 = 18 个像素；边缘分隔段仅一侧有瓦片则取该单侧的 9 个像素）。
3. 统计这些像素中各颜色的出现次数，选出现次数最多的颜色作为该段分隔线的新颜色。若最多票数有多色并列，则在并列色中选全局出现频率更高者（全局频率 = 该颜色在所有瓦片内部像素中的总出现次数）。
4. 将该段分隔线的所有像素重涂为投票选出的颜色。
5. 分隔线交叉点（行分隔与列分隔交汇的像素）取其所有相邻瓦片（最多 4 个）的全部内部像素做同样的多数色投票，独立决定颜色。

**关键洞察**：分隔线在源题中是静态结构元素，这里变为输出目标——其颜色由它所分隔的内容"投票"涌现，分隔线的角色从"划分空间"翻转为"聚合信息"。

## 新题 3：参照图例恢复遮挡精灵体

**组合逻辑**：[连通分量检测/connected_component_detection](已有) → [平移归一化/translate_normalize + 形状相同/same_shape](已有，用于局部匹配) → [可见像素约束推断/infer_from_visible](创新：从周期性平铺推断改为依据参照形状推断) → [补全/completion](已有) + [重涂色/recolor](已有) → [擦除/erase](已有，擦除图例区)

**来源原语**：连通分量检测/connected_component_detection、部分标记/partial_marker（14754a24）；形状相同/same_shape、平移归一化/translate_normalize、占位符对象/placeholder_obj（ad38a9d0）；遮挡区域/occluded_region、可见像素约束推断/infer_from_visible（ca8f78db）；擦除/erase（d35bdbdc）；补全/completion（ca8f78db）

**依赖链**：右区精灵体被黑色矩形部分遮挡，单凭可见部分无法确定完整形状。左区完整参照精灵体提供形状字典。平移归一化后的形状匹配将每个遮挡体与唯一一个参照体配对。配对成功后用参照体的形状恢复遮挡部分，副本颜色取参照体颜色。最后左区图例被擦除。任一环节缺失（无参照→无法推断完整形状；无匹配→无法确定配对；无擦除→输出包含冗余信息）都导致无法求解。

黑色矩形遮挡了右区的精灵体局部，利用左区完整的参照精灵体进行形状匹配来恢复被遮挡的部分，恢复后擦除整个参照图例区。

**输入结构**：黑(0)背景，约 20x14。网格被一条垂直的品红(6)分隔线（宽 1 像素，贯穿全高）分为左右两区。左区（图例区）包含 3~5 个完整的单色 4-连通精灵体（每个 4~8 像素，形状各异——不规则紧凑形，无孔洞），颜色各不相同，取自蓝(1)、红(2)、绿(3)、黄(4)、橙(7)。右区包含同样数量的精灵体，每个精灵体的形状与左区中某一个完全相同（平移归一化后一致），但颜色统一为灰(5)。右区每个灰色精灵体被一个黑(0)矩形（2~3 像素宽/高）部分遮挡，矩形覆盖精灵体的一部分像素使其变为黑色。生成约束：每个被遮挡精灵体的可见部分（非黑像素）足以与唯一一个参照体匹配——即可见部分是该参照体的平移归一化掩码的真子集，且不与其他参照体的任何子集重合；左右区精灵体一一对应，无多余无遗漏。

**规则**：
1. 识别品红(6)分隔线，将网格分为左区和右区。
2. 在左区，对每个非背景、非品红的 4-连通分量提取其平移归一化掩码（将边界框左上角平移至原点），建立参照字典：{归一化掩码 → 颜色}。
3. 在右区，对每个灰(5)的 4-连通分量（仅统计灰色像素，忽略被遮挡的黑色像素），提取其归一化掩码作为"可见子集"。
4. 对每个可见子集，遍历参照字典，找到唯一一个参照掩码使得可见子集是该掩码的子集（即可见像素的相对坐标全部包含在参照掩码中，允许在子集内平移对齐时尝试所有偏移量，取使子集完全落入参照掩码的唯一偏移）。
5. 用匹配到的参照掩码恢复被遮挡像素：将参照掩码中有而可见子集中无的像素位置，在右区对应坐标处填充该参照体的颜色。同时将原有灰(5)可见像素也重涂为该参照体的颜色。
6. 擦除左区所有内容和品红(6)分隔线——将左区及分隔线范围内所有像素设为黑(0)。输出仅保留右区恢复后的精灵体。

**关键洞察**：可见像素不是周期性平铺的残留（源题 ca8f78db 的逻辑），而是完整形状的随机碎片——必须与外部图例逐一比对才能确定完整形态，图例本身在输出中消失。

## 新题 4：滑动轨迹选通容器充能

**组合逻辑**：[对侧配对/opposite_pairing + 滑动/sliding + 相向移动留迹汇合/inward_trails_meet_mark](已有) ⊗ [带边框容器/bordered_container + 逐步充能/incremental_charge](已有) ← [碰撞停止/collision_stop](已有，但作用对象从射线改为滑动轨迹)（⊗ 表示双向约束：容器阻挡轨迹，轨迹反过来决定充能量）

**来源原语**：对侧配对/opposite_pairing、滑动/sliding、孤立像素/isolated_pixel、汇合点/meeting_point、相向移动留迹汇合/inward_trails_meet_mark（29c11459）；带边框容器/bordered_container、逐步充能/incremental_charge、能量上限步数/energy_caps_steps（271d71e2）；碰撞停止/collision_stop（e12f9a14）；邻接/adjacency（b775ac94）

**依赖链**：对侧像素对沿共享行/列相向滑动留轨迹，但容器边框阻挡轨迹前进（碰撞停止）。轨迹绘制完成后，每个容器统计其边框 4-邻接的轨迹像素总数，该数即为充能数（但不超过容器内灰色像素总数）。充能方向由轨迹分布决定：从轨迹像素最密集的那侧边框向内充能。三重循环依赖——容器位置影响轨迹走向，轨迹分布决定充能量和方向，充能量受灰色像素数上限约束。

对侧像素对相向滑动留下彩色轨迹，轨迹被容器边框阻挡；轨迹与容器边框的邻接数决定容器内灰色像素的充能数量和充能方向。

**输入结构**：黑(0)背景，约 20x20。3~4 个带边框容器散布在网格内部：每个容器由黑(0)边框（1 像素宽的闭合矩形框，外尺寸约 4x6 或 6x4）围成，内部填充灰(5)像素（内尺寸约 2x4 或 4x2，共 8 个灰像素）。网格的四条边上（第 0 行、最末行、第 0 列、最末列）各有若干孤立的彩色像素（每个 1 像素），颜色从蓝(1)、红(2)、绿(3)、黄(4)中取，同色像素恰好出现两次且分布在对侧边上（如一个蓝像素在顶边、另一个蓝像素在底边，且两者处于同一列；或一个红像素在左边、另一个红像素在右边，且两者处于同一行）。生成约束：不同色的像素对的滑动路径可以相交但不会与同一容器的同一侧边框邻接超过该容器内灰色像素数；每个容器至少有一侧边框会被至少一条轨迹邻接。

**规则**：
1. 识别所有对侧同色像素对。对于顶-底对，两像素共享同一列；对于左-右对，两像素共享同一行。
2. 每对像素同时从各自位置沿共享行/列向对方滑动，每步前进一格。每步在当前位置留下自身颜色的轨迹像素（覆盖背景黑色）。若下一步位置是容器边框或另一条已绘制轨迹的像素，则该像素停止前进（碰撞停止），但配对方继续滑动直到也碰撞或两者相遇。两像素到达相邻格或同一格时，汇合点（两者间的那个格，或重合的那个格）涂为品红(6)。处理顺序：按像素对颜色值从小到大（蓝1→红2→绿3→黄4），先处理的轨迹可以阻挡后处理的轨迹。
3. 轨迹绘制全部完成后，对每个容器：统计其边框像素的 4-邻域中轨迹像素（非黑、非灰、非边框自身颜色的像素）的总数，记为 T。
4. 充能数 C = min(T, 容器内灰色像素总数)。
5. 确定充能方向：统计容器四条边（上、下、左、右）各自邻接的轨迹像素数，取最大者对应的方向。若平局，按上→右→下→左的优先级选择。"从该方向充能"意味着从该侧边框内侧起，逐行（或逐列）将灰(5)像素替换为橙(7)，共替换 C 个像素。行/列内从左到右（水平充能时从上到下）依次替换。
6. 原始边框像素和轨迹像素保持不变。

**关键洞察**：容器既是轨迹的障碍物（改变轨迹形态），又是轨迹的信息接收者（通过邻接计数获取充能指令）——同一对象在同一题中扮演截然不同的因果角色。

## 新题 5：十字轴对称展开标记后按切比雪夫距离填充方块

**组合逻辑**：[对称补全/symmetry_complete + 双轴对称/biaxial_symmetry + 四象限镜像填充/quadrant_mirror](已有) → [填充/fill + 切比雪夫距离/chebyshev_dist + 近阻挡距定尺寸/blocker_dist_size](已有，但填充目标由对称补全产生) + [碰撞停止/collision_stop](已有，阻挡像素阻止填充扩展)

**来源原语**：对称补全/symmetry_complete、十字轴线/cross_axis、稀疏标记/sparse_marker、双轴对称/biaxial_symmetry、四象限镜像填充/quadrant_mirror（60d73be6）；填充/fill、标记像素/marker_pixel、阻挡像素/blocker_pixel、正方形区域/square_region、切比雪夫距离/chebyshev_dist、近阻挡距定尺寸/blocker_dist_size（ff72ca3e）

**依赖链**：黄色标记仅存在于一个象限，必须先通过十字轴双轴对称补全到其余三个象限，才能获得完整的填充中心集合。每个中心（无论原始还是反射产生的）根据其到最近灰色阻挡像素的切比雪夫距离来确定红色方块的边长。反射产生的标记与不同象限的阻挡像素交互，因此同一原始标记的四个副本可能产生不同大小的方块。没有对称补全→只有四分之一的填充中心；没有阻挡距离规则→方块大小不确定。

将单象限的黄色标记通过十字轴反射补全到所有象限，然后以每个标记为中心、按最近灰色阻挡像素的切比雪夫距离画红色方块。

**输入结构**：黑(0)背景，约 17x17（奇数行列以确保十字轴居中）。一条绿(3)的完整行（正中行）和一条绿(3)的完整列（正中列）构成十字轴。黄(4)标记像素仅出现在左上象限（十字轴以外区域），共 2~4 个，互不相邻。灰(5)阻挡像素散布在所有四个象限中（每个象限 2~5 个），互不相邻，且不与黄色标记相邻。生成约束：每个黄色标记反射到其余三个象限后，落点均为黑色背景（不与阻挡像素或十字轴重合）；每个标记（含反射副本）到最近阻挡像素的切比雪夫距离至少为 2（保证至少生成 1x1 的方块）；不同标记产生的红色方块互不重叠。

**规则**：
1. 识别绿(3)十字轴：满行的行号为 axis_row，满列的列号为 axis_col。
2. 收集所有黄(4)像素的坐标作为原始标记集合 M。
3. 对每个标记 (r, c) in M，计算其三个反射位置：
   - 跨行轴反射：(2*axis_row - r, c)
   - 跨列轴反射：(r, 2*axis_col - c)
   - 双轴反射：(2*axis_row - r, 2*axis_col - c)
   将反射位置加入标记集合。在这些位置放置黄(4)像素。若反射位置超出网格边界则丢弃。
4. 对完整标记集合中的每个标记 (r, c)（按行优先、列次优先从左上到右下处理）：
   - 计算 d = 到所有灰(5)阻挡像素的切比雪夫距离的最小值。
   - 半径 R = d - 1。
   - 以 (r, c) 为中心，绘制边长为 (2R+1) 的红(2)正方形：将所有满足 |r'-r| <= R 且 |c'-c| <= R 的格子 (r', c') 涂为红(2)，但仅覆盖黑(0)背景像素，不覆盖黄(4)、灰(5)、绿(3)或先前已绘制的红(2)像素。
5. 十字轴、黄色标记、灰色阻挡像素保持不变。

**关键洞察**：填充中心的完整集合必须通过对称补全才能获得，而每个反射副本的方块大小取决于目标象限中阻挡像素的局部分布——同一源标记在不同象限可能产生不同大小的方块，使得对称补全与局部距离分析形成非平凡交互。

## 新题 6：形状配对滑动与条件对称补全

**组合逻辑**：[连通分量检测/connected_component_detection + 平移归一化/translate_normalize + 形状相同/same_shape](已有，用于配对) → {有配对 → [滑动/sliding + 相向移动留迹汇合/inward_trails_meet_mark](已有)；无配对 → [对称补全/symmetry_complete + 双轴对称/biaxial_symmetry](已有，用于生成配对方) → 再滑动}（条件分支结构）

**来源原语**：连通分量检测/connected_component_detection（14754a24）；形状相同/same_shape、平移归一化/translate_normalize（ad38a9d0）；滑动/sliding、对侧配对/opposite_pairing、相向移动留迹汇合/inward_trails_meet_mark（29c11459）；对称补全/symmetry_complete、十字轴线/cross_axis、双轴对称/biaxial_symmetry（60d73be6）

**依赖链**：形状匹配决定哪些精灵体已有配对——有配对的直接滑动汇合。无配对的（独特形状的）精灵体必须先通过十字轴点对称反射来"生成"其配对方，然后再滑动。条件分支是关键耦合点：同一输入中一部分对象走匹配路径，另一部分走生成路径，最终都做滑动汇合，但滑动方向和颜色规则不同。

多个彩色精灵体通过形状匹配配对后相向滑动汇合，无配对的精灵体先通过十字轴对称反射生成镜像副本再滑动。

**输入结构**：黑(0)背景，约 19x19（奇数行列）。绿(3)十字轴（一条完整行 + 一条完整列）将网格分为四个象限。4~6 个单色 4-连通精灵体（每个 3~5 像素，紧凑不规则形，无孔洞）分布在各象限中，颜色各不相同，从蓝(1)、红(2)、黄(4)、橙(7)、栗(9)中取。其中部分精灵体与另一个精灵体形状完全相同（平移归一化后一致），构成"已匹配对"；其余精灵体形状独一无二，构成"未匹配体"。生成约束：已匹配对的两个精灵体处于不同象限且共享一行或一列（轴线行/列不算）；未匹配体的点对称反射落点为纯黑色背景且在网格内；所有滑动路径互不交叉。

**规则**：
1. 检测所有非背景、非绿(3)的 4-连通分量，提取每个精灵体的平移归一化掩码和颜色。
2. 按归一化掩码将精灵体分组：掩码相同的两个精灵体构成一对（保证不会出现三个或更多同形）；掩码唯一的为未匹配体。
3. **已匹配对**的处理：两个同形精灵体沿共享行或共享列相向滑动。每步两者同时移动一格（整体平移），在原位置留下自身颜色的轨迹。两者的边界框相邻（间距 1 格）时停止，中间的那一行/列格子涂为灰(5)作为汇合线。
4. **未匹配体**的处理：
   a. 以十字轴交叉点为对称中心，对该精灵体做 180 度点对称，生成其"镜像副本"。副本颜色为品红(6)。
   b. 原体与副本沿经过十字轴交叉点的连线方向相向滑动（即各自向交叉点方向移动），留下各自颜色的轨迹。边界框相邻时停止，汇合格涂为灰(5)。
5. 处理顺序：已匹配对按两者边界框中心的中点坐标从左上到右下处理；未匹配体按其原始位置从左上到右下处理。后处理的轨迹不覆盖先处理的轨迹或汇合线。
6. 十字轴保持绿(3)不变。

**关键洞察**：形状匹配不用于重涂色（源题 ad38a9d0 的用法），而用于决定每个对象进入哪条处理分支——匹配成功走直接滑动路径，匹配失败走"先生成再滑动"路径。条件判断本身成为推理链的分叉节点。

## 新题 7：包围框内分隔线定位子区后跨区反色修复凹痕

**组合逻辑**：[包围框/bounding_box + 包围框内部/inside_bbox + 全空行列检测/detect_empty_row_col](已有) → [区域分割](创新：分隔线将包围框内部分为两个子区) → [去噪/denoise + 邻域多数色/neighborhood_majority_color](已有) → [缺陷标记/defect_mark + 反色填充/opposite_color_fill](已有，但"反色"由分隔线划分的对侧子区定义) → [重涂色/recolor 分隔线](已有，da2b0fe3 的绿色标记)

**来源原语**：包围框/bounding_box、包围框内部/inside_bbox、分隔行列/separator_row_col、全空行列检测/detect_empty_row_col（da2b0fe3）；去噪/denoise、缺陷标记/defect_mark、前景区域/foreground_region、凹痕/dent、邻域多数色/neighborhood_majority_color、反色填充/opposite_color_fill、忽略干扰项/ignore_distractors（de809cff）；重涂色/recolor（多源）

**依赖链**：包围框定位前景区域→区域内全空行/列检测找到分隔线→分隔线将区域分为两个子区，每个子区有自己的主色→子区内黑色凹痕被检测出来→每个凹痕的 3x3 修复色取自对侧子区的主色（不是自身子区的主色）→分隔线自身被涂为绿色并延伸至全画布。去噪必须在凹痕检测之前完成（否则噪点会被误判为凹痕）。没有分隔线→无法定义"对侧"→反色规则无法执行。

检测前景包围框内的空白分隔线，将包围框分为两个子区，每个子区的黑色凹痕用对侧子区的主色进行 3x3 修复，分隔线本身涂为绿色延伸至全画布。

**输入结构**：黑(0)背景，约 18x18。一个大型前景区域由两种颜色构成（如蓝(1)和红(2)），占据网格中央约 12x12 的范围，整体被一个最小包围框圈定。包围框内部恰好有一条完全由背景色（黑(0)）构成的行或列（宽度 1 像素），将内部分成两个子区。一侧子区以蓝(1)为主色，另一侧以红(2)为主色。每个子区内有 1~3 个小型黑(0)凹痕（每个凹痕为单独的 1 像素黑点，被同色像素包围）。每个子区边界处可能有 1~2 个单像素噪点（颜色为对侧子区的主色，出现在本子区内部，与本子区主色像素 4-邻接数 <= 1）。生成约束：凹痕的 3x3 邻域不与分隔线相邻（确保 3x3 修复不跨越分隔线）；凹痕的 3x3 修复区域互不重叠；噪点不与凹痕 8-邻接。

**规则**：
1. 找到前景（所有非黑像素）的最小包围框。
2. 在包围框内部（不含包围框边界行/列），检测完全由黑(0)构成的行或列。恰好存在一条，记为分隔线（若为行则记 sep_row，若为列则记 sep_col）。
3. 分隔线将包围框内部分为子区 A（分隔线上方/左方）和子区 B（分隔线下方/右方）。
4. **去噪**：对每个子区，检测其中的孤立噪点——定义为颜色不等于该子区多数色、且与同色像素的 4-邻接数为 0 的单像素。将这些噪点替换为该子区的多数色。每个子区的多数色 = 该子区内出现次数最多的非黑颜色。
5. **凹痕检测与修复**：去噪后，在每个子区中找到所有内部黑(0)像素（即被子区的多数色完全 4-包围的黑色单像素）。对每个凹痕像素 (r, c)：
   - 确定其所属子区（A 或 B）。
   - 取**对侧**子区的多数色作为修复色（若凹痕在子区 A 则用子区 B 的多数色，反之亦然）。
   - 将以 (r, c) 为中心的 3x3 区域中的所有像素涂为修复色，但仅覆盖与凹痕同子区多数色相同的像素和凹痕本身的黑色像素，不覆盖其他颜色的像素。
   - 凹痕中心点 (r, c) 本身涂为青(8)。
   - 处理顺序：按行优先、列次优先从左上到右下。
6. 将分隔线（包围框内的全黑行或列）涂为绿(3)，并将该绿色延伸至全画布宽度/高度（即该行/列在包围框外的部分也涂为绿(3)）。

**关键洞察**：da2b0fe3 中的分隔线仅用于标记，de809cff 中的"反色"基于全局两大前景色。本题中分隔线既是空间切割工具（定义子区和"对侧"概念），又是输出着色目标——凹痕修复的"反色"语义完全依赖分隔线的位置，而分隔线自身的输出处理（绿色全画布延伸）又依赖包围框检测结果。三层逻辑环环相扣。
