## 新题 1：双信号精灵体——形状定方向、字形定颜色的虚线射线

**组合逻辑**：[decode/glyph_maps_color](创新：字形嵌入精灵体内部而非独立区域) + [ray_extend/dotted_ray_to_edge] + [centroid_bias_dir]（三者并行解码后汇合为单一输出）

**来源原语**：decode、code_glyph、glyph_maps_color（来自 ed74f2f2）；ray_extend、drawing、dotted_ray_to_edge（来自 13f06aa5）；directional_sprite、centroid_bias_dir（来自 13f06aa5）；marker_pixel（来自 b942fd60）

**依赖链**：每个复合精灵体同时编码两个独立信号——体型形状编码射线方向（质心偏移的反方向），内嵌字形编码射线颜色。两条解码路径必须分别完成后合并，才能确定该精灵体对应的射线。删除方向解码则颜色已知但不知往哪画；删除颜色解码则方向已知但不知画什么色。

从每个复合精灵体中分别解码形状（方向）和内嵌字形（颜色），合并后画出对应的虚线射线。

**输入结构**：约 14x14 黑(0)背景。3-4 个复合精灵体散布于网格中，彼此包围盒不重叠。每个精灵体由灰(5)体像素（7 个像素组成一个不对称的 4-连通块，包围盒约 3x3）和 1 个内嵌的亮色像素组成。灰体像素的质心相对包围盒中心向某一基本方向偏移（如质心偏左则射线方向为右）。内嵌亮色像素位于灰体包围盒内的一个固定格位，其颜色为红(2)、蓝(1)或绿(3)之一，直接指定射线颜色。生成约束：各精灵体的射线路径互不经过其他精灵体的包围盒。

**规则**：
1. 对每个复合精灵体，计算灰(5)体像素的质心坐标，与其包围盒中心比较。质心偏移最大的基本方向的反方向即为射线方向（如质心偏左上则射线向右下——但此题限定四个基本方向：上下左右，取行偏移和列偏移中绝对值较大的分量决定方向轴，再取反方向）。
2. 读取该精灵体包围盒内唯一的非灰(5)、非黑(0)像素，其颜色即为射线颜色。
3. 从该精灵体的包围盒中心出发，沿射线方向每隔一格涂一个射线颜色的像素（即涂一格、跳一格），直到到达网格边缘。起始格（包围盒中心本身）不涂色。
4. 精灵体的灰(5)体像素和内嵌亮色像素在输出中保持不变。
5. 若虚线射线路径上的某格已被其他精灵体的体像素占据，则该格跳过（不涂色），射线继续向前。

**关键洞察**：精灵体是一个双编码对象——几何形状编码方向、内嵌标记编码颜色——必须对同一个对象进行两次独立解码并合并结果，才能确定输出射线的完整属性。

## 新题 2：镜像标记再展开——反射创造新交叉点

**组合逻辑**：[mirror/flip_within_bbox](创新：仅对标记子图案做水平镜像) → [draw_line/marker_to_row_col]（镜像产生的新标记与原标记共同参与展开）

**来源原语**：mirror、flip_within_bbox（来自 e74e1818）；draw_line、row_col_cross、marker_to_row_col（来自 8731374e）；rectangle、marker_pixel（来自 8731374e）；mono_mask、bounding_box（来自 e74e1818）；erase、noise_pixel（来自 91714a58）

**依赖链**：水平镜像将非对称的稀疏标记变成对称分布，新增的镜像标记与原标记一起参与行列展开。最终的网格图案由原始标记和镜像标记共同决定——若跳过镜像，缺少一半标记，图案不对称；若跳过展开，标记不产生行列线，仅有离散点。两步之间通过标记集合耦合。

将矩形内的稀疏标记水平镜像后，所有标记（原始+镜像）展开为整行整列的交叉网格。

**输入结构**：约 12x14 黑(0)背景，散布若干孤立噪声像素（非黑的孤立单像素，不与任何矩形相邻）。中央有一个实心轴对齐矩形（约 8x10），由黄(4)填充。矩形内部有 2-3 个蓝(1)标记像素，位置不在矩形的垂直中轴线上（即水平镜像后会产生新位置）。生成约束：标记像素的镜像位置不与原标记重合（保证镜像确实新增了标记）。

**规则**：
1. 识别网格中最大的单色实心矩形（忽略矩形外的噪声像素），裁剪到其包围盒。
2. 以裁剪后的矩形为画布，初始填满黄(4)。
3. 将每个蓝(1)标记像素关于矩形垂直中轴线做水平镜像：原标记在矩形内第 c 列（0-indexed），则镜像位置在第 w-1-c 列（w 为矩形宽度），行不变。若镜像位置已有标记则不重复添加。
4. 对所有标记像素（原始 + 镜像），将其所在行的所有列和所在列的所有行涂为蓝(1)。即每个标记生成一条完整的水平线和一条完整的垂直线。
5. 行线与列线的交叉处仍为蓝(1)。
6. 输出为裁剪后的矩形。

**关键洞察**：水平镜像在展开之前倍增并重新定位了稀疏标记，使得最终的行列交叉网格呈现左右对称的结构。仅看展开后的输出，必须逆推哪些行列线来自原标记、哪些来自镜像标记，才能还原规则。

## 新题 3：孔洞数定缩放因子——计数驱动的模板印章

**组合逻辑**：[counting/hole_count](创新：孔洞数映射为缩放因子而非颜色) → [pixel_scaling + stamp]

**来源原语**：counting、enclosed_background_region、hole_count_to_color_mapping（来自 37d3e8b2，重新映射为 hole_count_to_scale）；pixel_scaling、stamp、template、scale_correspond（来自 447fd412）；foreground_object（来自 37d3e8b2）

**依赖链**：孔洞计数产出一个数值，该数值参数化模板的缩放倍数。缺少计数则缩放因子未知，缺少模板则无物可缩放，缺少印章操作则缩放后的模板无处放置。三者通过"孔洞数→缩放因子→印章尺寸"链式耦合。

数每个前景对象内部的封闭孔洞数作为缩放因子，将小模板按该倍数放大后印章在对象位置。

**输入结构**：约 16x16 黑(0)背景。左上角（行 0-2、列 0-2 范围内）有一个小模板图案，由蓝(1)像素组成，为一个不对称的 4-连通小图形（3-5 个像素，包围盒 2x3 或 3x3）。网格其余区域散布 2-3 个较大的灰(5)前景对象，每个对象为大致矩形的实心填充块（约 5x5 至 6x6），内部挖有 1 至 3 个孔洞（被灰像素完全包围的 4-连通黑(0)背景区域）。各对象间距不小于 8 格，保证最大缩放（3 倍）后的印章不相互重叠。生成约束：每个对象的孔洞数互不相同。

**规则**：
1. 识别左上角区域的蓝(1)小图案作为模板，记录其包围盒内的像素相对坐标。
2. 对每个灰(5)对象，计算其内部 4-连通封闭背景区域的数量 k（1、2 或 3）。
3. 将模板按因子 k 放大：模板的每个像素扩展为 k x k 的蓝(1)方块。
4. 将放大后的模板印章到该灰对象的包围盒左上角对齐位置（放大模板的左上角与灰对象包围盒的左上角重合）。
5. 灰(5)对象本身被擦除（变为黑(0)），仅保留蓝(1)印章。
6. 左上角的原始模板从输出中移除（变为黑(0)）。
7. 超出网格边界的印章部分裁剪丢弃。

**关键洞察**：灰对象内部的孔洞不是装饰——它们是缩放因子的数值编码。一个有两个孔洞的对象获得 2 倍放大的印章，三个孔洞则 3 倍。必须对比多个示例才能确认孔洞数→缩放因子的映射（而非孔洞数→颜色）。

## 新题 4：重叠矩形的深度推断与按深度重涂色

**组合逻辑**：[erase/噪声去除](识别矩形) + [counting](创新：计数重叠深度而非孔洞) + [recolor]（结构为"分解→推断→重涂"的非线性回溯）

**来源原语**：erase、solid_rectangle、noise_pixel、area_comparison（来自 91714a58，泛化为识别所有矩形）；counting（来自 37d3e8b2、e681b708）；recolor（来自 37d3e8b2、e681b708）

**依赖链**：求解者必须从可见表面逆向分解出底层重叠的矩形、从重叠区域的可见颜色推断堆叠顺序、对每个矩形计算被几个矩形覆盖（深度值），最后根据深度重涂色。跳过分解则深度无法确定；跳过深度计算则重涂色无依据。这是一个非线性结构：必须同时满足"矩形边界一致"和"堆叠顺序与可见颜色一致"两个约束。

将相互重叠的彩色矩形按堆叠深度重新涂色，顶层与底层的矩形获得不同颜色。

**输入结构**：约 13x13 黑(0)背景，散布少量噪声像素（孤立的非黑单像素，任意两个噪声像素不 4-相邻，且不构成 2x2 块）。3-4 个轴对齐实心矩形，每个至少 3x4，各使用不同的非黑颜色（从蓝(1)、红(2)、绿(3)、黄(4)中取）。矩形部分重叠：在重叠区域，只有最上层矩形的颜色可见。生成约束：(a) 堆叠顺序无歧义——每对重叠的矩形至少有一个可见的重叠区域可判断谁在上面；(b) 每个矩形至少有一条完整的边在可见表面上，使其完整范围可被推断。

**规则**：
1. 去除噪声：删除所有孤立的非黑像素（不属于任何至少 3x4 的实心矩形区域的像素）。
2. 重建每个矩形的完整范围：利用可见边缘推断被遮挡的部分。每个矩形恢复为完整的轴对齐实心矩形。
3. 对每个矩形，计算覆盖在它上方的其他矩形的数量 d（即在该矩形的范围内，有多少其他矩形的区域与之重叠且位于更上层）。
4. 按深度 d 重涂色：d=0（最顶层）→ 蓝(1)，d=1 → 红(2)，d=2 → 绿(3)，d=3 → 黄(4)。
5. 重叠区域显示最上层矩形重涂后的颜色。
6. 背景保持黑(0)。

**关键洞察**：输入中矩形的原始颜色与输出无关——它们仅用于推断堆叠顺序。输出颜色完全由堆叠深度决定。必须对比多个示例才能发现"原始颜色无关、深度决定输出色"这一隐蔽规则。

## 新题 5：图例重涂色合并对象后重力堆叠

**组合逻辑**：[recolor/legend_color_replace](改变对象颜色标识) → [gravity_drop + stacking]（作用于重涂色后的新连通分量）——重涂色通过合并对象改变了重力下落的物理结构

**来源原语**：recolor、color_sub_map、micro_legend、legend_color_replace（来自 e9b4f6fc）；gravity_drop、stacking、collision_stop、nearest_first_settling（来自 6ad5bdfd）；edge_wall、wall_determines_direction（来自 6ad5bdfd）；monochrome_object（来自 17829a00）

**依赖链**：图例重涂色将某些对象变为与相邻对象相同的颜色，使原本独立的对象合并为更大的刚性连通体。重力下落作用于合并后的连通体而非原始对象。最终堆叠形态取决于合并结果——跳过重涂色则对象各自独立下落（结果不同），跳过重力则合并后的对象静止不动。两步通过"连通分量的重新定义"深度耦合。

通过图例替换颜色使部分相邻对象合并为更大的刚体，然后将所有对象向边墙做重力堆叠。

**输入结构**：约 12x14 黑(0)背景。底部一行为完整的灰(5)边墙。网格中散布 6-8 个小型单色 4-连通前景对象（每个 2-3 像素），颜色来自红(2)、绿(3)、蓝(1)、橙(7)。部分不同颜色的对象之间仅隔一个黑像素（即若颜色相同则它们会 4-连通）。左上角或右上角有 1-2 个水平的双像素图例多米诺骨牌，每个左右排列为 [替换色, 被替换色]（如 [红(2), 绿(3)] 表示绿变红）。生成约束：至少一条图例替换会使两个原本被一个黑像素隔开的对象变为同色，且替换后它们通过"被替换色像素变色后"与相邻对象实现 4-连通合并。

**规则**：
1. 读取每个图例多米诺骨牌（左色为替换色，右色为被替换色）。将网格中所有被替换色的前景像素改为替换色。图例多米诺骨牌本身和灰(5)边墙不参与替换。
2. 重涂色完成后，重新计算 4-连通分量：颜色相同且 4-相邻的像素合并为同一个刚性对象。
3. 从网格中移除图例多米诺骨牌（变为黑(0)）。
4. 对所有前景对象施加向下重力：距底部边墙最近的对象先结算，每个对象作为刚体向下滑动，直到碰到边墙、已结算的对象或网格下边界时停止。
5. 边墙保持不动。

**关键洞察**：图例替换不仅仅是视觉上的颜色变化——它能使原本通过一格黑像素隔开的两个不同色对象在变为同色后，因中间像素也变色而 4-连通合并为一个更大的刚性体。这个更大的刚体在重力下落时的行为与两个独立小对象截然不同（如一个 L 形刚体与两个独立的直线体堆叠姿态不同）。

## 新题 6：递归射线网络中标记孔洞数决定线段颜色

**组合逻辑**：[ray_extend + recursive_expansion/perpendicular_turn](射线网络拓扑) + [counting/hole_count](创新：孔洞数编码射线线段颜色而非对象重涂色)

**来源原语**：ray_extend、recursive_expansion、perpendicular_turn、marker_triggers_turn、depth_first_expand（来自 b942fd60）；start_pixel、marker_pixel、ray_network（来自 b942fd60）；counting、enclosed_background_region、hole_count_to_color_mapping（来自 37d3e8b2）

**依赖链**：递归射线网络决定哪些标记被到达以及到达顺序；每个标记的孔洞数决定从该标记触发的下一段射线的颜色。射线网络的拓扑控制了"谁遇到谁"，孔洞计数控制了"遇到后画什么色"——两者缺一不可。跳过递归展开则不知道射线路径，跳过孔洞计数则不知道每段颜色。

从起点发射递归射线，遇到标记对象时转向；每个标记的内部孔洞数决定转向后新射线段的颜色，最终生成多色射线网络。

**输入结构**：约 15x15 黑(0)背景。左边缘有一个红(2)起点像素。网格中散布 3-4 个标记对象，每个标记为灰(5)像素组成的小矩形框（外轮廓为 3x3 至 5x5 的单像素宽矩形边框），框内部有 0 至 3 个封闭孔洞（被灰边框完全包围的 4-连通黑(0)背景区域；0 个孔洞即框内全部被灰填满）。标记对象间距足够大，各自包围盒不相邻。生成约束：(a) 各标记孔洞数互不相同；(b) 从起点出发的射线按深度优先展开能依次到达所有标记。

**规则**：
1. 从红(2)起点像素向右发射一条水平射线，初始颜色为红(2)。射线逐格涂背景像素为当前颜色。
2. 射线遇到某标记对象的包围盒边缘时停止（停在包围盒外一格的位置，该格已被涂色）。
3. 计算该标记对象的封闭孔洞数 h，映射射线颜色：h=0 → 蓝(1)，h=1 → 绿(3)，h=2 → 黄(4)，h=3 → 橙(7)。
4. 从射线停止格出发，向两个垂直方向各发射一条新射线，颜色为步骤 3 确定的颜色。
5. 深度优先处理新射线（先向右/下方向，后向左/上方向）。
6. 新射线若遇到另一个标记对象，重复步骤 2-5（用新标记的孔洞数确定下一段颜色）。
7. 已被触发过的标记对象不再发射新的垂直射线（仅阻挡当前射线）。
8. 射线遇到网格边缘时停止。
9. 所有标记对象的灰(5)框在输出中保持不变。

**关键洞察**：每个标记对象不只是射线转向的控制点——其内部结构（孔洞数）编码了下一段射线的视觉属性（颜色）。最终的多色射线网络的配色方案只有同时理解递归展开顺序和逐标记孔洞计数才能预测。

## 新题 7：杯口投射线交叉计数决定内部填色

**组合逻辑**：[fill/opening_extend_dir](杯内填充 + 开口方向投射) + [counting](创新：计数投射线与他杯投射线的交叉数) + [recolor]（结构为"局部→全局交互→回写局部"的非流水线拓扑）

**来源原语**：fill、opening、opening_extend_dir（来自 d4f3cd78）；cup_outline、enclosed_region（来自 d4f3cd78）；ray_extend（来自 b942fd60、13f06aa5、469497ad）；counting（来自 37d3e8b2、e681b708）；recolor（来自 37d3e8b2、e681b708）；中心对齐/center_alignment（来自 54d82841）

**依赖链**：这是一个"局部操作→全局交互检测→结果回写局部"的三角结构，而非线性流水线。每个杯的开口方向决定其投射线方向（局部属性），投射线之间的交叉关系是全局涌现的（取决于所有杯的位置和朝向的组合），交叉计数又反过来决定每个杯内部的填充颜色（回到局部）。单独看任何一个杯无法确定其输出颜色——必须知道所有杯的投射线布局。

从每个杯形轮廓的开口向外投射线条，计算各杯投射线与其他杯投射线的交叉数，据此决定杯内填充颜色。

**输入结构**：约 16x16 黑(0)背景。3-4 个杯形轮廓，每个杯为一个单像素宽的矩形边框（约 3x4 至 4x5），边框颜色各不相同（从红(2)、绿(3)、橙(7)、栗(9)中取），且恰好有一侧边缺失（即开口）。各杯的开口朝向不全相同（有的朝上、有的朝右等）。杯之间间距足够大，包围盒不重叠。生成约束：(a) 各杯投射线的延伸路径至少产生一对交叉（即至少两条不同杯的投射线共享某个格子）；(b) 各杯的交叉计数不全相同（保证颜色映射的可辨识性）。

**规则**：
1. 对每个杯形轮廓，将其封闭内部（开口侧以外被边框三面包围的区域内的黑(0)像素）临时填充为青(8)。
2. 从每个开口处的每个缺口像素格，沿开口方向（垂直于缺失边）向外逐格画青(8)线，直到遇到非黑(0)像素或网格边缘时停止（不覆盖阻挡物）。
3. 对每个杯，计算其投射线（步骤 2 画出的所有青(8)格）与其他杯的投射线重合的格数 n（即有多少个格子同时属于两个不同杯的投射线路径——若多条线经过同一格，按不同杯的对数分别计数）。简化处理：n 为与本杯投射线有交叉的**其他杯的数量**（0、1、2 或 3）。
4. 按交叉杯数 n 重涂杯内填充颜色：n=0 → 蓝(1)，n=1 → 红(2)，n=2 → 黄(4)，n=3 → 品红(6)。
5. 投射线本身在输出中保持青(8)。杯的边框保持原色不变。
6. 若两条投射线在同一格重合，该格仍为青(8)。

**关键洞察**：每个杯的最终内部颜色不取决于自身属性（颜色、大小、开口方向），而取决于它与其他杯的空间交互——其投射线与多少个其他杯的投射线相交。这是一个全局涌现的属性：移动任意一个杯都可能改变所有杯的输出颜色。
