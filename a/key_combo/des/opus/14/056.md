## 新题 1：射线分区洪泛填色

**组合逻辑**：[射线延伸](创新：射线不再仅作为输出装饰线，而是作为空间分区的结构性边界) + [洪泛填充](创新：填充区域不由预设轮廓定义，而由动态生成的射线几何决定) + [多数色投票](跨源复用)

**来源原语**：射线延伸/带框块/框架缺口/射线交汇/碰撞停止(e12f9a14), 洪泛填充/标记像素/封闭区域/标记在封闭区域内/多数色决定填充(4b6b68e5)

**依赖链**：框架缺口决定射线方向 → 射线碰撞与网格边界形成封闭分区 → 分区拓扑决定哪些标记像素属于同一区域 → 区域内标记的多数色决定该区域的填充颜色。删除射线逻辑则无分区边界，删除洪泛填充则分区为空，删除标记投票则无颜色来源。

将带框块发射的对角射线重新定义为空间分割工具：射线与框架一起将背景切分成若干封闭区域，每个区域内散布的标记像素通过多数投票决定该区域的填充色。

**输入结构**：约 18x18 网格，背景黑(0)。3~4 个带框块，每个由 4x4 的绿(3) 框包围一个 2x2 的单色内部块（各块颜色不同，可选蓝(1)、红(2)、黄(4)、灰(5) 等），每个框恰有一个缺口像素（缺口位于框的某条边上，位置因块而异）。网格背景区域散布 10~15 个孤立的单像素标记，颜色在红(2)、蓝(1)、黄(4) 中随机选取。生成约束：各带框块互不相邻（边界框之间至少间隔 2 像素），保证射线能有效延伸；标记像素不与框或其他标记相邻。

**规则**：
1. 每个带框块的缺口像素向外发射一条对角射线，颜色为该框内部块的颜色。射线方向由缺口在框上的位置决定：缺口在顶边则向上偏（左上或右上，取决于缺口偏左还是偏右于内部块中心列）；底边类似向下偏；左边向左偏；右边向右偏。精确规则：连接缺口位置与内部块中心，取反方向的 45 度对角方向。
2. 射线逐像素向外延伸，将经过的背景像素涂为内部块的颜色，直到遇到网格边界、任何已有非背景像素（包括其他射线、其他框架）或自身出发的框架像素时停止（不涂终点）。
3. 当两条射线在同一像素相遇（90 度碰撞）时，两条射线均在碰撞点前一格停止，碰撞点保持为背景（留下 1 像素间隙）。
4. 射线绘制完成后，框架、内部块和射线像素将背景分割为若干 4-连通区域。对每个区域：收集其中所有标记像素的颜色，若存在标记则用多数色填充整个区域（平局时选该区域中行号最小、行号相同时列号最小的标记像素的颜色）；若区域内无标记则保持背景色。
5. 填充后擦除所有原始标记像素（它们被填充取代）。框架、内部块和射线线条保持不变。

**关键洞察**：对角射线不是装饰性痕迹，而是将空间切割成投票选区的隐形墙壁；每个选区的填充色取决于射线几何恰好将哪些标记像素划入同一区域——移动一个框架的缺口位置就会重新划分选区，改变整个填充结果。

## 新题 2：十字印章后方向性压缩

**组合逻辑**：[印章覆盖](创新：印章结果不是最终输出，而是重力压缩的输入材料) + [重力下落](创新：重力不作用于预设对象，而是作用于刚刚由印章生成的动态像素集) ← [边缘标记线](方向指示器跨源复用)

**来源原语**：印章覆盖/十字模板/矩形/标记像素/内部包含/以标记为中心印章(264363fd), 重力下落/滑动/边缘标记线/栅格对齐/标记指示方向(afe3afe9)

**依赖链**：十字模板定义印章形状 → 标记像素定义印章中心 → 印章覆盖在矩形内生成十字图案 → 边缘标记线指定重力方向 → 重力将印章生成的像素沿该方向压缩堆积。印章决定"有多少像素、在哪些行列"，重力决定"这些像素最终堆在哪个方向的边界"。

在矩形容器内以标记像素为中心印上十字图案，然后将容器内所有非边框像素沿边缘标记线指示的方向做重力下落堆积。

**输入结构**：约 16x16 网格，背景黑(0)。2~3 个单色矩形轮廓（每个矩形由不同颜色的一像素厚边框构成，如蓝(1)、红(2)、绿(3)，内部约 5x5~7x7 的空腔）。每个矩形内部有 1~2 个孤立的标记像素，颜色与边框不同（如黄(4)或灰(5)）。矩形外部有一个小型十字模板精灵（如 3x3 的加号形，中心及四臂各一像素，用品红(6)绘制），以及一条完整的边缘标记线（如网格最右列全部填充为橙(7)，表示该边缘）。生成约束：矩形之间不重叠不相邻；标记像素位于矩形内部且距边框至少 2 像素（保证十字臂有延伸空间）；十字模板精灵位于所有矩形外部。

**规则**：
1. 裁剪十字模板精灵，识别其有效臂方向（水平、垂直或双向）。本题中模板为标准加号形（双向臂）。
2. 对每个矩形，以其内部每个标记像素为中心，印上十字模板：沿有效臂方向，用标记像素的颜色涂满从中心出发直到碰到矩形边框像素为止的所有背景像素（不覆盖边框本身）。若两次印章在同一像素重叠，后处理的标记像素（按行优先、列次优先顺序）覆盖先前的。
3. 确定重力方向：边缘标记线沿顺时针边界旅行规则映射——顶边→右，右边→下，底边→左，左边→上。例如标记线在最右列则重力方向为下。
4. 在每个矩形的内部空间中，将所有非背景、非边框的像素（即印章生成的像素）沿重力方向滑动，直到碰到边框内壁或另一个已停止的像素为止。处理顺序：沿重力方向从远端向近端逐像素处理（如重力向下则从最底行开始向上扫描），保证堆积正确。
5. 矩形边框、十字模板精灵、边缘标记线在输出中保持不变。

**关键洞察**：十字印章在每个矩形内创造了特定数量和分布的前景像素，但这些像素的最终位置完全由重力方向决定——同一组印章在不同重力方向下会产生截然不同的密排图案。需要从示例中同时推断印章规则和重力映射规则。

## 新题 3：原型拉伸映射指导迷宫寻路

**组合逻辑**：[拉伸](创新：拉伸不再用于绘制线段本身，而是用于建立锚点之间的连接关系) + [寻路/连线](创新：路径的端点和颜色不由标记像素直接给出，而由拉伸映射后的原型边推导) ← [门段](路径必须穿越的约束点)

**来源原语**：拉伸/紧凑原型/稀疏骨架锚点/线段/顶点坐标映射/行列独立拉伸(b0f4d537), 寻路/连线/平行墙壁/门段/穿越门中心/走廊正交路径(7e576d6e)

**依赖链**：紧凑原型的拓扑结构（哪些顶点相连、每条边什么颜色）→ 行列独立拉伸将原型顶点映射到锚点坐标 → 映射确定了哪些锚点对需要连线 → 墙壁和门段约束了实际路径走向 → 路径颜色来自原型边。原型提供"连什么、用什么色"，迷宫提供"怎么走"。

紧凑图原型通过行列坐标拉伸映射到稀疏锚点网络，原型中的每条彩色边指示对应锚点对之间需要画一条穿越门段的正交路径，路径颜色取自原型边。

**输入结构**：约 20x20 网格，背景黑(0)。网格分为两个区域，由灰(5)竖线分隔。左侧约 5x5 的小面板包含紧凑原型：3~4 个顶点（像素交叉点或端点），用不同颜色的水平/垂直线段相连（如红(2)线段连接顶点 A-B，蓝(1)线段连接顶点 B-C）。右侧约 14x14 的大面板：灰(5)全跨水平墙壁 2~3 条，每条墙壁有一个 3 像素宽的门段（门段处墙壁缺失）。大面板中散布黄(4)锚点像素，数量与原型顶点相同。生成约束：锚点的行坐标集合与原型顶点的行坐标集合大小相同（可独立拉伸对齐），列坐标同理；每对需连线的锚点之间至少存在一条可行的正交路径穿越所有中间墙壁的门段中心。

**规则**：
1. 在紧凑原型中识别所有顶点（线段的端点、拐角或交叉点处的像素位置）。
2. 将原型顶点的行坐标排序后，与黄色锚点的行坐标排序后一一对应；列坐标同理（行列独立拉伸映射）。由此每个原型顶点对应一个唯一的黄色锚点。
3. 对原型中每条彩色线段（连接两个顶点的边），在大面板中对应的两个锚点之间绘制正交路径。路径颜色为该原型边的颜色。
4. 路径绘制规则：从起点锚点出发，沿正交方向（水平或垂直）前进。若遇到墙壁，沿墙壁平移到最近门段的中心像素，穿越门段，继续前进到终点锚点。路径在走廊中选择使总曼哈顿距离最短的正交折线。
5. 若两条路径在某像素重叠，按原型边的处理顺序（先处理原型中更靠左上的边）决定颜色：后绘制的覆盖先绘制的。
6. 原型面板、灰色分隔线、墙壁、门段和黄色锚点在输出中保持不变。

**关键洞察**：紧凑原型是一张压缩后的连接关系图——它的几何尺寸无关紧要，重要的是拓扑（谁连谁）和颜色属性。黄色锚点是这张图在物理迷宫中的投影，而墙壁和门段将抽象的"连接"转化为具体的路径规划问题。

## 新题 4：碎片拼接后跨标记线镜像

**组合逻辑**：[移动/互补拼合](创新：拼合结果不是最终输出，而是镜像操作的输入几何体) + [镜像](创新：镜像的对象不是预存的完整图案，而是刚刚由碎片拼合产生的新矩形) ← [稀疏标记线](镜像轴跨源复用)

**来源原语**：移动/补全/碎片/锚定物体/矩形/同色碎片拼成矩形/互补拼合/碎片触边锚不触边(fe45cba4), 镜像/稀疏标记线/前景图案/平行对称轴/跨标记线反射(66ac4c3b)

**依赖链**：识别同色碎片对（触边碎片 + 锚定碎片）→ 平移碎片完成矩形 → 矩形的最终位置和形状确定 → 稀疏标记线提供镜像轴 → 以完成后的矩形为源图案跨标记线镜像 → 镜像用第二种颜色绘制。碎片移动改变了镜像的输入几何体；标记线位置改变了镜像的输出位置。

将触边碎片平移到锚定碎片旁补全为实心矩形，然后将每个完整矩形跨稀疏标记线做镜像，镜像副本涂为标记线的颜色。

**输入结构**：约 15x15 网格，背景黑(0)。1~2 种活跃前景色（如红(2)、蓝(1)）。对每种活跃色：一个锚定碎片（4-连通单色对象，3~8 像素，不触及任何网格边缘）和一个同色的边缘碎片（触及网格左边缘的 4-连通单色对象，3~6 像素）。将边缘碎片沿水平方向平移到锚定碎片旁时，两者恰好拼成一个实心矩形。另有一条稀疏标记行或列：若干灰(5)像素沿同一行（或同一列）排列，该行/列平行于碎片所触及的网格边缘。生成约束：每种活跃色的锚定碎片与其完成后的矩形位置不与标记线重叠；锚定碎片与标记线之间有足够空间放置镜像副本；不同活跃色的碎片互不重叠。

**规则**：
1. 对每种活跃前景色，找到唯一的水平平移使边缘碎片移动到锚定碎片旁，两者并集为实心轴对齐矩形（如 fe45cba4）。将边缘碎片原位置擦除为背景，在新位置绘制。
2. 所有矩形拼合完成后，对每个完成的矩形，将其所有像素跨稀疏标记线做镜像反射：若标记线为水平行，则上下翻转坐标；若为垂直列，则左右翻转坐标。
3. 镜像像素涂为稀疏标记线的颜色（灰(5)），而非矩形自身的颜色。
4. 若镜像像素落在网格外，舍弃。若镜像像素与已有非背景像素重叠，镜像像素不覆盖（原有像素优先）。
5. 稀疏标记线本身保持不变。锚定碎片和拼合后的矩形保持不变。

**关键洞察**：碎片拼合的平移量决定了完成矩形的精确形状和位置，而矩形相对于镜像轴的位置决定了镜像副本出现在哪里。在碎片拼合之前做镜像会产生错误的几何体（因为碎片尚未就位），这迫使求解者必须先完成拼合再执行镜像。

## 新题 5：周期传播与同心带互补修复

**组合逻辑**：[周期性填充](修复可传播的像素) + [同心层填充](修复在所有周期副本中均缺失的系统性空洞) ← [对角线标记](提供同心带的颜色序列)——两种修复机制互补，非流水线

**来源原语**：补全/填充/周期性格/缺失像素/平移等价/平移向量决定填充(484b58aa), 同心层填充/空心矩形框/对角线标记/嵌套层次/对角序映射色环(99306f82)

**依赖链**：这是一个互补约束结构。周期传播能恢复大部分缺失像素（只要某个周期副本在该位置有可见色），但若某些同心带在所有副本中均被擦除，则传播无能为力。此时同心层规则接管：对角线标记给出从外到内的颜色序列，可填充那些系统性空缺的带。反过来，若没有周期传播提供的部分结构信息，也无法判断哪些带缺失、哪些存在。两者必须协同工作。

在含有系统性缺失的周期性同心嵌套图案中，先用最强平移向量传播可见像素恢复大部分内容，再用对角线标记提供的颜色序列填充剩余的整带空缺。

**输入结构**：约 18x18 网格。网格大部分区域显示一个周期性着色图案，但许多像素为黑(0)表示缺失。该图案的一个完整周期单元格（约 6x6~8x8）本应是一组同心矩形带：最外圈一像素宽的带为某色，向内依次嵌套更多带，直到中心。但在输入中，某 1~2 条完整的同心带在所有周期副本中均被擦除为黑(0)（系统性缺失），其余像素中约 30%~40% 随机缺失（局部缺失，可通过周期传播恢复）。在网格左上角（不与周期图案重叠的区域），有一串对角线标记像素：从左上到右下，每步行+1列+1，每个标记为一种颜色，颜色顺序对应同心带从外到内的颜色序列。对角线标记数量等于完整单元格的同心带总数。生成约束：周期平移向量的最大支持度无歧义（即最强平移向量唯一）；对角线标记不与周期图案区域重叠。

**规则**：
1. 找到非零平移向量中，重叠可见像素（两端均非黑(0)）数量最多且无颜色矛盾的向量（如 484b58aa）。利用该向量及其逆向量的传递闭包，将同一等价类中的可见颜色传播到类内所有黑(0)像素。
2. 传播完成后，检查周期单元格：某些同心带位置仍全为黑(0)（因为这些带在所有副本中均缺失，传播无法恢复）。
3. 读取对角线标记颜色序列（从左上到右下），对应同心带从最外层到最内层。
4. 对照传播后的单元格，确定哪些带已恢复（有颜色）、哪些带仍缺失（全黑）。用对角线标记中对应层的颜色填充所有仍缺失的带。
5. 用完全修复的单元格铺满整个周期区域。对角线标记像素从输出中移除（它们是指令，不是输出内容）。

**关键洞察**：周期传播和同心带规则各自只能修复一类缺失——传播修复随机散布的局部缺失，同心带规则修复在所有副本中一致缺失的系统性空洞。两者的修复范围互补且不重叠，缺少任何一个都无法完成重建。

## 新题 6：形状归一化驱动的瓦片压缩重涂色

**组合逻辑**：[压缩](创新：压缩的输出颜色不取自瓦片自身颜色，而由外部形状图例决定) + [重涂色/形状匹配](创新：形状归一化不用于原地重涂同一对象，而是决定压缩像素的颜色——形状信息跨越了空间尺度)

**来源原语**：压缩/瓦片/标记像素/网格分块/填充位出标记色(5ad4f10b), 重涂色/占位符对象/形状相同/平移归一化(ad38a9d0)

**依赖链**：网格分块确定 3x3 瓦片布局（哪些位置有内容、哪些为空）→ 每个瓦片内的占位符对象提取并平移归一化其形状 → 形状与图例中的参考形状匹配 → 匹配到的参考形状的颜色成为压缩输出中该位置的像素色。压缩提供空间布局，形状匹配提供颜色语义，两者交汇在最终的 3x3 输出上。

将大型 3x3 瓦片阵列压缩为 3x3 输出网格，但每个输出像素的颜色不取自瓦片内容的显示色，而是根据瓦片内对象的平移归一化形状在图例中查找对应颜色。

**输入结构**：约 15x15 网格，背景黑(0)。单像素灰(5)分隔线将网格分为 3x3 的等大正方形瓦片（每个瓦片约 4x4）。部分瓦片（4~7 个）内包含一个单色小对象（全部用统一的占位符色绘制，如红(2)），对象为 4-连通、3~6 像素的不规则形状；其余瓦片为空（全背景）。在网格下方或右侧（由灰(5)分隔线隔开），有一个图例区域：2~3 个小型参考形状，每个用不同颜色绘制（如蓝(1)、绿(3)、黄(4)），每个参考形状也是 4-连通、3~6 像素。生成约束：每个瓦片内对象的平移归一化形状一定能在图例中找到匹配（图例覆盖所有出现的形状类别）；同一形状可能出现在多个瓦片中。

**规则**：
1. 对每个非空瓦片，提取其中的占位符对象，计算平移归一化形状（将对象平移使其边界框左上角对齐到 (0,0)）。
2. 将归一化形状与图例区域中每个参考形状的归一化形状逐一比对，找到完全匹配的参考形状。
3. 输出为 3x3 网格（无分隔线）：空瓦片位置输出背景色黑(0)；非空瓦片位置输出其匹配到的参考形状的颜色（不是占位符色红(2)，而是图例中该形状所用的颜色）。
4. 图例区域和分隔线不出现在输出中。

**关键洞察**：占位符颜色（红(2)）是误导——所有瓦片内对象看起来颜色相同，但它们的形状各异。真正的信息编码在几何形状中，而非颜色中。压缩决定了空间布局（哪些位置有输出），形状匹配决定了语义着色（输出什么颜色），两者缺一不可。

## 新题 7：外部连通分量计数决定内部同心带层数

**组合逻辑**：[计数](创新：计数结果不输出为柱状图，而是编码为同心嵌套深度) + [同心层填充](创新：带颜色不由对角线标记静态给出，而由外部对象的数量动态决定) + [排序](决定颜色到层深度的映射顺序)

**来源原语**：计数/连通分量/固定色序/基线对齐(aaecdb9a), 同心层填充/空心矩形框/嵌套层次(99306f82), 排序/按高度排列(b7999b51)

**依赖链**：外部连通分量按颜色分组并计数 → 计数结果排序（多→少）→ 排序后的颜色序列成为同心带的从外到内颜色映射 → 计数最多的颜色涂最外圈带，计数最少的涂最内层。外部对象的空间分布编码了内部装饰信息，这种跨区域的信息传递是核心创新。

统计矩形框外各色 8-连通对象的数量，按数量降序排列这些颜色，然后用排列后的颜色序列从外到内填充矩形框的同心嵌套带。

**输入结构**：约 16x16 网格，背景黑(0)。网格中央有一个一像素厚的绿(3)矩形框，内部空（约 8x8~10x10 的空腔）。矩形框外部散布着若干单色 8-连通前景对象（每个对象 2~5 像素），颜色选自红(2)、蓝(1)、黄(4)、灰(5)等，3~4 种颜色，每种颜色有不同数量的对象（如红色 4 个对象、蓝色 2 个、黄色 1 个）。生成约束：各颜色的对象数量互不相同（无平局）；颜色种类数不超过矩形框内可容纳的最大同心带数（即 min(框内宽, 框内高) / 2 向上取整）；外部对象不与矩形框相邻。

**规则**：
1. 对矩形框外部的每种前景色，统计其 8-连通对象的数量（如 aaecdb9a）。
2. 将颜色按对象数量从多到少排序。数量相同时（生成约束保证不会发生），按固定色序 grey(5), red(2), teal(8), maroon(9), pink(6) 中的先后顺序排列。
3. 用排序后的颜色序列从外到内填充矩形框的内部空间（如 99306f82）：最外一圈（紧贴框内壁的像素环）涂排序第一的颜色（数量最多），下一圈向内缩一像素涂第二颜色，依次类推。若颜色用完而同心带仍有剩余，最后一种颜色填满剩余的所有内层（包括中心）。
4. 矩形框本身（绿(3)）保持不变。外部对象保持不变。

**关键洞察**：框外散落的对象看似随机噪声，实际上它们的数量分布编码了框内同心装饰的配色方案——每种颜色在外部出现的对象越多，它在内部就越靠外层（面积越大）。

## 新题 8：旋转对齐后按包围盒高度分层叠加

**组合逻辑**：[旋转](创新：旋转不用于匹配碎片，而是用于将多个精灵对齐到同一朝向以便叠加) + [透明叠加](创新：叠加层序不由空间象限位置决定，而由包围盒高度排序决定) + [排序](创新：排序不产生柱状图，而是决定图层优先级)

**来源原语**：旋转/模板/模板匹配/缩放旋转对齐碎片(6aa20dc0), 透明叠加/面板/图层优先级/象限位决定层序(e99362f0), 排序/前景颜色掩码/按高度排列/包围盒高决定柱高(b7999b51)

**依赖链**：识别各面板精灵为同一模板的旋转副本 → 确定基准朝向（包围盒最高的精灵为未旋转原版）→ 将所有精灵旋转对齐到基准朝向 → 按原始包围盒高度排序确定叠加层序 → 从底层到顶层依次叠加，上层非背景像素覆盖下层。旋转使叠加有意义（不同朝向的精灵无法对齐叠加），排序决定冲突解决策略。

将多个旋转变体的同模板精灵先旋转对齐到基准朝向，再按原始包围盒高度从矮到高分层叠加，高层覆盖低层。

**输入结构**：约 16x16 网格，背景黑(0)。灰(5)垂直分隔列将网格分为 3~4 个等宽面板。每个面板包含一个单色精灵（每个面板用不同颜色，如红(2)、蓝(1)、绿(3)、黄(4)），每个精灵是同一个非对称基模板的旋转副本（0/90/180/270 度之一）。精灵大小约 3x4~4x5 像素，形状不规则（非对称以确保旋转可区分）。生成约束：基模板非对称（四种旋转产生四种不同外观）；每个面板中精灵居中放置；各面板大小相同。

**规则**：
1. 识别所有精灵为同一基模板的旋转变体。基准朝向定义为：所有精灵中，原始包围盒高度（旋转前，即精灵在其面板中的实际包围盒高度）最大的那个精灵的朝向即为基准朝向。若多个精灵包围盒高度相同，取最左面板中的精灵为基准。
2. 将每个精灵旋转到基准朝向（即推断它是基准旋转了多少度得到的，然后做逆旋转），使所有精灵形状对齐。旋转后每个精灵保持其原始颜色。
3. 按原始包围盒高度（旋转前的面板中实际高度）从小到大排序。高度相同时，左面板优先（排在前面，即更底层）。
4. 将对齐后的精灵叠加到一个空白画布上：排序第一的（最矮）作为最底层先绘制，排序最后的（最高）作为最顶层后绘制。每个精灵的左上角对齐到画布的 (0,0)。上层的非背景像素覆盖下层。
5. 输出画布大小为基准朝向精灵的包围盒大小。分隔线和原始面板不出现在输出中。

**关键洞察**：包围盒高度编码了双重信息——它既标识了基准朝向（最高者为未旋转版），又决定了叠加的图层顺序。不识别旋转关系就无法对齐精灵进行有意义的叠加；不根据高度排序就无法确定冲突像素的最终颜色。
