## 新题 1：封闭区域计数驱动精灵旋转

**组合逻辑**：[计数(counting)](已有) + [旋转(rotate)](已有) ← [封闭区域(enclosed_region)](已有, 创新：从分隔框架移入栅格单元内部，成为旋转参数的隐式编码) + [分隔栅格(divider_grid)](已有) + [位置索引(position_index)](已有, 创新：从颜色查找变为旋转量索引)

**来源原语**：计数/封闭区域/忽略干扰项(89565ca0), 旋转/阵列排布(46442a0e), 分隔栅格/位置索引(09629e4f), 精灵体(多题)

**依赖链**：每个单元格的内部墙壁结构 → 计数该单元的封闭背景区域数 → 该数值决定该单元内精灵的旋转角度。计数结果直接参数化旋转操作；不计数则旋转量未知，不旋转则计数无意义。

将网格单元内的墙壁拓扑结构解码为旋转参数，对每个单元的精灵施加不同角度的旋转后输出。

**输入结构**：约 15x21 的网格，灰(5) 色分隔线将网格划分为 2x3 共 6 个等大单元格（每格约 6x6）。每个单元格内包含：(a) 一个由红(2) 色像素组成的 4-连通小图形（3~6 像素，形态各不相同，不具旋转对称性），(b) 若干蓝(1) 色单像素宽的内部墙壁线段，将单元格的剩余黑(0) 色背景分割为 1~4 个封闭区域。内部墙壁从单元边界或其他墙壁延伸，保证每个封闭区域都是 4-连通的。不同单元格的封闭区域数各不相同（生成约束：6 个单元格的区域数为 {1,2,3,4} 的某个子集，保证无歧义映射）。红色精灵不与蓝色墙壁接触。

**规则**：
1. 对每个单元格，计算其中由蓝(1) 色墙壁和灰(5) 色单元边界共同围成的 4-连通黑(0) 色封闭背景区域的数量 N。
2. 将该单元格内的红(2) 色精灵以其边界框中心为旋转中心，顺时针旋转 (N mod 4) x 90 度。N=1 转 90 度，N=2 转 180 度，N=3 转 270 度，N=4（即 0 mod 4）不旋转。
3. 输出时保留灰色分隔线，移除所有蓝色内部墙壁（替换为黑色背景），保留旋转后的红色精灵。

**关键洞察**：蓝色墙壁的拓扑功能（分割出几个封闭区域）是精灵旋转量的隐式编码——视觉上墙壁只是线条杂物，但它们的数量和连接方式决定了各单元格的旋转参数。仅看一个示例无法确定"区域数→旋转角"的映射规则（需对比不同单元格的区域数与精灵朝向变化来归纳）。

## 新题 2：三角朝向编码叠加层序

**组合逻辑**：[透明叠加(transparent_overlay)](已有) + [重涂色(recolor)](已有, 创新：叠加前需根据三角朝向动态确定层序，而非固定象限位置) ← [朝向编码方向(orientation_encodes_direction)](已有, 创新：从编码射线方向变为编码层叠优先级) + [三角精灵体(triangle_sprite)](已有, 创新：从射弹发射器变为层序标识符)

**来源原语**：透明叠加/象限掩码/层叠顺序/四象限折叠同画布(75b8110e), 三角精灵体/朝向编码方向(409aa875)

**依赖链**：每个象限内的三角精灵朝向 → 解码为该象限的层叠优先级 → 按此优先级顺序将四个象限掩码叠加到同一画布。三角方向不解码则层序未知；层序不确定则叠加结果不确定。

解码每个象限角落处三角标记的朝向以确定四层掩码的叠加优先级，折叠到半尺寸画布。

**输入结构**：约 14x14 的网格，均匀黑(0) 色背景，被两条交叉的虚拟中线分为 2x2 四个等大区域（各约 7x7）。每个区域包含：(a) 一组单色前景像素形成一个掩码图案，四个区域分别使用红(2)、绿(3)、黄(4)、蓝(1) 四种不同颜色；(b) 在该区域的某个角落处（紧贴区域角），有一个由灰(5) 色组成的 3 像素轴对齐 L 形三角精灵（占据角落的 2x2 区域中的 3 格）。四个三角精灵的 L 形缺口方向各不相同，分别指向四个对角方向之一。不同示例中，同一象限内的三角朝向不同（生成约束：四个三角的缺口方向互不相同，构成四个对角方向的一个排列）。各区域的彩色掩码像素之间存在部分重叠位置（即叠加到同一画布时会有像素冲突）。

**规则**：
1. 识别每个区域角落的灰(5) 色 L 形三角精灵，确定其缺口方向（L 形中 2x2 正方形缺失的那个角的方向）。
2. 缺口方向到层叠优先级的映射：缺口朝左上 = 优先级 1（最底层，最先绘制），缺口朝右上 = 优先级 2，缺口朝左下 = 优先级 3，缺口朝右下 = 优先级 4（最顶层，最后绘制）。
3. 从每个区域提取彩色掩码（不含灰色三角），作为一个图层。
4. 创建一个区域大小的黑色输出画布。按层叠优先级从低到高的顺序，依次将四个掩码图层绘制到画布上，后绘制的覆盖先绘制的。
5. 输出该半尺寸画布。

**关键洞察**：源题中层叠顺序由象限位置硬编码（左上最先、右上最后）；本题中层叠顺序由三角精灵的朝向编码，同一象限在不同示例中可能有不同的层叠优先级。必须对比多个示例才能归纳出"缺口方向→优先级"的映射关系，因为仅看一个示例无法区分"位置决定层序"与"朝向决定层序"。

## 新题 3：路径连通选靶 + 端点朝向旋转印章

**组合逻辑**：[印章覆盖(stamp_overlay)](已有) + [旋转(rotate)](已有) ← [路径连通(path_connectivity)](已有, 创新：从颜色转移的选靶机制变为印章分发的路由机制) + [朝向编码方向(orientation_encodes_direction)](已有, 创新：从射弹方向变为旋转角度编码) + [形状匹配(shape_matching)](已有)

**来源原语**：印章覆盖/空位接受印章/支撑签名匹配(e5062a87), 路径网络/路径连通/端点决定目标(d35bdbdc), 旋转(46442a0e), 朝向编码方向/三角精灵体(409aa875)

**依赖链**：路径连通性筛选出可到达的槽位（不可达的即使形状匹配也不接受印章）→ 每个可达槽位端点处的 L 形标记朝向决定印章的旋转角度 → 旋转后的印章覆盖到对应槽位。三个约束（形状匹配、路径可达、旋转角度）同时作用，缺一不可。

通过灰色路径网络将模板精灵路由到匹配的空槽位，按各槽位端点处方向标记的朝向旋转后印入。

**输入结构**：约 20x20 的网格，黑(0) 色背景。包含以下元素：(a) 一个红(2) 色模板精灵（4-连通，约 4~8 像素），周围附带灰(5) 色支撑结构像素（与精灵像素在同一边界框内，定义支撑签名）；(b) 4~6 个空槽位，每个由灰(5) 色支撑结构组成，形状与模板的支撑签名完全匹配，模板的红色像素对应位置为黑(0) 色；(c) 灰(5) 色单像素宽路径段从模板延伸，但仅连接其中 2~4 个槽位（部分槽位虽然形状匹配但无路径可达）；(d) 在每个槽位的路径入口处（路径与槽位支撑结构相邻的位置旁），有一个由橙(7) 色组成的 3 像素 L 形标记，L 形的缺口朝向四个正交方向之一（上、右、下、左）。不同槽位的 L 形标记朝向不同（生成约束：模板精灵不具 90 度旋转对称性，确保不同旋转产生可区分的结果）。

**规则**：
1. 识别模板精灵（红(2) 色图案）及其灰(5) 色支撑签名。
2. 扫描所有候选槽位：支撑结构与模板的灰色支撑签名完全匹配，且模板红色像素对应位置为黑色。
3. 在匹配的槽位中，仅保留通过灰色路径与模板 8-连通可达的槽位。
4. 对每个可达槽位，读取其路径入口旁的橙色 L 形标记，确定旋转角：缺口朝上 = 0 度，缺口朝右 = 90 度顺时针，缺口朝下 = 180 度，缺口朝左 = 270 度顺时针。
5. 将模板的红色图案以该旋转角旋转后，印入该槽位（红色像素覆盖对应黑色位置）。
6. 移除所有灰色路径段和橙色 L 形标记。保留模板本体、印章结果和所有灰色支撑结构。未被路径连接的槽位保持空（黑色）不变。

**关键洞察**：形状匹配是必要非充分条件——形状匹配但无路径可达的槽位不接受印章；路径可达也是必要非充分条件——还必须形状匹配。两重过滤同时生效后，旋转角度由第三个独立信号（L 形标记朝向）编码。仅看单个示例难以区分"路径连通是否是必需条件"——需要对比有路径连接和无路径连接的同形状槽位。

## 新题 4：菱形边界对称补全后射线填充

**组合逻辑**：[对称补全(symmetry_completion)](已有, 创新：从矩形网格内部缺口填充变为菱形边界像素恢复) + [射线延伸(ray_extend)](已有) ← [双轴镜像轨道(two_axis_orbit)](已有, 创新：轨道作用于菱形边界而非矩形内部) + [遇阻停止(stop_at_blocker)](已有, 创新：阻挡物包含对称补全新生成的边界像素)

**来源原语**：对称补全/双轴镜像轨道/缺失像素/轨道内已知色唯一(af22c60d), 射线延伸/菱形框/侧标记/遇阻停止/框内填充(95755ff2)

**依赖链**：菱形边界的缺口 → 通过双轴镜像轨道补全边界 → 补全后的边界改变了菱形内部的阻挡几何 → 侧标记的射线在新几何下延伸直到被阻挡（包括新补全的像素）。对称补全的输出直接修改了射线延伸的约束条件。

先用双轴对称补全修复残缺的菱形边界，再从外侧标记向内发射射线，射线在补全后的完整几何中遇阻停止。

**输入结构**：约 17x17 的网格，绿(3) 色背景，包含：(a) 一个以网格中心为中心的单像素厚菱形框，菱形边界像素为蓝(1) 色，但有 3~5 个边界像素缺失（为绿色背景）；菱形关于水平中线和垂直中线具有双轴对称性。(b) 菱形外侧的上、下、左、右四个方向各有 0~2 个彩色标记像素（使用红(2)、黄(4)、橙(7) 等非蓝非绿色），位于菱形外接矩形的边上且在菱形对应边的法线方向上。(c) 菱形内部有 1~3 个灰(5) 色阻挡像素。（生成约束：缺失的边界像素在两个对称轴的镜像轨道中至少有一个已知同伴，保证补全唯一；每个标记像素的射线路径在补全前和补全后经过不同数量的内部像素，保证补全对结果有实质影响。）

**规则**：
1. 识别菱形框的水平和垂直对称轴（过菱形中心的水平线和垂直线）。
2. 对菱形边界上每个缺失像素（绿色背景位置但位于菱形几何边界上），收集其在两轴下的镜像轨道中所有已知（蓝色）的边界像素颜色，用唯一已知色填充该缺口。（本题中边界统一为蓝(1)，但对称轨道机制保证了缺口位置的确定。）
3. 边界补全后，每个外侧标记像素沿其所在边法线方向向菱形内部发射射线（上侧标记向下、右侧标记向左、下侧标记向上、左侧标记向右）。
4. 沿射线路径，将菱形严格内部的绿色背景像素涂为该标记的颜色。遇到任何非背景像素（包括蓝色边界像素——无论原有还是新补全的——以及灰色阻挡像素）时停止，不修改该阻挡像素。
5. 保留所有原始元素（包括补全后的边界、标记像素、阻挡像素）不变。

**关键洞察**：对称补全的结果直接改变了射线的可达范围——某条射线在残缺边界下本可穿透到更远处，但补全后新增的蓝色边界像素截断了它。两个操作共享菱形边界这一空间结构，前者修改它，后者依赖它，形成因果耦合。仅看单个示例难以区分"射线是被原有边界还是补全边界截断"。

## 新题 5：掩码并集识别互换色对的选择性段内互换

**组合逻辑**：[形状匹配(shape_matching) → 像素并集(pixel_union)](已有, 创新：并集检测不再标记操作数/目标，而是输出一个颜色对) + [颜色互换(color_swap)](已有, 创新：互换的色对不是预定义的固定映射，而是由并集检测动态确定) ← [对边配对(opposite_edge_pair)](已有) + [配对间像素互换(toggle_between_pairs)](已有, 创新：互换的颜色不固定，由另一个分析步骤确定)

**来源原语**：像素并集/双掩码并集等三/精灵体(fea12743), 颜色互换/标记像素/对边配对/配对间像素互换/网格边缘(d2acf2cb)

**依赖链**：六个精灵的掩码分析（找到并集关系的三元组）→ 两个操作数精灵的颜色确定互换色对 → 边缘标记对选定的行/列段内，执行该色对的互换。并集分析的输出（颜色对）是互换操作的输入参数；标记对选定作用范围。三者同时约束输出。

通过精灵掩码的并集关系发现两个互换颜色，然后在边缘标记对选定的行列段内执行该色对互换。

**输入结构**：约 18x18 的网格，黑(0) 色背景。包含两个区域：(a) 网格上半区：六个约 4x4 的单色精灵排列成 3x2 阵列，行间列间有 1~2 行/列黑色间隔。六个精灵分别使用红(2)、绿(3)、蓝(1)、黄(4)、橙(7)、青(8) 六种不同颜色，每个精灵在其 4x4 边界框内有非空前景掩码。恰好存在唯一一对精灵，其前景掩码的逐像素 OR 等于第三个精灵的掩码（每个操作数至少贡献一个唯一像素）。(b) 网格下半区：一个由多种颜色（包括上述六色中的至少四种）填充的约 8x8 彩色区域，黄(4) 色标记像素成对出现在该区域的对边上（左右边配对选定行、上下边配对选定列），共 2~3 对标记。（生成约束：操作数精灵的两种颜色在下半区的彩色区域中都有出现；彩色区域中不含上半区精灵。）

**规则**：
1. 在上半区的六个精灵中，将每个精灵裁剪到其 4x4 边界框，提取前景掩码（二值化为"有色/无色"）。
2. 枚举所有精灵对 (A, B)，检查是否存在第三个精灵 C 使得 mask(A) OR mask(B) == mask(C)，且 A 和 B 各自至少有一个 C 没有的像素不成立（即 A 和 B 的并集恰好等于 C，A 和 B 各自贡献至少一个独有像素）。找到唯一的 (A, B, C) 三元组。
3. 记录 A 和 B 的颜色为互换色对 (colorA, colorB)。
4. 在下半区，识别黄(4) 色标记对：左边沿与右边沿同行的标记对选定该行的严格内部段，上边沿与下边沿同列的标记对选定该列的严格内部段。
5. 在每个选定段内，将 colorA 的像素重涂为 colorB，将 colorB 的像素重涂为 colorA。其余颜色不变。
6. 上半区精灵、黄色标记和选定段之外的所有像素保持不变。

**关键洞察**：互换哪两种颜色并非预定义常量，而是由一个形状分析问题（掩码并集三元组检测）的输出动态决定。仅看下半区无法知道互换什么；仅看上半区无法知道互换发生在哪里。两个分析（掩码并集 + 边缘标记配对）各提供互换操作的一个关键参数。

4. 在拼接后的矩形画布中，枚举所有宽和高均 >= 2 的全黑矩形区域，找到面积最大者（若平局取最靠左上角的）。
5. 将该最大全黑矩形填充为绿(3) 色。
6. 输出拼接后的画布（含绿色填充的矩形和红色精灵像素）。

**关键洞察**：紧密拼接本身不产生最终输出——它创造了一个新的空间排列，在这个排列中涌现出一个在原始输入中根本不存在的几何特征（最大空矩形）。解题者必须先在脑中模拟拼接过程，才能预测空矩形的位置和大小。两步操作之间的耦合是涌现性的：拼接改变了空间拓扑，搜索依赖新拓扑。
