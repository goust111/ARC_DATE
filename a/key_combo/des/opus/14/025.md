## 新题 1：对角朝向决定重力方向

**组合逻辑**：[分类 + 对角朝向](已有) → 分支 → {[滑动/重力沉降](创新：方向由分类结果决定，NW-SE 向下沉降，NE-SW 向右沉降)} → [重涂色](已有，颜色标记方向)

**来源原语**：分类 + 对角朝向（1d61978c），滑动/重力沉降（1e0a9b12），重涂色（1d61978c）

**依赖链**：对角朝向分类将前景像素分为两组；分类结果决定每组的沉降轴方向（垂直 vs 水平）；沉降改变像素位置；重涂色根据沉降方向标记最终颜色。分类结果同时控制物理运动方向和输出颜色，三者缺一则输出不可确定。

将散布在网格中的单色对角线段按朝向分组，NW-SE 朝向的像素在各自列内向下沉降，NE-SW 朝向的像素在各自行内向右沉降，并分别着色以标记方向。

**输入结构**：约 12x12 网格。黑(0)为背景。单一前景色绿(3)形成若干互不相连的短对角线段（每段 2~4 像素，沿对角方向 4-连通）。部分线段沿 NW-SE 方向排列（即像素的左上或右下方有同色邻居），其余沿 NE-SW 方向排列（即像素的右上或左下方有同色邻居）。各线段之间至少间隔 2 行 2 列，互不接触。生成约束：两组像素分别执行列内下沉和行内右移后，不会有两个像素落在同一格。

**规则**：
1. 对每个绿(3)像素，检测其对角邻居：若存在 (r-1,c-1) 或 (r+1,c+1) 方向的同色邻居，则归入 NW-SE 组；若存在 (r-1,c+1) 或 (r+1,c-1) 方向的同色邻居，则归入 NE-SW 组。每个像素恰好属于一组。
2. NW-SE 组：对每一列，将该列中属于 NW-SE 组的像素从上到下收集，清除原位，按原有从上到下的顺序堆叠到该列底部（紧贴网格底边或已有堆叠像素之上），与 1e0a9b12 的列内重力沉降相同。
3. NE-SW 组：对每一行，将该行中属于 NE-SW 组的像素从左到右收集，清除原位，按原有从左到右的顺序堆叠到该行右端（紧贴网格右边或已有堆叠像素之左）。
4. 重涂色：所有沉降后属于 NW-SE 组的像素涂为青(8)，属于 NE-SW 组的像素涂为红(2)。

**关键洞察**：对角线段的几何朝向不仅是分类标签——它直接编码了物理运动的轴方向。同一批像素如果朝向翻转，沉降方向和最终位置都会完全不同。需要对比多个示例确认"朝向→沉降轴"的映射关系（而非朝向→颜色的简单映射）。

## 新题 2：频率排名决定像素角色——连线还是保留

**组合逻辑**：[频率排序](已有) → [分类](创新：按频率将颜色分为结构色和连线色) → {结构色像素保留不变 | 连线色像素执行[连线 + 行列对齐端点间填充](已有)} → [重涂色](创新：所有连线色统一为橙)

**来源原语**：频率排序 + 少数色替换（9caf5b84），连线 + 行列对齐端点间填充（253bf280），重涂色（ef26cbf6）

**依赖链**：频率排序决定哪些颜色是结构色（保留）、哪些是连线色（端点）；连线操作仅对连线色执行，在同色同行/同列端点之间填充；最后所有连线色像素（含原端点和新绘线段）统一重涂为橙色，消除颜色身份。频率排名改变则结构色/连线色分工改变，整个输出随之改变。

根据颜色出现频率将像素分为结构角色和连线角色：频率最高的两种颜色保持不变，其余颜色的同色像素在行列对齐时互相连线，最后所有连线色统一变为橙色。

**输入结构**：约 12x12 网格。黑(0)为背景。网格中散布 4~5 种非背景色的像素，总计约 20~30 个前景像素。每种颜色的像素数量不同且无并列（可明确排出频率名次）。频率最高的两种颜色各有 6~10 个像素，形成可辨识的结构图案（如线条或块状）。频率较低的颜色各有 2~4 个像素，散布各处。对于每种低频色，其像素在同一行或同一列中恰好成对出现（0 或 2 个），不存在 3 个以上同色像素位于同一行或同一列的情况。高频色像素不参与连线，即使它们有同行同列的配对。橙(7)不出现在输入中。

**规则**：
1. 统计每种非背景色的像素总数，按数量从高到低排列。取前两名为"结构色"，其余为"连线色"。
2. 保留所有结构色像素和背景色不变。
3. 对每种连线色，在每一行中：若该行恰好有该色的两个像素，则将这两个像素之间（不含端点）的所有背景像素涂为该连线色。在每一列中同理处理。
4. 将所有连线色像素（包括原端点像素和步骤 3 中新绘制的线段像素）统一重涂为橙(7)。

**关键洞察**：颜色的身份不决定其角色——只有其数量排名决定。同一种颜色在一道题中是结构色（被保留），换一道题中如果数量下降就变成连线色（被连线后消融为橙色）。需要对比多个示例才能确认"前两名保留、其余连线"的频率阈值规则。

## 新题 3：对称补全后异或差分

**组合逻辑**：[对称补全 + 镜像](创新：分别对两个半区独立执行，各自关于自身垂直中轴对称) → [逐像素比较 + 异或差异判定](已有，但比较对象是两个隐式生成的对称图案)

**来源原语**：对称补全 + 镜像 + 对称（c35c1b4c, 496994bd），逐像素比较 + 异或差异判定 + 分隔列 + 面板对齐（34b99a2b）

**依赖链**：输入的两个半区各自不对称，必须先分别补全为对称图案，再进行异或比较。如果跳过对称补全直接比较原始半区，得到的差异掩码与正确输出不同。对称补全生成了比较所需的完整信息，异或提取了两个对称图案之间的结构差异。

将分隔线两侧各自不对称的稀疏图案补全为关于各自中轴的对称图案，然后计算两个对称图案的异或差异，输出差异掩码。

**输入结构**：奇数列宽（如 11 列）、约 9 行的网格。黑(0)为背景。正中间一列全部填充灰(5)作为分隔列。左半区（5 列）包含若干蓝(1)前景像素，集中分布在左半区的左侧，不关于左半区自身垂直中轴对称。右半区（5 列）包含若干绿(3)前景像素，集中分布在右半区的右侧，同样不关于右半区自身垂直中轴对称。两半区的前景像素数量各为 3~6 个。生成约束：左半区补全后的蓝色图案与右半区补全后的绿色图案不完全重合（至少有 1 个位置存在差异），也不完全互补（至少有 1 个位置两者都有前景或都无前景）。

**规则**：
1. 对左半区（分隔列左侧的 5 列）：将所有蓝(1)像素关于左半区的垂直中轴（第 3 列，即左半区的第 2 列，0-indexed）做左右镜像。镜像产生的新像素也涂为蓝(1)，原有像素保留。补全后左半区呈水平对称。
2. 对右半区（分隔列右侧的 5 列）：将所有绿(3)像素关于右半区的垂直中轴做左右镜像，同理补全为水平对称。
3. 移除分隔列。输出网格宽度等于一个半区的宽度（5 列），高度不变。
4. 逐像素比较两个补全后的图案（左半区的蓝色掩码 vs 右半区的绿色掩码），在相同的 5 列坐标空间内对齐：
   - 若该位置恰好一侧有前景、另一侧无前景（异或为真），则输出红(2)。
   - 若该位置两侧同时有前景或同时无前景（异或为假），则输出黑(0)。

**关键洞察**：输入中可见的稀疏像素不是被比较的对象——它们只是压缩编码。真正被比较的是两个隐式对称图案，求解者必须先在脑中完成对称补全，再做差分。仅看一个示例可能误以为是对原始稀疏像素的直接异或；需要对比多个示例才能发现中间的对称补全步骤。

## 新题 4：拓扑封闭性门控印章操作

**组合逻辑**：[连通分量检测 + 边界可达性](已有) → 分支判定 → {封闭图块：[印章覆盖](已有) | 开放图块：[重涂色](已有，标记像素变色)}

**来源原语**：连通分量检测 + 边界可达性 + 拓扑分类（84db8fc4），印章覆盖 + 分隔网格 + 模板图块 + 标记像素（e734a0e8），重涂色（ef26cbf6）

**依赖链**：分隔线中的缺口创造了隐式拓扑结构：某些图块的内部背景区域通过缺口与网格边缘相连（开放），某些被完整分隔线包围（封闭）。同样的灰色标记像素在封闭图块中触发印章覆盖，在开放图块中仅被重涂为红色。拓扑分类是操作选择的门控条件——改变一处缺口就可能改变某个图块的拓扑类别，从而改变该图块的整个变换结果。

在一个有缺口的分隔网格中，根据图块是否被分隔线完全封闭来决定操作：封闭且标记的图块接收模板印章，开放且标记的图块仅将标记像素变为红色。

**输入结构**：约 16x16 网格。灰(5)像素形成规则的分隔线网格，将画布分割为若干等大的矩形图块（如 3x4 的图块排列，每个图块内部约 4x3，分隔线宽 1 像素）。其中一个图块内包含一个非灰非黑的彩色小图案（2~5 个像素，使用蓝(1)、绿(3)等颜色），作为模板图块。另有若干图块的内部各含一个灰(5)标记像素（与分隔线同色但位于图块内部，不与分隔线相连）。部分分隔线段被擦除（替换为黑(0)背景），形成 1~2 像素宽的缺口。缺口使得部分图块的内部背景区域通过缺口与相邻图块的内部或网格边缘 4-连通相连。生成约束：模板图块的四面分隔线完整无缺口；每个标记图块恰好有一个内部灰像素；至少有一个封闭的标记图块和一个开放的标记图块。

**规则**：
1. 对网格中所有黑(0)背景像素进行 4-连通区域检测。一个图块是"封闭"的，当且仅当其内部的背景像素所属的 4-连通区域不与网格的任何边缘行/列相接触。否则该图块是"开放"的。
2. 对每个封闭且含标记像素的图块：用模板图块的内容完整覆盖该图块的内部（印章覆盖），标记像素被模板内容替换。
3. 对每个开放且含标记像素的图块：仅将该标记像素从灰(5)重涂为红(2)，图块其余内容不变。
4. 无标记像素的图块（无论封闭或开放）、模板图块本身、以及所有残留的分隔线像素均保持不变。

**关键洞察**：标记像素的存在是操作的必要条件但不是充分条件——同样的标记在封闭图块中触发印章，在开放图块中仅触发变色。区分两者的关键是追踪分隔线缺口导致的背景连通性，而这种连通性在视觉上不显眼。

## 新题 5：四角矩形中距离竞争的标记色填充

**组合逻辑**：[四角标记围定内部](已有) → [填充](已有) + [行列对齐 + 对齐标记定颜色](创新：多个候选标记竞争，最近者胜出)

**来源原语**：四角标记围定内部 + 角标记 + 矩形（af902bf9），填充（af902bf9），行列对齐 + 对齐标记定颜色 + 单像素标记（ef26cbf6）

**依赖链**：四角标记定义矩形的几何位置和形状（来自 af902bf9 的检测机制）。每个矩形可能有多个行列对齐的彩色标记（来自 ef26cbf6 的对齐概念），需要通过曼哈顿距离竞争选出唯一的颜色来源。矩形的几何结构决定了哪些标记是"对齐"的候选者，距离比较决定了最终填充颜色。两个编码通道（角标记编码形状，彩色标记编码颜色）必须同时解码才能确定输出。

用四个黄色角标记确定矩形轮廓，用与矩形行列对齐的彩色单像素标记确定填充颜色——当多个标记同时对齐时，选取离矩形中心最近的标记。

**输入结构**：约 15x15 网格。黑(0)为背景。若干组黄(4)像素，每组恰好 4 个，分布在两行两列的交叉处，定义 2~3 个互不重叠的矩形（矩形内部为黑色）。矩形边长约 3~6 像素。另有若干彩色单像素标记（使用红(2)、蓝(1)、绿(3)中的颜色，每个标记恰好 1 像素），分布在矩形外部。每个标记与至少一个矩形"行列对齐"：标记的行坐标落在某矩形的行范围 [r_top, r_bottom] 内（但列坐标在矩形列范围外），或标记的列坐标落在某矩形的列范围 [c_left, c_right] 内（但行坐标在矩形行范围外）。生成约束：每个矩形至少有一个对齐标记；不同矩形不共享最近标记（每个标记最终只服务于一个矩形）。

**规则**：
1. 检测所有由四个黄(4)像素定义的矩形：四个黄像素位于 (r1,c1)、(r1,c2)、(r2,c1)、(r2,c2)，其中 r1 < r2，c1 < c2。
2. 对每个矩形，收集所有与之行列对齐的彩色标记像素（标记的行在 [r1,r2] 范围内且列在 c1 左侧或 c2 右侧，或标记的列在 [c1,c2] 范围内且行在 r1 上方或 r2 下方）。
3. 在候选标记中，计算每个标记到该矩形中心像素（行 = floor((r1+r2)/2)，列 = floor((c1+c2)/2)）的曼哈顿距离，选取距离最小的标记。若距离相同，优先选取行对齐的标记（即标记行坐标在矩形行范围内的）。
4. 将该矩形内部（不含黄色边界像素）填充为被选标记的颜色。
5. 保留黄色角标记像素。擦除所有彩色单像素标记。

**关键洞察**：黄色角标记编码几何信息（在哪里填），彩色标记编码外观信息（填什么色），两者是独立的编码通道。当一个矩形有多个对齐标记时，并非按行列唯一匹配（如 ef26cbf6），而是通过距离竞争选出胜者——需要对比多个示例才能发现距离优先规则，而非简单的行列对应。

## 新题 6：重力沉降进入盆地后触发配对色反转

**组合逻辑**：[重力下落 + 碰撞停止](已有) → [连通分量检测 + 边界可达性 → 拓扑分类](已有，创新：在静态障碍结构上预判盆地位置) → [配对色映射](已有，创新：仅对落入盆地的像素执行)

**来源原语**：重力下落 + 碰撞停止 + 障碍物（28a6681f），连通分量检测 + 边界可达性 + 拓扑分类（84db8fc4），反转 + 配对色映射（6ea4a07e）

**依赖链**：重力将上方像素沉降到下方障碍结构中，落点由列位置和障碍形状决定。拓扑分类预先将下方的空白区域分为"盆地"（封闭、不连通至边缘）和"开阔地"（连通至边缘）。像素的最终颜色取决于落点属于哪种区域：盆地中的像素执行配对色反转，开阔地的像素保持原色。三个操作形成物理-拓扑-颜色的三角耦合：改变障碍形状会同时影响落点和盆地边界，一个小变化可能使像素从盆地跳到开阔地（或反之），导致颜色翻转。

散落在上方的彩色像素在重力作用下沉降到下方的障碍结构上；落入封闭盆地的像素执行配对色反转，落在开阔表面的像素保持原色。

**输入结构**：约 14x14 网格。黑(0)为背景。一条完整的水平灰(5)线将网格分为上下两区（位于约第 4~5 行）。上区：散布若干彩色像素，颜色仅限青(8)、绿(3)、灰(5)三种（即 6ea4a07e 中的配对色输入色）。每种颜色 2~4 个像素，互不相邻。下区：品红(6)和栗(9)像素构成静态障碍结构——若干不规则的壁状和台阶状形状，形成 2~3 个封闭凹陷（盆地）和若干开放表面。下区的障碍结构不使用青、绿、灰、红(2)、蓝(1)、黄(4)中的任何颜色。生成约束：上区的彩色像素在下落后，至少有一个落入盆地，至少有一个落在开阔地；灰色分界线恰好一行宽。

**规则**：
1. 在下区（灰色分界线以下），对所有黑(0)背景像素进行 4-连通区域检测。将不与网格底边或左右边缘接触的黑色连通区域标记为"盆地"，其余标记为"开阔地"。
2. 移除灰(5)分界线（该行所有灰色像素变为黑(0)背景）。
3. 对上区每个彩色像素（青(8)、绿(3)、灰(5)），在其所在列内向下移动，穿过黑(0)背景格，直到碰到障碍像素（品红(6)或栗(9)）、另一个已沉降的像素、或网格底边为止。像素停在碰撞位置的上方一格。按从下到上的顺序处理各像素（下方的先落位，上方的后落位堆叠其上）。
4. 判定每个沉降后像素的最终位置：
   - 若该位置在步骤 1 中被标记为"盆地"内的格子，则执行配对色反转：青(8)→红(2)，绿(3)→蓝(1)，灰(5)→黄(4)。
   - 若该位置为"开阔地"或在盆地上方堆叠超出原始盆地区域，则保持原色不变。
5. 障碍结构保持不变。

**关键洞察**：同一种颜色的两个像素可能因为分别落入盆地和开阔地而在输出中变成不同的颜色——颜色变换不取决于输入色本身，而取决于重力将像素送往何处。盆地的封闭性是隐式的，需要从障碍结构中推断。

## 新题 7：重复图案选取后按唯一图案数缩放

**组合逻辑**：[裁剪 + 图案匹配 + 出现两次者选取](已有) → [分类/计数](创新：统计唯一图案种类数作为缩放因子) → [像素放大](已有，缩放因子由计数结果决定)

**来源原语**：裁剪 + 图案匹配 + 出现两次者选取（f5aa3634），像素放大 + 每像素扩展为色块（9172f3a0），分类（1d61978c）

**依赖链**：图案匹配从多个精灵体中筛选出唯一的重复图案（目标选择）。所有精灵体的唯一图案种类总数编码了放大倍率（信息提取）。像素放大将选中的图案按该倍率逐像素扩展（几何变换）。三步形成链式信息依赖：匹配找到"放大什么"，计数找到"放大几倍"，缺少任何一环都无法确定输出。

从多个散布的精灵体中找出恰好出现两次的图案，统计所有唯一图案的种类数 N，然后将该重复图案逐像素放大 N 倍输出。

**输入结构**：约 18x18 网格。黑(0)为背景。网格中散布 N 组互不接触的 4-连通多色精灵体（N 约 3~5）。每组精灵体由 3~6 个非黑像素组成，使用 2~3 种颜色，形状各异（具体形状由连通结构和像素数决定，不固定为某种命名形状）。恰好有一种图案在网格中出现了两次（两个实例的裁剪后彩色内容完全相同，包括内部的黑色孔洞，但位置不同），其余 N-1 种图案各出现一次。不同示例中 N 的值不同（如示例 1 中 N=3，示例 2 中 N=4），导致放大倍率不同。

**规则**：
1. 对每个精灵体，裁剪到其最小包围盒，保留包围盒内的所有像素颜色（含内部黑色像素）。
2. 比较所有裁剪结果，找到恰好出现两次的唯一图案 P。
3. 统计所有不同裁剪图案的种类数 N（重复图案算一种）。
4. 对图案 P 执行像素放大：将 P 中每个像素（含黑色像素）替换为 NxN 的同色方块。输出网格大小为 (P 的行数 x N) 行 x (P 的列数 x N) 列。
5. 输出仅包含放大后的图案，不保留原网格中的其他精灵体或背景。

**关键洞察**：干扰精灵体（非重复的）不仅仅是需要过滤的噪声——它们的数量直接编码了放大倍率。增加一个干扰精灵体就会使输出尺寸增大。需要对比 N 不同的示例才能发现"种类数=倍率"的规则。

## 新题 8：重复图案选定模板后按标记位置旋转印章

**组合逻辑**：[图案匹配 + 出现两次者选取](已有) → [印章覆盖 + 标记指定放置位置](已有) + [旋转](创新：旋转角度由标记在图块内的象限位置编码)

**来源原语**：图案匹配 + 出现两次者选取 + 裁剪（f5aa3634），印章覆盖 + 分隔网格 + 模板图块 + 标记指定放置位置（e734a0e8），旋转 + 标记定旋转源目（ecaa0ec1）

**依赖链**：图案匹配在多个图块中选出重复出现的精灵体作为印章模板（"印什么"由重复性决定，非显式标记）。标记像素的存在指示"印在哪"。标记像素在图块内的具体位置编码旋转角度（"怎么印"），将同一模板以不同朝向印入不同图块。三个信息来源（重复性→模板、标记存在→位置、标记坐标→旋转）互相独立又缺一不可。

在分隔网格中，通过图案重复性识别印章模板，将其以标记像素编码的旋转角度印入各标记图块，同时擦除原始重复实例。

**输入结构**：约 17x17 网格。灰(5)分隔线将网格分割为若干等大的正方形图块（如 4x4 的图块排列，每个图块内部 3x3，分隔线宽 1 像素）。部分图块内有彩色精灵体（每个精灵体使用 1~2 种非灰非黑的颜色，2~4 像素，4-连通），其中恰好一种精灵体图案在两个不同图块中出现（两处内容裁剪后完全相同），其余精灵体图案各出现一次。另有若干空白图块（内部全为黑(0)背景），每个空白图块中包含恰好一个灰(5)标记像素——该标记像素位于图块内部 3x3 区域的四个角落像素之一（左上、右上、右下、左下）。模板精灵体的图案不具有 90 度旋转对称性（旋转后能看出区别）。生成约束：每个标记图块内的标记像素仅占据四角位置中的一个；所有分隔线完整无缺口。

**规则**：
1. 对每个含精灵体的图块，裁剪出其内部图案（3x3 区域的内容）。比较所有图案，找出恰好出现两次的图案作为印章模板 T。
2. 对每个含灰色标记像素的空白图块，确定标记像素在图块内部 3x3 区域中的角落位置：
   - 标记在左上角 (0,0) → 旋转 0 度（不旋转）。
   - 标记在右上角 (0,2) → 顺时针旋转 90 度。
   - 标记在右下角 (2,2) → 旋转 180 度。
   - 标记在左下角 (2,0) → 顺时针旋转 270 度。
3. 将模板 T 按对应角度旋转后覆盖到该图块的 3x3 内部区域中，替换原有内容（包括标记像素）。
4. 将原来包含模板精灵体的两个图块清空（内部区域全部变为黑(0)背景）。
5. 所有分隔线、无标记的空白图块、以及包含非模板精灵体的图块保持不变。

**关键洞察**：模板的选择不由颜色或位置决定，而由"恰好出现两次"的重复性决定——这是 f5aa3634 的选择逻辑。但标记像素不仅是"在此印章"的存在标志（如 e734a0e8），其在图块内的精确位置还编码了旋转指令——同一模板在不同图块中呈现不同朝向。需要对比多个标记图块的输出才能归纳出"角落位置→旋转角度"的映射。
