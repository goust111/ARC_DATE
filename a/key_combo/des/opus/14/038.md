## 新题 1：对角射线分区周期填充

**组合逻辑**：[ray_cast](创新：对角射线作为分区墙而非装饰) + [flood_fill] + [sorting](创新：按面积而非空间位置排序) + [periodic_fill]

**来源原语**：ray_cast/diag_adjacency/solid_square/diag_marker（来自 7ddcd7ec）、flood_fill/enclosed_region/region_order（来自 7447852a）、periodic_fill（来自 7447852a）

**依赖链**：对角射线的几何位置决定了区域的边界形状和面积 → 面积排序产生了与空间位置无关的秩序 → 周期采样在这个秩序上选择目标区域。三者共同决定输出，删除任一环节都无法确定哪些区域被填充。

将锚点方块的对角标记射线用作分区墙，射线与网格边界围成的封闭区域按面积排序后，周期性地选择区域进行填充。

**输入结构**：约 15x15 的黑(0)背景网格。网格中分布 2~4 个蓝(1)单色实心 2x2 方块，互不共享行或列。每个方块有 1~2 个蓝(1)单像素对角邻接于其角落（与方块本体不在同一行/列，位于方块角的对角延伸方向上）。生成约束：任意两条对角射线不会重合于同一条对角线路径上；所有射线与网格边界围成的区域均为简单多边形（无悬挂线段）。

**规则**：
1. 对于每个对角标记像素，沿其远离父方块的对角方向（即标记像素相对于其所邻接角的方向）逐格延伸，将路径上所有黑(0)像素涂为灰(5)，直至射线离开网格边界。
2. 灰(5)射线像素加上网格四边界将黑(0)背景分割为若干互不连通的区域（4-连通判定）。蓝(1)方块、蓝(1)标记、灰(5)射线均不属于任何区域。
3. 按面积（区域内像素总数）对所有区域升序排序。面积相同时，按区域中行号最小的像素所在行升序排列；行号仍相同时，按该行中列号最小的像素所在列升序排列。
4. 对排序后位置为 0, 3, 6, 9, ...（即每隔 3 个取 1 个，从第 0 个开始）的区域，将其所有像素填充为黄(4)。
5. 其余区域保持黑(0)不变。蓝方块、蓝标记、灰射线均保持不变。

**关键洞察**：对角射线在源题中仅是形状的视觉延伸，在此处它们承担了分区墙的结构角色。填充目标由面积排序而非空间邻近性决定——增减一个标记像素会改变所有区域的面积分布，从而重新洗牌哪些区域被选中填充。

## 新题 2：路径生长驱动的递归印章

**组合逻辑**：[path_grow + obstacle_deflection](已有) → [pixel_scaling + recursive_stamp](创新：印章掩模由动态路径而非静态像素决定)

**来源原语**：path_grow/obstacle_deflection/control_pixel/blocker（来自 712bf12e）、pixel_scaling/recursive_stamp/cell_block_mapping/input_pattern（来自 cce03e0d）

**依赖链**：路径生长的轨迹决定了印章掩模的形状 → 印章掩模决定了放大输出中哪些块接收原始图案的复制 → 障碍像素既偏转路径又出现在每份印章副本中，形成双重角色的紧耦合。

从底行控制像素向上生长路径，路径遇障碍向右偏转；路径覆盖的所有像素构成印章掩模，用于在放大网格中递归印章整幅原始图案。

**输入结构**：一个 5x5 的网格。底行（第 4 行）含 1~3 个红(2)控制像素，其余底行像素为黑(0)。网格内部散布若干灰(5)障碍像素（不在底行）。其余像素使用蓝(1)、绿(3)等非红非灰非黑颜色构成一个小图案。生成约束：每条路径至少能向上行进 2 步（不会被堵死在底行附近）；从一个控制像素出发的路径不会经过另一个控制像素的起始位置。

**规则**：
1. 从每个红(2)控制像素出发，逐步向上生长路径：若当前格的正上方为非灰且在网格内，则移动到正上方并将该格标记为"已访问"；若正上方为灰(5)障碍或超出边界，则尝试移动到当前格的右侧一格——若该格为非灰且在网格内，则移动到该格并标记为"已访问"，然后从该格继续尝试向上；若右侧也不可用（灰或超出边界），路径终止。
2. 收集所有被任一路径访问的格（包括初始红像素位置）构成"印章掩模"集合。
3. 构建 25x25（即 5x5 个 5x5 块）的输出网格，初始全黑(0)。将输入的 5x5 网格视为块索引模板：对于印章掩模中的每个格 (r,c)，将原始 5x5 输入图案完整复制到输出中对应的块位置（输出行 r*5 到 r*5+4、输出列 c*5 到 c*5+4），像素值保持与输入完全一致（包括红、灰、黑等所有颜色）。
4. 印章掩模之外的块全部保持黑(0)。

**关键洞察**：障碍像素承担双重角色——它们既偏转路径（改变掩模形状），又作为输入图案的一部分出现在每份印章副本中。移动一个障碍，同时改变了"哪些块被印章"和"每份印章里包含什么内容"。

## 新题 3：壁纸补全后的标记选择性重涂

**组合逻辑**：[completion + residue_infers_period](已有) → [recolor](创新：仅对补全像素重涂，由标记列位置选色)

**来源原语**：completion/periodic_tile/erased_pixel/periodic_repeat/residue_infers_period（来自 ea959feb）、recolor/marker_pixel/column_position_mapping/marker_column_determines_row_color（来自 a85d4709）

**依赖链**：先推断周期瓦片并补全缺损 → 补全产生"哪些像素是恢复的"这一中间信息 → 标记像素的列位置决定重涂颜色，但只对已恢复像素生效。若跳过补全，则不知道哪些像素应被重涂；若跳过标记读取，则不知道重涂为何色。

推断壁纸的最小重复瓦片并补全被擦除的像素；然后根据每行中标记像素的水平位置，仅将该行中补全的像素重涂为指定颜色，原始幸存像素不受影响。

**输入结构**：约 12x12 的网格，包含一个使用 2~3 种颜色（如蓝(1)、红(2)、绿(3)）的周期性壁纸图案，行周期和列周期各为 2~4 格。部分图案像素已被擦除为黑(0)背景。此外，网格中散布灰(5)标记像素，每行最多一个灰标记，且灰标记不覆盖任何壁纸图案位置（灰标记仅出现在原本为黑(0)背景的位置上，即壁纸的"空位"处）。生成约束：擦除的像素足够稀疏，使得残留的前景像素能唯一确定最小周期；至少有 3 行包含灰标记且该行中存在被擦除的像素，以便推断标记与重涂颜色的对应关系。

**规则**：
1. 忽略灰(5)标记像素，从残留的非黑非灰前景像素推断壁纸的最小行周期 P_r 和列周期 P_c。对于每个残差类 (r mod P_r, c mod P_c)，如果有前景像素，则该残差类的颜色唯一确定。
2. 将所有属于有色残差类但当前为黑(0)的像素补全为对应的壁纸颜色。记录这些像素为"已补全像素"集合。
3. 对于每一行，如果该行包含灰(5)标记像素，读取标记的列位置：列位置在 [0, W/3) 范围内为"左区"，在 [W/3, 2W/3) 范围内为"中区"，在 [2W/3, W) 范围内为"右区"（W 为网格宽度，区间用整除划分）。
4. 将该行中所有"已补全像素"重涂：左区 → 黄(4)，中区 → 橙(7)，右区 → 品红(6)。该行中原始幸存的壁纸像素保持不变。
5. 不含灰标记的行中，已补全像素保持其在步骤 2 中恢复的壁纸颜色。灰标记像素在输出中保持灰(5)不变。

**关键洞察**：补全步骤恢复了壁纸，但其真正目的是产生"哪些像素是恢复的"这一隐含中间信息——只有这些像素才会被标记驱动的重涂所影响。一行若无擦除像素，即使有标记也无可见效果；反之若无标记，补全像素保持原色。

## 新题 4：分区排序驱动的精灵互换与秩填充

**组合逻辑**：[flood_fill + four_connected_partition](创新：分隔墙建分区) → [sorting + region_order](已有) → [pattern_swap + simultaneous_replacement](已有) + [recolor](创新：按分区排序秩决定背景色)

**来源原语**：flood_fill/divider_wall/four_connected_partition/corner_anchor（来自 782b5218）、sorting/region_order（来自 7447852a）、pattern_swap/foreground_sprite/sprite_template/same_size_bounding_box/color_identifies_template/simultaneous_replacement（来自 3391f8c0）、recolor（来自 bb43febb）

**依赖链**：红色分隔线建立分区 → 分区面积决定排序秩 → 秩的奇偶性决定背景填充颜色 → 精灵模板互换与背景填充同时发生在同一区域内，互不干扰但共同依赖分区结构。移动分隔线会同时改变区域面积排序和精灵所属区域，导致背景色和精灵形状同时变化。

红色分隔线将网格切分为矩形区域，每区域含一个精灵；两种颜色的精灵同步互换模板，同时每个区域的背景按面积排序的秩奇偶性决定是否填充。

**输入结构**：约 15x15 的黑(0)背景网格。红(2)像素组成水平和垂直的直线段，将网格切分为若干矩形区域（红线从一侧边界延伸到另一侧或到另一条红线，确保分区完整）。每个矩形区域内恰好有一个 4-连通的小精灵（3~6 像素），颜色为蓝(1)或绿(3)。所有蓝精灵形状相同（同一模板），所有绿精灵形状相同（另一模板），两种模板的边界框尺寸相同。生成约束：至少有 2 个蓝精灵和 2 个绿精灵；各区域面积互不相同（避免排序歧义）；精灵不接触红分隔线。

**规则**：
1. 红(2)分隔线将网格分为若干矩形区域。每个区域的"面积"定义为区域内非红像素的总数（包含精灵像素和黑背景像素）。
2. 按面积升序排列所有区域，赋予排序秩 0, 1, 2, ...。
3. 同步执行精灵互换：将每个蓝(1)精灵替换为绿模板（绘制为绿(3)），将每个绿(3)精灵替换为蓝模板（绘制为蓝(1)）。替换在原精灵边界框的中心位置对齐。先清除所有原精灵像素为黑(0)，再绘制所有新精灵（同步替换，避免覆盖冲突）。
4. 对于排序秩为奇数的区域，将该区域内所有黑(0)背景像素（不包括精灵像素和红线像素）填充为黄(4)。排序秩为偶数的区域保持黑(0)背景。
5. 红(2)分隔线像素保持不变。

**关键洞察**：分隔线同时控制两个独立效果：精灵互换依赖分区确定"哪个精灵在哪个区域"，而背景填充依赖面积排序秩的奇偶性。移动一条分隔线会同时改变区域面积（影响排序秩和背景色）和精灵的归属区域（影响互换定位），产生联动效应。

## 新题 5：四象限镜像射线交叉标记

**组合逻辑**：[mirror + four_quadrant_layout](已有) → [ray_extend + pixel_as_ray_center](已有) → [recolor](创新：根据射线来源的不同进行交叉点分类着色)

**来源原语**：mirror/four_quadrant_layout/mirror_symmetric_expand（来自 62c24649）、ray_extend/full_row_column_ray/pixel_as_ray_center（来自 140c817e）、recolor/diagonal_neighbor（来自 140c817e）、rays_overwrite_cross（来自 f8be4b64）

**依赖链**：镜像将少量控制像素扩展为 4 倍 → 射线从所有副本发射，产生原始输入中不存在的交叉 → 交叉点的着色取决于交叉射线来自不同还是相同控制像素的副本，这要求回溯射线归属。三个步骤信息传递不可逆。

先将输入四象限镜像展开，然后从每个控制像素（含镜像副本）发射整行整列射线，最后根据射线交叉点的来源关系进行分类着色。

**输入结构**：一个小的矩形网格（约 5x7），黑(0)背景上有 2~3 个蓝(1)控制像素。控制像素互不共享行或列。生成约束：网格行数和列数均大于 2。

**规则**：
1. 构建一个 2H x 2W 的镜像网格（H、W 为原始网格的行数和列数）：左上象限为原始输入，右上象限为左右镜像，左下象限为上下镜像，右下象限为左右+上下镜像。此时每个原始蓝像素在镜像网格中产生 4 个副本。
2. 对镜像网格中的每个蓝(1)像素，将其所在整行和整列的所有非蓝像素涂为蓝(1)（若该位置已为蓝则不变）。
3. 将每个蓝像素的原始位置（即步骤 1 中放置的像素，不含射线延伸产生的像素）重涂为红(2)。
4. 检查所有蓝(1)像素位置：若某个蓝像素同时位于来自不同原始控制像素（在镜像前追溯到不同源）的两条射线的交叉点上（即它同时在某个源 A 的副本的行射线上，又在某个源 B（B!=A）的副本的列射线上，或反之），则将该像素重涂为绿(3)。
5. 仅位于单一源的射线上（无论是行射线还是列射线）的蓝像素保持蓝(1)。

**关键洞察**：镜像不是简单的放大——它将 2~3 个控制像素扩展为 8~12 个射线源，产生大量原始输入中不存在的交叉。绿色交叉标记形成的图案完全由控制像素间的相对位置决定，且因镜像对称性而呈现四重对称。判断交叉来源要求将镜像副本追溯到原始源。

## 新题 6：种子分组腔体的循环调色板填充

**组合逻辑**：[flood_fill + connectivity_reachable + seed_color_labels_fill](创新：种子仅标定分组，不提供填充色) + [tiling/cyclic_header](创新：头序列作为循环调色板按腔体排序分配颜色)

**来源原语**：flood_fill/seed_pixel/enclosed_cavity/line_drawing/connectivity_reachable/seed_color_labels_fill（来自 8b7bacbf）、tiling/header_sequence/diag_index_map/cyclic_header_doubled（来自 539a4f51）

**依赖链**：种子像素通过连通性将腔体归入不同组 → 头序列提供循环调色板 → 每组腔体按空间排序后独立循环同一调色板，组内腔体数量不同导致循环相位不同。种子决定分组但不决定颜色，头序列决定颜色但不决定分组，缺一不可。

种子像素通过线条连通性标定各自的腔体组，但填充颜色不来自种子本身，而是从顶行头序列中按腔体空间排序循环取用。

**输入结构**：约 15x15 的黑(0)背景网格。灰(5)线段在网格中构成若干封闭环路，围出 4~8 个黑(0)腔体（4-连通判定的封闭区域）。2~3 个唯一色单像素（如红(2)、蓝(1)、橙(7)）位于网格边界上，每个种子通过 8-连通与某段灰线相连。每段灰线连接恰好一个种子。顶行（第 0 行）包含一段头序列：从左到右的 2~3 个非黑像素（如黄(4)、绿(3)、品红(6)），后接黑(0)填充。头序列中的颜色互不相同，且不与种子颜色重复。生成约束：每个种子至少连接 1 个腔体，至少有一个种子连接 2 个以上的腔体；头序列长度小于任一种子所连腔体的最大数量（确保循环至少绕回一次）。

**规则**：
1. 对每个边界种子像素，通过 8-连通找到与之相连的灰(5)线段集合。
2. 对每段灰线集合，找出所有边界接触该线段的黑(0)封闭腔体（腔体的 4-连通边界中至少有一个像素与该灰线 4-相邻）。这些腔体归入该种子的组。
3. 读取顶行头序列：从第 0 行第 0 列开始，收集所有连续的非黑像素作为调色板 P（有序列表）。
4. 对每个种子组内的腔体，按腔体中行号最小的像素所在行升序排列，行号相同时按列号最小的像素所在列升序排列。
5. 对排序后第 i 个腔体（0-indexed），填充颜色为 P[i mod len(P)]——即循环使用头序列调色板。
6. 种子像素保持原色不变。灰线和头序列保持不变。

**关键洞察**：种子颜色标定了腔体的分组归属但不参与填充——填充颜色完全来自头序列的循环。两个不同种子的组独立循环同一调色板，若一组有 2 个腔体、另一组有 5 个腔体，它们使用调色板的深度不同，产生不同的颜色序列。需要对比多个示例才能区分"种子色决定填充色"（错误假设）和"头序列循环决定填充色"（正确规则）。

## 新题 7：矩形对角对称分类重涂

**组合逻辑**：[recolor + interior_vs_border + only_interior_recolored](已有) + [mirror（作为对称性检测而非构建操作）](创新：全局对角对称关系决定局部重涂颜色)

**来源原语**：recolor/filled_rectangle/interior_vs_border/only_interior_recolored（来自 bb43febb）、mirror/four_quadrant_layout（来自 62c24649 — 这里的"镜像"用作对称性判据而非空间构建）

**依赖链**：矩形的边框/内部划分决定哪些像素可被重涂 → 全局对角对称分析对所有矩形进行分类 → 分类结果决定每个矩形的内部颜色。这是同时约束结构：必须先分析所有矩形的全局对称关系，才能确定任何一个矩形的颜色。

分析每个灰色矩形沿网格主对角线反射后是否与另一个矩形重合，将矩形分为三类并分别重涂内部颜色。

**输入结构**：约 14x14 的黑(0)背景网格（行数等于列数，即方形网格），包含 4~6 个灰(5)实心轴对齐矩形，每个矩形的高和宽均至少为 3。矩形之间不重叠，矩形不接触网格边界。生成约束：至少有一对矩形沿主对角线互为镜像（即矩形 A 的边界框 (r1,c1)-(r2,c2) 映射为 (c1,r1)-(c2,r2) 后恰好与矩形 B 重合），至少有一个矩形自身关于主对角线对称（边界框满足 r1=c1 且 r2=c2），至少有一个矩形的对角镜像位置不与任何矩形重合。

**规则**：
1. 对每个灰(5)矩形 R，计算其边界框沿主对角线的镜像位置：将 (r1,c1)-(r2,c2) 映射为 (c1,r1)-(c2,r2)。
2. 分类：
   - A 类（互为镜像）：R 的对角镜像位置恰好被另一个灰矩形 R' 完全覆盖（边界框完全重合）。R 和 R' 互为 A 类。
   - B 类（自身对称）：R 的对角镜像位置与自身的边界框完全重合（即 r1=c1 且 r2=c2，矩形中心在主对角线上且形状关于对角线对称）。
   - C 类（无配对）：R 的对角镜像位置不与任何灰矩形（包括自身）的边界框重合。
3. 对每个矩形，保留其 1 像素宽的灰(5)边框不变，将严格内部的所有像素重涂为：A 类 → 红(2)，B 类 → 蓝(1)，C 类 → 绿(3)。
4. 黑(0)背景像素保持不变。

**关键洞察**：矩形的内部颜色不由任何局部属性（面积、位置、形状）决定，而由全局对称关系决定——必须检查所有矩形的对角镜像位置才能分类任何一个。外观相同的两个矩形可能获得不同颜色，仅因它们在对角线对称结构中的角色不同。这是一个同时约束问题，不存在可以依次处理单个矩形的流水线。

## 新题 8：条形编码旋转与行提取

**组合逻辑**：[counting + categorical_count](已有) → [rotate + whole_grid_rotate](创新：旋转量由外部编码决定) → [erase + summary_generation](创新：旋转后提取单行作为输出)

**来源原语**：counting/categorical_count/horizontal_bar/row_major_fill（来自 5289ad53）、rotate/whole_grid_rotate/square_grid（来自 ed36ccf7）、summary_generation（来自 5289ad53）、erase（来自 782b5218）

**依赖链**：右区条形的计数编码了两个参数 → 黄条数决定旋转量 → 旋转改变了图案中每行的内容 → 橙条数决定从旋转后图案中提取哪一行。两个计数分别控制不同维度的变换，同时改变一种条的颜色会同时影响旋转和提取，产生双重联动。

右半区的彩色横条编码两个参数：一种颜色的条数决定左半区图案的旋转角度，另一种颜色的条数决定从旋转结果中提取哪一行作为输出。

**输入结构**：约 7x15 的网格，由一条垂直灰(5)分隔线（位于网格中部某列，从顶到底）分为左右两半。左半区：一个 H x H 的方形彩色图案（使用蓝(1)、红(2)、绿(3)等颜色，H 与左半区高度相同且等于网格高度）居中放置，背景黑(0)。右半区：若干单像素厚度的水平横条，颜色为黄(4)或橙(7)，每条横跨右半区全宽，不同条在不同行，不重叠。右半区的非横条像素为黑(0)。生成约束：黄(4)条数不超过 3（确保旋转量 0~3 有意义）；橙(7)条数小于 H（确保行索引有效）；左半区图案关于旋转不对称（不同旋转产生不同结果）。

**规则**：
1. 计数右半区中黄(4)横条的数量 Y 和橙(7)横条的数量 O。
2. 计算旋转量 R = Y mod 4。将左半区的 H x H 图案逆时针旋转 R x 90 度（R=0 不旋转，R=1 旋转 90 度，R=2 旋转 180 度，R=3 旋转 270 度）。
3. 从旋转后的图案中提取第 O 行（0-indexed，从顶部开始计数）。
4. 输出仅为该单行（1 x H 的网格）。丢弃灰分隔线、右半区和图案的其余行。

**关键洞察**：右区的横条不是装饰——它们是编码信号。黄条和橙条各自独立编码一个参数，但它们作用于同一个图案的变换链上：旋转改变了每行的内容，因此提取第 O 行的结果取决于旋转量。将一条黄色横条改为橙色会同时减少旋转量并增加提取行号，对输出产生双重非线性影响。

## 新题 9：分隔行编码旋转的对角拼装

**组合逻辑**：[jigsaw_assemble + rotate](创新：旋转量由碎片的序数位置隐式编码) + [concatenate + diag_layout](已有) + [separator_row + blank_row_separator](创新：分隔行作为分组界与旋转编码器的双重角色)

**来源原语**：jigsaw_assemble/rotate/fragment（来自 f560132c）、concatenate/diag_copy/diag_layout/separator_row/blank_row_separator（来自 fb791726）、rotate/whole_grid_rotate（来自 ed36ccf7）

**依赖链**：分隔行划定碎片组的边界 → 碎片组的序数位置（由分隔行数量决定）编码旋转量 → 旋转后的碎片必须在对角线布局中几何兼容 → 对角拼装产生最终输出。分隔行同时承担分组和编码两个角色，缺一不可。

绿色分隔行将网格划分为若干碎片组，每组中的矩形碎片按其组的序数位置旋转后，沿对角线拼装到输出网格中。

**输入结构**：约 20x8 的网格（高大于宽）。绿(3)的满行水平分隔行将网格分为 3~4 组（组数 N）。每组内黑(0)背景上有一个矩形彩色碎片（使用蓝(1)、红(2)、黄(4)等颜色），碎片的边界框为 H_f x W_f（所有碎片旋转前后的边界框尺寸一致——例如 3x4 和 4x3 视为旋转关系）。碎片内部图案不具有旋转对称性（即旋转 90/180/270 度后图案均不同）。生成约束：N 不超过 4；碎片边界框在 0 度和 90 度旋转后的尺寸均能放入对角块中。

**规则**：
1. 识别绿(3)分隔行，将网格划分为 N 组。第一组（最顶部）编号为 0，依次递增。
2. 从每组中提取矩形碎片（组内唯一的非黑非绿连通区域的最小边界框）。
3. 对编号为 k 的组中的碎片，顺时针旋转 k x 90 度（k=0 不旋转，k=1 旋转 90 度 CW，k=2 旋转 180 度，k=3 旋转 270 度 CW）。
4. 构建 N x N 块的输出网格，每块尺寸为旋转后碎片的边界框大小（若旋转 90/270 度则 H_f 和 W_f 互换）。将第 k 个旋转后碎片放入对角线上的第 (k, k) 块。
5. 所有非对角线块填充为黑(0)。输出中不包含绿分隔行。

**关键洞察**：分隔行的数量和位置不仅决定了碎片的分组，还通过序数位置隐式编码了每个碎片的旋转量。从单个示例中无法确定旋转量是由序数位置、碎片颜色还是碎片形状属性决定——必须对比多个示例中同一序数位置的碎片均旋转相同角度才能归纳出规则。
