## 新题 1：奇方阵中心锚定字形印章

**组合逻辑**：[标注中心](已有) + [奇偶性](已有) → [编码映射](创新：将几何尺寸映射为字形索引) → [图案印章](已有) + [擦除](已有)

**来源原语**：标注中心、奇偶性、奇边长才标注 ← 22806e14；图案印章、编码映射、字形字典 ← dfadab01；擦除 ← 22806e14

**依赖链**：奇偶性筛选决定哪些方阵参与后续处理 → 通过筛选的方阵的边长值作为字形字典的索引键 → 标注中心确定印章的锚点坐标 → 图案印章在锚点处绘制对应字形 → 擦除原方阵像素。删除奇偶性筛选则无法确定目标集合；删除边长编码则无法确定印哪个字形；删除中心标注则无印章坐标；删除擦除则输出叠加不清。

对每个奇边长实心方阵，用其边长值查字形字典，在方阵中心位置印上对应字形并擦除原方阵。

**输入结构**：约 20x20 的黑(0)背景网格。散布 4~6 个绿(3)实心正方形，边长从 3 到 9 不等，既有奇数也有偶数边长，各方阵互不重叠且不相邻（任意两方阵边界框间距至少 1 像素）。网格最下方两行为字形图例区：用灰(5)分隔符将图例区分为 3~4 个等宽槽位，每个槽位内放置一个 3x3 的红(2)字形图案（各字形形状不同，如十字、角标、对角线等），槽位从左到右分别对应奇数边长 3、5、7（若有第四槽位则对应 9）。生成约束：所有奇边长方阵的边长值都能在字形图例中找到对应槽位。

**规则**：
1. 扫描网格中所有绿(3)实心正方形（4-连通单色区域且边界框为正方形且完全填满）。
2. 对每个方阵，计算其边长 s。若 s 为偶数，保留该方阵不做任何改动。
3. 若 s 为奇数，执行以下步骤：
   a. 计算中心像素坐标 (r_center, c_center) = (r_top + s//2, c_left + s//2)。
   b. 在字形图例中，按槽位从左到右的顺序，将第 k 个槽位（k 从 0 开始）对应边长 2k+3。找到 s 对应的槽位，提取其 3x3 字形。
   c. 将该 3x3 字形以 (r_center - 1, c_center - 1) 为左上角印到网格上，使用红(2)绘制字形的前景像素，字形的背景像素不覆盖（透明处理）。
   d. 将原方阵的所有绿(3)像素替换为黑(0)，但已印上的红(2)字形像素保留。
4. 擦除字形图例区（最下方两行全部置为黑(0)）。
5. 处理顺序：按方阵边界框左上角坐标从上到下、从左到右依次处理。由于生成约束保证方阵互不重叠，处理顺序不影响最终结果。

**关键洞察**：方阵的几何属性（边长）同时扮演两个角色——奇偶性决定是否参与变换，具体数值决定查字典的索引键——这种"属性双重复用"在任何单一参考题中都不存在。

## 新题 2：缩放块阵列中的射线分叉导航

**组合逻辑**：[像素放大](已有) + [块格阵列](已有) → [射线延伸](已有) + [墙段开口分支](创新：将缩放生成的间隙作为分支口) → [边缘像素复制](创新：射线末端复制标记色)

**来源原语**：像素放大、块格阵列、格位映射、前景掩码 ← 8719f442；射线延伸、分支、墙段开口分支、边缘标记、从边缘推进 ← f9a67cb5；边缘像素复制 ← 8719f442

**依赖链**：像素放大将种子图案转化为块阵列 → 块与块之间的间隙构成射线可通行的通道网络 → 射线从边缘标记出发在通道中推进 → 遇到块壁时在相邻间隙处分支 → 所有射线末端（死胡同处）向四邻域复制一个标记色像素。删除缩放则无迷宫结构；删除射线则缩放结果无意义的后续变换；删除末端复制则无法区分死胡同与通路。

将小图案缩放为块阵列构建迷宫，从边缘标记射入射线并在通道中分叉，最终在每个死胡同末端标记终止点。

**输入结构**：约 19x19 的黑(0)背景网格。左上角 3x3 区域放置一个蓝(1)前景掩码（3~5 个蓝像素构成 4-连通图形，其余为黑(0)）。网格的某一条边缘（上、下、左或右）上恰好有一个橙(7)单像素边缘标记，位置不与左上角 3x3 区域相邻。生成约束：缩放后的块阵列与边缘标记之间存在至少一条连通的背景通道（即射线至少可以推进一步）。

**规则**：
1. 提取左上角 3x3 蓝(1)前景掩码。
2. 在网格中央构建 9x9 块阵列：将每个前景像素映射为 3x3 蓝(1)实心块，放置在以网格中心为锚点的对应格位中。具体地，3x3 掩码的 (i,j) 位置映射到中央 9x9 区域的 (3i, 3j) 至 (3i+2, 3j+2) 子区域。块之间的空格保持黑(0)。
3. 从橙(7)边缘标记出发，沿垂直于该边缘的方向向网格内部推进射线：
   a. 射线沿直线前进，将经过的黑(0)像素涂为橙(7)。
   b. 当射线的下一个像素是蓝(1)块壁时，停止前进。找到被命中的连续蓝(1)墙段（沿垂直于射线方向的最大连续蓝(1)像素序列）。
   c. 检查该墙段两端之外的相邻像素：若为黑(0)（即间隙/开口），从该开口像素沿原射线方向继续发射新的分支射线。
   d. 递归执行：每条分支射线遇到下一面墙时重复步骤 b-c。
   e. 若射线到达网格边界仍未遇到墙壁，则在边界处停止。
4. 标记死胡同：对所有射线路径的末端像素（定义为：该橙色像素沿射线方向的下一个像素是蓝(1)块壁或网格边界，且该墙段两端均无开口），将该末端像素的四邻域中所有黑(0)像素涂为红(2)。
5. 已有橙(7)或蓝(1)像素不被红(2)覆盖。

**关键洞察**：紧凑的 3x3 种子图案既是块阵列的蓝图也是射线迷宫的拓扑定义——改变种子中任一像素都会同时改变障碍分布和可达路径集合。

## 新题 3：孔洞拼合后按行控制色重涂

**组合逻辑**：[形状嵌合 + 互补拼合](已有) → [每行独立取色](创新：拼合后的像素按所在行获取颜色) + [重涂色](已有)

**来源原语**：形状嵌合、互补拼合、精灵体、孔洞、拼块填孔洞后变色 ← 6a1e5592；每行独立取色、行控制色、重涂色、同行对齐 ← c7d4e6ad

**依赖链**：形状嵌合确定每块灰色拼图放入哪个孔洞 → 拼合后每块拼图跨越若干行 → 行控制色为每行指定独立颜色 → 重涂色将拼合像素逐行替换为对应控制色。删除拼合则无像素需要重涂；删除行控制色则涂什么颜色无从确定；两者缺一不可。

将灰色拼图块嵌入红色形状的孔洞中，嵌入后的像素不统一变色，而是逐行采用该行的控制色。

**输入结构**：约 15x15 的黑(0)背景网格。网格中有一个红(2)不规则形状（约 30~50 像素的 4-连通区域，边界框约 8x8 至 10x10），内部包含 2~3 个黑(0)孔洞（每个孔洞 3~8 像素，形状不规则但 4-连通）。红色形状外部散布 2~3 个灰(5)拼图块（每块是 4-连通的单色小图形，3~8 像素），每块恰好与一个孔洞形状互补（旋转 0 度即可嵌入，无需旋转或翻转）。网格最右列为控制色列：在红色形状边界框覆盖的每一行上，最右列放置一个单像素控制标记，颜色从 {蓝(1), 绿(3), 黄(4), 品红(6)} 中选取（同一题中可重复使用颜色，但不同示例中同一行的控制色可能不同）。未被红色形状边界框覆盖的行在最右列无控制标记。生成约束：每个灰色拼图块与恰好一个孔洞互补匹配，无歧义；各拼图块互不重叠。

**规则**：
1. 识别红(2)形状边界框内的所有黑(0)孔洞（边界框内的黑色 4-连通区域）。
2. 对每个灰(5)拼图块，裁剪其边界框。找到唯一一个孔洞使得拼图块的形状与孔洞完全匹配（像素级重合）。将拼图块平移到孔洞位置。匹配顺序：按拼图块边界框左上角从上到下、从左到右依次尝试。
3. 清除原灰(5)拼图块的位置（置为黑(0)）。
4. 对每个已放置的拼图像素 (r, c)：读取第 r 行最右列的控制色标记。将该像素涂为控制色。若第 r 行无控制色标记（不应在正确生成的输入中出现），则该像素保持黑(0)。
5. 红(2)形状本身不变。控制色列的标记像素保留不动。

**关键洞察**：拼图块的空间身份（形状）决定它去哪里，但它最终的颜色身份完全由目标位置的行坐标决定——同一块拼图的不同像素可能呈现不同颜色。

## 新题 4：单调最短路径并集的方向性错切

**组合逻辑**：[路径填充 + 最短路径并集](已有) → [错切 + 逐行偏移](创新：对路径并集的几何结果施加变形) + [门洞朝向](创新：朝向编码错切方向)

**来源原语**：路径填充、最短路径并集、门框、走廊路径、门洞朝向 ← 692cd3b6；错切、逐行偏移 ← 9f41bd9c

**依赖链**：门框位置和门洞确定路径端点 → 单调最短路径并集生成一个二维几何区域 → 两门框的相对方位决定错切轴（水平相邻→按行错切，垂直相邻→按列错切） → 逐行/列偏移施加累进错切 → 超出边界的像素裁剪。删除路径计算则无几何对象可变形；删除错切则退化为原题；删除方位判断则错切方向不确定。

先计算两门框间的单调最短路径并集，再根据门框相对方位对路径区域施加累进错切变形。

**输入结构**：约 18x18 的黑(0)背景网格。包含两个蓝(1)门框（每个门框为 3x3 的单像素厚空心方框，中心像素为红(2)标记），分别位于网格的不同区域，两框之间有若干灰(5)单像素厚水平或垂直线段作为障碍物。每个红(2)标记恰好有一个黑(0)四邻居（即门洞间隙），间隙外侧的第一个非框像素即为外部门洞点。两门框的连线方向以水平为主（两框中心的列距 >= 行距）或以垂直为主（行距 > 列距），不会恰好相等。生成约束：两外部门洞点之间存在至少一条仅使用缩短曼哈顿距离步骤的单调路径；障碍物不完全阻塞所有路径。

**规则**：
1. 确定两个门框各自的外部门洞点 A 和 B（红色标记的唯一黑色四邻居再向外一步的像素）。
2. 将所有蓝(1)框像素、红(2)标记和灰(5)障碍视为阻塞物。
3. 计算从 A 到 B 的单调最短路径并集：仅允许向目标方向缩短曼哈顿距离的四邻域步骤（即若 B 在 A 的右下方，则只允许向右和向下移动）。路径并集 = 所有此类路径经过的黑(0)像素的集合，加上 A、B 两点及两个门洞间隙像素。
4. 将路径并集的所有像素涂为黄(4)。
5. 判断错切方向：若两门框中心的列距 >= 行距（水平为主），则按行错切；否则按列错切。
6. 施加错切：
   a. 按行错切时：确定路径并集覆盖的最小行号 r_min。对路径并集中第 r 行的所有黄(4)像素，整体向右平移 (r - r_min) 个像素。
   b. 按列错切时：确定路径并集覆盖的最小列号 c_min。对路径并集中第 c 列的所有黄(4)像素，整体向下平移 (c - c_min) 个像素。
7. 平移后超出网格边界的像素丢弃。平移前的原位置若不再被任何黄(4)像素占据则恢复为黑(0)。
8. 蓝(1)框、红(2)标记和灰(5)障碍保持不变。若错切后的黄(4)像素与框/障碍重叠，黄(4)覆盖在最上层。

**关键洞察**：路径并集是一个中间几何产物而非最终答案——它必须经历一次依赖全局方位信息的空间变形才能得到输出。

## 新题 5：翻转检测驱动的双色互换模板补全

**组合逻辑**：[模板匹配 + 部分匹配识别](已有) → [镜像 + 翻转对应](创新：翻转类型编码颜色变换规则) → [双色互换](创新：由翻转类型触发) + [忽略干扰项](已有)

**来源原语**：模板匹配、部分匹配识别、目录模板、工作区精灵、忽略干扰项 ← 3ed85e70；镜像、翻转对应、模板块 ← cfb2ce5a；双色互换 ← b94a9452

**依赖链**：部分匹配识别将工作区片段与模板配对 → 配对过程中必须检测四种朝向（原始、水平翻转、垂直翻转、双轴翻转） → 检测到的翻转类型决定是否执行双色互换 → 按确定的朝向和色彩映射补全工作区精灵。删除翻转检测则无法同时确定朝向和颜色规则；删除双色互换则翻转检测结果无下游消费者。

识别工作区中的部分精灵属于哪个模板的哪种翻转视角，按翻转类型决定是否互换模板的两种前景色后再补全。

**输入结构**：约 20x20 的网格。左侧约 1/3 宽度为灰(5)目录背景区，其中放置 2~3 个模板精灵（每个模板为 4x4 至 5x5 的多色图案，恰好使用两种非背景非黑色的前景色，如蓝(1)+红(2)、绿(3)+黄(4)等，各模板使用不同的颜色对）。右侧约 2/3 为黑(0)工作区，包含 3~5 个部分精灵和 1~2 个干扰物体。每个部分精灵是某模板的一个连续子区域（至少包含模板面积的 1/3），可能处于以下朝向之一：原始朝向、水平翻转（左右镜像）、垂直翻转（上下镜像）、或双轴翻转（180 度旋转）。干扰物体的颜色或尺寸与所有模板都无法匹配。生成约束：每个部分精灵与其匹配模板的配对和朝向是唯一确定的；同一模板在工作区中最多出现两次且朝向不同。

**规则**：
1. 提取目录区中的所有模板（灰(5)背景上的 4-连通非灰非黑色区域），记录每个模板的两种前景色为 colorA（像素数较多者）和 colorB（像素数较少者；若相等则取颜色编号较小者为 colorA）。
2. 对工作区中每个非黑 4-连通物体，尝试与每个模板在四种朝向下进行子区域匹配：
   a. 将模板分别做原始、水平翻转、垂直翻转、双轴翻转，得到四个变体。
   b. 对每个变体，滑动窗口检查工作区物体的像素是否与变体的某个对齐子区域完全吻合。
   c. 若找到唯一匹配，记录匹配的模板、朝向和对齐偏移。若无匹配，标记为干扰项。
3. 对每个匹配成功的部分精灵，确定颜色映射：
   a. 原始朝向（无翻转）：保持原色（colorA→colorA, colorB→colorB）。
   b. 仅水平翻转：互换两色（colorA→colorB, colorB→colorA）。
   c. 仅垂直翻转：互换两色（colorA→colorB, colorB→colorA）。
   d. 双轴翻转：保持原色。
4. 将匹配模板按检测到的朝向变换后，应用颜色映射，以对齐偏移将完整模板印到工作区，覆盖已有像素。模板变体中灰(5)背景像素视为透明不绘制。
5. 干扰物体保持不变。
6. 处理顺序：按工作区物体边界框左上角从左到右、从上到下。

**关键洞察**：翻转检测不仅是几何对齐的手段，更是色彩变换规则的隐式编码——单轴翻转触发互换而双轴翻转（等价于旋转 180 度）不触发，这种对称性质与颜色操作的绑定必须通过对比多个示例才能归纳。

## 新题 6：逐步消耗标记驱动精灵累进缩放

**组合逻辑**：[逐步移动 + 消除 + 最近标记优先](已有) → [像素放大](创新：每次消耗后执行一次增量缩放) + [边缘像素复制](创新：缩放方式为外缘像素向外复制一圈)

**来源原语**：逐步移动、消除、最近标记优先、朝向决定搜索线 ← 5545f144；像素放大、边缘像素复制、前景掩码 ← 8719f442

**依赖链**：最近标记优先确定下一个消耗目标 → 精灵移动到该标记位置并消耗它 → 每次消耗触发一次边缘像素复制（精灵边界框外扩一圈，边缘像素向外复制） → 放大后的精灵形状改变了后续"最近标记"的距离计算（距离以边界框边缘到标记的曼哈顿距离为准） → 重复直到所有标记被消耗。删除移动则精灵位置固定无法接触标记；删除缩放则消耗无累积效应；删除距离重算则缩放无后续影响。

精灵逐步移向最近标记并消耗，每次消耗后精灵向外扩展一圈边缘复制像素，放大的体积影响后续距离判断。

**输入结构**：约 20x20 的黑(0)背景网格。一个蓝(1)小精灵（3~5 像素的 4-连通单色图形）位于网格某处。散布 3~5 个红(2)单像素标记，各标记之间及标记与精灵之间的最小曼哈顿距离 >= 4。生成约束：在精灵按照规则逐步移动和扩展的过程中，精灵的边界框始终不会覆盖到尚未被消耗的标记像素（即扩展不会意外吞噬远处的标记）；每一步的最近标记唯一（无平局）。

**规则**：
1. 初始状态：精灵为蓝(1)像素集合 S，计算其边界框 B。
2. 对所有剩余红(2)标记，计算每个标记到当前边界框 B 的最小曼哈顿距离（标记像素到 B 内最近边缘像素的距离）。选择距离最小的标记 M。
3. 移动精灵：计算偏移量 (dr, dc) 使精灵的边界框中心移动到标记 M 的位置。将 S 中每个像素 (r,c) 平移到 (r+dr, c+dc)。清除原位置的蓝(1)像素（置为黑(0)），在新位置绘制蓝(1)。消耗标记 M（将其置为黑(0)并从标记列表中移除）。
4. 边缘扩展：计算移动后精灵的新边界框 B'。将 B' 向上、下、左、右各扩展 1 像素得到 B''。对 B'' 中每个不属于 B' 的边缘像素 (r', c')：找到 B' 边界上距 (r', c') 最近的精灵像素（若有多个取行号最小者，再取列号最小者），将 (r', c') 涂为该精灵像素的颜色蓝(1)，并将 (r', c') 加入 S。若 B'' 超出网格边界，忽略越界像素。
5. 重复步骤 2~4 直到所有标记被消耗。
6. 输出最终网格，只保留最终位置的蓝(1)精灵和黑(0)背景。

**关键洞察**：精灵的移动路径依赖于其当前大小（大小影响距离计算），而大小又由历史消耗次数决定——这形成一个"历史依赖的贪心序列"，仅看最终状态无法反推中间过程，必须模拟每一步。

**关键洞察**：被行列乘积准则"淘汰"的颜色并非废弃信息——它们的统计频率编码了提取结果的装饰结构，形成"内容来自合格者，形式来自淘汰者"的双重利用关系。

**依赖链**：射线从边缘推进遇到墙段 → 必须测量墙段长度并判断奇偶 → 奇数长度墙段：射线在该墙段的所有开口处分支 → 偶数长度墙段：射线仅在距命中点最近的一个开口处分支（若两侧等距取上方或左方的） → 不同分支策略导致完全不同的可达区域。删除奇偶判断则分支策略不确定；删除墙段计数则无奇偶信息；删除射线则计数和分支策略无用武之地。

射线从边缘向内推进，遇到墙段时根据墙段像素长度的奇偶性选择不同的分支策略——奇数长度全开口分支，偶数长度仅最近开口分支。

**输入结构**：约 18x18 的黑(0)背景网格。网格某一边缘上恰好有一个橙(7)单像素边缘标记。网格内部有 3~5 条蓝(1)墙段（每条墙段为水平或垂直的连续蓝色像素序列，长度 2~7 不等，既有奇数长度也有偶数长度），墙段之间互不接触（任意两条墙段的像素之间曼哈顿距离 >= 2）。每条墙段的两端之外至少有一侧存在黑(0)开口（即墙段不紧贴网格边界，墙段端点的延伸方向有空间）。生成约束：从边缘标记出发的射线至少能遇到两条不同长度奇偶性的墙段；射线路径不会在第一条墙段前就到达对面边界。

**规则**：
1. 从橙(7)边缘标记出发，沿垂直于该边缘的方向（上边缘→向下，下边缘→向上，左边缘→向右，右边缘→向左）发射射线。
2. 射线沿直线前进，将经过的黑(0)像素涂为橙(7)。
3. 当射线的下一个像素是蓝(1)墙段时：
   a. 确定被命中的墙段：沿垂直于射线方向找到包含该蓝色像素的最大连续蓝(1)序列，记其长度为 L。
   b. 将射线命中点处的蓝(1)像素涂为橙(7)（射线穿过命中点）。
   c. 找出该墙段两端之外的相邻像素位置（沿墙段方向各延伸一格）。若该位置在网格内且为黑(0)，则标记为"开口"。
   d. 若 L 为奇数：从所有开口位置各发射一条新的分支射线（方向与原射线相同，即继续向内推进）。
   e. 若 L 为偶数：仅从距射线命中点最近的一个开口发射分支射线。若两侧开口距命中点等距，选择行号较小的（水平墙段）或列号较小的（垂直墙段）一侧。若某侧无开口（墙段该端紧贴边界），则只用另一侧。
4. 每条分支射线继续向前推进，重复步骤 2-3，直到到达网格边界或遇到无开口的墙段阻断。
5. 射线到达网格边界时停止（边界像素也涂为橙(7)）。
6. 所有未被射线经过的蓝(1)墙段像素保持不变。

**关键洞察**：外观相同的墙段间隙可能产生完全不同的射线行为——区别不在间隙本身，而在其所属墙段的总长度奇偶性，这是一个需要测量而非直接观察的隐藏属性。
