## 新题 1：迷宫路径距离决定精灵排列顺序

**组合逻辑**：[洪泛填充](创新：不用于着色而用于计算BFS距离) → [面积排序](创新：排序键由迷宫拓扑距离替代面积) → [基线对齐排列](已有) → [擦除](已有)

**来源原语**：洪泛填充/路径连通(b782dc8a)、排序/面积排序(4df5b0ae, beb8660c)、精灵体(4df5b0ae, e41c6fd3)、迷宫走廊(b782dc8a)、基线对齐排列(4df5b0ae)

**依赖链**：迷宫的拓扑结构决定 BFS 距离 → BFS 距离作为排序键替代几何属性 → 排序结果决定精灵体的输出排列位置。删除迷宫则距离无法计算；删除排序则布局无法确定；删除精灵提取则无输出内容。

从迷宫入口出发计算到各精灵体的路径距离，按距离远近排列精灵体。

**输入结构**：约 18x18 的网格，黑(0)为背景。青(8)像素构成迷宫壁，形成单像素宽的走廊网络（走廊为黑(0)像素），走廊保证连通且无环路。3~5 个单色 4-连通精灵体（每个 3~6 像素，颜色各不相同，从红(2)、绿(3)、蓝(1)、橙(7)、品红(6)中选取）分别嵌在不同的走廊死端处（精灵体的某一像素与走廊黑像素 4-邻接）。一个栗(9)像素位于网格某一边缘的走廊入口处，作为 BFS 起点。生成约束：从栗(9)起点到各精灵体的最短路径长度互不相同；精灵体互不接触。

**规则**：
1. 从栗(9)起点出发，沿黑(0)走廊像素进行 4-连通 BFS 扩展。每个走廊像素记录其 BFS 距离值。青(8)壁和精灵体像素不可通行。
2. 对每个精灵体，取其所有像素中与走廊黑像素 4-邻接的像素，找到这些邻接走廊像素中 BFS 距离最小的值，作为该精灵体的距离键。
3. 按距离键从小到大排序所有精灵体。
4. 提取每个精灵体的边界框（框内非精灵体像素视为透明）。
5. 输出网格高度等于最高精灵体的边界框高度，宽度等于所有边界框宽度之和加上间隔列数（相邻精灵体之间 1 列黑(0)间隔）。按排序结果从左到右放置精灵体，底部对齐。
6. 栗(9)起点、迷宫壁、走廊均不出现在输出中。

**关键洞察**：精灵体的排列顺序既不由其空间坐标决定，也不由其面积决定，而由迷宫的拓扑路径长度决定——两个在网格上相邻的精灵体，在迷宫路径中可能相距很远。

## 新题 2：格子色带编码条纹传播的颜色循环

**组合逻辑**：[压缩](已有：格子结构压缩为粗网格) → [颜色循环](创新：循环序列从粗网格中提取而非预设) → [条纹传播](创新：条纹颜色由外部数据驱动)

**来源原语**：压缩/格子结构/色带分组/行列交叉(80214e03)、条纹传播/边界线段/颜色循环(221dfab4)、前景色集分带(80214e03)、条纹范围差异(221dfab4)

**依赖链**：格子结构的色带压缩产出粗网格 → 粗网格底行的颜色序列成为条纹传播的循环调色板 → 边界线段启动条纹传播时使用该调色板。删除格子压缩则调色板未知；删除条纹传播则下半区无输出；删除边界线段则传播无起点。

将格子结构压缩为粗网格，取其底行颜色序列作为调色板，从边界线段向上传播条纹。

**输入结构**：约 20x20 的网格，灰(5)为背景。上半区（约占 60%高度）包含一个被背景包围的矩形格子结构：青(8)分隔线将内部划分为规则的色带交叉区块，每个区块内为单一前景色（从红(2)、蓝(1)、绿(3)、橙(7)、品红(6)中选取），区块可含背景色空洞。格子至少 3 行 3 列色带。下半区全为灰(5)背景，底部边缘有一段黄(4)线段（宽 3~5 像素）。生成约束：粗网格底行至少包含 2 种不同颜色；上下半区之间至少隔 2 行背景。

**规则**：
1. 按参考题 80214e03 的方法，将格子结构中的行和列按前景色集分为连续色带，每个行带/列带交叉区域替换为其唯一前景色，得到粗网格。
2. 读取粗网格最底行的颜色，从左到右形成颜色序列 C1, C2, ..., Ck。
3. 从黄(4)边界线段出发，向上逐行传播条纹。条纹宽度为 1 行，条纹之间有 1 行灰(5)间隔。条纹颜色按序列 C1, C2, ..., Ck 循环（到达 Ck 后回到 C1）。
4. 每条条纹仅覆盖黄(4)线段的列跨度范围内的像素。
5. 条纹传播在到达上半区格子结构的底边时停止（不覆盖格子结构）。
6. 上半区格子结构保持原样输出。

**关键洞察**：格子结构不仅是独立的视觉元素，它压缩后的底行颜色直接编码了条纹传播的调色板——必须先完成格子解读才能确定条纹颜色。

## 新题 3：框架同色精灵计数驱动地形列重涂

**组合逻辑**：[计数/同色匹配](已有) → [列高度极值](创新：不再标记唯一极值，而用计数结果选取多个极值列) → [重涂色](创新：重涂对象从像素变为整列地形上方区域)

**来源原语**：计数/空心框架/图案精灵体/同色匹配/计数映射点数(8f215267)、地形轮廓/列高度极值(e45ef808)、重涂色(c9f8e694, e45ef808)、擦除(98cf29f8)

**依赖链**：同色精灵计数给出每种颜色的数量 → 数量值选取地形中对应数目的最深列 → 被选列的地形上方背景被重涂为框架颜色。删除计数则不知道选几列；删除地形深度分析则不知道选哪些列；删除重涂则无可见输出变化。

统计每个框架颜色对应的精灵数量，用该数量选取地形中最深的若干列并涂上框架颜色。

**输入结构**：约 20x15 的网格，黑(0)为背景。网格分三个纵向区域：(a) 顶部区域（约 4 行）散布 3~8 个小型单色 4-连通精灵体（每个 2~4 像素），颜色从蓝(1)、绿(3)、橙(7)中选取，可有多个同色精灵体。(b) 中间区域（约 4 行）包含 2~3 个空心矩形框架，每个框架颜色从蓝(1)、绿(3)、橙(7)中选取且与至少一个精灵体颜色匹配，框架之间不重叠，框架内部为黑(0)。(c) 底部区域（约 7 行）为灰(5)地形轮廓：每列由若干黑(0)背景像素后接连续灰(5)像素直到底部，各列地形起始行不同形成起伏轮廓。生成约束：每种框架颜色对应的精灵计数互不相同且均不超过地形总列数的一半；各列地形深度（地形起始行以上的黑(0)像素行数）互不相同。

**规则**：
1. 对每种框架颜色 C，统计顶部区域中颜色为 C 的精灵体数量，记为 N(C)。
2. 计算地形轮廓中每列的"深度"（该列地形起始行以上的黑(0)像素行数）。
3. 将所有列按深度从大到小排序。对每种框架颜色 C，选取排名前 N(C) 的深度最大的列。
4. 将被选列中地形起始行以上的所有黑(0)像素重涂为颜色 C。
5. 若两种颜色的选取列有冲突（同一列被多种颜色选取），以计数 N 较大的颜色优先。
6. 擦除顶部区域的所有精灵体。框架保持原样。地形灰(5)像素不变。

**关键洞察**：精灵体的数量不是直接变成输出图案，而是间接控制"选取几列地形进行涂色"——计数结果经过地形深度排序的中介才映射到空间位置。

## 新题 4：精灵面积排名重写行控制色驱动占位符重涂

**组合逻辑**：[计数](创新：计数对象从精灵实例数变为单个精灵的像素面积) → [排序](已有) → [行首色决定填色](创新：控制色不是预设而是由排序结果动态指派) → [重涂色](已有)

**来源原语**：计数/前景像素(d631b094)、排序/面积排序(4df5b0ae, 8abad3cf)、重涂色/占位像素/控制像素/行首色决定填色(c9f8e694)、擦除(98cf29f8)

**依赖链**：精灵面积测量 → 面积排名建立排序 → 排序名次与行位置配对 → 配对结果替换控制像素颜色 → 新控制色决定占位符最终颜色。任何一步被删除，控制像素的颜色指派都无法确定，占位符颜色也随之失效。

测量散落精灵体的面积并排名，用排名顺序重新指派各行的控制色，再据此重涂占位符。

**输入结构**：约 15x15 的网格，黑(0)为背景。第 0 列的若干行各有一个控制像素（颜色各不相同，从红(2)、蓝(1)、绿(3)、橙(7)中选取），这些行散布着灰(5)占位像素形成的连通形状（每个形状跨 1~3 行，同一行内可有多个灰(5)像素，形状在行间通过 4-连通相连）。网格右半区散布着与控制像素同色的单色 4-连通精灵体（每种颜色恰好 1 个精灵体，每个 3~8 像素），精灵体之间互不接触，也不接触占位像素或控制像素。生成约束：精灵体数量等于控制像素行的数量；各精灵体面积互不相同；控制像素行从上到下排列。

**规则**：
1. 测量每个精灵体的像素面积。
2. 按面积从小到大排列所有精灵体，建立排名序列 S1, S2, ..., Sn（S1 面积最小）。
3. 将控制像素行按从上到下编号为第 1 行、第 2 行、...、第 n 行。
4. 将第 k 行的控制像素颜色替换为排名第 k 的精灵体 Sk 的颜色（即面积最小的精灵体颜色指派给最上方的控制行，依此类推）。
5. 对每个含控制像素的行，将该行所有灰(5)占位像素重涂为该行当前控制像素的颜色。
6. 擦除右半区所有精灵体。

**关键洞察**：原始控制像素的颜色是"假线索"——它们会被精灵面积排名的结果完全覆盖；真正决定占位符颜色的是精灵体之间的面积大小关系。

## 新题 5：地形深度奇偶性决定对齐精灵是否镜像

**组合逻辑**：[对齐/对齐到锚点](已有) → [列高度极值](创新：不标记极值而计算各列深度的奇偶性) → [镜像](创新：镜像不是全局操作而是按条件逐个精灵体选择性执行)

**来源原语**：对齐/精灵体/锚点像素/共享归一掩码/对齐到锚点(e41c6fd3)、镜像(80214e03, 9f236235)、地形轮廓/列高度极值(e45ef808)

**依赖链**：精灵体垂直对齐到锚点 → 对齐后确定每个精灵体的中心列 → 中心列处的地形深度奇偶性决定是否镜像该精灵体。删除对齐则精灵体列位置未规范化；删除地形分析则镜像条件不可知；删除选择性镜像则输出形态错误。该题不是线性流水线——对齐和地形分析可并行执行，结果在镜像决策处汇合。

将多个同形精灵体垂直对齐到青色锚点，再根据各精灵体中心列处地形深度的奇偶性决定是否水平镜像。

**输入结构**：约 18x18 的网格，黑(0)为背景。上半区（约 12 行）包含 4~5 个单色 4-连通精灵体（每个 4~8 像素，颜色各不相同），所有精灵体共享相同的归一化掩码（即平移到原点后形状相同），各精灵体分散在不同列且互不重叠。其中一个精灵体为青(8)色，作为垂直对齐锚点。下半区（约 6 行）为灰(5)地形轮廓：每列有若干黑(0)像素后接连续灰(5)像素到底，各列地形起始行不同。生成约束：精灵体的归一化掩码左右不对称（否则镜像无法观测）；各精灵体中心列处的地形深度涵盖奇数和偶数两种情况；精灵体之间水平间隔至少 2 列。

**规则**：
1. 找到青(8)精灵体的顶行位置 R_anchor。
2. 对每个精灵体（含青(8)），保持其原始左列不变，将其顶行平移到 R_anchor（垂直对齐）。
3. 计算每个精灵体边界框的水平中心列 C_mid（取边界框左列与右列的算术平均值，向下取整）。
4. 在地形轮廓中，读取 C_mid 列的深度值 D（该列地形起始行以上的黑(0)像素行数）。
5. 若 D 为奇数，将该精灵体水平镜像（以其边界框水平中心为轴翻转）。若 D 为偶数，保持原样。
6. 青(8)精灵体始终不镜像，无论其列处地形深度如何。
7. 地形轮廓在输出中保持不变。

**关键洞察**：地形轮廓不是装饰背景——它在每个精灵体的中心列处编码了一个二元信号（奇/偶），静默地控制着该精灵体是否翻转；必须对比多个示例才能发现这一关联。

## 新题 6：十字射线划分区域后以边界主色洪泛填充

**组合逻辑**：[射线延伸](已有) → [交叉点特殊着色](已有) → [洪泛填充](创新：填充色不由种子决定而由围成区域的边界颜色组成决定) → [碰撞阻挡](创新：墙壁阻断射线传播而非物体滑动)

**来源原语**：射线延伸/孤立像素/十字图案/交叉点特殊着色(23581191)、洪泛填充/路径连通(b782dc8a)、碰撞阻挡(98cf29f8)

**依赖链**：种子像素发出射线 → 射线被墙壁截断形成有限线段 → 线段与墙壁共同划分空间为封闭区域 → 每个封闭区域的边界颜色组成决定填充色 → 交叉点标记为特殊色。这是一个"结构解构"型题目：输入看似简单（两个像素和几段墙），但输出需要理解射线、墙壁、区域划分三者的交互。

从两个种子像素发射十字射线（遇墙停止），射线和墙壁将网格划分为区域，每个封闭区域按边界主色填充。

**输入结构**：约 15x15 的网格，黑(0)为背景。两个孤立前景像素分别为橙(7)和蓝(1)，不在同一行或同一列。3~5 段青(8)墙壁线段散布在网格中（每段为水平或垂直的连续青(8)像素，长度 3~7，不与种子像素同行同列位置重叠但可能截断射线路径）。生成约束：两个种子像素的射线至少各被一段墙壁截断；射线和墙壁共同形成的线段网络至少划分出 3 个完全封闭区域（四面均有射线或墙壁或网格边缘围合）；两个种子像素不被同一封闭区域包含。

**规则**：
1. 从橙(7)像素出发，沿其所在行向左右、所在列向上下各发射一条射线。射线沿途将黑(0)像素涂为橙(7)。射线遇到青(8)墙壁像素或网格边缘时停止（不覆盖墙壁像素，停在墙壁前一格）。
2. 从蓝(1)像素出发，以相同方式发射四条蓝(1)射线。蓝射线遇到青(8)墙壁、橙(7)射线像素或网格边缘时停止。
3. 在橙(7)射线与蓝(1)射线交叉的位置（某像素同时处于一条橙射线和一条蓝射线的延伸路径上），将该像素标记为红(2)。
4. 射线和墙壁将网格划分为若干区域。对每个完全封闭的区域（由射线像素、墙壁像素和网格边缘围合，内部全为黑(0)），统计其边界上橙(7)像素数和蓝(1)像素数（不含红(2)和青(8)）。
5. 若边界上橙(7)像素多于蓝(1)像素，用橙(7)填充该区域。反之用蓝(1)填充。相等时用红(2)填充。
6. 不完全封闭的区域（与网格边缘相邻且无射线/墙壁围合的区域）不填充，保持黑(0)。

**关键洞察**：射线不只是视觉线条而是空间划分的边界；每个被围合区域的填充色取决于围合它的两种射线的数量对比——这一规则需要对比多个示例中不同区域的填充结果才能归纳。

## 新题 7：瓦片降噪后的色频编码线段排序键

**组合逻辑**：[降噪](已有) → [压缩](已有) → [计数](创新：计数对象从精灵体变为粗网格中的同色像素频率) → [排序](创新：排序键不是线段自身属性而是外部色频查表) → [按长度递增堆叠](创新：堆叠顺序由色频替代长度)

**来源原语**：降噪/瓦片/噪声像素/忽略标记取主色/网格分块(5614dbcf)、压缩(5614dbcf, 80214e03)、计数(8f215267, d631b094)、排序/线段/条带/按长度递增堆叠(beb8660c)

**依赖链**：瓦片降噪 → 压缩产出粗网格 → 粗网格中各色频率计算 → 色频作为线段的排序键（通过颜色匹配关联） → 排序后堆叠输出。删除降噪则粗网格颜色可能被灰噪声干扰导致频率错误；删除压缩则无法统计色频；删除色频计算则排序键未知；排序和堆叠缺一则输出布局无法确定。

将瓦片网格去噪压缩后统计各色出现频率，用频率作为排序键重排下方的彩色线段并堆叠。

**输入结构**：约 21x15 的网格，黑(0)为背景。上半区（约 9 行 = 3 块行 x 3 像素）包含一个由 3x3 瓦片组成的矩阵（至少 3 行 4 列瓦片）。每个瓦片由一种主色填充（从蓝(1)、红(2)、绿(3)、橙(7)中选取，至少 8/9 像素为主色），部分瓦片包含 1~2 个灰(5)噪声像素。纯背景瓦片（全为黑(0)或仅含灰(5)和黑(0)）也存在。下半区（约 6 行）有一条栗(9)全宽条带在最底行，其上方散布 2~4 条单像素厚的水平彩色线段（各线段颜色从蓝(1)、红(2)、绿(3)、橙(7)中选取，颜色各不相同，长度各不相同）。生成约束：线段颜色集合是瓦片主色集合的子集；各颜色在粗网格中的出现频率互不相同。

**规则**：
1. 对上半区的瓦片矩阵：将每个 3x3 瓦片替换为其非灰(5)、非黑(0)的主色（仅含灰和黑的瓦片替换为黑(0)），得到粗网格。
2. 在粗网格中统计每种非黑(0)颜色出现的像素数，得到色频映射 F(C)。
3. 对下半区的每条水平线段，通过颜色匹配查表获取其排序键 F(线段颜色)。
4. 按排序键从小到大排列线段。排序键相同时（生成约束保证不会发生），按线段长度从短到长排列。
5. 清除下半区线段的原始位置。将排序后的线段从上到下（键值最小的在最上方）逐行放置在栗(9)条带正上方的连续行中，每条线段右对齐到网格右边缘。
6. 上半区瓦片矩阵在输出中保持原样（不压缩）。栗(9)条带不变。

**关键洞察**：线段的排列顺序不由其自身长度或位置决定，而由上半区瓦片网格中同色瓦片的出现频率决定——瓦片区域是一张隐藏的排序查找表。

## 新题 8：对称恢复遮挡区后在标记点印章复制

**组合逻辑**：[补全/对称恢复遮挡](已有) → [裁剪](已有) → [印章覆盖/精灵对准标记复制](创新：被印章的精灵内容来自运行时恢复而非输入中的现成精灵) → [碰撞阻挡](创新：印章重叠时的冲突解决依据到原遮挡区的距离)

**来源原语**：补全/遮挡矩形/平移对称图案/对称轨道/对称恢复遮挡(f9012d9b)、裁剪(80214e03)、印章覆盖/标记像素/中心对齐/精灵对准标记复制(88a10436)、碰撞阻挡(98cf29f8)

**依赖链**：平移对称检测 → 遮挡区恢复 → 恢复内容裁剪为精灵体 → 精灵体在标记点处印章 → 重叠区域按距离判定优先级。删除对称恢复则精灵内容未知；删除裁剪则精灵范围不确定；删除印章则标记点无法响应；删除冲突规则则重叠区域颜色歧义。

先用平移对称性修复被遮挡的图案区域，再将修复后的内容作为精灵体在各标记点处复制粘贴。

**输入结构**：约 16x16 的网格。大部分区域填充着一个平移周期性的彩色图案（至少 3 种非黑颜色，周期不超过 5x5），图案内无真正的黑(0)像素。图案中有一个矩形区域（3x3 至 5x5）被黑(0)像素完全遮挡。在图案区域之外的背景（灰(5)）上，散布 2~4 个栗(9)标记像素。生成约束：从栗(9)标记到遮挡矩形中心的曼哈顿距离互不相同；标记像素位置保证以标记为中心放置恢复后的精灵体时不会超出网格边界；不同标记处的印章区域可能重叠。

**规则**：
1. 检测图案的平移对称性（忽略黑(0)遮挡像素）。
2. 利用对称轨道，从非遮挡区域取等价像素填充每个黑(0)遮挡像素，恢复遮挡区的真实内容。
3. 裁剪恢复后的遮挡矩形区域，作为精灵体 P。
4. 对每个栗(9)标记像素：以标记为中心，粘贴精灵体 P（P 的中心对齐到标记位置）。粘贴时，P 中的每个像素覆盖目标位置的原有像素。
5. 若两个标记处的印章区域重叠，重叠像素归属于距原遮挡矩形中心曼哈顿距离更近的那个标记的印章。
6. 原图案区域（包括已恢复的遮挡区）保持不变。栗(9)标记像素被精灵体覆盖。

**关键洞察**：遮挡区既是需要修复的缺陷，又是需要复制的模板——在修复之前，印章的内容是完全未知的；冲突解决规则巧妙地将优先级系于标记与缺陷原点的距离。

## 新题 9：十字标记臂色选取滑动体并确定碰撞优先级

**组合逻辑**：[图案识别/十字标记](已有) → [同色匹配](创新：匹配对象从精灵-框架变为标记臂色-矩形体) → [滑动/沿杆滑至锚定物](创新：滑动的选择性由标记匹配决定) → [碰撞阻挡](创新：碰撞优先级由标记重复色规则决定) → [擦除](已有)

**来源原语**：图案识别/十字标记/中心与臂颜色/重复色为答案/忽略干扰项(642d658d)、滑动/矩形体/连接杆/碰撞阻挡/沿杆滑至锚定物(98cf29f8)、同色匹配(8f215267)、擦除(98cf29f8)

**依赖链**：识别十字标记并提取臂色 → 臂色匹配矩形体决定哪些体需要滑动 → 重复臂色规则确定优先滑动体 → 优先体先滑动，其终止位置成为后续体的障碍 → 连接杆指示滑动方向后被擦除。这是一个"隐式编码"型题目：十字标记的几何结构编码了滑动选择和碰撞优先级两条信息。

识别黄心十字标记的臂色，匹配对应的矩形体进行滑动，重复出现的臂色对应的矩形体优先移动。

**输入结构**：约 18x18 的网格，黑(0)为背景。网格中散布 3~5 个不同颜色的矩形体（每个为 2x2 至 3x4 的实心单色矩形，颜色从蓝(1)、红(2)、绿(3)、橙(7)、品红(6)中选取）。每个矩形体有一条单像素宽的同色连接杆从矩形体某一侧向一个基数方向延伸 2~5 格。网格中另有 2~4 个黄(4)中心十字标记（每个为黄(4)中心像素加四个同色正交邻接臂像素），各标记的臂色为上述矩形体颜色之一。生成约束：恰好有一种臂色出现在两个或更多标记上（重复色），其余臂色各出现一次；每种出现在标记臂上的颜色都对应一个矩形体；至少一个矩形体的颜色不出现在任何标记臂上；连接杆方向上无其他矩形体直接阻挡（但优先体滑动后可能阻挡后续体）。

**规则**：
1. 找到所有黄(4)中心的十字标记，提取每个标记的臂色（四臂颜色相同）。
2. 统计各臂色的出现次数。恰好出现 2 次以上的臂色为"优先色"。
3. 颜色与某标记臂色匹配的矩形体标记为"活跃体"。颜色不匹配任何标记臂色的矩形体保持静止。
4. 优先色对应的活跃体首先滑动：沿其连接杆方向移动，移动距离等于连接杆长度，直到矩形体到达网格边缘或碰到另一个矩形体（以先到者为准）。连接杆在滑动后擦除。
5. 其余活跃体随后滑动：规则同上，但此时优先体的终止位置已成为新障碍。多个非优先活跃体之间按其边界框左上角行优先、列其次的顺序依次滑动。
6. 十字标记在输出中保持不变。静止矩形体保持不变。

**关键洞察**：十字标记不是装饰而是操作指令——臂色选择了哪些矩形体参与滑动，而同一臂色在多个标记上的重复出现编码了碰撞优先级；不识别标记就无法确定移动顺序。

## 新题 10：对角折叠产出洪泛种子配置驱动走廊交替着色

**组合逻辑**：[折叠/对角到边映射](已有) → [洪泛填充](创新：种子位置和颜色由折叠结果编码而非输入直接给出) → [路径奇偶交替涂色](已有) → [网格分块](创新：将折叠产物的3x3网格映射到大网格的分区位置)

**来源原语**：折叠/对角线像素/对角到边映射(ca8de6ea)、洪泛填充/迷宫走廊/种子像素/路径连通/路径奇偶交替涂色(b782dc8a)、网格分块(5614dbcf)

**依赖链**：5x5对角X图案折叠为3x3网格 → 3x3网格的非黑像素确定种子颜色和位置 → 3x3位置映射到走廊网格的对应分区中心 → 从各种子出发按BFS奇偶交替颜色填充走廊。删除折叠则种子配置不可知；删除位置映射则种子放置位置不确定；删除奇偶填充则走廊无法着色。

将角落的5x5对角X图案折叠为3x3种子配置图，据此在走廊网格中定位种子并以奇偶交替色洪泛填充。

**输入结构**：约 18x18 的网格，黑(0)为背景。左上角嵌入一个 5x5 的子网格，其两条对角线上的 9 个像素各有颜色（从蓝(1)、红(2)、绿(3)、橙(7)中选取，中心像素和各臂可不同色），非对角线位置为黑(0)。5x5 子网格与网格其余部分之间有 1 列和 1 行灰(5)分隔线。分隔线之外的区域（约 12x12）为走廊网格：青(8)壁像素形成规则的 3x3 分块结构（将 12x12 区域分为 3x3 个大约 4x4 的分区），每个分区内部为黑(0)走廊，分区之间通过 1 像素宽的走廊开口连通。生成约束：折叠后的 3x3 网格中非黑像素至少 2 个且至多 4 个；走廊网格中所有分区通过开口全连通。

**规则**：
1. 将左上角 5x5 X 图案按参考题 ca8de6ea 的折叠规则压缩为 3x3 网格：中心不变；西北对角臂 → 上边从左到中心；东北臂 → 右边从上到中心；西南臂 → 左边从中心到下；东南臂 → 下边从中心到右。
2. 3x3 网格中每个非黑(0)像素成为一个种子。其在 3x3 中的位置 (r, c)（r, c 从 0 开始）映射到走廊网格中第 r 个分区行、第 c 个分区列的中心像素。
3. 将种子像素放置到走廊网格的对应位置。
4. 从每个种子出发，沿黑(0)走廊像素进行 4-连通 BFS。BFS 距离为偶数的像素涂为种子自身颜色，距离为奇数的像素涂为黄(4)。
5. 若两个种子的 BFS 扩展在同一走廊像素相遇，该像素归属 BFS 距离较短的种子。距离相等时，该像素涂为灰(5)。
6. 青(8)壁像素不变。5x5 X 图案区域和灰(5)分隔线在输出中保持不变。

**关键洞察**：5x5 X 图案是走廊填充的"加密配置文件"——必须先正确折叠才能知道哪些分区有种子、种子是什么颜色；折叠结果直接决定走廊的颜色分布。
