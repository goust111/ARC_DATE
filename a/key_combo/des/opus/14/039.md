## 新题 1：模板形状门控的重力穿透

**组合逻辑**：[形状匹配](已有) + [重力下落](已有) + [重涂色](已有) — 创新：模板掩码替代宽度作为穿透判据，L 框架从"视觉选择器"变为"物理过滤器"

**来源原语**：
- 形状匹配、掩码相同、模板、框架、前景对象、模板选同形重涂 ← 参考题 63613498
- 重力下落、分隔行、穿透与停靠、宽度决定行为 ← 参考题 84ba50d3
- 重涂色 ← 参考题 63613498 / a61f2674

**依赖链**：L 框架内的模板提供判据 → 重力下落将精灵推向分隔行 → 掩码匹配决定穿透/停靠 → 穿透精灵被重涂为模板色。删除模板则无法区分精灵行为；删除重力则精灵不移动；删除分隔行则无穿透/停靠的物理边界。

一句话总结：精灵向下坠落至分隔行，形状与 L 框架内模板匹配的穿透到底并变色，不匹配的停在分隔行上方。

**输入结构**：约 16x18 黑(0)背景网格。中部有一条横贯全宽的灰(5)水平分隔行（单行）。分隔行上方散布 4-6 个小型单色精灵（各为不同非黑非灰颜色，4-连通，3-7 像素，形状各异，彼此不重叠且列范围互不交叉）。分隔行下方左侧有一个灰(5) L 型框架（竖直腿在右、水平腿在底），框架内部区域包含一个用某种非黑非灰颜色绘制的小型模板形状（3-6 像素，4-连通）。上方恰好有一个精灵与模板具有相同的归一化二值掩码（形状相同但颜色不同），其余精灵形状各异且均不匹配模板。生成约束：所有精灵的列范围（bounding box 水平跨度）互不重叠，保证下落路径无歧义；不同示例使用不同的模板形状，使得求解者无法记忆特定外形。

**规则**：
1. 提取 L 型框架内模板的归一化二值掩码 M（将模板裁剪到最小 bounding box，转为 0/1 掩码）。
2. 对分隔行上方的每个精灵，将其也归一化为最小 bounding box 的二值掩码。
3. 每个精灵保持列位置不变，向下移动（重力下落）直至其 bounding box 底边紧贴分隔行上方。
4. 判断该精灵的归一化掩码是否与 M 完全相同：
   - 相同：精灵穿透分隔行，继续下落直至 bounding box 底边抵达网格最底行。同时将精灵所有像素重涂为模板的颜色。
   - 不同：精灵停在分隔行正上方（bounding box 底行 = 分隔行行号 - 1），保持原始颜色不变。
5. L 框架及其内部的模板在输出中保持不变。
6. 分隔行自身保持不变。穿透精灵从分隔行"通过"，分隔行像素不受影响；若穿透精灵的最终位置与分隔行行重叠，精灵像素覆盖分隔行像素。

**关键洞察**：L 框架不仅是视觉标注——它定义了一把"形状钥匙"，只有掩码匹配钥匙的精灵才能穿透物理屏障。形状相似性决定物理行为，这是参考题 63613498（匹配 → 重涂）和 84ba50d3（宽度 → 穿透）中都不存在的逻辑关系。

## 新题 2：质心导向重力与极值距离筛选

**组合逻辑**：[重力下落](创新：方向由质心偏移决定) + [排序](已有) + [重涂色 + 擦除](已有) — 创新：每个精灵有独立的重力方向，由其与吸引子的几何关系决定；落定后按距离执行极值筛选

**来源原语**：
- 重力下落、穿透与停靠 ← 参考题 84ba50d3
- 质心偏移定位 ← 参考题 4e45f183
- 排序、重涂色、擦除、保留极值高度分色 ← 参考题 a61f2674
- 距离 ← 参考题 b8cdaf2b

**依赖链**：吸引子位置 + 精灵质心 → 计算偏移方向 → 确定每个精灵的重力向量 → 精灵沿各自方向下落并停靠 → 计算落定后距吸引子的距离 → 按距离排序 → 仅保留最近和最远两个精灵并分别重涂色。删除方向计算则重力无定义；删除重力则位置不变导致距离排序结果不同；删除极值筛选则输出包含所有精灵。

一句话总结：精灵各自朝向吸引子方向坠落至网格边缘，落定后仅保留离吸引子最近（蓝）和最远（红）的两个精灵。

**输入结构**：约 15x15 黑(0)背景网格。网格中某个非中心、非边缘位置有一个栗(9)单像素标记作为"吸引子"。网格上散布 4-6 个小型精灵（各为不同非黑非栗颜色，4-连通，3-5 像素，形状各异），与吸引子互不相邻且不重叠。生成约束：(a) 每个精灵沿其确定的重力方向下落时，路径上不会与其他精灵的最终停靠位置冲突（即无论处理顺序如何，最终结果相同）；(b) 落定后各精灵到吸引子的曼哈顿距离两两不同，确保最近和最远唯一。

**规则**：
1. 栗(9)单像素为吸引子 A。
2. 对每个精灵 S，计算从 S 的 bounding box 中心（行列坐标各取 bounding box 上下/左右的算术均值并取整）到 A 的行偏移 dr（A 行号 - S 中心行号）和列偏移 dc（A 列号 - S 中心列号）。
3. 将偏移量化为四个基本方向之一：取 |dr| 和 |dc| 中较大者对应的轴方向（dr > 0 则向下，dr < 0 则向上，dc > 0 则向右，dc < 0 则向左）。若 |dr| = |dc|，优先取垂直方向（即按 dr 的符号取上或下）。
4. 将精灵整体沿该方向平移，保持内部像素布局不变，直至精灵 bounding box 的前沿抵达网格边缘（最前沿行/列触碰第 0 行/第 0 列/最后一行/最后一列）。
5. 所有精灵落定后，计算每个精灵新 bounding box 中心到 A 的曼哈顿距离。
6. 距离最小的精灵重涂为蓝(1)；距离最大的精灵重涂为红(2)。
7. 所有其他精灵擦除为黑(0)背景。
8. 吸引子标记自身也擦除为黑(0)背景。

**关键洞察**：每个精灵拥有个性化的重力方向——这不是全局物理力，而是由精灵与吸引子的空间关系编码的定向推力。初始位置编码了方向信息，但最终位置（经重力后）编码了距离排名，两层信息在不同阶段各自发挥不同的决策作用。

## 新题 3：标尺长度像素放大与镜像位置放置

**组合逻辑**：[像素放大](已有) + [平移/镜像](已有) + [归一化朝向](已有) — 创新：标尺的长度被重新解释为缩放因子（而非平铺重复次数），标尺同时编码大小、位置和朝向三重信息

**来源原语**：
- 标尺条、端部附着、标尺长度决定重复 ← 参考题 9c1e755f（长度含义被创新为缩放因子）
- 像素放大 ← 参考题 8a6d367c
- 平移、镜像位置、内部朝向不变 ← 参考题 8ee62060
- 归一化朝向、宽高互换 ← 参考题 d749d46f

**依赖链**：标尺方向 → 决定是否旋转母题以归一化朝向 → 标尺长度 → 作为像素放大的缩放因子 → 标尺位置 → 水平镜像得到放置位置 → 将放大后的母题绘制到镜像位置。删除归一化则竖直标尺产生错误朝向的放大图；删除镜像则不知放置位置；删除缩放则母题尺寸错误。

一句话总结：从标尺末端提取母题，按标尺长度像素放大，将放大结果放置到标尺的水平镜像位置。

**输入结构**：约 20x18 黑(0)背景网格。网格左半区有 2-3 条灰(5)标尺条，部分为水平方向、部分为竖直方向，长度各为 2-4 格。每条标尺的一端紧邻附着一个小型彩色母题（bounding box 为 2x2 或 2x3，使用非黑非灰颜色，每条标尺的母题颜色和形状各异）。水平标尺的母题附着在其右端，竖直标尺的母题附着在其下端。标尺条之间互不相邻。右半区为空白黑色背景，用于放置放大后的母题。生成约束：每条标尺的缩放后母题尺寸（= 母题 bounding box 各维度 x 标尺长度）不超过网格右半区的可用空间，且不同标尺对应的放大结果在右半区互不重叠。

**规则**：
1. 对每条标尺条依次处理（按标尺 bounding box 左上角的行优先、列次优先排序）：
   a. 提取其末端附着的母题，裁剪到最小 bounding box。
   b. 若标尺为竖直方向，将母题顺时针旋转 90 度（归一化为水平朝向）；若标尺为水平方向，母题保持不变。
   c. 记录标尺的长度 L（以格数计，不含母题本身）。
   d. 对（可能已旋转的）母题进行像素放大：母题中每个像素扩展为 L x L 的同色方块，背景像素扩展为 L x L 的背景块。
   e. 计算标尺条的水平镜像列位置：设标尺 bounding box 的最左列为 c0、bounding box 宽度（含母题整体的宽度）为 w，镜像后的最左列 = grid_width - w - c0。
   f. 将放大后的母题绘制到镜像位置，其顶行与原始标尺 bounding box 的顶行齐平。
2. 原始标尺条和母题在输出中保持不变。
3. 若多个放大母题在镜像区域有重叠（根据生成约束不应发生），后处理的覆盖先处理的。

**关键洞察**：标尺条承担三重角色——末端标识母题（"是什么"），长度编码缩放因子（"放大多少"），位置编码目标放置点（"放在哪儿"，通过水平镜像推算）。竖直标尺额外触发母题旋转，使得标尺方向也隐含了朝向信息。这种多义复用在参考题中不存在：9c1e755f 的标尺只控制平铺重复次数，8ee62060 的镜像不涉及缩放，8a6d367c 的缩放因子来自帧尺寸而非标尺。

## 新题 4：频率过滤后碎片空间展布重建同心环

**组合逻辑**：[连通检测 + 计数](已有) + [跳过最高频](已有) + [同心层填充](已有) — 创新：统计频率用于颜色级过滤，过滤后存留颜色的全局空间展布范围（而非原始碎片帧大小）决定同心环尺寸

**来源原语**：
- 连通检测、单色连通体、计数、按数量降序 ← 参考题 2753e76c
- 跳过最高频、频率排序 ← 参考题 f8b3ba0a
- 同心层填充、同心正方形层、嵌套层次、按边长降序排列 ← 参考题 c658a4bd
- 忽略干扰项 ← 参考题 d4469b4b / a3325580

**依赖链**：连通检测 → 按颜色计数分量数 → 最高频颜色作为干扰项被剔除 → 存留颜色的全局 bounding box 边长作为环尺寸 → 按边长降序排列为同心环。删除频率过滤则多一个颜色进入环构建导致错误输出；删除全局 bbox 计算则不知环大小；删除同心构建则无输出结构。

一句话总结：在散落的彩色碎片中，剔除分量数最多的干扰颜色，将剩余颜色按其全局空间展布范围从大到小排为居中同心方环。

**输入结构**：约 16x16 黑(0)背景网格。网格上散布着 4-5 种非黑颜色的像素碎片。每种颜色形成多个小型 4-连通分量（每个分量 2-8 像素，形状不规则），各颜色的分量数互不相同。其中一种颜色的分量数严格多于其他所有颜色（至少多 2 个），此为干扰色。各颜色的碎片分布范围不同——有的颜色的碎片分散在网格的较大区域内，有的集中在较小区域。生成约束：(a) 剔除干扰色后，剩余每种颜色的全局正方形 bounding box 边长（见规则第 3 条定义）两两不同且均为奇数；(b) 最大的全局正方形 bbox 边长不超过 15。

**规则**：
1. 对每种非黑颜色，检测其所有 4-连通分量，统计分量数量。
2. 找出分量数最多的颜色 C_max，将该颜色的所有像素在输出中丢弃（不参与后续步骤）。
3. 对每种存留颜色 c，计算包含 c 的所有像素的最小轴对齐 bounding box 的行跨度 H 和列跨度 W，取 S_c = max(H, W) 作为该颜色的"展布边长"。
4. 将存留颜色按 S_c 从大到小排序。
5. 创建正方形输出网格（边长 = 最大的 S_c）。以网格中心为对称中心，从外到内依次绘制居中同心正方形环：最外环使用 S_c 最大的颜色，次外环使用 S_c 次大的颜色，以此类推。每个正方形环的边长等于该颜色的 S_c 值，绘制时只画外边框（宽 1 像素），内部由更内层的环或黑(0)背景填充。
6. 若相邻两层环的 S_c 值差恰好为 2，则两环紧密嵌套（无间隙）；若差大于 2，两环之间出现黑色背景间隙。

**关键洞察**：分量数最多的颜色是噪声干扰，必须通过统计识别并丢弃。存留颜色的输入坐标被完全抛弃——重建依据不是碎片的原始位置，而是它们在空间中的"展布范围"（全局 bbox 边长）。这是从统计度量（频率过滤）到几何度量（空间展布）再到结构重建（同心环）的三级跳跃，每级的输出改变了下一级的输入数据结构。

## 新题 5：旋转调度瓦片推断与遮挡补全

**组合逻辑**：[平铺/补全](已有) + [旋转](已有) + [归一化朝向](创新：推断位置依赖的旋转调度规则) — 创新：平铺不是简单的平移重复，每个瓦片位置有独立的旋转状态，旋转调度本身是需要从多示例中归纳的隐藏规则

**来源原语**：
- 平铺、补全、重复瓦片、遮挡区域、可见像素约束推断 ← 参考题 ca8f78db
- 旋转、旋转对称、象限、提取原始瓦片 ← 参考题 2013d3e2
- 归一化朝向 ← 参考题 d749d46f

**依赖链**：可见瓦片 → 旋转归一化以推断基础瓦片图案 → 分析各位置的旋转状态以发现旋转调度规则 → 对遮挡位置应用调度规则确定旋转角度 → 用旋转后的基础瓦片填补缺失区域。删除旋转归一化则无法识别基础瓦片（相邻瓦片朝向不同会被误判为不同图案）；删除调度规则推断则不知每个位置应使用哪种旋转；删除平铺补全则无法填补遮挡区域。

一句话总结：网格由同一基础瓦片的旋转副本铺成，每个位置的旋转角度按隐藏的 2x2 周期调度规则决定；部分瓦片被黑色遮挡，需推断基础瓦片和旋转调度后补全。

**输入结构**：约 16x16 网格。网格被等分为 4x4 的子区域阵列（每个子区域 4x4 像素，共 16 个子区域）。每个子区域包含同一基础瓦片图案的旋转副本（0 / 90 / 180 / 270 度之一）。基础瓦片是一个 4x4 的多色图案（使用 2-3 种非黑颜色和黑(0)），具有非对称形状（旋转后可区分四种朝向，即该图案不具有 90 度旋转对称性）。旋转调度遵循一个以 2x2 为单位的重复模式：位于阵列坐标 (i, j) 的瓦片，其旋转角度由 (i mod 2, j mod 2) 确定性决定（例如 (0,0) 对应 0 度, (0,1) 对应 90 度, (1,0) 对应 270 度, (1,1) 对应 180 度——具体映射需从示例推断）。2-4 个子区域被黑(0)像素完全遮挡，另有 2-3 个子区域被部分遮挡（部分像素被替换为黑色）。生成约束：至少保留四种旋转状态各一个完整可见的瓦片实例，使得基础瓦片和旋转调度规则可从可见信息中唯一确定。

**规则**：
1. 识别子区域阵列的分割方式：网格大小 / 子区域大小 = 阵列维度。
2. 收集所有完整可见的子区域（不含任何黑色遮挡像素的子区域——注意基础瓦片本身也可能包含黑色像素，需通过多个子区域对比来区分"瓦片自身的黑色"与"遮挡黑色"：若某位置在同一旋转状态的多个实例中始终为黑色，则为瓦片自身像素）。
3. 将所有完整可见的子区域分别旋转 0 / 90 / 180 / 270 度，聚类以找到唯一的基础瓦片 T（所有子区域在适当旋转后都与 T 一致）。
4. 对每个完整可见的子区域，确定它是 T 的哪种旋转副本（0 / 90 / 180 / 270 度），记录其阵列坐标 (i, j) 和旋转角度 r。
5. 从所有 (i, j, r) 记录中推断旋转调度映射 f：(i mod 2, j mod 2) → r。该映射是一个 2x2 查找表。
6. 对每个被遮挡（全黑或部分黑）的子区域，根据其阵列坐标 (i, j) 计算 f(i mod 2, j mod 2) 得到应有的旋转角度，将 T 按该角度旋转后填入该子区域。
7. 输出完全恢复的网格。

**关键洞察**：这不是简单的平移平铺——相邻瓦片可能朝向不同，对相邻子区域取"相同"的假设会直接失败。求解者必须先发现所有可见瓦片本质上是同一图案的四种旋转变体，再推断哪种旋转出现在哪个位置，发现 2x2 的周期调度规律。旋转调度规则是一个二阶隐藏模式——需对比多个示例中不同位置的瓦片来归纳。

## 新题 6：形状匹配选源的距离控制射线延伸

**组合逻辑**：[形状匹配](已有) + [射线延伸](已有) + [擦除](已有) — 创新：L 框架同时编码"匹配谁"（形状密钥）和"射线多长"（距离密钥），单一视觉元素承担双参数角色

**来源原语**：
- 形状匹配、掩码相同、模板、框架、前景对象 ← 参考题 63613498
- 射线延伸、距离、距离决定阶梯高度 ← 参考题 b8cdaf2b
- 擦除 ← 参考题 a61f2674

**依赖链**：L 框架提供模板掩码 → 形状匹配找到唯一匹配对象 → 该对象与框架之间的空间距离确定射线长度 → 从匹配对象发射射线 → 其余对象被擦除。删除形状匹配则不知射线发射源；删除距离计算则不知射线长度；删除射线则无可见新增输出。

一句话总结：在散布的对象中找到与 L 框架模板形状匹配的唯一对象，以它为中心向四方发射射线，射线长度等于它与 L 框架的距离，其余对象全部擦除。

**输入结构**：约 16x16 黑(0)背景网格。网格一角（如左下角）有一个灰(5) L 型框架（竖直腿在右、水平腿在底），框架内有一个非黑非灰颜色的小型模板形状（3-6 像素，4-连通）。网格上另散布 4-6 个彩色对象（各为不同非黑非灰颜色，4-连通，3-8 像素，形状各异）。恰好有一个对象的归一化二值掩码与模板相同（颜色可能不同），其余对象的掩码各不相同且均不匹配模板。各对象 bounding box 互不重叠。生成约束：匹配对象与 L 框架的曼哈顿距离 D（两者 bounding box 中心之间）满足从匹配对象的每个像素向四方延伸 D 格的射线均不与 L 框架重叠，且射线不越出网格边界。

**规则**：
1. 提取 L 型框架内模板的归一化二值掩码 M（裁剪到最小 bounding box，转为 0/1 掩码）。
2. 对每个非框架、非模板的对象，计算其归一化二值掩码。找到唯一与 M 完全匹配的对象 O。
3. 擦除所有不匹配的对象（像素置为黑(0)背景）。
4. 计算 O 的 bounding box 中心 (ro, co)（行列各取上下/左右算术均值并取整）与 L 框架 bounding box 中心 (rf, cf) 之间的曼哈顿距离 D = |ro - rf| + |co - cf|。
5. 从 O 的每个非背景像素位置 (r, c) 出发，向上、下、左、右四个方向各延伸一条射线。每条射线从 (r, c) 的相邻格开始，连续绘制 D 个像素。射线像素涂为灰(5)。若射线提前遇到网格边界则截止（不绘制超出边界的部分）。
6. O 本身保持其原始颜色不变。
7. L 框架和框架内模板在输出中保持不变。

**关键洞察**：L 框架是一个"双参数编码器"——其内部形状是"形状密钥"，指定哪个对象被激活；它与被激活对象之间的空间距离是"强度密钥"，指定射线延伸的长度。两个独立参数打包在一个视觉元素及其空间位置中，求解者必须同时提取形状和距离两种信息。参考题 63613498 中的 L 框架只做形状选择不涉及距离，b8cdaf2b 中的距离来自底行色条位置不涉及形状匹配——两者的信息从未由同一元素同时承载。

## 新题 7：频率过滤后的矩形宽高互换排列

**组合逻辑**：[计数 + 跳过最高频](已有) + [宽高互换](已有) + [排列](已有) — 创新：频率过滤和几何变换是独立操作但必须串联执行，过滤改变了哪些矩形进入变换管线，变换改变了矩形的几何外观

**来源原语**：
- 计数、频率排序、跳过最高频 ← 参考题 f8b3ba0a
- 忽略干扰项 ← 参考题 d4469b4b / a3325580
- 归一化朝向、排列、矩形、宽高互换 ← 参考题 d749d46f
- 面积筛选 ← 参考题 a3325580

**依赖链**：计数每种颜色的矩形数量 → 跳过最高频颜色（干扰色） → 对存留矩形执行宽高互换 → 按原始水平位置底对齐排列为输出。删除频率过滤则多余矩形参与排列导致输出错误；删除宽高互换则矩形形状不对；删除排列则输出布局无法确定。

一句话总结：统计矩形颜色频率并剔除出现最多的颜色，对剩余矩形执行宽高互换后按原始水平位置底对齐排列。

**输入结构**：约 15x12 黑(0)背景网格。网格上分布 6-10 个实心单色矩形（每个矩形使用一种非黑颜色填充，宽 1-4 格，高 2-6 格）。共使用 3-4 种颜色，同一颜色可能对应不同尺寸的矩形。各矩形互不重叠、互不相邻（至少间隔 1 列背景像素）。其中一种颜色的矩形数量严格多于任何其他颜色（至少多 1 个），此颜色为干扰色。生成约束：(a) 各颜色的矩形数量两两不同；(b) 存留矩形（非干扰色）的宽高互换后尺寸均可在输出网格中容纳；(c) 存留矩形的原始 bounding box 左列坐标两两不同，保证水平排序无歧义。

**规则**：
1. 检测所有非黑色矩形对象，记录每个矩形的颜色、宽 w、高 h 和 bounding box 最左列坐标 x。
2. 按颜色统计矩形数量。找出数量最多的颜色 C_max，丢弃所有颜色为 C_max 的矩形。
3. 对每个存留矩形，执行宽高互换：原始宽 w 变为新高、原始高 h 变为新宽，即 (w, h) → (h, w)。矩形仍填充原始颜色。
4. 将所有互换后的矩形按原始左列坐标 x 从小到大排序。
5. 构建输出网格：高度 = 所有互换后矩形中的最大高度（即原始矩形中的最大宽度），宽度 = 所有互换后矩形宽度之和 + 矩形数量 - 1（相邻矩形之间各间隔 1 列黑(0)背景）。
6. 从左到右依次绘制每个互换后的矩形，每个矩形底边对齐输出网格最底行，相邻矩形之间间隔 1 列黑(0)背景。

**关键洞察**：最高频颜色是伪装成普通数据的干扰项——它的矩形在视觉上与其他矩形无异，只能通过跨色频率统计识别。存留矩形经历维度反转：原本高而窄的变为矮而宽，原本矮而宽的变为高而窄，使得输出外观与输入截然不同。频率过滤和维度反转必须同时正确执行：只过滤不反转，或只反转不过滤，输出都是错误的。需对比多个示例才能确认干扰色的选择规则（最高频）和几何变换规则（宽高互换而非旋转或缩放）。
