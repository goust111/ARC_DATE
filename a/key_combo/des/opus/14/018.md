## 新题 1：路径掩膜切换射线

**组合逻辑**：[寻路](已有) + [射线延伸·切换重涂](已有，作用域创新：从全列缩窄为路径交集) → 路径-射线交叉域内逐像素切换

**来源原语**：寻路/端点像素/障碍像素/最短路径(b15fca0b)、射线延伸/切换重涂/控制像素(981add89)、颜色匹配(981add89)

**依赖链**：最短路径计算产出一条空间轨迹 → 每条射线的作用域被限制为该轨迹与本列的交集像素 → 射线的切换规则只在路径像素上生效。删除路径计算，射线无法知道作用域；删除射线，路径仅是一条未着色的轨迹。

将控制像素射线的切换效果限定在两端点间的最短路径上，使得路径几何和射线列位置共同决定最终着色。

**输入结构**：黑(0)背景，约 12x12 网格。顶行有 2~3 个控制像素，颜色各不相同，取自绿(3)、黄(4)、橙(7)中的若干种。网格中散布蓝(1)障碍像素，形成不规则的迷宫式分布。另有两个红(2)端点像素，位于非顶行、非障碍位置。生成约束：两端点之间恰好存在一条（唯一）经由非蓝像素的 4-邻接最短路径；该路径至少与两个不同控制列相交；路径上除端点外全为黑(0)背景像素；控制像素所在列上无蓝(1)障碍。

**规则**：
1. 找到从一个红(2)端点到另一个红(2)端点的唯一 4-邻接最短路径（蓝(1)像素不可通行），路径包含两个端点本身。
2. 对顶行的控制像素按列坐标从左到右依次处理。对每个控制像素，取其所在列与最短路径的交集像素集合 S。
3. 对 S 中每个像素执行切换规则：若该像素当前颜色等于该控制像素颜色，则擦除为黑(0)；否则，涂为该控制像素颜色。红(2)端点像素也参与切换（若恰好在控制列上）。
4. 路径上不在任何控制列中的像素保持不变。
5. 非路径像素（包括蓝障碍、背景、控制像素本身）全部保持不变。
6. 当同一路径像素处于多个控制列交集时（生成时保证不发生此情况，每个路径像素至多属于一个控制列）。

**关键洞察**：射线的作用域不再是一整列，而是该列与最短路径的交集——路径几何成为射线的空间滤波器。求解者必须同时推理出迷宫最短路径和射线切换机制，二者在交集像素处耦合。

## 新题 2：对称修复后的标记象限裁剪

**组合逻辑**：[标记像素·象限选择](已有) + [对称补全](已有，补全范围创新：限定于标记所选象限) → 先定位后修复再裁剪

**来源原语**：分隔十字/标记像素/象限/标记所在象限保留(2dc579da)、对称补全/缺失矩形区域/对称图案/全对称恢复缺失(e66aafb8)、裁剪(2dc579da, e66aafb8)

**依赖链**：标记像素确定目标象限 → 该象限内有缺损区域需通过 D4 对称从其他象限恢复 → 裁剪输出恢复后的目标象限。删除标记，不知道裁剪哪个象限；删除对称补全，裁剪出的象限含黑洞；删除裁剪，输出整张图无法体现标记选择。

在被分隔十字划分的四象限网格中，根据标记像素选出目标象限，利用全网格的 D4 对称性修复该象限中的缺损区域，输出修复后的象限。

**输入结构**：正方形网格（奇数边长，约 11x11 或 13x13）。灰(5)分隔十字——一条灰色完整行与一条灰色完整列交叉于网格中心，将网格分为四个等大的矩形象限。除分隔十字和缺损区域外，整张网格的非背景像素图案在水平、垂直、两条对角线反射下保持不变（D4 对称），使用 2~3 种前景色（如蓝(1)、红(2)、绿(3)）。一个象限内有一个橙(7)标记像素，占据该象限中某个本应为前景色的位置（即标记像素覆盖了一个对称图案像素，但标记本身不属于对称图案）。同一象限内另有一个矩形子区域被清空为黑(0)——该矩形至少 2x2，不覆盖标记像素，不接触分隔十字。其余三个象限的图案完整无损。生成约束：缺损矩形内每个像素的 D4 对称轨道中，至少有一个落在非缺损象限的非背景位置，从而保证可恢复。

**规则**：
1. 识别灰(5)分隔十字（唯一的灰色完整行和完整列）。
2. 找到橙(7)标记像素，确定它所在的象限为目标象限。
3. 对目标象限内每个黑(0)像素（缺损区域），计算其在完整网格上的 D4 对称轨道（水平反射、垂直反射、两条对角线反射共 8 个位置，去除落在分隔十字上的位置）。从轨道中取到的第一个非黑(0)值，填入该缺损位置。
4. 将橙(7)标记像素也通过相同的对称轨道恢复为其正确的图案颜色。
5. 裁剪目标象限（不包含分隔十字行列），输出为一个矩形网格。

**关键洞察**：标记像素的双重角色——它既是象限选择器（告诉你输出哪个象限），又是一个需要被修复的缺损点（它覆盖的那个图案像素也需要通过对称恢复）。求解者必须先用标记选象限、再从对称中恢复包括标记位在内的全部缺损，最后裁剪。

## 新题 3：双通道轮廓填充——射线定色、面积定靶

**组合逻辑**：[射线延伸](已有) ∩ [计数·面积匹配](已有) → 两个独立信息通道在同一轮廓对象上汇聚（射线提供颜色，面积提供目标）

**来源原语**：射线延伸/控制像素(981add89, 99fa7670)、计数/填充/轮廓对象/行内腔/面积匹配/像素数等于腔面积(7acdf6d3)、擦除(7acdf6d3)、实心矩形(23b5c85d)

**依赖链**：红色矩形的面积 = N → 在所有轮廓中找到行内腔面积 = N 的唯一轮廓（通道 A）；控制像素射线向下延伸 → 判断哪条射线的列范围与该轮廓列范围相交（通道 B）。通道 A 确定"填哪个轮廓"，通道 B 确定"用什么颜色填"。两者在目标轮廓处汇聚。删除面积匹配，不知道填哪个轮廓；删除射线，不知道用什么颜色。

控制射线确定填充颜色，源矩形面积确定填充目标轮廓，二者在同一轮廓对象上交汇。

**输入结构**：黑(0)背景，约 14x14 网格。顶行有 2~3 个控制像素，颜色各不相同（如绿(3)、黄(4)、橙(7））。网格中有 3~4 个灰(5)轮廓对象——每个是一个单色空心矩形框（边框为灰(5)，内部为黑(0)背景，宽和高各至少 3），各轮廓的行内腔面积（每行中最左灰像素与最右灰像素之间的黑像素数之和）互不相同。另有一个红(2)实心矩形（宽高各至少 2），不与任何轮廓重叠。生成约束：恰好一个轮廓的行内腔面积等于红矩形的像素总数；每个轮廓的列范围至多与一条控制射线列相交；被面积匹配命中的那个轮廓恰好有一条控制射线列穿过其列范围；控制像素列与红矩形列不重叠。

**规则**：
1. 计算红(2)实心矩形的像素总数 N。
2. 对每个灰(5)轮廓对象，计算其行内腔面积：在轮廓占据的每一行上，统计最左灰像素与最右灰像素之间（不含灰像素本身）的黑(0)像素个数，逐行求和。
3. 找到行内腔面积恰好等于 N 的唯一轮廓——即目标轮廓。
4. 将每个控制像素沿其所在列从第 1 行向下延伸到底行，将该列上的所有黑(0)像素涂为该控制颜色。若列上有灰(5)或红(2)像素，保持不变（射线跳过非背景像素）。
5. 确定哪条控制射线的列落在目标轮廓的列范围（轮廓 bbox 的最左列到最右列）内。取该射线的颜色作为填充色 F。
6. 将目标轮廓的行内腔像素（步骤 2 中统计过的那些黑(0)位置）涂为颜色 F。
7. 将红(2)实心矩形擦除为黑(0)。
8. 所有非目标轮廓、控制像素、射线着色和其余背景保持不变。

**关键洞察**：填充操作的"位置"和"颜色"来自两个完全独立的信息源——面积匹配选靶，射线列交集定色。求解者若仅关注面积可找到目标轮廓但不知颜色；若仅关注射线可知颜色但不知目标。两条推理线需同时完成才能确定输出。

## 新题 4：形状匹配双输出——颜色重涂与旋转步数滑动

**组合逻辑**：[形状匹配·旋转反射等价](已有) →→ 分叉为 [重涂色](由匹配色决定) + [滑动](由旋转步数奇偶决定方向)（创新：一次匹配产出两种信息分别驱动不同操作）

**来源原语**：形状匹配/旋转反射等价/精灵体/图例区域/分隔线(845d6e51)、重涂色(845d6e51, aedd82e4)、滑动/分隔线/颜色匹配定去向(7d7772cc)

**依赖链**：形状匹配产生两个结果——(a)匹配到的模板颜色，(b)将查询形状对齐到模板所需的旋转步数。颜色结果驱动重涂色操作；旋转步数的奇偶性驱动滑动方向（偶数步→向分隔线靠拢，奇数步→远离分隔线滑至远端）。删除形状匹配，既无法确定颜色也无法确定滑动方向；删除重涂色，形状匹配的颜色信息被浪费；删除滑动，旋转信息被浪费。

通过图例中的模板匹配查询精灵体的形状（允许旋转和反射），匹配结果同时提供重涂颜色和滑动方向。

**输入结构**：黑(0)背景，约 15x18 网格，中间有一条灰(5)竖直分隔线（一整列灰色）将网格分为左右两半。左半为图例区域，包含 3~4 个模板精灵体，每个精灵体是一个 4-连通单色小图形（3~6 像素，边界框不超过 3x3），颜色各不相同（取自蓝(1)、绿(3)、黄(4)、橙(7)）；各模板在所有 8 种刚性变换（4 旋转 x 2 反射）下形状互不等价。右半为查询区域，包含相同数量的精灵体，全部为红(2)，每个的形状在某种旋转/反射下与恰好一个模板匹配。生成约束：每个模板恰好被一个查询匹配；查询精灵体之间水平间距足够大，滑动后不会重叠；查询精灵体中既有旋转步数为偶数（0 或 180 度）的匹配，也有奇数（90 或 270 度）的匹配，以确保两种滑动方向在示例中都出现。

**规则**：
1. 对右半每个红(2)查询精灵体，将其形状（4-连通像素集的相对坐标）与左半所有模板在 8 种刚性变换下比较，找到唯一匹配的模板及所需变换。
2. 将查询精灵体从红(2)重涂为匹配模板的颜色。
3. 确定对齐所需的最小顺时针旋转步数（0、1、2、3 步，每步 90 度；若存在多种等价变换——如纯旋转和旋转+反射都能对齐——取不含反射的纯旋转版本的步数；若只有含反射的变换能对齐，取反射后所需的旋转步数）。
4. 若旋转步数为偶数（0 或 2）：将重涂后的精灵体整体水平滑动，直到其最右列的像素紧贴灰(5)分隔线右侧一格（即列坐标 = 分隔线列 + 1）。
5. 若旋转步数为奇数（1 或 3）：将重涂后的精灵体整体水平滑动，直到其最左列的像素位于网格最右列。
6. 滑动时精灵体行坐标不变，仅列坐标平移。原位置擦除为黑(0)。
7. 左半图例区域（含模板和分隔线）保持不变。

**关键洞察**：形状匹配不仅确定颜色映射，还隐式产出旋转几何信息。旋转步数的奇偶性——而非颜色或大小——决定了滑动方向。求解者必须从示例中发现"偶数步靠近、奇数步远离"这一隐蔽规则，仅看单个示例无法区分。

## 新题 5：尺寸门控射线——单像素吸收、多像素穿透

**组合逻辑**：[射线延伸](已有，传播规则创新：遇障碍物的行为由目标尺寸决定) + [尺寸分类](已有) + [重涂色](已有) → 连通分量的尺寸属性反过来改变射线的物理传播行为

**来源原语**：射线延伸/控制像素(981add89, 99fa7670)、连通分量/尺寸分类/单像素分量重涂(aedd82e4)、重涂色(aedd82e4)

**依赖链**：射线从控制像素向下传播 → 遇到前景像素时，需判断该像素所属 4-连通分量的尺寸 → 单像素分量：吸收射线（被重涂，射线终止）；多像素分量：穿透（不变，射线继续）。尺寸分类是射线传播规则的判定条件，非独立步骤。删除尺寸判断，射线行为不确定；删除射线，没有触发重涂的机制。

控制像素向下发射有色射线，射线遇到前景连通分量时根据分量大小决定行为：单像素分量被吸收并重涂为射线色后射线终止；多像素分量对射线透明，射线穿过继续延伸。

**输入结构**：黑(0)背景，约 11x11 网格。顶行有 2~3 个控制像素，颜色各不相同（如绿(3)、黄(4)、橙(7)）。顶行以下散布若干红(2) 4-连通分量：部分为单像素孤立点，部分为 2~5 像素的连通图形（具有不同的几何结构，可为直线段、折线或不规则团块）。生成约束：每条控制列上至少有一个单像素红分量和一个多像素红分量；不同控制列上的前景分量互不共享（即每个分量至多被一条射线穿过）；同一列上的单像素分量不相邻于多像素分量（避免连通性歧义）。

**规则**：
1. 对顶行控制像素按列坐标从左到右依次处理。
2. 对每个控制像素，从其正下方（第 1 行）开始逐行向下扫描该列：
   - 若当前格为黑(0)背景：涂为该控制颜色，继续向下。
   - 若当前格为红(2)：判断该红像素所属的 4-连通分量的像素总数。
     - 若分量大小 = 1（孤立像素）：将该像素重涂为控制颜色，射线**终止**（不再向下延伸）。
     - 若分量大小 > 1：该像素保持红(2)不变，射线**穿透**继续向下扫描。
   - 若当前格为非黑、非红颜色（如已被之前射线涂过的控制色）：射线**终止**。
3. 控制像素本身保持不变。未被任何射线触及的像素保持不变。

**关键洞察**：射线的传播长度不由固定障碍决定，而由动态的连通分量尺寸属性决定——大分量对射线透明，小分量则成为终止屏障。求解者必须同时理解射线传播机制和连通分量尺寸判定，二者在每次碰撞事件中耦合。

## 新题 6：完整方块分类构建迷宫拓扑

**组合逻辑**：[标记·完整方块检测](已有) + [寻路](已有，迷宫拓扑创新：由几何完整性分类决定而非静态障碍) → 形状分类输出成为寻路输入的拓扑约束

**来源原语**：标记/完整方块/角点邻接/完整方块才标记(14b8e18c)、寻路/端点像素/障碍像素/最短路径/四邻接连通/最短路径唯一(b15fca0b)、筛选(23b5c85d)

**依赖链**：几何完整性检测将前景对象分为完整方块 vs 非方块 → 完整方块及其角外标记像素共同构成迷宫障碍 → 非方块对象不阻塞通行 → 在此拓扑上寻找端点间最短路径。删除完整性分类，所有对象都变成障碍或都可通行，迷宫拓扑完全不同；删除寻路，分类结果无处使用。

根据几何完整性将前景对象分为阻塞体（完整方块）和可通行体（非方块），完整方块额外生长角外标记扩展阻塞范围，然后在此拓扑上进行端点间最短路径搜索。

**输入结构**：黑(0)背景，约 14x14 网格。包含 4~6 个蓝(1) 4-连通前景对象，尺寸从 2x2 到 5x5 不等，形态各异。其中一些是完整方块：边界框为 NxN 正方形且边界框边上所有位置均被蓝(1)填满（可以是实心方块或空心方框，只要边框完整即可）。其余对象的边界框不是正方形，或正方形边框不完整（如 L 形、条形、有缺口的框）。另有两个橙(7)端点像素，不与任何蓝对象相邻（8-邻接意义下）。生成约束：不同蓝对象之间互不相邻（8-邻接意义下至少隔 2 格，为角外标记留空间）；两端点之间恰好存在唯一 4-邻接最短路径（在完整方块及其标记构成的阻塞下）；该路径至少经过一个非方块对象所在区域（穿过其像素所在格）。

**规则**：
1. 识别所有蓝(1) 4-连通前景对象，对每个对象检测其是否为完整方块：边界框为 NxN（N >= 2），且边界框四条边上的所有格子均为蓝(1)。
2. 对每个完整方块，在其四个角的外侧生成红(2)角外标记：每个角有两个相邻的外侧背景格（分别沿水平和垂直方向），若该格为黑(0)背景则涂为红(2)。每个完整方块最多产生 8 个标记。
3. 定义阻塞集合 B = 所有完整方块的蓝(1)像素 + 所有红(2)角外标记像素。
4. 非完整方块的蓝(1)对象不属于阻塞集合（可通行）。
5. 找到从一个橙(7)端点到另一个橙(7)端点的唯一 4-邻接最短路径，将 B 中的像素视为不可通行。路径可以穿过非完整方块的蓝(1)像素和黑(0)背景。
6. 将路径上除两个端点外的所有像素涂为黄(4)（若路径经过非完整方块的蓝(1)像素，该像素也变为黄(4)）。
7. 其余像素保持不变（蓝对象、红标记、背景、端点）。

**关键洞察**：形状的几何完整性——而非颜色、大小或位置——决定了它是障碍还是通道。外观相似的蓝色对象可能一个阻塞、一个可通行，取决于其边框是否为完整方块。角外标记进一步扩大了完整方块的阻塞范围，使分类步骤对迷宫拓扑的影响更加显著。

## 新题 7：双角色掩码——色板分区与克罗内克源

**组合逻辑**：[像素放大·克罗内克自积](已有，从单色扩展为多色) + [对齐比较](已有，比较结果创新：不决定滑动方向而决定扩展位置) → 同一掩码同时充当宏观筛选器和微观复制模板

**来源原语**：像素放大/印章覆盖/二值掩码/自相似嵌套/掩码克罗内克自积(80af3007)、对齐比较/同列对齐/颜色匹配(7d7772cc, 981add89)、编码映射(80af3007)、分隔线(7d7772cc)

**依赖链**：9x9 块放大区域解码为 3x3 二值掩码 M → 分隔线下方的 3x3 色板 C 与 M 逐格比较 → M[r][c]=ON 且 C[r][c] 非背景时该位置为"活跃"，其余为"沉默" → 在 9x9 输出中，活跃位置放置 M 的 3x3 翻版（着色为 C[r][c] 的颜色），沉默位置放置空白块。M 同时是解码对象（宏观）和印章模板（微观），删除 M 的任一角色都无法生成输出；删除色板 C，无法确定哪些位置活跃、也无法确定颜色。

将块放大的二值掩码解码后，结合分隔线下方的色板进行多色克罗内克式展开：掩码同时决定展开位置的资格和每个位置内的微观图案，色板提供宏观筛选和着色。

**输入结构**：黑(0)背景，约 12x13 网格。上部为一个 9x9 区域，由蓝(1)前景色和黑(0)背景色组成的块放大二值图案——将该区域划分为 9 个 3x3 块，每块要么全蓝(1)要么全黑(0)，编码一个 3x3 二值掩码 M。9x9 区域下方紧接一行灰(5)水平分隔线。分隔线下方是一个 3x3 的色板区域 C，每格为以下颜色之一：黑(0)、红(2)、绿(3)、黄(4)。生成约束：M 中至少有 3 个 ON 格；C 中至少有 2 个非黑格，且 C 的非黑格位置是 M 的 ON 格位置的子集（C 在 M 的 OFF 位置上必须为黑(0)）；C 中的非黑格颜色互不相同。

**规则**：
1. 将 9x9 区域解码为 3x3 二值掩码 M：块(r,c)（r,c 各取 0~2）全蓝 → M[r][c]=ON，全黑 → M[r][c]=OFF。
2. 读取分隔线下方的 3x3 色板 C。
3. 对 M 的每个格 (r,c)：
   - 若 M[r][c]=ON 且 C[r][c] 为非黑色 → 该位置"活跃"，记录填充色为 C[r][c]。
   - 否则 → 该位置"沉默"。
4. 构建 9x9 输出网格。对每个宏观位置 (r,c)（对应输出中第 r*3 ~ r*3+2 行、第 c*3 ~ c*3+2 列的 3x3 子块）：
   - 若 (r,c) 活跃：在该 3x3 子块中，按掩码 M 的形状放置像素——M[i][j]=ON 的位置涂为该位置的填充色，M[i][j]=OFF 的位置为黑(0)。
   - 若 (r,c) 沉默：该 3x3 子块全为黑(0)。
5. 输出仅为这个 9x9 网格，不包含分隔线和色板。

**关键洞察**：掩码 M 在输出中扮演双重角色——宏观层面它是位置资格过滤器（只有 M=ON 的位置才可能活跃），微观层面它是每个活跃块内的形状模板。色板 C 在 M 的 ON 位置上施加第二层筛选和着色。求解者仅看 M 的 Kronecker 自积（80af3007）会漏掉色板的过滤效应；仅看色板则无法知道块内的微观形状。

## 新题 8：计数奇偶驱动排序方向的竖条半涂与压缩

**组合逻辑**：[计数](已有) → [排序](已有，排序方向创新：由外部计数奇偶性决定) + [重涂色·等分](已有) → [紧凑排列](已有) —— 计数的奇偶性作为隐蔽决策节点改变后续排序行为

**来源原语**：竖直条/等分/下半变色/重涂色(ce9e57f2)、计数(d5c634a2, 7acdf6d3, a1aa0c1e)、排序(a1aa0c1e)、紧凑排列/空间位置排序(1990f7a8)、标记像素(14b8e18c)、擦除(7acdf6d3)

**依赖链**：散布的标记像素被计数 → 计数结果 N 的奇偶性决定排序方向（偶=升序，奇=降序） → 竖条按高度排序后依次排列 → 每根竖条进行上半/下半等分重涂。删除计数，不知升序还是降序；删除排序，输出排列无规律；删除半涂，输出与参考题 a1aa0c1e 过于相似。

统计网格中标记像素的数量，其奇偶性隐式控制竖条的排序方向；每根竖条上半保持原色、下半重涂为第二色；最终按排序顺序紧凑排列。

**输入结构**：黑(0)背景，约 15x10 网格。包含 4~6 根红(2)竖直条——每根宽 1 列、高 3~8 格，散布在不同列位置，彼此不相邻。另有若干绿(3)标记像素散布在不与任何竖条同列的位置上（全为孤立单像素，互不相邻）。一条灰(5)水平参考线位于网格底部倒数第二行（仅用于视觉分隔，不影响逻辑）。生成约束：不同示例中绿标记数量不同，且奇偶性不同（以确保排序方向在示例间变化）；竖条高度互不相同；竖条数量在所有示例中一致。

**规则**：
1. 统计网格中绿(3)标记像素的总数 → N。
2. 对每根红(2)竖直条（同列连续红像素段），测量其高度 H。
3. 若 N 为偶数，按高度升序排列所有竖条；若 N 为奇数，按高度降序排列。
4. 对每根竖条进行上下等分重涂：上部 ceil(H/2) 个像素保持红(2)，下部 floor(H/2) 个像素重涂为蓝(1)。
5. 构建输出网格：宽度 = 竖条数量，高度 = 最高竖条的高度。按步骤 3 的排序顺序从左到右依次排列竖条，每根竖条底端对齐输出网格底行。竖条上方空余位置为黑(0)。
6. 绿标记像素、灰参考线、原始竖条位置信息均不出现在输出中（输出仅含压缩后的竖条排列）。

**关键洞察**：绿色标记像素的数量不决定任何视觉属性（不决定颜色、不决定大小），仅通过奇偶性隐式切换排序方向。这一规则无法从单个示例归纳——求解者必须对比两个标记数奇偶性不同的示例，才能发现条形排列方向反转的原因。
