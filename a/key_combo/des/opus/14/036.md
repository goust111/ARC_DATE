## 新题 1：射线补墙洪泛分区

**组合逻辑**：[射线延伸](创新：射线作为结构墙而非视觉轨迹) + [洪泛填充] + [重涂色]（三者紧耦合：射线结果决定拓扑，拓扑决定涂色）

**来源原语**：射线延伸(ray_extend, 来自 9344f635/ac605cbb) + 洪泛填充(flood_fill, 来自 7b6016b9/8f3a5a89) + 重涂色(recolor, 来自 62ab2642) + 微型标记(micro_marker, 来自 9344f635) + 墙壁障碍(wall_barrier, 来自 8f3a5a89) + 封闭区域(enclosed_region, 来自 7b6016b9) + 朝向决定方向(orientation_determines_direction, 来自 9344f635) + 内外分区(in_out_partition, 来自 7b6016b9) + 边界连通分内外(border_in_out, 来自 7b6016b9)

**依赖链**：标记朝向 → 射线方向 → 射线与已有墙段拼合为完整围栏 → 洪泛填充识别内外 → 内部区域涂红、外部涂绿。若不先射线补墙，墙段有缺口，洪泛无法形成封闭区域；若不洪泛，无法区分内外；三步缺一不可。

从彩色标记的朝向发射射线补全不完整的灰墙，再用洪泛填充将墙围出的封闭区域涂红、外部涂绿。

**输入结构**：约 15x15 的网格，背景为黑(0)。灰(5) 像素构成若干不连续的墙段（每段为 3~8 像素的水平或垂直直线），这些墙段大致围出一到两个区域但留有缺口。在缺口附近散布 2~4 个同色的 2 像素标记（domino）：水平排列的标记表示水平方向，垂直排列的表示垂直方向。每个标记颜色各不相同（从蓝(1)、红(2)、绿(3)、黄(4) 中选取），但在射线阶段仅用灰(5) 绘制射线。生成约束：每个标记发出的射线恰好能填补一段墙的缺口，使墙段连为完整围栏；标记不在墙段上；所有标记射线互不交叉。

**规则**：
1. 对每个 2 像素标记，判断其朝向：若两像素水平相邻则为水平标记，若垂直相邻则为垂直标记。
2. 从标记中心位置沿其朝向的两个方向同时发射灰(5) 射线，每条射线延伸直到碰到已有的灰(5) 墙段像素或网格边界时停止（终点处不覆盖已有墙像素）。
3. 射线绘制完成后，擦除所有彩色标记像素（标记本身不保留）。
4. 此时灰墙段加灰射线构成完整的墙网络。从网格四条边界出发，对所有通过黑(0) 像素 4-连通可达的区域进行洪泛标记为外部。
5. 将外部黑像素重涂为绿(3)。
6. 将剩余黑像素（被墙完全包围、无法从边界到达的区域）重涂为红(2)。
7. 所有灰(5) 像素（原墙段 + 射线）保持不变。

**关键洞察**：标记在源题中仅用于发射视觉轨迹或行列条；这里标记的朝向信息被重新解读为"墙缺口的方向"，射线不是装饰而是结构性补墙。拓扑分区（内/外）完全取决于射线能否正确封闭围栏——朝向判断错误会导致缺口未补、洪泛穿透、内外颠倒。

## 新题 2：双少数蓝图竞争叠加

**组合逻辑**：[缩放](保留) + [透明叠加](创新：叠加对象从面板变为两个竞争的分形蓝图) → 冲突解决使用稀有度优先规则（全新结构关系）

**来源原语**：缩放/scale(来自 b99e7126) + 透明叠加/transparent_overlay(来自 281123b4) + 少数单元/minority_cell(来自 b99e7126) + 多数单元/majority_cell(来自 b99e7126) + 分隔网格/separator_grid(来自 b99e7126) + 自相似/self_similarity(来自 b99e7126) + 图层优先级/layer_priority(来自 281123b4) + 少数图案为蓝图/minority_pattern_as_blueprint(来自 b99e7126)

**依赖链**：识别两种少数单元 → 分别缩放为网格级蓝图 → 蓝图重叠位置需冲突解决 → 少数单元数量更少者优先。若不先完成两个缩放，无法发现重叠；若不计数比较稀有度，重叠区域的填充无法确定。缩放、叠加、计数三者耦合。

在含两种不同少数单元的分隔网格中，分别将每种少数图案缩放为网格级蓝图，重叠位置以更稀有的类型优先。

**输入结构**：约 15x15 的网格，由单色分隔线（栗(9)，1 像素宽）分为 5x5 的单元阵列，每个单元内部为 2x2 的图案区域。大多数单元（约 17~19 个）共享相同的内部图案（多数图案），称为 M 型。剩余单元分为两类少数图案——A 型和 B 型，各出现 2~4 次，且 A 型出现次数严格少于 B 型。A 型和 B 型的内部图案互不相同，也与 M 型不同。每种少数图案的内部 2x2 像素视为一个二值蓝图（非背景像素=活跃，背景像素=非活跃），它指示该类少数单元应在 5x5 单元阵列的哪些位置出现。生成约束：A 型和 B 型的蓝图各自与其在阵列中的实际位置一致（已有的少数单元位于蓝图活跃位置）；两种蓝图的活跃位置存在至少 1 个重叠单元格。

**规则**：
1. 识别分隔线颜色（完全覆盖某些行和列的单色），确定单元阵列的大小和每个单元的边界。
2. 统计每个单元的内部图案，按出现频率分为多数图案 M、少数图案 A、少数图案 B 三类。
3. 对 A 型和 B 型分别提取内部图案作为二值蓝图：在 2x2 图案中，非背景(非0)像素位置为活跃。
4. 将每个蓝图缩放到 5x5 单元阵列级别：蓝图中的活跃位置对应阵列中应放置该少数图案的单元。
5. 对阵列中每个单元确定输出图案：
   - 若该位置仅被 A 蓝图标记为活跃 → 填入 A 型图案。
   - 若该位置仅被 B 蓝图标记为活跃 → 填入 B 型图案。
   - 若该位置被两个蓝图同时标记 → 填入出现次数更少的那种少数图案（A 型次数 < B 型次数，所以填 A 型）。
   - 若该位置不被任何蓝图标记 → 保持 M 型图案。
6. 输出网格保持与输入相同的尺寸和分隔线结构。

**关键洞察**：源题 b99e7126 只有一种少数图案，缩放后直接填充即可；源题 281123b4 的叠加优先级由固定的循环位置决定。这里两种分形蓝图在同一网格上竞争，优先级由蓝图源的稀有度（出现次数）决定——这是源题中不存在的"稀有度→优先级"结构关系。

## 新题 3：去重压缩后提取镜像周期

**组合逻辑**：[压缩](保留) → [裁剪+镜像周期提取](创新：压缩结果不是最终输出而是周期检测的输入)

**来源原语**：压缩/compress(来自 ce8d95cc) + 裁剪/crop(来自 2dee498d) + 镜像/mirror(来自 2dee498d) + 重复行/dup_row(来自 ce8d95cc) + 重复列/dup_column(来自 ce8d95cc) + 精灵体/sprite(来自 2dee498d) + 瓦片/tile(来自 2dee498d) + 相邻相同/adjacent_identical(来自 ce8d95cc) + 周期/period(来自 2dee498d) + 相同行列合并/merge_identical(来自 ce8d95cc) + 最小周期含翻转/smallest_period_flipped(来自 2dee498d)

**依赖链**：输入有大量重复行列 → 压缩去重 → 压缩结果中隐藏着水平镜像周期 → 提取最小周期块。不先压缩则周期被拉伸干扰无法检测；不做周期提取则压缩结果仍含冗余。两步实质性耦合。

输入网格沿两轴做了行程扩展，压缩去重后的结果是一个水平镜像平铺的图案，需进一步提取最小重复周期。

**输入结构**：约 18x24 的网格，前景使用 2~3 种颜色（从蓝(1)、红(2)、绿(3)、黄(4) 中选取），背景为黑(0)。网格是一个小图案经过两步膨胀后的结果：(a) 原始图案为一个约 3x3 的精灵体；(b) 先将精灵体水平平铺 3~4 次，相邻副本间允许左右翻转或上下翻转；(c) 再将平铺结果沿两轴做行程扩展——每行和每列被随机复制 1~3 次，产生连续相同的行/列段。不同示例中，精灵体形状不同、翻转方式不同、扩展倍率不同。

**规则**：
1. 从上到下扫描行，保留每段连续相同行的第一行；从左到右扫描列，保留每段连续相同列的第一列。取交集得到压缩后的网格。
2. 在压缩后的网格上，从最小宽度开始尝试候选周期 W（W 必须整除压缩后网格宽度）。
3. 对每个候选 W，将压缩网格切成等宽的列块。检验每个块是否与第一个块完全相同、或是第一个块的水平翻转、或是第一个块的垂直翻转、或是第一个块的 180° 旋转。
4. 选取满足条件的最小 W，输出压缩网格的最左侧 W 列宽的块作为最终结果。

**关键洞察**：源题 ce8d95cc 的压缩是终点操作（压缩即输出）；源题 2dee498d 的周期提取直接作用于输入。这里压缩是中间步骤，其输出的尺寸直接影响周期检测的候选集。若跳过压缩，扩展后的重复行列会制造虚假的更大周期；若跳过周期提取，压缩结果仍含多个翻转副本。

## 新题 4：射线紧缩重塑墙体后描内边框

**组合逻辑**：[压缩/紧缩至锚](创新：紧缩不是美化而是改变拓扑) → [洪泛填充] → [描边/draw_inner_border]

**来源原语**：压缩/compact_to_anchor(来自 f28a3cbb) + 洪泛填充/flood_fill(来自 8f3a5a89) + 描边/draw_inner_border(来自 8f3a5a89) + 锚块/anchor_block(来自 f28a3cbb) + 射线像素/ray_pixel(来自 f28a3cbb) + 封闭区域/enclosed_region(来自 8f3a5a89) + 墙壁障碍/wall_barrier(来自 8f3a5a89) + 同色射线归属锚块/ray_belongs_anchor(来自 f28a3cbb) + 可达性/reachability(来自 8f3a5a89) + 射线像素紧缩至锚/compact_to_anchor(来自 f28a3cbb) + 边界连通区分结构/border_connected_distinguishes_structural(来自 8f3a5a89)

**依赖链**：散落的同色射线像素 → 紧缩至各自 3x3 锚块旁 → 紧缩后的彩色块体与蓝墙共同形成新障碍网络 → 从网格角落洪泛找可达区域 → 可达区域中紧邻障碍的背景像素描橙边框 → 不可达区域中的孤立蓝墙碎片被擦除。三步中任何一步的输出都是下一步的必要输入。

将散落的射线像素压缩回各自的锚块后，新形成的彩色块体连同蓝墙共同构成障碍，再通过洪泛填充识别封闭区域并描绘内边框。

**输入结构**：约 20x20 的网格，背景为黑(0)。包含 2~3 个 3x3 的纯色锚块（每个锚块用不同颜色，从红(2)、绿(3)、黄(4) 中选取），每个锚块的同色像素还散布在沿该锚块的行、列、或 45° 对角线方向上的远处位置（每条射线方向上有 1~4 个散落像素）。此外，蓝(1) 像素构成若干墙段（3~10 像素的直线段），部分与网格边界相连（结构性墙），部分完全在内部不连边界（装饰性墙）。生成约束：紧缩完成后，锚块加其紧缩后的射线像素与结构性蓝墙共同围出至少 1 个封闭区域；装饰性蓝墙位于封闭区域内部。

**规则**：
1. 对每种前景颜色（非黑非蓝），找到该颜色的 3x3 实心锚块。该颜色的所有其他像素都是射线像素。
2. 对每个射线像素，确定它与锚块的方位关系（行对齐、列对齐、或 45° 对角线对齐）。沿该方位将射线像素向锚块方向平移，紧贴锚块或已紧缩的同色像素放置（按距离从近到远依次紧缩，像素互不重叠）。
3. 紧缩完成后，将所有非黑像素（彩色锚+紧缩像素+蓝墙）视为障碍。
4. 从网格四条边界出发，通过黑(0) 像素 4-连通洪泛标记所有可达区域。
5. 在可达区域中，每个黑像素若 4-邻域内存在障碍像素或位于网格边界，则涂为橙(7)（内边框）。
6. 不可达区域中的蓝(1) 像素（装饰性墙碎片）擦除为黑(0)。
7. 所有彩色锚块和紧缩后的射线像素保持不变。不可达区域的黑像素保持黑(0)。

**关键洞察**：源题 f28a3cbb 中射线紧缩是纯粹的美化操作（输出更整齐）；源题 8f3a5a89 中墙体是固定输入。这里紧缩操作实质性地改变了障碍物的几何形状——散落的像素不构成屏障，紧缩后的密实块体才构成有效墙壁。拓扑结构（封闭与否）完全取决于紧缩的结果。

## 新题 5：分隔线计数编码瓦片尺寸用于噪声修复

**组合逻辑**：[计数](创新：计数结果不是输出尺寸而是噪声修复的隐含参数) + [修复噪声]（两者通过"瓦片尺寸"这一隐含变量紧耦合）

**来源原语**：计数/counting(来自 7039b2d7) + 修复噪声/repair_noise(来自 135a2760) + 分隔线/separator_line(来自 7039b2d7) + 周期瓦片/periodic_tile(来自 135a2760) + 噪声像素/noise_pixel(来自 135a2760) + 框架分区/frame_partition(来自 135a2760) + 分区数决定尺寸/partition_count_determines_size(来自 7039b2d7) + 周期重复/periodic_repetition(来自 135a2760) + 忽略干扰项/ignore_distractors(来自 135a2760)

**依赖链**：灰分隔线 → 计数行段数 R 和列段数 C → 瓦片尺寸为 R x C → 用该尺寸对非分隔区域的噪声图案做逐残差位多数表决修复 → 输出单个干净瓦片。计数和修复通过瓦片尺寸参数耦合：不计数则瓦片大小不确定（多种尺寸都可能平铺），修复无唯一解；不修复则计数结果无用。

通过计数网格中分隔线划出的行段数和列段数得到隐含的瓦片尺寸，再利用该尺寸修复一块噪声周期图案，输出干净瓦片。

**输入结构**：约 16x16 的网格，背景为黑(0)。灰(5) 像素构成若干完整的水平行和垂直列（与 95a58926 的分隔行列类似，跨越整个网格宽度或高度）。这些灰行列将网格分成矩形区域。所有非灰区域作为一个整体，包含一个周期性平铺图案（使用 1~2 种颜色，从蓝(1)、红(2)、绿(3) 中选取），但有约 10%~20% 的像素被随机替换为错误颜色（噪声）。灰分隔线的行段数为 R（非分隔连续行的段数），列段数为 C（非分隔连续列的段数）。隐含的干净瓦片大小恰好为 R 行 C 列。生成约束：该 R x C 瓦片在非灰区域中至少沿每个轴重复 2 次；噪声不破坏灰分隔线本身。

**规则**：
1. 找出所有完全由灰(5) 填充的行和列，这些是分隔线。
2. 计算非分隔行的连续段数 R，计算非分隔列的连续段数 C。
3. 提取所有非灰像素位置。对每个非灰像素 (r, c)，计算其在瓦片中的残差位置 (r', c')，其中 r' = 该像素在非灰行序列中的序号 mod R，c' = 该像素在非灰列序列中的序号 mod C。
4. 对每个残差位置 (r', c')，收集所有映射到该位置的像素颜色，取多数表决（出现次数最多的颜色）作为干净瓦片在 (r', c') 的颜色。
5. 输出该 R x C 的干净瓦片。

**关键洞察**：源题 7039b2d7 中，分隔线计数直接产生输出网格尺寸——计数是终点操作。源题 135a2760 中，瓦片尺寸通过试探每个可能的小尺寸来推断。这里计数结果作为修复算法的输入参数，绕过了试探过程。求解者若不注意分隔线数量与瓦片尺寸的隐含对应关系，将面对一个尺寸不确定的噪声修复问题——多个尺寸似乎都能修复，但只有分隔线编码的那个尺寸才在所有示例中一致。

6. 将排名 2 的分量放置在右上角区域，顺时针旋转 90°。
7. 将排名 3 的分量放置在左下角区域，旋转 180°。
8. 将排名 4 的分量（最大）放置在右下角区域，顺时针旋转 270°。
9. 每个分量在其区域内左上角对齐（旋转后的边界框左上角与区域左上角重合）。

**关键洞察**：源题 b1fc8b8e 中四个副本相同，位置固定；源题 ed98d772 中旋转角度由象限位置决定。这里四个分量大小不同，面积排名同时编码位置和旋转——最小的分量不旋转且在左上角，最大的旋转最多且在右下角。求解者必须发现"面积→排名→(位置,旋转)"这一三重绑定关系。

## 新题 7：嵌套空心框的洪泛层级填色

**组合逻辑**：[洪泛填充](创新：多层嵌套产生层级深度而非二元内外) + [重涂色](创新：涂色由嵌套深度和框周长共同决定) + [擦除]

**来源原语**：洪泛填充/flood_fill(来自 7b6016b9) + 重涂色/recolor(来自 62ab2642) + 擦除/erase(来自 f21745ec) + 空心矩形/hollow_rect(来自 f21745ec) + 封闭区域/enclosed_region(来自 7b6016b9) + 连通区域/connected_region(来自 62ab2642) + 内外分区/in_out_partition(来自 7b6016b9) + 尺寸匹配/size_match(来自 f21745ec) + 墙分隔区域/wall_partitions_regions(来自 62ab2642) + 极值面积决定颜色/extreme_area_determines_color(来自 62ab2642) + 边界连通分内外/border_in_out(来自 7b6016b9)

**依赖链**：识别多个空心矩形框 → 确定嵌套关系（哪个框在哪个框内部） → 计算嵌套深度 → 洪泛填充按深度分层 → 奇数深度涂一种颜色、偶数深度涂另一种 → 不嵌套任何区域的最内层框被擦除。嵌套判定需要框的几何关系，填色需要深度信息，擦除需要嵌套拓扑——三者互相依赖。

多个空心矩形框相互嵌套，根据嵌套深度交替填色：外部为绿、第一层封闭区域为红、第二层为绿，依此类推；不包含任何内层的最小框被擦除。

**输入结构**：约 18x18 的网格，背景为黑(0)。包含 3~5 个不同颜色的空心矩形框（一像素宽边框），颜色从蓝(1)、红(2)、绿(3)、黄(4)、灰(5) 中选取。矩形框可以嵌套（一个完全在另一个内部），但不交叉（边框不重叠）。嵌套深度至少为 2 层（即至少有"外框→中框→内框"的结构）。每个框的内部为黑(0)。生成约束：相邻嵌套框之间至少隔 1 像素黑色间隙；最内层至少有 1 个框不包含任何其他框。

**规则**：
1. 识别所有空心矩形框（每种非黑色恰好构成一个一像素宽的矩形边框）。
2. 建立嵌套关系：框 A 嵌套在框 B 内部，当且仅当 A 的边框所有像素都在 B 的内部区域中。
3. 确定每个框的嵌套深度 D：不被任何框包含的最外层框 D=1，被一层框包含的 D=2，依此类推。
4. 对黑(0)背景区域按 4-连通分量分组。每个黑色分量的"区域深度"定义为包含它的最内层框的深度；网格外部（不被任何框包含）深度为 0。
5. 将深度为偶数的黑色区域（含外部，深度 0）涂为绿(3)。
6. 将深度为奇数的黑色区域涂为红(2)。
7. 若一个框是"叶框"（不包含任何其他框），则擦除该框的边框像素为背景色——具体颜色取决于该框所在区域的深度填色结果（即用上述规则确定的该深度对应的颜色覆盖框像素）。
8. 非叶框保留其原始边框颜色不变。

**关键洞察**：源题 7b6016b9 只有二元的内/外分区；源题 62ab2642 的区域着色仅取决于面积极值。这里嵌套创造了多层深度，深度的奇偶性决定颜色——这是一个需要递归拓扑分析才能确定的规则。叶框擦除规则增加了额外约束：求解者必须同时理解嵌套关系（谁包含谁）和深度奇偶性（决定涂色），且擦除操作依赖于涂色结果。

## 新题 8：中心竞争者的收缩射线与碰撞标记

**组合逻辑**：[生长+收缩](保留面积比较机制) + [射线延伸](创新：收缩的对象从缩退点发射射线) + [重涂色](创新：碰撞点产生新颜色)（三路耦合：面积决定角色，角色决定行为，行为产生交互）

**来源原语**：生长/grow(来自 df978a02) + 收缩/shrink(来自 df978a02) + 射线延伸/ray_extend(来自 ac605cbb/9344f635) + 重涂色/recolor(来自 ac605cbb) + 前景对象/fg_object(来自 df978a02) + 中心间隙/center_gap(来自 df978a02) + 标记像素/marker_pixel(来自 ac605cbb) + 轨迹线段/trail_segment(来自 ac605cbb) + 面积最大者/largest_area(来自 df978a02) + 轨迹交叉/trail_intersection(来自 ac605cbb) + 最大外扩余内缩/max_grow_rest_shrink(来自 df978a02) + 交叉产生对角线/cross_spawns_diagonal(来自 ac605cbb)

**依赖链**：面积比较 → 确定最大者（生长）和其余者（收缩） → 收缩者失去中心端像素，从该像素位置向外发射灰射线 → 最大者向外侧生长三像素帽 → 若两条灰射线相交，交点涂橙并沿左下对角线延伸橙线。面积→角色分配→几何变形→射线拓扑→碰撞检测，五步链式耦合。

四个围绕中心间隙的对象中，最大者向外生长，其余三个收缩并从收缩点向外发射灰色射线，射线交叉点产生橙色对角线。

**输入结构**：约 15x15 的网格，背景为黑(0)。有一个约 3x3 的黑色中心间隙区域。四个 4-连通的单色对象（各用不同颜色：蓝(1)、红(2)、绿(3)、黄(4)）分别从上、下、左、右四个方位指向中心间隙。每个对象由 4~10 像素组成，为不规则的连通形状，各自有一个像素最接近中心间隙（中心端像素）。四个对象的面积互不相同，且恰好有一个面积最大。生成约束：中心间隙与每个对象之间至少隔 1 像素；各对象沿其所在方位排列（上方对象的所有像素都在中心间隙上方等）。

**规则**：
1. 找到中心间隙——距四个对象边界框中心最近的背景连通区域。
2. 计算每个对象的面积，确定唯一面积最大者。
3. 对三个非最大对象：
   a. 找到其中心端像素（距中心间隙最近的那个像素）。
   b. 将该像素涂为黑(0)（收缩一像素）。
   c. 从该像素的原位置出发，沿远离中心的基本方向（上方对象向上、下方对象向下、左方对象向左、右方对象向右）发射灰(5) 射线，延伸直到碰到网格边界为止。
4. 对最大对象：
   a. 确定其远离中心的外侧方向。
   b. 找到该对象在外侧边缘的中间列（若水平方向的对象则为中间行），在该位置的外侧添加一个 3 像素的 T 形帽（沿外侧方向伸出 1 像素，并在垂直方向各扩展 1 像素），颜色与该对象相同。
5. 检查所有灰射线之间的交叉：若两条射线（一条水平一条垂直）在同一像素位置交叉，将该像素涂为橙(7)，并从该位置沿左下对角线方向逐像素延伸橙色线，直到碰到非黑像素或网格边界为止。
6. 所有未被修改的像素保持原色。

**关键洞察**：源题 df978a02 中生长/收缩是终态操作，不产生后续效果。源题 ac605cbb 中射线从固定标记发出，碰撞规则是预设的。这里收缩操作"释放"了一个像素位置，该位置成为射线的发射点——收缩不仅是形态变化，更是射线拓扑的起点。面积比较的结果（谁最大）间接决定了哪些方向会有射线、射线能否交叉、以及对角线出现在哪里。

## 新题 9：象限镜像叠加的密度优先级

**组合逻辑**：[镜像](创新：镜像类型由象限位置编码而非固定) + [透明叠加](保留) + [计数](创新：像素密度决定图层优先级而非循环位置)（三条独立规则必须同时正确才能得到正确输出）

**来源原语**：镜像/mirror(来自 2dee498d) + 透明叠加/transparent_overlay(来自 281123b4) + 计数/counting(来自 f931b4a8) + 四象限/four_quadrants(来自 f931b4a8) + 面板/panel(来自 281123b4) + 控制区域/control_region(来自 f931b4a8) + 图层优先级/layer_priority(来自 281123b4) + 像素数决定尺寸/pixel_count_sets_size(来自 f931b4a8，创新为像素数决定优先级)

**依赖链**：四个象限各自镜像变换（变换类型由位置决定）→ 变换后四个图层叠加为一个象限大小的输出 → 叠加冲突由原始（变换前）象限的前景像素密度解决。三条规则（位置→变换类型、密度→优先级、透明叠加机制）各自独立，但输出是三者的联合结果。

四个象限的图案分别经过位置编码的镜像变换后透明叠加，冲突像素由原始象限中前景像素最少者优先。

**输入结构**：一个偶数边长的正方形网格（如 12x12），由一行一列的灰(5) 十字线分成四个大小相等的象限（每象限约 5x5 或 6x6，不含分隔线本身）。每个象限内有一种独特的前景颜色（从蓝(1)、红(2)、绿(3)、黄(4) 中选取）的图案，背景为黑(0)。四个象限的前景像素数互不相同。不同示例中，图案形状不同、像素数不同、颜色分配不同。

**规则**：
1. 移除灰(5) 十字分隔线，提取四个象限的图案。
2. 对每个象限施加由其位置决定的镜像变换：
   - 左上象限：水平翻转（左右镜像）。
   - 右上象限：垂直翻转（上下镜像）。
   - 左下象限：180° 旋转（等价于水平+垂直翻转）。
   - 右下象限：不变换（保持原样）。
3. 计算每个象限在变换前的前景像素数量 N（非黑非灰像素的个数）。
4. 将四个变换后的象限叠加为一个象限大小的输出。叠加规则：
   - 黑(0)像素视为透明。
   - 若某位置只有一个象限有非透明像素，使用该像素。
   - 若多个象限在同一位置有非透明像素（冲突），选择原始前景像素数 N 最小的那个象限的颜色（更稀疏的图案优先）。
   - 若该位置所有象限都是透明的，输出黑(0)。
5. 输出仅为叠加后的单个象限大小的网格，不包含分隔线。

**关键洞察**：源题 281123b4 的叠加优先级由面板的循环位置固定决定（第三面板最前）。这里优先级由内容属性（像素密度）决定——更稀疏的图案总是可见的，更密集的被遮挡。求解者若假设位置决定优先级（如源题），会在多个示例间得到矛盾的结果；只有统计每个象限的像素数并发现"少即优先"规则才能一致解释所有示例。同时，镜像变换类型由位置编码——求解者需要同时独立发现两条规则。
