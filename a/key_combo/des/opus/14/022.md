## 新题 1：孔洞编码的角落位移

**组合逻辑**：[计数·背景孔洞](已有) → [复制·角落对象](创新：目标角由孔洞数参数化，不再固定为"下一角")

**来源原语**：
- 计数(op), 背景孔洞(obj), 孔洞数量唯一(cond) ← 358ba94e
- 复制(op), 角落对象(obj), 接触两边缘(rel), 顺时针到下一角(cond), 忽略干扰项(cond) ← bc93ec48

**依赖链**：孔洞计数产生整数 h，该整数直接参数化角落复制的目标位置（顺时针第 h 个角落）。删除计数则无法确定目标角；删除角落识别则无法确定搬移对象。

将锚定在角落的前景块按其内部孔洞数搬移到顺时针方向第 h 个角落，忽略非角落干扰块。

**输入结构**：
- 网格约 15x15，黑(0)背景。
- 2-4 个单色 4-连通前景块分别锚定在不同网格角落——每块的边界框同时紧贴该角的两条相邻边缘。每块前景像素数 8-12，边界框 5x5。
- 每块 5x5 边界框内部的背景像素即"孔洞"，孔洞数 h 在 {1, 2, 3} 中且各块互不相同。不同示例中同类对象的具体像素排布不同，但边界框始终 5x5。
- 网格中可能存在 1-2 个不触及任何角落的干扰前景块（边界框至多接触一条边缘），它们保持原位不参与搬移。
- 生成约束：任意两个角落对象搬移后的目标角不重合。

**规则**：
1. 识别角落对象：边界框同时触及网格两条相邻边缘的 4-连通前景块。其余前景块为干扰项，保持不动。
2. 对每个角落对象，计算其 5x5 边界框内的背景像素数量 h（1 <= h <= 3）。
3. 将该对象搬移到当前角落顺时针方向第 h 个角落（h=1 下一角，h=2 对角，h=3 前一角）。搬移时保持像素相对于边界框的排布不变，将边界框对齐到目标角的两条边缘。
4. 原位置的所有像素恢复为黑(0)背景。
5. 干扰块和已经是背景的区域保持不变。

**关键洞察**：孔洞数不是用于筛选异常值（如 358ba94e 中找唯一孔洞数的块），而是编码了搬移距离；需要对比多个示例才能归纳出"h 即顺时针步数"的映射，而非固定"总是移到下一角"。

## 新题 2：周期异常值定位与差异高亮

**组合逻辑**：[平铺·最小周期检测](已有) ⇄ [计数·异常值提取](创新：用周期共识定义"正常"，再定位偏离的周期单元) → [裁剪 + 重涂色](创新：仅输出异常单元并高亮差异像素)

**来源原语**：
- 平铺(op), 最小周期单元(obj), 列周期重复(rel), 最小周期扩展(cond) ← d8c310e9
- 裁剪(op), 计数(op), 前景块(obj), 异常值提取(cond), 孔洞数量唯一(cond) ← 358ba94e
- 重涂色(op) ← 009d5c81

**依赖链**：周期检测建立共识模板，共识模板是异常值检测的前提；异常值检测定位唯一偏离单元，裁剪和高亮依赖该定位结果。三个环节环环相扣——删除周期检测则无法定义"正常"；删除异常定位则无法确定裁剪范围。

从水平重复的周期图案中找到唯一有缺陷的周期单元，裁剪输出并将偏离像素高亮为红色。

**输入结构**：
- 网格约 8x24，单一前景色（如蓝(1)）在黑(0)背景上形成水平重复图案。
- 图案具有最小列周期 P（3 <= P <= 6），网格宽度为 P 的 4-6 倍。
- 所有周期副本中，恰好一个副本有 1-3 个像素与共识模板不同（可能是前景变背景或背景变前景）。其余副本完全一致。
- 不同示例中，P 值、前景图案形状和异常位置均不同。

**规则**：
1. 检测最小列周期 P：找到最小的 P 使得对每一行，至少 (宽度/P - 1) 个 P 宽列带的内容相同。
2. 将网格按 P 宽切分为若干周期单元。对每个像素位置 (r, c mod P)，取所有周期单元在该位置的多数值作为共识模板。
3. 找到恰好一个周期单元，其中存在与共识模板不一致的像素。
4. 输出该异常单元的裁剪（P 列宽 x 全高）。其中与模板一致的像素保持原色，与模板不一致的像素重涂为红(2)。

**关键洞察**：周期检测（d8c310e9 中用于补全）在这里反向使用——不是补全缺失部分，而是利用冗余副本建立共识以暴露异常。异常判定标准是"与其他副本不同"，而非某种绝对属性。

## 新题 3：实心条包络与标记射线的交叉标记

**组合逻辑**：[包络生成·逐步收缩](已有) + [射线延伸](已有) → [透明叠加·冲突检测](创新：两种独立生成的几何图形在重叠处产生第三种标记色)

**来源原语**：
- 包络生成(op), 实心条(obj), 菱形轮廓(obj), 中心对称(rel), 逐步收缩(cond) ← c97c0139
- 射线延伸(op), 标记像素(obj), 投射到引导线(rel) ← ac3e2b04
- 透明叠加(op), 图层优先级(rel) ← 6a11f6da

**依赖链**：包络生成和射线延伸分别产生两种几何结构，二者的空间重叠区域触发第三种颜色标记。删除任一生成过程，重叠区域不存在，第三种颜色无处产生。

围绕水平条生成菱形包络，从标记像素发射垂直射线，在射线穿过包络的交叉处标记特殊颜色。

**输入结构**：
- 网格约 17x17，黑(0)背景。
- 2-3 条水平实心条，每条由单一前景色绘制（如蓝(1)、绿(3)），厚度 1 像素，长度 5-9 像素，各条之间垂直间距足够大（至少 6 行），使生成的菱形包络互不重叠。
- 1-2 个灰(5)孤立像素，每个位于某条实心条的水平跨度范围内的列上，但不在任何条所在的行上。
- 生成约束：灰像素的列坐标落在至少一条实心条的左端列与右端列之间（含端点），保证射线与至少一个菱形包络有交集。

**规则**：
1. 对每条水平实心条，在其周围生成青(8)菱形包络：条所在行保持不变；条上方第 k 行和下方第 k 行各画一段青(8)水平线段，该线段比条短 k 像素（左右各缩 k），直到线段长度缩为 0。仅在背景像素上绘制青(8)。
2. 从每个灰(5)像素向上和向下发射垂直射线（同列），在背景像素上绘制灰(5)，射线延伸到网格边缘。射线不覆盖已有的实心条像素和青(8)包络像素。
3. 检测空间冲突：若某个像素位置同时处于射线列上且处于某个菱形包络区域内（即该位置在步骤 1 中本应被绘制为青(8)，同时在步骤 2 中本应被绘制为灰(5)），则将该位置绘制为红(2)。
4. 实心条的原始像素保持不变。灰(5)标记像素本身保留。

**关键洞察**：菱形包络和垂直射线是两个独立的空间生成过程，红(2)标记仅出现在二者"争夺"同一像素的位置。求解者必须分别理解两种生成规则，再推断出冲突标记逻辑——这不是简单的图层覆盖，而是冲突检测。

## 新题 4：标记定向投射与距离优先叠加

**组合逻辑**：[投影·接触边决定方向](创新：标记数量编码投射距离) + [透明叠加·图层优先级](创新：投射距离短者优先)

**来源原语**：
- 投影(op), 标记像素(obj), 小方块(obj), 接触边决定投影(rel), 颜色决定投影深度(cond) ← e39e9282
- 透明叠加(op), 图层优先级(rel), 底层最优先(cond) ← 6a11f6da
- 平移(op), 无重叠间距(rel) ← 5521c0d9

**依赖链**：标记的位置决定投射方向，标记的数量决定投射距离，两者共同确定目标位置。当多个投射结果空间重叠时，距离优先级规则决定最终颜色。方向→距离→冲突解决三层逻辑缺一不可。

将带有侧边标记的小方块沿标记指示方向投射，投射距离等于标记像素数，重叠时距离短的方块覆盖距离长的。

**输入结构**：
- 网格约 15x15，黑(0)背景。
- 3-4 个实心 3x3 小方块，每个方块使用不同的单一前景色（如蓝(1)、绿(3)、黄(4)、橙(7)）。
- 每个方块的恰好一侧（上、下、左或右）紧邻 1-3 个栗(9)标记像素，排成一行或一列紧贴该侧。标记像素数量在不同方块之间可以不同。
- 生成约束：方块初始位置互不相邻（间距至少 2 像素）；投射后至少存在一对方块的目标区域有重叠，以测试优先级规则。

**规则**：
1. 对每个方块，确定投射方向：栗(9)标记像素在方块的哪一侧，方块就向该侧的反方向投射（标记在上方 → 向下投射，标记在右侧 → 向左投射，以此类推）。
2. 投射距离 = 该方块侧边的栗(9)标记像素数量（1-3 格）。方块整体平移相应距离。
3. 清除所有方块和标记的原始位置（恢复为背景）。
4. 在目标位置绘制各方块。若两个方块的目标区域重叠，投射距离较短的方块优先（其像素覆盖在上层）。投射距离相同时，行坐标更小的方块优先。

**关键洞察**：标记不仅编码方向（哪一侧），还编码距离（几个像素），且投射方向与标记位置相反——这一"反向"规则需要对比多个示例才能确认。距离优先级更是隐蔽规则：仅在重叠发生时才可观察。

## 新题 5：控制条序列与面板掩码的布尔交集

**组合逻辑**：[生成序列·条长决定序列](已有) → [换行平铺](已有) → [布尔运算·双掩码交集](创新：序列生成的掩码与独立面板掩码取交集)

**来源原语**：
- 生成序列(op), 控制条(obj), 递增递减游程(obj), 长度递增后递减(rel), 条长决定序列(cond) ← 5d588b4d
- 换行平铺(op) ← 5d588b4d
- 布尔运算(op), 掩码区域(obj), 分隔行(obj), 对齐(rel), 双掩码交集输出(cond) ← 6430c8c4
- 面板(obj), 分隔行(obj), 位置对齐(rel) ← 0c9aba6e

**依赖链**：控制条长度 n 参数化序列形状，序列换行后生成第一层掩码；该掩码与第二面板的独立掩码取交集才得输出。删除序列生成则缺少第一层掩码；删除布尔交集则输出仅为序列图案。面板宽度同时约束序列的换行方式，产生非线性耦合。

用控制条长度生成递增递减序列并换行平铺为掩码，与分隔线下方的独立掩码取交集输出。

**输入结构**：
- 网格约 11x16，黑(0)背景。
- 一条全宽红(2)分隔行将网格分为上下两个等高面板（每个面板高 5 行）。
- 上面板：第一行左端有一段蓝(1)水平控制条（长度 n，2 <= n <= 5），其余像素为黑(0)背景。
- 下面板：黑(0)背景上有一个黄(4)前景掩码（4-连通连通分量，像素数 8-20，形状不规则）。
- 不同示例中，n 值和黄色掩码形状均不同。

**规则**：
1. 读取上面板第一行蓝(1)控制条长度 n。
2. 生成一维前景序列：蓝(1)游程长度依次为 1, 2, ..., n, n-1, ..., 2, 1，相邻游程之间插入 1 个黑(0)背景像素。
3. 将该序列按上面板宽度（= 网格宽度）逐行换行排列，形成一个与面板同尺寸（5 行 x 网格宽度）的二维蓝色掩码。最后一行不足部分用黑(0)填充。
4. 将蓝色掩码与下面板的黄色掩码逐像素对齐。输出一个面板大小的网格：在两个掩码均为前景的位置绘制绿(3)，其余位置为黑(0)。

**关键洞察**：序列的换行宽度等于面板宽度，这使得 n 不仅决定序列内容，还通过换行方式决定二维掩码的形状——改变面板宽度会导致相同 n 产生不同的掩码图案。交集运算再施加一层筛选，使最终输出同时受 n、面板宽度和下面板形状三者约束。

## 新题 6：锚点偏移的循环母题填充

**组合逻辑**：[循环填充·标记界定母题](已有) + [平移·锚定定位](创新：锚点列坐标参数化每次循环的水平偏移量)

**来源原语**：
- 循环填充(op), 标记列(obj), 母题行(obj), 空白后缀区(obj), 标记界定母题(rel), 循环重复(cond) ← 12422b43
- 擦除(op) ← 12422b43
- 平移(op), 锚定定位(rel) ← 7b3084d4
- 标记像素(obj) ← 7b3084d4, e39e9282

**依赖链**：灰标记界定母题内容（循环填充的输入），红标记的列坐标序列参数化每次循环副本的水平偏移（平移量）。删除灰标记则无法提取母题；删除红标记则所有副本无偏移，退化为普通循环填充。

提取灰标记界定的母题，在空白后缀区循环重复，每次重复按对应红标记的列位置做水平偏移。

**输入结构**：
- 网格约 10x18，黑(0)背景。
- 最左列（列 0）的顶部有一段连续的灰(5)像素（2-4 行），标记母题区域。这些行内包含一个由非黑非灰前景色（如蓝(1)）绘制的图案。
- 灰标记行下方，有 2-4 个红(2)孤立像素散布在不同行上（每行至多一个），列坐标各不相同。红像素之间至少间隔一行。
- 最低红像素下方到网格底部为全背景的空白后缀区（至少 6 行，足以容纳 2 个以上母题副本）。
- 生成约束：母题宽度不超过网格宽度的一半，使偏移后母题不会完全超出网格。

**规则**：
1. 提取母题：将灰(5)标记行中的图案复制出来，同时将灰(5)像素替换为黑(0)背景。母题高度 = 灰标记行数。
2. 收集所有红(2)像素的列坐标，按行从上到下排列为偏移序列 [c1, c2, ..., ck]。
3. 从空白后缀区的第一行开始，逐次写入母题副本。第 i 次副本（i 从 1 开始）的每个像素水平右移 c_{((i-1) mod k) + 1} 列。若右移后像素列坐标超出网格宽度，则从左侧环绕（列坐标 mod 网格宽度）。
4. 副本之间紧密排列（无间隔行），循环直到空白后缀区填满。最后一个副本若超出网格底部则截断。
5. 擦除所有红(2)像素（恢复为背景）。原母题区域保留替换灰色后的内容。

**关键洞察**：红标记像素的列坐标不是空间布局的一部分，而是对循环填充偏移量的编码。偏移序列本身也被循环使用，产生周期性的水平错位图案——求解者必须同时理解"灰→母题内容"和"红列坐标→偏移指令"两层编码。

## 新题 7：孔洞数定包络尺寸与标记色定包络颜色

**组合逻辑**：[计数·背景孔洞](已有) → 包络半径 + [标记像素颜色](已有) → 包络颜色 ⇒ [包络生成](创新：尺寸与颜色由两个独立属性分别决定)

**来源原语**：
- 计数(op), 前景块(obj), 背景孔洞(obj), 孔洞数量唯一(cond) ← 358ba94e
- 包络生成(op), 菱形轮廓(obj), 中心对称(rel), 逐步收缩(cond) ← c97c0139
- 标记像素(obj), 接触边决定投影(rel) ← e39e9282
- 擦除(op) ← 009d5c81

**依赖链**：孔洞数独立决定包络半径，标记颜色独立决定包络颜色。两个属性分属不同来源（块内部结构 vs. 外部标记），缺少任一属性都无法完全确定输出——删除孔洞计数则包络大小未知，删除标记颜色则包络颜色未知。

围绕带孔洞的前景块生成正方形包络框，框的厚度等于孔洞数，框的颜色由邻近标记像素的颜色决定。

**输入结构**：
- 网格约 20x20，黑(0)背景。
- 3-4 个灰(5) 4-连通前景块，每块边界框 5x5，块有实心灰色外壳但内部包含 1-3 个背景孔洞（各块孔洞数互不相同）。不同示例中块的具体像素排布不同。
- 每块附近（边界框外 1-2 像素处）有一个孤立的非灰非黑像素（颜色为蓝(1)、红(2)或绿(3)之一），作为该块的颜色标记。每块恰好关联一个标记（取最近的标记，各标记与各块一一对应）。
- 各块之间间距足够大（边界框间距至少 8 像素），使最大包络（3 层厚）也不会重叠。
- 生成约束：标记与最近块的距离唯一确定配对（无歧义）。

**规则**：
1. 对每个灰(5)前景块，计算其 5x5 边界框内的背景像素数 h（1 <= h <= 3）。
2. 将每个标记像素与距离其边界框中心最近的前景块配对。
3. 以该块的 5x5 边界框为核心，向外扩展 h 层正方形边框（第 1 层为 7x7 的最外圈像素，第 2 层为 9x9 的最外圈像素，以此类推）。每层边框颜色 = 配对标记像素的颜色。仅在背景像素上绘制边框。
4. 擦除所有标记像素（恢复为背景）。原灰色前景块保持不变。

**关键洞察**：包络的两个参数（尺寸和颜色）由两个完全独立的信息源编码——尺寸来自块的内在拓扑属性（孔洞数），颜色来自外部标记的色彩。求解者必须分别发现两条独立规则并同时应用，任一规则的缺失都会导致输出不确定。

## 新题 8：交替旋转的周期平铺

**组合逻辑**：[平铺·最小周期检测](已有) + [旋转·整图半周旋转](创新：180 度旋转仅施加于偶数编号的周期副本，奇数副本不变)

**来源原语**：
- 平铺(op), 补全(op), 最小周期单元(obj), 局部图案(obj), 列周期重复(rel), 最小周期扩展(cond) ← d8c310e9
- 旋转(op), 画布(obj), 整图半周旋转(cond) ← 6150a2bd

**依赖链**：周期检测确定基本瓦片，旋转规则决定每个副本的朝向。删除周期检测则无法确定瓦片宽度；删除旋转规则则退化为简单平铺。两者耦合点在于：瓦片内容和旋转状态共同决定每一列的最终像素值。

检测最小列周期，用交替的正向和 180 度旋转副本铺满网格宽度。

**输入结构**：
- 网格约 7x20，黑(0)背景上有单一前景色（如蓝(1)）绘制的图案。
- 图案从左边缘开始，占据前 2P 列（P 为最小列周期，3 <= P <= 5），其中前 P 列和后 P 列的内容呈 180 度旋转关系。网格右侧剩余列为全背景。
- 图案在 P 宽度内不具有 180 度旋转对称性（否则交替规则不可观察）。
- 不同示例中，P 值和图案内容不同。

**规则**：
1. 检测最小列周期 P：从可见的前 2P 列中推断——前 P 列为基本瓦片 T，后 P 列为 T 的 180 度旋转。
2. 从左到右用交替副本填充整个网格宽度：第 1 个副本（列 0 至 P-1）为 T；第 2 个副本（列 P 至 2P-1）为 T 旋转 180 度；第 3 个副本为 T；第 4 个为旋转 T；以此类推。
3. 若最后一个副本超出网格宽度，截断到网格右边缘。

**关键洞察**：与简单平铺（d8c310e9）不同，这里的"周期"实际为 2P——但基本构造单元仍是 P，只是奇偶副本的朝向不同。若求解者仅检测表观周期 2P 并简单重复，在 P 非对称时可以得到相同结果，但更深层的理解是交替旋转。需要对比多个示例（不同 P 值）来排除"纯 2P 周期"的假说。

## 新题 9：形状编码的补全颜色

**组合逻辑**：[补全·缺失像素填充](已有) + [形状编码颜色·按形状映射](创新：形状编码的不是重涂色目标，而是补全填充所用的颜色)

**来源原语**：
- 补全(op), 连通分量(obj), 包围盒内部(rel), 缺失像素异色补(cond) ← 60b61512
- 重涂色(op), 擦除(op), 标记字形(obj), 形状编码颜色(rel), 按形状映射颜色(cond) ← 009d5c81

**依赖链**：标记字形的形状决定补全颜色，而补全颜色必须已知才能填充缺失像素。删除形状解码则补全颜色不确定；删除补全操作则形状解码无处施用。

每个不完整前景块由邻近标记字形的形状决定其缺失像素的填充颜色，填充后擦除标记。

**输入结构**：
- 网格约 15x15，黑(0)背景。
- 3-4 个不完整的黄(4) 8-连通前景块，每块位于一个 3x3 边界框内，框内有 1-3 个黑(0)缺失像素。不同块的缺失位置不同。
- 每块的边界框外 2-3 像素处，有一个 3x3 灰(5)标记字形。每个标记字形具有不同的灰像素排布（如十字形、L 形、对角形等，3-5 个灰像素组成）。同一字形形状在所有示例中映射到同一颜色。
- 标记字形与前景块的配对由空间邻近性决定（取边界框中心距离最近的配对）。每个标记恰好对应一个块。
- 生成约束：各块和标记之间间距足够大，配对无歧义。

**规则**：
1. 将每个灰(5)标记字形与最近的不完整黄(4)块配对（按边界框中心距离）。
2. 解码标记字形的形状以确定填充颜色——该映射需从训练示例中归纳（例如：十字形 → 红(2)，L 形 → 蓝(1)，对角形 → 绿(3)）。
3. 对每个黄(4)块，将其 3x3 边界框内的所有黑(0)缺失像素填充为步骤 2 确定的颜色。
4. 擦除所有灰(5)标记字形像素（恢复为背景）。黄(4)像素保持不变。

**关键洞察**：在 60b61512 中所有缺失像素统一填橙色，在 009d5c81 中形状编码用于大面积重涂色。此题将两者交叉——形状编码针对的是小尺度补全的填充色，且每个块可能获得不同颜色。求解者必须同时理解空间配对规则和形状-颜色映射表。

## 新题 10：引导线上的自宽平移与垂直射线连接

**组合逻辑**：[平移·移动自身高度](创新：改为沿引导线方向移动自身宽度) + [射线延伸·投射到引导线](创新：射线从平移后的新位置发出，连接相邻引导线)

**来源原语**：
- 平移(op), 实心矩形(obj), 无重叠间距(rel), 移动自身高度(cond) ← 5521c0d9
- 射线延伸(op), 引导线(obj), 投射到引导线(rel), 交叉点印章环形(cond) ← ac3e2b04
- 标记像素(obj) ← 7b3084d4

**依赖链**：平移改变矩形位置，射线从新位置发出。删除平移则射线起点错误；删除射线则输出仅为平移后的矩形。平移距离取决于矩形自身宽度（自适应参数），射线终点取决于下一条引导线的位置——两个几何约束分别来自对象属性和全局布局。

将引导线上的矩形沿引导线方向右移自身宽度，再从新位置的左上角向下发射射线直到触及下一条引导线，在交点处标记绿色。

**输入结构**：
- 网格约 16x16，黑(0)背景。
- 2-3 条全宽水平红(2)引导线（单像素厚的完整行），各引导线之间垂直间距至少 4 行。
- 每条引导线上有 1-2 个实心单色矩形（非红非黑色，如蓝(1)、黄(4)、橙(7)），矩形底边与引导线重合（矩形覆盖引导线上对应的像素）。矩形高度 2-3 像素，宽度 2-4 像素。同一引导线上的矩形之间有足够间距。
- 生成约束：每个矩形右移自身宽度后不会与同一引导线上的其他矩形重叠；最底部引导线上的矩形不发射向下射线（无下一条引导线可达）。

**规则**：
1. 对每个矩形，将其沿所在引导线方向向右平移，距离等于矩形自身宽度。若平移后超出网格右边缘，则从左边缘环绕。
2. 原位置恢复为红(2)引导线像素（矩形移走后露出引导线）和黑(0)背景（引导线行之上的矩形部分）。
3. 从每个矩形平移后位置的左上角像素出发，向下发射一条蓝(1)垂直射线。射线逐像素向下延伸，仅绘制在背景像素上，遇到红(2)引导线时停止（不覆盖引导线像素）。
4. 若射线到达了一条引导线，在该引导线上射线正下方的像素位置绘制一个绿(3)标记点（覆盖该处的红色）。
5. 最底部引导线上的矩形仅执行平移，不发射射线。

**关键洞察**：平移距离是自适应的（取决于矩形自身宽度，而非全局常量），这改变了射线的起始列；射线的终止条件又取决于下一条引导线的行位置。整条推理链中，矩形宽度→平移距离→射线起点→引导线交叉点→绿色标记，每一步的输出都是下一步的输入。
