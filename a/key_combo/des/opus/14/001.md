## 新题 1：噪声归并改变拓扑后的条件重涂

**组合逻辑**：[擦除/归并](已有，源自参考题20的噪声过滤) + [空洞检测](已有，源自参考题10的拓扑判断) → [条件重涂](创新：噪声处理改变对象的拓扑分类，分类结果反向决定涂色)

**来源原语**：擦除/erase、邻接/adjacency、邻接够归并否则删/merge_or_delete（参考题20 7e0986d6）；内部包含/interior_containment、含空洞对象重涂/objects_with_holes_recolored、重涂色/recolor（参考题10 b2862040）

**依赖链**：噪声像素的归并或删除直接改变前景对象的像素集合 → 某些原本有空洞的对象因噪声归并后空洞被填满 → 空洞检测的结果依赖噪声处理的空间副作用 → 最终重涂色由处理后的拓扑状态决定，而非原始拓扑。删除噪声处理则无法得到正确拓扑；删除拓扑检测则噪声处理无意义。

噪声像素的空间分布隐式编码了哪些对象将改变拓扑类型，从而决定最终涂色结果。

**输入结构**：约 15x15 网格，黑(0)背景。含 4-5 个单色 4-连通前景对象，每个对象使用不同颜色（从红(2)、绿(3)、蓝(1)、黄(4)中选取），每个对象形态为紧凑的连通区域（约 8-15 像素），内部恰好包含一个由背景色构成的 4-连通空洞（1-3 像素大小的封闭背景区域）。另有若干橙(7)孤立噪声像素散布于网格中：部分噪声像素紧邻某个前景对象边界（与该对象有 >= 2 个 4-邻接接触），部分噪声像素孤立于所有对象（与任何前景对象的 4-邻接接触 < 2 个）。关键布局约束：在部分前景对象中，紧邻空洞边缘存在噪声像素，归并后恰好能填满该空洞；在另一部分对象中，噪声像素虽紧邻对象但不在空洞附近，归并后空洞仍保留。生成时保证每个噪声像素最多与一个前景对象有 >= 2 的邻接接触，不存在同时紧邻两个不同对象的噪声像素。

**规则**：
1. 对每个橙(7)噪声像素，统计其与各前景对象颜色的 4-邻接接触数。
2. 若某噪声像素与某前景对象的同色邻接 >= 2，将该噪声像素重涂为该对象颜色（归并入对象）。
3. 若某噪声像素与所有前景对象的邻接均 < 2，将其擦除为黑(0)。
4. 噪声处理完毕后，对每个前景对象（此时可能已因归并而扩大）重新进行空洞检测：检查该对象的 4-连通像素集合是否仍包围至少一个 4-连通背景区域。
5. 仍然包含空洞的对象：将其全部像素重涂为青(8)。
6. 空洞已被噪声归并填满的对象（不再包含任何封闭背景区域）：保持原色不变。

**关键洞察**：噪声像素充当空洞的"塞子"——它们是否恰好位于空洞边缘决定了归并后对象的拓扑是否改变，从而间接控制了该对象的最终颜色。需要对比多个示例才能归纳出"拓扑改变与否决定涂色"这一隐蔽规则，因为单个示例中可能所有对象都属于同一类。

## 新题 2：对称性门控射线延伸

**组合逻辑**：[对称检测](已有，源自参考题5) → [条件分支筛选](创新：对称性类型匹配对齐方向才触发) → [射线延伸](已有，源自参考题16)

**来源原语**：对称检测/symmetry_detection、镜像轴/mirror_axis、对称否决定输出色/symmetric_vs_asym_color（参考题5 44f52bb0）；射线延伸/ray_extend、锚定方块/anchor_square、标记像素/marker_pixel、行列对齐/row_col_alignment、对齐标记连向锚点/marker_to_anchor（参考题16 d43fd935）；擦除/erase（参考题15 1f85a75f）

**依赖链**：每个标记像素关联一个 3x3 图案 → 图案的对称性类型决定该标记是否有资格发射射线 → 对齐方向与对称类型的匹配关系构成第二层筛选 → 仅通过双重筛选的标记执行射线延伸。删除对称检测则所有对齐标记都会发射（退化为参考题16）；删除射线延伸则对称检测无空间输出（退化为参考题5的布尔判断）。

检测每个标记的关联图案的镜像对称类型，只有对称类型与标记对齐方向匹配的标记才向锚定方块发射射线。

**输入结构**：约 15x15 网格，黑(0)背景。网格中央偏左或偏右处有一个 2x2 的绿(3)锚定方块。网格中散布 4-6 个单像素标记，每个标记颜色互不相同（从红(2)、蓝(1)、黄(4)、品红(6)、橙(7)、栗(9)中选取）。每个标记要么与锚定方块共享某一行（行对齐），要么共享某一列（列对齐），不存在同时行列对齐的标记。每个标记附近（曼哈顿距离 <= 2，不与其他元素重叠）有一个同色的 3x3 图案（该图案在黑(0)背景上，由标记色像素构成非全填充的连通形态，3-7 个前景像素）。生成时保证每个标记色在网格中恰好出现一个标记像素和一个 3x3 图案，且各图案之间、各标记之间互不重叠。

**规则**：
1. 对每个标记像素，定位其关联的 3x3 图案（网格中与该标记同色的唯一 3x3 区域）。
2. 对每个 3x3 图案检测两种镜像对称性：水平对称（第 0 行与第 2 行逐元素相同）和垂直对称（第 0 列与第 2 列逐元素相同）。
3. 行对齐标记（与锚定方块共享行）：仅当其图案具有水平对称性时，从该标记沿所在行向锚定方块方向延伸射线，逐像素涂上标记色，直到射线到达锚定方块的相邻列为止（不覆盖锚定方块本身）。
4. 列对齐标记（与锚定方块共享列）：仅当其图案具有垂直对称性时，从该标记沿所在列向锚定方块方向延伸射线，逐像素涂上标记色，直到射线到达锚定方块的相邻行为止。
5. 未通过对称性匹配的标记：擦除该标记像素（设为黑(0)）。
6. 所有 3x3 图案在输出中一律擦除（设为黑(0)），无论对称性检测结果如何。锚定方块和通过筛选的标记像素保留原色。

**关键洞察**：对称性检测不再输出布尔指示像素，而是充当射线延伸的准入门控；且门控条件并非"是否对称"的单一判断，而是"对称类型是否匹配对齐方向"的双重约束——水平对称放行行对齐标记，垂直对称放行列对齐标记。需对比多个示例才能归纳出类型与方向的对应关系。

## 新题 3：遮挡序列编码图案重复与逐份着色

**组合逻辑**：[遮挡序推断](已有，源自参考题11) → [计数](创新：路径长度即重复次数) + [重涂色序列](创新：路径顺序决定每份副本的颜色) → [裁剪 + 重复](已有，源自参考题2)

**来源原语**：遮挡顺序/occlusion_order、交叉处可见性/crossing_visibility、遍历所有颜色/traverse_all_colors、重绘/redraw（参考题11 c920a713）；裁剪/crop、重复/repeat、模板/template（参考题2 b0039139）；重涂色/recolor（参考题1 9aec4887）

**依赖链**：矩形边框的交叉遮挡构成有向图 → 唯一哈密顿路径产生颜色序列 → 序列长度决定模板重复次数 → 序列各位决定对应副本的涂色。删除遮挡分析则无法确定顺序和数量；删除重复则遮挡图无空间输出；两者通过"同一序列同时编码数量和颜色"紧密耦合。

从重叠矩形边框的交叉遮挡中推断唯一线性序列，该序列同时决定模板的重复次数和每份副本的颜色。

**输入结构**：约 20x20 网格，黑(0)背景。网格主体区域包含 3-5 个 1 像素厚的轴对齐矩形边框，每个边框使用不同颜色（从红(2)、蓝(1)、黄(4)、品红(6)、橙(7)中选取），各边框尺寸不同（宽 4-10、高 4-10），位置部分重叠使得每对边框的周长至少有一个交叉点。在交叉点处，某一颜色可见（覆盖另一颜色），记录遮挡方向。网格的一个角落区域（与边框区域间隔至少 2 行 2 列）包含一个灰(5)的小型非矩形连通图案（模板，3-6 像素），置于黑(0)背景上。生成时保证：各边框的交叉遮挡关系构成恰好一条哈密顿路径（无环、无分叉、覆盖所有颜色），且每个边框的完整矩形可从其可见像素的包围盒唯一推断。

**规则**：
1. 对每个边框颜色，取其所有可见像素的包围盒，推断该颜色的完整矩形边框。
2. 在两个边框的周长交叉处，检查可见颜色：若 B 色在 A 与 B 的交叉点处可见，则建立有向边 A -> B（B 遮挡 A）。
3. 在所有边框颜色构成的有向图中找到唯一的哈密顿路径，得到从"最底层"到"最顶层"的颜色序列 [C1, C2, ..., CN]。
4. 将角落的灰(5)模板裁剪至其包围盒。
5. 将裁剪后的模板沿垂直方向重复 N 次（N = 序列长度 = 边框数量），相邻副本之间插入 1 行黑(0)间隔。
6. 从上到下，第 i 份副本（i=1..N）的灰(5)像素重涂为颜色 Ci。
7. 输出仅包含重复着色后的模板堆叠，不包含原始边框。

**关键洞察**：矩形边框的交叉点处"谁覆盖谁"隐式编码了一条全局线性序列，该序列不只决定空间层级（参考题11的用途），还同时作为重复次数和逐份颜色映射的唯一信息源。需对比多个示例才能确定序列方向（最底层在前还是最顶层在前）以及模板堆叠的朝向。

## 新题 4：路径连通分组驱动质心扫描序循环着色

**组合逻辑**：[路径追踪](创新：从"寻找终点"改为"定义分组连通性") + [扫描序排序](已有，源自参考题13) → [循环颜色分配](创新：作用于分组而非单像素)

**来源原语**：路径追踪/path_follow、引导像素/guide_pixel、路径连接/path_connected、棋盘格/checkerboard（参考题9 9ba4a9aa）；排序/sort、扫描序/scan_order、长轴决定扫描/longer_axis_determines_scan、循环颜色分配/cyclic_color_assignment、孤立像素/isolated_pixel（参考题13 9473c6fb）；擦除/erase

**依赖链**：引导像素路径将孤立前景像素连接成若干分组 → 每个分组的质心位置决定排序依据 → 所有质心的分布范围决定扫描方向（行优先或列优先）→ 扫描序决定循环颜色分配。删除路径分组则每个像素独立着色（退化为参考题13）；删除循环着色则分组无输出效果；删除扫描序则无法确定分组顺序。

通过引导像素路径将散布的前景像素连接成分组，再按分组质心的空间分布确定扫描方向，最终以组为单位循环分配颜色。

**输入结构**：约 18x18 网格，灰(5)背景。网格中散布 8-12 个孤立的单像素前景点，颜色各异（从红(2)、蓝(1)、黄(4)、品红(6)、橙(7)、栗(9)中选取，同色像素可重复出现）。部分像素对之间由绿(3)引导像素链连接：引导像素沿水平或垂直方向排列，相邻引导像素间隔恰好 2 格（即在 2-cell lattice 上，与参考题9相同）。一条引导路径的两端各紧邻一个前景像素（4-邻接）。部分前景像素无任何引导路径连接（孤立成单元素组）。生成时保证：引导路径不分叉、不成环；每个前景像素最多被一条路径的一端触及；通过路径的传递连通性可将所有前景像素划分为 3-5 个不相交的分组，每组 1-4 个像素。

**规则**：
1. 构建连通图：两个前景像素若被同一条绿(3)引导路径的两端分别紧邻（4-邻接），则属于同一分组。通过传递性确定所有分组。
2. 计算每个分组的质心：分组内所有前景像素的行坐标平均值和列坐标平均值（取浮点数，不取整）。引导像素不参与质心计算。
3. 计算所有质心的包围盒（最小行到最大行、最小列到最大列）。若包围盒的行跨度 >= 列跨度，按质心行坐标升序排列各分组（行坐标相同时按列坐标升序）；否则按质心列坐标升序排列（列坐标相同时按行坐标升序）。
4. 按排列顺序对各分组循环分配颜色：第 1 组红(2)、第 2 组青(8)、第 3 组栗(9)、第 4 组红(2)、第 5 组青(8)......以此循环。
5. 将每个分组内所有前景像素重涂为该组分配的颜色。擦除所有绿(3)引导像素（设为灰(5)背景）。

**关键洞察**：引导路径在本题中不是导航路线（参考题9中用于从起点寻找终点），而是分组连接器——它定义了哪些孤立像素属于同一实体。循环颜色分配的单位从单个像素（参考题13）提升为像素组，且排序依据是组的质心而非组内任何单个像素的位置，这使得同组内像素可能分布在质心的不同侧却获得相同颜色。需对比多个示例才能归纳出"质心决定排序"而非"最高行像素决定排序"。

## 新题 5：半轮廓镜像补全后的拓扑分类与形态反转

**组合逻辑**：[镜像补全](已有，源自参考题8) → [拓扑分类](已有，源自参考题10/7，创新：作用于补全后而非原始形态) → [形态反转](创新：分类结果决定相反方向的变换——空心变实心、实心变空心)

**来源原语**：镜像/mirror、半侧轮廓/half_outline、对称轴/symmetry_axis、填充/fill、内部行段填充/fill_interior_spans（参考题8 bf32578f）；内部包含/interior_containment、含空洞对象重涂/objects_with_holes_recolored（参考题10 b2862040）；分类/classify、内部判定类型/interior_determines_type（参考题7 2ba387bc）；擦除/erase

**依赖链**：半轮廓必须先镜像补全才能判断拓扑 → 补全后的拓扑分类（有洞 vs 无洞）决定变换方向 → 变换方向相反于分类结果（有洞则填实、无洞则挖空）。删除镜像补全则形状不完整、无法判断拓扑；删除分类则不知该填还是该挖；删除变换则前两步无输出意义。三步形成不可跳过的推理链，且最终变换的方向由中间分类的结果反向决定，不是简单的流水线传递。

将不完整的半轮廓镜像补全为完整形状，依据补全后是否包含封闭空洞进行拓扑分类，然后对每个形状执行与其拓扑相反的变换——空心变实心、实心变空心。

**输入结构**：约 16x16 网格，黑(0)背景。包含恰好两个不同颜色的半轮廓（如红(2)和蓝(1)），分别位于网格的上半区和下半区，互不重叠且行范围不交叉。每个半轮廓是某个水平对称封闭轮廓的左半部分：由该颜色的前景像素构成一个 4-连通图形，其最右列即为对称轴的左侧。每个半轮廓的行跨度为 4-8 行，列跨度为 3-6 列，像素数 8-20。两个半轮廓的结构设计使得：其中一个镜像补全后形成的完整形状内部包含至少一个 4-连通封闭背景区域（空洞），另一个镜像补全后的完整形状内部无任何封闭背景区域（实心轮廓）。生成时保证各半轮廓镜像补全后的完整形状互不重叠（列范围充分分隔或行范围不交叉）。

**规则**：
1. 对每个半轮廓，确定其对称轴：取该半轮廓所有前景像素的最右列记为 col_R，对称轴位于 col_R 与 col_R+1 之间的虚拟半列位置。
2. 将半轮廓关于对称轴做水平镜像：对每个前景像素 (r, c)，生成镜像像素 (r, 2*col_R + 1 - c)。镜像像素使用与原半轮廓相同的颜色。原始半轮廓像素保留。
3. 对每个补全后的完整形状进行拓扑分类：检查该形状像素集合所围成的区域内是否存在 4-连通的封闭背景区域（即被形状像素完全包围、无法沿 4-邻接路径到达网格边界的背景像素连通分量）。有封闭区域者分类为"空心"，无者分类为"实心"。
4. 对"空心"形状执行填充：将其所有内部封闭背景区域的像素涂为该形状的颜色，使之变为实心。
5. 对"实心"形状执行挖空：仅保留 4-连通外边界像素（即与至少一个背景像素 4-邻接的形状像素），将所有非外边界的内部像素擦除为黑(0)，使之变为仅有 1 像素厚度的空心轮廓。
6. 输出包含两个变换后的形状，背景保持黑(0)。

**关键洞察**：半轮廓隐藏了完整形状的拓扑信息——无法直接从半边判断补全后是空心还是实心。而最终变换恰好与拓扑分类结果相反（空心 -> 填实、实心 -> 挖空），这一反转规则需对比两个不同形状在多个示例中的变化才能归纳出来，因为单看一个形状无法区分"规则是总是填充"还是"规则是依拓扑反转"。
