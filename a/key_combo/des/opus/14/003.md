## 新题 1：重力聚合后的多米诺配对与外轮廓描边

**组合逻辑**：[滑动/重力沉降] → [四邻接配对 + 配对则变色擦除](创新：配对对象由重力动态决定) → [轮廓描边](创新：对配对擦除后的空位描边，而非对实体描边)

**来源原语**：滑动/重力沉降(3618c87e)、四邻接配对/配对则变色擦除(d90796e8)、轮廓描边/外侧相邻(aa62e3f4)

**依赖链**：重力改变像素的垂直位置 → 新位置决定哪些异色像素形成4-邻接多米诺 → 多米诺配对后双方被擦除，产生特定形状的空洞 → 空洞的外轮廓被描边。删除重力步骤则无法确定配对关系；删除配对步骤则没有空洞可描边；删除描边步骤则输出不完整。

将散落的彩色像素下沉至底部，新形成的异色邻接对被擦除后，在其留下的空洞周围描绘外轮廓。

**输入结构**：约 12x12 网格，黑(0)背景。底行为灰(5)基线行。网格中上部散布若干红(2)像素和绿(3)像素，各自孤立（彼此不4-邻接），位于不同行不同列。另有少量蓝(1)像素作为干扰项（不参与配对）。生成约束：每列至多两个非背景非基线像素；重力沉降后恰好形成若干对红绿4-邻接多米诺（水平或垂直相邻），且不存在三个以上异色像素成链的情况；沉降前不存在红绿4-邻接对。

**规则**：
1. 识别基线色（底行颜色，灰(5)）和背景色（出现最多的颜色，黑(0)）。
2. 对每列从底到顶扫描，将每个非背景非基线像素下沉至该列最低的可用单元格（基线可被占据，即下落像素可替换基线位置）。
3. 沉降完成后，找出所有4-连通的红(2)-绿(3)多米诺对（恰好两个异色像素4-邻接）。蓝(1)像素和未配对的红/绿像素视为干扰项，保持不动。
4. 对每个多米诺对：将两个像素都擦除为背景色黑(0)，形成一个2-像素空洞。
5. 对每个空洞，找出其所有4-邻接的非空洞单元格（包括背景、基线、干扰像素），将这些单元格涂为橙(7)。若某单元格同时是两个不同空洞的4-邻接，仍涂为橙(7)（无冲突）。已有颜色的非背景像素（如蓝(1)干扰项）不被覆盖，仅背景和基线单元格被涂橙。
6. 网格尺寸不变。

**关键洞察**：沉降前红绿像素彼此远离，肉眼无法预判配对关系；必须先模拟重力确定最终位置，才能发现哪些像素成为多米诺。描边的对象不是实体而是擦除后的"负空间"——这与参考题 aa62e3f4 中对实体轮廓描边形成反转。

## 新题 2：格元居中归位后的形状频次重涂色

**组合逻辑**：[平移对齐/格元内居中] → [旋转翻转不变 + 形状频次分组](创新：分类以居中后的标准化位置为前提) → [重涂色](创新：重涂色由跨区域频次比较决定)

**来源原语**：平移对齐/格元内居中(20981f0e)、形状频次分组/旋转翻转不变/共享与唯一形状(62593bfd)、重涂色(604001fa)

**依赖链**：精灵图偏离格元中心 → 居中归位统一坐标系 → 归位后才能可靠比较各精灵的规范化形状 → 频次分类（共享/唯一）决定重涂色方案。若跳过居中步骤，同构形状因偏移不同会被误判为不同形状，导致频次分类错误。

将偏心的精灵图居中对齐到格元中心后，按旋转/翻转等价的形状出现频次将共享形状涂为一种颜色、唯一形状涂为另一种颜色。

**输入结构**：约 19x19 网格，黑(0)背景。红(2)标记像素形成规则的笛卡尔点阵（如 4x4 点阵，间距为 4 像素），将网格划分为等大格元。每个被占用的格元内有一个蓝(1)的4-连通精灵图（3~5 像素，边界框 2x2），但精灵图并未居中放置——其边界框左上角偏离格元中心位置。共约 8~12 个精灵图。生成约束：至少两组精灵图在旋转/翻转等价意义下形状相同（每组至少 2 个），且至少一个精灵图的形状唯一；精灵图的偏移量在不同格元中各不相同，使得未归位前直接像素比较会将同构形状判为不同。

**规则**：
1. 识别红(2)标记点阵及其间距，确定每个格元的边界。
2. 对每个含精灵图的格元，将精灵图平移至格元中心位置（边界框左上角置于标记点下方、右方各半个间距处），清除原始位置像素。
3. 对所有居中后的精灵图计算规范化形状：将像素坐标转为相对于边界框左上角的局部坐标，遍历4种旋转 x 2种翻转共8种变换，取字典序最小的像素集合作为规范形。
4. 统计每种规范形出现的次数。出现 2 次及以上的为"共享形状"，仅出现 1 次的为"唯一形状"。
5. 将所有共享形状的精灵图重涂为黄(4)；将所有唯一形状的精灵图重涂为橙(7)。
6. 红(2)标记点阵保持不变。

**关键洞察**：同一形状在不同格元中的不同偏移位置使它们表面上看起来完全不同；居中归位是形状比较的必要前置条件——跳过此步会把实际相同的形状误判为唯一形状，导致涂色错误。求解者需要从多个示例中归纳出"先归位再比较"这一隐含前提。

## 新题 3：精灵形状分类驱动的差异化同心色带填充

**组合逻辑**：[排序/形状频次分组 + 旋转翻转不变] ⇒ 分叉 → { 共享区域：[填充/同心色带(正序调色板)]，唯一区域：[填充/同心色带(逆序调色板)] }

**来源原语**：形状频次分组/旋转翻转不变/共享与唯一形状(62593bfd)、填充/同心正方形层/循环色带/距离决定调色板(13e47133)、标记像素(13e47133)、精灵体(6e4f6532)

**依赖链**：每个分区区域内同时包含标记像素（供调色板）和一个小精灵（供形状分类）→ 精灵形状需跨区域比较确定频次 → 频次结果决定该区域的调色板方向（正序/逆序） → 同样的标记配置在不同分类下产生完全不同的同心带图案。删除分类步骤则无法确定调色板方向；删除标记则无调色板可用。

根据各分区内嵌精灵的形状是否跨区域共享，决定该区域同心色带的调色板读取方向——共享区域从外到内、唯一区域从内到外。

**输入结构**：约 21x21 网格。灰(5)墙线将网格分隔为 4~6 个大小不等的封闭矩形区域。每个区域内部以黑(0)为底色，包含：(a) 2~4 个孤立标记像素，颜色各异（取自红(2)、绿(3)、黄(4)、蓝(1)、品红(6)），分布在距区域边界不同的切比雪夫距离处；(b) 一个 4-连通的小精灵（3~5 像素），颜色为栗(9)，位于区域内任意位置但不与标记像素4-邻接。生成约束：至少两个区域的精灵在旋转/翻转等价下形状相同，且至少一个区域的精灵形状唯一；不同区域的标记像素配置允许相同或不同；每条反对角线上的标记颜色不要求一致。

**规则**：
1. 识别灰(5)墙线，确定各封闭矩形区域。
2. 在每个区域中提取栗(9)精灵并计算其规范化形状（旋转/翻转不变，取8种变换中字典序最小者）。
3. 跨所有区域统计规范形频次：出现 2 次及以上 → 该区域标记为"共享"；出现 1 次 → 标记为"唯一"。
4. 在每个区域中，按各标记像素到区域边界的切比雪夫距离从小到大排列，读取其颜色组成调色板序列 P。若无标记位于边界上（距离 0），则黑(0)底色作为 P 的首元素。
5. 共享区域：直接使用 P 作为调色板；唯一区域：将 P 反转后使用。
6. 对区域内每个单元格，计算其到区域边界的切比雪夫距离 d，涂色为 palette[d mod len(palette)]。
7. 擦除所有栗(9)精灵像素（精灵仅用于分类，不出现在输出中）。灰(5)墙线保持不变。

**关键洞察**：标记像素配置完全相同的两个区域，仅因内含精灵的形状频次不同（共享 vs 唯一），就会产生截然不同的同心带图案——调色板相同但读取方向相反。求解者必须先跨区域比较精灵形状，才能确定每个区域的填充规则。仅看单个示例的一个区域无法判断调色板方向。

## 新题 4：凸耳镜像落体的碰撞重涂色

**组合逻辑**：[镜像 + 凸耳决定镜像轴] → [擦除原件] → [滑动/重力沉降] → [碰撞检测 + 重涂色](创新：重力后不同来源的镜像体碰撞时按面积决定涂色)

**来源原语**：镜像/凸耳/对侧放置/凸耳决定镜像轴(dc2e9a9d)、擦除(d90796e8)、滑动/重力沉降/基线行(3618c87e)、重涂色(604001fa)

**依赖链**：凸耳位置决定镜像方向 → 镜像生成红色副本于对侧 → 原件擦除后仅剩副本 → 重力使副本下沉 → 下沉后不同副本可能4-邻接（碰撞） → 碰撞时较小连通分量被重涂。每一步的输出实质性改变下一步的输入：镜像方向决定副本初始位置；初始位置决定重力路径；重力路径决定碰撞关系；碰撞关系决定涂色。

根据绿色轮廓的凸耳方向生成对侧镜像副本，擦除原件后让副本在重力作用下沉降，碰撞的副本中较小者被重涂。

**输入结构**：约 15x18 网格，黑(0)背景。底行为蓝(1)基线行。网格中上部散布 3~4 个4-连通的绿(3)空心轮廓对象（每个约 8~14 像素，形成闭合或近闭合的环形，边界框约 3x3 至 4x5）。每个绿色轮廓的边界框恰好有一侧包含一个单像素凸耳（该侧比对侧多出一个绿色像素）。各轮廓之间至少间隔 2 行 2 列。生成约束：镜像副本的初始位置不超出网格；重力沉降后至少有一对来自不同原始轮廓的副本发生4-邻接碰撞，且各碰撞对中两个副本的像素数不同（无需 tie-break）。

**规则**：
1. 对每个绿(3)轮廓对象，找到其边界框上含凸耳的一侧。
2. 在凸耳对侧、隔一个像素的位置，放置该轮廓的水平或垂直镜像副本，涂为红(2)。凸耳在左/右侧 → 水平镜像；凸耳在上/下侧 → 垂直镜像。
3. 擦除所有原始绿(3)像素为背景黑(0)。
4. 对所有红(2)像素施加重力：每个红像素下沉至其所在列的最低可用单元格（蓝(1)基线可被占据）。
5. 沉降完成后，检查所有红(2)连通分量（4-连通）。若两个分别来源于不同原始轮廓的连通分量之间存在4-邻接关系（至少一对像素4-相邻），则发生"碰撞"。
6. 对每组碰撞的两个分量：像素数较少的分量被重涂为黄(4)；像素数较多的保持红(2)。
7. 未碰撞的红(2)分量保持不变。蓝(1)基线行保持不变。

**关键洞察**：凸耳方向间接决定了碰撞结果——凸耳在左的轮廓向右镜像，凸耳在下的轮廓向上镜像，这些方向差异导致副本在重力后落入不同的列区间。求解者必须完整模拟"镜像→擦除→沉降→碰撞判定"四步链，任何一步跳过都无法得出正确涂色。

## 新题 5：多米诺预处理后的面板透明叠加

**组合逻辑**：[四邻接配对 + 配对则变色擦除](逐面板独立执行) → [透明叠加/非空标记合并](创新：叠加内容由配对预处理改变) → [冲突解决：按面板存活标记总数多者优先]

**来源原语**：四邻接配对/配对则变色擦除/忽略干扰项(d90796e8)、透明叠加/同尺寸面板/非空标记合并(7c9b52a0)、面板/分隔线(7c9b52a0)、计数(e3fe1151)

**依赖链**：多米诺配对改变面板内容（绿变青、红被擦除） → 改变后的内容参与叠加 → 叠加时同一位置可能有多面板贡献不同颜色 → 冲突解决需要统计每个面板中存活（非空）标记的总数 → 该总数因多米诺擦除而减少，所以配对结果影响冲突优先级。

在每个面板中先处理红绿多米诺对（绿变青、红擦除），然后将所有面板透明叠加；重叠位置取存活标记最多的面板之色。

**输入结构**：约 17x17 网格。品红(6)作为分隔色填充网格边缘及内部分隔条，将网格分为 4 个等大矩形面板（2x2 排列），每个面板约 7x7。面板底色为黑(0)，面板内散布稀疏彩色标记（每面板约 5~8 个非黑像素）。标记颜色包括红(2)、绿(3)、蓝(1)、黄(4)。部分红(2)与绿(3)像素形成4-邻接多米诺对，其余红/绿像素为未配对的干扰项。生成约束：四个面板形状相同；叠加后至少有 2 个位置存在多面板冲突（同一相对位置有两个或更多面板提供了非黑标记）；多米诺处理会使至少一个面板的存活标记数减少（因红像素被擦除），从而影响冲突优先级排序；不出现三个以上红绿像素成链的情况。

**规则**：
1. 识别品红(6)分隔色，确定四个等大面板及其相对坐标系。
2. 在每个面板内独立执行多米诺处理：找出所有4-连通的红(2)-绿(3)多米诺对；对每对，将绿(3)像素涂为青(8)，将红(2)像素擦除为黑(0)。未配对的红、绿像素保持原色不动。
3. 统计每个面板中存活的非黑标记总数（多米诺处理后）。
4. 创建一个与面板同尺寸的空白输出（全黑）。遍历每个相对位置：若仅一个面板在该位置有非黑标记，直接采用；若多个面板在同一位置有非黑标记，采用存活标记总数最多的面板的颜色；若存活标记总数相同，取在原网格中位置更靠左上（先比行再比列）的面板。
5. 输出为该单面板尺寸的网格。

**关键洞察**：多米诺处理不仅改变了个别像素的颜色，还通过擦除红色像素降低了面板的存活标记总数，从而削弱了该面板在叠加冲突中的优先级。一个面板可能在处理前拥有最多标记，但因含有较多多米诺对而在处理后丧失优先权。求解者需要先完成所有面板的多米诺处理，再全局比较存活数，才能正确解决冲突。

## 新题 6：角标裁剪后标记像素驱动的同心色带填充

**组合逻辑**：[裁剪 + 角标色决定重涂](创新：角标色不用于重涂而是注入调色板) → [擦除边框] → [填充/同心色带 + 距离决定调色板](创新：调色板由角标色与内部标记共同构成)

**来源原语**：裁剪/角标记像素/边框/中心图案/内部包含/角标色决定重涂(3de23699)、填充/同心正方形层/循环色带/距离决定调色板/标记像素(13e47133)

**依赖链**：角标像素定义裁剪边界 → 裁剪去框后得到内部区域 → 角标颜色被作为调色板首元素（距离 0 的色带） → 内部标记像素按切比雪夫距离排列提供后续调色板元素 → 同心色带覆盖整个内部区域。角标像素在此承担双重角色：既是空间定位锚点，又是调色板贡献者。

提取角标定义的矩形内部区域后，以角标颜色为最外层色带、以内部标记的距离排列为后续色带，用同心矩形框循环填充整个内部。

**输入结构**：约 18x18 网格，黑(0)背景。网格中有一团非黑像素组成的聚落。聚落的四角各有一个橙(7)角标像素，它们围成一个矩形区域。矩形最外一圈为蓝(1)边框像素。边框内部（中心图案区域）约 8x8 至 10x10，底色为黑(0)，其中散布 2~4 个孤立标记像素（颜色各异，取自红(2)、绿(3)、黄(4)、品红(6)），位于距内部区域边界不同的切比雪夫距离处。生成约束：各标记像素到内部边界的切比雪夫距离互不相同，确保调色板无歧义；内部区域足够大以展现至少 2 轮完整的色带循环。

**规则**：
1. 找到四个橙(7)角标像素，确定它们围成的矩形边界框。
2. 去除最外一圈蓝(1)边框，保留内部区域（即边界框向内缩一行一列）。
3. 构建调色板 P：以橙(7)（角标色）为 P[0]；然后按内部各标记像素到内部区域边界的切比雪夫距离从小到大排列，依次追加其颜色到 P。若无标记位于距离 1 处，该位置不填（调色板紧凑排列，不留空位）。
4. 对内部区域的每个单元格，计算其到内部区域边界的切比雪夫距离 d，涂色为 P[d mod len(P)]。此操作覆盖所有原有像素（包括标记像素本身和黑色底色）。
5. 输出为该内部区域的子网格（尺寸等于内部区域）。

**关键洞察**：在参考题 3de23699 中角标色用于重涂中心图案的颜色，这里角标色被创新地注入同心色带的调色板作为首元素——它在空间上标定了裁剪边界，在色彩上定义了最外层色带，两个角色通过"边界 = 距离 0"这一几何事实自然统一。求解者需要从多个示例中发现角标色总是充当调色板第一个元素这一隐含规则。

## 新题 7：格子连线填充与精灵空间过滤的汇聚

**组合逻辑**：{ [连线/共行或共列 + 双色交叉混合色] 与 [形状频次分组 + 旋转翻转不变] } ⇒ 汇聚 → [重涂色](创新：两条独立推理链的结果交叉作用)

**来源原语**：连线/格子单元/标记像素/网格线/共行或共列/双色交叉混合色(e760a62e)、形状频次分组/旋转翻转不变/共享与唯一形状(62593bfd)、精灵体(6e4f6532)、重涂色(604001fa)

**依赖链**：这是一个非线性汇聚结构——两条独立推理链并行执行后结果合并。链 A：红/绿标记像素沿格子行/列连线填充单元格，红绿交叉处变品红。链 B：蓝色精灵按规范化形状频次分为共享/唯一两类，唯一精灵被擦除，共享精灵保留。汇聚：被填充的格子单元格中，处于任何一个存活（共享）精灵的同格子行 AND 同格子列的单元格被重涂为黄色。两条链任缺其一都无法确定最终输出。

红/绿标记在格子中连线填充后，只有与共享形状精灵同行同列的已填充单元格被二次重涂为黄色。

**输入结构**：约 21x21 网格。青(8)格子线（单像素宽）将网格分割为规则的矩形单元格（如 5x5 个单元格，每个约 3x3 像素）。部分单元格内有一个红(2)或绿(3)标记像素（位于单元格中央）。另有部分空单元格内放置一个蓝(1)的4-连通小精灵（3~5 像素，边界框不超过单元格大小）。生成约束：红标记和绿标记各至少 4 个，且存在至少一个格子行或列同时含红和绿标记（产生交叉）；蓝精灵共 5~8 个，其中至少两个在旋转/翻转等价下形状相同（共享），至少一个形状唯一；至少一个共享精灵位于某个已填充单元格的同格子行且同格子列（触发重涂）。

**规则**：
1. 识别青(8)格子线，确定所有矩形单元格的位置及其格子行号/列号。
2. **链 A（连线填充）**：对红(2)标记，任何一格子行中含 2 个以上红标记的，填充该行中最左到最右红标记之间的所有单元格为红(2)；格子列同理。对绿(3)标记执行相同操作。单元格被红和绿同时填充的，涂为品红(6)。填充时保留青(8)格子线不变，仅改变单元格内部像素。
3. **链 B（精灵分类）**：提取所有蓝(1)精灵，计算规范化形状（旋转/翻转不变，8 种变换取字典序最小）。出现 2 次及以上的为"共享"，保留；出现 1 次的为"唯一"，擦除为黑(0)。
4. **汇聚（空间过滤重涂）**：遍历所有在步骤 2 中被填充的单元格（红、绿或品红）。若某填充单元格的格子行中存在一个存活的共享精灵，且该单元格的格子列中也存在一个存活的共享精灵（两个精灵可以是不同的），则将该单元格重涂为黄(4)。不满足此条件的填充单元格保持步骤 2 的颜色。
5. 存活的共享精灵保持蓝(1)。格子线保持青(8)。未被填充也未含精灵的单元格保持黑(0)。

**关键洞察**：连线填充和精灵分类是两个完全独立的子问题，但最终涂色需要将两者的结果在格子坐标系中交叉引用。单独看连线填充结果无法判断哪些单元格会变黄；单独看精灵分类也无法知道黄色影响区域。求解者必须同时完成两条推理链后才能合并结果。

## 新题 8：接触边界镜像与嵌入标记编码的负片色

**组合逻辑**：[镜像 + 接触边界定轴] → [负片色映射](创新：负片颜色不固定，由嵌入在前景形状内的 L-标记朝向编码) → [擦除标记]

**来源原语**：镜像/拼接/前景形状/接触边界定轴/负片色映射(6f473927)、标记朝向编码颜色(604001fa)、擦除(d90796e8)、标记体(604001fa)

**依赖链**：前景触碰的垂直边界确定反射轴 → 反射后需确定负片区域的填充色 → 填充色由嵌入前景内部的 L-标记朝向决定 → 标记必须在反射前读取（反射后标记形状会改变，无法正确解码） → 最终输出中标记被擦除。边界触碰决定空间结构，标记朝向决定颜色映射，两者缺一不可。

红色前景触碰一侧垂直边界，以该边界为轴水平反射拼接，反射半中原黑色区域涂为 L-标记朝向所编码的颜色，原红色区域变黑，标记从两半中擦除。

**输入结构**：约 10x8 网格（宽大于高），黑(0)背景。红(2)前景像素组成一个4-连通形状（8~15 像素，不规则，无对称要求），该形状触碰恰好一个垂直边界（左边界或右边界），不触碰另一个垂直边界，也不触碰水平边界。在红色前景形状内部（被红色像素包围的位置），有一个橙(7) L-三联骨牌标记：占据一个 2x2 区域中的 3 个单元格，缺失一个角。生成约束：L-标记完全在前景形状内部（其 4-邻接邻居全为红(2)或其他橙(7)标记像素）；前景形状足够大以容纳标记且标记位置唯一；网格宽度为偶数，使反射后两半等宽。

**规则**：
1. 确定红(2)前景触碰的垂直边界（左或右）。该边界即为反射缝。
2. 在反射前，读取前景内部的橙(7) L-标记。确定其 2x2 边界框中缺失角的位置，映射到颜色：缺左上角 → 绿(3)；缺右上角 → 青(8)；缺左下角 → 黄(4)；缺右下角 → 品红(6)。记此颜色为 C。
3. 水平反射整个网格。在反射半中：所有黑(0)像素 → C；所有红(2)像素 → 黑(0)；所有橙(7)像素 → 黑(0)。
4. 若前景触碰左边界：反射半在左，原始半在右。若触碰右边界：原始半在左，反射半在右。
5. 在原始半中，将所有橙(7)标记像素擦除为红(2)（标记仅用于编码，不出现在最终输出中，其位置恢复为前景色）。
6. 输出网格宽度 = 原始宽度 x 2。

**关键洞察**：参考题 6f473927 的负片色固定为青色，这里负片色被参数化——由嵌入前景内部的 L-标记动态编码。关键在于标记必须在反射前解码，因为反射会镜像翻转标记形状，使"缺左上角"变成"缺右上角"，导致解码错误。求解者需要从多个示例（不同标记朝向对应不同负片色）中归纳出角位到颜色的映射表。

## 新题 9：箭头推送像素后射线受阻的边框标记

**组合逻辑**：[箭头方向解码/横杆偏移定方向] → [滑动](创新：箭头不是自身移动，而是推送同行/列的游离像素) → [射线延伸 + 边框端点标记](创新：被推送的像素可能阻挡射线)

**来源原语**：箭头精灵/矩形边框/边框端点/朝向对齐/横杆偏移定方向(689c358e)、射线延伸/重涂色(689c358e)、滑动(3618c87e)、标记像素(928ad970)

**依赖链**：箭头横杆偏移确定指向方向 → 方向决定推送游离像素的移动方向 → 被推送像素的最终位置可能恰好落在箭头尖端到边框的射线路径上 → 射线被阻挡则不标记边框端点。箭头的指向同时控制两件事：推送方向和射线方向，而推送结果可能反过来阻止射线到达边框——这构成一个自我干涉环路。

箭头推送同行/列的游离像素沿指向方向滑动，然后从箭头尖端向边框发射射线；若射线路径被推送后的像素阻挡则不标记边框，否则将边框端点涂为箭头颜色。

**输入结构**：约 15x15 网格。最外一圈为灰(5)实心矩形边框（单像素宽）。边框内部底色为黑(0)。内部包含 3~4 个单色箭头精灵（非对称T形，由一条长4像素的杆和一条长3像素、偏向尖端一侧的横杆组成，共 6 像素），每个箭头颜色不同（取自红(2)、绿(3)、蓝(1)、黄(4)）。箭头方向由横杆偏移确定（横杆更靠近的一端为尖端）。内部还散布若干栗(9)游离像素（单像素），部分位于某箭头的同行或同列。生成约束：每个箭头的杆轴方向上（从短端到边框方向），同行或同列恰好有 0~2 个栗(9)像素；被推送的栗(9)像素到达最终位置后，至少有一个箭头的射线路径被阻挡，至少有一个箭头的射线路径未被阻挡；推送方向上栗(9)像素之间不会互相碰撞（间距足够）。

**规则**：
1. 识别灰(5)边框和内部区域。
2. 对每个箭头精灵，通过横杆偏移确定其指向方向（上/下/左/右）。
3. 对每个箭头，找到其杆轴延长线方向（从尖端到边框方向）上同行（水平箭头）或同列（垂直箭头）的所有栗(9)像素。将这些像素沿箭头指向方向滑动，直到碰到边框、另一个非背景像素或另一个已滑动到位的栗(9)像素时停止（不重叠，紧靠停止）。处理顺序：沿箭头指向方向，距边框最近的栗(9)像素先滑动。
4. 所有箭头的推送完成后（各箭头独立推送自己行/列上的栗(9)），从每个箭头的尖端沿指向方向发射射线。射线沿直线前进，若在到达边框前遇到任何非背景像素（包括被推送到位的栗(9)或其他箭头的像素），射线被阻挡，不标记边框。
5. 射线未被阻挡而到达边框的：将射线命中的边框像素涂为该箭头的颜色；将该箭头杆轴上对侧的边框像素涂为黑(0)。
6. 射线被阻挡的箭头：不对边框做任何操作。
7. 内部的箭头精灵、游离像素（包括已滑动的）和背景保持不变。

**关键洞察**：箭头通过推送游离像素可能无意中阻断了自己的射线——推送方向和射线方向相同，被推送的像素正好挡在射线路径上。这是一个"自我干涉"结构：箭头的指向同时驱动推送和射线，而推送的结果可能否决射线的效果。求解者需判断每个箭头是否会被自己推送的像素阻挡。

## 新题 10：十字分割镜像与区域多重集互补填充

**组合逻辑**：[十字图案/对称轴定义 + 镜像] → [计数/颜色多重集相同 + 各区域缺像素](创新：镜像在先改变各象限内容，再做多重集互补) → [填充]

**来源原语**：十字图案/前景遮罩/象限/对称轴定义/十字色作涂色源(47c1f68c)、镜像(47c1f68c)、计数/颜色多重集相同/各区域缺像素(e3fe1151)、分隔线/标记像素/填充(e3fe1151)

**依赖链**：十字图案将网格分为四个象限 → 上左象限的遮罩被镜像到其余三个象限（用十字色涂色） → 镜像后四个象限各自包含十字色像素和原有像素 → 统计各象限中非十字色、非背景像素的颜色多重集 → 取各色最大计数为目标多重集 → 各象限的缺失颜色在空白位置补齐。镜像改变了各象限的内容分布，使得多重集比较的基准发生变化。

十字线将网格分四象限，左上遮罩被镜像到其余象限后，四象限间进行颜色多重集互补，将各自缺少的颜色填入空位。

**输入结构**：约 15x15 网格（奇数边长），黑(0)背景。中央有一条完整的水平线和一条完整的垂直线，均为灰(5)，在网格中心交叉形成十字。上左象限中有一个由红(2)像素组成的不规则前景遮罩（4-连通，5~10 像素）。四个象限中各自还散布若干独立的彩色像素（取自蓝(1)、绿(3)、黄(4)、品红(6)），每个象限中有 2~4 个这样的像素，但各象限的颜色种类和数量不完全相同，且每个象限恰好有一个黑(0)空位（除背景大片黑色外，在非背景像素应占据的区域中恰缺一个）。生成约束：镜像遮罩不会覆盖已有彩色像素的位置（遮罩像素只落在黑(0)位置）；镜像后各象限的非灰、非黑像素颜色多重集互不完全相同但可通过各补一个像素达成一致；目标多重集由四个象限中各色最大计数定义，每个象限恰好缺一种颜色的一个计数。

**规则**：
1. 识别灰(5)十字线（中央行和中央列），确定四个象限。
2. 提取上左象限中的红(2)遮罩形状。
3. 将遮罩以十字线为轴镜像到其余三个象限：上右象限水平镜像、下左象限垂直镜像、下右象限中心对称镜像。镜像副本涂为灰(5)（十字色）。原始上左象限的红(2)遮罩也重涂为灰(5)。
4. 镜像完成后，在每个象限中统计所有非灰(5)、非黑(0)像素的颜色多重集。
5. 对每种颜色，取四个象限中该色出现次数的最大值，汇成目标多重集 T。
6. 对每个象限，将其当前多重集与 T 比较，找出缺失的颜色及数量（每个象限恰缺一种颜色的 1 个计数）。
7. 在每个象限中，找到唯一的黑(0)空位（该象限中被灰(5)遮罩和彩色像素占据后剩余的、位于象限有效区域内的空单元格），将其填为缺失颜色。
8. 灰(5)十字线和灰(5)遮罩像素保持不变。

**关键洞察**：遮罩的镜像在空间上为"多重集互补"创造了前提条件——镜像后的灰色像素占据了原本的空位，改变了各象限中"哪些位置是可用空位"的判定。如果不先做镜像，空位的位置和数量不同，多重集互补的结果也完全不同。两步操作通过"空间占位"紧密耦合。
