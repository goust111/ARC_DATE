## 新题 1：沿裂缝擦除后镜像修复

**组合逻辑**：[擦除](创新：擦除结果暴露镜像轴位置) + [面积比较](创新：比较两半大小以决定保留方向) + [镜像](创新：轴由擦除位置隐式确定，非显式整行/列/对角线)

**来源原语**：擦除(2faf500b)、裂缝标记线(2faf500b)、沿短轴分裂(2faf500b)、镜像(ad3b40cf)、面积比较(67385a82)、异常值选择(ad3b40cf)

**依赖链**：擦除裂缝线暴露对象的分裂结构 → 面积比较确定哪一半是"完好半"→ 镜像以裂缝位置为轴将完好半反射覆盖受损半。三步环环相扣：不擦除则无法确定轴位置；不比较面积则不知保留哪侧；不镜像则无法重建对称体。

将每个前景对象中的裂缝线擦除，然后将像素较多的完好半沿裂缝位置镜像反射，覆盖像素较少的受损半，使对象变为关于裂缝线对称的完整形状。

**输入结构**：约 18x18 的黑(0)背景网格。网格上有 3~5 个互不相邻的单色前景对象（每个对象使用蓝(1)、绿(3)、黄(4)中的一种，不同对象颜色可相同或不同），每个对象是 4-连通的不规则形状，约 10~20 像素。每个对象内部恰好有一条红(2)裂缝线——一条 1 像素宽的直线段（水平或竖直），贯穿对象较短轴方向，将对象分为两个 4-连通的半体。两个半体的像素数不同（一侧多、一侧少），且较多的那一半关于裂缝线呈镜像对称时，其反射恰好覆盖较少半的所有位置并可能多出若干像素。生成约束：每个对象的较多半沿裂缝线反射后不会超出网格边界，且不同对象的反射结果互不重叠。

**规则**：
1. 将所有红(2)像素擦除为黑(0)。
2. 对每个前景对象，识别原裂缝线的位置和方向（水平线或竖直线）。
3. 统计裂缝线两侧各自的前景像素数量，像素较多的一侧为"完好半"，较少的一侧为"受损半"。
4. 将完好半的每个像素沿裂缝线做镜像反射（水平裂缝则上下翻转，竖直裂缝则左右翻转），在反射位置绘制该对象的主体颜色。反射像素覆盖受损半的原有像素以及受损半中因不对称而缺失的位置。
5. 完好半的原始像素保持不变。最终每个对象成为关于裂缝线位置严格对称的形状。

**关键洞察**：裂缝线既是需要擦除的噪声特征，又是重建对称体的隐式镜像轴——它的双重身份将擦除和镜像操作紧密耦合。面积不对称是判断修复方向的唯一线索，必须对比多个示例才能确认"较多侧保留"这一规则（而非"左侧保留"或"上侧保留"）。

## 新题 2：框内标记计数驱动模板平铺次数

**组合逻辑**：[计数](创新：计数结果不渲染为视觉计数器，而是参数化另一操作的重复次数) + [平铺](创新：重复次数由计数动态决定，方向由模板与框的邻接位置决定)

**来源原语**：计数(c8b7cc0f)、框内包含(c8b7cc0f)、忽略干扰项(c8b7cc0f)、矩形框(c8b7cc0f)、标记像素(c8b7cc0f)、平铺(e8dc4411)、邻接触碰(e8dc4411)、模板(e8dc4411)

**依赖链**：计数框内标记 → 得到数值 N → N 决定模板向外平铺的次数；同时，模板与框的邻接侧决定平铺方向。计数和邻接分析缺一不可：没有计数则不知铺多少份，没有邻接分析则不知往哪铺。

统计每个矩形框内部的标记像素数量 N，然后将紧贴该框外侧的小模板形状向远离框的方向平铺 N 份。

**输入结构**：约 20x20 的黑(0)背景网格。网格上有 2~4 个橙(7)的 1 像素厚矩形框（内部空间 3x3 到 5x5）。框内散布着若干蓝(1)标记像素（1~5 个），框外也散布着若干蓝(1)干扰像素。每个框的外侧恰好有一个绿(3)的小模板形状（4-连通，2~4 像素的不规则小图形）紧贴框的某一条边（上/下/左/右），即模板中至少有一个像素与该框的外壁 4-相邻。不同框的模板贴靠方向可以不同。生成约束：每个框的模板平铺展开后不超出网格边界，不同框的平铺结果互不重叠。

**规则**：
1. 对每个橙(7)矩形框，统计严格位于框内部的蓝(1)像素数量 N（框外的蓝像素是干扰项，忽略）。
2. 确定该框外侧绿(3)模板贴靠的是哪一条边（上/下/左/右）。
3. 以模板自身的边界框尺寸为步长，沿远离框的方向（贴靠上边则向上，贴靠右边则向右，依此类推）依次放置 N 个模板的平移副本。第一个副本紧邻原始模板，第二个紧邻第一个副本，以此类推。
4. 所有副本使用绿(3)绘制，仅绘制模板形状中的非背景像素。
5. 原始框、框内标记、原始模板和所有干扰像素均保持不变。

**关键洞察**：框内标记数不是被渲染成计数图案（如 3x3 计数格），而是直接驱动了一个空间操作的重复参数。框外的同色标记是干扰项——必须对比多个示例才能确认"只计框内"这一规则。模板贴靠的边暗示了平铺方向，这一空间关系在任何源题中均不存在。

## 新题 3：枢轴旋转引发合并后按连通性重涂色

**组合逻辑**：[旋转/半周](原有) → [连通分量分析](创新：旋转后产生的连通性合并是涌现效应) → [重涂色](创新：颜色由合并后的连通分量成分决定)

**来源原语**：旋转(90347967)、枢轴像素(90347967)、点对称(90347967)、绕枢轴半周旋转(90347967)、重涂色(67385a82)、连通分量(67385a82)、面积比较(67385a82)

**依赖链**：180 度旋转改变所有形状的空间位置 → 原本分离的形状可能在新位置上 4-连通合并 → 合并后的连通分量被重涂色为品红(6)，未合并的保持原色。旋转是产生合并的唯一途径，合并判定依赖旋转后的位置，重涂色依赖合并判定——三步紧密耦合且存在涌现效应。

将所有前景形状绕灰色枢轴像素做 180 度点反射；反射后，因空间重排而与其他形状 4-连通合并的连通分量被重涂色为品红(6)，未发生合并的形状保持原色。

**输入结构**：约 15x15 的黑(0)背景网格。一个灰(5)枢轴像素位于网格的非中心位置。4~6 个小型前景形状散布于网格上，每个形状是单色 4-连通区域（2~5 像素），使用蓝(1)、红(2)、绿(3)、黄(4)中的不同颜色（每种颜色至多使用一次）。形状之间互不 4-相邻。生成约束：对所有形状做 180 度点反射后，恰好有部分形状在反射后的位置上与其他反射后的形状 4-连通相邻（即合并），其余形状反射后仍然互不相邻。所有反射位置不超出网格边界。同一形状不与自身的反射重叠。

**规则**：
1. 对每个非黑(0)、非灰(5)的前景像素 (r, c)，计算其关于灰(5)枢轴像素 (pr, pc) 的 180 度反射位置：(2*pr - r, 2*pc - c)。
2. 在输出网格中，将反射位置绘制为该像素的原始颜色。原始位置清除为黑(0)。灰(5)枢轴像素保持原位。
3. 在反射后的网格中，计算所有非背景、非枢轴像素的 4-连通分量。
4. 若某连通分量包含来自两个或以上原始形状的像素（即不同颜色的像素在反射后 4-相邻合并），将该连通分量的所有像素重涂色为品红(6)。
5. 若某连通分量的所有像素来自同一个原始形状（同色且反射后未与其他形状合并），保持其原始颜色不变。

**关键洞察**：品红像素标记了旋转后的"碰撞区"。求解者必须先模拟 180 度旋转得到新位置布局，再分析连通性以确定哪些形状合并——这是旋转操作的涌现效应，无法从单个形状的变换中预测。必须对比多个示例才能确认重涂色规则针对的是"跨色合并"而非"面积阈值"。

## 新题 4：格子拓扑分类控制重力滑动通道

**组合逻辑**：[洪泛填充/分类](创新：分类结果不是最终颜色，而是定义滑动通道的通行性) + [滑动](创新：滑动路径受格子拓扑约束，而非沿自由空间直线运动)

**来源原语**：洪泛填充(83302e8f)、格子框架(83302e8f)、封闭背景区域(83302e8f)、包含(83302e8f)、完整与缺损区异色(83302e8f)、滑动(3906de3d)、碰撞阻挡(3906de3d)、同列对齐(3906de3d)

**依赖链**：洪泛填充将背景区域分为完整单格（密封）和破损多格通道（连通）→ 破损通道构成可通行网络 → 前景像素沿重力方向在通道内滑动直至碰壁。格子分类决定哪些区域可通行，滑动路径完全依赖分类结果——分类不是终态而是约束。

分析破损格子的拓扑结构：密封的完整格子单元不可通行，破损处形成连通通道。将通道内的彩色像素沿边缘标记指示的重力方向滑动，直到碰到格子壁或网格边界。

**输入结构**：约 16x16 的黑(0)背景网格。绿(3)像素构成一个 1 像素厚的矩形格子框架（约 4x4 或 5x3 的格子阵列），部分格子线段缺失（断裂），使某些相邻格子单元的背景区域连通形成通道。格子内部分单元中各有一个彩色像素——使用红(2)、蓝(1)、黄(4)中的一种（每个单元至多一个像素，可有若干单元为空）。网格的某一条边（上/下/左/右）上有一个灰(5)像素，作为重力方向指示器（灰在底边表示重力向下，灰在右边表示重力向右，依此类推）。生成约束：每个彩色像素所在的格子单元要么是密封的完整单元，要么属于破损通道的一部分；在重力方向上，每个彩色像素的滑动终点位置不与其他彩色像素冲突（即不会两个像素滑到同一格）。

**规则**：
1. 对格子框架内的所有黑(0)背景区域做 4-连通洪泛填充分析。面积等于其边界框面积的区域是"密封单元"；面积大于边界框面积的区域是"破损通道"（多个单元因格子断裂而连通）。
2. 密封单元中的彩色像素无法移动，保持原位。
3. 破损通道中的彩色像素沿灰(5)指示的重力方向滑动：在通道的黑(0)空间内逐格移动，直到碰到绿(3)格子壁或网格边界时停止（停在壁前一格）。
4. 滑动时像素只能在通道内移动——不能穿过完好的格子壁段。
5. 密封单元填充为橙(7)以标记其密封状态；破损通道保持黑(0)。格子框架绿(3)像素和灰(5)指示器保持不变。

**关键洞察**：格子的拓扑完整性决定了每个像素的命运——密封单元中的像素被"锁定"，而破损通道中的像素可以沿重力滑动。求解者必须先分析格子拓扑（哪些缺口连通了哪些单元），再推断每个像素的运动路径。通道的形状决定了滑动路径的转弯方式，这在任何源题中都不存在。

## 新题 5：奇偶性选择性偏转流

**组合逻辑**：[流动绘制](创新：流的偏转响应取决于当前格的棋盘奇偶性) + [重涂色](创新：偏转带来的奇偶翻转改变后续偏转响应，产生级联效应)

**来源原语**：流动绘制(f15e1fac)、边缘起点像素(f15e1fac)、逐步偏移(f15e1fac)、对齐时偏移(f15e1fac)、奇偶性选色(5e6bbc0b)、棋盘格图案(5e6bbc0b)

**依赖链**：流路径逐格推进 → 每一格的棋盘奇偶性决定该格响应哪种颜色的偏转器 → 偏转改变行/列位置从而翻转奇偶性 → 翻转后的奇偶性改变对下一个偏转器的响应。奇偶性和偏转形成反馈环路：每次偏转都改变后续所有偏转的选择性，路径是整个反馈链的结果。

绿(3)源像素从左边缘向右流动。顶边上的蓝(1)偏转器和红(2)偏转器交替影响路径：当流路径所在格的棋盘奇偶性为偶时仅响应蓝偏转器，为奇时仅响应红偏转器。每次偏转使路径下移一格，从而翻转奇偶性，改变后续偏转响应。

**输入结构**：约 14x14 的黑(0)背景网格。左边缘上有 2~4 个绿(3)源像素，分布在不同行。顶边缘上有若干蓝(1)和红(2)像素作为偏转器，分布在不同列（蓝和红交替或随机排列，总共 4~8 个偏转器）。网格的其余部分全为黑(0)。棋盘奇偶性按 (行号+列号) % 2 定义：结果为 0 的格为偶性格，结果为 1 的格为奇性格。生成约束：源像素均位于偶性格（即源像素的行号+列号为偶数）；所有流路径在偏转后不超出网格下边界。

**规则**：
1. 每个绿(3)源像素从其位置开始，逐步向右移动（每步列号+1）。
2. 移动到新格后，检查当前格的棋盘奇偶性 P = (当前行 + 当前列) % 2：
   - 若 P = 0（偶性格），检查当前列的顶边是否有蓝(1)偏转器。若有，路径下移一行（行号+1），然后继续向右。
   - 若 P = 1（奇性格），检查当前列的顶边是否有红(2)偏转器。若有，路径下移一行（行号+1），然后继续向右。
   - 若当前奇偶性与顶边偏转器颜色不匹配（偶性格遇到红偏转器，或奇性格遇到蓝偏转器），不偏转，直接继续向右。
3. 流路径经过的每个格都绘制为绿(3)。
4. 流路径到达网格右边缘或下边缘时终止。
5. 顶边的蓝(1)和红(2)偏转器以及左边的绿(3)源像素保持不变。

**关键洞察**：偏转不仅改变路径位置，还翻转棋盘奇偶性，从而改变路径对后续偏转器的响应类型（蓝/红）。这形成了一个级联反馈：一次偏转可能导致后续某个本会生效的偏转器失效（或反之）。求解者必须逐格追踪奇偶状态才能推断完整路径，不能简单地将所有偏转器视为等价。

## 新题 6：边界贯穿线划分区域后区域内蛇形排序

**组合逻辑**：[连线](创新：贯穿线不是最终绘制目标，而是用于划分空间区域) + [排序+压缩/蛇形填充](创新：排序在每个区域内独立进行，区域本身的空间顺序决定蛇形填充的段落分配)

**来源原语**：连线(6cdd2623)、边界定位(6cdd2623)、标记像素(6cdd2623)、画布边界(6cdd2623)、边界标记定贯穿线(6cdd2623)、排序(cdecee7f)、压缩(cdecee7f)、列序排列(cdecee7f)、蛇形填充(cdecee7f)、奇行反序(cdecee7f)、散布标记(cdecee7f)

**依赖链**：识别边界标记色 → 画贯穿线 → 贯穿线将网格划分为矩形区域 → 统计每区域内散布标记数量 → 按区域从左上到右下的顺序将各区域的标记数量映射为蛇形序列的连续段。线的绘制决定区域边界，区域边界决定计数范围，计数结果决定蛇形输出——三步紧耦合。

用边界标记颜色画出贯穿网格的直线，这些线将网格划分为若干矩形区域。统计每个区域内散布标记的数量，然后将这些数量按区域的空间顺序排成一个蛇形序列输出。

**输入结构**：约 15x15 的网格，背景为黑(0)。网格边界上有 2~4 个灰(5)像素（边界标记），分布在不同边上——位于上/下边缘的标记定义竖直贯穿线（通过其所在列），位于左/右边缘的标记定义水平贯穿线（通过其所在行）。这些贯穿线将网格划分为 2x2 或 2x3 等若干矩形区域。网格内散布着若干彩色标记像素（每个 1 像素，使用红(2)、蓝(1)、绿(3)、黄(4)中的一种），每个区域内有 0~9 个标记。生成约束：每个区域内的标记数量互不相同；标记不位于贯穿线上。

**规则**：
1. 识别灰(5)边界标记像素（所有像素均在网格外边缘上）。
2. 对每个边界标记画贯穿线：上/下边缘的标记画通过该列的完整竖直灰(5)线，左/右边缘的标记画通过该行的完整水平灰(5)线。
3. 贯穿线将网格划分为矩形区域。按区域左上角的位置从左到右、从上到下排序，编号为区域 1, 2, 3, ...
4. 对每个区域，统计其内部（不含贯穿线上的像素）的非背景、非灰色标记像素总数 N_i。
5. 输出一个 K 行 M 列的小网格（K、M 使得 K*M >= 区域总数，取最小的正方形或接近正方形的矩形），使用蛇形填充顺序（第 0 行从左到右，第 1 行从右到左，第 2 行从左到右...）依次写入每个区域的标记数量 N_i，数量用对应区域内出现次数最多的标记颜色表示（将该颜色绘制在该格中）。若某区域无标记（N_i=0），对应格保持黑(0)。

**关键洞察**：贯穿线不是装饰而是空间分区工具——它们的位置决定了哪些标记被归入同一区域。蛇形序列的内容（颜色）和位置（顺序）分别由区域内标记的颜色和区域的空间排序决定。求解者必须先正确画线分区，才能正确计数；必须正确确定区域顺序，才能正确填充蛇形序列。

## 新题 7：拼接组装后沿涌现裂缝线分裂

**组合逻辑**：[拼接/连接配对](原有) → [擦除](创新：擦除的目标是组装后才涌现的完整裂缝路径) → [滑动/两侧分离](创新：分离沿着涌现路径而非预设轴)

**来源原语**：拼接(cbebaa4b)、连接像素(cbebaa4b)、锚点精灵(cbebaa4b)、连接配对(cbebaa4b)、逐步拼合(cbebaa4b)、擦除(2faf500b)、裂缝标记线(2faf500b)、滑动(2faf500b)、沿短轴分裂(2faf500b)、两侧等距分离(2faf500b)

**依赖链**：各精灵体通过红色连接像素配对拼合成完整体 → 拼合后，各精灵体中的黄色裂缝像素首尾相连形成一条贯穿整体的裂缝路径（这条路径在拼合前是碎片化的，无法识别为裂缝）→ 擦除整条裂缝路径 → 沿裂缝将整体分为两半，两半各向外平移一个像素。拼接是裂缝涌现的前提，擦除以涌现裂缝为目标，分裂以擦除结果为依据——典型的涌现效应驱动的三步链。

将散落的精灵体通过连接像素拼合为完整体，拼合后各精灵体中隐藏的黄色像素连成一条裂缝线；擦除该裂缝线并将整体沿裂缝分为两半，两半各向外移动一格。

**输入结构**：约 20x20 的黑(0)背景网格。4~6 个散落的精灵体，每个是一个 4-连通的多色小图形（主体使用蓝(1)、绿(3)、橙(7)中的一种，5~10 像素）。每个精灵体边缘有 1~2 个红(2)连接像素，内部有 1~2 个黄(4)像素。其中一个精灵体包含一个 3x3 的灰(5)块作为锚点标识。红色连接像素用于配对拼接：每个红像素恰好与另一个精灵体的一个红像素配对（平移后重叠）。生成约束：所有精灵体拼合后，各精灵体内的黄(4)像素恰好连成一条 4-连通的直线段或折线（贯穿整体的裂缝路径），将整体分为两个 4-连通半体（忽略黄色像素后）。裂缝路径在拼合前分散在各精灵体中，无法从单个精灵体推断完整路径。

**规则**：
1. 锚点精灵体（含灰(5)块的精灵体）保持原位。
2. 逐步拼接其余精灵体：将每个精灵体平移，使其某个红(2)像素与已拼合体上某个未配对的红(2)像素重叠。所有红色连接像素在拼合后成对重叠。
3. 拼合完成后，识别所有黄(4)像素——它们现在形成一条连续的 4-连通路径（裂缝线）。
4. 擦除所有黄(4)像素为黑(0)。同时擦除所有红(2)连接像素为黑(0)。
5. 确定裂缝路径的整体方向（水平为主或竖直为主，取路径边界框的长轴方向）。
6. 裂缝路径将剩余像素分为两个半体。沿裂缝的短轴方向，两个半体各向外平移 1 像素（若裂缝水平走向，则上半体上移 1 格、下半体下移 1 格；若裂缝竖直走向，则左半体左移 1 格、右半体右移 1 格）。
7. 灰(5)锚点块跟随其所在半体移动。

**关键洞察**：裂缝路径是拼接操作的涌现产物——在各精灵体分离时，黄色像素只是孤立的内部标记，毫无"裂缝"含义。只有拼合后它们才连成一条贯穿线，揭示出分裂的位置。这种"先组装、后发现隐藏结构、再据此拆解"的逻辑是源题中不存在的新结构关系。

## 新题 8：贯穿线被前景对象按面积选择性遮挡

**组合逻辑**：[连线](原有) + [面积比较/分类](创新：面积阈值决定遮挡优先级而非重涂色) + [重涂色](创新：被线覆盖的单像素对象变色，形成标记效果)

**来源原语**：连线(6cdd2623)、画布边界(6cdd2623)、边界定位(6cdd2623)、边界标记定贯穿线(6cdd2623)、重涂色(67385a82)、连通分量(67385a82)、面积比较(67385a82)、多像素涂色留单(67385a82)、原对象遮挡叠加(41e4d17e)

**依赖链**：画贯穿线 → 线与前景对象在空间上重叠 → 每个重叠位置的结果取决于该对象的连通分量面积：面积 > 1 的对象遮挡线（对象像素保留），面积 = 1 的孤立像素被线覆盖并重涂色为线的颜色。连线和面积分类共同决定每个像素的最终状态——遮挡规则将二者紧密耦合。

通过边界标记画出贯穿网格的灰色直线。线与前景对象交叉时，多像素对象遮挡线（对象优先），而单像素对象被线覆盖并吸收为线的颜色。

**输入结构**：约 14x14 的网格，背景为黑(0)。网格边界上有 2~3 个橙(7)标记像素——它们是唯一位于网格最外圈的非背景色像素。网格内部散布着若干前景对象：3~5 个多像素的 4-连通形状（每个 3~8 像素，使用蓝(1)、绿(3)、红(2)等颜色），以及 3~6 个孤立的单像素前景像素（使用黄(4)或其他颜色）。部分前景对象和单像素恰好位于橙色标记所定义的贯穿线经过的行或列上。生成约束：至少有一个多像素对象和一个单像素对象位于同一条贯穿线的路径上。

**规则**：
1. 识别橙(7)边界标记：位于上/下边缘的标记定义竖直贯穿线（通过该列），位于左/右边缘的标记定义水平贯穿线（通过该行）。
2. 绘制灰(5)贯穿线覆盖对应的整行或整列。
3. 处理线与前景对象的重叠——对每个被线经过的非背景像素位置：
   a. 确定该像素所属的 4-连通前景分量的面积。
   b. 若面积 > 1（多像素对象），该对象的所有像素保留原色，遮挡灰线（线在该位置不显示）。
   c. 若面积 = 1（孤立像素），该像素被灰(5)线覆盖，重涂色为灰(5)。
4. 不在贯穿线路径上的所有前景对象和单像素保持原状不变。
5. 橙(7)边界标记保持不变。

**关键洞察**：相同颜色的前景像素可能因连通性不同而命运迥异——连成一体的大对象拥有遮挡优先权（如同矩形挡住十字线），而孤立像素反被线吞噬。求解者必须同时理解"边界标记画线"和"面积决定遮挡"两条规则，并在空间上叠加它们的效果。仅看单个示例可能误以为"所有前景都遮挡线"或"所有前景都被线覆盖"——必须对比含不同面积对象的多个示例才能归纳出面积阈值规则。

## 新题 9：枢轴反射后按新位置最近角填充矩形

**组合逻辑**：[旋转/180度](创新：旋转改变位置从而改变最近角，而非旋转即终态) + [填充](创新：填充的锚点和范围由旋转后的位置决定，非原始位置)

**来源原语**：旋转(90347967)、枢轴像素(90347967)、点对称(90347967)、绕枢轴半周旋转(90347967)、填充(4a1cacc2)、孤立前景像素(4a1cacc2)、网格角(4a1cacc2)、最近角距离(4a1cacc2)、曼哈顿距离最小(4a1cacc2)

**依赖链**：每个前景像素绕枢轴做 180 度反射得到新位置 → 在新位置重新计算最近网格角 → 从新位置到最近角填充矩形。旋转改变了"最近角"的选择（原位置的最近角可能不同于反射后位置的最近角），因此填充范围完全依赖旋转结果。不做旋转则填充区域错误，不做填充则旋转只是搬运像素。

将每个彩色前景像素绕灰色枢轴做 180 度反射，然后在反射后的位置找到最近的网格角，填充从反射位置到该角的矩形区域。

**输入结构**：约 12x12 的黑(0)背景网格。一个灰(5)枢轴像素位于网格的偏心位置（非中心，非边角，距各角的曼哈顿距离互不相同）。2~4 个孤立的单像素前景像素，每个使用不同颜色（蓝(1)、红(2)、绿(3)、黄(4)），散布在网格上。生成约束：每个前景像素经 180 度反射后仍在网格内；各前景像素反射后的最近角互不相同（即每个反射像素对应不同的网格角）；从各反射位置到其最近角填充的矩形互不重叠。

**规则**：
1. 对每个非黑(0)、非灰(5)的前景像素 (r, c)，计算其关于灰(5)枢轴 (pr, pc) 的 180 度反射位置：(r', c') = (2*pr - r, 2*pc - c)。
2. 在反射位置 (r', c')，计算到四个网格角 (0,0)、(0, W-1)、(H-1, 0)、(H-1, W-1) 的曼哈顿距离，找到最近的角 (cr, cc)。
3. 将从 (r', c') 到 (cr, cc) 的轴对齐矩形区域（含两端点）全部填充为该前景像素的颜色。
4. 原始前景像素位置清除为黑(0)。灰(5)枢轴像素保持原位。
5. 若枢轴像素位于某个填充矩形内，枢轴仍保持灰(5)不被覆盖。
6. 先处理反射位置距其最近角更远的像素（即先填充大矩形），后处理距离近的像素（后填充小矩形覆盖在前面之上）。这确保小矩形在重叠时优先显示。

**关键洞察**：旋转不是最终变换，而是改变了填充操作的关键参数（最近角选择）。同一个源像素在原位和反射后可能对应不同的最近角，导致完全不同的填充方向和范围。求解者必须先完成旋转计算，再判断最近角，最后执行填充——跳过任一步都无法得到正确输出。处理顺序规则（远的先画、近的后画覆盖）需要对比多个示例中重叠情况才能归纳。

## 新题 10：裁剪掩码后按角点占用分类并编码到标记列

**组合逻辑**：[裁剪](创新：裁剪不是为了输出，而是为了提取结构特征) + [分类/角点占用](创新：分类结果不是单格输出，而是驱动双重操作——重涂色原对象 + 编码到标记列)

**来源原语**：裁剪(4c177718)、掩码图案(27a28665)、角点(27a28665)、分类(27a28665)、角点占用映射标签(27a28665)、重涂色(e048c9ed)、标记列(e048c9ed)、长度映射颜色(e048c9ed)、固定编码表(e048c9ed)

**依赖链**：裁剪每个对象的边界框 → 分析 3x3 掩码的角点占用 → 角点数映射为分类颜色 → 分类颜色同时应用于两个目标：重涂原对象、绘制到标记列对应行。裁剪提取分类特征，分类决定颜色，颜色分发到两个空间位置——扇形依赖结构而非线性。

将每个 5 像素前景对象裁剪为 3x3 掩码，按其四角占用数分类映射为一种颜色，然后将该颜色同时涂到原对象和右侧标记列的对应行。

**输入结构**：约 15x15 的黑(0)背景网格。右侧最后一列是灰(5)标记列（整列为灰色）。网格其余区域散布 3~5 个前景对象，每个对象由同色的恰好 5 个像素组成（4-连通），使用橙(7)作为统一的初始颜色，边界框恰好为 3x3。各对象互不相邻，且不与标记列相邻。不同对象的 3x3 掩码形状不同（即 5 个像素在 3x3 框中的分布方式不同），使得它们的角点占用数各异。生成约束：各对象的角点占用数（0, 1, 2, 4 中的某个值）互不相同，确保每个对象映射到不同的分类颜色。

**规则**：
1. 对每个橙(7)前景对象，提取其 3x3 边界框作为掩码。
2. 统计该掩码四个角（左上、右上、左下、右下）中被前景像素占据的数量 K。
3. 按固定编码表将 K 映射为分类颜色：K=0 → 品红(6)，K=1 → 蓝(1)，K=2 → 绿(3)，K=4 → 红(2)。
4. 将该对象的所有 5 个像素从橙(7)重涂为其分类颜色。
5. 在灰(5)标记列中，找到与该对象中心行（边界框中心行）相同的那一行，将该格从灰(5)涂为该对象的分类颜色。
6. 标记列中未被涂色的格保持灰(5)。

**关键洞察**：裁剪和角点分析是中间步骤，其结果不直接输出，而是驱动两个下游操作（重涂原对象 + 编码到标记列）。分类颜色在两个不同空间位置同时体现，形成扇出结构。求解者必须先理解角点占用→颜色的映射表（需对比多个示例归纳），再理解该颜色的双重应用方式。所有对象初始同为橙色，必须靠形状分析而非颜色区分来推断规则。
