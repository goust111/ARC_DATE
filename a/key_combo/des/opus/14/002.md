## 新题 1：蛇径编码色环

**组合逻辑**：[遍历顺序](创新：蛇形路径的邻接访问顺序编码颜色置换关系) + [重涂色](已有) + [膨胀](创新：光晕颜色由置换结果决定而非标记原色)

**来源原语**：蛇形路径·遍历顺序·端点（7b5033c1），重涂色·固定颜色置换映射（0d3d703e），膨胀·光晕·邻域扩展·标记保留原色（4258a5f9），单像素标记（963f59bc）

**依赖链**：蛇形路径的遍历顺序产出标记的访问序列 -> 访问序列定义颜色的循环置换映射 -> 置换映射决定每个标记的光晕颜色 -> 光晕绘制时标记自身保留原色。去掉遍历则无法确定置换；去掉置换则光晕颜色无定义；去掉光晕则输出退化为零散色点。

一句话总结：追踪蛇形路径经过各彩色标记的先后顺序，由此建立一组循环色彩置换，为每个标记绘制置换后颜色的光晕，标记本身保留原色。

**输入结构**：约 12x12 的黑(0)背景网格。一条灰(5)蛇形路径在网格中蜿蜒，由 4-连通单色像素组成，恰好有两个端点（仅一个 4-邻居为灰色的像素）。路径不分叉、不自交。网格中另有 3~5 个不同颜色的单像素标记（从红(2)、绿(3)、蓝(1)、黄(4)、橙(7)中选取），每个标记不在蛇形路径上，但恰好与蛇形路径的某一个像素 4-相邻。每个标记恰好与蛇形路径的一个像素相邻（不会有标记与蛇形路径的多个像素相邻）。不同标记相邻的蛇形路径像素互不相同。生成约束：任意两个标记的 3x3 邻域互不重叠；所有标记距网格边缘至少 1 像素。

**规则**：
1. 确定蛇形路径的遍历方向：从两个端点中选取行号更小者出发；若行号相同，选列号更小者。从该端点沿唯一的 4-连通路径依次访问每个灰(5)像素。
2. 按遍历顺序记录蛇形路径依次经过（4-相邻）的标记颜色，形成一个有序颜色列表，例如 [红(2), 蓝(1), 黄(4), 绿(3)]。
3. 建立循环置换映射：列表中第 i 个颜色映射到第 (i+1) 个颜色；最后一个颜色映射到第一个。例如上述列表产生映射 红->蓝, 蓝->黄, 黄->绿, 绿->红。
4. 擦除整条蛇形路径（全部灰像素变为黑(0)背景）。
5. 对每个标记像素，将其 3x3 邻域（以标记为中心，裁剪到网格边界内）中的所有黑(0)背景像素涂为该标记的**置换后颜色**（即步骤 3 中映射到的颜色）。
6. 所有标记像素自身保留其**原始颜色**不变（覆盖在光晕之上）。
7. 若多个标记的 3x3 光晕在某像素重叠（按生成约束不会发生，但作为边界规则说明），后处理的标记覆盖先处理的；处理顺序为遍历访问顺序。

**关键洞察**：蛇形路径本身不出现在输出中，它的唯一作用是通过遍历顺序编码一组颜色循环置换；若不追踪路径就无法确定哪种颜色映射到哪种颜色。遍历的起始端点选择规则（左上优先）需要对比多个示例才能归纳。

## 新题 2：对称缺陷播种填充

**组合逻辑**：[对称补全](创新：缺陷像素不再是待恢复的遮挡区，而是标识填充种子的信号) + [区域填充](创新：填充边界来自对称图案本身) + [重涂色](已有：缺陷修复)

**来源原语**：对称补全·双轴镜像对称·遮挡由镜像恢复（67b4a34d），区域填充（1190bc91），重涂色（0d3d703e），前景对象（963f59bc）

**依赖链**：双轴对称分析发现缺陷像素的位置与颜色 -> 缺陷颜色成为区域填充的种子色，缺陷位置成为填充起点 -> 对称图案的前景像素充当填充边界 -> 填充完成后修复缺陷像素为正确前景色以恢复对称。去掉对称分析则无法定位缺陷；去掉填充则仅修复几个像素毫无意义；去掉修复则对称性仍然破缺。

一句话总结：在一个近乎双轴对称的前景图案中找到打破对称的缺陷像素，以缺陷为种子在对称图案围出的封闭区域内扩散填充缺陷颜色，最后将缺陷本身修复为正确前景色。

**输入结构**：约 13x13 的黑(0)背景网格（行列数均为奇数，使对称中心恰好落在一个像素上）。一组蓝(1)前景像素构成一个关于网格中心同时具有水平和垂直镜像对称的图案。该图案可以是任意连通或不连通的对称形状（如十字、菱形边框、对称散点等），但其前景像素将背景划分为若干 4-连通封闭区域（封闭指被前景像素和/或网格边界完全围合）。图案中恰好有 2~3 个"缺陷"像素：这些位置本应为蓝(1)前景（由双轴对称可推知），但实际被替换成了各不相同的非黑非蓝颜色（从红(2)、绿(3)、黄(4)中选取）。每个缺陷像素所在的封闭背景区域互不相同。生成约束：缺陷像素始终位于封闭区域的边界上（即至少有一个 4-邻居是黑(0)背景且属于某个封闭区域），保证缺陷处于其所属封闭区域的入口位置。

**规则**：
1. 通过双轴（水平 + 垂直）镜像对称分析，找到所有不满足对称性的像素位置。这些位置即为缺陷，它们的实际颜色是非蓝非黑的特殊颜色。
2. 对每个缺陷像素，将其位置临时恢复为蓝(1)前景色（即假装对称完好），然后从缺陷的那个位置出发，向该位置 4-邻域中属于黑(0)背景的方向进行 4-连通区域填充，填充色为该缺陷的原始特殊颜色。填充在遇到蓝(1)前景像素或网格边界时停止。
3. 填充完成后，将所有缺陷位置的像素永久修复为蓝(1)（恢复完美对称）。
4. 若某个封闭区域不含任何缺陷像素，则该区域保持黑(0)背景不变。
5. 不同缺陷的填充区域不会重叠（由生成约束保证：每个缺陷在不同封闭区域的边界上）。

**关键洞察**：缺陷像素身兼两职——它既是打破对称性的"错误"，又是区域填充的种子和颜色来源。必须先利用对称性找到缺陷，才能确定填充位置和颜色；但填充的边界恰恰是对称图案本身。这一双重角色使得对称分析和区域填充不可分离。对称类型为双轴（非单轴），需对比多个示例方可确认。

## 新题 3：射线分区标记灌注

**组合逻辑**：[射线延伸](已有) + [区域填充](创新：填充种子为散落的标记像素而非连通对象) + [处理顺序决定遮挡](已有)

**来源原语**：射线延伸·射线遮挡分区·处理顺序决定遮挡·多色长线段（1190bc91），区域填充（隐含于1190bc91），标记像素（4258a5f9/6d0160f0）

**依赖链**：多色顶行逐像素从左向右发射对角射线 -> 先发射的射线遮挡后发射的射线，形成不同形状的分区 -> 散落标记像素各自位于某一分区内 -> 以标记色 4-连通填充该分区的背景像素。去掉射线则无分区边界；去掉填充则分区存在但无标记色扩散；改变射线处理顺序则分区形状改变导致标记归属不同分区。

一句话总结：顶行多色像素从左到右依次向下发射两条 45 度对角射线（先发射的遮挡后发射的），由此将下方网格切割为若干区域，再用散落在各区域中的彩色标记像素作为种子进行 4-连通区域填充。

**输入结构**：约 15x15 的黑(0)背景网格。最顶行（第 0 行）从左到右包含 4~6 个非黑像素（各不相同的颜色，从蓝(1)、红(2)、绿(3)、黄(4)、灰(5)、品红(6)中选取），其余位置为黑(0)。顶行非黑像素可以不连续（中间可有黑像素间隔）。在第 2 行及以下的区域中，散落有 2~4 个单像素标记，每个标记颜色各不相同且不与顶行任何像素颜色重复（从橙(7)、青(8)、栗(9)中选取）。生成约束：每个标记恰好位于射线分区后的某一个独立 4-连通背景区域中，且不同标记位于不同的区域；至少有一个背景区域不含标记。

**规则**：
1. 按从左到右的顺序处理顶行的每个非黑像素。
2. 对当前处理的像素 (0, c)，同时向左下方（行+1, 列-1）和右下方（行+1, 列+1）发射两条 45 度射线。射线沿对角方向逐像素延伸，将经过的像素涂为该顶行像素的颜色。
3. 射线在以下任一情况停止（不包含终止点）：遇到已被涂色的非黑像素（即先前射线留下的痕迹）；到达网格边界之外。
4. 所有射线处理完毕后，射线将下方网格分割为若干 4-连通的黑(0)背景区域。
5. 对每个标记像素，以其位置为起点、其颜色为填充色，进行 4-连通区域填充。填充在遇到任何非黑像素（射线像素或其他标记的填充像素）或网格边界时停止。
6. 不含标记的背景区域保持黑(0)不变。
7. 顶行像素保留原色不变。射线像素保留其颜色不变。标记像素被其自身颜色的填充覆盖（视觉上不变）。

**关键洞察**：射线的左到右处理顺序决定了遮挡关系——早发射的射线挡住晚发射的，改变了分区的形状和大小。因此同一组标记在不同的射线处理顺序下会填充不同形状的区域。处理顺序规则需要对比多个示例才能确认（顶行像素并非总是连续排列，需确认是按列坐标从小到大而非按颜色或其他属性排序）。

## 新题 4：象限镜像生洞·标记定色

**组合逻辑**：[镜像/旋转](创新：镜像操作创造出带孔洞的精灵体副本) + [填充](创新：孔洞填充色由散落标记的位置对应关系决定) + [象限决定反射轴](已有)

**来源原语**：镜像·旋转·象限决定反射轴（b10624e5），填充·孔洞·源与目标对齐（3a25b0d8），精灵裁剪·精灵体（2697da3f），单像素标记·标记像素（963f59bc/f5c89df1）

**依赖链**：精灵体的裁剪确定其形状和孔洞位置 -> 象限位置决定镜像/旋转方式 -> 镜像后孔洞出现在新的坐标位置 -> 标记像素的象限内局部坐标与镜像后孔洞的局部坐标匹配 -> 匹配到的孔洞被填充为标记颜色。去掉镜像则其他象限无精灵体无孔洞；去掉位置匹配则不知哪个孔洞填什么色；去掉填充则输出只有空洞精灵体副本。

一句话总结：将左上象限的带孔精灵体按象限位置镜像/旋转到其余三个象限，然后根据各象限中散落标记像素的局部位置找到对应孔洞并填充标记颜色。

**输入结构**：约 14x14 的黑(0)背景网格（行列数均为偶数）。网格以中心点为基准分为四个等大的象限（左上、右上、左下、右下，各约 7x7）。左上象限包含一个蓝(1)前景精灵体（4-连通，约 8~15 像素），精灵体内部有 2~3 个单像素孔洞（被前景完全围合的黑(0)像素）。其余三个象限各有 1~2 个彩色单像素标记（从红(2)、绿(3)、黄(4)、橙(7)、品红(6)中选取，各标记颜色不同）。标记的"象限内局部坐标"（即标记在其所在象限内的行列偏移）恰好等于左上象限精灵体某个孔洞经过对应镜像/旋转变换后的局部坐标。生成约束：同一象限内不同标记对应不同的孔洞；每个象限中的标记数不超过该象限经镜像后产生的孔洞数。

**规则**：
1. 裁剪左上象限的蓝(1)精灵体及其孔洞（紧凑边界框）。
2. 为其余三个象限生成精灵体副本，变换规则如下：
   - 右上象限：将精灵体水平镜像（左右翻转）。
   - 左下象限：将精灵体垂直镜像（上下翻转）。
   - 右下象限：将精灵体旋转 180 度（等价于水平 + 垂直镜像）。
3. 将每个副本放置到对应象限中，使副本的紧凑边界框在象限内的位置与原精灵体在左上象限内的位置关于象限边界对称。
4. 对每个标记像素，计算其"象限内局部坐标"（标记行号减去象限起始行号，标记列号减去象限起始列号）。在该象限的精灵体副本中，找到变换后局部坐标与之相同的孔洞。
5. 将匹配到的孔洞像素填充为该标记的颜色。标记像素本身被擦除（变为黑(0)背景）。
6. 未被任何标记匹配到的孔洞保持黑(0)不变。
7. 左上象限的原始精灵体及其孔洞保持不变（孔洞仍为黑(0)）。

**关键洞察**：镜像操作将孔洞移到了新的局部坐标，标记必须通过与镜像后坐标的匹配才能"找到"自己要填充的孔洞。这意味着求解者必须先推断出每个象限对应的镜像类型（水平/垂直/180度），才能建立标记位置到孔洞的对应关系。象限与镜像类型的映射规则需要对比多个示例才能确认。

## 新题 5：框尺寸定缩放·框色定重涂

**组合逻辑**：[缩放](创新：缩放因子由目标空心框的内部尺寸与模板尺寸之比决定) + [印章放置](已有) + [重涂色](创新：模板中出现次数最多的颜色被替换为框边颜色)

**来源原语**：缩放·尺寸比编码缩放（b10624e5），印章覆盖·多色模板·同尺寸替换（e76a88a6），空心框（4c7dc4dd），重涂色（0d3d703e）

**依赖链**：空心框的内部面积与模板面积之比决定缩放倍率 -> 模板按倍率缩放产生不同尺寸的副本 -> 框边颜色指定重涂色的目标颜色 -> 缩放后的模板中频率最高的颜色被替换为框边颜色 -> 重涂后的模板印入框内部。去掉缩放则模板尺寸不匹配；去掉重涂则所有框内图案颜色相同失去框色信息；去掉印章则缩放和重涂无目的地。

一句话总结：将一个小型多色模板按每个空心框内部尺寸等比缩放，再将模板中最高频颜色替换为该框的边框颜色，然后将处理后的模板印入框的内部。

**输入结构**：约 18x18 的黑(0)背景网格。网格左上角有一个小型多色模板（约 3x3 像素的紧凑矩形，包含 2~3 种非黑颜色，如红(2)和绿(3)，其中一种颜色的像素数严格多于其他颜色）。网格中另有 2~4 个空心矩形框，框边为单色且各框颜色不同（从蓝(1)、黄(4)、品红(6)、橙(7)中选取），框边宽度均为 1 像素，框内部全为黑(0)。每个框的内部尺寸（高x宽）均为模板尺寸的整数倍（如内部 6x6 对应模板 3x3 的 2 倍缩放，内部 9x9 对应 3 倍缩放），不同框的缩放倍率可以不同。生成约束：各框互不重叠且不覆盖模板；框内部尺寸的行倍率和列倍率相同（等比缩放）。

**规则**：
1. 识别模板：找到唯一一个不被任何空心框包围的、由多种非黑颜色组成的紧凑矩形区域，记录其像素内容和尺寸 (h_t x w_t)。
2. 识别所有空心框：每个框是一个由单色像素组成的 1 像素宽的矩形环，内部全为黑(0)。记录每个框的边框颜色和内部尺寸 (h_i x w_i)。
3. 对每个空心框，计算缩放倍率 k = h_i / h_t（= w_i / w_t，由生成约束保证相等）。
4. 将模板进行最近邻缩放：模板中坐标 (r, c) 的像素填充到缩放后图像的 (r*k) 到 (r*k + k - 1) 行、(c*k) 到 (c*k + k - 1) 列的 k x k 块中。
5. 确定模板中出现次数最多的颜色（"主色"）。在缩放后的副本中，将所有主色像素替换为该空心框的边框颜色。其他颜色不变。
6. 将处理后的副本放置到空心框的内部区域，与框内部左上角对齐。
7. 框边框像素保留不变。模板保留不变。

**关键洞察**：每个空心框同时编码了三个参数——位置（在哪里印）、缩放倍率（内部尺寸与模板的比）、重涂色（边框颜色替换模板主色）。尤其是"模板主色被替换"这一规则不能从单个示例中确认（可能误以为是某个特定颜色被替换），需要对比多个不同框色的示例才能归纳出"始终替换最高频颜色"的规则。

## 新题 6：色带优先级仲裁区域填充

**组合逻辑**：[压缩](创新：压缩结果不作为输出，而是编码优先级序) + [区域填充](创新：多种子同时扩张，碰撞时由外部优先级仲裁) + [擦除](已有：上半区擦除)

**来源原语**：压缩·色带·空间排列顺序·行主色压缩单像素（4be741c5），区域填充（1190bc91），填充·前景对象（aa18de87），分隔行（506d28a5），擦除（6d0160f0）

**依赖链**：上半区的锯齿色带压缩为颜色优先级序列 -> 下半区的前景图案将背景分为封闭区域 -> 标记种子各自在封闭区域内扩张填充 -> 当不同种子的填充在共享边界处竞争同一像素时，上半区编码的优先级序列决定谁胜出。去掉压缩则无法仲裁边界竞争（填充结果不确定）；去掉填充则优先级序无用武之地；去掉仲裁则重叠区域结果不确定。

一句话总结：上半区的水平色带压缩为一列颜色序列编码优先级，下半区的前景图案围出多个区域各有彩色种子，种子进行竞争式区域填充，边界碰撞由上半区优先级从高到低仲裁。

**输入结构**：约 15x17（15 行 17 列）的黑(0)背景网格。一条完整的灰(5)水平分隔行将网格分为上下两个面板（上面板约 6 行，下面板约 8 行，分隔行 1 行）。上面板完全被 3~4 种颜色的水平色带覆盖（无黑色背景），每种颜色占据 1~3 行，色带边界呈锯齿状（同一行的多数像素为该带颜色，少数像素为相邻带颜色），带色从上到下依次为例如红(2)、绿(3)、黄(4)。下面板以黑(0)为背景，包含一组品红(6)前景像素构成的连通图案（如弯折线段、分支结构等），该图案将下面板的黑(0)背景分割为若干 4-连通封闭区域（被品红像素和/或网格边界围合）。在其中 3~4 个封闭区域中各有一个单像素标记（颜色与上面板的色带颜色一一对应，如红(2)、绿(3)、黄(4)），每个区域最多一个标记。生成约束：至少有两个标记所在的封闭区域共享一段品红边界（使得去掉该边界后两区域会合并，产生竞争场景）；上面板色带的颜色集合与下面板标记的颜色集合完全相同。

**规则**：
1. 压缩上面板的色带：对上面板的每一行取行主色（该行出现次数最多的颜色），得到一个从上到下的颜色序列。去除相邻重复，得到色带颜色的有序列表，例如 [红(2), 绿(3), 黄(4)]。
2. 该列表的顺序定义优先级：列表中越靠前的颜色优先级越高（最上方的色带 = 最高优先级）。
3. 在下面板中，同时从每个标记像素出发进行 4-连通区域填充，填充色为标记自身颜色。填充在遇到品红(6)像素或网格边界时停止。
4. 将下面板中所有品红(6)边界像素移除（变为黑(0)），使原本被品红像素分隔的相邻区域合并。
5. 对合并后出现的每个争议像素（原品红边界位置，现在相邻两侧有不同颜色的填充区域），以及任何因边界消除而新增的连通像素：将该像素涂为其 4-邻域中优先级最高的颜色（依据步骤 2 的优先级序列）。
6. 从争议像素出发继续向 4-连通的黑(0)像素扩散，直到遇到已着色像素或网格边界。扩散颜色为步骤 5 确定的优先级胜出色。
7. 擦除上面板和分隔行（全部变为黑(0)），仅输出下面板区域。

**关键洞察**：色带压缩的结果不是最终输出——它编码了一套隐含的优先级规则，只在填充发生边界竞争时才生效。如果所有标记的填充区域互不相邻，优先级规则永远不会被触发，求解者就无法归纳出该规则。因此必须有多个示例，其中至少一个示例中发生竞争，才能推断出"上方色带 = 高优先级"的隐蔽规则。

## 新题 7：轮廓扫描成形·旋转嵌图

**组合逻辑**：[填充(逐行扫描)](已有) + [旋转匹配](创新：用扫描填充产生的形状几何来确定模板的旋转角度) + [印章覆盖](创新：模板透明色由轮廓颜色决定)

**来源原语**：填充·轮廓像素·逐行扫描·填充轮廓间区域（aa18de87），旋转匹配·旋转·源与目标对齐（3a25b0d8），印章覆盖·多色模板·同尺寸替换（e76a88a6），裁剪（9f27f097）

**依赖链**：对角轮廓像素经逐行扫描填充产生封闭形状 -> 形状的边界框尺寸决定模板需要哪种旋转才能匹配 -> 旋转后的模板覆盖到形状内部 -> 轮廓颜色指定模板的透明色（该色像素在覆盖时不替换填充色）。去掉扫描填充则无形状无嵌入目标；去掉旋转匹配则模板尺寸不匹配形状；去掉透明色规则则形状内填充色完全被覆盖失去扫描填充的痕迹。

一句话总结：对角线轮廓像素经逐行水平扫描填充产生若干封闭形状，将角落处的多色模板旋转到与每个形状边界框匹配的方向后嵌入形状内部，其中与轮廓同色的模板像素在嵌入时透明（保留填充色）。

**输入结构**：约 16x16 的黑(0)背景网格。网格中有若干橙(7)像素组成的对角线笔画（每条笔画是一段 4-连通或 8-连通的对角线段），这些笔画的排布使得在逐行扫描填充后会产生 2~3 个不重叠的封闭区域。网格右下角有一个多色模板（约 3x4 或 4x3 的紧凑矩形），模板包含 2~3 种非黑颜色（如红(2)、绿(3)、橙(7)），其中橙(7)像素出现在模板中。模板的高宽比不为 1:1（非正方形），使得 0 度和 90 度旋转对应不同的边界框尺寸。生成约束：每个扫描填充后的封闭区域的内部尺寸（不含轮廓像素的纯填充区域边界框）恰好等于模板的某个旋转版本（0度、90度、180度、270度之一）的尺寸；不同区域可能需要不同的旋转角度。

**规则**：
1. 逐行扫描填充：对每一行，从左到右找到所有橙(7)轮廓像素。对每对相邻的橙(7)像素（同一行中按列坐标排序后的连续两个），将它们之间的所有黑(0)像素涂为红(2)。
2. 扫描填充后，红(2)区域与橙(7)轮廓共同形成若干视觉上的封闭形状。对每个 4-连通的红(2)区域，计算其紧凑边界框尺寸 (h x w)。
3. 对每个红(2)区域，在模板的四种旋转（0度、90度顺时针、180度、270度顺时针）中找到边界框尺寸与 (h x w) 完全匹配的旋转版本。若 0 度模板尺寸为 (h_t x w_t)，则 90 度为 (w_t x h_t)，以此类推。选择匹配的旋转角度最小的版本（0 < 90 < 180 < 270）。
4. 将选中旋转版本的模板覆盖到红(2)区域上，对齐区域的边界框左上角。覆盖规则：模板中非橙(7)的像素直接覆盖目标位置的红(2)像素；模板中橙(7)的像素为"透明"，不做任何覆盖，保留目标位置原有的红(2)填充色。
5. 轮廓像素（橙(7)）保持不变。模板原始位置保持不变。网格中未被扫描填充涉及的黑(0)区域保持不变。

**关键洞察**：轮廓像素的颜色（橙(7)）恰好出现在模板中，且在嵌入时充当透明色——这一规则不能从形状或旋转逻辑中推导出来，只能通过对比多个示例中模板嵌入后的残留填充色位置来归纳。模板中的橙(7)像素"消失"并非巧合，而是因为轮廓色 = 透明色。
