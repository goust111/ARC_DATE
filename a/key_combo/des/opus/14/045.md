## 新题 1：连通帧数决定同心填充色环深度

**组合逻辑**：[connectivity_test](创新：连通分量内的帧数量作为参数输出) → [concentric_fill](创新：色环长度由连通帧数K参数化)

**来源原语**：connectivity_test, bridge_path, connectivity, connected_color_else_black ← 239be575；concentric_fill, hollow_rectangle, concentric_layer, nesting_hierarchy, distance_color_cycling ← a3f84088

**依赖链**：桥接路径将若干帧连为一个分量 → 计数分量内帧数K → K决定同心填充使用的颜色数量 → 不同分量的帧获得不同配色方案。删除连通分析则K未知，删除同心填充则无输出变换。

将散布在网格中的空心矩形帧按桥接路径的连通关系分组，每组包含的帧数量决定其同心填充的颜色环长度。

**输入结构**：
- 约15x20网格，黑(0)背景
- 3-5个灰(5)空心矩形帧，单像素宽边框，内部为黑(0)，大小各异（内部区域约3x3到6x6），互不嵌套、互不正交邻接
- 帧之间可能存在青(8)单像素宽桥接路径（仅水平或垂直延伸，不穿越任何帧的边框），将某些帧连通为同一分量
- 不同连通分量包含的帧数量不同（例如一个分量含1帧、另一个含2帧、第三个含3帧）
- 生成约束：每个帧的内部至少3x3；桥接路径不分叉（每条路径连接恰好两个帧）；各连通分量的帧数K互不相同

**规则**：
1. 以所有非黑像素（灰(5)帧像素 + 青(8)桥接像素）为前景，构建4-连通分量
2. 对每个连通分量，计数其中包含的完整帧数量K（一个帧定义为：由灰(5)像素构成的封闭矩形边框）
3. 定义固定颜色序列 S = [红(2), 蓝(1), 绿(3), 黄(4)]。对每个帧，取S的前K个颜色构成该帧的填充色环（若K>4则循环使用整个S，即色环为S的前K mod 4项加上完整循环）
4. 对每个帧的内部区域，从紧邻帧边框内侧的一圈像素（第0层）开始向内逐层编号。第i层使用色环中第 i mod K 个颜色填充
5. 保留所有灰(5)帧边框像素和青(8)桥接路径像素不变
6. 各帧独立填充，处理顺序不影响结果

**关键洞察**：桥接路径本身不产生任何视觉变化，但它改变了连通分量的帧数K，从而间接决定了帧内同心环使用几种颜色——必须对比包含不同帧数的分量才能归纳出"K→色环长度"这一隐蔽映射。

## 新题 2：封闭孔洞提取为自相似印章种子

**组合逻辑**：[crop + enclosure detection](已有) → [stamp_overlay](创新：将孔洞的内部图案同时用作印章内容和放置掩模)

**来源原语**：crop, hollow_rectangle, enclosed_region, enclosure, object_with_hole_selected ← b9b7f026；stamp_overlay, seed_sprite, pixel_to_block_mapping, fg_position_copy ← 5b6cbef5

**依赖链**：多对象中识别出含孔洞的唯一帧 → 提取帧内部的二值图案 → 该图案既定义印章内容又定义放置位置 → 自相似块扩展生成输出。任一步缺失均无法确定输出。

在多个前景对象中找出唯一含封闭孔洞的空心帧，提取帧内部的二值图案并以其为种子进行自相似块扩展。

**输入结构**：
- 约12x12网格，黑(0)背景
- 3-5个单色4-连通前景对象，各自颜色不同（从蓝(1)、红(2)、绿(3)、橙(7)、品红(6)中选取），互不正交邻接
- 恰好一个对象是空心矩形帧（边框完整、宽1像素），其内部区域为NxN（N=3或4），帧内部混合排列着帧颜色像素和黑(0)像素，形成特定图案
- 其余对象为实心（边界框内无4-连通黑色封闭区域）
- 生成约束：帧内部至少有2个且至多N*N-1个黑(0)像素（孔洞不为空也不占满整个内部）；其余实心对象的4-连通黑色邻域均可到达网格边缘（无封闭）

**规则**：
1. 对每个前景对象，检测其边界框内部是否存在不触及边界框边缘的4-连通黑(0)区域。找到唯一拥有此类封闭黑色区域的对象，即"空心帧"，记其颜色为C
2. 提取空心帧的NxN内部区域（不含帧边框）为二值图案P：颜色C的像素标记为前景(1)，黑(0)的像素标记为背景(0)
3. 创建(N*N)x(N*N)的全黑输出网格。将P的每个像素(r,c)映射到输出中以(r*N, c*N)为左上角的NxN块：若P[r][c]=前景，则在该块中绘制P的一个副本（前景像素用颜色C绘制，背景像素保持黑(0)）；若P[r][c]=背景，则该块全部保持黑(0)
4. 输出仅包含扩展结果，原网格中所有其他对象丢弃

**关键洞察**：空心帧的内部图案承担双重角色——它既是印章内容（每个副本长什么样），也是放置掩模（哪些块位置放置副本）。必须先从多个对象中甄别出含孔洞者，才能提取种子；单看输出的自相似结构无法反推是哪个对象贡献了种子。

## 新题 3：柱状条算术结果参数化边缘带平移距离

**组合逻辑**：[counting + height_arithmetic](已有) → [translate + erase](创新：算术结果跨域作为空间平移的距离参数)

**来源原语**：counting, vertical_bar, color_encodes_sign, height_arithmetic ← 37ce87bb；translate, erase, edge_strip, marker_active_edge, trail_color_move ← d255d7a7

**依赖链**：青条高度求和 - 红条高度求和 = D → D成为边缘图案带的水平平移列数 → 执行平移并擦除原位置。算术和平移属于完全不同的领域，必须先解算术才能执行空间变换。

左侧彩色柱状条的高度进行有符号加减运算，计算结果作为右侧边缘图案带向左平移的列数。

**输入结构**：
- 约15x12网格，黑(0)背景
- 左区域（列0-5）：3-4根底部对齐、单像素宽的垂直柱状条，各条之间至少隔1列黑色。青(8)条代表正值，红(2)条代表负值。各条高度在1-8之间
- 分隔线（列6）：一列灰(5)像素贯穿整个网格高度
- 右区域（列7-14）：沿网格最右边缘存在2列宽的纵向图案带，由橙(7)像素在黑(0)背景上构成图案（非全满，有间隔）
- 生成约束：D = 所有青(8)条高度之和 - 所有红(2)条高度之和，保证 1 <= D <= 6（即平移后图案带不越过分隔线也不超出网格）；图案带平移后不与柱状条或分隔线重叠

**规则**：
1. 计算 D = 所有青(8)柱状条的高度之和 - 所有红(2)柱状条的高度之和
2. 将右侧2列宽的边缘图案带整体向左平移D列（每个橙(7)像素的列坐标减D）
3. 擦除图案带原始位置的所有橙(7)像素（改为黑(0)）
4. 保留所有柱状条、灰(5)分隔线不变
5. 平移后的图案带保持原有的橙(7)/黑(0)排列不变

**关键洞察**：柱状条区域不产生自身的视觉输出变化——它纯粹是一个编码了平移距离的"计算器"。算术结果从"计数"领域跨到"空间变换"领域，这种跨域参数传递需要对比多个示例（不同的条高度组合→不同的平移距离）才能发现。

## 新题 4：投票填充腔室后双轴反射平铺

**组合逻辑**：[fill + adjacent_majority_vote](已有) → [tiling + biaxial_reflection](创新：投票填充的结果作为未知种子瓦片进行对称平铺)

**来源原语**：fill, connected_chamber, separator_wall, marker_pixel, orthogonal_adjacency, adjacent_majority_vote ← 7c8af763；tiling, tile, quadrant_layout, biaxial_reflection ← 67e8384a

**依赖链**：标记像素多数投票 → 决定各腔室填充色 → 填充后的网格成为种子瓦片 → 双轴反射产生4象限输出。种子瓦片在输入中不可见，必须先解投票才能构建。

依据相邻标记像素的多数颜色填充各腔室，将填充后的小网格作为种子进行2x2双轴反射平铺。

**输入结构**：
- 约6x6网格，黑(0)背景
- 灰(5)墙壁像素将网格分隔为3-5个不规则4-连通腔室（腔室内部为黑(0)空区域）
- 墙壁上嵌有若干标记像素：颜色为红(2)、蓝(1)或绿(3)，每个标记像素占据一个原本属于墙壁的位置（即该像素替代了灰(5)）
- 每个腔室至少有2个正交邻接的标记像素
- 生成约束：每个腔室邻接的标记像素中存在唯一的多数颜色（不出现票数并列）；灰(5)墙壁加标记像素将网格完全分隔（每个腔室都是封闭的4-连通黑色区域）

**规则**：
1. 识别背景色黑(0)和墙壁色灰(5)
2. 对每个4-连通黑(0)腔室，收集与其正交邻接的所有非黑非灰标记像素的颜色，取出现次数最多的颜色作为该腔室的填充色
3. 将腔室内所有黑(0)像素重涂为该填充色
4. 以填充后的6x6完整网格（含墙壁和标记像素）为种子瓦片T
5. 构建12x12输出：左上象限 = T；右上象限 = T的水平镜像（每行像素序列左右翻转）；左下象限 = T的垂直镜像（行序列上下翻转）；右下象限 = T的180度旋转（水平+垂直翻转）
6. 墙壁和标记像素在种子T中保持原色，参与平铺

**关键洞察**：输入中看不到最终输出的任何一个象限——必须先通过投票推断各腔室颜色（这需要对比多个示例确认"多数决"规则），再将结果平铺。投票和平铺是两种本质不同的操作（局部统计 vs 全局几何），通过中间产物（种子瓦片）紧密耦合。

## 新题 5：桥接连通性路由部分行到不同模板

**组合逻辑**：[connectivity_test](创新：连通性作为路由机制选择目标模板) → [complete + prefix_map](已有)

**来源原语**：connectivity_test, bridge_path, connectivity ← 239be575；complete, template_row, prefix_segment, col_alignment, prefix_map_complete, encoding_map ← 82819916

**依赖链**：桥接路径的4-连通关系 → 确定每条部分行对应哪个模板 → 使用对应模板的颜色图案通过前缀映射补全该行。删除桥接路由则模板选择未知，删除补全则无输出变换。

通过青色桥接路径的连通关系确定每条部分行应参照哪个模板行，然后按前缀颜色映射规则补全。

**输入结构**：
- 约14x18网格，黑(0)背景
- 顶部区域（行0-2）：两条完整的非黑模板行。模板A位于行0，由红(2)和蓝(1)两种颜色的像素交替排列构成（贯穿整行宽度）。模板B位于行2，由绿(3)和黄(4)两种颜色交替排列构成。行1为全黑分隔行
- 底部区域（行5起）：4-6条部分行（前缀行），每条从列0开始有一段连续非黑前缀（长度>=2），前缀之后为黑色。前缀行之间至少隔一行全黑
- 桥接区域（行3-4及部分行之间的空间）：青(8)像素构成的单像素宽路径，从某些部分行向上延伸连接到模板A或模板B所在的行（通过正交邻接到达模板行的像素）
- 生成约束：每条部分行恰好通过青(8)桥接连通到一条模板行（不存在同时连通两条模板或不连通任何模板的情况）；桥接路径互不相交；每条部分行的前缀包含恰好两种非黑颜色，与对应模板同列位置配对后能推导出一对一的颜色映射

**规则**：
1. 以所有非黑像素为前景，构建4-连通分量
2. 对每条部分行，确定其所属连通分量是否包含模板A（行0）或模板B（行2）的像素。包含哪个模板则该模板即为该行的"目标模板"
3. 对每条部分行的前缀，将前缀中每个像素的颜色与目标模板同列位置的颜色配对，推导颜色映射M：若前缀像素颜色为X且对应模板位置颜色为a，则M[a]=X
4. 将目标模板从列0到最后一列的完整颜色序列，通过映射M逐列转换，生成该部分行的完整输出行（覆盖原有前缀和黑色区域）
5. 保留模板行A和B不变，保留青(8)桥接路径不变

**关键洞察**：桥接路径不是装饰——它是信息路由，物理上决定每行补全时参照哪个模板。单看部分行的前缀颜色无法区分目标模板（两种映射可能产生相同的前缀），必须追踪桥接路径的连通关系才能确定。

## 新题 6：标记指向滑动后轨迹交替涂色

**组合逻辑**：[slide + collision_stop](已有) → [recolor/alternating_parity](创新：对滑动产生的轨迹线段应用奇偶交替涂色) + [erase]

**来源原语**：slide, sprite, contact_edge_align, collision_stop ← 11dc524f；recolor, alternating_parity_recolor, sequential_index ← a5f85a15；erase, marker_pixel ← d255d7a7

**依赖链**：标记像素方位 → 确定滑动方向 → 精灵体滑向边框碰撞停止 → 滑动路径形成轨迹 → 轨迹长度由碰撞距离决定 → 对轨迹奇偶交替涂色。轨迹的存在和长度都依赖滑动结果。

每个精灵体沿标记指示的反方向滑动至灰色边框，移动路径上留下的轨迹被奇偶交替涂色。

**输入结构**：
- 约15x15网格，黑(0)背景，四边各有1像素宽的灰(5)边框
- 2-3个小型单色精灵体（4-连通，3-6像素，颜色各不相同，不使用灰(5)、红(2)、黄(4)），位于网格内部，互不正交邻接，不触碰灰(5)边框
- 每个精灵体的某一侧（上/下/左/右之一）正交邻接恰好一个红(2)标记像素，标记位于精灵体外部
- 每个精灵体在滑动方向上的"前导边"宽度恰好为1像素（保证轨迹为单像素宽线段）
- 生成约束：精灵体到滑动方向上灰(5)边框之间的路径上无其他非黑像素；各精灵体的滑动轨迹互不交叉；每个精灵体的轨迹长度至少为3（保证交替模式可见）

**规则**：
1. 对每个精灵体，确定红(2)标记相对于精灵体的方位（上/下/左/右）。滑动方向为标记方位的反方向（标记在左 → 向右滑动）
2. 将精灵体沿滑动方向整体平移，直到其前导边正交邻接灰(5)边框像素时停止（碰撞停止）
3. 精灵体从起始位置移动到最终位置过程中，其前导边经过的所有中间位置像素（不含最终位置处精灵体本身占据的像素，也不含起始位置处精灵体本身占据的像素）构成"轨迹线段"
4. 对轨迹线段中的像素，沿滑动方向从最终位置最近端开始编号（索引从0起）：偶数索引像素涂为精灵体的原始颜色，奇数索引像素涂为黄(4)
5. 精灵体在最终位置保持原色不变
6. 擦除所有红(2)标记像素（改为黑(0)）
7. 各精灵体的处理互相独立，顺序不影响结果

**关键洞察**：轨迹长度不是预设常数——它取决于精灵体初始位置到边框的距离和滑动方向。交替涂色的视觉效果因轨迹长短而变化，需要对比不同长度的轨迹才能排除"固定长度交替"等错误假设，归纳出通用的"奇偶"规则。

## 新题 7：内部空分隔线既是断裂标记又是镜像轴

**组合逻辑**：[detect_empty_row_col](创新：检测到的空行列直接充当镜像轴) → [mirror](创新：标记像素决定镜像方向而非轴位置) + [recolor]

**来源原语**：separator_row_col, bounding_box, inside_bbox, detect_empty_row_col ← da2b0fe3；mirror, foreground_object, adjacency, mirror_toward_marker_recolor ← 2bcee788；recolor ← 多题共有

**依赖链**：检测前景对象内部的空分隔行/列 → 该行/列成为镜像的对称轴 → 标记像素位于分隔线的某一侧决定哪半部分被镜像 → 镜像副本重涂色。轴位置来自检测，镜像方向来自标记，三者缺一不可。

在前景对象的边界框内找到唯一的空分隔行或列作为镜像轴，将标记像素指示一侧的子对象沿轴镜像并重涂色。

**输入结构**：
- 约14x14网格，黑(0)背景
- 一个大型不规则前景对象，颜色为橙(7)，4-连通，占据网格中央约6x8到8x10的区域，形状不对称
- 该对象的边界框内部恰好存在一条完全为黑(0)的行（水平分隔）或列（垂直分隔），将对象视觉上分为两个子部分
- 一个红(2)标记像素位于对象外部，与对象的某一侧正交邻接。标记明确位于分隔线的某一侧（例如水平分隔线上方或下方）
- 生成约束：分隔行/列严格位于边界框的第一行/列和最后行/列之间（不在边缘）；对象在分隔线两侧的部分均包含至少4个橙(7)像素；红(2)标记像素只有一个

**规则**：
1. 找到前景对象（所有橙(7)像素）的边界框
2. 在边界框内部扫描：找到一条在边界框列范围内全部为黑(0)的行，或在边界框行范围内全部为黑(0)的列。这就是分隔线
3. 分隔线将橙(7)对象分为两个子部分。确定红(2)标记像素在分隔线的哪一侧（对水平分隔线：标记在上方还是下方；对垂直分隔线：标记在左侧还是右侧）
4. 将标记像素所在一侧的子部分沿分隔线做镜像反射。对水平分隔线：上下翻转；对垂直分隔线：左右翻转。镜像以分隔线为对称轴
5. 镜像副本的所有像素涂为绿(3)。若镜像副本与分隔线另一侧的原有橙(7)像素位置重叠，绿(3)覆盖橙(7)
6. 分隔线保持黑(0)不变
7. 标记侧的原始橙(7)子部分保持不变
8. 擦除红(2)标记像素（改为黑(0)）

**关键洞察**：空分隔行/列拥有双重身份——它既是对象内部结构的断裂标记（需要检测其存在和位置），又是镜像操作的几何对称轴。标记像素增加了第三层决策：它不决定轴在哪里（轴由分隔线决定），而是决定哪一半被镜像——三种信息来自三种不同的输入元素。

## 新题 8：互补形状匹配后以颜色反转方式嵌入缺口

**组合逻辑**：[shape_match + complementary_shape](已有) → [color_invert](创新：匹配后不直接填入而是做边界框内颜色反转再嵌入，产生"负片"效果)

**来源原语**：shape_match, template_gap, source_shape, complementary_shape, unique_complement ← 18447a8d；color_invert, binary_pattern ← 48131b3c；fill ← 7c8af763

**依赖链**：形状匹配确定精灵体-缺口配对 → 对精灵体在边界框内做颜色反转（精灵体色→黑，背景→模板色） → 将反转结果嵌入缺口 → 缺口呈现精灵体的"负片"。匹配解决"去哪里"，反转解决"变成什么"。

将下方精灵体按形状匹配到上方模板缺口中，以颜色反转方式嵌入使缺口呈现精灵体的负片图案。

**输入结构**：
- 约16x12网格，黑(0)背景
- 上半区（行0-6）：2-3个矩形模板块，各自为不同单色（如红(2)、蓝(1)、绿(3)），每个模板块内部有一个由黑(0)像素构成的4-连通缺口（缺口形状各异，3-6像素）。模板块之间至少隔2列黑色。模板块尺寸约4x4到6x6
- 下半区（行8-11）：2-3个小型单色精灵体（4-连通，颜色与模板颜色均不同，如橙(7)、品红(6)、灰(5)），互不邻接
- 每个精灵体的形状与恰好一个模板缺口的形状全等（可能需要旋转或翻转）
- 生成约束：精灵体与缺口之间存在唯一一对一配对；每个缺口完全被模板颜色包围（是封闭黑色区域）；每个精灵体的边界框尺寸与对应缺口的边界框尺寸相同（无需缩放）；精灵体形状各不相同

**规则**：
1. 对每个下半区精灵体，提取其边界框内的二值图案（精灵体颜色→前景，黑(0)→背景）
2. 对每个上半区模板缺口，提取其边界框内的二值图案（黑(0)缺口像素→前景，模板颜色→背景）
3. 匹配：将每个精灵体的二值图案与各缺口的二值图案比较。对精灵体依次尝试以下变换：原始方向、水平翻转、垂直翻转、90度顺时针旋转、90度旋转+水平翻转、180度旋转、270度顺时针旋转、270度旋转+水平翻转。取第一个使精灵体二值图案与某缺口二值图案完全一致的变换，建立配对
4. 对每个已配对的精灵体，在其（经变换后的）边界框内执行颜色反转：精灵体颜色的像素 → 黑(0)，边界框内原为黑(0)的像素 → 对应模板的颜色
5. 将反转后的图案放入缺口位置（与缺口边界框对齐）
6. 下半区的原始精灵体被擦除（改为黑(0)）
7. 模板块中缺口以外的像素保持原色不变

**关键洞察**：形状匹配解决配对问题，但颜色反转改变了填充语义——精灵体的轮廓在缺口中反而变为黑色"镂空"，而精灵体边界框内的空白区域被填为模板色。最终效果是缺口内呈现精灵体的"负片"，这一反转规则需要对比多个示例才能与"直接填入"区分开。

## 新题 9：帧距离排序碎片拼合顺序

**组合逻辑**：[距离测量(concentric_fill的空间距离概念)](创新：距离用于排序而非着色) → [packing](创新：拼合优先级由外部空间参照物决定而非碎片自身属性)

**来源原语**：concentric_fill, concentric_layer, nesting_hierarchy ← a3f84088（距离概念）；packing, polyomino_fragment, compact_rectangle, non_overlap_packing, descending_area_place ← b7cb93ac；hollow_rectangle, enclosure ← b9b7f026（帧作为参照物）

**依赖链**：灰色帧提供空间参照点 → 计算每个碎片到帧的最小距离 → 距离排序取代默认的面积排序 → 按距离顺序执行拼合。帧在输出中消失，但它决定了拼合结果的形态。

以网格中的灰色方帧为空间参照，按各碎片到帧的最小曼哈顿距离从近到远排序后，将碎片拼入一个无缝紧凑矩形。

**输入结构**：
- 约18x18网格，黑(0)背景
- 一个灰(5)空心正方形帧（边长约8-10像素，边框宽1像素），位于网格中央或偏某方向
- 4-6个小型单色多连块碎片（4-连通，各3-6像素），颜色各不相同（从红(2)、蓝(1)、绿(3)、黄(4)、橙(7)、品红(6)中选取），散布在帧内外各处
- 碎片形状各不相同，碎片总面积恰好等于某个矩形的面积
- 生成约束：各碎片到灰(5)帧像素的最小曼哈顿距离互不相同（保证排序无歧义）；碎片不触碰帧的灰(5)像素（最小距离>=1）；存在一种合法拼合方案能将所有碎片无重叠填满目标矩形

**规则**：
1. 对每个碎片，计算其所有像素到最近灰(5)帧像素的曼哈顿距离，取最小值作为该碎片的"帧距离"
2. 按帧距离从小到大排序碎片（距帧最近的碎片最先处理）
3. 确定目标矩形尺寸：总面积 = 所有碎片面积之和。在所有面积等于总面积的矩形中，选择宽高差（|宽-高|）最小的；若宽高差相同，选宽>=高的（宽为水平方向，高为垂直方向）
4. 按排序顺序依次放置碎片。对当前碎片，依次尝试以下8种变换：原始方向、水平翻转、垂直翻转、90度顺时针旋转、90度旋转+水平翻转、180度旋转、270度顺时针旋转、270度旋转+水平翻转。对每种变换，从矩形左上角(0,0)开始逐行从左到右扫描放置位置，选取第一个使碎片完全在矩形内且不与已放置碎片重叠的位置
5. 每个碎片保持其原始输入颜色
6. 输出仅为填满的紧凑矩形，灰(5)帧和黑色背景均丢弃

**关键洞察**：灰色帧在输出中完全不出现——它唯一的作用是提供距离参照以确定拼合顺序。改变帧的位置会重新排列各碎片的距离排名，进而改变拼合结果。必须对比多个示例（帧位置不同导致排序不同导致拼合结果不同）才能归纳出"距离决定顺序"这一隐蔽规则，而非"面积决定顺序"或"颜色决定顺序"等替代假设。
