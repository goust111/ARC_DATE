## 新题 1：拓扑门控射线反射

**组合逻辑**：[计数/孔洞数](创新：孔洞奇偶性决定光学行为而非颜色映射) + [射线延伸/边界反射](创新：反射条件由精灵体拓扑决定而非固定颜色) + [重涂色](创新：射线继承反射体颜色)

**来源原语**：计数、封闭区域、孔洞数映射颜色、忽略干扰项(e3721c99)；射线延伸、边界反射、对角射线种子、特定色反射射线(7e2bad24)；精灵体(e3721c99)

**依赖链**：孔洞计数决定每个精灵体是反射器还是透明体 → 反射/透射属性决定射线路径拓扑 → 射线路径决定哪些像素被绘制 → 反射体颜色决定射线后续段的颜色

将一条对角射线从种子出发穿越网格，射线遇到偶数孔洞的精灵体时反射并继承其颜色，遇到奇数孔洞的精灵体时穿透并覆盖。

**输入结构**：黑(0)背景，约20x20网格。一条由2-3个像素组成的8-连通蓝(1)对角射线种子位于网格的一个角落区域。网格中散布4-6个不同颜色（红(2)、绿(3)、黄(4)、橙(7)等，均非黑非蓝）的精灵体，每个精灵体是4-连通的单色不规则图形（5-15像素），部分精灵体包含封闭孔洞（被精灵体像素完全包围的背景色区域，不触及精灵体边界框边缘），孔洞数量从0到3不等。精灵体之间间距至少3个像素，使射线有足够的空间在它们之间传播。生成约束：射线种子的对角延伸方向在离开网格前至少穿越2个精灵体。

**规则**：
1. 对每个非蓝精灵体，计数其封闭孔洞数（完全被精灵体像素包围且不触及精灵体边界框边缘的背景色连通区域数）。
2. 偶数孔洞（含0）的精灵体为"反射体"；奇数孔洞的精灵体为"透射体"。
3. 从射线种子的外侧端点出发，沿种子所示的对角方向（四个对角方向之一，由种子像素排列确定）逐像素延伸射线。
4. 射线经过背景像素时，将其涂为当前射线颜色（初始为蓝(1)）。
5. 若射线的下一个像素属于反射体精灵体：不涂该像素；根据射线与精灵体边界的接触面方向反射——水平边界翻转行方向，垂直边界翻转列方向。反射后，当前射线颜色更新为该反射体的颜色，后续射线段以此新颜色绘制。
6. 若射线的下一个像素属于透射体精灵体：将该像素涂为当前射线颜色（覆盖原色），射线方向不变，继续前进。
7. 射线到达网格边界时终止（不做边界反射）。
8. 若射线在同一步既触及反射体又触及边界，以反射优先。

**关键洞察**：精灵体的外形无法区分反射体与透射体——必须计数内部封闭孔洞的奇偶性才能判定光学行为；这是一个纯拓扑属性，将形状的"内部结构"与射线的"外部路径"耦合在一起。

## 新题 2：折叠组装铺贴源

**组合逻辑**：[折叠/透明叠加/对称互补](创新：折叠恢复的不是最终输出而是铺贴所需的源图案) + [平铺/纵向重复](创新：铺贴的瓦片不直接存在于输入中，需先组装)

**来源原语**：折叠、透明叠加、分隔线、对称互补、前景优先(e3497940)；平铺、纵向重复、行带、前景行带铺满画布(8eb1be9a)

**依赖链**：识别分隔线并分出左右半区 → 折叠右半区叠加到左半区以恢复完整瓦片条带 → 用完整条带作为铺贴单元纵向重复填满输出网格

将网格沿垂直分隔线折叠，将互补的左右半区合成一个完整的图案条带，再将该条带纵向平铺填满整个输出。

**输入结构**：黑(0)背景，约11x(2k+1)网格（奇数列宽以容纳分隔线）。一条非背景色的垂直分隔列（如灰(5)）贯穿全高，将网格分为等宽的左右两个区域。左区域中有一条连续的水平条带（高度h行，h < 网格高度），条带内包含若干前景像素（使用红(2)、蓝(1)、绿(3)等颜色），但条带内有明显的背景空缺。右区域在条带对应行的镜像位置包含互补的前景像素——左区域有前景的位置右区域为背景，左区域为背景的位置右区域有前景（镜像后颜色与左区域一致）。条带以外的行全为背景色。生成约束：完整条带高度h整除输出网格高度；左右两个片段单独看都不构成完整图案（各自至少缺失30%的前景像素）。

**规则**：
1. 识别垂直分隔列，将网格分为左区域和右区域。
2. 将右区域水平镜像（左右翻转）。
3. 将镜像后的右区域透明叠加到左区域：对每个像素位置，若某一侧为前景则取该前景色，若两侧均为前景则颜色必然一致（取任一即可），若两侧均为背景则为背景。此步骤产出完整的图案条带。
4. 移除分隔列。输出网格宽度等于单侧区域宽度，高度与输入相同。
5. 以完整条带为纵向铺贴单元，从条带原始行位置出发，向上和向下重复该条带，直至填满输出网格的全部行。

**关键洞察**：输入中不存在可直接铺贴的完整图案——左右两半各持有条带的互补碎片，只有通过折叠合成才能获得铺贴源；折叠是铺贴的前提，铺贴是折叠的目的，删除任一步骤均无法求解。

## 新题 3：轮廓长度制约同心填充深度

**组合逻辑**：[滑动/轮廓邻接/最长贴边路径](创新：轮廓路径长度作为数值参数而非终点定位) + [同心层填充/奇偶距离决定颜色](创新：填充深度由外部测量决定而非填满整个区域) + [控制像素/以控制点为中心](沿用)

**来源原语**：滑动、轮廓邻接、障碍轮廓、标记像素、最长贴边路径(97c75046)；同心层填充、矩形边框、控制像素、奇偶距离决定颜色、以控制点为中心(b7fb29bc)

**依赖链**：标记像素沿视线滑到边框外轮廓 → 沿轮廓走最长贴边路径并计步L → L成为同心填充的层数上限 → 从控制像素出发按奇偶涂L层环

标记像素滑向矩形边框并沿其外轮廓行走，行走步数决定边框内部以控制像素为中心的同心环填充层数。

**输入结构**：黑(0)背景，约18x18网格。2-3个不重叠的矩形一像素宽边框，每个边框使用不同的前景色（如红(2)、绿(3)、蓝(1)），每个边框内部至少7x7像素以容纳多层同心环。每个边框内部恰有一个与边框同色的控制像素，位于非中心位置。每个边框外部恰有一个与该边框同色的标记像素，该标记像素与边框之间恰好存在一条水平或垂直的无障碍视线（视线上全为背景色）。生成约束：边框彼此不接触且不触及网格边界；每个标记像素的最长贴边路径长度介于3到该边框可容纳的最大同心环层数之间。

**规则**：
1. 对每个边框，找到与其同色的外部标记像素。
2. 沿标记像素与边框之间的唯一视线方向，将标记像素滑到边框外轮廓旁的最后一个背景像素位置。
3. 从到达位置出发，尝试沿边框外轮廓的两个可能方向（贴着边框外壁4-邻接行走）行走，选择行走距离更长的那个方向。计行走步数为L。
4. 在边框内部，计算每个背景像素到控制像素的切比雪夫距离d。
5. 仅填充距离d在1到L（含）范围内的像素：d为奇数涂黄(4)，d为偶数涂橙(7)。
6. 距离d > L的内部背景像素保持黑(0)。
7. 边框、控制像素、标记像素均保留原色不变。
8. 多个边框独立处理，互不影响。

**关键洞察**：边框外部的空间测量（轮廓行走步数）决定了边框内部的填充深度——外部计算与内部填充分属不同的几何系统，但通过一个数值参数紧密耦合。

## 新题 4：引导像素路由面板图案交换

**组合逻辑**：[引导像素/角落定位/角落色转移后消](创新：引导像素的位置编码配对关系而非仅提供颜色) + [交换/图案掩码/分隔面板/成对交换](创新：交换对象由外部引导像素的空间位置决定而非固定邻接) + [擦除](沿用)

**来源原语**：引导像素、角落定位、角落色转移后消(aabf363d)；交换、图案掩码、分隔面板、成对交换、底色作为涂色源(5a719d11)；擦除(aabf363d)

**依赖链**：读取角落引导像素的颜色和位置 → 颜色匹配到对应面板 → 位置对角配对确定交换搭档 → 执行图案掩码交换并以引导像素颜色重涂 → 擦除引导像素

网格角落的引导像素按颜色锁定面板、按位置对角配对，控制哪两个面板交换图案掩码并决定交换后的涂色，最后引导像素消失。

**输入结构**：约15x15网格，灰(5)分隔色形成完整的空白行和空白列，将网格分割为2x2排列的四个等大矩形面板。四个面板分别有不同的底色（红(2)、绿(3)、蓝(1)、黄(4)各一），每个面板内含一个由橙(7)像素构成的少数图案（4-连通不规则图形，4-10像素）。网格的四个角落中恰好有两个角落各放置一个引导像素，每个引导像素的颜色等于某个面板的底色（两个引导像素颜色不同，分别匹配不同的面板）。生成约束：两个引导像素匹配的面板不在同一行也不在同一列（即它们处于对角位置），确保交换路由是非平凡的对角交换。

**规则**：
1. 识别四个角落中的两个引导像素，记录各自的颜色和角落位置（左上、右上、左下、右下）。
2. 每个引导像素的颜色匹配一个面板（颜色等于该面板底色的那个面板）。两个匹配到的面板构成交换对。
3. 对交换对中的两个面板，各自提取其橙(7)图案的形状掩码（像素相对于面板左上角的偏移集合）。
4. 将两个面板各自清除为纯底色（擦除原有图案）。
5. 将面板A的图案掩码粘贴到面板B的对应位置，涂色为匹配面板A的那个引导像素的颜色（即面板A的底色）。
6. 将面板B的图案掩码粘贴到面板A的对应位置，涂色为匹配面板B的那个引导像素的颜色（即面板B的底色）。
7. 擦除两个引导像素为黑(0)。
8. 未参与交换的两个面板、所有分隔线均保持不变。

**关键洞察**：引导像素身兼三职——通过颜色选择面板、通过角落位置暗示对角配对关系、完成使命后自我消除——它们不只是颜色容器，更是编码了空间路由信息的指令像素。

## 新题 5：尾部定向收缩印章轨迹

**组合逻辑**：[印章覆盖/对角偏移重复/尺寸决定步幅](创新：印章方向由尾部向量决定而非固定对角) + [尾部向量/尾部指示位移](创新：尾部编码印章方向而非滑动位移) + [收缩楔形/逐行交换双色](创新：每次印章副本在垂直于传播方向上收缩并翻转双色)

**来源原语**：印章覆盖、对角偏移重复、尺寸决定步幅、裁剪(e619ca6e)；尾部向量、尾部指示位移、尾部决定平移(c6e1b8da)；收缩楔形、逐行交换双色(b5bb5719)

**依赖链**：尾部方向 → 确定印章传播轴 → 矩形自身尺寸 → 确定步幅间距 → 每个副本收缩+色反转 → 裁剪越界部分 → 副本宽度归零时终止

每个带尾矩形沿尾部方向按自身尺寸为步幅反复印章，每个副本比前一个在垂直于传播方向上缩窄两像素并翻转内部双色条纹，直到副本收缩至零或完全越界。

**输入结构**：橙(7)背景，约18x22网格。2-3个前景矩形，每个矩形内部填充双色水平条纹图案（如红(2)与灰(5)逐行交替），矩形宽度至少5像素、高度至少4像素。每个矩形从其一条边的中央伸出一个一像素宽的尾部（尾部颜色为栗(9)），沿上、下、左、右四个基本方向之一延伸，长度至少2像素。生成约束：各矩形及其最终印章轨迹的范围互不重叠；尾部不与其他矩形相交。

**规则**：
1. 对每个矩形，识别并移除其尾部。尾部所指方向即为印章传播方向。
2. 设矩形高度为h、宽度为w。若尾部方向为垂直（上或下），步幅为h，每个副本宽度缩减2（左右各缩1）；若尾部方向为水平（左或右），步幅为w，每个副本高度缩减2（上下各缩1）。
3. 第k个副本（k=1,2,...）放置在距原矩形位置沿传播方向偏移k * 步幅处。
4. 第k个副本在收缩维度上比原矩形缩减2k像素（两侧各缩k像素），非收缩维度不变。居中于原矩形在该维度的中心线。
5. 每个副本内部的双色条纹相对于前一个副本互换（第1个副本相对原矩形互换红↔灰，第2个副本换回，以此交替）。
6. 若副本的收缩维度降至0或更小，终止该矩形的印章序列。
7. 若副本部分越出网格边界，仅保留界内部分。
8. 原矩形（去尾后）保留不变。各矩形的印章序列独立绘制，互不覆盖。

**关键洞察**：尾部是方向指令、矩形尺寸是步幅参数、每次复制都是原件的退化回声——三个来自不同源题的原语（尾部→方向、尺寸→步幅、收缩+色反转→衰减）合流为一个自衰减复制器，缺少任一参数都无法确定完整的印章序列。

## 新题 6：对称性过滤的距离着色

**组合逻辑**：[反射对称/交集差集分别着色](创新：对称性检测作为过滤器而非最终输出) + [同心层填充/奇偶距离决定颜色/以控制点为中心](创新：距离着色仅作用于通过对称性筛选的像素子集)

**来源原语**：反射对称、前景像素、交集差集分别着色(a8610ef7)；同心层填充、控制像素、奇偶距离决定颜色、以控制点为中心(b7fb29bc)

**依赖链**：水平反射对称检测将前景像素分为对称集和非对称集 → 非对称集统一标灰 → 对称集中每个像素计算到控制像素的切比雪夫距离 → 按距离奇偶分别着色

前景像素先经水平反射对称测试分为两组：通过测试的按到控制像素的距离奇偶着色，未通过的统一标灰。

**输入结构**：黑(0)背景，约13x13网格。一组蓝(1)前景像素构成一个不规则图形，该图形关于网格水平中线并非完美对称——部分像素在镜像行有对应前景像素，部分没有（至少5个像素有镜像对应，至少3个没有）。网格中另有一个红(2)控制像素，位于非水平中线位置，紧邻或嵌入前景图形中。生成约束：控制像素不在水平中线上；对称像素覆盖至少3个不同的切比雪夫距离值。

**规则**：
1. 对每个蓝(1)前景像素，设其位于(r, c)，检查位置(H-1-r, c)是否也是蓝(1)前景像素（H为网格高度）。
2. 若镜像位置也是前景像素：该像素归入"对称集"。若不是：归入"非对称集"。
3. 将所有非对称集像素重涂为灰(5)。
4. 对对称集中的每个像素，计算其到红(2)控制像素的切比雪夫距离d = max(|r - r_ctrl|, |c - c_ctrl|)。
5. d为奇数的对称像素涂为黄(4)；d为偶数的对称像素涂为绿(3)。
6. 控制像素保持红(2)不变。
7. 背景像素保持黑(0)不变。

**关键洞察**：对称性检测（全局几何属性）充当门控过滤器，决定哪些像素有资格参与距离着色（局部度量属性）——两个操作分属不同几何范畴（反射 vs. 辐射），它们的交汇创造出在任一源题中都不存在的分层着色逻辑。

## 新题 7：旋转模板着色带角标验证的分隔网格

**组合逻辑**：[旋转/模板掩码形状对应](创新：旋转后的模板像素映射到网格区域而非缩放到掩码) + [压缩/分隔网格/四角同色定区域色/角标一致性](创新：角标验证对旋转映射结果做二次过滤)

**来源原语**：旋转、像素放大、多色模板、模板掩码形状对应、旋转缩放后匹配(103eff5b)；压缩、分隔网格、顶点标记、角标一致性、四角同色定区域色(7837ac64)；重涂色(多个源题)

**依赖链**：识别小模板并旋转90° CW → 旋转后模板的行列对应分隔网格的行列带 → 每个模板像素的颜色提议对应区域的填充色 → 角标一致性验证决定区域是否接受提议色 → 不一致区域填黑

小型多色模板旋转90度后，其每个像素的颜色映射到分隔网格的对应区域，但只有四个角标全部一致的区域才接受该颜色，其余区域填黑。

**输入结构**：黑(0)背景，约17x17网格。灰(5)分隔条（1像素宽）构成一个M行N列的矩形区域网格（如4行3列共12个区域）。部分区域顶点（分隔条交叉点的对角位置）有单像素标记，颜色为黄(4)或绿(3)——有些区域的四个角标全为黄(4)，有些全为绿(3)，有些角标颜色混杂或缺失。网格一角（与分隔网格间隔至少2个背景像素）放置一个N行M列的小型多色模板（一个像素代表一个区域），使用红(2)、蓝(1)、橙(7)、栗(9)等颜色。生成约束：模板旋转90° CW后变为M行N列，与分隔网格的区域布局一一对应；至少3个区域角标一致，至少2个区域角标不一致。

**规则**：
1. 识别分隔网格和小型多色模板。
2. 将模板顺时针旋转90度（原模板第1列从下到上变为旋转后第1行从左到右）。
3. 旋转后模板的第i行第j列像素对应分隔网格的第i行第j列区域。该像素颜色即为该区域的"提议颜色"。
4. 对每个区域，检查其四个对角角标像素（区域四角处、位于分隔条交叉点对角方向的像素）。
5. 若四个角标全为同一非灰非黑颜色（一致）：将该区域内部所有像素填充为提议颜色。
6. 若角标不全一致（颜色混杂、部分缺失、或全为灰/黑）：将该区域内部所有像素填充为黑(0)。
7. 分隔条、角标像素、原始模板均保持不变。

**关键洞察**：模板提供"应该是什么颜色"（需要几何变换才能读取），角标提供"允不允许着色"（需要拓扑验证才能判定）——两个独立信息源交叉决定每个区域的最终状态，缺少任何一个都无法确定输出。

## 新题 8：遮挡恢复揭示隐藏障碍制约充能平移

**组合逻辑**：[遮挡恢复/滑动](创新：恢复的目的不是画面还原而是揭示运动障碍) + [平移/逐步充能/能量上限步数](创新：运动步数多了一个障碍距离上限) + [擦除](沿用)

**来源原语**：遮挡恢复、实心矩形、尾部向量、尾部决定平移(c6e1b8da)；平移、逐步充能、带边框容器、能量上限步数、颜色匹配配对、目标标记(271d71e2)；擦除(aabf363d)

**依赖链**：识别被遮挡的静态矩形并恢复其完整形状 → 恢复后出现的矩形可能阻挡容器移动路径 → 容器移动步数 = min(尾部长度, 灰色内部格数, 到最近恢复后障碍的距离-1) → 执行平移并逐步充能 → 擦除尾部

先恢复被部分遮挡的静态矩形以揭示真实的障碍布局，再让带尾容器向目标平移——移动步数受灰色燃料、尾部长度和新暴露障碍三者中最小值制约。

**输入结构**：黑(0)背景，约18x18网格。2-3个静态实心矩形，各自颜色不同（如红(2)、绿(3)），部分矩形的边界框区域被其他叠加物覆盖（某些像素被另一种颜色的前景遮挡），使其看起来不完整。1-2个带边框容器：黑(0)边框围成的矩形，内部由灰(5)和橙(7)像素混合填充（灰色为未充能，橙色为已充能）。每个容器的一条边外侧紧贴一个栗(9)头部精灵（单像素），从头部精灵出发沿一个基本方向延伸一条一像素宽的栗(9)尾部（长度至少2像素）。尾部延伸方向上远处有一个同色栗(9)目标标记像素。生成约束：恢复遮挡后，至少有一个静态矩形部分阻塞了某个容器的移动路径，且该障碍距离比尾部长度和灰色格数都更紧（即障碍距离是三者中的最小值），使得不恢复遮挡就会算错移动步数。

**规则**：
1. 识别所有非容器、非尾部的彩色前景矩形。对每个这样的矩形，计算其完整边界框，将边界框内所有非该颜色的像素恢复为该颜色（遮挡恢复），恢复顺序：面积更大的矩形先恢复，后恢复的不覆盖先恢复的。
2. 对每个带边框容器，从其栗(9)头部精灵确定尾部方向（尾部延伸方向即移动方向）。
3. 计算三个移动上限：(a) 尾部长度（尾部像素数）；(b) 容器内部灰(5)像素总数；(c) 容器前进边缘沿移动方向到最近障碍物（恢复后的静态矩形或网格边界）的距离减1（避免重叠）。
4. 实际移动步数 = min(a, b, c)。
5. 将容器整体（边框+内部）沿移动方向平移该步数个像素。
6. 平移后，将容器内部的灰(5)像素从头部朝向一侧开始逐个转为橙(7)，共转换"实际移动步数"个灰像素。
7. 擦除尾部和目标标记为黑(0)。
8. 绘制优先级：恢复后的静态矩形在最底层，容器在其上层。若容器平移后与静态矩形在位置上重叠，容器覆盖静态矩形。

**关键洞察**：输入中被遮挡的矩形看起来只是残缺图形，但恢复其完整形状后它们成为容器移动路径上的障碍——这些"隐藏障碍"在输入中不可见，必须先完成遮挡恢复才能正确计算移动距离，否则容器会"穿墙"移动到错误位置。

## 新题 9：面积图例驱动的精灵体重涂色

**组合逻辑**：[计数/保留颜色与面积](创新：像素计数用于查表而非拉直) + [颜色图例/图例行内配对](创新：图例编码"长度→颜色"映射而非直接配色) + [重涂色](创新：原地重涂而非几何变换)

**来源原语**：计数、保留颜色与面积、前景掩码(dce56571)；颜色图例、图例行内配对(0becf7df)；孔洞数映射颜色(e3721c99)；重涂色(多个源题)

**依赖链**：解析图例条目 → 每条水平线段的长度定义一个"面积→颜色"映射 → 计数每个灰色精灵体的像素总数 → 查表匹配面积 → 原地重涂精灵体为对应颜色

左上角的颜色图例用不同长度的水平色条编码"像素面积→目标颜色"映射；对网格中每个灰色精灵体计数其像素总数，在图例中查找等长条目，将精灵体原地重涂为该条目的颜色。

**输入结构**：黑(0)背景，约15x15网格。左上角区域有一个颜色图例：3-4条水平线段纵向排列（每条占一行），每条线段颜色不同（如红(2)长3像素、蓝(1)长5像素、绿(3)长4像素、黄(4)长6像素），各条左端对齐。图例下方和右侧散布4-6个灰(5)精灵体，每个精灵体是4-连通不规则形状（3-8像素），形状各异但某些精灵体的像素总数相同。生成约束：每个精灵体的像素总数恰好等于图例中某一条线段的长度（像素数）；每个图例条目至少匹配一个精灵体；不存在像素数不在图例中的精灵体。

**规则**：
1. 解析图例：识别左上角区域中所有非背景色的水平连续线段。每条线段定义映射：像素数（线段长度）→ 颜色（线段颜色）。
2. 对图例区域之外的每个灰(5)精灵体（4-连通分量），计算其总像素数P。
3. 在图例中查找长度等于P的线段，获取其颜色C。
4. 将该精灵体的所有像素从灰(5)原地重涂为C，位置和形状完全保留。
5. 图例本身保持不变。
6. 处理顺序不影响结果（各精灵体互不相邻，独立重涂）。

**关键洞察**：图例的线段长度不是装饰属性而是编码了一个"面积→颜色"查找表——求解者必须跳出"图例直接展示颜色对应关系"的常规理解，转而将线段几何尺度本身视为查询键，再将每个不规则精灵体的面积作为查询值来检索目标颜色。

## 新题 10：缩放因子推断与模板补全

**组合逻辑**：[像素放大/模板掩码形状对应/旋转缩放后匹配](创新：缩放因子不给定需从局部匹配推断) + [外推/前缀匹配/完整模式续写缺失](创新：前缀是二维区块而非一维行序列) + [补全](创新：补全依赖推断出的缩放参数)

**来源原语**：像素放大、多色模板、模板掩码形状对应、旋转缩放后匹配(103eff5b)；外推、前缀匹配、补全、完整模式续写缺失(90f3ed37)；重涂色(多个源题)

**依赖链**：识别小模板和大型局部图案 → 尝试不同缩放因子k将模板顶部与局部图案对齐 → 确定k后用完整缩放模板补全缺失区域

一个小型多色模板的完整放大版本仅部分呈现在网格中；求解者必须通过比对现有部分与模板来推断缩放因子，再用该因子放大整个模板以补全缺失区域。

**输入结构**：黑(0)背景，约20x20网格。网格一角有一个小型多色模板（如3行4列），使用3-4种非黑颜色（如红(2)、蓝(1)、绿(3)、黄(4)）。网格的另一区域有一个大型局部图案：它是该模板按整数因子k（k在2到4之间）放大后的顶部若干行——即模板的前m行（m < 模板总行数）每个像素扩展为k x k同色块后的结果。大型图案的下方为背景（缺失部分）。生成约束：现有局部图案至少覆盖放大后模板的前2行像素块（即至少2*k行）；完整放大后的模板不超出网格范围；模板与局部图案不重叠。

**规则**：
1. 识别小型多色模板（位于角落的小型多色矩形区域）和大型局部图案（远离模板的大型多色区域）。
2. 推断缩放因子k：将模板的第一行的每个像素扩展为1xk同色块，尝试k=2,3,4,...直到扩展后的行与大型图案的前k行完全匹配（大型图案的前k行应为模板第一行像素各放大为kxk块的结果）。
3. 以确定的k值，将整个模板放大（每个模板像素→kxk同色块）。
4. 将放大后的完整模板覆盖到大型局部图案的位置：现有部分保持不变（验证一致性），缺失部分（原为背景的区域）用放大模板的对应像素填充。
5. 小型模板保留不变。

**关键洞察**：缩放因子是隐式信息——既未直接标注也无法从单一像素推断，必须通过将模板与大型局部图案进行二维对齐匹配才能确定；只有推断出正确的k值，才能计算出缺失区域的像素颜色，实现从"部分"到"完整"的补全。
