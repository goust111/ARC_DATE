## 新题 1：弹射路径上的精灵印章与墙侧镜像

**组合逻辑**：[射线延伸/ray_cast + 反射弹回/reflection_bounce](弹射路径确定印章位置) → [最近邻归属/nearest_assign](弹射点匹配最近精灵体) → [镜像/mirror](创新：弹射墙侧决定是否镜像，替代原语池中由标记颜色触发镜像的方式) → [印章覆盖/stamp](在弹射点印章精灵体)

**来源原语**：ray_cast + reflection_bounce（参考题 a3df8b1e）、nearest_assign（参考题 6855a6e4）、mirror（参考题 6855a6e4, 3e980e27）、stamp（参考题 3e980e27）、sprite（参考题 6855a6e4, 2c181942, 3e980e27）

**依赖链**：弹射路径产生弹射点序列 → 每个弹射点通过最近邻匹配决定使用哪个精灵体 → 弹射发生在左墙还是右墙决定该精灵体是否左右镜像 → 镜像后的精灵体印章到弹射点位置。删除任一环节（路径、匹配、镜像判定、印章），其余部分均无法独立产生正确输出。

在弹射点处印章最近的精灵体，弹射墙侧决定精灵体是否镜像翻转。

**输入结构**：黑(0)背景网格，约 15x20。网格中包含：(1) 一个绿(3)孤立像素作为弹射起点，位于网格下半部分；(2) 2-4 个小型单色精灵体（每个 3-6 像素，4-连通，非对称形状，颜色各不相同，取自红(2)、蓝(1)、黄(4)、橙(7)），分散在网格中部区域，彼此不相邻且不靠近左右边界。生成约束：精灵体之间的 Manhattan 距离至少为 6，确保最近邻归属无歧义；弹射路径不穿过任何精灵体的像素。

**规则**：
1. 从绿(3)起点像素出发，沿右上 45 度对角线方向移动，每经过一个格子绘制一个绿(3)像素。遇到左墙或右墙时水平方向反转（左变右或右变左），垂直方向始终向上。到达网格顶部边界外时停止。
2. 每个弹射点定义为路径中水平方向发生反转的那个格子（即紧贴左墙第 0 列或右墙最后一列的格子）。
3. 对每个弹射点，计算它到每个精灵体（以精灵体边界框中心为参考点）的 Manhattan 距离，选择距离最小的精灵体。
4. 若弹射点紧贴左墙（列 = 0），将所选精灵体左右镜像后以弹射点为中心印章到网格上；若紧贴右墙（列 = 宽度-1），直接以弹射点为中心印章，不做镜像。
5. 印章超出网格边界的部分裁剪丢弃。印章像素覆盖弹射路径的绿色像素但不覆盖其他精灵体的原始像素。后印章的覆盖先印章的（按弹射点从下到上的顺序处理）。

**关键洞察**：弹射发生在左墙时精灵体被镜像，右墙时不镜像——这条隐蔽规则必须通过对比至少两个弹射点的印章结果与原始精灵体形状才能归纳出来。

## 新题 2：面板对称差提取种子图案，阻挡像素裁剪周期平铺

**组合逻辑**：[透明叠加/transparent_overlay](创新：由合并叠加改为对称差/XOR 提取) → [种子图案/seed_motif + 周期重复/periodic_repeat + 平铺/tile](对称差结果作为种子周期平铺) → [切比雪夫距离/chebyshev_dist + 阻挡像素/blocker_pixel](创新：阻挡像素不限制生长尺寸而是擦除已铺像素)

**来源原语**：transparent_overlay + panel + panel_correspondence（参考题 bbb1b8b6）、seed_motif + periodic_repeat + tile + fill_grid（参考题 9b30e358）、chebyshev_dist + blocker_pixel（参考题 ff72ca3e）

**依赖链**：两面板的对称差决定种子图案的形状 → 种子图案以其边界框高度为周期纵向平铺 → 阻挡像素以切比雪夫距离擦除平铺结果中的近邻像素。种子提取依赖面板比较，平铺依赖种子，擦除依赖平铺结果与阻挡位置，三者紧密串联且每一步改变信息形态。

比较两面板的对称差得到种子图案，将其纵向周期平铺后，用阻挡像素按切比雪夫距离裁剪掉邻近区域。

**输入结构**：黑(0)背景网格，约 12x25。一条灰(5)分隔列将网格分为左右两个等宽面板（每个约 12x12）。左面板中有若干红(2)前景像素构成一个不规则图案（4-连通，5-12 像素）；右面板中有若干蓝(1)前景像素构成另一个不规则图案（4-连通，5-12 像素），两图案在面板坐标系中有部分重叠、部分独有区域。此外，网格中散布 2-3 个黄(4)阻挡像素，位于面板内部（不在分隔列上）。生成约束：两面板图案的对称差（在面板坐标系中仅一侧有前景的位置集合）非空，且边界框高度至少为 2；阻挡像素不与任何前景像素重合。

**规则**：
1. 将左右面板按相同坐标逐格比较。提取"对称差"位置：在面板坐标系中，恰好只有一个面板在该位置有前景像素的所有格子。这些格子构成种子图案，颜色统一设为绿(3)。
2. 计算种子图案的边界框高度 H。以 H 为周期，将种子图案在纵向上周期复制，填满左面板坐标范围内的整个网格高度。水平位置保持不变。
3. 对每个黄(4)阻挡像素，将平铺结果中所有切比雪夫距离小于等于 2 的绿(3)像素擦除为黑(0)背景。
4. 输出尺寸等于单个面板的尺寸（不含分隔列），仅包含存活的绿(3)像素和黑(0)背景。原始面板内容、分隔列、阻挡像素均不出现在输出中。

**关键洞察**：阻挡像素的作用不是限制种子的生成，而是在平铺完成后对结果做局部擦除——擦除半径（切比雪夫距离 <= 2）必须通过对比多个示例中阻挡像素周围的空洞大小才能归纳出来。

## 新题 3：重力下落后按内部面积排名分层结构重涂

**组合逻辑**：[重力下落/gravity_drop + 碰撞停止/collision_stop](矩形下落并堆叠) → [排序/sort + 长度排名/length_ranking](创新：按内部面积排名，而非原语池中按长度排名) → [重涂色/recolor + 角边内部分别涂色/corner_border_interior_recolored + 局部位置分类/local_position_classification](创新：重涂方案分层，排名决定涂色深度)

**来源原语**：gravity_drop + collision_stop + nearest_first（参考题 f0100645）、sort + length_ranking（参考题 97d7923e）、recolor + corner_border_interior_recolored + local_position_classification（参考题 b6afb2da）

**依赖链**：重力下落决定矩形最终位置 → 落定后计算每个矩形的内部面积并排名 → 排名等级决定该矩形获得哪种深度的结构重涂方案。删除重力步骤则位置错误；删除排名则无法确定涂色方案；删除结构分类则无法执行涂色。三者形成严格的信息变换链。

所有矩形先重力下落堆叠，再按内部面积排名，排名决定每个矩形获得何种深度的角-边-内结构涂色。

**输入结构**：黑(0)背景网格，约 15x15。包含 3-5 个实心单色矩形（每个至少 3x3，颜色取自红(2)、绿(3)、橙(7)、栗(9)，各矩形颜色不同）。矩形悬浮在不同高度，下方有空行。生成约束：不同矩形的列范围互不重叠（确保下落时不发生水平方向碰撞）；每个矩形的内部面积（(高-2)*(宽-2)）互不相等（确保排名无歧义）。

**规则**：
1. 对所有矩形施加向下重力：每个矩形保持形状垂直下落，直到底边触及网格底部或已堆叠矩形的顶部。处理顺序为从下到上（底边行号最大的先落）。
2. 落定后，计算每个矩形的内部面积 = (高度 - 2) * (宽度 - 2)。按内部面积从大到小排名（面积最大为 rank 1）。平局时按矩形左边界列号从小到大排（靠左者 rank 更高）。
3. 根据排名分层重涂：
   - Rank 1（内部面积最大）：四角格涂蓝(1)，剩余边框格涂黄(4)，严格内部格涂红(2)。
   - Rank 2：四角格涂蓝(1)，剩余边框格涂黄(4)，内部格保持该矩形的原始颜色不变。
   - Rank 3 及更低：仅四角格涂蓝(1)，所有其他格（边框和内部）保持原始颜色。
4. 背景格始终为黑(0)。

**关键洞察**：重涂方案是分层的——只有排名最高的矩形获得完整的三区涂色，排名递减则涂色逐层退化。这种排名与涂色深度的对应关系必须跨示例对比不同尺寸矩形的输出才能发现。

## 新题 4：视线射线桥接矩形，方位编码射线颜色，连通性门控标记变色

**组合逻辑**：[射线延伸/ray_cast + 视线对齐/sightline_align](从标记像素向四方向射线) → [方位对应/direction_correspondence + 方位决定颜色/direction_color](创新：方位色不是固定邻居而是延伸射线的全程颜色) → [两体之间/between_two_objects + 间隙区域涂色/gap_region_recolor](创新：连通计数决定标记像素自身颜色)

**来源原语**：ray_cast + sightline_align + nearest_neighbor（参考题 e1d2900e）、direction_correspondence + direction_color（参考题 d364b489）、between_two_objects + gap_region + fill（参考题 d6ad076f）、marker_pixel（参考题 d364b489, e1d2900e）、rectangle_object（参考题 d6ad076f）

**依赖链**：射线延伸确定哪些方向能到达矩形 → 方向决定该射线的颜色 → 射线到达的矩形数量决定标记像素自身是否变色。射线着色和标记变色是同一次射线扫描的两种输出，不可分离。

从标记像素射出四方向射线直到命中矩形，射线按方位着色；当标记恰好桥接两个矩形时，标记自身变色为绿(3)。

**输入结构**：黑(0)背景网格，约 18x18。包含 3-5 个单色实心矩形（每个 2x3 到 4x4，颜色取自蓝(1)、栗(9)、橙(7)，各矩形颜色可相同），以及 2-4 个灰(5)孤立标记像素。生成约束：每个标记像素至少有一个方向上的无阻挡视线能到达某个矩形的边界；不同标记的射线路径互不交叉；标记像素不在任何矩形内部或边界上。

**规则**：
1. 对每个灰(5)标记像素，沿上、下、左、右四个方向各发射一条射线。射线沿该方向逐格前进，仅穿越黑(0)背景格。遇到非背景格（矩形边界像素或另一个标记像素）或网格边界时停止。
2. 若射线因命中矩形边界像素而停止（非网格边界、非其他标记），则该射线有效。将该射线经过的所有背景格（不含标记像素自身，不含矩形边界像素）按方位着色：向上的射线涂红(2)，向下的射线涂青(8)，向左的射线涂橙(7)，向右的射线涂品红(6)。
3. 若射线因到达网格边界或命中其他标记像素而停止，则该射线无效，不绘制任何像素。
4. 统计每个标记像素的有效射线命中了多少个不同的矩形（同一矩形被两条不同方向的射线命中只计一次）。若恰好命中 2 个不同矩形，将该标记像素自身重涂为绿(3)；否则标记保持灰(5)不变。
5. 所有矩形保持原始颜色和位置不变。

**关键洞察**：标记像素的最终颜色不由其自身属性决定，而由其空间连通性决定——恰好桥接两个矩形的标记变绿。这条规则必须通过对比桥接两个矩形的标记与仅连接一个矩形的标记才能归纳出来。

## 新题 5：同色滑动靠墙后按拓扑反色

**组合逻辑**：[滑动/slide + 同色物体朝同色墙/same_color_wall + 近者优先不重叠/nearest_first + 碰撞停止/collision_stop](物体滑向同色墙壁) → [封闭孔洞/enclosed_hole + 包含关系/containment](检测物体拓扑) → [重涂色/recolor + 有孔触发重涂/hole_presence_triggers_recolor](创新：有孔物体滑动到位后颜色反转为对侧墙色)

**来源原语**：slide + same_color_wall + nearest_first + collision_stop（参考题 f0100645）、enclosed_hole + containment + hole_presence_triggers_recolor（参考题 aa4ec2a5）、recolor（参考题 b6afb2da, 09c534e7）

**依赖链**：颜色匹配决定滑动方向 → 近者优先+碰撞停止决定最终位置 → 拓扑检测（有孔/无孔）决定是否反色。运动规则和着色规则相互独立但作用于同一对象——必须先确定位置才能看到输出，但颜色由拓扑独立决定，形成"位置由颜色匹配驱动、最终颜色由拓扑驱动"的交叉依赖。

物体按颜色滑向匹配的墙壁，到位后有封闭孔洞的物体颜色反转为对侧墙色。

**输入结构**：黑(0)背景网格，约 14x14。左侧第 0 列整列为红(2)墙壁，右侧最后一列整列为蓝(1)墙壁。网格内部散布 4-6 个 4-连通单色小对象（每个 4-8 像素），颜色为红(2)或蓝(1)。其中部分对象形状上包含一个封闭的黑(0)孔洞（即对象像素完全 4-连通包围的一个或多个背景格），其余对象为实心。生成约束：同色物体在同一行范围内不重叠，确保滑动路径无歧义；每个有孔物体的孔洞至少为 1 个背景像素。

**规则**：
1. 每个内部对象按颜色匹配墙壁：红(2)对象向左滑动朝向红(2)墙壁，蓝(1)对象向右滑动朝向蓝(1)墙壁。
2. 同色对象中，距离目标墙壁最近的优先处理。每个对象水平滑动直到其边缘像素紧贴墙壁列或已落位的同色对象，保持垂直位置和形状不变。
3. 所有对象落位后，对每个对象进行拓扑检测：检查该对象的像素是否 4-连通包围了至少一个黑(0)背景格（封闭孔洞）。
4. 有封闭孔洞的对象：将其颜色反转为对侧墙壁的颜色（红(2)变蓝(1)，蓝(1)变红(2)）。孔洞内的背景格保持黑(0)。
5. 无封闭孔洞的实心对象：保持原始颜色不变。
6. 两侧墙壁列始终保持原色不变。

**关键洞察**：物体靠向自己颜色的墙壁，但有孔的物体到位后叛变为对方颜色——运动方向由原始颜色决定，最终颜色由拓扑决定，两条规则看似矛盾但共同作用产生"红墙旁出现蓝色物体"的反直觉输出。必须对比有孔和无孔物体的滑动结果才能分离这两条规则。

## 新题 6：像素膨胀引发连通合并，合并后内部区域重涂

**组合逻辑**：[像素放大/pixel_expand](创新：仅膨胀孤立像素为 2x2 块，不做全局缩放) → [连通分量/connected_component + 邻域全包含/full_neighborhood_inside_component](膨胀后重新检测连通分量及内部像素) → [重涂色/recolor + 标记在分量内/marker_inside_component](内部像素重涂为该分量中标记像素的颜色)

**来源原语**：pixel_expand（参考题 46f33fce）、connected_component + full_neighborhood_inside_component + singleton_marker + solid_interior + recolor（参考题 09c534e7）

**依赖链**：像素膨胀改变连通拓扑 → 新的连通分量可能由原先不相邻的元素合并而成 → 在新分量中检测 3x3 邻域全包含的内部像素 → 内部像素的重涂颜色来自该分量中唯一的标记像素。膨胀前后拓扑不同是核心——不膨胀则无合并，无合并则无内部区域。

孤立像素膨胀为 2x2 块后可能与邻近簇合并为更大连通分量，合并后产生的内部像素被重涂为该分量标记像素的颜色。

**输入结构**：黑(0)背景网格，约 12x12。包含两类前景元素：(1) 若干灰(5)孤立单像素，彼此不相邻；(2) 若干小型 4-连通灰(5)簇（每个 3-5 像素，形状不规则），每个簇内部嵌入恰好一个非灰色的标记像素（颜色取自红(2)、蓝(1)、绿(3)、黄(4），不同簇的标记颜色不同）。生成约束：部分孤立像素与某个簇的边界框距离恰好为 1（膨胀后会合并），部分孤立像素远离所有簇（膨胀后仍孤立）；每个簇至多与膨胀后的一个孤立像素合并；合并后的分量至少有一个像素满足 3x3 邻域全在分量内。

**规则**：
1. 识别所有灰(5)孤立单像素（8-邻域内无其他非背景像素的前景像素）。
2. 将每个孤立像素膨胀为 2x2 灰(5)块：以原像素为左上角，向右和向下各扩展一格。膨胀像素仅覆盖背景格，不覆盖已有前景像素。
3. 膨胀完成后，重新计算所有非背景像素的 4-连通分量。原先不相邻的孤立像素（现为 2x2 块）可能与邻近的簇合并为同一分量。
4. 对每个包含标记像素的连通分量，找出所有 3x3 邻域完全被该分量包含的像素（即该像素的 8 个邻居全部属于同一分量）。这些像素为该分量的"内部像素"。
5. 将内部像素重涂为该分量中标记像素的颜色。标记像素自身保持原色。所有非内部的分量像素保持灰(5)。
6. 膨胀后仍孤立（未与任何含标记的簇合并）的 2x2 块保持灰(5)不变。

**关键洞察**：膨胀本身不产生视觉上有意义的变化，但它改变了连通拓扑——原本不相邻的元素合并后才可能产生 3x3 全包含的内部区域。重涂的范围和颜色都取决于膨胀引发的合并结果，而非原始布局。

## 新题 7：嵌套空心框的反射印章与包含深度驱动的色彩重写

**组合逻辑**：[颜色配对/color_pairing + 颜色匹配配对/color_match_pairing](精灵体与同色框配对) → [镜像/mirror + 跨框中线反射入内/reflect_centerline_in](精灵体反射入框) → [包含关系/containment](检测框的嵌套层次) → [重涂色/recolor](创新：被外框包含的内框中的反射印章颜色被重写为外框颜色)

**来源原语**：mirror + reflect_centerline_in + hollow_rect + nearest_assign + sprite（参考题 6855a6e4）、color_match_pairing + color_pairing（参考题 2c181942, 3e980e27）、containment + hole_presence_triggers_recolor + recolor（参考题 aa4ec2a5）、stamp（参考题 3e980e27）

**依赖链**：颜色配对决定精灵体→框的分配 → 轴向推断和反射决定印章位置与形态 → 框的嵌套关系（某框完全在另一框内部）改写反射印章的颜色。前两步与参考题 6855a6e4 的反射逻辑类似但引入了多框嵌套，第三步的包含深度判定创造了原语池中不存在的"嵌套改色"结构关系。

精灵体按颜色匹配到空心框并反射入内；若目标框被另一框嵌套包含，则反射后的印章颜色被重写为外层框的颜色。

**输入结构**：黑(0)背景网格，约 20x20。包含 2-3 个不同颜色的空心矩形框（框边宽 1 像素，颜色取自红(2)、蓝(1)、绿(3)），其中一个较小的框完全位于另一个较大框的内部空间中（嵌套），第三个框独立存在（不嵌套）。框外散布 2-3 个小型精灵体（每个 3-5 像素，4-连通，不对称），每个精灵体的颜色与某个框的颜色相同。精灵体沿其匹配框的某一行或某一列对齐（以便推断反射轴）。生成约束：每个框恰好匹配一个精灵体；精灵体反射后不超出框的内部空间；嵌套的内框至少与外框在每个方向上相距 2 格（为反射留出空间）。

**规则**：
1. 按颜色将每个精灵体匹配到同色的空心框。
2. 根据精灵体与其匹配框的空间对齐关系推断反射轴：若精灵体与框中心在同一行带上则为水平反射轴，若在同一列带上则为垂直反射轴。
3. 将每个精灵体关于其匹配框的中心线（水平或垂直）做镜像反射，将反射结果绘制在框内部对应位置。保留框本身的边界像素不变。
4. 检测框的嵌套关系：若框 A 的边界框完全位于框 B 的内部空间（不含框 B 的边界像素），则 A 被 B 嵌套包含。
5. 对于被嵌套包含的框（如框 A 在框 B 内部）：将步骤 3 中绘制在框 A 内部的反射印章像素全部重涂为外层框 B 的颜色。
6. 对于未被嵌套的独立框：其反射印章保持精灵体的原始颜色不变。

**关键洞察**：同样的反射操作，在嵌套框和独立框中产生不同颜色的输出。精灵体的颜色决定它去哪个框，但框的空间包含关系决定反射印章的最终颜色。这种"目标决定去向、上下文改写结果"的分离必须通过对比嵌套框与独立框的输出才能发现。
