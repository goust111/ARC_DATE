## 新题 1：重力沉降后的拓扑封闭检测

**组合逻辑**：[重力下落](已有) → [包含检测](创新：检测对象从静态固有属性变为动态落定后涌现的属性) → [重涂色](已有，但涂色依据是落定后的拓扑而非原始属性)

**来源原语**：重力下落(#1 825aa9e9), 可动对象(#1), 障碍物(#1), 邻接阻挡(#1), 重涂色(#18 810b9b61), 连通分量(#18), 封闭区域(#18), 包含(#18), 有空洞则重涂(#18)

**依赖链**：多个独立精灵体在重力作用下落定 → 落定后相邻的精灵体合并为新连通分量 → 合并后的分量可能形成封闭区域（源题中不存在的涌现结构） → 封闭性决定重涂颜色。重力改变拓扑，拓扑决定颜色——三者缺一不可。

将散落在网格上方的多个蓝色小图形按重力落到灰色地板上，落定后彼此相邻的图形合并；合并后围住黑色空洞的组重涂为绿色，未围住的保持蓝色。

**输入结构**：
- 黑(0)背景，约 15x15 网格
- 灰(5)地板：一行灰色像素横跨网格全宽，位于底部或接近底部的某行
- 3-5 个蓝(1)小精灵体（每个 3-6 像素，4-连通，形状各异——可以是弯折、分叉等不规则形态），散布于网格上半部分
- 各精灵体在水平方向的包围盒可能有重叠（即某些列被多个精灵体占据），但精灵体之间在竖直方向上不接触
- 生成约束：精灵体的形状和水平位置经过设计，使得落定后至少一组相邻精灵体的合并体能围住至少一个黑色内部像素，同时至少一个精灵体落定后不参与任何封闭

**规则**：
1. 所有蓝(1)精灵体同时在重力作用下逐行下落。每步中，从最低行开始向上逐个处理每个精灵体：若将该精灵体整体下移一行后，其所有像素都不与灰(5)地板、网格底边或其他已停止的蓝像素重叠，则下移；否则该精灵体停止。重复此过程直到所有精灵体停止。
2. 落定后，计算所有蓝(1)像素的 4-连通分量。
3. 对每个分量，检测其是否封闭：若存在黑(0)像素无法仅通过其他黑(0)像素经 4-连通路径到达网格边界（即被蓝色像素和灰色地板完全围住），则该分量"封闭"。
4. 将封闭分量的所有蓝像素重涂为绿(3)。非封闭分量保持蓝(1)。
5. 灰色地板和黑色背景不变。

**关键洞察**：封闭性不是任何单个精灵体的固有属性——它在重力沉降后由多个精灵体的相对落位和地板共同涌现；仅看精灵体的原始形状或位置无法预测封闭结果。

## 新题 2：模板匹配门控腔室填充

**组合逻辑**：[模板匹配](已有) → {匹配: [洪泛填充](已有) / 不匹配: [擦除](已有)}（创新：匹配结果不是重涂颜色而是决定执行哪种完全不同的操作——填充 vs 清除）

**来源原语**：模板匹配(#3 50f325b5), 模板图案(#3), 形状匹配(#3), 含旋转反射变换(#3), 洪泛填充(#20 e69241bd), 墙壁(#20), 封闭区域(#20), 标记像素(#20), 标记色填充区域(#20), 擦除(#2 71e489b6)

**依赖链**：参考模板定义匹配标准 → 每个腔室的精灵体与模板比较 → 比较结果分叉为两种完全不同的操作路径（填充或清除） → 填充时标记像素提供颜色。模板匹配是门控条件，洪泛填充和擦除是互斥的两个操作分支，三者构成条件分支结构而非线性流水线。

墙壁围出若干腔室，每个腔室有一个绿色精灵体和一个彩色标记；参考腔室中有一个青色模板；精灵体匹配模板（含旋转反射）的腔室被标记色洪泛填充，不匹配的腔室被清空。

**输入结构**：
- 黑(0)背景，约 18x18 网格
- 灰(5)墙壁将网格分隔为 4-6 个腔室；每个腔室是灰色墙壁和/或网格边界围成的 4-连通黑色区域
- 其中一个腔室（如左上角）只含一个青(8)参考模板：一个 4-连通单色小图形（3-5 像素，形状不规则）
- 其余每个腔室包含：(a) 一个绿(3)精灵体（3-5 像素，4-连通，形状各异），(b) 恰好一个标记像素，颜色从红(2)、蓝(1)、黄(4)、橙(7)中选取且各腔室标记颜色互不相同
- 部分绿色精灵体是青色模板的旋转/反射变体，其余形状不同
- 生成约束：至少一个腔室匹配，至少一个不匹配

**规则**：
1. 提取青(8)模板所在腔室中模板的紧凑包围盒归一化掩码。
2. 生成该掩码的全部 8 种旋转/反射变体（0/90/180/270 度旋转，各搭配有/无水平翻转），去重。
3. 对每个非模板腔室，提取绿(3)精灵体的紧凑包围盒归一化掩码，与模板的所有变体逐一比较。
4. 若匹配（掩码完全相同）：将该腔室内所有黑(0)像素洪泛填充为该腔室标记像素的颜色；绿色精灵体和标记像素也被填充色覆盖（融入填充区域）。
5. 若不匹配：擦除该腔室内的绿色精灵体和标记像素（均设为黑(0)），腔室变为空黑腔。
6. 灰色墙壁和模板腔室保持不变。

**关键洞察**：模板匹配不决定颜色映射而是门控整个操作类型——同样的腔室结构在匹配时被填满、不匹配时被清空，这是一个条件分支而非单一变换的参数化。

## 新题 3：环路凸角定向印章

**组合逻辑**：[环路追踪+分类涂色](创新：分类结果不仅标记颜色，还触发空间放置操作) + [印章覆盖+镜像](创新：镜像轴不由外部标记决定而由拐角几何朝向决定)

**来源原语**：环路追踪(#9 15663ba9), 分类涂色(#9), 闭合正交环路(#9), 弯折像素(#9), 多数转向为凸(#9), 印章覆盖(#19 760b3cac), 镜像(#19), 精灵体(#19), 方向指示(#19)

**依赖链**：环路追踪识别每个弯折及其类型 → 凸弯折位置成为印章放置点（凹弯折不放置） → 每个凸弯折的几何朝外方向同时决定印章的放置位置和镜像方式。弯折分类、放置决策和镜像选择三者由同一个几何属性（拐角朝外方向）统一驱动。

闭合正交环路上的每个凸角向外放置精灵体的镜像副本，镜像轴由该角的朝外对角方向决定；凹角重涂为黄色。

**输入结构**：
- 黑(0)背景，约 20x20 网格
- 一条蓝(1)闭合正交环路：单像素宽的 4-连通闭合回路，每个像素恰有 2 个环路邻居，至少 4 个凸角
- 一个红(2)小精灵体（4-连通，3-4 像素，包围盒在 2x3 或 3x2 以内），放置在环路内部，不与环路像素相邻
- 生成约束：每个凸角的朝外对角方向有足够空间（至少精灵体包围盒大小）放置印章，且各印章之间不重叠、不与环路重叠

**规则**：
1. 追踪环路并分类每个弯折像素：多数转向方向为凸角，少数转向方向为凹角，非弯折像素为直行。
2. 对每个凸弯折像素，确定其"朝外对角方向"：该弯折有 2 个环路邻居分别在正交方向 d1 和 d2 上；朝外对角方向 = 与 (d1, d2) 相反的对角方向（如邻居在东和南，则朝外方向为西北）。
3. 在每个凸角处放置红色精灵体副本：将精灵体的包围盒定位，使其最靠近环路的那个角（即朝外方向的对角）与凸弯折像素的朝外对角邻格对齐。
4. 镜像规则：若朝外方向含水平分量朝左（NW 或 SW），将精灵体水平翻转后再放置；若朝外方向含水平分量朝右（NE 或 SE），保持原样放置。
5. 按环路顺时针追踪顺序依次处理凸角；若某个印章的放置区域与已放置的印章或环路像素重叠，跳过该角。
6. 每个凹弯折像素重涂为黄(4)。直行像素保持蓝(1)。
7. 环路内部的原始红色精灵体被擦除（设为黑(0)）。

**关键洞察**：凸角的朝外方向同时编码了三条信息——该角是否放置印章（凸 vs 凹）、印章放在哪里（朝外对角位置）、以及是否镜像（左右朝向）——单一几何属性驱动三重决策。

## 新题 4：逐格比较赋予差异化重力

**组合逻辑**：[压缩/逐格比较](创新：比较结果不输出颜色标记而是赋予物理属性——"重量") + [重力下落](创新：同一网格内两种重量的像素遵循不同下落规则并互相阻挡)

**来源原语**：压缩(#6 fafffa47), 逐格比较(#6), 堆叠掩码(#6), 双背景标记输出(#6), 重力下落(#1 825aa9e9), 可动对象(#1), 缓冲行间距(#1), 邻接阻挡(#1)

**依赖链**：两个堆叠掩码逐格比较 → 比较结果将像素分为"重"（双重前景）和"轻"（单一前景）两类 → 重像素无缓冲直落，轻像素带一行缓冲 → 重像素和轻像素在下落时互相阻挡。比较决定分类，分类决定物理，物理中两类互相约束——是同时约束满足而非线性流水线。

两个堆叠半区逐格比较产生"重"像素（双重重叠处）和"轻"像素（单一前景处）；重像素贴地下落，轻像素悬浮于重像素或地面上方一行。

**输入结构**：
- 黑(0)背景，网格约 12x24（纵向分为上下两个 12x12 半区）
- 上半区：绿(3)前景像素在黑色背景上，形成 2-3 个小型 4-连通图形（各 4-8 像素）
- 下半区：橙(7)前景像素在黑色背景上，形成 2-3 个小型 4-连通图形（各 4-8 像素）
- 上下半区部分前景像素在相同的相对位置重叠，部分不重叠
- 生成约束：重叠像素至少 3 个，每个半区的非重叠像素至少 3 个；重叠像素和非重叠像素在水平方向上有交错，确保下落时产生阻挡交互

**规则**：
1. 将上下两个 12x12 半区逐格对齐比较。
2. 生成一个 12x12 输出网格，初始全黑：
   - 上下均有前景（绿和橙在同一相对位置） → 红(2)"重"像素
   - 仅上半区有前景 → 黄(4)"轻"像素
   - 仅下半区有前景 → 黄(4)"轻"像素
   - 上下均为背景 → 黑(0)
3. 所有彩色像素在此 12x12 网格内下落：
   - 重(红)像素：逐行下落直到接触网格底边或已停止的任何彩色像素，无间隔直接贴靠。
   - 轻(黄)像素：逐行下落直到其正下方第二格被已停止的彩色像素或网格底边占据（即停在障碍物或地面上方留一行黑色缓冲）。
4. 处理顺序：从底行向上逐行扫描；同一行内从左到右。每个像素独立判定是否可下移。重复扫描直到无像素移动。
5. 若轻像素下方的缓冲行恰好被另一个正在下落的重像素占据，轻像素需再次上移一行以维持缓冲（重像素优先占位）。

**关键洞察**：逐格比较不产生可见标记而是生成隐式的物理属性图——像素的"重量"来自两层掩码的重叠关系，不同重量导致不同的落地规则，最终的空间布局是重量分布与重力交互的涌现结果。

## 新题 5：射线碰撞计数分类

**组合逻辑**：[射线延伸](已有) + [计数](创新：计数对象不是连通分量的个数而是每个方块接收到的碰撞事件数) + [分类涂色](创新：分类依据不是转向方向而是碰撞计数)

**来源原语**：射线延伸(#8 ec883f72, #16 85fa5666), 对角角点(#16), 对角邻接(#16), 碰撞停止(#15 36a08778), 计数(#10 b230c067), 分类涂色(#9 15663ba9), 连通分量(#10)

**依赖链**：每个方块向四个对角方向发射射线 → 射线遇到其他方块时停止（碰撞） → 统计每个方块有多少条射线被其他方块终止 → 碰撞计数决定重涂颜色。射线的空间交互模式是全局的（一个方块的射线是否碰撞取决于所有方块的位置），计数是对全局交互的局部统计，涂色是计数的可视化。

多个灰色 2x2 方块各从四角发射对角射线，射线碰到其他方块时停止；统计每个方块有几条射线被方块（而非网格边界）终止，按碰撞数重涂方块颜色。

**输入结构**：
- 黑(0)背景，约 15x15 网格
- 4-7 个灰(5)实心 2x2 方块，散布于网格中，任意两个方块之间在水平和竖直方向上至少间隔 3 格
- 生成约束：方块分布使得至少一个方块的 4 条射线全部到达网格边界（0 次方块碰撞），至少一个方块有 2 条或更多射线被其他方块终止

**规则**：
1. 对每个灰色 2x2 方块，确定其四个外角对角邻格（左上角的 NW 邻格、右上角的 NE 邻格、右下角的 SE 邻格、左下角的 SW 邻格）。
2. 从每个外角邻格出发，沿对应对角方向（NW 角向 NW，NE 角向 NE，等）逐格延伸橙(7)射线。
3. 射线在以下情况停止：(a) 到达网格边界（包含边界格），(b) 下一格是非黑像素（另一个方块的灰像素或另一条已绘制的射线的橙像素）——停止于当前格，不绘制下一格。
4. 同时处理所有方块的射线：先标记所有射线路径，若两条射线在同一格相遇，该格为橙色，两条射线都在该格终止。
5. 对每个方块，统计其 4 条射线中有多少条是被另一个灰色方块终止的（射线最后一格的对角方向下一格是灰色方块的像素）。被网格边界终止或被其他射线终止的不计入。
6. 按碰撞计数重涂方块颜色：0 次 → 蓝(1)，1 次 → 绿(3)，2 次 → 黄(4)，3 或 4 次 → 红(2)。
7. 橙色射线保留在输出中。

**关键洞察**：每个方块的颜色编码了它在方块网络中的"连通度"——射线是探测工具，碰撞计数是连通度的度量，而连通度只有在全局射线交互完成后才能确定，不能从局部信息推断。

## 新题 6：对称性检测驱动排序拼接

**组合逻辑**：[镜像](创新：镜像不用于构建输出而是用于诊断——检测精灵体的对称性等级) + [裁剪](已有) + [排序](创新：排序键不是空间位置而是对称性度数) + [拼接](创新：拼接顺序由对称性排序决定)

**来源原语**：镜像(#17 833dafe3), 四向对称扩展(#17), 裁剪(#4 1cf80156), 紧凑包围盒提取(#4), 精灵体(#4), 排序(#11 22a4bbc2), 按位置排序(#11), 拼接(#17), 形状匹配(#10 b230c067), 重涂色(#10)

**依赖链**：裁剪提取每个精灵体 → 对每个精灵体做水平和垂直镜像比对检测对称性 → 对称性等级决定重涂颜色 → 对称性等级决定排序顺序 → 按排序顺序拼接成输出行。镜像是诊断工具而非构建工具，其检测结果同时驱动颜色和空间两条输出路径。

将散落的精灵体按对称性等级（双轴 > 单轴 > 无）排序，对称的涂蓝、半对称涂黄、不对称涂红，然后按此顺序横向拼接为单行输出。

**输入结构**：
- 黑(0)背景，约 20x20 网格
- 4-6 个绿(3)4-连通精灵体，每个 4-8 像素，分散于网格中互不接触
- 每个精灵体的包围盒在 4x4 以内
- 精灵体具有不同对称性：部分在水平和垂直翻转下均自身重合（双轴对称），部分仅在一个轴下重合（单轴对称），部分在任何翻转下都不重合（无对称）
- 生成约束：三种对称类别各至少出现一个精灵体

**规则**：
1. 对每个绿色精灵体，裁剪出其紧凑包围盒内的掩码。
2. 对每个裁剪后的掩码，测试水平镜像对称性（左右翻转后与原掩码相同）和垂直镜像对称性（上下翻转后与原掩码相同）。
3. 赋予对称性分数：双轴对称 = 2，单轴对称 = 1，无对称 = 0。
4. 重涂色：分数 2 → 蓝(1)，分数 1 → 黄(4)，分数 0 → 红(2)。
5. 按对称性分数从高到低排序。同分精灵体之间按其在原始网格中的包围盒左上角位置行优先列次之（row-major）排序。
6. 构建输出：将排序后的裁剪精灵体（已重涂色）从左到右水平排列，相邻精灵体之间间隔一列黑色。输出网格高度 = 所有精灵体包围盒高度的最大值，宽度 = 所有包围盒宽度之和 + 间隔列数。每个精灵体顶部对齐，底部多余行填黑。

**关键洞察**：镜像操作在此题中是一个分析工具而非构建工具——它生成的翻转副本仅用于与原版比对判定对称性，从不出现在输出中；但对称性的判定结果同时决定了颜色和空间位置两个维度的输出。

## 新题 7：周期条纹切割碎片化计数

**组合逻辑**：[周期掩码](创新：周期行用于切割对象而非延伸条纹) + [擦除](创新：擦除沿周期行进行，将连通对象切断为碎片) + [计数](创新：计数的是每个原始对象被切出的碎片数) + [重涂色](已有，唯一/重复碎片数分涂)

**来源原语**：周期掩码(#14 6a980be1), 周期条纹(#14), 擦除(#2 71e489b6), 计数(#10 b230c067), 连通分量(#10), 重涂色(#10), 唯一重复形分涂(#10)

**依赖链**：识别周期条纹行 → 在条纹行上擦除前景像素切断对象 → 切割产生的碎片数取决于对象形状与条纹周期的几何交互（涌现属性） → 碎片数的唯一/重复分布决定重涂颜色。条纹周期、对象形状和碎片计数三者交织，任一改变都影响最终结果。

红色水平周期条纹横贯网格；绿色对象跨越多条条纹行；擦除条纹行上的绿色像素将对象切成碎片；碎片数唯一的对象涂蓝，碎片数与其他对象相同的涂黄。

**输入结构**：
- 黑(0)背景，约 18x18 网格
- 红(2)水平条纹：每隔 k 行（k 在 3 到 5 之间，各示例 k 值相同）有一行全宽红色像素
- 4-6 个绿(3)4-连通前景对象（每个 6-15 像素，形状不规则，高度跨越至少 2k 行使每个对象穿过至少两条条纹行）
- 绿色对象与红色条纹行在同一格时，该格在输入中显示为绿(3)（绿色覆盖红色）
- 非对象区域的条纹行显示为红(2)，可从中推断周期 k
- 生成约束：切割后至少一个对象的碎片数是唯一的（与其他对象不同），至少两个对象的碎片数相同

**规则**：
1. 识别红(2)条纹行：在非绿色区域中找到全宽红色行，推断其周期 k 及所有条纹行的行号（包括被绿色对象遮盖的行）。
2. 对每个绿色对象，擦除其位于条纹行上的所有绿色像素（设为红(2)，恢复条纹）。
3. 计算剩余绿色像素的 4-连通分量。根据每个碎片与切割前所属的原始对象的从属关系进行分组（碎片属于切割前在 4-连通意义上包含它的原始对象）。
4. 统计每个原始对象产生的碎片数。
5. 碎片数在所有对象中唯一（仅此一个对象有该碎片数）的对象：将其所有碎片重涂为蓝(1)。
6. 碎片数与至少一个其他对象相同的对象：将其所有碎片重涂为黄(4)。
7. 红色条纹行保持红(2)，黑色背景不变。

**关键洞察**：周期条纹充当均匀切割工具，但不同形状和位置的对象被切出不同数量的碎片——碎片数是条纹周期与对象几何的涌现交互属性，不可从任一单独因素推断。

## 新题 8：缺陷检测驱动瀑布级联

**组合逻辑**：[标记环绕/异常值选择](创新：异常检测的结果不是视觉标记而是物理模拟的初始条件) + [重力下落+溢出扩散](创新：蓝色前景区域的边界充当架子，而非独立的水平线段)

**来源原语**：标记环绕(#2 71e489b6), 异常值选择(#2), 缺陷像素(#2), 前景区域(#2), 邻域包围(#2), 重力下落(#15 36a08778), 溢出扩散(#15), 架子(#15), 级联分支(#15), 碰撞停止(#15)

**依赖链**：蓝色区域中检测结构缺陷（内部小型黑色孔洞） → 缺陷位置成为水流源头 → 水从缺陷向下流经黑色背景 → 遇到下方蓝色区域的上边界时横向扩散并从边缘溢出继续下落。同一蓝色区域既是缺陷的容器又是水流的障碍物——双重角色是源题中不存在的结构关系。

蓝色水平带状区域中的黑色缺陷孔洞成为水源；橙色水流从缺陷向下流动，碰到下方蓝色区域时在其上方横向扩散并从两端溢出继续下落。

**输入结构**：
- 黑(0)背景，约 20x25 网格（纵向较长）
- 蓝(1)前景形成 2-3 条宽水平带状区域（每条 2-4 行厚，横跨网格大部分宽度），分布在不同的垂直位置，带与带之间有多行黑色间隔
- 每条蓝色带内有 1-2 个黑(0)缺陷孔洞：1-2 个像素大小的黑色格，其 8-邻域全部是蓝色像素或网格边界
- 最下方蓝色带的下方有足够的黑色空间供水流扩散
- 生成约束：上方带的缺陷产生的水流垂直落下后能到达下方带的上表面，且下方带的水平范围不完全覆盖水流落点（使水流能从带的边缘溢出形成级联）

**规则**：
1. 检测缺陷像素：在蓝色区域内部寻找黑(0)像素，其 8-邻域全部是蓝(1)像素（或网格边界）。
2. 从每个缺陷像素出发，向下逐格发起橙(7)水流。
3. 水流下落规则：水流从当前格向下移动一格；若下一格为黑(0)，将其涂为橙(7)并继续；若下一格为蓝(1)（碰到蓝色带的上表面），停止下落。
4. 碰到蓝色带时的横向扩散：在水流停止的那一格（蓝色带上方一格，已涂橙），向左右两个方向沿同一行逐格扩散橙色，直到碰到非黑(0)像素（如蓝色带在该行的延伸部分）或网格边界。
5. 从横向扩散的左端和右端各自恢复垂直下落：从左端像素向下、右端像素向下分别继续水流（回到步骤 3 的规则）。
6. 若两股水流在同一格汇合，合并为一股继续下落。
7. 水流到达网格底边时停止。缺陷像素本身保持黑(0)（它是源头但不被涂色）。蓝色区域不变。

**关键洞察**：蓝色区域在此题中扮演双重角色——它既是缺陷的容器（缺陷的定义依赖于蓝色区域的包围），又是水流的障碍物（蓝色带的上边界充当架子）；这种"生成源头的结构同时也是阻挡源头产物的结构"是源题中不存在的自指关系。

## 新题 9：封闭轮廓内精灵体平铺

**组合逻辑**：[裁剪](已有) + [包含检测](创新：不用于判定重涂而是决定哪些区域接受平铺) + [平铺](创新：平铺模板来自裁剪的精灵体，平铺范围由拓扑封闭性决定)

**来源原语**：裁剪(#4 1cf80156), 紧凑包围盒提取(#4), 精灵体(#4), 平铺(#14 6a980be1), 包含(#18 810b9b61), 封闭区域(#18), 有空洞则重涂(#18)

**依赖链**：裁剪精灵体提供平铺模板 → 封闭性检测确定哪些轮廓的内部是合法的平铺区域 → 在封闭轮廓内部用精灵体模板平铺填充。裁剪决定"铺什么"，封闭性决定"铺哪里"，平铺算法决定"怎么铺"——三者缺一则输出无法确定。

蓝色线条在网格上勾勒出若干轮廓（有的封闭有的有缺口），红色小精灵体在旁边提供平铺模板；封闭轮廓的内部用精灵体图案平铺填充，有缺口的轮廓不填充。

**输入结构**：
- 黑(0)背景，约 20x20 网格
- 若干蓝(1)轮廓线：单像素宽的 4-连通线条，部分形成封闭环（围住内部黑色区域），部分有缺口（不完全封闭的开放线段或近似环但有断裂）
- 一个红(2)小精灵体（4-连通，3-4 像素，包围盒为 2x2 或 2x3），放置在远离所有轮廓的位置
- 生成约束：至少 2 个封闭轮廓和至少 1 个开放轮廓；每个封闭轮廓的内部面积至少能容纳精灵体包围盒的 2x2 次平铺（即内部至少 4x4）

**规则**：
1. 裁剪红(2)精灵体至其紧凑包围盒，得到平铺模板（记模板宽 w、高 h）。
2. 识别每个蓝(1)4-连通分量。
3. 对每个蓝色分量，测试封闭性：是否存在黑(0)像素被该分量完全包围（该黑色像素无法通过 4-连通路径经其他黑色像素到达网格边界而不穿过蓝色像素）。
4. 对每个封闭分量：确定其内部区域（所有被包围的黑色像素集合）。以内部区域的最小包围盒左上角为起点，按行优先列次之的顺序放置平铺模板副本，每次水平步进 w 格、竖直步进 h 格。仅当模板像素对应的格位于内部区域中且为黑色时才涂为红(2)；超出内部区域或落在蓝色像素上的模板像素不绘制。
5. 开放分量（不封闭）保持蓝色不变，其周围无任何填充。
6. 原始红色精灵体从网格上擦除（设为黑(0)）。

**关键洞察**：拓扑封闭性在此题中不是一个标签（如源题中"有洞则重涂"），而是一个空间过滤器——它选出有资格接受空间操作（平铺）的区域；精灵体则从一个独立对象转变为重复使用的基元，两种源题中独立的机制在新题中形成了"模板提供者-区域选择器-填充执行器"的三角依赖。

## 新题 10：重叠比较生成墙壁与标记的一体化填充

**组合逻辑**：[压缩/逐格比较](创新：单次比较同时生成两类输出——墙壁结构和填充标记) + [洪泛填充](创新：填充的墙壁和标记都不预存在于输入，而是从同一比较操作涌现)

**来源原语**：压缩(#6 fafffa47), 逐格比较(#6), 堆叠掩码(#6), 双背景标记输出(#6), 洪泛填充(#20 e69241bd), 墙壁(#20), 封闭区域(#20), 标记色填充区域(#20), 标记在区域内(#20)

**依赖链**：两个堆叠半区逐格比较 → 双重前景位置生成灰色墙壁 → 仅上半区前景生成绿色标记 → 仅下半区前景生成橙色标记 → 墙壁围出封闭区域 → 含单一标记色的区域被该色洪泛填充 → 含混合标记或无标记的区域保持不变。比较操作的三种输出类别分别扮演完全不同的角色（结构/标记/空白），它们在填充步骤中重新交互。

两个堆叠半区逐格比较：重叠位置变成灰色墙壁，仅在一侧出现的位置变成对应颜色的标记；墙壁围出腔室后，含单一标记色的腔室被该色洪泛填充。

**输入结构**：
- 黑(0)背景，网格约 12x24（纵向分为上下两个 12x12 半区）
- 上半区：绿(3)前景像素在黑色背景上，形成 2-3 个 4-连通图形（各 5-10 像素，部分含直角弯折或分叉）
- 下半区：橙(7)前景像素在黑色背景上，形成 2-3 个 4-连通图形（各 5-10 像素）
- 上下半区的图形部分重叠（在相同相对位置），重叠像素形成连通的线状或网状结构
- 生成约束：重叠像素（将成为墙壁）的分布能围出至少 2 个封闭区域；至少一个封闭区域内只含绿色标记（仅上半区有前景），至少一个封闭区域内只含橙色标记（仅下半区有前景），且至少一个区域无标记或同时含两种标记

**规则**：
1. 将上下两个 12x12 半区逐格对齐比较，生成一个 12x12 输出网格：
   - 上下均有前景 → 灰(5)（墙壁像素）
   - 仅上半区有前景 → 绿(3)（标记像素）
   - 仅下半区有前景 → 橙(7)（标记像素）
   - 上下均为背景 → 黑(0)（空白）
2. 将灰(5)像素视为墙壁，计算所有非灰像素的 4-连通区域。
3. 对每个区域检查其内部的标记像素：
   - 若区域内所有标记像素为同一颜色（全绿或全橙），将该区域内所有像素（包括黑色空白和标记像素）洪泛填充为该标记颜色。
   - 若区域内无标记像素，或同时包含绿色和橙色标记，保持该区域不变（标记像素保留原色，黑色像素保持黑色）。
4. 灰色墙壁不变。

**关键洞察**：逐格比较的一次运算同时产生了三种角色不同的输出——墙壁（结构）、标记（信号）和空白（容器）——这三者在随后的洪泛填充中重新交互：墙壁定义了"哪些区域存在"，标记定义了"区域用什么颜色填"，空白定义了"什么被填"。单一操作的三分类输出驱动了后续操作的全部参数。
