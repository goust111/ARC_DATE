## 新题 1：标记射线围墙与洪泛封填

**组合逻辑**：[射线延伸](创新：从标记像素向四方发射，止于红墙/其他标记/边界) + [洪泛填充](已有) + [区域封闭](创新：封闭由射线与红墙共同构成，单一来源不足以形成封闭)

**来源原语**：射线延伸(ray_extension) ← 8b9c3697/0b17323b；洪泛填充(flood_fill) ← a5313dff；标记像素(marker_pixel) ← 846bdb03/ac0c2ac3；墙壁线段(wall_segment) ← a5313dff；封闭区域(enclosed_region) ← a5313dff/445eab21；区域封闭(region_enclosure) ← a5313dff；边界内延续(continue_within_bounds) ← 0b17323b

**依赖链**：射线延伸的结果与已有红墙共同构成新的障碍网络 → 障碍网络的拓扑决定哪些背景区域被完全封闭 → 洪泛填充仅作用于封闭区域。三者缺一不可：无射线则红墙不构成封闭；无红墙则射线不形成闭合围栏；无洪泛则无法生成输出。

从标记像素发出的射线与散布的红色墙壁共同围成封闭区域，将这些被困区域统一填充为蓝色。

**输入结构**：约 15x15 的网格，黑(0)为背景。网格中散布若干红(2)像素作为不可穿越的墙壁段，这些红像素单独不围成任何封闭区域（即所有背景像素仅通过红墙无法与边界隔绝）。2~3 个不同颜色的单像素标记（使用除黑(0)和红(2)以外的颜色，如蓝(1)、绿(3)、黄(4)），各自位于网格内不同位置，互不相邻，且不紧贴红墙。生成约束：保证至少存在两个标记，使得它们的射线与红墙配合后能围成至少一个封闭区域；任意单个标记的射线与所有红墙配合均不能独立围成封闭区域。

**规则**：
1. 对每个标记像素，从其上下左右四个相邻格开始，沿该方向逐格延伸射线。射线以标记自身的颜色着色。射线遇到以下情况时停止（停止前的最后一格仍着色，障碍格本身不被覆盖）：(a) 下一格为红(2)墙壁像素；(b) 下一格为另一个标记像素；(c) 下一格超出网格边界。
2. 所有标记的射线同时计算终点（各射线仅以红墙和其他标记像素为障碍，不以其他射线像素为障碍），然后统一绘制。若两条射线经过同一格，该格可取任意一条射线的颜色（对后续洪泛填充仅需非黑即可）。
3. 将所有非黑(0)像素（红墙、标记、射线）视为墙壁，从网格四条边界上的所有黑(0)像素出发，通过 4-连通扩散标记所有可达的背景像素。
4. 将所有未被标记为可达的背景像素填充为蓝(1)。红墙、标记像素和射线像素保持不变。

**关键洞察**：没有任何单个标记的射线足以与红墙围成封闭区域——封闭是多个标记射线与红墙交互后的涌现效果。求解者必须先模拟所有射线，才能判断哪些区域被包围。

## 新题 2：重叠空心框的面积优先级填充

**组合逻辑**：[计数](已有) → [面积比较](创新：最小面积胜出，而非最大) → [填充](创新：填充对象为框内区域，冲突由面积大小裁决)

**来源原语**：计数(counting) ← 6e82a1ae/445eab21/81c0276b；比较(compare) ← 445eab21；填充(fill) ← ac0c2ac3；空心矩形(hollow_rectangle) ← 445eab21；封闭区域(enclosed_region) ← 445eab21/a5313dff；面积比较(area_comparison) ← 445eab21；冲突优先级(conflict_priority) ← 1b8318e3

**依赖链**：计数各框的内部面积 → 面积大小关系决定重叠区域的颜色归属 → 填充操作需要面积排名结果才能确定每个像素的最终颜色。面积计数与填充通过"冲突解决"这一决策节点紧耦合。

将多个互相重叠的空心矩形框的内部分别填充为框色，重叠区域由内部面积最小的框胜出着色。

**输入结构**：约 12x12 的网格，黑(0)为背景。3 个单色空心矩形框（边框厚度 1 像素），颜色各不相同，如红(2)、蓝(1)、绿(3)。每个框的边界框完全在网格内部，不贴网格边缘。各框的尺寸不同（内部面积互不相等），至少有两个框的内部区域存在重叠（即一个框的内部像素落入另一个框的内部范围，但框的边框像素不计入内部）。框的边框像素可能交叉（两个框的边框经过同一格）。生成约束：三个框的内部面积两两不同，无平局；至少存在一个像素同时属于两个框的内部区域。

**规则**：
1. 对每个空心矩形框，计算其内部面积：严格位于边框内部的背景像素数量（不含边框本身）。
2. 将每个框的内部区域填充为该框的颜色。
3. 若某个像素同时属于两个或三个框的内部区域，该像素着色为其中内部面积最小的那个框的颜色。
4. 若两个框的边框交叉于同一格，该格着色为内部面积较小的那个框的边框颜色。
5. 不属于任何框内部也不属于任何框边框的背景像素保持黑(0)。

**关键洞察**：优先级判定是面积最小者胜出，而非直觉中"大框包含小框"或"后画覆盖先画"的逻辑。求解者需要对比多个示例（不同重叠配置与尺寸）才能排除按颜色、按位置等其他假设，归纳出"最小面积优先"的规则。

## 新题 3：跨面板算术线延伸与颜色继承

**组合逻辑**：[外推](已有) + [重涂色](创新：延伸进入新面板时继承目标面板的线条颜色) + [分隔行检测](已有，用于确定面板边界)

**来源原语**：外推(extrapolate) ← 0b17323b；重涂色(recolor) ← ac0c2ac3/6e82a1ae/ad173014；分隔行(separator_row) ← ce4f8723/dc46ea44；等距标记点(equally_spaced_markers) ← 0b17323b；算术线(arithmetic_line) ← 0b17323b；等距共线(equally_spaced_collinear) ← 0b17323b；跨面板搬运(cross_panel_move) ← dc46ea44；边界内延续(continue_within_bounds) ← 0b17323b

**依赖链**：等距共线的标记确定步长向量 → 外推沿步长向量向两端延伸 → 分隔行标记面板边界 → 延伸穿越分隔行时触发重涂色条件 → 目标面板中已有标记的颜色决定新色 → 延伸在遇到已有标记/分隔行/另一条延伸时终止。外推的方向、重涂色的条件、终止条件三者互相耦合。

将三个面板中各自的等距算术线向两端延伸，当延伸穿过分隔行进入邻近面板时，延伸像素采用目标面板的线条颜色。

**输入结构**：约 18x10 的网格，黑(0)为背景。两条全宽水平灰(5)分隔行将网格等分为三个面板（上、中、下），每个面板高度相等（至少 4 行）。每个面板内恰好有 3 个同色像素构成一条等距算术线（颜色各面板不同，如上=红(2)、中=蓝(1)、下=绿(3)）。三条算术线的方向各不相同（如一条水平、一条垂直、一条对角），步长向量也各不相同。生成约束：至少有一条线的延伸方向会穿越分隔行进入相邻面板；三条线的延伸路径在本面板内互不经过任何其他面板的标记像素。

**规则**：
1. 在每个面板中，找到 3 个等距标记像素，计算步长向量（从第一个到第二个标记的行列差）。
2. 从最后一个标记（按行优先排序）起，沿步长向量逐步延伸；同时从第一个标记起，沿步长向量的反方向逐步延伸。
3. 延伸像素在其所在面板内使用该面板原始算术线的颜色着色。
4. 当延伸的下一步越过灰(5)分隔行进入相邻面板时：跳过分隔行本身（不着色分隔行），在相邻面板的对应位置继续延伸，且从此处起延伸像素改用该相邻面板的算术线颜色。
5. 延伸在以下情况下停止：(a) 下一步超出网格边界；(b) 下一步落在已有标记像素上（任何面板的原始三个标记）；(c) 下一步落在灰(5)分隔行上且该分隔行的另一侧已无空间继续（即到达网格顶部/底部边界附近的分隔行）；(d) 下一步落在已被其他延伸着色的像素上。
6. 灰(5)分隔行、所有原始标记像素保持不变。

**关键洞察**：延伸像素的颜色不由发出延伸的面板决定，而由延伸当前所在的面板决定。同一条延伸线在穿越面板边界后会变色，形成多色线段。求解者需要对比不同延伸方向和穿越情况才能归纳此规则。

## 新题 4：横带划分中的位置条件镜像图案

**组合逻辑**：[扩展 + 边框绘制](已有) + [图案复制](创新：复制到每个横带中) + [镜像](创新：标记列位决定是否翻转，非原题的边色判定)

**来源原语**：扩展(expand) ← 0f63c0b9；边框绘制(frame_drawing) ← 0f63c0b9；镜像(mirror) ← 846bdb03/7468f01a；图案复制(pattern_replication) ← 4c416de3；单像素标记(single_pixel_marker) ← 0f63c0b9；横带(horizontal_band) ← 0f63c0b9；图案块(motif) ← 846bdb03；按行排序(sorted_by_row) ← 0f63c0b9；中点划分归属(midpoint_band_assignment) ← 0f63c0b9

**依赖链**：标记像素的行坐标 → 中点划分确定横带范围 → 边框绘制为每个横带画框；同时，标记像素的列坐标 → 判断是否需要镜像 → 图案复制时的朝向随之确定；图案颜色继承标记颜色。行、列、颜色三个属性分别控制不同操作。

按标记像素的行划分横带并绘制边框，同时将一个小图案复制到每个横带中，图案是否水平翻转取决于标记像素在网格左半还是右半。

**输入结构**：约 15x15 的网格，黑(0)为背景。3~4 个不同颜色的单像素标记，位于不同行（行坐标两两不同），分散在网格各处。另有一个小的前景图案（由 3~5 个像素组成的 4-连通单色小图形，使用与所有标记颜色都不同的颜色，如灰(5)），位于网格的某个角落区域，不与任何标记同行同列。该图案不具备水平对称性（左右翻转后外观不同）。生成约束：标记中至少有一个列坐标 < grid_width/2（在左半），至少有一个列坐标 >= grid_width/2（在右半）。

**规则**：
1. 按行坐标从小到大排序所有标记像素。
2. 在相邻标记行的中点处划分横带边界。最上方标记的横带上边界为第 0 行，最下方标记的横带下边界为最后一行。
3. 对每个横带：用该标记的颜色绘制一条全宽水平线，位于标记所在行。若横带触及网格顶部边缘，另绘制第 0 行的全宽水平线；若触及底部边缘，另绘制最后一行的全宽水平线。绘制该横带左右两侧的边界列（第 0 列和最后一列），纵向范围覆盖整个横带，颜色同标记。
4. 将小前景图案复制到每个横带中：图案的水平中心对齐到标记像素的列坐标，图案的顶边放在标记行的下一行。图案像素颜色替换为该标记的颜色。
5. 若标记像素的列坐标 >= grid_width/2（位于网格右半），则该横带中放置的图案先做水平镜像翻转，再按上述位置放置。列坐标 < grid_width/2 的标记对应的图案保持原始朝向。
6. 图案像素超出横带范围或网格边界的部分舍弃。
7. 原始的小前景图案在其原始位置被擦除（变为背景色）。

**关键洞察**：标记像素的列坐标既决定图案的水平放置位置，又决定图案是否需要镜像——这是同一个空间属性的双重用途。求解者需要对比左半和右半的标记才能发现镜像规则。

## 新题 5：逻辑或非掩模的对角线铺展

**组合逻辑**：[逻辑运算(NOR)](已有) → [平铺 + 对角线偏移复制](创新：NOR运算的结果作为平铺的种子图案，而非直接输出)

**来源原语**：逻辑运算(logical_op) ← 1b2d62fb；平铺(tile) ← d13f3404；二值掩模(binary_mask) ← 1b2d62fb；分隔条(separator_bar) ← 1b2d62fb；前景图案(foreground_motif) ← d13f3404；逐像素对应(pixelwise_correspond) ← 1b2d62fb；对角线偏移复制(diagonal_offset_copy) ← d13f3404；逻辑或非合并(logical_NOR_combine) ← 1b2d62fb；画布加倍(canvas_doubling) ← d13f3404

**依赖链**：分隔条将输入分为两个掩模 → 逻辑 NOR 运算产生中间图案（该图案在任何参考题中都不存在，是两个掩模交互的涌现结果）→ 中间图案成为对角线偏移复制的种子 → 在加倍画布上铺展产生最终输出。NOR 的输出形状直接决定铺展后的视觉结构。

对两个分隔条隔开的二值掩模做逻辑或非运算，将结果作为种子图案在加倍画布上沿对角线偏移铺展。

**输入结构**：约 6x13 的网格，黑(0)为背景。一条全高蓝(1)垂直分隔条位于网格中央列，将网格分为左右两个等宽面板（各宽 6 列）。左面板包含一个栗(9)色前景掩模（若干栗色像素散布在黑色背景上）；右面板包含一个红(2)色前景掩模（若干红色像素散布在黑色背景上）。两个掩模的尺寸相同（行数 = 网格高度，列数 = 面板宽度）。生成约束：NOR 结果（两个掩模对应位置都是背景的那些格）至少有 3 个像素且不构成全空或全满的平凡情况。

**规则**：
1. 定位蓝(1)垂直分隔条，提取左面板掩模 L 和右面板掩模 R（分隔条本身不属于任何面板）。
2. 将 L 和 R 逐像素对应：栗(9)和红(2)视为"前景/活跃"，黑(0)视为"背景/不活跃"。
3. 计算逻辑 NOR：对应位置两个掩模都不活跃（都是黑(0)）的格记为青(8)，其余格记为黑(0)。产生一个与单面板同尺寸的 NOR 图案 N。
4. 创建一个高度 = 2 倍 N 的行数、宽度 = 2 倍 N 的列数的加倍画布，初始填满黑(0)。
5. 对 NOR 图案 N 中每个青(8)像素在位置 (r, c)，在加倍画布上的所有位置 (r+k, c+k)（k = 0, 1, 2, ... 且不超出画布边界）涂上青(8)。
6. 输出为加倍画布。

**关键洞察**：NOR 运算本身产生的稀疏点阵是不可预测的中间产物，只有先正确完成 NOR 才能得到对角线铺展的种子。铺展后的对角线条纹结构完全取决于 NOR 结果中像素的具体分布，二者紧密耦合。

## 新题 6：算术线分隔空间与孤点侧向归色

**组合逻辑**：[外推](创新：向两端延伸形成空间分隔线) + [吸附](创新：吸附目标是延伸线而非锚块框) + [重涂色](创新：颜色由原始所在侧决定，非距离或像素数)

**来源原语**：外推(extrapolate) ← 0b17323b；吸附(snap) ← 1b8318e3；重涂色(recolor) ← 6e82a1ae/ac0c2ac3；等距标记点(equally_spaced_markers) ← 0b17323b；算术线(arithmetic_line) ← 0b17323b；孤立像素(singleton_pixel) ← 1b8318e3；等距共线(equally_spaced_collinear) ← 0b17323b；最近距离(nearest_distance) ← 1b8318e3；边界内延续(continue_within_bounds) ← 0b17323b；最短距离分配(nearest_frame_assign) ← 1b8318e3

**依赖链**：等距标记确定步长向量 → 外推向两端延伸形成一条贯穿网格的分隔线 → 分隔线将网格划分为两个半区 → 每个孤立像素的原始所在半区决定其最终颜色 → 孤立像素吸附到线上最近点。空间分隔（由外推产生）既是吸附的目标，又是颜色判定的依据，二者通过分隔线这一几何结构耦合。

将三个等距标记定义的算术线向两端延伸至网格边界，形成分隔线；将散落的孤立像素吸附到该线的最近点，并根据孤立像素原来位于线的哪一侧来决定其最终颜色。

**输入结构**：约 12x12 的网格，黑(0)为背景。3 个蓝(1)像素构成一条等距算术线（可为对角方向，步长向量如 (2, 1) 或 (1, 2) 等，使延伸线为倾斜线而非水平/垂直线，以便将网格分成明确的两个半区）。另有 4~6 个孤立单像素，颜色各异（如红(2)、绿(3)、黄(4)、灰(5)等），散布在网格内蓝色线的两侧。生成约束：线的两侧各至少有 2 个孤立像素；每个孤立像素与蓝色线上最近像素的曼哈顿距离 >= 2；所有孤立像素到线上最近点的距离两两不同（无平局）。

**规则**：
1. 找到 3 个蓝(1)等距标记像素，按行优先排序确定方向，计算步长向量。
2. 从第一个标记沿步长向量反方向、从最后一个标记沿步长向量正方向，逐步延伸蓝(1)像素直到超出网格边界。延伸线完全由蓝(1)像素构成。
3. 延伸线将网格的非线像素划分为两个半区。判定方法：对于步长向量 (dr, dc) 定义的线方向，从线上任一点到目标像素的法向量若指向线的"上方/左方"则为 A 侧，指向"下方/右方"则为 B 侧。具体地：对于斜线上一点 (r0, c0) 和目标点 (r, c)，计算叉积 (r - r0) * dc - (c - c0) * dr，正值为 A 侧，负值为 B 侧。
4. 清除所有孤立像素的原始位置（变为黑(0)）。
5. 对每个孤立像素，找到蓝色延伸线上与其曼哈顿距离最小的像素位置，将该孤立像素移动到该位置。移动后的像素颜色不保留原色，而是由其原始所在半区决定：A 侧的孤立像素变为绿(3)，B 侧的变为红(2)。
6. 若多个孤立像素吸附到线上的同一点（生成约束已排除此情况，但作为边界处理：距离较近者优先占据该点，较远者占据该点的相邻线上像素，方向为朝向第一个标记的方向）。
7. 蓝(1)的延伸线像素保持蓝色，即使有孤立像素吸附到其上——孤立像素的颜色覆盖蓝色。

**关键洞察**：孤立像素的原始颜色是干扰项——最终颜色完全由其位于分隔线哪一侧决定。求解者需要对比多个示例，发现不同原始颜色的像素在同一侧得到相同最终颜色，才能排除"保持原色"或"按原色映射"等错误假设。

## 新题 7：锚块吸附的距离分级涂色轨迹

**组合逻辑**：[吸附](已有) + [计数](创新：计数对象从像素数变为移动距离) → [重涂色](创新：由距离区间映射颜色，而非像素数映射) + [轨迹着色](创新：轨迹不涂黑而是涂为距离对应色)

**来源原语**：吸附(snap) ← 1b8318e3；重涂色(recolor) ← 6e82a1ae/ac0c2ac3；计数(counting) ← 6e82a1ae/81c0276b；孤立像素(singleton_pixel) ← 1b8318e3；锚块(anchor_block) ← 1b8318e3；外框边缘(outer_frame) ← 1b8318e3；最近距离(nearest_distance) ← 1b8318e3；最短距离分配(nearest_frame_assign) ← 1b8318e3；像素数映射颜色(count_to_color) ← 6e82a1ae → 创新为距离映射颜色；轨迹涂黑(trail_painted_black) ← 8b9c3697 → 创新为轨迹涂色

**依赖链**：每个孤立像素吸附到最近锚块的外框 → 移动距离（king-move 步数）决定颜色映射 → 轨迹（起点到终点的路径）和终点像素统一涂为该距离对应的颜色。距离测量既驱动吸附目标选择，又驱动最终涂色——同一个量的双重作用构成耦合。

将散落的孤立像素吸附到最近的灰色锚块外框上，根据移动距离将轨迹和终点统一涂为对应颜色，孤立像素的原始颜色为干扰项。

**输入结构**：约 12x12 的网格，黑(0)为背景。2 个灰(5)实心 2x2 锚块，位置互不相邻（king-move 距离 >= 5）。5~6 个孤立单像素，颜色各不相同（如红(2)、蓝(1)、绿(3)、黄(4)、橙(7)等），散布在网格内。生成约束：每个孤立像素到其最近锚块的 king-move 距离两两不同，且涵盖距离 2、距离 3~4、距离 5 以上三个区间各至少一个像素；无平局（每个孤立像素有唯一最近锚块）。

**规则**：
1. 灰(5) 2x2 锚块保持不变。
2. 对每个孤立像素，计算其到每个锚块的 king-move（切比雪夫）距离，取最近锚块。距离定义为从像素到锚块 4 个格中最近那格的切比雪夫距离。
3. 将孤立像素吸附到最近锚块的一格外框上：外框 = 锚块 2x2 区域外围一圈（共 12 格）。目标格为外框中与孤立像素切比雪夫距离最小的格，若有多个等距格取行号最小者，再行号相同取列号最小者。
4. 确定移动距离 D = 孤立像素原始位置到目标外框格的切比雪夫距离。根据 D 选择轨迹颜色：
   - D <= 2：轨迹颜色为绿(3)
   - 3 <= D <= 4：轨迹颜色为红(2)
   - D >= 5：轨迹颜色为蓝(1)
5. 绘制从孤立像素原始位置到目标格的 king-move 最短路径（每步沿 8 方向中使切比雪夫距离减小最快的方向移动）。路径上的所有中间格和目标格均涂为步骤 4 确定的轨迹颜色。
6. 孤立像素的原始位置也涂为轨迹颜色（作为轨迹的起点）。
7. 孤立像素的原始颜色在输出中不再保留——被轨迹颜色覆盖。

**关键洞察**：孤立像素的原始颜色（红、蓝、绿、黄、橙等）是纯粹的干扰项，最终颜色完全由移动距离决定。求解者必须通过对比多个示例中不同原始颜色但相同距离区间的像素得到相同最终颜色，才能排除颜色保留或颜色映射的假设。

## 新题 8：同心方环着色与墙壁封闭灰化

**组合逻辑**：[填充(同心方环着色)](已有) + [洪泛填充](创新：不是在空白背景上判定封闭，而是在已着色的方环上叠加灰化) → 两层操作修改同一区域，后者覆盖前者

**来源原语**：填充(fill) ← ac0c2ac3；洪泛填充(flood_fill) ← a5313dff；重涂色(recolor) ← ac0c2ac3；同心方环(concentric_ring) ← ac0c2ac3；标记像素(marker_pixel) ← ac0c2ac3；墙壁线段(wall_segment) ← a5313dff；封闭区域(enclosed_region) ← a5313dff；距离映射(distance_mapping) ← ac0c2ac3；区域封闭(region_enclosure) ← a5313dff；切比雪夫距离(chebyshev_distance) ← ac0c2ac3；孤立背景区域填充(unreachable_background_filled) ← a5313dff

**依赖链**：标记像素的切比雪夫距离 → 确定同心方环的调色板 → 填充所有格为方环颜色；同时红墙像素覆盖方环颜色 → 红墙的拓扑结构决定哪些区域被封闭 → 被封闭的区域无论原方环颜色如何，统一被灰化。两个独立的着色逻辑（方环 + 灰化）作用于同一画布，灰化依赖方环结果被红墙中断后的连通性。

先按切比雪夫距离给全网格涂上同心方环颜色，再用红色墙壁遮断方环，将被墙壁完全包围的区域统一覆盖为灰色。

**输入结构**：11x11（奇数边长正方形）的网格，黑(0)为背景。网格中心为第 (5,5) 格。在切比雪夫距离 1~5 的各距离层上各有一个不同颜色的标记像素（如距离 1 → 蓝(1)、距离 2 → 绿(3)、距离 3 → 黄(4)、距离 4 → 橙(7)、距离 5 → 栗(9)），中心格 (5,5) 本身也有一个标记像素（如品红(6)）。另有若干红(2)像素散布在网格中，构成至少一段连续的障碍墙（4-连通或直线排列，足以与网格边界或自身围成至少一个封闭区域）。生成约束：红墙单独不足以覆盖任何完整的方环层；红墙形成的封闭区域至少包含 2 个不同方环距离层的像素（以确保灰化跨越多层）。

**规则**：
1. 对网格中每个格 (r, c)，计算其到中心 (5,5) 的切比雪夫距离 d = max(|r-5|, |c-5|)。
2. 找到距离 d 处的标记像素，将 (r, c) 涂为该标记的颜色。距离 0 的格涂为中心标记的颜色。所有格都被涂色——没有背景残留。
3. 红(2)墙壁像素覆盖方环着色：凡输入中为红(2)的格，在输出中保持红(2)，不受方环着色影响。
4. 将红(2)像素视为不可穿越的墙壁。从网格四条边界上所有非红像素出发，通过 4-连通路径（只经过非红像素）标记所有可达的格。
5. 将所有不可达的非红格（被红墙完全封闭的格）统一覆盖为灰(5)，无论其方环颜色是什么。
6. 可达的非红格保持其方环颜色不变。红(2)墙壁像素保持红(2)。

**关键洞察**：方环着色和灰化覆盖是两个独立的着色机制作用于同一画布——方环提供"底图"，红墙提供"遮挡"，灰化是遮挡造成的"阴影"。求解者需要先理解方环规则（从标记距离推断），再理解灰化规则（从红墙封闭推断），二者缺一不可。

## 新题 9：镜像对称条件分支的双模逻辑运算

**组合逻辑**：[镜像对称检测](创新：对称性本身不是操作而是判定条件) → [逻辑运算](创新：具体执行哪种逻辑运算由对称检测结果决定，而非固定为一种) + [透明叠加/NOR](已有)

**来源原语**：逻辑运算(logical_op) ← 1b2d62fb；镜像(mirror) ← 846bdb03/7468f01a；透明叠加(transparent_overlay) ← ce4f8723；分隔行(separator_row) ← ce4f8723；二值掩模(binary_mask) ← 1b2d62fb；前景掩码(foreground_mask) ← ce4f8723；逐像素对应(pixelwise_correspond) ← 1b2d62fb；镜像对称(mirror_symmetry) ← e8686506；并集合并(union_merge) ← ce4f8723；逻辑或非合并(logical_NOR_combine) ← 1b2d62fb；逐格对齐(cell_aligned) ← ce4f8723

**依赖链**：分隔行将输入分为上下两个掩模 → 检测下掩模是否为上掩模的水平镜像 → 对称匹配则执行并集（OR）并涂绿 / 不匹配则执行或非（NOR）并涂红 → 结果写入中间面板。对称检测是决策节点，决定后续操作的种类和输出颜色，构成条件分支结构。

检测上下两个掩模是否互为水平镜像：若是，在中间面板输出它们的并集（绿色）；若否，输出它们的逻辑或非（红色）。

**输入结构**：约 15x7 的网格，黑(0)为背景。两条全宽水平灰(5)分隔行将网格等分为三个面板（上、中、下），每个面板高度相等（至少 3 行）。上面板包含一个栗(9)色前景掩模（若干栗(9)像素构成的图案）。下面板包含一个橙(7)色前景掩模。中间面板初始为全黑(0)。上下面板尺寸相同。生成约束：在所有示例中，有的示例下掩模是上掩模的精确水平镜像（将上掩模每行的列顺序翻转后与下掩模逐格一致），有的不是。每种情况至少出现一次。

**规则**：
1. 定位两条灰(5)分隔行，提取上面板掩模 U 和下面板掩模 D（栗(9)和橙(7)视为前景/活跃，黑(0)视为背景/不活跃）。
2. 将 U 水平镜像（每行内列顺序翻转），得到 U'。
3. 逐格比较 U' 和 D 的活跃状态：若所有格的活跃/不活跃状态完全一致，则判定为"镜像匹配"；否则为"不匹配"。
4. 若镜像匹配：
   - 对 U 和 D 逐格计算逻辑 OR（任一活跃则活跃）。
   - 活跃格涂绿(3)，不活跃格涂黑(0)。
   - 将结果写入中间面板。
5. 若不匹配：
   - 对 U 和 D 逐格计算逻辑 NOR（两者都不活跃则活跃）。
   - 活跃格涂红(2)，不活跃格涂黑(0)。
   - 将结果写入中间面板。
6. 上面板和下面板的内容被清空（全部填为黑(0)）。灰(5)分隔行保持不变。

**关键洞察**：执行哪种逻辑运算本身是一个需要推理的未知——求解者必须先发现对称检测这一隐含判定步骤，再发现两种不同的后续操作。仅看单个示例只能确定一种逻辑运算，必须对比镜像匹配和不匹配两种情况的示例才能完整归纳规则。
