## 新题 1：箭头定向模板旋转印章

**组合逻辑**：[朝向推断/dir_inference](创新：从控制射线方向改为控制模板旋转角度) + [印章覆盖/stamp_overlay] + [擦除/erase]（已有原语）

**来源原语**：朝向推断、缺角指示方向（参考题 6e19193c）；印章覆盖、模板掩码（参考题 e6721834、5a5a2103）；擦除（参考题 fd02da9e）

**依赖链**：箭头精灵体的缺角方向决定模板的旋转角度；旋转后的模板替换箭头原位——不推断方向就无法选择旋转，不擦除箭头就会与模板冲突。

根据每个箭头精灵体的朝向，将唯一模板旋转至对应角度后印章到箭头所在位置。

**输入结构**：黑(0)背景网格，约 15x15。左上角 3x3 区域有一个蓝(1)的非对称模板精灵体（3~5 个前景像素构成的不规则连通图案，不具备 90 度旋转对称性）。网格其余区域散布 3~5 个绿(3)箭头精灵体，每个占据 2x3 或 3x2 的边界框，形状为矩形缺去一个角像素（保留 5 个像素），各箭头之间至少间隔 4 个像素。每个箭头恰好缺去四个角之一，缺角位置各异。生成约束：箭头旋转印章后不会超出网格边界，不同箭头的印章区域不重叠。

**规则**：
1. 识别左上角 3x3 区域中的蓝(1)非对称模板。
2. 对每个绿(3)箭头，定位其边界框中唯一的黑(0)角像素，根据缺角位置确定指向方向：缺左上角→指向左上→旋转 0 度，缺右上角→指向右上→顺时针旋转 90 度，缺右下角→指向右下→旋转 180 度，缺左下角→指向左下→顺时针旋转 270 度。
3. 擦除该箭头的所有绿(3)像素（还原为黑(0)）。
4. 将模板按确定角度旋转后，以蓝(1)色印章在箭头边界框中心位置（取边界框中心行列，向下向右取整），模板中心对齐该位置。
5. 箭头按其边界框左上角的行优先、列次优先顺序依次处理。
6. 左上角模板本身在输出中保留不变。

**关键洞察**：箭头的缺角在源题中用于推断射线延伸方向，在此处被重新解释为模板旋转角度的编码；模板的非对称性使得四种旋转产生四种不同输出，缺角方向与旋转角度的对应关系需要对比多个示例才能归纳。

## 新题 2：触发点分割路径局部反转

**组合逻辑**：[颜色序列反转/reverse_color_seq](创新：局部反转而非整体) + [触发点分束/trigger_splits_beam](创新：从射线分束改为路径分割) + [计数/counting]（已有原语）

**来源原语**：颜色序列反转、端到端遍历、单像素宽路径（参考题 5792cb4d）；触发像素、触发点分束（参考题 db695cfb）；计数（参考题 dc2aa30b）

**依赖链**：触发像素将路径分为两段——没有触发像素就不知道在哪分割；计数比较两段长度——没有计数就不知道反转哪段；反转操作仅作用于较短段——没有反转整个变换就缺失。三个环节删任一个都无法确定输出。

灰色触发像素将多色路径一分为二，仅反转像素数较少的那段的颜色序列。

**输入结构**：黑(0)背景网格，约 12x15。网格中有一条由多种前景色（红(2)、蓝(1)、绿(3)、黄(4)、橙(7)中的若干种）构成的 4-连通单像素宽路径，路径恰好有两个端点且无分支，总长度 10~20 像素。路径上恰好有一个灰(5)像素作为触发点，它不在路径的两个端点上。生成约束：灰(5)触发点将路径分成的两段长度不同（保证无需 tie-break），且路径不自我相邻（路径上的任意像素最多只有 2 个 4-连通的路径邻居）。

**规则**：
1. 从路径一端出发，4-连通遍历至另一端，记录经过的像素序列。
2. 找到序列中唯一的灰(5)触发像素，以它为分界将路径分成两段（触发像素不归入任一段）。
3. 计算两段各自的像素数量。
4. 对像素数量较少的段：在原位反转该段的颜色序列（该段的第一个像素获得原来最后一个像素的颜色，依次类推）。
5. 像素数量较多的段保持颜色不变。
6. 灰(5)触发像素在输出中保持灰(5)不变。

**关键洞察**：触发像素在源题中作为射线的分束器，在此处作为路径的分割器；路径的两段谁被反转不是由位置或颜色决定，而是由计数比较决定——这个比较规则必须对比多个示例才能归纳出"较短段反转"的法则。

## 新题 3：孔洞分类角落吸引与中心聚拢

**组合逻辑**：[滑动/slide] + [重涂色/recolor](创新：角落标记色传递给无孔物体) + [有孔者升无孔者降/hole_up_holeless_down](创新：从上下分流改为角落vs中心分流)（已有原语改造）

**来源原语**：滑动、堆叠、碰撞停止、封闭孔洞、封闭对象、开放对象（参考题 ac2e8ecf）；角落标记、角落位置选模板（参考题 fd02da9e）；重涂色、相对方位（参考题 18286ef8）

**依赖链**：孔洞检测将物体分为两类——有孔物体按颜色匹配角落标记确定滑动目标，无孔物体按空间距离找最近角落标记获取新颜色后滑向网格中心。没有孔洞检测无法分类；没有角落标记有孔物体无目标、无孔物体无新颜色；没有滑动和堆叠无法安排最终位置。

检测物体是否有封闭孔洞：有孔物体滑向同色角落，无孔物体被最近角落标记重涂色后滑向网格中心。

**输入结构**：灰(5)背景网格，约 16x16。四个角落各有一个单像素标记：左上角=红(2)，右上角=蓝(1)，左下角=绿(3)，右下角=黄(4)。网格内部散布 4~6 个单色 4-连通前景物体（每个 5~12 像素），物体之间互不相邻。其中 2~3 个物体为封闭框架（内部包含至少一个被完全包围的灰(5)孔洞），它们的颜色分别与某个角落标记相同（红(2)、蓝(1)、绿(3)或黄(4)之一）且每种颜色最多一个封闭框架。其余 2~3 个物体为无孔的线状或不规则形状，统一使用橙(7)。生成约束：各物体滑动后不会超出网格边界；不同有孔物体的目标角落互不相同。

**规则**：
1. 检测每个前景物体是否包含封闭孔洞（物体像素完全包围的背景连通区域）。
2. 有孔物体：找到颜色匹配的角落标记，沿直线向该角落滑动直到物体边界框的对应角触及网格边或已放置物体。保持物体形状、颜色不变。按物体中心到目标角落的曼哈顿距离从近到远依次处理。
3. 无孔物体：计算物体中心到四个角落标记的曼哈顿距离，将物体重涂为最近角落标记的颜色（距离相同时取行号更小的角落）。然后将物体向网格中心点（第 8 行第 8 列）滑动，直到边界框中心到达该点或碰到已放置物体停止。按物体中心到网格中心的曼哈顿距离从远到近依次处理。
4. 四个角落标记像素在输出中保留不变。

**关键洞察**：孔洞检测在源题中决定上/下分流方向，此处重新定义为角落/中心分流；角落标记在源题中选择固定模板，此处同时充当有孔物体的目标定位器和无孔物体的颜色来源——两种完全不同的语义作用统一在同一组标记像素上，需要多个示例才能理清双重功能。

## 新题 4：射线围区边界色洪泛填充

**组合逻辑**：[连线/line_drawing] + [射线延伸/ray_extend + 触发点分束/trigger_splits_beam](创新：分束产生的几何分区作为洪泛填充的目标) + [洪泛填充/flood_fill](创新：填充色由围区边界颜色组成决定)

**来源原语**：连线、对角线段连接、同色配对、端点对（参考题 1f876c06）；射线延伸、触发像素、触发点分束、对角对齐（参考题 db695cfb）；洪泛填充（参考题 4e469f39）

**依赖链**：对角连线建立基础线网→触发像素在线上产生垂直分束射线→线网和射线共同围合出封闭区域→洪泛填充根据围区边界颜色组成选择填充色。四步之间逐级依赖：没有连线就没有线网，没有分束就没有足够的围区，没有边界色分析就无法确定填充色。

对角线连接同色像素对，触发像素在对角线上发射垂直射线，围出的封闭区域按边界颜色组成进行洪泛填充。

**输入结构**：黑(0)背景网格，约 15x15。蓝(1)像素成对出现，每对位于同一条 45 度对角线上，共 2~3 对（4~6 个蓝像素）。品红(6)像素 1~3 个，每个恰好位于某对蓝(1)像素的对角连线路径上（即品红像素与该对的两个蓝像素共线于同一条 45 度对角线）。每条对角连线上最多一个品红触发像素。生成约束：连线和射线形成的线网至少围合出 2 个不接触网格边的封闭区域；不同对角连线互不交叉（但分束射线可以与其他连线交叉）。

**规则**：
1. 对每对蓝(1)像素，沿 45 度对角方向绘制蓝(1)线段连接它们（包含两端点和中间所有像素）。
2. 对每个品红(6)触发像素，判断它所在对角线的方向（左上-右下或右上-左下），发射与该方向垂直的两条 45 度射线（即旋转 90 度方向），从触发像素出发向两侧延伸至网格边界，使用品红(6)绘制。
3. 颜色优先级：蓝(1)覆盖品红(6)。交叉位置显示蓝(1)。
4. 识别所有被线条和网格边界完全包围的黑(0)4-连通封闭区域（不包含任何接触网格边缘的区域）。
5. 对每个封闭区域，检查其边界（与该区域 4-邻接的所有非黑像素）的颜色：若边界全为蓝(1)→填充红(2)；若边界全为品红(6)→填充绿(3)；若边界同时包含蓝(1)和品红(6)→填充黄(4)。
6. 接触网格边缘的背景区域保持黑(0)不变。

**关键洞察**：触发像素的分束射线在源题中是纯粹的视觉输出，此处射线与连线共同创造几何分区——分区的存在完全依赖于分束行为。填充颜色由封闭区域边界的颜色组成决定，而非固定映射，需要对比多个区域和示例才能归纳出三种边界组成到三种填充色的规则。

## 新题 5：标记计数缩放与行调色板重涂

**组合逻辑**：[像素放大/pixel_scale](创新：缩放因子由标记数量隐式编码) + [重涂色/recolor + 行调色板/row_palette](创新：逐行带重涂应用于缩放后的输出) + [计数/counting]（已有原语）

**来源原语**：像素放大、基元图案、逐级展开（参考题 762cd429）；行调色板、行标记、模板掩码、分隔网格（参考题 5a5a2103）；计数（参考题 dc2aa30b）

**依赖链**：行标记的数量编码缩放因子（计数→缩放）；行标记的颜色决定缩放后各行带的颜色（行调色板→重涂）。同一组标记像素同时提供两种信息，删除计数则无法确定缩放比例，删除行调色板则无法确定输出颜色。

统计左侧行标记数量确定缩放因子，将角落基元图案等比放大后，按行标记颜色逐带重涂。

**输入结构**：灰(5)背景网格，约 18x18。左上角 3x3 区域包含一个单色（蓝(1)）基元图案，该图案由 3~7 个蓝(1)前景像素和灰(5)背景像素构成（不完全填满 3x3，具有识别性的非对称形状）。沿第 0 列（左边缘），从第 4 行开始向下，有 N 个单像素行标记，每个占一行一列，颜色各不相同（从红(2)、绿(3)、黄(4)、橙(7)、品红(6)、青(8)中选取），标记之间无间隔、连续排列。N 为 3 的倍数（6 或 9），且 N 不超过网格高度减 3。生成约束：放大后的图案（Nx N 像素）不超出网格边界。

**规则**：
1. 统计左边缘行标记的总数 N。缩放因子 S = N / 3。
2. 将左上角 3x3 基元图案等比像素放大 S 倍：每个原始像素扩展为 SxS 的像素块，生成 NxN 的放大图案。
3. 放大图案放置在网格左上角（第 0 行第 0 列起始，覆盖原 3x3 区域）。
4. 将 N 个行标记从上到下编号 1~N，每个标记对应放大图案中的一行。第 k 个行标记的颜色替换放大图案第 k 行中所有前景像素的颜色（原灰(5)背景像素保持灰(5)不变）。
5. 在输出中移除左边缘的行标记像素（还原为灰(5)）。
6. 网格中放大图案和行标记区域以外的部分保持不变。

**关键洞察**：同一组行标记同时编码两种信息——数量决定缩放比例，颜色决定重涂方案。缩放因子不是固定常数而是由输入隐式编码的，需要对比不同标记数量的示例才能归纳出 S=N/3 的关系。行调色板在源题中与固定大小的网格配合，此处必须与动态缩放后的尺寸匹配，两者通过标记数量紧密耦合。

## 新题 6：间隙等分多物体水平滑动堆叠

**组合逻辑**：[间隙对半分/gap_bisect](创新：从两个矩形之间的等分扩展为多物体的滑动目标边界) + [滑动/slide + 碰撞停止/collision_stop + 堆叠/stack]（已有原语组合改造）

**来源原语**：间隙对半分、奇数间隙留中线、矩形（参考题 d968ffd4）；滑动、堆叠、碰撞停止（参考题 ac2e8ecf）

**依赖链**：间隙的宽度和位置决定了滑动的目标边界——没有间隙等分规则，物体不知道滑到哪里停止；碰撞堆叠解决同侧多物体的空间冲突——没有堆叠规则，多物体重叠无法处理；奇偶间隙宽度改变中心列的处理方式——需要多个示例才能发现。

左右两组矩形向中央间隙各自半区滑动，碰撞堆叠，奇数宽间隙的中心列保持空白。

**输入结构**：黑(0)背景网格，约 15x20（15 行 20 列）。网格中央有一条 3~7 列宽的垂直背景间隙（全为黑(0)），将网格分为左右两半。左半包含 2~4 个单色矩形物体（每个 2x2 至 3x4，颜色从红(2)、蓝(1)、绿(3)中选取，各物体颜色可以不同），这些物体位于不同列但行范围可能重叠。右半同样包含 2~4 个单色矩形物体（颜色从黄(4)、橙(7)、品红(6)中选取）。生成约束：所有左半物体的行范围与所有右半物体的行范围覆盖相同的总行区间（使得滑动后可能发生同行碰撞）；同侧物体不重叠。

**规则**：
1. 识别垂直间隙：找到所有完全为黑(0)的连续列，这些列构成中央间隙。
2. 计算间隙的中心线。若间隙宽度为偶数（2W 列），左半区为间隙左 W 列，右半区为间隙右 W 列。若间隙宽度为奇数（2W+1 列），左半区为间隙左 W 列，右半区为间隙右 W 列，中心列保持黑(0)。
3. 左侧物体向右滑动：每个物体水平右移直到其右边缘触及左半区的右边界或碰到已放置物体的左边缘。垂直位置不变。
4. 右侧物体向左滑动：每个物体水平左移直到其左边缘触及右半区的左边界或碰到已放置物体的右边缘。垂直位置不变。
5. 同侧处理顺序：按物体与间隙的水平距离从近到远依次处理（距离相同时行号小的先处理）。
6. 物体形状和颜色保持不变。间隙外的原始物体位置还原为黑(0)。

**关键洞察**：间隙等分在源题中只是两个对称矩形之间的简单空间划分，此处扩展为多物体的滑动目标——间隙的宽度和奇偶性同时约束所有物体的最终位置。滑动的碰撞堆叠在源题中发生在垂直方向，此处改为水平方向且目标不是网格边缘而是间隙半区边界，需要同时理解间隙等分和碰撞规则。

## 新题 7：瓦片内路径长度排序与颜色反转

**组合逻辑**：[排序/sorting + 重排/rearrange](创新：排序键由路径遍历长度提供而非前景像素计数) + [颜色序列反转/reverse_color_seq + 端到端遍历/endpoint_traversal]（已有原语新作用：同一路径遍历同时提供排序键和反转数据）

**来源原语**：排序、重排、瓦片、分隔线、阵列排布、前景数决定排序（参考题 dc2aa30b）；颜色序列反转、端到端遍历、单像素宽路径、形状不变仅反色序（参考题 5792cb4d）

**依赖链**：路径遍历同时生成两个信息——路径长度（供排序）和颜色序列（供反转）。排序改变瓦片位置，反转改变瓦片内路径颜色，两者共享同一个路径遍历过程。去掉排序则瓦片不动（颜色反转仍可做但位置错误），去掉反转则瓦片重排但颜色未变（缺失变换），去掉路径遍历则两者都无法执行。

按各瓦片内部路径长度排序重排瓦片，同时反转每条路径的颜色序列。

**输入结构**：黑(0)背景网格，11x11。灰(5)分隔线（第 3、7 行和第 3、7 列为完整灰线）将网格分为 3x3 共 9 个 3x3 瓦片。每个瓦片内部包含一条多色 4-连通单像素宽路径，路径长度 2~7 像素不等（9 个瓦片的路径长度两两不同），路径无分支，恰好两个端点。路径使用的颜色从红(2)、蓝(1)、绿(3)、黄(4)、橙(7)中选取，同一路径上相邻像素颜色不同。生成约束：9 条路径的长度互不相同。

**规则**：
1. 对每个瓦片，从路径中距离瓦片左上角最近的端点（曼哈顿距离较小的端点；相同时取行号更小的）开始，4-连通遍历至另一端点，记录颜色序列和路径长度。
2. 按路径长度从小到大排列 9 个瓦片。
3. 将排序后的瓦片放入网格槽位：从左下角（第 3 行第 3 列区域，即第 8-10 行第 0-2 列）开始，同一行从左到右填充，填满一行后向上移动一行。
4. 放入新槽位时，反转瓦片内路径的颜色序列：遍历起点像素获得原遍历终点像素的颜色，依次类推。路径的几何形状（像素位置）保持不变，仅颜色改变。
5. 灰(5)分隔线保持不变。

**关键洞察**：路径遍历在源题中仅用于反转颜色序列，此处同时作为排序键的来源——遍历的"副产品"（路径长度）驱动了瓦片的空间重排。排序和反转耦合在同一次遍历中：反转的方向取决于遍历起点的选择，而遍历起点又影响排序的 tie-break（虽然长度两两不同，但起点选择决定了颜色序列的方向，因此反转结果依赖于起点规则）。

## 新题 8：跨带图案补全与优先级叠合

**组合逻辑**：[补全/completion + 形状匹配/shape_match](创新：补全的参考模板分布在不同水平带中) + [透明叠加/transparent_overlay + 固定优先合成/fixed_priority_compositing](创新：叠合对象是补全后的带而非原始带)

**来源原语**：补全、形状匹配、对称图案、完整图案推断缺失（参考题 72322fa7）；透明叠加、折叠、等高带、颜色掩码层、同坐标叠加、固定优先合成（参考题 3d31c5b3）

**依赖链**：先补全后叠合——不补全就会有缺失像素导致叠合结果出现不该有的空洞；叠合的优先级顺序非自然序（第 3、4 带交换），补全无法解决冲突，必须靠优先级规则。去掉补全则叠合结果有缺陷，去掉叠合则四带无法合成为一带，去掉优先级规则则冲突位置无解。

先在各带内补全残缺图案，再按非自然优先级叠合四带为一带。

**输入结构**：黑(0)背景网格，16x16（4 个等高水平带，每带 4x16）。每带有专属前景色：第 1 带（顶部第 0-3 行）=红(2)，第 2 带（第 4-7 行）=蓝(1)，第 3 带（第 8-11 行）=绿(3)，第 4 带（第 12-15 行）=黄(4)。每带包含若干 3x3 图案实例（中心像素 + 周围壳像素，壳像素的偏移模式全局统一，例如"上、下、左、右四个正交邻居"）。每带中至少有一个完整图案（中心+完整壳）和一个残缺图案（仅中心无壳，或仅壳无中心）。完整图案至少在一个带中出现以提供全局壳模式参考。生成约束：不同带中的图案位置有局部坐标重叠（即至少两个带在相同的局部列位置有图案实例），以产生叠合冲突。

**规则**：
1. 从任意带中的完整图案（中心+完整壳都存在）学习全局壳偏移模式（中心像素周围哪些相对位置需要壳像素）。
2. 在每个带中，对仅有中心的残缺图案：在壳偏移位置补上该带颜色的壳像素（如果该位置是黑(0)背景则补，已有其他像素则不覆盖）。对仅有壳的残缺图案：在壳包围推断出的中心位置补上该带颜色的中心像素。
3. 补全完成后，将四带叠合为一带（输出尺寸 = 单带尺寸 4x16）：对每个局部坐标 (r, c)（r 取 0~3，c 取 0~15），从四带的 (r, c) 位置中按优先级取第一个非黑像素作为输出值。
4. 优先级顺序：第 1 带 > 第 2 带 > 第 4 带 > 第 3 带（注意第 3 和第 4 带优先级互换）。
5. 若所有四带的 (r, c) 位置都为黑(0)，输出黑(0)。

**关键洞察**：补全和叠合是紧耦合的两步——补全改变了每带的像素分布，从而改变叠合时的冲突格局。如果跳过补全直接叠合，某些位置会缺失像素导致低优先级带的颜色意外显现。优先级的第 3/4 带互换是非自然排列，单个示例可能无法区分自然序和互换序，必须对比多个带有冲突的示例。

## 新题 9：双面板掩码过滤频率打包

**组合逻辑**：[掩码裁剪/mask_crop](创新：掩码不裁剪图像而是过滤统计样本) + [计数/counting + 排序/sorting + 按频率降序/descending_freq + 逐列填充/column_fill]（已有原语组合）

**来源原语**：双面板（参考题 e6721834）；掩码裁剪、精灵窗口、空白窗口、标记点偏移对应（参考题 2f0c5170）；按频率降序、逐列填充、计数（参考题 bd283c4a）；排序（参考题 dc2aa30b）

**依赖链**：掩码选择哪些像素参与频率统计——不同掩码产生不同频率排名；频率排名决定打包顺序——没有排序则无法确定输出的颜色排布。掩码和频率打包通过"被选中的像素集合"紧密耦合：掩码改变样本集→样本集改变频率→频率改变打包顺序。

右面板的掩码过滤左面板像素，统计被选中像素的颜色频率，按频率降序逐列底部起打包输出。

**输入结构**：黑(0)背景网格，约 10x22（10 行 22 列，其中左面板 10x10 占第 0-9 列，中间第 10 列为灰(5)分隔列，右面板 10x10 占第 11-20 列，第 21 列为黑(0)留白）。左面板密集填充 3~5 种前景颜色（红(2)、蓝(1)、绿(3)、黄(4)、橙(7)），几乎无黑(0)像素。右面板为二值掩码：栗(9)像素表示选中，黑(0)像素表示不选，大约 30%~60% 的位置为栗(9)。生成约束：经掩码过滤后，至少 3 种颜色被选中，且选中像素中各颜色的频率互不相同（无需 tie-break）。

**规则**：
1. 右面板为掩码。对右面板中每个栗(9)像素位置 (r, c')（c' 为面板内列号 0~9），取左面板相同位置 (r, c') 的像素颜色，加入选中像素集合。
2. 统计选中像素集合中每种非黑颜色的出现次数。
3. 按频率从高到低排列颜色。
4. 输出网格尺寸为 10x10（单面板大小）。逐列从左到右、每列从底到顶填充：先放置最高频颜色的所有像素，紧接着放次高频，依此类推。当一列填满后继续到下一列的底部。
5. 输出中未填充的位置保持黑(0)。
6. 灰(5)分隔列和右面板不出现在输出中。

**关键洞察**：掩码在源题中用于空间裁剪（复制图案到目标位置），此处用于统计过滤——掩码不决定"放在哪"，而是决定"数什么"。同一个左面板在不同掩码下会产生不同的频率排名和完全不同的打包结果，这种掩码→统计→空间重组的链条是源题中不存在的结构关系。

## 新题 10：对角端点递增三角填充

**组合逻辑**：[连线/line_drawing + 同色配对/same_color_pairing](创新：连线不是画直线段而是逐行递增展开为三角形) + [逐行递增/row_by_row_increment + 每行递增扩展/row_incremental_expand](创新：递增方向从水平改为沿对角方向)

**来源原语**：连线、同色配对、端点对、对角线段连接（参考题 1f876c06）；逐行递增、每行递增扩展、色段、填充（参考题 bbc9ae5d）

**依赖链**：同色配对确定端点对和对角方向——没有配对不知道三角形的方向和范围；逐行递增决定每行填充的宽度——没有递增规则不知道三角形的形状。端点位置同时编码了对角方向和递增步数（两端点的行距=步数），两种信息紧密耦合在同一组输入中。

同色端点对之间不画对角线段，而是从一端逐行递增展开直到另一端，形成直角三角形填充。

**输入结构**：黑(0)背景网格，约 14x14。2~4 种前景颜色，每种颜色恰好出现两次。每对同色像素位于同一条 45 度对角线上（行差的绝对值=列差的绝对值）。不同颜色对的像素互不相邻，且生成约束：各对产生的三角形填充区域互不重叠。

**规则**：
1. 对每种前景颜色，找到其两个像素，确定上方像素（行号较小者）为起点，下方像素为终点。
2. 确定对角方向：若终点在起点的右下方，则对角方向为"右下"；若终点在起点的左下方，则对角方向为"左下"。
3. 从起点所在行开始，逐行向下填充：
   - 第 0 行（起点行）：仅填充起点像素自身（1 个像素）。
   - 第 k 行（起点行 + k）：填充一个水平色段，从起点正下方第 k 行的列位置开始，沿对角方向延伸 k+1 个像素（即色段覆盖 k+1 列）。若对角方向为"右下"，色段从起点列开始向右延伸 k+1 个像素；若对角方向为"左下"，色段从起点列开始向左延伸 k+1 个像素（最右端为起点列，最左端为起点列-k）。
4. 填充持续到终点所在行为止。终点行的色段的对角方向末端像素恰好是终点像素。
5. 所有颜色对独立处理，按颜色对中起点行号从小到大的顺序依次绘制。后绘制的覆盖先绘制的（但生成约束保证无重叠）。

**关键洞察**：源题中的对角连线是一维线段，源题中的逐行递增是水平色段的逐行延伸——两者组合后产生了源题中都不存在的二维三角形填充。对角端点的位置隐式编码了三角形的方向（左下/右下）和大小（行距=递增步数），这种几何信息的双重编码需要对比多个示例（不同方向、不同大小的三角形）才能归纳。
