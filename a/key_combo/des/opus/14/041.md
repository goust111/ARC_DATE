## 新题 1：像素数同时编码邻域几何与扩展深度

**组合逻辑**：[计数(counting)](创新：从全局统一系数改为逐对象双重编码) + [描边(mark_neighbors)](创新：邻域几何不由颜色决定而由像素数奇偶决定) → 扩展深度由像素数量值决定

**来源原语**：计数(counting) ← ac0a08a4；描边/mark_neighbors ← 0ca9ddb6, b27ca6d3；对角邻接(diagonal_adjacency)/正交邻接(orthogonal_adjacency) ← 0ca9ddb6；尺寸分类(size_classification) ← b27ca6d3；数量决定倍率(count_determines_scale) ← ac0a08a4

**依赖链**：每个连通分量的像素数 N 同时决定两件事——N 的奇偶性选择邻域几何类型（偶数→对角，奇数→正交），N 的数值决定扩展层数（偶数为 N/2 层，奇数为 (N-1)/2 层）。删除像素计数则无法确定几何和深度；删除几何选择则无法区分标记方向；删除深度规则则无法确定扩展范围。三者缺一不可。

一句话总结：根据每个彩色连通分量的像素数，用奇偶性选择对角或正交邻域，用数值大小决定扩展层数，围绕该分量绘制对应颜色的标记光晕。

**输入结构**：约 17x17 的黑(0)背景网格。散布 4-6 个单色 4-连通前景分量，每个分量由 3-7 个像素组成，每个分量的颜色互不相同（使用蓝(1)、红(2)、绿(3)、品红(6)、橙(7)等）。分量形态不限（可为线段、折线、不规则团块等），但各分量之间的间距足够大（最小间距 >= 最大可能扩展半径 + 1），保证在最大层数扩展后各分量的标记区域互不重叠。生成约束：每个分量的像素数至少为 3，且至少有一个偶数像素数分量和一个奇数像素数分量。

**规则**：
1. 识别所有 4-连通的非黑前景分量，记每个分量的像素数为 N。
2. 若 N 为偶数：以该分量的每个像素为中心，向外扩展 N/2 层对角邻域（第 1 层为每个前景像素的 4 个对角邻居，第 2 层为第 1 层所有像素的对角邻居中尚未被标记的位置，依此类推），标记色为黄(4)。
3. 若 N 为奇数：以该分量的每个像素为中心，向外扩展 (N-1)/2 层正交邻域（第 1 层为每个前景像素的 4 个正交邻居，后续层同理），标记色为橙(7)。
4. 扩展时超出网格边界的位置跳过。
5. 原始前景像素保持不变，不被标记色覆盖。
6. 若不同分量的标记区域意外重叠（违反生成约束时的兜底），像素数更大的分量的标记优先。

**关键洞察**：像素数的奇偶性和数值是一个量的两个面——奇偶选择标记的几何形状（对角菱形 vs 正交十字），数值选择光晕的厚度。仅看单个示例可能猜到固定几何和固定层数，必须对比多个分量和多个示例才能归纳出双重编码规则。

## 新题 2：多数色频次即为面积重涂阈值

**组合逻辑**：[多数投票(majority_vote)](已有) → [计数(counting)](创新：多数色的频次作为另一操作的阈值而非写入像素) → [重涂色(recolor)](创新：阈值不固定而由上方图案的统计量动态决定)

**来源原语**：多数投票(majority_vote)/计数(counting)/单点绘制(single_cell_paint) ← 27a77e38；重涂色(recolor)/面积超阈值则变色(recolor_above_threshold) ← ae58858e；分隔行(separator_row)/双分区(two_partitions)/图案区(pattern_region)/结果区(result_region) ← 27a77e38；连通分量(connected_component) ← ae58858e

**依赖链**：上方图案的多数色投票产生两个信息——多数色本身（决定重涂目标颜色）和该色的出现次数（决定面积阈值）。下方区域的每个连通分量必须同时满足面积条件才会被重涂。删除多数投票则不知颜色也不知阈值；删除面积判断则所有分量都被重涂（与示例矛盾）；删除重涂操作则无输出变化。

一句话总结：从分隔线上方的图案中找出多数色及其出现次数 K，将下方区域中面积 >= K 的所有连通分量重涂为该多数色。

**输入结构**：约 12x20 的网格。中间有一条全宽灰(5)水平分隔行。上方区域（图案区）：黑(0)背景上散布 3-4 种非黑、非灰颜色的像素（例如红(2)、蓝(1)、绿(3)），总数约 15-25 个像素，其中某一颜色的像素数严格最多（不平局）。下方区域（结果区）：黑(0)背景上有 4-6 个单色 4-连通分量，面积从 2 到 8 不等，颜色各异（均非黑、非灰、不含上方图案中出现的颜色）。生成约束：上方多数色的频次 K 取值在 4-7 之间，使下方至少有一个分量面积 >= K、至少有一个分量面积 < K。

**规则**：
1. 找到全宽灰(5)分隔行，将网格分为上方图案区和下方结果区。
2. 在图案区中统计每种非黑、非灰颜色的像素数，找到频次严格最高的颜色 C 及其出现次数 K。
3. 在结果区中，对每个 4-连通非黑分量：若其面积（像素数）>= K，将该分量的所有像素重涂为 C。
4. 面积 < K 的分量保持原色不变。
5. 图案区和分隔行在输出中保持不变。

**关键洞察**：上方图案同时编码了"涂什么颜色"和"哪些对象有资格被涂"两条独立信息。单个示例中阈值看似固定（如恰好是 5），需对比多个示例（不同图案、不同 K 值）才能归纳出 K = 多数色频次。

## 新题 3：逐精灵缩放后匹配空腔

**组合逻辑**：[计数(counting)](创新：从全局系数变为逐对象独立系数) → [像素放大(pixel_scale)](创新：每个精灵各自缩放，非全局统一) → [嵌入填充(inlay_fill)](已有，但操作对象是缩放后的精灵)

**来源原语**：像素放大(pixel_scale)/计数(counting)/前景数为放大系数(foreground_count_as_scale_factor)/数量决定倍率(count_determines_scale) ← ac0a08a4；嵌入填充(inlay_fill)/模板框架(template_frame)/精灵体(sprite)/矩形空腔(rectangular_cavity)/尺寸匹配(size_matching)/唯一槽位配对(unique_slot_pairing) ← 5dbc8537

**依赖链**：每个精灵的像素数决定其自身的缩放系数 → 缩放改变精灵的尺寸 → 缩放后的尺寸用于匹配空腔。若跳过计数则不知缩放系数；若跳过缩放则精灵尺寸远小于空腔无法匹配；若跳过空腔匹配则不知精灵放置位置。源题 ac0a08a4 中计数是全局的（整个网格的前景像素数统一决定放大倍率），这里改为逐精灵独立计数独立缩放，本质不同。

一句话总结：每个精灵按自身像素数放大后，恰好嵌入模板框架中尺寸匹配的唯一空腔。

**输入结构**：约 20x20 的网格，黑(0)背景。网格中有一个大型蓝(1)实心区域作为模板框架，框架内有 3 个矩形空腔（黑(0)区域），空腔尺寸各异（例如 4x6、6x6、9x6）。框架外有 3 个小型精灵体，每个精灵是一个由单一非黑、非蓝颜色组成的 4-连通小图形，像素数分别为 2、3、3（各精灵颜色不同，例如红(2)、绿(3)、黄(4)）。精灵的形状各异（如 1x2 横条、L 形 3 像素、1x3 竖条），各精灵间互不相邻。生成约束：像素数为 N 的精灵缩放 N 倍后（每像素变 NxN 块），其包围盒恰好与某个空腔尺寸一致，且缩放后的精灵与空腔之间形成一一对应（无歧义配对）。

**规则**：
1. 识别蓝(1)模板框架及其内部的矩形空腔。
2. 识别框架外的所有非黑、非蓝色精灵体（每个精灵为一个 4-连通分量）。
3. 对每个精灵，计算其像素数 N。
4. 将该精灵按系数 N 进行像素放大：精灵包围盒内的每个像素（包括背景像素）变为 NxN 的同色方块。
5. 将缩放后的精灵按尺寸（宽 x 高）与空腔一一匹配。
6. 将每个缩放后的精灵放入其匹配的空腔中（左上角对齐）。
7. 输出为模板框架区域（包含已填充空腔的完整框架包围盒）。

**关键洞察**：精灵在原始输入中看起来远小于空腔，求解者必须发现"每个精灵按自身像素数独立缩放"这一隐藏步骤，才能理解为何缩放后恰好与空腔匹配。仅凭一个示例可能猜出固定缩放系数，需多个不同像素数的精灵对比才能归纳出"像素数 = 缩放系数"。

## 新题 4：对称性选定种子驱动跨瓦片螺旋

**组合逻辑**：[对称检测(symmetry_detect)](已有) → 选定激活种子 → [螺旋绘制(spiral_draw)](创新：螺旋跨越瓦片边界，障碍来自所有瓦片) + [擦除(erase)](创新：对称瓦片的种子被擦除)

**来源原语**：对称检测(symmetry_detect)/瓦片(tile)/堆叠排列(stacked_layout)/选无对角对称瓦片(select_asym_tile) ← 662c240a；螺旋绘制(spiral_draw)/种子像素(seed_pixel)/障碍像素(blocker_pixel)/递增步长(increasing_step)/遇障碍停止(stop_at_blocker) ← e5c44e8f；擦除(erase) ← 9f8de559

**依赖链**：对称检测 → 确定哪个瓦片的种子"激活" → 激活种子发出螺旋 → 螺旋路径受所有瓦片中的障碍像素约束 → 同时对称瓦片的种子被擦除。对称检测和螺旋绘制在源题中毫无关联（662c240a 输出的是裁剪后的瓦片，e5c44e8f 的种子是唯一给定的），这里它们之间产生了全新的"选择→生成"结构关系。

一句话总结：将网格分为若干瓦片，找到障碍像素布局不具备对角对称性的唯一瓦片，从该瓦片的种子像素出发在整个网格上绘制螺旋直到撞上障碍，同时擦除其余瓦片的种子。

**输入结构**：约 15x15 的网格，黑(0)背景。网格被等分为 3 个水平条带瓦片（每个 5x15）。每个瓦片中包含：一个绿(3)种子像素，以及若干灰(5)障碍像素（3-6 个）。在 3 个瓦片中，恰好 2 个瓦片的灰(5)障碍像素布局具有主对角线转置对称性（即以瓦片自身坐标系衡量，将障碍像素坐标 (r,c) 转置为 (c,r) 后仍与原布局一致），另外 1 个瓦片的障碍布局不对称。每个瓦片的种子像素位置任意，但不与障碍像素重叠。生成约束：不对称瓦片的种子位于网格中部区域附近（使螺旋有充分空间展开）。

**规则**：
1. 将网格等分为 3 个水平条带瓦片。
2. 对每个瓦片，仅检查其灰(5)障碍像素的布局：将障碍像素坐标转换为瓦片内局部坐标 (r, c)，检查所有 (r, c) 是否与 (c, r) 一一对应。
3. 恰好有 1 个瓦片的障碍布局不满足对角转置对称——该瓦片中的绿(3)种子像素被"激活"。
4. 从激活种子出发，在整个网格（不限于该瓦片）上绘制螺旋：方向序列为上、右、下、左循环，步长序列为 2, 2, 4, 4, 6, 6, ...（每个方向走完对应步数后转向）。
5. 每一步：若目标位置在网格内且为黑(0)背景，则涂为绿(3)；若目标位置超出网格边界则跳过该步但步数仍消耗；若目标位置为灰(5)障碍像素，则整条螺旋立即停止（不涂该位置）。
6. 其余 2 个对称瓦片的种子像素被擦除（涂为黑(0)背景）。
7. 所有灰(5)障碍像素保持不变。

**关键洞察**：螺旋的起点由对称性分析决定（非位置、非颜色），螺旋的终点由全局障碍分布决定（不限于种子所在瓦片），两者的交互使输出图案难以直接预判。求解者必须先完成对称性判断才能确定螺旋从哪里开始。

## 新题 5：异色矩形沿角标对角平移并分裂碰撞体

**组合逻辑**：[颜色异常值选择(outlier_color_selection)](创新：从象限选取改为矩形选取) → [平移(translate) + 角位指示方向(corner_indicates_dir)](已有，但只施加于异常值对象) → [分裂(split)](创新：分裂由平移碰撞触发而非预设路径)

**来源原语**：颜色异常值选择(outlier_color_selection) ← 0b148d64；平移(translate)/填充矩形(filled_rectangle)/控制像素(control_pixel)/角位指示方向(corner_indicates_dir)/对角固定步移(diagonal_fixed_step) ← 470c91de；分裂(split)/穿越并分开(pass_through_split)/轴线排列(axis_arrangement) ← 9f669b64；擦除(erase) ← 多题

**依赖链**：异常值颜色检测 → 选定唯一运动体 → 控制像素确定对角运动方向 → 运动体沿对角线持续平移直到碰撞或到达边界 → 若碰撞到另一矩形则将被碰撞矩形沿垂直于运动方向的轴分裂。三个环节缺一不可：不知谁是异常值则不知谁运动；不知角位则不知方向；不知分裂规则则碰撞无法处理。源题中三者分属不同谜题（0b148d64 做颜色异常值选取、470c91de 做角位平移、9f669b64 做穿越分裂），这里它们形成全新的"选择→运动→碰撞交互"链，且碰撞的对象和分裂方向都取决于运动方向，产生涌现效应。

一句话总结：在若干带角标的彩色矩形中找出颜色唯一的异常矩形，沿其角标方向对角平移，若碰撞到另一矩形则将该矩形沿运动垂直方向一分为二。

**输入结构**：约 18x18 的黑(0)背景网格。4 个填充矩形（约 3x2 到 4x3 大小），每个矩形有一种主体颜色。其中 3 个矩形共享同一颜色（如红(2)），第 4 个矩形为不同颜色（如绿(3)）——即颜色异常值。每个矩形的一个角上有一个青(8)控制像素（替换该角的一个像素）。4 个矩形在网格中分散放置，保证异常矩形沿其青(8)角标指示的对角方向移动时，路径上恰好经过一个同色（红(2)）矩形。生成约束：异常矩形的移动路径不经过多于一个其他矩形；至少有一个红(2)矩形不在运动路径上。

**规则**：
1. 识别所有填充矩形（将每个矩形的青(8)像素视为其角上的控制标记，该位置实际属于矩形）。
2. 统计每个矩形的主体颜色（非青色的颜色），找到颜色唯一的异常矩形。
3. 异常矩形的青(8)控制像素所在角的方向即为运动方向（如青(8)在右上角→运动方向为右上，即行 -1、列 +1）。
4. 将异常矩形的青(8)像素恢复为矩形主体颜色，得到完整矩形。
5. 擦除异常矩形的原始位置（涂为黑(0)）。
6. 沿运动方向逐步平移该矩形（每步行列各移 1），直到矩形的下一步位置与另一个矩形重叠或矩形边缘触及网格边界。
7. 若因碰撞停止：异常矩形停在碰撞前最后的合法位置。被碰撞的矩形沿垂直于运动方向的轴被分裂——将被碰撞矩形沿异常矩形运动路径的投影线一分为二，两半各向垂直方向外移 1 格。被碰撞矩形的青(8)控制像素随其所在半边移动。
8. 若因边界停止：异常矩形停在最后的合法位置，无分裂发生。
9. 未被碰撞的矩形保持原位不变（保留其青(8)控制像素）。

**关键洞察**：其他矩形上的青(8)角标是视觉诱饵——它们暗示所有矩形都会移动，但实际上只有颜色异常值才动。分裂方向取决于运动方向（垂直于运动轴），而非被碰撞矩形的自身属性，这需要对比多个示例（不同运动方向产生不同分裂轴）才能归纳。

**依赖链**：杯口朝向 → 确定螺旋起始方向（上/右/下/左中的一个）→ 从杯口中点发出螺旋 → 螺旋受障碍阻断（包括其他杯体和先绘制的螺旋）→ 处理顺序由杯壁面积决定（最小先处理）。这形成"属性提取→参数注入→顺序生成→互相约束"的四层耦合。aba27056 中杯口只产生直线射线，e5c44e8f 中螺旋起始方向固定且只有一个种子——这里杯口和螺旋的结合是全新的结构关系，多杯互相阻挡则产生涌现效应。

一句话总结：对多个不同朝向的杯形容器，填充内部后从各杯口出发绘制螺旋（方向由杯口决定），按面积从小到大处理，先画的螺旋成为后画螺旋的障碍。

**输入结构**：约 22x22 的黑(0)背景网格。包含 2-3 个杯形容器，每个杯由一种非黑颜色的像素围成（如红(2)、蓝(1)、绿(3)），杯壁厚度为 1 像素。每个杯的开口朝向不同（一个朝右、一个朝上、一个朝左等），杯的大小各异（杯壁像素数从 8 到 16 不等）。杯之间间距至少 4 格。网格上另有若干灰(5)孤立障碍像素分散放置（不与杯相邻）。杯的内部（被杯壁包围且从开口不可达的黑(0)像素）为空。生成约束：各杯面积互不相等（无平局）；杯的间距和障碍分布使得至少有一个螺旋会被另一个杯体或先画的螺旋阻断。

**规则**：
1. 识别所有杯形容器及其颜色。每个杯的开口方向通过如下方式判定：找到杯壁包围盒上唯一缺口所在的边（上/下/左/右）。
2. 将每个杯的内部封闭像素（通过从开口对面的边进行 4-连通洪泛可达的黑(0)像素）填充为黄(4)。
3. 按杯壁像素数从小到大排列处理顺序（像素数最少的杯先处理）。若两个杯的壁像素数相同，则包围盒左上角更靠左上的先处理。
4. 依次处理每个杯：从该杯开口边的中点位置出发（若开口宽度为偶数则取偏左/偏上的中点），向开口方向发出一条螺旋。
5. 螺旋规则：第一步方向为开口朝向，随后按顺时针旋转（如开口朝右→第一段向右，第二段向下，第三段向左，第四段向上，循环）。步长序列为 1, 1, 2, 2, 3, 3, ...（每两段递增 1）。
6. 螺旋的每一步：若目标位置在网格内且为黑(0)背景，则涂为该杯的杯壁颜色；若超出网格则跳过但步数仍消耗；若目标位置为任何非黑像素（包括其他杯壁、灰(5)障碍、黄(4)填充、先前绘制的螺旋轨迹），则螺旋立即终止（不涂该位置）。
7. 所有灰(5)障碍像素、杯壁像素、黄(4)填充保持不变。

**关键洞察**：每个杯的螺旋起始方向不同（由杯口朝向决定），而处理顺序（由杯壁面积决定）决定了谁的螺旋先画——先画的螺旋会阻挡后画的螺旋。同样的杯群如果面积排序不同则输出完全不同，这一隐藏的顺序依赖需要对比多个示例才能发现。

## 新题 7：轨迹方向瞄准空腔，尺寸不匹配则擦除精灵

**组合逻辑**：[射线延伸(ray_cast) + 反向投射(opposite_direction)](创新：射线不再擦除障碍而是用于定位目标空腔) → [嵌入填充(inlay_fill) + 尺寸匹配(size_matching)](创新：匹配失败时不跳过而是触发擦除) → [擦除(erase)](创新：擦除由尺寸不匹配条件触发)

**来源原语**：射线延伸(ray_cast)/标记像素(marker_pixel)/轨迹(trail)/反向投射(opposite_direction)/首个障碍(first_obstacle) ← 9f8de559；嵌入填充(inlay_fill)/模板框架(template_frame)/矩形空腔(rectangular_cavity)/精灵体(sprite)/尺寸匹配(size_matching)/唯一槽位配对(unique_slot_pairing) ← 5dbc8537；擦除(erase) ← 9f8de559, d59b0160

**依赖链**：每个精灵的轨迹指示方向 → 射线瞄准模板上的特定空腔 → 精灵尺寸与目标空腔比对 → 匹配则填入，不匹配则精灵被擦除。9f8de559 中射线的作用是擦除命中点，5dbc8537 中空腔分配基于全局尺寸匹配而非方向——这里射线的功能变为"空间寻址"（方向定位空腔），而擦除的触发条件变为"尺寸不匹配"，两者都与源题用法本质不同。

一句话总结：每个带标记和轨迹的精灵沿轨迹反方向射线瞄准模板中的空腔——尺寸吻合则嵌入，不吻合则精灵被抹去。

**输入结构**：约 20x22 的黑(0)背景网格。中央偏上有一个蓝(1)实心模板框架（约 10x14），内含 4 个矩形空腔（黑(0)区域），尺寸各异（如 2x3、3x3、2x4、3x4）。模板框架下方分散放置 4 个精灵体，每个精灵由一种独特颜色的 4-连通像素组成（如红(2)、绿(3)、黄(4)、品红(6)），像素数 4-12 不等。每个精灵旁边紧邻一个红(2)标记像素，标记像素旁连接一条 3 像素长的品红(6)直线轨迹（轨迹方向为上/下/左/右之一，从标记像素出发远离模板方向延伸）。精灵的红(2)标记像素与品红(6)轨迹不计入精灵本身。生成约束：恰好 3 个精灵的尺寸（包围盒宽 x 高）与其射线瞄准的空腔匹配，1 个精灵不匹配。每个空腔最多被一个精灵瞄准。

**规则**：
1. 识别蓝(1)模板框架及其矩形空腔。
2. 对每个精灵，找到其红(2)标记像素和品红(6)轨迹。
3. 从轨迹到标记的方向即为"瞄准方向"（轨迹从标记延伸远离模板，因此从轨迹末端指向标记的方向指向模板）。
4. 从标记像素沿瞄准方向射出一条射线，穿过黑(0)背景直到进入蓝(1)框架。射线进入框架后继续前行，遇到的第一个空腔（射线穿过的第一个黑(0)矩形区域属于空腔的一部分）即为该精灵的目标空腔。
5. 检查精灵的包围盒尺寸（宽 x 高）是否与目标空腔尺寸完全一致。
6. 若匹配：将精灵（仅限精灵像素，不含标记和轨迹）放入空腔中（左上角对齐）。擦除原位置的精灵、标记和轨迹（涂为黑(0)）。
7. 若不匹配：擦除该精灵、标记和轨迹（涂为黑(0)），空腔保持空白。
8. 未被任何精灵瞄准的空腔保持空白。

**关键洞察**：轨迹方向同时服务于两个功能——它既标示"精灵来自哪个方向"（视觉线索），也作为射线的瞄准方向精确指定目标空腔。尺寸不匹配时的擦除行为是需要从多个示例对比才能归纳的隐蔽规则（在所有精灵都恰好匹配的示例中不可见）。

## 新题 8：旋转恢复遮挡区后按遮挡总面积阈值擦除大分量

**组合逻辑**：[旋转(rotate) + 半周旋转恢复(half_turn_restores)](已有) → 恢复后改变连通性 → [计数(counting)](创新：计数对象从前景像素变为遮挡块总面积) → [擦除(erase) + 面积超阈值则变色(recolor_above_threshold)](创新：阈值不再固定而等于遮挡块总面积)

**来源原语**：旋转(rotate)/遮挡块(occluder_block)/旋转对称图案(rotational_pattern)/旋转对应(rotational_match)/半周旋转恢复(half_turn_restores) ← ff805c23；重涂色(recolor)/擦除(erase)/连通分量(connected_component)/前景对象(foreground_object)/面积超阈值则变色(recolor_above_threshold)/计数(counting) ← ae58858e

**依赖链**：遮挡块同时扮演双重角色——(1) 它们遮盖了旋转对称图案的一部分，必须通过 180 度旋转恢复被遮内容；(2) 它们的总面积 K 成为后续擦除操作的面积阈值。恢复后的像素可能连接原本断开的分量（改变连通图谱），而阈值取决于遮挡块大小——遮挡越多恢复越多但阈值也越高。这种张力关系是涌现性的：遮挡块的尺寸同时影响"恢复什么"和"删除什么"。

一句话总结：将 180 度旋转对称图案中被蓝色块遮挡的部分恢复原貌后，擦除所有面积大于等于蓝色遮挡块总面积的连通分量。

**输入结构**：约 15x15 的网格，黑(0)背景。网格上有一个由红(2)和绿(3)像素组成的复杂图案，该图案具有 180 度旋转对称性（以网格中心为旋转中心）。图案上叠放 2-3 个蓝(1)实心矩形遮挡块（大小各异，如 2x2、2x3、1x4），遮挡块覆盖了部分图案像素。遮挡块的位置不关于网格中心对称（否则恢复信息缺失）。生成约束：遮挡块的 180 度旋转对应位置处无其他遮挡块（确保被遮内容可通过旋转恢复）；恢复后至少有一个 4-连通分量面积 >= K（K = 所有蓝(1)遮挡块面积之和），至少有一个分量面积 < K。

**规则**：
1. 识别所有蓝(1)矩形遮挡块，计算其总面积 K（所有蓝(1)像素数之和）。
2. 对每个遮挡块，将网格绕中心旋转 180 度，读取旋转后对应位置的像素值。
3. 用旋转对应位置的像素值替换遮挡块位置的蓝(1)像素，恢复被遮部分。
4. 在恢复后的网格上，识别所有 4-连通的非黑前景分量（红(2)和绿(3)像素组成的分量，两种颜色的相邻像素属于同一分量）。
5. 将面积 >= K 的分量完全擦除（涂为黑(0)）。
6. 面积 < K 的分量保持不变。

**关键洞察**：蓝色遮挡块同时编码了两条信息——它们标示了需要通过旋转恢复的区域，同时它们的总面积定义了擦除阈值。增大遮挡面积会恢复更多像素（可能合并分量使其变大）同时也提高阈值（使更多分量"幸存"），两者的竞争效应使结果不可简单推断。

## 新题 9：多米诺描边构建障碍墙约束螺旋路径

**组合逻辑**：[描边(outline) + 尺寸分类(size_classification)](创新：描边结果不作为最终输出而作为另一操作的空间约束) → [螺旋绘制(spiral_draw) + 遇障碍停止(stop_at_blocker)](创新：障碍非预设而由前一步操作动态生成)

**来源原语**：描边(outline)/连通分量(connected_component)/尺寸分类(size_classification)/微型对象描边(micro_obj_outlined) ← b27ca6d3；螺旋绘制(spiral_draw)/种子像素(seed_pixel)/障碍像素(blocker_pixel)/递增步长(increasing_step)/遇障碍停止(stop_at_blocker) ← e5c44e8f；擦除(erase) ← 多题

**依赖链**：尺寸分类区分单像素和双像素对象 → 仅双像素对象（多米诺）获得绿色边框描边 → 绿色边框成为螺旋的障碍 → 螺旋从种子出发遇绿色边框停止。单像素对象不生成边框，螺旋可穿越其位置。这形成了"分类→生成障碍→约束路径"的因果链，且障碍的存在完全取决于分类结果。源题 b27ca6d3 中描边是最终输出，e5c44e8f 中障碍是预设的——这里描边的输出成为另一操作的输入条件，两者建立了全新的上下游关系。

一句话总结：对红色像素中的双连体（多米诺）进行绿色描边，然后从蓝色种子出发绘制螺旋，绿色边框作为障碍阻断螺旋，单红像素不产生阻挡。

**输入结构**：约 17x17 的黑(0)背景网格。网格中有若干红(2)前景对象：部分是单像素（孤立红点），部分是 2 像素的水平或垂直多米诺（4-连通）。红(2)对象总计 6-10 个（其中 3-5 个多米诺，3-5 个单像素）。另有一个蓝(1)单像素作为螺旋种子。红(2)对象和蓝(1)种子之间至少间隔 2 格。无其他颜色的前景像素。生成约束：至少有一个多米诺的描边区域位于螺旋的理论路径上（若无描边则螺旋可到达的区域），使得描边确实影响螺旋的终止点。

**规则**：
1. 识别所有 4-连通红(2)对象并按面积分类：面积 = 1 为单像素，面积 = 2 为多米诺。
2. 对每个多米诺：计算其包围盒，向四周各扩展 1 格（裁剪到网格边界），在扩展后的矩形边缘（周长上的像素）中，将所有黑(0)背景像素涂为绿(3)。已有红(2)像素不被覆盖。
3. 单像素红(2)对象不做任何处理。
4. 从蓝(1)种子出发绘制螺旋：方向序列为上、右、下、左循环，步长序列为 2, 2, 4, 4, 6, 6, ...。
5. 每一步：若目标位置在网格内且为黑(0)背景或红(2)单像素，则涂为蓝(1)（红(2)单像素被蓝(1)覆盖）；若目标位置超出网格则跳过但步数消耗；若目标位置为绿(3)描边像素或红(2)多米诺像素，则螺旋立即终止（不涂该位置）。
6. 绿(3)描边像素、红(2)多米诺像素保持不变。被覆盖的红(2)单像素变为蓝(1)。

**关键洞察**：单像素红点和多米诺在视觉上很相似，但只有多米诺产生绿色"围墙"来阻挡螺旋。求解者必须先发现尺寸分类规则（单 vs 双），再理解描边的产物作为障碍的传递机制，最后计算螺旋路径与障碍的碰撞点。将任一红色单像素误判为多米诺（或反之）都会导致障碍布局错误、螺旋终点不同。

## 新题 10：十字掩模替换改变拓扑后洪泛填充残存封闭区

**组合逻辑**：[重涂色(recolor) + 擦除(erase) + 方框换为十字掩模(square_to_cross_mask)](已有) → 拓扑变化（角像素擦除打通路径） → [填充(fill) + 封闭区域(enclosed_region)](创新：填充的对象是掩模替换后的新拓扑下仍然封闭的区域)

**来源原语**：重涂色(recolor)/擦除(erase)/空心矩形(hollow_rect)/十字图案(cross_pattern)/方框换为十字掩模(square_to_cross_mask) ← 6c434453；填充(fill)/封闭区域(enclosed_region)/内部包含(interior_containment) ← aba27056

**依赖链**：十字掩模替换（角像素删除）→ 改变全局 4-连通拓扑（原本封闭的区域可能经由角缺口与外部连通）→ 洪泛填充仍然封闭的区域。6c434453 中掩模替换是最终操作，aba27056 中填充作用于预设的封闭区域——这里掩模替换的输出改变了哪些区域可供填充，形成了"局部变形→全局拓扑涌现→区域筛选"的链路。一个角像素的有无就可能决定一个区域是否被填充，这种蝴蝶效应使结果高度非直觉。

一句话总结：将由绿色线条和 3x3 空心方框组成的网络中的每个方框替换为十字形（删角留边），然后填充网络中仍然封闭的所有背景区域。

**输入结构**：约 15x15 的黑(0)背景网格。网格上有一个由绿(3)像素组成的网络结构，包括：若干条水平和垂直的绿(3)线段（宽度 1 像素），以及若干个 3x3 空心绿(3)方框（8 个绿(3)像素围绕 1 个黑(0)中心像素）。方框位于线段的交叉点或端点上，方框的边缘像素与线段像素可能共用。网络将背景分割为若干个区域，其中部分区域完全被绿(3)像素 4-连通封闭（区域内的黑(0)像素无法通过 4-连通路径到达网格边缘），部分区域可以通达边缘。3x3 方框总计 3-5 个。生成约束：至少有一个封闭区域在所有方框执行十字掩模替换后仍然保持封闭；至少有一个封闭区域在替换后因角缺口打通而不再封闭。

**规则**：
1. 识别所有 3x3 空心方框：在网格中寻找所有满足"以 (r,c) 为中心的 3x3 区域内，中心为黑(0)、周围 8 个位置全为绿(3)"的位置。
2. 对每个方框执行十字掩模替换：
   - 将 4 个角像素（(r-1,c-1), (r-1,c+1), (r+1,c-1), (r+1,c+1)）涂为黑(0)（擦除），但若该角像素同时也是某条线段的一部分（即该像素的 4-连通绿(3)邻居中有不属于此方框的绿(3)像素），则保留不擦除。
   - 将 4 个边邻像素（(r-1,c), (r,c-1), (r,c+1), (r+1,c)）保持绿(3)。
   - 将中心 (r,c) 涂为红(2)。
3. 所有方框替换完成后，对网格进行 4-连通背景洪泛分析：从网格四条边上的所有黑(0)像素开始 4-连通洪泛，所有可达的黑(0)像素标记为"外部"。
4. 未被标记为"外部"的黑(0)像素即为封闭区域，将其全部涂为黄(4)。
5. 红(2)中心像素、绿(3)线段和保留的方框像素不变。

**关键洞察**：方框角像素的擦除看似是局部操作，但它可能在绿色网络中打开缺口，使原本封闭的背景区域与外部连通。哪些区域在替换后仍然封闭取决于网络的全局拓扑——一个远离方框的区域也可能因为角缺口的级联效应而"泄漏"。求解者必须先执行所有掩模替换，再重新判断封闭性，不能逐个方框独立处理。
