## 新题 1：镜像墙壁塑形对角射线

**组合逻辑**：[镜像](创新：镜像产物不直接画出，而是作为射线的隐形障碍) + [射线延伸](创新：多方向对角射线受隐形墙约束截断) + [碰撞停止] + [重涂色](已有)

**来源原语**：镜像/镜像对称(dc0a314f, 9ecd008a)、射线延伸/对角方向(623ea044, e179c5f4)、碰撞停止(80a900e0)、重涂色(e179c5f4)

**依赖链**：左半区图案经镜像计算出右半区的虚拟墙位置 -> 虚拟墙位置截断从起点像素出发的四条对角射线 -> 射线路径与最终显现的墙像素共同构成输出，重叠处墙色覆盖射线色

从左半区的图案推断右半区的隐形障碍，再由这些障碍塑造起点像素发出的对角射线长度，最终将射线与显现的障碍叠合输出。

**输入结构**：约 15x15 的网格，黑(0)背景。一条灰(5)竖线将网格等分为左右两半（位于正中列，宽 1 像素）。左半区散布若干红(2)像素（3~7 个，4-连通的小块或孤立点，不接触灰线也不接触网格边界）。右半区仅有一个蓝(1)孤立像素，位于右半区中部偏上。生成约束：蓝像素关于灰线的镜像位置不在任何红像素上；左半区图案关于灰线的镜像投射到右半区后，至少有一个镜像红像素恰好落在蓝像素某条对角射线的路径上。

**规则**：
1. 以灰(5)竖线为对称轴，计算左半区每个红(2)像素在右半区的镜像位置，记为"虚拟墙"集合（此时不绘制）。
2. 从蓝(1)像素出发，沿四个对角方向（右上、右下、左上、左下）各发射一条射线。每条射线逐步延伸，每步行进一格对角距离。
3. 射线的每一步检查目标格：若目标格是虚拟墙位置、灰线、或超出网格边界，则该射线在上一步停止（停止格不包含目标格）。若目标格是另一条射线已绘制的像素，继续穿过不停止。
4. 所有射线绘制完毕后，将虚拟墙集合中的每个位置绘制为红(2)。
5. 若某格同时是射线像素和虚拟墙像素，最终颜色为红(2)（墙色覆盖射线色）。
6. 左半区保持原样不变，灰线保持原样不变。四条射线按右上、右下、左上、左下的固定顺序依次绘制（射线之间不互相阻挡）。

**关键洞察**：虚拟墙在输出中才可见，求解者必须先通过镜像推算墙位置，再在脑中模拟射线碰撞，才能得出射线长度——镜像与射线延伸通过"隐形障碍"这一中间产物紧密耦合。

## 新题 2：滑动对齐后逐像素差异裁剪

**组合逻辑**：[滑动对齐](创新：两个精灵体沿不同轴滑动到同一区域) + [逐像素比较](创新：比较对象不是预置面板而是滑动后的重叠区域) + [裁剪](已有) + [差异分类着色](已有)

**来源原语**：滑动对齐/颜色匹配锚点/边缘位置决定轴(581f7754)、逐像素比较/差异分类着色(d47aa2ff)、裁剪(dc0a314f, 5117e062)、标记像素(581f7754, 5117e062)

**依赖链**：锚点边缘位置决定每个精灵体的滑动轴 -> 滑动后两个精灵体的边界框产生重叠区域 -> 重叠区域内逐像素比较产生差异着色图 -> 裁剪出仅包含重叠区域的输出

两个带标记像素的精灵体分别沿锚点指定的轴滑动，在重叠区域做逐像素比较并着色输出。

**输入结构**：约 15x15 的网格，黑(0)背景。网格内部有两个多色精灵体（每个精灵体由 2~3 种非黑非青颜色组成，4-连通，边界框约 4x4~5x5，形状不规则且互不相同）。每个精灵体内部恰好有一个橙(7)标记像素。网格边界上有两个孤立的橙(7)锚点像素（4-邻居均为黑(0)或网格外）：一个位于顶边（非角落），另一个位于右边（非角落）。两个精灵体初始位置互不重叠，且与边界锚点不相邻。生成约束：顶边锚点与一个精灵体的标记像素同列时该精灵体无需滑动，但此情况不会出现——两个锚点分别对应两个精灵体（按如下匹配规则），滑动后两个精灵体的边界框有至少 2x2 的重叠区域。

**规则**：
1. 将两个精灵体分别标记为 A 和 B。精灵体 A 是标记像素距顶边锚点的曼哈顿距离较小者，精灵体 B 是另一个。
2. 精灵体 A 对应顶边锚点：将 A 整体水平滑动，使 A 的标记像素所在列与顶边锚点所在列对齐（行位置不变）。
3. 精灵体 B 对应右边锚点：将 B 整体垂直滑动，使 B 的标记像素所在行与右边锚点所在行对齐（列位置不变）。
4. 计算滑动后 A 和 B 边界框的重叠矩形区域。
5. 在重叠区域内逐像素比较：
   - 若 A 和 B 在该格都有非黑像素且颜色相同：输出该颜色。
   - 若 A 和 B 在该格都有非黑像素但颜色不同：输出黄(4)。
   - 若仅 A 有非黑像素：输出红(2)。
   - 若仅 B 有非黑像素：输出蓝(1)。
   - 若两者在该格均为黑(0)：输出黑(0)。
6. 输出仅为裁剪后的重叠矩形区域。

**关键洞察**：锚点的边缘位置（顶边 vs 右边）分别决定了对应精灵体的滑动轴（水平 vs 垂直），滑动距离取决于标记像素与锚点的列/行差，而最终的比较结果完全由滑动后的重叠几何决定——改变任一锚点位置都会改变重叠区域形状和比较结果。

## 新题 3：唯一频率色定位对角线，对角线筛选目标并描框

**组合逻辑**：[计数/频率唯一性](已有) + [射线延伸/对角方向](创新：对角线不是纯装饰而是空间筛选器) + [描边/框](创新：框不是围绕频率目标本身，而是围绕被对角线穿过的其他像素) + [擦除](已有)

**来源原语**：计数/最低频色定位目标(31aa019c)、射线延伸/对角方向/过像素画双对角线(623ea044)、描边/框(31aa019c)、擦除(e9bb6954, 1a07d186)、忽略干扰项(50846271)

**依赖链**：颜色频率统计定位唯一出现的源像素 -> 源像素决定双对角线的原点和颜色 -> 对角线路径与其他散布像素的交叉判定 -> 被穿过的像素获得红框，未被穿过的像素被擦除

统计颜色频率找出唯一色像素作为对角线原点，对角线穿过的其他像素被描框保留，其余擦除。

**输入结构**：约 12x12 的网格，黑(0)背景。网格中散布 8~14 个非黑孤立像素（彼此不 4-连通），使用 3~4 种颜色。其中恰好一种颜色只出现 1 次（该像素为"源像素"），其余颜色各出现 2 次或更多。生成约束：源像素不在网格边角；从源像素出发的两条完整对角线（左上-右下、右上-左下延伸至网格边界）至少各穿过 1 个其他非黑像素；至少有 1 个非黑像素不在任一对角线上（作为被擦除的干扰项）。

**规则**：
1. 统计每种非黑颜色的出现次数，找到恰好出现 1 次的颜色，该颜色的唯一像素即为源像素。
2. 从源像素出发，沿四个对角方向（左上、右上、左下、右下）各画一条射线延伸至网格边界，射线颜色为源像素的颜色。射线绘制时穿过所有像素（不因碰到非黑像素而停止）。
3. 检查每个非源的非黑像素是否位于这两条对角线上（即是否与源像素的行差绝对值等于列差绝对值）：
   - 若在对角线上：保留该像素原色，并在其周围绘制一个 3x3 红(2)框（框的 8 个外围格填充红(2)，中心保留原像素颜色；若框的某些格超出网格边界，则舍弃超出部分；若框的某格与对角线射线重合，红(2)覆盖射线色）。
   - 若不在对角线上：擦除该像素（置为黑(0)）。
4. 源像素本身保留原色，不描框。
5. 多个被框像素的 3x3 红框若有重叠格，该格仍为红(2)。

**关键洞察**：频率分析决定对角线原点，但对角线的几何路径才是真正的筛选机制——同一批散布像素在不同源像素位置下会产生完全不同的"存活/擦除"分组，需要对比多个示例才能发现"对角线穿过"而非"距离最近"是筛选标准。

## 新题 4：柱高排序重分配后的同色滑动归位

**组合逻辑**：[排序/重分配](已有) + [滑动/同色配对](创新：滑动目标不是原始柱位置而是排序后的新位置) + [碰撞阻挡](创新：重分配改变了碰撞判定的几何条件) + [无匹配色则删除](已有)

**来源原语**：排序/高度排序/重分配/槽位保持颜色(31f7f899)、滑动/同色配对/碰撞阻挡/无匹配色则删除(1a07d186)、柱状条/基线(31f7f899)、满行列条(1a07d186)、孤立像素(1a07d186)

**依赖链**：柱高排序产生新的柱-槽分配方案 -> 槽位颜色不变但柱形互换，改变了每个位置的颜色标签 -> 散布像素按颜色匹配排序后的柱而非排序前的柱 -> 像素滑动方向和距离由排序后的布局决定

先按高度排序重分配柱状条，再让散布像素滑向颜色匹配的（已重新排列的）柱，排序改变了滑动目标位置。

**输入结构**：约 10x18 的网格，黑(0)背景。底部有一行灰(5)基线横贯全宽。基线上方有 4 根垂直柱状条，每根宽 1 像素，高度互不相同（范围 2~7 格），颜色分别为红(2)、蓝(1)、绿(3)、黄(4)，从左到右排列在不同列上，柱间至少隔 2 列。基线下方无内容。在基线上方、柱状条右侧的空白区域中，散布 3~5 个孤立彩色像素，每个像素的颜色为上述四种柱色之一（可重复），且不与任何柱同列。可能有 0~1 个像素的颜色为橙(7)（不匹配任何柱色）。生成约束：各柱高度互不相同；散布像素所在行高度不超过基线上方最高柱的顶端行；每个散布像素向左水平滑动到匹配色柱时路径上无其他柱阻挡（在排序前的布局中如此，但排序后不保证——排序后路径上可能出现新柱阻挡，此时像素停在新柱旁边）。

**规则**：
1. 将四根柱状条按高度从矮到高排序（高度相同时不会发生，已由生成约束保证）。
2. 将排序后的柱形（高度轮廓）依次放入从左到右的四个原始槽位中。每个槽位保持其原始颜色不变——即最左槽始终为红(2)、第二槽为蓝(1)、第三槽为绿(3)、最右槽为黄(4)，但槽内的柱高度变为排序后对应位置的高度。
3. 对每个散布像素，找到与其颜色相同的柱（排序后颜色由槽位决定，位置可能已改变高度但列位置不变）。从该像素出发向左水平滑动（每步左移一列）。
4. 滑动过程中，若下一格是任何柱的像素或基线像素，则停在当前位置（碰撞阻挡）。若滑动到达目标柱的相邻右侧一格，则停在该格。
5. 颜色为橙(7)的像素无匹配柱，直接擦除（置为黑(0)）。
6. 输出为完成排序和滑动后的完整网格。

**关键洞察**：排序只改变柱的高度轮廓而不改变槽位颜色和列位置，但高度变化意味着某些原本"空旷"的行现在有了柱像素阻挡，散布像素的滑动路径因此被截断在不同位置——求解者必须先完成排序才能判断滑动结果。

## 新题 5：反弹路径生成面板模板掩码后填色拼接

**组合逻辑**：[射线延伸/边界反射](创新：反弹路径在受限面板内产生形状各异的掩码) + [填充/色板决定填色](已有) + [拼接](已有)

**来源原语**：射线延伸/反弹路径/边界反射(e179c5f4)、起点像素(e179c5f4)、填充/模板掩码/纯色色板/色板决定填色(15660dd6)、拼接/分栏面板(15660dd6)、行列对应(15660dd6)

**依赖链**：每个面板内的起点像素位置 + 面板尺寸 -> 反弹路径的具体形状（路径即掩码）-> 掩码 + 对应色板颜色 -> 填色后的面板 -> 拼接输出

在分栏面板中，每列面板的模板掩码不是预绘的固定图案，而是由起点像素发出的反弹对角射线在面板边界内反射生成的轨迹。

**输入结构**：约 14x16 的网格。灰(5)行和灰(5)列将网格分为 2 行 x 3 列共 6 个面板，每个面板内部约 4x4（不含边框）。最左列的 2 个面板各填充一种纯色（非灰非黑），分别为红(2)和蓝(1)，作为该行的"行标签色"。在剩余的 2 列 x 2 行 = 4 个面板中：每列恰好有一个面板内部为某种纯色非黑非灰的色板色（如绿(3)或黄(4)），另一个面板内部为黑(0)背景加一个橙(7)起点像素（位于面板内某格）。生成约束：每列的色板面板与起点面板分别在不同行；起点像素不在面板边角；面板内部尺寸至少 4x4 以确保反弹路径有足够空间产生可辨识的形状。

**规则**：
1. 对每个非最左列的面板列，识别色板面板（纯色填充）和起点面板（含橙(7)像素）。
2. 在起点面板中，从橙(7)像素出发，向右上方发射一条对角射线。射线在面板内部边界反射（左右边界反转水平方向，上下边界反转垂直方向），持续前进直到射线回到起点像素或到达面板内某个角格为止。射线经过的所有格（含起点）构成该列的"模板掩码"。
3. 取该列色板面板的纯色作为填充色，取色板面板所在行的行标签色作为边框色。
4. 构造一个输出面板：尺寸与面板内部相同，边框为行标签色（1 像素宽），内部中模板掩码位置填充色板色，非掩码位置填充黑(0)。
5. 将各列生成的输出面板按原列顺序从左到右拼接，面板间用 1 列黑(0)分隔。最左列的行标签面板不出现在输出中。

**关键洞察**：同样的"面板+色板"拼接结构中，模板掩码不是静态绘制的，而是由反弹射线的物理轨迹生成——面板尺寸和起点位置的微小变化会导致截然不同的掩码形状，求解者必须在脑中模拟反弹才能预测掩码。

## 新题 6：行对齐偏移后十字交叉生成与消除

**组合逻辑**：[滑动/边界对齐](创新：行偏移改变了标记像素的绝对列坐标) + [射线延伸/十字图案](创新：十字由行对齐后的标记像素生成，而非固定位置的实心方块) + [交叉点重置背景](已有) + [重涂色](已有)

**来源原语**：滑动/对齐/色段/同行排列/边界对齐(984d8a3e)、射线延伸/十字图案/实心方块/行列对齐/交叉点重置背景(e9bb6954)、重涂色(50846271)、标记像素(50846271)

**依赖链**：色段右边界对齐确定每行的滑动量 -> 滑动改变标记像素的列坐标 -> 新列坐标决定十字图案的水平位置 -> 多个十字的交叉区域被重置为背景色

**输入结构**：约 12x12 的网格，黑(0)背景。网格包含三种颜色：黑(0)为背景、绿(3)为"主色段"色、灰(5)为"侧色"。每行有一段连续的绿(3)色段，色段左侧填充灰(5)，色段右侧填充灰(5)（与 984d8a3e 结构类似但侧色相同）。各行绿色段长度相同，但起始列不同，导致右边界参差不齐。在绿色段中，某些行包含恰好一个红(2)标记像素（替换该位置的绿色），共 2~4 个标记像素分布在不同行。生成约束：标记像素所在行互不相同；对齐后任意两个标记像素不同列（确保十字无完全重合）；对齐后至少有一对标记像素的十字产生交叉（即标记像素 X 的行与标记像素 Y 的列有交点）。

**规则**：
1. 找到所有行中绿(3)色段右边界列的最小值 min_right。
2. 将每行整体水平滑动，使该行的绿色段右边界对齐到 min_right 列。滑动时行内所有像素（含灰色侧边和红色标记）随之平移，超出左边界的像素丢弃，右侧空出的格填充灰(5)。
3. 对齐完成后，找到所有红(2)标记像素的新位置。
4. 从每个红(2)标记像素出发，向上、向下、向左、向右各延伸射线，将射线路径上的所有格（含标记像素本身所在的整行和整列）重涂为红(2)。射线覆盖时：红(2)覆盖绿(3)和灰(5)，但不覆盖黑(0)背景（射线仅在非黑格上绘制，遇黑格跳过继续延伸至行/列末端——即射线是该行/列中所有非黑格的重涂，不是连续线段）。
5. 若两个不同标记像素的十字在某非黑格相交（即该格同时位于标记 X 的行/列和标记 Y 的行/列），将该格重置为绿(3)（原始主色段色），而非红色。
6. 黑(0)背景格始终不变。

**关键洞察**：行滑动改变了标记像素的绝对列位置，从而改变了十字图案的几何布局和交叉位置。同一组标记像素在不同的滑动量下会产生不同的交叉模式——求解者必须先完成对齐计算才能确定哪些格被重置。

## 新题 7：轨迹终点定位条件性对称修复或互换

**组合逻辑**：[沿路径移动](创新：路径终点不是移动目的地，而是目标区域的坐标指针) + [对称补全](创新：补全不总是发生，取决于路径终点是否指向缺失区域) + [镜像](已有) + [条件分支：修复 vs 互换]（创新组合）

**来源原语**：沿路径移动/轨迹路径/标记像素(c9680e90)、对称补全/缺失区域/镜像/镜像补缺并裁出(9ecd008a)、分隔行(c9680e90)、裁剪(9ecd008a)

**依赖链**：源像素沿轨迹移动到终点 -> 终点坐标映射到上方网格中的某个区块 -> 判断该区块是否为缺失区域 -> 若是：镜像补全缺失区域 -> 若否：将该区块内容与镜像补全后的缺失区域内容互换

**输入结构**：约 14x14 的网格。上方区域（约 8 行）包含一个左右镜像对称的彩色图案（使用红(2)、蓝(1)、绿(3)等颜色，黑(0)背景），但其中恰好有一个 3x3 的纯黑(0)缺失区域打破了对称性。该缺失区域的镜像对应位置是完整的彩色区块。上方区域可以被划分为若干个不重叠的 3x3 区块（网格尺寸保证这一点）。一行品红(6)分隔行横贯全宽。下方区域（约 5 行）包含：一个橙(7)源像素和一条由黄(4)像素组成的 4-连通轨迹与源像素相连。轨迹是无分叉的单路径，终点为轨迹的非源端。生成约束：将终点的列坐标和行坐标分别对 3 取模后映射到上方区域的某个 3x3 区块（列坐标 / 3 = 区块列索引，终点行坐标在下方区域中的相对行 = 区块行索引），该映射始终指向一个有效的 3x3 区块。不同示例中，终点有时指向缺失区域本身，有时指向其他非缺失区块。

**规则**：
1. 在下方区域中，从橙(7)源像素出发，沿黄(4)轨迹 4-连通逐步行走至轨迹终点（轨迹中离源像素最远的端点）。
2. 计算终点在下方区域中的相对位置：rel_row = 终点行 - 分隔行行号 - 1，rel_col = 终点列。
3. 将 rel_row 和 rel_col 映射到上方区域的 3x3 区块索引：block_row = rel_row，block_col = rel_col / 3（整数除法）。定位到上方区域的目标 3x3 区块。
4. 通过左右镜像找到缺失区域的修复内容：对缺失区域中的每个格 (r, c)，从镜像列 (r, W-1-c)（W 为上方区域宽度）复制颜色，得到修复补丁 P。
5. 条件判断：
   - 若目标区块就是缺失区域（3x3 全黑）：将修复补丁 P 填入缺失区域，上方区域其余部分不变。
   - 若目标区块不是缺失区域：将目标区块的当前内容 Q 复制到缺失区域位置，将修复补丁 P 复制到目标区块位置（即互换：缺失处填 Q，目标处填 P）。
6. 输出仅为修改后的上方区域（不含分隔行和下方区域）。

**关键洞察**：轨迹的几何形状编码了一个"地址"，指向上方网格中的某个区块。求解者不仅要完成镜像修复，还要判断轨迹指向的是不是缺失区域本身——这个条件分支只有对比多个示例（有的指向缺失区域，有的不指向）才能归纳出来。

4. 对每个选中精灵体，裁剪其最小边界框（仅含精灵体像素，不含标记像素；边界框内精灵体像素保留原色，非精灵体格为黑(0)）。

**关键洞察**：青色标记同时承担"选择"和"排除"双重角色——它选中精灵体参与排序，但自身不计入面积，也不出现在输出中。求解者必须先通过标记筛选，再数面积排序，最后拼装——三步之间任一步的结果都影响最终输出。

1. 将 2x2 色块中的四个像素展开到网格四角（如 66e6c45b）：左上像素色 -> 网格左上角格，右上像素色 -> 网格右上角格，左下像素色 -> 网格左下角格，右下像素色 -> 网格右下角格。原 2x2 色块位置恢复为棋盘格背景色。

5. 菱形轮廓、棋盘格未被射线覆盖的部分、以及角落像素本身均保持不变。

**关键洞察**：展开操作和射线发射形成因果链——2x2 块的位置决定四种颜色分配到哪个角落，进而决定每条射线的颜色，而射线的互相阻挡（先绘制的可能截断后绘制的）使得 2x2 块内部的颜色排列影响最终图案的对称性。需要对比多个示例才能确认射线绘制顺序和阻挡规则。

## 新题 10：面板比较差异区域的循环层深填色

**组合逻辑**：[逐像素比较/差异分类着色](创新：比较不是最终输出而是中间步骤，产生差异区域掩码) + [循环填充/层深度递增](创新：填充的区域由差异比较决定而非预定义的对角带) + [调色板行](已有) + [裁剪](已有)

**来源原语**：逐像素比较/面板/分隔列/面板对齐/差异分类着色(d47aa2ff)、循环填充/层深度递增/调色板行/层深模色板取色(b457fec5)、裁剪(dc0a314f)、重涂色(b457fec5)

**依赖链**：左右面板逐像素比较产生差异掩码（三类：共有、仅左、仅右）-> 每类差异区域作为独立的填充目标 -> 从各区域的重心出发计算层深 -> 用调色板行循环填色

比较两个面板的差异，将差异区域按类别分组，每组按距离组重心的层深做循环调色板填色。

**输入结构**：约 10x21 的网格。一列栗(9)分隔列将网格分为等宽的左面板和右面板（各约 10x10）。两个面板各包含若干非黑前景像素（使用红(2)、蓝(1)、绿(3)等颜色），在黑(0)背景上形成图案。两面板的图案有部分重叠、部分差异（即某些位置两面板颜色相同，某些位置仅一侧有前景色）。网格最底行为一行调色板像素：从左到右依次为 2~4 种不同颜色（如橙(7)、黄(4)、品红(6)），剩余格为黑(0)。生成约束：仅出现在左面板的前景像素集合构成一个 4-连通区域；仅出现在右面板的前景像素集合也构成一个 4-连通区域（两个差异区域各自连通但互相不连通）；调色板颜色不包含面板中使用的前景色或栗(9)。

**规则**：
1. 移除分隔列，将左右面板按单元格位置对齐比较（第 i 行第 j 列 vs 第 i 行第 j 列）。
2. 分类每个单元格：
   - 类型 S（共有）：两面板在该位置都有非黑像素且颜色相同。
   - 类型 L（仅左）：仅左面板有非黑像素。
   - 类型 R（仅右）：仅右面板有非黑像素。
   - 类型 O（两面板均为黑(0)）：忽略。
3. 对类型 S 的格保留原色不变。
4. 对类型 L 的连通区域：计算该区域所有格坐标的算术平均值作为重心 (cr, cc)（四舍五入到最近整数）。对区域中每个格 (r, c)，层深 d = max(|r - cr|, |c - cc|)。将该格重涂为调色板中第 (d mod 调色板长度) 个颜色（调色板从索引 0 开始，按最底行从左到右的非黑像素顺序排列）。
5. 对类型 R 的连通区域：同样计算重心和层深，同样使用调色板循环填色，但调色板的起始偏移为 1（即该格颜色为调色板第 ((d + 1) mod 调色板长度) 个颜色）。
6. 输出为一个与单面板等大的网格（10x10），包含处理后的 S、L、R 类型格，O 类型格为黑(0)。最底行调色板不出现在输出中。

**关键洞察**：像素比较不是终点而是起点——它产生的差异区域成为循环填色的画布。"仅左"和"仅右"区域使用相同调色板但起始偏移不同，求解者必须对比多个示例才能发现偏移差异，而非简单地认为两类区域用同一套规则。
