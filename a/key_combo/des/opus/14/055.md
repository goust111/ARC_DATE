## 新题 1：边框色定向重力滑移与障碍阻挡

**组合逻辑**：[平移/translate](创新：从单步移动扩展为全程滑移至阻塞) + [填充/fill](堆叠结果) ← [颜色匹配边/color_match_side](决定方向) ← [障碍精灵体](路径约束)

**来源原语**：平移、颜色匹配边、朝匹配边移动（5034a0b5）；障碍精灵体、像素数守恒、边界贴合（88bcf3b4）；边框边、内部像素（5034a0b5）

**依赖链**：边框边颜色决定每个内部像素的滑移方向（无边框则方向不确定）；障碍像素阻断滑移路径并产生堆叠（无障碍则退化为简单贴边）；处理顺序解决多像素同向滑移时的目标冲突（无顺序则结果歧义）

四种颜色的边框边同时定义四个方向的重力场，内部像素按颜色匹配滑向对应边框，灰色障碍像素阻挡路径产生堆叠。

**输入结构**：约 12x12 网格。最外圈为一像素厚的边框：四条边各为不同纯色——顶边红(2)、底边蓝(1)、左边黄(4)、右边绿(3)，四个角像素为黑(0)。边框内部大部分为黑(0)背景，散布 6~10 个单像素，每个像素颜色为红(2)、蓝(1)、黄(4)或绿(3)中的一种。另有 2~3 个灰(5)单像素作为障碍。生成约束：不同内部像素初始不重叠；灰(5)像素不与任何边框边同色。

**规则**：
1. 灰(5)像素为障碍，始终不移动。
2. 每个非灰、非黑内部像素识别与自身同色的边框边，确定滑移方向：红(2)向上、蓝(1)向下、黄(4)向左、绿(3)向右。
3. 按像素到目标边框边的曼哈顿距离升序处理（最近者优先）；距离相同时按从左到右、从上到下的位置顺序处理。
4. 每个像素沿确定方向直线滑移，遇到边框边、已定位的其他像素或灰(5)障碍时停在紧邻前一格。
5. 边框本身不变。

**关键洞察**：四个重力方向在同一网格中共存，处理顺序防止碰撞歧义，而灰色障碍将简单贴边问题变为带约束的堆叠问题——需要对比多个示例才能归纳出处理顺序规则。

## 新题 2：网格缺失交叉点裁剪后印章到标记槽位

**组合逻辑**：[裁剪/crop](由缺失交叉点定界) → [印章覆盖/stamp](裁剪结果作为模板) ← [标记像素](选择目标槽位)

**来源原语**：裁剪、网格线、缺失交叉点、四角围合、背景色空洞（a644e277）；印章覆盖、槽位、分隔列、标记像素、标记选槽接收精灵（363442ee）

**依赖链**：缺失交叉点确定裁剪范围（无法跳过裁剪直接印章，因为模板不是预给的）；裁剪产出的子图成为印章模板（裁剪目标与印章来源耦合）；标记像素选择目标槽位（无标记则不知道印在哪）

在网格结构中通过缺失交叉点定位并裁剪出一个子区域，将裁剪结果作为印章模板，印到右侧面板中被标记像素选中的槽位里。

**输入结构**：约 20x15 网格。左半部分：由橙(7)色线条组成的规则网格（水平线和垂直线，间距约 3 个像素），网格单元内散布少量彩色像素（红(2)、蓝(1)等，各单元内容不同）。恰好四个网格线交叉点被替换为黑(0)背景色，这四个缺失点构成一个轴对齐矩形的四角。右半部分（以灰(5)分隔列隔开）：一列等大槽位，每个槽位尺寸与四角围合的裁剪区域相同。部分槽位中心有一个红(2)标记像素，其余槽位为纯黑(0)。生成约束：四个缺失交叉点构成的矩形至少包含两个完整网格单元；标记槽位至少 1 个、至多 4 个。

**规则**：
1. 在左侧网格中找到四个黑(0)色的缺失交叉点（它们本应是橙(7)色）。
2. 以这四个点为角，做包含性裁剪（含边界上的网格线），得到一个子图作为印章模板。
3. 在右侧面板中，找到中心含有红(2)标记像素的槽位。
4. 将裁剪模板逐像素覆盖到每个被标记的槽位中（模板完全替换槽位原有内容）。未被标记的槽位、分隔列、左侧网格均保持不变。

**关键洞察**：印章模板不是直接给出的，而是通过网格缺失交叉点的结构性信号间接定义的——求解者必须先识别缺失模式完成裁剪，才能获得印章内容。

## 新题 3：镜像异或检测不对称像素并按半区着色

**组合逻辑**：[镜像/reflect](生成参照) → [异或/xor](检测不对称) → [重涂色/recolor](按空间位置分色)

**来源原语**：镜像、阵列排布（8d5021e8）；异或、掩码、逐像素异或输出（3428a4f5）；重涂色、按原色区分涂色（bcb3040b）；面积排名（a8d7556c——此处改为位置判断）

**依赖链**：镜像产生参照副本（无镜像则无法执行异或比较）；异或揭示原图与镜像的差异像素（无异或则不知道哪些像素不对称）；半区着色依赖异或结果的空间位置（无位置判断则不知道涂什么色）

将一个近似左右对称的精灵体自我镜像后做异或，找出不对称像素，然后根据不对称像素在对称轴左侧还是右侧分别着不同颜色。

**输入结构**：约 10x10 网格，黑(0)背景。一个红(2)色单连通精灵体（约 12~20 像素），关于其包围盒的垂直中轴线近似对称，但有 1~3 个像素打破对称（某些位置多出或缺少像素）。无其他前景色。生成约束：不对称像素在左侧和右侧均有分布（不全在一侧）；精灵体包围盒宽度为奇数（确保中轴线落在像素中心上）。

**规则**：
1. 计算红(2)精灵体的包围盒，确定垂直中轴线。
2. 将精灵体关于中轴线做左右镜像，生成一个虚拟的镜像副本（仅用于比较，不画在输出中）。
3. 逐像素异或原图与镜像：原图有色而镜像无色的像素，以及原图无色而镜像有色的像素，均为"不对称像素"。
4. 对称像素（原图和镜像都有色）保持红(2)不变。
5. 不对称像素中，位于中轴线左侧（含轴线上）的涂绿(3)，位于右侧的涂蓝(1)。
6. 背景保持黑(0)。

**关键洞察**：镜像不是输出操作而是一种分析工具——它生成参照以暴露原图的不对称结构；异或的结果不直接输出，而是驱动后续的空间着色决策。需要对比多个示例才能归纳出左/右对应绿/蓝的映射。

## 新题 4：双维外推——位移轨迹与层色循环

**组合逻辑**：[外推/extrapolate](空间位移延续) + [重涂色/recolor](层色循环移位) ← [同心方框层](承载双维变化的对象)

**来源原语**：外推、帧序列、内部精灵、等间距排列、匀速运动延续（ba1aa698）；重涂色、同心方框层、深度排序、层色序内外翻转（85c4e7cd）

**依赖链**：帧间位移差确定空间外推方向和步长（无位移分析则位置错误）；帧间层色变化确定颜色循环规律（无颜色分析则着色错误）；两条规律独立但必须同时正确才能得到正确输出（缺任一维则答案错）

从三帧共边面板中，一个移动的同心环图案既在空间上匀速平移，又在层颜色上逐帧循环移位，需同时外推出第四帧的位置和颜色。

**输入结构**：约 25x8 网格，包含三个共享垂直边界列的等宽面板（每面板约 8x8），面板填充色为黑(0)，边框色为灰(5)。每个面板内有一个 5x5 的三层同心矩形环图案（外环一像素厚、中环一像素厚、核心一像素），使用三种颜色（红(2)、蓝(1)、绿(3)）。面板 1 到面板 3 之间，环图案的中心位置按固定行列偏移量 (dr, dc) 移动（dr 和 dc 各为 -1、0 或 +1 中的一个）。同时，三层的颜色分配逐帧循环移位一位（例如面板 1：外=红、中=蓝、核=绿；面板 2：外=绿、中=红、核=蓝；面板 3：外=蓝、中=绿、核=红）。生成约束：三帧中环图案不越出面板边界；dr 和 dc 不同时为 0。

**规则**：
1. 识别三个面板及各面板内的同心环图案。
2. 计算相邻面板间环中心的行偏移 dr 和列偏移 dc（恒定值）。
3. 计算相邻面板间层颜色的循环移位方向和步长（恒定值，每帧移位 1 位）。
4. 输出一个独立面板（与输入面板同尺寸，同框架颜色），环图案中心位置在面板 3 的基础上再平移 (dr, dc)，三层颜色在面板 3 的基础上再循环移位 1 位。
5. 由于输出是独立面板而非共边面板，列方向上的偏移量按完整面板宽度计算而非共边间距。

**关键洞察**：外推包含两个独立维度——空间位移（线性）和颜色分配（循环）——仅从单个示例对无法同时确定两条规律，必须对比三帧才能分别归纳。

## 新题 5：计数驱动同心环生成与位置编码着色

**组合逻辑**：[计数/counting](确定环层数) + [填充/fill](生成同心环) ← [排序/sort](确定层色顺序) ← [忽略干扰项](过滤无效对象)

**来源原语**：计数、正方形块、忽略干扰项、干扰体（1fad071e）；填充、同心方框层、深度排序（85c4e7cd）；排序（f18ec8cc）；忽略非正方形（b1986d4b）

**依赖链**：计数结果决定同心环层数（无计数则不知道画几层）；排序结果决定各层颜色（无排序则颜色分配歧义）；干扰过滤保证计数正确（无过滤则计数偏差，后续全错）

统计网格中有效的 2x2 单色正方形个数 N，生成 N 层同心矩形环，各层颜色由正方形的空间位置排序决定。

**输入结构**：约 15x15 网格，黑(0)背景。散布 2~5 个实心 2x2 单色正方形，每个颜色不同（从红(2)、蓝(1)、绿(3)、黄(4)、橙(7)中选取）。另有若干单像素干扰点（颜色可能与正方形相同或不同）和 1~2 个 2x2 红(2)正方形作为非目标干扰（仅当目标色不含红时出现）。网格右下角有一个 1x1 灰(5)像素作为锚点。生成约束：有效正方形之间互不相邻（8-连通不接触）；灰(5)锚点不与任何正方形重叠；有效正方形数 N 满足 2 <= N <= 5。注：只有颜色各不相同的 2x2 正方形计入有效计数，颜色与任何已计入正方形重复的 2x2 正方形视为干扰。

**规则**：
1. 扫描所有 2x2 窗口，找到全部纯色 2x2 正方形。忽略单像素干扰和颜色重复的正方形（仅保留每种颜色的第一个，按从上到下、从左到右扫描序）。
2. 统计有效正方形个数 N。
3. 按有效正方形的左上角坐标排序：先按行从上到下，行相同按列从左到右。
4. 以灰(5)锚点为中心，生成 N 层同心矩形环（最外层尺寸为 (2N-1) x (2N-1)，每层向内收缩一像素）。最外层涂排序中第一个正方形的颜色，次外层涂第二个，依此类推，最内层（中心像素）涂最后一个。
5. 清除原有的所有正方形和干扰点，仅保留生成的同心环。灰(5)锚点被同心环中心覆盖。

**关键洞察**：计数不仅产生一个数字（环层数），还通过排序产生一个有序颜色序列（环层色）——两者缺一不可；需要对比多个示例才能归纳出排序依据是空间位置而非颜色本身。

## 新题 6：按面积排名配对精灵体与空心框架后拉伸填充

**组合逻辑**：[排序/sort](面积排名产生配对) → [拉伸/stretch](精灵体映射到框架内部) ← [面积排名/area_ranking](双重排序：框架按内面积、精灵按像素数)

**来源原语**：拉伸、精灵体、空心矩形、包围盒映射、线段连接再填充（465b7d93）；排序、面积排名（a8d7556c / a87f7484）；前景最多者选出（a87f7484——此处扩展为全排名而非仅选最大）

**依赖链**：双重排序产生精灵-框架配对（无排序则配对方式未知，单示例下多种配对都合理）；拉伸操作依赖配对关系确定目标框架（无配对则无法确定拉伸目标）；拉伸方法（线段连接 + 填充）需要精灵形态信息（无精灵则无拉伸内容）

多个精灵体按像素数排序，多个嵌套空心框架按内面积排序，按排名一一配对后将各精灵体拉伸填充到对应框架内部。

**输入结构**：约 18x18 网格，黑(0)背景。3 个不同颜色的一像素厚空心矩形框架（灰(5)、橙(7)、青(8)），它们同心嵌套但不相邻（框架之间有至少 2 像素间隔）。3 个小型精灵体（各 3~6 像素，4-连通，颜色分别为红(2)、蓝(1)、绿(3)）位于所有框架的外侧，互不重叠。生成约束：三个框架的内面积两两不同；三个精灵体的像素数两两不同；精灵体不接触任何框架。

**规则**：
1. 按内部面积从小到大排列三个框架，得到排名 1（最小）、2、3（最大）。
2. 按前景像素数从少到多排列三个精灵体，得到排名 1（最少）、2、3（最多）。
3. 同排名配对：排名 1 的精灵体映射到排名 1 的框架，以此类推。
4. 对每对：将精灵体包围盒的四角映射到对应框架内部区域的四角（左上对左上、右下对右下）。在映射后的位置之间画水平或垂直线段连接相邻精灵体像素的映射点，然后对线段围成的封闭区域做洪泛填充，颜色为精灵体颜色。
5. 清除原始精灵体（框架外的位置恢复为黑色）。框架本身保持不变。

**关键洞察**：配对规则基于双重排名（精灵像素数 vs. 框架内面积），不是由颜色或空间邻近性决定的——从单个示例无法排除其他配对假设，必须对比多个示例才能确认排名配对规则。

## 新题 7：三标记点定矩形后按标记分布做半区双色描边

**组合逻辑**：[补全/complete](三点定矩形框) + [描边/border_drawing](绘制边框) + [重涂色/recolor](半区分色) ← [标记像素分布](编码分色规则)

**来源原语**：补全、标记像素、空心矩形、包围盒、三点定矩形框（e7639916）；描边、边框、半区分色、排序（1bfc4729）

**依赖链**：三个标记点确定矩形几何（无标记则无框可画）；标记在矩形边上的分布（2+1）确定分色轴和颜色归属（无分布分析则分色歧义）；描边和分色必须同时完成（先画再分色则等效，但分色规则依赖标记位置，不可独立确定）

三个标记像素确定矩形框的边界，其中两个标记在同一边、一个在另一边，这种 2-vs-1 分布决定矩形框的双色分割方式。

**输入结构**：约 12x12 网格，黑(0)背景。恰好三个红(2)色标记像素，它们位于其共同包围盒的边界上。其中两个标记位于包围盒的同一条边（均在顶边、均在底边、均在左边或均在右边），第三个标记位于对边（若两个在顶边，第三个在底边；若两个在左边，第三个在右边）。生成约束：包围盒至少 4x4；三个标记不共线；两个同边标记不在角点上（确保可区分边归属）。

**规则**：
1. 计算三个红(2)标记像素的包围盒。
2. 识别"双标记边"（含 2 个标记的那条边）和"单标记边"（含 1 个标记的对边）。
3. 确定分割轴：若双标记边和单标记边是水平边（顶/底），则沿包围盒的水平中线上下分割；若为垂直边（左/右），则沿垂直中线左右分割。
4. 绘制包围盒的完整矩形边框。包含双标记边的那一半边框涂绿(3)，包含单标记边的那一半边框涂蓝(1)。分割线上的像素归入双标记边一侧。
5. 恢复三个原始红(2)标记像素（覆盖在边框之上）。

**关键洞察**：标记像素承担双重功能——既定义矩形几何（包围盒），又通过 2-vs-1 的非对称分布编码边框的颜色分割规则。仅看一个示例可能无法区分"按标记数分色"和"按方位固定分色"，需要多个示例确认。

## 新题 8：掩码异或产出平铺种子后交替镜像铺满画布

**组合逻辑**：[异或/xor](计算种子图案) → [平铺/tile] + [镜像/reflect](交替翻转铺满) ← [分隔行](分离两个掩码) + [分隔列](分离掩码区与画布区)

**来源原语**：异或、掩码、分隔行、对齐、逐像素异或输出（3428a4f5）；平铺、镜像、精灵体、阵列排布、交替翻转平铺（8d5021e8）

**依赖链**：异或产出种子图案（种子不在输入中直接给出，无异或则无法获取）；种子的非对称性使得交替镜像铺展产生丰富图案（若种子对称则镜像无效果，这是涌现性质）；画布尺寸与种子尺寸的整数比确定铺展维度（两者耦合）

对两个分隔行隔开的二值掩码做逐像素异或，将结果作为种子，用交替镜像方式平铺到右侧画布中。

**输入结构**：约 15x20 网格。左侧区域（约占网格宽度 1/3，以灰(5)分隔列与右侧隔开）内，由一条黄(4)分隔行上下隔开两个等大的二值掩码（每个约 4x4），掩码用红(2)表示"活跃"、黑(0)表示"非活跃"。右侧区域为纯黑(0)画布，高度为掩码高度的 3 倍，宽度为掩码宽度的 2 倍。生成约束：两个掩码不完全相同（异或结果非全黑）；异或结果非对称（至少一个轴不对称），确保镜像铺展产生可观察的变化。

**规则**：
1. 找到黄(4)分隔行，将其上方和下方的红/黑掩码分别提取。
2. 逐像素异或：两个掩码在对应位置不同则输出绿(3)，相同则输出黑(0)。得到一个绿/黑种子图案。
3. 将种子作为基础瓦片，按 3 行 x 2 列的方式交替镜像铺满右侧画布：与相邻瓦片共享边的方向做翻转（水平相邻则左右翻转，垂直相邻则上下翻转）。
4. 左侧区域（掩码、分隔行、分隔列）保持不变。

**关键洞察**：种子图案是隐式的——不在输入中直接出现，而是两个掩码的异或结果；异或天然产生非对称图案，使得交替镜像铺展产生复杂的对称结构，这种视觉复杂性是两步耦合的涌现效果。

## 新题 9：按前景密度排序精灵条带并按时钟指针旋转

**组合逻辑**：[排序/sort](前景密度排名决定输出位置) + [旋转/rotate](时钟指针编码旋转角度) ← [计数/counting](前景像素计数驱动排序) ← [精灵体 + 标记像素](独立编码两种信息)

**来源原语**：裁剪、精灵体、面积排名、前景最多者选出（a87f7484）；旋转、时钟指针编码角度（a32d8b75）；排序、色块条带、整块移动保持内容（f18ec8cc）；计数（1fad071e）

**依赖链**：前景像素计数产生排序键（无计数则排序依据不明）；排序改变精灵体输出顺序（无排序则位置错误）；时钟指针独立编码旋转角度（无时钟指针则旋转角度不确定）；排序和旋转作用于同一组精灵体但基于不同信息源（两者独立但必须同时正确）

一条精灵体条带中的各瓦片按前景像素数排序后重排，同时每个瓦片按其配对的时钟指针标记旋转。

**输入结构**：约 9xN 网格（N 为 3 的倍数，约 12~18），由两行 3x3 瓦片组成。下行：3~6 个 3x3 瓦片水平排列，每个瓦片含一个非黑单色精灵体图案（颜色互不相同，从红(2)、蓝(1)、绿(3)、黄(4)、橙(7)中选取），前景像素数各不相同（范围 2~7）。上行：与下行一一对应的 3x3 时钟指针单元，每个单元中心为品红(6)像素，中心的上/右/下/左四个邻位中恰好一个也是品红(6)，指示旋转方向（上=0度、右=90度顺时针、下=180度、左=270度顺时针）。生成约束：各瓦片前景像素数两两不同。

**规则**：
1. 解析每对（精灵体瓦片，时钟指针单元），从左到右配对。
2. 按精灵体瓦片中非黑像素数从多到少降序排列（最密优先）。像素数相同时（本题生成约束排除此情况）按原始位置从左到右。
3. 对每个精灵体瓦片，按其配对时钟指针编码的角度做顺时针旋转。
4. 输出：仅一行 3x3 瓦片，按降序排列后的顺序水平排列，每个瓦片已旋转。不输出时钟指针行。

**关键洞察**：排序依据（前景像素数）和变换参数（旋转角度）由两个独立信息源编码（瓦片自身 vs. 配对时钟指针），仅做排序不旋转或仅做旋转不排序都不能得到正确输出——需对比多个示例分离这两种独立规则。

## 新题 10：绕障碍绘制标记点连线并按穿越像素原色着色

**组合逻辑**：[连线/draw_line](两标记点间路径) + [绕障重绘/reroute_around_obstacle](遇障碍绕行) + [重涂色/recolor](按路径像素原色分色) ← [边界贴合](绕行轨迹约束) + [按原色区分涂色](着色条件)

**来源原语**：连线、标记像素、线段、两点直线路径、按原色区分涂色（bcb3040b）；绕障重绘、障碍精灵体、边界贴合、像素数守恒（88bcf3b4）

**依赖链**：两个标记点确定连线意图（无标记则无线可画）；障碍精灵体阻断直线路径，迫使绕行（无障碍则退化为直线连线原题）；绕行路径上的像素按原色着色（路径形状和着色规则交织——路径改变则着色位置改变，着色规则需要知道绕行前每个像素的原始颜色）

两个标记点之间的连线路径遇到障碍精灵体时沿其边界绕行，路径上原为前景色的像素变一种颜色、原为背景色的像素变另一种颜色。

**输入结构**：约 14x14 网格，黑(0)背景，散布若干蓝(1)前景像素（无规则图案，覆盖约 15~25% 面积）。两个红(2)标记像素位于同一行、同一列或同一 45 度对角线上。一个由灰(5)像素组成的 4-连通小型障碍精灵体（3~5 像素）位于两标记点之间的直线路径上。生成约束：障碍完全阻断直线路径（不能从障碍像素之间穿过）；绕行后路径不超出网格边界；两标记点距离至少 6 个像素。

**规则**：
1. 找到两个红(2)标记像素，确定它们之间的直线方向（水平/垂直/对角）。
2. 从一个标记向另一个标记逐步行走。在未遇到障碍时，沿直线方向前进。
3. 当下一步将进入灰(5)障碍像素时，开始绕行：沿障碍边界的顺时针方向行走（贴合障碍外侧），直到重新回到原直线路径的延长线上且前方无障碍，然后恢复直线行走。
4. 对整条路径（含直线段和绕行段，不含两个标记像素本身）上的每个像素着色：原为蓝(1)的像素变绿(3)；原为黑(0)的像素变红(2)。
5. 灰(5)障碍本身不变。两个标记像素保持红(2)。

**关键洞察**：路径计算和颜色映射必须联合完成——绕行改变了路径形状，而着色规则取决于绕行路径下方的原始像素颜色，两者无法独立求解；顺时针绕行规则需要对比多个示例（障碍在路径不同侧的情况）才能归纳。
