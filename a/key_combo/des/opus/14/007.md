## 新题 1：奇偶相位棋盘填充

**组合逻辑**：[填充](创新：由奇偶相位控制填充位置而非全部填充) + [坐标奇偶匹配](创新：标记像素不再涂满同奇偶背景，而是仅在框架内生效) + [空心矩形](已有) + [标记像素](已有)

**来源原语**：填充/fill(参考题 00dbd492, 868de0fa)、坐标奇偶匹配/coord_parity_match(参考题 d492a647)、空心矩形/hollow_rect(参考题 00dbd492)、标记像素/marker_pixel(参考题 d492a647)

**依赖链**：空心矩形框定义填充的空间边界 → 框内标记像素同时编码填充颜色和奇偶相位 → 奇偶相位决定框内哪些像素被填充、哪些保持黑色。三者缺一不可：无框则无填充边界，无标记则无颜色和相位信息，无奇偶规则则退化为实心填充。

在每个空心矩形框内，根据内部标记像素的绝对坐标奇偶性，将框内部分像素填充为标记颜色，形成棋盘格图案。

**输入结构**：约 15x15 的黑(0)背景网格。网格中散布 3-5 个一像素厚的蓝(1)空心矩形框，尺寸各异（内部宽高范围 3-7 像素），框与框之间互不重叠且不相邻。每个框的内部恰好有一个非蓝非黑的单独彩色像素（即标记像素），颜色在红(2)、绿(3)、黄(4)、品红(6)等中各不相同。标记像素的位置在框内部不固定——不同框中标记可能在不同的相对位置。生成约束：每个框的内部至少 3x3，确保棋盘效果可见；各框的标记像素颜色互不相同。

**规则**：
1. 对每个蓝(1)空心矩形框，定位其内部唯一的标记像素，记其颜色为 C、绝对坐标为 (r, c)。
2. 计算该标记像素的坐标奇偶相位：row_parity = r mod 2，col_parity = c mod 2。
3. 遍历该框内部所有黑(0)像素，对位于 (ri, ci) 的像素：若 (ri mod 2) == row_parity 且 (ci mod 2) == col_parity，则将该像素填充为颜色 C；否则保持黑(0)。
4. 标记像素本身保持不变（它已经是颜色 C，且自然满足自身的奇偶条件）。
5. 蓝(1)边框像素保持不变。框外区域保持黑(0)。

**关键洞察**：标记像素的绝对坐标同时编码了三种信息——填充颜色、行奇偶相位、列奇偶相位。同一个框内，将标记像素平移一格就会产生完全不同的棋盘相位，因此必须对比多个示例才能确认相位来源于标记的绝对坐标而非相对位置。

## 新题 2：对称修复驱动的印章模板

**组合逻辑**：[对称补全](已有) + [裁剪](已有) + [印章覆盖](创新：模板不是预先给定的，而是通过对称修复动态生成) + [分隔行](已有) + [锚点像素](已有)

**来源原语**：对称补全/symmetry_completion(参考题 981571dc)、裁剪/crop(参考题 6b9890af, da6e95e5)、印章覆盖/stamp(参考题 a9f96cdd, b4a43f3b)、分隔行/separator_row(参考题 b4a43f3b)、锚点像素/anchor_pixel(参考题 a9f96cdd)、镜像对应/mirror_correspondence(参考题 981571dc)、推断对称轴/infer_symmetry_axes(参考题 981571dc)

**依赖链**：上半区的残缺图案通过对称轴推断 → 镜像对应修复缺失像素 → 修复后的完整图案裁剪为印章模板 → 模板被印在下半区的每个锚点位置。对称修复的结果直接决定印章内容，跳过修复则模板不完整、输出错误。

将上半区一个有像素缺失的双轴对称图案修复完整后，作为印章模板，粘贴到下半区每个锚点像素的位置上。

**输入结构**：约 18x10 的黑(0)背景网格，被一条完整的灰(5)水平分隔行分为上下两区。上半区（约 7 行）包含一个由多种颜色组成的图案，该图案具有关于自身中心的垂直和水平双轴对称性，但有 2-4 个像素被擦除为黑(0)（形成缺口）。该图案的边界框约 5x5 至 7x7，非黑像素至少使用 2 种颜色。擦除的像素分布使得从任意单轴都不能独立恢复所有缺失像素——至少需要两轴协同才能完全修复。下半区（约 10 行）是黑(0)背景上散布的 2-4 个红(2)锚点像素，锚点之间距离足够大，使得以锚点为中心粘贴上半区图案的边界框时彼此不重叠且不越界。生成约束：上半区图案在修复后具有严格的双轴对称性；下半区锚点位置确保粘贴后图案完全在网格内。

**规则**：
1. 在上半区，从所有非黑像素中推断垂直和水平两条对称轴的位置。
2. 对每个黑(0)像素，通过垂直轴和水平轴的镜像位置查找非黑像素：如果某个镜像位置有非黑像素，则用该颜色填补当前位置。如果两个轴的镜像都给出非黑候选且颜色不同，取通过两轴同时镜像（对角镜像）的第三个候选位置的颜色；若仍不唯一，保留与垂直轴镜像相同的颜色。
3. 将修复后的上半区图案裁剪为其最小边界框，得到印章模板 T。
4. 在下半区，对每个红(2)锚点像素，将 T 的中心像素对齐到锚点位置，粘贴 T 的全部非黑像素（覆盖锚点本身和周围的黑像素）。
5. 输出仅包含下半区（灰分隔行及上半区被移除）。

**关键洞察**：上半区的受损图案不能直接用作印章——它必须先经过双轴对称修复才能获得完整模板。缺失像素的位置经过设计，使得单看一个示例时可能误判对称轴位置，必须对比多个示例才能确认对称修复规则优先级。

## 新题 3：菱形膨胀后的包含优先级填充

**组合逻辑**：[膨胀](已有) + [洪泛填充](已有) + [面积奇偶定填充色](创新：奇偶判断的对象从固定矩形变为膨胀后的菱形内部) + [包围关系](创新：嵌套菱形膨胀后产生新的包含关系和重叠) + [菱形轮廓](已有)

**来源原语**：膨胀/dilate(参考题 d753a70b)、洪泛填充/flood_fill(参考题 868de0fa)、面积奇偶定填充色/parity_sets_fill(参考题 868de0fa)、包围关系/enclosure(参考题 da6e95e5)、菱形轮廓/diamond_outline(参考题 d753a70b)、包含/containment(参考题 868de0fa)

**依赖链**：所有菱形统一膨胀一层 → 膨胀改变了菱形之间的包含关系和重叠状态 → 重叠区域需要优先级判定（小原始半径优先） → 膨胀后封闭区域面积的奇偶性决定填充颜色。求解者必须同时追踪膨胀前的半径信息（用于优先级）和膨胀后的面积信息（用于填充颜色），两步不可拆分。

将网格中的多个曼哈顿菱形轮廓统一膨胀一层后，根据原始半径确定重叠优先级，再根据膨胀后内部面积的奇偶性决定填充颜色。

**输入结构**：约 17x17 的橙(7)背景网格。网格中有 3-4 个一像素厚的曼哈顿菱形轮廓（即每个菱形由满足 |row - center_row| + |col - center_col| = radius 的像素构成），颜色各不相同，取自红(2)、绿(3)、蓝(1)、品红(6)。菱形的原始半径范围为 2-5，中心位置使得部分菱形嵌套（一个完全在另一个内部）但轮廓像素不重叠。生成约束：膨胀一层后至少有一对菱形产生轮廓像素重叠；每个菱形的中心和半径保证膨胀后不越出网格边界；所有菱形的原始半径互不相同（确保优先级无歧义）。

**规则**：
1. 对每个菱形轮廓，记录其中心坐标和原始半径 R_orig。
2. 将每个菱形的半径扩大 1（即绘制 radius = R_orig + 1 的新轮廓），颜色保持不变。同时保留原始轮廓——即每个菱形现在有两层轮廓（R_orig 和 R_orig + 1）。
3. 膨胀后若两个菱形的轮廓像素在同一格重叠，则原始半径较小的菱形优先——该格的颜色取半径较小的菱形的颜色。
4. 膨胀后，每个菱形的最内层轮廓（R_orig）围成一个封闭区域。计算该封闭区域的面积（即 |row - center_row| + |col - center_col| < R_orig 的像素数量，含被外层菱形轮廓占据的格子在内的总格数）。
5. 洪泛填充每个菱形的封闭内部区域：若面积为偶数，填充黄(4)；若面积为奇数，填充该菱形自身的轮廓颜色。填充不覆盖任何轮廓像素。
6. 若一个菱形的内部包含另一个菱形的轮廓，该轮廓像素保持不变，填充仅作用于非轮廓像素。

**关键洞察**：填充颜色取决于膨胀后的面积，但重叠优先级取决于膨胀前的半径——求解者必须在膨胀操作中同时保留两套信息（原始半径用于优先级、新轮廓用于面积），无法只看最终状态就确定答案。

## 新题 4：边缘链接排序驱动的游程重涂色

**组合逻辑**：[排序/链式连接排序](已有) + [循环填充/标记高度决定长度](创新：游程长度控制的不是空间行列，而是链序中的连续块数) + [重涂色](已有) + [边缘像素匹配](已有) + [调色板列](已有)

**来源原语**：排序/reorder(参考题 78332cb0)、边缘像素匹配/edge_pixel_matching(参考题 78332cb0)、链式连接排序/chaining_by_edge_contact(参考题 78332cb0)、循环填充/cyclic_fill(参考题 e7b06bea)、标记高度决定长度/marker_height_run_len(参考题 e7b06bea)、重涂色/recolor(参考题 9b2a60aa)、调色板列/palette_col(参考题 e7b06bea)、长度标记段/length_marker(参考题 e7b06bea)

**依赖链**：边缘像素匹配确定块的链接顺序 → 链接顺序定义了"第几个块"的序号 → 灰色标记段高度 H 提供游程长度 → 调色板颜色按序号分配给连续 H 个块并循环。三条信息源（链接拓扑、游程长度、调色板颜色）汇聚到"每个块涂什么色"这一决策上，缺任何一条都无法确定输出。

将多个精灵体块按边缘像素匹配确定的链式顺序排列成条带，并用调色板颜色按游程长度循环重涂每个块的前景。

**输入结构**：约 20x20 的黑(0)背景网格。网格主体区域包含 5-7 个 5x5 的单色精灵体块（每个块内有一种非黑前景色组成的 4-连通图形，其余为黑(0)），块与块之间被灰(5)分隔线（一像素宽的完整行或列）隔开，形成网格状布局。所有精灵体块的前景当前为同一种颜色（如青(8)）。网格左上角有一段垂直的灰(5)标记段，高度为 H（范围 1-3），位于分隔线区域之外的独立位置。标记段正下方有 2-3 个垂直排列的不同颜色的像素（非灰非黑），构成调色板（从上到下依次为 C1, C2, ...）。生成约束：精灵体块的边缘前景像素保证存在唯一的完整链式排列（每个块恰好与一个或两个邻居的对向边缘有前景像素重合）。

**规则**：
1. 识别所有 5x5 精灵体块及其位置。
2. 对每对块，检查它们的对向边缘（如 A 的右边缘与 B 的左边缘）是否在相同行偏移处存在前景像素。若存在至少一个偏移位置二者都有前景像素，则这两个块可连接。
3. 找到唯一的从链头到链尾的完整排列，使每个块恰好出现一次。链头为仅有一个连接方向的块。
4. 读取调色板颜色 P = [C1, C2, ...]，读取标记段高度 H。
5. 按链式顺序，对每个块重涂前景色：链中第 1 至第 H 个块的前景色改为 C1，第 H+1 至第 2H 个改为 C2，依此类推，循环使用调色板。当块总数不是 H * |P| 的整数倍时，最后一组可能不满 H 个。
6. 输出：将重涂后的块按链式顺序排成一行水平条带，块与块之间用单列灰(5)分隔。擦除标记段和调色板。

**关键洞察**：灰色标记段的高度在源题中控制的是单列内的逐行颜色游程，但在本题中它控制的是链式序列中连续块的颜色分组长度——游程的"单位"从像素行变成了整个精灵体块。

## 新题 5：十字扩展围合与邻接计数条件填充

**组合逻辑**：[扩展/臂色中心色分延](已有) + [洪泛填充](已有) + [计数](创新：计数的对象从矩形框变为围合某区域的十字体数量) + [封闭区域](创新：区域不是由矩形框围成，而是由多个扩展后的十字体共同围合) + [正交对角分工](已有)

**来源原语**：扩展/expand(参考题 0962bcdd)、正交对角分工/ortho_diag_role_split(参考题 0962bcdd)、臂色中心色分延/arm_center_split_growth(参考题 0962bcdd)、洪泛填充/flood_fill(参考题 868de0fa)、计数/counting(参考题 868de0fa)、封闭区域/enclosed_region(参考题 868de0fa)

**依赖链**：十字体扩展产生 5x5 图元（正交臂色 + 对角中心色） → 多个图元之间形成封闭的黑色走廊区域 → 计数每个走廊区域被多少个十字体的扩展图元所邻接 → 邻接数的奇偶决定填充时使用臂色还是中心色 → 填充颜色取自最近十字体的对应颜色类型。扩展步骤创造几何、计数步骤分类区域、颜色类型选择将扩展的双色结构延续到填充逻辑中。

将多个小十字扩展为 5x5 双色图元后，根据围合区域被多少个图元邻接的奇偶性，选择用臂色或中心色填充该区域。

**输入结构**：约 17x17 的黑(0)背景网格。网格中有 3-5 个小 3x3 十字图案，每个十字由臂色（四个臂端像素）和中心色（中心像素）两种颜色组成，臂色和中心色各不相同。不同十字的颜色对互不相同（如十字 A：臂色红(2)/中心色黄(4)，十字 B：臂色蓝(1)/中心色绿(3)）。十字之间的距离安排为：扩展为 5x5 后各图元不重叠，但相邻图元之间恰好留出 1-3 像素宽的黑色走廊，使得部分走廊区域被完全封闭（四面被图元或网格边界围合）。生成约束：至少有 2 个被完全封闭的走廊区域；不同封闭区域的邻接十字体数量至少有奇偶之分。

**规则**：
1. 将每个 3x3 十字扩展为 5x5 图元：臂色沿正交方向（上下左右）各延伸一格；中心色沿四个对角方向各延伸一格。中心像素保持中心色。原 3x3 的臂端像素保持臂色。
2. 识别扩展后网格中所有被非黑像素或网格边界完全封闭的黑(0)连通区域（4-连通）。
3. 对每个封闭区域，计算有多少个不同的十字体的扩展图元与该区域边缘相邻（即该区域的某个黑像素与该图元的某个非黑像素 4-连通相邻）。记此数为 K。
4. 确定该区域的"最近十字体"：取区域所有像素的质心，找距该质心最近的十字体中心（欧氏距离，生成约束保证无平局）。
5. 填充规则：若 K 为奇数，用该最近十字体的**中心色**填充整个区域；若 K 为偶数，用该最近十字体的**臂色**填充整个区域。
6. 未被封闭的黑色区域（与网格边界连通的外部区域）保持黑(0)不变。

**关键洞察**：十字扩展的双色结构（臂色/中心色分工）不仅决定了图元的外观，还延续到了填充逻辑中——邻接计数的奇偶性选择的不是两种固定颜色，而是同一个十字体的两种角色颜色中的一种，将扩展操作的内部结构与填充操作耦合在一起。

## 新题 6：符号解码调色板的游程循环框内填充

**组合逻辑**：[符号解码/符号映射颜色](已有) + [循环填充/标记高度决定长度](创新：游程循环的目标从单列变为矩形框内部逐列填充) + [空心矩形/框内尺寸决定缩放](创新：框的尺寸不再决定缩放比例，而是决定循环填充的总行列数) + [长度标记段](已有)

**来源原语**：符号解码/symbol_decoding(参考题 17cae0c1)、符号映射颜色/symbol_to_color_mapping(参考题 17cae0c1)、循环填充/cyclic_fill(参考题 e7b06bea)、标记高度决定长度/marker_height_run_len(参考题 e7b06bea)、空心矩形/hollow_rect(参考题 6b9890af, 00dbd492)、框内尺寸决定缩放/frame_size_sets_scale(参考题 6b9890af)、调色板列/palette_col(参考题 e7b06bea)、长度标记段/length_marker(参考题 e7b06bea)、符号掩码/symbol_mask(参考题 17cae0c1)

**依赖链**：符号掩码通过编码本解码为颜色 → 解码后的颜色构成有序调色板 → 灰色标记段高度提供每种颜色的游程长度 → 空心矩形框的内部尺寸决定填充总面积 → 调色板颜色按游程长度逐列、逐行循环铺满框内部。四条信息（编码本、符号排列、标记高度、框尺寸）汇聚为一个输出，任何一条缺失都无法确定结果。

将网格左侧的符号掩码解码为调色板颜色，按灰色标记段给定的游程长度，逐列循环填充右侧空心矩形框的内部。

**输入结构**：约 20x15 的黑(0)背景网格。左侧区域（约占 4 列）从上到下排列 2-4 个 3x3 的符号掩码，每个掩码由黑(0)和灰(5)像素组成不同图案，掩码之间有一行黑(0)间隔。右侧区域有一个大的空心红(2)矩形框，内部宽度 6-10 像素、高度 6-10 像素。网格左上角（在符号掩码上方或左侧）有一段垂直灰(5)标记段，高度 H 为 2 或 3。生成约束：框的内部高度能被 H 整除或最后一段允许不满；符号掩码的图案在训练示例间保持一致（构成固定编码本）；各掩码解码后的颜色互不相同。

**规则**：
1. 对每个 3x3 符号掩码，将灰(5)像素视为 1、黑(0)像素视为 0，生成一个 3x3 二进制矩阵。使用任务编码本将该矩阵映射为一种颜色。编码本从训练示例中学习（每个示例展示相同掩码到相同颜色的映射）。
2. 解码后的颜色按掩码从上到下的顺序排列，构成调色板 P = [C1, C2, ...]。
3. 读取灰(5)标记段高度 H 作为游程长度。
4. 填充红(2)框的内部区域：按列从左到右逐列处理，每列内按行从上到下填充。每种颜色连续填充 H 个像素，然后切换到调色板中的下一种颜色，循环使用。每一列从调色板的第一种颜色重新开始循环。
5. 红(2)框边框保持不变。擦除左侧符号掩码区域和灰色标记段（替换为黑(0)）。输出为整个网格。

**关键洞察**：符号掩码、标记段和矩形框三者分别编码了"什么颜色"、"每种颜色占多少行"和"填充多大区域"——三种信息来源在空间上分离，必须全部正确解码后才能组合出唯一输出。编码本无法从单个示例推断，必须对比多个训练示例。

## 新题 7：透明叠加合并中的奇偶优先仲裁

**组合逻辑**：[透明叠加/标记无冲突合并](创新：冲突不再被禁止，而是由奇偶规则仲裁) + [坐标奇偶匹配](创新：奇偶不控制填充范围，而是控制冲突解决时的空间优先方向) + [填充矩形/同尺寸对齐](已有) + [标记像素](已有)

**来源原语**：透明叠加/overlay(参考题 25e02866)、标记无冲突合并/markers_merge(参考题 25e02866)、坐标奇偶匹配/coord_parity_match(参考题 d492a647)、填充矩形/filled_rectangle(参考题 25e02866)、同尺寸对齐/same_size_align(参考题 25e02866)、标记像素/marker_pixel(参考题 d492a647, 25e02866)、共享底色/shared_base_color(参考题 25e02866)

**依赖链**：多个同尺寸矩形需要对齐叠加 → 叠加过程中标记像素可能在同一相对位置冲突 → 参考像素的坐标奇偶性定义一个分区函数 → 每个冲突位置根据自身相对坐标的奇偶类别选择不同的优先规则（靠左矩形优先 vs. 靠右矩形优先）。叠加操作创造冲突，奇偶规则解决冲突，二者形成一个非线性的判定结构——同一合并过程中不同位置适用不同规则。

将多个同尺寸的带标记矩形透明叠加合并为一个，当标记像素冲突时，根据冲突位置相对坐标的奇偶性选择来自左侧矩形或右侧矩形的标记。

**输入结构**：约 15x20 的黑(0)背景网格。网格中有 3-4 个相同尺寸的填充矩形（如 5x7），彼此不重叠，水平排列（从左到右）。每个矩形的底色相同（如蓝(1)），内部散布 3-5 个非底色的标记像素，颜色取自红(2)、绿(3)、黄(4)、品红(6)等。不同矩形的标记像素在相对位置上部分重合（即至少 1-2 个相对坐标处有多个矩形都放置了标记且颜色不同），部分不重合。在所有矩形的右下方，有一个孤立的参考像素，颜色为橙(7)，不属于任何矩形。生成约束：至少存在 2 个相对位置产生真正的颜色冲突（不同矩形在该位置给出不同的非底色标记）。

**规则**：
1. 将所有矩形按其左上角的列坐标从小到大编号为 1, 2, 3, ...（即从左到右）。
2. 以第一个矩形的左上角为参考原点，为每个矩形内部的像素计算相对坐标 (dr, dc)。
3. 创建一个与单个矩形同尺寸的输出矩形，底色为蓝(1)。
4. 对每个相对坐标 (dr, dc)：收集所有矩形在该位置的像素颜色。
   - 若所有矩形在该位置均为底色 → 输出底色。
   - 若恰好一个矩形在该位置有非底色标记 → 输出该标记颜色。
   - 若多个矩形在该位置有不同的非底色标记（冲突）→ 查看参考像素的绝对坐标 (rref, cref)，计算 (dr mod 2, dc mod 2)：
     - 若 (dr mod 2) == (rref mod 2) 且 (dc mod 2) == (cref mod 2)：取编号最小（最左）的矩形的标记颜色。
     - 否则：取编号最大（最右）的矩形的标记颜色。
5. 输出：仅输出合并后的单个矩形（擦除输入中的所有原始矩形和参考像素）。

**关键洞察**：参考像素不筛选哪些格子被填充，而是定义了一个位置依赖的优先级函数——与参考像素同奇偶的冲突位置由最左矩形做主，反之由最右矩形做主。这使得同一次合并中不同位置的仲裁方向不同，无法用单一全局优先级解释。

## 新题 8：框内锚点的递减射线与包含门控

**组合逻辑**：[射线延伸/逐步缩短行程](已有) + [包含/包围关系](创新：包含关系不用于选择目标对象，而是作为射线的边界条件开关) + [空心矩形](已有) + [锚点像素](已有) + [描框](已有)

**来源原语**：射线延伸/ray_extend(参考题 9772c176)、逐步缩短行程/progressively_shortened(参考题 9772c176)、包含/containment(参考题 868de0fa, da6e95e5)、包围关系/enclosure(参考题 da6e95e5)、空心矩形/hollow_rect(参考题 00dbd492, 868de0fa)、锚点像素/anchor_pixel(参考题 a9f96cdd)、描框/draw_frame(参考题 e2092e0c)

**依赖链**：每个锚点发出四方向递减射线 → 射线的终止规则取决于锚点是否在框内（包含关系判定） → 框内锚点的射线在框壁处截断，框外锚点的射线自然递减至消失或遇到框壁停止但不穿入 → 框壁对射线构成单向屏障。包含关系将同一射线规则分化为两种截然不同的行为模式。

从每个锚点像素向四个正交方向发出逐步缩短的递减射线，框内锚点的射线被框壁截断，框外锚点的射线自由延伸但不穿透框壁。

**输入结构**：约 20x20 的黑(0)背景网格。网格中有 2-3 个不同尺寸的空心绿(3)矩形框（一像素厚边框，内部为黑(0)），框之间不重叠不相邻。部分框的内部有 1-2 个彩色锚点像素（非绿非黑），部分锚点像素位于所有框的外部。共计 4-6 个锚点像素，颜色各异，取自红(2)、蓝(1)、黄(4)、品红(6)、橙(7)等。生成约束：至少 2 个锚点在框内、至少 1 个锚点在框外；框外锚点到最近框壁的距离至少为 3（确保射线有缩短空间）；框内锚点到四面框壁的距离至少为 2。

**规则**：
1. 判定每个锚点像素是否位于某个绿(3)框的内部（被框的四条边完全包围）。
2. 从每个锚点像素出发，沿上、下、左、右四个方向各发出一条递减射线。射线规则：射线在锚点所在行（左右方向）或列（上下方向）上绘制，起始宽度为 1 像素。每延伸一步（一个像素距离），射线在垂直于延伸方向上的宽度不变（始终为 1 像素宽），但每隔 2 步长度缩短 1 格（即第 1-2 步画出、第 3-4 步画出但整体短 1、第 5-6 步再短 1...直到长度缩减为 0）。实际效果：射线颜色等于锚点颜色，在延伸方向上逐步递减。
3. 框内锚点的射线终止条件：射线遇到绿(3)框壁像素时立即停止（不覆盖框壁），即使递减长度尚未耗尽。
4. 框外锚点的射线终止条件：射线自由延伸直到递减长度耗尽或到达网格边界。若射线路径上遇到绿(3)框壁，射线在框壁前一格停止（不穿透框壁、不覆盖框壁）。
5. 锚点像素本身被其射线起始段覆盖（变为射线颜色，实际上颜色不变）。绿(3)框壁像素始终保持不变。
6. 若两条来自不同锚点的射线在同一像素重叠，取来自距该像素更近的锚点的颜色（曼哈顿距离）；若距离相同，取来自行坐标更小（更靠上）的锚点的颜色。

**关键洞察**：同一条递减射线规则在框内和框外产生完全不同的几何效果——框内射线被四面墙壁截断形成短而对称的星形爆发，框外射线则形成长而逐渐消散的拖尾。包含关系不是简单的过滤器，而是改变了射线的终止条件，使同一规则分化出两种视觉模式。
