## 新题 1：对角射线激活选择性同余填充

**组合逻辑**：[射线延伸](创新：射线用于选择而非重涂色) → [循环填充](已有) + [对角线激活](创新：激活的结果是选中对象，而非改变颜色) + [同余类交错铺满](已有)

**来源原语**：射线延伸·对角线激活·底色决定涂色(d07ae81c), 循环填充·同余类交错铺满·对角线·等距偏移(05269061), 标记像素(9caba7c3/d07ae81c), 擦除(d23f8c26)

**依赖链**：标记像素的对角射线决定哪些对角线段被"激活"（选择机制）；被激活的线段才触发同余类铺满（填充机制）；未被激活的线段被擦除。射线的几何路径同时承载"选择"和"铺满方向"两重语义——去掉射线则不知选哪些线段，去掉铺满则激活毫无意义。

将标记像素的对角射线作为选择器，仅让射线穿过的对角线段按其同余类周期性铺满整个网格，未被射线选中的线段被擦除。

**输入结构**：约 15x15 网格，背景黑(0)。网格上散布 2~3 个红(2) 标记像素。另有 3~5 条 NW-SE 方向的短对角线段（每条 2~4 像素），每条使用不同颜色（从蓝(1)、绿(3)、黄(4)、品红(6) 中选取）。各对角线段互不相邻，与红标记像素也不相邻。生成约束：每条对角线段的像素均满足 row - col = 常数（即同一条 NW-SE 对角线上），不同线段的 (row - col) mod 3 值互不相同；至少一条线段不被任何红标记的射线穿过。

**规则**：
1. 从每个红(2) 标记像素出发，沿 NW-SE 方向和 NE-SW 方向分别向两端延伸射线至网格边界，标记射线经过的所有格子为"已激活"（红标记自身也算已激活）。
2. 对每条彩色对角线段：若其至少一个像素位于已激活格子上，则该线段被"选中"。
3. 对每条选中的线段：计算其 NW-SE 同余偏移量 d = (row - col) mod 3。将网格中所有满足 (row - col) mod 3 = d 的黑(0) 格子涂上该线段的颜色。若线段自身的像素也在这些位置上，保持原色不变。
4. 未被选中的对角线段的所有像素擦除为黑(0)。
5. 红(2) 标记像素在输出中保持不变。
6. 冲突解决：若两条选中线段的同余偏移量相同（生成约束已排除此情况，但作为安全规则），按线段中心像素到最近红标记的曼哈顿距离排序，距离小的颜色优先（覆盖距离大的）。

**关键洞察**：红标记的对角射线并不直接改变任何颜色，而是充当"选通门"——射线穿过哪些线段决定了哪些同余类被铺满、哪些被清除。同一条射线可能同时选中多条不同偏移量的线段，导致多个同余类同时铺满而形成交错图案。

## 新题 2：嵌套深度决定镜像轴向的对称补全

**组合逻辑**：[规范化·包含树分析](已有) → [对称补全](创新：镜像轴由包含深度动态决定，而非固定双轴) + [包含树](已有) + [标记方块→对称中心](已有)

**来源原语**：规范化·包含树·嵌套框架·封闭区域·拓扑决定布局(2d0172a1), 对称补全·镜像·标记方块·对称中心·标记定义双轴镜像(4938f0c2)

**依赖链**：必须先构建包含树确定每个区域的嵌套深度；深度的奇偶性决定在该区域内执行水平镜像还是垂直镜像；每个区域内的标记方块定义镜像中心。去掉包含树分析则镜像轴无法确定；去掉镜像操作则深度分析无用。拓扑结构成为操作的参数选择器，而非两个独立操作的串联。

解析嵌套矩形框架的包含深度，在每层区域内以标记方块为中心执行单轴对称补全，镜像轴方向由该区域的嵌套深度奇偶性决定。

**输入结构**：约 19x19 网格，背景黑(0)。2~3 层嵌套的灰(5) 矩形单像素宽边框，每层边框完全包围内层。在最内层和各层之间的环形区域中各有一个绿(3) 的 2x2 实心标记方块。在部分区域中（不必每个区域都有），标记方块的某一侧（或两侧、三侧）有红(2) 前景像素构成的不规则 4-连通形状（3~7 像素），这些前景像素仅出现在标记方块的一个或两个象限中，不跨越标记方块的中心轴线。生成约束：前景形状的镜像补全结果不会超出其所在区域的边框范围。

**规则**：
1. 识别所有灰(5) 矩形边框，构建包含树。最外层边框深度 = 0，其内部直接子边框深度 = 1，依次递增。未被任何边框包围的区域（即最外层边框外部）深度 = -1，不参与变换。
2. 对每个深度 >= 0 的区域（边框内部、两层边框之间、或最内层边框内部），找到该区域中的绿(3) 2x2 标记方块。以标记方块几何中心为镜像中心。
3. 若该区域的深度为偶数（0, 2, ...），执行**水平轴**镜像：对区域内每个红(2) 像素，计算其关于标记方块中心的上下对称位置，在对称位置涂红(2)（仅覆盖黑(0) 像素）。
4. 若该区域的深度为奇数（1, 3, ...），执行**垂直轴**镜像：对区域内每个红(2) 像素，计算其关于标记方块中心的左右对称位置，在对称位置涂红(2)（仅覆盖黑(0) 像素）。
5. 灰(5) 边框、绿(3) 标记方块均保持不变。不含红色前景的区域不做任何操作。
6. 边界处理：镜像后的像素若落在灰(5) 边框上或区域外，不绘制（生成约束保证这不会发生）。

**关键洞察**：参考题 4938f0c2 中标记方块总是触发固定的双轴镜像，而这里每个标记方块只执行单轴镜像，且选择哪条轴取决于该方块在嵌套层次中的位置——拓扑结构编码了操作参数，而非直接编码操作结果。需对比多个示例才能归纳出深度奇偶与轴向的对应关系。

## 新题 3：遮挡补全重塑视线图的贪心寻路

**组合逻辑**：[补全·隐含区域重涂](已有) → [贪心遍历](创新：补全后的完整形状成为动态障碍物，改变视线图拓扑) + [前景遮挡](创新：从颜色层面的遮挡转为路径规划层面的阻挡)

**来源原语**：补全·被遮挡形状·矩形足迹·前景遮挡·隐含区域重涂(52df9849), 贪心遍历·起始块·目标块·走廊路径·同行同列对齐·视线可见·视线遮挡判断·最近未访问优先(3490cc26)

**依赖链**：部分矩形形状被其他前景色遮挡，必须先推断其完整足迹并补全；补全后的完整形状构成新的视线遮挡物，改变起始块到目标块之间的可见关系；贪心寻路依据补全后的视线图进行。若不补全，路径规划基于错误的可见性；若不寻路，补全操作毫无目的。关键耦合点：某些路径在补全前看似畅通，补全后被堵死，迫使贪心走另一条路。

先推断并补全被遮挡的矩形形状，然后在补全后的网格上执行贪心最近可见块寻路，绘制连接走廊。

**输入结构**：约 17x17 网格，背景黑(0)。一个红(2) 2x2 起始块和 3~5 个青(8) 2x2 目标块散布于网格。另有 2~3 个实心矩形区域（每个约 3x4 到 5x6 像素），颜色为黄(4)，部分矩形被橙(7) 像素遮挡——即矩形的某些像素被替换为橙(7)，但矩形的完整边界框内不含黑(0) 背景像素（全被黄(4) 或橙(7) 填满），表明这些橙色像素实际占据了黄色矩形的隐含足迹。起始块和目标块不互相遮挡，但部分块对之间的同行/同列视线穿过黄色矩形的隐含足迹区域。生成约束：补全后视线图保证存在从起始块经若干目标块的贪心路径（每步选最近可见未访问块），且该路径与未补全时的贪心路径至少有一步不同。

**规则**：
1. 识别所有黄(4) 的 4-连通区域。对每个区域，计算其边界框。若边界框内所有像素均为非黑色（黄(4) 或橙(7)），则将边界框内所有橙(7) 像素重涂为黄(4)，完成该矩形的补全。
2. 在补全后的网格上执行贪心遍历：从红(2) 起始块出发，在同两行带或同两列带中寻找可见的青(8) 目标块。两个 2x2 块"同带对齐"指它们的两行（或两列）范围完全重合。"可见"指两块之间该带内的所有像素均为黑(0)（无任何非背景像素阻挡）。
3. 在所有可见且未访问的目标块中选择最近的一个（距离 = 两块边缘之间的像素间隔数；若距离相同，优先选行号较小的块，再相同则选列号较小的）。
4. 将当前块与所选目标块之间带内的所有黑(0) 像素涂为橙(7)，形成走廊。然后以该目标块为当前块，重复步骤 2-3。
5. 当没有可见的未访问目标块时停止。所有块和已补全的矩形保持原色不变。

**关键洞察**：遮挡补全不仅恢复了矩形的视觉完整性，更关键的是改变了路径规划的约束图——某些在补全前看似可行的走廊在补全后被封堵，迫使贪心遍历选择完全不同的路径。求解者必须先完成补全才能正确判断视线。

## 新题 4：连通拓扑分类门控双模式扩展

**组合逻辑**：[模式检测·拓扑分类](创新：检测的不是固定图案而是连通性质) ⇒ 分支 { [掩码映射](已有) | [像素放大](已有) } + [对角链式连接](已有作为分类依据) + [自身色选掩码](已有)

**来源原语**：模式检测(1818057f), 八连通区域·对角链式连接·仅对角接触变色(ecb67b6d), 掩码映射·像素放大·自身色选掩码·全局掩码·块单元(973e499e)

**依赖链**：先将每个 8-连通彩色区域按内部 4-连通结构分类——若 4-连通子块仅通过对角角点连接（对角链），则归为"链式区域"；否则归为"实心区域"。分类结果决定该区域使用哪种扩展模式：链式区域使用自身色掩码映射（每个像素扩展为一个微型掩码），实心区域使用简单像素放大（每个像素变为 2x2 同色块）。去掉拓扑分类则不知用哪种扩展；去掉扩展操作则分类无用。分类本身是一个推理步骤，而非简单属性读取。

按 8-连通区域的内部 4-连通拓扑分类，对角链式区域进行自身色掩码映射扩展，实心连通区域进行像素放大扩展。

**输入结构**：约 7x7 网格，背景黑(0)。网格上有 3~5 个 8-连通的单色区域，各区域使用不同颜色（从蓝(1)、红(2)、绿(3)、黄(4)、灰(5) 中选取），每个区域 3~6 像素。区域之间至少间隔 1 个黑(0) 像素。部分区域是"对角链式"的：由 2~3 个 4-连通子块组成，子块之间仅通过对角角点相连（如一个像素在 (r,c)、另一个在 (r+1,c+1)，它们 8-连通但不 4-连通）。其余区域是"实心"的：整个区域构成单个 4-连通块。生成约束：至少有一个链式区域和一个实心区域。

**规则**：
1. 识别所有非黑 8-连通区域。对每个区域，分解为 4-连通子块。
2. 分类：若一个 8-连通区域包含多个 4-连通子块，且每对相邻子块仅通过对角角点相连（不存在共享边的像素对），则该区域为"链式"。否则（整个区域是单个 4-连通块）为"实心"。
3. 构建输出网格：输出尺寸 = 输入行数 x 输入行数 乘以 输入列数 x 输入列数（即输入每个像素对应输出的一个与输入同尺寸的块）。
4. 对输入中的每个像素 (r, c)：
   - 若 (r, c) 是黑(0) 背景，对应输出块全部填黑(0)。
   - 若 (r, c) 属于**链式区域**且颜色为 c_val：输出块是输入网格的"c_val 色掩码"——在输出块中，原输入中颜色为 c_val 的位置填 c_val，其余填黑(0)。
   - 若 (r, c) 属于**实心区域**且颜色为 c_val：输出块全部填 c_val（等效于简单像素放大）。
5. 输出块按输入像素的行列顺序拼接，无间隔。

**关键洞察**：两种扩展模式在参考题中各自独立使用。这里它们共存于同一张输出网格中，由每个像素所属区域的拓扑分类来选择——求解者必须先理解对角连通性的概念，再将其映射到正确的扩展规则，形成"分类→分支执行"的推理结构。

## 新题 5：十字检测定位描边框架与内部擦除

**组合逻辑**：[模式检测](已有：检测 '+' 十字) → [描边](创新：边框不画在画布边界，而是以十字中心为圆心动态确定尺寸) → [擦除](创新：由描边框架的覆盖范围决定擦除目标) + [邻域全匹配](已有) + [画布边界](已有)

**来源原语**：模式检测·十字图案·前景对象·邻域全匹配(1818057f), 描边·画布边界(6f8cd79b), 擦除·仅保留中轴(d23f8c26), 包围框(d56f2372)

**依赖链**：十字检测确定边框的中心位置和数量；每个十字中心到最近网格边缘的距离确定边框的半径；边框围合的区域定义擦除范围——框内非十字的前景像素被清除。去掉十字检测无法确定边框位置；去掉描边则检测结果无法驱动几何变换；去掉擦除则描边仅是叠加，不产生信息变换。三者形成检测→生成→过滤的紧耦合链。

检测前景中的 '+' 十字图案，以每个十字中心为中心绘制正方形边框，框内的非十字前景像素被擦除。

**输入结构**：约 15x15 网格，背景黑(0)。大量蓝(1) 前景像素构成若干 4-连通区域，形态各异（有的紧凑，有的细长，有的带分支，3~12 像素不等）。其中部分位置自然形成 '+' 十字图案：一个蓝(1) 像素的上下左右四个正交邻居也都是蓝(1)。十字图案可能嵌入在更大的前景区域中，也可能恰好是孤立的 5 像素十字。生成约束：十字中心之间的曼哈顿距离 >= 6，保证以下规则产生的边框互不重叠。

**规则**：
1. 扫描所有蓝(1) 像素，找出满足"上下左右四个正交邻居均为蓝(1)"的像素，标记为十字中心。
2. 对每个十字中心 (r, c)，计算其到四条网格边缘的最小距离：d = min(r, c, H-1-r, W-1-c)，其中 H、W 为网格高度和宽度。
3. 以 (r, c) 为中心，绘制边长为 2d+1 的正方形边框（单像素宽），颜色为绿(3)。边框的四条边分别位于 r-d 行、r+d 行、c-d 列、c+d 列，四角共享。若边框像素位置上已有内容（蓝(1) 或其他），覆盖为绿(3)。
4. 对每个十字中心，将其边框**严格内部**（不含边框线本身）所有非十字的蓝(1) 像素擦除为黑(0)。"十字像素"指十字中心本身及其上下左右四个邻居共 5 个像素，这些保留蓝(1) 不擦除。
5. 边框外部的蓝(1) 前景像素保持不变。

**关键洞察**：十字图案在参考题中仅用于重涂色标记，这里十字变成了几何操作的定位锚点——不仅定位边框中心，还通过自身到边界的距离编码了边框的缩放尺寸。框内擦除进一步依赖十字的精确位置来豁免十字自身，形成"检测→定参→保护性擦除"的三层耦合。

## 新题 6：控制条充当镜像轴反射对齐精灵体

**组合逻辑**：[跨度对齐](已有) → [镜像](创新：镜像轴不是 2x2 标记方块的中心而是控制条本身) → [擦除](已有：移除控制条) + [控制条](创新：从"重复方向指示器"变为"反射平面") + [精灵体](已有)

**来源原语**：镜像·对称补全·对称中心(4938f0c2), 平铺·擦除·精灵体·控制条·跨度对齐·沿控制条重复(c62e2108)

**依赖链**：跨度对齐确定每条控制条管辖哪个精灵体（同参考题 c62e2108 的匹配机制）；但操作从"沿控制条方向平铺"变为"以控制条为轴镜像翻转"；翻转后若两个精灵体的镜像产物在空间上重叠，按精灵体包围框面积从小到大的顺序绘制（小的后画，覆盖大的）；最后控制条被擦除。去掉跨度对齐无法匹配精灵体和控制条；去掉镜像则对齐毫无意义；去掉擦除则输出包含不应存在的控制条。控制条的三重角色（选择器、轴、被擦除物）使三个操作不可分割。

以控制条为镜像轴反射其跨度对齐的精灵体到对侧，擦除控制条本身。

**输入结构**：约 15x15 网格，背景黑(0)。2~3 个彩色精灵体（4-连通单色不规则形状，每个 4~8 像素，颜色各异，从红(2)、蓝(1)、黄(4) 中选取）。2~3 条单像素宽的灰(5) 控制条（水平条或垂直条），每条跨越至少 5 格。每条控制条与恰好一个精灵体"跨度对齐"：水平控制条与某精灵体拥有完全相同的列跨度（起始列和终止列一致）；垂直控制条与某精灵体拥有完全相同的行跨度。精灵体位于其对齐控制条的一侧（上方/下方或左方/右方），不接触控制条。生成约束：各精灵体的镜像结果不会与其他未镜像的精灵体原始位置重叠；镜像结果不超出网格边界。

**规则**：
1. 识别所有灰(5) 单像素宽的完整行段或列段作为控制条。识别所有非黑非灰的 4-连通区域作为精灵体。
2. 匹配：对每条水平控制条，找到与其列跨度（最小列到最大列）完全相同的精灵体；对每条垂直控制条，找到与其行跨度完全相同的精灵体。每条控制条恰好匹配一个精灵体。
3. 镜像：对每对匹配的(控制条, 精灵体)，以控制条所在的行（水平条）或列（垂直条）为镜像轴，将精灵体的每个像素反射到轴的对侧。反射公式——水平轴在第 r_bar 行：像素 (r, c) 映射到 (2*r_bar - r, c)；垂直轴在第 c_bar 列：像素 (r, c) 映射到 (r, 2*c_bar - c)。在反射位置涂上精灵体原始颜色，仅覆盖黑(0) 像素。
4. 冲突解决：若两个精灵体的镜像产物占据同一像素（生成约束已排除与原始精灵体的重叠，但不排除镜像产物之间的重叠），则按精灵体像素数从多到少的顺序先绘制，再按像素数从少到多的顺序覆盖——即像素数少的精灵体的镜像最终可见。
5. 擦除所有灰(5) 控制条像素为黑(0)。原始精灵体保留不变。

**关键洞察**：参考题中控制条指示平铺方向，标记方块定义镜像中心——两个完全不同的机制。这里控制条的一维结构被重新诠释为镜像轴，同时保留了跨度对齐的选择语义。控制条在匹配、反射、擦除三个阶段扮演不同角色，其几何位置对所有阶段都不可或缺。

## 新题 7：对角射线通道门控逐步标记迁移

**组合逻辑**：[射线延伸](创新：射线定义可通行通道而非涂色目标) ⊗ [逐步推进·循环迁移](创新：迁移不再沿固定车道而是沿射线通道) + [对角线激活](创新：激活产生通道约束) + [标记条·边缘满条](已有)

**来源原语**：射线延伸·对角线激活·标记像素·基底色区域(d07ae81c), 生长·逐步推进·循环迁移·边缘满条·标记条·重涂色(758abdf0)

**依赖链**：标记像素的对角射线在网格上刻画出"可通行通道"；边缘满条发射标记条沿车道向对侧迁移，但标记条只能移动到位于已激活通道上的格子——若下一步位置不在通道上则标记条停滞。通道网络与迁移规则同时约束输出，两套系统交织：去掉射线则所有标记条都停滞（无路可走）；去掉迁移规则则通道只是无意义的标记。

标记像素的对角射线定义可通行通道，边缘标记条仅沿通道内的车道逐步迁移。

**输入结构**：约 13x13 网格，背景黑(0)。网格的左边缘（第 0 列）有一条完整的蓝(1) 竖条（从第 0 行到最后一行全部填蓝(1)），即边缘满条。在第 1 列中，部分行有红(2) 单像素标记条（紧邻蓝条右侧），其余行为黑(0)。网格内部散布 2~4 个绿(3) 标记像素（不在第 0 或 1 列）。生成约束：每个红(2) 标记条所在行上，至少有一个绿(3) 标记像素的某条对角射线穿过该行的第 2 列位置（否则该标记条永远无法前进，题目保证每个标记条至少可以走一步）。

**规则**：
1. 从每个绿(3) 标记像素出发，沿 NW-SE 和 NE-SW 两个方向分别向两端延伸射线至网格边界。将射线经过的所有格子标记为"通道"（绿(3) 标记像素自身也是通道）。
2. 对每个红(2) 标记条像素（位于第 1 列、第 r 行）执行迁移：
   - 检查第 2 列第 r 行是否为通道且当前为黑(0)。若是，将该位置涂红(2)，并将第 1 列第 r 行的红(2) 擦除为黑(0)——标记条向右移动一格。
   - 若第 2 列第 r 行不是通道或不是黑(0)，标记条不移动，保持在第 1 列。
3. 对已移动到第 2 列的标记条，继续检查第 3 列同行位置是否为通道且为黑(0)。若是，继续移动（擦除旧位置，涂新位置）。重复此过程直到下一列同行位置不是通道、不是黑(0)、或超出网格。
4. 当一个标记条到达网格最后一列（第 W-1 列）时，将该位置改涂为蓝(1)（与边缘满条同色），表示迁移完成。
5. 绿(3) 标记像素在输出中保持不变。蓝(1) 边缘满条保持不变。迁移过程中标记条不会覆盖绿(3) 像素（遇到绿像素则停止，停在前一格）。
6. 处理顺序：从上到下逐行处理标记条，同行内不存在多个标记条。

**关键洞察**：参考题中标记条的迁移是沿固定车道无条件推进，对角射线则用于涂色。这里对角射线创造了稀疏的"通道网络"，标记条的水平迁移被限制在通道交叉点上——射线的几何角度决定了哪些行列交叉处是可通行的，相当于用对角线几何编码了一张隐式的通行许可表。

## 新题 8：像素放大中子像素对角线编码遮挡深度

**组合逻辑**：[像素放大](已有) + [补全](已有) → [前景遮挡→深度排序](创新：遮挡关系从"需要修复的缺陷"变为"需要编码的信息") + [对角线标记](创新：对角线不标记背景共线性而标记深度层级)

**来源原语**：像素放大·对角线标记·共对角背景标记(f0afb749), 补全·被遮挡形状·矩形足迹·前景遮挡·隐含区域重涂(52df9849)

**依赖链**：必须先推断遮挡关系来确定每个矩形的完整足迹和相对深度顺序；放大网格后，每个输入像素对应 2x2 的输出块；在重叠区域内，2x2 块的填色模式编码该位置的深度信息——非重叠像素全填原色，重叠像素的 2x2 块中只在主对角线位置填该层颜色、副对角线填被遮挡层颜色。去掉遮挡分析则不知深度顺序和重叠区域；去掉放大则无子像素空间编码深度；去掉对角线编码则放大后的重叠区域颜色不确定。三个操作共同决定每个输出像素的颜色。

将含有部分遮挡矩形的网格放大两倍，在重叠区域用子像素对角线图案同时显示上层和下层颜色。

**输入结构**：约 8x8 网格，背景黑(0)。网格上有 2~4 个不同颜色的实心矩形（每个 2x3 到 4x5 像素，颜色从蓝(1)、红(2)、黄(4)、灰(5) 中选取）。矩形之间存在部分重叠：在重叠区域，只显示"上层"矩形的颜色，下层矩形的颜色被遮挡。遮挡关系可从可见部分推断——每个矩形的可见像素都位于某个矩形边界框内，且该边界框内的所有非背景像素要么是该矩形颜色，要么是遮挡它的矩形颜色。生成约束：不存在三层重叠（同一像素至多被两个矩形覆盖）；每个矩形至少有一条完整的边可见（用于推断完整尺寸）；遮挡关系构成全序（可以排出明确的从上到下顺序）。

**规则**：
1. 识别所有矩形及其完整边界框。方法：对每种非背景颜色，找到该颜色所有像素的边界框。若边界框内存在其他颜色的非背景像素，则该边界框区域内的那些其他颜色像素属于遮挡当前矩形的上层矩形。由此推断每个矩形的完整足迹。
2. 确定遮挡深度排序：若矩形 A 的颜色出现在矩形 B 的边界框内部（替换了 B 的像素），则 A 在 B 上面。按此关系排出从顶层到底层的完整顺序。
3. 创建 2H x 2W 的输出网格（H、W 为输入尺寸）。
4. 对输入中的每个像素 (r, c)，对应输出的 2x2 块为 (2r, 2c), (2r, 2c+1), (2r+1, 2c), (2r+1, 2c+1)：
   - 若 (r, c) 为黑(0) 背景：输出块 4 个像素全填黑(0)。
   - 若 (r, c) 仅被一个矩形覆盖（无重叠）：输出块 4 个像素全填该矩形颜色。
   - 若 (r, c) 被两个矩形覆盖（有重叠，输入中显示的是上层颜色 c_top，被遮挡的是下层颜色 c_bot）：输出块的主对角线位置 (2r, 2c) 和 (2r+1, 2c+1) 填 c_top；副对角线位置 (2r, 2c+1) 和 (2r+1, 2c) 填 c_bot。
5. 所有矩形在输出中均按其完整足迹参与计算（包括输入中被遮挡而不可见的部分）。

**关键洞察**：参考题中像素放大的对角线标记用于标识背景像素是否与前景共对角线，遮挡补全则用于恢复被遮挡的形状。这里两者融合产生了全新语义：放大后的子像素空间不是均匀放大原图，而是利用 2x2 块内的对角线/反对角线位置分别编码上下两层颜色——同一个输出块同时呈现了遮挡关系的"深度切片"。求解者必须同时理解遮挡推理和子像素编码才能生成正确输出。
