## 新题 1：孔洞数选定反射轴

**组合逻辑**：[计数 count](创新：计数结果不映射颜色而映射几何操作类型) + [镜像 mirror](已有) + [重涂色 recolor](已有)

**来源原语**：计数/按孔洞数映射颜色(0a2355a6)、封闭区域(0a2355a6)、镜像(88207623)、跨轴反射(88207623)、重涂色(88207623)

**依赖链**：封闭区域计数 → 决定沿哪条轴做反射 → 反射后的副本被涂为指定颜色。若不先计数孔洞，则不知沿哪条轴反射；若不做反射，则无输出变化。三者缺一不可。

一句话总结：根据每个闭合对象内部孔洞的数量，选择沿垂直轴还是水平轴镜像该对象，并将镜像副本涂为对应颜色。

**输入结构**：约 15x15 的网格，背景为黑(0)。一条红(2)竖直线（1 像素宽，贯穿网格全高）和一条蓝(1)水平线（1 像素宽，贯穿网格全宽）交叉形成坐标轴，将网格分为四个象限。各象限中分布有 2-4 个绿(3) 4-连通单色闭合图形（每个 5-12 像素），每个图形内部封闭 1 或 2 个黑(0)孔洞（4-连通黑色区域，不与外部背景相连）。不同示例中各图形的具体形状不同，但均为闭合结构且像素数、轮廓各异。生成约束：每个图形的反射落点区域不与任何已有对象（包括其他图形及其反射副本）重叠；两条轴线交叉于网格中心附近。

**规则**：
1. 保持红(2)竖直轴和蓝(1)水平轴不变。
2. 对每个绿(3)图形，计数其内部封闭的黑(0)孔洞数量（4-连通，不与网格边缘背景相连的黑色区域）。
3. 孔洞数 = 1 → 将该图形沿红(2)竖直轴做水平镜像，副本涂为黄(4)。
4. 孔洞数 = 2 → 将该图形沿蓝(1)水平轴做垂直镜像，副本涂为灰(5)。
5. 原始绿(3)图形保持不变。
6. 反射副本中若有像素落在轴线上，则该像素不绘制（轴线像素优先保留）。
7. 处理顺序不影响结果（生成约束保证反射副本之间互不重叠）。

**关键洞察**：孔洞数量不是映射到颜色（如参考题 0a2355a6 中孔洞数→蓝/绿/红/黄），而是映射到几何操作的选择——拓扑属性决定空间变换类型，这是源题中不存在的结构关系。

## 新题 2：旋转补全创造洪泛边界

**组合逻辑**：[对称补全 symmetry_completion](已有) + [洪泛填充 flood_fill](已有) + [描边 outline](已有) — 三者存在涌现关系：补全操作创造出输入中不存在的封闭区域，使得洪泛填充从无效变为有效

**来源原语**：对称补全/旋转/旋转对称(1b60fb0c)、缺失部分标记新色(1b60fb0c)、洪泛填充/封闭区域/区域可达性(543a7ed5)、描边/外部邻接区域(543a7ed5)、标记像素(88207623)

**依赖链**：旋转补全 → 产生新的封闭边界（涌现） → 标记像素选择性激活洪泛填充 → 描边装饰完成后的轮廓。删除补全步骤，则无封闭区域可填；删除填充步骤，则标记像素无意义；删除描边，则外部轮廓缺失。

一句话总结：补全一个旋转不完整的蓝色形状，将补全后新产生的封闭区域中含有标记的填充为黄色，并在整个形状外围描绿色轮廓。

**输入结构**：约 13x13 的网格，背景为黑(0)。蓝(1)像素构成一个近似四重旋转对称的图形，但缺失约四分之一（某个象限方向的臂或局部区域缺失）。该图形为非凸的复杂形状（如带有弯折的臂、局部凹陷等），具体轮廓在不同示例中不同，但旋转对称中心可从已有部分推断。在输入的黑(0)区域中，散布有 1-3 个孤立的橙(7)标记像素，这些像素的位置经设计，在蓝色形状补全后恰好位于蓝+红像素包围形成的封闭区域内部。生成约束：补全后至少形成 2 个独立的封闭区域（4-连通黑色区域不与网格边缘相连）；部分封闭区域含有橙(7)标记，部分不含；橙(7)标记在补全前不被任何结构包围（即在输入中它们所在的黑色区域可达网格边缘）。

**规则**：
1. 检测蓝(1)像素的旋转对称中心（所有已有蓝色像素最佳拟合的旋转中心点）。
2. 将所有蓝(1)像素分别旋转 90 度、180 度、270 度（顺时针），若旋转后的位置为黑(0)背景，则涂为红(2)。已有蓝(1)像素不变。
3. 识别由蓝(1)+红(2)像素共同围成的封闭区域——从网格边缘通过黑(0)背景（4-连通）无法到达的黑(0)连通区域。
4. 若某封闭区域内包含至少一个橙(7)标记像素，则将该区域中所有黑(0)像素涂为黄(4)，橙(7)标记像素本身保留不变。
5. 不含橙(7)标记的封闭区域保持黑(0)不变。
6. 对整个蓝(1)+红(2)形状添加外轮廓：每个不属于形状、不属于封闭区域、且 8-邻接至少一个蓝(1)或红(2)像素的黑(0)背景像素，涂为绿(3)。

**关键洞察**：橙色标记像素在输入中看似随意散布在开放的黑色区域中，只有完成旋转对称补全后才能判断哪些标记被封闭——补全操作创造了新的拓扑结构（封闭区域），这是输入中不存在的涌现现象，使得标记的语义在补全前后发生了根本变化。

## 新题 3：接触方向推移与尺寸排序色彩轮换

**组合逻辑**：[推移 push](已有) + [擦除 erase](已有) + [循环移位 cyclic_shift](创新：从精灵网格行位移改造为颜色属性的环形轮换) + [尺寸排序 size_ordering](创新：从竖条高度排序改造为任意图形面积排序)

**来源原语**：推移/擦除/接触侧决定方向/推至边界停止/固定标记(5623160b)、网格边界(5623160b)、循环移位(e78887d1)、尺寸排序(48634b99)

**依赖链**：接触侧 → 推移方向（空间决策链），面积排序 → 颜色环形轮换（属性决策链）。两条决策链正交：空间位置决定运动方向，尺寸大小决定颜色分配，缺少任一链则输出错误。

一句话总结：将与中央标记接触的各色对象推向其接触反方向的网格边界，同时按面积从小到大环形轮换它们的颜色。

**输入结构**：约 15x15 的网格，背景为黑(0)。网格中央区域有一簇栗(9)像素组成的固定标记（约 4-8 像素，形状紧凑但不规则，4-连通）。有 3-4 个不同颜色的单色 4-连通前景对象（每个 3-8 像素，形状不规则，像素数各不相同），每个对象恰好在一个基本方向（上、下、左、右之一）与栗(9)标记接触（即该对象至少有一个像素在该方向上与栗色像素 4-邻接，且不在其他方向与栗色像素邻接）。各对象颜色互不相同，从蓝(1)、红(2)、绿(3)、黄(4)中选取。生成约束：各对象像素数严格互不相等；每个对象向其推移方向移动后不会与其他已推移对象的最终位置重叠；四个基本方向中至少有三个方向各有一个对象。

**规则**：
1. 记录每个非栗色前景对象的原始颜色和像素数。
2. 按像素数从小到大排序所有对象，记为 O1, O2, ..., On（n 为对象数量）。
3. 将每个对象从原位擦除（恢复为黑(0)背景）。
4. 对每个对象，确定其与栗(9)标记接触的基本方向 d，将对象整体沿 d 的反方向平移，直到对象中最靠近该方向网格边界的像素恰好位于边界行/列上。
5. 执行颜色环形轮换：O1（最小）接收 O2 的原始颜色，O2 接收 O3 的颜色，...，On（最大）接收 O1 的原始颜色。
6. 栗(9)标记保持不变。

**关键洞察**：空间位置（接触方向）和尺寸属性（面积排序）是两个独立的排序维度，分别控制"去向何方"和"涂何颜色"。仅看单个示例可能猜出推移方向，但必须对比多个示例才能归纳出颜色轮换遵循面积排序而非空间位置排序。

## 新题 4：标记色编码射线间距与交叉检测重涂

**组合逻辑**：[射线延伸 ray_extension](已有) + [周期平铺 periodic_tiling](创新：周期长度不再固定，由标记颜色参数化) + [重涂色 recolor](创新：射线交叉点产生源题中不存在的第三种颜色)

**来源原语**：射线延伸/周期平铺/邻接侧决定方向/不覆盖源对象/十字图案/标记块(53fb4810)、标记色编码距离/标记像素(72a961c9)

**依赖链**：标记颜色 → 解码出周期间距参数 → 射线按该间距周期延伸 → 不同射线在空间交叉 → 交叉位置重涂新色。若不解码颜色，间距未知；若不做射线延伸，无交叉可言；若不检测交叉，则错过颜色变化。

一句话总结：从十字形物体的臂端向外发射周期性射线，射线重复间距由标记颜色编码，不同射线交叉处涂为特殊颜色。

**输入结构**：约 18x18 的网格，背景为黑(0)。灰(5)像素构成 1-2 个"+"形物体（每个由 5 像素组成：中心 + 四个基本方向各延伸 1 像素）。在每个"+"形的各臂端外侧，紧邻放置一个单像素标记，颜色为红(2)或蓝(1)。每个标记恰好与"+"的一个臂端像素 4-邻接，位于该臂的延伸方向上。每个"+"的四个臂端不一定都有标记，但至少有两个臂端有标记。生成约束：不同"+"形物体之间有足够间距，使得来自不同"+"（或同一"+"的不同臂）的射线在网格范围内至少存在一处空间交叉。

**规则**：
1. 对每个标记像素，确定它紧邻"+"形的哪一侧（上/下/左/右），由此确定射线方向为背离"+"中心的方向。
2. 将标记颜色解码为周期间距：红(2) → 间距 2（从标记位置起，沿射线方向每 2 格绘制 1 格），蓝(1) → 间距 3（从标记位置起，沿射线方向每 3 格绘制 1 格）。
3. 从紧邻标记的下一个位置起（标记本身保留原色），沿射线方向按解码的间距周期性绘制像素：第 1 个绘制位置距标记 1 格，此后每隔（间距-1）个空格绘制 1 格，颜色与标记相同，直到网格边界。
4. "+"形灰(5)像素不被覆盖；若射线绘制位置落在"+"形像素上，则跳过该位置。
5. 交叉检测：若某个位置同时被两条或更多不同射线覆盖（即该位置在多条射线的绘制计划中均应被着色），则该位置涂为黄(4)，而非任一射线的标记颜色。
6. 仅被一条射线覆盖的位置保持该射线对应的标记颜色。

**关键洞察**：标记颜色同时承担两个角色——它既是射线的绘制颜色，也编码了射线的重复周期间距。不同间距的射线在空间上交叉时产生第三种颜色（黄色），这是单条射线不会产生的涌现效应，只有理解了间距编码规则并正确计算交叉位置才能得出正确输出。

## 新题 5：图最短路径索引模板拼接

**组合逻辑**：[最短路径 shortest_path](已有) + [像素放大 pixel_expand](创新：不是对整个网格放大，而是对路径上节点的颜色索引模板后逐个拼接) + [裁剪 crop](已有)

**来源原语**：最短路径/图结构/节点方块/轨道段/终端节点/最短路径选择(7b0280bc)、像素放大/颜色到模板映射/模板遮罩/色卡/顺序配对(42f83767)、裁剪(5bd6f4ac)

**依赖链**：图最短路径 → 路径上节点颜色序列 → 每个颜色查图例获取模板 → 按路径顺序拼接模板得到输出。若不求最短路径，不知选哪些节点；若不查模板映射，不知输出内容；若不按路径顺序拼接，排列错误。

一句话总结：在方块-轨道图中找到两个终端之间的最短路径，将路径上各站点的颜色作为索引在图例中查找对应模板，按路径顺序左右拼接输出。

**输入结构**：约 20x20 的网格，背景为黑(0)。网格分为上下两个区域，中间至少隔 1 行黑(0)背景。上方区域（约前 5 行）为图例区：从左至右依次排列 3 个 2x2 单色色卡（颜色分别为红(2)、绿(3)、蓝(1)），每个色卡右侧间隔 1 列后跟随一个 3x3 灰(5)模板遮罩（由灰(5)前景像素和黑(0)背景像素构成的二值图案，每个模板形状不同——如对角线、十字、L形等），色卡与模板按从左至右出现顺序一一配对。相邻的色卡-模板对之间间隔至少 2 列。下方区域（约第 7 行起）为图区：若干 2x2 单色方块作为节点，通过灰(5) 1-像素宽轨道段（水平或垂直直线）连接，形成无向图。恰好有 2 个节点颜色为橙(7)，称为终端节点；其余节点的颜色从红(2)、绿(3)、蓝(1)中选取（即图例中出现的色卡颜色）。生成约束：两个终端之间存在唯一最短路径（按经过的边数计算）；最短路径上的非终端节点数量在 2-4 之间；同一颜色可出现在多个非终端节点上。

**规则**：
1. 在下方图区中，找到两个橙(7)终端节点之间的最短路径（经过边数最少的路径）。
2. 沿最短路径从左侧终端到右侧终端（若两终端在同一列，则从上方终端到下方终端），依次收集路径上所有非终端节点的颜色，形成有序颜色序列。
3. 对颜色序列中的每个颜色，在上方图例中找到同色的 2x2 色卡，取出其配对的 3x3 模板。
4. 将模板中的灰(5)像素重涂为该节点的颜色，黑(0)像素保持黑(0)。
5. 将所有重涂后的 3x3 模板按路径顺序从左至右排列，相邻模板之间间隔 1 列黑(0)背景。
6. 输出为拼接后的矩形（高 3 行，宽 = 模板数 x 3 + (模板数-1) x 1）。

**关键洞察**：图结构充当地址系统——最短路径不仅筛选出哪些节点参与输出，还通过路径遍历顺序决定了模板的排列次序。图区和图例区编码了输出的两个不同维度（选择哪些模板、以及模板的视觉内容），必须交叉引用才能求解。

## 新题 6：网格线补全界定单元格后周期修复

**组合逻辑**：[补全 completion](已有) + [填充 fill](已有) + [平铺 tiling](创新：周期平铺被限定在由前一步补全结果所确定的单元格边界内进行)

**来源原语**：补全/填充/网格线/缺口/相邻像素标有效线/缺口补另色/行列对齐(4612dd53)、平铺/周期瓦片/标记为缺失值/行列周期(f823c43c)

**依赖链**：网格线补全 → 确定单元格边界 → 在每个单元格内识别周期瓦片并修复缺失值。若不先补全网格线，则单元格边界不明确，无法正确分割区域以推断各自的周期；若不做周期修复，则缺失值未填补。

一句话总结：先修复断裂的蓝色网格线以确定单元格边界，然后在每个单元格内推断该单元格独有的周期图案并填补粉色标记处的缺失像素。

**输入结构**：约 15x15 的网格，背景为黑(0)。蓝(1)像素构成一组不完整的直线网格（若干水平线和竖直线），网格线上存在缺口（部分蓝色像素缺失，显示为黑色背景）。有效网格线的判定：某一行中存在至少一对水平相邻的蓝(1)像素 → 该行为有效水平线；某一列中存在至少一对垂直相邻的蓝(1)像素 → 该列为有效竖直线。补全后的网格线将空间分割为若干矩形单元格。在部分单元格内，存在由红(2)和绿(3)两种颜色构成的周期图案（如棋盘格、条纹、小方块重复等），但其中某些位置被品红(6)标记像素替代（表示缺失值）。不同单元格内的周期图案可以不同（行周期、列周期、颜色排列不同），但每个单元格内部的图案是自洽的单一最小周期。部分单元格可能完全为空（全黑(0)背景且无品红标记），无需处理。生成约束：每个含图案的单元格内，非品红像素足以唯一确定该单元格的最小行列周期瓦片；品红标记仅出现在含图案的单元格内，不出现在网格线上。

**规则**：
1. 识别有效网格线：行中存在至少一对水平相邻蓝(1)像素 → 该行整行为有效水平网格线；列中存在至少一对垂直相邻蓝(1)像素 → 该列整列为有效竖直网格线。
2. 在每条有效网格线上，将该行/列中所有黑(0)缺口像素涂为红(2)。
3. 补全后的蓝(1)+红(2)网格线将网格分割为若干矩形单元格（网格线本身不属于任何单元格）。
4. 对每个单元格，忽略品红(6)像素，从剩余的非黑(0)像素（即红(2)和绿(3)图案像素）中推断最小行列周期瓦片。
5. 将单元格内每个品红(6)像素替换为其在单元格内坐标（相对于单元格左上角）对应的周期瓦片中的颜色值。若该瓦片位置对应黑(0)背景，则替换为黑(0)。
6. 完全为空的单元格保持不变。

**关键洞察**：网格线修复和周期图案修复是两层级联的"补全"操作：第一层修复结构边界（网格线的缺口），第二层在第一层确定的边界内修复内容（单元格内的周期图案）。两层修复必须按序执行——单元格的范围直到网格线修复后才能确定，而周期推断依赖于正确的单元格划分。

## 新题 7：形状循环变换解码网格分块地址

**组合逻辑**：[形状变换 shape_transform](已有) + [裁剪 crop](已有) + [重涂色 recolor](已有) + [传输 transmit](创新：线路传递的不是形状本身，而是颜色信息作为重涂参数)

**来源原语**：形状变换/形状循环映射/令牌(a47bf94d)、传输/端点配对/线路网络(a47bf94d)、裁剪/网格分块/取角落分块(5bd6f4ac)、重涂色(48634b99)

**依赖链**：令牌形状循环变换 → 变换后的形状类型作为地址索引 → 从网格分块中裁剪对应区块 → 线路终端的颜色决定裁剪区块的重涂色。四步中任一步缺失或顺序错误则无法得到正确输出。

一句话总结：将 3x3 令牌做一步形状循环变换，用变换后的形状类型选定 3x3 区块阵列中的对应区块并裁剪输出，区块中的前景色改为线路另一端指示像素的颜色。

**输入结构**：约 19x19 的网格，背景为黑(0)。网格主体为一个 3x3 排列的区块阵列，每个区块 5x5，区块之间由 1 像素宽的灰(5)分隔线隔开（阵列整体占 17x17，分隔线在第 5、11 列和第 5、11 行）。每个 5x5 区块内包含一个由灰(5)像素组成的小图案（4-连通，3-8 像素，各区块图案不同且形状不规则）。在网格主体右侧或下方的空白区域，放置一个 3x3 令牌——三种形状之一：实心块（全部 9 个像素填充）、X 形（4 个角像素 + 中心像素共 5 像素）、或菱形（中心 + 上下左右 4 个像素共 5 像素），令牌颜色为栗(9)。从令牌中心出发，一条 1 像素宽的栗(9)线路（水平或垂直直线，或一次直角折线）连接到一个孤立的单像素指示像素，该指示像素的颜色从红(2)、绿(3)、蓝(1)、黄(4)中选取。生成约束：令牌形状在不同示例中不同（以便求解者归纳形状→位置映射）；指示像素颜色在不同示例中可能不同。

**规则**：
1. 对令牌执行一步形状循环变换：实心块 → 菱形，菱形 → X 形，X 形 → 实心块。
2. 变换后的形状类型映射到 3x3 区块阵列中的位置：菱形 → 第 0 行第 2 列（右上角区块），X 形 → 第 1 行第 1 列（正中央区块），实心块 → 第 2 行第 0 列（左下角区块）。
3. 裁剪出对应位置的 5x5 区块（仅含区块内容，不含分隔线）。
4. 沿令牌的栗(9)线路找到另一端的指示像素，读取其颜色。
5. 将裁剪出的 5x5 区块中所有灰(5)前景像素重涂为指示像素的颜色，黑(0)背景像素保持不变。
6. 输出为重涂后的 5x5 区块。

**关键洞察**：令牌的形状不是直接输出的视觉内容，而是经过一步循环变换后充当"地址"——它指定去九宫格的哪个区块提取数据。令牌本身在输出中不出现，线路仅传递颜色信息用于重涂。形状的含义是间接的（需先变换再解码为位置），这与参考题中令牌直接作为视觉输出物的用法截然不同。
