## 新题 1：噪声量编码条纹排序权重

**组合逻辑**：[去噪/denoise] + [计数/counting](创新：噪声数量作为排序键) → [重排/rearrange](创新：按噪声键垂直重排行)

**来源原语**：去噪、主色占优、条纹行列、噪声像素（参考题 e26a3af2）；计数（参考题 edcc2ff0/54db823b/6455b5f5）；重排、基线对齐（参考题 3d6c6e23）

**依赖链**：噪声计数提取排序键 → 去噪销毁噪声但保留干净条纹 → 按已提取的键对干净条纹重排。排序键在去噪时被销毁，因此必须先计数后去噪；去噪后的单色行才能正确排列，因此必须先去噪后重排。三步缺一不可。

将含噪水平条纹的网格清洗并按每行噪声像素数从少到多自上而下排列。

**输入结构**：一个约 8x12 的矩形网格，黑(0)为背景。网格由水平色带行组成——每行有一个主色（非黑，取自 1-9 中的若干种），同时散布 0-3 个噪声像素（颜色与该行主色不同，可为任意非主色颜色或黑色）。不同行的主色可以相同也可以不同。每行至少有 60% 像素为主色，确保主色唯一可辨。各行的噪声数量互不相同（保证排序无歧义）。

**规则**：
1. 对每一行，统计噪声像素数量（与该行主色不同的像素数），记为该行的"权重"。
2. 去噪：将每一行所有像素替换为该行的主色，得到纯色行。
3. 将所有纯色行按权重从小到大自上而下排列。权重最小的行排在最顶部，权重最大的行排在最底部。
4. 输出排列后的纯色行组成的网格（尺寸不变）。

**关键洞察**：噪声像素具有双重身份——它既是需要清除的污染，又是编码最终行序的隐藏参数。排序键在去噪过程中被不可逆地销毁，求解者必须意识到噪声数量"先用后弃"的时序约束。

## 新题 2：图元分解计数选择镜像源象限

**组合逻辑**：[分解/decompose] → [重涂色/recolor](图元形状决定涂色) → [计数/counting](创新：按象限统计特定图元数量) → [镜像/mirror](创新：计数结果选择源象限，而非固定象限)

**来源原语**：分解、基本图元、图元形状决定涂色（参考题 150deff5）；镜像、双轴反射四象限、阵列排布（参考题 3af2c5a8）；计数、面积比较（参考题 6455b5f5）

**依赖链**：分解决定每个图元的形状类型 → 形状决定涂色 → 涂色后才能按颜色分类计数 → 各象限的方块图元计数决定哪个象限做镜像源 → 镜像操作传播的是分解重涂后的内容而非原始灰色。每一步的输出实质改变下一步的输入。

将网格中的灰色区域分解为基本图元并按形状涂色，然后以方块图元最多的象限为源做双轴镜像填充全图。

**输入结构**：一个偶数边长的正方形网格（约 12x12 或 14x14），黑(0)背景。网格由中心行和中心列隐式分为四个等大象限（无可见分隔线）。每个象限内有一个或多个连通的灰(5)前景区域（3-12 像素，4-连通，不跨越象限边界）。每个灰色连通区域可被唯一地分解为非重叠的 2x2 正方形和 1x3 或 3x1 矩形的组合。各象限的 2x2 正方形图元数量互不相同（保证源象限唯一）。

**规则**：
1. 对整个网格中所有灰(5)连通区域执行图元分解：找到将每个区域恰好覆盖为 2x2 正方形和 1x3（或 3x1）矩形的唯一非重叠分解。
2. 将每个 2x2 正方形图元涂为青(8)，每个 1x3/3x1 矩形图元涂为红(2)。
3. 统计每个象限中青(8)正方形图元的数量。
4. 青(8)图元数量最多的象限为"源象限"。
5. 将源象限的内容（含涂色后的图元和黑色背景）通过双轴镜像填充其余三个象限：水平相邻象限做左右翻转，垂直相邻象限做上下翻转，对角象限做 180 度旋转。镜像覆盖目标象限的全部内容。

**关键洞察**：源象限不是固定的，而是由分解结果决定的——同一个灰色区域在不同分解下可能产生不同的正方形数量，因此求解者必须先正确分解才能判断源象限。镜像传播的是涂色后的图案而非原始灰色。

## 新题 3：标记颜色定向移动后距离编码拉伸量

**组合逻辑**：[移动/move](颜色决定目标边) + [计数/counting](创新：记录移动前的垂直距离) → [擦除/erase] → [拉伸/stretch](创新：拉伸量来自标记原始距离而非外部锚点)

**来源原语**：移动、边框、颜色匹配边、颜色决定目标边（参考题 d687bc17）；拉伸、空心矩形、标记决定拉伸终点（参考题 b548a754）；擦除（参考题 d687bc17/edcc2ff0）

**依赖链**：标记的颜色确定它要移动到的边 → 标记的原始位置到目标边的距离编码了该边的拉伸量 → 移动后标记到达边沿，距离信息被消耗 → 按已记录的距离对各边执行拉伸。标记像素同时编码方向（颜色）和位移量（位置），两条信息从同一像素中提取但驱动不同操作。

将框内标记按颜色移至匹配边，并按标记原始距离拉伸该边。

**输入结构**：一个约 15x15 的网格，黑(0)背景。中央有一个一像素宽的空心矩形框，框的四条边各用不同颜色：上边蓝(1)、下边绿(3)、左边红(2)、右边黄(4)。框的四角为黑(0)。框的内部（黑色区域）散布 1-4 个标记像素，每个标记的颜色与四条边中的恰好一条相同。不同标记可以匹配同一条边。生成约束：每个标记到其匹配边的垂直/水平距离至少为 2，且拉伸后框不超出网格边界。

**规则**：
1. 对每个框内标记像素，记录它到匹配颜色边的垂直距离（若匹配上/下边）或水平距离（若匹配左/右边），记为 d。
2. 将所有内部标记像素擦除（设为黑色）。
3. 对每条有匹配标记的边，将该边向外拉伸 d 个像素。若同一边有多个标记，取最大距离。无匹配标记的边不动。
4. 按拉伸后的新尺寸重绘空心矩形框（保持原来的四边颜色、一像素宽度、黑色角和黑色内部）。
5. 框外保持黑色背景。

**关键洞察**：每个标记像素是一个二维编码器——其颜色通道选择拉伸方向，其空间坐标通道量化拉伸幅度。这两条信息在标记被擦除后均不可再读取，因此必须在同一遍扫描中同时提取。

## 新题 4：周期推断修复图例后展开标记

**组合逻辑**：[周期推断/periodic_inference] → [间隙填充/gap_filling](创新：作用于边缘图例串而非内部瓦片) → [展开/expand](图例锚定对齐)

**来源原语**：周期推断、间隙填充、忽略缺失值推断、周期瓦片、缺失像素（参考题 1d0a4b61）；展开、边缘图例串、孤立标记、颜色位置匹配、图例锚定对齐（参考题 5af49b42）

**依赖链**：图例串有缺损 → 周期推断从可见部分恢复完整图例 → 恢复后才能确定每种颜色在图例中的唯一位置 → 位置决定展开的锚点偏移 → 展开操作使用完整图例。若图例有黑洞则无法确定锚点；若不展开则标记未变换；两步形成不可跳过的推理链。

先推断并修复带缺损的周期图例串，再以修复后的图例展开内部标记像素。

**输入结构**：一个约 12x15 的网格，灰(5)背景。
- 顶部第 0 行为一条水平图例串，由若干种前景色按短周期（2-4 个像素为一个重复单元）排列而成，但其中 1-3 个位置被替换为黑(0)（缺失数据）。图例的完整周期中每种颜色只出现一次。
- 网格内部散布若干孤立的单像素标记，每个标记的颜色恰好在完整图例中出现于唯一一个位置。标记不位于第 0 行。标记之间的行距足够大，使得展开后的图例串在行方向上互不干扰。
- 生成约束：图例的每个周期相位至少在一个非黑位置可见，确保周期可被唯一推断。

**规则**：
1. 将图例串中的黑(0)像素视为缺失数据。找到与所有非黑像素一致的最小重复周期，用该周期的相应相位颜色填补所有黑色缺失位置，得到完整图例串。
2. 对网格内部每个孤立标记像素：在完整图例中找到该标记颜色所在的唯一位置索引 k。
3. 将完整图例串水平复制到标记所在行，水平平移使得图例的第 k 个位置恰好对准标记像素的列坐标。
4. 复制的图例串超出网格左右边界的部分裁剪丢弃。
5. 图例串覆盖时，后处理的标记行覆盖先处理的（按标记行号从上到下依次处理）。

**关键洞察**：图例本身是残缺的——部分颜色只出现在被破坏的位置，直接查找会找不到。必须先利用周期性恢复完整图例，才能确定每种标记颜色的锚点索引。周期推断和展开操作通过"图例完整性"这一信息桥梁不可分割地耦合在一起。

## 新题 5：筛选后物体总数编码场景循环位移

**组合逻辑**：[计数/counting] + [擦除/erase](标记色筛选物体) → [计数/counting](创新：存活物体总数成为位移参数) → [循环位移/cyclic_roll] → [裁剪/crop]

**来源原语**：计数、擦除、指示条、标记色筛选物体、条长等于物体计数（参考题 edcc2ff0）；循环位移、裁剪、控制列、标记位定位移量（参考题 6d1d5c90）

**依赖链**：指示条标记颜色决定场景中哪些物体存活 → 存活物体数量决定指示条条长并同时作为循环位移量 → 位移应用于筛选后的场景 → 裁剪去除指示条。筛选决策和位移参数从同一次计数中同时产生，不可拆分为独立子问题。

用指示条筛选场景物体，存活物体的总数决定场景的垂直循环滚动量。

**输入结构**：一个约 12x15 的网格，分为上下两部分：
- 上部指示条区（约 3 行）：黑(0)背景，第 0 列每行各有一个彩色单像素标记（1-3 个标记，颜色各异）。
- 下部场景面板（其余行）：有一种非黑的统一背景色（如灰(5)），其上散布若干 4-连通前景物体，颜色取自 2-4 种。
- 标记颜色都是场景中出现的物体颜色的子集。
- 生成约束：存活物体的总数不超过场景面板的行数（确保循环位移有意义且不退化为恒等变换），且总数大于 0。

**规则**：
1. 对指示条中的每种标记颜色，统计场景面板中该颜色的 4-连通物体数量。
2. 在指示条中，将每个标记替换为从第 0 列开始的水平同色条，长度等于该颜色的物体计数。计数为 0 的标记擦除。
3. 场景面板中，颜色不在标记集合中的前景物体全部涂为场景背景色（即擦除）。
4. 将所有标记颜色的物体计数求和，得到总数 S。
5. 将筛选后的场景面板整体向下循环位移 S 行（底部溢出的行从顶部重新进入）。
6. 输出仅包含位移后的场景面板（指示条区域移除）。

**关键洞察**：指示条执行双重功能——它既是颜色筛选器（决定哪些物体存活），又是位移量编码器（存活物体总数 = 滚动行数）。位移量不是独立参数，而是从筛选结果中涌现的：改变筛选标记会同时改变存活的物体和滚动距离，两者不可独立调整。

## 新题 6：对称修复后识别周期并向下延伸

**组合逻辑**：[对称补全/symmetric_completion](控制标记指示源侧) → [补全/completion] + [平移/translate](创新：对称修复后的行图案才展现周期平移结构)

**来源原语**：对称补全、对称轴、控制标记、控制标记指示源侧、轴对称反射（参考题 5b692c0f）；补全、平移、行图案、画布、周期平移、周期偏移延续行（参考题 53b68214）；对称轨道、掩码像素（参考题 3631a71a）

**依赖链**：图案的一侧被损坏 → 控制标记标识可信侧 → 镜像修复损坏侧 → 修复后的完整行才呈现周期平移结构 → 由周期和偏移量向下延伸至目标行数。若不先修复对称，损坏像素会干扰周期检测；若不执行周期延伸，输出行数不足。

先修复半边损坏的对称图案，再利用修复后显现的周期平移规律向下补全网格。

**输入结构**：一个宽 10、高 4-6 行的矩形网格。
- 背景色为黑(0)，前景用一种非黑颜色（如蓝(1)）。
- 网格包含一条垂直的黄(4)轴线（单像素宽，贯穿所有行），以及一个偏离轴线的黄(4)控制像素，位于轴线某一侧。
- 控制像素所在侧（源侧）的前景图案是完整正确的。
- 另一侧（目标侧）有 1-3 个前景像素被替换为灰(5)（掩码色）。
- 源侧的行图案在垂直方向上呈现固定周期 p（2 或 3 行）和固定水平偏移 dx 的平移序列关系，但目标侧因掩码污染而无法直接观察到该周期性。
- 生成约束：网格高度小于 10，且 p 和 dx 可从源侧唯一确定。

**规则**：
1. 识别黄(4)轴线和控制像素。控制像素所在侧为源侧。
2. 将源侧的前景/背景图案镜像到目标侧，替换所有灰(5)掩码像素。同时移除黄(4)轴线和控制像素（设为背景色黑(0)），得到修复后的完整行。
3. 从修复后的完整行中推断最小垂直周期 p 和水平偏移 dx：即每隔 p 行，行内的前景像素整体水平移动 dx 列（循环取模）。
4. 将修复后的行复制到一个宽 10、高 10 的黑色画布的顶部。
5. 对于缺失的底部行（第 h 行到第 9 行），每行的图案等于其上方第 p 行的图案水平移动 dx 列后的结果。超出网格边界的像素丢弃。

**关键洞察**：掩码损坏隐藏了周期结构——如果直接对含掩码的行做周期检测，会得到错误的周期或偏移。求解者必须先信任控制标记指示的源侧、通过镜像修复另一侧，然后才能在干净数据上推断周期平移规律。对称修复是周期检测的前提条件，而非独立步骤。

## 新题 7：区域内同心环计数决定极值区域涂色

**组合逻辑**：[填充/fill](创新：在分隔区域内画同心环) + [裁剪/clip](环裁剪到区域边界) → [计数/counting](创新：计数对象是前景环像素而非物体) → [面积比较/area_comparison] → [重涂色/recolor](极值区域分别涂色)

**来源原语**：填充、同心环、角标记像素、奇偶距离决定填色、最近归属（参考题 d22278a0）；分隔线、封闭区域、面积比较、极值区域分别涂色、重涂色、计数（参考题 6455b5f5）；裁剪/clip（参考题 d22278a0）

**依赖链**：标记位置决定环形几何 → 环在区域边界处被裁剪 → 裁剪后的前景像素数量取决于标记位置与区域形状的交互 → 各区域的前景数量排名决定最终涂色。标记位置同时控制环图案和统计排名，一像素之差可能翻转结果。

在被分隔线划分的各区域内，以标记为中心画同心方环，然后按前景环像素数量给极值区域整体重涂色。

**输入结构**：一个约 15x15 的网格，黑(0)背景。红(2)分隔线（单像素宽，水平和垂直）将网格分割为若干矩形区域（4-6 个区域）。每个区域内部恰好有一个彩色标记像素（颜色非红(2)非黑(0)，各区域标记颜色互不相同）。标记不位于区域边缘行/列。各区域面积可以不同。生成约束：各区域的最终前景像素计数互不相同，保证极值唯一。

**规则**：
1. 对每个区域，以其内部标记像素为中心，计算区域中每个非分隔线像素到标记的切比雪夫距离 d。
2. 将切比雪夫距离为偶数（含 0）的像素涂为该标记的颜色，距离为奇数的像素保持黑(0)。这在每个区域内产生围绕标记的同心方环图案，自然裁剪于区域边界。
3. 红(2)分隔线保持不变。
4. 统计每个区域中被涂色的前景像素总数（即偶数距离像素的数量）。
5. 前景像素数量最多的区域：将该区域所有已涂色像素（偶数距离位置）重涂为蓝(1)，奇数距离位置保持黑(0)。
6. 前景像素数量最少的区域：将该区域所有已涂色像素重涂为青(8)，奇数距离位置保持黑(0)。
7. 其余区域保持各自标记颜色的环图案不变。

**关键洞察**：前景像素计数不仅取决于区域面积，还取决于标记在区域内的偏心程度——靠近角落的标记产生的环弧会被大量裁剪，即使区域很大也可能前景像素少于较小但标记居中的区域。标记位置与区域形状的几何交互决定了统计排名，这一关系在单个示例中难以归纳。

## 新题 8：条纹噪声中的图例标记双重身份

**组合逻辑**：[去噪/denoise](主色覆盖全列) + [展开/expand](图例锚定对齐)（创新：噪声像素中的一部分同时是图例标记，需在去噪前识别分离） → [重涂色/recolor]

**来源原语**：去噪、条纹行列、噪声像素、主色占优、主色覆盖全行列（参考题 e26a3af2）；展开、边缘图例串、孤立标记、颜色位置匹配、图例锚定对齐（参考题 5af49b42）；重涂色（参考题 150deff5/edcc2ff0）

**依赖链**：网格是垂直条纹 + 噪声的叠加，部分噪声像素的颜色恰好出现在底部图例中 → 这些像素是"图例标记"而非普通噪声 → 必须在去噪前识别并记录它们的位置和颜色 → 去噪时将所有噪声（含标记）清除为条纹主色 → 在干净条纹上，于每个标记的原始位置展开图例串。去噪和展开不可互换：先展开会在噪声背景上产生错误叠加，先去噪会销毁标记信息。

识别垂直条纹中嵌入的图例标记像素，去噪后在标记原始位置展开底部图例串。

**输入结构**：一个约 12x12 的网格。
- 网格主体为垂直色带条纹——每列有一个主色（非黑），占该列至少 70% 的像素。
- 散布若干噪声像素（与所在列主色不同的像素）。噪声像素分两类：(a) 普通噪声——颜色不出现在底部图例中；(b) 图例标记——颜色出现在底部图例中。求解者需通过颜色匹配区分两类。
- 最底行（最后一行）为一条水平图例串，包含若干种颜色按固定顺序排列。图例串中每种颜色只出现一次。图例串不参与条纹结构（不受去噪影响）。
- 图例标记不位于最底行，且每个标记的颜色在图例中有唯一对应位置。
- 生成约束：各列的主色都不出现在图例串中（确保主色与图例颜色集合不交叉）；同一行上不会有多个图例标记的展开区域重叠。

**规则**：
1. 识别最底行的图例串及其颜色序列。
2. 对网格中非最底行的每个像素，判断其是否为噪声（与所在列主色不同）。若是噪声且其颜色出现在图例串中，标记为"图例标记"并记录其行、列坐标和颜色。
3. 去噪：对非最底行的每一列，将所有像素替换为该列的主色（噪声和标记均被覆盖）。最底行的图例串保持不变。
4. 对每个已记录的图例标记：在图例串中找到该颜色的位置索引 k。将完整图例串水平复制到该标记原始所在行，水平平移使图例第 k 个位置对齐标记的原始列坐标。超出网格左右边界的部分裁剪。图例串覆盖该行的条纹颜色。
5. 多个标记按其行号从上到下依次处理，后处理的覆盖先处理的（同行不会有冲突，由生成约束保证）。
6. 输出完整网格（含最底行图例）。

**关键洞察**：噪声像素中隐藏着一类具有语义的"图例标记"，它们与普通噪声在外观上无法区分——唯一的甄别依据是其颜色是否出现在图例串中。去噪操作会不加区分地清除两类噪声，因此求解者必须在去噪前通过颜色交叉比对完成标记识别。信息的提取（标记识别）和销毁（去噪）在时序上形成不可逆耦合。
