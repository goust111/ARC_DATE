## 1. 射线穿仓连锁

- 参考题目题号：9（212895b5）、19（3ad05f52）、15（fe9372f3）
- tags:
  - operation:射线延伸, ray_extension
  - operation:连锁填充, chain_fill
  - object:实心方块, solid_square
  - object:框架房间, framed_room
  - object:阻挡像素, blocker_pixel
  - relation:轴线穿透, axis_penetration
  - condition:对准中心轴才透光, center_axis_alignment_required

### docstring

```text
从实心方块发出的四条射线穿过对准中心轴的空心房间并点亮它们，被散点与未对准的房间截断。

输入结构
- 黑色背景上有一个 3×3 实心红色方块作为源。
- 若干灰色空心正方形房间：奇数边长、一格厚的框架，内部为黑。
- 若干蓝色散点像素。

规则
- 从红色方块四条边的中点向外各发射一条一格粗的红色射线。
- 射线遇到网格边缘停止，遇到蓝色散点在其前一格停止。
- 若射线命中某房间外壁且恰好对准该房间的中心行或中心列，则该房间
  内部全部涂红，射线从对侧壁外的对齐格继续延伸，可依次穿过多个房间。
- 若命中位置未对准房间中心轴，射线在壁前一格停止，该房间不涂色。

关键洞察
- 房间不是障碍而是可穿透的珠子，但只有沿中心轴命中才透光点亮；
  真正的障碍是散点与偏轴命中的壁。
```

## 2. 双面板周期修复后取交

- 参考题目题号：14（ca8f78db）、18（f2829549）
- tags:
  - operation:周期推断, period_inference
  - operation:遮挡复原, occlusion_restoration
  - operation:逻辑运算, logical_operation
  - object:等宽面板, equal_width_panel
  - object:分隔列, separator_column
  - object:遮挡矩形, occluding_rectangle
  - relation:逐格比较, cell_comparison
  - condition:先复原再取交, restore_before_intersection

### docstring

```text
先分别复原两侧被遮挡的周期图案，再输出两侧同为前景处的绿色交集。

输入结构
- 中央一列灰色分隔线把网格分成等宽的左右面板。
- 每个面板是黑背景加单一前景色的周期性二维图案，两侧前景色不同、
  周期也不同。
- 每个面板各自被若干品红色矩形遮挡。

规则
- 把品红像素视为未知，对每个面板分别推断与全部可见像素一致的最小
  周期矩形，并平铺复原整个面板。
- 输出一个面板大小的网格：在两侧复原结果同为前景色的格子涂绿，
  其余为黑。

关键洞察
- 直接对可见像素取交在部分格子上碰巧正确，但被遮挡处必须先各自
  完成周期复原；两个面板的周期互不相同，需要分别推断。
```

## 3. 长度铸环

- 参考题目题号：4（beb8660c）、16（8fff9e47）
- tags:
  - operation:长度编码, length_encoding
  - operation:同心环构造, concentric_ring_construction
  - object:线段, segment
  - object:嵌套层, nested_layer
  - relation:长度映射环边长, length_maps_to_ring_side
  - relation:方向映射环边, orientation_maps_to_ring_edges
  - condition:位置为干扰, position_is_distractor

### docstring

```text
把散落线段按长度铸成同心方环，水平线段提供环的上下边、竖直线段提供左右边。

输入结构
- 黑背景上散布若干一格粗的单色线段，有水平也有竖直，颜色各异、
  位置随意。
- 所有长度为奇数，同一方向内长度互不相同。

规则
- 输出一个边长等于最长线段长度的正方形网格。
- 每条长为 L 的线段对应以输出中心为中心、边长为 L 的正方形空心环：
  水平线段用自己的颜色涂该环的上、下两条水平边（含四角），
  竖直线段涂左、右两条竖直边（不含角）。
- 没有任何线段对应的长度，其环保持黑色；长度为 1 的线段对应中心单格。

关键洞察
- 线段的位置与出现顺序全是干扰，长度就是环的边长，方向决定它为环
  贡献哪两条边；同一长度的一横一竖会合成一个双色完整环。
```

## 4. 缺角为箭，颜色互换

- 参考题目题号：3（3aa6fb7a）、9（212895b5）、13（642248e4）
- tags:
  - operation:补全, completion
  - operation:射线延伸, ray_extension
  - operation:颜色互换, color_exchange
  - object:缺角L形, corner_missing_l_shape
  - object:散点目标, scattered_target_pixel
  - relation:缺角编码方向, missing_corner_encodes_direction
  - condition:线取点色点取线色, reciprocal_recoloring
  - condition:忽略干扰项, ignore_distractors

### docstring

```text
每个缺角 L 沿缺角所指的对角方向认领一个散点，连线取散点的颜色，散点反被改涂为该 L 的颜色。

输入结构
- 黑背景上有若干单色 L 形对象（2×2 正方形缺一角的三格），颜色各异。
- 另有若干颜色各异的孤立散点像素，其中一部分不在任何 L 的对角视线上。

规则
- 为每个 L 用自身颜色补上缺角；从 2×2 中心指向缺角的对角方向是该 L
  的朝向。
- 沿此方向看出去，若存在散点，取最近的一个为目标：从补角格外一格起
  到目标前一格止画一条对角连线，连线颜色取目标散点原来的颜色，同时
  把目标散点改涂为该 L 的颜色。
- 若该方向上没有散点，则只补角、不画线。
- 未被任何 L 认领的散点保持原色不变。

关键洞察
- 缺失的角是隐藏的箭头，既要补全又指明方向；连线与目标发生颜色互
  换——线取点色、点取 L 色，输出里颜色的流向与直觉相反，而不在视线
  上的散点只是干扰。
```

## 5. 液位驱动位移

- 参考题目题号：8（b0c4d837）、13（642248e4）
- tags:
  - operation:计数, counting
  - operation:平移, translate
  - operation:重涂色, recolor
  - object:U形容器, u_shaped_container
  - object:边缘条, edge_bar
  - object:控制像素, control_pixel
  - relation:行区间归属, row_range_association
  - condition:朝近端移动, toward_nearer_bar
  - condition:余量映射步数, headspace_maps_to_steps

### docstring

```text
每个标记朝较近的边条移动，步数等于其所属容器液面之上的空行数，落点涂成边条的颜色。

输入结构
- 最左列与最右列是两条完整的不同色竖直边条。
- 中间黑背景里有若干灰色 U 形容器，每个容器内有黄色底对齐液体。
- 每个容器的内部行范围内另有一个青色单像素标记位于容器之外；
  标记到两条边条的水平距离保证不相等，移动路径保证畅通。

规则
- 对每个标记，找到内部行范围覆盖它所在行的容器，数出该容器内部
  液面之上的空行数 h。
- 把标记沿水平方向朝较近的边条移动 h 格，移动后的像素改涂为该边条
  的颜色，原位清为背景。
- 容器、液体与边条保持不变。

关键洞察
- 一次移动的三个要素来源各不相同——方向由较近的边条决定，步数由
  所属容器的空余量（不是液体高度）决定，颜色由目标边条提供。
```

## 6. 自掩码镜像壁纸

- 参考题目题号：6（973e499e）、7（c48954c1）
- tags:
  - operation:像素放大, pixel_scale
  - operation:掩码映射, mask_mapping
  - operation:镜像, mirror
  - object:全局掩码, global_mask
  - object:块单元, block_cell
  - relation:自身色选掩码, self_color_selects_mask
  - condition:槽位奇偶选反射, slot_parity_selects_reflection

### docstring

```text
每个像素展开成整幅网格的同色自掩码块，块的朝向按槽位行列奇偶做上下或左右翻转。

输入结构
- 输入是一个全部为前景色的小网格（无黑格）。
- 黑色只在输出中作为空位出现。

规则
- 输出把每个输入像素 (r,c) 替换为一个与输入同形的块。
- 块内容先取自掩码：输入中颜色等于该像素颜色的位置写该颜色，
  其余写黑。
- 再按槽位坐标变换朝向（行列均从 0 计）：c 为奇数则左右翻转，
  r 为奇数则上下翻转，行列都为奇数则两个方向都翻。

关键洞察
- 块的内容由像素颜色挑选全局掩码，块的朝向由槽位奇偶挑选反射，
  两条规则独立复合；只有掩码本身不对称时翻转才可见。
```

## 7. 量体裁框

  - operation:转置, transpose
  - operation:形状匹配, shape_matching
  - object:角标记, corner_marker
  - object:前景对象, foreground_object
  - relation:尺寸配对, size_based_assignment
  - condition:互换尺寸需转置, swapped_dims_require_transpose

### docstring

```text
每个对象平移进内部尺寸与其包围盒相符的四角标记框，尺寸互换时先沿主对角线转置再放入。

输入结构
- 黑背景上有若干组黄色四角标记，每组恰好标出一个矩形的四个角，
  各矩形内部尺寸互不相同。
- 另有等数量的单色 4 连通对象，颜色各异，包围盒尺寸互不相同。
- 每个对象恰有唯一一个匹配框。

规则
- 若对象包围盒 h×w 与某框内部尺寸直接相等，将对象平移放入该框内部，
  包围盒与内部对齐。
- 若只与 w×h 相等，则先把对象沿主对角线转置再放入。
- 对象原位清空，角标记保持不变。

关键洞察
- 配对依据是尺寸而不是距离或颜色；互换尺寸的配对要求转置——是对角
  反射而非旋转，用手性对象才能分辨二者。
```

## 8. 对角重力与镜像验收

- 参考题目题号：17（9dfd6313）、4（beb8660c）、10（8be77c9e）
- tags:
  - operation:滑动, sliding
  - operation:对称检验, symmetry_test
  - operation:重涂色, recolor
  - object:对角线, diagonal_axis
  - object:前景对象, foreground_object
  - relation:斜向重力, diagonal_gravity
  - relation:跨轴镜像配对, cross_axis_mirror_pairing
  - condition:互为镜像则涂绿, mirror_pair_recolored_green

### docstring

```text
所有对象沿斜向滑落到主对角线上堆积，落定后跨对角线互为镜像的一对整体涂绿。

输入结构
- 正方形网格的主对角线是一条完整灰线。
- 对角线两侧散布若干单色小对象，颜色各异。

规则
- 每个对象沿垂直于主对角线的斜向滑动（每步行列各变一格，朝对角线
  一侧），直到贴上灰线或先落定的对象为止；离对角线近的对象先落定。
- 全部落定后，若某两个分居两侧的对象关于主对角线恰好互为镜像
  （位置与形状经转置后完全重合），则这一对对象全部改涂绿色。
- 其余对象保持原色，灰线不变。

关键洞察
- 重力方向是斜的而不是上下左右；滑动只是前置，真正的判定是落定后
  跨对角线的镜像配对测试，配对结果由初始形状与落点共同决定。
```

## 9. 边序为钥，螺旋为锁

- 参考题目题号：8（b0c4d837）、15（fe9372f3）
- tags:
  - operation:序列读取, sequence_reading
  - operation:螺旋填充, spiral_fill
  - object:边界像素, border_pixel
  - object:空心框, hollow_frame
  - relation:边序映射填序, border_order_maps_fill_order
  - condition:基数方向循环填, cyclic_color_fill
  - condition:间距为干扰, spacing_is_distractor

### docstring

```text
按顺时针读出的边界像素颜色序列，沿顺时针螺旋循环填满空心框的内部。

输入结构
- 黑背景；网格最外圈边界上散布若干彩色像素。
- 网格中部有一个灰色空心矩形框，内部全黑；内部格数不是边界像素数
  的整数倍。

规则
- 从网格左上角起沿边界顺时针方向依次读取彩色像素，得到循环颜色钥匙。
- 在框内部从其左上格起，沿顺时针螺旋向内逐格填色，循环使用钥匙序列
  直到内部填满。
- 边界像素与灰框保持不变。

关键洞察
- 边界像素的间距与所在边都是干扰，只有顺时针顺序有意义；读取与填充
  是同一条顺时针、左上锚定的走线在两个尺度上的重演。
```
