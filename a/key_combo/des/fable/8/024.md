## 1. 深度图例重排

- 参考题号: 3 (ea32f347)、15 (281123b4)、20 (e99362f0)、6 (f4081712)
- tags:
  - operation:透明叠加, transparent_overlay
  - operation:遮挡恢复, occlusion_recovery
  - operation:排序, sorting
  - operation:裁剪, crop
  - object:实心矩形, solid_rect
  - object:细条, thin_bar
  - object:分隔线, separator_line
  - relation:同色配对, same_color_pairing
  - relation:长度排名, length_ranking
  - condition:排名决定图层顺序, rank_determines_layer_order

### docstring

```text
依照图例条的长度排名重新决定重叠矩形的前后层序，并重绘整块画布。

输入结构
- 网格由一条满宽灰色分隔线分为上方画布与下方图例区。
- 画布为黑底，数个互相重叠的异色实心矩形按某个隐藏层序绘制而成，
  每个矩形的四条边都至少有一段未被遮挡。
- 图例区为若干水平细条，颜色与画布矩形一一对应，长度互不相同。

规则
- 由可见部分恢复每个矩形的完整范围（四边均有可见段，故完整边界可唯一还原）。
- 图例条越长，对应颜色的矩形在输出中的图层越靠上。
- 按此层序自底向上重绘所有完整矩形；输出仅画布部分，不含分隔线与图例区。

关键洞察
- 图例条不是装饰而是深度表：输入中呈现的遮挡关系是干扰信息，
  真实层序由长度排名给出；且重绘前必须先从可见边框把被遮挡的矩形范围推理还原，
  因为换序后原本被盖住的部分会重新露出。
```

## 2. 动画去噪并预测下一帧

- 参考题号: 8 (351d6448)、9 (0607ce86)、13 (20981f0e)
- tags:
  - operation:序列外推, sequence_extrapolation
  - operation:投票恢复, majority_vote_recovery
  - operation:平移, translate
  - object:面板, panel
  - object:分隔行, separator_row
  - object:精灵, sprite
  - relation:等距堆叠, equally_spaced_stacking
  - condition:恒定偏移平移, constant_offset_translation
  - condition:忽略噪声, ignore_noise

### docstring

```text
从五帧含噪动画中恢复干净精灵，并输出按恒定位移外推的第六帧。

输入结构
- 网格由满宽分隔行分成五个等大的黑底面板，构成一条动画带。
- 同一个多色精灵每帧按恒定向量平移。
- 每帧的精灵有零至两个像素被破坏（被抹成背景或改成错误颜色）；
  精灵同一相对位置的像素在至少四帧中保持正确。

规则
- 识别精灵的逐帧恒定位移，把五帧对齐到同一坐标系。
- 对精灵每个相对位置在五帧间取多数颜色，得到干净精灵。
- 把干净精灵放到第五帧位置再加一次恒定位移处，
  输出单个面板大小的第六帧，不含任何噪声像素。

关键洞察
- 任何单帧都不可信，而答案帧在输入中根本不存在：
  必须先做运动补偿把五帧对齐、逐像素投票去噪，
  再把时间轴向前推一步——直接平移复制最后一帧会把它的噪声一起带走。
```

## 3. 锁眼串联灌注

- 参考题号: 4 (c0f76784)、5 (79fb03f4)、7 (178fcbfb)
- tags:
  - operation:洪泛填充, flood_fill
  - operation:隐形射线, invisible_ray
  - operation:连锁反应, chain_reaction
  - object:双缺口空心矩形, two_gap_hollow_rect
  - object:种子像素, seed_pixel
  - object:画布边界, canvas_boundary
  - relation:视线可达, line_of_sight
  - condition:缺口对齐无阻挡才灌注, gap_alignment_unblocked_fill

### docstring

```text
边界种子沿隐形直线射入，射线只能经缺口进出空心矩形；被射线穿入内部的矩形
整体灌成种子色，且射线可经对齐的第二个缺口穿出，串联点亮下一个矩形。

输入结构
- 黑底网格上有若干灰色单像素厚的空心矩形，每个矩形的墙上恰有两个一像素缺口。
- 网格边界上有若干彩色单像素种子：左/右边界种子水平发射，上/下边界种子垂直发射。
- 射线在输入输出中均不显示；输入保证每个矩形至多被一条有效射线进入。

规则
- 每颗种子沿其发射方向作直线前进；在途中撞到任何灰墙即终止，什么都不发生。
- 若射线恰好穿过某矩形的缺口进入其内部，则该矩形内部整体填成种子色。
- 射线在矩形内部沿原方向继续前进：若正好从另一个缺口穿出则继续飞行，
  可再进入并灌注下一个矩形；否则撞内壁终止。
- 两个缺口都未被命中的矩形保持空心；种子与灰墙原样保留，不画射线痕迹。

关键洞察
- 颜色归属由"锁眼可达性链"决定，而不是距离或行列的表面对应：
  一颗种子可以串联点亮一串矩形，而离矩形最近、甚至与缺口同行的种子
  只要先被别的墙挡住就是诱饵；必须在脑中完整追踪每条隐形射线的穿入与穿出。
```

## 4. 断面连续性拼图

- 参考题号: 16 (e9fc42f2)、15 (281123b4)、8 (351d6448)
- tags:
  - operation:拼接, stitch
  - operation:重排, reorder
  - operation:镜像翻转, mirror_flip
  - object:条带, strip
  - object:分隔列, separator_column
  - object:多色折线, multicolor_polyline
  - relation:断面轮廓匹配, edge_profile_match
  - condition:跨界连续性决定顺序与姿态, continuity_determines_order_and_pose

### docstring

```text
把被打乱且部分被镜像翻转的竖直条带恢复正确姿态与顺序，
使跨越条带边界的多色折线全部重新连续。

输入结构
- 网格被灰色分隔列分成若干等宽条带。
- 原图上有一个横贯所有条带的多色连通图案（若干彩色折线）；
  条带被打乱左右顺序，其中若干条带还被水平镜像翻转后给出。
- 各条带内另有少量不贴边的孤立装饰像素。

规则
- 每个条带有原样与镜像两种姿态。
- 当且仅当条带 A（某姿态）右缘上彩色像素的（行，颜色）集合与
  条带 B（某姿态）左缘完全一致时，B 才能紧跟在 A 右侧。
- 输入保证使全部断面吻合的姿态组合与全序唯一；
  按该顺序与姿态重排条带（分隔列保留），输出完整网格。

关键洞察
- 没有任何显式的配对标记，接口信息就是图案被切开的"断面"，
  且每个条带有两种可能姿态：解题者必须同时求解排列与翻转，
  某条带"怎么排都接不上"正是它被翻转过的信号；
  断面匹配的方向性（右缘对左缘）同时唯一确定了整条链的朝向。
```

## 5. 压缩坐标下的配对对称补全

- 参考题号: 19 (7d419a02)、6 (f4081712)、10 (6455b5f5)、18 (ddf7fa4f)
- tags:
  - operation:坐标压缩, coordinate_compression
  - operation:对称补全, symmetry_completion
  - operation:映射归纳, mapping_induction
  - object:分隔线, separator_line
  - object:格元, lattice_cell
  - relation:格元空间中心对称, cell_space_point_symmetry
  - relation:颜色配对互换, color_pair_swap
  - condition:孪生格经配对表恢复缺失, twin_cell_mapped_recovery

### docstring

```text
把不等距分隔线压缩成规则格阵后，发现格元颜色关于阵列中心成"颜色互换对称"，
据此把被抹黑的格元恢复为孪生格颜色的配对色。

输入结构
- 满行/满列灰色分隔线把网格切成行宽、列宽各不相等的格元阵列。
- 一部分格元被某种颜色整格填满，其余格元为黑。
- 以格元下标看，中心对称的两个格元的颜色并不相同，
  而是恒按一个固定的双向配对表互换（例如红↔蓝、黄↔绿）；
  有少数格元被抹黑，破坏了这一结构。配对表不显式给出。

规则
- 给行带与列带编号，得到压缩后的规则格阵。
- 先从所有完好的中心对称格对中归纳出颜色配对表。
- 对每个黑格查看其中心对称孪生格：若孪生格有颜色，
  则把该黑格整格填成孪生色在配对表中的对应色；孪生格也是黑的格保持黑。
- 分隔线与其余格元原样保留。

关键洞察
- 三重隐藏叠加：像素级对称因行列宽不等而全部失效，需先换到格元坐标；
  格元级"相同颜色"的对称检验同样失败，因为对称关系是颜色互换而非相等；
  互换表本身没有给出，必须先从完好格对中归纳出来，再反过来用于修复缺失格。
```

## 6. 隐形台球

- 参考题号: 11 (7ddcd7ec)、5 (79fb03f4)、17 (12eac192)、2 (2b9ef948)
- tags:
  - operation:重涂色, recolor
  - operation:对角反弹射线, diagonal_billiard
  - object:角落种子, corner_seed
  - object:障碍像素, obstacle_pixel
  - object:画布边界, canvas_boundary
  - relation:轨迹覆盖, path_coverage
  - condition:反弹轨迹决定涂色, bounce_path_determines_color

### docstring

```text
角落彩色种子沿对角线发出会在边界反弹的隐形台球轨迹，
被轨迹扫过的灰色障碍像素改涂为对应种子色。

输入结构
- 黑底矩形网格，一至两个角落各有一个彩色种子像素。
- 内部散布若干灰色单像素障碍；障碍不阻挡轨迹。
- 任意两个种子的轨迹互不重合，每个障碍至多落在一条轨迹上。

规则
- 每颗种子从其角落沿指向网格内部的对角方向发射一条 45 度轨迹，
  碰到边界即作镜面反弹，直到抵达任一角落为止。
- 轨迹本身不绘制；轨迹经过的每个灰色障碍改涂为该种子的颜色。
- 未被任何轨迹经过的障碍保持灰色；种子像素原样保留。

关键洞察
- 参与规则的对象从头到尾没有被画出来：解题者必须在脑中把对角线
  弹射并折返多次，才能判定哪些灰点属于哪个种子；
  多数被涂色的障碍位于至少一次反弹之后的折线段上，
  而离种子很近却不在折线上的灰点是天然诱饵。
```
