## 1. 隐形对角刷

- 参考题目题号：7 (1f876c06)、3 (b7256dcd)
- tags:
  - operation:连线, line_drawing
  - operation:重涂色, recolor
  - operation:擦除, erase
  - object:端点对, endpoint_pair
  - object:中性遮罩, neutral_mask
  - relation:同色配对, same_color_pairing
  - relation:对角穿越, diagonal_crossing
  - condition:穿越计数定色, crossing_count_determines_color

### docstring

```text
用同色端点对隐式生成的对角线为被穿过的灰色区域定色，线本身与端点最终都不画出。

输入结构
- 背景为黑色。
- 若干前景色各恰好出现两个像素，且每对像素恰为一条严格 45 度对角线段的两端。
- 另有若干灰色 4 连通区域散布在网格中，端点像素不与灰色区域相邻。

规则
- 对每种成对颜色，求出其两端点之间对角线段所经过的全部格子（这条线不画出）。
- 灰色连通区域若恰被一种颜色的线段穿过（即该区域至少一个格子落在该线段上），整块重涂为该颜色。
- 若被两种及以上颜色的线段穿过，整块擦成背景色。
- 未被任何线段穿过的灰色区域保持灰色。
- 所有端点像素在输出中擦为背景。

关键洞察
- 对角线从未在画面上出现，它只是端点对的生成元；输出唯一可见的效果是灰块的换色与消失，必须反推隐形线的走向与穿越次数才能解释每个灰块的命运。
```

## 2. 转向罗盘

- 参考题目题号：4 (6773b310)、19 (cdecee7f)、20 (271d71e2)
- tags:
  - operation:计数, counting
  - operation:压缩, compress
  - object:分隔线, separator_line
  - object:标记像素, marker_pixel
  - relation:网格分区, grid_partition
  - relation:计数编码转向, count_encodes_turn
  - condition:链式行走带朝向状态, stateful_chain_walk

### docstring

```text
把每个分区内的标记数读成相对转向指令，携带朝向状态从起点区一路走出棋盘，输出被走过分区的摘要图。

输入结构
- 灰色整行整列分隔线把棋盘划成 m×n 个矩形分区。
- 每个分区含 1~4 个红色标记像素。
- 恰有一个分区额外含一个蓝色起点像素，该像素紧贴本分区的某一条边。

规则
- 标记数编码相对转向：1=直行，2=右转，3=掉头，4=左转。
- 初始朝向由蓝色起点像素所贴的分区边给出（贴上边即朝上，依此类推）。
- 从起点分区开始，每进入一个分区，先按该分区的红色标记数更新当前朝向，再沿新朝向移动到相邻分区；反复执行直到走出棋盘边界（题面保证路线不自交、必然走出）。
- 输出 m×n 摘要网格：被走过的分区（含起点）为蓝色，其余为黑色。

关键洞察
- 红色标记数不是要统计的对象数量，也不是绝对方向，而是转向指令；必须携带朝向状态沿链执行，初始朝向又藏在起点像素贴边的位置里，任何一步理解错误都会使整条路线偏离。
```

## 3. 蛇序量条

- 参考题目题号：6 (7b5033c1)、8 (f8ff0b80)
- tags:
  - operation:展直, straighten
  - operation:计数, counting
  - object:蛇形路径, snake_path
  - object:前景色掩码, foreground_mask
  - relation:颜色关联跨对象, color_join_across_objects
  - condition:保留像素序, preserve_pixel_order
  - condition:忽略干扰项, ignore_distractors

### docstring

```text
按多色蛇的遍历顺序，把各同色散布对象的面积转成竖条，拼接成一根单列量条。

输入结构
- 背景为黑色。
- 网格中唯一的多色 4 连通链（蛇）恰有两个端点，蛇上每格一种颜色且互不相同。
- 另散布若干单色对象：与蛇上颜色相同的对象各恰有一个；还可能存在颜色不在蛇上的干扰对象。

规则
- 从蛇最靠左上的端点开始逐格遍历整条蛇。
- 对遍历到的每个颜色 c，在输出列末尾追加一段长度等于 c 色散布对象像素数的 c 色竖条。
- 颜色不在蛇上的对象全部忽略。
- 输出为 N×1 单列，N 为所选对象面积之和。

关键洞察
- 输出顺序由蛇的走向给出、与对象大小或位置无关，每段长度又由对象面积给出、与蛇无关；两类信息必须靠颜色配对拼接，按面积排序或按位置排序都会得到错误的量条。
```

## 4. 限能连线

- 参考题目题号：11 (dbc1a6ce)、20 (271d71e2)
- tags:
  - operation:连线, connect
  - operation:逐步充能, incremental_charge
  - object:标记像素, marker_pixel
  - object:电池条, battery_bar
  - relation:同行列对齐, row_col_aligned
  - condition:能量门控连接, energy_gates_connection

### docstring

```text
只有当同行（列）电池的灰格数量足以覆盖间距时，这对蓝色标记才被连接，且消耗的灰格逐一转橙。

输入结构
- 背景为黑色。
- 某些行（或列）含恰好一对蓝色标记像素，以及同一行（列）内一段连续的灰色电池条。
- 电池条与标记像素不相邻，也不位于两标记之间。

规则
- 对每一对同行（列）蓝标，数出两标之间严格内部的背景格数 g 与该行（列）电池条的灰格数 n。
- 若 g≤n：用青色填满两标之间的全部内部格，并把电池条中靠近标记对的一端起的 g 个灰格改为橙色，其余灰格保留。
- 若 g>n：不连线，电池条保持全灰。
- 其他像素一律不变。

关键洞察
- 连线不是无条件的：每根线都要向本行（列）的电池"支付"与线长相等的能量，付不起就整条取消；电池条上的橙灰分界忠实记录了支付额，是判断规则的关键证据。
```

## 5. 示范图例

### docstring

```text
顶部图例用"变换前→变换后"的示范对定义每种钥匙色对应的操作，下方每个图案按其钥匙色执行对应操作。

输入结构
- 顶部图例区：每条示范由一个钥匙色像素和左右并排的两个小网格组成，右图是左图经某种固定操作（如左右镜像、旋转 90 度、两色互换等）的结果；示范图形不对称，保证操作可唯一辨认。
- 一条分隔线之下是主区域：若干图案散布，每个图案旁附一个钥匙色像素。

规则
- 从每条示范的前后差异中推断该钥匙色所代表的操作。
- 对主区域每个图案，施加其钥匙色对应的操作，在原位置替换。
- 输出仅保留主区域，且删去所有钥匙色像素。

关键洞察
- 操作表不是先验给定的，而是由题面内部的示范对现场教会的；解题分两步——先从示范对"学会"每种颜色的含义，再把学到的操作"应用"到新图案上，跳过学习步骤无法猜出任何一个输出。
```

## 6. 错位互补壁纸

- 参考题目题号：17 (c663677b)、2 (94f9d214)、12 (abbfd121)
- tags:
  - operation:补全, complete
  - operation:周期推断, period_inference
  - operation:透明叠加, overlay
  - object:重复瓦片, repeating_tile
  - object:缺损像素, corrupted_pixel
  - relation:错位拷贝对齐, shifted_copy_alignment
  - condition:两级修复, two_stage_repair

### docstring

```text
先恢复上下两块壁纸窗口之间隐藏的平移量互相补洞，补不上的再用壁纸自身周期自补。

输入结构
- 一条分隔线把网格分成上下两块同尺寸区域。
- 两块区域是同一张无限周期壁纸上两个不同位置的窗口，即两块内容整体相差一个未知平移量。
- 两块中各散布若干黑色缺损像素（黑不是壁纸用色）；上块的缺损遮蔽了某些周期相位的全部拷贝，仅靠上块自身的周期性无法唯一恢复。

规则
- 找出唯一的平移量 t，使按 t 对齐后两块的所有非黑像素完全一致。
- 输出修复后的上块：上块的每个黑格优先用下块中按 t 对齐的对应格颜色填补。
- 若对应格也是黑（双重缺损），则用上块推断出的最小周期相位填补。
- 非黑像素原样保留。

关键洞察
- 两块不是"逐格比较标记异同"的叠加掩码，而是同一壁纸的错位拷贝——必须先恢复隐藏的对齐平移量才能互补；对齐后仍补不上的格子还要再退一层用周期性自补，两级修复缺一不可，单用任何一级都无法完成全部修复。
```

## 7. 孔洞算术

- 参考题目题号：1 (67e490f4)、8 (f8ff0b80)
- tags:
  - operation:嵌入填充, inlay_fill
  - operation:计数, counting
  - operation:裁剪, crop
  - object:模板框架, template_frame
  - object:孔洞, hole
  - object:精灵体, sprite
  - relation:数量匹配面积, count_matches_area
  - condition:形状为诱饵, shape_is_decoy

### docstring

```text
框内每个孔洞用"散布个数等于孔洞面积"的那种颜色填充，形状相似只是诱饵。

输入结构
- 背景为最常见色。
- 一个大的单色实心框架内部含若干背景色孔洞，各孔面积互不相同。
- 框外散布若干组同色小精灵，每种颜色的精灵个数互不相同；个别精灵的形状故意与某些孔洞相似。
- 题面保证每个孔的面积都恰对应唯一一种颜色的精灵个数。

规则
- 裁剪到框架的外接矩形。
- 对框内每个孔洞，数出其面积 a，找到框外恰有 a 个精灵的那种颜色，用该色填满这个孔。
- 框架像素保持原色。

关键洞察
- 孔与颜色的配对钥匙是"个数=面积"的算术对应，而不是形状匹配；个别精灵形状与孔洞相似是埋下的诱饵，按形状配对会得到错误颜色。
```
