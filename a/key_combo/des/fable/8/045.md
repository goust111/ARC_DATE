## 1. 角点残迹重建与奇偶填充

- 参考题目题号: 3、4、9
- tags:
  - operation:重建, reconstruction
  - operation:绘制, drawing
  - operation:奇偶填充, parity_fill
  - object:角点残迹, corner_remnant
  - object:隐形矩形, invisible_rectangle
  - relation:生成元定形体, generator_defines_shape
  - relation:嵌套重叠, nesting_overlap
  - condition:覆盖奇偶决定填色, coverage_parity_colors

### docstring

```text
由 L 形角点残迹复原一批从未画出的矩形边框，并按每个格被矩形覆盖次数的奇偶为内部着色。

输入结构
- 黑色背景上散布若干三像素的灰色 L 形残迹，每个残迹标记某个矩形的一个角，且开口指向该矩形的内部。
- 每个矩形恰好留下四个配套的角残迹；不同矩形的残迹相互混杂，矩形可以嵌套或部分重叠。

规则
- 将朝向与行列对齐关系相互一致的四个残迹配成一组，复原该组对应的矩形边框。
- 输出中先画出全部灰色矩形边框。
- 再统计每个非边框格被多少个复原矩形严格包含：次数为奇数的涂红色，偶数（含零）保持黑色；边框格保持灰色。

关键洞察
- 画面上从未出现完整矩形，L 残迹的开口方向是唯一的配对依据——按"就近配对"会得到错误的矩形。
- 着色不是按嵌套深度而是按覆盖次数的奇偶，部分重叠区域会像异或一样翻转颜色。
```

## 2. 连锁罗盘坠落

- 参考题目题号: 5、7、8
- tags:
  - operation:提取, extract
  - operation:重力滑动, gravity_slide
  - operation:堆叠, stack
  - object:单色边框, monochrome_frame
  - object:边缘标记, edge_marker
  - object:伪框机关, latent_frame_trap
  - relation:帧心色配边, center_color_matches_edge
  - relation:装配触发连锁, assembly_triggers_chain
  - condition:近侧优先结算, nearest_first_settling
  - condition:新罗盘变向重坠, new_compass_redirects

### docstring

```text
完整 3×3 框的中心色选出重力边，散件坠落；第一轮堆积会把一个缺角伪框补装成新的完整框，触发向新方向的第二轮坠落。

输入结构
- 网格四条边上各有一个颜色互不相同的单像素边缘标记。
- 场内散布若干单色小散件，其中混有缺角或缺边的伪 3×3 框。
- 恰有一个完整的 3×3 框：八个边框像素同色、中心为另一色，中心色与某条边的标记颜色相同。

规则
- 完整框与四个边缘标记固定不动；其余散件（含伪框）作为刚体向中心色对应标记所在的边坠落，离目标边近者先结算，碰到网格边、固定框或已结算散件即停。
- 若坠落后某个单像素散件恰好补上某伪框的缺口、使之成为新的完整 3×3 框且其中心色对应另一条边，则该新框立即固定为第二个罗盘兼障碍，其余已结算散件全部解除固定，向新方向再次坠落结算。
- 如此迭代，直至不再产生新罗盘；输出最终堆积状态。

关键洞察
- 坠落不是终点而是装配过程——第一轮重力的真正作用是造出第二个罗盘。
- 不追踪"哪个缺口会被恰好补上"就无法预测最终方向；伪框既是会坠落的普通散件，又是待激活的机关。
```

## 3. 双重损伤的镜像修复

- 参考题目题号: 1、2、12
- tags:
  - operation:对称补全, symmetry_completion
  - operation:擦除, erase
  - object:马赛克画布, mosaic_canvas
  - object:缺失区域, missing_patch
  - object:侵入色块, intruder_blob
  - relation:双轴镜像, biaxial_mirror
  - condition:二阶反射兜底, second_order_reflection
  - condition:区分损伤类型, damage_type_distinction

### docstring

```text
修复一幅同时被黑洞和单色涂抹破坏的双轴对称马赛克。

输入结构
- 底图是同时具有左右和上下镜像对称的多彩马赛克。
- 若干矩形区域被涂成纯黑（空洞）；另有若干单色连通色块直接覆盖在马赛克上（涂抹），涂抹所用颜色也在完好马赛克中合法出现。
- 同一格的水平镜像位与垂直镜像位可能同时受损，此时其 180 度点对称位完好。

规则
- 判定涂抹的依据是：与镜像位不一致、且自身构成一整块同色连通区域的一侧是受损侧。
- 空洞格与涂抹格都用其水平镜像位、垂直镜像位或点对称位中任一完好格的值恢复（完好位若不止一处，取值必然一致）。
- 输出完整修复后的网格。

关键洞察
- 损伤有两种伪装——黑洞显而易见，涂抹块以合法颜色出现，只能靠"整块同色、镜像位却是杂色"识破。
- 部分格的一阶镜像位同样受损，需要二阶（点对称）反射才能找到幸存样本；切勿把涂抹块当作应该对称复制的前景。
```

## 4. 倒带弹射色带

- 参考题目题号: 10、11、14、16
- tags:
  - operation:射线延伸, ray_extend
  - operation:循环填充, cyclic_fill
  - operation:局部翻转, local_reverse
  - object:发射序列, launcher_sequence
  - object:倒带反射块, rewind_reflector
  - object:网格边界, grid_edge
  - relation:边界镜面反射, edge_mirror_bounce
  - condition:相位跨反弹保持, phase_persists_across_bounce
  - condition:灰块反弹倒序, grey_bounce_reverses_order
  - condition:抵角终止, corner_terminates

### docstring

```text
斜向彩色周期序列沿对角方向延伸，网格边是保持颜色相位的镜子，灰色块是使颜色序列倒放的倒带反射体，色带抵达网格角时终止。

输入结构
- 黑色背景上有一段沿 45 度对角线排列的彩色像素序列，长度即颜色周期，排列顺序给出前进方向。
- 场内另有若干灰色实心块，其位置保证色带最终能到达某个网格角。

规则
- 从序列末端沿对角方向逐格前进，并按序列颜色顺序循环着色。
- 撞到网格边时镜面反弹，颜色相位连续不变。
- 下一格是灰色块时同样反弹，但从反弹那一步起颜色按原序列的逆序继续循环；再次撞灰块则翻转回正序。
- 抵达网格四角之一时色带终止；灰色块保持不变。

关键洞察
- 两种反射体几何行为相同、对颜色的作用相反——边是镜子、灰块是倒带机。
- 只看轨迹会以为所有反弹等价，必须从颜色序列的正逆变化中分辨反弹的种类；相位像一条连续带子跨过每次反弹，从不重新开始。
```

## 5. 对角导火索

- 参考题目题号: 6、15、18
- tags:
  - operation:连通检测, connected_component_detection
  - operation:重涂色, recolor
  - operation:计数, counting
  - operation:描边, outline
  - object:对角链, diagonal_chain
  - object:种子像素, seed_pixel
  - object:干扰灰区, distractor_grey_region
  - relation:对角链式连接, diagonal_chain_link
  - condition:仅纯链传导, only_pure_chain_conducts
  - condition:链长定爆炸半径, chain_length_sets_radius

### docstring

```text
只有构成纯对角链的灰色区域才能把端点种子的颜色传导到另一端，并在远端引爆一圈半径等于链长的方框。

输入结构
- 黑底上有若干灰色 8 连通区域：部分是"纯对角链"——像素间仅以对角角接相连且不分支的单链；其余灰区含边贴接触或有分支。
- 每条纯对角链恰有一个端点与一个彩色单像素种子对角相邻；非链灰区旁也可能放有种子作干扰。

规则
- 对每个灰色区域判定是否为不分支的纯对角链。
- 若是且一端邻接种子：整条链重涂为种子色，并以链的远端像素为中心，用种子色画一个空心正方形边框，其切比雪夫半径等于链的像素个数，出界部分裁掉。
- 非纯链（含边贴接触或分支的灰区）及其旁的种子保持原样不动。

关键洞察
- 传导资格藏在连通拓扑里——链必须纯靠对角角接维系且不分支，边贴一格或分叉即失效。
- 爆炸的位置由"远离种子的那一端"决定，大小由链长计数决定；拓扑判定、方向、计数定尺寸三层缺一不可。
```

## 6. 借轴轨道分类

- 参考题目题号: 1、12、17
- tags:
  - operation:重涂色, recolor
  - operation:对称检测, symmetry_detection
  - object:对称标志物, symmetric_marker
  - object:干扰物体, distractor_object
  - object:前景像素云, pixel_cloud
  - relation:对称轴借用, axis_borrowed
  - relation:反射轨道, reflection_orbit
  - condition:轨道占据模式定色, orbit_occupancy_colors

### docstring

```text
在多个灰色物体中找出唯一双轴对称的标志物，以它自身的两条镜像轴为准，按每个蓝色像素的镜像伙伴占据模式重新着色。

输入结构
- 黑色背景上有若干灰色物体，其中恰有一个同时具有水平与垂直镜像对称，其余只有单轴对称或无对称。
- 标志物的行数与列数均为奇数，使两条对称轴恰好落在整行整列上；标志物不必位于网格中央。
- 另有一片散布的蓝色像素云环绕在各物体周围。

规则
- 找出唯一双轴对称的灰色标志物，取其自身的竖直对称轴与水平对称轴。
- 对每个蓝色像素查看其关于竖直轴的映射位与关于水平轴的映射位是否也是蓝色：两者皆有涂红色；仅竖直轴映射位有涂黄色；仅水平轴映射位有涂青色；两者皆无涂灰色。
- 所有灰色物体保持不变。

关键洞察
- 对称轴不是网格的中线，而是从唯一双轴对称物体身上借来的——标志物一旦偏离中心，按网格中线配对会全盘皆错。
- 颜色编码的是每个像素在借来轴系下的镜像伙伴占据模式，其余灰色物体只是考验轴源识别的干扰项。
```
