## 1. 绕障双源波纹

- 参考题目：759f3fd3、b9e38dc0、1b8318e3
- tags:
  - operation:泛洪填充, flood_fill
  - operation:填充, fill
  - object:填充种子, fill_seed
  - object:障碍物, obstacle
  - relation:最近距离, nearest_distance
  - condition:偶数传播距离, even_geodesic_distance
  - condition:等距留空, tie_left_blank

### docstring

```text
以两个种子像素为中心，沿绕过障碍的传播距离画交替波纹环，按更先到达者归属颜色，同时到达处留空。

输入结构：
- 背景为最常见色。
- 灰色像素构成若干墙段（障碍）。
- 另有恰好两个不同颜色的孤立种子像素。

规则：
- 对每个背景格，计算它到两个种子各自的四连通最短路径长度，路径不得穿过灰墙。
- 若它到某一种子严格更近，且该最短距离为偶数，则涂成该种子的颜色。
- 最短距离为奇数的格保持背景；到两个种子距离相等的格保持背景。
- 灰墙与种子本身保持不变。

关键洞察：
- 波纹不是几何同心环，而是绕障传播的等距线；画面同时叠加"最近种子分区"与
  "距离奇偶"两层筛选，障碍使环在墙后弯曲、断裂，两种波在中线处彼此截断。
```

## 2. 穿墙计步变色交换

- 参考题目：1efba499、46c35fc7、5adee1b2
- tags:
  - operation:交换, swap
  - operation:循环移色, color_cycle
  - operation:擦除, erase
  - object:标记像素, marker_pixel
  - object:障碍段, barrier_segment
  - object:颜色图例, color_legend
  - relation:跨障碍配对, cross_barrier_pair
  - condition:穿越厚度定步数, thickness_sets_steps

### docstring

```text
同行或同列隔墙相对的两个标记像素互相穿墙交换位置，并按穿过的墙厚沿图例色序前进相应步数变色。

输入结构：
- 背景为最常见色。
- 数量最多的非背景色构成若干实心墙段，各行各列至多与一段墙相交。
- 网格一侧边缘有一竖条单像素图例，自上而下给出一个颜色循环序列。
- 其余非背景像素为孤立标记，有的在同一行或同一列上隔着一段墙两侧各一个。

规则：
- 对每条恰好穿过一段墙、且墙两侧各有一个标记的行或列：删去两个原标记，
  把每个标记放到墙段另一侧紧贴墙外的第一格。
- 落点标记的新颜色，是其原颜色在图例循环序列中向后前进 k 步得到的颜色，
  k 等于该行/列上穿过的墙段厚度（墙格数）。
- 仅一侧有标记的行列不变；墙体与图例保持不变。

关键洞察：
- 墙不仅是交换的分界，还是"变色计数器"——穿过多厚的墙就沿图例转多少步；
  厚度为一的薄墙情形会伪装成"换成图例下一色"的简单规则。
```

## 3. 双向缩略图互补

- 参考题目：c4d067a0
- tags:
  - operation:补全, complete
  - operation:缩放, scale
  - object:缩略图, minimap
  - object:色块网格, colored_block_grid
  - relation:坐标映射, coordinate_mapping
  - condition:双向互补, bidirectional_completion
  - condition:共有成员定对齐, shared_members_fix_alignment

### docstring

```text
角落缩略图与主区大色块网格互为同一图案的两种比例表示，且各自残缺，需用对方补全彼此。

输入结构：
- 背景为最常见色。
- 一角有由单像素组成的点阵缩略图，缺若干点。
- 主区为按规则格点排布的 N×N 纯色方块阵，同样缺若干块。
- 每个图案位置至少在缩略图或主区一侧出现；两侧都出现的位置颜色一致。

规则：
- 用同时出现在两侧的位置确定缩略图格点到主区块位的比例与偏移。
- 对缩略图有点而主区空缺的位置，补上对应颜色的 N×N 方块。
- 对主区有块而缩略图空缺的位置，补上对应颜色的单像素点。
- 已有像素与方块全部保持不变。

关键洞察：
- 图例与被描述对象没有主从之分——映射必须双向使用，先靠双方共有的成员
  对齐坐标系，再互相填补对方的缺口。
```

## 4. 散点里程表平移

- 参考题目：470c91de、f3cdc58f、8597cfd7
- tags:
  - operation:平移, translate
  - operation:计数, counting
  - operation:擦除, erase
  - object:填充矩形, filled_rectangle
  - object:控制像素, control_pixel
  - object:孤立像素, singleton_pixel
  - relation:角位指示方向, corner_indicates_dir
  - relation:同色配对, same_color_pairing
  - condition:计数定步长, count_sets_distance

### docstring

```text
每个带青色缺角的彩色实心矩形沿缺角对角方向平移，步数等于画面上同色散点的数量，散点被清除、缺角被补全。

输入结构：
- 背景占多数。
- 若干实心彩色矩形，每个恰有一个角被青色控制像素替换，不同矩形颜色互不相同。
- 画面其余处散布着与各矩形同色的孤立像素（散点）。

规则：
- 统计每种矩形颜色的孤立散点个数 k。
- 擦除该矩形的原始占位与全部同色散点。
- 把补全缺角后的完整矩形，沿青色角所指的对角方向平移 k 格后重画；
  青色像素在输出中不再出现。

关键洞察：
- 散点不是噪声而是"里程表"——颜色把散点与矩形配对，数量决定平移距离，
  控制角只提供运动方向和待补的缺口。
```

## 5. 指针链堆叠

- 参考题目：aab50785、cbebaa4b、f3cdc58f
- tags:
  - operation:裁剪, crop
  - operation:堆叠, stack
  - operation:排序, sort
  - object:标记块, marker_block
  - object:提取区域, extracted_region
  - relation:行对齐配对, row_aligned_pair
  - relation:内容指针链, content_pointer_chain
  - condition:忽略干扰项, ignore_distractors
  - condition:唯一无入度起点, unique_unpointed_start

### docstring

```text
把每对同色 2×2 标记块之间的矩形内容裁出，按内容中隐藏的"颜色指针"串成的链条顺序自上而下堆叠。

输入结构：
- 网格含杂色噪声。
- 若干对 2×2 纯色标记块成对出现，每对两块同色且共享同样的两行（左右配对），
  不同对颜色互不相同；噪声不使用任何标记颜色。
- 除链尾一段外，每对标记块之间的矩形内容中恰嵌有一个像素，其颜色是另一个
  标记对的颜色；链尾一段的内容不含任何标记颜色。

规则：
- 裁出每对标记块之间（不含标记）的矩形内容。
- 把"某段内容中嵌的标记色像素"理解为指向拥有该标记色的那一段；从不被任何
  内容指向的一段开始，沿指针依次连接成单链。
- 按链条顺序把各段矩形自上而下垂直堆叠为输出；指针像素作为内容一部分保留，
  标记块与所有噪声全部丢弃。

关键洞察：
- 堆叠顺序与各段在画面中的空间位置无关，由藏在内容内部的颜色指针链决定——
  每段内容既是被搬运的数据，又携带指向下一段的地址；起点是唯一无人指向的段。
```

## 6. 钥匙入锁孔旋环

- 参考题目：46c35fc7、292dd178、49d1d64f
- tags:
  - operation:循环移色, color_cycle
  - object:环形前景, ring_object
  - object:缺口像素, gap_pixel
  - object:画布边界, canvas_boundary
  - relation:钥匙对锁孔, key_to_keyhole
  - condition:旋转量逐环而定, per_ring_rotation

### docstring

```text
把每个带一个缺口的 3×3 彩环整体顺时针旋转，直到与画布外框同色的"钥匙"色块落到缺口原来的位置。

输入结构：
- 画布最外一圈是单一颜色的实心边框。
- 内部背景上散布若干 3×3 环形对象，每个环的八个环位中七个为彩色、
  一个为背景缺口。
- 每个环恰有一个环位的颜色与外框颜色相同。

规则：
- 把每个环的八个环位（含缺口）视为一个循环序列，整体沿顺时针方向旋转若干步，
  使与外框同色的环位恰好落到原缺口所在的环位上。
- 其余六种颜色与缺口随旋转同步移动，相对次序不变。
- 环心、边框与背景保持不变。

关键洞察：
- 外框颜色是全局给出的"钥匙"，缺口是每个环的"锁孔"；旋转量不是固定常数，
  而是由钥匙色与锁孔的相对角位逐环决定。
```

## 7. 镜线折转周期铺设

- 参考题目：53fb4810、b942fd60、b9e38dc0
- tags:
  - operation:周期平铺, periodic_tiling
  - operation:射线延伸, ray_extend
  - object:十字图案, cross_shape
  - object:标记块, marker_tile
  - object:障碍物, obstacle
  - relation:邻接侧决定方向, adjacency_side_determines_dir
  - relation:镜面反射, mirror_reflection
  - condition:相位保持, phase_preserved
  - condition:不覆盖源对象, preserve_source_object

### docstring

```text
贴在十字臂上的小图块沿臂的方向周期复制前进，遇到对角镜线像光一样反射转向并保持周期节拍，直到走出画布。

输入结构：
- 背景为最常见色。
- 一个主色构成若干"+"形；每条臂端外侧贴有一个小的彩色图块。
- 画面另散布若干由灰色像素组成的对角线段（镜线，走向为"/"或"\"）。

规则：
- 每个图块以自身尺寸为周期，沿其所贴臂指向的方向逐份复制前进。
- 当下一份复制将与镜线重叠时，不画该份，改为按镜线走向做 90 度反射，
  从镜线旁继续按同一周期与节拍铺设。
- "+"与镜线永不被覆盖；铺设持续到复制越出画布为止。

关键洞察：
- 平铺不是一条直线冲到边缘，而是一束携带周期节拍的"光"；对角镜线改变
  方向但不重置节拍，同一图块的复制序列在拐角两侧必须连续衔接。
```
