## 1. 迷宫测地选色

- 参考题目题号: 8, 20
- tags:
  - operation:寻路, pathfinding
  - operation:重涂色, recolor
  - operation:擦除, erase
  - object:障碍像素, blocker_pixel
  - object:标记像素, marker_pixel
  - object:前景对象, foreground_object
  - relation:测地最近邻, geodesic_nearest
  - condition:欧氏近者被墙隔, euclidean_decoy

### docstring

```text
把灰色对象涂成沿迷宫可达路径最近的标记颜色，并清除所有标记。

输入结构：
- 黑色背景上分布蓝色墙体像素，构成含通道的迷宫。
- 恰有一个灰色4连通对象。
- 若干种其他颜色作为标记像素散布，每种颜色一到数个。

规则：
- 对每种标记颜色，计算该颜色任一标记像素到灰色对象任一像素的最短4邻通路步数，
  通路只能经过非蓝色格；被墙完全围死的标记颜色视为不可达。
- 取测地距离唯一最小的颜色，把灰色对象的每个像素涂成该颜色。
- 输出保留全部蓝色墙体，清除所有标记像素，其余为黑。

关键洞察：
- 直线距离最近的标记往往被墙隔开，须绕行甚至完全不可达；
  比较的是穿过迷宫的通路长度，而不是空间直线距离。
```

## 2. 对称差显影加号

- 参考题目题号: 17, 2
- tags:
  - operation:异或合成, xor_compositing
  - operation:重涂色, recolor
  - object:半区掩码, half_mask
  - object:微型条, micro_bar
  - object:隐含十字, implied_plus
  - relation:对齐, alignment
  - relation:四向对齐, four_way_aligned
  - condition:恰一为前景, exactly_one_foreground
  - condition:缺失中心, missing_center

### docstring

```text
把上下两半的对称差显影成粉色条群，并给其中隐含加号的缺失中心补上黄色。

输入结构：
- 网格高为偶数，按位置垂直均分为上下两半，无分隔线。
- 两半共享同一背景色；上半有一种前景色，下半有另一种前景色。

规则：
- 把上下两半按位置对齐，恰有一半为前景的位置记为真。
- 真值位置恰好构成若干互不相邻的水平或垂直二像素条；
  其中部分条以"左右上下各隔一格空隙"的方式围绕一个空中心排成隐含加号，
  其余条为孤立干扰。
- 输出为半区大小：真值位置涂粉色，每个隐含加号的中心涂黄色，其余为背景色。

关键洞察：
- 条和加号在任何一半中都不存在，只有对齐两半取对称差之后才显影；
  黄色标的是显影图上四条二像素条共同缺失的中心。
```

## 3. 棱镜反弹

- 参考题目题号: 5, 1
- tags:
  - operation:射线延伸, ray_extend
  - operation:擦除, erase
  - object:起点像素, start_pixel
  - object:反弹路径, bouncing_path
  - object:令牌, token
  - relation:边界反射, boundary_reflection
  - relation:令牌即棱镜, token_as_prism
  - condition:碰撞改向, collision_redirect
  - condition:顺序模拟, sequential_simulation

### docstring

```text
从红色起点向上追踪对角反弹路径，路径上的令牌像棱镜一样使路径反向并被吞并。

输入结构：
- 黑色背景；最底行恰有一个红色起点像素。
- 网格中散布若干彩色令牌像素（非红非黑非蓝）。
- 左右边缘是反射墙。

规则：
- 从起点出发，初始水平方向向右（若起点在最右列则向左），
  每步上移一行并水平移一格。
- 若下一步水平越界，先反转水平方向再走。
- 若走入的格是令牌，则该令牌并入路径且水平方向立即反转。
- 到达最顶行后结束。
- 输出中起点保持红色，路径经过的格（含被吞并的令牌格）涂蓝色，
  未被路径经过的令牌保留原位原色，其余为黑。

关键洞察：
- 令牌不是被动的收集品，而是会改变后续轨迹的反射体；
  必须按步顺序模拟，前面的碰撞决定后面能否碰到别的令牌，
  第一眼看似只在墙上反弹。
```

## 4. 瓦片语句的周期

- 参考题目题号: 3, 10, 6
- tags:
  - operation:平铺, tile
  - operation:补全, complete
  - object:分隔线, separator_line
  - object:瓦片图案, tile_pattern
  - object:最小周期单元, minimal_period
  - relation:网格分区, grid_partition
  - relation:形状相同, shape_identity
  - relation:格序列周期, cell_sequence_period
  - condition:周期与行长错位, period_row_misaligned

### docstring

```text
把分隔网格的空单元格按整个单元格序列的最小周期补全。

输入结构：
- 单色分隔线把画布划分为若干行若干列的等大单元格。
- 部分单元格内绘有小图案（存在几种不同图案），其余单元格为纯背景空格。

规则：
- 按行优先阅读顺序把全部单元格排成一个序列。
- 已填单元格与某个最小周期 p 的循环序列一致，且可见格足以唯一确定 p，
  p 不整除每行的格数。
- 把每个空格填上循环序列在该位置应有的图案，分隔线保持不变。

关键洞察：
- 周期存在于"单元格序列"这一粒度而不是像素列；
  因为周期与行长错位，同一列上下两行的图案并不相同，
  逐列复制和"把唯一图案抄满"都会失败。
```

## 5. 磨损坠落

- 参考题目题号: 1, 16, 19
- tags:
  - operation:重力下落, gravity_drop
  - operation:擦除, erase
  - operation:计数, counting
  - object:令牌, token
  - object:障碍像素, blocker_pixel
  - relation:同归于尽, mutual_destruction
  - relation:长度板数守恒, length_plate_conservation
  - condition:逐格磨损, per_cell_attrition
  - condition:长度一即停靠, unit_length_rests

### docstring

```text
让每根竖条在下落中逐格磨损击碎灰板，输出停驻的残条与幸存的板。

输入结构：
- 黑色背景；顶部悬着若干竖直单色条（长度1到5，各占一列，每列至多一根）。
- 各列下方散布若干灰色单格挡板，板与板之间有空隙。
- 也存在只有挡板没有竖条的列。

规则：
- 每根竖条在其列内下落。当条的底端接触一块灰板时：
  若条当前长度大于1，则该板与条的底端一格同归于尽
  （板从输出消失，条缩短一格），残条继续下落；
  若条当前长度等于1，则停在该板之上。
- 任何长度的条落到最底行都会停住。
- 输出中残条保持原色与竖直姿态，停在停靠板上方或底行；
  被击碎的板消失，未被撞击的板原样保留；无竖条的列挡板全部保留。

关键洞察：
- 条与板同归于尽、逐格消耗——输出里条缩短的格数恰等于该列消失的板数；
  条的初始长度决定它能穿多深，长度1的条表现得像普通重力落体，
  这一守恒关系要靠对比输入输出的条长与板数才能发现。
```

## 6. 十字断桥

- 参考题目题号: 11, 9
- tags:
  - operation:十字擦除, cross_erasure
  - operation:连通判定, connectivity_test
  - operation:擦除, erase
  - object:标记块, marker_block
  - object:保护像素, protected_pixel
  - object:桥接路径, bridge_path
  - relation:连通性, connectivity
  - relation:先改图再判定, modify_then_test
  - condition:特定色像素豁免, specific_color_pixel_exemption
  - condition:断开整体清除, disconnected_pair_removed

### docstring

```text
黄色标记的行列十字剪断青色桥，随后只保留仍然连通的哑铃。

输入结构：
- 黑色背景。
- 若干"哑铃"：两个2×2红色方块由一条宽为1的青色4连通桥相连，
  桥上个别格可能是红色。
- 恰有一个2×2黄色标记，不与其他物体相邻。

规则：
- 选中黄色标记所占的两行与两列，把选区内所有青色像素变黑，
  红色与黄色像素不变。
- 然后对每个哑铃检查其两个红色方块是否仍处于同一个非黑4连通分量：
  仍连通的哑铃原样保留；断开的哑铃其全部剩余像素（红块与残桥）一并清除。
- 黄色标记保留在输出中。

关键洞察：
- 黄块不是矩形橡皮而是两行两列的十字擦除器；
  桥上的红色段是擦除豁免，使得部分穿越十字的桥幸存；
  每个哑铃的去留由擦除之后的连通性判定决定，是"先改图、再判定"的因果链。
```

## 7. 接缝指纹重组

- 参考题目题号: 13, 4, 3
- tags:
  - operation:拼接, concatenation
  - operation:滑动, sliding
  - object:路径片段, path_segment
  - object:分隔列, separator_col
  - object:边界色带, border_color_strip
  - relation:接缝对齐, seam_alignment
  - relation:边缘列指纹, edge_column_fingerprint
  - condition:顺序由匹配推断, order_inferred_by_matching
  - condition:接缝列重叠合并, seam_column_overlap_merge

### docstring

```text
按边缘列指纹把打乱的碎片重新排序并重叠拼接成原图。

输入结构：
- 画布上有若干等高的矩形彩色碎片，宽度各异，
  彼此由全背景列隔开，左右顺序已被打乱。
- 存在唯一一种排列，使得每个碎片的最右一列与其后继碎片的最左一列完全相同；
  除这些配对外，任意两条碎片边缘列的图案互不相同。

规则：
- 找到链首（其最左列不等于任何其他碎片的最右列）。
- 按边缘列相等关系依次连接全部碎片；
  拼接时相邻两块的相同边缘列重叠合并为一列。
- 输出为拼接后的完整图案，不含任何分隔空列。

关键洞察：
- 边缘列图案既是排序的钥匙又规定了重叠量——接缝处两块共享同一列，
  因此输出宽度是各碎片宽度之和减去接缝数；
  按输入顺序直接拼接会得到错误的图。
```
