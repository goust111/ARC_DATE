## 1. 孔洞的钥匙

- tags:
  - operation:裁剪, crop
  - operation:填充, fill
  - operation:形状匹配, shape_matching
  - object:连通分量, connected_component
  - object:孔洞, hole
  - object:伪噪声碎块, pseudo_noise_fragment
  - relation:形状全等配键, congruence_keying
  - condition:反噪声诱饵, anti_noise_decoy
- 参考题目：20 (1f85a75f)、5 (ce602527)、9 (77fdfe62)

### docstring

```text
一句话总述：裁剪最大连通对象，并用散落在外的小碎块作为形状钥匙给它的内部孔洞上色。

输入结构：
- 背景为最常见色。
- 网格上有一个面积最大的单色四连通对象，其内部含若干形状互不相同的背景孔洞。
- 对象之外散落着若干小的单色连通碎块：其中一部分碎块与某个孔洞平移全等，
  其余碎块与任何孔洞都不全等。

规则：
- 找到唯一的最大四连通对象，取其边界框做紧致裁剪作为输出画布。
- 对该对象的每个内部孔洞，在外部碎块中寻找与其平移全等（不旋转不翻转）的
  碎块；找到则把该孔洞整体填成该碎块的颜色。
- 与任何孔洞都不全等的碎块是真噪声，不产生任何效果；没有配对碎块的孔洞
  保持背景色。

关键洞察：
- 散落的小碎块并非应当丢弃的噪声：它们是按形状配键的填色图例，孔洞的
  形状本身就是查找钥匙——"提取大物体、扔掉小碎块"的惯性思路正是诱饵。
```

## 2. 缺口罗盘

- tags:
  - operation:旋转, rotate
  - operation:平移, translate
  - operation:擦除, erase
  - object:多色精灵体, multicolor_sprite
  - object:光环标记, halo_marker
  - object:锚点像素, anchor_pixel
  - relation:颜色匹配, color_matching
  - relation:缺口定朝向, gap_sets_orientation
  - condition:旋转后锚定, rotate_then_anchor
- 参考题目：6 (dc1df850)、4 (a251c730)、19 (d6542281)

### docstring

```text
一句话总述：把每个精灵旋转到尾巴指向光环缺口的方向，再平移使锚点压在光环
中心上。

输入结构：
- 黑色背景上有若干多色精灵，每个精灵含一个唯一的最少色像素作为锚点，
  并带有一截可辨认的单像素尾巴（精灵无旋转对称）。
- 另有等量的着陆标记：每个标记是一个中心像素外加一圈灰色光环，光环恰好
  缺一格，缺口位于上下左右四个正方向之一。
- 每个标记中心像素的颜色与恰好一个精灵的锚点颜色相同。

规则：
- 按锚点颜色为每个精灵找到它的着陆标记。
- 把精灵旋转 0/90/180/270 度，使其尾巴的伸出方向与"缺口相对光环中心的
  方向"一致。
- 平移旋转后的精灵，使锚点像素与标记中心重合；擦除精灵原位置与整个光环，
  只保留落位后的精灵。

关键洞察：
- 光环不是装饰而是一只罗盘：缺口方位是旋转指令，中心是平移终点，颜色是
  配对钥匙，三条信息缺一不可，只做颜色锚定而不旋转会在多数示例上出错。
```

## 3. 残迹放大补全

- tags:
  - operation:缩放, scale
  - operation:印章覆盖, stamp_overlay
  - object:精灵体, sprite
  - object:残迹像素, residue_pixel
  - relation:跨尺度重叠匹配, cross_scale_overlap
  - condition:唯一一致落位, unique_consistent_placement
- 参考题目：5 (ce602527)、19 (d6542281)

### docstring

```text
一句话总述：散落的同色残迹是某个小精灵放大后的部分像素，找出唯一的精灵、
倍率与位置并补全整个放大体。

输入结构：
- 背景为最常见色，网格里有若干形状互不相同的小单色精灵。
- 另有一片同一种颜色的残迹像素，该颜色不属于任何精灵。
- 恰有一个精灵按 2 倍或 3 倍整倍放大后，存在唯一平移使全部残迹像素落在
  放大体的掩码内部，且放大体不与其他前景冲突；其余任何精灵、倍率、平移
  组合都无法做到。

规则：
- 对每个精灵、每个倍率、每个平移，检验残迹像素是否全部被放大后的精灵
  掩码覆盖且放大体不压住其他前景。
- 取唯一通过检验的组合，在该位置用残迹颜色画出完整的放大精灵。
- 其余精灵与背景保持不变。

关键洞察：
- 残迹既是选择器又是定位器：它同时唯一确定被放大的精灵、放大倍率与放置
  位置，而形状比对必须跨尺度进行——按原尺寸去套任何精灵都对不上。
```

## 4. 连锁沉降

- tags:
  - operation:滑动, slide
  - operation:计数, count
  - operation:重涂色, recolor
  - object:连通分量, connected_component
  - object:灰色地形, terrain
  - relation:面积决定位移上限, area_caps_displacement
  - relation:触地并入地形, landing_merges_terrain
  - condition:低者先落的连锁, low_first_chain
  - condition:诱饵重力, gravity_decoy
- 参考题目：13 (8e301a54)、16 (5521c0d9)、19 (d6542281)

### docstring

```text
一句话总述：物体按从低到高的次序依次下落，落程等于自身像素数且被地形
截断，凡贴上地形的物体立刻变灰并入地形，改变后续物体的落点。

输入结构：
- 背景之上有一片灰色静止地形（底边或带凸起的平台），以及若干彩色单色
  四连通物体。
- 部分物体的列跨度相互重叠，使先落者可能垫在后落者下方。
- 部分物体离地形近，部分离地形远。

规则：
- 按物体最低像素所在行从低到高依次处理每个彩色物体。
- 当前物体下移 min(自身像素面积, 到其正下方当前地形的净空行数) 行。
- 落定后若物体与地形上下相接（即净空行数不大于自身面积），该物体整体
  重涂为灰色并从此计入地形；若额度用尽仍未接触地形，物体保持原色停在
  半空。
- 已并入地形的像素为后续物体提供新的支撑面。

关键洞察：
- 这不是一次性的重力结算，而是一条因果链：位移额度来自各物体自身的
  面积；触地者改变身份成为地形，垫高后来者的落点。看第一个示例像
  "全部落地变灰"的简单重力，悬空保色的物体与被垫住的物体共同否决了
  这一读法，且必须按自低向高的次序重演整条链才能得到正确输出。
```

## 5. 光环倒带

- tags:
  - operation:擦除, erase
  - operation:因果反演, causal_inversion
  - object:光环区域, halo_region
  - object:遮挡前景, occluder
  - object:伪光环, fake_halo
  - relation:缺格由遮挡解释, gap_explained_by_occlusion
  - condition:可解释性判定, explainability_test
- 参考题目：6 (dc1df850)、20 (1f85a75f)

### docstring

```text
一句话总述：把每个真正的光环倒带回它的中心红点，缺格的光环只有能用遮挡或
出界解释时才算真光环。

输入结构：
- 黑底网格上有若干蓝色连通形，以及一些其他颜色的前景像素。
- 一部分蓝形是某中心的 3x3 光环残留：中心为黑，环上缺失的格子要么超出
  网格边界，要么恰被其他颜色的前景像素占据。
- 另一部分蓝形无论选哪个中心都无法满足上述解释，是伪光环。

规则：
- 对每个蓝色连通形，寻找一个中心格，使该中心的 3x3 邻域满足：邻域内的
  蓝像素恰为该蓝形的全部像素；邻域内非蓝的格子或在网格外、或被非蓝前景
  占据；中心自身为黑。
- 存在这样的中心时，擦除该蓝形并把中心涂红；不存在时该蓝形原样保留。
- 其他颜色的前景像素一律保持不变。

关键洞察：
- 这是"红点扩张出只填背景的光环"的反问题：光环的缺口不是随机破损，而是
  扩张时避开前景留下的证据，必须逐格用遮挡与出界去核验缺口，才能确认
  中心并区分真伪光环。
```

## 6. 隐形边长密钥

- tags:
  - operation:计数, count
  - operation:查表匹配, table_lookup
  - operation:印章放置, stamp
  - object:角点标记, corner_marker
  - object:字典条目, dictionary_entry
  - object:字形, glyph
  - relation:角点定义正方形, corners_define_square
  - relation:边长为键, side_length_as_key
  - condition:从未画出的度量作键, unseen_measure_as_key
- 参考题目：14 (11e1fe23)、7 (9110e3c5)、11 (d8e07eb2)

### docstring

```text
一句话总述：三个角点暗示一个从未画出的正方形，用它的边长当字典钥匙取出
字形，并把字形印在缺失的第四角上。

输入结构：
- 网格被一条分隔线分为主区与字典区。
- 主区为黑底，恰有三个同色像素位于某个轴对齐正方形的三个角上；正方形
  本身与第四角都没有画出，且各示例的正方形边长不同。
- 字典区有若干条目，每个条目由一小簇像素（各条目簇的像素个数互不相同）
  和簇旁边的一个 3x3 字形组成；簇与字形的颜色都与角点颜色无关。

规则：
- 由三个角点推出正方形与其缺失的第四角位置，量出正方形的边长（边所跨
  的格数）。
- 在字典区找到簇像素数等于该边长的唯一条目。
- 输出主区：保留三个角点，把该条目的 3x3 字形以中心对齐印在第四角
  位置上，其余保持黑底；不输出分隔线与字典区。

关键洞察：
- 字典的钥匙是一个画面上不存在的量：不是角点个数（恒为三）、不是任何
  颜色，而是由角点隐式定义的正方形边长；同一组角点既供出钥匙，又供出
  字形的落点。
```

## 7. 共线即指令

- tags:
  - operation:模式检索, pattern_search
  - operation:镜像, mirror
  - operation:旋转, rotate
  - object:钥匙图形, key_shape
  - object:主图案, main_pattern
  - relation:出现位置共线, occurrences_collinear
  - condition:排布方向选变换, layout_selects_transform
- 参考题目：11 (d8e07eb2)、17 (00576224)、10 (cfb2ce5a)

### docstring

```text
一句话总述：在主图案中找出钥匙图形的全部出现位置，用这些位置的排布方向
决定对整幅主图案施加哪种变换。

输入结构：
- 网格底部以一条分隔线隔出一个小的单色钥匙图形。
- 分隔线上方是多色主图案，与钥匙同形状的图形（颜色不限）在其中出现若干次。
- 每个示例中这些出现位置或全部同行、或全部同列、或既不全同行也不全同列。

规则：
- 在主图案中找到钥匙形状的所有出现位置（不旋转不翻转，忽略颜色）。
- 出现位置全部同行则输出主图案的左右镜像；全部同列则输出上下镜像；
  两者都不满足则输出旋转 180 度的主图案。
- 输出不包含分隔线与钥匙图形。

关键洞察：
- 钥匙图形本身不参与任何变换，它的价值全在"出现在哪儿"：多个出现位置的
  共线方向才是真正的变换指令，而钥匙自己的形状走向是无关的诱饵。
```

## 8. 断层转轮

- tags:
  - operation:平移, translate
  - operation:对齐, align
  - operation:擦除, erase
  - operation:补全, completion
  - object:调色板行, palette_row
  - object:彩色横条, colored_bar
  - object:缺口, gap
  - object:无名横条, unlisted_bar
  - relation:循环读序, cyclic_reading_order
  - relation:缺口三重身份, gap_triple_role
  - condition:宽度是诱饵, width_decoy
- 参考题目：18 (bae5c565)、16 (5521c0d9)、15 (1caeab9d)

### docstring

```text
一句话总述：用那根颜色不在图例里的横条补全图例的被抹格，再从缺口起循环
读出颜色序，按此序把所有横条以缺口列为轴自底向上堆叠。

输入结构：
- 最底行是一条调色板图例：一串互不相同的颜色，其中恰有一格被抹成背景
  （缺口）。
- 图例上方散落着若干高为一格、宽度为奇数且各异的彩色横条；恰有一根
  横条的颜色不出现在可见图例中，其余横条颜色与可见图例一一对应。
- 横条在输入中的上下顺序与左右位置都与图例无关；宽度常呈现误导性的
  单调排列。

规则：
- 缺口是被抹掉的图例格：其内容就是那根无名横条的颜色，先把它填回图例。
- 从缺口格开始向右循环读出补全后的完整颜色序（越过最右端后回到最左端
  继续），该序即自底向上的堆叠次序。
- 擦除所有横条原位置，按此次序把横条自图例上方一行起逐行密排堆叠，
  每根横条的中心格对准缺口所在列；输出保留补全后的图例行。

关键洞察：
- 缺口有三重身份：它是被抹去的图例格（内容由无名横条供出）、循环读序的
  起点、堆叠的对齐轴。按宽度排金字塔或朴素地从图例最左端读序都是诱饵
  ——不先识破"无名条补缺口"与"从缺口起读并回卷"这两步，塔的层序在
  多数示例上都会装错。
```

## 9. 镜带修复

- tags:
  - operation:平铺, tiling
  - operation:镜像, mirror
  - operation:修复, repair
  - object:瓦片, tile
  - object:破损像素, corrupted_pixel
  - relation:中间行翻转的周期结构, mirrored_band_period
  - condition:结构反推恢复, restore_from_structure
- 参考题目：17 (00576224)、10 (cfb2ce5a)

### docstring

```text
一句话总述：识别"整图由瓦片平铺、且中间瓦片行整体左右镜像"的构造，据此
把被涂改的少数像素改回去。

输入结构：
- 网格本应由一个小瓦片按阵列平铺构成，其中位于中间的那一行瓦片整体使用
  瓦片的左右镜像，其余瓦片行使用原瓦片；瓦片自身左右不对称，镜像行因此
  与其余行可分辨。
- 少数像素被涂改成了别的颜色，破坏了这一构造。
- 涂改像素远少于遵循构造的像素，且同一瓦片内坐标在全图各处至多被涂改
  一次，保证多数表决可恢复。

规则：
- 反推瓦片内容：对瓦片内每个坐标，聚合所有瓦片格位（中间行先左右翻转
  回原方向）上该坐标的颜色，取多数色。
- 用反推出的瓦片按同一构造（中间瓦片行镜像）重绘全图，即把每个被涂改
  像素恢复为构造要求的颜色。
- 输出与输入同尺寸。

关键洞察：
- 朴素的周期检测会在中间带上失败——那里的"错位"不是破损而是整行镜像；
  只有察觉这一层构造，冗余才能对齐，破损像素才有唯一的正确恢复值。
```

## 10. 自指分块复原

- tags:
  - operation:印章覆盖, stamp_overlay
  - operation:互补合成, complementary_merge
  - operation:因果反演, causal_inversion
  - object:分块网格, block_grid
  - object:残缺副本, partial_copy
  - object:控制像素, control_pixel
  - relation:布局即图案, layout_is_pattern
  - condition:控制色只存于布局, control_color_only_in_layout
- 参考题目：8 (ad7e01d0)、12 (cce03e0d)、19 (d6542281)

### docstring

```text
一句话总述：从若干残缺副本互补拼回原图案，而原图案中灰色像素的位置只能
从"哪些块非空"的布局里读出。

输入结构：
- 大网格按原图案的尺寸均匀分块，一部分块中放着原图案的残缺副本（各自
  缺失不同位置的像素），其余块全黑。
- 所有副本中的灰色像素都被抹去：任何一个副本里都看不到灰色，但各副本
  合起来覆盖了原图案的全部非灰像素。
- 分块布局遵循自指规则：非空块在块网格中的格位，恰好就是原图案中灰色
  像素所在的格位。

规则：
- 识别分块结构，叠合所有非空块：同一格位上各副本出现过的颜色取并集，
  恢复全部非灰像素。
- 把"非空块的位置图"当作原图案的灰色掩码：这些格位涂灰。
- 输出恢复完整的原图案，尺寸等于单个块的尺寸。

关键洞察：
- 这是分块印章的反问题，而且钥匙藏在结构里：灰色像素在所有副本中集体
  缺席，它们唯一的记录就是布局本身——图案曾用自己的灰像素决定自己被
  盖章的位置，如今布局反过来供出了灰像素。
```
