## 1. 唯一装配的负空间

- tags:
  - operation:平移, translate
  - operation:无重叠拼合, non_overlap_pack
  - object:矩形框, rect_frame
  - object:碎块, puzzle_piece
  - object:负空间, negative_space
  - relation:互补拼合, complement_fit
  - condition:唯一装配, unique_assembly
- 参考题目题号：20 (681b3aeb)、18 (846bdb03)、1 (543a7ed5)

### docstring

```text
把两块碎片装进空框内的唯一合法位置，再把装不满的内部空缺涂黄。

输入结构：
- 黑色背景上有一个灰色空心矩形框，框内为空。
- 框外散落两个单色多联骨牌碎片，颜色互不相同，只允许平移、不允许旋转或翻转。
- 保证两碎片放入框内互不重叠且不越界的平移方案恰有一种（由碎片彼此的凹凸咬合锁定）。
- 黄色在输入中不出现，专用于新增标记。

规则：
- 找出两碎片在框内唯一的合法放置，把它们按原色画到框内相应位置。
- 框内未被任何碎片覆盖的格子涂黄。
- 清除碎片的原位置，矩形框保持不变。

关键洞察：
- 黄色形状在输入中从未出现：它是唯一装配完成后的负空间，不真正解出装配就无法知道缺件长什么样。
```

## 2. 红绿转向门光束

- tags:
  - operation:射线延伸, ray_cast
  - operation:连线, draw_path
  - object:双色多米诺, bicolor_domino
  - object:路径起点, path_start
  - relation:四邻接配对, four_neighbor_pairing
  - relation:矢量转向, vector_redirect
  - condition:红端终止, red_end_stop
  - condition:忽略干扰项, ignore_distractors
- 参考题目题号：10 (d90796e8)、11 (dc433765)、16 (cb2d8a2c)

### docstring

```text
一束从边界射入的青色光线在红绿多米诺上改道：绿端把它折向红指绿的方向，红端把它吸收。

输入结构：
- 黑底网格，边界上恰有一个青色起点像素。
- 场上散布若干红-绿四连通二元组（真多米诺），另有孤立红点、孤立绿点以及仅对角接触的红绿对充当干扰。
- 保证每个示例中光线既经过至少一次绿端转向，也存在展示红端终止或穿过干扰点的情形。

规则：
- 光线从青色像素沿垂直于所在边界的方向射入网格，沿途的背景格涂青。
- 光线进入某个真多米诺的绿格时，改沿"该多米诺红格指向绿格"的方向从绿格继续前进。
- 光线进入真多米诺的红格时立即终止。
- 孤立红点、孤立绿点与对角红绿对不影响光线：光线照常穿过其所在行列，这些格保持原色。
- 光线走出网格边界即结束；输出为原图叠加青色轨迹，所有红绿像素保持不变。

关键洞察：
- 红绿相邻对不是待消除的对象，而是带极性的转向门：必须先用四邻接判定哪些是真门并排除干扰，再把每扇门读成一个方向矢量，绿端通行转向、红端吸收终止。
```

## 3. 看不见的菱形只在相交处显形

- tags:
  - operation:包络生成, envelope_generation
  - operation:逻辑与合并, logical_and_merge
  - object:实心条, solid_bar
  - object:隐形菱形, implicit_diamond
  - relation:长度编码半径, length_encodes_radius
  - condition:双重覆盖显色, double_cover_reveal
- 参考题目题号：19 (c97c0139)、5 (195ba7dc)、16 (cb2d8a2c)

### docstring

```text
每根灰条隐含一个以条长定半径的菱形领域，只有被至少两个领域同时覆盖的格子才涂红。

输入结构：
- 黑底网格上有若干水平或竖直的一格宽灰色实心条，长度均为奇数。
- 各条的位置与长度不同，部分条的隐含领域彼此交叠，部分条孤立无交。
- 红色在输入中不出现；示例中条长与条间距搭配多样，足以钉死半径规律。

规则：
- 每根长度为 L 的条隐含一个以条中点为中心、半径 (L-1)/2 的曼哈顿菱形领域；领域本身从不画出。
- 被至少两个隐含领域覆盖的背景格涂红。
- 只被一个领域覆盖或不被覆盖的格保持黑色；灰条像素保持不变。

关键洞察：
- 参与规则的菱形从未被完整画出，画面上只有它的生成元（条）与相交残迹（红色透镜区）；
  透镜区的形状同时依赖两条的长度与间距，必须反推出"条长即半径"的隐含领域律才能解释全部示例。
```

## 4. 体内矢量·撞墙裁剪·指令抹平

- tags:
  - operation:印章覆盖, stamp_repeat
  - operation:裁剪, clip
  - operation:重涂色, recolor
  - object:精灵体, sprite
  - object:指令像素对, instruction_pixel_pair
  - object:障碍墙, obstacle_wall
  - relation:位移矢量编码, displacement_encodes_vector
  - condition:撞墙裁剪即停, wall_clip_stop
  - condition:指令抹平, instruction_erased
- 参考题目题号：8 (985ae207)、3 (8618d23e)、17 (dfadab01)、16 (cb2d8a2c)

### docstring

```text
读出精灵体内灰指橙的位移矢量作为步长反复盖章，撞上青墙的那份被裁掉墙后部分即停，指令像素全部抹平。

输入结构：
- 黑底上有一个单色精灵体，其内部有两个像素被替换为灰色与橙色各一枚，第一眼像纹理或孔洞标记。
- 场上另有一条青色直墙（贯通的整行或整列）。
- 灰指橙的位移可为任意方向（含非 45 度斜向）；保证各份复制互不重叠，且示例中存在
  "离网格边界尚远即停"与"末份被切掉部分像素"的情形，用以反证越界停止说。

规则：
- 令 v 为精灵体内从灰像素指向橙像素的位移矢量。
- 在原件位置加 v、2v、3v …… 处依次盖章复制整个精灵。
- 第一份与墙接触或跨越墙的拷贝，只绘制位于墙之前（原件一侧）的像素，墙上及墙后的像素被裁掉，随后停止盖章。
- 原件与所有拷贝中的灰、橙像素一律恢复为精灵体色，输出中不再出现这两色；墙保持不变。

关键洞察：
- 平移指令藏在对象自身体内：两枚异色像素不是孔洞、纹理或方向头，而是自引用的步长矢量；
  步进终点由墙的裁剪决定而非网格边界；输出把指令抹平，只留下它的效果。
```

## 5. 孔洞是燃料，灰头是方向

- tags:
  - operation:平移, translate
  - operation:计数, counting
  - operation:擦除, erase
  - object:前景对象, foreground_object
  - object:封闭孔洞, enclosed_hole
  - object:方向头, direction_head
  - relation:孔数编码步长, hole_count_encodes_distance
  - condition:头指方向, head_sets_direction
- 参考题目题号：9 (37d3e8b2)、11 (dc433765)、15 (a78176bb)

### docstring

```text
每个带孔物体沿灰头指向的方向平移，步数等于它体内封闭孔的个数，然后灰头消失。

输入结构：
- 黑底上有若干互不接触的单色四连通物体，颜色互不相同，每个物体内部含 1 至 4 个封闭的背景孔。
- 每个物体外侧恰有一个灰色单像素"头"与其四邻接，头所在的一侧即该物体的朝向。
- 保证平移后各物体互不重叠且不越界；示例中设置"移动后并未贴住任何东西"与
  "途中越过其他物体所在行列"的情形，反证碰撞停止说与趋近目标说。

规则：
- 对每个物体，数出其封闭背景孔的连通块个数 N。
- 将物体连同其孔洞形状沿"从物体指向灰头"的方向平移 N 格。
- 删除所有灰头；物体原位置恢复背景。

关键洞察：
- 平移距离不由任何外部目标或碰撞决定，而由物体自身的孔数编码；灰头只提供方向，用完即弃。
```

## 6. 榫宽配槽宽·整件沉入

- tags:
  - operation:平移, translate
  - operation:重涂色, recolor
  - object:凸起, tab
  - object:缺口, notch
  - object:实心矩形, solid_rectangle
  - relation:宽度匹配, width_match
  - relation:互补拼合, complement_fit
  - condition:无匹配则不动, no_match_stays
  - condition:就近无效, nearest_fails
- 参考题目题号：12 (8dab14c2)、20 (681b3aeb)、8 (985ae207)

### docstring

```text
按榫头宽度把每个小件对接进大矩形上等宽的槽口并整件沉入体内，配不上的件原地不动。

输入结构：
- 黑底上有一个灰色大实心矩形，四条边上开有若干宽 1 至 3 格、深 1 格的槽口，槽口宽度互不相同。
- 场上散落若干彩色小件：每件为一个实心块加一个等宽、深 1 格的榫头，榫头朝向已与目标槽口所在边一致，无需旋转翻转。
- 其中恰有一件的榫宽与任何槽口都不相等（诱饵件）。
- 小件初始位置与其目标槽口既不同行列也不邻近；示例中设置"就近分配"与"同行分配"的反例。

规则：
- 将每个可配对小件平移到唯一等宽的槽口处：榫头填入槽口后继续沿同方向推入，
  直到整件完全没入大矩形轮廓之内、件的外缘与矩形该边平齐；件身覆盖到的灰格改为件色。
- 诱饵件保持原地不动。
- 其余小件的原位置恢复背景；矩形未被覆盖的灰色像素不变。

关键洞察：
- 三层咬合：槽口只是钥匙孔，榫宽与槽宽才是唯一配对钥匙；件不是贴在外壁而是整件沉入矩形体内，
  沉入深度由件自身进深决定；宽度无匹配的件是例外，根本不参与移动。
```

## 7. 互补残片的唯一姿态

- tags:
  - operation:镜像, mirror
  - operation:旋转, rotate
  - operation:裁剪, crop
  - operation:中心重建, reconstruct
  - object:矩形框, rect_frame
  - object:互补残片, complementary_fragment
  - relation:无冲突互补, conflict_free_complement
  - condition:唯一姿态, unique_pose
- 参考题目题号：18 (846bdb03)、6 (3af2c5a8)、14 (db0c5428)

### docstring

```text
框内残片与框外游离残片是同一图案的互补两半，找出唯一能无冲突拼满的旋转或镜像姿态并输出完整图案。

输入结构：
- 黑底上有一个灰色矩形框，框内已画有某多色图案的一部分像素（残片 A），其余框内格为黑。
- 框外有一个与框内区等大的游离色块（残片 B），是同一图案在某个旋转/镜像姿态下的另一部分像素，其余格为黑。
- 保证恰有一个 D4 变换使 B 与 A 无冲突（重叠格颜色一致）且两者并集恰好填满整个框内区域；
  按原样直放会发生颜色冲突（诱饵）。

规则：
- 找出该唯一变换，把 B 变换后与 A 逐格合并。
- 输出为框内区域的完整图案裁剪，不含灰框。

关键洞察：
- 正确姿态不能靠外观对称直觉，也不能默认原样放入：它只能由"无冲突且互补填满"这一联合判据唯一裁定，
  框内外两半各自单看都残缺无义。
```

## 8. 锚点对齐后才涌现的孔洞

- tags:
  - operation:逻辑或合并, logical_or_merge
  - operation:洪泛填充, flood_fill
  - operation:平移对齐, anchor_align
  - object:掩码, mask
  - object:分隔列, separator_column
  - object:锚点像素, anchor_pixel
  - relation:区域可达性, region_reachability
  - condition:合并后涌现封闭区, closure_emerges_after_merge
- 参考题目题号：5 (195ba7dc)、1 (543a7ed5)、18 (846bdb03)

### docstring

```text
以红锚点重合的方式叠合两块掩码，并集涂蓝，只有合并后才围死的黑色区域涂黄。

输入结构：
- 一条灰色贯通分隔列把网格分成两块等大的黑/橙掩码面板。
- 每块面板内各有一枚红色锚点像素，锚点不算掩码内容，其所在格按黑处理。
- 两块掩码图案相对各自面板边框的偏移不同：按面板边框直接叠合是错的
  （诱饵：首个示例按边框叠合貌似合理，后续示例失效）。
- 任一单块面板中都不存在封闭孔洞——每块面板上的"洞"都留有缺口。
- 蓝色与黄色在输入中不出现。

规则：
- 以两枚红锚点重合的方式把两块掩码平移叠合。
- 叠合后逐格求并：任一掩码为橙的格输出蓝。
- 在并集图中被蓝完全包围、不与裁剪边界连通的黑色区域涂黄；其余格保持黑。
- 输出为叠合后两掩码覆盖区域并集的最小外接矩形裁剪。

关键洞察：
- 三层咬合：对齐基准是红锚点而非面板边框；随后才是逐格并集；
  封闭区域在任一单块面板中都不存在，只有在正确对齐并合并后才涌现——两块掩码恰好互相补上对方的缺口。
```
