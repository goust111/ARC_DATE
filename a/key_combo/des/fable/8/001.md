## 1. 隐藏螺旋的周期修复

- 参考题目：9（e5c44e8f）、5（29ec7d0e）
- 难度评审：达标偏上
- tags:
  - operation:螺旋绘制, spiral_draw
  - operation:周期推断, period_inference
  - operation:补全, repair
  - object:隐藏中心, hidden_center
  - object:采样像素, sampled_pixel
  - relation:路径展开为序列, path_unrolled_to_sequence
  - condition:唯一中心可行, unique_center_feasible

### docstring

```text
把散落的彩色像素识别为一条隐藏方形螺旋上周期色带的采样，并把这段螺旋补画完整。

输入结构：
- 黑色背景网格上散布若干彩色像素，彼此互不相邻，乍看杂乱无章。
- 所有彩色像素实际位于同一条方形螺旋的路径上：螺旋自某个未标出的中心格出发，
  按上、右、下、左的方向循环行进，腿长依次为 1、1、2、2、3、3……
- 沿螺旋从中心逐格读出颜色时，这些像素是一个周期重复颜色序列的部分采样；
  该序列的每个周期位置至少被采样一次。

规则：
- 找出唯一的中心格，使所有彩色像素都恰好落在以它为起点的方形螺旋路径上。
- 将螺旋路径从中心到最远的彩色像素为止展开成一维格子序列，
  由已有像素推断颜色序列的最小周期。
- 按该周期给这段螺旋路径上的每个格着色（已有像素保持不变），其余格保持黑色。

关键洞察：
- 螺旋本身从未被画出，散点只是它的生成元；必须先做几何复原（定中心、复原路径），
  再把二维路径压成一维做周期修复——两个异质子问题缺一不可，任何一步都没有视觉捷径。
```

## 2. 周期瓦片的破缺折叠

- 参考题目：5（29ec7d0e）、13（47996f11）、12（b1fc8b8e）
- 难度评审：达标
- tags:
  - operation:周期推断, period_inference
  - operation:表决定位, majority_vote_locate
  - operation:坐标折叠, coordinate_folding
  - object:周期瓦片, periodic_tile
  - object:破缺像素, deviant_pixel
  - relation:商空间映射, quotient_space_mapping
  - condition:破缺色属图案调色板, deviant_color_in_palette
  - condition:折叠坐标互不冲突, folded_coords_distinct

### docstring

```text
在一幅周期平铺图案中找出违反周期的少数格，把它们折叠回瓦片坐标系，拼成一张瓦片大小的答案。

输入结构：
- 一幅稠密多色图案，是某个最小周期瓦片（行周期 p、列周期 q）在整幅网格上的平铺；
  p、q 不直接给出，需由图案自身推断。
- 少数格违反周期：其颜色与同瓦片坐标（行 mod p，列 mod q）的其余同类格不一致。
- 违反格所用的颜色全部取自图案本身大量使用的调色板，无法靠"生僻颜色"直接定位。

规则：
- 先由非破缺格的多数一致性推断最小瓦片尺寸与瓦片本色表：对每个瓦片坐标类做表决，
  占多数的颜色为本色，少数者即破缺格。
- 输出一张恰为 p×q 的网格：把每个破缺格按其（行 mod p，列 mod q）坐标折叠放入输出，
  画上它在输入中的（错误）颜色，其余格为黑。
- 不同破缺格不会折叠到同一瓦片坐标。

关键洞察：
- 偏差不是要修掉的噪声，而是被周期结构掩护的隐藏消息；且消息必须被搬回商空间
  （瓦片坐标系）才拼得成形——直觉的"按原图相对位置裁剪包围盒"会被示例推翻，
  周期既是定位破缺的裁判，也是重排破缺的坐标系。
```

## 3. 罗盘接力：碰撞激活的连锁滑动

- 参考题目：20（54dc2872）、9（e5c44e8f）、17（55783887）
- 难度评审：达标
- tags:
  - operation:平移, translate
  - operation:碰撞检测, collision_detect
  - object:嵌入标记像素, embedded_marker
  - object:单色精灵, mono_sprite
  - relation:激活传播, activation_propagation
  - relation:标记方位即方向, marker_side_is_direction
  - condition:唯一起点标记色, unique_start_marker_color
  - condition:每精灵至多滑动一次, each_sprite_moves_once

### docstring

```text
从唯一的起点精灵开始，沿各自内嵌罗盘的方向做碰撞接力滑动，未被撞到的精灵永远不动。

输入结构：
- 背景色画布上有若干单色精灵，每个精灵体内嵌一个异色标记像素。
- 标记像素紧贴其精灵包围盒的某一条边，指向上、下、左或右。
- 恰有一个精灵的标记颜色在全图独一无二，它是链条的起点；
  其余精灵的标记同为另一种颜色。

规则：
- 起点精灵沿其标记所贴的边的方向直线滑动，途经格必须全为背景，
  直到再前进一步就会与其他精灵重叠或出界为止。
- 若它因贴上另一个精灵而停下，被撞的精灵随即被激活，
  沿"自己"标记所指的方向按同样规则滑动；接力如此传递。
- 每个精灵至多滑动一次；撞停者即使对方随后滑走也不再补动；
  已滑动过的精灵再次被撞不会再激活。
- 未被激活的精灵保持原位，并作为障碍参与阻挡。
- 输出保留所有精灵及其内嵌标记，仅位置更新。

关键洞察：
- 内嵌标记既是身份也是罗盘：贴边方位编码各自的滑动方向；
  运动不是全体同时的重力压实，而是由唯一起点出发、经碰撞逐个点火的因果链——
  每一次滑动都改写后续的障碍布局，链条的形状只能按序模拟得到。
```

## 4. 自指遮挡：点数声明被压次数

- 参考题目：4（cf98881b）、8（6a11f6da）、7（edcc2ff0）、15（694f12f3）
- 难度评审：达标偏上
- tags:
  - operation:计数, counting
  - operation:约束求解, constraint_solving
  - operation:透明叠加, transparent_overlay
  - operation:擦除, erase
  - object:空心矩形, hollow_rect
  - object:内部标记点, interior_marker_dot
  - relation:点数即被压计数, dot_count_is_covered_count
  - relation:仅交叠框互相计数, only_overlapping_count
  - condition:满足全部声明的层序唯一, unique_consistent_depth_order

### docstring

```text
每个空心框肚子里的灰点数声明"有多少个框压着我"，解出唯一自洽的层序并按它重新合成画面。

输入结构：
- 黑色背景上有若干不同颜色的空心矩形框，框与框存在交叠；
  交叠格在输入中按某个任意的原始层序显示其中一个框的颜色。
- 每个框内部仅属于该框、不属于任何其他框内部的区域，散布若干灰色标记点。

规则：
- 灰点数不是排序键，而是自指声明：每个框的灰点数等于
  "在正确层序中位于该框之上、且与该框交叠的框的数目"；
  互不交叠的框彼此不计数，因此点数多寡与层高没有单调关系。
- 找出唯一满足全部声明的层序，然后按该层序从最底层开始
  逐个完整重绘每个空心框（框线补全、不再有缺口），并擦除全部灰色标记点。
- 输入中框与框的可见遮挡顺序与答案无关。

关键洞察：
- 深度不是被直接编码出来的数值，而是一组互相牵制的局部约束的唯一解；
  "点数多者靠上（或靠下）"两个方向的单调假设都会被示例推翻
  （存在同点数不同层、零点数却居中层的构造），
  必须把灰点重新理解为对交叠邻居的被压计数并做全局求解。
```

## 5. 四角窗口与投递锚

- 参考题目：3（af902bf9）、20（54dc2872）、14（e9ac8c9e）
- 难度评审：达标
- tags:
  - operation:平移, translate
  - operation:擦除, erase
  - object:角标记, corner_marker
  - object:隐形窗口, implicit_window
  - object:内嵌锚像素, embedded_anchor
  - object:孤立目标像素, isolated_target
  - relation:同色三重角色, one_color_three_roles
  - relation:颜色配对, color_pairing
  - condition:锚对齐目标, anchor_aligns_target

### docstring

```text
用四个同色角标围出的隐形窗口裁下其中的图案，以图案里混入的同色像素为锚，把整幅图案投递到远处的孤立同色像素上。

输入结构：
- 黑色背景。每组包含：四个颜色为 C 的像素，分别位于某个矩形四角的外侧对角处、
  共享两行两列，围出一个隐形窗口；窗口内部是一幅多色图案；
  图案内部恰有一个像素的颜色也是 C，乍看像杂色。
- 网格其他位置另有一个孤立的 C 色像素，是该组的投递目标。
- 存在多组时，各组的颜色 C 互不相同。

规则：
- 由四个角标推出隐形窗口的范围，取出窗口内部的整幅图案。
- 将图案整体平移，使图案中那个 C 色像素恰好落在孤立目标像素的位置，覆盖目标像素。
- 擦除图案的原位置与四个角标；图案中的 C 色像素随图案一起保留在新位置。

关键洞察：
- 被搬运的对象从未有明确边框，它由角标隐式围出；
  而配对与对齐由同一种颜色 C 一肩挑起三种角色——外侧的窗口角标、
  混在图案中的伪装锚点、远处的投递目标，三者缺一则搬运无从谈起。
```

## 6. 直方图不是汇总，是点名册

- 参考题目：19（2753e76c）、7（edcc2ff0）、15（694f12f3）
- 难度评审：达标
- tags:
  - operation:排序, sorting
  - operation:计数, counting
  - operation:擦除, erase
  - operation:裁剪, crop
  - object:指示条, indicator_bar
  - object:单色物体, mono_object
  - relation:条长即面积名次, bar_length_is_area_rank
  - condition:条长不等于任何面积, bar_length_never_equals_area
  - condition:未点名即擦除, unnamed_erased

### docstring

```text
把画面一侧的右对齐彩条读成排名点名册：每种颜色只保留其面积名次等于条长的那一个物体。

输入结构：
- 输入由一条分隔线分成两部分：一侧是直方图面板，每行至多一种颜色的右对齐实心条；
  另一侧是场景，含多种颜色的物体，同色物体互不相连且面积互不相同。
- 条长与该色任何物体的面积都不相等。

规则：
- 长度为 k 的颜色条表示：该颜色的所有物体按面积从大到小排名，
  名次恰为 k 的那一个物体被保留。
- 未被点名的同色物体，以及颜色未出现在直方图中的所有物体，一律擦除为背景。
- 输出只保留场景部分，直方图面板连同分隔线整体裁去。

关键洞察：
- 彩条不是对场景的计数汇总，而是反向下达的选择指令；
  且条长匹配的不是面积数值而是面积名次——第一直觉"条长=面积"
  会因条长与任何面积都不相等而被示例强制推翻，必须重建名次索引。
```
