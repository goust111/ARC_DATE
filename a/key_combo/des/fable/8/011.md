## 1. 抽走最上层的条

- tags:
  - operation:层序推断, infer_layer_order
  - operation:擦除, erase
  - operation:重力下落, gravity_drop
  - object:全幅条, full_span_bar

  - relation:邻接支撑, adjacency_support
  - condition:交叉可见色为上层, visible_at_crossing_is_top
  - condition:唯一极大层被移除, unique_top_removed
- 参考题目题号: 8(1a2e2828)、7(825aa9e9)
- 难度评审: 达标

### docstring

```text
总述
找出层叠横竖条中唯一处于最顶层的那一条并整条抽走，被抽走处恢复下层颜色，原本搁在这条横条上的小物块随之坠落到下一个支撑上。

输入结构
- 黑色背景上有若干单色条，每条要么横贯整行宽、要么纵贯整列高，颜色互不相同。
- 横条与竖条相互交叉，交叉格显示叠放次序中较高一条的颜色。
- 另有一种独立的物块色，构成若干 4 连通小物块，每个物块恰好紧贴在某条横条的正上方一行，且其所在各列不经过任何竖条。

规则
- 在每个交叉格上，由可见颜色得到"可见条压在另一条之上"的次序约束，汇总得到条带间的叠放偏序。
- 找到唯一没有任何条压在其上的条，将它整条抽走；它与其它条的交叉格改画为对应下层条的颜色，其余被抽走的格变为背景。
- 若被抽走的是横条：原本紧贴其上的每个物块沿所在各列整体竖直下落，直到再次紧贴某条横条的正上方一行，若下方再无横条则落至底边；其余物块保持不动。
- 若被抽走的是竖条，所有物块保持不动。

关键洞察
- 交叉格的颜色不是装饰而是叠放次序的证据；要抽走哪条并不由任何标记指定，而是由全部交叉共同推出的唯一极大层；抽条与坠落构成连锁，物块的落点取决于抽条之后的剩余地形。
```

## 2. 拼合残缺的副本

- tags:

  - object:残缺副本, partial_copy

  - condition:忽略干扰项, ignore_distractors
- 参考题目题号: 18(321b1fc6)、20(ff805c23)、1(42f14c03)
- 难度评审: 达标偏上

### docstring

```text
总述
画面上散布着同一多色图案的若干残缺副本，每个副本都有一部分格子被遮挡色盖住，有的副本还整体旋转了180度；把它们对齐合并，输出从未完整出现过的原图案。

输入结构
- 背景色占主导。场上有若干个同尺寸的矩形图案副本，彼此不相邻。
- 每个副本内，一部分格子显示图案的真实颜色，其余格子被同一种遮挡色覆盖；不同副本被遮挡的格子集合不同，任何一个副本都不完整。
- 部分副本相对原图案旋转了180度；图案本身没有旋转对称，方向可以唯一判定。
- 另有若干尺寸与副本不同的杂色矩形，属于干扰。

规则
- 找出所有同尺寸的候选副本，排除尺寸不符的干扰块。
- 确定遮挡色：它是唯一一种在各副本中占据位置互不一致、而其余颜色在对齐后完全吻合的颜色。
- 对每个副本尝试原方向与旋转180度两种摆法，选择使其未遮挡格与其他副本一致的方向。
- 将全部副本按同一方向对齐叠加，每个格子取任一未被遮挡的副本在该处的颜色，输出这幅完整图案。

关键洞察
- 答案在画面上从未整幅出现；遮挡色标记的是"未知"而不是颜色本身，完整图案只能由互补的残缺视图取并集得到，而每个副本的朝向要靠与其他副本的一致性反推。
```

## 3. 修复周期轨道的错点

- tags:
  - operation:周期推断, period_inference
  - operation:平移, translate
  - operation:重涂, recolor
  - operation:擦除, erase
  - object:轨道点, track_dot
  - object:散点, scattered_pixel
  - relation:颜色指针, color_pointer
  - condition:周期缺陷定位, periodic_defect
  - condition:忽略干扰项, ignore_distractors
- 参考题目题号: 17(e21d9049)、3(5168d44c)、5(f45f5ca7)、10(494ef9d7)
- 难度评审: 达标

### docstring

```text
总述
等距点组成的直线轨道按短周期循环着色，其中恰有一个点写错了颜色；错误颜色指向场上同色的那个散点，该散点移到错点处并被改涂成该位置本应有的周期色。

输入结构
- 一条水平或竖直的轨道由等距的单像素点组成，点色按一个短周期序列循环，恰有一个点破坏周期。
- 轨道之外散布若干单像素散点，颜色互不相同；其中恰有一点的颜色等于错点当前显示的错误颜色。
- 散点中同时存在颜色恰为"该位置本应有色"的一点，它是诱饵，保持不动。
- 背景为黑色。

规则
- 由轨道上其余点推断周期序列，定位唯一破坏周期的错点，并推出该位置本应有的颜色。
- 在散点中找到颜色与错点错误颜色相同的那一点，把它移到错点位置并改涂为周期应有色（错点由此被修正），擦除其原位置。
- 其余散点（包括与应有色同色的诱饵点）保持不动。

关键洞察
- 错误颜色不是要保留的信息而是指针，它选中哪个散点消失；真正要涂上的颜色在该处从未出现过，必须由周期推断得出；而与应有色相同的那个散点是天然诱饵——直觉的"把正确颜色补进来"恰恰是错的。
```

## 4. 表头的乘积

- tags:
  - operation:填充, fill
  - operation:擦除, erase
  - object:行标签, row_label
  - object:列标签, column_label
  - object:内部像素, interior_pixel
  - relation:行列交叉, row_col_intersection
  - relation:出现位置集合, occurrence_set
  - condition:笛卡尔积决定目标格, cartesian_product_targets
- 参考题目题号: 2(a406ac07)、5(f45f5ca7)、4(a6953f00)
- 难度评审: 达标偏上

### docstring

```text
总述
右边与底边是两条颜色表头，内部每个彩色像素被重新安置：它的目标格是"其颜色在右表头出现的所有行"与"在底表头出现的所有列"的全部交叉格。

输入结构
- 最右一列与最下一行是表头，其余为内部区域，内部以背景色为主。
- 表头由若干非背景颜色组成，同一颜色可以在一条表头中出现零次、一次或两次。
- 内部散布若干单像素，颜色取自表头用到的颜色集合。

规则
- 对每个内部像素的颜色 c：取右表头中所有颜色为 c 的行组成行集，取底表头中所有颜色为 c 的列组成列集。
- 擦除该像素原位置，把行集与列集的每一个交叉格都涂成 c。
- 若某一侧表头中 c 出现零次，交叉格集合为空，该像素被直接删除。
- 表头两条边保持不变；不同颜色的目标格互不冲突。

关键洞察
- 同一条规则在不同例子里呈现出"移动、复制成两份或四份、凭空消失"三种截然不同的表象；把它们统一起来的是表头出现位置集合的笛卡尔积——颜色在表头中的出现次数不是噪声，而是目标对象的重数。
```

## 5. 咬合连锁

- tags:
  - operation:重力下落, gravity_drop
  - operation:连锁反应, chain_reaction
  - object:地形, terrain
  - object:悬浮物块, floating_block
  - relation:互补轮廓, complementary_profile
  - relation:落定成为新支撑, settled_becomes_support
  - condition:完全支撑才停靠, full_support_seating
  - condition:不咬合则不动, no_fit_no_fall
- 参考题目题号: 7(825aa9e9)、6(18447a8d)
- 难度评审: 达标

### docstring

```text
总述
悬空物块只有在底部轮廓与支撑面完全互补时才会竖直落下咬合；每个落定的物块并入地形成为新的支撑面，从而解锁下一个物块，连锁进行直到再没有物块能落。

输入结构
- 底部是一条单色的不规则地形，向上起伏形成若干凹口。
- 上方悬浮若干形状各异的单色物块。初始时恰有一个物块能完全咬合，其余物块所需的目标轮廓要靠先落的物块顶面拼出。
- 另有诱饵物块：其宽度与某凹口相同但底部轮廓错位一格，永远无法咬合。
- 背景为黑色。

规则
- 支撑面初始为地形与底边。
- 反复执行：找出能沿所在各列竖直下移、使"物块与支撑不重叠，且物块每个底面格（各列中该物块最低的格）的正下紧邻格均为支撑"的物块（每一轮恰有一个），让它落到该唯一位置，并把它并入支撑面。
- 直到没有物块可落为止；不能咬合的物块保持原位悬浮。
- 地形保持不变，各物块保留自身颜色。

关键洞察
- 这不是一次性的重力题：下落的许可条件是"每格皆有支撑"的完全咬合，而先落的物块用自己的顶面轮廓拼出后落物块所需的凹口，落下顺序被咬合可行性唯一强制；轮廓只差一格的诱饵物块看似该落，却永远悬浮，首次接触即停的直觉是陷阱。
```

- 难度评审: 达标

### docstring

```text
总述
从场上唯一游离的小形状出发，把它当钥匙去开缺口形状与之互补的锁箱，箱内装的图案又是下一把钥匙，沿链一路开到底；最后取出的图案与任何剩余缺口都不互补，它就是答案，按其最小边界框裁剪输出。

输入结构
- 黑色背景上有若干空心矩形锁箱，每个箱壁上开有一个形状各异的缺口，箱内装着一个小图案。

- 每把钥匙的形状恰与至多一个箱的缺口互补（归一化平移后完全吻合）。
- 相当一部分锁箱在整条链上从未被打开，属于干扰；且若干干扰箱的内容物同样与任何缺口都不互补，仅凭"失配"无法辨认宝物，必须沿链行走。

规则
- 用当前钥匙在所有未开箱的缺口中找到形状互补的唯一缺口，打开该箱，取出箱内图案作为新钥匙。
- 重复此过程；当手中图案与任何未开箱的缺口都不互补时停止。
- 以最后取出图案的最小边界框裁剪输出，保留其颜色，背景为黑。

关键洞察
- 单次形状匹配只是一环，全部对象构成一条隐藏的指针链——每个箱子的内容物指向下一个箱子；大多数箱子是死路干扰，链的终点不由任何标记指定，而是由"再也开不动"这一失配条件判定，且必须从起始钥匙正向走链才能确定是哪一个。
```

## 7. 拉伸接力

- tags:
  - operation:拉伸, stretch
  - operation:连锁反应, chain_reaction
  - object:实心矩形, solid_rectangle
  - object:指示像素, indicator_pixel
  - object:画布边界, canvas_boundary
  - relation:方向指示, direction_indication
  - relation:碰撞传递, collision_relay
  - condition:留一格空隙, one_cell_gap
  - condition:末环拉至边缘, last_reaches_edge
- 参考题目题号: 14(b548a754)、19(b527c5c6)、7(825aa9e9)
- 难度评审: 达标

### docstring

```text
总述
唯一带指示点的矩形沿指示方向拉伸，撞上别的矩形时停下并把"继续拉伸"接力给被撞矩形的对侧，链条一路传递，直到某个矩形拉到画布边缘为止。

输入结构
- 黑色背景上有若干实心单色矩形，颜色互不相同。
- 恰有一个矩形的边上嵌着一个指示像素，指明拉伸方向（指示像素位于该矩形朝该方向的边上）。
- 沿该方向依次排开的矩形彼此不接触，行列跨度保证链上相邻矩形会正面相撞。

规则
- 带指示点的矩形沿指示方向整体加长，直到其前沿与下一个矩形之间只剩一格空隙时停止。
- 被撞上的矩形从它背向来向的一侧开始，按同一方向、同一规则继续加长；如此接力。
- 链上最后一个矩形前方再无矩形，它一直加长到画布边缘。
- 指示像素保留在原格；各矩形的加长部分使用各自的颜色。

关键洞察
- 只有一个标记，却有多个矩形变形：拉伸是会传染的因果链，每一环的终点由下一环的位置决定，而"留一格空隙"与"最后一环贴边"是两种不同的停止条件，缺一不可。
```

```text
总述
红色物块沿等距槽点轨道朝青色端标方向前进 N 槽，N 是场上完整 2×2 黄方块的个数；途中顶上灰色货箱就推着走，相邻货箱连锁前移。

- 一条水平或竖直轨道由等距的绿色槽点组成，一端槽点为青色方向标。

- 步数从未直接标出，须先用"完整方块"过滤规则从残块与噪点中数出 N；而灰箱既不是墙也不是可越过的空位，而是会被连锁推动的货物，它们在输出中的新位置由红块行程与初始间隙共同决定。
```

## 9. 按容积倒入凹槽

- tags:
  - operation:计数, counting
  - operation:擦除, erase
  - operation:重力铺平, gravity_fill
  - object:地形凹槽, terrain_basin
  - object:像素团, pixel_blob
  - relation:面积等于容积, area_equals_capacity
  - relation:量守恒配对, quantity_conservation_pairing
  - condition:形状无关, shape_irrelevant
  - condition:忽略干扰项, ignore_distractors
- 参考题目题号: 15(67c52801)、12(84f2aca1)、7(825aa9e9)、9(d4b1c2b1)
- 难度评审: 达标

### docstring

```text
总述
把每团彩色像素当作液体：数出它的面积，找到容积恰好相等的地形凹槽，把这团颜色擦除并按重力铺平填进那个凹槽。

输入结构
- 底部是灰色地形，向上起伏，围出若干侧壁封闭、上方开口的凹槽；各凹槽的容积互不相同。
- 上方悬浮若干形状不规则的单色像素团，颜色互不相同；每团的面积恰与某个凹槽的容积相等。
- 凹槽数量多于像素团数量，多出的凹槽保持空置。
- 至少有一团的形状恰好能嵌入某个容积不等的错误凹槽，构成形状匹配的诱饵。

规则
- 计算每个 4 连通像素团的面积，以及每个凹槽的容积（凹口内的背景格数）。
- 按"面积 = 容积"建立唯一配对。
- 擦除每团原有像素，在配对凹槽内填入该团颜色并恰好填满整个凹槽。
- 地形与空置凹槽保持不变。

关键洞察
- 这题看上去像形状匹配或俄罗斯方块，实际上形状毫无意义：守恒的量是面积，液体在凹槽里重新排布成完全不同的形状，配对的依据是"量"而不是"形"——能按形状嵌进去的那个凹槽恰恰是错的。
```

### docstring

```text
总述
每个矩形沿其指示点方向拉长，终点不是散点本身，而是与指示点同色的那颗散点所在的行（或列）线；散点的另一坐标毫无意义。

输入结构
- 黑色背景上有若干实心单色矩形，每个矩形一条边的中央嵌有一个异色指示像素，指明拉伸方向。
- 场上每种指示色各有一颗同色散点，位置任意，通常不在矩形的拉伸路径上。

规则
- 对每个矩形，找到与其指示像素同色的散点。
- 矩形沿指示方向整体加长，直到其前沿到达该散点所在的行（竖直拉伸时）或所在的列（水平拉伸时）。
- 散点被擦除；指示像素随矩形的这条边同步外移；不同矩形的拉伸互不干扰。

关键洞察
- 散点看似目的地，其实矩形根本不朝它去；散点只是一条不可见截止线留下的投影残迹——它的两个坐标中只有一个承载信息，另一个纯属干扰，而"拉到画布边缘"或"拉到碰见散点"的直觉都是陷阱。
```

## 11. 少数派批注

- tags:
  - operation:像素缩小, pixel_downscale
  - operation:分块推断, block_inference
  - object:放大块, scaled_block
  - object:少数色格, minority_cell
  - relation:整体缩放, uniform_scale
  - relation:少数覆盖多数, minority_overrides_majority
  - condition:块尺寸未标出, block_size_hidden
  - condition:因果反演, causal_inversion
- 参考题目题号: 9(d4b1c2b1)、20(ff805c23)、1(42f14c03)
- 难度评审: 达标

### docstring

```text
总述
网格是一幅小图按未知倍率整体放大的结果，但部分放大块里掺入了少量另一种颜色；还原小图时，掺色块对应的像素要取那种少数色，纯色块取本色。

输入结构
- 网格尺寸能被某个大于 1 的块边长整除，按该边长切块后，每块要么纯色，要么由一种多数色和一种少数色组成（少数色格数严格少于块面积的一半）。
- 块边长在不同例子中不同，且从未被标出。
- 少数色也都取自图案用过的调色板，无法凭颜色本身识别。

规则
- 找出最大的块边长 s，使网格可按 s×s 整除切块，且每块至多含两种颜色、其中一种占多数。
- 对每块：若只有一种颜色，输出像素取该色；若有两种，输出像素取其中的少数色。
- 按块的排布组成小图输出，尺寸为原网格除以 s。

关键洞察
- 直觉是把少数格当噪声、用多数表决抹平，而正确方向恰好相反——多数色只是放大后的底稿，散落的少数格才是对该像素的修订批注；同时放大结构毫无标记，块尺寸要靠"每块至多两色"的可整除分块性反推，这是放大操作的因果反演。
```
