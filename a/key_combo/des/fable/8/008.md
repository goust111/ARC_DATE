## 1. 针孔成像

- 参考题目题号: 15, 16, 18
- tags:
  - operation:投影成像, pinhole_projection
  - operation:填充, fill
  - object:空心矩形, hollow_rectangle
  - object:缺口像素, gap_pixel
  - relation:点对称映射, point_symmetric_mapping
  - condition:仅内部成像, image_clipped_to_interior

### docstring

```text
把箱外图案通过箱壁上唯一的缺口，以点对称方式成像到空心矩形箱体内部。

输入结构
- 黑色背景；一个单像素厚的空心矩形"箱体"，箱壁上恰有一个缺口（背景色像素）。
- 箱外散布若干彩色像素组成的图案；箱体内部为空。

规则
- 以缺口像素为对称中心，将箱外每个彩色像素映射到其点对称位置。
- 若映射位置落在箱体内部，则以原像素颜色涂上该格；落在其他位置的映射一律弃置。
- 箱外图案与箱体（含缺口）保持不变。

关键洞察
- 缺口不是破损而是"针孔"——成像是关于缺口这一单点的中心对称（倒像），
  而不是关于箱壁的轴镜像；只有穿过针孔后能落入箱内的像素才被底片记录。
```

## 2. 色带程序

- 参考题目题号: 2, 8, 9
- tags:
  - operation:指令执行, program_execution
  - operation:擦除, erase
  - object:单像素宽路径, one_pixel_path
  - object:边缘图例像素, border_legend_pixel
  - object:行走者像素, walker_pixel
  - relation:位置编码语义, position_encodes_semantics
  - condition:从行走者一端读带, read_from_walker_end

### docstring

```text
把多色路径当作串行指令带，按边缘图例把每种颜色译成方向，驱动行走者画出轨迹。

输入结构
- 背景为主色；网格四条边上各有一个孤立的彩色图例像素，四色互不相同。
- 场内有一条由这四种颜色组成的 4 连通单像素宽路径，恰有两个端点、无分叉。
- 一个灰色行走者像素与路径的某一个端点相邻，且不在路径上。

规则
- 每种颜色的方向由其图例像素所在的边决定：上边=向上，下边=向下，左边=向左，右边=向右。
- 从与行走者相邻的那个端点开始，沿路径逐格读出颜色序列。
- 行走者从自身位置出发，按读出的方向序列每条指令走一格。
- 输出中擦除整条路径，保留四个图例像素，行走者经过的所有格（含起点与终点）涂成灰色。

关键洞察
- 路径不是要被变换的几何对象，而是一条串行指令带；
  颜色的含义不由固定口诀给出，而由该颜色的图例像素贴在哪条边上现场定义。
```

## 3. 多数色印章

- 参考题目题号: 3, 7, 15
- tags:
  - operation:印章覆盖, stamp
  - operation:像素放大, scale_up
  - operation:颜色互换, color_swap
  - object:双色母图, two_color_motif
  - relation:自相似嵌套, self_similar_nesting
  - condition:多数色定基准, majority_color_as_identity

### docstring

```text
将双色母图自相似展开：多数色格贴原样副本，少数色格贴双色互换副本。

输入结构
- 输入是 h×w 网格，前景由恰好两种颜色组成一个母图，其余为背景。
- 两种前景色的格数不相等。

规则
- 输出为 (h·h)×(w·w)，输入的每一格对应输出中一个 h×w 块。
- 输入中多数色的格，其对应块贴入母图的原样副本。
- 输入中少数色的格，其对应块贴入两种前景色互换后的母图副本。
- 背景格对应的块全为背景。

关键洞察
- 这不是单一印章的分形展开——每个副本的配色由其父格在母图中
  扮演的颜色角色决定：多数色是"本色"，少数色触发反色副本。
```

## 4. 边影重建

- 参考题目题号: 5, 14, 16, 20
- tags:
  - operation:填充, fill
  - object:边缘线段, border_segment
  - object:隐形矩形, implicit_rectangle
  - relation:双投影交集, dual_projection_intersection
  - condition:小者在上, smaller_on_top
  - condition:忽略干扰项, ignore_distractors

### docstring

```text
用上边与左边同色线段的行列跨度重建实心矩形，重叠处小矩形盖住大矩形。

输入结构
- 黑背景；网格最上一行有若干水平彩色线段，最左一列有若干竖直彩色线段。
- 多数颜色在两条边上各出现一段；个别颜色只在其中一条边出现。
- 由双边影确定的各矩形面积互不相同。

规则
- 对每个同时在上边和左边出现的颜色，以上边线段给出的列区间和
  左边线段给出的行区间围成实心矩形并涂该色。
- 只在一条边出现的颜色不产生任何矩形。
- 两个矩形重叠时，重叠格涂面积较小者的颜色。
- 两条边上的原线段保持不变。

关键洞察
- 场内矩形从未被画出，它们只以两条正交边影的形式存在；
  重建之外还须发现叠放次序由面积决定——小矩形浮在大矩形之上，
  而缺一条边影的颜色是诱饵。
```

## 5. 反弹光带

- 参考题目题号: 2, 9, 14, 19
- tags:
  - operation:射线延伸, ray_extend
  - operation:反射, reflect
  - operation:计数, counting
  - object:图例色条, legend_strip
  - object:分隔线, separator_line
  - relation:段序对应色序, segment_order_matches_color_order
  - condition:图例长度定段数, legend_length_sets_count

### docstring

```text
从起点沿对角线发射光线在场内反弹，图例色条依次给出每段颜色，并以自身长度决定反弹段数。

输入结构
- 一条完整的分隔线把网格分成窄的图例区和大的竞技场。
- 图例区内有一条彩色色条（一串相邻彩色格）。
- 竞技场内有一个起点像素（颜色与色条第一格相同）和一个与它对角相邻的灰色方向点。

规则
- 光线从起点出发，朝灰色方向点所指的对角方向前进；
  撞到竞技场边界或分隔线即按镜面反射折返。
- 第 i 段轨迹涂图例色条第 i 格的颜色。
- 共画出与色条长度相同数量的段，画完最后一段抵达反弹点后停止。
- 灰色方向点被第一段轨迹覆盖；图例与分隔线保持不变。

关键洞察
- 色条同时承担两种职责——既是各段的调色顺序，又以自身长度充当反弹次数的计数器；
  起点颜色与色条首格同色是发现这一对应的入口线索。
```

## 6. 字形施法

- 参考题目题号: 4, 15, 18
- tags:
  - operation:镜像, mirror
  - operation:旋转, rotate
  - operation:平移映射, rigid_map
  - object:标记字形, marker_glyph
  - object:前景对象, fg_object
  - relation:字形对称类编码操作, glyph_symmetry_encodes_operation
  - relation:字形轴心为几何基准, glyph_axis_as_anchor
  - condition:原位擦除落新位, erase_source_place_image

### docstring

```text
小字形既示范要施加的变换，又以自身的对称轴或对称心充当变换的几何基准，把大对象刚体映射到网格的新位置。

输入结构
- 背景网格上有一个较大的不对称单色对象，和一个远离它的 3×3 单色小字形。
- 字形恰好具有一种对称性：仅左右镜像对称、仅上下镜像对称、或仅 180° 旋转对称。
- 变换后的对象落点保证在网格内。

规则
- 判定字形的对称类型。
- 若字形仅左右镜像对称：以经过字形中心列的整条竖直线为轴，把大对象反射到网格另一侧。
- 若字形仅上下镜像对称：以经过字形中心行的水平线为轴反射大对象。
- 若字形仅 180° 旋转对称：绕字形中心格把大对象旋转 180°。
- 对象原位置擦除，字形保持不变。

关键洞察
- 字形是一个完整的算子——它的对称类型说明"做什么"，它的对称轴/对称心说明"绕哪里做"；
  对象接受的恰是那次使字形自身保持不变的刚体变换。
  解题者看到的只是对象"瞬移并翻转"，必须同时破译操作类型与几何锚点两层编码。
```

## 7. 指针色链

- 参考题目题号: 4, 16, 20
- tags:
  - operation:排序, sorting
  - operation:拼接, concatenate
  - object:空心矩形, hollow_rectangle
  - object:内部指针像素, interior_pointer_pixel
  - relation:颜色指针链, color_pointer_chain
  - condition:无人引用者为链头, unreferenced_is_head
  - condition:忽略干扰项, ignore_distractors

### docstring

```text
空心框内的单个像素以颜色指向下一个框，沿链依序输出各框颜色。

输入结构
- 黑背景上散布若干互不同色的空心矩形框。
- 除一个框内部为空外，每个框内部恰有一个彩色像素，其颜色等于另一个框的框色。
- 另有一两个实心方块作干扰；框的空间位置与链序无关。

规则
- 内部像素建立"当前框 → 该颜色的框"的指向关系。
- 找到其框色未被任何内部像素引用的框作为链头，沿指向依次访问；内部为空的框是链尾。
- 输出一行 1×n 网格，按访问顺序写下各框的框色。
- 实心方块忽略，不参与链。

关键洞察
- 排列顺序既不是位置也不是大小，而是藏在框内的颜色指针拼成的链表；
  空腹之框是终点，无人指向之框是起点。
```
