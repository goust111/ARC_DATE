## 1. 汇合残迹显影

- 参考题目题号: 8 (29c11459)、7 (995c5fa3)
- tags:
  - operation:滑动, sliding
  - operation:裁剪, crop
  - object:孤立像素, isolated_pixel
  - object:汇合点, meeting_point
  - relation:同色配对, same_color_pairing
  - condition:奇偶定残迹, parity_sets_mark
  - condition:残迹组图, marks_form_sprite

### docstring

```text
让每对同色像素相向滑动，只保留汇合残迹，并裁剪出残迹拼成的隐藏图案。

输入结构:
- 黑色背景网格上散布若干非黑像素，每种颜色恰好出现两次。
- 每对同色像素位于同一行或同一列，两者之间全为黑色。
- 全部汇合残迹合起来构成一个紧凑的小图案。

规则:
- 每对像素同时相向移动，不在沿途留下任何轨迹。
- 两像素间空格数为奇数时，双方汇合于正中一格，留下该颜色的单格残迹；
  空格数为偶数时，双方停在中央相邻两格，留下该颜色的双格残迹。
- 输出为所有残迹的最小包围盒裁剪，残迹保持各自颜色，其余为黑。

关键洞察:
- 输入像素本身不是图案，图案由每对像素的汇合位置生成；
  间距奇偶决定残迹是一格还是两格，裁剪之后隐藏图形才会显现。
```

## 2. 卷轴复位与镜像修复

- 参考题目题号: 18 (6d1d5c90)、2 (b7955b3c)
- tags:
  - operation:循环位移, cyclic_roll
  - operation:补全, complete
  - object:标记像素, marker_pixel
  - object:遮挡块, occluder
  - relation:行偏移编码, row_offset_encode
  - relation:轴对称, mirror_symmetry
  - condition:先复位后修复, realign_then_repair

### docstring

```text
按灰色标记把每一行卷回原位，再用恢复出的左右对称性修补被遮挡的格子。

输入结构:
- 矩形网格的每一行恰好含有一个灰色像素，其余为一幅彩色图画的格子。
- 原始图画中灰色像素全部位于最左列，其右侧部分左右轴对称；
  输入是对原图每行各自做了不同量的循环右移得到的。
- 少量非灰色格子被色 8 覆盖，且任一被覆盖格的镜像位置未被覆盖。

规则:
- 将每一行循环移动，使该行的灰色像素回到最左列。
- 删除最左侧的灰色列。
- 对剩余图画中的每个色 8 格，用其关于竖直中轴的镜像格颜色填补。
- 输出修复完成的图画。

关键洞察:
- 灰色像素是每行被打乱量的记录，对称性只有在全部行复位后才显现；
  必须先解卷再修补，直接在输入上寻找对称是徒劳的。
```

## 3. 框沿标记的滑动与灌色

- 参考题目题号: 5 (9b4c17c4)、1 (c3fa4749)
- tags:
  - operation:滑动, slide
  - operation:填充, fill
  - object:矩形边框, rect_frame
  - object:标记像素, marker_pixel
  - object:带孔对象, holed_object
  - relation:包含于, contained_in
  - condition:标记侧定方向, marker_side_direction
  - condition:标记色灌孔, marker_color_fills_holes

### docstring

```text
框上的异色标记指挥框内对象贴向该侧，并把对象的孔洞灌成标记色。

输入结构:
- 黑色背景上有若干互不接触的单色空心矩形框。
- 每个框的边框上恰有一格被替换成第三种颜色的标记，位于某条边上而非角上。
- 每个框内部有一个与框异色的四连通对象，含至少一个被对象完全包围的
  黑色孔洞，且尚未贴住标记所在的那条边。

规则:
- 每个框内对象沿垂直于标记所在边的方向整体平移，直到贴住该边的内侧。
- 平移完成后，把对象包围的孔洞全部填成标记的颜色。
- 标记格恢复为框的颜色；框、背景及其余部分保持不变。

关键洞察:
- 一格标记同时编码两件事：它所在的边给出滑动方向，它的颜色给出孔洞
  的灌色；对象并不与标记对齐，吸引它的是整条边而非标记那一格。
```

## 4. 破壁弹珠

- 参考题目题号: 15 (28e73c20)、5 (9b4c17c4)、8 (29c11459)
- tags:
  - operation:连线, draw_line
  - operation:擦除, erase
  - object:围墙, boundary_wall
  - object:缺口, gap
  - object:转向子, turn_pixel
  - relation:颜色决定方向, color_determines_direction
  - condition:一次性机关, single_use_trigger
  - condition:撞墙破口, breach_on_wall_hit

### docstring

```text
弹珠从围墙唯一缺口射入，按一次性转向子的颜色左转或右转，最终撞穿围墙，留下可自交的轨迹与新缺口。

输入结构:
- 网格四周有一圈灰色围墙，围墙上恰好缺一格，即入口。
- 围墙内部为黑色，散布若干红色与蓝色的单格转向子。
- 转向子是一次性的，部分转向子会被弹珠先后两次逼近。

规则:
- 弹珠从入口沿垂直于该边的方向进入内部，走过的每个内部格涂成黄色。
- 前进方向的下一格是红色转向子时原地右转九十度，是蓝色转向子时原地
  左转九十度，且该转向子随即消失，变为可通行的普通格。
- 已消失转向子的位置与已涂黄的轨迹格都可被再次直行穿过，轨迹可自交。
- 前进方向的下一格是围墙时，该墙格被撞穿改为黄色，弹珠离场，模拟结束；
  被触发过的转向子在输出中不再出现，未触发的原样保留。

关键洞察:
- 转向子不是永久路标而是一次性机关：同一位置第一次经过转向、第二次
  经过直行；不发现"消耗"这一层，就无法解释输出中消失的转向子与自交
  的轨迹，也追不出正确的破墙位置。
```

## 5. 螺旋轨道引力

- 参考题目题号: 15 (28e73c20)、9 (8e1813be)、5 (9b4c17c4)
- tags:
  - operation:滑动, slide
  - operation:排序, sorting
  - object:孤立像素, isolated_pixel
  - object:路径, path
  - relation:隐式一维轨道, implicit_1d_track
  - condition:顺序守恒压实, order_preserving_compaction

### docstring

```text
把散点视作串在隐形螺旋轨道上的珠子，全部滑向螺旋末端并压实。

输入结构:
- 黑色背景矩形网格上散布若干彩色单像素。
- 隐形轨道为从左上角向右出发、顺时针向内、遍历全部格子的螺旋路径。
- 像素颜色可以重复，位置任意。

规则:
- 将所有彩色像素沿螺旋路径向末端（螺旋中心一侧的终点）滑动，互不穿越。
- 滑动到不能再动为止，即全部像素占据螺旋路径最末端的连续若干格。
- 像素颜色不变，先后次序保持它们在螺旋路径上的原有次序。

关键洞察:
- 网格其实是一条一维轨道，规则是轨道上的顺序守恒压实；看穿二维散点
  背后的螺旋线序才是入口，向心聚拢只是表象。
```

## 6. 残卷推演

- 参考题目题号: 13 (6430c8c4)、19 (dae9d2b5)、2 (b7955b3c)
- tags:
  - operation:布尔运算, boolean_op
  - operation:补全, complete
  - object:并列面板, side_by_side_panel
  - object:分隔线, divider_line
  - object:未知遮罩, unknown_mask
  - relation:逐格对齐, cell_alignment
  - condition:由残例反推运算, infer_op_from_partial

### docstring

```text
用第三块残缺面板上寥寥几格的已知结果，反推两块掩码面板之间的布尔运算并补全全图。

输入结构:
- 三块等尺寸面板横向排列，由两条灰色整列分隔。
- 前两块面板各含一种前景色与黑色背景。
- 第三块面板大部分格子为色 8（未知），少数格子已揭示为黑色或第三种
  前景色；它是前两块面板按某种逐格布尔运算（并、交、差、对称差之一）
  得到的结果图，已揭示格足以唯一确定该运算。

规则:
- 将三块面板逐格对齐，列出候选布尔运算。
- 用已揭示格逐一排除不一致的运算，锁定唯一运算。
- 按该运算把所有色 8 格补全：结果为真处涂第三种前景色，为假处涂黑。
- 输出补全后的第三块面板。

关键洞察:
- 运算类型不是固定的，而是每个示例各自隐藏的未知量；已揭示的少数
  格子是用来鉴别运算的证据，而非需要保留的装饰。
```

## 7. 缺口指针与层色滚动

- 参考题目题号: 18 (6d1d5c90)、14 (7d1f7ee8)、6 (d2acf2cb)
- tags:
  - operation:循环位移, cyclic_roll
  - operation:重涂色, recolor
  - object:矩形边框, rect_frame
  - object:缺口, gap
  - relation:严格包含, strict_containment
  - relation:深度轴位移, depth_axis_shift
  - condition:缺口层定滚量, gap_depth_sets_shift

### docstring

```text
把每条嵌套框链的颜色沿深度方向循环下滚，滚动层数由链中带缺口的那个框的深度指定。

输入结构:
- 黑色背景上有若干组互不接触的嵌套单色空心矩形框，每组构成一条由外
  到内的包含链，各层颜色互不相同。
- 每条链中恰有一个框的边框上缺了一格（该格为黑色），其余框完整。

规则:
- 对每条链，设带缺口的框由外向内数处于第 d 层（最外层为第 1 层）。
- 将这条链的层颜色序列整体向内循环移动 d 层，即第 k 层框改涂原第
  k−d 层（按链长取模）的颜色。
- 所有框的形状、位置、缺口保持不变，只有颜色改变。

关键洞察:
- 循环位移发生在"包含深度"这条隐藏的轴上而不是几何行列上；缺口不是
  破损而是指针，它所在的深度编码滚动量，各链的滚动量彼此独立。
```
