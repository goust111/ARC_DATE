## 1. 连锁开门射线

- tags:
  - operation:射线延伸, ray_extend
  - operation:洪泛填充, flood_fill
  - object:空心矩形, rectangular_frame
  - object:边框缺口, border_gap
  - relation:缺口对齐, gap_alignment
  - condition:连锁传播, chain_propagation
  - condition:边框阻挡, wall_blocking
- 参考题目题号: 6、10、13

### docstring

```text
从内部已点亮的空心矩形出发，让射线沿缺口方向传播，逐个点亮缺口对齐的后续矩形，形成多米诺式的填充链。

输入结构：
- 黑色背景上有若干蓝色空心矩形框，边框为一像素厚。
- 每个矩形框在非角位置恰有两个缺口，分别位于不同的边；只有一个源矩形恰有一个缺口，且其内部已被青色填满。
- 部分矩形与传播路径对齐但对齐处是框壁而非缺口，它们是诱饵。

规则：
- 源矩形从其唯一缺口向外发射一条青色射线，沿垂直于该边的方向直行。
- 射线遇到网格边缘即终止；遇到矩形框壁像素即被挡下终止；若恰好命中某矩形的缺口，则穿入该矩形，将其内部全部填为青色。
- 被点亮的矩形随后从它的另一个缺口继续向外发射青色射线，重复上述过程，直到射线离开网格或被框壁挡住。
- 未被链条触及的矩形保持空心不变；射线经过的黑色格全部涂为青色，缺口格本身也被涂青。

关键洞察：
- 缺口不是要修补的缺陷而是门：一进一出，整幅图是一条由缺口对齐关系决定的单一传播链；与射线对齐但撞在框壁上的矩形只是诱饵。
```

## 2. 残迹双锚

- tags:
  - operation:补全, completion
  - operation:搜索, search
  - object:紧凑原型, compact_prototype
  - object:残迹像素, residue_pixel
  - relation:刚体变换, rigid_transform
  - condition:双锚定姿态, two_anchors_fix_pose
- 参考题目题号: 17、18、19、20

### docstring

```text
网格中散落的成对残迹像素是被擦除的原型副本仅存的痕迹，用每对残迹反推刚体变换并补画整个副本。

输入结构：
- 背景为黑色；网格某处有一个完整的多色紧凑原型（4连通对象）。
- 其余区域散布若干对孤立彩色像素；每对相互靠近（间距不超过原型对角线长度），不同对之间相距很远。
- 每个残迹像素的颜色都出现在原型中，且题目保证每对残迹在原型的各种姿态下只有唯一一种匹配方式。

规则：
- 找到唯一的完整原型对象。
- 将残迹像素按邻近性分组为对。
- 对每一对，在原型的8种姿态（4个旋转乘以是否镜像）中找出唯一的姿态与平移，使原型中两个对应颜色的格子恰好落在这对残迹像素上。
- 按该姿态与位置把整个原型补画出来，残迹像素本来就是副本的一部分；原型本体保持不变。

关键洞察：
- 单个残迹只能定位不能定向，两个残迹合起来唯一锁定副本的旋转、镜像与平移；画面上从未画出的副本要靠这两粒化石整体复原。
```

## 3. 隐形巡游换色

- tags:
  - operation:重涂色, recolor
  - operation:贪心遍历, greedy_traversal
  - object:起始块, start_block
  - relation:视线可见, line_of_sight_visible
  - relation:访问序列, visitation_order
  - condition:最近未访问优先, nearest_unvisited_first
  - condition:颜色沿序后移, colors_shift_along_walk
- 参考题目题号: 10、11

### docstring

```text
方块的颜色沿一条看不见的最近可见邻居巡游路线整体后移一位，路线本身不画出来。

输入结构：
- 背景黑色，散布若干同尺寸实心小方块，其中恰有一个灰色方块作为起点，其余方块颜色互不相同。
- 方块之间可能处于同两行或同两列的带状对齐；带内两块之间若有其他方块像素则互相不可见。

规则：
- 从灰色方块出发，反复走向与当前方块同带可见且未访问过的方块中距离最近的那一个（题目保证最近者唯一），直到无处可走，得到一条访问序列。
- 不画任何走廊：仅把颜色沿访问序列整体后移一位——序列中每个方块改涂成它前一个方块的颜色，灰色起点改涂成序列最后一个方块的颜色。
- 从未被访问到的方块保持原色不动。

关键洞察：
- 输出里颜色的置换不是按任何空间排序，而是按一条隐藏的贪心巡游路线；必须先在脑中走完这条路，才能知道谁把颜色交给谁。
```

## 4. 证据格线

- tags:
  - operation:周期填充, periodic_fill
  - operation:补全, completion
  - object:格线, grid_line
  - object:孤立点, isolated_dot
  - relation:同余对齐, modular_alignment
  - condition:证据计数定真伪, evidence_count_decides
  - condition:交点补另色, intersections_other_color
- 参考题目题号: 13、14

### docstring

```text
由散点的同余节拍复原隐藏格线，只有获得多粒支持的节拍才是真格线，孤证的点是冒名者要被抹去。

输入结构：
- 黑色背景上散布蓝色像素点。
- 大多数点落在一组等间距的隐藏水平线与一组等间距的隐藏垂直线上，两组各有自己的周期与相位；少数点不落在任何真格线上。
- 行方向与列方向上，真同余类获得的支持点数唯一最多。

规则：
- 在行方向与列方向分别找出支持点最多的同余类（间距一致且相位一致），这些同余类的位置就是真格线。
- 输出中把每条真水平线整行、每条真垂直线整列涂成蓝色；真横线与真竖线的交点格涂成红色。
- 不在任何真格线上的孤立点是假点，抹成黑色。

关键洞察：
- 格线从未整条画出，位置要靠周期同余从散点投票中推出；多粒支持是分辨真格线与冒名孤点的证据标准，落错节拍的点再显眼也只是冒名者。
```

## 5. 配额接力

- tags:
  - operation:滑动, slide
  - operation:射线延伸, trail_painting
  - object:引导像素, guide_pixel
  - object:轨迹条纹, trail_stripe
  - relation:同线对齐, colinear_alignment
  - condition:位移配额传递, displacement_quota_transfer
  - condition:引导色定首动, guide_color_selects_mover
- 参考题目题号: 1、10、12、15、20

### docstring

```text
角落引导色点选中同色方块并触发一次推挤，位移作为会被路程消耗的配额沿同一直线在方块间接力传递，扫过区域涂橙。

输入结构：
- 黑色背景；若干实心彩色小矩形排在同一行或同一列上，彼此之间有间隙。
- 网格一个角落有一个引导像素，其颜色与线上某个矩形相同。

规则：
- 引导色指定首动块；推动方向沿该直线、背离引导像素所在的一端。
- 首动块沿方向滑动直到贴上最近的下一块，记滑动距离为 d；若前方直到网格边都没有块，则滑到贴边为止。
- 被贴上的块获得配额 d 并沿同方向滑动：若滑满 d 格没有碰到块，就停在原地（可能停在空地中间）；若滑了 e（e 小于 d）格就贴上了再下一块，则它停下并把剩余配额 d 减 e 传给那一块，依此类推；配额为零则不再传递。
- 任何块滑到贴住网格边即令整条链终止。
- 每个滑动过的块扫过的格子涂橙，块以原色画在终点位置；引导像素在输出中消失。

关键洞察：
- 传递的不是推到底的指令，而是一份会被路程消耗的位移配额——后面的块可能停在空地中间，全部压实到边的直觉在多数示例中失效。
```

## 6. 缺口读带填圈

- tags:
  - operation:填充, fill
  - operation:周期填充, periodic_fill
  - object:空心矩形, rectangular_frame
  - object:边框缺口, border_gap
  - object:周期色带, periodic_color_band
  - relation:圈层投影, ring_projection
  - condition:缺口定读数起点, gap_sets_read_head
  - condition:无缺口不填, no_gap_no_fill
- 参考题目题号: 2、4、5、6

### docstring

```text
每个空心矩形的边框是一条绕周长卷绕的循环色带，从边框缺口处开始读出这条色带，并把读出的颜色序列一圈一圈向内填充矩形内部。

输入结构：
- 黑色背景上有若干空心矩形框，边框一像素厚，内部为黑。
- 每个框的边框像素不是单色，而是沿周长循环排列的一段颜色序列；序列非对称，正读与反读不同，不同起点读出的序列也不同。
- 大多数框在非角位置恰有一个缺口（缺失一个边框像素）；恰有一个框完全闭合、没有缺口。

规则：
- 对每个有缺口的框：从缺口处沿顺时针方向读边框颜色，得到一个颜色序列。
- 把矩形内部划分为同心圈层：紧贴边框的一圈为第1层，向内依次为第2层，最内层可能退化为一行、一列或一格。
- 第 k 层整层涂成序列第 k 项的颜色，序列用尽则循环再读。
- 缺口本身在输出中保持为背景色；没有缺口的框无从读起，内部保持黑色不变，边框原样保留。

关键洞察：
- 缺口不是要修补的缺陷，也不是射线的出口，而是循环色带的读数起点；边框上的一维周期序列被卷绕着投影到内部的径向圈层上，没有读数头的闭合框只是诱饵。
```
