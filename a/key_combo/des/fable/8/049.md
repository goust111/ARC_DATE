## 1. 周期损伤地图

- 参考题目: 18 (0dfd9992), 1 (d47aa2ff)
- tags:
  - operation:补全, inpaint
  - operation:逐像素比较, pixel_comparison
  - object:周期瓦片, periodic_tile
  - relation:平移对称, translational_symmetry
  - condition:差异分类着色, diff_class_color
  - condition:隐式参照图, implicit_reference

### docstring

```text
根据平移周期恢复出从未画出的真实图案，输出的不是修复图，而是按损伤方式分类着色的损伤地图。

输入结构
- 网格本应是一幅由非零颜色构成的平移周期平铺图案，真图案中不含黑色。
- 少数格子被破坏：一部分被清成黑色（缺失），另一部分被改写成与真色不同的其他非零颜色（篡改）。
- 未破坏的格子足以确定唯一的平移周期与每格真色。

规则
- 先由可见格子的平移轨道恢复每个格子的真实颜色。
- 输出与输入同尺寸：与真色一致的格子一律输出黑色。
- 输入中被清成黑色的损伤格输出青色；输入中被改成错误非零色的损伤格输出红色。

关键洞察
- 被比较的干净周期图从头到尾没有出现在画面上，它只能由轨道多数色重建；输出是"输入与隐式真图的差异分类图"，而不是修复结果。
```

## 2. 隐形射线的交点

- 参考题目: 20 (705a3229), 16 (95a58926)
- tags:
  - operation:射线延伸, ray_extend
  - object:孤立像素, isolated_pixel
  - object:虚拟路径, virtual_path
  - relation:投射到最近边界, projection_to_nearest_edge
  - relation:行列交叉, row_col_intersection
  - condition:只落交点, intersection_only

### docstring

```text
每个孤立像素向最近的水平边与垂直边各投出一条看不见的射线，输出只在不同像素的射线交叉处落子。

输入结构
- 黑色背景上散布若干互不相邻的彩色孤立像素。
- 每个像素到上下两边的距离不等，到左右两边的距离也不等。
- 构造保证任何交叉格上没有已有像素，且每个交叉格只被一对射线覆盖。

规则
- 为每个像素设想两条射线：沿所在列伸向较近的上边或下边，沿所在行伸向较近的左边或右边；射线本身不画出。
- 对每一对不同像素 A、B：若 A 的水平射线与 B 的垂直射线相交于某格，则该格涂上 B（提供垂直射线的一方）的颜色。
- 输出保留全部原始像素，其余格保持黑色。

关键洞察
- 射线是从未被画出的中间对象；答案不是画 L 形（那是诱饵），而是求隐形轨迹的两两交点，交点颜色由"竖直方"继承。
```

## 3. 排名直方图过滤

- 参考题目: 3 (b7999b51), 7 (1a07d186)
- tags:
  - operation:计数, counting
  - operation:排序, sorting
  - operation:擦除, erase
  - object:柱状图, histogram_bar
  - object:前景颜色掩码, foreground_color_mask
  - relation:颜色配对, color_pairing
  - condition:柱高为排名索引, bar_height_is_rank

### docstring

```text
底边柱状图不是统计结果而是点名册：颜色 c 的柱高 h 表示保留该颜色面积第 h 大的那个物体。

输入结构
- 网格底边贴着若干互不接触的单色竖柱，柱色互不相同。
- 上方场地中每种柱色各有若干个互不接触的物体，同色物体的像素数两两不同。
- 每种场上颜色都恰有一根对应颜色的柱，柱高不超过该色物体个数。

规则
- 对每种颜色 c，把该色物体按像素数从大到小排名。
- 只保留排名等于 c 色柱高的那个物体，位置与形状不变；该色其余物体全部擦成黑色。
- 所有柱也一并擦除，输出只剩被点名的物体。

关键洞察
- 第一眼会以为柱高统计的是面积或数量（参考题的正向逻辑），实际柱高是"第几名"的序数索引；必须先完成一次隐式排序才能读懂图例。
```

## 4. 条纹行程单

- 参考题目: 9 (746b3537), 19 (3e6067c3)
- tags:
  - operation:压缩, compress
  - operation:连线, draw_line
  - object:色带, color_stripe
  - object:标记像素, marker_pixel
  - relation:控制序列, control_sequence
  - condition:连续重复折叠, dup_collapsed
  - condition:段色记出发地, segment_takes_source_color

### docstring

```text
把左侧粗细不一的条纹压缩成颜色序列，作为右侧场地上的行程单，按序用 L 形线路连接各同色站点。

输入结构
- 一条灰色整列分隔线把网格分为左右两部分。
- 左部由若干整高竖条纹组成，条纹厚度不一，相邻条纹颜色不同。
- 右部黑底上，每个条纹颜色恰有一个单像素站点。

规则
- 将左部条纹按从左到右的顺序压缩去厚度，得到访问序列 c1, c2, …, ck。
- 从 c1 站点出发依次驶向下一站：每段先水平走到目标站所在列，再垂直走到目标站；行列已对齐时走直线。
- 每段经过的空格涂该段出发站的颜色 ci，站点保留自身颜色；分隔线与左部原样保留。

关键洞察
- 条纹厚度是诱饵，它不编码任何步长信息，只有去重后的颜色顺序才是指令；每段线的颜色记录的是"从哪来"而不是"到哪去"。
```

## 5. 弹道相撞

- 参考题目: 6 (e619ca6e), 1 (d47aa2ff)
- tags:
  - operation:印章覆盖, stamp
  - operation:裁剪, clip
  - object:实心矩形, solid_rect
  - relation:对角偏移重复, diag_offset_repeat
  - relation:朝向对方, toward_each_other
  - condition:尺寸决定步幅, size_determines_stride
  - condition:重叠标红, overlap_marked

### docstring

```text
两个实心矩形各自朝对方所在的象限方向按自身尺寸为步幅重复盖章，两条弹道的重叠区域涂红。

输入结构
- 黑底上只有两个颜色不同的实心矩形，二者行区间与列区间均不重叠。
- 两矩形的高宽可以不同，因而两条弹道的步幅不同。

规则
- 每个矩形沿单一对角方向重复出现：行方向取对方所在的上或下，列方向取对方所在的左或右；每步偏移量等于自身的（高, 宽），出界部分裁掉，完全出界即停。
- 先各自铺出整条弹道（含原矩形），再逐格比较：只被一条弹道覆盖的格涂该弹道颜色。
- 同时被两条弹道覆盖的格涂红色。

关键洞察
- 与"向两个对角方向铺满"的印象不同，每条弹道只有指向对方的单一方向；两条步幅不同的等差轨迹在中途交错，答案的红区是两组印章集合的逐格交集。
```

## 6. 幽灵小车

- 参考题目: 12 (2dd70a9a), 13 (182e5d0f)
- tags:
  - operation:寻路, pathfinding
  - operation:擦除, erase
  - object:起止标记, start_end_marker
  - object:转向珠, turn_bead
  - object:虚拟路径, virtual_path
  - relation:颜色编码转向, color_encodes_turn
  - condition:珠被消耗, bead_consumed
  - condition:门前停止, stop_at_gate
  - condition:路径不画出, path_never_drawn

### docstring

```text
一辆看不见的小车从绿色起点线开出，踩珠转向、吃珠前行，输出只留下"哪些珠消失了、车停在了哪"，整条路线从头到尾不画出。

输入结构
- 黑底上有一段绿色直线段（车库，其走向给出发车方向）和一段红色直线段（终点站）。
- 场中散布青色与橙色的孤立单像素转向珠，其中一部分并不在小车的路线上。

规则
- 小车从绿线前端出发沿绿线方向逐格直行；下一格若是转向珠，则驶上该格、吃掉该珠并转向：青珠右转九十度，橙珠左转九十度。
- 下一格若属于红线则停车。
- 输出：绿色车库整段擦成黑色，被吃掉的珠擦成黑色，停车格上放一个绿色像素；未被经过的珠与红线原样保留，路线上的其他格保持黑色。

关键洞察
- 路径是从未画出的隐形对象：示例的输入输出差异只有"消失的珠子集合"与"一个新绿点"，必须由哪些珠消失、停点在哪反推出整条路线，进而反解青/橙与右/左转的对应关系；任何一颗被误判的珠都会让路线对不上消失集合。
```

## 7. 循环壁纸填框

- 参考题目: 4 (5af49b42), 10 (d5d6de2d)
- tags:
  - operation:填充, fill
  - operation:展开, expand
  - object:边缘图例串, edge_legend_string
  - object:空心矩形, hollow_rectangle
  - object:孤立标记, isolated_marker
  - relation:颜色位置匹配, color_position_matching
  - condition:图例锚定对齐, legend_anchored_alignment
  - condition:周期延拓, periodic_extension

### docstring

```text
把顶边图例串当作循环壁纸，用每个空心框内的标记像素做相位锚，将框的整个内部按列铺满对应相位的壁纸。

输入结构
- 顶行有一段水平颜色串（图例），串内颜色互不相同。
- 场中有若干空心矩形框，框色不在图例串中；每个框内部恰有一个标记像素，其颜色在图例串中出现。
- 部分框的内部宽度大于图例串长度。

规则
- 把图例串视为向左右无限循环延拓的周期序列。
- 对每个框：设标记像素在列 m、其颜色位于串中第 p 位，则框内部每一列 c 的所有格子都填上串中第 (p + c − m) mod L 位的颜色（L 为串长）。
- 框的边保持原样，图例串保持原样；不同框因标记不同而呈现同一壁纸的不同相位。

关键洞察
- 图例串不是复制一次就完（那是参考题的旧逻辑）：框宽超过串长逼出"串是循环序列"这一步；标记像素同时锁定颜色与相位，空心框只是壁纸的取景窗。
```
