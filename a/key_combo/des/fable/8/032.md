## 1. 残彩影子

- tags:
  - operation:补全, completion
  - operation:平移, translation
  - operation:重涂色, recolor
  - object:精灵体, sprite
  - object:影子副本, shadow_copy
  - object:残迹色斑, residue_stain
  - relation:统一位移配对, uniform_offset_pairing
  - condition:残色决定重建色, stain_determines_color
- 参考题目题号: 12、9、1

### docstring

```text
从孤儿影子与其残留色斑重建从未画出的精灵。

输入结构：
- 黑色背景上有若干颜色互不相同的多格精灵。
- 每个精灵配有一个灰色同形副本（影子），所有精灵到其影子的位移向量相同。
- 恰有一个影子没有对应精灵（孤儿影子）；它的某一个格不是灰色而是别的颜色
  （色斑），该颜色未被任何现有精灵使用。

规则：
- 由完整的精灵—影子配对求出全局统一位移向量。
- 将孤儿影子的形状沿位移向量反向平移，得到缺失精灵的位置。
- 在该位置以色斑颜色画出完整精灵；把孤儿影子上的色斑格改回灰色。
- 其余内容原样保留。

关键洞察：
- 参与规则的对象从未被完整画出：影子给形状与位置、色斑给颜色、其余配对给
  位移，三处残迹拼出同一个缺失精灵。
```

## 2. 第四角的相位

- tags:
  - operation:补全, completion
  - operation:填充, fill
  - operation:绘制边框, draw_frame
  - object:角点标记, corner_marker
  - object:隐形矩形, implied_rectangle
  - object:棋盘格图案, checkerboard
  - relation:角位置对应, corner_correspond
  - condition:推断角决定奇偶锚点, inferred_corner_anchors_parity
- 参考题目题号: 2、7、3

### docstring

```text
补出每组三个角点暗示的矩形，并以那个从未画出的第四角为锚在内部铺棋盘。

输入结构：
- 黑色背景上有若干颜色组，每组恰有三个同色孤立像素，位于某个轴对齐矩形的
  三个角上。
- 各组颜色互不相同，矩形至少 5×5，各矩形互不接触。

规则：
- 对每组求出缺失的第四角位置，画出完整矩形的一像素厚边框（组色）。
- 在矩形内部铺棋盘：以紧贴缺失角内侧的那个内部格为锚，内部格中与锚点的
  行差与列差之和为偶数者涂组色，其余内部格保持背景。
- 网格其余部分不变。

关键洞察：
- 棋盘的相位锚不是左上角这类固定位置，而是三点推断出的、画面上从未出现的
  第四角；锚点选错时整个棋盘反相。首个示例中缺角恰在左上，故意让"左上锚"
  的误读成立，后续示例将其推翻。
```

## 3. 指针串成的队列

- tags:
  - operation:排序拼接, sort_and_concatenate
  - object:实心矩形, solid_rectangle
  - object:中心指针点, center_pointer_pixel
  - relation:颜色指针链, color_pointer_chain
  - condition:颜色查找键, color_lookup_key
  - condition:端点条件锁定头尾, endpoint_conditions_fix_ends
- 参考题目题号: 4、13、5

### docstring

```text
沿藏在中心像素里的颜色指针把散落的矩形串成链，按链序输出一行颜色条带。

输入结构：
- 黑色背景上散落若干大小、位置各异的单色实心矩形，主体色互不相同。
- 每个矩形正中镶一个单像素指针点，指针点颜色不同于所在矩形的主体色。
- 恰有一个矩形的指针点为黑色（链尾）；恰有一个矩形的主体色不被任何指针点
  使用（链头）；其余每个指针点的颜色都恰是另一个矩形的主体色。

规则：
- 从链头矩形出发，反复走到"主体色等于当前指针点颜色"的那个矩形，直到黑
  指针的链尾，得到全部矩形的一个全序。
- 输出一个 1×k 的条带（k 为矩形个数），第 i 格涂序列中第 i 个矩形的主体色。

关键洞察：
- 矩形的空间位置、大小与排列全是干扰；真正的顺序信息藏在颜色指针里，链头
  由"无人指向"、链尾由"黑指针"两个端点条件锁定，按位置或大小排序的读法
  都会与示例矛盾。
```

## 4. 四象限的异见者

- tags:
  - operation:透明叠加, transparent_overlay
  - operation:裁剪, crop
  - object:十字分隔线, cross_divider
  - object:象限蒙版, quadrant_mask
  - relation:逐像素对齐, cell_align
  - condition:唯一异见象限着色, odd_one_out_coloring
- 参考题目题号: 1、10、2

### docstring

```text
把四个象限蒙版逐格对齐，只给存在唯一"异见象限"的格子着色，颜色取那个异见者。

输入结构：
- 一种分隔色画出完整的实心十字，把网格分成四个等大的象限。
- 每个象限有自己专属的颜色，象限内是该颜色在黑背景上的散点蒙版，四色互不
  相同。

规则：
- 输出一个象限大小的网格，四个象限逐格对齐比较。
- 某对齐格上，若恰有一个象限的状态（有色或空）与其余三个象限都不同，则该
  格涂那个象限的专属色：三空一有时取有色者，三有一空时取缺席者。
- 其余情形（四同、二比二）该格保持黑色。

关键洞察：
- 着色规则对"存在"与"缺席"完全对称：三有一空时答案是画面上什么都没有的
  那个象限的颜色，任何并集、交集或多数决的读法都会在这类格子上失败。
```

## 5. 锁孔与炮口

- tags:
  - operation:射线延伸, ray_extend
  - operation:填充, fill
  - object:空心矩形, hollow_rectangle
  - object:缺口, gap
  - relation:门对门对齐, gap_to_gap_alignment
  - condition:中途阻挡失效, blocking_invalidates
  - condition:缺口定方向, gap_determines_direction
- 参考题目题号: 16、8、7、3

### docstring

```text
每个空心框从缺口向外发射隐形射线，只有恰好从另一个框的缺口射入时，才把那个框的内部染成发射者的颜色。

输入结构：
- 黑色背景上有若干颜色互异的一像素厚空心矩形框。
- 每个框的边框恰好缺一个格，缺口位于某条边的非角位置。
- 输入保证每个框至多被一条射线入门。

规则：
- 每个框沿"从框内经缺口向外"的垂直方向发射一条直线射线。
- 射线逐格前进：碰到任何框的边框实体格即被挡下，无事发生；先离开网格也无
  事发生。
- 若射线到达的格恰是某个框的缺口格、且沿前进方向的下一格是该框内部，则射
  线入门：该框全部内部格染成发射框的颜色，缺口格保持背景。
- 射线路径本身不画出；发射框自身颜色不变；一个框可以既命中别人又被别人命中。

关键洞察：
- 缺口同时是炮口和锁孔：连线关系不是"最近"或"同色"，而是门对门共线且中
  途无墙；撞在墙上的射线是诱饵。
```

## 6. 两帧之后

- tags:
  - operation:旋转, rotate
  - object:面板, panel
  - object:精灵体, sprite
  - object:枢轴像素, pivot_pixel
  - relation:时间序列帧, time_sequence_frames
  - condition:由两帧推变换再外推, infer_then_extrapolate
- 参考题目题号: 10、7

### docstring

```text
上下两个面板是同一场景的前后两帧，求出绕枢轴的旋转量后再演一帧作为输出。

输入结构：
- 一条水平分隔线把网格分成上下两个等大面板。
- 两个面板各含一个同色同形的多格精灵和一个位置相同的枢轴像素（另一颜色）。
- 精灵无旋转对称；下面板的精灵是上面板精灵绕枢轴旋转四分之一圈的整数倍
  所得。

规则：
- 比较两帧，求出唯一能把上帧精灵映到下帧精灵的绕枢轴旋转量。
- 对下帧精灵再施加一次同样的旋转，得到第三帧。
- 输出一个面板大小的网格：黑色背景、原位置的枢轴像素、第三帧位置的精灵。

关键洞察：
- 两个面板不是待合并的图层而是时间轴上的相邻两帧；枢轴是唯一的不动点，答
  案不在画面里，而在把已发生的变化再执行一次。
```

## 7. 越转越大

- tags:
  - operation:像素放大, pixel_scale
  - operation:旋转, rotate
  - operation:补全, completion
  - object:基元图案, motif
  - object:精灵体, sprite
  - relation:尺度取向联动序列, scale_orientation_sequence
  - condition:除以尺度后匹配, match_after_descaling
  - condition:序列外推缺项, extrapolate_missing_member
- 参考题目题号: 11、7、5、9

### docstring

```text
散落的精灵是同一基元在尺度—取向联动序列上的采样，补出序列中缺失的那一档并单独输出。

输入结构：
- 黑色背景上有三个同色精灵。
- 它们都是同一个 n×n 无旋转对称基元的整数倍像素放大，放大倍数取自 1、2、
  3、4 中的三个（缺一个）。
- 倍数每大一号，取向就比前一号顺时针多转四分之一圈。

规则：
- 把每个精灵按其倍数缩回原尺寸，还原出共同基元，并核对"每大一号多转 90°"
  的步进。
- 找出 1、2、3、4 中缺失的倍数，按序列推出它应有的取向。
- 输出仅为这枚缺失精灵：基元按推出的取向旋转、再按缺失倍数做像素放大后的
  紧致网格。

关键洞察：
- 按原样轮廓匹配三个精灵会一无所获，必须先"除以尺度"才能看见同一基元；
  缺失的不是画面上的某块区域，而是尺度与取向联动数列中唯一的空档，尺寸和
  旋转都要从序列外推。
```
