## 1. 隐形换色链的下一帧

- 参考题目题号：5 (ba1aa698)、1 (e4888269)
- tags:
  - operation:外推, extrapolate
  - operation:重涂色, recolor
  - object:帧序列, frame_sequence
  - object:内部精灵, inner_sprite
  - relation:帧间颜色映射, interframe_color_map
  - condition:映射与运动同时延续, map_and_motion_continue
  - condition:规则从未画出, rule_never_drawn

### docstring

```text
从共享边框的面板序列中同时推断精灵的匀速位移与逐帧固定换色映射，输出下一帧的独立面板。

输入结构：
- 网格是一行等宽面板，相邻面板共享竖直边框列。
- 每个面板内是同一形状的多色精灵，其位置逐帧按恒定向量平移。
- 精灵各部件的颜色逐帧变化：全部帧共用同一个"颜色→颜色"的固定替换表，
  每过一帧套用一次；替换表本身从未以图例形式画出。

规则：
- 比对相邻两帧同一部件的颜色，还原出单步颜色替换表。
- 输出一个独立面板：边框与底色和输入面板一致；精灵按恒定向量再平移
  一步（独立面板按整面板宽度推进，而非共享边框间距），并对所有部件
  再套用一次替换表。

关键洞察：
- 面板既是运动的帧也是换色的帧；替换表没有画在任何地方，只能从相邻
  帧同位部件的颜色差推断，且位移与换色必须同时外推——只平移不换色、
  或只换色不平移，都会得到错误的下一帧。
```

## 2. 叠影出模板

- 参考题目题号：16 (e133d23d)、19 (50f325b5)、4 (fafffa47)
- tags:
  - operation:透明叠加, transparent_overlay
  - operation:模板匹配, template_matching
  - operation:重涂色, recolor
  - object:面板, panel
  - object:分隔线, divider_line
  - object:模板图案, template_motif
  - relation:双掩码交集, mask_intersection
  - condition:模板从未单独画出, template_never_drawn
  - condition:含旋转反射变换, includes_rotation_reflection
  - condition:非重叠放置, non_overlapping_placement
  - condition:忽略干扰项, ignore_distractors

### docstring

```text
把分隔线两侧掩码的重叠部分当作模板，在下方噪声场中找出它的旋转反射拷贝并染红。

输入结构：
- 一条水平灰线把网格分成上带与下场，上带再被一条竖直灰线分成同尺寸
  的左右两块。
- 左右两块各含背景加一种前景色；两块前景形状各自都不是模板，模板从
  未被单独画出。
- 下场是散布绿色像素的噪声场，其中埋有模板的若干拷贝（可旋转、可反
  射），其余绿色像素是干扰。
- 红色不在输入中出现，仅用于输出标记。

规则：
- 按左右对应位置叠加两块掩码，双方都是前景的格子构成模板图案。
- 枚举模板的全部不同旋转与反射，在下场按行优先顺序扫描，找出模板格
  全为绿色的放置。
- 把选中放置的格子染成红色，跳过与已选放置重叠的更晚放置；其余像素
  （含上带与分隔线）全部保持不变。

关键洞察：
- 上带任何一侧的形状都不是要找的形状；只有两侧掩码的交集才是钥匙，
  必须先合成从未露面的模板，才能开始在噪声场里匹配。
```

## 3. 空腔配钥·多色印章

- 参考题目题号：17 (4c3d4a41)、19 (50f325b5)、2 (72ca375d)、13 (3e980e27)
- tags:
  - operation:嵌入对齐, insert_and_align
  - operation:印章覆盖, stamp_overlay
  - operation:擦除, erase
  - object:框架槽, frame_slot
  - object:图案精灵体, pattern_sprite
  - object:干扰体, distractor
  - relation:形状互补配对, shape_complement_pairing
  - condition:含旋转反射变换, includes_rotation_reflection
  - condition:取向决定花纹, orientation_determines_pattern

### docstring

```text
为大块体内的每个空腔找到经旋转或反射后形状完全吻合的多色钥匙，按吻合取向把整幅花纹印入空腔并清除所有候选。

输入结构：
- 背景色占主导；一个大的单色实心块体中挖出若干背景色空腔，空腔形状
  不规则且互不相同。
- 块体外散布若干多色候选精灵，其中恰有与空腔数相同的候选，其占据形
  状经某种旋转或反射后与某个空腔完全吻合。
- 其余候选是干扰项，可能与某个空腔面积相同但形状不同。
- 真钥匙的占据形状均无自对称，因此吻合取向唯一。

规则：
- 提取每个空腔的形状与每个候选的占据形状。
- 对每个空腔，找出唯一能经旋转或反射与其同形的候选及其唯一吻合取向。
- 把该候选的整幅多色图案按该取向变换后印入空腔，空腔内每格颜色由钥
  匙对应格决定；把所有候选（含干扰项）擦为背景，块体其余部分不变。

关键洞察：
- 第一眼像"选钥匙填色"，实际空腔内的逐格花纹由吻合取向决定：面积相
  同的干扰使数格子无效，多色花纹又使取向判断错误立刻反映为输出错
  误——必须同时解出"哪把钥匙"与"转到哪个朝向"。
```

## 4. 接力滑行

- 参考题目题号：11 (97c75046)、15 (2f767503)
- tags:
  - operation:滑动, slide
  - operation:连线, line_drawing
  - object:标记像素, marker_pixel
  - object:障碍轮廓, obstacle_contour
  - relation:轮廓邻接, contour_adjacency
  - relation:视线接力, sightline_relay
  - condition:最长贴边路径, longest_adjacent_path
  - condition:障碍逐一访问, visit_each_obstacle_once

### docstring

```text
让标记像素沿视线撞上障碍后贴边滑行，滑到头再沿新的视线冲向下一个障碍，如此接力直到无路可走，画出全程轨迹。

输入结构：
- 主导背景色画布上有一个单像素标记与若干互不相连的障碍块。
- 标记开始时恰有一条水平或垂直视线指向某个障碍。
- 每次贴边滑行结束后，端点处恰好又有唯一一条通向尚未访问障碍的直视
  线，直到最后一段为止。

规则：
- 标记沿视线直行到障碍前最后一个背景格；在两个可以绕行的转向中选择
  能与该障碍保持4邻接更长距离的一侧，贴边滑到该段轮廓尽头。
- 从新端点重复"直行—贴边滑行"，每个障碍只使用一次；当端点不再有通
  向新障碍的视线时停止。
- 把标记经过的全部格子（含起点与终点）涂成标记色，障碍保持不变。

关键洞察：
- 单次"指向再贴边"只是子步骤；答案是把该子步骤当作接力棒在多个障碍
  间传递形成的完整路径，中途任何一次转向选错都会驶向不同的障碍序
  列，错误会沿链条放大。
```

## 5. 剥壳坍缩

- 参考题目题号：12 (9720b24f)、8 (aa62e3f4)、17 (4c3d4a41)
- tags:
  - operation:擦除, erase
  - operation:重涂色, recolor
  - operation:嵌入对齐, insert_and_align
  - object:连通分量, connected_component
  - object:包围框, bounding_box
  - relation:包围框嵌套链, bbox_nesting_chain
  - relation:属性跨层转移, cross_layer_property_transfer
  - condition:形状取最内色取最外, inner_shape_outer_color
  - condition:居中放置, center_placement

### docstring

```text
把每棵层层嵌套的对象树坍缩成合成对象：形状取自最内层，颜色取自最外层，位置居中于最外层包围框。

输入结构：
- 黑色为空画布，其余颜色构成若干8连通单色对象。
- 部分对象按包围框严格包含关系嵌套成链或树：外层对象的包围框严格包
  含内层对象的包围框；同一外层可包含多条并列分支，链可有两层或更多
  层，各层颜色互不相同。
- 另有一些不属于任何嵌套结构的独立对象。

规则：
- 求出所有对象的包围框，按严格包含关系连成嵌套树。
- 对每棵树，只输出各分支最内层对象的形状，全部重涂为整棵树最外层对
  象的颜色；把这些形状按彼此原有的相对偏移组成一组，整组居中放置在
  最外层包围框的中心。
- 树中其余各层全部擦除；不在任何嵌套结构中的独立对象原样保留。

关键洞察：
- 输出对象的三个属性来自三个不同来源——形状取自最内、颜色取自最
  外、位置取自最外层包围框的中心；两层链上"直接父即最外"的直觉在三
  层链上会给出错误颜色，是埋好的诱饵。
```

## 6. 先换色后补全

- 参考题目题号：1 (e4888269)、20 (11852cab)
- tags:
  - operation:重涂色, recolor
  - operation:对称补全, symmetry_completion
  - operation:旋转, rotate
  - object:双列图例, two_col_legend
  - object:前景对象, foreground_object
  - relation:图例行序决定替换, legend_row_order
  - relation:旋转对称, rotational_symmetry
  - condition:逐行顺序链式替换, chain_replace
  - condition:换色后对称方显现, symmetry_emerges_after_recolor

### docstring

```text
先按竖直双列图例逐行链式换色，再利用换色后才显现的旋转对称补全对象上的黑色缺口。

输入结构：
- 主导背景包围一个多色对象与一个双列图例块：图例每行给出"左色→右
  色"的一条替换，从上到下依次生效，同一颜色可被后续行再次改写。
- 对象上有若干黑色缺失格；完整对象在换色完成后具有90度旋转对称。
- 换色之前，同一格与其旋转对应格的颜色可以不同，对称并不可见。

规则：
- 对图例外的每个非背景像素按图例行序做链式替换；图例本身与背景保留。
- 在换色后的对象上找到旋转对称中心，把每个彩色像素旋转到其余三个四
  分之一转位置。
- 用旋转对应格换色后的颜色填补黑色缺失格，其他像素不变。

关键洞察：
- 缺口的三个旋转对应格在原图中颜色互不一致，直接照抄无从下手；只有
  先做完图例的链式替换，四个对应位才收敛到同一颜色，对称才成为可用
  的修复工具——换色与补全的先后顺序是强制的。
```

## 7. 账目稽核

- 参考题目题号：18 (8f215267)、10 (ae58858e)
- tags:
  - operation:计数, counting
  - operation:擦除, erase
  - object:空心框架, hollow_frame
  - object:图案精灵体, pattern_sprite
  - relation:同色匹配, same_color_matching
  - relation:申报与核验, claim_verification
  - condition:点数申报总面积, dots_claim_total_area
  - condition:真假互换去留, keep_erase_swap_by_truth

### docstring

```text
核对每个空心框内的点数与场上同色图案的像素总面积，属实的框留框销证，不实的框销框留证。

输入结构：
- 背景为最常见色；若干不同颜色的空心矩形框，框内中线上画有若干与框
  同色的计数点。
- 框外散布若干与某个框同色的单色小图案，图案可为单像素或多像素。

规则：
- 对每个颜色为C的框，把框内点数视为对"场上颜色C图案的像素总面积"
  的申报，并数出真实总面积。
- 申报属实的框：框与点原样保留，其同色图案全部擦为背景。
- 申报不实的框：框与点全部擦为背景，其同色图案原样保留。

关键洞察：
- 两重反转——框内的点不是要生成的输出而是待核验的申报，且核对的量
  是像素总面积而非图案个数（当某示例中图案全为单像素时两种读法恰好
  一致，是埋好的诱饵）；保留与擦除随真假在框与图案之间互换。
```
