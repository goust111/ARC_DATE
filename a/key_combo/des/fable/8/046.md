## 1. 缺口即门

- 参考题目：5, 8, 13, 18（60a26a3e, e1d2900e, 445eab21, ac2e8ecf）
- tags:
  - operation:滑动, slide
  - operation:射线延伸, ray_extend
  - object:空心矩形, hollow_rectangle
  - object:边框缺口, border_gap
  - object:标记像素, marker_pixel
  - relation:视线对齐, sightline_align
  - condition:缺口为唯一入口, gap_as_door
  - condition:碰撞停止堆积, collision_stack
  - condition:忽略干扰项, ignore_distractors

### docstring

```text
与空心矩形同色的散点沿视线穿过边框上的唯一缺口被吸入矩形，在内部沿飞行方向依次堆积。

输入结构：
- 黑色背景上有若干单色空心矩形框，每个框的边框恰好缺一个像素，形成缺口。
- 网格中散布若干单点像素，有的与某个框同色，有的颜色与任何框都不同。
- 部分单点与某个缺口在同一行或同一列，部分不共线；共线路径上有的畅通，有的被其他框的边框挡住。

规则：
- 对每个单点，检查它是否与同色框的缺口在同一行或同一列、位于该框外部，且两者之间的直线路径上没有任何前景像素遮挡。
- 满足全部条件的单点沿该直线飞入缺口，进入后继续沿同方向前进，直到撞到对面内壁或先前进入的点为止，停在该处。
- 同一直线上有多个可进入的点时，距缺口近的点先进入，因此堆得更深。
- 颜色不匹配、不共线或视线被挡的单点保持原位不动。

关键洞察：
- 缺口不是绘制缺陷而是门：颜色匹配、共线、视线畅通三重过滤共同决定谁能入内，
  入内的点像滑块一样在矩形内部沿入射方向排队堆叠。
```

## 2. 读条选框再选房

- 参考题目：1, 3, 10, 19（1fad071e, 1a6449f1, 89565ca0, 4b6b68e5）
- tags:
  - operation:计数, counting
  - operation:裁剪, crop
  - operation:洪泛填充, flood_fill
  - object:指令条, instruction_bar
  - object:分隔框架, partitioned_frame
  - object:封闭房间, enclosed_room
  - object:标记像素, marker_pixel
  - relation:条长指定房间数, bar_length_selects_count
  - condition:计数为选择键, count_as_key
  - condition:颜色匹配是诱饵, color_match_decoy

### docstring

```text
用指令条的长度选出房间数相符的框架，把框内含标记点的那个房间整体染成标记色后，输出该框的严格内部。

输入结构：
- 网格边缘附近有一条不与任何框接触的单色实心条（指令条）。
- 其余为若干矩形框架，每个框内部被同色墙分隔成若干封闭背景房间；各框的房间数互不相同，且与框的外形大小无关。
- 每个框内部都恰有一个房间含一个彩色标记点，因此无法靠"哪个框有点"来定位目标。
- 其中一个框的边框颜色与指令条相同，但其房间数不等于条长，作为颜色诱饵。

规则：
- 数出指令条的长度 k。
- 对每个框数出其内部被墙分隔出的封闭房间数量，选出房间数恰为 k 的框。
- 输出该框的严格内部（含内部墙、不含边框）；其中含标记点的房间整体填充为标记点的颜色，标记点本身消失，其余房间保持背景色。

关键洞察：
- 这是一条两级钥匙链：条长选框，标记点选房。常见的"数房间画条"被反转为"读条选框"，
  而按颜色匹配选框、按有无标记点选框都是死路。
```

## 3. 镜像副本维护

- 参考题目：2, 4, 17（4c4377d9, 9b5080bb, 5b692c0f）
- tags:
  - operation:对称补全, symmetric_completion
  - operation:镜像, mirror
  - operation:擦除, erase
  - object:对称轴, symmetry_axis
  - object:面板, panel
  - object:原件与副本, original_and_copy
  - relation:跨轴镜像对应, cross_axis_correspond
  - condition:副本色为来源面板底色, copy_color_from_source_panel
  - condition:孤儿副本删除, orphan_copy_erased

### docstring

```text
跨轴维护镜像副本：缺副本的红色原件补上副本，无原件的孤儿副本被擦除。

输入结构：
- 一条贯穿全网格的灰线把画布分成两个底色不同的面板。
- 红色图形是原件，分布在两个面板上。
- 副本遵循一条隐含的颜色规则：位于某面板上的副本，其颜色等于对侧面板（即其原件所在面板）的底色。
- 有的红色原件在对侧镜像位置没有副本；有的非红图形在对侧镜像位置没有红色原件（孤儿副本）。

规则：
- 对每个红色原件检查关于灰线的镜像位置：若无副本，则在该位置画出其镜像形状，颜色使用原件所在面板的底色。
- 对每个非红前景图形检查其镜像位置：若没有红色原件与之对应，则将其擦除（涂成所在面板的底色）。
- 配对完好的原件与副本保持不变。

关键洞察：
- 判断谁是原件、谁是副本不靠形状而靠颜色语义——副本的颜色携带了其来源面板的身份；
  形状由镜像对应决定，颜色由面板归属决定，而缺一侧要补、缺另一侧要删，方向相反。
```

## 4. 绕梁落点

- 参考题目：16, 1, 20（f15e1fac, 1fad071e, af24b4cc）
- tags:
  - operation:流动绘制, flow_draw
  - operation:压缩, compress
  - object:边缘起点像素, edge_source_pixel
  - object:红色横梁, red_beam
  - relation:较近端绕行, detour_nearer_end
  - condition:仅输出落点行, output_landing_row_only
  - condition:等距偏左, tie_break_left

### docstring

```text
彩色水流从顶部起点下落，绕过红色横梁的较近一端，输出只有底行每列的落色。

输入结构：
- 顶行有若干不同颜色的起点像素。
- 网格内部散布若干长度不一的水平红色横梁，其余格子为空。
- 输入保证任意两股流不会落在同一列，且流不会被推出网格。

规则：
- 每股流从起点垂直下落。
- 当下一格属于某条红梁时，流水平移动到该梁较近一端的外侧一格（到两端距离相等时移向左端），然后继续下落。
- 输出为 1×宽度 的一行：每列写入最终落到底部该列的流色，无流落入的列为黑色。

关键洞察：
- 输出里既没有路径也没有横梁——横梁只存在于推理过程中；
  每次绕行的方向由"离哪一端更近"局部决定，落点是一连串局部选择逐级累积的结果，必须完整追踪才能得到。
```

## 5. 墙上签名

- 参考题目：10, 19, 3（89565ca0, 4b6b68e5, 1a6449f1）
- tags:
  - operation:重建, reconstruct
  - operation:洪泛填充, flood_fill
  - operation:擦除, erase
  - object:矩形框, rectangular_frame
  - object:蛀蚀像素, corruption_pixel
  - relation:蛀蚀构成单向环, corruption_forms_cycle
  - condition:颜色沿环反向流动, color_flows_against_cycle
  - condition:忽略离墙噪声, off_wall_noise_ignored

### docstring

```text
每个矩形框的边框被另一个框的颜色蛀蚀；修复所有墙之后，把每个框的边框色填进"墙上留有它签名"的那个框的内部。

输入结构：
- 黑色背景上有至少三个单色矩形框。
- 每个框的边框上有少数像素被替换成另一个框的边框色（每框的蛀蚀色唯一），蛀蚀关系构成覆盖所有框的单向环。
- 网格其余位置散布与各框颜色相同的孤立噪声点，它们都不在任何框的边框线上。

规则：
- 对每个框，以边框位置上占多数的颜色恢复完整边框。
- 识别每个框墙上的外来色 B（B 是另一个框 B 的边框色）。
- 将框 B 的内部填满被蛀框自己的边框色。
- 删除所有不在边框线上的孤立噪声点。

关键洞察：
- 直觉是"框被 B 色蛀蚀就把它填成 B 色"，在两框互蛀时结果碰巧一致，但三框成环时真规则暴露：
  蛀蚀是签名，颜色沿环反向流动——A 的墙上有 B 的签名，意味着 A 的颜色要送进 B 的肚子；
  而位置区分了语义：落在墙线上的"噪声"是指令，落在别处的才是真噪声。
```

## 6. 对角导线

- 参考题目：6, 5, 7（396d80d7, 60a26a3e, de1cd16c）
- tags:
  - operation:重涂色, recolor
  - operation:传播, propagate
  - object:小方块, small_block
  - object:源块, source_block
  - relation:仅对角邻接, diagonal_only_adj
  - relation:正交邻接, orthogonal_adj
  - condition:对角导通正交断路, diagonal_conducts_orthogonal_breaks
  - condition:近源胜出等距保持, nearer_source_wins_tie_keeps

### docstring

```text
红蓝两个源块的颜色沿"仅对角接触"的方块链竞相传播，任何存在共边接触的方块都是断路器。

输入结构：
- 黑色背景上散布若干同尺寸的灰色小方块，另有恰好一红一蓝两个源块。
- 有些方块两两只在角上（对角）接触，有些方块与邻块共享边（正交接触）。
- 两个源块自身不与任何方块共边。

规则：
- 与任何方块存在共边接触的方块为绝缘块：既不能被染色，也不向外传导。
- 从红、蓝两个源块同时出发，沿"仅对角接触"的非绝缘方块链逐步传播各自颜色。
- 每个可达的灰块染成链步数较近的那个源的颜色；到两源链步数相等的灰块保持灰色。
- 绝缘块与两源均不可达的方块保持灰色。

关键洞察：
- 连通性判断被整体反转：角接触是导线、边接触是断路器；
  在这张反转的连通图上，还要以链距离做两源竞争，等距处留下灰色的"分水岭"。
```

## 7. 指引寻亲

- 参考题目：14, 20, 15（7c008303, af24b4cc, 278e5215）
- tags:
  - operation:多数决, majority_vote
  - operation:复制, copy
  - operation:修复, repair
  - object:分区块, lattice_block
  - object:指引图, guide_map
  - object:噪声覆盖块, ruined_block
  - relation:跨尺度位置对应, cross_scale_correspond
  - relation:同多数色同纹理, same_majority_same_texture
  - condition:指引只给类别, guide_gives_category_only

### docstring

```text
用小指引图查出被毁块的类别，再从同类别的完好块借来纹理修复它。

输入结构：
- 分隔线把画布分成 m×n 个同尺寸块，每块内部有纹理且有唯一多数色；多数色相同的块纹理完全相同。
- 画布之外另有一个 m×n 的小指引图，与画布之间以空行或空列隔开，指引图每格的颜色等于对应位置块的多数色。
- 恰有一个块被一种不在指引图中出现的噪声色整块覆盖，其原貌完全不可见。

规则：
- 建立指引图格与画布块的位置一一对应。
- 由指引图对应格读出被毁块应有的多数色。
- 在画布中找到多数色与之相同的完好块，把它的内部纹理完整复制到被毁块。
- 画布其余部分与指引图保持不变。

关键洞察：
- 指引图只给"类别"不给"纹理"，修复需要两跳：
  先做跨尺度的位置对应查出被毁块属于哪一类，再到同类兄弟块处取回真正的图案；
  只看指引图会以为该把整块涂成纯色，那正是诱饵。
```
