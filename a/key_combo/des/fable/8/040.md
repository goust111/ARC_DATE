## 1. 双向剪影定物

- 参考题目：8a004b2b、b91ae062、7d7772cc
- tags:
  - operation:像素放大, scale_up
  - operation:对齐放置, align_and_place
  - object:精灵体, sprite
  - object:边缘剪影, edge_silhouette
  - object:矩形画框, rectangular_frame
  - relation:正交投影约束, orthogonal_projection_constraint
  - condition:双视图唯一定位, two_views_fix_placement

### docstring

```text
依据画框上、左两条彩色剪影，反求小精灵的放大倍率、朝向与位置，把从未画出的放大精灵画进画框。

输入结构
- 网格一角有一个小型多色精灵，另有一个由边框色围成的大空矩形画框。
- 画框上边外侧一行与左边外侧一列各有一串彩色像素：分别记录目标图形
  自上向下看、自左向右看时每列/每行最先遇到的像素颜色；画框内部为空。

规则
- 目标图形是小精灵经恒等、左右翻转、上下翻转或旋转 180 度之一、
  再整格放大 k 倍后的图形。
- 枚举朝向、倍率与放置，使其在画框内自上看的首色序列与上侧剪影逐列一致、
  自左看的首色序列与左侧剪影逐行一致；这样的组合唯一。
- 在画框内画出该图形，其余保持不变。

关键洞察
- 画面上从未出现目标物体，只有它的两条一维"视图"；单条剪影有多解，
  两条正交剪影的交集才唯一锁定朝向、倍率与位置。
```

## 2. 错相循环校对

- 参考题目：c3f564a4、34b99a2b
- tags:
  - operation:补全, complete
  - operation:逐像素比较, cell_by_cell_comparison
  - object:对角周期图案, diagonal_periodic_pattern
  - object:分隔列, separator_column
  - relation:对角线同余, diagonal_residue
  - relation:相位对齐, phase_alignment
  - condition:生成元级差异判定, generator_level_difference

### docstring

```text
两块被打洞的对角循环面板其实是同一张壁纸的错相拷贝，先滑动循环对齐相位，滑不掉的残差整条对角线标红。

输入结构
- 奇数宽网格，中央一列为单色分隔条，两侧是同尺寸面板。
- 两块面板都是沿同一对角方向的循环彩色图案，各自被挖去若干黑洞，
  每种循环色在各自面板中仍可见。
- 右面板的"对角同余类→颜色"循环表相对左面板整体相移了若干位，
  此外还有少数同余类被换成了别的颜色。

规则
- 分别由可见像素还原两块面板的循环表。
- 在所有相移量中找到使两表重合位数最多的唯一相移。
- 输出一块右面板大小的网格：按最佳相移对齐后，两表一致的同余类
  按还原后的右面板填色，不一致的同余类整条对角线涂红。

关键洞察
- 逐格比较可见像素被黑洞误导；按同余类硬对齐又几乎处处冲突——
  那是相位差造成的假差异。必须先滑动循环找到最佳重合，
  剩下滑不掉的残差才是真正被改动的对角线。
```

## 3. 沿途取指折线

- 参考题目：136b0064、142ca369
- tags:
  - operation:连线, draw_polyline
  - operation:解码指令, decode_instructions
  - object:字形指令, glyph_instruction
  - object:起始标记, start_marker
  - relation:就近取指, nearest_instruction
  - condition:路径决定读序, path_determines_reading_order

### docstring

```text
从起点出发画折线，每一段的指令取自离当前端点最近的未用字形，路径一边生长一边决定阅读顺序。

输入结构
- 背景网格上散布若干 3x3 单色字形和一个灰色起点像素；
  字形之间以及字形与起点互不相邻。
- 每个字形形如指向上下左右之一的箭头：箭头指向给出线段方向，
  字形的像素个数给出线段长度。

规则
- 折线自灰色起点开始。每一步选取与当前端点棋盘距离最近、
  且尚未使用过的字形，按其方向与长度延伸折线，
  然后以新端点重复，直到所有字形用完。
- 每一步的最近字形都是唯一的。折线用灰色画在背景上，字形保留。

关键洞察
- 字形没有固定的全局阅读顺序（不按行列，也不按颜色）；
  读取顺序由折线自身的生长实时决定，走错一段将导致后续所有指令错位。
```

## 4. 边标定向、图例定序

- 参考题目：d255d7a7、7d7772cc、136b0064
- tags:
  - operation:滑动, slide
  - operation:擦除, erase
  - object:图例列, legend_column
  - object:边界标记, boundary_marker
  - object:分隔线, separator_line
  - relation:顺序编码, order_encoding
  - relation:方向编码, direction_encoding
  - condition:先落者成障, landed_blocks_later

### docstring

```text
每种颜色的像素滑向自己边标所指的那条边，滑动批次按图例列的顺序进行，先落定者成为后来者的障碍。

输入结构
- 网格有一圈边框，边框上每种前景色各嵌有一个同色边标。
- 分隔线外的窄条为图例列，自上而下排出这些颜色，每色一格。
- 场内散布这些颜色的像素，不同颜色的像素在行、列上彼此交错。

规则
- 按图例列自上而下的顺序逐色处理：轮到某色时，该色所有像素
  同时向其边标所在的边直线滑动，碰到边框或已落定像素即贴着停下。
- 处理完毕后场内只保留落定位置，原位擦为背景；边框、边标、图例不变。

关键洞察
- 方向表和时间表分存两处：边标给去向，图例给先后；
  不同方向的批次互相堆挡，顺序一错，整个堆积形状连锁改变。
```

## 5. 滤色射线的交点

- 参考题目：f341894c、45bbe264、142ca369
- tags:
  - operation:射线延伸, ray_cast
  - object:边界标记, boundary_marker
  - object:墙壁像素, wall_pixel
  - relation:行列交叉, row_column_crossing
  - relation:同色透射, same_color_transparency
  - condition:异色碰撞停止, different_color_collision_stop
  - condition:射线不显影, invisible_ray

### docstring

```text
边框标记向内发射看不见的射线，射线穿过同色墙、止于异色墙，输出只在幸存射线的交叉点上落色。

输入结构
- 背景网格外边框上有若干彩色标记像素，分布在上下左右四边。
- 场内散布多种颜色的墙像素。

规则
- 每个标记垂直于其所在边向内发射一条隐形射线；射线穿过与标记同色的墙，
  遇到异色墙即在其前一格终止，否则贯穿到对边。
- 射线本身不画。仅当一条水平射线与一条竖直射线的存续区间相交于某格：
  两标记异色则该格涂红，同色则涂该公共色。
- 墙与标记保持原样，其余为背景。

关键洞察
- 墙不是一视同仁的障碍而是滤色器，同一堵墙对一条射线是空气、
  对另一条是尽头；输出上看不到任何线，一个交点是否存在
  取决于两段互不可见的存续区间是否都延伸到了那里。
```

## 6. 以疵选材

- 参考题目：7bb29440、c3f564a4
- tags:
  - operation:裁剪, crop
  - operation:选择, selection
  - operation:补全, repair
  - object:周期矩形, periodic_rectangle
  - relation:缺陷相对隐含图案, defect_vs_implied_pattern
  - condition:最少缺陷数, minimum_defect_count

### docstring

```text
每个矩形都带着自己的周期花纹和少量违纹杂点，裁出杂点最少的矩形并把它修复成完美花纹。

输入结构
- 背景上散布若干分离的实心矩形，每个矩形内部是自身的二维周期花纹，
  各矩形的花纹与用色可以不同。
- 每个矩形内有若干违反其自身周期的杂色像素；
  杂色可能恰好是该花纹的合法用色之一。

规则
- 对每个矩形推断其周期花纹，把与花纹矛盾的像素计为缺陷。
- 选出缺陷数最少的那个矩形（唯一），按其花纹修复全部缺陷后裁剪输出。

关键洞察
- 缺陷不能靠"少数色"识别——杂点可以借用花纹本身的颜色；
  只有先还原每个矩形从未完整呈现的理想花纹，
  才能数出真正的瑕疵并完成修复。
```

## 7. 同色门廊与撞线

- 参考题目：692cd3b6、45bbe264
- tags:
  - operation:路径填充, path_fill
  - object:门框, doorway_frame
  - object:走廊路径, corridor_path
  - relation:颜色配对, color_pairing
  - condition:最短路径并集, monotone_shortest_path_union
  - condition:走廊相交特殊色, corridor_crossing_special

### docstring

```text
把门芯同色的门框两两配对，为每一对铺设最短单调走廊的并集，不同走廊相遇的格子改涂红色。

输入结构
- 网格上有偶数个小门框，每个门框中心有一个彩色门芯，
  门芯颜色两两配对出现。
- 每个门芯恰有一个背景四邻作为门洞，门洞向外一格是门外格。

规则
- 同色门芯的两个门框配成一对；所有门框像素都是障碍。
- 对每一对，在其两个门外格之间，取只朝对方方向走行列步的
  全部最短路径的并集，连同两个门洞一起涂成黄色。
- 属于两对不同走廊并集的格子涂红。

关键洞察
- 走廊不是一条选定的路而是全体单调最短路的叠影；
  不同颜色对的叠影可以互相穿过，相遇处才是红色的来源。
```

## 8. 台球计数徽记

- 参考题目：142ca369、ff28f65a
- tags:
  - operation:反弹, bounce
  - operation:计数, counting
  - operation:编码, encoding
  - object:箭头精灵体, arrow_sprite
  - object:吸收点, absorber_pixel
  - object:固定图案, fixed_pattern
  - relation:隐式轨迹, implicit_trajectory
  - condition:计数决定填充位, count_sets_positions

### docstring

```text
让箭头发出的对角射线在网格边界间反弹、被吸收点吸收，把反弹次数写进固定的 3x3 蓝色徽记。

输入结构
- 输入是含一个三像素 L 形箭头（2x2 外接框缺一角）与
  一个异色吸收点的黑底网格。
- 输出恒为 3x3 黑网格。

规则
- 箭头沿缺角方向发出对角射线；射线碰到网格边界按镜面反弹
  （碰到角则原路返回），碰到吸收点即终止。
- 数出终止前经历的边界反弹次数 n（不超过五）。
- 在 3x3 输出中按左上、右上、中心、左下、右下的固定顺序填入 n 个蓝格。

关键洞察
- 轨迹从未画出，答案也不关心轨迹形状；被编码的是一条隐式台球路径的
  反弹事件数，位置信息全部被抛弃。
```
