## 1. 旋转入槽

- 参考题目：16（fd4b2b02 旋转/矩形条）、20（1e0a9b12 重力滑动）、9（e73095fd 空心结构）、15（94414823 空心框与外部对象）
- tags:
  - operation:滑动, sliding
  - operation:旋转, rotate
  - object:实心矩形块, solid_block
  - object:U形槽, u_shaped_slot
  - relation:尺寸唯一匹配, size_unique_matching
  - condition:开口方向定重力, opening_sets_gravity
  - condition:无匹配则不动, unmatched_stay

### docstring

```text
把每个实心矩形块旋转适配后从对应U形槽的开口送入，并沿进入方向滑到槽底；无槽可配的块留在原地。

输入结构：
- 黑背景上散布若干互异颜色的实心矩形块。
- 另有若干灰色三边一像素厚的U形槽，开口朝上、朝左或朝右，槽内腔为矩形。
- 每块经过0度或90度旋转后，其垂直于某槽进入方向的边长恰好等于该槽开口的内宽，
  且这种块-槽配对全局唯一；也可能存在与任何槽都不匹配的块。

规则：
- 每块旋转（0或90度）使其恰能严丝合缝穿过配对槽的开口。
- 块沿开口的反方向滑入内腔，直到贴住槽底停下。
- 块的原位清空；找不到配对槽的块原样保留；槽本身不变。

关键洞察：
- 块与槽的配对既不靠颜色也不靠位置邻近，而是"旋转后能否严丝合缝穿过开口"；
  开口朝向同时决定了槽内的重力方向，侧开口槽迫使块横过来进入。
```

## 2. 枢轴接力

- 参考题目：7（90347967 枢轴点对称）、17（a47bf94d 沿线传输）、12（35ab12c3 忽略干扰项）
- tags:
  - operation:传输, transmit
  - operation:旋转, rotate
  - object:枢轴像素, pivot_pixel
  - object:导线路径, wire_path
  - object:多色精灵, multicolor_sprite
  - relation:点反射复合, point_reflection_composition
  - condition:沿线有序应用, ordered_along_wire
  - condition:忽略干扰项, ignore_distractors

### docstring

```text
把精灵沿导线依次关于每个灰色枢轴做180度点反射，只画出最终像。

输入结构：
- 黑背景上有一个非点对称的多色精灵。
- 一条青色单像素路径从精灵近旁出发，路径上按顺序嵌着若干灰色枢轴像素。
- 路径之外还散落着游离的灰色像素，不属于任何枢轴序列。

规则：
- 按导线从精灵端起的顺序，依次把精灵（连位置带形状）关于当前枢轴做180度点反射，
  前一次的像作为下一次反射的原像。
- 输出仅画出最终像；原精灵位置清空。
- 导线、枢轴与游离灰点原样保留，游离灰点不参与反射。

关键洞察：
- 偶数个枢轴的复合是纯平移（精灵朝向不变），奇数个则整体旋转180度；
  只含单枢轴的示例会诱导成"绕点对称"的简单规则，多枢轴示例才暴露复合结构。
```

## 3. 缺口引流

- 参考题目：13（140c817e 控制像素射线）、9（e73095fd 空心矩形填充）、12（35ab12c3 路径通畅）、15（94414823 框外标记定内部填色）
- tags:
  - operation:射线延伸, ray_extend
  - operation:填充, fill
  - object:空心矩形框, hollow_rect_frame
  - object:边框缺口, frame_gap
  - object:控制像素, control_pixel
  - relation:缺口与点共线, gap_pixel_collinear
  - condition:路径需通畅, path_clearance
  - condition:无引流则留空, no_ray_no_fill

### docstring

```text
每个空心框的内腔涂成"透过其边框缺口能直视到的那个控制像素"的颜色。

输入结构：
- 黑背景上有若干灰色一像素厚的空心矩形框，每框边壁上恰缺一格。
- 若干彩色单像素控制点散布在框外。
- 控制点与缺口之间可能隔着其他框的壁或其他控制点。

规则：
- 从每个控制点沿上下左右四个方向引隐形直线。
- 若某条直线恰好穿过某框的缺口，且从控制点到缺口之间没有任何非背景像素阻挡，
  则该框的整个内腔填充该控制点的颜色。
- 每框至多被一条这样的直线命中；未被命中的框内腔保持黑色。
- 框、缺口与控制点全部原样保留。

关键洞察：
- 起作用的射线从未被画出——真正的配对关系是"缺口与控制点共线且视线通畅"，
  与距离远近、颜色种类都无关；与缺口同行但被别的框壁挡住的控制点是诱饵。
```

## 4. 隐线成表

- 参考题目：19（db615bd4 稀疏结构稠密化）、14（ef26cbf6 分隔表行列对齐涂色）、2（e734a0e8 分隔网格）

  - object:稀疏分隔线, sparse_separator
  - object:掩码区域, mask_region
  - object:单像素标记, singleton_marker
  - relation:行列对齐, row_col_align
  - condition:两点定线, two_pixels_define_line

### docstring

```text
先把残缺的分隔线补全成完整表格，再按表格行列对齐关系用标记色重涂各掩码区域。

输入结构：
- 黑背景上散落线色像素，每个都落在某条应存在的完整横线或竖线的位置上。
- 凡含有至少两个线色像素的整行或整列即为一条分隔线。
- 线间的单元格里分布着掩码色区域，以及每格至多一个单像素彩色标记。

规则：
- 把所有满足两点判据的行与列整条涂成线色，得到完整分隔表格。
- 对每个含掩码区域的单元格，找到与其同表行或同表列的唯一含标记单元格，
  把掩码像素全部改成该标记的颜色。
- 标记像素与补全后的线保留。

关键洞察：
- 表格结构在输入中从未完整出现，必须先由稀疏残迹重建；
  只有重建之后"同行同列"这一配色关系才成立，掩码形状与标记之间没有任何形状对应。
```

## 5. 沟槽争色

- 参考题目：4（137f0df0 块阵列沟槽涂色）、14（ef26cbf6 标记对齐定色）、13（140c817e 整行整列射线）
- tags:
  - operation:分区涂色, zone_coloring
  - object:块阵列, block_array
  - object:网格沟槽, lattice_gutter
  - object:边缘标记像素, edge_marker
  - relation:标记沿槽对齐, marker_gutter_align
  - condition:交点取近者, intersection_nearest_wins

### docstring

```text
用边缘标记的颜色沿对应沟槽涂色，交叉点由沿槽距离更近的标记胜出。

输入结构：
- 黑背景上有一个完整矩形阵列的灰色2x2块，块带之间是一像素宽的空沟槽。
- 阵列包围盒之外、部分沟槽行或沟槽列的延长线上，各有至多一个彩色单像素标记
  贴近网格边缘。

规则：
- 每条有标记的沟槽在阵列包围盒内的部分涂成该标记的颜色。
- 交叉像素同时属于横竖两条已涂色沟槽时，取沿沟槽走到标记距离更近那一侧的颜色。
- 只有一侧有标记的交叉点直接取该侧色；无标记的沟槽保持黑色。
- 灰块与所有标记不变。

关键洞察：
- 交叉点不是按"横向优先"或"后涂覆盖"这类固定次序解决的——
  头一个示例里恰好所有交点都是横向更近，会诱导出错误的优先级规则，
  必须发现按距离逐点裁决。
```

## 6. 双向标尺

- 参考题目：5（5d588b4d 控制条定参数）、10（60c09cac 像素放大）、11（b4a43f3b 半分辨率对应）
- tags:
  - operation:像素放大, pixel_upscale
  - operation:像素缩小, pixel_downscale
  - object:边缘标尺条, edge_ruler_bar
  - object:单色对象, monochrome_object
  - relation:同色配对, same_color_pairing
  - condition:条向定轴, bar_orientation_sets_axis
  - condition:缩放至条长, scale_to_bar_length

### docstring

```text
把每个对象沿与其同色边缘条的方向整数缩放，使该方向尺寸恰好变为条长——
条短于对象则收缩，条长于对象则放大。

输入结构：
- 黑背景；网格顶边或底边贴着若干水平一像素厚彩色条，左边或右边贴着若干竖直条。
- 场内散布颜色互异的单色对象，部分对象在边缘有一根或两根同色条。
- 对象与其同色条在对应方向的尺寸之间总存在整数倍关系：可能条是对象的整数倍，
  也可能对象是条的整数倍——此时对象呈等宽块状纹理，可无损收缩。

规则：
- 水平条控制同色对象的水平尺寸，竖直条控制垂直尺寸。
- 条长大于对象该向尺寸时按整数倍逐列（行）复制放大，
  条长小于时按整数倍逐列（行）抽并收缩，目标尺寸恰为条长。
- 缩放以对象原边界框左上角为锚。
- 同色有两根不同方向条的对象两轴各自独立缩放；无同色条的对象原样不动；所有条保留。

关键洞察：
- 条不是倍率读数而是目标尺寸的标尺——只看放大示例会归纳出"倍数=条长÷对象尺寸"
  的单向规则，收缩示例迫使把规则统一为"缩放到与条等长"；
  条的朝向决定作用轴，两轴可被不同的条独立指挥。
```

## 7. 角标握手

- 参考题目：6（3de23699 角标裁剪重涂）、2（e734a0e8 标记格接收印章）、14（ef26cbf6 分隔网格与标记）

  - operation:重涂色, recolor
  - operation:印章覆盖, stamp_overlay
  - object:角标记像素, corner_marker
  - object:中心图案, central_pattern
  - object:分隔线网格, separator_grid
  - object:标记像素, marker_pixel
  - relation:同色握手, color_handshake
  - condition:标记为锚点, marker_as_anchor

### docstring

```text
由四个角标裁出中心图案并重涂为角标色，只盖章进标记颜色与角标相同的单元格，
并以标记像素为图案的左上角锚点。

输入结构：
- 网格一角有一簇图形——四个同色角标像素框定一块另一颜色的中心图案。
- 其余区域被分隔线划分成单元格，若干单元格内各含一个单像素彩色标记，颜色不一。

规则：
- 取四角标围成矩形的内部图案，整体重涂为角标的颜色。
- 对每个标记颜色等于角标颜色的单元格，把重涂后的图案盖入该格，
  图案的左上像素与该标记像素重合。
- 其他颜色标记的单元格保持不变；原图案簇与分隔线原样保留。

关键洞察：
- 角标像素身兼三职——圈定裁剪范围、给出成品颜色、并作为"口令"筛选接收单元格；
  其他颜色的标记是外形相同的诱饵，图案的放置位置由标记自身坐标决定而非格中心。
```

## 8. 奇偶回声

- 参考题目：8（92e50de0 奇偶格接收副本）、2（e734a0e8 标记选格）、18（c9e6f938 镜像）
- tags:
  - operation:印章覆盖, stamp_overlay
  - operation:镜像, mirror
  - object:分隔线网格, separator_grid
  - object:种子图案, seed_motif
  - object:标记像素, marker_pixel
  - relation:格距奇偶定反射, cell_offset_parity_reflection
  - condition:仅标记格接收, only_marked_receive

### docstring

```text
把种子格内容盖进每个被标记的单元格，副本按行距与列距的奇偶分别做上下和左右镜像。

输入结构：
- 分隔线把网格划分成等大的单元格。
- 一个单元格内含多像素种子图案；若干其他单元格内各含一个分隔线色的内部标记像素。
- 其余单元格为空。

规则：
- 对每个含内部标记的单元格，取种子格的整格内容：
  若该格与种子格的列序号之差为奇数则先左右镜像，
  行序号之差为奇数则再上下镜像（两者皆奇等效180度旋转），然后整体贴入目标格。
- 标记像素被贴入内容覆盖；未标记格保持空。

关键洞察：
- 副本不是简单平铺——反射状态随格距奇偶在棋盘上交替：
  只看相邻格会误以为是纯镜像，只看同奇偶格又会误以为是纯复制，
  必须同时读出"标记选格"与"位移定向"两条规律。
```
