## 1. 折杆入座

- 参考题目题号：4（b9630600 空心矩形）、11（230f2e48 折叠/铰接）、20（7c66cb00 对接）
- tags:
  - operation:折叠, fold
  - operation:对接, dock
  - operation:填充, fill
  - object:直线杆, straight_rod
  - object:铰接标记, hinge_marker
  - object:空心矩形, hollow_rectangle
  - relation:长度精确相等, exact_length_match
  - condition:末梢落于开口, tip_lands_on_opening

### docstring

```text
把每根直杆在铰点处折转九十度，使尾梢精确对接某个空心框的开口，并用杆色灌满该框内部。

输入结构
- 背景为黑色。若干互不接触的灰色空心矩形框，每个框恰有一面墙正中缺失一格作为开口，框内为背景。
- 若干水平或竖直的直杆：杆身为单一线色（各杆不同），一端有青色锚点标记，杆身中部有一个洋红铰点标记。

规则
- 每根杆保留从锚点到铰点的一段不动，铰点另一侧的尾段绕铰点垂直折转九十度。
- 两个垂直折向中，选择使折后尾段末梢恰好落在某个框的开口格上的那一个方向；每根杆恰有一个可对接的框，每个框恰被一根杆对接。
- 对接完成后，该框的内部（含开口格）全部填充为该杆的线色；杆保持折后的形态，锚点与铰点标记保留。

关键洞察
- 折向不是朝空间开阔的一侧（首个示例中两者恰好一致，是诱饵）；真正的判据是尾段长度与铰点到开口的距离精确相等，折叠、对接与灌色三层互相锁定。
```

## 2. 键值柱配色

- 参考题目题号：3（9b365c51 调色板对应）、9（25094a63 隐藏对象检测）、16（d59b0160 图例作为过滤器）
- tags:
  - operation:重涂色, recolor
  - operation:擦除, erase
  - operation:计数, counting
  - object:键值柱, key_value_column
  - object:封闭孔洞, enclosed_hole
  - object:伪孔凹槽, pseudo_hole_notch
  - relation:孔数查表, hole_count_lookup
  - condition:无码即删, no_key_erased

### docstring

```text
左侧键值柱以码段高度为键、值段颜色为值，按对象的封闭孔洞数查表配色，查不到码的对象整体删除。

输入结构
- 背景为黑色。左侧若干从顶行垂下的柱，每根柱由两段构成：上段为统一码色（青色）、高度各柱不同，底端一格为该柱的值色（各柱不同）。
- 右侧若干互不接触的灰色连通对象；对象内部有封闭的背景孔洞，边缘另有开向外部的背景凹槽（非封闭）。

规则
- 数出每个灰色对象的封闭孔洞数 n（开向外部的凹槽不计）；若存在码段高度恰为 n 的柱，则该对象整体重涂为该柱底端的值色（孔洞与凹槽保持背景）。
- 若不存在码段高度为 n 的柱，则该对象整体擦除为背景。
- 输出中删去全部键值柱。

关键洞察
- 柱不是调色板序列而是键值表：整柱视为一种颜色、或按位置顺序一一对应都是诱饵（首个示例中位置顺序恰好成立）；对象侧真正的键是封闭孔数，凹槽是伪孔；查不到键的对象被过滤删除，三层判据缺一不可。
```

## 3. 闸门射线

- 参考题目题号：15（d037b0a7 同列向下传播）、14（758abdf0 边条与车道）、20（7c66cb00 反转色映射）
- tags:
  - operation:射线延伸, ray_extend
  - operation:色彩改写, color_rewrite
  - object:源像素, source_pixel
  - object:双色横杆, two_tone_bar
  - relation:当前色对闸色, current_color_vs_gate
  - condition:连锁通行, chained_passage

### docstring

```text
顶端源像素向下放射线，每道横杆按"当前颜色是否等于闸色"决定放行并改写颜色，形成连锁通行。

输入结构
- 背景为黑色。顶行有若干彩色源像素，位于不同列。
- 下方有若干条互不相邻的整行横杆；每条横杆主体为一种填充色，左右两端各一格为另一种闸色。

规则
- 每个源像素沿本列向下延伸射线，初始颜色为源色。
- 射线抵达一条横杆时：若射线当前颜色等于该杆的闸色，则穿过该杆并在穿过后变为该杆的填充色；否则射线终止于杆上方一格。
- 射线沿途按所处区段的当前颜色涂色，直至底行或首次被拦截处；横杆自身不变。

关键洞察
- 通行权取决于"当前"颜色而非源色：上一道杆的换色决定了下一道杆能否通过，构成连锁反应；只看单条射线或单道杆会误以为是简单的分段染色。
```

## 4. 图例库存拼贴

- 参考题目题号：7（626c0bcc 精确覆盖按形着色）、16（d59b0160 图例区域）
- tags:
  - operation:重涂色, recolor
  - operation:平铺, tiling
  - object:图例区域, legend_region
  - object:前景掩码, foreground_mask
  - relation:瓦片互锁拼合, tile_interlocking
  - condition:图例定义库存, legend_defines_inventory
  - condition:唯一精确覆盖, unique_exact_cover

### docstring

```text
以图例区展示的彩色小形状为瓦片库存，对灰色掩码做唯一精确覆盖并按图例配色。

输入结构
- 背景为黑色。左上角有一个由单色边线围出的图例区，内部并列摆放若干个小形状，每个形状单独一色。
- 主区域有一个灰色单色掩码。

规则
- 仅用图例中的形状（只允许平移，不旋转不翻转，可重复使用也可不用），对灰色掩码做恰好一次的精确覆盖；该覆盖唯一。
- 将每块放置的瓦片重涂为它在图例中的颜色。
- 图例区及其边线保持不变。

关键洞察
- 瓦片形状不是固定约定而是由图例定义的库存；个别图例瓦片在某些示例中从未被使用，是诱饵；瓦片之间可以互锁，局部背景形状不能作为切分依据，唯一性来自整体的精确覆盖。
```

## 5. 孤形蓝图

- 参考题目题号：5（aee291af 图案仅出现一次）、18（8e2edd66 克罗内克积）、3（9b365c51 顺序一一对应）
- tags:
  - operation:克罗内克积, kronecker_product
  - operation:去重筛选, uniqueness_filter
  - object:蓝图精灵体, blueprint_sprite
  - object:印章精灵体, stamp_sprite
  - relation:行主序一一对应, row_major_correspondence
  - condition:唯一性定角色, uniqueness_assigns_role
  - condition:份数等于前景格数, copy_count_equals_cells

### docstring

```text
唯一出现的形状是蓝图，反复出现的形状是印章，按行主序把印章色依次盖进蓝图的克罗内克展开。

输入结构
- 背景为黑色。画面散布若干小型单色精灵体，形状仅两类：一类形状出现多次（每份颜色各异），另一类形状仅出现一次。
- 多次形状的份数恰好等于唯一形状的前景格数。

规则
- 输出尺寸为唯一形状尺寸与多次形状尺寸的克罗内克展开。
- 按行主序枚举唯一形状的每个前景格：第 k 个前景格替换为多次形状的掩码，颜色取按画面位置行主序排列的第 k 份印章的颜色；唯一形状的背景格替换为全背景块。

关键洞察
- 唯一性决定角色分工：孤形是宏结构、复形是微结构；印章颜色的取用顺序由画面位置的行主序与蓝图前景格的行主序一一对应，"份数等于前景格数"正是发现这层对应的入口。
```

## 6. 廊距分色

- 参考题目题号：4（b9630600 空心矩形与走廊）、8（332202d5 最近种子分区与等距分隔）
- tags:
  - operation:最近扩散, nearest_fill
  - operation:填充, fill
  - object:空心矩形房间, hollow_room
  - object:走廊, corridor
  - object:种子像素, seed_pixel
  - relation:路径距离, geodesic_distance
  - condition:等步置隔断, equidist_separator

### docstring

```text
两个种子色沿房间与走廊的可通行路径扩散，各格取路径步数较近的种子色，等步格成为墙色隔断。

输入结构
- 背景为黑色格构成的可通行区域。灰色空心矩形房间散布网格中，墙上开口由一格宽的背景走廊互相连通，构成一个连通网络。
- 恰有两个房间内部各含一个种子像素，颜色互不相同。

规则
- 两种子色沿可通行背景格按四连通同步逐步扩散，墙不可穿越。
- 每个可达背景格涂为路径步数较近的种子色；两色恰好等步到达的格涂为灰色（与墙同色）。
- 墙与开口结构保持不变，不可达的背景格保持背景。

关键洞察
- 距离是绕墙的路径距离而非直线距离：首个示例中两者恰好一致（诱饵），其余示例中走廊绕行使直观上"更近"的种子在路径上反而更远；等步格构成的灰色隔断正好把网络切成两块领地。
```

## 7. 择法分区

- 参考题目题号：8（332202d5 最近种子分区）、19（2de01db2 行内反相）、12（ce9e57f2 逐行独立处理）
- tags:
  - operation:反转, invert
  - operation:重涂色, recolor
  - operation:擦除, erase
  - object:种子横杆, seed_bar
  - object:行内图案, row_pattern
  - relation:最近种子分区, nearest_seed_part
  - condition:种子色选变换, seed_color_selects_op
  - condition:等距异色清空, equidist_diff_cleared

### docstring

```text
每个非杆行按最近种子杆的颜色决定施加哪种变换——重涂、还是反相，等距异色行整行清空。

输入结构
- 背景为黑色。若干整行种子横杆，杆色仅有 P、Q 两种。
- 其余各行含一段稀疏的灰色图案，行与行的图案互不相同。

规则
- 每个非杆行找到与其行距最近的种子杆：
  - 最近杆为 P 色：该行灰色图案原形重涂为 P，其余格保持背景。
  - 最近杆为 Q 色：该行做行内反相——原图案格变为背景，行内其余格全部涂为 Q。
- 若该行与上下两侧最近杆等距且两杆颜色不同，则整行清空为背景；等距且同色的按该色规则处理。

关键洞察
- 种子颜色选择的不是"涂什么颜色"而是"施加哪种变换"；反相行与重涂行在输出中外观悬殊，首个示例容易被误读为普通的最近染色分区。
```
