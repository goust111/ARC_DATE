## 1. 层序回退

- tags:
  - operation:层序推断, layer_infer
  - operation:擦除, erase
  - operation:补全, completion
  - object:直线, straight_line
  - object:标记像素, marker_pixel
  - relation:遮挡层次, occlusion_order
  - condition:回退至标记层, rollback_to_marked_layer
- 参考题目题号：16、3、9

### docstring

```text
一句话总述：
根据孤立标记像素指定的目标层，剥掉其上方的所有直线，并把场景复原到目标层刚画完的时刻。

输入结构：
- 背景为占多数的单一颜色。
- 每种前景色是一条贯穿整个网格的一格宽横线、竖线或 45 度斜线的可见部分；上层直线在交点处遮挡下层直线。
- 另有一个不落在任何直线上的孤立像素，其颜色与其中一条直线相同，作为目标层标记。

规则：
- 由同色共线的可见像素复原每条完整直线。
- 在每个交点上，可见颜色所属的直线位于经过该点的其余直线之上，由此恢复唯一的自底向上叠放顺序。
- 删除严格位于标记色直线之上的所有直线；标记像素本身也抹去。
- 按叠放顺序重新绘制剩余直线：标记色直线成为最顶层，先前被删除层遮挡的下层像素全部重新显现。

关键洞察：
- 这不是"擦掉几种颜色"的就地编辑：上层被删后，下层直线原本被遮挡的缺口必须凭直线的整体几何补回来，因此必须先重建完整直线与全局层序，再整体重绘。
```

## 2. 接口对接成链

- tags:
  - operation:对接拼合, docking
  - operation:平移, translate
  - operation:裁剪, crop
  - object:精灵体, sprite
  - object:连接点, connector_pixel
  - relation:同色配对, same_color_pairing
  - condition:唯一序链, unique_chain
- 参考题目题号：7、3、16

### docstring

```text
一句话总述：
把散落的灰色部件按接口颜色两两配对、依伸出方向贴合，平移拼成唯一一条链后紧裁输出。

输入结构：
- 黑色背景上散落若干互不接触的灰色部件。
- 每个部件带一个或两个接口像素（非灰非黑），接口像素恰有一个灰色四邻，即从部件边缘向外伸出一格。
- 每种接口颜色在全图恰好出现两次，且分属两个不同部件；恰有两个部件只带一个接口，其余部件各带两个接口。

规则：
- 颜色相同的两个接口互为对接口。对接时只做平移：把一个部件移动到使两个对接口像素相邻、且各自的伸出方向恰好相对。
- 从任一只带一个接口的部件出发，沿接口配对逐个拼接所有部件，得到唯一的链条。
- 拼接完成后，把所有接口像素重涂为灰色，再对全部非背景像素做紧致裁剪作为输出。

关键洞察：
- 接口颜色是跨部件的配对签名，整幅拼装是接口配对图上唯一的一条链；对接的相对位置不靠形状试拼，而由"接口相邻、伸出方向相对"唯一锁定。
```

## 3. 双账本定位入侵者

- tags:
  - operation:计数, counting
  - operation:擦除, erase
  - object:地形轮廓, terrain_contour
  - object:分隔行, separator_row
  - object:精灵体, sprite
  - relation:柱高对应计数, bar_equals_count
  - relation:双键交叉比对, dual_key_cross_check
  - condition:唯一未入账对象, unique_unregistered_object
- 参考题目题号：5、12、19

### docstring

```text
一句话总述：
底部与右侧各有一份对同一片对象场的普查账本，一份按颜色计数、一份按尺寸计数，两本账同时多出的那一个对象是入侵者，把它擦除。

输入结构：
- 一条完整的水平分隔行与一条完整的竖直分隔列把网格划出中央对象场、底部账本区与右侧账本区。
- 对象场为黑背景，散布互不接触的单色 4 连通对象，颜色可重复、尺寸（像素数）可重复。
- 底部账本是从底边长起的彩色柱子：每种对象颜色一根柱，柱高记录该颜色的对象个数。
- 右侧账本是从右边缘向左长的灰色横条：自上而下第 k 根横条的长度记录尺寸恰为 k 的对象个数。

规则：
- 两本账各自恰好与对象场差一：颜色账在某种颜色 c 上比场内实际少记一个，尺寸账在某个尺寸 k 上也少记一个。
- 场内恰有一个对象同时具有颜色 c 与尺寸 k——它是未入账的入侵者，将其擦为黑色。
- 其余一切（含两本账）保持不变。

关键洞察：
- 单看任何一本账都只能把嫌疑缩小到一批对象（同色的有好几个、同尺寸的也有好几个）；只有识破两条边带是同一片场的两种不同键的直方图，交叉比对才能唯一锁定那一个对象。
```

## 4. 跨尺度互证修复

- tags:
  - operation:降采样, downsample
  - operation:补全, completion
  - object:多色图案, multicolor_pattern
  - object:缩放副本, scaled_copy
  - relation:整数缩放对应, int_scale_correspond
  - condition:旋转反射等价, rotation_reflection_equivalence
  - condition:块内多数决, block_majority
  - condition:已知格优先, known_cell_priority
- 参考题目题号：14、8、6、15

### docstring

```text
一句话总述：
同一幅多色画面画了小图和一份经过旋转或镜像再整数放大的大副本，用大图对应块的多数色填补小图缺失格，输出修补完成的小图。

输入结构：
- 黑背景上有两个矩形图案：一个带若干黑色缺失格的小图案，以及把完整小图案施加某个未知的旋转/镜像变换后再按整数倍率 s 逐格放大的大副本。
- 大副本上散布噪声像素：多数块内噪声只占少数，但恰有个别块被噪声占到半数以上，这些重灾块对应的小图格都不缺失。

规则：
- 由两个图案边界框边长之比得到倍率 s。
- 在八种朝向中，恰有一个朝向使小图全部已知格与大图对应块的多数色一致（重灾块除外），以此确定对应关系。
- 小图已知格一律保持不变；每个缺失格填入其对应块的多数色。
- 输出修补后的小图（小图案自身的尺寸）。

关键洞察：
- 两幅图互为对方的纠错码：几何对应（倍率与朝向）要靠小图已知格锚定，缺失内容要靠大图块多数决找回，而多数决失灵的重灾块恰好落在小图已知格上兜底——把大图整幅降采样、或不解出朝向就逐块照抄，都会得到错误答案。
```

## 5. 遮挡定向的图案转移

- tags:
  - operation:印章覆盖, stamp_overlay
  - operation:重涂色, recolor
  - operation:层序推断, layer_infer
  - object:分隔面板, separated_panel
  - object:图案掩码, motif_mask
  - object:交叉点, crossing_point
  - relation:遮挡层次, occlusion_order
  - condition:上层为源, top_is_source
- 参考题目题号：4、16、3

### docstring

```text
一句话总述：
每对面板由两条同各自底色的引线相连并恰好交叉一次，交点处压在上面的颜色指明由哪块面板向另一块盖印图案。

输入结构：
- 主导背景色上分布若干对同尺寸矩形面板；每块面板由一种底色和少量图案色像素构成。
- 每块面板从边缘引出一条与其底色同色的一格宽直线段；同一对面板的两条引线恰好垂直相交一次，交点只显示其中一方的底色。
- 不同面板对之间互不接触，各对的传递方向不必相同。

规则：
- 对每一对面板：交点可见颜色所属的面板为源，另一块为宿。
- 清掉宿面板原有的图案像素（还原为宿的底色），再把源面板的图案掩码按面板内相对位置盖印到宿面板上，掩码像素涂成源面板的底色。
- 源面板、两条引线与交点保持原样。

关键洞察：
- 交点的遮挡不是绘图瑕疵而是一支箭头——谁压在上面谁就是图案的输出方；传递方向必须逐对从交叉点读出，任何"固定从左到右"的猜测都会在别的面板对上翻车。
```

## 6. 叠影反演——找回缺失的对角顶点

- tags:
  - operation:补全, completion
  - object:标记像素, marker_pixel
  - object:隐形矩形, hidden_rectangle
  - relation:对角定框, diagonal_defines_rect
  - relation:奇偶叠影, odd_cover_shadow
  - condition:由叠影反推生成元, invert_from_overlay
- 参考题目题号：3、8、13

### docstring

```text
一句话总述：
黄色区域是一组从未画出的实心矩形的异或叠影，每个矩形只给出一枚对角顶点，找回每个矩形缺失的另一枚顶点。

输入结构：
- 背景为主导色。图中有一片（可能不连通的）黄色区域，以及若干孤立的彩色标记像素，每种标记色恰好出现一枚。
- 隐含设定：每种标记色对应一个轴对齐实心矩形（含边界），已给标记像素是它的一个角；所有矩形的异或叠影（被奇数个矩形覆盖的格）恰好等于图中的黄色区域；标记像素绘制在叠影之上。
- 缺失顶点的位置由黄区与已给顶点唯一确定。

规则：
- 为每种标记色求出缺失的那枚对角顶点，使全部矩形既不同行也不同列地张成，且它们的异或叠影与黄色区域严丝合缝一致。
- 输出：在输入网格上补画每枚缺失顶点（用对应标记色），其余一切保持不变。

关键洞察：
- 黄色区域不是底纹或对象，而是一组隐形矩形叠加后的奇偶残迹；黄区的每个凸角与凹角都是某个矩形角的痕迹，必须把"叠影是矩形异或"这一生成机制反推回去，缺失的角才有着落——任何把黄区当作现成形状去延伸或补全的读法都无法解释孤立的彩色标记。
```
