## 1. 图例行序定倍数

- tags:
  - operation:像素放大, pixel_scaling
  - operation:擦除, erase
  - object:图例, legend
  - object:单色对象, mono_object
  - relation:行序编码倍数, order_encodes_scale
  - condition:图例顺序决定层级, legend_order_layer
- 参考题目: `305b1341`, `f25fbde4`, `b5ca7ac4`

### docstring

```text
按图例行序决定的倍数就地放大各色对象，重叠处按图例行序分层覆盖。

输入结构
- 背景色网格，第 0 列自第 0 行起为单列图例，每行一个颜色样本格。
- 画布其余部分散布若干单色 4 连通对象，颜色恰为图例中出现的颜色。
- 示例保证放大后的对象之间存在重叠区域。

规则
- 清除图例列。
- 图例第 k 行（从 1 数起）颜色对应的每个对象，以其 bbox 左上角为锚，
  整体像素放大 k 倍：每个像素变为 k×k 色块，形状内的背景间隙同步放大。
- 放大结果之间重叠时，图例靠前行的颜色画在上层：按图例从最后一行到
  第一行的顺序依次绘制，后画者覆盖先画者。

关键洞察
- 图例列并不给出任何配色映射；行号本身就是数据——同一个序号既是该色
  对象的放大倍数，又是它在遮挡冲突中的层级。
```

## 2. 缺角方块是斜镜

- tags:
  - operation:射线延伸, ray_extend
  - operation:补全, complete
  - object:空心方块, hollow_square
  - object:缺角, missing_corner
  - object:源像素, source_pixel
  - relation:边缘起始, edge_origin
  - condition:缺角编码镜向, missing_corner_encodes_mirror
  - condition:击中才补全, hit_triggers_completion
- 参考题目: `69889d6e`, `952a094c`, `409aa875`, `0d87d2a6`

### docstring

```text
从边缘源点发射光线，缺角空心方块作为斜镜使其九十度反射，画出完整光路并补全被击中的镜块。

输入结构
- 黑色背景；唯一一枚非黑源像素位于某条网格边缘上，朝网格内部垂直发射光线。
- 场上散布若干 3×3 空心方块，每个方块恰好缺一个角像素，中心格为背景。
- 示例保证光线始终沿某个方块的中心行或中心列进入该方块。

规则
- 光线自源像素出发沿直线前进，途经的背景格涂成源色。
- 光线到达某方块的中心格时按镜面转向：缺东北角或西南角的方块等价于「/」镜，
  缺西北角或东南角的方块等价于「\」镜；转向后继续前进，直至走出网格。
- 光路经过其中心的方块把缺角补全（补上的角保持方块自身颜色）；
  未被光线击中的方块保持缺角原样。
- 光线不涂改方块自身的格子。

关键洞察
- 缺角不是破损或噪声，而是镜面朝向的编码；同一处缺角信息被使用两次：
  先决定光线的反射方向，再决定被击中后哪一角需要补全。
```

## 3. 并集才是钥匙

- tags:
  - operation:补全, union_complete
  - operation:形状匹配, shape_matching
  - operation:填充, fill
  - object:模板孔洞, template_hole
  - object:残缺碎片, partial_fragment
  - relation:对齐合并取并集, align_merge_union
  - condition:各副本互补缺失, copies_complement
  - condition:匹配形状决定填色, shape_determines_fill
- 参考题目: `f8cc533f`, `93b4f4b3`, `73ccf9c2`

### docstring

```text
左板模板孔洞的形状，需用右板同色碎片的对齐并集来匹配，并以该颜色填孔。

输入结构
- 一条竖直分隔线把网格分为左右两板。
- 左板是单色模板覆盖在背景上，内部含若干互不连通的背景孔洞区域。
- 右板含多种颜色，每种颜色以 2~3 个彼此分离的残缺碎片出现；
  同色碎片是同一形状按 bbox 左上对齐的互补残片，没有任何单个碎片是完整的。

规则
- 对右板每种颜色：把各碎片分别裁剪到自身 bbox，按左上角对齐取掩码并集，
  得到该颜色的完整形状。
- 左板每个孔洞区域与恰好一个完整形状同形（允许平移，不允许旋转或镜像）；
  用该颜色填充该孔洞。
- 输出仅为处理后的左板。

关键洞察
- 拿任何单个碎片去和孔洞比对都会失败；形状钥匙只有把同色残片
  按左上对齐并起来之后才会显现。
```

## 4. 看不见的对角线对决

- tags:
  - operation:射线延伸, ray_extend
  - operation:连线, draw_line
  - object:对角线段, diagonal_bar
  - object:虚拟直线, virtual_line
  - relation:对角朝向, diagonal_orientation
  - relation:长度对决, length_duel
  - condition:奇偶决定有无整格交点, parity_gates_intersection
  - condition:等长平局特判, tie_special_case
  - condition:以输入线段为准, input_only_evidence
- 参考题目: `1d61978c`, `69889d6e`, `ded97339`, `409aa875`

### docstring

```text
每条对角线段确定一条无形的完整对角直线；异向线段两两在虚拟交点处对决，胜者才真正延长过去。

输入结构
- 背景网格上散布若干条一格厚对角线段，颜色各异；
  两种朝向（左上-右下与右上-左下）都存在，线段互不接触。

规则
- 对每一对朝向相反的线段，考察它们所在完整对角直线（画面上未画出）的交点：
  奇偶不匹配的线对没有落在整格上的交点，直接跳过。
- 交点为整格且当前为背景时发生对决：较长的线段沿自身方向真正延长到该交点
  （补画从线段近端到交点的整段延长，全部用胜者颜色），较短者原样不动。
- 两线段等长时，双方都延长到该交点，且交点格涂蓝色。
- 所有对决只依据输入线段的原始长度与位置判定；延长新画出的像素
  不参与任何后续判定。一条线段可以在多场对决中获胜并多次延长。

关键洞察
- 画面上从未出现完整对角线，相交发生在虚拟直线之间；谁有资格生长由
  长度对决决定，而且一切以输入原始线段为准——新长出的部分不产生连锁。
```

## 5. 容器外的重力罗盘

- tags:
  - operation:平移, translate
  - operation:排序, sort
  - operation:擦除, erase
  - object:空心矩形容器, rectangular_container
  - object:外部标记像素, external_marker
  - relation:标记颜色对应, marker_color_match
  - relation:所在侧编码方向, side_encodes_direction
  - condition:距离优先排序, distance_priority_ordering
  - condition:阻挡堆积, blocking_stack
- 参考题目: `94133066`, `b5ca7ac4`, `952a094c`

### docstring

```text
容器外的同色标记指明各颜色的滑落方向，标记离容器越近的颜色越先滑动堆积。

输入结构
- 背景网格中央有一个一格厚的空心矩形容器，内部散布若干种颜色的像素。
- 容器外，每种内部颜色恰有一枚同色标记像素，贴近容器的某一侧。

规则
- 每种颜色的滑动方向 = 从容器指向其外部标记所在的那一侧。
- 按各标记到容器外壁的直线距离从小到大，依次处理各颜色。
- 处理一种颜色时，其全部像素沿该方向滑动到底，被容器内壁或
  已静止的像素阻挡；同色像素按靠近目标壁者先落位。
- 清除全部外部标记；容器本身保持不变。

关键洞察
- 外部标记不是要搬进容器的内容，而是方向与优先级的双重指令：
  所在侧给出该色的重力方向，到容器的距离给出处理次序，
  而次序决定了谁垫底、谁堆在上面。
```

## 6. 旋转残卷拼完卷

- tags:
  - operation:旋转, rotate
  - operation:补全, complete
  - operation:裁剪, crop
  - object:象限, quadrant
  - object:分隔行列, separator_row_col
  - object:残缺副本, damaged_copy
  - relation:旋转副本对应, rotation_copy_correspondence
  - condition:各副本互补缺失, copies_complement
  - condition:缺失角度反推朝向, missing_angle_infers_orientation
- 参考题目: `0b148d64`, `f8cc533f`, `ea959feb`, `94133066`

### docstring

```text
三个象限是同一图案的三个残缺旋转副本，旋转对齐取并集复原全卷，再按缺失的角度补出空白象限。

输入结构
- 一行一列分隔线把网格分成四个等大象限。
- 其中三个象限各含同一图案的一个旋转副本，旋转角互不相同，
  取自 0°、90°、180°、270°；每个副本都残缺——部分像素被擦成背景，
  且三个副本的残缺互补。
- 第四个象限完全空白。
- 图案本身不具有任何 90° 旋转对称，保证角度指派唯一。

规则
- 先判定三个残缺副本各自的旋转角：以可见像素之间的两两旋转一致性唯一确定。
- 将三个副本旋转对齐后取并集，得到完整图案。
- 空白象限对应的旋转角是四个角度中未被使用的那一个。
- 输出 = 空白象限应有的完整内容：完整图案按该缺失角度旋转后写出，
  尺寸为单个象限。

关键洞察
- 三个副本互为旋转而非平移（先按平移对齐必然失败）；任何单个副本
  都不完整，完整图案只存在于旋转对齐后的并集之中；待求象限的朝向
  不写在画面上，要由"缺失的角度"反推。
```

## 7. 先照镜子再认亲

- tags:
  - operation:对称化, symmetrize
  - operation:形状匹配, shape_matching
  - operation:重涂色, recolor
  - object:占位符对象, placeholder_object
  - object:模板对象, template_object
  - relation:并集对称化对应, union_symmetrize_correspondence
  - condition:直接匹配必败, direct_match_fails
- 参考题目: `2a5f8217`, `73ccf9c2`, `f8cc533f`

### docstring

```text
每个蓝色占位对象与"某彩色模板并上它自己的左右镜像"同形，用该模板的颜色重涂占位。

输入结构
- 黑色背景上散布若干 4 连通对象。
- 蓝色对象都左右镜像对称，是待涂色的占位符。
- 非蓝对象都是左右不对称的彩色模板。

规则
- 对每个彩色模板，在其 bbox 内取"模板掩码 ∪ 该掩码的左右镜像"，
  得到它的对称化形状。
- 每个蓝色对象与恰好一个模板的对称化形状（归一化到 bbox 后）相同；
  将该蓝色对象整体重涂为对应模板的颜色。
- 模板与背景保持不变。

关键洞察
- 占位与模板直接比对永远失败；蓝色对象记录的是模板"照过镜子"
  之后的样子——占位全对称、模板全不对称，这一反差本身就是暗号。
```

## 8. 散点是旋钮

- tags:
  - operation:计数, counting
  - operation:旋转, rotate
  - operation:放置, place
  - object:帧序列, frame_sequence
  - object:分隔列, separator_column
  - object:单元精灵, unit_sprite
  - object:散布点, sparse_dot
  - relation:计数编码旋转, count_encodes_rotation
  - condition:码表跨帧自举, code_induced_across_frames
  - condition:帧序打乱诱饵, shuffled_order_bait
- 参考题目: `6e02f1e3`, `a32d8b75`, `ea959feb`

### docstring

```text
从多个帧中归纳"散点数等于旋转次数"的暗码，为空缺帧补上正确旋转的图案。

输入结构
- 竖直分隔线把网格分成若干等宽帧。
- 除待作答的一帧外，每帧含同一 sprite 的某个 90° 旋转副本与若干枚单像素散点；
  各帧中 sprite 占据相同的正方形 bbox 锚位。
- 恰有一帧散点数为 0，其 sprite 即基准朝向；待作答帧只有散点、没有 sprite。
- 帧的排列顺序与散点数无关（顺序被打乱）。

规则
- 各帧满足：sprite 旋转角 = 90° × 该帧散点数（顺时针，相对基准帧）。
- 输出 = 待作答帧的完整画面：保留其散点，并在锚位补上按其散点数
  旋转后的 sprite；输出尺寸为单帧。

关键洞察
- 旋转角与帧的排列顺序无关——按帧序找递增规律是诱饵；每帧的散点
  不是噪声，而是发给本帧 sprite 的旋转指令，这张码表没有图例给出，
  必须靠跨帧对照自行归纳。
```

## 9. 隐形条纹点名

- tags:
  - operation:重涂色, recolor
  - operation:擦除, erase
  - operation:计数, counting
  - object:种子像素, seed_pixel
  - object:虚拟条纹, virtual_stripe
  - object:单色对象, mono_object
  - relation:种子定条纹周期, seed_sets_stripe_period
  - condition:多数覆盖决定色, majority_cover_color
  - condition:零覆盖即除名, zero_cover_erased
- 参考题目: `0a938d79`, `1d61978c`, `0d87d2a6`

### docstring

```text
两颗边缘种子定义一套从不画出的周期条纹，用它给场上对象重涂或除名。

输入结构
- 背景网格；同一侧边缘上有两颗不同色的种子像素。
- 其余前景为若干灰色 4 连通对象，散布在网格各处。

规则
- 两种子定义交替虚拟条纹：过两种子所在行各一条横向条纹，
  并以两倍行距为周期向两端交替重复两种子色；条纹不画出。
- 每个灰色对象统计其像素被两色虚拟条纹行覆盖的数量：
  哪种颜色的条纹覆盖多，对象整体重涂为该色；
  两色覆盖相等（含都为零）则整个对象擦除为背景。
- 种子像素保留。

关键洞察
- 条纹系统从未出现在画面上，它只是一张隐形点名表；
  对象的存亡与新颜色由它和虚拟周期条纹的重叠票数决定，
  而不由对象自身的形状或位置直接决定。
```
