## 1. 自延拓印章链

- 参考题目题号: 11 (f5c89df1)、19 (a9f96cdd)、3 (247ef758)
- tags:
  - operation:印章覆盖, stamp_overlay
  - operation:链式复制, chain_replication
  - object:精灵体, sprite
  - object:锚点像素, anchor_pixel
  - object:种子像素, seed_pixel
  - relation:相对坐标复制, relative_coord_copy
  - condition:越界即终止, stop_at_boundary

### docstring

```text
沿精灵体内两枚控制像素定义的位移向量，把精灵体一份接一份地链式盖印，直到越出网格。

输入结构
- 黑色背景网格上有一个多像素的青色精灵体。
- 精灵体内部恰有一枚绿色锚点像素和一枚红色种子像素，它们替换了精灵体的两个格子。
- 网格其他地方恰有一枚孤立的红色像素。

规则
- 以锚点像素为原点，记录精灵体（连同两枚控制像素）的相对形状。
- 将精灵体盖印到孤立红色像素处，使锚点对准该红色像素。
- 新盖印出的副本又带有一枚红色种子像素，它成为下一次盖印的对准目标；如此反复。
- 当下一份副本有任何格子越出网格时停止；原精灵体与所有已盖印副本保留。

关键洞察
- 两种控制色的分工是关键：绿色是"贴附点"，红色是"再生点"；种子与锚点的相对位移决定了链条的固定步进向量。完整的复制列车从未在输入中画出，画面上只有它的生成元——第一个示例可设计成网格恰好只容一份副本，诱导"单次盖印"的错误假设，后续示例再展开整条链。
```

## 2. 远程点环开关

- 参考题目题号: 13 (b7fb29bc)、12 (9def23fe)
- tags:
  - operation:同心层填充, concentric_fill
  - operation:重涂色, recolor
  - object:矩形边框, rectangular_frame
  - object:控制像素, control_pixel
  - object:标记像素, marker_pixel
  - relation:切比雪夫距离作键, chebyshev_distance_key
  - condition:等距环被点亮, ring_lit_by_matching_distance

### docstring

```text
框外每枚标记按它到框内控制像素的切比雪夫距离，点亮框内对应半径的同心方环，并用自身颜色着色。

输入结构
- 网格有统一背景色；一个一像素厚的灰色矩形边框内部恰有一枚灰色控制像素。
- 边框外散布若干枚单像素标记，颜色各不相同；任意两枚标记到控制像素的切比雪夫距离互不相同。
- 部分标记故意与控制像素同行或同列摆放。

规则
- 对每枚框外标记，计算它到控制像素的切比雪夫距离 d。
- 在框内，把到控制像素切比雪夫距离恰为 d 的全部背景格涂成该标记的颜色；环超出边框的部分被裁掉。
- 未被任何距离命中的环保持背景色；边框、控制像素与框外标记原样保留。

关键洞察
- 同心环在输入中从未画出，它们只是潜在结构；标记与行列对齐与否毫无关系——同行同列的摆放是诱饵，引人按"标记排除行列"的规则去读——真正的钥匙是每枚标记的切比雪夫距离本身。
```

## 3. 走廊弹珠队列

- 参考题目题号: 8 (f1bcbc2c)、6 (ae3edfdc)、16 (f18ec8cc)
- tags:
  - operation:膨胀求交, dilate_intersect
  - operation:滑动, sliding
  - operation:排序, sort
  - object:路径组件, path_component
  - object:通道, channel
  - relation:队列次序保持, queue_order_preserved
  - condition:滑动至受阻, slide_until_blocked

### docstring

```text
散落在走廊入口附近的彩珠按到入口的远近排队穿过两条路径夹成的单格走廊，并在出口外靠墙依次叠停。

输入结构
- 黑色背景上有两条灰色的四连通单像素宽开放路径，二者平行蜿蜒；各自一格邻域膨胀的交集构成一条两端开口的单格宽走廊。
- 走廊一端开口附近散布若干枚颜色互不相同的单像素彩珠，不排成直线，且到入口格的棋盘距离互不相同。
- 另一端开口朝向一片空旷区域。

规则
- 走廊为两条路径各自一格邻域膨胀的交集；离彩珠更近的开口为入口，另一端为出口。
- 彩珠按到入口格的距离从近到远依次入廊、穿行、飞出：先出的珠沿出口开口方向直线滑行，直到撞上网格边缘停下；后出的珠停在前一枚珠子的正后方。
- 原彩珠位置全部清除；两条路径保持不变。

关键洞察
- 两条路径之间的缝隙不是待填色的目标，而是一条隐含的传送管道；出口端珠列是入口端"到入口距离"这一隐含队列次序的重新编码——离入口最近的珠最终离出口最远。
```

## 4. 变倍找差

- 参考题目题号: 7 (6b9890af)、15 (2c181942)、2 (506d28a5)
- tags:
  - operation:像素放大, pixel_upscale
  - operation:旋转, rotation
  - operation:掩码比对, mask_compare
  - operation:缩小输出, downscale_output
  - object:图案, pattern
  - relation:尺寸比定倍率, size_ratio_sets_scale
  - condition:唯一旋转最少失配, unique_rotation_min_mismatch

### docstring

```text
把小图案按尺寸比放大并旋转到与大图案对齐后逐块比对，输出缩小回小图案尺寸的差异掩码。

输入结构
- 黑色背景上有两个实心多色矩形图案块：一个 p×q 的小图案与一个 kp×kq 的大图案（k 为整数），二者位置无关。
- 大图案由小图案放大 k 倍并旋转某个 90° 的倍数得到，随后有少量 k×k 整块被改成了其他颜色。
- 恰有一个旋转角使逐块失配数最少。

规则
- 由两图案的边长之比得到倍率 k。
- 在 0°、90°、180°、270° 中选取使失配块数最少的旋转角，把放大后的小图案与大图案逐 k×k 块对齐比对。
- 输出一个与大图案同朝向、边长缩小 k 倍的网格：对应块一致处为黑，失配块处涂红。

关键洞察
- 两个图案的关系隐藏在"先放大再旋转"的归一化之后，直接逐格比对毫无意义；差异天然以 k×k 整块出现，因此答案存在于缩小 k 倍的坐标系里，而不是大图案的坐标系里。
```

## 5. 客籍指针排序

- 参考题目题号: 16 (f18ec8cc)、5 (414297c0)、17 (22a4bbc2)
- tags:
  - operation:排序, sort
  - operation:整块移动, block_move_intact
  - object:色块条带, color_stripe
  - object:标记像素, marker_pixel
  - relation:客色指后继, guest_color_points_to_successor
  - condition:无人指向者为链头, unreferenced_block_is_head

### docstring

```text
把竖直色块按块内客籍标记颜色构成的后继指针链重新从左到右排列。

输入结构
- 网格由若干等宽竖直色块拼成，每块有唯一的主色。
- 除恰好一块外，每块内部散布少量同一种"客籍"颜色的标记像素，该颜色必是另一块的主色。
- 所有客籍颜色互不相同，且没有任何块的客籍颜色指回自身。

规则
- 把"块 A 的客籍颜色是块 B 的主色"读作"B 是 A 的后继"。
- 链头是主色未被任何块用作客籍颜色的那一块；从链头出发沿后继关系排出全序，无标记的块自然落在链尾。
- 按此顺序将各块整块（连同其内部标记像素）从左到右重新拼合，块的内部内容一律不变。

关键洞察
- 块内的异色像素既不是要清除的噪声，也不是要重涂的对象，而是一张从未画出的链表的指针；目标顺序不写在任何图例里，只能沿指针逐块重建，且起点必须由"谁不被任何人引用"反向推出。
```

## 6. 遮得越深翻得越高

- 参考题目题号: 3 (247ef758)、18 (a8d7556c)、20 (d749d46f)
- tags:
  - operation:整形补全, amodal_completion
  - operation:遮挡重排, restack
  - operation:排序, sort
  - object:实心矩形, solid_rectangle
  - relation:被遮面积定层级, hidden_area_sets_depth
  - condition:被遮最多者置顶, most_hidden_on_top

### docstring

```text
从可见碎片还原每个被遮挡实心矩形的完整范围，算出各自被遮住的面积，再按"被遮面积越大层级越高"重新叠放。

输入结构
- 黑色背景上有若干互相重叠的实心单色矩形，颜色互不相同，按某个原始层叠顺序绘制，上层遮住下层。
- 每个矩形至少露出两个对角，故其完整边界可由同色像素的包围盒唯一还原。
- 各矩形被遮住的格数互不相同。

规则
- 对每种颜色取其可见像素的包围盒，还原该矩形的完整范围。
- 对每个矩形计算被遮面积 = 完整面积 − 可见格数。
- 按被遮面积从小到大依次绘制：被遮最少者最先画（压底），被遮最多者最后画（升到最上层）。
- 矩形位置与背景保持不变，只有重叠区域的归属发生改变。

关键洞察
- 新层级的钥匙既不写在颜色里，也不是把原始顺序简单反转——反转只是在个别示例里碰巧成立的诱饵；它是一个画面上不存在的派生量：每个矩形"丢失了多少"。而要得到它必须先补全整形、再与可见部分作差，原先被压得越狠的矩形在输出里升得越高。
```

## 7. 缺口管道连灌

- 参考题目题号: 1 (15663ba9)、10 (db7260a4)、14 (f8be4b64)、8 (f1bcbc2c)
- tags:
  - operation:填充, flood_fill
  - operation:射线延伸, ray_extend
  - operation:连锁传播, chain_propagation
  - object:闭合正交环路, closed_orthogonal_loop
  - object:缺口端口, gap_port
  - object:控制像素, control_pixel
  - relation:缺口对齐成管, gap_alignment_forms_pipe
  - condition:流经环才被填, filled_only_if_traversed

### docstring

```text
颜料从源环内出发，经缺口以直线射流串联注满沿途每个缺口对齐的环，未被流经的环保持空心。

输入结构
- 黑色背景上散布若干一像素宽的灰色闭合正交环路，每个环的边界上开有一或两个一像素宽的缺口。
- 恰有一个环内含一枚彩色源像素；该环只有一个缺口。
- 有两个缺口的环，其缺口分别与链条中相邻环的缺口在同一行或同一列上正对，其间无阻挡；另有部分环与任何射流都不对齐，是干扰项。

规则
- 用源像素颜色填满源环的内部，随后颜料从其缺口沿缺口朝外的方向直线喷出，画出射流线，直到进入某个环的缺口或抵达网格边缘。
- 射流经缺口进入的环，其内部同样被填满，颜料再从该环的另一个缺口继续直线喷出；如此连锁，直到射流抵达网格边缘或进入只有一个缺口的环为止。
- 所有被流经的环内部与射流线均涂为源色；未被流经的环及其内部保持原样；灰色环壁不变。

关键洞察
- 缺口不是画错的破损而是端口；哪些环被填并不取决于形状、大小或到源环的远近，而取决于它是否被这条从未整体画出的"管道链"串联——判断连通必须沿射流逐段追踪，一处错配就会使下游整段保持空心。
```
