## 1. 镜像还原钥匙选形

- tags:
  - operation:对称补全, symmetry_completion
  - operation:形状匹配, shape_matching
  - operation:重涂色, recolor
  - object:遮挡块, occluder
  - object:候选精灵, candidate_sprite
  - relation:还原后匹配, recover_then_match
  - condition:镜像诱饵候选, mirrored_decoy
- 参考题目题号: 8（dc0a314f）、12（8e5c0c38）、5（760b3cac）

### docstring

```text
先定位局部场景的竖直对称轴、用镜像还原遮挡方块下的隐藏图形，再以还原图形（而非其可见孪生）为钥匙，在候选中挑出真匹配并涂成遮挡块的颜色。

输入结构
- 网格上部是一个关于自身竖直轴严格镜像对称的图案场景，该轴不在网格中央列，需由图案本身定位。
- 场景中一块矩形区域被唯一的纯色实心方块遮住，遮挡色在整个网格中只出现在该方块上；被遮的图形自身不具有左右轴对称性。
- 网格下部散布若干形状互不相同的单色小图形（候选）：其中恰有一个与被遮图形（镜像还原后）平移全等，另有一个候选与轴另一侧可见的孪生图形原样平移全等（诱饵），其余候选形状无关。

规则
- 由上部图案的自重合性定位竖直对称轴。
- 把遮挡方块区域映射到轴另一侧，读取对应图案并水平翻转，得到被遮内容；用还原内容替换遮挡方块，使场景恢复完全对称。
- 在候选中找出与还原图形平移全等的那一个（不是与可见孪生原样全等的诱饵），将其整体重涂为遮挡块的颜色；其余候选与网格其余部分保持不变。

关键洞察
- 匹配的钥匙从未直接可见：必须完成对称还原才知道它的确切形状；由于图形非轴对称，"照抄可见孪生"的候选是陷阱——只有翻转后的形状才是被遮真身，而遮挡块的颜色正是给中选者的涂料。
```

## 2. 最近角定向的分形印章

- tags:
  - operation:印章覆盖, stamp
  - operation:旋转, rotate
  - operation:重涂色, recolor
  - object:模板面板, template_panel
  - object:针角像素, pin_corner_pixel
  - relation:最近角距离, nearest_corner_dist
  - condition:位置决定朝向, position_encodes_orientation
- 参考题目题号: 15（b190f7f5）、7（4a1cacc2）、2（cf5fd0ad）

### docstring

```text
把源面板的每个彩色像素扩展为模板印章的一份重涂拷贝，印章的旋转朝向由该像素在源面板内的唯一最近角决定。

输入结构
- 输入由两个等大的正方形面板并排或上下叠放，共享同一背景色。
- 一个面板是源网格，含稀疏彩色像素，且每个彩色像素到面板四角的曼哈顿距离有唯一最小者。
- 另一个面板是模板：用单一标记色画出的图案，其外接框的某一个角上有一个异色"针角"像素，标记模板的朝向。

规则
- 对 N×N 面板构造 N²×N² 输出，初始化为背景色。
- 对源网格中位于 (r,c) 的每个彩色像素：把模板（针角并入图案）整体旋转，使针角从模板原方位转到该像素最近角的方位；再把整个图案统一重涂为该像素的颜色。
- 把旋转重涂后的印章盖入输出中块坐标为 (r,c) 的 N×N 块。

关键洞察
- 旋转指令没有写在任何地方：它由每个源像素相对面板四角的几何位置隐式给出，而针角像素是唯一能定义"模板朝向"的锚点——忽略其中任何一个都无法确定印章的方向。
```

## 3. 条纹只是量尺，杂点才是答案

- tags:
  - operation:去噪, denoise
  - operation:裁剪, crop
  - object:条纹行列, stripe_line
  - object:噪声像素, noise_pixel
  - relation:主色占优, dominant_color
  - condition:噪声即输出, noise_is_output
- 参考题目题号: 19（e26a3af2）、12（8e5c0c38）、11（73182012）

### docstring

```text
判定条纹方向、按各线主色识破杂点，然后输出的不是洗净的条纹，而是全部杂点在其外接框内组成的图形。

输入结构
- 画布铺满横条纹或竖条纹（不同示例方向不同），每条线都有唯一主色，无独立背景色。
- 稀疏杂点打破条纹：杂点颜色可以与其他条纹线的主色相同，但不出现黑色。
- 全部杂点在其外接框内构成一个连贯图形。

规则
- 分别按行、按列统计主色覆盖数，取覆盖显著更高的方向为条纹方向。
- 与所在条纹线主色不同的像素即杂点。
- 输出为杂点外接框大小的网格：杂点保持原色与相对位置，其余格涂黑色。

关键洞察
- 这不是把画布洗干净的去噪题：条纹与主色只是判定"谁是杂点"的量尺，真正要交付的恰是被去掉的那部分；又因杂点可穿别的条纹主色的"伪装"，不能靠调色板差集抓杂点，只能逐线判定。
```

## 4. 迷宫洪水的下一帧

- tags:
  - operation:外推, extrapolate
  - operation:传播, propagate
  - object:面板序列, panel_sequence
  - object:背景通道, background_channel
  - relation:周期调度, periodic_schedule
  - condition:预测下一帧, predict_next_frame
- 参考题目题号: 16（2ccd9fef）、4（5961cc34）、1（b7f8a4d8）、6（6ffe8f07）

### docstring

```text
从等大面板序列中归纳洪水沿迷宫通道每帧推进的固定层数，输出按同一规律演化出的下一帧。

输入结构
- 输入由三个以上等大面板排成一行（或一列），面板间以分隔线隔开。
- 每个面板画着完全相同的墙体迷宫，墙体之间是背景通道。
- 一种洪水色从某个种子格出发占据通道格：第 k 帧的洪水恰为通道图中到种子的四邻域距离不超过 k·s 的全部格，步幅 s 为对本题恒定但需要归纳的正整数。

规则
- 对比相邻两帧的洪水边界，归纳出每帧推进的层数 s。
- 输出单个面板：墙体照抄，在最后一帧洪水的基础上，沿通道再做 s 层四邻域扩张。
- 墙体永不被淹没，扩张不得穿墙。

关键洞察
- 要求的不是最后可见的一帧，而是再演化一帧；推进量对时间恒定、对空间却被墙体折弯，只有把"帧差"读成通道图上的等距层，才能在拐角与窄道处画对新边界。
```

## 5. 缺口的两种命运

- tags:
  - operation:射线延伸, ray_extend
  - operation:擦除, erase
  - operation:补全, completion
  - object:空心矩形, hollow_rectangle
  - object:边框缺口, frame_gap
  - object:障碍对象, blocker_object
  - relation:行列对齐, row_column_alignment
  - condition:对齐定缺口角色, alignment_decides_gap_role
- 参考题目题号: 6（6ffe8f07）、4（5961cc34）、18（917bccba）

### docstring

```text
空心矩形边框上的缺口有两种命运：与内部像素对齐的缺口是出口，该像素被擦除并从缺口向外射出其颜色的射线；与任何像素都不对齐的缺口则被用边框色封补。

输入结构
- 背景网格上有一个一像素厚的空心矩形边框，边框上有若干个一像素宽的缺口。
- 矩形内部散布彩色单像素：一部分缺口与恰好一个内部像素同行（左右边缺口）或同列（上下边缺口）对齐；另一部分缺口与任何内部像素都不对齐；同时另有一些内部像素与任何缺口都不对齐。
- 边框外可能有实心障碍块位于某些射线路径上。

规则
- 对每个与内部像素对齐的缺口：把该像素从原位擦除，并从缺口外侧第一格起，沿离开矩形的方向画一条该像素颜色的射线，直到网格边缘，或在障碍块前一格停止。
- 对每个不与任何内部像素对齐的缺口：用边框色把缺口填补，使边框在该处闭合。
- 不与任何缺口对齐的内部像素原地保留。

关键洞察
- 同样是缺口，命运却由"是否有对齐的内部像素"决定——有则为出口（放行并射线），无则为缺陷（封补）；若只看部分示例，很容易把全部缺口当成待修复缺陷或把全部内部像素当成都会逃逸，只有把缺口、内部像素、障碍三方的对齐关系读全，才能同时画对射线、封口与留守像素。
```

## 6. 引力源指定的十字迁角

- tags:
  - operation:平移对齐, translate_align
  - operation:擦除, erase
  - object:空心矩形, hollow_rectangle
  - object:十字图案, cross_pattern
  - object:标记像素, marker_pixel
  - relation:最近角距离, nearest_corner_dist
  - condition:标记选定目的角, marker_selects_corner
- 参考题目题号: 18（917bccba）、7（4a1cacc2）、5（760b3cac）

### docstring

```text
每个矩形边框内的十字被搬到该边框四角中离全局孤立标记像素最近的那个角上，边框与标记保持不动。

输入结构
- 背景上有若干个一像素厚、互不相交的矩形边框；每个边框的内部各被一个颜色不同的十字（一整行加一整列）穿过。
- 网格上另有一个孤立标记像素，不属于任何边框与十字；它到每个边框四角的曼哈顿距离都有唯一最小者。
- 各十字迁移后的目标行与目标列互不重叠。

规则
- 对每个边框：擦除其原十字所在的整行整列上的十字色。
- 找出该边框四角中离标记像素曼哈顿距离最近的角，沿该角所在的整行与整列重画十字色。
- 把所有边框重新覆盖在十字之上，标记像素保持原样并覆盖在最上层。

关键洞察
- 标记像素自己不动也不被涂改，它是所有边框共享的"引力源"：不同边框的十字可迁往不同方位的角，只看几何距离——若只看第一个示例，很容易误以为目的角是固定方位。
```

## 7. 图案坍缩为对称轴

- tags:
  - operation:对称补全, symmetry_completion
  - operation:擦除, erase
  - operation:逐列填充, column_fill
  - object:色层, color_layer
  - object:对称轴, symmetry_axis
  - relation:逐色处理, per_color_processing
  - condition:输出轴而非图, axis_is_answer
- 参考题目题号: 12（8e5c0c38）、19（e26a3af2）、17（17b80ad2）

### docstring

```text
为每种颜色找出它专属的竖直镜像轴，然后把该颜色的像素全部收起，改画成位于轴列、贯穿全高的一条竖线。

输入结构
- 背景上有若干种非背景色，每种颜色的像素关于某一条竖直网格列近似镜像对称，但混有少量破坏对称的噪声像素。
- 各颜色的对称轴列互不相同；对每种颜色，使镜像配对像素数最大的轴列唯一。

规则
- 对每种颜色独立地：在所有竖直列中找到使该色像素镜像配对数最大的唯一轴列。
- 删除该颜色的全部像素（含噪声）。
- 在其轴列画一条贯穿网格全高的该色竖线；其余格子一律为背景色。

关键洞察
- 去噪与补全都只是幌子：图案是轴的"生成物"，而轴这个真正的对象从未被画出——输出要求把每个图案整体坍缩为其对称轴，且每种颜色的轴各自独立，不存在全局对称轴。
```

## 8. 晶格空洞的粗尺度图画

- tags:
  - operation:裁剪, crop
  - operation:降采样读出, downscale_readout
  - object:网格线, lattice_line
  - object:缺失交叉点, missing_intersection
  - object:干扰像素, distractor_pixel
  - relation:分块对应, block_correspondence
  - condition:缺损承载信息, defect_encodes_data
- 参考题目题号: 14（a644e277）、15（b190f7f5）、10（4f537728）

### docstring

```text
把规则晶格上被挖空的交点读成一幅低分辨率图画：输出以交点阵为坐标系的小网格，空洞处涂线色。

输入结构
- 一种线色按固定周期画满整幅网格的横线与竖线，构成规则晶格；交点处本应为线色。
- 若干交点被挖成背景色空洞；空洞数量不固定，也不构成某个矩形的四角。
- 部分晶格单元内部散布彩色干扰像素。

规则
- 按行列顺序对全部交点编号，得到 R 行 C 列的交点阵。
- 输出 R×C 网格：被挖空的交点对应格涂线色，完好交点对应格涂背景色。
- 单元内部的干扰像素一概忽略。

关键洞察
- 空洞既不是待修补的缺陷，也不是四角裁剪标记（数量与布局都对不上）：它们是以交点阵为像素坐标的一幅粗尺度图画，而看似有用的单元内彩色像素才是真正的噪声——精细结构上的"缺损"承载信息，显眼的"内容"反而无关。
```
