## 1. 多米诺连锁倾倒

- 参考题目: `84551f4c`、`96a8c0cd`、`f0f8a26d`
- tags:
  - operation:旋转, rotate
  - operation:连锁传导, chain_reaction
  - object:竖条, vertical_bar
  - object:顶端标记, top_marker
  - relation:高度即打击距离, height_equals_reach
  - condition:标记色定倒向, marker_color_sets_direction

### docstring

```text
把绿色首倒条推倒，让竖条按各自顶端颜色指定的方向连锁倾倒。

输入结构
- 黑色背景，最底一行之上立着若干单列宽的灰色竖条，所有竖条底端都在最底行。
- 每根竖条顶端一格是标记色：红色表示这根条被撞倒时向右倒，蓝色表示向左倒。
- 恰有一根竖条顶端是绿色，它是首倒条，向右倒。
- 竖条间距保证任一时刻倒下的条身至多压到一根仍直立的条，且所有倒下的条身互不重叠。

规则
- 高度为 h 的竖条倒下后，变成一根从其底端格起沿倒向延伸、长度为 h 的水平灰条，原顶标色画在该横条最远端一格。
- 若倒下的横条覆盖了某根仍直立竖条的底端格，那根条随即倾倒，方向由它自己的顶标颜色决定（红右蓝左），继续传导。
- 未被任何横条压到的竖条保持直立不变。

关键洞察
- 竖条的高度就是它倒下后的打击距离；传导方向不由波的来向决定，而由被撞条自身的顶标颜色决定，链条可以反向折返，撞到先前被跳过的条。
```

## 2. 环深色表查询

- 参考题目: `bda2d7a6`、`c8b7cc0f`、`d2abd087`
- tags:
  - operation:计数, counting
  - operation:重涂色, recolor
  - object:同心环色表, concentric_ring_legend
  - object:空心框, hollow_frame
  - relation:嵌套深度作索引, nesting_depth_as_index
  - condition:框内计数定色, inside_count_selects_color
  - condition:越界循环, cyclic_wrap
  - condition:忽略干扰项, ignore_distractors

### docstring

```text
数出每个灰框内部的青色标记数，用同心环色表把灰框重涂成对应深度的环色。

输入结构
- 黑色背景。网格某处有一个同心矩形环对象：一格厚的纯色环逐层嵌套，各环颜色互不相同，它是全题唯一的多色对象。
- 其余前景是若干灰色空心矩形框；青色单像素散布在各框内部与框外，框外的青点是干扰项。

规则
- 对每个灰框，数严格位于框内部的青色像素个数 N。
- 把该灰框的全部像素重涂为色表中第 N 层的颜色：色表按同心环从外到内的顺序排列，N 超过环数时循环计数。
- 擦除所有青色像素；同心环对象原样保留。

关键洞察
- 同心环不是被变换的对象，而是一张按嵌套深度排序的查色表；框内计数是索引，框外同色青点必须排除，且索引越界时按环序循环。
```

## 3. 破损即图案

- 参考题目: `903d1b4a`、`1cf80156`
- tags:
  - operation:对称折叠, symmetry_folding
  - operation:裁剪, crop
  - object:破损格, damaged_cell
  - object:对称图案, symmetric_pattern
  - relation:双轴反射轨道, two_axis_orbit
  - condition:轨道恢复颜色, orbit_recovers_color

### docstring

```text
把破损格沿双轴折叠成一个从未整体出现过的小图案并恢复其颜色输出。

输入结构
- 整幅网格是一个多色图案，忽略绿色像素后同时满足左右反射与上下反射对称。
- 绿色像素是破损格；每个含绿格的反射轨道中，其余格恰好呈现一种非绿颜色。

规则
- 对每个绿色格，取它在双轴反射群下的轨道，读出轨道内可见的那种颜色作为它的真实颜色。
- 把所有绿色格的位置折叠到左上象限，即用其轨道在左上象限的代表位置表示。
- 输出这些折叠位置的紧致包围盒裁剪：折叠位置填各自恢复出的真实颜色，其余格填黑色。

关键洞察
- 这不是修复题：绿色破损本身才是要输出的对象，双轴对称只是恢复其颜色的工具，输出图案在输入中从未完整出现。
```

## 4. 射线收集打包

- 参考题目: `96a8c0cd`、`05a7bcf2`
- tags:
  - operation:路径绘制, path_drawing
  - operation:绕行, detour
  - operation:压缩打包, pack
  - object:变道条, lane_shifter_bar
  - object:彩色单点, colored_dot
  - relation:命中顺序, hit_order
  - condition:障碍色决定绕向, obstacle_color_detour
  - condition:压缩至远端边界, pack_to_far_edge

### docstring

```text
让红色射线在蓝绿变道条之间穿行，收走沿途彩点并按命中顺序打包到远端。

输入结构
- 黑色背景，边界上有一个红色起点像素。
- 场内有若干与射线前进方向垂直的一格厚蓝色或绿色短条，以及若干颜色互不相同的单格彩点。

规则
- 红迹从起点向网格内部直行；撞到蓝条从行进方向的左侧绕过，撞到绿条从右侧绕过，绕行后回到原前进方向。
- 直行撞到彩点时把它收走并从原位擦除，射线不偏转继续前进，直到抵达对侧边界。
- 被收走的彩点按命中顺序从对侧边界向回依次紧密排在射线最终所在的车道上，先收的最靠边，这些彩点覆盖所到格。
- 蓝绿条保留原位，射线经过的其余背景格涂红；未被命中的彩点原样不动。

关键洞察
- 蓝绿条不是障碍而是变道器：每次绕行都改变后续车道，从而决定哪些彩点会被命中；输出远端的颜色序列是整条路径历史的编码。
```

## 5. 补全后拉伸

  - object:残缺范例, damaged_exemplar
  - object:纯色目标矩形, solid_target_rect
  - relation:跨副本互补, cross_copy_complement
  - condition:内部行程伸缩, interior_run_resize

### docstring

```text
先把同色残缺范例并集补全，再把完整图案弹性拉伸进每个纯色目标矩形。

输入结构
- 黑色背景上有若干矩形对象，同属一种外框颜色。
- 其中两个以上是同尺寸的多色范例矩形，每个都被黑洞抠去了一部分，但它们记录的是同一幅图案的不同残缺副本，并集恰好完整。
- 其余是该外框色的纯色实心矩形目标，尺寸各异且不等于范例尺寸。

规则
- 把各残缺范例按相对位置取并集，得到完整范例图案，并在原位补全每个残缺范例。
- 对完整范例的行与列做行程编码：各边界行程保持原厚度，只有内部行程按目标尺寸伸缩。
- 用伸缩后的图案原位替换每个纯色目标矩形。

关键洞察
- 任何单个范例都不足以生成目标内容，跨副本并集补全是模板可用的前提；尺寸适配靠内部行程伸缩而非整体几何缩放。
```

## 6. 负空间套娃

- 参考题目: `44d8ac46`、`84551f4c`、`1b59e163`、`1cf80156`
- tags:
  - operation:嵌套装配, nesting_assembly
  - operation:旋转, rotate
  - operation:裁剪, crop
  - object:孔洞, hole
  - object:实心块, solid_block
  - relation:洞形即外形, hole_matches_outline
  - relation:链式连接, chain_linkage
  - condition:端点定链向, endpoints_fix_chain
  - condition:忽略干扰项, ignore_distractors

### docstring

```text
按洞形恰好容纳另一块外形的钥匙关系，把散落的块逐层嵌套成套娃，输出装配结果的紧致裁剪。

输入结构
- 黑色背景上散布若干互不同色的块。多数块内部包着一个形状不规则的黑洞。
- 恰有一块是无洞实心块且其外形经旋转后与某个洞吻合，它是最内层。
- 恰有一块的外形不与任何洞吻合且自身有洞，它是最外层。
- 另可能有一个实心干扰块，与任何洞都不吻合。
- 每个有洞块的洞形，经 0、90、180 或 270 度旋转后恰与另一块的整体外形一致。

规则
- 从最外层块开始，把外形与其洞形吻合的块按所需旋转放入洞中并保留各自颜色。
- 对新放入块的洞重复此过程，直到最内层实心块放入为止。
- 干扰块与所有块的原位置都不出现在输出中；输出为装配完成图形的紧致包围盒裁剪。

关键洞察
- 钥匙是负空间的接力：洞不是待填充的缺陷，而是恰好容纳另一块整体外形的槽位；链条两端由无匹配的有洞块为最外层、被匹配的无洞块为最内层确定，装配顺序即嵌套顺序，干扰块靠双向都无匹配排除。
```

## 7. 面积序坠落堆叠

- 参考题目: `54d82841`、`83eb0a57`、`d6e50e54`
- tags:
  - operation:滑动, slide
  - operation:排序, ordering
  - object:悬浮对象, floating_object
  - object:地标像素, ground_marker
  - relation:同色对应, same_color_match
  - relation:堆叠依赖次序, order_dependent_stacking
  - condition:面积降序坠落, descending_area_fall

### docstring

```text
让悬浮对象先对齐同色地标列，再按面积从大到小依次坠落堆叠。

输入结构
- 黑色背景，上方悬浮若干互不同色、宽度为奇数的纯色对象。
- 最底一行有若干单格地标，颜色与悬浮对象一一对应。
- 多个对象的目标落区在列上相互重叠，因此坠落次序会改变最终堆形。

规则
- 每个对象先水平平移，使其包围盒中心列对准同色地标所在列。
- 然后按面积从大到小逐个竖直下落：对象整体下滑，直到自身任一格落在最底行，或有格正好落在已落对象之上，形状保持不变。
- 输出为全部对象落定后的画面；被覆盖的地标消失，未被覆盖的地标保留。

关键洞察
- 下落次序既不是从左到右也不是输入摆放顺序，而是面积降序；由于落区相互重叠，猜错次序会得到不同的堆叠结果。
```

## 8. 隐藏矩阵对称修复

- 参考题目: `85b81ff1`、`903d1b4a`
- tags:
  - operation:对称补全, symmetry_completion
  - operation:矩阵抽取, matrix_extraction
  - object:嵌入矩阵, embedded_matrix
  - object:分隔纹理, separator_texture
  - object:占位标记, placeholder_marker
  - relation:抽象层对称, abstract_level_symmetry
  - condition:对称类型逐例判定, per_example_symmetry_type

### docstring

```text
在分隔纹理埋藏的隐藏矩阵里判定对称类型并修复绿色破损格。

输入结构
- 网格是一张固定点阵：可编辑格按固定的行距与列距规则分布，其余格是重复的分隔纹理。
- 可编辑格构成一个隐藏的方形彩色矩阵；忽略其中的绿色占位格后，该矩阵恰好满足某一种对称，如转置对称或 180 度旋转对称，具体是哪一种因示例而异。
- 可见网格在像素层面并不对称：分隔纹理破坏了任何直接的镜像关系。

规则
- 按点阵规则抽取隐藏矩阵。
- 用未破损格判定该矩阵满足的唯一对称类型。
- 把每个绿色格替换为其对称位置格的颜色，再写回原点阵位置，输出整幅修复后的网格。

关键洞察
- 对称不存在于可见像素层，只存在于抽取出的抽象矩阵中；先解码点阵、再在抽象层判定对称类型，是唯一入口。
```
