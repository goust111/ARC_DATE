## 1. 色环步进

- 参考题目: 2 (54d9e175 颜色配对映射)、9 (8abad3cf 像素数决定尺寸)、17 (e048c9ed 计数编码)
- tags:
  - operation:重涂色, recolor
  - operation:计数, counting
  - operation:擦除, clear
  - object:骨牌图例, domino_legend
  - object:前景对象, foreground_object
  - relation:色环步进, color_cycle_stepping
  - condition:像素数定步数, pixel_count_sets_steps

### docstring

```text
按图例色环步进重涂每个对象，步数等于该对象自身的像素数。

输入结构：
- 黑色背景。网格一角有一排竖直二格骨牌图例，每张骨牌上格色 X、
  下格色 Y，表示映射 X→Y；全部骨牌合起来构成一个封闭的有向色环。
- 场景区域散布若干单色 4 连通对象，颜色均出现在色环中，像素数各异。

规则：
- 读出图例定义的有向色环。
- 对每个场景对象统计其像素数 n，从对象颜色出发沿色环前进 n 步，
  得到目标色。
- 将对象整体重涂为目标色，形状与位置不变；图例从输出中删除。

关键洞察：
- 骨牌不是一次性的替换表，而是可迭代的循环置换；真正的键是对象
  自身的像素数，它决定沿环走几步。单像素对象恰好伪装成"直接查表"，
  多像素对象揭穿这一诱饵。
```

## 2. 门距染色

- 参考题目: 5 (320afe60 缺口)、15 (a5313dff 封闭区域)、11 (8a371977 内外之分)、17 (e048c9ed 固定编码)
- tags:
  - operation:洪泛填充, flood_fill
  - operation:计数, counting
  - operation:重涂色, recolor
  - object:墙壁线段, wall_segment
  - object:边框缺口, border_notch
  - object:封闭区域, enclosed_region
  - relation:门链深度, door_chain_depth
  - condition:深度映射颜色, depth_maps_color

### docstring

```text
按从外部穿门进入所需的最少门数给每个房间染色。

输入结构：
- 黑色背景，灰色墙线构成多房间平面图。
- 墙上留 1 像素宽的缺口作为门；部分房间完全密闭无门。

规则：
- 与画布边界连通的背景为外部，记距离 0；背景像素只能经由门穿墙。
- 每个房间的距离 = 从外部到达它所需穿过的最少门数。
- 距离 1 的房间染蓝、距离 2 染红、距离 3 染绿、距离 4 染黄；
  无门可达的房间保持黑色；墙保持灰色不变。

关键洞察：
- 染色与房间的几何位置无关——紧贴画布边界的房间也可能距离很大；
  唯一的度量是门链上的拓扑深度，而不是"内外"或"远近"的直观印象。
```

## 3. 残迹拼合

- 参考题目: 3 (3a25b0d8 旋转匹配对齐)、18 (3391f8c0 双色模板)、19 (9b2a60aa 模板精灵)
- tags:
  - operation:旋转匹配, rotation_matching
  - operation:并集重建, union_reconstruction
  - operation:裁剪, cropping
  - object:精灵残迹, sprite_remnant
  - relation:残迹互补, complementary_remnants
  - relation:源与目标对齐, source_target_alignment
  - condition:重叠一致定姿态, overlap_consistency_fixes_pose

### docstring

```text
把同一精灵的两块残迹在唯一相容的旋转/翻转下对齐，输出按来源分色的完整精灵。

输入结构：
- 黑色背景上有两团颜色不同的 8 连通残迹。
- 它们是同一个完整精灵在不同姿态下各自缺失一部分像素的结果。
- 恰有一种旋转/翻转变换能使两者对齐后所有重叠像素完全一致。

规则：
- 像素较多的残迹保持原姿态，将另一残迹经旋转/翻转后与之对齐。
- 取两残迹掩码的并集得到完整精灵，紧致裁剪输出。
- 仅第一块残迹提供的像素用其颜色，仅第二块提供的用其颜色，
  两块共有的像素涂灰。

关键洞察：
- 完整精灵从未在画面上出现，它只能由两块残迹在正确姿态下互补拼出；
  重叠区既是校验对齐正确性的指纹，也在输出中以灰色显式标出。
```

## 4. 套匣链

- 参考题目: 4 (eb5a1d5d 嵌套方环)、14 (a25697e4 空腔尺寸匹配)、7 (0a1d4ef5 筛除干扰项)
- tags:
  - operation:嵌套, dock
  - operation:筛选, filter
  - object:方环, square_ring
  - object:空腔, cavity
  - relation:啮合链, exact_fit_chain
  - condition:外径等孔径, outer_equals_hole
  - condition:忽略干扰项, ignore_distractors

### docstring

```text
按"外径恰等于孔径"的啮合链把方框层层套入，丢弃套不进的干扰框。

输入结构：
- 黑色背景上散放若干单色正方形空心框，颜色互异。
- 框的壁厚不一（壁厚 ≥ 1），孔径 = 外径 − 2×壁厚。
- 恰存在一条装配链：链头框的孔径等于下一框的外径，逐级到底；
  另有干扰框，其外径不等于任何框的孔径、其孔径也不等于任何框的外径。

规则：
- 按"某框孔径 = 另一框外径"的关系串出唯一的装配链，
  不在链上的框全部舍弃。
- 输出为链头外径大小的正方形画布，链上各框同心放置，
  内层框恰好贴边填满外层框的孔。
- 最内框的孔保持黑色。

关键洞察：
- 装配顺序不是按大小排序——尺寸居中的干扰框谁的孔都进不去；
  唯一合法结构由外径与孔径的精确啮合关系决定，而非尺寸序。
```

## 5. 补模印章

- 参考题目: 6 (c803e39c 克罗内克积)、3 (3a25b0d8 孔洞决定角色)、15 (a5313dff 封闭判定)
- tags:
  - operation:印章覆盖, stamp_overlay
  - operation:补集, complement
  - object:二值掩码, binary_mask
  - object:孔洞, hole
  - relation:克罗内克积, kronecker_product
  - condition:孔洞定角色, hole_determines_role

### docstring

```text
以带孔掩码为印章、无孔掩码为版图做块展开，版图背景格盖印章的补模。

输入结构：
- 黑色背景上有两个互相分离的单色二值掩码，颜色不同，尺寸不必相同。
- 恰有一个掩码含被自身像素完全包围的封闭孔洞，另一个没有。

规则：
- 含孔者为印章 S（颜色 s），无孔者为版图 L（颜色 l）。
- 输出尺寸 = 版图行列数 × 印章行列数。
- 版图的每个前景格放一份 S：S 的前景像素涂 s 色、背景像素涂黑。
- 版图 bbox 内的每个背景格放一份 S 的补模：S 的前景位置涂黑、
  S 的背景位置涂 l 色。

关键洞察：
- 谁当印章由拓扑性质（有无封闭孔）而非大小决定；版图的背景不是
  留白，而是以互补底纹参与盖印——每个输出块内 s 色与 l 色像素
  的位置恰好互补。
```

## 6. 颜色寻址指令

- 参考题目: 17 (e048c9ed 条形段)、13 (3cd86f4f 行偏移)、6 (c803e39c 面板分隔)、2 (54d9e175 颜色作键)
- tags:
  - operation:滑动, slide
  - operation:裁剪, cropping
  - object:条形段, bar_segment
  - object:色块面板, color_panel
  - relation:颜色寻址指令, color_addressed_instruction
  - condition:长度定位移, length_sets_shift
  - condition:循环回卷, wraparound

### docstring

```text
每根色条是一条按颜色寻址的指令——凡含有该颜色的图案行循环右移条长格。

输入结构：
- 一条贯通的灰色分隔列把网格分成左窄右宽两个面板。
- 左面板散放若干水平实心条，颜色互不相同、长度不一、竖直位置任意。
- 右面板为彩色图案，每行至多含一种指令色（左侧条色之一）的像素。

规则：
- 对左面板每根颜色 c、长度 n 的条：右面板中所有含 c 色像素的行
  整体向右循环平移 n 格，移出右端的像素从左端回卷。
- 不含任何指令色的行保持不动。
- 输出仅为处理后的右面板，分隔列与左面板裁去。

关键洞察：
- 条与行的对应不看竖直位置而看内容——条的颜色出现在哪些行，
  指令就作用于哪些行；条在左面板中的竖直摆放位置是诱饵。
```
