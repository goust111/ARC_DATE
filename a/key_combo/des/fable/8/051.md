## 1. 稀疏采样的距离场重建

- 参考题目: 2 (ff2825db)、10 (aaef0977)
- tags:
  - operation:反演定位, inverse_locate
  - operation:填充, fill
  - object:调色板行, palette_row
  - object:标记像素, marker_pixel
  - relation:距离映射, distance_mapping
  - condition:曼哈顿距离, manhattan_distance
  - condition:循环色板, cyclic_palette
  - condition:环心未画出, hidden_center

### docstring

```text
由散点颜色反推从未画出的环心，再按首行色板补全整张曼哈顿同心环场。

输入结构
- 首行是色板行：自最左格起连续排列 k 种互不相同的非黑颜色，其余格为黑。
- 首行以下是黑色棋盘区，散布少量单像素彩点，颜色都出自色板行。

规则
- 棋盘区存在唯一一个黑色格作为环心（输入中从未画出），使每个彩点的颜色
  恰为色板中第 ((d-1) mod k)+1 种颜色，其中 d 是该点到环心的曼哈顿距离。
- 输出保持色板行不变；棋盘区每一格按它到环心的曼哈顿距离用同一编码规则
  上色；环心格保持黑色。

关键洞察
- 彩点不是要保留的对象，而是一个从未画出的同心环场的稀疏采样；必须先以
  色板为码表解出隐藏环心，整场的颜色规律才能落地。
```

## 2. 锚点钉死的碎片装配

- 参考题目: 8 (b7cb93ac)、12 (52fd389e)、2 (ff2825db)
- tags:
  - operation:拼合填充, packing
  - operation:旋转, rotation
  - operation:镜像, mirror
  - object:多连块碎片, polyomino_fragment
  - object:空心矩形框, rect_frame
  - object:控制像素, control_pixel
  - object:锚点像素, anchor_pixel
  - relation:同色锚定, same_color_anchor
  - condition:无重叠恰好填满, exact_fill

### docstring

```text
把外部碎片经旋转镜像装入空心框，使每个碎片的内嵌控制像素压在框内同色锚点上并恰好填满内部。

输入结构
- 黑底上有一个灰色单层空心矩形框，内部为黑，其中散布若干颜色互不相同的
  单像素锚点。
- 框外散布同样数量的单色四连通碎片，每个碎片体内嵌恰好一个异色控制像素，
  其颜色与某个锚点一一对应。
- 所有碎片的面积之和等于框内部面积。

规则
- 每个碎片可任意旋转与镜像后放入框内部，但其控制像素必须与同色锚点重合。
- 全部碎片互不重叠且恰好铺满框内部；满足这两条的装配方式唯一。
- 输出中框保持原样，内部显示装配结果（碎片体色与控制像素色均保留，控制
  像素覆盖锚点），框外原碎片位置清为背景。

关键洞察
- 锚点不是噪声而是装配坐标：控制像素同时指认碎片归属并钉死其中一格的
  位置，剩余姿态再由"互不重叠且恰好填满"唯一锁定。
```

## 3. 凸耳入口与容量溢出

- 参考题目: 1 (dc2e9a9d)、3 (9968a131)、16 (5545f144)
- tags:
  - operation:滑动, slide
  - operation:堆叠, stack
  - object:凸耳, tab
  - object:空心矩形箱, hollow_box
  - object:水平短条, horizontal_bar
  - relation:入口侧吞入, intake_side
  - relation:异侧贴壁, blocked_side
  - condition:凸耳定入口, tab_sets_entrance
  - condition:容量溢出分流, capacity_overflow
  - condition:距离次序, distance_order

### docstring

```text
凸耳一侧的短条按序被吞入箱腔靠内壁排放，装不下的连同异侧短条分别在箱外排队。

输入结构
- 黑底网格被整行空行分成若干水平条带。
- 每个条带含一个绿色空心矩形箱，内腔是一行黑色空位；箱的左壁或右壁中部
  开有一个单像素凸耳；箱两侧散布若干长度不一的水平实心短条。

规则
- 所有短条都向箱子水平滑动。
- 凸耳一侧的短条按离箱由近到远的次序依次经入口进入内腔，靠对侧内壁紧密
  排放；当下一个短条的长度超过内腔剩余空位时，它连同其后所有同侧短条改为
  贴在箱外入口一侧依次排队。
- 非凸耳一侧的短条被箱壁挡住，贴外壁依次排队。
- 箱与凸耳保持不动；平移腾出的格子恢复为背景。不同条带的凸耳方向不同。

关键洞察
- 单像素凸耳不是装饰而是入口，决定哪侧短条能被吞入；内腔容量引发溢出
  分流，同一侧的短条因排队次序不同而命运不同。
```

## 4. 叠印抵消的残影

- 参考题目: 13 (fea12743)、17 (19bb5feb)
- tags:
  - operation:掩码运算, mask_algebra
  - operation:压缩输出, compact_output
  - object:精灵体, sprite
  - relation:像素对称差, pixel_xor
  - relation:像素交集, pixel_intersection
  - condition:叠印抵消等三, two_xor_eq_third
  - condition:并集诱饵组, union_decoy_triple
  - condition:答案未画出, answer_not_drawn

### docstring

```text
找出叠印后重叠处相互抵消恰得第三个精灵的那对精灵，输出被抵消而从未现身的公共部分。

输入结构
- 黑底红前景，六个 4x4 精灵区排成 2 行 3 列，以空行空列分隔，每区一个
  非空掩码。
- 恰有一组三元组 (A,B,C) 满足 C 等于 A 与 B 的逐像素对称差：恰属 A、B
  之一的像素在 C 中存在，同属二者的像素在 C 中消失；且 A∩B 非空、
  A 与 B 各有独有像素。
- 另有一组满足简单并集关系 D∪E=F 的诱饵三元组混在其中。

规则
- 找到唯一满足对称差关系的三元组 (A,B,C)。
- 输出一个 4x4 网格：A 与 B 的交集像素涂绿，其余为黑。

关键洞察
- C 是 A、B 叠印后重叠处相互抵消的残影；答案掩码（交集）在整个画面任何
  位置都从未出现，它恰等于 (A∪B) 与 C 的差。按更显眼的并集关系配对会
  落入诱饵三元组，但那无法解释全部示例对。
```

## 5. 奇偶残迹的选择性重建

- 参考题目: 15 (d492a647)、18 (52df9849)
- tags:
  - operation:补全, complete
  - operation:消除, erase
  - object:点阵残迹, dotted_remnant
  - object:标记像素, marker_pixel
  - object:奇偶格点, parity_lattice
  - relation:坐标奇偶匹配, coord_parity_match
  - condition:密钥选择重建, key_selects_rebuild

### docstring

```text
以灰色标记的坐标奇偶为密钥：残迹落在同一奇偶格上的斑块补全为实心矩形，其余残迹整体擦除。

输入结构
- 黑底上有若干彩色点阵斑块：每个斑块是一个实心矩形被采样后的残迹，只保
  留了行奇偶与列奇偶等于某一固定组合的像素，点距为 2；不同斑块使用的
  奇偶组合不同。
- 另有一个孤立的灰色标记像素，不属于任何斑块。

规则
- 标记像素自身的 (行奇偶, 列奇偶) 组合是选中格。
- 某斑块的所有残点都落在选中格上时，填满该斑块残点的包围盒，恢复为该
  颜色的实心矩形。
- 残点落在其他奇偶组合上的斑块，其残点全部擦成黑色。
- 灰色标记像素保留。

关键洞察
- 灰点不是位置参照而是奇偶密钥；外观相同的点阵残迹，命运由它所骑的格子
  与密钥是否一致决定，补全与擦除各行其道。
```

## 6. 轨迹成墙的序贯觅食

- 参考题目: 16 (5545f144)、6 (ecdecbb3)
- tags:
  - operation:逐步移动, stepwise_move
  - operation:消除, consume
  - operation:轨迹描画, trail_draw
  - object:方块精灵, block_sprite
  - object:标记像素, marker_pixel
  - object:墙段, wall_segment
  - relation:视线可达, line_of_sight
  - condition:最近可见优先, nearest_visible_first
  - condition:轨迹即障碍, trail_becomes_wall
  - condition:残留封锁目标, sealed_targets_remain

### docstring

```text
精灵逐个吃掉视线内最近的标记，但走过的轨迹变成墙，反过来封死后续视线，封锁住的标记永远留下。

输入结构
- 黑底网格上有一个红色 2x2 精灵、若干青色单像素标记，以及少量灰色墙段。

规则
- 每一步，精灵沿四个正方向看，取同行或同列、中间无任何障碍（灰墙、已有
  轨迹、其他标记均阻挡视线）的可见标记中最近的一个（每步这样的标记唯一），
  整体平移过去吃掉它。
- 精灵走过的格子留下灰色轨迹；轨迹从此与原有灰墙一样阻挡视线与通行。
- 重复直到四个方向都看不到任何标记为止。
- 输出：最终精灵位置、全部灰色轨迹与原有灰墙，以及被封死而未被吃掉的
  剩余青色标记原样保留。

关键洞察
- 轨迹是活的障碍：先走的路会封死后面的视线，消耗顺序决定哪些标记被吃、
  哪些残留；残留标记不是噪声，而是被自己早先的轨迹隔离的目标。
```
