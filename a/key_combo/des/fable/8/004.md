## 1. 接力变色的对半填充

- 参考题目: `d968ffd4`, `fd02da9e`, `31adaf00`
- tags:
  - operation:射线延伸, ray_extend
  - operation:重涂色, recolor
  - object:矩形, rectangle
  - object:中继像素, relay_pixel
  - relation:间隙对半分, gap_bisect
  - relation:颜色接力, color_relay
  - condition:奇数间隙留中线, odd_gap_midline
  - condition:中继点不截停, relay_no_blocking

### docstring

```text
一句话总述
两个对齐的实心矩形各自向对方填充恰好一半间隙；行内途经的彩色中继像素不截停填充，而是把该行其后更靠中心的填充色换成中继色；奇数间隙的中心列保留背景。

输入结构
- 背景网格中有两个同尺寸、跨度对齐的单色实心矩形，分居间隙两侧，颜色互不相同；两矩形并排或上下相对。
- 间隙内散布少量单像素彩色中继点，其颜色不同于两矩形色与背景色；部分示例没有中继点。
- 中继点不落在间隙的中心线上。

规则
- 逐行（列）处理间隙：该行属于左（上）半的格子归左（上）矩形填充，属于右（下）半的格子归右（下）矩形填充；间隙长度为奇数时，中心列（行）保留背景。
- 每一侧的填充从矩形贴边处向中心推进，初始使用该矩形的颜色；推进途中每遇到一个中继像素，该像素连同其后更靠中心的格子改用该中继色，直至遇到下一个中继像素再次换色。
- 每行（列）独立进行，互不影响；矩形本体保持不变。

关键洞察
- 中继像素看似障碍，实则不截停任何填充——两侧始终精确各占一半；它们是接力棒，把颜色沿朝向中心的方向逐段替换。第一直觉"撞上即停"会在含中继点的示例上系统性失败，而换色方向是朝中心而非朝外，也必须从示例反推。
```

## 2. 方向密码归巢

- 参考题目: `4e45f183`, `228f6490`, `9a4bb226`
- tags:
  - operation:填充, fill
  - operation:擦除, erase
  - object:孔洞, hole
  - object:标记像素, marker_pixel
  - object:碎片, fragment
  - relation:质心偏移定位, centroid_offset_positioning
  - condition:方位映射孔洞, direction_maps_to_hole
  - condition:形状匹配为诱饵, shape_match_decoy

### docstring

```text
一句话总述
每个彩色碎片内部的标记像素指向八个方位之一，把灰色大矩形中对应方位的黑色孔洞填成碎片主色，碎片本身从输出中擦除。

输入结构
- 网格中央有一个灰色实心大矩形，内部挖有若干黑色孔洞；每个孔洞整体位于矩形中心的某个方位（上、下、左、右或四个斜角），不同孔洞的方位互不相同。
- 矩形外散布若干碎片，每个碎片由一种主色像素和恰好一个异色标记像素构成，标记像素不在碎片包围盒中心。
- 部分碎片的形状与某个孔洞的形状完全相同，但那不一定是它的目标孔洞。

规则
- 对每个碎片，取标记像素相对碎片包围盒中心的行列偏移符号，得到八向之一。
- 将灰矩形中位于中心同方位的孔洞的全部黑色像素填成该碎片的主色。
- 输出中所有碎片区域恢复为背景；未被任何碎片指向的孔洞保持黑色；灰矩形保持不变。

关键洞察
- 形状吻合是精心布置的陷阱：碎片不是拼图块而是寻址指令，孔洞按"方位对方位"接收颜色；必须发现碎片内部标记像素这一隐蔽入口，才能得到正确配对。
```

## 3. 密度定序的四层叠加

- 参考题目: `a68b268e`, `dce56571`, `9a4bb226`
- tags:
  - operation:透明叠加, transparent_overlay
  - operation:计数, counting
  - operation:裁剪, crop
  - object:象限区, quadrant
  - object:分隔十字, separator_cross
  - relation:层级优先, layer_priority
  - condition:稀疏者置顶, sparsest_on_top

### docstring

```text
一句话总述
分隔十字切出的四个象限按前景像素数从少到多决定图层高低，逐像素叠加成一个象限大小的输出。

输入结构
- 一条实心分隔行与一条实心分隔列（同一种非背景色）把网格切成四个等尺寸象限。
- 每个象限是背景加单一前景色的掩码，四种前景色互不相同，四个掩码的前景像素数两两不同。

规则
- 统计每个象限的前景像素数，像素数越少的掩码层级越高。
- 对每个输出位置，自最高层向下查看四个象限的对应像素，输出遇到的第一个非背景色；若四层全为背景则输出背景。
- 输出尺寸等于单个象限，分隔十字不出现在输出中。

关键洞察
- 训练示例故意让某一例的层序恰与"左上到右下"的位置序一致以设置诱饵；真正的层栈由稀疏度决定——最稀疏的掩码浮在最上面，重叠冲突处必须用计数而非象限位置来裁决。
```

## 4. 隐藏十字的连线

- 参考题目: `1818057f`, `253bf280`, `36d67576`
- tags:
  - operation:模式检测, pattern_detection
  - operation:连线, draw_line
  - object:十字图案, cross_pattern
  - object:前景团块, foreground_blob
  - relation:行列对齐, row_col_align
  - condition:邻域全匹配, all_neighbors_match
  - condition:同色端点才连, same_color_endpoints_only

### docstring

```text
一句话总述
在各单色团块内部检测隐藏的十字中心，把同行或同列且所属团块同色的两个十字中心之间的背景涂成该颜色。

输入结构
- 背景上分布若干互不接触的单色团块，颜色可以重复。
- 部分团块内部存在十字中心：该像素的四个正交邻居均属于同一团块。
- 团块还带有凸起、缺口等与十字无关的形状细节，作为干扰。

规则
- 找出所有团块中的全部十字中心像素。
- 对每一对处于同一行或同一列、且所属团块颜色相同的十字中心，把两中心之间严格中间的背景像素涂成该颜色；途中属于任何团块的像素保持不变。
- 颜色不同的对齐十字中心对不连线；所有团块原样保留。

关键洞察
- 连线端点从未被单独画出：它们是埋在不规则团块内部、只有做"四邻全同色"局部检测才能显形的隐式锚点；对齐但异色的中心对是第二重筛子，防止把任务误当成普通的对齐端点连线。
```

## 5. 自带位移的印章

- 参考题目: `d304284e`, `4e45f183`, `d511f180`
- tags:
  - operation:印章覆盖, stamp
  - operation:平移, translate
  - object:精灵体, sprite
  - object:锚点像素, anchor_pixel
  - relation:自指位移, self_encoding_offset
  - relation:周期排布, periodic_layout
  - condition:奇数号副本双色互换, odd_copies_swap_colors

### docstring

```text
一句话总述
精灵内部唯一的标记像素相对精灵包围盒中心的偏移向量就是平移步长，沿该向量反复复制模板，奇数号副本交换精灵色与标记色。

输入结构
- 背景网格中有一个 8 连通的单色精灵，其包围盒行、列边长均为奇数，内部嵌有恰好一个异色标记像素，且标记不在包围盒中心。
- 网格其余部分为空。

规则
- 位移向量等于标记像素坐标减去精灵包围盒中心坐标。
- 从原模板出发，沿位移向量依次放置副本，直到下一个副本有任何部分越出网格为止（越界的那个副本不放置）。
- 第 1、3、5……个副本把精灵色与标记色互换后绘制，第 2、4……个副本与原模板颜色相同；原模板保持不变。

关键洞察
- 画面上没有任何显式的方向或间距提示——精灵体内的标记像素既是被重涂的对象，又是自身平移群的生成元；双色交替进一步掩盖周期，让人误以为存在两种不同的模板。
```

## 6. 最长旅程的独迹

- 参考题目: `9bbf930d`, `aa300dc3`, `9a4bb226`
- tags:
  - operation:路径追踪, path_trace
  - operation:筛选, filter
  - operation:擦除, erase
  - object:粒子, particle
  - object:走廊, corridor
  - relation:同色夹道, same_color_flanking
  - condition:碰撞转向, collision_turn
  - condition:最长者选中, longest_selected

### docstring

```text
一句话总述
按同色夹道的走廊规则推演每个粒子的行进轨迹，只保留轨迹最长的那个粒子的完整路径，其余粒子连同起点一起擦除。

输入结构
- 网格由若干条平行彩色条构成走廊系统，彩条之间的背景带是走廊。
- 网格边缘有多个同色粒子像素，各自位于某条走廊的入口处。

规则
- 每个粒子沿所在走廊直行；前方被彩色格挡住时，转入与之垂直、且两侧被同色彩条夹住的背景走廊继续行进；无合法转向或到达网格边缘即停止。
- 统计每个粒子经过的格子数；输入保证恰有一个粒子的轨迹最长。
- 输出中只把最长轨迹的全部经过格涂成粒子色，其余粒子的起点与路径全部恢复为背景；彩条原样保留。

关键洞察
- 参与"最长者当选"比较的对象在输入中并不存在——必须先按碰撞转向规则把每条虚拟轨迹推演完毕，筛选才有对象；选择作用于推演出的路径而非任何可见线段。
```

## 7. 角落辖区里的方形烙印

- 参考题目: `31adaf00`, `fd02da9e`, `8cb8642d`
- tags:
  - operation:区域提取, region_extract
  - operation:贪心选择, greedy_selection
  - operation:连线, draw_lines
  - object:空白正方形区域, blank_square_region
  - object:障碍像素, obstacle_pixel
  - object:角落标记, corner_marker
  - relation:最近角落辖区, nearest_corner_jurisdiction
  - condition:非重叠约束, non_overlapping_constraint
  - condition:从大到小优先, largest_first_priority
  - condition:标记色传递, marker_color_pass

### docstring

```text
一句话总述
在灰色障碍围出的黑色空地中按从大到小、互不重叠的原则找出全部边长至少为 2 的正方形，在每个正方形内用离它最近的角落标记的颜色画对角 X。

输入结构
- 黑色背景上散布灰色障碍像素。
- 网格四角中的若干角落各有一个单像素彩色标记，颜色互不相同。
- 黑色区域中隐含若干边长不小于 2 的极大全黑正方形，以及不构成正方形的走廊与错位凸出。

规则
- 枚举所有边长不小于 2 的全黑正方形候选，按边长从大到小处理；与已入选正方形重叠的候选作废，幸存的同尺寸候选彼此不相交。
- 每个入选正方形按其中心到各带标记角落的曼哈顿距离，找到唯一最近的角落；在该正方形内部画两条对角线，涂成该角落标记的颜色。
- 灰色障碍、角落标记与未入选的黑格保持不变。

关键洞察
- 空间上要用"大正方形先占位"的贪心排除走廊与错位凸出；颜色上正方形自身不携带任何信息，必须到最远处的角落寻址取色——检索层与寻址层只在最终着色处咬合，两条线索缺一不可。
```
