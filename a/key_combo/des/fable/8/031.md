## 1. 边影成形

- tags:
  - operation:填充, fill
  - operation:外推, extrapolate
  - object:投影行程, projection_run
  - object:矩形, rectangle
  - relation:双投影配对, dual_projection_pairing
  - condition:未配对投影惰性, unpaired_run_inert
  - condition:双重覆盖湮灭, double_cover_annihilate
- 参考题目题号: 9772c176（边缘行程/外推）、fe45cba4（矩形补全）、5dbc8537（尺寸/区间匹配）、1b2d62fb（逐格逻辑合并）

### docstring

```text
把顶边与左边的同色投影行程配对重建矩形，但被两个矩形同时覆盖的格子相互湮灭为背景。

输入结构
- 黑色背景网格，内部完全空白。
- 顶边行含若干条互不相邻的彩色水平行程，左边列含若干条彩色竖直行程，
  行程均不占据角格。
- 部分颜色在顶边和左边各恰有一条行程；其余颜色只在其中一条边出现。
- 由配对行程确定的矩形两两之间存在交叠，且任何格子至多被两个矩形覆盖。

规则
- 对每个在顶边与左边都出现的颜色，以左边行程的行区间与顶边行程的
  列区间之交确定一个矩形区域。
- 恰被一个矩形覆盖的格子涂该矩形的颜色；被两个矩形同时覆盖的格子
  保持背景色。
- 只在一条边出现的行程不产生任何图形。
- 边框行程在输出中原样保留。

关键洞察
- 边上的彩色行程不是装饰或射线起点，而是从未画出的矩形在两条边上的
  投影；且矩形从不以完整实心的形态出现——重叠区互相抵消，画面上只有
  它们的"异或残迹"，必须先反推出完整矩形再做湮灭。
```

## 2. 掩模点阵开关

- tags:
  - operation:逻辑运算, logical_op
  - operation:镜像, mirror
  - operation:旋转, rotate
  - object:二值掩模, binary_mask
  - object:格子瓦片, lattice_tile
  - object:分隔条, separator_bar
  - relation:跨尺度对应, cross_scale_correspond
  - condition:逻辑组合选动作, logic_combo_selects_action
- 参考题目题号: 1b2d62fb（双掩模/分隔条/逐格逻辑）、a096bf4d（格子瓦片点阵）、f25ffba3（镜像）、5bd6f4ac（网格分块）

### docstring

```text
两块小掩模的逐格逻辑关系在瓦片点阵上选址：双亮的瓦片旋转 180 度，恰一亮的瓦片左右镜像。

输入结构
- 上方是由分隔线划分的 3x3 瓦片点阵，每个瓦片内部是一个既非左右对称
  也非中心对称的小图案。
- 下方是两块等尺寸的栗色/黑色 3x3 掩模，中间隔一条蓝色竖条。
- 掩模的行列数与瓦片点阵的行列数一致。

规则
- 逐格比较两块掩模：两块都为栗色的位置，对应瓦片内部整体旋转 180 度；
  恰有一块为栗色的位置，对应瓦片内部整体左右镜像；两块都为黑的位置，
  对应瓦片保持不变。
- 掩模格 (i,j) 对应点阵第 i 行第 j 列的瓦片。
- 输出仅为变换后的瓦片点阵，掩模与分隔条整体删除。

关键洞察
- 下方的小图不是又一块内容而是一张指令表；它作用于瓦片尺度而非像素
  尺度，且指令不是单比特开关——两块掩模的三种逻辑组合分别编码三种
  不同的几何动作，必须同时破译寻址与动作两层映射。
```

## 3. 重排画层

- tags:

  - operation:叠加, overlay
  - operation:补全, complete
  - operation:擦除, erase
  - object:十字标记, plus_marker
  - object:矩形, rectangle
  - relation:中心色配票, center_color_vote
  - condition:票数定层序, vote_count_z_order
  - condition:遮挡补全, amodal_completion
  - condition:忽略干扰项, ignore_distractors
- 参考题目题号: 642d658d（十字标记/计数/忽略干扰）、9385bd28（处理顺序/覆盖保护）、7e0986d6（矩形修复）、337b420f（叠放与忽略干扰）

### docstring

```text
数各矩形颜色获得的十字"选票"，按票数重新叠放所有矩形，并把被遮挡的残缺矩形先补全成整块。

输入结构
- 黑色背景上有若干互相重叠的异色实心矩形，输入中的遮挡关系使部分
  矩形残缺，但每个矩形的完整外延均可由可见部分唯一确定。
- 网格空白处散布十字标记：一个中心像素加四个同色臂，中心色与臂色
  各自独立取色。
- 中心色与某个矩形同色的完整十字是该矩形的选票；臂色与某矩形同色
  而中心色不同的十字，以及臂不全的残缺十字，都是假票。
- 各矩形的真实票数两两不同。

规则
- 对每个矩形，统计中心色与其同色的完整十字个数作为票数。
- 输出中把所有矩形按票数从少到多依次绘制为完整实心矩形，票多者
  后画、居于上层；每个矩形的范围取其由可见部分推断出的完整外延。
- 删除所有十字与残缺十字，背景保持黑色。

关键洞察
- 输入里看到的遮挡顺序是诱饵，真正的叠放次序写在画面角落的选票里，
  而计票的钥匙是最不显眼的中心像素而非醒目的臂色；重排时还必须先在
  脑中把每个被压住的矩形补全成整块，再按新次序发牌。
```

## 4. 括号收割

- tags:
  - operation:裁剪, crop
  - operation:堆叠, stacking
  - operation:镜像, mirror
  - object:控制像素对, control_pixel_pair
  - object:行段, row_segment
  - object:列段, column_segment

  - condition:标记顺序决定翻转, marker_order_flip
  - condition:行列混采, row_col_mixed_harvest
  - condition:忽略干扰项, ignore_distractors
- 参考题目题号: 505fff84（控制像素对/括号提取/堆叠）、f25ffba3（翻转）、d406998b（序列读序）

### docstring

```text
提取蓝-青标记对夹住的行段与列段并堆叠成输出，标记顺序颠倒的段先整体反转再放入。

输入结构
- 背景网格上散布内容像素，另有蓝色与青色控制像素。
- 有的行含恰好一对同行的蓝、青标记，有的列含恰好一对同列的蓝、青
  标记；所有标记对之间严格夹住的格数相同。
- 另有少量落单的蓝色或青色像素，不成对，属于干扰。

规则
- 找到所有成对标记：同一行内恰一蓝一青，或同一列内恰一蓝一青。
- 每对提取两标记之间（不含标记）的格子作为一条输出行；列段旋转为行。
- 若蓝在前（行内蓝在左、列内蓝在上）则保持原序；若青在前则该段整体
  反转后写入。
- 输出行按各对蓝色标记像素的阅读顺序（自上而下、同行自左而右）排列。
- 落单标记与未被夹住的内容全部丢弃。

关键洞察
- 括号对不仅圈定收割范围，还用自身的先后顺序编码"是否反转"；行括号
  与列括号服从同一套读法，落单标记是诱饵。
```

## 5. 折光信标

- tags:

  - object:缺口方块, notched_square
  - object:障碍像素, blocker_pixel

  - condition:出界停止, stop_at_edge
- 参考题目题号: e87109e9（发射源/障碍转向）、6bcdb01e（碰撞转弯/停止条件）、d406998b（交替奇偶）、f35d900a（奇偶编码）

### docstring

```text
光束从方块缺口射出，逢障碍按"顺、逆、顺、逆"交替直角转向，直到出界。

输入结构
- 背景网格上有一个 3x3 实心方块，其某条边的中点格缺失（露出背景），
  构成唯一缺口。
- 网格中散布若干单像素障碍点，颜色不同于方块。
- 障碍的布置保证光束每次转向后至少能前进一格。

规则
- 光束自方块沿缺口所指方向射出，逐格把途经的背景格涂成方块颜色。
- 当前进方向的下一格是障碍时不踏入：第 1 次碰撞顺时针转 90 度，
  第 2 次碰撞逆时针转 90 度，之后按碰撞次数的奇偶继续交替。
- 障碍像素保持原样；光束到达网格边缘出界即停止。
- 方块与缺口在输出中原样保留。

关键洞察
- 没有任何图例说明转向方向：转向规则藏在碰撞次数的奇偶里，是一条
  状态化规则，必须跨示例比对同一条光束前后两次转向才能读出"交替"。
```

## 6. 缺口认亲

- tags:
  - operation:补全, complete
  - operation:擦除, erase
  - object:空腔, cavity
  - object:碎片, fragment
  - relation:互补拼合, complement_fit
  - condition:双片联合拼腔, two_piece_joint_fill
  - condition:同面积诱饵, equal_area_decoy
  - condition:忽略干扰项, ignore_distractors
- 参考题目题号: fe45cba4（互补拼合/擦除）、5dbc8537（唯一槽位配对）、337b420f（忽略干扰项）、7e0986d6（矩形修复）

### docstring

```text
大矩形的空腔需要恰好两块碎片拼合才能严丝合缝地填满，找出这一对，补腔并删除它们。

输入结构
- 背景网格上有一个某颜色的大实心矩形，其内部或边缘缺一块不规则的
  背景色空腔。
- 网格其余位置散布若干小碎片，颜色各异且均与矩形颜色不同。
- 恰有一对碎片可经平移（不旋转不翻转）拼合成与空腔完全一致的形状
  且互不重叠。
- 另有单块面积恰等于空腔面积的诱饵碎片（形状不合），以及两块面积
  之和等于空腔面积但无法拼合的诱饵组合。

规则
- 将空腔全部涂成矩形的颜色，使矩形恢复为实心。
- 删除能两两拼合出空腔形状的那一对碎片，原位清为背景。
- 其余碎片全部原样保留。

关键洞察
- 单块认亲必然失败——面积相等的单块诱饵会把人引向逐一试拼的死路；
  钥匙是一对碎片的联合负空间，面积之和相等也不保证可拼合，必须真正
  完成二片拼图；补上的颜色取自宿主矩形而非碎片本身。
```

## 7. 扶正斜塔

- tags:
  - operation:剪切变换, shear_transform
  - operation:平移, shift
  - object:倾斜对象, leaning_object
  - object:锚定像素, anchor_pixel
  - relation:全局轴行反演, global_axis_inversion
  - condition:偏移随行距增, offset_grows_with_distance
  - condition:倾向各异, mixed_lean_directions
- 参考题目题号: 423a55dc（剪切/偏移随行距增）、fe45cba4（锚定物体）、32e9702f（平移）、b6afb2da（矩形）

### docstring

```text
以孤立灰点所在行为不动轴，把每个倾斜对象关于该轴反剪切扶正，行离轴越远滑动越多。

输入结构
- 背景网格上有若干互不接触的倾斜对象：每个对象由等长水平行段组成，
  相邻行整体错开一格，构成向左或向右倾斜的平行四边形。
- 网格某处恰有一个孤立灰色像素，不属于任何对象。
- 对象可以整体位于灰点行的上方、下方，或跨越该行。

规则
- 设灰点所在行为轴行；对每个对象检测其倾斜方向。
- 对象的每一行沿与倾斜相反的方向水平平移，平移量等于该行与轴行的
  行距，即把单位剪切关于轴行整体反演。
- 每个对象因此变为竖直实心矩形，其列位置等于该对象的倾斜延长线与
  轴行相交处的列区间。
- 灰点保留原位，背景不变。

关键洞察
- 灰点不是噪声而是全局转轴：反剪切不以对象自身的底行为锚，而以那条
  看不见的轴行为锚，因此扶正的同时对象还会整体滑移，滑移量由它离
  轴行的距离决定。
```
