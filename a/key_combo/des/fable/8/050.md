## 1. 微缩地址印章

- 参考题目题号：39e1d7f9、b99e7126、edb79dae
- tags:
  - operation:印章覆盖, stamp
  - operation:重涂色, recolor
  - object:格网, lattice
  - object:指令像素, instruction_pixel
  - relation:跨尺度寻址, cross_scale_addressing
  - condition:局部坐标即全局地址, local_coord_as_global_address

### docstring

```text
把每个彩色像素在其单元内的局部坐标读作全网格的单元地址，据此整格涂色。

输入结构
- 网格被单色分隔线划分为 N×N 个单元，每个单元内部为 N×N 的像素区。
- 大部分单元内部为纯背景；少数单元内部含有一个非背景、非分隔色的彩色像素。

规则
- 将每个彩色像素视为一条指令：它在所属单元内部的局部坐标 (r,c)，指向整个点阵中第 r 行第 c 列的那个单元。
- 把被指向单元的内部整体涂成该像素的颜色。
- 所有指令执行完后，抹去原指令像素；其所在单元若未被任何指令指向，则恢复纯背景。
- 分隔线保持不变。

关键洞察
- 每个单元都是整幅点阵的一张微缩地图：像素的"单元内位置"不是图案，而是"单元级地址"；同一像素同时具备颜色（写什么）与位置（写到哪）两重语义。
```

## 2. 锚段配准叠合

- 参考题目题号：2c737e39、ce4f8723、e760a62e、ed36ccf7
- tags:
  - operation:锚点对齐, anchor_alignment
  - operation:旋转, rotate
  - operation:透明叠加, transparent_overlay
  - object:分隔行, separator_row
  - object:有向锚段, directed_anchor_segment
  - relation:刚体配准, rigid_registration
  - condition:重叠生成第三色, overlap_third_color

### docstring

```text
把下面板绕锚段旋转平移到与上面板锚段头尾重合后叠加，重叠处生成第三色。

输入结构
- 一条全宽单色分隔行把网格分成上下两块等尺寸面板。
- 每块面板含一个单色不对称前景图形和一条两格长的锚段：一端灰色像素（头）、一端褐色像素（尾）。
- 两面板前景颜色不同；下面板的图形与锚段可能整体处于被旋转过的姿态。

规则
- 输出为单块面板的尺寸，上面板保持不动。
- 对下面板整体施加一个 90 度倍数的旋转加平移，使其锚段与上面板锚段完全重合，且头对头、尾对尾。
- 变换后逐格合并：仅上面板为前景处取上面板颜色，仅下面板为前景处取下面板颜色，双方均为前景处涂黄色。
- 两条锚段不算前景，合并后不保留。

关键洞察
- 灰-褐锚段是有向配准基线，不是图案的一部分；头尾两色使旋转角在四种可能中唯一确定。
- 部分示例中旋转角恰为 0，"纯平移对齐"是诱饵；必须先恢复姿态，再做带混合色的并集。
```

## 3. 字形程序路由

- 参考题目题号：0e671a1a、b2bc3ffd、ed36ccf7、ac3e2b04
- tags:
  - operation:连线, path_trace
  - operation:填充, fill
  - object:格网, lattice
  - object:方向字形, direction_glyph
  - relation:指令链, instruction_chain
  - condition:臂长即步数, arm_length_as_step
  - condition:干扰字形, decoy_glyph

### docstring

```text
从红色起点字形开始，按每个字形的朝向与臂长逐段跳跃，涂出整条执行路径。

输入结构
- 单色分隔线把网格划分为若干单元。
- 一个单元含红色字形（起点指令），一个单元内部整格为绿色（终点）。
- 若干单元含同族青色字形：一段直臂加在直臂一端侧面的一个偏头像素；其余单元为空。

规则
- 每个字形编码一条指令：方向为从臂的尾端指向偏头端所沿的直线方向，步数等于直臂的长度（不含偏头像素）。
- 从红色字形起执行：按方向在单元网格上跳过对应步数的单元，途中经过的空单元内部整格涂黄。
- 落点单元含下一条青色字形则继续执行；落点为绿色单元则停止。
- 未被路径访问的字形是干扰项，原样保留，不参与路径。

关键洞察
- 字形不是要移动或复制的对象，而是"方向+距离"的复合指令：朝向由偏头像素决定，距离由臂长决定。
- 画面是一段以红为入口、绿为出口的程序，必须逐条执行而非做整体几何变换；不在链上的字形一概无效。
```

## 4. 图例环与最近分区

- 参考题目题号：ac0c2ac3、df978a02、edb79dae、e760a62e
- tags:
  - operation:生长, grow
  - operation:重涂色, recolor
  - object:种子像素, seed_pixel
  - object:颜色图例, color_legend
  - relation:最近者分区, nearest_partition
  - condition:切比雪夫距离, chebyshev_distance
  - condition:等距留缝, tie_gap

### docstring

```text
以两枚种子为中心，在各自最近分区内按图例序列逐环上色，等距处留缝。

输入结构
- 主画布为背景色，含两个不同颜色的孤立种子像素。
- 画布右侧隔一条分隔列有一竖直图例条，自上而下列出若干颜色。

规则
- 对画布每个背景像素，计算它到两枚种子的切比雪夫距离，归属距离更近的种子。
- 归属某种子且距离为 d 的像素，涂成图例自上而下第 d 个颜色；种子自身 d=0 保持原色。
- 距离超过图例长度的像素保持背景；到两枚种子距离相等的像素保持背景，形成分界缝。
- 输出仅保留主画布区域，去掉分隔列与图例条。

关键洞察
- 环不是各自画满整幅再互相覆盖：每个像素先按"最近者得"划归领地，环只在领地内生长。
- 图例是"距离→颜色"的有序调色带而非对象；分界缝是双方并列僵持留下的痕迹。
```

## 5. 推力传递链

- 参考题目题号：b2bc3ffd、df978a02、c9f8e694
- tags:
  - operation:平移, translate
  - operation:计数, counting
  - object:推杆, pusher_bar
  - object:滑块, slider_segment
  - relation:碰撞传递, collision_transfer
  - condition:动量等于长度, momentum_equals_length
  - condition:逐格消耗, per_cell_consumption

### docstring

```text
左端红色推杆携带等于自身长度的动量，沿行向右逐格消耗、逢撞完全转移，推出一条碰撞链。

输入结构
- 黑背景网格；若干行各含一个贴左边缘的红色水平条（推杆）和其右侧若干互不相邻的单色水平段（滑块）。
- 各行互相独立，推杆长度与滑块布局逐行不同；其余行为空。

规则
- 每行独立处理，推杆动量等于其长度。
- 最靠近推杆的滑块开始向右滑动，每前进一格消耗一点动量。
- 若在动量耗尽前贴上下一个滑块，则立即停下并把剩余动量全部转交给该滑块，该滑块继续向右滑动，依此传递。
- 动量耗尽时整条链终止，其后滑块不动；滑块贴上右边缘时停下且剩余动量湮灭。
- 推杆保持原位不动。

关键洞察
- 滑块不是各自按固定规则位移："每块移动自身长度的距离"与"全部向右压紧"都是会被部分示例证伪的诱饵。
- 全行只有一份守恒的动量在碰撞链中传递，每块的实际位移由推杆长度与沿途空隙分布共同决定，必须理解消耗与转移的先后次序。
```

## 6. 边键拔河

- 参考题目题号：c9f8e694、e760a62e、df978a02
- tags:
  - operation:重涂色, recolor
  - object:占位像素, placeholder_pixel
  - object:边缘控制键, edge_key
  - relation:距离竞争, distance_contest
  - condition:等距湮灭, tie_annihilation
  - condition:键位不定端, key_at_either_end

### docstring

```text
每个灰色像素被同行与同列的边缘控制键争夺，距离近者为它上色，等距者湮灭为黑。

输入结构
- 背景网格内部散布灰色像素，可连成形状。
- 含灰像素的每一行在左端或右端边缘有至多一个彩色行键；含灰像素的每一列在上端或下端边缘有至多一个彩色列键。
- 每个灰像素至少受一个键管辖。

规则
- 对每个灰像素，计算它沿本行到行键的格数距离与沿本列到列键的格数距离。
- 距离小者获胜，灰像素涂成获胜键的颜色；只存在一个键时直接用该键颜色。
- 两距离相等时，该灰像素涂黑。
- 键像素与背景保持不变。

关键洞察
- 灰色形状不是按对象整体染色，也不是按行统一染色：每个像素独立参加一场行键与列键的拔河。
- 行键可能在左也可能在右、列键可能在上也可能在下，必须以真实臂长而非坐标大小判胜负；同一连通形状内部会被拔河结果切成多色，等距线以黑缝显形。
```
