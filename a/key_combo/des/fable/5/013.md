## 1. 隐形空腔拼图

- 参考题目: `9f5f939b`(隐含十字缺失中心)、`5dbc8537`(尺寸匹配入槽)、`fe45cba4`(移动补全)
- tags:
  - operation:平移, translate
  - operation:擦除, erase
  - object:微型条, micro_bar
  - object:隐含十字, implied_plus
  - object:精灵体, sprite
  - relation:隐式对象生成, implicit_object
  - relation:尺寸匹配, size_matching
  - condition:缺失中心定角, missing_center_as_corner

### docstring

```text
由两个从未画出的十字中心确定一个隐形矩形槽位,把尺寸唯一匹配的精灵搬进去。

输入结构:
- 背景画布上散布八条灰色两像素条,构成两组"隐含十字":每组四条围绕一个
  空缺中心,中心与每条之间隔一格背景。
- 画布上另散布若干实心单色矩形精灵,bbox 尺寸互不相同。

规则:
- 求出两个隐含十字的缺失中心;它们是一个从未画出的轴对齐矩形的一对对角
  顶点。
- 在精灵中找到 bbox 尺寸与该隐形矩形完全一致的唯一精灵。
- 输出为输入副本:擦除全部灰条,擦除该精灵的原位置,把它绘制在隐形矩形
  处;其余精灵原地不动。

关键洞察:
- 目标槽位在画面上没有任何像素,完全由两组条状标记的"缺失中心"间接生成;
  尺寸配对只有在先建立隐形矩形之后才有意义,单看任一层都无法解题。
```

## 2. 自相似破块

- 参考题目: `c803e39c`(克罗内克积)、`98c475bf`(模板学习与重建)
- tags:
  - operation:纠错重建, error_correction
  - operation:裁剪, crop
  - object:块单元, block_cell
  - object:二值掩码, binary_mask
  - relation:克罗内克积, kronecker_product
  - relation:自相似互证, self_similarity_cross_check
  - condition:单块篡改, single_block_corrupted

### docstring

```text
整幅网格是某个小图案与自身的克罗内克积,其中一块被篡改,输出真正的小图案。

输入结构:
- 网格边长为 n 的平方(如 9、16、25),可划分为 n×n 个 n×n 块。
- 存在一个从未单独给出的 n×n 二色图案 M:M 的前景位置对应的块内画着
  M 本身,M 的背景位置对应的块为纯背景。
- 恰有一个块被篡改:本应纯背景的块被涂上内容,或本应画 M 的块被涂错
  或涂空。

规则:
- 输出 n×n 的图案 M。

关键洞察:
- M 同时以两种身份存在:块级布局是 M,前景块的内容也是 M,互为拷贝。
- 篡改使某一种读法在一处失真,必须利用完好块之间的相互印证——用多数
  一致的块内内容恢复内容层,再用内容层反推布局层——才能还原真正的 M。
```

## 3. 镜厅针孔

- 参考题目: `6e453dd6`(孔洞触发射线、碰撞停止)、`b9e38dc0`(开口方向、障碍阻挡)、`9841fdad`(跨面板连通)
- tags:
  - operation:射线延伸, ray_cast
  - operation:反射, reflect
  - object:矩形边框, rectangular_frame
  - object:单像素缺口, pinhole_gap
  - object:对角镜, diagonal_mirror
  - object:障碍物, obstacle
  - relation:行列对齐, row_col_aligned
  - condition:通畅入射, unobstructed_entry
  - condition:对穿出射, pass_through_exit

### docstring

```text
框外光源只能从与它行列对齐且无遮挡的缺口射入封闭框,入射光在框内被对角镜
逐次反射,最终被吸收或从另一缺口穿出继续传播。

输入结构:
- 画布上有一个单色实心矩形框,框壁开有若干单像素缺口。
- 框外恰有一个彩色光源像素。
- 框内散布两种镜像素:青色代表"/"镜,橙色代表"\"镜;另有少量与框同色
  的吸收障碍像素。

规则:
- 光从光源出发,沿直线射向与其同行或同列、且中间路径无阻挡的那个缺口;
  其余缺口都是死口,保持原样。
- 光进入框内后逐格涂成光源色;撞到"/"或"\"镜时按对角反射改变方向,
  撞到障碍或框壁内侧即停止。
- 若光恰好行进到某个缺口位置,则穿出框外,继续沿直线传播涂色,直到
  网格边缘。
- 镜、障碍、框保持原样,光不覆盖镜像素本身的颜色。

关键洞察:
- 入口由框外几何(行列对齐+路径通畅)唯一选定,而出口无法直接看出,
  必须沿反射级联逐步模拟;缺口是双向通道而非终点,光路把框内外缝成
  一条因果链。
```

## 4. 箭头接力线

- 参考题目: `689c358e`(横杆偏置定向的 T 形箭头)、`252143c9`(定向射线)、`98c475bf`(边框锚点)
- tags:
  - operation:连线, connect
  - operation:射线延伸, ray_extend
  - object:箭头精灵, arrow_sprite
  - object:边框起点, frame_start
  - relation:因果接力, causal_relay
  - relation:朝向对齐, orientation_aligned
  - condition:横杆偏移定方向, crossbar_determines
  - condition:路径外为干扰, off_path_decoy

### docstring

```text
从边框起点出发的走线每撞到一个箭头就改走该箭头指的方向,每段线染成最近
经过的那个箭头的颜色。

输入结构:
- 网格四周为单色边框,框上有一个异色的起点像素。
- 框内散布若干单色六像素 T 形箭头精灵:长四直杆加偏置的长三横杆,横杆
  更靠近的一端为指向端。

规则:
- 从起点向框内沿垂直于边框的方向射入,第一段走线用起点色绘制。
- 走线撞上某个箭头的任何像素后,跳到该箭头尖端,改沿其指向继续画线,
  此后的线段改用该箭头的颜色。
- 重复接力,直至走线撞上边框;撞点也涂当前颜色。
- 不在走线路径上的箭头是干扰,保持原样。

关键洞察:
- 每个箭头的指向藏在横杆的偏置位置里;整条路径是一条因果接力链,线段
  颜色记录"最近听谁指挥",必须逐段模拟,任何一个箭头判向出错都会使
  后续全部偏离。
```

## 5. 到站次序造洋葱

- 参考题目: `45a5af55`(条高决定框厚的同心方框)、`d6e50e54`(最近距离滑动)、`668eec9a`(排序编码)
- tags:
  - operation:滑动, slide
  - operation:嵌套包裹, nested_wrapping
  - operation:排序, sorting
  - object:矩形, rectangle
  - object:锚点像素, anchor_pixel
  - object:同心正方形层, concentric_square_frame
  - relation:行列对齐, row_col_aligned
  - relation:距离决定层序, distance_maps_layer
  - condition:块长决定层厚, block_length_as_thickness

### docstring

```text
各色块沿行列滑向中央锚点,按全局到达次序由内向外织成同心方框,层厚取自
块沿滑动方向的边长。

输入结构:
- 画布上有一个单像素锚点。
- 四个方向散布若干实心单色矩形块,每块与锚点行对齐或列对齐,颜色互不
  相同,与锚点之间的空隙距离互不相同。

规则:
- 设想所有块同时同速滑向锚点:空隙最小者最先到达,依次得到全局到达
  次序。
- 输出一个新的正方形网格:中心一格为锚点色;第 k 个到达的块贡献由内
  向外第 k 层同心方框,颜色为块色,厚度等于该块沿滑动方向的边长。
- 输出边长由中心一格与各层厚度累加决定。

关键洞察:
- 层的顺序不由方向、颜色或块的大小决定,而由全局到达次序(即空隙距离
  的排序)决定;块的形体信息只以"沿滑动方向的边长"这一个数字幸存,
  垂直方向的宽度被完全丢弃。
```

## 6. 基准点组定向重建

- 参考题目: `98c475bf`(模板学习、锚点重建)、`9841fdad`(左参考右重建)、`833966f4`(顺序反转/取向变换)
- tags:
  - operation:补全, reconstruct
  - operation:旋转镜像, rotate_reflect
  - object:字形模板, glyph_template
  - object:手柄像素, handle_pixel
  - object:基准点组, fiducial_set
  - object:分隔列, separator_column
  - relation:局部构型定变换, local_config_determines
  - condition:三点唯一定解, three_points_unique

### docstring

```text
右半区每组残迹只有三个像素,它们是模板字形上一小块局部经某个旋转或镜像
变换后的像,求出该变换并以残迹为锚重建整个字形。

输入结构:
- 灰色分隔列把画布分为左右两半。
- 左半是一个完整的非对称单色字形,其某个确定位置紧贴一个红色手柄像素。
- 右半散布若干组残迹,每组由一个红手柄像素与两个字形色像素构成;这两个
  字形色像素正是模板中与手柄相邻的那两个字形像素,经过某个未知的旋转
  (0/90/180/270 度)或镜像组合变换后的位置。

规则:
- 以左半为模板,记录手柄与其相邻两个字形像素的相对构型。
- 对右半每组残迹,求出唯一能把模板局部构型映射到该残迹构型的旋转镜像
  变换。
- 将整个模板字形按该变换、以手柄为锚点绘制在右半;不同残迹组的变换
  各自独立。
- 左半与分隔列保持不变。

关键洞察:
- 三像素残迹不是待补的碎片,而是求解变换的最小基准点组:两个像素不足以
  在八个旋转镜像变换中唯一定解,第三个点才锁定唯一解;完整字形从未在
  右半出现过,完全由变换推出。
```

## 7. 级联剪枝生长

- 参考题目: `af726779`(间隔行交替色繁殖)、`b9e38dc0`(障碍阻挡传播)
- tags:
  - operation:生长, grow
  - operation:擦除, prune
  - object:种子行, seed_row
  - object:障碍物, obstacle
  - relation:相邻间隔, adjacent_gap
  - relation:繁殖树级联, generative_tree_cascade
  - condition:交替变色, alternating_color
  - condition:占位即绝后, occupied_kills_subtree

### docstring

```text
种子行向下逐代繁殖交替色像素,任何被障碍占据的出生点连同它的全部后代
一起消失。

输入结构:
- 统一背景,顶部附近一行同色种子像素行,行内含孤立点与连续段。
- 种子行下方散布少量灰色障碍像素。

规则:
- 当前活动行内每个"活-空-活"三元组,在向下隔一行的中间列位置生出一个
  子像素;生成行的颜色逐代在两种颜色间交替。
- 若某个出生点恰好被障碍占据,该子像素不出生,并且它本应参与的所有后续
  三元组繁殖全部落空。
- 持续繁殖直到没有新子像素产生或越出网格;障碍像素保留在输出中。

关键洞察:
- 障碍的影响不是几何直线阴影,而是沿繁殖树级联传播:抹掉一个出生点等于
  砍掉一整棵子树,远离障碍的位置也可能因祖先缺失而空缺,必须逐代模拟
  而不能按遮挡关系直接推断。
```

## 8. 配额纸带

- 参考题目: `278e5215`(蒙版+调色带)、`668eec9a`(顺序编码)、`8fff9e47`(逆序/顺序读取纸带)
- tags:
  - operation:重涂色, recolor
  - operation:裁剪, crop
  - object:单色蒙版, monochrome_mask
  - object:调色带, palette_strip
  - object:行段, row_segment
  - relation:阅读顺序展开, reading_order_unroll
  - relation:计数守恒, count_conservation
  - condition:段长为配额, length_as_quota

### docstring

```text
底部调色带是一条按阅读顺序展开的"配额纸带":每个色段的长度表示该颜色
要连续认领多少个蒙版行段,而不是任何位置或长度上的匹配。

输入结构:
- 画布底部一条单行调色带,由若干彩色段组成,各段长度不一。
- 画布中部一个大的灰色蒙版对象,内部含背景色孔洞,孔洞把蒙版的每一行
  切成若干灰色横向段。
- 全部行段的总数恰好等于调色带的总像素长度;蒙版与调色带水平错位,且
  行段长度与色段长度普遍不相等(个别巧合相等,是刻意诱饵)。

规则:
- 把蒙版的灰色横向段按行优先(自上而下、每行内自左向右)的阅读顺序编号。
- 调色带自左向右展开成颜色序列:长度为 n 的色段贡献 n 个连续名额。
- 第 i 个行段整段涂成颜色序列第 i 项的颜色。
- 输出为裁剪后的蒙版 bbox,孔洞保持背景色。

关键洞察:
- 解题者会先后尝试"绝对列位置对应"与"段长匹配字典",两者都被刻意
  错开而失效;真正的键是计数守恒——行段总数等于调色带总长,色段长度
  是"重复次数"而非几何长度,纸带按阅读顺序逐段发放颜色配额。
```
