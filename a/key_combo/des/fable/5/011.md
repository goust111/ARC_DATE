## 1. 残缺对称体的倾倒滑移

- 参考题目题号：5 (a09f6c25)、10 (99caaf76)、1 (db7260a4)
- tags:
  - operation:对称补全, symmetry_completion
  - operation:滑动, translate
  - operation:擦除, erase
  - object:残缺物体, incomplete_object
  - object:对称轴, symmetry_axis
  - relation:残缺侧编码方向, missing_side_encodes_direction
  - condition:单像素为噪声, singleton_noise
  - condition:抵达边界或叠停, reach_edge_or_stack

### docstring

```text
先按各自的对称轴补全每个残缺的红色物体，再让物体垂直于对称轴、朝原残缺一侧
滑动，直到撞上网格边缘或已停稳的物体。

输入结构
- 背景为主导色。
- 若干红色 4 连通物体，每个物体在去掉少量像素后恰有一类反射对称
 （竖直轴、水平轴或对角轴），缺失像素全部位于轴的同一侧。
- 另有孤立红色单像素，为噪声。

规则
- 擦除孤立噪声像素。
- 对每个物体先补全其反射对称。
- 补全后的物体沿垂直于自身对称轴的方向、指向原缺失像素所在一侧平移，
  直到碰到网格边缘或已停稳的物体（对角轴物体沿对角线滑动）。
- 沿运动方向距障碍更近的物体先落定，后落定者可叠停在先落定者上。

关键洞察
- 缺失像素不是要忽略的噪声（真正的噪声是孤立单像素），它们承担双重职责：
  既要被对称补全修复，又以其所在侧编码该物体的滑动方向。
- 不同物体的运动方向互不相同，由各自的轴向与残缺侧共同决定，
  不存在统一的重力方向。
```

## 2. 看不见的射线选容器

- 参考题目题号：1 (db7260a4)、7 (142ca369)
- tags:
  - operation:射线延伸, ray_cast
  - operation:反弹, bounce
  - operation:填充, fill
  - operation:擦除, erase
  - object:箭头精灵体, arrow_sprite
  - object:墙壁像素, wall_pixel
  - object:容器, container
  - relation:落点列决定容器, landing_column_selects_container
  - condition:无容器则铺满底行, no_container_floor
  - condition:轨迹不画出, trajectory_invisible

### docstring

```text
从箭头沿对角发射一条不画出的射线，经边界与墙像素反弹后到达底部，
落点列决定哪个 U 形容器被填满。

输入结构
- 网格上部空旷区有一个 3 像素 L 形箭头（2×2 缺一角）与若干灰色墙像素。
- 底部若干红色 U 形容器：两竖壁夹连续底边，内腔为空。

规则
- 射线从箭头缺角方向沿对角线飞行。
- 碰到左右网格边或灰色墙像素时水平方向反转、竖直方向不变，继续下行。
- 碰到容器像素或到达底行即停止，停止处的列为投放列。
- 若投放列位于唯一封闭容器的水平足迹内，用箭头颜色填满该容器内腔；
  否则整条底行涂成箭头颜色。
- 擦除箭头；墙像素保持不变；射线轨迹不画出。

关键洞察
- 画面上从未出现射线本身，输出里也没有它的任何痕迹。
- 箭头所在列并不是投放列：必须在脑中模拟对角飞行与反弹路径，
  才能得到真正的下落列。
```

## 3. 洞角成对的点对称搬运

- 参考题目题号：20 (a644e277)、8 (e729b7be)
- tags:
  - operation:点对称复制, point_symmetry_copy
  - operation:修复, repair
  - object:网格线, lattice_line
  - object:缺失交叉点, missing_intersection
  - object:标记像素, marker_pixel
  - relation:八洞分两组四角, eight_holes_two_rectangles
  - relation:公共中心旋转, shared_center_rotation
  - condition:源区有标记目标区空, source_marked_target_empty

### docstring

```text
八个缺失的格线交叉点围出两个同构矩形，把有图案的矩形绕两矩形公共中心
旋转 180 度复制进空矩形，并修复八个洞。

输入结构
- 规则的一格厚点阵：一种线色、一种背景色，格胞内散布少量彩色标记像素。
- 恰有八个格线交叉点缺失（呈背景色），它们可唯一分成两组，
  每组四洞构成一个矩形的四角，两矩形行列尺寸相同。
- 一个矩形覆盖的格胞含标记像素（源），另一个全空（目标）。

规则
- 找出八洞的唯一配对方式，得到源矩形与目标矩形。
- 以两矩形中心连线的中点为旋转中心，把源矩形内全部标记像素
  旋转 180 度画入目标矩形。
- 把八个洞恢复为线色，其余保持不变。

关键洞察
- 缺失交叉点不是要修复的噪声，而是成对矩形的角标。
- 必须先解出"八洞分两组"的配对，搬运的起点、终点与旋转中心才随之确定；
  旋转中心不在任何矩形内部，而在两矩形之间。
```

## 4. 斜边残迹定三角

- 参考题目题号：3 (e3f79277)、5 (a09f6c25)
- tags:
  - operation:补全, complete
  - operation:擦除, erase
  - object:角位边角, corner_piece
  - object:残迹采样点, residue_sample
  - object:三角轮廓, triangle_outline
  - relation:坐标和恒定, coordinate_sum_constant
  - condition:异色孤点为噪声, off_color_noise

### docstring

```text
角上的 L 形与散落的同色残迹点共同确定一个直角三角形轮廓，
残迹点正是尚未画出的斜边的采样。

输入结构
- 网格若干角上各有一个单像素粗、贴边的 L 形，颜色互不相同。
- 网格中部散布若干彩色像素，其中与某个 L 同色的点全部落在
  "到该角两坐标之和为同一常数"的反对角线上。
- 另有少量与任何 L 都不同色的孤立像素，为噪声。

规则
- 对每个 L：由同色残迹点的坐标和读出三角形直角边长 n（= 坐标和 + 1）。
- 把该 L 的两臂沿网格边延长到长度 n。
- 画出连接两臂端点的完整斜边，残迹点被吸收进斜边。
- 擦除所有噪声像素。

关键洞察
- 散点既不是要数的也不是要删的：它们是没画出的斜边的采样残迹。
- 参与规则的三角形从未被完整画出，画面上只有它的生成元（L 形）
  与投影残迹（斜边采样点）；由"两坐标之和恒定"识别这条隐形直线，
  三角形尺寸随之确定。
```

## 5. 图例长度选路

- 参考题目题号：19 (7b0280bc)、12 (195c6913)
- tags:
  - operation:路径搜索, path_search
  - operation:重涂色, recolor
  - object:节点方块, node_square
  - object:轨道段, track_segment
  - object:颜色图例, color_legend
  - relation:图结构, graph_structure
  - relation:图例长度选路, legend_length_selects_path
  - condition:首尾色定方向, endpoint_colors_orient

### docstring

```text
在方块-轨道图中找出节点数恰好等于图例循环长度的那条简单路径，
按图例颜色顺序为沿途节点染色。

输入结构
- bg 为主导色。
- 实心小方块为节点，1 格宽轨道段为边，构成一张图。
- 两个端点方块颜色特殊，其余节点为同一台站色。
- 网格一角有一行 2×2 色块图例，从左到右给出颜色序列，
  首色与尾色分别等于两个端点的颜色。

规则
- 在图中枚举两端点间的简单路径，唯一存在一条路径的节点总数（含两端）
  恰好等于图例色块数。
- 从颜色等于图例首色的端点出发，沿该路径把第 i 个节点涂成图例第 i 色。
- 该路径上的轨道段涂灰，其余保持不变。

关键洞察
- 要找的不是最短路径：最短路往往对不上图例长度，是第一眼的诱饵。
- 图例的长度是选路准则，图例的首尾色给出行进方向；
  长度与方向两个信息都藏在同一个图例里。
```

## 6. 缺锚行靠对称补齐的显影

- 参考题目题号：15 (3cd86f4f)、8 (e729b7be)、14 (269e22fb)
- tags:
  - operation:行平移, row_shift
  - operation:对称反解, symmetry_solve
  - operation:裁剪, crop
  - operation:擦除, erase
  - object:锚像素, anchor_pixel
  - object:隐藏图形, hidden_figure
  - relation:锚列对齐, anchor_column_alignment
  - condition:无锚行由对称约束定位, unanchored_rows_by_symmetry

### docstring

```text
按灰色锚像素把各行水平对齐使隐藏图形显影，但部分行没有锚，
这些行的位移必须由"显影后图形整体左右对称"这一约束反推出来。

输入结构
- 背景色主导的矩形网格。
- 大多数行恰有一个灰色锚像素，少数行没有锚。
- 每行另散布若干彩色像素，单看任何一行或原图整体都读不出形状。
- 存在唯一一组行位移，使全部彩色像素拼成一个 4 连通且左右镜像对称的
  多色图形。

规则
- 先把所有带锚的行水平平移，使灰锚对齐到同一列（位移全部非负且总量最小）。
- 对每个无锚行，在使整体图形左右对称且 4 连通的约束下解出其唯一位移。
- 擦除全部锚像素，输出显影图形的最小包围盒裁剪。

关键洞察
- 对齐基准分两层：有锚行由锚直接给出；无锚行的位移画面上没有任何标记，
  只能先完成第一层对齐、看出图形的对称骨架，再用对称性反解。
- 参与规则的图形从未被完整画出，彩色散点是被逐行错位打乱的残迹；
  若把无锚行当作已对齐或当作噪声，图形就拼不成对称连通体。
```

## 7. 互为镜像的修复源

- 参考题目题号：18 (135a2760)、14 (269e22fb)
- tags:
  - operation:修复噪声, repair_noise
  - operation:平铺, tiling
  - operation:对齐, align
  - object:周期瓦片, periodic_tile
  - object:框架分区, frame_partition
  - relation:二面体变换, dihedral_transformation
  - relation:交叉备份, cross_backup
  - condition:单区投票失效, single_region_vote_fails

### docstring

```text
两个分区里是同一周期图案的两个不同朝向副本，各自被污染在不同位置，
必须对齐朝向互相借用才能同时修复。

输入结构
- 框架色的整行整列把网格分成两个矩形分区，bg 填空。
- 每个分区内是一个小瓦片的周期平铺，各有若干污染像素。
- 两分区的平铺互为某个旋转/翻转（二面体变换）关系。
- 任一分区单独做逐残位多数投票都不足以确定干净瓦片：
  污染在某些残位上占多数。

规则
- 找出把分区 B 对齐到分区 A 的二面体变换。
- 对齐后逐格叠加，取每个残位上未被污染的一致颜色，得到干净瓦片。
- 按各自原朝向把干净平铺写回两个分区。

关键洞察
- 熟悉的"单区多数投票修复"在此失效——这是刻意埋下的诱饵，
  污染在某些残位上占了多数。
- 两个分区互为对方的备份，但备份被旋转/翻转过；
  必须先解出朝向关系，才能交叉借用信息完成修复。
```
