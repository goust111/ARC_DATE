## 1. 宽度筛河

- 参考题目: `332f06d7`, `2b83f449`, `58f5dbd5`
- tags:
  - operation:滑动, slide
  - operation:路径搜索, pathfinding
  - object:实心方块, solid_square
  - object:分叉河道, branching_channel
  - object:目标标记, destination_marker
  - relation:尺寸约束通行, size_constrains_passage
  - condition:顺序依赖, order_dependent
  - condition:碰撞停止, collision_stop

### docstring

```text
不同尺寸的方块沿分叉河道滑行，河道宽度像筛子一样把每个方块路由到唯一可达的目标点。

输入结构：
- 背景为众数色；一条河色通道蜿蜒分叉，末端有若干死端，每个死端处有一个灰色目标点。
- 河道上放着若干实心 N×N 方块，颜色互异、尺寸互异。

规则：
- 方块按尺寸从大到小依次移动；移动时其完整 N×N 区域必须始终落在河色内。
- 每个方块滑到它能到达的目标点处并覆盖该目标点；原位置回填河色。
- 先落位的方块成为后续方块的障碍物。

关键洞察：
- 各分支的最窄咽喉宽度构成一个尺寸筛：对每个方块，恰有一个目标点在它的可达域内；
  大方块先行还会封锁通路，改变小方块的可达域，处理顺序是答案的一部分。
```

## 2. 边界即指令带

- 参考题目: `8dab14c2`, `136b0064`, `da515329`
- tags:
  - operation:解码指令, decode_instructions
  - operation:连线, draw_polyline
  - object:凸起, tab
  - object:缺口, notch
  - object:起始标记, start_marker
  - relation:边界遍历顺序, boundary_traversal_order
  - condition:特征编码转向, feature_encodes_turn
  - condition:间距编码长度, spacing_encodes_length

### docstring

```text
把厚色块边界上的凸起与缺口顺时针读成一条折线程序，在别处画出这条折线。

输入结构：
- 黑色背景上有一个厚实的直角多边形色块，边界上散布若干单像素凸起与单像素缺口。
- 另有一个灰色起点像素，紧邻它的一个蓝色像素指示初始行进方向。

规则：
- 从色块最靠上、其次最靠左的边界格出发，顺时针沿边界行走一圈。
- 途中依次遇到的特征转成指令：凸起 = 右转，缺口 = 左转；相邻两个特征之间走过的
  边界步数 = 对应线段的长度（起点到第一个特征的步数为第一段长度）。
- 从灰色起点按初始方向依次画出各线段（涂蓝色），每段末尾执行该处的转向，指令用完即停。

关键洞察：
- 色块本身不是被变换的对象：它的边界缺陷是一条指令带，转向由特征种类编码，
  步长由特征间距编码，折线是这段"程序"的执行结果。
```

## 3. 面积定环距

- 参考题目: `ac0c2ac3`, `6ffbe589`, `b2bc3ffd`
- tags:
  - operation:填充, fill
  - operation:计数, counting
  - object:标记像素, marker_pixel
  - object:同心方环, concentric_ring
  - object:精灵, sprite
  - relation:面积映射距离, area_maps_distance
  - condition:切比雪夫距离, chebyshev_distance
  - condition:实心空心编码样式, solidity_encodes_style

### docstring

```text
以孤立像素为中心画同心方环，每个精灵用自己的面积认领一个环，用实心/空心决定染整环还是只染四角。

输入结构：
- 背景为众数色；恰有一个孤立单像素标记（唯一的单格对象）。
- 若干小型单色精灵散布各处，像素面积互不相同；有的是实心块，有的是空心框。

规则：
- 输出中擦除所有精灵，仅保留中心标记。
- 面积为 d 的精灵为切比雪夫距离 d 的方环提供颜色：
  实心精灵 → 该环全部格子染其色；空心精灵 → 只染该环的四个角格。
- 没有精灵认领的距离保持背景。

关键洞察：
- 精灵摆放的位置全是诱饵：半径由面积编码、样式由实心与否编码，
  画面上从未出现过任何一个环。
```

## 4. 周期残迹重组

- 参考题目: `17b866bd`, `9385bd28`, `6ffbe589`
- tags:
  - operation:裁剪, crop
  - operation:模式恢复, pattern_recovery
  - object:周期平铺, periodic_tiling
  - object:异常像素, anomaly_pixel
  - relation:坐标取模折叠, coordinate_mod_folding
  - condition:众数定模板, mode_defines_template
  - condition:隐藏图案, hidden_pattern

### docstring

```text
把周期平铺中零星的异常像素按"坐标取模"折叠进一个基本块，拼出从未完整出现过的隐藏图案。

输入结构：
- 整幅网格由一个 p×p 多色基本图案周期平铺而成。
- 少数格子的颜色偏离了平铺模板，异常色可以彼此不同。

规则：
- 对每个同余坐标类取众数色，恢复出 p×p 模板并确定周期。
- 每个异常像素记录其颜色与局部坐标 (行 mod p, 列 mod p)。
- 输出一个 p×p 网格：底色为模板的背景色，再把每个异常色写入其局部坐标。

关键洞察：
- 要输出的图案在画面上从未整体出现，它被打散寄存在不同的平铺周期里；
  大网格只是坐标系载体，答案是所有异常在模意义下的叠加。
```

## 5. 普查配给

- 参考题目: `7d7772cc`, `b2bc3ffd`, `9385bd28`
- tags:
  - operation:平移, translate
  - operation:计数, counting
  - operation:擦除, erase
  - object:分隔线, separator_line
  - object:参考列, reference_column
  - object:单色对象, monochrome_object
  - relation:同色配额, same_color_quota
  - condition:资源消耗, resource_depletion
  - condition:处理顺序保护, processing_order_protection

### docstring

```text
每个对象向分隔线移动的格数等于参考列中现存的同色像素数，且移动会把这些同色像素全部耗尽，使后来的同色对象无薪可领。

输入结构：
- 一条完整的竖直分隔线把网格分成两侧；一侧贴着网格边缘有一列彩色参考像素。
- 另一侧散布若干单色小对象，形状面积各异，可能出现颜色相同的多个对象。
- 两侧各有自己的背景色。

规则：
- 按对象到分隔线的距离由近到远依次处理。
- 处理某对象时，统计参考列中当前仍存在的与它同色的像素个数 k。
- 若 k>0：该对象沿自己的行向分隔线方向平移 k 格（若会撞上分隔线或已落位对象
  则贴着停下），同时把参考列中这 k 个同色像素擦成参考侧背景色。
- 若 k=0：该对象平移到远离分隔线的外边缘。原位置回填背景。

关键洞察：
- 位移量与对象自身的面积、形状、几何位置都无关，是对参考列的一次同色普查；
  且参考像素是一次性配给——先处理的同色对象把配额用光，之后的同色对象领到零
  而被放逐，处理顺序与资源消耗共同决定答案。
```

## 6. 单色印痕

- 参考题目: `fc7cae8d`, `58f5dbd5`, `62593bfd`
- tags:
  - operation:旋转, rotate
  - operation:镜像, reflect
  - operation:挖孔, punch_holes
  - object:多色主对象, multicolor_master_object
  - object:单色印痕, monochrome_imprint
  - relation:形状匹配定姿态, shape_match_determines_pose
  - condition:颜色点名剔除层, color_names_removed_layer
  - condition:旋转翻转不变, rotation_flip_invariant

### docstring

```text
把多色主对象按姿态搬进每个单色印痕，再把印痕自身颜色对应的色层挖成背景。

输入结构：
- 背景为众数色；一个不对称的多色主对象。
- 若干整块单色"印痕"，其形状恰是主对象掩码经过某个旋转/翻转后的结果；
  各印痕颜色互不相同，且都是主对象调色板中的颜色。

规则：
- 对每个印痕，求出把主对象形状映射成该印痕形状的唯一二面体变换。
- 按该变换把主对象的完整颜色图案绘制到印痕位置。
- 然后把该处图案中等于印痕原色的所有像素挖成背景；主对象保持不变。

关键洞察：
- 单色印痕同时携带两条信息：形状给出姿态（要用哪种旋转翻转），
  颜色点名要被剔除的色层；它不是要保留的对象，而是一条双重指令。
```
