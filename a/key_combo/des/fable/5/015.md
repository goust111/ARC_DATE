## 1. 罗盘指令蛇

- tags:
  - operation:路径遍历, path_traversal
  - operation:绘制轨迹, draw_trail
  - object:蛇形路径, snake_path
  - object:罗盘图例, compass_legend
  - object:起点像素, start_pixel
  - relation:颜色方向码表, color_to_direction
  - condition:端点定读向, endpoint_fixes_order
- 参考题目题号: `7b5033c1`, `58490d8a`, `6d1d5c90`, `fc10701f`

### docstring

```text
把蛇形路径按颜色逐格读成移动指令，依罗盘图例驱动起点像素画出轨迹。

输入结构：
- 背景色占主导，网格上有三类元素：一条 4-连通、无分叉、恰有两个端点的
  多色蛇形路径；一个 3×3 罗盘图例（灰色中心，中心的上、下、左、右四格
  各放一种指令色）；一个孤立的起点像素，其颜色不属于罗盘四色。
- 蛇上每一格的颜色都取自罗盘四色。

规则：
- 取蛇的两个端点中最靠上（同高取最靠左）的那个，从它出发沿路径逐格读出
  颜色序列。
- 罗盘中某指令色相对灰心的方位，即该颜色代表的移动方向。
- 从起点像素出发按序列逐条执行：向对应方向走一格，并把落脚格涂成该指令
  色；轨迹自交时后到的指令色覆盖先到的。
- 输出中擦除蛇与罗盘，只保留背景、起点像素与画出的轨迹。

关键洞察：
- 蛇不是要被搬运或拉直的图形，而是一条串行指令带；罗盘给出颜色到方向的
  码表，端点选取规则固定了读带方向——三者合起来才构成一段可执行的程序。
```

## 2. 隐匿母版修复

- tags:
  - operation:提取, extract
  - operation:修复标记, repair_mark
  - object:隐藏双色图, hidden_bicolor_image
  - object:受损副本, damaged_copy
  - relation:行列叉积, row_col_product
  - condition:标记色缺席, marker_color_absent
- 参考题目题号: `b71a7747`, `e84fef15`

### docstring

```text
从杂乱区域中提取占满行列叉积的隐藏双色图作为母版，据此把受损副本的缺失
像素标记出来。

输入结构：
- 一条分隔线把网格分成两个区域。
- 区域甲是多色杂乱画面，其中恰有一对颜色，其全部像素恰好占满"活跃行 ×
  活跃列"的完整叉积；其余颜色都是填充与干扰。
- 区域乙是单个图块，尺寸等于叉积图压缩后的尺寸；它与母版一致，只是若干
  前景像素被区域乙的背景色覆盖。
- 某种标记色在整个输入中缺席。

规则：
- 在区域甲中找到唯一满足行列叉积性质的颜色对，删除未被该对触及的行与列，
  压缩得到母版图。
- 将母版与区域乙逐格对比。
- 输出母版尺寸的网格：一致处保留母版颜色，受损处（乙为背景而母版为前景）
  涂标记色。

关键洞察：
- 母版从未被完整画出——它以行列叉积的形式潜藏在杂乱之中，且不能靠颜色
  编号来锁定；只有先完成这次"无颜色线索"的提取，修复与标记才有依据。
```

## 3. 波前接壤线

- tags:
  - operation:波前扩散, wavefront_spread
  - operation:标记, mark
  - object:源点, source_pixel
  - object:墙壁, wall
  - relation:测地等距, geodesic_equidistance
  - condition:并列最近判接壤, tie_marks_frontier
- 参考题目题号: `13e47133`, `7491f3cf`, `fc10701f`

### docstring

```text
标出到最近两个源点的绕墙最短距离恰好相等的所有格子，即两股波前的接壤线。

输入结构：
- 背景格可通行；一种墙色构成若干段不可穿越的障碍。
- 若干不同颜色的孤立源点像素散布在可通行区域。
- 一种接壤标记色在输入中缺席。

规则：
- 想象每个源点同时向外扩散，波前每步沿 4-连通方向推进一格，不能穿墙。
- 对每个可通行格，取它到各源点的绕墙最短步数；若最小值被两个及以上源点
  同时取得，该格涂接壤标记色。
- 其余一切保持原样：背景、墙、源点均不变。

关键洞察：
- 接壤线不是两点连线的中垂线——距离是绕过障碍的 4-连通测地距离，墙会把
  接壤线折弯、掐断，甚至推到与直观中线完全不同的位置。
```

## 4. 残迹重构菱环

- tags:
  - operation:反推重构, inverse_reconstruction
  - operation:绘制轮廓, draw_outline
  - object:菱形轮廓, diamond_outline
  - object:格线, lattice_line
  - object:残迹像素, residue_pixel
  - relation:交点采样, intersection_sampling
  - relation:共享半径约束, shared_radius_constraint
  - condition:欠定借约束补全, underdetermined_needs_propagation
- 参考题目题号: `d753a70b`, `13e47133`, `e84fef15`

### docstring

```text
由留在直线上的残迹像素反推被擦除的曼哈顿菱形轮廓，用采样充分的菱形解出
全体共享的未知半径，再借它补全采样不足的菱形并全部重画。

输入结构：
- 背景上画有若干条贯穿全宽或全高的直线（线色统一），构成稀疏格线。
- 线上散布着若干彩色残迹像素；同色残迹全部来自同一个被擦除的、一格厚的
  曼哈顿菱形轮廓与这些直线的交点，线外没有任何前景像素。
- 所有被擦除的菱形共用同一个半径，但该半径未写在画面任何地方。
- 至少一种颜色的残迹足以单独确定其菱形的中心与半径；其余颜色的残迹可能
  只有一两个点，单独看有多个可行解，结合公共半径后解唯一。

规则：
- 按颜色把残迹像素分组。
- 先找出残迹足以单独定解的颜色组，解出其菱形（所有残迹到中心的曼哈顿距
  离恰等于半径），由此得到全体共用的半径。
- 再用该半径逐组求解欠定的颜色组，确定各自唯一的中心。
- 在输出中以各自颜色画出全部完整菱形轮廓；格线保留，被轮廓经过的线格改
  涂轮廓色。

关键洞察：
- 画面上从未出现完整对象，只有它与直线相交留下的采样点；且单个对象的信
  息可以不够——公共半径这一隐含约束把信息从采样充分的对象传播到欠定的
  对象，先解谁、再解谁是有次序的。
```

## 5. 计数定厚同心带

- tags:
  - operation:计数, counting
  - operation:同心填充, concentric_fill
  - object:图例框, legend_box
  - object:目标区域, target_region
  - object:散布对象, scattered_object
  - relation:计数转厚度, count_to_thickness
  - condition:列序定带序, key_order_is_band_order
- 参考题目题号: `58490d8a`, `13e47133`, `b0039139`

### docstring

```text
数出每种钥匙色在图外的对象个数作为环带厚度，按图例列序在目标区域内画同
心色带。

输入结构：
- 一个黑色矩形图例框，其最左非黑列自上而下排着若干钥匙色像素，框内其余
  为空。
- 一个由边框围成的矩形目标区域，内部全为背景。
- 图例框与目标区域之外，散布着各钥匙色的若干个互不相触的对象。

规则：
- 对每种钥匙色，数出它在框外与区域外的独立对象个数。
- 按钥匙色在图例列中自上而下的顺序，从目标区域边界向内依次画环带：每种
  颜色的环带厚度等于其对象个数。
- 一轮颜色画完后循环重复该序列，直到目标区域被填满；中心剩余深度不足一
  个厚度时，画到填满为止。

关键洞察：
- 图例不再是输出画布——它只提供颜色次序；对象个数也不再是要输出的点数，
  而是被转译成每层环带的几何厚度。次序与数量两条线索缺一不可。
```

## 6. 选异成链

- tags:
  - operation:异常提取, outlier_extraction
  - operation:重排, reorder
  - object:格阵单元, lattice_cell
  - object:异格, odd_cell
  - relation:边缘像素咬合, edge_pixel_interlock
  - condition:链序覆盖行序, chain_overrides_row_order
- 参考题目题号: `38007db0`, `78332cb0`

### docstring

```text
从每个格排中挑出独一无二的单元格，再按边缘像素咬合关系把它们重新排成一
条竖带。

输入结构：
- 均匀格线把网格分成 R 行 × C 列的等大单元格，每格内是背景上的小图案。
- 每一行恰有一个图案独一无二的"异格"，同行其余格互为副本。
- 各异格图案的上、下边缘行上分布着前景像素。

规则：
- 逐行找出异格，共得 R 个候选块。
- 当且仅当块 A 的下边缘与块 B 的上边缘在相同列位上共享前景像素时，允许
  A 紧邻放在 B 的上方。
- 全体候选块存在唯一一种自上而下的完整链接顺序；输出为按此顺序排列的单
  列格阵，格线保留。

关键洞察：
- 逐行挑异格只是筛选素材；输出顺序与原行序无关，由块与块的边缘咬合唯一
  决定——按原行序自上而下摆放是第一眼最自然的陷阱。
```

## 7. 隐锚对齐

- tags:
  - operation:循环平移, cyclic_shift
  - operation:对齐还原, align_restore
  - object:横带, horizontal_strip
  - object:隐锚像素, hidden_anchor
  - relation:频次唯一定锚, frequency_singleton_anchor
  - condition:对齐反解位移, alignment_solves_shift
- 参考题目题号: `6d1d5c90`, `38007db0`

### docstring

```text
找出每条横带中颜色仅出现一次的隐锚像素，循环平移各带使隐锚竖直对齐，还
原被打乱的整图。

输入结构：
- 分隔线把网格分成若干条等高的横带。
- 各带原本共同构成一幅画面，但除最上带外，每条带都被独立地做过水平循环
  平移。
- 每条带内恰有一个像素满足"其颜色在该带中仅出现一次"；它是该带的隐锚，
  且各带隐锚的颜色可以互不相同。

规则：
- 在每条带内找出颜色频次为一的那个像素。
- 最上带保持不动；其余每条带水平循环平移，使其隐锚与最上带隐锚落在同一
  列。
- 输出对齐后的整幅网格，分隔线与隐锚保持原色。

关键洞察：
- 平移量没有写在任何控制条里，锚也不是某种保留色——它要靠"带内颜色频
  次为一"这一统计特征识别；对齐隐锚等价于反解每条带的未知位移。
```
