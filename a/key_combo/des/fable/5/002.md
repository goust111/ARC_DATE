## 1. 遮挡链调色循环

- 参考题目：c920a713（交叉遮挡有向链）、9473c6fb（扫描序循环染色）
- tags:
  - operation:排序, sort
  - operation:重涂色, recolor
  - object:矩形边框, rect_frame
  - object:孤立像素, isolated_pixel
  - relation:遮挡顺序, occlusion_order
  - relation:扫描序, scan_order
  - condition:长轴决定扫描, longer_axis_determines_scan
  - condition:颜色循环分配, cyclic_color_assignment

### docstring

```text
从重叠矩形框的交叉遮挡关系解出唯一颜色链，再把散布的灰色标记按扫描序循环染成链上颜色。

输入结构
- 背景网格上有若干一像素粗、颜色互异的矩形框，彼此重叠；每处交叉只显示
  其中一框的颜色，记录"被遮者指向可见者"的有向关系。
- 框区之外散布若干孤立的灰色单像素标记，标记集合的外接矩形有明确的长轴。

规则
- 由每处交叉建立"被遮框→可见框"的有向边，求出恰好经过全部框色一次的
  唯一链，得到一个颜色序列。
- 矩形框区域原样保留。
- 若标记外接矩形高不小于宽则按行主序、否则按列主序排列全部灰色标记，
  依次循环涂成链序颜色。

关键洞察
- 重叠的框不需要被解开重画：它们是一张用遮挡关系书写的调色顺序表；
  每个灰色标记的输出色只取决于它在主扫描方向上的序号。
```

## 2. 边界锚点十字定位镜像盖章

- 参考题目：e734a0e8（分隔网格盖章）、581f7754（边界锚点定轴）、4e7e0eb9（轴线决定镜像）
- tags:
  - operation:印章覆盖, stamp_overlay
  - operation:镜像, mirror
  - object:分隔网格, separator_grid
  - object:模板图块, template_tile
  - object:边界锚点, border_anchor
  - relation:行列投影交点, row_column_intersection
  - relation:颜色匹配配对, color_match_pairing
  - condition:边缘位置决定翻转, edge_position_determines_flip

### docstring

```text
用边界上成对同色锚点的十字交点选定目标图块，把唯一的模板图块按锚点所在边决定的镜像方向盖入。

输入结构
- 网格最外一圈为背景色边环；边环内侧由整行整列的分隔色线划分成等大的
  矩形图块。
- 恰有一个图块含多色图案（模板），其余图块只有背景。
- 边环上有若干非背景锚点像素，同色锚点恰好成对：一枚位于上边或下边，
  另一枚位于左边或右边。

规则
- 每对锚点中，水平边上那枚的列落入某一图块列带，竖直边上那枚的行落入
  某一图块行带，两者交出的图块即该对的目标图块。
- 把模板复制进目标图块：若该对的水平边锚点位于下边则先做上下翻转，位
  于上边则不翻；若竖直边锚点位于右边则再做左右翻转，位于左边则不翻。
- 模板图块、分隔线、锚点全部保持不变。

关键洞察
- 放置坐标不写在图块内部，而由外部锚点对的行列投影交出；锚点靠在哪条
  边等价于"从哪一侧观看模板"，直接编码两个轴向的翻转。
```

## 3. 隐形波前推进形状循环

- 参考题目：221dfab4（贴边线段条纹推进）、a47bf94d（形状循环映射）、30f42897（等长周期重复）
- tags:
  - operation:形状变换, shape_transform
  - operation:计数, count
  - object:边界线段, border_segment
  - object:令牌, token
  - relation:距离周期计数, distance_period_count
  - condition:形状循环映射, shape_cycle_mapping
  - condition:线段跨度限界, segment_span_limits

### docstring

```text
贴边线段的长度定义一列看不见的等距波前，波前每越过一个令牌一次，就把它的形状沿"实心→X→菱形"循环推进一步。

输入结构
- 背景网格的某条边上贴着一段长度为 n 的实心单色线段（波源）。
- 内部散布若干 3×3 令牌，形状为实心方块、X 形或菱形（中心加四邻）之一，
  颜色互异。

规则
- 想象与波源平行的波前依次位于距波源边 n、2n、3n……处，且只存在于波源
  线段的行/列跨度以内。
- 每个中心落在跨度内的令牌，数出它与波源边之间严格经过的波前条数 k，
  就地把形状按实心→X→菱形→实心循环前进 k 步，颜色不变。
- 跨度之外的令牌与其余像素保持原样；波前本身不画出。

关键洞察
- 网格上从未画出任何条纹：波长藏在波源线段的长度里，令牌形状是它到波
  源距离的周期计数器，而波的横向作用范围被波源跨度截断。
```

## 4. 注满顶塞

- 参考题目：7acdf6d3（面积匹配装填）、52df9849（遮挡足迹）、271d71e2（推移与容量）
- tags:
  - operation:填充, fill
  - operation:平移, translate
  - operation:擦除, erase
  - object:轮廓对象, outline_object
  - object:遮挡塞子, occluding_plug
  - object:源像素集, source_pixel_set
  - relation:面积匹配, area_matching
  - relation:注色顶出, fill_ejects_plug
  - condition:完整内腔计数, full_cavity_count

### docstring

```text
为每组散点找到完整内腔恰好等于其数量的矩形框，注满整个内腔并把侵入的遮挡塞子沿原方向顶出框外。

输入结构
- 背景网格上有若干同色一像素粗的空心矩形框，框内腔大小各异。
- 若干实心异色小块（塞子）从外部压在某些框的边上，部分格子侵入内腔；
  每个塞子只从一个方向侵入。
- 另有若干组散点，每组一种颜色，散落在框外空地上。

规则
- 每个框的完整内腔 = 边框围出的全部内部格数（含被塞子占据的格）。
- 每组散点的像素数恰好等于唯一一个框的完整内腔：擦除该组散点，把该框
  内腔的所有格子（包括塞子侵入的格）涂成该组颜色。
- 被注色顶到的塞子沿它原来的侵入方向反向平移，移动到恰好完全退出内腔、
  重新紧贴框外侧为止；塞子形状与颜色不变。
- 未匹配到散点组的框及其塞子保持原样。

关键洞察
- 若按"剩余空位"配对会在两个框之间打成平手，正确的配对量是被塞子部分
  掩盖的完整内腔；注色是原因，塞子被顶出是结果，输出必须同时体现这两层。
```

## 5. 燃料尾迹排队靠泊

- 参考题目：271d71e2（能量上限步数）、581f7754（边界锚点滑动对齐）、538b439f（走廊改写）
- tags:
  - operation:滑动对齐, slide_to_align
  - operation:逐步消耗, incremental_consume
  - object:实心方块, solid_block
  - object:尾迹线段, trail_segment
  - object:边界锚点, border_anchor
  - relation:排队阻挡, queue_blocking
  - condition:燃料上限步数, fuel_caps_steps
  - condition:连锁泊位, chained_berth

### docstring

```text
同一直线上的方块依次朝边界锚点滑动靠泊，每前进一步烧掉一格尾迹，尾迹烧完就地抛锚并挡住后车。

输入结构
- 背景网格的一条边上有一枚锚点像素；锚点的投影线（同一行或同一列）上
  排着若干实心单色方块，全部位于锚点同侧。
- 每个方块背离锚点的一侧连着一条灰色尾迹线段，尾迹长度即其燃料格数。

规则
- 按离锚点由近到远逐个处理：方块朝锚点滑动，直到紧贴锚点所在边或紧贴
  前一个已停稳的方块（含其残余尾迹），设所需步数为 d。
- 若尾迹长度不小于 d，方块滑满 d 步并烧掉 d 格尾迹（尾迹从末端缩短，随
  方块整体平移）；否则只滑尾迹长度那么多步，尾迹烧光，就地停下。
- 后续方块以最近的已停对象为新障碍；所有被腾出的格子恢复背景。

关键洞察
- 尾迹不是装饰而是燃料表：停靠位置由"排队需求"与"燃料余量"取较小者
  决定，一辆车燃料不足抛锚，会连锁改变它后面所有车的泊位。
```

## 6. 边环配对隐形分区压缩

- 参考题目：996ec1f3（分区取主色压缩）、581f7754（边界锚点）、538b439f（忽略干扰项）
- tags:
  - operation:压缩, compress
  - operation:计数, count
  - object:边界锚点, border_anchor
  - object:隐形分隔线, invisible_separator
  - object:噪点区域, noisy_region
  - relation:颜色配对对齐, color_pair_alignment
  - relation:主色代表区域, dominant_per_region
  - condition:忽略干扰项, ignore_distractors
  - condition:配对数决定尺寸, pair_count_determines_size

### docstring

```text
由边界上同色且严格对齐的锚点对还原从未画出的分隔线，把噪点网格压缩成各分区主色的小图。

输入结构
- 网格内部铺满多色噪点。
- 最外圈边界上有若干非背景像素：真锚点两两同色，且同行（左右边各一枚）
  或同列（上下边各一枚）；另有少量没有对齐同色伙伴的落单像素。

规则
- 只认"同色且同行/同列"的边界像素对，每对定义一条贯穿网格的隐形直线；
  落单的边界像素忽略。
- k 条横线与 m 条竖线把内部划成 (k+1)×(m+1) 个矩形区域。
- 输出 (k+1)×(m+1) 网格，每格取对应区域中出现次数最多的噪点颜色；锚点
  与隐形线本身不进入输出。

关键洞察
- 分隔线在输入里一格也没画：它由边界像素的颜色配对与几何对齐共同指认，
  干扰像素恰恰缺少其中一个条件；连输出尺寸本身也要靠数出配对数才能确定。
```
