## 1. 遮挡深度定步的缺口平移

- 参考题目题号：2、8、18
- tags:
  - operation:平移, translate
  - operation:补全, reconstruct
  - operation:堆叠, stacking
  - object:空心矩形精灵, ring_sprite
  - object:框架缺口, frame_gap
  - object:遮挡碎片, occluded_fragment
  - relation:遮挡层序, occlusion_order
  - relation:深度编码位移, depth_encoded_disp
  - condition:缺口决定方向, gap_determines_direction

### docstring

```text
把每个空心矩形沿自己缺口的方向平移"压在它上面的矩形数"格，再以完整形态按原层序重绘。

输入结构：
- 背景为出现最多的颜色。
- 若干不同颜色的一像素厚空心矩形两两部分重叠，上层矩形遮住下层边框的部分像素。
- 每个矩形边框上恰有一个单像素缺口，缺口总位于未被遮挡的边段上。

规则：
- 由可见碎片还原每个完整矩形的位置与尺寸，并由"谁的颜色占据了谁的模板像素"
  推出唯一的自顶向下层序。
- 设某矩形上方共压着 k 个矩形（顶层 k=0），沿其中心指向缺口的方向把它平移 k 格。
- 在背景画布上按原层序自底向上重绘所有矩形的完整边框（补齐被遮挡像素），
  各自的缺口保留在边框上随之平移。

关键洞察：
- 平移距离没有画在任何地方：缺口只给方向，距离来自遮挡关系的拓扑深度，
  两条信息缺一不可；顶层矩形因此原地不动，成为核对层序的锚点。
```

## 2. 等价表指定供体的遮挡修复

- 参考题目题号：6、19
- tags:
  - operation:补全, complete
  - operation:形状匹配, shape_match
  - operation:查表, table_lookup
  - object:十字遮罩, cross_mask
  - object:等价表格, equivalence_table
  - object:边缘图例, edge_legend
  - relation:旋转翻转等价, dihedral_equiv
  - condition:表格指定供体, table_selects_donor
  - condition:碎片多解陷阱, fragment_ambiguity_trap

### docstring

```text
按等价表指定的伙伴形状，把被灰色十字遮住的残缺对象修复完整。

输入结构：
- 网格右缘自上而下列出各前景色的单像素图例。
- 左上角区域是一张已画好的表：行列按图例顺序排列，2x2 红块表示两形状在
  旋转翻转下等价，2x2 灰块表示不等价。
- 场景区有每种前景色各一个的单色对象，其中恰有一个对象的若干像素被
  颜色 8 的 3x3 十字遮罩盖住。

规则：
- 在表中读出与受损颜色等价（红格）的那一个颜色，取其对象为供体。
- 把供体形状经过某个旋转或翻转对齐到受损对象的可见像素上，
  唯一的对齐方式给出被遮部分。
- 输出仅把遮罩像素改回受损对象的颜色，其余一切保持不变。

关键洞察：
- 可见碎片故意与不止一个候选形状相容，逐个试拼会得到多解；
  表格里的红格是唯一可靠的供体指针，先查表后拼形才是正解。
```

## 3. 乱序三帧的时序重建与反弹外推

- 参考题目题号：5、11、15
- tags:
  - operation:平移, translate
  - operation:推断, infer
  - operation:排序, sort
  - object:分栏面板, panel
  - object:分隔列, divider_column
  - object:静止墙体, static_wall
  - relation:等差运动, uniform_motion
  - relation:面板即帧, panel_as_frame
  - condition:时间顺序需重建, frame_order_hidden
  - condition:碰撞反弹, collision_bounce

### docstring

```text
先找出唯一能让所有对象做匀速（含反弹）运动的面板时间顺序，再外推出第四帧。

输入结构：
- 网格由两条全高分隔列切成三个等宽面板；分隔色只出现在分隔列上。
- 每个面板含同一堵静止墙体（三面板位置相同）和若干运动的单色小对象。
- 面板的左右排列顺序不是时间顺序。

规则：
- 运动定律：每个对象有恒定位移向量；当下一步会与墙体或面板边界重叠时，
  位移中导致碰撞的分量反号（反弹），本步按反弹后的向量走。
- 在六种可能的时间排列中，恰有一种使所有对象同时满足该定律；
  至少一个对象在这三帧历史中已经历过一次反弹。
- 按该时间顺序取最后一帧再演化一步（含可能发生的新反弹），
  输出这个面板大小的第四帧：墙体原样保留。

关键洞察：
- 面板的空间顺序是诱饵，直接把左中右当作前后帧会得到自相矛盾的速度；
  反弹使速度不能靠任意两帧简单差分，必须找到令全体对象自洽的唯一时间排列，
  而反弹规则本身也只能从这段历史中读出。
```

## 4. 背景咬痕指令的选角擦除

- 参考题目题号：4、13
- tags:
  - operation:擦除, erase
  - operation:补全, complete
  - object:连通分量, connected_component
  - object:角落标记, corner_marker
  - object:局部包围盒, local_bbox
  - relation:相对自身定位, self_relative_pos
  - condition:洞的实格定角, solid_cell_selects_corner
  - condition:按对象局部裁切, local_bbox_crop

### docstring

```text
读出每个对象体内背景咬痕的朝向，擦掉该对象包围盒对应角上的两行两列，并补平咬痕。

输入结构：
- 一个主背景色，若干互不接触的单色 4 连通实心对象。
- 每个对象内部恰有一个 2x2 窗口，其中三格是背景（L 形洞）、
  一格仍是对象色。

规则：
- 2x2 窗口中仍为对象色的那一格位于窗口的某个角，该角指明对象包围盒的同名角。
- 在该对象自己的包围盒内，把靠该角最外的 2 行与最外 2 列中的对象像素擦为背景。
- 把 L 形洞的三格补回对象色；其余像素不动。

关键洞察：
- 洞不是残缺而是指令，读的是 2x2 里"实"的那一格而非三格空缺；
  擦除以每个对象自身的包围盒为坐标系，而洞在体内的位置与其朝向刻意无关。
```

## 5. 射线后继链的定向堆叠

- 参考题目题号：3、7、16
- tags:
  - operation:排序, sort
  - operation:堆叠, stack
  - operation:旋转, rotate
  - operation:射线延伸, ray_extend
  - object:矩形, rectangle
  - object:标记像素, marker_pixel
  - relation:射线定后继, ray_defines_successor
  - relation:指针链全序, pointer_chain_order
  - condition:标记边朝下, marker_side_down

### docstring

```text
沿标记像素射线构成的后继链给矩形排序，把每个矩形转到标记边朝下后自上而下堆叠。

输入结构：
- 背景加若干实心单色矩形。
- 每个矩形恰有一条边的中点外侧紧贴一个统一标记色的单像素。
- 从标记像素沿该边外法线方向发射的直线，击中的第一个矩形就是它的后继；
  恰有一个矩形不被任何射线击中（链头），恰有一个矩形的射线直达边界（链尾）。

规则：
- 从链头沿后继关系遍历，得到所有矩形的全序。
- 把每个矩形旋转到其标记像素所在边朝下的姿态（标记像素本身不画）。
- 按链序自上而下、水平居中堆叠：输出高为各矩形定向后高度之和，
  宽为其中最大宽度，空余处为背景。

关键洞察：
- 顺序不来自位置、尺寸或到轴线的距离，而来自射线构成的指针链；
  同一个标记像素同时回答"下一个是谁"和"这个矩形怎么转"两个问题。
```

## 6. 由残迹反推发射体

- 参考题目题号：16
- tags:
  - operation:绘制, drawing
  - operation:因果反演, causal_inversion
  - object:方向精灵体, directional_sprite
  - object:虚线射线, dotted_ray
  - object:染色边界, painted_edge
  - relation:质心偏移定向, centroid_bias_dir
  - condition:残迹重建来源, trace_reconstructs_source
  - condition:奇偶间隔定位, parity_spacing_locates

### docstring

```text
根据画面上残留的虚线射线与被染色的边界，反推并画出早已被擦除的方向精灵。

输入结构：
- 背景网格上只剩残迹：若干条隔一格取点的对角虚线（每条一种颜色），
  每条虚线指向的那条边界边被整条染成同色；两条染色边相邻时共享角为黑。
- 左上角一个孤立像素给出精灵的体色图例；发射体本身不在画面上。

规则：
- 染色边界指明每条虚线的走向；虚线远离染色边的那一端再外推一格
  即原标记像素位置（虚线点从标记旁一格开始隔一取点）。
- 在每个标记位置画回该虚线颜色的单像素，并在其背离射线的一侧
  按统一的七像素模板画体色精灵，姿态使体块质心偏在标记后方。
- 擦去所有虚线、染色边界与图例，输出中只保留还原的精灵们。

关键洞察：
- 画面上只有果没有因：射线与染色边是生成过程的残迹，解题需整个反演该过程——
  由染色边定向、由虚线端点与奇偶间隔定位、由射线方向定精灵姿态。
```
