## 1. 火种连锁弹射

- 参考题目题号：4 (3dc255db)、20 (95755ff2)、10 (71e489b6)
- tags:
  - operation:弹射, ejection
  - operation:连锁传播, chain_propagation
  - object:杯形框架, cup_frame
  - object:尾刺, tail_spike
  - object:火种像素, spark_pixel
  - relation:射程决定连锁, range_determines_chain
  - condition:像素数即弹药量, pixel_count_ammo
  - condition:未点燃者不变, unfired_unchanged

### docstring

```text
只有被火种点燃、或被别的弹射线击中尾刺的杯形框架才会发射，其余杯保持原样。

输入结构：
- 背景为占多数的颜色，画面中散布若干空心杯形框架，每个框架有唯一边框颜色。
- 每个杯一侧有会聚成单点的尾刺，另一侧开口，开口内部放着若干内容像素
  （每杯一种非边框颜色）。
- 画面中恰有一个孤立火种像素（全图唯一颜色），与某一个杯的尾刺八邻接。

规则：
- 与火种相邻的杯首先发射：清空其内容像素，从尾刺起沿尾刺朝向逐格画内容色
  像素，最多画"内容像素数"个，遇到任何非背景像素或出界即截断，剩余弹药丢弃。
- 若截断某条弹射线的像素恰是另一个杯的尾刺，则那个杯也随之发射，如此递归传播。
- 从未被击中且不与火种相邻的杯完全不变，其内容像素保留在杯内。

关键洞察：
- 内容像素数量是弹药量，决定射程，从而决定连锁能否够到下一个尾刺；
  输出取决于因果链传播多远，而不是把所有杯一律清空——只看单个示例会误以为
  "所有杯都发射"，弹药不足够不到下一杯的示例会击破这一错觉。
```

## 2. 碎影拼形

- 参考题目题号：13 (64efde09)、17 (7b3084d4)、5 (25e02866)
- tags:
  - operation:变换折返, transform_foldback
  - operation:叠加合成, overlay_merge
  - object:矩形精灵体, rectangular_sprite
  - object:疤痕像素, scar_pixel
  - object:干净副本, clean_copy
  - relation:二面体对应, dihedral_correspondence
  - condition:目标图形从未整体出现, target_never_drawn

### docstring

```text
把散布在各个旋转/镜像副本上的疤痕像素折回模板坐标，拼出从未整体出现过的图形。

输入结构：
- 背景为最常见颜色；画面散布若干实心矩形精灵体，都是同一个 R×C 模板经
  旋转/镜像得到的副本。
- 模板图案本身无任何旋转镜像对称，故每个副本的变换唯一可辨。
- 恰有一个副本与模板完全一致（干净副本）；其余每个副本上有若干格被统一
  疤痕色覆盖（疤痕色不在模板配色中），各副本疤痕位置互不相同。

规则：
- 以干净副本为基准确定模板图案与输出朝向。
- 对每个带疤副本，求它相对干净副本的旋转/镜像变换，把疤痕格坐标按逆变换
  折算回模板坐标。
- 输出 R×C 网格，全为背景色，仅在全部疤痕折回后的并集位置画疤痕色。

关键洞察：
- 疤痕不是要修掉的噪声，而是一幅被拆散、又随宿主副本各自旋转打乱的图形碎片；
  参与答案的图形从未被完整画出，必须先识别每个副本的二面体对应关系才能
  把碎片拼合成形。
```

## 3. 错位的镜像碎片

- 参考题目题号：8 (8e5c0c38)、5 (25e02866)
- tags:
  - operation:对称补全, symmetry_completion
  - operation:搬运, relocate
  - operation:重涂色, recolor
  - object:色层, color_layer
  - object:对称轴, symmetry_axis
  - object:游离像素, stray_pixel
  - relation:跨色咬合, cross_color_interlock
  - condition:轴从未画出, axis_never_drawn

### docstring

```text
每种颜色图案中破坏对称的"噪点"其实是另一种颜色图案缺失像素的错色错位副本，
需将其镜像折返、改色补洞并从原处删除。

输入结构：
- 背景占多数；若干种非背景颜色各自形成一片近似左右对称的图案，
  各色竖直对称轴列互不相同且从未画出。
- 每种颜色图案缺失若干像素（轴一侧有像素、另一侧对应位置空缺）。
- 同时每种颜色混有少量无镜像伙伴的游离像素。

规则：
- 对每种颜色找出最能解释其像素布局的竖直镜像轴。
- 无镜像伙伴的游离像素为待搬运件；轴侧空缺为待补洞。
- 每个游离像素按"它自己颜色的轴"镜像折返后，恰好落在某个其他颜色图案的
  空缺位置上；将该位置补上空缺图案自身的颜色。
- 游离像素原位置清为背景。

关键洞察：
- 第一印象是"逐色去噪+对称补全"两件独立小事，实则所有颜色通过游离像素
  互相咬合——A 色的垃圾是 B 色的补丁，且搬运路线由 A 自己的隐形轴决定、
  落点着色由 B 图案决定，任何单色内部都解释不通。
```

## 4. 链式密码本

- 参考题目题号：11 (2d0172a1)、2 (5adee1b2)、19 (a834deea)
- tags:
  - operation:重涂色, recolor
  - operation:擦除, erase
  - object:嵌套框架, nested_frame
  - object:线性链, linear_chain
  - relation:包含树, containment_tree
  - relation:深度映射颜色, depth_to_color
  - condition:图例伪装成场景, legend_disguised

### docstring

```text
找到唯一一条每层只含一个孩子的嵌套链作为密码本，用"深度→颜色"重涂其余
所有框架，并抹去密码本本身。

输入结构：
- 背景占多数；前景由若干闭合矩形框（最内层可为实心小块）组成，
  彼此存在包含关系，形成若干棵包含树。
- 恰有一棵是严格线性链：每个框内只有一个直接孩子，最内层是实心小块，
  链上各层颜色互不相同。
- 其余包含树至少在某一层分叉，框颜色杂乱无规律。

规则：
- 求全部前景对象的包含树。
- 识别唯一严格线性链作为密码本，链上第 d 层（最外为 1）颜色记为 C(d)。
- 其余每个框按它在自己那棵树中的深度 d 重涂为 C(d)，形状与位置不变。
- 输出中把密码本链整条抹为背景。

关键洞察：
- 图例没放在网格边缘，而是伪装成场景中一个普通嵌套结构，必须靠
  "每层恰一子"这一拓扑特征才能把它从诱饵树里挑出来；框的尺寸与原色
  都是诱饵，唯一有效的键是包含深度。
```

## 5. 门位定档

- 参考题目题号：12 (3ad05f52)、18 (aaef0977)
- tags:
  - operation:寻路, pathfinding
  - operation:循环变色, cyclic_recolor
  - object:薄墙, thin_wall
  - object:门洞, door_gap
  - object:端点, endpoint
  - relation:拓扑事件计数, topological_event_count
  - condition:门位偏侧定极性, door_offset_polarity
  - condition:循环色板, cyclic_palette

### docstring

```text
沿两端点间唯一最短通路涂色，穿过每个门洞时依据门洞在那道墙上的偏侧位置
决定色环进档还是退档。

输入结构：
- 背景占多数；一种墙色构成若干道横竖薄墙，把画面分隔成一串房间；
  每道墙恰有一个一格宽门洞，门洞位置有的偏墙的一端、有的偏另一端。
- 起点像素带颜色（属于固定色环 红→黄→绿→蓝→红），终点是一个无色标记框；
  布局保证两者间最短四连通路径唯一。

规则：
- 视墙格为不可通行，找起终点间唯一最短四连通路径。
- 从起点色开始沿路径涂色。
- 每穿过一个门洞格（该格沿墙走向的两侧均为墙格）：若门洞位于该墙按自身
  走向坐标较小的一半，色环正向进一档，否则反向退一档，自穿门后的下一格生效。
- 一路涂到终点框内部，墙与门洞保持不变。

关键洞察：
- 两重隐蔽入口——颜色变化计的是穿门这一拓扑事件而非步数
  （门与门间距不等的示例使"等距变色"的第一印象失效）；
  进/退方向又编码在门洞相对墙体的偏侧位置里，
  必须把每扇门看成带极性的开关而不是普通通道。
```

## 6. 相位错动的壁纸

- 参考题目题号：9 (6cbe9eb8)、14 (df9fd884)、16 (8b9c3697)
- tags:
  - operation:平移复位, translate_restore
  - operation:周期外推, periodic_extrapolate
  - object:壁纸背景, wallpaper_bg
  - object:滑块, slider_block
  - object:相位错动带, phase_shift_band
  - relation:二阶特征即痕迹, second_order_trace
  - condition:因果反演, cause_effect_inversion

### docstring

```text
画面里没有画出任何拖痕，滑块推过的区域只表现为壁纸相位的错动带，
需识别错动带、把滑块退回带的远端并将带内壁纸相位复原。

输入结构：
- 整幅背景是双色周期壁纸（横竖均以固定小周期重复）。
- 若干实心矩形滑块（非壁纸配色）散布其上。
- 每个滑块一侧的等宽条带内，壁纸花纹本身完整，但相位相对周围错开一个
  固定偏移；条带远端与周围正常壁纸的缝合线即滑块的出发位置。

规则：
- 对每个滑块找出与其等宽、相位错动的壁纸条带；条带延伸方向即滑块
  被推动方向的反方向。
- 把滑块平移到条带远端（错动带与正常壁纸的缝合线处）。
- 滑块原位置与整条错动带内的壁纸，全部按周围正常壁纸的周期相位
  重新外推补齐，严丝合缝。

关键洞察：
- 运动痕迹从未被显式画出，唯一证据是壁纸相位这种"二阶特征"的局部不一致；
  解题者必须先发现看似完好的壁纸里藏着错位带，才能由果推因重建事前状态；
  修补不是涂底色，而是按周期外推花纹。
```

## 7. 孔洞配数、姿态随簇的印章

- 参考题目题号：6 (dfadab01)、3 (902510d5)、17 (7b3084d4)
- tags:
  - operation:图案印章, stamp_glyph
  - operation:计数, count
  - operation:旋转, rotate
  - object:字形字典, glyph_dictionary
  - object:点簇, dot_cluster
  - object:封闭孔洞, enclosed_hole
  - object:基准件, reference_piece
  - relation:属性等式配对, attribute_equality_pairing
  - condition:颜色是诱饵, color_is_decoy

### docstring

```text
无标注图例中的字形按"封闭孔洞数=点簇像素数"被选中，再按点簇自身的旋转姿态
旋转后以簇色盖章。

输入结构：
- 黑背景；网格一侧的图例区摆着若干 4×4 字形样例（统一图例色，形状互不相同
  且无旋转对称，各含 0~4 个不等的封闭孔洞，无任何计数或颜色标注）。
- 图例区旁有唯一一枚游离的灰色小形，标示基准朝向。
- 场景区散布若干点簇（每簇一种颜色，八连通）；每个点簇都是同一个无旋转对称
  的基准小形经 0°/90°/180°/270° 旋转的副本，再被增删至不同像素数（2~5 像素），
  增删后仍能唯一辨认其旋转姿态。
- 不同簇可同色不同数、异色同数。

规则：
- 数出每个字形的封闭孔洞数 k 与每个点簇的像素数 n；点簇匹配 k=n 的字形。
- 将该字形按此簇相对灰色基准件的旋转角旋转。
- 以簇包围盒左上角为锚点、用簇自身颜色绘制旋转后的字形，原点簇抹去。
- 图例区（含灰色基准件）全部清空。

关键洞察：
- 三重隐键互相咬合——颜色是纯诱饵（同色不同形、异色同形的示例击破"颜色选形"）；
  字形选择键是"簇像素数=字形孔洞数"这一无任何标注的跨对象属性等式；
  字形姿态又不由图例决定，而由每个簇残缺形状中读出的旋转角决定，
  旋转的零点藏在图例旁那枚不起眼的灰色基准件里。
```

## 8. 棋盘密钥小径

- 参考题目题号：1 (9ba4a9aa)、7 (c61be7dc)
- tags:
  - operation:路径追踪, path_follow
  - operation:裁剪, crop
  - object:棋盘格, checkerboard
  - object:环形物体, ring_object
  - object:引导像素, guide_pixel
  - relation:交替密钥校验, alternation_key_check
  - condition:同色诱饵分支, same_color_decoy_branch

### docstring

```text
从双色棋盘格源出发，只有颜色严格按棋盘两色交替的引导链才是真路，
沿真路走到底输出它指向的环形物体。

输入结构：
- 背景占多数；一个 3×3 双色棋盘格对象（源）、若干 3×3 环形物体（候选）、
  大量落在两格点阵上的引导像素。
- 引导像素只使用棋盘那两种颜色；链条存在分叉，有的分支上出现连续同色
  的相邻步。

规则：
- 从源出发，第一步引导像素颜色必须等于源棋盘左上角的颜色，
  此后每一步颜色必须与上一步严格交替。
- 分叉处淘汰违反交替律的分支；合法链唯一，延伸至某个环形物体旁。
- 输出该环形物体的 3×3 裁剪。

关键洞察：
- 路径合法性不由连通性决定，而由源对象自带的双色交替密钥校验；
  只看连通性会被同色诱饵分支带进死胡同，源棋盘的左上角颜色还悄悄
  规定了整条密钥序列的起始相位。
```
