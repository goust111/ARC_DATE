## 1. 叠层旋钮

- 参考题目题号: 68bc2e87, 1a244afd, 7ed72f31
- tags:
  - operation:层序推断, occlusion_order_inference
  - operation:旋转, rotate
  - object:空心矩形, hollow_rectangle
  - object:枢轴像素, pivot_pixel
  - object:精灵体, sprite
  - relation:层深编码转角, depth_encodes_rotation
  - condition:重叠定先后, overlap_determines

### docstring

```text
由重叠边框的遮挡层序算出每种颜色的"深度"，再让同色精灵绕枢轴逆时针旋转深度次。

输入结构：
- 黑色背景。画面一侧是若干一格厚、颜色互不相同的空心矩形框，两两部分重叠，
  重叠格上只显示最上层框的颜色。
- 画面另一侧，每种框色各有一个不对称的小精灵，紧邻处有一个灰色枢轴像素。

规则：
- 先按每种框色可见像素的外接矩形还原完整边框，再利用"重叠格可见者在上"的
  约束恢复自底向上的唯一层序；最底层深度记 0，向上依次 1、2……
- 每个精灵绕其灰色枢轴逆时针旋转 90° × (同色框的层深)，深度为 0 的精灵不动；
  旋转时保持各像素到枢轴的偏移长度不变，枢轴自身不动。
- 边框区域按输入原样保留。

关键洞察：
- 重叠的边框不是待输出的对象而是一组计数器：遮挡层序给出每种颜色的整数深度，
  这个序数才是旋转步数；框被遮住的部分无需看见，可见外接矩形加逐格的
  "谁压住谁"约束已唯一确定全部层序。
```

## 2. 投影印章

- 参考题目题号: edcc2ff0, 9344f635, 67e490f4, b10624e5
- tags:

  - operation:定位, locate
  - operation:印章放置, stamp
  - operation:擦除, erase
  - object:边缘直方条, margin_histogram_bar
  - object:精灵体, sprite
  - relation:行列投影为键, projection_as_key
  - condition:忽略干扰项, ignore_distractors
  - condition:线索一线两用, clue_dual_use

### docstring

```text
边缘的灰色堆叠条是某个精灵的逐行逐列像素投影，用它在干扰项中选出唯一匹配的
精灵，并盖印到条带标出的交汇区域。

输入结构：
- 网格分为主画布与上、左两条边缘刻度区，边缘区与画布之间以一条分隔色隔开。
- 上边缘若干列自上而下堆叠灰色像素柱，左边缘若干行自左而右堆叠灰色像素条。
- 主画布黑色背景上散布数个形状互异的单色精灵。

规则：
- 上边缘第 c 列灰柱的高度等于目标精灵落位后画布第 c 列的像素数，左边缘第 r 行
  灰条的长度等于落位后第 r 行的像素数。
- 在候选精灵中找出行投影与列投影同时与两组直方条吻合（允许整体平移）的唯一
  精灵，把它的外接矩形平移到非零灰柱列区间与非零灰条行区间的交汇矩形处。
- 其余精灵、原位置的目标精灵以及全部灰条与分隔线抹去，输出只剩落位后的画布。

关键洞察：
- 灰条一线两用：作为数值，它是目标形状的行列像素计数直方图，用来在干扰精灵
  中完成"看投影认形状"的辨认；作为位置，非零条所在的行列直接圈定落点。
```

## 3. 先小后大的四向滑动

- 参考题目题号: 5034a0b5, 17829a00, 4df5b0ae
- tags:
  - operation:滑动, slide
  - operation:排序, sort
  - object:边框边, frame_side
  - object:单色对象, monochrome_object
  - relation:颜色匹配边, color_match_side
  - relation:面积定次序, area_determines_sequence
  - condition:碰撞停止, collision_stop
  - condition:顺序改变结果, order_changes_outcome

### docstring

```text
内部对象按面积从小到大逐个向同色边框边滑动，先落位者成为后来者的障碍。

输入结构：
- 网格四周是一格厚边框：四角为背景色，四条边各为一种互不相同的实色。
- 内部散布若干面积互不相同的单色 4 连通对象，每个对象的颜色与某条边一致。

规则：
- 对象一次只动一个，按像素面积从小到大排队执行。
- 轮到的对象沿指向同色边的方向整体直线滑动，直到贴上该边、或撞上任何静止
  像素（含已滑完停稳的对象）的前一格为止。
- 全部对象滑完即为输出，边框保持不变。

关键洞察：
- 这不是同时滑动：面积序列是一条隐藏的时间轴，先落位的小对象会改变后来大
  对象的停点。若按"各对象独立滑到边"处理，会在路径交叉的示例上得到错误答案，
  且部分示例恰好与同时滑动一致，是刻意埋下的诱饵。
```

## 4. 缺镜的光路

- 参考题目题号: 7e2bad24, 7b80bb43
- tags:

  - object:对角射线轨迹, diagonal_ray_trace
  - object:反射镜段, mirror_segment
  - object:干扰彩条, distractor_bar
  - relation:拐折反推镜子, corner_implies_mirror
  - condition:生成元未被画出, generator_never_drawn
  - condition:忽略干扰项, ignore_distractors

### docstring

```text
由残缺的对角光路反推物理过程：补全轨迹缺口，并放回被擦掉的红色镜子。

输入结构：
- 黑色背景上有一条蓝色 8 连通对角折线，是某条射线走过的轨迹，但轨迹上有
  若干段缺口；轨迹的转折点处本应各有一段红色镜子，其中大多数已被擦除，
  仅个别保留作为样例。
- 画面另有几根横竖彩色直条，射线曾直穿其中一些（被穿过处已显蓝色）。

规则：
- 按"射线沿对角直线前进、遇红镜翻转一个坐标方向"的物理规则重放光路，
  把所有缺口补成蓝色，缺口的走向由两侧线段的对角方向唯一接续确定。
- 在每个没有现存镜子的转折点补画红镜：翻转行方向的转折补水平镜段，翻转
  列方向的转折补垂直镜段，镜段落在转折点沿原前进方向的下一格位置。
- 干扰彩条与保留的红镜原样不动。

关键洞察：
- 参与规则的镜子几乎从未被画出，画面上只有它们造成的拐折残迹；每处拐折
  翻转的是行还是列坐标，唯一决定所补镜子的朝向与位置。彩条上的蓝色穿孔
  恰是反证：能被直穿的条不是反射体，只有红色才是镜子。
```

## 5. 格间接力

- 参考题目题号: 18286ef8, 458e3a53, 68bc2e87
- tags:
  - operation:定位, locate
  - operation:链式追踪, chain_trace
  - operation:提取, extract
  - object:分隔线网格, separator_lattice
  - object:控制像素, control_pixel
  - relation:格内方位编码方向, position_encodes_direction
  - condition:无人指向者为起点, unpointed_is_start
  - condition:颜色是干扰身份, color_is_decoy

### docstring

```text
把分隔线网格里每格的偏心像素读作指向邻格的箭头，从无人指向的起点格开始
接力追踪，按访问顺序输出沿途颜色。

输入结构：
- 网格被整行整列的分隔色划分成规则格阵，每个格子内部恰有一个彩色像素，
  不同格子的像素颜色可以重复。
- 每格像素落在格子内部九宫方位之一：偏上、偏下、偏左、偏右、四个角落
  或正中。

规则：
- 一格像素相对本格中心的方位是一支箭头，指向相邻（含对角）方向的下一格；
  正中方位表示链的终点，走到此格即停。
- 起点是格阵中唯一没有被任何箭头指到的格子。从起点出发沿箭头逐格接力，
  直至到达正中方位的终点格。
- 输出一个单列网格：自上而下依次为链上各格像素的颜色，起点色在最上，
  终点色在最下；不在链上的格子不参与输出。

关键洞察：
- 像素的颜色全是干扰身份，真正的指令藏在"像素在格内的相对方位"这一几何
  残迹中；链条的入口没有任何显式标记，只能由"哪一格不被任何箭头指到"
  反向排查得出，之后顺链走完才能确定输出的颜色次序。
```

## 6. 形状即颜色

- 参考题目题号: 42f83767, 67e490f4
- tags:
  - operation:反向解码, inverse_decode
  - operation:重涂色, recolor
  - object:色卡, color_swatch
  - object:模板遮罩, stencil_mask
  - object:分块网格, block_partition_grid
  - relation:形状到颜色映射, shape_to_color_map
  - condition:旋转翻转不变, rotation_flip_invariant
  - condition:块色为诱饵, block_color_is_decoy

### docstring

```text
把由模板形状拼成的大网格反向压缩为索引小图：每块的输出颜色由其形状对应的
色卡决定，块自身绘制的颜色是系统性诱饵。

输入结构：
- 上方图例从左到右排列若干对"2×2 色卡 + 方形模板遮罩"，按顺序一一配对；
  各模板形状在允许旋转翻转的意义下互不相同。
- 空行之下是被均匀划分为同尺寸方块的大网格：每个非空方块内画着某个模板形状
  的任意旋转或翻转版本，且各方块的绘制颜色五花八门、与图例色卡无关。

规则：
- 对大网格的每个方块，忽略其绘制颜色，将其形状在允许旋转和翻转的前提下与
  图例模板匹配。
- 输出网格把每个方块压缩为一个像素：颜色取匹配模板所配色卡的颜色；空方块
  压缩为背景色像素。

关键洞察：
- 这是"逐像素展开"类题目的因果反演：信息藏在形状而非颜色里。方块上鲜艳的
  绘制颜色专门诱导"输出即块色"的第一直觉，只有做旋转翻转不变的形状识别，
  才能连回图例把形状翻译成色卡颜色。
```
