## 1. 信标吊装

- 参考题目题号: 17(中心投影), 8(重力下落与堆叠), 7(尺寸排名), 1(排序选择)
- tags:
  - operation:重力下落, gravity_drop
  - operation:排序, sorting
  - operation:计数, counting
  - object:图例对象, legend_object
  - object:信标像素, beacon_pixel
  - relation:尺寸排名配对, size_rank_pairing
  - relation:中心对齐, center_alignment
  - condition:先落为基后落叠上, landing_order_stacking

### docstring

```text
把散布的灰色对象按"像素数排名对应信标次序"吊运到底边信标列上方，依次落下并互相堆叠。

输入结构
- 黑色背景上散布若干个互不相触的灰色对象，各对象的像素数互不相同。
- 底行有与对象数量相同的黄色信标像素，位于互不相同的列。
- 除对象与信标外全部为背景。

规则
- 将对象按像素数从多到少排名，将信标按列从左到右排序，第 k 名对象
  分配给第 k 个信标。
- 按信标从左到右的次序依次处理：把对象平移，使其包围盒的中心列对准
  信标列，再让它竖直下落，落到底行上一行或已落对象之上（正下方任一
  格被占即停）。
- 对象原位置清空，底行信标保留。

关键洞察
- 信标同时编码三件事：目标列、与对象的配对（排名对次序的匹配，而非
  距离或颜色的匹配）、以及下落的先后；当相邻信标列间距小于对象宽度
  时，先落的对象会成为后落对象的地基，配对或次序判断错误都会得到不
  同的堆叠结果。
```

## 2. 位置操作码

- 参考题目题号: 2(标记像素双重角色), 9(角与边中分组), 11(轴线决定变换)
- tags:
  - operation:镜像, mirror
  - object:前景对象, foreground_object
  - object:标记像素, marker_pixel
  - relation:角与边中分组, corner_side_group
  - condition:标记位置编码镜像轴, marker_position_encodes_axis

### docstring

```text
按每个对象内部黄色标记所在包围盒位置的类别与方位，对该对象施加对应轴向的翻转。

输入结构
- 黑色背景上散布若干互不相触的单色非对称对象，各对象的紧包围盒为
  边长为奇数的正方形。
- 每个对象的紧包围盒内恰有一个黄色标记像素，位于包围盒的四个角格
  或四条边的中点格之一，且该格不属于对象本体。

规则
- 标记在边中点格：把对象在其包围盒内沿垂直于该边的方向翻转（上边
  或下边的中点对应上下翻转，左边或右边的中点对应左右翻转）。
- 标记在角格：把对象在其包围盒内沿经过该角的对角线翻转（左上、右
  下角对应主对角线，右上、左下角对应反对角线）。
- 翻转后删除标记像素，背景与其他内容不变。

关键洞察
- 黄色像素是一枚"操作码"：它相对包围盒的位置类别（角/边中）选择镜
  像轴的族（对角轴/正轴），具体位置再选出族内哪一条轴，一颗像素同
  时编码操作类型与操作参数。
```

## 3. 后继指针

- 参考题目题号: 6(色带整块重排与标记像素), 5(颜色对应), 4(隐藏结构决定排序)
- tags:
  - operation:排序, sort
  - object:色带, color_stripe
  - object:杂色像素, foreign_pixel
  - relation:后继指针链, successor_chain
  - condition:整带移动保持内容, block_move_intact

### docstring

```text
把每条竖直色带内的杂色像素读作"后继指针"，按拼出的链条重排所有色带。

输入结构
- 网格由若干等宽的竖直色带并列组成，每带有唯一的主色。
- 除一条完全纯净的带外，每条带内部散布若干个同一种其他带主色的像素
  （杂色）；每种主色至多在一条带中作为杂色出现。

规则
- 带 A 内的杂色为颜色 B，表示输出中 B 带应紧跟在 A 带右侧。
- 全部指针恰好拼成一条覆盖所有带的单链；链首是主色未作为任何杂色出
  现的那条带，纯净带没有出指针，是链的末端。
- 按链序从左到右重排各带；每条带连同其内部杂色像素整体平移，内容不变。

关键洞察
- 杂色既不是要清除的噪声，也不是计数或高度那样的排序键，而是指向后
  继的单向指针；纯净带不是"最干净"而是链的终点，最终顺序由链接关系
  而非任何数值大小决定。
```

## 4. 接力点火

- 参考题目题号: 9(3x3环与角边分组), 19(角位几何特征分类), 8(移动与阻挡), 14(标记指示方位)
- tags:
  - operation:平移, translate
  - object:环形对象, ring_object
  - object:缺口格, gap_cell
  - object:火花像素, spark_pixel
  - relation:缺口方位定向, gap_encodes_direction
  - relation:碰撞接力, collision_relay
  - condition:逐棒传递直至撞墙, chain_until_wall

### docstring

```text
红色火花点燃它所贴靠的环，被点燃的环沿自身缺口的反方向飞行，撞上谁就点燃谁，接力直到有环撞墙停下。

输入结构
- 黑色背景上散布若干单色 3x3 环形对象：中心为背景，环上八格恰缺一
  格（缺口可在角格或边中格）。
- 恰有一个红色火花像素与其中一个环的外侧四邻接，其余为背景。

规则
- 被点燃的环沿"缺口相对环心方向"的反方向逐格滑行；若下一步将与另
  一个环重叠，则停下并点燃被撞的环，被撞环再按它自己的缺口反方向飞
  行，依此接力。
- 若滑行前方是网格边界，则滑到贴住边界停下，连锁终止。
- 任意时刻只有一个环在动；未被点燃的环保持原位；红色火花在输出中消失。

关键洞察
- 运动不是同时的、也不是统一方向的重力，而是一条由碰撞逐棒传递的接
  力链；每一棒的方向由被点燃环自己的缺口决定——缺口是"喷口"，环朝
  缺口反方向推进——火花只标记第一棒，静止环既是潜在障碍又是潜在的
  下一棒，终局布局沿因果链涌现。
```

## 5. 残迹回溯与修复

- 参考题目题号: 8(对象移动), 16(折线路径), 15(平移对称修复), 14(标记指示方位)
- tags:
  - operation:平移, translate
  - operation:补全, inpaint
  - operation:擦除, erase
  - object:可动对象, movable_object
  - object:灰色残迹, grey_trail
  - object:周期瓦片, periodic_tile
  - relation:残迹端点定位, trail_endpoint_target
  - relation:平移对称, translational_symmetry
  - condition:腾出格按轨道修复, vacated_cells_restored_by_orbit

### docstring

```text
把每个对象沿其灰色残迹送回残迹远端的出发点，再用图案的平移对称性修复残迹与对象腾出的格子。

输入结构
- 背景是一幅具有平移周期的多色图案。
- 图案上叠放着若干单色对象（颜色不属于图案调色板）与一格宽的灰色折
  线残迹，每条残迹的一端与一个对象四邻接。

规则
- 对每个对象，设其与残迹相邻的对象格为锚点，沿残迹从近端走到另一端，
  把对象整体平移，使锚点落在残迹远端端点格上。
- 随后所有灰色残迹格与对象腾出的格子，按可见图案的平移对称轨道填回
  图案应有的颜色；对象在新位置继续覆盖图案。

关键洞察
- 灰线不是障碍、墙或要描的线，而是对象的运动残迹——答案是因果反演，
  对象退回出发地；被覆盖处的图案从未完整画出，必须由可见部分的平移
  轨道逐格推断；两个机制互相咬合：残迹的形状只有端点承重（拐折淘汰
  "沿直线射出"的假设），而腾出格子的正确颜色由周期性唯一确定。
```

## 6. 分隔线流水线

- 参考题目题号: 2(分隔线与瓦片分区), 11(颜色决定变换), 10(镜像), 12(布局分区)
- tags:
  - operation:镜像, mirror
  - operation:复制, copy
  - object:瓦片, tile
  - object:彩色分隔线, colored_separator
  - relation:分隔线编码变换, separator_encodes_op
  - condition:沿链逐级复合, compose_along_chain

### docstring

```text
沿瓦片链逐段执行分隔线颜色所编码的变换，把链首瓦片的图案传播到所有空瓦片。

输入结构
- 网格是一行 N 个等大的正方形瓦片，相邻瓦片之间由一条一格宽的单色
  竖直分隔线隔开。
- 只有最左侧瓦片内有图案，其余瓦片全为背景。
- 分隔线颜色取自一个小的固定集合，同一颜色在所有示例中代表同一种变换。

规则
- 从左到右逐段推进：右侧瓦片的内容等于对左侧相邻瓦片的当前内容施加
  两者之间分隔线颜色所对应的变换（如左右翻转、上下翻转、旋转 180 度、
  原样复制——具体对应关系由训练示例给出）。
- 分隔线本身原样保留。

关键洞察
- 分隔线不是布局装饰而是一串指令，瓦片是流水线上的中间状态：第 k 块
  瓦片承载的是前 k-1 个变换的复合结果。只含一条分隔线的示例教会每个
  操作码的含义，而多条分隔线的示例淘汰"每块瓦片都由首瓦片一步变换而
  来"的错误假设。
```

## 7. 跨尺度盖印

- 参考题目题号: 3(孔洞形状配对), 13(整数倍逐格放大), 5(形状图例), 2(标记像素)
- tags:
  - operation:填充, fill
  - operation:形状匹配, shape_matching
  - operation:像素放大, pixel_scaling
  - object:模板, template
  - object:封闭孔洞, enclosed_hole
  - object:标记像素, marker_pixel
  - relation:跨尺度形状对应, cross_scale_correspondence
  - condition:失配孔洞排除法归属, leftover_hole_by_elimination

### docstring

```text
把右侧小对象按整数倍放大后盖印进左侧与之形状匹配的孔洞，剩下唯一失配的孔洞由排除法用唯一未使用对象的主色填实。

输入结构
- 网格分为左右两个面板：左面板是一块单色模板，内含若干互不连通的背
  景孔洞；右面板在背景上散布若干小对象，每个对象主色单一且内部恰有
  一个异色标记像素。
- 除一个孔洞外，每个孔洞的掩码恰等于唯一一个对象的掩码（含标记格）
  按 1 倍或 2 倍逐格放大的结果；恰有一个孔洞不匹配任何对象、恰有一
  个对象不匹配任何孔洞。

规则
- 匹配的孔洞：按该倍率把对象连同其标记像素逐格放大后盖印进孔洞，标
  记放大为同倍见方的色块。
- 失配的孔洞：用唯一未被使用对象的主色填实。
- 输出仅保留处理后的左面板。

关键洞察
- 配对以跨尺度的精确逐格放大判定，倍率逐孔各异，"同大小比对"与"取
  色填充"两个直觉假设都会失败——孔洞里要印入放大后的双色图案而非纯
  色；最后一个孔洞没有任何形状证据，只能靠"每个对象恰用一次"的全局
  守恒用排除法补上。
```
