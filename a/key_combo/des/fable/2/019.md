## 1. 颜色指针循环搬位

- tags:
  - operation:搬移, relocate
  - object:轮廓, outline
  - object:标记像素, marker_pixel
  - relation:颜色指针, color_pointer
  - relation:循环置换, cyclic_permutation
  - condition:同时搬动, simultaneous_move
- 参考题目题号: dc2e9a9d, 2601afb7, 247ef758

### docstring

```text
把每个空心形状整体搬到"其内部圆点颜色所指向的形状"的原位置，所有搬动同时发生。

输入结构
- 黑色背景上有若干互不接触的单色空心形状，轮廓颜色互不相同。
- 每个形状内部恰有一个圆点像素，圆点颜色等于场上另一形状（或自身）的轮廓颜色。
- 圆点颜色构成轮廓颜色集合上的一个置换（每种轮廓颜色恰被一个圆点指向）。

规则
- 对每个形状，找到轮廓颜色等于其圆点颜色的目标形状。
- 将该形状（轮廓与圆点一起，颜色不变）平移，使其包围盒左上角落在目标形状原包围盒的左上角处。
- 所有形状按输入中的位置同时结算；圆点指向自身轮廓色的形状留在原地。

关键洞察
- 圆点不是要涂的颜色而是"地址"：颜色匹配定义了一张置换图，形状沿置换环同时换位，位置信息全部来自输入快照，而不是逐个搬动后的中间局面。
```

## 2. 模板自指印章

- tags:
  - operation:印章覆盖, stamp_overlay
  - operation:重涂色, recolor
  - object:分隔网格, divider_grid
  - object:模板掩码, template_mask
  - object:行标记, row_marker
  - relation:自指放置, self_referential_placement
  - relation:行调色板, row_palette
- 参考题目题号: 5a5a2103, 8f2ea7aa

### docstring

```text
用唯一模板的自身前景分布决定要盖章的网格单元，并按各行标记色重涂后盖入。

输入结构
- 背景为主色；一种颜色画满横竖分隔线，把画面分成 m 行 n 列等大的单元，每个单元内部恰为 m×n 像素。
- 分隔网格左侧外沿有一列行标记像素，每个单元行对应一个颜色。
- 恰有一个单元内含单色模板掩码，其余单元为空。

规则
- 读取模板掩码（m×n 布尔图案）。
- 清空所有单元内部（含模板所在单元）。
- 对模板掩码中每个前景位置 (i,j)，把整幅模板图案以第 i 行的标记色盖入第 i 行第 j 列的单元。
- 分隔线与行标记保持不变。

关键洞察
- 模板一身两职：既是被复制的印章，又是"往哪些单元盖章"的放置掩码；哪个单元收到印章与场上原有内容无关，颜色由行调色板给出而非模板本色。
```

## 3. 接力推移

- tags:
  - operation:滑动, slide
  - object:标记像素, marker_pixel
  - object:单色段, mono_segment
  - relation:接触传递, contact_relay
  - relation:排列顺序, ordering
  - condition:末段抵墙, last_hits_wall
- 参考题目题号: 55783887, 8e301a54, 4364c1c4

### docstring

```text
边缘标记沿其行/列发出推动，段与段之间以"碰到即停、被碰者接着滑"的接力方式传递运动。

输入结构
- 背景网格的部分边缘格上有标记像素，每个标记独占一行或一列，表示沿该行/列向网格内部推动。
- 被标记的行/列中散布着一个或多个互不接触的单色段。

规则
- 在每条被标记的行/列内，按离标记由近到远给段编号。
- 第一段沿推动方向滑动，直到与第二段（按其输入位置）相邻即停；随后第二段开始滑动，直到与第三段的输入位置相邻即停；依此接力。
- 最后一段一直滑到网格边缘贴墙；未被标记的行/列保持不变。

关键洞察
- 运动是碰撞传递而非整体压实：每一段停在其后继段的原位置旁，只有最后一段贴墙；单段的示例看起来像"推到墙"，多段局面会暴露真规则——输出中段与段之间留下由原布局决定的空隙。
```

## 4. 说谎标签

- tags:
  - operation:图案匹配, pattern_match
  - operation:裁剪, crop
  - operation:重涂色, recolor
  - object:精灵体, sprite
  - object:分隔线, separator
  - relation:旋转镜像等价, rotation_mirror_equivalence
  - condition:标签实体不符者选中, mismatched_label_selected
- 参考题目题号: f5aa3634, 9110e3c5, 5a5a2103

### docstring

```text
在贴了身份标签的灰色形状副本中找出唯一"标签与实体不符"的说谎者，按其真实身份色输出。

输入结构
- 一条分隔线把画面分成图例区与检索区。
- 图例区列出若干形状，各用互不相同的颜色绘制，构成"颜色→形状"字典。
- 检索区散布这些图例形状的旋转或镜像副本，全部重涂成同一种灰色；每个副本旁贴着一个单像素标签，其颜色声称该副本的身份。
- 恰有一个副本的标签颜色与其真实形状按字典应有的颜色不符。

规则
- 对每个灰色副本，在旋转与镜像等价意义下与图例形状比对，得到其真实身份色。
- 找出标签色与真实身份色不符的唯一副本。
- 输出该副本裁剪到包围盒的图案（保持它在检索区中的朝向），涂成其真实身份色。

关键洞察
- 统一的灰色切断了按颜色识别的捷径，贴着的标签是诱饵；唯一判据是"标签与形状实体不符"，输出颜色来自实体查字典而非标签。
```

## 5. 看不见的容器

- tags:
  - operation:搜索, search
  - operation:搬移, relocate
  - operation:擦除, erase
  - object:矩形精灵体, rectangular_sprite
  - object:背景空间, background_space
  - relation:面积守恒, area_conservation
  - condition:最大空矩形为容器, max_empty_rect_container
  - condition:唯一铺法, unique_tiling
- 参考题目题号: 3eda0437, 7b3084d4, 247ef758

### docstring

```text
把散落的实心矩形块搬进"最大全空矩形"里无缝铺满它。

输入结构
- 黑色背景上有不规则分布的灰色障碍像素，以及若干颜色互异、尺寸互异的实心矩形块。
- 把矩形块也视为占位后，存在唯一的面积最大、边长均不小于 2 的全空矩形（空腔）。
- 所有矩形块的面积之和等于空腔面积，且只用平移恰有一种方式把它们无缝铺满空腔。

规则
- 找到输入中的最大全空矩形。
- 把每个矩形块从原位擦除，平移放入空腔，使全部块恰好铺满空腔且互不重叠。
- 障碍像素与其余背景保持不变。

关键洞察
- 目标容器从未被画出：它是背景中的极大空矩形，而不是任何已画的框；"块面积之和等于空腔面积"是自检信号，铺法由块的尺寸组合唯一锁定。
```

## 6. 场内样例定镜像

- tags:
  - operation:镜像, mirror
  - operation:重涂色, recolor
  - object:轮廓, outline
  - object:凸耳, tab
  - relation:场内样例, in_grid_exemplar
  - condition:样例定参数, exemplar_sets_parameters
  - condition:凸耳定轴, tab_determines_axis
- 参考题目题号: dc2e9a9d, f5aa3634

### docstring

```text
场上唯一已配好镜像副本的带耳轮廓是"说明书"，照它的颜色、间隔与方位参数给其余轮廓补出镜像副本。

输入结构
- 黑色背景上有若干绿色空心轮廓，每个的包围盒恰有一条边上带一个单像素凸耳。
- 恰有一个轮廓旁已画好其镜像副本：形状与该轮廓镜像相同、颜色不同，与原包围盒隔开若干列/行背景，位于凸耳同侧或对侧。
- 副本颜色、间隔宽度、同侧还是对侧在不同谜面中各不相同。

规则
- 凸耳在左/右边的轮廓做水平镜像，在上/下边的做垂直镜像。
- 从已完成的样例对读出三项参数：副本颜色、与原包围盒的间隔、放在凸耳同侧还是对侧。
- 按这三项参数为其余每个轮廓画出镜像副本，只涂背景格，越界部分裁掉；样例对与所有绿色像素保持不变。

关键洞察
- 变换的自由参数不在任何固定约定里，而写在场内那对完成品上；先认出谁是样例，再把它当规则说明书使用——照搬"隔一格、固定色"的默认约定必然出错。
```

## 7. 分解定去向

- tags:
  - operation:分解, decompose
  - operation:滑动, slide
  - operation:重涂色, recolor
  - object:基本图元, primitive_shape
  - relation:形状定方向, shape_determines_direction
  - condition:唯一分解, unique_decomposition
- 参考题目题号: 150deff5, 8e301a54

### docstring

```text
把灰色复合块唯一分解成方块与长条后，各基本件按自己的形状类别向不同方向移动并重涂。

输入结构
- 黑色背景上有若干灰色连通块，每块都能且只能以一种方式无重叠地分解为 2×2 方块、1×3 横条、3×1 竖条。
- 同一列至多一根竖条、同一行至多一根横条参与移动（保证落点无歧义）。

规则
- 恢复唯一分解。
- 3×1 竖条整体沿所在列上移到顶端并重涂红色；1×3 横条整体沿所在行左移到最左端并重涂蓝色；2×2 方块原地重涂青色。
- 移出后的格子恢复背景。

关键洞察
- 连通块不是行动单位：必须先看破复合块由哪些基本件拼成，件的形状类别（而非颜色或位置）决定它去哪、变什么色；把整块一起搬或按连通体涂色都会失败。
```

## 8. 隐藏修复现场

- tags:
  - operation:对称补全, symmetry_completion
  - operation:搜索, search
  - object:遮罩像素, mask_pixel
  - object:正方形区域, square_region
  - relation:对称群推断, symmetry_group_inference
  - condition:最大相容群, maximal_consistent_group
  - condition:局部自洽定位, local_consistency_locates
- 参考题目题号: 929ab4e9, e40b9e2f

### docstring

```text
先定位唯一"忽略遮罩后局部自洽对称"的隐藏正方形子区域，再体检出其真实对称群并恢复遮罩格。

输入结构
- 长方形网格上是杂乱多色图案，恰有一种颜色充当遮罩，遮罩像素集中分布。
- 整幅图不具有任何全局对称；存在唯一一个正方形子区域：忽略遮罩后，其内部可见像素与正方形八对称的某个非平凡子群完全相容，且全部遮罩格都落在该子区域内。
- 不同谜面中子区域的位置、大小与相容群都不同（可能只有 180° 旋转，可能只有某条对角镜像，也可能是完整八重）；每个遮罩格在最大相容群下的轨道内至少含一个可见格且颜色一致。

规则
- 定位该唯一的正方形子区域（其余画面是打破全局对称的干扰背景）。
- 在子区域内逐一检验八种对称，保留与全部可见像素无冲突者，得到最大相容群。
- 把每个遮罩格替换为其轨道中可见格的唯一颜色；子区域外一切不动。

关键洞察
- 修复现场既没画边界也没标对称轴：先靠"遮罩聚集 + 局部自洽"锁定隐藏正方形，再给它验明真正的对称群，最后才补色；全局视角与默认八重对称都是陷阱。
```

## 9. 端点生成编织

- tags:
  - operation:连线, connect
  - operation:编织填充, weave_fill
  - object:标记像素, marker_pixel
  - object:交叉条, crossing_bar
  - relation:端点对生成线, endpoint_pair_generates_line
  - relation:沿线交替, along_line_alternation
  - condition:锚定相位, anchor_phase
- 参考题目题号: f3e14006, 55783887, 9968a131

### docstring

```text
由成对同色端点生成横竖线段，再按"沿线交替、锚点定相"的编织规则决定每个交叉处谁压谁。

输入结构
- 黑色背景上散布若干对同色单像素端点：每对或者同行、或者同列，颜色互不相同；线段本身没有画出。
- 另有恰好一个额外的彩色像素，它落在某两条待生成线段的交点位置上，颜色等于其中一条线的端点色——它是锚，表示该交叉处这条线在上。
- 保证所有交叉沿线段连通，交替约束可从锚传播到每个交叉且无矛盾。

规则
- 把每对同色端点用其颜色连成水平或竖直线段（含端点）。
- 横线与竖线的每个交点需决定谁在上：沿任一条线段，其依次经过的交叉上下严格交替。
- 从锚出发沿线传播该约束，唯一确定全部交叉；每个交叉格涂在上那条线的颜色，其余线上格子涂本线颜色。

关键洞察
- 画面上一条线都没有——线是端点对的生成物；那个"多出来的"像素不是第三种端点而是编织锚；交替按"这条线上的第几个交叉"数而非坐标，只能沿线接力推理，坐标棋盘格是会破产的诱饵。
```
