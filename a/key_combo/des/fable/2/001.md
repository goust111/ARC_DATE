## 1. 隐形弹射配色

- 参考题目题号: 2, 17, 8
- tags:
  - operation:射线延伸, ray_extend
  - operation:重涂色, recolor
  - operation:擦除, erase
  - object:种子像素, seed_pixel
  - object:反弹路径, bouncing_path
  - object:目标方块, target_block
  - relation:边界反射, boundary_reflection
  - relation:隐形路径对应, hidden_path_correspondence
  - condition:命中定色, hit_determines_color
  - condition:未命中即删除, unhit_erased

### docstring

```text
在底边种子发出的隐形反弹对角射线命中的灰色方块上,涂上对应种子的颜色,未被命中的灰色方块删除。

输入结构:
- 黑色背景网格,底边行上有若干互不相同颜色的单个种子像素。
- 网格内部悬浮着若干 2×2 的灰色方块。
- 灰色与种子颜色不重复,射线在输出中不可见。

规则:
- 每个种子沿对角方向向上发出一条射线,初始方向为右上(若种子紧贴右边界则为左上)。
- 射线每步同时上移一格、横移一格,碰到左右边界时水平方向反转。
- 射线进入某灰色方块的任一格时停止,该方块整体涂成该种子的颜色。
- 从顶边离开而未命中方块的射线无效果;未被任何射线命中的灰色方块涂回黑色。

关键洞察:
- 画面上从未画出射线本身;种子与方块之间的配对关系只能靠在脑中模拟反弹轨迹得到,
  命中与否同时决定涂色与删除。
```

## 2. 计数定层序叠加

- 参考题目题号: 16, 4, 5
- tags:

  - operation:计数, counting
  - operation:排序, sorting
  - object:面板, panel
  - object:分隔列, separator_column
  - relation:图层优先级, layer_priority
  - condition:连通块数决定优先级, component_count_determines_priority
  - condition:位置序与像素数为诱饵, position_and_pixel_count_decoy

### docstring

```text
将分隔开的若干同尺寸面板按连通块数目从少到多的顺序自上而下叠放成一幅图。

输入结构:
- 网格被数条整列的分隔线分成若干个同尺寸面板。
- 每个面板由背景 0 与恰好一种前景色组成,各面板前景色互不相同。
- 各面板前景的 4-连通块数目互不相同;前景像素总数的大小顺序与连通块数目的顺序不一致。

规则:
- 把每个面板的 0 视为透明。
- 统计每个面板前景的 4-连通块数目,数目最少的面板放在最上层,依次向下。
- 输出为单个面板尺寸,每格取自上而下第一个不透明的颜色,全透明处为 0。

关键洞察:
- 面板的排列位置与像素多少都是诱饵;决定遮挡关系的是各面板图案被拆成几块,
  越整块越靠上。
```

## 3. 多米诺连锁

- 参考题目题号: 8, 19, 13, 11
- tags:
  - operation:旋转, rotate
  - operation:平移, translate
  - operation:连锁反应, chain_reaction
  - object:立柱, standing_bar
  - object:标记像素, marker_pixel
  - relation:高度决定触及范围, height_determines_reach
  - condition:间距超过高度则中断, gap_exceeds_height_stops_chain
  - condition:后倒者覆盖先倒者, later_fall_covers_earlier

### docstring

```text
被标记的立柱向标记一侧倒下,并按"高度能否够到下一根"的判定引发连锁,输出全部倒下与幸存的立柱。

输入结构:
- 黑色背景,底行为地面,若干互不同色、宽 1 格的立柱竖直立于底行不同列上。
- 恰有一个异色标记像素悬浮于某根立柱顶端的左侧或右侧,指示该柱的倒向。
- 立柱之间的水平间距不一。

规则:
- 高度为 h、底座在列 c 的立柱向右倒下后,变为占据底行 c 到 c+h-1 列、颜色不变的横条
  (向左倒同理镜像)。
- 设倒向一侧最近的仍站立立柱底座在列 c';当 c'-c ≤ h 时该柱被撞倒并同向继续倒下,
  否则连锁在此中断。
- 后倒下的横条覆盖先前横条与之重叠的部分;未卷入连锁的立柱保持站立;标记像素从输出中去除。

关键洞察:
- 倒下等价于把竖条原地放倒成等长横条;整幅输出由"每根柱子的高度对比它与下一根的间距"
  这一逐对判定的连锁决定,一处够不着则后方全部幸存。
```

## 4. 视线印章

- 参考题目题号: 13, 9, 12, 7
- tags:
  - operation:印章覆盖, stamp
  - operation:旋转, rotate
  - operation:擦除, erase
  - object:精灵体, sprite
  - object:标记像素, marker_pixel
  - object:朝向像素, nose_pixel
  - relation:中心对齐, center_align
  - relation:朝向源对象, facing_source
  - condition:旋转使鼻尖指向原件, rotate_nose_toward_origin
  - condition:同向仅最近者成像, only_nearest_per_ray

### docstring

```text
在精灵中心发出的四条视线上,给每条视线最近的灰色标记盖一份鼻尖朝回原件的旋转拷贝,更远的标记被挡住而消失。

输入结构:
- 网格上有一个奇数边长正方形包围盒的彩色精灵,其某条边的正中嵌有一格异色"鼻尖"像素。
- 另有若干孤立的灰色标记像素,均与精灵包围盒中心同行或同列;同一方向上可能有多枚标记。
- 灰色与精灵颜色均不相同。

规则:
- 沿精灵中心向上、下、左、右四个方向看,每个方向只处理离精灵最近的那枚标记。
- 在该标记处盖一份精灵拷贝(拷贝包围盒中心落在标记上),在 0°/90°/180°/270° 中选择
  使鼻尖位于面向原精灵一侧的旋转。
- 同方向更远处的标记被这份拷贝"挡住视线",直接从输出中抹除;原精灵保持不变。

关键洞察:
- 旋转量不由标记本身给出,而是由"标记相对原件的方位"与鼻尖方位对齐反推得到;
  同一射线上只有最近者成像,其余标记是被遮挡的诱饵。
```

## 5. 双层形状筛

- 参考题目题号: 8, 11, 17
- tags:
  - operation:重力下落, gravity_drop
  - operation:形状匹配, shape_matching
  - object:隔板, sieve_board
  - object:凹槽, notch
  - object:精灵体, sprite
  - relation:通道对齐, channel_aligned
  - relation:逐层筛选, cascade_filtering
  - condition:形状全等方可穿过, congruence_required_to_pass
  - condition:不合者停于接触处, misfit_rests_at_contact

### docstring

```text
让精灵依次穿过两层筛板:形状与正下方凹槽全等才能穿过一层,输出三种归宿——卡在上板、卡在下板或落到底边。

输入结构:
- 黑色背景;两条水平实心隔板上下横贯网格,每块板的上边缘各开有若干凹槽(背景色缺口)。
- 最上方悬浮若干彩色精灵;每个精灵的列范围与两块板上同列位置的凹槽对齐,或不与任何凹槽相交。
- 精灵之间列范围互不重叠。

规则:
- 每个精灵在自己的列范围内竖直下落。
- 到达一块板时,若其形状与该板上正对它的凹槽形状完全一致,则穿过该板继续下落,凹槽保持为空。
- 不一致则下落到与该板轮廓最先接触的位置停住(可部分陷入不匹配的凹槽);
  连续穿过两板者落到底边停住。

关键洞察:
- 每块板都是一道全等测试,尺寸塞得进去并不算数;精灵的最终归宿由它与沿途各凹槽
  逐层比对的通过链决定,不同层的凹槽淘汰不同的精灵。
```

## 6. 巨形着色

- 参考题目题号: 20, 12, 17
- tags:
  - operation:像素放大, pixel_upscale
  - operation:掩码匹配, mask_matching
  - operation:重涂色, recolor
  - operation:旋转, rotate
  - object:单色巨形, mono_giant_shape
  - object:多色图案块, multicolor_pattern_block
  - relation:整数缩放对应, int_scale_correspond
  - condition:轮廓一致者选中, silhouette_match_selects
  - condition:忽略干扰项, ignore_distractors

### docstring

```text
用轮廓与灰色巨形整除缩放匹配的那块多色图案,给巨形按块上色,输出上色后的巨形。

输入结构:
- 黑色背景上有一个灰色大图案,它是某个 n×n 二值轮廓按整数倍 k 放大的结果。
- 另有若干个 n×n 的多色小图案块散布各处,块内含黑色格,非黑格的排布即其轮廓。
- 只有一个小块的轮廓经过 0°、90°、180° 或 270° 旋转后与巨形的缩小轮廓完全一致,
  其余为干扰项。

规则:
- 以巨形包围盒边长除以小块边长得到放大倍数 k,把巨形缩小为 n×n 轮廓。
- 在四种旋转中找到轮廓与之完全一致的那个小块。
- 输出为巨形包围盒大小:将选中小块按该旋转姿态摆正后,每个非黑格放大为 k×k 的
  同色实心块,黑格保持黑色。

关键洞察:
- 灰色巨形只是被放大的模板轮廓,颜色信息全部藏在唯一与之同构的小块里;
  必须先做缩放同构筛选、再连同旋转姿态一起把颜色搬回巨形。
```

## 7. 向量跳跃

- 参考题目题号: 8, 13, 10, 2
- tags:
  - operation:平移, translate
  - operation:解码, decode
  - object:精灵体, sprite
  - object:指令像素, instruction_pixel
  - relation:向量编码方向与步长, vector_encodes_dir_and_step
  - condition:反复跳跃至出界前停止, jump_until_next_exits

### docstring

```text
每个精灵按"自身中心指向体内异色像素"的向量反复跳跃,停在再跳一步就会出界的位置。

输入结构:
- 黑色背景上散布若干单色精灵,精灵包围盒为奇数边长,每个精灵体内恰有一格公共的
  异色指令像素。
- 指令像素相对精灵包围盒中心的偏移为水平、竖直或恰好 45° 对角方向,偏移长度不一。
- 各精灵的跳跃路径互不干涉。

规则:
- 把"包围盒中心到指令像素"的偏移向量作为一步的位移。
- 精灵(连同指令像素)整体平移该向量,反复进行,直到再平移一次会有任何一格越出
  网格边界为止。
- 所有精灵各自独立完成跳跃,背景保持黑色。

关键洞察:
- 指令像素同时编码方向和步长:精灵不是滑到贴墙为止,而是按固定步长跳跃,
  最终位置与边界之间会留下小于一步的余量,这个余量暴露了步长的存在。
```

## 8. 缺臂溯源

- 参考题目题号: 10, 7, 11, 1
- tags:
  - operation:链式追踪, chain_trace
  - operation:重涂色, recolor
  - operation:解码, decode
  - object:格子单元, lattice_cell
  - object:残缺十字, incomplete_cross
  - object:起点十字, start_cross
  - relation:缺失部位编码来路, absence_encodes_incoming
  - condition:反向接力解码, reverse_relay_decode
  - condition:正向读箭头为诱饵, forward_reading_decoy

### docstring

```text
从唯一完整的异色十字出发,沿"谁的缺臂指向我,谁就是下一格"的接力找出隐藏路线,并把沿途十字染成起点色。

输入结构:
- 网格被划分为若干同尺寸方格,每格中央画有一个十字图案。
- 恰有一个异色十字四臂完整,是路线的起点;其余十字同色且各缺一条臂。
- 保证行走过程中每一步"缺臂指向当前格的相邻格"唯一,且路线不成环。

规则:
- 从起点格出发:在当前格的上下左右相邻格中,找到"缺失的那条臂恰好指向当前格"的格子,
  走进去。
- 反复进行,直到没有任何相邻格的缺臂指向当前格,路线在此终止。
- 把途经(含起点与终点)的所有十字整体染成起点十字的颜色,其余格保持不变。

关键洞察:
- 缺臂不是行进方向而是"来路"的记号:把缺臂当箭头正着走是诱饵,正确路线必须反向解码——
  每一步都要找"指着我"的邻格接力。
```
