## 1. 层序坠落

- 参考题目题号：1（68bc2e87）、7（a48eeaf7）
- tags:
  - operation:补全, reconstruct
  - operation:排序, sorting
  - operation:移动, move
  - object:空心矩形, hollow_rectangle
  - object:重叠层, overlap_layer
  - relation:遮挡层序, occlusion_order
  - relation:支撑接触, support_contact
  - condition:层序即坠落顺序, layer_order_is_drop_order
  - condition:碰撞停止, collision_stop

### docstring

```text
按遮挡层序自底向上让每个矩形框依次坠落并互相支撑。

输入结构：
- 背景为单一颜色，前景是若干一格粗的空心矩形框，颜色互不相同。
- 框之间存在重叠，重叠格只显示位于上层的框的颜色，部分框因此残缺。
- 网格底边视为地面。

规则：
- 先由每个颜色可见像素的外接矩形还原出完整框。
- 由每个重叠格的显色关系推出全部框唯一的自底向上层序。
- 按该层序从最底层开始逐一坠落：框整体竖直下移，直到再下移一格就会与
  地面或已落定框的像素重合为止；坠落时只与地面和先落定的框发生碰撞，
  尚未轮到的框视为不存在。
- 输出中所有框完整画出，互不重叠。

关键洞察：
- 重叠像素揭示的不是绘制顺序而是时间顺序：最底层的框最先坠落、成为
  后落框的支撑，层序不同则堆叠结果不同，仅凭"全部推到底"无法得到
  正确答案。
```

## 2. 对称测谎

- 参考题目题号：18（3631a71a）、2（2a5f8217）、15（135a2760）
- tags:
  - operation:异常检测, anomaly_detection
  - operation:形状匹配, shape_matching
  - operation:裁剪, crop
  - object:对称图案, symmetric_pattern
  - object:入侵像素, intruder_pixel
  - object:模板对象, template_object
  - relation:对称轨道, symmetry_orbit
  - condition:轨道失谐定位置, orbit_dissonance_locates
  - condition:模板匹配定颜色, template_match_colors

### docstring

```text
揪出令对称图案失谐的入侵形状，再由模板库为它验明正身定色。

输入结构：
- 网格被一条分隔线分成两个面板。
- 左面板是一幅同时关于主对角线转置与水平、垂直翻转不变的方形图案，
  其中一小片连通区域被改写成图案调色板内已有的其他颜色，没有引入
  任何新颜色；每个对称轨道至多包含一个被改写的格子。
- 右面板散布若干形状互不相同的单色候选模板。

规则：
- 对左面板每个对称轨道取其成员的多数颜色为真值，与真值不符的格子
  即入侵格。
- 全部入侵格构成的形状与右面板中恰好一个模板的归一化掩码相同。
- 输出为入侵形状的外接矩形裁剪：入侵格统一涂成该匹配模板的颜色，
  其余格子置为黑色。

关键洞察：
- 入侵像素在颜色上毫无破绽，唯一线索是它令所在对称轨道失谐；
  且被提取的形状本身还不是答案，须与模板库做形状匹配才能确定输出
  颜色——对称性回答"在哪里"，模板库回答"是什么"。
```

## 3. 门链变色

- 参考题目题号：7（a48eeaf7）、11（fc10701f）、4（edb79dae）、15（135a2760）
- tags:
  - operation:滑动, sliding
  - operation:重涂色, recolor
  - object:标记像素, marker_pixel
  - object:锚点方块, anchor_block
  - object:闸门线段, gate_segment
  - object:颜色图例, color_legend
  - relation:射线对齐, ray_alignment
  - condition:穿门迭代映射, gate_iterates_map
  - condition:关门碰撞停止, closed_gate_stops
  - condition:忽略干扰项, ignore_distractors

### docstring

```text
让标记像素穿过一串闸门滑向锚块，每穿过一门颜色按图例演化一步。

输入结构：
- 背景网格上有一个实心锚块和一枚与它同行或同列对齐的标记像素。
- 标记与锚块之间横着若干垂直于路径的闸门线段：有的在标记所在行或列
  处留有一格开口（开门），有的没有（关门）。
- 网格其他区域散布不与路径相交的干扰线段，以及若干两格相贴的图例对，
  图例定义了"当前色 → 下一色"的映射。

规则：
- 标记沿直线滑向锚块，原位清除。
- 每穿过一扇开门，标记颜色按图例映射演化一次。
- 遇到第一扇关门即停在其前一格；若全为开门则停在紧贴锚块的一格。
- 输出保留锚块、闸门、干扰线段与图例，标记以最终颜色画在最终停点。

关键洞察：
- 停点和终色由同一次扫描共同决定：只有真正横跨路径且开口对准行列的
  门才计数，最终颜色是图例映射按穿门次数的迭代复合，停在哪里同时
  决定了演化几步。
```

## 4. 旋转互补

- 参考题目题号：8（7953d61e）、19（f8cc533f）、20（b10624e5）
- tags:
  - operation:旋转, rotation
  - operation:补全, complete
  - object:四象限, quadrant
  - object:部分图案, partial_pattern
  - object:分隔线, divider
  - relation:旋转轨道互补, rotation_orbit_complement
  - condition:旋转对齐取并集, rotate_align_union
  - condition:无镜像对称防误对齐, chirality_blocks_mirror

### docstring

```text
用四个旋转互补的残缺象限恢复整幅旋转拼图。

输入结构：
- 网格被一条整行与一条整列的分隔线划成四个等大的方形象限。
- 四个象限承载同一图案的四个旋转副本（0度、90度、180度、270度各一），
  但每个副本都缺失了一部分像素（缺失处为背景色）。
- 图案不具有镜像对称，且四个副本的缺失位置互补：每个图案格至少在
  一个副本中可见。

规则：
- 各象限的旋转角度由残存像素之间的一致性唯一确定。
- 将每个象限旋转回同一基准方向，把四份非背景像素取并集得到完整图案。
- 再把完整图案按各象限原有的旋转角度放回，重绘四个象限；分隔线保持
  不变。

关键洞察：
- 单个象限无法自我修复，缺失格的信息在别的象限里以旋转后的坐标存放；
  由于图案无镜像对称，误用翻转对齐会得到错误的补全。
```

## 5. 整数配尺

- 参考题目题号：16（928ad970）、20（b10624e5）、4（edb79dae）、2（2a5f8217）
- tags:
  - operation:缩放, scale
  - operation:旋转, rotation
  - operation:印章放置, stamp
  - object:标记像素, marker_pixel
  - object:精灵体, sprite
  - object:像素画块, pixel_art_block
  - relation:极值围区, extrema_enclose_region
  - condition:双向整数比选精灵, integer_ratio_selects
  - condition:同倍双向整除, same_factor_both_axes

### docstring

```text
在双向整数缩放与旋转下为标记围区选出唯一合身的精灵并重采样盖章。

输入结构：
- 背景上有四枚同色标记像素，分别给出唯一的上、下、左、右极值，
  四个极值之间围出一块空的矩形目标区。
- 网格其余位置散布若干精灵：有的精灵本身就是按整数倍放大过的像素画
  （内容呈 k×k 色块结构），有的比目标区小、有的比目标区大。
- 恰有一个精灵，其外接矩形与目标区尺寸之间存在两个方向共用的同一
  整数比（可能需要先旋转90度，方向可能是放大也可能是缩小）；其余
  精灵至多一个方向成整数比，或两个方向整数比不相等。

规则：
- 由标记极值确定目标区。
- 找出该唯一精灵：若目标区更大则按整数倍逐像素放大，若目标区更小则
  按 k×k 色块归并缩小，必要时先旋转90度。
- 将重采样结果恰好盖入目标区，其余内容与标记全部保持不变。

关键洞察：
- 目标区从未被画出，只由四枚游离标记隐式限定；候选筛选靠"两个方向
  共用同一整数比"的整除关系，且缩放方向不固定——必须意识到有的精灵
  是放大过的像素画、可以被整数倍缩小后放入，才找得到唯一解。
```

## 6. 残影认亲

- 参考题目题号：2（2a5f8217）、1（68bc2e87）、19（f8cc533f）
- tags:
  - operation:形状匹配, shape_matching
  - operation:补全, complete
  - operation:重涂色, recolor
  - operation:擦除, erase
  - object:遮挡带, occluder_band
  - object:占位符对象, placeholder_object
  - object:模板对象, template_object
  - relation:部分掩码匹配, partial_mask_matching
  - condition:遮挡作匹配约束, occlusion_constrains_match

### docstring

```text
为被横带遮住的占位残影找到唯一相容的模板并还其全形。

输入结构：
- 黑背景网格中横贯一条数格厚的灰色遮挡带。
- 若干蓝色占位形状与遮挡带相交，只露出带外的残缺部分，被带覆盖的
  部分不可见。
- 带外另有若干完整的彩色模板形状，形状互不相同；蓝色残影的可见形状
  与任何模板都不完全相同。

规则：
- 对每个蓝色残影，寻找唯一的模板：把模板放到残影位置后，其未被遮挡
  带覆盖的部分与残影可见部分完全一致。
- 输出中去掉遮挡带，把每个残影补全为完整模板形状，并整体改成对应
  模板的颜色。
- 模板本身保持不变。

关键洞察：
- 直接按可见形状做同形匹配必然失败；必须把遮挡带当作约束条件，做
  "模板减去被遮部分等于残影"的部分掩码匹配——占位对象自始至终没有
  被完整画出。
```

## 7. 相位错动

- 参考题目题号：15（135a2760）、14（32e9702f）
- tags:

  - operation:平铺, tiling
  - operation:裁剪, crop
  - object:周期瓦片, periodic_tile
  - object:相位错动区, phase_slip_region
  - relation:周期重复, periodic_repetition
  - condition:相位失配显形, phase_mismatch_reveals

### docstring

```text
从无缝壁纸的相位错动中提取从未被画出的剪影。

输入结构：
- 整幅网格由一块小瓦片周期平铺构成，瓦片内部各格颜色互不相同。
- 一片连通区域内的内容被整体平移了一个非零相位：局部看仍是合法的
  壁纸纹理，没有出现任何越界颜色。

规则：
- 由占多数的格子恢复全局瓦片及其相位基准。
- 与全局延拓不一致的格子集合即为剪影。
- 取剪影的外接矩形裁剪输出：剪影格涂灰色，其余格涂黑色。

关键洞察：
- 异常不在颜色层面而在相位层面，任何单格、单行都挑不出毛病；只有
  先重建全局周期基准，错动区域才作为一个整体形状显形——要找的对象
  从未被直接画出，画面上只有它对周期场的扰动。
```

## 8. 投影成层

- 参考题目题号：1（68bc2e87）、20（b10624e5）、12（137f0df0）
- tags:
  - operation:渲染, render
  - operation:填充, fill
  - object:投影线段, projection_segment
  - object:轨道, rail
  - object:实心矩形, filled_rectangle
  - object:分隔线, divider
  - relation:双投影定矩形, dual_projection_defines_rect
  - relation:遮挡层序, occlusion_order
  - condition:轨道远近编码层序, rail_distance_encodes_layer

### docstring

```text
仅凭两侧轨道上的一维投影按轨道远近层序渲染出层叠矩形。

输入结构：
- 网格由一条整行与一条整列的分隔线划出左上方的轨道区与右下方的空白
  画布区。
- 上方轨道区有若干行轨道，每行恰有一条彩色线段，给出对应颜色矩形的
  列范围；左侧轨道区有同样多列轨道，同色线段给出行范围。
- 同一颜色在两侧轨道区中所处的轨道序号相同：离画布越近的轨道序号
  越靠前。

规则：
- 每种颜色对应一个实心矩形，行、列范围分别由左、上两条同色线段给出。
- 在画布区内绘制全部矩形，重叠处由轨道更靠近画布的颜色覆盖更远的
  颜色。
- 输出只保留画布区。

关键洞察：
- 矩形从未被画出，画面上只有它们在两条边上的一维投影；轨道到画布的
  距离编码了层叠的上下顺序，把它误读成颜色数值顺序或从外到内的顺序
  都会在重叠处出错。
```
