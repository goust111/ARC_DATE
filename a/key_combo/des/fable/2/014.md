## 1. 隐形射线围墙泛洪

- 参考题目题号: 7 (d037b0a7)、4 (b9e38dc0)、13 (00d62c1b)、20 (342dd610)
- tags:
  - operation:射线延伸, ray_extend
  - operation:洪泛填充, flood_fill
  - object:方向编码像素, direction_coded_pixel
  - object:填充种子, fill_seed
  - relation:颜色编码方向, color_encoded_direction
  - relation:虚拟屏障, virtual_barrier
  - condition:射线不显现, rays_invisible
  - condition:射线互相截断, rays_truncate_each_other

### docstring

```text
让每个方向色像素射出一条看不见的墙，再从种子像素泛洪，涂满没有被隐形墙围住的连通区域。

输入结构
- 背景为黑色。
- 网格上散布若干单像素方向源：红=向右、蓝=向下、绿=向左、黄=向上（码表在全部示例中固定）。
- 恰有一个橙色种子像素，橙色不在方向码表内。

规则
- 每个方向源沿自身编码方向逐格推进，直到网格边缘或撞到任何非背景像素前停下；推进经过的格子记为隐形墙。
- 隐形墙、方向源与种子都不可通行；从种子做四连通泛洪，把可达的背景格全部涂成橙色。
- 输出中方向源保持原样，隐形墙所在格保持黑色，其余不变。

关键洞察
- 围住种子的墙从未被画出：颜色只给出方向，射线因互相截断而留下缺口，
  泛洪是否漏出完全取决于这些看不见的墙段拼没拼严。
```

## 2. 浸没的深度标尺

- 参考题目题号: 3 (8dae5dfc)、13 (00d62c1b)、5 (e9ac8c9e)、9 (77fdfe62)
- tags:
  - operation:重涂色, recolor
  - object:封闭边界, closed_boundary
  - object:嵌套矩形层图例, nested_layer_legend
  - object:标记像素, marker_pixel
  - relation:拓扑深度, nesting_depth
  - relation:深度索引图例层, depth_indexes_layer
  - condition:标尺自身深度对齐, legend_own_depth_offset
  - condition:图例在输出中删除, legend_removed

### docstring

```text
按每个灰色标记被封闭曲线包裹的层数重涂它，但深度标尺自己也泡在这些曲线里，读数必须从标尺自身的深度起算。

输入结构
- 背景为黑色；若干绿色封闭曲线，彼此不相交，可以嵌套。
- 网格各处散布灰色单像素标记，既可能在曲线内也可能在所有曲线之外。
- 另有一个实心多层同心矩形（图例，各层颜色互不相同），它本身也可能被若干条绿色曲线包裹；
  保证图例所在深度不超过任何灰标记的深度，且层数足够。

规则
- 对每个灰色标记，统计包裹它的绿色封闭曲线条数，记为深度 k；设包裹图例的曲线条数为 j。
- 图例从最外层到最内层依次对应深度 j、j+1、j+2、……，把每个深度为 k 的灰标记
  重涂为图例第 (k-j) 层（从外数）的颜色。
- 输出保留全部绿色曲线，图例整体抹为背景。

关键洞察
- 标尺不是悬在空间之外的，它浸在被测的拓扑里：包裹图例的那几条曲线充当了它"缺失的外层"，
  直接从 0 对齐的读法会在图例被包住的示例上失败。
```

## 3. 折页面板蛇形射线

- 参考题目题号: 1 (25c199f5)、7 (d037b0a7)、16 (afe3afe9)、4 (b9e38dc0)
- tags:
  - operation:拼接, concatenate
  - operation:射线延伸, ray_extend
  - object:分栏面板, panel
  - object:分隔列, divider_column
  - object:边缘标记线, edge_marker_line
  - object:障碍物, obstacle
  - relation:面板展开为长带, panels_unroll_to_strip
  - relation:折缝镜像, fold_mirror
  - condition:标记指示起始端, marker_indicates_start
  - condition:障碍截断, obstacle_blocks

### docstring

```text
把被分隔列切开的面板当作一条折叠起来的长带展开，让射线沿长带蛇形穿行后再折回原布局。

输入结构
- 网格被若干条全高分隔列切成等宽面板，分隔色只出现在分隔列上。
- 网格的左边缘或右边缘有一条全高标记线（另一种专用颜色）。
- 面板内散布彩色源像素与深灰障碍像素。

规则
- 想象长带从标记线一端折叠成这些面板：从标记端数第 2、4、……块面板在展开成长带时须左右翻转。
- 在展开后的长带上，每个源像素向远离标记端的方向发出射线，涂成源色，
  撞到障碍、其他源或长带尽头即停。
- 把长带按同样折法折回原来的面板布局输出（分隔列与标记线原样保留）。

关键洞察
- 分隔列是折缝而不是墙：射线在画面上呈蛇形——离开一块面板后从下一块面板的同侧边缘反向继续，
  "分隔列透明直穿"的猜想会在示例上失败。
```

## 4. 缺格缩略图

- 参考题目题号: 15 (b99e7126)
- tags:
  - operation:缩放, scale
  - operation:重涂色, recolor
  - object:分隔网格, separator_grid
  - object:少数单元, minority_cell
  - object:空白单元, blank_cell
  - relation:自相似, self_similarity
  - relation:整体降采样入局部, downscale_into_cell
  - condition:自身位置特殊标记, self_position_marked

### docstring

```text
把整张单元棋盘的少数/多数分布降采样成缩略图，填进唯一的空白单元里。

输入结构
- 网格被单色分隔线划分成 N×N 个等大单元，每个单元内部恰为 N×N 像素。
- 绝大多数单元装着同一幅多数图案，少数单元装着另一幅少数图案，
  恰有一个单元内部全为背景（空白单元）。

规则
- 构造一幅 N×N 缩略图：装少数图案的单元对应像素涂少数图案的主色，
  装多数图案的单元对应像素保持背景，空白单元自身的位置涂分隔线的颜色。
- 将缩略图按单元棋盘的方位一一对应地填入空白单元内部，其余部分原样保留。

关键洞察
- 这不是把小图放大，而是把全局收缩进局部：空白单元索要整张棋盘的自画像，
  并且必须在像里用分隔线色标出"我自己在这里"。
```

## 5. 洋葱指令带

- 参考题目题号: 3 (8dae5dfc)、20 (342dd610)、7 (d037b0a7)
- tags:
  - operation:层序读取, layer_sequence_read
  - operation:画线, draw_path
  - object:嵌套矩形层, nested_rect_layer
  - object:行走种子, walker_seed
  - relation:层序即时序, layer_order_is_time_order
  - condition:颜色定方向, color_sets_direction
  - condition:层厚定步数, thickness_sets_steps

### docstring

```text
把同心矩形从外到内的各层读成一串行走指令，让种子像素照着走出一条轨迹。

输入结构
- 背景为黑色。一处实心同心矩形（洋葱）：各层为均匀厚度的矩形环，各层厚度可不相同，
  层色取自方向码表红=右、蓝=下、绿=左、黄=上（码表在全部示例中固定）。
- 另有一个白色种子像素，位于空旷处。

规则
- 从最外层读到最内层，每层给出一条指令：方向由该层颜色决定，步数等于该层的厚度（单侧环宽）。
- 种子按指令顺序依次行走，把经过的每个格子（含每步落点）涂成白色，连成一条折线轨迹。
- 洋葱保持原样不动。

关键洞察
- 嵌套次序编码时间次序：同心层是一卷程序带，颜色是方向、厚度是里程，
  静止的洋葱驱动了远处的运动。
```

## 6. 滑移反射的脚印

- 参考题目题号: 14 (963f59bc)、2 (b7cb93ac)、6 (f35d900a)
- tags:
  - operation:镜像, mirror
  - operation:平移, translate
  - operation:放置, place
  - object:示范对, demonstration_pair
  - object:查询对象, query_object
  - relation:变换由样例定义, transform_defined_by_example
  - relation:滑移反射, glide_reflection
  - condition:轨道迭代至出界, orbit_until_out_of_bounds

### docstring

```text
两个红色图形示范了一个从未画出的滑移反射，蓝色图形要沿它走出一串左右交替的"脚印"直到出界。

输入结构
- 背景为黑色。两个红色图形构成示范对：它们恰好被一个滑移反射
  （先沿某条未画出的水平或竖直轴镜像，再沿该轴方向平移 d 格）互相映射。
- 轴的位置与平移量 d 由这对图形唯一确定，且示范对不满足任何单纯的镜像、平移或旋转。
- 另有一个形状不同的蓝色图形。

规则
- 从示范对反推出滑移反射的轴线位置与平移量。
- 从蓝色图形出发反复施加该滑移反射：每得到一个完全落在网格内的像就画一个蓝色副本，
  一旦下一个像有任何部分越界即停止。
- 红色示范对与原蓝色图形保持不变。

关键洞察
- 示范对之间既不是镜像也不是平移——单独试每一种都差半步，只有"镜像再滑动"的复合才能吻合；
  而示范只给了一步，答案是整条交替换边前进的脚印链。
```

## 7. 色配重力分拣

- 参考题目题号: 8 (470c91de)、19 (291dc1e1)、16 (afe3afe9)、12 (d749d46f)
- tags:
  - operation:滑动, slide
  - operation:旋转, rotate
  - object:填充矩形, filled_rectangle
  - object:控制像素, control_pixel
  - object:坐标轴线, axis_line
  - relation:控制色匹配轴线, control_matches_axis
  - condition:控制边为迎轴面, control_edge_faces_axis
  - condition:近者先落, closest_lands_first
  - condition:碰撞堆叠, collision_stacking

### docstring

```text
每个矩形按其边缘控制像素的颜色认领一条轴线，先转身让控制边朝向轴线，再按离轴近者先落的顺序坠落堆叠。

输入结构
- 背景为黑色。网格内部有一条红色满幅水平线与一条蓝色满幅竖直线，相交成十字。
- 若干实心单色矩形散布在各象限，每个矩形恰有一个控制像素嵌在自己的某条边上，颜色为红或蓝。

规则
- 控制像素为红的矩形坠向红色水平线（竖直移动），为蓝的坠向蓝色竖直线（水平移动），各自从所在一侧落下。
- 坠落前将矩形绕自身中心顺时针旋转（0°/90°/180°/270°），直到含控制像素的那条边成为朝向目标轴线的迎面。
- 同一侧同一坠向的矩形按初始离轴距离从近到远依次落下，贴到轴线或先前落定的矩形上即停；
  控制像素随矩形一起移动并保留。

关键洞察
- 控制像素身兼两职：颜色选择"哪种重力"，所在边决定落地姿态；
  后落的矩形会被先落的垫住，顺序本身也是规则的一部分。
```

## 8. 递归象限图例

- 参考题目题号: 5 (e9ac8c9e)、9 (77fdfe62)、15 (b99e7126)
- tags:
  - operation:重涂色, recolor
  - operation:分割, split
  - object:实心矩形, solid_rect
  - object:角标像素, corner_marker
  - object:复合角标, composite_marker
  - relation:角落对应, corner_correspond
  - relation:图例自嵌套, legend_self_nesting
  - condition:复合角标触发再分, composite_triggers_subdivision

### docstring

```text
用四个对角角标给灰色矩形的四个象限上色；若某个角标本身是 2×2 的四色块，它的象限就按同一法则再四分。

输入结构
- 背景为黑色。一个或多个实心灰色矩形，边长均为 4 的倍数。
- 每个灰矩形四个角的对角线外侧各有一个角标：要么是单个彩色像素，要么是一个 2×2 的四色小方块。

规则
- 抹去所有角标，把每个灰矩形均分为四个象限。
- 单像素角标：把对应角的整个象限涂成该色。
- 2×2 角标：把对应角的象限再均分为四个子象限，按 2×2 块内的相对方位把四个颜色分别涂进四个子象限。
- 该法则逐级适用于出现的每一层角标。

关键洞察
- 角标是象限的图例，而图例本身可以又是一张更小的图例——同一条规则对自己递归调用，
  读题的关键是发现"角标里还有角标"。
```
