## 1. 双帧外推与反弹

- tags:
  - operation:平移, translate
  - operation:外推, extrapolate
  - object:分隔条, divider_bar
  - object:双帧面板, two_frame_panels
  - relation:跨帧对应, cross_frame_correspondence
  - condition:位移向量重放, displacement_replay
  - condition:边界反弹, boundary_bounce
- 参考题目: `94f9d214`, `22208ba4`, `58743b76`

### docstring

```text
把上下两个面板读作同一场景的连续两帧，输出每个对象按自身位移向量再演化一步的第三帧，越界者在画布边缘反弹。

输入结构
- 网格被一条整行分隔条分为上下两个等大面板，两面板共享同一背景色。
- 两面板含同一组单色对象，颜色与形状一一对应；部分对象在两帧之间各自发生了不同的平移，其余对象静止。

规则
- 按颜色与形状把上下面板中的对象一一配对，求每个对象从上帧到下帧的位移向量。
- 输出一个面板大小的网格：把下帧中的每个对象再按其自身向量平移一次，静止对象保持原位。
- 若某方向的平移会使对象越出画布，则该对象沿该方向先行进到贴边，剩余位移反向（弹性反弹），另一方向的分量不受影响。

关键洞察
- 两个面板不是待叠加比较的掩码，而是时间序列中的两帧；不同对象的位移向量互不相同，必须逐对象外推而不能整体平移。
- 外推不是无界的：训练示例的运动全部在界内完成，只有把位移理解为带反弹的运动，才能解释测试对中撞墙的情形。
```

## 2. 镜像马赛克中的入侵者

- tags:
  - operation:裁剪, crop
  - operation:对称检测, symmetry_detect
  - object:前景面板, foreground_panel
  - object:入侵精灵, intruder_sprite
  - relation:四向反射对称, four_way_reflective_symmetry
  - condition:多数镜像表决, mirror_majority_vote
- 参考题目: `73182012`, `73ccf9c2`, `94f9d214`

### docstring

```text
在本应四向镜像的马赛克面板中，用三个镜像位置的多数表决找出被覆盖写入的入侵精灵并裁剪输出。

输入结构
- 大背景网格中有一块偶数高宽的前景面板，面板由某个源图案经左右、上下、180度反射拼成 2x2 马赛克。
- 一个单色精灵覆盖写入了面板的某个局部，其颜色取自面板本身的配色，破坏了若干格的镜像一致性。

规则
- 裁出前景面板；对面板中的每一格，与其三个镜像位置比较，取多数值为该格的应有颜色。
- 与应有颜色不符的格即入侵格。
- 输出入侵格集合的紧致包围盒：入侵格保持精灵色，其余格涂全局背景色。

关键洞察
- 精灵颜色在面板花纹中本来就存在，无法靠稀有颜色计数定位；只有把四向对称当作三重冗余校验，逐格表决才能剥离入侵者。
```

## 3. 镜面上的奇偶光线

- tags:
  - operation:射线延伸, ray_extend
  - operation:反射, reflect
  - object:边缘标记, edge_marker
  - object:镜子格, mirror_cell
  - relation:奇偶交替, parity_alternation
  - condition:路径步数定相位, path_length_phase
- 参考题目: `97999447`, `bf32578f`, `5adee1b2`

### docstring

```text
让每个边缘标记向内发射一条遇镜转向的光线，沿整条路径按步数奇偶交替涂标记色与灰色。

输入结构
- 黑色背景网格，四条边上有若干非灰色标记像素，各自属于上、下、左、右某条边。
- 网格内部散布单格镜子：青色镜使光线沿行进方向右转90度，红色镜使其左转90度。
- 各光线路径互不相交，也不穿过其他标记；每条光线至少反射两次。

规则
- 每个标记从所在边垂直向内发射光线，遇镜按镜色转向，直至离开网格。
- 沿路径为格子编号（标记本身为 0）：偶数步的格涂标记色，奇数步的格涂灰色。
- 镜子格保持镜色不改涂，但计入路径步数。

关键洞察
- 交替相位以沿路径累计的步数计，转弯后连续延伸；按行列坐标的奇偶去涂，会在反射之后出错。
```

## 4. 信标对盖章

- tags:
  - operation:放置, place
  - operation:缩放, scaling
  - operation:旋转, rotate
  - operation:重涂色, recolor
  - object:图章精灵, stamp_sprite
  - object:信标像素对, beacon_pixel_pair
  - relation:中点定位, midpoint_location
  - condition:对轴定向距定尺, pair_axis_orient_gap_scale
- 参考题目: `e9614598`, `57aa92db`, `bf45cf4b`

### docstring

```text
把画面中唯一的图章按每对同色信标给出的位置、方向、颜色与尺度盖出副本。

输入结构
- 黑色背景上有一个多格单色图章精灵（180度旋转对称），以及若干对同色单像素信标。
- 每种信标颜色恰好两枚，同行或同列对齐，间隔为偶数格；信标颜色互不相同，也不同于图章颜色。

规则
- 保留图章原位；逐对处理信标：先擦除两枚信标。
- 竖直对齐的信标对先把图章旋转90度（图章180度旋转对称，两个转向等价）。
- 以整数倍均匀放大图章，使副本沿对轴方向的跨度等于两信标（含端点）的跨度。
- 把副本重涂为该对信标的颜色，居中放在两信标之间，副本两端恰落在原信标位置。

关键洞察
- 一对信标不是画线或放固定十字的提示，而是同时编码放置中心、副本朝向、副本颜色与放大倍数的四重坐标。
```

## 5. 黄角视口与朝向

- tags:
  - operation:填充, fill
  - operation:像素放大, pixel_upscale
  - operation:旋转, rotate
  - object:角标记, corner_marker
  - object:模板瓦片, template_tile
  - relation:行列对齐, row_column_alignment
  - condition:整数倍恰好充满, integer_scale_exact_fit
  - condition:异色角定朝向, odd_corner_orients
- 参考题目: `af902bf9`, `57aa92db`, `bf45cf4b`

### docstring

```text
每组角标记围出一个隐藏矩形视口，用整数倍放大的正方形模板填满它，模板的旋转朝向由组内唯一的异色角指定。

输入结构
- 黑色背景上有一块多色正方形模板精灵，模板四角中恰有一角是特征色。
- 若干组角标记，每组四枚共享两行两列，标出一个隐藏矩形的四个外角；其中三枚为黄色、一枚为特征色。
- 每个隐藏矩形的内部为正方形，边长是模板边长的整数倍，各组倍数不同。

规则
- 为每组角标记确定其围出的内部区域，求使模板恰好充满该区域的整数放大倍数。
- 把模板旋转 0、90、180 或 270 度，使模板的特征角与该组的异色角处于同一角位。
- 将旋转后的模板逐像素放大后填入内部区域；角标记与原模板保持不变。

关键洞察
- 角标记同时给出三样东西：视口位置、专属放大倍数、以及经由异色角的朝向对齐；把它读成实心填充或统一朝向的复制都会失败。
```

## 6. 涟漪固化

- tags:
  - operation:擦除, erase
  - operation:膨胀, dilate
  - object:孤立像素, isolated_pixel
  - object:连通对象, connected_object
  - relation:同色归属, same_color_ownership
  - condition:距离定圈层, distance_selects_ring
- 参考题目: `5adee1b2`, `8f215267`, `522fdd07`

### docstring

```text
把每个孤立同色点化作围绕其所属对象的一整圈涟漪，圈层由点到对象的距离决定。

输入结构
- 背景色主导的网格上有若干互不相邻的单色多格对象，以及散布的孤立单像素点。
- 每个点与恰好一个对象同色，且不与任何对象相邻。

规则
- 求每个点到其同色对象包围盒的切比雪夫距离 j。
- 擦除所有孤立点；对每个对象，凡存在距离为 j 的点，就把该对象包围盒向外扩张 j 后的最外一圈中的背景格涂成对象色。
- 不同点选中的圈层彼此独立，未被指定的圈层保持背景，涂出的圈可以互不相邻。

关键洞察
- 点的数量不构成规则：同一对象的两个点若距离相同，只点亮同一圈；点的位置以距离的形式选择圈层，而不是以个数累加厚度。
```

## 7. 圈层的连锁输送

- tags:
  - operation:缩放, resize
  - operation:擦除, erase
  - object:奇数边正方形, odd_side_square
  - object:中心指针标记, center_pointer_marker
  - relation:颜色指针, color_pointer
  - relation:连锁传递, chain_transfer
  - condition:净圈数结算, net_ring_settlement
- 参考题目: `522fdd07`, `5adee1b2`, `8f215267`

### docstring

```text
中心标记色把方块连成有向输送图，每个带标记方块把一圈厚度送给标记所指的方块，输出按净得失结算后的方块。

输入结构
- 背景主导的网格上是若干奇数边实心单色正方形，本体色互不相同。
- 一部分方块的中心格被涂成另一方块的本体色（指针标记），其余方块是纯色。

规则
- 有标记的方块向"本体色等于其标记色"的方块输送一圈：自身边长减 2。
- 每被指认一次，边长加 2；同一方块可以同时送出并被多次指认，净变化为两者之和。
- 清空画布后按新边长重画所有方块，中心与颜色不变，输出中不再画标记。

关键洞察
- 标记色不是装饰而是指针；单个方块的胀缩无法孤立解释，必须把全部指针连成有向图并结算净流量——只按"有标记就缩小、无标记就不变"去读，会在被多次指认或既送又收的方块上失效。
```
