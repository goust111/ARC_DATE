## 1. 连锁揭示的射线清障

- 参考题号：10 (22425bda)、15 (2f767503)
- tags:
  - operation:射线延伸, ray_extend
  - operation:擦除, erase
  - operation:层序推断, layer_infer
  - object:直线, straight_line
  - object:标记条, marker_bar
  - object:控制像素, control_pixel
  - relation:遮挡层次, occlusion_order
  - condition:连锁反应, chain_reaction
  - condition:命中即整体擦除, hit_erases_whole

### docstring

```text
沿标记指向的射线逐条擦除挡路的完整直线，每次擦除都会揭示其下被遮挡的线段，直到射线畅通无阻。

输入结构
- 背景为最多色。前景包括：一个三像素直标记条及其中心旁的单个控制像素；若干条互不同色的完整直线（水平、竖直或 45 度斜线，单像素粗）。
- 线与线交叠处高层颜色遮住低层；每条线的可见共线像素足以唯一复原整条线，交叉处的可见颜色给出确定的上下层关系。

规则
- 由可见像素复原每条完整直线及交叉处的层序。
- 从标记条中心沿远离控制像素的方向发射射线；射线遇到的第一个前景像素所属（当前该格最上层可见）的那条线整条变为背景，同时被它遮住的更低层线像素恢复显示。
- 反复重新审视射线：只要路径上仍有前景像素，就擦除新的第一条挡路线并恢复其下内容，直到射线从标记条直达边界毫无阻挡。
- 未被击中的线保持恢复后的可见状态，标记条与控制像素原样保留。

关键洞察
- 擦除具有连锁性——移除上层线会让原本看不见的下层像素重新出现在射线路径上；必须同时掌握每条线的完整几何与相互层序，才能预测下一条被击中的线。
```

## 2. 自证的种子

- 参考题号：5 (5b6cbef5)、20 (0607ce86)
- tags:
  - operation:印章展开逆运算, inverse_stamp_expansion
  - operation:投票恢复, majority_vote_recovery
  - object:种子精灵, seed_sprite
  - object:块阵, block_array
  - relation:像素到块映射, pixel_to_block_mapping
  - condition:自相似自洽, self_similarity_consistency
  - condition:忽略稀疏噪声, ignore_sparse_noise

### docstring

```text
从被噪声污染的自相似展开图中反推出唯一自洽的种子小图。

输入结构
- 网格为 n²×n²（如 n=4 时 16×16），黑色为背景，恰有一种前景色；另有极少量污损——个别前景像素被抹去、个别背景处被点上前景色。
- 未被污染前，整幅图等于某个 n×n 种子按"前景位放整幅种子副本、背景位留空"的规则展开的结果。

规则
- 将网格均分为 n×n 个 n×n 块，按块内前景像素的多寡区分承载种子副本的实块与应当全空的空块。
- 实块在块阵中的排布图案本身必须与种子相同；对所有实块逐位取多数颜色，恢复出干净的 n×n 种子。
- 输出该 n×n 种子。

关键洞察
- 块阵的占位图与每个实块的内容是同一张图——这一自相似的自洽性既指出输出是什么，也提供了跨块投票纠错的依据；单看任何一块都可能带伤，全体互证之后种子唯一。
```

## 3. 假面之下的次序

- 参考题号：10 (22425bda)、11 (6cbe9eb8)、12 (bd283c4a)
- tags:
  - operation:层序推断, layer_infer
  - operation:补全, complete
  - operation:排序, sort
  - object:实心矩形, solid_rect
  - relation:遮挡层次, occlusion_order
  - relation:面积比较, area_comparison
  - condition:按真实面积重排层序, sort_by_true_area

### docstring

```text
复原每个被遮挡矩形的真实大小，并按真实面积重新决定谁压住谁，重绘整叠矩形。

输入结构
- 背景为最多色；若干互不同色的实心矩形相互重叠，上层遮住下层。
- 每个矩形的每条边都至少露出一段，因此其真实边界框可由可见像素的极值行列唯一确定；各矩形真实面积互不相同。

规则
- 由可见像素复原每个矩形的完整边界框，计算真实面积。
- 保持每个矩形的位置不变，按真实面积从大到小依次绘制：最大者最先画、居于最底层，最小者最后画、居于最顶层。
- 输出重绘后的画面。

关键洞察
- 可见像素数量是诱饵——被压得越狠的矩形露出越少；真正的排序键是复原后的边界框面积，输入的层序与面积序不一致之处正是输出必须翻转的地方。
```

## 4. 时刻表落体与消行

- 参考题号：19 (bd4472b8)、12 (bd283c4a)
- tags:
  - operation:重力下落, gravity_drop
  - operation:堆叠, stack
  - operation:满行消除, full_row_clear
  - object:顶行色序, top_row_color_sequence
  - object:分隔行, separator_row
  - object:悬浮物体, floating_object
  - relation:顺序敏感堆叠, order_sensitive_stacking
  - condition:按时刻表逐一落下, schedule_ordered_drop
  - condition:消行连锁沉降, cascade_settle_on_clear

### docstring

```text
按顶行颜色序列的先后让悬浮物体逐个竖直落下堆叠，任何被填满的整行立即消除并使上方沉降。

输入结构
- 顶行从左起排列若干颜色像素（其余为背景），其下是一条整行灰色分隔行。
- 分隔行以下的井区中悬浮着形状各异的单色物体，颜色与顶行序列一一对应；物体的列范围相互交错。

规则
- 依顶行从左到右的颜色顺序，逐个取对应颜色的物体，保持形状与列位置不变竖直下落，直到再降一格就会越出底边或与已落定像素重叠为止。
- 每个物体落定后检查井区：凡被非背景像素完全填满的行立即整行消除，其上方全部已落定像素整体下移一行；若因此再出现满行则继续消除，直至无满行。随后下一个物体才开始下落。
- 输出顶行与分隔行原样保留，井区为全部过程结束后的画面。

关键洞察
- 顶行是时刻表而非调色板——先落的物体构成后落物体的地形，而消行会反过来改写地形本身；顺序、堆叠与消行三者互为因果，只有完整按序模拟才能得到终局，任何一步静态直觉都会失效。
```

### docstring

```text
把碎裂的分隔线段拼回完整的横竖线网，再把每个分区的内容浓缩成一张小地图。

输入结构
- 背景为最多色；一种线色的短段散布于网格中，其中一部分互相共线、拼合后恰能延伸为贯穿整个网格的完整横线或竖线；另一部分与任何贯穿线都拼不起来。
- 线网划出的每个分区内部至多含一个非背景小物体——或是异色小色斑，或恰是拼不进线网的线色短段。

规则
- 找出所有能延伸为贯穿整行或整列的共线段组，复原完整分隔线；无法归入任何贯穿线的段视为分区内容。

关键洞察
- 分隔线从未完整画出——判别一段短线属于骨架还是内容，唯一依据是它能否与同伴接续成贯穿全图的直线；输出的尺寸与每格颜色都取决于这次复原。
```

### docstring

```text
把每个灰色零件旋转搬运到恰好能严丝合缝填满的同色块对之间的齿形空腔里。

输入结构
- 黑色背景上分布若干对同色块：每对的两块对向而立，相对的两条边呈凹凸齿形。
- 每对两块之间、公共跨度内的背景格构成该对的空腔；另有若干灰色 4 连通零件散布别处。

规则
- 对每个灰色零件尝试四种旋转与任意平移：若某姿态能恰好占满某个空腔的全部格子——不多一格也不少一格——则把该零件从原位擦除，按该姿态画入空腔并染成该对块的颜色。
- 每个空腔恰有一个零件与之相配；配不上任何空腔的灰色零件留在原地不动。

关键洞察
- 空腔本身从未被画出，它的轮廓由两侧齿形边共同挤出；匹配标准是面积与轮廓的完全相等，零件当前的摆放姿态与位置毫无提示作用。
```

## 7. 缺失的一帧

- 参考题号：4 (7fe24cdd)、20 (0607ce86)、9 (992798f6)
- tags:
  - operation:旋转, rotate
  - operation:轨迹推断, trajectory_infer
  - operation:补全, complete
  - object:运动快照, motion_snapshot
  - object:精灵体, sprite
  - relation:等差平移, uniform_translation
  - relation:等差旋转, uniform_rotation
  - condition:缺帧定位, missing_frame_localization

### docstring

```text
网格上散布着同一物体边平移边旋转留下的等距快照序列，找出被抹去的那一帧并按运动规律补画回去。

输入结构
- 背景为最多色；一个单色小图案沿一条直线方向等间距出现多次，每前进一步图案就比上一帧多转一个固定的四分之一圈，转向恒定。
- 序列中恰有一个位置的快照被完全抹去，只剩背景；图案自身无旋转对称，因此每帧姿态可分辨。

规则
- 识别各快照为同一形状的不同旋转态。
- 由快照的空间排列恢复行进方向与间距，由相邻帧的姿态差恢复每步的旋转方向。
- 据此确定缺帧所在的位置与应有姿态，把该姿态的图案补画在空缺处，其余保持不变。

关键洞察
- 运动规律从未被明示，位置等差与姿态等差都要从残存快照中读出；缺帧可以位于序列中段或端点，端点缺帧时甚至需要先判断序列本该有多长（由间距与网格边界共同锁定），仅靠"找空位"是不够的。
```

- 参考题号：7 (22eb0ac0)、10 (22425bda)
- tags:

  - object:标记像素, marker_pixel
  - object:画布边界, canvas_boundary
  - relation:同色配对, same_color_pairing
  - relation:行列互证, row_column_mutual_trigger

  - condition:级联至不动点, cascade_to_fixpoint
  - condition:先着色不改写, first_color_wins

### docstring

```text
两端同色的行被整行填色，被填的行又充当列的新端点，行列相互触发层层填充直至画面稳定。

输入结构
- 背景为最多色；仅网格的左右边界上散布成对的行标记像素，每个被标记的行左右各一枚。
- 初始时没有任何列标记。

规则
- 第一轮：凡左右端标记同色的行，整行填成该色。
- 此后每一轮交替进行：某列若其最上与最下的非背景像素分别属于两条已填色的整行且这两行颜色相同，则该列夹在两行之间的部分整列填成该色；新增的整列又可能让某行的最左与最右非背景像素变成同色，则该行两端之间的部分整行填色。
- 已经着色的格子不再改写；反复交替直至无新填充，输出稳定后的画面。

关键洞察
- 初始的边界标记只是火种——真正的结构由填充自身长出来：每条新线段都为正交方向制造新的"端点等式"，最终图形是一次行列互证的级联不动点，而非一遍扫描能得到的结果。
```

### docstring

```text
抽取偶格点画面，并按分隔带里成对对夹的指令像素改写被夹住的格点颜色。

输入结构
- 偶尺寸网格：偶行偶列格点承载主画面，奇数行列构成分隔带。
- 分隔带上散布少量彩色像素：有的两枚同色像素分别位于同一格点的正上与正下（或正左与正右）的分隔位，将该格点对夹；有的孤零零不成对。

- 只保留偶行偶列的格点，得到长宽减半的紧凑图。

- 落单的分隔带像素不产生任何效果。

关键洞察
- 分隔带并非纯粹的空白骨架，而是一条批注通道；一枚像素只是干扰，隔着格点遥相呼应的一对才构成生效的修改指令。
```
