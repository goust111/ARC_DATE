## 1. 双钥匙的压缩浮现检索

- 参考题目: `af24b4cc`、`63613498`、`ae4f1146`
- tags:
  - operation:压缩, compress
  - operation:多数决, majority_vote
  - operation:形状匹配, shape_match
  - operation:裁剪, crop
  - object:格盘, lattice
  - object:精灵体, sprite
  - relation:掩码相同, mask_equality
  - relation:颜色匹配, color_match
  - condition:隐式双钥匙, implicit_double_key

### docstring

```text
把噪声格盘逐块压缩成多数色，浮现出的形状与颜色作为双钥匙去检索散落对象，输出同时匹配两把钥匙的那个精灵。

输入结构：
- 网格一角有一个被背景色分隔线划分成 m×n 块的格盘，每块内部由两种颜色的像素
  混杂填充，且每块有唯一多数色。
- 所有块的多数色只取两种值，其中一种值对应的块数严格更少。
- 格盘之外的空地上散布若干 4 连通小精灵，其中包括：与浮现形状同形但颜色不同的
  诱饵、与浮现颜色同色但形状不同的诱饵，以及唯一一个"归一化掩码等于缩略图中
  少数色块构成的形状、且自身颜色等于该少数多数色"的精灵。

规则：
- 对格盘每块做多数决，得到一张 m×n 的粗缩略图。
- 取缩略图中出现次数较少的那种颜色，其所占格子构成一个二值掩码形状。
- 在格盘外的精灵中找到形状与颜色同时匹配的唯一精灵，原样裁剪输出。

关键洞察：
- 检索的两把钥匙（形状与颜色）都从未被直接画出，只在完成逐块多数决压缩之后
  才同时浮现；同形异色与同色异形的精灵是针对"只用一把钥匙"的定向诱饵，
  任何单钥匙捷径都会在某个示例上失败。
```

## 2. 斥力条上的沉降

- 参考题目: `3618c87e`、`cb2d8a2c`、`1a07d186`
- tags:
  - operation:滑动, sliding
  - operation:计数, counting
  - object:悬浮条, floating_bar
  - object:孤立像素, isolated_pixel
  - object:基线行, baseline_row
  - relation:像素计数编码距离, pixel_count_encodes_distance
  - relation:同色配对, same_color_pairing
  - condition:同色免疫, same_color_immunity

### docstring

```text
散点沿列下落，异色散点悬停在横条上方、间隔等于条上蓝点数，同色散点免疫斥力直接落在条顶。

输入结构：
- 底行为一整行基线色；空中悬浮若干列区间互不重叠的水平条，每条主体为单一
  颜色，条身上嵌有若干蓝色像素。
- 上方散布单个彩色像素（散点），每列至多一个；散点颜色与某些条的主体色相同，
  与另一些不同。

规则：
- 每个散点沿所在列竖直下落。
- 若下方最先遇到的条与散点异色，散点停在条上方，与条之间留出的空格数等于
  该条上蓝色像素的个数。
- 若与条同色，散点无视蓝点计数，直接下落到紧贴条顶的位置。
- 所在列没有条的散点一路下落到基线之上；条与蓝点在输出中保持原样。

关键洞察：
- 蓝点不是图案装饰而是斥力半径的计数编码；同色配对使斥力对"自己人"失效。
  只看无同色情形的示例会误以为规则只有"数蓝点留空"一条，必须合并两条子规则
  才能覆盖全部示例。
```

## 3. 指针链与同心环

- 参考题目: `d35bdbdc`、`ff2825db`、`ea32f347`
- tags:
  - operation:重涂色, recolor
  - operation:排序, sorting
  - object:边框精灵, bordered_sprite
  - object:同心方环, concentric_rings
  - relation:颜色查找键, color_lookup_key
  - relation:链式指针, pointer_chain
  - condition:链序决定层次, chain_order_determines_layer

### docstring

```text
以灰色边框的盒子为链头，沿"中心色等于下一个盒子的边框色"的指针关系串起所有盒子，把链序渲染成一圈圈同心方环。

输入结构：
- 黑背景上散布 n 个 3×3 的小盒：8 个边框像素同色、中心 1 个像素为另一色；
  各盒边框色互不相同。
- 恰有一个盒的边框为灰色（链头），恰有一个盒的中心为黑色（链尾）；
  其余每个盒的中心色都恰好等于另一个唯一盒子的边框色。

规则：
- 从灰框盒出发，反复按"当前盒中心色 → 边框为该色的盒"跳转，直到到达中心为
  黑的盒，得到覆盖全部 n 个盒的链序。
- 输出为 (2n-1)×(2n-1) 网格：最外一圈方环涂链头的边框色，往内每圈依次涂链上
  下一个盒的边框色，最中心 1 格涂链尾的边框色。

关键洞察：
- 中心像素是指向下一个对象的指针而非装饰；盒子的空间摆放顺序、阅读顺序都与
  答案无关，嵌套层次完全由颜色链接关系单独决定。
```

## 4. 时序表调度的坠落

- 参考题目: `3618c87e`、`1a07d186`、`ff2825db`、`337b420f`
- tags:
  - operation:滑动, sliding
  - operation:擦除, erase
  - object:细条, thin_bar
  - object:调度行, schedule_row
  - relation:序列编码次序, sequence_encodes_order
  - relation:碰撞阻挡, collision_blocking
  - condition:无匹配色则删除, unmatched_deleted
  - condition:穿过未轮到者, pass_through_pending

### docstring

```text
顶行颜色序列规定彩色横条的坠落次序，未列入时序表的条被删除，下落时穿过尚未轮到的悬浮条。

输入结构：
- 顶行从左到右排着若干单色像素（时序表）。
- 其下方的空中悬浮若干水平彩色条，颜色互不相同，位置各异、互不接触；
  部分条的颜色不在时序表中。

规则：
- 先删除颜色不在时序表中的条。
- 随后按时序表从左到右的颜色次序，让对应的条逐一竖直下落——下落过程中忽略
  尚未轮到的悬浮条，只与已落定条和网格底边碰撞：列区间相交则停在已落定条的
  上一行，否则落到底边。
- 顶行时序表在输出中保持原样。

关键洞察：
- 坠落次序既不是物理的"谁低谁先落"，也不是"谁长谁先落"，而是由顶行序列编码
  的调度表；先落的条会"穿过"仍悬空的后落条，随后者又落在它之上，形成物理
  直觉无法解释的堆叠倒置——这正是指向时序表的入口线索。
```

## 5. 对角生长的步数计数

- 参考题目: `396d80d7`、`902510d5`、`d2abd087`
- tags:
  - operation:填充, fill
  - operation:计数, counting
  - operation:擦除, erase
  - object:种子, seed
  - object:孤立像素, isolated_pixel
  - relation:计数决定步数, count_determines_steps
  - relation:仅对角邻接, diagonal_only_adj
  - condition:迭代生长, iterative_growth

### docstring

```text
每个彩色种子按其同色孤立散点的个数，执行相应轮数的"仅对角邻接"生长，随后清除所有散点。

输入结构：
- 背景上有若干不同颜色的种子（单像素或小实心块），互相远离。
- 另散布若干孤立单像素散点，每个散点颜色与某个种子相同，且不与任何同色像素
  相邻。
- 各种子生长完成后的图形互不重叠、互不相邻。

规则：
- 对每种颜色，数出其孤立散点个数 k。
- 该色种子生长 k 轮：每轮同时把所有"与当前图形对角相邻、且不与当前图形正交
  相邻"的背景格染成该色。
- 生长结束后擦除所有孤立散点，种子及生长痕迹保留。

关键洞察：
- 散点不是图案的一部分而是迭代次数的计数器；生长算子刻意反常——对角算邻居、
  正交不算，单像素种子会长成一圈圈斜向散布的棋盘菱形，而不是直觉中的实心
  扩张或十字扩张。
```

## 6. 三级间接寻址

- 参考题目: `ff2825db`、`d35bdbdc`、`ae4f1146`
- tags:
  - operation:计数, counting
  - operation:裁剪, crop
  - object:矩形边框, rect_frame
  - object:调色板行, palette_row
  - object:噪声像素, noise_pixel
  - relation:众数颜色作键, majority_color_as_key
  - relation:颜色配对映射, color_pair_mapping
  - condition:间接寻址, indirect_addressing

### docstring

```text
框内噪点的众数色经顶行调色板的色对映射换成另一种颜色，再以之为边框色检索小盒，输出盒内图案。

输入结构：
- 顶行是调色板：由若干组"左右相邻的双色对"组成，色对之间用背景隔开，定义
  颜色间的双向配对。
- 网格中有一个灰色矩形框，内部散布多色噪声像素，其中恰有一种颜色数量唯一
  最多。
- 其余空地散布若干带彩色边框的小盒，边框色互不相同，每盒内部各有一个小图案；
  其中特意存在一个边框恰为众数色本身的小盒作为诱饵。

规则：
- 统计灰框内噪点的众数色。
- 在调色板中找到含众数色的色对，取其配对色。
- 找到边框为配对色的小盒，裁剪输出其内部图案（不含边框）。

关键洞察：
- 众数色不出现在输出中，它只是间接寻址的第一把钥匙；调色板是码本而非装饰，
  边框是索引而非内容。"统计→查表→检索→裁剪"每层都只提供指向下一层的键，
  直接拿众数色当边框索引会掉进诱饵盒。
```

## 7. 转角跳相的染色路径

- 参考题目: `d35bdbdc`、`1e97544e`、`ff2825db`
- tags:
  - operation:重涂色, recolor
  - operation:周期推断, periodic_inference
  - object:路径, path
  - object:调色板行, palette_row
  - relation:相位偏移, phase_shift
  - condition:转角跳相, corner_phase_skip

### docstring

```text
沿灰色一笔画路径从彩色端点走起，用调色板的颜色循环逐格染色，每过一个转角相位额外前进一位。

输入结构：
- 顶行是一段调色板：若干不同颜色从左到右排成一列，定义循环色序。
- 网格中有一条 4 连通、一笔画、无分叉的灰色路径；路径一端起始于一个彩色像素，
  该颜色出现在调色板中。

规则：
- 从彩色端点出发沿路径逐格行走；起点格染端点色，每前进一格，颜色沿调色板
  循环推进一位。
- 走到路径的转角格（行进方向改变的格子）时，颜色推进两位而不是一位。
- 走完整条路径；调色板与端点像素在输出中保持原样。

关键洞察：
- 直行段是均匀的周期色带，转角是相位跳变点；只按"逐格循环"推色会在第一个
  转角之后全部错位。发现"转角吃掉一个相位"才是唯一能同时满足所有示例的规则。
```

## 8. 反弹镜像的印章轨迹

- 参考题目: `045e512c`、`3e980e27`、`cb2d8a2c`、`1a07d186`
- tags:
  - operation:印章覆盖, stamp
  - operation:镜像, mirror
  - operation:补全, complete
  - object:精灵体, sprite
  - object:部分副本, partial_copy
  - object:标记像素, marker_pixel
  - relation:位移向量, displacement_vec
  - relation:边界反射, boundary_reflection
  - condition:标记终止并染色, marker_stops_and_recolors

### docstring

```text
由残缺副本给出初始位移向量，精灵沿该向量反复盖章前进，撞到边界就反弹并镜像自身，盖到标记像素处停止并重涂。

输入结构：
- 黑背景上有一个多格的非对称彩色精灵，和一个与它同形状同色、但只画出部分
  像素的残缺副本，两者的对应位置给出一个位移向量。
- 网格另一处有一个单独的标记像素，颜色与精灵不同。

规则：
- 先把残缺副本补全，然后按位移向量继续盖出下一个完整副本，如此重复。
- 若下一次盖章会越出网格，则将位移向量在越界方向上取反，并把精灵沿该方向的
  轴镜像，再继续盖章。
- 当某次盖出的副本覆盖到标记像素时，本次盖章完成后停止；该副本整体重涂为
  标记像素的颜色。

关键洞察：
- 残缺副本既是待补全的对象又是速度的编码；边界不是终点而是镜面——反弹的
  同时形状翻转（精灵非对称，翻转可见）；标记像素既是唯一的停靠信号，又是
  终点副本的染色指令。
```
