## 1. 管线配对互换

- 参考题目题号：1 (dd6b8c4b)、12 (ad173014)、14 (5a719d11)
- tags:
  - operation:交换, swap
  - operation:重涂色, recolor
  - object:墙壁障碍, wall_barrier
  - object:密室, chamber
  - object:连接线, connector_line
  - object:精灵体, sprite
  - relation:连通配对, connectivity_pairing
  - condition:连线颜色作为涂色源, connector_color_source
  - condition:忽略邻近诱饵, ignore_proximity_decoy

### docstring

```text
沿彩色管线追踪密室之间的真实配对，把成对密室中的精灵互换位置并染成管线的颜色。

输入结构：
- 网格大部分被墙色填充，墙体中开凿出若干矩形密室，每间密室内有一个单色精灵。
- 每两间密室之间由一条蜿蜒的彩色管线穿墙相连，不同管线颜色不同；管线只负责连接，贴着密室边沿终止，不进入密室内部。
- 密室在版面上排成规则阵列，几何上相邻的密室往往不是管线相连的那一对。

规则：
- 追踪每条管线，找出它连接的两间密室，这两间密室构成一对。
- 将成对密室中的精灵互换：每个精灵保持自身形状，平移到对方密室中原精灵所占的位置（按包围盒对齐），原位置擦除。
- 互换后的两个精灵都重涂为连接这对密室的管线颜色；墙体、管线与密室空腔保持不变。

关键洞察：
- 配对关系不由距离或阵列位置决定，而由管线的连通拓扑决定；管线同时还是涂色的颜色源——
  它既回答"谁和谁换"，也回答"换完是什么颜色"。
```

## 2. 随向侧标

- 参考题目题号：5 (ecaa0ec1)、13 (3ad05f52)、15 (c87289bb)、16 (35ab12c3)
- tags:
  - operation:寻路, pathfinding
  - operation:印章覆盖, stamp_overlay
  - operation:旋转, rotate
  - object:走廊通道, corridor
  - object:入口标记, entry_marker
  - object:侧标像素, sidecar_pixel
  - relation:行进方向参照系, travel_frame_of_reference
  - condition:唯一通路, unique_route
  - condition:忽略干扰项, ignore_distractors

### docstring

```text
沿迷宫中唯一的单格宽通路行进，把入口处示范的"左侧装饰"随行进方向旋转着刻满沿途的墙壁。

输入结构：
- 网格由墙色与背景色构成一座迷宫，从入口标记到出口标记只存在一条宽度为一格的通路。
- 入口标记是一个特殊颜色的像素，位于通路起点；紧贴它、相对初始行进方向左侧的墙格上有一个装饰色像素，作为示范。
- 迷宫其他位置散布个别无关的杂色像素，与入口装饰无关。

规则：
- 找到从入口到出口的唯一通路，把通路上的每个背景格染成入口标记的颜色。
- 沿通路逐步行进，对每一步，把该步起点格按当前行进方向左侧紧邻的墙格染成装饰色；拐弯之后按新方向继续取"左侧"。
- 出口标记、墙体其余部分与散布的杂色像素保持不变。

关键洞察：
- 装饰所在的"左侧"不是固定方位，而是随行进方向旋转的相对方向；必须先确定行进朝向
 （由入口指向出口），入口旁的示范像素只给出第一步的相对位置关系，后续全靠随向推演。
```

## 3. 孔洞方向舵

- 参考题目题号：1 (dd6b8c4b)、3 (64a7c07e)、11 (8698868d)、14 (5a719d11)
- tags:
  - operation:平移, translate
  - operation:填充, fill
  - operation:擦除, erase
  - object:精灵体, sprite
  - object:孔洞, hole
  - object:彩色墙段, colored_wall
  - relation:孔洞偏移定方向, hole_offset_determines_direction
  - condition:滑行至墙, slide_until_wall
  - condition:墙色填孔, wall_color_plugs_hole

### docstring

```text
每个带偏心孔的色块朝孔洞偏离中心的方向一直滑到墙边，并用撞上的那面墙的颜色把孔填上。

输入结构：
- 网格中立着若干条直线墙段，不同墙段颜色不同。
- 背景上散布若干实心单色块，每块内部有一个背景色的孔洞；孔洞明显偏向色块中心的上、下、左或右一侧。
- 各色块的滑行路线互不交叠，不会与其他色块相撞，且每个滑行方向上都有一条彩色墙段挡住。

规则：
- 对每个色块，取孔洞相对色块中心的偏离方向（上下左右之一）作为它的滑行方向。
- 将色块沿该方向平移，直到紧贴第一条挡路的墙段为止，原位置擦除为背景。
- 到位后，把色块的孔洞填上它所紧贴的那面墙的颜色；墙体保持不变。

关键洞察：
- 孔洞是藏在物体内部的"方向舵"：它的偏心方向决定运动方向，而不是就近吸附或统一的重力方向；
  撞墙之后墙色反过来灌入孔中——运动的原因（孔）被运动的结果（墙色）填补。
```

## 4. 宽度闸筛落

- 参考题目题号：8 (05a7bcf2)、14 (5a719d11)、15 (c87289bb)
- tags:
  - operation:重力下落, gravity_drop
  - operation:重涂色, recolor
  - operation:擦除, erase
  - object:隔板线, shelf_line
  - object:缺口, gap
  - object:下落块, falling_block
  - relation:全跨对齐, full_span_alignment
  - condition:整跨落入缺口才穿过, pass_only_if_span_inside_gap
  - condition:停靠层定色, landing_shelf_colors_block

### docstring

```text
顶部的色块竖直下落，只有整个宽度都正对缺口时才能穿过一层隔板，最终停在哪层就染成哪层的颜色。

输入结构：
- 网格中横向排布若干条彼此平行的隔板线，每条隔板颜色不同、各自留有一段背景色缺口；最底一条隔板没有缺口。
- 隔板上方悬着若干实心矩形块，宽度与水平位置各不相同；各块所占的列区间互不重叠。

规则：
- 每个块保持所在列不变竖直下落；遇到一条隔板时，仅当块所占的全部列都落在该隔板缺口范围内才穿过去，否则停在这条隔板正上方。
- 依次对更下方的隔板重复判断，直到停下；没有缺口的最底隔板拦住所有到达它的块。
- 每个块停稳后整体重涂为拦住它的那条隔板的颜色，原位置擦除为背景。

关键洞察：
- 能否穿过一层不取决于块比缺口窄，而取决于块的整个列跨度是否恰好正对缺口——又窄又没对准照样被拦；
  块最终的颜色不是自带的，而是由它被哪一层接住来追认。
```

## 5. 测地距离定平铺跨度

- 参考题目题号：6 (017c7c7b)、9 (29623171)、13 (3ad05f52)
- tags:
  - operation:寻路, pathfinding
  - operation:平铺, tiling
  - object:分隔线, divider_line
  - object:迷宫面板, maze_panel
  - object:端点像素, endpoint_pixel
  - object:周期条带, periodic_strip
  - relation:跨面板传参, cross_panel_parameter
  - relation:最短路径, shortest_path
  - condition:测地长度为跨度, geodesic_length_sets_span

### docstring

```text
用迷宫面板里两端点之间的最短绕行步数，作为另一面板中周期条带应当补全到的总长度。

输入结构：
- 一条贯穿整图的分隔线把网格分成两个面板。
- 一个面板是迷宫：背景中立着若干墙段，另有两个同色端点像素分居两处；墙的摆放挡住两点间的直线方向，必须绕行。
- 另一个面板中有一条沿直线方向重复的周期图案条带，只画出了开头若干个周期，条带前方留有足够空位。

规则：
- 在迷宫面板中求两个端点之间的四连通最短路径长度，取路径所含格数（含两个端点）。
- 在条带面板中识别图案的重复周期，沿原方向继续平铺，直到条带占据的总格长恰好等于该最短路径长度；超出部分不画，允许截断在一个周期中间。
- 迷宫面板与分隔线保持原样输出。

关键洞察：
- 条带该有多长，在条带自己所在的面板里找不到答案：它由另一个面板中绕墙的测地距离决定——
  距离必须沿迷宫实际可走的路计量，直线距离和网格宽度都是诱饵。
```

## 6. 自相似递归

- 参考题目题号：2 (810b9b61)、11 (8698868d)、17 (c7f57c3e)
- tags:
  - operation:嵌套放置, nest_inside
  - operation:缩放, scale
  - object:空心框架, hollow_frame
  - object:孔洞, hole
  - relation:包含, containment
  - relation:孔形与体形自相似, hole_shape_self_similar
  - condition:自相似才延拓, recurse_only_if_self_similar

### docstring

```text
只有孔洞形状是自身外轮廓缩小版的空心物体，才在孔洞中央按同一缩放比例再画出下一层同形副本。

输入结构：
- 黑色背景上分布若干互不相触的单色空心物体，每个物体都完整包住一个居中的背景色孔洞。
- 一部分物体的孔洞与该物体的外轮廓是同一形状的整倍缩小（如方环套方孔、十字环套十字孔）；
  另一部分物体的孔洞形状与外轮廓不同（如方环套十字孔）。

规则：
- 对每个物体，比较孔洞形状与该物体外轮廓形状，判定标准为同形（允许整体缩放，不允许旋转翻转）。
- 若二者同形，按外轮廓到孔洞的缩放比例，在孔洞中央用该物体自身的颜色再画一个缩小一级的实心同形副本。
- 若二者不同形，该物体保持原样；所有物体的位置与颜色均不改变。

关键洞察：
- 判定条件是一种隐藏的自指：孔要与"孔所在物体自己的外形"相比较，而不是与其他物体或固定模板相比较；
  判定通过后要做的事是把这条缩放规律再向内延拓一层，而不是简单的重涂或填充。
```

## 7. 缺角指针链

- 参考题目题号：5 (ecaa0ec1)、7 (7bb29440)、19 (342ae2ed)、20 (91714a58)
- tags:
  - operation:选择, selection
  - operation:裁剪, crop
  - object:实心矩形, solid_rectangle
  - object:缺角, missing_corner
  - object:起点标记, start_marker
  - relation:指针链, pointer_chain
  - relation:对角偏移, diagonal_offset
  - condition:沿缺角对角线逐跳追踪, follow_notch_diagonal
  - condition:忽略旁链诱饵, ignore_decoy_chain

### docstring

```text
从带标记的矩形出发，沿每个矩形缺角所指的对角方向逐跳追踪，输出链条终点那个完好矩形的裁剪。

输入结构：
- 背景上散布若干实心单色矩形；一部分矩形缺了一个角格，另一部分四角完好。
- 恰有一个矩形内部含有一个特殊颜色的标记像素，它是追踪的起点；起点矩形也缺一个角。
- 从每个缺角矩形的缺角处沿对角方向引出的射线都恰好命中一个别的矩形；完好矩形不止一个，
  且版面上不止一条链以完好矩形收尾（存在诱饵链）。

规则：
- 从含标记的矩形开始，沿其缺角所在的对角方向作射线，命中的下一个矩形即为下一跳。
- 若下一跳矩形也有缺角，继续按它的缺角方向追踪；直到跳到一个四角完好的矩形为止。
- 输出该终点矩形的裁剪（其包围盒内容），其余一切舍弃。

关键洞察：
- 缺角不是残损而是指针：每个矩形用缺掉的角报出下一跳的方向；因为版面上存在多条指针链和多个完好矩形，
  只有从标记起点忠实地逐跳走完，才能知道哪个完好矩形是真正的终点。
```

## 8. 拐弯奇偶接力

- 参考题目题号：12 (ad173014)、15 (c87289bb)、18 (17b80ad2)、19 (342ae2ed)
- tags:
  - operation:计数, counting
  - operation:传播, propagate
  - operation:填充, fill
  - object:导线, wire
  - object:源像素, source_pixel
  - object:灯泡框, bulb_frame
  - object:分叉点, branch_point
  - relation:拐角事件计数, corner_event_counting
  - condition:累计奇偶决定通断, cumulative_parity_switches_state

### docstring

```text
信号从源点沿导线传播，每拐一次直角弯翻转一次，沿途每个灯泡按信号到达它时的累计奇偶被点亮或熄灭。

输入结构：
- 一个彩色源像素引出一条单格宽折线导线；导线沿途串联若干空心灯泡框，并可在分叉点分成多条支路。
- 支路的中途与末端都可能有灯泡；各段导线的拐弯次数各不相同。

规则：
- 信号从源出发沿导线传播，每经过一个直角拐弯翻转一次：源色与灰色互换（源色为亮、灰色为灭）。
- 每到一个灯泡，用信号当前的颜色填满该灯泡内部，然后信号原状继续向后传播（灯泡本身不改变信号）。
- 分叉处信号以当时的状态分别进入各支路，各支路独立累计其后的拐弯；源像素、导线与灯泡外框保持不变。

关键洞察：
- 一个灯泡的亮灭由"从源到它沿途累计"的拐弯奇偶决定，而不是由它邻近一段导线的形状决定；
  只看灯泡前最后一段的弯数，在多灯串联与分叉时会得出错误结论——第一个示例对里往往恰好蒙对，
  后面的示例对才拆穿这个诱饵。
```
