## 1. 缺陷即指令

- tags:
  - operation:周期补全, periodic_completion
  - operation:整体平移, global_translate
  - object:重复瓦片, repeating_tile
  - object:缺陷像素, defect_pixel
  - relation:颜色即位置编码, color_as_position_code
  - condition:位移向量求和, offset_vector_sum
- 参考题目题号: 17、20、16

### docstring

```text
把每个错色缺陷解码为一个位移向量，将修复后的周期图案按所有向量之和整体循环平移。

输入结构
- 整个网格由一个小矩形瓦片周期铺满，瓦片内每个格子的颜色互不相同。
- 少数格子的颜色被替换成了瓦片中另一位置的颜色，构成缺陷。

规则
- 由多数一致的区域推断出最小瓦片。
- 对每个缺陷格：设它按周期应有颜色 A、实际是颜色 B，B 在瓦片内的位置减去 A 在瓦片内的位置，得到一个位移向量。
- 将所有缺陷的位移向量求和，把完全修复后的周期图案按该总向量循环平移，作为输出。

关键洞察
- 缺陷不是要抹掉的噪声，而是一组分布式指令：因为瓦片内颜色互不相同，每个错色都唯一编码一个向量；答案是"修复并按指令总和平移"，只做修复会落入陷阱。
```

## 2. 走序嵌套环

- tags:
  - operation:贪心遍历, greedy_traversal
  - operation:同心环绘制, concentric_draw
  - object:起始块, start_block
  - object:目标块, target_block
  - relation:视线可见, line_of_sight_visible
  - condition:访问顺序定嵌套序, visit_order_nesting
- 参考题目题号: 15、12

### docstring

```text
按"最近可见"贪心访问顺序，把访问到的色块重画成一幅由外向内的嵌套方环。

输入结构
- 黑色背景上有一个红色 2×2 起点块和若干互不同色的 2×2 目标块。
- 部分块处于同一双行带或双列带中；带内夹在两块之间的任何非背景像素会遮挡视线。

规则
- 从红块出发，反复走向"同带可见且距离最近"的未访问块，直到再无可见的未访问块。
- 输出一个边长为 2k-1 的正方形，k 为被访问块数（含红块）。
- 最外环用红色，随后每往内一环使用访问序列中下一个块的颜色，中心一格为最后被访问块的颜色。
- 从未被访问到的块不出现在输出中。

关键洞察
- 嵌套顺序既不是按面积也不是按位置排序，而是一次会被遮挡的贪心视线行走的访问顺序；有些块虽然存在却永远走不到。
```

## 3. 钥匙插锁

- tags:
  - operation:旋转, rotate
  - operation:平移, translate
  - object:空心矩形容器, hollow_container
  - object:带齿对象, keyed_object
  - object:边框缺口, border_notch
  - relation:齿孔嵌合, tooth_slot_fit
  - condition:封闭容器不动, closed_container_static
- 参考题目题号: 14、11、9

### docstring

```text
把每个容器内的对象旋转成正确朝向的"钥匙"，插进容器边框的锁孔缺口里。

输入结构
- 黑色背景上有若干单像素厚的矩形边框容器，颜色各异。
- 每个容器内部有一个另一种颜色的小对象，由一个实心主体和一个单像素凸齿组成，对象无旋转对称性。
- 部分容器的边框上恰缺一格（锁孔），其余容器完全封闭。

规则
- 对每个有锁孔的容器：将内部对象绕自身旋转 0/90/180/270 度，使凸齿的朝向与锁孔所在边的朝外法向一致。
- 再平移对象，使凸齿恰好落在锁孔那一格、主体紧贴容器内壁，并从原位置擦除对象。
- 封闭容器及其内部对象保持不动。
- 输出中锁孔被对象的凸齿堵住，边框上出现一格异色。

关键洞察
- 缺口不是让对象逃出去的出口，而是锁孔——对象是钥匙，必须先旋转到齿对准孔再插入；堵住边框缺口的不是边框自身的颜色，而是钥匙的齿。
```

## 4. 跨尺度互校

- tags:
  - operation:形状匹配, shape_matching
  - operation:缺陷修复, defect_repair
  - object:缩放对象, scaled_object
  - object:蓝图对象, blueprint_object
  - object:干扰对象, distractor_object
  - relation:跨尺度同形, cross_scale_same_shape
  - condition:纯色自洽裁决, purity_adjudication
- 参考题目题号: 4、20

### docstring

```text
小图与它的放大副本各被篡改了一个像素，用放大块的纯色自洽性裁决每处不一致是谁的错并双向修复。

输入结构
- 背景色占多数，画面上有三个对象：一个多色小图、一个把它按整数倍 k 放大的副本（每个原格对应一个 k×k 纯色块）、一个形状无关的干扰对象。
- 小图上恰有一个像素被改成别的颜色；放大副本中恰有一个块内也有一个像素被改成别的颜色；两处位置不同。

规则
- 在三个对象中找出互为整数倍缩放的一对，剩下的是干扰。
- 逐格比对小图与放大副本，找到恰好两处不一致。
- 若不一致处的放大块是纯色，说明小图那格被篡改，把小图该格改成放大块的颜色。
- 若不一致处的放大块不纯（混入单个杂色像素），说明放大副本被篡改，把该杂色像素改回块的主色。
- 其余一切保持不变。

关键洞察
- 不一致本身分不出对错，裁决者是放大结构的内部自洽性——纯色块自证清白；两处缺陷必须分别向"对方"求真，不存在单一的标准答案方。
```

## 5. 隐形偏转器

- tags:
  - operation:流动绘制, flow_draw
  - operation:角点推断, corner_inference
  - object:边缘起点像素, edge_source_pixel
  - object:角点标记, corner_marker
  - relation:缺角定方向, missing_corner_direction
  - condition:推断中心处偏移, deflect_at_inferred_center
- 参考题目题号: 13、18

### docstring

```text
让边缘出发的水流在若干"隐形偏转器"处拐弯，偏转器的位置和方向都由三个角点标记的残缺正方形推断出来。

输入结构
- 黑色网格的上边缘有若干青色起点像素，水流向下流动。
- 场上散布若干组黄色像素，每组恰为一个轴对齐正方形的三个角，且各组彼此远离。

规则
- 对每组黄色角点，推断正方形的中心格与缺失的第四角。
- 从每个青色起点向下画青色路径；当路径将要进入某个推断中心格时，改为进入其缺角一侧的相邻格，然后继续向下。
- 黄色角点保持原样；路径画到下边缘为止。

关键洞察
- 起偏转作用的对象从未被画出：三个角点既定位了隐形偏转器的中心，缺失的那个角又给出了偏转方向。
```

## 6. 碰撞连锁

- tags:
  - operation:滑动, slide
  - operation:连锁触发, chain_trigger
  - object:空心矩形, hollow_rect
  - object:触发标记, trigger_marker
  - relation:颜色编码方向, color_coded_dir
  - condition:碰撞传递运动, collision_transfers_motion
- 参考题目题号: 3、15

### docstring

```text
一枚灰色触发点唤醒第一个精灵，运动沿碰撞链逐个传递，每个精灵都朝自己颜色规定的方向滑行。

输入结构
- 黑色背景上有若干 3×3 空心方形精灵，颜色取自方向码：绿=向左、黄=向下、粉=向上、青=向右。
- 恰有一个灰色像素与某个精灵相邻，作为唯一的起始触发点。

规则
- 被触发的精灵沿其颜色方向滑行：若途中撞上另一个精灵，则贴着它停下，并把"被触发"传给撞上的那个精灵；若一路畅通，则滑到贴住网格边缘，连锁结束。
- 每个精灵至多被触发一次；从未被触发的精灵原地不动。
- 灰色触发点保留在原位，输出为所有精灵的最终位置。

关键洞察
- 精灵颜色只是各自的方向码，真正决定"谁动"的是碰撞因果链；场上会留下永远没被撞醒的精灵作为诱饵。
```

## 7. 射线围墙

- tags:
  - operation:射线延伸, ray_extend
  - operation:洪泛填充, flood_fill
  - object:实心矩形, solid_rectangle
  - object:空心矩形, hollow_frame
  - relation:角对角对齐, corner_diagonal_align
  - relation:射线成墙, rays_as_walls
  - condition:围合区域才填充, fill_only_enclosed
- 参考题目题号: 19、5

### docstring

```text
被框角选通的对角射线充当围墙，把它们与网格边界围出的空地用空心框的颜色灌满。

输入结构
- 网格有占多数的背景色、一个实心矩形对象和一个与之分离的单像素厚空心方框，两者颜色不同。

规则
- 从实心矩形的每个外角沿朝外的对角线方向追踪；若这条射线遇到的第一个非背景像素恰好是空心框的一个角，则该射线被激活：把从矩形角出发直到网格边界的整条对角线上的背景格全部染成矩形的颜色（穿过框角继续延伸）。
- 未被选通的射线不画。
- 所有激活射线画完后，若存在被"射线像素与网格边界"完全围住、且内部不含任何原有对象像素的背景连通区域，将该区域洪泛填充为空心框的颜色。

关键洞察
- 射线不是答案而是中间构造物——它们先要通过"角对角"检验被选通，再作为新的围墙参与第二阶段的封闭区域判定；两阶段分别使用两个对象的颜色。
```

## 8. 指针链条带

- tags:
  - operation:重涂色, recolor
  - operation:链式跳转, pointer_chase
  - object:横条, horizontal_bar
  - object:起点条带, start_bar
  - relation:长度即序号指针, length_as_index_pointer
  - condition:越界或重访终止, stop_on_invalid_or_visited
- 参考题目题号: 6、7

### docstring

```text
条带的长度是指向"第几条"的指针：从绿色条带出发沿指针链行走，把走过的条带染红。

输入结构
- 黑色背景上从上到下排列着若干互不接触的水平条带，恰有一条是绿色，其余为蓝色。
- 条带长度不一。

规则
- 将条带自上而下编号为 1、2、3……
- 从绿色条带开始：读当前条带的长度 n，跳到序号为 n 的那条条带并把它染红，再读它的长度继续跳转。
- 当指针指向不存在的序号、或指向已访问过的条带时，行走终止。
- 绿色条带保持绿色，未被走到的蓝色条带保持蓝色。

关键洞察
- 长度既不参与大小比较也不是周期规律，它是指向序号的指针；被染红的集合看似毫无规律，实际是一条隐藏的指针链的轨迹，链的起点由唯一的绿色条带给出。
```
