## 1. 转角印章

- tags:
  - operation:印章覆盖, stamp_overlay
  - operation:旋转, rotate
  - operation:擦除, erase
  - object:精灵体, sprite
  - object:路径拐点, path_corner
  - relation:沿路径累积状态, cumulative_state_along_path
  - condition:转向定旋向, turn_sets_rotation
- 参考题目题号: 12 (2b9ef948)、6 (ed98d772)、17 (fd02da9e)

### docstring

```text
沿灰色折线在每个拐点盖上按累计转向旋转后的精灵印章，并擦除折线。

输入结构
- 黑色背景；一个单色小精灵（奇数边长，中心明确）。
- 一条灰色4连通折线，一端与精灵相邻（起点端），另一端悬空。
- 折线拐点彼此远离，保证各印章互不重叠且不出界。

规则
- 从精灵端沿折线行进，精灵初始朝向为原朝向。
- 每经过一个左转拐点，累计逆时针旋转90度；每经过一个右转拐点，累计顺时针旋转90度。
- 在每个拐点处，以拐点为中心盖上当前累计旋转后的精灵副本。
- 在折线终点再盖一次最终朝向的副本。
- 输出中灰色折线全部擦为背景，原精灵原地保留。

关键洞察
- 灰路径的端点位移毫无意义，信息全部藏在拐点序列里——每个印章的朝向记录的是行进至该点为止的净转向数，路径是一条被读完即焚的指令带。
```

## 2. 节奏对调

- tags:
  - operation:压缩, compress
  - operation:去重, deduplicate
  - operation:平铺, tile
  - object:拉伸块, stretched_block
  - relation:相邻重复, adjacent_repeat
  - relation:双通道分离, dual_channel_separation
  - condition:行列节奏互换, row_col_rhythm_swap
- 参考题目题号: 9 (e1baa8a4)、16 (cf5fd0ad)

### docstring

```text
把拉伸色块网格分解为颜色矩阵与行、列两条拉伸节奏，再让两条节奏互换后重新拉伸，图案本身不动。

输入结构
- 无背景的二维色块网格，由一个小的方形答案矩阵拉伸而成：第i个答案行被复制r_i次，第j个答案列被复制c_j次。
- r序列与c序列各自内部不全相等，两序列也互不相同。

规则
- 把相邻重复的行、列分组压缩，得到颜色矩阵，同时记录行节奏序列r=(r_1,...,r_n)与列节奏序列c=(c_1,...,c_n)。
- 输出把同一颜色矩阵按节奏互换重新拉伸：第i个答案行复制c_i次，第j个答案列复制r_j次。

关键洞察
- 网格携带两条互相独立的信息通道——颜色图案与拉伸节奏；输出既不是压缩、也不是转置：图案原地不动，只有行与列的节奏彼此易位。第一眼的"去重压缩"或"整体转置"读法都会在示例的尺寸与花纹上双双对不上。
```

## 3. 无角残弧补环

- tags:
  - operation:描边, outline
  - operation:生长, grow
  - object:同心环, concentric_ring
  - object:残段, arc_fragment
  - object:隐藏中心, hidden_center
  - relation:同心约束联立, concentric_constraint_join
  - condition:残迹反推生成元, residue_infers_generator
- 参考题目题号: 5 (d22278a0)、2 (5c2c9af4)

### docstring

```text
由几段不含拐角的环壁残段反推未画出的公共中心，补全所有出现过的同心方环并点出中心。

输入结构
- 黑底上有若干条同色的水平或垂直短线段。
- 它们都是以某个未画出的像素为中心的正方形环（切比雪夫等距环）的边段，且没有任何一段包含环的拐角。
- 这些残段合起来唯一确定中心位置。

规则
- 找到唯一能让所有残段落在其同心方环上的中心格。
- 对每个至少留有一段残段的半径，画出完整的方环（出界部分裁掉），环色与残段相同。
- 把中心格涂成红色。

关键洞察
- 任何一段孤立边段都定不出中心——一条水平段只说明"中心行距它某个未知半径"，必须联立不同朝向、不同半径的残段求交；被要求画出的主角（中心与整环）在输入里一个像素都没有出现。
```

## 4. 择空折光

- tags:
  - operation:射线延伸, ray_extend
  - operation:连线, draw_line
  - operation:折叠, fold
  - object:起点标记, start_marker
  - object:铰点像素, hinge_pixel
  - relation:逐点局部决策链, chained_local_decision
  - condition:空间大侧转向, turn_toward_space
- 参考题目题号: 18 (230f2e48)、10 (ea786f4a)、1 (bcb3040b)

### docstring

```text
从边缘标记射入一条光线，每碰到一个灰点就朝剩余空间更大的一侧拐90度，画出全程路径。

输入结构
- 黑色背景；一个彩色起点像素贴在网格边缘，行进方向为垂直该边向内。
- 若干灰色铰点散布网格中，只有部分会被光线经过。
- 在每个被经过的铰点处，左转、右转两个方向到网格边缘的距离不相等。

规则
- 光线从起点直行；进入灰色铰点时，比较左转、右转两个方向从该点到网格边缘的格数，转向格数更大的一侧。
- 继续直行并在后续铰点重复同样的比较，直到光线从边缘离开。
- 把光线经过的所有非灰格涂成起点色，铰点保持灰色。

关键洞察
- 铰点没有画出任何镜面朝向——转向不由铰点自身属性决定，而由当场丈量的两侧空旷程度决定；未被命中的灰点是纯粹的旁观者，误把它们全部纳入路径的读法在示例上走不通。
```

## 5. 指针接力传色

- tags:
  - operation:填充, fill
  - operation:擦除, erase
  - object:分隔线, separator_line
  - object:窗口格, window_cell
  - object:偏心标记, off_center_marker
  - relation:偏移即指针, offset_as_pointer
  - relation:链式回溯, chain_traceback
  - condition:链头定色, chain_head_sets_color
- 参考题目题号: 8 (54d9e175)、20 (b7256dcd)

### docstring

```text
各窗口内偏离中心的标记是指向邻窗的指针，颜色沿指针链从链头一路流到链尾，链上每个窗口都涂成链头的颜色。

输入结构
- 灰色整行整列分隔线把网格划成3x3窗口阵。
- 每个窗口恰有一个彩色标记像素，位于窗口中心或八个偏心位置之一。
- 偏心标记的偏移方向总指向存在的相邻窗口（含对角）；指针不构成环，每条链的最后一个窗口持中心标记；每个窗口至多被一个指针指中。
- 同一条链中间窗口的标记颜色与链头颜色不同。

规则
- 把"甲窗偏心标记指向乙窗"连成链；没有被任何指针指中且自身为偏心标记的窗口是链头。
- 链头的标记颜色沿链逐窗传递，链上每个窗口（含持中心标记的链尾）整窗涂成链头色。
- 不属于任何链的窗口整窗涂黑；原标记随重涂消失，灰色分隔线原样保留。

关键洞察
- 窗口的成色既不是自身标记色也不是直接上游的标记色，而要沿指针一路回溯到无人指中的源头——中间窗口的标记只是转发地址，不是颜料；"按自身标记填色"和"按上一窗标记填色"两种直觉读法都会在示例上破产。
```

## 6. 对角接力染色

- tags:
  - operation:重涂色, recolor
  - operation:擦除, erase
  - object:中性遮罩, neutral_mask
  - object:标记像素, marker_pixel
  - relation:对角接触图, diagonal_contact_graph
  - relation:最近归属, nearest_ownership
  - condition:跳数定归属平局冻结, hop_ownership_tie_freeze
- 参考题目题号: 20 (b7256dcd)、5 (d22278a0)

### docstring

```text
标记色沿灰块之间的对角接触一跳一跳接力传播，各灰块归属跳数最近的颜色，平局保持灰色。

输入结构
- 背景为最常见色；灰色像素构成若干4连通组件，组件之间只以对角相碰。
- 每个彩色标记像素与某个灰组件边相邻；至少两种标记颜色同场。

规则
- 与标记边相邻的组件是该颜色的0跳源。
- 颜色沿"对角接触"关系逐层扩散，一次接触算一跳；每个灰组件染成到它跳数最小的那种标记色。
- 若两种颜色以相同最小跳数到达，该组件保持灰色；无法到达的组件也保持灰色。
- 所有标记像素擦为背景。

关键洞察
- 组件之间从不共享边——真正的连通网络藏在4连通视角看不见的对角碰点上；染色是一场以组件为节点的最短路竞赛，而不是一次性的邻接传色。
```

## 7. 面积守恒注水

- tags:
  - operation:对接, dock
  - operation:填充, fill
  - operation:擦除, erase
  - operation:计数, counting
  - object:U形框架, u_shaped_frame
  - object:实心矩形, solid_rectangle
  - relation:同色匹配, same_color_matching
  - condition:面积守恒定液面, area_conserved_level
- 参考题目题号: 4 (b0c4d837)、19 (7c66cb00)、14 (4347f46a)

### docstring

```text
把每个实心色块当作定量液体倒进同色的U形容器，按面积守恒重新确定液面高度。

输入结构
- 黑色背景；若干开口向上的U形框，各用一种颜色，内宽互不相同。
- 别处漂浮着与框同色的实心矩形块，每块面积恰能被同色框的内宽整除。
- 块的宽度与同色框的内宽一般不相等。

规则
- 每个矩形块找到唯一同色的U形框。
- 把块擦除，在该框内部自底向上涂同色液体，液体总格数等于块的面积。
- 液面高度即块面积除以框内宽。

关键洞察
- 液面高度既不是块的高度也不是块的宽度——液体入容器要重新铺开，守恒的只有格子总数；宽框液面比原块矮、窄框液面比原块高的反差正是规则的指纹。
```

## 8. 跨角双折印花

- tags:
  - operation:镜像, reflect
  - operation:裁剪, clip
  - operation:透明叠加, transparent_overlay
  - operation:重涂色, recolor
  - object:实心矩形, solid_rectangle
  - object:精灵体, sprite
  - relation:越界折回, overflow_fold_back
  - condition:双折即点对称, double_fold_is_point_symmetry
  - condition:碰撞变红, collision_red
- 参考题目题号: 3 (8be77c9e)、7 (506d28a5)、1 (bcb3040b)

### docstring

```text
精灵悬出纸角，把两侧悬出部分各沿其纸缘折回、角外部分连折两次，叠印在纸上，落点已有像素处变红。

输入结构
- 黑底上有一个单色实心矩形（纸）和一个另色精灵。
- 精灵恰好跨过纸的一个角：同时悬出两条相邻边缘，角外也有像素。
- 各部分折回后都不越过纸的对侧边缘。

规则
- 保留精灵在纸上的部分。
- 仅悬出一条边的像素沿那条纸缘对折翻回纸面（紧贴纸缘外侧的一列/行落到纸缘那一列/行上）。
- 同时悬出两条边的角外像素先后沿两条纸缘各折一次翻回纸面（次序不影响结果）。
- 每个翻回像素落在空纸面上涂精灵色，落在已有精灵色像素的格上则该格涂红。
- 纸外的精灵像素全部擦除，纸的其余部分不变。

关键洞察
- 折纸只有一张纸，悬出像素却有三种命运——单侧悬出走镜像、角外悬出等价于绕纸角的点对称；红格是多层落点的指纹，输出图案是一份原件与三份折影的叠印。
```
