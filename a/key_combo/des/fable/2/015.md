## 1. 钥匙补孔

- tags:
  - operation:形状匹配, shape_matching
  - operation:旋转, rotate
  - operation:重涂色, recolor
  - operation:擦除, erase
  - object:空心矩形锁, hollow_lock
  - object:钥匙精灵, key_sprite
  - relation:孔位补集匹配, hole_complement_match
  - condition:旋转下唯一咬合, unique_fit_under_rotation
- 参考题目题号: 10、14、6

### docstring

```text
将每把彩色钥匙旋转后填入唯一能补满其内部孔洞的锁中，并把孔洞涂成钥匙的颜色。

输入结构
- 黑色背景上有若干单色空心矩形"锁"，锁框内部部分格子涂了框色（固定齿），
  其余内部格子为黑色孔洞。
- 场上散布与锁数量相同的单色 4 连通"钥匙"，颜色互不相同，且不与任何锁框同色。
- 每把钥匙在 0/90/180/270 度旋转中恰有一种方式使其形状与恰好一个锁的孔洞逐格重合；
  存在格子数相同但形状不互补的干扰配对，且距离最近的钥匙往往不是匹配者。

规则
- 对每把钥匙尝试四种旋转，找出唯一与某个锁的内部黑色孔洞完全重合的旋转与归属。
- 将该锁的孔洞格全部涂成对应钥匙的颜色，原钥匙位置擦除为黑色。
- 锁框与固定齿保持不变。

关键洞察
- 锁内的框色格子不是图案而是"已有部分"，钥匙要匹配的是缺失的补集；
  面积相等不代表互补，必须在旋转下逐格咬合，孔洞最终的颜色由配对关系决定而非就近原则。
```

## 2. 计数柱旋转

- tags:
  - operation:旋转, rotate
  - operation:重涂色, recolor
  - object:枢轴标记, pivot_marker
  - object:计数柱, counter_bar
  - object:线段, line_segment
  - relation:高度编码旋转量, height_encodes_rotation
  - condition:模四回绕, modulo_four_wrap
- 参考题目题号: 14、9、2

### docstring

```text
按下方黄色计数柱的高度模四，绕灰色枢轴顺时针旋转红色臂并留下绿色残影。

输入结构
- 黑色背景上有若干独立装置：一个灰色枢轴像素，一条从枢轴某侧伸出的红色直臂
  （水平或垂直，长度不一）。
- 每个枢轴正下方隔一个黑格挂着一根竖直黄色计数柱，柱高各不相同，可为 4 及以上。
- 每个装置旋转后的红臂均不越出画布，也不与其他装置重叠。

规则
- 读取计数柱高度 h，将红臂绕枢轴顺时针旋转 h 个四分之一圈（即 h 模 4 次 90 度）。
- 先把原红臂格全部改为绿色，再在旋转后的位置画等长红臂；两者重叠处以红色为准。
- 枢轴与计数柱保持不变。

关键洞察
- 黄色柱不是场景物体而是旋转次数计数器；高度为 4 的装置看似"免疫"实为整圈回绕
  （绿色残影被红臂原样覆盖，画面无变化），这一"无变化"样例正是识破模四编码的钥匙。
```

## 3. 双色地图与笔刷

- tags:
  - operation:印章覆盖, stamp_overlay
  - operation:旋转, rotate
  - operation:像素放大, pixel_upscale
  - object:控制精灵体, control_sprite
  - object:宏单元格模式, macro_cell_pattern
  - relation:粗模板精细替换, coarse_to_fine_substitution
  - relation:颜色编码朝向, color_encodes_orientation
  - condition:色数定角色, color_count_assigns_role
- 参考题目题号: 19、13、14

### docstring

```text
用单色笔刷精灵按双色地图放大作画，地图格颜色决定笔刷贴入时是否旋转 180 度。

输入结构
- 黑色背景上远离放置两个矩形精灵：一个"地图"精灵，其前景格由红、蓝两色构成；
  一个"笔刷"精灵，仅一种前景色，且形状在 180 度旋转下不对称。
- 输出画布为地图尺寸乘以笔刷尺寸的放大网格。

规则
- 地图的每个格子对应输出中一个笔刷大小的块，黑格对应全黑块。
- 红色地图格：将笔刷掩码原样贴入对应块；蓝色地图格：将笔刷掩码旋转 180 度后贴入。
- 贴入的笔刷像素涂成该地图格自身的颜色（红格产生红笔刷、蓝格产生蓝笔刷）。

关键洞察
- 两个精灵的角色由色数区分：双色者是布局，单色者是笔刷；宏格颜色同时承担两个职责
  ——决定块内涂色与决定笔刷朝向，只有注意到贴入图案存在两种互为倒转的姿态才能解码蓝格的含义。
```

## 4. 动量传递

- tags:
  - operation:推移, push
  - operation:滑动, sliding
  - object:固定标记, fixed_marker
  - object:前景对象, fg_object
  - object:网格边界, grid_boundary
  - relation:动量接力, momentum_relay
  - relation:碰撞阻挡, collision_block
  - condition:紧贴组透传, contact_group_passthrough
  - condition:末端至边界, last_reaches_boundary
- 参考题目题号: 20、8、18

### docstring

```text
栗色发射器沿外向推动相邻物体，动量在碰撞时逐个传递，紧贴成组的物体只弹出最远端者，
最后一个获得动量的物体撞到边界为止。

输入结构
- 背景为黑色，栗色像素构成固定发射器，恰有一个彩色 4 连通物体贴在发射器的某个正侧。
- 沿该外向方向的通道上散布若干互不相同颜色的物体，行（或列）区间与运动路径重叠；
  有些物体彼此紧贴成组。
- 通道尽头是网格边界。

规则
- 被发射的物体沿外向直线滑行，直到紧贴路径上的下一个物体后停下；动量传给被撞者。
- 若被撞者与更多物体紧贴成组，动量穿过整组，组保持不动，
  由组在运动方向最远端的物体被弹出继续滑行。
- 如此接力，最后获得动量的物体一直滑到网格边界停下；
  栗色发射器与未被波及的物体保持原位。

关键洞察
- 这不是"所有物体被推到墙边堆积"的重力题：任一时刻只有一个物体在动，
  碰撞点就是停靠点；紧贴组充当动量导管，看似最先该动的挡路者反而原地不动。
```

## 5. 投影重建与标记裁剪

- tags:
  - operation:裁剪, crop
  - operation:绘制, drawing
  - operation:擦除, erase
  - object:边缘线段, edge_bar
  - object:标记像素, marker_pixel
  - relation:投影配对, projection_pairing
  - relation:标记选中候选, marker_selects_candidate
  - condition:同色横竖成对, same_color_pair
  - condition:隐形对象重建, latent_object_reconstruction
- 参考题目题号: 15、11、12

### docstring

```text
顶边横条与左边竖条按颜色配对给出一批从未画出的矩形，
输出被黄色标记选中的那个矩形的空心框。

输入结构
- 网格第 0 行有若干互不重叠的彩色横条，第 0 列有同一批颜色的彩色竖条，
  同色条恰好一横一竖配对。
- 内部其余区域为黑色，恰有一个黄色标记像素（黄色不作条色）。
- 每种颜色对应一个假想矩形：列范围取自顶边同色横条、行范围取自左边同色竖条；
  黄色标记恰好落在其中一个假想矩形的范围内部，且不落入任何其他假想矩形范围。

规则
- 按颜色把顶条与左条配成坐标对，确定每个假想矩形的行列范围。
- 找到包含黄色标记的那个假想矩形。
- 输出一个与该矩形范围等大的网格，画出该颜色的一格宽空心矩形框，
  内部全黑（标记不保留）。

关键洞察
- 画面里没有任何矩形：两条边上的色条是同一物体在两个方向上的投影残迹；
  标记的作用不是被变换，而是从多个仅存在于推理中的候选里点名一个，
  答案的尺寸与颜色都要靠配对还原。
```

## 6. 量杆印章

- tags:
  - operation:印章覆盖, stamp_overlay
  - operation:擦除, erase
  - object:矩形体, rectangular_body
  - object:连接杆, connector_stem
  - object:网格边界, grid_boundary
  - relation:杆长编码间隔, stem_encodes_period
  - relation:颜色交替, parity_alternation
  - condition:越界即停, stop_before_overflow
- 参考题目题号: 18、7、10

### docstring

```text
把每个矩形本体沿其量杆方向反复盖章，相邻副本之间留出恰为杆长的空隙，
副本颜色在杆色与本体色之间交替。

输入结构
- 黑色背景上有若干独立结构：一个单色实心矩形本体，
  加一条从本体某侧中部伸出的一格宽直杆，杆色不同于本体色。
- 杆的长度不小于本体沿杆方向的边长（保证副本互不重叠）。
- 各结构的复制路径互不干扰，且方向各异。

规则
- 擦除量杆，保留本体。
- 沿杆的方向依次生成本体的副本：每个副本与前一个之间的空隙恰好等于杆长；
  第一个副本涂杆色，第二个涂本体色，如此交替。
- 当下一个副本会越出网格边界时停止，不画不完整的副本。

关键洞察
- 直杆酷似"滑向锚点的连接杆"，实为节拍尺：它不指示目的地，
  而是同时给出复制的方向、间隔与第一个副本的颜色相位；
  杆本身在输出中消失，只留下以它为周期的交替印记。
```

## 7. 双镜错格修复

- tags:
  - operation:压缩, compress
  - operation:镜像, mirror
  - operation:重涂色, recolor
  - object:格子结构, lattice
  - object:色带分组, color_band
  - relation:行列交叉, row_column_intersection
  - relation:双轴交叉校验, cross_axis_verification
  - condition:唯一错格, single_wrong_cell
- 参考题目题号: 17、6

### docstring

```text
把带孔噪声的格块图压缩成粗色网格，用左右与上下双镜像交叉定位唯一涂错的粗格并修复，
输出修复后的粗色网格。

输入结构
- 背景包围着一片由单色格块铺成的矩形点阵区，块内散布背景色孔洞，块的行高列宽不均一。
- 连续的行在同一行带内可见前景色集合相同，列同理，可据此切分行带与列带；
  每个行带×列带交叉块恰有一种前景色。
- 压缩后的粗色网格本应同时满足左右镜像与上下镜像对称，
  但恰有一个粗格颜色涂错，同时破坏两条对称轴。

规则
- 按行、列的前景色集合切分带，将每个交叉块提为一种颜色，得到粗色网格。
- 在粗网格上找左右镜像不匹配的格对，仅凭这一对无法分辨谁对谁错，
  再用上下镜像交叉验证——同时违背两轴的那个格子才是错格。
- 把错格改成它三个对称伙伴共有的颜色，输出修复后的粗色网格。

关键洞察
- 孔洞噪声使像素层面处处不对称，对称只在粗尺度成立；
  而单轴镜像只能发现矛盾不能裁决真伪，必须用第二条对称轴仲裁，
  错格是两轴证词的交点。
```
