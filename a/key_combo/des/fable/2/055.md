## 1. 斜向周期的破洞修复

- 参考题目题号: 17 (3cd86f4f)、15 (d8c310e9)、13 (fb791726)
- tags:
  - operation:错切, shear
  - operation:平铺补全, tile_complete
  - operation:填充, fill
  - object:平行四边形条带, sheared_band
  - object:最小周期单元, minimal_period
  - object:对角线边缘, diagonal_edge
  - relation:斜向平移对称, diagonal_translation_symmetry
  - condition:边缘斜率定错切步长, slope_determines_shear_step

### docstring

```text
把被逐行错切的竖直周期图案摆正，并用周期补全其中的黑色破洞。

输入结构
- 黑色背景上有一个平行四边形前景条带：它由某个 H×W 矩形图案将第 r 行
  整体向右平移 k·r 格得到，k 为固定错切步长（各示例不同），可由条带
  左缘对角线的斜率读出。
- 原矩形图案沿竖直方向以最小周期 q 重复（q<H），且不存在短的水平周期。
- 条带内部若干格被抠成黑色破洞，破洞不会同时打穿同一列上的整条周期链。

规则
- 由左缘斜率确定错切步长 k，把第 r 行向左平移 k·r 格，撤销错切，
  得到 H×W 矩形。
- 在摆正后的矩形上求对所有可见前景一致的最小竖直周期 q，用同列相距
  q 的完好格推断每个破洞应有的颜色。
- 输出补全后的 H×W 矩形图案。

关键洞察
条带在原坐标系里既无水平周期也无竖直周期，重复方向是斜的：只有先从
边缘斜率反推错切量、回到摆正坐标系，竖直周期才会显形并可用于补洞；
输出要求摆正矩形，堵住了"沿斜向直接复制"的捷径。
```

## 2. 自洽变换与颜色配对

- 参考题目题号: 20 (7d419a02)、6 (60d73be6)、11 (9565186b)
- tags:
  - operation:坐标压缩, coordinate_compression
  - operation:重涂色, recolor
  - operation:假设检验, hypothesis_testing
  - object:分隔线, separator_line
  - object:单色块阵, monochrome_block_matrix
  - object:遮盖块, occluded_block
  - relation:隐藏变换下的颜色配对, color_pairing_under_hidden_transform
  - condition:唯一自洽变换, unique_consistent_transform
  - condition:自配对假象诱饵, self_pairing_decoy

### docstring

```text
在三种候选变换中找出唯一使"颜色配对"自洽的隐藏变换，据此归纳配对表并
恢复被灰色遮盖的块。

输入结构
- 黑色的整行、整列分隔线把网格切成一个块阵，各行高、各列宽互不相等，
  因此像素级的任何对称都不成立。
- 每个块被单一颜色整块填充，其中若干块为灰色遮盖块；灰色只作遮盖色出现。
- 把块阵压缩成颜色矩阵后，存在唯一一种变换 T（取自：矩阵中心 180°
  点对称、左右镜像、上下镜像），使得每一对 (块 b, 块 T(b)) 的颜色构成
  一张一致的双向配对表（例如红↔蓝、黄↔绿，个别颜色与自身配对）；在
  另外两种变换下必然出现同一颜色对应两种颜色的矛盾。
- 配对表每个示例各不相同，需自行归纳。每个灰块在 T 下的伙伴块保证非灰，
  且所需配对已在非灰块对中出现过。

规则
- 忽略像素尺寸，把块阵读成压缩的颜色矩阵。
- 对三种候选变换分别检验：收集所有非灰块对的颜色对应，若无矛盾则该
  变换自洽；取唯一自洽的变换并归纳其配对表。
- 对每个灰块，取其在该变换下伙伴块的颜色，经配对表映射后整块涂上；
  分隔线与非灰块保持不变。

关键洞察
画面上没有任何肉眼可见的对称——变换联系的是"配对色"而非"相同色"，
无法靠视觉扫描发现，只能把每种变换当作假设去检验配对的自洽性；自配对
的颜色还会制造出局部普通对称的假象，诱导错误的变换选择，直接照搬伙伴
颜色会在非自配对处出错。
```

## 3. 测地波前充能

- 参考题目题号: 19 (8f3a5a89)、4 (271d71e2)、11 (9565186b)
- tags:
  - operation:泛洪填充, flood_fill
  - operation:逐步充能, incremental_charge
  - operation:擦除, erase
  - operation:计数, counting
  - object:墙壁障碍, wall_barrier
  - object:装饰碎片, decoration_fragment
  - object:能量条, energy_bar
  - object:地砖, floor_tile
  - object:角落标记, corner_marker
  - relation:测地距离排序, geodesic_distance_ranking
  - condition:边界连通区分结构, border_connected_structural
  - condition:能量守恒转移, energy_transfer

### docstring

```text
从角落标记出发沿通道计步，把测地距离最近的若干块灰砖点亮，并耗尽能量条。

输入结构
- 背景为主色，蓝色像素构成墙体；接触网格边界的蓝色连通部件是结构墙，
  悬在内部、不接边界的蓝色碎片是装饰。
- 一个品红单像素标记贴在某个角落的通道里；通道各处散布若干灰色地砖。
- 网格某一边贴着一段橙色能量条，长度为 N，与主区域被结构墙隔开。
- 设计保证：各灰砖到标记的绕墙最短步数互不相同，且灰砖总数大于 N。

规则
- 从标记做四连通洪水填充：结构墙阻挡，装饰碎片不阻挡并被擦成背景色。
- 对每块灰砖计算绕墙的最短步数，取最近的 N 块涂成橙色；其余灰砖保持灰色。
- 能量条整条变灰，表示 N 格能量已全部转移给点亮的地砖。

关键洞察
"最近"是绕墙的测地距离而非直线距离——直线更近的砖可能因绕行更远而
落选；同时只有接边界的蓝色才是真正的墙，内部碎片是要清除的假障碍，
误把碎片当墙会算错绕行路线。
```

  - operation:擦除, erase

  - relation:行列位置对应, row_column_correspondence
  - relation:涌现控制信号, emergent_control_signal
  - condition:四分支跨域动作, four_way_cross_domain_action

### docstring

```text
用两块面板逐格比较的结果驱动灰色模板点阵：单侧前景涂色，双前景旋转，
双背景擦除。

输入结构
- 网格一侧是 R 行 C 列的灰色小模板点阵，模板之间隔一格背景；每个模板
  是 3×3 包围盒内的灰色掩码，形状各异且多数不中心对称。
- 另一侧由一条分隔色竖线隔开两块 R×C 的面板，二者共享同一背景色，
  各自恰有一种前景色，两前景色不同。
- 点阵的行列数与面板尺寸严格相等。

规则
- 把两块面板逐格对齐比较，每个位置得到四种结果之一，并作用于点阵中
  同行同列的模板：
  - 仅左面板是前景：模板的灰色像素涂成左面板前景色，形状不变；
  - 仅右面板是前景：模板涂成右面板前景色，形状不变；
  - 两侧都是前景：模板保持灰色，但绕自身 3×3 中心旋转 180°；
  - 两侧都是背景：模板被整个擦成背景色。
- 输出裁剪为只含模板点阵的区域。

关键洞察
真正的控制图例在画面上并不存在——它是两块面板比较后才涌现的产物；
且比较结果驱动的动作横跨两个域：有的改颜色、有的改几何、有的删除，
单看任何一块面板或只盯颜色变化都拼不出完整规则。
```

## 5. 噪声即图例

- 参考题目题号: 12 (94be5b80)、11 (9565186b)
- tags:
  - operation:计数, counting
  - operation:印章覆盖, stamp_overlay
  - operation:擦除, erase
  - object:精灵体, sprite
  - object:散点图例, scatter_legend
  - object:插槽, slot
  - relation:频率排序, frequency_ranking
  - condition:名次定槽位, rank_determines_slot
  - condition:锚定推断栈几何, anchors_fix_stack_geometry

### docstring

```text
把散落像素的颜色频次读成图例，按名次补齐竖直精灵栈并清空散点。

输入结构
- 黑色背景。同一精灵掩码的若干彩色实例在画面一侧排成左缘对齐、间距
  相等的竖直栈，栈中若干槽位空缺。
- 画面其余区域散落多种颜色的单像素点，各颜色的像素数互不相同；散点
  颜色集合恰好等于完整栈应有的颜色集合。
- 已放置实例的颜色，其散点数名次与其所在槽位序号一致（数量最多的在
  最顶槽）；每个示例至少空缺两个不同颜色的槽位。

规则
- 统计每种散点颜色的像素数，按数量从多到少排出名次，名次即栈从上到
  下的槽位。
- 由已放置实例读出掩码、左缘与竖直间距，推出全部槽位位置。
- 在每个空槽位放入对应名次颜色的精灵实例；擦除所有散点。

关键洞察
画面上没有色条图例——看似该清理的噪声本身就是图例，颜色的出现次数
编码了它在栈中的名次；由于每例至少空缺两个不同颜色的槽，缺色的归属
只能靠计数决定，无法由已放实例的顺序旁推。
```

## 6. 同色相消的连锁下落

- 参考题目题号: 7 (25ff71a9)、4 (271d71e2)、10 (a680ac02)
- tags:
  - operation:滑动, sliding
  - operation:擦除, erase
  - object:彩色单元块, colored_cell_block
  - object:钉子, pin
  - relation:同色相邻, same_color_adjacency
  - condition:段长阈值消除, segment_length_threshold
  - condition:连锁反应, chain_reaction

### docstring

```text
色块在列内下落堆叠，同色相邻的整段消除后继续下落，直至连锁停止。

输入结构
- 黑色背景的竖直网格，各列中悬浮着若干彩色单元格，其间有空隙；同列
  中可出现重复颜色。
- 部分位置固定着灰色钉子：钉子不下落、不参与消除，下落的色块会被钉
  子托住。
- 示例中至少出现一次多轮连锁：一次消除腾出的空间使原本不相邻的同色
  块再次相遇。

规则
- 每列独立处理：所有彩色格向下坠落，落在网格底边、钉子或已堆叠的色
  块之上。
- 堆叠稳定后，同列内竖直相邻且同色的极大连续段若长度不小于二，则整
  段消除变黑。
- 消除腾出空间后其上方色块继续下落，可能拼出新的同色段，重复"下落—
  消除"直到稳定；灰钉与最终存留的色块即为输出。

关键洞察
这不是一次性的重力题：消除与再下落会连锁传导，隔着数个空位、原本互
不相邻的同色块可能在多轮塌落后相遇并一起消失，最终画面必须沿因果链
逐步推演，而钉子改变堆叠位置从而改变整条连锁的走向。
```

## 7. 取景窗的修复与装订

- 参考题目题号: 10 (a680ac02)、15 (d8c310e9)、3 (890034e9)
- tags:
  - operation:平铺, tile
  - operation:补全, complete
  - operation:裁剪, crop
  - operation:排序, sorting
  - operation:拼接, concatenate
  - object:空心矩形, hollow_rectangle
  - object:最小周期单元, minimal_period
  - relation:沿主轴排列, along_main_axis
  - condition:周期不符即涂改, deviation_marks_tampering
  - condition:先修复后裁剪, repair_before_crop

### docstring

```text
以全局周期修复各取景框内被涂改的图案，再把框内画面按主轴顺序装订成条。

输入结构
- 整个网格由一个二维周期图案平铺；图案上叠放若干个同色同尺寸、互不
  重叠的空心矩形框。
- 每个框内部有若干格被涂改成与周期不符的颜色；框外图案完好。

规则
- 由框外区域推断图案的最小二维周期。
- 对每个框，取其内部区域，把与周期预测不符的涂改格恢复成周期应有的
  颜色。
- 按各框中心沿分布主轴排序（列向分布更散则按列序从左到右，否则按行
  序从上到下），把修复后的内部区域边贴边拼接成一条输出。

关键洞察
矩形框不是要处理的对象而是取景窗；直接裁剪会把涂改一并带走，必须先
用只在框外可见的全局周期把窗口内容修复，再完成排序装订——修复、排序
两层缺一则输出即错。
```
