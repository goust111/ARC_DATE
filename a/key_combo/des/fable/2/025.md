## 1. 缺口互指传色

- tags:
  - operation:射线延伸, ray_extend
  - operation:填充, fill
  - operation:重涂色, recolor
  - object:空心矩形, rectangular_frame
  - object:边框缺口, border_gap
  - relation:视线匹配, sightline_matching
  - condition:缺口定向传色, gap_directed_color_transfer
- 参考题目题号: 551d5bf1, d4f3cd78, 696d4842

### docstring

```text
每个带缺口的空心框把自身颜色注入它"瞄准"的框，同时用对方的颜色封住自己的缺口。

输入结构：
- 黑色背景上有若干互不相触的单色空心矩形框，颜色互不相同。
- 每个框的边界上恰有一个非角缺口，框内部全为黑色。
- 从缺口沿该边的外法线方向看去，视线要么穿过纯黑背景后命中另一个框的边，要么径直离开网格。

规则：
- 对每个框，从缺口向外沿垂直于该边的方向作视线。
- 若视线命中另一个框：把被命中框的内部全部涂成发射框的颜色；同时把发射框自己的缺口那一格补上，颜色用被命中框的颜色。
- 若视线径直离开网格：该框不注入任何颜色，自己的缺口保持为黑。
- 视线经过的背景格保持黑色，不画射线。

关键洞察：
- 缺口既不是要修补的缺陷，也不是往外流的出口，而是一门"颜色炮"：颜色沿视线单向送进对方肚子里，而封口的颜色反向报出对方的身份；两框之间形成一对方向相反的颜色回执，互瞄的框看似"交换颜色"，单向瞄准的框则只收不发。
```

## 2. 隐形斜镜折光

- tags:
  - operation:射线延伸, ray_extend
  - operation:镜像, reflect
  - object:标记像素, marker_pixel
  - object:未画出的对称轴, invisible_axis
  - relation:镜像对应, mirror_correspondence
  - condition:推断对称轴, infer_symmetry_axis
  - condition:配对与孤点区分, paired_vs_singleton
- 参考题目题号: 981571dc, 696d4842, cb227835

### docstring

```text
一面从未画出的45度斜镜由成对像素暗示，孤立像素发出的水平光线在镜上折成竖直方向。

输入结构：
- 黑背景网格上散布若干彩色像素。
- 其中某些颜色恰好出现两次，两点关于同一条45度斜线互为镜像；这样的颜色对至少有两组。
- 其余颜色各只出现一次，是发射点；每个发射点所在行与那条斜线在网格内相交，且其光路上没有其他前景像素。

规则：
- 由所有成对像素推断出唯一的45度镜线（被该斜线穿过的格子连成的对角线）。
- 每个孤立像素沿自己所在的行朝镜线方向发出光线，用自身颜色涂满沿途背景格。
- 光线到达镜线所在格时不涂该格，按45度镜面的反射规律折成竖直方向，继续涂色直到网格边缘。
- 成对像素原样保留，镜线本身始终不显形。

关键洞察：
- 镜子从未被画出，画面上只有它的"倒影证据"；必须先区分哪些像素是成对的倒影、哪些是孤立的光源，再由像素对反演出镜线的位置与朝向（"/"或"\"），光线的折向由镜的朝向唯一决定，折点留黑正是镜子存在的唯一痕迹。
```

## 3. 暗号接龙成阶

- tags:
  - operation:堆叠, stacking
  - operation:平移对齐, translate_and_align
  - object:实心矩形, solid_rectangle
  - object:标记像素, marker_pixel
  - relation:链式指针, linked_chain
  - condition:标记色即后继色, marker_color_is_successor
  - condition:冲突优先级, conflict_priority
- 参考题目题号: 03560426, 776ffc46, ad7e01d0

### docstring

```text
按矩形体内暗藏的颜色指针把散乱矩形串成链，再折成左上起步的对角重叠阶梯。

输入结构：
- 背景为最常见色，前景是若干互不相触的单色实心矩形，体色互不相同。
- 除一个矩形外，每个矩形内部恰嵌有一个异色标记像素，标记色总等于另一个矩形的体色。
- 各标记色互不相同，且没有标记指向自身所在的矩形。

规则：
- 把每个矩形的标记色理解为"下一个矩形"的体色，从而把全部矩形串成一条链；链头是体色未被任何标记引用的矩形，链尾是没有标记的矩形。
- 清空画布为背景色，抹去所有标记，按链序摆放纯色矩形：链头的左上角贴网格左上角。
- 摆完一个高 h 宽 w 的矩形后，下一个矩形的左上角放在它右下角的同一格上（向下 h-1 行、向右 w-1 列），后放的矩形覆盖共享的角格。

关键洞察：
- 矩形的排列顺序与输入中的位置、大小、颜色深浅全都无关，真正的序藏在体内那颗"暗号像素"构成的单向指针链里；输入的空间布局是诱饵，按位置排序在部分示例上碰巧成立、在其余示例上必然失败。
```

## 4. 多米诺推倒

- tags:
  - operation:连锁反应, chain_reaction
  - operation:倒伏变换, topple_transform
  - object:立柱, vertical_bar
  - object:触发标记, trigger_marker
  - relation:顺序传递, sequential_propagation
  - condition:高度编码打击距离, height_encodes_reach
  - condition:冲突优先级, conflict_priority
- 参考题目题号: 03560426, 696d4842, d4f3cd78

### docstring

```text
从被标记的立柱开始向一侧推倒，柱高决定倒伏后能打到多远，够得着的柱继续连锁倒下。

输入结构：
- 网格底行为地面，其余为黑背景。
- 若干互不同色、宽为一格的竖直立柱立在底行上，彼此间隔不等。
- 恰有一个红色标记像素紧贴某根立柱柱顶的一侧；标记在哪一侧，该柱就向另一侧倒（推力方向）。

规则：
- 被推的高 h 立柱倒伏：变成占据底行、从自身立足格起沿倒向连续 h 格的横条，颜色不变。
- 若这段横条覆盖到另一根立柱立足格所在的列，该柱同向倒下，连锁继续；横条够不着的柱保持直立。
- 链上后倒的柱覆盖与先倒横条重叠的格子；红色标记从输出中消失。

关键洞察：
- 每根柱的高度就是它倒下后的"打击半径"；连锁能传多远不取决于间距的任何表面规律，而取决于沿途每根柱各自的高度是否恰好够到下一根——一根偏矮的柱就会让链条中断，它身后的柱群整体幸存。
```

## 5. 碎影共识

- tags:
  - operation:透明叠加, transparent_overlay
  - operation:修复, repair
  - operation:裁剪, crop
  - object:锚点像素, anchor_pixel
  - object:残缺副本, corrupted_copy
  - relation:锚点对齐, anchor_alignment
  - condition:多数决定色, majority_vote
- 参考题目题号: 137eaa0f, 981571dc, e8686506

### docstring

```text
把多份各自残缺、彼此散落的副本按灰色锚点配准叠合，逐格取多数色还原从未完整出现过的原图。

输入结构：
- 黑背景上散布若干互不相触的多色碎片，每个碎片恰含一个灰色像素。
- 所有碎片都是同一张隐藏图案的残缺副本：以灰点为公共基准点对齐后，各副本缺失了一部分格子，个别格子还被改成了错误颜色。
- 篡改只换色、不增格；图案范围为对齐后诸副本的并集，且每一格上正确颜色的出现次数严格多于任何其他颜色。

规则：
- 将每个碎片按其灰点平移到同一基准位置，叠成一摞。
- 对齐后至少被一个副本覆盖的每一格，取各副本在该格所给颜色中的严格多数作为输出色。
- 输出为还原图案的最小包围盒裁剪，灰点处保留灰色。

关键洞察：
- 完整的图案从未在画面上出现过，任何单个碎片都既残缺又含谎言；灰点不是颜色信息而是配准记号，把碎片当作独立对象去比较形状或颜色都会走进死路，真相只存在于全体副本逐格投票的共识之中。
```

## 6. 双轴拉伸印章

- tags:
  - operation:印章覆盖, stamp
  - operation:像素放大, pixel_scale
  - object:基元图案, motif
  - object:标记像素, marker_pixel
  - relation:双轴独立编码, two_axis_encoding
  - condition:行距列距分别定倍率, gap_per_axis_encodes_scale
  - condition:等比诱饵, uniform_scale_decoy
- 参考题目题号: 762cd429, ad7e01d0, 696d4842

### docstring

```text
角落图案被盖到各个灰点上，灰点到图案的行向间距与列向间距分别决定副本的竖直与水平放大倍数。

输入结构：
- 黑背景，左上角贴边放着一个多色小图案（基元）。
- 其余前景是散布在基元右下方向的灰色单像素标记（行差、列差均不为零）。
- 每个标记所在行与基元包围盒底边之间隔 dr 行纯背景，所在列与包围盒右边之间隔 dc 列纯背景（dr、dc 至少为 1，可不相等）。
- 各副本互不重叠且不越界；部分示例中恰好 dr 等于 dc。

规则：
- 对每个标记，分别读出竖直空隙 dr 与水平空隙 dc。
- 把基元每个像素拉伸成 dr 行 × dc 列的色块，得到各向异性放大的副本。
- 副本的左上角放在该标记格上，向右下方展开，覆盖标记；基元本体保持不动。

关键洞察：
- 一个灰点里藏着两个旋钮：到图案的竖直空隙和水平空隙是两条互相独立的编码轴。先见到的 dr=dc 示例会诱导出"距离决定等比倍率"的错误假设，只有把间距拆成两个方向分别读数，扁长与瘦高的副本才能得到解释。
```

## 7. 量杯注液

- tags:
  - operation:计数, counting
  - operation:填充, fill
  - object:杯形轮廓, cup_outline
  - object:液滴色块, liquid_blob
  - relation:容量配对, capacity_matching
  - condition:像素数等于内腔容积, count_equals_capacity
  - condition:忽略形状诱饵, ignore_shape_decoy
- 参考题目题号: d4f3cd78, 794b24be, 776ffc46, aab50785

### docstring

```text
把每摊形状各异的彩色"液体"倒进内腔容积恰好等于其像素数的杯子里灌满。

输入结构：
- 黑背景上有若干灰色杯子：顶边留有开口、近乎封闭的空心矩形轮廓，内腔为黑。
- 另散布若干单色不规则连通色块（液体），颜色互不相同，与杯子互不相触。
- 每摊液体的像素数与恰好一个杯子的内腔格数相等，配对全局唯一。
- 个别液体的轮廓形状恰好能几何地嵌进某个错误的杯腔。

规则：
- 数出每摊液体的像素数与每个杯子的内腔面积。
- 将像素数与内腔面积相等的液体与杯子配对。
- 输出中把每个杯子的内腔全部涂成配对液体的颜色，液体原位置清为黑，杯壁保持灰色。

关键洞察：
- 液体的轮廓形状全是幌子——按"形状能不能放进去"匹配会被诱饵带偏；真正守恒的是"体积"：液体倒进杯里会摊平灌满，配对只认像素计数，杯子是量杯而不是拼图槽。
```

## 8. 寻的停靠

- tags:
  - operation:循环移位, cyclic_shift
  - object:面板, panel
  - object:标记像素, marker_pixel
  - relation:颜色寻的, color_homing
  - relation:面板对应, panel_correspondence
  - condition:同色像素停靠标记列, homing_pixel_docks_at_marker
- 参考题目题号: e345f17b, cfb2ce5a, 776ffc46

### docstring

```text
右侧面板每行的彩色标记指定左侧图案该行中的同色像素，并命令该行循环移位使该像素停靠到标记所在列。

输入结构：
- 一条竖直灰线把网格分成左右两块等宽面板。
- 左面板是一幅多色图案，每行含多种颜色。
- 右面板黑底，每行恰有一个彩色标记；标记的颜色在左面板对应行中恰好出现一次。

规则：
- 对每一行，在左面板该行中找到与右面板标记同色的唯一像素。
- 将该行循环移位（移出一端的格子从另一端绕回），使这个像素落到与标记相同的面板内列位上。
- 输出为移位后的左面板，尺寸与左面板相同。

关键洞察：
- 右面板既不是要逐格比对的第二张图，也不是直接给出位移量的数值表——标记的颜色说"找谁"，位置说"停哪"，每行的实际移位量从不出现在画面上，必须由起点与停靠位反解；同一行里其他颜色都是干扰，认错寻的像素整行就会错位。
```

## 9. 筛墙分流

- tags:
  - operation:平移对齐, translate_and_align
  - operation:裁剪, crop
  - object:空心矩形围墙, hollow_wall
  - object:实心色块, solid_block
  - object:边框缺口, border_gap
  - relation:部分穿透, partial_pass_through
  - condition:对齐缺口者穿墙到对面内壁, aligned_part_passes_to_far_wall
- 参考题目题号: 551d5bf1, e8686506, aab50785

### docstring

```text
色块滑向带缺口的围墙，与缺口对齐的部分穿墙直达对面内壁，其余部分被墙挡下贴在墙外。

输入结构：
- 网格中央有一个大的灰色空心矩形围墙，某些边上开有直线缺口（不含角），墙内为空。
- 墙外散布若干单色实心矩形色块，互不相触。
- 每个色块沿朝墙的法线方向滑动时，其跨度恰与一个缺口的跨度部分重叠（色块比缺口宽），滑动路径上没有其他前景。

规则：
- 每个色块沿法线方向朝对应的墙边平移。
- 与缺口跨度对齐的那部分列穿过缺口继续前进，直到前端抵达对面墙的内壁停下，途中占据缺口格，把墙塞住。
- 未对齐缺口的其余列被墙的外壁挡住，停在紧贴墙面处。
- 两部分都保持原色，色块原位置清为背景。

关键洞察：
- 墙是一张筛网而不是单纯的障碍：一个整块在这里被剪开并分流——穿过的部分成为横贯墙内的长舌，挡下的部分成为贴墙的残块；缺口的位置与宽度决定了从哪里剪开、剪下多少、穿过后走多远，把色块当整体去"停靠"或"塞洞"在多数示例上都对不上。
```

## 10. 背向印章场

- tags:
  - operation:印章覆盖, stamp
  - operation:旋转, rotate
  - object:控制像素, control_pixel
  - object:带指向特征的源图案, pointed_motif
  - relation:径向朝向, radial_orientation
  - condition:相对方位定旋转, relative_direction_sets_rotation
- 参考题目题号: ad7e01d0, fc7cae8d, cfb2ce5a

### docstring

```text
把带"箭头"的模板盖到每个灰点上，各副本旋转到箭头背离模板本体的方向。

输入结构：
- 黑背景上有一个奇数边长正方形包围盒的多色模板，带有明显的指向特征（如一枚突出的鼻尖像素），本体不具旋转对称性。
- 其余前景是散布的灰色单像素控制点；每个控制点相对模板中心的行差与列差绝对值不等，主导方向唯一（上、下、左或右）。
- 各控制点足够分散，盖章后互不重叠、不越界、不压到模板本体。

规则：
- 对每个控制点，取它相对模板中心的主导方向（行差、列差中绝对值较大者的符号方向）。
- 将模板绕自身中心旋转，使其指向特征朝向该主导方向，得到副本。
- 把副本的中心格对准控制点盖下，控制点被覆盖；模板本体保持原样。

关键洞察：
- 控制点携带的不是颜色指令，而是方位：整幅画是一个以模板为圆心的辐射场，每个副本像罗盘针一样把鼻尖转向背离圆心的一方；旋转角度写在控制点与模板的几何关系里，而不在任何颜色对照表中，按固定朝向盖章只在个别方向的控制点上碰巧成立。
```
