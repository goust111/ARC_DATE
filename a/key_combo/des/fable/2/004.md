## 1. 计数寻址表格

- tags:
  - operation:计数, count
  - operation:填充, fill
  - object:分隔线网格, separator_grid
  - object:网格单元格, grid_cell
  - relation:计数即地址, count_as_address
  - relation:表格行列位, table_row_col_pos
  - condition:行优先编号, row_major_indexing
  - condition:同时寻址, simultaneous_addressing
- 参考题目: 4、11、15

### docstring

```text
把每个单元格内的像素数量当作行优先地址，向被寻址的单元格整格投递该颜色。

输入结构
- 单一分隔色构成完整的横竖网格线，将画布划分为 R 行 C 列的矩形单元格。
- 部分单元格内散布着若干同色像素（一个格内只有一种颜色），其余单元格为空。
- 同一输入中各源格的像素数量互不相同，且都不超过单元格总数。

规则
- 保留分隔线，清除所有散布像素。
- 将单元格按行优先顺序从 1 编号到 R×C。
- 对每个含 n 个颜色 c 像素的源格，把编号为 n 的单元格整格填满颜色 c。
- 所有寻址同时依据输入完成：目标格自身是否为源格不影响它接收颜色，
  其自身的计数仍照常向别处寻址。

关键洞察
- 像素数量不是要统计的量，而是一个指向表格位置的地址；填充目标与像素
  所在的单元格位置无关，粗看像直方图统计，实为同时完成的表内投递。
```

## 2. 开口互补走廊

- tags:
  - operation:连线, connect
  - operation:填充, fill
  - object:空心矩形, hollow_rectangle
  - object:墙壁开口, wall_opening
  - object:走廊, corridor
  - relation:开口互补配对, opening_complement_pair
  - condition:区间精确对齐, span_exact_match
  - condition:未配对封口, unmatched_sealed
- 参考题目: 14、1、2

### docstring

```text
只把墙上开口区间完全对齐的两个房间用走廊接通，落单的开口用墙色封死。

输入结构
- 背景上散布若干同色空心矩形房间，墙厚一格。
- 某些房间的墙上有开口：一段连续缺失的墙。
- 两个开口若朝向相对、所占的行（或列）区间完全相同、且它们之间的间隙
  全为背景，则互为搭档；每个开口至多有一个搭档。

规则
- 对每一对搭档开口，在两房间之间画走廊：沿开口区间外侧紧邻的两行
  （或两列），用墙色把两面墙连接起来，走廊内部保持背景。
- 没有搭档的开口用墙色补回，恢复成完整的墙。
- 房间其余部分保持不变。

关键洞察
- 连接资格由开口区间的精确对齐决定，而不是由房间距离决定；相距最近的
  两个开口未必能配对，而配不上的开口必须被封闭而非保留。
```

## 3. 残迹叠合

- tags:
  - operation:印章覆盖, stamp
  - operation:补全, completion
  - object:精灵体, sprite
  - object:锚点标记, anchor_marker
  - relation:锚点对齐, anchor_alignment
  - relation:并集重建, union_reconstruction
  - condition:无完整样本, no_complete_instance
- 参考题目: 7、15

### docstring

```text
用锚点把同一形状的多份残缺副本对齐叠合，重建从未完整出现过的原形，并把每份副本原位补全。

输入结构
- 背景占主导。画布上散布同一颜色的若干像素团，它们都是同一个隐藏形状
  的残缺副本：每份只保留了原形的一部分像素，且缺失的部分各不相同。
- 每份副本带有恰好一个异色锚点像素；锚点在隐藏形状坐标系中的位置对
  所有副本一致。
- 没有任何一份副本是完整的。

规则
- 以锚点为原点对齐所有副本，取像素并集，得到完整的隐藏形状。
- 在每份副本的原位置，按其锚点对齐补画出完整形状，缺失格用副本颜色补上。
- 锚点所在格也改涂副本颜色，输出中不保留锚点色。

关键洞察
- 完整形状在输入中从未出现，连像素最多的那份副本也有缺口；照抄最大
  副本必然漏格，只有把全部残片按锚点叠起来才能得到它。
```

## 4. 预算坠落

- tags:
  - operation:平移, translate
  - operation:计数, counting
  - object:全宽条纹, full_width_stripe
  - object:前景对象, foreground_object
  - relation:条纹定向, stripe_orients_motion
  - condition:位移等于面积, shift_equals_area
  - condition:碰撞截断, collision_truncation
  - condition:就近先落, nearest_settles_first
- 参考题目: 10、5、20

### docstring

```text
每个悬浮对象向全宽条纹方向移动，步数预算等于自身面积，途中被先落者挡住就提前停下。

输入结构
- 画布的某一条边上贴着一条满跨度的单色条纹，其余为背景与若干单色
  四连通对象。
- 条纹可能贴在上、下、左、右任意一边；对象都位于条纹的同一侧。

规则
- 所有对象朝条纹方向平移，按离条纹从近到远的次序逐个处理。
- 每个对象的位移上限等于它自身的像素数；若在用完预算前撞到条纹或已经
  就位的对象，则紧贴着停下。
- 条纹本身不动，对象的形状与颜色保持不变。

关键洞察
- 这不是普通的重力：面积小的对象预算不足，会悬停在半空；也不是纯粹的
  等面积平移：先落的对象会截断后落者的行程。位移预算与碰撞截断两条
  约束缺一不可，且处理次序由到条纹的距离决定。
```

## 5. 加速漂移延拓

- tags:
  - operation:循环填充, cyclic_fill
  - operation:擦除, erase
  - object:标记列, marker_column
  - object:母题行, motif_rows
  - object:空白后缀区, empty_suffix_region
  - relation:标记界定母题, marker_delimits_motif
  - relation:横向卷绕漂移, horizontal_wrap_drift
  - condition:漂移等差递增, drift_arithmetic_growth
- 参考题目: 12、3、19

### docstring

```text
从已有副本读出逐份递增的横向卷绕漂移规律，把顶部母题继续向下延拓填满空白后缀。

输入结构
- 黑背景。最左列自顶部起有一段连续灰色像素，标记出母题的行数 h；
  顶部 h 行是彩色母题（母题不含水平周期性）。
- 母题下方已画有恰好两份后续副本：第一份是母题每行向右循环移位 s 列的
  结果，第二份是第一份再向右循环移位 2s 列的结果（移出右边界的像素从
  左边界卷回）。
- 已有内容之下是全背景的空白后缀。

规则
- 把灰色标记格改回背景。
- 从两个已有间隙读出基准步长 s 与递增规律；继续向下逐份生成副本：
  第 k 次续写为上一份向右循环移位 k×s 列（k 从 3 起计）。
- 依次写入空白后缀直到画布底部，最后一份可以被底边截断。

关键洞察
- 漂移不是常数：只看第一个间隙会得出常数漂移的错误规律，它与输入中的
  第二份副本矛盾；真正的规律是移位量按份数等差递增，且所有移位都是
  卷绕式的。
```

## 6. 会聚残段

- tags:
  - operation:射线延伸, ray_extend
  - operation:画布补全, canvas_completion
  - object:轨迹残段, trail_fragment
  - object:十字图案, plus_pattern
  - object:隐藏中心, hidden_center
  - relation:反向会聚, backward_convergence
  - relation:八方向发射, eight_dir_emit
  - condition:周期相位对齐, periodic_phase_align
  - condition:生成元未画出, generator_not_drawn
- 参考题目: 9、19、16

### docstring

```text
把靠近边缘的射线残段反向延长找到从未画出的发射中心，重建完整的八方向星。

输入结构
- 黑背景。画布上只有若干段短残段：对角残段为蓝色，横竖残段按
  青-青-黄的三色循环着色。
- 每一段都落在某条从同一个隐藏中心射向边缘的射线的靠外部分；中心本身
  与射线的大部分没有画出。
- 各残段所在直线两两反向延长后交于唯一一点。

规则
- 反向延长所有残段，求出唯一公共交点，作为发射中心。
- 在中心画一个红色五像素十字。
- 从十字向八个方向补全射线直到边缘：四条对角线通体蓝色；四条横竖射线
  从紧邻臂端的格开始按青-青-黄循环着色，且必须与已有残段的颜色相位
  严丝合缝。

关键洞察
- 发射器在输入中并不存在，它只是全部残迹的公共原点；横竖残段的三色
  相位是校验——只有正确的中心位置能让补全的循环与每一段残迹吻合。
```

## 7. 计数列队

- tags:
  - operation:排序, sort
  - operation:计数, count
  - operation:填充, fill
  - operation:平移, translate
  - object:轮廓框, outline_frame
  - object:标记像素, marker_pixel
  - object:封闭区域, enclosed_region
  - relation:计数作排序键, count_as_sort_key
  - condition:多数色决定填充, majority_color_fill
  - condition:基线对齐, baseline_aligned
  - condition:忽略干扰项, ignore_distractors
- 参考题目: 13、4、10

### docstring

```text
把每个封闭轮廓按其内部标记像素的数量从左到右排成底边队列，并用内部多数色填满腹腔。

输入结构
- 背景占主导。画布上有若干单色封闭轮廓，各自围出内部区域；内部散布着
  若干单像素标记，颜色可以不止一种。
- 轮廓之外也散落着一些标记像素，作为干扰。
- 各轮廓的内部标记总数互不相同，且每个轮廓内部恰有一种出现次数最多的
  标记色。

规则
- 清空画布，移除全部标记与干扰。
- 将各轮廓保形保色搬到底边：按内部标记总数从小到大自左向右排列，
  底边对齐，从最左列开始放置，相邻轮廓之间空一列。
- 每个轮廓的内部区域填满其原内部的多数标记色。

关键洞察
- 内部计数不是要画成柱状图的量，而是队列的排序键；轮廓的面积与原位置
  都与次序无关，轮廓外的标记与一切无关。
```

## 8. 姿态即数据

- tags:
  - operation:重涂色, recolor
  - operation:擦除, erase
  - object:精灵体, sprite
  - relation:姿态量化, orientation_as_data
  - relation:众数定基准, mode_defines_reference
  - condition:旋转步数定色, rotation_steps_to_color
  - condition:镜像即干扰, mirror_is_distractor
- 参考题目: 20、17、16

### docstring

```text
识别出所有对象都是同一形状的不同旋转姿态，以出现次数最多的姿态为基准按旋转步数重新染色，镜像冒牌货整个清除。

输入结构
- 背景上散布若干同色对象，每个都是同一个基础形状经 0、90、180 或 270
  度旋转后的结果；基础形状没有任何旋转对称性。
- 恰有一种姿态出现的次数严格最多，作为基准姿态。
- 个别对象是基础形状的镜像，无法由任何旋转得到。

规则
- 对象的位置与形状保持不变，只改变颜色：与基准姿态相同的对象染蓝色；
  相对基准顺时针旋转 90、180、270 度的对象分别染红色、绿色、黄色。
- 镜像对象整个从画布清除，恢复为背景。

关键洞察
- 颜色不来自任何输入标记，而是把每个对象的姿态量化成相对基准的旋转
  步数；基准不是给定的，而是姿态的众数；混在其中的镜像体靠手性识别，
  它们不属于旋转序列，只能删除。
```
