## 1. 隐形圆心

- 参考题目题号：3 (e729b7be)、16 (a416fc5b)、6 (4938f0c2)、20 (87ab05b8)
- tags:
  - operation:点对称补全, point_symmetry
  - operation:擦除, erase
  - object:成对形状, paired_shapes
  - object:孤立形状, lone_shape
  - relation:反推旋转中心, inferred_center
  - condition:出界反转为删除, out_of_bounds_erase
  - condition:干扰项忽略, distractor_ignored

### docstring

```text
从一对互为180度旋转的同色形状反推出从未画出的旋转中心，再为孤立形状补出旋转像；若像出界则改为擦除孤立形状。

输入结构
- 背景色占多数。
- 恰有两个多格同色形状互为绕某点180度旋转的关系（该色记为配对色）。
- 恰有一个另一颜色的多格孤立形状。
- 另有一个配对色的单像素散点，不属于任何配对（诱饵）。

规则
- 找出互为180度旋转的两个配对色形状，其对应像素连线的公共中点即旋转中心；中心可落在格心、格边或格点上，画面中没有任何像素标示它。
- 将孤立形状绕该中心旋转180度：若旋转像完全落在网格内，则以孤立形状原色画出旋转像，其余保持不变。
- 若旋转像有任何格超出网格边界，则不画旋转像，并把孤立形状擦为背景色。
- 单像素散点与两个配对形状原样保留。

关键洞察
- 旋转中心从成对形状反推而来，从未被画出；同色单像素是诱饵而非圆心标记，配对识别必须按形状对应而非颜色唯一性进行；出界分支把"补全"反转为"删除"。
```

## 2. 残迹重建

- 参考题目题号：5 (e6721834)、2 (e7dd8335)、13 (d94c3b52)、15 (2dee498d)
- tags:
  - operation:印章覆盖, stamp_overlay
  - operation:重涂色, recolor
  - operation:镜像, mirror
  - object:精灵体, sprite
  - object:残迹掩码, remnant_mask
  - object:双面板, dual_panel
  - relation:前缀形状匹配, prefix_shape_match
  - condition:截断行数反推, truncation_inferred
  - condition:补出部分标红, inferred_cells_red

### docstring

```text
目标面板的灰色残迹是某源精灵被截去底部若干行后的剩余形状，且可能整体左右镜像；按唯一匹配重建完整精灵，补出的部分统一涂红。

输入结构
- 网格被一条分隔线分为两块面板。
- 源面板包含若干互不相同的多色完整精灵。
- 目标面板包含若干灰色残迹：每个残迹等于某个源精灵去掉底部至少一行后的剩余形状掩码，或该剩余形状的左右镜像，颜色信息被抹去。
- 题目保证每个残迹的（源精灵、截断行数、是否镜像）组合唯一。

规则
- 对每个残迹遍历源精灵、截断行数与镜像与否，找到唯一使前缀形状重合的组合。
- 在残迹位置重建完整精灵：残迹已有像素恢复为源精灵（按需镜像后）对应位置的原色；被截去的行补出，但一律涂红。
- 源面板与分隔线保持不变。

关键洞察
- 截断行数从未标出，必须由前缀形状匹配反推；镜像匹配使颜色恢复也要整体镜像；红色不是某个固定部位的装饰，而是"由推断补出"这一来源标签——恢复的格用真色，虚构的格用红色。
```

## 3. 看不见的剖分

- 参考题目题号：12 (626c0bcc)、18 (878187ab)、11 (d93c6891)
- tags:
  - operation:平铺, tiling
  - operation:计数, counting
  - object:前景掩码, foreground_mask
  - object:小型瓦片, small_tile
  - object:条形图, bar_chart
  - relation:精确覆盖, exact_cover
  - relation:计数映射尺寸, count_maps_to_size
  - condition:剖分不可见仅输出统计, cover_hidden_only_counts

### docstring

```text
对单色前景做唯一的四类小瓦片精确剖分，但输出的不是剖分着色，而是四类瓦片的条形计数图。

输入结构
- 背景为多数色，其余像素同为一种前景色。
- 前景恰能被平移后的四类瓦片精确覆盖一次：实心2x2方块，以及缺左上、缺左下、缺右上角的三种2x2 L形三格块；该剖分唯一。

规则
- 完成唯一剖分并统计四类瓦片各自的数量。
- 输出一个高4、宽为四个数量最大值的背景色网格。
- 第1到第4行从左端起分别涂蓝、红、绿、黄，长度依次等于方块、缺左上L、缺左下L、缺右上L的数量。

关键洞察
- 剖分在输出里完全不可见，却是唯一能得到正确计数的途径；L块可以互相咬合，缺口处未必露出背景，因此不能靠局部2x2背景形状识别瓦片，必须做全局精确覆盖。
```

## 4. 同色湮灭下落

- 参考题目题号：1 (984d8a3e)、9 (834ec97d)、7 (d255d7a7)
- tags:
  - operation:滑动, sliding
  - operation:擦除, erase
  - object:彩色像素列, colored_column
  - relation:列内次序, in_column_order
  - condition:同色相触湮灭, same_color_annihilation
  - condition:连锁反应, chain_reaction

### docstring

```text
所有像素在各自列内下落，落在同色像素正上方时两者一同湮灭，腾出的空间让上方像素继续下落并可连锁，输出稳定后的堆叠。

输入结构
- 黑色背景网格，各列散布若干彩色像素，同列像素之间可有空隙。

规则
- 每列独立处理，像素只竖直下落，互不横移。
- 自下而上依次落定：一个像素落在地板或异色像素之上则停住；若它落定时正下方是同色像素，则两者同时消失。
- 消失后其上方尚未处理的像素继续下落，可触发连锁湮灭。
- 输出所有列稳定后的画面。

关键洞察
- 每列的最终结果等价于把该列颜色序列自下而上做"栈式消除"：新色与栈顶相同则弹栈，否则压栈；空隙只是障眼，像素的具体行位置全部无关，只有列内颜色次序有意义。
```

## 5. 折回基本域

- 参考题目题号：15 (2dee498d)、17 (7b7f7511)、5 (e6721834)
- tags:
  - operation:裁剪, crop
  - operation:叠印, overprint
  - object:重复瓦片, repeated_tile
  - object:破缺像素, defect_pixel
  - relation:周期, period
  - relation:相位折叠, phase_folding
  - condition:异常按模周期归位, anomaly_mod_period

### docstring

```text
网格是一张基础瓦片的双向周期平铺，其中少数像素被改色，输出基础瓦片并把每个破缺像素按其瓦片内相位落回对应位置叠印。

输入结构
- 除少数破缺像素外，网格由一个矩形基础瓦片沿水平和竖直方向无翻转周期平铺而成，瓦片的高与宽分别整除网格的高与宽。
- 破缺像素的颜色与其所在相位的正确颜色不同，且任意两个破缺像素的瓦片内相位互不相同。

规则
- 取两个方向上的最小周期，得到基础瓦片；判断每个相位的正确颜色时以该相位全部副本中的多数色为准。
- 输出一个与基础瓦片同尺寸的网格：先按基础瓦片着色，再把每个破缺像素的异常颜色涂到它的相位坐标上。
- 破缺像素位于原平铺中的哪一份副本不影响结果。

关键洞察
- 输出乍看是"裁出一个周期"，但破缺点必须按模周期坐标折叠叠印回去；周期图案本身只是坐标系，真正要传递的图案由散落全图的异常像素拼合而成，它从未在输入中集中出现。
```

## 6. 缺格即指令

- 参考题目题号：13 (d94c3b52)、16 (a416fc5b)、19 (93b581b8)、5 (e6721834)
- tags:
  - operation:补全, complete
  - operation:平移, translate
  - object:符号槽位, symbol_slot
  - object:隐藏原型, hidden_prototype
  - object:分隔线, separator
  - relation:缺格方位映射方向, defect_maps_direction
  - condition:原型由并集涌现, prototype_from_union
  - condition:中心缺格原地不动, center_defect_stays

### docstring

```text
表格中每个符号都是同一隐藏原型缺一格的残本，缺格在3x3内的方位是移动指令，符号补全为原型后按该方位移入相邻槽位。

输入结构
- 网格是由单像素背景分隔线划分的槽位表格。
- 每个占用槽位含一个单色3x3符号掩码，符号颜色多样且与规则无关。
- 所有掩码都等于同一个3x3原型形状去掉恰好一格，原型本身从未完整出现。
- 题目保证所有符号同时移动后互不冲突且不越出表格。

规则
- 以全部掩码的并集为原型形状。
- 对每个符号找出它相对原型缺失的那一格，该格在3x3中的方位（八邻方向之一或中心）即该符号的移动指令。
- 把符号补全为完整原型并保持原色，移入该方向的相邻槽位；缺格在中心的符号原地补全、不移动。
- 移出后的原槽位清空为背景，分隔线保持不变。

关键洞察
- 乍看是"补全缺格"的修复题，实际缺格不是缺陷而是指令；原型从未被完整画出，只能由全部残本的并集涌现；移动方向读的是缺格在符号内部的位置，而非任何外部标记。
```
