## 1. 同心环程序射线

- 参考题目题号: 1 (508bd3b6)、3 (50c07299)、14 (8fff9e47)
- tags:
  - operation:射线延伸, ray_cast
  - operation:反射, reflect
  - operation:重涂色, recolor
  - object:嵌套层, nested_layer
  - object:双像素发射器, domino_launcher
  - object:矩形障碍, rect_obstacle
  - relation:层序映射段序, layer_order_maps_segment_order
  - condition:环数决定段数, ring_count_bounds_segments
  - condition:障碍兼程序带, obstacle_doubles_as_tape

### docstring

```text
让双像素发射器射出的对角射线在墙壁与同心环块之间反弹，并按同心环由内到外的
颜色依次为每段路径上色。

输入结构
- 黑色背景。
- 一个由若干层同色环逐层嵌套构成的实心同心正方形块。
- 一个由两个不同颜色像素对角相邻组成的发射器（尾像素与头像素，颜色固定且
  不与环色重复）。

规则
- 从头像素出发，沿尾指向头的对角方向前进。
- 射线碰到网格边界或同心块的边缘时按反射定律反弹：撞平壁翻转一个方向分量，
  撞角同时翻转两个分量。
- 两次反弹之间的第 k 段路径整体涂成同心块自最内层数起第 k 层的颜色。
- 当已画出的段数等于环层数时射线终止；发射器像素保留。

关键洞察
- 同心块身兼两职——它既是使射线反弹的实体障碍，又是决定各段颜色与总段数的
  程序带；环的层序就是路径段的时序。
```

## 2. 括号配对与并列同心塔

- 参考题目题号: 13 (505fff84)、14 (8fff9e47)
- tags:
  - operation:结构解析, parse_nesting
  - operation:绘制同心层, draw_concentric
  - object:控制像素对, control_pixel_pair
  - object:嵌套层, nested_layer
  - relation:同色配对即括号, same_color_pair_as_bracket
  - relation:嵌套深度映射层深, depth_maps_layer
  - condition:顶层多组并列, sibling_top_level_groups

### docstring

```text
把单行中成对出现的颜色解析为嵌套括号，并把每个顶层括号组画成一座同心方塔。

输入结构
- 输入是单行网格，黑色为背景。
- 每种前景色恰好出现两次，所有颜色对彼此正规嵌套、互不交叉。
- 每个顶层组内部是逐层单链嵌套；顶层可以有多个并列组。

规则
- 从左到右解析各颜色对的匹配关系，得到若干顶层组。
- 深度为 d 的组画成 (2d-1)x(2d-1) 的同心方块，最外圈到中心的颜色依次取该组
  从最外对到最内对的颜色。
- 各方块按组在行中的出现顺序从左到右、顶对齐、无间隔紧贴排列；输出高度为
  最大方块边长，其余格为黑。

关键洞察
- 同一颜色的两次出现是一对匹配的括号；输出的同心层级不是回文装饰，而是括号
  树的嵌套深度——只有单链示例会诱导出"彩虹环"误读，多组并列示例揭示必须按
  括号结构解析。
```

## 3. 负空间匹配与姿态印章

- 参考题目题号: 5 (3ed85e70)、8 (543a7ed5)、20 (50f325b5)
- tags:
  - operation:洪泛填充, flood_fill
  - operation:模板匹配, template_matching
  - operation:印章覆盖, stamp_overlay
  - object:封闭区域, enclosed_region
  - object:目录模板, catalog_template
  - object:分隔行, separator_row
  - relation:负空间形状匹配, negative_space_shape_match
  - condition:含旋转反射变换, includes_rotation_reflection
  - condition:姿态随匹配确定, pose_follows_match
  - condition:忽略干扰项, ignore_distractors

### docstring

```text
把每个灰块围出的孔洞按形状匹配到多色图例，并把该图例按匹配时所用的同一
旋转/反射姿态印入孔洞。

输入结构
- 一条满宽分隔行把网格分为工作区与图例区。
- 图例区有若干实心多色小图案，其轮廓形状互不相同且不具有非平凡自对称。
- 工作区有若干灰色大块，每块恰好围出一个从边界不可达的黑色孔洞。
- 每个孔洞的形状与唯一一个图例的轮廓在某个唯一的旋转/反射变换下同形；
  图例中含不匹配任何孔洞的干扰项。

规则
- 洪泛找出工作区中从边界不可达的黑色封闭区域。
- 把每个孔洞的归一化区域掩码与各图例轮廓在全部旋转和反射下比对，确定唯一
  匹配的图例以及唯一的匹配变换。
- 把该图例的完整多色图案施加同一变换后印入孔洞，逐格对应。
- 灰块、图例区、分隔行保持不变。

关键洞察
- 匹配作用于负空间——是空腔而非画出的形状；且匹配得到的不只是"哪个图例"，
  还有"以什么姿态"——孔洞的朝向决定了印入图案的旋转反射姿态。
```

## 4. L 路由与对角排队

- 参考题目题号: 6 (b745798f)、10 (dc46ea44)、15 (c8cbb738)
- tags:
  - operation:平移, translate
  - operation:擦除, erase
  - object:角落标记, corner_marker
  - object:精灵体, sprite
  - relation:朝向对应角, facing_corner
  - relation:对角排队, diagonal_queue
  - condition:同角按距排序, same_corner_order_by_distance

### docstring

```text
按每个精灵所附 L 标记的朝向把精灵搬运到对应网格角，去往同一角的多个精灵按
原始远近排成一条指向中心的对角链。

输入结构
- 统一背景色。
- 若干互不相触的单色精灵，均非红色。
- 每个精灵旁有一个红色三像素 L 标记（嵌于 2x2 框内），与该精灵对角相邻；
  L 在 2x2 框内缺失的那个格所在的方位即它指向的网格角。

规则
- 清空画布为背景色。
- 每个精灵路由到其 L 指向的网格角：去往同一角的精灵中，原位置离该角切比雪夫
  距离最近者优先，其包围盒紧贴角落放置。
- 后续精灵依次沿指向网格中心的对角方向排队，每个精灵的外角格与前一个精灵包
  围盒的内角格对角相邻。
- 所有 L 标记删除，不出现在输出中。

关键洞察
- L 不是要放大的图形而是路由指令；同一目的角的多个精灵不会重叠或合并，而是
  按原始距离排成一条指向中心的对角链——朝向决定去哪，远近决定排第几。
```

## 5. 有序拉伸与阻挡

- 参考题目题号: 9 (b548a754)、1 (508bd3b6)、10 (dc46ea44)
- tags:
  - operation:拉伸, stretch
  - object:空心矩形, hollow_rectangle
  - object:标记点, marker_pixel
  - relation:标记决定拉伸终点, marker_determines_stretch_endpoint
  - relation:阻挡截停, blocking_halt
  - condition:按延伸距离升序结算, ascending_extension_order

### docstring

```text
每个空心矩形框朝自己的同色标记拉伸，但拉伸体互相阻挡，必须按延伸距离从短到
长依次结算。

输入结构
- 统一背景色。
- 若干空心矩形框，各有唯一的边框色。
- 每框恰有一个与其同色的标记像素，位于该框某一边正对的行带或列带内。
- 各框到各自标记的延伸距离互不相等。

规则
- 按框到标记的延伸距离从小到大依次处理每个框。
- 处理时把框朝标记方向拉伸成更大的空心矩形：若顺利到达，新外边缘落在标记
  所在行/列上，标记被边框吸收。
- 若拉伸途中会撞上其他框（原始形体或已拉伸后的形体），则在紧贴障碍处截停，
  该框的标记保留在原处。

关键洞察
- 单独看每个框都是"拉到标记为止"，但拉伸体互相阻挡，真正的规则是结算顺序
  ——先短后长，先到者的身体改变后来者的终点；残留的标记是"没拉到"的证据。
```

## 6. 双轴折叠拼合杂质

- 参考题目题号: 16 (af22c60d)、20 (50f325b5)、13 (505fff84)
- tags:
  - operation:对称检测, symmetry_detect
  - operation:裁剪, crop
  - operation:透明叠加, transparent_overlay
  - object:对称轴, symmetry_axis
  - object:杂质像素, impurity_pixel
  - relation:双轴镜像轨道, two_axis_orbit
  - condition:轨道少数即杂质, orbit_minority_is_impurity
  - condition:折叠拼合碎片, fold_assembles_fragments

### docstring

```text
找出破坏双轴镜像对称的杂质像素，把它们沿两条镜轴折叠到同一区域，拼合出被
拆散藏进四个镜像分身的隐藏图形。

输入结构
- 网格是一幅关于一条水平镜轴与一条竖直镜轴对称的多色图案；轴未必居中，可能
  落在半格上。
- 少量杂质像素覆盖在图案上，每个镜像轨道内至多一个杂质。
- 全部杂质经双轴折叠后落在彼此邻接的一小片区域内，构成一个连贯多色小图形的
  互补碎片。

规则
- 推断使绝大多数像素两两吻合的两条镜轴。
- 对每个轨道取多数颜色为图案本色，与之不同的格即杂质。
- 把每个杂质沿两镜轴反射映射到同一个规范象限的对应位置，将所有映射后的杂质
  叠印。
- 按叠印结果的包围盒裁剪，保持颜色输出于黑底上。

关键洞察
- 对称既是筛出杂质的滤网，又是拼合它们的折叠坐标系——隐藏图形从未被完整
  画出，它的碎片分散在四个镜像分身里，只有沿双轴折叠才能复原。
```

## 7. 双帧外推与弹性反弹

- 参考题目题号: 10 (dc46ea44)、1 (508bd3b6)、3 (50c07299)
- tags:
  - operation:平移, translate
  - operation:反射, reflect
  - object:精灵体, sprite
  - object:分隔行, separator_row
  - relation:双帧速度推断, two_frame_velocity
  - relation:跨面板对应, cross_panel_correspond
  - condition:撞墙镜像回弹, wall_bounce

### docstring

```text
把上下两个面板当作连续两帧，推断每个精灵的速度并外推第三帧，越界的精灵按
墙面弹性反弹。

输入结构
- 一条满宽分隔行把网格分为上下两个等大面板。
- 两面板包含同一组颜色互不相同、形状保持不变的单色精灵。
- 每个精灵在下面板相对上面板平移了一个属于自己的位移向量。

规则
- 按颜色配对两帧中的精灵，求出各自的位移向量。
- 输出一个与单面板等大的网格，把每个精灵从下面板位置再平移一次该向量。
- 若某方向上第三步会使精灵包围盒越出面板 k 格，则该方向分量取反，精灵改为
  停在距该墙 k 格处（贴墙镜像回弹）；两个方向可独立回弹。

关键洞察
- 两个面板不是待比较的静态图案而是时间序列的两帧；速度是从未画出的隐藏对象，
  而反弹使第三帧无法靠简单的等差平移得到。
```
