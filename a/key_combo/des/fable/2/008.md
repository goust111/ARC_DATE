## 1. 双层对称显影补全

- 参考题目题号：1 (4c4377d9)、2 (9ecd008a)、8 (23b5c85d)、13 (ed36ccf7)
- tags:
  - operation:对称补全, symmetry_completion
  - operation:差分显影, difference_reveal
  - operation:裁剪, crop
  - object:双轴对称底图, biaxial_symmetric_canvas
  - object:隐形入侵图形, hidden_intruder_shape
  - relation:对称轨道表决, symmetry_orbit_voting
  - condition:同色覆写天然隐身, same_color_overwrite_invisible
  - condition:两层对称接力, two_stage_symmetry_relay

### docstring

```text
用底图的双轴对称表决显影出带洞的入侵残迹，再用入侵图形自身的对称补全洞格，裁剪输出完整入侵图形。

输入结构
- 画布绘有同时具有左右镜像与上下镜像对称的多色底图，底图不含黑色。
- 一个自身左右对称的入侵图形整体覆写了一块区域，逐格以入侵图形各格自身颜色覆写；
  凡覆写色恰与该格底图原色相同的格，画面上不留任何痕迹（天然隐身）。
- 任一格与其三个底图对称伙伴中至多一个被覆写；入侵图形每对自身镜像格中至少一格可显影；
  入侵图形紧致包围框的左右边界列上均有可见残迹格。

规则
- 对每个格取其左右镜像、上下镜像、中心旋转三个底图伙伴，按多数表决还原底图。
- 与还原值不同的格即可见残迹；残迹因隐身格而带洞。
- 以残迹紧致包围框的竖直中线为入侵图形自身的对称轴，把每个洞格补为其在入侵图形内镜像位置的颜色。
- 输出补全后入侵图形的紧致包围框裁剪：图形格保留各自颜色，形外格置黑。

关键洞察
- 入侵图形在画面上从未完整出现，需要两层不同的对称先后接力——底图的双轴对称负责显影，
  入侵图形自身的左右对称负责补洞；把显影出的带洞残迹直接当答案是第一眼陷阱。
```

## 2. 图例交点运算

- 参考题目题号：10 (e760a62e)、14 (8731374e)、15 (0becf7df)
- tags:
  - operation:连线, draw_line
  - operation:重涂色, recolor
  - object:图例, legend
  - object:标记像素, marker_pixel
  - object:分隔网格线, separator_line
  - relation:行列交叉, row_col_cross
  - condition:交点色由图例查表, intersection_color_from_legend
  - condition:无序颜色对运算, unordered_pair_operation

### docstring

```text
把每个标记像素展成整行整列笔画，异色笔画交叉点的颜色由图例中的三元组查表决定。

输入结构
- 顶部图例带由若干水平三连格组成，形如"甲 乙 丙"，与下方场地之间隔着一条横贯画布的灰色分隔线。
- 分隔线下方是黑底场地，散布若干孤立的彩色标记像素。
- 场地中任一格至多被一横一竖两道笔画经过；场地中出现的每个无序异色对都在图例中恰有一条对应三连格。

规则
- 每个标记像素向左右展成整行笔画、向上下展成整列笔画，笔画为标记自身颜色，只画在场地内。
- 两道异色笔画的交叉格，改涂图例中该无序颜色对"甲 乙"所对应的第三色"丙"。
- 同色笔画的交叉格保持该颜色；图例带与分隔线在输出中原样保留。

关键洞察
- 图例不是颜色替换表而是一张二元运算表：它规定的是"哪两种颜色相遇会产生什么"，
  交点的结局与笔画出现的先后、横竖方位全都无关；用"竖压横"或"后画覆盖先画"去套第一个示例都会在后续示例上破产。
```

## 3. 蛇形路径相位调色

- 参考题目题号：3 (13e47133)、16 (bae5c565)、18 (8b7bacbf)
- tags:
  - operation:重涂色, recolor
  - operation:路径追踪, path_tracing
  - object:调色板行, palette_row
  - object:线条画, line_drawing
  - object:种子像素, seed_pixel
  - relation:弧长决定色序, arc_length_determines_color
  - condition:种子色定相位, seed_color_sets_phase
  - condition:循环色带, cyclic_color_bands

### docstring

```text
沿每条灰色蛇形路径从彩色端点起步行走，按顶行调色板从该端点颜色所在位置开始循环上色。

输入结构
- 顶行左端连续若干格为一段无重复颜色的调色板，顶行其余格为背景。
- 场地上有一条或多条互不接触、宽度为一格的灰色简单路径，可任意拐弯、无分叉。
- 每条路径恰有一个端点格不是灰色，而是调色板中出现过的某种颜色。

规则
- 从彩色端点出发沿路径逐格行走；端点保留原色。
- 在调色板中找到端点颜色的位置，此后每走一格依次取调色板中的下一色，取到末尾后循环回开头。
- 路径以外的格与调色板行保持不变。

关键洞察
- 上色次序由沿路径行走的步数（弧长）决定，而不是几何距离或行列位置——路径的拐弯使二者截然不同；
- 端点的颜色不是要填的颜色，而是进入循环调色板的相位入口：不同路径的端点色不同，整条色带的起读位置随之不同。
```

## 4. 缺口指路射线走线

- 参考题目题号：5 (bf699163)、6 (9b2a60aa)、12 (ce22a75a)、19 (eee78d87)
- tags:
  - operation:解码, decode
  - operation:连线, draw_line
  - operation:降采样, downsample
  - object:宏块格阵, macro_block_grid
  - object:缺口环字形, gapped_ring_glyph
  - object:干扰环, distractor_ring
  - relation:缺口指向后继, gap_points_to_successor
  - condition:射线寻的, ray_cast_to_nearest
  - condition:走线至出界, walk_until_exit

### docstring

```text
在三乘三宏块画布上，从灰色缺口环出发按各环缺口方向逐段射线跳到下一环，并把走线降采样成宏块粗网格输出。

输入结构
- 画布长宽均为三的倍数，按三乘三划分为宏块。
- 部分宏块内有一个单色缺口环：三乘三空心方环恰好缺掉一个边中点格，缺口位于上、下、左、右之一。
- 恰有一个环为灰色，是起点；其余环颜色互不相同，其中一些是永远不会被走到的干扰环。

规则
- 从灰色环所在宏块出发，沿该环缺口所指方向看去，跳到该方向上最近的含环宏块，再按新环的缺口方向继续；
  若该方向上再无含环宏块，则沿该方向走到画布边缘为止，行走结束。
- 输出为宏块粗网格，长宽各为原来的三分之一：起点格涂灰色，被走到的环格涂该环自身颜色，
  两环之间以及最后冲出边缘途中经过的空宏块格涂该段出发环的颜色，其余格置黑。

关键洞察
- 环上唯一的缺口是方向指令，行走不是逐块挪动而是射线寻的：每段的长度不由字形本身给出，
  而由该方向上下一个环的位置决定；未被射线串起的环再显眼也只是干扰，颜色再多也不进入输出。
```

## 5. 推倒竖条连锁

- 参考题目题号：4 (2a28add5)、11 (3bd67248)、16 (bae5c565)
- tags:
  - operation:计数, counting
  - operation:连线, draw_line
  - operation:擦除, erase
  - object:竖条, bar
  - object:地板线, floor_line
  - object:触发标记, trigger_marker
  - relation:高度即打击范围, height_equals_reach
  - condition:连锁传导, chain_reaction
  - condition:够不着即停, out_of_reach_stops

### docstring

```text
红色标记的竖条向右倒下，倒下覆盖长度等于条高，压到谁谁接着倒，连锁止于够不着处。

输入结构
- 底行为一条完整的地板线，地板上立着若干互不相邻、颜色各异、高矮不一的单格宽竖条。
- 恰有一根条的顶格被染成红色，它是最先被推倒的条。

规则
- 一根立于列 x、高为 h 的条向右倒下后，从站立位置消失，改画为紧贴地板线上方一行中
  第 x+1 至 x+h 列的水平条，颜色为该条自身颜色（红色顶格标记不画入）。
- 若某仍站立的条所在列落在这段区间内，它随之向右倒下，依此连锁。
- 后倒的条只涂尚为背景的格；连锁够不着的条保持站立原样；地板线不变。

关键洞察
- 条的高度就是它倒下后的打击范围：散落的高度差不是装饰，而是一张隐式的传导网；
  最终哪些条倒下由逐段可达性递推决定——既不是"右侧全倒"，也不是"矮的就倒"，
  一根稍矮的条就可能让连锁在半途断掉。
```

## 6. 三洞分诊对称修复

- 参考题目题号：2 (9ecd008a)、8 (23b5c85d)、13 (ed36ccf7)、17 (1c02dbbe)
- tags:
  - operation:对称补全, symmetry_completion
  - operation:旋转, rotate
  - operation:筛选, filtering
  - object:缺失区域, missing_patch
  - object:候选补块, candidate_patch
  - object:近似诱饵块, near_miss_decoy
  - relation:全局对称一致性判决, global_symmetry_verdict
  - condition:镜像洞对不可互抄, mirrored_holes_unrecoverable
  - condition:朝向唯一可行, unique_orientation_fits

### docstring

```text
先分诊哪个黑洞能照镜子抄、哪对黑洞互为镜像无从抄起，再用全局对称性当判决器，从旋转过的候选补块中选出唯一可行者，输出修复完成的图案。

输入结构
- 画布主体是一幅只具有左右镜像对称、不含黑色的多色图案，其对称轴不在画布中央，需从图案本身定位。
- 图案上挖了三个同尺寸的黑色方洞：其中一个洞的镜像对应区域完好无损；另外两个洞的位置恰好互为镜像。
- 图案下方以背景带隔开，摆着若干同尺寸候选补块，每块可能被旋转过任意九十度的倍数；
  恰有一块存在唯一一种朝向，使填入镜像洞对后全图恢复完全左右对称；
  其余候选中含有与正确块仅差一至两格的近似诱饵块。

规则
- 定位图案的对称轴；镜像区域完好的洞直接按镜像恢复。
- 互为镜像的洞对无法互抄：逐块逐朝向把候选补块试填入其中一洞，另一洞填其镜像，
  检验整幅图案是否完全左右对称，采用唯一通过检验的补块与朝向。
- 输出修复后的完整图案区域，不含下方候选块摆放区。

关键洞察
- 三个洞表面相同实则两类，必须先分诊——能照镜子抄的洞是热身，互为镜像的洞对才是正题；
  对称性在这里身兼二职：既是修复工具，又是筛选与摆正外部补块的判决器；
  近似诱饵块的存在使"看着像就填"失效，只有全图逐格对称检验才能定案。
```

## 7. 碎窗拼布测谎

- 参考题目题号：3 (13e47133)、5 (bf699163)、19 (eee78d87)、20 (3194b014)
- tags:
  - operation:平铺, tiling
  - operation:对齐比对, alignment_check
  - operation:裁剪, crop
  - object:空心取景框, hollow_viewport_frame
  - object:周期花布, periodic_fabric
  - object:说谎窗口, lying_window
  - relation:位置决定相位, position_determines_phase
  - condition:多窗互证重建, multi_window_reconstruction
  - condition:合法片段错位, valid_patch_wrong_phase

### docstring

```text
黑色画布上的每扇取景框窗口都是同一张周期花布在各自位置处的取景，靠多窗按位置拼合互证复原花布，找出唯一相位错位的说谎窗口，输出它本应显示的内容。

输入结构
- 黑色画布上散放着若干空心矩形取景框，框内各有一片多色花纹窗口，框外没有任何花纹。
- 所有窗口都是同一张周期性无限花布在各自画布位置处的取景：
  每个窗口的内容由其在画布上的绝对位置对花布周期取相位决定；花布与周期均未直接给出。
- 恰有一个窗口被整体替换成这张花布另一相位处的合法片段：其内容局部看是毫无破绽的真花纹，
  但与它所在位置应有的相位不符；其余窗口彼此按位置对齐后完全相容。

规则
- 把各窗口按画布位置相互对齐比对，由内容错位与位置差的关系推断花布的行列周期与相位，
  以多数窗口相互印证的结果为准。
- 找出唯一与集体重建不相容的窗口。
- 输出该窗口按重建花布在其自身位置外推本应显示的内容，尺寸等于该窗口内区。

关键洞察
- 没有任何一处"框外真相"可以免费读到周期——花布只能靠多扇碎窗按位置拼合互证才能复原；
- 各窗内容两两不同只是相位差造成的假象，说谎窗的花纹本身完全合法，
  "找花纹破绽"与"窗口两两互比挑异类"全部失效，暴露它的只有与位置绑定的集体一致性；
- 答案是被替换前的"应然"画面，它不等于画面上现存的任何一块。
```
