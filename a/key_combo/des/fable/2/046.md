## 1. 码头秩配对下落

- 参考题目题号: `f0100645`, `3906de3d`, `97d7923e`, `4acc7107`
- tags:
  - operation:重力下落, gravity_drop
  - operation:重涂色, recolor
  - operation:排序, sort
  - object:码头线段, dock_segment
  - object:灰色物体, grey_object
  - relation:秩配对, rank_pairing
  - condition:碰撞停止, collision_stop
  - condition:面积长度排名对应, size_length_rank_match

### docstring

```text
让悬浮的灰色物体竖直下落堆叠，并按"物体面积排名对应码头长度排名"为每个物体重新着色。

输入结构：
- 背景为黑色。
- 底行分布若干互不相邻的水平彩色线段（码头），颜色互不相同，长度互不相同。
- 上方悬浮同样数量的灰色4连通物体，像素数互不相同，各物体的列区间可以重叠。
- 保证至少有一个物体：其正下方码头的颜色与按排名配对应得的颜色不同。

规则：
- 将灰色物体从原位清除，按初始最低行从低到高依次处理。
- 每个物体保持形状与所在列不变，竖直下落，直到其任一像素落在底行、码头或已沉降物体的正上方为止。
- 将码头按长度从长到短排名，物体按像素数从多到少排名；将第r名的物体整体涂成第r名码头的颜色。
- 码头保持不变。

关键洞察：
- 物体的落点由重力决定，而颜色与位置无关：面积排名与码头长度排名一一对应，"涂成正下方码头的颜色"是诱饵。
```

## 2. 缺席精灵印章

- 参考题目题号: `2546ccf6`, `b190f7f5`
- tags:
  - operation:对称补全, symmetry_completion
  - operation:印章覆盖, stamp
  - operation:重涂色, recolor
  - object:格元精灵, lattice_sprite
  - object:源面板, source_panel
  - relation:分块对应, block_correspondence
  - condition:三存一缺推断, infer_missing_from_three
  - condition:模板未画出, template_not_drawn

### docstring

```text
由三个镜像变体推断2×2格块中缺失的第四个精灵，并把它作为模板按源面板逐像素重涂后分块盖印。

输入结构：
- 一条贯穿整幅的分隔色直线将输入分为两部分。
- 一侧是由分隔色格线划分的2×2格块，其中三个格元各含同一精灵的镜像变体（单一颜色），剩下一个格元为空。
- 精灵自身不具有水平或竖直对称，因此四个镜像变体互不相同，缺失变体不等于任何已画出的变体。
- 另一侧是一个N×N的源面板，黑底上散布若干彩色像素。

规则：
- 对三个已有精灵按其相对空格元的位置做水平和/或竖直镜像，三者一致地确定出缺失格元应有的精灵掩码。
- 构造(N·m)×(N·m)的黑色输出（m为格元边长）。
- 对源面板每个位于(r,c)的非黑像素，把上述缺失精灵掩码涂成该像素的颜色，盖印到输出的第(r,c)个m×m块中；源面板为黑的块保持全黑。

关键洞察：
- 被盖印的模板从未在输入中被完整画出——它是2×2镜像四元组中缺失的那一个，必须先由对称补全推断出来，再进入分块印章流程。
```

## 3. 歧义动画补中帧

- 参考题目题号: `351d6448`, `760b3cac`, `9dfd6313`
- tags:
  - operation:序列外推, sequence_extrapolation
  - operation:镜像, mirror
  - operation:旋转, rotate
  - object:面板帧, panel_frame
  - object:精灵体, sprite
  - relation:等距堆叠, equally_spaced_stacking
  - condition:复合变换恒定, constant_composite_transform
  - condition:单步证据歧义, single_step_ambiguity

### docstring

```text
补出五帧动画中空缺的中间帧，每步对精灵施加同一个未知正交变换再平移固定偏移，而单步证据刻意存在歧义。

输入结构：
- 输入是五个等大的面板竖直堆叠，由整行分隔线隔开。
- 第1、2、4、5帧各含同一个单色精灵，第3帧全部为背景色。
- 精灵形状特制（例如恰好沿一条对角线对称），使得仅凭任何一对相邻可见帧（1→2或4→5），都有两种不同的正交变换假设（如"水平镜像"与"旋转90度"）同样吻合。

规则：
- 每步变换 = 对精灵施加同一个固定的镜像或旋转T，再将其包围盒平移一个固定偏移。
- 第2帧与第4帧相隔两步，二者的形状关系等于T∘T（镜像的二次复合为恒等，旋转90度的二次复合为旋转180度），据此排除假候选、唯一确定T。
- 对第2帧的精灵施加一次T与偏移得到第3帧；输出仅为补全后的第3帧（单面板大小）。

关键洞察：
- 精灵的偶然对称使单步证据永远二义；只有跨越缺失帧比较第2、4帧之间的两步复合效果，才能区分互为伪装的两种变换并补出正确朝向的中帧。
```

## 4. 折镜射线循环染色

- 参考题目题号: `891232d6`, `7ddcd7ec`, `9473c6fb`
- tags:
  - operation:射线延伸, ray_cast
  - operation:路径绘制, path_drawing
  - operation:重涂色, recolor
  - object:斜镜段, diagonal_mirror
  - object:入口标记, entry_marker
  - relation:方向指示, dir_indication
  - condition:斜向决定折转, mirror_orientation_turn
  - condition:段序循环染色, segment_ordinal_cyclic_color

### docstring

```text
从边缘入口垂直射入一条射线，每遇灰色斜镜段折转90度，并按折转次数循环染色各段路径。

输入结构：
- 背景为黑色，网格边缘有一个单独的绿色入口像素。
- 内部散布若干条灰色45度斜线段（每段至少2格），充当双面镜；其斜向为"\"或"/"。
- 镜段的摆放保证射线路径确定、不经过同一格两次，且最终离开网格。

规则：
- 射线从入口像素沿垂直于所在边的方向进入网格，逐格直行。
- 当前进方向上的下一格属于某镜段时，射线不进入镜格，而在当前格按该镜段的斜向折转90度（"\"把向右折为向下、向上折为向左等；"/"相反）。
- 依次将两次折转之间的每段直行路径涂色：第一段红色、第二段青色、第三段黄色，之后按红、青、黄循环，直至射线离开网格。
- 镜段保持灰色不变，入口像素保持绿色。

关键洞察：
- 斜线段的方向是转向编码，而路径颜色不取决于位置或方向，只取决于该段是第几次折转之后的行程——几何弹射与序数染色两层必须同时成立。
```

## 5. 里程最短路

- 参考题目题号: `7b0280bc`, `9af7a82c`
- tags:
  - operation:最短路径, shortest_path
  - operation:重涂色, recolor
  - operation:计数, counting
  - object:节点方块, node_square
  - object:轨道段, track_segment
  - relation:图结构, graph_structure
  - condition:里程权重, length_weighted
  - condition:诱饵少跳路线, fewer_hop_decoy

### docstring

```text
在方块-轨道图中为两个终端找总轨道格数最少的路线并重涂，路线以里程而非站数取胜。

输入结构：
- 背景为最常见色。
- 两个红色实心方块是终端，若干蓝色实心方块是车站，均为图的节点。
- 灰色一格宽轨道段连接成对的方块，构成图的边；每条边的格数即其里程。
- 保证按总里程计的最短路线唯一，且存在一条经过方块更少但总里程更长的诱饵路线。

规则：
- 在图中找出连接两个终端、沿途轨道格总数最少的路线。
- 将该路线上的每个车站方块涂成绿色，每段轨道涂成黄色。
- 其余方块、轨道与背景保持不变。

关键洞察：
- 网格是一张带权图：边权是轨道段的长度而不是边的条数；跳数最少、"看起来更直接"的那条路线是诱饵，取胜的是总里程。
```

## 6. 岔道串珠合流

- 参考题目题号: `7b0280bc`, `3906de3d`, `f0100645`
- tags:
  - operation:滑动, slide
  - object:轨道折线, track_polyline
  - object:珠子像素, bead_pixel
  - object:汇端方块, sink_square
  - relation:沿轨排序, along_track_ordering
  - relation:支线合流, branch_merge
  - condition:近者优先不重叠, nearest_first
  - condition:沿轨距离度量, path_metric

### docstring

```text
让散布在Y形轨道两条支线上的彩色珠子沿轨滑向汇端，按沿轨里程交错合流排队。

输入结构：
- 背景为黑色，一条一格宽、不自交的灰色轨道呈Y形：主干一端紧邻红色2×2方块（汇端），主干另一端在岔口分成两条支线。
- 主干与支线上若干格被彩色珠子占据（每珠一格，颜色互不相同）。
- 保证所有珠子到汇端的沿轨距离互不相等。

规则：
- 所有珠子沿轨道朝汇端滑动，且不得互相越过（同一条线路上的先后顺序保持不变）。
- 全体珠子按沿轨到汇端的距离从近到远依次定位：第一颗停在紧邻汇块的轨道格上，其后每颗停在前一颗身后的轨道格上。
- 来自两条支线的珠子因此在主干上按里程交错合流。
- 珠子腾出的格恢复为灰色轨道；红色方块与轨道形状保持不变。

关键洞察：
- 排队次序由沿轨一维里程统一决定：画面上看似贴近汇端、或与前一颗珠子同处一条支线，都不代表排在前面——两条支线像拉链一样按里程交错插队。
```

## 7. 角落认领连锁

- 参考题目题号: `4a1cacc2`, `f0100645`
- tags:
  - operation:填充, fill
  - object:孤立像素, lone_pixel
  - object:网格角, grid_corner
  - relation:贪心配对, greedy_matching
  - relation:抢占连锁, preemption_cascade
  - condition:曼哈顿距离最小, min_manhattan
  - condition:角唯一占用, exclusive_corner

### docstring

```text
各孤立像素竞争认领网格角，按"当前最近的未被占用角"逐一配对后各自填充到所认领角的矩形。

输入结构：
- 背景为黑色，网格上散布至多四个颜色互不相同的孤立像素。
- 所有像素-角之间的曼哈顿距离互不相等。
- 保证存在至少两个像素的最近角相同，使抢占实际发生。

规则：
- 反复执行：在所有尚未配对的像素与尚未被认领的角之间，取曼哈顿距离最小的一对完成配对，直到每个像素都认领了一个角。
- 每个像素向其认领的角填充由两者界定的（含端点的）轴对齐矩形，用该像素的颜色。
- 若矩形重叠，重叠格取配对距离较小的那个像素的颜色。

关键洞察：
- 每个角只能被占用一次：离某角最近的像素会抢占它，被挤掉的像素只能退而认领剩余的角——"各自涂到各自最近角"在多像素竞争时是诱饵，配对是一场全局的贪心连锁。
```

## 8. 双视角周期拼合

- 参考题目题号: `29ec7d0e`, `195ba7dc`
- tags:
  - operation:补全, repair
  - operation:平铺, tiling
  - operation:对齐, align
  - object:周期瓦片, periodic_tile
  - object:分隔列, separator_column
  - relation:跨面板互补, cross_panel_complement
  - condition:相位偏移推断, phase_offset_inference
  - condition:逐格叠加诱饵, pixelwise_merge_decoy

### docstring

```text
分隔线两侧是同一周期图案的两个错相残破视图，需对齐相位、互补取证后修复左视图的全部黑洞。

输入结构：
- 一条红色整列把输入分成同尺寸的左右两个面板。
- 两个面板都是同一个p×q周期色表的截取，但截取相位不同，且都被黑色空洞遮蔽。
- 任一面板单独的可见格不足以复原完整周期瓦片，两者合并则恰好足够；最小周期与相位偏移均唯一。

规则：
- 在每个面板内用可见格推断周期，并求出使两面板所有可见格一致的唯一相位偏移。
- 按该偏移合并两面板的可见格，复原完整的p×q瓦片。
- 用复原的瓦片按左面板的相位填补左面板的所有黑洞，输出修复后的左面板。

关键洞察：
- 等大的左右面板诱导人做逐格叠加，但两视图相位错开，直接按同坐标合并会自相矛盾；必须先以周期对齐相位，两片残缺证据才能互补成完整瓦片。
```
