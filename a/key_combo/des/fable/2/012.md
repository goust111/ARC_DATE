## 1. 变色巡游射线

- tags:
  - operation:射线延伸, ray_extend
  - operation:重涂色, recolor
  - object:对角射线种子, diagonal_ray_seed
  - object:反射镜段, mirror_segment
  - object:双列图例, two_col_legend
  - relation:状态匹配反射, state_matched_reflection
  - condition:图例链式变色, legend_chain_recolor
- 参考题目题号: 6, 12, 15

### docstring

```text
从对角种子发射的射线只被与其当前颜色相同的线段反射，每次反射后按双列
图例换成下一种颜色，画出一条逐段变色的折线。

输入结构：
- 黑色背景网格，含一段 2~3 像素的对角射线种子，其颜色为起始色，末端
  指明前进方向。
- 若干水平或竖直的单色线段散布在网格中，颜色各异。
- 网格一角有一个紧凑的两列图例块，每行给出一对颜色（左列到右列）。

规则：
- 射线从种子末端沿对角方向前进，将沿途的背景格染成当前颜色。
- 当下一格属于某线段且该线段颜色等于射线当前颜色时发生反射：该格不被
  染色；撞水平线段时翻转行方向，撞竖直线段时翻转列方向；随后在图例中
  找到左列等于当前颜色的行，射线换为该行右列的颜色继续前进。
- 颜色不等于射线当前颜色的线段视为透明，射线直接穿过，这些格保持原色
  不被覆盖。
- 射线离开网格边界即结束；图例与所有线段保持不变。

关键洞察：
- 哪些线段是"镜子"不是固定的，而取决于射线此刻的颜色；图例规定了每次
  反射后的换色顺序，于是整条路径是一场按图例串起来的寻宝：只有颜色链
  上的线段才参与反射，其余同形线段全是幌子。
```

## 2. 拓扑通行迷宫

- tags:
  - operation:寻路, pathfinding
  - operation:重涂色, recolor
  - object:封闭对象, closed_object
  - object:开放对象, open_object
  - object:端点像素, endpoint_pixel
  - relation:四邻接连通, four_neighbor_connect
  - condition:有孔者为墙, hole_is_wall
  - condition:最短路径唯一, unique_shortest_path
- 参考题目题号: 3, 10, 20

### docstring

```text
只把"带封闭孔洞的对象"当作墙体，找出两个红点之间唯一的最短四邻接
路径并染黄。

输入结构：
- 黑色背景网格，恰有两个红色端点像素。
- 多个单色四连通前景对象，颜色多样：一部分是包含至少一个封闭背景孔洞
  的闭合框，另一部分是不含任何孔洞的开放线形。

规则：
- 含封闭孔洞的对象连同其全部像素不可通行；不含孔洞的对象像素与背景格
  一样可以通行。
- 求两个红色端点之间唯一的最短四邻接路径。
- 将路径上除端点外的所有格染黄，包括被穿过的开放对象像素；其余一切
  保持原样。

关键洞察：
- 墙与路的区分与颜色、大小、位置都无关，只取决于对象是否围出封闭孔洞
  这一拓扑性质；按颜色分类在个别示例上碰巧成立，但推广到全部示例必错。
```

## 3. 十字折页展开

- tags:
  - operation:平铺, tiling
  - operation:镜像, mirror
  - operation:画布扩展, canvas_expansion
  - object:输入瓦片, input_tile
  - object:引导行或列, guide_row_or_column
  - relation:交点锚定相位, cross_anchors_phase
  - relation:共享边镜像连续, edge_mirror_continuity
- 参考题目题号: 5, 14

### docstring

```text
瓦片中一行一列两条引导线的交叉点选定锚定块，沿十字带向四个方向以
"折页镜像"方式展开瓦片。

输入结构：
- 输入是 n×n 瓦片，恰有一条整行与一条整列由同一颜色构成，两条引导线
  相交于一点，其余部分是一般的不对称图案。

规则：
- 建立 n×n 个块、每块 n×n 的黑色画布。
- 设引导行为 r、引导列为 c，则填充第 r 个块行与第 c 个块列组成的十字带。
- 把原始瓦片放在块坐标 (r, c) 的锚定块上；从锚定块沿带的四个方向逐块
  展开，每前进一块就把上一块的图案关于两块公共边作镜像（左右方向交替
  左右翻转，上下方向交替上下翻转），使图案跨块连续。
- 带外的块保持全黑。

关键洞察：
- 两条引导线的交点不只是选带，还锚定了展开的相位起点；带的延伸不是
  复制粘贴而是折页展开——若示例瓦片恰好对称，平移与折页无法区分，
  只有不对称图案才暴露真正的规则。
```

## 4. 台球种子

- tags:
  - operation:射线延伸, ray_extend
  - object:种子像素, seed_pixel
  - object:方向标记, direction_marker
  - object:吸收像素, absorber_pixel
  - relation:边界反射, boundary_reflection
  - condition:自交变蓝, self_cross_blue
  - condition:吸收停止, absorb_stop
- 参考题目题号: 6, 7, 15

### docstring

```text
种子像素沿标记指示的对角方向做台球式反弹，直到被吸收点吸收，路径染成
种子色、自交处染蓝。

输入结构：
- 黑色背景网格，含一个彩色种子像素，其某个对角相邻格是灰色方向标记。
- 另有若干孤立的灰色吸收像素散布在网格中。

规则：
- 射线从种子出发，沿背离灰色标记的对角方向前进（即从标记指向种子的
  方向）。
- 触及网格边界时像台球一样反弹：撞上下边翻转行方向，撞左右边翻转列
  方向，撞到角上则两个方向同时翻转。
- 途经的背景格染成种子色；当射线第二次经过某个已染色格时，该格改染
  蓝色。
- 射线进入任一灰色吸收像素所在格时立即终止；方向标记与吸收像素保持
  灰色不变。

关键洞察：
- 折线不是画出来的对象，而是一条受边界反弹支配的轨迹；终点由灰色吸收
  点决定，路径的自交点以蓝色单独标出，灰色像素同时扮演"起始方向"与
  "终止条件"两种角色。
```

## 5. 图例指挥的坠落

- tags:
  - operation:滑动, slide
  - operation:堆叠, stack
  - object:精灵体, sprite
  - object:边缘图例, edge_legend
  - relation:图例位置定重力, legend_side_sets_gravity
  - relation:图例行序决定顺序, legend_row_order
  - condition:依序坠落互锁, sequential_drop_interlock
  - condition:碰撞停止, collision_stop
- 参考题目题号: 12, 20

### docstring

```text
精灵们朝图例所贴的那条边"坠落"，坠落次序按图例从远端读起，先落者成为
后落者互锁的地基。

输入结构：
- 黑色背景网格，若干形状各异、颜色互不相同的单色四连通精灵悬浮在不同
  位置。
- 网格某一条边上贴着一条单行或单列图例，恰好列出全部精灵颜色各一次。

规则：
- 清空画布，保留图例。
- 重力方向指向图例所贴的那条边：贴底边则向下，贴右边则向右，其余同理。
- 按图例从离该边最远的一端向近端的顺序逐个处理精灵。
- 每个精灵保持形状与垂直于重力方向上的坐标不变，沿重力方向滑动，直到
  与该边或已落定的精灵碰撞后固定。
- 全部精灵落定后即为输出。

关键洞察：
- 既不是"低者先落"的物理直觉，也不是固定向下的重力——方向与次序都由
  图例的位置和读取方向编码；精灵形状互相咬合，次序不同堆出的地形不同，
  因此图例顺序是结果不可分割的一部分，先落的垫在下面成为后落者的地基。
```

## 6. 风车中的镜像赝品

- tags:
  - operation:旋转, rotation
  - operation:重绘, redraw
  - object:象限, quadrant
  - object:分隔十字, separator_cross
  - relation:四象限旋转关系, pinwheel_relation
  - condition:手性异常修复, chirality_impostor_repair
- 参考题目题号: 14, 16, 19

### docstring

```text
四个象限本应构成同一图案的 90 度风车旋转家族，找出被换成镜像赝品的
那个象限并按旋转关系修复。

输入结构：
- 网格边长为奇数，中间行与中间列构成分隔十字，划出四个同尺寸的正方形
  象限。
- 存在一个基准图案：四个象限依次应为它旋转 0、90、180、270 度的副本，
  构成风车关系；图案本身不具有镜像对称性。
- 恰有一个象限被替换成了"该位置应有图案的镜像翻转"，其余三个象限保持
  正确。

规则：
- 以旋转关系两两校验四个象限，找出与其余三个不一致的那一个。
- 用其余任一正确象限经相应角度旋转，得到该位置应有的图案并替换赝品。
- 输出修复后的完整网格，分隔十字保持不变。

关键洞察：
- 赝品与真品由完全相同的像素多重集构成，粗看四个象限"都像同一个图案"；
  必须区分旋转与镜像这两种全等变换，才能发现唯一一个手性相反的象限。
```

## 7. 现场示范的运算

- tags:
  - operation:布尔运算, boolean_op
  - operation:裁剪, crop
  - object:掩码区域, mask_region
  - object:分隔线, divider_line
  - object:微型示例, inline_demo
  - relation:示范决定运算, demo_selects_op
  - condition:逐例变化的规则, per_example_rule
- 参考题目题号: 8, 12

### docstring

```text
网格里附带一组"小输入、小输入、小结果"的微型示范，先从示范中读出本例
使用的布尔运算，再把它施加到主掩码对上。

输入结构：
- 主区域：两个同尺寸的单色掩码被一条整行或整列分隔线隔开，各以一种
  前景色标记若干格。
- 副区域：与主区域隔开的角落里并排放着三个同尺寸的小网格——两个小
  掩码和一个小结果，小结果使用第三种颜色。
- 不同示例对中，示范演示的运算可以不同（交、并、异或等）。

规则：
- 对照两个小掩码与小结果，唯一确定示范所演示的逐格布尔运算；小掩码
  经过取值设计，能够区分所有候选运算。
- 去掉分隔线，把主区域两掩码逐格对齐，施加刚才读出的运算。
- 输出与单个主掩码同尺寸：运算为真的格涂示范结果所用的颜色，其余为
  背景。

关键洞察：
- 变换规则本身不是恒定的，它被画在输入里：那三个小网格不是待处理的
  数据，而是一份现场示范；不读懂示范，仅凭主掩码对无法知道该做哪种
  运算。
```

## 8. 双重归属的放大

- tags:
  - operation:计数, counting
  - operation:像素放大, pixel_upscale
  - object:矩形框, rectangular_frame
  - object:标记像素, marker_pixel
  - object:精灵体, sprite
  - relation:颜色配对选框, color_pairing
  - relation:空间包含定色, containment_sets_color
  - condition:框内计数定倍率, count_sets_scale
  - condition:忽略干扰项, ignore_distractors
- 参考题目题号: 2, 4, 11

### docstring

```text
精灵的放大倍率来自"同色框"的内部计数，放大后的颜色来自"宿主框"的
颜色，两种归属关系各司其职。

输入结构：
- 背景网格上有若干个一格厚的矩形框，颜色互不相同；灰色标记像素散布在
  各框内外。
- 一个小的单色四连通精灵严格位于某个矩形框的内部，但精灵的颜色恰与
  另一个矩形框相同。

规则：
- 找到与精灵同色的那个矩形框，数出严格位于其内部的灰色标记数 N。
- 找到空间上包含精灵的宿主框，取其颜色 C。
- 输出为精灵形状的 N 倍像素放大：精灵每个像素变成 N×N 的同色块，全部
  染成颜色 C，背景格同样放大。
- 其余矩形框以及框外的灰色标记均为干扰，与答案无关。

关键洞察：
- 题中存在两种"归属"——颜色配对与空间包含，它们并存且分工：前者给出
  倍率、后者给出颜色；把任何一种归属当成唯一线索都会得到错误答案。
```

## 9. 走出来的最近

- tags:
  - operation:寻路, pathfinding
  - operation:重涂色, recolor
  - operation:擦除, erase
  - object:前景对象, foreground_object
  - object:标记像素, marker_pixel
  - object:障碍像素, blocker_pixel
  - relation:测地距离选择, geodesic_nearest
  - condition:直线距离是陷阱, euclidean_decoy
- 参考题目题号: 10, 18

### docstring

```text
把灰色对象染成"沿可通行路径走过去最近"的那种标记颜色，而不是直线距离
最近的颜色。

输入结构：
- 黑色背景网格上有若干蓝色墙体、一个灰色四连通对象，以及数个颜色互不
  相同的孤立标记像素。
- 从每个标记到灰色对象都存在绕过墙体的四邻接通路。

规则：
- 对每种标记颜色，计算从该标记出发、不得穿过蓝色墙体、到达灰色对象
  任一像素的最短四邻接步数。
- 取步数最小的那种标记颜色，把灰色对象整体染成该色。
- 擦去所有标记像素，蓝色墙体保持不变。

关键洞察：
- "最近"按迷宫中的实际步行距离衡量，而非直线距离；直线上最近的标记
  往往被墙隔开、绕行更远，蓝色墙体的存在正是为了颠覆直觉上的名次。
```
