## 1. 周界指令环

- 参考题目题号: `1 (e48d4e1a)`, `2 (30f42897)`, `5 (40853293)`
- tags:
  - operation:计数, counting
  - operation:平移, translate
  - object:边框段, border_segment
  - object:实心对象, solid_object
  - relation:环形路径, cyclic_path
  - relation:同色配对, same_color_pairing
  - relation:面积决定偏移, area_determines_offset
  - condition:计数器消失, counter_disappears

### docstring

```text
将每条边框彩色线段沿周界环顺时针移动，步数等于内部同色实心对象的像素数，该对象随之消失。

输入结构：
- 黑色背景网格，最外圈边框上有若干条颜色互不相同的连续彩色线段，线段可跨过角格。
- 网格内部对每种线段颜色恰有一个同色的实心连通对象，对象不与边框接触。
- 保证各线段移动之后互不重叠。

规则：
- 把最外圈边框按顺时针方向展开成一条首尾相接的环形路径。
- 对每种颜色，数出内部同色对象的像素个数 n。
- 将该颜色的边框线段沿环形路径顺时针平移 n 格，其余边框格保持黑色。
- 所有内部对象从输出中删除。

关键洞察：
- 内部对象不是要移动的图形，而是纯数值指令：它的面积规定了同色线段在
  周界环上的位移量，指令用完即消失；边框必须被理解为一维循环路径而非
  四条独立的边。
```

## 2. 双闸折叠

- 参考题目题号: `11 (5d2a5c43)`, `7 (5e6bbc0b)`, `9 (f76d97a5)`
- tags:
  - operation:透明叠加, transparent_overlay
  - operation:重涂色, recolor
  - object:二值掩码, binary_mask
  - object:分隔列, divider_column
  - relation:逐行指令, per_row_instruction
  - relation:自左向右折叠, left_to_right_fold
  - condition:颜色选择运算, color_selects_operation
  - condition:埋诱饵, decoy_hypothesis

### docstring

```text
两条分隔列的颜色逐行指定三块面板自左向右的两步折叠运算，结果以青色写入紧凑输出。

输入结构：
- 网格由三块等尺寸的黑/黄二值面板与两条全高单格分隔列交替排成：
  面板、分隔列、面板、分隔列、面板。
- 每条分隔列的每个格子是蓝色或红色，同一列内可以逐行不同。

规则：
- 输出与单块面板同尺寸，逐行独立计算。
- 先将左、中面板的该行按第一条分隔列该行格子的颜色做运算：
  蓝色为并集（任一面板为黄则真），红色为对称差（恰好一个面板为黄则真）。
- 再将上一步结果与右面板该行按第二条分隔列该行格子的颜色做同种运算。
- 最终为真的格子输出青色，其余输出黑色。

关键洞察：
- 分隔列不是隔板而是两道串联的逐行运算闸门，必须发现"逐行、自左向右
  两步折叠"的复合结构；并集与对称差只在面板重叠的格子上产生差别，
  只看无重叠的行会误以为整题是简单的三层叠加。
```

## 3. 反弹预算

- 参考题目题号: `4 (a3df8b1e)`, `1 (e48d4e1a)`, `7 (5e6bbc0b)`
- tags:
  - operation:射线延伸, ray_cast
  - operation:计数, counting
  - object:孤立像素, isolated_pixel
  - object:计数器像素, counter_pixel
  - object:画布边界, canvas_boundary
  - relation:反射弹回, reflection_bounce
  - relation:计数限定反弹, count_limits_bounces
  - condition:预算耗尽即停, stop_when_budget_spent
  - condition:计数器消失, counter_disappears

### docstring

```text
从底边彩色像素发出的对角光线在四壁间反弹，顶行灰色像素的个数是允许的反弹次数，预算用尽后光线停在下一次触壁处。

输入结构：
- 黑色网格，底边上恰有一个非黑非灰的彩色像素作为发射点。
- 顶行自左端起有一段连续的灰色像素，其个数即反弹预算。
- 保证光线路径不经过角格，也不经过灰色像素所在的格子。

规则：
- 光线从发射点出发向右上方沿对角线前进，途经格子涂成发射点颜色。
- 每次到达任一边界格，相应方向分量反转并记一次反弹，反弹格同样涂色。
- 完成与灰色像素个数相同的反弹后，光线继续前进，到达的下一个边界格
  涂成红色并停止。
- 灰色像素从输出中删除。

关键洞察：
- 灰色像素不参与画面，它是反弹配额：没有终止条件的封闭盒内光线会无限
  反弹，配额同时决定了路径的确切长度与红色终点的位置。
```

## 4. 谁是谁的像

- 参考题目题号: `14 (269e22fb)`, `18 (c48954c1)`, `9 (f76d97a5)`
- tags:
  - operation:镜像, mirror
  - operation:重涂色, recolor
  - operation:裁剪, crop
  - object:精灵体, sprite
  - relation:二面体变换, dihedral_transformation
  - relation:隐藏示例对, hidden_demo_pair
  - relation:颜色定方向, color_determines_direction
  - condition:唯一变换, unique_transform
  - condition:忽略干扰项, ignore_distractors

### docstring

```text
在三个漂浮图形中找出互为旋转翻转像的隐藏示例对，把示例演示的变换与换色施加到第三个图形上。

输入结构：
- 均匀黑色背景上漂浮三个单色图形，颜色互不相同。
- 恰有一对图形形状同构：一个是另一个经过某个旋转或翻转后的结果；
  该形状不具有任何非平凡对称，故所用变换唯一。
- 第三个图形与这两者形状均不同构，且它的颜色总等于示例对中原形的颜色。

规则：
- 在三个图形间两两比对，找出唯一的同构对。
- 设与第三个图形同色者为原形（颜色 x），另一个为像（颜色 y），
  由原形到像提取二面体变换 t 与色映射 x 变 y。
- 对第三个图形施加同一变换 t 并换色为 y。
- 输出为结果的紧凑包围盒裁剪，背景为黑。

关键洞察：
- 变换规则不写在训练对之间，而是画在每个输入内部：一对图形就是一份
  完成好的输入输出小样；样例对没有任何位置或分隔提示，须自行发现
  同构关系，而变换方向不能靠位置猜，只能由"第三个图形与原形同色"
  这一颜色证据确定。
```

## 5. 双缺陷瞄准

- 参考题目题号: `2 (30f42897)`, `19 (b7955b3c)`, `17 (e41c6fd3)`
- tags:
  - operation:平移, translate
  - operation:补全, repair
  - operation:模式检测, pattern_detection
  - object:周期边框, periodic_border
  - object:精灵体, sprite
  - object:锚点像素, anchor_pixel
  - relation:环形周期, cyclic_period
  - relation:异常即坐标, anomaly_as_coordinate
  - relation:十字交点定位, cross_intersection_targeting
  - condition:缺陷修复, defect_repaired
  - condition:忽略干扰项, ignore_distractors

### docstring

```text
边框上两个违反周期相位的缺陷格分别给出行坐标与列坐标，把含灰色锚点的精灵平移到十字交点并修复缺陷。

输入结构：
- 网格最外圈边框沿顺时针方向呈严格的双色周期图案。
- 边框上恰有两个缺陷格：缺陷使用的仍是周期双色之一，但违反周期相位
  （应为一色处涂了另一色），单看颜色完全合法。
- 一个缺陷位于水平边框（上边或下边），另一个位于竖直边框（左边或右边）。
- 网格内部有一个多格彩色精灵，其中恰含一个灰色锚点像素；
  另有若干形状相似但不含灰色锚点的干扰对象。

规则：
- 沿边框逐格核对周期，找出两个相位违例格。
- 取竖直墙缺陷所在的行与水平墙缺陷所在的列，得到交叉点。
- 将含锚点的精灵刚性平移，使灰色锚点像素恰好落在交叉点上；
  精灵形状与颜色不变，原位置清为黑色，干扰对象原地不动。
- 把两个缺陷格修复为周期应有的颜色。

关键洞察：
- 缺陷颜色本身合法、入口极隐蔽，必须先建立"边框本应严格周期"的模型
  逐格校验才能发现；两个缺陷不是各自就近的停靠点，而是分别贡献一个
  坐标分量的十字瞄准线，交点才是锚点的落点，输出中边框恢复完美周期。
```

## 6. 钥匙与锁

- 参考题目题号: `6 (e73095fd)`, `12 (d6ad076f)`, `5 (40853293)`, `3 (0a2355a6)`
- tags:
  - operation:平移, translate
  - operation:填充, fill
  - object:空心矩形, hollow_rectangle
  - object:缺口, gap
  - object:线段, bar_segment
  - relation:长度配对, length_matching
  - relation:封口触发填充, sealing_triggers_fill
  - condition:连锁反应, chain_reaction
  - condition:钥匙决定填色, key_color_fills

### docstring

```text
把每根彩色短条平移进缺口宽度与其长度相等的灰色空心矩形缺口中封口，被封口的矩形内部染成钥匙的颜色。

输入结构：
- 黑色背景上有若干灰色空心矩形轮廓，多数矩形在某条边上恰有一个缺口，
  各缺口宽度互不相同；可能存在一个天生无缺口的完整矩形。
- 散落着与缺口数量相同的彩色短条（横条或竖条），每根长度恰等于一个
  缺口的宽度，方向与该缺口一致。

规则：
- 按长度把每根短条与唯一等宽的缺口配对。
- 将短条平移到缺口处恰好补齐缺失的轮廓格，颜色保持不变，原位置清为黑色。
- 每个被短条封口的矩形，其内部黑色区域全部染成封口短条的颜色。
- 天生无缺口的完整矩形内部保持黑色。

关键洞察：
- 染色不是"封闭即填充"：天生封闭的矩形并不上色，只有钥匙进入锁孔才把
  自己的颜色灌进内部——填充是配对与移动的因果结果，填充色也由钥匙而非
  锁决定。
```

## 7. 棋盘上的异色

- 参考题目题号: `7 (5e6bbc0b)`, `20 (e50d258f)`, `9 (f76d97a5)`
- tags:
  - operation:模式检测, pattern_detection
  - operation:重涂色, recolor
  - operation:裁剪, crop
  - object:棋盘格图案, checkerboard_pattern
  - object:违例像素, violation_pixel
  - relation:奇偶性定应有色, parity_determines_expected_color
  - relation:违反方向定输出色, violation_direction_to_color
  - condition:图形即偏差, figure_is_deviation

### docstring

```text
找出违反棋盘着色的所有格子，按其违反方向重新着色后输出这些格子的最小包围盒裁剪。

输入结构：
- 网格整体是颜色 a 与 b 构成的标准棋盘格，相位由整体多数格决定。
- 少数格子的颜色与棋盘规定相反：应为 a 处却是 b，或应为 b 处却是 a；
  这些违例格共同构成一个隐藏图形。

规则：
- 依据棋盘相位判定每个格子的应有颜色，标出所有违例格。
- 取全部违例格的最小包围盒作为输出尺寸。
- 包围盒内：应为 a 却是 b 的格子输出蓝色，应为 b 却是 a 的格子输出红色，
  其余格子输出黑色。

关键洞察：
- 图形不由颜色本身给出：同一种颜色在一半位置上是正常背景、在另一半
  位置上是违例信号，必须先重建棋盘坐标系才能看见隐藏图形；图形还自带
  由违反方向决定的双色，违例不仅有位置，还有极性。
```
