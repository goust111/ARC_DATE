## 1. 图例定向绕行

- tags:
  - operation:路径追踪, path_trace
  - operation:连线, line_drawing
  - object:粒子, particle
  - object:竖直墙段, vertical_wall_segment
  - object:颜色图例, color_legend
  - relation:图例映射行为, legend_maps_behavior
  - condition:撞墙按色绕行, wall_color_determines_detour
- 参考题目: 9bbf930d(10), 9385bd28(5), dfadab01(20)

### docstring

```text
青色粒子自左缘向右穿行，撞上彩色墙段时按图例规定的方向绕行，画出全部轨迹。

输入结构：
- 背景为黑色的大网格，中部与右部散布若干竖直彩色墙段（不满列的竖条，颜色各异）。
- 左缘若干行各有一个青色粒子起点。
- 网格左下角有图例区：每个图例项为竖直相邻的两格，一格为某墙色，另一格为灰色，
  灰格位于墙色格的上方或下方。

规则：
- 每个粒子逐格向右移动，途经格涂为青色。
- 当粒子右侧一格是墙格时，查图例：该墙色的灰格在上，粒子改为沿当前列向上移动；
  灰格在下则向下移动。
- 绕行期间每步检查右侧：一旦右侧不再是墙格，下一步恢复向右移动。
- 粒子从右缘离开即完成；轨迹全部保留为青色，墙与图例原样保留。

关键洞察：
- 图例不是颜色替换表，而是行为表：每种墙色被映射为一个绕行方向，
  同一张图例控制所有粒子在所有墙前的转向决策。
```

## 2. 下采样点阵重建

- tags:
  - operation:像素采样, pixel_subsample
  - operation:旋转, rotate
  - operation:镜像, mirror
  - object:逻辑点阵, logical_dot_lattice
  - object:候选板, candidate_panel
  - relation:投影对应, projection_correspondence
  - condition:姿态消歧唯一匹配, pose_disambiguates_unique_match
- 参考题目: 33067df9(1), 2c181942(13), 67636eac(8)

### docstring

```text
稀疏点阵是候选库中某个图案经旋转或镜像后再隔行隔列采样的投影，重建这幅完整图案。

输入结构：
- 网格被背景带分成同尺寸的若干板块：一个点阵板与若干候选板，边长为奇数。
- 点阵板的彩色像素只落在偶数行与偶数列的交点上，其余为背景。
- 候选板都是致密的多色图案，且任何候选在原始姿态下的取样都与点阵板不一致。

规则：
- 存在唯一的候选与唯一的姿态（旋转 0/90/180/270 度，或先左右镜像再旋转），
  使该候选经此变换后在全部偶行偶列交点处的取样与点阵板逐点一致（含背景点）。
- 输出该候选按此姿态变换后的完整图案。

关键洞察：
- 点阵是最终输出的下采样投影，它同时指定内容与姿态：先要识破稀疏点阵是
  隔行隔列采样，再发现原姿态逐板比对必然全部失败，只有引入旋转与镜像
  才能找到唯一的候选-姿态组合。
```

## 3. 面积定标的正负印章

- tags:
  - operation:图案印章, stamp_glyph
  - operation:像素放大, pixel_scale
  - operation:裁剪, clip
  - object:模板图案, template_pattern
  - object:正方形标记块, square_marker_block
  - relation:边长映射倍率, side_length_maps_scale
  - condition:实心正片空心负片, solid_positive_hollow_negative
- 参考题目: dfadab01(20), 33067df9(1), edcc2ff0(14)

### docstring

```text
把每个正方形标记块替换成模板图案的印章：边长定放大倍数，实心与空心决定正片或负片。

输入结构：
- 网格左上角以背景隔开处放着一幅 3×3 灰色模板图案（部分格为灰、部分为背景）。
- 场上散布若干正方形标记：实心 n×n 色块，或边框厚 1 格、内部为背景的 n×n 空心方框，
  n 取 1、2、3，颜色各异。

规则：
- 输出中抹去模板本体。
- 每个实心 n×n 色块：以其左上角为锚，画出模板放大 n 倍后的 3n×3n 正片印章——
  模板灰格对应的放大区域涂该标记的颜色，其余为背景。
- 每个空心 n×n 方框：同样锚定与放大，但画负片——模板背景格对应的区域涂标记色，
  灰格对应的区域留背景。
- 印章超出网格边界的部分裁掉。

关键洞察：
- 标记块不是要保留的物体而是三重指令：边长是缩放倍数，实心或空心是正负片开关，
  颜色是画笔；模板只是字典条目，不属于场景。
```

## 4. 遮挡序重建

- tags:
  - operation:排序, sort
  - operation:拼接, concatenate
  - object:行列条, row_column_bar
  - object:交叉格, crossing_cell
  - relation:遮挡即先后, occlusion_encodes_order
  - relation:传递推理, transitive_inference
  - condition:遮挡链定全序, occlusion_chain_determines_total_order
- 参考题目: 070dd51e(2), 9344f635(6), 67636eac(8)

### docstring

```text
从横竖条带交叉处的遮挡关系推出全部条带的绘制先后，输出自底层到顶层的颜色序列。

输入结构：
- 网格由若干整行横条与若干整列竖条叠加渲染而成，条带颜色互不相同。
- 每个交叉格显示后画（上层）条带的颜色，其余格显示条带自身颜色或背景。

规则：
- 由非交叉部分恢复每条条带的颜色，由每个交叉格读出该处两条带的上下关系。
- 同向条带互不交叉，其先后须经与异向条带的遮挡关系传递推出；
  全部遮挡关系恰好确定唯一的全序。
- 输出 1×N 横条，自左向右依次为最底层至最顶层条带的颜色。

关键洞察：
- 交叉处的颜色是"时间"的化石：每个交叉给出一对条带的先后，
  而同向条带之间的次序只能靠遮挡链的传递性间接推出。
```

## 5. 藏键排序拼接

- tags:
  - operation:裁剪, crop
  - operation:排序, sort
  - operation:拼接, concatenate
  - operation:镜像, mirror
  - object:连通精灵, connected_sprite
  - object:键像素, key_pixel
  - relation:键行号编码次序, key_row_encodes_order
  - condition:键偏半侧定翻转, key_half_determines_flip
  - condition:位置顺序为诱饵, spatial_order_is_decoy
- 参考题目: 67636eac(8), dfadab01(20), c9e6f938(16)

### docstring

```text
按精灵体内灰色键像素的行号重新排序拼接精灵，键的左右半位置决定该精灵是否先做左右镜像。

输入结构：
- 背景网格上散布若干个包围盒同尺寸（宽为偶数）的单色精灵，水平方向排开。
- 每个精灵内部恰有一个灰色像素（键），各精灵键所在的包围盒行号互不相同，
  且恰为 0 到 n-1。

规则：
- 键位于包围盒左半的精灵保持原样；位于右半的精灵先整体左右镜像。
- 将各精灵的包围盒裁剪按键行号从小到大自左向右拼接成输出。
- 输出中键像素恢复为该精灵自身的颜色。

关键洞察：
- 精灵的空间排列顺序是诱饵；次序与朝向都写在精灵体内：
  键的行号是序号，键偏向哪半是镜像开关，且键在输出中被消耗掉。
```

## 6. 线段轴域对称染色

- tags:
  - operation:重涂色, recolor
  - object:红色线段轴, red_segment_axis
  - object:灰色散点, grey_scatter_pixel
  - relation:场内轴镜像配对, in_scene_axis_mirror_pairing
  - relation:线段跨度即作用域, segment_span_is_scope
  - condition:双检验四类着色, dual_test_four_way_coloring
- 参考题目: ce039d91(15), c1d99e64(12), 0d87d2a6(19)

### docstring

```text
以场内两条红色线段为镜轴给灰点做双重对称检验，按通过哪些检验把灰点染成蓝、绿或黄。

输入结构：
- 黑背景上有一条竖直红色线段（占某列的一个行区间）和一条水平红色线段
  （占某行的一个列区间），以及若干灰色散点；灰点不与红线共行共列。

规则：
- 竖轴检验：灰点的行号落在竖线段的行区间内，且它关于竖线段所在列的镜像位置也是灰点。
- 横轴检验：灰点的列号落在横线段的列区间内，且它关于横线段所在行的镜像位置也是灰点。
- 只通过竖轴检验的灰点涂蓝，只通过横轴检验的涂绿，两项都通过的涂黄，
  都不通过的保持灰色。红线原样保留。

关键洞察：
- 对称轴不是画布中线而是场景内的有限线段：线段的跨度是检验的作用域，
  看似成对但越出作用域的灰点不染色；两个独立检验叠加出四类着色。
```

## 7. 方向选择连通方式的计数配色

- tags:
  - operation:计数, counting
  - operation:重涂色, recolor
  - object:指示条, indicator_bar
  - object:碎片物体, fragment_object
  - relation:长度即计数键, length_is_count_key
  - condition:横四连通竖八连通, horizontal_4conn_vertical_8conn
- 参考题目: edcc2ff0(14), e0fb7511(9), 9344f635(6)

### docstring

```text
把指令带里的每根灰条涂成计数匹配的颜色：横条按四连通计数查色，竖条按八连通计数查色。

输入结构：
- 顶部为黑色指令带，带内散布互不接触的灰色横条与竖条，长度不一。
- 下方为非黑背景的场景板，含多种颜色的碎片状物体，部分同色碎片只以对角相触。

规则：
- 对每根水平灰条（长 n）：找出场景中四连通物体个数恰为 n 的唯一颜色，把整条涂成该色。
- 对每根竖直灰条（长 m）：找出场景中八连通物体个数恰为 m 的唯一颜色，把整条涂成该色。
- 场景板原样保留。

关键洞察：
- 条的方向不是摆放差异而是计数定义的选择器：同一堆像素在四连通与八连通下
  个数不同，只有分别采用两种连通性，每根条才恰有唯一匹配色。
```
