## 1. 缺口串联的守恒排水

- 参考题目: e12f9a14(框与缺口)、9aaea919(数量守恒转移)、8efcae92(内部标记计数)、13713586(直线通道)
- tags:
  - operation:传输, transfer
  - operation:计数, counting
  - operation:擦除, erase
  - object:空心框, hollow_frame
  - object:框架缺口, frame_gap
  - object:标记像素, marker_pixel
  - relation:缺口对准成链, gap_alignment_chain
  - condition:数量守恒, count_conservation

### docstring

```text
所有框内的水滴沿缺口对准形成的管线汇入链末端,末端缺口向外排出一条长度等于全链水滴总数的色带。

输入结构
- 黑色背景上有若干彼此独立的空心矩形框,墙为同一颜色,每个框的墙上恰有一个单格缺口。
- 每个框内部散布若干同一颜色的水滴像素。
- 部分框的缺口沿垂直于所在边的向外直线恰好对准另一个框的缺口,且沿途无任何阻挡;
  这些对准关系把若干框连成一条或多条有向链;画面中也可能存在不与任何框对准的孤立框。

规则
- 把每个框的缺口视为唯一出口,水滴沿出口方向流出。
- 若出口直线通向另一框的缺口,则把两缺口之间的直线通道全部涂成水滴色,该框的水滴全部流入下游框。
- 每条链最末端的框(其出口不通向任何缺口)从缺口向外画一条水滴色直线,长度等于整条链所有框内水滴的总数。
- 孤立框直接向外排出长度等于自身水滴数的直线。
- 所有框内部清空为背景;框墙保持不变。

关键洞察
- 缺口既是方向线索又是拓扑线索:对准的缺口把框接成有向管线;
  末端排出线的长度由整条链的水滴计数守恒决定,而不是最近一个框的自身计数。
```

## 2. 残片的负空间拼图

- 参考题目: fd096ab6(模板与碎片对齐)、bb52a14b(缺失掩码)、aee291af(多对象比对)
- tags:
  - operation:对齐, align
  - operation:补全, completion
  - operation:反转, negation
  - object:残片, fragment
  - object:隐形模板, invisible_template
  - relation:平移对齐, translate_align
  - condition:缺失区互补, missing_regions_disjoint

### docstring

```text
把同一隐形图案的几个残缺副本对齐,输出每个副本各自缺失的部分,拼成一幅互补的负空间图。

输入结构
- 黑色背景上有若干个单色残片,颜色互不相同,彼此分离。
- 所有残片都是同一个从未完整出现的图案的平移副本,各被抹去了一块不同的区域;
  被抹去的区域在图案坐标系下互不重叠。
- 任意残片之间的共有部分足以唯一确定它们的平移对齐(无旋转、无翻转)。

规则
- 通过平移把所有残片对齐到同一图案坐标系,重构出完整图案的范围。
- 输出网格为完整图案外接矩形的大小。
- 图案中被某个残片缺失的格,涂上那个残片自己的颜色。
- 被所有残片共同拥有的格保持背景色。

关键洞察
- 输出画的不是重构出的图案本身,而是它的负空间:
  每个残片"缺了什么"用它自己的颜色标注;由于缺失区互不重叠,每格的颜色归属唯一。
```

## 3. 计票定层序的投影

- 参考题目: 13713586(向边条投影分层)、8efcae92(稀有标记计数)、7e0986d6(噪点语义重解释)
- tags:
  - operation:射线延伸, ray_extend
  - operation:遮挡覆盖, occlusion_overwrite
  - operation:计数, counting
  - object:边缘实心条, solid_edge_bar
  - object:平行线段, parallel_segment
  - object:标记像素, marker_pixel
  - condition:计数定绘制顺序, count_sets_draw_order
  - condition:埋诱饵, decoy_first_example

### docstring

```text
每条彩色线段向实心边条投影成色带,覆盖次序不由远近决定,而由各段所携稀有标记像素的数量决定。

输入结构
- 恰有一条网格边被涂成实心灰条,背景为黑色。
- 其余前景是若干与灰条平行的单色线段,主色互不相同;
  每条线段上有若干格被同一种稀有标记色替换。

规则
- 每条线段向灰条方向投影出与自身等宽的主色矩形色带,从线段所在位置一直铺到灰条之前。
- 标记数少的段先画,标记数多的段后画;后画的色带覆盖先画色带的重叠部分。
- 标记像素不出现在输出中:每条线段连同其标记位整体并入自己的主色色带;灰条保持不变。

关键洞察
- 直觉的"近者覆盖远者"只在部分示例里凑巧成立;
  真正的层序钥匙是每段携带的标记像素张数——标记本身在输出中消失,只作为覆盖优先级的票数。
```

## 4. 穿膜堆叠的形状循环

- 参考题目: a47bf94d(形状循环映射)、9aaea919(车道下落堆叠)、494ef9d7(滑动停止)
- tags:
  - operation:滑动, slide
  - operation:形状变换, shape_transform
  - operation:计数, counting
  - operation:堆叠, stack
  - object:令牌, token
  - object:变换膜, transform_line
  - relation:路径穿越计数, path_crossing_count
  - condition:形状循环映射, shape_cycle_mapping
  - condition:先落垫高后落, earlier_landing_raises_later

### docstring

```text
令牌依高度次序竖直下落堆叠,每穿过一条灰色膜线形状就沿固定循环变换一步,先落者垫高后落者从而改变其穿线数。

输入结构
- 黑色背景,底部为实心地板。
- 上方悬浮若干 3x3 单色令牌,形状取自一个循环族(实心方块、十字、X 形);
  同一列区间内可有多枚令牌上下错开。
- 画面中散布若干条只横跨部分列的水平灰色线段;灰线不是障碍物。

规则
- 位置低的令牌先落,落在地板或已落令牌之上紧贴停住,并成为后落令牌的新地板。
- 每个令牌按它实际走过的下落路径,计数完整穿过的灰线条数,
  形状沿固定循环前进相应步数,颜色不变。
- 灰线与地板在输出中保持原样;令牌原来悬浮的位置清空为背景。

关键洞察
- 灰线不是障碍而是变换计数器,且计数的是"实际路径":
  先落的令牌垫高了后落令牌的停点,使其少穿若干条灰线;
  堆叠次序与穿线计数互相咬合,不能各自独立计算。
```

## 5. 单元阵中的反弹光线

- 参考题目: 55059096(对角连线)、c3202e5a(分隔网格单元)、4c416de3(朝向语义)、e12f9a14(光线转向)
- tags:
  - operation:射线延伸, ray_extend
  - operation:连线, connect
  - object:分隔线, separator_line
  - object:网格单元, grid_cell
  - object:箭头图形, arrow_glyph
  - relation:单元级轨迹, cell_level_trajectory
  - condition:边界镜面反弹, boundary_mirror_bounce
  - condition:遇箭头停止, stop_at_arrow

### docstring

```text
把分隔网格的每个单元当作一个大像素,每个箭头沿其对角朝向发出可在阵列边界镜面反弹的光线,直到进入另一个箭头单元为止,沿途空单元被点亮为光线颜色。

输入结构
- 网格被同色分隔线划成等大的方形单元阵。
- 部分单元内画有一个直角箭头小图形,箭头有四种对角朝向,颜色各异;其余单元为空。

规则
- 在单元坐标系下,每个箭头从自身单元出发,沿其朝向按对角方向逐单元前进。
- 光线碰到单元阵边界时按镜面反射规则改变方向继续前进。
- 光线进入含另一箭头的单元时停止。
- 把光线途经的每个空单元的中央涂一个发射箭头颜色的像素;箭头本身与分隔线保持不变。
- 每条光线在示例结构上保证会命中某个箭头单元。

关键洞察
- 轨迹发生在"单元"这一粗尺度上且包含反弹:
  两个箭头之间的连接关系不再是画面上可直接看出的对齐,
  必须在粗尺度上追踪折线路径,才能确定哪些单元被点亮、以及用谁的颜色。
```

## 6. 隐形棱镜的探测与穿透

- 参考题目: 13713586(边到物的射线)、d968ffd4(轴向走廊)、8efcae92(实心矩形)、42f14c03(忽略干扰)
- tags:
  - operation:反向推理, inverse_inference
  - operation:填充, fill
  - operation:射线延伸, ray_extend
  - object:探测线, probe_ray
  - object:隐形矩形, invisible_rectangle
  - relation:端点包络, endpoint_envelope
  - condition:贯穿线为阴性证据, full_ray_negative_evidence
  - condition:擦边诱饵, tangent_ray_decoy

### docstring

```text
从四边伸入的探测线有些被一块从未画出的隐形矩形吸收而中断,反推出矩形后把它涂黄,并让每条中断线在矩形另一侧续画到对面边缘。

输入结构
- 黑色背景;从网格四条边垂直伸入若干条单格宽的彩色探测线。
- 有的线半途中断:它的末端紧贴隐形矩形的表面。
- 有的线贯穿整个网格:其中既有行列确实避开矩形的,也有恰好擦着矩形边缘经过的。
- 隐形矩形是唯一的实心轴对齐矩形,画面上没有任何属于它的像素。

规则
- 半途中断的探测线,其末端紧贴矩形的一条边;贯穿线证明矩形不占据它所在的行或列。
- 综合全部贴边证据与排除证据,恢复出唯一与之一致的矩形位置和大小,并把矩形区域涂黄。
- 每条中断线沿原方向越过矩形,在矩形另一侧从紧贴表面处起,续画同色直线直到对面网格边缘。
- 原有的探测线与贯穿线保持不变。

关键洞察
- 矩形只存在于"线停在哪里"与"线没停"之中,擦边贯穿线会误导局部判断,必须全局一致地定位矩形;
  定位只是第一跳,第二跳还要把每条被吸收的线按"穿透"语义补全到对面边缘。
```
