## 1. 孔码显影

- 参考题目题号: 16、20、8
- tags:
  - operation:周期推断, periodic_inference
  - operation:折叠聚合, phase_folding
  - operation:提取, extraction
  - object:周期瓦片, repeating_tile
  - object:缺失像素, missing_pixel
  - relation:相位归并, phase_merging
  - condition:忽略缺失推断周期, ignore_missing_to_infer
  - condition:缺失即信号, absence_is_signal

### docstring

```text
把散布在周期壁纸上的黑色缺失格折叠到一个周期瓦片上，输出这张"孔码"瓦片的显影图。

输入结构：
- 网格是由一块最小周期瓦片平铺成的壁纸，瓦片本身不含黑色。
- 若干格被黑色替换为缺失格。
- 忽略黑色后，与全部非黑格一致的最小周期瓦片唯一。

规则：
- 忽略黑格，推断最小周期瓦片，相位原点取网格左上角。
- 输出为与瓦片同尺寸的网格。
- 对每个黑格计算其在瓦片上的相位，在输出对应相位处填入该相位本应有的真实颜色。
- 未被任何黑格命中的相位填黑。

关键洞察：
- 黑格不是要修复的破损，而是打在周期坐标系上的信息孔；输出不是修复后的壁纸，
  而是全部孔折叠到单个瓦片后的显影——修复题的外壳下藏着一道提取题。
```

## 2. 剥去表层

- 参考题目题号: 2、11、15
- tags:

  - operation:擦除, erase
  - operation:补全重绘, restore_redraw
  - operation:计数, counting
  - object:矩形边框, rect_frame
  - object:计数标记, counter_pixels
  - relation:遮挡顺序, occlusion_order
  - relation:交叉处可见性, crossing_visibility
  - condition:计数定剥离层数, count_sets_peel_depth

### docstring

```text
读出交叠矩形框的遮挡层序，按角落灰点的数量剥掉最上面的若干层，并补全被剥层遮住的下层像素。

输入结构：
- 黑背景上若干 1 格厚、颜色互不相同的轴对齐矩形框互相交叠。
- 交叉处的可见颜色记录上下遮挡关系，由全部交叉可恢复唯一的叠放全序。
- 网格角落另有一簇与所有框分离的灰色像素。

规则：
- 由每种颜色可见像素的包围盒推断该框的完整周界。
- 由交叉处可见性建立遮挡关系，得到唯一叠放全序。
- 数出灰色像素的个数 k，删除层序最上面的 k 个框和全部灰点。
- 剩余框按原层序重绘，包括原先被删除框遮住而不可见的部分。

关键洞察：
- 灰点不是噪声而是剥离深度计数器；答案不是把框全部拆散重排，
  而是把这叠框从顶端揭掉 k 张后的完整画面，被揭走的框底下要露出正确的下层颜色。
```

## 3. 严丝合缝

- 参考题目题号: 5、3、9
- tags:
  - operation:滑动, slide
  - operation:嵌入填充, inlay_fill
  - operation:重涂色, recolor
  - object:墙壁, wall
  - object:凹口, notch
  - object:精灵体, sprite
  - relation:负形互补, negative_shape_complement
  - condition:碰撞停止, collision_stop
  - condition:仅平移匹配, translation_only_match
  - condition:嵌合成败分支, fit_or_jam_branch

### docstring

```text
把每个精灵沿所在行滑向厚墙，与墙缘凹口严丝合缝的精灵没入墙中化为墙色，咬不合的精灵卡在碰撞处保持原色。

输入结构：
- 网格一侧是一堵单色实心厚墙，墙的内缘刻有若干背景色凹口。
- 另一侧散落若干单色精灵，每个精灵的行区间恰对着一个凹口的行区间。
- 有的精灵形状恰是其正对凹口在凹口包围盒内的补形（拼图互补），
  有的不是——其中可能有与凹口同形却不互补的。

规则：
- 每个精灵沿水平方向向墙滑动，直到任一行先接触墙体或凹口壁即停止。
- 若停止时精灵与凹口拼合恰好无缝填满凹口包围盒、墙缘变为平直，
  则该精灵全部重涂为墙色并入墙体。
- 否则精灵停在碰撞位置并保持自身颜色。
- 精灵原位置清为背景，墙与其余像素不变。

关键洞察：
- 判定不是同形匹配而是负形互补——精灵与凹口像拼图的一对；
  与凹口同形的精灵反而咬不合，会像不合的钥匙一样卡在墙外。
```

## 4. 回巢

- 参考题目题号: 20、16、1
- tags:

  - operation:周期推断, periodic_inference
  - operation:标记放置, marker_placement
  - object:周期瓦片, repeating_tile

  - relation:先修复后定位, repair_then_locate
  - condition:忽略缺失推断, ignore_missing_to_infer

### docstring

```text
按壁纸周期修复被啃出的黑色隧道，再把灰色标记放在修复后颜色为巢穴色的那个隧道端点上。

输入结构：
- 网格是一张不含黑色的周期壁纸，其最小瓦片中恰有一格是全图最稀有的颜色（巢穴色）。
- 一条 4 连通、宽 1、无分叉的黑色隧道蜿蜒穿过壁纸，两端在几何上没有任何差别。
- 忽略黑色后最小周期瓦片唯一；隧道两个端点中恰有一个端点的相位对应巢穴色。

规则：
- 忽略黑色，推断最小周期瓦片。
- 将隧道全部黑格按各自相位恢复为壁纸颜色。
- 找出两个隧道端点中修复后颜色为巢穴色的那一个，把该格改放灰色像素。

关键洞察：
- 画面里从未画出啃食者，只有它的残迹；隧道两端在输入里无法区分，
  选端的依据只存在于修复之后——必须先完成周期修复，才能知道哪一端落在巢穴相位上。
  黑格既是要补的缺失，也是通向巢穴的路径，两条子规则首尾咬合。
```

## 5. 点火连锁

- 参考题目题号: 15、7、12
- tags:
  - operation:十字擦除, cross_erasure
  - operation:连锁传播, chain_propagation
  - object:标记块, marker_block
  - object:点火标记, ignition_marker
  - object:保护像素, protected_pixel
  - object:噪声背景, noisy_background
  - relation:接触点燃, contact_ignition
  - condition:射线遇红停止, ray_stops_at_red
  - condition:迭代至稳定, iterate_to_fixpoint

### docstring

```text
从带点火标记的黑块开始，让宽 2 的十字擦除带在红色防火像素间连锁点燃其他黑块，烧不到的黑块保持沉默。

输入结构：
- 网格填满多色杂噪，其中散布若干 2x2 纯黑块。
- 若干红色像素散布其间，充当防火格。
- 恰有一个黄色像素与某个黑块 4 邻接，作为点火标记。

规则：
- 点燃与黄色标记邻接的初始黑块。
- 被点燃的块沿它占据的两行向左右、沿它占据的两列向上下推进宽 2 的擦除带；
  带逐步推进，遇到下一步 2 格中含红色即在该方向停止，到网格边缘也停止。
- 带扫过的格全部变黑；带覆盖到某个未点燃黑块的任一格时，该块被点燃并同样发射擦除带。
- 重复直到不再有新块被点燃。
- 输出中黄色标记被擦黑，未点燃的黑块保持原样，未被扫过的杂噪与全部红像素不变。

关键洞察：
- 擦除不是一次性的十字，而是被红像素截断、经由黑块接力的连锁传播；
  哪些黑块会引爆取决于防火像素围出的可达性，而不是与起点的距离远近。
```

### docstring

```text
用成对精灵相减得到的亏形为模板里的每个孔洞配色。

输入结构：
- 背景上有一个大的单色模板框，其内部有若干背景色孔洞。
- 框外散落若干精灵，同色精灵恰好成对。
- 每对中一个是完整图形，另一个是去掉了部分格子的残缺副本，
  残缺副本作为子形在完整图形中的平移对齐唯一。

规则：
- 对每对同色精灵，按唯一平移对齐求出缺失掩码：完整图形有而残缺副本无的格集合。
- 每个孔洞的形状与恰好一对精灵的缺失掩码在允许旋转、翻转下全等。
- 裁出模板框的包围盒并全部涂为框色，再把每个孔洞按其匹配对的颜色填充。

关键洞察：
- 孔洞的钥匙从未直接画在场上——它是每对精灵相减后的亏形；
  拿完整精灵或残缺精灵直接与孔比对都不会成功，参与匹配的形状只能被"算"出来。
```

## 7. 格阵里的壁纸

- 参考题目题号: 14、20、16
- tags:

  - operation:间隙填充, gap_filling

  - relation:包围盒行列分组, bbox_row_column_grouping

  - condition:最小尺寸过滤, minimum_size_filtering

### docstring

```text
把矩形格阵压缩成小色表，再用色表自身的周期补全格阵中缺失的矩形颜色。

输入结构：
- 带杂色干扰的背景上，若干边长至少 3 的实心单色矩形排成行列格阵。
- 同一行的矩形竖直包围盒区间重叠、同一列的水平包围盒区间重叠。
- 格阵中部分交叉位置没有矩形。
- 把现有矩形压缩得到的色表是某个更小瓦片的周期平铺，
  且该周期唯一决定所有缺失单元的颜色。

规则：
- 过滤掉不成实心大矩形的干扰像素。
- 按包围盒区间分组得到表的行与列，将每个矩形的颜色写入对应单元。
- 对空缺单元，用整张表的最小周期推断出其颜色。
- 输出补全后的色表。

关键洞察：
- 压缩得到的小表不是终点——它本身是一张残缺的壁纸；
  缺失矩形的颜色在大网格里根本不存在，只能从表这一层的周期读出，
  两级结构各藏一半答案。
```

## 8. 层叠沙漏

- 参考题目题号: 12、7、1
- tags:
  - operation:重力下落, gravity_drop
  - object:容器, container
  - object:盖子, lid
  - object:内容像素, content_pixel
  - relation:容器壁阻挡, wall_blocking
  - relation:跨容器传递, cross_container_cascade
  - condition:逐列独立下落, per_column_fall
  - condition:封口不落, sealed_stays

### docstring

```text
未封口容器里的内容像沙粒一样逐列坠落，穿过开口、落上别人的盖子或落进下方的容器，封口容器连同悬空的内容原样保持。

输入结构：
- 背景上有多个 U 形单色框容器，开口朝向各异（上、下、左均有），在竖直方向上彼此错落。
- 部分容器的开口处被第三种颜色的直线盖子封住。
- 容器内部装有若干彩色内容像素，有的悬在容器中部。

规则：
- 封口容器的内容完全不动，即使开口朝下、内容悬空。
- 未封口容器的每个内容像素按所在列独立竖直下落；
  容器壁、所有盖子、网格底边与已落定的像素都是障碍，同列像素保持原有相对上下顺序。
- 从开口朝下的容器漏出的像素继续下落，可能落进下方开口朝上的容器内、
  落在某个盖子上或落到网格底部。
- 容器框与盖子本身不动。

关键洞察：
- 开口方向不对应任何"流出方向"的映射——一切内容只服从同一竖直重力；
  盖子既是自家的封条也是别人的地板，哪些沙会动、最终落在哪里，
  完全由墙与洞的几何决定，而不是由容器的朝向查表决定。
```
