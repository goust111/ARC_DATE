## 1. 弹射巡游染色

- tags:
  - operation:射线延伸, ray_extend
  - operation:填充, fill
  - object:空心矩形, hollow_rect
  - object:方向帽, direction_cap
  - object:颜色条图例, color_bar_legend
  - relation:访问顺序映射色, visit_order_maps_color
  - condition:路径不可见, path_never_drawn
- 参考题目题号: 4e469f39, 694f12f3, 880c1354, bdad9b1f

### docstring

```text
按一条从未画出的对角弹射光路的访问顺序，用图例颜色依次填充被撞到的灰色空心矩形的内部。

输入结构：
- 黑色背景网格上散布若干一格厚、内部为背景的灰色空心矩形。
- 有一个发射器：一个彩色像素，其对角相邻处有一个同色帽像素，帽相对发射
  像素的方位给出发射的对角方向。
- 网格左边缘有一列自上而下排列的颜色条图例，颜色互不相同，数量不少于
  矩形个数。

规则：
- 从发射器沿帽指示的对角方向发出一条不可见光束。
- 光束撞到灰色矩形的水平边时竖直分量取反，撞到竖直边时水平分量取反，
  继续沿新的对角方向前进；到达网格边缘即终止。
- 按光束撞击矩形的先后顺序，把第 k 个被撞到的矩形的内部整体填成图例
  自上而下的第 k 种颜色；同一矩形只在首次被撞到时计数。
- 从未被撞到的矩形保持空心；光路本身不画出；发射器、帽、图例保持不变。

关键洞察：
- 灰色矩形身兼两职：既是改变光路的反射镜，又是被染色的目标；染色顺序
  由这条在输出中完全不可见的弹射路径决定，图例只提供颜色的次序表。
```

## 2. 周期折叠缺陷

- tags:
  - operation:平铺, tiling
  - operation:压缩, compress
  - operation:叠加, overlay
  - object:种子瓦片, seed_tile
  - object:重复图案, repeating_pattern
  - object:缺陷像素, defect_pixel
  - relation:模周期坐标, coordinates_modulo_period
  - condition:缺陷随折叠汇入, defects_fold_into_tile
- 参考题目题号: d10ecb37, 0a938d79, e2092e0c

### docstring

```text
把整幅周期平铺图按其周期折叠成一块基本瓦片，散布的缺陷像素随折叠落位后叠印在瓦片上。

输入结构：
- 网格由一个小尺寸种子瓦片沿行列两个方向严格周期地重复铺满。
- 少量像素被改成了既不属于瓦片配色的其他颜色（缺陷），缺陷散布在
  全图各处；周期本身未在图中标注。
- 任意两个缺陷对周期取模后不落在瓦片的同一格。

规则：
- 从重复结构中推断出平铺的行周期与列周期，确定基本瓦片的图案。
- 输出一块与基本瓦片同尺寸的网格，先按无缺陷的正确瓦片图案绘制。
- 把每个缺陷的行列坐标分别对行周期、列周期取模，得到它在瓦片内的
  折叠位置，用该缺陷自己的颜色覆盖输出中对应的格子。

关键洞察：
- 这不是"提取种子并忽略噪声"：缺陷不是噪声，周期图案是它们共用的
  坐标系；把全图沿周期折叠后，所有缺陷都会汇入同一块瓦片并保留下来。
```

## 3. 隐藏对齐取异

- tags:
  - operation:逻辑运算, logical_op
  - operation:镜像, mirror
  - operation:模式匹配, pattern_match
  - object:二值掩模, binary_mask
  - object:分隔条, separator_bar
  - relation:逐像素对应, pixelwise_correspond
  - relation:最优对齐唯一, unique_best_alignment
  - condition:对齐变换从未标注, alignment_never_marked
- 参考题目题号: 1b2d62fb, 7ed72f31, e2092e0c

### docstring

```text
找出使两块掩模几乎重合的那个从未被标注的刚体变换，对齐后输出仍然对不上的少数格子。

输入结构：
- 一条蓝色分隔条把画布分成两块同尺寸的栗色/黑色二值掩模，栗色为激活格。
- 第二块掩模是第一块经过八种刚体变换（恒等、旋转 90/180/270 度、四种
  翻转）中的某一种之后，再改动了少数几个格子得到的；画面上没有任何
  标记指明用了哪种变换。
- 在全部八种变换中，恰有一种使两块掩模的不一致格数严格最少。

规则：
- 对第一块掩模逐一尝试八种刚体变换，与第二块逐格比较，找出不一致格数
  唯一最少的那种变换。
- 以第二块掩模的坐标系输出一幅同尺寸网格：对齐后两侧仍不一致的格子
  输出青色，其余格子输出黑色。

关键洞察：
- 直接按画面位置逐格比较是诱饵——某个训练示例里恒等对齐看似也能给出
  一幅差异图，但规则在全部示例上只对"最佳对齐后的残差"成立；真正的
  对齐变换从未被画出，只能从"几乎重合"中反推出来。
```

## 4. 连线成腔，腔间轮色

- tags:
  - operation:连线, connect
  - operation:洪泛填充, flood_fill
  - operation:循环轮换, cyclic_shift
  - object:标记像素, marker_pixel
  - object:封闭区域, enclosed_region
  - object:控制像素, control_pixel
  - relation:同行列对齐, row_col_aligned
  - relation:面积比较, area_comparison
  - condition:轮换对象由连线涌现, shifted_objects_emerge_from_connect
- 参考题目题号: dbc1a6ce, 880c1354, 445eab21, 694f12f3

### docstring

```text
先把对齐的蓝色标记连线围出封闭腔，再把每个腔染成面积序上前一个腔内彩点的颜色。

输入结构：
- 黑色背景网格上散布蓝色标记像素，若干标记彼此同行或同列。
- 另有若干互不同色的彩色单像素（既非蓝也非黑）散布在网格各处。

规则：
- 第一阶段：每一行内把蓝色标记按列排序，相邻标记之间的背景格画成
  蓝色；每一列内同理；蓝色标记本身保留。
- 连线后的蓝色网络把背景分割成若干 4 连通区域；不接触网格边缘的区域
  为封闭腔，每个封闭腔内恰含一个彩色单像素；落在开放区域里的彩点是
  干扰，原样保留、不参与后续规则。
- 第二阶段：把各封闭腔按面积从小到大排成循环序；每个腔的全部背景格
  染成该循环序中前一个腔（最小腔取最大腔）里彩点的颜色，各腔内原有
  彩点保留在原位。

关键洞察：
- 被轮换染色的对象在输入里从未被画出——它们是连线之后才涌现的腔体；
  且每个腔得到的不是自己彩点的颜色，而是沿面积循环序错一位的颜色，
  只看单个腔与其内点的对应关系必然对不上全部示例。
```

## 5. 蛇形程序拼链

- tags:
  - operation:滑动, sliding
  - operation:拼接, concatenation
  - operation:排序, sort
  - object:程序色块, program_block
  - object:路径片段, path_segment
  - object:端点, endpoint
  - relation:蛇形读序, boustrophedon_read_order
  - condition:读出序列定拼接次序, decoded_sequence_orders_chain
- 参考题目题号: d017b73f, cdecee7f, c64f1187

### docstring

```text
按角落色块以蛇形读出的颜色序列规定的次序，把散布的彩色路径片段端点对端点拼成一条链。

输入结构：
- 网格一角有一个实心小色块（程序块），其格色互不相同。
- 其余区域散布着与程序块颜色一一对应的单色路径状片段，每个片段在其
  最左列和最右列各有唯一一个度为 1 的端点像素。
- 片段在画面上的摆放次序与程序块无关。

规则：
- 按蛇形次序读程序块：第 0 行从左到右，第 1 行从右到左，逐行交替，
  得到一个颜色序列。
- 按该序列的先后取出对应颜色的片段：第一个片段保持其原有竖直位置放在
  输出最左侧；此后每个片段整体竖直平移（不旋转、不改色），使其左端点
  与前一片段右端点同行，并紧贴其右侧粘放。
- 输出仅为拼好的紧凑链条；程序块不进入输出。

关键洞察：
- 任何摆放次序都能让片段竖直滑动后首尾相接，所以拼接次序无法从几何
  上推出；角落色块不是图案而是一段程序，蛇形读出的颜色序列才是链条
  唯一合法的装配顺序。
```

## 6. 绕隐形质心的角序条码

- tags:
  - operation:排序, sort
  - operation:计数, counting
  - operation:压缩, compress
  - object:散布物体, scattered_object
  - object:控制标记点, control_marker
  - relation:环绕角度排序, angular_order_around_center
  - relation:计数编码长度, count_encodes_length
  - condition:标记定起点与方向, marker_sets_start_and_direction
- 参考题目题号: 880c1354, d631b094, a1aa0c1e, cdecee7f

### docstring

```text
把散布的彩色物体按绕全体质心的角序排成条形码：每行一个物体，行内长度为其像素数，起点与转向由灰色标记给出。

输入结构：
- 黑色背景上散布若干互不相同颜色的单色小物体，像素数各不相同。
- 恰有一个灰色单像素，与某一物体相邻；画面上没有画出任何中心结构。

规则：
- 以全部彩色物体像素的公共质心为中心（该中心从未被画出），计算每个
  物体质心相对它的方位角。
- 与灰色像素相邻的物体为起点；灰色像素相对该物体偏向哪一侧，环绕
  次序就朝那一侧的相邻物体推进（由此定出顺时针或逆时针）。
- 输出网格高为物体个数，宽为最大像素数：第 i 行从左端起连续填入按上述
  环绕次序排第 i 位的物体的颜色，长度等于该物体的像素数，其余格为黑。

关键洞察：
- 行序既不是阅读顺序也不是大小顺序，而是绕一个从未画出的公共质心的
  角序；灰色标记一点两用——它贴着谁谁就是起点，它偏向哪侧就朝哪侧转。
```
