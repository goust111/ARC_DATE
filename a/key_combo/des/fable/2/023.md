## 1. 穿墙计深调色渗透

- tags:
  - operation:射线延伸, ray_extend
  - operation:分支, branch
  - object:色板行, palette_row
  - object:分隔行, separator_row
  - object:边缘标记, edge_marker
  - object:墙段, wall_segment
  - relation:深度索引配色, depth_indexed_palette
  - condition:墙段开口分支, branch_at_opening
  - condition:空码位跳过涂色, blank_code_skips_paint
- 参考题目题号: 5 (f9a67cb5)、1 (9356391f)
- 难度评审档位: 达标偏上

### docstring

```text
将边缘标记向内渗透，每穿过一道断墙就换用码行中的下一个颜色涂画。

输入结构：
- 网格顶部第一行为码行，其下一行为满宽分隔行，分隔行以下为场地。
- 场地背景占多数，含若干条与分隔行平行的满宽断墙行（墙色一致，
  行内留有背景缺口），以及底边上的一个单格标记；标记颜色等于码行
  第一个有效码位的颜色。
- 码行从左端起到最后一个非背景格为有效码段，码段内部可含背景格，
  有效码位个数恰为墙行数加一。

规则：
- 保持码行、分隔行与所有墙格不变，从标记出发向内画渗透轨迹。
- 标记沿所在列向内直行，轨迹经过的空格涂当前深度的码色，起始深度
  为 0（涂第一个码位的颜色）。
- 当直行的下一格是墙时，沿该连续墙段的近侧向两边延伸涂色，直到
  墙段两端为止；墙段两端相邻的缺口格涂下一深度的码色，并从每个
  界内缺口继续向内直行，深度加一。
- 某深度的码位若为背景色，该深度的轨迹格保持背景不落色，但推进
  与分支照常进行。

关键洞察：
- 码行不是场地的一部分，而是按"已穿过的墙数"索引的调色板：渗透
  轨迹的形状由分支遍历决定，颜色却由拓扑深度决定，两者缺一不可，
  这既不是普通洪水填充，也不是几何距离配色。
```

## 2. 叠牌层序循环借色

- tags:
  - operation:填充, fill
  - object:竖向色带, vertical_band
  - object:叠牌指示, stack_indicator
  - relation:遮挡层序, occlusion_order
  - relation:循环相邻, cyclic_adjacent
  - condition:空缺借层序邻色, gap_borrows_stack_neighbor
  - condition:忽略空间顺序, ignore_spatial_order
- 参考题目题号: 9 (c4d1a9ae)、14 (652646ff)、19 (264363fd)
- 难度评审档位: 达标

### docstring

```text
按角落叠牌显示的层序（而非左右位置）循环借色，填补每条竖向色带的缺口。

输入结构：
- 背景为占比最高的颜色；场上若干条互不重叠的竖向色带，每条一种
  颜色，带内混有背景缺口。
- 某个角落有一叠部分重叠的实心小方块，颜色与各色带一一对应；
  相邻方块的遮挡关系给出一条自上而下的完整层序。

规则：
- 读出叠牌的层序：谁压住谁，谁就在上层，由此得到全部颜色从顶层
  到底层的排列。
- 每条色带的缺口格，填入层序中紧邻其上一层那条色带的颜色；最顶层
  的色带借用最底层的颜色（循环）。
- 已有的前景像素、带外背景与角落叠牌全部保持不变。
- 第一个训练示例中层序恰与左右空间顺序一致，构成诱饵。

关键洞察：
- 色带在画面上的左右顺序是诱饵；真正的"相邻"由角落小叠牌的遮挡
  层序定义，缺口借的是层序上邻而非空间右邻——指示对象用遮挡关系
  给一组空间对象重新编号。
```

## 3. 无争议方块票数定图层

- tags:
  - operation:透明叠加, transparent_overlay
  - operation:计数, counting
  - object:等尺寸面板, equal_panel
  - object:完整方块, full_square_block
  - relation:图层优先级, layer_priority
  - relation:跨面板争议, cross_panel_contest
  - condition:无争议方块计票, uncontested_square_votes
  - condition:票数定层序, vote_orders_layers
- 参考题目题号: 11 (6a11f6da)、15 (3b4c2228)
- 难度评审档位: 达标

### docstring

```text
把三块等尺寸面板透明叠加成一块，"无争议"的完整 2×2 方块越多的面板越后画（越在上层）。

输入结构：
- 输入由三块等高等宽的面板竖直排列组成，面板之间由满宽分隔线隔开。
- 每块面板只用一种前景色，含若干个 4 连通对象：一部分是实心 2×2
  方块，其余是单像素或小碎形。

规则：
- 一块面板中的某个完整 2×2 方块，只有当其 4 个格位在另外两块面板
  的对应位置上全部是背景时，才算一张有效"选票"；被任一其他面板的
  前景压到任何一角的方块无投票权。
- 统计每块面板的有效票数（三块面板的票数两两不同）。
- 以票数从少到多的顺序，依次把整块面板的全部前景像素叠画到同一块
  输出面板上，后画者覆盖先画者；输出即叠加后的单面板。
- 第一个训练示例中恰好底部面板票数最多，看似"底层最优先"，构成诱饵。

关键洞察：
- 票数无法在单块面板内独立数出：必须先把三块面板对齐比对、剔除
  被争议的方块，才能得到票数；而票数又反过来决定叠加时谁覆盖谁。
  直接数每块面板的全部方块，在部分示例中会给出错误层序。
```

## 4. 幽灵矩形归属判定

- tags:
  - operation:重涂色, recolor
  - operation:补全, reconstruct
  - operation:擦除, erase
  - object:空心矩形, hollow_rectangle
  - object:遮挡碎片, occluded_fragment
  - object:标记像素, marker_pixel
  - relation:重建后包含, containment_after_reconstruction
  - relation:嵌套层次, nesting_hierarchy
  - condition:可见像素定边框, visible_defines_bbox
  - condition:最内层归属, innermost_owner
  - condition:框外标记擦除, outside_markers_erased
- 参考题目题号: 14 (652646ff)、16 (c658a4bd)、10 (a04b2602)
- 难度评审档位: 达标偏上

### docstring

```text
把每个标记像素改成真正含着它的最内层矩形框的颜色，框的完整轮廓需先从可见碎片复原。

输入结构：
- 背景为占比最高的颜色；若干个颜色互不相同的空心矩形框互相重叠或
  嵌套，上层框会遮住下层框的部分边框。
- 每个框在每条轴向上的极值像素均可见，因此其全部可见像素的边界框
  就是完整矩形。
- 另有一种专用标记色的散布单像素，有的落在某些框的真实内部，有的
  落在所有框之外。

规则：
- 对每种框色，用其全部可见像素的边界框复原完整矩形轮廓；复原结果
  不画出。
- 对每个标记像素，找出所有复原后内部严格包含它的矩形，取其中面积
  最小者，把该标记重涂为那个框的颜色。
- 不被任何复原矩形内部包含的标记直接擦除为背景。
- 所有框保持输入原样，缺口不修补。
- 存在这样的标记：因局部边框被遮挡，看似在框外，实则在真实内部。

关键洞察：
- 包含关系要对"从未完整出现在画面上的矩形"判定：可见碎片只是完整
  矩形的投影，被遮挡的那段边框虽然不可见，却照样圈住标记。
```

## 5. 多层筛网连锁下落

- tags:
  - operation:投射, project
  - operation:擦除, erase
  - operation:补全, repair
  - object:引导条, guide_bar
  - object:散布像素, scattered_pixel
  - relation:逐层筛落, cascade_sieve
  - relation:次序决定结果, order_determines_outcome
  - condition:单格缺口堵塞, single_gap_plugged
  - condition:宽缺口穿过, wide_gap_passes
  - condition:穿过全部则消失, erased_if_through_all
- 参考题目题号: 20 (f83cb3f6)、17 (1190bc91)
- 难度评审档位: 达标

### docstring

```text
让散布像素逐层下落穿过多道破损横条：单格缺口被第一个到达的像素堵死，宽缺口放行，落定者染成所在横条的颜色。

输入结构：
- 背景为占比最高的颜色；若干条互相平行、颜色互不相同的单格厚横向
  引导条自上而下排列，条上留有缺口，缺口宽度为一格或多格。
- 引导条上方散布着同一种颜色的源像素；同一列中可以有多个源像素。

规则：
- 源像素按离条堆由近到远的顺序，逐个沿自身所在列竖直下落。
- 下落遇到某条时：该列处若是条上实格，则停在实格正上方，并把自己
  染成这条的颜色；若是宽度大于一格的缺口，则穿过并继续向下一条
  下落；若是恰好一格宽的缺口，则钻入缺口把它堵上——该像素染成
  这条的颜色并成为条的一部分。
- 缺口一旦被堵，同列后续像素按实格处理；已落定的像素同样视作
  障碍，后落者叠在其上。
- 穿过全部引导条仍未落定的像素坠出网格，从画面中消失。
- 输出中源像素的原位置全部恢复为背景。

关键洞察：
- 这不是一次静态投影：先落的像素会改写筛网本身（堵住单格缺口），
  后落像素面对的是被前者修补过的条，最终落点由"缺口宽度 + 下落
  次序"的连锁反应共同决定。
```

## 6. 停泊后的绿色航道

- tags:
  - operation:平移, translate
  - operation:排序, sort
  - operation:重涂色, recolor
  - object:边框方块, bordered_square
  - object:走廊, corridor
  - object:障碍块, obstacle_block
  - relation:颜色决定目标, color_determines_destination
  - relation:对向连通, facing_connect
  - condition:行重叠内移, row_overlap_shifts_inward
  - condition:无阻挡跨段涂色, unobstructed_span_recolored
- 参考题目题号: 3 (b5ca7ac4)、8 (2bee17df)
- 难度评审档位: 达标

### docstring

```text
把带边框的方块按边框色停泊到左右两侧后，在同时被两侧方块占据且中间畅通的行里涂绿航道。

输入结构：
- 背景为黑色；场上散布若干个 5×5 带边框方块，边框为青色(8)或
  红色(2)，内部另有颜色；方块互不接触，行区间可能彼此重叠。
- 另有若干灰色(5)障碍块散布在中部，远离两侧停泊区，不参与移动。

规则：
- 青框方块移到左缘（列 0），红框方块移到右缘（列 W−5），各自保持
  原行不变。
- 青框按离左缘由近到远、红框按离右缘由近到远的顺序处理；若某方块
  的行区间与已停泊在同侧边缘的方块重叠，则向内退一个方块宽度停放。
- 停泊完成后逐行检查：若该行同时穿过至少一个左侧停泊方块和至少
  一个右侧停泊方块，且两侧最靠中间的方块之间全为背景（无灰色
  障碍），则把这段中间地带涂绿；其余行不动。
- 灰色障碍保持原位。

关键洞察：
- 绿色航道画在"停泊之后"的虚拟港口里：一行是否畅通、通道两端在哪，
  都取决于近边优先与重叠内移的停泊次序，直接看输入的方块位置得不到
  答案——先要在脑中把船停好，才知道哪条水道通航。
```

## 7. 双帧推演

- tags:
  - operation:同心层填充, concentric_fill
  - operation:帧间推演, extrapolate_next_frame
  - object:等尺寸面板, equal_panel
  - object:种子像素, seed_pixel
  - relation:时序而非图层, temporal_not_layer
  - condition:只长背景格, grow_on_bg_only
  - condition:冲突格留空, conflict_stays_bg
- 参考题目题号: 1 (9356391f)、11 (6a11f6da)
- 难度评审档位: 达标

### docstring

```text
输入的两块并排面板不是待叠加的图层，而是同一场景的前后两帧；推演并输出第三帧。

输入结构：
- 输入由两块等尺寸面板左右并排组成，中间以满高分隔线隔开。
- 两块面板背景相同，各含数个同位置的彩色种子像素及其周围的同色
  图案：左面板为时刻 T 的画面，右面板为时刻 T+1 的画面。
- 每个种子每一步向外长出一圈自己颜色的同心方环（切比雪夫距离等于
  步数的那一圈）；生长只覆盖背景格；同一步中被两个不同生长同时
  抢占的格子保持背景（干涉留空）；出界部分裁剪。

规则：
- 从两帧的差异中识别上述生长规则，包括只长背景格、双方抢占则留空、
  出界裁剪。
- 在右面板画面的基础上再推演一步，输出时刻 T+2 的单块面板。

关键洞察：
- 最强的诱饵是把两块面板当作透明叠加或找不同的静态任务；实际上
  它们是时间序列的相邻两帧，答案是一帧从未在输入中出现过的画面——
  必须先从帧差里反推出带干涉的生长动力学，再向前外推一步。
```
