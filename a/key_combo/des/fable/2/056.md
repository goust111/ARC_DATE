## 1. 几重门

- 参考题目题号: e69241bd, dbff022c, 941d9a10, 45a5af55
- tags:
  - operation:填充, fill
  - operation:计数, counting
  - object:墙壁, wall
  - object:封闭区域, enclosed_region
  - object:门洞缺口, door_gap
  - object:色条图例, stripe_legend
  - relation:拓扑连通深度, topological_depth
  - condition:穿门数查表定色, escape_depth_lookup

### docstring

```text
给每个房间染色，颜色由"从这个房间走到室外最少要穿过几扇门"查右缘图例柱得到。

输入结构：
- 背景上由同一墙色砌成的建筑，被墙分割成若干房间；房间之间、房间与室外
  之间仅通过墙上的单格缺口（门）连通；房间可以嵌套或并排毗邻。
- 网格右缘有一根图例柱，自底向上堆叠若干互异颜色的单元格。

规则：
- 对每个房间，求从室内走到室外背景所需穿过的最少门数 k（穿过一扇门算
  一步，途中可借道其他房间）。
- 将该房间内部整体填充为图例柱自下而上第 k 格的颜色。
- 墙、门洞与图例柱保持不变。

关键洞察：
- 房间的颜色与它自己框上开了几扇门无关，也与嵌套层数不完全一致——真正
  的钥匙是穿门的最短逃逸深度：贴着外墙却没有外门的房间必须绕道邻屋，
  深度反而更大；图例柱是"深度→颜色"的序数查询表。
```

## 2. 认色转身滑动

- 参考题目题号: 17829a00, 6e4f6532, 48f8583b
- tags:
  - operation:滑动, slide
  - operation:旋转, rotate
  - operation:擦除, erase
  - object:边界色条, border_bar
  - object:单色对象, monochrome_object
  - object:标记像素, marker_pixel
  - relation:颜色匹配, color_matching
  - condition:少数色定目的地, minority_color_routes
  - condition:标记位定姿态, marker_position_orients
  - condition:碰撞堆叠, collision_stack

### docstring

```text
每个对象按体内唯一异色像素的颜色选定目标边条，先旋转让该像素朝前、再滑
过去依次堆叠。

输入结构：
- 四条边各有一条满边色条，四色互异；内部为背景。
- 若干互不相连的单色对象，每个对象内贴边处恰有一颗异色像素，其颜色等于
  四条边条之一；对象主体色也可能与某条边条同色。

规则：
- 对象先在 0/90/180/270 度中取最小旋转，使异色像素位于对象沿滑动方向的
  最前一排。
- 再沿垂直于目标边条的方向滑动，贴上边条或先停靠的对象时停止，原位擦除。
- 朝同一边滑动的对象按初始位置距该边由近到远的次序依次滑动。

关键洞察：
- 一颗像素双重编码——它的颜色选目的地、它在对象内的位置定着陆姿态
  （标记面先着地）；主体色与边条同色是幌子；堆叠结果还取决于由初始距离
  隐式给出的先后次序。
```

## 3. 条高即节拍

- 参考题目题号: 45a5af55, 16de56c4
- tags:
  - operation:周期填充, periodic_fill
  - object:色条, color_stripe
  - object:标记像素, marker_pixel
  - relation:条高即周期, height_as_period
  - condition:同余对齐, modular_alignment
  - condition:接力换色, relay_recolor

### docstring

```text
左缘每段色条在自己覆盖的行带内，以自身高度为周期向右打点，遇到落在节拍
上的彩点则由其接力换色。

输入结构：
- 网格最左一列由若干段竖直色条自上而下拼满，各段颜色互异、高度不一。
- 其余区域为背景，散布少量单格彩点，每行至多一个。

规则：
- 高度为 h 的色条负责它覆盖的每一行：在该行距左缘列 h、2h、3h……的格子
  染上条色，直到右缘。
- 若某行的彩点恰好位于节拍格上，该点保留原色，其右侧的后续节拍全部改用
  该点的颜色继续。
- 不在节拍格上的彩点保持不变，节拍照常越过它延伸。

关键洞察：
- 周期不由点与点的间距给出，而由条自身的高度给出——同一个数字既是行带
  宽又是节拍步长；踩上节拍的点是接力棒，踩空的点只是路人。
```

## 4. 镜中搬运

- 参考题目题号: 2f0c5170, 62c24649, 6e4f6532
- tags:
  - operation:镜像, mirror
  - operation:平移粘贴, translate_and_paste
  - operation:掩码裁剪, mask_crop
  - object:精灵窗口, sprite_window
  - object:空白窗口, empty_window
  - object:共享标记点, shared_marker_pixel
  - relation:位移定轴, displacement_sets_axis
  - condition:标记为锚亦为轴, marker_as_anchor_and_axis

### docstring

```text
把精灵窗中的图案以共享标记为轴、按两窗相对方位翻转后，对齐标记粘贴进
空窗。

输入结构：
- 外背景上有两个等大的实心矩形窗口，各含一个相同颜色的标记像素。
- 一个窗口内还有由若干非底色像素组成的精灵，另一个窗口除标记外空无一物。
- 两窗的水平偏移与垂直偏移不相等。

规则：
- 输出裁剪为空窗大小，底色取空窗底色。
- 若空窗相对精灵窗的偏移以水平为主，精灵先以标记所在列为轴左右镜像；
  以垂直为主则以标记所在行为轴上下镜像。
- 镜像后平移精灵，使两个标记重合，粘贴所有非底色像素，标记像素保留。

关键洞察：
- 标记身兼两职：既是对齐的锚点，又是翻转的轴；翻转方向不写在画面里，
  而藏在两窗的相对方位中——像隔着一面镜子照过去。
```

## 5. 箭头是推手

- 参考题目题号: 689c358e, 17829a00, 6e4f6532
- tags:
  - operation:滑动, slide
  - operation:擦除, erase
  - object:箭头精灵, arrow_sprite
  - object:实心方块, solid_square
  - object:矩形边框, rect_frame
  - relation:朝向对齐, orientation_aligned
  - condition:横杆偏移定方向, crossbar_determines
  - condition:有物推物无物自走, push_or_move
  - condition:串推堆叠, chain_push

### docstring

```text
每支箭头把它指向路径上的所有货物像推箱子一样串推到底，路上无货时才自己
滑到底。

输入结构：
- 一像素矩形外框围住背景；框内有若干六像素 T 形箭头（长 4 的杆加偏向
  尖端一侧的长 3 横杆）与若干实心小方块货物，货物颜色异于箭头。
- 一支箭头指向的直线路径上可有零至多个货物；各箭头的路径互不交叉；
  另有不被任何箭头指中的旁观货物。

规则：
- 由横杆偏置的一端读出箭头指向。
- 路径上有货物时：箭头原地不动，路径上的全部货物沿该方向被串推到底，
  依次紧贴框内侧（或紧贴前一个货物）堆叠，原位擦除。
- 路径上没有货物时：箭头自身沿指向滑到紧贴框内侧，原位擦除。
- 不被指中的货物原地不动。

关键洞察：
- 直觉里飞出去的是箭头，实际动身的是被指中的货物——箭头是推手不是行者，
  且一推推一串；只有扑空的箭头才亲自跑到底。
```

## 6. 数量筑塔

- 参考题目题号: ff28f65a, 45a5af55, c3e719e8
- tags:
  - operation:计数, counting
  - operation:嵌套包裹, nested_wrapping
  - object:精灵体, sprite
  - object:同心正方形层, concentric_square_frame
  - relation:数量映射, count_mapping
  - condition:计数定层序与厚度, count_sets_order_and_thickness

### docstring

```text
数出每种颜色的对象个数，按个数从小到大自内向外筑同心方框，个数兼作边长
与层厚。

输入结构：
- 黑背景上散布若干种颜色的连通对象；同色对象的形状、大小、位置各异
  （大对象可能个数少、小对象个数多）。
- 各颜色的对象个数互不相同。

规则：
- 统计每种颜色的连通对象个数。
- 个数最小的颜色画成中心实心正方形，边长等于该个数。
- 其余颜色按个数升序逐层向外包裹方框，每层厚度等于该颜色的个数。
- 输出为这组同心方框构成的正方形网格。

关键洞察：
- 对象的形状与大小全是烟雾弹，唯一有效的量是"每色有几个"；这个数字身兼
  两职——既排定层序，又决定该层厚度。
```

## 7. 顺藤摸瓜

- 参考题目题号: e9b4f6fc, dbff022c
- tags:
  - operation:裁剪, crop
  - operation:重涂色, recolor
  - object:多色目标对象, multicolor_target
  - object:微型图例, micro_legend
  - relation:颜色替换映射, color_sub_map
  - condition:链式传递替换, cascade_replace

### docstring

```text
裁出大目标，并把图例多米诺串成的替换链一路走到链首，用链首色替换链上
所有颜色。

输入结构：
- 背景上有一个实心矩形多色目标，以及若干游离的双格图例多米诺（水平读
  左新右旧，竖直读上新下旧）。
- 一块多米诺的"旧"色可能是另一块的"新"色，从而串成链，链长可达 3 以上；
  也存在"旧"色不出现在目标中的干扰多米诺。

规则：
- 输出为目标的紧致裁剪。
- 把多米诺按"新←旧"关系串成链；目标中位于某条链上的每种颜色，统一替换
  为该链链首（只当"新"、从不当"旧"）的颜色。
- 不在任何链上的目标颜色保持不变。

关键洞察：
- 图例不是一张平行的一步替换表，而是一条藤——必须顺着"新←旧"关系摸到
  尽头，中间色不会残留在输出里；按一步替换的读法会在长链示例上出错。
```

## 8. 鸡尾酒

- 参考题目题号: 444801d8, 6e4f6532, ff28f65a
- tags:
  - operation:计数, counting
  - operation:填充, fill
  - operation:擦除, erase
  - object:杯状轮廓, cup_outline
  - object:标记像素, marker_pixel
  - relation:数量容量匹配, count_capacity_matching
  - condition:子集和配对, subset_sum_pairing
  - condition:多者沉底分层, majority_sinks_layering

### docstring

```text
把散落的水滴按"两色数量之和恰等于杯容量"两两配对入杯，多的颜色沉底、
少的浮面，逐格灌满。

输入结构：
- 黑背景上有若干开口朝上的同轮廓色杯形，内腔为矩形且容量互不相同、
  内部为空。
- 网格其余地方散布若干种颜色的单格水滴；水滴颜色数恰为杯数的两倍，
  每个杯对应且仅对应一对颜色，其水滴总数之和等于该杯内腔容量，且这一
  整体配对方案是唯一可行的；同杯两色的水滴数不相等。

规则：
- 为每个杯找出总数之和恰等于其容量的那一对颜色。
- 两色一起注入：数量多的颜色先从内腔底行开始逐行、行内从左到右连续
  灌注，灌满其格数后，数量少的颜色紧接着继续灌注直至内腔全满。
- 所有水滴原位擦除，杯的轮廓与其余部分不变。

关键洞察：
- 配对是一道"两两凑整"的子集和谜题——水滴离哪个杯近毫无意义；入杯后的
  层序由数量决定（多者沉底如密度分层），两色交界发生在某一行的中间，
  其位置只能靠逐格计数得到。
```

## 9. 厚框即镜头

- 参考题目题号: e7a25a18, 45a5af55
- tags:
  - operation:像素放大, pixel_upscale
  - operation:裁剪, crop
  - object:矩形边框, rect_frame
  - object:内部图案, interior_pattern
  - relation:厚度定倍率, thickness_sets_scale
  - condition:轴向各自缩放, anisotropic_scale

### docstring

```text
按矩形框左右边厚横向放大、上下边厚纵向放大框内图案，输出放大后的图案
本身。

输入结构：
- 背景上有一个单色矩形框，左右两边厚度相同、上下两边厚度相同，两个厚度
  可以不同。
- 框的内腔里有一个由非背景、非框色像素组成的小图案，位置随意，内腔留有
  富余空白，内腔尺寸与图案尺寸之比不等于放大倍数。

规则：
- 取内腔图案的紧致包围盒。
- 水平方向按左右边厚为倍数、垂直方向按上下边厚为倍数，把图案逐像素放大。
- 输出即放大后的图案网格，不含框与背景留白。

关键洞察：
- 框不是取景器而是镜头：它的边厚按轴向分别编码放大倍数；内腔与图案的
  尺寸比对不上倍率，放大倍数只能从框的厚度里读出。
```
