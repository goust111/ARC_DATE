## 1. 连锁上跳

- 参考题目题号: 10 (5521c0d9)、18 (712bf12e)
- tags:
  - operation:平移, translate
  - operation:连锁反应, chain_reaction
  - object:实心矩形, solid_rectangle
  - object:控制标记, control_marker
  - relation:碰撞传导, collision_propagation
  - condition:移动自身高度, shift_own_height

### docstring

```text
让红色触发矩形向上跳自身高度，被压到的矩形依次连锁上跳各自的高度。

输入结构
- 黑色背景网格上分布若干互不重叠的实心单色矩形。
- 恰有一个矩形为红色（触发者），其余矩形颜色各异。
- 上方空间保证连锁过程中没有矩形越出上边界。

规则
- 红色矩形整体上移，位移量等于它自己的高度。
- 若某个矩形移动后的落点区域与另一矩形重叠，则被压到的矩形也上移自身的高度；
  该判定对每个新移动的矩形继续生效，直至再无重叠。
- 未被任何移动矩形压到的矩形保持原位；所有移动矩形的原位置清为背景。

关键洞察
- 谁移动不由列对齐或距离决定，而由碰撞链的因果传导决定；
  且每个矩形的位移是它自己的高度而非触发者的高度，
  链条上高矮不同的矩形跳得远近不同。
```

## 2. 图例演示变换

- 参考题目题号: 19 (845d6e51)、8 (3c9b0459)、13 (59341089)
- tags:
  - operation:旋转, rotate
  - operation:镜像, mirror
  - object:图例区域, legend_region
  - object:分隔线, divider
  - relation:颜色索引操作, color_indexed_operation
  - condition:图例示范变换, legend_demonstrates_transform

### docstring

```text
图例区里每种颜色用一对"变换前→变换后"图形示范一种几何操作，把该操作施加到同色的查询图形上。

输入结构
- 一条 L 形分隔线从上边缘连到左边缘，围出左上角的图例区。
- 图例区内每种颜色恰有两个同形图形：左边为原样，右边为对其施加某个几何操作
  （旋转 90 度、旋转 180 度、水平镜像、垂直镜像之一）后的结果；
  示范形状不具有任何非平凡对称性，因而示范的操作唯一。
- 图例区外分布若干单色查询图形，颜色都在图例中出现，形状与图例形状无关。

规则
- 对每个查询图形，按其颜色找到图例中的示范对，读出左形到右形所施加的那个操作。
- 在查询图形自身的包围盒内施加同一操作，变换后图形的包围盒左上角与原包围盒左上角对齐。
- 分隔线、图例区和背景保持不变。

关键洞察
- 图例不是"形状查颜色"的字典，而是"颜色查操作"的字典；
  真正的信息藏在每对图形左右两形的差异里，查询图形的形状本身与图例形状无须匹配。
```

## 3. 隐形交汇点

- 参考题目题号: 20 (ae3edfdc)、1 (99fa7670)
- tags:
  - operation:滑动, sliding
  - object:孤立像素, isolated_pixel
  - object:隐形中心, hidden_center
  - relation:行列对齐, row_column_alignment
  - condition:交点从未画出, center_never_drawn
  - condition:压缩到隐形中心, compress_to_hidden_center

### docstring

```text
每种颜色的散点沿各自的行列射线滑拢，聚成一个中心从未画出的空心十字。

输入结构
- 黑色背景上有若干颜色组，每组由同色孤立像素组成，组与组在空间上交错分布。
- 每组存在唯一格 (r,c)：组内每个像素要么在第 r 行、要么在第 c 列；
  且第 r 行、第 c 列上各有至少两个该组像素，格 (r,c) 本身是背景。

规则
- 对每组求出交汇格：组内多点共处的那一行与多点共处的那一列的交点。
- 组内每个像素沿它所在的行或列向交汇格滑动；同一侧的多个像素保持顺序依次紧密排队，
  最靠内的像素紧贴交汇格。
- 交汇格保持背景色不上色；不同颜色组互不干扰。

关键洞察
- 吸引点不是画面上的任何标记，而是"多点共行"与"多点共列"两条隐形直线的交点；
  散点是隐形十字的残迹，输出把残迹压实但中心依旧留空。
```

## 4. 走廊自编码

- 参考题目题号: 3 (5d588b4d)、7 (692cd3b6)
- tags:
  - operation:生成序列, generate_seq
  - operation:路径追踪, path_follow
  - object:走廊路径, corridor_path
  - object:孤立像素, isolated_pixel
  - relation:转角计数, corner_count
  - condition:路径上的递增递减游程, rise_fall_on_path
  - condition:自身几何决定参数, self_geometry_as_control

### docstring

```text
把一条弯折走廊当作一维纸带，用走廊自己的拐角数 n 生成 1..n..1 的游程序列并沿带写入。

输入结构
- 黑色背景上有一条灰色的 4 连通简单路径（走廊），恰有一端接触网格边缘，该端为起点。
- 网格中另有一个孤立的彩色像素，给出书写用的墨水色，它不与走廊相邻。
- 走廊长度保证足以容纳整个序列。

规则
- 数出走廊的拐角格数（路径在该格改变行进方向），记为 n。
- 构造游程长度依次为 1,2,…,n,n-1,…,2,1 的序列，相邻游程之间隔一个格。
- 从起点沿走廊逐格行进：游程格改涂墨水色，间隔格保持灰色；
  序列写完后剩余走廊格保持灰色；孤立像素保留原位。

关键洞察
- 控制值 n 不来自任何色条或标记，而来自走廊自身的弯折数——路径既是纸带又是程序；
  走廊的二维形状对写入内容毫无影响，只有沿带的一维顺序和拐角计数有效。
```

## 5. 残缺搭档修复

- 参考题目题号: 19 (845d6e51)、11 (8ee62060)、16 (5b692c0f)
- tags:
  - operation:形状匹配, shape_matching
  - operation:对称补全, symmetric_completion
  - object:精灵体, sprite
  - object:残迹, residue_fragment
  - relation:同构配对, congruent_pairing
  - condition:旋转反射等价, rotation_reflection_equivalence
  - condition:姿态由残迹反推, pose_inferred_from_residue
  - condition:颜色是干扰项, color_as_distractor

### docstring

```text
每个残缺图形用与它形状同源的完整图形做模板，按残迹自身的摆放姿态补全。

输入结构
- 背景上有偶数个单色图形，按形状两两配对：每对中一个是完整模板，
  另一个是同一形状经过某种旋转或反射后再被抹掉若干像素的残迹。
- 残迹保留的像素足以唯一确定其姿态：在模板的所有旋转反射变体与摆放位置中，
  恰有一种能完全覆盖住残迹的幸存像素。
- 颜色任意：同一对的两个图形颜色可以不同，不同对之间也可能撞色，
  完整与残缺无法靠颜色区分。

规则
- 找出所有"某图形是另一图形某个旋转反射变体的真子集"的配对。
- 对每个残迹，选出唯一能与其幸存像素完全吻合的模板变体及摆放位置，
  在原地补上缺失像素，补充像素涂残迹自身的颜色。
- 模板图形与背景保持不变。

关键洞察
- 谁是模板谁是残迹不看颜色也不看位置，只看形状间的包含关系；
  修复所用的姿态不是模板画出的姿态，而是必须从残迹幸存像素中反推出的那个旋转反射变体。
```

## 6. 门对门

- 参考题目题号: 7 (692cd3b6)、6 (ac3e2b04)、18 (712bf12e)
- tags:
  - operation:重涂色, recolor
  - operation:射线延伸, ray_extend
  - object:门框, doorway_frame
  - object:核心像素, core_pixel
  - object:障碍块, blocker
  - relation:门洞朝向, doorway_orientation
  - condition:双向通视, mutual_visibility
  - condition:遮挡即失效, obstruction_blocks

### docstring

```text
只有门洞正对且通道无遮挡的两个方框才会隔空交换各自的核心颜色。

输入结构
- 背景上有若干灰色矩形空心框，每框恰在一条边上开一个 1 格门洞，
  框内中心各有一个彩色核心像素，颜色互不相同。
- 画面上散布少量灰色单像素障碍。
- 每个门洞至多与一个别的门洞构成正对关系。

规则
- 从每个门洞沿垂直于框壁的方向向外做射线。
- 若两个框的门洞位于同一行或同一列、彼此的射线都恰好射进对方门洞，
  且两洞之间没有任何前景格，则两框正对：把两框的核心像素颜色互换。
- 其余一切保持不变：门洞不对齐、朝向相背、或通道被障碍挡住的框，其核心颜色原样保留。

关键洞察
- 框心是否连线不看框心，而看门洞——两框中心对齐但门开在别侧就毫无交互；
  一颗不起眼的灰色障碍像素落在通道上，就足以掐断整条交换关系。
```
