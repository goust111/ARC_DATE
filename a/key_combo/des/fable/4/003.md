## 1. 错位旋转帧的合成补全

- 参考题目题号: `351d6448`, `11852cab`, `a416fc5b`
- tags:
  - operation:序列外推, sequence_extrapolation
  - operation:旋转, rotate
  - operation:对称补全, symmetry_completion
  - object:面板帧, panel_frame
  - object:分隔行, separator_row
  - object:前景精灵, foreground_sprite
  - relation:旋转配准, rotational_registration
  - condition:跨帧并集复原, cross_frame_union_restores

### docstring

```text
把四帧旋转动画配准合成出完整精灵，并输出它的下一帧。

输入结构
- 网格由整行分隔线分成竖直堆叠的四个等大方形面板，面板背景为共享的左上角颜色。
- 四个面板依次呈现同一个非对称精灵每帧顺时针旋转90度的视图。
- 每一帧都被遮挡掉一部分像素，且各帧缺失的部位互不相同，任何单帧都不是完整精灵。

规则
- 把第k帧逆时针旋转(k-1)×90度，配准回第一帧的方向。
- 对四个配准后的视图取非背景像素的并集，复原完整精灵。
- 输出一个面板大小的网格，内容为完整精灵再顺时针转90度后的第五帧——其方向恰与第一帧相同，因为四帧转满一周。

关键洞察
- 四个面板不是四个不同对象，而是同一对象的四个旋转视图；单帧对称补全或直接复制某帧都失败，只有跨帧配准取并集才能复原，而答案又不等于任何现有帧。
```

## 2. 对称缺口的钥匙归位

- 参考题目题号: `11852cab`, `18447a8d`, `4ff4c9da`
- tags:
  - operation:对称补全, symmetry_completion
  - operation:形状匹配, shape_match
  - operation:重涂色, recolor
  - operation:擦除, erase
  - object:主体图形, main_body
  - object:缺口, gap
  - object:钥匙精灵, key_sprite
  - relation:旋转对称, rotational_symmetry
  - relation:互补形状, complementary_shape
  - condition:旋转后唯一配对, unique_match_after_rotation

### docstring

```text
用散落的彩色钥匙块补全一个旋转对称灰色主体的缺口，并给每个缺口涂上对应钥匙的颜色。

输入结构
- 画面中央有一个大的灰色主体，其完整形态具有绕自身中心的90度旋转对称。
- 主体上有若干处缺口：缺口处被挖成背景，但每个缺口的三个旋转对应位置都完好。
- 画面外围散落若干彩色小精灵（钥匙），每把钥匙的形状等于某个缺口的真实形状在其某个旋转对应方向下的样子。

规则
- 找到主体的旋转中心，利用三个完好的旋转对应位置推出每个缺口的真实形状。
- 把每把钥匙在四种旋转方向下与各缺口形状匹配，找到唯一配对。
- 用钥匙的颜色填充对应缺口，抹去所有外围钥匙；主体其余像素保持灰色。

关键洞察
- 缺口的形状不写在缺口处，而写在它的旋转对应位置上；钥匙只提供颜色与验证，直接拿钥匙对缺口做平移匹配会因方向不符而失败。
```

## 3. 分区缺席色填充与拆墙合并

- 参考题目题号: `e872b94a`, `9565186b`, `ea32f347`
- tags:
  - operation:填充, fill
  - operation:重涂色, recolor
  - operation:擦除, erase
  - object:前景屏障, fg_barrier
  - object:背景区域, bg_region
  - object:彩点, colored_dot
  - relation:跨区域色集互补, cross_region_palette_complement
  - condition:缺席色决定填色, absent_color_fills
  - condition:同色相邻拆屏障, same_fill_removes_barrier

### docstring

```text
用全图色集的缺席色填充每个被屏障隔出的背景区域，填色相同的相邻区域之间拆除屏障。

输入结构
- 单一前景色的屏障把背景分割成若干4连通区域。
- 每个区域内散布若干单像素彩点；全图彩点合起来构成一个公共颜色集合，而每个区域恰好缺少该集合中的一种颜色。

规则
- 汇总整幅图所有彩点的颜色，得到公共颜色集合。
- 对每个区域，找出集合中未在该区域出现的那一种颜色，把该区域的全部背景像素和彩点都涂成这一缺席色。
- 若两个区域填得同一种颜色且只隔一道屏障（存在同时与两区相邻的屏障像素），把这段屏障也改涂成该颜色使两区合并；其余屏障保持不变。

关键洞察
- 每个区域的答案颜色在该区域内一个像素都没出现过——颜色全集必须跨区域汇总才能得到，任何只看单区域内多数色或稀有色的读法都会失败。
```

## 4. 双种子节拍冲印与湮灭

- 参考题目题号: `92e50de0`, `37d3e8b2`, `03560426`
- tags:
  - operation:印章覆盖, stamp_overlay
  - operation:计数, counting
  - object:分隔线, separator_line
  - object:种子图案, seed_motif
  - object:开放单元格, open_cell
  - relation:单元格阵列, cell_array
  - relation:自指周期, self_referential_period
  - condition:像素数即周期, pixel_count_is_period
  - condition:点阵相撞留空, lattice_collision_annihilates

### docstring

```text
两个种子图案各以自身像素数为周期冲印到单元格阵列中，两套周期点阵相撞的单元格互相湮灭留空。

输入结构
- 脚手架色的整行整列分隔线把网格划分成开放单元格阵列，边缘单元格可能被截断。
- 恰有两个开放单元格里各画着一个种子图案，颜色不同、像素数不同（分别为N1、N2），其余单元格为空。

规则
- 分别数出两个图案的像素数N1、N2，并记录各自像素相对所在单元格左上角的偏移。
- 每个图案以自己所在的单元格为原点，凡单元格行号差与列号差都是其像素数整数倍的单元格构成它的接收点阵。
- 若某单元格只落在一个图案的点阵上，就按偏移冲印该图案的副本，在被截断的边缘单元格处裁剪；若同时落在两个点阵上，则该单元格什么都不画，保持空白（两个源格自身除外，源图案保留）；分隔线不变。

关键洞察
- 接收副本的位置不是固定的棋盘奇偶，而是两套以图案自身像素数为周期的点阵——图案既是内容又是节拍；两套节拍的公倍数格互相湮灭，留空的格子不是遗漏而是规则的必然。
```

## 5. 指令带程序与地形咬合

- 参考题目题号: `33b52de3`, `891232d6`, `95755ff2`
- tags:
  - operation:路径绘制, path_drawing
  - operation:射线延伸, ray_extend
  - operation:索引映射, index_mapping
  - object:指令带, instruction_tape
  - object:起点标记, start_marker
  - object:障碍像素, obstacle_pixel
  - relation:颜色编码方向, color_encodes_direction
  - condition:遇阻停止, stop_at_blocker
  - condition:按带序执行, execute_in_tape_order

### docstring

```text
把条状彩色指令带当作程序执行：方向由指令颜色决定，每段长度由场景障碍决定。

输入结构
- 网格顶部有一条与场景隔开的一像素宽彩色指令带，颜色按固定方向码取值（方向码可从训练示例学得，如红=上、蓝=下、绿=左、黄=右）。
- 场景内有一个起点标记像素和若干散布的障碍像素，其余为背景。

规则
- 从起点出发，按指令带从一端到另一端的顺序逐条执行：沿该指令的方向直线前进，直到下一格是障碍或出界为止，把走过的背景格涂成该指令的颜色。
- 一条指令走完后停在原地，接着执行下一条指令；若一开始就被挡住，则该指令走零步。
- 全部指令执行完后，把最终停留格涂成起点标记色；障碍与指令带保持不变。

关键洞察
- 指令带不是场景里的一个对象而是一段程序；转向次序写在带上，每一段能走多远写在场景里——答案由程序与地形咬合决定，缺一不可。
```

## 6. 孔洞数作为区域地址

- 参考题目题号: `37d3e8b2`, `e872b94a`, `e88171ec`
- tags:
  - operation:计数, counting
  - operation:填充, fill
  - operation:擦除, erase
  - object:封闭背景孔洞, enclosed_background_hole
  - object:带孔方块, holed_block
  - object:前景屏障, fg_barrier
  - object:背景区域, bg_region
  - relation:计数即地址, count_as_address
  - condition:阅读顺序编号, reading_order_indexing

### docstring

```text
把每个带孔方块的孔洞数当作地址，把它的颜色填进阅读顺序下对应编号的背景区域。

输入结构
- 屏障色的曲折墙把背景分割成若干4连通区域。
- 画面中散布若干实心彩色方块，每块内部挖有k个封闭的背景孔洞，各块的k互不相同且不超过区域总数。

规则
- 先把所有彩色方块（连同其孔洞）抹成背景，此时按各区域最靠上最靠左像素的阅读顺序给区域编号1、2、3……
- 每个方块的孔洞数k是一个地址：把编号为k的区域的全部背景像素涂成该方块的颜色。
- 没有被任何方块指向的区域保持背景色，屏障保持不变。

关键洞察
- 孔洞数不映射到固定调色板（那是诱饵读法），而是指向阅读顺序编号的区域；颜色随方块走、位置随孔数走，方块所在的区域与它染色的区域通常不同。
```
