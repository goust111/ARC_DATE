## 1. 幻影镜墙反弹

- 参考题目题号：14, 18, 19
- tags:
  - operation:射线延伸, ray_cast
  - operation:反弹, bounce
  - operation:镜像, mirror
  - object:箭头精灵体, arrow_sprite
  - object:墙壁像素, wall_pixel
  - object:分隔线, separator_line
  - relation:对称互补, symmetric_complement
  - condition:隐匿对象显形, hidden_object_materialize

### docstring

```text
让箭头射线在空白半区内飞行，撞上由另一半区镜像暗示的幻影墙时反弹并使其显形。

输入结构：
- 网格中央有一条贯穿全高的灰色分隔列，把画面分成等宽的左右两个半区。
- 右半区散布若干单像素彩色墙点；左半区除一个三像素 L 形箭头外全为背景。
- 左半区在输入中不画任何墙，但按分隔列镜像后，右半区每个墙点在左半区都有唯一对应位置。

规则：
- 以分隔列为对称轴，把右半区每个墙点映射到左半区，得到输入中不可见的幻影墙集合。
- 箭头沿其缺角方向发射对角射线，途经的背景格涂成射线当前颜色（初始为箭头色）。
- 射线正对撞上幻影墙时双轴反转，侧擦时仅翻转被擦到的轴；每次反弹把该幻影墙格以其墙色画出，
  射线随后改用该墙色继续飞行。
- 射线飞出网格或到达分隔列时停止；右半区与分隔列保持不变。

关键洞察：
- 左半区并不空：真正参与反弹的障碍从未被画出，必须用分隔列的镜像对称把右半区的墙
  "翻印"过来，射线路径才能确定；被撞到的幻影墙以显形为证。
```

## 2. 双约束拉丁格

- 参考题目题号：5, 8, 15
- tags:
  - operation:补全, completion
  - object:色表, color_table
  - object:精灵模板, sprite_template
  - object:空白单元, blank_cell
  - relation:行列唯一约束, row_column_uniqueness_constraint
  - condition:拉丁方约束, latin_square_constraint
  - condition:形色正交, shape_color_orthogonal

### docstring

```text
在形状与颜色各自满足行列拉丁约束、且形色组合互不重复的前提下补全空缺单元。

输入结构：
- 网格被单像素黑色间隔线划分为 n×n 个等大单元。
- 每个已填单元含一个小精灵，其形状取自 n 种模板、颜色取自 n 种颜色。
- 若干单元完全空白；已填单元在任何行列中形状不重复、颜色也不重复，
  且没有两个单元的形状颜色组合相同。

规则：
- 保持已填单元不变。
- 为每个空白单元选定唯一的形状与颜色，使每行每列都恰好包含全部 n 种形状各一次、
  全部 n 种颜色各一次，且全网格中每种形状颜色组合至多出现一次。
- 断言约束系统存在唯一补全。

关键洞察：
- 空格由两条互相独立的拉丁约束共同锁定：只按颜色或只按形状推理都会剩下多解，
  必须让两套约束与组合去重条件互相咬合，才能唯一确定每个空白单元。
```

## 3. 缺席面板重建

- 参考题目题号：4, 7, 12
- tags:
  - operation:透明叠加, transparent_overlay
  - operation:因果反演, causal_inversion
  - object:面板, panel
  - object:颜色图例, color_legend
  - object:判决面板, verdict_panel
  - relation:多数表决, majority_vote
  - condition:少数派身份染色, dissenter_identity_color
  - condition:重建未画出对象, reconstruct_unseen

### docstring

```text
从两块在场面板与一块带异议署名的判决面板出发，反推从未画出的第三块面板。

输入结构：
- 网格分为四个区域：面板槽 A、面板槽 B、一个完全空白的面板槽 X 三槽并排，
  各槽上方有一枚身份色像素作图例；下方另有一块与面板同尺寸的彩色判决面板 C。
- A、B 是黑底灰色图案；C 由灰、黑及三种身份色像素构成。
- C 是三块面板 A、B、X 逐格表决的产物：三者一致的格位保留共同取值（灰或黑）；
  恰有一块面板与另两块不同的格位，被涂成该异议面板的身份色。

规则：
- 输出为单块面板大小，内容为面板 X，逐格反推：
- C 为灰或黑：三面板一致，X 取该值。
- C 为 X 的身份色：X 是异议者，取 A、B 共同取值的相反值。
- C 为 A 的身份色：A 是异议者，X 与 B 相同。
- C 为 B 的身份色：B 是异议者，X 与 A 相同。

关键洞察：
- X 从未被画出，画面上只有它投票留下的痕迹；必须先看懂判决面板的生成机制
  （异议者署名表决），再把这套因果整体反演，才能逐格恢复缺席者。
```

## 4. 穿透导流沉降

- 参考题目题号：9, 13, 20
- tags:
  - operation:滑动, sliding
  - operation:擦除, erase
  - object:搁板线段, shelf_segment
  - object:前景像素, foreground_pixel
  - relation:颜色相等判定, color_equality
  - condition:同色穿透, pass_through_same_color
  - condition:异色导流, deflect_on_diff_color

### docstring

```text
让顶部散点下落，同色搁板被穿孔穿透，异色搁板则把它导流到较近的一端继续下落，直至落底。

输入结构：
- 黑色背景上分布若干条水平单行搁板线段，各自单色、纵向彼此错开、互不相触。
- 网格上部散布若干彩色单像素。
- 布局保证：任一像素撞上任一搁板时，落点到搁板两端的距离不相等；
  各像素的折线路径互不干涉；部分像素沿途只遇到同色搁板，其表现与普通重力
  下落到底完全一致，构成诱饵。

规则：
- 每枚散点竖直下落。
- 遇到与自身同色的搁板格：穿透而过，并把该搁板格擦成背景，留下穿孔。
- 遇到与自身异色的搁板格：不停下，沿该搁板表面滑向距离落点较近的一端，
  越过端点后继续竖直下落，重复上述判定。
- 像素到达底行时停止；未被穿过的搁板格保持原样。

关键洞察：
- 这里没有"停在搁板上"这回事：同色是可以打穿的纸、异色是导流的斜面，
  每枚像素都要沿"穿孔—导流—再下落"的折线走到底行；与普通重力一致的
  像素是掩盖判定条件的诱饵，穿孔痕迹则是路径的证据。
```

## 5. 滑窗环谱拼接

- 参考题目题号：3, 9, 12, 17
- tags:
  - operation:补全, completion
  - operation:重涂色, recolor
  - object:同心方框层, concentric_layer
  - object:占位层, placeholder_layer
  - relation:深度排序, depth_order
  - relation:滑窗重叠, sliding_window_overlap
  - condition:隐藏母序列一致, hidden_mother_sequence

### docstring

```text
把每个同心环靶中被灰色占位的一层，恢复成使所有靶的层色序列都成为同一条隐藏母序列
连续子串的唯一颜色。

输入结构：
- 背景上散布若干同心正方形环靶，层数可不同，每层一格厚、逐层单色。
- 每个靶恰有一层被整层涂成灰色占位。
- 存在一条从未在画面中出现的颜色母序列：每个靶补全后由外向内读出的层色序列，
  都是这条母序列的一段连续子串；各靶子串两两存在足够重叠，
  使全部灰层颜色被唯一确定。

规则：
- 把每个靶按层深展开为由外向内的颜色序列，灰层视为未知位。
- 寻找一条母序列与各靶到母序列的对齐方式，使所有已知层颜色同时吻合，
  并断言该对齐系统对每个未知位给出唯一颜色。
- 将每个灰层整层涂成推得的颜色，其余保持不变。

关键洞察：
- 单看任何一个靶，灰层颜色都无法确定；诸靶是同一条从未画出的色谱上的滑动窗口，
  只有把它们相互重叠拼接、重建母序列，缺失的层色才被全局锁定。
```

## 6. 双模板锚定补全

- 参考题目题号：3, 8
- tags:
  - operation:补全, completion
  - operation:平移, translate
  - object:模板精灵体, template_sprite
  - object:碎片, fragment
  - relation:平移对齐, translate_align
  - condition:形状鉴别模板, shape_identifies_template
  - condition:组级消歧, group_level_disambiguation

### docstring

```text
把每种颜色的碎片补全成两个候选模板中唯一能整体覆盖它们的那个模板的平移副本。

输入结构：
- 背景上有两个完整的单色模板，形状不同但边界框同尺寸，颜色互不相同。
- 其余前景颜色各自构成一至多块分离碎片；每种颜色的全部碎片恰好是某一个模板
  某个平移副本的子集。
- 存在这样的颜色：它的单块碎片能分别嵌入两个模板，但该颜色所有碎片合起来
  只与其中一个模板的同一平移副本相容。

规则：
- 对每种碎片颜色，在两个模板的所有平移放置中寻找能同时覆盖该颜色全部碎片像素的
  唯一放置。
- 按该放置把整个模板形状涂成碎片颜色，补全缺失像素。
- 两个完整模板与背景保持不变。

关键洞察：
- 模板边界框同尺寸使尺寸线索失效；单块碎片可能两边都吻合，
  只有把同色碎片作为整体联合锚定，才能鉴别出唯一的模板与放置位置。
```
