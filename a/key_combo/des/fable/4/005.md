## 1. 相位入坞：带缺陷的周期补丁

- tags:
  - operation:平铺, tile
  - operation:旋转, rotate
  - operation:翻转, flip
  - object:周期场, periodic_field
  - object:补丁, patch
  - object:缺陷像素, defect_pixel
  - relation:相位对齐, phase_alignment
  - condition:补丁内容覆盖周期推断, patch_overrides_periodicity
- 参考题目: 484b58aa, 9b30e358, a25697e4, 6aa20dc0

### docstring

```text
把若干携带缺陷的散装补丁经旋转/翻转后按周期相位装回等大的破洞，缺陷像素必须随补丁一起落位。

输入结构
- 网格上半部是一个双色周期场，周期母题不具有任何旋转或镜像对称。
- 周期场中挖有若干个同尺寸的矩形破洞，破洞内为第三种底色。
- 一条整行底色分隔线之下的下半部散放着与破洞同尺寸的矩形补丁；每块补丁的主体
  延续周期场的双色纹理，但其中混有一至数个第四种颜色的缺陷像素。
- 补丁可能相对其目标破洞被旋转或镜像过；不同补丁的缺陷个数可能相同。

规则
- 对每块补丁，尝试旋转与翻转，使其非缺陷部分与某个破洞处的周期相位完全衔接；
  由于母题无对称性，每块补丁恰有一个可行的(破洞, 姿态)组合。
- 按该姿态把补丁嵌入对应破洞，缺陷像素随姿态变换后原样保留在场中。
- 输出只保留修复完成的上半部周期场（分隔线与补丁区不输出）。

关键洞察
- 破洞尺寸全部相同，唯一能区分归属与姿态的是周期相位本身；而缺陷像素又使
  "直接按周期外推填洞"失效——必须先用周期定位补丁，再让补丁内容覆盖周期推断。
```

## 2. 符号图例：净计数决定生长还是剥蚀

- tags:
  - operation:计数, counting
  - operation:膨胀, dilate
  - operation:侵蚀, erode
  - object:矩形块, rectangular_block
  - object:控制像素, control_pixel
  - object:符号图例, sign_legend
  - relation:颜色编码正负, color_encodes_sign
  - condition:净值符号决定方向, net_sign_determines_direction
- 参考题目: 52fd389e, 37ce87bb, 3befdf3e

### docstring

```text
按两种控制色的净计数让每个矩形块向外生长或向内剥蚀，图例给出哪种颜色是正、哪种是负。

输入结构
- 背景上分布若干实心矩形块，颜色各异；每块内部嵌有两种固定控制色的若干像素。
- 背景某处孤立地竖放着一对上下相邻的控制色像素，是全图唯一的双色竖直对，
  作为符号图例：上方颜色计 +1，下方颜色计 -1。
- 每块的净值绝对值都严格小于该块较短边长的一半。

规则
- 对每个矩形块，净值 n = 正色像素数 − 负色像素数。
- n > 0：以块自身颜色向外加画厚度为 n 的整圈边框（膨胀 n 层），块与控制像素不变。
- n < 0：把块最外侧 |n| 圈涂回背景（被剥掉圈层内的控制像素一并消失），核心保留。
- n = 0：该块原样不动。

关键洞察
- 控制像素不是"个数即厚度"的单向编码，而是一对带符号的操作数：净值的符号选择
  生长/剥蚀两种相反操作，数值给出层数；正负号本身要从那对孤立竖直图例里读出。
```

## 3. 修复引信：颜色点名的连锁洪泛

- tags:
  - operation:补全, complete
  - operation:洪泛填充, flood_fill
  - operation:连锁反应, chain_reaction
  - object:破口矩形框, broken_rect_outline
  - object:内部游离像素, inner_stray_pixel
  - relation:填充色点名下一个框, fill_color_names_next_frame
  - condition:修复动作触发填充, repair_triggers_fill
- 参考题目: 60b61512, 00d62c1b, 195c6913

### docstring

```text
补全破口矩形框并洪泛其内腔，填充色若恰等于某个闭合框的框色，就点燃那个框继续洪泛，连锁直到无框可点。

输入结构
- 黑色背景上分布若干一像素粗的矩形框，框色各异且互不相同。
- 少数框的边上缺失少量像素（破口框），其余框本来就完整闭合。
- 每个框内部恰有一个颜色不同于框色的游离像素；框外背景上另散落若干
  与任何框色无关的干扰像素。
- 各框内部像素的颜色与各框框色构成一条无环的点名链：破口框是链头，
  链上不存在分叉，也有闭合框始终不被任何链点到。

规则
- 用框色补齐每个破口框的缺口，并把它的内腔洪泛成其内部游离像素的颜色
  （该像素融入填充）。
- 若刚完成的填充色恰好等于场上某个闭合框的框色，则该框被点燃：同样用它
  内部游离像素的颜色洪泛其内腔，并继续按此规则向下传递。
- 链条走不到的闭合框保持原样，其内部像素保留；框外干扰像素一律不变。

关键洞察
- 洪泛不是"封闭且含像素"的静态性质，而是一条由修复动作点火、靠"填充色等于
  框色"逐环点名的引信；判断某个闭合框填不填，必须把整条因果链追到它面前，
  而不是就地看它自己的样子。
```

```text
从每个双色指针沿其指向画线汇聚到从未画出的公共枢纽格，并删除唯一指不到枢纽的谎报指针。

输入结构
- 背景上散布若干两格指针：一格是所有指针共有的灰色尾格，另一格是各指针
```

## 5. 碎片拼图与残洞对称补全

### docstring

```text
用相互重叠一致的矩形碎片拼出从未完整出现的模板，再用拼出后才显现的左右镜像对称补上无碎片覆盖的残洞。

输入结构
- 背景上散放三到四块多色矩形碎片，均为同一隐藏模板的轴对齐窗口截图（无旋转）。
- 任意相邻碎片间存在内容完全一致、且在对方内部唯一可定位的重叠区，
  足以把所有碎片链式对齐。
- 对齐后的并集覆盖模板包围盒的绝大部分，但留有少量任何碎片都未覆盖的内部残洞；
  每个残洞的镜像位置均被覆盖。隐藏模板整体左右镜像对称，但任何单个碎片内

- 依据唯一重叠区把碎片平移对齐，取并集得到带残洞的模板雏形。

- 输出即完整模板（输出尺寸等于模板包围盒，与输入尺寸无关）。

关键洞察
- 模板从未被完整画出：先靠重叠一致性把窗口拼回整体，而堵住最后残洞的对称性
```

## 6. 接力偏转的光线

- tags:
  - operation:路径模拟, path_simulation
  - operation:射线延伸, ray_extend
  - object:光源像素, source_pixel
  - object:双格转向器, domino_deflector
  - relation:内部先后编码出射方向, hit_order_encodes_exit
  - condition:颜色是诱饵, color_is_decoy
- 参考题目: 195c6913, 8d510a79, 9344f635

### docstring

```text
从边界光源垂直射入一条光线，每次撞上双格转向器就沿"被击中格指向另一格"的方向接力出射，直到离开网格。

输入结构
- 网格边界上有一个红色光源像素，光线自它垂直于所在边射入网格内部。
- 场内散布若干单色两格多米诺（转向器），颜色各不相同且互不相邻。
- 转向器的摆放保证光线路径有限、不成环，最终从某条边离开。

规则
- 光线直线前进，途经的背景格全部涂红。
- 撞上某转向器的一格 X（另一格为 Y）时，光线改为沿 X→Y 方向从 Y 之后继续前进：
  垂直撞上轴向即拐 90 度，沿轴撞上则穿过后直行。
- 再次撞上其他转向器则继续接力，直到光线离开网格；转向器自身颜色保持不变。

关键洞察
- 出射方向不写在任何颜色或形状记号里，而藏在"先撞到哪一格"这一内部几何顺序中；
  五颜六色的转向器诱导人去找颜色→方向的对照表，其实颜色与规则完全无关。
```

## 7. 藏在误差里的消息：投票只是中间步骤

- tags:
  - operation:多数投票, majority_vote
  - operation:差分, difference
  - operation:掩码汇总, mask_union
  - object:含错精灵, corrupted_sprite
  - object:隐藏模板, hidden_template
  - relation:误差位置构成图形, error_positions_form_shape
  - condition:先共识后差分, consensus_then_diff
- 参考题目: 6aa20dc0, 5289ad53, b74ca5d1

### docstring

```text
对若干污损副本逐格投票重建真模板，再把每个副本偏离模板的格位并集起来，输出这团误差本身拼成的图形。

输入结构
- 背景上整齐散放五个左右同尺寸的多色精灵，均无旋转与镜像，皆为同一隐藏
  模板的污损副本。
- 每个副本有二到四个格被改成杂色（污损色彼此不同、无规律），同一格位在
  全部副本中至多被污损一次，没有任何副本完全干净。
- 全部副本的污损格位互不重复，其并集在精灵坐标系内恰好拼出一个连通图形。

规则
- 将各精灵同位对齐，逐格取多数色，得到真模板（不输出）。
- 把每个精灵与真模板逐格比对，收集所有不一致的格位。
- 输出与单个精灵同尺寸的黑底网格，把上述格位的并集涂成灰色。

关键洞察
- 干净模板既没在输入中出现，也不是答案：它只是用来照出污损的镜子。真正的
  消息写在错误的分布里——必须先靠互相纠错的投票取得共识，再反过来用共识
  给每份证词挑错，误差位置叠在一起才是要画的形状。
```

## 8. 色链追踪：映射要走到底

  - relation:配对色映射, paired_color_mapping
  - condition:映射按链取终点, mapping_follows_chain_to_terminal

### docstring

```text
把图中每个物体的颜色沿"上源下靶"色对图例构成的有向链一路替换到链的终点色。

输入结构
- 背景上散布若干多格单色物体，以及若干竖直相邻的 1×2 双色像素对（图例）。
- 每个图例对表示一条映射：上格颜色 → 下格颜色；全体图例构成无环的有向链，
  一种颜色至多作为一条图例的源。
- 部分物体的颜色是某条链的中间色，部分已是终点色（不再作任何图例的源）。

规则
- 从物体颜色出发，沿图例反复代换：A→B 后若存在 B→C 则继续，直到当前色
  不再是任何图例的源。
- 将该物体整体涂成链的终点色；已是终点色的物体保持不变。
- 图例像素对本身原样保留。

关键洞察
- 图例给出的不是一步到位的查表，而是可以级联的有向边；只代换一步在多跳链的
  示例上必然出错——必须把零散色对读成一张图，并沿链走到不动点。
```
