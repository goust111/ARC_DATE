## 1. 孤影点名

- tags:
  - operation:偏移阴影, offset_shadow
  - operation:对称补全, completion
  - object:精灵体, sprite
  - object:阴影残迹, shadow_residue
  - relation:遮挡, occlusion
  - condition:孤影反推本体, orphan_shadow_inversion
- 参考题目题号: 310f3251, 3345333e, 73ccf9c2

### docstring

```text
一句话总述：
- 找到唯一没有本体遮挡的完整灰影，按全图统一的影子偏移反推并补画缺失的精灵本体。

输入结构：
- 背景色占主导，前景精灵均为同一种颜色，彼此分离。
- 每个精灵都带一个灰色影子：影子是精灵形状按同一固定向量平移后的副本，
  且被后画的本体遮住重叠部分，画面上只剩新月状灰色残迹。
- 恰有一处灰影完整无缺——它对应的本体已被擦成背景。
- 影子偏移向量在不同示例对中不同，需要从画面自行推断。

规则：
- 对任一完好的"本体+残迹"对，求出唯一能使"平移后的本体形状减去本体自身"
  恰好等于灰色残迹的偏移向量。
- 找到不与任何本体相配的完整灰影。
- 把该灰影形状按偏移向量的反方向平移，在该处用前景色补画缺失的本体；
  本体覆盖影子的重叠部分，使该处与其他精灵呈现一致的"本体+残月"结构。
- 其余像素一律保持原样。

关键洞察：
- 灰色新月不是独立图形，而是被本体压住的整形影子；唯一完整的影子暴露了
  缺席者，反向套用全图统一的投影关系即可让它归队。
```

## 2. 看不见的波前

- tags:
  - operation:条纹传播, stripe_propagation
  - operation:填充, fill
  - object:边界线段, border_segment
  - object:隐形波前, invisible_wavefront
  - relation:干涉交点, interference_intersection
  - condition:间距自指线段长, spacing_equals_own_length
  - condition:走廊跨度限制, corridor_span_limit
- 参考题目题号: 221dfab4, 45bbe264, 21f83797

### docstring

```text
一句话总述：
- 两条贴边的彩色线段各自向对边发出一族看不见的等距波前，波前本身不画，
  只有两族波前相遇的格子显形涂红。

输入结构：
- 背景色网格，仅有两个前景对象：左边缘上一段竖直黄色线段（占据若干连续行），
  上边缘上一段水平绿色线段（占据若干连续列）。
- 红色不出现在输入中，网格内部全为背景。
- 网格尺寸保证每个方向至少容纳两道波前。

规则：
- 黄线段向右传播：在与左边缘距离为其自身长度的整数倍的每一列上，
  形成一道只覆盖黄线段行跨度的竖直隐形波前。
- 绿线段向下传播：在与上边缘距离为其自身长度的整数倍的每一行上，
  形成一道只覆盖绿线段列跨度的水平隐形波前。
- 两族波前都不画出；仅当一道竖直波前与一道水平波前相交，且交点同时落在
  黄线段的行跨度和绿线段的列跨度内时，该格涂红。
- 其余一切保持原样。

关键洞察：
- 线段不是要移动或延长的对象，而是波源：波的间距等于线段自身长度（自指），
  两族波前全程隐形，只有干涉相遇点留下痕迹；输出的红点阵是两个看不见的
  周期在各自走廊交叠区里的乘积。
```

## 3. 破缺即精灵

- tags:
  - operation:图案推断, pattern_inference
  - operation:裁剪, crop
  - object:周期平铺图案, periodic_tile
  - object:伪装精灵, camouflaged_sprite
  - relation:破缺构形, deviation_forms_shape
  - condition:调色板内伪装, in_palette_camouflage
- 参考题目题号: abbfd121, 73ccf9c2

### docstring

```text
一句话总述：
- 网格上没有任何肉眼可见的前景对象；先重建严格周期的底布，再把颜色与周期
  预测不符的格子显影成精灵并裁剪输出。

输入结构：
- 整幅网格由一个小尺寸行列周期瓦片平铺而成，瓦片使用两到四种非黑颜色。
- 存在一片四连通区域，其中每个格子的颜色被换成了瓦片调色板中的另一种
  颜色——仍然是背景常见色，肉眼看不出任何前景。
- 异常区域远小于全图，其余像素严格遵守周期，最小周期由守规区域唯一确定。

规则：
- 由占绝大多数的守规像素推断唯一的最小周期瓦片。
- 逐格比对实际颜色与周期应有颜色，不一致的格子构成异常集合。
- 取异常集合的紧致包围盒作为输出画布：异常格保留其当前颜色，
  包围盒内其余格子涂黑。

关键洞察：
- 精灵从未被画出，它只以"违反周期"的方式存在；颜色稀有度和连通团都靠不住，
  唯一的显影剂是先在心里铺回那张看不见的周期底布。
```

## 4. 叛徒指轴

- tags:
  - operation:对称检测, symmetry_detect
  - operation:镜像, mirror
  - operation:擦除, erase
  - object:精灵体, sprite
  - relation:异类定义坐标轴, outlier_defines_axis
  - condition:不对称方向选轴向, asymmetry_direction_selects_axis
- 参考题目题号: 73ccf9c2, c9e6f938, 3345333e, 9bebae7a

### docstring

```text
一句话总述：
- 唯一不自对称的精灵不是要提取的答案，而是全局镜轴的化身：按它缺失的对称
  方向立轴，把其余精灵镜像复制过去，再把它本身抹掉。

输入结构：
- 背景色网格上散布若干互不相触的单色精灵。
- 除一个精灵外，其余精灵各自既左右对称又上下对称。
- 例外精灵恰好在一个方向上不对称（左右不对称而上下对称，或相反），
  且其包围盒在该方向宽度为奇数。
- 所有精灵都不跨越例外精灵的中心行/列，镜像副本保证完整落在网格内
  且互不重叠。

规则：
- 逐个检测精灵的自对称性，找到唯一的例外精灵。
- 若它左右不对称，取其包围盒中心列为竖直镜轴；
  若它上下不对称，取其中心行为水平镜轴。
- 把其余每个精灵关于该轴作镜像，在对侧补画副本，原件保留。
- 把例外精灵擦成背景。

关键洞察：
- 打破对称的对象是坐标系而非内容：它不对称的那个方向指明轴的朝向，
  它的中心线给出轴的位置，用后即焚。
```

## 5. 针孔暗箱

- tags:
  - operation:点对称成像, point_reflection
  - object:空心矩形框, hollow_frame
  - object:针孔缺口, pinhole_gap
  - object:标记像素, marker_pixel
  - relation:框外投影框内, outside_projects_inside
  - condition:缺口为对称中心, gap_as_center
- 参考题目题号: ec883f72, 3345333e, 21f83797

### docstring

```text
一句话总述：
- 把框壁上的缺口当针孔：框外每个彩色像素关于缺口做点对称，落在框内部的
  像点按原色画出，形成一幅倒立的像。

输入结构：
- 背景色网格上有一个单色一像素厚空心矩形框，框壁上恰有一个格子缺失
  （呈背景色），即针孔；缺口不在框角上。
- 框外散布若干彩色像素点，框内部起初全为背景。

规则：
- 设针孔格坐标为 h；对每个框外彩色像素 p，计算像点 2h − p
  （即 p 关于 h 的点对称位置）。
- 若像点严格位于框内部（不含框壁），则把该格涂成 p 的颜色。
- 若像点落在框壁、框外或出界，则不画任何东西。
- 框、缺口、所有框外像素保持原样。

关键洞察：
- 缺口不是待修补的破损，而是一个以"缺失"来书写的对称中心：外景穿过它
  旋转 180 度在暗箱内部成像，像与源关于针孔等距对望，投不进箱内的源
  不留任何痕迹。
```

## 6. 环形跑道上的等步跳跃

- tags:
  - operation:查表匹配, table_lookup
  - operation:填充, fill
  - object:字形单元格, glyph_cell
  - object:分隔行, separator_row
  - object:查询行, query_row
  - relation:循环序, cyclic_order
  - condition:步幅一致外推, constant_stride_extrapolation
- 参考题目题号: d8e07eb2, 221dfab4

### docstring

```text
一句话总述：
- 下方参考带按从左到右给出一个首尾相接的字形循环序，上方查询行是在这条环上
  以固定步幅跳跃的采样，把空缺单元填上下一跳的字形。

输入结构：
- 网格被一条整行分隔线分成上下两带，底色统一。
- 下带是参考带：一行等宽单元格，每格内有一个彼此不同的彩色小字形，
  从左到右构成循环序（最末格的后继是最左格）。
- 上带是查询行：一行同样规格的单元格，前若干格已填有参考带中出现过的字形
  （颜色形状均一致），最后一格为空。
- 查询行相邻两格的字形在参考带上的位置差恒为同一步幅；步幅在不同示例对中
  不同，需自行推断，已填格足以验证这一步幅。

规则：
- 在参考带中查出查询行每个已填字形的位置，求出恒定步幅 s（按环计，允许绕回）。
- 从最后一个已填字形的位置沿环再前进 s 格，取出对应字形。
- 将该字形按原色原样画入查询行的空缺单元；其余一切保持不变。

关键洞察：
- 参考带不是匹配字典而是一条环形跑道：查询行不是它的连续片段，而是等步幅的
  跳跃采样，步幅要自己量出来，而且下一跳可能越过表尾绕回表头。
```
