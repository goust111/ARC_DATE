## 1. 坠落层深取调色板色

- tags:
  - operation:滑动, sliding
  - operation:重涂色, recolor
  - object:满行列条, full_span_bar
  - object:调色板列, palette_column
  - object:孤立像素, isolated_pixel
  - relation:碰撞阻挡, collision_blocking
  - relation:层深度递增, layer_depth_increasing
  - condition:层深模色板取色, depth_mod_palette_color
- 参考题目题号：5（b457fec5）、6（1a07d186）

### docstring

```text
灰点向横条坠落堆叠后，按堆叠层深循环取调色板颜色重涂。

输入结构
- 黑色背景；一条满宽的单色横条位于网格中部。
- 紧贴横条上方、靠最左端有一列连续彩色像素构成调色板，自条向上依次为第 1、2、3……层的颜色。
- 横条上方与下方各散落若干灰色像素。

规则
- 条上方的灰点竖直下落、条下方的灰点竖直上升，各自朝横条移动，碰到条或已落定的灰点即停；同列中离条近者先落定。
- 落定后，每个灰点按它与横条的距离（层数）取调色板对应颜色，层数超过调色板长度则循环取色。
- 横条与调色板保持不变。

关键洞察
- 灰点的最终颜色与初始位置无关，取决于坠落堆叠后涌现的层深；调色板既是颜色图例，又是从条向外计数的序数尺。
```

## 2. 指示体三重编码的旋转印章列

- tags:
  - operation:印章覆盖, stamp
  - operation:旋转, rotate
  - operation:重涂色, recolor
  - object:模板, template
  - object:指示精灵体, indicator_sprite
  - relation:邻接触碰, adjacency_touch
  - relation:对角方向, diagonal_dir
  - condition:像素数编码旋转, pixel_count_encodes_rotation
  - condition:指示决定方向色, indicator_dir_color
- 参考题目题号：2（e8dc4411）、12（6ffbe589）

### docstring

```text
模板沿每个触碰指示体的方向重复盖印，副本颜色取指示体色，每步旋转量由指示体像素数编码且逐副本累积。

输入结构
- 非黑色背景。
- 一个黑色不对称模板精灵，其包围盒为正方形。
- 一到多个单色小指示体（2~4 像素）与模板正交相触，颜色互不相同且异于背景。

规则
- 抹去所有指示体。
- 对每个指示体，取模板中心指向它的方向（八向之一），以模板包围盒边长为步长沿该方向平移出连续副本，直至完全出界。
- 第 k 个副本用该指示体的颜色绘制，并绕自身包围盒中心顺时针旋转 k×(指示体像素数 mod 4)×90°。
- 黑色模板本体保持不动。

关键洞察
- 指示体同时编码三件事：位置给出复制方向、颜色给出副本颜色、像素数给出每步旋转增量；旋转是逐副本累积的，而非全列统一角度。
```

## 3. 图例决定输出顺序的形状字典

- tags:
  - operation:形状匹配, shape_matching
  - operation:重涂色, recolor
  - operation:堆叠, stack
  - object:图例区域, legend_region
  - object:分隔线, divider
  - object:精灵体, sprite
  - relation:堆叠, stack
  - condition:旋转反射等价, rotation_reflection_equivalence
  - condition:图例序定输出序, legend_order_to_output_order
- 参考题目题号：10（845d6e51）、9（e21a174a）

### docstring

```text
按左上图例的排列顺序（而非查询区的空间位置）把占位色查询精灵重新染色并纵向堆叠成输出。

输入结构
- 一条 L 形分隔线从上边缘折到左边缘，围出左上图例区。
- 图例区内自上而下排列若干互不同色的单色模板精灵。
- 分隔线外散布同一占位色的查询精灵，每个查询精灵的形状在允许旋转与镜像的意义下与唯一一个图例形状相同，且一一对应。

规则
- 输出为新网格：按图例自上而下的顺序，把对应的查询精灵依其在查询区中的原有方向逐个纵向堆叠，包围盒上下紧贴、左对齐。
- 每个精灵染成对应图例的颜色。
- 输出宽度为最宽查询精灵包围盒的宽度，空余填背景。

关键洞察
- 查询区内的位置与阅读顺序都是幌子；匹配需忽略方向，而输出的颜色与堆叠次序都来自图例字典本身的排列。
```

## 4. 等量穿串的碰撞传递

- tags:
  - operation:滑动, sliding
  - object:入射条, incident_bar
  - object:方块串, block_chain
  - object:满行列条, full_span_bar
  - relation:碰撞阻挡, collision_blocking
  - relation:穿串传递, through_chain_transfer
  - condition:长度编码弹出数, length_encodes_ejection_count
  - condition:次序保持堆叠, order_preserving_stack
- 参考题目题号：6（1a07d186）、12（6ffbe589）

### docstring

```text
入射条撞上一串静止方块后贴串停下，串的远端等量弹出同样多的方块，依次滑到墙边堆叠。

输入结构
- 黑色背景；一面满跨的墙条。
- 每条工作线上有一个彩色入射条（长度 L 为 1~3，沿线方向延伸）、一串连续共线的静止方块（串长大于 L，各块颜色可不同且异于入射条颜色）与该墙三者共线；入射条在串的一侧、墙在另一侧。
- 网格中有多条这样的独立直线（横、竖皆可），各线的 L 不同。

规则
- 每条线上，入射条沿直线滑向方块串，贴上串头即停。
- 串靠墙一端的 L 个方块被弹出，其余串块原地不动。
- 弹出的方块保持各自颜色，依次滑向墙并靠墙紧密堆叠，原先越靠串尾的块最终越靠墙（相对次序保持）。
- 线与线互不影响；墙保持不变。

关键洞察
- 三层结构必须同时发现：碰撞不是推走整串，位移像动量一样穿过串体，入射条停在串头而弹出发生在远端；弹出的方块数量恰等于入射条长度，长度是数量的隐藏编码；弹出块在墙边的堆叠次序保持原串内次序。仅看单线会误读为"滑到障碍前停下"或"整串被推走"，只有对比各线不同的 L 才能锁定守恒关系。
```

## 5. 门树传播、墙色记入房色

- tags:
  - operation:填充, filling
  - object:连通腔室, connected_chamber
  - object:分隔墙, separator_wall
  - object:条缺口, bar_gap
  - object:种子像素, seed_pixel
  - relation:门树连通, door_tree_connectivity
  - condition:入口墙色定房色, entry_wall_color_fills_room
- 参考题目题号：8（cf133acc）、13（7c8af763）

### docstring

```text
从种子房间出发穿过墙上缺口逐房传播，每个房间整体染成其入口所在墙的颜色。

输入结构
- 若干满跨横条与竖条（墙，颜色可各不相同）把网格划分成矩形房间。
- 部分墙上有单格缺口（门），门的连通关系构成一棵树。
- 某个房间内有一个彩色种子像素，其余为背景。

规则
- 种子所在房间整体填成种子色。
- 从该房间出发沿门逐房传播，每个新到达的房间整体填成"进入它时穿过的那扇门所在墙"的颜色；树结构保证每个房间入口唯一。
- 没有门可达的房间保持背景。
- 所有门格填回所在墙的颜色，墙被补全。

关键洞察
- 缺口不是残缺而是通道；房间颜色不由房内或紧邻的任何东西直接决定，而是记录"进入它的那堵墙"——必须按传播次序追踪整棵门树，只看相邻墙无法得到答案。
```

## 6. 灰点选块兼象限定向的自印章

- tags:
  - operation:印章覆盖, stamp
  - operation:旋转, rotate
  - operation:像素放大, pixel_upscale
  - object:控制像素, control_pixel
  - object:源图案, source_pattern
  - object:象限, quadrant
  - relation:像素到块映射, pixel_block_mapping
  - relation:象限对应, quadrant_correspondence
  - condition:象限编码旋转, quadrant_encodes_rotation
- 参考题目题号：14（ad7e01d0）、1（d89b689b）

### docstring

```text
把整幅输入按灰点位置盖印到对应输出块，副本朝向由灰点所处象限决定。

输入结构
- 输入是一个偶数边长 n 的正方形图案，含若干颜色，其中灰色为控制色。
- 输出为 n²×n² 网格，划分成 n×n 个 n×n 的块。

规则
- 对每个灰色像素 (r,c)：把整幅输入图案盖印到第 (r,c) 块。
- 副本按该像素相对全图中心的象限旋转：左上 0°、右上顺时针 90°、右下 180°、左下 270°。
- 其余块保持全黑。

关键洞察
- 灰点身兼两职：坐标选择目标块，象限决定该副本的旋转方向；同一图案会以不同朝向出现在不同块中，仅当发现"块中图案的朝向随灰点象限而变"才能解出。
```

## 7. 以标记为原点的四向色尺

- tags:
  - operation:填充, filling
  - operation:擦除, erase
  - object:标记像素, marker_pixel
  - object:十字区域, cross_region
  - object:断点像素, breakpoint_pixel
  - relation:行列归属, row_col_membership
  - condition:按断点序分段涂色, color_by_breakpoint_order
  - condition:末端之外抹黑, erase_beyond_last
- 参考题目题号：16（319f2597）、8（cf133acc）

### docstring

```text
黑色标记的行与列构成四条臂，臂上彩点作为断点由内向外分段上色，最后断点之外抹黑。

输入结构
- 网格几乎被单一场色填满。
- 有一个单像素黑色标记；若干彩色像素散布，其中一部分恰在标记所在行或列上（臂上），另一部分不在（干扰）。

规则
- 从标记向外沿每条臂走：从标记（不含）到第一个彩色断点（含）之间的格子染成第一个断点的颜色，第一到第二断点之间染第二断点色，依此类推。
- 最后一个断点之外直到边缘全部染黑；没有断点的臂整条染黑。
- 不在臂上的彩色像素与其余区域保持不变。

关键洞察
- 十字不是被均匀擦除，而是一把以标记为原点的四向色尺：彩点标出各段的外端点，尺末之外才被抹黑；臂外彩点纯属干扰，参与与否由行列归属而非颜色决定。
```
