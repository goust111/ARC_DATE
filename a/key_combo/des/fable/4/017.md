## 1. 弱侧领地

- tags:
  - operation:逻辑运算, logical_op
  - operation:计数, counting
  - operation:重涂色, recolor
  - object:位掩码, bitmask
  - object:分隔列, separator_col
  - relation:逐行对比派发, per_row_comparison_dispatch
  - condition:少数侧决定运算, minority_side_selects_op
- 参考题目题号: 17 (0520fde7)、16 (94f9d214)、13 (4e7e0eb9)

### docstring

```text
一句话总述：
两块掩码逐行对峙，每行数一数双方激活格的多少，只保留"弱势一方独有"
的格；平局的行才取交集，命中的格涂绿。

输入结构：
- 输入由左右两个等尺寸掩码和中间一列纯灰分隔柱组成。
- 左掩码用蓝色在黑底上作图，右掩码用红色在黑底上作图。
- 分隔柱通体灰色，除分界外不携带任何信息。

规则：
- 输出与单侧掩码同尺寸，底色为黑。
- 对每一行分别处理：设该行蓝掩码激活格数为 a、红掩码激活格数为 b。
- 若 a < b，输出该行中仅蓝侧激活（红侧未激活）的格。
- 若 b < a，输出该行中仅红侧激活（蓝侧未激活）的格。
- 若 a = b，输出该行中两侧同时激活的格。
- 命中的格一律涂绿，其余保持黑色。

关键洞察：
- 没有任何显式标记告诉你每行做哪种集合运算——派发键藏在每行自身的
  数量对比里：行内少数派的"专属领地"才被保留，势均力敌时才看重叠。
- 若第一个示例的多数行恰好平局，会被误读成整体逐像素 AND，这个错误
  假设在其余示例上会当场破产。
```

## 2. 残迹指定象限的旋转

- tags:
  - operation:旋转, rotation
  - operation:拼接, assembly
  - operation:对齐放置, align_and_place
  - object:精灵体, sprite
  - object:角标记, corner_marker
  - object:象限, quadrant
  - relation:残迹约束放置, residue_constrains_placement
  - condition:全局排列消歧, global_permutation_disambiguates
- 参考题目题号: 5 (7953d61e)、2 (8a004b2b)、10 (890034e9)

### docstring

```text
一句话总述：
在四角黄点框定的 2n×2n 区域里，凭每个象限内的稀疏残迹给它分配小图
样的一种旋转，四个象限恰好取遍四种旋转，装配出完整输出。

输入结构：
- 画面某处有一个 n×n 的多色小图样，完整可见。
- 另一处有四个黄色单点，标出一个 2n×2n 目标区域的四角。
- 目标区域内部散落少量彩色残迹像素；每个象限内的残迹都与小图样的
  某种旋转（0/90/180/270 度）在对应位置上逐格同色。

规则：
- 以黄点为角裁出 2n×2n 目标区域作为输出画布。
- 为每个 n×n 象限分配小图样的一种旋转，要求该旋转与象限内全部残迹
  逐格吻合。
- 单个象限的残迹可能与不止一种旋转吻合；但四个象限必须恰好取遍四种
  旋转、互不重复，满足此约束的分配全局唯一。
- 按分配结果把四个旋转版本整体填入各象限，得到输出。

关键洞察：
- 这不是固定方位的旋转拼图：旋转与象限的对应关系每题不同，不能沿用
  "原图-右转-下转"的固定墙纸直觉。
- 残迹是被裁到只剩几粒像素的完整象限；局部证据不足时，答案由"四种
  旋转各用一次"的全局排列约束咬合出来，缺了哪一环都拼不拢。
```

## 3. 看不见的射线连锁

- tags:
  - operation:射线延伸, ray_extend
  - operation:连锁反应, chain_reaction
  - object:标记像素, marker_pixel
  - object:交点, intersection_point
  - relation:对角线激活, diagonal_activation
  - condition:异源异向交点凝结, cross_source_intersection_condenses
- 参考题目题号: 3 (d07ae81c)、17 (0520fde7)

### docstring

```text
一句话总述：
每个标记点沿两条对角线发出看不见的射线，来自不同标记、方向相异的射
线交点凝结成新标记并继续发射，直到不再产生新交点，输出全部凝结点。

输入结构：
- 黑底网格上只有若干青色标记像素，没有其它对象。
- 标记数量很少，但它们的对角线会在网格内部相交。

规则：
- 每个标记沿 NW-SE 与 NE-SW 两条完整对角线向网格边缘发出射线，
  射线本身不落色。
- 凡有一条 NW-SE 向射线与一条 NE-SW 向射线来自两个不同的标记，
  且相交于同一个原为黑色的格，该格凝结为一个橙色新标记。
- 新标记同样向四个对角方向发射射线；重复凝结过程，直到再无新交点
  产生为止。
- 输出保留原青色标记，全部凝结点为橙色，其余格保持黑色。

关键洞察：
- 画面上从未画出任何一条线：参与规则的射线只以交点的形式显形，而
  每个交点又是新的发射源，答案是这场连锁反应收敛后的不动点。
- 只看第一代交点会漏掉后续代际；只把对角线画出来又会多涂大片射线
  路径——两种直觉解法各错一半。
```

## 4. 环形墙纸的断口

- tags:
  - operation:平铺, tiling
  - operation:镜像, mirror
  - operation:填充, fill
  - object:边框段, border_segment
  - object:矩形边界, rectangular_border
  - relation:环形周期, cyclic_period
  - condition:图样倒序交替, motif_alternates_with_reverse
- 参考题目题号: 15 (30f42897)、20 (bc4146bd)、9 (bf32578f)

### docstring

```text
一句话总述：
边框一圈本是"图样段与其倒序段"交替铺成的环形墙纸，把被灰色覆盖的
断口按环上的规律复原。

输入结构：
- 网格内部全部为黑色，图案只出现在最外一圈边框上。
- 把边框按顺时针展开成一条首尾相接的色带：色带由一段长为 k 的多色
  图样与它的倒序段交替铺满整圈，环长是 2k 的整数倍。
- 图样自身不回文，因此正序段与倒序段可以区分。
- 环上有一段连续区间被灰色覆盖，覆盖段可以跨过网格角点；未覆盖的
  部分足以唯一确定图样与相位。

规则：
- 沿顺时针把边框展开为一维环形序列。
- 从未损坏的部分恢复出图样段及其倒序段的交替周期与相位。
- 把每个灰格换成完整墙纸中该位置应有的颜色；内部黑色区域保持不变。

关键洞察：
- 修复不能在二维邻域里做：墙纸的周期只存在于展开后的一维环上，跨角
  的断口迫使解题者放弃平面对称直觉，改到周界坐标系里找规律。
- 真周期是 2k 而不是 k：只按图样长度平移取样会把倒序段抄错，必须
  识破"正序—倒序"的交替律。
```

## 5. 大图反哺小样

- tags:
  - operation:缩放匹配, scale_matching
  - operation:降采样, downsample
  - operation:填充, fill
  - object:模板, template
  - object:放大副本, scaled_replica
  - relation:尺寸匹配, size_matching
  - condition:副本证据回填孔洞, replica_evidence_fills_holes
- 参考题目题号: 2 (8a004b2b)、10 (890034e9)

### docstring

```text
一句话总述：
大场景里嵌着小模板的整倍放大副本，用放大副本反向填补小模板上的灰色
孔洞，输出补全后的小模板。

输入结构：
- 画面一角有一个带孔的小模板：多色图案中若干格被灰色占位。
- 画面其余部分是一个大场景，其中某处嵌着该模板按某一整倍数 k 逐格
  放大后的完整副本；场景中另有与模板无关的干扰图形。
- 放大倍数 k 与副本位置每题不同，均无任何标注。

规则：
- 以小模板的非灰格为钥匙在大场景中搜索匹配：存在唯一的倍数 k 与
  位置，使模板每个非灰格对应场景中一个同色的 k×k 实心块。
- 对模板的每个灰格，读取匹配处对应 k×k 块的颜色，回填该灰格。
- 输出为补全后的小模板，尺寸即模板包围盒。

关键洞察：
- 证据的流向与常见的"放大并放置"相反：完整信息在放大副本一侧，
  小模板才是残缺者；必须先以残缺者为钥匙锁定副本与倍数，再把颜色
  按块降采样搬回来。
- 干扰图形使"找场景中最像的东西"不可靠，只有孔洞之外的格逐块同色
  这一硬约束才能锁定唯一匹配。
```

## 6. 双层墙纸的显形

- tags:
  - operation:平铺, tiling
  - operation:透明叠加, overlay
  - operation:重涂色, recolor
  - object:轮廓字形, contour_glyph
  - object:周期格点, periodic_lattice
  - relation:相位继承, phase_inheritance
  - condition:双墙纸重叠标色, double_coverage_marked
- 参考题目题号: 14 (eee78d87)、4 (ccd554ac)、17 (0520fde7)

### docstring

```text
一句话总述：
两个小字形各是一张从未画出的周期墙纸露出的唯一样本，按各自位置的
相位把两张墙纸铺满全画布并显形，重叠处标红。

输入结构：
- 黑底网格上有两个 3×3 轮廓字形，颜色不同、形状不同、位置任意，
  包围盒互不重叠；除此之外没有别的对象。
- 输出与输入同尺寸。

规则：
- 每个字形视为一张周期 3 墙纸的唯一显形样本：整张墙纸是该 3×3
  母元沿行、列以步长 3 无限重复，其中一份恰好落在字形原位，墙纸
  相位由此与字形包围盒的位置对齐。
- 把两张墙纸各自铺满与输入同尺寸的画布。
- 只被一张墙纸实格覆盖的格涂该墙纸的颜色；被两张墙纸实格同时覆盖
  的格涂红色；其余格为黑。

关键洞察：
- 字形不是要搬运或复制的对象，而是各自无限墙纸露出的一角；相位不由
  任何计数或标注给出，而是从字形的绝对位置继承。
- 参与重叠判定的两张完整墙纸在输入中从未被画出，答案是这两个仅存
  生成元的隐式图层的干涉图样。
```
