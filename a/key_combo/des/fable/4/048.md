## 1. 环码级联旋转

- 参考题目题号: `bda2d7a6`, `3c9b0459`, `4522001f`, `e87109e9`
- tags:
  - operation:旋转, rotate
  - object:同心正方形层, concentric_ring
  - object:缺口, notch
  - relation:嵌套层序, nesting_order
  - condition:缺口宽度编码转角, notch_width_encodes_angle
  - condition:旋转沿嵌套累加, rotation_accumulates_inward
  - condition:编码映射, encoding_map

### docstring

```text
把每个同心环连同其内部按环上缺口宽度所编码的角度级联旋转。

输入结构:
- 正方形画布由若干层一格厚的同心正方形环组成，每环单色且颜色互异。
- 最内层是一个无任何旋转对称的多色核心图案。
- 每个环在某条边的正中开有一个背景色缺口，宽度为一、二或三格（边长为
  奇数，保证正中位置唯一）。

规则:
- 缺口宽度编码旋转角: 一格 = 顺时针九十度，两格 = 一百八十度，三格 =
  顺时针二百七十度。
- 自最外环向内逐环处理: 把当前环连同其内部的一切，整体绕画布中心旋转
  该环缺口宽度所编码的角度。
- 处理完所有环后输出。

关键洞察:
- 旋转是级联的: 内层被所有外层的旋转依次带动，第 k 层的实际转角是第
  1 到 k 层编码角之和，核心承受全部编码角的总和；把每个环按自身编码
  独立旋转是看似合理的错误捷径。
```

## 2. 指针链叠合

- 参考题目题号: `6a11f6da`, `cbebaa4b`, `1caeab9d`
- tags:
  - operation:透明叠加, transparent_overlay
  - operation:拼接, assemble
  - object:等尺寸面板, equal_size_panel
  - object:指针像素, pointer_pixel
  - relation:链式配对, chain_pairing
  - relation:图层优先级, layer_priority
  - condition:层序由指针链决定, stacking_order_from_pointer_chain

### docstring

```text
沿面板上指针像素构成的颜色链确定叠放层序，将所有同尺寸面板透明叠合成
一块。

输入结构:
- 黑色背景上分散着若干块同尺寸矩形面板，每块由自己的主色像素与背景色
  孔洞组成，各面板主色互不相同。
- 除一块外，每块面板内恰有一个既非主色也非背景色的指针像素，其颜色
  等于另一块面板的主色；指针关系构成一条覆盖全部面板的单链。
- 面板在画布上的左右摆放顺序与链序刻意不同。

规则:
- 没有被任何指针指向的面板是最底层；每块面板的指针颜色指出紧邻其上的
  一层；没有指针像素的面板是最顶层。
- 按此链序自底向上依次把各面板的主色像素叠印到同一画布上，后画的覆盖
  先画的，背景孔洞透明不覆盖。
- 指针像素视为背景，不参与叠印。输出为单块面板的尺寸。

关键洞察:
- 层序与面板在画布上的位置无关，由指针像素颜色构成的链表遍历序决定；
  指针像素是元数据不是图案，摆放顺序是诱饵。
```

## 3. 四色角标是旋转算子

- 参考题目题号: `95990924`, `4522001f`, `f5aa3634`
- tags:
  - operation:旋转, rotate
  - object:角标记, corner_marker
  - object:精灵体, sprite
  - relation:环绕手性, winding_chirality
  - condition:相位编码转角, phase_encodes_angle
  - condition:手性编码转向, chirality_encodes_direction
  - condition:诱饵散点, decoy_pixels

### docstring

```text
四色角标组的相位与环绕方向共同构成一条旋转指令，作用于其围住的灰色
精灵。

输入结构:
- 黑色背景上散布单像素彩点（仅蓝、红、黄、绿四色）与若干灰色小精灵，
  精灵无旋转对称也无镜像对称。
- 部分彩点构成角标组: 四点恰为某正方形的四个角、四色各一，且正方形
  内部恰好围住一个灰色精灵。
- 基准排列为“蓝西北、红东北、黄东南、绿西南”（顺时针读为蓝红黄绿）；
  角标组可能是基准的整体旋转（顺时针环绕），也可能是其镜像（逆时针
  环绕）。
- 另有凑不满四角或不成正方形的散点诱饵，以及不被任何角标围住的灰色
  精灵。

规则:
- 对每个角标组读出两个参数: 蓝色所在角相对基准位置的偏转给出旋转角
  （零、九十、一百八十或二百七十度）；四色环绕方向给出旋转方向
  （顺时针环绕则顺时针旋转，逆时针环绕则逆时针旋转）。
- 把被围住的灰色精灵按该指令绕自身中心旋转后原位重画。
- 角标点、散点诱饵、未被围住的精灵一律原样保留。

关键洞察:
- 角标不是装饰而是一条双参数旋转指令——蓝色角的相位给角度，四色环绕
  的手性给方向；只看相位会把镜像组的旋转方向搞反。
```

## 4. 落单精灵的缺失伙伴

- 参考题目题号: `3c9b0459`, `f5aa3634`, `cbebaa4b`, `97a05b5b`
- tags:
  - operation:旋转, rotate
  - operation:裁剪, crop
  - object:精灵体, sprite
  - relation:互补配对, complementary_pairing
  - condition:异常值选择, outlier_selection
  - condition:补形构造输出, output_constructed_from_complement

### docstring

```text
全部灰色精灵按“旋转半周后互补成实心矩形”两两配对，为唯一落单者构造
出从未画出的缺失伙伴。

输入结构:
- 黑色背景上分散若干个互不接触的灰色四连通精灵。
- 除一个外，精灵两两配对: 一对精灵的外接矩形同尺寸，且把其中一个旋转
  一百八十度后与另一个按外接矩形对齐叠放，恰好不重不漏拼满整个矩形。
- 落单精灵与至少一对已配对精灵共享相同的外接矩形尺寸；另有若干平移
  全等的精灵作为干扰。

规则:
- 通过互补检验找出唯一无法配对的精灵。
- 输出一个与其外接矩形同尺寸的网格: 取该矩形减去落单精灵所得的补形，
  旋转一百八十度，以灰色画出，其余为黑色。

关键洞察:
- 配对判据是“半周旋转后互补拼满矩形”，而不是形状相同——平移全等的
  精灵对是诱饵；答案是输入中从未出现的那块拼图，必须由补集加旋转构造
  出来。
```

## 5. 配准后的多数决修复

- 参考题目题号: `c444b776`, `c3f564a4`, `6a11f6da`, `2c0b0aff`, `4522001f`
- tags:
  - operation:补全, complete
  - operation:旋转, rotate
  - operation:计数, counting
  - object:分隔线, separator_line
  - object:受损副本, damaged_copy
  - object:角标像素, corner_marker_pixel
  - relation:逐像素多数决, pixelwise_majority_vote
  - condition:配准后投票, vote_after_registration
  - condition:无完好副本, no_intact_copy

### docstring

```text
宫格各格是同一图案经不同旋转后的受损副本，先按角标像素配准、跨格逐
像素多数决复原，再按各格原朝向修复回填。

输入结构:
- 单色分隔线把画布划分成若干等大的正方形格。
- 存在一个真图案，其某个固定角上有一枚唯一的青色角标像素。
- 每格内容是真图案旋转零、九十、一百八十或二百七十度之一后，再把少数
  像素改成其他颜色的结果（可能改成背景色，也可能是鲜艳的错色；角标
  像素本身不受损）。
- 各格旋转量不尽相同，损坏位置与颜色各不相同；没有任何一格完好；配准
  对齐后每个位置上正确颜色在全部副本中严格占多数。
- 某一格损坏极少，诱导直接复制它。

规则:
- 由每格中青色角标像素所在的角推断该格的旋转量。
- 将所有副本逆旋转到公共朝向，逐像素取出现次数最多的颜色，得到真图案。
- 把真图案按每格自身的旋转量转回，整格替换该格内容（所有损伤被修复，
  各格朝向保留）；分隔线不变。

关键洞察:
- 投票必须在配准后的公共坐标系中进行——在画布坐标下直接跨格比较会因
  朝向不同而失效；青色角标是配准钥匙，输出不是统一平铺，而是保留各格
  自身朝向的修复。
```

## 6. 孔洞的双重职责

- 参考题目题号: `b91ae062`, `4522001f`, `6a11f6da`, `97a05b5b`
- tags:
  - operation:像素放大, pixel_upscale
  - operation:透明叠加, transparent_overlay
  - operation:计数, counting
  - object:孔洞, hole
  - relation:图层优先级, layer_priority
  - condition:孔数编码倍率, hole_count_encodes_scale
  - condition:孔洞即透明窗, holes_are_windows
  - condition:编码映射, encoding_map

### docstring

```text
每个带孔对象按孔数放大并原位放置，倍率小者叠在上层，放大后的孔洞成为
透视下层的窗口。

输入结构:
- 黑色背景上若干互不重叠的实心单色对象，每个对象内部含若干个一格大小
  的背景色孔洞。
- 各对象的孔洞数互不相同，且均不少于二。
- 结构保证各对象放大后不越出画布。

规则:
- 每个对象放大 k 倍，k 等于其孔洞数: 每格变成 k×k 的同色块，放大体
  的外接矩形左上角与原对象外接矩形的左上角对齐。
- 按倍率从大到小的顺序绘制: 先画倍率最大的对象，之后倍率较小者依次
  叠画其上。
- 叠画时放大成 k×k 的孔洞既不涂色也不清除——下层已画的颜色透过孔洞
  可见。
- 输出画布尺寸与输入相同，原始小对象不保留。

关键洞察:
- 孔洞身兼两职: 数量编码放大倍率，放大后又充当透明窗口；叠放次序也由
  同一计数反向决定（倍率越小越靠上），三条规则全部咬合在孔上。
```

## 7. 图例色环与图上距离

- 参考题目题号: `e87109e9`, `bda2d7a6`, `95990924`, `cb2d8a2c`
- tags:
  - operation:描边, decorate
  - object:图例条, legend_bar
  - object:邻接图, adjacency_graph
  - relation:图跳数, graph_distance
  - condition:色环按跳数索引, color_cycle_indexed_by_hops
  - condition:空间距离为诱饵, euclidean_distance_decoy

### docstring

```text
以图例给出的色环为刻度，按对象在邻接图上到源的跳数给每个灰色对象描边。

输入结构:
- 画布顶部有一条与主区域用背景行隔开的图例: 若干色格从左到右给出一个
  颜色循环序列。
- 主区域黑色背景上散布若干灰色对象；恰有一个对象已带有图例中某色的
  一格厚八邻域描边（源）。
- 若两对象的描边圈会接触或重叠（即最小切比雪夫距离不超过二），视为在
  邻接图上相邻；全体对象在该图上连通。
- 存在空间上离源很近、但邻接链上跳数很大的对象作为诱饵。

规则:
- 输出只保留主区域，图例移除。
- 计算每个对象到源对象在邻接图上的最短跳数 d。
- 该对象的描边色等于图例色环中从源色出发前进 d 步（到末尾循环回绕）
  的颜色；源对象保持原描边。

关键洞察:
- 决定描边色的是邻接图上的最短路跳数，而非空间直线距离——离源很近但
  需绕行多跳的对象颜色反而靠后；图例不是装饰，而是循环刻度。
```

## 8. 拓扑定向的光束

- 参考题目题号: `e87109e9`, `cb2d8a2c`, `7ec998c9`
- tags:
  - operation:射线延伸, ray_extend
  - operation:转向, turn
  - object:障碍块, obstacle_block
  - object:空心框, hollow_frame
  - condition:实心空心编码转向, topology_encodes_turn
  - condition:自撞停止, self_collision_stop
  - condition:颜色为诱饵, color_decoy

### docstring

```text
边界发射的光束在障碍前转向，转向方向由障碍是实心还是空心决定，撞到
自身轨迹即停。

输入结构:
- 黑色背景；一枚绿色发射像素位于网格边界上。
- 场内散布若干障碍: 一部分是实心矩形块，一部分是一格厚的空心矩形框；
  障碍颜色五花八门且与实心、空心无关。
- 第一个示例中障碍颜色恰与转向方向相关，是刻意的诱饵，后续示例打破
  这一假象。

规则:
- 光束从发射点垂直于边界射入，沿途把背景格涂成绿色。
- 前方一格是障碍时就地转向: 实心障碍则顺时针转九十度，空心框则逆时针
  转九十度，然后继续直行。
- 前方一格是绿色轨迹（含发射点）时光束停止；走到网格边界也停止。
- 障碍及其颜色原样保留。

关键洞察:
- 转向由障碍的拓扑属性（有无内腔）编码，颜色是刻意的诱饵；光束可能被
  自身轨迹截停，终点由整条转向因果链决定。
```
