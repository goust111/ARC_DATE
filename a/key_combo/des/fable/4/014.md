## 1. 轨迹前缀里的转向密码

- tags:
  - operation:寻路, pathfinding
  - operation:连线, draw_line
  - operation:规则示教破译, rule_demo_decoding
  - object:转向指令像素, turn_instruction_pixel
  - object:轨迹前缀, trace_prefix
  - object:起止标记, start_end_marker
  - relation:颜色编码方向, color_encodes_direction
  - condition:映射随输入而变, per_input_mapping
  - condition:确定性模拟, deterministic_simulation
- 参考题目题号: 6、17

### docstring

```text
沿已画出的绿色折线前缀继续走完全程，转向法则要从前缀自己绕过障碍的方式里读出来。

输入结构:
- 黑色背景网格中散布若干青色与黄色的单像素障碍。
- 一条绿色折线从边界出发、已画出前半段轨迹，途中已在至少一个青色障碍和至少一个黄色障碍前完成过转向。
- 一段红色短直线是终点。
- 颜色与左转/右转的对应关系在不同输入之间会互换，不存在固定码表。
- 保证续行轨迹每一步唯一：转向后下一格总是可走，且有限步内抵达红线。

规则:
- 读取绿色前缀在青色障碍前、黄色障碍前各自的转向方向，得到本输入的颜色-转向法则。
- 从前缀末端沿当前方向逐格直行；前进方向的下一格是障碍时，按该法则原地转九十度，障碍本身不被进入、不被改动。
- 前进方向的下一格属于红色终点线时停止。
- 把续行走过的所有格子涂成绿色，其余保持不变。

关键洞察:
- 给出的绿线不只是起点标记，它是规则的示教样本：颜色对应哪种转向没有全局答案，
  必须从已有轨迹的转弯处现场破译，再把同一法则外推到剩余路程；整条路径是确定性模拟，不是最短路搜索。
```

## 2. 颜色指挥的自我盖章

- tags:
  - operation:印章覆盖, stamp_overlay
  - operation:镜像, mirror
  - operation:旋转, rotate
  - object:种子精灵, seed_sprite
  - object:指令像素, instruction_pixel
  - relation:像素到块映射, pixel_to_block_mapping
  - condition:颜色决定副本姿态, color_selects_pose
- 参考题目题号: 5、17、20

### docstring

```text
把多色种子网格按块展开，每个前景像素用自身颜色规定的姿态放入一份完整种子的副本。

输入结构:
- 输入是一幅 4x4 小网格，黑色为空白背景。
- 前景像素只使用蓝、红、绿三种颜色中的若干种，可混合出现。

规则:
- 输出为 16x16 网格，划分成 4x4 个块，与输入像素一一对应。
- 背景像素对应的块保持全黑。
- 前景像素对应的块内放入整幅输入的一个副本（副本保留其原本的全部颜色）：
  蓝色像素放原样副本，红色像素放左右镜像副本，绿色像素放旋转一百八十度的副本。

关键洞察:
- 种子同时扮演三重角色：放置掩码、被盖章的图案、以及逐像素的姿态指令带；
  块与块之间的差异不是噪声，而是由指挥像素的颜色决定的镜像与旋转。
```

## 3. 残迹里的模板

- tags:
  - operation:擦除, erase
  - operation:掩码裁剪, mask_crop
  - object:噪声像素, noise_pixel
  - object:多色正方形, multicolor_square
  - object:隐藏模板, hidden_stencil
  - relation:邻接支撑, adjacency_support
  - condition:邻接不足则删除, delete_unsupported
  - condition:去噪结果作掩码, denoised_shape_as_mask
- 参考题目题号: 4、8

### docstring

```text
把噪声云去噪后剩下的形状当作模板，套在多色正方形上裁出答案。

输入结构:
- 黑色背景网格中有一个 k x k 的致密多色正方形。
- 另一处有一片青色像素云：真实模板像素彼此相连、支撑充分，混入的噪点只有零个或一个青色四邻。
- 云的内部与外部都散布噪点；去噪后剩余像素的紧致包围盒恰为 k x k。

规则:
- 删除所有青色四邻数不足两个的青色像素，只保留支撑充分的像素。
- 取保留像素的 k x k 包围盒作为二值模板，与多色正方形按位置对齐。
- 模板为青处保留正方形的像素，其余位置置黑；输出这个 k x k 网格。

关键洞察:
- 真正的模板从未被完整画出，画面上只有它被噪声污染后的残迹；
  必须先用邻接支撑准则复原模板，再把它当作裁剪掩码使用，两步缺一不可。
```

## 4. 搬走遮挡块再修复留下的洞

- tags:
  - operation:移动, move
  - operation:补全, inpaint
  - object:遮挡矩形, occluding_rect
  - object:空心框靶位, hollow_frame_target
  - object:周期瓦片, periodic_tile
  - relation:平移对称, translational_symmetry
  - relation:同尺寸对接, same_size_docking
  - condition:搬运与修复耦合, move_and_repair_coupled
- 参考题目题号: 2、7、9

### docstring

```text
把灰色实心矩形搬进同尺寸的灰色空心框里，并用图案的平移周期性修复它搬走后留下的缺口。

输入结构:
- 整幅画布是一个平移周期的多色图案，没有真正的背景色。
- 图案上压着一个灰色实心矩形（遮挡块）。
- 另一处有一个外廓同尺寸的灰色空心框，框内仍透出图案。

规则:
- 在空心框位置画上同尺寸的灰色实心矩形，覆盖框与框内图案。
- 删除原位置的实心矩形，用图案的平移对称从可见区域恢复该处被遮挡的颜色。
- 其余像素保持不变。

关键洞察:
- 灰色块既是待搬运的对象又是遮挡物：空心框指定它的落点，
  而它离开后的空洞必须靠周期对称补全；只搬不补或只补不搬都无法解释示例。
```

## 5. 光环传染链

- tags:
  - operation:膨胀, dilate
  - operation:连锁传播, chain_propagation
  - object:实心单色物体, solid_mono_object
  - object:火种标记, seed_marker
  - object:光环, halo
  - relation:光环相邻即点燃, halo_adjacency_ignites
  - condition:光环色记录点燃者, halo_color_records_igniter
  - condition:不可达者无光环, unreached_no_halo
- 参考题目题号: 1、13

### docstring

```text
从带火种标记的物体开始，让外扩包围盒光环逐级点燃相邻物体，光环颜色记录点燃者。

输入结构:
- 黑色背景上散布若干互不相邻的实心单色物体，颜色互不相同。
- 唯一一个黄色单像素紧贴其中一个物体，是火种标记。
- 保证传播每一轮至多点燃一个新物体，传播链唯一。

规则:
- 被点燃的物体获得光环：其紧致包围盒向外扩一格、裁剪到网格内，把该区域内的背景格涂成光环色，物体本身不变。
- 火种物体最先点燃，光环用黄色。
- 若某未点燃物体的像素与已画出的光环格正交相邻，它随即被点燃，光环颜色取点燃它的那个物体的本体颜色。
- 传播直到没有新物体被点燃；未被波及的物体保持原样，无光环。

关键洞察:
- 光环不是逐物体的装饰而是传染介质：哪些物体有光环由链式可达性决定，
  而每圈光环的颜色回溯性地写下了"是谁点燃了我"。
```

## 6. 伪装成图案色的遮挡

- tags:
  - operation:补全, inpaint
  - operation:周期推断, periodic_inference
  - object:周期织纹, periodic_weave
  - object:涂抹补丁, painted_patch
  - relation:对角线相位偏移, diagonal_phase_shift
  - condition:违律格才是遮挡, law_violation_marks_occlusion
  - condition:遮挡色即成员色, occluder_color_in_cycle
- 参考题目题号: 16、9、7

### docstring

```text
修复周期彩色织纹上的涂抹补丁，而涂抹用的颜色本身就是织纹的成员色。

输入结构:
- 整幅网格是一个颜色循环按对角相位平铺的周期织纹，每行相对上一行错开一位。
- 若干矩形补丁被用循环中的某一种颜色 C 整块涂抹。
- C 同时也作为正常织纹色出现在画面各处。

规则:
- 从服从周期规律的格子推断颜色循环与相位。
- 凡颜色违反该规律的格子判定为被涂抹，改写为规律要求的颜色。
- 符合规律的 C 色格保持不变。

关键洞察:
- 遮挡色不是"多出来的第十种颜色"，它就是图案自身的颜色之一；
  辨认哪些格子被涂抹的唯一依据是每个格子是否服从全局周期律，而不是颜色身份——
  直觉的"把 C 全换掉"或"找突兀色"都会失败。
```

## 7. 会吸收与染色的棱镜

- tags:
  - operation:投射, project
  - operation:重涂色, recolor
  - object:多色棱镜, multicolor_prism
  - object:边界彩点, border_pixel
  - relation:同行列对齐, row_col_aligned
  - condition:同色被近侧吸收, absorb_on_near_match
  - condition:出射取远侧色, exit_color_from_far_edge
- 参考题目题号: 13、3

### docstring

```text
边界彩点向中央多色棱镜发射射线：与近侧格同色的被吸收，其余穿透并被远侧格染色后射出。

输入结构:
- 黑色背景中央有一个多色实心矩形棱镜，每格颜色可各不相同。
- 画布边界上有若干单像素彩点，每个都与棱镜同行或同列。

规则:
- 每个边界点沿所在行或列向棱镜直射，入射段（从彩点到棱镜前一格）涂成彩点自身的颜色。
- 设近侧格为该行/列上射线碰到的第一个棱镜格，远侧格为最后一个棱镜格。
- 若彩点颜色与近侧格颜色相同，射线被吸收：只保留入射段，不再穿出。
- 否则射线穿过棱镜（棱镜保持不变），从远侧格外一格直到画布边界画出出射段，颜色取远侧格的颜色。

关键洞察:
- 棱镜不是障碍而是滤色器：是否穿透由入射色与近侧边缘的比对决定，
  出射色又由远侧边缘决定，射线两端的颜色都由棱镜边缘、而非彩点本身说了算。
```
