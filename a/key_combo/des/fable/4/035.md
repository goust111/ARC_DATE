## 1. 尺寸定序的互阻射线带

- 参考题目: `ecdecbb3`、`f8be4b64`、`08ed6ac7`、`e76a88a6`
- tags:
  - operation:射线延伸, ray_extend
  - operation:排序, sorting
  - object:实心正方形, solid_square
  - relation:尺寸排名决定次序, size_rank_to_order
  - condition:遇前景终止, stop_at_fg
  - condition:射线互为障碍, rays_block_rays

### docstring

```text
按边长从大到小依次让每个正方形向四周喷出射线带，后喷的射线被先喷的挡住。

输入结构
- 背景为黑色，前景是若干颜色互不相同、边长互不相同的实心正方形。
- 正方形彼此分离，且不与网格边缘相接。

规则
- 将正方形按边长从大到小排序，依次处理。
- 处理一个正方形时，从它的四条边分别向外画与边等宽的同色射线带；
  射线带逐格推进，碰到任何非背景格（其他正方形或此前画出的射线带）
  即在该方向停止，否则一直画到网格边缘。
- 全部正方形处理完毕后即为输出，正方形本身保持不变。

关键洞察
- 射线带不仅被正方形阻挡，也被先画出的射线带阻挡，因此结果依赖处理
  次序；次序没有画在图上，而是由各正方形的边长排名隐含给出——大者
  先行。
```

## 2. 行列表头的异或乘法表

- 参考题目: `5b526a93`、`31d5ba1a`、`5833af48`、`195ba7dc`
- tags:
  - operation:异或合成, xor_compositing
  - operation:补全, completion
  - object:行列格点, row_column_lattice
  - object:掩码, mask
  - object:分隔线, separator_lines
  - relation:表头组合生成单元, header_pair_generates_cell
  - condition:灰格待求, gray_cell_unknown
  - condition:诱饵排除, decoy_elimination

### docstring

```text
内部每个单元都是其行表头与列表头掩码的逐格异或，把灰色未知单元按此法则补全。

输入结构
- 网格被分隔线划分成等大的方形单元阵列。
- 第一行与第一列的单元是表头：每个表头装着一个由自身颜色构成的掩码，
  各表头颜色互不相同；左上角单元为空。
- 其余为内部单元：大多数已用统一的前景色画好图案，个别单元被整格
  填成灰色。

规则
- 对每个内部单元，取其所在行的行表头掩码与所在列的列表头掩码，
  逐格比较：恰有一方是前景的位置涂统一前景色，其余位置为背景。
- 已画好的内部单元全部满足该法则；把每个灰色单元替换为按同一法则
  算出的图案，其余保持不变。

关键洞察
- 这不是把表头复制进格子的表格，而是一张运算表：单元由两个表头
  逐像素异或生成；个别已填单元与"取并"的结果恰好一致，是诱饵，
  必须用其他单元排除"或"而确认"异或"。
```

## 3. 贯穿条截面还原隐形矩形

- 参考题目: `ecdecbb3`、`98c475bf`、`e76a88a6`
- tags:
  - operation:补全, reconstruct
  - object:贯穿条, full_span_bar
  - object:彩色线段, colored_segment
  - relation:截面即投影, cross_section_projection
  - condition:横竖联立定界, two_axis_constraints
  - condition:对象从未画出, object_never_drawn

### docstring

```text
条上的彩色段是隐形矩形被贯穿条切出的截面，联立横竖截面还原并画出每个矩形。

输入结构
- 背景上有若干完整贯穿网格的灰色横条与灰色竖条，间距不等。
- 部分条上出现整段连续的彩色像素替代了灰色；同一颜色的彩色段可能
  分布在多根条上。
- 每种颜色的彩色段至少出现在一根横条和一根竖条上；除条与彩色段外
  没有其他前景。

规则
- 对每种颜色：横条上该色段给出一段列范围，竖条上该色段给出一段行
  范围；同色各段给出的范围彼此一致。
- 该颜色对应一个实心矩形，上述行范围与列范围即其边界。
- 输出与输入同尺寸：先画出全部还原的实心矩形，再把所有贯穿条恢复
  为纯灰色压在矩形之上。

关键洞察
- 矩形从未被画出，画面上只有它与各条相交处留下的截面残迹；一根横条
  只给出列范围、一根竖条只给出行范围，必须两方向联立才能反求出完整
  矩形。
```

## 4. 收费站长龙：推挤、劈裂与扣件

- 参考题目: `9f669b64`、`a48eeaf7`、`28a6681f`
- tags:
  - operation:滑动, slide
  - operation:分裂, split
  - object:实心方块, solid_block
  - object:垂直细条, perpendicular_bar
  - object:网格边缘, grid_edge
  - relation:轴线排列, axis_arrangement
  - condition:连锁推挤, chain_push
  - condition:逐站扣件, toll_per_bar

### docstring

```text
推动者沿轴收集方块组成长龙，每穿过一根垂直细条就被扣下当时的队首方块，剩余队伍抵达网格边缘。

输入结构
- 背景上所有前景物体排在同一条水平或垂直轴线上。
- 轴线一端是一个颜色独特的实心推动者方块；沿其前进方向混杂分布着
  若干颜色互不相同的实心方块和若干长边垂直于轴线的灰色细条。
- 前进方向的尽头是网格边缘，且方块数量多于细条数量。

规则
- 推动者沿轴向前滑动，碰到实心方块就把它并入队伍，贴紧后一起继续
  前进，推动者始终在队尾。
- 队伍碰到垂直细条时：细条在与队伍截面等宽处劈开，此刻位于队首的
  那个方块被留在缺口正中不再前进，细条两半向外各让一格、与被扣
  方块保持分离；队伍其余部分越过该细条继续前进。
- 队伍最前端抵达网格边缘时全体停止。输出为所有物体的最终位置：
  每根细条的缺口中嵌着一个被扣的方块，剩余队伍（推动者殿后）紧贴
  网格边缘依次排列。

关键洞察
- 细条是收费站——每过一站扣掉当时的队首；哪个方块留在哪根细条、
  哪些方块到达边缘，取决于收集顺序与扣件顺序的整条因果链，任何单个
  物体的终点都无法孤立算出。
```

## 5. 色带图例与计数定深的图层合成

- 参考题目: `ea9794b1`、`08ed6ac7`、`25c199f5`
- tags:
  - operation:透明叠加, transparent_overlay
  - operation:计数, counting
  - operation:重涂色, recolor
  - object:面板, panel
  - object:色带图例, color_strip_legend
  - relation:数量排名映射层序, count_rank_to_depth
  - condition:少者在上, fewer_on_top
  - condition:色带自底向顶对应层序, strip_bottom_to_top_maps_layers

### docstring

```text
按前景像素数把四个面板排成图层叠加，覆盖关系由计数决定，各层重涂的颜色由一根竖直色带图例自底向顶给出。

输入结构
- 输入被分隔线分成四个等大的面板，每个面板恰含一种前景色的掩码，
  四个面板的前景像素数互不相同、颜色互不相同。
- 画面另有一根长度为四的竖直色带，四格颜色互不相同，与面板颜色无关。

规则
- 数出每个面板的前景像素数，从多到少排出层序：最多的在最底层，
  最少的在最顶层。
- 输出为单个面板大小：自底向顶依次把各掩码的前景位置盖上去，后盖
  的层覆盖先盖的层。
- 每层不保留原色：最底层涂色带最下端的颜色，向上依次对应，最顶层
  涂色带最上端的颜色。

关键洞察
- 要同时解释覆盖关系与输出颜色，必须发现两条互相独立又互相印证的
  隐藏对应——"像素越少的层越靠上"决定遮挡，色带自底向顶的顺序决定
  每层的新颜色；面板位置与原颜色都是无效线索。
```

## 6. 落水入盆按壁标循环染色

- 参考题目: `28a6681f`、`13e47133`
- tags:
  - operation:重力下落, gravity_drop
  - operation:重涂色, recolor
  - object:水像素, water_pixel
  - object:盆地, basin
  - object:标记像素, marker_pixel
  - relation:壁标序列即调色板, wall_markers_as_palette
  - condition:深度循环色带, cyclic_depth_bands

### docstring

```text
让悬空的水滴落进盆地堆积，再按盆壁标记自下而上读出的调色板给水体逐层循环染色。

输入结构
- 背景为黑色，灰色地形构成一个或多个开口向上的盆地。
- 盆地上空散布若干蓝色水像素。
- 每个盆地的一侧内壁上嵌着几个颜色互异的标记像素，自盆底向上排列，
  不同盆地的标记序列可以不同。

规则
- 每个水像素竖直下落，被挡住时沿唯一空出的斜向格滑动，直到落进
  盆地并逐格堆满最低的可用位置；所有水都落定后得到各盆地的水体。
- 对每个盆地，把内壁标记按所在行自下而上读出，得到该盆地的调色板。
- 水体自盆底起第 d 层（d 从 0 计）整层涂调色板中第 d mod 调色板长度
  项的颜色；地形与标记保持不变。

关键洞察
- 蓝色只是水的临时身份：水量决定层数，而每层的最终颜色由盆壁标记
  序列循环给出——标记不是要移动的对象，而是嵌在墙里的调色板图例。
```
