## 1. 隐形锚点回收

- 参考题目题号: `9f5f939b`(032-10), `f28a3cbb`(032-5), `42a50994`(032-1)
- tags:
  - operation:压缩, compact
  - operation:擦除, erase
  - object:微型条, micro_bar
  - object:隐含十字中心, implied_plus_center
  - object:孤立像素, isolated_pixel
  - relation:视线归属, sightline_membership
  - condition:十字完整性定去留, completeness_decides

### docstring

```text
把散落的前景像素沿视线回收到从未画出的十字中心旁，只有完整的十字才有吸引力。

输入结构：
- 黑色背景，前景只有一种颜色。
- 前景含若干 1×2 双像素条：其中一部分以"上下左右各距一个空心中心 2 至 3 格、
  且与中心之间留一格空隙"的方式，四条一组围出隐含的十字中心；另有恰好缺一条
  （只有三条）的不完整十字。
- 其余前景是孤立散点，每个散点恰好落在唯一一个（完整或不完整）十字中心所在的
  行或列上，位于对应方向条的外侧远处。

规则：
- 找出所有由四条双像素条围成的完整十字中心（中心本身始终是背景，画面上从未出现）。
- 与完整十字中心共行或共列的散点，沿该视线向中心滑动，依次紧贴对应方向条的外端
  连续排列（相当于把条向外延长若干格）；同一侧多个散点按靠近中心者优先的顺序
  紧密堆叠。
- 与不完整十字（三条）对位的散点全部擦除为背景。
- 所有条、中心格及中心四邻的空隙格保持不变。

关键洞察：
- 散点的吸引锚从未被画出：它是四条双像素条围出的缺失中心；条既是推断中心的
  生成元，又是散点压缩时的停靠壁。是否"回收"取决于十字的完整性——缺一条的
  十字不具吸引力，其视线上的散点只是应清除的噪声。
```

## 2. 噪点是旋钮

- 参考题目题号: `42a50994`(032-1), `d753a70b`(032-8)
- tags:
  - operation:收缩, shrink
  - operation:膨胀, dilate
  - operation:擦除, erase
  - object:方框轮廓, square_outline
  - object:孤立像素, isolated_pixel
  - relation:计数定层数, count_sets_steps
  - condition:内外定方向, inside_outside_sign

### docstring

```text
每个空心方框按同色孤立像素的数量伸缩相应层数，方向由这些像素在框内还是框外决定。

输入结构：
- 单色背景上有若干一格厚、互不接触的空心正方形框，各框颜色互不相同。
- 另散布若干孤立单像素，每个孤立像素的颜色与某个框相同；同色孤立像素要么全部
  位于该框内部，要么全部位于该框外部。
- 部分框没有任何同色孤立像素。

规则：
- 对每个框统计同色孤立像素个数 k：像素在框内则框以同一中心向内收缩 k 层
  （每层边长减 2），像素在框外则向外膨胀 k 层（每层边长加 2）。
- k=0 的框保持原样。
- 输出中所有孤立像素擦除为背景。
- 输入保证伸缩后各框仍完整落在画布内、互不接触，且收缩后边长至少为 3。

关键洞察：
- 孤立像素不是待清除的噪声，而是每个框的控制参数：数量给出伸缩层数，内外位置
  给出伸缩方向；"擦除"只是参数被消耗后的表象。只看含 k=0 框与少量散点的局部，
  会误判为纯噪声清除题。
```

## 3. 让标签成真

- 参考题目题号: `9ddd00f0`(032-18), `e9c9d9a1`(032-11)
- tags:
  - operation:搬移, relocate
  - object:分隔线网格, separator_grid
  - object:带孔色块, holed_block
  - relation:孔洞即地址, hole_as_address
  - condition:搬迁后自洽, self_consistent_after_move

### docstring

```text
把每个带孔色块搬到孔洞坐标所指的单元格，使所有孔洞标签变为真。

输入结构：
- 绿色分隔线把画布划分为 n×n 个 n×n 的单元格（n 为 3 或 4）。
- 部分单元格内含一个实心彩色 n×n 块，块内恰有一个背景色孔洞；孔洞在块内的
  局部坐标 (r,c) 是一个阵列地址。
- 输入保证各块的地址互不相同，且这些地址恰好构成这些块所占单元格集合上的
  一个排列（允许不动点）。

规则：
- 每个块整体搬入其孔洞坐标 (r,c) 所指的单元格，孔洞相对块的位置保持不变；
  分隔线保持不动。
- 孔洞坐标恰好等于自身单元格坐标的块保持不动。
- 搬迁彼此成环时同时完成，互不覆盖；未涉及的单元格保持背景。

关键洞察：
- 孔洞不是缺损而是地址标签，输出是使每个标签"变为真"的唯一重排：搬迁完成后，
  每个块的孔洞坐标都恰好等于它所在单元格的坐标。诱饵在于不动点——若某示例中
  多数块恰好已在其地址上，会误以为孔洞只是位置的自洽记号、输入即输出。
```

## 4. 撞墙右转的印章

- 参考题目题号: `d304284e`(032-17), `88bcf3b4`(032-14), `1190bc91`(032-7)
- tags:
  - operation:印章覆盖, stamping
  - operation:转向, turn
  - object:精灵体, sprite
  - object:墙壁像素, wall_pixel
  - relation:碰撞触发转向, collision_triggers_turn
  - condition:转向次数定色, turn_count_colors

### docstring

```text
精灵沿直线等距盖章，撞到墙、画布边缘或自己的旧印时顺时针转向并换色，直到无处可盖。

输入结构：
- 黑色背景上有一个单色前景精灵（8 连通，带紧致包围盒），以及若干灰色墙壁像素
  或墙块。
- 精灵与墙互不接触。

规则：
- 从原精灵出发向右，每隔"精灵宽+1"列放一个印章副本；副本以包围盒对齐，
  掩码不旋转。
- 若下一槽位越出画布，或其掩码将覆盖任何墙像素或已画前景像素，则该槽不放置，
  改从最后一个成功放置的副本处顺时针转向（右→下→左→上→右……），沿新方向
  以对应间距（竖向为"精灵高+1"行，横向为"精灵宽+1"列）继续放置。
- 副本颜色由已发生的转向次数决定：第 0 段沿用原精灵色，第 1 段粉色，
  第 2 段红色，第 3 段黄色，之后四色循环。
- 刚转向后的第一个槽位仍无法放置时立即再次转向；连续四次转向都无法放置则链终止。
- 原精灵与所有墙像素保持不变。

关键洞察：
- 墙不是要避开的静物而是转向开关；链条后期还会被自己早先的印章挡住而继续转弯，
  路径呈向内收拢的螺旋。颜色不是位置的固定节律，而是"已转向次数"的计数器——
  只看第一段会误判为普通的周期印章题。
```

## 5. 谁多谁先画

- 参考题目题号: `1d61978c`(032-15), `1190bc91`(032-7)
- tags:
  - operation:射线延伸, ray_extend
  - operation:重涂色, recolor
  - object:对角线段, diagonal_bar
  - relation:种群定次序, population_orders
  - condition:先画者遮挡后画者, earlier_occludes_later

### docstring

```text
两种朝向的对角短条先后向两端延伸并互相遮挡，先后次序由像素多数决定，最后按朝向染色。

输入结构：
- 黑色背景，前景仅一种颜色，全部是一格厚的对角短条，只有 ↘ 与 ↗ 两种朝向。
- 输入保证同朝向的条互不共对角线，且两朝向的像素总数不同。

规则：
- 统计两种朝向的像素总数，总数多的朝向为先手。
- 先手朝向的每条从两端沿自身对角方向延伸，遇画布边缘停止，或在即将踏上任何
  已有前景像素的前一格停止。
- 然后后手朝向的条同样延伸，但会被先手的原条与其延伸共同阻挡。
- 输出把先手朝向的条与延伸全部染青色，后手的条与延伸染红色，背景不变。

关键洞察：
- 延伸的先后次序不是固定方向的约定，而是由两个朝向的像素种群多数临场决定；
  后手射线被先手网格截断的残缺形态正是次序的证据。仅凭单个示例容易误判为
  "某个固定朝向总是先画"。
```

## 6. 大图小图互相搭救

- 参考题目题号: `ce602527`(032-12), `db0c5428`(032-16)
- tags:
  - operation:补全, complete
  - operation:旋转对齐, rotation_align
  - object:块拼图, block_mosaic
  - object:缩略图, miniature
  - relation:跨尺度互引用, cross_scale_mutual_reference
  - condition:旋转角需推断, rotation_inferred

### docstring

```text
一幅块拼图与它的旋转缩略图各缺一处，先推断旋转角，再让两者互相修补。

输入结构：
- 背景上分离放置两个矩形区域：大图由 n×n 个 k×k 单色色块拼成，小图为 n×n 像素。
- 小图是大图按 90°、180° 或 270° 之一旋转后的逐块缩影：小图第 (i,j) 像素的颜色
  等于大图对应块的颜色。
- 大图恰有一个色块整块缺失（呈背景色），小图恰有一个像素缺失；两处缺失经旋转
  对应后位置不同。
- 输入保证可见部分只与唯一一个旋转角完全吻合。

规则：
- 用可见的块与像素找出唯一自洽的旋转角。
- 按该对应关系，用小图对应像素的颜色把大图缺失块整块填实，用大图对应块的颜色
  填补小图缺失像素。
- 其余一切保持不变。

关键洞察：
- 两个表示互为参照，没有哪一方是完整的"原本"，修复必须双向进行；而对应关系
  本身也是隐藏的——旋转角只能从两处残缺之外的重叠证据中反推。0° 不在候选之列，
  直接按原位对照会在每个示例上失败。
```

## 7. 溢流接力

- 参考题目题号: `e45ef808`(032-2), `78e78cff`(032-3)
- tags:
  - operation:填充, fill
  - operation:连锁溢流, cascade_overflow
  - object:地形轮廓, terrain_contour
  - object:单点标记, singleton_marker
  - relation:矮沿定水位, lower_rim_sets_level
  - condition:溢流方向逐段比较, spill_direction_by_comparison

### docstring

```text
水从标记列注入脚下的盆地，每个盆地灌到较矮界峰的高度后向矮的一侧溢出，
接力灌满下游盆地，直到从画布边缘流走。

输入结构：
- 每列自底部起有一段连续的灰色地形柱，柱高起伏形成若干峰与盆地（盆地由相邻
  两峰之间的低洼列组成，这两峰即其左右界峰）；地形上方为黑色背景。
- 空中恰有一个红色标记像素，位于某个盆地上空；标记列正下方即注水入口。
- 输入保证每个被水经过的盆地左右界峰高度不同，溢流链上每个后继盆地的远侧界峰
  都矮于来水翻越的界峰（水只向前不回灌），且链最终到达画布某一侧边缘。

规则：
- 水注入标记列所在的盆地；该盆地内高于地形顶面、且不高于其较矮界峰顶行的
  所有格填为蓝色。
- 灌满后水越过较矮界峰，流入其另一侧的下一个盆地，按同一规则继续灌注；
  若较矮的一侧是画布边缘，水直接流走，该处不留水色。
- 途中翻越的峰顶正上方不留水色；红色标记与灰色地形保持不变。

关键洞察：
- 标记只指定入口；真正决定输出的是地形的峰谷序列——每个盆地的水位由较矮界峰
  决定，两峰高低的比较又决定溢流方向，多个盆地被串成一条单向的因果链。诱饵是
  以为只有标记正下方的一个盆地有水，而实际水色一路延伸到画布边缘一侧。
```
