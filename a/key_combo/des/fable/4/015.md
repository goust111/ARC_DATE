## 1. 簇长定旋

- tags:
  - operation:印章覆盖, stamp
  - operation:旋转, rotate
  - operation:计数, counting
  - object:精灵体, sprite
  - object:标记条, marker_bar
  - relation:中心对齐, center_align
  - condition:条长编码旋转档位, bar_length_encodes_rotation
  - condition:条向决定旋向, bar_orientation_sets_spin
- 参考题目: `1b59e163`、`88a10436`、`985ae207`、`dc2aa30b`

### docstring

```text
把唯一的彩色精灵旋转后盖印到每根灰色标记条上，条的长度与走向共同决定旋转角与旋向。

输入结构
- 背景为黑色，网格中有一个奇数×奇数包围盒的单色精灵，形状无旋转对称。
- 其余前景是若干条互相分离的灰色直条，长度为 1 至 4，走向为水平或竖直。

规则
- 保留原精灵不动。
- 对每根灰条，设其长度为 k：水平条把精灵顺时针旋转 (k-1)×90°，竖直条把精灵逆时针旋转 (k-1)×90°。
- 把旋转后的精灵以包围盒中心对齐到该条最靠上、最靠左的端点格盖印，然后擦除整根灰条。

关键洞察
- 灰条既不是障碍物也不是复制次数，它是一只旋钮：长度给出旋转档位，走向给出旋转方向；长度为 1 的条两种读法一致，恰好退化为原样复制。
```

## 2. 独子算符

- tags:
  - operation:布尔叠加, boolean_overlay
  - operation:忽略干扰, ignore_distractor
  - object:面板, panel
  - object:独子像素, singleton_pixel
  - object:分隔列, separator_column
  - relation:对齐, alignment
  - condition:标记色选算符, marker_color_selects_operator
  - condition:输出用标记色, output_in_marker_color
- 参考题目: `e345f17b`、`99b1bc43`、`0ca9ddb6`、`50f325b5`

### docstring

```text
找到全图唯一只出现一次的独子像素，它的颜色指定两块面板的叠加算符，输出用它的颜色作画。

输入结构
- 一条灰色整列把网格分成左右等宽的两块黑底面板，各含一种前景色的掩码。
- 网格中恰有一个像素，其颜色与两面板前景色、分隔色、背景色都不同，且全图仅出现一次；它可以落在任意一块面板内部。

规则
- 把独子像素视为背景，得到两面板的前景掩码并逐格对齐。
- 按独子颜色选择判定：红色选恰有一侧是前景的格；蓝色选两侧都是前景的格；黄色选两侧都是背景的格。
- 输出一块面板大小的黑底网格，把选中的格全部涂成独子颜色。

关键洞察
- 那个多出来的像素同时扮演两个角色：作为杂质必须先从掩码里剔除，作为指令又决定整题的叠加逻辑与输出用色。
```

## 3. 隔空点环

- tags:
  - operation:重涂色, recolor
  - operation:视线匹配, sightline_matching
  - object:实心矩形, solid_rectangle
  - object:标记像素, marker_pixel
  - relation:边距深度, edge_distance_depth
  - condition:间距编码层深, gap_encodes_depth
- 参考题目: `696d4842`、`516b51b7`

### docstring

```text
每个游离标记隔着一段空隙正对某个实心矩形，空隙长度指定矩形内部哪一圈同心层被染成标记色。

输入结构
- 黑底网格上有若干互不相邻的实心单色矩形。
- 另有若干单像素标记，每个标记沿所在行或列隔着 g≥1 个连续背景格正对唯一一个矩形的边，且该矩形第 g 层存在。

规则
- 把矩形最外圈记作第 0 层，向内每进一圈层数加一。
- 对每个标记，量出它与矩形边之间的背景空隙长度 g，把该矩形第 g 层整圈重涂为标记色。
- 擦除所有标记；同一矩形可被多个标记染出多圈，其余像素保持不变。

关键洞察
- 标记与矩形之间的距离不是要填的通道，而是一把尺子：外部隔几格，就在内部数几层——沿直线量出的数被读成同心深度。
```

## 4. 负形寻踪

- tags:
  - operation:模板匹配, template_matching
  - operation:重涂色, recolor
  - operation:擦除, erase
  - object:空腔, cavity
  - object:连通体, connected_object
  - relation:互补掩码, complement_mask
  - condition:含旋转反射变换, includes_rotation_reflection
  - condition:忽略干扰项, ignore_distractors
- 参考题目: `50f325b5`、`0692e18c`、`2a5f8217`

### docstring

```text
实心色块内部挖掉的那个洞才是模板，把场上与洞形相同的绿色连通体染成色块色，其余绿色全部清除，并把洞补平。

输入结构
- 黑底网格上有一个颜色为 C 的实心矩形块，其内部严格包含一个背景色空腔（4 连通的小洞）。
- 其余前景全是绿色像素，构成若干彼此分离的 8 连通小组件；其中有些干扰组件与空腔像素数相同但形状不同。

规则
- 取空腔在其包围盒内的归一化形状作为模板，枚举其全部旋转与反射变体。
- 逐个组件比对：形状与某个变体完全一致的组件整体重涂为 C；不一致的组件全部擦成背景。
- 最后把空腔本身用 C 填平，矩形块其余部分不变。

关键洞察
- 要找的形状从未作为前景画出，它只以缺口的形式存在；解题的第一步是把注意力从画上的东西移到被挖掉的东西上。
```

## 5. 现场码表

- tags:
  - operation:解码指令, decode_instructions
  - operation:连线, draw_path
  - object:图例对, legend_pair
  - object:分隔列, separator_column
  - object:起始标记, start_marker
  - relation:位移向量, displacement_vector
  - relation:顺序读取, sequential_reading
  - condition:场内自学映射, learn_map_from_grid
- 参考题目: `136b0064`、`b4a43f3b`、`d06dbe63`

### docstring

```text
左半图用彩点—灰点演示对现场定义每种颜色的位移向量，右半图按程序行逐色执行，从起点画出落点轨迹。

输入结构
- 一条整列分隔线把网格分成左右两个黑底面板。
- 左面板散布若干演示对，每对由一个彩色像素和一个灰色像素组成、彼此靠近；不同对之间相隔很远、颜色互不相同，配对无歧义。
- 右面板顶行从左到右排着一串程序色块，下方空旷处有一个灰色起点像素。

规则
- 对每个演示对，从彩色像素指向灰色像素的行列偏移就是该颜色的位移向量。
- 输出只保留右面板：清空顶行程序，从起点出发按程序顺序逐色移动，每执行一步就把落点格涂成该步的颜色。
- 起点保持灰色；中途不画连线，只标各步落点。

关键洞察
- 颜色到位移的码表不写在规则里，而藏在图里：左面板那些像噪声的点对，正是当场颁布的指令字典。
```

## 6. 层数选形

- tags:
  - operation:描边, mark_neighbors
  - operation:计数, counting
  - object:空心框, hollow_frame
  - object:标记像素, marker_pixel
  - relation:嵌套包含, nesting_containment
  - condition:奇偶选邻域几何, parity_selects_neighborhood
  - condition:断框不计, broken_frame_excluded
- 参考题目: `0ca9ddb6`、`516b51b7`、`50f325b5`

### docstring

```text
数出每个红点被多少个闭合框包住，按层数的奇偶给它长出对角或十字光晕，一层未包的点保持沉默。

输入结构
- 黑底网格上有若干青色矩形框：一部分是闭合的空心矩形，可互相嵌套或并列；另一部分缺了一段口子，看似框却包不住东西。
- 其余前景是若干孤立红色像素，散落在不同的嵌套深度上。

规则
- 对每个红点，统计严格包含它的闭合框个数，缺口框不计。
- 层数为奇数：把它四个对角邻格中的背景格涂黄；层数为正偶数：把它四个正交邻格中的背景格涂橙。
- 层数为零的红点不产生任何标记；框与红点本身保持不变。

关键洞察
- 选择邻域几何的不是红点的颜色，而是它的拓扑处境——被包围的层数；而判断包围必须先识破那些开口的假框。
```

## 7. 偏移即微缩位移

- tags:
  - operation:平移, translate
  - object:标记点阵, marker_lattice
  - object:精灵体, sprite
  - object:格元, lattice_cell
  - relation:格元内偏移, in_cell_offset
  - condition:偏移向量微缩位移, offset_encodes_scaled_displacement
  - condition:落点居中放置, center_placement
- 参考题目: `20981f0e`、`88a10436`、`136b0064`

### docstring

```text
点阵把画布划成等大格元，格元内精灵偏离中心的向量是它在格元尺度上要走的位移的等比微缩，方向与距离都从这份歪里读出。

输入结构
- 一种前景色构成完整规则的孤立标记点阵，划分出等大的方形格元，格元内部为奇数边长。
- 部分格元中各有一个小精灵，精灵的包围盒中心要么与格元中心重合，要么沿上下左右某一方向偏离中心 1 格或 2 格，恰有一维偏移为零。

规则
- 居中的精灵原地不动。
- 偏离的精灵设其偏移向量非零分量的绝对值为 m，则整体沿偏移方向移动 m 个格元，并在落点格元内居中放置，原位置清空。
- 点阵保持不变；落点格元保证原本为空且在阵内。

关键洞察
- 格元内的微小偏移是格元间宏观位移的缩小副本——偏几格就走几个格元，往哪偏就往哪走；居中只是到站后的落座姿势，而恰好居中的精灵是引人误读成全部居中归位的诱饵。
```
