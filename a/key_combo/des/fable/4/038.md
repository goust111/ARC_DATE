## 1. 破壁壁纸

- 参考题目题号：1、14、17
- tags:
  - operation:平铺, tile
  - operation:周期推断, period_inference
  - object:缺口矩形框, one_gap_rect_frame
  - object:重复瓦片, repeating_tile
  - relation:缺口定延伸向, gap_determines_extension
  - condition:相位穿框连续, phase_continuous_under_frame

### docstring

```text
把框内壁纸沿唯一缺口的方向整带外溢平铺到网格边缘，且相位按"图案在框下连续"计算。

输入结构：
- 网格有统一背景色；画面上有一个一格厚的单色矩形框，框某条边的非角位置恰缺一个像素。
- 框内部完整填有一幅多色壁纸图案，其行列周期均明显小于内部尺寸，每个周期相位在框内至少完整出现两次。
- 框外全部是背景。

规则：
- 缺口所在边的外法向即延伸方向。
- 延伸条带为与框内部在垂直于延伸方向上对齐、等宽的所有框外背景格，从框外一直到网格边缘。
- 将壁纸按其行列周期延拓填入条带与缺口像素本身；延拓相位以框内图案为基准，并把框的一格厚度计入坐标——图案在框体之下连续通过，框外第一线的相位等于框内最后一线再隔一线的相位。
- 框的其余像素与另三侧背景保持不变。

关键洞察：
- 缺口不是一条射线的出口，而是指明整幅壁纸泄漏方向的指针。
- 框是盖在连续壁纸上的遮挡物：外溢图案的相位必须跳过框厚计算，把框内末线逐行顺接到框外会恰好错一个相位。
```

## 2. 罗盘调色条

- 参考题目题号：15、20
- tags:
  - operation:重涂色, recolor
  - operation:排序, sort
  - operation:擦除, erase
  - object:孤立像素, isolated_pixel
  - object:调色条, palette_bar
  - relation:条向定扫描序, bar_orientation_determines_scan
  - condition:锚点定相位, anchor_fixes_phase
  - condition:颜色循环分配, cyclic_color_assignment

### docstring

```text
按贴边彩条的朝向确定散点扫描序，并以唯一锚点对齐相位后循环涂上彩条的颜色序列。

输入结构：
- 黑色背景上有一条长度至少为三、紧贴网格某条边的彩色条，条内各格颜色构成一个有序序列，序列中可含重复色。
- 背景上另散布若干孤立像素；其中恰有一个像素的颜色出现在彩条中，且该颜色在条中只出现一次；其余散点的颜色均不属于条的颜色集合。

规则：
- 彩条水平放置时，散点按行主序（自上而下、行内自左而右）排列；竖直放置时按列主序（自左而右、列内自上而下）排列。
- 彩条颜色序列的读向：水平条自左向右，竖直条自上而下。
- 把条的颜色序列沿散点排列循环分配；循环相位由锚点唯一确定——颜色出现在条中的那个散点必须恰好分到它自己原有的颜色。
- 输出中彩条整体擦为背景，所有散点改为分配到的颜色，其余保持不变。

关键洞察：
- 彩条一身三职：朝向是扫描罗盘，内容是调色序列，而循环起点不能默认从第一个散点配第一个颜色，必须用唯一锚点反推相位。
- 散点自身的颜色几乎全是诱饵，唯一携带信息的是那颗与条同色的锚。
```

## 3. 补角选装

- 参考题目题号：3、10、12
- tags:
  - operation:重涂色, recolor
  - operation:擦除, erase
  - object:同色标记对, same_color_marker_pair
  - object:同形副本, identical_copies
  - relation:对角补角, complementary_corner
  - relation:补角选副本, corner_selects_copy
  - condition:退化对无效, degenerate_pair_void
  - condition:未选中擦除, unselected_erased

### docstring

```text
每对同色标记张成一个隐形矩形，其两个空缺角中命中灰色副本的那个角点名该副本换上标记色，其余副本消失。

输入结构：
- 背景网格内部散布多个同形状的灰色小图案副本，互不重叠。
- 另有若干彩色标记像素，每种颜色恰出现两枚，位于网格任意位置且不落在副本上。
- 多数颜色的两枚标记不同行不同列；它们张成的隐形矩形的另外两个角（补角）中，恰有一个落在某个灰色副本的格子上，不同颜色命中不同副本。
- 个别颜色的两枚标记同行或同列（矩形退化），不命中任何副本；另有一些副本不被任何补角命中。

规则：
- 对每个非退化同色对，取两标记 (r1,c1)、(r2,c2) 张成矩形的两个补角 (r1,c2) 与 (r2,c1)；落在灰色副本上的那个补角选中该副本，把副本整体染成标记色。
- 同行或同列的退化对不选中任何副本。
- 未被任何补角选中的灰色副本整体擦为背景；所有标记像素也擦为背景。

关键洞察：
- 矩形从未被画出：两枚标记只是它的一条对角线，真正起作用的是画面上从未出现的另外两个角。
- 第一反应的"连线、中点、包围盒"都会被示例否定；副本命运二分——被点名的换装、无人点名的消失，还须识破退化对诱饵。
```

## 4. 剔相条纹

- 参考题目题号：10、14、17
- tags:
  - operation:周期推断, period_inference
  - operation:射线延伸, ray_extend
  - operation:擦除, erase
  - object:矩形边框, rectangular_frame
  - object:周期条纹, periodic_stripe
  - object:标记像素, marker_pixel
  - relation:周期掩码, periodic_mask
  - condition:标记取消相位线, marker_cancels_phase_line

### docstring

```text
把框内的周期条纹按周期投影到整幅画布，但被外部标记点名的相位整线取消。

输入结构：
- 一格厚的矩形框内部含有沿同一方向、等间隔分布的若干条整行（或整列）条纹，条纹色与框色不同，其余内部为背景。
- 框外背景上散布若干枚第三色标记像素；每枚标记都恰好位于条纹按周期延拓后会经过的某条框外新线上（不与任何框内已有条纹共线），且这些被点名的线各不相同。

规则：
- 由框内条纹推断方向、周期与相位，把该等差行（列）族延拓到整幅网格，得到全部候选线。
- 删除所有含标记像素的候选线；其余候选线在整幅网格上染成条纹色，但只改写背景格，框像素保持原色。
- 所有标记像素擦为背景。

关键洞察：
- 标记既不是要保留的对象也不是噪声，而是逐线的取消码。
- 必须先在头脑中完成全域周期延拓，才能解释标记为什么恰好都落在"尚未画出"的线上——它们点名的是未来的条纹。
```

## 5. 影子拼合

- 参考题目题号：2、9、15、17
- tags:
  - operation:重建, reconstruct
  - operation:补全, complete
  - object:残缺副本, partial_copies
  - object:锚点像素, anchor_pixel
  - relation:锚点对齐叠合, anchor_alignment_union
  - condition:互补覆盖, complementary_coverage

### docstring

```text
以锚点像素对齐叠合所有残缺副本，重建从未现身的完整模板，再用各自的颜色把每个残片补全。

输入结构：
- 背景上散布若干个单色"残片"，颜色互不相同，它们都是同一个隐藏模板形状的不同残缺版本，缺失部分各不相同。
- 每个残片都含一枚固定锚色的锚点像素；锚点在隐藏模板中的位置固定且在任何残片中都不缺失。
- 按锚点对齐后，所有残片存在部分的并集恰好覆盖完整模板。
- 残片外形上可能含有局部对称或重复的花纹，仅靠轮廓相互套叠会产生歧义，锚点是唯一可靠的对齐基准。

规则：
- 以各残片的锚点像素为共同原点对齐叠合，取形状并集，得到完整模板。
- 在每个残片的原位置按锚点对齐，补上该残片相对完整模板缺失的格子，补色使用该残片自身的颜色。
- 锚点像素保持锚色不变，背景其余部分不变。

关键洞察：
- 完整形状从未在画面中出现，它只存在于所有残缺副本的并集之中。
- 每个残片既是求解材料又是被修复对象——信息互补，缺谁都拼不完整；没有锚点这一坐标基准，叠合本身就无从谈起。
```

## 6. 按数取物

- 参考题目题号：6、9、19、20
- tags:
  - operation:计数, counting
  - operation:裁剪, crop
  - object:空心形状, hollow_shape
  - object:内腔精灵, cavity_sprite
  - object:孤立像素, isolated_pixel
  - relation:计数选腔, count_selects_cavity
  - relation:两跳指针, two_hop_pointer
  - condition:扣除藏品面积, sprite_area_excluded

### docstring

```text
腔外散点的个数指认内腔剩余面积与之相等的空心形状，输出藏在该腔中的小精灵。

输入结构：
- 背景上有若干颜色互异的空心封闭形状，每个恰围住一块4连通的背景内腔。
- 每个内腔中藏着一个小的彩色精灵，颜色异于形状色与散点色，且不接触腔壁。
- 各内腔的剩余背景格数（扣除腔内精灵占格后）互不相同；同时另有某个形状，其内腔总格数（不扣精灵）恰好也等于散点数，构成选错门的陷阱。
- 背景上另散布若干枚同色孤立散点，均不落在任何内腔中。

规则：
- 统计腔外散点的个数 n。
- 找出内腔剩余背景格数恰好等于 n 的形状；腔内精灵占的格子不计入面积。
- 输出该腔中精灵的包围盒裁剪，其余一概舍弃。

关键洞察：
- 散点是计数钥匙，但它指向的不是形状本身而是腔中藏品——这是一次两跳指针。
- 计的是腔中"剩余负空间"：藏品自身占的格子必须扣除，按内腔总面积去配对会恰好走进另一扇错门。
```
