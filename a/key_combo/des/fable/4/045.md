## 1. 游程异常压缩

- 参考题目: `ce8d95cc`, `6773b310`
- tags:
  - operation:压缩, compression
  - operation:重涂色, recolor
  - object:重复行, dup_row
  - object:重复列, dup_column
  - relation:游程宽度信道, run_width_channel
  - condition:行列异常交点标记, anomaly_intersection_mark

### docstring

```text
把双向游程拉伸的图案压缩回原型,并只在行、列拉伸倍率同时异常的交点处改涂红色。

输入结构:
- 网格是一幅小图案沿行、列两个方向做游程扩展的结果:原型的每一行被复制成一条行带,每一列被复制成一条列带。
- 原型中相邻的行互不相同、相邻的列互不相同,且原型不含红色。
- 绝大多数行带和列带的宽度等于同一个基准倍率,少数行带或列带的宽度偏离基准。

规则:
- 合并相邻的相同行与相同列,得到压缩原型;每条行带、列带在原型中对应一行、一列。
- 统计全部行带与列带的宽度,取出现次数最多的宽度为基准倍率。
- 仅当一格同时位于宽度异常的行带与宽度异常的列带所对应的行与列上时,把该格改涂红色;其余格保持压缩后的颜色。

关键洞察:
- 压缩只是表层任务,拉伸倍率本身是隐藏信道;单侧异常不留痕迹,只有行、列异常相交的格子才携带信号。
```

## 2. 残迹双轴

- 参考题目: `4938f0c2`, `6d75e8bb`
- tags:
  - operation:镜像, mirror
  - operation:对称补全, symmetry_completion
  - object:残缺副本, partial_copy
  - relation:翻折对应反推轴位, residue_infers_axis
  - condition:复合副本无中生有, composed_copy_from_nothing

### docstring

```text
红色原形关于两条从未画出的镜轴各留下一份残缺翻折副本,反推轴位并补全两份副本,再画出经两轴复合的第四份副本。

输入结构:
- 黑色背景上有一个完整的红色任意形状(非对称)。
- 一份蓝色残迹:红形关于某条隐形水平轴翻折后被擦去若干格的残缺副本。
- 一份绿色残迹:红形关于某条隐形竖直轴翻折后被擦去若干格的残缺副本。
- 两条轴与任何位置标记都不在画面上;残迹各自保留的格子足以唯一确定对应轴;四个图形互不重叠。

规则:
- 把蓝色残迹与红形按竖直翻转关系逐格配对,反推出水平镜轴的行位;把绿色残迹与红形按水平翻转关系配对,反推出竖直镜轴的列位。
- 将蓝、绿副本补全为红形的完整翻折像。
- 再关于两轴依次翻折(等价于绕两轴交点旋转 180°),在对应位置画出完整的黄色第四副本;输出保留红形。

关键洞察:
- 镜轴的生成元不是任何标记,而是残迹与原形之间的翻折对应关系;黄色副本在输入中毫无踪迹,只有真正解出两条轴的交点才能落笔。
```

## 3. 双重负空间

- 参考题目: `f1bcbc2c`, `42f14c03`
- tags:
  - operation:膨胀求交, dilate_intersect
  - operation:重涂色, recolor
  - operation:擦除, erase
  - object:通道, channel
  - object:带孔钥匙块, keyed_block_with_hole
  - relation:孔洞形状匹配, hole_shape_matching
  - condition:忽略外形干扰, ignore_outline_distractors

### docstring

```text
成对灰色物体之间的一格宽空隙要用彩色钥匙块认领上色,但钥匙的匹配键不是它的外形,而是它内部孔洞的形状。

输入结构:
- 黑色背景上若干对灰色物体成对放置,每对之间隔着一格宽的背景空隙,对与对之间相距较远。
- 另有若干带孔的实心彩色块散布在空白处:每块内部有一个背景色孔洞。
- 一部分钥匙块的孔洞形状与某条空隙平移全等(不旋转不翻转);其余钥匙块以及所有钥匙块的外轮廓形状都是干扰项。

规则:
- 对每一对灰色物体,把两者各自向八邻域膨胀一格并取交集,得到它们之间一格宽的通道形状。
- 若某个钥匙块的孔洞与该通道平移全等,把通道格子涂成该钥匙块的颜色。
- 输出中抹去所有钥匙块;没有匹配孔洞的通道保持背景色;灰色物体原样保留。

关键洞察:
- 参与匹配的两个形状在输入中都未被直接画出——通道是物体光晕交集的负空间,匹配键是钥匙内部的负空间;拿钥匙外形去匹配是刻意留下的歧途。
```

## 4. 层序轮转

- 参考题目: `83eb0a57`, `6d75e8bb`
- tags:
  - operation:透明叠加, transparent_overlay
  - operation:补全, complete
  - object:矩形, rectangle
  - relation:边界框推断, bbox_inference
  - relation:遮挡定序, occlusion_ordering
  - condition:层序循环移位, layer_cyclic_shift

### docstring

```text
从互相遮挡的实心矩形中推断出完整的上下层全序,再把层序循环移位——最顶层沉底、其余各升一层——重新绘制。

输入结构:
- 黑色背景上有若干实心单色矩形,颜色互不相同。
- 每个矩形至少部分可见,可见像素的包围盒等于其完整范围。
- 层序中相邻的任意两个矩形都有重叠区域,保证全序可从遮挡关系唯一推出。

规则:
- 由每种颜色可见像素的包围盒恢复矩形的完整位置与尺寸。
- 对每对重叠矩形,重叠区显示谁的颜色谁就在上,由此汇总出唯一的上下全序。
- 将全序循环移位:原最顶层放到最底,其余每层上移一位;按新序自底向顶在空画布上重绘所有完整矩形。

关键洞察:
- 输入的层序从未显式给出,必须由每处重叠的可见颜色拼出全序;诱饵是简单反转或保持层序,而轮转要求对全序的完整重构,任何一处推错都会在输出中留下痕迹。
```

## 5. 宽度指针

- 参考题目: `a3f84088`, `b7256dcd`
- tags:
  - operation:同心层填充, concentric_fill
  - operation:重涂色, recolor
  - object:空心矩形, hollow_rectangle
  - object:种子像素, seed_pixel
  - relation:宽度作指针, width_as_pointer
  - condition:自家种子是诱饵, own_seed_decoy

### docstring

```text
每条环带整体涂色,但颜色不取自己内部的种子,而取"以自己宽度为序号"的那条环带内的种子颜色。

输入结构:
- 黑色背景上有一组同心的一格厚灰色矩形框,相邻框四边间距相等;相邻框之间的区域为环带,从最外圈到最内圈依次编号 1,2,3,…。
- 每条环带的黑色区域内恰有一枚彩色种子像素,颜色互不相同且不含灰色。
- 每条环带的宽度都不超过环带总数;至少存在一条环带其宽度不等于自身序号。

规则:
- 从外到内给环带编号,并测量各环带宽度。
- 序号为 d、宽度为 w 的环带,整体涂成序号为 w 的那条环带中种子像素的颜色;原种子像素一并被覆盖,整条环带同色。
- 灰色框保持原样,最外框以外与最内框以内保持黑色。

关键洞察:
- 种子颜色与它所在的环带无关——宽度是把每条环带重定向到另一条环带的指针;"各带涂自家种子"是第一眼的诱饵,它只在宽度恰好等于自身序号的不动点环带上碰巧成立。
```

## 6. 姿态搬运

- 参考题目: `a47bf94d`, `b942fd60`, `da515329`
- tags:
  - operation:传输, transmit
  - operation:旋转, rotate
  - object:线路网络, wire_network
  - object:令牌, token
  - relation:端点配对, endpoint_pairing
  - condition:净转角决定旋转, net_turn_rotation

### docstring

```text
沿导线把端点处的字形令牌搬运到另一端,令牌在行进中保持相对行进方向的姿态,落地时随导线的净转角旋转。

输入结构:
- 黑色背景上有若干条一格厚、四连通、只在直角处转弯的灰色折线导线,互不接触。
- 每条导线的一个端点外侧放着一个 3×3 的非对称单色字形:字形中心位于沿该端出发方向反向两格处。
- 字形颜色互不相同,且不与导线相接。

规则:
- 对每条导线,从有字形的一端走到另一端,记录出发方向与到达方向。
- 在到达端沿到达方向向外两格处放置该字形的副本,副本相对原字形旋转的角度等于从出发方向转到到达方向的转角。
- 原字形与导线保持不变。

关键洞察:
- 旋转角不是固定值,也不是转弯次数的查表,而是首末方向之差;把令牌想象成保持车头姿态滑行在导线上,答案唯一确定。
```

## 7. 隐形光源

- 参考题目: `b942fd60`, `896d5239`
- tags:
  - operation:射线延伸, ray_extend
  - object:标记像素, marker_pixel
  - object:影线, shadow_ray
  - relation:共同原点反推, common_origin_inference
  - condition:近点遮蔽远点, nearest_caster_wins

### docstring

```text
根据已画出的几条影线反推一个从未画出的光源,再为其余色点补画由该光源投出的影线。

输入结构:
- 黑色背景上散布若干彩色单像素色点。
- 其中一部分色点已带有影线:从该点沿某个米字方向延伸到网格边缘的同色射线。
- 所有色点都与某个共同的隐形光源格在水平、竖直或对角方向上对齐;光源格本身始终是背景色。

规则:
- 把已有影线反向延长,其交点即隐形光源的位置。
- 对每个尚无影线的色点,沿光源指向该点的方向,把点后方直到边缘的背景格涂成该点颜色。
- 若同一条射线上有多个色点,只有最靠近光源的点投影,线上更远的色点保持自身颜色且不再投影。
- 光源格保持背景色。

关键洞察:
- 规则的核心对象是一个在输入输出中都不存在的光源;已画出的影线不是装饰,而是定位它的仅有证据;近点遮蔽远点检验解题者按光学几何而非逐点延长来理解影线。
```

## 8. 微宏互换

- 参考题目: `cce03e0d`, `ce8d95cc`
- tags:
  - operation:印章覆盖, stamp_overlay
  - operation:像素放大, pixel_scaling
  - object:输入图案, input_pattern
  - relation:格位映射, cell_block_mapping
  - condition:微观宏观角色互换, micro_macro_swap

### docstring

```text
输入是小图章按宏观布局盖出的大图,输出把两者角色互换:以原布局为新图章、按原图章的形状重新盖章。

输入结构:
- 输入可以唯一地划分成等大的块阵:非空块内容完全相同,构成图章 A;非空块的位置分布构成布局 B。
- 图章 A 与布局 B 形状不同,均只用同一种前景色。
- 块的尺寸即图章 A 的尺寸,划分方式在该约束下唯一。

规则:
- 分解输入,得到图章 A(块内容)与布局 B(非空块的占位图)。
- 输出与输入同尺寸,划分成以 B 的尺寸为块的块阵:A 的每个前景格对应一个块,在该块中盖上 B 的形状;A 的背景格对应全黑块。

关键洞察:
- 输入输出都是"图章⊗布局"的乘积,但乘法两侧被调换;解题的入口在于意识到大图既描述了图章,也同时描述了布局,二者可拆开重组。
```
