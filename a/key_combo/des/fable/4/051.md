## 1. 对称轴延长线

- 参考题目题号: 13、20、6
- 难度评审: 达标
- tags:
  - operation:对称检测, symmetry_detect
  - operation:连线, draw_line
  - operation:擦除, erase
  - object:前景对象, foreground_object
  - object:对称轴, symmetry_axis
  - relation:交叉, crossing
  - condition:对称类型决定画线方向, symmetry_sets_line_direction
  - condition:交叉点标黄, crossing_marked_yellow
  - condition:原对象遮挡叠加, object_occludes_overlay
  - condition:单像素为噪声, singleton_noise

### docstring

```text
将每个前景对象沿其唯一反射对称轴画出贯穿全图的同色直线，直线被对象遮挡，不同直线的背景交点涂黄，孤立单像素噪声被擦除。

输入结构
- 黑色背景上分布若干颜色互不相同的 4 连通前景对象。
- 每个非单像素对象恰有一种反射对称：左右对称或上下对称，且对称轴恰好落在整格列/行上（对象宽或高为奇数）。
- 另有若干孤立单像素，颜色任意，均为噪声。

规则
- 擦除所有孤立单像素。
- 左右对称的对象沿其竖直对称轴所在列画一条贯穿画布的同色竖线；上下对称的对象沿其水平对称轴所在行画同色横线。
- 直线画在对象层之下：所有原对象保持原样覆盖在直线之上。
- 两条不同直线相交且交点未被任何对象覆盖时，该交点涂黄。

关键洞察
- 对象自身的对称类型不是要报告的属性，而是选择画线方向的开关；线的位置由对称轴给出，遮挡层序与交点标色共同决定最终画面。
```

## 2. 标记路由接力

- 参考题目题号: 1、8
- 难度评审: 达标
- tags:
  - operation:滑动, slide
  - operation:重涂色, recolor
  - object:边缘方块, edge_block
  - object:方向标记, direction_marker
  - object:轨迹条纹, trail_stripe
  - relation:接触停止, contact_stop
  - relation:接力传递, relay_transfer
  - condition:标记偏移决定方向, marker_offset_sets_direction
  - condition:轨迹涂橙, trail_orange

### docstring

```text
贴边的红色方块向画布内滑动，被撞的蓝色方块按自身内部黄标记指示的方向接力滑动，逐级传递直到最后一块抵达边缘，所有扫过的路径涂橙。

输入结构
- 黑色背景。恰有一个红色 3x3 实心方块贴着某一条外边缘。
- 画布内散布若干蓝色 3x3 方块，互不接触；每个蓝块中心的上、下、左、右四邻位中恰有一格为黄色标记像素，其余为蓝色。

规则
- 红色方块垂直于所贴边缘向画布内部滑动，直到与第一个蓝色方块接触后停止。
- 被撞的蓝色方块沿自身黄标记相对中心的偏移方向滑动，直到接触下一个蓝色方块或抵达画布边缘停止；接力逐级传递，每个被撞方块都按自己的标记方向出发。
- 每个移动过的方块把扫过的格子涂橙；方块本体在新位置保持原样（含黄标记）。

关键洞察
- 运动不是整体平移而是碰撞接力，且每一段方向不由上一段继承，而是从被撞方块内部黄标记的偏移重新读出，路径因此在画布中逐段拐弯。
```

## 3. 锚点配准叠加

- 参考题目题号: 7、12
- 难度评审: 达标
- tags:
  - operation:透明叠加, transparent_overlay
  - operation:平移, translate
  - object:分隔行, separator_row
  - object:锚点像素, anchor_pixel
  - object:前景掩码, foreground_mask
  - relation:锚点对齐, anchor_alignment
  - condition:并集差集涂绿, xor_union_green
  - condition:交集涂蓝, intersection_blue

### docstring

```text
以上下两半各自唯一的红色锚点为配准基准，将下半掩码平移对齐后与上半叠加，仅一方为前景处涂绿、双方均为前景处涂蓝，输出单个半幅网格。

输入结构
- 一条全宽分隔行的颜色只在该行出现，把网格分成等高的上下两半，两半背景色相同。
- 每一半含一个灰色前景掩码和恰好一个红色锚点像素。
- 两半掩码位置相互错开；以各自锚点为原点对齐后两掩码有重叠部分，且下半掩码平移后完全落在半幅画布内。

规则
- 删除分隔行，将下半整体平移，使其红色锚点与上半红色锚点重合。
- 输出与半幅同尺寸的网格：对齐后仅一方为灰色前景的格子涂绿，双方都是灰色前景的格子涂蓝，其余为背景。
- 锚点重合处涂红。

关键洞察
- 两半不能按原始行列直接逐格对齐；红色锚点是配准坐标原点，先发现平移量再合并，才能得到正确的对称差（绿）与交集（蓝）分区。
```

## 4. 折返射线

- 参考题目题号: 2、11
- 难度评审: 达标
- tags:
  - operation:射线延伸, ray_cast
  - operation:反弹, bounce
  - operation:重涂色, recolor
  - object:标记像素, marker_pixel
  - object:轨迹, trail
  - object:障碍像素, obstacle_pixel
  - relation:反向投射, opposite_direction
  - condition:边界镜面反射, border_reflection
  - condition:首个障碍标红, first_obstacle_marked_red

### docstring

```text
红色标记沿粉色尾迹的反方向发出对角射线，射线在画布边界处像光线一样反弹，粉色路径一直画到击中第一个非背景像素并把该像素涂红。

输入结构
- 单一背景色画布上有一个红色标记像素，其一侧紧邻一段直线排列的对角粉色尾迹，表明标记的来向。
- 画布上散布若干灰色障碍像素。
- 从红色标记沿尾迹反方向直线延伸会先离开画布：必须经过至少一次边界反弹才会命中障碍。

规则
- 从红色标记出发，沿粉色尾迹的反方向逐格绘制粉色对角路径。
- 路径抵达画布边界时按入射角等于反射角反弹后继续延伸；恰好射入角落时原路折返。
- 当路径的下一格是非背景像素时停止：该像素涂红，路径不再延伸。
- 画面其余部分保持不变。

关键洞察
- 尾迹给出运动方向，但直线延伸并不成立；必须发现边界的镜面反弹规则，沿折线追踪后命中的那一个障碍才是唯一被改写的格子。
```

## 5. 燃料计数推进

- 参考题目题号: 14、8、15
- 难度评审: 达标
- tags:
  - operation:滑动, slide
  - operation:计数, counting
  - operation:擦除, erase
  - object:箭头对象, arrow_object
  - object:燃料散点, fuel_pixel
  - object:墙体, wall_bar
  - relation:同色配对, same_color_pairing
  - relation:接触停止, contact_stop
  - condition:散点数决定位移, dot_count_as_displacement
  - condition:未耗燃料保留, unused_fuel_retained

### docstring

```text
每个箭头对象沿自身指向滑动，位移步数等于画布上同色散点的数量，每走一格消耗一枚散点；提前撞墙则停止，未消耗的散点保留原位。

输入结构
- 黑色背景。若干朝向明确的箭头形对象，指向上、下、左、右之一，各对象颜色互不相同。
- 画布上散布与各对象同色的孤立单像素作为燃料点，位置与对象路径无关。
- 另有灰色墙体条；各对象的滑动带互不干涉。

规则
- 每个对象沿其指向滑动，每移动一格消耗一枚自己颜色的燃料点，燃料点按与该对象起始位置距离从近到远的顺序被消耗。
- 对象在燃料耗尽、或下一步将与灰墙、画布边缘接触时停止。
- 被消耗的燃料点从画布上消失；未消耗的燃料点保留原位；灰墙保持不变。

关键洞察
- 位移长度不由任何局部特征给出，而等于同色散点的数量；撞墙截断时剩余燃料保留，消失的燃料数恰等于实际位移——必须从散点部分消失的现象反推出燃料与步数的守恒关系。
```

## 6. 换色门射线

- 参考题目题号: 16、20、10
- 难度评审: 达标
- tags:
  - operation:射线延伸, ray_cast
  - operation:重涂色, recolor
  - object:边缘标记, edge_marker
  - object:空心矩形, hollow_rectangle
  - relation:穿越交换, pass_through_swap
  - relation:级联搬运, cascade_relay
  - condition:双色互换, two_color_swap

### docstring

```text
边缘标记向画布内发出直线射线，每穿入一个空心矩形框就与该框交换颜色：框整体重涂为射线来色，射线此后改用框的原色，颜色沿路径逐级搬运。

输入结构
- 黑色背景。网格边缘上有若干彩色标记像素。
- 画布内部有若干互不交叠、颜色互不相同的空心矩形框；每个框至多位于一条射线的路径上。
- 有的射线不穿过任何框，有的先后穿过一个或两个框。

规则
- 每个边缘标记向画布内部垂直发出直线射线，射线以标记自身颜色开始逐格绘制，只绘制背景格。
- 每当射线穿入一个框，射线与该框交换颜色：框的全部边框像素重涂为射线到达时的颜色，射线此后改用该框原来的颜色绘制。
- 射线一直延伸到对侧边缘；不被射线穿过的框保持原色。

关键洞察
- 框不是障碍也不是滤色器，而是交换器：输出中框的变色与射线的分段变色相互咬合；串联两框时第二个框得到的是第一个框的原色，颜色像接力棒一样沿射线搬运。
```

## 7. 遮挡层序反转

- 参考题目题号: 20、7
- 难度评审: 达标偏上
- tags:
  - operation:重绘, redraw
  - object:空心矩形, hollow_rectangle
  - relation:遮挡, occlusion
  - relation:隐藏层序, hidden_z_order
  - condition:断口反推次序, breaks_reveal_order
  - condition:层序整体反转, order_reversal

### docstring

```text
从交叠处的覆盖关系推断多个空心矩形的上下层序，再按完全相反的层序重新绘制它们。

输入结构
- 背景上有若干颜色互不相同的空心矩形边框，两两之间存在交叠。
- 每处交叠只显示较上层矩形的颜色，即下层矩形的边框在交叠处被打断。
- 所有覆盖关系一致地给出一条从最底层到最顶层的全序链。

规则
- 依据每处交叠中谁的边框完整、谁的边框被打断，恢复矩形的层序。
- 保持每个矩形的位置、尺寸、颜色不变，按相反层序重绘：原最底层变为最顶层，原最顶层变为最底层。
- 交叠处改为显示新层序中较上层矩形的颜色。

关键洞察
- 画面里没有任何显式的次序标记；层序只能从断口的分布反推，而答案是这一隐藏全序的整体反转，输出中每处断口恰好换到另一方身上。
```

## 8. 干涉生长

- 参考题目题号: 18、2
- 难度评审: 达标偏上
- tags:
  - operation:生长, grow
  - operation:重涂色, recolor
  - object:种子行, seed_row
  - object:障碍像素, obstacle_pixel
  - relation:双亲扩散, two_parent_spread
  - condition:同至抵消, xor_cancel
  - condition:交替变色, alternating_color
  - condition:障碍被击中标红, hit_obstacle_marked_red

### docstring

```text
种子像素逐行向下做左右斜向扩散，两个父格同时到达的格子相互抵消，生成行粉橙交替，被波前击中的灰色障碍不落子并涂红。

输入结构
- 绿色背景。顶部某一行含若干橙色种子像素。
- 下方散布若干灰色障碍像素，其余均为背景。

规则
- 从种子行开始逐行向下推进：下一行某格被激活，当且仅当它左上、右上两个父格中恰有一个是当前行的活跃像素；两个父格都活跃则相互抵消，该格不激活。
- 被激活的格子若是背景则落子，生成行颜色按粉、橙逐行交替；若该格是灰色障碍，则不落子并把该障碍涂红，该处不再作为下一行的父格。
- 推进到底行或再无激活格时停止；原种子行与未被命中的障碍保持不变。

关键洞察
- 扩散不是简单的三角形填充：同时到达即抵消的异或规则产生镂空的干涉图样；障碍只有被波前实际击中才会变红，未被触及的障碍是检验规则的试金石。
```

## 9. 模板甄别降采样

- 参考题目题号: 17、12、3
- 难度评审: 达标
- tags:
  - operation:下采样, downsample
  - operation:筛选, filtering
  - object:分隔行列, separator_rows_and_columns
  - object:模板块, template_block
  - object:干扰图形, distractor_shape
  - relation:形状全等, shape_congruence
  - condition:允许旋转镜像, rotation_mirror_allowed
  - condition:同数异形干扰, same_count_distractor

### docstring

```text
以唯一的红色图形为模板，把单元块阵列折叠为小网格：块内图形与模板全等（允许旋转镜像）则保留其颜色，否则归于背景。

输入结构
- 灰色分隔行与分隔列把网格划分为等大的矩形单元块阵列。
- 恰有一个单元块内的连通图形为红色，作为模板块；其余单元块各含一个其他颜色的小连通图形或为空。
- 部分非模板图形与模板像素个数相同但形状不同，计数捷径不成立。

规则
- 输出网格的行列数等于单元块阵列的行列数。
- 某块内图形与红色模板在允许平移、旋转、镜像的意义下形状全等时，该输出格取该块图形的颜色；否则取背景色。
- 模板块自身对应的输出格取红色。

关键洞察
- 折叠的依据既不是有无也不是数量，而是与唯一红色模板在旋转镜像意义下的形状同一性；同像素数的异形图形是专门堵住计数捷径的干扰。
```
