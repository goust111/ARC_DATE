## 1. 隐形线段交汇印章

- tags:
  - operation:连线, line_drawing
  - operation:印章覆盖, stamp
  - object:标记像素, marker_pixel
  - object:十字图案, cross_pattern
  - relation:同色配对, same_color_pairing
  - relation:纵横相交, cross_intersection
  - condition:仅交点具象化, only_intersections_materialize
  - condition:纵横色分层, orientation_color_layering
- 参考题目题号: 070dd51e、b60334d2

### docstring

```text
将每对同色标记视为一条从未画出的轴对齐线段，仅在横线段与纵线段的交叉点处印上一个 3×3 双层花纹，其余一切（包括标记本身）全部抹去。

输入结构
- 黑色背景；若干前景色，每种颜色恰好出现两个像素。
- 同色的两个像素恰好共行或恰好共列，构成一条虚拟的水平或垂直线段。
- 画面上没有其他对象；部分线段互不相交，充当诱饵。

规则
- 为每对同色标记连一条想象中的线段（不画出）。
- 找出所有"横线段与纵线段在双方严格内部相交"的交点。
- 在每个交点处以 3×3 印章绘制：四个对角邻格取横线段的颜色，四个正交邻格取纵线段的颜色，中心格保持背景。
- 输出中删除所有标记像素，只保留印章花纹。

关键洞察
- 线段自始至终不存在于画面上，成对的标记只是它们的生成元；答案里花纹的位置由不可见几何的交点决定，花纹的两层颜色分别泄露了两条隐形线的方向归属，而从未相交的配对彻底消失。
```

## 2. 拆墙洪泛

- tags:
  - operation:擦除, erase
  - operation:洪泛填充, flood_fill
  - object:角括号, corner_bracket
  - object:墙壁线段, wall_segment
  - object:封闭区域, enclosed_region
  - relation:标记在括号内部, marker_inside_bracket
  - condition:先拆墙后判封闭, erase_then_reenclose
  - condition:连锁反应, chain_reaction
- 参考题目题号: 1e81d6f9、a5313dff

### docstring

```text
先按括号内标记指定的颜色拆除全图同色墙段，再对拆墙后的画面重新判定封闭性，只把仍然封闭的黑色腔体填蓝。

输入结构
- 黑色背景；红色墙体围成若干腔体，部分墙体中混有一至两种其他颜色的墙段。
- 画面一角有一个单色角括号，其包围盒内部、括号格之外恰有一个前景标记像素。
- 标记颜色与某一种混色墙段颜色相同；蓝色不在输入中出现。

规则
- 读取括号内标记的颜色，把全图中该颜色的所有像素（标记自身除外）擦为黑色。
- 以擦除后剩余的非黑像素为墙，找出经四邻无法连通到画布边界的黑色区域，将其填蓝。
- 括号、标记以及未被点名的其他颜色墙段原样保留。

关键洞察
- 封闭性必须在拆墙之后重新计算：输入里看似密闭的腔体，若其墙上含有被点名的颜色，拆除后即漏气而不再填色；填蓝的范围是删除操作的下游结果，而非输入画面的直接属性。
```

## 3. 测地涟漪

- tags:
  - operation:填充, fill
  - operation:重涂色, recolor
  - object:封闭区域, enclosed_region
  - object:标记像素, marker_pixel
  - object:同心环, concentric_ring
  - relation:距离映射, distance_mapping
  - condition:测地距离, geodesic_distance
  - condition:循环色板, cyclic_palette
  - condition:无标记腔体不填, unmarked_cavity_untouched
- 参考题目题号: aaef0977、a5313dff

### docstring

```text
在每个含有标记像素的封闭腔体内，按沿腔体内部绕行的最短步数（测地距离）画出循环色环，无标记的腔体保持原样。

输入结构
- 黑色背景上灰色墙体围出若干形状各异的封闭腔体，其中包含凸形腔体与凹形、回廊形腔体。
- 部分腔体内恰有一个非灰色标记像素，其余腔体完全为空。
- 标记颜色属于固定色环序列中的某一色。

规则
- 对每个含标记的腔体，以标记为源点，只允许走腔体内部的四邻步，计算每格的最短路径距离。
- 距离 0 的源点保持标记色；距离每增加 1，颜色从标记色出发沿固定色环 黄→绿→红→青 循环前进一格。
- 灰色墙体、无标记腔体和腔体外背景全部保持不变。

关键洞察
- 色环的层级不是曼哈顿距离而是绕墙的测地距离——在凸腔体中两者恰好一致（这正是陷阱），而在凹形回廊中色带必须沿走廊拐弯延伸，直线距离很近的两格可能相差许多环。
```

## 4. 榫卯入窗

- tags:
  - operation:对接拼合, docking
  - operation:平移, translate
  - object:精灵体, sprite
  - object:连接点, connector_pixel
  - object:角标记, corner_marker
  - relation:对接对齐, docking_alignment
  - relation:包围框对齐, bounding_box_alignment
  - condition:窗口尺寸消歧, window_resolves_ambiguity
- 参考题目题号: 20270e3b、a1570a43

### docstring

```text
两块带接口像素的碎片存在多种几何上可行的拼接方式，唯一能使拼合体包围盒恰好填满四角标记窗口的拼法才是正解，拼好后整体移入窗内。

输入结构
- 黑色背景上有两个同色精灵，各带一个接口色像素。
- 另有四个同色角标记像素，标出一个矩形的四个角。
- 接口像素的相对位置允许两个精灵按水平相邻、垂直相邻等不止一种方式对接。

规则
- 枚举使两个接口像素恰好相邻且两精灵互不重叠的所有平移拼法。
- 计算每种拼法拼合体的包围盒，取其尺寸恰好等于角标记矩形内部尺寸的唯一拼法。
- 把接口像素改涂为精灵色，将拼合体整体平移到窗口内部，使包围盒与窗口内部完全重合。
- 清除两精灵的原位置，保留四个角标记。

关键洞察
- 接口只给出"相邻"这一局部约束，本身不足以定解；真正的选择器是远处那扇看似无关的角标记窗——尺寸匹配把多个几何可行解裁成唯一解，对接与入窗两步互为验证。
```

## 5. 转位表决

- tags:
  - operation:旋转, rotate
  - operation:投票恢复, majority_vote_recovery
  - operation:颜色反转, color_invert
  - object:方形网格, square_grid
  - object:二值图案, binary_pattern
  - relation:旋转同源, rotational_kinship
  - condition:对齐后投票, vote_after_alignment
  - condition:反相面板需还原, inverted_panel_restored
- 参考题目题号: ed36ccf7、0607ce86、48131b3c

### docstring

```text
四个面板是同一图案的四个旋转视角且各含少量污损、其中一块还被整体反色，须对齐还原后逐格表决，输出修复好的原始图案。

输入结构
- 画布被分隔线划成 2×2 四个等大的正方形双色面板。
- 四个面板分别是同一图案旋转 0°、90°、180°、270° 后的副本，且各自有少量格的颜色在图案双色之间被翻转（污损）。
- 恰有一块面板除旋转之外还做了两色的整体互换。

规则
- 把四个面板分别旋转回同一取向（以左上面板的取向为准）。
- 对反色的那块面板先做两色互换还原。
- 对齐后逐格取四份副本的多数色（每格至多一份被污损，多数唯一）。
- 输出修复后的单个面板。

关键洞察
- 面板之间不能直接逐格比较——表面上四块图案互不相同，只有识破"旋转 + 一块反相"的双重伪装并把它们搬回同一坐标系，冗余才会显形，污损才能被三比一的表决淘汰。
```

## 6. 穿堂留痕

- tags:
  - operation:滑动, slide
  - operation:重涂色, recolor
  - object:标记像素, marker_pixel
  - object:实心矩形, solid_rectangle
  - object:矩形框架, rect_frame
  - object:画布边界, canvas_boundary
  - relation:视线对齐, sightline_align
  - condition:实心为墙空心为门, solid_wall_hollow_door
  - condition:穿越留足迹, traversal_leaves_trail
- 参考题目题号: e1d2900e、4347f46a

### docstring

```text
标记沿视线滑行，空心框是可穿透的门洞——穿越时在框内留下自己颜色的足迹，实心块才是真正的墙，终点由滑行线上第一个实心块决定。

输入结构
- 黑色背景；一种前景色构成若干矩形，其中有的是实心块，有的是一格厚的空心框。
- 另一种颜色为若干单点标记，每个标记有唯一一条与若干矩形共行或共列的无阻视线滑行方向。
- 同一条滑行线上可以依次排布多个矩形。

规则
- 每个标记沿其视线方向滑行：遇到空心框则从近侧壁穿入、远侧壁穿出并继续滑行，同时把它在该框内部经过的每一格染成标记色（足迹）。
- 遇到实心块则停在其外侧紧贴的一格。
- 若滑行线上没有实心块，标记穿完所有空心框后滑出画布，不再出现在输出中，但沿途足迹全部保留。
- 矩形壁与实心块不改动，标记的原位置清除。

关键洞察
- 矩形不是统一的"磁铁"：只看含实心块的示例会得出"贴壁即停"的错觉；空心框其实是透明门洞，答案由整条滑行线的串联结果决定——终点看第一个实心块，痕迹看途经的每个空心框，二者可以同时缺席或同时出现。
```

## 7. 折纸叠印

- tags:
  - operation:镜像折叠, fold_mirror
  - operation:裁剪, crop
  - object:全空行列, fully_blank_row_column
  - object:面板阵列, panel_array
  - relation:镜像对齐, mirror_alignment
  - relation:面积最大选取, largest_area_select
  - condition:空线为折痕, blank_line_as_crease
  - condition:底板色优先, base_color_priority
- 参考题目题号: c1d99e64、3ed85e70、fcb5c309

### docstring

```text
画面里完全空白的行与列不是缺失的引导线而是折痕：把侧翼面板沿折痕镜像翻叠到最大的主面板上，输出叠印后的主面板。

输入结构
- 黑色背景上分布着彩色像素。
- 恰有一条或两条完全空白的行/列把画布分成若干面板，其中恰有一个面积最大的主面板。
- 侧翼面板的尺寸不超过主面板。

规则
- 找出全空的行与列，作为折痕。
- 每个与主面板隔一条折痕相邻的侧翼面板，绕该折痕做镜像翻折落到主面板上；与主面板对角相望的面板做两次镜像（等效点对称）后叠印。
- 翻折像素只印在主面板的黑色格上，主面板原有的彩色格优先保留。
- 输出为主面板范围的裁剪。

关键洞察
- 空白行列在此不该被补成引导线，而是物理折痕——侧翼图案必须先镜像再叠加，且主面板既有颜色拥有覆盖优先权；折痕识别、镜像方向、叠印次序三层判定共同决定输出的每一格。
```
