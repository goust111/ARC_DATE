## 1. 杯口节拍认领

- 参考题目题号：10（d4f3cd78）、20（16de56c4）、12（d59b0160）
- tags:
  - operation:射线延伸, ray_extend
  - operation:重涂色, recolor
  - operation:擦除, erase
  - object:杯形轮廓, cup_outline
  - object:开口, opening
  - object:散点, scattered_dot
  - relation:同余对齐, modular_alignment
  - condition:开口宽度定周期, opening_width_period

### docstring

```text
每个散点若落在某只杯开口的发射带上、且到杯口的距离是开口宽度的整数倍，就染成该杯的颜色，否则被擦除。

输入结构：
- 黑色背景上有若干单色"杯"：几乎封闭的矩形轮廓，每只杯在一条边上有一个
  宽度不小于二的开口，各杯的开口宽度与朝向互不相同。
- 网格其余处散布若干灰色单像素散点。

规则：
- 每只杯从其开口沿开口朝向向外确定一条宽度等于开口宽度的发射带。
- 散点若位于某发射带内，且它到杯口外壁的垂直距离是该杯开口宽度的整数倍
 （合拍），则染成该杯的颜色。
- 带外的散点与带内不合拍的散点全部擦为背景。
- 杯本身保持不变；设计保证每个散点至多被一只杯认领。

关键洞察：
- 开口不只指方向——它的宽度就是节拍周期；散点的去留与归属取决于它到
  杯口的距离与开口宽度的同余关系，带内不合拍的散点是刻意布置的诱饵。
```

## 2. 路径是环带的规格书

- 参考题目题号：8（99306f82）、15（5792cb4d）
- tags:
  - operation:同心层填充, concentric_fill
  - operation:擦除, erase
  - object:空心矩形框, hollow_rect_frame
  - object:单像素宽路径, one_pixel_path
  - object:端点像素, endpoint_pixel
  - relation:游程映射环层, run_to_ring_mapping
  - condition:接触端定读向, touching_end_read_direction

### docstring

```text
把与框相连的多彩路径按同色游程翻译成框内由外向内的矩形环带：游程颜色定环色，游程长度定环厚。

输入结构：
- 空网格上有一个单色空心矩形框，框内为空。
- 一条一像素宽的多彩路径在框外蜿蜒，一端与框的外壁相接，另一端游离。
- 路径由若干极大同色游程组成，相邻游程颜色不同；路径的几何拐弯与游程
  分界无关；游程序列设计为非回文，各游程长度之和恰好铺满框内。

规则：
- 从接框的一端出发遍历路径，依次读出各同色游程的颜色与长度。
- 在框内由外向内填矩形环带：第 k 个游程给出第 k 层环的颜色，环厚等于
  该游程的长度；最后一个游程填满剩余中心。
- 输出中路径被整条擦除，框与背景保持不变。

关键洞察：
- 路径的蜿蜒形状是伪装，它的颜色串才是内容——同色游程序列恰是框内
  嵌套环带由外向内的规格书（色加厚），读取方向由接框端点决定。
```

## 3. 法则写在图里

- 参考题目题号：9（c0f76784）、10（d4f3cd78）、12（d59b0160）
- tags:
  - operation:洪泛填充, flood_fill
  - operation:计数, counting
  - object:封闭区域, enclosed_region
  - object:开口, opening
  - object:示范轮廓, exemplar_outline
  - relation:在场对照表, in_grid_codebook
  - condition:封闭性入场, closedness_gate
  - condition:面积决定填充色, area_determines_fill_color

### docstring

```text
图中已填色的封闭轮廓示范了本图专属的"内部面积对填色"法则，把每个仍空着的封闭轮廓按该法则补填，带缺口的轮廓保持空白。

输入结构：
- 黑底上散布若干灰色轮廓形状。
- 一部分轮廓完全封闭且内部已被某种颜色填满，构成示范。
- 另一部分封闭轮廓内部为空；还有个别轮廓带缺口，不封闭。
- 同一输入内，内部面积相同的已填轮廓颜色一致；不同输入（包括各训练
  示例对之间）使用互不相同的面积对颜色法则。

规则：
- 从已填轮廓读出本图的面积对颜色对照表，面积按被围住的内部格数计。
- 对每个内部为空的封闭轮廓，数出其内部面积并查表填色。
- 带缺口的轮廓不封闭，不予填色；灰轮廓与背景保持不变。

关键洞察：
- 法则不在题外而在图内——每个输入自带一份互不相同的对照表，跨示例
  背规则必然失败（首个训练对中面积次序恰与彩虹色序一致，是刻意布置
  的假规律）；缺口轮廓是"看起来该填"的诱饵，封闭性才是入场券。
```

## 4. 角落里的真值表

- 参考题目题号：5（1b2d62fb）、17（3428a4f5）、12（d59b0160）
- tags:
  - operation:逻辑运算, logical_op
  - object:二值掩模, binary_mask
  - object:分隔条, separator_bar
  - object:图例区域, legend_region
  - relation:逐像素对应, pixelwise_correspond
  - condition:图例即运算符, legend_as_operator

### docstring

```text
网格角上的二乘二图例是一张真值表，规定如何逐像素合并分隔条两侧的两个掩模。

输入结构：
- 一条满高单色分隔条把主区域分成同尺寸的左右两块掩模；掩模用某前景色
  表真、背景色表假。
- 角落有一个带边框的二乘二图例，与主区域分离；图例格用输出色点亮或留
  背景。
- 图例第 r 行第 c 列对应组合"左掩模值为 r、右掩模值为 c"（零为假、
  一为真），亮格表示该组合输出真。

规则：
- 读出图例编码的两输入布尔函数。
- 对左右掩模逐像素求该函数：结果为真的格子涂图例亮格所用的颜色，为假
  的格子留背景。
- 输出尺寸等于单个掩模。
- 不同示例对编码不同的布尔函数，且含非对称函数，迫使解题者确定行列
  语义并真正读表，而不能背一个固定运算。

关键洞察：
- 图例既不是调色板也不是过滤器，它是运算符本身——二乘二的四个格子
  恰是两输入布尔函数的完整真值表，每个输入自带自己的逻辑门。
```

## 5. 姿态与角标的合同

- 参考题目题号：16（94133066）、19（5614dbcf）、3（689c358e）
- tags:
  - operation:旋转, rotate
  - operation:镜像, mirror
  - operation:裁剪, crop
  - object:等大隔间, equal_compartment
  - object:精灵体, sprite
  - object:外部标记像素, external_marker
  - relation:标记姿态一致律, marker_pose_law
  - condition:多数归纳唯一违例, majority_rule_single_violator

### docstring

```text
每个隔间里的精灵姿态须与贴在隔间外角的标记一致，找出唯一违约的隔间并输出其改正后的内容。

输入结构：
- 灰色分隔线把网格划分成若干等大隔间，每个隔间内是同一个非对称精灵的
  某个旋转或翻转姿态。
- 每个隔间外侧紧贴其某一个角有一个标记像素。
- 精灵内部有一个唯一异色格作为特征格。

规则：
- 从多数隔间归纳一致律：精灵的特征格总位于隔间中与角标同侧的角区。
- 恰有一个隔间违反该律。
- 对违约隔间的精灵施加使其守约的旋转或翻转，输出该隔间修正后的网格，
  尺寸等于单个隔间。

关键洞察：
- 角标是每个隔间私有的朝向合同；这条律不写在任何一处，必须由守约的
  多数隔间归纳出来，再反过来改正唯一的违约者——输出的是修复结果，
  而不是违例者本身。
```

## 6. 自带标尺的图案

- 参考题目题号：11（60c09cac）、6（b0f4d537）
- tags:
  - operation:像素放大, pixel_upscale
  - operation:计数, counting
  - object:前景图案, foreground_pattern
  - relation:行列自参照, self_referential_rows_cols
  - condition:前景计数定倍率, foreground_count_scale

### docstring

```text
把图案非均匀放大：每一列在输出中的宽度等于该列前景像素的个数，每一行的高度等于该行前景像素的个数。

输入结构：
- 黑色背景上有一个多彩前景图案，其包围盒内既有前景格也有背景格。
- 包围盒的每一行、每一列都至少含一个前景像素。

规则：
- 对包围盒第 c 列，数出其非背景像素个数记为该列宽度；对第 r 行同理
  记为该行高度。
- 输出中原图格变成对应"行高乘列宽"的同色块，背景格亦按块放大保持
  背景，按原行列顺序拼接。
- 输出尺寸为各行高之和乘各列宽之和。

关键洞察：
- 没有任何外部标尺——图案就是自己的标尺；看似普通的整数倍均匀放大
  是诱饵（个别示例的行列计数几乎一致），真正的倍率藏在每行每列自己
  的前景计数里。
```

## 7. 尘埃落框

- 参考题目题号：14（9af7a82c）、8（99306f82）、1（d22278a0）
- tags:
  - operation:计数, counting
  - operation:排序, sort
  - operation:同心层填充, concentric_fill
  - operation:擦除, erase
  - object:空心矩形框, hollow_rect_frame
  - object:散点, scattered_dot
  - relation:距离定层序, distance_determines_layer
  - condition:个数定环厚, count_determines_thickness

### docstring

```text
框外每种颜色的散点按"离框最近者在外"的次序沉积成框内由外向内的矩形环带，环厚等于该色散点个数。

输入结构：
- 一个单色空心矩形框立在网格上，框内为空。
- 框外散布几种颜色的单像素散点；各色散点个数互不相同，各色到框的最小
  距离也互不相同。
- 框内可填区域的尺寸恰好容纳按规则卷成的全部环带。

规则：
- 对每种颜色，取其所有散点到框的最小切比雪夫距离。
- 按该距离从小到大排层：最近的颜色成为最外环，依次向内。
- 每种颜色填厚度等于其散点个数的矩形环带，最内色填满剩余中心。
- 散点全部擦除，框保持不变。

关键洞察：
- 层序与厚度来自两个不同的度量——个数只定厚度，"谁离框最近"才定
  层序；按数量大小排层是诱饵，部分示例中两种次序刻意不一致。
```
