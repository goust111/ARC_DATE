## 1. 双点阵印章的残迹修复

- 参考题目题号：2（e619ca6e）、16（71e489b6）
- tags:
  - operation:印章覆盖, stamp
  - operation:补全, completion
  - object:实心矩形, solid_rect
  - object:缺陷像素, defect_pixel
  - relation:对角偏移重复, diag_offset_repeat
  - condition:尺寸决定步幅, size_determines_stride
  - condition:残迹选择修复, residue_selects_restoration
  - condition:忽略干扰项, ignore_distractors

### docstring

```text
在两族按自身尺寸沿对角线等距重复的同色矩形中，只把留有残迹的缺位补画完整。

输入结构：
- 背景为黑色，前景只有一种颜色。
- 前景由若干实心矩形组成，矩形只有两种尺寸（互不相同，如 2×3 与 3×2）。
- 每种尺寸的矩形各自排成一条对角等差链：相邻拷贝的位移恰为该矩形自身的
  (高, 宽)；链在网格边缘处的拷贝会被裁掉出界部分，两条链在画面中交错穿插。
- 每条链各缺失一个内部槽位的拷贝：一处完全为空（净缺口），另一处残留
  1~2 个前景像素（残迹）。

规则：
- 按矩形尺寸把拷贝分成两族，分别恢复各族的对角等差位置序列。
- 找出两族链条中间断缺的槽位。
- 只把含有残迹像素的那个缺位补画为完整矩形（位置由等差关系精确决定）；
  净缺口保持原样，其余画面不变。

关键洞察：
- 同色矩形其实属于两条独立的链，步幅就是各自的身材；两处缺口貌似同类，
  残迹才是"补画授权"，净缺口是诱饵。而残迹只指认槽位，精确落点必须由
  等差步幅推出。
```

## 2. 安全路径上的念珠序列

- 参考题目题号：15（cc9053aa）、20（1da012fc）、10（642d658d）
- tags:
  - operation:寻路, pathfinding
  - operation:重涂色, recolor
  - object:轨道路径, track_path
  - object:端点, endpoint
  - object:障碍物, obstacle
  - object:占位块, placeholder_object
  - relation:邻域禁区, neighbor_exclusion
  - relation:路径顺序对应, path_order_correspondence
  - condition:唯一安全路径, unique_safe_path
  - condition:忽略干扰项, ignore_distractors

### docstring

```text
沿两端点间唯一安全路径依次读出路上彩珠的颜色，并按阅读顺序涂给场外的灰色
占位块。

输入结构：
- 黑色背景上有一条带分岔的青色四连通轨道；轨道上嵌有一个黄色起点像素与
  一个褐红色终点像素。
- 若干橙色阻塞像素贴近轨道；轨道的某些格被替换为其他颜色的单像素"彩珠"，
  分布在主路与分岔上。
- 网格另一侧有一列互相分离的灰色占位方块，数量等于安全路径上彩珠的数量。

规则：
- 每个橙色像素连同其八邻域为禁区，删去落入禁区的轨道格。
- 剩余轨道中，从黄色起点到褐红终点存在唯一简单路径。
- 沿该路径从起点走到终点，按途经顺序记录彩珠颜色；不在该路径上（死岔上）
  的彩珠一律忽略。
- 将灰色占位块按自上而下的顺序依次涂成记录到的颜色；其余画面保持不变。

关键洞察：
- 橙色禁区不仅裁出唯一通路，还顺手把诱饵彩珠隔离在死岔上；占位块的颜色
  不由距离或形状决定，而由"行走次序"这一在画面上看不见的量决定。
```

## 3. 条形身高改写母题循环

- 参考题目题号：6（12422b43）、4（a61f2674）、14（6d0160f0）
- tags:
  - operation:循环填充, cyclic_fill
  - operation:排序, sorting
  - object:母题行, motif_rows
  - object:标记列, marker_column
  - object:竖直线段, vertical_bar
  - object:分隔线, separator_line
  - relation:高度排名, height_ranking
  - relation:标记界定母题, marker_delimits_motif
  - condition:排名决定循环序, ranking_determines_cycle_order
  - condition:相位续接, phase_continuation

### docstring

```text
把上方被灰色括号标出的彩色母题行循环填入空白后缀，但循环次序由侧栏竖条的
高度排名决定，且必须接续已画行的相位。

输入结构：
- 一条贯穿全高的灰色分隔列把网格分为宽的主面板和窄的侧栏。
- 主面板：最左列顶端有一段连续灰色括号像素，标出 k 行母题；每行母题是一
  种独立颜色的行图案，k 行颜色互不相同。母题下方已画出 1~2 行"续接行"
  （少于一个完整周期），再往下是全背景的空白后缀。
- 侧栏：k 根一格宽、底部对齐的竖条，颜色与 k 行母题一一对应，高度互不
  相同；竖条的高度排名与母题行自上而下的摆放顺序不一致。

规则：
- 把母题行按所属竖条高度从高到低排序，得到循环序列（灰色括号格视为背景）。
- 已画出的续接行是该循环序列的开头若干项；从其后继项开始，把循环序列继续
  逐行写满空白后缀。
- 主面板其余部分与侧栏、分隔列保持不变。

关键洞察：
- 母题的书写顺序只是摆放顺序，真正的播放顺序藏在侧栏的"身高榜"里；已画
  的一两行不足一个周期、看不出循环序，只用来对准相位并验证排名读法。
```

## 4. 对角导线的连锁点灯

- 参考题目题号：12（ecb67b6d）、15（cc9053aa）、11（477d2879）
- tags:
  - operation:重涂色, recolor
  - operation:连锁传播, chain_propagation
  - object:八连通区域, eight_conn_region
  - object:控制标记点, control_marker
  - object:小方块, small_square
  - relation:对角链式连接, diagonal_chain
  - relation:方向连续性, direction_continuity
  - condition:交叉非分岔, crossing_not_branch
  - condition:分岔断电, branch_blocks_current

### docstring

```text
源点颜色沿灰色对角导线传播点亮末端灯块，被点亮的灯块又作为新源点向相接的
其他导线继续供电；交叉处直行穿过，真分岔断电。

输入结构：
- 画面为橙色底；灰色像素组成若干一格宽的对角走线，两条走线可在一格处呈
  "X"形对角交叉并共享该格。
- 走线的每个末端与一个彩色源点像素、或一个黑色 2×2 灯块的某个角对角相接；
  同一个灯块可以与多条走线相接。
- 画面中只有一到两个彩色源点，灯块数量更多，部分灯块与源点之间没有任何
  一条直接导线相连。

规则：
- 从源点出发沿导线逐格行进：在存在直行延续的格子保持原对角方向穿过
  （包括"X"形交叉格）；仅当无直行延续且恰有一个转向延续时转向。
- 若某格无直行延续且有两个及以上转向延续（真分岔），该股电流断电终止。
- 电流走通到灯块时，把这条导线的全部灰格与该灯块涂成电流颜色，且该灯块
  立即成为新的源点，向与它相接的其余尚未通电的导线继续供电；如此连锁，
  直到没有新的灯块被点亮。
- 未通电的导线与未点亮的灯块保持原样（真分岔导线即使与已亮灯块相接，也
  无法把电送到对端）。

关键洞察：
- 电流不是一次性的——灯块是中继站，远端看似与源点无关的灯要经过多级转发
  才亮；同时看似分叉的灰色团可能是两条互相穿过的直线："X"形共享格按方向
  连续性拆成两条各自独立的导线，而"T/Y"形歧路才是真分岔、会掐断整条链路。
  两个机制互相咬合：一处误判交叉/分岔，整个下游连锁全部判错。
```

## 5. 破缺即地址

- 参考题目题号：14（6d0160f0）、16（71e489b6）、3（5117e062）
- tags:
  - operation:复制, copy
  - operation:对称补全, symmetry_completion
  - operation:擦除, erase
  - object:瓦片, tile
  - object:分隔线, separator_line
  - object:缺陷像素, defect_pixel
  - object:精灵体, sprite
  - relation:网格分区, grid_partition
  - condition:异常值选择, outlier_selection
  - condition:缺陷坐标编码槽位, defect_encodes_slot

### docstring

```text
找到唯一有对称破缺的精灵，用对称性补上缺格，并把修复后的精灵搬到由缺格
局部坐标命名的槽位。

输入结构：
- 正方形画布被整行整列的灰色分隔线划成 3×3 个 3×3 瓦片。
- 若干瓦片内各有一个彩色精灵；除一个精灵外，其余精灵均具有某种精确对称
  （镜像或旋转）。
- 唯一的例外精灵恰有一个本应着色却是黑色的缺格：补上该格后它恢复对称，
  且不存在通过删除单格恢复对称的读法。

规则：
- 逐瓦片检查对称性，找到唯一破缺的精灵及其缺格。
- 依对称性把缺格补成精灵颜色，得到修复精灵。
- 缺格在其瓦片内的局部 (行, 列) 即目标槽位的宏观 (行, 列)：把修复精灵
  完整复制到该槽位。
- 其余所有非分隔线格清为黑色，灰色分隔线保留。

关键洞察：
- 那个黑色缺格身兼三职：它的存在从一群完美对称的诱饵精灵中挑出源精灵，
  它的对称伙伴给出修复内容，它的局部坐标给出投递地址。
```
