## 1. 边界口令走廊寻路

- 参考题目: 22eb0ac0(第8题)、b15fca0b(第3题)、55059096(第1题)
- 评审档位: 达标
- tags:
  - operation:寻路, pathfinding
  - operation:相等测试, equality_test
  - object:边界标记对, boundary_marker_pair
  - object:隐形走廊, hidden_corridor
  - object:端点像素, endpoint_pixel
  - relation:两端同色授权, endpoints_match_authorize
  - condition:最短路径唯一, unique_shortest_path
  - condition:通道从未画出, corridor_never_drawn

### docstring

```text
在只有边界标记暗示的隐形走廊网络中,把两红点间的唯一最短路涂黄。

输入结构
- 黑色背景网格;内部仅有两个红色端点像素,别无前景。
- 部分行在左右两端各有一个彩色边界标记,部分列在上下两端各有一个彩色
  边界标记;同一行(列)的两个标记颜色可能相同也可能不同。
- 两个红色端点都位于某条"两端同色"的行或列上。

规则
- 一行(列)当且仅当其两端边界标记颜色相同时,整行(列)成为可通行
  走廊;其余所有内部格子视为不可通行。
- 在走廊网络上求两个红色端点之间的唯一最短四邻接路径。
- 保留输入所有像素,把该路径的中间格子涂黄。

关键洞察
- 走廊在输入中从未被画出:两端颜色相等是行列的通行"口令",不匹配的
  标记对是死路诱饵;路径必须沿匹配行列拐弯前进,而非直线穿越空地。
```

## 2. 图例双向拨轮

- 参考题目: 9385bd28(第19题)、de1cd16c(第17题)、e48d4e1a(第12题)、e78887d1(第5题)
- 评审档位: 达标(深化后复审)
- tags:
  - operation:计数, counting
  - operation:重涂色, recolor
  - object:颜色图例, color_legend
  - object:色块区域, color_region
  - object:双色标记像素, two_color_marker
  - relation:图例构成色环, legend_forms_cycle
  - condition:净刻度定步数, net_ticks_determine_steps
  - condition:标记消失, marker_disappears

### docstring

```text
灰白两种标记是方向相反的拨轮刻度,按净刻度把每个色块沿图例色环拨到新颜色。

输入结构
- 网格主体被划分为若干实心矩形色块区域,区域颜色都出现在图例中。
- 每个区域内部嵌有灰色与白色两种标记像素,可以混合出现,数量不一;
  同一示例中同色区域可含不同的标记组合。
- 网格一侧有一竖条图例:自上而下一列互不相同的颜色。

规则
- 把图例自上而下读成首尾相接的循环色环。
- 对每个区域,计算净步数 = 灰色标记数 − 白色标记数;从区域当前颜色在
  色环中的位置出发,沿色环前进净步数(负数则反向),把整个区域连同其
  中标记重涂为到达的颜色。
- 图例保持原样。

关键洞察
- 图例是转轮而非"旧色→新色"查表;两种标记是方向相反的刻度,先相互
  抵消再拨动;净步数为零的区域原色不动,看起来像被某种条件"豁免",
  诱使人误读出并不存在的豁免规则。
```

## 3. 面朝主体停靠

- 参考题目: 2697da3f(第9题)、7c66cb00(第13题)、252143c9(第11题)、e48d4e1a(第12题)
- 评审档位: 达标偏上
- tags:
  - operation:旋转, rotate
  - operation:平移停靠, dock
  - operation:重涂色, recolor
  - object:主精灵, main_sprite
  - object:眼睛像素, eye_pixel
  - object:召唤标记, summon_marker
  - relation:朝向主体, face_the_source
  - condition:先近后远停靠, nearest_docks_first
  - condition:标记消失, marker_disappears

### docstring

```text
每个标记召唤一个旋转到面朝主精灵的副本,沿直线滑向主精灵依次贴合停靠。

输入结构
- 黑色背景;网格中部有一个主精灵,其内部含一个颜色唯一的"眼睛"像素,
  标出精灵的朝向。
- 若干单像素召唤标记散布在主精灵中心的正上、正下、正左、正右四条方向
  线上;同一方向线上可有多个标记。
- 标记颜色互不相同,且不同于精灵的任何颜色。

规则
- 每个标记生成主精灵的一个旋转副本:旋转角度使副本的眼睛一侧正对主精灵。
- 副本主体重涂为标记颜色,眼睛像素保留原色。
- 副本从标记位置沿方向线滑向主精灵,直到与已有前景相邻即停;同一方向
  线上离主精灵近的标记先停靠,后来者贴着前者停下。
- 所有标记像素消失,主精灵不动。

关键洞察
- 标记只提供方向、颜色与先后次序;副本的姿态不是抄自输入,而是由
  "眼睛必须面向主体"反推出的旋转,四个方向四种姿态在输入中大多从未
  出现。
```

## 4. 覆盖深度指针

- 参考题目: d19f7514(第20题)、de1cd16c(第17题)、d4b1c2b1(第10题)
- 评审档位: 达标
- tags:
  - operation:透明叠加, transparent_overlay
  - operation:计数, counting
  - operation:重涂色, recolor
  - object:面板, panel
  - relation:逐像素对齐, cell_align
  - condition:覆盖数索引面板, coverage_indexes_panel

### docstring

```text
把各面板掩码对齐叠起,每格按被覆盖的层数去取第几号面板的颜色。

输入结构
- 输入由 2 至 4 个等尺寸面板竖直堆叠而成,面板间以一条分隔行隔开。
- 每个面板是黑底加单一前景色的掩码,各面板前景色互不相同。

规则
- 输出为单个面板大小的黑底网格。
- 将所有面板逐像素对齐,统计每格被前景覆盖的面板层数 k。
- k 为 0 的格保持黑色;k≥1 的格涂成自上而下第 k 个面板的前景色。

关键洞察
- 颜色不跟随掩码的身份走:只被最下面板覆盖的孤格拿到的却是最上面板的
  颜色——覆盖深度是指向面板序号的指针,而不是哪层在上的胜负。
```

## 5. 调色板年轮

- 参考题目: bae5c565(第2题)、b7fb29bc(第4题)、e78887d1(第5题)
- 评审档位: 达标
- tags:
  - operation:同心层填充, concentric_fill
  - operation:循环读取, cyclic_read
  - object:调色板行, palette_row
  - object:控制像素, control_pixel
  - relation:缺口为读取起点, gap_is_origin
  - condition:缺口环留空, gap_ring_hollow
  - condition:控制像素消失, control_pixel_disappears

### docstring

```text
以孤立控制像素为圆心,按调色板行自缺口起循环读色,画出一圈圈方形年轮。

输入结构
- 顶行是一条调色板行,含恰好一个背景缺口,其余各格颜色互不相同。
- 顶行以下是大片背景,其中只有一个孤立的控制像素。

规则
- 保留调色板行。
- 对下方区域的每个格子,计算它到控制像素的切比雪夫距离 d。
- 从缺口格开始沿调色板行向右(到行尾绕回行首)数 d 格,把该格颜色涂给
  该像素;若数到的是缺口,则该像素保持背景。
- 控制像素本身距离为 0,恰落在缺口上,因而在输出中消失。

关键洞察
- 一维调色板被卷成二维年轮:缺口既是读取起点又周期性地变成空心环,
  控制像素被自己的第 0 环抹去;环色顺序不是彩虹惯例,而是调色板自缺口
  读起的循环。
```

## 6. 跨尺度补形

- 参考题目: bb52a14b(第16题)、d4b1c2b1(第10题)、e50d258f(第6题)
- 评审档位: 达标
- tags:
  - operation:补全, completion
  - operation:像素放大, pixel_upscale
  - operation:印章覆盖, stamp
  - object:模板精灵, template_sprite
  - object:放大副本, scaled_copy
  - object:缺失掩码, missing_mask
  - relation:模板与副本尺度匹配, template_copy_scale_match
  - condition:忽略干扰项, ignore_distractors

### docstring

```text
把模板上黄色标出的缺失掩码,按各副本自己的放大倍数补涂到每个放大副本上。

输入结构
- 黑色背景上有一个完整的小模板精灵,其中黄色像素标出"缺失掩码",非黄
  像素构成图案本体。
- 别处散布该图案本体的整数倍逐像素放大副本(倍数因副本而异),它们都
  缺少黄色部分。
- 另有少量零散的干扰像素,不与任何副本构成放大关系。

规则
- 以黄色像素的包围盒确定模板窗口。
- 对每个副本,找出唯一的放大倍数 s,使副本恰为模板非黄部分的 s 倍逐像素
  放大。
- 把模板中每个黄格对应的 s×s 块在该副本处补涂为黄色;模板与干扰像素
  保持不变。

关键洞察
- 匹配不在同一尺度上进行:副本是模板的放大投影,黄色掩码必须先随倍数
  放大再转移,倍数本身要从每个副本反推。
```
