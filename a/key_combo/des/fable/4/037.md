## 1. 对角线外看不见的墙

- 参考题目: `dc2e9a9d`, `5ffb2104`, `98cf29f8`, `66ac4c3b`
- 难度评审: 达标偏上
- tags:
  - operation:镜像, mirror
  - operation:滑动, slide
  - object:对角标记线, diagonal_marker_line
  - object:锚定物, anchor_object
  - relation:碰撞阻挡, collision_blocking
  - relation:虚对象生成, virtual_object
  - condition:镜像即障碍, mirror_is_obstacle

### docstring

```text
物体沿自己的行或列滑向一条完整的对角标记线，真正挡住它的是对侧锚块关于对角线的镜像所占据的、从未画出的位置。

输入结构
- 网格上有一条占满主对角线方向的单色标记斜线。
- 斜线一侧有一到两个实心矩形锚块，另一侧有相同数量的单色可动物体，
  形状任意，颜色与锚块不同。
- 每个可动物体沿水平或竖直方向朝斜线滑动，路径上没有画出的障碍。

规则
- 把每个锚块关于对角标记线做镜像（行列坐标互换式反射），得到不画出的
  虚障碍区域。
- 每个可动物体保持形状，朝斜线方向逐格平移，直到再前进一格就会与任一
  虚障碍或斜线本身重叠为止。
- 路径上没有虚障碍的物体一直滑到贴住斜线。
- 输出中锚块与斜线原样保留，可动物体只出现在新位置，虚障碍永不画出。

关键洞察
- 阻挡物从未被画出：它是对侧锚块跨对角线的镜像投影，行列互换的反射使
  "离线等距"无法靠水平目测得出；同一画面里有的物体撞虚墙、有的物体
  贴线停，逼迫解题者放弃表面的等距规律去重建那面看不见的墙。
```

## 2. 分隔线上的对位记号

- 参考题目: `5d2a5c43`, `79cce52d`
- 难度评审: 达标
- tags:
  - operation:透明叠加, transparent_overlay
  - operation:平移, translate
  - object:二值掩码, binary_mask
  - object:分隔列, divider_column
  - object:标记像素, marker_pixel
  - relation:双侧对齐, bilateral_alignment
  - condition:标记位定位移量, marker_is_shift
  - condition:并集合并, union_merge

### docstring

```text
先按分隔列上标记像素给出的行数错位对齐，再把两块面板并集成一种新颜色。

输入结构
- 一条单色整列分隔线把网格分成左右两块等大的黑黄面板，黄色格是掩码
  像素。
- 分隔列上恰有一个格被另一种标记颜色替换。

规则
- 记标记像素所在的行号为 k，顶行为 0。
- 把右面板整体向下平移 k 行，移出底部的行丢弃，顶部空出的行视为全黑，
  再与左面板逐格对齐。
- 输出一块与单侧面板等大的网格：对齐后任一面板为黄的格涂青色，其余
  为黑。
- 训练示例中有一例 k=0，看似朴素并集。

关键洞察
- 分隔列不只是边界，它是一条控制列：两块面板并不是天然对齐的，标记
  像素的行号给出了叠加之前必须补偿的错位量，k=0 的示例是诱饵。
```

## 3. 罗盘兼标尺的十字

- 参考题目: `d364b489`, `98cf29f8`, `79cce52d`, `99fa7670`
- 难度评审: 达标
- tags:
  - operation:平移, translate
  - object:十字图案, cross_pattern
  - object:孤立像素, isolated_pixel
  - relation:方位对应, direction_correspondence
  - condition:图例定方向, legend_defines_direction
  - condition:臂长定距离, arm_length_is_distance

### docstring

```text
网格中的彩色十字既是罗盘又是标尺：每种颜色的散点沿其颜色臂的方向移动，
移动格数等于该臂的长度。

输入结构
- 黑色背景上有唯一一个彩色十字团作图例：一个中心像素，向上、下、左、
  右伸出若干条臂，每条臂是一种颜色的连续直线段，各臂颜色互不相同、
  长度不等。
- 其余前景是散布的单像素彩点，颜色都出现在图例的臂上。
- 任意两点按规则移动后互不重叠、不出网格。

规则
- 图例整体保持不动。
- 每个彩点沿"其颜色的臂相对中心的方向"精确移动 L 格，L 为该颜色臂的
  长度；点与点之间、点与图例之间没有碰撞交互；原位置清空。
- 训练示例中多数彩点移动后恰好贴住网格边缘或图例，看上去像"朝该方向
  滑到底"的重力规则；但每个示例都有个别点移动后悬停在半空。

关键洞察
- 十字不只给方向还给距离：臂的朝向是该颜色的位移方向，臂的长度是位移
  的格数；"滑到底"是被刻意布置的错误捷径，悬停在半空的点是识破它的
  钥匙。
```

## 4. 排列里的表头

- 参考题目: `458e3a53`, `a406ac07`, `1e32b0e9`
- 难度评审: 达标
- tags:
  - operation:提取, extract
  - operation:重涂色, recolor
  - object:分隔线网格, separator_lattice
  - object:纯色单元格, solid_cell
  - relation:行列交叉, row_col_intersection
  - relation:阵列排布, array_layout
  - condition:纯色即表头, solid_is_header
  - condition:标签同色时填充, labels_match_fill
  - condition:忽略干扰项, ignore_distractors

### docstring

```text
用嵌在格阵内部、每行每列恰一个的纯色单元格充当行列表头，输出行表头
序列与列表头序列的等式表。

输入结构
- 一色分隔线把网格划成 n 行 n 列等大的单元格。
- 每行恰有一个单元格通体一色，每列也恰有一个，纯色格的位置构成一个
  排列；纯色格的颜色序列中存在重复颜色。
- 其余单元格填满多彩杂纹。

规则
- 第 i 行的表头色取该行纯色格的颜色，第 j 列的表头色取该列纯色格的
  颜色。
- 输出一个 n×n 网格：当第 i 行与第 j 列的表头色相同时，格 (i,j) 涂
  这个颜色，否则涂黑。

关键洞察
- 表头不在边框上，而是以每行每列恰一个纯色格的排列形式埋在格阵内部；
  由于颜色有重复，匹配亮格远多于纯色格本身的位置，"把纯色格位置降采样
  标出"的捷径在所有示例上都会失败，必须真正做两个表头序列的逐位全交叉
  比对。
```

## 5. 输出位移本身

- 参考题目: `79cce52d`, `5d2a5c43`
- 难度评审: 达标偏上
- tags:
  - operation:循环位移, cyclic_roll
  - operation:比对, compare
  - object:分隔列, divider_column
  - object:多彩面板, multicolor_panel
  - relation:双侧对齐, bilateral_alignment
  - relation:双轴偏移编码, dual_axis_offset
  - condition:输出编码参数, output_encodes_parameter

### docstring

```text
比对分隔线两侧的两块面板，反推出它们之间的循环位移量，并把这个位移向量
画成输出网格上的一个点。

输入结构
- 一条单色整列分隔线分开两块等大的多彩面板。
- 右面板由左面板向下循环滚动 dr 行、再向右循环滚动 dc 列得到。
- 面板图案没有平移自重合，位移量唯一。

规则
- 输出一个与单块面板等大的网格，通体涂分隔线的颜色。
- 仅把第 dr 行第 dc 列的那一个格涂成红色，行列都从 0 起数。

关键洞察
- 要输出的不是变换后的图案，而是变换本身：输出网格是一张位移向量表，
  那个孤点的行列坐标就是两个循环滚动量；把输出误当成滚动后的面板是
  第一眼的诱饵读法。
```

## 6. 吞下再停

- 参考题目: `dc2e9a9d`, `98cf29f8`, `d37a1ef5`, `5ffb2104`
- 难度评审: 达标
- tags:
  - operation:滑动, slide
  - object:空心矩形, hollow_rect
  - object:凸耳, tab
  - object:像素簇, pixel_cluster
  - relation:内部区域, interior_region
  - condition:凸耳决定方向, tab_determines_direction
  - condition:完整包含才停止, containment_stop

### docstring

```text
带凸耳的空心框沿凸耳方向滑动，穿过散点像素簇，直到把整团像素严格吞进
内腔才停下。

输入结构
- 黑色背景上有一个一格厚的空心矩形框，框的某一条边外侧带一个同色单
  像素凸耳。
- 沿凸耳所指方向的前方有一团另一种颜色的散点像素簇，簇的包围盒小于
  框的内腔。

规则
- 框连同凸耳沿凸耳方向逐格平移，途中允许框环与簇像素交叠。
- 框停在簇第一次完全位于内腔之内、不触碰框环任何一格的位置。
- 输出：原位置的框擦除，新位置画出框和凸耳，簇像素原样不动。

关键洞察
- 停止条件是完整包含而不是接触：把散点当障碍会让框停得太早，框必须
  径直穿过它们，直到整团像素落进肚子里；凸耳只给方向，何时停由包含
  关系裁定。
```

## 7. 搬进画外的家

- 参考题目: `d37a1ef5`, `dc2e9a9d`, `66ac4c3b`
- 难度评审: 达标
- tags:
  - operation:镜像, mirror
  - operation:擦除, erase
  - object:空心矩形, hollow_rect
  - object:标记像素, marker_pixel
  - object:画布边界, canvas_boundary
  - relation:相对方位, relative_orientation
  - condition:方位决定镜像轴, orientation_determines_axis
  - condition:画外裁剪, offcanvas_clipping

### docstring

```text
把源框内的图案按两框相对方位镜像后搬进目标框，而目标框有一部分伸出网格
边缘、从未画出，搬运结果也随之被裁剪。

输入结构
- 黑色背景上有两个同色空心矩形框。
- 源框完整可见，内腔有若干彩色标记像素。
- 目标框与源框同尺寸，但被网格边缘裁掉一部分，画面上只剩残缺的框环，
  其内腔可见部分全黑。
- 两框沿水平或垂直方向错开。

规则
- 先由"两框同尺寸"这一约束补全目标框（含画外部分），建立其内腔坐标系。
- 按内腔相对坐标把源框标记复制进目标框：若目标框在源框的左侧或右侧，
  复制前先把图案在内腔内水平镜像；若在上方或下方，则先垂直镜像。
- 落在网格之外的像素丢弃。
- 复制完成后擦除源框内的所有标记，两个框的可见部分保持不变。

关键洞察
- 目标容器从未被完整画出：它的内腔坐标系必须用与源框同尺寸这一约束
  反推重建；随后的镜像轴又不由图案自身决定而由两框方位决定，最后还要
  接受画外裁剪，三层缺一不可。
```

## 8. 两股颜色相遇处留白

- 参考题目: `7666fa5d`, `5d2a5c43`, `d37a1ef5`
- 难度评审: 达标
- tags:
  - operation:填充, fill
  - object:对角线段, diagonal_segment
  - object:平行四边形区域, parallelogram_region
  - relation:平行配对, parallel_pairing
  - relation:重叠区域, overlap_region
  - condition:段间区域填充, fill_between_segments
  - condition:重叠即抵消, overlap_cancels

### docstring

```text
分别往两族平行斜线段之间灌各自的颜色，两片填充相遇的格子不涂色而留作
背景。

输入结构
- 背景为最常见色。
- 两种前景颜色各自形成若干条反对角线短线段，同色线段两两平行、隔空
  相对，围出待填充的平行四边形条带。

规则
- 对每种颜色，沿主对角线方向把同色相邻线段之间的背景格填成该色，方法
  与单族填充相同。
- 若某格同时落在两种颜色的填充区域内，则保持背景色不涂。
- 线段本身原样保留。
- 训练示例中有一例两族区域不相交。

关键洞察
- 第一层规则是往线段之间灌色，但还有第二层：两股颜色的势力范围重叠时
  不混色、不覆盖，而是互相抵消留白，只有恰好属于一族的格子才被染色；
  不相交的示例是诱饵，会让人以为只是两次独立填充。
```

## 9. 穿墙即染色

- 参考题目: `5ffb2104`, `a406ac07`, `8886d717`, `98cf29f8`
- 难度评审: 达标
- tags:
  - operation:重力下落, gravity_drop
  - operation:重涂色, recolor
  - object:孤立像素, isolated_pixel
  - object:墙线段, wall_segment
  - relation:碰撞阻挡, collision_blocking
  - relation:连锁反应, chain_reaction
  - condition:同色即停, same_color_stops
  - condition:穿墙改色, pass_through_dyes

### docstring

```text
顶部的彩色落体竖直下落，穿过异色墙时被染成墙色，直到遇到与当前颜色相同
的墙才停在墙上。

输入结构
- 黑色背景。上部散布若干单像素彩色落体，每列至多一个。
- 下方有若干条各自单色的水平墙线段，处于不同高度、覆盖不同的列区间，
  互不接触。

规则
- 每个落体在自己的列内竖直下落，自上而下逐一遇到下方的墙。
- 遇到一堵墙时：若墙色等于落体当前颜色，落体停在这堵墙的正上方一格；
  若不等，落体穿过这堵墙，并把自身颜色改成这堵墙的颜色，继续下落。
- 一路没有停下的落体以它最终的颜色落在底行上。
- 墙全部原样保留，落体的原始位置清空。

关键洞察
- 墙既是滤网又是染缸：停不停的判据不是落体的初始颜色，而是它一路被
  沿途墙壁不断改写的当前颜色，前一堵墙决定了它对下一堵墙的反应；只用
  初始颜色判定的读法在多墙的列上会给出错误落点。
```

## 10. 坐标就是滚动量

- 参考题目: `1e32b0e9`, `79cce52d`
- 难度评审: 达标
- tags:
  - operation:循环位移, cyclic_roll
  - operation:补全, completion
  - object:模板, template
  - object:分隔线, divider_line
  - relation:阵列排布, array_layout
  - condition:坐标即参数, coordinate_is_parameter
  - condition:缺格补全, missing_cell_completion

### docstring

```text
九宫阵列里每个子格都是模板按自己所在的行列号循环滚动后的样子，把被涂黑
的那个子格补全。

输入结构
- 单色分隔线把网格分成 3×3 个等大的正方形子格。
- 左上子格是模板；位于阵列第 i 行第 j 列的子格是模板向下循环滚动 i 行、
  向右循环滚动 j 列的结果，行列从 0 起数。
- 恰有一个子格被整块涂黑。

规则
- 找出被涂黑子格的阵列坐标 (i,j)，用模板向下滚 i 行、向右滚 j 列重建
  其内容并填回。
- 若被涂黑的恰是左上模板格，则用任一其他子格按其坐标反向滚动还原模板
  后填回。
- 输出整个网格，其余部分原样不动。

关键洞察
- 九个子格既不是同一幅图的重复，也不是彼此独立的图案：每格与模板之间
  的循环位移量恰好等于它自己的阵列坐标，位置本身就是变换参数；把阵列
  当成同图复制来补全会得到错误答案。
```
