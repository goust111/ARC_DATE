## 1. 十字算盘

- 参考题目题号：18（ac0c2ac3）、12（4093f84a）、17（1efba499）
- tags:
  - operation:滑动, sliding
  - operation:检测, detection
  - object:同心方环, concentric_ring
  - object:图例码本, legend_codebook
  - object:标记像素, marker_pixel
  - relation:距离映射, distance_mapping
  - condition:切比雪夫距离, chebyshev_distance
  - condition:同侧滑动, same_side_slide

### docstring

```text
把十字臂上的彩色珠子滑到图例码本规定的半径位置。

输入结构
- 黑色背景。网格一角有一个奇数边长的小型同心方环图案（图例），每一环恰为一种颜色，
  与场景其余部分由空白隔开。
- 场景中有一个唯一的灰色中心像素；若干彩色像素分布在中心所在的行或列上，
  每条半行/半列上至多一个，颜色都出现在图例中。

规则
- 从图例读出码表：每种颜色对应它那一环到图例中心的切比雪夫距离 d。
- 每个彩色像素沿自己所在的行或列滑动，保持在中心的同一侧，
  停在与中心距离恰为 d 的格子上；已经处在正确距离的像素不动。
- 灰色中心与角落图例原样保留。

关键洞察
- 角落的小同心环不是要变换的对象，而是一张颜色到半径的码表；
  珠子的当前位置是无效信息，颜色才是它真正的地址。
```

## 2. 窗口碎片修复

- 参考题目题号：19（dc0a314f）、16（e8686506）、6（446ef5d2）
- tags:
  - operation:拼图组装, jigsaw_assemble
  - operation:裁剪, crop
  - object:遮挡块, occluder
  - object:矩形碎片, rectangular_piece
  - object:单色区域, mono_region
  - relation:边界颜色延续, boundary_continuation
  - condition:仅平移, translation_only
  - condition:无对称场景, no_symmetry

### docstring

```text
用散落的碎片修复被遮挡的窗口，锚点是窗口边缘的颜色延续，输出只给窗口内容。

输入结构
- 场景占据网格中的一个矩形区域，由若干大块单色矩形区域拼成，整体没有任何对称性；
  场景外的空白为黑色。
- 场景内有一个唯一颜色的实心矩形遮挡块（窗口），该颜色仅出现于此；
  场景中任何单色区域的边界都不与窗口边界重合。
- 空白处散落若干小矩形碎片，不含遮挡色，总面积恰等于窗口面积。

规则
- 只用平移（不旋转不镜像）把全部碎片无重叠地铺满窗口。
- 铺放必须使窗口边界上每个格子的颜色与紧邻窗口外的场景格颜色相同
  （被切开的单色区域向窗口内延续），满足此约束的铺法唯一。
- 输出为铺好后窗口内部的裁剪图。

关键洞察
- 场景没有对称性可用，镜像恢复的思路是死路（诱饵）；
  真正的答案在碎片里，而窗口一圈的颜色延续是唯一的定位锚。
```

## 3. 双影还原

- 参考题目题号：14（db93a21d）、1（ba97ae07）、19（dc0a314f）
- tags:
  - operation:检测, detection
  - operation:填充, fill
  - object:投影线段, projection_segment
  - object:正方形, square
  - object:网格边缘, grid_edge
  - relation:行列交叉定位, row_col_intersection
  - relation:遮挡层级, occlusion_order
  - condition:等长配对, equal_length_pairing
  - condition:小者在上, smaller_on_top

### docstring

```text
用底边和左边的两组影子线段反推从未画出的正方形，并按小者在上处理重叠。

输入结构
- 黑色背景。底边一行上有若干彩色横线段，左边一列上有若干彩色竖线段，线段互不接触。
- 每条底边线段是某个隐形实心正方形的列范围投影，每条左边线段是某个正方形的行范围投影；
  同一个正方形的两条投影颜色相同、长度相同。
- 所有正方形的边长互不相同；同一种颜色可能属于多个正方形。

规则
- 把底边线段与左边线段按长度相等配对（长度互异保证配对唯一）。
- 在每对投影的行范围与列范围的交叉处画出该颜色的实心正方形。
- 若两个正方形区域重叠，重叠处显示边长较小者的颜色（小方块在上层）。
- 边上的投影线段原样保留。

关键洞察
- 画面上从未出现正方形本体，只有它在两条边上的影子；
  配对的依据是长度而不是颜色——同色多方块会让按颜色配对出错（诱饵），
  而重叠层级由尺寸而非出现顺序决定。
```

## 4. 走廊同步的房间

- 参考题目题号：2（b9630600）、7（25e02866）
- tags:
  - operation:透明叠加, overlay
  - operation:检测, detection
  - object:填充矩形, filled_rectangle
  - object:走廊, corridor
  - object:标记像素, marker_pixel
  - relation:走廊连通分组, corridor_connectivity_group
  - relation:同尺寸对齐, same_size_align
  - condition:组内取并集, union_within_group

### docstring

```text
只在走廊连通的房间之间合并标记图层，孤立房间保持原样。

输入结构
- 黑色背景上分布若干同尺寸、同底色的实心矩形房间，每间嵌有若干非底色的标记像素。
- 部分房间之间由一种专用颜色的宽度为 1 的直线走廊连接，走廊两端各接在一间房间的墙上。

规则
- 按走廊把房间划分为连通组。
- 每个连通组内，把所有房间的标记像素按房内相对坐标取并集，
  然后把这份并集叠印回该组的每一间房间；组内标记保证无颜色冲突。
- 不与任何走廊相连的房间保持不变；走廊本身原样保留。

关键洞察
- 房间确实是同一模板的图层，但合并的范围不是全体房间，
  而是由走廊网络的连通分量决定；把所有房间一股脑合并会在部分示例上得到错误答案
  （诱饵：某个示例恰好只有一个连通组）。
```

## 5. 自带重力的容器

- 参考题目题号：13（855e0971）、4（5e6bbc0b）、17（1efba499）
- tags:
  - operation:压缩, compact
  - operation:检测, detection
  - object:矩形区域, rect_region
  - object:移动像素, moving_pixel
  - object:障碍像素, obstacle_pixel
  - relation:包含, containment
  - relation:碰撞阻挡, collision_blocking
  - condition:长宽比选轴, aspect_selects_axis
  - condition:多数半边定向, majority_half_orients
  - condition:共享色即障碍, shared_color_is_obstacle

### docstring

```text
每个矩形容器内的移动像素沿容器长轴、朝移动像素较多的一端压实，途中被共享障碍色像素挡住分段堆积。

输入结构
- 黑色背景上分布若干互不接触的单色非正方形实心矩形容器，底色可各不相同。
- 每个容器内部嵌有两类非底色像素：一类是该容器专属的移动色像素
  （该颜色只出现在这一个容器里）；另一类是障碍色像素，
  障碍色是唯一在多个容器中都出现的颜色。
- 以长轴中点为界把容器分成两半（长度为奇数时中线不计），
  每个容器两半的移动像素数保证不相等。

规则
- 对每个容器独立处理：压实的轴取容器的长轴，朝向取移动像素较多的那一端。
- 宽容器内逐行、高容器内逐列，移动像素向该端滑动，
  遇到端壁、障碍像素或先前停下的移动像素即停；障碍像素固定不动；
  空出的格子恢复容器底色。
- 容器外形与背景不变。

关键洞察
- 没有全局重力，也没有外部方向标记——压实的轴写在容器的形状里，
  朝向写在容器自己的内容分布里；哪种颜色是障碍不靠图例，
  而靠唯一跨容器共享这一身份识别；障碍把每行/列切成小段，
  移动像素只在段内堆积（诱饵：某个示例中所有容器方向恰好一致，看起来像全局重力）。
```

## 6. 手性冲压

- 参考题目题号：20（7df24a62）、11（d2acf2cb）
- tags:
  - operation:模式匹配, pattern_match
  - operation:填充, fill
  - operation:颜色互换, color_swap
  - object:矩形精灵体, rect_sprite
  - object:标记像素, marker_pixel
  - relation:旋转镜像判别, chirality_detection
  - condition:镜像匹配则负片, mirror_match_negates

### docstring

```text
按散落星座冲压源精灵：旋转匹配印正片，镜像匹配印负片。

输入结构
- 黑色背景上有一个实心矩形源精灵：底色填充并嵌有若干标记色像素，
  标记掩码没有任何旋转或镜像自对称（八个刚体变换结果互不相同）。
- 其他地方散落着标记色像素，其中一些成组构成源掩码某个刚体变换（旋转或镜像）
  后的精确拷贝，且该拷贝矩形足迹内的其余格子全为背景。

规则
- 找到源矩形，枚举其标记掩码的全部旋转与镜像。
- 对每个匹配成功的星座：若匹配变换是纯旋转（含不动），
  把足迹内的背景格涂成底色（正片冲压）；若匹配必须经过镜像，
  则把足迹内的背景格涂成标记色、并把星座像素改涂成底色（负片冲压）。
- 源精灵与不构成任何匹配的散落像素保持不变。

关键洞察
- 冲压之前必须判断这份拷贝的手性：同一个星座旋转版和镜像版的区别只是几何朝向，
  却决定了整块印出来是正片还是负片——颜色规则由几何手性驱动。
```
