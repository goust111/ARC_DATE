## 1. 双轴投影签名

- 参考题目题号：5、15、16
- tags:
  - operation:计数, counting
  - operation:提取, extract
  - operation:擦除, erase
  - object:精灵体, sprite
  - object:直方图条带, histogram_band
  - relation:双轴投影匹配, dual_axis_projection_match
  - condition:唯一同时匹配, unique_joint_match
  - condition:忽略干扰项, ignore_distractors

### docstring

```text
从内部多个同色精灵中，找出唯一一个其逐列、逐行像素计数同时与顶部和左侧
黄色直方图条带吻合的精灵，单独保留。

输入结构：
- 黑色背景。顶部条带与主区域之间隔一条完整灰色横线，左侧条带与主区域之间
  隔一条完整灰色竖线，左上角落区域留黑。
- 顶部条带内每一网格列有一段自灰线向上生长的黄色柱（长度可为零），左侧
  条带内每一网格行有一段自灰线向左生长的黄色横条。
- 主区域散布若干互不接触的绿色精灵（全部同色，颜色不构成线索）。
- 数据保证：恰有一个精灵双轴同时匹配；存在只匹配单轴的诱饵精灵。

规则：
- 顶部条带第 c 列柱长等于目标精灵在主区域第 c 列占据的格子数，左侧条带
  第 r 行条长等于目标精灵在第 r 行占据的格子数，均按绝对行列对齐。
- 输出与输入同尺寸，只保留目标精灵原位原样，其余一切（条带、灰线、其他
  精灵）全部置黑。

关键洞察：
- 黄色柱既不是坐标指针也不是独立图案，而是某个内部精灵的两轴像素计数
  投影签名；单看任一轴都会被诱饵骗到，必须双轴同时吻合才能锁定唯一目标。
```

## 2. 尾焰滑动与动量接力

- 参考题目题号：11、12、20
- tags:
  - operation:滑动, slide
  - object:可移动对象, movable_object
  - object:尾焰凸起, tail_flame_projection
  - object:锚点方块, anchor_square
  - relation:碰撞阻挡, collision_blocking
  - relation:动量接力, momentum_relay
  - condition:凸起反向决定方向, projection_opposite_direction

### docstring

```text
红色对象沿其尾焰凸起的反方向滑动，撞上物体时自己停下、把动量传给被撞者，
被撞者沿同方向继续滑动，接力直至有物体抵达边缘或紧贴静止的青色锚块。

输入结构：
- 黑色背景；若干红色对象，每个为实心矩形主干加恰好一个从某侧伸出的
  单像素凸起（尾焰）。
- 若干灰色实心方块（无凸起，自身不主动运动）；一个固定青色 2x2 锚块。
- 数据保证：每条运动线路上的碰撞次序唯一、路径互不交叉；示例中既有朝
  青色锚块运动的对象也有背离它的对象；存在两级以上的接力链（红撞灰、
  灰再撞灰）。

规则：
- 凸起相对主干的朝向记为 d，红色对象沿 d 的反方向整体平移。
- 任何运动中的物体在即将与下一物体 4 邻接时停下，被撞的物体沿同一方向
  继续滑动；被接力的物体若前方直到边缘无物体，则滑到紧贴边缘。
- 青色锚块被撞时不动，运动到此终止。输出为所有物体的最终位置。

关键洞察：
- 其一，方向不是凸起所指也不是被锚块吸引，而是凸起（尾焰）的反方向；
  其二，碰撞不是简单停靠，动量像牛顿摆一样只传给被撞者，链条上只有
  最末一个物体走完剩余路程。
```

## 3. 孔洞数定周期、长度序选取

- 参考题目题号：13、16、18
- tags:
  - operation:重涂色, recolor
  - operation:计数, counting
  - operation:排序, sort
  - operation:擦除, erase
  - object:横条, horizontal_bar
  - object:孔洞团块, holed_blob
  - condition:孔洞数决定周期, hole_count_determines_period
  - condition:按长度排序选取, select_by_length_rank

### docstring

```text
以灰色团块的孔洞数 N 为周期，把横条按"长度从短到长"排序后序号为 N 的
倍数的横条原地涂红，并擦除灰色团块。

输入结构：
- 黑色背景；若干互不接触、长度互不相等的实心横条（蓝或青混杂，颜色与
  规则无关），自上而下排列。
- 角落处一个灰色团块，内部含若干完全被灰色包围的黑色孔洞。
- 数据保证：不同示例的 N 不同；团块像素总数与孔洞数刻意不等；示例一中
  长度排序恰与自上而下位置排序一致（诱导位置序假设），后续示例打破。

规则：
- 数出团块孔洞数 N（孔洞为团块包围盒内不与外部连通的黑色 4 连通区域）。
- 把横条按长度从短到长编号 1,2,3,…；编号为 N 倍数的横条整条原地涂红，
  其余横条不变。
- 灰色团块在输出中擦为黑色。

关键洞察：
- 既要发现周期 N 藏在团块的拓扑（孔洞数）里而非其大小或颜色，又要发现
  排序键是长度序而非画面上下的位置序；示例一的巧合排列是诱饵，团块只是
  参数载体，用完即弃。
```

## 4. 邻居房间数染色

- 参考题目题号：3、13
- tags:
  - operation:重涂色, recolor
  - operation:计数, counting
  - object:连通区域, connected_region
  - object:分隔墙, partition_wall
  - relation:墙分隔区域, wall_partitions_regions
  - relation:邻接关系图, adjacency_graph
  - condition:邻居数决定颜色, neighbor_count_determines_color

### docstring

```text
把每个被灰墙分隔出的黑色房间按其隔薄墙相邻的房间数量重涂颜色。

输入结构：
- 一格宽灰色墙线把网格划分成若干黑色房间（4 连通区域），布局不规则、
  房间大小形状各异。
- 数据保证：房间面积与邻居数刻意不相关；示例一中最大房间恰好邻居最多，
  形成"面积决定颜色"的诱饵，示例二打破。

规则：
- 两个房间若存在某个灰墙格同时与二者 4 邻接，则互为邻居。
- 数每个房间的邻居数 k：k=1 涂蓝，k=2 涂红，k=3 涂黄，k=4 涂绿
  （数据保证 k 不超过 4）。
- 墙保持灰色，网格边缘不算邻居。

关键洞察：
- 颜色与房间自身的面积、形状、位置都无关，取决于分隔结构的关系图——
  隔着一格薄墙能碰到多少个不同的房间；特征在房间之间，而不在房间内部。
```

## 5. 隐形弹道的出口标记

- 参考题目题号：9、17、19
- tags:
  - operation:射线延伸, ray_cast
  - operation:反射, reflect
  - object:对角线段, diagonal_segment
  - object:矩形障碍, rect_obstacle
  - object:路径端点, path_endpoint
  - relation:碰撞反弹, collision_bounce
  - condition:端点编码方向, endpoints_encode_direction
  - condition:路径不显影, path_not_drawn

### docstring

```text
从每个发射器沿对角方向射出一条不显影的光线，经红色矩形多次反弹后，
仅在其离开网格前经过的最后一格涂黄。

输入结构：
- 黑色背景；若干发射器，每个由两格青色尾部加一格黄色头部排成一条
  对角线，尾到头的对角方向即发射方向。
- 若干红色实心矩形障碍。
- 数据保证：光线不会正对矩形的角、不会击中发射器；每个示例至少有一条
  光线反弹两次以上（排除直线出界捷径）。

规则：
- 光线从黄色头部出发，沿尾到头的对角方向逐格前进。
- 将要撞入红色格时，被红色阻挡的那一侧分量取反（数据保证每次反弹只需
  翻转一个分量），继续前进；光线可多次反弹。
- 光线走出网格时，把它在网格内经过的最后一格涂黄。输出为输入原样
  （发射器、矩形保留）加上这些黄色出口标记，路径本身不画。

关键洞察：
- 输出中多出的孤立黄点是隐形弹道的出口——整条路径从未画出，只留下
  生成元（发射器）与残迹（出口点），必须由发射方向与红色矩形的反弹
  几何在脑中重建全程。
```

## 6. 展开与坍缩的状态翻转

- 参考题目题号：1、13
- tags:
  - operation:展开, expand
  - operation:交替填色, alternating_fill
  - operation:擦除, erase
  - object:线段, line_segment
  - object:金字塔, pyramid
  - relation:中心对称展开, center_expand
  - relation:互逆变换, inverse_transform_pair
  - condition:状态决定方向, state_determines_direction
  - condition:奇偶决定颜色, parity_determines_color

### docstring

```text
把每条竖直线段展开成以它为轴的交替双色金字塔，同时把已有的金字塔坍缩回
其生成线段。

输入结构：
- 黑色背景上有两类互不接触的对象：
- (a) 单色竖直线段，颜色各异且非灰；
- (b) 交替双色金字塔——底行最宽、逐行收窄至一格塔尖，每行以中心列为轴，
  离中心水平距离为偶数的格是轴色、为奇数的格是灰色。
- 某个示例只含线段（诱导"全部展开"的假设），混合示例揭示双向规则。

规则：
- 展开操作定义：长度 L、颜色 A、底端在第 r 行第 c 列的竖线，展开为高 L
  的金字塔：第 i 层（i=0 为底层第 r 行，向上递增）宽 2(L-1-i)+1、以第 c
  列为中心，偶距格涂 A、奇距格涂灰。
- 输出中：每条竖线被其展开像替换；每座金字塔被其唯一逆像——中心列上
  自底行向上、长为塔高、颜色为轴色的竖线——替换。

关键洞察：
- 线段与金字塔是同一展开算子的前后两态；解题不是套用单向变换，而要先
  判断每个对象处于哪一态，再沿相反方向走一步。
```

## 7. 网内类比

- 参考题目题号：6、7、10、14
- tags:

  - operation:旋转, rotate
  - operation:擦除, erase
  - object:精灵体, sprite
  - relation:同色示范对, same_color_demo_pair
  - relation:类比迁移, analogy_transfer
  - condition:唯一变换识别, unique_transform_identification

### docstring

```text
由同色的一对精灵示范一种刚体变换，把该变换原地施加到颜色不同的第三个
精灵上。

输入结构：
- 黑色背景上恰有三个互不接触的精灵。
- 其中两个同色（示范对），互为同一形状经{水平镜像、垂直镜像、顺时针
  90 度、逆时针 90 度、180 度}之一变换的结果；形状足够不对称，使连接
  两者的变换唯一。
- 第三个精灵颜色不同（查询对象），其包围盒为正方形。
- 数据保证：不同示例使用的变换不同；示范对之间的相对位移与规则无关。

规则：
- 识别示范对之间唯一成立的变换 T。
- 把查询精灵绕其自身包围盒中心施加 T：原像擦除，变换像原地绘制。
- 示范对在输出中原样保留。

关键洞察：
- 变换规则不在题外固定，而由画面内部的同色对现场示范；示范对之间的
  相对位移是干扰信息——要迁移的是姿态变换本身，而不是平移向量。
```

## 8. 侧色归巢与障碍反转

- 参考题目题号：2、9、20
- tags:
  - operation:平移, translate
  - object:边框边, frame_side
  - object:内部像素, interior_pixel
  - object:矩形障碍, rect_obstacle
  - relation:颜色匹配边, color_match_side
  - condition:障碍反转目的地, obstacle_flips_destination

### docstring

```text
内部像素朝与自己同色的边框边直线飞去并贴边停下，路径被灰色方块挡住的
像素改为飞到对侧边贴边停下。

输入结构：
- 网格四边是一格厚的边框：四角为黑色，四条边各为一种互不相同的纯色。
- 内部散布与某条边同色的像素，以及若干灰色实心方块（障碍）。
- 数据保证：反向路径畅通，没有两个像素停在同一格；示例中存在像素离
  匹配边更远的情形（排除"就近停靠"捷径）；无障碍示例先诱导"直达匹配边"
  假设，含障碍示例打破。

规则：
- 每个内部像素沿指向其同色边框边的垂直方向直线移动。
- 若从当前位置到该边的路径上没有灰色格，则移动到紧贴该边内侧的一格停下。
- 若路径上有灰色格，则改为沿相反方向移动到紧贴对侧边内侧的一格停下。
- 灰色方块与边框保持不动。

关键洞察：
- 边框侧色规定像素的归属方向，但灰色障碍不是让像素中途停下，而是把
  目的地整个翻转到对侧——第一眼形成的"就近停靠"或"直达匹配边"假设都会
  在含障碍的示例上失效。
```
