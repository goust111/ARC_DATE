## 1. 旋转变色对称补全

- tags:
  - operation:对称补全, symmetry_completion
  - operation:颜色置换, color_permutation
  - object:对称图案, symmetric_pattern
  - object:掩码像素, masked_pixel
  - relation:旋转轨道映射, rotation_orbit_mapping
  - condition:旋转伴随换色, rotation_coupled_recolor
- 参考题目题号: 2, 16

### docstring

```text
用同旋转轨道上的可见像素并施加相应次数的颜色循环，恢复每个被粉色掩码遮住的格子。

输入结构:
- 网格为正方形，几乎填满彩色图案，若干粉色像素是掩码。
- 完整图案满足：绕中心旋转90度后图形位置重合，但每个颜色被一个固定的颜色循环替换为下一个颜色。
- 另有一种不参与循环的稳定色，旋转后颜色保持自身。

规则:
- 先比较同一旋转轨道上相隔90度的两个可见格子，自举推断出颜色循环。
- 对每个粉色格子，找到其旋转轨道上任一可见格子，按二者相隔的旋转次数沿循环推进颜色，填入结果。
- 非掩码格子全部保持不变。

关键洞察:
- 图案的对称不是"颜色不变"的普通对称，而是"旋转一次、换色一步"的等变对称；
  稳定色让朴素的复制式补全在部分格子恰好成立，成为掩盖真规则的诱饵。
```

## 2. 槽位类比累计

- tags:
  - operation:类比推理, analogy_inference
  - operation:旋转, rotate
  - operation:重涂色, recolor
  - object:分隔线, divider_line
  - object:槽位, slot
  - relation:顺序排列, sequential_order
  - condition:逐槽累计复合变换, cumulative_composite_transform_per_slot
- 参考题目题号: 1, 8

### docstring

```text
用前两个槽位现场给出的复合变换，逐槽累计地填满其余空槽。

输入结构:
- 灰色分隔线把网格等分成一行有序的同尺寸区域。
- 第一、二个区域分别画有图案A与图案B，其余区域全黑。
- B恰为A经同一个复合变换T的结果：一次90度旋转叠加一组颜色对调。

规则:
- 比对A与B，同时推断T的旋转分量与颜色对调分量。
- 每个后续空槽等于前一个槽位再施加一次完整的T。
- 分隔线原样保留。

关键洞察:
- 变换不是预设的固定旋转，而是由前两槽这对现场样例定义的复合操作；
  只匹配形状会漏掉颜色对调，只匹配颜色会漏掉旋转，二者必须同时从样例读出并逐槽累计。
```

## 3. 级联拉伸

- tags:
  - operation:拉伸, stretch
  - operation:级联激活, cascade_activation
  - object:实心矩形, solid_rectangle
  - object:标记点, marker_pixel
  - relation:行列对齐, row_column_alignment
  - condition:拉伸解锁新标记, stretch_unlocks_new_marker
- 参考题目题号: 4, 5

### docstring

```text
让带边框矩形朝对齐的标记逐级拉伸，直到再无新的标记落入它的行列跨度。

输入结构:
- 背景上有一个由边框色和内部色构成的矩形，以及若干孤立的单像素标记。
- 初始时恰有一个标记与矩形行列对齐（位于矩形的正上、正下、正左或正右方向）。

规则:
- 将矩形沿对齐方向拉伸，使外边框推进到该标记所在的行或列，标记被新边框吞并。
- 拉伸后重新检查：若有原本不对齐的标记落入扩大后矩形的行或列跨度，则继续向它拉伸。
- 重复到没有对齐标记为止；始终不对齐的标记在输出中原样保留。

关键洞察:
- 拉伸不是一次性的：每次生长都扩大矩形的行列覆盖，从而"解锁"下一个标记；
  哪些标记参与、以什么顺序参与，由生长过程自身逐步决定，而非初始布局一眼可见。
```

## 4. 形状钥匙与泛洪

- tags:
  - operation:形状匹配, shape_match
  - operation:泛洪填充, flood_fill
  - object:封闭墙, closed_wall
  - object:孔洞, hole
  - object:精灵体, sprite
  - object:填充种子, fill_seed
  - relation:形状匹配孔洞, shape_matches_hole
  - condition:匹配封堵改变连通, match_seals_connectivity
- 参考题目题号: 3, 17

### docstring

```text
先用墙外精灵按形状封堵墙上匹配的孔洞，再让种子颜色从内域经剩余开孔泛洪到外部。

输入结构:
- 一圈闭合墙围出内域，墙上开有若干形状各异的缺口。
- 内域中有一个填充种子像素；墙外散布若干单色小精灵。
- 部分精灵的形状与某个缺口相同（允许旋转或翻转）；有的缺口没有匹配精灵，也存在无匹配的干扰精灵。

规则:
- 每个与缺口形状匹配的精灵消失于原位，其颜色填入对应缺口，将缺口封死。
- 种子颜色从种子处4连通泛洪：染满内域，并经未封堵的缺口漏出，在墙外继续蔓延至网格边界。
- 墙体、已封堵缺口与留在原地的干扰精灵都阻挡洪水，干扰精灵保持原样。

关键洞察:
- 形状匹配不是终点而是开关：它决定墙上哪些缺口仍然连通内外，从而决定洪水的最终版图；
  不匹配的精灵既是配对阶段的干扰项，又是外部泛洪要绕开的礁石。
```

## 5. 双投影定位

- tags:
  - operation:旋转, rotate
  - operation:计数, counting
  - operation:绘制, drawing
  - object:投影条, projection_bar
  - object:图例精灵, legend_sprite
  - relation:投影一致性, projection_consistency
  - condition:唯一姿态放置, unique_pose_placement
- 参考题目题号: 12, 1, 7

### docstring

```text
把图例精灵旋转后放进画布，使其行、列像素计数与两条边上的投影条完全吻合。

输入结构:
- 顶部边缘每列悬挂一段竖直短条，长度等于目标精灵在该列的像素数；
  左侧边缘每行伸出一段水平短条，长度等于目标精灵在该行的像素数；无占用的行列没有条。
- 一个角落的封闭小框内画着精灵样板；画布其余部分为空。

规则:
- 数出顶部与左侧各条的长度，得到目标的列计数轮廓与行计数轮廓。
- 将样板精灵旋转某个90度的倍数放到画布中，使两组计数同时吻合；合法的旋转与位置组合恰有一个。
- 在该位置画出旋转后的精灵；投影条与图例小框保持不变。

关键洞察:
- 要画的对象从未出现在目标位置，画面上只有它的两个一维影子；
  影子的长度轮廓同时锁定精灵的朝向与落点——只对上外接框的宽高还不够，必须逐行逐列对上计数。
```

## 6. 镜像幽灵障碍

- tags:
  - operation:射线延伸, ray_extension
  - operation:镜像, mirror
  - object:双面板, dual_panel
  - object:障碍物, obstacle
  - object:方向精灵体, directional_sprite
  - relation:镜像位置对应, mirrored_position_correspondence
  - condition:幽灵障碍阻挡, ghost_obstacle_blocking
- 参考题目题号: 11, 6, 5, 17

### docstring

```text
让射线在本面板直行，但把另一面板的障碍按镜像位置折算进来一起参与阻挡。

输入结构:
- 一条灰色直线把网格分成镜像对应的两个等大面板。
- 一个面板里有一个箭头精灵，缺角指示其发射方向。
- 两个面板各散布一些实心障碍块，位置互不相同。

规则:
- 从箭头沿其指向发射射线，逐格涂上箭头颜色。
- 射线遇到障碍即停——无论该障碍画在本面板，还是画在另一面板的镜像对应位置（幽灵障碍）。
- 同时在另一面板的镜像位置画出整条射线的镜像副本。

关键洞察:
- 两个面板是同一空间的两次曝光：任一面板"空着"的格子未必可通行，
  真正的障碍集合是两面板障碍经镜像映射后的并集；只看本面板会在幽灵障碍处穿墙。
```

## 7. 残迹反演补因

- tags:
  - operation:因果反演, causal_inversion
  - operation:旋转, rotate
  - operation:绘制, drawing
  - object:虚线射线, dotted_ray
  - object:发射器精灵, emitter_sprite
  - object:残迹像素, residue_pixel
  - relation:现场范例映射, in_scene_exemplar_mapping
  - condition:残迹定向定位, residue_orients_and_anchors
- 参考题目题号: 19, 9, 6

### docstring

```text
借助唯一完整的"发射器+射线"范例和每条残迹旁仅存的一粒残片，为其余射线补回朝向与位置都正确的发射器。

输入结构:
- 黑背景上有若干条间隔一格涂色的虚线射线，其中有的射线两端都抵达网格边缘。
- 恰有一条射线的一端连着完整的非对称发射器精灵，其姿态与该射线方向保持固定的相对关系。
- 其余射线的发射器已被抹去，只在原处各留下一个孤立的残片像素；
  每条射线连同其发射器或残片各用一种颜色。

规则:
- 从完整实例读出发射器形状、它与射线方向的相对姿态、以及它贴合射线端点的方式。
- 对每条残缺射线，在两端与四个90度朝向中，选择使发射器恰好覆盖该残片像素、
  且覆盖处与范例中同一相对位置像素对应的那个端点与朝向；按此画出发射器，用该射线自己的颜色。
- 完整实例与所有射线保持不变。

关键洞察:
- 对贯穿两边的射线，方向无法从射线本身读出；孤立的残片像素既指认哪一端是"因"的所在，
  又通过与范例逐像素对位锁定发射器的精确落点——一粒看似噪点的像素同时承担定向与定位两职。
```

## 8. 变色镜路由

- tags:
  - operation:射线延伸, ray_extension
  - operation:重涂色, recolor
  - object:斜镜, diagonal_mirror
  - object:起点标记, start_marker
  - relation:反射转向, reflection_turn
  - condition:颜色随镜更新, color_updates_per_mirror
  - condition:同色透射, same_color_transparency
- 参考题目题号: 18, 5, 12, 14

### docstring

```text
从起点发射光束，按斜镜转向前进，路径颜色在每次反射后换成该镜的颜色，且同色镜对光束透明。

输入结构:
- 黑背景网格的边缘上有一个起点像素。
- 内部散布若干两像素的斜对角镜子，摆放呈"/"或"\"两种朝向，每面镜子是单一颜色。

规则:
- 光束从起点沿垂直于所在边的方向进入网格，路径格涂当前颜色，初始颜色为起点颜色。
- 光束进入镜子格时：若光束当前颜色与该镜相同，则直穿且颜色不变；
  否则按镜子朝向转90度（"/"把向右变向上、向左变向下，"\"相反），并把此后的路径颜色改为该镜颜色。
- 光束到达网格边界即停止；镜子像素保持原样。

关键洞察:
- 镜子颜色不是装饰：光束携带一个沿途被改写的颜色状态，同色透射规则使同一面镜子
  对不同来历的光束表现不同；必须同时追踪"方向"与"最近一次染色"两个状态才能画对折线。
```
