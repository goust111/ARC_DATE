## 1. 递变闸门下落

- 参考题目题号: `10, 16, 19, 20`
- tags:
  - operation:重力下落, gravity_drop
  - operation:重涂色, recolor
  - object:闸门条, gate_bar
  - object:源像素, source_pixel
  - relation:颜色匹配放行, color_match_pass
  - condition:逐闸链式变色, chained_gate_recolor

### docstring

```text
让顶行源像素逐一下落，颜色与闸门上层相同者穿过并被染成下层色，否则停在闸门上方。

输入结构：
- 背景为黑色。顶行散布若干孤立的彩色源像素。
- 网格中部有若干条水平"闸门"，每条闸门厚两行、宽度不等：上行为单一颜色A，
  下行为单一颜色B（A≠B），同一闸门内两行等长对齐。
- 不同闸门高度互不相同，水平覆盖范围可以只占部分列。

规则：
- 每个源像素在自己的列内竖直下落，各列独立。
- 下落中遇到闸门时，比较像素"当前颜色"与该闸门上行颜色：相同则穿过闸门
  并把当前颜色改为下行颜色，继续下落；不同则停在闸门上方一格。
- 未被任何闸门拦下的像素落至底行。
- 输出保留所有闸门原样，顶行源像素清除，在各停靠位置画出停靠像素的最终颜色。

关键洞察：
- 闸门是"条件变色滤器"而非普通障碍：能否穿过第二道闸门取决于第一道闸门
  把像素改成了什么颜色，判定必须沿下落路径逐闸链式进行，而不能只看像素的
  初始颜色。
```

## 2. 尾迹路线与惯性续滑

- 参考题目题号: `2, 13, 16`
- tags:
  - operation:沿路径移动, path_move
  - operation:滑动, slide
  - operation:排序, sort
  - object:精灵体, sprite
  - object:轨迹路径, trace_path
  - relation:末段方向定惯性, last_segment_sets_inertia
  - condition:长尾迹先行, longer_trail_first
  - condition:碰撞停止, collision_stop

### docstring

```text
按尾迹总长从长到短的顺序，让每个精灵沿自己的折线尾迹走到尽头，再沿最后一段方向惯性滑行，直到撞上边界或先停稳的精灵。

输入结构：
- 背景为黑色，含若干互不相触的单色精灵（小型连通块）。
- 每个精灵接有一条一格宽的灰色尾迹，尾迹可以是直线或带直角拐弯的折线，
  一端与精灵相接；各精灵尾迹总长互不相同。

规则：
- 精灵按尾迹总长从长到短依次运动。
- 每个精灵先沿自己的尾迹逐格走到尾迹远端，随后沿尾迹最后一段的行进方向
  继续直线滑行，直到贴上网格边缘或先前已停稳的精灵为止。
- 所有尾迹从输出中清除，精灵保持形状与颜色。

关键洞察：
- 尾迹同时编码三件事：路线（必须先逐段走完的折线前缀）、末端惯性方向
  （走完后继续滑行的朝向）、优先级（总长越长越先动）；共享通道的精灵最终
  堆叠取决于运动顺序，而顺序只写在尾迹长度里。
```

## 3. 锚形即度量

- 参考题目题号: `12, 16, 17`
- tags:
  - operation:绘制边框, draw_ring
  - object:方块锚点, square_anchor
  - object:十字锚点, cross_anchor
  - object:生成元像素, generator_pixel
  - relation:就近归属, nearest_anchor_assignment
  - relation:锚形定度量, anchor_shape_sets_metric
  - condition:距离定环半径, distance_sets_radius

### docstring

```text
每个散点围绕离它更近的锚点画一圈恰好穿过自身的等距环，环是方是菱由锚点自己的形状决定。

输入结构：
- 背景为黑色。网格中有两个单色锚点，颜色互不相同：一个是3×3实心正方形，
  另一个是五格十字（中心加上下左右）。
- 其余前景为若干孤立的彩色单像素散点，颜色各异。

规则：
- 每个散点归属于中心离它更近的锚点（示例中两种度量下判断一致，无歧义）。
- 若归属方形锚，以方形锚中心为圆心，画出切比雪夫距离恰等于该散点距离的
  一格厚正方形环；若归属十字锚，画出曼哈顿距离恰等于该散点距离的一格厚
  菱形环。
- 环取散点颜色，恰好穿过散点，出界部分截断。锚点保持原样，散点融入所在环。

关键洞察：
- 锚点的形状就是它那套度量的"单位球"——实心方块泄露切比雪夫度量，十字
  泄露曼哈顿度量；散点是从未画出的环族的生成元，中心、几何、半径分别由
  归属、锚形、距离三层读出。
```

## 4. 奇一裁决叠加

- 参考题目题号: `1`
- tags:
  - operation:透明叠加, transparent_overlay
  - operation:重涂色, recolor
  - object:分隔行, divider_row
  - object:三联面板, triple_panel
  - relation:逐格投票, cellwise_vote
  - condition:唯一异类面板染色, odd_one_out_panel_colors_cell

### docstring

```text
三块面板逐格投票，谁是唯一的异类（唯一亮或唯一暗的面板），输出格就涂谁的颜色。

输入结构：
- 黑色背景网格被两条等距的满宽分隔行分成三块等大的面板。
- 每块面板在黑底上恰有一种自己的前景色，三块面板前景色互不相同。

规则：
- 输出与单块面板同形。逐格对齐比较三块面板的该位置是否为前景。
- 恰有一块面板为前景时，输出该格涂这块面板的颜色。
- 恰有两块面板为前景时，输出该格涂"缺席"的那块面板的颜色。
- 三块全为前景或全为背景时，输出该格为黑。

关键洞察：
- 规则不是并集、交集、异或或多数表决，而是"找唯一异类"：无论它是唯一
  亮着的还是唯一熄灭的，都由那块与众不同的面板的颜色为该格签名；三块
  一致时无异类，格子保持黑。
```

## 5. 引线围城再放水

- 参考题目题号: `3, 18`
- tags:
  - operation:连线, draw_line
  - operation:填充, flood_fill
  - object:成对标记, paired_markers
  - object:种子像素, seed_pixel
  - relation:同色配对, same_color_pairing
  - condition:新墙成腔后再填充, fill_after_walls_drawn
  - condition:竖线交叉优先, vertical_priority_at_cross

### docstring

```text
先把所有同色点对连成线段，再从唯一的单身种子点出发，用种子色淹没被新线段围出的那片区域。

输入结构：
- 黑色背景上散布彩色像素：除一个颜色只出现一次（种子）外，其余每种颜色
  恰出现两次，且每对同色像素同行或同列。
- 种子像素不与任何其他像素同色。

规则：
- 先将每对同色像素之间的行/列区间画满该颜色；横竖线段相交处保留竖线颜色。
- 画完全部线段后，从种子像素出发做四连通洪水填充：填充只在黑色背景上蔓延，
  被任何线段像素阻挡。
- 将填充可达的全部背景格涂成种子色（种子像素保持原位原色），线段保留。

关键洞察：
- 挡住水流的墙在输入里并不存在，它由第一步连线才生成；必须先完成
  "点对成线"的因果前件，才能判断种子被围在哪个腔里。
```

## 6. 键色定模、键长定倍

- 参考题目题号: `11, 15`
- tags:
  - operation:印章放置, stamp
  - operation:缩放, scaling
  - operation:裁剪, crop
  - object:精灵体, sprite
  - object:锚点标记, anchor_marker
  - relation:颜色匹配, color_matching
  - condition:最少色为锚点, rarest_color_as_anchor
  - condition:标记边长定放大倍数, marker_size_sets_scale

### docstring

```text
把每个实心方块标记替换为颜色匹配的精灵放大件，放大倍数等于方块边长。

输入结构：
- 网格由一条分隔线分成样板区与作业区。
- 样板区有若干多色小精灵，每个精灵含一个唯一的最少色像素作为锚点。
- 作业区散布若干实心正方形标记（1×1、2×2或3×3），每个标记的颜色与某个
  精灵的锚点色相同。

规则：
- 对每个标记，选出锚点色与其颜色相同的精灵。
- 将该精灵整体放大k倍（k为标记边长），即每个像素变为k×k块。
- 将放大后的精灵印入作业区，使放大后的锚点像素块恰好覆盖该标记的位置，
  原标记被覆盖。
- 输出仅为作业区（裁去样板区与分隔线）。

关键洞察：
- 每个标记同时是三重钥匙：颜色选模板、位置定落点、边长定倍率；精灵的
  最稀有色既是配对键也是缩放后的对位锚。
```

## 7. 奇偶格律与房间

- 参考题目题号: `3, 9`
- tags:
  - operation:填充, filling
  - object:标记像素, marker_pixel
  - object:奇偶格点, parity_lattice
  - object:隔墙, wall
  - relation:坐标奇偶匹配, coord_parity_match
  - relation:连通可达, connectivity_reachable
  - condition:同室同奇偶才染色, same_room_same_parity

### docstring

```text
每个彩色标记只把"和它同一房间且行列奇偶都相同"的黑格染成自己的颜色。

输入结构：
- 网格由灰色隔墙划分成若干封闭房间，其余为黑色背景。
- 若干房间内各有一个彩色标记像素，颜色互不相同；也可能有空房间。

规则：
- 对每个标记，取其行奇偶与列奇偶。
- 将与该标记四连通可达（不穿过灰墙）、且行奇偶与列奇偶都与标记一致的
  黑格染成标记色。
- 灰墙、标记本身、其他房间以及同房间内奇偶不匹配的黑格保持不变。

关键洞察：
- 染色条件是两套毫无关系的判据的合取：全局坐标奇偶与局部连通可达，
  缺一不可；只看奇偶会染出墙外，只看连通会染满全屋。
```
