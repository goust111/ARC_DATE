## 1. 绕障等距染色

- tags:
  - operation:泛洪填充, flood_fill
  - operation:重涂色, recolor
  - object:障碍物, obstacle
  - object:标记像素, marker_pixel
  - object:填充种子, fill_seed
  - relation:距离映射, distance_mapping
  - condition:测地距离等值线, geodesic_distance_contour
  - condition:障碍弯折距离场, obstacle_bends_field
- 参考题目：4（b9e38dc0）、12（ac0c2ac3）

### docstring

```text
以中心像素为源，按绕过障碍的逐层扩散距离给背景着色，各条色带由散落的
标记像素以其自身的绕障距离认领。

输入结构
- 网格有主导背景色；一个特殊颜色的中心像素；若干灰色实心障碍块；
  若干散落的彩色单像素标记。
- 无障碍的示例中输出恰好是以中心为心的同心方环（诱饵：诱导按几何
  同心环理解）。

规则
- 从中心像素做八连通逐层扩散，障碍格不可进入也不可穿越，得到每个
  背景格的扩散层数 d。
- 每个标记像素有自己的层数 d_m；输出中所有层数等于 d_m 的格子涂成
  该标记的颜色。
- 中心与障碍保持原色；层数超过最大标记层数的格子保持背景色。

关键洞察
色带不是几何同心环，而是绕障最短步数的等值线；标记不指定位置或
半径，它用自身到中心的绕障距离认领整条等值线，因此色带在障碍背后
弯折、汇合。
```

## 2. 图例即程序的走线

- tags:
  - operation:计数, counting
  - operation:路径模拟, path_simulation
  - operation:重涂色, recolor
  - object:图例框, legend_box
  - object:三角精灵体, triangle_sprite
  - relation:颜色索引行, color_keyed_row
  - relation:点数即步长, dot_count_as_step_length
  - condition:固定右转, fixed_right_turn
- 参考题目：13（58490d8a）、14（5545f144）、17（195c6913）

### docstring

```text
把图例框里每行圆点的个数按行序读成一串步长，让箭头精灵从起点出发按
固定右转依次走出各段折线，并用对应行的键色涂画路径。

输入结构
- 一个黑色矩形图例框：最左非黑列自上而下是若干键色像素，每个键色
  像素右侧隔格排着若干圆点。
- 框外有一个三角形箭头精灵，尖端指示初始朝向。
- 框外另散落若干与键色同色的杂物对象，其个数与圆点数不符（诱饵：
  诱导按"图例记录对象计数"理解）。

规则
- 按图例行自上而下读取：第 i 行键色 c_i、圆点数 n_i。
- 从精灵尖端所在格起，沿初始朝向前进 n_1 格并涂 c_1，右转九十度，
  再走 n_2 格涂 c_2，依此类推直到读完所有行。
- 图例框与杂物保持不变，三角精灵被路径起段取代。

关键洞察
图例不是计数结果也不是输出画布，而是一段程序——行序是执行顺序、
点数是步长、键色是画笔颜色；箭头只提供起点与初始朝向。
```

## 3. 双门竞争的授权通行

- tags:
  - operation:逐步移动, stepwise_move
  - operation:擦除, erase
  - object:标记像素, marker_pixel
  - object:路径, path
  - object:门结构, gate_motif
  - relation:颜色匹配授权, color_match_authorization
  - condition:双门竞争, competing_gates
  - condition:半段消耗, half_path_consumption
- 参考题目：9（182e5d0f）、11（581f7754）、2（5b37cb25）

### docstring

```text
每条路径组件两端各有一座门，路上的标记像素沿路径走向端柱颜色与自己
相同的那座门，消耗走过的半段路径并停在门内侧，未走的半段保留。

输入结构
- 背景主导色；若干条互不相连的四连通单色路径，每条路径中部有一个
  颜色鲜明的标记像素。
- 路径两端各有一座门——直线排列的"端柱-路径色-端柱"三元组；两座门
  的端柱颜色不同，其中恰有一座门的端柱颜色与本组件标记像素颜色相同。
- 部分示例中较近的门恰好是同色门（诱饵：诱导"走向较近的门"）。

规则
- 每个组件中，标记沿路径走向端柱颜色与自身相同的那座门。
- 从标记原位到停止位之间的路径像素全部擦为背景；标记最终落在与匹配
  门中心相邻、且不在两根端柱之间的那个路径格上。
- 从标记原位通往另一座门方向的路径段保持原样；两座门的端柱与门中心
  全部保留。

关键洞察
两座门的取舍不由距离、方向或先后决定，配对钥匙是标记像素自身的颜色
对门端柱颜色；且路径只被消耗一半——走过的消失、未走的保留，输出
同时携带运动痕迹与静止残段。
```

## 4. 孔洞即指针的嵌套重建

- tags:
  - operation:规范化, canonicalize
  - operation:嵌套放置, nest_inside
  - operation:裁剪, crop
  - object:精灵体, sprite
  - object:孔洞, hole
  - object:嵌套框架, nested_frame
  - relation:包含树, containment_tree
  - relation:孔内色指针, hole_content_as_pointer
  - condition:孔洞数是诱饵, hole_count_is_decoy
- 参考题目：10（8698868d）、20（2d0172a1）

### docstring

```text
散落带孔精灵的包含关系藏在孔洞内部——某些孔里恰有一个单像素，其颜色
指向被该精灵直接包含的另一个精灵，按这张指针图把全部精灵规范地画成
嵌套框图。

输入结构
- 背景主导色；若干颜色互异、形状各异的实心带孔精灵，散落各处互不接触。
- 某些孔洞内部恰含一个非背景单像素，其颜色等于另一个精灵的颜色；每个
  精灵至多两个孔含指针像素，其余孔为空。
- 精灵的孔洞总数与它在结构中的层级无关（诱饵：孔洞数顺序诱导按计数
  排序的嵌套）。

规则
- 孔内像素颜色为 c，表示该精灵直接包含颜色为 c 的精灵；未被任何指针
  指向的精灵是最外层。
- 输出把每个有指针孔的精灵画成一像素厚矩形框（用自身颜色），其直接
  包含者画在框内并与框线四周留一圈背景；无指针孔的精灵画成单个实心
  像素。
- 同一父框内的两个子对象按其对应指针孔在父精灵中的相对方位（左右或
  上下）并排摆放，中间隔一格背景。
- 所有原始形状、位置与空孔全部丢弃，输出裁剪到最外层框大小。

关键洞察
真正的结构从未在空间上画出——精灵彼此不挨着，包含树整个编码在
"哪个孔里藏着谁的颜色"里；孔洞的个数是诱饵，孔洞的内容才是指针。
```

## 5. 绕框传播的形状换代

- tags:
  - operation:图案复制, pattern_replication
  - operation:旋转, rotation
  - operation:形状变换, shape_transform
  - object:空心框, hollow_frame
  - object:角落标记, corner_marker
  - object:序列条, sequence_strip
  - relation:循环映射, cycle_mapping
  - relation:源角到目标角映射, source_to_target_mapping
  - condition:各角独立着色, per_corner_coloring
- 参考题目：19（4c416de3）、6（a47bf94d）、17（195c6913）

### docstring

```text
从空心框上唯一画全的源角出发，沿顺时针把角图案复制到其余三个角：
每前进一个角，图案沿网格顶部给出的形状序列前进一代，旋转到该角的
朝向，并使用该角标记像素的颜色。

输入结构
- 网格顶部并排若干 3×3 示例块，从左到右给出一个形状序列；各形状不具
  旋转对称性，以规范朝向画出。
- 下方一个大空心方框：某一个角已用某色画好序列中的某个形状（源角，
  按该角朝向摆放），其余三个角各有一个颜色互异的单像素标记。

规则
- 定位源角图案在顶部序列中的位置。
- 从源角顺时针到下一个角：画序列中的下一个形状（到末尾则循环回开头），
  旋转到与该角朝向一致，用该角标记像素的颜色；再下一个角前进两代，
  依此类推。
- 标记像素被图案取代；框与顶部序列保持不变。

关键洞察
三个待画角需同时组合三条独立线索——顶部序列给"画什么"（按顺时针
步数在序列中前进）、角的位置给"怎么转"、角上标记给"用什么色"；
源角是序列指针的起点，而不是要复制的模板本身。
```

## 6. 角标定框的拼装重涂

- tags:
  - operation:平移拼接, translate_assemble
  - operation:重涂色, recolor
  - object:线段条, bar_sprite
  - object:角标记, corner_marker
  - object:矩形边框, rectangular_frame
  - relation:拼合覆盖, assembly_coverage
  - condition:像素数定尺寸, pixel_count_determines_size
  - condition:占角对应色, corner_color_transfer
- 参考题目：1（83b6b474）、19（4c416de3）、2（5b37cb25）

### docstring

```text
两个角像素张出一条边、散落对象的像素总数反解出另一边长，由此确定一个
从未画出的矩形框线；把散落的直条与折线段平移拼上去恰好铺满，盖住角格
的段整体改涂该角的颜色。

输入结构
- 背景主导色；两个颜色互异的孤立单像素，是某矩形一条边的两个端点
  （框线本身未画出）。
- 网格其余处散落若干同一中性色的一像素粗对象：横竖直条与 L 形折线。

规则
- 目标是一像素厚的矩形框线：一条边由两个角像素确定，垂直方向的边长由
  "所有散落对象的像素总数等于框线周长"这一守恒条件唯一解出（框只有
  一侧放得下，设计保证）。
- 仅允许平移（不旋转不翻转），把所有对象摆上框线，使框线每格恰被覆盖
  一次，无一格多余或缺失（拼法唯一）。
- 盖住某个角格的对象整体重涂为该角像素的颜色；未盖角的对象保持中性色。

关键洞察
要拼的框在输入中不存在也不完全由标记决定——角像素只给出一条边，
另一维必须用像素数守恒反解；先算尺寸、再唯一拼装、最后按占角改色，
三步次序缺一不可。
```
