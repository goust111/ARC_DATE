## 1. 连锁榫卯

- 参考题目题号: 13, 6, 7, 3
- tags:
  - operation:重力下落, gravity_drop
  - operation:平移, translate
  - operation:擦除, erase
  - object:可动对象, movable_object
  - object:地形表面, terrain_surface
  - relation:轮廓互补, profile_complement
  - condition:唯一可嵌定顺序, unique_fit_forces_order
  - condition:忽略干扰项, ignore_distractors

### docstring

```text
悬浮件按被迫的先后次序逐个水平寻位、垂直落下，与不断更新的表面零缝隙咬合，先落者的顶面成为后落者的凹口，无处可嵌者擦除。

输入结构：
- 背景为占多数的颜色；网格底部有一片灰色地形，上表面呈锯齿状，带有若干形状各异的凹口。
- 地形上方悬浮着若干互不相连的彩色对象，颜色互不相同；对象初始的水平位置与其归宿无关。
- 部分对象只能嵌合在其他对象落定后新形成的表面上，而无法直接嵌合原始地形；另有干扰件自始至终无处可嵌。

规则：
- 表面初始为灰色地形的上轮廓。
- 反复执行：在尚未落定的对象中，找出在当前表面上恰有唯一零缝隙咬合位置的对象——落定后其下方与已落定实体之间不残留任何被围出的背景空格；将其水平移到该处并垂直落下，计入实体，表面随之更新。
- 直到没有对象再能嵌合为止；余下对象整体擦除为背景。
- 已落定对象保持原颜色，地形保持不动。

关键洞察：
- 这不是一次性的各就各位——落定顺序由"当前唯一可嵌"自我强制，前一件的顶面轮廓才是后一件的真正凹口；首例中各件恰在原始地形凹口正上方是诱饵，而某件"暂时嵌不进"并不等于它是干扰件。
```

## 2. 只画影子

- 参考题目题号: 12, 11, 17, 2
- tags:
  - operation:绘制矩形, draw_rectangle
  - operation:擦除, erase
  - object:投影残迹, edge_projection
  - object:锚点标记, anchor_marker
  - relation:包含定配对, containment_pairing
  - condition:影子可复用, shared_projection
  - condition:忽略干扰项, ignore_distractors

### docstring

```text
顶边与左边的灰色线段是若干看不见的实心矩形的投影，内部孤点指认真实的投影配对并提供颜色，据此把矩形画回来。

输入结构：
- 背景占多数。第 0 行上有若干段水平灰色线段，第 0 列上有若干段竖直灰色线段。
- 网格内部散布若干彩色孤立像素；其中一部分落在某对"顶线段列区间 × 左线段行区间"的交叉矩形内，其余落在任何交叉矩形之外。
- 同一条边线段可以同时是多个矩形的投影（被多个孤点共享）。

规则：
- 每个位于某交叉区域内的孤点指认一个真实矩形：行区间取自对应的左边线段，列区间取自对应的顶边线段。
- 以该孤点的颜色画出整个实心矩形。
- 擦除全部边线段与所有孤点（含交叉区域之外的干扰孤点）。

关键洞察：
- 矩形从未被画出，画面上只有它在两条边上的影子；按出现顺序把顶线段与左线段一一配对是诱饵，唯一可靠的配对证据是孤点的包含关系，且一条影子可被多个矩形复用。
```

## 3. 奇偶闸门

- 参考题目题号: 9, 8, 7
- tags:
  - operation:移动, move
  - operation:重涂色, recolor
  - object:实心矩形, solid_rectangle
  - object:障碍墙, barrier_wall
  - relation:同轴对齐的矩形对, coaxial_rect_pair
  - condition:奇偶定通透, parity_permeability
  - condition:诱饵示例, decoy_example

### docstring

```text
橙色矩形沿走廊滑向褐色目标，逐面穿过像素数为奇数的灰墙并留下红色过痕，遇到第一面偶数灰墙即被挡下。

输入结构：
- 背景占多数；一个实心橙色矩形与一个同尺寸实心褐色矩形共享行区间（或列区间），二者之间是笔直走廊。
- 走廊沿途有若干条与运动方向垂直的灰色直墙，每面墙完整封住走廊截面并可向两侧伸出；各墙的总像素数有奇有偶。

规则：
- 擦除橙色矩形的原位置。
- 橙色矩形沿走廊向褐色矩形滑动：每遇一面总像素数为奇数的墙即穿过，并把该墙与走廊截面重叠的那段改为红色。
- 遇到第一面总像素数为偶数的墙时，紧贴其前方停下并画出橙色矩形。
- 若途中没有偶数墙，橙色矩形滑到目标处，覆盖并取代褐色矩形。

关键洞察：
- 首例中一路皆奇、矩形直达目标，诱导出"无视灰墙、直接搬运"的假规则；墙的通透性藏在总像素数的奇偶里，且红色过痕只记录被穿过的墙，而不是被扫过的走廊。
```

## 4. 指针套环

- 参考题目题号: 5, 2, 11, 16
- tags:
  - operation:嵌套, nest
  - operation:排序, sorting
  - operation:绘制, draw
  - object:空心方框, hollow_frame
  - object:控制像素, control_pixel
  - relation:颜色指针链, color_pointer_chain
  - condition:未被引用者为头, unreferenced_head
  - condition:忽略原尺寸, ignore_original_size

### docstring

```text
把散落的空心方框按"框内孤点颜色指向下一个框"的链条重排成同心回字形，从无人指向的框开始由外向内。

输入结构：
- 背景占多数；散布 n 个颜色互异的空心方框，尺寸大小与链条顺序无关。
- 其中 n−1 个框的内部各有一个孤立像素，孤点颜色等于另一个框的颜色；恰有一个框内部为空。
- 恰有一个框的颜色不被任何孤点引用。

规则：
- 以"孤点颜色 = 下一框颜色"为指针，把 n 个框串成一条链：链头是不被任何孤点引用的框，链尾是内部无孤点的框。
- 输出为 (4n−3)×(4n−3) 网格：按链序由外向内画同心方环，最外环边长 4n−3，相邻环之间隔一圈背景，环边长依次递减 4，链尾画为中心单像素。
- 各环颜色取对应框的颜色；输入中框的原始尺寸与位置全部弃用。

关键洞察：
- 嵌套顺序不来自面积或位置——首例中恰好"大套小"是诱饵；框内孤点是颜色指针，整幅图是一张待排序的链表，输出几何是按链长重新合成的，而不是把原框搬进去。
```

## 5. 漏格滴落

- 参考题目题号: 20, 13, 7
- tags:
  - operation:重力下落, gravity_drop
  - operation:填充, fill
  - operation:修复模板, repair_template
  - object:格点骨架, lattice_frame
  - object:封闭腔室, enclosed_cavity
  - object:标记像素, marker_pixel
  - relation:缺口即通道, gap_as_channel
  - condition:模板偏差检测, template_deviation

### docstring

```text
让顶部彩色标记沿所在列穿过青色格架上的缺口逐层下落，填满第一个下方无缺口的腔室，并用青色补好沿途穿过的缺口。

输入结构：
- 网格主体是周期重复的青色格架，围出成行成列的黑色腔室。
- 格架的某些水平墙段上缺失一个像素（缺口），即周期模板中应为青色处呈黑色。
- 格架上方的空白区有若干彩色孤立标记，各占不同列；每个标记所在列的最上层墙必有缺口。

规则：
- 每个标记沿自身所在列竖直下落：某腔室顶墙在该列处有缺口则落入该腔室，底墙在该列处也有缺口则继续下穿。
- 落到第一个底墙在该列处完好的腔室为止，把该腔室的全部黑色像素填成标记颜色，并擦除标记原位。
- 标记穿过的每个缺口都用青色补回，使格架恢复周期模板。

关键洞察：
- 缺口不是破损噪声而是单向通道：先对照周期模板找出所有偏差，才能追踪每列的下落深度；被填色的腔室可以离标记很远，且输出中通道被回填，痕迹只剩最终腔室的颜色。
```

## 6. 跳帧续拍

- 参考题目题号: 14, 17, 2
- tags:
  - operation:旋转, rotate
  - operation:外推, extrapolate
  - operation:计数, counting
  - object:精灵体, sprite
  - object:枢轴像素, pivot_pixel
  - object:计步标记, step_marker
  - relation:两帧定变换, two_frames_define_motion
  - condition:标记一物两用, marker_dual_use

### docstring

```text
每组给出同一形状绕灰色枢轴连拍的两帧，贴在起点帧上的红点既指明起点又给出还要前进的步数，只画出跳步后的终帧。

输入结构：
- 背景占多数；每种前景色有两个全等（可旋转重合）的非对称精灵和一个灰色枢轴孤点。
- 紧贴其中一个精灵有 1~3 个红色单像素。
- 组内第二帧等于起点帧绕枢轴顺时针或逆时针旋转 90° 的结果，方向各组独立；各组彼此远离，互不干扰。

规则：
- 对每组，以贴有红点的精灵为第一帧，从两帧测出绕枢轴的 90° 旋转方向。
- 令 k 为红点个数，把该旋转从第二帧起再连续作用 k 次，仅画出最终帧（中间帧不画），颜色同该组精灵。
- 保留原有两帧、枢轴与红点不变。

关键洞察：
- 红点一物两用——既区分帧序（从而确定旋转方向）又是跳步计数；两个同形精灵不是静态对称关系而是运动的前两帧，答案位置从未在画面出现，且 k=2 时终帧恰是起点帧的 180° 对侧，容易被误读成"中心对称补全"。
```
