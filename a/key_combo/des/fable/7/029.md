## 1. 隐形锚点

- 参考题目题号: `5 (f28a3cbb)`, `12 (3490cc26)`
- tags:
  - operation:压缩, compress
  - operation:补全, completion
  - object:射线像素, ray_pixel
  - object:隐形锚块, invisible_anchor
  - relation:共线汇聚, collinear_convergence
  - condition:交点定锚, intersection_sets_anchor

### docstring

```text
每种颜色的散点各自位于若干条汇聚直线上，在这些直线的公共交点处画出该色 3x3 锚块，并把散点沿各自直线压缩到紧贴锚块。

输入结构
- 黑色背景；存在若干种前景颜色。
- 每种颜色的像素分布在 2~4 条穿过同一格点的水平、竖直或对角直线上，
  交点处及其 3x3 邻域内没有任何该色像素（锚块从未被画出）。
- 不同颜色的射线可以交错穿插，互为干扰。

规则
- 对每种颜色，找出其像素所在的所有直线并求出唯一的公共交点。
- 以交点为中心画出该色 3x3 实心方块。
- 将每条直线上的该色像素沿直线向方块滑动，压缩为紧贴方块外侧的连续一段。
- 其余位置恢复为背景。

关键洞察
- 压缩目标从未在输入中出现：锚块必须由多条射线的共线汇聚关系反推出来。
- 先求交点、再补画锚块、最后沿线压缩，三层推断缺一不可，
  跳过任何一层都无法得到正确输出。
```

## 2. 格阵印章补全

- 参考题目题号: `2 (cbded52d)`, `6 (af22c60d)`
- tags:
  - operation:对称补全, symmetry_completion
  - operation:平移复制, translate_copy
  - object:分隔线格阵, separated_tile_lattice
  - object:印章图案, stamp_pattern
  - relation:格阵坐标双轴轨道, tile_two_axis_orbit
  - condition:镜像轴需反推, axes_inferred
  - condition:轨道内容平移一致, orbit_content_translated

### docstring

```text
分隔线把网格切成格阵，非空格子的占据布局关于格阵坐标系中两条需要自行反推的镜像轴对称，把空缺格子用其对称轨道中已知格子的图案原样平移填入。

输入结构
- 全宽全高分隔线切出约 6x5 个等大小格子。
- 部分格子内画有多色小印章图案，其余格子为纯背景。
- 占据格子的布局在格阵行下标与列下标上各存在一条镜像轴，
  但轴不一定过格阵几何中心。
- 同一双轴轨道上的已知格子图案完全相同（不做镜像翻转），
  且部分印章图案本身不对称。

规则
- 在格阵下标层面反推行镜像常数与列镜像常数，使已知占据格子经反射后
  仍落在占据格子上且图案一致。
- 对每个应被占据而为空的格子，取其行镜像、列镜像与双镜像格子构成的轨道；
  轨道中已知格子的图案唯一，将该图案不加翻转地平移进空格子。
- 轨道全空的格子保持为空。

关键洞察
- 对称既不在像素层、轴也不在中心——必须把画面抽象成格阵坐标上的
  占据布局才能反推出两条镜像轴。
- 复制时印章按平移而非镜像进入空格，不对称印章会拆穿逐像素镜像的错误解法；
  空缺可能正对着另一空缺，必须使用完整的双轴轨道而非单次反射。
```

## 3. 无名量尺

- 参考题目题号: `4 (edcc2ff0)`, `9 (84f2aca1)`
- tags:
  - operation:填充, fill
  - operation:擦除, erase
  - operation:裁剪, crop
  - object:指示条, indicator_bar
  - object:空心矩形, hollow_frame
  - object:封闭内部, enclosed_interior
  - relation:条长匹配空腔面积, bar_length_matches_area
  - condition:匿名指令按度量配对, anonymous_bars_pair_by_measure

### docstring

```text
顶部横条的颜色是诱饵、长度才是指令——长度为 k 的条认领下方场景中内部恰好围住 k 格空腔的那个空心矩形框，把该框的空腔灌满条自己的颜色，未被任何条认领的框整体擦除。

输入结构
- 黑色指示条带位于上方，里面有若干互不相邻的水平横条；
  条的颜色互不相同且都不在下方场景中出现，条长互不相同。
- 条带下方是带独立背景色的矩形场景，散布若干个单色的一格厚空心矩形框，
  框的颜色互不相同。
- 各框内部空腔的面积互不相同，且空腔面积与框的宽度、高度、周长、
  框像素数都刻意错开（例如同时出现 2x6 与 3x4 等不同形状的空腔，
  使按宽、按高、按边长配对都会在某个示例上失败）。

规则
- 算出每个空心框内部空腔的格数。
- 长度为 k 的横条认领空腔恰为 k 格的那个框，把该框的空腔全部涂成
  这根条的颜色，框壁保持原色。
- 没有被任何条长认领的框，连壁带腔整体重涂为场景背景色。
- 输出只保留场景面板，指示条带整体裁去。

关键洞察
- 条的颜色在场景中根本找不到，"按颜色配对"的第一直觉必然落空。
- 条与框的对应量也不是肉眼可读的宽、高或周长，而是必须逐框推算的
  空腔面积——一维长度对上二维面积是唯一走得通的配对；
  配对成功后条色才反过来成为灌入空腔的颜料。
```

## 4. 门牌引路

- 参考题目题号: `7 (e5790162)`, `15 (d37a1ef5)`
- tags:
  - operation:路径绘制, path_painting
  - operation:转向, turn
  - object:起点像素, start_pixel
  - object:空心矩形, hollow_frame
  - object:标记像素, marker_pixel
  - relation:标记偏侧定转向, marker_side_sets_turn
  - condition:相对行进方向判读, side_relative_to_heading

### docstring

```text
从绿色起点沿直线前进，撞到空心框时按框内标记偏在行进方向的哪一侧决定左转或右转，沿途涂绿直至走出网格。

输入结构
- 黑色背景上有一个绿色起点像素与若干个互不相交的单色空心矩形框。
- 每个框内部恰有一个标记像素，明确偏向框内某一侧而不在中线上。
- 起点恰有一个正对某框壁的初始行进方向。

规则
- 从起点沿初始方向逐格前进，把经过的背景格涂绿。
- 当前方一格是某框的壁时不进入该框：以当前行进方向为参照，
  判断框内标记位于左半侧还是右半侧，相应地原地左转或右转 90 度后继续前进。
- 框与标记像素保持不变。
- 当下一步越出网格时停止。

关键洞察
- 转向指令不是颜色而是几何关系：同一个框从不同方向撞上时给出的
  左右含义不同，必须把标记位置换算到行进坐标系里读取。
- 框内标记不是要填充或连接的目标，而是只有在特定撞击时刻才生效的路牌。
```

## 5. 年轮计数

- 参考题目题号: `10 (8abad3cf)`, `19 (ff28f65a)`, `20 (539a4f51)`
- tags:
  - operation:计数, counting
  - operation:排序, sort
  - operation:编码, encoding
  - object:四连通物体, four_conn_object
  - object:同心角环, concentric_L_ring
  - relation:对角索引映射, diag_index_map
  - condition:环厚等于物体计数, ring_thickness_equals_count

### docstring

```text
统计每种颜色的物体个数，把颜色按个数从小到大排成序列并各自重复其个数次，再按 max(行,列) 的对角索引规则铺成一个方形年轮图。

输入结构
- 黑色背景上散布若干种颜色的 4 连通物体。
- 同色物体形状大小不一，但各颜色的物体个数互不相同。
- 物体的像素数与物体个数刻意错开，像素多的颜色未必物体多。

规则
- 数出每种颜色的物体个数，并按个数升序排列颜色。
- 把每种颜色连续写入序列，重复次数等于其物体个数，
  得到长度为总个数的颜色序列。
- 输出为该长度见方的网格，每个格子取序列中下标 max(行,列) 的颜色。

关键洞察
- 输出的嵌套 L 形色环里，环的厚度编码个数、环的层序编码名次。
- 必须数物体而非数像素，且要识破 max(行,列) 的一维序列投影——
  输出不是二维图案，而是一条计数序列穿过对角索引规则的影子。
```

## 6. 众里寻疵

- 参考题目题号: `8 (aee291af)`, `13 (d19f7514)`, `14 (25e02866)`
- tags:
  - operation:透明叠加, overlay
  - operation:异常检测, deviation_detect
  - object:同尺寸面板, same_size_panel
  - object:缺陷像素, defect_pixel
  - relation:逐像素多数表决, cellwise_majority
  - condition:偏离多数者输出, minority_survives

### docstring

```text
多块同尺寸的花纹矩形是同一底版的复制品，各自带有少量位置互不相同的错版像素，把所有错版像素按局部坐标汇集到一块黑板上输出。

输入结构
- 背景上分离放置 4~5 个同尺寸实心矩形，花纹为多色且不规则。
- 每个矩形与公共底版相比恰有 1~3 个像素被改成了别的颜色。
- 各矩形的改动位置互不重叠。

规则
- 把所有矩形按局部坐标对齐，逐格取多数颜色重建底版。
- 找出每个矩形中与底版不一致的像素。
- 输出一个与矩形同尺寸的黑色网格，在每个改动的局部位置写入
  该矩形中实际出现的颜色。

关键洞察
- 底版花纹本身是巨大的干扰项且完全不进入输出——真正的内容是
  只有靠跨矩形逐格对比才能显形的缺陷集合。
- 单看任何一个矩形都无法辨认缺陷；答案图案在输入中从未整体出现，
  它由分散在各复制品上的错版像素拼合而成。
```

## 7. 巡游名录

- 参考题目题号: `12 (3490cc26)`, `4 (edcc2ff0)`
- tags:
  - operation:贪心遍历, greedy_traversal
  - operation:编码, encoding
  - object:起始块, start_block
  - object:目标块, target_block
  - relation:视线可见, line_of_sight_visible
  - relation:访问序列, visit_order
  - condition:最近可见优先, nearest_visible_first

### docstring

```text
从红色 2x2 方块出发，反复走向同一行带或列带内视线可见且距离最近的未访问彩色方块，输出把访问到的颜色按顺序排成一行。

输入结构
- 黑色背景上有一个红色 2x2 起始块与若干个颜色互不相同的 2x2 目标块。
- 块与块可在共享的两行带或两列带内对齐，位于中间的其它方块会遮挡视线。
- 部分目标块永远不会被访问到，充当干扰。

规则
- 从红块开始，在当前块的行带与列带内寻找未访问、视线未被遮挡的目标块，
  走向其中距离最近的一个并记下其颜色。
- 如此反复，直到当前块看不到任何未访问目标块为止。
- 输出为 1xN 网格，按访问顺序依次写入记下的颜色。

关键洞察
- 输入里没有任何路径痕迹，输出也不画走廊——答案是那条从未显形的
  贪心巡游路线的"行程单"。
- 漏判一次遮挡或一次就近选择，整段序列都会错位；
  未被访问的方块虽然醒目，却从不进入输出。
```
