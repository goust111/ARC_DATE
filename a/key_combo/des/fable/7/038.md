## 1. 残影定轴

- 参考题目题号：11（88207623）、16（72ca375d）、1（2204b7a8）
- tags:
  - operation:镜像, mirror
  - operation:筛选, filter
  - object:精灵体, sprite
  - object:残迹像素, fragment_pixel
  - object:干扰体, distractor
  - relation:跨轴反射, reflection_across_axis
  - condition:自洽定轴, consistency_fixes_axis
  - condition:残迹色指定涂色, fragment_color_paint

### docstring

```text
依据散落残迹反推每个精灵的隐形镜轴，补全整幅反射像并抹除无法自洽的伪残迹。

输入结构：
- 背景为占多数的颜色，网格上有若干彼此分离的单色精灵。
- 每个精灵附近散布着两到四个同色孤立像素（残迹色，与精灵色不同，且各精灵的残迹色互不相同）。
- 另有少量孤立像素，其颜色可能与某种残迹色相同，但无法归入任何自洽的反射。
- 任何镜轴都没有被画出来。

规则：
- 对每种残迹色，寻找唯一一条竖直或水平的隐形轴，使该色所有残迹像素恰好落在对应精灵按此轴反射后的像素集合内。
- 以残迹色补画该精灵的完整反射像（残迹像素位置不变，它们本来就是反射像的一部分）。
- 无法与任何精灵在任何轴下全体自洽的孤立像素是伪残迹，输出中抹为背景。
- 原精灵原样保留。

关键洞察：
- 镜轴从未出现在画面上；看似噪声的散点其实分成两类——能整体嵌进某次反射的真残迹和嵌不进去的诱饵，全体自洽性同时定出轴的位置与该删除的像素。
```

## 2. 缺口接力表

- 参考题目题号：18（0a1d4ef5）、9（9b5080bb）、12（470c91de）
- tags:
  - operation:压缩, compress
  - operation:筛选, filter
  - object:填充矩形, filled_rectangle
  - object:缺口, notch
  - relation:包围盒行列分组, bbox_row_column_grouping
  - relation:缺口指向邻居, notch_points_neighbor
  - condition:链式回溯取色, chase_chain_for_color
  - condition:忽略干扰项, ignore_distractors

### docstring

```text
把矩形格阵压缩成小表格，但每格的颜色要沿缺口指针一路接力到实心矩形才能取到。

输入结构：
- 占多数的背景上散落少量小尺寸杂色噪点。
- 有意义的对象是单色实心矩形（每边至少 3 格），它们的包围盒行带与列带构成完整的行列格阵。
- 多数矩形恰好在某一条边的中点缺一格（露出背景色的缺口），缺口所在边指向格阵中同一行或同一列的相邻矩形。
- 少数矩形完好无缺；沿缺口方向逐个跳到相邻矩形最终总会到达完好矩形，途中不成环，且指针链会拐弯。

规则：
- 忽略噪点，只保留矩形格阵，按行带、列带压缩成紧凑小网格，每个矩形对应一格。
- 完好矩形对应的格取自身颜色。
- 有缺口的矩形对应的格：从它出发沿缺口指向跳到相邻矩形，若那个矩形也有缺口就继续沿新的方向跳，直到到达完好矩形，取那个完好矩形的颜色。

关键洞察：
- 缺口不是破损也不需要修补，它是指针；一个格子的输出颜色既不取决于它自己，也不取决于离它最近的完好矩形，而取决于指针链拐弯之后真正到达的那个"实心根"。
```

## 3. 动量配额接力

- 参考题目题号：12（470c91de）、6（99caaf76）、17（9aaea919）
- tags:
  - operation:平移, translate
  - operation:计数, counting
  - object:填充矩形, filled_rectangle
  - object:标记条, marker_bar
  - relation:尾巴指示方向, tail_indicates_dir
  - relation:碰撞传递运动, collision_transfers_motion
  - condition:步数配额守恒, step_budget_conservation

### docstring

```text
青色尾巴的长度是全链共享的动量配额，碰撞把剩余步数交给被撞者，位移沿矩形链传递直到配额耗尽。

输入结构：
- 占多数的背景上有若干互不接触的单色实心矩形。
- 恰有一个矩形在一条边的外侧附着一段青色直线尾巴（1 格宽，长度不定），尾巴垂直于该边、指向矩形外。
- 沿尾巴的反方向（矩形的前进方向）望去，若干矩形错落分布；其余矩形没有任何附属物。

规则：
- 带尾巴的矩形沿尾巴所指的反方向（尾巴在后、头朝前）逐步滑动；青色尾巴在输出中消失。
- 设尾巴长度为 D，全链总共只能走 D 步。
- 运动中的矩形若在配额耗尽前贴上另一矩形（再走一步就会重叠），就停在原地，并把剩余步数移交给被撞的矩形；被撞者接着沿同一方向滑动。
- 如此逐个传递，直到累计走满 D 步，此刻正在运动的矩形就地停下（可能停在空地中间）；若某个接棒者前方直到边界都没有矩形，它用完剩余步数后停下。
- 不在传递链上的矩形一动不动。

关键洞察：
- 没有对象注定滑到边界或滑到相邻——所有对象的位移之和恰好等于尾巴长度；尾巴既指方向又是全链共享的步数预算，碰撞只是预算的移交。
```

## 4. 燃料螺旋

- 参考题目题号：13（8b28cd80）、8（469497ad）、19（ea786f4a）
- tags:
  - operation:螺旋绘制, spiral_drawing
  - operation:计数, counting
  - object:孤立像素, isolated_pixel
  - object:计数团块, counter_blob
  - relation:相对方位定初向, relative_direction_sets_heading
  - condition:计数定长, count_sets_length

### docstring

```text
把团块烧成燃料：从标记像素出发按团块的方位起步，画一条长度恰好等于团块像素数的顺时针方形螺旋。

输入结构：
- 黑色背景上只有两个前景对象：一个孤立的单像素标记（色 A），一个实心团块（色 B）。
- 团块与标记处在同一行或同一列，位于标记的上、下、左或右方。

规则：
- 数出团块的像素个数 N，并把团块从输出中抹去。
- 从标记出发，第一步朝团块所在的方位走；此后按顺时针方形螺旋前进，臂长依次为 1,1,2,2,3,3,…（每走完一段臂就右转）。
- 沿途恰好涂 A 色 N 格（不含标记本身），然后停笔；标记保留。

关键洞察：
- 团块既不是障碍也不是目的地：它的方位是点火方向，它的像素数是燃料量，螺旋在燃料耗尽的那一格戛然而止，而不是画到网格边界。
```

## 5. 风车杂交印章

- 参考题目题号：10（007bbfb7）、20（65b59efc）、3（212895b5）
- tags:
  - operation:印章覆盖, stamp_overlay
  - operation:旋转, rotate
  - operation:重涂色, recolor
  - object:模板掩码, template_mask
  - object:印章精灵, stamp_sprite
  - relation:模板给位与色, template_gives_position_color
  - relation:印章给形, stamp_gives_shape
  - relation:象限风车定向, quadrant_pinwheel_orientation
  - condition:逐块继承模板色, block_inherits_cell_color

### docstring

```text
一个精灵给形状、另一个精灵给位置与颜色，且每个印章副本按其所在象限像风车一样旋转后再盖章。

输入结构：
- 黑色背景上有两个彼此远离的小精灵：一个偶数行、偶数列、含两到三种颜色的"模板"精灵（没有正中行列，每个格严格属于一个象限），一个单色且不具备任何旋转对称的"印章"精灵。
- 二者的行列尺寸可以不同。

规则：
- 输出尺寸为模板高×印章高、模板宽×印章宽，划分为与模板格一一对应的块阵。
- 模板的每个非黑格：把印章的形状复制进对应块，并把整个副本涂成该模板格的颜色。
- 副本的朝向由该格在模板中的象限决定：左上象限原样，右上顺时针旋转 90°，右下旋转 180°，左下旋转 270°。
- 模板的黑格对应的块保持全黑；输入中的两个精灵本身不出现在输出里。

关键洞察：
- 这不是任何一个精灵的自分形——块的位置与颜色来自模板，块内的形状来自印章；同一形状在四个象限里以风车方式转动，副本的朝向信息不写在任何输入格上，而写在它自己的位置里。
```

## 6. 隐形光源

- 参考题目题号：5（310f3251）、15（11e1fe23）、16（72ca375d）
- tags:
  - operation:偏移阴影, offset_shadow
  - operation:补全, completion
  - object:精灵体, sprite
  - object:阴影像素, shadow_pixel
  - object:孤儿阴影, orphan_shadow
  - relation:方向场汇聚, direction_field_convergence
  - relation:隐形光源, invisible_light_source
  - condition:反演补画本体, invert_to_restore_body

### docstring

```text
每个影子都贴在本体背离某个从未画出的光源的一侧；先反推光源，再给孤儿影补画它的本体。

输入结构：
- 背景上有若干红色实心精灵，形状、尺寸各不相同。
- 每个精灵带一个灰色影子：与本体同形，且沿"光源中心指向本体中心"的主方向（水平、垂直或对角，八向之一）紧贴在本体背光的一侧。
- 光源本身没有画出，任何格都不标它。
- 恰有一个灰色影子没有对应的红色本体。

规则：
- 由多对本体-影子的贴合方向反推出唯一的隐形光源位置：各对"影子指向本体"方向的反向延长线交于同一点。
- 对孤儿影：本体位于影子朝向光源的一侧，与影子同形紧贴，用红色补画出来。
- 其余一切原样保留。

关键洞察：
- 影子的方向场是唯一的线索——它们共同指认一个从未出现在画面上的点；孤儿本体的位置不是由常量偏移给出的，而是由这个隐形点的方位反演出来的。
```
