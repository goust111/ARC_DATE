## 1. 转角印记

- tags:
  - operation:路径模拟, path_simulation
  - operation:印章覆盖, stamp_overlay
  - object:起点条, start_bar
  - object:障碍走廊, blocker_corridor
  - object:转弯格, turning_cell
  - relation:正交对角分工, ortho_diag_role_split
  - condition:转向手性定形状, turn_handedness_shape
  - condition:仅填背景格, only_bg_filled
- 参考题目题号：7 (6bcdb01e)、2 (f0df5ff0)、4 (0962bcdd)

### docstring

```text
沿障碍走廊模拟起始条的行进路线，不画路径，只在每个转弯格盖形状由转向左右决定的印章。

输入结构：
- 背景为最常见色；一个两像素的起始条恰有一端贴网格边界。
- 大量障碍像素围成一条一格宽的走廊，走廊内每次碰撞恰有唯一垂直通路。

规则：
- 从边界端出发，经起始条的另一端进入网格逐格前进；下一格为障碍时
  转向唯一可行的垂直方向，下一格出界时终止。
- 行进路径本身不涂任何颜色。
- 在每个发生转向的格子上以其为中心盖印：左转盖正十字（中心加上下
  左右四邻），右转盖斜十字（中心加四个对角邻）。
- 印章用起始条颜色，只覆盖背景格；障碍与起始条保持不变。

关键洞察：
- 走廊路径是从未画出的生成元，输出只记录转弯事件及其手性；直行段
  不留任何痕迹，印章形状编码的是"向哪边转"这一派生信息。
```

## 2. 粗格换色对称补块

- tags:
  - operation:压缩, compress
  - operation:对称补全, symmetry_completion
  - object:格子结构, lattice
  - object:色带分组, color_band
  - object:缺失块, missing_block
  - relation:点对称, point_symmetry
  - relation:颜色配对映射, color_pair_mapping
  - condition:映射表由画面涌现, mapping_emerges_from_grid
- 参考题目题号：14 (80214e03)、6 (9ecd008a)、8 (9b365c51)

### docstring

```text
把噪声块阵压缩成粗色网格，发现它满足"点对称位置颜色恒定配对交换"的规律，
用由画面自身显露的色对表恢复完全缺失的块。

输入结构：
- 背景包围一个由单色块组成的行带×列带点阵，每块内部有随机背景孔洞。
- 恰有一个行带×列带交叉区完全是背景（整块缺失）。

规则：
- 按整行、整列的前景色集把非空行、列分组成连续的带，每个带交叉区取
  其唯一前景色，得到粗色网格，缺块对应的粗格未知。
- 粗网格在 180° 点对称下不是同色，而是颜色两两恒定配对（部分颜色可
  与自身配对），配对表由所有完好的对称格对一致地显露。
- 取缺格的点对称像格的颜色，经配对表映射后填入缺格。
- 输出补全后的粗色网格。

关键洞察：
- 像素级因孔洞噪声没有任何对称；粗尺度上直接镜像与直接同色点对称也
  都不成立——结构是点对称的，但颜色被一个隐藏的配对交换所扭曲，
  配对表必须从完好格对中读出，而不是任意给定的码表。
```

## 3. 三姿归一表决

- tags:
  - operation:多数投票, majority_vote
  - operation:姿态归一, pose_normalization
  - operation:重涂色, recolor
  - object:精灵副本, sprite_copy
  - object:污染格, corrupted_cell
  - relation:刚体变换对齐, rigid_transform_alignment
  - condition:副本无自对称, no_self_symmetry
  - condition:逐位至多一份污染, at_most_one_corrupt_per_slot
- 参考题目题号：19 (cd3c21df)、6 (9ecd008a)、18 (27a77e38)

### docstring

```text
同一多色精灵以三种不同姿态散布在网格上，每份都被少量污染，先识别各自的
变换并归一姿态，再逐格三方表决恢复真值，输出修复后的整幅网格。

输入结构：
- 背景上有三个互相分离、包围盒等大的多色精灵。
- 它们本是同一图案经过三种不同的刚体变换（恒等、90°/180°/270° 旋转、
  水平/垂直镜像中的三种，各份不同且不事先告知）得到的副本。
- 每份副本各有少量格被改成错误颜色，同一归一化位置上至多一份被污染。
- 图案本身没有任何自对称，保证每份所受的变换可唯一辨认。

规则：
- 找出三份副本各自所受的变换，把它们归一到同一姿态。
- 对齐后逐格取三份颜色的多数作为真值。
- 把每个污染格按其副本自身的姿态改回正确颜色。
- 输出修复后的整幅网格，三份副本的位置与姿态保持不变。

关键洞察：
- 三份副本姿态各不相同，直接逐格互比全部失配；污染又让任意两份之间
  的姿态匹配都不完美，必须在允许少量失配的前提下同时解出三个变换，
  再用三方表决区分"姿态差异"与"真污染"。
```

## 4. 等面积腔配对互换

- tags:
  - operation:交换, swap
  - operation:重涂色, recolor
  - operation:擦除, erase
  - object:空心矩形框, hollow_rectangle
  - object:内腔, interior_cavity
  - object:图案掩码, motif_mask
  - relation:面积匹配配对, area_matching_pairing
  - condition:框色作为涂色源, frame_color_source
  - condition:忽略干扰项, ignore_distractors
- 参考题目题号：15 (5a719d11)、1 (7acdf6d3)、16 (1c786137)

### docstring

```text
空心框按内腔尺寸相等两两配对，配对双方互换内部母题，并把母题重涂为
来源框的框色。

输入结构：
- 背景上散布偶数个单色空心矩形框，框色有重复（同色框不一定是配对对象）。
- 每个框内腔中有一个异色母题图案。
- 内腔尺寸（高×宽）恰好两两相等构成配对，不同配对的内腔尺寸互不相同；
  空间上最近的框通常不是配对对象。

规则：
- 按内腔尺寸相等确定配对。
- 每对框中，把甲框的母题形状按内腔左上角对齐粘贴进乙框内腔，涂成甲框
  的框色；同时把乙框的母题粘贴进甲框内腔，涂成乙框的框色。
- 原母题位置恢复为背景；框本身不变。

关键洞察：
- 配对的键是内腔尺寸这一派生量，颜色相同与空间邻近都是诱饵；母题自身
  的颜色也是干扰项，真正被传递的只有形状掩码与来源框的框色。
```

## 5. 双底交集配腔

- tags:
  - operation:透明叠加, transparent_overlay
  - operation:裁剪, crop
  - object:面板, panel
  - object:背景交集掩码, bg_intersection_mask
  - object:轮廓精灵, outline_sprite
  - object:内腔, interior_cavity
  - relation:隐形形状匹配, hidden_shape_matching
  - condition:唯一腔全等, unique_cavity_congruence
- 参考题目题号：17 (e345f17b)、19 (cd3c21df)、1 (7acdf6d3)

### docstring

```text
两块掩码面板中同时为背景的格子构成一个隐形形状，它与下方某个轮廓精灵
的内腔全等，裁剪出那个轮廓精灵。

输入结构：
- 网格被分隔线划成三个区域：上部并排两块等大面板，各含一种颜色的掩码
  图案；下部一排颜色各异、互相分离的空心轮廓精灵。
- 每个轮廓精灵围出一个形状不同的内腔。

规则：
- 把两块面板逐格对齐，取两边都是背景的格子集合，得到一个从未被画出的
  形状。
- 候选轮廓精灵自身的实体形状与该形状均不全等，全等的是其中唯一一个
  精灵的内腔（轮廓所围出的背景区域）。
- 输出该精灵的包围盒裁剪，保持其原有颜色。

关键洞察：
- 参与匹配的两个对象都从未被直接画出——一个是两张掩码的背景交集，
  一个是轮廓围出的腔；拿交集形状去比精灵实体会全部失配。
```

## 6. 隐心环场

- tags:
  - operation:同心层填充, concentric_fill
  - operation:约束反解, constraint_inversion
  - object:矩形边框, rectangular_frame
  - object:采样像素, sample_pixel
  - object:隐藏中心, hidden_center
  - relation:切比雪夫距离, chebyshev_distance
  - condition:奇偶距离决定颜色, parity_distance_color
  - condition:中心从未画出, center_never_drawn
- 参考题目题号：9 (b7fb29bc)、16 (1c786137)

### docstring

```text
框内散布的红黄像素是同一同心环场的采样，找出唯一一致的隐藏中心并补全
整个奇偶环场。

输入结构：
- 一个矩形单色框，内部大部分为背景，散布若干红色与黄色像素。
- 存在唯一的内部格 c，使所有黄像素到 c 的 Chebyshev 距离为奇数、所有
  红像素到 c 的 Chebyshev 距离为正偶数；中心格本身没有被画出。

规则：
- 找出唯一满足全部奇偶约束的中心格 c。
- 把框内所有背景格按到 c 的 Chebyshev 距离染色：奇数染黄、偶数染红
  （中心格距离为 0，染红）。
- 框保持不变，染色结果与已有采样像素自然衔接。

关键洞察：
- 散点不是噪声，而是隐藏环场的采样；控制中心从未被画出，只能由全体
  采样的奇偶约束联立反解出来。
```

## 7. 门牌接龙

- tags:
  - operation:连线, draw_path
  - operation:寻路, pathfinding
  - object:平行墙壁, parallel_walls
  - object:门牌色对, door_nameplate_pair
  - object:标记像素, marker_pixel
  - relation:颜色指针链, color_pointer_chain
  - condition:名字色选门, name_color_selects_door
  - condition:忽略几何诱饵, ignore_geometric_decoys
- 参考题目题号：20 (7e576d6e)、8 (9b365c51)、3 (78e78cff)

### docstring

```text
从起点标记的颜色出发，按"每扇门右侧色牌指定下一道墙的门名"的颜色链
依次选门，把路线穿过所有被选门的中央。

输入结构：
- 若干道平行的满跨墙，每道墙上有多扇门；每扇门在墙行上表现为
  "色牌A、背景、色牌B"三格，A 是这扇门的名字，B 指向下一道墙要走
  的门的名字。
- 两个同色标记像素位于墙组两外侧；同一道墙上各门名字互不相同。
- 链条自洽：最后一扇被选门的 B 牌色恰等于标记颜色。

规则：
- 起点标记的颜色是第一道墙要走的门的名字；找到名字为该色的门，读它
  的 B 牌色，作为下一道墙的门名，逐墙接龙。
- 从起点标记出发以正交折线依次穿过每扇被选门中央的背景格，连到终点
  标记，路线涂成标记色。
- 其余门与色牌保持不变，路线不得穿过未选中的门。

关键洞察：
- 正确的门不由几何位置（最近、对齐）决定，而由一条从未整体画出的
  颜色指针链决定；每扇门同时携带"自己是谁"和"下一个是谁"两条信息。
```
