## 1. 走廊选票

- 参考题目: `692cd3b6`, `de1cd16c`
- tags:
  - operation:路径填充, path_fill
  - operation:计数, counting
  - operation:投票, vote
  - operation:擦除, erase
  - object:门框, doorway_frame
  - object:走廊路径, corridor_path
  - object:标记像素, marker_pixel
  - relation:门洞朝向, doorway_orientation
  - condition:最短路径并集, monotone_shortest_path_union
  - condition:区域内标记胜出, region_marker_wins

### docstring

```text
用两门之间的隐形走廊圈定选票，把走廊染成票数最多的颜色。

输入结构：
- 背景为主导色，画面含两个小型同色框形物体，每框中心各有一个标记像素。
- 每个中心标记恰有一个背景四邻（门洞豁口），豁口再向外一格为外门洞格。
- 画面各处散布多种颜色的孤立像素（浮尘），浮尘不属于任何物体、不构成障碍。

规则：
- 仅把两个框体视为障碍，求两外门洞格之间所有"逐步靠近对方"的行/列单调最短
  路径的并集，加上两个门洞豁口，构成隐形走廊。
- 统计恰好落在隐形走廊内的浮尘各颜色的数量，取数量唯一最多的颜色为胜出色。
- 擦除画面上全部浮尘，把整条隐形走廊（含豁口）染成胜出色。
- 框体与中心标记保持不变。

关键洞察：
- 计票区域从未被画出：必须先重建两门之间的单调路径并集，才知道哪些浮尘拥有
  投票权；全局数量最多的颜色往往不是走廊内的多数派。
```

## 2. 开口连锁点火

- 参考题目: `d4f3cd78`, `84551f4c`, `692cd3b6`, `73c3b0d8`
- tags:
  - operation:射线延伸, ray_extend
  - operation:填充, fill
  - object:封闭区域, enclosed_region
  - object:开口, opening
  - relation:链式连接, chain_linkage
  - relation:开口朝向, opening_direction
  - condition:开口决定延伸向, opening_extend_dir
  - condition:对准才点亮, alignment_ignites

### docstring

```text
从唯一预先点亮的舱室出发，让光沿"开口对准开口"的链条点亮后续舱室。

输入结构：
- 黑色背景上有若干同色矩形轮廓舱室，每个舱室的边界上恰有两个单格开口。
- 恰有一个舱室内部已填满黄色（种子舱），其余舱室内部为空。
- 画面中存在开口互相对准、但与种子链不连通的舱室对，作为干扰。

规则：
- 种子舱从自己的两个开口各向外发射一条黄色直线光线，方向为开口向外的法向。
- 光线沿背景直行：碰到舱壁则停在壁前一格；到达网格边缘则止于边缘。
- 若光线恰好沿直线从另一舱室的开口正面射入，该舱室被点亮：内部全部填黄，
  并立即从它的另一个开口继续向外发射光线；已点亮的舱室不再重复点亮。
- 输出画出所有光线路径（黄色）、所有被点亮舱室的内部填黄；未被点亮的舱室
  保持空心。

关键洞察：
- 点亮不看距离也不看颜色，只看几何对准：开口既是出口也是入口，激活只能沿
  "从种子可达"的开口链传播，孤立的对准舱室对永远不会亮。
```

## 3. 里外互换的嵌套符号

- 参考题目: `80af3007`, `e84fef15`
- tags:
  - operation:压缩, compress
  - operation:修复异常, repair
  - operation:印章覆盖, stamp
  - object:二值掩码, binary_mask
  - object:重复图块, repeated_tile
  - relation:自相似嵌套, self_similar_nest
  - relation:多数投票共识, majority_vote
  - condition:嵌套层级互换, nesting_swap
  - condition:受损副本被指认, damaged_identified

### docstring

```text
识别 9x9 图案中"外层排布"与"内层笔画"两个不同的 3x3 符号，修复唯一受损块后
输出里外互换的嵌套图。

输入结构：
- 输入为 9x9、单一前景色，本应为两个不同 3x3 二值符号的嵌套积——外层符号 A
  为 1 的块位置放内层符号 B 的完整 3x3 副本，A 为 0 的位置放全背景块。
- 恰有一个 3x3 块被破坏：内容与应有情况不符，可能是本应为空的块多了格，也
  可能是本应为 B 副本的块缺了格或被改了形；其余八块完好。
- 输入保证符号对与受损块位置的解释唯一。

规则：
- 按 3x3 分块，找出唯一的符号对 (A, B) 与唯一受损块，使其余八个块完全符合
  "A 的 1 位放 B 副本、0 位放空块"的嵌套结构。
- 用完好副本恢复 B、用块的空/非空排布恢复 A。
- 输出 9x9 的里外互换嵌套图——B 为 1 的块位置放 A 的完整副本，B 为 0 的位置
  放全背景块，不保留任何损伤痕迹。

关键洞察：
- 这幅图不是符号与自身的自积，而是两个不同符号的嵌套——外层排布与内层笔画
  各是一个符号；受损块靠其余副本的一致性指认并修复，而输出要求把嵌套关系
  里外反转，排布变笔画、笔画变排布。
```

## 4. 沙堆多米诺

- 参考题目: `73c3b0d8`, `2685904e`, `84551f4c`
- tags:
  - operation:平移, shift
  - operation:柱状填充, histogram_fill
  - operation:旋转, rotate
  - object:移动像素, moving_pixel
  - object:触发条, trigger_bar
  - object:链式序列, chained_sequence
  - relation:链式连接, chain_linkage
  - condition:高度即宽度, height_equals_width
  - condition:够得着才推倒, reach_topples_next

### docstring

```text
悬浮像素先落到地面条上堆成柱，然后从标记柱开始向右连锁倒伏，柱高变成倒下后
的占地宽度。

输入结构：
- 背景为主导色，底部有一条全宽横条（地面），地面上方空中散布同色悬浮像素。
- 地面条上恰有一个异色标记格，标记格所在列上方有沙。
- 各柱互不相邻，落定后柱高互有不同。

规则：
- 每个悬浮像素沿所在列竖直下落，落在地面条或先前落定的像素之上，逐列堆成
  一格宽实心柱。
- 站在标记格上的柱首先向右倒下——擦除竖柱，从柱底格起向右画一条长度等于原
  柱高的水平条（画在地面条上方第一行）。
- 若某根已倒柱的水平条末端到达或越过下一根直立柱柱底的相邻列，该柱也被推倒
  并同样向右倒伏，如此连锁。
- 水平条互相重叠处同色叠画；未被任何倒伏条够到的柱保持直立；地面条与标记格
  保持不变。

关键洞察：
- 柱的高度就是它倒下后的杀伤半径——链条能否延续取决于"沙堆出来的高度"与
  "柱间距"的比较；沙没堆够高的地方链条就断，后面的柱再密也不会倒。
```

## 5. 隐形的发射源

- 参考题目: `d07ae81c`, `8e5c0c38`
- tags:
  - operation:射线延伸, ray_extend
  - operation:擦除, erase
  - object:标记像素, marker_pixel
  - object:残迹散点, residue_dots
  - relation:对角线激活, diagonal_activation
  - condition:因果反演, causal_inversion
  - condition:忽略干扰项, ignore_distractors

### docstring

```text
从散落的对角残迹反推从未画出的发射源，重绘完整的X形光束并清除冒充残迹的噪声。

输入结构：
- 黑色背景上散布若干青色像素：大部分是若干隐形源点发出的四向对角光束留下的
  残迹，少数是不属于任何光束的同色噪声。
- 源点格本身是背景色，从未被画出。
- 每个真实源点的四个对角方向上各有至少两个残迹作证；噪声点凑不出这样的四向
  双重见证。

规则：
- 找出所有满足"四个对角方向上各存在至少两个青色像素与之对角对齐"的背景格，
  这些格是源点。
- 以每个源点为中心，向四个对角方向画青色直线直到网格边缘，并把源点格涂黄。
- 不落在任何一条重绘光束上的青色像素是噪声，擦除。

关键洞察：
- 参与规则的对象从未出现在画面上：画面只有光束的残迹和伪装成残迹的同色噪声，
  唯有"四个方向都有双重见证"的空格才配当发射源，噪声在源点确定之后才暴露。
```

## 6. 量子跳跃

- 参考题目: `64a7c07e`, `1b8318e3`, `320afe60`
- tags:
  - operation:平移, translate
  - operation:吸附, snap
  - object:前景对象, foreground_object
  - object:边框缺口, border_notch
  - object:锚墙, anchor_wall
  - relation:边界框决定偏移, bounding_box_determines_offset
  - condition:缺口决定方向, notch_determines_dir
  - condition:按自身宽度跳跃, jump_by_own_width
  - condition:整除余数定间隙, remainder_sets_gap

### docstring

```text
让每个带缺口的方块朝缺口指向的墙做步长等于自身宽度的跳跃，跳到不与墙重叠的
最远处。

输入结构：
- 画面左右两侧各有一道竖直的灰色实墙，中间散布若干实心矩形物体。
- 每个物体在左边界或右边界上挖有一个单格缺口。
- 各物体互不同行，跳跃途中无相互阻挡；部分物体到墙的间隙恰为自身宽度的整数
  倍，部分不是。

规则：
- 每个物体朝其缺口所在一侧的墙水平跳跃，每一跳的步长恰等于自身边界框的宽度。
- 反复起跳，直到再跳一步就会与墙重叠为止，物体停在那里。
- 物体的形状、缺口与颜色保持不变；两道墙保持不变。

关键洞察：
- 物体不是滑到墙边贴住：位移被自身宽度量子化，间隙能否清零取决于整除关系；
  恰好整除的物体看起来像"滑动贴墙"，正是第一眼的诱饵。
```

## 7. 底部字典

- 参考题目: `150deff5`, `2685904e`
- tags:
  - operation:分解, decompose
  - operation:重涂色, recolor
  - object:基本图元, primitive_shape
  - object:编码行, code_row
  - object:分隔行, separator_row
  - relation:长度对应颜色, length_maps_color
  - condition:编码行定义图元字典, code_row_defines_dictionary

### docstring

```text
按画面底部彩色段写成的"图元字典"分解灰色复合块，并给每个图元涂上其长度对应
的颜色。

输入结构：
- 一条全宽分隔线把画布分为上方工作区与底部字典行。
- 字典行中有若干条彼此隔开的彩色水平段，段的长度互不相同，颜色互不相同。
- 工作区内是若干灰色复合块；每块都能且只能按一种方式切成横放或竖放的一格宽
  长条，条长都出现在字典中。

规则：
- 读出字典：每种段长对应该段的颜色。
- 把每个灰色复合块唯一地分解为一格宽的长条（横竖均可），条长必须是字典中
  出现的长度。
- 将每根条按其长度在字典中对应的颜色重涂，位置不动。
- 分隔线与字典行保持原样。

关键洞察：
- 合法图元不是先验固定的形状库：字典写在画面底部，段长挑选尺寸、段色决定
  涂色，同一个灰块在不同字典下会有不同的切法与配色。
```
