## 1. 对称裁定角色的迷宫

- tags:
  - operation:寻路, pathfinding
  - operation:重涂色, recolor
  - object:前景掩膜, fg_mask
  - object:端点像素, endpoint_pixel
  - relation:镜像对称, mirror_symmetry
  - relation:四邻接连通, four_neighbor_connect
  - condition:失配者为端点, unpaired_as_endpoint
- 参考题目题号：3（b15fca0b）、6（ce039d91）
- 评审档位：达标

### docstring

```text
一句话总述
网格中所有灰像素按左右镜像配对，恰有两枚灰像素没有镜像伙伴，它们是路径端点，
其余成对灰像素是迷宫墙；将两端点之间唯一的最短四邻接路径的内部涂黄。

输入结构
- 黑色背景，唯一前景色为灰色；网格宽度为偶数。
- 灰像素中恰有两枚在关于竖直中线的镜像位置上没有灰像素，其余灰像素均两两镜像配对。
- 部分墙像素同样孤立、离群分布（其伙伴位于另一半），端点无法凭孤立性猜出。
- 两枚失配灰像素之间存在唯一的最短四邻接路径（只经过黑色格，视所有配对灰像素为墙）。

规则
- 对每枚灰像素检查其关于竖直中线的镜像格；镜像格也是灰色的像素（连同其伙伴）
  全部视为不可通行的墙。
- 剩下恰好两枚无伙伴的灰像素为起点与终点。
- 求两端点间唯一的最短四邻接路径，将路径中间经过的黑色格涂黄。
- 所有灰像素原样保留。

关键洞察
全图只有一种前景色，墙与端点的身份不由颜色区分，而由"是否有镜像伙伴"这一
对称检验裁定；先做对称配对分出角色，才能开始寻路。
```

## 2. 灰点折光

- tags:
  - operation:射线延伸, ray_cast
  - operation:填充, fill
  - object:端点像素, endpoint_pixel
  - object:拐点像素, pivot_pixel
  - object:干扰像素, distractor_pixel
  - relation:同色配对, same_color_pairing
  - condition:几何可连性定线型, connectability_selects_line_type
  - condition:闲置灰点为诱饵, idle_pivot_as_decoy
- 参考题目题号：3（b15fca0b）、10（d364b489）、17（6d58a25d）
- 评审档位：达标（修订版）

### docstring

```text
一句话总述
边框上恰出现两次的颜色对，要么直连成水平/竖直/45度对角线段，要么经由唯一一枚
与其一者同行、另一者同列的灰色拐点连成 L 形折线；单例颜色与未被任何折线使用的
灰点都是噪声。

输入结构
- 黑色网格，彩色像素只出现在四条边框上；内部散布若干灰色像素。
- 某些颜色在边框上恰出现两次：其中一部分对恰可用一条水平、竖直或45度对角直线相连；
  另一部分对既不共行、不共列、也不共对角，但内部恰有唯一一枚灰点与对中一枚共列
  （或共行）、与另一枚共行（或共列），且由这枚灰点连出的 L 形折线不经过其他灰点。
- 其余颜色在边框上只出现一次；部分灰点不服务于任何颜色对。

规则
- 按颜色配对边框像素。
- 可直连的对，用该颜色画出连接两枚像素的直线段（含端点）。
- 不可直连的对，找到其唯一匹配灰点，用该颜色画出"边框像素—灰点—另一边框像素"
  的 L 形折线两臂（灰点本身保持灰色）。
- 单例颜色像素原样保留、不画线；未被使用的灰点原样保留。
- 由构造保证所有已画线段与折线互不交叉。

关键洞察
灰点是从未被完整画出的折线的生成元——判断每个颜色对属于"直连"还是"折连"、
并在多枚灰点中甄别出真正的拐点，是先于画线的两层筛选；单例颜色与闲置灰点是
双重诱饵。
```

  - object:九宫格, nine_cell_grid
  - object:占位标记, placeholder_marker
  - relation:序列递进, sequence_progression
  - condition:读序为螺旋, spiral_reading_order
  - condition:朝向计数失效, orientation_count_ambiguous
- 参考题目题号：2（be03b35f）、4（a416fc5b）、11（3c9b0459）
- 评审档位：达标偏上

### docstring

```text
一句话总述
九宫格瓦片沿"左上起顺时针沿外圈、最后进中心"的螺旋读序每步顺时针旋转90度，
输出被占位色覆盖的那格应有的瓦片。

输入结构
- 网格由一像素分隔线划成 3×3 九个等大方格。
- 八个方格内是同一非四重对称图案的不同旋转副本，一个方格被单一占位色填满。
- 按螺旋顺序读取时，相邻两格的图案恰好相差顺时针90度旋转。
- 占位格在螺旋序中的位置使得仅统计各朝向出现次数无法唯一确定缺失朝向。

规则
- 确定螺旋读序，由可见八格验证"每步顺时针转90度"的递进关系。
- 占位格图案等于其螺旋序前一格图案顺时针旋转90度（等价地，后一格逆时针旋转90度）。
- 输出该方格大小的补全图案。

关键洞察
旋转角不由方格的行列位置直接决定，而由隐含的螺旋读序决定；同一朝向在九格中
出现不止一次，"数缺失朝向"的捷径失效，必须先恢复读序。
```

## 4. 旋入锁孔

- tags:
  - operation:填充, fill
  - operation:旋转, rotate
  - operation:擦除, erase
  - object:空心矩形, hollow_rectangle
  - object:封闭区域, enclosed_region
  - object:精灵体, sprite
  - relation:正负形状匹配, positive_negative_shape_match
  - condition:只认旋转不认镜像, rotation_only_no_mirror
- 参考题目题号：2（be03b35f）、14（b9b7f026）、15（48d8fb45）
- 评审档位：达标（修订版）

### docstring

```text
一句话总述
每个游离的多色小精灵按形状（只允许旋转、不允许镜像）匹配到唯一的框内孔洞，
把精灵按对齐所需的旋转角旋转后逐格填入孔洞，再擦除游离精灵。

输入结构
- 黑色背景上有若干单色矩形框，每个框内包围一个由背景格构成的非矩形孔洞；
  各孔洞形状互不相同且都不具有旋转对称性。
- 框外散布同样数量的多色小精灵，每个精灵的形状与恰好一个孔洞的形状在某个
  0/90/180/270度旋转下全等。
- 至少有一个精灵与某个不匹配的孔洞形状恰成镜像关系（镜像不算匹配）。
- 精灵内部由多种颜色组成图案。

规则
- 提取每个框内不与网格边界连通的背景孔洞形状，以及每个游离精灵的形状。
- 在只允许旋转的前提下把精灵与孔洞一一配对。
- 对每个配对，求出使精灵形状与孔洞形状重合的唯一旋转角，把精灵的多色图案
  按该角度旋转后逐格填入孔洞。
- 游离精灵原位置擦为背景；框保持不变。

关键洞察
匹配发生在正形状（精灵）与负形状（孔洞）之间，且只认旋转不认镜像——镜像相似
的洞是专门的陷阱；填入时精灵的内部图案必须随对齐旋转一起转动，只把形状对上
还不够。
```

## 5. 朝心印章

- tags:
  - operation:印章覆盖, stamp
  - operation:镜像, mirror
  - operation:重涂色, recolor
  - object:模板面板, template_panel
  - object:前景像素, foreground_pixel
  - relation:分块对应, block_correspondence
  - condition:象限决定朝向, quadrant_determines_orientation
- 参考题目题号：1（bc4146bd）、5（b190f7f5）、10（d364b489）
- 评审档位：达标偏上

### docstring

```text
一句话总述
按分形印章规则把模板盖入每个源像素对应的块，但每份模板要按源像素所在象限做
水平/竖直翻转，使所有副本"朝向"源面板中心。

输入结构
- 输入由两个等大的 N×N 方形面板并列（或上下堆叠）构成，共享同一背景色。
- 一个面板是带若干彩色前景像素的源网格，另一个面板是用单一标记色画出的
  非对称模板掩膜。
- N 为偶数，源面板的四个象限划分无歧义。

规则
- 建立 N²×N² 的背景画布。
- 源像素位于 (r, c) 时，取模板掩膜、涂成该像素颜色；若 c 落在源面板右半则
  先左右翻转，若 r 落在源面板下半则再上下翻转；然后盖入输出的第 (r, c) 块。

关键洞察
模板不是刚性图章——它的朝向由源像素相对面板中心的象限决定，四个象限产生四种
镜像变体，使整幅输出获得指向中心的准对称结构；仅发现分形分块对应还不够，必须
再发现"位置→朝向"的第二层规律。
```

## 6. 双重冗余修复

- tags:
  - operation:补全, completion
  - operation:对称补全, symmetry_completion
  - object:周期瓦片, periodic_tile
  - object:缺损像素, erased_pixel
  - relation:周期重复, periodic_repeat
  - relation:镜像对称, mirror_symmetry
  - condition:单一冗余不足, single_redundancy_insufficient
- 参考题目题号：6（ce039d91）、7（ea959feb）、13（f4081712）
- 评审档位：达标

### docstring

```text
一句话总述
图案同时具有行方向平移周期与关于水平中线的上下镜像对称，被擦成擦除色的格子
须综合两种冗余才能全部恢复。

输入结构
- 矩形网格上是多色图案：行方向按某最小周期 p 平移重复，同时整图关于水平中线
  上下镜像对称。
- 若干格被擦成一种输入中专用的擦除色。
- 擦除分布保证：仅用周期或仅用镜像都无法恢复所有缺格，但两者联合（含关系复合）
  可以，且恢复结果唯一。

规则
- 从未擦格子推断行方向最小周期与上下镜像轴。
- 对每个擦除格，收集其全部周期同余格、镜像对应格以及两种关系复合可达的格子中
  未被擦除者；这些格子颜色一致，即为该格颜色。
- 输出完全修复后的网格。

关键洞察
诱饵在于第一眼像单纯的周期壁纸修复——但部分缺格的所有周期同伴同样被擦除，
只有再发现第二套独立的镜像冗余并把两套关系复合起来，才能闭合全部缺口。
```

## 7. 像素展环

- tags:
  - operation:填充, fill
  - object:标记像素, marker_pixel
  - object:锚点像素, anchor_pixel
  - relation:切比雪夫距离, chebyshev_distance
  - relation:就近归属, nearest_assignment
  - condition:距离即半径, distance_as_radius
- 参考题目题号：10（d364b489）、12（759f3fd3）、16（12997ef3）
- 评审档位：达标

### docstring

```text
一句话总述
网格中有两枚灰色锚点；每个彩色像素归属于距它较近的锚点，并扩展成以该锚点为
中心、经过它自身的完整切比雪夫方环。

输入结构
- 黑色背景，恰有两枚灰色锚点像素，另有若干互不同色的单个彩色像素。
- 每枚彩色像素到两锚点的切比雪夫距离不相等（无平局）。
- 归属同一锚点的彩色像素到该锚点的距离互不相同。
- 由构造保证所有方环互不重叠。

规则
- 对每枚彩色像素，取距其较近的灰色锚点，计算切比雪夫距离 d。
- 把以该锚点为中心、切比雪夫半径为 d 的整圈方环（出界部分裁掉）涂成该像素的颜色。
- 灰色锚点保留；未被任何环覆盖的格子保持背景。

关键洞察
彩色像素既是调色板又是量尺——它不指示方向或顺序，而是用自身与所属锚点的距离
选定自己要占据的那一圈方环；先要用"就近归属"把像素划给正确的中心，再做
"距离→半径"的展开。
```

## 8. 洞数计步的图例链

- tags:
  - operation:重涂色, recolor
  - operation:擦除, erase
  - object:调色板图例, palette_legend
  - object:连通分量, connected_component
  - object:封闭区域, enclosed_region
  - relation:映射链, mapping_chain
  - condition:洞数编码步数, hole_count_encodes_steps
- 参考题目题号：8（94be5b80）、9（dbff022c）、14（b9b7f026）
- 评审档位：达标偏上（修订版）

### docstring

```text
一句话总述
边缘图例给出"旧色→新色"的单跳词典，每个色块沿词典链前进的步数等于它内部
背景色孔洞的数量。

输入结构
- 网格主体是背景上的若干单色色块，每个色块内部封闭着 0 个、1 个或多个背景色
  孔洞（不与外部背景连通）。
- 一条 2×N（或 N×2）图例贴在网格一边：靠外一行是旧色、靠内一行是对应新色。
- 词条可链式衔接（某词条的新色是另一词条的旧色）且无环。
- 训练对中存在同色但孔洞数不同的两个色块，它们的输出颜色不同。

规则
- 读出图例的旧→新单跳映射。
- 对每个色块数出其内部封闭孔洞数 k，把色块颜色沿映射连续代换恰好 k 次
  （若中途颜色不在任何旧色中则停在该色）。
- k=0 的色块保持原色。
- 输出中孔洞保持背景色不变，整条图例区域擦为背景。

关键洞察
第一眼像固定换色表，但同色色块产出不同结果，迫使寻找第二变量——色块自身的
孔洞数是它在映射链上要走的步数；图例提供路径，对象自身编码里程。
```
