## 1. 字形即操作的自指解码

- 参考题目: `995c5fa3`, `36d67576`, `c48954c1`
- tags:
  - operation:解码, decode
  - operation:镜像, mirror
  - operation:旋转, rotate
  - operation:裁剪, crop
  - object:字形图案, glyph_pattern
  - object:多色精灵体, multicolor_sprite
  - relation:自指编码, self_referential_code
  - condition:字形对称即变换, glyph_symmetry_is_transform
  - condition:左序复合, left_to_right_composition

### docstring

```text
依左至右将每个灰色字形自身唯一的对称性作为变换，依次复合施加于多色精灵并输出结果。

输入结构
- 黑色背景。上部横排若干（一至三个）3×3 灰色字形，由灰格与黑格组成，彼此以黑列分隔。
- 下部有一个多色精灵。
- 每个字形恰好具有一种非平凡自对称：左右镜像、上下镜像、主对角转置、副对角转置或 180° 旋转之一。

规则
- 按从左到右的顺序读取字形。
- 每个字形贡献一步变换：即该字形自身在哪种对称操作下保持不变，就对精灵施加哪种操作。
- 将这些变换按左序依次复合作用于精灵。
- 输出为最终精灵裁剪至其包围盒的结果。

关键洞察
- 字形不是需要跨示例查表记忆的任意代码：它的形状就是操作本身——检测字形自身的不变对称，
  就读出了要施加的变换。码表从未给出，却处处自明。
```

## 2. 串行重力与一次性染色闸门

- 参考题目: `2b83f449`, `aabf363d`, `b5ca7ac4`
- tags:
  - operation:重力下落, gravity_drop
  - operation:重涂色, recolor
  - operation:擦除, erase
  - object:令牌, token
  - object:平台, platform
  - relation:顺序依赖, order_dependency
  - condition:平台消耗连锁, platform_consumption_chain
  - condition:末次染色定色, last_color_wins

### docstring

```text
从左到右串行模拟令牌下落，令牌吸收并销毁沿途彩色平台，最终落点与末次吸收的颜色即为答案。

输入结构
- 黑色背景。上方散布若干彩色单像素令牌，每列至多一个。
- 中下部有若干水平的单行彩色平台（长度不小于二），以及若干灰色平台或网格底边充当地面。
- 令牌初始颜色可与平台颜色相同或不同。

规则
- 按列从左到右逐个令牌完整模拟，前一个令牌落定后才开始下一个。
- 令牌竖直下落；落在彩色平台顶面时，令牌改为该平台的颜色，整条平台随即从网格中消失，令牌继续下落。
- 落在灰色平台顶面或网格底边时令牌停止。
- 输出中：被消耗的彩色平台消失、未被触及的彩色平台保留，灰色结构不变；每个令牌画在最终位置并使用
  其最终颜色（途中若吸收多次以最后一次为准，未经过任何彩色平台则保持原色）。

关键洞察
- 彩色平台是一次性的染色闸门：左边令牌消耗掉的平台改变了右边令牌的下落深度与染色序列。
  单看一个令牌像独立的自由落体，全局却是顺序敏感的连锁反应。
```

## 3. 影子拼装：灰段是若干一维投影的并集

- 参考题目: `dc46ea44`, `99fa7670`, `d6542281`
- tags:
  - operation:平移, translate
  - operation:对齐, align
  - object:精灵体, sprite
  - object:边缘投影段, edge_projection_segment
  - object:分隔行, separator_row
  - relation:一维投影对应, projection_correspondence
  - relation:投影并集约束, projection_union_constraint
  - condition:全局拼装唯一解, global_assembly_unique

### docstring

```text
把图例中的精灵放回场景，使全体精灵包围盒在顶行与最左列上的一维投影之并恰好等于给出的灰色线段。

输入结构
- 一条通栏分隔行把网格分成上方场景区与下方图例区。
- 场景区除顶行的若干灰色横段与最左列的若干灰色竖段外全为黑色。
- 图例区画有若干颜色互不相同、朝向固定的精灵。

规则
- 每个精灵按图例中的原始朝向放入场景恰好一次，彼此互不重叠。
- 全体精灵包围盒的行区间投影到最左列之并须恰好等于灰竖段集合，列区间投影到顶行之并须恰好等于
  灰横段集合；一条灰段可以由多个精灵的影子首尾相接或部分重叠合成，段数与精灵数不必对应。
- 输入保证满足全部约束的摆放方式唯一。
- 输出为场景区：顶行与最左列的灰段全部清为黑色，画上放置好的各精灵。

关键洞察
- 灰段不是逐段认领的单个影子，而是若干从未画出的摆放在两条边上的一维影子之并集；
  必须把各精灵的宽与高当作可拆分、可叠合的量做全局联立拼装，就近逐段配对必然失败。
```

## 4. 直条编码的外扩螺旋

- 参考题目: `a1aa0c1e`, `99fa7670`, `7ddcd7ec`
- tags:
  - operation:射线延伸, ray_extend
  - operation:计数, counting
  - operation:擦除, erase
  - object:控制条, control_bar
  - object:孤立像素, isolated_pixel
  - relation:长度编码步长, length_encodes_step
  - condition:成对递增螺旋, paired_increment_spiral
  - condition:方位定向, attachment_side_direction

### docstring

```text
把每个标记旁的同色直条读作初始方向与步长，画出成对递增、顺时针旋进的矩形螺旋，直至走出网格。

输入结构
- 黑色背景上有若干彩色标记像素。
- 每个标记恰有一条与之相接的同色直条，位于标记的上、下、左或右侧，长度为 N（不含标记本身）。
- 输入保证各螺旋路径互不接触。

规则
- 对每个标记：首段方向为背离直条的方向，即直条指向标记方向的延长线。
- 自标记出发，依次直行 N、N、N+1、N+1、N+2、N+2、……格，每段走完后顺时针转 90°，
  直到路径离开网格为止。
- 路径以标记颜色绘制；输出中原直条被擦除为背景，标记像素保留。

关键洞察
- 直条是一支被消耗的复合密钥：它的方位给出发射方向，长度给出初始步长；
  成对加一的步长律使折线成为不自交的外扩矩形螺旋，而这条增长律本身必须靠比对示例才能发现。
```

## 5. 破缺折叠：对称是画布，缺陷是笔迹

- 参考题目: `67b4a34d`, `de493100`, `c48954c1`
- tags:
  - operation:镜像, mirror
  - operation:裁剪, crop
  - operation:解码, decode
  - object:对称图案, symmetric_pattern
  - object:缺陷像素, defect_pixel
  - relation:折叠聚合, fold_aggregation
  - condition:少数派即信号, minority_is_signal

### docstring

```text
把双轴对称壁纸上所有破坏对称的少数派像素折叠进一个象限，拼出一幅从未完整出现过的图形。

输入结构
- 网格高宽均为偶数，铺满一幅关于水平中轴与竖直中轴皆镜像对称的多色壁纸图案。
- 图案中散布若干缺陷格：其颜色与其四元对称轨道中另外三格的一致颜色不同。
- 输入保证不同缺陷折叠后不落在同一格。

规则
- 对每个四元轨道，若三格同色、一格异色，则该异色格为缺陷，记录其颜色。
- 将每个缺陷映射到其轨道在左上象限的代表坐标。
- 输出为高宽各减半的黑底网格，仅在各代表坐标处填入对应缺陷色。

关键洞察
- 这不是一道修复对称的题，方向恰好相反：对称的壁纸只是载体，答案是被四个象限分摊的破缺信息——
  只有把网格沿两条中轴折叠，散落各处的残迹才会汇聚成一个完整图形，任何单一象限里都只有碎片。
```

## 6. 最低缺口封顶的级联注水

- 参考题目: `00d62c1b`, `a699fb00`, `2b83f449`
- tags:
  - operation:洪泛填充, flood_fill
  - operation:重力下落, gravity_drop
  - object:容器, container
  - object:缺口, gap
  - object:滴口, faucet_pixel
  - relation:液面平衡, water_level
  - relation:水路可达性, flow_reachability
  - condition:最低泄漏点封顶, lowest_leak_caps_level
  - condition:级联流动, cascade_flow

### docstring

```text
让水从滴口沿重力落入容器并逐层积满，水位止于最低缺口并从缺口溢出续落，画出稳态的水路与水面。

输入结构
- 黑色背景。顶行有一个蓝色滴口像素。
- 网格中有若干灰色容器：一像素厚、开口向上的盆状边界；部分容器的侧壁上恰有一个单格缺口。
- 各容器在竖直方向错落分布。输入保证：被水路经过的每个容器侧壁都恰有一个缺口，
  且级联的最后一股水直达网格底边；无缺口的容器均不在水路上。

规则
- 从滴口正下方开始以蓝色画竖直水柱，直到落入某容器内部。
- 容器内的水自盆底逐层填满内部空格；水面升至该容器最低缺口所在行即停止（该行连同缺口格填水），
  随后自缺口外侧一格起继续竖直下落，重复上述过程。
- 未落入任何容器的水柱画至网格底行为止。
- 未被水路经过的容器保持全空；所有容器壁保持不变。

关键洞察
- 每个容器的水位不由容量或形状决定，而由其最低泄漏点封顶；哪些容器有水又取决于水路的可达性——
  看第一个示例很容易误以为"所有盆都要注满"，实际上水只走一条由缺口串起来的因果链。
```

## 7. 十字坐标系下的象限收纳

- 参考题目: `917bccba`, `d89b689b`, `b5ca7ac4`
- tags:
  - operation:平移, translate
  - operation:排序, sort
  - operation:裁剪, crop
  - object:空心矩形, hollow_rectangle
  - object:十字图案, cross_pattern
  - object:散落单像素, singleton_pixel
  - relation:象限对应, quadrant_correspondence
  - condition:距离序对角收纳, distance_ordered_diagonal_packing

### docstring

```text
把框外的散点按其相对十字交点的象限收进对应房间，并按到交点的距离沿指向框角的对角线依次码放。

输入结构
- 黑色背景上有一个一像素厚的空心矩形框；框内一条整行横线与一条整列竖线（另一颜色）组成十字，
  十字交点在框内但不必居中，把内部分成四个房间。
- 框外散布若干彩色单像素，颜色可重复。
- 输入保证任意同象限两点到十字交点的切比雪夫距离互不相等，且每个房间足以容纳其收纳序列。

规则
- 以十字交点为原点，判断每个外部像素所处的象限，归入对应的房间。
- 每个房间内，把归入的像素按到十字交点的切比雪夫距离从近到远排序。
- 从该房间中与十字交点对角相邻的内角格开始，沿指向该房间框角的对角线逐格放置这些像素的颜色。
- 输出裁剪到框（含框边界）：框与十字保留，房间内画上码放结果，其余为黑。

关键洞察
- 象限由十字交点定义而非网格或框的中心——十字偏置时按几何中心划分象限会全部归错；
  四个房间的码放方向互为镜像，却都由"从内角射向外角"这同一条局部法则生成。
```
