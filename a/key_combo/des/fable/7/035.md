## 1. 周期栅栏的真门与破损

- 参考题号: #12 (e95e3d8e)、#19 (84ba50d3)、#7 (6ad5bdfd)
- tags:
  - operation:补全, complete
  - operation:重力下落, gravity_drop
  - object:周期瓦片, periodic_tile
  - object:栅栏带, fence_band
  - object:标记像素, marker_pixel
  - relation:周期对齐, periodic_align
  - condition:一致缺口才可通行, consistent_gap_passable
  - condition:碰撞停止, collision_stop

### docstring

```text
修复水平周期栅栏后让标记下落，只有周期意义上的真门可以穿过，破损缺口依然阻挡。

输入结构
- 背景为主色；网格中部有一条数行高的栅栏带，沿水平方向以固定周期重复同一母题。
- 母题内含若干整列为背景的"真门"；此外若干周期实例中另有格子被抹成背景（破损缺样）。
- 栅栏带上方散布单像素彩色标记。

规则
- 由所有非背景栅栏格推断最小水平周期，并据此补全破损，得到修复后的栅栏。
- 每个标记竖直下落：其所在列在修复后的栅栏带内若含非背景格，则停在栅栏带上沿
  的上方一格，同列多个标记依次向上堆叠。
- 若该列在修复后的带内整列为背景（真门），标记穿过栅栏一直落到网格底行，
  同列多个标记自底向上堆叠。
- 输出为修复后的完整栅栏加全部落定的标记。

关键洞察
- 画面上的缺口分两类：只有在每一个周期实例中都出现的缺口才是真门；
  破损缺口虽然看起来是开的，修复后依然挡住下落。
- 碰撞面由重建出的周期决定，而不是由画面像素决定——判定能否穿过之前必须先修复周期。
```

## 2. 动量接力

- 参考题号: #7 (6ad5bdfd)、#6 (e4941b18)
- tags:
  - operation:滑动, slide
  - operation:级联传递, cascade_transfer
  - operation:擦除, erase
  - object:边墙, edge_wall
  - object:实心块, solid_block
  - object:冲击标记, impulse_marker
  - relation:墙面确定方向, wall_determines_direction
  - condition:逐块接力结算, one_block_moves_at_a_time
  - condition:碰撞停止, collision_stop

### docstring

```text
冲击标记触发车道内的块逐个接力撞向边墙，空隙沿链条向后传递，而不是整体压实。

输入结构
- 一种颜色构成完整的单像素厚边墙，且不在其他位置出现；墙的所在边给出运动方向。
- 每条垂直于墙的车道内有若干颜色互不相同的实心短块。
- 部分车道在离墙最远的块的外侧紧贴一个统一颜色的冲击标记像素；背景为主色。

规则
- 只结算带冲击标记的车道，冲击标记本身从输出中消失。
- 车道内离墙最远的块先沿车道朝墙滑动，撞上下一块即停（紧贴其近侧）；
  被撞的块随后以同样方式滑向再下一块；如此逐块接力，最后一块滑到紧贴边墙。
- 没有冲击标记的车道保持原样，边墙保持不变。

关键洞察
- 碰撞把运动传给下一块而不是推着一起走：结算后相邻块之间的空隙
  等于原先更靠墙一侧的对应空隙，整条车道并没有压实成一堆。
- 这既不是全体贴墙的堆积，也不是等距平移——两种直觉假设都会被示例否定。
```

## 3. 拼链定序的条带叠色

- 参考题号: #1 (78332cb0)、#20 (9344f635)
- tags:
  - operation:射线延伸, ray_extend
  - operation:排序, reorder
  - object:图例块, legend_block
  - object:双像素标记, domino_marker
  - object:分隔线, separator_line
  - relation:边缘像素匹配, edge_pixel_matching
  - condition:链序决定覆盖优先级, chain_order_determines_layering

### docstring

```text
图例小块靠边缘像素拼成唯一链条，链序决定画布上各色条带交叉处的覆盖顺序。

输入结构
- 一条分隔线把网格分成图例区与画布区。
- 图例区内若干等大的单色图案块被分隔线隔开、顺序打乱；块与块之间可以按
  "相邻边前景像素位置吻合"拼接，全体恰好拼成唯一的一条链。
- 画布区内每种图例颜色恰有一个双像素 domino：横放者标记其所在行，竖放者标记其所在列。

规则
- 先按边缘匹配把图例块排成唯一链条，得到颜色的先后顺序。
- 在画布上把每个 domino 延伸成整行或整列的同色条带。
- 条带按链条顺序依次绘制：靠链尾的颜色后画，交叉处覆盖先画的颜色。
- 输出仅为画好条带的画布区。

关键洞察
- 交叉处谁压谁在画布内找不到任何依据，覆盖优先级被编码在图例块的边缘拼接顺序里。
- 横竖朝向只决定条带走向，不决定层级；"行覆盖列"或"固定某色优先"的直觉假设
  都会在后续示例中被推翻。
```

## 4. 恰配口袋与瓶颈

- 参考题号: #18 (332f06d7)、#11 (42f14c03)
- tags:
  - operation:滑动, slide
  - operation:路径搜索, pathfinding
  - object:蜿蜒通道, winding_channel
  - object:口袋腔室, pocket_chamber
  - object:实心方块, solid_square
  - relation:尺寸约束通行, size_constrains_passage
  - condition:恰好尺寸匹配, exact_size_match
  - condition:忽略干扰项, ignore_distractors

### docstring

```text
实心方块沿分叉河道滑行，进入唯一"既够得着又恰好合身"的口袋；被瓶颈隔断的同尺寸口袋只是诱饵。

输入结构
- 背景为主色；河道色构成一条带分叉的连通通道。
- 通道的各个端点接有边长不一的正方形口袋（口袋区域也是河道色）。
- 通道上有一个 N×N 的异色实心方块（mover）。

规则
- 方块只能在整体处于河道内的前提下滑动，因此宽度小于 N 的路段无法通过。
- 在所有边长恰为 N 的口袋中，找到方块沿通道可达的那一个，
  把方块移入该口袋并恰好填满；方块原位置恢复为河道色。
- 边长不为 N 的口袋，以及因瓶颈而不可达的 N×N 口袋，全部保持不变。

关键洞察
- 目的地由"尺寸恰配"与"通行可达"两个条件共同锁定，缺一不可。
- 单看形状最匹配或距离最近的口袋，往往正是被窄口挡住的诱饵；
  必须沿通道逐段核对通行宽度才能排除它。
```

## 5. 负形的变倍认领

- 参考题号: #9 (e69241bd)、#11 (42f14c03)、#3 (9172f3a0)
- tags:
  - operation:洪泛填充, flood_fill
  - operation:像素放大, pixel_upscale
  - object:迷宫墙, maze_wall
  - object:腔室, chamber
  - object:图例形状, legend_shape
  - relation:缩放形状匹配, scaled_shape_matching
  - condition:倍数逐对不同, per_pair_scale_factor
  - condition:忽略干扰项, ignore_distractors

### docstring

```text
迷宫腔室按"某个图例小形状放大整数倍后的形状"认领颜色并整腔填色，各对匹配的放大倍数互不相同。

输入结构
- 网格一侧是墙色构成的迷宫，把背景分隔成若干 4 连通腔室。
- 另一侧空地上放着若干互不同色的实心小图例形状，图例之间形状互不相同。

规则
- 对每个图例形状尝试所有整数倍逐格放大（每格变 k×k，k≥1）。
- 若某腔室的形状在平移意义下与某图例的某一倍放大像全等，则把该腔室整体填成该图例的颜色。
- 每个图例至多匹配一个腔室、每个腔室至多被一个图例匹配，且不同匹配对的倍数各不相同。
- 无匹配的腔室保持背景色，无匹配的图例是干扰项；输出中图例区清为背景，迷宫墙保持不变。

关键洞察
- 参与匹配的是"洞"而不是物：腔室这一负空间才是形状对象。
- 匹配跨尺度且倍数逐对不同——在任何单一尺度上做全等比对都会漏配，
  必须把每个图例当作可任意整数倍缩放的模板逐对试配。
```

## 6. 干涉影子

- 参考题号: #2 (195ba7dc)、#7 (6ad5bdfd)、#5 (7491f3cf)、#19 (84ba50d3)
- tags:
  - operation:重力下落, gravity_drop
  - operation:透明叠加, transparent_overlay
  - operation:擦除, erase
  - object:精灵, sprite
  - object:地形, terrain
  - relation:反事实独立结算, counterfactual_independent_settling
  - condition:仅保留交集, intersection_only
  - condition:碰撞停止, collision_stop

### docstring

```text
两个悬空精灵各自在"对方不存在"的平行世界里落到地形上，输出中精灵消失，只留下两个落定结果的重叠部分作为黄色影子。

输入结构
- 背景为主色；底部有一段高低起伏的地形色。
- 上方悬着两个不同颜色的 4 连通精灵，水平范围部分重叠。

规则
- 让其中一个精灵在忽略另一个精灵的世界里整体竖直刚性下落，
  直到任一列接触地形或网格底边为止，碰撞停止。
- 对另一个精灵做同样的独立结算。
- 取两个落定形状逐格的交集，把交集格填为黄色放入输出。
- 两个精灵本身从输出中完全消失，地形保持原样。

关键洞察
- 输出里根本没有原来的两个精灵——黄色影子是两个平行世界落定结果的干涉痕迹。
- 按"先后依次堆叠"的世界观计算重叠会得到完全不同的答案；
  交集形状无法从任何单个精灵直接读出，必须分别完成两次反事实下落再合成。
```

## 7. 稀色签名的块级印章

- 参考题号: #10 (2dc579da)、#8 (48f8583b)、#5 (7491f3cf)
- tags:
  - operation:印章覆盖, stamp_overlay
  - object:分隔十字, separator_cross
  - object:控制面板, control_panel
  - object:低频色签名, rare_color_signature
  - relation:掩码选源面板, mask_selects_source_panel
  - condition:最低频色作为索引, least_frequent_color_as_key

### docstring

```text
控制面板的每个散点按"稀有色签名"索引一个图案面板，把整个面板印章到输出块阵的对应位置。

输入结构
- 居中的单色分隔十字把网格分成四个等大面板。
- 其中一个面板只含稀疏的孤立单像素，是控制板；其余三个面板是致密图案。
- 每个图案面板中出现次数最少的颜色唯一，作为该面板的签名色；
  控制板上每个散点的颜色都等于某个图案面板的签名色。

规则
- 输出是（控制板行数×面板高）行、（控制板列数×面板宽）列的块阵。
- 控制板的每个非背景格：把签名色与该格颜色相同的整个图案面板原样复制到对应块。
- 控制板的背景格对应全背景块；分隔十字不进入输出。

关键洞察
- 散点颜色是按各面板"出现次数最少的颜色"来索引面板的——面板的主色是幌子，
  两个面板的主色可以完全相同，唯一可靠的名字是它的稀有色。
- 散点是块级像素：它选择的不是一个颜色，而是一整块图案的放置。
```
