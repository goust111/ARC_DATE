## 1. 螺旋雕刻

- tags:
  - operation:螺旋绘制, spiral_draw
  - operation:重涂色, recolor
  - object:路径, path
  - object:孤立控制点, isolated_control
  - relation:连锁反应, chain_reaction
  - condition:碰撞转向, turn_on_collision
  - condition:标记触发转向兼换色, marker_triggers_turn_and_recolor
- 参考题目题号：28e73c20, 963c33f8, 96a8c0cd

### docstring

```text
从左上角起顺时针绘制螺旋轨迹，散布的标记像素在前瞻判定中等同于已画轨迹，
既迫使螺旋提前转向、雕刻出畸变的螺旋形状，又使被它逼转的轨迹从转向处换用
该标记的颜色。

输入结构
- 网格几乎全黑，仅散布若干孤立单像素标记，颜色互不相同且都不是灰色。

规则
- 从左上角出发向右绘制轨迹，初始颜色为灰色。
- 前瞻判定中，标记格与已画轨迹格同等看待：当下一步将越界，或前方两格是
  轨迹或标记时，顺时针转向；当下一步将进入轨迹或标记格时停止。
- 若某次转向是由标记（而非边界或自身轨迹）触发的，则从该转向格起，后续
  轨迹改用该标记的颜色，直到下一次由标记触发的转向。
- 所有标记像素本身保持原样。

关键洞察
- 标记同时扮演两种角色：像幽灵墙一样实时改变螺旋的几何——早期一次逼转
  会连锁改变后续整条路径与之后遇到哪些标记；又像信号灯一样给被它逼转的
  路径段着色。轨迹颜色段的边界与螺旋的畸变点是同一组事件。
```

## 2. 指令带巡线

- tags:
  - operation:路径绘制, path_drawing
  - operation:绕行, detour
  - operation:擦除, erase
  - object:边界标记, border_marker
  - object:障碍条, obstacle_bar
  - object:控制像素, control_pixel
  - relation:遭遇序对应指令序, encounter_order_maps_instruction_order
  - condition:指令定绕行方向, instruction_determines_detour
- 参考题目题号：96a8c0cd, 963c33f8

### docstring

```text
红色轨迹从边界标记直线深入，遇到的第 k 条灰色横条按指令带第 k 个像素的
颜色决定向左或向右绕行，指令带用毕后被擦除。

输入结构
- 背景为主色；边界上有一个红色出发标记。
- 网格内部有若干条一格厚的灰色横条，与行进方向垂直，左右位置各不相同。
- 网格某个角落沿边缘排着一段由蓝色与绿色像素组成的连续指令带，其长度
  等于灰色横条的数量。

规则
- 轨迹从红色标记沿垂直于该边界的方向向内直行。
- 每次即将撞上一条灰色横条时，取指令带中尚未使用的最靠前像素：蓝色则从
  行进方向的左侧绕过该条，绿色则从右侧绕过，绕行后回到原前进方向继续
  直行；轨迹到达对侧边界停止。
- 输出中灰色横条保持不动，轨迹经过的背景格涂红，指令带整体擦除。

关键洞察
- 指令带与障碍之间没有任何空间对位关系；它是一个按遭遇顺序消耗的队列，
  第 k 个指令支配第 k 次相遇，而不是支配某个特定位置的横条。
```

## 3. 链式迁移

- tags:
  - operation:平移, translate
  - operation:擦除, erase
  - object:多色精灵体, multicolor_sprite
  - object:嵌入标记像素, embedded_marker
  - object:孤立控制点, isolated_control
  - relation:颜色配对, color_pairing
  - relation:配对链, pairing_chain
  - condition:被占格即落点, occupied_cell_is_anchor
- 参考题目题号：54dc2872, 82819916

### docstring

```text
唯一的孤立控制点只牵动第一只精灵，其余精灵各自落到"体色与自己标记色相同
的那只精灵"在输入中的标记格上，形成一条迁移链。

输入结构
- 背景为主色；有若干 L 形精灵，每只由一种重复体色加一个异色嵌入标记像素
  构成，各精灵体色互不相同。
- 另有恰好一个孤立单像素控制点。
- 每只入链精灵的标记色，要么等于控制点颜色，要么等于另一只精灵的体色，
  且这种匹配一一对应。

规则
- 标记色等于控制点颜色的精灵，其目标是控制点所在格。
- 标记色等于某只精灵体色的精灵，其目标是那只精灵在输入中嵌入标记像素
  所占的格。
- 把每只有目标的精灵整体平移，使其 L 拐角落在目标格上；擦除所有精灵原位
  与控制点后统一绘制。
- 标记色与任何目标都不匹配的精灵留在原地。

关键洞察
- 画面上只画了一个锚点，其余锚点在输入中都被精灵自己的标记像素占着；
  只有解出体色-标记色的配对链，才能看出那些被占格同时也是落点。
```

## 4. 负空间对位布尔

- tags:
  - operation:布尔运算, boolean_op
  - operation:平移, translate
  - object:掩码区域, mask_region
  - object:分隔线, divider_line
  - object:封闭区域, enclosed_region
  - relation:孔洞配准, hole_registration
  - condition:交集输出, intersection_out
  - condition:锚点从未画出, anchor_never_drawn
- 参考题目题号：6430c8c4, 54dc2872, 0a2355a6

### docstring

```text
两个被分隔行隔开的前景掩码各含恰好一个单格封闭孔洞，按孔洞对孔洞平移
叠合后，两掩码前景的交集涂绿输出。

输入结构
- 一条通体一色的分隔行把网格分成上下两个等大的矩形。
- 每一半含背景色和一种前景色掩码，两半前景色互不相同。
- 每个掩码内部恰有一个被前景完全包围的单格背景孔洞，除此之外两半再无
  封闭孔洞。

规则
- 输出为一半的尺寸，采用上半的坐标系。
- 找出每个掩码中唯一的单格封闭孔洞，把下半整体平移使两个孔洞重合。
- 叠合后两半皆为前景的格涂绿（孔洞格本身按背景对待），其余格为背景；
  平移后未被下半覆盖到的格按下半为背景处理。

关键洞察
- 配准锚点从未被画出——它是每个掩码内部的"负空间"（唯一的封闭孔洞）；
  两个掩码的对位关系由这对看不见的孔洞给出，而按网格行列直接对齐在部分
  示例中恰好成立，是刻意设置的假象。
```

## 5. 孔洞定节拍

- tags:
  - operation:重涂色, recolor
  - operation:计数, counting
  - object:连通分量, connected_component
  - object:封闭区域, enclosed_region
  - object:交替格栅, alternating_lattice
  - relation:列周期, column_periodicity
  - relation:拓扑数定频率, topology_sets_frequency
  - condition:相位由对象位置给定, phase_from_object_position
- 参考题目题号：0a2355a6, ba26e723

### docstring

```text
青色对象的孔洞数决定黄色条带上粉色高亮列的周期，对象自身的横向位置决定
这些列的相位。

输入结构
- 黑色背景上有一个带若干 4 连通封闭黑色孔洞的青色对象，以及一片与其
  分离的黄色条带结构（若干行内黑黄相间或整行皆黄）。
- 青色对象的形状与大小在各示例间差异很大。

规则
- 设青色对象的孔洞数为 n，其最左列为 c。
- 保持青色对象与所有黑色像素不变。
- 在黄色结构中，凡列号与 c 关于 n 同余的列，其黄色像素全部改为粉色。

关键洞察
- 高亮列的规律无法只从条带内部读出：节拍来自另一个对象的拓扑孔洞数，
  起拍位置来自它的空间位置，两条线索缺一不可。
```

## 6. 弹性立柱

- tags:
  - operation:弹性拉伸, elastic_stretching
  - operation:模板填充, template_filling
  - object:多色范例矩形, multicolor_exemplar_rect
  - object:障碍物, obstacle
  - object:边缘标记, edge_marker
  - relation:按目标尺寸调整, resize_to_target
  - condition:内部行程拉伸, interior_run_stretches
- 参考题目题号：40f6cd08, 41ace6b5, 963c33f8

### docstring

```text
把范例竖条按每根标记列的净空高度做弹性拉伸后立入：两端色带定高，只有
中段行程伸缩。

输入结构
- 背景为主色；网格一侧立着一根多段竖条范例，从上到下由几段纯色横带
  组成，其中恰有一段与上下相邻段颜色不同的中段。
- 顶边上有若干标记像素指出目标列；底部各目标列上方有高度不一的灰色
  地形块。范例所在列无标记与地形。

规则
- 对每根标记列，取从顶行到该列地形最高格上一格的净空区间，在其中自上
  而下重画范例：首末各色带保持原有行数不变，仅中段带拉伸或压缩，使总高
  恰好填满净空。
- 地形、范例与其余背景保持不变，标记像素被立柱顶端覆盖。

关键洞察
- 立柱不是范例的等比缩放，而是行程级的弹性配长——只有唯一的内部行程
  吸收全部高度差；必须同时读出"哪一段可伸缩"与"每列净空到底多高"。
```

## 7. 隐形锚点连线

- tags:
  - operation:连线, connect
  - object:微型条, micro_bar
  - object:隐含十字, implied_plus
  - relation:四向对齐, four_way_aligned
  - relation:同行同列相邻连接, adjacent_anchor_connection
  - condition:缺失中心, missing_center
  - condition:无障碍通路, unobstructed_path
- 参考题目题号：9f5f939b, 60a26a3e, 55059096

### docstring

```text
先由四根两像素短条推定每个隐含十字的空缺中心，再在同行或同列相邻的中心
之间沿背景连红线。

输入结构
- 背景为主色，单一前景色构成若干孤立的横向或纵向两像素短条。
- 部分短条按上下左右各隔一格的方式围出隐含十字的空缺中心；另有一些短条
  只凑齐两三个方向，不构成完整十字。

规则
- 仅当某背景格的上下左右四个方向、距离 2 到 3 格处都恰有短条时，该格才
  是一个锚点中心。
- 对每一行与每一列，把其中的锚点中心按顺序两两相邻配对；若一对相邻中心
  之间的连线段上除本对十字自身的短条外全是背景，则把这段线上的背景格
  （含两个中心）涂红。
- 不满足条件的短条与格子保持不变。

关键洞察
- 被连接的对象从未被完整画出——锚点是四根分离短条围出的"空位"；连接只
  发生在可见性相邻的锚点之间，凑不齐四向的短条组是专门的诱饵。
```
