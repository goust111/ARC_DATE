## 1. 框计数驱动的螺旋

- 参考题目题号: 4, 12
- tags:
  - operation:计数, counting
  - operation:排序, sorting
  - operation:螺旋绘制, spiral_drawing
  - object:空心矩形, hollow_rect
  - object:标记像素, marker_pixel
  - object:中心标记, center_marker
  - object:调色板, palette
  - relation:计数决定段长, count_determines_segment_length
  - condition:方向分色, direction_based_color_split

### docstring

```text
把散落各框内的灰点计数、升序排列，作为一条外扩方形螺旋的逐段长度，从孤立起点标记出发按左、下、右、上的顺序绘制。

输入结构
- 背景占绝大多数。
- 左上角有两个相邻的调色像素：左侧颜色用于水平段，右侧颜色用于竖直段。
- 网格中散布若干彩色空心矩形框，每个框内部含有若干灰色标记点，
  各框的灰点计数互不相同。
- 另有一个不属于任何框的孤立像素，是螺旋的起点标记。

规则
- 统计每个框内部灰点的数量，把这些数量按从小到大排序，得到长度序列。
- 从起点标记出发，依次按左、下、右、上循环转向；第 i 段行走的格数等于
  长度序列中的第 i 个数。
- 水平段涂左调色色，竖直段涂右调色色；起点标记保留原色。
- 输出中删去所有矩形框与灰点；两枚调色像素保留。
- 保证螺旋不越出网格。

关键洞察
- 各框不是场景内容而是参数表：灰点计数经排序后成为螺旋的逐段步长；
  第一眼容易误以为步长是固定递增数列，对照多个示例才能发现步长
  来自框内计数的排序结果。
```

## 2. 象限残片复原与冒充者

- 参考题目题号: 1, 8, 19
- tags:
  - operation:旋转, rotate
  - operation:透明叠加, transparent_overlay
  - operation:裁剪, crop
  - object:十字分隔线, cross_divider
  - object:象限, quadrant
  - object:精灵体, sprite
  - object:冒充者残片, impostor_fragment
  - relation:象限旋转对应, quadrant_rotation_correspondence
  - condition:并集补全, union_completion
  - condition:冒充者定朝向, impostor_sets_orientation

### docstring

```text
四个象限里有三片是同一多色图案经不同旋转后的残缺副本，另一片是冒充者；找出冒充者，把三片真品旋转对齐并集补全，按冒充者对角象限的朝向输出完整图案。

输入结构
- 一种非背景色构成整行整列的实心十字，把网格分成四个象限。
- 其中三个象限各含同一多色图案的一份残缺旋转副本：各自缺失一部分
  像素，任何单片都不完整，但三片互补。
- 剩下一个象限是冒充者——与其余任何一片在任意旋转翻转下都无法
  无冲突地对齐。

规则
- 对四片两两尝试旋转对齐，找出互相兼容的三片，余下的即冒充者。
- 把三片真品旋转到同一朝向后逐格并集：任一真品在该格有前景色就
  输出该色。
- 输出朝向取冒充者所在象限的对角象限中那片真品在输入里的朝向；
  输出尺寸为图案的紧致包围盒。

关键洞察
- 先要发现"四片并非都属于同一系统"，兼容性判定本身就是解题的
  一部分；冒充者不仅要被剔除，还反过来指定输出的朝向基准——
  只裁最完整的一片必缺像素，忽略冒充者则朝向无从确定。
```

## 3. 符号筛选后的顺时针压缩

- 参考题目题号: 9, 16
- tags:
  - operation:压缩, compress
  - operation:滑动, slide
  - object:空心符号, hollow_symbol
  - object:边缘标记线, edge_marker_line
  - relation:形状频次分组, shape_frequency_grouping
  - condition:旋转翻转不变, rotation_flip_invariant
  - condition:唯一形状剔除, unique_shape_removed
  - condition:标记指示方向, marker_indicates_dir

### docstring

```text
把粗格上的空心符号缩成像素，剔除形状孤例，再沿标记边的顺时针方向压实。

输入结构
- 网格有背景、一条占满某条边的标记线，以及排布在粗行列点阵上的
  单色空心符号。
- 每个符号占据一个固定大小的方块，颜色各异，形状之间可能互为
  旋转或翻转关系。

规则
- 将每个符号在粗网格的对应格位换成一枚该符号颜色的像素，得到
  缩小的符号网格。
- 对符号形状做旋转翻转归一：形状在场景中出现两次及以上的符号
  保留，形状孤例的符号删除。
- 标记边给出压缩方向（沿边界顺时针行进）：上边 → 向右，
  右边 → 向下，下边 → 向左，左边 → 向上；保留像素按原相对
  次序滑到底。
- 输出为压缩后的符号网格，不包含标记线。

关键洞察
- 三层依次咬合：大图先要读成缩小的符号网格，再按旋转翻转不变的
  形状频次筛掉孤例，最后才轮到标记线以顺时针方式解码出重力方向；
  跳过任何一层都得不到正确答案。
```

## 4. 空洞数决定的图层优先级

- 参考题目题号: 7, 8
- tags:
  - operation:透明叠加, transparent_overlay
  - operation:折叠, collapse
  - operation:计数, counting
  - object:等高带, equal_height_band
  - object:颜色掩码层, color_mask_layer
  - object:封闭区域, enclosed_region
  - relation:同坐标叠加, same_position_overlay
  - condition:空洞数定优先级, hole_count_priority

### docstring

```text
把等高的几条颜色掩码带按各自围出的封闭空洞数排定图层次序，叠加成一条带。

输入结构
- 网格被均分为若干条等高的水平带，各带同尺寸。
- 每条带是黑底上的单色掩码，掩码可能围出若干四连通的封闭背景空洞。
- 各带的空洞数互不相同。

规则
- 统计每条带的掩码所围出的封闭空洞数量。
- 按空洞数从多到少排定优先级：空洞越多的带越靠上层。
- 在每个局部坐标处，自上层向下层查找，输出第一个非黑的颜色；
  四处全黑则输出黑。
- 输出尺寸等于单条带。

关键洞察
- 图层次序既不是带的排列顺序也不是固定表，而是每条带自身的拓扑
  性质；必须先对每层整体做封闭空洞计数，才知道谁压住谁——按
  位置顺序叠加在部分示例上会碰巧成立，在其余示例上必然失败。
```

## 5. 面积预算的反弹拉伸

- 参考题目题号: 6, 11, 2
- tags:
  - operation:拉伸, stretch
  - operation:计数, counting
  - object:空心矩形, hollow_rectangle
  - object:标记点, marker_pixel
  - object:阻挡对象, blocker_object
  - relation:颜色配对, color_pairing
  - condition:面积等于拉伸量, area_equals_stretch_budget
  - condition:遇阻反弹溢出, blocked_overflow_reversed

### docstring

```text
每个矩形框沿其同色标记指示的方向拉伸，拉伸总格数等于自身内部色像素数，遇到障碍或边界时剩余的拉伸量反弹到对侧继续伸。

输入结构
- 背景为最常见色。
- 若干由边框色与内部色构成的实心矩形，各矩形边框色互不相同。
- 每个矩形在其某一侧的行或列延长线上有一枚与其边框同色的孤立
  标记像素，只指示方向。
- 部分矩形与其拉伸方向之间存在其他矩形的阻挡，或紧邻网格边界。

规则
- 矩形的拉伸预算等于其内部色像素的个数。
- 先沿标记方向逐行或逐列扩张，每扩一行/列消耗一点预算。
- 当再扩一步会触及其他对象或越出网格时，剩余预算转向相反一侧
  继续扩张；两侧都无法再扩时停止，多余预算作废。
- 扩张后的矩形用原边框色重新描边、原内部色填充；所有标记像素
  从输出中消失，其余内容不变。

关键洞察
- 标记只给方向不给终点，真正的拉伸量藏在矩形自己的面积里；
  受阻后的反向溢出使得只看无阻挡的示例会把规则误认成
  "伸到标记为止"，而阻挡示例里矩形会朝标记的反方向长出去。
```

## 6. 嵌套归属的计数摘要错位

- 参考题目题号: 12, 17
- tags:
  - operation:计数, counting
  - operation:排序, sorting
  - operation:循环移位, cyclic_shift
  - object:空心矩形, hollow_rect
  - object:标记像素, marker_pixel
  - relation:嵌套包含, nested_containment
  - relation:有序槽位, ordered_slots
  - condition:最内层归属, innermost_ownership
  - condition:长度与颜色解耦, length_color_decoupled

### docstring

```text
框可以嵌套；每个框只统计直接属于自己的灰点，按计数升序摘要成行，且每行颜色向后借用下一名次框的颜色。

输入结构
- 背景占主导，场上有若干颜色互不相同的空心框。
- 框之间存在嵌套：某些框整个位于另一框的内部。
- 灰色标记点散布在各框内部；各框的直接灰点数互不相同。

规则
- 每枚灰点归属于包含它的最内层框。
- 按直接计数从小到大给框排名次。
- 输出每个名次一行，从上到下按名次排列；第 i 行的长度等于
  第 i 名框的计数。
- 第 i 行的颜色取第 i+1 名框的颜色，最后一名的行取第一名框的
  颜色。
- 各行左对齐，右侧用背景补齐到最大计数；输出高为框数、宽为
  最大计数。

关键洞察
- 两处相位都会骗人：灰点表面上同时落在外层框的范围内，必须按
  最内层归属重新分账；行色又与行长错开一位，默认"行色即该框色"
  会使所有行整体对不上号。
```

## 7. 双块合缝的空洞拼图

- 参考题目题号: 10, 7, 16
- tags:
  - operation:填充, fill
  - operation:模式匹配, pattern_match
  - object:面板, panel
  - object:分隔列, separator_column
  - object:封闭区域, enclosed_region
  - object:拼块, piece
  - relation:二对一拼合, two_pieces_one_hole
  - condition:旋转翻转允许, rotation_flip_allowed
  - condition:无缝无叠, seamless_no_overlap
  - condition:干扰块弃用, distractor_discarded

### docstring

```text
左面板每个对象围出的封闭空洞都无法被任何单个拼块填满，必须从右面板挑出两个拼块经旋转翻转拼合、无缝无叠地恰好填满整个洞。

输入结构
- 一条实心分隔列把网格分成左右两个面板。
- 左面板有若干前景对象，每个对象内部围出一个四连通的封闭背景
  空洞。
- 右面板散布若干单色实心拼块，颜色互不相同。
- 每个洞恰好存在唯一的一对拼块与唯一的拼合摆放（允许旋转与翻转）
  能把洞无缝无叠地填满；右面板另含不属于任何洞的干扰拼块。

规则
- 为每个空洞找出能拼合填满它的那一对拼块，及各自的旋转翻转摆放。
- 把洞内格子按落位的拼块分别涂成对应拼块的颜色。
- 干扰拼块弃用；输出为填补后的左面板，不含分隔列与右面板。

关键洞察
- 没有任何拼块单独与洞形吻合，一对一匹配的第一直觉必然落空；
  真正的配对是二对一的组合拼合，需要同时确定分组、朝向与相对
  摆放，两块的接缝在输出里以双色分界的形式留下证据。
```
