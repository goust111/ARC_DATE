## 1. 相位环扩展

- 参考题目题号：5（9356391f）、6（178fcbfb）、11（b60334d2）
- tags:
  - operation:同心层填充, concentric_fill
  - object:种子像素, seed_pixel
  - object:标记环, marker_ring
  - relation:切比雪夫距离索引, chebyshev_index
  - condition:种子色决定相位, seed_color_determines_phase

### docstring

```text
以完整的同心环结构为色板，从相位由种子颜色决定的位置继续向外展开第二组同心环。

输入结构
- 黑色背景上有一个"生成元"：围绕某中心像素的若干圈切比雪夫同心方环，中心一色，
  每圈一色，颜色互不相同；结构可能被网格边缘裁掉一部分，只留部分弧段。
- 另有一个孤立的种子像素，其颜色恰好等于生成元中某一圈（非中心）的颜色。

规则
- 按切比雪夫距离从生成元读出颜色序列 c0（中心）, c1, c2, …, ck。
- 找到种子颜色在该序列中的位置 p。
- 以种子为中心画同心方环：距离 d 的整圈取色 c(p+d)，直到序列在 ck 耗尽为止；
  出界部分裁剪，且只涂背景格。
- 生成元保持不变。

关键洞察
- 色板从未以一行代码的形式给出，必须从二维同心对象按距离顺序恢复；
  且种子不是序列的开头——它的颜色指明展开的起始相位，新结构只是旧序列的"后缀"。
```

## 2. 双色版式点名双印章

- 参考题目题号：3（8f2ea7aa）、7（1b59e163）、1（67385a82）
- tags:
  - operation:印章覆盖, stamp
  - operation:像素放大, scale_up
  - object:精灵体, sprite
  - object:孤立像素, isolated_pixel
  - relation:颜色寻址, color_as_addressing_key
  - condition:版式格色选印章, layout_cell_color_selects_stamp
  - condition:忽略干扰项, ignore_distractors

### docstring

```text
双色版式图形逐格点名两枚同尺寸印章之一，拼出放大的分发式拼贴。

输入结构
- 黑色背景上有一个由两种颜色混合组成的"版式"连通图形。
- 另有两个单色"印章"图形，颜色分别等于版式所用的两种颜色；
  两印章的包围盒尺寸相同但形状不同。
- 网格上另散布若干孤立单像素杂色噪点。

规则
- 忽略所有孤立单像素。
- 输出高 = 版式包围盒高 × 印章包围盒高，宽同理。
- 版式包围盒内每个前景格 (r, c)：在输出的第 (r, c) 个印章大小的块中，
  粘贴与该格颜色相同的那枚印章（保持印章自身颜色）。
- 版式的背景格对应全背景块。

关键洞察
- 放大图不是任何单个对象的自相似复制——版式的每个格用颜色"点名"两枚印章之一；
  颜色在这里不是外观属性而是寻址键，三个对象的角色（一个版式、两个印章）
  由单色/双色区分，而非大小或位置。
```

## 3. 行程单巡游

- 参考题目题号：5（9356391f）、19（a2fd1cf0）、7（1b59e163）
- tags:
  - operation:连线, draw_line
  - object:色板行, palette_row
  - object:分隔行, separator_row
  - object:起点标记, start_marker
  - relation:曼哈顿路径, manhattan_path
  - condition:代码行定访问序, code_row_defines_visit_order
  - condition:同色识别起点, start_identified_by_separator_color

### docstring

```text
把顶部代码行当作行程单，从起点按其顺序用先横后竖的折线依次接力访问同色标记。

输入结构
- 第一行从左端起是若干互不相同的非背景颜色（其后为背景），
  第二行是一条全宽单色分隔行。
- 分隔行下方的主区域是黑色背景：每个代码颜色恰有一个对应的单像素标记，
  另有一个颜色与分隔行相同的单像素作为起点。

规则
- 从起点出发，按代码行自左向右的顺序依次前往对应颜色的标记。
- 每一段路径先沿当前行水平走到目标列，再垂直走到目标行；
  沿途只把背景格涂成该段目标标记的颜色（先画的段不被后画的覆盖）。
- 到达一个标记后以它为新起点走下一段；
  所有标记像素、代码行与分隔行保持不变。

关键洞察
- 顶行不是配色板而是访问次序表；起点靠"颜色等于分隔行"这一暗合来识别。
  按就近顺序连线在部分示例中碰巧成立，是刻意的诱饵。
```

## 4. 空腔弹出与自愈

- 参考题目题号：13（8b9c3697）、15（3aa6fb7a）、10（1acc24af）、7（1b59e163）
- tags:
  - operation:印章覆盖, stamp
  - operation:补全, completion
  - operation:射线延伸, ray_cast
  - object:凹槽, pocket
  - object:标记像素, marker_pixel
  - object:结构体, structure
  - relation:负形即零件, cavity_as_object
  - condition:走廊命中定落点, corridor_hit_determines_landing
  - condition:忽略干扰项, ignore_distractors

### docstring

```text
把结构边缘的每个凹腔沿开口方向弹射到走廊上的灰色标记处印成灰色，并用结构色把凹腔填平。

输入结构
- 黑色背景上有一个大的蓝色结构，其边缘向内凹进若干"口袋"：
  结构包围盒内、与外部背景连通的黑色空腔，每个口袋只朝一个方向开口。
- 结构外散布若干灰色单像素标记；每个口袋沿其开口方向的走廊上恰有一枚标记，
  其余标记不在任何走廊上。

规则
- 对每个口袋，取其空腔形状，沿开口朝外方向平移，
  直到形状首次覆盖某个灰色标记的位置，把这份形状印成灰色（被覆盖的标记消失）。
- 同时用蓝色把原口袋填平，使结构在该处恢复平整。
- 不在任何走廊上的灰色标记原样保留。

关键洞察
- 被移动的"零件"在输入里从未被画出——它是结构的负形；
  表面看是标记把碎片吸了出来，实际是同一个形状同时以正形（灰印）
  和补全（蓝填）出现在两处。
```

## 5. 图例重写

- 参考题目题号：9（2072aba6）、16（15113be4）、5（9356391f）
- tags:
  - operation:像素放大, pixel_upscaling
  - operation:图案替换, pattern_substitution
  - operation:擦除, erase
  - object:指令区域, instruction_region
  - object:分隔行, separator_row
  - relation:块解码为映射, decode_block_to_mapping
  - condition:图例即白名单, legend_is_whitelist
  - condition:忽略干扰项, ignore_distractors

### docstring

```text
按网格自带的图例把主区域每个像素重写为对应的 2x2 图案块，放大一倍输出。

输入结构
- 一条全宽黄色分隔行把网格分成上方主区域与下方图例区。
- 图例区由若干组"一个单像素颜色 + 紧贴其右的一个 2x2 图案块"构成，
  组之间以背景隔开；2x2 块内部可含多种颜色。
- 主区域是背景上散布的若干种颜色的图形。

规则
- 输出只对应主区域，高宽各放大 2 倍。
- 主区域中每个像素：若其颜色在图例中登记过，替换为对应的 2x2 块；
  背景像素替换为 2x2 背景块。
- 主区域中出现、但图例未登记的颜色，替换为 2x2 背景块（整体被擦除）；
  图例中登记、主区域未出现的颜色是干扰项。
- 分隔行与图例区不进入输出。

关键洞察
- 逐像素替换的"替换表"不是题目固定规则，而是画在输入里的数据；
  图例既是密码本又是白名单——不在册的颜色不是保留而是删除。
```

## 6. 自指占用图

- 参考题目题号：16（15113be4）、3（8f2ea7aa）、12（81c0276b）
- tags:
  - operation:掩码匹配, mask_matching
  - operation:重涂色, recolor
  - object:格子单元, lattice_cell
  - object:格线, grid_line
  - relation:自指描述, self_referential_description
  - condition:占用图匹配单元, occupancy_map_matches_cell
  - condition:自指一致性, self_inclusion_consistency

### docstring

```text
在被格线分成 3x3 单元的网格中，找出内部图案恰好描述"哪些单元非空"的那个自指单元并将其重涂。

输入结构
- 黄色格线把网格分成 3x3 个 3x3 单元。
- 其中若干单元内含蓝色图案（形状各异），其余单元全空。

规则
- 把九个单元的占用情况（非空记 1、全空记 0）压缩成一张 3x3 占用图。
- 恰有一个单元的内部蓝色图案与这张占用图完全一致（保证唯一）。
- 把该单元内的蓝色全部重涂为红色，其余一切保持不变。

关键洞察
- 要寻找的模板不在任何专门的指令区，而是整张图对自身的元描述——
  某个单元画着"全图哪些单元被占用"的地图，且这张地图必须把它自己所在的位置
  也标为占用（自指一致性），据此与其他碰巧相似的图案区分。
```

## 7. 名次配线

- 参考题目题号：14（dc2aa30b）、12（81c0276b）、19（a2fd1cf0）、1（67385a82）
- tags:
  - operation:排序, sorting
  - operation:连线, draw_line
  - operation:重涂色, recolor
  - object:候选块, candidate_object
  - object:终点标记, end_marker
  - relation:面积比较, area_comparison
  - relation:同名次配对, rank_pairing
  - condition:折线连接, L_path_connection

### docstring

```text
把左侧灰色块按面积排名、右缘端口按行序排名，同名次者配对：连出端口色的折线并把灰块染成端口色。

输入结构
- 黑色背景。左半部散布若干灰色实心块，面积互不相同。
- 最右一列上有同样数量的彩色端口像素，颜色互不相同、各占一行。
- 各配对折线在布局上互不交叉（由布局保证）。

规则
- 灰块按面积从小到大排名，端口按行号从上到下排名，第 i 名与第 i 名配对。
- 将配对灰块整体重涂为端口颜色；从该块包围盒的最右列出发，
  先垂直画到端口所在行，再水平画到端口，沿途只把背景格涂成端口颜色。
- 端口像素保持不变。

关键洞察
- 对应关系既不是就近也不是形状匹配，而是两族对象各自排序后的同名次对接
  （面积序对接行序）；示例中距离最近的配对偶尔与名次一致，属于诱饵。
```
