## 1. 对称折叠显影

- tags:
  - operation:异常检出, anomaly_detection
  - operation:折叠, fold
  - operation:裁剪, crop
  - object:八重对称纹理, eightfold_texture
  - object:偏离像素, deviant_pixel
  - relation:八重对称轨道, eightfold_orbit
  - relation:基本域折叠, fundamental_domain_fold
  - condition:轨道多数表决, orbit_majority_vote
- 参考题号: 929ab4e9 (1)、72322fa7 (17)、b94a9452 (18)

### docstring

```text
在近似八重对称的方形图案中检出破坏对称的像素，并把它们折叠回同一个八分之一基本域，拼出隐藏精灵后裁剪输出。

输入结构
- 方形网格铺满多色纹理，绝大多数像素在正方形的八重对称群（四个旋转与四条镜像）下保持一致。
- 每个对称轨道至多有一个像素偏离该轨道的多数色；异常像素散布在全网格的任意轨道成员位置上，原位看不出任何形状。
- 不存在专用的"异常色"：偏离像素使用的颜色同样大量出现在正常纹理中，无法按颜色筛选。

规则
- 对每个格子取其八重对称轨道，以轨道内的多数色为正常色，收集所有与正常色不同的格子。
- 对每个异常格施加群中唯一能把它映入左上八分之一基本楔形（先镜像折入左上象限、再沿主对角线折入其上三角）的对称变换，得到规范位置。
- 异常格保留自身颜色落到规范位置上，输出这些规范位置的最小包围盒裁剪，其余填黑。

关键洞察
- 对称既是显影液又是折叠指令：异常像素在原位是无意义的散点（检出后直接裁剪是第一个死胡同），真正的精灵被对称群"打散"到各轨道成员上，只有把每个异常折回基本域才能重组出它；而由于异常色混在正常纹理色中，检出这一步也只能靠逐轨道多数表决。
```

## 2. 自解码指令带

- tags:
  - operation:路径追踪, path_follow
  - operation:外推, extrapolate
  - operation:映射反解, mapping_decode
  - object:指令带, instruction_strip
  - object:已执行轨迹, executed_trail
  - relation:前缀对齐, prefix_alignment
  - condition:前缀覆盖全部指令色, prefix_covers_all_codes
- 参考题号: 90f3ed37 (3)、9ba4a9aa (2)、ba1aa698 (12)

### docstring

```text
用画布上已执行的一段路径破译顶部彩色指令带的颜色-方向对应，再把剩余指令走完。

输入结构
- 网格顶部以一条分隔行隔出水平指令带：一串彩色单元格，颜色取自三到四种。
- 主区有一个起点像素（独有颜色）和一条从它出发的已画轨迹；轨迹长度恰好覆盖指令带的前若干条指令，第 k 步的移动方向对应带上第 k 格的颜色。
- 每种指令颜色在已执行前缀中至少出现一次，保证映射可被唯一反解。

规则
- 将已画轨迹的逐步方向与指令带前缀逐格对齐，反解出颜色到方向的映射。
- 从轨迹末端继续，按带上剩余颜色逐格移动，每步用轨迹色画一格。
- 输出补完整条路径后的网格，指令带与分隔行保持不变。

关键洞察
- 颜色与方向的密码本不在题面上，而藏在"已执行前缀"里：画好的路径是指令带的部分执行结果，必须先把它当作对照样本反解出映射，再外推剩余部分——前缀既是示例又是钥匙，且各示例间的映射可以不同，不能背表。
```

## 3. 生长的下一帧

- tags:
  - operation:外推, extrapolate
  - operation:生长, grow
  - object:帧序列, frame_sequence
  - object:种子行, seed_row
  - relation:相邻间隔繁殖, adjacent_gap_reproduce
  - condition:交替变色, alternating_color
  - condition:过程推进而非平移, process_step_not_translation
- 参考题号: ba1aa698 (12)、af726779 (8)

### docstring

```text
把横向排列的面板识别为间隔生长过程的连续时间帧，推演生长一代并输出下一帧。

输入结构
- 网格由共享竖直边框的等宽面板横向排列而成，各面板背景与边框相同。
- 第一块面板只有一条水平橙色种子行；此后每块面板比前一块多一代生长痕迹：在当前代下方两行处，凡当前代中"活跃-背景-活跃"三元组的中点生成一个子像素，代色在粉/橙之间交替，已有痕迹全部保留。
- 相邻两帧恰好相差一代。

规则
- 对比相邻面板的差异，归纳出三元组繁殖规律与颜色交替规律。
- 输出一块与单个面板同尺寸的独立面板（四周完整边框），内容为在最后一帧基础上再生长一代；若无子可生，则新一代为空、其余照抄。

关键洞察
- 前两帧的差异极易被读成"整行下移/复制"，但后续帧在连续段处不繁殖、在间隔处繁殖，暴露出这是元胞式生长的时间序列；答案是把过程推进一步，而不是对图形做平移或缩放外推。
```

## 4. 锚点之像

- tags:
  - operation:印章覆盖, stamp_overlay
  - operation:对称变换, symmetry_transform
  - object:分隔网格, separator_grid
  - object:模板图块, template_tile
  - object:锚点像素, anchor_pixel
  - relation:标记为锚点之像, marker_is_anchor_image
  - condition:轨道位置定唯一变换, orbit_position_determines_transform
- 参考题号: e734a0e8 (9)、929ab4e9 (1)、8a004b2b (13)

### docstring

```text
把模板图块盖到每个被标记的图块里，变换方式由标记像素落在模板锚点对称轨道的哪个位置决定。

输入结构
- 分隔色的整行整列把网格划成等大的方形图块。
- 恰有一个图块画着多色不对称精灵，其中含一个独有锚点色像素；锚点不在图块中心，也不在任何对称轴上，故其八重对称轨道有八个互异位置。
- 部分空白图块各含一个锚点色的单像素标记，其在图块局部坐标系中的位置恰为锚点轨道中的某一点；其余图块全空。

规则
- 对每个带标记的图块，找出正方形八种对称变换中把模板锚点映到标记位置的唯一一种。
- 用该变换作用于整块模板精灵后盖入该图块，锚点像素随变换正好落在标记处。
- 全空图块与分隔线保持不变。

关键洞察
- 标记不只是"要盖章"的开关，它是锚点在未知变换下的像：单个像素的位置就完整编码了旋转与镜像方式，原样盖章只会在恰为恒等变换的图块上碰对，其余图块必须先由标记位置反解变换再落章。
```

## 5. 钥匙与锁孔

- tags:
  - operation:填充, fill
  - operation:射线延伸, ray_extend
  - object:缺口矩形框, one_gap_rect_frame
  - object:钥匙像素, key_pixel
  - relation:视线匹配, sightline_matching
  - relation:全局一一配对, global_bijective_assignment
  - condition:精确对准缺口, exact_gap_alignment
- 参考题号: 292dd178 (16)、696d4842 (14)

### docstring

```text
每把钥匙像素沿直线视线穿过全局唯一配对的框缺口进入，注入自身颜色填满框内部并留下进入通道。

输入结构
- 背景网格上有若干矩形框，每个框的边上恰缺一个非角像素作为缺口。
- 另有与框等数量的彩色单像素钥匙散布在框外；每把钥匙与某些缺口同行或同列且中间为纯背景。
- 全局恰存在一种钥匙到缺口的一一配对，使每把钥匙都沿无遮挡直线精确对准自己的缺口。

规则
- 求出唯一的一一配对：钥匙必须与缺口本身共线对准（对准框壁其他位置不算），且视线路径上没有任何前景像素。
- 把钥匙到缺口之间的背景直线段、缺口格本身以及框的整个内部全部涂成该钥匙的颜色。
- 钥匙像素保留原位原色，框壁颜色不变。

关键洞察
- 个别钥匙能看见多个缺口、个别缺口被多把钥匙看见，按最近距离的局部贪心会撞车，只有满足全局一一约束的配对成立；并且颜色是穿过缺口从外向内"灌入"的，与常见的内部向外泄漏方向恰好相反。
```

## 6. 稀疏镜面

- tags:
  - operation:稠密化, densify
  - operation:射线延伸, ray_extend
  - operation:反射, reflect
  - object:边缘光源, edge_source
  - object:稀疏斜点列, sparse_diagonal_dots
  - object:孤立干扰点, isolated_distractor
  - relation:两步点阵成镜, lattice_forms_mirror
  - condition:至少三点共线才补密, three_collinear_to_densify
- 参考题号: db615bd4 (15)、f9a67cb5 (6)、896d5239 (11)

### docstring

```text
先把两步点阵上的稀疏斜点补密成实心 45 度镜面，再让边缘光束在镜面间反射，画出完整光路。

输入结构
- 网格某条边上有一个单像素光源标记，垂直于该边向内发射直线光束。
- 场内散布若干斜向点列：同色像素隔一格排在 45 度直线上，是镜面的稀疏残迹，不同镜段之间明显分离。
- 另有少量同色孤立干扰点，不落在任何两步斜点列上。

规则
- 将每条含至少三个共线两步点的斜点列补密为连续的实心 45 度镜段（填满中间空格）。
- 光束从光源沿垂直边界方向射入，直线前进；撞上补密后的镜段像素时按 45 度镜面规则转向 90 度，继续前进，直到从网格边缘射出。
- 输出中镜段以补密后的实心形态呈现，光路经过的背景格涂成光源色，孤立干扰点原样保留。

关键洞察
- 镜子从未被完整画出：按可见像素判断碰撞会让光束从稀疏点之间的空隙"穿过去"得到错误光路；必须先识别两步点阵并补密，反射几何才成立，而孤立点因不满足三点共线既不补密也不参与反射。
```

## 7. 隐形隔板

- tags:
  - operation:因果反演, causal_inversion
  - operation:补全, complete
  - object:水源, water_source
  - object:架子, shelf
  - object:水迹, water_trail
  - relation:铺开长度编码板长, spread_length_encodes_shelf
  - condition:唯一无支撑段, unique_unsupported_run
- 参考题号: 36a08778 (19)、90f3ed37 (3)

### docstring

```text
根据瀑布留下的水迹形态，反推出被抹去的那块隔板并补画回去。

输入结构
- 网格含隔板色的若干水平隔板与水色的完整水迹；生成水迹的物理为：水从顶缘源头下落，碰到隔板沿板顶铺开到两端各多一格，再从两端悬空处继续下落，抵达底行为止。
- 其中恰有一块隔板被从画面上抹去：某段水平水迹的正下方没有任何隔板支撑。
- 其余隔板齐全，且整幅水迹与全部隔板（含被抹去的那块）的正向模拟完全一致。

规则
- 从可见的板-水对归纳出"铺开长度 = 板长 + 两端各一格"且铺开位于板顶上一行的关系。
- 找到唯一没有隔板支撑的水平铺开段，在其正下一行、两端各内缩一格的范围补画隔板色像素。
- 其余一切保持不变。

关键洞察
- 必须先从可见部分学会正向物理，才能把唯一违反支撑关系的水平段反演成隔板的行、位置与长度；直接把该水平段整段描成隔板会在两端各多出一格，而铺开与板长的偏移量只能从其他完好的板-水对中读出。
```
