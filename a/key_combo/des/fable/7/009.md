## 1. 路由框射线接力

- 参考题目题号: 5 (2f767503)、4 (f15e1fac)、11 (df8cc377)、1 (db93a21d)
- tags:
  - operation:射线延伸, ray_extend
  - operation:重涂色, recolor
  - object:标记条, marker_bar
  - object:控制像素, control_pixel
  - object:空心矩形, hollow_rect
  - object:标记像素, marker_pixel
  - relation:方位指针, direction_pointer
  - condition:入框转向换色, reroute_and_recolor

### docstring

```text
从标记条发出射线，射线每穿入一个空心框就按框内指针改向并换成框色，画出全程折线路径。

输入结构：
- 黑色背景网格上有一根三像素直条和一个紧贴条中心的控制像素，二者颜色不同。
- 另有若干互不相交的单色空心矩形框，每个框内部恰有一个非框色的标记像素，
  该像素位于框中心的正上、正下、正左或正右方，不贴框边。
- 各框颜色互不相同，射线经过的路线上框的先后顺序由几何位置唯一确定。

规则：
- 从条中心沿远离控制像素的方向发出射线，初始颜色取条的颜色，逐格在背景上着色。
- 射线命中某个框的边时停止着色，改从该框中心出发，方向改为框内标记像素
  相对框中心的方位，颜色改为该框的框色，出框之后继续在背景上逐格着色。
- 重复上述转发过程，直到射线离开网格边界；框、框内标记、条与控制像素保持原样。

关键洞察：
- 空心框既不是障碍物也不是待填充的容器，而是转发器：框内那个像素不属于任何图案，
  它是出射方向的指针；射线的颜色随所经框逐段接力，路径必须整链模拟才能得出。
```

## 2. 导线长度定嵌套

- 参考题目题号: 17 (a47bf94d)、14 (5587a8d0)、11 (df8cc377)
- tags:
  - operation:排序, sort
  - operation:同心环绘制, concentric_draw
  - operation:擦除, erase
  - object:线路网络, wire_network
  - object:连通分量, connected_component
  - object:空心矩形, hollow_rect
  - relation:路径长度排序, path_length_ordering
  - condition:线长定嵌套序, wire_length_nesting

### docstring

```text
把各团块的颜色按其导线长度从长到短填成中央空框内的嵌套方环。

输入结构：
- 背景为黑色，画面中央有一个灰色空心正方形框，框内为空。
- 框外散布若干单色实心团块，形状任意、面积互不相同。
- 每个团块经一条单像素宽的灰色折线导线与框的外沿相连，各导线互不接触且长度互不相同。
- 框内部边长恰为 2×团块数−1；团块面积的大小顺序与导线长度的顺序刻意不一致。

规则：
- 度量每条导线的像素数，把团块按导线从长到短排序。
- 在框内部画同心方环：导线最长的团块颜色占最外环，依次向内，
  导线最短的团块颜色占中心格。
- 擦除所有团块与导线，只保留灰框与框内新图案。

关键洞察：
- 嵌套次序既不由团块面积决定，也不由团块到框的直线远近决定；
  唯一的排序键是导线这条弯路本身的长度，面积与直线距离都是诱饵。
```

## 3. 湮灭队列

- 参考题目题号: 3 (182e5d0f)、7 (494ef9d7)
- tags:
  - operation:滑动, slide
  - operation:擦除, erase
  - operation:分类, classify
  - object:路径, path
  - object:门结构, gate_motif
  - object:标记像素, marker_pixel
  - relation:顺序配对湮灭, sequential_pair_annihilation
  - condition:标记类型定门行为, marker_type_gate_behavior
  - condition:门前停止, stop_at_gate

### docstring

```text
让路径上的一串标记依次向前滑动：灰标记与所遇的门同归于尽，橙标记被门挡住并使后队跟停。

输入结构：
- 背景为黑色，一条单像素宽的绿色折线路径从网格一端延伸到另一端。
- 路径靠起点的一段上坐着若干标记像素，颜色为灰或橙，彼此之间可有空档。
- 路径沿途有若干门：门位于路径像素上，其垂直两侧各有一个红色端像素。

规则：
- 标记按离门较近者先行的顺序逐个沿路径向前滑动，滑动中不越过前方标记。
- 灰标记滑到最近的未消之门的门位时，该门的两个红端与该灰标记一同消失，
  路径该处恢复通行，轮到下一个标记前进。
- 橙标记滑到最近未消之门前的路径格停下；其后方所有标记依次紧贴排队停下，不再前进。
- 若所有门都已被消掉，剩余标记滑到路径末端依次紧贴停靠。
- 输出保留绿色路径、幸存的门与所有停下的标记。

关键洞察：
- 门不是固定的墙：它对灰标记是可被消耗的一次性关卡，对橙标记才是真正的墙；
  最终画面由"灰-门逐对湮灭、橙触发全队冻结"这条链式过程决定，
  任何一个标记的落点都依赖它前方整段队列的历史。
```

## 4. 取向试配入槽

  - operation:擦除, erase
  - object:框架槽, frame_slot
  - object:精灵体, sprite

  - condition:唯一取向贴合, unique_orientation_fit
  - condition:忽略干扰项, ignore_distractors

### docstring

```text
为每个槽找出经旋转或镜像后能与其槽底地形无缝互补的零件并嵌入，多余零件原地保留。

输入结构：
- 画面中有两个由灰色矩形框围出的槽，槽底边内侧长着高低不一的灰色柱状地形，
  两槽地形互不相同。
- 框外散布三个多色小零件，形状互不相同且都不具有旋转或镜像对称。
- 每个槽恰有一个零件存在某个旋转或镜像取向能与其地形完全互补，
  且两槽匹配的零件不同，剩余一个零件与任何槽都配不上。

规则：
- 对每个槽，枚举各零件的全部旋转与镜像取向，找出能水平放入槽内、
  与地形逐列相接、既无缝隙也无重叠的唯一组合（零件、取向、水平位置）。
- 把匹配零件以该取向嵌入对应槽中的贴合位置，并擦除它在框外的原件。
- 未被任何槽选中的零件与两个槽的框、地形保持原样。

关键洞察：
- 钥匙从不以画面上的原始朝向示人：逐列高度剖面要在想象中翻转旋转之后才对得上；
  配对是槽与零件之间的双向选择，剩下的那个零件是配不上任何锁的诱饵。
```

## 5. 隐形矩形的压叠碎片

- 参考题目题号: 4 (f15e1fac)、16 (070dd51e)、14 (5587a8d0)、13 (e760a62e)
- tags:
  - operation:填充, fill
  - operation:擦除, erase
  - object:边缘起点像素, edge_source_pixel
  - object:矩形, rectangle
  - relation:同色配对, same_color_pairing
  - relation:面积排序, area_ordering
  - condition:投影重建矩形, projections_define_rect
  - condition:重叠区取上层色, overlap_takes_upper_color

### docstring

```text
只画出由边缘影段暗示的隐形矩形两两压叠的重叠区，重叠区取面积较小矩形的颜色。

输入结构：
- 黑色背景网格的四条边上贴着若干彩色线段（影段），网格内部完全为空。
- 每种颜色恰好出现两段：一段在水平边（上边或下边），一段在竖直边（左边或右边）。
- 同色两段分别给出一个矩形的列跨度与行跨度，该矩形完整落在网格内部且从未被画出；
  各矩形面积互不相同。

规则：
- 对每种颜色，由其竖直边影段的行跨度与水平边影段的列跨度确定一个隐形矩形。
- 对每一对隐形矩形求重叠区域；若非空，则在输出中把该区域填成
  两者中面积较小的矩形的颜色。
- 输出与输入同尺寸，除这些重叠区外全部为黑色；四边影段一并擦除，矩形本身不画。

关键洞察：
- 边上的线段不是待操作的对象，而是画面中从未出现过的矩形在两条边上的投影；
  输出里看不到任何一个完整矩形，只看得到它们互相压叠时露出的上层碎片——
  谁在上层由面积小者浮在上的层序决定，与影段长短、绘制顺序都无关。
```

## 6. 朝向投票定轴补全

- 参考题目题号: 2 (1d61978c)、10 (11852cab)、18 (0e206a2e)
- tags:
  - operation:对称补全, symmetry_completion
  - operation:镜像, mirror
  - operation:分类, classify
  - operation:擦除, erase
  - object:对角线段, diagonal_bar
  - object:前景对象, foreground_object
  - relation:对角朝向, diagonal_orientation
  - condition:多数朝向定轴向, majority_orient_axis
  - condition:最长线段定轴位, longest_bar_axis_position

### docstring

```text
以多数朝向中最长的对角线段所在直线为镜轴，补全残缺对象并清除所有线段。

输入结构：
- 黑色背景上有一个较大的多色对象，其一部分被抹成背景色而残缺。
- 画面其余处散布若干单像素宽的对角短线段，分属主对角与反对角两种朝向。
- 对象现存像素与不止一条对角直线的镜像局部一致，仅凭对象自身无法确定轴；
  多数朝向中最长的那条线段所延伸的对角直线穿过对象，是唯一能给出
  完整一致补全的镜轴。

规则：
- 按像素数统计两种对角朝向的多寡，取多数朝向；在该朝向的线段中找出最长的一条。
- 把这条线段延长成贯穿网格的对角直线作为镜轴，将对象每个现存像素镜像到轴另一侧，
  为背景色的对应位置补上该像素的颜色。
- 擦除所有散布的对角线段，输出只保留补全后的对象。

关键洞察：
- 散布线段不是待重涂的图形，而是一张选票加一把钥匙：朝向多数先选出轴的方向，
  该朝向内的最长者再给出轴的位置——全局最长的线段可能属于少数朝向，是诱饵；
  补全用的是斜镜像，而不是看似同样吻合的旋转对称或正交镜像。
```
