## 1. 位置图例指挥旋转与染色

- 参考题目题号：1（1da012fc）、3（73ccf9c2）、11（edb79dae）
- tags:
  - operation:旋转, rotate
  - operation:重涂色, recolor
  - object:图例矩形, legend_rectangle
  - object:占位形状, placeholder_shape
  - object:非对称尖端, asymmetric_tip
  - relation:相对位置对应, relative_position_correspondence
  - condition:朝向差决定旋转, orientation_difference_rotation

### docstring

```text
按相对位置布局将各占位形状与图例标记配对，再把每个形状旋转到尖端指向其标记的方位并染成标记色。

输入结构：
- 背景为占优色；一个灰色实心矩形图例内嵌若干彩色单像素标记，每个标记恰位于
  图例中心的正上、正下、正左或正右方向上。
- 图例外散布同样数量的橙色占位形状——全部同色，无法靠颜色配对。
- 每个形状的紧致包围框为正方形，带唯一单像素"尖端"突出于主体，
  其四个旋转姿态互不相同。

规则：
- 把全部占位形状的整体包围框视为布局图，把图例包围框视为标记布局图，
  按包围框内相对位置的唯一最小总距离将形状与标记一一配对。
- 每个形状绕自身包围框中心旋转，使尖端指向其配对标记相对图例中心的方位。
- 将旋转后的形状整体染成配对标记的颜色，写回原包围框位置；图例与背景不变。

关键洞察：
- 图例是双重指令——标记的相对位置决定"谁配谁"（形状全同色，配对只能靠
  布局对应），标记的方位决定"转到哪"，标记的颜色决定"染成什么"。
- 旋转量不是固定码表，而是形状自身当前朝向（由尖端读出）与标记方位之差。
```

## 2. 遮挡轨迹的动力学复原

- 参考题目题号：2（2dd70a9a）、18（f9012d9b）
- tags:
  - operation:补全, reconstruct
  - operation:寻路, pathfinding
  - object:遮挡矩形, occluding_rect
  - object:障碍像素, barrier_pixel
  - object:路径, path
  - condition:运动学衔接, kinematic_join
  - condition:因果反演, causal_inversion

### docstring

```text
用路径的运动规律重建被灰色矩形遮住的路径段，并反推出被遮住的转向障碍像素。

输入结构：
- 黑色背景上散布青色障碍像素。
- 一条绿色路径从绿色起点短线延伸至红色终点短线，路径遵循"直行、且仅在
  下一格为青色障碍时转向"的运动规律。
- 一个灰色实心矩形遮住路径中间一段，连同该段范围内触发转向的障碍像素；
  矩形之外的路径与障碍完整可见。

规则：
- 读取路径进入矩形处的位置与方向、离开矩形处的位置与方向。
- 若两方向相同，遮挡段为直线段；若两方向垂直，遮挡段恰含一次转向，
  转折点为入口射线与出口射线的唯一交点。
- 将灰色矩形区域还原为黑背景，画回绿色路径段，并在转折点沿入口方向的
  下一格补回一枚青色障碍像素。

关键洞察：
- 遮挡区不靠对称或复制恢复，而靠路径运动学衔接入口与出口。
- 必须反推出画面上从未出现的"因"——触发转向的障碍像素：
  轨迹是果，障碍是因，本题要求由果溯因。
```

## 3. 锚点对齐后的对称差

- 参考题目题号：4（31d5ba1a）、1（1da012fc）
- tags:
  - operation:异或合成, xor_compositing
  - operation:平移对齐, translate_align
  - object:锚点像素, anchor_pixel
  - object:半区掩码, half_mask
  - relation:锚点对应, anchor_correspondence
  - condition:恰一为前景, exactly_one_foreground

### docstring

```text
以两半区各自唯一的黄色锚点对齐后再取前景对称差，恰一为前景处涂粉色。

输入结构：
- 一条灰色分隔线把网格分成上下两个同尺寸区域，共享同一背景色。
- 每个区域含一个唯一的黄色锚点像素和一种自己的前景色图案，
  黄色只作锚点使用，不属于图案内容。

规则：
- 平移下区使两黄色锚点重合，以上区坐标系为准。
- 输出与单个区域同尺寸：对齐后恰有一个区域为前景的位置涂粉色。
- 两者同为前景、同为背景、锚点重合处、以及下区未覆盖到的位置
  一律输出背景色。

关键洞察：
- 两半区不能按原始位置逐格比较——黄色像素不是图案内容而是坐标原点，
  必须先对齐锚点再做对称差。
- 个别示例中锚点恰好同位，直接逐格异或看似成立（诱饵），
  但推广到其余示例即失败。
```

## 4. 同色矩形传送门

- 参考题目题号：2（2dd70a9a）、5（d6e50e54）、11（edb79dae）
- tags:
  - operation:射线延伸, ray_extend
  - object:传送门矩形对, portal_rectangle_pair
  - object:起点短线, start_marker
  - relation:颜色配对, color_pairing
  - relation:边上偏移保持, edge_offset_preserved
  - condition:对侧射出, opposite_side_exit

### docstring

```text
绿色射线在成对同色矩形之间传送穿行，画出画布上全部轨迹段。

输入结构：
- 背景上有若干实心矩形，按颜色恰两两成对，同色矩形尺寸相同。
- 一条绿色两像素短线给出射线的起点与初始方向。
- 射线每次都会击中某矩形的一条边或飞出画布。

规则：
- 射线沿方向直行，在背景上留下绿色轨迹。
- 当射线撞到某矩形边上某一格时，找到其同色配对矩形，从配对矩形的对侧边、
  距边端点相同偏移的格子处，以原方向射出并继续直行，矩形内部不画。
- 射线飞出画布时结束；输出为原图加上全部绿色轨迹段。

关键洞察：
- 矩形不是障碍而是成对的传送门；出口由"颜色配对 + 入口在边上的相对偏移 +
  对侧射出"三层规则共同决定。
- 轨迹在画布上呈现为若干不连续的共线段，其衔接关系从未被画出，
  须由解题者自行接续。
```

## 5. 槽位变换求根

- 参考题目题号：20（8e5a5113）、16（67e8384a）
- tags:
  - operation:旋转, rotate
  - operation:镜像, mirror
  - object:分隔线, divider_line
  - object:槽位, slot
  - relation:变换幂次, transform_power
  - condition:反解生成元, solve_generator

### docstring

```text
由两个相隔 k 格的已填槽位反解出逐槽恒定变换，再补全整行槽位。

输入结构：
- 灰色分隔线把网格分成一行 N 个同尺寸方形槽位。
- 恰有两个槽位（不一定相邻）画有同一图案的不同姿态，其余槽位为空背景。
- 相邻槽位之间恒定施加同一未知变换 T，T 取自
  {顺时针90°、旋转180°、左右镜像、上下镜像}；图案无任何自对称，保证解唯一。

规则：
- 设两个已填槽位相隔 k 步，在候选集中找出唯一使 T 连续作用 k 次
  能把左侧图案变为右侧图案的 T。
- 从已知槽位出发向两侧施加 T 或其逆，填满所有槽位。

关键洞察：
- 给定的不是相邻样本对，必须解"T 的 k 次幂等于观测到的变换"这一方程。
- 例如相隔两步观测到 180° 旋转时，生成元只能是 90° 旋转而不是 180° 本身，
  因为 180° 施加两次是恒等，与观测矛盾。
```

## 6. 双异类辨析与共识修复

- 参考题目题号：3（73ccf9c2）、18（f9012d9b）、12（98c475bf）
- tags:
  - operation:补全, reconstruct
  - operation:对称检测, symmetry_detect
  - object:精灵副本, sprite_copies
  - relation:镜像等价类, mirror_equivalence
  - condition:共识修复, consensus_repair
  - condition:双异类辨析, dual_outlier_discrimination

### docstring

```text
在多份同形异色的精灵副本中区分合法的镜像副本与真正缺损的副本，
并用共识形状修复后者。

输入结构：
- 背景上散布同一精灵的若干平移副本，各副本颜色互不相同、互不接触。
- 精灵形状左右不对称。
- 其中恰有一个副本以左右镜像姿态完整放置，另恰有一个副本缺失了
  若干像素（变为背景色）。

规则：
- 对每个副本取紧致包围框掩码，在允许左右镜像的等价意义下与其余副本比对，
  得到共识形状。
- 与共识或其镜像完全一致的副本保持不变。
- 唯一与两者都不一致的副本为缺损副本：选择使缺失像素数最少的姿态
  （正或镜像，输入保证唯一），在其原位置按其自身颜色补齐缺失像素。
- 输出为整幅网格，仅缺损处被填补。

关键洞察：
- 画面里有两个"异类"，但只有一个需要修复——镜像是合法变换而缺损不是。
- 共识必须在镜像等价类下建立，否则会把完好的镜像副本错当损坏来修。
```

## 7. 多孔沉淀分层

- 参考题目题号：15（dce56571）、8（e7a25a18）
- tags:
  - operation:计数, counting
  - operation:填充, fill
  - object:空心容器, hollow_container
  - object:多孔对象, porous_object
  - relation:孔洞数定序, hole_count_ordering
  - condition:面积定层厚, area_layer_thickness

### docstring

```text
把散乱的多孔彩色对象熔入空心容器，孔洞数决定浮沉层序，实心面积决定层厚。

输入结构：
- 背景上有一个空心矩形容器（单色边框、内部为背景）和若干互不接触的
  彩色连通对象，颜色互不相同。
- 每个对象内部封闭着若干背景色孔洞，各对象孔洞数互不相同。
- 每个对象的实心像素数（不含孔洞）恰为容器内部宽度的整数倍，
  全部对象实心像素总数恰好填满容器内部。

规则：
- 清除容器外所有对象。
- 在容器内部自底向上逐层填充纯色横行：孔洞最少的颜色沉在最底层，
  孔洞越多的颜色越靠上。
- 每种颜色占据的整行数等于该颜色实心面积除以容器内部宽度；
  容器边框保持不变。

关键洞察：
- 对象的形状与画面位置无关，它们只是颜色计量；但层厚与层序来自两个
  不同的量——厚度由实心面积决定，浮沉次序由孔洞数决定（孔多者轻、浮于上层）。
- 部分示例中面积序恰与孔洞序一致，是为诱饵；只有孔洞计数在全部示例下成立。
```

## 8. 藏在自身内部的缩略图

- 参考题目题号：17（e57337a4）、7（2c0b0aff）、10（f25fbde4）
- tags:
  - operation:压缩, compress
  - operation:裁剪, crop
  - object:粗粒度块, coarse_block
  - object:标记像素, marker_pixel
  - relation:整体局部自指, whole_part_self_reference
  - condition:缩略图匹配, thumbnail_match

### docstring

```text
找出恰好等于整幅网格压缩缩略码的那个块并裁剪输出。

输入结构：
- 9×9 网格可均分为 9 个 3×3 块。
- 网格只含唯一的占优填充色与唯一的稀疏标记色；各块为纯填充色或在
  填充色上散布标记色像素。

规则：
- 按"块内含标记色像素则记标记色，否则记填充色"将整幅网格压缩为
  一个 3×3 码。
- 恰有一个块的内容逐格等于该码，将该块裁剪为 3×3 输出。

关键洞察：
- 目标块不靠位置、对称或计数选出，而是"整体的缩略图藏在自身内部"——
  必须先做全图压缩才能识别它。
- 缩略块本身也参与压缩（它含标记像素与否会反馈进码中对应的一格），
  整体与局部构成自洽的不动点。
```
