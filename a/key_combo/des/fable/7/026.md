## 1. 接力码表·旋转识别

- tags:
  - operation:符号解码, symbol_decoding
  - operation:重涂色, recolor
  - operation:擦除, erase
  - object:符号掩码, symbol_mask
  - object:图例配对, legend_pair
  - relation:相邻定义映射, adjacency_defines_mapping
  - relation:同义词跳转链, synonym_chain
  - relation:旋转等价, rotation_equivalence
  - condition:码表来自图内, in_grid_codebook
- 参考题目: `17cae0c1`, `50aad11f`, `1e5d6875`

### docstring

```text
在图内现场学习"字形接力码表"：孤立字形先按旋转等价匹配图例字形，再沿同义词链传递到末端色块取色。

输入结构：
- 黑色背景。前景为三乘三区块：灰色字形掩码与纯色实心方块。
- 图例对有两种：定义对（字形右邻一个纯色方块）与同义词对（字形右邻另一个字形）。
- 作业区是孤立出现的字形，可能是图例中某字形旋转九十、一百八十或二百七十度后的形态。
- 所有图例字形在旋转等价意义下互不相同，且均无旋转对称；同义词链最终都通向某个定义对。

规则：
- 由定义对建立"字形到颜色"的直接映射；由同义词对建立"字形到字形"的跳转。
- 每个孤立字形按旋转等价找到匹配的图例字形；若它只有同义词跳转，则继续沿链走到拥有定义的字形，取其颜色。
- 将孤立字形所在区块整体替换为该颜色的实心方块；所有图例对擦除为背景。

关键洞察：
- 码表不是先验固定的，而是图内相邻关系现场定义的；匹配必须在旋转等价下进行；
  且映射可能是间接的——需要发现"字形右邻字形"是改写跳转而非另一种图案，沿链传递才能取到颜色。
```

## 2. 破口容器泄漏

- tags:
  - operation:平移, translate
  - operation:擦除, erase
  - object:带缺口容器, gapped_container
  - object:珠串, bead_sequence
  - relation:缺口定向, gap_orientation
  - relation:顺序保持压紧, order_preserving_compaction
  - condition:容量决定滞留, capacity_caps_leak
- 参考题目: `271d71e2`, `256b0a75`, `ef135b50`, `52364a65`

### docstring

```text
让每个容器内的彩珠沿墙上唯一缺口滑出，在外侧障碍前压紧堆叠，装不下的彩珠滞留在容器内贴紧缺口。

输入结构：
- 背景为最多色。若干灰色空心矩形容器，每个容器恰有一面墙缺一个单格缺口。
- 容器内部沿缺口所在的行或列排着一串彩色像素（可有空隙，颜色可不同），内部其余为空。
- 缺口向外的直线路径上没有其他彩色像素，终止于网格边缘或另一容器的外壁；各容器的泄漏路径互不相交。

规则：
- 每个容器的彩珠沿缺口方向依次滑出：离缺口近者先出、走得最远，全部紧贴外侧障碍压紧成连续一段，颜色顺序保持不反转。
- 缺口外可用格数不足时，多出的彩珠留在容器内，贴着缺口一侧压紧排列，顺序同样保持。
- 容器壁与缺口保持原样，容器内其余格清空为背景。

关键洞察：
- 缺口是唯一的"重力"方向指示；彩珠像串珠一样滑动，压紧后次序保持而非反转；
  外侧空间是容量上限，决定哪些珠子泄出、哪些滞留，两段都要按同一顺序压紧。
```

## 3. 面积定长射线

- tags:
  - operation:射线延伸, ray_extension
  - operation:擦除, erase
  - object:边缘标记, edge_marker
  - object:实心对象, solid_object
  - relation:同色配对, color_pairing
  - relation:面积迁移为长度, area_as_length
  - condition:交点大者覆盖, larger_area_wins_crossing
- 参考题目: `256b0a75`, `ea32f347`, `6df30ad6`, `d4a91cb9`

### docstring

```text
把每个内部实心对象的面积转写成同色边缘标记射线的长度，交叉处由面积更大的一方覆盖。

输入结构：
- 黑色背景。网格四条边上贴边分布着若干单像素彩色标记，每种颜色恰一个。
- 网格内部漂浮着与标记同色的实心单色对象，每色恰一个，面积两两不同。

规则：
- 擦除所有漂浮对象。
- 每个边缘标记向网格内部垂直发射一条同色射线，长度等于其同色对象的像素数（不含标记本身）。
- 若两条射线交叉，交叉格涂对应对象面积较大一方的颜色。

关键洞察：
- 漂浮对象不是被操作的图形而是刻度：它的面积是另一处射线的长度参数；
  同一个面积量被复用两次——先定长度，再在交点处裁决覆盖优先级。
```

## 4. 空白十字折叠与橡皮象限

- tags:
  - operation:镜像, reflect
  - operation:裁剪, crop
  - operation:擦除, erase
  - object:全空行列, fully_blank_row_column
  - object:象限碎片, quadrant_fragment
  - object:负片象限, eraser_quadrant
  - relation:折痕对齐, fold_alignment
  - condition:取最大象限, largest_quadrant_canvas
  - condition:单色象限做减法, monochrome_quadrant_subtracts
- 参考题目: `c1d99e64`, `996ec1f3`, `f8a8fe49`, `8618d23e`

### docstring

```text
以空白行列为折痕把四个大小不等的象限折叠到最大象限上，其中红色象限折上来的不是图案而是橡皮擦。

输入结构：
- 网格恰有一个全为背景色的行和一个全为背景色的列，构成空白十字，把网格分成四个大小互不相同的象限。
- 三个象限持有同一幅多色图案的互补碎片（折叠对齐后每格前景至多来自其中一个象限）。
- 余下一个象限的前景全部是红色，红色不出现在其他象限。

规则：
- 以空白行、空白列为折痕，把其余三个象限镜像翻折到行列两方向都较大的那个象限上。
- 先取三个图案象限各层前景的并集，得到拼合图案。
- 再把红色象限折上来的红色格作为橡皮：拼合图案中与之重合的格擦除为背景。
- 输出为最大象限尺寸的网格。

关键洞察：
- 空白十字不是缺线也不是分隔符而是折痕；象限大小不等使平移拼接必然错位，只有镜像折叠能对齐；
  且四个象限并非同质——红色象限是负片，它折上来的内容做减法而非加法。
```

## 5. 针孔倒像

- tags:
  - operation:点对称投影, point_reflection
  - operation:重涂色, recolor
  - operation:擦除, erase
  - object:墙线段, wall_segment
  - object:针孔缺口, pinhole_gap
  - object:标记像素, marker_pixel
  - relation:隔孔三点共线, collinear_through_pinhole
  - condition:标记为倒像种子, marker_seeds_image
- 参考题目: `6df30ad6`, `d4a91cb9`, `f8a8fe49`, `ddf7fa4f`

### docstring

```text
每个灰色对象透过墙上的针孔缺口在另一侧成点对称倒像，倒像颜色取自与对象隔孔共线的标记。

输入结构：
- 黑色背景。若干棕色直墙线段，每条墙上恰有一个单格缺口（针孔）。
- 每个针孔一侧有一个灰色四连通对象，另一侧有一个彩色单像素标记；对象的某个像素、针孔、标记三点共线，且标记恰位于该像素关于针孔的点对称位置上。
- 不同针孔的成像区域互不重叠，倒像不越出网格。

规则：
- 对每个针孔，将其同侧灰对象的每个像素以针孔格为中心做点对称，映到墙另一侧。
- 在映射位置画出整个倒像，颜色用该针孔配对标记的颜色；标记本身恰是倒像的一个像素，被倒像吸收。
- 原灰对象与墙保持不变，针孔保持为背景。

关键洞察：
- 诱饵是把对象平移或镜像复制到墙另一侧；实际是小孔成像——以缺口为中心的点对称（旋转一百八十度）倒像；
  标记不是要寻找的目标而是倒像的一个种子像素，它同时给出配对关系与倒像颜色。
```

## 6. 地线重力与消行

- tags:
  - operation:滑动, shift
  - operation:擦除, erase
  - object:满行地线, full_line_ground
  - object:悬浮块, floating_block
  - relation:重力朝向地线, gravity_toward_ground
  - condition:满行连锁消除, full_line_clear_cascade
- 参考题目: `984d8a3e`, `c1d99e64`, `52364a65`, `ef135b50`

### docstring

```text
让悬浮块朝满线地面下落堆叠，随后连锁消除所有被填满的平行层。

输入结构：
- 网格的某一条边上有一条贯穿整边的单色地线（满行或满列），其颜色仅此一处出现。
- 网格其余部分散布若干彩色实心块，任意两块在垂直于重力方向上不共享行或列。
- 靠近地线处可能已有堆叠的前景。

规则：
- 重力方向指向地线：所有悬浮块沿该方向平移，直到碰到地线、已有前景或已落定的块。
- 落定后，检查平行于地线的每一层：被前景完全填满的层整层消除，地线与该层之间不动、外侧所有前景向地线方向整体移一层；连锁进行直到没有满层。
- 地线保持不变。

关键洞察：
- 满线不是待补的缺线而是地面，它同时给出重力方向；
  只做重力是诱饵解——落定后还要按"满层消除并连锁下移"重写画面才是完整规则。
```
