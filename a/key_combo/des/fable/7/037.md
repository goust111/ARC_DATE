## 1. 隐形投影的交点

- tags:
  - operation:射线延伸, ray_extend
  - operation:交点检测, intersection_detection
  - object:标记像素, marker_pixel
  - relation:投射到最近边界, projection_to_nearest_edge
  - relation:跨源相交, cross_source_intersection
  - condition:距离近者定色, nearer_marker_colors
- 参考题目题号: 705a3229, 67a423a3, 0b17323b

### docstring

```text
一句话总述
只把各标记那两条从未画出的"最近边界L射线"彼此交叉的格子涂上颜色，颜色取离交点更近的那枚标记。

输入结构
- 黑色背景上散布若干彩色单像素标记，互不相邻。
- 每枚标记到上下两边界距离不等、到左右两边界距离不等；任意交点到两枚相关标记的
  曼哈顿距离也不相等（全程无平局）。

规则
- 为每枚标记设想两条射线：沿所在列伸向较近的水平边界，沿所在行伸向较近的垂直边界；
  这些射线不画进输出。
- 若一枚标记的竖向射线与另一枚标记的横向射线在某格相遇（该格同时落在两条射线的
  区间内），此格为交点；标记自己的两条射线交于自身，不计。
- 复制输入，把每个交点涂成与它曼哈顿距离较近的那枚标记的颜色。

关键洞察
参与规则的射线在画面上从不存在，画面只有生成元；必须在脑中按"最近边界"为每枚标记
投射一个L，两枚标记的隐形笔画交叉之处才是唯一要落笔的地方。第一眼容易误读成
"连接标记对"，但连线解释不了交点的位置与颜色归属。
```

## 2. 线段名册的排班

- tags:
  - operation:排序, sorting
  - operation:计数, counting
  - operation:填充, fill
  - object:线段对象, line_object
  - object:分隔行, separator_row
  - relation:最高行决定序, topmost_determines
  - condition:长度决定份额, length_maps_count
  - condition:分隔下循环填充, below_separator_cycle_fill
- 参考题目题号: 668eec9a, bd4472b8, e048c9ed

### docstring

```text
一句话总述
把分隔行上方的彩色线段编成一份"顺序×份额"的颜色日程，循环逐行填满分隔行下方。

输入结构
- 一条全灰行把网格分为上下两区，下区全为背景。
- 上区背景上有若干互不同色、一格宽的线段（横、竖或斜向），各线段的最高行互不相同；
  线段从左到右的排列顺序与其垂直顺序故意不一致。

规则
- 按每种颜色线段的最高行从上到下确定颜色顺序。
- 每种颜色在日程中连续占据的行数等于该线段的格数。
- 复制输入；从分隔行下第一行开始逐行按日程涂满整行，日程走完则从头循环，
  直到网格底边。

关键洞察
上区不是要保留的图案，而是一份带权名册：垂直位置给出顺序，长度给出份额；
从左到右的排列是诱饵，真正的排序键是最高行，真正的重复数藏在线段的格数里。
```

## 3. 碾痕之下的花纹

- tags:
  - operation:滑动, slide
  - operation:补全, inpaint
  - operation:擦除, erase
  - object:可移动对象, movable_object
  - object:残迹条带, trail_band
  - object:周期底纹, periodic_ground_pattern
  - relation:截面匹配, cross_section_match
  - condition:因果反演, causal_inversion
  - condition:按底纹周期复原, restore_by_pattern_period
- 参考题目题号: 9b4c17c4, 7e0986d6, 2dee498d

### docstring

```text
一句话总述
画面是滑动结束后的终局：把每个滑块沿真实碾痕移回出发端，并把一切灰格
（碾痕、噪声、滑块腾出的位置）按底面周期花纹复原。

输入结构
- 整幅底面是一张双色周期花纹（条纹或棋盘式），其上压着若干实心彩色矩形滑块。
- 每个滑块恰有一条灰色条带与其一侧四邻接：条带截面宽度与滑块完全相同，
  沿滑动轴连续延伸——那是滑块滑过时碾掉花纹留下的痕。
- 另有零散灰斑：或不与任何滑块相接，或截面宽度与所接滑块不符。

规则
- 对每个滑块，找出与其四邻接且截面等宽对齐的灰色条带，认作碾痕。
- 把滑块沿碾痕方向平移碾痕的长度，即回到碾痕远端的出发位置。
- 随后把碾痕格、滑块腾出的格子以及所有零散灰斑，一律按底面花纹在该处
  应有的颜色复原。

关键洞察
灰色不是对象，而是"信息被抹掉的地方"：碾痕的形状告诉你滑块从哪里来，
花纹的周期告诉你被抹掉之前是什么；截面等宽且相接，是碾痕区别于噪声、
从而决定滑块反演方向与距离的唯一证据。
```

## 4. 缺口朝心的装配

- tags:

  - operation:旋转, rotate
  - object:选择器块, selector_block
  - object:缺角环精灵, notched_ring_sprite
  - object:象限, quadrant
  - relation:图例位置映射, legend_position_mapping
  - relation:颜色索引匹配, color_index_matching
  - condition:缺口指向中心, notch_faces_center
- 参考题目题号: 7d18a6fb, f0f8a26d

### docstring

```text
一句话总述
按7x7选择器的象限标记把同色缺角环精灵放进对应象限，放置前旋转每个精灵，
使缺口一律落在朝向画布中心的内角。

输入结构
- 背景中有一个7x7选择器块：主体一色，四个3x3象限中心处至多各有一枚标记像素。
- 网格其他位置，每种标记色恰有一个3x3精灵：八格方环缺去一个角格，
  各精灵的缺角方向互不相同。

规则
- 输出为7x7背景画布，中间一行一列留空，形成四个3x3象限。
- 每枚标记指定一个象限；把同色精灵复制进该象限。
- 复制前将精灵旋转0/90/180/270度，使缺角格恰好位于该象限中离画布中心最近的角上。
- 无标记的象限保持背景。

关键洞察
精灵在输入中的朝向是干扰信息：朝向不从输入继承，而由装配约束统一决定——
四个缺口都要咬向共同的中心，像拼片互相扣合；只做"按位复制"会在朝向上全错。
```

## 5. 三点台球

- tags:
  - operation:外推, extrapolate
  - operation:反弹, bounce
  - object:起点标记, start_marker
  - object:落点标记, landing_markers
  - object:候选靶点, candidate_targets
  - relation:折点内嵌镜律, bend_teaches_mirror
  - relation:离散踩点命中, discrete_landing_hit
  - condition:边界镜面反射, boundary_mirror_reflection
  - condition:恰踩即止, stop_on_exact_landing
- 参考题目题号: 0b17323b, 705a3229

### docstring

```text
一句话总述
绿起点与两枚蓝落点给出一条正在反弹的跳跃轨迹；从末点按还原出的恒定步伐
继续跳跃，越界分量按镜面取反，落点涂红，直到恰好踩中某枚黄靶——
被越过而未踩中的黄点不算命中。

输入结构
- 背景网格上有一枚绿色起点、两枚蓝色后继落点，以及若干枚黄色像素。
- 三点是同一轨迹按固定步伐依次落下的连续三步：相邻两段位移或者完全相同，
  或者恰好相差一次边界反弹（某一分量取反），后一情形中中间那枚落点确实
  贴近对应边界（按原步伐再走会越界）。
- 黄色像素中恰有一枚会被某次落点恰好踩中；其余黄点或恰好躺在两次落点
  之间的连线上、或不在弹道附近，数据保证它们不会被踩中。

规则
- 以绿点到第一枚蓝点的位移为步伐向量；若第一枚蓝点到第二枚蓝点的位移
  与之不同，说明其间发生了一次镜面反弹，当前真实步伐取反弹后的那段位移。
- 从第二枚蓝点出发按当前步伐逐步跳跃；若下一步的行或列将越出网格，
  先把越界的那个分量取反再落步；两个分量都越界则都取反。
- 每个落点涂红；当某个落点恰为黄色像素时停止，该黄点保持黄色，
  其余黄点原样保留。

关键洞察
球不是沿线滑行而是离散踩点：黄点即使躺在两次落点之间的直线上也不会被
命中，只有被步伐恰好踩到的那枚才是真靶。而反弹定律并不画在画面上，
它藏在给定三点的折点里——三点恰好共线的示例是诱饵。解题者必须同时识破
"直线外推"和"连续连线"两层错觉，才能选对终点、画对轨迹。
```

## 6. 双层周期的缺块

- tags:
  - operation:平铺, tiling
  - operation:镜像, mirror
  - operation:补全, complete
  - object:瓦片, tile
  - object:姿态序列, posture_sequence
  - object:缺失块, missing_block
  - relation:周期, period
  - condition:姿态循环节外推, posture_cycle_extrapolation
- 参考题目题号: 2dee498d, bd4472b8, fd096ab6

### docstring

```text
一句话总述
网格由基准瓦片按一个循环的姿态序列水平拼成，其中一块被整块抹成背景；
联立两层周期把缺块补回。

输入结构
- 网格由等宽列块水平拼成，块宽整除总宽。
- 除恰好一块整块为背景外，其余每块都是基准块的姿态变体：
  原样、左右翻转、上下翻转或旋转180度。
- 各块的姿态沿水平方向构成一个可推断的短循环节
  （例如 原样、左右翻、180度、原样、左右翻、180度……）。

规则
- 由非空块推断块宽与每块相对基准块的姿态。
- 识别姿态序列的循环节，外推出缺失块在其位置上应有的姿态。
- 把基准块按该姿态变换后填入缺块，输出修复后的整图。

关键洞察
缺块内容无法靠复制任何单个邻居得到：像素层的瓦片周期只给出内容，
姿态层的循环节才给出朝向；两层周期必须联立求解，姿态摆错则整块全错。
```

## 7. 嵌套塔当尺子与罗盘

- tags:
  - operation:计数, counting
  - operation:射线延伸, ray_extend
  - object:嵌套矩形, nested_rectangle
  - object:标记像素, marker_pixel
  - relation:颜色配对, color_pairing
  - relation:塔心指向, center_to_marker_bearing
  - condition:层数定长度, depth_maps_length
  - condition:主轴定方向, major_axis_direction
- 参考题目题号: 5751f35e, 7d1f7ee8, e048c9ed, 705a3229

### docstring

```text
一句话总述
每枚标记沿"同色嵌套塔中心指向标记"的主轴方向长出一条射线，
长度等于那座塔的嵌套层数。

输入结构
- 背景上立着若干座嵌套塔：同色空心矩形层层严格包含，层数2到5，
  各塔颜色互不相同。
- 塔外散布若干单像素标记，每枚颜色与某座塔相同；
  标记到该塔中心的行差与列差绝对值不等（主轴无平局）。

规则
- 每枚标记按颜色认领一座塔，数出塔的嵌套层数k。
- 取塔中心指向标记的位移中绝对值较大的轴向分量，作为延伸方向。
- 从标记出发沿该方向再涂k格标记色；塔与标记原样保留。

关键洞察
矩形塔不是被操作的对象，而是一件量具：层数是刻度，
塔心与标记的相对方位是罗盘指针——射线的长度与方向都不写在标记自己身上，
必须跨对象读数才能画对每一笔。
```
