## 1. 孔洞指针重排

- 参考题目题号: 3, 5, 16
- tags:
  - operation:移动, move
  - object:瓦片阵列, tile_array
  - object:分隔行列, separator_row_col
  - object:位置孔洞, position_hole
  - relation:阵列坐标编码, array_coord_encoding
  - condition:孔洞即目的地, hole_encodes_destination
  - condition:孔洞随位改标, hole_relabeled_at_destination

### docstring

```text
按孔洞编码的目标坐标重排瓦片，并把每块瓦片的孔洞改写成新位置的自标签。

输入结构：
- 正方形网格边长为 n*n+n-1，被单像素背景分隔行列划分成 n×n 的瓦片阵列。
- 部分阵列位置放有瓦片：每块瓦片是一种前景色的 n×n 实心块，内部恰有一个背景色孔洞。
- 全部孔洞的局部坐标所编码的阵列位置，恰好与被占用的阵列位置集合相同（指针在占用位置上构成一个置换）。

规则：
- 把每块瓦片整体搬到其孔洞局部坐标 (r,c) 所指的阵列位置 (r,c)。
- 搬定后，把该瓦片的孔洞改挖在编码"新位置"的局部坐标处，即输出中每块瓦片的孔洞都是所在位置的自标签。
- 分隔行列与空位保持背景。

关键洞察：
- 同一套"孔洞局部坐标=阵列坐标"的编码被读写了两次：输入里孔洞是"该去哪"的指针，
  输出里孔洞是"我在哪"的标签；只搬瓦片不改孔洞、或只改孔洞不搬瓦片，
  都无法同时解释所有示例。表面上它像一道"孔洞=自身位置"的补全题，细看才会发现输入孔洞与位置不符。
```

## 2. 镜面折线换纹

- 参考题目题号: 2, 7, 19
- tags:
  - operation:射线延伸, ray_extend
  - operation:颜色互换, color_swap
  - object:标记像素, marker_pixel
  - object:镜面段, mirror_segment
  - object:轨迹线段, trail_segment
  - relation:反射转向, reflection_redirects
  - condition:反射触发色换, reflection_triggers_color_swap
  - condition:节拍跨反弹连续, phase_continuity

### docstring

```text
从标记像素发出三格节拍的双色射线，每经一次镜面反弹就转向90度并对换双色角色，节拍跨反弹连续。

输入结构：
- 黑背景。一个彩色标记像素，紧邻一个灰色指示像素给出初始前进方向。
- 场上散布若干面"镜子"，每面镜子由两个对角相邻的灰色像素组成，对角朝向表示镜面方向（如同 / 或 \）。
- 黄色不在输入中出现，仅用于输出轨迹。

规则：
- 射线自标记出发沿指示方向逐格前进，维持 1,2,3 循环节拍：节拍 1、2 染当前主色，节拍 3 染当前副色；
  初始主色为标记色、副色为黄色。
- 撞上镜面像素时该格保持灰色、不染色不计拍，射线按镜面朝向折转 90 度继续。
- 每发生一次反弹，主色与副色互换（节拍计数不重置）。
- 射线行进到网格边缘为止；构造保证轨迹不自交。

关键洞察：
- 镜子同时干两件事：几何上折转路径、图案上对换双色；
  漏掉任何一半，或让三格节拍在反弹处重新起头，都会在某个示例上露馅。
```

## 3. 传送带轮转

- 参考题目题号: 1, 11, 18
- tags:
  - operation:重涂色, recolor
  - operation:擦除, erase
  - object:路径网络, path_network
  - object:精灵体, sprite
  - relation:路径连通, path_connectivity
  - relation:顺序对应, ordinal_correspondence
  - condition:自指颜色定起点, self_keyed_sprite_sets_start
  - condition:忽略干扰项, ignore_distractors

### docstring

```text
沿灰色一笔路径的访问顺序把各接触精灵的中心色向后传一位，起点由中心色等于边框色的自锁精灵指定。

输入结构：
- 背景上有一条灰色一笔画路径（8连通，恰有两个端点），沿途经端口接触若干"边框+单像素中心"精灵；
  每个精灵边框一色、中心另一色，各精灵边框色互不相同。
- 恰有一个精灵的中心色与自身边框色相同（自锁精灵），它接触路径的一个端点。
- 另有若干不与路径接触的精灵作干扰。

规则：
- 从自锁精灵所接的端点出发沿路径走到另一端，按接触先后得到访问序 v1(自锁), v2, …, vk。
- 输出中 v(i+1) 的中心色改为 v(i) 的原中心色，v1 的中心色改为 vk 的原中心色；所有边框不变。
- 擦除一切不接触路径的精灵；路径原样保留。

关键洞察：
- 路径是有方向的传送带：自锁精灵（中心=边框）既是唯一可辨识的锚点，也指定了传送的起点和方向；
  中心色沿访问顺序整体轮转一位，而不是表面上更像的成对交换或颜色查表替换。
```

## 4. 隐形镜子

- 参考题目题号: 9, 13, 20
- tags:
  - operation:对称检测, symmetry_detection
  - operation:镜像, mirror
  - operation:复制放置, replicate_stamp
  - object:精灵体, sprite
  - object:孤例精灵, singleton_sprite
  - relation:镜像轴, mirror_axis
  - relation:同带管辖, band_governance
  - condition:旋转对为假镜, rotation_pair_is_fake_mirror
  - condition:忽略干扰项, ignore_distractors

### docstring

```text
同色精灵对定义看不见的镜子，把与之同带的孤例精灵反射过去；180度旋转对是假镜子。

输入结构：
- 黑背景上散布若干形状不对称的单色精灵。同色精灵恰好两两成对：
  有的对沿一条竖直轴互为左右镜像（行区间相同、左右并列），
  有的对沿一条水平轴互为上下镜像（列区间相同），其余对互为180度旋转。
- 另有若干颜色无配对的孤例精灵，每个孤例的行区间（或列区间）恰与唯一一个成对组的行区间（列区间）重叠。
- 镜像对的间距保证对称轴恰好落在整列或整行上。

规则：
- 每个左右镜像对在两者正中定义一条竖直镜轴；上下镜像对定义正中的水平镜轴；180度旋转对不定义镜轴。
- 每个孤例精灵交给与它同行带（同列带）的那对精灵：
  若该对定义了镜轴，则在输出中添加孤例关于该轴的镜像副本（颜色不变、原件保留）；
  若该对是旋转对，孤例保持原样、不添加任何东西。
- 成对精灵原样保留；轴线本身始终不画出。

关键洞察：
- 镜子从头到尾没有被画出，它只存在于每对精灵的相对姿态里；
  必须先区分真镜像对与180度旋转的假镜子，再把每个孤例交给管辖它的那面镜子反射；
  输出里也看不到轴，只有多出来的镜像副本。
```

## 5. 活闸重力筛

- 参考题目题号: 4, 6, 10
- tags:
  - operation:移动, move
  - operation:堆叠, stack
  - object:矩形, rectangle
  - object:障碍段, barrier_segment
  - object:实心墙, solid_wall
  - relation:区间包含, span_containment
  - condition:墙定重力方向, wall_sets_gravity
  - condition:门宽判定通过, gate_admits_span
  - condition:先落者封门, earlier_lander_seals_gap

### docstring

```text
实心墙指明重力方向，矩形依次朝墙坠落，整体落入缺口才能穿过横杆，先落者会封堵缺口、改写筛子。

输入结构：
- 网格恰有一条边被整条实心墙封住，墙即地面，重力垂直指向它。
- 场中与墙平行地横亘一到两条带缺口的黑色横杆。
- 其余是若干实心彩色矩形，垂直于重力方向的跨度各不相同。

规则：
- 矩形按离墙从近到远的次序依次坠落，坠落中垂直于重力的位置不变。
- 遇横杆时：若矩形垂直于重力方向的整个跨度落在该横杆某个缺口的跨度之内，则穿过横杆继续坠落；
  否则停在横杆前一行（列）。
- 坠落也会被已落定的矩形挡住（垂直方向有任一重叠即接触），停在其上贴紧。
- 停在横杆上的矩形若遮住某缺口的口面，该缺口对之后的矩形即告封死。
- 全部落定后输出，墙与横杆原样保留。

关键洞察：
- 先要从那条实心边读出重力方向；缺口是按区间包含判定的几何筛，而且筛子是活的——
  先落者可以把缺口封死，使本来能穿过的后来者被截在上层，落定次序因此成为答案的一部分。
```

## 6. 两跳引用

- 参考题目题号: 14, 17, 1
- tags:
  - operation:重涂色, recolor
  - operation:擦除, erase
  - object:单色区域, monochrome_region
  - object:孤立像素, isolated_pixel
  - relation:颜色查找键, color_lookup_key
  - condition:两跳取色, two_hop_lookup
  - condition:指针成环, pointers_form_cycles

### docstring

```text
把每个区域重涂成"它的孤立像素所指区域里那颗孤立像素"的颜色——沿颜色指针走两跳取色。

输入结构：
- 网格是若干单色区域的拼镶，区域颜色互不相同。
- 每个区域内部恰有一颗颜色异于本区域的孤立像素，其颜色等于另一个区域的区域色，构成一枚指针。
- 全部指针在区域集合上构成若干不相交的环（既有二元环也有更长的环）。

规则：
- 对每个区域 A：设 A 的孤立像素指向区域 B（像素颜色=B 的区域色），
  再读 B 内孤立像素的颜色 c，把 A 全域（含其像素位置）填成 c。
- 所有孤立像素在输出中消失。

关键洞察：
- 表面规则"区域变成自己像素的颜色"在二元环上必然出错——那里两跳恰好回到自身、区域颜色应当不变；
  真正的规则读的是"引用的引用"，等价于每个环上的区域色沿指针方向整体前移两步。
```

## 7. 破缺暗图

- 参考题目题号: 12, 3, 15
- tags:
  - operation:平铺, tiling
  - operation:裁剪, crop
  - object:模板瓦片, stencil_tile
  - object:异常像素, defect_pixel
  - relation:平移周期, translate_period
  - relation:阵列坐标编码, array_coord_encoding
  - condition:缺陷局部坐标定址, defect_offset_addresses_output
  - condition:埋诱饵, decoy_tile_position

### docstring

```text
看穿周期贴图，把每块受损瓦片里被改像素的局部坐标当地址、被改成的颜色当墨水，在瓦片大小的输出上落点成图。

输入结构：
- 整个网格由一个 p×q 基础图案严格周期平铺（宽高均为周期的整数倍）。
- 少数瓦片受损：瓦片内恰有一个像素被改成基础图案调色板内的另一种颜色，因此破缺不会以生色跳出画面。
- 其余瓦片与基础图案逐像素一致。

规则：
- 用多数一致性恢复基础图案，与之逐瓦片比对，找出受损瓦片及其被改像素。
- 输出一个 p×q 网格：对每块受损瓦片，取被改像素在瓦片内的局部坐标 (r,c) 和被改成的颜色 c'，
  在输出 (r,c) 处填 c'；其余位置填黑。
- 构造保证不同受损瓦片的被改像素局部坐标互不相同。

关键洞察：
- 有两道暗门：第一，破缺用的是图案自己的颜色，必须先整体看穿周期纹理、把它当背景剔除才能发现它们；
  第二，落点地址是缺陷在瓦片内的局部偏移，而不是受损瓦片在阵列中的位置——后者是人人都会先试的诱饵。
```

## 8. 齿轮双环

- 参考题目题号: 6, 8, 7
- tags:
  - operation:计数, counting
  - operation:旋转, rotate
  - object:同心环, concentric_ring
  - object:散点组, scatter_group
  - relation:同心嵌套, concentric_nesting
  - condition:像素数定步数, pixel_count_sets_steps
  - condition:啮合反向, meshed_counter_rotation

### docstring

```text
外环内容按散点个数顺时针转动，与之啮合的内环等步数反向转动。

输入结构：
- 网格中有两圈同心矩形环，环上每格都有颜色，两环之间隔一圈背景。
- 环外散布一团同色散点。
- 环上颜色排列无对称性，保证旋转量可唯一读出。

规则：
- 数出散点的个数 n。
- 外环上的颜色序列沿周界顺时针平移 n 格；内环沿周界逆时针平移 n 格。
- 散点原样保留。

关键洞察：
- 散点不是要清理的噪声而是刻度：它的个数就是转动步数；
  两环之间没有画出任何传动结构，却按"相邻齿轮必反转"的方式联动，
  方向关系是必须从示例中读出的隐含机械约束。
```
