## 1. 隐形承重面板

- 参考题目题号：66f2d22f、df9fd884
- tags:
  - operation:重力下落, gravity_drop
  - operation:透明叠加, transparent_overlay
  - operation:裁剪, crop
  - object:双侧面板, bilateral_panels
  - object:障碍像素, obstacle_pixel
  - relation:双侧对齐, bilateral_alignment
  - condition:障碍不显现, invisible_obstacle

### docstring

```text
把左面板中的物体按重力下落，落点由右面板同坐标的隐形障碍决定，输出只保留左面板。

输入结构
- 网格由一条竖直分隔线分成左右两块等大的面板。
- 左面板：背景上散布若干彼此分离的多格彩色物体，悬浮在不同高度，可能有多个物体共享同一列。
- 右面板：背景上散布若干单色障碍像素，其位置与左面板逐行逐列一一对应。

规则
- 输出为单个面板大小，仅以左面板为画布。
- 将右面板的障碍像素按行列对应映射到左面板坐标系，作为不可见的支撑物。
- 左面板每个物体整体竖直下落：当物体任一格再下落一步会越过底边、压到映射来的障碍格、或压到已落定的物体时停止；同列有多个物体时，位置更低者先落定。
- 输出中不绘制障碍与分隔线，只绘制落定后的物体。

关键洞察
- 右面板不是用来比较或叠加显示的图案，而是左面板的隐形碰撞地图；
  物体停在"半空"的位置，正是另一面板同坐标障碍的顶上。
```

## 2. 角点残迹与遮挡定序

- 参考题目题号：97a05b5b、b527c5c6、31adaf00
- tags:
  - operation:重建, reconstruct
  - operation:层叠渲染, z_order_render
  - object:实心矩形, solid_rectangle
  - object:角点残迹, corner_residue
  - relation:遮挡定序, occlusion_ordering
  - condition:缺角即被覆盖, missing_corner_means_covered

### docstring

```text
由每种颜色仅存的角点重建实心矩形，并用缺失的角推断上下遮挡顺序后分层绘制。

输入结构
- 黑色背景上没有任何完整矩形，只有若干颜色各异的孤立像素。
- 每种颜色的像素是同一个轴对齐实心矩形的角点：可见 4 个角，或恰好 3 个角。
- 若某矩形只剩 3 个角，则缺失的第 4 个角恰好位于压在它上面的另一矩形内部；
  任何相互重叠的两个矩形中，恰有一方有一个角落入另一方内部。
- 矩形的上下层次与其面积、位置均无关。

规则
- 对每种颜色，用可见角点复原完整矩形（3 个角可唯一确定第 4 个角）。
- 若颜色 A 的缺角位于颜色 B 的矩形内部，则判定 B 压在 A 之上。
- 按由下到上的层次把所有矩形涂成实心：先画下层，再让上层覆盖重叠部分。

关键洞察
- 参与规则的矩形从未被完整画出，画面上只有它们的生成元（角点）；
  而"少了哪个角"这一缺席信息本身，就是层叠顺序的全部证据。
```

## 3. 循环位移等价类中的异类

- 参考题目题号：79cce52d、358ba94e
- tags:
  - operation:裁剪, crop
  - operation:循环位移, cyclic_roll
  - object:图案块, pattern_block
  - relation:位移等价, shift_equivalence
  - condition:异常值提取, outlier_extraction

### docstring

```text
找出唯一不能通过二维循环位移变回公共底图的图案块并按原样裁剪输出。

输入结构
- 背景上分布若干个同尺寸的多色图案块，彼此分离。
- 除一个块外，其余每个块都是同一底图经过某种行、列循环位移得到的版本，位移量各不相同。
- 所有块（包括异类块）的颜色计数完全相同，无法靠颜色统计区分。

规则
- 把块与块在所有行列循环位移组合下比对，能互相卷动重合的块归入同一等价类。
- 恰有一个块在任何位移下都无法与其他块重合。
- 将该块按原样裁剪为输出。

关键洞察
- 各块表面上两两不同，真正的同类关系藏在循环位移不变性之下；
  异类不是"看起来最不一样"的那个，而是任何卷动都对不上的那个。
```

## 4. 游程色环解码

- 参考题目题号：99306f82、9b2a60aa、79cce52d
- tags:
  - operation:同心层填充, concentric_fill
  - operation:游程解码, run_length_decode
  - object:空心矩形框, hollow_rect_frame
  - object:彩色条带, color_strip
  - object:端点标记, endpoint_marker
  - relation:游程长度定厚度, run_length_sets_thickness
  - condition:标记端定读向, marker_end_sets_reading_direction

### docstring

```text
把带端点标记的彩色条带按游程解码为矩形框内由外向内的同心色环，每段游程的长度即该色环带的厚度。

输入结构
- 背景上有一个一像素厚的空心矩形框，内腔为空。
- 另有一条与框分离的直线彩色条带，由若干段连续同色像素组成，各段长度不一；
  条带一端紧邻一个单独的端点标记像素。
- 条带各段长度之和恰等于内腔同心环的总层数。

规则
- 从靠近端点标记的一端开始读条带，依次得到（颜色，游程长度）序列。
- 在框内腔从最外圈向内填同心矩形环：第一段颜色填最外 L1 层环，
  第二段颜色填接下来的 L2 层，依此类推，最后一段填至中心。
- 框、条带与端点标记保持不变。

关键洞察
- 条带不是逐像素对应逐圈的调色板，而是游程编码——一段的长度决定该颜色环带的厚度；
  当所有游程长度为 1 时两种读法恰好重合，这正是第一个示例埋下的诱饵；
  读取方向由端点标记指定，读反则全错。
```

## 5. 锁齿补集嵌合

- 参考题目题号：66f2d22f、97a05b5b、6e4f6532
- tags:
  - operation:平移, translate
  - operation:旋转, rotate
  - operation:擦除, erase
  - object:空心矩形框, hollow_frame
  - object:锁齿突起, inner_protrusion
  - object:自由物体, free_object
  - relation:占用补集, occupancy_complement
  - condition:恰好铺满, exact_fill

### docstring

```text
把每个自由物体旋转平移进唯一能与框内锁齿互补、恰好无缝铺满内腔的矩形框。

输入结构
- 背景上有若干一像素厚的矩形框，框壁颜色相同；每个框的内腔壁上伸出若干与框同色的锁齿。
- 另有数量与框相同的自由彩色物体散布在背景上，颜色各异。
- 每个物体经过 0/90/180/270 度旋转后，恰好能与唯一一个框的锁齿拼成整块内腔：
  既不与锁齿重叠，也不留任何空格。

规则
- 为每个物体找到唯一可行的框与旋转角，把物体放入内腔中与锁齿互补的位置。
- 擦除物体原位置。
- 框与锁齿保持不变。

关键洞察
- 判断归属的依据不是"放得进去"，而是物体与锁齿互为占用补集：
  多个框可能都塞得下某个物体而不重叠，但只有一个框会被它严丝合缝地填满。
```

## 6. 孔径守恒挤出

- 参考题目题号：7b6016b9、a934301b、b527c5c6
- tags:
  - operation:擦除, erase
  - operation:挤出重排, extrude_repack
  - operation:计数, counting
  - object:封闭容器, closed_container
  - object:开口, aperture
  - object:内容物, content_pixels
  - relation:面积守恒, area_conservation
  - condition:开口宽度定形状, aperture_width_sets_shape

### docstring

```text
每个容器内的像素从器壁唯一的开口挤出，重排成以开口宽度为一边、总数守恒的实心矩形。

输入结构
- 背景上有若干灰色器壁围成的封闭容器，每个器壁上恰有一处宽度为 w 的开口，
  不同容器的开口宽度不同。
- 每个容器内腔散布 N 个同色内容像素，N 恰为 w 的整数倍；不同容器的内容颜色不同。
- 每个开口正前方的背景足够容纳挤出物，互不碰撞。

规则
- 清空每个容器的内腔。
- 从开口正外侧起，沿开口所在壁的外法线方向，画一个宽 w、长 N/w 的实心矩形，
  颜色为该容器的内容色，且与开口对齐。
- 器壁与开口保持原样。

关键洞察
- 挤出物的长度不是"一直画到边界"，而是由像素总数除以开口宽度得到——
  内容物只是被换了个形状，一个像素都没有增减。
```
