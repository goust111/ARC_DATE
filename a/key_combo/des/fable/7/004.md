## 1. 补缺下落

- 参考题目题号: 1, 19
- tags:
  - operation:重力下落, gravity_drop
  - operation:填充, fill
  - object:引导条, guide_bar
  - object:散布像素, scattered_pixel
  - relation:投射到引导条, project_to_guide
  - condition:缺口消耗补堵, gap_plugged_by_pixel
  - condition:连锁反应, chain_reaction

### docstring

```text
逐列下落的杂散像素被引导条接住；落入缺口的像素补堵缺口并被消耗，从而改变同列后续像素的停靠层。

输入结构：
- 背景为黑色；若干条一格厚的水平灰色引导条横贯网格（可为不满全宽的条段），条上带有若干单格缺口（缺口即同一行左右两侧均为灰色的背景格）。
- 引导条上方散布单色的彩色像素，同一列内可有多枚。

规则：
- 每列独立处理；列内像素按由低到高的顺序依次垂直下落。
- 下落像素在下降途中若经过一个缺口格，则被消耗，该格变为灰色（缺口被补堵）；否则停靠在本列遇到的第一个灰格的正上方一格。
- 缺口补堵后，同列后续下落的像素将停靠在这条补好的引导条上方。
- 若像素所在列下方既无灰格也无缺口，则该像素被擦除。
- 输出保留全部引导条（含补堵后的灰格）与停靠后的彩色像素，其余为背景。

关键洞察：
- 缺口不是"漏掉即擦除"的洞，而是会被先落像素补上的消耗坑；答案取决于列内下落次序——低处的像素先补缺口，高处的像素才有处可站。
```

## 2. 隐枢旋转

- 参考题目题号: 4, 5, 16
- tags:
  - operation:旋转, rotate
  - operation:计数, counting
  - object:三角标记框, three_corner_frame
  - object:颜色图例, color_legend
  - object:精灵体, sprite
  - relation:缺角即枢轴, missing_corner_as_pivot
  - condition:图例高度为旋转次数, legend_height_as_turn_count

### docstring

```text
以三枚角标记所缺的第四角为隐形枢轴，将每个彩色精灵绕该点顺时针旋转，旋转次数由同色图例块的高度给出。

输入结构：
- 背景为黑色。三枚黄色单点标记构成一个正方形的三个角，第四个角从未画出。
- 网格中散布一个或多个颜色互不相同的单色精灵。
- 左上角贴顶排列若干单色图例块，每块颜色 K、高度 k，与某个精灵同色。

规则：
- 由三枚黄色标记推出正方形缺失的第四角，该格即旋转枢轴（枢轴处不画任何像素）。
- 对每个颜色为 K 的精灵，绕枢轴顺时针旋转 90°×k，k 为同色图例块的高度。
- 输出中精灵只出现在旋转后的位置，原位清空；黄色标记与图例保持不变。

关键洞察：
- 枢轴从未被画出，必须由三角标记补出第四角；图例块的高度不是尺寸而是四分之一圈数——k=2 时貌似点对称，k=1、3 时才暴露真规则。
```

## 3. 门距奇偶

- 参考题目题号: 6, 8, 13
- tags:
  - operation:洪泛填充, flood_fill
  - operation:计数, counting
  - object:分隔线, separator_line
  - object:种子像素, seed_pixel
  - object:障碍物, obstacle
  - relation:房间图最短门距, room_graph_door_distance
  - condition:门距奇偶决定色, parity_by_door_count
  - condition:堵门不可通行, blocked_door_is_wall

### docstring

```text
以房间为单位做奇偶染色：从种子房间出发，按穿过门的最少次数给每个可达房间整体填色，奇偶交替。

输入结构：
- 一种颜色构成贯穿整个网格的分隔行与分隔列，把画面切成矩形房间；分隔线上开有若干单格的"门"。
- 某个房间内并置两枚不同颜色的种子像素 A 与 B；个别门的门口恰好被一枚第三色障碍像素堵住。

规则：
- 把每个房间看作一个节点，未被障碍堵住的门是边；被障碍像素占据的门视为墙。
- 计算每个房间到种子房间需要穿过门的最少次数 d。
- d 为偶数（含种子房间自身）的房间整体填成颜色 A，d 为奇数的填成颜色 B；不可达的房间保持背景。
- 分隔线与门口的障碍像素保持原样；种子像素融入所在房间的填色。

关键洞察：
- 交替不发生在逐格路径上，而发生在房间图的最短门距上——房间大小与门的位置都不影响奇偶，只有"穿门次数"才算一步，而被堵住的门根本不是边。
```

## 4. 整除选模板

- 参考题目题号: 9, 10
- tags:
  - operation:搜索, search
  - operation:填充, fill
  - operation:重复, repeat
  - operation:旋转, rotate
  - object:空心矩形区域, empty_rect_region
  - object:模板, template
  - relation:尺寸整除匹配, size_divisibility_match
  - condition:唯一整除者被平铺, unique_divisor_tiled

### docstring

```text
找出最大的全黑空矩形，再从散布的模板中选出唯一能按原样或旋转 90° 后整除该矩形尺寸的那个，把它平铺填满矩形。

输入结构：
- 网格上分布若干形状尺寸各异、彼此分离的单色小模板。
- 其余区域存在一个面积最大、两边都不小于 2 的全黑矩形空腔（不必是连通黑区的全部）。

规则：
- 枚举所有两边均不小于 2 的全黑矩形，取面积最大者为目标腔。
- 对每个模板的外接矩形图案，检查原始方向与旋转 90° 两种姿态：恰有一个模板在恰一种姿态下，高与宽同时整除目标腔的高与宽。
- 以该姿态的模板图案为砖（含其中的背景格）按行列周期平铺，正好铺满目标腔；其余模板与全部原有像素保持不变。

关键洞察：
- 空矩形不是被随便填色的坑，而是一把"尺寸筛子"：它用整除关系在候选模板中选出唯一的铺砖者，且可能要求先旋转再入选。
```

## 5. 缺口出射链

- 参考题目题号: 13, 14, 17
- tags:
  - operation:射线延伸, ray_extend
  - operation:洪泛填充, flood_fill
  - object:空心矩形框, hollow_rect_frame
  - object:框架缺口, frame_gap
  - object:填充种子, fill_seed
  - object:障碍物, obstacle
  - relation:射线接触传染, ray_contact_contagion
  - condition:缺口为出射口, gap_as_exit_port
  - condition:连锁反应, chain_reaction

### docstring

```text
颜色从唯一含种子的框出发，沿框缺口射出的射线在框与框之间传染：被击中的框整体填色，并继续从自己的缺口出射。

输入结构：
- 背景上分布若干个一格厚的灰色空心矩形框，每个框的边上恰有一个单格缺口。
- 恰有一个框的内部含一枚彩色种子像素；画面上另散布个别孤立的灰色障碍点。

规则：
- 含种子的框先把内部全部填成种子色，然后从缺口向框外沿垂直于该边的方向射出一条同色射线。
- 射线逐格前进并把经过的背景格染色，直到撞上灰色像素（框壁或障碍点）或飞出网格边缘。
- 若射线撞上的是某个尚未填色的框（撞壁或恰好经缺口射入皆可），该框内部整体填上此色，并同样从自己的缺口射出下一条射线；已填过色的框不再重复触发。
- 被障碍点挡下的射线就地终止，其后的框保持空心。

关键洞察：
- 缺口是每个框唯一的"出射口"，框壁则处处可作"受击口"；整幅画是一条由缺口朝向串起来的传染链，一枚不起眼的灰色障碍点就能斩断下游所有填色。
```

## 6. 多屏投影

- 参考题目题号: 1, 13, 17
- tags:
  - operation:投影, projection
  - operation:擦除, erase
  - object:引导条, guide_bar
  - object:灯标, lamp_marker
  - object:散布像素, scattered_pixel
  - relation:遮挡优先, occlusion_priority
  - condition:影落挡光点后首屏, shadow_on_first_screen_after_blocker
  - condition:缺口移交视线, gap_hands_over_sightline

### docstring

```text
平行光穿过多块带缺口的屏，把每条视线上第一个挡光的精灵像素的影子，投在挡光点之后第一块屏的背光面上；缺口把视线放行给更远的屏。

输入结构：
- 网格一条边上有一整排灯标色像素，标出平行光的来向。
- 网格中立着两块（或多块）与该边平行的单格厚灰色引导屏，彼此相隔数格，屏上各带若干单格缺口。
- 灯与各屏之间、屏与屏之间乃至最远屏之后都散布若干单色精灵像素。

规则：
- 对每条垂直于屏的视线，从灯标一侧出发逐格前进：
- 若先遇到精灵像素，记下其颜色 C（该像素为本视线唯一挡光者），继续前进到挡光点之后遇到的第一格屏灰格，在其背光面紧贴一格涂 C；若挡光点之后直到出网格都没有屏灰格，则不留任何影子。
- 若先遇到屏灰格（其前没有精灵），光被屏无声挡下，本视线不产生影子，屏后一切精灵失效。
- 视线经过屏的缺口时直接放行，继续前进。
- 输出删去全部精灵，仅保留灯标、各屏与影子。

关键洞察：
- 影子永远落在"挡光点之后的第一块屏"上——屏前精灵隔着缺口能把影子投到远屏，而屏前无精灵的视线连影子都没有；缺口不是无事发生，而是把整条视线移交给下一块屏。
```
