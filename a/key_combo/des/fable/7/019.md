## 1. 隐心方环的径向补全

- tags:
  - operation:补全, completion
  - operation:循环填充, cyclic_fill
  - object:同心方环, concentric_square_rings
  - object:标记像素, marker_pixel
  - relation:切比雪夫距离, chebyshev_dist
  - relation:径向周期, radial_period
  - condition:中心未画出, center_never_drawn
  - condition:标记为缺失值, markers_missing_val
- 参考题目: 9 (05269061)、16 (ff72ca3e)、18 (f823c43c)

### docstring

```text
以从未画出的中心为原点，按切比雪夫环的周期配色补全所有粉色缺失像素。

输入结构：
- 黑色背景上分布着若干段同心方环弧段：它们是以某一格为中心、按切比雪夫
  距离分层的方形环的可见部分。
- 环的颜色随环半径按一个固定短颜色序列周期循环。
- 中心格本身从未被画出；若干粉色像素标记被遮挡的格。
- 可见弧段唯一确定中心位置与颜色循环序列；存在某个整环完全被遮挡，
  该环上没有任何可见颜色格。

规则：
- 由可见弧段推断唯一的中心格。
- 对每个粉色像素，计算它到中心的切比雪夫距离，按"半径对周期取余"查出
  该环应有的颜色并重涂。
- 其余像素（包括未画出的环的其他背景格）保持不变。

关键洞察：
- 图案的周期性存在于"到隐形中心的切比雪夫距离"这一维度上，而不是行列
  方向；由于存在被完全遮挡的整环，"在同一环上抄可见颜色"的捷径行不通，
  必须同时推出隐形中心和径向周期两件事。
```

## 2. 分隔线上的交换算子

- tags:
  - operation:下采样, downsample
  - operation:交换, swap
  - object:分隔行列, separator_rows_and_columns
  - object:算子像素, operator_pixel
  - relation:相邻单元配对, adjacent_cell_pairing
  - relation:串联复合, sequential_composition
  - condition:分隔缺陷为算子, separator_defect_as_operator
- 参考题目: 1 (68b67ca3)、6 (d406998b)、13 (54d9e175)

### docstring

```text
压缩去除分隔行列时，把分隔线上的灰色缺陷当作交换算子依次作用于相邻逻辑单元。

输入结构：
- 网格的偶数索引行列交叉处构成彩色逻辑单元格，奇数索引行列是分隔行列，
  几乎全为背景。
- 少数分隔格上有灰色像素，每个灰色像素恰好位于两个相邻逻辑单元的正中间
  （同行相邻或同列相邻）。
- 同一逻辑单元不会同时接触水平算子和垂直算子。

规则：
- 先让每个灰色算子交换它两侧逻辑单元的颜色：同一行内的水平算子从左到右
  依次生效，同一列内的垂直算子从上到下依次生效。
- 然后删除全部分隔行列，输出半尺寸的紧凑网格。
- 灰色像素本身不进入输出。

关键洞察：
- 分隔线不是纯粹的空载体，其上的缺陷是作用于逻辑单元的算子；相邻算子
  串联时按顺序复合，等效于一段单元的循环移位——把各算子当作彼此独立的
  交换，在算子相邻串联的样例上会得到错误答案。
```

## 3. 面积守恒下的层序倒置

- tags:
  - operation:补全, completion
  - operation:层序反转, depth_inversion
  - object:矩形遮挡物, rect_occluder
  - relation:遮挡蕴含深度, occlusion_implies_depth
  - relation:面积守恒, area_conservation
  - condition:守恒量消除歧义, invariant_resolves_ambiguity
  - condition:层序整体反转, reverse_depth_order
- 参考题目: 3 (62ab2642)、8 (abbfd121)、10 (c8cbb738)

### docstring

```text
借助所有矩形面积相同这一隐藏守恒量补全被遮挡矩形，再按完全颠倒的遮挡层序重新渲染。

输入结构：
- 背景色单一，若干实心单色矩形互相重叠成一摞，上层截断下层的可见区域。
- 至少一个矩形完全可见；所有矩形的真实面积（含被遮挡部分）彼此相等。
- 部分矩形被遮挡得仅凭"把可见部分补成某个矩形"无法唯一还原，但结合
  共同面积约束后还原唯一。
- 任意两个重叠矩形之间谁截断谁均可从画面读出，整摞矩形构成唯一全序；
  存在三层以上相互重叠的格。

规则：
- 从完全可见的矩形读出共同面积，据此唯一还原每个被遮挡矩形的完整范围。
- 由"谁截断谁"恢复输入自底向上的层序。
- 在输出中按与输入完全相反的层序自底向上重绘全部完整矩形：原最底层
  变为最顶层。背景保持不变。

关键洞察：
- 面积守恒是从未言明、只能通过对比完整矩形才能发现的约束，缺了它部分
  矩形的隐藏范围存在多解；层序也不是现成属性，必须从遮挡截断关系整体
  重建之后再反转——存在三层重叠处，逐对交换可见色的捷径会得到错误答案。
```

## 4. 半影模板的并集重建

- tags:
  - operation:模板提取, template_extraction
  - operation:补全, completion
  - operation:旋转镜像, rotate_reflect
  - object:变换副本, transformed_copy
  - object:对齐签名, alignment_signature
  - relation:残缺并集重建, partial_union_reconstruction
  - condition:模板从未完整出现, template_never_fully_drawn
- 参考题目: 2 (3e980e27)、7 (b1fc8b8e)、15 (79369cc6)

### docstring

```text
把两个各缺一部分的定向副本对齐并集出完整模板，再为只剩签名的副本补上缺失的图案色。

输入结构：
- 黑色背景上分布着同一个双色模板（图案色加签名色）的若干旋转或镜像副本。
- 其中两个副本各自缺失了不同部分的像素，但它们的签名色部分都足以确定
  各自的朝向，且两者覆盖的模板区域合并后恰好完整。
- 另有一到多个放置位置只画出了完整的签名色像素，完全没有图案色。
- 签名图形没有任何旋转或镜像自对称。

规则：
- 利用签名色把两个残缺副本配准到同一朝向坐标系，取并集重建完整模板。
- 对每个只有签名的放置，按其签名呈现的朝向，把模板中该放置缺失的全部
  图案色像素补画出来。
- 输入中已有的像素一律保留。

关键洞察：
- 完整模板在画面上从未出现过，它只能由两个互补的残缺副本跨朝向拼合而
  成；把较完整的那个副本直接当作模板使用，会在补全位置留下无法解释的
  空缺。
```

## 5. 窗口内的锚点盖章

- tags:
  - operation:印章覆盖, stamp
  - object:窗口格, window_cell
  - object:精灵体, sprite
  - object:标记像素, marker_pixel
  - relation:颜色定内部锚点, color_selects_internal_anchor
  - relation:窗口为独立画布, window_as_canvas
  - condition:容纳性消除歧义, containment_resolves_ambiguity
- 参考题目: 2 (3e980e27)、12 (bf45cf4b)、13 (54d9e175)

### docstring

```text
把模板窗口中的精灵盖到每个标记窗口，使精灵中与标记同色的格恰好落在标记位置上。

输入结构：
- 灰色整行整列把网格分隔成若干同尺寸窗口。
- 恰有一个窗口内是一个多色精灵；其余非空窗口各含一个单独像素，其颜色
  必定在精灵中出现。
- 精灵中任一颜色最多出现两个格；当某标记色在精灵中有两个候选格时，
  只有一个候选能让精灵完整落在窗口内。

规则：
- 对每个标记窗口，把精灵原样平移进该窗口，使精灵中与标记同色的那个格
  与标记位置重合。
- 若该颜色在精灵中有两个格，选择使精灵不越出窗口边界的那一个。
- 模板窗口与灰色分隔线保持不变。

关键洞察：
- 标记色配对的不是"精灵整体的目的地"，而是精灵内部的一个锚点格，因此
  不同颜色的标记引起各不相同的平移偏置；锚点出现二义时，由"精灵必须被
  窗口容纳"这一隐含约束消解。
```

## 6. 边框载体决定叠序的居中叠加

- tags:
  - operation:裁剪, crop
  - operation:透明叠加, transparent_overlay
  - object:圆角边框, rounded_frame
  - object:内部图案, inner_pattern
  - relation:中心对齐, center_alignment
  - relation:载体尺寸定层序, carrier_size_sets_depth
  - condition:边框仅为载体, frame_is_carrier_only
- 参考题目: 3 (62ab2642)、10 (c8cbb738)、17 (db118e2a)

### docstring

```text
丢弃圆角边框，把各内部图案裁剪后居中叠加，边框越小图案越靠上层。

输入结构：
- 背景上分布若干互不接触的圆角矩形边框（四角为背景色），边框尺寸互不
  相同；每个边框内部包含一个图案。
- 各图案裁剪到自身边界框后，高宽奇偶性彼此兼容，可以共同居中。
- 至少存在两个图案在叠加时争用同一格。

规则：
- 输出画布为背景色，尺寸等于各图案边界框的最大高与最大宽。
- 把每个图案裁剪到边界框并在画布上居中叠加。
- 多个图案争用同一格时，来自更小边框的图案覆盖来自更大边框的图案。
- 边框本身不进入输出。

关键洞察：
- 叠放优先级由承载图案的边框尺寸决定，而不是由图案自身大小或颜色决定
  ——图案大小顺序与边框大小顺序在部分样例中相反；边框是唯一的深度线索，
  却又完全不出现在输出里。
```

## 7. 先移动再分区的连锁涂色

- tags:
  - operation:平移, translate
  - operation:重涂色, recolor
  - object:边界矩形, boundary_rectangle
  - object:分隔墙, partition_wall
  - relation:多重性选移动色, multiplicity_selects_mover
  - relation:后置状态分区, partition_after_motion
  - condition:极值面积定色, extreme_area_determines_color
  - condition:两段连锁, causal_chain
- 参考题目: 3 (62ab2642)、20 (22208ba4)

### docstring

```text
让重复色矩形按自身尺寸向内平移，然后在移动后的新格局中给最小与最大黑色区域涂色。

输入结构：
- 黑色背景中有一格宽的灰色墙线与若干贴边的实心单色矩形。
- 恰有一种颜色的矩形出现多次，其余颜色的矩形各出现一次。
- 移动完成后，所有矩形与灰色墙共同把黑色像素分割为若干四连通区域，
  其中最小区域与最大区域各自唯一。

规则：
- 把重复色的每个矩形从原位清除，并沿它所贴靠的行边界与列边界各向内
  平移自身的高与宽；单次色矩形与灰色墙保持不动。
- 在移动后的格局中求全部四连通黑色区域，把唯一最小区域整体涂橙色，
  唯一最大区域整体涂青色，其余黑色像素保持不变。

关键洞察：
- 涂色针对的是移动之后才存在的区域格局——输入中现成的区域划分是诱饵，
  直接在输入上找极值区域会得到错误答案；多重性选出移动者，移动又反过
  来改写用于极值判定的空间结构。
```
