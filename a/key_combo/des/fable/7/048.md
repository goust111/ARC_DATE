## 1. 换色镜像修复

- 参考题目题号: 17 (f9d67f8b)、10 (d511f180)、1 (c9e6f938)
- tags:
  - operation:对称补全, symmetry_completion
  - operation:重涂色, recolor
  - object:遮挡像素, occluding_pixel
  - object:对称图案, symmetric_pattern
  - relation:双色互换, two_color_swap
  - relation:轴对称, axial_symmetry
  - condition:镜像伴随换色, mirror_with_color_swap

### docstring

```text
用"左右镜像时两种颜色互换、上下镜像时颜色不变"的隐藏复合对称，修复被污损色覆盖的像素。

输入结构
- 矩形网格上绘有多色图案，另有一种污损色覆盖若干格，污损色不属于图案本身。
- 去除污损后，图案关于一条竖直轴满足"位置镜像且颜色 A、B 互换、其余颜色不变"的换色对称，
  关于一条水平轴满足普通镜像对称。
- 两条轴的位置需从图案自身推断，不一定经过几何中心。

规则
- 找出唯一能使全部可见像素自洽的水平轴、竖直轴以及互换色对 A/B。
- 每个污损格从其对称轨道（左右镜像、上下镜像、二者复合的 180 度旋转）中任一可见同伴取色：
  经上下镜像取到的颜色直接使用；经左右镜像或 180 度复合取到的颜色执行一次 A/B 互换
  （A 写成 B、B 写成 A、其余颜色原样）。
- 未污损像素全部保持不变。

关键洞察
- 图案的对称不是纯几何对称，而是"几何镜像 ∘ 颜色置换"的复合对称；只按普通镜像补色会在
  A、B 两色处系统性出错，必须发现随左右镜像一起生效的颜色互换才能自洽全部示例。
```

## 2. 面积射程弹射

- 参考题目题号: 3 (6e19193c)、18 (d631b094)、20 (a3df8b1e)
- tags:
  - operation:射线延伸, ray_extend
  - operation:计数, counting
  - object:箭头精灵体, arrowhead_sprite
  - object:画布边界, canvas_boundary
  - relation:朝向推断, dir_inference
  - relation:反射弹回, reflection_bounce
  - condition:面积决定射程, area_determines_range

### docstring

```text
每个箭头沿其指向发射一条长度等于自身像素数的对角射线，射线撞画布边界反弹后继续走完剩余步数。

输入结构
- 黑色背景上散布若干个互不相触的小箭头，每个箭头是从实心方块上缺去一角得到的形状，
  缺角指向一条对角方向。
- 各箭头颜色可同可异；布局保证各射线互不相遇、也不穿过其他箭头。

规则
- 对每个箭头，由缺角位置推断其对角朝向，并数出该箭头包含的像素个数 n。
- 从缺角所在的外侧格起，沿该对角方向逐格前进并涂成箭头颜色，总共走 n 步。
- 途中碰到画布边界时按镜面反射改变相应分量的方向（碰左右边反转水平分量，
  碰上下边反转竖直分量，角上同时反转），继续走完剩余步数。
- 箭头本体保持不变。

关键洞察
- 射线并非一直延伸到边界：射程是箭头自身面积这一"步数预算"，长预算的射线会在边界上
  折返，短预算的射线停在半途；只有把"数量"读成"距离"并叠加反弹几何，才能同时解释
  全部示例。
```

## 3. 旋转落点选区

- 参考题目题号: 6 (1a244afd)、7 (a5313dff)
- tags:
  - operation:旋转, rotate
  - operation:洪泛填充, flood_fill
  - object:枢轴像素, pivot_pixel
  - object:源像素, source_pixel
  - object:封闭区域, enclosed_region
  - object:墙壁线段, wall_segment
  - relation:同行或同列, same_row_or_col
  - relation:区域封闭, region_enclosure
  - condition:落点决定填充目标, landing_selects_region

### docstring

```text
将每个洋红源像素绕其配对蓝色枢轴逆时针旋转 90 度，落点所在的红墙封闭空腔整体洪泛填充为洋红。

输入结构
- 黑色背景上有红色单像素粗的墙，围出若干个互不连通的封闭空腔；部分红墙不闭合，是干扰。
- 另有蓝色枢轴像素与洋红源像素，每个源像素与唯一一个蓝色枢轴同行或同列配对。
- 源像素与枢轴都位于红墙之外的开放背景上。

规则
- 按同行或同列关系为每个洋红源像素匹配唯一的蓝色枢轴。
- 保持到枢轴的距离不变，把源像素相对枢轴的位置向量逆时针旋转 90 度得到落点。
- 若落点位于某个被红墙完全围住的空腔内部，则将该空腔的全部背景格洪泛填充为洋红；
  若落点在开放背景、红墙上或画布之外，则不产生任何填充。
- 删除所有洋红源像素；蓝色枢轴与红墙保持不变。

关键洞察
- 被填充的区域与任何可见对象都不相邻：真正的指针是"旋转后的落点"这一从未画出的位置。
  必须先解出行列配对与旋转，再做封闭性判定，两层缺一不可；按"离源像素最近的空腔"等
  直觉捷径无法吻合全部示例。
```

## 4. 封闭门控周期复原

- 参考题目题号: 11 (50a16a69)、7 (a5313dff)、17 (f9d67f8b)
- tags:
  - operation:补全, complete
  - operation:重涂色, recolor
  - object:重复瓦片, repeating_tile
  - object:遮挡像素, occluding_pixel
  - object:墙壁线段, wall_segment
  - relation:周期延拓, periodic_extension
  - relation:区域封闭, region_enclosure
  - condition:封闭才修复, restore_only_if_enclosed

### docstring

```text
只有被闭合红色围线完全圈住的破损区域才按底层周期图案复原，圈外破损与不闭合红线原样保留。

输入结构
- 画布底层是一个由小矩形瓦片周期平铺的多色图案，图案本身不含红色与灰色。
- 若干团灰色斑块覆盖在图案上作为破损；部分斑块外围画有一圈红色细线，红线可能闭合，
  也可能留有缺口。
- 红线也遮住其下的图案。

规则
- 由未破损部分推断周期图案的最小瓦片及其相位。
- 判定每一团灰斑是否被一条闭合红线完全围住（红线有缺口即不算围住）。
- 被围住的灰斑及围住它的整条红线都恢复为周期图案在对应位置的颜色。
- 未被围住的灰斑与不闭合的红线保持原样。

关键洞察
- 破损修复不是无条件的：红圈的闭合性是"批准修复"的开关，圈外破损是要保留的实体而非
  待修的损伤；同时瓦片周期必须在带破损的画面上推断，先全局推周期、后局部判封闭，
  两层推理缺一不可。
```

## 5. 变色弹道

- 参考题目题号: 20 (a3df8b1e)、19 (fc754716)、5 (b942fd60)
- tags:
  - operation:射线延伸, ray_cast
  - operation:描边, trace_path
  - operation:重涂色, recolor
  - object:起点像素, start_pixel
  - object:画布边界, canvas_boundary
  - object:控制标记, control_marker
  - relation:反射弹回, reflection_bounce
  - condition:同色定初向, color_match_sets_direction
  - condition:撞墙取色, wall_color_pickup
  - condition:缺口即出口, gap_is_exit

### docstring

```text
起点像素先朝侧墙上与它同色的那一格所在方向对角弹射，之后每撞一次彩色墙格就换用该墙格颜色
继续画，撞到墙上的黑色缺口则轨迹就此射出终止。

输入结构
- 画布最左列与最右列是两道竖直侧墙，由多种颜色的竖直色段拼成，其中夹杂个别黑色缺口格。
- 内部为黑色背景，有一个彩色起点像素；起点像素的颜色在两道侧墙中恰好只出现于其中一道墙上。
- 顶行开放。

规则
- 初始水平方向指向"含有与起点同色墙格"的那一侧，竖直方向恒为向上。
- 沿对角逐格前进，所经背景格涂成当前颜色，初始当前颜色为起点像素颜色。
- 当下一步将进入侧墙列时读取撞到的墙格：若为彩色，水平方向反转，且当前颜色改写为该
  墙格颜色，继续前进；若为黑色缺口，轨迹立即终止。
- 轨迹走出顶行自然结束；侧墙、缺口与起点像素保持不变。

关键洞察
- 侧墙身兼四职：出发方向的路标（颜色匹配）、反射面、实时改写轨迹颜色的调色板、以及
  决定轨迹终点的出口开关。不发现"初始方向由颜色匹配反推"与"轨迹颜色是状态而非常量"
  这两条隐式规则，任何单一直觉都无法同时吻合全部示例。
```

## 6. 隐形矩形的合法旋转

- 参考题目题号: 2 (e7639916)、6 (1a244afd)、19 (fc754716)
- tags:
  - operation:绘制边框, draw_frame
  - operation:旋转, rotate
  - object:标记像素, marker_pixel
  - object:枢轴像素, pivot_pixel
  - object:空心矩形, hollow_rect
  - relation:包围盒, bounding_box
  - condition:三点定矩形框, three_pts_define_rect
  - condition:唯一入界旋转, unique_inbounds_rotation

### docstring

```text
三个标记像素张成一个从未画出的矩形框，把它绕枢轴旋转到唯一能完整落入画布的角度后画出。

输入结构
- 均匀背景上恰有三个同色标记像素与一个异色枢轴像素。
- 三个标记像素位于其公共包围盒的边界上；枢轴像素在包围盒之外。
- 包围盒若原地画出也完整在画布内，但那不是答案。

规则
- 求三个标记像素的包围盒，得到一个矩形边框（只取一格粗的边框，不含内部）。
- 以枢轴像素为中心，分别尝试将该边框旋转 90、180、270 度；恰有一个角度使旋转后的
  边框完全落在画布内。
- 用标记颜色画出该唯一合法角度下的旋转边框。
- 三个标记像素与枢轴像素保持原位原色（新边框与它们重合处保留原色）。

关键洞察
- 参与旋转的矩形从未在输入中出现，它只由三个控制点生成；旋转角度也没有任何显式标记，
  而是由"旋转后必须整体入界"这一约束反推出的唯一解。原地画框（源直觉）与固定角度
  （单例直觉）都会在其他示例上失败。
```

## 7. 条纹伪装信使

- 参考题目题号: 16 (e26a3af2)、18 (d631b094)
- tags:
  - operation:去噪, denoise
  - operation:压缩, compress
  - object:条纹行列, stripe_line
  - object:噪声像素, noise_pixel
  - relation:主色占优, dominant_color
  - relation:包围盒, bounding_box
  - condition:偏离主色即信号, deviant_is_signal
  - condition:图底反转, figure_ground_inversion

### docstring

```text
输出不是修复后的条纹布面，而是把所有偏离本行（或本列）主色的像素当作信号，按其包围盒裁剪导出。

输入结构
- 画布是横条纹或竖条纹的整幅彩色布面，每条条纹线有唯一主色。
- 少量像素偏离其所在条纹线的主色：一部分使用布面之外的生僻色，另一部分伪装成其他
  条纹的颜色。

规则
- 分别按行、按列统计主色覆盖率，取明显更接近单色的方向为条纹方向。
- 在该方向上，凡与所在条纹线主色不同的像素都是信号像素，其余都是布面。
- 取全体信号像素的包围盒，输出该包围盒大小的网格：信号像素保留原色与相对位置，
  其余格为黑。

关键洞察
- 与"修复条纹"的直觉相反，这里布面才是要丢弃的部分，噪声才是要保留的信号；且信号
  不能按"颜色是否罕见"判定——伪装成条纹色的信号只有逐线与该线主色比对才能识破。
```

## 8. 图例定层叠加

- 参考题目题号: 12 (cf98881b)、15 (64efde09)
- tags:
  - operation:透明叠加, transparent_overlay
  - object:分隔列, separator_column
  - object:色彩面板, color_panel
  - object:控制标记, control_marker
  - relation:前后遮挡, front_back_occlusion
  - condition:图例序即层序, legend_order_is_depth

### docstring

```text
按画布左侧一列图例像素给出的顺序，而不是面板的空间排列顺序，把各透明面板从后到前叠加成一幅图。

输入结构
- 画布主体是若干个等大的图案面板，由灰色竖条分隔，每个面板只用一种前景色，黑格为透明。
- 画布最左侧有一列孤立的彩色图例像素，自上而下每格一色，颜色与各面板前景色一一对应；
  图例列与面板区之间以灰条隔开。
- 面板从左到右的排列顺序与图例顺序一般不一致。

规则
- 读取图例列颜色，自上而下依次代表从最前层到最后层。
- 以图例最下方颜色对应的面板为最底层，按图例自下而上的顺序把对应面板的非黑格依次
  覆盖上去。
- 输出为单个面板大小的合成图。

关键洞察
- 层序不再由面板的空间位置编码，而是被抽离成一段独立的控制序列；必须先识别出图例列
  是"指令"而非"图案"，再用它重排遮挡关系。按面板左右位置定深度的源直觉只在个别示例
  中碰巧成立。
```
