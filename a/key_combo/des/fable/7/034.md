## 1. 缺口链流

- tags:
  - operation:射线延伸, ray_extend
  - operation:洪泛填充, flood_fill
  - operation:重涂色, recolor
  - object:空心矩形, rectangular_frame
  - object:边框缺口, border_gap
  - object:种子像素, seed_pixel
  - relation:链式传播, chain_propagation
  - relation:访问序, visit_order
  - condition:缺口方向决定射线, gap_direction_determines_ray
  - condition:循环色板, cyclic_palette
- 参考题目题号: 551d5bf1, 7b0280bc, 9473c6fb, aaef0977

### docstring

```text
种子色从空心框的缺口逐框"流"过场景，水流每进入一个新框就把颜色推进到循环色板的下一色。

输入结构：
- 黑色背景上散布若干蓝色一格厚的空心矩形框，框之间互不接触。
- 恰有一个框（源框）内部含一个红色种子像素，源框边上恰有一个非角缺口。
- 其余每个框的边上有一个或两个非角缺口；部分框的缺口与任何流线都不对齐，是旁观者。

规则：
- 水流带着当前颜色（初始为红）从源框的缺口出发，沿垂直于缺口所在边、朝框外的方向直线前进，途经的背景格涂当前颜色。
- 若直线恰好穿过另一个框的某个缺口，水流进入该框：颜色先推进到循环色板 红、青、灰 的下一色，再用新颜色填满该框内部；若该框还有另一个缺口，水流以新颜色从那里继续直线流出，否则传播结束。
- 若直线撞上任何框壁或流出网格边缘，传播结束。
- 未被水流经过的框、缺口与背景保持不变。

关键洞察：
- 缺口不是缺陷而是门——只有恰好正对流线的缺口才接纳水流；答案由一条隐含的框间访问链决定，每个框的填色编码的是它在链中的序号而非它自身的任何属性，旁观框哪怕缺口朝向流线所在的行列，只要错开一格就分毫不动。
```

## 2. 半影模板

- tags:
  - operation:点对称补全, point_symmetry
  - operation:印章覆盖, stamp
  - object:中心标记, center_marker
  - object:邻域模板, neighborhood_template
  - object:孤立标记, isolated_marker
  - relation:模板与副本匹配, template_copy_match
  - condition:先补全后印章, complete_before_stamp
  - condition:忽略干扰项, ignore_distractors
- 参考题目题号: e729b7be, 39e1d7f9, bb52a14b, 642d658d

### docstring

```text
围绕范例黄心的残缺图案要先经180度点对称补全，才能整章印到每个孤立黄色标记上。

输入结构：
- 黑色背景上恰有一个黄色像素的5x5邻域内带有彩色图案（范例黄心），其余黄色像素的5x5邻域内没有任何彩色格（孤立标记）。
- 范例图案是某个绕黄心点对称的完整图形的"一半"：每一对以黄心为中心互为点对称的格子中，恰有一格被画出。
- 图中另散布少量与图案同色的干扰像素，它们都落在所有黄色像素的5x5窗口之外。

规则：
- 取范例黄心5x5窗口内的全部彩色格；对每个位于相对偏移d处的颜色，在偏移-d处补上同色，得到完整的点对称模板（黄心保持黄色）。
- 将补全后的完整模板以黄心对准的方式印到每个孤立黄色标记处，越出网格的部分裁掉。
- 范例邻域自身也被补全为完整模板；干扰像素保持不变。

关键洞察：
- 要盖的章从未被完整画出——范例只是真模板的一半投影，直接照抄画面上的邻域会让每个副本都缺一半；必须先由点对称把隐含的另一半恢复出来，副本处才会出现比范例本身更多的像素。
```

## 3. 序数转章

- tags:
  - operation:印章覆盖, stamp
  - operation:旋转, rotation
  - operation:排序, sort
  - object:模板精灵, template_sprite
  - object:孤立标记, isolated_marker
  - relation:扫描序, scan_order
  - condition:长轴决定扫描, longer_axis_determines_scan
  - condition:序数决定旋转, ordinal_determines_rotation
- 参考题目题号: 9473c6fb, 39e1d7f9, 7953d61e, c909285e

### docstring

```text
把灰框里的模板依次印到各个标记上，扫描序每前进一号，模板就多逆时针转90度。

输入结构：
- 黑色背景上有一个灰色完整矩形框，框内是一个3x3的多色模板，模板在四个旋转朝向下互不相同。
- 框外散布若干孤立的青色标记像素。

规则：
- 求全部青色标记的外接矩形：若其高不小于宽，标记按行优先扫描排序；否则按列优先。
- 第k个标记（k从0数起）处，以标记格为中心印上模板逆时针旋转 k 次90度后的副本（k对4取余），印章覆盖标记本身，越界部分裁掉。
- 灰框与其中的模板原样保留。

关键洞察：
- 各处印的不是同一个章——朝向随标记的扫描序号逐个转动；而给标记编号所用的扫描方向本身不是固定的行优先，要先从标记群外接矩形的长轴读出来，读错方向则几乎每个章的朝向都会错。
```

## 4. 绕墙年轮

- tags:
  - operation:洪泛填充, flood_fill
  - operation:重涂色, recolor
  - object:标记像素, marker_pixel
  - object:墙像素, wall_pixel
  - object:图例色带, legend_strip
  - relation:距离映射, distance_mapping
  - condition:测地距离, geodesic_distance
  - condition:循环色板, cyclic_palette
  - condition:障碍豁免, obstacle_exemption
- 参考题目题号: aaef0977, 319f2597, 58490d8a, 58c02a16

### docstring

```text
以孤立标记为源，按绕开红墙的最短步数给全图染上图例色带的循环年轮。

输入结构：
- 背景为最常见色；恰有一个孤立标记像素，其颜色等于图例色带的第一色。
- 若干红色像素连成的墙段散布图中，个别墙段围出完全封闭的死区。
- 某个角落有一个灰色小框，框内一行像素依序给出循环色带。

规则：
- 对红墙之外的每个格子，计算从标记出发、四连通且不得穿过红墙的最短路径长度。
- 距离为t的格子涂上色带中第t个颜色（对色带长度取余）；标记处距离为0，保持首色。
- 红墙像素保持红色；灰框及其中的色带原样保留；被墙围死而不可达的格子保持背景色。

关键洞察：
- 年轮不是以标记为中心的同心菱形——墙让波前绕行，墙背面的格子比同样直线距离的格子"更老"，死区则永远不上色；色序也不是可背诵的固定表，必须从图例色带里读，两处都照曼哈顿距离直觉硬套就会在墙后整片涂错。
```

## 5. 双尺度冗余修复

- tags:
  - operation:递归展开, recursive_expand
  - operation:补全, completion
  - object:种子掩码, seed_mask
  - object:污损块, corrupted_block
  - relation:自相似替换, self_similar_sub
  - relation:双尺度对应, cross_scale_correspondence
  - condition:块色对应种子格, block_color_matches_seed_cell
  - condition:前景背景分别替换, fg_bg_separate
- 参考题目题号: 58c02a16, c4d067a0, bb52a14b

### docstring

```text
大图是种子图案的自相似展开，用块内小图形反推种子，重建那个被整块涂平的污损块。

输入结构：
- 网格边长为 n 的平方（如 25 = 5x5），划分为 n x n 个大小为 n x n 的块。
- 每个完好的块内部都画着同一个 n x n 掩码图案：掩码格用该块的主色，其余格用背景色；一部分块的主色为甲色，其余块的主色为乙色。
- 恰有一个块被污损：整块被涂成第三种颜色，原有图案与主色不可见。

规则：
- 从任一完好块读出 n x n 掩码；这个掩码同时也是块级布局——掩码格所在位置对应甲色块，其余位置对应乙色块。
- 按掩码查出污损块的位置属于甲色块还是乙色块，以相应主色在该块内重画掩码图案。
- 输出修复后的完整展开图，其余部分保持不变。

关键洞察：
- 同一图案在两个尺度上被编码了两遍——块内的小图形与块色的大布局互为备份；污损抹掉的是像素尺度的信息，但答案藏在块尺度里（反之亦然），只有意识到"图案即布局"这层自指，才能同时恢复污损块的主色与内部花纹。
```

## 6. 图例测谎裁剪

- tags:
  - operation:计数, counting
  - operation:裁剪, crop
  - object:图例框, legend_box
  - object:前景对象, foreground_object
  - relation:颜色索引行, color_keyed_row
  - condition:计数不符指认目标, mismatch_identifies_target
  - condition:忽略干扰项, ignore_distractors
- 参考题目题号: 58490d8a, c8b7cc0f, c909285e, f8b3ba0a

### docstring

```text
图例框逐行申报各颜色的对象数量，恰有一行说谎，输出说谎颜色那个唯一对象的裁剪。

输入结构：
- 黑色背景上有一个矩形图例框：每行最左是一个键色像素，右侧每隔一格一个点，点数即该颜色"申报的对象数量"。
- 框外散布各键色的若干互不相触的单色对象；恰有一种颜色的实际对象数与其申报点数不符，且该颜色在场景中实际只有一个对象。
- 其他颜色中也可能有恰好一个对象的，但它们的申报都如实。

规则：
- 对每个键色，数图例框外互不相触的同色对象个数，与该行点数逐一比对。
- 找出唯一账目不符的键色；输出该键色唯一对象外接矩形内的子网格。

关键洞察：
- 图例在这里不是等待填写的答案，而是一份需要核验的口供；"只有一个对象的颜色"是诱饵——如实申报的颜色也可以只有一个对象，唯一能指认目标的是申报与实数的差额，计数本身只是指针，真正的输出是被指认对象的裁剪。
```

## 7. 熔铸配平框

- tags:
  - operation:计数, counting
  - operation:排序, sorting
  - operation:拼接, assembly
  - object:前景对象, foreground_object
  - relation:频率排序, frequency_ordering
  - condition:像素数定尺寸, pixel_count_determines_size
  - condition:最方正框, most_balanced_frame
  - condition:顺时针排布, clockwise_layout
- 参考题目题号: 83b6b474, f8b3ba0a, 9473c6fb

### docstring

```text
把所有前景像素熔成一圈一格厚的最方正空心框，框上颜色按像素数从多到少顺时针连续排布。

输入结构：
- 黑色背景上散布若干单色对象，颜色有数种，形状与位置任意。
- 各颜色的像素总数互不相同；前景像素总数 N 恰能写成某个一格厚矩形框的周长 2h+2w-4，且使 |h-w| 最小的 (h,w) 唯一。

规则：
- 统计每种颜色的像素总数；输出一个 h x w 网格，边界一圈为框、内部为黑，其中 (h,w) 是周长等于 N 且高宽最接近的尺寸。
- 从左上角出发沿框顺时针走一圈，颜色按像素总数从多到少依次铺设，每种颜色占据与其像素数相等的一段连续格子。

关键洞察：
- 对象的形状和位置全是幌子——它们只是各颜色的料仓；输出的形状不从任何输入对象复制而来，而是由像素总量反解出的配平框，框上的分段则是频率排名沿周界展开的顺时针条形图，既要想到"周长等于总数"，又要想到"最方正"这一挑选准则。
```

## 8. 交替门最短路

- tags:
  - operation:最短路径, shortest_path
  - operation:重涂色, recolor
  - object:格网, lattice
  - object:门缺口, door_gap
  - object:终端房间, terminal_room
  - relation:图结构, graph_structure
  - relation:分隔线划分, separator_partition
  - condition:门色交替, alternating_door_colors
  - condition:最短路径选择, shortest_path_selection
- 参考题目题号: 39e1d7f9, 7b0280bc, 551d5bf1, 16de56c4

### docstring

```text
在被隔墙划分的房间迷宫里，找一条黄青门色必须交替的最少过门路线，涂亮沿途房间与门。

输入结构：
- 网格被完整的横竖灰色分隔线划成规则的房间阵列。
- 部分相邻房间之间的隔墙上开有一格宽的门，每扇门被涂成黄色或青色。
- 两个房间内各含一个红色标记像素，是起点与终点；其余房间为空。

规则：
- 把房间看作节点、门看作边；合法路线要求相继穿过的门颜色严格交替（黄青黄青…或青黄青黄…，首门颜色不限）。
- 在所有合法路线中取过门数最少的一条（输入保证唯一）；把路线经过的每个房间内部涂绿（红色标记保留原样），路线穿过的每扇门涂灰。
- 其余房间、门与隔墙保持不变。

关键洞察：
- 房间图上纯粹的最短路是陷阱——空间上最近的那条路会在连续同色门处被节拍卡死；真正的距离定义在"门色交替"这条约束之上，合法的最优路线有时必须绕远，只按迷宫直觉走位会得到一条更短但非法的诱饵路径。
```
