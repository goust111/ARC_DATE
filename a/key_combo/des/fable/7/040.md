## 1. 边缘坐标标记生成的隐形矩形层叠

- tags:
  - operation:填充, fill
  - operation:擦除, erase
  - object:边缘标记, edge_marker
  - object:矩形, rectangle
  - relation:行列对齐, row_column_alignment
  - relation:层叠顺序, layer_stack
  - condition:同色标记定界, same_color_markers_bound
  - condition:面积小者在上, smaller_area_on_top
- 参考题目题号: 14 (af902bf9)、11 (75b8110e)、17 (445eab21)

### docstring

```text
用边缘上的同色坐标标记还原从未画出的实心矩形，并按面积从大到小依次叠放。

输入结构
- 背景为黑色，除最上一行与最左一列外，画布内部完全为空。
- 顶行与左列上散布若干彩色标记像素；每种颜色恰好出现四次：顶行两个、左列两个。
- 各颜色对应矩形的面积互不相同，且示例中矩形之间存在多重重叠。

规则
- 对每种颜色，顶行的两个标记给出两条列边界，左列的两个标记给出两条行边界，
  四条边界围成一个实心矩形（含边界行列）。
- 在同尺寸的空白画布上画出所有矩形：按面积从大到小的顺序先后绘制，
  面积小者后画、覆盖在先画者之上。
- 顶行与左列的标记像素在输出中全部擦除。

关键洞察
- 矩形本体在输入中从未出现，画面上只有它在顶行与左列上的行列投影；
  重叠处的可见性不由位置或颜色决定，而由所有矩形的面积排序决定，
  必须先解码全部矩形再排序，才能确定任何一个重叠格的颜色。
```

## 2. 隐形王步路径筛除精灵

- tags:
  - operation:连线, connect
  - operation:擦除, erase
  - operation:筛选, filtering
  - object:起点标记, start_marker
  - object:终点标记, end_marker
  - object:精灵体, sprite
  - relation:路径穿越, path_crossing
  - condition:切比雪夫最短路径, chebyshev_shortest
  - condition:路径不显现, path_invisible
- 参考题目题号: 8 (992798f6)、9 (c62e2108)、3 (3194b014)

### docstring

```text
沿蓝到红的规范最短王步路径扫过画布，被路径触碰的精灵整体消失，路径本身不画。

输入结构
- 背景画布上恰有一个蓝色像素与一个红色像素，二者行与列均不相同。
- 画布上另散布若干互不接触的单色精灵（多种颜色、多种形状）。
- 示例中存在位于蓝红包围盒内但不在路径上的幸存精灵，
  也存在仅被"对角段在前"这一种路径形态触碰的精灵。

规则
- 在脑中构造从蓝到红的规范路径：先沿对角方向连续行进，
  直到与红点同行或同列，再沿直线行进至红点；
  路径格为途经的全部中间格，不含蓝红两端。
- 凡与路径格集合相交的精灵，整体擦除为背景。
- 蓝红像素与未被触碰的精灵原样保留；路径在输出中不涂任何颜色。

关键洞察
- 决定精灵去留的路径在输入与输出中都不可见，必须凭规则构造；
  "对角在前、直行在后"的精确形态无法直接看到，
  只能从哪些精灵幸存、哪些消失中反推出来，
  而"擦除包围盒内所有精灵"的直觉解释会在后续示例上失败。
```

## 3. 凹口互补对接

- tags:
  - operation:形状匹配, shape_match
  - operation:旋转, rotate
  - operation:翻转, flip
  - operation:对接拼合, docking
  - operation:裁剪, crop
  - object:底座, base
  - object:孔洞槽位, hole_slot
  - object:拼块, piece
  - condition:互补唯一, unique_complement
  - condition:忽略干扰项, ignore_distractors
- 参考题目题号: 13 (20270e3b)、18 (898e7135)、12 (be94b721)

### docstring

```text
把唯一能在某个朝向下与底座凹口互补的拼块转正嵌入，删除其余拼块并紧致裁剪。

输入结构
- 画布上有一个大的单色底座，其边缘被挖去一个不规则的背景色凹口；
  凹口形状非矩形且无旋转对称。
- 画布其他位置散布若干小拼块，颜色各异；
  恰有一个拼块经过旋转或翻转后与凹口形状完全互补，
  干扰块与它尺寸相同、形状只差一两格。

规则
- 在八个朝向下将每个拼块的形状与凹口的负形逐一比对，找出唯一吻合者。
- 将该拼块按吻合朝向嵌入凹口，保留拼块自身的颜色；其余拼块全部删除。
- 输出为嵌合后整体（底座加嵌入块）的紧致裁剪。

关键洞察
- 没有任何连接点颜色提示对接位置：槽位由底座的负形给出，
  匹配必须在"缺口"与"实块"之间跨正负形进行；
  干扰块与凹口大小一致、仅差一两格，逐格核对朝向不可省略。
```

## 4. 散点计数定周期条纹

- tags:
  - operation:计数, counting
  - operation:擦除, erase
  - operation:射线延伸, ray_extend
  - object:空心矩形, hollow_rectangle
  - object:标记像素, marker_pixel
  - object:周期条纹, periodic_stripe
  - relation:计数决定尺寸, count_determines_size
  - condition:框定颜色相位方向, frame_sets_color_phase_direction
- 参考题目题号: 5 (6a980be1)、6 (902510d5)、19 (50cb2852)

### docstring

```text
把空心框与散点全部擦除，代之以整幅周期条纹——周期由散点个数给出，颜色、走向与相位由框给出。

输入结构
- 背景画布上有一个单色空心矩形框，框内部为空。
- 框外散布 n 个同色的孤立单像素，散点色不同于框色。
- 框的宽与高不相等。

规则
- 数出散点的个数 n。
- 若框的宽大于高，条纹为一格厚的整行横条，第一条锚定在框上边缘所在行；
  若高大于宽，条纹为整列竖条，锚定在框左边缘所在列。
- 以框色绘制条纹，从锚定行（列）出发向两个方向周期延伸铺满画布，
  相邻条纹的行（列）号之差为 n。
- 框与散点在输出中全部擦除，其余均为背景。

关键洞察
- 框既不是要保留的边界，也不是要填充的容器：
  它一身供出条纹的颜色、走向与相位三个参数；
  而看似噪声的散点，其位置与颜色都无意义，
  唯一的贡献是它们的数目 n，即条纹的周期。
```

## 5. 排名链上的幽灵矩形

- tags:
  - operation:重涂色, recolor
  - operation:填充, fill
  - operation:比较, compare
  - object:空心矩形, hollow_rectangle
  - object:封闭区域, enclosed_region
  - relation:面积比较, area_comparison
  - relation:排名循环映射, rank_chain_mapping
  - condition:颜色尺寸双重传递, color_and_size_transferred
  - condition:保留边框涂内部, keep_border_fill_inside
- 参考题目题号: 17 (445eab21)、19 (50cb2852)、4 (890034e9)

### docstring

```text
每个空心框的内部嵌入一个幽灵矩形：其尺寸与颜色都取自内部面积恰低一名的那个框，链尾最小框内部保持为空。

输入结构
- 背景上散布三到五个互不接触的单色空心矩形框，颜色互不相同。
- 各框内部的行数与列数都严格互不相同且可全序排列，
  内部面积随之严格递增；所有框内部均为背景色。
- 框的空间摆放顺序与面积排名顺序不一致。

规则
- 按内部面积把所有框排成一条从小到大的链。
- 每个框保持边框原色；除最小框外，
  在每个框的内部以内部区域左上角对齐，嵌入一个实心矩形：
  其行列尺寸等于面积恰低一名的框的内部行列尺寸，
  颜色等于那个框的边框色。
- 面积最小的框在链上没有来源，内部保持背景不变。

关键洞察
- 出现在每个框内部的既不是它自己的颜色也不是固定色，
  而是"下一个更小框的内部"这一从未以该颜色画出过的投影；
  颜色与尺寸沿看不见的面积排名链同时传递，
  必须先给所有框完成排序，才能确定任何一个内部的内容，
  而链尾的空内部正是整条传递链方向的唯一泄露。
```

## 6. 残缺模板的镜像修复双向印章

- tags:
  - operation:对称补全, symmetry_completion
  - operation:印章覆盖, stamp
  - operation:像素放大, pixel_upscale
  - operation:翻转, flip
  - object:模板区, template_region
  - object:掩码标记, mask_marker
  - object:分隔行, separator_row
  - relation:面板对应, panel_correspondence
  - condition:标记色选印章朝向, marker_color_selects_orientation
- 参考题目题号: 1 (b4a43f3b)、2 (ad7e01d0)、18 (898e7135)

### docstring

```text
先用上下镜像补全被打洞的上方模板，再按下方掩码把补全后的模板印成大图：红点印原样，蓝点印左右翻转。

输入结构
- 一条整行灰色分隔行把画布分成上下两个同尺寸区域。
- 上方是一个本应上下轴对称的多色模板，但若干格被挖成背景色，
  破坏了对称；每个被挖格的镜像位置保持完好。
- 下方是同尺寸掩码，只含背景、红色标记点与蓝色标记点。

规则
- 先修复模板：每个被挖格取其上下镜像位置的颜色，得到完整模板。
- 输出为按掩码逐格分块的大网格，每块与模板同尺寸：
  红点对应的块印补全后的模板原样，
  蓝点对应的块印补全后模板的左右翻转版本，
  其余块全为背景。

关键洞察
- 直接拿画面上的残缺模板去印必然处处缺格：
  真正的印章在输入中从未完整出现，须先由上下对称修复得到；
  两种标记色区分的不是印什么颜色，而是印章的朝向，
  且左右翻转与用于修复的上下对称互不重合，翻转版本无法靠对称性混过。
```

## 7. 自引用印章

- tags:
  - operation:印章覆盖, stamp
  - operation:连通检测, connected_component_detection
  - operation:筛选, filtering
  - object:最大连通分量, largest_component
  - object:源图案, source_pattern
  - relation:像素到块映射, pixel_block_mapping
  - condition:最大分量既是模板又是掩码, largest_component_as_template_and_mask
- 参考题目题号: 2 (ad7e01d0)、3 (3194b014)、12 (be94b721)

### docstring

```text
输入中唯一最大的连通体既充当印章的位置掩码又充当印章内容的过滤判据：只在它自己的像素位上，印下只剩它自己的净化图案。

输入结构
- 输入为一个小网格，含背景与若干颜色互不相同的 4 连通单色分量。
- 恰有一个像素数唯一最大的分量；其余分量都是较小的干扰体。

规则
- 生成净化图案：把输入中不属于最大分量的前景像素全部改为背景，
  最大分量原样保留。
- 输出按输入的行列数逐格分块，每块与输入同尺寸：
  输入中属于最大分量的每个像素，其对应输出块印上整幅净化图案；
  其余块全为背景。

关键洞察
- 选块的不是任何固定的控制颜色，而是"最大连通体"这一结构角色；
  且被印下的也不是原输入而是它的净化版——
  小分量在位置层与内容层被同一判据剔除两次，
  按颜色选块或印原图的两条捷径都会在示例上留下多余的块或多余的像素。
```

## 8. 闸门控制条

- tags:
  - operation:平移, translate
  - operation:重涂色, recolor
  - object:控制条, control_bar
  - object:缺口, gap
  - object:精灵体, sprite
  - relation:跨度对齐, span_alignment
  - condition:跨度落入缺口方可通过, fits_through_gap
- 参考题目题号: 9 (c62e2108)、16 (fbf15a0b)、13 (20270e3b)

### docstring

```text
所有精灵朝控制条坠落：跨度完全落入缺口投影的精灵穿过缺口坠到对侧边缘并被染成条色，其余被条挡停且颜色不变。

输入结构
- 画布上有一根一格厚的整行（或整列）控制条，
  条上恰有一段连续的背景色缺口。
- 条的一侧散布若干互不接触的单色精灵，
  精灵沿条方向的投影互不重叠；条与各精灵颜色互不相同。

规则
- 每个精灵沿垂直于条的方向朝条平移，平行方向位置不变。
- 若精灵在平行于条方向上的投影完全落在缺口的投影之内，
  它穿过缺口继续移动，直到贴上对侧画布边缘停下，
  并且整个精灵被重新涂成控制条的颜色。
- 否则它在条前贴条停下，保持原色。
- 控制条与缺口在输出中保持不动。

关键洞察
- 条不是墙也不只是终点线，而是一道闸：
  精灵的归宿由自身跨度与缺口跨度的包含关系逐个判定，
  且穿过与否同时改写位置与颜色两个通道——
  "全部停在条前"或"全部保持原色"的单通道解释都会在示例上失败。
```
