## 1. 镜厅级联

- tags:
  - operation:镜像, reflect
  - operation:重涂色, recolor
  - object:稀疏标记线, sparse_marker_line
  - object:前景图案, foreground_motif
  - relation:级联反射, cascaded_reflection
  - condition:逐轴换色, per_axis_recolor
- 参考题目: 14、9、6

### docstring

```text
把主图案沿一排互相平行的稀疏标记线逐级反射，每一级副本涂成对应标记线的颜色。

输入结构
- 黑色背景上有一个多格单色主图案。
- 主图案同一侧分布着若干条互相平行的稀疏虚线（点状标记线），每条一种颜色，线与线的间距互不相等。

规则
- 保留原图案与全部标记线。
- 将主图案关于距它最近的标记线做轴反射，得到第一级副本，涂成该线的颜色。
- 再将第一级副本关于下一条标记线反射，得到第二级副本，涂成第二条线的颜色，依此级联，直到越过最后一条线为止。
- 副本超出画布的部分裁剪丢弃。

关键洞察
- 每一级反射的对象是上一级副本而不是原图案；由于线距互不相等，副本既不是等步长平移，
  也不是"原图各自关于每条线反射"的结果，只有级联反射能同时解释所有示例。
```

## 2. 失真缩略图

- tags:
  - operation:分块映射, block_mapping
  - operation:压缩, compress
  - operation:重涂色, recolor
  - operation:擦除, erase
  - object:分隔行, divider_row
  - object:缩略图面板, thumbnail_panel
  - relation:整倍分辨率对应, integer_scale_alignment
  - relation:跨分辨率找茬, cross_resolution_diff
  - condition:不符之处即改令, mismatch_is_command
- 参考题目: 3、8、18

### docstring

```text
分隔线下方的小面板伪装成大面板的逐块缩略图，只有与真实缩略图不符的格子才是改令，按不符处修改大面板对应粗块。

输入结构
- 一条贯穿整行的灰色分隔线把网格分成上下两个面板。
- 上面板是黑底像素画，行列数恰为下面板的整数倍；按整数倍划分后，上面板每个粗块内的前景像素至多使用一种颜色。
- 下面板与粗块网格同规格，大部分格子如实等于对应粗块的前景色（空块对应黑格），少数格子与实况不符。

规则
- 逐块计算上面板的真实缩略图，与下面板逐格比对。
- 相符的格子：对应粗块保持原样。
- 不符且下面板格为颜色 c：把对应粗块内的全部前景像素改涂为 c，块内形状不变。
- 不符且下面板格为黑色：把对应粗块整块清成黑色。
- 输出只保留修改后的上面板，尺寸与上面板相同。

关键洞察
- 小面板乍看只是大面板的忠实压缩副本、毫无信息量；真正的指令藏在它与真实缩略图的分歧处——
  必须先自己算出"本该是什么"，再用找出的差异反向驱动全分辨率画面的修改。
```

## 3. 无形裂纹

- tags:
  - operation:滑动, slide
  - operation:擦除, erase
  - object:边缘标记, edge_marker
  - object:实心矩形, solid_rectangle
  - relation:隐形切割线, invisible_cut_line
  - condition:穿过内部才裂开, interior_crossing_splits
- 参考题目: 4、6、16

### docstring

```text
从边缘标记发出一条从不画出的直线，凡被这条线穿过内部的实心矩形都沿线裂开，两半各向外错开一格。

输入结构
- 黑色背景上散布若干互不相邻的实心单色矩形。
- 网格边缘上有一到两个单像素青色标记，各自垂直于所在边指向网格内部。
- 沿标记方向的整条直线上，有的矩形被它穿过内部，有的矩形与它只擦边或不相交。

规则
- 每个标记确定一条贯穿全网格的直线（横向标记给一行，纵向标记给一列），这条线本身不画出。
- 被该线穿过内部的矩形：删去落在线上的那一排像素，线一侧的像素整体垂直于线向外移一格，
  另一侧向相反方向移一格。
- 只擦边或不相交的矩形保持原样。
- 输出中删除边缘标记，直线经过的背景不留任何痕迹。

关键洞察
- 标记既不画射线也不移动自身：它生成一条从未被画出的切割线，其效果只体现在被切开矩形的分离上；
  诱导解"沿标记画一条彩线"无法解释任何示例的输出。
```

## 4. 双钥印章

- tags:
  - operation:图案印章, stamp_glyph
  - operation:旋转, rotate
  - object:控制像素, control_pixel
  - object:朝向像素, orientation_pixel
  - object:字形字典, glyph_dictionary
  - relation:双通道编码, dual_channel_encoding
  - condition:颜色定形灰点定向, color_shape_gray_direction
- 参考题目: 1、16、20

### docstring

```text
把每个彩色控制像素替换成它对应的 3×3 字形，字形贴入时的朝向由紧邻的灰色像素决定。

输入结构
- 黑色背景上散布单像素彩色控制点，每个控制点的四邻中恰有一个灰色像素。
- 每种控制点颜色对应一个固定的非对称 3×3 字形；部分输入在角落展示某颜色字形的基准样例，
  样例右下方带一个同色标签像素。

规则
- 字形的基准朝向为"上"；将字形旋转，使基准方向指向该控制点旁灰色像素所在的方位。
- 以控制点为中心贴入旋转后的 3×3 字形，灰色像素被字形覆盖消失，越界部分裁剪。
- 输出中移除字形样例及其标签像素。

关键洞察
- 每个控制点携带两条独立信息：颜色查字形字典决定"画什么"，灰色邻居决定"朝哪转"；
  只有同时解码两个通道，四个方向上的示例才能全部吻合，只按颜色盖章会在朝向上系统性出错。
```

## 5. 洞数为钟

- tags:
  - operation:旋转, rotate
  - operation:计数, counting
  - object:封闭洞, enclosed_hole
  - object:枢轴像素, pivot_pixel
  - relation:绕点旋转, rotation_around_pivot
  - condition:洞数定角度, hole_count_sets_angle
  - condition:枢轴位置定方向, pivot_side_sets_direction
- 参考题目: 13、15、20

### docstring

```text
以每个形状专属的灰色枢轴为中心，把形状旋转"洞数×四分之一圈"，枢轴在洞内转逆时针、在形外转顺时针。

输入结构
- 黑色背景上有若干互不接触的单色块状形状，每个形状围出零到三个封闭的背景洞。
- 每个形状恰好配一个灰色像素：要么落在它的某个洞里，要么贴在它的外侧。
- 保证旋转结果不越界、不与其他形状或枢轴重叠。

规则
- 数出该形状封闭洞的个数 n。
- 以灰色像素为枢轴，把整个形状旋转 n 个四分之一圈：灰像素在洞内则逆时针，在形状外侧则顺时针。
- 形状原位置清为背景，灰色枢轴原地保留；n 为零的形状原地不动。

关键洞察
- 洞承担双重角色：洞的个数是旋转的角度，枢轴是否躲在洞里决定旋转的方向；
  把洞只当作形状外观、或把灰点只当作装饰，都无法同时解释各示例在角度与方向上的差异。
```

## 6. 破镜重圆

- tags:
  - operation:滑动, slide
  - object:锯齿碎片, jagged_fragment
  - relation:位移向量, displacement_vec
  - relation:互补咬合, complementary_interlock
  - condition:并集成实心矩形, union_forms_solid_rect
- 参考题目: 4、5、19

### docstring

```text
每种颜色的两块锯齿碎片中，让较小块平移嵌进较大块拼成实心矩形，并把补进去的那块换成灰色示人。

输入结构
- 黑色背景上散布若干单色碎片，每种颜色恰好两块，彼此分离。
- 同色两块的锯齿边缘互补：存在唯一的平移，使两块互不重叠地拼成一个无洞的实心矩形。
- 任何一块单独的包围盒都不等于合成后的矩形，互补齿深浅不一并相互咬进对方包围盒。
- 不同颜色的碎片位置交错，干扰配对的视觉判断。

规则
- 对每种颜色，保持较大块颜色与位置不动，把较小块整体平移到唯一能使两块合成实心矩形的位置。
- 平移后的较小块改涂灰色，使矩形内嵌着一道锯齿状的灰色补片。
- 输出网格尺寸与输入相同，其余背景不变。

关键洞察
- 目标位置没有画在任何地方，判定标准是一个隐含的全局形状约束——"并集为实心矩形"；
  由于任一单块的包围盒都不是答案、且补片必须以灰色精确画出锯齿轮廓，
  "直接填满某块的包围盒"或"贴边靠拢"之类的捷径全部失效，只有互补齿完全咬合的那个平移成立。
```

## 7. 残迹定容

- tags:
  - operation:对称补全, symmetry_completion
  - operation:镜像, reflect
  - operation:旋转, rotate
  - operation:重涂色, recolor
  - object:象限图案, quadrant_motif
  - object:单像素残迹, single_pixel_relic
  - relation:残迹检索变换, relic_indexes_transform
  - relation:位置为钥颜色为漆, position_keys_color_paints
  - condition:逐象限独立选变换, per_quadrant_transform
- 参考题目: 2、9、1、5

### docstring

```text
用左上象限的图案补全其余三个象限：每个象限的摆放变换由其仅存残迹像素的"位置"反推，整份副本再统一涂成残迹的"颜色"。

输入结构
- 偶数边长的方形网格，左上象限画有一个非对称的多色图案。
- 其余三个象限几乎全黑，每个象限只残留一个彩色像素（残迹）；残迹颜色不在图案的用色之中。
- 每个残缺象限中，候选变换（平移复制、左右镜像、上下镜像、180° 旋转）里恰有一种
  会让图案的前景恰好覆盖残迹所在的格子。

规则
- 对每个残缺象限逐一处理：把左上图案的前景掩膜按四种候选变换各试摆入该象限，
  找出唯一使残迹位置被前景覆盖的那一种。
- 用该变换摆放图案的完整副本填满这个象限，并把整份副本统一改涂为残迹的颜色。
- 三个象限各自独立选取变换与颜色，左上象限原样保留。

关键洞察
- 残迹是一枚双重钥匙：它的位置是检索变换的指纹，它的颜色是该象限副本的漆色；
  在原图案里寻找残迹颜色的对应像素是死路——颜色通道与匹配无关，只有按前景形状逐一试摆才能锁定变换，
  而三个象限可以各用不同的变换，任何"整体一种对称"的读法都会在某个残迹上露馅。
```

## 8. 隔板译色

- tags:
  - operation:补全, inpaint
  - operation:颜色转译, color_translation
  - object:分隔行, divider_row
  - object:双面板, dual_panel
  - relation:同构异色, same_structure_diff_palette
  - condition:对侧几何加本侧色表, counterpart_fills_holes
- 参考题目: 8、11、7

### docstring

```text
分隔线两侧是同一幅非周期图案的两种配色版本，各缺不同的洞；用对侧面板的几何加本侧的色表补全全部黑洞。

输入结构
- 一条贯穿整行的灰色分隔线把网格分成上下两个同尺寸面板。
- 两面板逐格对齐后结构完全相同，但使用两套不同的调色板，颜色一一对应。
- 每个面板各有若干黑色缺损格，两面板的缺损位置互不重合。
- 图案本身没有周期性或对称性可用。

规则
- 用两面板都完好的对齐格子归纳出上下颜色的一一对应表。
- 上面板的每个黑格：取下面板同位置的颜色，经对应表译回上面板的颜色后填入。
- 下面板的黑格同理反向翻译填补。
- 分隔线与其余像素原样保留，输出为整幅修复后的网格。

关键洞察
- 单个面板内部无规律可依，周期补全与对称补全都会失败；缺失信息全部藏在另一块"变了色的同一幅画"里，
  而翻译词典本身没有给出，必须从两面板对齐的完好格子中现场归纳。
```

## 9. 摆锤点名

- tags:
  - operation:路径模拟, path_simulation
  - operation:交替转向, alternating_turn
  - operation:重涂色, recolor
  - object:色序图例, color_sequence_legend
  - object:起点标记, start_marker
  - object:灰色障碍, gray_obstacle
  - relation:撞击次序定色, hit_order_assigns_color
  - condition:色序用尽即停, sequence_exhausted_stops
- 参考题目: 6、17、10

### docstring

```text
一枚从不画出的粒子从起点直行，在障碍与边界处左右交替转向，被撞到的障碍按撞击次序依次涂上题头色序中的颜色。

输入结构
- 左上角一行 2×2 单色小方块自左向右给出一个颜色序列。
- 网格边缘有一个单像素起点标记，垂直于所在边指向网格内部。
- 场内散布若干灰色单像素障碍。

规则
- 粒子从起点沿所指方向直行，路径不画出。
- 迎面撞上障碍时：把该障碍涂成色序中的下一个颜色，然后粒子在障碍前一格转向 90° 继续走。
- 撞到网格边界时同样转向 90°，但不消耗颜色。
- 转向方向自第一次碰撞起左右交替（逆时针、顺时针、逆时针……），障碍碰撞与边界碰撞都计入交替。
- 色序用尽时粒子立即消失；未被撞到的障碍保持灰色，色序方块与起点标记原样保留。

关键洞察
- 障碍获得的颜色与它的位置和外观无关，只取决于一条从未画出的折线路径访问它的次序；
  而路径的形状又被"所有碰撞统一左右交替"的隐藏节拍控制，漏数一次不涂色的边界反弹，整条路径就会错开。
```
