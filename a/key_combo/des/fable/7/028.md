## 1. 瓦片指针链

- 参考题目题号: 16 (4e45f183)、2 (5961cc34)、10 (a096bf4d)
- tags:
  - operation:级联遍历, chain_traversal
  - operation:降采样, downsample
  - object:格子瓦片, lattice_tile
  - object:瓦片碎片, tile_fragment
  - object:起始标记, start_marker
  - relation:质心偏移即指针, centroid_offset_as_pointer
  - condition:唯一色起点, unique_color_start
  - condition:越界或重访即停, stop_on_exit_or_revisit

### docstring

```text
沿瓦片内碎片质心方向构成的隐藏指针链遍历瓦片阵列，输出被访问格的粗网格图。

输入结构:
- 分隔线将画布划分为 m×n 个 5×5 瓦片阵列，瓦片内部有统一底色。
- 每个瓦片内部有一小块标记色碎片; 除一个瓦片的碎片为红色(起点)外，其余碎片同为蓝色。
- 碎片形状各异，其质心相对瓦片几何中心的偏移落在八个方向之一，且不与中心重合。

规则:
- 对每个瓦片，取碎片质心相对瓦片几何中心的行列偏移符号，得到指向相邻瓦片(含对角)的方向。
- 从红色碎片所在瓦片出发，沿各瓦片的指向逐格跳转; 当下一步越出阵列或到达已访问过的瓦片时停止。
- 输出 m×n 粗网格: 被访问过的瓦片(含起点)对应格涂红，其余格为黑。

关键洞察:
- 碎片质心方向不是槽位归类，而是指向下一瓦片的指针; 整个阵列是一张隐藏的有向图，
  答案由从唯一入口出发的一条链决定，未被链触及的指针全部是干扰。
```

## 2. 双轴换色修复

- 参考题目题号: 6 (dc0a314f)、12 (2de01db2)
- tags:
  - operation:镜像, mirror
  - operation:重涂色, recolor
  - operation:裁剪, crop
  - object:遮挡块, occluder
  - object:被遮区域, occluded_region
  - relation:置换对称, symmetry_up_to_color_swap
  - relation:双轴分工, dual_axis_partition
  - condition:置换需自证, swap_inferred_from_visible
  - condition:镜像源被自身污染, mirror_source_self_occluded

### docstring

```text
用两条各自伴随不同颜色对换的对称轴恢复被遮方块，其中一条轴的镜像源被遮挡自身污染。

输入结构:
- 方形场景中有一个唯一的纯色正方形遮挡块，遮挡色不在场景其他处出现。
- 除遮挡块外，场景关于竖直中轴满足"位置镜像+颜色对换 σv"，关于水平中轴满足"位置镜像+颜色对换 σh"。
- σv 与 σh 各为一对颜色互换(其余颜色自映射)，两者不同且逐例不同，需从可见区域推断。
- 遮挡块靠近竖直中轴，使其关于竖直中轴的镜像区域与遮挡块自身部分重叠。

规则:
- 由远离遮挡的可见对应点对分别推断 σv 与 σh。
- 被遮方块中，竖直镜像源未被污染的部分，用水平翻转并施加 σv 恢复。
- 镜像源落回遮挡块内部的部分，改用竖直翻转并施加 σh 从水平镜像位置恢复。
- 仅输出恢复出的方块。

关键洞察:
- 既不是普通镜像对称也不是单一换色对称——每条轴绑定各自的颜色对换;
  且必须发现首选轴的镜像源被遮挡块自身咬住，才会启用第二条轴分区补全。
```

## 3. 负空间笔画

- 参考题目题号: 8 (a64e4611)、20 (136b0064)
- tags:
  - operation:解码指令, decode_instructions
  - operation:连线, draw_polyline
  - object:背景走廊, background_corridor
  - object:杂色前景, clutter_foreground
  - object:起始标记, start_marker
  - relation:顺序读取, sequential_reading
  - condition:负空间即指令, negative_space_as_instruction

### docstring

```text
把杂色场中隐藏的纯背景直条依次翻译成笔画，从灰色起点画出一条折线。

输入结构:
- 网格由主导背景色和一种密集杂色构成，另有一个灰色起点像素。
- 杂色场中隐藏着若干条一格宽、互不接触的纯背景直条(水平或竖直);
  随机背景空隙短而零碎，不与直条混淆。

规则:
- 找出所有长度达到阈值(≥4)的纯背景直条，按其最上最左端点的行优先顺序排序。
- 从灰色起点开始逐条执行: 水平直条表示向右走其长度步，竖直直条表示向下走其长度步，段与段首尾相接。
- 在输入网格上把整条折线(含起点)涂成绿色，其余保持原样，作为输出。

关键洞察:
- 指令从未被画出——要读的对象是画面的负空间;
  看似"给走廊涂色"的场景实际是一段用空白书写的程序。
```

## 4. 深度调色叠加

- 参考题目题号: 17 (e99362f0)、9 (85b81ff1)、13 (e509e548)
- tags:
  - operation:透明叠加, transparent_overlay
  - operation:计数, counting
  - operation:排序, sorting
  - object:面板, panel
  - object:十字分隔线, cross_separator
  - relation:重叠深度分层, overlap_depth_strata
  - relation:双计数互索引, dual_count_cross_indexing
  - condition:体量排名定层色, size_rank_colors_depth

### docstring

```text
把四个面板对齐成重叠深度图，再用各面板前景像素数的升序排名作为调色板，给每个重叠深度层着色。

输入结构:
- 一条整行整列的灰色十字把网格分成四个等大面板。
- 每个面板由一种透明背景色和一种前景色组成，四个面板的前景像素数两两不同，前景区域相互部分重叠。

规则:
- 去掉十字，把四个面板按局部坐标对齐。
- 对每个局部坐标格统计有多少个面板在该格为前景，记为深度 j (0~4)。
- j=0 的格涂黑; j≥1 的格，涂"前景像素数在四个面板中排第 j 小"的那个面板的前景色。
- 输出单面板大小。

关键洞察:
- 输出既不是覆盖叠放也不是取并集: 颜色边界跟随重叠等深线走;
  而深度到颜色的映射不是任意码表，而是由面板自身的体量排序给出——
  逐格重叠计数与整板像素计数这两个互不相干的计数结构互为索引。
  按体量顺序叠放面板的覆盖式解法与真规则不等价，会在部分格上出错。
```

## 5. 残迹弹射反推

- 参考题目题号: 18 (e179c5f4)、19 (3f7978a0)、2 (5961cc34)
- tags:
  - operation:射线延伸, ray_extension
  - operation:反推, inverse_inference
  - object:残迹像素, remnant_pixel
  - object:障碍横条, obstacle_bar
  - object:反弹路径, bouncing_path
  - relation:边界反射, boundary_reflection
  - condition:唯一一致起点, unique_consistent_start
  - condition:对象只留残迹, object_left_as_remnants

### docstring

```text
从零散残迹反推出唯一能覆盖它们的弹射对角路径并补全。

输入结构:
- 黑色背景上散布若干青色残迹像素，另有一条灰色水平障碍条悬在网格内部。
- 存在唯一一条对角弹射路径: 从底边某格出发斜向上走，遇左右边界水平反向，
  从下方撞到灰条时竖直反向(转为向下)，走出上边界或底边界即结束;
  青色残迹是该路径途经格的子集。

规则:
- 在所有"底边起点 × 初始左右方向"的候选路径中，找出恰好覆盖全部青色残迹的那一条。
- 将该路径途经的所有格(含残迹格)涂成蓝色，灰条保持不变，其余保持黑色，作为输出。

关键洞察:
- 没有给出起点，弹射规则须反着用: 残迹是从未完整画出的路径的采样，
  答案由"哪条合法路径能解释所有证据"唯一决定，障碍条使心算弹道无法只看两侧墙。
```

## 6. 嵌套奇偶搬移

- 参考题目题号: 3 (a04b2602)、4 (e9afcf9a)、12 (2de01db2)
- tags:
  - operation:搬移, relocate
  - operation:旋转, rotate
  - object:空心矩形, hollow_rectangle
  - object:内容像素, content_pixel
  - relation:嵌套深度, nesting_depth
  - relation:点对称, point_symmetry
  - condition:奇偶决定是否搬移, parity_gates_relocation
  - condition:忽略框外干扰, ignore_outside_distractors

### docstring

```text
按空心矩形嵌套深度的奇偶，把奇数深度环带内的内容像素绕本环带外框中心做 180 度点对称搬移。

输入结构:
- 黑色背景上有若干黄色空心矩形框，框与框之间要么不相交要么严格嵌套，嵌套深度最多三层。
- 各环带区域内散布内容像素(颜色可各异)，框外也有内容像素。

规则:
- 对每个非框格计算包含它的矩形框个数(嵌套深度)。
- 深度为奇数的环带: 其中每个内容像素移动到关于其最内层包含框 bbox 中心的点对称位置，
  原位置变黑(构造保证目标位置仍在同一环带内且互不冲突)。
- 深度为偶数(含 0，即框外)的内容像素保持不动; 黄色框始终不变。

关键洞察:
- 只看单层示例会总结成"每个框内部图案整体旋转 180 度";
  嵌套示例中只有奇数层在动、偶数层原样保留，
  暴露真正的开关是包含计数的奇偶性，且操作是逐像素点对称搬移而非重涂。
```

## 7. 轨迹反编译

- 参考题目题号: 20 (136b0064)、11 (b20f7c8b)
- tags:
  - operation:反编译, decompile
  - operation:查表替换, lookup_replace
  - object:折线, polyline
  - object:字形指令, glyph_instruction
  - object:起始标记, start_marker
  - relation:编码映射, encoding_map
  - condition:转弯定分段, turns_delimit_segments
  - condition:码表跨例归纳, codebook_induced_across_examples

### docstring

```text
把画布上的一条折线从起点起逐段反编译成字形指令列，输出程序而非图形。

输入结构:
- 画布上有一条单色简单折线(不自交、每格至多两个路径邻居)，其一端被灰色像素标记为起点。
- 折线由水平段与竖直段交替构成，每段的方向与步长都取自一个跨示例固定的小码表，
  每种(方向, 步长)对应一个固定的 3×3 字形。

规则:
- 从灰色端点出发沿折线走到另一端，在每个转弯处切分，得到有序的段列表。
- 把每段的方向与步长查码表换成对应字形。
- 输出一个 3 列宽的窄网格: 按段顺序自上而下摆放字形，字形间隔一行背景。

关键洞察:
- 这是绘图题的因果反演: 输入是执行结果，要求还原指令序列;
  码表没有图例，只能从各训练对的"图形-程序"对应中归纳，
  而唯一合法的切分依据是折线自身的转弯。
```

## 8. 局部互补印章

- 参考题目题号: 1 (0692e18c)、13 (e509e548)
- tags:
  - operation:像素放大, pixel_scaling
  - operation:印章覆盖, stamp_overlay
  - object:前景像素, foreground_pixel
  - object:邻域掩码, neighborhood_mask
  - relation:局部自互补, local_self_complement
  - condition:每格印章各异, per_cell_stamp

### docstring

```text
把每个前景像素放大成 3×3 块，块内图案是该像素自身 3×3 邻域的互补掩码。

输入结构:
- 黑底网格上散布单一前景色像素，可形成小连通团。
- 输出为输入的 3 倍尺寸。

规则:
- 输入为黑的格，其对应 3×3 输出块整块为黑。
- 输入为前景的格，取以它为中心的 3×3 邻域(越界按黑处理):
  邻域中为黑的位置在输出块中涂前景色，为前景的位置(含中心自身)在输出块中保持黑。
- 孤立前景像素因此得到一圈八邻环，团内像素的输出块则各不相同。

关键洞察:
- 画面强烈暗示经典的"整图作全局印章"分形题，但各块图案不一致戳穿了它;
  印章不是全局的，每个像素盖的是自己邻域的否定，邻居越多的格在输出中反而越暗。
```
