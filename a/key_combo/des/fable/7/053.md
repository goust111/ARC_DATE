## 1. 拉伸倍数即颜色

- 参考题目: `ce8d95cc`, `9385bd28`, `3ee1011a`
- tags:
  - operation:压缩, compression
  - operation:重涂色, recolor
  - object:重复行, dup_row
  - object:颜色图例, color_legend
  - relation:相邻相同, adjacent_identical
  - condition:重复次数映射颜色, run_length_maps_color
  - condition:图例自编码, legend_self_encoding

### docstring

```text
折叠竖直拉伸的灰色图案，并按每行的拉伸倍数查图例上色。

输入结构：
- 黑色背景；主体是一个仅沿竖直方向被拉伸的灰色图案：原始小图案的每一行
  被连续复制 1~4 次，且原始图案相邻行互不相同（保证折叠唯一）。
- 主体右侧隔一列空白有一组水平图例短条：每条为单色，长度互不相同（1~4），
  长度为 k 的短条给出"复制 k 次"对应的输出颜色；图例条的上下排列顺序无规律。

规则：
- 自上而下把相邻完全相同的行折叠为一行，并记录该段的行数 k。
- 输出为折叠后的图案（不含图例区），其中每个折叠行内的灰色像素重涂为
  图例中长度为 k 的短条的颜色；黑色背景保持不变。
- 列方向不折叠。

关键洞察：
- 拉伸倍数在普通压缩题里是被丢弃的冗余，这里它是颜色信息的载体；
  而图例条自身的长度就是键，图例的空间顺序毫无意义。
```

## 2. 等宽入桶与连锁溢出

- 参考题目: `18447a8d`, `beb8660c`, `b7249182`, `825aa9e9`
- tags:
  - operation:形状匹配, shape_match
  - operation:滑动, sliding
  - object:横条, horizontal_bar
  - object:空心矩形, hollow_rectangle
  - relation:长度开口配对, length_matches_opening
  - condition:容量满则溢出, overflow_on_full
  - condition:按初始高度定序, order_by_initial_height

### docstring

```text
把每根横条装进内宽与其长度相等的容器；容器装满后，多余的条溢出到最窄的
仍有空位的更宽容器。

输入结构：
- 黑色背景；下半部有若干开口朝上的单色空心矩形容器（左右壁与底各一格厚），
  内宽互不相同，内部高度（容量）各异。
- 上半部悬浮若干一格厚的彩色水平短条；短条的水平位置与其归属容器无关；
  同一长度的短条可以有多根。

规则：
- 短条按初始位置从低到高依次处理。
- 每根短条优先进入内宽等于其长度的容器：水平对齐内腔，落到容器内最低的空行上。
- 若该容器已被先前的条装满（条数达到内部高度），这根条溢出：改投内宽大于
  其长度、仍有空位的容器中最窄的那个，靠左壁对齐落到最低空行。
- 清除短条的原位置；容器与网格其余部分不变。

关键洞察：
- 分配依据是长度与内宽的精确相等而非重力路径，且容量限制引发连锁溢出——
  后处理的条的去向取决于先前所有条造成的占用状态；恰好悬在某容器上方的条
  会诱导"竖直下落"的错误假设。
```

## 3. 突起双重选择器折叠

- 参考题目: `7ee1c6ea`, `f1cefba8`, `67a3c6ac`
- tags:
  - operation:镜像, mirror
  - object:矩形边框, rectangular_frame
  - object:叶状突起, leaf_protrusion
  - relation:突起定轴, leaf_selects_axis
  - relation:同色匹配, same_color_matching
  - condition:仅落背景格, paint_background_only

### docstring

```text
按框壁突起的位置与颜色，把框内同色像素沿突起所在行/列对折复制。

输入结构：
- 黑色背景上有若干一格厚的灰色矩形框，框内散布多种颜色的像素。
- 每个框外壁贴有一到两个单像素彩色突起；突起颜色必与框内某种像素颜色相同，
  同一框上不同突起颜色互异。

规则：
- 突起贴在左壁或右壁：对称轴为突起所在的行；贴在上壁或下壁：对称轴为
  突起所在的列。
- 对每个突起：框内与它同色的像素以该轴做镜像复制（原像素保留，镜像落点为
  新增像素）；镜像落点超出框内区域的丢弃，落在已有非黑像素上的不绘制。
- 框内其他颜色的像素、框本身与突起保持不变。

关键洞察：
- 突起是双重选择器：位置选轴、颜色选参与镜像的像素集合；对称轴通常偏离
  框中心，"关于框中心对称补全"是第一个示例埋下的错误假设。
```

## 4. 像素数编程的弹射路径

- 参考题目: `891232d6`, `6ffbe589`
- tags:
  - operation:射线延伸, ray_extend
  - operation:路径绘制, path_drawing
  - object:障碍物, obstacle
  - object:边缘标记, edge_marker
  - relation:投射, projection
  - condition:像素数编码转向, pixel_count_encodes_turn

### docstring

```text
从边缘标记发射射线，每次撞上障碍物就按其像素数顺时针偏转相应倍数的 90 度。

输入结构：
- 黑色背景；网格边缘有一个红色起点像素。
- 内部散布若干灰色 4-连通障碍物，每个障碍物含 1~3 个像素，彼此互不相邻。

规则：
- 从起点垂直于所在边向网格内部发射射线，途经的黑格涂成黄色。
- 当前进方向的下一格属于某障碍物时，不进入该格，而在当前格按该障碍物的
  像素数顺时针转向：1 像素转 90 度，2 像素转 180 度，3 像素转 270 度，
  然后继续前进。
- 射线走出网格边缘时结束，出口处最后一个格涂红色；障碍物保持灰色不变。

关键洞察：
- 偏转角不取决于障碍物的形状、位置或撞击面，而由其像素数编码；只含单像素
  障碍的示例会诱导"总是右转"的反弹假设。
```

## 5. 交叉基数自指对齐

- 参考题目: `e376de54`, `beb8660c`, `22a4bbc2`
- tags:
  - operation:对齐, align
  - operation:裁剪, trim
  - object:线段, line_segment
  - relation:正交双族, orthogonal_families
  - condition:交叉基数选参考, cross_count_selects_reference

### docstring

```text
两族正交线段各自对齐到本族的参考线，而每族的参考由另一族的线段数量选出。

输入结构：
- 黑色背景；若干条水平线段各占一行，若干条竖直线段各占一列，颜色互异，
  端点参差。
- 水平线段共 H 条，竖直线段共 V 条（H≠V）。恰有一条水平线段长度等于 V，
  恰有一条竖直线段长度等于 H，它们即两族的参考线。
- 两条参考线都不是本族的最长、最短，也不在本族排列的中间位置；此外任一族
  中不存在长度等于本族条数的线段。

规则：
- 水平族其余线段保持所在行与颜色，起止列改写为与水平参考线一致
  （不足延长，多余裁掉）。
- 竖直族其余线段保持所在列与颜色，起止行改写为与竖直参考线一致。
- 两条参考线与背景保持不变。

关键洞察：
- 参考线不由长短极值、位置或颜色选出，而由交叉的基数自指选出——水平族的
  参考是"长度恰等于竖直线段条数"的那条，反之亦然；"长度等于本族条数"是
  刻意布下的诱饵。
```

## 6. 正交投影重建与面积层序

- 参考题目: `9385bd28`, `ea9794b1`, `3ee1011a`
- tags:
  - operation:填充, fill
  - object:投影带, projection_band
  - object:矩形, rectangle
  - relation:正交投影, orthogonal_projection
  - relation:图层优先级, layer_priority
  - condition:面积定层序, area_determines_order

### docstring

```text
由顶行与左列的同色投影段重建各彩色实心矩形，重叠处面积小者覆盖面积大者。

输入结构：
- 网格第一行与第一列是投影带，其余内部区域全黑。
- 每种颜色在顶行恰形成一段连续色段，在左列也恰形成一段连续色段；
  各矩形面积互不相同，且至少有两个矩形重叠。

规则：
- 颜色 c 的矩形由左列 c 段给出的行区间与顶行 c 段给出的列区间的
  笛卡尔积确定。
- 在内部区域画出所有实心矩形；两矩形重叠处，显示面积较小者的颜色。
- 顶行与左列的投影带原样保留。

关键洞察：
- 画面上从未画出任何矩形，只有它们的两条正交投影；层序既不按颜色编号也
  不按位置，而由面积决定——小矩形永远浮在大矩形之上。
```
