## 1. 缺席朝向补全

- 参考题目: 10, 17, 18
- tags:
  - operation:模板匹配, template_matching
  - operation:旋转, rotate
  - operation:镜像, mirror
  - object:精灵体, sprite
  - relation:朝向轨道, orientation_orbit
  - relation:形状匹配, shape_matching
  - condition:缺失变体输出, missing_variant_output
  - condition:重复朝向定色, duplicate_orientation_sets_color

### docstring

```text
枚举母版形状的全部旋转反射朝向，输出画面中从未出现的那个朝向，并用重复朝向对象的共享颜色绘制。

输入结构：
- 黑色背景上散布八个互不相邻的精灵体，都是同一个无任何自对称的母版在旋转与反射（共八种朝向）下的变体。
- 画面恰好出现其中七种朝向，且其中一种朝向出现两次（共八个对象）。
- 对象颜色互不相同，唯有重复朝向的两个对象共享同一颜色。

规则：
- 提取任一对象的归一化包围盒掩码作为母版，生成其八种旋转反射朝向。
- 将每个对象归一化后与八种朝向逐一匹配，统计每种朝向的出现次数。
- 输出唯一从未出现的朝向的最小包围盒图案，颜色取重复朝向对象的共享颜色。

关键洞察：
- 答案对象从未被画出，它是朝向轨道中缺席的成员；重复出现的对象既是诱饵
 （易误答"输出重复的那个"），又是输出颜色的钥匙。
```

## 2. 克罗内克积换序

- 参考题目: 15, 11
- tags:
  - operation:克罗内克积, kronecker_product
  - operation:因式分解, factorization
  - object:块阵列, block_array
  - object:二值掩码, binary_mask
  - relation:两级嵌套, two_scale_nesting
  - condition:交换因子次序, swap_factor_order

### docstring

```text
把两层嵌套的克罗内克积网格因式分解为外层布局掩码与内层瓦片掩码，再按交换次序重新乘起来输出。

输入结构：
- 输入是单一前景色网格，构造为 A⊗B：外层布局掩码 A 的每个前景格被整块替换为
  内层瓦片掩码 B，背景格替换为全黑块。
- A 与 B 的行列尺寸互素，使双层分解唯一；二者形状不同、均无平移周期、不可再分解。

规则：
- 从行列方向的块状周期结构中恢复外层掩码 A 与内层掩码 B。
- 构造 B⊗A：以 B 为外层布局，把 B 的每个前景格整块替换为掩码 A，前景色不变。
- 输出与输入尺寸相同。

关键洞察：
- 输入输出同尺寸，看似只是像素重排；真正的规则是识别乘积结构并交换因子次序——
  克罗内克积不满足交换律，B⊗A 与 A⊗B 是不同的画面。
```

## 3. 封闭容积排名色循环

- 参考题目: 4, 5, 6
- tags:
  - operation:重涂色, recolor
  - operation:计数, counting
  - operation:排序, sort
  - operation:洪泛填充, flood_fill
  - object:空心对象, hollow_object
  - object:封闭区域, enclosed_region
  - relation:容积排名, capacity_ranking
  - condition:封闭性定资格, closure_determines_eligibility
  - condition:排名循环换色, rank_cycle_recolor

### docstring

```text
只有内腔完全封闭的空心对象参与颜色循环，按内腔容积排名把颜色循环传递一位。

输入结构：
- 黑色背景上若干颜色互异的空心对象。
- 多数对象的内腔被边框完全包围（封闭）；少数对象边框带一格宽的缺口，
  内腔与外部背景连通（不封闭），缺口肉眼不显眼。
- 封闭对象的内腔容积互不相同，且对象自身像素数的排序与容积排序故意不一致。

规则：
- 先用洪泛判定每个对象的内腔是否封闭；带缺口的对象整体保持原样，不参与后续任何步骤。
- 封闭对象按内腔黑格数从小到大排序，每个整体重涂为容积排名恰高一位的对象的颜色，
  容积最大者取容积最小者的颜色。
- 内腔黑格与背景保持不变。

关键洞察：
- 存在三层入口：先发现参与资格由封闭性决定（把缺口对象混入循环会得出自相矛盾的映射），
  再发现计量键是内腔容积而非对象像素数，最后发现颜色映射不是固定码表，
  而是由容积排名生成的循环置换。
```

## 4. 隐形镜轴反推

- 参考题目: 2, 12, 17
- tags:
  - operation:镜像, mirror
  - operation:连线, draw_line
  - object:精灵体, sprite
  - object:隐形轴, hidden_axis
  - relation:形状配对, shape_pairing
  - relation:镜像与平移判别, mirror_vs_translation
  - condition:同色假对陷阱, same_color_fake_pair
  - condition:仅镜像对画轴, axis_only_for_mirror_pairs

### docstring

```text
按归一化形状把精灵体两两配对，为互为镜像的对画出那条从未出现的镜轴（水平、垂直或对角），纯平移的对不画。

输入结构：
- 黑色背景上偶数个精灵体，形状均无自对称。
- 配对依据是形状全等（允许镜像等价）；颜色不可靠——存在同色但形状不同、
  并非一对的陷阱对象。
- 每对要么关于一条水平、垂直或 45 度对角的隐形轴互为镜像，要么只是彼此的平移拷贝。
- 构造保证镜轴恰落在整格上；青色未在输入中出现，保留作轴色。

规则：
- 将所有对象按归一化掩码（含镜像变体）两两配对。
- 对每对判别是镜像关系还是平移关系。
- 镜像对根据两者的相对姿态确定轴向（水平、垂直或对角），在两对象合并包围盒
  范围内画出青色轴线；平移对不添加任何东西；原有对象全部保留。

关键洞察：
- 镜子本身从未被画出，只能由成对残迹反推；颜色是诱饵——按颜色配对会把陷阱对象
  凑成假对；只取两对象中点而不校验镜像姿态，会给平移对画出多余的轴，
  也定错对角轴的方向。
```

## 5. 蓄水预算溢流连锁

- 参考题目: 7, 6, 1
- tags:
  - operation:重力下落, gravity_drop
  - operation:计数, counting
  - object:水像素, water_pixel
  - object:盆地, basin
  - object:蓄水条, reservoir_bar
  - relation:溢流连锁, overflow_chain
  - condition:水量预算, water_budget
  - condition:较低盆沿溢出, lower_rim_overflow

### docstring

```text
把顶部蓄水条中数好的水量从注水口倒下，沿地形逐盆装满并向较低盆沿溢流，画出最终静止水面。

输入结构：
- 灰色像素构成静止地形，形成若干高度、容积不同的开口朝上盆地，盆地之间由台阶相连。
- 网格顶行附近有一段蓝色蓄水条，其正下方即注水列，条的长度即水量总数。
- 构造保证水面始终以整层落定，不出现半层。

规则：
- 蓄水条消失，等量的水从注水列落入正下方第一个盆地。
- 水在盆内从最低处逐层填满；水位到达较低一侧盆沿时，多余的水越过该侧继续下落，
  进入下一个盆地，依此连锁进行。
- 水量用尽后输出：地形不变，水以蓝色静止层显示，蓄水条位置恢复为背景。

关键洞察：
- 水的去向不能逐盆独立判断：每个盆地留住多少取决于自身容积与较低盆沿的高度，
  剩余水量沿溢流方向连锁传递；蓄水条的长度是整条因果链的总预算。
```

## 6. 相位错动域标记

- 参考题目: 3, 16, 10
- tags:
  - operation:对称检测, symmetry_detect
  - operation:重涂色, recolor
  - object:平移周期图案, translation_pattern
  - object:相位错动域, phase_shift_domain
  - object:孤立杂点, isolated_noise_pixel
  - relation:平移对称, translational_symmetry
  - condition:统一向量拟合矩形, coherent_shift_rectangle
  - condition:忽略孤立杂点, ignore_isolated_noise

### docstring

```text
在整幅双向周期图案中找出被整体错动了相位的矩形域并整格涂红，随机杂点保持原样。

输入结构：
- 画布铺满一个双向平移周期的多色图案。
- 存在一个矩形域，其内容是同一图案整体平移一个固定非周期向量的结果（相位错动域）；
  域内部分格子可能恰好与原图案重合。
- 另有少量孤立杂点，颜色与周期图案不符，但彼此不相邻、不成结构。

规则：
- 检测全局平移周期，逐格找出与周期图案不符的格子。
- 若一批不符格能被一个统一的平移向量解释并聚成实心矩形，该矩形即错动域：
  把域内全部格子（包括碰巧与原图案重合的格子）涂红。
- 孤立杂点无法被统一向量解释，保持不变。

关键洞察：
- 诱饵是"把所有不符像素都当缺陷标出"：错动域内有些格子局部看完全正常，
  只有把不符格拟合成一个整体平移的矩形，才能补上这些看不见的成员，
  并把真正的随机杂点排除在外。
```
