## 1. 隐形围墙洪泛

- tags:
  - operation:洪泛填充, flood_fill
  - operation:结构推断, structure_inference
  - object:角标记像素, corner_marker
  - object:虚拟边框, virtual_frame
  - object:种子像素, seed_pixel
  - relation:四角共构矩形, corners_define_rect
  - condition:不完整角组无效, incomplete_corners_invalid
- 参考题目题号：5、20、2、7

### docstring

```text
从种子出发洪泛填充黑色背景，但要把仅由四个同色角点暗示、从未画出的矩形边框当作不可穿越的墙。

输入结构：
- 黑色背景网格上散布若干组彩色角点；凡四个同色像素恰好构成一个轴对齐矩形的四角，即定义一个矩形。
- 存在同色像素不足四个、或无法构成矩形四角的干扰组，它们不定义任何矩形。
- 恰有一个蓝色种子像素，可能位于某个矩形内部，也可能在所有矩形之外。

规则：
- 每个被定义的矩形，其整圈周界格（含四角之间从未画出的边）视为墙，洪泛不可进入也不可穿过。
- 从种子出发沿四邻方向遍历所有可达的黑色格，将它们涂成蓝色。
- 角点像素、墙上格与不可达的黑色格保持原样；墙格在输出中仍是黑色，不被画出。

关键洞察：
- 阻挡洪泛的墙在输入和输出中都不存在实体像素，它只能由"四个同色角点共构一个矩形"这一关系推断出来；不足四角的同色像素只是诱饵，不产生墙；种子在矩形内的示例会戳破"填充所有外部背景"的表象。
```

## 2. 周期偏差即取样指针

- tags:
  - operation:周期推断, periodic_inference
  - operation:异常检测, anomaly_detection
  - operation:裁剪, crop
  - object:周期表, periodic_table
  - object:标记模板, stencil_marker
  - relation:偏差构形, deviation_configuration
  - condition:偏差色属调色板, deviant_in_palette
- 参考题目题号：16、8、2

### docstring

```text
在一张全局周期色表中找出所有与周期规律不符的格子，它们的位置拼成一个 L 形取样模板，输出模板所指的 3x3 区域。

输入结构：
- 网格整体按一个可从可见部分唯一推断的二维周期规律着色。
- 少数格子的颜色与周期规律不符；这些格子使用的颜色同样来自周期调色板，因此单看颜色无法识别它们。
- 全部不符格恰好占据某个 3x3 区域右侧一列与下侧一行紧邻的格位，构成 L 形模板；该 3x3 区域自身完好无偏差。

规则：
- 由可见格推断周期规律，逐格比对找出所有偏差格。
- 把偏差格的位置整体解读为 L 形取样模板，定位其左上方的 3x3 区域。
- 输出即该 3x3 区域的原样裁剪。

关键洞察：
- 偏差格没有任何专用颜色或局部特征，它们只作为"与全局周期规律的不一致"存在；取样模板本身从未被直接画出，必须先重建周期规律才能看见这枚指针。
```

## 3. 缺角为向的对接

- tags:
  - operation:射线延伸, ray_extend
  - operation:对接, dock
  - operation:重涂色, recolor
  - operation:擦除, erase
  - object:L形精灵, L_sprite
  - object:空心矩形, hollow_rect
  - relation:缺角指示方向, missing_corner_as_direction
  - condition:命中容器才入驻, hit_container_to_dock
- 参考题目题号：9、14、18、7、2

### docstring

```text
每个缺角 L 形精灵沿其缺角所指的对角方向发出一条看不见的射线，命中哪个空心矩形，就搬进那个矩形的内部并改穿矩形的颜色。

输入结构：
- 黑色背景上有若干 4x4 的单色空心矩形框，内部为 2x2 空腔，框色互不相同。
- 另有若干单色 L 形精灵，各占 2x2 包围盒中的三格，颜色与所有框不同。
- 以缺角在 2x2 包围盒中所处的角为方向（如缺右上角则向右上），从缺角格沿该对角方向延伸，恰好命中至多一个矩形框。

规则：
- 对每个精灵，从缺角位置沿其对角方向逐格延伸，找到第一个被命中的空心矩形。
- 将精灵按原方向放入该矩形的 2x2 空腔，并重涂为矩形框的颜色；空腔中对应精灵缺角的一格保持黑色。
- 从原位置擦除精灵；未被任何射线命中的矩形框保持空腔为空。

关键洞察：
- 精灵与容器之间的配对既不看距离也不看颜色，唯一的纽带是缺角这一"负空间"所编码的对角朝向；连接两者的射线从未被画出，示例中按最近的框或直觉配色都会得到错误配对。
```

## 4. 配重定坠距

- tags:
  - operation:滑动, slide
  - operation:计数, count
  - operation:配对, pairing
  - object:下落体, faller
  - object:配重块, weight
  - relation:同色跨物传参, cross_object_parameter
  - condition:碰撞提前停止, collision_early_stop
- 参考题目题号：11、18、10

### docstring

```text
悬空物体各自竖直下落，落距等于底边上与其同色的配重块的面积，途中撞上已落定物体或底边则提前停下，配重块随之消失。

输入结构：
- 黑色背景；上方悬浮若干互不同色的单色 4 连通物体（下落体）。
- 底边上停靠着若干实心小块（配重块），每块颜色与某个下落体相同，配重块面积互不相同。
- 下落体之间的列范围可能重叠。

规则：
- 先将全部配重块从画面移除。
- 按初始位置从低到高依次处理每个下落体：令其竖直下落 k 行，k 为其同色配重块的像素数；若途中会与已落定物体或底边重叠，则停在其上方，落距不足 k 也不再继续。
- 下落体形状与颜色保持不变。

关键洞察：
- 落距不由下落体自身的任何属性决定，而是由画面另一处同色配重块的面积远程给定；第一个示例恰好与纯重力一致，是诱饵，后续示例中部分物体因配额未用尽而悬停半空，戳破"单纯重力下落"的表象。
```

## 5. 抽样反推波纹染色

- tags:
  - operation:洪泛填充, flood_fill
  - operation:周期推断, periodic_inference
  - operation:循环填充, periodic_fill
  - object:样本像素, sample_pixel
  - object:种子像素, seed_pixel
  - object:障碍物, blocker
  - relation:距离取模映射, distance_modulo_mapping
  - condition:绕障波前, wavefront_around_blockers
- 参考题目题号：5、8、14、16

### docstring

```text
散落的彩色像素是同一张"波纹图"的抽样，先由它们反推出按通行距离循环的色环，再以种子为源把整张波纹图补全。

输入结构：
- 主区域为黑色背景，含一个红色种子像素、若干灰色障碍块，以及散布的少量彩色样本像素。
- 每个样本像素的颜色等于最终答案中该格应有的颜色。
- 样本的通行距离足以唯一确定循环周期 k 与色序（含种子处的第 0 色）。

规则：
- 以种子为源，沿四邻方向仅经非障碍格计算每格的绕障最短步数 d（种子自身 d 为 0）。
- 由各样本像素的 d 与颜色恢复"d mod k -> 颜色"的循环表。
- 将每个可达格（含样本格与种子格）染成表中第 d mod k 个颜色；障碍与不可达格保持不变。

关键洞察：
- 散点既不是噪声也不是障碍，而是待求答案自身的抽样；必须先意识到它们的组织规律是"绕过障碍的真实通行距离"而非几何直线距离——障碍背后样本的"迟到"相位是识别该度量的关键——才能反推色环并整体展开。
```

## 6. 框壁色针驱动的内容轮换

- tags:
  - operation:对接, dock
  - operation:图指针解读, pointer_decoding
  - operation:擦除, erase
  - object:空心矩形, hollow_rect
  - object:色针像素, color_pin
  - object:内容图案, cavity_pattern
  - relation:颜色即有向边, color_as_directed_edge
  - condition:指针环整体轮换, cycle_shift_contents
- 参考题目题号：20、7、18、3、2

### docstring

```text
每个空心矩形框的框壁上嵌着一枚异色像素，它不是要修复的瑕疵，而是指向"下一个框"的颜色指针，所有框的内容物沿指针构成的环整体轮换一步。

输入结构：
- 黑色背景上有若干互不同色的 1 格厚空心矩形框，空腔尺寸相同；每个空腔内有一个形状各异的小图案。
- 每个框的框壁恰有一格不是本框颜色，而是另一个框的颜色；这些"色针"合起来使全体框构成一个单一有向环。
- 色针在框壁上的位置各不相同，与任何几何方向无关。

规则：
- 把每枚色针读作有向边"本框 -> 与色针同色的框"，得到全体框的一个环。
- 将每个框空腔中的图案原样（不旋转不变色）搬入其指针所指框的空腔，按图案在原空腔中的相对位置放置；所有框同时轮换一步。
- 输出中每枚色针被修复为本框颜色，框本身位置不变。

关键洞察：
- 入口藏在框壁那格杂色上——按去噪直觉它是该被修掉的缺陷（输出中它确实被修复了，进一步伪装），但内容物的去向既不看距离、不看大小也不看颜色相似度，唯一的解释是把杂色读作指向同色框的有向边，再发现全部边闭合成环、内容随环轮换；同一枚像素先当路标用完，再被抹去。
```
