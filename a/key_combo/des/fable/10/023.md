## 1. 补墙锁孔

- 参考题目题号：1（20270e3b）、4（845d6e51）、13（67c52801）
- tags:
  - operation:对接拼合, docking
  - operation:旋转, rotate
  - operation:裁剪, crop
  - object:墙体空洞, wall_hole
  - object:锁点像素, lock_pixel
  - object:精灵体, sprite
  - relation:负形全等, negative_shape_congruence
  - condition:锁点重合定姿态, lock_overlap_fixes_pose

### docstring

```text
将散落的精灵旋转翻折后嵌入墙上与之全等的空洞，姿态由锁点像素重合唯一确定，输出修复后的墙。

输入结构
- 网格有统一背景色；一块大的实心单色矩形墙，内部挖有若干背景空洞，其中部分空洞
  在旋转反射下形状全等，仅锁点方位不同。
- 每个空洞边沿的墙面上恰有一个锁点色像素与洞四邻接。
- 墙外散布与空洞数量相同的单色精灵，每个精灵由主体和恰一个附着在主体边缘外侧的
  锁点色像素组成。

规则
- 对每个精灵，在旋转与镜像等价下找出唯一一个空洞，使精灵主体恰好填满空洞，且精灵
  的锁点像素恰好落在该洞旁的墙面锁点上。
- 以该唯一姿态将精灵主体填入空洞，保留精灵自身颜色；重合的两个锁点涂回墙色。
- 清除墙外全部精灵，输出为沿墙的紧致裁剪。

关键洞察
- 空洞是负形，匹配须在旋转反射等价下进行；仅凭形状可能有多个候选洞，锁点的相对
  方位才把"哪个洞、哪种姿态"同时钉死。
```

## 2. 角射线的隐形交点

- 参考题目题号：18（27a28665）、19（6e19193c）、9（8d510a79）
- tags:
  - operation:射线延伸, ray_cast
  - object:掩码图案, mask_pattern
  - object:角点, corner_cell
  - object:交叉点, intersection_pixel
  - relation:角占据决定方向, corner_occupancy_determines_direction
  - condition:异掩码射线交叉标记, cross_mask_intersection_marked

### docstring

```text
每个3×3掩码从被占据的角向外发射对角射线，输出只保留不同掩码射线两两交叉的格。

输入结构
- 黑底网格上散布若干 3×3 五像素单色掩码，颜色互异，彼此相距较远。
- 部分掩码占据边中点却不占据角（诱饵）；各掩码的角占据数覆盖多种档位。

规则
- 对每个掩码，检查其 3×3 包围盒四角是否被占据；每个被占据的角沿向外对角方向发出
  一条射线直到网格边缘，途中遇到其他掩码像素则在其前一格停止；未占据的角不发射。
- 输出为同尺寸全黑网格，仅将同时处于两条来自不同掩码的射线路径上的格涂红。
- 掩码与射线本身均不出现在输出中。

关键洞察
- 输出与输入表面毫无相似——答案是一个从未被画出的射线系统的交点集；射线方向不是
  统一约定，而是由每个掩码自身的角占据模式读出，非角像素只凑形状不贡献方向。
```

## 3. 带相位的刻度阵列

- 参考题目题号：10（34cfa167）、3（a406ac07）、20（ad7e01d0）
- tags:
  - operation:周期延伸, periodic_extend
  - operation:印章覆盖, stamp
  - object:刻度像素, tick_pixel
  - object:印章精灵, stamp_sprite
  - relation:行列交叉, row_col_intersection
  - relation:相位偏移, phase_offset
  - condition:前两刻度定周期, first_two_ticks_define_period

### docstring

```text
将上缘与左缘各自只给出前两项的周期刻度外推成整条边，再以给定精灵相对最近交叉点的
偏移为全局相位，在每个交叉点的同偏移处印一份拷贝。

输入结构
- 黑底网格；顶行有两个同色刻度像素，最左列有两个另一色刻度像素，分别是两组等差
  刻度的前两项。
- 网格内部另有一个小的多色精灵，其中心并不落在任何行列交叉点上，而是偏离最近
  交叉点一个小于半周期的偏移向量。

规则
- 由顶行两刻度的列距与左列两刻度的行距得到两个周期，分别向右、向下补齐刻度至边界。
- 行刻度所在行与列刻度所在列的每个交叉点构成点阵；读出精灵中心相对其最近交叉点的
  偏移向量。
- 在每个交叉点加上该偏移的位置，以之为中心印一份精灵拷贝；原精灵即阵列中的一员，
  保持原位；拷贝互不重叠，越界的交叉点不印；刻度（含补齐部分）保留。

关键洞察
- 第一眼会以为精灵应对准交叉点印制，但训练对显示所有拷贝都带同一个偏移——原精灵
  不是独立模板，而是这个周期阵列中唯一露出的样本，它的位置本身编码了全局相位。
```

## 4. 展开图的反演与姿态

- 参考题目题号：20（ad7e01d0）、5（bf45cf4b）、4（845d6e51）、2（6ecd11f4）
- tags:
  - operation:降采样, downsample
  - operation:分块解析, block_parse
  - object:瓦片, tile
  - object:基准块, anchor_block
  - relation:像素到块映射, pixel_block_mapping
  - condition:朝向编码颜色, orientation_encodes_color

### docstring

```text
把由同一瓦片按原样或旋转180°摆放而成的分块大图压缩回占据掩码，像素颜色记录每块的姿态。

输入结构
- 输入网格可被均匀划分为若干等大的块，块尺寸等于瓦片尺寸，画面上没有分割线。
- 左上角第一块必为瓦片的原样拷贝（基准）；其余每块要么全为背景，要么是该瓦片的
  原样拷贝或旋转180°的拷贝；瓦片图案无180°自对称。

规则
- 从左上基准块读出瓦片及其尺寸，按该尺寸划分整幅输入。
- 输出为块行数×块列数的小网格：原样拷贝块记绿色，旋转180°拷贝块记红色，空块记黑色。

关键洞察
- 大图是某个从未画出的小掩码经"像素扩为瓦片"的展开；反演时每个被占像素还携带一位
  以瓦片朝向编码的信息，姿态判断必须以左上基准块为绝对基准。
```

## 5. 换道的循环列车

- 参考题目题号：6（12422b43）、14（96a8c0cd）、9（8d510a79）
- tags:
  - operation:循环填充, cyclic_fill
  - operation:绕行, detour
  - object:母题序列, motif_sequence
  - object:障碍条, obstacle_bar
  - relation:端点决定车道, endpoint_determines_lane
  - condition:障碍色决定绕向, obstacle_color_detour

### docstring

```text
顶部彩色母题列向下循环延伸，遇障碍条时按其颜色跳到条的左端或右端外侧车道继续。

输入结构
- 黑底网格；某列顶部若干行是一段彩色母题序列，其下方为空。
- 网格下方散布若干一格厚的水平障碍条，颜色为蓝或绿，长度不一，互不同行，
  均不贴网格左右边缘，且条端外一格及其下方为背景。

规则
- 从母题段末端正下方开始，逐行向下写入母题颜色的循环延续，初始车道为母题所在列。
- 每次下移前检查当前车道正下方一格：若为蓝条像素，车道改为该条最左端再往左一列；
  若为绿条像素，车道改为该条最右端再往右一列；然后在新车道的下一行写入，并保持
  新车道继续向下。
- 母题颜色的循环计数不因换道而中断；写到底行为止；障碍条保留原样。

关键洞察
- 障碍不是终点也不只是偏移一格的路障：换道幅度由条自身的长度与端点位置决定，
  颜色只决定绕向哪一端；循环相位与几何绕行互不干扰。
```

## 6. 看不见的表头值

- 参考题目题号：3（a406ac07）、18（27a28665）、2（6ecd11f4）
- tags:
  - operation:分类, classification
  - operation:填充, fill
  - object:掩码表头, mask_header
  - object:格区, cell_region
  - relation:行列交叉, row_col_intersection
  - condition:角位同时占据, corner_position_both_occupied

### docstring

```text
内部每个3×3格区的四角显示对应行掩码与列掩码角占据模式的按位交集。

输入结构
- 网格顶缘一行等距排列若干 3×3 掩码，左缘一列同样排列若干 3×3 掩码，
  颜色各异、形状互不相同；同色不同角数、同角数不同色的掩码对均存在（诱饵）。
- 内部是与掩码行列对齐的 3×3 背景格区阵列，以一格间隔分隔。

规则
- 对内部第 i 行第 j 列的格区，逐一考察四个角位：当且仅当左缘第 i 个掩码与顶缘第 j 个
  掩码在该角位同时被占据时，格区的该角涂灰。
- 掩码的非角像素与颜色不参与比较；格区其余格保持背景。

关键洞察
- 行列表头的"值"既不是颜色也不是整体形状，而是四角占据的位模式；内部阵列是两组
  位模式的逐位与运算表。
```

## 7. 标记导航的嵌套

- 参考题目题号：12（6cbe9eb8）、11（639f5a19）、20（ad7e01d0）
- tags:
  - operation:排序, sorting
  - operation:嵌套, nest
  - operation:裁剪, crop
  - object:空心矩形, hollow_rect
  - object:控制像素, control_pixel
  - relation:面积递减嵌套, area_descend_nest
  - condition:象限指定嵌角, quadrant_selects_corner

### docstring

```text
将散布的空心矩形按面积从大到小重建为逐层嵌套，每层嵌入的角落由上一层框内控制像素
的象限指定。

输入结构
- 黑底上散布若干颜色互异、大小互异的空心矩形框，框之间互不接触。
- 除最小框外，每个框内部恰有一个青色控制像素，位于框内某个象限。

规则
- 输出网格取最大框的尺寸，先画最大框。
- 按面积降序，每个后续框放入前一个框的内部，并紧贴前一框控制像素所指象限对应的
  内角；控制像素本身不画入输出。
- 重复直到最小框放毕。

关键洞察
- 嵌套的方位不是固定惯例，而是一条由各层自带标记逐层读出的路线；控制像素只指路
  不成像，输出里看不到任何一个标记。
```

## 8. 反射入场与深度染色

- 参考题目题号：17（6855a6e4）、16（516b51b7）、7（c97c0139）
- tags:
  - operation:镜像, mirror
  - operation:重涂色, recolor
  - object:空心矩形, hollow_rect
  - object:精灵体, sprite
  - relation:最近邻归属, nearest_assign
  - condition:层深奇偶决定颜色, layer_depth_parity_color

### docstring

```text
灰色物体越过对齐矩形框的中线反射入框，反射像素按其在框内的层深奇偶染成红或绿。

输入结构
- 黑底网格；若干空心矩形框和框外的灰色物体。
- 每个灰色物体与恰一个框沿同一行或同一列对齐，且反射后完全落入该框内部。

规则
- 每个灰色物体关于其对齐框的中线（垂直于对齐方向）做镜像，拷贝落入框内部。
- 拷贝的每个像素按它到框内壁的最小层距染色：与内壁相邻记层距 1，层距为奇数染红，
  为偶数染绿。
- 原灰色物体从框外抹去，框保留原色。

关键洞察
- 框不只是反射轴的载体，还是一个同心深度场；外来物体的最终颜色逐像素由落点深度
  决定，与它的原色无关。
```
