## 1. 折缝差异印章

- 参考题目题号: `14 (e3497940)`, `11 (264363fd)`, `16 (2a28add5)`
- tags:
  - operation:折叠比对, fold_compare
  - operation:印章覆盖, stamp
  - object:分隔线, separator_line
  - object:差异图形, diff_sprite
  - object:标记像素, marker_pixel
  - relation:镜像差集, mirror_difference
  - condition:标记颜色决定印色, marker_color_paint

### docstring

```text
以分隔线两侧面板的镜像差异图形为印章,按各标记像素的颜色在下方画布上逐一盖印。

输入结构
- 一条纵向灰色分隔列把网格上部分成等宽的左右两个面板;
- 一条横向灰色分隔行的下方是画布区,画布上散布若干不同颜色的单像素标记;
- 左右面板近似互为镜像,仅有少数格位不一致,不一致格位构成一个连通小图形,
  其包围盒的行数与列数均为奇数。

规则
- 把右面板水平镜像后与左面板逐格比对,取所有不一致格位的集合作为印章形
  (差异处双方各自是什么颜色并不重要,只取位置集合,坐标以左面板为准);
- 以印章形包围盒的中心格为锚点,对画布上的每个标记像素盖印一次:
  印章形整体染成该标记的颜色,锚点对准标记所在格;
- 输出仅为盖印完成后的画布区,标记像素被印章覆盖,其余保持背景。

关键洞察
- 折叠在这里不是为了互补叠加,而是作比较器;首个示例极易被误读为普通的
  折叠叠加题,但按叠加逻辑无法解释输出;
- 真正参与规则的对象(印章图形)从未被直接画出,它只以两面板的差集存在。
```

## 2. 分区降采样与对角序列恢复

- 参考题目题号: `5 (780d0b14)`, `6 (4aab4007)`, `10 (2c0b0aff)`
- tags:
  - operation:压缩, compress
  - operation:补全, complete
  - object:分隔线, divider_line
  - object:空区域, empty_region
  - object:杂点, noise_dot
  - relation:反对角线等值, anti_diagonal_equivalence
  - relation:对角色序周期, diagonal_sequence_period
  - condition:粗尺度推断, coarse_scale_inference
  - condition:忽略干扰项, ignore_distractors

### docstring

```text
把分隔区域按主色降采样为粗网格,再依反对角线等值与对角色序的周期性补出全部空缺。

输入结构
- 整行整列的黑色分隔线把网格划成 R×C 个矩形区域;
- 非空区域内散布一种"主色"像素,并混有少量另一种颜色的杂点
  (杂点颜色各区域不一,像素个数与摆放随意);
- 若干区域完全为空;以主色降采样得到的 R×C 色矩阵沿每条反对角线
  (行号+列号相等)同色;
- 大多数反对角线上至少有一个非空区域,但恰有一整条反对角线的区域全部为空;
- 按反对角线序号排列的颜色序列是一个周期序列。

规则
- 取每个非空区域的多数色(主色),把区域折叠为一格,得到部分可见的
  R×C 色矩阵;
- 所在反对角线上尚有可见颜色的空格,取该反对角线的唯一颜色;
- 整条为空的那条反对角线,其颜色由对角色序的周期规律延拓得到;
- 输出为补全后的 R×C 网格。

关键洞察
- 规律在粗尺度而非像素尺度,像素级怎么补都对不上;杂点与像素个数是诱饵;
- 仅靠反对角等值仍差一步:必须再发现"反对角线颜色随序号周期变化"这层规律,
  才能恢复整条缺失的对角线。
```

## 3. 反射链光路

- 参考题目题号: `19 (e39e9282)`, `12 (d968ffd4)`, `8 (9c1e755f)`
- tags:
  - operation:射线延伸, ray_extend
  - operation:反射, reflect
  - object:实心方块, solid_square
  - object:光源像素, source_pixel
  - relation:链式传播, chained_propagation
  - condition:颜色决定光学行为, color_det_optics

### docstring

```text
边缘光源发出的光线依次被粉色方块横向错位反射、被灰色方块吸收,输出每条光线的终点。

输入结构
- 黑背景上散布若干实心正方形块:粉色为反射镜,灰色为吸收体,
  边长均为奇数且可以不同,摆放位置高低不一;
- 网格边缘有一个或多个栗色光源像素。

规则
- 每个光源沿其所在行(源位于左右边缘)或所在列(源位于上下边缘)直线传播;
- 传播途中依次结算与路径相交的方块:
  - 经过粉色方块后,光线的行号(或列号)关于该方块的中心行(列)做镜像,
    随后从方块另一侧继续同向传播;
  - 撞上灰色方块则终止,在被撞面外侧紧邻的背景格染栗色;
- 路径若不再与任何方块相交,则在对侧边缘格染栗色;
- 方块与光线路径不相交时对光线没有任何影响;
- 输出=输入网格加上每条光线的终点栗色像素,光源保留。

关键洞察
- 方块不是目标物而是光学元件;每次关于不同中心的镜像都会改变后续
  会命中哪些方块,必须按顺序追踪整条因果链;
- 关于不同中心的反射不满足交换律,复合结果不可约化为简单的奇偶计数。
```

## 4. 计数差位移向量

- 参考题目题号: `16 (2a28add5)`, `4 (4364c1c4)`, `12 (d968ffd4)`
- tags:
  - operation:计数, counting
  - operation:平移, translate
  - object:主体块, main_block
  - object:力点, force_dot
  - relation:同带对齐, band_aligned
  - condition:计数差决定位移, count_diff_displacement

### docstring

```text
每个主体对象按四个方向上"力点"像素的计数差构成的二维向量整体平移。

输入结构
- 背景色占多数;若干单色多格主体对象,形状颜色各异;
- 大量统一颜色的单像素力点,每个力点恰好落在某一个主体的行带或列带内
  (即与该主体的 bbox 同行区间或同列区间)。

规则
- 对每个主体统计:L=行带内位于其左侧的力点数,R=右侧;
  U=列带内位于其上方的力点数,D=下方;
- 主体水平平移 R-L 格(正向右),垂直平移 D-U 格(正向下),
  两个方向同时结算;
- 输出中所有力点消失,主体形状与颜色不变,原位置变为背景。

关键洞察
- 力点不是要连线、包围或吸附的目标;单看一个示例像"移动到最近的点旁",
  这一读法在其余示例上会失败;
- 每侧的个数之差构成一个位移向量,方向与距离全部来自计数差。
```

## 5. 异质克罗内克与同色反相

- 参考题目题号: `2 (8e2edd66)`, `20 (b4a43f3b)`, `7 (58f5dbd5)`
- tags:
  - operation:克罗内克积, kronecker_product
  - operation:重涂色, recolor
  - operation:图底反转, figure_ground_invert
  - object:结构面板, structure_panel
  - object:单元掩码, unit_mask
  - relation:角色由单色性决定, role_by_monochromy
  - condition:同色反相, same_color_invert

### docstring

```text
以单色面板为单元掩码、多色面板为结构,做逐格重染的克罗内克展开,同色格触发图底反转。

输入结构
- 一条灰色分隔线把网格分成两个面板;
- 一个面板含多种非背景颜色(结构面板),另一个只含单一颜色 c(单元掩码);
- 两个面板的相对位置(左右/上下、谁先谁后)在不同示例中不固定。

规则
- 输出的行列数 = 结构面板尺寸 × 掩码面板尺寸;
- 结构面板的每个格对应输出中一个掩码大小的块:
  - 非背景格且颜色 v≠c:该块 = 掩码形状染成 v,掩码背景处留背景;
  - 非背景格且颜色恰为 c:该块改用掩码的反相
    (掩码为背景处染 c,掩码本体处留背景);
  - 背景格:对应全背景块。

关键洞察
- 两个面板的角色不由位置决定,而由是否单色决定;
- 与掩码同色的格触发图底反转,这一分支只有对比多个示例才会显形,
  单看首例会以为是纯粹的重染展开。
```

## 6. 角标定向纠错

- 参考题目题号: `17 (f4081712)`, `5 (780d0b14)`, `18 (9caba7c3)`
- tags:
  - operation:旋转, rotate
  - operation:纠错, correct
  - object:面板, panel
  - object:角标像素, corner_marker
  - relation:同一母图旋转副本, rotated_copies
  - relation:多数自洽定基准, majority_consistency
  - condition:角标编码朝向, marker_encodes_orientation
  - condition:唯一矛盾者修正, unique_mismatch_fix

### docstring

```text
六个面板都是同一母图案的旋转副本并带角标声明朝向,找出唯一"图案与角标矛盾"的面板并把它转正。

输入结构
- 灰色分隔线把网格分成 2×3 共六个等大面板;
- 每个面板是同一母图案(无任何旋转对称)的 0/90/180/270 度旋转副本,
  朝向可以重复出现;
- 每个面板恰有一个黄色像素位于面板的某个角:约定母图案处于基准朝向时
  黄标在左上角,旋转把黄标带到对应的角;
- 恰有一个面板,其图案的实际朝向与黄标声明的朝向不一致。

规则
- 把各面板按其黄标声明的朝向旋回基准,自洽的多数面板旋回后彼此重合,
  由此得到母图案;
- 唯一旋回后与众不同的面板即矛盾面板;
- 把矛盾面板的图案替换为"母图案按其黄标声明的朝向旋转"的结果,
  黄标位置不动;
- 输出为修正后的整幅网格,其余面板与分隔线保持不变。

关键洞察
- 大图没有任何全局像素对称,逐像素对称补全必然失败;
- 黄标是朝向声明而非装饰:必须先用自洽多数恢复母图案,才能发现谁在说谎;
- 朝向允许重复,靠"数缺口"的排除法无效,只能真正执行旋转比对。
```

## 7. 标尺遥控周期重染

- 参考题目题号: `15 (ba26e723)`, `8 (9c1e755f)`, `16 (2a28add5)`
- tags:
  - operation:重涂色, recolor
  - object:格栅图案, lattice_pattern
  - object:标尺条, ruler_bar
  - object:附着像素, attached_pixel
  - relation:行列周期, periodicity
  - condition:标尺编码周期相位轴颜色, ruler_encodes_params

### docstring

```text
远处每条灰色标尺条以自身的长度、位置、朝向和附着色遥控格栅图案的一次周期性重染。

输入结构
- 网格一侧是一块多行的格栅图案(背景与单一前景色的交替纹样);
- 图案之外的空白处有一条或多条灰色直条,每条一端附着一个彩色像素。

规则
- 每条灰条独立结算一次重染:
  - 水平灰条作用于列:周期 = 条长,相位 = 附着像素所在列,
    选中与该列模周期同余的所有列;
  - 竖直灰条作用于行:周期 = 条长,相位 = 附着像素所在行;
- 把格栅图案内被选中列(行)上的前景像素重染为该条附着像素的颜色,
  背景格与其余前景保持不变;
- 输出与输入同尺寸,灰条及其附着像素抹为背景。

关键洞察
- 周期、相位、作用轴、新颜色四个参数全部由远处的标尺条编码:
  长度=周期,位置=相位,朝向=轴,附着色=新色;
- 格栅内部不含任何这些信息;首例容易误判为"固定每隔三列重染",
  该读法在其余示例上失效。
```

## 8. 缺角对齐残片融合

- 参考题目题号: `13 (aab50785)`, `14 (e3497940)`, `17 (f4081712)`
- tags:
  - operation:裁剪, crop
  - operation:旋转对齐, rotate_align
  - operation:透明叠加, transparent_overlay
  - object:缺角标记块, notched_marker_block
  - object:残缺副本, partial_copy
  - relation:多视图互补, multi_view_complement
  - condition:缺角方位定姿态, notch_encodes_pose
  - condition:忽略干扰项, ignore_distractors

### docstring

```text
每对缺角标记块之间的条带是同一隐藏图案的残缺副本,按缺角方位把部分副本旋转 180 度后再叠加融合出完整图案。

输入结构
- 网格含噪声像素;一种标记色只以"2×2 缺一角的 L 形块"出现,
  且总在同两行带内左右成对,每对的两个 L 形块缺角方位一致;
- 每对标记之间夹着等大的矩形条带;
- 这些条带都是同一隐藏图案的残缺副本:各自有一部分格被抹为背景,
  残缺位置互不相同,任一格至少在一个副本中可见;
- 缺角在右下的那些对,其条带是图案旋转 180 度后的副本;
  缺角在左上的对为原样副本。

规则
- 提取每对标记之间的矩形条带;
- 缺角在左上的对保持原样,缺角在右下的对先把条带整体旋转 180 度;
- 把全部条带逐格叠加:每格取各副本中出现的唯一非背景色;
- 输出融合后的完整图案,尺寸 = 条带尺寸。

关键洞察
- 直接叠加在个别示例上碰巧可行,但一般会产生颜色冲突——冲突本身就是提示:
  部分残片是倒置的;
- 标记块不只是定位符,它的缺角方位是每张残片的姿态密码;
- 隐藏图案从未完整出现过,融合而非按序拼接才是答案。
```
