## 1. 对称破缺指路

- 参考题目题号:1(d56f2372)、4(f0100645)、5(66ac4c3b)
- tags:
  - operation:滑动, slide
  - operation:补全, complete
  - object:前景物体, foreground_object
  - relation:对称, symmetry
  - condition:破缺方向决定运动, defect_direction_determines_motion
  - condition:碰撞停止, collision_stop
  - condition:对称者静止为障碍, symmetric_objects_static

### docstring

```text
每个破缺了镜像对称的物体朝缺口所在的一侧滑动,停稳后补全自身;完全对称的物体原地不动充当障碍。

输入结构
- 背景为最常见颜色,前景为若干互不相触的 4 连通单色物体。
- 一部分物体裁剪到包围框后关于竖直或水平中轴完全镜像对称。
- 其余物体恰好缺失一个像素:补上该格后即恢复完全对称,且该缺失格关于对称轴的镜像孪生格是实心的。
- 输入保证各移动物体的滑动路径互不相交,只与边界和静止物体碰撞。

规则
- 完全对称的物体保持原位不变。
- 每个破缺物体沿"从实心孪生格指向缺失格"的方向(垂直于其对称轴)整体滑动,
  直到撞上网格边界、完全对称物体或已停稳的物体为止。
- 物体停稳后补上缺失像素,恢复完全镜像对称。

关键洞察
- 运动是修复对称的冲动的外化:缺口在哪一侧,物体就朝哪一侧滑;
  完全对称即静止,残缺者滑到尽头后把自己补全——运动方向不写在任何外部线索里,只藏在每个物体自身的破缺中。
```

## 2. 计数链走廊

- 参考题目题号:7(d4c90558)、20(b9630600)
- tags:
  - operation:计数, counting
  - operation:排序, sorting
  - operation:连线, connect
  - operation:擦除, erase
  - object:空心矩形, hollow_rect
  - object:标记像素, marker_pixel
  - object:走廊, corridor
  - relation:包含, containment
  - condition:按计数链连接, chain_by_count_order
  - condition:重叠决定走廊宽度, overlap_corridor_width

### docstring

```text
按房间内灰色标记数的升序,把空心矩形房间连成一条走廊链。

输入结构
- 单一前景颜色构成若干互不相连的空心矩形房间,散布在背景上。
- 每个房间内部含若干灰色标记像素,各房间的标记数互不相同。
- 对计数排序后相邻的每一对房间之间,都存在一段水平或竖直的可见间隙:
  两房间内部的行(或列)区间重叠,且间隙内全为背景。
- 存在几何上更近、间隙更短、但计数不相邻的房间对作为干扰。

规则
- 统计每个房间内部的灰色标记数,并按数量从小到大得到一条全序链。
- 只在链上相邻的房间对之间修走廊:沿两房间内部重叠区间的两条边界行(或列)
  横跨间隙涂上框色,再擦掉两条边界线之间正对的墙壁格,使内部连通。
- 灰色标记与未被打通的墙壁保持不变。

关键洞察
- 走廊的连接对象不由距离或朝向决定——房间内隐藏的计数给出一条全序,
  走廊只沿这条计数链铺设,几何上更近的房间对可能毫无通道。
```

## 3. 图例角落定位的镜像扩展与手性换色

- 参考题目题号:2(833dafe3)、16(0becf7df)
- tags:
  - operation:镜像, mirror
  - operation:拼接, assembly
  - operation:重涂色, recolor
  - object:图例, legend
  - object:象限, quadrant
  - relation:图例行内配对, legend_row_pairing
  - condition:反射奇偶决定换色, reflection_parity_swap
  - condition:图例角落决定象限, legend_corner_placement

### docstring

```text
把输入扩展成 2×2 四向镜像布局:反射奇数次的象限按图例互换颜色,输入自身落在图例所指的角落。

输入结构
- 输入网格整体为图案,其中某一个角上嵌有一个 2×2 的实心图例块,
  图例的两行各给出一对不同颜色。
- 图案中的前景颜色都出现在图例颜色之中;不同示例里图例所在的角不同。

规则
- 输出为输入的两倍高、两倍宽,由输入及其左右反射、上下反射、双重反射四个象限拼成。
- 输入原样放入图例所在角对应的那个象限。
- 与它相邻的两个象限(各经一次反射得到)中,每个非背景像素换成图例同一行中的另一种颜色;
  对角象限(经两次反射)保持原色。
- 图例像素与其他像素遵循同一换色规则。

关键洞察
- 反射的奇偶性以颜色显形:单次镜像翻转手性,同时触发图例定义的成对换色,
  两次镜像则把颜色换回来;而那个 2×2 小块既是调色表,又是原图在输出中的定位锚。
```

## 4. 熔断闸门

- 参考题目题号:8(2b83f449)、4(f0100645)、19(d35bdbdc)
- tags:
  - operation:重力下落, gravity_drop
  - operation:擦除, erase
  - object:令牌, token
  - object:闸门, gate
  - object:墙壁, wall
  - relation:同色匹配, same_color_matching
  - condition:碰撞停止, collision_stop
  - condition:铺满同色即熔断, full_cover_fuse
  - condition:连锁塌落, cascade_collapse

### docstring

```text
彩色令牌依次坠落堆叠,一条闸门只有被同色令牌完全铺满才熔断消失,并引发上方连锁塌落。

输入结构
- 网格由墙壁色围成若干竖井结构,井内悬有若干单色水平闸门条,长度不一。
- 顶行有若干单像素彩色令牌,各占一列;闸门色与令牌色取自同一批前景颜色。

规则
- 令牌按从左到右的顺序逐个沿自身所在列下落,停在墙壁、已停稳令牌或闸门之上。
- 当某条闸门的每一格上都直接压着与闸门同色的令牌时,该闸门熔断:
  闸门与压在其上的这些同色令牌一同消失,原先叠在它们上方的所有令牌重新下落,
  并可能连锁触发下一次熔断,直到全局稳定。
- 异色令牌压在闸门上只会占位,永久阻止该闸门熔断。
- 输出为全部结算完毕后的稳定状态:墙壁、未熔断的闸门与停稳的令牌;消失处恢复背景。

关键洞察
- 闸门不是被单个钥匙打开的——它要求被同色令牌完全铺满才熔断,且钥匙同归于尽;
  一个异色占位就能锁死整条闸门,而每次熔断引发的塌落会重排上方一切并可能引爆连锁,
  一遍简单模拟不足以得到终局。
```

## 5. 逐列仲裁分隔行

- 参考题目题号:12(e98196ab)、16(0becf7df)
- tags:
  - operation:透明叠加, transparent_overlay
  - operation:擦除, erase
  - object:分隔行, separator_row
  - object:等高面板, equal_height_panel
  - relation:分隔对齐, separator_alignment
  - condition:冲突按同列分隔色仲裁, per_column_arbitration
  - condition:伪装噪声列, camouflage_columns

### docstring

```text
叠加分隔行上下两块等高面板,重叠冲突处由分隔行在同一列的颜色钦点赢家。

输入结构
- 一条非背景的满宽横行把网格分成上下两块等高面板;
  该行每一格都有前景颜色,多种颜色铺满,看似装饰性花纹。
- 两块面板各含前景像素,叠加后存在若干冲突格。
- 输入保证:每个冲突格所在列的分隔行颜色恰与两个冲突色之一相同;
  且各列的仲裁结果无法用任何一张全局颜色优先序解释。

规则
- 删去分隔行,把下面板与上面板按局部坐标对齐叠加,输出为单块面板大小。
- 只有一方为前景的格子直接保留该前景色。
- 两面板前景在同一格冲突时,查看分隔行在该列的颜色,保留与之同色的那一方。

关键洞察
- 被删除的分隔行是一张逐列仲裁表:冲突发生在哪一列,就由那一列的分隔色裁决胜负;
  全局的"某色总是赢"或"上/下面板总是赢"都会在别的列被推翻,其余分隔格的颜色只是伪装。
```

## 6. 标记行引力带

- 参考题目题号:9(0f63c0b9)、4(f0100645)、14(d6e50e54)
- tags:
  - operation:滑动, slide
  - operation:重涂色, recolor
  - object:单像素标记, single_pixel_marker
  - object:前景物体, foreground_object
  - relation:按行排序, sorted_by_row
  - condition:中点划分归属, midpoint_band_assignment
  - condition:双向吸附, bidirectional_attraction
  - condition:碰撞停止, collision_stop

### docstring

```text
每个前景物体竖直吸附到自己所属引力带的标记行上,并染成该标记的颜色。

输入结构
- 背景为最常见颜色。
- 前景包括若干孤立的单像素彩色标记(所在行互不相同)和若干更大的 4 连通单色物体。
- 标记颜色与物体颜色互不相同;物体至少含两个像素,借此与标记区分。

规则
- 按相邻标记行之间的中点把网格切成若干水平引力带,每个物体按其包围框中心所在带归属一个标记。
- 位于标记行上方的物体竖直下落、位于下方的物体竖直上升,
  直到贴住标记行,或先撞上同带内已停稳的物体;同带内按到标记行的距离由近及远依次结算。
- 停稳的物体整体重涂为其所属标记的颜色;标记像素保留原位原色。

关键洞察
- 标记行不是普通的地板——每一条都是双向引力线,吸引的是"带内"而非"下方"的物体:
  看似在做自由下落的物体,可能正被脚下更近的另一条线越过;
  物体的新颜色泄露了这场按中点划界的引力归属。
```
