## 1. 层序即行程

- 参考题目题号: `68bc2e87`（17）、`9bbf930d`（5）、`e41c6fd3`（11）
- tags:
  - operation:层序恢复, occlusion_order_recovery
  - operation:路径绘制, path_draw
  - object:空心矩形, hollow_rectangle
  - object:重叠层, overlap_layer
  - relation:遮挡定先后, occlusion_determines_order
  - relation:中心共线, center_alignment
  - condition:层序即时间表, stack_order_as_itinerary

### docstring

```text
把遮挡层序当作行程表，按从底到顶的次序用线段依次串联各矩形框的中心。

输入结构：
- 黑色背景上有若干互相重叠的单像素厚空心矩形框，每框一种颜色；
  重叠处只显示位于上层的框色。
- 框的大小与位置和层序无关，层序不能由尺寸或坐标猜出。
- 层序中相邻的两个框，其中心处于同一行或同一列，且两中心间的直线段
  不经过第三个框的中心。

规则：
- 由可见像素恢复每个框的完整外接边框；每个重叠格的可见色给出该处
  两框的一条上下约束，全部约束汇总出唯一的从底到顶全序。
- 保留所有框；从最底层框的中心出发，按层序依次向下一个框的中心画
  直线段，线段用目的框的颜色，只覆盖背景格。
- 每个框的中心格画上该框自身颜色的点。

关键洞察：
- 遮挡不是需要修复的破损，而是一份时间表：每个遮挡关系是一条先后
  约束，全体约束拼出唯一行程，输出画的正是这段行程本身。
```

## 2. 公共空白蓝图的分形编织

- 参考题目题号: `0c9aba6e`（12）、`b99e7126`（13）、`15660dd6`（4）
- tags:
  - operation:透明叠加, transparent_overlay
  - operation:缩放平铺, scale_tile
  - object:面板, panel
  - object:分隔行, separator_row
  - object:隐藏掩码, hidden_mask
  - relation:双面板背景交集, both_panels_background_intersection
  - relation:自相似, self_similarity
  - condition:负空间为蓝图, negative_space_as_blueprint

### docstring

```text
隐藏于两面板公共空白中的蓝图，指挥两个前景印章在放大尺度上的分形编织。

输入结构：
- 一条独有颜色的整行分隔线把网格分成上下两块等大的面板，面板尺寸
  n×m（n,m≤5）。
- 上面板只含颜色A的前景与黑背景，下面板只含颜色B的前景与黑背景。

规则：
- 去掉分隔行，把两面板按位置对齐，取"两侧都是黑"的格，得到 n×m 的
  隐藏掩码。
- 输出为 (n·n)×(m·m) 的黑底网格，划分成 n×m 个 n×m 的块。
- 掩码为真的块位置，整块画入上面板的前景图案（A色）；掩码为假的块
  位置，整块画入下面板的前景图案（B色）。

关键洞察：
- 指挥放置的对象在画面上从未出现——它既不是A形也不是B形，而是两者
  的公共空白；先去叠加两个前景是诱饵。两个可见图案只是印章，真正的
  蓝图是它们共同留白的负空间，还须再跨一个尺度按它编织两种印章。
```

## 3. 不平衡既是罗盘也是里程表

- 参考题目题号: `44f52bb0`（8）、`a79310a0`（3）、`f8ff0b80`（16）
- tags:
  - operation:对称检测, symmetry_detection
  - operation:平移, translate
  - operation:计数, counting
  - object:精灵体, sprite
  - relation:镜像轴, mirror_axis
  - relation:质量不平衡, mass_imbalance
  - condition:对称轴选运动轴, symmetry_axis_selects_motion_axis
  - condition:像素差定步数, pixel_difference_sets_distance

### docstring

```text
每个精灵的镜像对称轴选出运动方向线，偏重的一半给出指向，两半像素差给出步数。

输入结构：
- 黑背景上有若干互不相同颜色、彼此分离的精灵。
- 每个精灵恰好关于自身包围盒的一条中轴（水平轴或垂直轴）镜像对称，
  关于另一条不对称。
- 输入保证每个精灵按规则移动的路径上没有其他精灵，且不出界。

规则：
- 关于水平中轴对称的精灵沿水平方向运动，关于垂直中轴对称的精灵沿
  垂直方向运动。
- 运动指向为不对称方向上像素较多的那一半所在的一侧。
- 移动步数等于该方向上两半像素数之差；精灵形状与颜色不变，平移后输出。

关键洞察：
- 没有箭头、没有滑到底的墙：精灵形状里同时藏着运动的轴、符号与模长。
  第一个示例看似"滑到贴墙"是诱饵，只有两半像素差才能解释全部示例。
```

## 4. 画布即查找表

- 参考题目题号: `09629e4f`（1）、`e41c6fd3`（11）
- tags:
  - operation:重涂色, recolor
  - operation:查表, lookup
  - object:色键块, color_key_block
  - object:精灵体, sprite
  - relation:隐含九宫区带, implicit_ninth_partition
  - relation:相对环绕地址, relative_wrapped_address
  - condition:色键为原点, key_block_as_origin

### docstring

```text
按精灵落在隐含九宫格的哪个区带，以色键块所在区带为原点相对查表重新上色。

输入结构：
- 网格的行数与列数均为3的倍数。黑背景上散布若干同形（归一后掩码
  一致）而颜色各异的精灵。
- 另有一个 3×3 的实心色键块，块内九格颜色互不相同。
- 每个精灵与色键块都完整落在网格按行、列三等分划出的某个隐含区带内。

规则：
- 将网格按行、列各三等分，得到并未画出的 3×3 区带划分。
- 以色键块所在区带为原点：每个精灵按其区带相对原点的偏移（按 3 取模
  环绕）读取色键中对应格的颜色，并整体改涂为该色；形状与位置不变。
- 输出中抹去色键块。

关键洞察：
- 分隔栅格从未画出：整张画布本身就是一张 3×3 查找表。索引还是以色键
  位置为原点的相对环绕地址——绝对位置读法只在色键恰居左上区带时碰巧
  成立，这是诱饵。
```

## 5. 颜色带静止，长度带反转

- 参考题目题号: `5792cb4d`（6）、`e41c6fd3`（11）
- tags:
  - operation:序列反转, sequence_reverse
  - object:单像素宽路径, one_pixel_path
  - object:端点像素, endpoint_pixel
  - object:锚点像素, anchor_pixel
  - relation:双通道分解, dual_channel_decomposition
  - condition:形状与色序不变, shape_and_color_order_fixed
  - condition:长度序列反转, length_sequence_reversed

### docstring

```text
路径形状与颜色次序都不动，被反转的只是长度通道：第k段颜色获得倒数第k段的长度。

输入结构：
- 背景占多数；全部前景（除一个灰色锚点外）构成一条四连通、单像素宽、
  无分支的路径，恰有两个端点。
- 路径由若干单色连续段组成，各段长度互不相同。
- 灰色锚点与其中一个端点对角相邻，不属于路径。

规则：
- 从锚定端走到另一端，取出颜色序列 c1…ck 与长度序列 L1…Lk。
- 保持颜色次序 c1…ck 不变，把长度序列替换为其反转 Lk…L1。
- 从锚定端起按 (c1,Lk),(c2,Lk-1),… 重新涂写整条路径；路径形状、
  锚点与背景都不变。

关键洞察：
- 路径是两条并行的纸带——颜色带与长度带。整体反转（诱饵一）与保持
  不变（诱饵二）都能解释部分观感，唯有发现"颜色带静止、长度带反转"
  这一通道分解，各段边界的细微滑移才全部对上；锚点只规定读写方向。
```

## 6. 对称缺口是跨尺度指令单

- 参考题目题号: `e40b9e2f`（19）、`b99e7126`（13）、`09629e4f`（1）
- tags:
  - operation:对称补全, symmetry_complete
  - operation:跨尺度换算, cross_scale_mapping
  - object:分隔网格, separator_grid
  - object:少数单元, minority_cell
  - object:补全像素, completion_pixel
  - relation:旋转闭包, rotation_closure
  - condition:缺口坐标为指令, missing_positions_as_instructions

### docstring

```text
唯一不具四重旋转对称的单元，其补全所需添加的像素位置是整张九宫格的改造指令。

输入结构：
- 分隔线把网格划成 3×3 个单元，每个单元内部为 3×3。
- 其中八个单元的图案关于各自单元中心具有 90° 旋转对称；剩下一个单元
  的图案不对称，但补上若干像素后可无颜色冲突地唯一达到四重旋转对称。
- 补全所需的新增像素位置不指向不对称单元自身所在的单元坐标。

规则：
- 找到那个不对称单元，求出使其达到四重旋转对称所需添加的像素集合，
  并在该单元内补上（用该单元图案的颜色）。
- 把这些新增像素在单元内的 3×3 坐标读作九宫格的单元坐标：被指到的
  每个单元，其内部整体改涂为不对称单元图案的颜色（实心）。
- 分隔线与其余未被指到的单元保持不变。

关键洞察：
- 补全对称只是第一层，也是诱饵：真正的信息不在补全后的图案里，而在
  "缺了哪些位置"里——缺口坐标经过一次跨尺度换算，成为对整张栅格动手
  的指令单。
```

## 7. 缺口量尺缠绕隐形矩形

- 参考题目题号: `af902bf9`（9）、`88bcf3b4`（15）、`cf133acc`（7）
- tags:
  - operation:边界铺设, boundary_lay
  - object:角标记, corner_marker
  - object:量尺条, ruler_bar
  - object:条缺口, bar_gap
  - relation:角点定矩形, corners_define_rectangle
  - relation:远近分配方向, proximity_assigns_direction
  - condition:像素数守恒, pixel_count_conservation

### docstring

```text
把被缺口分成两段的量尺条，按远近分别以顺、逆时针缠绕到只由四个黄角点暗示的矩形边界上。

输入结构：
- 黑背景。四个黄色像素两两共享两行两列，位于一个从未画出的矩形四角
  的对角线外侧；矩形边界与内部均为黑。
- 另有一根贴着网格边、被一个单格缺口分成两段的直量尺条（非黄色），
  与矩形分离，两段总长小于矩形周长。

规则：
- 由四个黄点恢复矩形的完整边界路径，并找到离量尺条最近的边界角。
- 靠近矩形的一段量尺的长度，从该角起沿顺时针方向逐格涂写边界；
  远离矩形的一段量尺的长度，从该角起沿逆时针方向逐格涂写边界；
  颜色均用量尺条色，涂写格数与各段长度严格相等。
- 量尺条从输出中移除；黄色角点保留；边界其余部分保持黑色。

关键洞察：
- 矩形只以四个角的约束存在；量尺条不是障碍也不是装饰，而是要被搬运
  到隐形边界上的两段长度——像素总数在搬运中守恒，缺口是把总长拆成
  顺、逆两个流向的分配器。
```

## 8. 直方图缠成螺旋

- 参考题目题号: `f8ff0b80`（16）、`8b28cd80`（20）、`88bcf3b4`（15）
- tags:
  - operation:计数, counting
  - operation:排序, sorting
  - operation:螺旋绘制, spiral_drawing
  - object:前景色掩码, foreground_mask
  - object:种子像素, seed_pixel
  - relation:面积排序, area_ordering
  - condition:像素数守恒, pixel_count_conservation
  - condition:忽略形状位置, ignore_shape_position

### docstring

```text
把各颜色掩码按像素数降序连接成一条燃料带，从灰色种子起顺时针缠成方形螺旋。

输入结构：
- 黑背景上散布若干颜色的掩码，形状与位置任意；各颜色的像素总数互不
  相同。
- 另有唯一的灰色种子像素，不属于任何掩码。

规则：
- 数出每种非灰颜色的像素数，按数量从大到小排序。
- 擦除所有掩码，从种子出发按固定步长序列 1,1,2,2,3,3,…、以
  上-右-下-左的顺时针次序走出方形螺旋轨迹。
- 沿轨迹逐格涂色：先用最大掩码的颜色涂其原像素数个格，涂完立即换
  下一种颜色，直到所有颜色的像素数耗尽；种子格保留灰色。

关键洞察：
- 掩码的形状与位置全是干扰，只有各色的基数存活；直方图不是被排成
  柱状列，而是被缠绕进一条螺旋，颜色的交界落在螺旋的中途而非拐角，
  总涂色格数与输入前景像素总数守恒。
```
