## 1. 沉底直线的抽除

- tags:
  - operation:层序推断, infer_layer_order
  - operation:平铺补全, periodic_restore
  - object:全幅直线, full_span_line
  - object:周期底纹, periodic_lattice
  - relation:遮挡层次, occlusion_order
  - condition:唯一最底层, unique_bottom_layer
- 参考题目：6 (22425bda)、10 (ca8f78db)、11 (1a2e2828)

### docstring

```text
删除叠层直线中的最底层直线，并用周期底纹恢复其覆盖处。

输入结构
- 整幅网格是一个规则的二维周期色纹（底纹），其调色板不含直线所用颜色。
- 若干条贯穿整行或整列的一格粗彩色直线覆盖在底纹之上，每条一色。
- 直线相互交叉，交叉格显示层序较高者的颜色。

规则
- 由可见共线像素恢复每条完整直线；在每个交叉格记录"可见色在另一色之上"
  的约束。
- 找出唯一处处被压在下面的直线：它在自己的所有交叉处均不可见。
- 将该直线删除：它单独覆盖的格恢复为由其余可见底纹推断出的最小周期图案
  对应色；它与其他直线的交叉格保持原样不动。

关键洞察
- 交叉处的可见色编码层序，被删除的不是最显眼而是最底层的线；底纹的周期
  必须从未被覆盖的格中重建，才能补出它身下的颜色。
```

## 2. 孔洞指针链

- tags:
  - operation:重涂色, recolor
  - operation:链式追踪, chain_follow
  - object:瓦片阵列, tile_array
  - object:位置孔洞, position_hole
  - relation:坐标指针, coordinate_pointer
  - condition:根色传播, root_color_propagate
- 参考题目：9 (9ddd00f0)、5 (c4d067a0)

### docstring

```text
把每块瓦片的孔洞读作指向另一瓦片的坐标指针，沿指针链走到尽头，用终点
瓦片的颜色重涂整块并填实孔洞。

输入结构
- 网格由单格背景行列分隔成 n×n 个 n×n 的单色瓦片。
- 每块瓦片恰有一个背景色孔洞；孔洞在瓦片内的局部坐标 (r,c) 指向阵列中
  第 r 行第 c 列的瓦片。
- 指向自身的瓦片是根；所有指针链在有限步后到达某个根，不存在环；每个
  输入中都存在长度不小于 2 的指针链。

规则
- 从每块瓦片出发沿指针逐块跳转，直至到达指向自身的根瓦片。
- 输出保持分隔行列不变，把每块瓦片整块（含孔洞位置）填成其根瓦片的
  颜色。

关键洞察
- 孔洞不是自身位置的标签而是指向他处的指针，且必须沿链传递到根；只做
  单步替换在链长不小于 2 的瓦片上会得到错误颜色。
```

## 3. 中轴操作码

- tags:
  - operation:按码重写, opcode_rewrite
  - object:中轴列, center_column
  - object:半区图案, half_pattern
  - relation:逐行指令, per_row_instruction
  - condition:含义就地反推, infer_code_in_grid
  - condition:埋伏伪装行, disguised_rows
- 参考题目：14 (d23f8c26)、15 (1e32b0e9)

### docstring

```text
把中轴列读作逐行操作码，按各行指令用左半重写右半，指令含义须由本输入
中未损坏的多数行反推。

输入结构
- 网格列数为奇数，正中一列的每格是两种指令色之一，左半与右半等宽。
- 每行的左半是任意图案；多数行的右半已按该行指令正确写出：一种指令
  表示右半是左半的镜像，另一种表示右半是左半的平移复制。
- 少数损坏行的右半不符合本行指令，且往往恰好等于按另一种指令写出的
  结果。
- 两种指令色与两种写法的对应关系在不同输入间不固定，只能靠该输入内部
  自洽的行反推；每个输入中两种指令色都至少出现在一个左半不对称的完好
  行上。

规则
- 在本输入内，用左半不对称且右半与某一种写法完全一致的行确定每种指令
  色对应哪种写法。
- 逐行按其中轴指令色，用左半重新生成右半；左半与中轴列保持不变。

关键洞察
- 中轴列是逐行的操作码通道；由于损坏行可能完美伪装成另一种写法，
  "就近修复"必然出错，唯一裁决者是先在完好行上破译出的指令含义。
```

## 4. 缺口准入计数

- tags:
  - operation:计数, counting
  - operation:计数渲染, tally_render
  - object:矩形框, rectangular_frame
  - object:门缺口, gate_gap
  - object:阻挡碎段, blocker_segment
  - relation:视线准入, sightline_admission
  - condition:路径畅通, clear_path
  - condition:忽略干扰项, ignore_distractors
- 参考题目：19 (c8b7cc0f)、2 (95755ff2)、8 (e1d2900e)

### docstring

```text
每个矩形框留有一格缺口，统计框内标记加上能沿直线穿过缺口进入的框外
标记，并把总数以行优先填入该框内部。

输入结构
- 背景网格上有若干一格粗的矩形框，各框颜色不同，每框边上恰缺一格作为
  门。
- 同一种标记色的单格像素散布在框内与框外；还有少量与框、标记不同色的
  阻挡碎段。
- 每个框外标记至多与一个门共线。

规则
- 一个框外标记可进入某框，当且仅当它位于穿过该门的那一行或那一列的
  框外一侧，且它与门之间没有任何框壁、阻挡碎段或其他标记。
- 对每个框，N = 框内原有标记数 + 可进入标记数。
- 输出同尺寸网格：保留所有框与阻挡碎段，清除所有标记像素，再按行优先
  顺序把每框内部的前 N 格涂成标记色。

关键洞察
- 缺口是唯一的准入通道；直接数框内标记或数所有共线标记都会出错，必须
  逐一核验"共线、在外侧、路径畅通"三个条件，同线靠外的标记还会被靠内
  的标记挡在门外。
```

## 5. 锚点碎片拼图

- tags:
  - operation:对齐拼合, align_merge
  - operation:裁剪, crop
  - object:矩形碎片, rect_fragment
  - object:锚点像素, anchor_pixel
  - object:隐藏精灵, hidden_sprite
  - relation:锚点配准, anchor_registration
  - condition:整体从未出现, whole_never_shown
- 参考题目：7 (3ed85e70)、18 (470c91de)、10 (ca8f78db)

### docstring

```text
画面上散落的每个矩形碎片都是同一从未完整出现的精灵的一扇窗口，以各
碎片中唯一的青色锚点像素对齐并拼合出完整精灵。

输入结构
- 黑色背景上分散着若干实心矩形碎片，碎片之间互不重叠、位置与大小各异。
- 每个碎片内恰有一个青色像素，其余格均为非黑非青的精灵颜色。
- 所有碎片都是同一隐藏精灵的矩形裁片；青色像素在每个碎片中都覆盖精灵
  的同一个格（锚点格），碎片的对齐并集恰好覆盖精灵全部格。

规则
- 把每个碎片按"青色像素重合"平移对齐；对齐后重叠处的非青颜色必然一致。
- 输出对齐并集的紧致裁剪：精灵各格取其在任一碎片中的颜色，锚点格保持
  青色。

关键洞察
- 完整精灵从未被画出，画面上只有它的残迹；碎片间没有可直接匹配的公共
  轮廓，唯一的配准依据是每片必含的同一锚点像素。
```

## 6. 四源洪泛竞赛

- tags:
  - operation:洪泛填充, flood_fill
  - operation:重涂色, recolor
  - object:边界线, border_line
  - object:标记像素, marker_pixel
  - object:墙壁碎段, wall_segment
  - relation:最近绕行源, nearest_geodesic_source
  - condition:全幅判源, full_span_identifies_source
  - condition:同色不供色, same_color_no_supply
  - condition:视线是诱饵, sightline_decoy
- 参考题目：12 (2204b7a8)、13 (e69241bd)、2 (95755ff2)、11 (1a2e2828)

### docstring

```text
四条颜色互异的边界线同时向内洪泛，每个绿色标记染成绕过墙壁后步数真正
最近的那条边界线的颜色，直线可见性是诱饵。

输入结构
- 网格四条边各被一条贯穿整边、颜色互不相同的边界线占据。
- 内部散布绿色标记像素，以及若干与某些边界线同色的墙壁碎段。
- 保证每个标记到四条边界线的最短绕行步数有唯一最小者。

规则
- 墙壁碎段与标记都视为障碍，边界线上每格是源；距离按只走背景格的
  4 连通最短步数计算，标记格自身可作为终点。
- 每个标记重涂为绕行步数最近的边界线的颜色。
- 被墙完全围住、无法到达任何边界的标记擦为背景；墙壁碎段与边界线保持
  不变。

关键洞察
- 与边界线同色的内部碎段只是墙、不供色，供色者由"贯穿整边"的性质判定；
  部分标记沿直线能"看见"某条边界，但绕行步数更近的却是另一条被挡住的
  边，直线视距与曼哈顿距离的假说都会在后续示例上崩塌，真正的度量是
  绕墙的洪泛步数。
```

## 7. 层序叠印

- tags:
  - operation:层序推断, infer_layer_order
  - operation:叠印合成, overlay_composite
  - object:全幅直线, full_span_line
  - object:彩色方框, colored_box
  - object:框内图案, boxed_sprite
  - relation:颜色配对, color_pairing
  - relation:遮挡层次, occlusion_order
  - condition:唯一序链, unique_chain
- 参考题目：6 (22425bda)、7 (3ed85e70)、11 (1a2e2828)

### docstring

```text
由直线交叉处的遮挡关系恢复各颜色的层序，再按此层序自底向上把与直线
同色的方框内的图案叠印到一张画布上。

输入结构
- 网格一侧区域内若干条一格粗、贯穿整行或整列的彩色直线相互交叉，交叉
  格显示上层颜色。
- 另一区域有同样多个等大的一格粗方框，框色与直线颜色一一对应；每框
  内部有一个由若干彩色格组成的小图案。
- 交叉给出的层序约束恰好确定唯一的自底向上全序。

规则
- 恢复每条直线并由交叉可见色建立"上/下"约束，求出唯一全序。
- 新建一张与方框内部等大的背景画布，按全序从最底层颜色开始，依次把
  对应方框内的图案画上去；后画的覆盖先画的。
- 输出这张画布。

关键洞察
- 方框自身的位置与排列不含次序信息，叠印顺序完全由另一处直线交叠的
  遮挡链给出；把两个区域用颜色配对是解锁本题的第一步。
```

## 8. 落单者的残缺配偶

- tags:
  - operation:同构配对, congruence_pairing
  - operation:补全, complete
  - object:前景图形, foreground_shape
  - object:落单图形, unpaired_shape
  - object:残片, fragment_relic
  - relation:旋转翻转同构, congruence_up_to_D4
  - condition:唯一配对缺口, unique_pairing_gap
  - condition:对象未被完整画出, object_never_fully_drawn
- 参考题目：20 (73ccf9c2)、7 (3ed85e70)、4 (71e489b6)

### docstring

```text
前景图形按形状两两成对，唯一落单图形的"配偶"只剩一角残迹，找到残迹
并按落单者的形状将其补全。

输入结构
- 背景上有若干种颜色的连通图形，颜色互不相同。
- 除两个例外，这些图形按形状两两配对：每对的两个图形经旋转、翻转、
  平移后可完全重合，但颜色不同。
- 例外一是一个没有任何同构同伴的完整图形（落单者）；例外二是一小撮
  同色像素（残片），它恰是落单者形状某个旋转翻转版本的一部分，且能
  覆盖残片全部像素的对齐方式唯一。

规则
- 在旋转翻转变换下把图形按形状配对，找出唯一落单的完整图形与那撮不成
  形状的残片。
- 求出落单者形状经过何种旋转翻转、放置在何处能恰好覆盖残片的全部像素。
- 用残片自身的颜色把该位置补成完整图形；其余一切保持不变。

关键洞察
- 残片太小，单看它无法得知全貌；只有先完成全场的形状配对、发现唯一的
  配对缺口，才能知道残片是谁的配偶、应当补成什么样子。
```
