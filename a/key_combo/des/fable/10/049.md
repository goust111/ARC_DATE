## 1. 隐形停靠环

- 参考题目: `6ad5bdfd`(15), `4a1cacc2`(19), `f8b3ba0a`(12), `aaef0977`(7)
- tags:
  - operation:滑动, slide
  - operation:计数, counting
  - object:孤立标记像素, marker_pixel
  - object:多连块, polyomino
  - relation:面积决定停距, area_sets_distance
  - relation:小件优先结算, smallest_first_settling
  - condition:同侧唯一落点, same_side_unique_stop
  - condition:占环让位外移, occupied_ring_yield

### docstring

```text
每个物体沿它与标记共线的方向移动到"距离等于自身格子数"的停靠环上，环位被占则向外让位。

输入结构
- 黑色背景；恰有一个红色标记像素。
- 若干互不同色的单色四连通物体，每个物体与标记同行或同列，
  可分布在标记的上下左右四个方向上；物体不含红色。

规则
- 物体按格子数从小到大依次结算。
- 每个物体只沿它与标记共线的那条直线移动，且始终留在标记同侧；
  目标位置是其最近端到标记的直线距离恰好等于自身格子数——
  离标记过近的物体向外后退，过远的物体向内靠拢。
- 若目标位置已被先结算的物体占用，则沿同方向继续外退到最近的
  不重叠位置；标记不动，物体原位清空。

关键洞察
- 标记周围有一组从未画出的同心停靠环，每个物体的环半径由它自身的
  面积决定；这不是引力吸附——太近的物体反而后退，且小物体优先入环，
  大物体被迫让位外移。
```

## 2. 镜像补墙寻路

- 参考题目: `0934a4d8`(5), `f9012d9b`(10), `f8f52ecc`(11)
- tags:
  - operation:对称补全, symmetry_completion
  - operation:连线, connect
  - object:遮挡矩形, occluding_rect
  - object:障碍墙, obstacle_wall
  - object:端点像素, endpoint_pixel
  - relation:先补全后寻路, restore_then_route
  - condition:唯一最短路径, unique_shortest_path

### docstring

```text
先用左右镜像对称恢复被灰色矩形遮住的墙体，再用红色画出两枚端点像素之间绕墙的唯一最短路径。

输入结构
- 黑色背景上青色墙体关于网格竖直中线左右镜像对称。
- 一个灰色实心矩形遮住其中一侧的部分区域，墙与背景都可能被盖住。
- 另有两个红色端点像素位于未遮挡处；数据保证恢复后两点间只经过背景的
  最短路径唯一。

规则
- 将每个灰色格子恢复为其镜像位置所示的内容（青墙或黑背景）。
- 在恢复后的网格中，沿四连通方向找出两红点之间只经过背景的唯一最短
  路径，把路径格子涂红。
- 青色墙体全部保留，灰色矩形不再出现。

关键洞察
- 不先做对称恢复就无法正确寻路——灰色区域下藏着改变通路的墙，
  看似敞开的近道实际被堵，真正的通道只有在补全之后才显现。
```

## 3. 面板小件即指令

- tags:
  - operation:镜像, mirror
  - operation:旋转, rotation
  - operation:叠加, overlay
  - object:并列面板, panel
  - object:指令小件, instruction_piece
  - relation:形状编码操作, shape_codes_op
  - condition:右侧覆盖左侧, right_over_left

### docstring

```text
面板里的小件不是干扰而是操作指令，按它先变换大精灵，再把各面板叠加成单个面板。

输入结构
- 三个等大的方形面板由一格黑色分隔列并排排开。
- 每个面板内有同色的一大一小两个物体：大的是精灵，小的是指令件，
  形如横条、竖条或方点；三个面板颜色互不相同。

规则
- 横条令本面板精灵上下翻转，竖条令其左右翻转，方点令其旋转一百八十度，
  变换均以精灵自身包围盒为准原地进行。
- 随后删除指令件，把三个面板按格对齐叠加成一个面板大小的输出。
- 重叠处右侧面板的颜色覆盖左侧。

关键洞察
- 小物体看似应当被舍弃的干扰件，实则各自编码一种翻转操作；
  不先按指令变换精灵，叠加出来的画面就是错的。
```

## 4. 洋葱图例重生长

- 参考题目: `8dae5dfc`(6), `aaef0977`(7), `6df30ad6`(1)
- tags:
  - operation:填充, fill
  - operation:擦除, erase
  - object:嵌套矩形层, nested_rect_layer
  - object:孤立标记像素, marker_pixel
  - relation:图例转距离场, legend_to_distance_field
  - relation:层厚定带宽, thickness_sets_bandwidth
  - condition:切比雪夫等距线, chebyshev_isolines

### docstring

```text
把嵌套矩形当作图例读出"颜色-带宽"序列，再以孤立标记为中心按切比雪夫距离重新长出对应的同心方环场。

输入结构
- 黑色背景上有一个多层嵌套的实心矩形：各层为均匀厚度的矩形环，
  长宽不等、颜色互异、厚度不尽相同。
- 远处有一个孤立的标记像素，标记色等于嵌套矩形最内层的颜色。

规则
- 自内向外读出图例的颜色序列及各层厚度。
- 输出中擦除图例矩形，保留标记像素；以标记为中心，从切比雪夫距离一
  起依次向外画正方形方环带：第一段带宽等于最内层厚度、用最内层色，
  下一段带宽与颜色取自下一层，直至最外层画完，越出网格的部分截断。
- 其余格保持背景。

关键洞察
- 嵌套矩形不是被变换的对象，而是一把只读的"色标尺"；由于图例是
  长宽不等的矩形环而输出是正方方环，整体平移复制图例必然失败——
  必须抽象出厚度序列，才能围绕标记把洋葱按等距线重新长出来。
```

## 5. 孪生对定隐轴

- 参考题目: `4e7e0eb9`(9), `b7cb93ac`(8), `0934a4d8`(5)
- tags:
  - operation:镜像, mirror
  - object:精灵体, sprite
  - object:孪生对, twin_pair
  - relation:生成元定义变换, generator_defines_transform
  - condition:镜像对唯一, unique_mirror_pair
  - condition:平移对为诱饵, translated_pair_decoy

### docstring

```text
找出互为镜像的那对孪生精灵，推出它们隐含的反射轴，并把其余每个精灵搬到该轴的镜像位置。

输入结构
- 黑色背景上散布若干单色不对称精灵。
- 其中恰有一对同色同形的精灵互为竖直轴或水平轴反射像；
  另有同形同色但只是平移复制的精灵对作为干扰。
- 反射轴不必位于网格中央；数据保证轴落在整格或格线上，
  且所有镜像落点在界内。

规则
- 由孪生镜像对确定唯一的反射轴。
- 孪生对保持原样；其余每个精灵整体替换为它关于该轴的镜像，
  原位清空。

关键洞察
- 反射轴从未被画出，画面上只有它的一对生成元；平移复制的对子
  无法定义轴，只有真正的镜像对才携带这条隐藏的对称线。
```

## 6. 双件拼洞

- 参考题目: `b7cb93ac`(8), `337b420f`(3), `0934a4d8`(5)
- tags:
  - operation:拼合填充, packing
  - operation:旋转, rotation
  - operation:镜像, mirror
  - object:带洞矩形, holed_rectangle
  - object:多连块碎片, polyomino_fragment
  - relation:互补拼合, complement_fit
  - condition:恰两件成对, exact_pair
  - condition:忽略干扰碎片, ignore_distractors

### docstring

```text
从散落碎片中挑出恰好能互锁填满矩形空洞的那两块，拼入洞中，其余碎片全部清除。

输入结构
- 一块大的单色实心矩形内部有一个背景色的四连通空洞。
- 矩形外散落若干各色多连块碎片，数量多于所需。

规则
- 找到唯一一对碎片，使其面积之和等于洞的面积，且允许旋转与翻转后
  能无重叠、无空隙地拼满该洞（数据保证选对与摆法唯一）。
- 按该摆法把两块碎片以各自原色填入洞中。
- 输出中矩形外的所有碎片清空。

关键洞察
- 没有任何一块碎片能独自填洞——先用面积核算筛出候选对，
  再靠两块的互锁形状确认唯一解；多余碎片是必须被排除的诱饵。
```

## 7. 先修复后延拓

- 参考题目: `baf41dbf`(4), `f9012d9b`(10)
- tags:
  - operation:补全, completion
  - operation:平铺延拓, tiling_extension
  - object:平移对称图案, translational_pattern
  - object:控制像素, control_pixel
  - object:污染格, corrupted_cell
  - relation:先修复后延拓, repair_then_extend
  - relation:控制点定延拓界, control_bounds_extension
  - condition:保持相位截断, phase_preserving_cut

### docstring

```text
先用周期多数投票修复图案里的污染格，再把修复后的周期图案延拓铺满控制像素框定的目标矩形。

输入结构
- 背景为主导色；一个具有水平与竖直平移周期的彩色图案占据一个小矩形，
  其中少量格子被统一的污染色覆盖。
- 另一颜色的孤立控制像素各自位于目标矩形四边的外侧一格处。

规则
- 对图案内每个污染格，取其平移周期轨道上未污染格的一致颜色予以恢复。
- 以修复后的图案为锚、按原周期向四周平铺，铺满控制像素框定的目标矩形，
  边界处按格截断（目标尺寸不必是周期的整数倍）。
- 控制像素原样保留。

关键洞察
- 诱饵有两层——直接平铺会把污染扩散出去，而把延拓当成拉伸会破坏相位；
  正确做法是先靠周期自证清白地修复，再保持相位地延拓截断。
```

## 8. 绕障最近染色

- 参考题目: `6df30ad6`(1), `f8f52ecc`(11)
- tags:
  - operation:重涂色, recolor
  - operation:擦除, erase
  - object:前景对象, foreground_object
  - object:标记像素, marker_pixel
  - object:障碍墙, obstacle_wall
  - relation:测地最近选择, geodesic_nearest_selection
  - condition:绕墙路径距离, path_distance_metric

### docstring

```text
用"绕墙可达步数"最少的那个标记的颜色给灰色物体重新上色，而不是直线距离最近的那个。

输入结构
- 黑色背景上有一个灰色四连通物体、若干青色墙段，以及数个不同颜色的
  孤立标记像素。
- 数据保证每个标记都能绕墙到达灰色物体，且最小步数的赢家唯一。

规则
- 对每个标记，计算它到灰色物体任一格的四连通最短路径长度，
  路径不得穿过青墙。
- 取步数最小的标记颜色。
- 输出保留青墙，擦除所有标记，把灰色物体整体涂成获胜颜色。

关键洞察
- 诱饵是欧氏最近——直线上最近的标记往往被墙隔开，真正的度量是
  绕过墙体的测地距离；墙不是装饰，它改写了"最近"的含义。
```
