## 1. 隐形围墙寻路

- tags:
  - operation:寻路, pathfinding
  - operation:连线, draw_path
  - object:标记像素, marker_pixel
  - object:隐形墙, invisible_wall
  - object:起止标记, start_end_marker
  - relation:同色配对, same_color_pairing
  - relation:行列对齐, row_col_align
  - condition:虚拟障碍触发转向, virtual_barrier_triggers_turn
  - condition:异色对为诱饵, mismatched_pair_decoy
- 参考题目：16（22eb0ac0）、17（2dd70a9a）、20（253bf280）、12（cb2d8a2c）

### docstring

```text
沿被同色对齐标记对暗示的隐形墙之间的通道，把绿色路径从起点引到红色终点。

输入结构
- 黑色背景网格，边界上有一段绿色短线（起点与初始行进方向）和一段红色短线（终点）。
- 内部散布若干彩色标记像素：一部分同色像素对严格同行或同列；
  另有异色的对齐像素对与落单像素作为干扰。

规则
- 每对同色且同行（或同列）的标记像素之间的空隙（不含端点）构成一道隐形墙；
  异色对齐对与落单像素不产生墙。
- 路径自绿色线出发直行；当前方下一格属于某道隐形墙、是标记像素或越界时，
  转向左右中唯一可通行的一侧（构造保证唯一）。
- 前方下一格为红色线时停止，将走过的格子涂绿；
  标记像素保持原样，墙始终不画出。

关键洞察
- 真正的障碍从未被画出：必须先按"同色且对齐"的配对规则在脑中补全墙体；
  异色对齐对是诱饵，路径看似绕开的是空无一物的黑格。
```

## 2. 孔洞计数定放大倍率

- tags:
  - operation:计数, counting
  - operation:像素放大, pixel_upscale
  - operation:嵌套放置, nest_inside
  - object:空心框架, hollow_frame
  - object:精灵体, sprite
  - object:孔洞, hole
  - relation:计数决定倍率, count_determines_scale
  - relation:尺寸吻合, size_fit
  - condition:多解配对由孔数唯一化, hole_count_disambiguates
  - condition:孔洞染框架色, holes_take_frame_color
- 参考题目：15（8698868d）、3（898e7135）、1（e48d4e1a）

### docstring

```text
数出每个精灵的孔洞数作为放大倍率，把放大后的精灵嵌入内腔恰好吻合的空心框架。

输入结构
- 青色背景上有若干正方形空心框架，内腔为大小不同的背景色方区。
- 别处散布若干带孔的单色精灵，每个精灵颜色不同，
  内部含若干个4连通背景色孔洞。

规则
- 每个精灵的放大倍率等于其孔洞数 n：把精灵按 n 倍像素放大。
- 放大后的精灵与内腔尺寸恰好吻合的框架配对，平移放入该内腔；
  放大后的孔洞用框架颜色填充。
- 精灵原位清为背景，框架保持不变。
- 构造上仅按尺寸凑配对存在多个可行方案，
  只有按孔洞数给出的倍率能形成全局一致的一一配对。

关键洞察
- 尺寸吻合不足以定配对；孔洞数是精灵自带的放大指令，
  只有它给出的倍率能让所有精灵与框架恰好一一对应。
```

## 3. 跨尺度模板转印与同色挖空

- tags:
  - operation:像素放大, pixel_upscale
  - operation:形状匹配, shape_match
  - operation:旋转, rotate
  - operation:翻转, flip
  - operation:印章覆盖, stamp
  - operation:擦除, erase
  - object:精灵体, sprite
  - object:占位对象, placeholder
  - relation:缩放对应, scale_correspondence
  - relation:掩码匹配, mask_matching
  - condition:占位色即删除键, placeholder_color_is_delete_key
  - condition:忽略干扰项, ignore_distractors
- 参考题目：11（321b1fc6）、3（898e7135）

### docstring

```text
把多色模板按各自的倍率与朝向转印到每个放大占位体上，并挖掉与占位色同色的模板格。

输入结构
- 黑色背景上有一个小的多色模板精灵。
- 另有若干大的单色占位体：每个都是模板掩码按某整数倍率做块级放大、
  再经过旋转或翻转得到；倍率与朝向因物体而异。
- 可能存在一个尺寸恰为模板整数倍但形状不同构的干扰物体。

规则
- 对每个占位体，找出使其块级下采样后与模板掩码重合的倍率 k 与朝向。
- 按该倍率与朝向把模板各格颜色以 k×k 块转印到占位体上；
  但模板中颜色等于该占位体自身颜色的格子，转印为背景（挖空）。
- 擦除原模板；下采样后与模板不同构的干扰物体保持原样。

关键洞察
- 占位色不只是待覆盖的底色，它还是删除键：
  每个副本都缺失模板中与自己同色的那些块，因此各副本互不相同。
```

## 4. 路径里程上的游程调色

- tags:
  - operation:寻路, pathfinding
  - operation:循环填充, cyclic_fill
  - operation:连线, draw_path
  - object:调色板列, palette_col
  - object:长度标记段, length_marker
  - object:障碍像素, barrier_pixel
  - relation:顺序排列, sequential_order
  - relation:路径里程为轴, path_arclength_axis
  - condition:标记高度决定长度, marker_height_run_len
  - condition:障碍触发转向, barrier_triggers_turn
- 参考题目：19（e7b06bea）、17（2dd70a9a）、12（cb2d8a2c）

### docstring

```text
先按转向触发像素走出一条贯穿网格的路径，再沿行进里程用调色板做游程循环上色。

输入结构
- 黑色背景，内部散布青色转向触发像素。
- 某条边界上有一个绿色起点像素，行进方向垂直该边界指向内部；
  一条边缘上排着一列有序的调色板像素；另有一段顶端对齐的灰色标记竖段。

规则
- 从绿色起点垂直边界向内直行，前方下一格为青色时
  转向左右中唯一可行的一侧（构造保证唯一），直到抵达对侧边界。
- 按行进顺序自起点之后第一格开始给路径格上色：
  依调色板顺序循环取色，每种颜色连续涂 h 格，h 等于灰色竖段的高度。
- 青色像素、调色板与灰段保持不变，起点保持绿色。

关键洞察
- 调色板不是沿行或列展开的：路径的一维里程才是真正的画布，
  颜色分段跟着步数走，拐弯不打断游程。
```

## 5. 孔洞为燃料的角落迁移

- tags:
  - operation:计数, counting
  - operation:平移, translate
  - operation:填充, fill
  - operation:擦除, erase
  - object:角落对象, corner_object
  - object:孔洞, hole
  - relation:接触两边缘, touching_two_edges
  - relation:计数决定步数, count_determines_steps
  - condition:孔洞耗尽填实, holes_consumed_filled
  - condition:顺时针迁移, clockwise_migration
  - condition:忽略干扰项, ignore_distractors
- 参考题目：6（bc93ec48）、15（8698868d）、1（e48d4e1a）

### docstring

```text
每个锚在网格角上的物体按自身孔洞数顺时针迁移相应个数的角，并在到达时把孔洞填实。

输入结构
- 背景为占多数的颜色；前景为若干单色4连通物体。
- 一部分物体的包围盒同时贴住两条相邻边界（锚在某个角）；
  其余物体贴单边或悬在内部，是干扰项。
- 角上物体内部含若干背景色孔洞。

规则
- 对每个角上物体，数其4连通孔洞数 n，沿顺时针方向
  （左上→右上→右下→左下→左上）迁移 n 个角，包围盒对齐目标角放置。
- 迁移是移动而非复制：原位清为背景；
  到达后物体的所有孔洞用其自身颜色填实。
- 非角上物体保持原样，其孔洞不填；构造保证各物体的目标角互不冲突。

关键洞察
- 孔洞是迁移的燃料：既决定绕角步数，又在到达时被耗尽填平；
  孔洞数为4的物体原地不动却变为实心，
  暴露"顺时针移一格"式简单规则的诱饵。
```

## 6. 多数决的逐波连锁染色

- tags:
  - operation:重涂色, recolor
  - operation:连锁传播, chain_propagation
  - object:连通分量, connected_component
  - object:标记像素, marker_pixel
  - relation:边邻接计数, edge_adjacency_count
  - condition:邻接多数决, adjacency_majority_rule
  - condition:逐波扩散, wavefront_spread
- 参考题目：5（477d2879）

### docstring

```text
以共享边长的多数决逐波给拼图区域染色，先染成的区域在下一波成为新的颜色源。

输入结构
- 网格被黑色与灰色的4连通区域交错铺满（同色区域互不相邻）。
- 少数彩色标记像素嵌在部分区域内部，是最初的颜色源。

规则
- 第一波：每个含有或边邻接标记像素的区域，
  染成与其共享边数最多的标记的颜色。
- 之后每一波：每个尚未染色、但与已染色区域边邻接的区域，
  统计与各颜色共享的边界长度，染成共享边界最长的那个颜色；
  构造保证每次统计无并列。
- 重复直到所有黑灰区域染毕；标记像素保持原样。

关键洞察
- 颜色不是从最近的标记一步读出的：远离标记的区域由先染色的邻区
  逐波接力决定，共享边界最长的邻居才有话语权，
  染色次序本身参与决定结果。
```

## 7. 锚定朝向的奇偶叠加

- tags:
  - operation:旋转, rotate
  - operation:翻转, flip
  - operation:透明叠加, overlay
  - object:填充矩形, filled_rectangle
  - object:锚点臂, anchor_arm
  - object:标记像素, marker_pixel
  - object:共享底色, shared_base_color
  - relation:同尺寸对齐, same_size_align
  - condition:奇偶抵消, parity_cancellation
  - condition:锚点定向归一, anchor_orientation_normalize
- 参考题目：9（25e02866）、3（898e7135）

### docstring

```text
把每个方形图层按锚点臂归一朝向后对齐叠合，标记像素按奇偶抵消合成一块输出板。

输入结构
- 背景包围若干同尺寸的正方形填充图层，共享同一底色。
- 每层某个角上有一个锚点像素，且沿一条边紧邻着第二个同色像素，
  两者构成指示朝向的短臂；各层经过不同的旋转或翻转。
- 每层内部散布若干同一种颜色的标记像素。

规则
- 将每个图层旋转/翻转，使锚点位于左上角、短臂指向右侧，
  然后按同一坐标系叠合所有层。
- 输出一块同尺寸方板：底色填充，左上保留归一后的锚点臂；
  某个位置若在奇数个图层中是标记，则涂标记色；
  偶数个（含零）则保持底色。
- 输入中的图层与其余画面不再输出。

关键洞察
- 叠加不是覆盖而是异或：重合的标记两两抵消；
  而不先按锚点臂统一朝向，奇偶统计就会在错误的格点上进行——
  朝向归一是这台奇偶机器的隐藏前提。
```
