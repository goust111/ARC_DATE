## 1. 三联帧外推

- 参考题目题号: 1（等分面板/分隔条）、3（滑动）、15（碰撞停止）、5（镜像）
- tags:
  - operation:滑动, sliding
  - operation:镜像, mirror
  - object:等分面板, equal_panel
  - object:分隔条, separator_bar
  - object:精灵体, sprite
  - relation:面板为时间帧, panel_as_time_frame
  - condition:匀速外推带反弹, extrapolate_with_bounce

### docstring

```text
把三联面板当作连续三帧动画，推算并画出第四帧。

输入结构
- 网格被两条竖直分隔条分成三个等大的面板，背景色一致。
- 每个面板含同一个单色精灵，仅位置不同；给出的三帧内精灵位移恒定，未与面板边缘发生碰撞。

规则
- 以面板内坐标读取精灵在三帧中的位置，得到恒定的每帧位移向量。
- 在单个面板大小的画布上画出第四帧：精灵按该位移再走一步。
- 若这一步使精灵包围盒越出面板，越出量按撞壁等量折返；发生反弹时精灵沿被撞墙的法向轴翻转（撞左右墙则左右镜像，撞上下墙则上下镜像）。

关键洞察
- 三个面板不是供挑选拼接的空间图层，而是时间序列；答案是画面上从未出现过的第四帧，反弹还会翻转精灵的朝向。
```

## 2. 孔洞定层序

- 参考题目题号: 12（分隔十字/层级优先）、8（透明叠加）、13（孔洞计数）
- tags:
  - operation:透明叠加, transparent_overlay
  - operation:计数, counting
  - operation:裁剪, crop
  - object:象限区, quadrant
  - object:分隔十字, separator_cross
  - object:封闭背景区域, enclosed_background_region
  - relation:图层优先级, layer_priority
  - condition:孔洞数定层序, hole_count_sets_layer_order

### docstring

```text
将分隔十字分出的四个象限叠成一层，重叠处由各象限对象的孔洞数决定谁在最上。

输入结构
- 一行一列同色分隔线构成十字，把网格分成四个等大象限。
- 每个象限是背景加一种独有前景色的掩码，前景构成一个带封闭背景孔洞的连通对象。
- 四个对象的封闭孔洞数两两不同。

规则
- 输出为单个象限大小的画布，四象限逐像素对齐。
- 某位置若有多个象限是前景，取孔洞数最多的那个象限的颜色；只有一个前景则直接取它；全为背景则输出背景。

关键洞察
- 层叠深度与象限方位无关：每一层的“高度”写在它自己的孔洞计数里，孔洞多者浮在最上，按方位排层序只在个别示例里碰巧成立。
```

## 3. 暗室成像

- 参考题目题号: 5（分隔线/镜像）、2（枢轴像素/包含）、11（印章覆盖）
- tags:
  - operation:印章覆盖, stamp
  - operation:裁剪, crop
  - object:分隔线, separator_line
  - object:小孔, pinhole
  - object:多色源图案, multicolor_source_pattern
  - object:屏幕矩形, screen_rect
  - relation:中心对称, point_symmetry
  - relation:包含, containment
  - condition:过孔倒像屏内保留, pinhole_inverted_image_on_screen

### docstring

```text
把源图案透过分隔线上唯一的小孔投影到另一侧的屏幕上，成一幅只在屏内保留的倒像。

输入结构
- 一条整行或整列的分隔线上恰有一个背景色缺口，即小孔。
- 分隔线一侧有一个多色源图案；另一侧有一块单色实心矩形屏幕，屏幕不与分隔线相贴，其余全为背景。

规则
- 以小孔单元为对称中心，把源图案的每个像素点对称映射到另一侧，颜色不变。
- 只有落在屏幕矩形内部的映射像素才被画出并覆盖屏色；落在屏外或网格外的一律舍弃。
- 源图案、分隔线、小孔与屏幕其余部分保持原样。

关键洞察
- 轴镜像的诱饵会把像投错位置甚至投不到屏上——成像上下、左右同时颠倒，只有以孔为中心的点对称才与屏上落点一致；屏幕既是画布也是裁剪窗，屏外的像根本不存在。
```

## 4. 弯管接力

- 参考题目题号: 10（双格骨牌/尺寸分类）、15（射线延伸/碰撞停止）、11（标记触发）
- tags:
  - operation:射线延伸, ray_cast
  - operation:连线, draw_line
  - object:双格骨牌, domino
  - object:标记像素, marker_pixel
  - relation:端点发射, emit_from_endpoints
  - condition:碰撞转向接力, collision_relay_turn
  - condition:标记触发起点, marker_triggers_start

### docstring

```text
从红色标记的双格骨牌出发，让射线在骨牌间接力转弯，画出整条管路。

输入结构
- 黑背景上散布若干互不相邻的双格骨牌，其中恰有一枚骨牌的一格是红色、另一格是本体色，其余骨牌整体单色。
- 布局保证射线每次都命中某枚与其行进方向垂直的骨牌的端格，且每枚骨牌至多被命中一次。

规则
- 起点骨牌以红格为尾、另一格为头，沿骨牌轴向由尾指头方向从头部射出射线。
- 射线沿直线把经过的黑格涂灰，直到进入某枚骨牌：入射格成为新的尾，另一格成为新的头，射线改沿这枚骨牌的轴向从头部继续。
- 如此接力，直到射线飞出网格；所有骨牌与红格保持不变。

关键洞察
- 每枚骨牌都是一段弯管：被击中的那端是入口，另一端指明出口方向；红色只是唯一的起点阀门，整条路径由骨牌的朝向链式决定。
```

## 5. 半张模板

  - operation:对称补全, symmetry_completion

  - operation:重涂色, recolor
  - object:占位符对象, placeholder_object
  - object:模板对象, template_object
  - relation:归一化形状匹配, normalized_shape_matching
  - condition:补全后匹配, match_after_completion

### docstring

```text
把每个彩色半模板沿切边镜像补全，再据此给同形的灰色占位对象上色。

输入结构
- 黑背景上有若干灰色占位对象和若干彩色模板对象。
- 每个彩色模板都是某个轴对称完整形状沿对称轴切开后的一半。

规则
- 把每个彩色模板沿其包围盒的某一条边镜像补全成完整形状；四种补全中恰有一种与某个灰色占位对象同形（平移比较，不旋转）。
- 将该灰色占位对象整体涂成对应模板的颜色；模板自身保持半张不动，未被任何补全命中的占位不存在。

关键洞察
- 直接拿画面上的形状去配对必然失败：彩色对象全都只画了一半，必须先在脑中补全对称；即使某半张恰与某个占位原样相同，也只有按补全后的完整形状匹配才能解释全部示例。
```

## 6. 窗口谎言

- 参考题目题号: 17（周期瓦片/最小周期推断）、2（控制像素/极值行列）、14（裁剪输出）
- tags:
  - operation:补全, repair
  - operation:裁剪, crop
  - object:周期瓦片, periodic_tile
  - object:控制像素, control_pixel
  - relation:极值行列, extreme_row_col
  - condition:窗外周期重建窗内, outside_period_rebuilds_window

### docstring

```text
用窗口外的周期规律重建被篡改的窗口内容并单独输出。

输入结构
- 整个网格本应是一个小瓦片的周期平铺；四个同色角标像素（该色不在别处出现）标出一个矩形窗口的四角。
- 窗口内部的颜色已被改写，与周期不符；窗口外的所有像素完全服从周期。

规则
- 仅用窗口外的像素推断最小周期瓦片。
- 输出一个与窗口等大的网格，内容为按周期本应出现的真实颜色；四个角标位置同样按周期恢复。

关键洞察
- 诱饵是把窗口里看到的东西裁下来交卷：窗内像素全是伪造的，唯一可信的证据在窗外，答案是画面上从未完整出现过的那块真图。
```

## 7. 柱状图图例

- 参考题目题号: 18（柱状图/计数排序）、7（同形归类）、4（擦除干扰项）
- tags:
  - operation:计数, counting
  - operation:形状匹配, shape_matching
  - operation:重涂色, recolor
  - operation:擦除, erase
  - object:柱状图, histogram_bar
  - object:连通分量, connected_component
  - relation:同形归类, shape_class_grouping
  - condition:条高等于同形个数, bar_height_equals_class_count
  - condition:无匹配者擦除, unmatched_erased

### docstring

```text
按“条高＝同形个数”的图例给灰色形状家族上色，无名家族整族擦除。

输入结构
- 网格底边立着几根互不相邻、高度两两不同的单色实心竖条。
- 其余区域是若干灰色对象；同形（平移等价）的对象构成一族，各族的成员数两两不同。

规则
- 每根竖条声明一条图例：高度为 h 的 c 色条，对应恰有 h 个成员的那一族。
- 把该族所有成员整体涂成 c 色；成员数与任何条高都不符的族，全部擦为背景。
- 竖条本身保持不变。

关键洞察
- 条形图不是要生成的摘要而是输入端的图例，且键既不是位置也不是面积，而是同形对象的出现次数——先归类、再点数、后查表，按左右顺序一一对应只是诱饵。
```

## 8. 碎行画卷

- 参考题目题号: 16（循环位移/控制列）、3（标记像素/列对齐）、5（镜像/颜色角色）
- tags:
  - operation:循环位移, cyclic_roll
  - operation:镜像, mirror
  - operation:裁剪, crop
  - object:标记像素, marker_pixel
  - object:控制列, control_column
  - relation:行独立位移, per_row_roll
  - relation:环形邻接定向, cyclic_adjacency_orientation
  - condition:辨向回卷撕边, orient_align_trim

### docstring

```text
被逐行打乱的画卷里，有的行还被整行翻转；按红蓝端点辨向、回卷、撕边，交出完整图画。

输入结构
- 真图最左列全为红色、最右列全为蓝色，红蓝不在图画本体中出现。
- 输入是真图的每一行各自做独立循环位移后的样子，且其中部分行在位移前还被整行左右翻转；因此每行恰含一红一蓝，且两者在行的环形序上相邻。

规则
- 对每一行看红蓝的环形邻接方向：蓝的右邻是红为正常行；红的右邻是蓝为翻转行，先整行左右翻转复原。
- 再将每行循环位移使红点移到最左列，此时蓝点自然落到最右列。
- 最后删除最左、最右两列，输出中间的图画。

关键洞察
- 不存在全局位移量，红点也不编码数字；红蓝是每行的两枚端点锚，它们的环形先后次序泄露该行是否被镜像过——先辨向、再回卷，散乱条纹才拼回连贯画面。
```
