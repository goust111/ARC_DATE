## 1. 隐形平行四边形筛

- 参考题目题号：cb227835、009d5c81、22a4bbc2
- tags:
  - relation:对角分解, diag_decompose
  - object:隐形边界, invisible_boundary
  - condition:同色对定角, color_pair_as_corners
  - operation:重涂色, recolor
  - operation:擦除, erase

### docstring

```text
由唯一同色像素对推出一个从未画出的平行四边形边界，据内外关系筛选并重涂散点。

输入结构
- 黑色背景上散布若干单像素前景点。
- 恰有一种颜色出现两次，其余前景颜色各出现一次。
- 同色对两点的行偏移与列偏移都非零且大小不等。

规则
- 找到唯一出现两次的颜色，把这两个像素当作平行四边形的一对对角顶点。
- 把两点间向量分解为一段45度对角向量加一段水平或垂直向量，以这两段为邻边构造平行四边形的闭合边界路径；该边界在输出中不画出。
- 严格位于边界内部的散点全部重涂为该同色对的颜色。
- 恰好落在边界路径上的散点保持原色。
- 边界外部的散点擦除为背景。
- 两个顶点像素保持原色。

关键洞察
- 承重对象（平行四边形）在画面上从未出现，必须先从唯一的同色对反推出它，
  再把它当作纯粹的分类边界使用，而不是当作要描绘的图形——"画出绿色轮廓"
  式的直觉是诱饵。
```

## 2. 中点读表

- 参考题目题号：29c11459、a834deea、009d5c81
- tags:
  - operation:连线, draw_line
  - object:色盘图例, color_dial
  - relation:对侧配对, opposite_pairing
  - relation:中点寻址, midpoint_addressing
  - operation:擦除, erase

### docstring

```text
每对对侧像素之间连一条线，线色由两点中点落在3x3色盘上的那个格子决定，最后擦掉色盘。

输入结构
- 黑背景中部某处有一个3x3实心彩色色盘，九个格子各有颜色。
- 其余前景是成对出现的单像素：每对两点同行或同列，分居色盘两侧，
  且到二者中点的距离相等。
- 每一对的中点都落在色盘九格之内。

规则
- 为每一对像素画一条端点间的完整直线段。
- 整条线（含两端点与中点）统一涂成"中点所在色盘格"的颜色，覆盖沿途一切像素。
- 未被任何线覆盖的色盘格子擦除为背景。

关键洞察
- 成对像素自身的颜色是诱饵，与输出完全无关；线色既不是端点色也不是固定色，
  而是由几何中点在色盘上"读出"的地址值——运动汇合点被当作查表地址，
  色盘是被消费掉的图例。
```

## 3. 阀门与转向

- 参考题目题号：6e453dd6、3e6067c3、5e6bbc0b
- tags:
  - operation:平移, translate
  - operation:射线延伸, ray_cast
  - object:分隔列, separator_column
  - object:控制像素, control_pixel
  - condition:孔洞触发射线, hole_triggers_ray
  - condition:颜色决定路径, color_codes_path

### docstring

```text
形状右滑贴住分隔列后，孔洞向右发射红色射线，射线遇到控制像素时按其颜色直行或转向下方。

输入结构
- 一条竖直灰色分隔列把网格分成左右两半。
- 左半是若干黑色连通形状，背景色为bg。
- 右半散布少量控制像素，颜色只有绿与蓝两种，各自独占一行一列位置，其余为bg。

规则
- 每个黑色连通体整体右移，直到右缘贴住分隔列。
- 滑动后，紧贴分隔列左侧的封闭bg孔洞所跨的每一行，向右半发射一条红色射线。
- 射线向右延伸：命中绿色控制像素则穿过并继续直行到右缘；
  命中蓝色控制像素则从该像素正下方一格起转为向下延伸，
  直到底边或撞上非bg像素为止；行内无控制像素则直行到右缘。
- 控制像素保留原色，射线只涂bg格。

关键洞察
- 红线的最终形状不是固定的整行横线，而是三层因果依次决定的结果：
  滑动制造孔洞、孔洞决定发射行、控制色改写射线路径——任何一层的改变
  都会级联改变输出。
```

## 4. 位移的奇偶

- 参考题目题号：5e6bbc0b、6e453dd6、22a4bbc2
- tags:
  - operation:压缩, compact
  - condition:标记定压缩方向, marker_sets_dir
  - condition:碰撞停止, collision_stop
  - relation:位移奇偶决定变色, displacement_parity_recolor

### docstring

```text
所有物体向青色标记所在边压缩堆叠，滑动了奇数格的物体变灰，偶数格（含未动）的保持原色。

输入结构
- 黑背景网格的某条非角落边上有一个青色标记像素。
- 网格中散布若干实心单色小物体；沿滑动方向的同一条行或列内可有多个物体。

规则
- 标记在左右边则所有物体沿行向该侧滑动，在上下边则沿列滑动。
- 每个物体滑动到撞上网格边缘或已停稳的物体为止；同一条线内靠目标边者先停。
- 统计每个物体实际滑过的格数：奇数则整体重涂为灰色，偶数（包括0）保持原色。
- 青色标记保留。

关键洞察
- 变灰与否与物体的颜色、大小、终点位置都无关，取决于一个画面上从未直接
  显示的二阶量——滑动位移——的奇偶性；而该位移又被同线物体的堆叠所改变，
  必须先正确执行压缩才能读出这个隐藏参数。
```

## 5. 钥匙定位

- 参考题目题号：f18ec8cc、18447a8d、3e6067c3
- tags:
  - object:模板缺口, template_gap
  - relation:互补形状, complementary_shape
  - condition:整块移动保持内容, block_move_intact
  - relation:钥匙三重承载, key_triple_encoding
  - operation:填充, fill

### docstring

```text
底部每把钥匙的形状指定搬哪个色块、横向位置指定块搬到哪里、颜色决定补孔色。

输入结构
- 上部由若干等宽竖直色块并排组成，每块有唯一主色，块内各有一个背景色镂空孔，
  孔形互不相同。
- 一条整行背景把上部与底部隔开。
- 底部散布与块数相同的彩色小形状（钥匙）：每把钥匙的横向范围落在恰好一个
  块位（列槽）的正下方；钥匙的横向排列顺序与孔的匹配关系没有固定规律；
  每把钥匙与恰好一个块的孔全等。

规则
- 每把钥匙指定一次搬运：孔形与该钥匙全等的块，整体搬到该钥匙正上方的列槽位置；
  块内像素随块整体移动。所有搬运同时进行，恰构成一个置换。
- 重排后把每块的孔用其匹配钥匙的颜色填实。
- 底部钥匙行清为背景。

关键洞察
- 钥匙是一物三重承载：位置指定目的地、形状指定搬运对象、颜色指定补孔色；
  "按从左到右顺序一一对应"是诱饵，真正的对应关系只由孔与钥匙的形状互补给出。
```

## 6. 自证取向的印章

- 参考题目题号：5b6cbef5、009d5c81、2bcee788
- tags:
  - operation:印章覆盖, stamp_overlay
  - relation:像素到块映射, pixel_to_block_mapping
  - operation:镜像, mirror
  - condition:自指取向选择, self_referential_orientation

### docstring

```text
把种子印进每个非黑格对应的块中，每份副本的取向必须使副本在宿主格位置上的颜色恰好等于宿主格自身的颜色。

输入结构
- 输入是一个仅含黑色与两种前景色的小网格，既是被复制的种子，也是放置掩码。
- 种子没有非平凡对称；对每个非黑格，四种取向（原样、左右镜像、上下镜像、
  180度旋转）中恰有一种满足下述自洽条件。

规则
- 输出被划分为与输入等分的块阵，每块尺寸等于输入。
- 对输入的每个非黑格(r,c)，在四种取向中选出唯一使"变换后种子在(r,c)处的颜色
  等于该格自身颜色"的取向，把该取向的种子印入对应块。
- 黑格对应的块保持全黑。

关键洞察
- 副本的取向不由任何外部图例或固定码表给出，而由一个自指条件决定：
  每份副本必须在自己所在的槽位上"自证"宿主格的颜色；同一种子因此在
  输出中以多种取向共存，取向差异正是掩码颜色分布的投影。
```

## 7. 双向的长度序号巧合

- 参考题目题号：22a4bbc2、2753e76c、e21a174a
- tags:
  - object:横条, horizontal_bar
  - operation:计数, counting
  - operation:重涂色, recolor
  - relation:长度序号自指匹配, length_equals_rank
  - condition:双向计数叠加, bidirectional_ranking

### docstring

```text
横条从上数与从下数各有一个序号，长度恰等于其中一个序号的条变红，恰好同时等于两个序号的条变蓝，其余不变。

输入结构
- 黑背景上是若干互相分离、长度各异的实心单色横条。
- 画面上没有任何方向标记或图例。
- 每个示例中既存在只在一个计数方向上满足巧合的条，
  也可能存在双向都满足巧合的条。

规则
- 从上往下给横条编号得序号t，从下往上编号得序号b。
- 某条的长度（像素数）恰等于t或b之一，则整条重涂为红色。
- 恰好同时等于t与b，则整条重涂为蓝色。
- 两者都不等的条保持原样。

关键洞察
- 被选中的条不是按颜色、位置或固定周期挑出的，而是"长度与序数两个量的巧合"；
  画面上不存在计数起点的提示，两套隐含的方向计数同时有效，
  只用单一方向去解释会在部分示例上失效——这正是埋下的诱饵。
```
