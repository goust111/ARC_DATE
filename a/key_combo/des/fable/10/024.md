## 1. 定向求交

- 参考题目题号：8 (fc7cae8d)、16 (0520fde7)、10 (77fdfe62)
- tags:
  - operation:旋转, rotate
  - operation:逻辑交, logical_AND
  - operation:重涂色, recolor
  - object:引导边, guide_edge
  - object:位掩码, bitmask
  - object:边框, frame
  - condition:正规化后对齐, canonicalize_then_align
  - condition:归属定色, attribution_coloring

### docstring

```text
把两个带指向边的方形装置各自转正后逐格比较其内部位掩码：同蓝为红、同黑为黑、仅一方为蓝处输出持蓝一方的框色。

输入结构
- 黑色背景画布上放着两个互不接触的方形装置。
- 每个装置由一圈单色边框围成，两装置框色不同；边框四条边中恰有一条整边为青色"指向边"，其余三边为该装置自己的框色。
- 边框内部是同尺寸 k×k 的蓝/黑位掩码；两个装置的摆放朝向各不相同（个别示例中恰好一致，构成诱饵）。

规则
- 将每个装置绕自身中心旋转 90° 的整数倍，使其青色指向边位于正上方。
- 在统一朝向下读取两个 k×k 内部掩码。
- 输出 k×k 网格：两掩码对应格同为蓝处输出红色，同为黑处输出黑色，仅一方为蓝处输出那一方装置的框色。

关键洞察
- 两个掩码不能按画面原样对齐：青色边定义了各装置自己的"上方"，必须先各自转正再比较；不一致格还要追溯到贡献蓝格的装置并用其框色标记归属，边框由此从装饰变成输出调色板。
```

## 2. 重复次数换轴

- 参考题目题号：9 (e1baa8a4)、19 (f25fbde4)、12 (7b7f7511)
- tags:
  - operation:压缩, compress
  - operation:去重, deduplicate
  - operation:像素放大, pixel_scaling
  - relation:相邻重复, adjacent_repeat
  - condition:重复数即数据, multiplicity_as_data
  - condition:行列重复数对调, row_col_count_swap

### docstring

```text
把被拉伸的网格还原成基底后，将行、列两组重复次数互换，重新拉伸输出。

输入结构
- 输入是无背景的实心彩色网格，由一个 k×k 的非对称基底矩阵拉伸而来。
- 基底第 i 行在输入中被连续复制成 r_i 行相同行，第 j 列被连续复制成 c_j 列相同列。
- 两组重复数不全为 1，且两序列不整体相等。

规则
- 合并相邻的相同行与相同列，得到 k×k 基底矩阵，并记录行重复数序列 r 与列重复数序列 c。
- 用对调后的次数重新展开基底：第 i 行连续复制 c_i 次，第 j 列连续复制 r_j 次。
- 输出重新展开后的网格。

关键洞察
- 重复次数不是要丢弃的冗余，而是两条按位置排列的数据序列；答案既不是压缩后的基底（去重诱饵），也不是输入的转置（被非对称基底堵住），而是同一基底在行列次数互换后的重新拉伸。
```

## 3. 四通道格阵合成

- 参考题目题号：6 (cbded52d)、7 (92e50de0)、18 (23581191)、2 (bcb3040b)
- tags:
  - operation:印章覆盖, stamp_overlay
  - operation:重涂色, recolor
  - object:分隔线格阵, separated_tile_lattice
  - object:种子图案, seed_motif
  - relation:行列交叉, row_col_intersection
  - relation:局部偏移分轴继承, offset_split_inherit
  - condition:形状竖偏随行, shape_voffset_by_row
  - condition:颜色横偏随列, color_hoffset_by_col

### docstring

```text
在分隔线格阵中，对每个有序种子对，在其"行×列"交叉单元格里合成新图案：形状与竖直偏移继承行主，颜色与水平偏移继承列主。

输入结构
- 分隔线把画布划分成若干等大的单元格阵列。
- 少数单元格内各有一个单色小图案（种子），种子颜色两两不同，且任意两个种子既不同单元行也不同单元列。
- 各种子图案的形状及其在自己单元格内的位置互不相同；其余单元格为空。

规则
- 对每个有序种子对 (A, B)，定位"A 所在单元行"与"B 所在单元列"交叉处的空单元格。
- 在该单元格内绘制 A 的图案形状，但整体涂成 B 的颜色。
- 该图案包围盒在单元格内的竖直位置取 A 图案的竖直位置，水平位置取 B 图案的水平位置。
- 所有种子自身与分隔线保持不变。

关键洞察
- 一个图案的四个属性——形状、颜色、格内竖直位置、格内水平位置——被拆成两组沿不同坐标轴独立传播：形与竖偏随单元行来自行主，色与横偏随单元列来自列主；只有完成这一双线性分解，交叉格里的每个合成图案才能同时被解释。
```

## 4. 锁孔配钥

- 参考题目题号：4 (b9b7f026)、3 (bf699163)、1 (b94a9452)、8 (fc7cae8d)
- tags:
  - operation:擦除, erase
  - operation:填充, fill
  - operation:重涂色, recolor
  - object:空心框, hollow_frame
  - object:封闭区域, enclosed_region
  - object:游离精灵, free_sprite
  - relation:负空间全等匹配, negative_space_congruence
  - condition:双色互换, two_color_swap
  - condition:多余者保留, unmatched_kept

### docstring

```text
把每个游离精灵与形状全等的框内孔洞配对：精灵消失，孔洞填上框的原色，框重涂为精灵的颜色。

输入结构
- 背景画布上有若干单色空心框，每个框完整包围一块背景孔洞；孔洞形状各异且不都是矩形。
- 画布其余位置散布着比框多一个的游离单色实心精灵，互不接触；框色与精灵色之间没有任何对应关系。
- 每个孔洞的形状与恰好一个精灵全等（允许旋转与镜像）；恰有一个精灵与任何孔洞都不全等。

规则
- 对每个空心框，找到与其孔洞形状全等的精灵。
- 将该精灵从原位置擦除。
- 把该框的孔洞整块填成该框原来的框色，同时框本身重涂为该精灵的颜色。
- 与任何孔洞都不匹配的精灵原样保留。

关键洞察
- 配对的依据是从未被画出的负空间——框内那块缺失的背景才是锁孔的形状；钥匙插入后发生颜色置换：精灵色浮到框上、框色沉入孔中，而多出的那个精灵是检验是否真正做了形状匹配而非按色配对的试金石。
```

## 5. 弹射变色路径

- 参考题目题号：2 (bcb3040b)、15 (8403a5d5)、18 (23581191)、1 (b94a9452)
- tags:
  - operation:射线延伸, ray_extend
  - operation:连线, draw_line
  - operation:重涂色, recolor
  - object:种子像素, seed_pixel
  - object:画布边界, canvas_boundary
  - relation:对角反弹路径, diagonal_bounce_path
  - condition:反弹换色, toggle_on_bounce
  - condition:交叉点特殊着色, intersection_colored
  - condition:角落终止, corner_termination

### docstring

```text
从对角双色发射器出发画反弹路径，每次反弹在两色之间切换段色，被路径经过两次的格子变红。

输入结构
- 黑色画布上唯一的前景是一个对角相邻的双像素发射器，两格颜色不同，分别为 A 色与 B 色。
- 从 A 指向 B 的对角方向即发射方向。
- 画布尺寸保证路径在有限步内到达某个角落。

规则
- 路径从 B 格之后沿发射方向逐格对角延伸，起始段涂 B 色。
- 碰到画布边缘按 45 度反弹继续；每反弹一次，当前段颜色在 A、B 之间切换。
- 路径到达画布角落时终止。
- 被路径经过不止一次的格子最终涂红，只经过一次的格子保持其所属段的颜色；发射器两格原样保留。

关键洞察
- 发射器同时编码了起点、方向与两种交替色；路径颜色是一个随反弹翻转的状态而非固定属性，红格标出的正是这条折线与自身的交点。
```

## 6. 对称为钥的拼合

- 参考题目题号：14 (f560132c)、12 (7b7f7511)、9 (e1baa8a4)
- tags:
  - operation:拼图组装, jigsaw_assemble
  - operation:裁剪, crop
  - object:碎片, fragment
  - object:重复瓦片, repeated_tile
  - relation:轴向复制, axial_dup
  - condition:对称约束定拼法, symmetry_locks_assembly
  - condition:沿重复轴取首半, first_half_extract

### docstring

```text
把散落碎片平移拼成一个恰为自身双份复制的矩形，并输出其中的单份底图。

输入结构
- 背景色画布上散落若干互不接触的多色碎片。
- 碎片只允许平移，不允许旋转或镜像。
- 所有碎片可以无缝无重叠地拼成一个实心矩形，且能成立的拼法唯一地使该矩形沿某一条轴恰好等于同一图案的两份相邻复制。

规则
- 将全部碎片平移拼合成实心矩形，使矩形沿水平或竖直方向由两个完全相同的半区组成。
- 找到这条复制轴，输出矩形沿该轴的前一半。

关键洞察
- 拼图没有给出任何目标图案或颜色图例，"拼完后必须是自身的双份复制"这一对称约束本身就是唯一能锁定拼法的钥匙；而答案还要再剥掉这层冗余，只保留单份底图。
```
