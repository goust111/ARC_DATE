## 1. 缺口引路

- 参考题目题号：5（5a5a2103）、11（1190e5a7）、19（6ca952ad）
- tags:
  - object:分隔网格, divider_grid
  - object:单像素缺口, wall_gap
  - operation:滑动, slide
  - relation:级联路由, cascade_routing
  - condition:无缺口格为汇点, sink_cell
  - operation:填充, fill

### docstring

```text
让每个彩色像素沿着单元格墙上的缺口逐格穿行，最终把它到达的无缺口单元格整格染色。

输入结构
- 分隔色的完整横竖条把画布划分成等大的矩形单元格。
- 部分墙段上恰好缺失一个像素（缺口），每个单元格四面墙上合计至多一个缺口。
- 少数单元格内部各有一个彩色像素，其余单元格内部为空。
- 保证沿缺口指引前进不会成环，且每个无出口格至多接收一个像素。

规则
- 把每个缺口理解为所在单元格的唯一出口，出口方向为从格内指向该缺口所在的那面墙。
- 每个彩色像素反复执行：穿过当前格的出口进入相邻格；若当前格没有出口，则停止。
- 像素停在的格即汇点：把该汇点格的内部整格涂成该像素的颜色，像素原位置恢复为背景。
- 分隔条连同缺口保持原样；没有像素到达的格内部保持背景。

关键洞察
- 墙上的缺失像素不是破损或噪声，而是一张单向门路线图；答案由整条传递链的
  终点决定，而不是由像素的起始格决定。
```

## 2. 灰影归位

- 参考题目题号：4（d6542281）、8（269e22fb）
- tags:
  - object:多色精灵体, multicolor_sprite
  - object:灰色残影, gray_silhouette
  - operation:模板匹配, template_matching
  - relation:二面体变换, dihedral_transformation
  - operation:印章覆盖, stamp_overlay
  - condition:唯一完全覆盖, unique_full_cover

### docstring

```text
为每片灰色残影找到唯一能完全盖住它的精灵姿态，并在原地把该精灵完整印出。

输入结构
- 黑底上有若干互不相同的 8-连通多色精灵。
- 另有若干灰色像素团，每团是某个精灵经过某种旋转或镜像后的形状足迹的一部分，
  不携带任何颜色信息。
- 保证对每团灰影，恰有一个（精灵、姿态、平移）组合使精灵足迹完全覆盖该团灰影，
  且印下后不与其他前景重叠。

规则
- 对每团灰影，遍历每个精灵的八种旋转镜像姿态与所有平移，找出使灰影每个像素
  都落在精灵足迹内的唯一方案。
- 按该姿态与位置把精灵的完整彩色图案印在画布上，覆盖这团灰影。
- 原精灵保持原位不动，背景其余部分不变。

关键洞察
- 灰影只提供形状碎片：既要认出它属于哪个精灵，还要认出精灵被转到了哪个姿态；
  颜色要在匹配完成后才能从原精灵搬运过来。
```

## 3. 零点转码

- 参考题目题号：5（5a5a2103）、10（e681b708）、11（1190e5a7）
- tags:
  - object:分隔网格, divider_grid
  - object:模板掩码, template_mask
  - object:散点, scatter_dots
  - operation:计数, counting
  - operation:旋转, rotation
  - relation:点数差定姿态, count_delta_sets_pose
  - relation:点色定涂色, dot_color_sets_paint
  - condition:基准零点在模板格, baseline_in_template_cell

### docstring

```text
以模板格自带的散点数为零点基准，其余格按点数与基准之差决定模板旋转、按点色决定涂色后印回各格。

输入结构
- 分隔条把画布分成等大的单元格。
- 恰有一格含一个灰色的非对称模板图案，该格内另散布若干灰色散点（基准点）。
- 其余格或者为空，或者含 1 至 4 个同色彩色散点；散点在格内位置任意，
  同一格内颜色一致，不同格可不同。

规则
- 读取模板格中的灰色图案作为模板，数出模板格内的基准点数 b。
- 对每个含彩色散点的格：清除散点，把模板逆时针旋转 ((该格点数 − b) mod 4)×90 度，
  涂成该格散点的颜色，按模板在原格内的相对位置印入该格。
- 空格保持为空；模板格清除基准点、保留灰色模板；分隔条不变。

关键洞察
- 散点是双通道编码：个数管旋转、颜色管涂色，而位置无关紧要；旋转编码还是
  相对的——零点藏在模板格自己的散点里，把点数当绝对旋转数，会在基准不为一
  的示例上全面出错。
```

## 4. 一线三职

- 参考题目题号：15（15696249）、5（5a5a2103）、6（539a4f51）
- tags:
  - object:输入瓦片, input_tile
  - object:引导行或列, guide_row_or_column
  - operation:平铺, tiling
  - operation:画布扩展, canvas_expansion
  - operation:重涂色, recolor
  - relation:引导线选带, guide_selects_band
  - relation:引导线为调色序列, guide_as_palette
  - condition:黑位留空, black_slot_empty

### docstring

```text
引导线同时指定放大画布中的带位置、带内哪些块被放置、以及每份拷贝的涂色。

输入结构
- 输入是 n×n 瓦片，恰有一条行或列整条被占用为引导线：其上每个位置或为某种
  颜色或为黑。
- 引导线至少含两种非黑颜色；瓦片其余部分是黑底上的一个单色图形。

规则
- 输出为 n×n 个块、每块 n×n 的全黑画布。
- 若引导线是第 r 行，考察块行 r：对第 c 个块，若引导线第 c 个位置非黑，
  则把图形（不含引导线）按原相对位置放入该块，并整体重涂为该位置的颜色；
  若该位置为黑，则该块留空。引导线为列时按块列与行号对称处理。
- 其他块全部保持黑。

关键洞察
- 引导线被读了三次：它的行列号选定带，它的黑与非黑决定带内块的有无，它的
  颜色序列决定各块涂色；瓦片图形自身的颜色只是占位，从不出现在输出中。
```

## 5. 斜线量尺

- 参考题目题号：16（5c0a986e）、12（db93a21d）、9（928ad970）
- tags:
  - object:对角线段, diagonal_segment
  - object:彩色散点, color_dot
  - operation:尺寸映射, length_to_size
  - operation:方形绘制, square_draw
  - operation:擦除, erase
  - relation:方向定角, dir_sets_corner
  - condition:覆盖取色, covered_dot_colors

### docstring

```text
每条灰色斜线在其内端长出一个边长等于线长的实心正方形，颜色取自它罩住的那颗散点。

输入结构
- 黑底上有若干条灰色 45 度线段，每条从网格边缘出发向内部延伸。
- 画布上另散布若干彩色单像素点。
- 保证每个待生成的正方形区域内恰好落有一颗散点，各正方形互不重叠且完全在界内。

规则
- 对每条灰线段，记其像素数为 L、延伸方向为 d：在线段内端点沿 d 方向再前进
  一步的位置作为角点，铺一个 L×L 的实心正方形，使该角点是正方形上与线段
  相接的那个角。
- 正方形涂成它覆盖区域内那颗散点的颜色，散点被并入正方形。
- 灰线段保留原样；未被任何正方形覆盖的散点清除为背景。

关键洞察
- 灰线是量尺兼指针：长度给边长，方向给安放角；散点看似噪声，其实是颜色
  种子——但只有先确定正方形的位置与大小，才能知道每颗种子属于谁、哪些
  种子被淘汰。
```

## 6. 尺寸之钥

- 参考题目题号：19（6ca952ad）、7（57edb29d）、12（db93a21d）
- tags:
  - object:空心容器, hollow_container
  - object:水平横条, horizontal_bar
  - operation:滑动, slide
  - operation:重力下落, gravity_drop
  - relation:长度配内宽, length_matches_width
  - condition:有键传送无键坠落, keyed_teleport_else_fall
  - condition:先入座后落体, seat_before_fall

### docstring

```text
每根横条飞向内宽与它等长的空心容器并沉底，配不上对的条才服从普通重力竖直坠落。

输入结构
- 黑色背景。画布下部散布若干开口朝上的 U 形空心容器（同一墙色），内宽互不相同。
- 画布上部悬浮若干水平的单像素厚横条（各自颜色不同），长度互不相同。
- 横条长度与容器内宽之间至多一一相等；至少有一根横条不存在等宽容器，
  至少有一个容器不被任何条匹配。
- 保证无匹配横条各自的竖直下落路径互不干扰。

规则
- 对每根横条，寻找内宽恰好等于其长度的容器：若存在，则该条水平平移到该容器
  开口正上方并竖直落入，恰好嵌在两壁之间、贴着容器内底放置。
- 所有有匹配的条就位之后，没有等宽容器的横条再从各自原位置竖直下落，停在其
  正下方遇到的第一个障碍（容器外壁、已落定的条或画布底边）之上。
- 容器形状与所有横条的颜色保持不变；条的原位置恢复为背景。

关键洞察
- 画面伪装成一场普通的重力游戏，但多数条走的其实是"钥匙配锁"路线：长度是键、
  内宽是锁，横向位置无关紧要；只有配不上锁的条才真正服从竖直重力，两套
  运动学在同一画面并存，须分对象辨别。
```
