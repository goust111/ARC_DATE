## 1. 对称缺口成形

- 参考题目题号: 6 (8e5c0c38)、12 (903d1b4a)、18 (72ca375d)
- tags:
  - operation:对称补全, symmetry_completion
  - operation:裁剪, crop
  - object:色层, color_layer
  - object:对称轴, symmetry_axis
  - relation:逐色处理, per_color_processing
  - condition:缺口集合即输出图形, missing_cells_form_output

### docstring

```text
收集各色层相对自身镜像轴缺失的像素位置，这些缺口本身拼成要输出的图形。

输入结构：
- 黑色背景上有若干种非黑颜色，每种颜色的像素关于某条属于自己的竖直轴几乎镜像对称。
- 每种颜色都有少量像素在轴另一侧缺少镜像伙伴，缺失位置在输入中是黑色。
- 不同颜色的对称轴位置互不相同。

规则：
- 对每种颜色，找出使未配对像素最少的竖直镜像轴。
- 对每个缺少镜像伙伴的像素，取其关于该轴的镜像位置，记为该颜色的一个缺口。
- 汇总所有颜色的缺口位置，取它们的最小包围框裁剪，缺口处涂对应颜色，其余为黑。

关键洞察：
- 表面上像逐色去噪或补全对称，实际上既不删也不补：真正的答案是那些"本应存在
  却没画出来"的格子集合，它们共同构成一个从未在输入中出现过的图形。
```

## 2. 遮挡深度直方图

- 参考题目题号: 3 (9af7a82c)、5 (cf98881b)
- tags:
  - operation:计数, counting
  - operation:排序, sort
  - object:实心矩形, solid_rectangle
  - object:柱状图, histogram_bar
  - relation:前后遮挡, front_back_occlusion
  - relation:层序推断, depth_order_inference
  - condition:柱高等于被遮面积, bar_height_is_hidden_area

### docstring

```text
复原相互遮挡的实心矩形，按由前到后的层序排列成柱状图，柱高等于每个矩形被遮住的像素数。

输入结构：
- 黑色背景上有若干个颜色互不相同的实心矩形，它们相互重叠成一摞，每个矩形只露出一部分。
- 每个矩形至少露出两个对角的角点，因此其完整范围可以复原。
- 任意两个重叠矩形之间可见的覆盖关系构成一条完整的前后链。

规则：
- 由可见角点复原每个矩形的完整范围。
- 若矩形 A 的完整范围内某格显示的是矩形 B 的颜色，则 B 在 A 之前；由此排出全部矩形的前后总序。
- 统计每个矩形被其它矩形遮住的格数。
- 输出宽度等于矩形个数、高度等于最大被遮格数的黑底网格：第 k 列对应前后序中第 k 个矩形，
  用其颜色从顶部向下涂其被遮格数那么多格。

关键洞察：
- 柱状图的排列顺序不是按数量排序，而是按遮挡推出的深度；柱子的高度数的恰恰是画面上
  看不见的那部分面积，最前面的矩形对应一根空柱。
```

## 3. 转折残迹折线楔形

- 参考题目题号: 15 (a65b410d)、13 (7ec998c9)、14 (50aad11f)
- tags:
  - operation:填充, fill
  - operation:外推, extrapolate
  - object:线段, segment
  - object:标记像素, marker_pixel
  - object:折线路径, folded_path
  - relation:转折残迹, breakpoint_residue
  - condition:分段斜率末段外推, piecewise_slope_last_extends

### docstring

```text
散点是从未画出的折线边界的转折点，把红色横段两侧按各自折线围成的区域整片填色。

输入结构：
- 黑色背景上有一条从左边界出发的红色水平线段。
- 红段上方散布若干绿色孤立像素，下方散布若干蓝色孤立像素。
- 每侧的边界是一条以红段右端点为起点、依次经过该侧全部散点的折线：相邻两个转折点
  之间每行的列移动量为固定整数，但不同段的移动量各不相同。

规则：
- 把每侧散点按行序与红段右端点连成折线，求出每一段的每行步长。
- 越过该侧最后一个散点后，边界以最后一段的步长继续延伸到网格边缘。
- 红段上方每行从左边界涂绿到该行边界所在列（含），下方每行涂蓝到该行边界所在列（含）；
  边界超出右边界则截到右边界，退出左边界即停止。
- 保留红段；散点被填充吸收，不再单独可见。

关键洞察：
- 边界折线从未被画出，散点只是它的转折残迹；用单一全局斜率去拟合会在某段出错，
  必须识别"每过一个散点斜率就改变、末段斜率负责外推"的分段结构。
```

## 4. 残点连锁搬运

- 参考题目题号: 19 (54dc2872)、14 (50aad11f)
- tags:
  - operation:平移, translate
  - operation:擦除, erase
  - object:多色精灵体, multicolor_sprite
  - object:嵌入标记像素, embedded_marker
  - object:孤立控制点, isolated_control
  - relation:颜色配对, color_pairing
  - relation:连锁反应, chain_reaction
  - condition:残迹成为新控制点, residue_becomes_control

### docstring

```text
唯一的孤立控制点召唤标记同色的精灵搬家，精灵离开时留下的体色残点又召唤下一个精灵，
如此连锁直至无人应召。

输入结构：
- 黑色背景上分布若干多色精灵：每个精灵是一种体色的小连通块，内部嵌有恰好一个异色标记像素。
- 任一颜色至多充当一个精灵的体色，也至多充当一个精灵的标记色。
- 另有恰好一个孤立的单像素，是初始控制点。

规则：
- 找到标记色等于当前控制点颜色的精灵，将它整体平移，使其标记像素恰好落在控制点上，
  控制点被覆盖消耗。
- 该精灵离开原位时，在原标记像素所在的格子留下一个其体色的单像素，成为新的控制点。
- 重复上述过程，直到没有精灵的标记色与当前控制点颜色相同为止；最后留下的残点保留在画面上。
- 标记色始终不被召唤的精灵原地不动。

关键洞察：
- 输入里只画了一个控制点，其余控制点都是搬运过程自己产生的；精灵的落点依赖前一次搬运
  留下的残迹，必须按因果链逐个推演，不能各自独立决定。
```

## 5. 形色双拉丁消元

- 参考题目题号: 1 (8d5021e8)、7 (39a8645d)、12 (903d1b4a)
- tags:
  - operation:补全, complete
  - object:精灵体阵列, sprite_array
  - relation:阵列排布, array_layout
  - relation:行列拉丁约束, latin_square_constraint
  - condition:形状颜色解耦, shape_color_decoupled
  - condition:双空格消元, two_blank_elimination

### docstring

```text
在形状与颜色各自满足行列不重复的精灵阵列中，用消元法补出两个空位上的精灵。

输入结构：
- 网格划分为 n×n 个等距摆放的精灵位，每个位置放一个小精灵。
- 所有精灵共有 n 种形状与 n 种颜色：每行每列的 n 个形状互不相同，每行每列的
  n 种颜色也互不相同。
- 形状与颜色的绑定不固定，同一形状在不同位置可以是不同颜色。
- 恰有两个精灵位是空的，且位于同一行的不同列。

规则：
- 该行缺少两种形状与两种颜色。
- 对每个空位，看其所在列已有的形状与颜色，从行缺失集合中排除已在该列出现者，
  剩下的形状与颜色即属于该空位。
- 输出与输入同尺寸的网格，在两个空位画上推得的精灵，其余保持不变。

关键洞察：
- 空位上该画的"形状-颜色"组合很可能从未在输入中整对出现过：形状约束与颜色约束是
  两张相互独立的拉丁方，必须分别消元再拼合，而不是从画面上找一个现成精灵来抄。
```

## 6. 对齐减层复原背景

- 参考题目题号: 5 (cf98881b)、6 (8e5c0c38)、12 (903d1b4a)
- tags:
  - operation:透明叠加, transparent_overlay
  - operation:对称补全, symmetry_completion
  - operation:平移匹配, translation_matching
  - object:色彩面板, color_panel
  - object:分隔列, separator_column
  - relation:前后遮挡, front_back_occlusion
  - relation:因果反演, causal_inversion
  - condition:被遮区域靠镜像恢复, occluded_recovered_by_mirror

### docstring

```text
在合成画面中找到前景图案的落点，把它减去，再用背景层自身的左右镜像对称补上被遮住的洞，
输出完整背景层。

输入结构：
- 一条红色竖直分隔线把输入分成两块面板。
- 一块是合成画面：背景层被前景层覆盖，前景的非黑像素遮住其下内容。
- 另一块面板单独画出前景图案，但它在合成画面中的位置是任意的：前景图案以某个未知的
  平移嵌在合成画面中，且该精确匹配位置唯一。
- 据"该面板全部非黑像素能在合成画面中整体平移匹配"辨认哪块是前景面板。
- 背景层关于自身竖直中线镜像对称，且前景从不同时盖住一对镜像格。

规则：
- 在合成画面中搜索前景图案的唯一平移匹配位置。
- 匹配处的格子属于前景，其余格子的合成值就是背景值。
- 被前景占据的格子，背景值取其关于背景层竖直中线的镜像位置的值。
- 输出合成画面面板大小的背景层。

关键洞察：
- 前景面板给的是"是什么"而不是"在哪里"，必须先完成对齐才能做叠加的逆运算；
  被减掉后留下的洞并非丢失，背景的镜像对称保证每个被遮格的伙伴可见——
  对称性在这里是解除遮挡的钥匙，不是修复目标。
```
