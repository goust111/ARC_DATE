## 1. 级联滚动条带

- 参考题目：79cce52d、29623171、03560426
- tags:
  - operation:循环位移, cyclic_roll
  - operation:裁剪, crop
  - object:控制行, control_row
  - object:标记像素, marker_pixel
  - relation:级联传递, cascade_transfer
  - condition:标记位定位移量, marker_is_shift
  - condition:上一行输出即下一行指令, previous_output_is_next_command

### docstring

```text
删去顶部控制行后，各负载行依次循环右移，每行的位移量等于上一行滚动完成后其青色标记所在的列号。

输入结构：
- 网格顶行为控制行：灰色填充中含唯一一个青色标记像素。
- 其余每行为一条负载行：由多色图案组成，且每行恰含一个青色像素。

规则：
- 删除顶部控制行。
- 第一条负载行循环右移的步数为控制标记的列号（从 0 计）。
- 此后每条负载行的位移步数等于上一条负载行滚动完成后青色像素所在的列号。
- 逐行处理直至底部，输出为全部滚动后的负载行。

关键洞察：
- 位移量不是全局常数，而是逐行级联传递——每一行滚动后的标记落点成为
  下一行的控制指令；只按控制行统一平移会从第二行起全部出错。
```

## 2. 图例相位延伸

- 参考题目：53fb4810、5af49b42
- tags:
  - operation:周期平铺, periodic_tiling
  - operation:射线延伸, ray_extension
  - object:边缘图例串, edge_legend_string
  - object:墙条, wall_bar
  - object:标记像素, marker_pixel
  - relation:邻接侧决定方向, adjacency_side_determines_dir
  - relation:颜色位置匹配, color_position_matching
  - condition:图例锚定相位, legend_anchored_phase

### docstring

```text
把每个贴墙标记沿背离墙的方向延伸为周期重复的图例串，相位以标记颜色在图例中的唯一位置锚定。

输入结构：
- 底行是一条由互不相同颜色组成的水平图例串，其上方以整行黑色与场地分隔。
- 场内有若干竖直灰色墙条。
- 每条墙的左侧或右侧紧贴一个或多个彩色标记像素，标记颜色都在图例串中恰好
  出现一次。

规则：
- 对每个标记，确定其贴在墙的哪一侧，沿其所在行向背离墙的方向铺设图例串的
  周期重复，直至网格边缘或撞到另一面墙。
- 相位对齐使标记像素恰好处于其颜色在图例串中的下标位置。
- 朝墙一侧不延伸；墙与图例行不被覆盖。

关键洞察：
- 标记不是被替换成一次图例拷贝，而是一个相位锚——方向由贴墙侧决定，
  内容由图例决定，相位由颜色在图例中的唯一下标决定，三者缺一不可。
```

## 3. 隐形矩形递归显影

- 参考题目：7837ac64、29623171、67636eac
- tags:
  - operation:计数, counting
  - operation:筛选, filtering
  - operation:裁剪, crop
  - operation:递归收缩, recursive_shrink
  - object:顶点标记, vertex_marker
  - object:隐形矩形, invisible_rectangle
  - object:散点, scattered_dot
  - relation:生成元重建, generator_reconstruction
  - condition:最密区域胜出, densest_region_wins
  - condition:逐层钻入, layer_by_layer_descent

### docstring

```text
由同色四角点定义的隐形矩形按内部灰点数投票选出胜者，再钻入胜者内部对次级隐形矩形重复投票，直至无矩形可选，输出最深层胜者的内部裁剪。

输入结构：
- 黑底；若干种颜色各出现恰好四个像素，构成一个轴对齐矩形的四角，矩形边框
  从未画出。
- 部分四角组完整地位于其他四角组所围矩形的内部，形成多层嵌套。
- 另有散布的灰色单点。

规则：
- 在当前画布（初始为整幅输入）内，找出所有完整的同色四角组并重建各自的
  隐形矩形。
- 统计每个矩形严格内部的灰点数，取计数最大（唯一）者为胜者。
- 把画布收缩为胜者的严格内部，重复上述投票；当画布内不再存在完整四角组时
  停止。
- 输出最终画布的裁剪：灰点保留为灰色，其余格子填充最后一轮胜者的角点颜色。

关键洞察：
- 矩形从未被画出，四个角点只是生成元；而且投票不是一次性的——胜者内部还
  藏着下一轮选举，落在画布外的角点组自动失去参选资格，必须逐层钻入才能
  到达真正的输出。
```

## 4. 青色炮口连锁传色

- 参考题目：d90796e8、b7256dcd、a8c38be5、53fb4810
- tags:
  - operation:射线延伸, ray_extension
  - operation:重涂色, recolor
  - operation:擦除, erase
  - object:双色多米诺, bicolor_domino
  - object:中性遮罩, neutral_mask
  - object:炮口像素, muzzle_pixel
  - relation:方向编码, direction_encoding
  - relation:连锁接力, chain_relay
  - condition:命中即整体染色, hit_recolors_region
  - condition:忽略干扰项, ignore_distractors

### docstring

```text
彩色体经由紧贴的青色炮口发射射线为远处灰区染色，被染色的灰区又能借自己身边的青色炮口继续开炮，形成接力链。

输入结构：
- 黑底；若干灰色 4 连通区域作为中性遮罩。
- 若干单格彩色像素，其中一部分与一个青色像素 4 邻接成对，构成初始发射器。
- 部分灰色区域边上也紧贴着青色单像素。
- 另有不与任何青色配对的孤立彩色像素作为干扰项。

规则：
- 任何"已着色的物体 + 紧贴其边的青色单像素"构成一门炮，方向取从物体指向
  青色像素的邻接方向。
- 从青色像素沿该方向发射射线穿过黑色格，命中的第一个灰色区域整体重涂为
  该物体的颜色。
- 被染色的区域若也紧贴着青色像素，则以同样方式继续发射同色射线，逐级接力，
  直至射线出界或无青色炮口；输入保证每个灰区至多被一条射线命中。
- 最后擦除所有青色像素与初始彩色单像素；未被命中的灰区保持灰色，孤立彩色
  干扰像素保留。

关键洞察：
- 青色像素不是装饰而是通用炮口——谁有颜色谁就能开炮；颜色沿着
  "多米诺→灰区→灰区"的指向链远程接力，而不是传给空间上最邻近的区域，
  且整条链最后不留任何发射装置的痕迹。
```

## 5. 锚点对齐与密度层序叠加

- 参考题目：e99362f0、2f0c5170、29623171、ea32f347
- tags:
  - operation:透明叠加, transparent_overlay
  - operation:平移对齐, translate_and_align
  - operation:计数, counting
  - object:面板, panel
  - object:十字分隔线, cross_separator
  - object:共享锚点像素, shared_anchor_pixel
  - relation:锚点偏移对应, anchor_offset_correspondence
  - relation:密度排名定层序, density_rank_layer_order
  - condition:最稀疏者最上层, sparsest_on_top

### docstring

```text
移除十字后，四个面板按白色锚点对齐平移，再按前景像素数从多到少的顺序叠加，最稀疏者压在最上层。

输入结构：
- 一条完整十字（整行加整列）把网格分成四个等尺寸面板。
- 每个面板含黑色背景、一种前景色的若干像素、以及恰好一个白色锚点像素。
- 四个面板的前景像素数两两不同。

规则：
- 移除十字；以前景像素最多的面板为基准画布并保持其自身坐标。
- 其余面板整体平移，使各自白色锚点与基准锚点重合，越界像素裁掉。
- 按前景像素数从多到少的顺序依次把各面板的前景像素画上画布，后画者覆盖
  先画者。
- 锚点像素视为背景，不参与叠加，输出中不出现白色。

关键洞察：
- 图层顺序不由面板方位决定，而由前景密度排名决定——最稀疏的面板最后落笔
  覆盖一切；锚点只负责对齐，本身不是内容。
```

## 6. 榫卯锁链拼接

- 参考题目：67636eac、5af49b42、03560426、de809cff
- tags:
  - operation:裁剪, crop
  - operation:拼接, concatenate
  - operation:排序, sort
  - operation:缺陷修复, defect_repair
  - object:实心矩形, solid_rectangle
  - object:孔洞, hole
  - object:榫头, tenon
  - relation:锁匙匹配, lock_and_key_matching
  - condition:榫列等于上家孔列, tenon_column_equals_hole_column
  - condition:无榫者为链头, tenonless_is_head

### docstring

```text
把同尺寸的实心单色矩形按"榫头列号等于上家孔洞列号"的锁匙关系连成唯一链条，自上而下插接拼合。

输入结构：
- 黑底上分布 k 个彼此分离的 h×w 实心单色矩形精灵。
- 每个精灵内部恰有一个单格黑色孔洞。
- 除一个精灵外，其余每个精灵的顶边正上方还贴着一个与其同色的单格榫头。
- 所有孔洞列号与榫头列号使得"榫头列号 = 上家孔洞列号"能且只能连成一条
  覆盖全部精灵的链。

规则：
- 无榫头的精灵是链头，置于最上。
- 此后每一节选取榫头列号等于上一节孔洞列号的精灵接在下方。
- 拼接时下家的榫头插入上家的孔洞——输出中该孔洞格显示下家的颜色，榫头
  本行不再单独占行。
- 链尾精灵的孔洞无人插入，保持黑色；输出为 (k·h)×w 的垂直拼接。

关键洞察：
- 既不能按画面位置排序，也不能按孔洞位置排序——次序由孔与榫的几何锁匙
  匹配唯一决定；孔洞在输出中被下家的颜色填住，成为链条咬合过的残迹，而
  链尾留下的那个黑孔正是链条终点的证据。
```
