## 1. 弹射入槽

- 参考题目: a3df8b1e, d9f24cd1, db7260a4
- tags:
  - operation:弹射模拟, bounce_simulation
  - operation:填充, fill
  - object:标记像素, marker_pixel
  - object:障碍像素, blocker_pixel
  - object:容器, container
  - relation:反射弹回, reflection_bounce
  - condition:着地列选容器, landing_column_selects
  - condition:无容器仅涂着地格, no_container_single_cell

### docstring

```text
让顶部弹子沿斜线在侧壁与灰色障碍间弹射下落，用其着地列选中的红色容器灌注弹子颜色。

输入结构
- 黑色背景。顶行有一个蓝色弹子像素，其左侧或右侧紧邻一个青色方向像素。
- 网格内部散布若干灰色障碍像素；底部有若干开口朝上的红色 U 形容器
  （两壁一底，内腔为空的矩形区域）。
- 保证弹射路径每步至多触发一次反转，路径不穿过容器，且着地列至多落在
  一个容器的内腔列范围内。

规则
- 弹子从蓝色像素出发沿斜下方向移动，初始水平朝向为背离青色方向像素的一侧。
- 每步斜向移动一格；若目标格越出左右边界或为灰色像素，则水平朝向反转后
  再斜向移动，竖直分量始终向下。
- 弹子到达底行后：若着地列位于某容器内腔的列范围内，把该容器内腔全部
  涂成蓝色；否则仅把着地格涂成蓝色。
- 输出中清除顶行的蓝色与青色标记，障碍与容器保持不变。

关键洞察
- 弹子的运动轨迹本身不画出，画面只保留结果；着地列由斜线弹射决定，
  把弹子按起始列竖直投影会选中错误的容器。灰色像素不是遮挡物，
  而是与左右边界同等地位的反射壁。
```

## 2. 象限配对余数取色

- 参考题目: 996ec1f3, 6165ea8f, 9a4bb226
- tags:
  - operation:压缩, compress
  - operation:形状匹配, shape_match
  - operation:配对消去, pair_elimination
  - object:十字分隔线, cross_separator
  - object:四象限, quadrant
  - object:归一化掩码, normalized_mask
  - relation:旋转翻转等价, dihedral_equiv
  - condition:落单者入选, unpaired_selected
  - condition:忽略干扰项, ignore_distractors

### docstring

```text
在每个象限内把对象按形状两两配对消去，把四个落单对象的颜色压缩进 3x3 输出的四角。

输入结构
- 恰有一整行与一整列为同一分隔色，构成把网格划成四个矩形象限的十字。
- 每个象限内有奇数个互不相触的单色小对象。象限内的对象在旋转或翻转
  等价意义下恰能两两配成同形对，只剩一个对象没有同形伙伴。
- 同一配对的两个对象颜色互不相同、朝向不同，且大小与摆放位置无规律；
  四个象限落单对象的形状互不等价，颜色与大小亦无跨象限规律。

规则
- 把每个对象归一化为紧致掩码，在旋转与翻转等价下于象限内部两两配对。
- 找出每个象限中唯一没有同形伙伴的落单对象。
- 输出 3x3 网格：中间行与中间列涂分隔色，每个角格涂对应象限落单对象
  的颜色，其余对象全部忽略。

关键洞察
- 落单对象没有任何直接的视觉标记：它不是最大、最小、颜色最多或位置
  特殊的那个，同形伙伴又靠颜色不同与朝向翻转来伪装，主导色与跨象限
  找同形都是死路；只有在象限内部完成全部同形配对，余下的那一个才会
  显形。
```

## 3. 错位循环色螺旋

- 参考题目: 72207abc, a3df8b1e, a5f85a15
- tags:
  - operation:延伸, extend
  - operation:循环填充, cycle_fill
  - object:折线段, polyline_segment
  - object:色彩循环, color_cycle
  - relation:递增段长, increasing_length
  - relation:同侧转弯, same_side_turn
  - relation:逐格推进循环, per_cell_cycle_advance
  - condition:整段容纳才绘制, whole_segment_fits

### docstring

```text
沿已画螺旋的走向继续绕圈：段长逐段加一，颜色沿路径逐格循环推进，直到下一整段放不下为止。

输入结构
- 黑色背景上有一条一格宽折线，由若干直线段依次相接构成；相邻段互相
  垂直，且每次都向同一侧转弯，下一段从上一段终点沿新方向的相邻格开始。
- 从起点数起，各段的格数依次为 1, 2, 3, ...。
- 沿路径逐格看，颜色按一个短颜色循环反复推进；循环长度与段长互不对齐，
  因此靠后的段会在段中途换色。输入画出的部分足以唯一确定该循环。

规则
- 从已画部分读出转弯侧向、当前段长序号，以及沿路径逐格推进的颜色循环
  和当前循环相位。
- 依次追加新线段：段长继续加一，方向继续向同侧旋转 90 度；新增的每个
  格子沿路径顺序继续按循环取色，相位跨段连续、不因转弯重置。
- 当下一段无法完整落在网格内时整体停止，不画不完整的段；已画部分保持
  不变。

关键洞察
- 颜色不是按段分配而是按格分配：开头的短段恰好各呈单色，诱导出"一段
  一色"的错误假设，只有靠后段的中途换色才暴露真相；延伸时必须同时对齐
  三件事——递增的段长、连续的循环相位、以整段能否放下为准的停止条件，
  任何一处计数错位都会得到错误输出。
```

## 4. 印章痕迹反演

- 参考题目: dc1df850, b1fc8b8e, fd096ab6
- tags:
  - operation:因果反演, causal_inversion
  - operation:印章覆盖, stamp_overlay
  - object:印章痕迹, stamp_trace
  - object:干扰像素, distractor_pixel
  - relation:重叠并集, overlapping_union
  - condition:边界裁剪, boundary_clipped
  - condition:分解唯一, unique_decomposition

### docstring

```text
把蓝色区域反解为若干枚 3x3 印章的并集，在原图上把每枚印章的中心改涂红色。

输入结构
- 黑色背景，散布若干黄色前景像素，另有一片或多片蓝色区域。
- 蓝色区域恰好是若干枚 3x3 实心印章的并集：印章之间可以互相重叠，
  可以被网格边界裁剪，且印章不覆盖黄色像素——黄色处保持黄色，
  在蓝区内形成孔洞。
- 保证能拼出该并集的印章中心组合唯一。

规则
- 求出唯一一组印章中心：每枚印章为以中心为中点的 3x3 邻域，经边界
  裁剪并跳过黄色像素后，全体印章的并集恰好等于全部蓝色像素。
- 输出在输入之上把这些中心格改涂红色；其余蓝色、黄色与背景保持不变。

关键洞察
- 这是印章过程的因果反演：蓝区不是待补全或描边的对象，而是重叠印章
  留下的痕迹。被边界裁剪的印章其中心可能贴边甚至位于蓝区凸包之外的
  直觉位置，被黄色打洞的印章必须凭残缺的痕迹辨认，逐格验证并集相等
  才能排除多余或缺失的中心。
```

## 5. 屋顶导流

- 参考题目: db7260a4, 1e0a9b12, 320afe60
- tags:
  - operation:重力下落, gravity_drop
  - operation:填充, fill
  - object:容器, container
  - object:屋顶, roof
  - object:标记像素, marker_pixel
  - relation:开口朝向分流, opening_orientation_routing
  - relation:级联改道, cascade_rerouting
  - condition:近端滑出, slide_to_nearer_end

### docstring

```text
让顶行彩色像素竖直下落，经倒扣屋顶逐次导流、被正放容器承接，画出每个像素的最终归宿。

输入结构
- 黑色背景。顶行有若干颜色互不相同的单像素。
- 网格中部与底部有若干灰色部件：每个部件要么是开口朝上的 U 形容器
  （两壁一底，内腔为空），要么是开口朝下的 ∩ 形屋顶。
- 保证各下落像素的路径互不干扰；像素落在屋顶顶面时，落点到顶面两端的
  距离不相等。

规则
- 每个顶行像素沿所在列竖直下落，按遇到的部件依次处理：
- 落到 ∩ 形屋顶的顶面上时，滑向距离较近的那一端，再移到该端外侧相邻列，
  从该处继续竖直下落；
- 从开口进入 U 形容器内腔时，把整个内腔涂满该像素的颜色，下落结束；
- 落到容器壁顶、屋顶侧壁顶或一路无阻到达底行时，像素停在最后可行格。
- 输出清除顶行原像素，画出各像素停住的格或涂满的内腔，灰色部件不变。

关键洞察
- 最终归宿不能按起始列竖直投影求得：屋顶把像素横向改道，且可能连续
  经过多个屋顶层层转向后才被容器接住；部件的开口朝向决定它是导流的
  屋顶还是承接的容器，同一像素的落点由整条级联路径决定。
```

## 6. 面积射线折转

- 参考题目: c61be7dc, d364b489, d9f24cd1
- tags:
  - operation:压缩, compress
  - operation:射线延伸, ray_extend
  - object:卫星像素, satellite_pixel
  - object:前景对象, foreground_object
  - relation:像素数决定长度, pixel_count_length
  - relation:方位决定方向, direction_from_satellite
  - condition:遇边折转, fold_at_border

### docstring

```text
把每个对象压缩成一条从其红色喷嘴出发的等面积射线，越出边界的剩余长度沿边折转画完。

输入结构
- 黑色背景上有若干互不相触的单色对象，每个对象恰有一个红色卫星像素
  与该对象的某格正交相邻、位于对象之外。
- 卫星相对其所邻对象格的方位（上、下、左、右）即该对象的发射方向。
- 保证各射线（含折转后的部分）互不重叠。

规则
- 先清除所有对象与卫星像素，得到空背景画布。
- 对每个对象，从其卫星原位置的格子开始，沿发射方向画一条对象颜色的
  射线，总格数等于该对象的像素数，卫星格计为第一格。
- 若画到边界格时仍有剩余格数，则将方向顺时针旋转 90 度沿边继续画，
  必要时在角落再次折转，直到画满总格数为止。

关键洞察
- 射线长度由对象面积守恒而来，方向由卫星方位编码；触边不是截断而是
  顺时针折转，长射线末端的确切位置必须逐格计数并叠加折转才能确定，
  仅看方向或仅看长度都无法定位。
```
