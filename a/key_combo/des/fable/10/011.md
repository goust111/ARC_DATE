## 1. 缺角矩形的层序复原

- 参考题目: `4290ef0e`, `b6afb2da`, `8a6d367c`
- tags:
  - operation:补全, complete
  - operation:填充, fill
  - object:角点生成元, corner_generator
  - object:实心矩形, solid_rectangle
  - relation:包含, containment
  - relation:覆盖层序, occlusion_order
  - condition:缺角定层序, missing_corner_orders_layers

### docstring

```text
由散落的同色角点重建从未画出的重叠矩形，并按“缺角者居下”的侵入关系恢复覆盖层序。

输入结构
- 黑色背景上散布若干组彩色像素，每组同色，是一个轴对齐实心矩形
 （长宽均不小于 3）的角点。
- 每组给出全部四个角，或恰好缺失一个角；缺失的角的位置必然落在
  另一组所定义矩形的内部。
- 相互重叠的矩形之间的上下关系，均可由“谁的缺角落在谁的体内”
  经传递闭包唯一确定。

规则
- 由每组角点重建其轴对齐矩形；三个角可唯一确定第四个角。
- 若 A 组缺失的角位于 B 组矩形区域内，则判定 B 覆盖 A。
- 在输出中按层序自底向上绘制所有实心矩形，后画者覆盖先画者；
  与他者不重叠的矩形绘制次序不影响结果。

关键洞察
- 矩形从未被画出，画面上只有角点生成元；缺失的角不是缺陷而是
  残迹——它被上层矩形“吃掉”，恰好编码了整叠矩形的覆盖顺序。
```

## 2. 负片供体

- 参考题目: `4290ef0e`, `e3721c99`, `184a9768`
- tags:

  - operation:重涂色, recolor
  - operation:擦除, erase
  - object:半身精灵, half_sprite
  - object:脊柱轴线, spine_axis
  - object:负片洞, negative_space_hole
  - relation:镜像全等配对, mirror_congruence_pairing
  - condition:负空间藏形, shape_hidden_as_hole
  - condition:平移全等陷阱, translation_congruence_trap

### docstring

```text
把每个灰色半身缺失的一半，从某个色块上挖出的镜像负片洞里认领回来，用该色块的颜色补全整体并清场。

输入结构
- 背景为最常见色。
- 若干“受体”：一条竖直深蓝脊柱线，一侧贴着一个灰色半身图案，
  另一侧为空；各半身形状互不相同且均无对称性。
- 其余为若干实心矩形色块，颜色互不相同，每块内部挖有一个背景色的洞。
- 对每个受体，恰有一个色块的洞形与其半身镜像全等；另存在洞形与
  某半身平移全等（未经镜像）的干扰色块，以及洞形与任何半身无关的
  多余色块。

规则
- 对每个受体，找到洞形与其灰色半身镜像全等（而非平移全等）的色块。
- 以脊柱线为轴在空侧补全镜像半身，并把补全后的完整图案
 （原半身加新半身）整体涂成该色块的颜色。
- 擦除全部脊柱线与全部色块（含干扰与多余者）。

关键洞察
- 缺失的一半从未被正面画出，它以负空间的形式藏在色块的洞里；
  洞与半身之间恰差一次翻转，平移全等的洞是陷阱，只有镜像洞才交出
  颜色；灰色半身与脊柱线只是脚手架，输出里只留下穿上新颜色的完整
  对称体。
```

## 3. 带假指针的色标链

- 参考题目: `668eec9a`, `891232d6`, `505fff84`
- tags:
  - operation:排序, sorting
  - operation:压缩, compress
  - object:线段对象, line_object
  - object:端点色标, endpoint_color_tag
  - object:色条行, color_stripe_row
  - relation:颜色指针链, color_pointer_chain
  - condition:有出边无入边者为链头, out_edge_no_in_edge_head
  - condition:回边假指针, back_edge_fake_pointer
  - condition:忽略干扰项, ignore_distractors

### docstring

```text
从双重特征锁定链头，沿端点色标遍历线段链，绕过指向已访问线段的假指针，把链序压缩为色条输出。

输入结构
- 背景占主导，网格中散布若干条颜色互不相同的一格宽线段。
- 链上每条线段（除链尾外）至少一端贴有一个单独的异色像素色标，
  色标颜色等于某条线段的主体色；部分线段两端各有一个色标，其中
  恰有一个指向链中更早出现过的线段（假指针）。
- 另有孤立干扰线段：既不带任何色标，主体色也不被任何色标引用。
- 链头带色标但不被引用；链尾被引用但不带色标。

规则
- 链头是“带色标且不被任何色标引用”的唯一线段（孤立线段虽不被
  引用但无色标，据此排除）。
- 从链头出发，每步在当前线段的色标中选择指向尚未访问线段的那一个
  前进，直至到达链尾，得到链上全部线段的唯一排列。
- 输出为 N 行 3 列网格（N 为链上线段数，不含孤立干扰），第 k 行
  整行涂成链中第 k 条线段的主体色。

关键洞察
- 线段的位置、长度与方向全部无关；链头必须由“有出边、无入边”
  两个特征联合锁定，遍历途中还要识破指回旧线段的假指针，孤立线段
  永远进不了输出。
```

## 4. 消失的推者

- 参考题目: `9f669b64`, `8b9c3697`, `6f8cd79b`
- tags:
  - operation:平移, translate
  - operation:补全, complete
  - operation:反演复原, inverse_restore
  - object:分裂栅条, split_bar
  - object:漆痕, paint_residue
  - object:画布边界, canvas_boundary
  - relation:残迹反推, residue_backtracking
  - condition:断口共线定走廊, aligned_gaps_define_corridor

### docstring

```text
从栅条上一致的分裂残迹反推已滑出画面的方块，复原推挤发生之前的场景。

输入结构
- 背景占主导，若干条颜色互不相同、原本上下贯通的竖直栅条横向排开。
- 每条栅条在同一段行区间处断开，上半整体上移一格、下半整体下移一格，
  是被同一滑块穿越后留下的分裂痕迹。
- 走廊一端的网格边缘列上有一段滑块颜色的竖直漆痕，其长度等于滑块的
  边长；画面中不存在滑块本身。

规则
- 由各栅条共享的断口行区间确定滑块的穿行走廊，由漆痕确定滑块的颜色、
  边长与出发端。
- 将每条栅条的两半向内移回一格，并补齐走廊行中的栅条格，使所有栅条
  恢复为上下贯通的完整竖条。
- 在出发端紧贴网格边缘、于走廊内居中画出该颜色的实心正方形滑块，
  并覆盖原漆痕。

关键洞察
- 画面是事件发生之后的残局：断口的错位方向说明这是“穿越分裂”而非
  缺损，漆痕是滑块出发时留下的唯一身份凭证，二者合起来才能唯一还原
  事发前的画面。
```

## 5. 槽位射线的连锁捕获

- 参考题目: `8b9c3697`, `8e301a54`, `e3721c99`
- tags:
  - operation:对接, dock
  - operation:滑动, slide
  - operation:射线延伸, ray_cast
  - object:内部槽位, interior_socket
  - object:可移动组件, movable_component
  - object:结构体, structure
  - relation:距离优先成交, nearest_pair_first
  - condition:轨迹涂黑, trail_painted_black
  - condition:动态连锁分配, dynamic_chain_assignment

### docstring

```text
按“距离最近的槽位—红件对先成交”的迭代次序，把走廊中的红件依次吸入各结构体的槽位并留下黑色轨迹。

输入结构
- 背景为最常见色，若干大型非红结构体各带一个内部槽位，槽位开口
  朝向同一条直线走廊。
- 全部红色可移动组件也位于这条走廊上，走廊两端的槽位可以相向而对；
  红件数不少于槽位数。
- 任意时刻，各“槽位到其射线上最近红件”的距离互不相等，成交次序
  无歧义。

规则
- 反复执行：每个未成交槽位沿开口方向的射线找到最近的剩余红件，
  选出全局距离最小的一对，把该红件平移入槽位，并把它滑过的走廊格
  涂黑。
- 已入槽的红件不再阻挡射线；全部槽位成交后，剩余红件擦除，结构体
  保持不变。

关键洞察
- 分配不是静态的“各取所见第一个”：每次成交都会腾空走廊、改变剩余
  槽位看到的最近红件，最终归属由距离驱动的连锁次序决定，仅凭第一眼
  的静态配对会得出错误答案。
```

## 6. 双轴括号与调色板定序

- 参考题目: `505fff84`, `bae5c565`, `668eec9a`
- tags:
  - operation:裁剪, crop
  - operation:拼接, concatenate
  - object:控制像素对, control_pixel_pair
  - object:调色板行, palette_row
  - relation:括号界定提取范围, bracket_delimited_extraction
  - relation:行列交叉定位, row_col_cross_locating
  - condition:调色板定序, palette_order
  - condition:忽略干扰项, ignore_distractors

### docstring

```text
用同色的行界标与列界标交叉圈定子窗口，再按顶行调色板的颜色次序把窗口内容水平拼接。

输入结构
- 顶行是一条调色板行，从左到右列出若干颜色；其下方为主画布。
- 对调色板中的每种颜色，主画布左边缘列上恰有该色两个像素，夹出
  一个行区间；底边缘行上恰有该色两个像素，夹出一个列区间。
- 各颜色的行区间高度全部相同；边缘上还可能出现不在调色板中的
  颜色界标（干扰）。

规则
- 对调色板中的每种颜色，取其行区间与列区间的交叉区域作为该色窗口，
  拷贝窗口内部内容（不含界标本身）。
- 按调色板行中颜色从左到右的次序，把各窗口水平拼接为输出。
- 边缘颜色不在调色板中的窗口整组舍弃。

关键洞察
- 提取范围没有画在任何一处：行界标与列界标分别躺在两条边上，必须
  按颜色跨边配对才能交叉定位出窗口；输出的次序也不取窗口的空间位置，
  而听从调色板行。
```

## 7. 滤色的边界影子

- 参考题目: `6f8cd79b`, `891232d6`, `8e301a54`
- tags:
  - operation:描边, border_draw
  - operation:擦除, erase
  - object:画布边界, canvas_boundary
  - object:单色对象, monochrome_object
  - relation:投射, projection
  - relation:遮挡改色, occluder_recolors_shadow
  - condition:最近边归属, nearest_edge_assignment

### docstring

```text
每个对象向其最近的画布边投下影子，被中间物遮挡的影段改涂遮挡者的颜色，输出只保留边框。

输入结构
- 背景网格内散布若干互不同色的单色实心矩形，均不接触画布边缘。
- 每个对象到四条边的最小距离唯一，不存在并列；所有影段不触及
  边框四角。
- 某些对象与其最近边之间部分或全部隔着另一个对象。

规则
- 输出与输入同尺寸：内部全部清为背景，四条边画一圈默认灰色边框。
- 每个对象向其最近边投影，影段范围等于对象在该边方向上的跨度。
- 影段中被其他对象隔挡的列（或行）涂遮挡者的颜色，未被隔挡的部分
  涂对象自身颜色；多层隔挡时取最靠近该边的遮挡者。
- 对象只在自己的最近边方向产生影子；即使它在某行或某列上是从别的
  边看进来的第一个物体，只要那条边不是它的最近边，它就不自行投影，
  但仍会为别人的影子改色。

关键洞察
- 边框不是“四面环视看见谁涂谁”：影子的存在由最近边归属决定，
  影子的颜色再被路径上的遮挡者逐段改写，两层规则缺一不可。
```

## 8. 双缝光锥

- 参考题目: `bae5c565`, `891232d6`, `e3721c99`
- tags:
  - operation:传播, propagate
  - operation:填充, fill
  - object:挡光条, wall_row
  - object:障碍像素, obstacle_pixel
  - object:颜色图例, color_legend
  - relation:锥形扩散, cone_spread
  - condition:障碍切断光路, obstacle_blocks_light
  - condition:重叠区图例换色, overlap_legend_color

### docstring

```text
两束光从顶部挡光条的缺口以锥形逐行下扩，障碍切断传播，双光交叠区依图例涂成混合色。

输入结构
- 顶行是一条实心挡光条，恰有两个缺口，缺口处分别是两种不同颜色的
  光源像素。
- 网格内部散布若干深色障碍块；某个角落放着一条一乘三的图例：两端
  为两种光色，中间为交叠区应使用的颜色。

规则
- 每种光从其缺口向下传播：若某行某格被该光照亮，则下一行中其正下方
  与左右斜下方三格中非障碍的格也被照亮。
- 仅被一种光照亮的背景格涂该光色；被两种光同时照亮的背景格涂图例
  中间色；障碍、图例与未被照亮的格保持原样。

关键洞察
- 照亮范围不是泛洪填充：光只能逐行斜向扩张，障碍在其正下切断光路
  而形成扩散的阴影；两束锥光的交叠只能靠分别追踪两束光才能得到，
  图例中间色标注的正是这块交叠区。
```
