## 1. 朝向印章

- 参考题目题号: 1, 6, 11
- tags:
  - operation:印章覆盖, stamp
  - operation:旋转, rotate
  - operation:重涂色, recolor
  - object:模板面板, template_panel
  - object:前景像素, foreground_pixel
  - relation:分块对应, block_correspondence
  - relation:最近边归属, nearest_side_assignment
  - condition:最近边定朝向, nearest_side_sets_orientation

### docstring

```text
一句话总述：把源面板中每个彩色像素展开为模板的一份重涂副本，副本的旋转朝向由该像素在源面板内唯一最近的边决定。

输入结构：
- 输入由两个等大的 N×N 面板并排或上下拼接，共享同一种背景色。
- 一个面板是掩码模板：用单一标记色画出的不对称图形，其四种旋转形态互不相同。
- 另一个面板是源面板：稀疏分布若干彩色像素；保证每个彩色像素到源面板四条边的最近距离唯一（不存在并列最近边）。
- 各示例中同时出现最近边不同的多个源像素，因而输出中的副本朝向互不相同。

规则：
- 构造 N²×N² 输出，初始化为背景色。
- 对源面板中位于 (r, c)、颜色为 k 的每个像素：先判断它在源面板内唯一最近的边（上/下/左/右）。
- 将模板旋转，使模板的"上方"指向该最近边：最近边为上则不旋转，为右则顺时针转 90 度，为下则转 180 度，为左则逆时针转 90 度。
- 将旋转后的模板整体重涂为颜色 k，盖印到输出的第 (r, c) 个 N×N 分块中；无源像素的分块保持背景。

关键洞察：
- 源像素同时提供三条信息：分块位置、副本颜色、以及通过"离哪条边最近"隐式编码的副本朝向；朝向没有画在图上，而是由位置几何读出的。
```

## 2. 环上补缺

- 参考题目题号: 2, 8, 16
- tags:
  - operation:平移, translate
  - operation:擦除, erase
  - operation:修补, repair
  - object:空心矩形, rectangular_frame
  - object:标记条, marker_bar
  - object:缺口, gap
  - relation:循环迁移, cyclic_migration
  - relation:顺序占位, queued_occupancy
  - condition:头尾定向, head_tail_direction

### docstring

```text
一句话总述：环形边框上的双格标记沿框同向滑行，依次冲进前方第一个空缺口，把缺口补成自己的颜色。

输入结构：
- 背景网格上有一个一格厚的空心矩形边框，框色单一。
- 框环上存在若干一格宽的缺口（环上被断开为背景色的单格）。
- 框环上另有若干标记：每个标记占据环上相邻两格，头格为该标记的彩色，尾格为统一的辅助色；所有标记的头尾朝向沿环是同一个旋转方向。
- 缺口数与标记数相等；每个示例中都存在两个以上标记的前方第一缺口相同的情形（必然发生排队顺延）。

规则：
- 每个标记沿其头部所指的环向滑行，冲向前方第一个缺口。
- 若该缺口已被沿环更近的标记占据，则该标记越过它继续滑向下一个缺口；恰好一一占满全部缺口。
- 占据后：缺口处填上该标记的彩色（一格），标记原来的两格恢复为框色，辅助色尾格随之消失。
- 输出为完整闭合的边框：原缺口位置显示各标记的颜色，其余环格均为框色；框内外其他像素不变。

关键洞察：
- 缺口与标记的配对不是"就近配对"，而是"同向排队"：多个标记指向同一缺口时，只有沿环最先到达者占位，其余被迫顺延到更远的缺口；配对关系由环向先后次序涌现，方向要从头尾双格的姿态读出。
```

## 3. 层叠还原

- 参考题目题号: 12, 13, 14
- tags:
  - operation:补线, line_completion
  - operation:射线延伸, ray_cast
  - operation:排序, sort
  - object:边界点, boundary_dot
  - object:交点样本, crossing_sample
  - object:隐藏直线, hidden_line
  - relation:遮挡传递, occlusion_transitivity
  - condition:样本定全序, samples_fix_total_order
  - condition:参与对象未被画出, object_never_drawn

### docstring

```text
一句话总述：由边界端点还原贯穿整行整列的隐藏彩线，并依据少量已画出的交点推断全部彩线的层叠顺序，补全所有交点的遮挡关系。

输入结构：
- 背景网格的边界上成对出现同色端点：一对同色端点标出一条贯穿整行或整列的隐藏直线，线身本身未画出。
- 网格内部有少量单像素点，每个都恰好落在某一条行线与某一条列线的交叉位置上，其颜色等于两条线中压在上面那条线的颜色。
- 保证：由这些已知交点出发，通过传递比较可以唯一确定所有线之间的整体层叠顺序；且存在未被样本直接给出、必须靠该顺序推断的交点。

规则：
- 将每条隐藏线补画为完整的一行或一列，使用其端点颜色。
- 任意行线与列线的交点处，只显示层叠顺序更高（更靠上层）的那条线的颜色。
- 层叠顺序取与所有已给交点颜色一致的唯一全序；未直接给出的交点由该全序推得。

关键洞察：
- 参与规则的直线从未被完整画出，画面上只有它们的端点与少量交点残迹；已画出的交点不是噪声，而是"谁压住谁"的证据。单个证据只给出一对线的上下关系，全部交点的答案要靠这些局部证据经传递性拼出的全局层叠顺序才能确定。
```

## 4. 司机与车身

- 参考题目题号: 8, 15, 16
- tags:
  - operation:平移, translate
  - object:边框边, frame_side
  - object:主体对象, main_object
  - object:标记像素, marker_pixel
  - relation:嵌入标记定向, embedded_marker_steers
  - relation:颜色匹配边, color_match_side
  - condition:碰撞停止, collision_stop
  - condition:忽略干扰项, ignore_distractors

### docstring

```text
一句话总述：每个对象由其体内嵌着的单个司机像素驾驶，整体滑向颜色与司机相同的边框边，直到撞框或撞上先落位的对象。

输入结构：
- 网格有一格厚的矩形边框：四角为背景色，四条边各为一种互不相同的实心颜色。
- 框内背景上散布若干多格单色对象；每个对象内部恰嵌有一个颜色不同的像素（司机）。
- 部分对象的主体颜色恰好等于某条边框边的颜色，但司机颜色才决定去向；也存在司机颜色不匹配任何边的对象。
- 每个示例中都存在滑行路径被先落位对象挡住、从而叠靠在其上的情形。
- 保证：各对象按"距目标边行进距离小者先落位"的顺序滑行时，路径与终点唯一，无并列冲突。

规则：
- 司机颜色与某条边相同的对象，整体（连同司机）沿垂直于该边的方向滑行，直到贴上该边或贴上已经落位的对象为止。
- 多个对象的落位顺序为：距各自目标边行进距离小者先行。
- 司机颜色不匹配任何边的对象保持原位；边框与背景不变。

关键洞察：
- 决定运动方向的不是对象自身的颜色（那是诱饵），而是嵌在体内的司机像素；对象之间还会互相垫住，先落位者成为后来者的新地面，终局布局由距离次序逐个累积而成。
```

## 5. 蛇道节拍

- 参考题目题号: 12, 15, 2
- tags:
  - operation:周期填充, periodic_fill
  - operation:重涂色, recolor
  - object:管道路径, pipe_path
  - object:节拍种子, beat_seed
  - object:检查点, checkpoint_dot
  - relation:一维展开, path_unrolling
  - relation:颜色继承, color_inheritance
  - condition:同余对齐, modular_alignment

### docstring

```text
一句话总述：沿灰色蛇形管道从种子端出发按固定节拍点涂颜色，途经检查点后节拍色被检查点颜色接管。

输入结构：
- 背景网格上有一条一格宽、四连通、无分叉的灰色管道，有两个端点。
- 靠近其中一个端点，管道上已有两格被同一种颜色点亮：它们是节拍序列的前两拍，二者沿管道的间隔即节拍周期。
- 管道沿途另有若干单格检查点：管道格被替换成其他颜色，位置不必落在节拍上。

规则：
- 从点亮格所靠近的端点出发，沿管道逐格前进，把第二颗种子之后每隔一个周期的管道格涂上当前颜色，直至管道另一端。
- 当前颜色初始为种子颜色；每当行进越过一个检查点，当前颜色立即改为该检查点的颜色，此后的节拍格都用新颜色。
- 检查点自身保持原色，未落在节拍上的管道格保持灰色，管道之外的像素不变。

关键洞察：
- 这不是二维图形规律：必须把蛇形管道展开成一条一维序列，周期由前两拍的沿管道距离读出（沿途拐弯不改变节拍），检查点则扮演接力染色的换色闸门。
```

## 6. 链序装填

- 参考题目题号: 18, 19, 17
- tags:
  - operation:排序, sort
  - operation:计数, counting
  - operation:填充, fill
  - operation:裁剪, crop
  - object:条纹, stripe
  - object:端帽像素, cap_pixel
  - object:正方形区域, square_region
  - relation:指针链定序, pointer_chain_order
  - relation:长度守恒, length_conservation
  - condition:忽略干扰项, ignore_distractors

### docstring

```text
一句话总述：按端帽颜色串成的隐藏链条决定装填次序，把各条纹按自身本体长度的格数依次连续装填进灰色正方形。

输入结构：
- 网格上有一个 k×k 的灰色正方形和若干条一格宽、互不同色的条纹，条纹方向一致（全横或全竖），不同条纹的本体长度可以相同。
- 每条条纹的一端额外附着一个端帽像素（颜色不同于本体）：端帽颜色等于链条中下一条条纹的本体颜色；恰有一条条纹没有端帽，它是链条的末尾；链条的开头是本体颜色未被任何端帽引用的那条条纹。
- 所有条纹本体长度之和恰等于 k²；条纹的空间位置、长度大小均与链条次序无关。

规则：
- 以灰色正方形为输出画布，输出仅为该正方形大小。
- 条纹全横时按行优先（自左而右、自上而下）、全竖时按列优先（自上而下、自左而右）连续填格。
- 从链头条纹开始，沿端帽指针逐条处理：每条颜色连续填入与其本体长度相等的格数（不含端帽），颜色块允许跨行（或跨列）折行，直至填满整个正方形。

关键洞察：
- 装填次序既不是空间顺序也不是长度顺序（二者都是诱饵，且长度可能并列而根本排不出全序）：每条条纹用端帽颜色指名"下一棒"，必须先在图中解出这条隐藏的接力链，再做面积守恒的折行连续装填，颜色边界一般不落在行尾。
```
