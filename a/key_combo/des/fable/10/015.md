## 1. 被拔走的光源

- 参考题目:17(6ffe8f07)、5(56ff96f3)、19(aa18de87)、8(f15e1fac)
- tags:
  - operation:射线反演, ray_inversion
  - operation:填充, fill
  - object:射线残迹, ray_residue
  - object:障碍墙, blocker_wall
  - relation:条带定源, band_locates_source
  - condition:空腔即光源, cavity_is_source

### docstring

```text
黄色射线臂是被移除光源留下的残迹,反推每个光源矩形并在其空腔处补画绿色。

输入结构
- 黑色背景;蓝色像素段为固定的墙。
- 黄色像素构成若干水平与垂直条带(射线臂):它们由一个或多个未画出的实心矩形按行向左右、按列向上下发射而成,射线在蓝墙或网格边界前停止。
- 光源矩形自身所占区域为黑色(源已被移除);不同源的臂可以交叉,交叉处仍为黄色;任何臂都不穿过其他源的空腔。

规则
- 水平臂的行区间给出源矩形的高,垂直臂的列区间给出源矩形的宽。
- 真正的源位于臂端相汇的黑色空腔处;臂与臂的交叉处是黄色的,不是源。
- 某一侧的臂可能被紧贴源的墙完全挡住而缺失,此时该侧的源边界由其余臂的带宽推定。
- 在每个源空腔处填绿;黄臂、蓝墙与背景保持不变。

关键洞察
- 参与规则的主角从未被画出:光源只能从它的射线残迹反推。
- 辨别真假中心的依据是"源被移除后是黑洞,而臂的交叉仍是黄色";被墙封死的缺臂方向要靠垂直方向臂的带宽补出边界。
```

## 2. 厚度配对

- 参考题目:1(d753a70b)、10(eb5a1d5d)、3(6ea4a07e)
- tags:
  - operation:剥层, peel
  - operation:重涂色, recolor
  - object:实心色块, solid_blob
  - relation:腐蚀深度配对, erosion_depth_pairing
  - condition:同深度同色, equal_depth_same_color

### docstring

```text
把每个灰色形状染成与它剥层深度相同的那个彩色形状的颜色。

输入结构
- 黑色背景上散布若干实心形状:一部分各具彩色,另一部分全为灰色,两组数量相等。
- 两组形状在面积、外接框大小、轮廓上均无对应关系,这些可见属性全是诱饵。

规则
- 对每个形状反复剥去与背景四邻接的最外层,直到形状消失,剥的次数记为该形状的深度。
- 每例中彩色组内深度互不相同,灰色组内深度互不相同,且两组深度集合一致。
- 将每个灰色形状整体重涂为深度相同的那个彩色形状的颜色;彩色形状保持不变。

关键洞察
- 配对的钥匙不是大小、面积或轮廓的相似,而是一个画面上看不见的量——最厚处可剥的层数;瘦长的大形状深度可以比小方块还浅。
```

## 3. 换色轮的平铺修复

- 参考题目:16(2dee498d)、7(8eb1be9a)、3(6ea4a07e)、14(af22c60d)
- tags:
  - operation:平铺, tile
  - operation:对称补全, symmetry_completion
  - operation:重涂色, recolor
  - object:瓦片, tile
  - object:缺失矩形, missing_rectangle
  - relation:周期含翻转, period_with_flip
  - relation:颜色循环, color_cycle
  - condition:相位决定翻转与配色, phase_determines_flip_and_palette

### docstring

```text
网格由一个种子块沿水平方向铺成,相邻副本交替左右翻转且前景色沿固定三色轮循环,补全被黑洞遮住的部分。

输入结构
- 网格宽为种子块宽的整数倍,由种子块的一系列副本水平拼接而成。
- 第 k 个副本等于:种子在 k 为奇数时先做左右镜像,再把三种前景色按 蓝→红→绿→蓝 的色轮循环 k 步换色;背景色不参与循环。
- 一个矩形区域被涂黑遮挡,遮挡可跨越副本边界。

规则
- 从可见部分确定种子宽度、翻转相位与色轮相位。
- 对洞内每个像素,取某个可见副本中的对应像素:先按两副本的翻转差异对齐列位置,再按色轮相位差换色,然后填回。
- 输出为完整修复后的网格。

关键洞察
- 平铺的不变量不是"逐块相同",而是"块与块相差一个固定的几何翻转加一个固定的颜色轮转";直接照抄最近的可见块会得到错误的方向或颜色。
```

## 4. 双轴由计数而定

- 参考题目:15(d631b094)、6(a8610ef7)、14(af22c60d)、9(878187ab)
- tags:
  - operation:计数, count
  - operation:镜像, mirror
  - operation:重涂色, recolor
  - object:前景像素, foreground_pixel
  - object:计数标记, count_marker
  - relation:计数映射坐标, count_maps_to_coordinate
  - relation:双轴镜像轨道, two_axis_orbit
  - condition:轨道占据数定色, orbit_occupancy_colors

### docstring

```text
两撮标记像素的数量分别指定一条隐形的竖直轴与水平轴,再按每个前景像素镜像轨道中的同伴数目重涂色。

输入结构
- 黑色背景;橙色像素构成主图案。
- 网格边缘另有一撮青色像素与一撮灰色像素,与主图案明显分离。
- 青色像素的个数 c 指定竖直轴位于第 c 列,灰色像素的个数 r 指定水平轴位于第 r 行(从 1 数起);两条轴不画出,也不与图案的几何中线重合。

规则
- 对每个橙色像素,取它关于竖直轴、水平轴以及两轴复合的三个镜像位置,出界的镜像位置不计。
- 统计这些镜像位置中同为橙色的个数 m:m=3 涂红,m 为 1 或 2 涂黄,m=0 涂蓝。
- 青色与灰色标记保持原样。

关键洞察
- 两条对称轴从未画出,也不在图案的中线上:它们藏在两撮标记的"数量"里——计数在这里给出的不是输出尺寸,而是坐标。
```

## 5. 缺了一块的镶嵌

- 参考题目:12(5dbc8537)、2(4e45f183)、16(2dee498d)、20(67e8384a)
- tags:
  - operation:嵌入填充, inlay_fill
  - operation:旋转翻转, rotate_flip
  - operation:对称补全, symmetry_completion
  - object:模板框架, template_frame
  - object:花纹碎块, patterned_piece
  - object:空腔, cavity
  - relation:形状模D4匹配, shape_matching_mod_d4
  - condition:全局对称裁定姿态与缺件, global_symmetry_resolves_pose_and_missing

### docstring

```text
把外部花纹碎块旋转或翻转后嵌入形状匹配的空腔;当空腔形状对称导致姿态歧义、以及最后一个无碎块可用的空腔,都只能靠"成品必须整体左右镜像对称"这一约束裁定。

输入结构
- 灰色大模板占据一块矩形区域,内部挖有若干多联骨牌形状的黑色空腔。
- 模板轮廓与空腔布局关于其竖直中轴左右镜像对称:空腔成镜像对,个别空腔正好骑在轴上。
- 模板之外散布双色花纹碎块,每块的轮廓经某个旋转或翻转后与恰好一个空腔吻合;其中一些空腔的轮廓自身是对称的,仅凭轮廓无法确定碎块姿态。
- 碎块比空腔少一块。

规则
- 先按"形状模旋转翻转"给每个碎块找到唯一归属的空腔。
- 轮廓不对称的空腔,碎块姿态被轮廓唯一确定;轮廓对称的空腔,在可行姿态中选使镜像位置两空腔的花纹互为左右镜像的那一个;骑轴空腔的花纹必须自身左右对称,以此定姿态。
- 无碎块对应的空腔,取其镜像伙伴已定的花纹做左右镜像后填入。
- 输出为模板外接框内的成品,外部碎块不再出现。

关键洞察
- 局部信息(轮廓)只能完成一半的工作;姿态歧义与缺件是同一个问题的两面,都由"填完后的整体必须左右镜像对称"这一从未明说、要从训练对中归纳出的全局约束统一裁定。
```

## 6. 撞红即顺时针

- 参考题目:13(d282b262)、8(f15e1fac)、17(6ffe8f07)
- tags:
  - operation:滑动, sliding
  - operation:转向, turning
  - object:刚性精灵, rigid_sprite
  - object:红色转向点, red_turner_pixel
  - relation:碰撞阻挡, collision_block
  - condition:撞红顺时针转向, red_turns_clockwise

### docstring

```text
所有精灵同步向右滑动,每次即将撞上红点就把行进方向顺时针旋转九十度,撞界即停,撞同伴则等待,输出全部静止后的终态。

输入结构
- 黑色背景;若干互不接触的单色实心精灵;若干红色单像素固定不动。
- 布局保证每个精灵最终都会静止。

规则
- 反复进行同步回合:每回合中,每个未终止的精灵沿其当前方向(初始向东)尝试前进一格。
- 若前方任一目标格是红点,该精灵本回合不动,方向顺时针旋转九十度(东→南→西→北→东,可多次转向)。
- 若前进会越出边界,则该精灵永久终止;若目标格被其他精灵占据,则本回合等待,待对方移开后可继续。
- 当一整回合无人移动且无人转向时全部结束;红点保留在原位,输出终态网格。

关键洞察
- 第一个示例里每个精灵至多撞一次红点,看上去像"红点=改为向下"的绝对规则;只有后续示例中出现向西、向北的折返轨迹,才暴露出真规则是"相对于当前方向的顺时针旋转"——红点是转向器而非墙,且先静止的精灵会反过来改写后来者的路径。
```
