## 1. 重力排名生成隐形图例

- 参考题目: `3906de3d`, `58743b76`, `1e32b0e9`
- tags:
  - operation:滑动, sliding
  - operation:重涂色, recolor
  - object:平台, platform
  - object:分隔线, divider_line
  - object:图例, legend
  - relation:碰撞阻挡, collision_blocking
  - relation:高度排名, height_ranking
  - condition:排名决定图例顺序, ranking_determines_legend_order

### docstring

```text
左侧彩色方块按重力落到各自平台上，按最终停留高度从低到高排出颜色序列，用它自上而下重涂右侧的灰色矩形队列。

输入结构
- 网格被一条竖直分隔线分成两半。
- 左半部为黑背景，散布若干灰色水平平台（高度各不相同），每个平台正上方悬浮一个彩色方块（每色恰一个）。
- 右半部自上而下排列着与方块数量相同的灰色实心矩形。
- 方块的初始高低次序、左右次序均与落定后的高度次序不一致。

规则
- 每个彩色方块在自己的列内竖直下落，停在正下方最近的平台顶上。
- 按落定后所在行从低到高（网格底部为低）对颜色排序，得到颜色序列。
- 右半部的灰色矩形按自上而下的次序依次涂成该序列中的颜色。
- 左半部保持落定后的状态输出。

关键洞察
- 重涂右侧所需的图例从未画出——它是左侧重力模拟结束后由停留高度排名涌现的顺序；方块的初始左右次序与初始高低次序都是诱饵。
```

## 2. 走廊钥匙链

- 参考题目: `b9630600`, `d35bdbdc`, `239be575`
- tags:
  - operation:路径追踪, path_tracing
  - operation:擦除, erase
  - object:空心矩形, hollow_rectangle
  - object:走廊, corridor
  - relation:颜色查找键, color_lookup_key
  - relation:走廊相邻, corridor_adjacency
  - condition:双重约束匹配, dual_constraint_match
  - condition:不匹配即终止, halt_on_no_match

### docstring

```text
从被填充的起点房间出发，沿走廊按"中心钥匙色 = 下一间边框色"的指针链依次点亮房间，擦除链外的一切房间与走廊。

输入结构
- 黑背景上有若干空心矩形房间，边框颜色互不相同，每个房间中心有一个单像素"钥匙色"。
- 部分房间之间由宽 1 的灰色走廊直线连接；走廊网络含分叉与不在链上的旁支。
- 恰有一个房间的内部已被完全填充（起点标记）。
- 网格中存在边框色与某钥匙色相同、却与当前房间不相邻的诱饵房间。

规则
- 读当前房间的中心钥匙色。
- 在与当前房间有走廊直接相连的房间中，找到边框色等于该钥匙色的唯一一间，将其内部填充为其边框色并移动过去。
- 重复上述步骤，直到相连房间中无边框色匹配者为止。
- 输出中删除所有未被访问的房间以及不在访问路径上的走廊，保留访问序列的房间与所经走廊。

关键洞察
- 钥匙色构成一条指针链，但链的每一步必须同时满足颜色匹配与走廊相邻两重约束——只按颜色跳跃会被不相邻的诱饵房间带错路，只按走廊走会在分叉处无从选择。
```

## 3. 压缩钥匙修复镶嵌

- 参考题目: `90c28cc7`, `4aab4007`, `269e22fb`
- tags:
  - operation:填充, infill
  - operation:压缩, downscale
  - object:矩形分区, rectangular_partition
  - object:遮挡空洞, occlusion_hole
  - object:色彩钥匙, color_key
  - relation:二面体变换, dihedral_transformation
  - relation:网格采样, grid_sampling
  - condition:唯一朝向匹配, unique_orientation_match

### docstring

```text
用角落那张经过未知旋转/翻转的分区压缩图作钥匙，填补大镶嵌图中的黑色遮挡。

输入结构
- 主区域是一幅彩色矩形分区镶嵌：每个分区为单色矩形，行宽列宽不一，其中若干像素被黑色遮挡。
- 一条分隔线外的附属小区域内有一个小彩色矩阵，它等于该镶嵌"每分区取一色"的压缩图，但被施加了八种二面体变换之一。

规则
- 由可见部分恢复镶嵌的行列分区骨架。
- 在八种朝向中找出使小矩阵与所有可见分区颜色一致的唯一朝向。
- 按该朝向下对应矩阵元素的颜色填充每个被遮挡像素。
- 输出只保留修复后的主镶嵌，不含分隔线与钥匙区域。

关键洞察
- 小矩阵是整幅镶嵌的压缩钥匙，但直接对不上——必须同时确定分区骨架与钥匙的朝向，两者互相印证之后每个洞的颜色才唯一。
```

## 4. 反弹预测下一帧

- 参考题目: `2ccd9fef`, `3906de3d`, `f3e62deb`
- tags:
  - operation:外推, extrapolate
  - operation:反射, reflect
  - object:面板序列, panel_sequence
  - object:墙体, wall
  - relation:周期时序, temporal_schedule
  - condition:预测下一帧, predict_next_frame
  - condition:碰撞反弹, bounce_on_collision

### docstring

```text
由前几个面板中各彩色点的匀速运动推算下一时刻，越墙处按镜面反弹，输出下一帧面板。

输入结构
- 网格由分隔线分成一行 N 个等大的面板，每个面板带相同的边框墙。
- 面板序列显示若干颜色互不相同的单像素点在盒内按各自恒定速度矢量运动的连续时刻。

规则
- 对每个颜色点用相邻两帧求出位移矢量。
- 向前推进一步；若该步会越过墙体，则在墙处按镜面反射反转相应速度分量并走完剩余步长。
- 输出为单个面板，画出所有点的新位置，墙与背景不变。

关键洞察
- 这不是线性外推——靠墙的点在下一帧会反弹，直接延长轨迹会把点画进墙里；每个点的反弹时机不同，必须逐点判断。
```

## 5. 远近定角色并开门

- 参考题目: `1b8318e3`, `b6afb2da`, `b548a754`
- tags:
  - operation:重涂色, recolor
  - operation:擦除, erase
  - object:矩形, rectangle
  - object:孤立像素, singleton_pixel
  - relation:最近距离, nearest_distance
  - relation:局部位置分类, local_position_classification
  - condition:距离排名决定角色, distance_rank_determines_role
  - condition:方位决定缺口, direction_determines_gap

### docstring

```text
把每个孤立彩色像素按最近距离分配给灰色矩形，距离排名决定"边框/内部"两种涂色角色，较远像素的方位还在边框上开出一个缺口。

输入结构
- 黑背景上有若干灰色实心矩形（高宽均不小于 5）和若干彩色孤立像素。
- 按国王距离最近分配，每个矩形恰好得到两个孤立像素，两像素到该矩形的距离不同。
- 较远像素严格位于矩形某一条边的正对方向（其行或列落在矩形范围内）。

规则
- 将每个孤立像素分配给离它最近的矩形。
- 对每个矩形：用较近像素的颜色重涂其边框，用较远像素的颜色重涂其严格内部。
- 在边框上正对较远像素的那一格擦出一个背景色缺口（门）。
- 擦除所有孤立像素。

关键洞察
- 两颗像素同时编码三层信息：最近距离决定归属，距离排名决定颜色角色（近者得边框、远者得内部），较远像素的方位决定门的位置；颜色本身与阅读顺序都是诱饵，任何单看一层的假设都无法同时解释三种输出特征。
```

## 6. 弧长残迹补周期

- 参考题目: `d35bdbdc`, `2ccd9fef`, `aa18de87`
- tags:
  - operation:外推, extrapolate
  - operation:重涂色, recolor
  - object:路径, path
  - object:残迹点, residue_pixel
  - relation:一维序列化, one_dimensional_serialization
  - relation:周期调度, periodic_schedule
  - condition:最短循环节, minimal_period
  - condition:稀疏采样定相位, sparse_samples_determine_phase

### docstring

```text
一笔画灰色曲线上零散嵌着几颗彩色残迹点，它们在弧长坐标下呈现严格的循环颜色序列，按该周期把整条曲线逐格补全上色。

输入结构
- 黑背景上一条宽 1、8 连通、无分叉的一笔画灰色曲线。
- 曲线上散布若干彩色像素，在平面上看毫无规律。
- 曲线按弧长逐格编号后，全部颜色构成某个最短循环节的无限重复，已上色像素是其中的部分采样，且采样足以唯一确定循环节与相位。

规则
- 从任一端点出发把曲线像素串成一维序列。
- 找出与全部已上色像素一致的最短循环颜色节及其相位。
- 按该周期为所有灰色像素逐格上色，得到整条曲线的完整周期着色。

关键洞察
- 彩点在二维平面上是杂乱残迹，任何按行、按列、按对角或按距离找规律的尝试都会失败；规律只存在于曲线自身的一维弧长坐标中，必须先序列化再从稀疏采样反推出周期与相位。
```

## 7. 供电指令

  - object:电源块, power_block

  - condition:连通才执行, execute_only_if_connected
  - condition:行覆盖列, row_overrides_column

### docstring

```text
只有经导线与电源连通的多米诺才执行"横排竖列"的涂色指令，未通电的多米诺被整体擦除。

输入结构
- 背景为主色；一个灰色电源方块；若干青色曲折导线。
- 若干彩色的双像素多米诺（水平或竖直）。
- 部分多米诺经青色导线与电源 4 连通，部分不连通；两类多米诺在形状与朝向上不可区分。

规则
- 与电源连通的竖直多米诺把它所在整列涂成自身颜色。
- 与电源连通的水平多米诺把它所在整行涂成自身颜色；行条后画，覆盖列条。

- 导线与电源在未被条覆盖处保留。

关键洞察
- 多米诺的朝向是指令，但指令是否执行由供电连通性这条隐蔽前提决定——通电与未通电的多米诺外观完全一样，只看形状与朝向会把诱饵也画出来。
```

## 8. 拉伸并延拓对角场

- 参考题目: `b548a754`, `4aab4007`, `f3e62deb`
- tags:
  - operation:拉伸, stretch
  - operation:外推, extrapolate
  - object:标记点, marker_pixel
  - object:矩形, rectangle
  - relation:反对角线等值, anti_diagonal_equivalence
  - relation:行列对齐, row_column_alignment
  - condition:标记决定拉伸终点, marker_determines_stretch_endpoint
  - condition:新增区按周期延拓, new_area_extended_by_period

### docstring

```text
把带对角条纹内部的矩形沿标记方向拉伸到标记处，新增面积按原对角周期场延拓上色。

输入结构
- 背景为主色。
- 一个带单色边框的矩形，其内部由沿对角线方向周期重复的彩色条纹填充。
- 一个孤立标记像素位于矩形的正上、正下、正左或正右方向，且其行/列落在矩形范围内。

规则
- 将矩形朝标记方向拉伸，使新的外边框到达标记所在行或列，标记被新边框吞并。
- 新增的内部区域不是纯色填充，而是按原内部条纹的对角等值规律延拓每一格的颜色。
- 其余区域保持背景。

关键洞察
- 标记只决定几何终点；新增面积的颜色既不是复制相邻行也不是内部纯色，而是对角周期场的延拓——几何拉伸与图案外推两个机制必须同时识别，缺一个就画错半幅图。
```
