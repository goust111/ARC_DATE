## 1. 缠框层序决定面板叠放

- tags:
  - operation:透明叠加, transparent_overlay
  - operation:排序, sort
  - object:矩形边框, rect_frame
  - object:颜色面板, color_panel
  - relation:交叉处可见性, crossing_visibility
  - relation:层级优先, layer_priority
  - condition:遮挡链定优先序, occlusion_chain_sets_priority

### docstring

```text
一句话总述
- 从交叠矩形框群读出层叠次序，并按该次序把等尺寸颜色面板透明叠加成一张输出图。

输入结构
- 背景为最常见色。网格一侧是若干个一像素厚、互相部分交叠的单色矩形框；
  每处交叠点只显示其中一框的颜色，全部交叠关系连成一条覆盖所有框色的链。
- 网格另一侧并排放着数个同尺寸矩形面板，面板之间以背景隔开；每个面板由
  背景和单一前景色构成，前景色与框色一一对应。
- 面板的排列顺序与框的层叠顺序无关（诱饵：按左右排列叠加在第一个示例
  之外均不成立）。

规则
- 由每个颜色可见像素的包围框恢复各矩形框的完整周界；在两框周界相交处，
  可见颜色属于上层框，据此建立"下压→上盖"的有向关系，串成唯一的自底
  向顶全序。
- 将各面板视为透明图层，颜色对应的框越靠顶层，其面板优先级越高。
- 输出与单个面板同尺寸：每个像素取所有面板中优先级最高的非背景色；
  若全部为背景则输出背景。

关键洞察
- 面板在画面上的左右排列只是摆放，真正的叠放次序写在另一处框群的遮挡
  关系里；这是一道"钥匙在别处"的叠加题。
```

## 2. 反向像素放大找瑕疵

- tags:
  - operation:降采样, downscale
  - operation:计数, counting
  - object:多色瓦片, polychrome_tile
  - object:瑕疵像素, defect_pixel
  - relation:众数原型, majority_prototype
  - condition:瓦片副本对照原型, copy_vs_prototype
  - condition:无分隔自寻块尺寸, tiling_size_unmarked

### docstring

```text
一句话总述
- 把大网格识别为某个隐藏掩码的瓦片放大结果，并把每个有瑕疵的瓦片副本
  折算成小网格上的一个错色像素。

输入结构
- 大网格可被均分为若干同尺寸子块，无任何分隔线提示子块的边界与尺寸。
- 每个子块要么整块为背景，要么是同一多色原型瓦片的平移副本，副本数量
  远多于两个。
- 少数副本中恰有一个像素颜色与原型不符；同一子块至多一个错误像素；
  全体副本经逐像素多数表决可唯一恢复原型。

规则
- 找出使划分成立的子块尺寸，并按逐像素多数表决重建原型瓦片。
- 构造与子块行列数同尺寸的小网格：含错误像素的副本位置填该错误像素的
  颜色，其余位置（背景块与无瑕副本）一律填背景。
- 输出该小网格。

关键洞察
- 这不是把放大图还原成控制掩码的裁剪题（诱饵）；输出记录的是每个瓦片
  副本相对原型的"病灶颜色"，无瑕副本与空块在输出里同样归于背景。
```

## 3. 角点配对消歧与隐形矩形交集

- tags:
  - operation:裁剪, crop
  - object:角点生成元, corner_generator
  - object:精灵体, sprite
  - relation:包围框包含, bbox_containment
  - relation:区域交集, region_intersection
  - condition:配对须框住完整精灵, pairing_disambiguated_by_containment
  - condition:交集唯一选物, intersection_selects_unique

### docstring

```text
一句话总述
- 先靠"每个矩形必须完整框住精灵"消解同色角点的配对歧义，再取全部隐形
  矩形的交集，输出唯一完全落在交集内的精灵。

输入结构
- 背景上散布若干个多像素连通精灵，形状颜色各异。
- 另有一种角标记色的孤立单像素共四粒（或六粒），它们两两配对可张成多
  个候选矩形，矩形本身从未画出。
- 角点存在多种两两配对方式；只有一种配对方式使每个张成的矩形都完整框
  住至少一个精灵，其余配对会产生切开精灵或空框的矩形。
- 每个合法矩形单独看都框住不止一个精灵，但全部合法矩形的公共交集内恰
  好完整包含一个精灵；所有角点的整体包围盒内含有多个精灵（堵住"看全
  体角点包围盒"的捷径）。

规则
- 枚举角点的两两配对方式，取唯一使所有张成矩形都完整框住精灵的配对。
- 求这些矩形区域（含边界）的交集。
- 找到唯一完全位于交集内部的精灵，输出它的紧致包围盒裁剪。

关键洞察
- 矩形只有角点这样的"生成元"被画出，且连生成元怎样成对都需要用"框必
  须框住完整精灵"反推；任何单个矩形都不足以定位目标，只有全部隐形矩
  形的交集才唯一指认要裁剪的精灵。
```

## 4. 四扇错位取景窗与底图贴片

- tags:
  - operation:平移, translate
  - operation:补全, completion
  - object:分隔十字, separator_cross
  - object:取景窗, viewport
  - object:贴片精灵, decal_sprite
  - relation:相位差即向量, phase_offset_as_vector
  - condition:纹理对齐求偏移, texture_alignment_yields_offset
  - condition:出窗部分裁切, clip_at_window_edge

### docstring

```text
一句话总述
- 识别十字分隔的四个象限是同一幅底图的四扇错位取景窗，把左上窗中覆盖
  的异色精灵按对齐关系补画进其余三扇窗。

输入结构
- 一条实心分隔行与一条实心分隔列构成十字，把网格分成四个等尺寸象限。
- 四个象限显示同一幅非周期多色纹理底图的四个不同取景位置：任意两窗的
  画面可凭纹理内容唯一对齐，得到各窗相对左上窗的取景偏移向量。
- 左上象限中另有一个由纹理外颜色构成的小精灵，覆盖在纹理之上。
- 四窗乍看只是"四块相似的花纹"（入口隐蔽：偏移从未被标注，须自行发现
  并测出）。

规则
- 凭纹理逐像素对齐四扇窗，求出每扇窗的取景偏移向量。
- 精灵属于底图上的固定贴片：对其余三扇窗，把精灵按该窗偏移换算到窗内
  坐标并画出；若精灵超出该窗取景范围则只画落在窗内的部分，完全不在窗
  内则该窗不画。
- 分隔十字、纹理与左上窗精灵保持不变。

关键洞察
- 四个象限不是四个独立图案，而是同一张底图的四扇错位窗口；精灵是钉在
  底图上的，它在每扇窗里的位置由从未画出的取景偏移决定。
```

## 5. 图例字典决定端口对接

- tags:
  - operation:拼接, stitch
  - operation:裁剪, crop
  - object:图例区域, legend_region
  - object:连接端口, connector_port
  - object:分隔线, divider
  - relation:图例中介配对, legend_mediated_pairing
  - condition:端口异色须查表, ports_unequal_need_lookup
  - condition:端口侧面定方向, port_side_sets_direction

### docstring

```text
一句话总述
- 用图例给出的颜色配对关系当作接口字典，把各个对象按端口对接拼装成整
  体并输出其紧致裁剪。

输入结构
- 网格由一条分隔线划出一小块图例区：图例中是若干横向紧贴的双像素色对
  （如 a|b），表示颜色 a 与颜色 b 互为伙伴。
- 主区散布若干多色前景对象：每个对象有统一的主体色，边界上嵌着少量端
  口像素，端口颜色各不相同、且与主体色不同。
- 任何两个应对接的端口颜色都不相等，只能靠图例配对；端口的几何远近与
  正确配对不一致（堵住"就近对接"的捷径）。

规则
- 读取图例，建立端口颜色的伙伴关系。
- 平移各对象（不旋转不翻转），使每一对伙伴端口沿各自暴露的边界侧面到
  边相贴；所有对象拼成一个整体。
- 丢弃图例与分隔线，输出拼装结果的紧致包围盒裁剪，端口像素保留原色。

关键洞察
- 端口颜色互不相同，画面上看似没有任何配对依据；真正的接口表写在角落
  那几粒不起眼的图例像素里。
```

## 6. 交叠可见性写成的替换表

- tags:
  - operation:重涂色, recolor
  - operation:颜色映射, color_mapping
  - object:矩形边框, rect_frame
  - object:查询精灵, query_sprite
  - relation:交叉处可见性, crossing_visibility
  - relation:被盖到盖上的映射, hidden_to_visible_map
  - condition:互盖排除层序读法, mutual_cover_blocks_ordering

### docstring

```text
一句话总述
- 把矩形框群每处交叠"谁盖住谁"读成有向的颜色替换规则，并将这张表施加
  到旁边的查询精灵上。

输入结构
- 一个区域内有若干单色一像素厚矩形框两两部分交叠；每处交叠点只显示一
  种颜色，同一对框在其所有交叠点上覆盖方向一致。
- 另一区域有一个多色查询精灵，其所用颜色全部出现在框色之中。
- 覆盖关系中存在互相成对的情形（甲盖乙处、乙又在别处盖甲），因此这些
  关系拼不成一个层叠全序（堵住"整理层序"的读法）。

规则
- 对每处交叠，记录规则"被盖颜色 → 盖上颜色"；汇总后每种查询色恰有一
  条出边。
- 将查询精灵中每个像素的颜色按该表替换一次。
- 输出替换后精灵的紧致包围盒裁剪，形状与布局不变。

关键洞察
- 框群不是要整理的层叠对象，而是一张用遮挡书写的颜色替换表；出现互盖
  恰恰说明这里读的是映射而不是次序。
```

## 7. 借完整印痕补最底层

- tags:
  - operation:补全, completion
  - operation:重涂色, recolor
  - object:印痕副本, stamp_copy
  - object:精灵原形, sprite_prototype
  - relation:遮挡顺序, occlusion_order
  - condition:顶层借形, borrow_shape_from_top
  - condition:可见数不指示层深, visible_count_misleads

### docstring

```text
一句话总述
- 多枚同形异色印痕层层压叠，用唯一完整可见的顶层印痕恢复精灵原形，并
  以最底层印痕的颜色输出这枚完整精灵。

输入结构
- 背景上有若干枚彼此部分重叠的印痕，每枚是同一精灵形状的平移副本，各
  用一种颜色。
- 交叠使除顶层外的每枚印痕都缺了一部分；交叠关系连成唯一的自顶向底链。
- 可见像素最少的印痕不一定是最底层（堵住"数可见像素挑最少"的捷径）。

规则
- 找到唯一完整无缺的印痕，取其形状为精灵原形。
- 按每处交叠"可见者在上"建立遮挡链，定位链末端的最底层印痕。
- 输出精灵原形的紧致裁剪，整体涂成最底层印痕的颜色。

关键洞察
- 最底层印痕的完整形状从未出现在画面上；它的形要向顶层完整副本借，它
  的身份要沿遮挡链去找。
```
