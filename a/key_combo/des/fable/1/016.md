## 1. 嵌套象限下钻，蓝点为燃料

- tags:
  - operation:区域填充, region_fill
  - operation:擦除, erase
  - object:控制像素, control_pixel
  - object:象限, quadrant
  - relation:所属象限, containing_quadrant
  - relation:路径内含决定生效, on_path_containment_activates
  - condition:燃料驱动递归, fuel_driven_recursion

### docstring

```text
以红色像素为地址指针反复四等分下钻：只要当前选中的区域里还有蓝色像素，就再切一层，直到选中区域不含蓝色为止，把最终区域填红。

输入结构：
- 恰有一个红色像素（地址指针），若干蓝色像素散布各处，其余均为背景色。
- 构造保证每次需要切分的区域行数与列数均为偶数，且红色像素在每一层都严格落在某个象限内部（不骑在切分线上）。

规则：
- 令当前区域为整个网格。
- 若当前区域内存在至少一个蓝色像素，则把该区域上下、左右各对半分为四个象限，并把当前区域更新为红色像素所在的那个象限；重复此判断。
- 当当前区域内不再含蓝色像素时停止。输出与输入同尺寸：全部清为背景色，再把最终选中的矩形区域整体填成红色。

关键洞察：
- 蓝色像素既不是干扰项也不是简单的计数器，而是"继续下钻"的燃料：只有恰好层层落入红点地址路径选中区域内的蓝点才逼出更深一刀，远离路径的蓝点从第一刀起就被切掉，看似存在却从不生效。用"数蓝点定深度"的假设能过部分示例，却在路径外蓝点较多的示例上崩塌。
```

## 2. 重复精灵对与搬运镜面

- tags:
  - operation:镜像, mirror
  - operation:搬运, move
  - object:精灵体, sprite
  - object:重复图案对, duplicate_pattern_pair
  - relation:重复对定镜轴, duplicate_pair_defines_axis
  - condition:出现两次者为指令, twice_pattern_as_instruction
  - condition:搬运而非复制, move_not_copy

### docstring

```text
唯一出现两次的精灵图案定义一面隐形镜子：重复对自身不动，其余精灵全部被搬运（而非复制）到镜子另一侧的镜像位置。

输入结构：
- 背景上散布若干多色精灵；恰有一种精灵图案（按紧致包围盒逐格比对）以平移复制的方式出现两次，其余图案各不相同。
- 两份拷贝沿同一行带对齐且间隔偶数列（或沿同一列带对齐且间隔偶数行），使它们的垂直平分线恰好落在两列（两行）之间。
- 其余精灵不骑跨该平分线，且镜像后仍完整落在网格内。

规则：
- 找出重复精灵对，取连接两份拷贝方向上的垂直平分线为镜轴。
- 重复对的两份拷贝原样保留。
- 其余每个精灵从原位置整体删除，绘制到关于镜轴的镜像位置：跨越竖直镜轴时形状左右翻转，跨越水平镜轴时上下翻转，颜色保持不变。

关键洞察：
- 重复出现的图案不是要提取的目标，而是一条指令；且指令内容是反射不是平移——被搬运的精灵都翻了面，而作为"镜框"的重复对自己纹丝不动，这同时排除了"提取重复者"和"把重复对的位移向量套在所有对象上"两个第一直觉。
```

## 3. 东向沉降与靠山传色

- tags:
  - operation:滑动, sliding
  - operation:重涂色, recolor
  - object:前景对象, fg_object
  - object:画布边界, canvas_boundary
  - relation:碰撞阻挡, collision_block
  - relation:依靠链, support_chain
  - condition:重力沉降, gravity_settle
  - condition:根对象定颜色, root_determines_color

### docstring

```text
所有前景对象向右滑动沉降；停稳后每个对象改涂成它沿"依靠链"追溯到的、直接顶住右边界的那个根对象的颜色。

输入结构：
- 背景色占主导，其余为若干互不相触的单色 4 连通对象，颜色各异。
- 对象的行带互相交叠，使沉降后一些对象顶在其他对象的左侧。
- 构造保证沉降终态中每个对象的右侧至多与一个对象相邻，但一个对象的左侧可以同时被多个对象依靠。

规则：
- 把每个对象视为保持形状的刚体，同步向右滑动，直到所有对象都被右边界或无法再动的对象挡住。
- 在终态中，若对象 A 的某格与对象 B 的某格左右相邻且 B 在右，则 A 依靠 B。
- 直接接触右边界的对象保留自身颜色；其余对象沿依靠关系一路向右追溯到接触边界的根对象，整体改涂成根对象的颜色。

关键洞察：
- 输出颜色由碰撞因果链决定：不是按行带取最右者的颜色，而是问"谁挡住了我、又是谁挡住了它"，一路问到墙根。一个高大的根对象可以沿多条支链把自己的颜色传给不同行带的对象，专门击破"逐行看最右"的捷径。
```

## 4. 反相图例解码

- tags:
  - operation:符号解码, symbol_decoding
  - operation:反转, invert
  - operation:压缩, compress
  - object:符号掩码, symbol_mask
  - object:面板, panel
  - object:图例精灵, legend_sprite
  - relation:图案匹配, pattern_match
  - condition:补集匹配, complement_match
  - condition:码表在图内, in_grid_codebook

### docstring

```text
顶部每个灰色符号面板要先做灰黑反相，才能在下方散布的彩色图例中找到同形状的精灵；按面板顺序输出解得颜色组成的一行。

输入结构：
- 网格顶部是由 n 个 3×3 面板拼成的横带，每个面板在黑底上用灰色画一个符号。
- 横带下方散布若干单色精灵（图例），颜色互不相同，位置与排列顺序无意义。
- 构造保证：每个面板的反相掩码（原灰格变黑、原黑格变灰后的灰格集合）按紧致包围盒逐格比对，与恰好一个图例精灵的形状相同；不做反相则任何面板都找不到匹配。
- 构造保证：存在灰格数量相同但解码颜色不同的面板，颜色无法靠计数得到。

规则：
- 对每个面板取其 3×3 掩码的补集，作为该面板真正编码的形状。
- 在图例精灵中找到形状与该补集相同的唯一精灵，读取其颜色。
- 输出为 1×n 的一行，第 i 格是第 i 个面板解出的颜色。

关键洞察：
- 码表不在题外而藏在画面里，但钥匙是反着插的：面板上画出的灰色部分是符号的底片，必须取补集才能在图例中配对；图例的存在说明颜色不由任何固定映射给出，反相的必要性又堵死了直接形状匹配的入口。
```

## 5. 翻越镜柱后坠落

- tags:
  - operation:镜像, mirror
  - operation:滑动, sliding
  - operation:重涂色, recolor
  - object:精灵体, sprite
  - object:标柱像素, pillar_marker
  - relation:标柱列定镜轴, marker_column_axis
  - condition:镜像后重力沉降, mirror_then_gravity
  - condition:中间态不可见, hidden_intermediate

### docstring

```text
每个标柱像素指定一根竖直镜柱：与其配对的精灵关于该柱做左右镜像得到镜像体，镜像体改涂标柱颜色并竖直坠落到底；原精灵不动，标柱消失。

输入结构：
- 背景上有一到两个左右不对称的单色精灵；每个精灵的行带内恰有一个颜色独特的标柱像素，位于精灵左侧或右侧。
- 构造保证：各镜像体彼此列不重叠、互不影响，且镜像后的下落起点不与任何已有前景重叠。

规则：
- 对每个精灵，以其配对标柱像素所在的整列为镜轴，求出精灵关于该列左右镜像后的位置与翻转形状，并把颜色换成标柱像素的颜色，得到镜像体。
- 镜像体从镜像位置整体竖直下落，直到被网格底边或已有前景（原精灵或先停稳的镜像体）挡住。
- 原精灵保持原位原色，删除所有标柱像素。

关键洞察：
- 镜像体并不停在镜像位置：它的列坐标由镜柱反射决定，行坐标由随后的重力决定，而"反射后的悬空位置"这一中间状态从未出现在画面上——必须从落体翻转的形状反推出那次看不见的反射，再从列的偏移反推出镜轴就是被删除的标柱所在列。
```

## 6. 孔内点数拨转

- tags:
  - operation:旋转, rotate
  - operation:计数, counting
  - operation:擦除, erase
  - object:封闭孔洞, enclosed_hole
  - object:点缀像素, pip_pixel
  - relation:孔心为支点, hole_center_pivot
  - condition:点数定转角, pip_count_rotation
  - condition:偏心支点致位移, off_center_pivot_shift

### docstring

```text
每个带孔对象绕自己孔的中心格旋转，顺时针转过的四分之一圈数等于孔内点缀像素的个数，随后点缀消失。

输入结构：
- 背景上有若干互不相触的单色对象，每个对象内部包着一个奇数边长的方形封闭背景孔，孔的位置明显偏离对象的几何中心。
- 每个孔内放有 1 至 4 个黄色点缀像素；黄色不作他用。

规则：
- 数出每个对象孔内点缀像素的个数 k。
- 以该孔的中心格为支点，把整个对象连同孔顺时针旋转 k 个四分之一圈；构造保证旋转后对象仍完整落在网格内且不与其他对象相触。
- 清除全部点缀像素，孔内恢复为背景色。

关键洞察：
- 点数是转角编码，支点是孔心而不是对象中心：支点偏心使对象一边转一边整体搬家，位移量反过来暴露了真正的旋转中心；k=4 的对象转满一圈回到原位，看似"点缀无效"，实则是同一规则的静默特例，专门迷惑按"点数多少分类操作"的假设。
```
