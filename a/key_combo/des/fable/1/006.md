## 1. 坠落壁纸

### docstring

```text
将坠落到底部的碎片按重力逆推放回壁纸空洞，再用还原后才能唯一确定的最小重复基元补齐其余空洞。

输入结构：
- 网格被一条整行的分隔线（其颜色不在壁纸中出现）分为上下两区：上区是带黑色空洞的周期壁纸，下区是黑色背景上贴底堆积的彩色碎片堆。
- 上区每个空洞原有的像素沿所在列竖直坠落，依次堆入下区同列；来自更低空洞的像素先落下，位于碎片堆更下方。
- 若某列碎片堆已顶满至分隔线，说明该列还有像素溢出画面而丢失；未顶满的列其碎片数与该列空洞数相等。
- 仅凭上区可见的非黑格无法唯一确定最小重复基元；补回全部碎片后基元才唯一，且有些相位的颜色只出现在碎片中。

规则：
- 对每一列，将碎片堆自下而上依次填回该列空洞自下而上的对应位置。
- 顶满至分隔线的列中，多出的最高处空洞视为像素已丢失，暂留为空。
- 以还原后的全部非黑格推断唯一的最小重复基元，用对应相位的颜色填补剩余空洞。
- 输出中上区为完整壁纸，分隔线保留，下区全部恢复为黑色。

关键洞察：
- 碎片不是噪声而是空洞内容的"果"，必须先做重力反演把果放回因的位置；周期推断只有在此之后才有唯一解，两个机制是串联咬合而非并列的。
```

## 2. 一元两尺度自愈

### docstring

```text
从壁纸推断最小基元，用它同时修复原尺度的黑色空洞和窗口中放大像里被整块涂错的格块。

输入结构：
- 整幅网格铺满同一周期壁纸，其上散布少量黑色空洞。
- 网格中恰有一个矩形窗口，其内容不是壁纸的延续，而是壁纸最小基元的一个逐像素整数倍放大像：基元的每个格对应窗口内一个同色实心方块，窗口尺寸恰等于基元尺寸乘以放大倍数，窗口内恰好只含基元的一个放大像。
- 窗口内有少数格块被整块涂成了错误颜色；窗口内不含黑色，错误格块数量足够少，不影响识别放大倍数。

规则：
- 忽略窗口区域与黑色空洞，由其余格子推断唯一的最小重复基元。
- 用基元对应相位的颜色填补窗口外的所有黑色空洞。
- 把基元按放大倍数逐像素放大并与窗口对齐，将窗口内颜色不符的格块整块改为应有颜色。
- 输出为修复后的整幅网格。

关键洞察：
- 窗口的正确内容从未以该尺度完整出现，唯一参照是从窗口之外的壁纸推断出的潜在基元；按"壁纸延续相位"修复窗口、或在窗口内部找周期自检都是走不通的诱饵——窗口恰好只含一个放大像，错误又以整块为单位。
```

## 3. 刻度消除连锁

### docstring

```text
让悬空像素坠落，反复消除长度达到底部刻度条所示阈值的水平同色段，直到画面稳定。

输入结构：
- 网格底部两行是特殊区：倒数第二行为一整行地面色，最底一行的左端有一段灰色刻度条（其余为黑），刻度条长度 L 在不同示例中不同。
- 地面之上的黑色背景中散布若干彩色像素，可悬空、可堆叠；像素颜色不与地面色、灰色混淆。
- 多种颜色混杂，保证坠落与消除交替的过程有限且结果唯一。

规则：
- 地面之上的所有像素沿所在列下落，落在地面或其他像素之上；地面行与刻度行不参与坠落。
- 落定后，将所有"同一行内水平连续、同色、长度不小于 L"的像素段同时消除（变黑）。
- 消除腾出空间后上方像素再次坠落；坠落与消除交替进行，直到既无悬空像素也无长度达到 L 的同色段。
- 输出稳定后的画面，地面与刻度条原样保留。

关键洞察：
- 消除阈值不是通用常数，而是由画面外围刻度条长度给出的隐参数——在某些示例里同色三连安然无恙；且这不是一次性沉降，消除引发新坠落、新坠落又拼出新的可消除段，答案是整条连锁反应的终态。
```

## 4. 双源等距缝

### docstring

```text
在迷宫走廊中标出沿走廊到两个源点最短路程恰好相等的格子。

输入结构：
- 青色格构成迷宫墙体，黑色格是走廊；走廊中有两个不同颜色的单像素源点，位于同一连通走廊内，颜色均不是黄色。
- 走廊拓扑保证等距格存在且分布不规则。

规则：
- 对每个黑色走廊格，分别计算它沿走廊（四连通，墙不可穿越）到两个源点的最短步数。
- 两个步数恰好相等的走廊格涂成黄色；其余所有格保持不变。
- 源点自身与墙体永不改变。

关键洞察：
- 距离是沿走廊绕行的路程而非直线距离：第一眼像"两点连线的垂直平分线"，但绕过墙体后等距缝会弯折、断裂、甚至出现在两源点连线的同一侧，只有"沿走廊路程等距"的假设能同时解释所有示例。
```

## 5. 钥匙入锁

### docstring

```text
把每个带凹口的方块旋转成凹口朝下，平移到与凹口形状完全相同的地面立齿上方落下扣合。

输入结构：
- 网格底部是一整行地面色；地面上竖立若干实心矩形立齿，宽度、高度各不尽相同，颜色各异。
- 空中悬浮若干单色矩形方块，每块的某条边上开有一个矩形凹口（宽 w、深 d）；凹口可能朝左、朝右、朝上或朝下。
- 每个凹口的宽深与恰好一根立齿的宽高完全相等，一一对应；另有一根不与任何凹口同形的干扰齿（可能与某凹口同深不同宽）。
- 方块颜色与立齿颜色的对应关系不可靠：有的示例里恰好同色配对，有的示例里同色并不同形。

规则：
- 将每个方块旋转 90° 的整数倍，使凹口朝正下方。
- 把方块平移到凹口形状与之完全相同的立齿正上方，凹口与立齿逐列对齐，竖直落下，直到立齿完全插入凹口、方块底边贴住地面。
- 干扰齿保持空置；输出中空中不再有方块，落位后的方块互不重叠。

关键洞察：
- 配对的真正钥匙是"凹口形状=立齿形状"的几何咬合而不是颜色；颜色在部分示例中是诱饵，且必须先把凹口旋转归一化朝下，才能正确比对宽与深。
```

## 6. 隐形管网接力

### docstring

```text
唯一的信件像素按"缺口进、另一缺口出"的规则在空心方框组成的隐形管网中多跳接力飞行，在每个中转框正中盖下同色邮戳，直到送达单缺口框或搁浅在墙外。

输入结构：
- 黑色背景上散布若干同一墙色、边长为奇数的空心矩形方框；有的框恰有一个单格缺口（端点框），有的框恰有两个单格缺口（中转框），缺口可开在任意边的任意位置。
- 恰有一个端点框的正中有一个彩色单像素信件，其余框内部为空。
- 数据保证：飞行路径有限不成环；不出现射线沿墙线掠过缺口的情形。

规则：
- 信件经所在端点框的缺口射出，沿缺口所在行或列、垂直于该边向外直线飞行，途中黑色格不留任何痕迹。
- 射线以途中碰到的第一个障碍为准：若首先命中某框的缺口格，信件穿入该框；若首先命中墙格，信件停在该墙外侧紧贴一格；若一路无阻，信件停在网格边缘最后一格。
- 穿入两缺口的中转框时，在该框正中盖一个信件色邮戳，随后信件立即从另一个缺口按同样方式射出，继续接力。
- 穿入单缺口的端点框时，信件停在该框正中，接力结束。
- 输出中所有方框与缺口原样保留，起点框中心恢复为空，画面上新增各中转框的邮戳与信件的最终位置。

关键洞察：
- 缺口同时规定了"能否进入"与"从哪射出"：整张画面是一张从未画出的有向管网，信件的走向在每个中转框被重新定向；且射线服从"第一障碍"原则——看似遥遥对准的缺口可能被中间某堵墙截断，只有逐跳追踪隐形路径并识别端点框与中转框的角色差异，才能同时解释邮戳链、送达与搁浅。
```
