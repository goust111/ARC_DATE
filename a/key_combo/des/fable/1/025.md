## 1. 连锁锚定滑车

- tags:
  - operation:滑动, slide
  - operation:擦除, erase
  - object:矩形体, rectangular_body
  - object:连接杆, connector_stem
  - object:锚定物, anchor_object
  - relation:链式连接, chain_linkage
  - condition:碰撞停止, collision_stop
  - condition:已就位者成新锚, settled_becomes_anchor

### docstring

```text
沿各自连接杆的方向依次滑动矩形体，已就位的矩形体成为后续滑动的新锚定物。

输入结构：
- 黑色背景网格上有一个实心矩形锚定物，它是唯一不带连接杆的对象。
- 其余每个对象由一个实心矩形体和一根一格宽的直连接杆组成，各对象颜色互不相同。
- 输入中至多一个对象的滑动路径直达锚定物，其余对象的杆看似指向空地。

规则：
- 反复执行：找出唯一一个满足条件的对象——沿其杆方向平移矩形体、途中无阻挡、
  且最终能与已就位结构（锚定物或已停靠的矩形体）相邻停靠。
- 擦除该对象的连接杆，把矩形体沿杆方向滑动到与已就位结构相邻处停下，
  该矩形体随即加入已就位结构。
- 重复直至没有对象满足条件；始终无法停靠的对象整体保持原样。

关键洞察：
- 杆不是轨道长度而是方向指令，滑动距离由撞上已就位结构决定。
- 已就位的矩形体会改变后续对象的可达性，必须按依赖顺序模拟——
  输入里看似指向空地的杆，其实指向"未来才出现"的停靠面。
```

## 2. 墙域奇偶重力

- tags:
  - operation:滑动, slide
  - object:分隔墙线, separator_wall
  - object:背景区域, background_region
  - object:精灵体, sprite
  - relation:二部图结构, bipartite_structure
  - condition:交替类别定方向, alternating_class_direction
  - condition:碰撞停止, collision_stop

### docstring

```text
由分隔墙构成的区域二部图决定每个区域内精灵体的滑动方向：与左下角区域同类的下落，异类的上浮。

输入结构：
- 网格由背景色和一格厚的红色分隔墙组成，墙把背景分割成若干四连通区域，
  每段墙恰好分隔两个区域。
- 部分区域内各含一个单色精灵体；精灵体的颜色、大小、高低位置与方向无关，
  且布局刻意使"按高低、大小、颜色定方向"等表面规律只在部分示例成立。

规则：
- 把每个背景区域视为节点，隔一段墙相邻的两个区域连边；
  含左下角的区域记为甲类，跨一段墙翻转一次类别。
- 甲类区域内的精灵体在本区域内竖直下滑，乙类区域内的竖直上浮，
  碰到墙或网格边缘即停，列位置不变。
- 墙保持不变，区域不染色。

关键洞察：
- 方向信息完全不在精灵体自身或其所在区域的任何可见属性上，
  而在以左下角为基准、跨墙交替的隐藏奇偶标签上。
```

## 3. 走廊互见配对填充

- tags:
  - operation:填充, fill
  - operation:擦除, erase
  - object:标记像素, marker_pixel
  - object:障碍段, barrier_segment
  - relation:对角配对, diagonal_pairing
  - relation:边界走廊互见, border_corridor_visibility
  - condition:走廊畅通才填充, open_corridor_fills

### docstring

```text
每种成对出现的角标颜色，仅当两角点之间沿包围盒边缘存在一条未被障碍截断的 L 形走廊时，才把包围盒填充为该颜色，否则擦除这对角标。

输入结构：
- 背景网格上有一种障碍色，其像素构成若干直线段。
- 其余每种前景色恰好出现两次，作为一对角标像素，行列均不重合。
- 部分对的包围盒内部含有障碍但边缘走廊畅通，
  用于淘汰"盒内无障碍才填充"的表面读法。

规则：
- 对每对同色角标，考察两条 L 形走廊：先横后竖、先竖后横，
  各沿包围盒的两条边行进。
- 若至少一条走廊完全不经过障碍像素，则把包围盒内所有背景格染成该对颜色，
  盒内原有障碍像素保持可见。
- 若两条走廊都被截断，则擦除这两个角标；障碍永不改变。

关键洞察：
- 判定发生在包围盒的边界走廊上而不是内部——
  盒内的障碍不挡"合拢"，压在边框路径上的障碍才挡。
```

## 4. 并集钥匙开锁

- tags:
  - operation:补全, complete
  - operation:填充, fill
  - operation:擦除, erase
  - object:部分图案, partial_pattern
  - object:封闭孔洞, enclosed_hole
  - object:边框, border
  - relation:对齐合并取并集, align_merge_union
  - relation:形状匹配, shape_matching
  - condition:各副本互补缺失, copies_complement
  - condition:单片吻合是诱饵, single_piece_decoy

### docstring

```text
把多份残缺副本按左上对齐取并集拼出完整钥匙形，找到内孔形状与之吻合的唯一锁框，用锁框自身颜色填死其内孔，并消耗掉全部钥匙碎片。

输入结构：
- 背景网格一侧散布若干不同颜色的色块，每块都是同一精灵掩码的残缺副本，
  裁到包围盒后左上对齐，各自缺失互补的部分。
- 另一侧有若干封闭边框对象，每个边框内部包围一个背景孔洞，孔洞形状各不相同。
- 恰有一个边框的孔洞等于全部残缺副本的并集；
  同时存在某个单独的残缺副本恰好等于另一个边框的孔洞，用作诱饵。

规则：
- 把每个残缺副本裁到包围盒并按左上对齐求并集，得到完整模板。
- 找到内孔与模板全等（不旋转不镜像）的边框，
  把该孔洞全部染成该边框自身的颜色。
- 擦除所有残缺副本，其余边框保持不变。

关键洞察：
- 任何单独一块碎片都是陷阱——只有互补并集才是真正的钥匙，
  单片能吻合的锁是诱饵。
```

## 5. 管道输液

- tags:
  - operation:擦除, erase
  - operation:堆叠, stack
  - object:矩形边框容器, framed_container
  - object:连接管道, connector_pipe
  - object:液体像素, liquid_pixel
  - relation:管长即先后, pipe_length_ordering
  - condition:像素数守恒, pixel_count_conservation
  - condition:自底向上沉积, bottom_up_settle

### docstring

```text
把各源容器内的液体像素经管道全部转移进唯一的空容器，按管道长度从短到长的到达顺序自底向上逐行沉积，像素总数守恒。

输入结构：
- 网格上有若干矩形边框容器，边框色统一；恰有一个容器内部为空（目标容器），
  其余容器内部散布若干同色液体像素，各容器液体颜色不同。
- 每个源容器由一条一格宽的管道线连接到目标容器，管道长度互不相同。

规则：
- 统计每个源容器的液体像素数并清空源容器；管道与所有边框保持不变。
- 按管道长度从短到长决定进入顺序；液体在目标容器内部自底行向上、
  每行从左到右沉积，前一种颜色铺完其全部像素后下一种紧接着继续铺。
- 目标容器内液体总数等于各源液体数之和。

关键洞察：
- 管道不运送形状只运送数量——源内液体的摆放形状无关紧要，守恒的是计数；
  层序由管长这一"距离即先后"的隐藏时钟决定。
```

## 6. 定长绳索铺设

- tags:
  - operation:连线, connect
  - operation:擦除, erase
  - object:起点标记, start_marker
  - object:终点标记, end_marker
  - object:定长直条, fixed_length_bar
  - relation:唯一最短通路, unique_shortest_path
  - condition:像素数守恒, pixel_count_conservation
  - condition:预算截断或过冲, budget_truncate_or_overshoot

### docstring

```text
把边缘处长为 L 的绳色直条擦除，改为从起点标记出发、沿唯一最短四邻通路向终点方向铺设恰好 L 格绳色，长度严格守恒。

输入结构：
- 网格上有一个起点标记像素、一个终点标记像素和若干障碍块，
  障碍布置使起终点间的最短四邻通路唯一。
- 网格边缘另有一根长为 L 的绳色直条。

规则：
- 擦除边缘直条；从紧邻起点的第一格开始沿唯一最短通路逐格铺绳色，共铺 L 格。
- 若 L 小于通路长度，绳在半路终止、不与终点相接；
  若 L 大于通路长度，多余部分越过终点沿最后前进方向直线继续铺完。
- 起点、终点、障碍保持不变。

关键洞察：
- 这不是"连接两点"——绳是守恒的实物，
  答案由长度预算截断或冲出唯一测地线得到；
  部分示例里绳恰好够长，诱导"必须连到终点"的误读。
```

## 7. 镜厅接力

- tags:
  - operation:镜像, mirror
  - object:精灵体, sprite
  - object:标记条, marker_bar
  - relation:跨度裁剪, span_clipping
  - relation:链式连接, chain_linkage
  - condition:等距反射, equidistant_reflection
  - condition:只留最终像, final_image_only

### docstring

```text
镜条把精灵体上与其跨度对齐的部分等距反射到另一侧，反射出的像若又落入别的镜条的跨度带，则被接力继续反射，画面只保留每条光路最终静止的像。

输入结构：
- 背景网格中央有一个多色精灵体；周围散布若干灰色直条（镜条），
  各自与网格坐标轴平行、长度不一，与精灵体隔着若干背景格。
- 镜条的摆放使部分反射像恰好落入另一镜条的跨度带内；
  训练示例中至少有一例仅发生单次反射，诱导"各镜条独立成像"的误读。

规则：
- 逐像素处理：精灵体像素若投影落在某镜条跨度内，
  以该镜条所在直线为轴等距反射得到新位置。
- 若新位置的投影又落在另一根尚未参与本光路的镜条跨度内、且位于其入射一侧，
  则以那根镜条为轴继续反射；如此接力直至不再落入任何新镜条的跨度。
- 只在最终静止位置画出该像素（保留原色），中间落点不画；
  每根镜条对同一光路至多作用一次；镜条与精灵体本体保持不变。

关键洞察：
- 单镜直觉不够——像会被后续镜条接力搬运，
  最终位置由所经镜条序列的复合反射决定；
  "独立成像"的读法只在部分示例里侥幸成立。
```
