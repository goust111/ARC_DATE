## 1. 晶格缺陷拼补

- 参考题目: `184a9768`, `332efdb3`, `ce8d95cc`
- tags:
  - operation:周期推断, period_inference
  - operation:拼合填充, tiling_fill
  - operation:平移, translate
  - operation:擦除, erase
  - object:周期底纹, periodic_texture
  - object:缺陷区域, defect_region
  - object:源精灵, source_sprite
  - relation:偏离周期即孔洞, deviation_defines_hole
  - condition:精灵精确拼合缺陷, sprites_exactly_tile_defects

### docstring

```text
先重建底纹的理想周期图案找出缺陷，再把散落的精灵平移进去恰好拼满全部缺陷。

输入结构
- 网格的一片矩形区域覆盖着一个沿行、列双向周期重复的多色底纹，周期与花样每个示例不同。
- 底纹内部有若干成片格子被替换成了背景色（缺陷）；缺陷没有边框，不与任何别的对象相邻，形状不规则。
- 底纹区域之外的背景上散落着若干彼此分离的精灵。

规则
- 由未受破坏的部分推断底纹的最小周期块，得到整片区域的理想底纹。
- 实际格色与理想底纹不一致的格子构成缺陷格集合。
- 把每个精灵只做平移（不旋转、不翻转、不改色）放入缺陷区域；每个精灵恰用一次，所有精灵的落位掩码互不重叠且并集恰为全部缺陷格。
- 精灵原位置清为背景；底纹其余部分与网格背景保持不变。

关键洞察
- "洞"从未被画出：它既无边框也无包围结构，只有先在脑中补全那张看不见的理想周期图案，缺陷才会显形；而精灵形状集合对该缺陷集合恰好存在唯一的精确拼合。
```

## 2. 伸缩量换轴

- 参考题目: `ce8d95cc`, `67636eac`
- tags:
  - operation:压缩, compression
  - operation:再展开, re_expansion
  - object:重复行带, dup_row_band
  - object:重复列带, dup_column_band
  - relation:游程向量, run_length_vector
  - condition:行列倍数互换, swap_axis_multiplicity

### docstring

```text
图案内容原样保留，但把行方向与列方向的拉伸倍数序列互换后重新展开。

输入结构
- 输入是一个小核心图案经逐行、逐列复制拉伸得到的大图：相邻相同的行构成行带，相邻相同的列构成列带，各带厚度不一。
- 行列相邻去重后得到的核心图案是正方形（行带数等于列带数）。

规则
- 自上而下记录各行带的高度序列 H，自左向右记录各列带的宽度序列 W，行列相邻去重得到核心图案。
- 以 W 作为新的各行带高度、以 H 作为新的各列带宽度，重新展开核心图案；图案本身不转置、不镜像、不改色。

关键洞察
- 输出乍看像转置或缩放，其实图案朝向从未改变；被交换的只是两条隐藏的游程向量——真正被操作的对象不是像素，而是行与列的重复次数。
```

## 3. 蛇形指令带

- 参考题目: `7b5033c1`, `342dd610`
- tags:
  - operation:遍历, traverse
  - operation:轨迹绘制, trajectory_drawing
  - operation:擦除, erase
  - object:蛇形路径, snake_path
  - object:端点, endpoint
  - object:起点标记, start_marker
  - relation:颜色编码位移, color_encoded_disp
  - condition:按遍历顺序执行, execute_in_traversal_order

### docstring

```text
把蛇形彩带按端点顺序读成一串移动指令，从灰色起点出发逐步画出执行轨迹。

输入结构
- 背景为黑色。
- 一条 4 连通、无分支、恰有两个端点的蛇形路径，每格颜色取自四种指令色：红、黄、蓝、绿。
- 远离蛇的位置有一个孤立的灰色像素作为起点。

规则
- 从蛇最靠左上的端点开始，沿路径逐格读取颜色序列。
- 从灰色起点出发依序执行：红=右移一格，黄=左移一格，蓝=上移一格，绿=下移一格；每走一步就用该指令色涂所到之格。
- 若某步落到已涂过的格（含起点），新色覆盖旧色。
- 输出中整条蛇被擦除，只保留灰色起点与画出的轨迹。

关键洞察
- 蛇的形状毫无意义：它是按遍历顺序排列的一维指令带，真正的图形是在别处被"执行"出来的轨迹；入口在于意识到两团互不接触的颜色之间隔着一层时间关系。
```

## 4. 雾下残影

- 参考题目: `ad38a9d0`, `e99362f0`, `184a9768`
- tags:
  - operation:一致性补全, consistency_completion
  - operation:擦除, erase
  - operation:重涂色, recolor
  - operation:裁剪, crop
  - object:形状图例, shape_legend
  - object:雾块, fog_block
  - object:可见碎片, visible_fragment
  - relation:碎片被形状覆盖, fragments_covered_by_shape
  - condition:缺失部分须在雾内, hidden_cells_under_fog

### docstring

```text
从图例中找出唯一能解释场景残影的形状，补全它、还原它的颜色并抹去雾。

输入结构
- 网格被一条整行分隔线分成上下两区：上区是图例区，并排放着几个完整的单色形状，颜色互不相同；下区是场景区。
- 场景区有若干灰色实心矩形雾块，以及一些橙色的散落碎片像素；碎片一律显示为橙色，与图例颜色无关。

规则
- 在图例形状与平移位置中寻找一个组合，使该形状恰好覆盖全部橙色碎片，且形状中未显示为碎片的格子全部落在雾块之内；题目保证这样的解释唯一。
- 输出仅为场景区（不含分隔线与图例）：雾块全部清为背景，被找到的形状在其位置上完整画出，并使用它在图例中的颜色；其余为背景。

关键洞察
- 目标对象从未被完整画出，连颜色都被抹成了统一的影色；同时锁定形状、位置与真实颜色的，是"碎片必须全被覆盖、缺口必须全被雾藏住"这一双向一致性。
```

## 5. 双距定角切除

- 参考题目: `52364a65`, `ddf7fa4f`, `184a9768`
- tags:
  - operation:擦除, erase
  - object:连通对象, connected_object
  - object:孤立标记, singleton_marker
  - object:标记噪声, marker_noise
  - relation:正对配对, facing_alignment
  - relation:间隙编码边长, gap_encodes_side_length
  - condition:相对自身裁切, local_corner_crop

### docstring

```text
每个对象由两枚正对的灰标记在互相垂直的方向上各给出一段空隙，按这两段距离在最近角削去一个矩形缺口。

输入结构
- 背景上有若干单色 4 连通实心对象。
- 每个对象恰有两枚孤立灰标记：一枚位于其包围盒的正上或正下方向，另一枚位于正左或正右方向，各与对象隔着若干格背景。
- 另有一些灰色像素不与任何对象正对，属于噪声。

规则
- 将每个对象与其两枚正对标记配对；设竖直方向标记与对象的空隙为 a 格，水平方向标记与对象的空隙为 b 格。
- 在对象包围盒中取同时靠近这两枚标记的那个角，削去该角处 a 行 × b 列范围内的对象像素（改为背景）。
- 删除所有灰色像素（含噪声）；对象其余部分保持不变。

关键洞察
- 缺口的两个边长分别藏在两段互相垂直、空无一物的距离里；单看任何一枚标记都解释不了缺口的形状，只有把两条隐形标尺交到同一个角上才能读出规则，并且要先分辨有效标尺与噪声。
```

## 6. 梳齿节拍射线

- 参考题目: `a1aa0c1e`, `58e15b12`, `342dd610`
- tags:
  - operation:计数, count
  - operation:周期打点, periodic_dotting
  - operation:重涂色, recolor
  - object:梳状结构, comb_motif
  - object:虚线射线, dotted_ray
  - relation:齿数编码步长, teeth_encode_step
  - condition:同格同拍变色, coincidence_recolor

### docstring

```text
每把梳子按自己的齿数为周期向网格内部打点，两条节拍在同一格重合处变为粉色。

输入结构
- 背景为黑色。
- 若干单色"梳子"贴着网格边缘放置：一条与该边平行的脊柱条，加上从脊柱伸向网格内部的若干等距单格梳齿。
- 不同梳子颜色不同、齿数不同，可位于不同的边。

规则
- 对每把梳子，数出梳齿数 k，并取脊柱的中心格。
- 从脊柱中心沿梳齿指向的垂直方向，在距离 k、2k、3k……的格子处各打一个该梳颜色的点，直到出界。
- 梳子本体保留不动；若两把不同梳子的点落在同一格，该格涂粉色。

关键洞察
- 梳齿不是装饰而是数字：它同时给出射线的发射方向与节拍周期；画面上并不存在的两条"虚线"，只在同拍相遇的格点上留下证据。
```
