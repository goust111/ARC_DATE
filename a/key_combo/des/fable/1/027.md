## 1. 弹痕帧外推

- tags:
  - operation:外推, extrapolate
  - operation:反射, reflect
  - operation:描痕, dent_marking
  - object:帧序列, frame_sequence
  - object:运动小球, moving_ball
  - object:墙壁凹痕, wall_dent
  - relation:历史累积, history_accumulation
  - condition:触壁反弹留痕, bounce_leaves_dent

### docstring

```text
一句话总述：面板序列记录小球在框内匀速运动并在框壁反弹的历史，每次撞壁在墙上
留下永久凹痕，输出为下一帧的独立面板。

输入结构：
- 网格由若干等宽面板横向排列构成，相邻面板共享一列边框，每个面板有相同的
  墙壁边框与底色。
- 面板内有同一个彩色小球逐帧移动，位移在碰壁前保持恒定，碰壁后对应分量反向。
- 小球每次撞击墙壁，被撞的那个墙壁像素永久变为小球色（凹痕），并在该帧及
  之后所有帧中保留，因此靠后的帧累积了更多凹痕。

规则：
- 把各面板视为时间连续帧，由相邻帧位置差推出小球的速度分量；凹痕的增长方向
  同时给出帧的先后与历次撞点。
- 在最后一帧基础上再推进一步：若这一步撞到内壁则按镜面反射折返，并在撞点
  新增一个小球色凹痕。
- 输出一个独立完整面板，画出小球的新位置、全部已有凹痕以及可能新增的凹痕。

关键洞察：
- 面板是携带历史的时间帧：凹痕既是撞击的证据又是帧序的标尺，外推必须同时
  延续小球的反弹运动和墙面痕迹的累积，二者互相校验。
```

## 2. 开门放水

- tags:
  - operation:洪泛填充, flood_fill
  - operation:开缺口, punch_gap
  - object:嵌套同心框, nested_frames
  - object:侧标记, side_marker
  - object:水色内域, water_core
  - relation:颜色匹配选层, color_match_layer
  - condition:内层链式开门, inner_chain_gating

### docstring

```text
一句话总述：外部标记在与自己同色的框层上开门，中心水色只能沿"由内到外每一层
都已开门"的链条逐层外泄。

输入结构：
- 背景上有一组居中嵌套的单像素厚正方形框，各层颜色互不相同，最内层框内部
  被一种"水"色填满。
- 最外层框之外散布若干单像素标记，每个标记与某一层框同色，且位于可沿行或列
  垂直射向框组的位置。

规则：
- 每个标记沿行或列向框心方向作用：它无视沿途所有异色框层，只在与自己同色的
  那一层框上、其行列对准的位置打开一个单像素缺口（该框像素变为背景色），
  标记本身消失。
- 所有门开完后，水从最内层向外洪泛：两相邻框层之间的走廊是连通的，水能进入
  某条走廊当且仅当它内侧的每一层框都至少有一个缺口；若最外层也有缺口且更内
  各层均已开门，水继续泄到框外背景。
- 被水到达的走廊与背景区域全部染成水色，水流经的缺口像素同样染成水色；
  未被水到达的区域与全部框层保持原样。

关键洞察：
- 标记选层靠颜色匹配而非首层阻挡，缺口是门而非装饰；水位由"最靠内的未开门
  框层"一票否决——外层开再多门，只要有一层内框无门，水就止步于该层之内。
```

## 3. 叠放图例

- tags:
  - operation:不透明叠加, opaque_overlay
  - operation:排序, ordering
  - object:面板, panel
  - object:标签像素, tag_pixel
  - object:图例色条, legend_strip
  - relation:图例定层序, legend_defines_zorder
  - condition:冲突由上层覆盖, upper_layer_wins

### docstring

```text
一句话总述：按图例条给出的层序把若干同尺寸面板作为不透明图层叠放，冲突处由
更靠上的图层覆盖。

输入结构：
- 分隔色背景中放着若干同尺寸矩形面板，每个面板由统一底色加若干彩色笔画构成，
  并在固定角落带有一个不参与图案的标签像素，各面板标签颜色互不相同。
- 网格某处另有一条与面板无关的窄色条，由各标签颜色排成一行或一列，不含底色。

规则：
- 色条按从左到右（竖条则从上到下）的顺序给出图层自底向顶的叠放次序，
  标签色相同的面板即对应该次序中的位置。
- 新建一块同尺寸底色面板，按次序把各面板的笔画依次盖上：后盖的笔画覆盖
  先盖的笔画。
- 标签像素与色条本身不出现在输出中。

关键洞察：
- 面板叠加不是透明取并集：孤立的色条并非装饰，而是唯一给出遮挡次序的图例，
  冲突像素的归属完全由它决定。
```

## 4. 镜像腔室换色

- tags:
  - operation:洪泛填充, flood_fill
  - object:墙壁, wall
  - object:封闭腔室, enclosed_chamber
  - object:标记像素, marker_pixel
  - relation:中心对称配对, central_symmetry_pairing
  - condition:伙伴腔室供色, partner_supplies_color

### docstring

```text
一句话总述：迷宫墙壁把背景分成腔室，每个腔室整体染成与它中心对称的伙伴腔室内
标记的颜色。

输入结构：
- 同一种墙色在背景上围出若干封闭腔室，墙壁布局关于网格中心 180 度旋转对称。
- 每个腔室内恰有一个单像素彩色标记，标记位置不必对称，颜色可各不相同。

规则：
- 以网格中心 180 度旋转把腔室两两配对，位于中心的腔室与自身配对。
- 将每个腔室（含标记原位置）整体洪泛染成其伙伴腔室中标记的颜色。
- 墙壁保持不变。

关键洞察：
- 标记染的不是自己所在的腔室：颜色沿墙壁布局的旋转对称被送往对面的伙伴腔室，
  自配对的中心腔室恰好维持原色，掩盖了这一交换。
```

## 5. 螺旋续拍

- tags:
  - operation:外推, extrapolate
  - operation:旋转, rotate
  - object:基准像素, pivot_pixel
  - object:图案副本, sprite_copy
  - relation:方向旋转距离递增, rotating_growing_orbit
  - condition:对称补全为诱饵, symmetry_decoy

### docstring

```text
一句话总述：同一非对称图案绕基准像素每拍方向旋转 90 度、距离等差递增地向外
盘旋，输出补上序列的下一拍。

输入结构：
- 网格上有一个颜色唯一的基准像素和同一图案的三份副本，图案自身无旋转对称。
- 三份副本到基准像素的方向依次相差 90 度，到基准像素的距离依次增加同一个
  固定步长，副本本体也随方向每拍旋转 90 度。
- 副本先后次序由距离从小到大唯一确定。

规则：
- 由三份副本读出旋转方向（顺或逆时针）与距离步长。
- 对最后一份副本再施加一次同样的变换：方向再转 90 度，距离再增加一个步长，
  本体再旋转 90 度，把第四份副本画入网格。
- 原有副本与基准像素保持不变。

关键洞察：
- 三份副本不是残缺的四重旋转对称图形：按补全对称去放置只会得到错误的半径——
  它们是一段螺旋运动的连续帧，方向与距离必须同时外推。
```

## 6. 负形配钥

- tags:
  - operation:填充, fill
  - operation:擦除, erase
  - object:大连通块, big_blob
  - object:封闭孔洞, enclosed_hole
  - object:散落小件, scattered_piece
  - relation:负形互补配对, complement_pairing
  - condition:拼合成实心矩形, union_forms_rectangle

### docstring

```text
一句话总述：散件与大块内部孔洞的配对依据不是形状全等，而是二者拼合恰成实心
矩形的互补关系，孔洞按配对散件的颜色填实。

输入结构：
- 网格上有一个单色大连通块，内部封闭着若干背景色孔洞，孔洞形状互不相同且
  均不是矩形。
- 大块之外散落着与孔洞数量相同的彩色小件，任何小件都不与任何孔洞形状全等；
  部分小件像素数相同，仅靠计数无法配对。
- 每个小件经平移和旋转后，与且仅与一个孔洞可以无重叠地拼合成一个实心矩形。

规则：
- 对每个孔洞与每个小件尝试拼合：小件与孔洞形状放入同一包围盒，恰好互补铺满
  整个矩形者配对成功，配对是一一对应。
- 将每个孔洞的全部像素染成配对小件的颜色。
- 删除大块之外的所有小件，大块本身保持不变。

关键洞察：
- 直觉的"找同形钥匙"必然失败——没有任何小件与孔洞同形；真正的配对关系是
  负形互补：小件是孔洞相对矩形的余料，颜色沿这一隐藏关系归位。
```
