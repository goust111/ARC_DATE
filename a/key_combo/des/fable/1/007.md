## 1. 对称补墙定封闭

- tags:
  - 操作:对称补全
  - 操作:洪泛填充
  - 对象:围墙线段
  - 对象:缺口
  - 关系:镜像轨道
  - 条件:缺口分类决定拓扑

### docstring

```text
先按镜像对称区分墙上的破损与真门，修复破损后再判定封闭并填充房间。

输入结构
- 黑色背景网格上分布红色一格粗的围墙线段，整幅红墙图案关于竖直中轴镜像对称。
- 墙上存在若干个被抹成背景的缺口：有的缺口镜像位置是完好的红墙，有的缺口与其镜像位置同时缺失。
- 蓝色不在输入中出现。

规则
- 找到红墙图案的竖直对称轴，逐个检查缺口：镜像位置是红墙的缺口视为破损，恢复为红墙；镜像位置同为缺口的视为成对的真门，保持敞开。
- 在修复后的墙体上，以4连通方式从网格边界洪泛背景；无法到达边界的背景格全部涂蓝。
- 输出保留修复后的红墙、蓝色填充、敞开的真门与外部黑色背景。

关键洞察
- 缺口不是同一种东西：单侧缺失是损伤、成对缺失是门；封闭性必须在修复之后重新判定——一扇真门能让看似完整的房间漏气，一处破损修好后房间反而变成密闭。
```

## 2. 三点张成的印章点阵

- tags:
  - 操作:外推
  - 操作:印章覆盖
  - 对象:精灵体
  - 对象:锚点像素
  - 对象:生成元标记
  - 关系:二维点阵生成
  - 条件:整体在界内才印

### docstring

```text
把两枚灰点读作平移生成元，将带锚点的精灵体印满它们张成的整个二维点阵。

输入结构
- 背景色占主导，网格上有一个连通的多色精灵体，精灵体内部恰有一枚黄色锚点像素。
- 另有两枚孤立的灰色单像素点，与锚点不共线。
- 网格中除上述内容外没有其他前景。

规则
- 以精灵体的黄色锚点为原点，原点指向两枚灰点的位移分别为生成向量 v1、v2。
- 点阵结点为一切整数组合 i·v1 + j·v2 对应的位置（i、j 可取负数、零、正数，也可同时非零）。
- 对每个结点：若把精灵体的锚点对齐到该结点后整个精灵体都落在网格内，就在该处印一份精灵体（含黄色锚点）。
- 抹去两枚灰点；原精灵体即 i=j=0 的结点，保持不动。

关键洞察
- 两枚灰点不是两个粘贴目标，而是生成元：真正的目标集合包含从未被标出的结点——反方向的 -v1、-v2 以及组合出的 v1+v2 等，都要盖章。
```

## 3. 交叉格的距离优先权

- tags:
  - 操作:射线延伸
  - 操作:重涂色
  - 对象:横条段
  - 对象:竖条段
  - 关系:交叉
  - 关系:距离势场
  - 条件:近源者胜
  - 条件:等距标新色

### docstring

```text
把每条彩色短条补成整行或整列，每个交叉格由离自己原始短条更近的那条线占据，等距交叉涂黄。

输入结构
- 单一背景色画布上有若干条一格粗、颜色互不相同的短条段，有横有竖。
- 横条各占不同的行，竖条各占不同的列，延伸后横竖之间会产生交叉。
- 黄色不在输入中出现。

规则
- 每条横条用自身颜色补满所在整行，每条竖条用自身颜色补满所在整列。
- 对每个横竖交叉格：沿行计算它到该行原始横条段最近端的格数距离（位于原始段内计0），沿列同理计算到原始竖条段的距离。
- 距离严格小的一方用自己的颜色占据交叉格；两距离相等时交叉格涂黄。
- 原始短条段的像素保持原色。

关键洞察
- 延伸出的线不是均质的：每个格子都带着"离源头多远"的隐含势场，交叉处的覆盖关系由这个势场逐点裁决，而不是由颜色、方向或先后次序统一决定。
```

## 4. 缝合边界的传送门射线

- tags:
  - 操作:路径绘制
  - 操作:重涂色
  - 对象:边界标记
  - 对象:成对传送门
  - 关系:同色配对
  - 关系:拓扑缝合
  - 条件:非门边界格终止

### docstring

```text
从红色起点射出的轨迹在边界的同色成对门之间瞬移续行，画出穿越缝合拓扑的完整红色轨迹。

输入结构
- 单一背景色网格，边界上有一枚红色起点标记。
- 另有若干对传送门标记：每种颜色恰好两枚、都位于边界上，颜色互不相同且不为红色。
- 所有标记都不在网格角上。

规则
- 射线自红色起点向网格内部垂直射入，沿直线前进，途经的背景格逐格染红。
- 当射线到达某个边界格：若该格是传送门，则从同色的另一枚传送门格续行，方向为垂直于新边界指向网格内部，传送门格本身保持原色。
- 若到达的边界格不是传送门，则把该格染红并停止。
- 轨迹可以与先前已染红的格相交并继续穿过。

关键洞察
- 边界上的同色成对标记把网格的边"缝"在了一起：射线在门处既不反弹也不绕行，而是从配对的另一处继续；整条轨迹在被缝合的拓扑里其实是一条直线，门的配对关系（而非位置远近）决定它下一段出现在哪里。
```

## 5. 密闭腔换血，漏气区蒸发

- tags:
  - 操作:洪泛填充
  - 操作:双色互换
  - 操作:擦除
  - 对象:封闭腔
  - 对象:墙壁线段
  - 对象:干扰像素
  - 关系:拓扑作用域
  - 条件:可达即蒸发
  - 条件:各腔独立

### docstring

```text
以红墙的真实拓扑划定作用域：每个密闭腔内的两种颜色互换，能通到边界的彩色像素全部清除。

输入结构
- 黑色背景上分布红色一格粗的墙体，围出若干腔室；有的轮廓完整，有的留有缺口，腔室之间还可以嵌套。
- 网格中散布若干非红非黑的彩色像素：每个密闭腔内部恰好出现两种颜色（各至少一枚），墙外与漏气轮廓内也散布着颜色相同的干扰像素。
- 红色与黑色之外的颜色不构成墙。

规则
- 以红墙为障碍、从网格边界做4连通洪泛，标出所有能到达边界的格子。
- 不可达的连通腔即密闭腔：腔内两种颜色的像素同时互换颜色；各腔独立处理，颜色对可各不相同。
- 所有可达格子上的彩色像素（包括漏气轮廓里的和墙外散落的）一律改为黑色背景。
- 红墙保持不变。

关键洞察
- 换色不是全局操作，它的作用域由拓扑而非轮廓外观决定：有缺口的"房间"其实是外部，里面的颜色会蒸发；嵌套的密闭腔各自独立换血，同一种颜色在不同腔里的命运可以完全不同。
```

## 6. 对称缺陷即换色图例

- tags:
  - 操作:重涂色
  - 对象:钥匙图案
  - 对象:缺陷格
  - 对象:多色目标对象
  - 关系:镜像配对
  - 关系:缺陷编码换色对
  - 条件:同对双向互换
  - 条件:缺陷保留不修复

### docstring

```text
钥匙图案里破坏镜像对称的格子成对读作换色指令，把这些颜色对同时应用到独立的目标对象上。

输入结构
- 背景分隔出两个前景部分：一幅较大的"钥匙"图案与一个独立的多色目标对象。
- 钥匙图案关于自身包围盒的竖直中轴近似镜像对称：绝大多数格子与镜像格同色，仅有少数缺陷格与镜像格颜色不同。
- 缺陷格与其镜像格给出的无序颜色对彼此一致、互不冲突；目标对象由这些配对颜色及可能的一种不参与配对的底色组成。

规则
- 找到钥匙图案的竖直对称轴，收集所有与镜像格颜色不一致的位置，把每处的两种颜色记为一条双向换色对。
- 在目标对象上同时执行全部换色对：每条对中的两色互换，不参与任何配对的颜色保持不变。
- 钥匙图案（包括缺陷）原样保留，只有目标对象被重新着色。

关键洞察
- 图例从未被单独画出——它藏在对称的"错误"里：破坏对称的地方不是需要修复的损伤，而是一条条换色指令；照惯例去补全对称反而答错。
```
