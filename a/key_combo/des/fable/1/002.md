## 1. 边界坐标织框

- tags:
  - operation:绘制, draw
  - operation:排序覆盖, ordered_overpaint
  - operation:重涂色, recolor
  - object:边界标记, border_marker
  - object:隐形矩形框, implied_hollow_frame
  - object:内部散点, interior_pixel
  - relation:同色行列绑定, same_color_row_col_binding
  - condition:面积小者优先, smaller_area_wins
  - condition:最小包含框捕获, smallest_enclosing_capture

### docstring

```text
将边界上的同色标记按行列绑定成从未画出的矩形框，按"小框在上"的次序描画，并让内部散点被最小包含框捕获重涂。

输入结构
- 背景为黑色。每种框色恰好出现四次且全部位于边界上（不含四个角格）：
  左边界两格标记两行，上边界两格标记两列。
- 网格内部另散布若干杂色单像素散点，散点颜色与所有框色不同。

规则
- 对每种框色，用它在左边界标记的两行和在上边界标记的两列确定一个矩形。
- 在网格内画出该颜色的单像素厚空心矩形框；多个框重叠时按面积从大到小
  依次绘制，后画覆盖先画，重叠处显露面积较小的框。
- 对每个内部散点：找出内部包含它的所有矩形中面积最小的那一个，把该散点
  重涂为这个矩形的框色；不被任何矩形包含的散点清除。
- 边界上的原始标记保持不变。

关键洞察
- 矩形从未在输入中出现，颜色把两条行坐标与两条列坐标捆绑成一个隐形框；
  "面积小者优先"同时支配两件事——框线重叠处的显隐与散点的归属，散点
  其实是对隐形框嵌套关系的探针。
```

## 2. 折叠镜矩形

- tags:
  - operation:镜像, reflect
  - operation:补全, complete
  - object:角点矩形, corner_implied_rectangle
  - object:散点像素, scattered_pixel
  - relation:分区反射, region_typed_reflection
  - condition:带区轴对称角区点对称, band_axis_corner_point

### docstring

```text
识别四个同色散点构成的隐形矩形，画出边框，并把框外散点按分区镜面规则折叠进框内。

输入结构
- 黑色背景上散布若干颜色的单像素散点。
- 恰有一种颜色出现四次，且这四个像素恰好落在一个轴对齐矩形的四个角上；
  其余颜色的散点数量不一（有的也出现四次但不构成矩形，是干扰组），
  位置在该矩形内外都有。

规则
- 用该颜色补全整条矩形边框。
- 位于矩形行跨度内、框外左右两侧的散点，以其面对的竖直框边为镜轴反射
  进框内；位于列跨度内、框外上下两侧的散点，以水平框边为镜轴反射进框内。
- 位于四个对角区域的散点，以离它最近的矩形角点为中心做点对称，落入框内。
- 反射产生的像素保留原色画在框内；框外散点全部清除，框内原有散点保持不动。

关键洞察
- 先要在散点中认出哪四个同色点构成矩形，其余同色组都是干扰；矩形边框是
  折痕，侧带走轴对称、角区走点对称，整个外部平面像纸一样被折进框里。
```

## 3. 对角弹球

- tags:
  - operation:射线延伸, ray_extend
  - operation:镜像, reflect
  - object:方向精灵体, directional_sprite
  - object:标记像素, marker_pixel
  - relation:质心偏移定向, centroid_bias_dir
  - condition:边界反弹, border_bounce
  - condition:撞体终止, stop_at_body

### docstring

```text
从每个方向精灵体发出对角射线，射线在网格边缘反弹前行，直到撞上任一精灵体像素，沿途以标记色涂画轨迹。

输入结构
- 背景占多数。网格上散布若干个同一体色、形状相同（含旋转翻转变体）的
  精灵体，每个精灵体内嵌一个独有颜色的标记像素。
- 每个精灵体的体像素明显偏在标记像素的一侧，指向某个对角方向的反方向。

规则
- 每个标记像素沿体像素质心偏移的反方向（四个对角方向之一）发射射线，
  逐格斜向前进，把经过的背景格涂成标记色。
- 射线撞到网格边缘时像光线一样反弹：撞上边或下边时竖直分量反向，撞左边
  或右边时水平分量反向，恰好射入角格时原路折返。
- 射线一旦踏入任何精灵体像素（体色或标记色，包括自己的）所在格即停止，
  该格不改色。
- 不同射线的轨迹互不重叠（谜题设计保证）。

关键洞察
- 精灵体的不对称是隐藏的方向盘；网格边缘不是终点而是镜子，整条轨迹是
  同一条对角线被反复折叠的结果，真正的终点由实体精灵体决定。
```

## 4. 隐形晶格

- tags:
  - operation:周期延伸, periodic_extend
  - operation:填充, fill
  - operation:补全, complete
  - object:刻度像素, tick_pixel
  - object:晶格单元, lattice_cell
  - object:种子像素, seed_pixel
  - relation:粗空间配对, coarse_space_pairing
  - condition:同色种子张成单元块, same_color_spans_cells

### docstring

```text
由每条边上仅有的两个刻度推断出一张不可见的周期晶格，再在晶格单元的粗空间里为同色种子对填充它们张成的整块单元矩形。

输入结构
- 背景占多数。上边界恰有两个同色刻度像素，左边界恰有另一颜色的两个
  刻度像素。
- 网格内部散布若干种子像素；每种种子颜色出现一次或两次，都不落在刻度
  所示的行列上。

规则
- 以上边界两刻度的列距为周期，向左右两侧周期延拓，得到全部竖直晶格线
  所在的列；左边界两刻度同理给出全部水平晶格线所在的行。晶格线位置在
  输出中保持背景色，不画出。
- 晶格把内部分割成矩形单元。出现两次的种子颜色：以两个种子所在单元为
  对角，把这两个单元张成的单元块里的每个单元整体填充该色。
- 只出现一次的种子颜色：只填充它所在的那个单元。
- 输出同时把两条边界上的刻度按各自周期补全到整条边。

关键洞察
- 每边的两个刻度只是无穷周期序列的最初两项，晶格必须同时向两个方向
  延拓；配对与连线不发生在像素空间，而发生在晶格单元构成的粗网格上——
  填充块的边缘会自动对齐到从未画出的晶格线。
```

## 5. 转盘信使

- tags:
  - operation:旋转, rotate
  - operation:镜像, mirror
  - object:转盘, dial
  - object:精灵体, sprite
  - relation:颜色信道配对, color_channel_pairing
  - condition:边针旋转角针翻转, edge_rotate_corner_flip

### docstring

```text
用刻针颜色把每个转盘与同色精灵体配对，按刻针位置指示的朝向就地旋转或翻转该精灵体，然后抹去所有转盘。

输入结构
- 黑色背景上散布若干形状不对称、边界框为正方形的单色精灵体，主色各不相同。
- 另有等量的转盘：三乘三的灰色空心方框，框上恰有一格换成了彩色刻针；
  刻针位置只会在四条边的中点或四个角上，刻针颜色与某个精灵体的主色相同。

规则
- 每个转盘通过刻针颜色找到它控制的精灵体。
- 刻针在边中点时，把精灵体在自己的边界框内旋转，使它原先朝上的一侧转到
  刻针所指的方向（上针即不动）。
- 刻针在角上时，把精灵体沿"该角与其对角连线"所在的对角线翻转。
- 所有精灵体就地替换为变换后的图形，所有转盘从输出中清除。

关键洞察
- 颜色是传递参数的信道，转盘的几何位置是参数本身：边针说"顶部转到这边"，
  角针说"沿这条对角线翻面"。只看含边针的示例会误以为规则只有旋转，
  角针示例才暴露翻转分支。
```

## 6. 自寻址包裹

- tags:
  - operation:搬移, relocate
  - operation:重涂色, recolor
  - object:十字分隔线, cross_divider
  - object:象限精灵体, quadrant_sprite
  - relation:质心偏移寻址, centroid_bias_addressing
  - condition:形随身走色留原地, shape_moves_color_stays

### docstring

```text
十字分隔线把网格分成四个象限，每个精灵体按自身形状写明的对角地址搬去目的象限，但抵达后换上目的象限原住民的颜色。

输入结构
- 一条整行和一条整列的分隔线把网格切成四个象限，每个象限内有一个单色
  精灵体，四个精灵体颜色互不相同、形状均不对称。
- 每个精灵体的像素质心相对其边界框中心偏向某个对角方向。

规则
- 读取每个精灵体质心偏移所指的对角方向，该方向对应的象限就是它的目的
  象限；四个精灵体的目的地恰好构成一个排列（谜题设计保证）。
- 把每个精灵体搬进目的象限，保持它相对象限左上角的偏移不变。
- 搬入后的精灵体改用目的象限中原精灵体的颜色；分隔线保持原样。

关键洞察
- 不存在统一的全局变换：有的示例排列恰好貌似整体旋转，其余示例会拆穿它，
  地址必须逐个从形状里读出。形状随包裹迁移，颜色属于地皮——两种属性在
  搬运中解绑。
```
