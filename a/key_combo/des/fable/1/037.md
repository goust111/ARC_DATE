## 1. 尺度家族的空档

- 参考题目题号: `447fd412`, `cd3c21df`, `b2bc3ffd`
- tags:
  - operation:像素放大, pixel_scaling
  - operation:计数, counting
  - object:精灵体, sprite
  - relation:缩放等价分组, scale_equivalence_grouping
  - condition:尺度序列内部空档, internal_gap_in_scale_run
  - condition:忽略干扰项, ignore_distractors

### docstring

```text
在按"形状模缩放"分组的精灵家族中，找出尺度序列存在内部空档的家族，输出其基础形状按缺失尺度放大后的渲染。

输入结构
- 黑色背景上散布多个互相分离的单色 4 连通精灵。
- 同色精灵互为同一基础形状的整数倍像素放大副本，构成一个"尺度家族"。
- 每个家族的尺度取值本应构成一段连续整数区间；恰有一个家族在区间内部缺失一个尺度档，其余家族的尺度序列完整。
- 不同家族的尺度区间起止各不相同，家族成员数不能用于定位缺陷家族。

规则
- 将每个精灵归一化到尺度 1，按"颜色 + 归一化形状"分组。
- 对每组收集其出现过的尺度集合，找到内部缺一档的那一组及其缺失尺度 k。
- 输出一个恰好容纳该基础形状按 k 倍放大后的最小网格：黑底上以该家族颜色绘制放大形状。

关键洞察
- 分组依据既不是位置也不是绝对大小，而是缩放等价关系；答案由家族尺度序列的内部空档给出，
  成员数量、最大尺寸与孤立程度都是诱饵。
```

## 2. 按长度定序的透明连线

- 参考题目题号: `070dd51e`, `a2fd1cf0`, `bbb1b8b6`
- tags:
  - operation:连线, line_drawing
  - operation:透明叠加, transparent_overlay
  - object:标记像素, marker_pixel
  - relation:同色配对, same_color_pairing
  - relation:曼哈顿路径, manhattan_path
  - condition:长度定绘制次序, length_determines_order
  - condition:先画者占交叉点, earlier_keeps_crossing

### docstring

```text
将每个同色像素对连线，其中恰有一对需走先横后纵的折线，所有连线按路径长度从短到长依次透明叠画。

输入结构
- 背景为黑色，每种前景色恰好出现两个像素。
- 除一对之外，其余同色对都恰好共行或恰好共列。
- 恰有一对既不共行也不共列。
- 所有连线路径的格数互不相等。

规则
- 共行或共列的同色对之间画该颜色的直线段（含两端点）。
- 异行异列的那一对画 L 形折线：从更靠上的端点先沿其所在行横向走到另一端点所在列，再纵向走到另一端点（含拐点）。
- 全部路径按格数从少到多依次绘制；后画的路径不覆盖任何已着色的格，交叉处保留先画路径的颜色。

关键洞察
- 交叉处的颜色层级并非由横竖方向或颜色编号决定，而是由路径长度排序决定；
  L 形折线以其曼哈顿全长参与排序。仅看单个示例容易误读为"竖线压横线"，该读法在其余示例中失效。
```

## 3. 缺角滑移与旋转对齐

- 参考题目题号: `da6e95e5`, `a61ba2ce`, `dc2e9a9d`, `b2bc3ffd`
- tags:
  - operation:旋转, rotate
  - operation:平移, translate
  - object:角标记, corner_marker
  - object:凹口, notch
  - relation:包围关系, enclosure
  - condition:缺角定方向与终点, missing_corner_sets_dir_and_stop
  - condition:凹口定旋转量, notch_sets_rotation
  - condition:同色簇锚定不动, same_color_anchored

### docstring

```text
将每个异色簇的中心对象先旋转使凹口对准缺角方向，再沿对角线滑到缺角停靠；同色簇原样锚定不动。

输入结构
- 背景占多数；网格含若干互不干扰的簇。
- 每簇由一个单色 4 连通中心对象与三枚同色单像素角标组成；三枚角标占据一个矩形的三个角，第四个角空缺。
- 角标矩形与中心对象的包围盒同中心且严格更大。
- 中心对象带有一个单格方向性凹口，使其四个旋转方位互不相同。

规则
- 对每簇确定空缺的角及其相对簇中心的对角方向。
- 若中心对象颜色与角标颜色不同：先将对象绕自身中心旋转 0、90、180 或 270 度，使凹口指向缺角方向；
  再沿该对角方向平移，使旋转后包围盒的同名角恰好落在缺角位置；三枚角标保持不动。
- 若中心对象颜色与角标颜色相同，该簇原样保留。

关键洞察
- 缺角同时编码运动方向与停靠终点，对象自身凹口的方位决定旋转量，二者缺一不可；
  颜色一致在这里不是选取条件而是禁止移动的锚——正好反用"标记色与对象同色"的常见选取逻辑。
```

## 4. 隐形十字的交点枢轴

- 参考题目题号: `23581191`, `90347967`, `dc2e9a9d`
- tags:
  - operation:旋转, rotate
  - object:孤立像素, isolated_pixel
  - object:枢轴像素, pivot_pixel
  - object:前景掩码, foreground_mask
  - relation:行列交叉, row_col_intersection
  - relation:点对称, point_symmetry
  - condition:枢轴从未画出, pivot_never_drawn
  - condition:出界可行性裁决, feasibility_selects_pivot

### docstring

```text
以橙青两枚种子隐含十字的两个异色交点为候选枢轴，对精灵做 180 度点反射，取反射像不出界的那个枢轴。

输入结构
- 黑色背景上有恰好一个橙色像素与一个青色像素，二者异行异列。
- 另有一个由其他颜色组成的 4 连通精灵，与两枚种子分离。

规则
- 设想橙色与青色像素各自的整行整列十字（不画出）；两条异色行列相交得到两个候选枢轴：
  (橙色所在行, 青色所在列) 与 (青色所在行, 橙色所在列)。
- 分别计算精灵绕两个候选枢轴的 180 度点反射像，恰有一个候选使反射像完整落在画布内。
- 清除精灵原位置，在该枢轴的反射位置按原色重画精灵；橙青像素保持不变。

关键洞察
- 参与规则的枢轴从未被画出，它只是两枚种子隐含行列的交点；
  两个候选之间不靠距离或方位挑选，而由"反射像是否越界"这一可行性检验自动裁决。
```

## 5. 滚动至标记的缺陷行

- 参考题目题号: `6d1d5c90`, `cd3c21df`, `10fcaaa3`
- tags:
  - operation:循环位移, cyclic_roll
  - operation:异常检测, anomaly_detection
  - object:控制列, control_column
  - object:标记像素, marker_pixel
  - object:周期条纹, periodic_stripes
  - relation:对齐, alignment
  - condition:标记是目的地非位移量, marker_is_destination_not_shift

### docstring

```text
删除控制列后，将周期条纹图像按行循环滚动，使唯一缺陷格所在的行对齐到红色标记的行号。

输入结构
- 最左一列为控制列：全粉色，仅一格为红色标记。
- 其余部分是沿竖直方向周期重复的彩色条纹图案，其中恰有一格颜色不符合周期规律（缺陷格）。

规则
- 删除左侧控制列。
- 在剩余图像中依据周期规律定位缺陷格所在的行 d，读出红色标记所在的行 r。
- 将剩余图像整体按行循环下移 (r − d) mod 高度，使缺陷行落在第 r 行；条纹相位随之一起滚动。

关键洞察
- 标记行号不是位移量而是目的地：把它当作固定下移量的读法只在缺陷恰在首行的示例中侥幸成立；
  真正的位移量由标记行与缺陷行之差给出，而缺陷本身必须先靠周期规律的破缺才能找到。
```

## 6. 多数决摘要、平票裁决与放大盖章

- 参考题目题号: `af24b4cc`, `447fd412`, `fcb5c309`
- tags:
  - operation:压缩, compress
  - operation:多数决, majority_vote
  - operation:像素放大, pixel_scaling
  - object:分隔行列, separator_row_col
  - object:矩形框架, rect_frame
  - relation:尺寸比定缩放, size_ratio_sets_scale
  - condition:平票块取框色, tie_block_takes_frame_color

### docstring

```text
把噪声点阵按块多数决压缩成摘要图，平票块的颜色由矩形框裁决，再按尺寸比放大填入框的内部并输出。

输入结构
- 网格一处为由背景分隔线划分的 m×n 色块点阵：每块同尺寸、内部含少量杂色。
- 绝大多数块有唯一多数色；恰有一块内部两种颜色数量持平（平票块）。
- 另一处为一个单色空心矩形框，内部全为背景，内部尺寸恰为 (m·s)×(n·s)，s 为正整数。

规则
- 对点阵每块取唯一多数色，得到 m×n 摘要图；平票块的颜色取矩形框本身的颜色。
- 由框内部尺寸与点阵规模之比得到缩放因子 s。
- 将摘要图每格放大为 s×s 色块填入框内部；输出为框内部区域的裁剪。

关键洞察
- 框不是待裁剪的内容而是身兼三职的供体：其内部尺寸反推缩放因子、其内部范围即输出画布、
  其边框颜色补上多数决无法裁决的平票块；块内杂色被多数决整体丢弃，不进入输出。
```

## 7. 色序旋转对称的残件归位

- 参考题目题号: `1b60fb0c`, `a61ba2ce`, `fcb5c309`
- tags:
  - operation:对称补全, symmetry_completion
  - operation:旋转, rotate
  - operation:重涂色, recolor
  - object:精灵体, sprite
  - object:游离碎片, detached_fragment
  - relation:旋转对称, rotational_symmetry
  - relation:颜色循环序, color_cycle_order
  - condition:碎片色是干扰, fragment_color_is_distractor
  - condition:缺口色由色序推断, hole_color_from_cycle

### docstring

```text
用画面上错位的游离碎片补全大图形缺失的旋转扇区，安装时旋转到位，并按颜色循环序推断出的应有颜色重涂。

输入结构
- 背景上有一个大型图形：四个扇区绕中心在形状上四重旋转对称，但颜色互不相同，
  且沿旋转方向按固定的循环顺序排列。
- 其中一个扇区整体缺失为背景。
- 网格他处有一个游离 4 连通碎片：其形状与缺失扇区在唯一某个四分之一转整数倍的旋转下完全吻合，
  但碎片自身的颜色不是缺口应有的颜色。

规则
- 由其余三个扇区确定旋转中心、缺失扇区的应有形状以及颜色循环顺序。
- 将碎片旋转到吻合方向放入缺口，并改涂为按色序推断出的缺口应有颜色。
- 清除碎片原位置；其余部分不变。

关键洞察
- 补全材料不是凭空生成的：缺失部分以旋转错位的残件形式已存在于画面上；
  吻合判定只看形状，碎片颜色是干扰信息，缺口的真正颜色必须由三个在位扇区的循环色序推断。
```
