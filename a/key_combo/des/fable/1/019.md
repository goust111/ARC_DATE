## 1. 交叉证据下的图层复原渲染

- tags:
  - operation:层序推断, infer_layer_order
  - operation:填充渲染, solid_render
  - object:空心矩形, hollow_rect
  - object:交叠区域, overlap_region
  - relation:传递闭包, transitive_closure
  - condition:交叉可见色为上层, visible_at_crossing_is_top

### docstring

```text
由空心矩形框在交叉点处露出的颜色推断全部堆叠层序，再把所有矩形按该层序渲染成实心遮挡图。

输入结构
- 黑色背景上有若干个颜色互不相同的一格粗空心矩形框。
- 框的边可以相互交叉，每个交叉格只显示层序较高的那个框的颜色。
- 结构保证：内部区域相互重叠的任意两框，其轮廓必有交叉格；全部交叉
  证据经传递补全后，足以唯一确定所有相互重叠框之间的相对层序。

规则
- 在每个交叉格读出"可见色压住被遮色"的约束，并用传递性推出所有
  重叠框对的上下关系。
- 输出与输入同尺寸：把每个框按其外接矩形整体填成本色实心矩形，按
  从最底层到最顶层的顺序依次绘制，后画者覆盖先画者。
- 与任何框都不重叠的框直接实心绘制，绘制次序对结果无影响。

关键洞察
- 输入只有细轮廓和交叉处几粒遮挡痕迹，却编码了一张完整的图层表；
  要求的不是找出最顶层的那一个框，而是重建整个实心遮挡场景，其中
  某些框对的先后只能借第三个框传递推出。
```

## 2. 同列钥匙的周期修补

- tags:
  - operation:补全, completion
  - operation:条件修补, conditional_repair
  - object:周期瓦片, periodic_tile
  - object:补丁像素, patch_pixel
  - relation:同列配对, same_column_pairing
  - condition:颜色相符才修复, repair_on_color_match

### docstring

```text
周期图案上的缺口只有在同列上方悬着颜色相符的补丁像素时才被修复，其余缺口保持黑色。

输入结构
- 网格下部为图案区：由两种颜色按唯一的最小矩形瓦片周期平铺，若干
  格被黑色缺口遮住；忽略缺口后可见部分与该瓦片完全一致。
- 图案区上方为一条黑色空带，带内散布单像素补丁，每列至多一个，
  补丁颜色取自两种图案色。

规则
- 先由可见像素推断周期瓦片，从而得知每个缺口"应有"的颜色。
- 对每个补丁：在其所在列自上而下找第一个应有颜色与补丁相同的缺口，
  把该缺口涂成此颜色；同列没有匹配缺口的补丁直接消失。
- 未获修补的缺口保持黑色；输出的上方空带全为黑色。

关键洞察
- 这不是普通的周期补全：瓦片只决定每个缺口"想要"的颜色，能否真被
  修好取决于同列是否恰有同色补丁，且一个补丁只修最上面那一个匹配
  缺口——看完第一个示例就把所有缺口补齐正是布好的陷阱。
```

## 3. 传送门弹道

- tags:
  - operation:射线延伸, ray_cast
  - operation:重涂色, recolor
  - object:边界标记对, border_marker_pair
  - object:箭头, arrow
  - object:实心色块, solid_block
  - relation:同色配对传送, teleport_by_color_pair
  - condition:出射沿出口内法线, exit_along_inward_normal
  - condition:碰撞停止, collision_stop

### docstring

```text
从箭头射出的光线撞上边界传送门就从同色的另一扇门钻出、沿新门所在边的内法线继续飞行，画出全程轨迹并把最终命中的色块重涂。

输入结构
- 黑色背景。网格边界格上贴着若干对传送门：同色两两配对，各对颜色
  互不相同，且都不在角格上。
- 场内有一个两像素箭头（灰色尾格加天蓝色头格，方向为尾指头，水平
  或竖直），以及若干实心单色块。
- 结构保证：光线路径有限、不与自身相交、不会沿边界滑行，命中结果唯一。

规则
- 光线从箭头头部前方出发，沿箭头方向直行，把途经的黑格涂成天蓝色。
- 下一格是传送门格时：改由同色的另一扇门出发，沿该门所在边界的
  内法线方向继续前进（门格颜色保留）。
- 下一格是实心色块时：光线终止，该块整体重涂为天蓝色；下一格越出
  网格时：光线终止。

关键洞察
- 边界上成对的同色像素不是要连线的端点，而是会改写行进方向的门：
  出射方向只由出口门贴在哪条边决定，与入射方向无关，因此答案必须
  一段一段模拟，任何"把门对直接连起来"的读法都会在拐弯处露馅。
```

## 4. 缺口私有重力与漏斗外泄

- tags:
  - operation:定向滑动, directional_slide
  - object:空心箱, hollow_box
  - object:壁上缺口, wall_gap
  - object:可移动像素, movable_pixel
  - relation:缺口定义方向, gap_defines_direction
  - relation:跨箱接力, cross_box_relay
  - condition:对准缺口才逃逸, escape_only_if_aligned
  - condition:碰撞停止, collision_stop

### docstring

```text
每个箱子的沙粒朝自家箱壁缺口所在的一侧滑动，正对缺口的那粒会穿过缺口漏到箱外继续滑行，甚至钻进别的箱子。

输入结构
- 黑色背景；若干一格粗空心矩形箱，每个箱壁恰好缺一格（不在角上）。
- 每个箱内散布若干黄色沙粒；箱外还可能有其他箱、箱间空地和网格边界。
- 结构保证：所有滑动与外泄互不冲突，最终结果与结算顺序无关。

规则
- 每个箱内的沙粒一律沿"缺口所在边"的方向滑动（缺口开在右壁就向右），
  先到者先停，依次紧贴箱壁排队。
- 与缺口同行或同列对齐的沙粒不会被箱壁拦住：它穿过缺口继续直行，
  直到撞上箱壁、已静止的沙粒或网格边缘才停下；若途中恰好从另一个
  箱的缺口钻入，就换成在那个箱里继续滑到撞壁。
- 箱壁与缺口保持原样，输出中所有沙粒处于最终静止位置。

关键洞察
- 场上没有统一的重力：每个箱的"下"由自己缺口的方位私人定义；缺口
  同时是方向指针和漏斗，只有恰好对准它的沙粒才能逃逸，并把运动接力
  到箱外乃至下一个箱子里。
```

## 5. 破环筛除与嵌套奇偶反色

- tags:
  - operation:反转, invert
  - operation:闭合性筛查, closure_check
  - object:闭合环, closed_ring
  - object:破口环, broken_ring
  - relation:嵌套深度, nesting_depth
  - condition:奇偶决定反色, parity_decides_invert
  - condition:破口不构成包围, gap_voids_enclosure

### docstring

```text
只有真正闭合的灰环才算包围层，被奇数层闭合环包住的区域把红点与黑底整体反色，偶数层区域原样保留。

输入结构
- 黑色背景上有若干条一格粗的灰色环，环与环可以嵌套，深度可达三层。
- 其中一部分环带有一个一格宽的破口（不在角上），乍看与闭合环几乎无异。
- 环内外散布红色单像素。

规则
- 带破口的环不构成包围，仅作为普通灰色像素保留。
- 对每个非灰格，统计包住它的"闭合"灰环层数（不穿过闭合环便无法
  到达网格边界的层数）。
- 层数为奇数的格反色：红变黑、黑变红；层数为偶数（含零）的格保持
  不变；所有灰色像素（含破口环）原样保留。

关键洞察
- 两重陷阱叠加：先要发现有些环被一格破口废掉了包围资格、其内芯实际
  与外界同层；再要发现反色的真正开关是闭合包围层数的奇偶，而非一次
  内外判定——两层筛选缺一不可。
```

## 6. 掷网捕获：货物驱动的空箱漂移与吞噬

- tags:
  - operation:平移, translate
  - operation:重涂色, recolor
  - object:空心矩形, hollow_rect
  - object:货物像素, cargo_pixel
  - object:自由散点, loose_pixel
  - relation:偏侧定方向, eccentricity_defines_direction
  - relation:像素数决定步长, pixel_count_distance
  - condition:落点罩住则染色, capture_recolor_on_landing

### docstring

```text
每个空心箱被抛向内部货物偏重的一侧，抛出距离等于货物个数，旧货物被留在原地，箱子落点罩住的散点被捕获并染成箱色。

输入结构
- 黑色背景；若干一格粗、完好无缺、颜色各异的空心矩形箱。
- 每个箱内装有若干彩色单像素货物；结构保证每箱货物的整体重心相对
  箱子几何中心只朝上、下、左、右之一严格偏移。
- 画布上另散布若干自由散点；结构保证每个箱平移后箱壁只落在空格上、
  不越界，各箱结算互不干扰。

规则
- 对每个箱：判定货物重心偏向箱中心的哪一侧，箱子朝该侧平移，步数
  等于箱内货物像素的个数。
- 原货物像素原地不动、颜色不变，箱子移走后裸露在外。
- 箱子到达新位置后，凡严格位于其内部的自由散点全部重涂为该箱的
  颜色；未被任何箱罩住的散点保持原样。

关键洞察
- 位移向量从未被画出：方向藏在货物相对箱心的偏侧，长度藏在货物的
  数量；同时"旧货不随箱走、新货被染成箱色"构成一次抛网式的因果链，
  把箱子当整体搬运或把染色当装饰的读法都会失败。
```

## 7. 潜影取景框

- tags:
  - operation:裁剪, crop
  - operation:补全, completion
  - object:潜在矩形框, latent_frame
  - object:散点, scattered_pixel
  - object:诱饵实心块, decoy_solid_rect
  - relation:共矩形周界, co_perimeter
  - condition:唯一通过判据者为框, unique_qualifier_is_frame

### docstring

```text
找出所有像素都落在自身包围盒周界上的那种颜色，把这个从未画全的矩形框补完整，并裁出框内景象。

输入结构
- 黑色背景上散布多种颜色的单像素点，每色至少四粒。
- 恰有一种颜色满足：包围盒高、宽都不小于三，且它的全部像素都落在
  包围盒的四条边线上；其余颜色或有像素严格在自身包围盒内部，或
  包围盒退化成线。
- 场内另有一个画得完完整整的实心单色矩形块充当诱饵；潜影框内部
  可能同时罩着诱饵块和别色散点。

规则
- 逐色检查"全部像素共矩形周界"这一判据，唯一通过者即取景框色。
- 以该色包围盒为界裁剪输入作为输出，把输出最外一圈全部补涂成
  取景框色，圈内内容原样保留。

关键洞察
- 取景框在输入中从未成形，只剩四条边线上的稀疏采样点；那个画得最
  完整、最惹眼的实心矩形反而是诱饵，真正的裁剪依据是把散点认出
  "共周界"指纹后才浮现的潜影矩形。
```
