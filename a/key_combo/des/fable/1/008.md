## 1. 框阵拉丁方（边框即调色板）

- 标签：
  - 操作:填充
  - 对象:空心矩形
  - 对象:对象格阵
  - 关系:行列唯一约束（作用于对象层）
  - 条件:内部色禁用自身边框色

### docstring

```text
在空心方框阵列中为每个空框内部填色，使框阵的内部色构成拉丁方，且任何框的内部色不得与其自身边框色相同。

输入结构：
- 背景为黑色，画布上排列着 n 行 n 列大小相同的空心正方形框。
- 每个框的边框为一种非黑颜色，全部边框颜色恰好构成一个 n 色调色板。
- 部分框的内部已被某调色板颜色实心填满，其余框内部仍是黑色空白。

规则：
- 保持所有边框与已填内部不变。
- 为每个空白内部选一种调色板颜色，使得：框阵的每一行、每一列中，
  n 种颜色作为内部色各出现一次；且每个框的内部色不等于该框自己的边框色。
- 已给线索恰好使同时满足两条约束的填法唯一。

关键洞察：
行列唯一约束作用在"框的阵列"这一抽象层而非像素行列上；调色板并未单独
给出，它藏在边框颜色的集合里，而每个框的边框色同时又是对其内部的一条
否定线索——只用拉丁方约束无法定解，必须把"内部异于边框"当作第二套约束
联立使用。
```

## 2. 卷带盒（蛇带经缺口注入空心矩形）

- 标签：
  - 操作:补全
  - 操作:序列重排
  - 对象:单像素宽路径
  - 对象:空心矩形
  - 对象:边框缺口
  - 关系:一维弧长到二维蛇形走行的对应
  - 条件:彩色长度等于内部面积

### docstring

```text
从白帽端读出彩蛇的颜色序列，经边框缺口以蛇形走行写满空心矩形的内部。

输入结构：
- 背景为黑色。一条 4-连通单像素宽多色路径（蛇），其一个端点为白色帽，
  规定读带方向。
- 另有一个单色空心矩形框，边框上恰缺一格，缺口位于紧邻框角的位置；
  框内部全为黑色。
- 蛇的彩色部分长度恰好等于框内部的格子数。

规则：
- 从白帽的下一格起沿蛇走到另一端，读出颜色序列。
- 写入起点是与缺口相邻的那个内部角格；先沿缺口所在边的方向朝远端书写，
  写满一排后折入下一排反向书写，如此蛇形往返直到内部填满。
- 蛇、框、缺口在输出中保持原样。

关键洞察：
缺口不是破损而是入带口——它同时指定写入的起始角与首排方向；蛇与矩形
看似无关，实由"彩色长度=内部面积"这条隐藏等式配对，答案是把一维色带
重新序列化成二维块。
```

## 3. 图例接力染色

- 标签：
  - 操作:重涂色
  - 操作:擦除
  - 对象:颜色图例
  - 对象:灰块邻接链
  - 对象:标记像素
  - 关系:图例作为循环后继函数
  - 条件:标记色定入位点

### docstring

```text
以图例色条为循环后继表，把颜色从标记像素起沿灰块邻接链逐块接力传递。

输入结构：
- 背景为黑色。一条孤立的直线色条是图例，由若干互不相同的颜色依次排列
  而成。
- 若干灰色 4-连通块彼此相邻地串成一条不分叉的链，链的空间走向可以任意
  弯折。
- 恰有一个彩色标记像素与链的某一个端点块相邻，其颜色出现在图例中。

规则：
- 与标记相邻的端点块整块染成标记色，随后擦除标记像素为背景。
- 沿链每前进一块，就把该块染成图例中当前颜色的下一种颜色；越过图例
  末尾时循环回图例开头继续取色。
- 图例本身保持不变。

关键洞察：
图例不是"输入色到输出色"的映射表，而是一个循环后继函数；标记色的作用
是给出在这个循环序列中的入位点，链上各块的染色次序由块与块的邻接关系
决定，与它们在画面上的左右上下位置无关。
```

## 4. 染液射线与选择性穿墙

- 标签：
  - 操作:射线延伸
  - 操作:重涂色
  - 对象:发射器像素
  - 对象:染料像素
  - 对象:水平墙段
  - 关系:射线携带可变颜色状态
  - 条件:同色墙拦截、异色墙穿透
  - 条件:对象角色由尺寸判定

### docstring

```text
顶行发射器向下发射射线，射线穿过染料像素时改变自身颜色，而墙只拦得住
与它同色的射线。

输入结构：
- 背景为黑色，顶行上的非背景像素是发射器，各自颜色不同。
- 网格内部散布两类前景物：孤立的单像素是染料，长度不小于二的水平线段
  是墙。

规则：
- 每个发射器沿所在列向下延伸射线，射线初始为发射器颜色，沿途把背景格
  涂成当前颜色。
- 射线到达染料像素时不停止：从该格起射线改用染料的颜色继续向下。
- 射线到达墙格时，若墙色与射线当前颜色相同则射线就此停止；否则射线
  穿过墙（墙格保持墙色不变），在墙下方继续绘制。
- 未被射线经过的染料与墙保持原样，射线到达底边自然结束。

关键洞察：
物体的角色由尺寸而非颜色决定——孤立点是换色剂、线段才是墙；而墙能否
拦截取决于射线抵达时的"当前颜色"，因此上游吸收哪种染料会连锁地决定
下游哪堵墙生效，第一眼"遇物即停"的读法在多数示例上都会画错。
```

## 5. 残印复原

- 标签：
  - 操作:补全
  - 操作:裁剪
  - 对象:周期贴印残片
  - 对象:矩形精灵
  - 关系:周期等价类折叠
  - 条件:无任何完整实例可见

### docstring

```text
画布上只有一个周期贴印精灵被边缘裁剪后的残片，凭周期关系把从未完整
出现的精灵拼回，并输出精灵本体。

输入结构：
- 背景为黑色。某个每格皆非背景的多色矩形精灵，曾按固定的行周期与列周期
  在一张更大的平面上反复贴印。
- 输入画布是从该平面上裁下的一块：画布内每个可见的贴印实例都被画布
  边缘切掉了一部分，没有任何一个实例是完整的。
- 全部残片合起来覆盖精灵的每一个格子，重叠部分颜色一致，使周期与拼合
  唯一。

规则：
- 比对残片间重合部分，推断贴印格阵的行周期与列周期。
- 把相隔整数个周期的格子视为同一精灵格，将各残片按此对齐叠合，拼出
  精灵的全部内容。
- 输出该精灵自身尺寸的完整网格。

关键洞察：
要求输出的对象在输入中从未被完整画出——它只以边缘残迹的形式存在；
周期把不同残片的对应格子连成等价类，答案是把互补的残片沿周期折叠回
同一张模板。
```

## 6. 灰影指令（重复形状对是平移向量）

- 标签：
  - 操作:平移
  - 对象:分隔线块阵
  - 对象:灰色剪影块
  - 对象:彩色原版块
  - 关系:块对相对位置编码指令
  - 条件:块阵坐标环绕搬移

### docstring

```text
块阵中一对形状相同的块（彩色原版与灰色剪影）给出位移向量，整个块阵按
该向量环绕循环搬移。

输入结构：
- 网格被整行整列的分隔线划成块阵，每块内含互不相同的小图案。
- 恰有一块的图案是另一块图案的同形灰色剪影（形状逐格相同、颜色全为灰）。

规则：
- 找出剪影块与其彩色原版块，取从剪影块指向原版块的块阵坐标差 (dr, dc)。
- 把所有块（含这两块）在块阵上按 (dr, dc) 平移，越界的块从对侧环绕
  回来；块内图案随块整体搬移，不旋转不镜像。
- 分隔线保持不变。

关键洞察：
灰影块不是等着被上色的对象——它与原版的相对位置才是全图唯一的指令；
指令由一对块的关系而非任何画出的标记编码，且平移在块阵坐标上环绕，
而非像素平移。
```
