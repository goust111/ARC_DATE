## 1. 级联倒水

- tags:
  - operation:计数, counting
  - operation:射线延伸, ray_extend
  - object:杯形轮廓, cup_outline
  - object:开口, opening
  - relation:开口对准传递链, opening_alignment_chain
  - condition:像素守恒, pixel_conservation

### docstring

```text
沿开口对准的传递链把水层层倒下去，终端杯吐出长度等于链上总水量的射线。

输入结构：
- 黑色背景上有若干杯形对象：近封闭的单色矩形轮廓，边界上恰有一个一格宽的开口；
  各杯轮廓颜色互不相同，水色全局统一。
- 每个杯子内部有若干水色像素，数量不一。
- 若从一个杯子的开口沿其朝向前进，恰好进入另一个杯子的开口，则前者的水传给后者；
  生成保证传递关系无环、传递路径无阻挡，且终端射线不越出网格。

规则：
- 清空所有杯内的水色像素。
- 把每个杯子的水量沿"开口正对开口"的通路逐级汇入下游杯子。
- 对每个没有下游的终端杯，从其开口沿朝向向外画一条水色直线，
  长度等于汇到它这里的水量总和（含它自己的）。

关键洞察：
- 射线长度不由终端杯自身决定：水量沿开口对准关系守恒地级联汇聚，
  必须先重建传递链、再沿链求和。
```

## 2. 隐形矩形嵌套取色

- tags:
  - operation:重涂色, recolor
  - operation:结构重建, structure_reconstruction
  - object:拐角标记, corner_marker
  - object:调色板行, palette_row
  - object:标记像素, marker_pixel
  - relation:嵌套深度计数, nesting_depth_count
  - condition:深度定调色板取色, depth_indexes_palette
  - condition:忽略干扰项, ignore_distractors

### docstring

```text
用同色角标复原从未画出的矩形，按嵌套层数给每个灰点从调色板取色。

输入结构：
- 黑色背景上有若干对同色 L 形角标，每对标出一个矩形的两个对角，
  L 的开口朝向矩形内部；矩形边界本身从不画出。
- 复原出的矩形彼此可以嵌套或部分重叠；各对角标颜色互不相同。
- 画面中散布若干灰色单像素点；网格底部左侧有一条水平调色板，
  从左到右依次给出第 1、2、3…层对应的颜色。

规则：
- 将每对同色角标补全成一个矩形区域（仅用于判定，不画出）。
- 对每个灰点，统计覆盖它的矩形个数 d：d≥1 时把它涂成调色板中第 d 个颜色；
  d=0 时清为黑色。
- 角标与调色板原样保留。

关键洞察：
- 参与判定的矩形在画面上只有两个角的残迹；
  灰点的新颜色只由嵌套计数决定，与覆盖它的矩形颜色无关——角标颜色是干扰项。
```

## 3. 带噪表头等式表

- tags:
  - operation:修复噪声, repair_noise
  - operation:填充, fill
  - object:行标签, row_label
  - object:列标签, column_label
  - object:周期序列, periodic_sequence
  - relation:行列交叉, row_col_intersection
  - condition:先修复后判等, repair_before_match

### docstring

```text
先按周期修复被污染的行列表头，再用修复后的表头做同色等式表填充。

输入结构：
- 网格内部为背景色；最右一列是行标签序列，最下一行是列标签序列，右下角格不参与。
- 两条标签序列各自按一个短周期重复，且各有少数格被替换成了别的颜色；
  每条序列的长度至少覆盖其周期三次，污染格是少数。

规则：
- 对每条标签序列，按周期位置多数一致推断真实周期串，改正被污染的格。
- 对每个内部格，比较其行的（修复后）右端标签与其列的（修复后）底端标签：
  同色则把该格涂成这一颜色，否则保持背景。
- 输出中的两条表头也是修复后的样子。

关键洞察：
- 直接用可见表头做等式表会得到错误图案；
  必须先识破表头是带噪的周期序列并修复，等式关系才成立。
```

## 4. 折线认领循环位移

- tags:
  - operation:循环位移, cyclic_roll
  - operation:计数, counting
  - object:分隔面板, separated_panel
  - object:弯折折线, bent_polyline
  - relation:颜色认领配对, color_claim_pairing
  - condition:拐弯数定位移量, bend_count_is_shift
  - condition:伸展轴向定位移轴, extent_axis_is_shift_axis

### docstring

```text
每个面板的图案循环位移，控制它的折线按颜色认领而非按位置对齐：
面板图案中出现的那种折线色指认其控制者，拐弯数给出位移量，伸展轴向给出位移轴向。

输入结构：
- 一条分隔色横线把网格分成上下两带：上带是控制带，
  排着若干条互不同色的单色折线（一格宽的连续路径，拐弯 1 至 3 次；
  或横向伸展、或纵向伸展）。
- 下带被分隔色竖线分成同样数量的面板，每个面板内是一幅多色图案；
  每幅图案的用色中恰好含有一种折线色，且各面板认领的折线互不相同。
- 折线的左右排列顺序与面板顺序无关（不按位置对应），
  部分示例中按位置对齐恰好会给出错误答案。

规则：
- 每个面板由"其图案中出现的那种折线色"的折线控制。
- 数出该折线的拐弯数 k：折线横向伸展则把面板图案循环右移 k 格，
  纵向伸展则循环下移 k 格（移出的部分从另一侧回绕）。
- 折线、分隔线保持不变。

关键洞察：
- 控制与被控不按上下位置对应，而按"面板图案中含有该折线的颜色"配对；
  位移量藏在折线的拐弯数（拓扑）里，轴向藏在其伸展方向里——位置对齐是诱饵。
```

## 5. 钥匙门因果链轨迹

- tags:
  - operation:路径追踪, path_trace
  - operation:重涂色, recolor
  - object:粒子, particle
  - object:门格, door_cell
  - object:整列竖墙, full_column_wall
  - relation:钥匙匹配选门, key_matches_door
  - condition:穿门换钥匙, pass_door_swap_key
  - condition:轨迹分段变色, segmented_trail_color

### docstring

```text
粒子以当前颜色为钥匙选择每面墙上的门，穿过后换上墙体色作为下一把钥匙。

输入结构：
- 背景色网格上有若干条互不相邻的整列竖墙，每条墙体单独一色。
- 每条墙上嵌着数个一格宽的"门"格，门格颜色各异且不同于墙体色。
- 左边缘有一个带初始颜色的粒子像素；
  生成保证每面墙上恰有一扇门的颜色等于粒子到达时的颜色。

规则：
- 粒子自左向右直行；到达一面墙前的相邻列时，
  沿该列竖直移动到颜色等于自己当前颜色的那扇门所在行，穿门而过。
- 穿门后粒子的颜色变为该墙的墙体色；
  轨迹（含竖直寻门段与门格）都按粒子经过该段时持有的颜色绘制。
- 粒子到达右边缘停止；输出保留所有墙与完整轨迹。

关键洞察：
- 门色是钥匙、墙体色是新钥匙：粒子在每面墙的选择由上一面墙的墙体色决定，
  形成一条因果链；轨迹因此是分段变色的，多数门格只是干扰。
```

## 6. 标记定向多重重力

- tags:
  - operation:滑动, slide
  - operation:堆叠, stack
  - object:边墙, edge_wall
  - object:矩形块, rectangle_block
  - object:标记像素, marker_pixel
  - relation:标记色认领墙面, marker_claims_wall
  - condition:近墙优先结算, nearest_first_settling
  - condition:碰撞停止, collision_stop

### docstring

```text
每块按自己内嵌标记像素的颜色认领一面边墙，向它滑动堆积。

输入结构：
- 黑色背景；网格的两条以上边缘各有一面单色整边墙，一格厚，颜色互不相同。
- 内部散布若干单色矩形块，每块内部嵌有一个异色标记像素，
  标记色总等于某面墙的颜色。
- 生成保证按规则结算时不出现顺序歧义。

规则：
- 各块向其标记色对应的那面墙滑动：与目标墙距离最近的块先结算。
- 块沿直线刚体滑动，直到再走一步会撞上墙、已结算的块或网格边界为止；
  标记像素随块移动，保持在块内的相对位置。
- 墙保持不变。

关键洞察：
- 重力不是全局方向：每块由自己体内的标记像素指派去向，
  不同去向的块在途中互相成为对方的障碍。
```

## 7. 象限翻转印章

- tags:
  - operation:印章覆盖, stamp
  - operation:镜像, mirror
  - object:模板面板, template_panel
  - object:前景像素, foreground_pixel
  - relation:分块对应, block_correspondence
  - condition:象限决定印章朝向, quadrant_determines_stamp_orientation

### docstring

```text
把源面板的每个彩色像素扩展成模板印章，但印章的朝向服从输出的四象限镜像布局。

输入结构：
- 输入由两个等大的正方形面板并排（或上下叠放）组成，边长 N 为偶数：
  一个是含若干彩色前景像素的源面板，另一个是用单一标记色画出的模板面板。
- 两个面板共享同一背景色；模板形状不具有左右或上下对称性。

规则：
- 生成 N²×N² 的输出，划分为 N×N 个块，初始化为背景色。
- 源面板位置 (r, c) 上的每个前景像素，把模板掩码染成该像素的颜色后，
  印到输出的第 (r, c) 块。
- 印章朝向由块所在象限决定：左上象限原样；右上象限左右镜像；
  左下象限上下镜像；右下象限两轴皆镜像。

关键洞察：
- 印下的不是同一枚图章：输出整体是一张四象限反射布局，
  每枚印章都要按其落点所在象限翻转，而不是简单的复制粘贴。
```
