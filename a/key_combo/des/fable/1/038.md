## 1. 导线折角旋转传输

- tags:
  - operation:传输, transmit
  - operation:旋转, rotate
  - object:导线, wire
  - object:令牌, token
  - relation:折角计转向, bend_encodes_turn
  - condition:净转角决定旋转, net_turn_rotation
- 参考题目题号: 2（a47bf94d）、10（6ffbe589）、15（99caaf76）
- 难度评审: 达标

### docstring

```text
沿导线把端点令牌搬运到另一端，导线的净转角决定令牌的旋转量。

输入结构：
- 黑色为背景。若干条互不接触的单格宽导线，每条由横竖线段与直角折角组成，颜色各不相同。
- 每条导线恰有一端紧贴一个 3×3 的非对称单色令牌图案，另一端悬空；令牌从其所贴边的中格与导线相连。

规则：
- 沿导线从令牌端走向悬空端，每遇一次右折记顺时针 90 度，每遇一次左折记逆时针 90 度，把全部折角依次累加得到净旋转量。
- 在悬空端外侧、沿末段方向放置该令牌的拷贝：拷贝按净旋转量旋转，并改用这条导线自身的颜色绘制，悬空端仍与拷贝所贴边的中格相接。
- 原令牌、导线与其余部分保持不变。

关键洞察：
- 导线不是单纯的通路，它的几何折转本身就是一串旋转指令；令牌到达时的姿态等于出发姿态按导线方向变化量旋转的结果，颜色则被途经的导线染成线色。
```

## 2. 双嵌套系统深度换色

- tags:
  - operation:补全, completion
  - operation:重涂色, recolor
  - object:嵌套方框, nested_frames
  - object:角标记, corner_marker
  - relation:深度配对, depth_pairing
  - condition:同深度跨系统换色, swap_colors_by_depth
- 参考题目题号: 9（93c31fbe）、1（85c4e7cd）、11（4290ef0e）
- 难度评审: 达标

### docstring

```text
重建只剩角块的暗框后，把两组嵌套方框按深度逐层交换颜色。

输入结构：
- 黑色为背景。网格中有两组互不接触的嵌套矩形框系统，各由若干一格厚、严格嵌套的矩形框组成。
- 两组层数相同，但整体大小、位置、长宽比例都不同。
- 其中一组的部分方框完整画出、部分只以四个同色 2×2 的 L 形角块出现，四角共同确定一个矩形；另一组全部完整画出。

规则：
- 先把每组同色角块补全成完整的一格厚矩形框。
- 把两组框按各自从最外到最内的深度对齐配对，同深度的两个框交换颜色。
- 输出中所有方框均为完整矩形，位置与形状保持不变。

关键洞察：
- 两组框之间没有任何位置或大小上的对应，唯一的配对关系藏在嵌套深度里；而只画四角的暗框同样占据一个深度层，漏掉它会使整条配对链错位。
```

## 3. 墙上残迹复原隐形拷贝

- tags:
  - operation:模板匹配, template_matching
  - operation:补全, completion
  - object:图例精灵, legend_sprite
  - object:墙段, wall_segment
  - relation:交截残迹, intersection_residue
  - condition:残迹锁定唯一平移, residues_pin_translation
- 参考题目题号: 6（6ecd11f4）、17（f9a67cb5）、12（14754a24）
- 难度评审: 达标

### docstring

```text
根据墙面上的变色残迹，把只露出截面的隐形图例拷贝完整画出。

输入结构：
- 黑色为背景。灰色形成若干条相互平行、可能断开的墙段。
- 远离墙体处有一个完整的多色图例精灵。
- 墙体上有少量带图例颜色的格子：它们恰好是图例的一个平移拷贝与墙体相交的全部位置，拷贝落在墙外的部分没有画出。

规则：
- 在网格中寻找唯一一个平移位置，使图例精灵与灰墙的交集恰好等于全部变色残迹。
- 在该位置把图例完整画出：残迹保持原样，拷贝覆盖到的黑色格与灰墙格都改为图例中对应位置的颜色。
- 图例本体与其余墙体保持不变。

关键洞察：
- 变色的墙格不是独立标记，而是一个从未整体出现的物体与墙的截面；多条墙上的残迹共同锁定唯一的平移位置，图例提供缺失的完整形状。
```

## 4. 指针格链式盖章

- tags:
  - operation:盖章, stamp
  - operation:旋转, rotate
  - operation:连锁反应, chain_reaction
  - object:图例图案, legend_motif
  - object:指针格, pointer_cell
  - relation:印章生成下一锚点, stamp_spawns_anchor
  - condition:旋转逐次递增, rotation_accumulates
- 参考题目题号: 12（14754a24）、10（6ffbe589）、15（99caaf76）
- 难度评审: 达标偏上

### docstring

```text
以图例中的灰色指针格为传动装置，做旋转逐次递增的链式盖章。

输入结构：
- 黑色为背景。一个奇数边长的非对称多色图例图案被围在一个封闭外框里，图案中恰有一个灰色格，作为指针。
- 框外只有一个孤立的灰色锚点格。

规则：
- 把图例（不含外框）以中心对准锚点盖下，得到第 1 个印章。
- 印章中灰色指针格的落点成为下一个锚点：第 k 次盖章以该锚点为中心，并按顺时针 90 度乘以 (k-1) 旋转图例后盖下。
- 如此连锁进行，直到下一个锚点出界或落在已盖下的印章格上为止。
- 图例与外框保持不变。

关键洞察：
- 画面上只给出链条的第一个环节，后续锚点全部由印章自身生成；指针格既是图案的一部分又是传动装置，旋转随链条逐步累积，整个输出是一条自引用的因果链。
```

## 5. 交集布局异或内容

- tags:
  - operation:异或, xor
  - operation:求交, intersect
  - operation:平铺, tiling
  - object:分隔行, separator_row
  - object:掩码, mask
  - relation:跨尺度分工, cross_scale_roles
  - condition:布局与内容来自不同比较, layout_content_differ
- 参考题目题号: 3（3428a4f5）、19（15696249）
- 难度评审: 达标

### docstring

```text
两侧掩码的交集决定宏观布局，异或决定块内图案，两张导出图分别在两个尺度上起作用。

输入结构：
- 一条整行的黄色分隔行把输入分成上下两个同尺寸的 n×n 掩码，上半为红色与黑色，下半为蓝色与黑色。
- 两个掩码既有共同着色的位置，也有各自独占着色的位置。

规则：
- 逐格比较两个掩码，得到两张导出图：两侧都着色的位置构成交集图，恰有一侧着色的位置构成异或图。
- 输出为 n·n × n·n 的黑色画布，划分为 n×n 个块。
- 交集图每个着色位置对应的块内，画一份绿色的异或图；其余块保持全黑。

关键洞察：
- 诱饵是把输出当成某一张导出图与自身的分形复合；实际上布局与内容来自两次不同的逐格比较，同一对掩码在宏观与微观两个尺度上各投影出一张不同的图。
```

## 6. 错位双视图配准合成

- tags:
  - operation:配准, registration
  - operation:合并补全, merge_completion
  - object:半区域, half_region
  - object:残缺精灵, partial_sprite
  - relation:内容对齐, content_alignment
  - condition:唯一无冲突偏移, unique_conflict_free_offset
- 参考题目题号: 3（3428a4f5）、4（8618d23e）、11（4290ef0e）
- 难度评审: 达标偏上

### docstring

```text
找出使上下两幅残缺图无冲突重合的唯一错位，将它们并成完整图案。

输入结构：
- 一条整行的灰色分隔行把输入分成上下两个同尺寸区域。
- 两个区域各画有同一个多色精灵的一份残缺拷贝：两份拷贝在各自区域内的位置不同，缺失的格子也不同，但合起来覆盖精灵的全部格子。

规则：
- 在所有平移错位中寻找唯一一个，使两份残缺拷贝重叠时所有同时着色的格子颜色完全一致。
- 按该错位把下半的拷贝对齐到上半的拷贝上，取两者的并集补全精灵。
- 输出为与单个区域同尺寸的网格：保持上半原有内容不动，在其位置上画出补全后的完整精灵。

关键洞察：
- 分隔行诱导人做逐格叠加或异或，但两半根本没有对齐；真正的对应关系藏在内容里，必须先用无冲突重合恢复隐藏的错位，再合并两份互补的残片。
```
