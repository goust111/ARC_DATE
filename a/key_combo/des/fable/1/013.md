## 1. 隐形射线按访问序取色

### docstring

```text
追踪一条由转向控制点引导的隐形射线，按访问顺序用角落的对角调色板重涂被访问的控制点。

输入结构：
- 黑色背景网格上有一个绿色起点像素，四个方向中恰有一个方向的视线首个非背景像素是控制点。
- 场上散布若干粉色与青色单像素控制点，其中一部分位于射线路径上，其余是干扰。
- 网格一角有一串沿对角线相邻排列的单像素标记（调色板），颜色互不相同且不与绿、粉、青重复；调色板远离射线活动区域。

规则：
- 从绿色起点朝可见控制点方向逐格前进；当下一格是粉色控制点时在当前格右转，是青色控制点时左转，控制点本身不被覆盖；触发转向的控制点依次记为第 1、2、3……个被访问的控制点。
- 射线不留任何痕迹，直到走出网格为止。
- 把对角调色板从靠角一端向内依次读出颜色序列，将第 k 个被访问的控制点重涂为序列第 k 色。
- 起点、未被访问的控制点、调色板与背景全部保持不变。

关键洞察：
- 射线在输出中不可见，它只是给控制点排序的隐形指针；控制点的新颜色由“第几个被访问”决定，而与它的位置、原色或离起点的距离无关。
```

## 2. 克罗内克因子互换

### docstring

```text
把画面读成“占位布局 ⊗ 瓦片图案”的克罗内克乘积，输出两个因子互换后的乘积。

输入结构：
- 灰色分隔线把网格划分成 R 行 C 列的等大瓦片阵列。
- 每个非空瓦片内部含有完全相同的单色图案（形状与瓦片内位置都一致），其余瓦片内部为纯背景。
- 非空瓦片在阵列中的分布构成布局掩码 A（R×C），瓦片内公共图案构成图案掩码 B（r×c）。

规则：
- 输出不含分隔线，尺寸为 (r·R)×(c·C)。
- 把 B 当作宏观布局：B 的每个前景格对应输出中一个 R×C 的块，块内按 A 的分布放置前景像素；B 的背景格对应全背景块。
- 前景颜色沿用输入图案的颜色，背景沿用输入背景色。

关键洞察：
- 输入是乘积 A⊗B 的画面：哪些瓦片被占用是一层图案，瓦片里画的是另一层图案；答案不是抽取或去除某一层，而是让两层互换角色，输出 B⊗A。
```

## 3. 同色穿透连锁塌落

### docstring

```text
让下落方块穿透并切断同色横板、被异色截停，被切下的板段接着下落，输出整场连锁塌落的终态。

输入结构：
- 网格底行是一条完整的灰色地板，其余背景为黑色。
- 空中悬着若干条一格厚的单色横板，高度、颜色、横跨的列区间各不相同，互不接触。
- 顶部有一个实心单色小矩形作为下落体，场上至少有一条横板与它同色。

规则：
- 下落体竖直下落：下方是异色横板、地板或任何已停稳的物体时停在其上；下方是同色横板时穿透而过，并把该板中与下落体列区间重叠的部分抹去，剩余的左右两段成为自由板段。
- 下落体完全停稳后，自由板段各自竖直下落；板段是惰性的，碰到任何东西都停住不再切割；由更低的切口产生的板段先落定。
- 所有物体停稳后的画面即输出，地板保持完整。

关键洞察：
- 同色在这里不是吸引或归并，而是“无碰撞”：下落体只被异色拦住；每一次穿透都把一条板变成两个新的下落物，答案是这场连锁反应结束后的静止画面。
```

## 4. 手性对向隐形轴聚拢

### docstring

```text
找出互为左右镜像的手性物体对，让每一对聚拢到灰色标记列两侧拼成关于它对称的整体，抹掉所有配不成对的物体。

输入结构：
- 背景之上散布若干单色 8 连通物体；顶边有一个灰色单像素，标记一条竖直的轴列，轴列上没有其他前景。
- 部分物体两两成对：同色、占据完全相同的行区间、形状掩码互为水平翻转，且该形状自身不具左右对称性；每对的两个成员分居轴列两侧。
- 其余物体配不成对，其中混有形状平移全等的同色“假对”和左右自对称的物体作干扰。

规则：
- 两物体配对当且仅当：颜色相同、行区间相同、掩码水平翻转后全等，且形状不是左右自对称。
- 每一对中，两物体各自水平滑动到紧贴轴列的两侧：左成员的最右列贴在轴列左邻列，右成员的最左列贴在轴列右邻列，行位置不变；拼成的整体恰好关于标记列左右对称。
- 所有未配对的物体（包括平移全等的假对与左右自对称的物体）抹为背景；灰色标记保留。

关键洞察：
- 配对判据是“翻转后全等”而不是“全等”，一模一样的两个物体反而是噪声；顶边那个不起眼的灰点是全场的对称轴，手性对不是相互靠拢，而是共同向这条隐形轴聚拢成镜像拼图。
```

## 5. 双向形状字典

### docstring

```text
以“整数倍放大＋旋转翻转”为等价关系在图例样本与场上物体之间建立形状对应，把颜色沿着“谁缺色就补谁”的方向双向传递。

输入结构：
- 一个带边框的图例矩形内散布若干小样本图案；图例之外散布同样数量的大物体；每个大物体恰是某个样本经某一整数倍放大（每格变 k×k，不同物体的倍率可以不同）并旋转或翻转后的形状。
- 样本形状两两之间即使经过放缩、旋转、翻转也互不全等，故形状对应唯一。
- 恰有一个样本是灰色的，其余样本颜色互不相同；恰有一个场上物体是灰色的，其余场上物体各带颜色；两个灰色成员的形状并不对应。
- 样本与物体的排布位置没有任何对应关系。

规则：
- 为每个场上物体找出唯一能通过整数倍放大加旋转翻转与之全等的样本。
- 灰色的场上物体重涂为其对应样本的颜色；灰色的样本重涂为其对应场上物体的颜色。
- 其余样本、物体、边框与背景全部保持不变。

关键洞察：
- 图例不是单向的颜色来源而是一部双向字典：颜色顺着“有色→灰色”的方向流动，既可能从图例流向场上，也可能从场上流回图例；配对本身还隔着一次倍率归一化和一次旋转翻转。
```

## 6. 双因弯折的水流反演

### docstring

```text
区分水流的两类弯折——隐形边缘偏折点造成的整体错位与可见障碍造成的局部绕行——抹除前者的影响、保留后者的机制，重画出没有偏折点的世界里的水流，并把偏折点本身补画出来。

输入结构：
- 黑色网格左边缘有若干青色源点，每个源点引出一条延伸到右边缘的青色路径。
- 场上另有少量灰色障碍像素；路径遇到正前方的障碍时从下方绕行：斜下一格、平行越过、再斜上回到原行。
- 除绕行外，路径还会在某些列以对角一步整体上移或下移一格且不再回落；这类错位在所有路径上发生于完全相同的列、方向一致；输入中没有红色像素。

规则：
- 甄别两类弯折：全体路径同列同向的永久错位来自隐形的边缘偏折点；个别路径下绕又回升的凸包来自可见的灰色障碍。
- 对每个错位列，按方向在该列的施力侧边缘补画一个红色像素：向下错位画在顶行，向上错位画在底行。
- 把每条路径重画为：从源点沿原行笔直向右，仅在正前方遇到灰色障碍时按“斜下—平过—斜回”绕行，直到右边缘；不再发生任何错位。
- 障碍像素保持原位。

关键洞察：
- 弯折有两种成因，只有“人人都在同一列拐”的才是被擦掉的偏折点留下的痕迹；拉直不是简单抹平——错位消失后路径回到原行，可能撞上原先撞不上的障碍、也可能不再需要原先的绕行，必须在重建出的无偏折世界里把水流重新走一遍。
```

## 7. 异常块的跨尺度作用

### docstring

```text
在自相似的块阵列中找出唯一被旋转或翻转过的异常块，把这一变换施加到整个宏观布局上，并把异常块本身归正。

输入结构：
- 前景由若干等大的图案块组成，块与块之间由背景间隔，块的位置落在规则的方形阵格（行列数相等）上。
- 所有块内画着同一个单色图案 B，唯独一个块里的图案是 B 经过某个旋转或翻转 T 后的样子；B 自身不具有任何旋转或翻转对称，因此 T 唯一可辨。
- 块在阵格上的占位分布构成宏观布局掩码 A。

规则：
- 找到异常块，识别其相对标准图案的变换 T。
- 对宏观布局 A 施加同一个变换 T，得到新的块占位分布。
- 在新布局的每个占位处都画上标准朝向的图案 B（异常被归正），块间距与块尺寸保持不变。

关键洞察：
- 那个转了向的块不是要局部修复的瑕疵，而是一条作用于另一尺度的指令：微观层查出的变换要拿到宏观层去执行，同时微观层恢复一致。
```

## 8. 比较播种交替生长

### docstring

```text
把分隔线上方两行的逐列相等比较结果播种到下方，再按“有色—背景—有色”三元组规则向下交替生长出粉橙三角纹样。

输入结构：
- 一条水平灰色分隔线横贯网格，其上方紧贴两行彩色像素，逐列对齐，部分列可以为空。
- 分隔线下方是大片绿色背景；输入中不含粉色与橙色。

规则：
- 逐列比较上两行：两格均非背景且颜色相同的列，在分隔线下方第二行同列生成一个橙色种子像素；其余列不生成。
- 以种子行为当前行反复生长：当前行中每个“有色—背景—有色”的相邻三元组，在其下方隔一行的中间列生成一个子像素；每代生成行的颜色在粉与橙之间交替。
- 当没有三元组可繁殖或下一代越出网格时停止；分隔线及其上方保持不变。

关键洞察：
- 三角纹样的种子并没有画在输入里，它是上方两行逐列相等判定的结果；必须先解出这层比较，隔行繁殖的生长规则才有起点。
```

## 9. 堆叠锚定的落地倾斜

### docstring

```text
让悬浮物体按由低到高的次序落下并可能互相堆叠，再各自以落定后的最底行为锚，向同色侧墙的方向逐行剪切倾斜。

输入结构：
- 网格最左列与最右列是两种不同颜色的完整竖墙，底行是灰色地板。
- 墙间悬浮若干实心单色物体，每个物体的颜色与左墙或右墙之一相同；部分物体的列区间相互重叠。
- 布局保证剪切后的物体互不接触、不越出两墙。

规则：
- 按初始最底行从低到高的次序，让物体依次竖直下落：落在地板或先前已落定的物体上。
- 全部落定后，每个物体以自己落定时的最底行为锚，向与其颜色相同的墙的方向剪切：高于锚行 d 行的像素向该方向平移 d 格。
- 墙与地板保持不变。

关键洞察：
- 画面里的倾斜量不是常数：每个物体倒向哪边由它和哪面墙同色决定，倒多少由每个像素离这个物体自己的锚行多高决定，而锚行又取决于它落在地板上还是叠在别的物体上——重力次序、颜色归属与剪切三层必须按序解开。
```
