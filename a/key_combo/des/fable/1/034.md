## 1. 面板拓扑决定叠放次序

- 参考题目: `281123b4`, `44d8ac46`, `5d2a5c43`
- tags:
  - operation:透明叠加, transparent_overlay
  - operation:计数, counting
  - object:面板, panel
  - object:分隔列, separator_column
  - object:孔洞, hole
  - relation:图层优先级, layer_priority
  - condition:孔洞数决定层序, hole_count_sets_depth

### docstring

```text
将分隔线分开的各面板透明叠加为一幅图，叠放前后次序由每个面板图形自身的封闭孔洞数决定。

输入结构
- 网格被若干整列分隔线分成 3~4 个同尺寸面板。
- 每个面板含背景 0 与恰一种前景色，各面板前景色互不相同。
- 各面板前景形状的封闭孔洞数（被前景围死的背景连通域个数）互不相同。

规则
- 将各面板按位置对齐、视 0 为透明，叠加为一个面板尺寸的输出。
- 层序按孔洞数从多到少排列，孔洞最多的形状在最前。
- 每格输出自前向后第一个非背景色，全空处保持 0。

关键洞察
- 层序既不由面板位置也不由像素多少决定（首个示例中位置序恰与孔洞序一致，是诱饵）；
  隐藏的排序键是各形状自身的拓扑属性——封闭孔洞的数量。
```

## 2. 残片沿环并集重建

- 参考题目: `ad173014`, `72322fa7`, `5d2a5c43`, `f9d67f8b`
- tags:
  - operation:补全, completion
  - operation:重涂色, recolor
  - object:空心方框, hollow_square
  - object:连接线, connector_line
  - object:残片, fragment
  - relation:环形连接, ring_connection
  - relation:并集重建, union_reconstruction
  - condition:顺时针取色, clockwise_color_source
  - condition:原型从未画出, prototype_never_drawn

### docstring

```text
用所有框内残片的并集重建从未完整出现的底图案，补全每个框，新补像素涂顺时针下一框残片的颜色。

输入结构
- 若干红色空心方框由蓝色连线两两连接成一个环，每框恰接两段蓝线。
- 每个框内部是同一隐藏图案的单色残片，各框残片颜色互不相同、缺损位置各不相同。
- 隐藏图案从未完整画出，它等于所有残片形状（按框内相对位置对齐）的并集。

规则
- 将各框残片按框内相对位置对齐取并集，得到完整图案的形状。
- 在每个框内补齐缺失的图案像素：原有残片像素保持原色，
  新补像素涂成顺时针下一个框残片的颜色。
- 红框、蓝线与背景保持不变。

关键洞察
- 完整图案在画面上从未出现，只能由全部残片的并集涌现；
  蓝色环只用来指定补色的来源方向，颜色并不整体轮换——
  这与"框内颜色顺时针轮换"的表面猜测相悖。
```

## 3. 双框计数寻址叠加

- 参考题目: `c8b7cc0f`, `1990f7a8`, `281123b4`
- tags:
  - operation:计数, counting
  - operation:透明叠加, transparent_overlay
  - operation:裁剪, crop
  - object:矩形框, rectangular_frame
  - object:标记像素, marker_pixel
  - object:精灵体, sprite
  - relation:计数即地址, count_as_address
  - condition:忽略干扰项, ignore_distractors
  - condition:框序定层序, frame_order_sets_layer

### docstring

```text
用两个矩形框内的标记计数在精灵序列中寻址，选出两个精灵并按框的阅读序透明叠加。

输入结构
- 背景网格上有两个同色一格厚矩形框，框内外都散布着标记色像素，框外的同色标记是干扰项。
- 网格上另散布若干彩色精灵，各精灵的外接矩形尺寸相同，且不含框色与标记色。

规则
- 分别统计两个框内部严格包含的标记像素数 N1、N2（框按阅读序取先后）。
- 将精灵按其外接矩形左上角的阅读序编号为 1, 2, 3, …。
- 取第 N1 号与第 N2 号精灵，按外接矩形对齐、视背景为透明叠加，
  第一个框选中的精灵在上层。
- 输出为一个精灵外接矩形尺寸的网格。

关键洞察
- 框内计数不是要渲染的结果而是索引：它指向"第几个精灵"；
  两个计数各选一层，框的先后决定遮挡关系。
```

## 4. 射线连锁激活下落

- 参考题目: `73c3b0d8`, `c92b942c`
- tags:
  - operation:平移, shift
  - operation:射线延伸, ray_extend
  - object:触发条, trigger_bar
  - object:移动像素, moving_pixel
  - object:种子像素, seed_pixel
  - relation:连锁激活, chain_activation
  - condition:射线命中才下落, ray_hit_enables_fall
  - condition:诱饵重力, gravity_decoy

### docstring

```text
从紧贴横条上方的种子像素出发，让对角射线逐轮唤醒悬浮像素下落，未被唤醒者保持悬浮。

输入结构
- 一种前景色构成一根全宽横条。
- 另一种前景色是若干悬浮像素，每列至多一个。
- 恰有一个悬浮像素已位于横条正上方一格，作为种子。

规则
- 已落地的像素（起初只有种子）沿两条向上对角方向发射射线直至网格边缘。
- 射线经过位置上的悬浮像素被激活，竖直落到自身列横条正上方一格，落地后同样发射射线。
- 反复传播直到没有新的激活。
- 输出画出所有落地像素、所有落地像素的对角射线痕迹（只染仍为背景的格，用绿色痕迹色），
  未被任何射线经过的悬浮像素保持原位；横条不变。

关键洞察
- 这不是整体重力：下落资格由射线的连锁传播决定，与横条的距离无关；
  "所有像素都会落下"的重力解读会在存在未被唤醒像素的示例上失效。
```

## 5. 同色传送门寻路

- 参考题目: `cc9053aa`, `40853293`
- tags:
  - operation:寻路, pathfinding
  - operation:重涂色, recolor
  - object:轨道路径, track_path
  - object:端点, endpoint
  - object:传送门, portal
  - relation:同色配对, same_color_pairing
  - condition:最短路径唯一, unique_shortest_path
  - condition:诱饵绕行路, detour_decoy

### docstring

```text
把两栗色端点间的最短轨道路线染成栗色，路线可经同色像素对瞬移。

输入结构
- 黑底上有一条青色 4 连通轨道网络与恰好两个栗色端点像素。
- 轨道上嵌有若干对非青非栗的彩色像素，每种颜色恰好出现两次。
- 不使用瞬移时端点间也存在一条明显的连通路线（诱饵）。

规则
- 沿轨道 4 连通移动，走到某个彩色像素时可花一步瞬移到它的同色搭档处。
- 在所有可行走法中恰有一条步数最短的路线。
- 把该路线经过的青色格全部染成栗色；端点、彩色像素与未经过的轨道保持不变。

关键洞察
- 成对的彩色像素不是要连线的端点，而是改写轨道连通性的传送门；
  表面可走的绕行长路是诱饵，最短路必须穿过传送门。
```

## 6. 双块拼合填洞

- 参考题目: `44d8ac46`, `d5d6de2d`, `72322fa7`, `7acdf6d3`
- tags:
  - operation:填充, fill
  - operation:擦除, erase
  - operation:形状匹配, shape_match
  - object:灰色实心块, solid_gray_block
  - object:孔洞, hole
  - object:色块, color_piece
  - relation:双块拼合, two_piece_assembly
  - condition:旋转翻转全等, congruent_up_to_flip_rotation
  - condition:面积相等假配对, equal_area_decoy

### docstring

```text
把每个灰块孔洞用恰好两个散落色块经旋转翻转拼合填满，按拼合方案双色上色并吸走用掉的色块。

输入结构
- 黑底上有若干灰色实心块，每块内部含一个连通的黑色孔洞。
- 空地上散落若干实心单色小色块，颜色互不相同。
- 每个洞恰可由其中两个色块经旋转/镜像、互不重叠且恰好填满地拼合而成，
  且两块的选取与摆放方式唯一。
- 另有若干任何拼法都用不上的干扰色块，其中存在面积等于某洞面积、
  形状却与洞不全等的单块假诱饵。

规则
- 为每个洞找出唯一的双块拼合方案。
- 洞内像素按各块覆盖区域涂成对应色块的颜色。
- 被使用的色块从原位擦为背景；干扰色块与灰块保持不变。

关键洞察
- 洞形与任何单个色块都不全等：洞是两个色块的拼合像，
  配对与摆放由几何拼图关系唯一确定，面积相等的单块是诱饵。
```

## 7. 平铺多数投票差错地图

- 参考题目: `c92b942c`, `2037f2c7`, `f9d67f8b`, `c8b7cc0f`
- tags:
  - operation:差异提取, difference_extraction
  - operation:平铺, tiling
  - operation:汇总渲染, summary_render
  - object:瓦片, tile
  - object:损坏像素, corrupted_pixel
  - relation:多数投票, majority_vote
  - condition:原型从未画出, prototype_never_drawn
  - condition:瓦片级聚合, tile_level_aggregation

### docstring

```text
从九个瓦片中投票重建从未画出的原型图案，并输出一张 3x3 的瓦片级差错地图。

输入结构
- 网格恰为 3x3 个同尺寸瓦片的拼接，每个瓦片都是同一原型图案的副本。
- 每个副本至多有一个像素被改成了某种非背景的错误颜色，错误颜色可各不相同。
- 原型图案本身从未单独给出。

规则
- 对每个瓦片内坐标取九个瓦片的多数颜色，重建原型。
- 逐瓦片与原型比对，输出一个 3x3 网格：
  损坏瓦片对应格写入该瓦片中错误像素的颜色，完好瓦片对应格为背景 0。

关键洞察
- 答案不在像素层而在瓦片层：先靠跨瓦片多数投票凭空恢复原型，
  再把逐像素差异聚合成一张 3x3 的摘要图；原型与差错都不曾直接可见。
```
