## 1. 同步生长直至相遇

- 参考题目题号: 1（d753a70b）、5（6e453dd6）
- tags:
  - operation:膨胀, dilate
  - operation:模拟演化, simulation
  - object:菱形轮廓, diamond_outline
  - relation:相遇距离定半径, meeting_distance_sets_radius
  - relation:连锁因果, chained_causality
  - condition:碰撞停止, collision_stop
  - condition:边界裁剪不停止, clipping_no_stop

### docstring

```text
所有同色菱形轮廓同时逐层向外膨胀，任意两条轮廓相遇时双方永久停止，恰好共享的相遇格涂红。

输入结构：
- 单一背景色网格上有若干条同色的一格厚曼哈顿菱形轮廓，颜色全部相同，不提供任何颜色线索。
- 各轮廓初始半径与中心位置各异，部分轮廓可被网格边缘裁剪。
- 布局保证每条轮廓最终都会与至少一条其他轮廓相遇。

规则：
- 所有未停止的轮廓同时膨胀：每步半径加一，保持中心不变，重画一格厚轮廓。
- 某一步完成后，若两条轮廓出现共享格或四邻接，则这两条轮廓永久停止，其余轮廓继续膨胀。
- 两条轮廓恰好共享的相遇格涂红；被网格边缘裁剪不构成停止条件。
- 输出为全部轮廓停止后的最终画面。

关键洞察：
- 每条轮廓的最终半径不是统一步数，而是由它与邻居的相遇距离决定；后停者的半径依赖先停者何时停下，构成连锁因果。
- 边缘裁剪是诱饵：轮廓撞到网格边界并不会停，只有撞到另一条轮廓才会停。
```

## 2. 投影残迹重建

- 参考题目题号: 8（7df24a62）、11（2a5f8217）、13（8597cfd7）
- tags:
  - operation:计数, counting
  - operation:印章覆盖, stamp_overlay
  - object:模板对象, template_object
  - object:边缘投影条, edge_projection_bar
  - relation:直方图匹配, histogram_matching
  - condition:对象仅以投影出现, object_only_as_projection
  - condition:同尺寸模板排除捷径, same_bbox_decoy

### docstring

```text
根据网格边缘的两轴投影直方图，找出从未画出的隐藏对象并把匹配模板印回投影框定的位置。

输入结构：
- 黑色背景网格上散布若干彩色模板形状。
- 网格上边缘悬挂若干灰色竖条，左边缘悬挂若干灰色横条；被投影的对象本身从未出现在画面上。
- 至少有两个模板的外接框尺寸完全相同。

规则：
- 上边缘每根竖条的长度等于隐藏对象在该列的像素个数，左边缘每根横条的长度等于隐藏对象在该行的像素个数。
- 在所有模板中找出行、列像素直方图与边缘条完全吻合的唯一模板。
- 将该模板按原色印到由边缘条位置框定的行列区域内，并清除所有边缘灰条。

关键洞察：
- 灰条既不是装饰也不是分隔线，而是一个从未被画出的对象留下的两轴投影"影子"。
- 仅凭外接框尺寸无法确定答案，必须逐行逐列核对像素计数直方图。
```

## 3. 窗口指针链

- 参考题目题号: 7（54d9e175）、17（f8f52ecc）
- tags:
  - operation:填充, fill
  - operation:链式追踪, chain_following
  - object:分隔线, separator_line
  - object:窗口格, window_cell
  - object:标记像素, marker_pixel
  - relation:窗内偏移编码方向, offset_encodes_direction
  - condition:中心标记为终端, center_marker_terminal
  - condition:终端色定链上填色, terminal_color_fills_chain

### docstring

```text
每个窗口内标记像素偏离中心的方向构成指向相邻窗口的指针，整个窗口填充为指针链终端窗口的标记颜色。

输入结构：
- 灰色分隔线把网格划分为窗口阵列，每个窗口为 3x3。
- 每个窗口内恰有一个彩色标记像素，位于窗口九格之一，各窗口标记颜色互不约束。
- 指针关系保证无环，且每条链都能到达某个终端窗口。

规则：
- 标记偏离窗口中心的方向（八方向）指向对应方向的相邻窗口，构成指针；标记恰在窗口正中心的窗口为终端。
- 每个窗口沿指针链一路走到终端，整个窗口填充为该终端窗口标记像素的颜色。
- 终端窗口填充自身标记色；灰色分隔线保持不变。

关键洞察：
- 标记像素的颜色在非终端窗口全是诱饵，真正携带信息的是标记在窗口内的相对位置。
- 每个窗口的填色不由自身决定，而由它所属指针链的终点统一决定。
```

## 4. 嵌合后的余隙

- 参考题目题号: 4（6a1e5592）、8（7df24a62）、18（66f2d22f）
- tags:
  - operation:平移, translate
  - operation:旋转, rotate
  - operation:镜像, mirror
  - operation:重涂色, recolor
  - object:孔洞, hole
  - object:精灵体, sprite
  - relation:互补拼合, complement_fit
  - condition:唯一无冲突放置, unique_collision_free_placement
  - condition:余隙即答案, leftover_is_answer

### docstring

```text
把游离拼块经旋转镜像唯一地嵌入容器孔洞并涂成容器色，再把仍未被覆盖的孔洞格全部涂绿。

输入结构：
- 黑色背景上有一个大的单色实心容器形状，其外接框内含若干黑色孔洞。
- 容器之外散落若干灰色拼块，每块形状各异。

规则：
- 每个拼块经过旋转或镜像后，存在唯一一个放置位置，使其完全落在孔洞内，且不与容器及其他已放拼块冲突。
- 放置全部拼块后，把拼块重涂为容器色，使放置痕迹在输出中完全消失。
- 孔洞中仍未被任何拼块覆盖的格子全部涂绿。

关键洞察：
- 输出里看不出任何一块拼块放在了哪里，唯一可见的答案是"放置之后剩下的空隙"。
- 必须先完整解出全部拼块的唯一嵌合方案，才能反推出哪些格子是余隙；绿格是嵌合过程的补集残迹。
```

## 5. 标记压力缩放

- 参考题目题号: 9（522fdd07）、13（8597cfd7）、19（54db823b）
- tags:
  - operation:缩放, resize
  - operation:计数, counting
  - object:奇数边正方形, odd_side_square
  - object:稀疏标记, sparse_marker
  - relation:标记层级定方向, marker_layer_sets_direction
  - relation:标记个数定幅度, marker_count_sets_magnitude
  - condition:边长循环回绕, side_length_wraparound

### docstring

```text
每个实心正方形按内部标记像素的位置层级决定膨胀或收缩方向、按标记个数决定步数，边长在奇数环上循环回绕。

输入结构：
- 单一背景色网格上有若干实心奇数边长正方形，边长属于集合 1、3、5、7、9。
- 每个正方形内散布少量标记像素，颜色各异，均不同于正方形色和背景色。
- 每个正方形的标记要么全部位于正方形最外圈，要么全部位于严格内部。

规则：
- 标记全在最外圈的正方形膨胀，标记全在严格内部的正方形收缩。
- 变化步数等于该正方形内标记像素的个数，每步边长变化二。
- 边长在环 1-3-5-7-9 上循环：收缩越过一绕回九，膨胀越过九绕回一。
- 每个正方形的中心与颜色保持不变，所有标记像素在输出中消失。

关键洞察：
- 标记的颜色是诱饵，真正携带信息的是标记相对正方形的位置层级（决定方向）与个数（决定幅度）。
- 边长的环形回绕使得大幅变化不能用"膨胀就一直变大"的直觉外推，必须严格按环计算。
```

## 6. 形状配对字典

- 参考题目题号: 2（f2829549）、11（2a5f8217）、15（dbff022c）
- tags:
  - operation:形状匹配, shape_matching
  - operation:重涂色, recolor
  - operation:裁剪, crop
  - object:分隔线, separator_line
  - object:模板对象, template_object
  - relation:形状配对导出色映射, shape_pairing_derives_color_map
  - condition:位置打乱防捷径, shuffled_positions
  - condition:映射含互换对, swap_pairs_in_mapping

### docstring

```text
用上、中两层物体的形状配对关系提取隐藏的颜色字典，再把该字典应用到下层图案并单独输出。

输入结构：
- 两条水平灰线把网格分为三层面板。
- 上层含若干彩色形状；中层含与上层完全相同的形状多重集，但颜色全部更换且位置彻底打乱，映射中存在互换对（如红换蓝且蓝换红）。
- 下层是一幅用上层颜色绘制的图案。

规则：
- 把上、中两层的物体按归一化形状（外接框内像素掩码，位置无关）一一配对，得到"上层色到中层色"的颜色映射。
- 将该映射逐格应用到下层图案。
- 输出仅为换色后的下层面板，去掉灰线与上两层。

关键洞察：
- 颜色字典不是以图例形式直接给出的，而是隐藏在两层物体的形状配对关系之中。
- 按位置对应与颜色恒等都是诱饵；互换对使得部分猜对映射也会全盘出错，必须完成全部形状配对。
```
