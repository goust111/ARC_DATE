## 1. 风车残片互补

- 参考题目题号: `043-1 (ed98d772)`、`043-2 (3a25b0d8)`、`043-14 (e3497940)`
- tags:
  - operation:旋转, rotate
  - operation:补全, completion
  - operation:透明叠加, transparent_overlay
  - object:精灵体, sprite
  - object:残迹, residue
  - relation:四旋转互补, four_rot_complement
  - condition:任何单象限不完整, no_single_quadrant_complete

### docstring

```text
将 2h×2h 网格视为同一隐藏精灵的四个旋转残片组成的风车，取旋转归位后的并集补全全部四个象限。

输入结构：
- 网格边长为偶数，画面上没有任何分隔线；四个 h×h 象限分别是同一多色精灵
  按风车方位（左上原样、右上逆时针90°、左下180°、右下顺时针90°）的旋转副本。
- 每个副本都被擦除了一部分像素（置为背景），任何单个象限都不完整，
  任何两个象限的并集也不完整。
- 精灵的每个像素至少在一个象限中保留。

规则：
- 识别四象限之间的旋转对应关系，将各象限逆变换回同一坐标系并取像素并集，
  重建完整精灵。
- 按同一风车方位把完整精灵的四个旋转副本写回四个象限，
  输出补全后的整幅网格。

关键洞察：
- 画面上从未出现完整精灵，它只能由分散在四个旋转坐标系中的残迹取并得到；
  补全的依据是象限之间的旋转互补，而非任何单象限内部的对称。
```

## 2. 缺口写成的字

### docstring

```text
点阵网格中缺失的交叉点在"格线坐标系"下构成一幅缩小的图画，按交叉点行列尺寸输出。

输入结构：
- 一种线色构成周期规整的水平与垂直格线，格线在网格边界处可被任意裁断；
  交叉点中有若干处被背景色取代（缺失）。
- 格内单元里散布若干其他颜色的标记像素，这些标记自身也拼得出
  貌似有意义的图案。

规则：
- 找出格线所在的行位置与列位置，得到交叉点阵列的行数 R 与列数 C。
- 输出 R×C 网格：交叉点缺失的位置写线色，交叉点完好的位置写背景色。
- 格内标记像素与输出无关。

关键洞察：
- 真正的图画写在"哪个交叉点不在"这一负空间里，且必须在降采样后的
  交叉点坐标系中阅读；格内醒目的彩色标记是诱饵。
```

## 3. 视线公投

- 参考题目题号: `043-17 (39a8645d)`、`043-8 (9565186b)`、`043-19 (1d398264)`、`043-1 (ed98d772)`
- tags:
  - operation:射线检测, ray_casting
  - operation:计数, counting
  - operation:旋转, rotate
  - operation:裁剪, crop
  - object:箭头标记, arrow_marker
  - object:精灵体, sprite
  - relation:视线可达, line_of_sight
  - condition:有效票多数定旋转, valid_vote_majority_rotation
  - condition:忽略干扰项, ignore_distractors

### docstring

```text
只有射线能击中大精灵的箭头才是有效选票，按有效票的多数朝向把裁剪后的大精灵旋转输出。

输入结构：
- 网格上有一个多色大精灵和若干形状同构的四像素小箭头，
  箭头只有上、右、下、左四种朝向。
- 每支箭头沿其指向发出的直线射线，要么击中大精灵的前景像素，
  要么径直射出网格边缘。
- 击中者（有效票）中恰有一种朝向严格多数；
  全体箭头的朴素多数朝向不总与有效票多数一致。

规则：
- 对每支箭头沿其朝向作射线检测：击中大精灵前景像素者记为有效票，
  射出边缘者作废。
- 统计有效票的四种朝向，取唯一多数朝向。
- 将大精灵裁剪至紧致包围盒，按"上=0°、右=顺时针90°、下=180°、
  左=逆时针90°"旋转后输出。

关键洞察：
- 箭头的投票资格由几何视线裁定，计票结果落在旋转参数空间而非图形本身；
  直接清点全部箭头、或以为输出是高频小图形，都是诱饵。
```

## 4. 对称者入殿

- 参考题目题号: `043-6 (72ca375d)`、`043-13 (dd6b8c4b)`、`043-7 (ff72ca3e)`、`043-10 (952a094c)`
- tags:
  - operation:聚集, gather
  - operation:擦除, erase
  - operation:计数, counting
  - operation:填充, fill
  - object:空心矩形, rectangular_frame
  - object:精灵体, sprite
  - object:干扰体, distractor
  - relation:切比雪夫距离, chebyshev_dist
  - condition:对称性裁定迁移, symmetry_gates_migration
  - condition:距离排序填充, distance_ranked_fill

### docstring

```text
只有自身具有对称性的精灵才被拆解迁入空心矩形，按离矩形从近到远的次序把各自的像素数写成彩条逐行排入内部。

输入结构：
- 背景网格上有一个一像素厚的空心矩形，以及若干互不相邻的单色精灵，
  颜色、大小各异。
- 一部分精灵具有轴对称或旋转对称，其余精灵不具有任何对称；
  矩形内部面积恰好等于所有对称精灵的像素总数。
- 各对称精灵到矩形边框的最小切比雪夫距离互不相同。

规则：
- 判定每个精灵是否具有（水平、垂直、对角或旋转）对称，
  仅对称精灵参与迁移，其余原地保留。
- 将对称精灵按到矩形的距离从近到远排序，依次把每个精灵的像素数量
  写成该精灵颜色的连续段，按行优先顺序填满矩形内部。
- 迁移精灵的原位置清为背景，矩形本身不变。

关键洞察：
- 谁移动由形状对称性裁定，而非颜色或大小；矩形内的彩条既编码了
  各精灵的像素计数，又按空间远近编码了排列次序。
```

## 5. 相向而行的光

- 参考题目题号: `043-19 (1d398264)`、`043-3 (253bf280)`、`043-12 (6bcdb01e)`
- tags:
  - operation:射线延伸, ray_extension
  - operation:填充, fill
  - object:实心方块, filled_square
  - object:射线, ray
  - relation:罗盘方向, compass_direction
  - relation:共线相向配对, collinear_facing_pair
  - condition:相向截停中分, facing_rays_split_gap
  - condition:无对手照到边缘, unopposed_ray_to_edge

### docstring

```text
每个 3×3 实心方块的八个外围格向罗盘方向发光，相向的两道光在中途各染半程会合，无对手的光一直照到边缘。

输入结构：
- 背景网格上有两个以上颜色互不相同的 3×3 实心单色方块。
- 若两个方块存在共线（同行、同列或同对角线）且方向相对的一对发射格，
  则这两格之间的空格数为偶数。
- 任意两条不相向的光线路径互不相交。

规则：
- 每个方块的八个非中心格沿其相对中心的罗盘方向向外发射光线，
  用方块自身颜色涂过沿途背景格。
- 若某条光线的正前方存在另一方块相向发射的光线，两者各自涂满
  两发射格之间自己一侧的一半空格后停止。
- 没有相向对手的光线一直涂到网格边缘。

关键洞察：
- 光线是同时推进的流：只有严格共线且方向相对的发射格才会彼此截停，
  会合点固定在两方块的正中；其余光线仍遵循照到边缘的默认规则。
```

## 6. 山河划界

- 参考题目题号: `043-13 (dd6b8c4b)`、`043-7 (ff72ca3e)`
- tags:
  - operation:重涂色, recolor
  - operation:距离场, distance_field
  - object:墙壁障碍, wall_barrier
  - object:源像素, source_pixel
  - relation:可达性, reachability
  - relation:测地最近归属, geodesic_nearest_assignment
  - condition:等距留白, tie_stays_floor

### docstring

```text
以穿墙不可行的最短步数为准，把每个地板格划归离它更近的那个颜色源，等距之处留作边界。

输入结构：
- 网格由地板色、墙色和两个颜色不同的源像素组成，
  墙把地板分隔成弯曲的通路。
- 所有地板格都至少与一个源连通。

规则：
- 对每个源做只许走地板、四连通的最短距离测量，墙不可穿越。
- 每个地板格染成距离严格更近的那个源的颜色；
  两源距离相等的地板格保持地板色。
- 墙与两个源像素原样保留。

关键洞察：
- 分界线由绕墙的真实路径距离决定，而非直线远近：无墙时边界是笔直的
  中垂带，一旦有墙，领地会顺着通道深入到看似属于对方的一侧。
```

## 7. 手风琴校对

- 参考题目题号: `043-14 (e3497940)`、`043-9 (e7a25a18)`
- tags:
  - operation:折叠, fold
  - operation:镜像, mirror
  - operation:透明叠加, transparent_overlay
  - object:分隔线, separator_line
  - object:面板, panel
  - relation:奇偶交替镜像, parity_alternating_mirror
  - condition:冲突标红, conflict_marked_red
  - condition:一致保留原色, agreement_keeps_color

### docstring

```text
把被多条竖直分隔线等分的网格自右向左手风琴式折叠到最左板上，逐格校对各层前景：一致保留原色，冲突标红。

输入结构：
- k 条（k≥2）同色竖直分隔线把网格等分成 k+1 块等宽面板。
- 各面板含若干前景像素，前景可跨多种颜色。

规则：
- 以最左板为底，其余面板按手风琴折叠映射依次叠上：与底板相邻的板
  水平镜像，再下一板恢复原向，如此按板序奇偶交替。
- 对底板每一格收集所有层落在该格的前景像素：全为同色则写该色，
  出现不同色则写红色，无前景则写背景色。
- 输出尺寸等于单块面板。

关键洞察：
- 各板到底板的坐标映射按板序奇偶交替镜像，这一点只能从多板冲突的
  位置反推出来；输出编码的是层间一致性判决，而非任何单层的内容。
```
