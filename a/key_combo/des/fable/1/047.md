## 1. 散点计数拨动的区域色轮

- 参考题目题号：880c1354、a934301b、2601afb7
- tags:
  - operation:重涂色, recolor
  - operation:循环轮换, cyclic_shift
  - operation:计数, counting
  - operation:擦除, erase
  - object:分隔结构, divider_structure
  - object:分离区域, separated_region
  - object:标记像素, marker_pixel
  - relation:环绕角度排序, angular_order_around_center
  - condition:计数决定轮转步数, count_sets_shift_steps

### docstring

```text
围绕分隔结构将各区域颜色顺时针轮转，轮转步数等于画面中散布的灰色标记像素总数。

输入结构：
- 网格中央有一个固定颜色的分隔结构，输出中保持不变。
- 其余非背景颜色构成若干彼此分离的单色 4 连通区域，环绕分隔结构分布。
- 背景上另散布若干孤立的灰色标记像素，不与任何区域相邻。

规则：
- 保持分隔结构与所有区域的形状、位置不变。
- 以分隔结构质心为圆心，按屏幕坐标顺时针方向对各区域的质心角排序，得到循环序。
- 数出灰色标记像素总数 k，所有区域的颜色沿该循环序整体顺时针推进 k 步。
- 输出中删去全部灰色标记像素。

关键洞察：
- 单看首个示例会以为是固定一步轮转；步数其实不是常数，而是由与区域毫无
  接触的散点计数编码的参数，散点只是"旋钮"，用后即弃。
```

## 2. 射线定序的字形折线解码

- 参考题目题号：2f767503、136b0064、505fff84
- tags:
  - operation:射线延伸, ray_extend
  - operation:解码指令, decode_instructions
  - operation:连线, draw_polyline
  - operation:擦除, erase
  - object:标记条, marker_bar
  - object:控制像素, control_pixel
  - object:字形指令, glyph_instruction
  - relation:射线命中, ray_intersection
  - relation:顺序读取, sequential_reading
  - condition:命中定序, hit_order_defines_reading
  - condition:编码映射, encoding_map

### docstring

```text
沿标记条指向的射线依命中顺序读取字形指令，在空画布上画出对应折线。

输入结构：
- 背景上散布若干 3x3 单色字形。
- 另有一个三像素直标记条和一枚紧贴条中点的控制像素。

规则：
- 从标记条中点向背离控制像素的方向发出直线射线。
- 只有包围盒被射线穿过的字形参与解码，按沿射线的先后排序；
  未被穿过的字形全部忽略。
- 字形像素数编码一段笔画：4 → 向上 2 格，5 → 向右 3 格，
  6 → 向下 3 格，7 → 向左 2 格；笔画颜色取该字形自身颜色。
- 在同尺寸空画布上，以标记条中点为起点顺次连画各段，每段从上一段终点
  继续；输入中的字形、标记条与控制像素都不保留。

关键洞察：
- 字形排布貌似杂乱，读取顺序既不是行序也不是列序，而是由射线的空间
  命中顺序定义；未被射线穿过的字形是诱饵。
```

## 3. 隐形矩形对称差选区

- 参考题目题号：d22278a0、7ee1c6ea、15113be4
- tags:
  - operation:重涂色, recolor
  - operation:擦除, erase
  - object:角标记像素, corner_marker
  - object:隐式矩形, implicit_rectangle
  - object:内容像素, content_pixel
  - relation:同色成对, same_color_pairing
  - relation:区域重叠, region_overlap
  - condition:覆盖奇偶决定去留, coverage_parity_decides

### docstring

```text
同色角标记对张成的隐形矩形按覆盖奇偶构成选区，作用于散布的内容像素：
单覆盖换色，双覆盖与区外擦除。

输入结构：
- 背景网格上有两类前景：若干彩色角标记孤立像素与大量散布的青色内容像素。
- 每种角标记颜色恰好出现两次，位于某个矩形的一对对角上；矩形本身从未画出。

规则：
- 每对同色角标记张成含端点的隐形实心矩形区域。
- 恰好落在一个矩形内的内容像素，重涂为该矩形（角标记）的颜色。
- 同时落在两个矩形内的内容像素擦为背景；不在任何矩形内的内容像素也擦为背景。
- 输出中角标记像素本身全部删除。

关键洞察：
- 参与规则的矩形从未被完整画出，画面上只有它的两粒生成元；矩形互不相交
  且内容点都落在矩形内的示例看似"包围盒内换色"，重叠示例暴露出真正的
  选区是矩形族的对称差。
```

## 4. 跨面板高度阶梯上的变色标记推进

- 参考题目题号：48634b99、9b5080bb、2601afb7
- tags:
  - operation:重涂色, recolor
  - operation:标记推进, marker_advance
  - object:面板, panel
  - object:竖直条, vertical_bar
  - object:标记段, marker_segment
  - relation:尺寸排序, size_ordering
  - relation:所属面板, panel_membership
  - condition:半段位置保持, half_position_kept
  - condition:对侧面板色, opposite_panel_color

### docstring

```text
标记半段沿全局高度阶梯推进到下一根更高的条，其新颜色由目的条所在面板
反推出的对侧面板底色决定。

输入结构：
- 网格被分成两个大面板，各有自己的面板底色。
- 两个面板里共同散布若干一格宽、底端对齐、高度互不相同的共享色竖条。
- 恰有一根条的上半段或下半段被涂成标记色，该标记色恒等于源条所在面板的
  对侧面板底色。

规则：
- 把当前标记半段涂回条的共享色。
- 在两个面板的全部竖条中，找到高度紧邻大于源条的那一根（全局排序，不分面板）。
- 将目的条的同侧半段（上/下与源一致）重涂为目的条所在面板的对侧面板底色。

关键洞察：
- 高度阶梯跨面板延续，标记的新颜色不是常数：它由目的条身处哪个面板反推
  出对侧面板色。首个示例中标记恰好换了面板，会误以为标记色固定不变。
```

## 5. 色彩指引作为地址表

- 参考题目题号：7c008303、20981f0e、b1fc8b8e
- tags:
  - operation:平移对齐, translate_align
  - operation:擦除, erase
  - object:色彩指引块, color_guide
  - object:精灵体, sprite
  - object:象限, quadrant
  - relation:指引色映射象限, guide_maps_quadrant
  - relation:格元内居中, centered_within_cell
  - condition:指引即地址, guide_as_address
  - condition:无址即弃, unlisted_color_discarded

### docstring

```text
2x2 色彩指引不改颜色而改位置：每个精灵被搬到指引中同色格所对应的画布
象限中央，颜色不在指引里的精灵被丢弃。

输入结构：
- 网格某处有一个 2x2 四色指引块。
- 其余前景是若干散落的小型单色精灵，颜色互不相同。

规则：
- 将画布按 2x2 宏布局分成四个象限，与指引块的四个格一一对应。
- 颜色出现在指引中的精灵保持形状与颜色，平移到对应象限，使其包围盒
  中心与该象限中心重合。
- 颜色不在指引中的精灵整体删除；指引里没有对应精灵的颜色格不产生输出。
- 指引块本身删去，原精灵位置清空。

关键洞察：
- 与"指引给区域上色"的常见读法相反，这里颜色是精灵的名字、指引是
  地址表；指引块查询的是"去哪"，而不是"变什么色"。
```

## 6. 箭头连锁擦除

- 参考题目题号：2f767503、505fff84、a934301b
- tags:
  - operation:射线延伸, ray_extend
  - operation:擦除, erase
  - object:标记条, marker_bar
  - object:控制像素, control_pixel
  - object:箭头对象, arrow_object
  - relation:射线命中, ray_intersection
  - relation:链式传递, chain_propagation
  - condition:命中即整体擦除, hit_erases_whole
  - condition:连锁反应, chain_reaction

### docstring

```text
从灰色起始箭头出发的射线触发连锁：每个被命中的箭头整体消失并沿自身
指向再射一线，未卷入连锁的箭头原样保留。

输入结构：
- 背景上分布若干"箭头对象"：三像素直条加一枚贴在条中点旁的控制像素，
  各箭头颜色互不相同。
- 其中恰有一个灰色箭头是起点。

规则：
- 灰色箭头从条中点沿背离其控制像素的方向发出直线射线。
- 射线首个命中的尚存箭头被激活：该箭头整体擦除，并从它自己的条中点
  沿它自己的指向再发一条射线；已擦除的箭头不再阻挡后续射线。
- 依此连锁，直到某条射线不再命中任何箭头而射出边界为止。
- 输出：所有被激活的箭头（含灰色起点）擦为背景，未被命中的箭头保持不变。

关键洞察：
- 擦除集合不是"被起点射线扫到的一切"，而是一条因果链：每个牺牲者的
  姿态决定下一个牺牲者，链外近旁的箭头只是诱饵。
```

## 7. 带符号标记计数查表换色

- 参考题目题号：a934301b、2601afb7、7c008303
- tags:
  - operation:重涂色, recolor
  - operation:计数, counting
  - operation:擦除, erase
  - object:前景对象, foreground_object
  - object:标记像素, marker_pixel
  - object:色板行, palette_row
  - relation:标记包含于对象, marker_in_object
  - relation:有序槽位, ordered_slots
  - condition:净值索引色板, signed_count_indexes_palette
  - condition:净零则擦除, zero_net_erases

### docstring

```text
对象内两种标记像素做带符号计数，净值作为顶部色板行的查表下标，净值
为零的对象整体擦除。

输入结构：
- 网格顶行从左到右排着若干色板格，与画面主体以空行隔开。
- 画面主体为背景加若干分离的同色 4 连通对象，对象内嵌少量灰色与橙色
  标记像素。

规则：
- 对每个对象数出灰色标记数减橙色标记数的净值 k。
- k > 0 时，该对象的全部像素（含标记位）整体重涂为色板行左起第 k 个颜色。
- k = 0 时，该对象整体擦为背景。
- 色板行保持不变。

关键洞察：
- 两种标记不是两类装饰而是一对正负号；查表下标是它们的代数净值。只含
  正标记的示例会诱导"数点查表"的读法，混合示例暴露相减关系，净零对象
  则连查表资格都被抵消。
```
