## 1. 碎片织带补全

- 参考题目: 1、9、16
- 难度评审: 达标偏上
- tags:
  - operation:补全, complete
  - operation:重涂色, recolor
  - object:线段片段, segment_fragment
  - object:双色行, two_color_row
  - relation:区间重叠拼接, overlap_stitching
  - relation:列对齐, col_alignment
  - condition:等价类角色序列, role_equivalence
  - condition:非周期防延拓, aperiodic_sequence

### docstring

```text
把每条水平双色残段沿一条从未完整出现的隐藏角色序列补成整行。

输入结构:
- 背景为主导色。每个非空行含且仅含一条连续的水平非背景线段，
  线段可从任意列开始、到任意列结束，不存在覆盖整行的线段。
- 每条线段内两种角色都出现，因而恰用两种颜色。
- 存在一个覆盖全宽的隐藏二值"角色序列"：每条线段内，同色格对应同角色、
  异色格对应异角色，且与角色序列在其区间上完全一致。
- 保证：所有线段的列区间两两链式重叠并合并覆盖整个宽度；
  角色序列不是任何短周期的重复。

规则:
- 利用线段间区间重叠处的同异色结构，把各线段的局部双色划分
  拼接成整幅宽度上统一的角色划分。
- 将每条线段所在的行补成整行：该行在角色A的所有列涂该线段中
  角色A的颜色，角色B同理。
- 全背景行保持不变。

关键洞察:
- 模板行从未被画出——它只以碎片形式分摊在各行的不同区间里；
  任何单独一行都不足以补全自身，必须把所有残段当作同一条隐藏
  织带的碎片来拼接；逐行周期延拓的直觉会失败，因为角色序列非周期。
```

## 2. 周界巡游的下一帧

- 参考题目: 16、3
- 难度评审: 达标
- tags:
  - operation:序列外推, sequence_extrapolation
  - object:面板帧, panel_frame
  - object:分隔行, separator_row
  - object:边框段, border_segment
  - relation:环形周期, cyclic_period
  - relation:等距堆叠, equally_spaced_stacking
  - condition:恒定周界步长, constant_perimeter_step
  - condition:拐角换向, corner_turning

### docstring

```text
沿面板边框的环形路径外推巡游图案，输出下一帧。

输入结构:
- 输入是由整行分隔线隔开的四个等尺寸面板的垂直堆叠，
  面板背景同色，面板内部为空。
- 每个面板中，全部非背景格构成一条贴着面板最外圈边框的连续图案带，
  带内各格颜色可不同且颜色序列不对称。
- 四帧中，图案带沿边框顺时针环形路径以恒定步数推进；
  颜色序列沿路径顺序保持不变。
- 保证：测试组的下一帧推进必然跨越至少一个拐角。

规则:
- 把面板最外圈按顺时针展开成循环路径，读出图案带及其恒定推进步长。
- 将图案带再推进一个步长，画在与单个面板同尺寸的空画布的边框上，作为输出。
- 图案跨越拐角时随路径转向，越过路径起点时回绕。

关键洞察:
- 分隔行把网格变成动画胶片，但运动不是平移——它发生在展开的边框环上；
  前几帧看似水平滑动的图案，在需要输出的一帧会拐过角、由横变竖，
  只有环形坐标下的恒定步长假设能同时解释所有帧。
```

## 3. 嵌套链里的颜色对流

- 参考题目: 8、13
- 难度评审: 达标
- tags:
  - operation:重涂色, recolor
  - object:封闭区域, enclosed_region
  - object:连通分量, connected_component
  - relation:内部包含, interior_containment
  - relation:深度反序重排, depth_reversal
  - condition:链内颜色对流, in_chain_color_convection

### docstring

```text
在每条"洞中有物"的嵌套链内，让对象颜色沿深度反序对流，形状与位置保持不动。

输入结构:
- 背景主导；前景由若干互不相触的单色连通体组成。
- 部分对象构成嵌套链：对象B整体位于对象A的封闭背景孔内，
  B的孔内还可以有更深的C，链深可达三层以上；同图可有多条互不嵌套的链。
- 另有若干不含也不被含的独立对象。
- 链内各对象颜色互异；对象面积与深度无单调关系。
- 保证：存在深度为三层以上的链；两层链使"里外颜色互换"与
  "全局颜色映射"两种假设在别的链上失效；独立对象的颜色也在某条链中出现。

规则:
- 找出所有嵌套链：按"位于封闭孔内"的包含关系给链上对象定深度。
- 每条链内，把颜色序列按深度反转重排：最深对象的颜色涂给最外层对象，
  次深的涂给次外层，依此类推；对象形状与位置不变。
- 独立对象与背景保持原样。

关键洞察:
- 变化的不是形状而是颜色的"漂浮"——颜色沿各自的嵌套链对流到
  镜像深度的对象上；两层链表现为里外互换，容易误读为全局颜色对换
  或图例映射，但三层链的中间层不动、颜色相同的独立对象不参与，
  只有"按链内深度反序"能同时解释一切。
```

## 4. 标记半区的货舱

- 参考题目: 18、2、5
- 难度评审: 达标
- tags:
  - operation:重力下落, gravity_drop
  - operation:擦除, erase
  - object:分隔列, separator_column
  - object:可动对象, movable_object
  - object:障碍物, obstacle
  - object:标记像素, marker_pixel
  - relation:标记对齐指定半区, marker_selects_half
  - relation:同坐标转运, same_coordinate_transfer
  - condition:碰撞停止, collision_stop
  - condition:刚体整体下落, rigid_body_fall

### docstring

```text
把未标记半区的可动对象按原坐标搬进有标记的半区，再让所有可动刚体落到底。

输入结构:
- 一条全高的单色分隔列把网格分成同尺寸的左右两半。
- 每半各含：触及底边的固定障碍结构（每半唯一的触底非背景色），
  以及若干4连通的可动色刚体。
- 恰有两个标记色像素，同处一个半区，标记色全图唯一且不属于任何对象。

规则:
- 含标记的半区为容器：保留其障碍与可动对象，把标记像素涂回背景。
- 把另一半区的全部可动对象按相同的行列坐标复制进容器半区
  （保证不与容器内容重叠），该半区的障碍被弃置。
- 在容器内反复将任一可整体下移一格的可动刚体下移一格
  （被障碍、底边或已停对象挡住即停），直至不动点；
  保证结果与结算顺序无关。
- 输出为容器半区的最终画面，尺寸等于半个输入（不含分隔列）。
- 保证：示例中被弃置半区的障碍若参与结算会改变结果；
  且存在带悬空突出部的刚体使逐列坠落与刚体坠落不同。

关键洞察:
- 分隔列不是对称轴也不是逐像素合并的掩码——两半不平权：
  标记挑出唯一的物理舞台，另一半只是货物清单，它自己的地形被整体丢弃；
  且下落是刚体整体的，逐列独立坠落会得到错误的堆叠。
```

## 5. 空腔的异类

- 参考题目: 4、15、8、20
- 难度评审: 达标
- tags:
  - operation:裁剪, crop
  - operation:重涂色, recolor
  - object:封闭区域, enclosed_region
  - object:杂色前景, clutter_foreground
  - relation:图底反转, figure_ground_reversal
  - relation:形状多重集比较, shape_multiset_compare
  - condition:不触边即封闭, enclosed_iff_not_touching_border
  - condition:异常值选择, outlier_selection

### docstring

```text
把被前景围死的背景空腔当作对象比较形状，找出形状独一无二的那个空腔，
以围住它的对象的颜色输出其紧致剪影。

输入结构:
- 前景占据画面大部，由多个多色团块与零散噪点组成；背景色唯一。
- 背景连通区域分两类：与网格边界连通的外部背景与海湾，
  以及被前景4连通封死、不触任何边界的内部空腔。
- 空腔按平移全等分组：恰有一种形状只出现一次，其余每种形状至少出现两次。
- 保证：每个空腔的全部4邻前景像素同属一个单色连通体；
  面积最大的空腔不是答案；存在面积大于答案空腔的开放海湾；
  最大前景连通体的裁剪与正确输出不同。

规则:
- 收集所有不与边界连通的背景空腔，按形状（平移全等）分组。
- 取形状仅出现一次的那个空腔。
- 输出其最小包围盒裁剪：空腔格涂成包围它的那个前景连通体的颜色，
  盒内其余格为背景。

关键洞察:
- 要比较的对象从未被画出——必须先做图底反转，把前景中的"空"
  当作形状收集起来，再在负空间的形状多重集里找异类；
  显眼的最大团块、最大空腔、深入内部的大海湾都是诱饵，
  答案由封闭性与形状唯一性两重筛选共同确定。
```

## 6. 双源涟漪的干涉

- 参考题目: 13、11、3
- 难度评审: 达标
- tags:
  - operation:填充, fill
  - object:锚点像素, anchor_pixel
  - object:颜色图例, color_legend
  - object:同心方环, concentric_ring
  - relation:距离映射, distance_mapping
  - relation:最近源归属, nearest_source
  - condition:切比雪夫距离, chebyshev_distance
  - condition:间隔一格的环, odd_distance_rings

### docstring

```text
以全体锚点的最近切比雪夫距离场为底，只在奇数距离处按图例依次画有间隔的方环。

输入结构:
- 背景主导；若干同色锚点像素散布；网格边缘有一条水平图例色条
  （颜色互异，不含锚色与背景色），与锚点分离。
- 图例长度L决定涟漪圈数。
- 保证：示例包含两锚场的干涉区，独立盖章假设与最小距离场假设
  在该区结果不同。

规则:
- 对每个非图例格，取它到所有锚点的切比雪夫距离的最小值d。
- 若d=2k-1且1<=k<=L，涂图例第k色；其余格保持背景。
- 锚点与图例原样保留，输出与输入同尺寸。

关键洞察:
- 不能把每个锚点的环独立盖章再叠加——在两锚靠近处，
  一个锚的环会被另一锚更小的距离"熄灭"，环因干涉出现缺口与融合；
  环与环之间隔一格的空隙和图例截止使距离场只显影一半。
```

## 7. 镜界的显影

- 参考题目: 7、9、12
- 难度评审: 达标
- tags:
  - operation:镜像, reflect
  - operation:拼接, concatenate
  - operation:擦除, erase
  - operation:重涂色, recolor
  - object:掩码像素, mask_pixel
  - object:精灵体, sprite
  - relation:纵向拼接, vertical_stacking
  - relation:依附取色, host_color_inheritance
  - condition:潜影仅镜中显形, latent_image_in_mirror

### docstring

```text
输出是输入的"下接行反转"镜像拼接，但灰色潜影团只在镜像半区显影，
并显影为各自所依附对象的颜色。

输入结构:
- 背景上有若干单色前景对象，以及若干4连通的灰色覆盖团；
  灰色全图仅作覆盖层使用，不构成对象。
- 每个灰团与恰好一个前景对象的像素4邻接触（依附于它）；
  不同灰团可依附不同对象。
- 保证：至少一个示例中灰团依附的对象不是离它包围盒最近的显眼对象，
  使"就近取色"失败；灰团的形状与依附对象形状无关。

规则:
- 输出画布高度为输入两倍。
- 上半 = 把输入中所有灰团涂回背景后的画面。
- 下半 = 上半的行反转镜像。
- 再把每个灰团显影到下半：团内每格映射到其行镜像位置，
  涂成该团所依附对象的颜色。

关键洞察:
- 镜像拼接不是对原输入整体做的——灰团是"只存在于镜中"的潜影：
  在本体半区它必须被抹除，在镜像半区它以宿主对象的颜色显形；
  单看上半这只是一道普通的镜像追加题，把两半逐格比对才会发现
  潜影的去向与取色规则，抹除、镜像、显影、色继承四层缺一不可。
```
