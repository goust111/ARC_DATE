## 1. 分块展开继承掩码对称

- tags:
  - operation:印章覆盖, stamp_overlay
  - operation:镜像, mirror
  - object:种子精灵, seed_sprite
  - object:掩码, placement_mask
  - object:分隔线, divider_line
  - relation:像素到块映射, pixel_to_block_mapping
  - relation:全局对称约束, global_symmetry_constraint
  - condition:对称类型决定副本朝向, symmetry_type_sets_copy_orientation

### docstring

```text
将分隔线一侧的不对称种子精灵按另一侧掩码做分块展开，且每个副本的朝向必须使整幅输出继承掩码自身的对称性（镜像或点对称）。

输入结构
- 一条单色满行或满列分隔线把网格分成两个面板。
- 小面板是一个不对称的单色种子精灵（含背景格）。
- 大面板是一个单色掩码，其前景分布或者关于中轴镜像对称，或者关于中心点对称；不同示例对的对称类型可以不同。

规则
- 输出为掩码的分块展开：掩码每格对应一个种子大小的块，背景格对应全背景块。
- 每个前景格的块内放置一个种子副本；副本经过恰当的翻转或 180 度旋转，使整幅输出与掩码具有完全相同的对称类型：镜像对称的掩码在轴两侧放互为镜像的副本，点对称的掩码在对径位置放互为 180 度旋转的副本。
- 分隔线与种子面板不进入输出。

关键洞察
- 展开出的副本并非同一朝向（把所有块都放原样种子是陷阱）；副本的变换方式不由位置查表决定，而是先识别掩码是镜像对称还是点对称，再由"整体输出必须继承该对称"这一全局约束唯一确定。
```

## 2. 按隐藏面积重排层序

- tags:
  - operation:排序, sorting
  - operation:补全, reconstruct
  - operation:计数, counting
  - object:空心矩形, hollow_rectangle
  - object:重叠层, overlap_layer
  - relation:遮挡层序, occlusion_order
  - condition:隐藏像素数定新层序, hidden_count_sets_new_order

### docstring

```text
重建每个被遮挡的空心矩形框，统计各框被盖住的像素数，并按"被遮挡越多越靠上"的新层序重新绘制整幅叠层。

输入结构
- 背景单色；每种前景色构成一个一格粗的空心矩形框。
- 各框相互重叠，重叠处只显示最上层框的颜色，每框至少有部分像素可见。
- 任意两框被遮挡的像素数互不相同。

规则
- 由每种颜色可见像素的包围盒重建该框的完整一格粗边框。
- 统计每框完整边框中不可见（被其他框盖住）的格子数。
- 在同尺寸背景画布上，按被遮挡数从小到大自底向上重新绘制所有完整框：被遮挡最多的框画在最顶层，重叠处按新层序显色。

关键洞察
- 新的叠放顺序与原图的可见层序无关（直接把原层序反转重绘是陷阱）；排序键是每个框"看不见的部分有多大"，而这必须先把从未完整出现的框重建出来才能计数。
```

## 3. 螺旋仪表守恒反推

- tags:
  - operation:计数, counting
  - operation:补全, reconstruct
  - operation:擦除, erase
  - object:仪表盘, gauge_input
  - object:竖管, tube
  - object:挡板, cover_plate
  - relation:总量守恒, quantity_conservation
  - condition:读数为全场总量, gauge_counts_global_total
  - operation:螺旋填充, spiral_fill

### docstring

```text
揭开被挡板盖住的竖管，按"螺旋仪表读数等于全场液体总量"的守恒关系补画出缺失的液柱。

输入结构
- 黑底网格中立着若干根互不相连的单格宽 U 形竖管（同一种管壁色），各管内部有自管底起的液柱，液位各不相同。
- 其中一根管的内部被一块异色实心挡板完全盖住。
- 网格另一处有一个分离的 3x3 仪表区，从左上角起沿顺时针螺旋连续填有若干格液体色。

规则
- 数出仪表上液体色的格数 k。
- 把所有可见液柱的格数求和，k 减去可见总和即被盖管内的液体格数。
- 去掉挡板，在该管内自管底向上画出这么多格液体色；管壁、其余液柱、仪表与背景保持不变。

关键洞察
- 仪表读数既不是被盖管的液位，也不是任何一根管的刻度，而是全场液体总量；被盖住的液柱从未被画出，只能靠总量守恒反推出来。
```

## 4. 三掩码恰一次投票

- tags:
  - operation:布尔运算, boolean_op
  - operation:裁剪, crop
  - object:分隔十字, separator_cross
  - object:掩码区域, mask_region
  - object:标记像素, marker_pixel
  - relation:分区, partition
  - relation:逐格对齐, cellwise_alignment
  - condition:恰好一次为真, exactly_one_hit

### docstring

```text
十字分隔出的四个象限中三个装有掩码，输出一个象限大小的网格，只在恰好被一个掩码占据的位置涂上标记像素的颜色。

输入结构
- 一种颜色构成整行加整列的实心分隔十字，把网格分成四个等大的象限。
- 其中三个象限各含一种前景色的散布掩码，三种掩码颜色互不相同。
- 剩下一个象限只含一个单独的标记像素；空槽象限的位置在不同示例对中可以不同。

规则
- 去掉十字，把三个掩码按各自象限内的位置逐格对齐。
- 输出一个象限大小的背景网格：某格若在三个掩码中恰好出现一次前景，则涂成标记像素的颜色。
- 出现零次、两次或三次的格保持背景。

关键洞察
- 交集、并集或奇偶（异或）都是陷阱——三个掩码同时为前景的格在奇偶下为真而在"恰一次"下为假；标记像素不参与叠加，它只提供输出颜色并指出哪个象限是空槽。
```

## 5. 状态序列的隐向续写

- tags:
  - operation:补全, complete
  - operation:外推, extrapolate
  - operation:重涂色, recolor
  - object:条带组, strip_group
  - object:列状态序列, column_state_sequence
  - relation:前缀匹配, prefix_matching
  - relation:方向无关同构, orientation_free_isomorphism
  - condition:书写方向需推断, writing_direction_inferred

### docstring

```text
以横贯顶部的完整条带的压缩列状态序列为模板，把网格中其余竖直条带沿各自隐藏的书写方向续写完整，续写部分涂蓝。

输入结构
- 黑底网格顶部有一条横贯整幅的水平前景条带，是完整模板；把它逐列压缩（每列前景格的偏移形态为一个状态，相邻重复状态合并）得到模板状态序列。
- 网格其余部分是同色的若干竖直短条带，彼此分离；每条是模板状态序列的一个前缀，但有的自其顶端向下书写，有的自其底端向上书写。

规则
- 保留所有已有前景格。
- 对每条竖直条带，分别按向下读与向上读压缩出两种状态序列，能与模板前缀对齐的那种即其书写方向。
- 沿该方向用蓝色续写模板剩余的状态直到网格边缘；若前缀已到达模板末状态，则以末状态延续到边缘。

关键洞察
- 各条带真正共享的不是逐格图案，而是抽象的压缩状态顺序——它与条带的横竖方向和书写朝向都无关；必须先推断出隐藏的书写方向，才知道该续写哪一段、往哪个方向写。
```

## 6. 镜像补全模板的定向盖印

- tags:
  - operation:印章覆盖, stamp
  - operation:镜像, mirror
  - operation:旋转, rotate
  - object:半幅精灵, half_sprite
  - object:分隔列, divider_column
  - object:槽位, slot
  - object:记号对, mark_pair
  - relation:轴对称补全, axial_completion
  - condition:双标记锚定旋转, marker_pair_anchors_rotation

### docstring

```text
以分隔列为镜像轴补全从未画完整的模板精灵，再按槽内双像素标记锚定的旋转朝向，把完整精灵盖印进右侧对应槽位。

输入结构
- 一条满高单色分隔列把网格分成左窄右宽两部分。
- 左侧紧贴分隔列画着一个精灵的一半：主体单色，内含一个异色记号格；完整精灵是这一半关于分隔列的镜像拼合，因而含有一对对称的记号格。
- 右侧被均分成与完整精灵同尺寸的槽位；部分槽位内含两个异色标记像素，其构型恰好等于完整精灵的记号对在某个唯一旋转（0/90/180/270 度）下的位置。

规则
- 先把左半精灵关于分隔列镜像拼合，得到完整的正方形精灵。
- 对每个含标记的槽位，选择使记号对恰好落在两个标记像素位置上的旋转，把完整精灵以该朝向盖印满整个槽位，原标记被记号格覆盖。
- 无标记槽位、分隔列与左侧半精灵保持不变。

关键洞察
- 模板从未被完整画出——分隔列不只是布局分界，更是精灵的镜像轴；槽内的双像素标记也不只是"要不要盖印"的开关，它们的相对构型指定了印章的旋转朝向。
```
