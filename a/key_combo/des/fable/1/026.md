## 1. 孔数转环锁

- tags:
  - operation:重涂色, recolor
  - operation:计数, counting
  - object:同心正方形层, concentric_ring
  - object:钥匙精灵, key_sprite
  - relation:最外环色寻址, outermost_color_addressing
  - condition:孔洞数定循环步数, hole_count_sets_cycle_steps

### docstring

```text
用每把钥匙精灵的连通孔洞数，把与其同色配对的同心环系统的颜色沿嵌套序循环转动相应步数。

输入结构
- 黑色背景网格上分布若干组互不接触的同心矩形环系统；每组由一格厚的单色环
  逐层嵌套构成，同一系统内颜色可在更深层重复出现。
- 网格其余位置散布若干实心小方块（钥匙），每把钥匙内部含有若干个由背景色
  构成的连通孔洞。
- 每把钥匙的颜色恰好与唯一一组环系统的最外环颜色相同；钥匙颜色也可能与
  别的系统的某个内层环颜色相同，但那不是配对依据。

规则
- 按"钥匙颜色 = 最外环颜色"把钥匙与环系统一一配对。
- 对每组环系统，记录从外到内首次出现的去重颜色序，视为循环序。
- 数出配对钥匙内部的连通孔洞数 k，把该系统每种记录颜色替换为循环序中它
  前面第 k 位的颜色（即整组颜色沿嵌套序向外转 k 步）。
- 输出中擦除全部钥匙，环系统之外的背景保持不变。

关键洞察
- 钥匙不是要移动的对象而是参数载体：颜色是按最外环寻址的"锁孔"，孔洞数是
  转动步数；重涂是嵌套序上的循环移位，而不是任何固定的颜色映射表。
```

## 2. 蛇形传送带

- tags:
  - operation:放置, place
  - operation:计数, counting
  - object:分隔栅格, divider_grid
  - object:精灵体, sprite
  - object:障碍格, blocker_cell
  - relation:蛇形单元序, boustrophedon_cell_order
  - condition:像素数定步数, pixel_count_sets_steps
  - condition:障碍格剔除, blockers_excluded

### docstring

```text
把分隔栅格的单元格按蛇形顺序排成传送带，每个精灵沿传送带前进"自身像素数"个有效格。

输入结构
- 分隔色整行整列把网格划分成若干行若干列的等大单元格。
- 少数单元格内各有一个单色精灵（形状与像素数不一），若干单元格被灰色完全
  填满（障碍格），其余单元格为空。

规则
- 把单元格按蛇形顺序排列：最上一行从左到右，下一行从右到左，逐行折返。
- 从序列中剔除全部灰色障碍格，得到有效传送带序列。
- 每个精灵沿有效序列向前移动 n 个位置，n 等于该精灵自身的像素个数；
  移动后保持它在原单元格内的相对位置。
- 分隔线与障碍格保持不变，精灵原单元格清空。

关键洞察
- 行进路线既不是行优先也不是直线，而是蛇形折返且跳过障碍格的一维序列；
  步数不是常数，由每个精灵自身的像素数各自决定。
```

## 3. 骨牌导向光线

- tags:
  - operation:射线延伸, ray_extend
  - operation:描边连线, path_tracing
  - object:三角精灵体, triangle_sprite
  - object:双色多米诺, bicolor_domino
  - relation:朝向定初始方向, facing_sets_direction
  - relation:骨牌轴向即偏折矢量, domino_axis_is_turn_vector
  - condition:经骨牌接力换色, relay_recolor_at_domino
  - condition:忽略干扰项, ignore_distractors

### docstring

```text
从三角箭头尖端发出光线，撞上双色骨牌的一半就沿"被撞半格指向另一半格"的方向偏折并换色，直到走出网格。

输入结构
- 黑背景网格上有一个实心三角形箭头精灵，尖端指向某个正方向。
- 散布若干双色骨牌（两个正交相邻的异色格），横放或竖放；被光线撞到的骨牌
  总与光线来向垂直；另有一些骨牌不会被撞到，是干扰项。

规则
- 光线从箭头尖端正前方一格出发，沿尖端方向直行，把经过的背景格涂成当前
  光色；初始光色为箭头颜色。
- 光线撞到某个骨牌的一半时，新方向为"从被撞格指向另一半格"的方向
  （即转90度），随后从另一半格外侧继续直行，光色从此变为另一半格的颜色。
- 骨牌两格保留原色；重复直行与偏折，直到光线走出网格边缘；未被撞到的
  骨牌原样保留。

关键洞察
- 转向指令没有任何码表，它写在骨牌自身的几何里——骨牌的轴向就是偏折
  矢量；换色接力把路径按经过的骨牌切成分段，双色骨牌是"方向+颜色"的
  复合指令元。
```

## 4. 极值区域负片换装

- tags:
  - operation:平铺, tiling
  - operation:重涂色, recolor
  - object:种子图案, seed_pattern
  - object:分隔线, divider_line
  - relation:面积比较, area_comparison
  - relation:图底反转, figure_ground_inversion
  - condition:极值区域交换负片, extremes_swap_negatives

### docstring

```text
每个矩形区域用自己的种子图案平铺，但面积最小与最大的两个区域互相用对方种子的负片平铺。

输入结构
- 红色整行整列分隔线把黑色网格划分成若干矩形区域，面积最小与最大的区域
  各只有一个。
- 每个区域左上角贴有一份单色种子图案（一个小的周期花纹单元，外接矩形内
  含色格与黑格），其余格为黑色；不同区域的种子颜色互不相同。

规则
- 普通区域：以区域左上角为原点，用自己种子的外接矩形做平铺单元铺满区域，
  越界截断。
- 面积最小的区域：改用面积最大区域种子的负片平铺——tile 外接矩形内色格
  与黑格互换，色格使用最大区种子的颜色。
- 面积最大的区域：同样改用面积最小区域种子的负片平铺。
- 红色分隔线保持不变。

关键洞察
- 极值区域的花纹既换了颜色又对不上形状：它们不是直接交换种子，而是交换
  了对方种子的图底反转版本；配对键是面积极值，花纹键是负片关系。
```

## 5. 分形渐变印章

- tags:
  - operation:像素放大, pixel_upscale
  - operation:印章覆盖, stamp_overlay
  - operation:重涂色, recolor
  - object:精灵体, sprite
  - relation:自身为模板, self_as_stencil
  - relation:蛇形序号, boustrophedon_index
  - condition:序号定循环换色步数, index_sets_cycle_steps

### docstring

```text
按分形印章规则放大精灵，但每个副本的配色按其蛇形序号做循环换色。

输入结构
- 输入是一个 n×n 小精灵，含黑色背景格与若干种非黑颜色的像素。
- 输出为 n²×n² 网格，划分成 n×n 个 n×n 的块，每块对应一个输入格。

规则
- 输入格为黑的块整块保持黑色；输入格非黑的块内印上完整的输入精灵。
- 把非黑输入格按蛇形扫描顺序（首行从左到右、逐行折返）编号为 0,1,2,…。
- 记录精灵各颜色按行优先首次出现的去重色序作为循环序；第 i 号块中的副本，
  把每种颜色替换为循环序中它后面第 i 位的颜色。

关键洞察
- 副本之间的颜色差异不是噪声：印章位置由输入自身的非黑格选定，而每个
  副本的配色由它在蛇形阅读序中的序号驱动循环换色，0 号副本与原精灵
  完全相同。
```

## 6. 独苗渗透

- tags:
  - operation:压缩, compress
  - operation:计数, counting
  - object:墙壁, wall
  - object:散布像素, scattered_pixel
  - relation:滑动堆积, slide_and_stack
  - condition:全局唯一色渗墙, globally_unique_color_permeates

### docstring

```text
每行彩色像素向右滑动堆积在灰墙左侧，但颜色在整幅图中仅出现一次的像素会渗过墙，落在该行墙右第一格。

输入结构
- 黑背景网格中有一整段竖直灰色墙（占据一列的连续若干行），墙右侧为空。
- 墙左侧散布彩色单像素，每行可有多个；有的颜色在整幅图中出现多次，有的
  颜色在整幅图中恰好只出现一次；每行至多含一个"独苗色"像素。

规则
- 每行独立向右滑动：非独苗像素按原相对次序连续堆积、紧贴墙的左侧。
- 颜色在整幅网格中恰好出现一次的像素不参与左侧堆积，而是渗过墙，落在
  该行墙右侧第一格。
- 独苗渗出后，该行其余像素照常合拢贴墙，不留缺位；墙保持不变。

关键洞察
- 渗透资格与像素的位置、次序、离墙距离都无关——判据是整幅图层面的颜色
  出现次数；只盯着单独一行永远归纳不出规则，第一个示例还容易被"队首
  渗透"或"最远者渗透"的假规则误导。
```

## 7. 骑线信使换装

- tags:
  - operation:交换, swap
  - operation:重涂色, recolor
  - object:分隔栅格, divider_grid
  - object:骑线信使对, straddling_messenger_pair
  - object:精灵体, sprite
  - relation:隔线正对配对, across_divider_pairing
  - condition:目标侧半格定色, target_side_half_sets_color
  - condition:忽略干扰项, ignore_distractors

### docstring

```text
隔着分隔线正对的一对异色信使像素使两侧区域互换内部图案，且搬入的图案被重涂为目标侧信使半格的颜色。

输入结构
- 分隔色的整行整列把黑色网格划分成若干矩形区域。
- 某些相邻区域对之间有一对隔着分隔线正对的异色像素（信使对，两格分属
  两个区域并与同一分隔线格正交相邻）；每个区域至多参与一对。
- 每个参与区域内部各有一个小图案；另有一些完全落在单个区域内部的像素对
  与散点，属于干扰项。

规则
- 对每个信使对，其连接的两个区域互换各自的内部图案，图案按区域内相对
  位置整体搬移。
- 搬入目标区域的图案被整体重涂为信使对中贴着目标区域那一格的颜色；
  信使像素本身原样保留。
- 未被信使连接的区域及其中的干扰像素保持不变；分隔线不变。

关键洞察
- 有效指令是"被分隔线劈开、从未连成整体"的信使骨牌；它同时携带两条
  指令——连接关系（换谁）与目标侧颜色（涂成什么），图案颜色不跟内容走
  而跟地盘走。
```
