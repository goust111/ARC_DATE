## 1. 弹射轨迹的遮挡修复与碰钉反演

- tags:
  - operation:射线延伸, ray_cast
  - operation:遮挡修复, occlusion_repair
  - operation:因果反演, causal_inversion
  - object:孤立碰钉, single_cell_bumper
  - object:遮挡块, occluder_block
  - relation:反射弹回, reflection_bounce
  - condition:由果推因画回障碍, infer_hidden_bumper_from_bend

### docstring

```text
移除灰色遮挡块，依据弹射运动规律补全被遮住的轨迹段，并把由反弹位置反推出的、被遮住的红色碰钉画回来。

输入结构：
- 黑色背景网格上散布若干红色单格"碰钉"。
- 一条蓝色轨迹从底部某格出发沿对角线向上行进：当斜向前方一格越出左右边界或恰为红色碰钉时，
  水平方向立即反转，本步改沿反方向斜向上移动；轨迹最终从顶部离开，沿途每格涂蓝。
- 一个灰色实心矩形遮挡块覆盖轨迹中间一段，遮挡区域内一律显示灰色；
  遮挡块可以同时盖住轨迹格、背景格和红色碰钉。
- 保证：遮挡区内至多隐藏一次反弹，且遮挡区内的红色碰钉恰为引起该反弹的碰钉
  （不存在轨迹未触及的被遮碰钉）。

规则：
- 输出与输入同尺寸，遮挡区外一切保持不变。
- 灰色块整体消失：其覆盖范围内，轨迹实际经过的格恢复为蓝色，其余恢复为黑色。
- 若由进出遮挡区的可见轨迹方向推得区内发生了反弹、且反弹位置不贴左右边界，
  则该反弹必由一颗被遮住的碰钉引起，须在唯一确定的位置把这颗红色碰钉画回。

关键洞察：
- 修复依据不是对称或插值，而是轨迹自身的运动定律；
  更深一层是因果反演——碰钉本身从未在输入中露面，
  它的存在与位置只能从"轨迹被折弯"这一果反推出来。
```

## 2. 变尺度镜像共识去噪

- tags:
  - operation:去噪, denoise
  - operation:缩放, scale
  - operation:镜像, reflect
  - operation:多数投票, majority_vote
  - object:十字分隔线, cross_separator
  - object:四象限, quadrant
  - relation:象限决定反射轴, quadrant_determines_reflection
  - relation:尺寸比编码缩放, size_ratio_encodes_scale
  - condition:跨副本共识恢复, cross_copy_consensus

### docstring

```text
十字分隔的四个象限是同一母题按不同整数倍缩放并按象限位置镜像后的带噪副本，输出经共识复原的一倍母题。

输入结构：
- 一条整行与一条整列的同色分隔线构成十字，但十字不在正中，四个象限尺寸不同。
- 存在一个母题图案：左上象限为母题的整数倍放大原方向副本，右上为左右镜像副本，
  左下为上下镜像副本，右下为一百八十度副本，各象限放大倍数由各自尺寸决定。
- 每个象限内都有噪声：以该象限自身的放大格为单位被整块改成无关颜色；
  保证同一母题格至多在一个象限中被噪声覆盖。

规则：
- 找到十字，切出四个象限。
- 将每个象限按其倍数缩小、并按象限位置反镜像，得到四份母题读数。
- 逐格取多数颜色，输出一倍大小、按左上方向摆放的干净母题。

关键洞察：
- 没有任何一个象限是干净的，答案不在画面上任何一处完整出现；
  四份经过不同缩放与镜像的残缺证据只有对齐之后才能相互修复，
  噪声按放大格整块出现也堵死了在单个象限内部自我修复的捷径。
```

## 3. 能量守恒的碰撞链

- tags:
  - operation:平移, translate
  - operation:逐格耗能, incremental_charge
  - operation:碰撞传递, collision_transfer
  - object:能量条, energy_bar
  - object:滑块, sliding_block
  - relation:宽度即质量, width_as_mass
  - condition:能量上限步数, energy_caps_steps
  - condition:接触即传递, transfer_on_contact

### docstring

```text
行首黄条的长度是一笔能量预算，推动本行方块依次碰撞传递，方块每移动一格消耗与自身宽度相等的能量。

输入结构：
- 背景网格中有若干互不相邻的轨道行。
- 每条轨道行的最左端是一段连续黄条，右侧散布若干实心方块
  （宽一格或两格，彼此间有空隙，颜色互不相同且非黄）。

规则：
- 每条轨道行独立结算；黄条长度等于该行初始能量，黄条本身不动。
- 能量先作用于最左侧方块：方块向右滑动，每滑动一格消耗等于其宽度的能量；
  当它与右侧下一个方块相邻时立即停下，把剩余能量全部传给被撞方块，
  被撞方块按同样规则继续。
- 剩余能量小于当前方块宽度时结算结束，余量作废；
  方块滑到最右边界时停下，剩余能量湮灭。
- 输出为结算完成后的网格。

关键洞察：
- 黄条不是装饰而是预算，位移在碰撞中像动量一样向右传递；
  宽方块是重物，同样距离花费双倍能量，
  因此各方块的最终位移由预算、间隙和宽度三者共同结算，而不是整体平移。
```

## 4. 指针色链的二维拼装

- tags:
  - operation:排序, sort
  - operation:拼接, concatenate
  - operation:裁剪, crop
  - object:精灵体, sprite
  - object:入口出口标记, entry_exit_marker
  - relation:颜色指针链, color_pointer_chain
  - relation:标记边决定拼接方向, marker_edge_sets_direction
  - condition:空间顺序是诱饵, spatial_order_is_decoy

### docstring

```text
按"出口标记颜色等于下一块入口标记颜色"的隐藏链序，把散落的碎块首尾相接拼成一条蛇形整体并裁剪输出。

输入结构：
- 黑色背景上散布若干单色主体碎块；每个碎块边缘最多嵌有一个入口标记像素
  与一个出口标记像素，标记颜色不同于主体色。
- 恰有一个碎块没有入口标记（链头），恰有一个没有出口标记（链尾）；
  每种标记颜色在全图恰好出现两次，分别作为某块的出口与另一块的入口。

规则：
- 从链头出发，反复寻找入口标记颜色等于当前块出口标记颜色的碎块，得到唯一链序。
- 依链序拼装：后一块只平移（不旋转不翻转），使其入口标记像素与前一块的
  出口标记像素正交相邻，且相邻方向为出口标记所在边缘的朝外方向，链因此会拐弯。
- 保证拼装结果互不重叠；输出为整条拼装体的最小包围盒裁剪，所有像素保持原色。

关键洞察：
- 画面上的空间排列是干扰项，真正的顺序写在颜色指针里；
  标记颜色同时承担三重职责——链接顺序、拼接方位与逐块对位。
```

## 5. 颜色轮转的旋转对称修复

- tags:
  - operation:旋转, rotate
  - operation:颜色置换, color_permutation
  - operation:遮挡修复, occlusion_repair
  - object:遮挡块, occluder_block
  - object:复合对称图案, compound_symmetric_pattern
  - relation:几何乘颜色的联合不变性, joint_geometry_color_invariance
  - condition:置换表需自行归纳, permutation_inferred_not_given

### docstring

```text
整幅图案在"绕中心顺时针旋转九十度、同时每种颜色沿一个隐藏的固定循环前进一步"的复合变换下保持不变，利用这一复合对称恢复被单色方块遮挡的区域。

输入结构：
- 正方形网格上绘有多色图案，其上叠加一个单色实心遮挡方块。
- 图案满足复合不变性：把整幅图绕中心顺时针旋转九十度，
  再把每种颜色替换为固定循环中的下一种颜色，结果与原图完全一致。
- 该颜色循环没有任何图例或标注，只能通过对比未被遮挡的旋转对应位置自行归纳。
- 保证遮挡方块与它的三个旋转对应区域互不重叠。

规则：
- 找到遮挡方块的位置。
- 取其逆时针旋转九十度对应位置的未遮挡内容，将该内容顺时针旋转九十度、
  并把每个颜色按归纳出的循环前进一步，填回遮挡位置。
- 输出恢复后的完整网格。

关键洞察：
- 单看几何该图案并不旋转对称（旋转后颜色全对不上），单看颜色分布又似乎处处均衡，
  复合不变性是唯一的入口；而颜色循环表本身也是隐藏的，
  必须先从可见区域的旋转对应格中把置换规律读出来，才能把借来的内容换装后填回。
```

## 6. 钥匙孔投放

- tags:
  - operation:配对, matching
  - operation:平移, translate
  - operation:滑行堆叠, slide_and_stack
  - operation:封口涂色, seal_recolor
  - object:带缺口边框, notched_frame
  - object:矩形条, rectangular_bar
  - relation:长度锁孔配对, length_keyed_slot
  - condition:顺时针处理顺序, clockwise_processing_order
  - condition:滑到障碍或对壁停下, slide_until_blocked

### docstring

```text
框外的每个矩形条从边框上与其等长的缺口投入框内，沿垂直于该边的方向滑行到底，再用自身颜色封住缺口。

输入结构：
- 背景网格上有一个大的单色矩形边框（一像素厚），
  边框上开有若干长度互不相同的缺口，分布在不同侧边。
- 框外散布若干实心单色矩形条；每个矩形条与缺口一一对应：
  它平行于某条侧边的那条边长恰好等于且仅等于一个缺口的长度。

规则：
- 按缺口沿边框自左上角起顺时针的顺序逐一处理：找到与该缺口等长匹配的矩形条，
  把它从缺口平移入框并与缺口对齐，沿垂直于该侧边的方向向框内滑行，
  直到贴上对面框壁或先前已停放的矩形条为止。
- 每次投放后，把该缺口处缺失的边框像素涂成该矩形条的颜色（封口）。
- 框外原矩形条消失；输出为完成全部投放与封口后的网格。

关键洞察：
- 缺口既是钥匙孔又是投币口：长度匹配决定"谁从哪进"，
  滑行与先后堆叠决定"停在哪"，封口颜色记录"谁进过"；
  只把条放在缺口旁、或只做长度分类，都无法得到正确画面。
```
