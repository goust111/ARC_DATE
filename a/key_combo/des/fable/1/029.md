## 1. 镜纹折叠

### docstring

```text
识别出网格是由一块母版瓦片以"隔列左右镜像、隔行上下镜像"的方式铺满的，再把散落在各副本中的异常格经各自副本的镜像反变换折叠回母版后输出。

输入结构
- 整个网格由左上角一块母版瓦片铺满：瓦片列序号为奇数的副本被左右镜像，
  行序号为奇数的副本被上下镜像，行列序号都为奇数的副本被双重镜像。
- 少数格子被一种母版中不存在的颜色覆盖（异常格），散落在不同副本里；
  干净格子足以唯一确定母版内容与铺法。
- 任意两个异常格折叠回母版后的落点互不相同。

规则
- 由干净格子推断母版瓦片的尺寸与内容，以及每个副本相对母版的镜像朝向。
- 输出一个母版大小的网格，先绘制干净母版。
- 对每个异常格：取它在所在副本内的局部坐标，按该副本的镜像做反变换，
  得到它在母版内的落点，在输出的对应位置用异常色覆盖。

关键洞察
- 这不是普通平铺：直接按行列取余折叠会把镜像副本里的残迹折错位置；
  必须先看破"隔行隔列翻转"的铺法，让每块残迹沿自己那份副本的变换走回家，
  图形才拼得起来。异常格不是待修复的破损而是被拆散的讯息，
  答案既不是修复后的大网格，也不是干净母版本身。
```

## 2. 异或钥匙

### docstring

```text
上下两块对齐面板的前景不一致处构成一把从未画出的钥匙，在工作区中找到唯一能严丝合缝容纳它的孔洞并补实。

输入结构
- 网格上部被一条整行分隔线分成上下等高的两块面板，分隔色只出现在该行；
  两块面板背景相同、逐格对齐，各含一种不同的前景色。
- 分隔区域下方是工作区：若干灰色实心矩形，每个矩形内部挖有一个黑色孔洞，
  孔洞形状互不相同。

规则
- 将两块面板逐格对齐比较，恰有一侧为前景、另一侧为背景的位置集合
  构成钥匙形状。
- 在工作区里寻找与钥匙形状完全相同（只允许平移，不允许旋转或翻转）的
  唯一孔洞。
- 输出只保留工作区：该孔洞用灰色补满，其余矩形与孔洞原样保留。

关键洞察
- 两块面板既不是要输出的图案也不是要合并的图层，它们只是钥匙的生成元；
  参与匹配的形状在输入中从未被完整画出，只存在于两块面板的对称差之中。
```

## 3. 计数定叠序

### docstring

```text
由可见残角恢复每个被遮挡实心矩形的完整范围，再按散点区各颜色的像素数把它们以新的上下叠放次序重新绘制。

输入结构
- 主区域是若干颜色互异、相互重叠的实心矩形，按某个输入次序绘制，
  压在下面的矩形被部分遮挡；每个矩形至少有两个相对的角未被遮挡。
- 一条通高的分隔列把主区域与散点区隔开；散点区中每种矩形颜色都有
  若干散落像素，各颜色的像素数互不相同，且与对应矩形的大小无关。

规则
- 由每个颜色可见的相对角恢复该矩形的完整边界框。
- 统计散点区每种颜色的像素数。
- 在主区域重新绘制全部矩形：像素数最多的颜色最先画（垫底），
  像素数依次减少的颜色依次后画，像素数最少的颜色盖在最顶层；
  分隔列与散点区原样保留。

关键洞察
- 输入里谁压住谁是干扰信息，真正的叠放次序写在另一侧的计数表里；
  而要执行重排，必须先意识到被遮挡的矩形可以由残角唯一复原。
```

## 4. 连锁感染

### docstring

```text
定向种子发出一条不可见射线，被击中的空心矩形内部染上射线的颜色，并从其余三边中点向外再发射自身边框色的射线，感染沿链条级联。

输入结构
- 黑色背景上分布若干互不接触的空心矩形，边框颜色互异、边长均为奇数。
- 一处种子由一个彩色像素与一个紧邻的灰色像素组成，灰色像素指示发射方向；
  种子色不同于任何矩形边框色。
- 布局保证：每条射线至多击中一个矩形，每个矩形至多被一条射线击中，
  级联过程无环。

规则
- 种子沿灰色像素所指方向发出一条射线（射线本身不画出）。
- 射线击中某个空心矩形的边框时，该矩形内部被整体填充为该射线的颜色；
  随后该矩形从其余三条边的中点向外各发出一条新射线，
  新射线的颜色是这个矩形自身的边框色。
- 级联进行到所有射线都射出网格或落空为止。
- 输出：所有边框、种子与方向标保持原样，被感染矩形的内部按感染它的
  射线颜色填充，未被击中的矩形内部保持黑色。

关键洞察
- 每个矩形内部的颜色记录的是"谁感染了它"而不是"它自己是谁"；
  必须沿几何可达性追出整条感染谱系，颜色沿链条逐级更替，
  仅看单个矩形无法判定其内部颜色。
```

## 5. 体内方向针

### docstring

```text
每个精灵按体内偏心标记指出的方向一直滑到彩色边框旁，并换上所贴边框段的颜色。

输入结构
- 网格最外圈一整圈由若干段不同颜色的连续色段构成彩色边框。
- 边框内的黑色区域散布若干单色精灵，每个精灵体内恰有一格异色标记；
  标记格明显偏向精灵边界框中心的上、下、左或右一侧，偏向唯一。
- 布局保证：各精灵的滑动路径互不相交，到位后每个精灵贴住的边框格
  同属一个色段。

规则
- 读出每个精灵标记格相对其边界框中心的偏向，作为该精灵的滑动方向。
- 抹去标记格，将精灵沿该方向平移到紧贴边框内侧为止。
- 精灵整体重涂为它所贴的那段边框的颜色；原位置恢复为黑色，边框不变。

关键洞察
- 标记不是要与边框对齐的锚点，而是藏在体内的罗盘；精灵最终的颜色
  不在自己身上，而由运动终点处的边框段决定——方向、位置、颜色
  三层信息必须依次解出。
```

## 6. 拉框不拉纹

### docstring

```text
把带内部花纹的空心矩形拉伸到控制点标定的新边界；花纹格不按比例缩放，而是各自跟随离它最近的框角、保持原有相对位移。

输入结构
- 背景上有一个空心矩形：一格厚边框，内部散布若干花纹格，
  花纹色不同于边框色。
- 框外散布若干孤立控制像素；存在唯一一个不小于原矩形的新矩形，
  使每个控制像素恰好位于它某条边的外侧一格处。
- 每个花纹格按行列距离到原矩形四角有唯一最近角。

规则
- 求出被控制像素标定的新矩形，在原网格上擦去旧边框、画出新边框。
- 每个花纹格记录它相对原矩形最近角的行列偏移，随该角移动到
  新矩形的对应角后，按同一偏移重画。
- 控制像素保持不变，其余背景不变。

关键洞察
- 拉伸的是框不是纹：花纹既不等比缩放，也不原地不动，而是被四个角瓜分、
  各随其主平移——框的形变把原本连成一体的花纹撕开成四片；
  误按整体平移或比例缩放都会在部分示例上露馅。
```

## 7. 水面残影

### docstring

```text
让每个悬浮精灵水平找位并落到水面线上，使其在水下的倒影与已画出的残影碎片吻合，再补全整个倒影。

输入结构
- 一条整行的灰色水面线横贯网格，线上方的黑色天空中悬浮若干
  颜色互异的单色精灵。
- 线下方的水域中散布少量彩色格，每种颜色是某个精灵倒影的一部分残影，
  即该精灵落位后关于水面线镜像中的若干格。
- 每种颜色的残影足以唯一确定该精灵的水平落位。

规则
- 对每个精灵，寻找一个水平位置，使精灵竖直下落、底边紧贴水面线上方时，
  它关于水面线的镜像恰好覆盖水下所有同色残影格。
- 把精灵移到该位置（原位置清空），并在水下画出完整镜像。
- 水面线保持不变；输出中每个精灵与其完整倒影隔线对称。

关键洞察
- 水下碎片不是独立对象而是答案的残迹：精灵的落点在输入中从未直接标出，
  必须以自身倒影反推回来——先解逆问题定位，再做正向的镜像补全。
```
