## 1. 隐形镜轴与颜色轮换

- tags:
  - 操作:镜像
  - 操作:重涂色
  - 对象:精灵体
  - 关系:隐形轴配对
  - 条件:颜色置换非对合

### docstring

```text
一句话总述：
找出散落精灵之间从未画出的公共镜轴与非对合的颜色置换，为唯一没有伙伴的精灵补画出它的镜像伙伴。

输入结构：
- 背景为黑色，其上散布若干个形状不对称的单色精灵。
- 除一个精灵外，其余精灵两两配对：每对成员的形状关于一条公共的竖直（或水平）镜轴互为镜像，镜轴本身从未画出。
- 每对成员颜色不同：把镜轴一侧成员的颜色经同一个固定颜色置换映射，得到另一侧成员的颜色；该置换是三个颜色的轮换（甲→乙→丙→甲），而非两色互换。
- 恰有一个精灵没有伙伴。

规则：
- 由所有配对联立恢复出镜轴位置，以及从轴左（上）侧到右（下）侧方向的颜色置换。
- 找到无伙伴的孤儿精灵，在镜轴另一侧补画其镜像；孤儿在左（上）侧则其伙伴颜色取置换的正向像，在右（下）侧则取逆向像。
- 其余像素保持不变。

关键洞察：
- 镜轴与颜色置换都不是画出的对象，只能由多对精灵的证据联立恢复；单看一对会误以为只是两色互换，综合所有对才能发现置换是单向轮换，因此补画的颜色取决于孤儿位于轴的哪一侧。
```

## 2. 射线断口中的隐形精灵

- tags:
  - 操作:形状匹配
  - 操作:印章覆盖
  - 操作:擦除
  - 对象:射线
  - 对象:图例精灵
  - 关系:遮挡残迹定位
  - 条件:八种姿态唯一匹配

### docstring

```text
一句话总述：
多条贯穿网格的直线射线在同一区域留下对齐的断口，用角落图例的形状推断出隐形精灵的位置与姿态并把它画出来。

输入结构：
- 黑色背景上有若干条从网格边缘出发、横贯或纵贯整个网格、宽度为一的直线射线。
- 网格一角有一个不与任何射线接触的单色小图例精灵。
- 场上放置着该图例精灵经旋转或翻转（八种姿态之一）后的一个隐形实例：射线经过它占据的格子时像素缺失，形成断口；实例不在射线上的部分完全不可见。

规则：
- 收集所有射线的断口格，找到图例精灵的唯一一种姿态与位置，使实例恰好覆盖全部断口且不覆盖任何未断的射线格。
- 在该位置以图例颜色画出完整的实例（包括不在任何射线上的格子）。
- 擦除角落的图例，其余像素保持不变。

关键洞察：
- 被求对象从未被画出，画面上只有它挡住射线留下的残迹；断口只是它与射线的交集，必须用图例形状在八种姿态之间做匹配才能补全看不见的其余部分，而不是把断口简单修补回射线。
```

## 3. 行程记录仪：门色的左右手账

- tags:
  - 操作:解码
  - 操作:排序
  - 对象:路径
  - 对象:门结构
  - 对象:起点标记
  - 关系:连通顺序读取
  - 条件:行进朝向定左右
  - 条件:终止门截断
  - 条件:忽略伪门

### docstring

```text
一句话总述：
沿蜿蜒路径从起点行进，把跨在路径上的每道门的两根门柱颜色按行进时的左右手方向记入两列账本，直到黑柱终止门截断行程。

输入结构：
- 网格由统一底色填充，其上有一条宽度为一、四连通、不分叉的绿色路径，路径一端放着一个灰色起点标记。
- 路径沿线有若干道门：某个路径格两侧、垂直于该处行进方向紧贴着一对门柱像素；同一道门的两根门柱可以同色也可以异色。
- 恰有一道门的两根门柱都是黑色，是终止门。
- 网格其他地方散布一些不跨在路径上的成对像素，是伪门。

规则：
- 从灰色标记出发沿路径向另一端行进；每穿过一道彩色门，记录一行两格：行进方向左手侧门柱的颜色记入左列，右手侧门柱的颜色记入右列。
- 到达终止门所在路径格之前停止，其后路径上的门一律不记录。
- 输出一个 k 行 2 列的网格，自上而下为经过顺序，k 为记录的门数。

关键洞察：
- 账本的左右列不看网格的绝对方向，而看行进朝向的左右手——路径每次拐弯后，按同样绝对方位摆放的门柱会换列；读取顺序由路径连通顺序而非扫描顺序决定，终止门使远端的门作废，不跨路径的像素对只是伪门。
```

## 4. 分隔线两侧的双守恒律

- tags:
  - 操作:填充
  - 操作:遮挡求解
  - 对象:分隔线
  - 对象:横条
  - 对象:遮挡矩形
  - 关系:行内守恒
  - 条件:位置镜像加长度互补

### docstring

```text
一句话总述：
从未被遮挡的行中归纳出黄红两条横条的位置镜像与长度互补两条守恒律，再用它们解出被遮挡行的右侧内容。

输入结构：
- 黑色背景上有一条完整的灰色竖直分隔线。
- 每一行在分隔线左侧有一段连续黄色横条，右侧有一段连续红色横条；不同行的横条长短与位置各不相同。
- 其中一到两行的分隔线以右整段被一块实心青色矩形完全遮住。

规则：
- 未遮挡的行共同满足两条规律：红条近端到分隔线的距离等于该行黄条近端到分隔线的距离；黄条长度与红条长度之和在所有行中是同一个常数。
- 对每个被遮挡的行，按这两条规律在右侧摆放红条，其余被遮挡的格子恢复为黑色背景。
- 分隔线与左侧内容保持不变。

关键洞察：
- 变换规则没有被显式画出，它是所有可见行共同满足的守恒律；部分行黄红等长，会诱导"红条是黄条的等长镜像"的错误假设，只有联立位置与长度两条独立的守恒律才能唯一解出被遮挡的行。
```

## 5. 图案的对称性就是指令

- tags:
  - 操作:镜像
  - 操作:旋转
  - 操作:裁剪
  - 对象:分隔线
  - 对象:面板图案
  - 对象:精灵体
  - 关系:对称性跨面板迁移
  - 条件:唯一自对称选指令

### docstring

```text
一句话总述：
识别大面板图案唯一具有的自对称，并把这一对称作为操作施加到小面板的精灵上。

输入结构：
- 一条完整分隔线把网格分成一大一小两块面板。
- 大面板是一幅多彩图案，在左右翻转、上下翻转、一百八十度旋转、主对角转置、反对角转置五种变换中恰好只对其中一种保持不变。
- 小面板内有一个形状不对称的单色精灵；当大面板的对称属于转置类时，小面板是正方形。

规则：
- 检验大面板图案，找出它唯一满足的那种自对称。
- 输出与小面板同尺寸的网格：把小面板整体按这种变换（以小面板自身的中心轴或中心点为基准）作用后输出。
- 大面板与分隔线不进入输出。

关键洞察：
- 大图案不是需要修补或复制的数据，而是一枚指令：它唯一拥有的自对称就是要施加给另一对象的操作；解题的入口在于意识到两块面板之间传递的是"变换"而非"内容"。
```

## 6. 指向中心的十字罗盘

- tags:
  - 操作:印章覆盖
  - 操作:重涂色
  - 对象:标记像素
  - 对象:空心矩形
  - 对象:十字图案
  - 关系:隐含参照系定向
  - 条件:朝向背向手性定色

### docstring

```text
一句话总述：
以唯一空心矩形的中心为参照，为每个标记像素盖上一枚按"朝向—背向—左右手性"定色的十字印章。

输入结构：
- 黑色背景上有一个唯一的空心矩形（边长为奇数，中心格唯一）和若干彼此远离的蓝色标记像素。
- 每个标记与矩形中心的行差与列差绝对值不相等，即不落在中心的正对角线上。

规则：
- 对每个标记像素，向上下左右四个邻格各涂一格：从标记指向矩形中心的主方向（行差与列差中绝对值较大的那个方向）一臂涂红色，相反一臂涂青色；以红臂为前方，其顺时针一侧的臂涂橙色，逆时针一侧的臂涂粉色。
- 印章在网格边界处裁剪；标记像素本身与空心矩形保持不变。

关键洞察：
- 十字的配色不是固定罗盘：部分标记恰好位于中心正下方，会诱导"上红下青"的绝对方位假设；实际上每枚十字都是同一副罗盘朝着隐含参照点旋转后的印章，而参照点本身从未被标出，只能从空心矩形的结构里读出。
```

## 7. 自引用马赛克的坏块修复

- tags:
  - 操作:掩码映射
  - 操作:对称补全
  - 对象:块单元
  - 对象:全局掩码
  - 关系:双重自引用
  - 条件:唯一坏块可重建

### docstring

```text
一句话总述：
大网格是某个小种子图按"每个像素扩展为其颜色在种子图中的全局掩码"生成的块状马赛克，找出唯一被涂改的坏块并按自引用规律修复。

输入结构：
- 网格可均分为 n×m 个块，每块自身也是 n×m（块阵形状与块内形状相同）。
- 存在一个从未画出的 n×m 种子图：位于块阵位置 (i,j) 的块，其块内恰在"种子图中颜色等于种子图 (i,j) 格颜色"的那些位置涂上该颜色，其余位置为黑。
- 恰有一个块被整体替换成与上述规律矛盾的图案。

规则：
- 从未被涂改的块中恢复种子图——每个块的非黑颜色报出种子图对应格的值，每个块的非黑位置集合报出该颜色在种子图中的全部出现位置。
- 定位与规律矛盾的坏块，用它应有的颜色与掩码重新画出。
- 输出修复后的完整网格。

关键洞察：
- 种子图从未出现在画面上，但每个块都以两种方式同时引用它——颜色引用种子图一个格子的值，形状引用该颜色在种子图中的全局分布；这种双重自引用产生的冗余既能揭发坏块，也足以唯一重建它。
```
