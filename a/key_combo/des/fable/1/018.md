## 1. 螺旋残迹分段上色

- tags:
  - 操作:螺旋绘制
  - 操作:顺序上色
  - 对象:标记像素
  - 对象:隐形路径
  - 关系:沿路径一维顺序
  - 条件:最近标记决定当前色

### docstring

```text
沿从未画出的标准顺时针螺旋重建路径，并按散点在路径上的先后顺序给螺旋分段上色。

输入结构：
- 输入为全黑的正方形网格，其上散布若干彩色单像素点，乍看杂乱无章。
- 所有彩色点都恰好位于同一条螺旋路径上：该螺旋从左上角出发向右行进、顺时针盘旋、
  臂与臂之间留一格间隙，但输入中并未画出。
- 螺旋起点（左上角格）必有一个彩色点；各点颜色可以重复出现。

规则：
- 先按固定法则生成该尺寸的螺旋路径：从左上角向右出发，当下一步将越界或前方两格已属
  路径时顺时针转向，当下一步将进入已有路径格时停止。
- 从起点沿路径遍历，维护“当前颜色”：每经过一个彩色点就把当前颜色换成该点的颜色。
- 把路径上每一格涂成经过它时的当前颜色；路径外保持黑色。

关键洞察：
- 散点不是噪声而是一条隐形螺旋的残迹；真正的坐标系是沿螺旋的一维顺序，各点把这条
  一维带切成若干染色区段。
```

## 2. 镜像虫洞洪泛

- tags:
  - 操作:洪泛填充
  - 操作:镜像
  - 对象:中轴线
  - 对象:障碍墙
  - 对象:种子像素
  - 关系:镜像增强连通
  - 条件:迭代至不动点

### docstring

```text
从种子洪泛填充黑色区域，每个新填充格还会点燃它关于中轴线的镜像格，如此反复直至稳定。

输入结构：
- 一条贯穿整个网格的红色直线位于正中，把画面分成可镜像对应的两半。
- 两侧各有若干灰色墙体，但墙体布局关于红线并不对称；背景为黑色。
- 网格中恰有一个蓝色种子像素。

规则：
- 反复执行以下两步直到不再有新增：已填充集合沿四连通向相邻黑格扩散；每个已填充格
  关于红线的镜像格若为黑格则也被填充。
- 将最终填充到的格全部涂成蓝色。
- 红线、灰墙及其余格保持不变。

关键洞察：
- 连通性被镜像通道增强：水能渗入被完全封死的镜像房间，在里面继续流动，甚至再镜像
  回本侧点燃新的房间；只把可达区域整体镜像一次得不到正确答案，必须迭代到不动点。
```

## 3. 镜面弹射选块

- tags:
  - 操作:射线延伸
  - 操作:反射
  - 操作:裁剪
  - 对象:箭头精灵
  - 对象:斜置镜面
  - 对象:候选图块
  - 关系:横杆偏移定方向
  - 条件:出口落点选块

### docstring

```text
从箭头尖端发出的光线经斜置镜面折转后离开弹射区，用其出口落点在三个候选图块中选出唯一输出。

输入结构：
- 网格上部并排放着三个等宽的多彩图案块，块间由分隔线隔开，图案互不相同且不含红色。
- 一条水平分隔线把图案区与下方的弹射区隔开。
- 弹射区内有一个六像素的单色不对称T形箭头（长四主杆加长三横杆，横杆偏向尖端一侧），
  以及若干条由红色格组成的斜线镜面。

规则：
- 由横杆的偏移方向确定箭头指向，从尖端沿该方向发出一条沿格直行的光线。
- 光线撞上红色斜镜面时按镜面走向折转九十度继续前进，可发生多次反射。
- 光线最终向上穿过水平分隔线离开弹射区；出口所在列落入哪个图案块的列区间，就输出
  哪个图案块（按原样裁剪，不含分隔线）。

关键洞察：
- 整个光学装置只是一枚指针：光路本身不出现在输出里，答案是被它选中的那块图案；
  不模拟反射、只看箭头初始指向或比较图案本身都会选错。
```

## 4. 认领影子

- tags:
  - 操作:投影匹配
  - 操作:旋转
  - 操作:滑动
  - 操作:擦除
  - 对象:直方图条
  - 对象:分隔板
  - 对象:候选形状
  - 关系:一维投影定身份
  - 条件:朝向未知需搜索
  - 条件:归位后影子消失

### docstring

```text
找出在某个旋转朝向下横向投影与隔板直方图完全一致的唯一形状，让它旋到该朝向、平移到
隔板旁与影子逐行对齐，并抹去被认领的影子。

输入结构：
- 一条灰色竖直隔板将网格分为左右两区，背景为黑色。
- 左区若干红色横条逐行紧贴隔板向左伸出、长度不一，占据一段连续行区间，构成一列直方图。
- 右区散布数个朝向各异的蓝色形状；恰有一个形状在其四种旋转朝向中的唯一朝向下，
  自上而下的逐行格数序列与条长序列完全相等；干扰形状中有的像素总数与直方图总和相同，
  有的在某朝向下行数与条数相同，有的轮廓神似。

规则：
- 对每个蓝色形状在四种旋转朝向下分别求包围盒内自上而下的逐行格数序列，找出与红条
  长度序列相等的唯一“形状+朝向”。
- 把该形状旋到该朝向，平移到紧贴隔板右侧、行区间与直方图行区间完全对齐的位置，
  并染成红色。
- 抹去左区直方图；其余蓝色形状与隔板保持原样。

关键洞察：
- 条形图是一个从未画出的形状的横向影子，且照射方向未知：必须同时确定“是谁的影子”
  与“从哪个朝向照出”；形状归位后影子消失，输出里唯一的红色实体正是影子的主人。
```

## 5. 无形墙围出的水域

- tags:
  - 操作:射线延伸
  - 操作:洪泛填充
  - 对象:箭头精灵
  - 对象:矩形边框
  - 对象:隐形屏障
  - 对象:种子像素
  - 关系:横杆偏移定方向
  - 条件:不可见墙限定可达域

### docstring

```text
每个箭头从尖端向指向方向引一道看不见的直线屏障，黄色种子只能在屏障与边框围成的腔室
内漫延。

输入结构：
- 网格四周是一圈单像素矩形边框，内部背景为黑色。
- 边框内散布若干六像素的单色不对称T形箭头（长四主杆加长三横杆，横杆偏向尖端一侧），
  指向各不相同。
- 内部另有一个黄色种子像素；诸箭头的射线与边框共同围出包含种子的腔室。

规则：
- 对每个箭头，由横杆偏移确定指向，自尖端沿该方向作直线延伸至边框，作为一道屏障；
  屏障不着色、不显示。
- 从种子做四连通洪泛，不得越过边框、箭头本体与任何屏障；把可达的背景格全部涂黄。
- 输出仅在输入之上新增黄色格，其余一切原样保留。

关键洞察：
- 决定水域边界的墙从未被画出：黄色区域会出现看似悬空的笔直边缘，只有解码每个箭头的
  指向并在脑中补全射线，这些边缘才有解释；若屏障两侧都可达，两片黄区之间会残留一条
  黑色细线，正是隐形屏障的影子。
```

## 6. 容量寻址

- tags:
  - 操作:计数
  - 操作:洪泛填充
  - 操作:重涂色
  - 对象:空心封闭框
  - 对象:指令像素组
  - 关系:数值间接指针
  - 条件:点数等于容量方生效
  - 条件:废指令与空框留存
  - 对象:干扰属性

### docstring

```text
每个空心框内的散点是一条寻址指令：点数等于哪个框的内部容量，就把那个框用点的颜色整体
填满；通不过容量校验的指令作废。

输入结构：
- 黑色背景上有若干灰色空心封闭框，形状不限于矩形，各框内部黑格容量互不相同。
- 每个框内部散落一组同色像素，各组颜色互不相同；有的框的指令恰好指向自己。
- 恰有一组的点数与任何框的容量都不相等（废指令），它恰好位于唯一不被任何有效指令
  指中的框内。
- 个别样例中，某组点数还会与某框的宽度、高度或周长等其他属性偶然相等，用作误导。

规则：
- 对每个框数出其内部指令像素的点数并记下颜色。
- 若点数等于某框的内部容量，就把那个框的内部全部涂成该颜色（框内原有指令像素一并
  覆盖）。
- 废指令像素与其所在的空心框原样保留；灰色框体一律不变。

关键洞察：
- 框里的点是描述另一个容器的指令，数字桥的两端是“点数=内部容量”而非宽度、周长或
  “填自己”；自指样例与属性撞车都是诱饵，废指令说明指令必须先通过容量校验才生效。
```

## 7. 差异之形

- tags:
  - 操作:异或合成
  - 操作:像素缩放
  - 操作:形状匹配
  - 操作:旋转
  - 操作:翻转
  - 操作:裁剪
  - 对象:半区掩码
  - 对象:候选精灵
  - 关系:缩放对应
  - 条件:对称差为检索键
  - 条件:八方向匹配

### docstring

```text
取两幅并排面板前景的对称差作为检索键，在下方候选中找出它经整倍放大与改向后的唯一化身
并输出。

输入结构：
- 网格上部是左右并排、尺寸相同的两块面板，中间隔一条分隔线；两面板共享同一背景色，
  且各自恰有一种前景色。
- 网格下部散布数个单色候选精灵，颜色与朝向各异，每个精灵都由某个 k×k 实心方块阵列
  拼成，k 因精灵而异。
- 恰有一个候选精灵按块缩小后，与面板对称差形状在旋转或翻转下全等。

规则：
- 将两面板按位置对齐，取“恰有一侧为前景”的格集，得到差异形状。
- 对每个候选精灵求其块级缩小形，在八种朝向下与差异形状比对。
- 输出唯一匹配的候选精灵，按其原颜色、原朝向、原放大倍数做最小包围盒裁剪。

关键洞察：
- 作为钥匙的形状从未被画出，它只存在于两幅面板的差异之中；候选又经过放大与改向的
  伪装，必须叠加“对称差—块级缩小—全等比对”三层变换才能认出它。
```
