## 1. 隐形矩形的专属选票

```text
由角点几何复原多个相互重叠、从未画出的矩形，散点只有在唯一归属某矩形内部时才算选票，
输出得票最多矩形的边框与其票内多数色。

输入结构
- 背景为黑色，画面上散布若干种颜色的孤立像素。
- 存在若干种角点色：每种颜色的全部像素恰好构成一个轴对齐矩形的四个角，
  这些矩形相互重叠，但矩形本身从未被画出；角点色不一定是最稀有的颜色。
- 另有多种散点色像素分布于各矩形内部、重叠区与全部矩形之外。
- 可能存在恰有四个像素却不构成矩形四角的诱饵色。
- 保证恰有一个矩形的专属选票数严格最多，且其票内恰有一种颜色数量严格最多。

规则
- 对每种颜色检查其像素集合的几何构型，识别所有"全部像素恰为某矩形四角"的
  角点色，并复原各隐形矩形。
- 一个散点像素仅当严格位于恰好一个矩形内部时，才计为该矩形的选票；
  落在重叠区或所有矩形之外的散点作废。
- 选出选票最多的矩形。
- 输出与该矩形同尺寸的网格：最外圈涂其角点色，内部全部涂其选票中数量最多的散点色。

关键洞察
- 参与规则的矩形从未被画出，只有四个生成元角点，须由像素集的几何构型而非
  数量或稀有度识别。
- 重叠区的散点是废票——第一直觉"统计每个矩形内的全部散点"会被重叠区诱导出
  错误的赢家，唯一归属才是计票资格。
```

## 2. 通配去重与补洞互证

```text
把被拉伸复制且部分单元被涂成空白色的网格，坍缩回原始小矩阵并补全空白。

输入结构
- 存在一个未给出的小答案矩阵；输入由它把每行复制成若干相邻同行、
  每列复制成若干相邻同列拉伸而成。
- 拉伸之后，若干单元被改写成同一种空白色；空白色不在答案矩阵中出现。
- 保证：同一行段（对应答案矩阵同一行的那组相邻行）内，每个列位置至少有
  一个未被改写的单元；列段同理。
- 保证：相邻两个行段之间，总存在某列，两侧单元都可见且颜色不同；列段同理。

规则
- 识别空白色（构成孔洞的那种颜色）。
- 合并相邻行：把空白视为通配符，两行在所有双方可见的位置同色即属同段，
  段内每个位置取该段中可见的颜色；列同理。
- 输出坍缩且补全后的小矩阵，不含任何空白。

关键洞察
- 去重与补洞互为前提：按精确相等去重会被空白破坏，必须把空白当通配符
  才能正确合并；而合并后的段恰好为每个空白提供了唯一可见的补全值。
```

## 3. 步变换推断与跨缺口复合

```text
一行格元里的精灵由同一个未知步变换逐格生成，从可见相邻对联合推断步变换的
几何与颜色两部分，并跨越连续缺口复合它来补全空格。

输入结构
- 一种颜色构成竖直分割线，把画布切成一行若干等大格元。
- 其中若干格为空（可能出现连续两格的缺口），其余格各含一个多色精灵。
- 存在一个固定的步变换——由某种翻转或旋转与某个颜色置换复合而成——使
  每个格元的精灵等于前一格精灵施加该变换。
- 保证可见的相邻格对足以唯一确定步变换，且精灵形状不具备会造成歧义的对称性。

规则
- 从所有可见的相邻格对中联合推断步变换的几何部分与颜色置换部分，
  二者必须对全部可见对同时自洽。
- 对每个空格，从最近的可见格元出发，按间隔距离复合步变换或其逆变换，
  得到应填的精灵。
- 画入空格，分割线与已有格元保持不变。

关键洞察
- 几何部分与颜色部分必须联合推断，单看形状或单看颜色都可能有多解。
- 连续缺口迫使施加步变换的二次复合——翻转的自逆性与颜色置换的循环性在
  复合下分道扬镳，把"镜像加换色"当成对合的人会在两步缺口的第二格出错。
```

## 4. 缺口之门与推挤压实

```text
外部滑块沿行列滑向带一个缺口的空心矩形框，撞墙者贴墙堆叠，
对准缺口者穿门而入并把框内散块推挤到对面内壁压实。

输入结构
- 黑色背景上有一个灰色单层空心矩形框，边上（非角处）恰有一个一格宽的缺口。
- 框外散布若干彩色滑块像素，每个都沿所在行或列与框的某条边垂直对齐；
  同一条线上可有多个滑块。
- 框内部在缺口所在的直线上可能已有若干松散像素。

规则
- 每个滑块沿自己的行或列滑向矩形框。
- 路径撞上框壁的滑块停在紧贴框壁的外侧格；同线后续滑块依次贴着前一个停下，
  形成堆叠。
- 路径恰好经过缺口的滑块穿入框内继续滑行，推着沿途一切松散像素一起前进，
  直到最前方像素抵住对面内壁；全部参与者压实成一段，颜色与相对顺序保持。
- 框本身与缺口保持原样，输出最终画面。

关键洞察
- 缺口是一扇门：滑块的命运不取决于它自己，而取决于它的行列是否对准缺口。
- 入内者引发推挤连锁，框内原有像素被间接搬运——它们自己从不主动移动。
```

## 5. 锚点配对与转向印章

```text
把源面板里的精灵按锚点颜色配到目标面板的标记上，
再绕锚点旋转到与标记的方向针一致后盖章。

输入结构
- 画布上有两个带边框的矩形面板：源面板内是若干多格精灵，
  目标面板内是若干孤立标记像素。
- 每个精灵内恰有一个锚点格（该精灵中出现次数最少的颜色）和一个紧邻锚点的
  灰色方向格。
- 标记颜色与各精灵锚点颜色一一对应；每个标记也恰有一个紧邻的灰色方向格，
  指示目标朝向。

规则
- 按颜色把每个标记与锚点同色的精灵配对。
- 把精灵绕其锚点旋转 0、90、180 或 270 度，使精灵内"锚点指向灰格"的方向
  与目标处"标记指向灰格"的方向一致。
- 平移旋转后的精灵，令锚点落在标记位置上盖章。
- 输出为盖章完成后的目标面板。

关键洞察
- 配对需要两把钥匙：颜色决定"配给谁"，灰色方向针决定"转多少"。
- 旋转角不是全局固定的，而是逐对由两根方向针的夹角给出。
```

## 6. 同步竞速射线

```text
左缘源点向右、上缘源点向下同步逐格生长射线，先到者占格并截停后到者，
同时到达则双双止步。

输入结构
- 背景为黑色；最左列有若干彩色源像素，最上行有若干彩色源像素，
  颜色互不相同。
- 除这两条边缘上的源点外，画布初始为空。

规则
- 所有射线同时从各自源点出发，每一拍前进一格：左缘源向右，上缘源向下，
  把经过的格涂成自己的颜色。
- 若下一格已被别的射线先占，则本射线就地终止，不再前进。
- 若两条射线同一拍到达同一格，则该格保持背景色，两条射线同时终止。
- 未被截停的射线一直画到画布边缘；输出最终画面。

关键洞察
- 交点归属由到源距离的竞速决定，而一次截停会让该射线从此缺席更远处的
  所有交点——早局部的胜负会级联改写晚局部的格局，不能孤立判定每个交叉。
```

## 7. 双尺度互证修复

```text
大图案是未知种子形状在两个尺度上的自嵌套展开，
利用宏观占位与微观块内容的相互印证，清除杂点并修复缺损。

输入结构
- 背景为黑色；存在一个未直接给出的 n×n 二值种子形状。
- 无损画面应为：把画布分成 n×n 个等大块，种子为 1 的块位置内画上
  种子形状的单色副本，为 0 的块位置全空。
- 实际输入被少量破坏：真被占块内可能丢失或多出少数像素，但仍多数吻合
  种子形状；真空块内可能出现少量杂点，杂点不构成种子形状。

规则
- 按整除关系把画布分成 n×n 个等大块。
- 从内容强烈吻合共识形状的块中表决出候选种子形状。
- 宏观占位图本身也必须等于该种子形状，以此约束裁定含杂点的可疑块
  是真占还是真空。
- 用裁定后的真种子在两个尺度上重建无损画面并输出。

关键洞察
- 同一个形状被同时写进宏观排布与微观内容，两个尺度互为校验码。
- 单看任何一块或单看占位图都可能被破坏误导，只有跨尺度对照才能唯一还原。
```
