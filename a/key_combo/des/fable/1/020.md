## 1. 动量接力

- tags:
  - operation:滑动, slide
  - operation:连锁触发, chain_trigger
  - object:凸头方块, nub_block
  - object:网格边界, grid_edge
  - relation:碰撞阻挡, collision_blocking
  - condition:凸头定向, nub_points_direction
  - condition:配额传递, momentum_quota_transfer

### docstring

```text
让红色方块沿凸头方向滑动撞击，运动的"格数配额"沿碰撞链逐段传递，输出接力停止后的局面。

输入结构：
- 黑色背景上散布若干物体，每个物体都是一个 2x2 单色方块外加贴在某条边中部的同色凸头像素，凸头所指一侧即该物体朝向。
- 恰有一个红色触发者，其余物体颜色互不相同、朝向各异。
- 布局保证每次滑动至多撞上一个物体。

规则：
- 红色物体沿自己的朝向逐格滑动，直到被物体挡住或到达网格边缘；若到边缘则连锁结束。
- 设它实际滑过 d 格，被撞物体获得配额 d，沿"它自己的朝向"滑动：至多 d 格。
- 若滑了 k<d 格就被另一物体挡住，则把剩余配额 d-k 传给该物体，依此接力。
- 配额耗尽、或滑动方到达边缘时，连锁终止；从未被撞到的物体保持原位，所有物体形状颜色不变。

关键洞察：
- 这既不是整体重力、也不是"滑到撞上为止"：被撞物体常常停在空地中间，因为它花掉的是接力来的动量配额；每一环的方向由被撞者自身凸头决定，方向与配额两条线索必须同时对上。
```

## 2. 条纹折环

- tags:
  - operation:去噪, denoise
  - operation:卷折重构, fold_rebuild
  - object:条纹行列, stripe_line
  - object:嵌套层, nested_layer
  - relation:序列映射层序, sequence_maps_layer
  - condition:条宽定环厚, stripe_width_sets_ring_thickness

### docstring

```text
把带噪条纹画布还原成干净色条序列，再把这串色条按各自宽度从外到内卷成一个同心方环图案。

输入结构：
- 画布被横向或纵向的彩色条纹铺满，各条纹颜色不同、宽度不等。
- 稀疏噪声像素散落其上，但每条真实条纹线内主色仍严格占优。

规则：
- 按横条与纵条两种解读分别累计各线主色像素数，取总分严格更高的方向为真实条纹方向。
- 沿该方向从靠上（横条）或靠左（纵条）一端开始，读出干净条纹序列，每项记下颜色与宽度。
- 设全部宽度之和为 T，输出 2T x 2T 的正方形：第一条颜色画成厚度等于其宽度的最外圈方环，下一条紧贴其内侧，依次向内，最后一条构成中心实心方块。

关键洞察：
- 输出的中心一行从左扫到右恰好是条纹序列接上其倒序；整幅条纹画布只是同心图案沿半径方向的展开，条宽即环厚，靠上/靠左的条纹在最外层。
```

## 3. 双例归纳

- tags:
  - operation:变换归纳, transform_induction
  - operation:旋转, rotation
  - operation:镜像, mirror
  - operation:裁剪, crop
  - object:示范精灵对, demo_sprite_pair
  - object:目标精灵, target_sprite
  - relation:同色配对, same_color_pairing
  - condition:联立消歧, joint_disambiguation

### docstring

```text
从两组同色示范精灵里归纳出唯一能同时解释它们的取向变换，把该变换施加到没有伙伴的目标精灵上。

输入结构：
- 背景上共有五个精灵：两种颜色各有两个精灵，同色的一对构成一组示范，位于上方的是变换前形状，位于下方的是变换后形状。
- 第五个精灵颜色独一无二，没有同色伙伴，它是待变换的目标。
- 每组示范单独看都与不止一种旋转或镜像变换相容，但把两组联立后，八种取向变换中恰有一种同时成立。

规则：
- 在恒等、三种旋转与四种镜像共八种取向变换中，找出唯一把每组示范的上方形状变为下方形状的那一种。
- 将该变换施加于目标精灵，输出变换结果的最小包围盒裁剪。

关键洞察：
- 单组示范因形状自带部分对称而存在多解，只按其中一组匹配会得到看似合理却错误的取向；答案必须由两组示范的交集唯一确定。
```

## 4. 背面视角

- tags:
  - operation:补全, reconstruct
  - operation:镜像, mirror
  - operation:透明叠加, layered_overlay
  - object:遮挡矩形, occluding_rect
  - relation:图层优先级, layer_priority
  - condition:遮挡定层序, occlusion_reveals_order
  - condition:背面视角, back_view

### docstring

```text
从互相遮挡的碎片推断每张实心矩形色板的完整范围与上下叠放次序，再渲染整叠色板从背面看去的样子。

输入结构：
- 背景上叠放着若干互不同色的实心矩形色板，重叠处只露出上层颜色。
- 每种颜色可见像素的包围盒就是该矩形的真实范围（每个矩形四条边所在行列都有像素露出）。
- 两两重叠关系足以串出一条唯一的从底到顶全序。

规则：
- 用每种颜色的可见包围盒恢复出完整矩形。
- 每处重叠区露出的颜色属于较上层的矩形，据此排出全部矩形从底到顶的次序。
- 输出与输入同尺寸：把所有矩形按"原底层最后画"的相反次序重新叠涂，并将整幅结果左右镜像。

关键洞察：
- 输出是把这叠不透明色板整体翻个面从背后看：左右颠倒，且原来被压住的颜色翻到最上层——只反层序不镜像、或只镜像不反层序都是陷阱。
```

## 5. 滚动旋转带

- tags:
  - operation:补全, reconstruct
  - operation:去噪, denoise
  - operation:旋转, rotation
  - object:遮挡矩形, occluding_rect
  - object:块单元, block_cell
  - relation:逐块旋转接力, per_block_rotation_relay
  - condition:多数表决, majority_vote
  - condition:伪镜像陷阱, fake_mirror_trap
  - condition:块界自推断, seamless_period_inference

### docstring

```text
发现画布被无缝划分成一排相邻方块、且每块都是前一块顺时针旋转 90 度的接力图案，用对应像点的多数表决还原被遮区域。

输入结构：
- 画布可被无缝划分为 k 个 h x h 的相邻方块（没有任何分隔线，h 需自行从周期性推断）。
- 最左块为图元，其后每块都等于前一块顺时针旋转 90 度。
- 一块实心灰色矩形遮住部分区域（可跨越相邻方块边界）；另有少量噪声像素篡改个别格子。
- 图元刻意接近镜像对称：按"相邻块交替镜像"的假设补全会在若干格子上出错。
- 每个对应组保证：被遮格子至多一个、被篡改成员至多一个；灰色不在图案用色之内。

规则：
- 推断块宽 h 与块数 k；按累计旋转把每个格子与它在其余各块中的对应像点归为一组。
- 对被遮住的每个格子，取组内全部可见成员的多数色作为还原色。
- 输出被遮矩形区域的还原内容，尺寸等于该矩形。

关键洞察：
- 块与块之间的真关系是"逐块再旋转 90 度"而非镜像交替；块界没有画出来、要靠周期性自己找；且因为有噪声，照抄任何单个对应像点都会踩坑，必须整组表决。
```

## 6. 指令巡行

- tags:
  - operation:路径绘制, path_draw
  - operation:查表解码, lookup_decode
  - object:图例面板, legend_panel
  - object:指令散点, instruction_pixel
  - object:双像素走者, two_pixel_walker
  - relation:位置定义语义, position_defines_meaning
  - condition:踩点才生效, stepped_on_only
  - condition:每例重定义色义, per_example_rebinding

### docstring

```text
按角落图例把散点颜色解码成转向指令，让箭头走者一路直行、踩点转向，画出全程轨迹。

输入结构：
- 画布上有一个双像素走者：红色头与灰色尾，行进方向为尾指向头。
- 画布一角有一个单色边框围成的图例面板，框内一行并排三个颜色像素：位于左格的颜色表示左转，位于中格的颜色表示停止，位于右格的颜色表示右转。
- 画布其余地方散布这三种颜色的单像素指令点；三种指令颜色在不同示例对中并不相同，必须现场查面板。
- 走者路径不会经过图例面板。

规则：
- 走者从头部出发沿行进方向逐格前进，所经格子一律染红。
- 每当踏进一个指令点：左转色则左转 90 度，右转色则右转 90 度，停止色则就地停下，指令格同样染红。
- 若下一步会越出网格，走者在边缘停下。
- 未被踏到的指令点原样保留，图例面板原样保留。

关键洞察：
- 指令颜色本身无固定含义，含义由它在图例框内的"位置"临时定义；散点中只有恰好落在轨迹上的才被执行，其余全是干扰。
```

## 7. 角点奇偶

- tags:
  - operation:填充, fill
  - operation:全局配组, global_grouping
  - object:角标记, corner_marker
  - object:矩形, rectangle
  - relation:行列对齐, row_column_alignment
  - condition:唯一划分, unique_partition
  - condition:奇偶叠涂, parity_paint

### docstring

```text
把画布上的黄点全局配组成若干矩形的四角，再按覆盖次数的奇偶给画布叠涂：奇数次为红，偶数次为黑。

输入结构：
- 黑色背景上只有黄色单像素点，共 4n 个。
- 这些点存在唯一一种划分方式，使每组四点恰好构成一个轴对齐矩形的四个角（共享两行两列）。
- 不同组的点之间存在同行同列的伪对齐，用来伪装成不存在的矩形；矩形之间可以重叠或嵌套。

规则：
- 找出那个唯一合法的四角划分，得到 n 个闭合矩形区域（含边界行列）。
- 对每个格子统计它被多少个矩形覆盖：奇数次染红，偶数次（含零次）保持黑色。
- 所有黄点最后原样保留为黄色。

关键洞察：
- 黄点不是各自独立的标记，而是必须全局同时满足的角约束；重叠区按奇偶抵消，两块矩形的公共部分会重新露出黑底，只按"矩形内部全染红"作答会在交叠处踩坑。
```
