## 1. 包络残迹反推生成线段

- tags:
  - operation:重建, reconstruct
  - operation:擦除, erase
  - object:三角残迹, triangle_residue
  - object:隐藏线段, hidden_bar
  - relation:包络配对, envelope_pairing
  - condition:残迹反推生成线, residue_infers_generator
- 参考题目题号: 13、10

### docstring

```text
由残存的包络三角形对反推被擦除的生成线段，输出只保留重建出的线段。

输入结构
- 黑色背景上散布若干实心等腰三角形，逐行（或逐列）宽度依次递减两格。
- 每对底边相对、平行等长、恰隔一条黑缝的同色三角形，原本是一条水平
  （或竖直）线段向两侧逐步收缩生成的菱形包络，线段所在的中线已被整条
  擦成黑色。
- 另有若干落单三角形（找不到配对者）作为干扰。

规则
- 将"底边相对、平行、等长、恰隔一行（或一列）黑缝"的同色三角形两两配对。
- 在每对之间的黑缝处画回一条该颜色线段：长度等于可见最宽一行的长度
  加二，且与三角形底边居中对齐。
- 画完后擦除所有三角形；无配对的落单三角形直接删除，不产生线段。

关键洞察
- 三角形不是要保留的对象，而是消失线段的"衍射残迹"；由包络逐层收缩
  两格的规律可知，原线段比画面上可见的最宽一行还要长两格，必须反推
  生成元而不是简单连接两个三角形。
```

## 2. 间隙配额跨容器灌注

- tags:
  - operation:计数, counting
  - operation:填充, fill
  - operation:擦除, erase
  - object:孤立种子, isolated_seed
  - object:实心矩形, solid_rectangle
  - relation:垂直对位, vertical_alignment
  - condition:间隙高度转配额, gap_height_to_quota
  - condition:余量跨隙传递, residual_passes_gap
- 参考题目题号: 18、5

### docstring

```text
每颗悬空种子按它与下方第一个矩形之间的间隙高度获得灌注配额，配额沿同列
的矩形串自上而下逐个灌注。

输入结构
- 黑色背景；上方有若干孤立的彩色单像素种子。
- 每颗种子的正下方沿同一列排着一个或多个实心灰色矩形，矩形之间隔着
  黑色空隙；有的种子正下方没有任何矩形。

规则
- 对每颗下方有矩形的种子：数出种子与第一个矩形顶边之间的黑色行数 d，
  作为要灌注的"行数配额"。
- 自第一个矩形顶边起，逐行把矩形整行涂成种子颜色，每涂一行消耗一点
  配额；若矩形涂满而配额未尽，剩余配额跳过下方黑色空隙（空隙不涂色、
  不消耗配额），从下一个矩形的顶边继续灌注。
- 配额耗尽即停；矩形串用完则多余配额废弃。擦除所有种子；正下方无矩形
  的种子直接删除。

关键洞察
- 种子不是要下落或画轨迹的对象，它与容器之间的"空气高度"才是被传递的
  数值；该数值像液体一样跨过空隙逐容器灌注，空隙只被跳过而不消耗配额。
```

## 3. 三象限投票纠错补全

- tags:
  - operation:对称补全, symmetry_completion
  - operation:纠错, error_correction
  - object:标记方块, marker_square
  - object:象限图案, quadrant_pattern
  - relation:三份冗余, threefold_redundancy
  - condition:逐位多数表决, per_cell_majority_vote
- 参考题目题号: 3、10

### docstring

```text
以 2x2 标记块为中心，把三个各含少量错误的已知象限逐位投票，重建全部
四个象限的干净对称图案。

输入结构
- 背景为单一颜色；网格中央有一个实心 2x2 标记块。
- 标记块周围四个象限中，三个画有前景图案，第四个完全空白。
- 三个已知象限的图案本应关于标记中心双轴对称（即互为镜像、折算后
  完全一致），但每个象限都混入了少量错误：该有的像素缺失、不该有的
  像素多出。

规则
- 以标记块中心为水平与竖直双镜轴，把三个已知象限逐格折算到同一标准
  象限坐标。
- 每个标准位置取三票多数：至少两个象限认为是前景则判为前景，否则判为
  背景。
- 用表决结果同时补出空白象限并改正三个已知象限，输出完全双轴对称的
  图案；标记块原样保留。

关键洞察
- 这不是把某个现成象限镜像过去——任何单一象限都是脏的，三份冗余拷贝
  的逐位多数表决才是唯一能同时定位并修复错误的机制。
```

## 4. 缺角定位、方位取色

- tags:
  - operation:补全, complete
  - operation:查表取色, color_lookup
  - object:三角标组, three_corner_group
  - object:调色块, palette_block
  - relation:宏观象限, global_quadrant
  - condition:方位查色缺角定位, quadrant_color_corner_position
- 参考题目题号: 8、17

### docstring

```text
补上每个三角标组缺失的第四角，补角颜色由整组相对中央调色块所处的象限
查表决定。

输入结构
- 背景为单一颜色；网格中有唯一一个实心 2x2 调色块，四格颜色互不相同。
- 四周散布若干灰色三角标组：每组三个单像素，恰为某个正方形的三个角，
  第四个角缺失。
- 每组整体位于调色块的左上、右上、左下、右下四个象限之一。

规则
- 对每组补出正方形缺失的第四角像素，位置由缺角决定。
- 补角颜色不取灰色：以标组中心相对调色块中心所处的象限为索引，查
  调色块中同象限那一格的颜色作为补角颜色。
- 原有三个灰角与调色块全部原样保留。

关键洞察
- 缺角的方向只决定"画在哪"，与颜色无关；颜色由整组的宏观方位查中央
  色表——示例中特意安排了缺角方向与整组方位不一致的标组，用来戳破
  "按缺角方向取色"的第一直觉。
```

## 5. 色条是尺寸指令而非计数汇报

- tags:
  - operation:筛选, filter
  - operation:擦除, erase
  - object:指令色条, instruction_bar
  - object:四连通物体, four_conn_object
  - relation:同色配对, same_color_pairing
  - condition:面积等于条长, size_equals_bar_length
- 参考题目题号: 12、4

### docstring

```text
顶部色条是先行下达的尺寸指令：只保留像素数恰好等于同色条长度的物体。

输入结构
- 顶部是黑色指令区，含若干从第 0 列起的水平色条，各色至多一条，长度
  互不相同。
- 下方场景面板有自己的非黑背景色，散布多个 4 连通彩色物体；同色物体
  可有多个，且大小各不相同。

规则
- 面板中每个物体：若其颜色在指令区有对应色条，且物体像素数恰好等于
  该色条的长度，则保留；否则涂成面板背景色。
- 颜色未出现在指令区的物体一律删除。
- 指令区原样保留。

关键洞察
- 因果方向与直觉相反——色条不是对面板物体的统计汇报，而是筛选阈值；
  第一个示例中每种颜色恰好只有一个等长物体，极易误读成"条长等于物体
  计数"或"输出汇总条"，后续示例才暴露真正的匹配方向。
```

## 6. 周期条带叠加颜色轮转的修复

- tags:
  - operation:补全, complete
  - operation:色环推进, color_cycle_step
  - object:周期条带, periodic_band
  - object:缺失像素, missing_pixel
  - relation:平移加置换, translation_plus_permutation
  - condition:步数随距离累积, steps_accumulate_with_distance
- 参考题目题号: 1、9

### docstring

```text
修复黑洞必须同时用上"图案按竖条带周期重复"与"每重复一次全部颜色沿
固定置换环推进一步"的复合规律。

输入结构
- 网格由一个宽 w 的基础竖条带向右反复拼接而成；但每拼接一次，条带内
  所有颜色都按同一个颜色置换环前进一步。
- 若干像素被擦成黑色缺口；黑色不出现在置换环中。

规则
- 由未缺损区域确定条带宽 w 与颜色置换环（含环上的不动点颜色）。
- 对每个黑洞：取同一行中列号与其相差 w 的整数倍的任一已知像素，把该
  像素的颜色沿置换环推进相应的条带数步，得到填充色。
- 输出为完全修复后的网格。

关键洞察
- 这不是普通的平铺修复——相邻条带对应格的颜色并不相等，而是"轮转一
  档"；置换环上恰好安排了不动点颜色作掩护，使前两条带乍看像纯周期，
  只有对不上的颜色才逼出隐藏的置换层。
```

## 7. 双墙投影重建隐形矩形

- tags:
  - operation:重建, reconstruct
  - operation:分层叠放, layered_painting
  - object:投影刻度, projection_tick
  - object:隐形矩形, invisible_rectangle
  - relation:双投影配对, dual_projection_pairing
  - condition:面积决定层序, area_determines_order
- 参考题目题号: 11、13

### docstring

```text
把底边与右边两组彩色刻度线段按颜色配对成实心矩形，并按面积从大到小的
次序叠放画出。

输入结构
- 黑色背景；最底一行有若干互不重叠的彩色水平线段，最右一列有同一批
  颜色的竖直线段，两组颜色一一对应。
- 除这两条边外，场景内部完全空白。

规则
- 每种颜色：底行线段给出列区间，右列线段给出行区间，二者张成一个实心
  矩形，画入内部区域。
- 矩形之间可以重叠；重叠处按面积从大到小依次绘制，即面积小的矩形覆盖
  面积大的矩形。各矩形面积互不相同。
- 底行与右列的刻度线段原样保留。

关键洞察
- 两条边不是要延伸的射线源，而是同一批隐形矩形在两面"墙"上的投影；
  参与规则的对象从未被完整画出，且叠放次序由面积这一派生量决定，而非
  位置或颜色顺序。
```

## 8. 灰点陈述孔数的自指筛选

- tags:
  - operation:裁剪, crop
  - operation:计数, counting
  - object:灰点标记, gray_marker
  - object:带孔物体, holed_object
  - relation:自指匹配, self_referential_match
  - condition:灰点数等于孔数, markers_equal_holes
- 参考题目题号: 7、14

### docstring

```text
裁剪输出灰点数量恰好等于自身孔洞数量的唯一物体。

输入结构
- 黑色背景上散布若干彩色实心物体，每个物体内部留有若干一格大小的
  黑色孔洞，孔洞数各不相同。
- 每个物体身上贴有若干灰色像素，各物体的灰点数彼此不同。

规则
- 对每个物体分别数出其内部孔洞数与其所贴灰点数。
- 唯一存在一个物体两数恰好相等；裁剪输出该物体，其中灰点位置还原为
  物体自身颜色，孔洞保留为黑色。

关键洞察
- 灰点不是装饰也不是指向别处的选择指针，而是对物体自身一项隐藏属性
  （孔数）的"陈述"，只有陈述为真的物体被输出；各物体灰点数互不相同，
  使"选灰点最多者""选最大物体"等捷径在跨示例时全部被证伪，第一个
  示例中被选中者恰好也是最大物体，专作诱饵。
```

## 9. 外距选层、方位选边

- tags:
  - operation:同心层填充, concentric_fill
  - operation:重涂色, recolor
  - object:空心方框, hollow_square
  - object:外部标记像素, outer_marker_pixel
  - relation:距离对深度, distance_to_depth
  - relation:方位对边段, side_to_segment
  - condition:外距翻折为内层, outer_gap_folds_inward
- 参考题目题号: 9、20

### docstring

```text
框外每个彩色标记按它与方框的间隔距离选定内部同心壳层，再按它所在的
方位只点亮该层朝向它的那一条边段。

输入结构
- 黑色背景；一个一格厚的灰色空心方框。
- 框外散布若干彩色单像素标记，分别位于框的上、下、左、右方向，与
  框壁之间隔着数量不等的黑色格。

规则
- 框内部按到框壁的距离划分同心壳层：紧贴框壁的一圈为第 1 层，向内
  逐层递增。
- 每个标记与框的最近间隔距离 d 选定第 d 层；标记相对方框的方位选定
  该层四条边段中朝向标记的那一条，把这条边段整段涂成标记色。
- 不同标记可以命中同一层的不同边段；未被任何标记指定的部分保持黑色；
  方框与外部标记原样保留。

关键洞察
- 标记既不是射线起点，也不触发整圈涂层；它与框之间的空气间隙被"翻折"
  成内部深度，而它的方位再从该深度的一圈中切出一条边——两个独立维度
  必须同时破解，缺一个都对不齐示例。
```

## 10. 模板字典反查降采样

- tags:
  - operation:解码压缩, decode_downscale
  - operation:模板匹配, stencil_match
  - object:模板图例, stencil_legend
  - object:噪声块, noise_block
  - relation:形状级匹配, shape_level_matching
  - condition:不匹配即背景, unmatched_to_background
- 参考题目题号: 16、10

### docstring

```text
把由模板块拼成的大图逐块识别、反查图例，压缩成一格对应一块的索引小图。

输入结构
- 顶部图例给出若干个 3x3 中性色模板，形状互不相同，其中包括一个实心
  满块模板；图例与下方主区以空行隔开。
- 主区的行列数可被 3 整除，划分为 3x3 块：每块要么是某个模板以单一
  颜色染成的拷贝，要么是与任何模板都对不上的杂乱噪声块。

规则
- 对主区每个 3x3 块，与图例模板做形状匹配（忽略颜色，只比对前景格的
  位置布局）。
- 匹配成功的块在输出中记为一格，颜色取该块的染色；与所有模板都不匹配
  的噪声块在输出中记为背景色。
- 输出网格的行列数为主区的三分之一。

关键洞察
- 不能用"每块取众数颜色"的捷径——噪声块同样有众数色，会得到错误的
  非背景输出；只有形状级的模板核对才能区分真图元与噪声。图例是用来
  反查的解码字典，其本身不进入输出。
```
