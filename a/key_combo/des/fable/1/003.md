## 1. 动量接力滑动

- 主要机制: 碰撞时运动整体转移（牛顿摆式接力）
- 原语来源: 滑动/碰撞停止（17829a00）× 颜色匹配边（5034a0b5）× 链式反应传播（5961cc34）
- tags:
  - 操作:滑动
  - 操作:碰撞传递
  - 对象:边框边
  - 对象:实心块
  - 关系:颜色匹配边
  - 条件:动量整体转移
  - 条件:紧贴即停

### docstring

```text
一句话总述
唯一与边框同色的块朝其同色边滑动，碰撞时把运动整体转交给被撞的块，接力直到有块贴上边框。

输入结构
- 网格最外圈是一格厚边框：四角为背景色，四条边各为一种互不相同的纯色。
- 内部散布若干互不相触的实心矩形块；恰有一个块与某条边同色（发动块），
  其余块均为同一种中性色。
- 发动块滑向同色边的路径上依次隔空排布着零个或多个中性块。

规则
- 发动块沿直线滑向与其同色的边。
- 当滑动块的任一格即将与另一块重叠时，滑动块立即停在紧贴处，
  被撞的块沿同一方向继续滑动。
- 运动如此逐块接力，直到当前滑动块紧贴边框为止。
- 不被撞到的块保持原位；边框与所有块的形状、颜色不变。

关键洞察
- 块不会推挤成堆也不会一起贴墙：碰撞把运动完整转移给被撞块，
  每个中途参与的块只前进到紧贴"下一个块原位置"处，
  只有接力链最后一个块真正抵达边框。
- 全场唯一的方向信息来自发动块与边框的颜色匹配，中性块自身不携带方向。
```

## 2. 并集里的隐形模板

- 主要机制: 模板从未画出，仅作为全部碎片对齐后的并集隐式存在
- 原语来源: 模板补全/碎片锚定（fd096ab6）× 生成元残迹（灵感参考：参与规则的对象从未被完整画出）
- tags:
  - 操作:补全
  - 操作:对齐叠合
  - 对象:碎片
  - 对象:锚点像素
  - 关系:锚点对齐
  - 条件:并集成形
  - 条件:无完整样本

### docstring

```text
一句话总述
把所有碎片按各自的锚点像素对齐取并集得到从未画出的完整模板，再用模板把每个碎片补全。

输入结构
- 均匀背景上有若干颜色互不相同的碎片（同色像素合为一个碎片，可不连通）。
- 每个碎片中恰含一个锚点色像素，锚点在完整形状中占据同一个固定位置。
- 没有任何碎片是完整形状；完整形状不在输入中出现。

规则
- 以锚点像素为公共原点，把所有碎片平移对齐后取并集，得到隐藏模板的完整掩码。
- 对每个碎片：保持其锚点与已有像素不动，用该碎片自身的颜色补出模板中缺失的格子。
- 锚点像素在输出中保持锚点色，背景保持不变。

关键洞察
- 完整模板在画面上从未出现，它只作为全部碎片对齐后的并集隐式存在；
  任何单个碎片（包括最大的那个）都不足以充当模板，必须跨对象汇总残缺投影。
```

## 3. 穿过遮挡的周期平铺与探针

- 主要机制: 遮挡下相位照常推进，遮挡块作为隐形图层的采样探针
- 原语来源: 周期平铺/贴附侧定方向（53fb4810）× 前景遮挡（52df9849）× 控制像素读值（fc754716）
- tags:
  - 操作:周期平铺
  - 操作:射线延伸
  - 操作:重涂色
  - 对象:基座条
  - 对象:图案块
  - 对象:遮挡块
  - 关系:贴附侧定方向
  - 条件:相位全程保持
  - 条件:中心格采样定色

### docstring

```text
一句话总述
小图案沿背离基座方向周期延伸并从遮挡块下方穿过，每个被穿过的遮挡块整体改染成其中心格下方那枚看不见的图案色。

输入结构
- 背景为最常见色。
- 若干基座条（同一基座色的短实心条），每条基座一侧紧贴一个小的多色周期图案块。
- 画面散布若干灰色实心遮挡块（奇数边长，有唯一中心格），
  有的位于延伸路径上，有的不在。

规则
- 每个图案块以自身为一个周期，沿背离基座的方向重复延伸至网格边缘，
  但只画在背景格上。
- 延伸经过遮挡块时不画出被盖住的格子，相位照常推进，
  露出处与全局周期严格对齐。
- 被延伸穿过的遮挡块整体改染为"其中心格若无遮挡本应是的图案色"；
  未被穿过的遮挡块保持灰色。
- 基座与图案块本体保持不变。

关键洞察
- 遮挡块下有一层从未画出的图案在按相位继续；遮挡块是这层隐形图案的采样探针，
  其整体颜色泄露了中心格下的隐藏值，因此必须真正推算被遮部分，
  而不能只"跳过后继续"。
```

## 4. 边框图例路由折线

- 主要机制: 彩色散点是转向指令，指令含义由边框图例现场定义
- 原语来源: 颜色定射线方向（8d510a79）× 边框边作方向标签（5034a0b5）× 路径记录（bcb3040b）× 链式串行（5961cc34）
- tags:
  - 操作:射线延伸
  - 操作:连线
  - 对象:边框边
  - 对象:路由点
  - 对象:起点缺口
  - 关系:颜色查表转向
  - 条件:图例随题面变化
  - 条件:串行接力路由

### docstring

```text
一句话总述
从边框缺口射入的射线每进入一个彩色路由点，就立即转向朝着与该点同色的那条边框边，走出一条被记录的折线。

输入结构
- 网格最外圈为一格厚边框：四角为背景色，四条边各为一种互不相同的纯色，
  且不同示例中四种颜色的方位分配不同。
- 边框某处有一格被起点色替换成缺口，射线从缺口垂直于所在边射入内部。
- 内部散布若干单像素路由点，颜色均取自四种边色。

规则
- 射线沿直线前进，途经的背景格染成起点色。
- 每当射线进入一个路由点格，立即改向为指向与该路由点颜色相同的那条边框边，
  路由点本身颜色保留。
- 射线到达边框即终止。
- 未被经过的路由点保持原样，不产生任何路径。

关键洞察
- 彩色散点不是障碍也不是目标，而是转向指令；指令的含义不在点本身，
  而在边框图例里——同一颜色在不同题面代表不同方向，必须每次现场查表。
- 路径是唯一一条按指令串行走出的折线，缺口给出了入射方向。
```

## 5. 算出来的钥匙

- 主要机制: 算术结果作为跨对象选择的键值
- 原语来源: 高度加减算术（37ce87bb）× 棋盘格计数匹配（df8cc377）× 填充（2281f1f4）
- tags:
  - 操作:计数
  - 操作:算术
  - 操作:填充
  - 对象:竖条
  - 对象:空心矩形
  - 对象:棋盘格
  - 关系:数量相等匹配
  - 条件:高度差作键值
  - 条件:唯一命中

### docstring

```text
一句话总述
用加色条总高减去减色条总高得到键值，找到内部棋盘格数恰等于键值的那个空心矩形并按棋盘式染色。

输入结构
- 网格底部有若干底对齐的单格宽竖条：青色条为加项，红色条为减项。
- 网格其余区域散布若干一格厚的空心矩形框，内部均为空背景且大小各异。
- 恰有一个矩形框的内部棋盘格数等于键值；另布有干扰框，
  例如内部总面积等于键值的框、棋盘格数等于只算加项总高的框。

规则
- 计算键值 = 青色条高度之和 − 红色条高度之和。
- 对每个矩形框，从内部左上角开始按棋盘格隔一染一地数出可染格数。
- 将棋盘格数恰等于键值的那个矩形框的内部按该棋盘模式染成灰色；
  其余框、竖条与背景保持不变。

关键洞察
- 竖条不是待搬运的对象而是一台算高度差的计算器；矩形框不按位置或外观匹配，
  而是以内部棋盘容量等于算术结果这一纯数量关系被选中，
  面积相等或只算加项都会指向错误的框。
```

## 6. 隐形中线的交点

- 主要机制: 从未画出的中线两两相交留下痕迹，颜色由行提供者决定
- 原语来源: 中心十字线（41e4d17e）× 行列交叉/笛卡尔积（2281f1f4）× 遮挡吞没（41e4d17e 的叠放次序）
- tags:
  - 操作:放置
  - 对象:空心矩形
  - 对象:隐形中线
  - 对象:交点像素
  - 关系:行列交叉
  - 条件:行提供者定色
  - 条件:落框即吞没

### docstring

```text
一句话总述
每个空心矩形的中心行与中心列是两条不画出的隐形直线，把不同矩形的隐形行与隐形列的交点染成提供行的矩形的颜色。

输入结构
- 背景上分布若干互不相触、颜色互不相同的奇数边长空心矩形。
- 各矩形的中心行两两不同，中心列两两不同。

规则
- 把每个矩形的中心行与中心列视为贯穿整个画布的隐形直线，直线本身不绘制。
- 对每一对不同矩形 A、B：A 的中心行与 B 的中心列的交点若落在背景上，
  则把该格染成 A 的颜色。
- 交点落在任何矩形的边框上或内部时不染色。
- 所有矩形保持原样。

关键洞察
- 画面上自始至终没有任何直线；新增的孤立像素是隐形中线两两相交留下的痕迹，
  且颜色跟随提供"行"的矩形，而非提供"列"的或距离更近的矩形。
```
