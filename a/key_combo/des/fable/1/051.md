## 1. 缺口流出序列

- 参考题目题号：19、6、2
- tags:
  - operation:提取, extract
  - operation:射线延伸, ray_extend
  - operation:擦除, erase
  - object:缺口矩形框, one_gap_rect_frame
  - object:内部散点, interior_scatter
  - relation:测地距离排序, geodesic_order
  - condition:缺口定向与序, gap_sets_direction_and_order

### docstring

```text
框内散点按到缺口的距离排队，沿缺口外的直线依次流出。

输入结构
- 网格有统一背景色和若干互不接触的同色空心矩形框。
- 每个框的边上恰有一个非角位置缺失一格，即缺口。
- 每个框内部散布若干彩色像素；同一框内任意两个散点到缺口的框内
  最短四连通距离互不相同。

规则
- 对每个框，计算每个内部散点沿框内空格走到缺口格的最短四连通步数。
- 从缺口向框外作垂直于该边的射线，自框外第一格起，按距离从小到大
  把散点颜色依次填入射线上的连续格。
- 清除框内全部散点为背景色；框体与缺口保持原样。

关键洞察
- 内部散点不是噪声而是内容物：缺口同时给出出口位置、流出方向和
  排序基准，散点按"谁先到出口谁先出去"的次序在框外排成一列；
  按行读、按列读或按包围盒顺序读都会得到错误的序列。
```

## 2. 置换对称真轴

- 参考题目题号：3、10、7
- tags:
  - operation:筛选, filtering
  - operation:镜像, mirror
  - operation:补全, complete
  - operation:擦除, erase
  - object:候选贯穿线, candidate_full_line
  - object:前景图案, foreground_motif
  - relation:形状层近似对称, shape_level_near_symmetry
  - relation:跨轴颜色置换, cross_axis_color_bijection
  - condition:唯一真轴, unique_true_axis
  - condition:诱饵轴剔除, decoy_axis_removal

### docstring

```text
在多条候选贯穿线中找出形状层面近似镜像的真轴，归纳跨轴颜色置换后
补全缺失像素，并抹去假轴。

输入结构
- 背景上有一幅多色前景图案和若干条同色的贯穿整行或整列的候选线；
  候选线所在的行或列除线色外不含任何前景像素。
- 恰有一条候选线满足：前景的占位形状（不看颜色）关于它镜像对称，
  且两侧对应像素的颜色遵循一个一致的双射置换——左侧每种颜色恒
  对应右侧某种颜色。
- 另有少数格是"单侧缺失"：一侧有前景而镜像位置为背景。
- 其余候选线两侧的前景连占位形状都明显不对称。

规则
- 逐条检验候选线，找到占位形状近似镜像的那条真轴。
- 把其余候选线整条抹为背景。
- 从完好的对应像素对中归纳颜色置换表；对每个单侧缺失格，取镜像
  位置的颜色经置换后补在背景一侧；真轴保留。

关键洞察
- 对称藏在占位形状层面，两侧颜色不同是伪装，直接按颜色找对称会
  把真轴也判成假轴；补全用的颜色也不是镜像色本身，而要过一道从
  图中自行归纳的置换。
```

## 3. 三证词对质

- 参考题目题号：4、14、16、5
- tags:
  - operation:压缩, compress
  - operation:配准, registration
  - operation:多数投票, majority_vote
  - object:分隔条, separator_bar
  - object:放大变换副本, scaled_oriented_replica
  - relation:尺度对应, scale_correspondence
  - relation:朝向对应, orientation_correspondence
  - condition:倍率由边长比推断, ratio_from_dims
  - condition:三方多数定真值, three_way_majority

### docstring

```text
三个区域是同一幅图在不同倍率、不同朝向下的三份证词；先配准归一
再逐格多数决，输出修复后的正立小图。

输入结构
- 两条贯穿分隔条把网格分成三个区域，尺寸分别为最小版本及其两个
  不同整数倍的放大，倍数组合随示例变化。
- 三个区域是同一幅母图的三个版本：除放大外，每个版本还各自经过
  了八种正交朝向（旋转 0/90/180/270 度及各自的镜像）之一的变换；
  母图没有任何旋转或镜像自对称，故配准唯一。
- 每个版本中另有少数块被整块换成错误的均匀颜色；同一逻辑位置至
  多一个版本出错。

规则
- 由各区域的边长及长宽是否互换，识别每个版本的倍率与可能的转置。
- 把每个区域分块降采样到最小尺寸，穷举朝向找到使三个版本几乎逐
  格一致的配准，以最小区域的朝向为准。
- 对每个逻辑格取三个版本中出现至少两次的颜色，输出该最小尺寸的
  正确图。

关键洞察
- 归一有两个独立维度——尺度和朝向，少做任何一个都对不上号；
  配准的依据只能是"内容彼此几乎一致"这一内生约束，而孤立的错误
  块恰好要等三方对质的多数决才能与真实差异区分开。
```

## 4. 演示教算子

- 参考题目题号：14、16、13
- tags:
  - operation:逻辑运算, logical_op
  - operation:规则归纳, rule_induction
  - object:演示三联面板, demo_triple_panel
  - object:主掩码对, main_mask_pair
  - object:分隔条, separator_bar
  - relation:逐像素对应, pixelwise_correspond
  - condition:算子由演示定义, operator_defined_by_demo
  - condition:四组合全覆盖, all_four_combos_present

### docstring

```text
从题面上排的演示三联归纳本题使用的逐格逻辑算子，再把它施加到
下排的主掩码对上。

输入结构
- 分隔条把网格分成两排：上排三个等尺寸小面板 P、Q、R，下排两个
  等尺寸大面板 A、B。
- P、Q、A、B 的活跃格用同一种颜色，R 的活跃格用另一种颜色。
- R 恰是 P 与 Q 按某个逐格二元逻辑运算得到的结果，且 P、Q 的逐格
  取值组合覆盖了全部四种情况。
- 不同示例演示的算子各不相同，如与、或、异或、或非等。

规则
- 对照 P、Q、R，归纳该算子在四种输入组合（双活跃、仅左活跃、
  仅右活跃、双空）下的输出。
- 对 A、B 逐格应用该算子。
- 输出与 A 同尺寸：结果为真的格涂 R 的活跃色，其余为背景。

关键洞察
- 这道题里"规则"本身不固定——它作为一组演示数据画在上排；
  解题分两层：先从小面板反演出算子的真值表，再把它施加到大面板
  上，任何一个示例单看都自带完整的说明书。
```

## 5. 视线交汇

- 参考题目题号：16、19、6
- tags:
  - operation:射线延伸, ray_extend
  - operation:多数投票, majority_vote
  - operation:单点绘制, single_cell_paint
  - object:指向精灵, pointer_sprite
  - object:诱饵精灵, decoy_sprite
  - relation:视线交汇, sightline_convergence
  - condition:最多覆盖格唯一, max_coverage_cell_unique

### docstring

```text
找出被最多条视线穿过的那一格，画出命中它的视线并点亮它。

输入结构
- 背景上散布若干指向精灵：每个精灵是一根 3 格短杆（体色互不相同），
  加上杆一端延长线上紧邻的 1 格灰色喷嘴，喷嘴所在端即指向。
- 多数精灵的视线——从喷嘴起沿杆的延长方向的直线——穿过同一格；
  另有一到两个诱饵精灵，其视线不经过该格。
- 保证被最多条视线穿过的格唯一。

规则
- 从每个喷嘴沿其指向作射线，统计每个背景格被穿过的次数。
- 找出被最多条视线穿过的唯一格。
- 命中该格的每条视线，从喷嘴外第一格画到该格前一格，用各自杆的
  体色；该格本身涂灰色；诱饵精灵保持原样，不画线。

关键洞察
- 目标格在输入中毫无标记，它只存在于多条视线的交汇处；而且不能
  求"全体视线的公共交点"——诱饵会让公共交点不存在，必须改取
  被穿过次数最多的那一格。
```

## 6. 光过缺口

- 参考题目题号：19、7、9
- tags:
  - operation:射线延伸, ray_extend
  - operation:洪泛填充, flood_fill
  - object:边缘发射器, edge_emitter
  - object:缺口矩形框, one_gap_rect_frame
  - relation:对准判定, alignment_test
  - condition:缺口在光路上才入内, gap_on_path_to_enter

### docstring

```text
边缘发射器的光线只点亮缺口恰好在其光路上的框。

输入结构
- 网格边缘上有若干发射器像素，颜色互不相同，各自向垂直于所在边
  的内侧方向发光。
- 场内散布若干互不接触的同色空心矩形框，每框恰有一个非角缺口。
- 发射器所在的行或列上可能有零个、一个或多个框。

规则
- 每条光线沿直线穿过背景格，走过的格涂成该发射器的颜色。
- 光线若到达某框的缺口格，就穿过缺口进入框内并终止：该框整个
  内部洪泛涂成光色，缺口格也涂光色。
- 光线若碰到框壁（非缺口）则终止于壁前一格，该框内部不填；
  一路无阻的光线画到对侧边缘为止。

关键洞察
- 框亮不亮与它离发射器的远近无关，只取决于它唯一的缺口是否恰好
  摆在某条光路上；缺口同时是判定条件、入口和光的终点，离得最近
  的框反而可能一直是暗的。
```

## 7. 多米诺连锁

- 参考题目题号：11、18
- tags:
  - operation:折叠, fold
  - operation:连锁反应, chain_reaction
  - object:直线杆, straight_rod
  - object:触发像素, trigger_pixel
  - relation:触及传递, reach_propagation
  - condition:高度盖过间距则倒, fall_if_height_covers_gap

### docstring

```text
推倒第一根杆，够得着下一根就继续倒，够不着连锁就此打住。

输入结构
- 底边一行为地面色，其上立着若干根同色竖直杆，杆底都落在地面上，
  高度与相邻间距各不相同。
- 最外侧一根杆的顶端外侧紧邻一个触发像素，表示把这根杆向内侧
  （其余杆所在的一侧）推倒。

规则
- 被推倒的杆绕底端旋转放平：改为占据地面上方第一行、从原底端所
  在列起向倒向连续延伸、总长等于杆高的水平线段。
- 若放平后的线段到达或越过下一根未倒之杆所在的列，下一根杆也向
  同方向倒下；否则连锁就此终止。
- 未被波及的杆保持直立；触发像素在输出中消失。

关键洞察
- 每根杆的命运由"前一根的高度是否盖得过两者的间距"逐级决定，
  是一条会中途断掉的因果链；既不能只推第一根，也不能全部放平，
  必须沿链逐根裁定断点在哪。
```

## 8. 测地年轮

- 参考题目题号：2、7、9、12
- tags:
  - operation:洪泛填充, flood_fill
  - operation:交替选取, alternating_selection
  - object:不规则腔体, irregular_cavity
  - object:种子像素, seed_pixel
  - object:壁上色标, wall_color_mark
  - relation:测地距离, geodesic_distance
  - condition:波前奇偶定色, wavefront_parity_color
  - condition:近远色标定序, near_far_mark_order

### docstring

```text
从种子出发沿腔内测地距离一圈圈交替涂色，两种颜色与先后次序由
嵌在腔壁上的两个色标决定。

输入结构
- 墙色围成一个封闭的、形状不规则（含凹陷或通道）的腔体，腔内
  其余为背景。
- 腔内有一个种子像素；腔壁上恰有两格被换成了两种不同的色标颜色。
- 两个色标到种子的腔内最短四连通距离不相等。

规则
- 计算腔内每个背景格到种子的最短四连通距离，只许走腔内、绕开墙。
- 距离为奇数的格涂"近色标"的颜色，距离为偶数的格涂"远色标"的
  颜色；近与远按两个色标到种子的腔内测地距离比较。
- 种子保留原色，墙与色标保持不动，腔内填满为止。

关键洞察
- 环带跟随的是绕障碍的波前距离而不是直线距离，凸区域里它看似
  同心方环，进了凹腔同一环就会拐弯分叉；用哪两种颜色、谁先谁后
  在题面上没有明说，要从壁上两个色标与种子的远近关系里读出来。
```
