## 1. 边界播撒，近者优先

```text
每个边界标记以其同色散点的个数为周期向网格内部播撒射线，交叉处距离己方标记近者获胜，散点本身全部抹除。

输入结构
- 黑色背景网格，四条边界上有若干不同颜色的标记像素，均不在角落。
- 网格内部散布这些颜色的孤立散点，位置任意。
- 每种颜色恰有一个边界标记；散点个数因颜色而异。

规则
- 对每种颜色 c，数出内部散点的个数 k，并删除这些散点。
- 从 c 的边界标记向网格内部（垂直于所在边）播撒：在距标记 k、2k、3k……格处
  各涂一个 c 色像素，直到越出对侧边界为止。
- 横向与纵向的播撒射线若命中同一格，保留距自己标记更近的那个颜色
  （示例中不出现等距冲突）。
- 边界标记本身保留。

关键洞察
- 散点是纯粹的计数材料，既不保留也不与标记连线；个数被读成播撒的节拍（周期），
  而交叉竞争由"离源更近"裁决，与颜色和处理顺序无关。
```

## 2. 陪审团定轴，只交补丁

```text
四块面板中两块共享同一条镜像轴、一块关于另一条轴对称作孤票诱饵，唯一双轴皆不对称的面板按多数轴补全，但只输出补全时新增的那些格子。

输入结构
- 分隔线把网格等分成四块同尺寸方形面板，每块为背景加一种前景色掩码，四色互不相同。
- 恰有两块掩码关于同一条中轴（水平中轴或垂直中轴之一）镜像对称。
- 另一块掩码关于另一条中轴对称，是孤票诱饵。
- 剩下一块掩码关于两条中轴都不对称。

规则
- 检测每块面板掩码关于水平、垂直两条中轴的对称性，取得票最多的那条轴为公认轴。
- 双轴皆不对称的面板是残缺者：把它的掩码关于公认轴做镜像，
  取镜像中落在背景上的格子，即补全所需新增的部分。
- 输出单块面板尺寸的网格，只画这些新增格子，颜色沿用残缺面板自身的前景色，
  其余格子为背景。

关键洞察
- 对称轴不是全局约定，而由面板间"投票"产生，孤票对称是陷阱；
  输出不是修好的整体而是修补用的那块补丁——掩码里已有的部分一格都不画。
```

## 3. 房间数拨表针

```text
每个分隔框架内部的封闭房间数决定同色小母题原地顺时针旋转的步数。

输入结构
- 黑色背景上有若干彩色矩形分隔框架，框架内部被同色隔墙分成一个或多个封闭房间。
- 每个框架颜色在网格其他位置对应一个同色小母题，母题的包围盒为正方形，
  且母题不与任何框架相邻。

规则
- 对每个框架，数出其墙体围出的封闭房间个数 n。
- 找到与该框架同色的母题，绕自身包围盒中心顺时针旋转 90°×n（按模 4 生效），
  原地放回。
- 所有框架及其隔墙保持不变。

关键洞察
- 框架既不是容器也不是被改写的对象，而是每个母题的"表盘"：
  房间计数是唯一从框架流向母题的信息，同色是配对通道。
```

## 4. 隐形线只留交点

```text
同列上下成对与同行左右成对的边界标记各自定义一条从未画出的隐形线，只在同色隐形线的交叉处涂上该颜色。

输入结构
- 黑色背景，前景像素全部位于最外圈边界上，颜色若干。
- 上、下边界中位于同一列且同色的两个标记构成一条隐形竖线；
  左、右边界中位于同一行且同色的两个标记构成一条隐形横线。
- 另有一些无法按上述方式配对的边界像素作为干扰。

规则
- 找出所有同色对齐的标记对，得到若干条隐形竖线与隐形横线。
- 隐形线本身一律不画。
- 仅当一条隐形竖线与一条隐形横线颜色相同时，在二者交叉的格子涂上该颜色；
  异色交叉与不成对标记不产生任何输出。
- 全部边界像素原样保留。

关键洞察
- 标记定义的线是纯粹的中间量，画面上永不出现；
  答案只由"同色×同色"的交点生成，颜色配对与几何对齐必须同时成立。
```

## 5. 色钥链

```text
整行单色行给出入口颜色，沿"边框色→内容色"的指针链逐个跳箱，输出链条末端箱子的内容。

输入结构
- 杂色噪声网格中恰有一行整行同色，其余各行均含多种颜色。
- 网格上散布若干空心方框，边框颜色互不相同，每个方框内部装有一个单色小图案。
- 某些方框的内容颜色恰是另一个方框的边框颜色，从而首尾相接成链；
  链外另有干扰方框，其内容颜色同样不对应任何边框；噪声中也零散出现这些颜色。

规则
- 读取唯一单色行的颜色，作为当前颜色。
- 反复执行：找到边框为当前颜色的方框，读取其内部图案的颜色作为新的当前颜色；
  若不存在边框为该颜色的方框则停止。
- 停止时输出最后进入的那个方框的内部区域（不含边框），尺寸即其内部大小。

关键洞察
- 方框的内容不是答案而是下一站的地址，画面构成一条隐藏的指针链；
  单色行只提供链条入口，中途任何一站都不是终点，
  链外的"无后继"方框专门堵死绕过链条的捷径。
```

## 6. 缺口即重力

```text
每个空心矩形框上的一格缺口决定框内散件的下落方向，散件朝缺口一侧堆积，正对缺口的那一道还会漏出框外继续滑行。

输入结构
- 黑色背景上有若干灰色空心矩形框，每个框恰在某一条边的非角落位置开有一格缺口。
- 每个框内部散布若干彩色单格散件，位置任意。
- 不同框的缺口可以位于不同方向的边上。

规则
- 对每个框，把缺口所在边的朝向定为该框的重力方向，
  框内所有散件沿该方向滑动并靠墙依次堆积，同一道内保持原有先后次序。
- 与缺口正对的那一道散件不被墙挡住：按先近后远依次穿过缺口滑出框外，
  继续沿重力方向滑行，直到撞上网格边界、其他框或先漏出的散件为止。
- 框体与缺口保持不变。

关键洞察
- 重力方向不是全局给定的，而由每个框自身的缺口位置局部决定；
  缺口同时扮演方向指针与唯一泄漏通道两重角色。
```

## 7. 锚点剪纸

```text
以两侧灰色锚点重合的方式对齐两张掩码，用较小的掩码在较大的掩码上剪洞。

输入结构
- 一条实心分隔列把网格分成等宽的左右面板，
  各含背景、一种前景色掩码和恰好一个灰色锚点像素。
- 两侧前景色不同，两侧掩码的格数不相等；灰色只作为锚点出现。
- 两个锚点在各自面板内的位置一般不同，按面板坐标直接对齐会得到错误答案。

规则
- 把格数较少的掩码整体平移，使其锚点与较大掩码一侧的锚点重合。
- 输出较大掩码所在面板（去掉锚点）：凡被平移后的小掩码覆盖的大掩码前景格
  改为背景，其余保持不变。
- 小掩码本身不画入输出，分隔列与锚点也不出现在输出中。

关键洞察
- 对齐基准不是面板边框而是锚点，逐格叠加的惯性直觉会失效；
  大小关系指派"纸与剪"的角色，操作是有方向的集合减法而非并集。
```

## 8. 杆高配面积

```text
把对象按面积排名，与旗杆按高度排名逐位对齐，每个对象整体重涂成对应名次旗杆顶端的旗色，面积垫底的对象无杆可配、被抹除。

输入结构
- 网格底边立着 m 根互不等高的旗杆：杆身为一格宽的灰色竖条，
  顶端一格是旗色，各旗色互不相同。
- 网格其余位置散布 m+1 个单色对象，形状、颜色各异且面积互不相同。
- 旗杆的左右排列顺序、与各对象的远近位置均无规律。

规则
- 把 m+1 个对象按面积从大到小排名，把 m 根旗杆按高度从高到低排名。
- 面积第 i 名的对象整体重涂为高度第 i 名旗杆的旗色（i = 1…m），
  位置与形状不变。
- 面积最小的对象整体擦成背景；旗杆原样保留。

关键洞察
- 配对的键是两个各自隐藏的名次序列——面积名次对齐杆高名次；
  旗杆的左右位置、与对象的距离、对象原颜色全是无效线索，
  且对象比旗杆多一个，末位注定出局。
```
