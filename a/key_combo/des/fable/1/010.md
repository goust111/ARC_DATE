## 1. 相位窗口补画

- tags:
  - operation:补全, completion
  - operation:平铺, tiling
  - object:周期瓦片, periodic_tile
  - object:矩形窗框, rectangular_frame
  - relation:绝对坐标相位对齐, absolute_phase_alignment
  - condition:空窗按全局相位填充, empty_window_filled_by_global_phase

### docstring

```text
透过多个窗框窥见同一张从未完整画出的周期壁纸，按全局相位把空窗框的内部补画出来。

输入结构
- 黑色背景上散布若干灰色矩形窗框，窗框之间互不接触；窗框外一律是黑色背景。
- 除一个窗框外，其余窗框内部各显示一小片多色图案；这些碎片各不相同，乍看像互不相干的独立小图。
- 恰有一个窗框内部全黑（空窗）。所有可见碎片合起来足以唯一确定壁纸的最小行列周期及空窗所需每个格位的颜色。

规则
- 所有非空窗框内的可见像素都是同一张全局周期壁纸的采样，壁纸的周期与相位锚定在整幅网格的绝对坐标上。
- 求出能同时解释全部可见样本的最小行列周期与各剩余类颜色。
- 按该全局规律逐格填充空窗框的内部；窗框边、其余窗框内容与背景保持不变。

关键洞察
- 各窗框里的不是独立图案，而是同一张壁纸在不同相位处的裁片；空窗内容无法从任何窗框原样照抄，只能把所有碎片放回绝对坐标对齐后按周期推出。
```

## 2. 缺口滑车与游标间隙

- tags:
  - operation:平移, translate
  - object:空心矩形, rectangular_frame
  - object:边框缺口, border_gap
  - object:游标像素, gauge_pixel
  - relation:碰撞停止, collision_stop
  - condition:框内距离预演停靠间隙, interior_distance_prefigures_gap

### docstring

```text
让每个带缺口的空心框沿缺口朝向滑行，按框内游标预演的间隙在障碍前停靠。

输入结构
- 黑色背景上有若干彩色空心矩形框，每个框的边上恰有一个非角落的缺口。
- 部分框的内部有一个灰色游标像素，有的框内没有。
- 网格中另有若干青色实心条作为固定障碍；各框的滑行路径互不交叉。

规则
- 每个框沿缺口所在边的外法线方向整体滑行。
- 先求它一直滑到与最近的障碍条或网格边缘恰好贴上的位置；再看框内游标沿滑行轴到缺口所在边内壁的距离 d，框最终停在与该障碍之间恰好留出 d 格空隙的位置。
- 框内没有游标的框恰好贴住障碍停下。框保持形状、颜色、缺口位置与游标的框内相对位置不变；障碍条与背景不变。

关键洞察
- 缺口是喷口，指明滑行方向；框内游标不是货物也不是计数器，它到前壁的距离是一段被提前画进框里的量尺——框停下后与障碍之间的空隙恰好等于这段距离。
```

## 3. 变色台球

- tags:
  - operation:射线延伸, ray_extend
  - operation:反射, reflect
  - operation:重涂色, recolor
  - object:彩边框, colored_border
  - object:发射点, emitter
  - object:尾焰像素, exhaust_pixel
  - relation:反弹取壁色, bounce_takes_wall_color
  - condition:黑壁吸收, black_wall_absorbs

### docstring

```text
让斜向台球从发射点出发在四周墙壁间反弹，每撞一次彩墙球路就换成那格墙的颜色，撞上黑墙即被吸收。

输入结构
- 网格最外一圈是墙：墙上分段涂着几种颜色，也留有若干黑色墙段。
- 内部为黑色背景，只有一个彩色发射点像素，其斜后方对角紧贴一个灰色尾焰像素。
- 出发方向是从尾焰像素指向发射点的对角线方向；整条轨迹不会正撞在四角上。

规则
- 球沿对角线前进，把经过的内部背景格涂色，第一段使用发射点自身的颜色。
- 撞到彩色墙格时按该面墙做镜面反弹，反弹后的一段改用被撞墙格的颜色继续涂。
- 撞到黑色墙格时球被吸收，轨迹到此结束；轨迹交叉处后画的一段覆盖先画的；墙、发射点与尾焰像素保持原样。

关键洞察
- 边框是双重机关：彩色墙格既让球转向又预告下一段的画笔颜色，黑色墙格是唯一的终点；整条彩色折线的配色与长度早被墙上的分段悄悄写定。
```

## 4. 自印章重铸

- tags:
  - operation:印章覆盖, stamp
  - operation:修复, repair
  - operation:去噪, denoise
  - object:色块网格, block_grid
  - object:残缺副本, partial_copy
  - relation:自相似嵌套, self_similar_nesting
  - condition:占位掩模即母版, occupancy_mask_is_motif

### docstring

```text
把一幅残破的自印章图重铸完整：块的占位图本身就是母版，用它重画每个被占的块。

输入结构
- 网格边长是某个数 n 的平方，可按 n×n 个大块划分，前景只有一种颜色。
- 一部分大块里画着同一个 n×n 母版图案的残缺副本，每个副本至少保留两个像素，但没有任何一个副本是完整的，甚至存在所有副本都共同缺失的格位。
- 其余大块基本为空，个别空块里散落一个孤立的噪声像素。

规则
- 含两个及以上前景像素的大块记为被占，只含一个像素的块视为噪声块。
- 把被占大块的位置排布读成一个 n×n 掩模：这个掩模就是母版本身。
- 输出中向每个被占大块印入完整母版，清除所有噪声像素与残缺，其余块全黑。

关键洞察
- 母版从未被完整画出，跨块多数表决也救不回所有副本都缺的那一格；唯一的完整蓝本藏在更高一层——哪些块被占的分布图恰好就是母版。
```

## 5. 倒影招魂

- tags:
  - operation:平移, translate
  - operation:旋转, rotate
  - operation:补全, completion
  - object:偏移阴影, offset_shadow
  - object:残迹像素, relic_pixel
  - relation:本体倒影配对, object_reflection_pairing
  - condition:先旋转后平移的反演, rotate_then_translate_inversion

### docstring

```text
从一枚残迹像素和一片完好的红色倒影出发，识破影子是本体旋转180度的拷贝，再按公共位移把被擦除的本体请回来。

输入结构
- 黑色背景上有若干各自单色的物体，每个物体都带一片红色影子：影子的形状是本体旋转180度后的样子，并按全网格统一的位移向量错开放置，影子与本体互不重叠。
- 部分物体自身恰好中心对称，单看它们会误以为影子只是平移拷贝；至少有一个完好物体不对称，能拆穿这一点。
- 其中一个物体几乎被擦光，只剩一个本色像素留在原位，它的红影子却完好无损。位移向量在不同示例对中各不相同。

规则
- 用不对称的完好配对确认影子的生成方式：本体旋转180度、再按统一位移平移，得到该位移向量。
- 找到没有本体相伴的那片红影子，把它旋转180度并按位移向量反向平移，得到被擦除本体的位置与形状。
- 用残迹像素的颜色涂满该本体，残迹像素应恰好落在其中；所有影子与其余一切保持不变。

关键洞察
- 影子不是待补的效果而是证据，且它撒了一半的谎——对称的物体掩盖了旋转；只有用不对称物体校准出"先旋转后平移"的真规则，孤影才能被正确反演，颜色则由残迹补上。
```

## 6. 门深灌彩

- tags:
  - operation:洪泛填充, flood_fill
  - object:色板行, palette_row
  - object:分隔行, separator_row
  - object:房间, room
  - object:门洞, doorway
  - relation:房间图最短门数, room_graph_door_distance
  - condition:色板长度限深, palette_length_caps_depth

### docstring

```text
从源点房间开始向邻室灌彩，穿过的门每多一扇颜色就换成色板的下一格，色板用完的房间保持黑暗。

输入结构
- 顶行从左端起排着一段色板，其后为黑；色板正下方是一整行灰色分隔线。
- 分隔线以下是主区：蓝色墙线把黑色背景完全隔成若干房间，墙上开着一些一格宽的门洞。
- 某个房间里有一个种子像素，其颜色等于色板的第一格。

规则
- 种子所在房间整间涂成色板第一格的颜色。
- 其余每个房间取它到种子房间需要穿过的最少门数 d，涂成色板第 d+1 格的颜色。
- 最少门数达到或超过色板长度的房间不涂色；门洞格本身保持黑色；墙、色板与分隔线保持不变。

关键洞察
- 扩散的度量不是格距而是门数：房间大小与远近都是干扰，只有房间图上的最短门数才索引色板；色板的长度同时是灌彩能到达的深度上限。
```

## 7. 孔洞钥匙

- tags:
  - operation:裁剪, crop
  - operation:填充, fill
  - object:精灵体, sprite
  - object:单像素标记, singleton_marker
  - object:封闭孔洞, enclosed_hole
  - relation:孔洞图样平移配对, hole_pattern_translation_match
  - condition:孔洞染标记色, holes_take_marker_color

### docstring

```text
散落的标记点其实是某只精灵孔洞图样的平移拷贝，认出它，裁下那只精灵并用标记色点亮孔洞。

输入结构
- 黑色背景上有若干只不同颜色的精灵体，每只内部封着若干背景孔洞，孔洞可以不止一格。
- 另有一种颜色只以孤立单像素出现，成群散落在空地上；这群点整体构成一个图样。
- 存在孔洞总数相同的精灵作干扰，仅靠数数无法唯一定位。

规则
- 取出全部孤立标记像素的位置集合。
- 找出唯一一只精灵，其全部孔洞格的位置集合经过某个平移后与标记集合完全重合。
- 输出该精灵的紧致裁剪，并把它的所有孔洞格涂成标记色，其余保持精灵原色。

关键洞察
- 标记群不是计数器而是钥匙的齿形：它是答案精灵孔洞图样的平移投影；数量相同的假钥匙插不进，只有形状吻合才能点名，随后标记色回灌孔中。
```
