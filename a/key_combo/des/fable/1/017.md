## 1. 跨尺度自证纠错

- 标签:
  - 操作:自相似嵌套
  - 操作:纠错修复
  - 对象:二值掩码
  - 对象:块阵列
  - 关系:粗排布等于细图案
  - 条件:恰一块状态翻转

### docstring

```text
整幅图应是同一个二值图案与自身的嵌套（粗尺度的块排布 = 每个非空块内部的细尺度图案），恰有一个块的状态与这条同一性矛盾，找到并修复它。

输入结构
- 网格为边长 s² 的正方形（s 为 3 或 4），仅含背景色与一种前景色，画面上没有任何显式的标记或遮挡提示。
- 网格可按 s×s 均分为 s² 个块：每个非空块内部都绘着同一个 s×s 二值图案，各非空块内容彼此完全一致。
- 若图完全自洽，"哪些块非空"的粗尺度排布应与这个细尺度图案完全相同；但输入中恰有一个块被整体翻转——本应非空的块被抹成全背景，或本应全空的块被画上了该图案——除此之外处处自洽。

规则
- 从各非空块内部读出公共的 s×s 图案作为真值。
- 把它与粗尺度的块排布逐位比对，找出唯一不一致的位置。
- 该块本应非空则按图案补画，本应为空则整块抹为背景；输出修复后的完整网格。

关键洞察
- 画面上没有任何东西标出错误在哪——所有非空块内部彼此完全一致，逐块比较找不出异常；唯一的裁判是"粗排布 = 细图案"的跨尺度同一性，错误只在两个尺度的比对中现形。
```

## 2. 碰撞接力滑行

- 标签:
  - 操作:滑动
  - 操作:补全
  - 对象:填充矩形
  - 对象:控制像素
  - 对象:起始标记
  - 关系:角位指示方向
  - 条件:碰撞接力
  - 条件:边界终止

### docstring

```text
由孤立起点标记选中的矩形先动，沿自己缺角指示的对角方向滑行，撞上谁谁接着动，直至最后一个矩形滑抵边界。

输入结构
- 背景上散布若干实心单色矩形，每个矩形恰有一个角格被替换成同一种控制色。
- 场上另有一个孤立的控制色像素，与恰一个矩形的边相邻，标记接力的第一棒。
- 布局保证：接力链恰好经过每个矩形一次，每次滑行的碰撞对象唯一，最后一棒滑行至网格边界停止。

规则
- 当前矩形沿指向自己控制色角的对角方向逐格滑行，直到再走一步就会与另一矩形重叠或越出边界时停下。
- 若因矩形受阻而停下，被撞的矩形立即成为新的当前矩形，按它自己的缺角方向继续接力；若因边界停下，过程结束。
- 输出中每个矩形画在其停止位置，缺角补回矩形本色；孤立起点像素删去。

关键洞察
- 缺角同时给出"补哪个格"和"往哪滑"；而最终布局取决于激活顺序——每个矩形停在下一棒的原始位置旁，随后下一棒又滑走，静态地逐个搬移得不到正确答案。
```

## 3. 变色镜面走线

- 标签:
  - 操作:路径模拟
  - 操作:转向
  - 操作:重涂色
  - 对象:镜条
  - 对象:发射像素
  - 关系:颜色编码手性
  - 条件:撞击翻转镜色
  - 条件:出界终止

### docstring

```text
光线从边界上的发射点垂直射入，遇到镜条按镜条颜色决定左转或右转，且镜条每被使用一次就整条翻转成另一种颜色。

输入结构
- 黑色背景上散布若干一格宽的水平或垂直短条，颜色为青色或橙色两种。
- 网格边界上有一个绿色发射像素，光线从它出发垂直于所在边界向内传播。
- 布局保证光线路径唯一确定，最终从网格边缘射出。

规则
- 光线逐格前进，把经过的背景格涂成绿色；当前方下一格是镜条格时不进入该格，而是原地转向：青色镜条左转 90°，橙色镜条右转 90°。
- 每次转向后，被撞的那个镜条整条翻转颜色（青变橙、橙变青），因此同一镜条再次被撞时转向方向相反。
- 光线沿新方向继续，直到走出网格边缘为止；输出为绿色轨迹与最终状态的镜条颜色叠加在原图上。

关键洞察
- 转向不是固定的反射定律，而是由镜条当前颜色决定的手性；镜条颜色又被撞击历史改写——必须按时间顺序模拟，输出里镜条的最终颜色本身就是被撞次数的痕迹。
```

## 4. 指针环搬运

- 标签:
  - 操作:平移
  - 操作:补全
  - 对象:瓦片
  - 对象:分隔线
  - 对象:标记像素
  - 关系:局部坐标编码宏格地址
  - 关系:指针成环
  - 条件:同时置换

### docstring

```text
每个精灵内部的黄色像素以局部坐标写出一个宏格地址，所有精灵同时沿这些指针搬到目标槽位，并把黄格补回本色。

输入结构
- 画布被贯穿的灰色分隔行与分隔列切成 3×3 的宏格阵列，每个宏格是 3×3 的小方块区域。
- 部分宏格内有单色精灵，其中恰有一格被黄色覆盖；其余宏格全为背景。
- 把黄色像素在本宏格内的行列位置读作（宏行，宏列），这些指针在有精灵的宏格之间构成一个环：每个精灵指向的槽位互不相同，且恰好都是有精灵的槽位。

规则
- 对每个精灵，读出其黄色像素的局部坐标，作为它要搬去的宏格地址。
- 所有精灵同时搬运：整块图案平移到目标宏格的对应位置，黄色格恢复为该精灵的本色。
- 空宏格保持背景，灰色分隔线原样保留。

关键洞察
- 黄色像素不是要保留的图案内容，而是一条写在图案坐标系里的地址：局部行列即宏观行列；由于指针构成环，逐个"复制过去"会互相覆盖，必须理解为同时置换。
```

## 5. 覆压图例重力分选

- 标签:
  - 操作:堆叠
  - 操作:擦除
  - 对象:双列图例
  - 对象:地面行
  - 对象:悬浮像素
  - 关系:图例行即覆压关系
  - 关系:局部关系链成全序
  - 条件:图例外颜色删除

### docstring

```text
把右侧悬浮像素在各自列中落到地面上，堆叠次序不是原有高低，而是由左侧两列图例链出的全序决定。

输入结构
- 网格底部为一整行地面色；左侧有一个两列图例块，每行给出一对颜色，各行链接后恰构成一条无分叉的链；图例与场景之间由背景隔开。
- 场景区散布若干彩色像素，同一列可含多色、可重复；有的颜色不在图例中出现。

规则
- 图例的每一行读作一条覆压关系：左色必须位于右色上方；把各行链起来，得到所有图例颜色从下到上的唯一全序。
- 场景区每一列独立处理：该列中属于图例颜色的像素全部落到地面正上方，按全序自下而上排列，同色相邻堆放，数量保持不变。
- 不在图例中的颜色的像素直接删除；地面与图例保持原样。

关键洞察
- 两列图例长得像换色码表，实际是一组"谁压在谁上面"的局部关系，要先把它们链成全序才能用；落下的堆不保持原来的竖直顺序，这一点会被恰好已按序排列的列所伪装。
```

## 6. 双轴换色对称揭底

- 标签:
  - 操作:对称补全
  - 操作:裁剪
  - 对象:实心遮挡矩形
  - 对象:镜像格对
  - 关系:形状双轴对称
  - 关系:颜色隐藏置换表
  - 条件:逐格选择还原路线
  - 条件:表从画面自身重建

### docstring

```text
画面在形状上双轴镜像对称，但左右镜像与上下镜像各自服从一张从未画出的颜色替换表，需从可见格对里重建两张表并按格选择路线，还原遮挡矩形下的颜色。

输入结构
- 除一个实心矩形遮挡块外，网格在形状上关于竖直轴与水平轴同时镜像对称：任一格与其左右镜像格、上下镜像格、180° 对角格同为背景或同为前景。
- 颜色上，左右镜像格对服从一张固定的一一对应表，上下镜像格对服从另一张不同的一一对应表，对角格对自动服从两表的复合；两张表都不以图例形式出现在画面上。
- 遮挡矩形完全落在一个象限内，颜色在别处不出现。
- 保证每个被遮格的三个镜像格都可见，且所需表值都能从可见格对读出，但并非每个被遮格都能只靠同一张表完成还原。
- 输出尺寸与遮挡矩形相同。

规则
- 从可见的左右镜像格对统计出水平表，从可见的上下镜像格对统计出竖直表。
- 对遮挡矩形内每格，取其任一可见镜像格：左右镜像经水平表换算，上下镜像经竖直表换算，对角格依次经两表复合换算，得到被遮颜色写入输出对应位置。
- 背景格经镜像仍为背景，直接写背景色。

关键洞察
- 陷阱有两层——直接抄镜像忽略了颜色被置换；只建一张表也不够，两条轴各有自己的表，有的格子所需的表项只能从另一条轴的格对中学到，必须逐格挑选可行路线，而三条路线殊途同归是画面自洽的检验。
```
