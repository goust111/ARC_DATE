## 1. 划分归属重组

- tags:
  - operation:形状对齐, shape_alignment
  - operation:重涂色, recolor
  - object:原型, prototype
  - object:残缺副本, defective_copy
  - relation:精确划分, exact_partition
  - condition:缺失归属决定颜色, missing_ownership_colors
- 参考题目题号：d94c3b52（原型与匹配）、626c0bcc（精确覆盖）、c3e719e8（整体印章）

### docstring

```text
将各彩色残缺副本的缺失像素按其归属拼回原型形状，输出一张“缺失归属图”。

输入结构
- 黑色背景网格上有一个完整的青色原型精灵体，以及若干个与原型形状相同（仅平移）的单色副本。
- 副本颜色互不相同且不为青色；每个副本都缺失了原型形状中的若干像素。
- 所有副本的缺失位置合在一起，恰好不重不漏地划分了原型形状的全部像素。

规则
- 找到唯一完整的青色原型，以其包围盒建立局部坐标。
- 将每个副本与原型按平移对齐，记录该副本缺失的局部位置集合。
- 输出为原型包围盒大小的网格：原型的每个形状像素涂成“在该位置缺失的那个副本”的颜色，非形状位置保持黑色。

关键洞察
- 副本不是要被补全的对象；它们的残缺才是信息本体——所有缺口恰好构成对原型形状的一次精确划分，输出把每块缺口按归属副本染色后重新拼合成完整原型。
```

## 2. 传动链旋转

- tags:
  - operation:传播, propagation
  - operation:旋转, rotation
  - object:空心方框, hollow_square
  - object:种子像素, seed_pixel
  - relation:贴边成链, edge_adjacent_chain
  - condition:传递方向决定旋向, step_direction_sets_rotation
- 参考题目题号：b7fb29bc（框与控制像素）、b942fd60（深度优先展开与方向转折）、913fb3ed（中心与外框关系）

### docstring

```text
种子像素沿贴边相连的空心方框链传播，水平传递时顺时针转90度，竖直传递时逆时针转90度。

输入结构
- 黑色背景上有若干个同尺寸的灰色空心正方形框（如5x5，内腔3x3），框与框以整边贴合相连，构成一条链或带分叉的树。
- 恰有一个框的内腔含有一个彩色种子像素，其余框内腔为空。

规则
- 从含种子的框出发，沿贴合关系向所有相邻空框逐个传播。
- 每向水平方向相邻的框传递一次，种子在框内腔局部坐标中绕内腔中心顺时针旋转90度后画出。
- 每向竖直方向相邻的框传递一次，则逆时针旋转90度后画出。
- 分叉处各分支独立继续累计旋转；框与种子的颜色保持不变。
- 输出为每个框内腔都有一个按累计旋转规则放置的种子像素。

关键洞察
- 框链是传动装置：像素在内腔中的位置是被传递的状态，而每一步的传递方向（水平或竖直）本身就是旋转方向的开关，旋转沿路径逐步累计而非按距离一次算出。
```

## 3. 计数寻址切割与坠落

- tags:
  - operation:计数, counting
  - operation:切割, cut
  - operation:滑动下落, gravity_slide
  - object:路径蛇, path_snake
  - object:计数条, counter_bar
  - relation:长度寻址, length_addressing
  - condition:切断触发坠落, cut_triggers_fall
- 参考题目题号：d0f5fe59（计数）、29c11459（滑动留迹）、03560426（整体平移与堆叠）、bf89d739（端点与线段）

### docstring

```text
按计数条长度从红端沿灰蛇数格切断，被切下的尾段整体坠落。

输入结构
- 黑色背景上有一条一像素宽、无自交的灰色4连通路径（蛇），其一端替换为红色端点像素。
- 网格某角落有一段与蛇分离的蓝色直线段，作为计数条。

规则
- 设蓝色计数条长度为 n；从红色端点起沿蛇前进，第 n 个蛇格为切点。
- 将切点格变为背景，蛇被分为含红端的头段与其余的尾段。
- 尾段作为刚体整体竖直下落，直到其任一像素到达底边、或落在其他前景像素正上方为止；头段与红端保持原位。

关键洞察
- 蓝条不是装饰而是地址：它的长度指向蛇上的切割位置；切割又触发第二阶段的刚体重力，两层规则由切点串联成因果链。
```

## 4. 双周期图案延拓求交

- tags:
  - operation:图案补全, pattern_completion
  - operation:平铺, tiling
  - object:周期图案, periodic_pattern
  - object:分隔线, separator
  - relation:平移对称, translational_symmetry
  - relation:前景交集, foreground_intersection
  - condition:全局相位对齐, global_phase_alignment
- 参考题目题号：caa06a1f（平移对称延拓与相位）、b4a43f3b（分隔行与区域对应）、d13f3404（透明叠加一致性）

### docstring

```text
把上下两个残缺的周期图案各自延拓到底部空区，仅两者前景重合处涂黄。

输入结构
- 网格被两条水平灰色分隔线分成三个区域。
- 上区含图案A的一个片段：红色前景像素构成具有平移周期的图案，只画出了一部分。
- 中区含图案B的一个片段：蓝色前景像素，同样是只画出一部分的周期图案。
- 下区全为黑色背景。

规则
- 分别推断A、B两个图案的平移周期；相位以整幅网格的全局坐标为准，分隔线不重置相位。
- 将两个图案各自按周期延拓覆盖到下区。
- 在下区中，同时被A的前景与B的前景覆盖的格子涂黄，其余保持黑色；上区、中区与分隔线原样保留。

关键洞察
- 下区既不是A的延拓也不是B的延拓，而是两张从未被完整画出的周期图案的交集；必须先在同一坐标系中把两个残片各自补全，答案才会显现。
```

## 5. 取景器画中画

- tags:
  - operation:下采样, downsample
  - operation:印章覆盖, stamp
  - object:取景框, viewfinder_frame
  - object:彩色物体, colored_object
  - relation:内腔定分辨率, cavity_sets_resolution
  - relation:自指缩略, self_referential_miniature
  - condition:含物块涂色, occupied_block_colored
- 参考题目题号：b4a43f3b（粗格与像素块对应）、5833af48（尺寸相除定分辨率）、b7fb29bc（矩形框与内部填充）

### docstring

```text
把整幅场景等比例压缩成一张小地图，画进灰色取景框的内腔，取景框自己也出现在这张小地图上。

输入结构
- 黑色背景网格上有一个灰色空心矩形框，内腔全为背景。
- 另散布若干个互不接触的彩色实心物体，形状各异。
- 网格的高、宽分别是框内腔高、宽的整数倍。

规则
- 设框内腔为 h x w；把整幅网格均匀划分为 h x w 个等大的块（每块大小为 网格高/h x 网格宽/w）。
- 块内含彩色物体像素，则该块对应的内腔格涂那种颜色（设计保证每块内至多出现一种物体颜色）。
- 块内含灰色框像素，则该内腔格涂灰；否则保持黑色。
- 把这张 h x w 小地图写入框的内腔，框外的一切原样保留。

关键洞察
- 空心矩形是一台取景器——它的内腔分辨率决定整幅画面的压缩比，答案不在别处，而是把包括取景器自身在内的全场景缩略图回填到内腔中；内腔里出现的灰色格正是取景器在自己屏幕上的倒影。
```

## 6. 一次性镜面光路

- tags:
  - operation:射线延伸, ray_extend
  - operation:方向偏转, deflection
  - object:入射口, entry_pixel
  - object:斜镜, diagonal_mirror
  - relation:命中反射, hit_reflect
  - condition:一次性失效, one_time_consumption
- 参考题目题号：b942fd60（一次性标记控制转向）、ac3e2b04（引导与垂直发射）、29c11459（滑动留迹）

### docstring

```text
光线从边缘红点射入，被斜镜反射，但每面镜子只能反射一次，再次命中时直接穿过。

输入结构
- 黑色背景网格的边缘有一个红色像素作为入射口，光线由此垂直于边界射入。
- 内部散布绿色与粉色的单像素镜子：绿镜按“/”方向反射，粉镜按“\”方向反射。

规则
- 光线沿直线传播，途经的背景格涂黄。
- 首次命中某面镜子时按其朝向偏转90度继续传播，该镜随即失效。
- 光线再次经过已失效的镜子时不偏转、直接穿过（镜子格保持原色，不涂黄）。
- 光线离开网格边界时结束；红色入射口保持不变。

关键洞察
- 镜子是一次性开关：光路可以绕回并第二次抵达同一面镜子，而此时它已经透明——把镜子当作永久反射器会得到死循环或错误路径。
```

## 7. 同色最近邻奇偶描边

- tags:
  - operation:描边, outline
  - operation:距离度量, distance_measure
  - object:孤立像素, isolated_pixel
  - object:空心框, hollow_square
  - relation:同色最近邻, same_color_nearest
  - condition:奇偶决定框色, parity_sets_outline_color
- 参考题目题号：913fb3ed（3x3空心框描边）、b7fb29bc（切比雪夫距离奇偶染色）、aedd82e4（孤立像素分类）

### docstring

```text
给每个孤立像素套3x3空心框，框色由它到最近同色像素的棋盘距离奇偶决定。

输入结构
- 黑色背景上散布若干孤立单像素，颜色可有多种，每种颜色至少出现两次。
- 各像素周围一圈为空，3x3框互不冲突且不出界。

规则
- 对每个像素，在与它同色的像素中找切比雪夫距离最近的一个（设计保证最近距离唯一确定）。
- 该距离为奇数则围绕它画橙色3x3空心框，为偶数则画蓝色3x3空心框。
- 中心像素保持原色不变。

关键洞察
- 框的颜色既不由中心颜色映射、也不由绝对位置决定，而是由同色伙伴之间的距离奇偶决定；颜色只用来划分“谁和谁算一对”，真正的开关是隐藏的距离场。
```
