## 1. 清障通行

- 标签:
  - 操作:压缩, 滑动, 路径搜索
  - 对象:锚块, 射线像素, 蜿蜒河道, 实心方块
  - 关系:清障改变可达性
  - 条件:尺寸约束通行, 堆积成新障

### docstring

```text
一句话总述
先把散落的射线像素压回同色 3×3 锚块腾出河道，再判断实心方块能否滑到目标——可达性由清障后的河道真实宽度决定。

输入结构
- 背景为最常见色，一条单色蜿蜒河道横穿网格。
- 河道上有两个同尺寸 N×N 实心方块：移动方块与目标方块，颜色互异。
- 第三种颜色有一个位于河道之外的实心 3×3 锚块；其余该色像素散落在指向锚块的行、
  列或对角直线视线上，其中一部分正好压在河道内部，像是挡路的礁石。

规则
- 第一步：每条射线上的散点向锚块方向紧缩，依次排进紧贴锚块的连续格位；被腾空的
  格子恢复所在区域的底色（河道内恢复河色，河道外恢复背景色）。
- 第二步：移动方块沿河道滑向目标，只能停留在整个 N×N 范围均为河色的位置；若能
  到达则取代目标方块，否则停在可达的最远处；方块出发位置用河色填平。
- 锚块与紧缩后堆积的像素固定不动，仍是实体障碍；堆积像素可能恰好落进河道，
  成为新的堵塞。

关键洞察
看似挡路的散点会自行归位，河道的真实宽度要在清障之后才能读出；而清障本身可能在
锚块旁堆出新的障碍——一处疏通，另一处淤塞，通行与否由两步规则的净效果决定。
```

## 2. 自指地图砖

- 标签:
  - 操作:压缩, 重涂色
  - 对象:瓷砖, 九宫格, 自指地图
  - 关系:跨尺度自相似
  - 条件:地图像素色定砖色, 对自身执行指令

### docstring

```text
一句话总述
九宫棋盘中藏着一块与"整盘压缩占位图"完全一致的自指地图砖，用它每个像素的颜色给
对应位置的瓷砖整体重染，地图砖也要对自身执行自己的指令。

输入结构
- 分隔条把画布分成 3×3 九个等大的 3×3 瓷砖格，部分格内有多色小图案，其余格全空。
- 把整个棋盘压缩成 3×3 占位图（非空格记占位）：恰有一个非空格内图案的占位形状与
  这张占位图完全一致，该格即地图砖。
- 地图砖内每个占位像素有各自的颜色，且它与其他图案砖一样是多色的，外观上没有任何
  特殊标识。

规则
- 逐格把每个非空瓷砖的占位形状与棋盘整体的非空分布比对，找出唯一吻合的地图砖。
- 对每个非空格 (r,c)：把该格内图案的全部非背景像素重染为地图砖 (r,c) 处像素的
  颜色，形状保持不变。
- 地图砖同样按它自己所在位置对应的颜色重染自身；空格保持全空，分隔条不变。

关键洞察
棋盘里有一块砖是整个棋盘的缩略图——必须先在宏观尺度上压缩整盘、再逐砖与微观图案
比对，跨尺度的自相似才是入口；地图砖既是指令表又是被指令的对象，对自身也要执行
一次自己的规定。
```

## 3. 负片转印

- 标签:
  - 操作:挖孔, 印章覆盖, 补全, 擦除
  - 对象:单色块, 孔洞图案, 标记像素
  - 关系:同色匹配, 负片转正片
  - 条件:无匹配则删除

### docstring

```text
一句话总述
把每个实心块内被雕空的图案取出，以正片形式、用块色盖印到同色孤立标记处，同时把块
补回实心。

输入结构
- 背景上有若干颜色互异的实心矩形块，多数块内部雕有一片背景色孔洞，孔洞构成一个
  小图案，其包围盒为奇数边长、中心格明确。
- 背景处散落孤立单像素标记，多数与某个块同色；个别标记颜色没有对应的块；个别块
  是无孔的完整实心块。

规则
- 对每个带孔块：记录孔洞图案，把块内孔洞全部补回块色，使块恢复实心。
- 找到同色标记，先清除标记像素，再以标记原位为图案中心格，用块色画出孔洞图案。
- 颜色没有对应块的标记直接擦除；无孔实心块对应的标记同样只被擦除（无图案可印）。

关键洞察
图案信息藏在"被挖掉的形状"里，孔洞是模板而非缺损；变换方向是从负片（块内空洞）到
正片（标记处实画），与"把图案刻进块"的第一直觉相反。
```

## 4. 波前触序

- 标签:
  - 操作:洪泛填充, 重涂色
  - 对象:墙体, 源点, 前景团块, 图例行
  - 关系:测地距离排序
  - 条件:触及次序对应图例序色

### docstring

```text
一句话总述
波从源点出发沿背景绕墙扩散，按首次触及各团块的先后顺序，用图例行给出的颜色序列
依次给团块整体重染。

输入结构
- 网格内含灰色墙体、一个青色源点像素、若干个橙色团块。
- 最底一行为图例行：左起排列 k 个颜色像素，k 等于团块个数；图例行与主画面之间
  隔着整行背景。
- 各团块到源点的最短绕行距离互不相同。

规则
- 波从源点沿背景做四连通扩散，墙体与团块均不可穿越。
- 按波首次接触的先后（即绕行最短距离由小到大），第 i 个被触及的团块整体染成图例
  行左起第 i 个颜色。
- 墙体、源点与图例行原样保留。

关键洞察
排序量是绕过墙体的路径距离而不是直线距离——直线上离源点最近的团块可能隔着一堵墙
反而排在最后；不比出真实的绕行远近，就会得到错误的颜色分配。
```

## 5. 镜面光路

- 标签:
  - 操作:射线延伸, 擦除
  - 对象:边框发射器, 斜镜, 虚拟光路
  - 关系:反射转折, 同色光路交汇
  - 条件:孤色发射器无效

### docstring

```text
一句话总述
边框发射器向内射出看不见的光线，光线遇灰色斜镜转折九十度，同色两条光路的唯一交点
处留下一粒该色像素，其余全部清空。

输入结构
- 边框上贴着若干发射器：2 像素同色短条，垂直于所在边向网格内部发射一条光线。
- 网格内部散布斜镜：每面镜子为 2 像素灰色对角短线，走向为"/"或"\"。
- 发射器颜色大多成对出现在不同位置；个别颜色只有一个发射器。同色两条光路恰好
  交于一格。

规则
- 光线从发射器向内直行；进入镜子所在格时按镜面走向转折 90°（"/"把向右的光折向上、
  向下的光折向左；"\"把向右的光折向下、向上的光折向左），随后继续直行，直到射出
  网格。
- 对每种成对颜色，求两条光路经过格子的公共格，在输出中把该格置为该颜色。
- 输出与输入同尺寸，其余一切（发射器、镜子、光线沿途）都不画，全部为背景。

关键洞察
答案所依赖的对象（光线）从未在画面上出现，必须沿光路心算追踪并正确处理每一次反射；
孤身颜色的发射器是诱饵，其光线不留任何痕迹。
```

## 6. 格网缺陷对

- 标签:
  - 操作:补全, 滑动, 擦除
  - 对象:格点骨架, 多余点, 缺口
  - 关系:行列视线配对, 链式排除
  - 条件:周期模板判缺陷, 同色多余点占位

### docstring

```text
一句话总述
周期格网同时存在多出的彩点与缺失的格点，每个彩点沿共线的行或列滑去填补一个缺口，
恢复完整格网并让缺口显出修补者的颜色。

输入结构
- 画布主体是周期重复的格网骨架图案。
- 若干位置违反周期模板：一类是模板应为背景处多出像素（多为彩色，个别恰与格网同色
  而极难察觉）；另一类是模板应为格网色处缺了像素而露出背景。
- 每个多余点与至少一个缺口同行或同列；全体配对存在唯一解。

规则
- 先由周期性反推完整模板，找出全部多余点与缺口。
- 每个多余点沿共处的行或列移动到对齐的缺口处，用自身颜色填入；每个缺口只接收
  一个点。
- 当某个多余点与两个缺口都对齐时，由其他点的唯一去向做排除，链式确定全部配对。
- 输出为完整格网：被修补的缺口呈现修补者颜色，多余点原位清为背景。

关键洞察
与格网同色的多余点只能靠周期模板揭穿，它同样要占用一个缺口，从而牵动整条排除链；
配对不是逐点独立的判断，而是一个相互制约的整体。
```

## 7. 接口装配

- 标签:
  - 操作:对接拼合, 旋转, 重涂色, 裁剪
  - 对象:碎片, 接口像素
  - 关系:同色接口贴合, 全局矩形校验
  - 条件:孤色接口弃用

### docstring

```text
一句话总述
若干带彩色接口像素的碎片按同色接口面对面贴合的方式旋转拼装成一个实心矩形，接口熔
为本体色，输出紧裁的成品；接口颜色无伴的碎片被弃用。

输入结构
- 背景上散布若干单色碎片，每个碎片边缘嵌有 1 至多个接口像素，接口颜色与本体不同。
- 每种接口颜色恰好出现在两个不同碎片上；个别碎片的接口颜色全场仅此一个（诱饵
  碎片）。
- 碎片可整体旋转（不镜像）；仅凭形状拼合存在多种拼法，同时满足"全部同色接口像素
  恰好相邻贴合"且"成品为无孔实心矩形"的拼法唯一。

规则
- 按接口颜色两两配对碎片，通过旋转与平移使同色接口像素面对面相邻，逐步装配。
- 以"成品必须是无孔实心矩形"为全局校验，确定每个碎片唯一的朝向与位置。
- 装配完成后把所有接口像素改为所在碎片的本体色，诱饵碎片整体舍弃。
- 输出为紧贴成品边界裁剪后的矩形。

关键洞察
局部贴合并不能唯一决定朝向——多个旋转都能让接口相邻；只有"最终必须成为实心矩形"
这一全局约束回头锁定每一步，装配是全局求解而非贪心拼接。
```
