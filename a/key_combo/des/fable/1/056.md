## 1. 光束转向连锁

- 参考题目题号：056-9 (85fa5666)、056-11 (79fb03f4)、056-1 (a680ac02)
- tags:
  - operation:射线延伸, ray_extend
  - operation:转向, turning
  - object:实心方块, solid_square
  - object:空心方框, hollow_frame
  - object:种子像素, seed_pixel
  - relation:连锁反应, chain_reaction
  - condition:填充性决定手性, fill_determines_chirality

### docstring

```text
从边缘种子发出的光束在场内 3x3 方块处转弯，实心块顺时针、空心框逆时针，连锁折行直到离开网格。

输入结构：
- 黑色背景；网格边缘上有一个彩色种子像素。
- 场内散布若干 3x3 对象：单色实心方块与单色空心方框；对象颜色各异但颜色无含义。
- 种子所在边垂直指向网格内部的方向上必有可推进的空间。

规则：
- 光束从种子出发，沿垂直于其所在边的方向进入网格，途经的黑色格逐格涂上种子颜色。
- 当光束前方下一格属于某个 3x3 对象时，光束停在该对象之前的一格，并在该格转向：
  实心方块使光束顺时针转 90°，空心方框使光束逆时针转 90°。
- 转向后继续直线传播与涂色，可连续经过多个对象多次转向，直到光束从网格边缘离开为止。
- 所有 3x3 对象自身保持不变；未被光束经过的格保持黑色；不在光束路径上的对象是天然干扰。

关键洞察：
- 方块不是障碍而是转向器；同一种碰撞事件的转向方向由对象的拓扑（实心还是空心）决定，
  整条路径是被逐段推演出来的折线，任何一次手性判断出错都会使后续路径整体偏离。
```

## 2. 残缺副本重建

- 参考题目题号：056-20 (1caeab9d)、056-13 (ae3edfdc)、056-6 (f25fbde4)
- tags:
  - operation:对齐, align
  - operation:并集重建, union_reconstruction
  - operation:裁剪, crop
  - object:残缺副本, incomplete_copy
  - object:锚点像素, anchor_pixel
  - relation:覆盖计数着色, coverage_count_coloring
  - condition:对象从未完整画出, never_fully_drawn

### docstring

```text
以灰色锚点对齐三个互补残缺的同形副本，重建完整形状并按覆盖数着色。

输入结构：
- 黑色背景上有三个彩色对象（如红、蓝、黄各一），它们都是同一个隐藏形状的残缺副本：
  每个副本缺失了形状的一部分像素，缺失部分互不相同，三者的并集恰好覆盖完整形状。
- 每个副本内部含有一个灰色像素，位于隐藏形状 mask 的同一相对位置，作为对齐锚点。
- 三个副本在网格中的位置与行列偏移互不相同。

规则：
- 以每个副本的灰色锚点为公共原点，把三个副本的像素折算到同一坐标系中叠合。
- 三副本像素的并集即完整形状；输出为该完整形状的紧致裁剪。
- 对齐后仅被一个副本覆盖的像素，涂该副本自身的颜色；
  被两个或三个副本同时覆盖的像素，涂灰色（锚点位置天然被三副本共有，故为灰色）。

关键洞察：
- 完整形状从未在画面中出现，画面上只有它的三份残迹；由于每份都残缺，无法靠形状
  匹配直接对齐，锚点是唯一可靠的坐标基准；输出的颜色同时揭示每个像素由谁"独家提供"。
```

## 3. 下落盖章绕行

- 参考题目题号：056-12 (db7260a4)、056-10 (c87289bb)、056-4 (985ae207)
- tags:
  - operation:重力下落, gravity_drop
  - operation:印章覆盖, stamp_repeat
  - operation:绕行, detour
  - object:精灵体, sprite
  - object:障碍线段, obstacle_segment
  - relation:近端绕行, detour_nearest_side
  - condition:末端破例缩短步长, terminal_step_shortening

### docstring

```text
顶部精灵按自身高度为步长向下反复盖章，遇水平障碍改从障碍近端外侧继续下落，直到贴住底边。

输入结构：
- 黑色背景；网格顶部贴边有一个小的多色精灵（如 2x2 或 2x3 图案）。
- 精灵下方分布若干条互不接触的水平单色障碍线段，长度与位置各异。

规则：
- 保留原精灵，以精灵自身高度为步长向正下方逐份盖章，每个副本紧贴上一个副本的下边。
- 若下一份副本的列范围与某条障碍线段相交且会与其重叠或越过它，则该方向的最后一份
  允许缩短步长，恰好贴住障碍的上边。
- 随后精灵水平平移到该障碍较近一端的外侧：与障碍左端距离更近则使精灵右缘位于障碍
  左端左侧一列，否则使精灵左缘位于障碍右端右侧一列；恰在中点时向右绕。
- 平移后的下一份副本顶行与该障碍所在行齐平，从那里继续向下逐份盖章。
- 上述过程可连锁绕过多条障碍；最终一份副本恰好贴住网格底边（同样允许缩短最后一步）。
- 所有障碍线段保持不变。

关键洞察：
- 障碍不拦截而是改道：下落所在的列由每条障碍的近端逐段重新选择，副本柱因此折成
  阶梯；均匀步长的盖章规律在贴靠障碍与贴靠底边两处系统性破例，需要同时看出周期性
  与破例条件。
```

## 4. 钥匙格镜像马赛克

- 参考题目题号：056-17 (c48954c1)、056-15 (247ef758)、056-2 (d4469b4b)
- tags:
  - operation:平铺, tiling
  - operation:镜像, mirror
  - operation:颜色互换, color_swap
  - object:瓦片, tile
  - object:钥匙格, key_grid
  - relation:槽位一一对应, slot_correspondence
  - condition:标记色决定色反转, marker_color_triggers_swap

### docstring

```text
按 3x3 钥匙格选出的槽位铺设源瓦片的镜像，其中一种标记色还要求交换瓦片的两种颜色。

输入结构：
- 输入含两个分离的 3x3 区块：一个双色源瓦片（恰好使用两种非黑颜色、无黑格），
  一个钥匙格（黑底上散布两种标记色的像素）。
- 两个区块的角色可由内容区分：钥匙格含黑色格而源瓦片不含。

规则：
- 输出为 9x9，划分为九个 3x3 槽位，与钥匙格的九个格一一对应。
- 钥匙格中为黑的槽位输出全黑。
- 被标记的槽位放入源瓦片的反射版本：中心槽位为原瓦片；上、下槽位行倒序；
  左、右槽位列倒序；四角槽位行列同时倒序。
- 若该槽位在钥匙格中的标记像素是第二种标记色，则在反射之后再交换瓦片的两种颜色。

关键洞察：
- 钥匙格同时携带两层互不相干的指令：像素的位置选择"铺哪里"，像素的颜色选择
  "要不要色反转"；而反射方式与标记完全无关，只由槽位相对中心的方位决定——
  三条线索必须拆开各归其位。
```

## 5. 嵌套深度与洋葱图例

- 参考题目题号：056-7 (00d62c1b)、056-14 (3ee1011a)、056-16 (278e5215)
- tags:
  - operation:洪泛填充, flood_fill
  - operation:擦除, erase
  - object:封闭区域, enclosed_region
  - object:同心方形层, concentric_square_layer
  - object:缺口边界, gapped_boundary
  - relation:嵌套深度查表, nesting_depth_lookup
  - condition:仅真闭合计层, closed_only_counts

### docstring

```text
按闭合边界的真实拓扑嵌套深度给区域填色，颜色查自图例洋葱的同心层序，带缺口的伪边界不构成一层。

输入结构：
- 黑色背景上有若干绿色边界曲线，彼此可嵌套多层，形成一棵或多棵嵌套树。
- 其中部分边界带有一两个像素的缺口，其"内部"实际与外部连通。
- 画面另一角有一个由多层同心单色矩形框套成的"图例洋葱"，每层一种颜色，
  与主体边界互不接触。

规则：
- 计算每个黑色区域被多少层真正闭合的边界包围，记为嵌套深度 d（最外部为 0）；
  带缺口的边界不闭合，不计入任何一层。
- 图例洋葱从最外层到最内层的颜色依次对应深度 1、2、3……：
  深度 d≥1 的区域填洋葱第 d 层的颜色。
- 所有绿色边界（含带缺口者）保持不变；深度 0 的区域保持黑色；
  图例洋葱整体从输出中擦除。

关键洞察：
- 三层判断缺一不可：先做拓扑核验分辨哪些边界真正闭合（缺口边界看似一层实则不算），
  再数真实嵌套深度，最后把图例的同心层序读成深度色表；区域的形状、图例的位置
  以及边界的视觉层数都是干扰。
```

## 6. 叠放次序反转

- 参考题目题号：056-1 (a680ac02)、056-14 (3ee1011a)、056-17 (c48954c1)
- tags:
  - operation:排序, sorting
  - operation:重绘, redraw
  - object:空心矩形, hollow_rectangle
  - relation:遮挡决定层序, occlusion_determines_order
  - relation:重叠, overlap
  - condition:全序整体反转, total_order_reversed

### docstring

```text
从空心矩形框之间的遮挡关系推断它们的叠放次序，然后按完全反转的次序重绘整个场景。

输入结构：
- 黑色背景上有三到四个不同颜色的空心矩形框，两两之间存在交叠。
- 画面遵循"上层覆盖下层"：每处交叠位置只显示较上层框的边像素，较下层框的边
  在该处被打断。
- 相邻层的框之间都有交叠，遮挡关系可完全确定唯一的叠放全序；
  且至少存在一处三个框共同交叠的区域。

规则：
- 根据每处交叠中谁的边被打断，恢复所有框的完整矩形轮廓与它们的叠放全序。
- 将叠放次序整体反转（原最底层变为最顶层，原最顶层变为最底层）。
- 按新次序自底向上重绘所有完整矩形框：每处交叠只显示新上层的边像素。
- 框的位置、尺寸、颜色都保持不变。

关键洞察：
- 输入中被打断的边不是形状本身的特征而是遮挡留下的残迹；必须先由局部遮挡证据
  重建每个完整矩形与全序，再做一次"时间反演"的重绘。逐处交叠简单互换可见性
  是行不通的捷径：三框共同交叠的区域只有依据反转后的全序才能画对。
```

## 7. 双侧梯度参数团

- 参考题目题号：056-3 (5207a7b5)、056-4 (985ae207)、056-2 (d4469b4b)
- tags:
  - operation:延伸填充, extension_fill
  - operation:擦除, erase
  - object:纵条, vertical_bar
  - object:参数像素团, parameter_cluster
  - relation:距离控制高度, distance_controls_height
  - relation:计数编码速率, count_encodes_rate
  - condition:不对称递变, asymmetric_gradient

### docstring

```text
灰色顶条向两侧生成逐列递变的填充，两侧的填充颜色与每步增减量分别由场上两个彩色像素团给出。

输入结构：
- 黑色背景；一根宽 1 的灰色竖条从顶边向下延伸，无缺口。
- 网格远处有两个互不相邻的彩色像素团（各为一种颜色，像素数很少且两团可不同），
  一个位于竖条左侧区域，一个位于右侧区域；两团都不与竖条同列或邻列。

规则：
- 保留灰色竖条，设其高度为 H。
- 设左团颜色为 cL、像素数为 nL：竖条左侧第 d 列自顶向下涂 cL，
  高度为 H + nL*d，超出网格底边则截断。
- 设右团颜色为 cR、像素数为 nR：竖条右侧第 d 列自顶向下涂 cR，
  高度为 H − nR*d，降至 0 或以下时该列及更远列不涂。
- 两个像素团从输出中擦除。

关键洞察：
- 递变速率不是常数：每个像素团身兼两职，用颜色指定本侧涂哪种色，
  又用自身像素数量指定本侧每步的增减量——画面角落的"杂点"其实是规则的参数，
  只有跨示例比较才会暴露速率在变。
```

## 8. 房间名牌

- 参考题目题号：056-2 (d4469b4b)、056-7 (00d62c1b)、056-1 (a680ac02)
- tags:
  - operation:查表替换, lookup_replace
  - operation:洪泛填充, flood_fill
  - operation:擦除, erase
  - object:封闭区域, enclosed_region
  - object:固定符号, fixed_symbol
  - relation:符号编码颜色, symbol_encodes_color
  - condition:仅封闭内生效, effective_only_when_enclosed
  - condition:忽略干扰项, ignore_distractors

### docstring

```text
每个封闭房间内的灰色小符号是颜色的名字：把房间漆成符号所编码的颜色并擦除符号。

输入结构：
- 黑色背景上有若干绿色闭合边界围成的房间，房间内部为黑色。
- 部分房间内部各含一个 3x3 灰色小符号（如 T 形、十字形、L 形等，
  符号种类固定且在训练示例间复用）。
- 封闭区域之外也可能散布同样的灰色符号。

规则：
- 每种灰色符号对应一种固定颜色，对应关系在所有示例间保持一致，需从示例中归纳。
- 将每个含符号房间的内部（含符号原先占据的格）整体填充为该符号所编码的颜色；
  绿色边界保持不变。
- 不含符号的房间内部保持黑色；位于所有封闭区域之外的灰色符号是干扰，直接擦除。

关键洞察：
- 灰色符号不是要保留的图形而是"颜色的名牌"；名牌只有写在拓扑封闭的房间里才生效，
  拓扑封闭性判断与符号查表解码两层规则缺一不可，且码表本身必须跨示例自行归纳。
```
