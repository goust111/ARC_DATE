## 1. 相位识漏的瀑布

- tags:
  - operation:周期推断, period_inference
  - operation:重力下落, gravity_drop
  - operation:溢出扩散, overflow_spread
  - object:架子, shelf
  - object:水源, water_source
  - object:缺损像素, corrupted_pixel
  - relation:周期相位对应, periodic_phase_match
  - condition:相位区分同貌背景, phase_disambiguates_background
- 参考题目题号: 3（36a08778）、13（c663677b）
- 评审档位: 达标偏上

### docstring

```text
从顶行水源落下的水沿货架漫流，货架缺口由横向周期唯一还原，缺口漏水、真端溢流。

输入结构：
- 背景为最常见色；架子色像素构成若干水平线段，全部架子行的布局沿水平方向按同一最小周期重复。
- 若干本应是架子的格子被抹成背景色，形成缺口；未被抹去的架子像素足以唯一推断该周期，缺口在输出中保持背景、不予修补。
- 贴着顶行有一个或多个水色像素，是水源。

规则：
- 先由现存架子像素推断唯一最小横向周期，得出每行架子的完整应有跨度；"应有架子却是背景"的格子即缺口。
- 水从每个水源竖直下落，途经的背景格染成水色，落到某架子段上后沿该架子上方一行向左右两侧漫延。
- 漫延的一侧若先到达缺口正上方，则水灌入缺口（缺口格染成水色）并从缺口下方继续竖直下落，该侧漫延到此为止；若先越过架子的真实端点，则在端点外一格处拐落，从那里继续竖直下落。
- 每一股继续下落的水按同样规则递归处理，直到抵达底边或既有水体。

关键洞察：
- 缺口旁的背景与端点外的背景在画面上一模一样，但一个让水"穿架而漏"、一个让水"绕端而溢"；把架子的断口当成两段独立货架去模拟会得到完全不同的水路，唯一能区分二者的是横向周期相位。
```

## 2. 顺序消融的闸门塔

- tags:
  - operation:重力下落, gravity_drop
  - operation:擦除, erase
  - object:令牌, token
  - object:闸门, gate
  - relation:同色对应, same_color_match
  - relation:连锁反应, chain_reaction
  - condition:碰撞停止, collision_stop
  - condition:顺序依赖, order_dependence
- 参考题目题号: 5（2b83f449）、2（a2d730bd）、3（36a08778）
- 评审档位: 达标

### docstring

```text
顶行令牌自左向右依次坠落，同色闸门被穿透并消融，异色闸门与先落者构成地形。

输入结构：
- 网格两侧为墙色，内部为背景色的竖直腔体。
- 顶行散布若干单像素彩色令牌，每列至多一个。
- 腔内横亘若干水平闸门条（长度不小于三格），每条闸门单色，闸门彼此不相触。

规则：
- 令牌按所在列从左到右的顺序逐一下落，前一枚完全沉降后下一枚才开始。
- 下落中令牌遇到与自己同色的闸门时，该闸门整条变为背景色，令牌穿过原闸门位置继续下落；一枚令牌可依次消融多条同色闸门。
- 遇到异色闸门、已沉降的令牌、墙或底边时，令牌停在其正上方一格。
- 输出为全部令牌沉降后的画面：被消融的闸门不再存在，存留的闸门与墙保持原样。

关键洞察：
- 令牌并非各自独立地在本列做碰撞判定：先落令牌消融的闸门往往横跨多列，为后续令牌打开了原本封死的通道，最终位形只能按左右次序把整条连锁走完才能得到。
```

## 3. 孔向接力的信号链

- tags:
  - operation:射线延伸, ray_extend
  - operation:重涂色, recolor
  - operation:擦除, erase
  - object:连通分量, connected_component
  - object:封闭区域, enclosed_region
  - object:种子像素, seed_pixel
  - relation:方向指示, direction_indication
  - relation:连锁分支, cascading_relay
  - condition:含空洞对象为潜在发射者, holed_objects_as_emitters
  - condition:仅被点燃者行动, only_ignited_fire
- 参考题目题号: 7（b2862040）、6（25d487eb）、12（9edfc990）、2（a2d730bd）
- 评审档位: 达标

### docstring

```text
唯一点燃的信号沿各对象孔的偏心方向逐站接力，中继站继续传递，无孔终点站吞下信号，未被触及的待命者保持沉默。

输入结构：
- 黑色背景上分布若干互不接触的单色四连通对象。
- 部分对象内部有一个完全封闭的背景孔，孔的中心相对该对象外接框中心恰沿上、下、左、右之一偏移；其余对象无孔。
- 恰有一个带孔对象的孔内含一个彩色单像素（信号种子），其颜色不同于任何对象色。
- 保证每次发射的射线至多命中一个对象、链不成环、链上每站至多被命中一次。

规则：
- 只有孔内含种子的对象首先发射：沿"该对象外接框中心指向孔中心"的方向，从自身边界外第一格起画一条一像素宽、种子色的射线，穿过背景延伸；种子像素本身抹为背景。
- 射线抵达另一对象则停在其边界前一格，该对象全部像素被重涂为种子色（孔保持背景）；若它自身带孔，则以同样方式沿自己的孔向继续发射种子色射线，接力下去。
- 射线若未命中任何对象则止于网格边缘，链到此为止；命中无孔对象时链自然终止。
- 所有未被链触及的对象（包括其他带孔对象）保持原样，不发射、不变色。

关键洞察：
- 画面上没有任何箭头，方向是"从体心望向孔心"这条从未画出的向量；而且并非所有带孔对象都会行动——它们只是装了瞄具的哑炮，只有被信号逐站点燃的那一支链会亮起来，链的走向由每站自己的孔重新决定。
```

## 4. 互为镜鉴的缩放双影

- tags:
  - operation:像素放大, pixel_upscale
  - operation:修补, repair
  - operation:重涂色, recolor
  - object:中心图案, central_pattern
  - object:缺损像素, corrupted_pixel
  - relation:均匀倍率对应, uniform_scale_correspondence
  - relation:交叉互证, cross_verification
  - condition:匀色块可信混色块存伪, uniform_block_trusted
- 参考题目题号: 14（c59eb873）、13（c663677b）、17（8fbca751）
- 评审档位: 达标

### docstring

```text
一大一小互为放大投影的两个图案各有损坏，以"匀色方块可信、混色方块存伪"为凭交叉互证，把两边都修复。

输入结构：
- 背景上有彼此分离的一大一小两个多色图案。
- 大图案的外接框边长恰为小图案外接框的同一整数倍 s，二者本应满足：大图案是把小图案每个像素放大成 s×s 同色方块的精确投影。
- 两个图案各自散布损坏：小图案的某些像素被改成调色板内的其他颜色；大图案的某些 s×s 方块内的部分像素被改色，使这些方块内部混色（可能混到被改色像素占多数）。
- 保证同一对应位置不会两边同时损坏：小图案像素被改处，其对应大方块完好匀色；大方块混色处，其对应小图案像素完好。

规则：
- 由两外接框边长之比得到唯一放大倍率 s，按 s 将两图案逐块对齐。
- 凡大图案中匀色的 s×s 方块视为可信：若小图案对应像素与其颜色不一致，则把小图案该像素改为方块色。
- 凡大图案中混色的方块视为损坏：将其整块重涂为小图案对应像素的颜色。
- 背景与其余像素不变。

关键洞察：
- 两个图案没有哪一个是完好的钥匙，可信度不是属于"图"而是属于"块"——匀色即真、混色即伪；在块内做多数表决会被占多数的改色像素骗倒，唯一稳固的证词来自另一幅影像的对应位置。
```

## 5. 同一枚印章的四种朝向

- tags:
  - operation:平铺, tiling
  - operation:旋转, rotate
  - operation:重涂色, recolor
  - object:小型瓦片, small_tile
  - object:前景掩码, foreground_mask
  - relation:旋转朝向对应, orientation_correspondence
  - condition:精确覆盖按朝向着色, exact_cover_by_orientation
  - condition:镜像例外, mirror_exception
- 参考题目题号: 1（626c0bcc）、16（e40b9e2f）
- 评审档位: 达标偏上

### docstring

```text
把前景掩码分解成同一枚不对称印章经旋转（其中一份还经镜像）的平移拷贝，按各自朝向染色，并揪出唯一的镜像冒充者。

输入结构：
- 网格一角孤立地给出一枚单色不对称小形状（印章），它没有任何旋转或镜像自对称。
- 其余前景是与印章同色的一个掩码，可被印章经旋转（其中一份还经镜像）后的平移拷贝恰好无重叠、无遗漏地铺满，且这种分解唯一。
- 掩码中的拷贝各自呈印章的 0°、90°、180°、270°（顺时针）旋转朝向，其中恰有一份无法由任何旋转得到，只能由镜像得到。

规则：
- 找出掩码的唯一铺砌分解，逐份判定朝向。
- 与印章同向的拷贝染蓝色，顺时针转 90°、180°、270° 的拷贝分别染红色、绿色、黄色。
- 那份只能镜像得到的拷贝染灰色。
- 角上的印章与背景保持不变。

关键洞察：
- 覆盖单元不是几种不同的形状，而是同一枚印章的不同朝向；由于印章不对称，每份拷贝的朝向唯一可判，而看似"又一个旋转态"的那份其实翻了面，旋转四色码表对它全部失配。
```

## 6. 门塞、套间与高度码表

- tags:
  - operation:计数, count
  - operation:洪泛填充, flood_fill
  - operation:擦除, erase
  - object:轮廓线, contour_line
  - object:封闭背景区域, enclosed_bg_region
  - object:标记像素, marker_pixel
  - object:色条, color_bar
  - relation:高度编码数量, height_encodes_count
  - relation:拓扑位置定语义, position_determines_role
  - condition:门缝连通合并计数, door_merged_counting
- 参考题目题号: 11（753ea09b）、4（a1aa0c1e）、12（9edfc990）、19（8886d717）
- 评审档位: 达标

### docstring

```text
拔掉嵌在围墙缺口上充当门塞的灰点，把貌似封闭的腔室焊通成套间，再按套间内真正的计数灰点总数查乱序高度码表上色。

输入结构：
- 轮廓色的围墙在背景上划出若干腔室，视觉上每个腔室都是完全封闭的。
- 灰色单像素分两种放置而颜色毫无差别：一种散落在腔内背景上（计数筹码），四邻皆为背景；另一种恰好嵌在围墙线的一格缺口里（门塞），沿墙方向的两个邻格均为围墙色、垂直墙方向的两个邻格均为两侧腔室的背景。
- 网格一侧竖立若干互不相触的单色竖条，颜色互不相同、高度互不相同，左右排列次序与高度故意无关。
- 保证：拔掉全部门塞后，按四连通并合出的每个套间，其腔内计数灰点总数恰等于某一竖条的高度；门塞不计入任何点数。

规则：
- 把嵌在围墙缺口上的灰点识别为门：该格视为通道，属于套间背景；散落腔内的灰点仍是计数筹码。
- 以围墙像素为障碍对背景做四连通划分，经门格连通的腔室合并为同一套间。
- 对每个套间数出计数灰点总数 n，找到高度恰为 n 的竖条，把该套间的全部背景格（含门格与筹码所在格）填成该条的颜色，筹码随之抹去。
- 围墙、竖条与套间之外的背景保持不变。

关键洞察：
- 同一种灰点有两种身份，身份不写在颜色上而写在拓扑位置上——嵌进墙线的是门塞、浮在房中的是筹码；不拔门塞则房间划分错，把门塞当筹码则点数错，任何一处认错都会让整张"高度=数量"的乱序码表查错行，全盘染错。
```
