## 1. 噪声即信号

- 参考题目题号：8（0607ce86）、6（88a62173）
- tags:
  - operation:投票恢复, majority_vote_recovery
  - operation:叠合拼装, overlay_assembly
  - object:插槽阵列, slot_array
  - object:精灵体, sprite
  - relation:槽内相对坐标, slot_relative_position
  - condition:偏差即信号, deviation_as_signal
  - condition:忽略干扰项, ignore_distractors

### docstring

```text
从规则精灵阵列各槽位的损伤差异中拼出隐藏图形，而不是清理噪声。

输入结构：
- 背景为最多色。
- 非背景像素构成规则排列的矩形槽位阵列，每个槽位是同一底色精灵的一份拷贝。
- 每份拷贝有若干像素被改成了别的颜色（偏差像素），不同槽位的偏差按槽内
  相对坐标互不重叠。
- 槽位之外另有少量游离噪声像素。

规则：
- 找出槽位阵列，并把各槽对齐到统一的槽内相对坐标系。
- 对每个相对位置取所有槽位的多数颜色，得到标准精灵。
- 输出一个精灵大小的网格：凡有某槽位在该相对位置偏离标准精灵的，写入该
  偏差颜色；其余位置写背景色。
- 槽位之外的游离像素全部忽略。

关键洞察：
- 题面伪装成"去噪修复"，但答案不是修好的阵列；所有拷贝的损伤叠放到同
  一张小图上，才是要输出的隐藏图形。
```

## 2. 对角镜与染色光束

- 参考题目题号：15（9f8de559）、3（85fa5666）、20（e87109e9）
- tags:
  - operation:射线延伸, ray_extend
  - operation:转向, turn
  - operation:重涂色, recolor
  - object:标记像素, marker_pixel
  - object:轨迹, trail
  - object:对角镜, diagonal_mirror
  - relation:反向投射, opposite_direction
  - condition:形状定镜向, shape_encodes_mirror
  - condition:镜色染束, mirror_dyes_beam

### docstring

```text
沿粉色轨迹的反方向从红点发射光束，遇对角双格镜按其斜线反弹并被镜色重新染色，画出整条折线。

输入结构：
- 背景占多数；有一个红色单像素发射源，其旁有一段直线粉色轨迹，指示光束
  的来向。
- 场上散布若干面镜子，每面镜子由两个对角相邻的同色像素组成，即一段"/"
  或"\"形斜线；不同镜子颜色各异。
- 镜子的摆放保证光束逐次反弹后最终离开网格。

规则：
- 光束从红色源出发，方向取粉色轨迹的相反方向，初始颜色为红色。
- 光束沿直线前进，把经过的背景格染成当前颜色。
- 将要撞上某面镜子时，按该斜线做 90 度反射（如"\"把向右的光束折向下）；
  反弹后光束改用该镜子的颜色继续前进并染色。
- 到达网格边缘停止；镜子与粉色轨迹本身保持不变。

关键洞察：
- 镜子不是障碍而是转向器兼染料——两个对角像素的连线方向就是镜面方向；
  粉色轨迹给出的不是目标方向而是来向。
```

## 3. 指针面板轮换

- 参考题目题号：14（b7f8a4d8）、2（3391f8c0）、9（d8e07eb2）、7（09c534e7）
- tags:
  - operation:查表匹配, table_lookup
  - operation:图案替换, pattern_swap
  - operation:擦除, clear
  - object:带框瓦片, framed_tile
  - object:单点标记, singleton_marker
  - relation:指针置换环, pointer_permutation_cycle
  - condition:同步替换, simultaneous_replacement
  - condition:颜色即地址, color_as_address

### docstring

```text
每块带框面板内的单像素指针以颜色指向另一块面板的框色，所有面板内容沿指针构成的置换环同时轮换。

输入结构：
- 背景上分布若干互不相接的矩形带框面板，各面板框色互不相同，内部区域同
  尺寸。
- 每块面板内部有一幅图案和一个单像素指针；指针颜色异于本面板内容与框色，
  且总等于另一块面板的框色。
- 全部指针合起来构成面板集合上的一个置换，环长可大于二。

规则：
- 读取每块面板的指针，得到"内容送往哪块面板"的映射。
- 同时进行：清空所有面板内部，把每块面板的原内容（不含指针）原样绘制到
  指针所指面板的内部，按内部区域左上角对齐。
- 框与背景保持不变，输出中删除所有指针像素。

关键洞察：
- 单像素不是杂色，它的颜色是地址；面板内容不是成对互换，而是沿指针环整
  体轮转，且必须同时进行——部分示例的二环会诱导成"简单互换"的错误规则。
```

## 4. 间距定环深

- 参考题目题号：17（99306f82）、13（696d4842）、5（fc754716）
- tags:
  - operation:同心层填充, concentric_fill
  - operation:计数, counting
  - object:空心矩形框, hollow_rect_frame
  - object:标记像素, marker_pixel
  - relation:视线匹配, sightline_matching
  - condition:间距编码层深, gap_distance_encodes_ring_depth

### docstring

```text
框外每个色点到它所望向的矩形框的直线间距，决定该色点颜色填在框内第几层同心环。

输入结构：
- 空背景上有两个内部为空的一像素厚矩形框。
- 框外散布若干单像素色点，每个色点与恰好一个框同行或同列且中间只有背景，
  据此确定归属。
- 归属同一框的各色点到框壁的背景格数互不相同，恰为 1 到 N（N 为该框内部
  的同心环层数）。

规则：
- 先按行列视线把每个色点归属到它望向的框。
- 对每个色点数出它与框壁之间的背景格数 d，把该框内部第 d 层同心环（最外
  为第 1 层）涂成该点颜色；最内的剩余中心块整块涂色。
- 框、色点与外部背景保持不变。

关键洞察：
- 色点的方位排列是诱饵——按顺时针或自上而下读色序会在部分示例上出错；
  真正的编码是"离框多远，就染多深"。
```

## 5. 括号视线捕获

- 参考题目题号：18（1e81d6f9）、13（696d4842）、4（6cbe9eb8）
- tags:
  - operation:搬移, relocate
  - operation:擦除, erase
  - object:角括号, corner_bracket
  - object:前景对象, foreground_object
  - relation:视线匹配, sightline_matching
  - condition:装得下才捕获, fit_to_capture
  - condition:角落对齐, corner_aligned

### docstring

```text
每个角括号沿其开口的对角方向望去，捕获第一个能装进括号内部的物体，贴角放入括号并擦除原位。

输入结构：
- 背景为最多色。
- 有若干个单色直角括号（L 形，占两条边），其开口朝向某个对角方向。
- 场上散布若干互不相接的前景物体，尺寸各异。

规则：
- 从每个括号的直角顶点沿开口对角方向作视线，依次检查视线扫过的物体。
- 跳过包围盒装不进括号内部的物体，捕获视线上第一个装得下的物体。
- 把被捕获物体平移进括号内部，使其包围盒角与括号直角贴合对齐，原位置
  擦除；未被任何括号捕获的物体保持原样。

关键洞察：
- 括号不是删除颜色的选择器，而是有口径的捕获器——离得最近的物体如果装
  不下就会被越过，"第一个装得下"才是被选中者。
```

## 6. 嵌套即指令

- 参考题目题号：4（6cbe9eb8）、1（c3fa4749）、13（696d4842）
- tags:
  - operation:平移, translate
  - operation:擦除, erase
  - object:空心矩形框, hollow_rect_frame
  - object:前景精灵, foreground_sprite
  - relation:嵌套层次, nesting_hierarchy
  - relation:贴靠侧, contact_side
  - condition:结构即程序, structure_as_program
  - condition:空隙编码步数, gap_encodes_steps

### docstring

```text
层层嵌套的空心框是一段移动程序——每层贴靠外层内壁的那一侧给出方向，贴靠侧对面的空隙宽度给出步数，把最内层小图形按程序搬走。

输入结构：
- 背景上有若干层依次嵌套的一像素厚空心矩形框，最内层框里有一个小图形。
- 每一层（含小图形相对最内框）恰好贴住其外一层内壁的一侧，其余三侧留有
  背景空隙。
- 贴靠侧正对面的空隙宽度即该层的步数。

规则：
- 从最外层到最内层，把每层读成一条位移指令：方向 = 该层贴靠的那一侧，
  步数 = 贴靠侧对面的空隙宽度。
- 输出网格上删去所有框，只保留小图形，并把它按全部指令的向量和从原位置
  平移；结果保证仍在网格内。

关键洞察：
- 嵌套框不是容器而是指令带——方向写在"贴哪边"，步数写在"对面剩多宽"，
  整叠嵌套要当成一段程序逐层解码并求和执行。
```
