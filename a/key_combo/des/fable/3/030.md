## 1. 缺席的互补搭档

- tags:
  - operation:反转填充, occupancy_inversion
  - operation:旋转, rotate
  - operation:配对, pairing
  - object:瓷砖, tile
  - object:分隔行列, separator_rows_and_columns
  - relation:复合变换配对, composite_transform_pairing
  - condition:落单者取搭档, unpaired_tile_partner
- 参考题目题号：7 (1c0d0a4b)、8 (1b60fb0c)、1 (358ba94e)

### docstring

```text
瓷砖两两按"逐格互补再旋转180度"结成搭档，找出落单的一块并画出它缺失的搭档。

输入结构
- 网格被整行整列的分隔线划分为奇数块等大瓷砖。
- 每块瓷砖用同一前景色与同一背景色画有图案。
- 除一块外，其余瓷砖两两配对：同对的两块中，一块等于另一块先逐格取补
  （前景变背景、背景变前景）再绕自身中心旋转180度的结果。
- 配对瓷砖在网格中的位置彼此无关；恰有一块瓷砖找不到搭档。

规则
- 在全部瓷砖间按"取补后旋转180度"的关系配对。
- 找出唯一无搭档的瓷砖。
- 输出一块与单块瓷砖等大的网格，内容为该落单瓷砖先逐格取补、再旋转180度
  的结果。

关键洞察
- 瓷砖间的配对既不是相同、不是单纯镜像旋转、也不是单纯互补，而是补集与
  旋转的复合；答案不是落单瓷砖本身，而是按该复合关系为它生成的缺席搭档。
```

## 2. 孔洞即矢量

- tags:
  - operation:填充, fill
  - operation:射线绘制, ray_drawing
  - operation:计数, counting
  - object:实心矩形, solid_rectangle
  - object:孔洞, hole
  - relation:偏移定方向, offset_sets_direction
  - condition:孔洞面积定长度, hole_area_sets_length
- 参考题目题号：6 (44d8ac46)、4 (a48eeaf7)、11 (c61be7dc)

### docstring

```text
把每个矩形内部的孔洞读作一支箭：偏移方向定射线方向，孔洞面积定射线长度。

输入结构
- 黑色背景上有若干互不相触的实心彩色矩形，颜色各不相同。
- 每个矩形内部有一个矩形黑色孔洞。
- 孔洞中心相对矩形中心的偏移严格沿八个方向（水平、竖直或45度对角）之一。

规则
- 对每个矩形，先用矩形自身颜色填满其孔洞。
- 再从矩形边界外紧邻的一格起，沿孔洞的偏移方向画一条该矩形颜色的射线；
  射线沿矩形中心所在的行、列或对角线延伸。
- 射线长度等于孔洞的格子数；射线到网格边界处截断。

关键洞察
- 孔洞不是要修补的缺陷，而是一枚编码：它的位置是方向盘，它的大小是刻度
  尺；修补孔洞只是发射后的清膛。
```

## 3. 旋转投票修复

- tags:
  - operation:对称补全, symmetry_completion
  - operation:多数投票, majority_vote
  - operation:重涂色, recolor
  - operation:擦除, erase
  - object:前景对象, foreground_object
  - object:调色板, palette
  - relation:旋转对称, rotational_symmetry
  - condition:象限分色, quadrant_color_split
- 参考题目题号：8 (1b60fb0c)、2 (27a77e38)、18 (08573cc6)

### docstring

```text
用三比一的旋转投票找出被破坏的象限，并用角落调色板中对应该象限的颜色标记
修复格。

输入结构
- 网格主体是一个关于其中心近似四重旋转对称的单色图形。
- 恰有一个象限中的少量格子偏离对称，既可能多画也可能漏画。
- 网格某个角落有一个远离图形的 2x2 调色板，四个颜色按其在调色板中的方位
  分别对应图形的四个象限。

规则
- 以图形的旋转中心，把每个格子与它旋转90、180、270度后的三个位置对比，
  取三者的多数值作为该格真值。
- 仅在真值与现状不同处修改：多画的格子清为背景；漏画的格子补上。
- 被补上的格子不用图形原色，而用调色板中该格所在象限对应方位的颜色涂写。
- 调色板保持不变。

关键洞察
- 修复本身只需旋转投票，但"用什么颜色修"另有一层：角落调色板按方位记录
  了四个象限各自的签名色，补上的格子要签上出错象限的名字。
```

## 4. 视线的交点与灰烬

- tags:
  - operation:填充, fill
  - operation:重涂色, recolor
  - object:标记像素, marker_pixel
  - object:墙体, wall_cell
  - relation:行列交叉, row_col_intersection
  - relation:射线遮挡, ray_occlusion
  - condition:双向可见才染色, dual_visibility_paint
  - condition:首墙染标记色, first_wall_stained
- 参考题目题号：20 (2281f1f4)、4 (a48eeaf7)、18 (08573cc6)

### docstring

```text
视线被墙截断时把那堵墙染成标记色，两束尚未熄灭的视线交会的行列交叉点涂红。

输入结构
- 网格背景为黑。
- 顶行有若干同色列标记，最左列有另一颜色的若干行标记。
- 网格内部散布灰色墙格。

规则
- 每个顶部标记沿所在列向下投射视线，每个左侧标记沿所在行向右投射视线。
- 视线在遇到的第一堵墙处截断，并把该墙格改涂为投射者的颜色；未遇墙的视线
  直达边界且不留任何痕迹。
- 对每个"标记列 × 标记行"的交叉格，仅当它同时位于其列视线与行视线被截断
  之前的范围内时，将其涂红。
- 标记与其余墙格保持不变。

关键洞察
- 被染色的墙看上去像是标记坠落后粘住的，但未被截断的标记并不落到边界，
  可见那不是坠落而是光的灰烬；红点也不是全部行列交点，而是两束视线都尚未
  熄灭之处。
```

## 5. 燃料螺旋

- tags:
  - operation:螺旋绘制, spiral_drawing
  - operation:计数, counting
  - operation:擦除, erase
  - object:中心标记, center_marker
  - object:填充块, filled_block
  - relation:像素数决定长度, pixel_count_length
  - condition:方位定旋向, side_sets_chirality
- 参考题目题号：18 (08573cc6)、11 (c61be7dc)、4 (a48eeaf7)

### docstring

```text
把色块当作燃料箱整体擦除，从标记点画出恰好消耗等量格子的方形螺旋，色块
相对标记的方位决定旋向。

输入结构
- 网格背景为黑，仅含两个前景成分：一个单格标记像素，和一个远离标记的单色
  连通色块。
- 色块中心与标记不在同一列。

规则
- 擦除整个色块。
- 从标记出发，以步长1,2,3,...依次转弯画方形螺旋，画出的格子全部使用色块
  的颜色。
- 色块位于标记右侧时，螺旋按顺时针次序转弯；位于左侧时按逆时针次序。
- 当累计画出的格子数达到色块的格子数时立即停笔。
- 标记像素保留原色。

关键洞察
- 色块不是要搬运或复制的对象，而是燃料：它的面积决定螺旋的墨量，它的方位
  决定螺旋的旋向。
```

## 6. 补全后再挑异类

- tags:
  - operation:对称补全, symmetry_completion
  - operation:计数, counting
  - operation:裁剪, crop
  - object:前景块, foreground_block
  - object:背景孔洞, background_hole
  - object:遮挡块, occluder
  - relation:前景遮挡, foreground_occlusion
  - condition:孔洞数量唯一, unique_hole_count
- 参考题目题号：1 (358ba94e)、3 (52df9849)、8 (1b60fb0c)

### docstring

```text
先按块内点对称还原被遮挡的格子，再挑出孔洞数独一无二的块并输出其还原后的
裁剪。

输入结构
- 背景色占多数。
- 一种前景色构成若干互不相连的等大方块：每块有实心边框，内部散布背景色
  孔洞，且每块的孔洞图案关于该块中心点对称。
- 另一种遮挡色覆盖了部分块的部分格子，但从不同时覆盖一对点对称的格子。

规则
- 对每个被遮挡的块，利用其自身的点对称性把被遮挡格还原为前景或孔洞。
- 统计每块还原后的孔洞数；恰有一个孔洞数只出现一次。
- 输出该块还原后的完整方块，按其包围盒裁剪，不含任何遮挡色。

关键洞察
- 想数孔必须先揭开遮挡，而揭开遮挡的钥匙藏在每个块自身的点对称里；
  对称还原、孔洞计数、异类提取三步串联，缺一不可。
```

## 7. 条纹窗外的对角线

- tags:
  - operation:重建, rebuild
  - operation:擦除, erase
  - operation:补全, complete
  - object:对角线, diagonal
  - object:窗口行, window_row
  - object:残迹像素, residue_pixel
  - relation:跨窗共线, cross_window_collinearity
  - condition:交点用窗色标记, crossings_take_window_color
- 参考题目题号：19 (05269061)、5 (4612dd53)、3 (52df9849)

### docstring

```text
散落在灰色窗口行上的彩点是被遮住的整条45度对角线的残迹，重建每条对角线并
把它们的交点涂回灰色。

输入结构
- 黑色背景上有若干整行的灰色条纹（窗口行）。
- 彩色像素只出现在灰色条纹上。
- 同色像素每色至少三个，且恰好共线于同一条45度对角线。

规则
- 抹去所有灰色条纹，恢复为黑色背景。
- 对每种颜色，画出穿过其全部残迹点、延伸到网格边界的整条45度对角线。
- 若两条不同色的对角线交于同一格，该格涂灰色，不涂任何一方的颜色。

关键洞察
- 条纹不是分隔符而是取样窗：对角线只在窗口行显影，参与规则的线从未被完整
  画出；抹掉窗子之后，颜色冲突的交点恰好用窗子的颜色留名。
```

## 8. 调色板的嵌套令

- tags:
  - operation:重建, rebuild
  - operation:计数, counting
  - operation:填充, fill
  - object:调色板行, palette_row
  - object:嵌套矩形, nested_rectangle
  - object:散点, scattered_pixel
  - relation:书写次序定嵌套, palette_order_sets_nesting
  - condition:散点数定厚度, pixel_count_sets_thickness
- 参考题目题号：16 (ff2825db)、13 (5751f35e)、9 (bd5af378)

### docstring

```text
按顶行调色板的先后次序，把各色散点重画为由外而内的同心厚框，厚度等于各色
散点的数量。

输入结构
- 网格顶行从左端起是一段无重复颜色的调色板，其余为黑。
- 调色板下方的画板区域内散布这些颜色的像素点。
- 散点的空间分布故意与真实嵌套次序矛盾：某色散点可以比另一色更靠中心，
  而调色板规定它在外层。
- 各色散点数量之和的两倍不超过画板区域的短边。

规则
- 抹去所有散点。
- 在画板区域内由外而内绘制同心矩形厚框：第一层贴画板边界，颜色取调色板
  第一色，厚度等于该色散点的个数。
- 随后每层紧贴上一层内侧，依调色板次序取色，厚度等于对应色散点个数。
- 全部层画完后剩余的中央矩形保持黑色；调色板行保持不变。

关键洞察
- 散点的位置是彻头彻尾的诱饵：谁在外、谁在内由调色板的书写次序决定，
  散点唯一的贡献是"数量即厚度"。
```
