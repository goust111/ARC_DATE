## 1. 链式射线接力

- 难度评审:`达标`
- 参考题目题号:题 1(689c358e)、题 2(d4a91cb9)、题 10(88bcf3b4)
- tags:
  - operation:射线延伸, ray_extend
  - operation:连锁激活, chain_activation
  - object:箭头精灵, arrow_sprite
  - object:矩形边框, rectangular_frame
  - object:边框端点, frame_endpoint
  - relation:颜色匹配定起点, color_match_starter
  - condition:横杆偏移定方向, crossbar_determines
  - condition:碰撞传递激活, hit_relays_activation

### docstring

```text
从与边框同色的箭头开始,沿指向接力发射射线,最终在边框上标记接力终点。

输入结构:
- 网格外围是一圈单像素实心矩形边框,内部为统一背景色。
- 内部散布若干互不相触的单色六像素 T 形箭头精灵:长 4 的主杆加长 3 的横杆,
  横杆偏向尖端一侧。
- 恰有一个箭头的颜色与边框颜色相同;其余箭头颜色互不相同且不同于边框。

规则:
- 与边框同色的箭头首先被点燃:从其尖端沿主杆轴向逐格发射一条同色射线。
- 射线遇到另一箭头精灵即停止,并点燃该箭头,由它继续按自身指向发射自己颜色的射线。
- 某条射线到达边框时接力结束:该边框格被涂成最后一个被点燃箭头的颜色。
- 从未被点燃的箭头保持原样,不发射任何射线。

关键洞察:
- 横杆偏移端是尖端,决定每个箭头的发射方向;与边框同色是引信标记。
- 答案由激活链的传递顺序决定,而非所有箭头同时发射:哪些箭头发光、
  边框终点取什么颜色,都只能沿链逐步推出。
```

## 2. 里程码填色

- 难度评审:`达标`
- 参考题目题号:题 8(2d0172a1)、题 12(9d9215db)、题 11(e69241bd)、题 14(c0f76784)
- tags:
  - operation:洪泛填充, flood_fill
  - object:嵌套框架, nested_frame
  - object:角落码, corner_code
  - object:封闭区域, enclosed_region
  - relation:包含链, containment_chain
  - condition:叶层锚定索引, leaf_anchored_index
  - condition:拓扑决定填色, topology_determines_fill

### docstring

```text
从每条嵌套链的最内层区域起,依次用角落对角码的颜色向外填充各层区域。

输入结构:
- 背景单色;一种前景色画出若干形状不规则的封闭框。
- 封闭框构成几条互不相交的嵌套链(每个框内直接包含至多一个子框),各链嵌套深度可以不同。
- 网格某角落有一段沿对角线排列的彩色像素码,码色不同于框色与背景。

规则:
- 对每条嵌套链,把它围出的各层背景区域从最内层向外编号 1,2,3……
- 从最靠角的码像素起数,第 k 个码像素的颜色即编号为 k 的区域的填充色。
- 用对应颜色洪泛填充每个被围区域;框、码与框外背景保持不变。

关键洞察:
- 调色表的锚点在每条链的最内层而不是最外层:链深相等的示例里"由外向内数"
  的假索引同样成立,链深不同的示例才暴露真规则——浅链的外层区域取的是低序号码色。
- 填色只取决于到最内层的层距,与区域大小、形状、位置以及从外面数的深度都无关;
  个别示例中区域大小与层号反相关,按大小取色的假规则同样破产。
```

## 3. 序列图例的连锁降落

- 难度评审:`达标`
- 参考题目题号:题 4(6ca952ad)、题 15(88e364bc)、题 10(88bcf3b4)
- tags:
  - operation:重力下落, gravity_drop
  - operation:时序模拟, sequential_simulation
  - object:可移动精灵, movable_sprite
  - object:边缘序列图例, edge_order_legend
  - object:地形, terrain
  - relation:先落者为障碍, landed_becomes_obstacle
  - condition:图例定次序, legend_determines_order
  - condition:碰撞停止, collision_stop

### docstring

```text
按边缘颜色序列列出的次序逐个落下悬浮精灵,先落者成为后落者的障碍。

输入结构:
- 黑色背景;底部有灰色的不规则地形。
- 上方悬浮若干互不相触的精灵,颜色互不相同。
- 某一侧边缘贴着一列颜色序列,其颜色与悬浮精灵一一对应,每色恰出现一次。

规则:
- 依照边缘序列从头到尾的顺序,每次取出对应颜色的精灵,令其保持形状竖直下落。
- 精灵下落直到与灰色地形、网格底边或已落定的精灵相触即停,随后成为固定障碍。
- 全部落完后输出:地形与边缘序列保持不变,各精灵处于落定位置。

关键洞察:
- 降落是逐个进行的时序过程:精灵的列区间相互重叠,先落的精灵会垫高后落精灵
  的落点,交换次序就得到不同结果,因此无法一次性各自独立下落。
- 边缘序列不是装饰或图例配色,而是这场连锁降落的时间轴。
```

## 4. 负形认领

- 难度评审:`达标`
- 参考题目题号:题 11(e69241bd)、题 6(7bb29440)、题 14(c0f76784)、题 8(2d0172a1)
- tags:
  - operation:洪泛填充, flood_fill
  - operation:形状匹配, shape_matching
  - operation:擦除, erase
  - object:墙壁, wall
  - object:封闭区域, enclosed_region
  - object:候选精灵, candidate_sprite
  - relation:图底反转, figure_ground_reversal
  - condition:全等认领定色, congruence_claims_color

### docstring

```text
让墙外的彩色精灵按形状全等认领各自对应的腔室并为其填色,被认领的精灵随之消失。

输入结构:
- 网格一侧有一块灰色墙体围成的封闭结构,内部被隔成若干形状互异的背景色腔室。
- 网格其余空地上散布若干单色实心精灵:每个腔室恰有一个与其形状全等
  (仅平移,不旋转不翻转)的精灵,另有若干与任何腔室都不全等的干扰精灵。
- 若干腔室与干扰精灵面积相同但形状不同。

规则:
- 把每个腔室与形状全等的精灵配对。
- 用该精灵的颜色洪泛填充对应腔室。
- 被认领的精灵整体擦除为背景;干扰精灵与灰墙保持不变。

关键洞察:
- 腔室是从未被当作对象画出的负形:必须完成图底反转,把墙体间的空洞当作形状,
  与外部精灵做全等匹配。
- 填色关系由形状认领决定,与距离、面积和颜色顺序无关——同面积异形的干扰精灵
  堵死了按面积配对的捷径;精灵是否消失反过来指认哪些是真钥匙。
```

## 5. 色带程序走针

- 难度评审:`达标偏上`
- 参考题目题号:题 13(4be741c5)、题 20(342dd610)、题 16(e98196ab)、题 5(5614dbcf)
- tags:
  - operation:压缩, compress
  - operation:降噪, denoise
  - operation:平移, translate
  - object:色带, color_band
  - object:分隔线, divider_line
  - object:起点像素, start_pixel
  - relation:序列即程序, sequence_as_program
  - condition:主色定方向, majority_color_directs
  - condition:带厚定步长, band_thickness_steps

### docstring

```text
把噪声色带压缩成程序,驱动分隔线另一侧的走针画出路径。

输入结构:
- 一条通宽的分隔线把网格分成程序区与画布区。
- 程序区被横向色带铺满:每条带占若干行,行内主色一致但夹杂少量杂色像素。
- 画布区是空背景,只有一个起点像素。

规则:
- 沿程序区自上而下压缩色带:每条带的主色给出一步的方向
  (每种颜色固定对应上、下、左、右之一,跨示例一致),带的行数给出这一步走的格数。
- 走针从起点出发按程序逐步移动,沿途经过的格子涂成起点像素的颜色。
- 输出保持分隔线与程序区不变,画布区画出完整路径。

关键洞察:
- 色带不是要输出的图案而是指令序列:主色即方向,带厚即步长,
  同一条带同时编码一步的两个分量。
- 杂色像素靠逐行主色判定滤除;把压缩结果当作答案输出正是本题埋下的假规则。
```

## 6. 镜中之钥

- 难度评审:`达标`
- 参考题目题号:题 18(9ecd008a)、题 6(7bb29440)、题 16(e98196ab)
- tags:
  - operation:对称补全, symmetry_completion
  - operation:选择, selection
  - operation:裁剪, crop
  - object:缺失区域, missing_patch
  - object:分隔行, separator_row
  - object:候选精灵, candidate_sprite
  - relation:镜像, mirror
  - condition:补全内容作键, recovered_patch_as_key

### docstring

```text
用镜像补全出缺失补丁,再按补丁描绘的形状从候选精灵中裁出对应者。

输入结构:
- 一条分隔行把网格分成上下两部分。
- 上部是左右镜像对称的图案,其中一块矩形区域被涂黑挖去,其镜像位置完好。
- 下部散布若干形状互异、颜色互异的候选精灵。

规则:
- 在上部沿竖直对称轴用镜像恢复被挖去补丁的内容。
- 恢复出的补丁是一个单色小形状;在下部找到形状与之全等(不旋转不翻转)的候选精灵。
- 输出该精灵的最小包围盒裁剪,保留其自身颜色。

关键洞察:
- 挖去的补丁不是答案而是指针:必须先做对称补全才能读出"选哪个精灵"的钥匙,
  单看下部无从取舍。
- 补丁颜色与目标精灵颜色无关,匹配只看形状;直接输出补全后的补丁
  或整个修复图都是假规则。
```
