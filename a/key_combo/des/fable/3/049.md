## 1. 孔洞指针链

- 难度评审：达标偏上
- 参考题目题号：5（9ddd00f0）、10（9473c6fb）、13（5ad4f10b）
- tags:
  - object:瓦片阵列, tile_array
  - object:位置孔洞, position_hole
  - relation:坐标即指针, coordinate_as_pointer
  - operation:链式追踪, chain_tracing
  - operation:重涂色, recolor
  - condition:颜色循环分配, cyclic_color_assignment
  - condition:自指瓦片为链尾, self_pointer_terminates

### docstring

```text
沿瓦片孔洞编码的指针链依次给瓦片做三色循环染色。

输入结构
正方形网格边长为 n*n+n-1，被单像素背景行和背景列分隔成 n×n 个 n×n
瓦片。每个瓦片以同一前景色填满，唯留一个背景孔洞像素；孔洞在瓦片内
的局部坐标 (r,c) 是一条指针，指向阵列中位置 (r,c) 的那个瓦片。

规则
把所有孔洞读作指针后，全部瓦片连成一条覆盖每个瓦片恰一次的链：链尾
是唯一一个孔洞指向自身阵列位置的瓦片，链头是唯一不被任何指针指向的
瓦片。保持孔洞与分隔线为背景，从链头出发沿链前进，把途经瓦片的前景
像素依次重涂为红、青、灰循环，直到链尾。

关键洞察
孔洞不是自身坐标的标签（这是参考结构留下的诱饵），而是指向别的瓦片
的指针；孔洞恰好等于自身坐标的那个瓦片是链的终点。染色顺序由这条隐
藏链而非任何扫描序决定。
```

## 2. 厚度编码的同心环

- 难度评审：达标
- 参考题目题号：1（c658a4bd）、7（b1986d4b）、12（7d1f7ee8）
- tags:
  - operation:同心层填充, concentric_fill
  - operation:计数, counting
  - operation:排序, sorting
  - object:矩形边框, rectangular_perimeter
  - object:孤立像素, isolated_pixel
  - relation:严格包含, strict_containment
  - condition:点数编码环厚度, count_sets_ring_thickness
  - condition:框外点为干扰, outside_dots_ignored

### docstring

```text
把散落的空心矩形重建为居中同心方环，每种颜色的环厚度由框内所含标记
点的个数编码。

输入结构
背景网格上散落若干互不接触、颜色互异、大小互异的空心矩形框；网格上
另散布同一标记色的孤立像素点，有的严格落在某个框的内部，有的落在所
有框之外。

规则
忽略框外的标记点，统计每个框内部（严格在边框以内）的标记点个数。输
出为居中同心方环图：各颜色从外向内按对应框的边长从大到小排列，每种
颜色连续占据的层数等于其框内点数；输出边长等于全部框内点数之和的两
倍减一，最内层收于中心像素。

关键洞察
若每框恰含一个点，本题退化为经典的一色一层同心重建——这是诱饵；一旦
某框含有多个点，一色一层的解法失配，必须发现内含点数编码的是该颜色
环带的厚度，而框的位置与其在画面上的重叠残缺都与答案无关。
```

## 3. 调色板定序的攀升路径互为障碍

- 难度评审：达标
- 参考题目题号：8（712bf12e）、9（9b365c51）
- tags:
  - operation:路径生长, path_grow
  - object:控制像素, control_pixel
  - object:调色板列, palette_column
  - object:障碍块, blocker
  - relation:顺序一一对应, order_correspondence
  - relation:先画路径阻挡后画路径, earlier_path_blocks_later
  - condition:障碍偏转, obstacle_deflection

### docstring

```text
按左侧调色板给出的顺序依次让底行控制像素向上生长，先长成的路径成为
后续路径的障碍。

输入结构
黑背景。最左列顶部自上而下排着若干互不相同的单像素调色板色；底行散
布同一组颜色的控制像素，每色恰有一个；网格内部散布灰色障碍块。

规则
按调色板自上而下的颜色顺序逐条生长路径：从该颜色的底行控制像素出发，
若正上方为黑则上移一格并涂成该色；若正上方非黑（灰障碍，或任何已经
画好的先前路径像素），则右移一格涂色后继续尝试上移；右移目标非黑或
出界则该路径终止；到达顶行终止。输出保留调色板列、障碍与全部路径。

关键洞察
各路径不是互相独立的：先生长的路径会成为后生长路径的障碍物，因此生
长次序改变最终图案。诱饵是按控制像素从左到右的自然顺序处理——只有按
调色板列的自上而下顺序模拟，全部示例才同时成立。
```

## 4. 隐形尖端的镜像楔

- 难度评审：达标
- 参考题目题号：17（896d5239）、18（67b4a34d）、14（90f3ed37）
- tags:
  - operation:填充, fill
  - operation:外推, extrapolate
  - object:斜线残迹, diagonal_fragment
  - object:三角楔形区域, triangular_wedge
  - relation:镜像配对, mirror_pairing
  - relation:对角线边界, diagonal_boundary
  - condition:尖端从未画出, apex_never_drawn
  - condition:无伙伴线段为干扰, unpaired_fragment_ignored

### docstring

```text
把成镜像对的绿色斜线残迹沿各自对角线延长，在从未画出的交点处定出楔
形尖端并将楔形内部填青。

输入结构
黑背景上散布若干绿色的 45 度斜线段。其中一些线段两两关于某条竖直轴
镜像对称，构成一对；另有一些线段没有镜像伙伴，是孤立残迹。

规则
对每一对镜像线段，将两段各自沿所在对角线朝镜像轴的方向延长，两条延
长线交于一个未被画出的背景点，该点即楔形尖端；楔形以尖端为顶点、沿
两条对角线方向张开，高度取到该对线段中离尖端最远的像素所在的行为
止；将楔形内部与边界上的所有非绿像素涂成青色。没有镜像伙伴的孤立线
段不产生任何楔形，原样保留。

关键洞察
楔形的生成元（尖端）从未出现在画面上：必须先用镜像对称为斜线残迹配
对，再沿对角线外推相交才能定位它；孤立斜线是诱饵，直接把每段斜线都
当作楔形边界会在示例上多画或错画区域。
```

## 5. 相位印章

- 难度评审：达标
- 参考题目题号：20（5833af48）、13（5ad4f10b）、2（e78887d1）、10（9473c6fb）
- tags:
  - operation:印章覆盖, stamp
  - operation:循环移位, cyclic_shift
  - object:宏单元格模式, macro_cell_pattern
  - object:控制精灵体, control_sprite
  - relation:粗模板精细替换, coarse_to_fine_substitution
  - relation:扫描序, scan_order
  - condition:相位等于扫描序号, phase_equals_scan_rank
  - condition:长轴决定扫描, longer_axis_determines_scan

### docstring

```text
把粗掩码的每个填充格替换为控制精灵按该格扫描序号循环移相后的版本。

输入结构
背景上有两个分离的部分：一个小的粗掩码图案（若干填充格构成的形状），
以及一个独立摆放的 m×m 多色控制精灵。

规则
输出尺寸为粗掩码行数×m 行、列数×m 列。粗掩码的每个空格对应输出中
一个 m×m 背景块；每个填充格对应一个 m×m 块，其内容是控制精灵行循
环下移 k 行后的版本，k 等于该填充格在扫描序中的序号（从 0 计）。扫
描方向不固定：若粗掩码前景包围盒的高度不小于宽度则按行优先扫描，否
则按列优先扫描。

关键洞察
各填充块的内容乍看互不相同，实为同一精灵的不同循环相位；相位并非任
意，等于该格的扫描序号；而扫描究竟按行还是按列由掩码形状的长轴方向
决定——若某示例恰好只有一行填充格，会误以为是简单的从左到右传送带，
换轴示例会使该假设失配。
```

## 6. 换色旋转四联去噪

- 难度评审：达标偏上
- 参考题目题号：11（6150a2bd）、19（74dd1130）、3（da2b0fe3）、9（9b365c51）
- tags:
  - operation:旋转, rotate
  - operation:重涂色, recolor
  - object:分隔行列, separator_row_col
  - object:四象限画布, quadrant_canvas
  - relation:旋转拷贝对齐, rotational_copy_alignment
  - relation:颜色双射伪装, color_bijection_disguise
  - condition:多数表决恢复, majority_vote_recovery
  - condition:诱饵镜像假设, mirror_decoy

### docstring

```text
四个象限是同一图案经不同旋转与不同颜色双射伪装后的带噪拷贝，解开两
层伪装后按多数表决输出干净图案。

输入结构
网格被一条整行和一条整列的分隔线划成四个等大的正方形象限。四象限来
自同一基准图案：左上为原图；其余三个各自被旋转了 90、180 或 270 度
（哪个象限对应哪个角度不固定），并且每个象限还各自经过一套不同的颜
色一一映射重涂（左上为恒等映射）；此外每个象限有少量像素被杂色污染，
同一图案格位至多在一个象限中被污染。

规则
先为每个象限推断其相对左上的旋转角与颜色双射（以绝大多数格位的一致
性为准），再把三个象限反向旋转、反向映射回左上取向与左上配色，与左
上象限逐格对齐；每格取四个候选值中的多数色。输出去噪后的单象限图案
（左上取向、左上配色）。

关键洞察
四象限乍看是四幅颜色和方向都无关的图；常见的四象限镜像翻折假设在此
对不齐，必须改用旋转对齐。噪声在单个象限内无法识别，只有同时解开旋
转与色映射两层伪装，四份拷贝的逐格表决才能让污染像素现形。
```

## 7. 边缘直方图召唤图例精灵

- 难度评审：达标
- 参考题目题号：16（20fb2937）、20（5833af48）、6（ff28f65a）、15（2c0b0aff）
- tags:

  - operation:印章覆盖, stamp
  - operation:计数, counting
  - object:图例精灵, legend_sprite
  - object:投影条, projection_bar
  - object:分隔行, separator_row
  - relation:直方图即投影, histogram_as_projection
  - condition:投影唯一匹配, projection_unique_match

### docstring

```text
顶边与左边的灰色条是一只从未画出的图例精灵的列投影与行投影，据此选
中精灵并画回它的原位。

输入结构
一条实心分隔行把网格分成上下两部分。下部是图例，排列着若干颜色互
异、形状互异的小精灵。上部为主画布，除从顶行向下垂落的灰色竖条与从
最左列向右伸出的灰色横条外全为背景：第 c 列竖条的长度等于隐藏精灵
在该列的像素个数，第 r 行横条的长度等于隐藏精灵在该行的像素个数。

规则
把灰条读作某个图例精灵的逐列与逐行像素计数直方图；在图例中找到唯一

出精灵包围盒在主画布中的位置。输出与主画布同尺寸：清除全部灰条，在
推得的位置以精灵自身颜色画出该精灵，其余为背景；图例与分隔行不输出。

关键洞察
灰条不是要保留或移动的对象，而是一只从未画出的精灵的两个一维投影；
仅凭包围盒大小往往有多个图例候选，必须逐行逐列比对像素计数才能唯一
选中，再由投影条的位置反推精灵应当出现的地方。
```

## 8. 移位量由行首标记驱动的精灵传送带

- 难度评审：达标偏上
- 参考题目题号：2（e78887d1）、6（ff28f65a）、14（90f3ed37）
- tags:
  - operation:循环移位, cyclic_shift
  - operation:计数, counting
  - operation:外推, extrapolate
  - object:精灵网格, sprite_lattice
  - object:标记像素, marker_pixel
  - relation:列固定颜色, col_fixed_color
  - condition:移位量非常数, shift_amount_is_data
  - condition:标记数列自身循环, marker_sequence_cycles

### docstring

```text
每个精灵行相对上一行左移的格数由该行行首的标记像素个数给出，输出按
标记数列的下一项移位并按列着色的下一精灵行。

输入结构
主体是 3x3 精灵网格：精灵行之间、精灵列之间以整行整列背景分隔；忽
略颜色时，每个精灵行的掩码序列都是上一精灵行循环左移若干格的结果。
网格最左侧在每个精灵行的高度上另有一小段标记像素，其个数记录该行相
对上一行的左移格数（第一行没有标记）；每个精灵列在所有行中保持固定
颜色。

规则
读出各行的移位量数列，该数列本身按固定短周期循环；取数列的下一项作
为新一行的移位量，把最后一行的掩码序列循环左移该数，再按各精灵列的
固定颜色着色。输出这一新的 3 行精灵带，不含标记与分隔。

关键洞察
相邻行之间的移位量不是常数 1：直接套用参考式的等距移位在部分行上会
失配。必须把行首标记读作移位计数，并进一步发现这些计数自身构成循环
数列，两层规律都解开才能外推出下一行的形状。
```
