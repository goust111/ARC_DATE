## 1. 周期隐障下落

- 参考题目题号: 5、10、12
- tags:
  - operation:重力下落, gravity_drop
  - operation:补全, completion
  - object:周期点阵, periodic_lattice
  - object:遮挡幕布, occluding_veil
  - object:标记像素, marker_pixel
  - relation:同列对齐, same_col_align
  - condition:可见像素约束推断, infer_from_visible
  - condition:隐藏障碍定停点, hidden_obstacle_stop

### docstring

```text
先从可见灰点推断全网格周期障碍，再让顶部标记穿过遮挡幕布下落停靠。

输入结构
- 黑色背景上，灰色障碍像素按同一个二维周期排布于全网格，周期可由可见部分唯一推出。
- 若干黄色实心矩形幕布覆盖部分区域，幕布内的障碍点不可见。
- 顶行附近有若干红色标记像素，每列至多一个，且都位于该列全部障碍点位之上。

规则
- 由可见灰点推断唯一最小二维周期，在逻辑上补全幕布之下的障碍点位。
- 每个红色标记沿所在列竖直下落，停在该列第一个（含被幕布遮挡的）障碍点位上方一格；
  该列不存在障碍点位时落至底行。
- 落点位于黄色幕布内时，仅将该格改涂红色；其余黄色像素与可见灰点保持不变，
  被遮挡的障碍点位在输出中仍不显示。

关键洞察
- 黄色幕布对视线不透明、对运动透明：真正的地形是完整的周期点阵，
  列内看不到灰点不代表可以落到底，必须先补全再下落。
```

## 2. 视线继承链

- 参考题目题号: 6、9、12、13
- tags:
  - operation:射线延伸, ray_extend
  - operation:重涂色, recolor
  - object:矩形边框, rect_frame
  - object:控制像素, control_pixel
  - object:双格指针, domino_pointer
  - relation:视线对齐, sightline_align
  - relation:朝向对应边色, facing_side_color
  - condition:链式颜色继承, chained_color_inherit
  - condition:处理顺序决定结果, order_determines_result

### docstring

```text
框内每只双格指针沿视线取色，视线撞到别的指针时继承其解析后的最终色。

输入结构
- 网格外圈是一像素厚矩形边框，四条边四种不同颜色（均非蓝非灰），四角为中性灰角点。
- 框内为黑色背景，散布若干 1x2 双格指针，每只由一个灰色头部与一个蓝色尾部组成，
  尾部到头部的方向即指针朝向。
- 沿朝向的视线最终总落在边框或另一只指针上，指向关系不构成环。

规则
- 每只指针从头部沿朝向发射直线视线，取视线遇到的第一个非背景目标。
- 目标是边框时，指针的最终色为该边的颜色。
- 目标是另一只指针时，最终色等于那只指针解析完成后的最终色。
- 将每只指针的两格整体涂成其最终色；边框、角点与背景保持不变。

关键洞察
- 颜色不是由指针与边框的相对位置直接决定，而是沿视线链条自边框逐级传递；
  必须按依赖顺序先解析被指向者，再解析指向者。
```

## 3. 沉降版图展开

- 参考题目题号: 5、14
- tags:
  - operation:重力下落, gravity_drop
  - operation:印章覆盖, stamp_overlay
  - object:二值掩码, binary_mask
  - object:分隔面板, separator_panel
  - relation:克罗内克积, kronecker_product
  - condition:重力沉降, gravity_settling
  - condition:版图为沉降后态, layout_is_settled_state

### docstring

```text
左板像素先沉降成版图，再以右板图案作瓦片做克罗内克展开。

输入结构
- 一条通高的分隔色竖线把输入分为左右两板。
- 左板为黑色背景，其中悬浮若干彩色单像素，颜色可各不相同。
- 右板是一幅单色二值图案，图案画布即右板本身。

规则
- 让左板每个彩色像素沿所在列竖直下落，同列像素自底向上依次堆叠，
  得到沉降后的版图；该版图不出现在画面中。
- 输出高为左板高乘图案高、宽为左板宽乘图案宽的画布。
- 版图中每个被占格，以该像素的颜色绘制一份右板图案作为对应位置的瓦片；
  未被占格对应的瓦片为全黑块。

关键洞察
- 克罗内克积的外层布局既不是左板原样，也不在画面上任何位置，
  而是左板经过重力沉降后的未来状态。
```

## 4. 深度环轮转

- 参考题目题号: 4、20
- tags:
  - operation:循环移位, cyclic_shift
  - operation:重涂色, recolor
  - operation:重绘, redraw
  - object:矩形边框, rect_frame
  - relation:遮挡顺序, occlusion_order
  - relation:有序槽位, ordered_slots
  - condition:深度环定色置换, depth_cycle_sets_permutation

### docstring

```text
由交叠可见性恢复各框的深度顺序，并把每框颜色替换为深度环上的后继颜色重绘。

输入结构
- 黑色背景上若干一像素厚的轴对齐矩形框，一框一色，互相交叠。
- 交叠格点显示较上层框的颜色；每种颜色的可见像素仍足以给出其完整外接矩形。
- 由"谁盖住谁"构成的关系恰好把全部框排成唯一的一条自底向顶深度链。

规则
- 由每色可见像素的外接矩形恢复各框的完整周界。
- 在每处交叠点读取可见颜色，建立"被盖者指向覆盖者"的关系，求出唯一深度链。
- 将每个框重涂为深度链中其上方相邻框的颜色，最顶层框取最底层框的颜色。
- 按与输入完全相同的遮挡关系重绘全部框。

关键洞察
- 输出等价于对输入可见像素施加一个颜色置换，但该置换不是任意码表，
  而是由遮挡结构推出的深度环，且每个示例的置换各不相同。
```

## 5. 刻度隐形矩形奇偶互换

- 参考题目题号: 10、17、18
- tags:
  - operation:颜色互换, color_swap
  - object:网格边缘, grid_edge
  - object:标记像素, marker_pixel
  - object:隐形矩形, implicit_rectangle
  - relation:同色刻度配对, same_color_tick_pairing
  - relation:区域奇偶叠加, region_parity_overlay
  - condition:生成元定区域, generators_define_region
  - condition:奇数覆盖触发互换, odd_coverage_toggles

### docstring

```text
顶边与左边的同色刻度对围出从未画出的矩形，格内颜色按被矩形覆盖次数的奇偶决定是否成对互换。

输入结构
- 顶边与左边分布若干彩色刻度像素，每种刻度色恰在顶边出现两次、左边出现两次。
- 一种刻度色的两条列线与两条行线围出一个隐形矩形区域，矩形本身从不画出。
- 网格内部为黑色背景加散布的青、粉、黄、橙四色像素；多个隐形矩形可以交叠。

规则
- 按同色刻度配对，恢复每个隐形矩形覆盖的区域。
- 统计每格被多少个矩形区域覆盖。
- 覆盖次数为奇数的格，其颜色按 青互换粉、黄互换橙 成对互换，黑色保持不变。
- 覆盖偶数次（含零次）的格保持原样；刻度像素保持不变。

关键洞察
- 矩形只以边缘刻度的生成元形式存在，且多个矩形的作用按奇偶叠加抵消：
  "每个矩形内部都互换"的表面规律在交叠区失效。
```

## 6. 层级互换

- 参考题目题号: 8、10、14
- tags:
  - operation:印章覆盖, stamp_overlay
  - operation:重绘, redraw
  - object:二值掩码, binary_mask
  - object:重复瓦片, repeating_tile
  - relation:克罗内克积, kronecker_product
  - relation:层级互换, hierarchy_swap
  - condition:两层分解唯一, unique_two_level_factorization

### docstring

```text
识别输入的两层自相似结构，并交换内外两层重新展开。

输入结构
- 黑色背景上只有一种前景色。
- 前景整体呈两层结构：一个小的布局形的每个占位格处，放着同一个瓦片形的完整拷贝，
  布局形空位处为全黑块。
- 布局形与瓦片形形状不同，且该两层分解在此输入下唯一。

规则
- 找出瓦片形与布局形两个二值掩码。
- 输出与输入同尺寸：改以瓦片形作外层布局，在其每个占位格处放一份布局形的完整拷贝，
  空位处为全黑块。

关键洞察
- 输入是"布局在外、瓦片在内"的克罗内克结构，输出是同一对因子的内外互换；
  两者尺寸与前景像素总数完全相同，差别只在层级次序。
```
