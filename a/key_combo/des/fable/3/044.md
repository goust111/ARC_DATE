## 1. 蛇径周期修补

- tags:
  - operation:路径追踪, path_trace
  - operation:补全, completion
  - object:蛇形路径, snake_path
  - object:遮挡像素, occluder_pixel
  - relation:遍历顺序, traversal_order
  - condition:沿路径一维周期, period_along_path
- 参考题目: `7b5033c1`, `f823c43c`

### docstring

```text
沿蛇形路径的遍历顺序推断颜色的最小重复周期，把路径上被粉色遮挡的格子补回正确颜色。

输入结构
- 背景为最常见色；非背景像素构成一条无分支的4连通链，恰有两个端点。
- 沿链遍历时，各格颜色按某个最小周期重复；周期内部含有重复颜色，仅看局部邻居不足以定色。
- 链上若干格被粉色覆盖；粉色不属于周期序列。

规则
- 从任一端点沿链逐格编号；忽略粉色格，求使所有同余位置可见颜色一致的最小周期。
- 每个粉色格取其同余位置上可见格的颜色。
- 链外像素与背景保持不变；从两端出发的编号给出相同的修补结果。

关键洞察
- 颜色的规律不在行列坐标里，而在路径的一维遍历序中：把蛇"拉直"后它只是一条被遮挡的周期色带。
- 二维视角下的平铺或对称解释是诱饵，只有沿链读色才能让所有示例同时成立。
```

## 2. 换相补丁

- tags:
  - operation:裁剪, crop
  - operation:异常判别, anomaly_detect
  - object:周期瓦片, periodic_tile
  - object:矩形补丁, rect_patch
  - relation:相位错位, phase_shift
  - condition:换色诱饵, recolor_decoy
  - condition:对象由破缺定义, object_by_violation
- 参考题目: `f823c43c`, `e88171ec`, `a68b268e`

### docstring

```text
在全局周期图案中找出两块异常矩形，输出其中"错位"而非"换色"的那一块。

输入结构
- 整幅网格由一个最小矩形瓦片周期平铺而成，瓦片含至少三种颜色。
- 恰有两块互不重叠、都不小于一个瓦片的轴对齐矩形补丁偏离平铺：
  换色补丁保持瓦片结构不动，只把瓦片中数量相等的两种颜色互换；
  错位补丁的内容仍取自同一平铺，但整体平移了一个非零相位。
- 瓦片在任何平移下都不会映成自身的两色互换版本，两类破缺不会混同。

规则
- 由未受污染的大部分区域推断瓦片与全局相位。
- 定位两块与全局平铺不一致的矩形区域，逐一判别破缺类型：
  与全局逐格比对，只换颜色而纹理位置未动的是换色补丁；整体纹理错开的是错位补丁。
- 输出错位补丁边界框内的内容，按输入原样裁剪。

关键洞察
- 目标对象从未被画出，它由"周期在哪里失效"定义；而两种失效不同价——
  换色补丁在视觉上更扎眼，且被互换两色数量相等使颜色统计毫无破绽，只有逐位置的结构比对才能分辨；
  真正的答案是破坏了相位的那一块。
```

## 3. 隐轴四重奏

- tags:
  - operation:对称补全, symmetry_complete
  - operation:擦除, erase
  - object:稀疏标记, sparse_marker
  - relation:隐含双镜轴, hidden_biaxial
  - condition:轴由点集反推, axes_from_points
  - condition:有伴为真孤者为噪, partnered_true_lone_noise
- 参考题目: `60d73be6`, `aedd82e4`

### docstring

```text
反推出从未画出的行、列两条镜轴，把有镜像伙伴的标记补成完整四重组，把孤立标记当噪声擦除。

输入结构
- 背景网格上散布若干单像素彩色标记；任何镜轴都没有画出来。
- 存在唯一的一行与一列，使得大多数标记能通过跨行轴、跨列轴或跨双轴的反射两两同色配对；
  其余少数标记在该轴系下没有任何同色伙伴。
- 标记不落在两条轴上；反射落到网格外的位置按裁剪处理。

规则
- 找出使同色配对数最大的那对行轴与列轴（输入保证唯一）。
- 凡在该轴系下拥有至少一个同色反射伙伴的标记，补齐它的全部四个反射位置（同色，越界裁剪）。
- 没有任何伙伴的标记全部擦除为背景；输出中不画轴。

关键洞察
- 镜轴是隐含的生成元，只能从点的构型中反推。
- "被至少一个镜像证实"是真图案与噪声的分界——先入为主的"把所有点都四重镜像"
  会被孤立噪点证伪，而噪点的存在又反过来干扰轴的反推，两层必须同时解开。
```

## 4. 反相分形

- tags:
  - operation:像素放大, pixel_upscale
  - operation:印章覆盖, stamp_overlay
  - operation:镜像, mirror
  - object:双色精灵, two_color_sprite
  - relation:自身为模板, self_as_stencil
  - condition:颜色编码取向与配色, color_encodes_pose_palette
- 参考题目: `007bbfb7`, `fd4b2b02`

### docstring

```text
把双色精灵分形展开：A色格印入原样副本，B色格印入左右镜像且两色互换的"反相"副本。

输入结构
- 输入是 h×w 的小精灵，含黑背景与恰好两种前景色 A、B，A 严格占多数。
- 精灵掩码左右不对称。
- 输出为 h²×w²，按 h×w 分块，与输入格一一对应。

规则
- 输入格为黑：对应块保持全黑。
- 输入格为 A 色：把精灵原样印入对应块。
- 输入格为 B 色：把精灵左右镜像，并把副本内的 A、B 两色互换后印入对应块。

关键洞察
- 精灵同时是模板与印章，而它自己的两种颜色是一份姿态指令表：
  少数色标记的块被同时施加了几何反射与色彩反相，两个"反"必须一起被发现——
  只发现镜像或只发现换色都无法同时解释所有块。
```

## 5. 镜像接力

- tags:
  - operation:镜像, reflect
  - operation:重涂色, recolor
  - object:精灵体, sprite
  - object:指示像素, indicator_pixel
  - relation:邻接接力, adjacency_relay
  - condition:递归应用单步规则, recursive_single_rule
- 参考题目: `b775ac94`, `aedd82e4`, `c9680e90`

### docstring

```text
让精灵沿一串指示像素接力镜像：每一步跨过贴着它的指示点翻一次身、换一次色，直到无点可接。

输入结构
- 黑背景上有一个主色精灵和若干颜色互不相同的单像素指示点。
- 恰有一个指示点与精灵的边或角相邻。
- 输入保证每一步生成的新副本都恰与一个尚未使用的指示点相邻，
  链的最后一个副本不与任何剩余指示点相邻。

规则
- 把精灵跨相邻指示点镜像：指示点在边侧则跨该边轴翻折，在角上则跨该角点做点反射；
  副本整体重涂为该指示点的颜色。
- 以最新副本为当前对象，重复上述步骤，直到无可用的相邻指示点。
- 输出保留原精灵与全部副本；所有被使用的指示点从画面上消失。

关键洞察
- 单步"跨指示点镜像并取其色"并不是全部规则，它必须被递归地施加在自己产出的副本上；
  接力顺序不由颜色决定，而由几何邻接一环扣一环地涌现——漏推一步或用错当前对象，
  后续所有副本的位置与姿态都会连锁出错。
```

## 6. 层序反演

- tags:
  - operation:透明叠加, transparent_overlay
  - operation:补全, completion
  - object:象限区, quadrant
  - object:分隔十字, separator_cross
  - object:同形精灵, same_shape_sprite
  - relation:遮挡定序, occlusion_orders_layers
  - condition:缺损即证据, damage_as_evidence
  - condition:输出反转层序, reversed_stacking
- 参考题目: `a68b268e`, `60b61512`

### docstring

```text
四个象限各摆着同一形状精灵的一份"被上层啃缺"的残片，反推出原始叠放顺序，再按相反的顺序重新叠放输出。

输入结构
- 一行一列同色分隔线组成十字，把网格分成四个共享同一坐标系的等大区域。
- 每个区域含一个单色精灵；四个精灵本是同一形状、各在自己的锚点位置，
  但每层的像素被"虚拟原始叠放"中位于其上方的各层完整形状啃掉了交叠部分：
  恰有一层完好无缺（原顶层），其余层残缺程度随层深递增。
- 输入保证层序为全序且唯一可辨，每个残片与完整形状的对位唯一。

规则
- 找出完好无缺的那层：它既是公共完整形状的字典，也是原顶层。
- 用该形状把每个残片补全到各自锚点位置。
- 根据"谁的缺口恰好落在谁的完整形状之下"恢复整套原始层序。
- 输出一个区域大小的网格：把四个补全后的精灵按与原始层序相反的顺序叠放
  （原底层现在在最上面），逐像素取最上层非背景色；十字不进入输出。

关键洞察
- 原始的叠放从未被画出——它只存在于各层残缺的形状里；
  完好层既是形状字典又是顶层身份证明，缺口与上层形状的吻合是唯一的排序证据；
  而答案还要把推出的顺序整个翻转过来，输入里最风光的完好层在输出里被压到最底下。
```

## 7. 缺件并集

- tags:
  - operation:补全, completion
  - operation:重涂色, recolor
  - object:精灵掩码, sprite_mask
  - relation:像素并集, pixel_union
  - condition:真子集判缺件, strict_subset_of_union
  - condition:缺口补入异色, fill_gap_diff_color
- 参考题目: `fea12743`, `60b61512`

### docstring

```text
在多块精灵掩码中找出"两块之并的残缺版"，用橙色补上它缺失的像素。

输入结构
- 黑背景上排列着若干同色、等大的矩形精灵区，由空行空列分隔。
- 恰有一组三元关系成立：某目标区的掩码是另外两块操作数掩码之并的真子集，
  且两块操作数各自贡献了并集中至少一个独有像素。
- 输入保证该三元组唯一，其余精灵区与任何组合都不构成上述关系。

规则
- 找出操作数 A、B 与残缺目标 C，满足 C 真包含于 A∪B。
- 在 C 所在区内，把 A∪B 有而 C 没有的像素位置涂成橙色；C 已有像素保持原色。
- 其余区域与像素全部不变。

关键洞察
- 三块掩码的关系不是相等而是"差一点相等"：目标是并集的残缺版。
- 发现这一关系需要在所有区之间两两取并再与其余区比对，而缺口像素既是
  该关系成立的证据，又恰好是要补进答案的内容——找到关系的那一刻答案同时显影。
```
