## 1. 遮挡快照重建与外推

- tags:
  - operation:外推, extrapolate
  - operation:叠合重建, union_reconstruction
  - operation:印章覆盖, stamp_overlay
  - object:帧序列, frame_sequence
  - object:遮挡带, occluder_band
  - object:部分掩码, partial_mask
  - relation:等间距排列, equal_spacing
  - condition:多帧并集成形, multi_frame_union
- 参考题目题号: 11 (ba1aa698)、19 (d6542281)、10 (35ab12c3)

### docstring

```text
一个精灵的若干等间距运动快照被一条竖直遮挡带各遮去不同部分，需跨帧并集重建完整形状，并在下一位置补画完整的新帧。

输入结构
- 黑色背景画布上有一条竖直的灰色遮挡带（若干连续整列）。
- 一个多色精灵沿固定方向匀速运动，画布上同时画出它的若干等间距快照。
- 凡落入遮挡带内的精灵像素被带色覆盖而不可见；不同快照被遮住的部分不同，
  且没有任何一个快照是完整的。

规则
- 依据快照之间的等间距对齐关系，把各快照的可见部分按位置叠合，
  拼出完整的精灵形状。
- 沿运动方向按同一间距外推一步，在下一位置完整印下精灵
  （该位置整体位于遮挡带之外）。
- 原有快照与遮挡带保持原样，被遮部分不补画。

关键洞察
- 参与规则的对象从未被完整画出：完整形状只存在于多帧可见部分的并集之中。
- 解题需要同时发现运动节奏与跨帧拼合两层结构，缺一不可——
  只做外推会画出残缺的精灵，只做拼合则不知道画在哪里。
```

## 2. 内伤马达

- tags:
  - operation:平移, translate
  - operation:计数, counting
  - operation:修复重涂, repair_recolor
  - object:精灵体, sprite
  - object:损伤像素, damage_pixel
  - relation:偏向定方向, offset_side_sets_direction
  - condition:点数定步长, count_sets_distance
  - condition:去噪诱饵, denoise_decoy
- 参考题目题号: 4 (d282b262)、3 (cb2d8a2c)、20 (794b24be)

### docstring

```text
把每个精灵内部的红色"损伤"像素读作马达——损伤偏向的反方向是运动方向、损伤个数是步数；精灵平移后损伤被修复成本体色。

输入结构
- 黑背景上散布若干单色刚性精灵。
- 每个精灵内部有少量红色像素替换了本体色，红像素全部偏在该精灵形心的
  同一侧（上／下／左／右之一）。
- 红色不是任何精灵的本体色，画面中不存在其它红色。

规则
- 对每个精灵，判定红像素簇相对精灵形心的偏向，精灵沿该偏向的反方向
  整体平移，步数恰等于红像素个数。
- 平移后的精灵以完整纯本体色绘出（红像素处被修复），原位置清空为背景。
- 各精灵的路径与终点互不冲突；部分精灵最终停在半空，
  不与任何边界或物体接触。

关键洞察
- 红像素既不是要去除的噪声，也不是要保留的图案，而是双通道指令：
  位置偏向给出方向、数量给出距离。
- 输出精灵是"修复后再喷射"的结果——仅做去噪不移动、或按碰撞滑动到边界，
  都无法解释全部示例。
```

## 3. 连锁锚定滑动

- tags:
  - operation:滑动, slide
  - operation:擦除, erase
  - operation:依赖排序, dependency_ordering
  - object:矩形体, rectangular_body
  - object:连接杆, connector_stem
  - object:锚定物, anchor_object
  - relation:碰撞阻挡, collision_blocking
  - relation:动态依赖, dynamic_dependency
  - condition:连锁次序, cascade_order
- 参考题目题号: 15 (98cf29f8)、8 (3490cc26)

### docstring

```text
以唯一固定锚块为起点，各"矩形体+直杆"物体按动态依赖次序依次沿杆方向滑动，直到贴上已固定的块；先落位者成为后来者的锚。

输入结构
- 黑背景上有一个唯一的实心矩形锚块（独有颜色）。
- 另有若干颜色互异的复合物体，每个由一个实心矩形体和一条指明方向的
  一格宽直杆组成。
- 初始时恰有一个物体沿其杆方向的滑动线路上能碰到锚块；
  其余物体的滑动线路上暂时空无一物，只有等别的物体落位后才有依靠。

规则
- 反复寻找沿杆方向滑动后能贴上"当前已固定块"的物体：擦除其杆，
  将其矩形体沿杆方向滑动，直到与该固定块相贴为止。
- 刚落位的矩形体立即成为新的固定块，供后续物体停靠。
- 重复上述步骤直到所有物体落位；锚块保持不动。

关键洞察
- 杆只给出方向，不给出距离——滑动的终点由"路上有谁已经就位"决定。
- 滑动线路暂时悬空不代表物体无效：处理次序由动态可停靠性决定，
  必须按拓扑顺序推演整场连锁反应，一步顺序错误则全局皆错，
  不存在逐物体独立求解的捷径。
```

## 4. 隐形矩形覆盖奇偶

- tags:
  - operation:生成元重建, generator_reconstruction
  - operation:奇偶叠加, parity_overlay
  - object:角标记, corner_marker
  - object:隐形矩形, implied_rectangle
  - relation:重叠, overlap
  - condition:覆盖奇偶定色, coverage_parity_sets_color
- 参考题目题号: 9 (7837ac64)、5 (868de0fa)、19 (d6542281)、17 (95990924)

### docstring

```text
由四个同色角点暗示的实心矩形从未被画出；输出把被奇数个隐形矩形覆盖的格子涂绿、其余涂黑。

输入结构
- 黑背景上散布若干组角点：每组四个同色像素构成一个轴对齐矩形的
  四个顶点，不同组颜色不同。
- 矩形本体从未画出；各暗示矩形可以任意交叠、嵌套。

规则
- 由每组四角复原其实心矩形（含边界）。
- 统计每个格子被多少个矩形覆盖：被奇数个覆盖的格子输出绿色，
  其余格子（包括被偶数个、不少于两个矩形覆盖者）输出黑色。
- 原角点颜色不保留。

关键洞察
- 两个矩形的交叠部分会相互抵消回背景——答案是各隐形矩形的异或叠加，
  而不是并集，也不是逐个填充。
- 单矩形的局部看起来像简单的"补全矩形"，交叠区域才暴露真正的规则；
  参与规则的对象只以生成元（角点）的形式存在。
```

## 5. 镜面反射带折返

- tags:
  - operation:镜像, mirror
  - operation:折返反射, fold_reflection
  - object:镜柱, mirror_line
  - object:挡墙, blocking_wall
  - relation:视线, line_of_sight
  - condition:越墙深度变回退, overshoot_becomes_rebound
- 参考题目题号: 13 (496994bd)、8 (3490cc26)、3 (cb2d8a2c)

### docstring

```text
左侧图案关于灰色镜柱反射到右侧，途中被挡墙截住的像素再关于挡墙折返一次弹回。

输入结构
- 一条完整的灰色竖直镜柱把画布分为左右两侧。
- 左侧有若干彩色像素图案。
- 右侧只有若干竖直的枣红色挡墙线段与背景；不同行的墙位置可以不同，
  也可以无墙。

规则
- 每个左侧彩色像素先映射到关于镜柱对称的右侧位置。
- 若该行在镜柱与目标位置之间（含目标位置）存在挡墙格，
  则像素改为关于该挡墙格再反射一次：越过墙的深度变成墙前的回退距离。
- 左侧原图案、镜柱与挡墙全部保持不变；折返后的落点保证位于
  镜柱与挡墙之间且互不冲突。

关键洞察
- 这不是一次简单镜像——墙不会吞掉像素，而是把它弹回来，
  等价于光线的二次反射。
- 同一图形的不同行因墙位不同而发生不同深度的折叠，
  输出图案是逐行变形的镜像，无法用整体变换一步得到。
```

## 6. 分形自相似不动点检索

- tags:
  - operation:压缩, compress
  - operation:匹配, match
  - operation:筛选, filtering
  - object:粗粒度块, coarse_block
  - object:标记像素, marker_pixel
  - relation:自相似, self_similarity
  - relation:阵列排布, array_layout
  - condition:压缩码即钥匙, code_is_its_own_key
- 参考题目题号: 1 (e57337a4)、18 (da6e95e5)、9 (7837ac64)

### docstring

```text
在多个两色大图案中找出唯一"压缩后仍是自己"的分形图案，输出它的3×3粗码。

输入结构
- 画布上散布若干彼此分离的 9×9 两色图案，每个由主导填充色与
  稀疏标记色构成（各图案配色互不相同），都可均分为 3×3 个 3×3 粗块。
- 画布上不存在任何显式的比对钥匙。

规则
- 把每个图案压缩为 3×3 粗码：粗块内含标记像素记为标记位，
  否则记为填充位。
- 检查每个图案是否自相似：它的每个标记位粗块，其内部 3×3 标记分布
  必须恰好与整体 3×3 粗码图样相同；填充位粗块内部必须纯为填充色。
- 恰有一个图案满足自相似；以该图案自身的两种颜色输出其 3×3 粗码。

关键洞察
- 题面上没有钥匙——钥匙就是图案自己：要找的是"放大一层后仍等于
  自身粗码"的分形不动点。
- 压缩在这里不是最终答案的直接来源，而是自指验证的工具；
  其余图案的粗块内容与整体码不一致，仅是干扰项。
```

## 7. 虚线围栏封闭性

- tags:
  - operation:洪泛填充, flood_fill
  - operation:周期归纳, period_induction
  - object:虚线围栏, dashed_fence
  - object:封闭区域, enclosed_region
  - relation:周期一致, periodic_consistency
  - condition:破律缺口为门, aperiodic_gap_is_door
- 参考题目题号: 5 (868de0fa)、11 (ba1aa698)、8 (3490cc26)

### docstring

```text
按固定周期画成虚线的围栏视为封闭墙：真正封闭的栏内涂成围栏色；周期被打破处是门，带门的围栏保持不变。

输入结构
- 黑背景上有若干单色矩形围栏轮廓，轮廓不是实线，而是沿边界按固定周期
  循环的虚线（例如"两格墙一格空"）。
- 某些围栏在某处的缺失长度超出该周期应有的空隙——那是一扇真正的门。
- 每个任务中封闭围栏与带门围栏同时存在；不同围栏的虚线周期可以不同。

规则
- 对每个围栏，沿边界归纳出它的虚线周期；符合周期的空隙视为墙的一部分。
- 若边界上所有空隙都符合周期，则该围栏封闭：把内部区域全部涂成
  围栏颜色（虚线笔画原样保留）。
- 若存在超出周期的缺口（门），该围栏整体保持不变。

关键洞察
- 填充与否不由像素级连通性决定——按像素看，每个围栏都是"漏"的。
- 必须先归纳出每条围栏自己的虚线节律，才能区分"结构性空隙"与
  "真正的门"；把所有缺口一视同仁会导致全部围栏都无法封闭。
```
