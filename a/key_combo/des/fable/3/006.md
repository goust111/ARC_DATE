## 1. 计数即坐标

- tags:
  - operation:计数, counting
  - operation:平铺, tiling
  - object:离散对象, scattered_objects
  - relation:对角索引映射, diag_index_map
  - condition:连通块数即索引, component_count_is_index
- 参考题目：9caf5b84、539a4f51

### docstring

```text
统计每种前景色的四连通连通块个数，个数为 k 的颜色占据输出方表中对角索引 k-1 的 L 形套框。

输入结构：
- 黑色背景上散布若干种前景色的对象，同一颜色可能是一个大块，也可能是多个小块。
- 各前景色的连通块个数恰好取遍 1 到 N（N 为颜色种数），无并列。
- 颜色的像素总数排序与连通块个数排序在部分示例中故意不一致。

规则：
- 对每种前景色数出四连通连通块的个数 k。
- 输出为 N×N 方表：格 (r,c)（从 0 计）取连通块个数为 max(r,c)+1 的那种颜色。
- 即个数为 1 的颜色只占左上角一格，个数为 N 的颜色构成最外圈 L 形套框。

关键洞察：
- 输入的空间布局与像素多少全是幌子；真正的键是"这类颜色碎成了几块"，
  块数直接充当输出中的对角坐标。按像素频率排序在部分示例上会给出错误的层序。
```

## 2. 破缺处即锚点

- tags:
  - operation:印章放置, stamp
  - operation:对称检测, symmetry_detection
  - object:精灵体, sprite
  - object:锚点标记, anchor_marker
  - object:边框矩形, bordered_rectangle
  - relation:颜色匹配, color_matching
  - condition:破坏对称的像素为锚, symmetry_breaking_anchor
- 参考题目：a251c730、ce039d91、7468f01a

### docstring

```text
每个精灵中唯一破坏其左右镜像对称的像素是它的锚点，将精灵平移使锚点压在目标框内同色标记上盖章。

输入结构：
- 画面含两个带边框的矩形区：源区内有若干多色精灵，目标区内有若干孤立的单像素标记。
- 每个精灵去掉某一个像素后恰好左右镜像对称，且这样的像素唯一；
  该像素的颜色与目标区某个标记的颜色一一对应。
- 锚点的颜色在精灵中不止出现一次，且部分精灵中最稀有的颜色故意不在破缺位置上。

规则：
- 对每个精灵找出唯一的像素，使得去掉它后剩余部分左右镜像对称；该像素即锚点。
- 将精灵整体平移，使锚点与目标区中同色标记重合，连同锚点一起盖下。
- 输出为目标矩形区，盖章前清除其内部原有的标记像素。

关键洞察：
- 锚点既不是"最稀有的颜色"，也不是"与标记同色的那个像素"（同色像素不止一个），
  而是"谁破坏了对称"；用任何一条捷径对位都会在部分精灵上盖错位置。
```

## 3. 双端赛跑

- tags:
  - operation:滑动, slide
  - operation:重涂色, recolor
  - object:路径, path
  - object:端点标记, endpoint_marker
  - relation:尺寸即速度, size_is_speed
  - condition:同时到达变灰, tie_becomes_grey
- 参考题目：182e5d0f、22208ba4、f35d900a

### docstring

```text
路径两端的标记以各自像素数为速度相向奔跑，路径每格染成先到者的颜色，同时到达的格子染灰。

输入结构：
- 黑色背景上有若干条互不接触的无分支单色路径。
- 每条路径两端各贴着一个标记，两端颜色不同；每个标记由 1 至 3 个同色像素组成。

规则：
- 对路径上任一格，取它沿路径到两端的步数，各自除以对应端标记的像素数。
- 商小的一端赢得该格，格子染成该端标记的颜色；两商相等的格子染成灰色。
- 两端的标记从画面上抹去，路径的线形保持不变。

关键洞察：
- 分界处不在路径中点，而在按两端标记大小之比划分的位置；
  速度就藏在标记的像素数里（首个示例两端等大，会诱导"取中点"的错误假设），
  恰好同刻到达的格子用灰色封线。
```

## 4. 穿堂而过

- tags:
  - operation:滑动, slide
  - operation:放置, place
  - object:空心矩形, hollow_rectangle
  - object:实心方块, solid_square
  - relation:开口链式路由, opening_chain_routing
  - condition:死胡同才落脚, dead_end_settles
- 参考题目：a680ac02、182e5d0f、22208ba4

### docstring

```text
实心方块沿直线滑行，能进就进、有后门就穿，直到落进沿途第一间没有出口的死胡同房间；进不去就抵墙停下。

输入结构：
- 黑色背景上有若干空心矩形框，每个框的墙上有一个或两个正对的开口。
- 另有若干实心方块，各自沿其所在行带或列带的一个方向滑动，路径上可能依次排着多个框。

规则：
- 方块滑动中遇到框时依次检验：若迎面墙上没有开口、或内腔的高宽容不下方块，
  方块紧贴该框外墙停下；若迎面墙有开口且容得下，方块穿门进入。
- 进入后若对面墙上还有一个开口，方块从后门穿出继续滑行，接着检验下一个框；
  若没有后门，方块在该内腔中居中落脚。
- 没有收留任何方块的框保持原样。

关键洞察：
- 方块的归宿不是"最近的能装下它的框"，而是沿途第一间"进得去且出不去"的死胡同；
  有后门的框只是走廊。必须把方块看作在一串房间中被逐间路由，才能预测它最终停在哪。
```

## 5. 微缩装修图

- tags:
  - operation:填充, fill
  - operation:缩放, scaling
  - object:分区区域, partitioned_region
  - object:同心精灵, concentric_sprite
  - relation:层序与层厚的放大, layer_sequence_scaled
  - condition:序列用尽即循环, cyclic_when_exhausted
- 参考题目：13e47133、458e3a53、639f5a19

### docstring

```text
每个分区中的小同心精灵是该分区的染色蓝图：由外向内读出它的层色与层厚，按同样的节奏给整个分区画同心色带。

输入结构：
- 网格被通高通宽的分隔线划成若干矩形分区，每个分区底色单一。
- 每个分区内部有一个小的同心方形精灵，各层颜色互不相同，层厚不必为一
 （例如外层厚 1、中层厚 2、中心厚 1）。
- 精灵在分区中的位置任意。

规则：
- 由外向内读出精灵的（颜色，厚度）层序列。
- 从分区边界向内按切比雪夫距离画同心带：先用首层颜色画其厚度那么多圈，
  再换下一层，序列用尽后从头循环，直至填满分区。
- 精灵被覆盖消失，分隔线保持不变。

关键洞察：
- 小精灵不是要保留的对象，而是整个房间的微缩装修图；它的位置无关紧要，
  层色与层厚才是被放大执行的指令——只抄颜色不抄厚度、或不循环续画，都会失败。
```

## 6. 字形自证其变换

- tags:
  - operation:符号解码, symbol_decoding
  - operation:镜像, mirror
  - operation:旋转, rotate
  - object:符号掩码, symbol_mask
  - object:精灵体, sprite
  - relation:对称性即指令, symmetry_is_instruction
  - condition:测试字形未见过, unseen_glyph
- 参考题目：17cae0c1、7468f01a、2dee498d

### docstring

```text
灰色指令字形自身唯一的非平凡对称就是要施加给彩色精灵的变换，输出变换后的精灵。

输入结构：
- 画面一角是一个黑灰二值的指令字形（如 4×4），其余部分是一个多色精灵。
- 每个字形恰好具有一种非平凡自对称：左右镜像、上下镜像或 180° 旋转之一。
- 精灵在三种候选变换下的结果互不相同，保证答案可辨识。
- 测试输入中的字形形状从未在训练示例中出现过。

规则：
- 检验字形在左右镜像、上下镜像、180° 旋转下哪一种保持自身不变（有且仅有一种）。
- 对彩色精灵施加这一变换。
- 输出为变换后精灵的紧致裁剪，字形不出现在输出中。

关键洞察：
- 字形不是查表用的代号，而是自带说明书：它对哪种操作保持不变，
  就对精灵执行哪种操作；把训练对里的字形当码表死记，在测试的新字形上必然失效。
```

## 7. 堵口连锁

- tags:
  - operation:填充, fill
  - operation:连线, draw_line
  - object:轮廓线, outline
  - object:封闭腔体, enclosed_cavity
  - relation:喷射堵塞因果链, jet_plug_causal_chain
  - condition:不动点定命运, fixpoint_decides_fate
- 参考题目：22168020、8b7bacbf、f35d900a

### docstring

```text
仍在喷射的破损轮廓会把正对的其他破口一格堵住，被堵住者变为封闭轮廓填满内腔且不再喷射，连锁传导直至稳定。

输入结构：
- 单色背景上有若干互不接触的单色轮廓图形。
- 有的轮廓完全封闭；有的在某段笔直的墙上恰好缺一格（破口）。
- 破口间的堵塞关系保证无循环，答案唯一。

规则：
- 完全封闭的轮廓：内腔全部涂成轮廓色。
- 破损轮廓从破口沿墙面外法线方向喷出本色直线，延伸到碰上其他图形或网格边缘为止。
- 若某条喷射线恰好正中另一轮廓的破口，该破口被一格喷射色堵住：
  这个轮廓从此按封闭轮廓处理（内腔填自身色），并且它自己不再喷射。
- 反复应用上述堵塞传导直至稳定：被堵住的轮廓收回自己的喷射线，
  可能使原本会被它堵住的下游轮廓恢复喷射。

关键洞察：
- 每个轮廓的命运不由自身形状单独决定，而由喷射-堵塞因果链的不动点决定；
  一个破口被堵住，不仅救活了这间容器，还抽走了它的喷射线，让下游的判定整体翻转。
  逐个轮廓孤立判断"封闭即填充"在存在连锁的示例上必然出错。
```
