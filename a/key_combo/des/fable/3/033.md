## 1. 坠落后求叠

- 参考题目题号：1（6430c8c4）、3（8e301a54）
- tags:
  - operation:滑动, slide
  - operation:布尔运算, boolean_op
  - object:连通分量, connected_component
  - object:分隔线, divider_line
  - relation:面积决定位移, area_determines_displacement
  - condition:坠落终态求交, post_fall_intersection

### docstring

```text
让上半区的每个对象按自身面积下坠后，与下半区掩码逐格比对，只保留两者同时占据的格。

输入结构
- 网格由一条整行分隔线分成上下两个等高矩形区。
- 上半区：背景上散布若干互不相触的4连通单色对象。
- 下半区：单一前景色构成一个掩码图形。

规则
- 上半区每个对象在其自身区域内竖直下坠，位移行数等于该对象的像素数，越过上半区底边的像素被裁掉。
- 移除分隔线，将下坠后的上半区与下半区逐格对齐。
- 输出与单个半区同形：两者都是前景的格涂红，其余为背景。

关键洞察
- 直接对齐两个半区做交集在个别示例中貌似成立（诱饵），但普适规则要求先按"面积=下坠行数"移动上半区对象；交集是对坠落终态而非原始画面进行的。
```

## 2. 破缺点印章

- 参考题目题号：5（cce03e0d）、18（72ca375d）
- tags:
  - operation:印章覆盖, stamp_overlay
  - operation:对称检测, symmetry_detection
  - object:破缺像素, breach_pixel
  - object:输入图案, input_pattern
  - relation:格位映射, cell_block_mapping
  - condition:对称破缺定控制格, symmetry_breach_as_control
  - condition:修复图案作印章, repaired_pattern_stamp

### docstring

```text
找出破坏图案镜像对称的少数像素，在放大画布上以修复后的对称图案对这些破缺位置做递归印章。

输入结构
- 小网格上有一个多色图案，该图案关于某条竖直或水平轴几乎镜像对称。
- 少数几个有色像素违反该对称：它们的镜像位置是背景。
- 对称轴是唯一去掉少数像素后能使图案完全镜像对称的轴。

规则
- 确定对称轴，把破缺像素（镜像位置为背景的有色像素）抹为背景，得到完全对称的修复图案。
- 输出画布的宏格阵列与输入同形，每个宏格与输入等大。
- 每个破缺像素的位置对应一个宏格，该宏格内印上一份修复图案；其余宏格全为背景。

关键洞察
- 控制格不是由某种固定颜色标出的，而是由"违反整体对称"这一性质选出的；且被印章的内容是修复后的图案，不是原输入。
```

## 3. 形借色移

- 参考题目题号：6（ad38a9d0）、10（dbff022c）、16（3a25b0d8）
- tags:
  - operation:填充, fill
  - operation:旋转匹配, rotation_matching
  - object:空心精灵体, hollow_sprite
  - object:孔洞, hole
  - relation:形状相同, same_shape
  - condition:已解实例作隐式图例, solved_instance_as_legend
  - condition:变换转嫁内容, transform_carried_to_content

### docstring

```text
画面里已完成的空心体是隐式图例；把每个空孔按形状匹配到某个已填孔洞，并把使两形状重合的那个旋转/翻转同样施加到孔内的多色图案上，再搬入空孔。

输入结构
- 背景上散布若干同一边框色的空心精灵体，各含一个不接触画布边界的封闭孔洞。
- 孔洞形状均无旋转/翻转对称。
- 部分孔洞已被一个多色小图案填满，其余孔洞为背景。
- 每个空孔的形状经唯一一种旋转/翻转后与某个已填孔洞重合；已填孔洞形状两两不同，且存在面积相同而形状不同的孔洞作干扰。

规则
- 对每个空孔，找到形状匹配的已填孔洞，求出使已填孔洞形状变为空孔形状的唯一刚体变换（旋转/翻转）。
- 把已填孔洞内的多色图案施加同一变换后整块搬入空孔。
- 已填精灵体保持不变，输出同尺寸。

关键洞察
- 网格里没有独立图例，已完成实例本身就是图例；且匹配只给出"配对"，真正的答案还要求把配对所依赖的几何变换转嫁到内容图案上——孔形无对称保证该变换唯一，图案朝向是否正确即是否找到了正确变换的证据。
```

## 4. 齐全者去，缺一者补

- 参考题目题号：7（d59b0160）、10（dbff022c）
- tags:
  - operation:擦除, erase
  - operation:填充, fill
  - object:图例区域, legend_region
  - object:连通分量, connected_component
  - object:封闭区域, enclosed_region
  - condition:包含全部目标色, contains_all_target_colors
  - relation:缺失色定填色, missing_color_determines_fill

### docstring

```text
以角落图例为标准配色，删去颜色齐全的对象，给恰缺一色的对象把孔洞补成缺失色。

输入结构
- 左上角有一个带边框的小图例区，内部列出一组目标颜色。
- 背景上散布若干多色4连通对象；部分对象内部有一个封闭的背景孔洞。

规则
- 读出图例内的目标色集合。
- 含有全部目标色的对象整体擦成背景。
- 恰好缺少一种目标色的对象，将其内部孔洞填成那种缺失的颜色。
- 其余对象与图例保持不变，输出同尺寸。

关键洞察
- 图例不是单一过滤器而是"应有配色清单"：同一份清单同时驱动两种相反的操作——齐全者消失、缺一者被补全；孔洞的存在为补色提供落点。
```

## 5. 限程磁吸

- 参考题目题号：3（8e301a54）、9（b548a754）
- tags:
  - operation:滑动, slide
  - operation:计数, counting
  - object:连通分量, connected_component
  - object:标记点, marker_pixel
  - relation:面积上限位移, area_caps_displacement
  - condition:接触即停, stop_on_contact
  - condition:连锁阻挡, chained_blocking

### docstring

```text
各对象朝唯一标记滑动，每个至多滑动等于自身面积的格数，且被前方已停对象或标记挡住时提前停下。

输入结构
- 背景网格上有一个孤立标记像素和若干单色4连通对象。
- 所有对象位于标记同一侧，且沿同一直线方向排列。

规则
- 按到标记的距离由近到远逐个处理。
- 每个对象沿该方向朝标记滑动，滑动格数取"自身像素数"与"滑到与障碍相邻所需格数"的较小值；障碍指标记像素或先前已停稳的对象。
- 标记保留在原位，输出同尺寸。

关键洞察
- 既不是纯重力堆叠也不是纯"面积=位移"：每个对象取两者中先触发的一个，且前面对象的停点会连锁改变后面对象的可行滑程（诱饵：只看堆满的示例像重力堆叠，只看稀疏的示例像面积位移）。
```

## 6. 中心对镜印章

- 参考题目题号：8（e9c9d9a1）、13（fb791726）、14（c64f1187）
- tags:
  - operation:印章覆盖, stamp_overlay
  - operation:旋转, rotate
  - object:图例模板, legend_template
  - object:分隔线网格, separator_grid
  - object:控制像素, control_pixel
  - relation:中心点对称格位, center_symmetric_cell
  - condition:位置与朝向同变换, position_orientation_cotransform

### docstring

```text
表格里每个彩色控制点把自己颜色的图例模板旋转180度后，印到关于表格中心对称的那个单元格里。

输入结构
- 顶部图例：若干彩色标记各自紧邻一个用统一墨色画出的小模板；模板均不具180度旋转对称。
- 下方是被分隔线划成奇数×奇数阵列的表格，部分单元格内含一个彩色控制像素，其余单元格为空。

规则
- 读图例得到颜色→模板形状的对照。
- 清空所有控制像素；对每个控制像素，找到其单元格关于表格中心单元格的点对称单元格，在那里以该控制像素的颜色印上对应模板，且模板先旋转180度再落印。
- 输出为去掉图例后的表格区域，分隔线保持不变。

关键洞察
- 模板既不印在控制点所在格，也不保持原朝向；宏格位置与微观朝向做的是同一个点对称变换（诱饵：若示例中恰有中心格控制点或近似对称模板，会误以为就地印章或只翻位置不翻朝向）。
```

## 7. 压层推理

- 参考题目题号：7（d59b0160）、12（ba97ae07）
- tags:
  - operation:重涂色, recolor
  - object:横条, h_bar
  - object:竖条, v_bar
  - object:遮挡块, occluder_block
  - relation:交叉, crossing
  - relation:传递层级, transitive_ordering
  - condition:遮挡还原, occlusion_recovery

### docstring

```text
由可见交叉处的压盖关系推出所有条带的全局上下层级，再把被灰色遮挡的交叉恢复成压在上面那条的颜色。

输入结构
- 背景上有若干整行横条与整列竖条，颜色互不相同。
- 任意两条交叉处，若未被遮挡，则整块呈现位于上层那条的颜色。
- 少数交叉被统一的遮挡色整块盖住；遮挡色不是任何条带色。

规则
- 从可见交叉读出成对的"谁在上"关系；这些关系经传递可推出全体条带的唯一全序。
- 把每个被遮挡的交叉改涂为该交叉两条中层级较高者的颜色。
- 其余部分不变，输出同尺寸。

关键洞察
- 被遮挡交叉的两条可能从未在别处直接示范过上下关系，只能通过第三方条带的传递链推出（诱饵：以为遮挡处填多数色、固定色或简单交替）。
```
