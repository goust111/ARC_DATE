## 1. 残端复原十字

- 参考题目题号: `f8be4b64`, `0e671a1a`, `b5ca7ac4`
- tags:
  - operation:绘制, drawing
  - operation:排序, ordering
  - object:十字图案, cross_pattern
  - object:臂端像素, arm_tip_pixel
  - relation:隐式中心, implicit_center
  - condition:尺寸定层序, size_sets_layer_order

### docstring

```text
由四个同色散点复原出隐形十字，并按十字大小从大到小依次绘制，小者覆盖大者。

输入结构：
- 黑色背景网格上散布若干组彩色像素，每组同色且恰好四个像素。
- 每组中恰有两个像素同列（上下臂端）、另两个像素同行（左右臂端），同行像素所在的行
  与同列像素所在的列相交于一点，即该组隐形十字的中心；四条臂长可以互不相等。
- 各组十字的总像素数互不相同；不同组的十字在画面上可能交叠。

规则：
- 对每组同色四点，取同列两点所在的列与同行两点所在的行，其交点为十字中心。
- 以该组颜色画出完整十字：中心像素，加上从中心通向四个臂端的四条实线。
- 按十字总像素数从大到小的顺序依次绘制，后画的小十字覆盖先画的大十字的交叠像素。

关键洞察：
- 参与规则的十字从未被完整画出，画面上只有它的四个臂端残迹，中心必须由行列交点反推。
- 交叠处的颜色不是先来先得，而是由所有十字大小的全序反向决定的层叠关系。
```

## 2. 捕获区间双重力

- 参考题目题号: `afe3afe9`, `6d58a25d`, `d22278a0`, `b5ca7ac4`
- tags:
  - operation:重力滑动, gravity_slide
  - object:边缘标记线, edge_marker_line
  - object:散点像素, scattered_pixel
  - relation:行列覆盖, row_col_coverage
  - relation:最近归属, nearest_ownership
  - condition:双捕获距离裁决, double_capture_distance

### docstring

```text
被边缘标记线段的投影捕获的像素滑向该边并堆叠，双重捕获时滑向更近的一边，未捕获者原地不动。

输入结构：
- 黑色背景。顶边上有一段红色线段，左边上有一段蓝色线段，两段都不占满整条边。
- 网格内部散布若干非红非蓝的单色像素。

规则：
- 若像素所在列位于顶边红段的列区间内，则它被红段捕获；若所在行位于左边蓝段的行区间内，
  则被蓝段捕获。
- 仅被一段捕获的像素沿直线滑向该段所在的边；被两段同时捕获的像素比较它到顶边的距离
  （行号）与到左边的距离（列号），滑向更近的一边（输入保证两距不相等）。
- 滑动像素停靠在标记线段旁或先到达的像素之后，同一行或列的多个像素按先近后远依次堆叠；
  未被任何一段捕获的像素保持原位。

关键洞察：
- 两条边线不是装饰也不是方向码，而是各自张开一片"捕获走廊"；一个像素的命运取决于它
  落在零条、一条还是两条走廊里。
- 双重捕获的裁决用的是像素自身的位置距离，与颜色无关；纹丝不动的像素正是识别走廊边界
  的反例证据。
```

## 3. 缺陷定位分形印章

- 参考题目题号: `929ab4e9`, `9565186b`, `91413438`
- tags:
  - operation:对称补全, symmetry_completion
  - operation:图案印章, stamp_glyph
  - object:精灵体, sprite
  - object:缺陷像素, defect_pixel
  - relation:四元镜像轨道, fourfold_mirror_orbit
  - condition:轨道多数决, orbit_majority
  - condition:缺陷位置定槽位, defect_position_sets_slot

### docstring

```text
按镜像轨道多数色修复精灵中的错误像素，再把修复后的精灵印到以错误像素位置为坐标的块阵槽位中。

输入结构：
- 输入是一个边长为偶数的小正方形精灵，其图案本应同时关于水平中轴与垂直中轴镜像对称。
- 少数格子被改成了错误颜色：每个四元镜像轨道中至多一个格子与其余三格不同，其余三格
  颜色一致。

规则：
- 将精灵每个格子与它的水平、垂直、双重镜像位置组成四元轨道，轨道内取多数色，把少数的
  错误格改为多数色，得到修复精灵。
- 设精灵边长为 n，构造 n×n 个槽位的黑色块阵，每个槽位大小为 n×n。
- 对输入中每个曾被修复的错误格位置 (r, c)，把整个修复精灵复制进块阵的第 (r, c) 号槽位；
  其余槽位保持全黑。

关键洞察：
- 错误像素身兼两职：内容上被轨道多数决抹除，位置上却升维成块阵坐标。
- 输出的不对称布局正是输入对称性破缺之处的地图，而每一枚印章本身已是修复后的完美对称体。
```

## 4. 连锁倒伏

- 参考题目题号: `fcc82909`, `11852cab`, `6bcdb01e`
- tags:
  - operation:旋转, rotate
  - operation:连锁反应, chain_reaction
  - object:彩色竖条, colored_bar
  - object:触发像素, trigger_pixel
  - relation:高度即射程, height_as_reach
  - condition:够不着即终止, gap_stops_chain

### docstring

```text
触发标记推倒最左的竖条，倒下的条以自身高度为射程向右压倒够得着的下一条，连锁至够不着处停止。

输入结构：
- 黑色背景网格的底行上立着若干宽一格、高度互不相同的彩色竖条，条与条的水平间距不等。
- 最左条左侧、同在底行的相邻格有一个红色触发像素。

规则：
- 从最左条开始：被推倒的条绕其底格向右放平，原本竖直的 h 格改为占据底行从原底格向右
  连续 h 格。
- 若某条放平后其覆盖区间接触到（相邻或压上）下一条所在列，则下一条也被推倒，依此向右
  连锁；若够不着下一条，连锁终止，其右所有条保持直立原样。
- 重叠像素按从左到右的倒伏顺序，后倒的覆盖先倒的；触发像素保留。

关键洞察：
- 条的高度就是它倒伏后的射程，连锁止于第一处"够不着"的空隙。
- 只看第一个示例容易误以为所有条都会倒下，或误以为高矮决定倒立；实际是逐条传递的因果
  链，断点由几何间隙决定。
```

## 5. 奇偶异场

- 参考题目题号: `d22278a0`, `b5bb5719`
- tags:
  - operation:填充, fill
  - object:标记像素, marker_pixel
  - relation:双距离场叠加, dual_distance_fields
  - condition:奇偶异或着色, parity_xor_fill

### docstring

```text
以两个标记像素为源各自展开奇偶环场，只有两场奇偶不同的格子被涂色，颜色取距离为偶的那一源。

输入结构：
- 黑色背景网格上仅有两个颜色不同的单像素标记。

规则：
- 对每个格子分别计算到两个标记的切比雪夫距离 d1 与 d2。
- 若 d1 为偶且 d2 为奇，涂第一个标记的颜色；若 d2 为偶且 d1 为奇，涂第二个标记的颜色。
- 若 d1 与 d2 同为偶或同为奇，该格保持黑色；标记像素自身不享有豁免，同样按此判据决定
  去留。

关键洞察：
- 单看一个源，它的偶距环是一圈套一圈的完整方环；输出里每圈却缺出规律性的豁口，豁口正
  是另一源的偶距环压过来的地方。
- 这不是"就近裁剪"的势力范围划分，而是两张奇偶场逐格异或的干涉图样。
```

## 6. 姿态槽位盖章

- 参考题目题号: `edb79dae`, `11852cab`, `afe3afe9`
- tags:
  - operation:图案印章, stamp_glyph
  - operation:旋转, rotate
  - object:框架, frame
  - object:多米诺占位符, domino_placeholder
  - object:精灵体, sprite
  - object:朝向锚, heading_anchor
  - relation:朝向匹配, heading_match
  - condition:灰格对灰头对齐, gray_aligns_gray

### docstring

```text
把框外的彩色精灵旋转到框内同色多米诺占位符指示的朝向，再以灰头对灰格盖章进框。

输入结构：
- 黑色背景上有一个单色空心矩形框。
- 框内有若干双格占位符：一格为彩色主格，紧邻一格为灰色指向格，灰格相对主格的方位为上、
  下、左或右；各占位符主格颜色互不相同。
- 框外每种主格颜色各有一个连通精灵；精灵中嵌有一个灰色像素作为"头"，灰头在精灵内恰有
  一个相邻的本色像素，从该邻格指向灰头的方向即精灵的当前朝向。

规则：
- 对每个占位符，找到框外同色精灵，将其旋转 0、90、180 或 270 度，使精灵朝向与占位符
  灰格相对主格的方位一致。
- 平移旋转后的精灵，使其灰头恰好落在占位符灰格的位置，然后按精灵本色画入框内，灰头位置
  在输出中也画为精灵本色。
- 盖章前，占位符的两个格子先还原为黑色；框与框外的精灵及其灰头原样保留。

关键洞察：
- 多米诺不是普通对象而是"姿态槽位"：同一枚占位符同时编码颜色索引、落点与朝向。
- 精灵的灰像素身兼两职——旋转前是罗盘指针，平移时是对齐把手，转向与对位两次匹配都咬合
  在这同一个像素上。
```

## 7. 众数的假面

- 参考题目题号: `9565186b`, `ecb67b6d`, `929ab4e9`
- tags:
  - operation:重涂色, recolor
  - operation:对称补全, symmetry_completion
  - object:连通区域, connected_region
  - object:侵占像素, occluder_pixel
  - relation:唯一整块, unique_single_component
  - condition:连通性而非数量, connectivity_not_count
  - condition:堵口者被吸收, occluder_absorbed

### docstring

```text
找出唯一连成一整块的颜色，把侵占其对称缺口的异色像素吸收为本色，其余异色像素涂灰。

输入结构：
- 黑底网格上有三到五种彩色，每种颜色的像素总数互不相同。
- 恰有一种颜色的全部像素构成单个四连通块，其余每种颜色都碎裂为至少两块。
- 该整块对象本应左右镜像对称，但它的少量格子被其他颜色的像素侵占（侵占不破坏它的连通
  性）；侵占像素与散落在别处的碎片颜色相同，无法仅凭颜色区分。

规则：
- 找到唯一构成单个连通块的颜色，以该对象自身的竖直镜像轴判定其完整轮廓。
- 凡位于完整轮廓内却被异色占据的格子，改为该对象的颜色。
- 其余所有异色像素一律原位改为灰色。

关键洞察：
- 首个示例里整块颜色恰好也是像素最多的颜色，"保留众数、余者涂灰"的假设会在后续示例
  崩塌——真正的判据是连通性，不是数量。
- 同色的异物有两种命运，分界不在颜色而在位置：是否恰好堵在整块对象的对称缺口上。
```

## 8. 转向器传色

- 参考题目题号: `6bcdb01e`, `b5bb5719`, `da515329`
- tags:
  - operation:射线延伸, ray_extend
  - operation:转弯, turn
  - object:阻挡像素, blocker_pixel
  - object:起点条, start_bar
  - relation:颜色即指令, color_as_instruction
  - condition:段色继承转向器, segment_inherits_deflector

### docstring

```text
光束从边界射入，撞上红色转向器右转、蓝色转向器左转，且每一段路径都染成上一个转向器的颜色。

输入结构：
- 黑色背景网格内散布若干红色与蓝色的单像素转向器。
- 边界上有一个绿色像素，紧邻其内侧还有一个绿色像素，两者给出光束的入射位置与方向。

规则：
- 从边界绿格出发，沿两绿格连线方向逐格前进；起始一段（直到第一次转向前）画绿色。
- 当正前方一格是转向器时不踩上去，而是原地转向：红色转向器顺时针转九十度，蓝色转向器
  逆时针转九十度；此后直到下一次转向前的整段路径，都涂成刚才那个转向器的颜色。
- 前方越出网格边界时光束离开，绘制结束；路径与自身交叉时，后画的段覆盖先画的段；所有
  转向器保持原位原色。

关键洞察：
- 转向器的颜色是一身二任的指令：几何上决定转向的手性，涂装上决定下一段路径的颜色，
  路径像被每个碰到的转向器"传染"。
- 反推时每段的颜色都指认了它上游的那个转向器，整条折线是一串因果链的可见残迹。
```
