## 1. 隐形周期地板

- 参考题目题号: `16de56c4`、`84ba50d3`、`12422b43`
- tags:
  - operation:重力下落, gravity_drop
  - operation:周期推断, period_inference
  - object:标记点, marker_dot
  - object:隐式地板线, implicit_floor_line
  - object:精灵, sprite
  - relation:间隙容纳, gap_fit
  - condition:高度决定穿透, height_determines_pass_through

### docstring

```text
让悬空的彩色精灵落在由两粒灰点隐式生成的周期地板上，装不进层间空隙的精灵直坠到底。

输入结构：
- 黑色背景。最左列恰有两个灰色像素，网格其余部分没有灰色。
- 两个灰点的行距 p 与其行号定义一族“隐形地板行”：所有与灰点行号模 p
  同余的行。地板行本身没有画出任何东西。
- 其余前景是若干 4 连通彩色精灵，两两不共享任何列；高度不足 p 的精灵
  初始完整位于相邻两条隐形地板行之间。

规则：
- 保留两个灰点。
- 高度 ≤ p−1 的精灵竖直下落，停在使其最底行紧贴其正下方第一条隐形
  地板行上方一格的位置。
- 高度 ≥ p 的精灵放不进相邻两条地板行之间的空隙，穿透全部地板，
  直落到网格底边。
- 地板行在输出中仍保持背景色。

关键洞察：
- 支撑精灵的地板从未被画出：最左列两粒灰点只给出周期与相位，整族
  横线要靠模运算还原；
- 且这些线不是对所有精灵都“实”的——精灵能否被相邻两线之间的空隙
  容纳（高度与周期的比较）决定它停层还是穿透坠底。
```

## 2. 径向码表

- 参考题目题号: `8dae5dfc`、`e4888269`
- tags:
  - operation:重涂色, recolor
  - object:嵌套矩形层, nested_rect_layer
  - object:散布精灵, scattered_sprite
  - relation:层序即置换, nesting_order_as_permutation
  - condition:全局循环后继替换, global_cyclic_successor

### docstring

```text
把唯一嵌套矩形的层色序列读成循环置换，并将它统一施加到全网格。

输入结构：
- 背景为最常见色。前景对象中恰有一个是实心嵌套矩形：由 k（k≥3）层
  颜色互不相同的矩形环逐层包裹，每次剥去最外一圈颜色均匀。
- 其余前景是若干零散精灵与像素，颜色全部取自这 k 种层色。

规则：
- 由外向内读出嵌套矩形的层色序列 c1, c2, …, ck，定义替换
  ci→c(i+1)（i<k），ck→c1。
- 对全网格每个前景像素施加一次该替换，包括嵌套矩形自身；背景不变。

关键洞察：
- 嵌套矩形不是待变换的对象，而是一张径向书写的码表；对它自己施加
  置换后层色恰好整体循环移动一步，这个“环在转动”的表象是诱饵——
  真正的规则是同一张颜色置换表同时改写了所有散件，置换的内容只能
  从矩形的嵌套层序里读出。
```

## 3. 同色镜像配对定轴

- 参考题目题号: `d56f2372`、`88207623`、`e729b7be`、`8403a5d5`
- tags:
  - operation:镜像, mirror
  - operation:连线, draw_line
  - object:同色精灵, same_color_sprite
  - object:隐形轴线, hidden_axis
  - relation:形状配对, shape_pairing
  - relation:变换类型分类, transform_classification
  - condition:孤例自对称, singleton_self_symmetric

### docstring

```text
为每对互为镜像或点对称的灰色精灵标出隐形的轴或中心，孤零的自对称精灵标出自己的内部轴。

输入结构：
- 黑色背景上散布若干灰色 4 连通精灵（全部同色，形状各异）。
- 精灵之间存在唯一的完美配对方案：每对精灵恰以下列三种关系之一
  互相对应，且恰有一种关系成立——
  (a) 关于某一整列互为左右镜像；
  (b) 关于某一整行互为上下镜像；
  (c) 关于某一格中心互为 180° 点对称。
- 恰有一个精灵没有伙伴，它自身关于某一整列或整行镜像对称。

规则：
- 对 (a) 类对，用绿色画满其反射轴所在的整列。
- 对 (b) 类对，用绿色画满其反射轴所在的整行。
- 对 (c) 类对，只在旋转中心格画一个黄色像素。
- 对孤零精灵，用绿色画出它自身对称轴所在的整列或整行。
- 输出为同尺寸黑色网格，仅含这些标记。

关键洞察：
- 所有精灵同色，配对不能靠颜色，只能在反射/旋转变换下做形状匹配，
  并为每对判定属于哪种变换——变换类型决定输出是列线、行线还是
  单个中心点；
- 轴与中心从未画出，须由对的相对位置精确反推；孤例的伙伴是它自己，
  是最容易误配的诱饵。
```

## 4. 杯口灌注

- 参考题目题号: `aba27056`、`12422b43`、`08ed6ac7`
- tags:
  - operation:循环填充, cyclic_fill
  - operation:擦除, erase
  - object:杯形容器, cup_shape
  - object:颜色流, color_stream
  - relation:开口朝向, opening_direction
  - relation:距离定序, distance_ordering
  - condition:先入沉底, first_in_sinks_deepest

### docstring

```text
把杯口外一串颜色按倒序灌入杯内并循环补满。

输入结构：
- 黑色背景上有一个灰色“杯”：缺去一条边的矩形框，内部为背景，
  开口可朝上下左右任一方向。
- 在开口正对方向的杯外，沿开口轴线散布若干彩色像素（可以不连续），
  构成一条颜色流；流像素个数不超过杯内层数。

规则：
- 将杯内部按平行于杯底（开口对面那条壁）的整层划分，最靠杯底的层
  最深。
- 按离杯口由近到远的顺序读出流像素颜色 s1, s2, …, sm；s1 填入最深层，
  s2 填次深层，依次向浅；层未填完则从 s1 起按原序循环继续，直至内部
  填满。
- 擦除杯外全部流像素，杯壁保持不变。

关键洞察：
- 先入杯者沉底：离杯口最近的颜色最先倒入、落在最深处，杯内层序恰与
  流的空间顺序相反；
- 颜色不足时不停止而按原序循环补满；层的深浅方向完全由开口朝向决定，
  杯可任意旋转。
```

## 5. 锚点对齐交集

- 参考题目题号: `7c9b52a0`、`0c9aba6e`、`dae9d2b5`、`50aad11f`
- tags:
  - operation:透明叠加, transparent_overlay
  - operation:裁剪, crop
  - object:面板, panel
  - object:锚点像素, anchor_pixel
  - relation:内容对齐, content_alignment
  - condition:全体共有交集, all_panels_intersection

### docstring

```text
把各面板的图案按红锚点对齐后取所有面板共有的点。

输入结构：
- 最常见色构成分隔结构，把网格划分成若干矩形面板；面板的尺寸与位置
  各不相同。
- 每个面板内部：恰有一个红色锚点像素，以及若干个该面板专属颜色的
  散点。

规则：
- 对每个面板，以其红锚点为原点，记录所有散点的相对坐标。
- 找出在每一个面板中都出现的相对坐标。
- 输出一块黑色画布：在这些公共相对坐标处画青色，原点处画红色；
  画布取包含全部青点与红点的最小矩形。

关键洞察：
- 面板不能按边框或左上角对齐，只能按内容中的锚点对齐——面板外形、
  大小与摆放全是干扰；
- 对齐之后要的也不是叠加的并集，而是所有面板共有的交集。
```

## 6. 递归炮台

- 参考题目题号: `252143c9`、`e4888269`、`16de56c4`
- tags:
  - operation:射线延伸, ray_cast
  - operation:擦除, erase
  - object:主像素, primary_pixel
  - object:卫星群, satellite_cluster
  - relation:象限指示方向, quadrant_indicates_dir
  - relation:命中接力, hit_relay
  - condition:入度为零定起点, zero_indegree_start

### docstring

```text
从种子起沿卫星指示的对角方向逐段折线飞行，每命中一座新炮台就换向换色，直至飞出网格。

输入结构：
- 背景为最常见色。前景包含若干种颜色；每种颜色恰有一个“主像素”，
  其余同色像素（卫星）全部位于以主像素为原点的同一个对角象限内，
  且不与主像素同行同列；满足该条件的主像素选取方式唯一。
- 从每个主像素出发，沿其卫星象限方向的对角线要么恰好命中另一个
  主像素，要么直达网格边缘；恰有一个主像素不被任何对角线命中。

规则：
- 以不被命中的主像素为起点，沿其卫星指示的对角方向飞行；每当命中
  一个主像素，就从该格起改用它的颜色、改沿它的卫星指示方向继续飞行。
- 最后一段飞至网格边缘为止。
- 输出：擦除全部卫星，在背景上画出整条折线轨迹，每一段用该段出发
  主像素的颜色；主像素本身并入轨迹。

关键洞察：
- 每个被命中的像素本身又是一座带指向卫星的新炮台，同一“象限定向”
  机制被递归使用；
- 起点不靠外观识别，而要靠“谁不被任何别的炮台瞄中”反推；卫星群
  不是噪声，而是每一段的方向舵。
```
