## 1. 嵌套环迷宫的镜深涂径

- tags:
  - operation:寻路, pathfinding
  - operation:重涂色, recolor
  - object:同心方框层, concentric_layer
  - object:端点像素, endpoint_pixel
  - object:门洞, gap_door
  - relation:深度排序, depth_order
  - condition:最短路径唯一, unique_shortest_path
  - condition:深度镜像配色, mirrored_depth_color
- 参考题目题号：1（85c4e7cd）、10（b15fca0b）

### docstring

```text
在嵌套彩色方环的迷宫中找出连接两个红色端点的唯一最短通路，并按深度对折
的环色给通路分段上色。

输入结构：
- 黑色背景上有 n 个一格厚的同心矩形环，从外到内颜色互不相同，记为
  c1..cn。
- 每个环上恰有一个背景色缺口作为门，各门位置彼此错开，迫使通路迂回。
- 两个红色端点像素：一个位于最外环与次外环之间的夹层，一个位于最内环
  内部；两端点间的四邻接最短路径唯一。

规则：
- 保留所有环与两个端点不变。
- 把环体视为墙、门视为通道，求出两端点之间唯一的四邻接最短路径。
- 定义格子的深度 d 为包围它的环数（最外夹层为 1，最内区域为 n）。
- 把深度为 d 的路径格涂成第 n+1-d 层环的颜色（环从外到内编号）。

关键洞察：
- 路径配色不取自刚穿过或将要穿过的环，而取自深度关于中心对折后的环：
  越靠外的路径段穿的是越靠内的环色，整条通路是环色序列的反演读数。
```

## 2. 双尺度掩码的正负印花

- tags:
  - operation:像素压缩解码, block_decode
  - operation:印章覆盖, stamp
  - object:二值掩码, binary_mask
  - object:细印章, fine_stamp
  - relation:尺度定角色, scale_assigns_role
  - condition:图底反相, figure_ground_inversion
  - condition:双色互补, two_color_complement
- 参考题目题号：7（80af3007）、20（f931b4a8）

### docstring

```text
把块放大编码的粗掩码解码为布局，在其开块印上细印章、关块印上细印章的
图底反相，并用两种颜色区分正负。

输入结构：
- 黑色背景上有两个前景图形，颜色不同。
- 一个图形占 9x9，由九个全实或全空的 3x3 瓦片构成，是块放大编码的
  3x3 掩码（颜色 A）。
- 另一个图形直接落在一个 3x3 包围盒内，是原尺寸细图案（颜色 B）。

规则：
- 输出为 9x9 网格。
- 把 9x9 图形压缩为 3x3 布局掩码。
- 布局掩码的每个开格填入细图案原样，用颜色 B。
- 每个关格填入细图案的图底反相（原实格变空、原空格变实），用颜色 A。

关键洞察：
- 两个图形的角色由编码尺度而非位置决定；输出没有任何空白块——关块不是
  留空而是负片，两种颜色在整幅输出中互补咬合成一张满版图。
```

## 3. 双块拼洞

- tags:
  - operation:拼合填充, tiling_fill
  - operation:平移放置, translate_place
  - operation:擦除, erase
  - object:封闭孔洞, enclosed_hole
  - object:精灵体, sprite
  - relation:二元拼图, two_piece_tiling
  - condition:含旋转反射变换, includes_rotation_reflection
  - condition:全局唯一拼法, globally_unique_tiling
  - condition:忽略干扰项, ignore_distractors
- 参考题目题号：2（184a9768）、13（50f325b5）

### docstring

```text
每个封闭孔洞由恰好两个精灵经旋转镜像后无缝拼合填满，把参与拼合的精灵
搬入洞中，其余精灵留在原地。

输入结构：
- 背景为主色，一块大的单色物体内部含若干形状各异的封闭背景孔洞。
- 物体外散布若干单色精灵；没有任何一个精灵能单独与某个洞全等。
- 每个洞恰好存在一对精灵，经各自旋转或镜像后能无重叠、无空隙地拼满
  该洞，且全体精灵到全体洞的这种配对拼合方案全局唯一。
- 另有若干干扰精灵不参与任何拼合。

规则：
- 大物体保持不变。
- 对每个洞，把与之对应的两个精灵按所需姿态搬入洞内拼满，各自保留原
  色，并擦除其原位置。
- 干扰精灵原样保留。

关键洞察：
- 先试单块全等必然失败——洞是二元拼图；哪些精灵移动不由颜色、大小或
  距离决定，而由全局唯一的两两拼合方案决定。
```

## 4. 标记军衔打包

- tags:
  - operation:压缩, compress
  - operation:拼接, concatenate
  - operation:擦除, erase
  - object:分栏面板, panel
  - object:分隔列, divider_column
  - object:标记像素, marker_pixel
  - relation:计数定次序, count_sets_order
  - condition:半区定读向, half_sets_direction
  - condition:先删标记再判空行, strip_markers_before_occupancy
- 参考题目题号：5（25c199f5）、17（f18ec8cc）、20（f931b4a8）

### docstring

```text
按各面板内标记像素的数量决定面板读取次序、按标记所在半区决定行内读向，
把非空行打包进单一面板。

输入结构：
- 网格被贯通的分隔列分成若干等宽面板，分隔色仅出现在分隔列。
- 每个面板内除内容像素外，还含若干个专用标记色像素（该颜色不作他
  用）：读取次序为第 k 名的面板恰含 k 个标记。
- 每个面板的标记全部位于其上半区，或全部位于其下半区。

规则：
- 先删除所有标记像素，再判断各面板中哪些行含非背景像素。
- 面板按标记数量从少到多的顺序依次读取。
- 标记位于上半区的面板，其非空行从上到下读取；位于下半区的从下到上
  读取。
- 把读出的行依次从输出面板顶部向下排列，其余行为背景。

关键洞察：
- 标记像素同时编码两件事：数量给面板排序、位置给行内读向；且必须先删
  标记再判空行——只含标记的行是会被误当内容保留的诱饵。
```

## 5. 遮挡下的加速旋转印迹

- tags:
  - operation:印章覆盖, stamp
  - operation:旋转, rotate
  - object:精灵体, sprite
  - object:残迹, occluded_trace
  - relation:递增间距序列, increasing_gap_sequence
  - relation:后盖压前, later_over_earlier
  - condition:四旋转循环, four_rotation_cycle
  - condition:生成元未完整出现, generator_never_fully_shown
- 参考题目题号：8（50c07299）、12（ed98d772）、18（72207abc）

### docstring

```text
从相互重叠的印迹序列中恢复精灵原形与盖印规律，继续以递增间距、每次
顺时针转九十度的方式盖印到放不下为止。

输入结构：
- 背景网格上沿同一水平带自一侧向另一侧盖有同一非对称精灵的若干枚印
  迹。
- 相邻印迹锚点间距依次递增一格；每枚相对前一枚顺时针旋转九十度。
- 起初间距小于精灵宽度，早期印迹被后盖的印迹部分覆盖，画面上只有最
  后一枚是完整的。

规则：
- 保留输入画面。
- 按同一规律继续向空白一侧盖印：新印迹相对前一枚再顺时针转九十度，
  锚点间距比上一次再多一格，后盖印迹覆盖先前像素。
- 印迹须完整落在网格内才盖，第一次放不下即停止。

关键洞察：
- 精灵的完整形状从未在早期印迹中出现，必须从最后一枚完整印迹反推生
  成元，由遮挡方向确定时间顺序，再同时外推间距递增与四旋转循环两条
  规律。
```

## 6. 双镜走廊的代际染色

- tags:
  - operation:镜像, reflect
  - operation:平铺, tiling
  - operation:重涂色, recolor
  - object:镜线, mirror_line
  - object:前景图案, foreground_motif
  - relation:平行对称轴, parallel_axes
  - relation:复合反射, compound_reflection
  - condition:代数奇偶定色, generation_parity_color
- 参考题目题号：4（66ac4c3b）、15（feca6190）、6（ba26e723）

### docstring

```text
把夹在两条平行镜线之间的图案向两侧反复镜像铺满网格，反射代数为奇的
镜像用镜线色、为偶的用原色。

输入结构：
- 网格上有两条平行的整行（或整列）镜线，颜色为 M。
- 两镜线之间夹着一个颜色为 F 的图案，镜线外两侧为大片背景。

规则：
- 原图案与镜线保持不变。
- 把两镜线之间的条带当作第 0 代，向两侧连续镜像：每越过一条镜线产生
  下一代镜像，超出网格的部分裁去。
- 第奇数代镜像的图案像素涂成 M，第偶数代涂成 F。

关键洞察：
- 两面镜子会产生无限次复合反射：奇数代是翻转像，偶数代其实等于平移
  像；颜色交替暴露的正是反射次数的奇偶性，只做一次反射无法匹配远处
  的副本。
```

## 7. 环上颜色的传送圈

- tags:
  - operation:重涂色, recolor
  - operation:去噪, denoise
  - object:同心方框层, concentric_layer
  - object:标记像素, marker_pixel
  - relation:有向圈, directed_cycle
  - condition:少数像素为指令, minority_pixel_as_instruction
  - condition:沿箭头反向取色, color_from_inverse_arrow
- 参考题目题号：1（85c4e7cd）、3（de809cff）、19（0becf7df）

### docstring

```text
嵌套方环上的异色杂点构成"把自己主色送给谁"的有向圈，沿圈反向传色后
所有环恢复纯色。

输入结构：
- 网格由同心的一格厚矩形环构成，每环有其主色，主色互不相同。
- 部分环各嵌恰好一个异色像素，其颜色是另一环的主色；把"环 X 藏有环 Y
  的主色"记作 X→Y，全部箭头构成若干不相交的有向圈（有的圈为两环互
  指，有的圈含三环以上）。
- 无杂点的环不参与。

规则：
- 环 X 藏有颜色 Y 的杂点表示 X 把自己的主色移交给主色为 Y 的环。
- 每个参与环的新主色等于唯一指向它的环的旧主色。
- 无杂点的环保持原色；输出中所有环均为纯色，杂点全部消失。

关键洞察：
- 杂点是"送出"而非"变成"——把每环直接改成其杂点颜色在两环互指时碰巧
  给出同样结果（诱饵），在三环以上的圈中就会失败；必须建立全局有向圈
  并沿箭头反向取色。
```

## 8. 原型残片补全

- tags:
  - operation:模板匹配, template_matching
  - operation:填充, fill
  - object:连通分量, connected_component
  - object:原型形状, prototype_shape
  - relation:面积比较, area_comparison
  - condition:唯一嵌入对齐, unique_embedding_alignment
  - condition:保留残片原色, keep_fragment_color
- 参考题目题号：14（1f85a75f）、13（50f325b5）

### docstring

```text
以面积最大的连通体为原型，把每个残片按其在原型形状中的唯一嵌入位置
补全成完整原型形状。

输入结构：
- 背景为主色，网格上散布若干单色连通体。
- 恰有一个连通体面积最大，是完整原型。
- 其余每个连通体的形状都是原型形状的真子集（残片），且每个残片在原型
  形状中只有一个可嵌入的对齐位置（不做旋转镜像）。

规则：
- 原型保持不变。
- 对每个残片，找出它作为子形状嵌入原型的唯一对齐方式，在残片所在位
  置按该对齐补画出原型的其余像素，使用残片自身的颜色。
- 残片原有像素保持不动。

关键洞察：
- 补全的锚点不由包围盒或质心给出，而由残片形状在原型中的唯一嵌入位
  置给出；面积最大者是唯一的形状字典，残片补出的部分可以伸向任意方
  向。
```
