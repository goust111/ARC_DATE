## 1. 锁孔式链式点火

- tags:
  - operation:连线, line_drawing
  - operation:重涂色, recolor
  - operation:擦除, erase
  - object:边框缺口, border_notch
  - object:前景对象, foreground_object
  - relation:方向传播, directional_propagation
  - condition:链式激活, chain_activation
  - condition:缺口即锁孔, notch_as_keyhole
- 参考题目题号: 14, 19, 20

### docstring

```text
射线只有恰好射入物体的缺口才能点燃它；点燃者继续发射，链条终结后未点燃的物体全部消失。

输入结构：
- 黑色背景上散布若干灰色小物体，每个物体边界上恰有一个单格缺口，缺口朝上、下、左、右四个方向之一。
- 恰有一个物体是红色的，作为初始火种；其余物体均为灰色。

规则：
- 点燃的物体从其缺口格沿缺口朝向发射一条橙色射线，射线穿过背景直行。
- 若射线到达的第一个非背景格恰是某物体的缺口格且缺口正对来向，该物体整体重涂为红色，并立刻从自己的缺口发射下一条射线，链式继续。
- 若射线击中物体的实体部位，射线在该处停下且链条就此终止，被击中的物体不点燃；射线出界同样终止。
- 传播结束后，所有仍为灰色的物体整体擦除，走过的射线保留为橙色。

关键洞察：
- 缺口既是炮口又是锁孔——发射与受燃都只经由缺口，第一个示例会诱导"击中即点燃"的假设，但只有"射入缺口才点燃"能解释全部示例；
- 最终画面由激活链的可达性决定，链外物体不留任何痕迹。
```

## 2. 稀有色锚点配准叠加

- tags:
  - operation:透明叠加, transparent_overlay
  - operation:移动, move
  - object:分隔行, separator_row
  - object:锚点像素, anchor_pixel
  - relation:频率比较, frequency_compare
  - relation:逐格对齐, cell_aligned
  - condition:稀有色即锚点, rare_color_as_anchor
  - condition:冲突重涂, conflict_recolor
- 参考题目题号: 2, 6, 10

### docstring

```text
按各自面板中仅出现一次的颜色像素配准两块图案，再逐格融合成一块输出。

输入结构：
- 一条通宽分隔行把网格分成等高的上、下两块面板，分隔色只出现在该行。
- 每块面板是共同背景色加一个多色图案，两块图案形状不同。
- 每块面板中恰有一种颜色的像素在该面板内只出现一次（稀有色），两块面板的稀有色可以不同；青色不在输入中出现。

规则：
- 去掉分隔行，把下面板整体平移，使它的稀有色像素与上面板的稀有色像素落在同一格；平移后落到面板外的像素舍弃。
- 输出为一块面板大小：某格只有一方是前景则保留那一方的颜色；双方前景同色则保留该色；双方前景异色则该格涂成青色；双方都是背景则保留背景色。

关键洞察：
- 锚点没有专用颜色，只能靠"面板内频次恰为一"识别；
- 对齐参数不由面板边界或图案重心给出，而由两枚锚点的配准决定；冲突格（包括锚点自身）是校验对齐是否正确的青色印记。
```

## 3. 散落旋转副本的表决修复

- tags:
  - operation:对称补全, symmetry_completion
  - operation:旋转, rotate
  - object:精灵体, sprite
  - object:缺陷像素, defect_pixel
  - object:边框, frame
  - relation:旋转对称, rotational_symmetry
  - relation:多数表决, majority_vote
  - condition:冒充者排除, impostor_exclusion
  - condition:框定输出朝向, frame_anchors_orientation
- 参考题目题号: 8, 12, 18, 20

### docstring

```text
在散落的精灵中找出互为旋转的四个带噪副本，排除冒充者，按被框住者的朝向表决还原干净瓦片。

输入结构：
- 背景上散落若干大小相同、互不相邻的多色精灵。
- 其中四个是同一源瓦片的 0°、90°、180°、270° 旋转副本，各含少量缺陷像素，且任何一组旋转对应的四格中至多一个被破坏。
- 另有恰好一个精灵是冒充者，不是其它精灵的任何旋转；四个副本中恰有一个被一圈单色矩形框围住。

规则：
- 找出互为旋转的四个副本：冒充者无法在允许少量缺陷的前提下与其余三个旋转对齐，据此排除。
- 把四个副本都旋转到被框住那个副本的朝向，逐格取多数色（至少三票一致）。
- 输出修复后的瓦片，尺寸等于精灵大小，不含框。

关键洞察：
- 由于每个副本都带噪声，旋转匹配不能要求逐格全等，必须接受近似一致，这也正是排除冒充者的判据；
- 框不贡献任何内容，只充当输出朝向的锚；坏格由其余三份旋转冗余多数还原。
```

## 4. 叠印团的模具认领

- tags:
  - operation:嵌入填充, inlay_fill
  - operation:擦除, erase
  - object:空腔, cavity
  - object:精灵体, sprite
  - object:前景区域, foreground_region
  - relation:遮挡压叠, occlusion_stacking
  - relation:形状认领, shape_claiming
  - condition:唯一全局分配, unique_global_assignment
  - condition:对象未被完整画出, object_never_fully_drawn
- 参考题目题号: 1, 10, 20

### docstring

```text
天上只有一团彼此叠压的印迹，用凹槽的形状去团中认领各自的碎块，并连同被遮挡的部分一起归位。

输入结构：
- 网格下部是一整片基色地形，上表面开有若干形状各异、向上开口的凹槽。
- 上方悬浮一团多色像素：它是若干单色碎块按未知压叠次序叠印的结果，上层碎块遮住下层碎块的部分像素。
- 碎块数量与凹槽数量相同，颜色互不相同，只平移、不旋转不翻转；碎块从未被完整画出。

规则：
- 每个凹槽的完整形状恰能以唯一方式套在叠印团上：某一种颜色的全部可见像素都落在槽形之内，而槽形内的其余像素都属于压在其上层的其它颜色——该颜色即此槽认领的碎块。
- 把每个凹槽用其认领碎块的颜色整体填满、与槽口齐平；输出中上方清空，地形保持基色。

关键洞察：
- 被遮挡的部分不靠猜，而是由槽形反推补全——凹槽是"模具目录"；
- 某个颜色的可见像素可能与多个槽形局部相容，必须找到同时满足所有槽的唯一全局分配；压叠次序本身是干扰信息，答案与次序无关。
```

## 5. 边框即图例的滑行程序

- tags:
  - operation:移动, move
  - operation:擦除, erase
  - object:边框, frame
  - object:标记像素, marker_pixel
  - object:精灵体, sprite
  - relation:颜色匹配边, color_matches_side
  - condition:颜色即指令, color_as_instruction
  - condition:滑到受阻, slide_until_blocked
- 参考题目题号: 11, 14, 16

### docstring

```text
把珠串读成程序：每颗珠的颜色指向同色边框方向，精灵朝该方向滑到受阻为止，逐珠执行。

输入结构：
- 网格下部是一圈单格厚矩形边框围住的场地，四条边各为一种颜色，四角为背景色。
- 场地内有一个精灵格（颜色不属于四种边色）和少量灰色障碍块。
- 边框上方隔一行背景处横排一串彩珠，珠色全部取自四种边色。

规则：
- 按从左到右的顺序读珠串；每颗珠令精灵向与珠同色的那条边的方向滑行，直到被边框内侧或灰色障碍挡住才停。
- 全部珠执行完后，输出去掉珠串，精灵画在最终位置，边框与障碍保持不变。

关键洞察：
- 四条边色不是装饰而是方向图例，珠色查边得方向、珠序即程序；
- "每珠走一格"的假设会在多数示例上失败——精灵是滑行而非单步，终点由障碍布局决定，同一珠串在不同障碍下终点完全不同。
```

## 6. 树形管道的分段推进

- tags:
  - operation:序列外推, sequence_extrapolation
  - operation:重涂色, recolor
  - object:面板帧, panel_frame
  - object:分隔行, separator_row
  - object:轴对齐线段, axis_aligned_segment
  - relation:等距堆叠, equally_spaced_stacking
  - relation:连通顺序, connectivity_order
  - condition:分段恒定推进, per_segment_constant_advance
  - condition:等长诱饵, equal_length_decoy
- 参考题目题号: 17, 2, 19

### docstring

```text
沿树形管道以直线段为单位推进液面，各分支同时前进，输出下一帧。

输入结构：
- 网格被通宽分隔行分成若干等大面板，每块面板画着同一条单格宽的树形通道，入口为根，含拐角与分叉点。
- 把通道按拐角与分叉点切成直线段并按距入口的段深度编号；第 n 块面板中，彩色液体恰好占据段深度不超过 n 的所有通道格，到达末端的分支停止。
- 从入口数起的前两段直线段长度相等。

规则：
- 输出一块面板大小的下一帧：液体扩展到段深度不超过 n+1 的所有通道格。
- 通道与面板其余内容原样保留。

关键洞察：
- 推进的度量单位是"直线段"而非格数或直线距离——前两段等长是诱饵，会诱导"每帧前进固定格数"的假设，该假设从第三帧起失效；
- 分叉处液体分头同时推进，分隔行把网格变成时间轴，答案是从未出现过的下一帧。
```
