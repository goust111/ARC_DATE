## 1. 标记锚定的模板姿态

- 参考题目题号: 8e5a5113 (4), 6d0160f0 (8), 898e7135 (5)
- 难度评审: 达标偏上
- tags:
  - operation:旋转, rotate
  - operation:翻转, flip
  - object:模板, template
  - object:分隔线, divider_line
  - object:槽位, slot
  - object:标记像素, marker_pixel
  - relation:锚点对位, anchor_alignment
  - condition:特征像素落点定姿态, special_pixel_lands_on_marker

### docstring

```text
把模板以能让其唯一特征像素恰好落在各槽位标记点上的姿态复制进每个空槽。

输入结构
- 灰色分隔线把画布分成若干等大的正方形槽位。
- 恰有一个槽位画有一个多色模板；模板中恰有一个黄色像素，且该像素不在
  模板方框的中心、对角线或中轴线上（保证 8 种姿态下落点互不相同）。
- 其余槽位除一个黄色标记像素外全为黑色背景。

规则
- 对每个空槽位，在模板的 8 种姿态（4 种旋转 × 是否镜像）中选出唯一能使
  模板黄色特征像素恰好落到该槽位标记像素所在格的姿态。
- 按该姿态将整幅模板画入槽位，标记像素被模板的黄色像素覆盖。
- 模板槽位保持不变。

关键洞察
- 标记像素不是要保留的内容，而是姿态方程的解锚点：特征像素在 8 种姿态
  下落点互不相同，一个标记点就唯一反解出整个槽位的旋转与镜像。
- 第一个示例中各槽姿态恰好像"依次旋转 90 度"（诱饵），后续示例打破，
  证明姿态由标记位置逐槽独立决定，与槽位顺序无关。
```

## 2. 绕墙波前染色

- 参考题目题号: aaef0977 (12), dd6b8c4b (10)
- 难度评审: 达标
- tags:
  - operation:填充, fill
  - operation:重涂色, recolor
  - object:墙壁障碍, wall_barrier
  - object:标记像素, marker_pixel
  - object:等距波前, wavefront
  - relation:可达性, reachability
  - relation:距离映射, distance_mapping
  - condition:测地距离, geodesic_distance
  - condition:循环色板, cyclic_palette

### docstring

```text
以每个标记为源，把它所在连通地板区域按绕墙最短步数染成循环色板的波前。

输入结构
- 画布由橙色地板和品红色墙壁组成，墙壁把地板分隔成若干 4 连通区域。
- 部分区域内各含恰好一个非橙非品红的标记像素，标记色属于固定色环
  绿-黄-黑-灰-红-青-栗-粉-蓝。

规则
- 保留所有墙壁。
- 对每个含标记的地板区域：标记格距离为 0、保持标记色；区域内其余每格
  染成色环中从标记色出发前进 d 步的颜色，d 为该格到标记格只经地板的
  最短 4 连通步数，超出色环长度后循环取色。
- 不含标记的区域保持橙色地板不变。

关键洞察
- 距离是绕墙的测地距离而不是曼哈顿距离：无墙示例中波前恰好是菱形同心
  环（诱饵），有墙时同一颜色的波前沿走廊拐弯、在薄墙两侧错开。
```

## 3. 按尺寸入腔而非按远近

- 参考题目题号: d6e50e54 (1), 913fb3ed (3), 91714a58 (2)
- 难度评审: 达标
- tags:
  - operation:滑动, slide
  - object:空心矩形, hollow_rectangle
  - object:实心矩形, solid_rectangle
  - relation:行列对齐, row_col_aligned
  - relation:尺寸吻合, dimension_fit
  - condition:唯一吻合者入腔, exact_fit_enters

### docstring

```text
所有实心矩形沿对齐方向滑向空心框，唯一内腔尺寸恰好吻合的矩形进入并填满
内腔，其余停在框外紧贴处。

输入结构
- 背景画布上有一个边厚 1 的空心矩形框，内腔为背景色。
- 另有若干互不相触的实心单色矩形，每个与框行对齐或列对齐（沿滑动方向
  的投影恰好落满内腔在该轴上的范围）且位于框外，滑动路径互不冲突。
- 恰有一个矩形的高宽与内腔完全相同；另有高宽恰为内腔转置的矩形作干扰。

规则
- 每个实心矩形沿其对齐的行或列直线滑向框。
- 高宽与内腔完全一致的矩形穿过框壁落入内腔并恰好填满。
- 其余矩形（包括仅在转置后才吻合的）滑到与框外壁相邻的位置停下。
- 框本身颜色与位置不变。

关键洞察
- 入腔资格由尺寸与内腔的严格吻合决定，与谁离框最近无关：第一个示例中
  最近者恰好也吻合（诱饵），后续示例中最近者并不吻合。
- 转置吻合不算吻合，因为滑动不带旋转。
```

## 4. 分布即钥匙的模板放大

- 参考题目题号: 42f83767 (15), 898e7135 (5), bf45cf4b (11)
- 难度评审: 达标偏上
- tags:
  - operation:像素放大, pixel_expand
  - operation:形状匹配, shape_match
  - operation:重涂色, recolor
  - object:模板遮罩, stencil_mask
  - object:索引网格, index_grid
  - relation:分布即钥匙, arrangement_as_key
  - condition:八方向匹配, all_orientations_matching

### docstring

```text
索引网格中每种颜色的像素分布形状本身指认它对应的镂空模板，再把每个像素
放大成该模板的染色副本。

输入结构
- 画布上部并排若干块同尺寸 k×k 的灰色正方形模板，各带背景色镂孔，孔
  图案两两在旋转翻转下不全等；其中存在孔数相同但形状不同的模板。
- 空行之下是一个多色索引网格，每种颜色的格子数等于恰好一块模板的孔数。
- 没有色卡图例。

规则
- 对索引网格中的每种颜色，取其所有格子组成的点阵并平移至外接框；该点
  阵与唯一一块模板的孔洞点阵在 8 种姿态（旋转、翻转）之一下全等，二者
  配对。
- 输出为索引网格按 k 倍放大：每个颜色为 c 的格子处印上与 c 配对的模板，
  模板灰色部分涂成 c，孔洞留背景色。

关键洞察
- 配对钥匙不是图例顺序（第一个示例中从左到右恰好也对，是诱饵），也不是
  孔数（存在孔数相同的模板堵死数数捷径），而是颜色在索引网格中的空间
  排布与模板孔洞图案的全等关系。
- 索引网格身兼两职：既是被放大的图像，又是配对的钥匙。
```

## 5. 噪声中的四角自证与象限填色

- 参考题目题号: af902bf9 (13), d89b689b (6), 91714a58 (2)
- 难度评审: 达标
- tags:
  - operation:填充, fill
  - operation:擦除, erase
  - object:角标记, corner_marker
  - object:噪声像素, noise_pixel
  - relation:行列对齐, row_column_alignment
  - relation:象限对应, quadrant_correspondence
  - condition:四角标记身兼两职, corners_dual_role

### docstring

```text
在散点中找出唯一恰好共两行两列的四个彩色像素，它们围出的矩形内部按象限
填上各自最近角的颜色，其余散点作为噪声擦除。

输入结构
- 黑色背景上散布约 7~10 个颜色各异的单像素。
- 恰有一组四个像素恰好占据两行与两列（构成矩形四角），其内部区域为空
  且高宽均为偶数。
- 其余像素与它们只存在成对的同行或同列巧合，凑不成第二个完整矩形。

规则
- 找到唯一四角对齐的像素组并保留这四个角像素。
- 把矩形内部（严格夹在两行两列之间的区域）按中心十字均分成四个象限，
  每个象限整体填成离它最近的那个角像素的颜色。
- 所有不属于该组的像素擦为背景。

关键洞察
- 角标记身兼两职：先以"两行两列"的对齐关系从噪声中自证身份，再各自为
  所辖象限提供填色。
- 成对的同行同列巧合是诱饵，四角齐备的完整性才是判据。
```

## 6. 交点遮挡还原绘制顺序

- 参考题目题号: e9bb6954 (7), c9f8e694 (19), 6d0160f0 (8)
- 难度评审: 达标偏上
- tags:
  - operation:重涂色, recolor
  - object:贯穿线, full_length_line
  - object:占位像素, placeholder_pixel
  - object:分隔线, separator_line
  - relation:遮挡定序, occlusion_order
  - relation:传递比较, transitive_comparison
  - condition:交点显后者, crossing_shows_later

### docstring

```text
由交点处谁盖住谁还原所有贯穿线的绘制先后，并把这一顺序依次填进下方的
灰色占位行。

输入结构
- 一条灰色分隔行把画布分为上下两部分。
- 上部画布内有若干条颜色互异的水平贯穿线与竖直贯穿线，它们按某个未知
  顺序先后画出，每个交点显示后画的那条线的颜色。
- 同向平行线之间没有交点。
- 下部有一行灰色占位像素，个数等于线的总数，其余为背景。

规则
- 对每对相交的线，交点颜色判定谁画在后。
- 平行线之间的先后没有直接交点可查，须经由与两者都相交的第三条线传递
  比较得到；由全部胜负关系恢复唯一的全序。
- 把占位像素从左到右依次涂成从最早画到最晚画的线色。
- 上部画布原样保留。

关键洞察
- 每个交点是一条"后者压前者"的胜负记录；两条平行线永不相交，它们的
  先后只能靠传递性间接推出。
- 绘制顺序与线的空间位置（左右、上下排列）无关，空间顺序是诱饵。
```
