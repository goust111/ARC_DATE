## 1. 遮挡链定角色的对角盖印

- 参考题目：652646ff、e619ca6e、447fd412
- tags:
  - operation:印章覆盖, stamp
  - operation:补全, reconstruct
  - object:实心矩形, solid_rect
  - relation:遮挡层序, occlusion_order
  - relation:对角偏移重复, diag_offset_repeat
  - condition:层序分配角色, depth_assigns_role
  - condition:尺寸决定步幅, size_determines_stride

### docstring

```text
从三个相互遮挡的实心矩形中读出层序，把最顶层矩形作为印章，沿对角方向以最底层矩形补全后的完整尺寸为步幅反复盖印。

输入结构：
- 黑色背景上有三个颜色互不相同的实心矩形，构成一条遮挡链：顶层矩形完整可见并压住中层，中层压住底层，顶层与底层互不接触。
- 被压住的矩形只露出残缺形状，但每个矩形四条边都至少露出部分像素，其真实外接框可由可见像素唯一恢复。

规则：
- 若某矩形的完整矩形区域内出现另一颜色的像素，则该颜色矩形位于其上方；据此排出三个矩形的上下层序。
- 最顶层矩形是印章图形；最底层矩形恢复后的高 h 与宽 w 是步幅。
- 以顶层矩形的位置为起点，向右下按偏移 (h, w)、(2h, 2w)……，向左上按偏移 (-h, -w)、(-2h, -2w)……反复盖印顶层矩形，越出网格的部分裁剪，直到副本完全出界为止。
- 原有三个矩形保持原样（含遮挡残缺），副本直接覆盖沿途像素。

关键洞察：
- 三个矩形分饰三角：遮挡关系是唯一的角色分配器——顶层给图形、底层给步幅、中层只负责把层序串成链；步幅取自那个被遮得最残缺、必须先补全外接框才能量出尺寸的矩形，而不是印章自身的尺寸（首例若按印章自身尺寸为步幅将得到错误答案）。
```

## 2. 跨容器的镜像搬运

- 参考题目：44f52bb0、7b6016b9、846bdb03
- tags:
  - operation:对称检测, symmetry_detection
  - operation:镜像搬运, mirror_transport
  - operation:修补, repair
  - object:环形墙, ring_wall
  - object:内部图案, interior_pattern
  - object:缺口像素, gap_pixel
  - relation:跨对象镜像配对, cross_object_mirror_pairing
  - condition:墙形定变换, wall_shape_defines_transform

### docstring

```text
把互为镜像的容器两两配对，用配对镜像把彼此的内容搬运合并，同时修补双方墙上的缺口。

输入结构：
- 黑色背景上有偶数个彼此分离的单色闭合环形墙容器，每面墙恰缺失一个像素。
- 每面墙自身形状不具有任何镜像对称性。
- 容器可两两配对：一对容器的墙在补上缺口后恰好互为镜像（左右镜像或上下镜像之一，外加平移）。
- 每对容器的内部各含一些另一色像素，是同一图案被拆开的两半：一半在 A 中，另一半以镜像形式在 B 中。

规则：
- 按"墙形状经镜像加平移后全等"给容器配对，并由墙的逐像素对应关系确定唯一的镜像变换。
- 把 A 的内部像素经该变换映入 B，与 B 的内容取并；反之亦然。
- 两面墙的缺口也由对方对应位置的墙像素修补。
- 输出中每对容器均封闭，且内含同一图案的两个互为镜像的完整副本。

关键洞察：
- 单个容器自身毫无对称可用，补全素材藏在另一个容器里；墙的轮廓是配对与对准的唯一钥匙——先把它当形状匹配问题解出等距变换，修缺口与并内容只是同一变换的两次使用。
```

## 3. 缺角编码层序

- 参考题目：846bdb03、652646ff、cf98881b
- tags:
  - operation:补全, reconstruct
  - operation:堆叠, stacking
  - operation:拓扑排序, topological_sort
  - object:角标像素, corner_marker
  - object:实心矩形, solid_rect
  - relation:缺失即遮挡, absence_encodes_occlusion
  - condition:幸存角定层序, surviving_corner_sets_depth

### docstring

```text
由残缺的四角标记恢复各实心矩形，并从"哪个角消失了"推断遮挡层序，重建完整的堆叠场景。

输入结构：
- 黑色背景上散布若干组同色像素，每组是一个轴对齐实心矩形的四角标记，但只画出了在最终堆叠场景中未被更上层矩形覆盖的角。
- 每组至少保留一对对角，足以唯一恢复矩形外接框。
- 任意两个区域重叠的矩形之间，至少一方有某个角落入另一方区域内。
- 输入中没有画出任何矩形本体，也没有其他深度提示。

规则：
- 由每组可见角标恢复矩形外接框。
- 若矩形 A 的某角位于矩形 B 的区域内：该角缺失则 B 在 A 上方；该角可见则 A 在 B 上方。
- 把所有上下关系汇总排序出整体层序，在黑画布上自底向顶依次绘制各实心矩形，后画覆盖先画。

关键洞察：
- 输入不是"待修复的角"而是"幸存的角"——缺失本身是信息：哪个角消失、消失在谁的地盘里，就是层序的全部编码；把缺角当噪声补齐会直接丢掉答案。
```

## 4. 枢轴嵌点金字塔

- 参考题目：db3e9e38、817e6c09、e3fe1151
- tags:
  - operation:排序, sorting
  - operation:平移, translate
  - operation:补缺, fill_missing
  - object:水平条, h_bar
  - object:嵌点像素, inset_pixel
  - object:金字塔, pyramid
  - relation:长度序即层序, length_order_is_layer
  - condition:等差缺项标记色补, missing_term_marker_color
  - condition:名次反推行号, rank_backsolves_row

### docstring

```text
围绕带嵌点的枢轴条把散落横条按长度插层成金字塔，等差数列缺失的一层用嵌点颜色补画。

输入结构：
- 黑色背景上散落若干互不接触的水平条，长度均为奇数且互不相同。
- 全部长度构成公差为 2 的等差数列，且恰缺中间一项。
- 恰有一条的正中格是一个异色嵌点像素——它是枢轴条；其余条颜色各异且无嵌点。

规则：
- 枢轴条保持原位，嵌点保留。
- 全部长度（含缺失项）从长到短对应金字塔自底到顶的连续各行；枢轴条的长度名次决定它在塔中的层位，据此反推塔底所在行。
- 其余条擦除后按各自长度放入对应行，并居中对齐嵌点所在列。
- 缺失长度的那一层用嵌点颜色画出居中横条。

关键洞察：
- 锚不是底——枢轴条可能是塔的任何一层，比它长的条要垫到它下方去；嵌点身兼三职：标识枢轴、给出中心列、充当缺失层的颜色；条在输入中的高低位置与长度顺序故意错乱是排列诱饵，由长度名次反推行号才是装配入口。
```

## 5. 溢流口钳制水位

- 参考题目：e45ef808、7b6016b9、41ace6b5
- tags:
  - operation:洪泛填充, flood_fill
  - operation:填充, fill
  - object:地形轮廓, terrain_contour
  - object:缺口像素, gap_pixel
  - relation:逃逸路径, escape_path
  - condition:溢流口定水位, spillway_sets_level

### docstring

```text
向起伏地形的盆地注水，水只能水平或向下流动，能经沿口或墙上缺口流出网格的格子不积水。

输入结构：
- 单一地形色构成一块与底边相连的 4-连通实心地形，轮廓起伏形成若干盆地，其余为黑色背景。
- 某些盆地的侧壁内部被挖去恰好一个像素形成穿墙缺口，该行上盆地内外的背景经此连通。
- 网格左右边界与底边之外视为排水口。

规则：
- 一个背景格积水，当且仅当不存在从它出发、每一步走向同行相邻背景格或正下方背景格、最终越出网格左右边界或底边的路径。
- 所有积水格涂蓝，地形与其余背景保持不变。

关键洞察：
- 密封盆地的水面停在两侧较低沿口的高度；带缺口的盆地并非简单"漏干"——缺口是新的溢流口，把水位钳制在缺口所在行，缺口以下的水依然留存。识别"只能水平与向下流动"的逃逸模型，才能同时解释沿口水位与半漏盆地。
```

## 6. 内嵌示范对的规则迁移

- 参考题目：65b59efc、846bdb03、44f52bb0
- tags:
  - operation:解码, decoding
  - operation:变换施加, apply_transform
  - object:示范对, demo_pair
  - object:图案精灵体, pattern_sprite
  - object:分隔线, separator_line
  - relation:示范定义变换, demo_defines_transform
  - condition:逐例归纳, per_instance_induction

### docstring

```text
网格一角内嵌一对"变换前到变换后"的示范图案，把从示范中归纳出的那一种变换施加到主区的每个图案上。

输入结构：
- 网格由一条分隔线分成小示范区与主区。
- 示范区并排放着两个同尺寸小图案，左为变换前、右为变换后。
- 主区散布若干与示范同尺寸的图案。
- 每个谜面实例的示范所体现的变换不同，可能是旋转、某轴镜像或一对颜色互换；示范图案足够不对称，使所体现的变换唯一可辨。

规则：
- 比对示范对，确定唯一能把左图变成右图的变换。
- 对主区的每个图案绕其自身外接框中心就地施加同一变换。
- 示范区与分隔线原样保留。

关键洞察：
- 训练示例之间没有共同的具体变换可归纳——真正共享的规则是"从画面自带的示范对里现学变换再迁移"；把示范区误当作普通对象处理会在第二个示例上立即失败。
```

## 7. 标记方块的极性缩放盖印

- 参考题目：447fd412、48131b3c、65b59efc
- tags:
  - operation:像素放大, pixel_scaling
  - operation:颜色反转, color_invert
  - operation:印章覆盖, stamp
  - object:模板, template
  - object:标记方块, marker_square
  - relation:缩放对应, scale_correspond
  - condition:边长定缩放因子, side_sets_scale
  - condition:颜色定极性, color_sets_polarity

### docstring

```text
把角落模板按各标记方块的边长放大后盖印到方块处，方块颜色决定盖正片还是负片。

输入结构：
- 网格角落有一个灰框圈出的 m×m 两色小板（前景色 F 与黑色背景），是模板。
- 主区散布若干实心 k×k 方块（k 可各不相同），颜色为 F 或另一色 G。

规则：
- 每个方块被替换为模板的 k 倍像素放大图章，以方块左上角为原点覆盖 mk×mk 区域，越出网格部分裁剪。
- F 色方块盖正片：模板 F 处画 F，黑处留背景。
- G 色方块盖负片：模板黑处画 G，F 处留背景。
- 模板与灰框原样保留。

关键洞察：
- 方块的边长与颜色是两条独立的指令通道：边长给倍率，颜色给极性；负片不是简单换色，而是掩码取反之后再着另一种颜色。
```

## 8. 图例配对的有向连锁湮灭

- 参考题目：41ace6b5、8f215267、cf98881b
- tags:
  - operation:重力下落, gravity_fall
  - operation:消除, annihilate
  - operation:解码, decoding
  - object:图例色对, legend_pair
  - object:方块, cell_block
  - object:石块, stone
  - relation:栈式配对, stack_pairing
  - condition:有向湮灭对, directed_annihilation_pair
  - condition:落定后判定, judge_after_settle

### docstring

```text
按顶部图例给出的有向湮灭对，让主区彩色格下落堆积并连锁湮灭，输出最终稳定画面。

输入结构：
- 网格顶部两行为图例区，与主区之间隔一条分隔线：图例由若干竖直色对组成，上格颜色 X、下格颜色 Y，表示"X 恰好落在 Y 正上方时二者湮灭"。
- 主区各列中悬浮若干彩色单格（列内彼此有空隙），混有少量灰色石块格；灰色从不出现在图例中。

规则：
- 主区所有格在各自列内竖直下落、保持列内相对次序，堆积到底边或下方格之上。
- 落定后，凡某格与其正下方格构成图例中的一个有向对（上格色在图例上位、下格色在图例下位），这两格立即一同湮灭，其上方的格继续下落补位；如此连锁直至稳定。
- 图例区与分隔线原样保留，主区输出最终堆叠。

关键洞察：
- 湮灭键是有向的——图例内部的上下位置就是要求的空间顺序，同一对颜色反过来叠不消；同色相邻也不消，除非图例明确列出；湮灭在落定后判定而非按输入相邻关系，每次湮灭暴露新的接触面，连锁能蚀穿整列，而灰石与一切未列入图例的接触是天然隔断。首个示例会诱导"同色相邻即消"或"无向配对"的错误读法，后续示例将其推翻。
```
