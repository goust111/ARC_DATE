## 1. 门径遍历

- 参考题目题号: 1 (c3202e5a)、15 (cf133acc)、16 (b94a9452)
- tags:
  - operation:提取, extract
  - operation:排序, sorting
  - object:分隔线, separator_line
  - object:缺口通道, gap_door
  - object:网格单元, grid_cell
  - relation:邻接连通, adjacency_link
  - condition:唯一路径遍历, unique_path_traversal
  - condition:缺口即通道, gap_as_passage

### docstring

```text
沿分隔线缺口构成的唯一通道遍历格阵，按访问顺序输出各格中心颜色组成的色条。

输入结构
- 黑色背景的方形网格被一种非黑分隔色的完整横竖线等分为方格阵。
- 每个方格中心有一个彩色像素，颜色互不相同；恰有一个方格的中心是
  2×2 同色方块，标记起点格。
- 分隔线上散布若干单像素黑色缺口，每个缺口恰好连通相邻两格；全部
  缺口把一部分格子连成一条不分叉的链，另有个别格子不与链连通。

规则
- 把缺口视为相邻格之间的门，从起点格出发沿链走到尽头，路线唯一。
- 输出为 1×n 横条，按访问顺序依次写入每个被经过方格的中心颜色，
  起点色在最左。
- 不在链上的格子是干扰项，不进入输出。

关键洞察
- 分隔线上的破损不是噪声而是门；输出的颜色次序由格间拓扑路径决定，
  与格子的画面位置和阅读顺序无关。
```

## 2. 扩张竞速

- 参考题目题号: 17 (52fd389e)、2 (f0df5ff0)、10 (9344f635)
- tags:
  - operation:扩展填充, expansion_fill
  - operation:计数, counting
  - object:矩形块, rectangular_block
  - object:控制像素, control_pixel
  - relation:同步扩张, simultaneous_growth
  - condition:计数决定扩展量, count_determines_expansion
  - condition:冲突优先级, conflict_priority
  - condition:仅填背景格, only_bg_filled

### docstring

```text
各矩形块以内嵌计数为轮数、以控制色同步向外逐圈扩张光环，相遇处归计数更多的块。

输入结构
- 背景色占主导；若干彼此分离的实心黄色矩形块。
- 每块内部嵌有恰一种非黄控制色的若干像素，不同块的控制像素数
  互不相同。

规则
- 所有块同时逐轮扩张：每轮把各自当前占域外侧一圈的背景格染成
  自己的控制色；一块共扩张 k 轮，k 为该块的控制像素数。
- 同一轮中两块争抢同一格时，该格归控制像素数较多的块。
- 原黄色块与控制像素保持原样，扩张只覆盖背景格。

关键洞察
- 光环不是各块独立画完再按大小叠放：先到先得的同步生长使近处的
  小计数块能挡住远处的大计数块；内嵌计数被双重使用——既是扩张
  轮数上限，又是同轮冲突时的优先权。
```

## 3. 对角生成与奇偶抵消

- 参考题目题号: 6 (952a094c)、10 (9344f635)、7 (48634b99)、16 (b94a9452)
- tags:
  - operation:填充, filling
  - operation:计数, counting
  - object:成对像素, paired_pixels
  - object:隐形矩形, implicit_rectangle
  - relation:对角生成, diagonal_generation
  - relation:尺寸排序, size_ordering
  - condition:覆盖奇偶决定显隐, parity_determines_visibility
  - condition:最小覆盖者取色, smallest_cover_colors

### docstring

```text
每对同色像素张成一个隐形实心矩形，被覆盖奇数次的格子着色、偶数次的格子留黑，奇数格取覆盖者中面积最小矩形的颜色。

输入结构
- 黑色背景上散布彩色像素，每种颜色恰好出现两枚，且两枚既不同行
  也不同列。
- 各像素对张成的矩形面积互不相同；矩形之间存在两重与三重交叠
  区域。

规则
- 为每种颜色生成以其像素对为对角顶点的实心矩形区域，矩形本身
  从未在输入中画出。
- 统计每个格子被多少个矩形区域覆盖：覆盖次数为偶数（含 0）的
  格子输出黑色；覆盖次数为奇数的格子染成覆盖它的诸矩形中面积
  最小者的颜色。

关键洞察
- 矩形仅由两枚角像素隐式生成；交叠区不是遮挡叠放关系而是奇偶
  抵消——两重交叠互相挖空，三重交叠重新显色，且颜色由面积最小
  的覆盖者决定。看似"层序遮挡加交叠透明"的读法会被三重交叠区
  证伪。
```

## 4. 折行周期修复

- 参考题目题号: 5 (58c02a16)、19 (db0c5428)、20 (e21d9049)、12 (e76a88a6)
- tags:
  - operation:中心重建, center_reconstruct
  - operation:重涂色, recolor
  - object:块阵列, block_array
  - object:模板, template
  - object:周期序列, periodic_sequence
  - relation:块级排布即数据, block_layout_as_data
  - condition:行主序折行周期, row_major_wrapped_period
  - condition:模板共享, shared_template

### docstring

```text
大图由同一模板的多个单色变体拼成，块颜色沿行主序构成周期序列，重建被整块抹去的子块。

输入结构
- 网格由若干同尺寸子块拼成；除一个子块被整块抹成背景色外，每个
  子块都是同一个二值模板图案的单色描绘，各块描绘颜色不同。
- 把每块的描绘颜色按行主序（逐行从左到右）排成一列，恰是一个短
  色序列的周期重复，且周期长度不整除每行块数，故二维排布上既不
  周期平铺也不对称。

规则
- 从任一完好子块读出共享的二值模板。
- 把块颜色按行主序线性化，识别其周期序列，推出被抹位置应有的
  描绘颜色。
- 用该颜色描绘模板填回被抹位置，输出修复后的整幅网格。

关键洞察
- 画面是"图案的图案"：块内内容处处相同，信息全在块颜色的排布里；
  而这个二维排布其实是一维周期序列的折行。缺失块的颜色由周期
  推出，内容由所有块共享的模板提供；对称补全与邻块复制都不成立。
```

## 5. 条高定序的周期铺设

- 参考题目题号: 7 (48634b99)、20 (e21d9049)、15 (cf133acc)
- tags:
  - operation:排序, sorting
  - operation:周期扩展, periodic_expand
  - operation:重涂色, recolor
  - object:竖条, vertical_bar
  - object:标记像素, marker_pixel
  - object:周期序列, periodic_sequence
  - relation:尺寸排序, size_ordering
  - condition:高度即序号, height_as_rank
  - condition:锚定相位, anchored_phase

### docstring

```text
按竖条高度排序读出顶端色序列，以最高条所在列为锚，将序列周期性铺满顶行。

输入结构
- 黑色背景；最底行立着若干互不相邻、单像素宽、同为灰色的竖条，
  高度互不相同。
- 每根竖条正上方一格有一个彩色数据像素，颜色可重复；顶行为空。

规则
- 将竖条按高度从矮到高排序，依次读出各自数据像素的颜色，得到一个
  色序列。
- 在顶行中，最高条所在列写入序列的末元素；再以序列长度为周期，
  从该锚点向左右两侧循环延展，铺满整个顶行。
- 竖条与数据像素保持不变。

关键洞察
- 条的左右位置是诱饵，真正的次序键是高度——条形阵是"乱序存储
  加排序键"的序列；铺设相位不从行首开始，而由最高条的列位置锚定。
```

## 6. 渗漏判密与内框继色

- 参考题目题号: 9 (83302e8f)、6 (952a094c)、15 (cf133acc)、1 (c3202e5a)
- tags:
  - operation:洪泛填充, flood_fill
  - operation:重涂色, recolor
  - object:空心矩形, rectangular_frame
  - object:缺口, gap
  - object:封闭背景区域, enclosed_bg
  - relation:包含, containment
  - relation:边界连通, border_connectivity
  - condition:密闭区染色, sealed_region_fill
  - condition:最内包围框继色, innermost_frame_color

### docstring

```text
背景之水自画布边缘经框上缺口渗入，只有未被浸到的密闭区按其最内包围框的颜色填充。

输入结构
- 单一背景色画布上有多个单像素厚的彩色空心矩形框，可相互嵌套，
  框与框互不接触。
- 部分框的边上开有单像素背景色缺口。

规则
- 从画布边缘对背景做连通渗透，渗透可穿过缺口进入框内。
- 渗透未及的每个背景连通区域，整体染成包围它的最内层矩形框的
  颜色。
- 被渗透到的背景保持背景色，所有框（含缺口）原样保留。

关键洞察
- 一个框破损会让它的内外连成同一片区域并交出染色权：染不染取决于
  对画布边缘的连通性，染什么色取决于包含链上最内层的包围框——
  看似"每个框内部按嵌套染色"，但破框链会让深处区域也保持背景。
```
