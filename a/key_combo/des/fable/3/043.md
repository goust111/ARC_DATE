## 1. 压缩域镜像修复

- 参考题目: 6 (ce8d95cc)、15 (5b692c0f)
- tags:
  - operation:压缩, compression
  - operation:对称补全, symmetric_completion
  - operation:拉伸, stretch
  - object:重复行, dup_row
  - object:重复列, dup_column
  - object:对称轴, symmetry_axis
  - object:损伤区块, damage_block
  - relation:压缩对应, compressed_correspondence
  - condition:对称仅在压缩域成立, symmetry_in_core_only

### docstring

```text
将网格按相邻重复行列折叠成核图案，在核内做左右镜像修复，再映回原网格补好损伤色区域。

输入结构
- 网格是某个小核图案经"相邻行成段复制、相邻列成段复制"得到的拉伸图。
- 核图案关于其中央列左右对称；轴两侧对应带的复制宽度一般不相等，
  因此整幅图在原尺寸下并不左右对称。
- 若干处像素被统一的损伤色覆盖，每处损伤恰好覆盖一个行带与列带的
  交矩形；损伤色不属于核图案调色板，且损伤不会同时出现在一对镜像位置。

规则
- 将相邻完全相同的行、列各自折叠为一份，得到核图案。
- 核中每个损伤色格取其关于中央列的镜像格颜色进行修复。
- 把修复后的核按原带宽序列重新展开，输出与输入同尺寸的修复图。

关键洞察
- 镜像对应关系只在压缩核中成立；由于轴两侧带宽不等，直接在原网格
  按列坐标反射会取到错误颜色，必须先折叠、再镜像、再展开。
```

## 2. 拉伸档案互换

- 参考题目: 6 (ce8d95cc)、7 (a59b95c0)、13 (9841fdad)
- tags:
  - operation:压缩, compression
  - operation:拉伸, stretch
  - object:重复行, dup_row
  - object:重复列, dup_column
  - relation:压缩与展开, compress_expand
  - relation:行列互换, row_col_exchange
  - condition:带宽即数据, run_length_as_data

### docstring

```text
把拉伸图折叠为方核后，用原来的列带宽序列去拉伸行、行带宽序列去拉伸列，重新展开输出。

输入结构
- 网格是一个 k×k 方核经带状复制得到的拉伸图：核第 i 行被复制为
  宽 r_i 的行带，第 j 列被复制为宽 c_j 的列带。
- 两个带宽序列一般不同。

规则
- 折叠相邻相同的行、列，恢复 k×k 方核。
- 输出把方核第 i 行复制 c_i 份、第 j 列复制 r_j 份后的展开图。
- 图案本身不转置、不镜像，只有横竖拉伸档案互换。

关键洞察
- 相邻重复不是要丢弃的冗余，而是两份可互换的"拉伸档案"；
  输出尺寸恰为输入尺寸的转置，但内容方向不变，只有厚薄互换。
- 诱饵：看到尺寸转置容易误答"转置整幅图"，内容方向不变即排除。
```

## 3. 配额路径与绕行连锁

- 参考题目: 5 (b2bc3ffd)、8 (c87289bb)、2 (4364c1c4)
- tags:
  - operation:平移, translate
  - operation:计数, counting
  - operation:绕行, detour
  - object:全宽条纹, full_width_stripe
  - object:前景对象, foreground_object
  - relation:排列顺序, ordering
  - condition:面积即路程预算, area_as_path_budget
  - condition:碰撞绕行, collision_detour
  - condition:连锁堵塞, chain_blocking

### docstring

```text
各对象按初始高度由高到低依次沿"上升—受阻绕行"路径移动，每走一格消耗一点配额，配额等于自身像素数。

输入结构
- 网格有主导背景色，顶部有一条全宽非背景条纹作为天花板。
- 条纹下方散布若干四连通单色对象，各对象初始最高行互不相同。

规则
- 按初始最高行从高到低依次处理对象，先定格的对象成为后续对象的障碍。
- 每个对象的移动配额等于其像素数，每移动一格（无论方向）消耗一点：
  能上移一步则上移；若上移会与已定格对象重叠，则朝"列跨度更快离开
  阻挡物列跨度"的一侧水平移动（距离相同时向右），一旦上方不再受阻
  立即恢复上移。
- 若被天花板阻挡则无绕行，就地停止并作废剩余配额；配额耗尽即定格。
- 原位置清为背景，条纹不动。

关键洞察
- 面积不是位移量而是"路程预算"，绕行的水平步也在花这笔预算；
  先落定的对象改变后来者的路径，形成连锁。
- 诱饵：部分示例无阻挡，表现为"上移自身像素数"的纯面积规则。
```

## 4. 哑口送色

- 参考题目: 12 (e12f9a14)、10 (d35bdbdc)
- tags:
  - operation:重涂色, recolor
  - operation:擦除, erase
  - object:带框块, framed_block
  - object:框架缺口, frame_gap
  - relation:端口对准, port_alignment
  - relation:隐形送色网, invisible_transfer_net
  - condition:缺口方向定向, gap_determines_dir
  - condition:无接收即擦除, unfed_erased

### docstring

```text
每个框缺口向外发出一条从不画出的直线信号，命中别的框缺口时把接收框的内块染成发送块的颜色，没有收到信号的内块被整体擦除。

输入结构
- 背景为最多色；墙色构成若干 4×4 方框，各围住一个 2×2 单色块。
- 每个方框的墙上恰有一个缺口像素。

规则
- 每个缺口沿其所在边的外法线方向发出一条隐形信号线；信号线只穿过
  背景格，碰到任何墙像素即失效，射出网格也失效。
- 若信号线到达的第一个非背景格恰是另一框的缺口位置（从正面射入），
  则该接收框的 2×2 内块在输出中被染成发送框内块的原始颜色。
- 所有信号同时结算、均使用输入中的原始颜色；每块至多收到一条信号。
- 未收到任何信号的内块整体擦除为背景；框与缺口保持不变，信号线
  在输出中不画出。

关键洞察
- 画面上从未出现任何连线，必须从缺口的几何对准推断一张隐形的
  有向送色网；颜色沿网一步传递，孤立的块被判定为断线而清空。
```

## 5. 条纹遮挡下的并集重建

- 参考题目: 17 (1caeab9d)、11 (57aa92db)、20 (39a8645d)
- tags:
  - operation:对齐, align
  - operation:补全, completion
  - operation:裁剪, crop
  - object:精灵体, sprite
  - object:锚点标记, anchor_marker
  - object:遮挡条纹, occluding_stripe
  - relation:形状相同, shape_identity
  - condition:并集恢复完整形, union_reconstruction
  - condition:可见最多定颜色, max_visible_color

### docstring

```text
把被灰条纹各自遮去不同部分的同形异色副本按锚点对齐取并集，输出完整形状的裁剪图，用可见像素最多的副本颜色着色。

输入结构
- 黑背景上有同一形状的若干异色副本，每个副本含一个白色锚点像素，
  锚点在形状内的相对位置相同。
- 若干灰色通栏条纹覆盖网格，遮去各副本的不同部分；没有任何一个
  副本是完整的，且恰有一个副本可见像素最多。

规则
- 以锚点为原点对齐所有副本，把各副本可见的形状像素取并集，
  得到完整形状掩码。
- 统计各副本可见形状像素数，取唯一最大者的颜色。
- 输出完整掩码最小包围盒的裁剪图：形状用该颜色，锚点位置画白色，
  其余为黑。

关键洞察
- 完整形状从未在画面出现，只存在于跨副本的并集中；可见最多的副本
  自己也缺一块，照抄任何单个副本都会出错。
```

## 6. 隐轴选段与对角反射

- 参考题目: 14 (aa300dc3)、15 (5b692c0f)
- tags:
  - operation:重涂色, recolor
  - operation:镜像, mirror
  - object:对角线段, diagonal_segment
  - object:对称轴, symmetry_axis
  - object:精灵体, sprite
  - relation:平行对角线带, parallel_diagonal_band
  - condition:最长线段选中, longest_selected
  - condition:奇数带选中间线, odd_band_middle_line
  - condition:选段即镜面, selected_segment_as_mirror

### docstring

```text
找出黑色对角线段中的最长者（奇数宽平行带取中线），把它所在的整条对角线当作镜面，将彩色精灵反射出一份同色副本，并把选中线段染青。

输入结构
- 灰色场地内嵌黑色像素构成的若干对角线段，可能形成相邻平行带。
- 另有一个远离黑色区域的多像素彩色精灵。

规则
- 沿两个对角方向找出所有极大连续黑段，取长度最大者；若最长候选
  构成相邻平行的奇数条带，取带的中间一条。
- 把该线段所在的整条对角线延长为镜面：保留原精灵，将其每个像素
  反射到镜面另一侧画出同色副本。
- 把选中的黑段染成青色，其余黑段不动。

关键洞察
- 线段选择规则给出的是一条隐藏直线笔画，它的真正作用不是被标记
  而是充当整幅图的反射轴。
- 诱饵：部分示例最长段唯一、无带歧义，容易漏掉"奇数带取中线"层；
  只染青不反射也能解释纯选段视角，精灵副本才暴露轴的身份。
```

## 7. 排布即自身

- 参考题目: 20 (39a8645d)、5 (b2bc3ffd)、7 (a59b95c0)
- tags:
  - operation:计数, counting
  - operation:裁剪, crop
  - object:精灵体, sprite
  - relation:形状相同, shape_identity
  - relation:跨尺度自相似, cross_scale_self_similarity
  - condition:排布拼出自身, layout_equals_shape
  - condition:数量等于面积, count_equals_area

### docstring

```text
找出"各副本的空间排布恰好拼出放大的自身形状"的那类精灵，输出它的单个拷贝。

输入结构
- 主导背景上散布多类小单色精灵，同形同色为一类，每类出现多次；
  各副本均无旋转翻转、彼此不相接。
- 恰有一类，其所有副本的包围盒中心落在一个等距点阵上，把有副本的
  点阵位置视为像素，得到的图形恰是该精灵自身的形状。
- 其余类别的排布图形与自身形状不符（可能恰好拼出别的类的形状，
  作为干扰）；另有一类的副本数恰好也等于其单体面积但排布与自身
  不符，堵住纯计数捷径。
- 出现次数最多的类与像素面积最大的类都不是答案类。

规则
- 对每一类精灵，取其各副本包围盒中心，检验这些中心是否构成等距
  点阵上的图形且该图形与该精灵自身的形状一致。
- 输出唯一满足自相似条件类别的单个精灵最小包围盒裁剪，颜色不变，
  背景为背景色。

关键洞察
- 要在"精灵内部的形状"与"副本之间的排布"两个尺度上看到同一个图形；
  副本数等于自身像素数只是自相似的必然推论，可作筛选入口但不充分。
- 诱饵：最高频类、最大类、以及"数量等于面积"的假不动点类全部不是
  答案，唯有跨尺度形状一致才是判据。
```
