## 1. 量子引力下落

- tags:
  - operation:平移, translate
  - object:实心矩形, solid_rectangle
  - relation:下方障碍, obstacle_below
  - condition:步长为自身高度, step_equals_own_height
  - condition:碰撞前停止, stop_before_collision
  - condition:自下而上结算, settle_bottom_up
- 参考题目题号：1 (5521c0d9)、12 (2c608aff)、2 (bd283c4a)

### docstring

```text
让每个实心矩形以自身高度为步长向下坠落，在碰撞发生前的最后一步停住。

输入结构：
- 黑色背景网格中散布若干互不相同颜色的实心正交矩形。
- 矩形之间列范围可能重叠；底边缘之下即为地面。
- 同一水平层不会出现列范围相交的并列矩形，结算次序无歧义。

规则：
- 从最靠下的矩形开始逐个结算：矩形反复向下平移，每步移动距离恰为自身高度。
- 当再走一步会与地面或已结算矩形重叠时停止，保留当前位置。
- 已停稳的矩形成为上方后续矩形的新障碍，依次向上处理完所有矩形。

关键洞察：
- 下落不是连续贴地：步长被自身高度量子化，矩形与支撑面之间通常留有
  小于自身高度的空隙；个别矩形恰好落满贴地，会诱导"普通重力"的错误假设。
- 结算顺序自下而上，先落者改变后落者的落点，落点存在链式依赖。
```

## 2. 孔洞牵引

- tags:
  - operation:平移, translate
  - operation:计数, counting
  - operation:重涂色, recolor
  - operation:擦除, erase
  - object:封闭区域, enclosed_region
  - object:边界标记, boundary_marker
  - relation:行列对齐, row_col_align
  - condition:孔洞数决定位移, hole_count_determines_shift
  - condition:忽略干扰项, ignore_distractors
- 参考题目题号：17 (f341894c)、18 (e3721c99)、12 (2c608aff)、1 (5521c0d9)

### docstring

```text
让每个被边界标记锁定的灰色精灵沿标记方向平移其孔洞数的格数，并染成标记颜色。

输入结构：
- 黑色背景内散布若干灰色精灵，每个精灵含 0 个或多个封闭孔洞。
- 网格外边界上有若干彩色标记像素，每个标记所在的行或列恰好穿过
  唯一一个灰色精灵。
- 部分灰色精灵不与任何标记对齐，是干扰项。

规则：
- 将每个标记与其行/列穿过的灰色精灵配对。
- 数出该精灵的封闭孔洞数 k，把精灵朝标记方向平移 k 格。
- 平移后的精灵整体重涂为标记颜色，孔洞处仍为背景。
- 未被任何标记锁定的灰色精灵从输出中抹去；标记像素保留原位。

关键洞察：
- 位移的方向来自配对标记，位移的距离来自精灵自身的拓扑（孔洞数），
  两条信息缺一不可。
- 无孔洞的精灵即使被标记锁定也只改色不移动，是对"有标记必移动"
  直觉的反例。
```

## 3. 裁判色条

- tags:
  - operation:逐像素比较, cell_by_cell_comparison
  - operation:重涂色, recolor
  - object:分隔列, separator_column
  - object:色彩图例, color_legend
  - object:二值掩码, binary_mask
  - relation:图例映射, legend_mapping
  - relation:面板对齐, panel_alignment
  - condition:异或差异判定, xor_difference
  - condition:行缝色决定输出色, row_seam_color_determines_output
  - condition:背景缝行关闭输出, bg_seam_row_gates_off
- 参考题目题号：11 (34b99a2b)、4 (1be83260)、10 (363442ee)

### docstring

```text
以中缝色条为逐行图例，把左右两块掩码的异或差异按所在行染成该行缝色，
缝色为背景的行差异被抹除。

输入结构：
- 网格宽度为奇数，正中一列是分隔条，左右为等大的单色二值掩码。
- 两侧前景色不同、背景色相同。
- 分隔条逐行取色：多数行为彩色，少数行与背景同色。

规则：
- 输出为单侧面板大小，先整体填背景色。
- 将左右面板逐格对齐比较，仅一侧为前景的格子记为差异格。
- 每个差异格染成其所在行分隔条像素的颜色。
- 分隔条为背景色的行视为关闭：该行差异格不输出。

关键洞察：
- 分隔条不是无信息的隔断，它同时是逐行调色图例和逐行开关。
- 两侧前景本身的颜色与输出颜色无关，它们只提供掩码。
```

## 4. 无形模板

- tags:
  - operation:补全, completion
  - operation:透明叠加, transparent_overlay
  - object:碎片, fragment
  - object:标记像素, marker_pixel
  - object:模板精灵体, template_sprite
  - relation:标记对齐, marker_alignment
  - condition:模板由碎片并集重建, template_from_fragment_union
- 参考题目题号：15 (fd096ab6)、13 (414297c0)、6 (83eb0a57)

### docstring

```text
把所有碎片按各自的红色锚点对齐取并集重建模板，再把每个碎片补全成完整模板。

输入结构：
- 背景上散布若干互不相同颜色的碎片，每个碎片恰含一枚红色锚点像素。
- 每个碎片都是同一个未知模板形状的一部分，且都以红色锚点对应模板的
  同一个格位。
- 没有任何一个碎片是完整的模板；所有碎片对齐后的并集恰为完整模板。

规则：
- 以红色锚点为原点，记录每个碎片相对锚点的占格集合。
- 将所有碎片的占格集合取并集，得到完整模板掩码。
- 对每个碎片，按其锚点位置把完整模板铺回原地：新补的格子用该碎片
  自身的颜色，锚点保持红色。

关键洞察：
- 模板从未在画面上被完整画出，它只存在于所有残片的并集之中。
- 沿用"选最大碎片当模板"的直觉会失败，因为每个碎片都有缺口。
```

## 5. 方位印章

- tags:
  - operation:印章覆盖, stamp
  - operation:旋转, rotate
  - object:精灵体, sprite
  - object:标记像素, marker_pixel
  - object:分隔列, divider_column
  - object:槽位, slot
  - relation:标记颜色配对, marker_color_pairing
  - relation:方向指示, direction_indication
  - condition:标记方位决定旋转, marker_side_determines_rotation
  - condition:忽略干扰项, ignore_distractors
- 参考题目题号：10 (363442ee)、13 (414297c0)、20 (3c9b0459)、17 (f341894c)

### docstring

```text
右侧槽内标记用颜色挑选左侧哪个源精灵、用贴靠方位决定其旋转，
把选中的精灵转向后盖入槽位。

输入结构：
- 一条通高单色分隔列把画布分成左右两部分。
- 左侧纵向排列两到三个方形源精灵：每个精灵主体为一种独有颜色，
  且都在顶边带一枚共享"鼻尖"色像素，源图中鼻尖一律朝上。
- 右侧被划分为若干等大方形槽位；部分槽位内有一枚彩色标记像素，
  紧贴槽位四条边之一的中点。

规则：
- 对每个有标记的槽位：标记颜色与哪个源精灵的主体色相同，就选中
  哪个精灵。
- 将选中的精灵旋转，使鼻尖朝向标记所贴靠的那条边。
- 把旋转后的精灵盖入槽位，覆盖并吞掉标记像素。
- 标记颜色与任何源精灵主体色都不匹配的槽位是干扰项，保持原样。
- 无标记槽位、分隔列与左侧源精灵保持不变。

关键洞察：
- 一枚标记像素同时编码两条独立信息：颜色是"选谁"，槽内方位是"转多少"。
- 只看鼻尖恰好都朝上的示例会误判为原样复制；无匹配色的标记是对
  "有标记必盖章"直觉的诱饵。
```

## 6. 对射贯穿

- tags:
  - operation:射线延伸, ray_extend
  - operation:连线, draw_line
  - operation:重涂色, recolor
  - object:矩形框架, rectangular_frame
  - object:孤立像素, isolated_pixel
  - relation:行列对齐, row_col_align
  - relation:对置配对, opposing_pairing
  - condition:同色对射贯穿, same_color_pair_penetrates
  - condition:异色撞墙停止, mismatched_ray_stains_wall
- 参考题目题号：12 (2c608aff)、16 (b527c5c6)、3 (ac605cbb)、11 (34b99a2b)

### docstring

```text
孤立像素向空心矩形框发射同色射线，只有与对侧同色像素成对时才能贯穿框体
连成通线，否则撞墙留痕。

输入结构：
- 黑色背景上有一个大的单色空心矩形框，框内为空。
- 框外散布若干孤立彩色像素，每个像素的行或列穿过框内区域。
- 有的像素在框对侧存在同行/同列的伙伴，伙伴可能同色也可能异色。

规则：
- 每个像素沿其与框对齐的方向朝框发射射线，射线用像素自身颜色填充
  沿途背景格。
- 若对侧同一行/列存在同色像素：两条射线贯穿框壁，在框内连成一条
  完整直线，被穿过的两处框壁格也改为该颜色。
- 若无同色对侧伙伴（无伙伴或伙伴异色）：射线止于框壁外侧，并把撞上
  的那一格框壁染成像素颜色，框内不留任何痕迹。

关键洞察：
- 行列对齐只保证撞墙；贯穿的钥匙是"对侧同色配对"这一双边条件。
- 异色对射的两枚像素各自留下撞痕，是对"对齐即联通"直觉的诱饵。
```

## 7. 示范阴影

- tags:
  - operation:偏移阴影, offset_shadow
  - operation:平移, translate
  - object:精灵体, sprite
  - object:阴影像素, shadow_pixel
  - relation:偏移, offset
  - relation:形状配对, shape_pairing
  - condition:示范对定义偏移向量, exemplar_pair_defines_offset
  - condition:前景覆盖阴影, foreground_over_shadow
- 参考题目题号：9 (310f3251)、15 (fd096ab6)、4 (1be83260)

### docstring

```text
从画面中唯一自带影子的示范精灵读出影子的偏移向量与颜色，
再给其余精灵补上同样的影子。

输入结构：
- 背景上有若干互不相同颜色的单色精灵。
- 恰有一个精灵旁伴随一份与它形状全等的复制体，复制体的颜色在全图中
  只出现这一处，即影子色。
- 其余精灵没有影子；不同示例中影子的偏移方向和距离各不相同。

规则：
- 找到形状全等的那一对精灵：影子色的一个为影子，另一个为示范本体。
- 由这对形状读出偏移向量（影子位置减本体位置）与影子颜色。
- 给其余每个精灵按同一偏移向量画出同形影子，颜色用影子色；
  影子与任何本体重叠处保留本体，影子出界部分裁掉。

关键洞察：
- 变换规则不写在题面约定里，而是由画面内的一对示范对象现场定义。
- 偏移向量逐示例变化，任何"固定方向阴影"的假设都会在第二个示例上破产。
```
