## 1. 指针链同心方阵

- 参考题目题号：5（3ee1011a 同心层填充）、12（4c416de3 空心框与标记）、2（dc433765 标记像素）
- tags:
  - operation:同心层填充, concentric_layer_filling
  - operation:排序, sorting
  - object:空心框, hollow_frame
  - object:标记像素, marker_pixel
  - relation:指针链, pointer_chain
  - condition:链序定层序, chain_order_layers
  - condition:尺寸诱饵, size_decoy

### docstring

```text
依照"框内标记色指向另一方框"的指针链确定嵌套顺序，把所有方框重组为一个同心方阵。

输入结构
- 背景为占主导的单一颜色。
- 画面上散布若干边框颜色互不相同的空心方框，尺寸与位置任意。
- 恰有一个方框内部为空；其余每个方框内部恰有一个标记像素，其颜色等于
  另一个不同方框的边框色，且所有标记色互不重复。

规则
- 把"方框 A 内含颜色 B 的标记"读作"B 方框嵌在 A 方框的内侧一层"。
- 沿指针可排出唯一链：链首是没有任何标记指向的方框（最外层），链尾是
  内部为空的方框（最内层）。
- 设方框共 n 个，输出 (2n−1)×(2n−1) 方阵：最外圈用链首的边框色，逐层
  向内依链序着色，中心 1×1 用链尾色。

关键洞察
- 方框的大小、位置乃至互相是否包含都是诱饵（示例中尺寸大小顺序与链序
  刻意不一致），嵌套顺序与几何完全无关，只由"内部标记色→边框色"的
  指针链给出。
```

## 2. 自相似占位修复

- 参考题目题号：17（8f2ea7aa 自相似印章）、16（42918530 复本共享补全）、13（42a50994 擦除）
- tags:
  - operation:印章覆盖, stamp
  - operation:补全, complete
  - operation:擦除, erase
  - object:精灵体, sprite
  - object:块阵, block_array
  - relation:自相似嵌套, self_similar_nesting
  - condition:占位内容一致性, mask_content_consistency

### docstring

```text
网格是母图案的自相似印章展开，恰有一处块级破坏，用"占位分布必须等于
块内容"这一自指等式定位并修复它。

输入结构
- 前景为单一颜色，背景为黑。
- 存在一个隐藏的 h×w 母图案，网格尺寸为 (h·h)×(w·w)，划分为 h×w 个
  大小均为 h×w 的块。
- 未破坏时：母图案在 (r,c) 为前景 ⇔ 块 (r,c) 内完整绘有母图案，其余
  块全空。
- 输入恰有一处块级破坏：要么一个应绘块被整块清空，要么一个应空块被
  整块绘上了母图案。

规则
- 所有非空块的内容完全一致，该内容即真实母图案。
- 把"非空块在块阵中的占位分布"与母图案逐格比对：若占位比母图案少一
  格，就在对应块补绘母图案；若多一格，就把对应块整块清空。

关键洞察
- 图案以两重身份同时存在——块内容与块占位；内容因多份复本冗余而保
  真，占位的单点错误无法靠复本间多数投票发现，只能靠"占位分布 = 块
  内容"的自相似等式检出并定向修复。
```

## 3. 门缝透光染房

- 参考题目题号：7（64efde09 射线）、14（e681b708 洪泛与区域标记）、4（1efba499 障碍段）
- tags:
  - operation:射线延伸, ray_extension
  - operation:洪泛填充, flood_fill
  - object:封闭房间, closed_room
  - object:门缺口, door_gap
  - object:标记像素, marker_pixel
  - relation:直线可达, line_of_sight
  - condition:门缝透光, door_gap_transmission
  - condition:就近诱饵, proximity_decoy

### docstring

```text
标记像素发出的直线光穿过门缝照亮房间，每间房被染成照到它的那束光的
颜色。

输入结构
- 背景为黑；单一墙色的一格厚墙体围成若干封闭矩形房间，房内为背景。
- 每间房的墙上恰有一个一格宽的门缺口。
- 房间外散布若干孤立彩色标记像素，颜色互不相同；其中一部分标记与任
  何门都不对齐（诱饵）。

规则
- 每个标记沿上下左右四个方向发出光线；光线穿过背景格（含房间内部）
  与门缺口，碰到墙格即终止。
- 若某标记的一束光穿过某房间内部，则把该房间内部全部染成该标记色；
  输入保证每间房恰被一束光穿过。
- 两扇正对的门可让同一束光接力穿过多间房；墙、门缺口与所有标记保持
  不变。

关键洞察
- 房间与颜色的配对既非就近也非包含，而是"穿过门缝的直线可达性"；离
  房间最近的标记常常是照不进来的诱饵，真正的光源可能隔着好几间屋子
  经对齐的门接力照入。
```

## 4. 尾巴位移接力

- 参考题目题号：20（c6e1b8da 尾部向量）、2（dc433765 趋近滑动）、4（1efba499 同线传递）
- tags:
  - operation:滑动, slide
  - object:实心矩形, solid_rectangle
  - object:尾部向量, tail_vector
  - relation:碰撞传递, collision_transfer
  - relation:连锁反应, chain_reaction
  - condition:位移守恒, displacement_conservation

### docstring

```text
带尾矩形注入等于尾长的总位移，位移沿走廊在碰撞中逐段传递，直至耗尽。

输入结构
- 背景为黑；同一行向（或列向）走廊上排列若干互异颜色的实心矩形，彼
  此之间留有背景间隙。
- 恰有一个矩形带一条一格厚的直尾巴（长度不小于 2），沿走廊方向从矩
  形一侧伸出，指向其余矩形所在的一侧。
- 输入保证整个传递过程不出界。

规则
- 抹去尾巴；带尾矩形沿尾巴方向平移，名义位移等于尾巴长度。
- 若它在走完之前与下一个矩形接触，就停在紧贴处，把剩余位移原封不动
  交给被撞矩形；被撞者继续沿同方向平移，依此连锁。
- 最后一个承接位移的矩形走完全部剩余格数；未被波及的矩形保持不动。

关键洞察
- 尾巴长度不是"带尾者的移动距离"，而是注入走廊的总位移量；碰撞不吞
  噬位移而是传递位移，各段间隙按顺序被吃掉，余量全部由链尾对象走
  完——按"每个都移动尾长"或"撞上即止"来推演都会在部分示例上出错。
```

## 5. 周期指令带走线

- 参考题目题号：19（d8c310e9 最小周期补全）、10（834ec97d 标记与条纹相位）、2（dc433765 标记移动）

  - object:最小周期单元, minimal_period
  - object:指令带, instruction_tape
  - object:标记像素, marker_pixel

  - condition:指令序列驱动, instruction_driven

### docstring

```text
先用最小周期补全底部指令带，再把整行指令逐格译成方向，驱动起点画出
一条路径。

输入结构
- 网格最底一行是指令带：左端已画出一段颜色序列，右侧其余格为背景；
  已画部分是某最小周期序列的前缀，且长度足以唯一确定该周期。
- 指令带之上的区域为背景，其中恰有一个起点标记像素，颜色不在指令带
  的用色之内。

规则
- 先按最小周期把指令带补满整行。

  （上、下、左、右，全部示例共用同一套对应），每读一格就朝对应方向
  走一步，并把走到的格染成该指令色。
- 起点像素保留原色；路径不自交、不越界（输入保证）；输出中指令带同
  样呈补全后的样子。

关键洞察
- 底部条带不是待补全的装饰花纹，而是一段程序：补全周期只是前置步
  骤，路径的步数等于整行宽度而非可见前缀——只按可见指令画一半路
  径，或只补带不画路径，都会与示例矛盾。
```

## 6. 三变换残片接力复原

- 参考题目题号：11（8be77c9e 镜像）、6（2697da3f 旋转与镜像复本）、16（42918530 复本并集补全）、20（c6e1b8da 遮挡恢复）
- tags:
  - operation:镜像, mirror
  - operation:旋转, rotate
  - operation:遮挡恢复, occlusion_restore
  - operation:并集补全, union_completion
  - object:精灵体, sprite
  - object:遮挡矩形, occluder_rectangle
  - relation:二面体变换对应, dihedral_correspondence
  - condition:跨变换接力借取, cross_transform_relay

### docstring

```text
同一多色图案的三份复本以互不相同的刚体变换散布，各自被不同的遮挡板
盖住一部分，须跨变换接力借取彼此的可见部分才能全部复原。

输入结构
- 背景网格上有同一多色图案的三份复本，所受变换互不相同（如恒等、某
  种镜像、180°旋转，各示例组合可不同），变换本身没有任何标注。
- 图案自身不具有任何镜像或旋转对称性。
- 每份复本被一块实心矩形遮挡板盖住一部分，三块遮挡板颜色互异，且不
  同于图案的任何用色。
- 输入保证：每个被遮格至少在另一份复本中可见，但存在只在"第三份"复
  本中可见的被遮格——没有任何两份复本能互相补全；完整图案从未整体
  出现。

规则
- 由三份残片的可见公共结构反推每对复本之间的变换与格点对应关系。
- 对每份复本：凡被遮挡板盖住的格，取任一在对应位置可见的其他复本中
  该格的颜色补上（可能需要经由两次不同的变换换算坐标）。
- 抹去三块遮挡板（未被图案占据的部分还原为背景），其余保持不变。

关键洞察
- 三份残片没有一份完整，两两之间也不能互相补全；复本间的对应既不是
  平移也不是同一种变换，缺失像素必须在三个不同取向的坐标系之间接力
  换算才能找齐——把任意两份对齐后就动手补全，会在只见于第三份的格
  上出错。
```

## 7. 折线顺序对折

- 参考题目题号：8（ca8de6ea 折叠压缩）、11（8be77c9e 镜像拼接）、20（c6e1b8da 遮挡层序）
- tags:
  - operation:折叠, folding
  - operation:镜像, mirror
  - operation:压缩, compression
  - object:折线, fold_line
  - object:画布, canvas
  - relation:顺序层叠, sequential_layering
  - condition:非背景覆盖, nonbg_overrides

### docstring

```text
把画布沿每条折线自左向右依次对折，新折上来的层覆盖旧层，输出最后剩
下的那一段。

输入结构
- 横向长条网格，若干条整列同为专用折色的竖直折线把画布分成多段。
- 各段绘有若干非背景图案；折色不作图案用色。
- 输入保证每次翻折的左段宽度不超过折线右侧的剩余宽度。

规则
- 找到最左的折线，把折线左侧的全部内容（含此前折叠累积的结果）以该
  折线为轴镜像翻折到右侧：距折线 k 格的列落到折线右侧第 k 格的列；
  翻折过来的非背景格覆盖原有内容，背景格不覆盖；折线本身消失。
- 对每条折线自左向右重复上述操作。
- 输出为最后一条折线右侧那段的最终画面（尺寸等于该段）。

关键洞察
- 折线不是分隔符而是一串按序执行的镜像算子；一段内容可能被翻折多
  次，奇数次翻折呈镜像、偶数次翻折回到原向，且后折上来的内容永远压
  在先前结果之上——试图用一次整体对称合成会得到错误的朝向与层序。
```
