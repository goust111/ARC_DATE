## 1. 冲击传递链

- tags:
  - operation:推移, push
  - operation:连锁传递, chain_transfer
  - object:发射标记, launcher_marker
  - object:前景对象, foreground_object
  - object:网格边界, grid_boundary
  - relation:标记定行列与方向, marker_selects_lane_and_dir
  - condition:动量逐个传递, momentum_handoff
  - condition:末端推至边界, last_to_boundary
- 参考题目: 5623160b, 0d87d2a6

### docstring

```text
边界发射标记沿其所在行列注入一次冲击，冲击在该行列的对象间逐个传递，
每个对象滑行到下一对象原位置前紧贴停下，最后一个对象滑行至网格边界。

输入结构:
- 黑色背景网格，边界上有若干单像素发射标记，各自位于不同的行或列。
- 每个发射标记所在的行(或列)内散布着若干互不相邻的单色实心对象，颜色各异。
- 另有一些不在任何发射行列上的对象作为静止干扰，各发射行列互不干涉。

规则:
- 发射标记不动，冲击从标记出发指向网格内部。
- 距标记最近的对象先滑行，方向远离标记，直到紧贴"下一个对象原先所占
  位置"的近端停下；随后下一个对象以同样方式滑行。
- 链中最后一个对象一直滑行到网格边界停下；不在发射行列上的对象不动。

关键洞察:
- 对象不是整体压实到墙边：每个对象只前进"它与下一个对象之间的间隙"
  那么远，运动像动量一样逐个传递，间隙序列整体向后移一位。
```

## 2. 灰影矢量合成

- tags:
  - operation:平移, translate
  - operation:擦除, erase
  - object:精灵体, sprite
  - object:灰影, gray_silhouette
  - relation:形状配对, shape_pairing
  - relation:矢量合成, vector_composition
  - condition:唯一无配对者被移动, unpaired_one_moves
- 参考题目: cd3c21df, 3e980e27

### docstring

```text
每个彩色图案的灰色影子给出一条位移矢量，将所有矢量相加，
作用在唯一没有影子的图案上。

输入结构:
- 黑色背景上散布若干多色图案与若干纯灰色图案。
- 每个灰色图案的形状与某个彩色图案完全相同、一一配对，各配对的形状互不相同。
- 恰有一个彩色图案没有同形状的灰色影子。

规则:
- 对每一配对，取"从灰色影子到同形彩色图案"的平移矢量。
- 将所有配对的矢量相加得到总位移。
- 输出中删去所有配对图案，仅保留无影子的图案，并将它按总位移平移到新位置。

关键洞察:
- 灰影不是待上色的目标，而是位移指令的起点；多条指令按矢量加法合成后，
  作用对象是画面中唯一"没有历史"的图案。
```

## 3. 单色化镜像分形

- tags:
  - operation:像素放大, pixel_upscale
  - operation:镜像, mirror
  - operation:重涂色, recolor
  - object:精灵体, sprite
  - relation:自引用替换, self_reference
  - relation:宿主格投影身份, host_cell_projects_identity
  - condition:颜色决定朝向, color_encodes_orientation
- 参考题目: 9172f3a0, 3e980e27, 59341089

### docstring

```text
把双色图案放大为分形，每个前景格展开为整幅图案的一份拷贝，
拷贝被染成宿主格的颜色，而宿主格的颜色同时决定拷贝是否左右镜像。

输入结构:
- 输入是一幅小图案，前景恰用两种颜色 A 与 B，背景为黑色。
- 图案左右不对称。

规则:
- 输出为 n 倍放大(n 为输入边长)，划分为 n×n 个块。
- 颜色 A 的格对应块粘贴整幅图案前景轮廓的单色拷贝(染成 A)；
  颜色 B 的格粘贴左右镜像后的单色拷贝(染成 B)；背景格对应全黑块。

关键洞察:
- 拷贝不保留原双色，颜色线索被宿主格吞并成单色，镜像开关只能通过比较
  各块的形状差异发现；每个像素同时向它的拷贝投影自己的身份(颜色)和
  姿态指令(是否镜像)。
```

## 4. 斜滑残迹重建

- tags:
  - operation:投影反演, projection_inversion
  - operation:绘制, draw
  - object:投影残迹, projection_trace
  - object:正方形, square
  - relation:等长配对, equal_length_pairing
  - relation:斜滑错位, diagonal_slide_offset
  - condition:对象未被画出, object_never_drawn
  - condition:两影按序联立, traces_solved_in_order
- 参考题目: db93a21d, 56ff96f3, f1cefba8

### docstring

```text
每个看不见的正方形曾沿左下 45 度方向滑落到底行留下一段印迹，又在最左列
留下行范围影子；须先用左影恢复高度，才能把印迹平移回正确的列位置重建正方形。

输入结构:
- 最底行上有若干互不相邻的水平青色印迹线段，最左列上有等量的竖直青色影子线段。
- 每条底部印迹与恰一条左侧影子长度相等；各正方形的边长互不相同。

规则:
- 将每条底部印迹与等长的左侧影子配对；左侧影子给出正方形的行范围。
- 设正方形底边到最底行的距离为 d(由行范围算出)；底部印迹是正方形底边
  沿左下对角滑落 d 步后的落点，故真实列范围 = 印迹列范围向右平移 d。
- 在该行列交汇处画黄色实心正方形，青色残迹保持不变。

关键洞察:
- 底部印迹不在正方形正下方，而是被斜滑错开了恰好等于离地高度的距离；
  只有先用另一条影子恢复出高度，才能把印迹反推回真实位置——两条残迹
  必须按序联立，缺一不可。
```

## 5. 杯口弹射与门禁捕获

- tags:
  - operation:射线延伸, ray_extend
  - operation:推移, move
  - object:杯形轮廓, cup_outline
  - object:开口, opening
  - object:孤立像素, isolated_pixel
  - relation:开口朝向, opening_direction
  - relation:颜色门禁, color_gate
  - condition:开口既是出口也是入口, opening_dual_role
  - condition:同色收底异色拒门, same_color_deep_settle
- 参考题目: d4f3cd78, 5623160b, 604001fa

### docstring

```text
装有小球的杯子把球从开口弹出，球沿直线飞行，只有与杯壁同色的空杯才会把它
收进杯底，异色空杯将它拒在门外，其余情况停在障碍前或网格边缘。

输入结构:
- 黑色背景上有若干几乎封闭的矩形杯形轮廓，杯壁各为一种颜色，
  每个杯壁上恰有一个单格开口。
- 部分杯内有一个与开口同行列对齐的彩色小球像素，其余杯为空。
- 各球的飞行路径互不相交，每个空杯至多迎来一个球。

规则:
- 每个球沿开口方向离开自己的杯子，沿直线飞行。
- 若路径恰从某个空杯的开口进入且球色与该杯壁同色，球继续行进到杯内
  紧贴对侧内壁停下；若球色与该杯壁异色，球停在开口外一格。
- 否则球在撞上第一个非背景格之前一格停下，一路无阻则停在网格边缘；
  杯子本身不变。

关键洞察:
- 开口是双重身份的门：对内是发射方向，对外是带颜色门禁的入口；
  同色球落到杯内最深处，异色球被拒于门外，撞墙的球停在墙前——
  三种停点由"是否开口、是否同色"两重判定决定。
```

## 6. 姿态程序复制

- tags:
  - operation:裁剪, crop
  - operation:拼接, concatenate
  - operation:旋转, rotation
  - operation:镜像, mirror
  - object:精灵体, sprite
  - relation:图案匹配, pattern_match
  - relation:排列定轴, arrangement_sets_axis
  - condition:唯一图案选取, unique_pattern_selected
  - condition:重复族编码变换程序, family_encodes_program
- 参考题目: cd3c21df, 28bf18c6, 59341089, b7cb93ac

### docstring

```text
重复出现的图案族沿一条轴排列，各拷贝的旋转镜像姿态构成一段程序，
把这段程序逐位施加到唯一不重复的图案上并拼接输出。

输入结构:
- 网格上有一族图案：同一形状的 k 份拷贝，各自可能被 180 度旋转、
  左右镜像或上下镜像，沿水平或竖直方向排成一行/一列。
- 另有恰一个形状不同的独特图案；族形状与独特图案都不具有旋转或镜像对称性。

规则:
- 以阅读顺序第一份族拷贝为基准姿态，读出后续每份拷贝相对基准的变换，
  得到长度为 k 的姿态序列。
- 将独特图案裁剪到包围盒，依次施加姿态序列中的每个变换，得到 k 份拷贝。
- 沿族的排列轴把这 k 份拷贝按序拼接成输出。

关键洞察:
- 重复的图案族不是干扰项也不是答案本体：它同时编码输出的份数、
  拼接方向和每一份的姿态，而唯一图案只提供内容。
```

## 7. 开口涨潮层染

- tags:
  - operation:填充, fill
  - object:封闭区域, enclosed_region
  - object:开口, opening
  - object:调色板行, palette_row
  - relation:测地距离分层, geodesic_layering
  - relation:调色板按层取色, palette_indexed_by_depth
  - condition:自开口起算的波前, wavefront_from_opening
- 参考题目: d4f3cd78, bae5c565, c7d4e6ad

### docstring

```text
水从容器唯一的开口涌入，按到开口的最短步数把内部划成一圈圈波前，
波前颜色依次取自顶部调色板行。

输入结构:
- 顶行从最左格起是一段调色板色带，长度等于最大层数。
- 下方是由单色墙构成的封闭容器，壁上恰有一个单格开口，内部形状曲折。
- 其余为黑色背景。

规则:
- 从开口正内侧的格开始，按四连通最短步数给容器内每个空格分层：
  步数为 0 的格为第 1 层，依次类推。
- 第 i 层的所有格染成调色板行第 i 个颜色。
- 调色板行、容器壁与外部背景保持不变。

关键洞察:
- 分层不是到墙距离形成的洋葱圈，而是从唯一开口出发绕墙流动的测地波前；
  曲折的内壁会让同一层在画面上绕成不规则的弧。
```
