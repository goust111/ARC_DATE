## 1. 双件拼装成瓦片再平铺

- tags:
  - operation:平移, translate
  - operation:拼合, pack
  - operation:平铺, tiling
  - operation:擦除, erase
  - object:精灵体, sprite
  - object:矩形空腔, rectangular_cavity
  - object:墙壁, wall
  - relation:互补拼合, complement_fit
  - condition:最密堆叠最小框, densest_minimal_bbox
  - condition:保持种子相位, preserve_seed_phase
- 参考题目：681b3aeb, a57f2f04

### docstring

```text
把游离碎块与腔内残件平移拼合成完整单元瓦片，再按残件当前相位把瓦片周期平铺满整个空腔。

输入结构：
- 主导色构成实心墙体，围出一个矩形空腔，空腔内部为统一的空腔色。
- 空腔内某处放着一个单色残件（碎块甲）。
- 墙体外的背景上游离着另一个不同色的碎块乙。
- 两碎块仅经平移即可拼合成一个无空腔色缝隙的实心矩形。

规则：
- 求碎块乙相对碎块甲的唯一无重叠平移，使二者拼成裁剪后空腔色格最少的
  实心矩形；该矩形即单元瓦片。
- 以碎块甲当前位置确定的相位为锚，将该瓦片周期性平铺满整个空腔，
  越出空腔的部分截断。
- 从原位置擦除碎块乙；墙体与外部背景其余部分保持不变。

关键洞察：
- 游离碎块不是要搬进腔里的对象，而是瓦片的缺失另一半；空腔内的残件
  同时提供拼合互补与平铺相位，先拼装、后铺墙是一条不可跳步的工序链。
```

## 2. 注水链

- tags:
  - operation:重力下落, gravity_drop
  - operation:填充, fill
  - operation:射线延伸, ray_extend
  - object:空心矩形, rectangular_frame
  - object:边框缺口, border_gap
  - object:水源像素, water_source_pixel
  - relation:连锁传播, chain_propagation
  - condition:缺口位置决定水位, gap_position_determines_level
  - condition:可达性决定注水, reachability_determines_fill
- 参考题目：28a6681f, 551d5bf1, 981add89

### docstring

```text
顶行水源垂直下落，只能经顶边缺口注入矩形框；框内水位由第二缺口的位置
决定，溢出的水继续下落形成逐级注水链。

输入结构：
- 黑色背景；顶行有若干青色水源像素。
- 下方散布若干互不接触的单像素厚矩形框，每框有一个或两个非角缺口
  （缺口处为黑）；所有框初始为空。

规则：
- 每个水源沿所在列垂直下落并画青色水迹；落到网格底边终止；落到某框
  顶边的非缺口格时停在其上一格。
- 若下落列恰好正对某框顶边缺口，水注入该框：
  - 该框仅有这一个缺口时，内部全部填青；
  - 第二缺口在侧壁时，内部仅严格低于该缺口行的行填青，缺口格染青，
    水再从缺口外侧一格起继续垂直下落，继续遵循全部规则，可再注入
    更低的框；
  - 第二缺口在底边时，内部不填，水从底缺口正下方继续下落。
- 未被任何水流经过的框保持全空，无论其缺口形态如何；框像素永不改变。

关键洞察：
- 框有没有水、水位多高，不由框自身形状决定，而由自上而下的注水链
  决定：缺口既是入口也是溢流口，一个框的溢流可能正是下一个框的水源。
```

## 3. 钥匙开锁的连环房间

- tags:
  - operation:填充, fill
  - operation:迭代闭包, iterative_closure
  - object:空心矩形, rectangular_frame
  - object:锁格, lock_cell
  - object:钥匙点, key_pixel
  - relation:颜色匹配配对, color_match_pairing
  - relation:依赖链, dependency_chain
  - condition:可达性不动点, reachability_fixpoint
- 参考题目：551d5bf1, 305b1341, 247ef758

### docstring

```text
每个上锁房间的锁色需要同色钥匙才能打开，打开的房间里又藏着新的钥匙，
迭代到不动点后点亮所有被打开的房间。

输入结构：
- 黑色背景上有若干互不接触的单像素厚矩形房间，框色统一。
- 每个房间边框上恰嵌有一个彩色锁格（替换框色像素）。
- 房间内部藏有零个、一个或多个彩色钥匙点（单像素）。
- 房间外的背景上散布少量彩色钥匙点，构成初始钥匙串。

规则：
- 初始持有钥匙集为所有房间外散布的钥匙点颜色。
- 若某房间的锁色属于当前持有集，该房间被打开：内部全部染成其锁色，
  且其内部所有钥匙点的颜色加入持有集。
- 重复上述过程直到没有新房间可开。
- 始终未被打开的房间保持原样，内部不染；锁格与框像素永不改变；
  钥匙点原位保留。

关键洞察：
- 一个房间能否打开不取决于它自己，而取决于通往它的钥匙依赖链：
  开甲才得到开乙的钥匙，开乙才得到开丙的钥匙；背景上看不到某色钥匙
  不代表那扇门永远打不开，它可能正锁在另一间屋里。
```

## 4. 图例配重与气泡

- tags:
  - operation:重力下落, gravity_drop
  - operation:排序, sorting
  - operation:重排, rearrange
  - object:图例, legend
  - object:竖管, tube
  - relation:图例序即密度序, legend_order_density
  - condition:计数守恒, count_conservation
  - condition:缺席即气泡, absent_color_floats
- 参考题目：305b1341, 28a6681f, dc2aa30b

### docstring

```text
按图例给出的密度次序让每根竖管中的彩色液滴重新分层沉降，
图例外的颜色作为气泡浮到最顶。

输入结构：
- 背景色网格上有若干管壁色画出的 U 形单格宽竖管，管口朝上。
- 每根管的内腔中散布彩色液滴格与背景空格，次序杂乱。
- 网格底行左端有一段水平色条作为图例，自左向右表示从重到轻。
- 管内恰有一种颜色未出现在图例中。

规则：
- 对每根管收集内腔全部液滴，各色计数守恒。
- 在管底自下而上按图例从重到轻的次序堆叠成连续色层。
- 图例未列出的颜色是气泡，堆叠在全部液体层之上；气泡以上为背景。
- 图例、管壁与其余背景保持不变。

关键洞察：
- 图例不是调色板而是密度表：管内容物不保留输入次序，而按图例名次
  重新分层；不在表上的颜色不服从重力，浮在液面之上。
```

## 5. 条高定步距的追踪射线

- tags:
  - operation:射线延伸, ray_extend
  - operation:阶梯扩展, stepped_expansion
  - object:控制像素, control_pixel
  - object:竖直柱, vertical_pillar
  - relation:同色配对, color_pairing
  - relation:周期性步长, periodic_step_length
  - condition:跨色重叠变色, cross_color_overlap_recolor
- 参考题目：981add89, 58e15b12

### docstring

```text
每个顶行控制像素向下发出阶梯射线，其水平漂移的周期与方向由同色竖柱的
高度和方位编码，异色射线交叉处染粉。

输入结构：
- 黑色背景；顶行有若干颜色互异的控制像素。
- 每种控制色在底边上各立有一根竖直柱，高度不一，
  所在列与其控制像素不同列。

规则：
- 设同色柱高为 h：射线自控制像素正下方开始逐行向下延伸，
  每走满 h 行就向柱所在的一侧平移一列，然后继续向下。
- 射线到达柱所在列后不再平移，竖直下行，至柱顶上方一格停止。
- 被两种不同颜色射线经过的格子染粉色；柱与控制像素保持不变。

关键洞察：
- 竖柱既是参数又是终点：高度给出阶梯周期，方位给出漂移方向，
  柱顶接住射线；柱不是场景里的障碍物，而是一份写给射线的飞行说明书。
```

## 6. 异常点的遗嘱

- tags:
  - operation:补全, completion
  - operation:重涂色, recolor
  - operation:擦除, erase
  - object:周期图案, periodic_pattern
  - object:异常像素, anomaly_pixel
  - relation:行列带选择, row_column_band_selection
  - condition:先行动后修复, act_then_repair
  - condition:顺序覆盖, ordered_overwrite
- 参考题目：4f537728, f9d67f8b, a57f2f04

### docstring

```text
找出双周期图案中的异常色像素，先用它的颜色重涂其所在行列的图案带，
再把异常点本身修复回周期原色。

输入结构：
- 网格由一个沿行、列均周期重复的双色图案（图案色与背景色）铺满。
- 极少数格子的颜色偏离周期预测：既非该处应有的图案色也非背景色，
  而是其他异常色。

规则：
- 由大量无冲突的重复推断行周期与列周期，得到每个格子的应有颜色。
- 对每个异常像素：将其所在行与所在列上所有应有颜色为图案色的格子
  重涂为该异常色；应有颜色为背景色的格子不动。
- 多个异常按自上而下、同行自左而右的顺序依次涂带，后涂覆盖先涂。
- 最后把每个异常像素自身恢复为它的应有颜色。

关键洞察：
- 异常像素不是待清除的噪声，而是一次性标记：它先以自己的颜色圈占
  行列图案带，然后消失在修复后的周期图案之中，画面上只留下它的遗产。
```

## 7. 缺口摆渡的光束

- tags:
  - operation:射线延伸, ray_extend
  - operation:洪泛填充, flood_fill
  - object:空心矩形, rectangular_frame
  - object:边框缺口, border_gap
  - object:源像素, source_pixel
  - relation:连锁传播, chain_propagation
  - condition:入口出口换向, entry_exit_redirection
  - condition:撞壁吸收, wall_absorption
- 参考题目：551d5bf1, 981add89

### docstring

```text
边界源点发出的光束在矩形框之间摆渡：从一个缺口进入就必从另一个缺口
离开，被穿过的框内部被点亮。

输入结构：
- 黑色背景；网格边界上有一个源像素。
- 内部有若干互不接触的单像素厚矩形框，每框恰有两个非角缺口。

规则：
- 光束从源像素出发，垂直于所在边向网格内部直线传播，
  路径上的黑格染成源色。
- 光束若正对某框的缺口则进入该框：框内部全部染成源色，随后光束从
  该框的另一个缺口射出，方向为垂直于出口所在边、指向框外，继续传播。
- 光束撞上框壁的非缺口部分即被吸收终止；到达网格边界亦终止。
- 未被光束造访的框保持原样，内部不填。

关键洞察：
- 缺口是成对的门：一进一出，出口的方位改写光束方向；哪些框被点亮
  取决于这条唯一的传播链，而不是框自身的任何性质。
```

## 8. 旋转靠港

- tags:
  - operation:复制放置, replicate_stamp
  - operation:旋转, rotate
  - operation:擦除, erase
  - object:精灵体, sprite
  - object:框架标记, frame_marker
  - object:端口像素, port_pixel
  - relation:颜色匹配配对, color_match_pairing
  - condition:端口朝向决定旋转, port_orientation_determines_rotation
- 参考题目：247ef758, e9fc42f2, c7f57c3e

### docstring

```text
把外部精灵旋转后停靠到大框内壁：端口像素必须贴住同色边框标记，
标记出现几次就停靠几份。

输入结构：
- 背景色网格中央有一个单像素厚矩形大框，框色统一，边框的非角位上
  嵌有若干彩色标记格（替换了框色像素）。
- 框外散布若干精灵：每个精灵由单色躯体加一个突出于躯体边缘的端口
  像素组成，端口色与某种标记色相同。

规则：
- 对每个精灵找到同色标记，将精灵旋转 0、90、180 或 270 度，
  使端口原本突出的方向指向该标记所在的边框。
- 把旋转后的精灵放入框内：端口像素落在紧贴标记内侧的格子上，
  躯体伸向框内。
- 同色标记出现多次时，在每个标记处各停靠一份拷贝。
- 随后从框外擦除原精灵；框、标记与背景其余部分保持不变。

关键洞察：
- 端口在精灵上的朝向是唯一的旋转依据：停靠不是平移搬运，
  而是让每个插头转到正对插座的方向。
```
