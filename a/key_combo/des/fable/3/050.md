## 1. 针孔倒影

- tags:
  - operation:投影, project
  - operation:旋转, rotate
  - operation:擦除, erase
  - object:墙壁, wall
  - object:门段, door_segment
  - object:双色精灵体, two_tone_sprite
  - relation:钥匙色选门芯, key_color_selects_door
  - relation:以门芯为枢轴点对称, point_reflection_about_door
  - condition:落墙或出界丢弃, clipped_at_wall
- 参考题目: 2 (7e576d6e)、8 (1a244afd)、11 (7c66cb00)、1 (fd02da9e)

### docstring

```text
每个双色精灵通过与其钥匙像素同色的门芯做点对称，投成墙另一侧的倒像。

输入结构：
- 网格有统一背景色，一条全跨度直墙（水平或竖直）把画布分成两侧。
- 墙上嵌有若干三像素门段，各门段中心像素（门芯）颜色互不相同，且不同于墙色与背景色。
- 墙的一侧散布若干精灵：每个精灵由主体色加恰好一个异色"钥匙像素"组成，
  钥匙像素颜色等于某个门芯色；精灵形状均不对称。另一侧没有前景。

规则：
- 保留墙与全部门段不变。
- 每个精灵找到与其钥匙像素同色的门芯，以该门芯为中心，把精灵的每个像素做
  180 度点对称，涂到墙另一侧的对应位置，各像素保持原色。
- 点对称后落在墙上或出界的像素直接丢弃。
- 擦除原侧的所有精灵。

关键洞察：
- 门芯不是通道而是针孔：精灵既不是平移穿门也不是镜像过墙，而是上下左右同时
  颠倒的点对称倒像，离门越远投得越远；钥匙像素既决定配对又随倒像一起翻转，
  只有不对称的精灵能把点对称与轴镜像区分开。
```

## 2. 弹簧容器

- tags:
  - operation:滑动, slide
  - object:U形容器, u_container
  - object:被包物体, contained_object
  - object:散落障碍, stray_blocker
  - relation:开口朝向定方向, opening_sets_direction
  - relation:埋深即射程, depth_sets_range
  - condition:碰撞提前截停, collision_caps_flight
  - condition:远者先结算, far_first_settle
- 参考题目: 18 (9720b24f)、9 (5ffb2104)、3 (9c56f360)

### docstring

```text
每个被 U 形容器包住的物体像压缩弹簧一样弹出：落点在它关于开口口沿的镜像距离处，途中被挡则提前停下。

输入结构：
- 黑色背景上有若干单色 U/C 形容器（缺一面的空心矩形），开口朝向各不相同。
- 每个容器内部恰好装着一个异色小物体，各物体的前端到开口口沿的格数（埋深）互不相同。
- 容器之外还散落着若干静止的单色物体。

规则：
- 容器与散落物体保持原位不动。
- 设某被包物体前端到其容器口沿的格数为 s，该物体沿开口朝向整体平移 2s 格，
  使前端落在口沿外第 s 格——埋得越深弹得越远。
- 若平移路径上或落点处会与任何前景像素重叠或出界，则退到路径上能停留的最远合法位置。
- 多个物体按平移距离从大到小依次结算，先落定者成为后来者的障碍。

关键洞察：
- 物体常常停在四周皆空的位置，"滑到障碍为止"的直觉不成立；真正的落点是物体
  关于容器口沿的镜像距离——埋深即射程，碰撞只是提前截停的上限。
```

## 3. 自指印章

- tags:
  - operation:印章覆盖, stamp_overlay
  - operation:重涂色, recolor
  - operation:擦除, erase
  - object:掩码图案, mask_pattern
  - object:角落标记, corner_marker
  - relation:角点占用选角落, corner_occupancy_selects
  - condition:标记色传递给印章, marker_color_pass
  - condition:自身即印章, self_as_stamp
- 参考题目: 17 (27a28665)、1 (fd02da9e)

### docstring

```text
按 3x3 图案自身占用了哪些角，把它自己盖印到网格的对应角落，并用角落标记的颜色上色。

输入结构：
- 背景网格中部有一个 3x3 双色图案：掩码色恰好五格，其余四格为背景色。
- 网格四个角落各有一个单像素颜色标记，四个标记颜色互不相同。

规则：
- 检查 3x3 图案的四个角格中哪些被掩码色占用。
- 对每个被占用的角，把整幅 3x3 图案盖印到网格的同方位角落
  （图案角格与网格角格对齐）：掩码格涂色，背景格不涂。
- 盖印副本的掩码色改涂为该角落原有标记像素的颜色。
- 擦除中央原图案与全部四个角落标记（含未被选中角落的标记）。

关键洞察：
- 3x3 图案同时是选择器与图章：角占用决定去哪些角，印下的内容就是它自己，
  而它自身的颜色毫无意义；角落标记只负责供色并被消耗。
```

## 4. 指针图例

- tags:
  - operation:计数, counting
  - operation:洪泛填充, flood_fill
  - operation:擦除, erase
  - object:图例框, legend_box
  - object:封闭区域, enclosed_region
  - object:灰点标记, tally_dot
  - relation:点数键入图例, count_keys_legend
  - relation:键色即地址, key_color_is_address
  - condition:指向构成置换, pointers_form_permutation
  - condition:忽略干扰项, ignore_distractors
- 参考题目: 20 (58490d8a)、19 (c8b7cc0f)、15 (4b6b68e5)

### docstring

```text
每条轮廓内的灰点数经图例译成一个颜色地址，指认另一条轮廓，把那条轮廓的内部填成发起者自己的轮廓色。

输入结构：
- 网格一角有一个图例框：每行最左是一个键色像素，右侧每隔一格排着若干灰点，
  各行点数互不相同。
- 画布其余部分有若干封闭轮廓，轮廓颜色互不相同，且恰好与图例键色集合一一对应。
- 每条轮廓内部散布若干灰点，轮廓外的空地上也散落干扰灰点。

规则：
- 对每条轮廓：数出其内部灰点数 N；在图例中找到点数为 N 的那一行，取其键色 C；
  找到轮廓色为 C 的那条轮廓，把它的内部全部填充为当前轮廓自己的颜色。
- 每条轮廓恰好被指向一次（指向关系构成一个置换，个别轮廓可能自指）。
- 内部灰点被填充覆盖，轮廓外的灰点全部擦除；轮廓边线与图例框保持不变。

关键洞察：
- 图例查出的颜色不是颜料而是地址——它指认要被填的另一条轮廓；真正的颜料是
  发起查询的轮廓自身的颜色。"查到什么色就把自己填成什么色"的直觉解法只在
  偶然自指的轮廓上碰巧正确，在其余轮廓上全部报错。
```

## 5. 隐形挡板与真假障碍

- tags:
  - operation:滑动, slide
  - object:可移动行程, movable_run
  - object:已停行程, settled_run
  - object:隐形障碍, invisible_barrier
  - relation:左端共线, left_ends_collinear
  - relation:同行阻挡, same_row_blocking
  - condition:贴右缘者运动, right_edge_means_moving
  - condition:斜率外推, slope_extrapolation
- 参考题目: 3 (9c56f360)、12 (4aab4007)、9 (5ffb2104)

### docstring

```text
把每条贴着右缘的水平行程向左滑，停在同行已停行程之后，或停在由所有已停行程左端连成的隐形直线上。

输入结构：
- 背景网格的若干行各含一到两段同色水平行程，长度不一。
- 右端紧贴网格右缘的行程仍在运动；右端不贴右缘的行程已停下，
  且所有已停行程的左端点恰好共线——位于一条竖直线或每行错开固定列数的斜线上。
- 有的行同时含一条已停行程和一条运动行程；有的行只有运动行程。
- 画布上没有任何障碍像素。

规则：
- 已停行程保持不变。
- 由已停行程的左端点确定那条直线，并按其斜率延伸到所有行。
- 每条运动行程整体左移，直到再前进一步就会与同行已停行程重叠，
  或其左端点到达该直线经过本行的位置，两个条件先满足者生效；
  行程长度与颜色不变。

关键洞察：
- 只看含同行已停行程的行会以为这是普通的"滑到障碍"，但只有运动行程的行
  暴露出真正的停靠面——一条从未画出、只能从已停行程左端的共线关系中
  反推并外推出来的挡板；"右端是否贴右缘"是区分动静的唯一标志。
```

## 6. 双片锁孔

- tags:
  - operation:对接, dock
  - operation:旋转, rotate
  - operation:重涂色, recolor
  - operation:擦除, erase
  - object:厚条缺口, notched_bar
  - object:精灵体, sprite
  - relation:双片旋转拼合, two_piece_rotated_tiling
  - condition:拼分唯一, unique_decomposition
  - condition:颜色是诱饵, color_is_decoy
- 参考题目: 11 (7c66cb00)、8 (1a244afd)、12 (4aab4007)

### docstring

```text
每根厚条的缺口由恰好两个精灵各自旋转后拼合填满，嵌入后一律染成厚条色。

输入结构：
- 网格下部平铺若干水平厚条，每条一色；每条内部挖去一个露出背景色的异形缺口。
- 上部散落着数量为缺口数两倍的实心单色精灵，颜色各异，
  且部分精灵刻意与某根错误厚条同色。
- 每个缺口恰好能被某两个精灵经各自 0/90/180/270 度旋转后不重叠、无空隙地拼满，
  且该二拆分方式对每个缺口唯一。

规则：
- 为每个缺口找出能拼满它的那一对精灵及各自的旋转角。
- 把两个精灵旋转后嵌入缺口，嵌入像素全部改涂为该厚条的颜色。
- 擦除上部所有精灵。输出中每根厚条都是无洞的实心条。

关键洞察：
- 一对一的形状匹配走不通——精灵数是缺口数的两倍；配对的键是两片形状在
  旋转下的无缝拼合而非颜色，同色只是引向错误厚条的陷阱，嵌入后全部被条色抹去。
```

## 7. 变焦透镜

- tags:
  - operation:像素放大, pixel_upscale
  - operation:替换, replace
  - object:矩形边框, rect_frame
  - object:全幅场景, full_scene
  - relation:厚度即倍率, thickness_is_zoom
  - condition:同心子域取样, concentric_sampling
- 参考题目: 5 (e7a25a18)、13 (a6f40cea)

### docstring

```text
把每个边框当作放大镜：框内画面替换为框心同心子区域按"边框厚度"倍放大后的图。

输入结构：
- 整幅网格铺满一幅多色像素场景。
- 场景上叠着一到两个空心矩形边框，边框各为单色、厚度为 t（如 2 或 3，
  两框厚度不同）；框内仍透出场景原像素，框内矩形的边长都能被各自的 t 整除。

规则：
- 框环与框外场景保持不变。
- 对每个边框，取其内部矩形的同心、边长为内部边长 1/t 的子区域，
  读出输入中该子区域的场景像素。
- 将该子区域按因子 t 做像素放大，恰好铺满整个框内矩形，覆盖原有画面。

关键洞察：
- 边框厚度不是装饰而是放大倍率；被放大的图像从未整幅出现，
  它的原件就摆在框中心的可见像素里。
```
