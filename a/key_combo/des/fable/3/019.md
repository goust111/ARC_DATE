## 1. 隐形护罩连通链

- 参考题目：239be575, ff72ca3e
- tags:
  - operation:连通判定, connectivity_test
  - object:标记像素, marker_pixel
  - object:阻挡像素, blocker_pixel
  - object:隐式方块, implicit_square
  - relation:切比雪夫距离, chebyshev_dist
  - condition:成链分量才涂色, chain_component_paint

### docstring

```text
为每个黄色标记推算其从未画出的护罩方块，只把与两个蓝色锚点同属一个连通分量的护罩涂红。

输入结构：
- 黑色背景网格上有两个 2×2 蓝色锚点方块。
- 散布若干黄色标记像素与若干灰色阻挡像素。
- 网格中没有画出任何方块区域，护罩只能由距离关系推算。

规则：
- 每个黄色标记以自身为中心确定一个正方形护罩，半径等于它到最近灰色像素的切比雪夫距离减一。
- 把所有护罩与两个蓝色锚点的并集按四连通划分连通分量。
- 只把同时包含两个蓝色锚点的那个连通分量中的护罩格全部涂红（保留黄、灰、蓝像素原样）；
  不在该分量中的护罩不涂；若不存在这样的分量则不涂任何红色。

关键洞察：
- 参与连通判定的方块从未在输入中画出，其尺寸由阻挡距离决定；一个护罩涂不涂色不取决于
  它自身，而取决于它是否加入了连接双锚点的整体链条。
```

## 2. 交点关系矩阵

- 参考题目：40853293, 0520fde7, af24b4cc
- tags:
  - operation:连线, draw_line
  - operation:压缩, compress
  - object:标记像素, marker_pixel
  - object:线段, line_segment
  - relation:同色配对, same_color_pairing
  - relation:相交关系抽象, incidence_abstraction
  - condition:竖线交叉优先, vertical_priority_at_cross

### docstring

```text
把成对端点隐含的横竖线段抽象成一张相交关系矩阵，相交处继承竖线段的颜色。

输入结构：
- 黑色背景上散布彩色像素，每种前景色恰好出现两次，且两像素同行或同列。
- 每对同色像素隐含一条从未画出的线段，线段分为若干横段与若干竖段。
- 构造保证任意两条横段不同行、任意两条竖段不同列。

规则：
- 输出是一个全新的小网格：行数等于横段数，列数等于竖段数。
- 横段按所在行从上到下排序，对应输出的各行；竖段按所在列从左到右排序，对应输出的各列。
- 输出格 (i,j) 在第 i 条横段与第 j 条竖段确实相交时填该竖段的颜色，否则为黑。

关键洞察：
- 输出不是画面的任何局部，而是场景的关系摘要：先把稀疏端点读成线段，再把"谁与谁相交"
  按空间次序编码成矩阵，格色沿用交叉处竖线优先的约定。
```

## 3. 燃料射线

- 参考题目：95755ff2, 902510d5, ff72ca3e
- tags:
  - operation:射线延伸, ray_extend
  - operation:计数, counting
  - operation:擦除, erase
  - object:侧标记, side_marker
  - object:阻挡像素, blocker_pixel
  - object:燃料像素, fuel_pixel
  - relation:计数决定长度, count_determines_length
  - condition:遇阻顺时针折转, clockwise_turn_at_blocker

### docstring

```text
边框标记发出射线，散落的同色像素是被吸收的燃料，燃料数决定路径总长，遇灰阻挡则顺时针折转继续。

输入结构：
- 黑色背景，网格边框上有若干互不同色的标记像素。
- 网格内部散布与各标记同色的燃料像素，以及若干灰色阻挡像素。
- 构造保证各射线路径互不冲突、折转处不出现死角。

规则：
- 每个边框标记垂直于所在边向内发射一条射线，逐格涂上标记色。
- 射线可走的总格数等于网格中该颜色燃料像素的数量；这些燃料像素在输出中被擦除。
- 当射线的下一格是灰色阻挡或越出网格时，行进方向顺时针旋转 90 度后继续，直到燃料耗尽。
- 灰色阻挡像素保持原样。

关键洞察：
- 射线长度与阻挡无关而由计数供给，阻挡只改变方向不消耗燃料；训练示例中会出现燃料恰好
  在阻挡前耗尽的局面，诱导"遇阻停止"的错误假设，只有折转示例能揭示真规则；散落像素并非
  装饰，而是先被"吃掉"再以路径长度的形式重新显形。
```

## 4. 碎片折叠与半身补全

- 参考题目：f25ffba3, af24b4cc, a61ba2ce
- tags:
  - operation:对称补全, symmetry_complete
  - operation:多数决, majority_vote
  - operation:裁剪, crop
  - object:缺陷像素, defect_pixel
  - object:旋转对称底图, rotational_pattern
  - relation:旋转轨道表决, rotation_orbit_vote
  - relation:翻转对称, flip_symmetry
  - condition:折叠收拢再镜像补全, fold_then_mirror_complete

### docstring

```text
用旋转轨道表决找出破坏四重对称的缺陷格，把碎片折叠回左上象限拼成半个图形，再镜像补全后裁剪输出。

输入结构：
- 偶数边长正方形网格，底图在设计上关于中心 90 度旋转对称（四重）。
- 少数格子被改色破坏对称，同一旋转轨道内至多一个缺陷；缺陷颜色可能与底图用色相同，
  无法靠色彩显眼度发现。

规则：
- 每格与它绕中心旋转 90/180/270 度的三个像组成四元轨道；轨道中三格一致、一格不同者，
  那一格即缺陷格。
- 把每个缺陷格用旋转对称折叠到左上象限（四个轨道位置恰有一个落在左上象限），保留缺陷
  自身的颜色；全部碎片折叠后拼合成一个残缺图形。
- 该拼合结果恰是某个左右镜像对称图形的左半边；做镜像补全得到完整图形。
- 输出为补全后完整图形的最小外接矩形裁剪，其余位置为黑。

关键洞察：
- 散落四个象限的"噪声"其实是同一幅隐藏图案被旋转打散的碎片；两层对称一个用于收集、
  一个用于生成——先借全局旋转对称把碎片收拢成半身，再识别出"这只是半身"并用局部镜像
  补完，单用任何一层都得不到答案。
```

## 5. 角位旋转印章

- 参考题目：e734a0e8, a61ba2ce
- tags:

  - operation:旋转, rotate
  - object:分隔网格, separator_grid
  - object:模板图块, template_tile
  - object:标记像素, marker_pixel
  - relation:标记指定放置位置, marker_position
  - relation:朝向映射, orientation_mapping
  - condition:角位差决定旋转量, corner_offset_rotation

### docstring

```text
把模板图块盖到每个有角标记的图块里，旋转量由模板自身锚角与目标标记角的相对位置决定。

输入结构：
- 分隔色的整行整列把网格划分成同尺寸的矩形图块。
- 唯一一个图块内含彩色图案，且该图块的某个角格上有一个分隔色像素充当锚点。
- 若干背景图块的某个角格上也各有一个分隔色像素作为标记。

规则：
- 对每个带角标记的背景图块，把模板图块整体旋转后盖入：旋转量取 0/90/180/270 度中
  唯一能把模板锚点角送到该图块标记角的那一个。
- 模板图块与分隔线保持不变；无标记的图块保持不变。

关键洞察：
- 标记不只指明"贴在哪"，它在图块内的角位还是一个旋转刻度盘：同一枚分隔色像素同时
  承担放置与定向两种编码，只看位置不看角位会在多数示例上失败。
```

## 6. 封口与洪水

- 参考题目：4c3d4a41, 543a7ed5, b9630600
- tags:
  - operation:嵌入对齐, insert_and_align
  - operation:旋转, rotate
  - operation:洪泛填充, flood_fill
  - object:空心框架, hollow_frame
  - object:缺口, gap
  - object:塞块, plug
  - relation:形状互补匹配, shape_complement_matching
  - relation:区域可达性, region_reachability
  - condition:搬运后拓扑定干湿, post_move_topology

### docstring

```text
把散落的塞块旋转后嵌进各自唯一匹配的框架缺口，再从边界放洪水，封住的房间保持干燥、漏风的房间被灌满。

输入结构：
- 背景色网格上有若干同色空心矩形框架，每个框架的墙上开有一个形状各异的缺口。
- 空白处散落彩色塞块，多数塞块的形状（允许旋转）恰与某一个缺口互补。
- 可能另有与任何缺口都不匹配的干扰塞块，也可能有配不到塞块的框架。

规则：
- 每个可匹配塞块经 0/90/180/270 度旋转后移入其唯一匹配的缺口，其原位置恢复为背景。
- 完成全部封口后，从网格边界做洪泛：所有四连通可达边界的背景格涂成青色（青色不出现在输入中）。
- 被完全封闭的框架内部保持背景色；未封上的框架内部被洪水从缺口灌入；干扰塞块留在原地不动。

关键洞察：
- 洪水的走向由搬运完成后的拓扑决定——塞块离开原地打开一条通路，堵上缺口又关闭另一条；
  必须先在脑中完成全部搬运才能判断哪里干哪里湿，直接对输入做封闭区域填充必然出错。
```

## 7. 三尺度会诊

- 参考题目：8719f442, af24b4cc
- tags:
  - operation:像素放大, pixel_scaling
  - operation:多数决, majority_vote
  - object:精灵体, sprite
  - object:块格阵列, block_lattice
  - relation:格位映射, cell_block_mapping
  - relation:跨尺度表决, cross_scale_vote
  - condition:三票多数定真值, three_vote_majority

### docstring

```text
同一图形的三份不同尺度摹本都带噪声，对每个逻辑格做跨尺度三方表决还原真图形，以最小尺度输出。

输入结构：
- 背景上有同一二值图形的三份摹本，尺度分别为 1 倍、2 倍、3 倍逐像素放大。
- 三份颜色互不相同、位置任意；每份都被少量噪声破坏，放大块内可能部分翻转，
  甚至整块完全反转（构造保证每块的多数值唯一）。

规则：
- 按外接矩形边长比识别三份摹本与逻辑格阵的对应关系。
- 对每个逻辑格，尺度 s 的摹本以其 s×s 块内的多数值投一票（1 倍直接投该格值）。
- 三票取多数得到真图形；输出真图形以 1 倍尺度、用 1 倍摹本的颜色绘制。

关键洞察：
- 三份没有一份是干净的，任何单份（包括最小那份）都会给出错误格；块内自愈修不了
  整块反转，轻信小样也会答错，真相只能由跨尺度三方表决产生。
```

## 8. 卷折合掌

- 参考题目：0520fde7, f25ffba3
- tags:
  - operation:逻辑交, logical_AND
  - operation:镜像, mirror
  - object:位掩码, bitmask
  - object:分隔列, separator_col
  - relation:连续折叠复合, sequential_fold_composition
  - condition:覆盖层数逐列变化, coverage_depth_varies

### docstring

```text
把左、中面板像卷纸一样依次翻折压到右面板上，落在同一格上的所有层全为蓝时该格输出红。

输入结构：
- 网格被两条竖直灰条分成左、中、右三个蓝/黑面板，宽度可互不相同。
- 构造保证折叠后各层都落在右面板范围内。

规则：
- 先沿左灰条把左面板翻折盖到中面板上，再沿右灰条把中面板连同已盖上的左面板整体
  翻折盖到右面板上。
- 输出与右面板同尺寸：某格为红当且仅当右面板该格为蓝、且所有折叠后落在该格上的层
  在该处也都为蓝；其余为黑。

关键洞察：
- 对齐方式既不是整体平移也不是单次镜像，而是连续卷折的复合：左面板经两次翻折落到
  右面板上时是平移关系（负负得正），中面板却是镜像关系，且不同列被 1、2 或 3 层覆盖，
  参与合取的层数随位置变化——只有还原折叠过程才能同时解释全部示例。
```
