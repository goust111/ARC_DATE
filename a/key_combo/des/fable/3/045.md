## 1. 珠计传形

- 参考题目题号: `a47bf94d`, `72a961c9`, `6e02f1e3`
- tags:
  - operation:传输, transmit
  - operation:计数, counting
  - operation:形状变换, shape_transform
  - object:线路网络, wire_network
  - object:令牌, token
  - object:珠子标记, bead_marker
  - relation:端点配对, endpoint_pairing
  - condition:计数定循环步数, count_sets_cycle_steps

### docstring

```text
沿导线把端点令牌传送到对面端点，令牌形状按导线上珠子的数量沿固定循环推进。

输入结构
- 背景色画布上有若干条互不接触的单色导线。
- 每条导线恰有一端以端点像素为中心画有一个 3×3 令牌（实心块、X 形或菱形之一），另一端为空。
- 导线路径上嵌有若干个与导线不同色的单像素珠子，各导线的珠子数不同。

规则
- 令牌形状构成固定循环：实心块 → X 形 → 菱形 → 实心块。
- 每条导线把源令牌传到空端：结果形状 = 源形状沿循环推进 k 步，k 为该导线上珠子的数量。
- 结果令牌使用源令牌的颜色，以空端端点像素为中心画出。
- 源令牌、导线与珠子全部保持不变。

关键洞察
- 珠子不是装饰或障碍，而是循环推进的计步器；珠子数恰为 3 的倍数时形状原样复制，
  只看单条导线极易误判为"复制"或"固定推进一步"，必须跨导线对比珠子数才能识破。
```

## 2. 隐形取景框

- 参考题目题号: `6cdd2623`, `8731374e`
- tags:
  - operation:裁剪, crop
  - operation:连线, draw_line
  - object:标记像素, marker_pixel
  - object:画布边界, canvas_boundary
  - object:隐形矩形, implicit_rectangle
  - relation:边界定位, boundary_pos
  - relation:行列交叉, row_col_cross
  - condition:生成元定隐形窗口, generators_define_window
  - condition:标记展为整行整列, marker_to_row_col
  - condition:忽略干扰项, ignore_distractors

### docstring

```text
用边界专属色的四个像素定义一个从未画出的矩形取景框，裁出框内区域并把其中的窗口专属色像素展成整行整列。

输入结构
- 画布上散布多种颜色的噪声像素。
- 恰有一种颜色 A 只出现在画布边界上，共四个像素：其中两个位于上或下边界（给出两列），
  两个位于左或右边界（给出两行）。
- 这两行两列围出一个矩形窗口（含端行列），窗口本身从未被画出。
- 恰有一种颜色 B 的所有像素都落在窗口内部；其余颜色在窗口内外均有分布。

规则
- 输出为窗口大小的网格。
- 底色取窗口内数量最多的颜色。
- 对 B 的每个像素，在输出坐标系内把其所在整行与整列涂成 B。
- 窗口内其余噪声色全部丢弃，窗口外一切不进入输出。

关键洞察
- 参与规则的矩形从未被完整画出，画面上只有它的四个边界生成元；
  A 与 B 分别是取景器与行列控制器，都要靠"专属分布域"而非颜色本身来识别。
```

## 3. 层叠筛落

- 参考题目题号: `f83cb3f6`, `67385a82`
- tags:
  - operation:投射下落, gravity_drop
  - operation:重涂色, recolor
  - operation:擦除, erase
  - object:筛条, sieve_bar
  - object:散布像素, scattered_pixel
  - relation:级联穿透, cascade_passthrough
  - relation:堆叠支撑, stacking_support
  - condition:缺口即通道, gap_is_channel
  - condition:承接者定色, catcher_sets_color
  - condition:漏尽则擦, erase_if_all_missed

### docstring

```text
散点穿过带缺口的多层筛条下落，停在第一个能接住它的支撑之上并逐个堆叠，落定后取承接筛条的颜色，全部漏过者被擦除。

输入结构
- 背景画布上有若干条水平、一像素厚、颜色互不相同的筛条，各条在不同列位置留有缺口。
- 筛条上方散布同一种颜色的孤立源像素。

规则
- 源像素按所在列竖直下落：正下方紧邻格是筛条像素或已落定像素时停下，
  是缺口或空格则穿过继续下落。
- 同一列的多个源像素按位置低者先落，后落者堆叠在先落者正上方。
- 落定后，源像素改涂为其所在堆最底部所接触的那条筛条的颜色。
- 穿过所有筛条仍未被接住的源像素从输出中擦除。
- 筛条保持不变，源像素原位置清空。

关键洞察
- 缺口不是损坏而是通道：每列的落点由该列自上而下第一个非缺口筛条决定；
  源像素并不保留自己的颜色，而是被承接它的筛条整堆重染。
```

### docstring

```text
按侧边图例列给出的顺序把四个等高色层合成为一层，图例中缺席的层整层作废。

输入结构
- 画布主体分为四个等高水平条带，每带是同一尺寸的单色掩码，颜色互不相同。
- 主体右侧隔一列空白后有一列图例：自上而下排列若干彩色像素，颜色取自条带色，
  数量可以少于四个。

规则
- 输出为单个条带尺寸的网格。
- 每个位置按图例自上而下的颜色顺序依次查询对应条带，取第一个在该位置为前景的条带颜色。
- 图例中未出现的条带色，其条带整体不参与合成。
- 参与条带全为背景的位置输出背景。

关键洞察
- 叠放顺序不是条带的自然上下顺序，而由图例列显式编码——某个示例中图例恰为自然顺序，
  是诱使读者忽略图例的陷阱；图例还兼作滤除器，缺席即整层删除。
```

## 5. 真身辨影

- 参考题目题号: `103eff5b`, `e2092e0c`
- tags:
  - operation:模式匹配, pattern_match
  - operation:旋转, rotate
  - operation:像素放大, pixel_scale_up
  - operation:重涂色, recolor
  - operation:擦除, erase
  - object:多色模板, multicolor_template
  - object:单色剪影, monochrome_silhouette
  - relation:旋转等价匹配, rotation_class_match
  - condition:唯一真身, unique_true_match
  - condition:镜像即伪影, mirror_is_decoy

### docstring

```text
在多个候选剪影中找出小模板经旋转与整数放大后的真身，为其着色并擦除所有伪影。

输入结构
- 背景画布上有一个小的多色模板和若干个大得多的单色剪影，各剪影颜色互不相同。
- 恰有一个剪影等于模板前景形状经某个 90 度倍数旋转再整数放大的结果。
- 其余剪影是模板镜像后放大、或局部改动一两块后的伪影。

规则
- 找出唯一能由模板经旋转加整数放大得到的剪影。
- 按该旋转与放大倍数，把模板各像素的颜色逐块填入这个剪影，替换其原色。
- 其余剪影整体擦除为背景；模板与背景保持不变。

关键洞察
- 匹配必须在旋转等价类内逐块核对且不含镜像；伪影专为"轮廓大致相同"的直觉设下陷阱，
  真身与伪影的区分不在颜色与大小，而在变换群的成员资格。
```

## 6. 格内偏移即速度

- 参考题目题号: `20981f0e`, `72a961c9`
- tags:
  - operation:平移, translate
  - operation:计数, counting
  - object:标记点阵, marker_lattice
  - object:精灵图, sprite
  - object:格元, lattice_cell
  - relation:偏移向量定方向, offset_vector_as_direction
  - condition:面积编码距离, area_encodes_distance
  - condition:居中者不动, centered_stays

### docstring

```text
把每个精灵在其格元内的偏移方向读作速度方向、像素面积读作步数，沿点阵把精灵移入目标格元并居中。

输入结构
- 一种颜色构成完整规则的点阵标记，把画布划分为相同大小的格元。
- 另一些颜色的精灵各自完整落在某个格元内，多数偏离该格元中心。

规则
- 每个精灵的移动方向 = 从其格元中心指向精灵包围盒中心的方向（水平、竖直或对角八向之一）。
- 移动格数 = 该精灵的像素面积。
- 精灵按原形状重画在目标格元的正中，原位置清空。
- 恰好居中的精灵原地保持不动。
- 点阵标记保持不变。

关键洞察
- "归位居中"只是表象：格内偏移不是要被修正的误差，而是编码方向的指令，
  面积则是它的里程——同一形状放在格内不同角落，会走向完全不同的目的地。
```
