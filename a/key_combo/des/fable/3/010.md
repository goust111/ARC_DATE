## 1. 抽走最底层矩形并还原周期底纹

- 参考题目: `22425bda`, `1a2e2828`, `abbfd121`, `484b58aa`
- 难度评审: `达标`
- tags:
  - operation:层序推断, infer_layer_order
  - operation:擦除, erase
  - operation:补全, completion
  - object:实心矩形, solid_rectangle
  - object:周期平铺图案, periodic_tile
  - relation:遮挡层次, occlusion_order
  - condition:全败于重叠者为底, loses_all_overlaps_is_bottom

### docstring

```text
从互相叠压的实心矩形堆中找出层序最底的那一个，将它抽走，并用周期底纹恢复它独占的覆盖区域。

输入结构：
- 网格底层是一个小周期的行列平铺多色图案。
- 若干纯色实心矩形叠放其上、互有重叠，每处重叠只显示较高层矩形的颜色。
- 层序构成偏序，其中恰有一个矩形不压住任何其他矩形（最底层），但可能有多个
  矩形无人压住（顶层不唯一）。
- 每个矩形四条边均有部分可见，其完整边界可由可见部分补全；最底层矩形被遮住
  的面积并非最大。

规则：
- 在每处重叠区域，可见颜色属于较高层矩形，据此为每对重叠矩形建立上下约束。
- 找出在其全部重叠处均不显示自身颜色、即不压住任何矩形的唯一最底层矩形。
- 由其可见部分补全完整矩形边界，将其整体抽走：它与其他矩形重叠的格子保持
  不变（那里本就显示上层颜色），它独占的格子按周期底纹的花纹恢复。

关键洞察：
- 最底层矩形既不是缺损最大的也不是最小的，它的身份只藏在"每处重叠的可见色
  都不是它"这一层序事实里；抽走后要恢复的花纹从未在该区域出现过，必须从画
  面其余可见底纹推断周期并延拓进来。
```

## 2. 双面板共同空白的互补拼合

- 参考题目: `fafffa47`, `228f6490`, `7b7f7511`
- 难度评审: `达标`
- tags:
  - operation:逐格比较, cell_comparison
  - operation:形状匹配, shape_matching
  - operation:嵌入, embed
  - object:堆叠掩码, stacked_mask
  - object:精灵体, sprite
  - object:干扰体, distractor
  - relation:背景交集, bg_intersection
  - condition:互补拼成实心矩形, complement_forms_solid_rect

### docstring

```text
两个堆叠掩码面板背景的交集定义一个从未画出的形状，在散布精灵中找出能与它
无缝拼合成实心矩形的唯一精灵，输出拼合结果。

输入结构：
- 网格被分隔线分成两部分：一部分是上下堆叠的两个等尺寸面板，各由共享背景色
  加一种各自前景色构成。
- 另一部分散布若干互不相触的单色精灵，形状颜色各异。
- 其中恰有一个精灵与"双背景交集形状"本身同形（诱饵），另有唯一一个精灵能与
  该形状互补拼合。

规则：
- 逐格对比两个面板，取两边都为背景色的位置集合，得到一个从未被画出的目标形状。
- 在精灵中找出唯一一个不旋转不镜像、仅平移后能与目标形状无缝无重叠拼合成
  一个实心矩形的精灵。
- 输出该实心矩形：其中目标形状部分涂红色，精灵部分保留精灵原色。

关键洞察：
- 参与拼合的一方在画面上从未出现，它是两个面板背景的交集；且匹配准则不是
  同形而是互补——与交集形状同形的那个精灵是诱饵，答案是能把它补成实心矩形
  的那一个。
```

## 3. 相位锁定的色键平铺盖章

- 参考题目: `92e50de0`, `58743b76`, `484b58aa`, `8a371977`
- 难度评审: `达标`
- tags:
  - operation:印章覆盖, stamp
  - operation:重涂色, recolor
  - object:格子结构, lattice
  - object:图例, legend
  - object:种子图案, seed_motif
  - relation:周期平铺映射, periodic_key_tiling
  - condition:同色条目锁相位, same_color_anchors_phase

### docstring

```text
把小色键按周期平铺到棚架单元格阵列上，相位由种子颜色在色键中的唯一同色条目
锚定，再逐格以映射色盖章种子图案。

输入结构：
- 棚架色画出完整横竖分隔线，把网格分成 R×C 个空单元格阵列。
- 另一独立区域有一个 r×c 实心色块矩阵作为色键（r<R，c<C），色键中恰有一格
  颜色与种子图案相同。
- 恰有一个空单元格内画有小图案（种子）。

规则：
- 把色键按 r×c 周期平铺到单元格阵列上，平铺相位不是从左上角开始，而必须
  平移使种子所在单元格恰好对应色键中那格同色条目。
- 每个单元格按其对应色键条目的颜色画入一份种子图案，格内偏移与种子相同。
- 对应到背景色条目的单元格保持空白；种子单元格保持原样。

关键洞察：
- 色键既不是要复制的图形，也不是从左上角平铺的表；种子颜色在色键中的唯一
  位置充当相位锚点，先对齐、再映射、最后逐格换色盖章。
```

## 4. 由叠影反解模板

- 参考题目: `a395ee82`, `88a10436`, `fafffa47`
- 难度评审: `达标偏上`
- tags:
  - operation:反解模板, template_inversion
  - operation:印章放置, stamp
  - object:复合图形, composite_figure
  - object:单像素布局, singleton_layout
  - object:交叠区域, overlap_region
  - relation:平移副本并叠, translated_union
  - condition:覆盖次数约束定形, coverage_count_constrains

### docstring

```text
复合图形由未知单色模板的若干平移副本并叠而成，依据锚点布局与重叠色约束
反解出模板本身。

输入结构：
- 背景上有一个复合图形：恰被一个副本覆盖的格子显示模板色 T，被两个及以上
  副本覆盖的格子显示重叠色 O。
- 另一处有一组稀疏单像素标记（一个原点色像素与若干 T 色像素），其相对偏移
  即各副本锚点的相对偏移。
- 布局保证模板唯一。

规则：
- 把标记读为副本的锚点偏移集合。
- 求唯一的模板掩码，使得按全部偏移各放一份后：并集恰为复合图形的全部非背景
  格，且被两份及以上覆盖的格恰为 O 色格、恰被一份覆盖的格恰为 T 色格。
- 输出模板的最小包围盒，以 T 色绘制。

关键洞察：
- 模板从未单独出现；每份副本都会画出模板的每个格子，因此模板必含于"图形按
  各锚点反向平移后的交集"，而 T/O 两类格子的覆盖次数约束把交集中的多余候选
  格逐一排除。
```

## 5. 跨色系互补修复重复瓦片

- 参考题目: `7b7f7511`, `484b58aa`, `abbfd121`
- 难度评审: `达标偏上`
- tags:
  - operation:补全, completion
  - operation:重涂色, recolor
  - operation:裁剪, crop
  - object:重复瓦片, repeated_tile
  - object:缺失像素, missing_pixel
  - relation:轴向复制, axial_dup
  - relation:颜色双射, color_bijection
  - condition:三级冗余兜底, three_level_redundancy

### docstring

```text
网格是同一瓦片沿一条轴的两份拷贝，但第二份经过了未知的颜色双射置换，两半
各有黑色缺失；修复须先反解色映射再互相借色，双方同缺处用瓦片内部最强自平移
兜底。

输入结构：
- 网格是某矩形瓦片沿水平或垂直轴复制成的两份相邻拷贝，第二份的每种颜色都被
  一个未知的颜色双射统一替换（两半肉眼看颜色完全不同，但结构同构）。
- 两半都被若干黑色缺失格污损，少数位置两半同时缺失。
- 瓦片自身含有更小的内部周期结构。

规则：
- 找出复制轴：在该轴向上两半的对应格（双方可见处）构成一致的颜色一一对应
  关系，另一轴则出现映射冲突。
- 由对应格恢复完整的颜色双射。
- 输出第一半色系下的单个瓦片：第一半可见处取原色，第一半缺失而第二半可见处
  取第二半颜色经逆映射后的颜色。
- 两半同处皆缺失时，用已恢复瓦片中可见像素的最强无冲突自平移向量恢复该格颜色。

关键洞察：
- 两半乍看是两幅无关图案，隐藏的复制关系必须透过颜色双射才能看见；借色必须
  先反解映射，映射也补不上的洞再靠瓦片自身更细的周期，三层机制逐级兜底。
```

## 6. 以周期性为准则的拼图组装

- 参考题目: `e8686506`, `abbfd121`, `7b7f7511`
- 难度评审: `达标`
- tags:
  - operation:拼图组装, jigsaw_assemble
  - object:碎片, fragment
  - object:周期平铺图案, periodic_tile
  - relation:拼合无缝, seamless_packing
  - condition:周期性定唯一拼法, periodicity_fixes_assembly

### docstring

```text
把散布的多色碎片无旋转平移拼入一个矩形，唯一拼法由"拼成结果必须是行列周期
图案"这一隐藏约束确定。

输入结构：
- 背景上散布若干互不相触的多色碎片（4 连通块），画面中没有任何完整矩形或
  完整周期图案出现。
- 碎片总面积恰为某矩形面积，矩形尺寸由总面积与可行性唯一确定。

规则：
- 把全部碎片不旋转不镜像地平移拼入该矩形，恰好无缝不重叠铺满。
- 拼成的矩形必须存在严格小于自身的水平与垂直周期（行列重复花纹）。
- 输出拼好的矩形。

关键洞察：
- 目标图案从未给出，周期性是隐藏的拼装准则；碎片色块衔接后必须自洽形成重复
  花纹，这一全局约束把每块碎片的位置钉死；按对称性去拼是诱饵。
```
