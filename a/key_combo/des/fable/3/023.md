## 1. 滚动入槽

- tags:
  - operation:平移, translate
  - operation:旋转, rotate
  - object:可移动组件, movable_component
  - object:内部槽位, interior_socket
  - relation:距离编码旋转, distance_encodes_rotation
  - condition:滚动语义, rolling_semantics
- 参考题目题号: `8b9c3697`, `6ffbe589`, `e48d4e1a`, `ed36ccf7`

### docstring

```text
将每个散件沿对齐轴滑入结构体的方形空腔，滑行距离决定其落位时旋转的次数。

输入结构
- 背景为最常见色。若干由墙色构成的大结构体，每个内部有一个 3×3 的背景空腔。
- 每个空腔的中心与某个外部散件的中心在同一行或同一列上对齐。
- 散件为单色、形状不对称、包围盒 3×3；每个空腔沿对齐轴恰有唯一散件与之对应。

规则
- 对每个空腔，沿对齐轴找到与其对齐的唯一散件，设两中心相距 d 格。
- 把散件从原位擦除，按顺时针旋转 (d mod 4)×90 度后放入空腔，使包围盒与空腔重合。
- 结构体与其余像素保持不变。

关键洞察
- 散件像"滚动"一样前进，每走一格翻转 90 度。
- 落位朝向无法从空腔形状读出（空腔是无信息的方腔），唯一的信息源是行进距离本身。
```

## 2. 连锁多数决

- tags:
  - operation:填充, fill
  - operation:连锁传播, cascade
  - object:房间晶格, room_lattice
  - object:分隔墙, separator_wall
  - relation:邻接多数决, adjacent_majority
  - condition:同步轮次迭代, synchronous_rounds
- 参考题目题号: `7c8af763`, `68b67ca3`

### docstring

```text
种子颜色在房间晶格中按"邻居多数决"逐轮扩散，直到所有房间被染色。

输入结构
- 等间距的分隔行与分隔列把网格划分成矩形房间阵列。
- 少数房间内含一个单像素种子色，其余房间为背景空房。

规则
- 先把每个种子房间整体染成其种子色。
- 之后反复执行同步轮次：某空房若其上下左右已染色邻居房间中存在唯一的多数色，
  则本轮结束时整间染成该色；无唯一多数则本轮跳过、留待后续轮次。
- 迭代至所有房间染色为止；分隔墙保持不变。
- 示例的布局保证每个空房最终都会在某一轮出现唯一多数。

关键洞察
- 染色不是一次性的近邻扩散：后染的房间会成为新的选票，改变更远房间的归属。
- 用"离哪个种子最近"推测会在多数与最近不一致的房间出错，必须按轮次演化求不动点。
```

## 3. 周期靶环

- tags:
  - operation:填充, fill
  - operation:周期推断, period_inference
  - object:全行条, full_row_bar
  - object:全列条, full_column_bar
  - object:标记像素, marker_pixel
  - relation:距离映射, distance_mapping
  - condition:切比雪夫距离, chebyshev_distance
  - condition:最小一致周期, minimal_consistent_period
- 参考题目题号: `67a423a3`, `ac0c2ac3`, `1ae2feb7`, `e7b06bea`

### docstring

```text
以满行满列条的交点为圆心，从稀疏取样点还原按切比雪夫距离呈周期的同心环调色，并涂满全图。

输入结构
- 一条满行与一条满列的灰条交叉于网格内部一点。
- 背景上散布若干彩色标记像素；到交点切比雪夫距离相同的标记颜色相同，但只有部分距离有标记。
- 标记的距离覆盖了周期内每个余数类，足以唯一确定周期与调色序列。

规则
- 每个标记规定"到交点切比雪夫距离为 d 的整圈环"的颜色。
- 找出与全部标记一致的最小周期 p（距离 d 与 d+p 的环同色），据此补出所有未取样距离的颜色。
- 把每个格子按其到交点的距离染成对应环色，覆盖灰条与原标记，输出中不留背景。

关键洞察
- 完整的环图案从未被画出，画面上只有它的少数生成元。
- 缺失的环色不能就近取或留空，必须先发现"颜色随距离呈周期循环"这一隐藏结构；
  两条灰条不是要保护的对象，只是指出圆心的指针。
```

## 4. 双晶格核对

- tags:
  - operation:下采样, downsample
  - operation:镜像, mirror
  - operation:比对, compare
  - object:奇偶晶格, parity_lattice
  - relation:交错双图层, interleaved_dual_layers
  - condition:一致保留不一致清除, agreement_keep
- 参考题目题号: `68b67ca3`, `c35c1b4c`, `de493100`

### docstring

```text
把交错存放的两张半分辨率图对齐核对，仅保留两图一致的像素。

输入结构
- 输入为 2H×2W 网格。偶行偶列格存放图 A，奇行奇列格存放图 B。
- 其余混合奇偶格全部为背景。
- 图 B 在存放时被左右镜像过。

规则
- 取出图 A（偶行偶列晶格）与图 B（奇行奇列晶格），先把 B 左右翻回。
- 输出 H×W 网格：两图同一格颜色相同时输出该色，不同或任一为背景时输出背景。

关键洞察
- 这不是把分隔行列删掉的普通下采样——夹在"分隔线"位置的像素不是杂波，
  而是另一张被镜像收纳的图。
- 只有发现两套奇偶晶格并把第二套翻转对齐，逐格核对才能成立；
  直接取偶晶格在两图不一致处必然出错。
```

## 5. 染色弹球

- tags:
  - operation:射线延伸, ray_cast
  - operation:描边, trace_path
  - object:孤立像素, isolated_pixel
  - object:阻挡像素, blocker_pixel
  - relation:反射弹回, reflection_bounce
  - relation:状态继承, state_inheritance
  - condition:阻挡即换色, blocker_swaps_color
- 参考题目题号: `a3df8b1e`, `55783887`, `8b9c3697`

### docstring

```text
光点从底边沿对角线向上弹射，撞到彩色挡点既反弹又"染"上挡点的颜色，画出一条分段变色的折线。

输入结构
- 黑底网格，底行有唯一起点像素。
- 内部散布若干彩色单像素挡点，多数挡点并不在最终路径上。

规则
- 光点自起点向右上方每步走一格对角线，途经格涂当前颜色（初始为起点色）。
- 撞到左右边界时水平方向反转。
- 下一步对角格若是挡点，则不进入该格，同样水平反转，且此后涂色改为该挡点色；
  挡点自身保留原色。
- 到达顶行后停止；未被路径撞到的挡点原样保留。

关键洞察
- 路径形状与颜色相互纠缠——哪些挡点"在路径上"取决于此前的反弹，
  而每次命中又同时改写后续轨迹与涂色。
- 必须按时间顺序模拟整条折线，无法按几何位置一次性判定挡点的取舍。
```

## 6. 投影重建

- tags:
  - operation:重建, reconstruct
  - operation:填充, fill
  - object:边界投影, border_projection
  - object:矩形, rectangle
  - object:探针像素, probe_pixel
  - relation:叠放次序, z_order
  - relation:压制关系传递闭包, occlusion_transitive_closure
  - condition:无配对即忽略, unmatched_ignored
- 参考题目题号: `de493100`, `67a423a3`, `aee291af`, `1ae2feb7`

### docstring

```text
由顶边与左边的彩色投影段重建各实心矩形，再用内部少量"露头"像素反推它们的叠放全序并整体渲染。

输入结构
- 内部大体为背景；顶行分布若干互不相同颜色的水平段，左列分布同一批颜色的竖直段，
  每种矩形色在两条边上各出现一段。
- 矩形重叠区域内散布少量彩色探针像素，给出该处最终可见的颜色。
- 另有至多一种颜色只在一条边上出现。

规则
- 每个双边配对色定义一个实心矩形：行范围取自左列段，列范围取自顶行段。
- 每个探针位于至少两个矩形的公共区域内，指明该处哪个矩形位于最上层；
  把全部探针给出的两两压制关系做传递闭包，得到唯一的叠放全序。
- 清空边界标记与探针，在同尺寸背景画布上按该全序从底到顶依次绘制各实心矩形，
  后画的覆盖先画的；只出现一次的颜色是残缺投影，直接舍弃。

关键洞察
- 矩形本体与叠放次序都从未被直接画出——前者只有两条边上的影子，
  后者只有重叠处的几枚露头像素。
- 面积大小、颜色读取顺序等表面线索都不是排序依据，必须由探针的压制关系传递推出全序。
```

## 7. 形状字典

- tags:
  - operation:重涂色, recolor
  - operation:擦除, erase
  - object:图例区, legend_strip
  - object:标记字形, marker_glyph
  - object:前景掩码, foreground_mask
  - relation:形状编码颜色, shape_encodes_color
  - condition:旋转镜像不变匹配, transform_invariant_match
  - condition:字形颜色是诱饵, glyph_color_decoy
- 参考题目题号: `009d5c81`, `aee291af`, `7df24a62`, `d23f8c26`

### docstring

```text
用画面一角被分隔线隔开的"字形→色样"图例，为主区每个大掩码查出新颜色并整体重涂。

输入结构
- 一条满行（或满列）分隔线把网格切成窄图例区与主区。
- 图例区排列若干词条，每条由一个小字形与其紧邻的一个纯色色样格组成。
- 主区有若干大块单色掩码，每块内部嵌着一个异色小字形；嵌入字形是某图例字形
  经过旋转或镜像后的副本，且嵌入字形自身的颜色恰好等于其他词条的色样色。

规则
- 对每个掩码，把其内嵌字形在旋转与镜像等价下与图例字形匹配。
- 将掩码连同内嵌字形全部重涂为匹配词条的色样色。
- 图例区与分隔线原样保留。

关键洞察
- 字形是查询键而非颜色来源——按字形自身颜色重涂正是布置好的陷阱。
- 键在写入掩码时被旋转镜像过，必须做形状等价匹配而不是逐像素比对。
```
