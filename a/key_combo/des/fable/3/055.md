## 1. 隐形橡皮擦

- tags:
  - operation:并集补全, union_completion
  - operation:取补集, complement_extraction
  - operation:裁剪, crop
  - object:残缺副本, partial_copy
  - object:隐形模板, hidden_template
  - relation:缺失区域平移同构, missing_regions_translated_copies
  - condition:答案仅以缺失存在, answer_exists_only_as_absence
- 参考题目题号: 11 (f8cc533f)、1 (bf699163)、4 (a87f7484)

### docstring

```text
输出从未被画出的"橡皮擦"形状——它只以每个残缺副本中的缺失区域存在。

输入结构
- 背景为黑色，前景只有一种颜色。
- 前景构成若干个彼此分离的连通块，每个连通块都是同一个隐藏模板
  被抹去一小块后的残缺副本。
- 被抹去的区域是同一个"橡皮擦"形状在模板内部不同位置的平移拷贝，
  且不触及模板边界，因而所有副本的包围盒大小一致；不同副本的
  缺失位置可能部分重叠。
- 模板的每个格子至少在一个副本中出现。

规则
- 将每个副本按包围盒对齐并取并集，得到完整的模板掩码。
- 对每个副本，用模板减去该副本，得到其缺失区域；所有缺失区域
  是同一形状的平移拷贝。
- 输出该形状的紧包围盒裁剪，其格子填前景色，其余为背景。

关键洞察
- 要输出的对象在画面上从未出现；补全模板不是目的，模板只是
  显影"负形"的底片，逐副本取补集才能看到同一把橡皮擦。
```

## 2. 钥匙孔连环

- tags:
  - operation:形状匹配, shape_matching
  - operation:计数, counting
  - operation:嵌套包裹, nested_wrapping
  - object:带孔实心块, blob_with_holes
  - object:钥匙孔, keyhole
  - object:同心方框, concentric_square_frame
  - relation:缩放内嵌链, scaled_containment_chain
  - condition:孔洞数定层厚, hole_count_as_thickness
  - condition:孔洞双重读取, holes_read_twice
- 参考题目题号: 2 (37d3e8b2)、13 (45a5af55)、7 (2a5f8217)

### docstring

```text
孔洞既是钥匙孔也是刻度：谁的轮廓能塞进谁的钥匙孔决定嵌套顺序，
孔洞总数决定每层厚度。

输入结构
- 黑色背景上散布若干互不相同颜色的实心连通块，每块内部有 1 至 4 个
  封闭背景孔洞。
- 除一个对象外，每个对象恰有一个"钥匙孔"：另一个对象的整体轮廓
  恰是该孔形状的 2 倍放大；其余孔洞均为 1x1 小孔。
- 只有小孔的对象是最内层；恰有一个对象的轮廓不被任何钥匙孔匹配
  （缩放意义下），是最外层。
- 对象的面积、包围盒大小与空间位置都与层序无关，内层对象可以
  比外层对象更大。

规则
- 由"A 的钥匙孔 x2 = B 的轮廓"建立 A 到 B 的内嵌链，从最外层
  一直排到最内层。
- 最内层对象化为中心实心正方形，边长等于其孔洞数；沿链向外，
  每个对象依次包裹一圈方框，厚度等于其孔洞总数（含钥匙孔），
  颜色为其自身颜色。
- 输出最终的同心方形图案。

关键洞察
- 嵌套顺序不写在位置或大小里，而是以 1:2 的缩放对应刻在拓扑上——
  谁能"塞进"谁的钥匙孔；同一批孔洞再被读第二遍，作为计数给出层厚。
```

## 3. 谁是真引导

- tags:
  - operation:对称补全, symmetry_completion
  - operation:裁剪, crop
  - object:稀疏引导色, sparse_guide_color
  - object:对称图案, symmetric_pattern
  - relation:双轴镜像轨道, biaxial_mirror_orbit
  - condition:结构判定真引导, structurally_identified_guide
  - condition:框内区域被篡改, framed_region_corrupted
- 参考题目题号: 1 (bf699163)、8 (e66aafb8)、16 (b8825c91)

### docstring

```text
先从两种稀有色中判定谁是真正的引导框，再用双轴镜像修复其框内
被篡改的区域，并只输出该区域。

输入结构
- 一个多色图案在水平与垂直中轴镜像下自洽，仅有两处例外。
- 两种稀有色各以少量散点出现：一种散点自身严格遵守双轴对称，
  是图案的一部分；另一种不参与对称，其包围盒框住一块矩形区域。
- 该矩形区域内部有若干格子被改写成图案调色板中的其他颜色，
  破坏了对称；被改写格子的镜像同伴都完好。
- 引导色散点不落在其包围盒的严格内部。

规则
- 对每种稀有色检查两件事：其散点集合是否双轴对称、其包围盒内部
  是否存在与镜像同伴矛盾的格子；两项皆异常的那一种是引导色。
- 对引导框严格内部与镜像轨道不符的格子，改写为轨道中位于框外的
  一致颜色。
- 输出修复后的包围盒严格内部子网格。

关键洞察
- 篡改格子用的是正常图案色，无法靠颜色发现，只能靠对称矛盾；
  而输出范围比矛盾格子的范围更大，必须由真引导框决定——先做
  "谁是引导"的结构判定，修复与裁剪才能同时正确。
```

## 4. 顺路盖章

- tags:
  - operation:印章, stamping
  - operation:旋转, rotate
  - object:精灵体, sprite
  - object:朝向像素, nose_pixel
  - object:单像素路标, waypoint_marker
  - relation:车行链路径, rook_chain_path
  - condition:行进方向定朝向, travel_direction_sets_orientation
- 参考题目题号: 12 (985ae207)、18 (4852f2fa)、19 (3e6067c3)

### docstring

```text
沿"每步恰有一个同行或同列的未访问路标"的车行路径行进，
在每个路标处盖一枚按行进方向旋转的精灵印章。

输入结构
- 黑色背景上有一个 3x3 精灵：主体为一种颜色的非对称掩码，
  边中位置嵌一个异色"鼻尖"像素，标出精灵当前的朝向。
- 另有若干同色单像素路标。从精灵中心出发，任意时刻恰有一个
  未访问路标与当前位置同行或同列，由此形成唯一的访问链。
- 每个路标与网格边缘及彼此相距足够远，印章互不重叠。

规则
- 从精灵出发依次访问路标：每一步走向唯一与当前位置同行或同列的
  未访问路标，该步的行进方向为上下左右之一。
- 在每个路标处，以路标为中心盖一枚精灵副本，并整体旋转，
  使鼻尖指向该步的行进方向。
- 原精灵保持不动，路标像素被印章覆盖，其余背景不变。

关键洞察
- 路标不是重复计数，也不是终点色钥匙，而是一条有序路径的站点；
  印章的朝向不由任何显式标记给出，而由"从哪儿来"的运动方向
  隐式决定。
```

## 5. 只闻其影

- tags:
  - operation:投影重建, projection_reconstruction
  - operation:透明叠加, overlay
  - object:边界色段, border_color_run
  - object:隐形矩形, invisible_rectangle
  - relation:同色两轴配对, same_color_axis_pairing
  - relation:阅读顺序定深度, reading_order_as_depth
  - condition:无配偶色段为诱饵, unpaired_run_is_decoy
- 参考题目题号: 9 (03560426)、10 (25e02866)、15 (8597cfd7)

### docstring

```text
矩形从未被画出——顶行和左列的色段是它们仅存的两道投影，
重建后按顶行阅读顺序叠放。

输入结构
- 网格内部全为背景色；只有最上一行与最左一列上有若干条彩色线段
  （色段）。
- 同一颜色恰好在顶行出现一段、在左列出现一段，两段配对定义一个
  隐形实心矩形：行范围取左列段的行区间，列范围取顶行段的列区间。
- 另有个别颜色只在一侧出现、没有配偶，不生成任何矩形。
- 各矩形之间存在重叠。

规则
- 为每个成对颜色重建其矩形。
- 在背景画布上按顶行色段从左到右的次序依次填入各矩形，
  后画的覆盖先画的；无配偶的色段不画且不保留。
- 输出去掉首行与首列后的内部区域。

关键洞察
- 画面上不存在任何矩形，只有它们在两条轴上的残影；顶行同时被
  读两遍——既给出每个矩形的列范围，又以左右次序给出遮挡叠放的
  先后。
```

## 6. 第三帧

- tags:
  - operation:平移, translate
  - operation:旋转, rotate
  - operation:外推, extrapolate
  - object:横分隔线, divider
  - object:双帧画面, two_frames
  - relation:跨帧形状配对, cross_frame_shape_pairing
  - condition:逐对象变换再作用一次, per_object_transform_applied_once
- 参考题目题号: 15 (8597cfd7)、10 (25e02866)、14 (412b6263)

### docstring

```text
分隔线上下是同一场景的连续两帧，为每个对象推断其专属变换并
再作用一次，输出第三帧。

输入结构
- 一条整行灰色分隔线把网格分成等高的上下两块画布。
- 两块画布中出现同一批对象；颜色可能重复，跨帧配对须按掩码形状
  进行，各对象的掩码在旋转等价意义下互不相同。
- 从上帧到下帧，每个对象经历自己的刚性变换：平移一个固定向量，
  其中个别对象还绕自身包围盒中心旋转 90 度（方向由两帧对比确定）。
- 第三帧中所有对象仍完整落在画布内。

规则
- 按形状把上下两帧的对象一一配对，推断每个对象的位移向量、
  是否旋转及旋转方向。
- 对下帧的每个对象再施加一次同样的变换，画在一块与单帧同大的
  背景画布上。
- 输出该第三帧画布。

关键洞察
- 分隔线不是用来比较或计数两侧数量的，上下两块是时间轴上的
  相邻两帧；答案不在画面里，而在"让时间再走一步"。
```

## 7. 指针连环

- tags:
  - operation:排序, ordering
  - operation:堆叠, stacking
  - object:实心矩形, solid_rectangle
  - object:指针像素, pointer_pixel
  - relation:颜色指针链, color_pointer_chain
  - relation:角点重叠, corner_overlap
  - condition:无人指向者为链头, unreferenced_is_head
- 参考题目题号: 9 (03560426)、12 (985ae207)、10 (25e02866)

### docstring

```text
每个矩形肚子里的杂色像素是指向下一个矩形的颜色指针，
按链表顺序把矩形打包成角点重叠的对角链。

输入结构
- 背景为最常见色，其上散布若干互不接触的实心单色矩形。
- 除一个矩形外，每个矩形内部恰有一个异色像素，其颜色等于
  另一个矩形的主体色；没有内部像素的矩形是链尾。
- 恰有一个矩形的主体色不被任何指针指到，是链头。
- 矩形在画面中的空间排列与链序无关。

规则
- 从链头出发沿指针遍历，得到矩形的链表顺序。
- 把画布清为背景，按链序摆放各矩形的纯色副本：第一个贴左上角，
  此后每个矩形的左上角格与前一个矩形的右下角格重合，
  后放者覆盖共享格。
- 输出与输入同尺寸的结果画布。

关键洞察
- 内部像素不是要合并的标记，也不是印章的钥匙，而是"下一个是谁"
  的指针；空间位置是彻底的诱饵，链表结构才是唯一的排序依据。
```
