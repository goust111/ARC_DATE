## 1. 隐形矩形的投影相交

- 参考题目：`673ef223`、`f8ff0b80`、`87ab05b8`
- tags:
  - operation:区域填充, region_fill
  - operation:计数, counting
  - object:边缘条带, edge_bar
  - object:隐形矩形, phantom_rectangle
  - relation:投影对应, projection_correspondence
  - relation:区域相交, region_intersection
  - condition:小面积覆盖大面积, smaller_area_on_top

### docstring

```text
由顶边与左边的同色投影条带还原从未画出的矩形，并只把它们的两两重叠区域涂成面积较小者的颜色。

输入结构：
- 黑色背景网格，顶边一行与左边一列上分布若干段彩色连续条带。
- 每种颜色恰好在顶边有一段、在左边有一段：顶边段给出该色隐形矩形的列范围，左边段给出行范围。
- 隐形矩形本身在画面内部完全不可见；不同颜色矩形的行列范围可能相互交叠。

规则：
- 对每种颜色，由其顶边段与左边段构造轴对齐矩形（行范围 × 列范围），矩形本身不绘制。
- 对每一对相交矩形，将交叠区域填充为其中面积较小矩形的颜色；三个及以上矩形共同覆盖处仍取面积最小者。
- 保留边缘投影条带原样，其余背景不变。

关键洞察：
- 参与规则的矩形从未被画出，画面只有它们在两条边上的投影；输出的着色不是关于条带的，而是这些隐形矩形的相交关系与面积次序。
```

## 2. 分割线连锁反应

- 参考题目：`855e0971`、`b7955b3c`、`673ef223`
- tags:
  - operation:连线, draw_line
  - operation:连锁传播, chain_propagation
  - object:矩形区域, rect_region
  - object:标记像素, marker_pixel
  - relation:相邻接触, adjacency_contact
  - relation:长短轴方向选择, aspect_axis_selection
  - condition:方形区域终止传播, square_region_terminates

### docstring

```text
唯一的标记像素在其矩形内画出垂直于长轴的分割线，分割线端点越界唤醒相邻矩形继续分割，直到方形区域或网格边缘吞掉传播。

输入结构：
- 网格被划分为若干单色矩形区域拼成的马赛克，区域行列对齐。
- 恰有一个稀有色标记像素落在某个非方形区域内部。
- 拼图布局保证传播路径不回环，每个区域至多被到达一次。

规则：
- 含标记的区域按自身长宽比分割：宽区域画过标记的整列，高区域画过标记的整行，线用标记色，止于区域边界。
- 分割线的每个端点若紧邻另一区域，则越过边界的第一格成为该区域的新标记，按该区域自身的长宽比继续画线。
- 新标记落入正方形区域时只染该格并终止该方向传播；线端点到达网格边缘时同样终止。

关键洞察：
- 分割方向不是全局固定的，它随每个被唤醒区域自身的长宽比翻转；整幅输出是一条由单个标记引发、被方形区域截断的连锁反应。
```

## 3. 旋转残片互补

- 参考题目：`e41c6fd3`、`b7955b3c`、`9f27f097`、`3af2c5a8`
- tags:
  - operation:补全, completion
  - operation:旋转配准, rotation_registration
  - object:精灵体, sprite
  - object:遮挡补丁, occluder_patch
  - relation:共享归一掩码, shared_norm_mask
  - relation:四方向旋转副本, four_rotation_copies
  - condition:跨副本恢复被遮内容, cross_copy_recovery

### docstring

```text
网格上四个互不接触的彩色精灵是同一形状的四个旋转副本，各自被灰色补丁遮去一部分，用其余副本的可见部分把每个副本补完并抹除灰色。

输入结构：
- 均匀背景上有四个单色精灵，颜色互不相同，分别是同一掩码旋转 0、90、180、270 度后的摆放。
- 灰色补丁成块地覆盖在精灵及其紧邻背景上，没有任何一个副本是完整的。
- 掩码的每个格子至少在一个副本中可见，且四个副本的旋转配准方式唯一。

规则：
- 通过可见部分对齐四个副本，确定每个副本的旋转角与掩码位置。
- 将四份可见信息在归一坐标下取并集，重建完整掩码。
- 对每个灰色像素，按其所属副本的旋转角回贴重建结果：掩码内的格子涂该副本自身的颜色，掩码外的格子涂背景色。

关键洞察：
- 完整形状从未在画面中出现过，它只能由四个残缺旋转副本互相拼补而成；灰色不是物体而是待恢复的窗口。
```

## 4. 换色转置对称补全

- 参考题目：`0934a4d8`、`73251a56`、`15113be4`
- tags:
  - operation:对称补全, symmetry_completion
  - operation:裁剪, crop
  - operation:重涂色, recolor
  - object:标记矩形, marker_rectangle
  - object:对称图案, symmetric_pattern
  - relation:转置配对, transpose_pairing
  - relation:颜色对合映射, color_involution
  - condition:对称仅在换色意义下成立, symmetry_up_to_recolor

### docstring

```text
方形图案在"转置后按固定颜色对合换色"的意义下自对称，用这条换色对称还原被纯色矩形遮住的补丁并单独输出。

输入结构：
- 方形彩色网格，存在一种颜色其全部像素恰构成一个实心矩形，且该矩形完全位于主对角线一侧。
- 除该矩形外，任意格子 (i,j) 与其转置格 (j,i) 的颜色都通过同一个颜色对合映射相互对应：部分颜色两两互换，其余颜色自映射。
- 对角线上只出现自映射颜色；被遮矩形的转置区域完全可见。

规则：
- 找到唯一构成实心矩形的颜色，确定被遮区域。
- 从所有可见的转置格对中读出颜色对合表。
- 对被遮矩形的每个格子，取其转置格颜色经对合映射后的值填入，仅输出该矩形区域的还原结果。

关键洞察：
- 网格并不字面转置对称，直接镜抄转置格会得到错误颜色；对称只在一个隐藏的换色字典下成立，而字典本身也要从画面中读出来。
```

## 5. 锚定朝向印章

- 参考题目：`5b6cbef5`、`6ecd11f4`、`3af2c5a8`、`67e8384a`
- tags:
  - operation:印章覆盖, stamp_overlay
  - operation:镜像, mirror
  - operation:重涂色, recolor
  - object:种子精灵, seed_sprite
  - object:控制网格, control_grid
  - object:锚点格, anchor_cell
  - relation:像素到块映射, pixel_to_block_mapping
  - relation:锚定方向场, anchor_direction_field
  - condition:同色格为原点, same_color_cell_as_origin

### docstring

```text
控制网格里与印章同色的唯一锚格定义一个方向场，其余彩色格接收染成自身颜色的印章副本，副本按相对锚格的方位做水平和竖直反射。

输入结构：
- 黑色背景上有两个分离对象：一个小的单色不对称印章图案，和一个密集多色控制网格。
- 控制网格中黑格为空位，彩色格为放置位。
- 恰有一个控制格的颜色与印章颜色相同，它就是锚格。

规则：
- 输出画布按控制网格的行列划分为与印章同尺寸的块。
- 锚格对应块放入原朝向、原色的印章。
- 其余每个彩色控制格，把印章染成该格颜色后盖入对应块：该格严格位于锚格所在列右侧则先左右反射，严格位于锚格所在行下方则再上下反射，位于左侧、上方或同行、同列则该轴不反射。
- 黑色控制格对应的块保持全黑。

关键洞察：
- 副本朝向不是网格几何象限决定的（锚格居中时这层诱饵貌似成立），而是以隐藏在控制格中的同色锚为原点的方向场；必须先在调色板里找到印章颜色的那一格。
```

## 6. 谦虚的目录格胞

- 参考题目：`15113be4`、`5b6cbef5`、`e50d258f`
- tags:
  - operation:掩码匹配, mask_matching
  - operation:补全, completion
  - object:格子单元, lattice_cell
  - object:格线, grid_line
  - object:占位图, occupancy_map
  - relation:格子分割, lattice_partition
  - relation:内容与布局同构, content_layout_isomorphism
  - condition:目录不含自身, self_excluding_catalog

### docstring

```text
画面被格线划分成 n×n 个格胞，其中藏着一个"目录"格胞——它的图案描述哪些格胞非空、但把它自己标为空；输出把它自己补进去之后的完整占位图。

输入结构：
- 网格由分隔线划分为 n×n 个同尺寸格胞，每个格胞内部也是 n×n 个像素。
- 部分格胞为空，其余格胞各含一个单色图案，图案与颜色各不相同。
- 恰有一个格胞的前景掩码与整体占位图（非空格胞记 1、空格胞记 0 的 n×n 图）恰好只差一位，且差的那一位正是该格胞自身所在的位置；没有任何格胞的掩码与占位图完全一致。

规则：
- 逐格胞判断空与非空，读出整体占位图。
- 寻找与占位图逐位比较恰差一位、且差异位等于自身格胞坐标的唯一格胞。
- 把该差异位补为前景后，用该格胞图案的颜色输出完整的 n×n 占位图。

关键洞察：
- 先按"内容等于布局"的直觉找完全一致的格胞会落空；目录不包含它自己，必须领会"差的那一位恰是它自身位置"的自洽条件，而输出的颜色也只能由这个格胞给出。
```

## 7. 数量与倍数的自洽之锁

- 参考题目：`6b9890af`、`f8ff0b80`、`9f27f097`、`e50d258f`
- tags:
  - operation:像素放大, pixel_upscale
  - operation:裁剪, crop
  - operation:计数, counting
  - object:空心矩形框, hollow_rect_frame
  - object:精灵体, sprite
  - relation:框内尺寸整数缩放, frame_interior_int_scale
  - relation:计数等于倍数自洽, count_equals_scale
  - condition:多候选唯一自洽, unique_self_consistent_candidate

### docstring

```text
从多个都能整除空心框内径的候选精灵中，选出像素个数恰好等于所需放大倍数的那一个，放大后填入框并输出框区域。

输入结构：
- 黑色背景上有一个单色空心矩形框和若干互不接触、颜色互异的小精灵。
- 框内部为空且为正方形。
- 不止一个精灵的边界框是正方形且其边长能整除框内径，即存在多个几何上可行的候选，各自对应不同的放大倍数。
- 其中恰有一个精灵，其前景像素个数等于用它填框所需的放大倍数。

规则：
- 对每个精灵计算候选倍数 k = 框内径 ÷ 精灵边界框边长，仅当整除时有效。
- 在所有几何可行的候选中，选出前景像素数恰好等于自身候选倍数 k 的唯一精灵。
- 把该精灵按像素放大 k 倍绘入框内部，输出框及其内部的裁剪区域。

关键洞察：
- 尺寸整除是第一眼的选择标准，但它给出多个候选（诱饵）；真正的钥匙是一条数量-几何自洽条件——精灵的像素数必须恰好说出它自己的放大倍数，几何与计数互为锁与钥。
```
