## 1. 数点造方，探入窄道

- tags:
  - operation:计数, counting
  - operation:滑动, sliding
  - object:蜿蜒通道, winding_channel
  - object:标记像素, marker_pixel
  - relation:计数映射尺寸, count_maps_to_size
  - condition:尺寸约束通行, size_constrains_passage
- 参考题目: `878187ab`, `332f06d7`

### docstring

```text
数出散落标记的个数作为方块边长，让这个从未画出的方块从通道口滑进蜿蜒通道，涂在能到达的最深处。

输入结构
- 黑色背景上，青色画出一条宽窄起伏、无分叉的蜿蜒通道，通道恰有一端开在网格边界上。
- 通道之外散落若干个孤立的黄色标记像素。

规则
- 统计黄色像素的个数 N。
- 设想一个 N×N 实心方块从边界开口进入通道，它只能占据整块 N×N 区域都是青色的位置，并沿通道逐格滑动。
- 找到它沿通道能到达的最远位置，把那块 N×N 区域涂成黄色；抹去所有散落的黄点，其余保持不变。

关键洞察
- 方块在输入中从未出现：黄点的个数是它的边长，黄点的位置全是干扰；通道里第一处宽度小于 N 的收口决定它的止步之处。
```

## 2. 条长排位，依序接段

- tags:
  - operation:排序, sort
  - operation:拼接, concatenation
  - operation:连线, trace
  - object:竖条, vertical_bar
  - object:路径片段, path_segment
  - object:起点标记, start_marker
  - relation:长度排名, length_ranking
  - condition:排名决定执行顺序, rank_as_schedule
- 参考题目: `97d7923e`, `d017b73f`, `e6de6e8f`

### docstring

```text
按竖条长度的排名决定各彩色矢量段的执行顺序，从绿色起点首尾相接画出折线。

输入结构
- 画布区有一个绿色起点像素，散放若干条一格粗的直线段，颜色互不相同；每段一端多出一个灰色端头像素。
- 网格底边立着若干竖条，长度互不相同，每条竖条的颜色与某个线段相同。
- 线段在画布上的摆放位置随机，与执行顺序无关。

规则
- 将竖条按长度从长到短排序，得到颜色顺序，即各线段的执行顺序。
- 从绿色起点出发按序执行每段：方向取该段"从尾端指向灰头"的方向，从当前点的下一格起沿该方向涂满该段长度个格子，用该段自身的颜色；画完后当前点移到末格。
- 输出中清除原来散放的线段与竖条，只保留背景、绿色起点和画出的折线。

关键洞察
- 竖条不是图形而是调度器：条色对应段色，条长的名次给出先后；线段的摆放位置是纯干扰，灰色端头唯一决定各段方向。
```

## 3. 涂边定轴，择精灵而染半

- tags:
  - operation:对称检测, symmetry_detect
  - operation:裁剪, crop
  - operation:重涂色, recolor
  - object:边框控制, frame_control
  - object:精灵体, sprite
  - relation:反射交换边对, reflection_swaps_edges
  - condition:对称类型匹配选择, symmetry_type_selection
- 参考题目: `73ccf9c2`, `fc7cae8d`

### docstring

```text
两条被整条涂色的边框边指定一根对称轴，选出恰以该轴对称的精灵裁剪，并按轴把两半染成对应的边框色。

输入结构
- 黑色背景上有若干个灰色精灵，每个精灵在自己的紧致包围盒内恰好具有一种非平凡对称（左右镜像、上下镜像、主对角镜像、反对角镜像之一）。
- 各精灵的对称类型互不相同，且总含同族干扰（如两条对角线对称各有其一）。
- 网格边框中恰有两条边被整条涂色，两条边颜色不同。

规则
- 目标对称轴是"恰好把这两条涂色边互换"的那次反射：左右两边对应竖直轴，上下两边对应水平轴，相邻两边对应交换它们的那条对角线。
- 选出对称类型恰为该反射的精灵，按包围盒裁剪作为输出底稿。
- 在裁剪内，把轴两侧的精灵像素分别染成该侧所朝向的那条涂色边的颜色；恰在轴上的像素保持灰色，背景保持黑色。

关键洞察
- 两条涂色边不直接指认精灵，而是通过"哪个反射恰好交换这两条边"来编码一根轴；同一根轴既负责挑选精灵，又负责给它的两半分派颜色，方向弄反立刻出错。
```

## 4. 换色射线

- tags:
  - operation:射线延伸, ray_extend
  - operation:重涂色, recolor
  - object:种子像素, seed_pixel
  - object:滤条, filter_bar
  - relation:穿透即交换, swap_on_pass
  - condition:同色吸收, same_color_absorbs
  - condition:连锁反应, chain_reaction
- 参考题目: `6ffe8f07`, `96a8c0cd`

### docstring

```text
种子向四方向发射光线，光线每穿过一根滤条就与它交换颜色，只有遇到与自身当前颜色相同的滤条才被吸收。

输入结构
- 黑色背景上有一个有色种子像素。
- 若干一格厚、与射线走向垂直的彩色短条横在种子的四个轴向通路上；同一方向可依次多条，颜色可重复；每根滤条至多位于一条光路上。

规则
- 从种子向上、下、左、右各射出一道光线，初始颜色为种子色，只在黑色格子上着色。
- 光线抵达一根滤条时：若条色不等于光线当前颜色，光线穿过，且两者交换颜色——该滤条整条重涂为光线原来的颜色，光线改用原条色继续；若条色等于当前颜色，光线停在条前，滤条颜色不变。
- 光线到达网格边缘时结束；输出保留种子与全部滤条（含被交换后的新色）。

关键洞察
- 滤条不是墙也不只是被动的染色器：穿透即交换，输出里每根条的新颜色是光经过那一刻所携颜色的化石，与光线各段颜色互相印证；一根条挡不挡光取决于之前整条交换链的累积结果，同色相遇才吸收。
```

## 5. 停靠为链，序还原

- tags:
  - operation:排序, sort
  - operation:重涂色, recolor
  - operation:擦除, erase
  - object:滑块, slider
  - object:轨迹, trail
  - object:颜色图例, color_legend
  - relation:停靠依赖, resting_dependency
  - condition:因果反演, causal_inversion
- 参考题目: `d255d7a7`, `332f06d7`, `97d7923e`

### docstring

```text
由灰色轨迹与"谁抵着谁"还原各滑块的到达先后，并按图例颜色重涂名次。

输入结构
- 黑色背景；网格某一条边整条是青色墙。
- 若干个颜色互不相同的实心小矩形滑块，各自从某条边界出发沿直线滑入，身后留有一条灰色轨迹；每个滑块的行进前方都恰好紧贴着青墙或另一个滑块的侧腹。
- 左上角一行连续的彩色图例格，从左到右代表到达名次。

规则
- 由灰色轨迹判断每个滑块的运动方向；它前方紧贴的对象就是使它停下的先到者。
- 紧贴青墙者第 1 个到达，紧贴第 1 名者第 2 个到达，依此沿停靠关系排出全部名次。
- 把第 i 名滑块整体重涂为图例第 i 格的颜色；抹去所有灰色轨迹与图例，青墙保留。

关键洞察
- 停靠关系是时间的化石：一个滑块只能停在已经静止的物体上，所以"谁抵着谁"给出唯一的到达链；离墙远近、轨迹长短都与名次无关，是天然的诱饵。
```

## 6. 镜厅显影

- tags:
  - operation:镜像, reflect
  - operation:重涂色, recolor
  - object:格点骨架, lattice_frame
  - object:精灵体, sprite
  - object:标记像素, marker_pixel
  - relation:标记指定腔室, marker_designates_cavity
  - condition:距离奇偶决定翻转, parity_determines_flip
- 参考题目: `8d5021e8`, `17b866bd`

### docstring

```text
以精灵所在腔室为原点，格架里每个被标记的腔室按行列距离的奇偶显影出精灵的镜像，并染成标记色。

输入结构
- 青色格架把网格划分成等大的黑色腔室阵列；其中一个腔室里画着一个双轴均不对称的单色精灵。
- 另有若干空腔室各含一个孤立的标记像素，颜色各异。

规则
- 对每个含标记的腔室：算出它与精灵腔室的行差与列差；行差为奇则上下翻转，列差为奇则左右翻转，两者可叠加。
- 清掉标记像素，把源腔室的整个内容按上述翻转后整体拷入该腔室，前景改用标记色；行差列差皆偶时为不翻转的平移拷贝。
- 精灵原腔室与格架保持不变；未标记的空腔室保持全黑。

关键洞察
- 整张网格隐含一座以精灵腔室为原点的"镜厅"：镜像平铺场无处不在却从未画出，标记只是选择让场中哪些格子显影并给出显影颜色；把它当成简单的平移复制，会在奇数距离的腔室上全部翻车。
```

## 7. 以房为格，奇偶泛染

- tags:
  - operation:洪泛填充, flood_fill
  - operation:填充, fill
  - object:房间, room
  - object:门洞, doorway
  - object:塞子像素, plug_pixel
  - relation:房间图连通, room_graph_connectivity
  - condition:房间级奇偶交替, room_level_parity
- 参考题目: `b782dc8a`, `17b866bd`, `d406998b`

### docstring

```text
把画面抽象成"房间-门"网络，从种子房间起按门数奇偶给整间房交替染色。

输入结构
- 青色墙体把黑色区域隔成若干房间；相邻房间的隔墙上有的开着一格门洞，有的门洞里嵌着一个非青色的塞子像素，有的根本没有门。
- 某个房间里水平并排放着两个异色种子像素；门洞布局保证任意两房间之间至多一条通路。

规则
- 空门洞可通行，被塞子堵住的门洞不通；由此得到房间之间的连通网络。
- 从种子房间（第 0 步）出发逐门扩散：偶数步房间整间涂成左边种子像素的颜色，奇数步房间涂成右边像素的颜色；不可达房间保持黑色。
- 墙与塞子保持不变；种子像素被本房间的涂色覆盖。

关键洞察
- 交替的单位是房间而不是像素：逐格洪泛的奇偶在门洞处就会错位，必须先把画面收缩成"房间-门"图再做奇偶染色；塞子像素让"看起来有门"与"真的连通"分离。
```

## 8. 边带磁带

- tags:
  - operation:解码, decode
  - operation:连线, trace
  - operation:擦除, erase
  - object:边缘带, edge_strip
  - object:起点标记, start_marker
  - relation:段序奇偶定轴, run_parity_axis
  - condition:颜色定正负长度定步, color_sign_length_step
- 参考题目: `d255d7a7`, `e6de6e8f`, `d406998b`

### docstring

```text
顶边的红蓝色带是一卷程序磁带，段序奇偶定轴向、段色定正负、段长定步长，从绿色起点走出折线。

输入结构
- 网格顶行是一条由红、蓝两色的连续段拼成的色带，段长不一；色带与画布之间隔着背景。
- 画布中有一个绿色起点像素。

规则
- 从左到右读出色带的段序列：第 1、3、5……段走水平方向，第 2、4、6……段走竖直方向。
- 红色段沿正方向（右/下）、蓝色段沿负方向（左/上），步数等于段长；从绿色起点出发依次行走，每一步用当前段的颜色涂在走过的格子上。
- 输出清除顶行色带，保留绿色起点与画出的折线。

关键洞察
- 色带不是装饰边框而是磁带：一段之内颜色只管符号、长度只管距离，而轴向由段的序号奇偶隐式给出；画布上的路径在输入中从未出现，却被顶行一维序列完全决定。
```
