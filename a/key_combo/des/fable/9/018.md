## 1. 缺损即钥匙

- 参考题目题号：5 (e84fef15)、7 (63613498)、11 (aabf363d)
- tags:
  - operation:修复异常, repair
  - operation:形状匹配, shape_match
  - operation:重涂色, recolor
  - object:重复图块, repeated_tile
  - object:候选模板, candidate_template
  - relation:多数投票共识, majority_vote
  - relation:缺损掩码即形状钥匙, damage_mask_as_key
  - condition:形状选色, shape_selects_color

### docstring

```text
用候选形状库解读受损副本的缺损图案，并以匹配候选的颜色标记修复处。

输入结构：
- 网格上部是由单色分隔线划分的等大方块阵列，各块本应为同一母图案的副本。
- 恰有一个受损块：其中部分母图案前景像素被母图案的背景色覆盖。
- 阵列下方散布若干互不相同的单色候选小形状，颜色互不相同，
  且这些颜色均未在母图案中出现。

规则：
- 对所有副本逐坐标取多数色，重建共识母图案，并定位唯一与共识不符的受损块。
- 把受损坐标的集合归一化为形状掩码，在候选库中找到形状与之相同的唯一候选。
- 输出为单个母图案大小的网格：先按共识母图案绘制，
  再把受损坐标处改涂为匹配候选的颜色。

关键洞察：
- 缺损不是噪声而是信息：受损像素的分布本身构成一把"形状钥匙"，
  它在候选库中的同形者提供修复处的标记颜色。
```

## 2. 隐链推空位

- 参考题目题号：13 (78332cb0)、12 (ad173014)、10 (332f06d7)
- tags:
  - operation:重涂色, recolor
  - operation:链式排序, chaining
  - object:方框块, framed_block
  - object:接口像素, port_pixel
  - object:空位块, hole_block
  - relation:边缘像素匹配, edge_pixel_matching
  - relation:链序推移, chain_shift
  - condition:空间邻近为诱饵, spatial_adjacency_decoy

### docstring

```text
沿接口匹配出的隐链，把各块的内部填色向空块方向整体推移一格。

输入结构：
- 背景上散布若干等大的方框块，互不接触；每块边框上嵌有若干接口色像素，
  框内区域整体填充一种颜色，各块填色互不相同。
- 恰有一个块的框内为背景色（空块）。
- 任取两块，若一块某条边上接口像素的偏移序列与另一块相对边上的偏移序列
  完全吻合，则这两块逻辑相连；全部块恰连成一条链，
  且块在画面上的远近与链上的邻接关系无关。

规则：
- 通过接口逐位匹配恢复整条链。
- 以空块为链上的空位：每个块的内部填色向空位方向沿链移动一格，
  空位随之移到链的另一端。
- 边框、接口像素与块的位置全部保持不变。

关键洞察：
- 画面上的空间邻近是诱饵，真正的邻接由接口像素的逐位吻合决定；
  空框是链上的"空位"，整条链像华容道滑块一样向它推进一格。
```

## 3. 碰撞接力的多米诺滑动

- 参考题目题号：18 (f3e62deb)、10 (332f06d7)、19 (dc433765)
- tags:
  - operation:滑动, slide
  - operation:连锁反应, chain_reaction
  - object:空心方框, hollow_square
  - object:实心起动块, solid_trigger
  - relation:颜色编码方向, color_coded_dir
  - relation:碰撞激活, collision_activation
  - condition:碰撞停止, collision_stop
  - condition:未被波及者不动, untouched_stay

### docstring

```text
只有被撞到的方框才会滑动：一枚实心起动块触发一场沿各自颜色方向的连锁接力。

输入结构：
- 网格为单一背景色，散布若干 3x3 精灵，颜色取自固定方向码：
  绿=向左，黄=向下，粉=向上，青=向右。
- 其中恰有一个是实心方块（起动者），其余全是空心方框。
- 精灵互不接触。

规则：
- 起动者沿其颜色方向平移，直到再前进一格就会越出网格或与其他精灵重叠，
  随后固定在该位置。
- 若它是因为顶到某个精灵而停下，则被顶到的那个精灵被激活，
  沿它自己的颜色方向以同样规则滑动，并可能继续激活下一个精灵。
- 连锁在某次滑动因网格边缘停下（或被激活者一步都无法移动）时终止；
  从未被顶到的精灵保持原位不动。
- 每次滑动后原位置清为背景色，精灵形状不变。

关键洞察：
- 这不是全体精灵各自滑向边缘，而是一条由碰撞传递的接力线；
  每个精灵的颜色方向码只在它被撞醒的那一刻才生效，
  未被波及的方向码全是无效的诱饵。
```

## 4. 杯链快递

- 参考题目题号：15 (3dc255db)、3 (d4a91cb9)、10 (332f06d7)
- tags:
  - operation:弹射, ejection
  - operation:擦除, erase
  - object:杯形框架, cup_frame
  - object:内容像素, content_pixel
  - object:尾刺, tail_spike
  - relation:尾口相接成链, tail_to_mouth_chain
  - relation:路径汇合, path_merging
  - condition:像素总数守恒, total_count_conservation
  - condition:出口杯外射, terminal_emission

### docstring

```text
让内容像素沿"尾刺对准杯口"的传递链逐站转运，最终由出口杯一次性射出全部像素。

输入结构：
- 背景上有若干杯形空心框架，边框颜色互不相同；
  每个杯有一根收敛的尾刺和一侧开口的杯口。
- 部分杯的口内装有内容像素，所有内容像素同色，且该色不用于任何边框。
- 从每个杯的尾刺沿尾刺方向作射线：要么正对射入另一个杯的杯口，
  要么直接射出网格边缘；由此杯群构成可以汇合的传递路径。
- 存在多个尾刺射向网格外的杯，但所有装有内容的杯沿传递路径
  最终汇入同一个出口杯。

规则：
- 每个装有内容的杯把口内像素清空，沿尾刺方向交给路径上的下一个杯，
  转运过程不留任何痕迹。
- 所有内容最终汇集到出口杯，再从出口杯的尾刺起点沿尾刺方向向外
  画一条内容色直线。
- 直线长度等于全网格原有内容像素的总数，越出网格的部分舍弃；
  所有杯框保持不变。

关键洞察：
- 尾刺与杯口的几何对准把孤立的杯连成隐形流水线；
  多个尾刺出网的杯里只有链上可达的那个才是真正的出口，
  而线的长度守恒地记录了沿途收纳的每一个像素。
```

## 5. 对称仲裁的块码

- 参考题目题号：6 (6350f1f4)、1 (f9d67f8b)、16 (90c28cc7)
- tags:
  - operation:解码, decode
  - operation:压缩, downscale
  - operation:对称补全, symmetry_completion
  - object:块网格, block_grid
  - object:重复精灵体, repeated_sprite
  - object:通配像素, wildcard_pixel
  - relation:宏观镜像对称, macro_mirror_symmetry
  - condition:歧义靠对称消解, ambiguity_resolved_by_symmetry

### docstring

```text
把块网格解码成宏观图像，无法判定的歧义块由宏观图像自身的镜像对称裁决。

输入结构：
- 网格被黑色分隔线划分成等大方块阵列；
  存在一个由多数色与少数色构成的两色小精灵。
- 每个方块要么是该精灵的副本，要么是精灵少数色的纯色空白块；
  灰色像素是被擦除的通配格，可当作任意颜色。
- 少数方块被灰色擦除得过多，以致既能解释为精灵副本又能解释为空白块
  （歧义块）；其余方块均可唯一判定，且每个歧义块的对称位置方块均可判定。

规则：
- 依据可判定方块恢复精灵图案，并把每个可判定方块解码为一个宏格：
  精灵副本记多数色，空白块记少数色，得到每块一像素的宏观图像。
- 已判定的宏格呈现唯一的整图镜像对称（水平轴或竖直轴之一）；
  每个歧义块取其对称位置宏格的判定结果。
- 输出为该宏观图像，行列数等于方块阵列的行列数。

关键洞察：
- 微观层面无法判定的块，并不靠局部信息补救；
  解码后的宏观图像自带对称约束，用"像"的身份反向裁决"原"的歧义。
```

## 6. 影带即图层表

- 参考题目题号：14 (bb43febb)、8 (4a1cacc2)、17 (575b1a71)
- tags:
  - operation:重建, reconstruct
  - operation:擦除, erase
  - object:影带线段, shadow_segment
  - object:空心矩形, hollow_rect
  - relation:投影生成本体, projection_generates
  - relation:遮挡定图层, occlusion_defines_layer
  - condition:断影按端点还原, broken_shadow_restored
  - condition:上层覆盖下层, upper_covers_lower

### docstring

```text
从底行与右列的影段还原从未画出的空心矩形，影与影的互相遮挡决定矩形的上下图层。

输入结构：
- 网格的最底一行和最右一列是影带，主区域在输入中全为背景。
- 每种前景色对应一个隐藏矩形：它在底行影带上的影是一个连续列区间，
  在右列影带上的影是一个连续行区间。
- 影带上影与影可以互相覆盖，处于上层的影会把下层的影盖断，
  但每条影的两个端点像素始终可见。
- 两条影带上读出的遮挡关系合并后构成一致的全序。

规则：
- 每种颜色的真实影区间取该色在对应影带上最外两个可见像素之间的完整区间，
  被盖住的中段一并计入。
- 由列区间与行区间相交重建一格宽的空心矩形边框。
- 按遮挡全序从最底层到最顶层依次绘制矩形，上层边框覆盖下层边框。
- 输出中把两条影带清为背景，只保留主区域中重建的矩形。

关键洞察：
- 影带同时编码两件事——矩形的几何（投影区间）与矩形的层叠
  （影的遮挡忠实复刻了本体的遮挡）；
  断裂的影必须先还原成完整区间，再按它压住谁、被谁压来决定绘制次序。
```
