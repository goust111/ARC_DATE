## 1. 双灯房的公共阴影

- tags:
  - operation:透明叠加, transparent_overlay
  - operation:射线延伸, ray_extend
  - object:面板, panel
  - object:分隔行, separator_row
  - object:灯条, lamp_bar
  - object:障碍块, blocker
  - relation:位置对齐, positional_alignment
  - relation:射线遇障停止, ray_stops_at_block
  - condition:双面板阴影交集, both_panels_shadow_intersection
  - condition:边缘决定光向, edge_sets_light_direction
- 参考题目题号: 0c9aba6e, 6ffe8f07, 69889d6e

### docstring

```text
求两块面板中各自照不到光的阴影区域的交集。

输入结构：
- 黑色背景网格被一条独占颜色的实心分隔线分为两块同尺寸面板。
- 每块面板恰有一条完整贴边的黄色灯条，位于面板四边之一；两块面板的灯条方位可以不同。
- 面板内其余前景像素是该面板专属颜色的障碍块。

规则：
- 在每块面板内，光从灯条的每个格子沿垂直于灯条的方向直线射入，途经的空格被照亮；
  射线在障碍块处停止，障碍格本身算被照亮，其后的格子为阴影。
- 灯条与被照亮的格子为亮区，面板内其余格子为阴影。
- 去掉分隔线，把两块面板按位置对齐。
- 输出一块面板大小的黑色网格，在两块面板同为阴影的位置涂青色。

关键洞察：
- 需要相交的不是画面上任何已画出的形状，而是由灯位与障碍共同派生、从未被画出的两片阴影；
  两块面板灯条方位不同，使两片阴影的朝向互不相同，交集无法从单侧读出。
```

## 2. 对准破口才肯流

- tags:
  - operation:移动, transfer
  - operation:擦除, erase
  - operation:堆叠, stack
  - operation:射线延伸, ray_extend
  - object:封闭区域, enclosed_region
  - object:缺口, gap
  - object:实心矩形框, rectangle_frame
  - relation:破口对准, gap_to_gap_alignment
  - relation:射线遇障停止, ray_stops_at_block
  - condition:数量守恒, count_conservation
  - condition:闭合与破口分治, closed_vs_punctured
- 参考题目题号: d931c21c, 6ffe8f07, 9aaea919, 1b8318e3

### docstring

```text
颜料只在两个容器的破口精确对准时整团转移并守恒堆积，否则从破口漏成一条长度等于颜料数的尾迹。

输入结构：
- 黑背景上有若干灰色矩形框容器。
- 部分容器内装一团单色颜料（4连通色块，各容器颜料颜色互不相同），部分容器内部为空。
- 每个容器在某条边上至多有一个一格宽破口（不在角上）；完全闭合的装料容器也存在。

规则：
- 闭合的装料容器保持原样。
- 对每个带破口的装料容器，沿破口的外法线方向看去：
  - 若这条视线恰好命中某个空容器的破口，且途中没有任何前景像素，则颜料整团转移——
    源容器内部清空，颜料在目标空容器内部从离其破口最远的一侧开始逐行堆积，
    堆积格数等于原颜料像素数，两容器之间不留任何痕迹。
  - 若视线没有命中任何空容器的破口，则颜料漏出——内部清空，
    从破口格起沿外法线画一条颜料色直线，长度等于颜料像素数（输入保证有空间画完）。

关键洞察：
- 破口是有方向的接口，转移与泄漏两种命运由"破口对破口"的精确对准关系决定；
  无论哪种命运，颜料像素总数都严格守恒，堆积的格数与尾迹的长度都是这个数的编码。
```

## 3. 灰色图钉下的隐形模板

- tags:
  - operation:透明叠加, transparent_overlay
  - operation:补全, complete
  - object:精灵体, sprite
  - object:锚点像素, anchor_pixel
  - object:碎片, fragment
  - relation:锚点对齐, anchor_alignment
  - relation:归一化形状比对, normalized_shape_matching
  - condition:碎片并集成模板, fragments_union_template
  - condition:原位补全, in_place_completion
- 参考题目题号: 137eaa0f, 82819916, 4ff4c9da

### docstring

```text
把所有碎片按灰色锚点对齐叠出完整模板，再把每个碎片原地补全成该模板。

输入结构：
- 黑背景上散布若干互不相邻的碎片，每个碎片由一种专属颜色的若干像素加恰好一个灰色锚点像素组成。
- 所有碎片都是同一个未画出的模板图形的不同部分：把它们按各自灰色锚点重合叠放后，
  彩色像素位置的并集恰好构成完整模板，重叠位置互不矛盾。
- 没有任何一个碎片单独等于这个并集，完整模板从未在画面中出现。

规则：
- 将所有碎片按灰色锚点对齐叠放，取彩色像素位置的并集，得到以锚点为原点的完整模板掩码。
- 在输出中把每个碎片原地补全：以其灰色锚点为原点铺上完整模板，
  全部用该碎片的专属颜色涂画，锚点位置也涂成碎片色。
- 补全后的各图形互不重叠（由输入布局保证）。

关键洞察：
- 没有任何碎片是完整的，也不存在现成的参照模板；
  模板只能通过锚点配准把所有残片叠加才能显形，随后再被广播回每个残片的位置。
```

## 4. 走样的瓷砖是图例

- tags:
  - operation:重涂色, recolor
  - object:壁纸背景, wallpaper_bg
  - object:异常瓷砖, deviant_tile
  - relation:周期重复, periodic_repeat
  - relation:位置对齐, positional_alignment
  - condition:编码映射, encoding_map
  - condition:诱饵为修复, repair_decoy
- 参考题目题号: cad67732, 82819916, 6cbe9eb8

### docstring

```text
从唯一走样的瓷砖上按格读出颜色替换表，并把它应用到整幅壁纸。

输入结构：
- 整幅网格由同一块多色瓷砖沿行与列周期平铺而成。
- 恰有一个瓷砖实例颜色走样：它与标准瓷砖逐格位置一一对应，
  但颜色经过了同一个一致的颜色替换；标准瓷砖中的每种颜色都在该实例中有确定的对应色。
- 除颜色外，走样瓷砖的内部结构与标准瓷砖完全相同。

规则：
- 找出平铺周期与走样的瓷砖实例。
- 将走样实例与标准瓷砖逐格对照，读出颜色替换表。
- 对整幅网格的每个像素应用该替换表并输出；此时原走样瓷砖与全图自然一致。

关键洞察：
- 异常瓷砖不是要修复回原样的破损，而是给出目标配色的图例；
  变换方向与"修复异常"的直觉相反——是全图向异常看齐，异常瓷砖是整个映射的不动点。
```

## 5. 套框是放大倍率

- tags:
  - operation:像素放大, pixel_upscale
  - operation:计数, counting
  - operation:擦除, erase
  - object:前景矩形, foreground_rectangle
  - object:精灵体, sprite
  - relation:面积递减嵌套, area_descend_nest
  - relation:角落对齐, corner_alignment
  - condition:嵌套深度定倍率, depth_sets_scale
  - condition:角落定锚点, corner_sets_anchor
- 参考题目题号: 6cbe9eb8, 60c09cac, ff28f65a

### docstring

```text
删去每组嵌套框，把其中的小图形以嵌套层数为倍率、以各框共享的对齐角为锚点做像素放大。

输入结构：
- 黑背景上有若干组互不接触的组件；每组由若干个逐层嵌套的空心矩形框和最内部的一个小精灵图形组成。
- 同组各框与精灵共享同一个对齐角：每个内层框都紧贴外层框的同一个角落放置，
  组内角向一致，组间可以不同。
- 各组的嵌套框数量可以不同。

规则：
- 数出每组的框数 k，并记下该组共享的对齐角方向。
- 删去所有框，把该组精灵按像素放大 k 倍：每个像素变为 k×k 的同色块。
- 放大以精灵靠对齐角一侧的角像素为不动点，向远离对齐角的方向扩展；
  放大结果互不重叠且不出界（由输入保证）。

关键洞察：
- 嵌套框既不是要重绘的结构也不是容器：层数是倍率读数，
  共享的角落是放大的锚点，框本身在输出中消失。
```

## 6. 格律表里的少数派

- tags:
  - operation:压缩, compress
  - operation:对称补全, symmetry_completion
  - operation:重涂色, recolor
  - object:填充矩形, filled_rectangle
  - object:颜色网格, color_grid
  - relation:包围盒行列分组, bbox_row_column_grouping
  - relation:双轴镜像, biaxial_mirror
  - condition:轨道内多数决, orbit_majority_vote
  - condition:忽略干扰项, ignore_distractors
- 参考题目题号: 0a1d4ef5, b8825c91, 929ab4e9

### docstring

```text
把矩形格律压缩成颜色小表，用小表的双轴镜像多数决找出并改正唯一放错颜色的矩形。

输入结构：
- 黑背景上散布少量单像素杂色干扰；有意义的对象是若干个至少3×3的单色实心矩形。
- 矩形按包围盒的行带与列带构成完整的 m×n 格律；
  各矩形尺寸与间距互不相同，因此整幅图在像素层面不具备任何对称性。
- 把格律压缩成 m×n 颜色小表后，小表在水平与竖直双轴镜像下本应对称：
  全表恰有一处格位的颜色与其四元镜像轨道内其余位置不同。

规则：
- 忽略干扰像素，按包围盒行列分组把矩形压缩为 m×n 颜色小表。
- 对小表的每个双轴镜像轨道做多数决，找出唯一与轨道多数色不符的格位。
- 输出整幅输入网格，仅把该格位对应的那个实心矩形整体重涂为其轨道的多数色，
  其余一切（含干扰像素）保持不变。

关键洞察：
- 对称性并不存在于像素层面，而存在于把矩形抽象成格位之后的颜色表上；
  要修的不是图案的形状，而是抽象表中被多数决揭穿的那一个格位。
```
