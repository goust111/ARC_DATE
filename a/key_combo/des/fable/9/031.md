## 1. 封闭性路由射线

- 参考题目题号: 8f3a5a89、ac2e8ecf、d07ae81c、221dfab4
- tags:
  - operation:射线延伸, ray_extend
  - operation:重涂色, recolor
  - object:边界标记像素, border_marker_pixel
  - object:封闭对象, closed_object
  - object:开放对象, open_object
  - relation:连锁反应, chain_reaction
  - condition:封闭性决定转向, closure_decides_turn
  - condition:碰撞转向换色, turn_and_recolor_on_hit

### docstring

```text
从边界标记发出一条射线，撞到对象前停步转向：撞到带孔的封闭对象左转，撞到无孔的开放对象右转，转向后的线段改用该对象的颜色，直至射出网格。

输入结构：
- 背景为黑色，网格边界上恰有一个洋红色(6)单像素标记。
- 场内散布若干互不接触的单色对象：一部分是内部含封闭孔洞的框形对象，
  另一部分是无孔的开放线形对象。
- 布局保证射线每次都正面撞上对象，且转向后的路径不会擦边穿过对象。

规则：
- 射线自标记出发，沿垂直于所在边界的方向进入网格，逐格向前涂画。
- 当前进方向的下一格是对象像素时，射线停在对象前一格并转向：
  该对象内部含封闭孔洞则相对前进方向左转90度，无孔则右转90度。
- 转向后继续前进，且此后线段的颜色改为刚撞到的那个对象的颜色；
  下一次撞击再按同一规则转向并再次换色。
- 首段线用洋红色；射线离开网格即终止；所有对象与标记本身保持不变。

关键洞察：
- 对象不是障碍装饰而是路由器：是否封闭孔洞编码左转还是右转，
  每段线的颜色记录最近一次经过的路由器，整条折线是一次连锁转发的轨迹。
```

## 2. 角图例对角滑动

- 参考题目题号: 58743b76、88e364bc、ac2e8ecf
- tags:
  - operation:对角滑动, diagonal_slide
  - operation:堆叠, stack
  - object:角落图例, corner_legend
  - object:彩色对象, colored_object
  - relation:图例方位映射角落, legend_position_maps_corner
  - condition:碰撞停止, collision_stop
  - condition:编码映射, encoding_map

### docstring

```text
按角上2x2图例中颜色所处的方位，把场内每个同色对象沿对角方向滑向对应的网格角落并碰撞堆叠。

输入结构：
- 网格一角有一个由四种互不相同颜色组成的2x2图例块，与场内对象不相邻。
- 场内散布若干单色4连通对象，颜色均取自图例四色；同色对象可有多个。

规则：
- 图例左上/右上/左下/右下四个格子的颜色分别对应网格的左上/右上/左下/右下四个角。
- 每个对象沿指向自己颜色对应角落的对角方向逐步滑动：每步整体斜移一格，
  直到再斜移一步会越界或与图例、其他对象重叠为止。
- 距目标角落切比雪夫距离更近的对象先移动，后动者堆叠在先动者之外。
- 图例保持原位不动。

关键洞察：
- 图例不提供换色映射，它的四个格子以"在图例内的方位"编码运动矢量：
  颜色告诉对象去哪个角，而不是变成什么颜色。
```

## 3. 压缩空间中的对称补全

- 参考题目题号: ce8d95cc、0934a4d8
- tags:
  - operation:压缩, compression
  - operation:对称补全, symmetry_completion
  - object:重复行, dup_row
  - object:重复列, dup_column
  - object:标记矩形, marker_rectangle
  - relation:双轴反射对称, biaxial_reflection_symmetry
  - condition:对称仅在压缩后成立, symmetry_only_after_compression
  - condition:标记遮挡区域, marker_occludes_region

### docstring

```text
先把相邻重复的行与列去重压缩，再利用压缩图的双轴镜像对称恢复被实心标记矩形遮住的格子，输出修复后的压缩图。

输入结构：
- 输入是一张小图案沿行、列两个方向按不等倍率做相邻复制拉伸后的大网格。
- 一种颜色以唯一实心矩形出现，遮住网格的一块区域；
  比较行列是否重复时该颜色视作任意值。
- 压缩后的小图案关于水平中轴与竖直中轴均镜像对称；
  由于各带的复制倍率不同，原始大网格本身并不对称。

规则：
- 自上而下扫描，把（忽略标记格后）彼此相同的相邻行归并为一行；
  再自左向右对列做同样归并。
- 在得到的压缩图中，仍被标记颜色占据的格子用水平镜像或竖直镜像位置上的
  非标记值填回。
- 输出这张恢复完成的压缩图。

关键洞察：
- 直接在原网格上找对称必然失败：对称只存在于去除复制倍率后的压缩空间里，
  先压缩、后补全的顺序是唯一通路。
```

## 4. 计数定序的嵌套方框

- 参考题目题号: 45a5af55、6455b5f5、1bfc4729
- tags:
  - operation:嵌套包裹, nested_wrapping
  - operation:计数, counting
  - object:实心正方形, solid_square
  - object:孤立像素, isolated_pixel
  - relation:排序, ordering
  - relation:逐层构建, layer_by_layer_build
  - condition:散点数定层序, dot_count_orders_layers
  - condition:边长定框厚, side_length_as_thickness

### docstring

```text
把每种既有实心正方形又有散点的颜色画成同心方框：散点数量决定由外到内的层序，正方形边长决定该层厚度。

输入结构：
- 背景黑色；场内有若干互不相同颜色的实心正方形，边长各异。
- 另散布这些颜色的孤立单像素散点，各色散点数量互不相同；
  个别颜色可能只有正方形而没有任何散点。

规则：
- 只保留同时拥有正方形和至少一个散点的颜色；
  只有正方形没有散点的颜色是装饰，整体舍弃。
- 按散点数量从多到少排列颜色：散点最多的颜色是最外层方框，
  最少的成为最中心的实心正方形。
- 每层方框的厚度等于该颜色实心正方形的边长；
  最内层画成边长等于其正方形边长的实心正方形。
- 输出恰好容纳全部层的正方形网格。

关键洞察：
- 尺寸与层序是两条独立通道：正方形的大小并不决定谁包谁，
  看似自然的"大的包小的"是诱饵，真正排序的是不起眼的散点计数，
  边长只兑换成厚度。
```

## 5. 破口泄流

- 参考题目题号: 88e364bc、8f3a5a89、ac2e8ecf
- tags:
  - operation:滑动, slide
  - operation:堆叠, stack
  - object:封闭区域, enclosed_region
  - object:墙壁缺口, wall_gap
  - object:可移动像素, movable_pixel
  - relation:拓扑破口定向, gap_topology_encodes_dir
  - condition:碰撞停止, collision_stop
  - condition:穿出后远端堆积, exit_then_stack_at_far_obstacle

### docstring

```text
每个封闭墙圈的墙上都有一个缺口，圈内的所有黄色像素从缺口喷出，沿缺口向外方向飞行并抵着第一个障碍堆叠成一段直线。

输入结构：
- 背景黑色；若干互不相接的墙色闭合圈，每圈的墙恰好缺一格，形成唯一缺口。
- 每个圈内部散布若干黄色(4)单像素；圈外还可能有其他墙体或网格边界充当障碍。

规则：
- 对每个圈：确定缺口向外（背离圈内部）的方向，以缺口所在行或列为轨道。
- 圈内全部黄色像素移出圈外，沿该轨道飞向远端，抵着首个障碍
  （其他墙体或网格边缘）依次堆叠，形成一段连续的黄色直线，
  线的格数等于该圈原有的黄色像素数。
- 圈内不再留任何黄色像素；所有墙体保持不变。

关键洞察：
- 运动方向不由重力或图例给出，而由墙的拓扑破口决定；
  且像素不是滑到缺口就停，而是穿出缺口飞到远端障碍处反向堆积。
```

## 6. 锚点配准后的重合显形

- 参考题目题号: 25e02866、94133066
- tags:
  - operation:旋转, rotate
  - operation:透明叠加, overlay
  - object:填充矩形, filled_rectangle
  - object:锚点像素, anchor_pixel
  - object:标记像素, marker_pixel
  - relation:同尺寸配准, same_size_registration
  - condition:锚点角定朝向, anchor_corner_orientation
  - condition:重合阈值显形, coincidence_threshold_reveals

### docstring

```text
把每块方形面板按角上锚点旋转到统一朝向后叠放，只有被至少两块面板同时标记的格子才在输出中着色。

输入结构：
- 背景上分布若干同尺寸的正方形面板：统一底色填充，
  一角有一个青色(8)锚点像素，内部散布若干红色(2)标记像素。
- 各面板可能相对彼此旋转了0/90/180/270度，锚点所在角揭示其朝向。

规则：
- 将每块面板旋转到锚点位于左上角的标准朝向。
- 输出一块同尺寸的底色正方形，不画锚点。
- 对齐后同一位置被两块或更多面板标记为红色的格子，在输出中涂红；
  只被一块面板标记的位置保持底色。

关键洞察：
- 面板不能按原样取并集：先要识破锚点是朝向钥匙完成旋转配准，
  再发现叠加的语义是"重合投票"而非合并——孤证的标记是噪声，
  只有至少两块面板共同见证的格子才是真图案。
```
