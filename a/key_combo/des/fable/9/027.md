## 1. 图例多米诺定层序的四板合成

- 参考题目：7（ea9794b1）、19（d90796e8）、10（f8ff0b80）
- tags:
  - operation:透明叠加, transparent_overlay
  - operation:排序, sort
  - object:面板, panel
  - object:双色多米诺, bicolor_domino
  - relation:两两覆盖关系, pairwise_cover_relation
  - condition:拓扑序定层叠, topological_layer_order
  - condition:位置层序诱饵, position_order_decoy

### docstring

```text
把四个面板按图例多米诺编码的覆盖关系拼出唯一层序，再合成为一个面板。

输入结构
- 画布上部被分隔线分成 2x2 四个等大面板，每个面板含一种独有前景色的图案，其余为背景。
- 画布底部隔一条分隔线是图例带，带内散布若干双色多米诺：两个四邻接像素，颜色取自两种不同的面板色。
- 多米诺横放时左色压右色，竖放时上色压下色；全体多米诺恰好确定四种面板色的唯一全序。

规则
- 从每个多米诺读出一条“甲色覆盖乙色”的关系，把所有关系经传递拼合成四色从底层到顶层的唯一次序。
- 按该次序从最底层面板开始，把各面板的非背景像素依次画到一个单面板大小的画布上，后画的覆盖先画的。
- 输出即该合成面板，不含分隔线与图例带。

关键洞察
- 面板的空间位置是诱饵：层叠深度不由左上、右下等固定位置决定，而由图例多米诺给出的两两压序经传递闭包拼成的全序决定。
```

## 2. 拼合矩形测出的隐藏向量

- 参考题目：9（fe45cba4）、16（414297c0）、12（df9fd884）
- tags:
  - operation:移动, move
  - operation:补全, complete
  - operation:擦除, erase
  - object:碎片, fragment
  - object:锚定物体, anchor_object
  - object:单像素标记, singleton_marker
  - relation:颜色钥匙分派, color_key_dispatch
  - condition:平移向量复用, translation_vector_reuse

### docstring

```text
完成两处碎片拼合各得到一个平移向量，再按体内标记的颜色把向量分派给乘客对象。

输入结构
- 背景色占主导。恰有两种“裂开色”，每种被拆成两个四连通对象：一个触边碎片与一个不触边的锚块，二者可经唯一平移拼成一个实心矩形。
- 另有若干“乘客”对象（颜色不同于裂开色），每个乘客体内嵌有恰一粒单像素标记，标记色等于某种裂开色。

规则
- 对每种裂开色，求出使触边碎片与锚块拼成实心矩形的唯一平移向量，并按此完成拼合，碎片原位清为背景。
- 每个乘客连同体内标记整体平移，所用向量是其标记颜色对应裂开色的拼合向量，原位清为背景。
- 其余像素保持不变。

关键洞察
- 拼矩形不是终点而是测量仪：每次拼合产出一个隐藏的平移向量，乘客体内的标记色是领取哪个向量的钥匙。
```

## 3. 穿过分隔角的染色射线

- 参考题目：20（ec883f72）、8（941d9a10）
- tags:
  - operation:射线延伸, ray_extend
  - operation:洪泛填充, flood_fill
  - object:实心矩形, solid_rectangle
  - object:分隔线, divider_line
  - object:封闭区域, bounded_region
  - relation:角对角对齐, corner_diagonal_align
  - condition:穿过分隔凸角才生效, pass_corner_gate

### docstring

```text
实心矩形的对角射线只有恰好穿过分隔线凸角时，才把颜色投送进随后进入的区域并整体填充。

输入结构
- 灰色分隔线把黑色画布分割成若干封闭区域。
- 若干实心彩色矩形分布在不同区域内。

规则
- 从每个矩形的每个外角沿外向对角线追踪，射线本身不画。
- 若射线遇到的第一个非黑像素恰是分隔线的一个凸角点，则射线穿过该角点，把它随后进入的那个区域的全部黑格洪泛填充为该矩形的颜色。
- 若射线先撞上分隔线的直边、其他矩形或画布边缘，则该射线无效。
- 分隔线与矩形保持不变；未被有效射线命中的区域保持黑色。

关键洞察
- 对角线不是要绘制的图形而是选择器：只有“矩形角—分隔凸角”的精确对角对齐才打开门，让颜色越过区域边界投送到下一个区域。
```

## 4. 看不见的周期与它的残迹连线

- 参考题目：17（caa06a1f）、14（71e489b6）、2（55783887）
- tags:
  - operation:补全, complete
  - operation:连线, connect
  - operation:擦除, erase
  - object:平移周期图案, translation_pattern
  - object:缺陷像素, defect_pixel
  - relation:对角线对齐, diagonal_alignment
  - condition:成对连线落单修复, paired_connect_single_repair
  - condition:埋诱饵, decoy_rule

### docstring

```text
先复原覆盖全图的平移周期图案以显形偏离格，同色对角成对者之间连线，落单者修复回图案。

输入结构
- 前景像素在非黑背景上构成一幅覆盖整个画布的平移周期图案。
- 少数格子的颜色与周期预测不符（偏离格）：部分偏离格两两同色且严格位于同一对角线上，其余偏离格颜色各自落单。

规则
- 由多数一致性恢复周期图案，据此找出全部偏离格。
- 每对同色且对角线对齐的偏离格：把两端及其间对角线上的所有格涂成该偏离色，覆盖底下的图案。
- 落单的偏离格写回周期图案的预测色。
- 其余格子按图案保持。

关键洞察
- 连线的端点从未以“物体”的姿态出现：只有先看见那幅看不见的周期规律，端点才作为它的残迹显形；而“把所有缺陷都修掉”是第一个示例会诱导的错误规则。
```

## 5. 两粒角标撑开的弹性印章

- 参考题目：11（40f6cd08）、16（414297c0）
- tags:
  - operation:弹性拉伸, elastic_stretching
  - operation:印章覆盖, stamp_overlay
  - object:多色范例矩形, multicolor_exemplar_rect
  - object:标记像素, marker_pixel
  - object:内部行程, interior_run
  - relation:标记颜色配对, marker_color_pairing
  - condition:虚拟包围盒适配, virtual_bbox_fit

### docstring

```text
每对同色角标撑出一个从未画出的矩形，把同外框色的范例弹性拉伸后印满它。

输入结构
- 画布上有若干多色范例矩形，外框色互不相同；每个范例的行与列可行程编码，且每轴恰有一个可伸缩的内部行程。
- 每种外框色另有恰两粒同色标记像素，分别是一个虚拟矩形的左上角与右下角；该矩形从未被画出，且不小于对应范例。

规则
- 按颜色把每对标记配给同外框色的范例。
- 将该范例弹性拉伸至恰好铺满两粒标记撑出的包围盒：两轴的边界行程宽度保持不变，仅内部行程伸长补足尺寸。
- 把拉伸结果原样印在包围盒位置，覆盖两粒标记；范例本体与其余像素不变。

关键洞察
- 印章的目标只以两粒对角标记的形式存在；适配不是几何等比缩放，而是“边带冻结、中段伸长”的结构性拉伸。
```

## 6. 括号插槽：联合钥匙、旋向定序、先后落定

- 参考题目：12（df9fd884）、15（846bdb03）
- tags:
  - operation:平移, translate
  - operation:旋转, rotate
  - operation:重力下落, gravity_drop
  - object:括号框, bracket_frame
  - object:双色条, bicolor_bar
  - relation:尺寸色集联合匹配, size_colorset_joint_key
  - relation:臂端色定朝向, arm_tip_color_orientation
  - condition:低者先落, lower_falls_first

### docstring

```text
每根竖直双色条按“长度×色集”联合钥匙找到自己的顶部括号，选旋转方向放平定朝向，再按原高低次序依次落底堆叠。

输入结构
- 画布顶边排列若干开口向下的同色括号，每个括号左右两竖臂末端各染一粒标签色，构成一个有序色对。
- 括号之间内宽可能重复、标签色集合也可能重复，但（内宽，标签色集合）二元组全局唯一。
- 画布中下部散布若干竖直双色条（上半一色、下半一色、宽一格），每条的长度等于其目标括号的内宽，其两色集合等于该括号的标签色集合；同一括号可对应多条。

规则
- 每条按（长度，色集合）联合钥匙找到唯一对应的括号；仅按长度或仅按色集合都存在错误候选。
- 将条旋转九十度放平：两种旋向给出相反的左右色序，取旋转后左右色序与括号臂端标签左右色序一致的那一个旋向。
- 条置于括号正下方通道并与内宽左右对齐；各条按输入中所处行从低到高的顺序依次下落，落至画布底边或已落定条之上，原位清为背景。
- 括号保持不变。

关键洞察
- 归属钥匙是尺寸与色集的联合，单看任何一维都会被诱饵带偏；朝向不是镜像判断而是旋转方向的选择；堆叠结果依赖处理次序——三层子规则互相咬合。
```

## 7. 瓦片格阵里的指针链

- 参考题目：1（cbded52d）、8（941d9a10）
- tags:
  - operation:重涂色, recolor
  - object:分隔线格阵, separated_tile_lattice
  - object:标记像素, marker_pixel
  - relation:局部偏移编码方向, offset_encodes_direction
  - condition:链式传播, chain_propagation
  - condition:颜色来自上一站, color_from_previous_tile

### docstring

```text
每个瓦片中心旁的标记是一枚方向指针，从起点瓦片沿指针链行走，把途经瓦片染成来路指针的颜色。

输入结构
- 画布被完整的分隔线分成等大瓦片格阵，各瓦片为同一基色。
- 部分瓦片在正中心的八个邻位之一有一粒标记像素；标记相对中心的偏移方向即该瓦片的指针方向。
- 恰有一粒标记的颜色全图唯一，它所在瓦片是链的起点；其余标记颜色可重复。

规则
- 从起点瓦片出发，沿其指针方向走到相邻瓦片；随后每到一个瓦片，若其有指针则继续沿其方向走。
- 每走进一个瓦片，把该瓦片的全部基色格重涂为“来路瓦片”指针标记的颜色；标记像素与分隔线保持不变。
- 当指针指向格阵之外、指向已重涂过的瓦片，或进入无指针的瓦片时，链终止。
- 未被访问的瓦片保持不变。

关键洞察
- 标记的局部偏移不是装饰而是方向指针；格阵是一张待遍历的有向图，染色沿链传播且每站的颜色来自上一站，而非本站。
```
