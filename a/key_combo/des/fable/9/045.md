## 1. 光迹反推镜位

- tags:
  - operation:射线延伸, ray_cast
  - operation:反演重建, causal_inversion
  - object:折线路径, polyline_path
  - object:隐形镜子, hidden_mirror
  - relation:入射方向延长, incoming_direction_extension
  - condition:边界反弹不计, edge_bounce_excluded
- 参考题目题号: 508bd3b6、a2fd1cf0

### docstring

```text
由光线留下的折线残迹逆向推出每一面看不见的镜子的位置。

输入结构
- 黑色背景上有一个青色起点像素，一条绿色对角折线路径从它出发，
  经若干次转折后延伸到网格边缘。
- 折线的转折有两类成因：碰到网格边缘反弹（转折点位于边缘行或
  边缘列上），或碰到看不见的镜子反弹（转折点位于网格内部）。
- 每个示例中两类转折都会出现；镜子本身在输入中完全不出现。

规则
- 复制输入。
- 沿路径从青色起点走到终点，找出每一个转折点。
- 对每个位于网格内部的转折点，沿其入射方向越过转折点一格，把
  该格涂成红色（即"若未反弹、光线本应进入的下一格"）。
- 位于边缘行或边缘列上的转折点不产生任何输出。

关键洞察
- 需要输出的对象（镜子）从未被画出，只能由路径几何逆推；
  并且必须先区分转折的成因——边界成因的转折是干扰，只有内部
  转折才对应一面镜子。
```

## 2. 隐藏折叠轴与颜色传递

- tags:
  - operation:镜像, mirror
  - operation:重涂色, recolor
  - operation:擦除, erase
  - object:灰色对象, grey_object
  - object:单像素标记, singleton_marker
  - object:分隔空线, empty_separator_line
  - relation:虚像与标记重合, virtual_image_marker_overlap
  - condition:包围框内唯一空线定轴, unique_empty_line_axis
- 参考题目题号: da2b0fe3、963f59bc、d35bdbdc

### docstring

```text
以包围框内那条没有画出的空线为轴折叠灰色对象，用虚像压中的标记色回染原对象。

输入结构
- 黑色背景；折叠轴一侧是若干个多像素灰色对象，另一侧散布若干
  单像素彩色标记。
- 全体前景的包围框内部恰有一条完全为背景的行或列（折叠轴）；
  该轴一般不与网格几何中线重合。
- 每个灰对象的镜像至多覆盖一个标记；至少有一个灰对象的镜像
  不覆盖任何标记。

规则
- 找到前景包围框内部唯一的全空行或全空列，作为折叠轴。
- 对每个灰对象计算它关于该轴的镜像（镜像本身不画出）。
- 若镜像覆盖了某个标记像素，则该灰对象在原位置整体重涂为该
  标记的颜色。
- 未覆盖任何标记的灰对象保持灰色。
- 擦除所有标记像素。

关键洞察
- 折叠轴既没有画出、也不是网格中线，而是包围框内唯一的空线；
  决定每个对象颜色的是一幅从未显示的虚像与标记的重合关系。
```

## 3. 人人缺角，唯一认领

- tags:
  - operation:平移, translate
  - operation:补全, reconstruct
  - operation:擦除, erase
  - object:缺角矩形, corner_missing_rectangle
  - object:补丁像素, patch_pixel
  - object:噪声像素, noise_pixel
  - relation:缺角方向射线, missing_corner_ray
  - condition:同色命中方为主角, same_color_hit_selects
- 参考题目题号: 91714a58、1e5d6875、5623160b、a1570a43

### docstring

```text
在一群都缺角的矩形中找出延长线上有同色补丁的那一个，让它飞去认领并补上自己的缺口。

输入结构
- 黑色背景上有若干实心单色矩形，每个矩形都缺一个角格，缺角
  方位各不相同。
- 画面散布若干杂色单像素点；其中恰有一个矩形满足：沿它缺角
  所指的对角方向延长线上存在一颗与它同色的孤立像素（补丁）。
- 其余矩形的延长线上没有任何同色点；散点中混有与某些矩形
  同色、但不在其延长线上的像素，以及各种异色像素。

规则
- 对每个矩形，从缺角格出发沿指向缺角的对角方向作射线检验，
  找出延长线上命中同色孤立像素的唯一矩形。
- 在全黑画布上，把该矩形沿这一对角方向逐步平移（每步一行
  一列），直到它的缺角格位置恰好与补丁像素重合。
- 画出补全后的完整矩形；其余矩形与全部散点一律清除。

关键洞察
- 每个矩形都有缺陷，"找唯一异常者"失效——选择键不是缺陷
  本身，而是缺陷方向、环境射线与同色命中的联合条件；同色
  散点必须同时通过方向检验才算数；补丁像素既决定平移距离，
  又亲自补上缺口。
```

## 4. 配对指令与路径重叠

- tags:
  - operation:连线, draw_line
  - operation:重涂色, recolor
  - operation:擦除, erase
  - object:指令二连块, instruction_domino
  - object:单像素彩点, singleton_dot
  - relation:曼哈顿路径, manhattan_path
  - relation:颜色查找键, color_lookup_key
  - condition:多径重叠变粉, multi_path_overlap_pink
- 参考题目题号: a2fd1cf0、d35bdbdc、58e15b12

### docstring

```text
把每个水平二连块读作一条连线指令，按指令在彩点间画 L 形路径并把重叠处标粉。

输入结构
- 黑色背景上散布若干孤立单像素彩点，每种颜色至多一个点。
- 另有若干水平二连块，左右两格颜色不同，且远离所有彩点；
  二连块中出现的每种颜色都对应画面上的一个彩点。
- 至少存在两条指令路径发生交叠。

规则
- 删除所有二连块。
- 对每个二连块 [A|B]，从颜色 A 的彩点出发，先沿其所在行水平
  画到颜色 B 彩点所在列，再沿该列垂直画到颜色 B 的彩点，路径
  用灰色，不覆盖两个端点本身。
- 被两条或更多路径共同经过的格子涂成粉色。
- 所有彩点保持不变。

关键洞察
- 二连块不是普通前景对象，而是"连接指令"：它的左右顺序规定
  了路径从谁出发、水平先行；画布上真正的关系网由这些指令间接
  给出，交叠处还需二次标记。
```

## 5. 条对编码的双参数阶梯

- tags:
  - operation:阶梯绘制, staircase_draw
  - object:锚点像素, anchor_pixel
  - object:竖直条对, vertical_bar_pair
  - relation:点对称双臂, point_symmetric_arms
  - relation:几何量编码参数, geometry_encodes_parameter
  - condition:条高定竖步条距定横步, height_and_gap_as_steps
- 参考题目题号: d06dbe63、58e15b12

### docstring

```text
从锚点画出两条点对称的灰色阶梯臂，其横步与竖步分别由远处竖条对的间距和条高编码。

输入结构
- 黑色背景上有一个青色锚点像素。
- 远离锚点处有一对同色竖条：两条等高（高 h），位于不同的两列，
  列间距为 w；条对不与阶梯路径相交。
- 示例中 h 与 w 不相等，两参数可区分。

规则
- 保留输入内容。
- 从锚点出发画灰色阶梯臂一：反复"向右画 w 格，再向上画 h 格"，
  直到越出网格为止。
- 再画与之点对称的阶梯臂二：反复"向左画 w 格，再向下画 h 格"，
  直到越出网格为止。
- 最后恢复青色锚点像素。

关键洞察
- 竖条对不是被变换的对象，而是参数载体：条高编码竖直步长，
  条间距编码水平步长；阶梯的形状只由这两个几何量决定，与条对
  自身的位置无关。
```

## 6. 极性滑行与色段落点

- tags:
  - operation:推移, push
  - operation:重涂色, recolor
  - object:对角线段, diagonal_segment
  - object:极性尖头, polarity_tip
  - object:色段边条, segmented_edge_bar
  - relation:头尾极性定方向, tip_polarity_direction
  - condition:落点色段定色, landing_segment_color
- 参考题目题号: 5623160b、508bd3b6、d35bdbdc

### docstring

```text
让每条带黄色尖头的灰色对角线段沿尖头方向滑到边条前，并染上落点所在色段的颜色。

输入结构
- 网格四条边各覆盖一格宽的边条，每条边条由若干段不同颜色拼成，
  色段边界位置各例不同。
- 内部黑色背景上有若干灰色对角三连段，每段在一端的对角延长线
  上多出一个黄色尖头像素。
- 部分对象离某条边很近、但尖头指向远处的另一条边，不能按最近
  边猜测归宿。

规则
- 每个对象（连同尖头）沿黄色尖头指向的对角方向逐步滑行，直到
  尖头进入紧贴某条边条的格子为止。
- 停下后，把整个对象（含尖头位置）重涂为尖头接触位置所在色段
  的颜色。
- 清空对象的原位置；四条边条保持不变。

关键洞察
- 运动方向由对象自身的头尾极性给出，而不是位置关系；对象的
  最终颜色既不在对象上、也不在任何码表中，而取决于精确的对角
  落点落进哪个色段——必须逐格追踪斜向轨迹，粗看"撞哪条边"
  不足以定色。
```
