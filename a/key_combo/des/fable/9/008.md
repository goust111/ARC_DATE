## 1. 弯管折光

- 参考题目题号: `d4f3cd78`, `9ba4a9aa`, `5545f144`
- tags:
  - operation:射线延伸, ray_extend
  - operation:填充, fill
  - object:弯管, elbow_pipe
  - object:封闭杯, closed_cup
  - object:开口, opening
  - relation:开口转向, opening_redirect
  - condition:双开口传输单开口终止, two_openings_pass_one_opening_ends

### docstring

```text
从边界源点发出的光线被双开口管件逐段折转，最终注满唯一的单开口终杯。

输入结构：
- 黑色背景网格，边界上有一个彩色源像素。
- 网格内散布若干灰色空心矩形管件：多数管件在两条不同侧壁上各有一个
  单格开口（弯管），恰有一个管件只有一个开口（终杯）。
- 部分管件不在光路上，是干扰件。

规则：
- 光线从源像素沿垂直于所在边界的方向向网格内部直线行进，路径格涂成源色。
- 光线恰好射入某弯管的开口时，该弯管内部全部涂成源色，光线改从另一个
  开口射出，方向为该开口朝外的法向，继续直线行进。
- 光线射入终杯的唯一开口时，终杯内部全部涂成源色，传输结束。
- 未被光线经过的管件保持原样，光路之外的格保持黑色。

关键洞察：
- 开口数量把同类外形的管件分成两种角色：双开口是转向器，单开口是终点
  容器；直线延伸被开口结构改写成一条确定的折线传输路径。
```

## 2. 对称残差合成隐藏图案

- 参考题目题号: `d56f2372`, `7f4411dc`, `e99362f0`, `1990f7a8`
- tags:
  - operation:对称检测, symmetry_detect
  - operation:透明叠加, transparent_overlay
  - object:载体对象, carrier_object
  - object:缺陷像素, defect_pixel
  - relation:镜像残差, mirror_residual
  - condition:残差合成图案, residuals_compose_sprite
  - condition:貌似去噪诱饵, pseudo_denoise_decoy

### docstring

```text
把每个对象相对自身镜像多出的残差格叠到同一画布上，拼出从未被完整画出的图案。

输入结构：
- 黑色背景上散布若干个单色对象，颜色互不相同。
- 每个对象的包围盒尺寸相同；对象在自身包围盒内几乎左右对称，
  只有少数几格破坏对称：这些格是前景，而其镜像位置是背景。
- 各对象的残差格在包围盒局部坐标下互不重叠。

规则：
- 对每个对象，取其包围盒并做左右镜像对比；凡"自身是前景而镜像位置是
  背景"的格记为该对象的残差格。
- 新建一张与包围盒同尺寸的黑色画布。
- 把每个对象的残差格按局部坐标画到画布上，颜色用该对象自身的颜色。
- 输出这张画布。

关键洞察：
- 破坏对称的格不是应被清除的噪声，而是被拆散寄存在各个对称载体里的
  图案碎片；答案图案在输入中从未被完整画出，只能靠逐个对象做镜像残差
  提取再叠加还原。
```

## 3. 等深环延伸与近弧分色

- 参考题目题号: `fc754716`, `2204b7a8`, `d4f3cd78`
- tags:
  - operation:环形延伸, ring_extend
  - operation:重涂色, recolor
  - object:标记像素, marker_pixel
  - object:同心矩形环, concentric_ring
  - relation:到边界等距, equidistant_to_border
  - relation:最近来源, nearest_source
  - condition:同环按近弧分段, same_ring_arc_partition

### docstring

```text
每个标记像素沿"与网格边界等距"的矩形环整圈延伸，同环多标记时按沿环最近分段染色。

输入结构：
- 黑色背景网格上散布若干彩色标记像素。
- 定义格的深度为它到最近网格边缘的距离；深度相同的格恰好构成一圈
  矩形环。
- 有的环上只有一个标记，有的环上有多个不同色标记，有的环没有标记。

规则：
- 每个标记把自己所在的整圈矩形环涂成自己的颜色。
- 若同一环上有多个标记，环上每一格涂成"沿环走最短弧长可达"的那个
  标记的颜色（设计保证无平局）。
- 没有标记的环及其余格保持黑色。

关键洞察：
- 像素的延伸轨道不是直线而是与边界等距的闭合环；深度为零的单标记
  情形貌似"标记色画外边框"的旧套路，多标记同环时才暴露真正规则：
  环是被多个来源按沿环距离瓜分的。
```

## 4. 四板叠加·局部支撑裁决

- 参考题目题号: `e99362f0`, `7f4411dc`
- tags:
  - operation:透明叠加, transparent_overlay
  - operation:裁剪, crop
  - object:面板, panel
  - object:十字分隔线, cross_separator
  - relation:邻接支撑, adjacency_support
  - condition:冲突格支撑多者胜, conflict_support_wins
  - condition:固定层序诱饵, positional_order_decoy

### docstring

```text
去掉十字把四板对齐叠加，冲突格不按固定层序，而由各板内该格的局部支撑数裁决。

输入结构：
- 一条整行与一条整列构成的十字分隔线把网格分成四块等大的面板。
- 每块面板由统一的背景色和一种本板前景色组成，四板前景色互不相同。
- 按局部坐标对齐后，部分位置只有一块板有前景，部分位置有多块板同时
  有前景（冲突格）。

规则：
- 移除十字，把四块面板按局部坐标对齐到一张单板尺寸的画布上。
- 只有一块板有前景的格，直接涂该板前景色。
- 冲突格：比较每块冲突板中该格前景像素在本板内的前景四邻个数，
  支撑数最多的板胜出，涂其前景色（设计保证冲突格无平局）。
- 其余格涂背景色。

关键洞察：
- 冲突不是由象限位置的全局层序解决的——首个示例的冲突恰好都被同一
  板赢下，像固定叠放顺序；真正的裁决是逐格进行的：谁在自己板内把这
  一格嵌得更深（邻接支撑更多），谁就占据这一格。
```

## 5. 杯口凝视取色与继承链

- 参考题目题号: `d4f3cd78`, `5545f144`, `2204b7a8`
- tags:
  - operation:填充, fill
  - operation:消除, consume
  - object:杯形轮廓, cup_outline
  - object:开口, opening
  - object:标记像素, marker_pixel
  - relation:开口朝向视线, gaze_direction
  - relation:依赖继承链, dependency_chain
  - condition:所见首物定色, first_seen_sets_color

### docstring

```text
每只杯沿开口方向看出去，看见标记就取其色填充，看见别的杯就继承那只杯的最终填充色。

输入结构：
- 黑色背景上有若干灰色杯形（单开口的空心矩形轮廓），开口朝向各异。
- 网格中散布若干彩色标记像素。
- 各杯视线互不冲突，"看见杯"的依赖关系不成环。

规则：
- 每只杯从其开口格沿开口朝外方向逐格看去，取第一个非黑格：
  - 若是标记像素：杯内部全部涂该标记色，该标记被擦除；
  - 若是另一只杯的杯壁：本杯内部涂"那只杯最终填充的颜色"，
    因此需先结算被看见的上游杯；
  - 若视线未遇任何非黑格而出界：本杯保持空。
- 未被任何视线看到的标记原样保留。

关键洞察：
- 开口是视线而非出口；颜色沿"谁看见谁"的因果链传播，必须按依赖顺序
  先解上游杯才能确定下游杯，被看见的标记还会从画面上消失。
```

## 6. 双片合璧补洞

- 参考题目题号: `42f14c03`, `681b3aeb`, `7f4411dc`
- tags:
  - operation:裁剪, crop
  - operation:平移拼合, translate_pack
  - object:带孔主体, object_with_hole
  - object:碎片, fragment
  - object:干扰体, distractor
  - relation:互补拼合, complement_fit
  - condition:双片恰满洞, two_pieces_fill_hole
  - condition:忽略干扰项, ignore_distractors

### docstring

```text
在散布的碎片中找出恰能两两拼合、无重叠铺满主体空洞的那一对，补洞后裁剪输出主体。

输入结构：
- 黑色背景上有一个大的单色主体，其包围盒内含一个连通的背景空洞。
- 主体周围散布若干个小的单色碎片，颜色互不相同。
- 恰有两块碎片可以只经平移（不旋转不翻转）、互不重叠地恰好铺满空洞；
  其余碎片是干扰件，且不存在其他能铺满空洞的碎片组合。

规则：
- 找到能合璧铺满空洞的那两块碎片及其唯一放置方式。
- 裁剪主体的包围盒作为输出：主体格保持主体色，空洞内每格涂上覆盖它
  的那块碎片的颜色。
- 干扰碎片与碎片原位不出现在输出中。

关键洞察：
- 没有任何单块碎片的形状与洞匹配，逐片比对必然失败；匹配关系存在于
  "两片互补拼合"这一层，干扰件只能靠整体拼装的成败来排除。
```

## 7. 行走轨迹重建·段色继承

- 参考题目题号: `5545f144`, `2204b7a8`, `3bd67248`
- tags:
  - operation:逐步移动, stepwise_move
  - operation:消除, consume
  - operation:连线, draw_line
  - object:箭头精灵, arrow_sprite
  - object:标记像素, marker_pixel
  - relation:朝向决定搜索线, facing_sets_search_line
  - condition:段色继承终点标记, segment_inherits_endpoint_color
  - condition:输出为运动史, trajectory_output

### docstring

```text
复现箭头精灵逐个吃掉标记的全过程，但输出的不是终态，而是每段涂上终点标记色的轨迹折线。

输入结构：
- 黑色背景上有一个箭头形精灵，尖端指示当前朝向。
- 网格中散布若干不同颜色的单像素标记。
- 每一步恰有一个正交方向的半线（从精灵头部起、沿该方向）上存在标记。

规则：
- 精灵反复行进：每步走向唯一有标记方向上最近的标记，吃掉它，
  朝向变为该方向；直到任何方向的半线上都没有标记为止。
- 输出为黑色画布上的一条折线：第 k 段是第 k 步走过的格
  （含终点格、不含起点格；初始起点格归入第一段），
  整段涂成该步吃掉的标记的颜色。
- 精灵本体与所有标记都不出现在输出中。

关键洞察：
- 要求输出的是运动史而非最终状态；每段折线的颜色来自这一段"终点处
  曾经存在、如今已被吃掉"的标记，必须先在脑中把整个行走过程演完，
  再反过来给每段路补上事后才知道的颜色。
```

## 8. 多臂锚链自复制

- 参考题目题号: `2f0c5170`, `53b68214`, `fc754716`
- tags:
  - operation:平移粘贴, translate_and_paste
  - operation:平铺, tile
  - object:精灵体, sprite
  - object:锚点像素, anchor_pixel
  - object:孤点像素, lone_pixel
  - relation:同色配对定偏移, same_color_pair_offset
  - condition:逐臂链式复制到出界, per_arm_chain_until_exit
  - condition:出界裁剪, clip_outside
  - condition:控制像素不保留, control_pixel_erased
  - condition:单次搬运诱饵, single_move_decoy

### docstring

```text
精灵体内每粒彩色锚点与远处的同色孤点配对成一支位移向量，精灵沿每支向量链式自复制直到出界。

输入结构：
- 黑色背景上有一个多格单色精灵，其内部嵌有若干粒（一至三粒）彼此
  颜色不同的锚点像素。
- 网格远处散布同样数量的孤立单像素，颜色与体内锚点一一对应；
  另有少量颜色不与任何锚点匹配的孤点作为干扰。

规则：
- 对每种锚点颜色，取向量 v 为"从体内锚点位置指向同色孤点位置"。
- 沿该向量把整个精灵依次粘贴到 v、2v、3v……处，直到新副本完全落在
  网格之外为止；部分出界的副本只保留界内部分。
- 每支复制链独立生成（设计保证互不重叠）；被链覆盖的孤点被盖去。
- 所有副本与原精灵中锚点所在的格一律涂精灵本体色；不匹配的干扰
  孤点原样保留。

关键洞察：
- 同色孤点貌似"把精灵搬运一次的落点"，实际只给出一支复制链的公差
  向量，链要越过孤点一直铺到出界；每粒体内锚点各持一支方向不同的
  向量，锚点与孤点都是控制像素，输出中不作为图案保留。
```

## 9. 底影反演印章

- 参考题目题号: `e5062a87`, `3de23699`, `53b68214`
- tags:

  - operation:重涂色, recolor
  - object:精灵体, sprite
  - object:轮廓残迹, contour_trace
  - object:色标像素, color_marker
  - relation:逐列底端对齐, per_column_bottom_align
  - condition:残迹反演放置, trace_inverts_placement

### docstring

```text
灰色折线是精灵下轮廓的投影残迹，把精灵按残迹反演的位置印回去并涂成旁侧色标的颜色。

输入结构：
- 黑色背景上有一个完整的多格单色精灵（样本）。
- 网格其余位置散布若干条灰色折线：每条在连续的若干列中逐列恰占一格，
  列数与精灵包围盒宽度相同，其起伏恰好等于精灵每列最低前景格的相对
  高度轮廓。
- 每条灰色折线最左一格的正下方一格处有一个彩色色标像素。

规则：
- 对每条灰色折线，把样本精灵整体平移放置：精灵包围盒的列区间与折线
  的列区间重合，且精灵每列的最低前景格恰位于该列灰格的正上方一格。
- 印出的精灵整体涂成该折线色标的颜色；色标像素被擦除，灰色折线保留。
- 样本精灵保持原位原色。

关键洞察：
- 折线上从未画出精灵本身，它只是精灵底边的一维投影；必须先认出这段
  起伏与样本每列最低点的对应关系，才能反演出唯一的放置位置，而颜色
  信息又存放在另一粒控制像素里。
```
