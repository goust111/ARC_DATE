## 1. 隐形枢轴的等差接力

- tags:
  - operation:补全, completion
  - operation:点对称映射, point_reflection
  - object:精灵体, sprite
  - object:隐形枢轴, hidden_pivot
  - relation:成对配对, color_pairing
  - relation:等差序列, arithmetic_progression
  - condition:枢轴从未画出, pivot_never_drawn
- 参考题目题号: 90347967, 44f52bb0, e41c6fd3, 8e5a5113

### docstring

```text
为唯一未配对的精灵补画出它的点对称伙伴，枢轴由已有配对的对称中心等差外推得到。

输入结构：
- 黑色背景上散布若干单色精灵，每种颜色恰好构成一或两个4连通精灵。
- 出现两次的颜色，其两个精灵互为绕某一点旋转180度的映像；各对的对称中心
  互不相同，且从未以任何像素形式画出。
- 恰有一种颜色只出现一次（未配对精灵）。

规则：
- 对每个成对颜色，求出两精灵间点对称的中心。
- 这些中心落在一条直线上且相邻间距相等，构成等差点列。
- 将点列向两端各延长一项，其中恰有一端使未配对精灵的180度映像完全落在
  网格内；以该端点为枢轴，补画未配对精灵的映像，原图其余内容保持不变。

关键洞察：
- 枢轴不是画面上的像素，而是由配对精灵反推出的"不可见对象"；未配对精灵
  的枢轴又藏在这些不可见中心组成的等差数列的延长项里——参与规则的关键
  对象在画面上只留下了它的生成元。
```

## 2. 乱序姿态槽位的互补拼图

- tags:
  - operation:旋转, rotate
  - operation:翻转, flip
  - operation:补全, completion
  - object:分隔线, divider_line
  - object:槽位, slot
  - object:缺失像素, missing_pixel
  - relation:姿态等价类, orientation_equivalence
  - condition:跨槽位互补, cross_slot_complementation
  - condition:姿态指派唯一无冲突, unique_consistent_assignment
- 参考题目题号: 8e5a5113, 484b58aa, 898e7135

### docstring

```text
先由残缺可见部分推断出各槽位所装副本的乱序旋转翻转姿态，再利用互补冗余
重建母图并补全全部槽位。

输入结构：
- 灰色分隔线把网格划分成若干同尺寸方形槽位。
- 每个槽位装着同一个多色实心图案在旋转或镜像后的一个副本，姿态在八种
  可能中乱序取用且没有任何标注；母图无任何旋转翻转对称性。
- 每个槽位都被若干黑色缺失块遮住一部分，没有一个槽位是完整的；图案本身
  不含黑色，母图每个像素至少在一个槽位中可见。

规则：
- 在八种姿态的指派中找出唯一使所有槽位可见像素两两对齐后无颜色冲突的
  一组指派。
- 按该指派把各槽位逆变换到同一基准方向，叠加可见像素重建完整母图。
- 再按各槽位原姿态用完整母图回填所有黑色缺失；分隔线保持不变。

关键洞察：
- 既没有完整模板，也没有已知的旋转次序；姿态本身要靠残缺副本之间的一致
  性拼图反推，其中看似同姿态的两个槽位可能实为镜像关系——重建与姿态
  指派互为前提，缺一步都无法落笔。
```

## 3. 围栏内外的真假黑洞

- tags:
  - operation:描边连线, outline_tracing
  - operation:填充, fill
  - object:轮廓顶点, outline_vertex
  - object:周期性格, periodic_lattice
  - object:缺失像素, missing_pixel
  - relation:极角排序, polar_angle_ordering
  - relation:平移等价, translation_equivalence
  - condition:围栏决定修补范围, fence_gates_repair
- 参考题目题号: 35ab12c3, 484b58aa, 896d5239

### docstring

```text
把顶点像素连成封闭围栏，只修补围栏内部的黑色缺口，外部的黑色缺口原样
保留。

输入结构：
- 整个网格铺着一张多色周期性图案，其上散布若干黑色缺失块。
- 若干红色顶点像素标出一个封闭多边形围栏的所有拐点；相邻拐点之间只沿
  水平、垂直或45度方向相连，且连线内部无遮挡。
- 黑色缺失块有的位于围栏内部，有的位于外部。

规则：
- 按绕顶点质心的极角顺序连接红色顶点，画出完整围栏（红色）。
- 求可见像素支持度最大且无颜色冲突的非零平移向量，按其平移等价类确定
  每个黑色像素在周期图案中应有的颜色。
- 只把围栏内部的黑色像素替换为周期图案颜色；围栏外部的黑色像素保持
  黑色。

关键洞察：
- 周期规律对所有黑洞都能给出预测，但顶点围栏才是"哪些洞该补"的开关；
  不先把稀疏顶点连成封闭边界，就无法区分真缺口与需保留的黑区——
  见洞就补恰恰是本题埋下的诱饵。
```

## 4. 漏斗接力

- tags:
  - operation:滑动, slide
  - object:三角楔形区域, triangular_wedge
  - object:标记像素, bead_pixel
  - object:缺口闸门, gap_gate
  - relation:碰撞阻挡, collision_blocking
  - relation:沿壁导向, wall_deflection
  - condition:开口决定穿越, gap_enables_passthrough
  - condition:多级接力, multi_stage_relay
- 参考题目题号: 896d5239, 98cf29f8, 87ab05b8

### docstring

```text
彩珠坠入绿色漏斗、顺斜壁滑向尖端，尖端封闭则堆积，尖端留有缺口则穿出并
继续直飞，可能接连穿过多个漏斗。

输入结构：
- 黑色背景上有若干绿色V形漏斗：两条45度斜壁相交处为尖端，开口朝上、
  下、左或右。
- 有的漏斗尖端像素完整（闭口），有的尖端处恰缺一格形成开口。
- 若干彩色单像素珠子散布各处，有的位于某漏斗两壁之间，有的在所有漏斗
  之外。

规则：
- 漏斗外的珠子不动。漏斗内的珠子按到尖端距离由近到远逐个处理。
- 珠子沿漏斗轴向尖端方向逐格移动，被斜壁挡住时沿壁向尖端方向斜移。
- 到达闭口尖端或压到已停珠子时停住堆积；到达开口尖端时穿出缺口，沿轴向
  继续直线飞行，途中若进入另一漏斗的两壁之间则重新受该漏斗支配，否则
  飞到网格边缘停在最后一格。
- 绿色漏斗全部保持原样。

关键洞察：
- 尖端那一格的有无是通行闸门；珠子的终点不由所在漏斗局部决定，而由开口
  串起的多级漏斗接力路径与先来后到的堆积共同决定。仅看第一个示例会误
  以为所有珠子都停在尖端，开口漏斗正是打破该错觉的埋伏。
```

## 5. 底边柱拨动嵌套层

- tags:
  - operation:计数, counting
  - operation:重涂色, recolor
  - operation:层序循环, layer_cycling
  - object:柱状图, histogram_bar
  - object:嵌套矩形层, nested_rect_layer
  - relation:柱高定转数, bar_height_sets_shift
  - relation:顺序对应, positional_correspondence
  - condition:柱需先被识别为指令, bars_are_instructions
- 参考题目题号: a3325580, 8dae5dfc, 44f52bb0

### docstring

```text
底边细柱既报身份又报转数，让每个嵌套矩形的颜色层序按对应柱高整体循环
转动。

输入结构：
- 网格上部散布若干实心嵌套矩形物体，每个由外到内套着若干整层单色矩形
  层，各物体的层数与层厚各不相同。
- 网格底边立着与嵌套矩形数量相同的1格宽单色竖柱，从左到右依次对应嵌套
  矩形从左到右的顺序，柱色恰等于对应矩形当前最外层的颜色；柱与物体之间
  没有任何分隔线。

规则：
- 把贴底边的1格宽竖柱识别为指令柱，其余物体为嵌套矩形。
- 对每个嵌套矩形，由外到内逐层剥离读出其颜色序列；设对应柱高为k，把
  颜色序列向内循环移动k位（原最外层色移到第k+1层的位置，最内侧溢出的
  颜色依次绕回最外层）。
- 层的几何厚度和边界保持不变，只按新序列整层重涂；输出中擦除全部指令柱。

关键洞察：
- 柱不是统计图而是转数旋钮，层作为整块颜色掩码循环搬家而非逐圈平移；
  当柱高恰为层数的倍数时矩形看似原样不动，这正是甄别循环规则、排除
  反转或两两交换等错误假设的关键示例。
```

## 6. 影子跟着姿态走

- tags:
  - operation:偏移复制, offset_copy
  - operation:旋转, rotate
  - operation:翻转, flip
  - object:精灵体, sprite
  - object:阴影像素, shadow_pixel
  - relation:共享归一掩码, shared_norm_mask
  - relation:协变偏移, covariant_offset
  - condition:干扰形状无影, distractor_unshadowed
- 参考题目题号: 35ab12c3, e41c6fd3, 898e7135, 90347967

### docstring

```text
把示范精灵身边的影子按每个副本的旋转翻转姿态"协变"地复制到所有同形
副本上。

输入结构：
- 背景上有若干同色精灵，其中除少数干扰形状外，其余都是同一个无任何
  旋转翻转对称性的母形在八种姿态（旋转/镜像）下的副本。
- 恰有一个副本（示范者）周围贴着若干另一颜色的影子像素。

规则：
- 用姿态匹配找出所有母形副本，并求出每个副本相对示范者的旋转翻转变换。
- 把示范者的每个影子像素相对其精灵的偏移，经过该副本的变换后，贴到该
  副本旁的对应位置。
- 与母形不同构的干扰形状不获得影子；原有内容保持不变。

关键洞察：
- 影子不是固定方向的装饰，而是随形体姿态一起旋转镜像的附属结构；按绝对
  方向照抄影子在旋转或镜像副本上必然出错——偏移向量必须与形体做同一个
  变换。
```

## 7. 孔洞的全局分配

- tags:
  - operation:形状匹配, shape_matching
  - operation:印章覆盖, stamp
  - operation:擦除, erase
  - object:框架, frame
  - object:孔洞槽位, hole_slot
  - object:拼块, piece
  - relation:唯一完美匹配, unique_perfect_matching
  - condition:局部多解需全局排除, local_ambiguity_global_resolution
- 参考题目题号: 898e7135, 1acc24af, fea12743

### docstring

```text
把散落的拼块经旋转翻转放进大框架的黑色孔洞里，个别拼块能塞进多个孔，
但使所有孔都被恰好占满的分配方式只有一种。

输入结构：
- 最大的连通体是一个单色框架，内部围着若干形状各异的黑色孔洞。
- 框架外散落着与孔洞数量相同的单色拼块，颜色互不相同。
- 某些拼块经旋转或翻转能与不止一个孔洞形状吻合，但全体拼块与全体孔洞
  之间恰好存在唯一的一一完美匹配。

规则：
- 为每个拼块列出它能吻合的孔洞，求出唯一能让每个孔洞都分到一个拼块的
  整体分配。
- 按该分配把每个拼块以吻合的姿态填进对应孔洞（保留拼块颜色），并擦除
  框架外的原拼块。

关键洞察：
- 逐个拼块就近贪心配对会卡死或出错；哪块进哪个孔不由局部形状独定，而由
  "人人有孔、孔孔有主"的全局约束唯一逼出——多义吻合正是通往全局推理
  的入口。
```
