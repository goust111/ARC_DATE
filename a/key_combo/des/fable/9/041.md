## 1. 遮挡考古：按堆叠层序重排同心环

- 参考题目：13（1a2e2828）、7（c658a4bd）、5（3befdf3e）
- tags:
  - operation:层序推断, infer_layer_order
  - operation:同心层填充, concentric_fill
  - object:空心矩形框, hollow_frame
  - object:交叠区域, overlap_region
  - relation:遮挡偏序, occlusion_partial_order
  - condition:层序决定嵌套, depth_determines_nesting

### docstring

```text
依据交叠处的遮挡关系（而非尺寸），把 n 个互相压叠的空心方框重排为 n 层同心回字环。

输入结构：
- 背景色网格上放置 n 个单像素粗、颜色互异的空心矩形框，彼此交叠。
- 每处交叠只显示位于上层的框的颜色，下层框在该处被遮断。
- 框的尺寸大小与堆叠层序刻意不一致；交叠关系足以推出唯一的堆叠全序。

规则：
- 在每个交叉处读出可见颜色，建立"可见者在上"的两两约束，并把约束链起来恢复唯一全序。
- 输出 (2n-1)×(2n-1) 网格：画 n 层单像素粗同心回字环，最底层框的颜色占最外圈，
  层序每升一层向内收一圈，最顶层颜色为中心 1 像素。

关键洞察：
- 嵌套顺序编码在交叠处的可见色形成的偏序中，与框的大小无关；
  按尺寸从大到小排环（另一类碎片重组题的惯性解法）会得到错误答案。
```

## 2. 逐行异常的差异像素拼出隐藏图形

- 参考题目：1（38007db0）、14（e3fe1151）、8（d364b489）
- tags:
  - operation:提取, extraction
  - operation:印章覆盖, stamp_overlay
  - object:网格单元, lattice_cell
  - object:差异像素, deviation_pixel
  - relation:逐行比较, row_wise_comparison
  - relation:局部坐标叠加, local_coord_superposition
  - condition:增删极性定色, polarity_determines_color

### docstring

```text
把每行异常单元与多数版本的单像素差异，按增删极性取色、按单元内局部坐标叠加成一张隐藏图形。

输入结构：
- 网格被颜色 L 的均匀网格线划分为 R×C 个等大单元，单元内部是背景上的小图案。
- 每行恰有一个单元与该行其余单元（多数版本）不同，且差异恰为单元内部的一个像素。
- 差异分两种极性：异常单元比多数版本"多画"一个前景像素，或"漏画"一个前景像素（该处退为背景）。
- 各行差异像素的单元内局部位置互不相同。

规则：
- 逐行比较，找出异常单元、差异像素的局部坐标及其极性。
- 输出一张与单元内部等大的网格，先全部填背景：
  多画型差异，在其局部坐标画上异常单元中该像素的颜色；
  漏画型差异，在其局部坐标画上多数版本中该像素的颜色。

关键洞察：
- 答案图形从未整体出现，它被拆成每行一个像素、藏在各行异常单元的差异处；
  抽出异常单元本身是诱饵。漏画型差异的颜色只存在于多数版本里而不在异常单元上，
  必须对照多数版本回读，增与删两种证据缺一则图形残缺。
```

## 3. 壁纸上的缺陷段：修复原处并沿反对角前移加长

- 参考题目：15（50a16a69）、16（50c07299）
- tags:
  - operation:补全, completion
  - operation:擦除, erase
  - operation:平移绘制, translate_draw
  - object:重复瓦片, repeating_tile
  - object:对角线段, diagonal_segment
  - relation:周期延拓, periodic_extension
  - relation:同反对角线, same_antidiagonal
  - condition:周期违例定位, period_violation_locates
  - condition:长度递增, length_increment

### docstring

```text
凭周期性违例找出骑在壁纸上的反对角缺陷段，用周期修复原处，再让它沿同一反对角线前移一段并加长一格。

输入结构：
- 网格整体是一个矩形色块单元的周期平铺（壁纸）。
- 一段位于同一反对角线上的连续像素被统一改写成颜色 D，形成缺陷段（列 c0..c1，长 L）。
- D 也出现在平铺单元的调色板中，因此无法凭颜色定位缺陷。

规则：
- 由未受污染的区域推断最小周期单元，与理想平铺逐格比对，找到唯一的连续反对角缺陷段。
- 输出中先用周期应有的颜色修复该段。
- 再在同一反对角线的列 c1+1 .. c1+L+1 上写入颜色 D（覆盖壁纸），新段长 L+1。

关键洞察：
- 缺陷段是骑在壁纸上的"对象"，只能靠周期性违例检出而非颜色；
  壁纸既是需要修复的背景，又是判定缺陷的参照模型——不重建周期就既找不到段，也补不回原色。
```

## 4. 四象限对称载体上的少数派消息

- 参考题目：17（7fe24cdd）、14（e3fe1151）、9（67385a82）
- tags:
  - operation:旋转, rotate
  - operation:镜像, reflect
  - operation:多数表决, majority_vote
  - object:正方形画布, square_canvas
  - object:分隔线, separator_line
  - object:异议像素, dissent_pixel
  - relation:轨道对应, orbit_correspondence
  - condition:变换须逐例推断, transform_must_be_inferred
  - condition:少数派即消息, minority_is_message

### docstring

```text
先辨认四个象限各自承载的对称变换，再用轨道多数表决剥离载体，读出散布其中的隐藏图形。

输入结构：
- 2N×2N 网格由分隔十字分成四个 N×N 象限。
- 每个象限是同一未知基底（本身无任何自对称）经八种方形对称变换（四旋转、四镜像）
  中某一种得到的像；四个象限的变换互不相同，且不固定为某种布局，须逐例推断。
- 把基底同一格在四象限的四个对应像素称为一条"轨道"；若干轨道中恰有一个像素被改成
  统一的信号色 M，其余轨道的四个像素完全一致。M 也出现在基底调色板中。

规则：
- 为每个象限确定其对称变换：取使四象限在全部轨道上最大程度一致的唯一解。
- 对每条轨道取四票多数（3:1）确定基底本色，找出所有持异议的像素。
- 把每个异议像素经其所在象限变换的逆映回基底坐标。
- 输出 N×N 网格：背景 0，仅在映回的位置画信号色 M。

关键洞察：
- 四个象限不是要构造的风车，而是信息载体；变换识别与多数表决互为前提——
  不解出各象限的变换就对不上轨道，不容忍每轨道一票反对又解不出变换。
- 信号色也在基底调色板中，凭颜色直接挑像素会混入载体本色，异议只能靠表决分离。
```

## 5. 绕墙泛洪：同速扩张、异色等距成缝

- 参考题目：12（332202d5）、10（c61be7dc）、18（cf133acc）
- tags:
  - operation:最近扩散, nearest_fill
  - operation:填充, fill
  - object:种子色块, seed_blob
  - object:墙壁, wall
  - relation:通路距离分区, geodesic_partition
  - condition:异色等距为缝, diff_color_tie_seam
  - condition:同色汇合无缝, same_color_merge

### docstring

```text
让所有种子在墙壁间同速泛洪扩张：每格归最先到达者，异色等距的锋面留成背景缝，同色汇合则无缝合并。

输入结构：
- 网格含背景色、固定颜色 W 的墙壁像素（曲折壁段与豁口，不构成完全封闭房间），
  以及若干种子色块；种子颜色可能互异，也可能有两个种子同色。
- 开阔区里种子间的直线远近与绕墙通路远近被刻意设计得不一致。

规则：
- 所有种子同时以四连通逐步扩张（同速）；墙壁不可穿越也不被染色。
- 每个背景格染成最先到达它的种子的颜色。
- 若同一步有颜色不同的种子同时到达某格，该格永久保留背景色且不再向外传播；
  若同时到达者颜色相同，正常染色并继续传播。
- 输出扩张终止后的整幅网格（墙壁保持 W）。

关键洞察：
- 距离是绕墙的通路距离而非直线距离：区域会穿过豁口绕到墙背面，
  仅凭直线最近分区（首例开阔区给出的假象）会画错边界。
- 等距锋面是否留缝取决于双方颜色——异色势力间留背景缝，同色势力无缝并流；
  缝格不传播，还会在墙角后方拖出缝的延伸。
```

## 6. 轴上残迹：由半份投影恢复嵌套正方形框

- 参考题目：6（9d9215db）、7（c658a4bd）、13（1a2e2828）
- tags:
  - operation:重建, rebuild
  - operation:排序, sorting
  - object:角落编码, corner_code
  - object:空心正方形框, hollow_square_frame
  - relation:投影配对, projection_pairing
  - condition:正方形性补全缺失投影, squareness_completes_projection
  - condition:按面积降序叠放, descending_area_stack

### docstring

```text
用顶行的成对色标与左列的单个色标，恢复从未画出的若干嵌套空心正方形框。

输入结构：
- 除顶行和左列外，网格全部为背景。
- 每种前景色在顶行恰好出现两个标记（列 c1、c2），在左列恰好出现一个标记（行 r1）。
- 这些标记是若干单像素粗空心正方形框在两条轴上的投影残迹。

规则：
- 每种颜色对应一个空心正方形框：列范围 c1..c2，边长 s = c2-c1+1，行范围 r1..r1+s-1。
- 按框的面积从大到小依次绘制，后画的小框覆盖先画的大框的重叠像素。
- 输出中顶行与左列的原始色标清除为背景，只留框。

关键洞察：
- 框本身从未出现，画面只有它们在两轴上的投影，且纵向投影只留了一半——
  另一半行界必须由"框是正方形"从横向投影的宽度推出。
- 重叠处的取舍由面积层序决定，而非标记出现的顺序。
```
