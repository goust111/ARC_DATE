## 1. 前缀示范转向射线

- 参考题目: 9 (e5790162), 14 (9f8de559), 2 (4c7dc4dd)
- tags:
  - operation:射线延伸, ray_extend
  - operation:转向, turn
  - operation:规则推断, rule_inference
  - object:路径, path
  - object:转向控制点, turn_ctrl_pixel
  - relation:前缀示范, prefix_demonstration
  - condition:语义跨例对调, semantics_swap_across_examples

### docstring

```text
沿已画出的绿色路径前缀读出两种控制色的转向含义，再把射线延续画到出界。

输入结构
- 黑色背景网格上有一条绿色路径前缀：从起点出发、已经过至少一枚控制像素并在其旁完成转向，止于某个中途格。
- 其余前景是散布的粉色与青色单像素控制点，位于路径前方的直线视野上。
- 两种控制色的转向方向相反；同一网格内含义一致，但不同示例之间左右含义可能对调。

规则
- 由前缀末端最后两格确定当前行进方向。
- 从前缀末端继续直线行进，把经过的背景格涂绿；遇到控制像素时不覆盖它，按本网格前缀已示范的含义左转或右转。
- 未被示范的另一种控制色取相反转向。持续行进，直到下一步越出网格为止。

关键洞察
- 控制色与转向之间没有固定码表；唯一可靠的依据是画面中已经走过并转过弯的那段前缀，它是嵌在输入里的规则示范，跨示例背记颜色含义必然出错。
```

## 2. 形色双拉丁方的违例修复

- 参考题目: 17 (4cd1b7b2), 16 (e734a0e8), 11 (662c240a)
- tags:
  - operation:补全, completion
  - operation:异常检测, anomaly_detect
  - object:分隔网格, separator_grid
  - object:图案精灵体, pattern_sprite
  - relation:行列唯一约束, row_column_uniqueness
  - condition:形色双拉丁约束, dual_latin_constraint
  - condition:无空白入口, no_blank_entry

### docstring

```text
网格图块在形状与颜色上各自构成拉丁方，找出唯一同时破坏两套约束的图块并推出它的唯一正确内容。

输入结构
- 分隔线把网格划分成 n×n 个等大图块，每块内画有一个小图案；图案有形状与颜色两个独立属性。
- 除一个图块外，每行每列各形状恰好出现一次、各颜色也恰好出现一次，且同一形状-颜色组合全盘至多出现一次，即颜色与形状互不绑定。
- 恰有一个图块内容错误：它使自己所在的行与列同时出现形状重复与颜色重复；没有任何空白提示其位置。

规则
- 分别按形状与按颜色审计各行各列的重复，交叉定位唯一的违例图块。
- 该块的正确形状是其所在行与列都缺失的那个形状，正确颜色是其所在行与列都缺失的那个颜色。
- 以其他同形图案的统一姿态重画该块，其余一切保持不变。

关键洞察
- 版面上没有空缺作入口，错误必须靠两套互相独立的拉丁约束交叉审计才能定位；形状与颜色互不绑定，把颜色当作形状的附属属性去推断会漏判或误判。
```

## 3. 十字准星计数菱形

- 参考题目: 1 (d2acf2cb), 5 (8f215267), 7 (c97c0139)
- tags:
  - operation:计数, counting
  - operation:擦除, erase
  - operation:包络生成, envelope_generation
  - object:标记像素, marker_pixel
  - object:网格边缘, grid_edge
  - relation:十字投影相交, crosshair_intersection
  - condition:计数映射半径, count_maps_to_radius

### docstring

```text
同色的两枚边缘标记以十字投影定出中心，同色内部散点的数量定出半径，画出空心菱形。

输入结构
- 黑色背景。对每种出现的前景色 c：上边或下边恰有一枚 c 色边缘标记，左边或右边也恰有一枚，另有若干枚 c 色单像素散布在内部。
- 一个网格中有两到三种前景色；各色菱形互不重叠且完整落在网格内；散点不落在任何菱形轮廓上。

规则
- 对每种颜色 c：取水平边标记所在列与竖直边标记所在行，交点即为中心。
- 数出内部 c 色散点的个数 r，并把这些散点全部擦成背景。
- 以中心为原点，把曼哈顿距离恰为 r 的所有格涂成 c 色，形成空心菱形轮廓；边缘标记保持不变。

关键洞察
- 内部散点不是待连接的几何素材而是计数器：它们的位置毫无意义，个数才是半径；中心也不在任何散点上，而由两枚边缘标记的十字投影交点给出。
```

## 4. 迭代剪枝存活填色

- 参考题目: 4 (42a50994), 6 (a64e4611), 20 (477d2879)
- tags:
  - operation:擦除, erase
  - operation:洪泛填充, flood_fill
  - operation:重涂色, recolor
  - object:连通分量, connected_component
  - object:闭合环, closed_loop
  - object:分支须, dendrite
  - relation:区域包含, region_containment
  - condition:迭代剪枝至稳定, iterative_pruning_fixpoint

### docstring

```text
反复删除只剩一个同色邻居的前景格直至稳定，再按环内标记给幸存环的内部填色。

输入结构
- 黑色背景上有一种前景色，构成若干四连通闭合环，环上挂着树状分支须，部分环之间还有两端都接在环上的连接通道。
- 每个闭合环内部恰有一枚颜色各异的标记像素；环外与通道上没有标记。

规则
- 反复删除四邻域中同色邻居数不超过一的前景格，直到再无格可删；悬挂的分支须会被逐层剪光，而闭合环以及两端连接不同环的通道全部存活。
- 对每个幸存闭合环，用其内部标记像素的颜色洪泛填充环的整个内部。
- 其余背景保持不变。

关键洞察
- 存活判据不是“是否属于闭合环”，而是“两端是否都有依托”：连接两环的通道不在任何环上却同样剪不掉；把规则误设为“只留闭合圈”会错删通道。
```

## 5. 图例查表的多数决填色

- 参考题目: 20 (477d2879), 18 (9110e3c5), 2 (4c7dc4dd)
- tags:
  - operation:重涂色, recolor
  - operation:查表映射, lookup_mapping
  - object:图例骨牌, legend_domino
  - object:标记像素, marker_pixel
  - object:连通分量, connected_component
  - relation:边邻接计数, edge_adjacency_count
  - condition:邻接多数决, adjacency_majority
  - condition:图例逐例变化, per_example_legend

### docstring

```text
灰色区域由邻接最多的标记色决定归属，但填入的是图例里该标记色对应的另一种颜色。

输入结构
- 一条整行分隔线把网格分成上下两部分：上方是工作区，下方是图例区。
- 工作区为黑色背景，含若干灰色四连通区域，区域边上贴着若干种标记单像素。
- 图例区放着若干个 1×2 双色骨牌：左格是标记色（键），右格是填充色（值）；键值对应关系每个示例都不同。

规则
- 对每个灰色区域，统计每种标记色与它共享的边邻接数，取邻接数严格最多的标记色为胜者（保证无并列）。
- 在图例中查出胜者对应的值色，用值色填满该灰色区域。
- 标记像素、图例与分隔线保持不变。

关键洞察
- 多数决只是选键，真正的填充色藏在图例里；图例逐例更换，使“直接用胜出标记色上色”的捷径在对照示例输出时立即破产。
```

## 6. 双束分工与奇偶抵消

- 参考题目: 1 (d2acf2cb), 15 (97999447)
- tags:
  - operation:颜色互换, color_swap
  - object:标记像素, marker_pixel
  - object:网格边缘, grid_edge
  - relation:对边配对, opposite_edge_pair
  - relation:光束交叉, beam_crossing
  - condition:奇偶次作用抵消, parity_cancellation
  - condition:双色束分工, pair_specific_swap

### docstring

```text
黄色对边光束互换黑青、红色对边光束互换粉橙，被偶数条同类光束覆盖的格恢复原色。

输入结构
- 网格内部只使用黑、青、粉、橙四色。
- 边缘上有若干对对齐的黄色标记与若干对对齐的红色标记，每对位于一组对边上，框定一条整行或整列光束；光束之间存在交叉。

规则
- 每条黄色光束把其严格内部各格做黑↔青互换；每条红色光束把其严格内部各格做粉↔橙互换。
- 一个格被多条光束覆盖时逐条施加互换：被奇数条黄束覆盖的黑/青格换色，被偶数条覆盖的还原；粉/橙格同理，只看红束条数。
- 所有边缘标记保持不变。

关键洞察
- 光束不是“染色区域”而是对合变换：作用两次等于不作用；交叉处的看似不变正是两次互换相互抵消的结果，且两种光束各管一对颜色、互不干扰。
```

## 7. 拓扑异类的归一化提取

- 参考题目: 19 (bd14c3bf), 11 (662c240a)
- tags:
  - operation:形状匹配, shape_match
  - operation:压缩, compress
  - operation:裁剪, crop
  - object:候选对象, candidate_object
  - relation:游程压缩等价, run_length_equivalence
  - relation:旋转反射等价, rotation_reflection_eq
  - condition:选拓扑异类, select_topology_outlier

### docstring

```text
在若干经过拉伸与旋转的图形中找出压缩后拓扑不同的那一个，输出它的游程压缩形态。

输入结构
- 黑色背景上散布若干个单色图形，颜色、大小、长宽比与朝向各不相同。
- 把每个图形裁剪到包围盒并把相邻重复的行与列压缩后，除一个图形外，其余压缩形态在旋转与镜像意义下全部相同。

规则
- 对每个图形做包围盒裁剪与游程压缩，在旋转与镜像等价下把图形分组。
- 找出唯一不属于多数类的图形。
- 输出该图形按原画面朝向的压缩形态，保留其颜色。

关键洞察
- 颜色、面积、长宽比、朝向全是诱饵，任何按外观属性的挑选都会失败；唯一可靠的判据是先压掉拉伸、再模掉旋转镜像之后剩下的拓扑形状。
```

## 8. 镜像壁纸的折叠复原

- 参考题目: 3 (bc4146bd), 8 (c59eb873), 4 (42a50994)
- tags:
  - operation:镜像, mirror
  - operation:平铺, tiling
  - operation:去噪复原, denoise_reconstruct
  - object:瓦片, tile
  - relation:行列奇偶翻转拼贴, alternating_flip_tiling
  - relation:折叠对齐, fold_alignment
  - condition:逐格多数决, per_cell_majority

### docstring

```text
把带噪点的镜像交替壁纸按块折叠对齐，用逐格多数决复原出干净的基础瓦片。

输入结构
- 整幅输入由同一基础瓦片拼成 q 行 × p 列的壁纸：第 i 行第 j 列的块在 j 为奇数时左右翻转、i 为奇数时上下翻转（行列均从零计）。
- 基础瓦片左右不对称也上下不对称；块与块之间没有分隔线，块的尺寸未直接给出。
- 少量像素被噪声改成了别的颜色；每个格位在所有块中被污染的份数少于一半。

规则
- 从翻转拼接的周期结构中推断出块的高与宽。
- 把每个块按其行列奇偶翻转回标准姿态，与基础瓦片逐格对齐。
- 输出一个瓦片大小的网格，每格取所有对齐副本中的多数颜色。

关键洞察
- 相邻块之间是镜面相接而非平移重复，直接按平移周期折叠会对不齐；必须先识别“行列奇偶各自独立翻转”的拼贴规律，再折叠投票去噪。
```
