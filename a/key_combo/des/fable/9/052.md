## 1. 反对称遮挡恢复

- 参考题目: ff805c23, d511f180
- tags:
  - operation:旋转, rotate
  - operation:重涂色, recolor
  - operation:裁剪, crop
  - object:遮挡块, occluder_block
  - object:反对称图案, anti_symmetric_pattern
  - relation:复合对称, composed_symmetry
  - condition:旋转加换色恢复, rotation_plus_swap_restores

### docstring

```text
将场景旋转180度并交换一对互补颜色，以恢复遮挡块下的隐藏图案。

输入结构：
- 背景色占多数，其上绘有一幅大图案，图案由两种"互补色"和若干中性色组成。
- 图案满足反对称：把整幅图旋转180度、再把两种互补色互换后，与原图完全一致；
  中性色像素旋转后落回同色位置。
- 一个单色实心矩形遮挡块覆盖图案的一部分，遮挡色不在图案中出现。

规则：
- 找到遮挡块的包围盒。
- 比对可见的中心对称位置对，找出唯一一对"旋转后颜色总是互换"的颜色。
- 将整幅输入旋转180度并互换这对颜色，在遮挡块原位置裁出补丁作为输出。

关键洞察：
- 图案不是普通的旋转对称：只做180度旋转得到的补丁形状正确但颜色相反；
  必须发现对称变换里还复合了一次双色互换，且互换的色对要靠可见部分自行推断。
```

## 2. 水库预算瀑布

- 参考题目: 36a08778, 271d71e2, 54db823b
- tags:
  - operation:重力下落, gravity_drop
  - operation:溢出扩散, overflow_spread
  - operation:计数, counting
  - object:水库柱, reservoir_column
  - object:架子, shelf
  - relation:级联分支, cascading_branch
  - condition:预算耗尽成潭, budget_exhausted_pools

### docstring

```text
模拟顶端水库的瀑布级联，水库柱的高度规定这一族水流总共能绕过几层板。

输入结构：
- 背景为最常见色；贴着顶边有若干单列的水色竖直短柱作为水库，柱高各不相同。
- 下方错落分布若干水平板（另一种前景色），板与板互不接触。

规则：
- 每个水库从柱底向正下方放出一条水流，携带预算，预算初值等于柱高。
- 水流下落把经过的背景格涂成水色；落到底行即自然结束。
- 水流撞到板时：若预算大于零，预算减一，从板两端外侧各一格分出两条子流继续下落，
  两条子流各自携带扣减后的预算；若预算等于零，水流沿板的上表面向两侧摊开，
  恰好铺满板的整个跨度后停止，不越过板端。

关键洞察：
- 水库的高度不是装饰而是预算：它限定这条水流谱系的分叉深度，
  预算耗尽的流不再绕过板，而是在板上摊成一汪死水；
  同一板阵下，不同高度的水库长出深浅不同的瀑布树。
```

## 3. 滤色门与挡板

- 参考题目: 64efde09, d5d6de2d, 8b7bacbf
- tags:
  - operation:射线延伸, ray_extension
  - operation:重涂色, recolor
  - object:空心矩形, hollow_rectangle
  - object:实心矩形, solid_rectangle
  - object:发射标记, emitter_marker
  - relation:门控连锁变换, gated_chain_transform
  - condition:空心透射换色实心阻挡, hollow_transmits_solid_blocks

### docstring

```text
从边缘发射像素射线：射线每穿过一个空心框就被染成框色，撞上实心块则戛然而止。

输入结构：
- 黑色背景；网格边缘上嵌有若干彩色单像素发射器，发射方向垂直于所在边指向内部。
- 场内散布若干轴对齐矩形，颜色各异：一像素厚的空心框，以及实心矩形块。

规则：
- 每个发射器沿发射方向逐格前进，把经过的背景格涂成当前颜色，
  当前颜色初始为发射器自身颜色。
- 射线撞到空心框时穿墙而过：框壁像素保持不变，但从进入框体那一刻起，
  当前颜色更新为该框的颜色，框内与框后的背景格都用新色涂画。
- 射线撞到实心矩形时，在它前一格停止。
- 射线抵达网格边缘时结束。

关键洞察：
- 矩形不是统一的障碍物：空心与实心的拓扑差别决定它是"滤色门"还是"挡板"；
  一条射线的分段颜色就是它穿过的门的序列记录，
  而轮廓相似的矩形可能给出完全不同的命运。
```

## 4. 补出缺失的同伴

- 参考题目: cd3c21df, ff805c23, 42918530
- tags:
  - operation:图案匹配, pattern_match
  - operation:变换归纳, transform_induction
  - operation:裁剪, crop
  - object:多色精灵体, multicolor_sprite
  - relation:二面体配对, dihedral_pairing
  - relation:全场统一变换, global_shared_transform
  - condition:孤例外推补全, unmatched_extrapolated

### docstring

```text
为在全场统一配对变换下落单的精灵补画出它缺失的同伴。

输入结构：
- 背景为主导色，其上散布若干互不相连的多色精灵，位置任意。
- 除一个精灵外，其余精灵两两配对：每对中的两个精灵由同一种二面体变换互相对应，
  且全场所有已配对的同伴对使用同一种变换。
- 逐格严格比较时几乎没有两个精灵完全相同，且有的图案严格重复出现奇数次，
  使"数出现次数找唯一"策略失效；各精灵颜色集合高度重叠，
  不能凭颜色构成或尺寸辨认答案。

规则：
- 对精灵两两尝试二面体变换找出全部配对，归纳出全场统一的那一种配对变换。
- 找出唯一没有同伴的精灵。
- 输出该精灵在统一配对变换下的像——即它缺失的同伴该有的样子，裁到紧致包围盒。

关键洞察：
- 孤例不是要展出的答案，而是缺了同伴的那一个；
  必须先从已配对的精灵中归纳出全场共用的变换，再把它外推到孤例身上，
  画出一幅从未在输入中出现过的图案。
```

## 5. 指针坐标系印章

- 参考题目: f5c89df1, ff805c23, 54dc2872
- tags:
  - operation:印章覆盖, stamp
  - operation:旋转, rotate
  - operation:擦除, erase
  - object:控制指针, pointer_control
  - object:锚点像素, anchor_pixel
  - relation:相对坐标复制, relative_coord_copy
  - relation:朝向对齐, orientation_alignment
  - condition:指针方向定旋转, pointer_sets_rotation

### docstring

```text
以指针为坐标系把源图形复制到各目的指针处，并按指针朝向差同步旋转。

输入结构：
- 背景网格上有一团源色像素构成的图形，以及若干"指针"：
  每个指针由一个彩色头像素和一个与其4邻接的灰色尾像素组成，尾指向头即指针朝向。
- 恰有一个指针的头像素与源色像素4邻接，它是锚指针；其余指针是目的指针，散布各处。

规则：
- 记录全部源色像素相对锚指针头像素的坐标集。
- 对每个目的指针，取"把锚指针朝向转到该指针朝向"所需的90度倍数旋转，
  将相对坐标集旋转后以目的头像素为原点、用源色重画图形。
- 输出中擦除原始源图形与所有指针的头尾像素，只保留各目的地的旋转副本。

关键洞察：
- 指针携带的不只是落点，而是一整个坐标系：
  副本必须随两枚指针的朝向差旋转，
  单纯平移照搬只在朝向恰好相同的目的地上碰巧正确。
```

## 6. 长边量子跳跃

- 参考题目: 64a7c07e, 36a08778, 271d71e2
- tags:
  - operation:平移, translate
  - object:前景矩形, foreground_rectangle
  - object:墙壁线段, wall_segment
  - relation:长边定方向, long_side_sets_direction
  - condition:按自身长度步进, step_by_own_length
  - condition:碰撞停止, collision_stop

### docstring

```text
每个矩形沿自己长边方向反复跳跃，步长等于长边长度，跳到不能再跳为止。

输入结构：
- 背景上有若干实心矩形物体（颜色各异）与若干灰色固定墙段。
- 每个物体宽高不等：宽大于高的物体向右运动，高大于宽的物体向下运动；
  各物体的运动路径互不交叉。

规则：
- 每个物体沿其运动方向一次跳一整步，步长等于它的长边长度。
- 只要再跳一步既不越出网格、也不与任何墙段重叠，就继续跳；否则停在当前位置。
- 墙保持原样，输出中把每个物体重绘在最终位置，原位置恢复为背景。

关键洞察：
- 运动是量子化的：物体往往停在离墙还差几格的地方，
  缝隙宽度正是剩余距离对步长取余的结果，
  "紧贴障碍滑行"的直觉在多数示例上都会失败。
```

## 7. 定向锚多数决修复

- 参考题目: 42918530, e681b708, 6aa20dc0
- tags:
  - operation:图案修复, pattern_repair
  - operation:旋转, rotate
  - operation:镜像, mirror
  - operation:分组, grouping
  - object:精灵体, sprite
  - object:定向锚像素, orientation_anchor
  - relation:同色组共享真图案, color_group_shares_truth
  - condition:归一化后多数投票, vote_after_normalization

### docstring

```text
先按角落锚把同组图章转正对齐，逐格多数投票得出真图案，再按各成员自身朝向放回修复。

输入结构：
- 背景上排布若干占据同尺寸矩形区域的单色图章，按主色分成若干组，
  每组成员数为奇数且不少于三。
- 同组成员画的本是同一幅图案，但各成员以不同的旋转或镜像朝向摆放；
  每个图章包围盒的某一角固定有一颗定向锚像素（特殊色）。
- 成员还可能带零星缺笔（漏成背景）或多笔（多出的主色像素）。

规则：
- 把每个成员按其定向锚旋转或镜像到锚位于左上角的标准朝向。
- 对齐后逐格统计组内成员该位取主色还是背景，多数者为该组真图案在此格的取值。
- 把真图案按每个成员原来的朝向变换回去，原位替换该成员，锚像素保留原角。

关键洞察：
- 直接原位投票会因朝向错乱得到噪声；锚像素给出每个成员的私有坐标系，
  归一化后多余笔画被多数票删除、缺失笔画被补齐，
  最后还要把真图案逆变换送回各自的朝向——每个成员既是待修复者又是证据。
```

## 8. 连通器水位

- 参考题目: 8b7bacbf, 54db823b, 36a08778
- tags:
  - operation:填充, fill
  - operation:计数, counting
  - object:封闭腔体, enclosed_cavity
  - object:悬滴标记, hanging_droplets
  - relation:体积守恒定水位, volume_sets_level
  - relation:底部连通等水面, communicating_vessels
  - condition:全腔同一水平线, single_horizontal_level

### docstring

```text
把悬在一个腔口上方的水滴注入底部互通的多腔容器，水在所有腔室内升到同一水平面。

输入结构：
- 黑背景上有灰色壁围成的容器结构；结构内腔由若干条向上开口的竖直腔室组成，
  各腔室在底部经由内部通道彼此连通。
- 腔底有台阶与凸起，各腔室宽窄深浅不一。
- 恰有一团彩色水滴像素悬在其中一个腔室的正上方，滴数即水的体积。

规则：
- 数出悬滴像素数 n。
- 在整个连通内腔中选取一条水平线，
  使严格位于该线以下的内腔空格总数恰好等于 n（示例保证恰好存在这样的线）。
- 把这些空格全部涂成水滴颜色；悬滴消失，容器壁保持不变。

关键洞察：
- 水不会只留在被注入的那个腔室——底部连通使所有腔室的水面必须等高；
  答案由"体积守恒"与"等水位"两条约束联合确定，
  逐腔平分或在注入腔逐行填充的直觉都会失败，
  远离注入口的腔室也会被淹到同一高度。
```

## 9. 行程单巡访

- 参考题目: 0e671a1a, 8b7bacbf, 5ad4f10b
- tags:
  - operation:连线, line_drawing
  - operation:读序, sequence_reading
  - object:站点像素, station_pixel
  - object:行程色带, itinerary_strip
  - relation:图例驱动路由, legend_driven_routing
  - condition:先横后纵路由, horizontal_then_vertical

### docstring

```text
按贴边色带给出的顺序巡访各色站点，每一跳先横后纵并涂上目的站的颜色。

输入结构：
- 黑背景上有一个灰色单像素起点和若干彩色单像素站点，颜色互不相同。
- 网格某条边上贴有一排连续的彩色色带，色带的颜色依次对应各站点，
  色带与站点在空间上互不接触。

规则：
- 从左到右（或从上到下）读出色带的颜色序列，作为巡访顺序。
- 从起点出发依次前往每个站点：每一跳先水平移动到目的站所在列，再竖直移动到目的站。
- 每一跳经过的背景格涂成目的站的颜色；起点、站点与色带保持不变。

关键洞察：
- 那排贴边像素不是装饰而是行程单：站点的空间远近与巡访次序无关，
  路径颜色的分段变化忠实回放了行程单上的序列。
```
