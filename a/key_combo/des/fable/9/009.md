## 1. 层序穿透射线

- 参考题目: `5 (981add89)`、`6 (68bc2e87)`
- tags:
  - operation:射线延伸, ray_extend
  - operation:排序, layer_sorting
  - object:空心矩形, hollow_rectangle
  - object:控制像素, control_pixel
  - relation:遮挡层序, occlusion_order
  - condition:层序决定穿透, layer_gates_ray

### docstring

```text
顶行控制像素向下发射射线，射线能否穿过每个矩形框由框之间隐藏的堆叠层序决定。

输入结构
- 背景单色；画面中有若干单像素粗、颜色互异的矩形框相互重叠，交叠处只显示位于上层的框色。
- 顶行有若干控制像素，每个控制像素的颜色都对应画面中一个矩形框的颜色。

规则
- 先由交叠处的可见颜色恢复所有矩形框自底向上的完整堆叠顺序。
- 每个控制像素沿所在列向下发射同色射线：射线在背景格上涂上自身颜色；遇到层序不高于自身对应框的框边时直接穿过（该格保持框色不变）继续向下；首次遇到层序高于自身对应框的框边时，在其上方一格停止。
- 射线未覆盖的部分与所有框保持原样，顶行控制像素不变。

关键洞察
- 射线的通行权不由颜色本身、也不由沿途相遇的先后决定，而由只能从交叠遮挡中读出的全局层序决定；必须先解出隐藏的堆叠排序，才能画对每一条射线的长度。
```

## 2. 并集围合与墙权归属

- 参考题目: `7 (66f2d22f)`、`19 (7b6016b9)`
- tags:
  - operation:透明叠加, transparent_overlay
  - operation:洪泛填充, flood_fill
  - object:双面板, two_panels
  - object:涌现封闭区, emergent_enclosure
  - relation:占用并集, occupancy_union
  - condition:墙体多数归属, wall_majority_owner

### docstring

```text
把左右两块面板叠加成一堵墙，只有叠加后才封闭的空洞按围墙多数方的颜色填充。

输入结构
- 输入宽度均分为左右两块等大面板，各含一种前景色的碎片。
- 单看任何一块面板，其前景都围不出任何封闭区域；两面板按行列对齐叠加后，占用并集形成一条或多条封闭围墙。

规则
- 按行列对齐两块面板，取两者前景占用的并集作为墙。
- 输出为单面板大小：与边界四连通的并集空格保持背景；被墙围死的空格逐洞填色——每个空洞填入与它八相邻的墙格中占多数的那一面板的前景色。
- 墙格自身在输出中保持背景。

关键洞察
- 任何一块面板都围不住任何区域，封闭性只在叠加并集中涌现；"两侧都空则标记"的补集读法在个别示例里碰巧成立，但外部空格永不填色戳破了它。空洞的颜色也不固定属于哪块面板，而由每个洞四周墙体的出身多数逐洞裁定。
```

## 3. 无主模板互补

- 参考题目: `2 (fd096ab6)`、`4 (ce602527)`
- tags:
  - operation:补全, completion
  - operation:平移对齐, translate_align
  - object:残缺拷贝, partial_copy
  - object:隐藏模板, hidden_template
  - relation:互补并集, mutual_union
  - condition:无完整母版, no_complete_master

### docstring

```text
画面上每种颜色都是同一隐藏形状的不完整平移拷贝，没有任何一份是完整的；把所有残片对齐取并集还原模板，再把每份拷贝就地补全。

输入结构
- 背景单色；若干种前景色，每种颜色的像素都是同一个隐藏模板形状经平移后的残缺子集，各份缺失的部分互不相同。
- 任何一种颜色都不是完整模板；设计保证任意两份拷贝在正确对齐下现存像素重叠充分、平移对齐方式唯一。

规则
- 按颜色分组；求出使各组互相相容（都是同一形状的子集）的唯一平移对齐。
- 对齐后取所有组现存像素的并集作为模板形状。
- 把每种颜色在原位置补成完整模板：用本色填上缺失格，其余像素保持不变。

关键洞察
- 模板从未被完整画出，它只存在于所有残片的并集之中；诱饵是把像素最多的一份当作母版去补全其余各份，但它自己同样有缺口，只有互补对齐才能同时修复所有拷贝。
```

## 4. 域诺链挂装

- 参考题目: `10 (9968a131)`、`18 (2a28add5)`
- tags:
  - operation:排序, chain_ordering
  - operation:滑动, shift
  - object:双色条, two_color_bar
  - object:控制像素, marker_pixel
  - relation:颜色共享成链, shared_color_chain
  - condition:逐级传递对齐, cascading_alignment

### docstring

```text
散落的双色条是一条链的散件，从标记色那根开始，按颜色共享关系把整条链逐节挂回成一列阶梯。

输入结构
- 背景单色；若干水平 1×2 双色条散布各处，行列均无序。
- 恰有一种颜色只出现在一根条上，且画面另有一个该颜色的孤立单像素作为起始标记。
- 按"相邻两节恰共享一种颜色"的关系，这些条可且仅可连成一条链。

规则
- 含标记色的条为链头，保持原位；孤立标记像素抹去。
- 其余条按链序逐节放置：每节放在上一节正下方一行，水平平移（不翻转、保持内部左右顺序）使它与上一节共享的颜色落在上一节该颜色（就位后）所在的列。
- 各条原位置清为背景。

关键洞察
- 条与条之间没有画出任何连接，链的结构只藏在颜色的共享关系里；放置又是逐级传递的——每节的落点由上一节放好后的位置决定，链序、链头与对齐参照都必须自己推出来。
```

## 5. 水量沿廊配给

- 参考题目: `9 (3ad05f52)`、`18 (2a28add5)`、`19 (7b6016b9)`
- tags:
  - operation:寻路, pathfinding
  - operation:计数, counting
  - operation:填充, fill
  - object:蓄水池, reservoir
  - object:框架房间, framed_room
  - object:门缺口, door_notch
  - relation:沿路顺序, along_route_order
  - condition:容量预算截断, capacity_budget_cutoff

### docstring

```text
蓄水池的像素数是总水量，沿走廊把一串房间依次灌满，水不够时最后一间只从底部灌起。

输入结构
- 墙色画出若干矩形房间，房间之间由带门缺口的走廊连成一条链；链的一端连接一个实心矩形蓄水池（水色）。
- 房间内部为背景；蓄水池像素数与沿链各房间内部面积由设计保证：截断发生处恰好落在整行。

规则
- 总水量等于蓄水池的像素个数。
- 从蓄水池沿走廊出发，按到达顺序给每个房间灌水：内部全部涂成水色，每灌满一间从水量中扣除其内部面积。
- 剩余水量不足以灌满下一间时，在该房间内自底行向上整行涂色，涂满"剩余水量 ÷ 房间内宽"行后停止；其后的房间保持空。走廊与门不涂色，蓄水池保持原样。

关键洞察
- 这不是普通洪泛：可达性只决定灌注顺序，真正决定涂色范围的是一条随路径逐间递减的容量预算；池子以像素计数而非形状参与规则，最后一间的水面高度是预算余额的几何化。
```

## 6. 尺度亲缘对换

- 参考题目: `4 (ce602527)`、`1 (df978a02)`
- tags:
  - operation:缩放, scaling
  - operation:形状匹配, shape_matching
  - object:缩放对象, scaled_object
  - object:干扰对象, distractor_object
  - relation:跨尺度同形, cross_scale_same_shape
  - condition:成对交换尺度, pairwise_scale_swap

### docstring

```text
找出忽略颜色后同形异尺度的对象对，让每一对原地交换体量。

输入结构
- 背景单色，其上有若干彩色对象；其中一些对象两两配对：形状相同但尺度相差 2 或 3 倍，颜色不同。
- 较大的一方可能被画布边缘裁掉一部分；另有不属于任何配对的干扰对象。

规则
- 忽略颜色，把每个对象与其余对象在 2、3 倍整数缩放下比较掩码；被裁剪的对象按出界补全后参与比较。
- 每对匹配成功的对象原地交换尺度：小的放大为对方尺度，大的缩小为对方尺度，均以（补全后）包围盒中心为锚点，各自保留原色；放大后出界的部分照常裁掉。
- 干扰对象与背景保持不变。

关键洞察
- 对象之间的亲缘关系跨颜色、跨尺度、甚至跨越画布边缘；输出不是挑选、裁剪或删除其中一方，而是让每对亲缘对象互换体量——被裁剪的大个子换成小尺度后才第一次完整现身。
```
