## 1. 镶在格局里的地图

- 参考题目：17 (af24b4cc)、19 (5614dbcf)、13 (3ed85e70)、5 (80214e03)
- tags:
  - operation:压缩, compress
  - operation:多数决, majority_vote
  - operation:旋转, rotate
  - operation:镜像, mirror
  - object:分隔栅格, divider_grid
  - object:自指缩略图, self_thumbnail
  - relation:块与像素对应, block_pixel_mapping
  - condition:容错唯一姿态, tolerant_unique_pose
  - condition:唯一失配块修正, unique_mismatch_fix

### docstring

```text
把藏在格局中的微缩自指图摆正后，按它重建整幅纯色格局。

输入结构
- 完整的分隔行列把网格划成 m×n 的色块格局；除一块外，每块都以一种主色
  填充，块内散布少量灰色噪点。
- 剩下那一块内部不是单色，而是一幅 m×n 的微缩色图。
- 微缩图是整个格局逐块主色的缩略图，但被施加了未知的旋转或镜像；在唯一
  正确的姿态下，它与格局的逐块主色恰好只差一处（其余姿态失配都多于一处）。
- 微缩图中对应它自己所在块的那个像素，给出的是该块"应有"的纯色。

规则
- 找出内部多色的微缩图块；对其余各块做忽略灰噪的多数决，得到格局主色图。
- 在八种旋转镜像姿态中，找到与主色图恰好只差一处的唯一姿态。
- 按该姿态的微缩图重建输出：每块整块涂成缩略图规定的纯色（失配块被纠正、
  灰噪点被清除、微缩图块本身涂成其自指像素声称的颜色），分隔线保持不变。

关键洞察
- 那个"花块"不是异常噪声而是整幅画面的自指地图；它的姿态无法直接读出，
  只能用"恰好一处失配"的容错匹配反推；连它自己的颜色也要由它内部对应
  自身位置的那个像素来宣告。
```

## 2. 图例当函数用

- 参考题目：16 (5adee1b2)、2 (b9b7f026)、3 (a8d7556c)
- tags:
  - operation:重涂色, recolor
  - operation:图例迭代, legend_iteration
  - object:颜色图例, color_legend
  - object:封闭孔洞, enclosed_hole
  - object:连通分量, connected_component
  - relation:图例映射, legend_mapping
  - condition:孔洞数定迭代次数, hole_count_iterations

### docstring

```text
按对象封闭孔洞的个数，沿左缘颜色图例链迭代相应步数来重涂对象。

输入结构
- 左缘排列若干 1×2 图例对，每对左格是源色、右格是像色，共同定义一个
  颜色映射；这些映射相互衔接，可连成链或环。
- 场内散布若干单色 4 连通对象，各自围出 0 到 3 个封闭背景孔洞。
- 对象颜色都出现在图例的源色集合中。

规则
- 数出每个对象封闭的背景孔洞个数 k。
- 从对象原色出发，沿图例映射连走 k 步，得到目标色；k 为 0 的对象保持原色。
- 将对象整体重涂为目标色，孔洞与背景保持不变。

关键洞察
- 图例不是一次性的换色表，而是一个可反复施加的函数；施加次数由对象的
  拓扑（孔洞数）决定，与其大小、位置、形状无关。首个示例中所有对象恰好
  都只有一个孔，看似普通的单次图例映射，其余示例打破这一错觉。
```

## 3. 门链洪泛

- 参考题目：15 (673ef223)、1 (7447852a)、2 (b9b7f026)、12 (642248e4)
- tags:
  - operation:射线延伸, ray_cast
  - operation:洪泛填充, flood_fill
  - object:封闭区域, enclosed_region
  - object:门像素, door_pixel
  - object:方向标记, direction_marker
  - relation:连锁触发, chain_trigger
  - condition:仅链上房间染色, chain_rooms_only

### docstring

```text
让方向标记发出的射线依次穿门点亮一串房间，未被链条经过的房间保持黑色。

输入结构
- 灰色墙体在黑色场地上围出若干互不连通的封闭房间，走廊为黑色背景。
- 每个房间的墙上恰嵌有两枚同色的彩色门像素，各房间的门色互不相同。
- 走廊中有一个两格的方向标记：青色尾格与黄色头格相邻。

规则
- 从标记头部沿尾指向头的方向发射射线，射线只在黑色走廊中直行。
- 射线击中某房间的门时，该房间内部整体洪泛为门色；随后从该房间的另一扇
  门向墙外一侧继续发射新的射线。
- 如此连锁，直到某条射线走出网格边缘为止；所有射线经过的走廊格涂成黄色
  （标记头色），未被任何门接入链条的房间保持黑色。

关键洞察
- 房间并非各自独立按门色填充；门把房间接成一条由几何决定的因果链，一个
  房间是否上色取决于它是否被链条命中，而链条的走向又由每个房间第二扇门
  的位置反过来决定。
```

## 4. 高度接力

- 参考题目：14 (ce9e57f2)、1 (7447852a)、3 (a8d7556c)
- tags:
  - operation:重涂色, recolor
  - operation:排序, sorting
  - object:竖直条, vertical_bar
  - relation:属性跨对象转移, attribute_transfer
  - relation:排名空间配对, rank_space_pairing
  - condition:次矮者定分割, next_shorter_split

### docstring

```text
每根红条底部改涂青色的格数，等于高度排名紧随其后那根条的高度，最矮条参照最高条。

输入结构
- 黑色背景上立着若干互不接触、落在同一底线上的红色实心竖条。
- 各条高度互不相同；条的左右排列顺序与高度排名顺序不一致（仅第一个训练
  示例中两种顺序恰好一致）。

规则
- 将竖条按高度从高到低排名；每条的参照条是排名紧随其后的那根，即比它矮
  的条中最高的一根。
- 每条自底向上数出参照条高度那么多格，改涂青色，其余部分保持红色。
- 最矮条的参照条是最高条；因参照不低于自身，整条改涂青色。

关键洞察
- 分割量不是条自身的属性（如一半高度），而是从"另一根条"搬运来的量；
  而配对的钥匙不在位置空间——左邻右舍是诱饵，首个示例故意让位置序与
  高度序重合——而在高度排名空间里首尾成环。
```

## 5. 自旋印章

- 参考题目：9 (5b6cbef5)、18 (1b60fb0c)
- tags:
  - operation:印章覆盖, stamp_overlay
  - operation:旋转, rotate
  - object:种子精灵, seed_sprite
  - relation:像素到块映射, pixel_to_block_mapping
  - relation:象限定姿态, quadrant_orientation
  - condition:前景位放旋转副本, fg_position_rotated_copy

### docstring

```text
把种子图印入每个前景像素对应的输出块，副本按该像素所在象限绕自身旋转相应角度。

输入结构
- 输入是偶数边长的正方形单色种子图，黑色为背景，仅一种前景色。
- 以几何中心划分，每个像素明确属于四个象限之一。

规则
- 输出为按输入边长平方放大的黑色网格，划成与输入同构的块阵。
- 对每个前景像素，把整幅种子图印入对应块：右上象限像素印原图，右下、
  左下、左上象限的像素分别印顺时针旋转四分之一、二分之一、四分之三圈
  的副本。
- 背景像素对应的块保持全黑。

关键洞察
- 展开不是均匀的自相似复制；副本的姿态由其落位相对中心的方位反馈决定，
  仿佛每份拷贝都随自己所在的象限一同旋转。若种子近似旋转对称，前几块
  会伪装成恒等拷贝。
```

## 6. 层序考古

- 参考题目：8 (52df9849)、2 (b9b7f026)、7 (83eb0a57)
- tags:
  - operation:排序, sorting
  - object:空心矩形, hollow_rectangle
  - relation:前景遮挡, foreground_occlusion
  - relation:传递序, transitive_order
  - condition:断边定上下, broken_edge_order

### docstring

```text
根据空心矩形框互相压断的边框恢复叠放次序，自底向上输出各框颜色组成的一列色条。

输入结构
- 黑色背景上叠放若干颜色互不相同的单色空心矩形框。
- 相交的两框中，处于下层者的边框在交叉处被上层者的颜色压断；框架其余
  部分完整可见。
- 并非任意两框都直接相交，但相交关系把所有框连通。

规则
- 对每对相交的框，看交叉处显示谁的颜色，得到这两框的上下关系。
- 不直接相交的框对通过共同相交的第三框传递比较，合成唯一的全序。
- 输出高度为框数的一列竖条：最下格是最底层框的颜色，最上格是最顶层框
  的颜色。

关键洞察
- 上下关系只在交叉处零星可见，且不少框对之间没有直接证据；全序必须沿
  相交链传递推出，面积大小、摆放位置、颜色次序都是诱饵。
```

## 7. 折线沿途的节拍

- 参考题目：1 (7447852a)、20 (06df4c85)
- tags:
  - operation:洪泛填充, flood_fill
  - operation:序列外推, sequence_extrapolation
  - object:分隔线, divider_line
  - object:封闭区域, enclosed_region
  - relation:沿线行进顺序, path_order
  - condition:等差续填, arithmetic_continuation

### docstring

```text
读出已填黄区域在红折线行进顺序中构成的等差数列，把数列后续命中的区域全部填黄。

输入结构
- 一条红色折线从网格一侧的端点出发蛇形折返前行至另一端，把黑色场地分成
  沿线依次出现的若干区域。
- 其中少数几个区域已被填成黄色，其余为黑。
- 已填区域按沿线行进顺序的序号构成一个等差数列的开头几项；各示例的公差
  互不相同。

规则
- 从红线的起点端沿线行进，按各区域沿途出现的先后给区域编号。
- 由已填黄区域的编号读出首项与公差。
- 将编号属于该等差数列的所有后续区域洪泛为黄色，已填与未命中的区域保持
  原样。

关键洞察
- 已填的黄区不是装饰而是数据：步长与起点必须从它们身上读出；而区域的
  真正顺序沿折线行进方向而非从左到右，两种顺序在折返处分道扬镳。
```

## 8. 借形补残

- 参考题目：13 (3ed85e70)、18 (1b60fb0c)、7 (83eb0a57)
- tags:
  - operation:模板匹配, template_matching
  - operation:补全, complete
  - operation:旋转, rotate
  - operation:镜像, mirror
  - object:目录模板, catalog_template
  - object:残缺精灵, partial_sprite
  - relation:姿态唯一匹配, unique_pose_match
  - condition:缺失部分标记新色, missing_marked_new_color

### docstring

```text
在目录里找到残缺精灵唯一能对上的模板与姿态，用红色补出它缺失的像素。

输入结构
- 网格一侧的衬色目录区陈列若干完整的多色模板精灵。
- 黑色工作区里有一个残缺精灵，它是某个模板经过旋转或镜像后的一部分视图。
- 红色在输入中不出现；残缺精灵自身往往呈现出貌似完整的轴对称外形。

规则
- 在所有模板的所有旋转与镜像姿态中，找出唯一能把残缺精灵作为子图完全
  覆盖的那个模板与姿态。
- 把该姿态下模板的其余像素按对齐位置补进工作区，全部涂成红色。
- 目录区与残缺精灵的可见像素保持不变。

关键洞察
- 残片自身的对称性是陷阱：按自对称补全得到的形状与任何模板都对不上；
  正确答案由另一处对象在某个隐藏姿态下的整体形状决定，模板与姿态都由
  可见残片唯一锁定。
```
