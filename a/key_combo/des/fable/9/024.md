## 1. 条尖排名定旋转

- 参考题目题号：4（ecaa0ec1）、8（9473c6fb）、10（a61f2674）
- tags:
  - operation:旋转, rotate
  - operation:排序, sort
  - operation:擦除, erase
  - object:竖直线段, vertical_bar
  - object:条尖标记, bar_tip_marker
  - object:精灵体, sprite
  - relation:颜色配对, color_pairing
  - condition:高度名次定旋转次数, height_rank_determines_turns

### docstring

```text
按同色条尖所在竖条的高度名次，把每个精灵体顺时针旋转对应次数的九十度。

输入结构
- 黑色背景上立着最多四根一格宽的灰色竖条，高度互不相同。
- 每根竖条顶端一格为独特的非灰颜色（条尖色），各条尖色互不相同。
- 网格其他位置有与竖条数量相同的单色精灵体，每个精灵体的颜色与某个
  条尖色一一对应；精灵体形状均无旋转对称。

规则
- 将竖条按高度从矮到高排名，最矮为第一名。
- 每个精灵体在自身包围盒内顺时针旋转 k 个九十度，并锚定回原包围盒的
  左上角，k 等于其同色条尖所在竖条的名次。
- 擦除所有竖条与条尖，只保留旋转后的精灵体。

关键洞察
- 条尖颜色是索引，旋转次数由高度的名次而非高度格数决定；名次为四的
  精灵旋转三百六十度即原样不动。把高度格数直接当旋转次数是诱饵，它
  只在个别示例中凑巧成立。
```

## 2. 车道反弹与染色闸门

- 参考题目题号：2（50aad11f）、6（9b4c17c4）、18（84ba50d3）
- tags:
  - operation:滑动, slide
  - operation:重涂色, recolor
  - operation:擦除, erase
  - object:车道, lane
  - object:闸门线, gate_line
  - object:端盖标记, cap_marker
  - relation:穿透染色, pass_through_dye
  - relation:反弹掉头, bounce_reverse
  - condition:端盖色定初始方向, cap_color_initial_direction
  - condition:末道彩闸定终色, last_dye_gate_final_color

### docstring

```text
让每条车道里的精灵按端盖指示的方向出发，穿彩闸门染色、碰灰闸门掉头，最终停靠时呈现完整路径上最后一次染色。

输入结构
- 竖直灰墙把网格分成若干车道。
- 每条车道一端有一格端盖：蓝端盖表示该车道的精灵初始向下移动，红端
  盖表示初始向上移动。
- 每条车道内有一个单色精灵，以及若干横跨车道的一格厚闸门线；彩色闸
  门与灰色闸门混杂分布，精灵两侧都可能有闸门。

规则
- 精灵沿初始方向逐格移动。
- 穿过一道彩色闸门时，精灵整体改为该闸门颜色，该闸门碎裂消失。
- 碰到一道灰色闸门时，精灵掉头反向移动，该灰闸门同样碎裂消失。
- 精灵最终沿当前方向走到车道尽头、紧贴端盖停下。
- 从未被精灵经过的闸门原样保留。

关键洞察
- 闸门分两种角色：彩色是一次性的染缸、灰色是一次性的反弹镜。反弹会
  把精灵送向"身后"的闸门，因此最终颜色取决于完整路径上最后穿过的
  彩色闸门，而不是初始方向上最靠前或最靠后的那一道。
```

## 3. 隐形棋盘定色

- 参考题目题号：8（9473c6fb）、12（ba9d41b8）、15（27a77e38）
- tags:
  - operation:重涂色, recolor
  - object:孤立像素, isolated_pixel
  - object:锚点标记, anchor_marker
  - object:隐形棋盘, invisible_checkerboard
  - relation:坐标奇偶相位, coordinate_parity_phase
  - condition:与锚点同相染同色, same_phase_same_color

### docstring

```text
按一张从未画出的全局棋盘相位，把每个蓝像素染成与它同相位的那枚锚点的颜色。

输入结构
- 黑背景上散布许多蓝色孤立像素。
- 另有恰好一个红色锚点像素和一个绿色锚点像素，两枚锚点的行列坐标和
  的奇偶性相反。
- 蓝像素与两锚点的远近、分布均无规律。

规则
- 以行号加列号的奇偶性划分隐形棋盘相位。
- 与红锚点同相位的蓝像素重涂为红色；与绿锚点同相位的蓝像素重涂为绿
  色。
- 两枚锚点原样保留，背景不变。

关键洞察
- 染色依据是一张从未被画出的全局棋盘的相位，红绿锚点只是这张棋盘的
  两个示例格。示例中靠近红锚的像素常被染红，"按最近锚点染色"是诱
  饵——总有远处的反例与测试对打破距离假设，只有奇偶相位对所有像素
  成立。
```

## 4. 孤立色放逐

- 参考题目题号：7（dc46ea44）、9（c35c1b4c）、15（27a77e38）
- tags:
  - operation:平移, translate
  - operation:擦除, erase
  - object:分隔行, separator_row
  - object:图案区, pattern_region
  - object:结果区, result_region
  - relation:邻接拓扑, adjacency_topology
  - condition:唯一不触他色者被选中, only_untouching_color_selected
  - condition:包围盒中心对齐, bbox_center_aligned

### docstring

```text
找出上区中唯一从不与其他颜色相触的颜色，把它的像素整体放逐到下区中央。

输入结构
- 一条满宽分隔行把网格分成上下两区。
- 上区是多色图案，多种前景色的像素交错分布；下区为纯背景。
- 上区诸颜色中，恰有一种颜色的每一个像素都不与任何其他前景色四邻
  接（只挨背景或同色像素）；其余每种颜色都至少在某处与别的前景色相
  邻。

规则
- 找出这种与所有其他颜色都不接触的孤立色。
- 把孤立色的全部像素保持相对位置整体平移到下区，使其包围盒中心对齐
  下区的中心。
- 孤立色像素从上区清除，上区其余内容与分隔行原样保留。

关键洞察
- 挑选标准不是数量、大小或形状，而是邻接拓扑：唯一一个从不与别的颜
  色相触的颜色。示例中最多数颜色可能恰好就是它（诱饵），但测试对会
  打破"数最多色"的假设。
```

## 5. 容器倾倒

- 参考题目题号：12（ba9d41b8）、14（5b37cb25）、16（d631b094）
- tags:
  - operation:计数, counting
  - operation:擦除, erase
  - operation:画带, draw_band
  - object:空心矩形, hollow_rectangle
  - object:缺口喷口, gap_spout
  - object:内容物像素, content_pixel
  - relation:体积守恒, volume_conservation
  - condition:缺口宽定液带厚, gap_width_determines_thickness
  - condition:数量除厚度定长度, count_over_thickness_length

### docstring

```text
把每个容器内的液体像素从边框缺口倒出，形成厚度等于缺口宽度、长度等于数量除以厚度的液带。

输入结构
- 黑背景上有若干单色空心矩形容器。
- 每个容器边框上恰有一个宽一格或两格的缺口。
- 每个容器内部装着若干液体像素：每个容器一种颜色，各容器互异，数量
  不一且保证能被缺口宽度整除。

规则
- 每个容器把液体从缺口倒出：从缺口外侧第一格起，沿背离容器的方向画
  一条液体色直带。
- 液带厚度等于缺口宽度，长度等于该容器液体像素数除以厚度。
- 容器内部清空为背景，边框连同缺口原样保留。

关键洞察
- 倒出过程体积守恒：厚度由喷口宽度决定，长度由总量折算。"液带长度
  等于像素数"只在宽一格的缺口下成立，宽两格的缺口会打破这一表层假
  设；缺口既是计量口也是方向标。
```

## 6. 投影重建与图例叠序

- 参考题目题号：8（9473c6fb）、11（e9ac8c9e）、15（27a77e38）
- tags:
  - operation:填充, fill
  - operation:排序, sort
  - object:投影带, projection_strip
  - object:图例带, legend_strip
  - object:实心矩形, solid_rectangle
  - relation:一维投影定二维范围, projections_define_extent
  - condition:图例定覆盖次序, legend_determines_z_order

### docstring

```text
用顶行与左列的两条一维投影重建出各色实心矩形，并按底行图例的次序决定重叠覆盖。

输入结构
- 网格顶行和最左列是两条投影带：每种前景色在顶行占一段连续区间，在
  最左列也占一段连续区间，各恰一段。
- 底行从第一列起是图例带，按次序每种颜色各占一格。
- 其余内部区域为空背景。

规则
- 每种颜色对应一个实心矩形：行范围等于它在左列的区间，列范围等于它
  在顶行的区间。
- 按底行图例从左到右的顺序依次绘制这些矩形，后画者覆盖先画者。
- 输出同尺寸网格：三条带原样保留，内部画好互相覆盖后的矩形。

关键洞察
- 矩形从未被画出，画面上只有它们的两条一维投影；重叠处的取舍由图例
  次序决定，而不是面积、位置或颜色循环。把图例当调色板循环分配是诱
  饵，它无法解释覆盖结果。
```

## 7. 多米诺连锁

- 参考题目题号：6（9b4c17c4）、10（a61f2674）、18（84ba50d3）
- tags:
  - operation:重力倾倒, topple
  - operation:平移, translate
  - object:竖直线段, vertical_bar
  - object:推手标记, pusher_marker
  - object:地面行, ground_row
  - relation:高度即触及范围, height_equals_reach
  - relation:连锁反应, chain_reaction
  - condition:间距不超高度则传播, gap_within_height_propagates

### docstring

```text
红色推手向场内倒下，逐根撞倒够得着的竖条，链条在第一个够不着的间隙处中断。

输入结构
- 底行是灰色地面，地面上立着若干一格宽的蓝色竖条，高度与间隔不一。
- 位于一端的那根竖条是红色的推手。

规则
- 推手朝其余竖条的方向倒下：高度为 h 的竖条倒下后，占据紧贴地面那一
  行、从底座列的下一列起共 h 格的横线，底座原位清空。
- 若某根仍站立的竖条所在列与倒下条底座列的距离不超过 h，它被撞倒并
  沿同方向继续倒下，形成连锁。
- 够不着的竖条保持站立，链条就此中断，更远处的竖条全部不动。
- 倒下横线的重叠处按倒下先后，后倒的覆盖先倒的。

关键洞察
- 竖条的高度就是它的打击半径；传播与否取决于高度与间距的逐段比较，
  而不是"全部倒下"或"整体滑动"。链条何处中断，必须沿倒下顺序逐
  根推演。
```
