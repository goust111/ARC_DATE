## 1. 加速点列续延

- tags:
  - operation:外推, extrapolate
  - operation:重涂色, recolor
  - object:变距标记点列, accelerating_markers
  - object:对角线图例, diagonal_legend
  - relation:间距等差, arithmetic_gap
  - condition:边界内延续, continue_within_bounds
  - condition:图例定色环, legend_color_cycle
- 参考题目: 13, 20

### docstring

```text
沿既有标记点列按"间距等差递增"的规律外推新点直至越界，新点颜色按角落图例循环取色。

输入结构
- 背景为主导色。网格某角落有一段紧贴角的对角线单像素图例，给出一个颜色序列。
- 场内有一列共线标记点（至少三个），相邻间距构成等差数列（公差可为零）。
- 既有标记点的颜色恰好是图例序列从头开始的循环取色。

规则
- 按行主序确定点列方向，读出相邻间距序列及其公差。
- 从最后一点起，依次以"上一间距加公差"为新间距放置新点。
- 新点颜色继续图例的循环序。
- 新点将落到界外时停止；图例与原有点保持不变。

关键洞察
- 点的间距不必相等，真正的不变量是间距的公差；角落对角线不是待续的点列，而是颜色循环表。训练示例中含公差为零的一例，会诱导"等距外推"的错误假设。
```

## 2. 隐形标尺平铺

- tags:
  - operation:平铺, tiling
  - object:瓦片图案, tile_motif
  - object:标记像素, marker_pixel
  - relation:端点对定线段, endpoint_pair_segment
  - relation:颜色匹配, color_matching
  - condition:灰端裁剪, clip_at_grey
- 参考题目: 2, 10, 14

### docstring

```text
每对"彩色起点像素—灰色终点像素"定义一条看不见的标尺，把主色与起点同色的图案沿标尺重复铺设并在灰端裁断。

输入结构
- 黑色背景。若干互不相邻的矩形小图案，每个图案含一种主色（占多数）与少量点缀色。
- 场内散布孤立像素：彩色像素与灰色像素成对出现，同对两像素同行或同列。
- 每个彩色孤立像素的颜色与恰好一个图案的主色相同。

规则
- 为每个彩色孤立像素在同行（或同列）找到配对的灰色像素。
- 取主色相同的图案，第一份拷贝的靠起点一角与彩色像素对齐，沿指向灰色像素的方向首尾相接重复铺设；铺设条带以标尺线为其上边缘（水平标尺）或左边缘（竖直标尺）。
- 铺设覆盖两枚端点像素本身；越过灰色像素位置的部分裁去（末份可为不完整拷贝）。
- 原图案样本保持不动。

关键洞察
- 标尺条从未画出，只剩两端点：彩色端负责"选哪个图案、从哪开始"，灰色端负责"铺到哪、朝哪停"。
```

## 3. 双重身份掩码印章

- tags:
  - operation:印章覆盖, stamp
  - operation:计数, counting
  - operation:透明叠加, overlay
  - object:掩码, mask
  - object:源图案, source_pattern
  - relation:像素到块映射, pixel_block_mapping
  - relation:逐像素比较, per_pixel_comparison
  - condition:稀者选位密者为章, sparse_selects_dense_stamps
  - condition:共同前景挖洞, common_foreground_carved
- 参考题目: 7, 18, 8

### docstring

```text
两幅叠放掩码中，前景较稀的一幅既充当块级选位坐标，又作为镂空刻刀刻在印章上；印章内容是较密一幅去掉两幅共同前景后的残迹。

输入结构
- 输入为上下叠放的两幅等尺寸矩形掩码，各为黑底加恰一种前景色，两幅前景色不同。
- 两幅逐像素对齐后存在若干共同前景位置。

规则
- 统计前景像素数：少者为"选位掩码"，多者为"印章掩码"。
- 印章图案 = 印章掩码中是前景、且选位掩码同位置不是前景的那些像素（保留印章掩码的颜色）。
- 输出划分为与单幅掩码同尺寸的块阵；选位掩码的每个前景像素对应一个块位，块内整幅复制印章图案，其余块全黑。

关键洞察
- 稀的一幅被用了两次——一次升格为块坐标，一次原位充当刻刀在印章上挖洞；被印出的图案带着搭档形状的孔，孔的来历是解题的入口。示例间上下面板会互换稀密角色。
```

## 4. 距离定环序

- tags:
  - operation:同心层填充, concentric_fill
  - object:空心矩形框, hollow_rect_frame
  - object:标记像素, marker_pixel
  - relation:棋盘距离, chebyshev_distance
  - relation:就近归属, nearest_assignment
  - condition:距离即层号, distance_indexes_ring
- 参考题目: 20, 10

### docstring

```text
每个孤立色点到最近空心矩形框的棋盘距离决定它为该框内由外向内第几层同心环上色，无点对应的层留空。

输入结构
- 空背景上有一到两个一像素厚的空心矩形框。
- 框外散布孤立彩色标记点，互不相邻；同一框同一距离至多一个点。

规则
- 每个标记点归属棋盘距离最近的框。
- 设点到该框边框的棋盘距离为 k，则该点颜色涂满框内部由外向内第 k 层矩形环。
- 没有任何点对应的层保持背景色；框、点与外部背景不变。

关键洞察
- 点的排列顺序与方位都是幌子，唯一有效的信息是离框多远；点是环层的遥控器，距离即层号。有意跳过某些距离值，留空环以否定"按顺序读色"的假设。
```

## 5. 全场同步滑动

- tags:
  - operation:滑动, slide
  - object:矩形, rectangle
  - object:挡墙, wall_segment
  - relation:通道交叉, channel_crossing
  - relation:间隙对半分, gap_bisect
  - condition:同速同步, simultaneous_motion
  - condition:碰撞停止, collision_stop
- 参考题目: 16, 15, 14

### docstring

```text
所有贴边矩形同时以相同速度滑向对边，横竖通道彼此交叉，任何矩形在即将撞上灰墙、已停矩形或另一移动矩形时停下，先到者占位、后到者被拦。

输入结构
- 背景主导。每个彩色实心矩形恰好贴住一条外边界，滑向对边。
- 横向与纵向矩形的通道可以交叉；场内可有灰色短墙段。
- 输入保证不出现两矩形同刻进入同一格的歧义。

规则
- 所有矩形同时逐格移动，速度相同；即将与灰墙或任何其他矩形（无论已停或在动）重叠时停下，可贴住。
- 同通道相向的两矩形无阻挡时于间隙正中相遇：原间隙为偶则贴合，为奇则中间留一行（列）背景。
- 若一方先被墙或横穿者拦停，另一方继续前进走完剩余全部间隙。
- 通道交叉处谁先到谁通过，后到者被已穿过或停驻在交叉口的矩形拦停。
- 无任何阻挡的矩形滑到对边贴住为止。

关键洞察
- 这不是逐个移动到位的静态几何题，而是一场同刻起跑的运动学：交叉口的胜负由出发距离决定，"正中相遇"只是无干扰时的特例表象。
```

## 6. 旋转缩略图补全

- tags:
  - operation:补全, complete
  - operation:旋转, rotate
  - operation:缩放, scale
  - object:缩略图, minimap
  - object:色块网格, colored_block_grid
  - relation:坐标映射, coordinate_mapping
  - condition:已有块钉死姿态, blocks_pin_orientation
- 参考题目: 12, 3

### docstring

```text
角落缩略图需先经过某个旋转或镜像才与主区色块布局对齐，用已放置的色块推断唯一姿态后补齐缺失色块。

输入结构
- 背景主导。左上角一小片单像素彩点构成缩略图。
- 其余区域是规则点阵上的 NxN 实心色块，部分位置空缺。
- 已放置的色块与缩略图逐点直接对照并不吻合，但足以排除八种姿态中的七种。

规则
- 在缩略图的旋转与镜像（八种姿态）中，找出唯一使每个已放置色块的颜色与位置都被对应像素解释的姿态。
- 按该姿态与固定格距把缩略图逐像素映射到主区块位。
- 在缩略图有色而主区空缺的位置补上对应颜色的 NxN 色块；缩略图区域原样保留。

关键洞察
- 缩略图不是所见即所得的地图，而是被转过向的底片；已放置的块不是装饰，是钉死唯一姿态的锚点。
```

## 7. 边距投影重建

- tags:
  - operation:填充, fill
  - object:边缘线段, edge_bar
  - object:矩形, rectangle
  - relation:行列交叉, row_col_cross
  - relation:颜色匹配, color_matching
  - condition:投影直积还原本体, projection_product_reconstruction
  - condition:外层边距后画覆盖, outer_margin_paints_last
- 参考题目: 5, 4, 14

### docstring

```text
顶部与左侧边距里的彩色投影条两两同色配对，各自还原为画布上的实心矩形，重叠处由更靠外的边距层对应的矩形覆盖。

输入结构
- 网格前 k 行为顶边距、前 k 列为左边距，其余为空画布（边距交角为空）。
- 顶边距每行恰有一条水平色条，左边距每列恰有一条竖直色条。
- 颜色两侧一一配对，且同色条所在的边距行号与列号相同（同层）。

规则
- 对每种颜色：顶条给出列跨度，左条给出行跨度，两跨度的直积为该色实心矩形，画入画布。
- 矩形重叠时按边距层序遮挡：所在边距层越靠外（序号越小）越后画、越在上层。
- 边距原样保留。

关键洞察
- 矩形从未被画出，画布上只有它在两条边上的影子；同色影子相乘还原本体，遮挡顺序也藏在边距的层序里。
```

## 8. 落点反推导流轨迹

- tags:
  - operation:射线延伸, ray_extend
  - operation:连线, draw_line
  - object:落点像素, landing_pixel
  - object:灰色斜坡, grey_ramp
  - relation:同列传播, same_column_propagation
  - condition:因果反演, causal_inversion
  - condition:遇坡横移, deflect_on_ramp
- 参考题目: 19, 1, 14

### docstring

```text
底行的每个彩色落点，反推出顶行唯一能经灰色斜坡导流后落到它的源列，并把整条轨迹涂成落点的颜色。

输入结构
- 黑背景。底行散布若干彩色落点像素；顶行为空。
- 场内有若干一像素宽的灰色对角线段（斜坡，左下或右下走向），彼此分离。
- 导流物理：一条从顶行某列出发的轨迹逐格下落；若正下方是坡格，则向该坡的下坡水平方向横移一格，如此贴坡上缘阶梯滑行，越过坡端恢复下落，直至底行。
- 输入保证每个落点恰好只有一个顶行源列的轨迹落在它上面，且各轨迹互不交叉。

规则
- 对每个底行落点，找出唯一使导流轨迹终点恰为该落点的顶行源列。
- 把该轨迹经过的所有格（含源与落点）涂成落点颜色；灰坡保持灰色。

关键洞察
- 给出的是果不是因——直接把落点竖直上延是诱饵（仅对上方无坡的落点成立）；必须掌握正向下落物理并倒着运行它，横移段只在"旁邻格正下方是指向自己的坡"处发生。
```
