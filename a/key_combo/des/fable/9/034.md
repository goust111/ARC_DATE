## 1. 尾迹台球

- 参考题目：1 (705a3229)、2 (72a961c9)、5 (99caaf76)
- tags:
  - operation:射线延伸, ray_extend
  - operation:反射, mirror_bounce
  - object:头部像素, head_pixel
  - object:尾迹条, tail_bar
  - relation:尾迹定向, tail_sets_direction
  - condition:尾长编码触壁次数, tail_length_encodes_bounces

### docstring

```text
让每个带尾迹的彩色头像素沿对角线发射光线，在网格边缘按台球规则反弹，尾迹长度决定它在第几次触壁时停下。

输入结构：
- 黑色背景网格上散布若干发射器：每个发射器由一个彩色头像素和一条沿对角方向
  与之相连的灰色尾迹条组成，尾迹长度 1 至 4 不等。
- 各发射器互不接触，各条光线路径经构造互不交叉、互不干扰。

规则：
- 每个发射器的光线从头像素出发，沿"尾迹指向头"的对角方向逐格前进，
  途经的背景格涂上头像素的颜色。
- 光线到达网格边缘时按镜面反射规则改变方向继续前进：碰上下边翻转竖直分量，
  碰左右边翻转水平分量。
- 尾迹条含 L 个灰格，则光线在第 L 次接触网格边缘的那一格停止；
  头像素与灰色尾迹在输出中保持不变。

关键洞察：
- 灰色尾迹不是装饰，它同时给出发射方向（几何朝向）与寿命（长度等于允许的
  触壁次数）；头像素的颜色只用于区分各条折线，真正的差异全部编码在尾迹里。
```

## 2. 图例蓝图

- 参考题目：18 (58490d8a)、20 (8eb1be9a)、14 (ac0a08a4)
- tags:
  - operation:复制, copy
  - operation:按图布点, layout_from_map
  - object:图例框, legend_box
  - object:键色点行, keyed_dot_row
  - object:精灵体, sprite
  - relation:点位即位移, dot_offset_encodes_position
  - condition:精灵宽度为位移单位, sprite_width_as_unit

### docstring

```text
把图例行里的每个点读成一条布点指令，以精灵自身宽度为单位，在精灵所在行按点的偏移量摆放它的副本。

输入结构：
- 画面一角有一个灰色边框的图例框：框内最左列是若干互异的键色像素，
  每个键色所在行的右侧散布同色的点，点与点之间的间距不规则。
- 框外每种键色恰有一个由该色构成的小精灵，其所在行留有足够空位。

规则：
- 对每个键色，读出其图例行中各点相对键像素的列偏移 d1、d2、…（单位为格）。
- 以该键色精灵的包围盒宽度 w 为步长单位，在精灵所在的行放置副本：
  第 i 个副本的包围盒左边相对原精灵左边向右平移 di×w 列。
- 原精灵与图例框整体在输出中保持不变。

关键洞察：
- 图例行不是计数表而是缩尺地图：点的个数只是副本数量的表象，
  点相对键像素的不规则间距才是真正的信息，它按精灵自身宽度放大后
  给出每个副本的确切落点。
```

## 3. 越框条纹与影子

- 参考题目：11 (6a980be1)、19 (b9e38dc0)、10 (79fb03f4)
- tags:
  - operation:平铺, tile
  - operation:射线延伸, ray_extend
  - operation:擦除, erase
  - object:矩形边框, rectangular_frame
  - object:周期条纹, periodic_stripe
  - object:障碍像素, obstacle_pixel
  - relation:周期掩码, periodic_mask
  - condition:障碍向背框侧投影阴影, obstacle_shadow_away_from_frame

### docstring

```text
把边框内的周期条纹推广成贯穿全画布的整行条纹，同时让散布的障碍像素在背离边框的一侧挡掉条纹。

输入结构：
- 画布上偏于一侧有一个单格厚的矩形边框，框内若干整行条纹按固定行周期排布，
  条纹色与框色不同。
- 框外散布若干单像素障碍，颜色与前述均不同；有的障碍落在条纹行的延长线上，
  有的不在。

规则：
- 从框内条纹读出行周期与相位，把画布上满足该周期的所有整行涂成边框的颜色，
  向左右两侧一直延伸到网格边缘。
- 位于条纹行上的障碍保持原色，并且自障碍起沿背离边框中心的方向，
  该行其余格保持背景色（阴影）。
- 边框本体与框内原条纹色全部抹去，不在条纹行上的障碍原样保留。

关键洞察：
- 边框不是要保护的容器，而是颜料来源与相位样板；框内条纹只是全局周期规律的
  局部采样。障碍只在传播方向的下游起作用，因此画面呈现"朝框一侧完好、
  背框一侧带影"的整行条纹。
```

## 4. 残迹滑移饰带

- 参考题目：17 (48131b3c)、20 (8eb1be9a)、16 (de493100)
- tags:
  - operation:平铺, tile
  - operation:颜色反转, color_swap
  - operation:镜像, mirror
  - operation:补全, reconstruct
  - object:行带, row_band
  - object:残迹像素, residue_pixel
  - relation:滑移反演, glide_inversion
  - condition:残迹反推平移量, residue_determines_shift

### docstring

```text
由一条完整行带和远处一小撮残迹像素反推出整条滑移反演饰带，并把它铺满全画布。

输入结构：
- 背景画布上有一条完整的水平行带，带内图案恰由两种前景色构成。
- 在画布竖直方向的另一处，留有寥寥数个前景像素，它们是该饰带某个远端副本的
  残迹，既不完整也不与原带同相。

规则：
- 饰带由第 0 号副本（原带）沿竖直方向逐份延展而成：第 k 号副本相对第 k-1 号
  副本上下翻转、两种前景色互换，并整体水平平移固定偏移 s 列。
- 偏移 s 不在画面中直接给出，必须让某号副本恰好与残迹像素逐格吻合才能解出。
- 解出后把所有副本（含翻转、换色、平移的累计效果）向上下铺满画布，
  超出边界的部分裁掉，残迹随之被补全。

关键洞察：
- 残迹是从未完整画出的副本留下的证据；解题需要同时锁定三件事——
  相邻副本的几何翻转、双色对合、水平滑移量——任何一件单独都无法与残迹吻合，
  必须联立求解才能确定唯一答案。
```

## 5. 柱状图折线

- 参考题目：3 (31f7f899)、12 (8b28cd80)、5 (99caaf76)
- tags:
  - operation:序列读取, sequence_reading
  - operation:折线绘制, polyline_drawing
  - object:柱状条, vertical_bar
  - object:基线, baseline
  - object:种子像素, seed_pixel
  - relation:柱高即步长, bar_height_encodes_step
  - condition:每段后顺时针转向, clockwise_turn_per_segment

### docstring

```text
把柱状图从左到右的柱高读成一串步长指令，让种子像素按"走一段、顺时针转 90 度"的方式画出折线。

输入结构：
- 画布底部有一条整宽基线，其上立着若干互不相邻的同色柱，高度各异。
- 画布上方空旷处有一个彩色种子像素，紧贴它有一个灰色尾格；
  初始朝向为从尾格指向种子的方向。

规则：
- 将柱子按从左到右的顺序读出高度 h1、h2、…、hk（不含基线所在行）。
- 从种子出发沿初始朝向前进 h1 格并逐格涂上种子色，然后顺时针转 90 度，
  前进 h2 格，如此往复，用完全部 k 个高度后停止。
- 基线、柱子、种子与灰色尾格全部原样保留，折线经构造不与它们相撞。

关键洞察：
- 柱状图不是要被搬动、排序或涂改的对象，而是一条只读的指令带；
  画面上从未画出的折线由"图表数据 + 起点姿态"两部分共同决定，
  柱子的数量决定折线的段数，柱子的高度决定每段的长度。
```

## 6. 密度定序叠印

- 参考题目：13 (aab50785)、3 (31f7f899)、18 (58490d8a)
- tags:
  - operation:裁剪, crop
  - operation:叠印, overlay
  - operation:计数, counting
  - object:标记块, marker_block
  - object:提取区域, extracted_region
  - relation:行对齐配对, row_aligned_pair
  - condition:前景密度决定覆盖顺序, density_determines_paint_order

### docstring

```text
把每对行对齐的 2x2 标记块之间的等大区域取出，按前景像素从少到多的顺序把它们叠印成一块。

输入结构：
- 网格含背景、少量散点噪声，以及唯一一种只以 2x2 块出现的标记色；
  标记块两两成对，同一对共享同样的两行行距。
- 每对标记块之间的矩形区域等宽等高，各区域内的前景像素个数互不相同。

规则：
- 取出每对标记块之间的矩形（不含标记块本身）。
- 输出一块与单个区域同尺寸的画布：按区域内前景像素个数从少到多的顺序
  依次叠印，后印区域的非背景像素覆盖先印区域的像素。
- 标记块、噪声与区域外的一切都不进入输出。

关键洞察：
- 各区域不是按空间位置拼接堆叠，而是压成同一块画布；覆盖优先级由
  内容密度这一内在属性给出。靠上的区域并不天然靠前，第一眼的
  "从上往下"读法会在部分示例上失效。
```

## 7. 凝视链条

- 参考题目：19 (b9e38dc0)、1 (705a3229)、8 (f45f5ca7)
- tags:
  - operation:泛洪填充, flood_fill
  - operation:射线延伸, ray_extend
  - operation:擦除, erase
  - object:半封闭墙, partial_enclosure
  - object:小精灵, small_sprite
  - relation:开口视线, opening_sightline
  - relation:链式传色, chained_color_relay
  - condition:链尾精灵供色并被消耗, chain_end_supplies_color_and_consumed

### docstring

```text
每个半封闭围墙从开口向外看，视线命中实心精灵则取其色，命中别的围墙则继承那个围墙最终的填充色，颜色沿凝视链条逆流传播。

输入结构：
- 黑色背景上有若干同色的 U 形围墙，开口朝向各不相同，内部为空。
- 画面上散布若干实心小精灵，颜色互异；有的围墙开口正对一个精灵，
  有的围墙开口正对另一个围墙的外壁。
- 凝视关系经构造不成环，每条链的尽头都是一个精灵。

规则：
- 对每个围墙，从开口中央沿开口朝向发出一条直线视线，取视线遇到的
  第一个非背景物体。
- 若命中的是精灵：围墙内部空腔填满该精灵的颜色，且该精灵在输出中整体抹去。
- 若命中的是另一个围墙的墙体：本围墙内部填充那个围墙最终确定的填充色
  （需先沿链条解析到尽头的精灵）。
- 未被任何视线命中的精灵原样保留，所有围墙墙体不变。

关键洞察：
- 一次命中的对象未必是颜色的源头：颜色沿凝视链条从链尾精灵逐级逆流传回。
  就近配对、同色暗示都是诱饵，只有把"看见"理解成可传递的关系
  才能解释全部示例。
```
