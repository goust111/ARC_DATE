## 新题 1:从交叉点读出整摞的次序

**来源原语**:矩形框(1a6449f1)、印章覆盖/遮挡(db118e2a)、压缩/摘要输出(19bb5feb)、顺序排列(8e5a5113)

**难度档案**
- 第一眼的故事:"输出色条是按矩形大小(或从左到右位置)排的颜色列表"——首例的叠放序恰与尺寸序、位置序一致,喂饱这两个故事;后续示例全部解绑。
- 最浅充分策略:不存在捷径——色条是全序的函数,而全序的全部证据是每对框交叉处的两三个像素,必须逐对读出"谁在上",再用传递性拼成整条链。局部翻证据写不出序列。
- 组装工作:稀疏两两不等式 → 传递闭包 → 全序 → 序列化;另有表征跳变(场景→序列)加长发现距离。

```text
空心矩形互相压叠,只有边框交叉的像素泄露谁在上;把整摞的叠放次序从上到下读成一根色条输出。

输入结构
- 黑(0)背景网格上有 3~5 个单色空心矩形(边框一像素厚,内部黑色,
  颜色互不相同),两两之间存在部分重叠;每处边框交叉的像素显示
  上层矩形的颜色。
- 生成约束:每对重叠矩形在两处交叉像素上胜负一致(无互扣);
  全体矩形的叠放全序可由可见的两两胜负经传递性唯一确定;
  第一个训练示例中叠放序恰好等于矩形从小到大的尺寸序、
  也等于从左到右的位置序,后续示例中两者全部与叠放序矛盾;
  交叉像素不被第三个矩形遮挡。

规则
- 在每对重叠矩形的交叉像素处读出该对的上下关系。
- 用传递性把所有两两关系拼成唯一的全序。
- 输出一个 n×1 的色条(n 为矩形数):最上格是最顶层矩形的颜色,
  向下依次到最底层。

关键洞察
- 每个矩形都只在几个像素上留下了证词,没有任何一处能看到整摞
  的样子;答案是把散落的"甲压乙"逐条收集、连成一条链之后
  才存在的东西——序列的每一格都花掉一次推理。
```

## 新题 2:旋转换色的双生互补

**来源原语**:旋转(8e5a5113)、颜色替换映射(e9b4f6fc)、修补(8886d717)、补全(4cd1b7b2)

**难度档案**
- 第一眼的故事:"右边是左边的复制,把洞互相抄过来"——直接抄会发现对不上;退一步猜"是旋转的复制"(首例换色映射恰为恒等,该故事在首例完全成立);后续示例中颜色也被换过,纯旋转修补填出错色。
- 最浅充分策略:必须联立求解两个纠缠的隐变量——试一个旋转角,才能建立格点对应;有了对应,才能从双方都完好的格子提取颜色双射;双射自洽则旋转正确,否则换角重来。没有绕开联立的路。
- 组装工作:4 个旋转候选 × 颜色双射一致性检验的假设搜索;两块面板的洞互相用"旋转+换色"的正逆两个方向修补。

```text
左右两块残缺面板由一次旋转加一套颜色替换相联;推出这两层隐藏关系,让两块互相补全对方的洞。

输入结构
- 网格被一条灰(5)色整列分隔线分为左右两块同尺寸正方形面板
  (各约 8×8)。右面板等于左面板旋转 90°、180° 或 270° 后,
  再按一个颜色双射(3~4 种颜色之间的换色表)重涂的结果。
- 两块面板各有 4~7 个黑(0)洞,位置经对应关系换算后互不重合
  (每个格位至少一侧完好)。
- 生成约束:忽略颜色后的占用掩码无任何旋转对称,保证旋转角
  唯一可辨;第一个训练示例的颜色双射为恒等(纯旋转可完全解释),
  后续示例的双射非平凡;旋转角与双射在不同示例中不同,
  必须逐例重新推断。

规则
- 找出使两面板完好部分逐格自洽的那个旋转角与颜色双射。
- 右面板的洞,用左面板对应格的颜色经双射填入;
  左面板的洞,用右面板对应格的颜色经双射的逆填入。
- 输出为两块面板均补全后的完整网格,分隔线不变。

关键洞察
- 两个隐变量互为钥匙:不知道转了多少度就对不上格子,对不上
  格子就提不出换色表,而换色表自洽与否又是检验旋转角的唯一
  标准——必须把两层假设作为整体来试,单独猜哪一层都无从验证。
```

## 新题 3:先分帮,再拼图

**来源原语**:阵列排布/瓦片(ccd554ac)、异常值选择(c3202e5a)、补全(4cd1b7b2)、计数(6e02f1e3)

**难度档案**
- 第一眼的故事:"输出是所有块的公共图案,逐格投多数票即可"——这是本题埋得最深的陷阱:全局逐格投票会产出一张混血图,在若干格上是错的,而且错得很自信。次一级的故事"取最干净(洞最少)的那块"也错——最干净的恰是少数派。
- 最浅充分策略:必须先聚类再合并,没有一步到位的路——两块是否同帮,只能比较双方都完好的格子;帮派分清后,多数帮内部再互补洞。跳过聚类的任何全局统计都会被少数帮污染。
- 组装工作:带洞的两两比对(缺失格不构成证据)→ 聚类 → 帮内多数完好格合并;两个阶段用的是同一批像素的不同读法。

```text
几块残缺的图案分属两个内部一致的帮派;先用互相完好的格子分清帮派,再用多数帮的成员互补出该帮的完整图案。

输入结构
- 黑(0)背景网格上排布 6~7 个同尺寸(约 5×5)图案块,分属两种
  母版:多数帮 4~5 块,少数帮 2~3 块;两种母版使用同一批颜色、
  结构相似(约七成格子相同),肉眼扫一眼分不出帮派。
- 每块有 2~4 个黑(0)洞,各块洞位不同。
- 生成约束:任意跨帮两块在双方都完好的格子上至少有 2 处不同,
  同帮两块在双方都完好的格子上完全一致(聚类可判定);多数帮
  每个格位至少有一名成员完好(可拼出完整母版);存在若干格位,
  多数帮成员在此多数有洞,使全局逐格投票在这些格位得出少数帮
  的颜色(投票陷阱可观测);少数帮成员的洞更少("最干净"诱饵)。

规则
- 两两比较各块在双方完好格上的内容,一致者同帮,分出两个帮派。
- 取成员数多的帮,把其成员逐格合并:每格取该帮任一完好成员的
  颜色,拼出完整母版。
- 输出该母版,尺寸等于单块尺寸。

关键洞察
- 多数决没有错,但投票权要先审资格:少数帮不是噪声,是另一个
  自洽的事实,把它们混进票箱,票数最高的答案就是一张两个母版
  的混血脸——先问"你是谁的副本",再问"这一格是什么"。
```

## 新题 4:套层切割

**来源原语**:标记对齐指定半区/保留标记半区(fbf15a0b)、裁剪(1a6449f1)、标记像素(8886d717)

**难度档案**
- 第一眼的故事:参考先验"一对标记选一半"——但场上有六枚同色标记,成三对;并行地取任何一对切一刀都得不到答案,输出比"一半"小得多。
- 最浅充分策略:按序执行三次有作用域的切割,且顺序不是约定而是被几何逼出来的——任一时刻,只有一对标记完整落在当前区域的某一半内(其余对都跨骑在当前中线上,无法解读);切一刀、收缩、原先跨线的对才变得可解读。想乱序执行,第一步就找不到第二个合法的对。
- 组装工作:每一步的解读依赖上一步的结果(作用域收缩),是一条真正的依赖链;标记同色,配对与次序全部要从几何推出,没有颜色提示。

```text
六枚同色标记成三对,每次用唯一"不跨当前中线"的一对选出半区并收缩,三层切割后输出最后剩下的区域。

输入结构
- 黑(0)背景网格(约 16×16)上散布六枚青(8)色单像素标记,
  两两同行或同列构成三对;另有若干小的彩色图案散布各处。
- 生成约束:任一时刻(初始网格及每次收缩后的区域),恰有一对
  标记同行或同列且完整位于当前区域沿该方向的同一半内,
  其余对均跨骑当前中线;每次切割的半分维度为偶数;
  三次切割后的最终区域内恰好包含一个彩色图案、不含标记。

规则
- 在当前区域内找到唯一不跨中线的对齐标记对,保留含它们的那
  一半,擦除这对标记,其余半区连同其中的标记与图案一并舍弃。
- 以收缩后的区域为新的当前区域,重复上述操作,直到没有标记。
- 输出最后剩下的区域(其中的彩色图案原样保留)。

关键洞察
- 三对标记摆在同一张图里,却不属于同一个时刻:每一对只有在
  轮到它的作用域里才有意义——切割的顺序没有写在任何地方,
  是"谁此刻不跨线"这个几何事实逼出来的;把六枚点读成一个
  按步展开的程序,才算读懂了这张图。
```

## 新题 5:朝向场补瓦

**来源原语**:平铺/瓦片(ccd554ac)、旋转(8e5a5113)、补全(4cd1b7b2)、等距偏移(05269061)

**难度档案**
- 第一眼的故事:"所有瓦片相同,抄一块补上"——立刻死于相邻瓦片朝向不同;第二个故事"抄同行/同列的邻居"——首例的朝向场恰好逐列恒定,该故事完全成立;后续示例朝向沿对角线推进,抄邻居全错。
- 最浅充分策略:朝向本身构成一张需要归纳的"元图案"——必须先把每块可见瓦片的旋转角标出来,在角度层面上找出场的规律(逐行推进、逐列恒定、沿对角推进……),再把空位的角度从场中推出、旋转母版填入。抄任何邻居都不充分。
- 组装工作:旋转角的逐块辨认(人眼对旋转匹配没有免费能力)+ 在"角度网格"上做第二层模式归纳;两层图案,看见的是第一层,规则在第二层。

```text
瓦片阵列里每块都是同一母版的某个旋转,朝向沿网格构成一个有规律的场;先归纳朝向场,再按场给空位补上正确朝向的瓦片。

输入结构
- 网格为 4×4 的瓦片阵列(每块 3×3),所有瓦片都是同一个多色
  母版经 0°、90°、180° 或 270° 旋转的结果;母版无任何旋转对称。
- 各瓦片的旋转档位由一个关于行列坐标的简单场决定(如逐列恒定、
  逐行顺时针推进一档、沿对角线推进一档等),不同示例的场不同。
- 2~3 个瓦片位被整块涂黑(空位)。
- 生成约束:可见瓦片足以唯一确定该例的朝向场(空位的档位被
  多个方向的可见瓦片交叉钉死);第一个训练示例的场为逐列恒定
  ("抄同列邻居"在该例完全成立),后续示例的场使一切"抄邻居"
  策略至少错一块;空位不相邻。

规则
- 辨认每块可见瓦片相对母版的旋转档位。
- 在瓦片坐标系上归纳档位随行列变化的规律(朝向场)。
- 按场推出每个空位应有的档位,把母版旋转到该档位填入空位。
- 其余瓦片不变,输出尺寸与输入相同。

关键洞察
- 画面有两层:像素层的图案人人可见,朝向层的图案要先把每块
  瓦片"读成一个角度"才浮现——空位的答案不在任何邻居身上,
  在那张由角度构成的第二层网格的规律里。
```

## 新题 6:稀疏条纹的周期破译

**来源原语**:同余类/等距偏移(05269061)、循环填充(05269061)、补全(4cd1b7b2)、忽略干扰项(c3202e5a)

**难度档案**
- 第一眼的故事:"把可见的一段花样往两边抄"——可见列稀疏且不成整段,直接抄没有素材;"对称补全""均匀插值"也都对不上。正确故事是:条纹是周期的,但周期没有给,要自己破译。
- 最浅充分策略:解一个小同余系统——每对同色可见列的间距都是周期的倍数,跨颜色的多条约束联立才能压出唯一周期;生成刻意安排一个"几乎正确"的小周期(与绝大多数证据相容,仅被一对远距同色列否决),不做完全验证就会掉进去。
- 组装工作:间距收集 → 公约数筛选 → 用全部证据验证候选周期 → 定相位 → 循环填充;这是"证据找齐后组装才开始"的最小样板。

```text
竖条纹按未知周期循环,大部分列被抹黑;从幸存彩列的间距里破译出唯一自洽的周期与相位,恢复整幅条纹。

输入结构
- 网格(约 4×27)原本是周期为 p(5~7)的竖条纹:列色按一个
  长度 p 的颜色序列无限循环;现在大部分列被涂黑,仅存 7~9 根
  彩色列,位置零散。
- 生成约束:周期 p 的每个同余类至少有一根幸存列(相位与全部
  序列颜色可恢复);存在一个更小的假周期 p′,与除一对之外的
  所有同色列间距相容,仅被一对相距最远的同色列否决(不完全
  验证必中招);幸存列不含任何连续 p 列的完整片段(无从直接
  抄样)。

规则
- 收集每对同色幸存列的间距,周期必须整除所有这些间距。
- 在满足全部间距约束的周期中取最小者,以任一幸存列锚定相位。
- 按周期与相位推出每一列的颜色,把所有黑列恢复为对应颜色。
- 输出尺寸与输入相同。

关键洞察
- 没有一根条纹是完整的,答案藏在"间距的公共约数"这个谁也
  没画出来的量里;差一点的周期能骗过几乎所有证据——最远的
  那对同色列,是专为不肯验完全部约束的人准备的。
```

## 自检记录

- **难度检验方式(本轮方法本身)**:每题按"第一眼故事 → 最浅充分策略 → 组装工作"三行档案审过,写在各题头部;没有一题的最浅充分策略是局部查表、感知白送或"找到证据即结束"。
- **组装类型互异**:传递链拼全序(1)、双隐变量联立(2)、聚类后合并(3)、作用域依赖链(4)、二层模式归纳(5)、同余系统求解(6)——六种组装骨架不重复。
- **无不可学习约定**:1 的色条方向、4 的切割顺序均非约定——前者由示例对比钉死,后者由"不跨线才可解读"的几何事实逼出;2、5 的隐变量逐例重推,无跨例背表。
- **归纳唯一性**:1 全序由传递闭包唯一;2 占用掩码无旋转对称保旋转唯一、格位互补保可修;3 同帮零分歧/跨帮双分歧保聚类唯一,多数帮逐格位有完好成员;4 每步恰一对可解读;5 空位档位被交叉钉死;6 同余类全覆盖且真周期唯一过全验。
