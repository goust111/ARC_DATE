## 新题 1:重叠灰区的隐序判决

**来源原语**:实心矩形面板(19bb5feb)、重涂色/颜色替换映射(e9b4f6fc)、忽略干扰项(1a6449f1)

**创新轴与层级**:本体轴·隐含全局关系(隐藏图层优先序)+ 句法轴·循环依赖(必须先跨示例归纳全局约定,才能判决任何局部冲突)。L3。

```text
把每个灰色重叠区判给隐藏优先序更高的那个矩形,重涂为胜者的颜色。

输入结构
- 黑(0)背景网格上散布若干实心单色矩形,部分矩形两两重叠;
  任何被两个矩形同时覆盖的格子在输入中一律画成灰(5)色,
  于是每个矩形只露出自己的非重叠部分。
- 另有不与任何矩形重叠的完整矩形作干扰项。
- 生成约束:每个灰色区恰好属于两个矩形(无三重重叠);每个矩形的
  可见彩色部分加上相邻灰区能唯一还原出完整矩形范围;灰(5)不用作
  矩形颜色;全部训练示例的判决结果所蕴含的颜色胜负关系无矛盾,
  且直接或经传递覆盖测试输入中出现的每一对冲突颜色。

规则
- 为每个灰色区还原出共享它的两个矩形及各自颜色。
- 存在一个跨所有示例一致的全局颜色优先序;把每个灰色格重涂为
  两个所有者中优先序更高(在上层)的那种颜色。
- 不重叠的矩形与背景保持不变,输出尺寸与输入相同。

关键洞察
- 单看任何一个示例,灰区判给谁毫无依据——胜负由画面上不存在的
  全局图层优先序决定;必须跨训练示例收集"谁压住谁"的证据,
  拼出总排序(有的颜色对要靠传递性推出),再回来判决测试中的冲突。
```

## 新题 2:对角像素的虚拟矩形与奇偶染色

**来源原语**:像素对/同色配对(494ef9d7)、边框包围内容/内部区域(1a6449f1)、奇偶条件(d22278a0)、标记像素擦除(fbf15a0b)

**创新轴与层级**:本体轴·隐式对象(矩形从未画出,只给对角生成元)+ 句法轴·门控(包含层数的奇偶决定染色还是擦除)。L3。

```text
同色像素对张成看不见的矩形,灰点按被这些矩形包含层数的奇偶决定变黄或消失。

输入结构
- 黑背景。若干种非灰非黄的颜色各恰好出现两个像素,构成同色对;
  每对的两个像素行不同且列不同,是一个虚拟矩形的一对对角顶点。
- 另散布若干灰(5)色单像素点。
- 生成约束:各虚拟矩形的边界互不重合;灰点不落在任何虚拟矩形的
  边界行列上(要么严格在内,要么严格在外);虚拟矩形可任意嵌套或
  交叠;示例中既有被奇数层包含的灰点,也有被偶数层(含零层)
  包含的灰点,且存在嵌套至少两层的区域以钉死"数层数"而非
  "是否在某矩形内"。

规则
- 把每种颜色的两个像素配成对,张成以它们为对角顶点的虚拟矩形。
- 对每个灰点,数它严格落在多少个虚拟矩形内部。
- 层数为奇数的灰点重涂为黄(4);层数为偶数(含零)的灰点擦为黑(0)。
- 作为顶点的彩色像素原样保留,输出尺寸与输入相同。

关键洞察
- 画面上一个矩形都没有:每对同色像素只是生成元,矩形要在感知阶段
  自行张成;判决量又不是单个包含关系,而是嵌套交叠叠加出来的
  覆盖层数的奇偶——两步都绕不开。
```

## 新题 3:拉丁方污损的双向指认与复原

**来源原语**:拉丁方约束/色表(4cd1b7b2)、修补(8886d717)、异常值选择/忽略干扰项(c3202e5a)

**创新轴与层级**:扩展轴 7·因果反演(输入是"完好拉丁方被涂改后"的结果,输出是涂改前的原状)+ 句法轴·发散汇合(行证据与列证据交叉才能定位)。L3。

```text
找出拉丁方中被涂改过的格子并恢复原色。

输入结构
- N×N(N=4~6)网格原本是完整拉丁方:N 种颜色每行每列各出现一次,
  没有空格。
- 有 1~3 个格子被"涂改":原色被覆盖成调色板内的另一种颜色,
  于是所在行与所在列各多出一对重复色、各缺失一种颜色。
- 生成约束:各污损格两两不同行不同列,且使用互不相同的覆盖色;
  保证除污损格外没有任何格子同时处于某行重复对和某列重复对中
  (被单方向牵连的合法格是必须排除的干扰);每个污损格所在行
  与所在列缺失的是同一种颜色。

规则
- 扫描每行每列,标出所有出现两次的颜色所涉及的格子。
- 只有同时被"行重复"与"列重复"双向指认的格子才是污损格;
  仅被单方向指认的是无辜格,保持不变。
- 把每个污损格恢复为其所在行与所在列共同缺失的那种唯一颜色。
- 输出为复原后的完整拉丁方,尺寸不变。

关键洞察
- 与"补空格"不同,破坏是不可见的:每个格子都有颜色,单看都合法。
  必须先建立涂改的正向模型——一次涂改会在行、列两个方向同时留下
  重复与缺失的证据——再用双向交叉指认把肇事格从被它牵连的
  无辜格中分离出来,倒推出原色。
```

## 新题 4:火种接力

**来源原语**:边缘标记/从边缘推进(f9a67cb5)、开口朝向/从开口发射(aba27056)、射线延伸(8886d717)、重涂色(e9b4f6fc)

**创新轴与层级**:扩展轴 6·过程动力学(同一条"命中—再发射"规则自我串联,步数由数据决定)。L2/L3。

```text
边缘火种点燃第一个方块,每个被点燃的方块再从自己的喷嘴朝喷嘴方向射出火线,连锁到火线飞出网格为止。

输入结构
- 黑背景网格,边界上有一个红(2)色单像素火种。
- 内部散布若干"喷嘴方块":3×3 实心单色方块,在某一条边的中点
  向外凸出一个同色像素(喷嘴),凸出方向即该方块的喷射方向;
  方块颜色互不相同,不使用红(2)和黄(4)。
- 生成约束:火种沿垂直于所在边的方向射入;每条火线要么命中某个
  方块的像素、要么直接出界,各段火线轨迹互不重叠;连锁不会重复
  访问同一方块;至少留一个从未被点燃的方块作干扰项。

规则
- 火种向网格内部直线推进,沿途黑格画成红色,直到抵达某个方块
  跟前(火线画到方块前一格为止)。
- 被命中的方块整体重涂为黄(4)(喷嘴一并变黄),并从喷嘴前方
  第一格起,沿喷嘴朝向射出新的红色火线。
- 新火线同样直行:命中下一个方块则重复上一步;出界则连锁结束。
- 从未被点燃的方块与其余背景保持不变,输出尺寸与输入相同。

关键洞察
- 没有一条能一眼读出的全局路径:第 k 段火线的方向藏在第 k-1 段
  命中的那个方块的喷嘴上——输出是同一条局部规则迭代到出界为止
  的轨迹,连锁多长完全由数据决定。
```

## 新题 5:三块合缝

**来源原语**:二值掩码(c803e39c)、平移(8ee62060)、裁剪(fbf15a0b)、内部朝向不变(8ee62060)

**创新轴与层级**:扩展轴 8·目标态/变分(规则是验收标准"拼成实心矩形",不给任何构造步骤)。L2/L3。

```text
把三个残缺色块平移拼合成一个无缝无叠的实心矩形并输出它。

输入结构
- 黑背景网格上散布三个互不接触的单色碎块,颜色互不相同,
  各为一个 4 连通的不规则形状。
- 拼装只允许平移:不得旋转、不得镜像。
- 生成约束:存在且仅存在一组相对平移,使三块像素恰好无重叠、
  无空洞地铺满某个矩形区域;碎块的锯齿边缘保证除正解外,
  任何两块的任何相对摆放都无法与第三块补成实心矩形。

规则
- 保持每块的形状与朝向不变,寻找三块的相对平移,使三块像素
  恰好无重叠地铺满一个实心矩形。
- 输出该矩形:每格取覆盖它的那个碎块的颜色。
- 输出尺寸等于拼成的矩形,与三块在输入中的原始位置无关。

关键洞察
- 规则只是一条验收标准,没有可照抄的流程;解题者要自己发明搜索:
  以锯齿边缘的互补性为线索试相对位移,唯一既不透光也不打架的
  拼法就是答案——输出按拼合结果裁剪,与"谁动谁不动"无关。
```

## 新题 6:自含缩略图的点名放大

**来源原语**:压缩/彩色标记/标记格定输出(19bb5feb)、归一化到固定尺寸(db118e2a)、等分网格(c3202e5a)、裁剪/内部区域(1a6449f1)

**创新轴与层级**:扩展轴 9·自指(地图嵌在疆域之中,且把自己也画了进去)。L3。

```text
网格里嵌着一张把自己也画进去的缩略图,输出缩略图上红格点名的那个分块的原始内容。

输入结构
- 15×15 黑背景网格,按 5×5 均分为 3×3 共九个分块(无分隔线)。
- 其中一个分块是"地图":恰为一圈灰(5)色一像素方框包着 3×3 内部;
  内部每格对应九个分块之一——非空分块画灰、全黑分块画黑,
  其中恰有一格画红(2),点名一个分块。
- 其余非空分块各含一个小图案(图案颜色不使用灰和红);
  若干分块全黑。
- 生成约束:地图内部与九个分块的实际虚实逐格吻合——地图所在的
  分块本身非空,故它对应的那格必为灰或红;红格不指向地图自身;
  只有地图分块具有"灰框+纯灰黑红内部"的形态;被点名的分块非空。

规则
- 找到地图分块,把它的 3×3 内部与九个分块的占用格局逐格对齐
  (地图自己占的那一格也要算作非空),确认缩略对应关系。
- 读出红格在 3×3 中的坐标,定位大图中对应的分块。
- 输出该分块的 5×5 原始内容。

关键洞察
- 同一批像素身兼两层身份:地图既是大图的一个分块(疆域的一部分),
  又是对整个大图的描述;对齐时必须把地图自己算作"非空"——
  这层自含关系正是验证缩略对应无误的钥匙。
```

## 新题 7:蛇径上的同余填色

**来源原语**:循环填充/同余类交错铺满(05269061)、从边缘推进(f9a67cb5)、顺序读取(8fff9e47)

**创新轴与层级**:扩展轴 5·参照系(规律只在沿路径的弧长坐标里成立,平面坐标下不可见)。L3。

```text
把蛇形路径沿其自身长度方向按模三周期补满颜色。

输入结构
- 黑背景上有一条一像素宽、不分叉、不自触的蛇形路径,可多次拐弯;
  路径格大部分为灰(5)色,其中若干格已被涂成彩色"珠子"
  (路径 = 灰格与珠子格的并集)。
- 珠子遵循:沿路径给格子编号后,编号模三同类的珠子同色,
  三个同余类各有一种颜色。
- 生成约束:三个同余类各至少有两颗珠子(钉死类色映射与周期);
  珠子摆放排除按行、按列、按欧氏距离等平面坐标解释——存在两颗
  几何相邻但异色的珠子和两颗几何远离但同色的珠子;
  路径不自触保证线序唯一。

规则
- 从任一端沿路径给格子编号(从哪端数起所得的类划分相同)。
- 编号模三相同的格子为一类,每类的颜色由该类已有珠子读出。
- 把所有灰色路径格涂成所属类的颜色,珠子与背景不变。

关键洞察
- 周期只存在于"沿路径的弧长坐标"中:蛇一拐弯,几何上紧挨的两格
  在路径序里可能相距很远;必须先把蛇展直,规律才现形——
  在平面坐标里找周期注定失败。
```
