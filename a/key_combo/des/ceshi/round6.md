## 新题 1:图例接龙

**来源原语**:图例行内配对/双向换色(0becf7df)、颜色互换(fc4aaf52)、印章/图例作为符号指令(0becf7df);组装形态=传递拼链(把若干映射按首尾相接排成唯一次序再复合)。

**难度档案**
- 第一眼的故事:"离对象最近的那张图例(或从左到右第一张)就是要用的换色表"——首例里图例恰按接龙次序从左往右摆,"按阅读序依次套用"完全成立,喂饱这个故事;后续示例把图例位置打乱,阅读序给出错色。
- 最浅充分策略:不存在捷径。每张图例是一个色集到色集的双射,答案是把对象的颜色推过**整条复合链**;而链的次序不写在任何位置上,只能靠"上一张的输出色集 = 下一张的输入色集"这一首尾相接关系拼出唯一的链。少接一环、接错一环,末端颜色全错;单看任何一张图例都读不出对象的最终颜色。
- 组装工作:先把 m 张图例按输入/输出色集匹配连成唯一链(一个小的传递排序问题),再做函数复合作用到对象上——证据(每张图例)各自都不够,全部接起来之后答案才存在。

```text
若干换色图例的调色板首尾相接,只有唯一一种次序能把它们连成一条链;按这条链复合,重涂那个多色对象。

输入结构
- 黑(0)背景网格上散布 m 张(3~4)小图例块,另有一个多色连通对象。
- 每张图例是一个 k×2 小块(k 约为 3):同一行左格颜色 a、右格颜色 b
  表示映射 a→b;整张图例是它的输入色集到输出色集之间的一个双射
  (两个色集等大、无重复)。
- 生成约束:恰好存在一种把 m 张图例排列的次序,使每张的输出色集
  等于下一张的输入色集(首尾相接);链首的输入色集等于对象用到的
  颜色集,链尾给出最终色集;各色集的重叠只按这条链发生,故链唯一、
  链首唯一(只有一张图例的输入色集含对象的颜色)。第一个训练示例中
  图例的从左到右摆放次序恰等于接龙次序,后续示例中两者不一致。

规则
- 从"输入色集等于对象颜色"的那张图例起,按"输出色集=下一张输入色集"
  把所有图例接成唯一的链。
- 对象每个像素的颜色顺着整条链推过去:c→图例1→图例2→…→图例m。
- 输出为按复合映射重涂后的对象,置于背景上(图例移除),尺寸不变。

关键洞察
- 每张图例是一个函数而不是一个备选项;处理次序写在它们调色板如何
  互相咬合里,不写在位置里。对象的最终颜色是把整条链装好之后才
  存在的东西——单独套用任何一张都得不到它。
```

## 新题 2:被抹中间帧的重建(本轮下限之一)

**来源原语**:面板序列/周期调度/预测下一帧(2ccd9fef)、擦除(b7256dcd 等)、补全(98c475bf, de493100);组装形态=因果反演(从各色的可见节拍重建被抹去的一帧)+ 环面参照系。

**难度档案**
- 第一眼的故事:"空白面板 = 左右邻居的平均/内插",或"空白就是留白,输出照抄某个邻居"。两者都错:空缺是**内部**的一帧,且颜色的运动会绕边回卷,邻居内插在回卷处给出错位。
- 最浅充分策略:把一排面板读成一段延时胶片,逐色归纳它的每步位移(带回卷),在缺帧处求值。刻意安排某色在缺帧两侧之间恰好发生一次回卷,使"取两邻居中点"必错,必须用该色的运动律模除求位。
- 组装工作:realize 这是时间序列而非并列图 → 逐色induce(dr,dc) mod (H,W) → 在缺帧处联合渲染各色。耦合较弱(各色独立律),故本题定位为本轮下限之一,如实标注。

```text
一排面板是一段延时胶片,每种颜色是一个按固定步长绕边平移的点;其中一张内部帧被整块抹黑,按各色的运动律把它重建出来。

输入结构
- 网格由 k 张(4~5)等大面板沿一行排开,面板间以灰(5)竖线分隔;
  从左到右读作时间 t=0..k-1。每张面板为 H×W(约 5×5)黑背景。
- 有 2~3 种动态颜色,每种在每张面板里是一个点;它的位置每步平移
  一个固定的(dr,dc),越界即从对侧回卷(在 H×W 的环面上移动),
  不同颜色的位移不同,行列均可能移动。
- 恰有一张内部面板 t*(1≤t*≤k-2)被整块涂黑(缺帧)。
- 生成约束:每种颜色的(dr,dc)可由其在可见面板中的位置唯一确定;
  至少一种颜色在 t*-1 与 t*+1 之间发生一次回卷,使"取两邻居中点"
  给出错误位置;各色的点在任一面板中不重合。

规则
- 把这排面板读作时间序列,全黑的内部面板是缺失的一帧。
- 对每种颜色,从可见帧归纳它每步的固定位移(含越界回卷)。
- 在缺帧处按各色运动律算出(回卷后的)位置,画上对应颜色的点。
- 输出这一张重建的面板,尺寸为单张面板 H×W。

关键洞察
- 空白不是要靠邻居填补的洞:面板是胶片,每种颜色沿环面匀速漂移,
  缺帧要从各自的运动算出,而不是从相邻两张图里抄或平均——回卷处
  专门惩罚把两个邻居取中点的人。
```

## 新题 3:生长到相切

**来源原语**:内嵌标记计数/计数决定扩展量/膨胀(52fd389e)、缓冲行间距(隐藏偏移)(825aa9e9)、印章覆盖(a9f96cdd);组装形态=变分/约束求解(全体光环共享一个待解的全局增量,由最紧的一对相切钉死)。

**难度档案**
- 第一眼的故事:"光环厚度 = 块内标记数"(直接照搬 52fd389e)。在颜色恰好凑巧的首例里成立;但多数示例的光环比标记数更厚,单靠计数解释不了。
- 最浅充分策略:必须认出所有光环在计数基础上还**一起**多长了同一个量 h,并且 h 被"谁也不许重叠、最近的一对恰好相切"这条全局约束唯一钉死。任一块的厚度都取决于那对限制全场的邻居,单看一块解不出。
- 组装工作:读出每块的标记数 → 找出限制全场的最近对、由相切条件解出全局 h → 按 count_i+h 渲染每个光环。这是"证据(各计数)找齐后,变分求解才开始"的样板;h 是全局共享变量,由最紧的一对联立定出。

```text
每个色块按内部标记数长出一圈同色光环,但所有光环在计数基础上再一起加厚同一个量,一直长到最近的两圈恰好相切为止。

输入结构
- 黑(0)背景网格上散布 3~5 个实心矩形色块,彼此分离;每块内部含
  若干枚另一种颜色的标记像素,count_i = 该块的标记数。
- 各块位置使它们的包围盒两两留有空隙。

规则
- 每个块 i 向四周长出一圈同色光环,厚度 = count_i + h,h 为一个
  全体共享的非负整数。
- h 取"任意两圈光环都不重叠"所允许的最大值——等价于让所有光环
  从各自的 count_i 起同步加厚,直到最近的一对恰好相切;h 即该上限。
- 用块自身的颜色填充扩大后的矩形(光环),原块与其内部标记覆盖
  在上层;输出尺寸不变。

关键洞察
- 计数只定下每圈光环的底厚,之后所有光环一起膨胀同一个量,直到
  最近的两圈相吻;任何一块的答案都无法脱离那对限制全场的邻居
  单独算出——厚度是一道全局的变分题,不是逐块的查表。
```

## 新题 4:弹射射线的轨迹

**来源原语**:射线延伸/沿列下行(981add89)、生长/逐步演化(af726779)、邻接阻挡(825aa9e9);组装形态=过程/动力学(局部转向规则自我串联,步数与轨迹由数据决定,跑到出界为止)。

**难度档案**
- 第一眼的故事:"顶行控制像素向下引一条直线"(直接照搬 981add89)。首例路径上无障碍,竖直直线完全成立;后续示例路径撞上彩色障碍,直线全错。
- 最浅充分策略:先归纳每种障碍颜色相对射线**行进方向**施加的转向(左转/右转),再把每条射线当动力学过程跑:直行→遇障碍按其颜色转 90°→继续,直到出界,沿途染上发射色。转向码是小表,但"射线会被障碍偏折"这一层要先认出;终态无法一眼看出,只能把过程跑完。
- 组装工作:归纳"障碍色→转向"码 + 逐条射线多次反射直到出界的模拟。深度在认出反射机制与归纳转向码,模拟本身是执行成本(如实计入附加成本而非推理深度),故本题为过程体裁的中等难度。

```text
顶行每个控制像素向下射出一条自己颜色的射线,遇到彩色障碍就按障碍颜色规定的方向转 90°,直到射出网格;输出所有射线的轨迹。

输入结构
- 黑(0)背景网格。顶行有若干控制像素,每个是一种颜色、标定一列,
  从该列向下发射一条同色射线。
- 网格内散布若干单像素彩色障碍,障碍颜色只有两三种;每种障碍色
  编码一个相对行进方向的转向(某色=右转 90°,另色=左转 90°)。
- 生成约束:每种转向色在示例中至少出现一次明确的偏折,转向码
  可唯一归纳;所有射线最终都会出界(无死循环),各射线轨迹不
  相交(免去叠加优先序的约定)。第一个训练示例的射线路径上无障碍
  (竖直直线),后续示例迫使至少一条射线发生反射。

规则
- 从示例归纳每种障碍色相对行进方向施加的转向(左/右)。
- 从每个顶行控制像素起,让射线直行;当前进方向的下一格是障碍时,
  按该障碍色转向 90°,从障碍处继续;沿途经过的格子染成发射色,
  直到射线离开网格。
- 保留障碍与控制像素,输出带全部射线轨迹的网格,尺寸不变。

关键洞察
- 顶行不是画竖线的模板而是一排发射器;每种障碍色是一面定向的镜子,
  射线的落点要把偏折过程在脑中跑完才知道——终态一眼看不出,
  步数由画面里障碍的摆布决定。
```

## 新题 5:边码填格

**来源原语**:标记列/长度映射数量/固定编码(e048c9ed)、行列分隔与坐标结构(7d419a02, 21f83797)、补全(98c475bf, de493100);组装形态=自指(边缘是对内部的描述)+ 约束系统求解(逐行逐列线索联立,唯一填法)。

**难度档案**
- 第一眼的故事:"边缘那些彩色小段是图例/装饰,把它们照抄或平移进去",或"内部被抹掉的部分照抄某个完好邻居"。都错:边缘不是内容,是对内部每行每列的**描述**,内部要按描述重新解出。
- 最浅充分策略:认出左侧每条边码给出对应行的彩色段序列(颜色+长度),顶部每条给出对应列的段序列;然后把内部当作一张彩色数织图,联立所有行约束与列约束解出唯一填法。任何只看单行或单列的局部推断都不足以定格——某些格子只有行列两条线索交叉才能定色。
- 组装工作:线索(边码)全部就位后,真正的组装才开始——行列约束的联立求解。这是"找到证据即结束"的反面:证据齐了,解题才刚起步。

```text
网格四周的边码逐行逐列描述了内部每条线的彩色段;内部被整片抹去,按所有行、列描述联立解出唯一的填法。

输入结构
- 一块内部网格(约 6×6 到 8×8)四周留有边距。左边距对齐每个内部行,
  用一串彩色小段按从左到右的顺序列出该行的各个彩色段:每段的颜色
  =该段颜色、长度=该段长度,段与段之间空一格;顶边距对齐每个内部列,
  同样自上而下列出该列的各彩色段。("段"指内部一条线上极大的同色连块。)
- 内部整片被抹成中性色(灰 5),即待求区域;边码完好。
- 生成约束:所有行、列边码联立后,内部填法唯一;边码本身互不遮挡、
  可无歧义读出各段的颜色与长度。

规则
- 把左边距读作各行线索、顶边距读作各列线索(每条线索是该线自左向右
  /自上而下的彩色段颜色与长度序列)。
- 求出内部唯一一种填色,使每一行、每一列都与自己的线索吻合。
- 输出内部已填好的整幅网格(边距不变),尺寸不变。

关键洞察
- 边缘不是布景,是内部的说明书;这张图不是被抄出来的,是被每一行、
  每一列关于自身的声明一起约束出来的唯一解——同一份像素既当"关于
  内容的描述",又逼出"内容"本身。
```

## 新题 6:按孔数分派(本轮下限之一)

**来源原语**:标记接触即赋色/邻接传色(b7256dcd)、对齐比较/匹配定去向(7d7772cc)、有花纹框为模板/尺寸匹配(f21745ec)、擦除与重涂色(多题);组装形态=决策树分派(同一判据把对象路由到几条完全不同的操作分支)。

**难度档案**
- 第一眼的故事:"按颜色分类处理"(红的一种待遇、蓝的一种)。示例里颜色被刻意跨类摆放,首例颜色恰与类别相关,喂饱这个错猜;后续示例中同色对象走进不同分支,颜色规则崩掉。
- 最浅充分策略:真正的判据是每个对象**围出的封闭孔洞数**(0/1/2),这不是颜色也不是尺寸;必须跨示例发现"孔数决定命运",再归纳每一类对应的那一种变换。发现判据是全部难点,分支动作各自是小规则。
- 组装工作:归纳判据(孔数)+ 每条分支的动作(0 孔→擦除;1 孔→重涂为定色;2 孔→用定色填满其孔洞),再逐对象路由执行。深度在识别隐藏判据、推翻颜色首猜;分支动作简单,故本题为决策树体裁的下限,如实标注。

```text
每个对象按它围出的封闭孔洞数被送进不同的处理分支,孔数而非颜色决定它的命运。

输入结构
- 黑(0)背景网格上有若干互相分离的连通对象;画面用到两三种颜色,
  但颜色**不是**分类依据(同一颜色的对象会落在不同类里)。
- 每个对象按其封闭孔洞数分为三类:0 孔、1 孔、2 孔。
- 生成约束:三类在训练示例里都出现且各自动作一致,可唯一归纳;
  颜色与类别刻意错配(第一个训练示例中颜色恰好与类别相关,构成
  "按颜色处理"的诱饵,后续示例中同色对象分属不同类,打碎该诱饵)。

规则
- 数出每个对象围出的封闭背景孔洞数。
- 按孔数路由到对应分支,执行该分支从示例归纳出的动作:
  0 孔→整个对象擦除为背景;1 孔→整体重涂为固定色 c1;
  2 孔→用固定色 c2 填满它的孔洞(轮廓保持)。
- 输出处理后的网格,尺寸不变。

关键洞察
- 决定每个对象怎么变的不是它的颜色、也不是它的大小,而是它围出
  几个洞;颜色是专门摆来引诱"按颜色分类"的幌子,看穿判据比执行
  任何一条分支都难。
```
