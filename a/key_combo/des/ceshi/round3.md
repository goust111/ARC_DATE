## 新题 1:边界同色配对的隐形交点印章

**来源原语**:同色系配对/忽略干扰项(494ef9d7)、边缘标记/从边缘推进(f9a67cb5)、模板(8e5a5113)、重涂色(e9b4f6fc)

```text
把每对同色边界标记的两条隐形射线的交点找出来,在交点处盖上按对色重涂的模板印章。

输入结构
- 黑(0)背景网格,四条边界上散布若干彩色单像素标记(不占四角)。
- 每种配对色恰好出现两次:一枚在上边界或下边界,另一枚在左边界或
  右边界;另可有一枚只出现一次的边界标记作干扰项。
- 网格内部有一个灰(5)色小图案作为印章原型,边界框为 3×3
  (中心格唯一)。
- 生成约束:各配对色的交点位置互不相同;以交点为中心放置 3×3
  印章后,各印章之间、印章与原型、印章与边界标记均不重叠,
  且完整落在网格内;灰与配对色不冲突。

规则
- 把边界标记按颜色两两配对,忽略无伙伴的单个标记。
- 每对标记各自向网格内部发出一条垂直于所在边的隐形射线:
  上下边界的标记给出一条竖直线(定列),左右边界的标记给出
  一条水平线(定行);两线交点即该对的锚点。
- 把灰色印章原型整体重涂为该对的颜色,以其中心格对准锚点盖章。
- 原型、边界标记与背景保持不变;射线本身不画出;
  输出尺寸与输入相同。

关键洞察
- 印章的落点在输入里没有任何像素:它是两枚同色标记各自射线的
  交点,必须先配对、再在脑中把两条线延伸出来;印章的形状与颜色
  又分别来自原型和配对色,三份信息缺一不可。
```

## 新题 2:杯口推出的层序带

**来源原语**:杯形容器/开口朝向/从开口发射(aba27056)、块序映射层序(8fff9e47)、滑动/擦除(494ef9d7)

```text
把杯子内部的彩色层沿开口方向推出来,在杯口外排成一条顺序不变的色带。

输入结构
- 黑背景网格上有一至两个杯形容器:一像素厚的单色杯壁围出一条
  一格宽、深 k 格(k=3~5)的内腔,一端开口(开口可朝上下左右
  任意方向)。
- 内腔从杯口到杯底填满 k 个彩色格(同杯内各层颜色互不相同,
  且不同于杯壁色)。
- 生成约束:从杯口沿开口方向到网格边界至少有 k 个空格,
  且该直线路径上没有其他物体;两个杯子时互不干扰。

规则
- 读出内腔中从杯口数第 1 层到第 k 层的颜色序列。
- 从杯口外第一格起,沿开口方向依次放置这 k 种颜色:
  第 i 格放从杯口数第 i 层的颜色(相当于整摞内容物被原序推出)。
- 内腔全部清为黑色,杯壁保持不变,输出尺寸与输入相同。

关键洞察
- 开口朝向一次给出两个参数:色带的铺设方向和层序的读取起点;
  杯内的空间顺序被转写成杯外沿射线的顺序,内容物本身一个都
  不变,变的只是承载顺序的坐标轴。
```

## 新题 3:等距足迹双向延拓

**来源原语**:等距偏移/裁剪延拓(05269061)、精灵体(8ee62060)、阵列排布(ccd554ac)

```text
同一精灵已沿等距直线轨迹留下几枚足迹,把这条等差轨迹向两端延拓铺满画布,出界部分裁剪。

输入结构
- 黑背景网格上,同一个小精灵体(可多色,边界框约 2×2~3×3)
  被画了 2~3 份,各份完全相同、无旋转无镜像,相邻两份的位移
  是同一个恒定向量(行差、列差不全为零)。
- 生成约束:位移向量的模长大于精灵尺寸,任何两份足迹不重叠;
  延拓后至少出现一份被网格边界裁掉一部分的残缺足迹
  (钉死"裁剪延拓"而非"放得下才画")。

规则
- 由已有足迹读出恒定位移向量。
- 沿该向量向两端延拓等差位置序列,在每个位置贴一份精灵拷贝。
- 与网格重叠不完全的拷贝只画界内部分;完全出界处停止。
- 已有足迹保持不变,输出尺寸与输入相同。

关键洞察
- 给出的足迹只是无限等差列中的相邻几项;补全对象是"轨迹"这个
  结构而不是某一份图形,所以两端都要延拓,边界处宁可裁碎
  也不留空。
```

## 新题 4:重复色种数定平铺倍数

**来源原语**:计数/色数映射(6e02f1e3)、平铺/边长决定重复数(ccd554ac)、忽略干扰项(c3202e5a)

```text
数出出现两次以上的颜色种数 k,把整幅输入(连同噪声)平铺成 k×k 的阵列。

输入结构
- 输入为 3×3 至 5×5 的小网格,散布若干彩色像素。
- 出现至少两次的颜色是目标色,恰好出现一次的颜色是噪声。
- 生成约束:目标色种数 k 取 1~3,训练示例覆盖至少两个不同的 k;
  各示例的噪声像素数彼此不同且与 k 无关(排除"噪声数+1"等
  替代解释);k×边长不超过 30。

规则
- 统计出现次数不少于两次的颜色种数,记为 k。
- 把整幅输入网格作为瓦片,纵向重复 k 次、横向重复 k 次拼成输出
  (噪声像素作为瓦片的一部分照抄)。

关键洞察
- 重复的单元是完整的输入画面,而重复的次数却只由其中一部分
  像素(重复出现的颜色)决定——数数时要剔除的噪声,平铺时
  又必须原样带上。
```

## 新题 5:空腔定壳的去留

**来源原语**:封闭区域/内部包含/填充(aba27056)、洪泛填充(7447852a)、擦除(fbf15a0b)

```text
内腔为空的环得到自己颜色的实心,内腔有核的环让位消失只留下核。

输入结构
- 黑背景网格上散布 3~5 个封闭环:一像素厚的单色闭合壁,
  围出 1~6 格的黑色内腔,环与环互不接触、互不嵌套。
- 部分环的内腔全黑;其余环的内腔中恰有一个彩色单像素核
  (核色不同于该环壁色)。
- 生成约束:每个示例中两种情况各至少出现一次;核严格位于
  内腔中,不接触环壁。

规则
- 逐环检查内腔:
  - 内腔全黑的环,用环壁自己的颜色洪泛填充内腔,变为实心块;
  - 内腔含核的环,把环壁全部擦为黑色,核原地保留。
- 其余背景不变,输出尺寸与输入相同。

关键洞察
- 同一种对象走向两个相反的命运:空则壳变得更多(得到实心),
  有核则壳失去一切(让位给核)——判据不在环自身的任何属性上,
  而在它包着的东西里。
```

## 新题 6:完整边框才算数的奇偶灌注

**来源原语**:矩形框/完整边框检测/边框包围内容(1a6449f1)、奇偶条件(d22278a0)、洪泛填充(7447852a)

```text
只把闭合完整的矩形框算作容器,给包含层数为奇数的黑色区域灌上黄色。

输入结构
- 黑背景网格上有一至两组嵌套摆放的一像素厚单色矩形框,
  嵌套深度最多 3~4 层,框与框互不接触,颜色不使用黄(4)。
- 其中至少一个框是破损的:边框缺失一个或几个像素,未能闭合。
- 生成约束:破损框所处的位置保证"把它当完整框计数"会翻转
  某片区域的奇偶(即忽略它与否,答案可见地不同);
  各框颜色无特殊含义。

规则
- 逐框检查边框是否完整闭合;破损的框不算容器,但其像素保留。
- 对每个黑色格子,数它被多少个完整框严格包含,记为深度。
- 深度为奇数的黑格涂黄(4);深度为偶数(含零)的黑格保持黑色。
- 所有框(完整的与破损的)原样保留,输出尺寸与输入相同。

关键洞察
- 灌色前必须先做资格审查:一个缺了口的框看上去仍在"包着"
  里面的区域,但它对深度没有贡献——数层数之前先验闭合,
  两步顺序不可颠倒。
```

## 新题 7:调色序拆解模板入槽

**来源原语**:分隔线/槽位/顺序排列(8e5a5113)、面板提供调色板/二值掩码(c803e39c)、多色目标对象(e9b4f6fc)

```text
按左侧色序条的顺序,把多色模板逐色拆成单色层,依次放进右侧的空槽位。

输入结构
- 网格被灰(5)色整列分隔线分成五个面板,从左到右:
  色序条面板(宽 1 列,自上而下叠放 3 个彩色格)、模板面板、
  三个空槽位面板;模板与各槽位同尺寸(约 4×4)。
- 模板恰好使用 3 种颜色,每种至少 2 个像素;色序条的 3 个格
  正是这 3 种颜色的一个排列。
- 生成约束:色序条的顺序在不同示例中不同,且不等于模板中
  各色的像素数排序或出现位置排序(排除旁路解释);
  槽位初始全黑。

规则
- 读色序条,自上而下得到颜色顺序 c1、c2、c3。
- 第 i 个槽位放入模板的 ci 色单层:ci 色像素按原位置保留,
  模板的其余像素处为黑。
- 色序条、模板、分隔线保持不变,输出尺寸与输入相同。

关键洞察
- 模板被当作三张重叠的单色掩码来读,槽位顺序由色序条这个
  外部键控制——把"多层叠成一图"反着做成"一图拆回多层",
  拆出来的每一层放在哪,画面另一处早已规定好。
```

## 新题 8:灰色精灵认领最近锚点色

**来源原语**:最近归属(d22278a0)、精灵体(8ee62060)、重涂色/颜色替换映射(e9b4f6fc)

```text
每个灰色精灵整体染成离它最近的彩色锚点的颜色。

输入结构
- 黑背景网格上有 3~4 个彩色单像素锚点,颜色互不相同;
  另散布 4~6 个灰(5)色精灵体(4 连通,3~5 像素),
  精灵与锚点、精灵与精灵互不接触。
- 生成约束:每个精灵到最近锚点的距离(取精灵各像素到锚点的
  最小值)在棋盘、曼哈顿、欧氏三种度量下给出同一个唯一的
  最近锚点,且比次近锚点至少近 2 格(排除度量歧义与并列);
  允许存在一个不被任何精灵认领的锚点作干扰项。

规则
- 对每个灰色精灵,找出与它距离最近的锚点。
- 把该精灵的全部像素重涂为那个锚点的颜色,形状位置不变。
- 锚点与背景不变,输出尺寸与输入相同。

关键洞察
- 颜色不来自任何图例或映射表,而来自空间竞争:锚点无形地
  瓜分了整个画布,每个精灵的新颜色只是它落在谁的势力范围里
  的记号。
```

## 自检记录

- **唯一归纳**:1 的干扰单标记与"射线不画出"由输出对比可辨,交点须同色配对方能定位;2 的层色互异使读取顺序在训练输出中唯一可见;3 强制出现残缺足迹,钉死"双向延拓+裁剪"而非"放得下才画";4 要求噪声数与 k 去相关,排除"噪声数+1"等旁路;5 每例两种命运并存,分支判据可对比发现;6 要求破损框处于"计不计入会翻转奇偶"的位置,闭合审查不可跳过;7 色序条顺序与像素数序、位置序去相关;8 用三度量一致+间隔 2 格封死度量与并列歧义。
- **答案唯一确定**:8 题均无随机成分;生成约束保证 1 的印章不重叠、2 的推出路径畅通、3 的足迹不重叠、6 的框互不接触、8 的最近锚点唯一。
- **与参考题不同构**:1 的锚点是两条隐形射线的涌现交点,f9a67cb5 的射线是显式绘制且无配对;2 把 aba27056 的"向开口外发射"改造成层序到线序的转写;5 的二分支与 8886d717 的"嵌入修补/孤立延伸"判据与动作均不同;6 在 1a6449f1 的完整性检测上叠加深度奇偶,输出为灌色而非提取;7 是 c803e39c 叠加方向的反向拆解;3、4 如实标注为近亲变体——3 是 05269061 等距延拓的载体推广(对角线→任意向量的精灵足迹),4 是 ccd554ac 的参数源替换(边长→重复色种数),按本轮定位变体允许出现。
