## 1. 奇偶换闸沉降

- tags:
  - operation:重力下落, gravity_drop
  - operation:重涂色, recolor
  - object:图例, legend
  - object:闸线, gate_line
  - relation:穿越计数, crossing_count
  - condition:奇偶翻转, parity_toggle

### docstring

```text
下落像素每穿过一条灰色闸线就按图例换一次颜色，最终按奇偶结果沉底堆叠。

输入结构
- 底行为统一基线色，最常见色为黑色背景。
- 左上角有一个2x2图例，每行给出一对可互换的颜色；图例所在角落不参与下落。
- 若干条整行宽的灰色闸线横穿网格，灰色不出现在图例中。
- 悬浮像素只使用图例中的颜色，散布在闸线上方或闸线之间；
  悬浮像素的数量保证堆叠不会触及最低的闸线。

规则
- 图例、基线与所有灰色闸线保持不变。
- 每个悬浮像素在本列内竖直下落，灰色闸线不阻挡下落，
  像素落到基线或已堆叠像素之上的最低空格；同列多个像素保持原有上下次序。
- 统计该像素起点与落点之间穿过的灰色格数：
  奇数则换成图例同一行中的配对色，偶数则保持原色。

关键洞察
- 灰色横线看似地板实为换色闸门：它可以被穿过，每穿过一次颜色在图例行内翻转一次，
  最终颜色由"下落路径上穿闸次数的奇偶"决定，而不是由起点或终点单独决定。
```

## 2. 同色虫洞巡游

- tags:
  - operation:射线延伸, ray_extend
  - operation:连线, draw_path
  - object:边框传送门, border_portal
  - object:双格指针, two_cell_pointer
  - relation:同色配对传送, same_color_teleport
  - condition:出口内法线续行, exit_normal_direction

### docstring

```text
双格指针沿其指向滑行，撞上边框上的彩色门便从同色的另一扇门射回场内，画出全程轨迹。

输入结构
- 网格四周是一圈灰色边框，边框上（非角落处）嵌有若干彩色格，
  每种颜色恰好出现两格，构成传送门对。
- 内部有一个红头蓝尾的双格指针，头尾相邻，头相对尾的方位即运动方向。
- 内部另有若干灰色实心墙块；示例保证轨迹不成回路。

规则
- 指针自头部出发沿指向直线前进，途经的背景格连同指针原来的两格一并涂成红色。
- 行进中到达边框上的彩色门时，跳到同色的另一扇门，
  沿该出口门所在边的内法线方向（即垂直指向场内）继续前进并继续涂色。
- 碰到灰色墙块或普通灰色边框格即停止。
- 门、墙与边框颜色保持不变。

关键洞察
- 边框上成对出现的彩色格不是装饰而是虫洞：穿门后方向不延续原方向，
  而由出口所在的边重新决定，轨迹因此可以在场内多次转折。
```

## 3. 试管配色计数

- tags:
  - operation:计数, counting
  - operation:填充, fill
  - operation:擦除, erase
  - object:试管, test_tube
  - object:散点, scattered_pixel
  - relation:颜色归类, color_classification
  - condition:计数定液面, count_determines_level

### docstring

```text
把散落像素按颜色归入同色试管，管内液面高度等于该颜色散点的个数。

输入结构
- 背景为黑色；若干竖直"试管"由单色管壁围成：内腔宽一格、上端开口、左右与底部封闭。
- 网格中散布若干彩色散点，每个散点颜色都与某支试管的管壁同色；
  散点可以出现在任何位置，包括贴着别的试管。
- 每种颜色的散点个数不超过对应试管的内腔深度。

规则
- 删除所有散点（还原为背景）。
- 统计每种管壁颜色的散点个数 n。
- 在对应试管的内腔中，从腔底向上连续涂 n 格该颜色。
- 管壁保持不变。

关键洞察
- 散点的位置与排布全是诱饵：无论散点离哪支试管近，
  起作用的只有按颜色分类后的数量，它被转写为同色试管中的液面高度。
```

## 4. 分形自洽修复

- tags:
  - operation:印章覆盖, stamp
  - operation:补全, reconstruct
  - object:自相似图案, self_similar_pattern
  - object:篡改块, corrupted_block
  - relation:掩码与图章同一, mask_equals_stamp
  - condition:自洽性定母图, self_consistency

### docstring

```text
在自嵌套图案中找出唯一自相矛盾的块并修复，使占位布局与块内容重新等于同一幅母图。

输入结构
- 网格边长为 n 的平方，被划分为 n x n 个等大的块。
- 图案本应自嵌套：存在一幅 n x n 单色母图，母图每个前景位置对应的块内
  画着整幅母图的副本，其余块全为背景。
- 恰有一个块被篡改：或是副本内容画错，或是某块的空/非空状态与母图不符。

规则
- 从多数完好副本中读出候选母图，再与非空块的占位布局互相印证，
  确定唯一能同时充当"占位掩码"与"块内图章"的母图。
- 按该母图重画整个网格：母图前景位置的块画母图副本，其余块清为背景。

关键洞察
- 母图在画面中扮演双重角色——既是决定哪些块非空的掩码，又是每个非空块内的图章；
  被篡改的块正是两重表述唯一失配之处，修复答案由自洽性本身唯一确定。
```

## 5. 撞击接力

- tags:
  - operation:滑动, slide
  - object:发射珠, launcher_bead
  - object:静止珠, resting_bead
  - object:墙块, wall_block
  - relation:动量接力, momentum_relay
  - condition:贴边定方向, edge_contact_direction

### docstring

```text
贴边的发射珠沿本行滑出，动量沿途逐珠接力，每颗被撞珠继续滑向下一颗，最后一颗停在墙前。

输入结构
- 背景为黑色。若干行各有一颗紧贴网格左边或右边的彩色发射珠，
  同一行内散布若干颜色各异的静止单格珠，行内还可能有一段灰色墙。
- 不同行互不影响；各行发射珠贴住的边可以不同，运动方向即离开该边的方向。

规则
- 发射珠沿本行滑行，滑到最近一颗静止珠的相邻格停下。
- 被撞的珠接过运动，沿同方向继续滑行，同样停在下一颗珠的相邻格并把运动传下去。
- 链上最后一颗珠一直滑到灰色墙或网格对边的相邻格停下。
- 所有珠颜色不变，墙保持不动。

关键洞察
- 撞击既不是穿越也不是整体压实：运动像接力棒逐珠传递，
  每颗珠最终停在下一颗珠"出发位置"的旁边，因此行内珠间会留下与原间距相关的空隙，
  珠的左右次序始终不变。
```

## 6. 折纸奇偶合成

- tags:
  - operation:镜像, mirror
  - operation:折叠, collapse
  - object:折线, fold_line
  - object:象限掩码, quadrant_mask
  - relation:翻折对位, fold_alignment
  - condition:奇偶取舍, parity_composite

### docstring

```text
沿灰色折线把四个象限折成四层，只有被奇数层前景覆盖的位置才在输出中点亮。

输入结构
- 网格中央有一条整行与一条整列的灰色折线，把画面分成四个等大的象限。
- 四个象限内是用同一种前景色画出的各自图案，其余为黑色背景。

规则
- 以折线为轴，把右半区向左翻折、下半区向上翻折
  （右下象限经水平与竖直双重翻转），四个象限对齐叠成与左上象限同大的四层。
- 输出为该尺寸的网格：某格被奇数层前景覆盖则涂前景色，
  被偶数层（含零层）覆盖则为黑色。
- 折线不进入输出。

关键洞察
- 折叠意味着先镜像再对位，而叠合不是求并集：两层相消、三层复现，
  取舍标准是覆盖层数的奇偶，如同薄纸重叠处透光性反转。
```

## 7. 九宫指令程序

- tags:
  - operation:滑动, slide
  - object:指令块, instruction_glyph
  - object:机器人像素, robot_pixel
  - object:分隔线, separator_line
  - relation:方位编码方向, position_encodes_direction
  - condition:顺序执行滑到底, sequential_slide_to_stop

### docstring

```text
从左到右执行顶部的九宫格方向指令，机器人每条指令都沿该方向滑到被挡为止，输出其最终位置。

输入结构
- 一条整行灰色分隔线把网格分为上下两部分。
- 上方并排若干个3x3指令块，块间以背景列隔开：每块由中心格与其八邻中的
  恰好一格同色点亮组成，点亮格相对中心的方位就是该条指令的方向。
- 下方是棋盘：散布灰色墙块，另有一个颜色唯一的机器人像素。

规则
- 依从左到右的次序逐条执行指令：机器人沿指令方向直线滑行，
  直到下一格是墙、分隔线或出界才停下，然后执行下一条。
- 输出保留指令区、分隔线与墙不变，机器人从原格移到全部指令执行完的落点，
  原格还原为背景。

关键洞察
- 方向不靠任何颜色对照表，而由指令块内点亮格相对中心的几何方位直接给出；
  每条指令走的不是一步而是滑到底，指令顺序因此不可交换。
```

## 8. 时间倒流

- tags:
  - operation:滑动, slide
  - operation:擦除, erase
  - object:实心方块, solid_block
  - object:坠落尾迹, fall_trail
  - relation:尾迹记录历史, trail_records_history
  - condition:因果反演, causal_inversion

### docstring

```text
把每个拖着尾迹的方块沿尾迹送回坠落前的位置并抹去尾迹，重现下落发生之前的画面。

输入结构
- 底行为基线色，其上堆着若干彩色实心方块。
- 部分方块正上方拖着一段与本块等宽的浅灰色竖直尾迹，
  从方块顶边向上延伸若干行，是该方块坠落时扫过的区域。
- 没有尾迹的方块本来就静止在原地。

规则
- 每个带尾迹的方块整体上移，距离等于其尾迹的行数，
  使方块顶部对齐尾迹原先的顶端。
- 抹去所有浅灰色尾迹。
- 无尾迹的方块与基线保持不变。

关键洞察
- 画面是"事后"状态：浅灰色不是独立物体而是运动残迹，
  题目要求逆着重力把历史倒放一步，尾迹长度就是回溯的距离。
```

## 9. 日照与透光

- tags:
  - operation:射线延伸, ray_extend
  - operation:重涂色, recolor
  - object:太阳标记, sun_marker
  - object:石块, stone_block
  - object:玻璃块, glass_block
  - relation:遮挡成影, occlusion_shadow
  - condition:材质定透光, material_transparency

### docstring

```text
从太阳所在的整条边射入平行光，石块背后留下阴影而玻璃透光，被照亮的背景格染成黄色。

输入结构
- 网格某条边上有一颗红色太阳像素，不同示例中太阳可位于不同的边。
- 场内散布灰色石块与青色玻璃块，其余为黑色背景。

规则
- 光从太阳所在的整条边垂直射入，沿每条平行射线前进。
- 射线途经的背景格染成黄色；遇到灰色石块即被挡住，
  该射线在石块之后的格保持黑色。
- 青色玻璃不挡光：射线原样穿过，其后的背景格照常染亮。
- 太阳、石块、玻璃自身颜色不变。

关键洞察
- 太阳像素只指明光来自哪条边，光是平行光而非从该点发散；
  两种"障碍"角色不同——灰色成影、青色透光，材质区别须从示例中亮区的形状反推。
```

## 附：反硬凑验收摘要

- **承重测试**：逐题删层检查——1题删图例则换色无定义、删闸线则无换色、删重力则穿闸数无从谈起；2题删门对则轨迹退化为直线；3题散点颜色与个数分别决定液面颜色与高度；4题占位与内容两重表述互为验证，缺一不可定位篡改块；5题删墙或删中间珠都会改变整条接力链的落点；6题删翻折则对位错误、改奇偶为并集则示例矛盾；7题指令顺序与滑到底语义均影响落点；8题尾迹长度直接决定回溯距离；9题两种材质与太阳方位均改变亮区。均无可删除的死层。
- **捷径测试**：1题最短解即"数起落点之间灰格的奇偶"，与设计一致；5题存在闭式（每珠停在下一珠出发位旁），但该闭式本身即接力洞察，无更短旁路；6题示例含两层与三层重叠格，堵死"取并集"捷径；7题示例中滑到底与走一步结果不同，堵死逐步捷径；其余各题未发现更短等价策略。
- **伪难度自查**：各题网格与对象数量保持小规模，无任意长映射表；难度来源均为规则入口的隐蔽性（闸门非地板、门非装饰、散点位置无关、掩码即图章、残迹非物体、平行光非点光源）而非执行负担。
