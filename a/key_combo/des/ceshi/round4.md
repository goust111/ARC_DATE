# Round 4 · 创新 ARC 题(参考题组 001)

> 参考题(20 道):6e02f1e3, 05269061, aba27056, 8e5a5113, ccd554ac, e9b4f6fc, 19bb5feb, c803e39c, db118e2a, 8886d717, 494ef9d7, 8ee62060, 4cd1b7b2, fbf15a0b, c3202e5a, 7447852a, 8fff9e47, f9a67cb5, d22278a0, 1a6449f1
>
> 原语池:同 select/001.md tags(操作/对象/关系/条件四类,详见 round1.md 头部登记)。
>
> 设计原则:难度对标 ARC-AGI-2——正确规则不能被廉价拿到:不能一眼看穿,
> 不能被人眼的免费能力(镜像检测、对齐、异类突出、颜色分组)白送,
> 不能退化为更简单的局部等价形式。诱饵假设、紧耦合、创新轴等都是服务于
> 质量的工具而非强制项:有自然的诱饵就用足,靠结构深度取胜的题不硬造误导。
> 每题从 2~4 道不同参考题抽原语,与参考题不同构,规则可由 2~4 个训练示例
> 唯一归纳。

## 新题 1:形色各一套的双重拉丁

**来源原语**:拉丁方约束/补全/色表(4cd1b7b2)、等分网格/网格单元(c3202e5a)、分隔线/槽位(8e5a5113)

**诱饵假设**:第一个示例里,每种形状恰好始终以同一种颜色出现(形色绑定),画面完全可以用"N 种固定色的图章排成拉丁方"这个单系统模型解释,空格按普通拉丁方推一步即得。第二个示例里同一形状以不同颜色出现、同一颜色套在不同形状上——形状和颜色其实是**两套互相独立的拉丁方**,空格的形状与颜色要分别在两套系统里各推一次,再合成一个格子。

```text
黑色空格处的图案,形状由形状拉丁方决定,颜色由另一套颜色拉丁方决定,两套约束各推各的。

输入结构
- 灰(5)色分隔线把网格等分为 N×N(N=3 或 4)个同尺寸单元格。
- 每个单元格内画一个占约 3×3 的小图案:形状取自 N 种固定微形状
  之一,颜色取自 N 种颜色之一。
- 形状的排布满足拉丁方:每行每列 N 种形状各出现一次;
  颜色的排布满足另一个独立的拉丁方:每行每列 N 种颜色各出现一次;
  两套排布互不相同。
- 有 1~2 个单元格被整格涂黑(空格)。
- 生成约束:N 种微形状两两不能通过旋转或镜像互相重合;
  第一个训练示例中形状与颜色一一绑定(单系统可完全解释),
  后续示例中绑定解除;空格的形状与颜色在各自系统中均被
  行列唯一性强制唯一;空格不多于 2 个且互不同行同列。

规则
- 对每个空格,在形状系统里找出其所在行与列都缺失的那种唯一形状。
- 在颜色系统里找出其所在行与列都缺失的那种唯一颜色。
- 用该颜色画出该形状填入空格,其余单元格与分隔线不变。

关键洞察
- 一个格子身上叠着两套互不相干的行列唯一性约束:形状的答案和
  颜色的答案来自两次独立的排除法,任何"图章整体复制"式的
  单系统解释都会在形色解绑的示例上失效。
```

## 新题 2:同色传送门

**来源原语**:同色系配对/忽略干扰项(494ef9d7)、边缘标记/从边缘推进(f9a67cb5)、射线延伸(8886d717)

**诱饵假设**:第一个示例里,每对传送门都恰好摆在射线的同一条直线上——画面看起来是"射线笔直穿过整个网格,只是经过彩色点附近时有一段没上色"(隧穿假设)。第二个示例里传送门的出口偏到了别的行:路径整体侧移,隧穿假设当场碎掉;同时入口最近的彩色点是异色门,只有"从同色伙伴处继续"能解释路径落点。

```text
射线撞进彩色传送门就从它的同色伙伴门再钻出来,方向不变,一路画到飞出网格为止。

输入结构
- 黑背景网格,某条边界上有一个红(2)色单像素火种。
- 内部散布若干彩色单像素传送门:每种门色恰好出现两枚,
  互为伙伴;门色不用红色。可有一对从未被射线经过的门作干扰。
- 生成约束:第一个训练示例中,每对被使用的门都与射线共线
  (出口落在入射直线的延长线上,隧穿假设可完全解释路径);
  后续示例中至少一对门的出口偏离入射直线,且入口门附近
  最近的其他门是异色门;路径不与已画格及门重叠回环,
  传送 2~3 次后出界;出口门沿行进方向的下一格在网格内。

规则
- 火种从边界向内直线推进,沿途黑格涂红。
- 行进中撞到传送门像素时,不涂该门,改从它的同色伙伴门
  沿同一方向的下一格继续推进、继续涂红。
- 重复上述过程,直到射线飞出网格边界。
- 所有门、未涉及的区域保持不变,输出尺寸与输入相同。

关键洞察
- 路径在画面上是不连续的,但在"传送门把两点缝合为一点"的
  拓扑里是一条直线:必须先把同色门在脑中配成对,才知道
  射线消失后会从哪里再冒出来、又为什么方向分毫不变。
```

## 新题 3:迷宫里的势力范围

**来源原语**:洪泛填充/封闭区域(7447852a)、最近归属/等距留白(d22278a0)、墙段(f9a67cb5)

**诱饵假设**:第一个示例的墙很稀疏,按直线距离(欧氏/棋盘)划分的势力范围与真实答案完全一致——"每个格子归直线距离最近的源"成立。第二个示例里一堵长墙横在某源与一片空地之间:那片空地直线上离它最近,却要绕远路才能走到,结果被另一个源占领——距离必须**沿通道走**着量。

```text
各色源点同时在迷宫通道里扩张,每个空格归沿通道步数最近的源,等距的格子留黑作边界。

输入结构
- 网格由灰(5)色墙段与黑色通道组成,通道全连通。
- 通道内放着 2~3 个彩色单像素源点,颜色互不相同。
- 生成约束:第一个训练示例中沿通道最近与直线最近处处给出相同
  归属;后续示例中存在一片区域,其直线最近源与沿通道最近源
  不同(墙逼出绕行);至少一个示例中存在可见的等距缝
  (一列/一段保持黑色的分界格),钉死"等距留黑"约定。

规则
- 从每个源点出发,沿通道做四邻接逐步扩张,记录每格到各源的
  最短步数。
- 每个通道格涂成步数最小的那个源的颜色;若最小步数并列,
  该格保持黑色。
- 墙与源点不变,输出尺寸与输入相同。

关键洞察
- 距离的度量方式才是本题的规则:墙不改变谁在扩张,只改变
  "远近"二字的含义——直线上的邻居可能是通道里的天涯,
  分界缝出现的位置只能用步数解释。
```

## 新题 4:数出多数派,盖在少数派头上

**来源原语**:等分网格(c3202e5a)、瓦片/阵列排布(ccd554ac)、印章(c803e39c)、计数(6e02f1e3)

**诱饵假设**:格阵里只有两种图案、各自阵营内部完全一致,异类突出的直觉失效。第一个示例里多数派图案恰好同时满足三个便宜判据:先出现在阅读序、占据左上角、也更花哨——"以左上角/先出现/更复杂者为模板"都成立。第二个示例里少数派占着左上而且更花哨,且两派数量是 5:4——只有一格之差,哪边是模板只能靠一格一格数出来。

```text
两种图案分占格阵,数清谁多谁少,把多数派图案盖到每个少数派格位上,其余全部清黑。

输入结构
- 网格可被等分为 M×N 个同尺寸单元格(约 3×3),无分隔线。
- 每个单元格装着两种多色图案之一;同种图案的各份完全相同,
  两种图案的份数不相等。
- 生成约束:第一个训练示例中多数派同时是先出现、占左上、
  更花哨的一方,后续示例中这些属性全部倒向少数派;
  至少一个示例的两派数量仅差一份(如 5:4);两种图案
  形状配色均不同,肉眼可分辨但无明显繁简差异不作保证。

规则
- 数出两种图案各占多少个单元格,份数多者为多数派。
- 输出同尺寸网格:原少数派单元格的位置画上一份多数派图案,
  原多数派单元格的位置整格清黑。

关键洞察
- 没有"异类"可供直觉捕捉——两派各自整齐,判决只剩下最朴素
  也最费力的一步:数数;而多数派图案最终只出现在它从未
  出现过的位置上,数量与地盘在输出里完成了一次互换。
```

## 新题 5:点数即环号

**来源原语**:计数/数量映射(6e02f1e3)、同心环/裁剪/中心标记(d22278a0)、擦除(fbf15a0b)

**诱饵假设**:第一个示例里,散点数量少的颜色恰好也离中心标记最近,"按远近把各色排成由内而外的环"成立。第二个示例里最远的颜色只有一颗散点(占据最内环),且各色点数为 1、2、4——第 3 环空缺:任何"排序分配环号"的解释都填不出这个洞,环号只能等于**该色散点的个数**。

```text
数出每种颜色的散点个数 k,以灰色标记为中心画出半径为 k 的同色方环,散点本身被消耗。

输入结构
- 黑背景网格上有一个灰(5)色单像素中心标记,以及若干种颜色的
  散点(每种颜色 1~5 个,不同颜色的个数互不相同)。
- 生成约束:第一个训练示例中各色的个数排序恰与"到中心的平均
  距离"排序一致,后续示例中两者矛盾;至少一个示例的个数集合
  有空缺(如 1、2、4),对应环留黑;至少一个示例的中心偏置,
  使最大环被网格边界裁剪;散点位置与规则无关、可任意。

规则
- 统计每种颜色的散点个数 k。
- 对每种颜色,在与中心标记棋盘距离恰为 k 的全部格子上涂该色,
  形成一圈方环;出界部分裁掉。
- 没有颜色对应的半径保持黑色;所有散点从输出中清除,
  中心标记保留,输出尺寸与输入相同。

关键洞察
- 散点的位置是彻底的烟雾弹,它们唯一的贡献是"有几颗";
  环系里的空洞是决定性证据——顺序可以解释谁内谁外,
  只有计数才能解释为什么某一环谁都不是。
```

## 新题 6:叠层全反转

**来源原语**:印章覆盖(db118e2a)、实心矩形面板(19bb5feb)、矩形框范围还原(1a6449f1)

**诱饵假设**:第一个示例只有两两重叠,"把每块重叠区涂成另一个矩形的颜色"这条纯局部规则完全成立;而且首例处处是小矩形压大矩形,"小的永远在上"也成立。第二个示例出现三层叠压的区域:局部对调在那里根本无定义——三层区在输入里只见最上层,输出要的是最底层,中间那层的身份只能靠"甲压乙、乙压丙"的两两证词加传递性推出来;同时大矩形压住了小矩形,尺寸假设一并阵亡。

```text
从两两遮挡的证词推出每处叠压的完整上下序,重新渲染出整体翻转后的画面:处处露出原来的最底层。

输入结构
- 黑背景网格上有 3~4 个实心单色矩形,颜色互不相同,按某个
  隐藏的全局叠放次序绘制:每个格子显示覆盖它的矩形中最上层
  的颜色。
- 存在两两重叠区,后续示例中存在被三个矩形同时覆盖的区域。
- 生成约束:每个矩形的四个角均未被遮挡(完整范围可由同色像素
  边界框唯一还原);凡同时覆盖某区域的矩形集合,其内部全序
  可由画面上可见的两两遮挡证据经传递性唯一确定;第一个训练
  示例只含两两重叠且处处小压大,后续示例含三重区且有大压小。

规则
- 由每种颜色的可见像素还原出各矩形的完整范围。
- 由每处两两重叠区读出局部上下关系,经传递性排出所有相关
  矩形的全序。
- 重新渲染:每个被覆盖的格子改为显示覆盖它的矩形中原次序
  **最底层**的颜色(即整体叠放次序翻转后的画面)。
- 未被重叠的部分与背景不变,输出尺寸与输入相同。

关键洞察
- 三层区是局部规则的坟场:输入只给最上层、输出只要最底层,
  而最底层是谁在那块区域里根本没有直接证据——必须去别处
  收集两两压制的证词,靠传递性把整条链拼出来再倒过来。
```

## 新题 7:唯一的合缝分配

**来源原语**:修补(8886d717)、墙段(f9a67cb5)、滑动/平移(494ef9d7)

**诱饵假设**:第一个示例里每个拼块恰好离自己的缺口最近,"就近入座"全对。第二个示例里就近分配会让某块塞进形状差一个像素的缺口——拼块之间、缺口之间都近似到只差一两个像素,局部看谁都像能进两个坑;唯一的全局完美分配要靠"先找只有一块能进的缺口"的排除法一步步逼出来。

```text
把每个拼块平移进唯一能让墙体完全无缝的缺口里,近似的形状是陷阱,分配必须全局自洽。

输入结构
- 网格中有一段实心灰(5)色厚墙,墙的边缘开着 3 个形状不规则
  的缺口;墙外散落 3 个彩色拼块(颜色互不相同,不得旋转镜像)。
- 每个拼块的形状与不止一个缺口高度近似(仅差 1~2 个像素),
  但恰好严丝合缝的缺口只有一个;三块三坑的完美分配全局唯一。
- 生成约束:分配的唯一性由形状差保证,且存在唯一的排除法
  突破口(某个缺口只有一块能进);第一个训练示例中就近分配
  恰好等于正确分配,后续示例中至少一块的最近缺口是错的;
  拼块平移路径无需考虑,直接以形状匹配落位。

规则
- 对每个缺口,逐一检验哪些拼块能与它逐像素严丝合缝。
- 从只有唯一候选的缺口开始定案,排除已用拼块后继续,
  直到三块三坑全部一一对应。
- 把每个拼块从原位置擦除,画入所属缺口(保持各自颜色),
  墙体补合;输出尺寸与输入相同。

关键洞察
- "看起来能进"和"真的能进"差着一两个像素:任何凭轮廓相似或
  距离远近的贪心分配都会在某一步撞死;唯一解藏在约束传播里
  ——先锁死没有选择的那个坑,剩下的才依次有了答案。
```

## 新题 8:形状接力,同时结算

**来源原语**:微型图例/图例替换语义(e9b4f6fc)、模板(8e5a5113)、精灵体/位置锚定(8ee62060)

**诱饵假设**:双像素骨牌的强先验是颜色替换表;第一个示例(单张骨牌)里形状供体又恰好是全场最大、离受体最近的精灵——即使看出发生的是形状变化,首猜也停在"变成最大/最近那个的形状"。第二个示例给出接力链:骨牌 (A,B) 与 (B,C) 并存,B 既是 A 的供体又是 C 的受体——若按先后顺序结算,A 会拿到 C 的形状;输出证明所有替换**同时**以各精灵的原始形状结算,供体的指认只认骨牌右侧颜色。

```text
每张骨牌让左色精灵换上右色精灵的原始形状;多张骨牌成链时全部同时结算,谁也不用谁换过之后的形状。

输入结构
- 黑背景主区散布 3~5 个单色精灵体(颜色、形状互不相同,
  互不接触);底部一行区域放着 1~2 张水平双像素图例骨牌,
  与主区及彼此不相邻。
- 骨牌左右两色各对应主区一个精灵;两张骨牌可以共享颜色,
  构成接力链(如 (A,B) 与 (B,C))。
- 生成约束:受体的新旧形状像素数不同(变化可见);改形后以
  原边界框左上角为锚,不越界、不与他物接触;第一个训练示例
  仅一张骨牌,且供体恰为全场最大且离受体最近,后续示例中
  供体既非最大也非最近,并出现接力链;链上结算顺序的两种
  读法在输出上可区分(串行会让链首拿到链尾的形状)。

规则
- 读取每张骨牌:左色为受体,右色为形状供体。
- 所有替换同时进行:每个受体擦除原形状,在原边界框左上角
  画上其供体在**输入中**的原始形状,颜色仍用受体自己的颜色。
- 既是供体又是受体的精灵,先以原形状供出,再接受自己的新形状。
- 骨牌、未点名精灵与背景不变,输出尺寸与输入相同。

关键洞察
- 图例语法照旧,语义换了两层:传递的不是颜色而是形状,
  结算的不是流水而是快照——链上每个精灵供出的都是旧我,
  串行思维在接力链上必然多走一步、错一环。
```
