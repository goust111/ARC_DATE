# ARC 创新出题标准

> 本文档汇总基于参考题创新生成 ARC 风格新题的完整标准，
> 适用于 key_combo 出题流程（参考题组 → 新题 roundN.md）。

---

## 一、ARC 题目硬性要求（底线，任何新题必须满足）

### 格式约束

- 每题为若干"输入网格 → 输出网格"对：训练示例对 + 测试对（通常 1 个）。
- 网格为二维数组，尺寸 1×1 至 30×30，每格取值 0~9（十种颜色，0 惯例为黑色背景）。
- 输入输出尺寸可以不同，输出尺寸本身可以是规律的一部分。
- 判定为逐格完全一致（含尺寸），无部分分。

### 设计约束

1. **2~4 个训练示例可唯一归纳**：示例必须足以无歧义地钉死规则——
   不能存在两种都能解释全部示例、但对测试输入给出不同答案的合理规则。
   示例不是越多越好：若一条规则需要 5 个以上示例才能无歧义表达，
   说明规则该拆分或简化。
2. **答案唯一且确定**：同一输入对应唯一正确输出，变换无随机成分。
3. **新颖性**：变换逻辑与库中已有题目不同构，不是换颜色换尺寸的重复。

### 难度定位

对标 ARC-AGI-2：规则需要多步推理与概念组合（先识别结构、再推断映射、最后应用变换），
规则可依赖上下文（同一操作在不同位置含义不同），避免一眼可见的单步规则。

## 二、创新与难度判据

### 创新判据

**核心判据**：把每个原语单独替换掉，推理骨架是否仍然成立？
若骨架本身是旧的（线性流水线、单步查表），换再稀有的原语也只是换皮。
反之，骨架新颖的题不会因为"别的题也用过某原语"而贬值。

**新颖性按解题体验评估，不按设计血统评估**：解题者看不见一道题从哪个
旧骨架变形而来，看得见的是解题过程是否全新（证据的形态、要做的推理、
输出的表征）。血统上是旧题变体、但解题体验实质不同的设计，不因出身降级；
反之，语义上再优美的概念（规则"讲起来"很深刻），若解题者存在不经过
该概念的充分策略，不构成创新也不构成难度。

### 难度判据（解题者席位原则）

难度必须坐在**解题者席位**上评估，而不是作者席位。作者容易数"我预设的
解法有几步"，但解题者不执行作者的算法——解题者看一眼画面，解析出一个
"发生了什么"的故事，对不上示例就换故事。**难度 = 从第一眼最自然的故事
到正确故事之间的修正距离**，而非算法步骤数。逐题必过的操作化检验：

1. **最浅充分策略**：一道题的深度等于能解出它的**最浅**策略的深度，
   而非作者叙事的深度。列出所有能得到正确输出的策略，取最浅者评级。
2. **感知捷径清零**：镜像检测、行列对齐、异类突出、颜色分组、邻近分组
   是人眼免费完成的；凡依赖这些能力的"匹配/检测/发现"步骤，计为零步。
   （注意旋转匹配不在此列——人眼对旋转全等没有免费能力。）
3. **局部重述测试**：若一条全局规则存在等价的局部形式（逐处独立计算
   即可得到答案），难度以局部形式计。全局叙事不因写得宏大而加分。
4. **"找到即结束"测试**：若解题者找到关键证据后推理量为零（剩下的只是
   查表或照抄），该题本质是"找隐藏差异"，考细心不考推理。好题的形态
   相反——**组装性**：单件证据不足以给出答案，证据全部找齐之后，
   一段真实的组装工作（拼链、联立、聚类、解约束）才刚开始。
5. **过程语言症状**：若规则只能用过程语言写出（先扫描、再记录、再合并、
   再按某顺序处理），多半是执行难而非发现难；人难的题规则一句话说完，
   但从第一眼走到这句话的路很远。规则从句超过三四条的题，难度往往
   来自说明书厚度，须警惕。
6. **劳动不等于深度**：大量逐格比对、大数目点数、长链记账考验细心与
   耐心，可作为附加成本，但不计入推理深度。

### 定位说明

第四节的方向目录与本节判据均为参考方向，不是硬性配额；单维变异的
流水线/变体题目允许出现。创新以参考题目与原语为出发点，方向目录只
用来在卡壳与自检时提示"还可以往哪些方向走"。一切工具（轴、诱饵、
组装形态）都服务于同一目标：让正确规则无法被廉价拿到。

## 三、生成流程

以下为推荐流程而非强制。各步共同的目标只有一个：让正确规则无法被
廉价拿到——不能一眼看穿、不能被感知捷径白送、不能退化为局部查表。

1. **提取原语池**：将参考题组的 tags 拆为 operation / object / relation /
   condition 四类原语，逐题登记。注意原语是**材料不是种子**：ARC1 + ARC2
   一千多道题几乎穷尽了这一层词汇，原语可以自造或外引，但新颖性不来自
   词汇——原语只是词汇，句法才是作者的 signature；且单纯组合原语，
   得到的多是浅机制（组合空间里浅机制占绝对多数），质量的方向感由
   下一步提供。

2. **选定组装骨架**：先为每题选一种**组装形态**作为骨架，再回原语池
   找材料。组装形态指第二节难度判据第 4 条所要求的推理结构——证据
   全部找齐后仍需真实组装的形态。已知形态（开放列表，鼓励发明新的）：
   - **传递拼链**：证据是零散的两两关系，答案要求把它们经传递性
     连成全序或链条；
   - **多变量联立**：两个以上隐变量互为验证条件（不知甲便无法检验乙，
     反之亦然），必须作为整体假设联合试错；
   - **聚类后合并**：证据分属多个内部一致的群体，必须先分群、再在
     群内综合；跳过分群的全局统计会被其他群体污染，且错得自信；
   - **作用域依赖链**：每一步的解读依赖上一步的结果，且执行顺序由
     画面的几何/逻辑事实逼出，而非依靠约定；
   - **二层归纳**：把每个对象读成一个抽象值（角度、数量、类别、次序）
     之后，规律存在于这些值构成的第二层图案中，像素层看不见规律；
   - **约束系统求解**：答案是同时满足多条分布式约束的唯一解，须收集
     全部约束联立求解；可埋一个"与绝大多数证据相容、仅被一条否决"
     的近似解，惩罚不完全验证。
   组装形态管难度的地板，第四节方向目录中的轴管结构的新颖性，
   两者可自由组合。

3. **铸造与飞行否决**：把原语铸进骨架，做**紧耦合**——前一步的输出是
   后一步的输入、参数或前提，跳过任何一步都得不到答案。在设计过程中
   （而非完稿后）随时用第二节的难度判据否决：塌缩成局部查表的、被感知
   捷径白送的、找到证据即结束的，当场回炉。否决不只是删除——为堵死
   某条捷径而被迫改变输出表征、证据密度或执行顺序的来源，往往正是
   新颖性的出处；被否决逼出来的设计常好于灵感给出的设计。

4. **难度档案（施工要求，非验收报告）**：每题定稿前写出三行：
   - **第一眼的故事**：解题者看完第一个训练示例，形成的最自然假设
     是什么；
   - **最浅充分策略**：列出所有能解出本题的策略，最浅的一条是什么，
     它是否真的绕不开组装工作；
   - **组装工作**：证据找齐后，解题者还必须做哪一段推理。
   写不出"合理但错误的第一眼故事"，说明规则一个示例就能看穿；
   写不出被堵死的最浅策略，说明存在捷径——两种情况都回炉。
   在此基础上设计**示例分布**：让第一个示例恰好喂饱那个错误首猜
   （诱饵假设——与正确规则在首例上给出相同输出、在后续示例上分道的
   合理假设），后续示例将其打碎。诱饵是工具不是义务：有自然的诱饵
   就用足，靠结构深度取胜的题不硬造误导。

5. **自检**（每题必过）：
   - [ ] 规则可从 2~4 个训练示例唯一归纳；可能歧义处已用生成约束排除
     （干扰项、反例的精心摆放；配对依据和优先序必须被示例钉死）；
   - [ ] 隐蔽规则（阈值、方向、颜色来源）可通过对比示例发现；
   - [ ] **无不可学习的约定**：任意的平局规则、处理顺序等"给代码补
     确定性的补丁"，示例中不出现则不可证伪、出现则不可归纳——必须
     改为由画面事实逼出唯一行为，或用生成约束排除其发生；
   - [ ] 输出确定、答案唯一；
   - [ ] 骨架与参考题及常见 ARC 结构不同构；同一轮内各题的组装骨架
     互不重复；
   - [ ] **如实标注**：轮内难度下限的题、与参考题血缘最近的题，
     在自检记录中标明而非隐藏——校准与生成同等重要。

6. **覆盖检查**（round 级）：统计原语池覆盖率，未覆盖者说明理由。
   覆盖率是记录不是配额——为凑覆盖率往一题里堆原语，是"条款堆叠"
   （规则从句越来越多、难度来自说明书厚度）的首要来源。

## 四、方向目录（卡壳与查漏时用）

以下八条轴是"结构新颖性可以来自哪里"的目录。**它不是生成的出发点**：
设计从第三节的流程走。本目录只在两个时机使用——设计卡壳时翻一翻找
出路；轮级自检时对照一遍，检查整轮是否落进单一体裁（组装形态保证了
难度地板，但保证不了风味多样：一轮题可能全是演绎味，而没有过程、
反演、变分等其他体验）。

### 基础两轴

**句法轴（依赖拓扑）**

同一批原语，换一种依赖拓扑就是全新的推理体验。已验证有效的拓扑形态：

- **门控**：一个操作的结果决定另一个操作是否发生；
- **涌现结构**：操作的副产品成为后续操作的对象；
- **角色转变**：对象在推理链中途改变身份；
- **操作重定义匹配标准**：检测/匹配发生在变换之后而非之前；
- **位置与内容分离**：操作锚定在坐标上而内容已经移动；
- **一因多果**：同一信号驱动多个不同参数；
- **发散汇合**：一次求解产出多个信号分别驱动不同分支，或两条独立构造最后合并；
- **循环依赖**：必须先全局扫描确定分派，才能提取局部所需的材料；
- **决策树**：同一判据把对象路由到多条完全不同的操作分支。

**本体轴（解析层）——"像素是什么"被重新定义**

创新发生在输入到场景的解析方式本身，变换可以极简，但解析欠定、需重建潜在结构：

- **隐式对象（虚拟结构）**：参与规则的对象从未被完整画出，画面上只有它的
  生成元、投影或残迹，解题者要"看见不存在的东西"，推理负担前移到感知阶段；
- **隐含全局关系（隐变量归纳）**：对象都可见，但决定它们如何互动的约定
  （次序、归属、语义）不在画面上，须跨实例归纳出这个隐变量再应用。

本体轴的意外感来自**本体错位**，句法轴的来自**因果错位**，两者正交。

### 六条扩展轴

**示教轴（网格内示教，二阶归纳）**
规则本身作为数据编码在画面里，且每个训练示例携带的具体规则各不相同；
跨示例保持不变的只有"如何从画面里读出规则"这一层，归纳对象从规则升格为读规则的方法。
编码载体不限，任何能在网格内表达"一条变换"的形式都算。

**参照系轴（坐标系错位）**
规则只在某个非默认的参照系里才简单——坐标、方向、距离或邻接关系须由画面内容
重新定义，而非沿用网格自带的行列框架；解题者要先发现并重建这个框架，规则才现形。
与本体轴的分界：对象解析正常，改的是度量框架——一个是"看见什么"，一个是"从哪个角度量"。

**过程轴（过程/动力学，连锁反应）**
输出是某条局部规则反复自我触发、演化到终止条件（不动点、出界、耗尽）的结果，
迭代的步数与轨迹由数据决定，终态无法一步看出，只能把过程在脑中跑完。
与句法轴的分界：不是几种操作串依赖，是同一操作自我串联，步数由数据决定。

**反演轴（因果反演，溯因推理）**
输入呈现的是某个过程作用之后的结果态，答案是它的原因、前状态或最小生成源。
解题者必须先从残留的证据归纳出正向过程，再逆着跑。反演天然比正向难一档。

**变分轴（目标态/变分，最优性原则）**
规则是验收标准而非流程：只规定输出必须满足的全局性质，以及编辑代价上的约束
（最小、恰好、唯一），不给任何构造步骤，解题者要自己发明求解过程。

**自指轴（地图与疆域）**
画面的一部分是对画面自身（或其余部分）的描述，同一份像素身兼"内容"与
"关于内容的描述"两层身份，规则围绕两层之间的一致性、指称或互相修正展开；
描述层的编码形式不限。ARC 语料中几乎没有，人类解起来有明显"啊哈"感。

### 轴间关系

- **边界辨析**：参照系轴与本体轴都发生在读图阶段，但本体改"什么算对象"、
  参照系改"在哪个坐标系里量"；示教轴是句法轴"参数内生化"（把规则中的
  常数搬进画面成为可读元素）的极限延伸——参数内生化搬进的是常数，
  示教搬进的是整个变换程序（归纳对象从规则升格为读规则的方法）。
- **歧义防线**：变分类必须靠构造保证最优解唯一；反演类是天然多解的逆问题，
  须靠生成约束钉死唯一答案；过程模拟类只要局部规则确定，唯一性天然成立。
- **叠加**：各轴可自由组合，本体 + 句法的组合最接近 ARC-2 难题形态。

## 五、书写格式

- 新题用**纯中文 docstring**书写，结构与参考题一致：
  1. 一句话总述；
  2. 输入结构；
  3. 规则；
  4. 关键洞察。
- 每题另附**难度档案**三行（第一眼的故事 / 最浅充分策略 / 组装工作）
  与来源原语；轮末附自检记录与覆盖检查。
- 一轮的所有新题存于同一 md 文档，命名 `roundN.md`，题目序号从 1 起排。
